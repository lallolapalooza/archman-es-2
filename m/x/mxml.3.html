mxml(3) API de Mini-XML mxml(3)

NOMBRE

mxml - API de Mini-XML

ARCHIVO DE INCLUSIÓN

#include <mxml.h>

LIBRERÍA

-lmxml

DESCRIPCIÓN

Mini-XML es una pequeña biblioteca de análisis de XML que puede utilizar para leer archivos de datos XML y similares a XML en su aplicación sin requerir bibliotecas grandes no estándar. Mini-XML solo requiere un compilador compatible con ANSI C (GCC funciona, al igual que los compiladores ANSI C de la mayoría de los proveedores) y un programa "make".

Mini-XML proporciona la siguiente funcionalidad:

  • Lectura de archivos y cadenas XML codificados en UTF-8 y UTF-16 y escritura de archivos y cadenas XML codificados en UTF-8.
  • Los datos se almacenan en una estructura de árbol de lista enlazada, preservando la jerarquía de datos XML.
  • Soporta nombres de elementos, atributos y valores de atributos arbitrarios sin límites preestablecidos, solo la memoria disponible.
  • Soporta tipos de datos entero, real, opaco ("CDATA") y de texto en nodos "hoja".
  • Funciones para crear, indexar y administrar árboles de datos.
  • Funciones "Find" y "walk" para localizar y navegar fácilmente árboles de datos.

Mini-XML no realiza validación u otros tipos de procesamiento de datos basándose en archivos de esquema u otras fuentes de información de definición, ni soporta entidades de caracteres distintas de las requeridas por la especificación XML.

USANDO MINI-XML

Mini-XML proporciona un único archivo de encabezado que puede incluir:

    #include <mxml.h>

Los nodos se definen por la estructura "mxml_node_t"; el miembro "type" define el tipo de nodo (elemento, entero, opaco, real o texto) que determina qué valor desea ver en la unión "value". Se pueden crear nuevos nodos utilizando las funciones "mxmlNewElement()", "mxmlNewInteger()", "mxmlNewOpaque()", "mxmlNewReal()" y "mxmlNewText()". Solo los elementos pueden tener nodos hijos, y el nodo superior debe ser un elemento, generalmente "?xml".

Carga un archivo XML usando la función "mxmlLoadFile()":

    FILE *fp;
    mxml_node_t *tree;
    fp = fopen("nombre_archivo.xml", "r");
    tree = mxmlLoadFile(NULL, fp, MXML_NO_CALLBACK);
    fclose(fp);

De manera similar, guarda un archivo XML usando la función "mxmlSaveFile()":

    FILE *fp;
    mxml_node_t *tree;
    fp = fopen("nombre_archivo.xml", "w");
    mxmlSaveFile(tree, fp, MXML_NO_CALLBACK);
    fclose(fp);

Las funciones "mxmlLoadString()", "mxmlSaveAllocString()" y "mxmlSaveString()" cargan árboles de nodos XML desde y guardan árboles de nodos XML en cadenas:

    char buffer[8192];
    char *ptr;
    mxml_node_t *tree;
    ...
    tree = mxmlLoadString(NULL, buffer, MXML_NO_CALLBACK);
    ...
    mxmlSaveString(tree, buffer, sizeof(buffer),
                   MXML_NO_CALLBACK);
    ...
    ptr = mxmlSaveAllocString(tree, MXML_NO_CALLBACK);

Puede encontrar un elemento/nodo con nombre usando la función "mxmlFindElement()":

    mxml_node_t *node = mxmlFindElement(tree, tree, "nombre",
                                        "atributo", "valor",
                                        MXML_DESCEND);

Los argumentos "nombre", "atributo" y "valor" se pueden pasar como NULL para actuar como comodines, por ejemplo:

    /* Encuentra el primer elemento "a" */
    node = mxmlFindElement(tree, tree, "a", NULL, NULL,
                           MXML_DESCEND);
    /* Encuentra el primer elemento "a" con atributo "href" */
    node = mxmlFindElement(tree, tree, "a", "href", NULL,
                           MXML_DESCEND);
    /* Encuentra el primer elemento "a" con "href" a una URL */
    node = mxmlFindElement(tree, tree, "a", "href",
                           "http://www.easysw.com/~mike/mxml/",
                           MXML_DESCEND);
    /* Encuentra el primer elemento con un atributo "src" */
    node = mxmlFindElement(tree, tree, NULL, "src", NULL,
                           MXML_DESCEND);
    /* Encuentra el primer elemento con "src" = "foo.jpg" */
    node = mxmlFindElement(tree, tree, NULL, "src",
                           "foo.jpg", MXML_DESCEND);

También puede iterar con la misma función:

    mxml_node_t *node;
    for (node = mxmlFindElement(tree, tree, "nombre", NULL,
                                NULL, MXML_DESCEND);
         node != NULL;
         node = mxmlFindElement(node, tree, "nombre", NULL,
                                NULL, MXML_DESCEND))
    {
      ... haz algo ...
    }

Para encontrar el valor de un nodo específico en el árbol, use la función "mxmlFindPath()":

    mxml_node_t *value = mxmlFindPath(tree, "ruta/a/*/foo/bar");

Las funciones "mxmlGetInteger()", "mxmlGetOpaque()", "mxmlGetReal()" y "mxmlGetText()" recuperan el valor de un nodo:

    mxml_node_t *node;
    int intvalue = mxmlGetInteger(node);
    const char *opaquevalue = mxmlGetOpaque(node);
    double realvalue = mxmlGetReal(node);
    int whitespacevalue;
    const char *textvalue = mxmlGetText(node, &whitespacevalue);

Finalmente, una vez que haya terminado con los datos XML, use la función "mxmlDelete()" para liberar recursivamente la memoria que se utiliza para un nodo particular o para todo el árbol:

    mxmlDelete(tree);

FUNCIONES

mxmlAdd

Añadir un nodo a un árbol.

void mxmlAdd (
    mxml_node_t *parent,
    int where,
    mxml_node_t *child,
    mxml_node_t *node
);

Añade el nodo especificado al padre. Si el argumento hijo no es NULL, coloca el nuevo nodo antes o después del hijo especificado dependiendo del valor del argumento where. Si el argumento hijo es NULL, coloca el nuevo nodo al principio de la lista de hijos (MXML_ADD_BEFORE) o al final de la lista de hijos (MXML_ADD_AFTER). La constante MXML_ADD_TO_PARENT puede usarse para especificar un puntero hijo NULL.

mxmlFindElement

Busca el elemento con el nombre especificado.

mxml_node_t * mxmlFindElement (
    mxml_node_t *node,
    mxml_node_t *top,
    const char *element,
    const char *attr,
    const char *value,
    int descend
);

La búsqueda está limitada por el nombre del elemento, el nombre del atributo y el valor; cualquier nombre o valor NULL se trata como un comodín, por lo que se pueden implementar diferentes tipos de búsquedas buscando todos los elementos de un nombre dado o todos los elementos con un atributo específico. El argumento descend determina si la búsqueda desciende a nodos hijos; normalmente utilizará MXML_DESCEND_FIRST para la búsqueda inicial y MXML_NO_DESCEND para encontrar descendientes directos adicionales del nodo. El argumento nodo superior limita la búsqueda a los hijos de un nodo particular.

mxmlFindPath

Busca un nodo con la ruta dada.

mxml_node_t * mxmlFindPath (
    mxml_node_t *top,
    const char *path
);

La "ruta" es una lista de nombres de elementos separados por barras. El nombre "" se considera un comodín para uno o más niveles de elementos. Por ejemplo, "foo/one/two", "bar/two/one", "/one", y así sucesivamente.

Se devuelve el primer nodo hijo del nodo encontrado si el nodo dado tiene hijos y el primer hijo es un nodo de valor.

Obtiene el valor de texto para un nodo o su primer hijo.

    mxml_node_t *node,
    int *whitespace
);

Se devuelve NULL si el nodo (o su primer hijo) no es un nodo de texto. El argumento "whitespace" puede ser NULL.

Nota: Los nodos de texto consisten en palabras delimitadas por espacios en blanco. Solo obtendrá palabras de texto individuales al leer un archivo XML con nodos MXML_TEXT. Si desea la cadena completa entre elementos en el archivo XML, DEBE leer el archivo XML con nodos MXML_OPAQUE y obtener las cadenas resultantes utilizando la función mxmlGetOpaque en su lugar.

mxmlIndexNew

Crea un nuevo índice.

    mxml_node_t *node,
    const char *element,
    const char *attr
);

El índice contendrá todos los nodos que contengan el elemento y/o atributo especificado. Si tanto "element" como "attr" son NULL, el índice contendrá una lista ordenada de los elementos en el árbol de nodos. Los nodos se ordenan por nombre de elemento y opcionalmente por valor de atributo si el argumento "attr" no es NULL.

mxmlLoadFd

Carga un descriptor de archivo en un árbol de nodos XML.

mxml_node_t * mxmlLoadFd (
    mxml_node_t *top,
    int fd,
    mxml_load_cb_t cb
);

Los nodos del archivo especificado se añaden al nodo superior proporcionado. Si no se proporciona ningún nodo superior, el archivo XML DEBE estar bien formado con un único nodo padre como
para todo el archivo. La función de devolución de llamada devuelve el tipo de valor que se debe utilizar para los nodos hijos. Las constantes MXML_INTEGER_CALLBACK, MXML_OPAQUE_CALLBACK, MXML_REAL_CALLBACK y MXML_TEXT_CALLBACK están definidas para cargar nodos de datos (hijos) del tipo especificado.

Nota: El error de programación más común al usar la biblioteca Mini-XML es cargar un archivo XML usando MXML_TEXT_CALLBACK, que devuelve el texto en línea como una serie de palabras separadas por espacios en blanco, en lugar de usar MXML_OPAQUE_CALLBACK, que devuelve el texto en línea como una sola cadena (incluyendo espacios en blanco).

    void *sax_data
);

Los nodos del archivo especificado se añaden al nodo superior especificado. Si no se proporciona un nodo superior, el archivo XML DEBE estar bien formado con un único nodo padre, como
para todo el archivo. La función de devolución de llamada devuelve el tipo de valor que debe utilizarse para los nodos hijos. Las constantes MXML_INTEGER_CALLBACK, MXML_OPAQUE_CALLBACK, MXML_REAL_CALLBACK y MXML_TEXT_CALLBACK se definen para cargar nodos hijos del tipo especificado.

La callback SAX debe llamar a mxmlRetain para cualquier nodo que deba conservarse para uso posterior. De lo contrario, los nodos se eliminarán cuando se cierre el nodo padre o después de cada nodo de datos, comentario, CDATA o directiva.

Guarda un árbol XML en una cadena asignada.

char * mxmlSaveAllocString (
    mxml_node_t *node,
    mxml_save_cb_t cb
);

Esta función devuelve un puntero a una cadena que contiene la representación textual del árbol de nodos XML. La cadena debe liberarse usando free() cuando haya terminado con ella. Se devuelve NULL si el nodo produciría una cadena vacía o si no se puede asignar la cadena.

El argumento de devolución de llamada especifica una función que devuelve una cadena de espacios en blanco o NULL antes y después de cada elemento. Si se especifica MXML_NO_CALLBACK, solo se añadirán espacios en blanco antes de los nodos MXML_TEXT con espacios en blanco iniciales y antes de los nombres de los atributos dentro de las etiquetas de los elementos de apertura.
