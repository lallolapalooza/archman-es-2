Nombre

mysql_sqlstate - devuelve el código de error SQLSTATE

Sintaxis

#include <mysql.h>
const char * mysql_sqlstate(MYSQL * mysql);

Descripción

Devuelve una cadena que contiene el código de error SQLSTATE para la función invocada más recientemente que puede tener éxito o fallar. El código de error consta de cinco caracteres. `00000' significa que no hay error. Los valores están especificados por ANSI SQL y ODBC.

Parámetro

Notas

Tenga en cuenta que no todos los códigos de error de la biblioteca cliente se mapean a errores SQLSTATE. Los errores que no se pueden mapear se devolverán con el valor HY000.

Valor de retorno

Una cadena que contiene el código de error SQLSTATE.
