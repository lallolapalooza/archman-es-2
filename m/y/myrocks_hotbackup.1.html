NOMBRE

myrocks_hotbackup - copia de seguridad en streaming para MariaDB MyRocks

DESCRIPCIÓN

Uso:

Copia de seguridad: establezca -o pipefail; myrocks_hotbackup --user=root --password=pw --port=3306 --checkpoint_dir=<directorio donde se crean los enlaces duros temporales de copia de seguridad> | ssh -o NoneEnabled=yes servidor_remoto 'tar -xi -C <directorio en el servidor remoto donde se enviarán las copias de seguridad>' . Debe ejecutar el comando de copia de seguridad en un servidor desde el que realice copias de seguridad.

Copia de seguridad usando WDT: myrocks_hotbackup --user=root --password=pw --stream=wdt --checkpoint_dir=<directorio donde se crean los enlaces duros temporales de copia de seguridad> --destination=<nombre del host remoto> --backup_dir=<nombre del directorio remoto>. Esto debe ejecutarse en el host de origen.

Mover-Copia de seguridad: myrocks_hotbackup --move_back --datadir=<datadir de mysql de destino> --rocksdb_datadir=<datadir de rocksdb de destino> --rocksdb_waldir=<directorio wal de rocksdb de destino> --backup_dir=<dónde se almacenan los archivos de copia de seguridad> . Debe ejecutar el comando mover-copia de seguridad en un servidor donde se envían los archivos de copia de seguridad.

OPCIONES

-h, --help
mostrar este mensaje de ayuda y salir
-i INTERVALO_PUNTO_CONTROL, --interval=INTERVALO_PUNTO_CONTROL
Número de segundos para renovar el punto de control
-c DIRECTORIO_PUNTO_CONTROL, --checkpoint_dir=DIRECTORIO_PUNTO_CONTROL
Nombre del directorio local donde se crearán los puntos de control.
-d DATADIR, --datadir=DATADIR
modo de copia de seguridad: datadir de MySQL de origen. modo mover_copia de seguridad: datadir de MySQL de destino
-s FLUJO_SALIDA, --stream=FLUJO_SALIDA
Configuración de opciones de copia de seguridad en streaming. Actualmente se admiten tar, WDT y xbstream. El valor predeterminado es tar
--destination=DESTINO
Nombre del servidor remoto. Solo se utiliza para el modo WDT hasta ahora.
--avg_mbytes_per_sec=AVG_MBYTES_PER_SEC
Velocidad media de copia de seguridad en MBytes/seg. Solo WDT.
--extra_wdt_sender_options=EXTRA_WDT_SENDER_OPTIONS
Opciones adicionales para el emisor WDT
--extra_wdt_receiver_options=EXTRA_WDT_RECEIVER_OPTIONS
Opciones adicionales para el receptor WDT
-u USUARIO_MYSQL, --user=USUARIO_MYSQL
Nombre de usuario de MySQL
-p CONTRASEÑA_MYSQL, --password=CONTRASEÑA_MYSQL
Nombre de la contraseña de MySQL
-P PUERTO_MYSQL, --port=PUERTO_MYSQL
Número de puerto de MySQL
-S SOCKET_MYSQL, --socket=SOCKET_MYSQL
Ruta del socket de MySQL. Tiene prioridad sobre --port.
-m, --move_back
Mover los archivos de copia de seguridad de MyRocks a las ubicaciones correctas.
-r ROCKSDB_DATADIR, --rocksdb_datadir=ROCKSDB_DATADIR
Directorio de datos de destino de RocksDB donde se moverán los archivos de datos de copia de seguridad. Debe estar vacío.
-w ROCKSDB_WALDIR, --rocksdb_waldir=ROCKSDB_WALDIR
Directorio de datos de destino de RocksDB donde se moverán los archivos wal de copia de seguridad. Debe estar vacío.
-b DIRECTORIO_COPIA_SEGURIDAD, --backup_dir=DIRECTORIO_COPIA_SEGURIDAD
modo de copia de seguridad para WDT: Directorio remoto para almacenar la copia de seguridad. modo mover_copia de seguridad: Ubicaciones donde se almacenan los archivos de copia de seguridad.
-f, --skip_check_frm_timestamp
omitir la comprobación de si los archivos frm se actualizan después de iniciar la copia de seguridad.
-D ARCHIVO_SEÑAL_DEBUG, --debug_signal_file=ARCHIVO_SEÑAL_DEBUG
propósito de depuración: esperar hasta que se cree el archivo especificado
