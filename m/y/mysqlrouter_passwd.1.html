NOMBRE

mysqlrouter_passwd - Herramienta de contraseñas de MySQL Router

SINOPSIS

mysqlrouter_passwd [opciones]

DESCRIPCIÓN

La utilidad mysqlrouter_passwd es una aplicación de línea de comandos para administrar las cuentas en el archivo passwd. Para ver un ejemplo de uso, consulte la Sección 6.1, "Una guía simple para la API REST de MySQL Router".

Información de uso:

Uso
  bin/mysqlrouter_passwd [opts] <comando> <nombre_archivo> [<nombre_usuario>]
  bin/mysqlrouter_passwd --help
  bin/mysqlrouter_passwd --version
Comandos
  delete
      Elimina el nombre de usuario (si existe) de <nombre_archivo>.
  list
      Lista una o todas las cuentas de <nombre_archivo>.
  set
      Agrega o sobrescribe la cuenta de <nombre_usuario> en <nombre_archivo>.
  verify
      Verifica si la contraseña coincide con las credenciales de <nombre_usuario> en <nombre_archivo>.
Opciones
  -?, --help
      Muestra esta ayuda y sale.
  --kdf <nombre>
      Función de derivación de clave (KDF) para 'set'. Una de pbkdf2-sha256, pbkdf2-sha512,
      sha256-crypt, sha512-crypt. Por defecto: sha256-crypt
  -V, --version
      Muestra información de la versión y sale.
  --work-factor <número>
      Indicador de factor de trabajo para KDF si se actualiza la cuenta.
