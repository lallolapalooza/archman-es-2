mysql_stmt_attr_get(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_stmt_attr_get(3) MariaDB Connector/C mysql_stmt_attr_get(3)

Nombre

mysql_stmt_attr_get - Obtiene el valor actual de un atributo de sentencia

Sinopsis

#include <mysql.h>
my_bool mysql_stmt_attr_get(MYSQL_STMT * stmt,
                            enum enum_stmt_attr_type,
                            void * attr);

Descripción

Obtiene el valor actual de un atributo de sentencia. Devuelve cero si tiene éxito, distinto de cero si falla.

Parámetro

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
enum_stmt_attr_type - atributo. Ver abajo.
•
attr - puntero a una variable, que contendrá el valor del atributo.

Tipos de atributos

El parámetro enum_stmt_attr_type tiene los siguientes valores posibles:

Valor Tipo Descripción
STMT_ATTR_UPDATE_MAX_LENGTH my_bool * Indica si mysql_stmt_store_result(3) actualizará el valor max_length de las estructuras MYSQL_FIELD.
STMT_ATTR_CURSOR_TYPE unsigned long * Los valores posibles son CURSOR_TYPE_READ_ONLY o el valor predeterminado CURSOR_TYPE_NO_CURSOR.
STMT_ATTR_PREFETCH_ROWS unsigned long * Número de filas que se pre-cargarán. El valor predeterminado es 1.
STMT_ATTR_PREBIND_PARAMS unsigned int * Número de parámetros utilizados para mariadb_stmt_execute_direct(3)
STMT_ATTR_STATE enum mysql_stmt_state * Estado de la sentencia preparada. Los valores posibles se definen en enum mysql_stmt_state. Esta opción se añadió en MariaDB Connector/C 3.1.0

Notas

•
Establecer el número de filas pre-cargadas solo funcionará para cursores de solo lectura.
