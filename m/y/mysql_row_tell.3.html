Nombre

mysql_row_tell - Devuelve el desplazamiento de fila de un cursor de resultados

Sinopsis

#include <mysql.h>
MYSQL_ROW_OFFSET mysql_row_tell(MYSQL_RES * res);

Descripción

Devuelve el desplazamiento de fila de un cursor de resultados. El valor de desplazamiento devuelto se puede utilizar para reposicionar el cursor de resultados llamando a mysql_row_seek(3).

Parámetro

•
res - un identificador de conjunto de resultados devuelto por mysql_store_result(3).

Notas

•
Esta función no funcionará si el conjunto de resultados se obtuvo mediante mysql_use_result(3).

Véase también

•
mysql_store_result(3)
•
mysql_row_seek(3)
