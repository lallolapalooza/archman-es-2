Nombre

mysql_session_track_get_next - Recupera la información del siguiente cambio de estado de la sesión

Sinopsis

#include <mysql.h>
int mysql_session_track_get_next(MYSQL * mysql,
                                 enum enum_session_state_type type,
                                 const char **data,
                                 size_t *length );

Descripción

mysql_session_track_get_next() recupera la información del cambio de estado de la sesión recibida del servidor después de una llamada exitosa a mysql_session_track_get_first(3).

mysql_session_track_get_next() debe ser llamada repetidamente hasta que un valor de retorno distinto de cero indique el fin de los datos.

Parámetros

•
mysql - manejador mysql, previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
type - tipo de información. Los valores válidos son
•
SESSION_TRACK_SYSTEM_VARIABLES
•
SESSION_TRACK_SCHEMA
•
SESSION_TRACK_STATE_CHANGE
•
SESSION_TRACK_GTIDS (no soportado)
•
data - puntero a los datos, que debe declararse como const char *
•
length - puntero a una variable size_t, que contendrá la longitud de los datos

Valor de retorno

Cero para éxito, distinto de cero si ocurrió un error.

Historial

mysql_session_track_get_next() se añadió en Connector/C 3.0 y MariaDB Server 10.2.
