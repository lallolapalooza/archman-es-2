MARIADB-HOTCOPY(1) Sistema de bases de datos MariaDB MARIADB-HOTCOPY(1)

NOMBRE

mariadb-hotcopy - un programa de copia de seguridad de bases de datos (mariadb-hotcopy es ahora un enlace simbólico a mariadb-hotcopy)

SINOPSIS

mariadb-hotcopy argumentos

DESCRIPCIÓN

mariadb-hotcopy es un script de Perl que fue escrito y contribuido originalmente por Tim Bunce. Utiliza FLUSH TABLES, LOCK TABLES y cp o scp para realizar una copia de seguridad de la base de datos. Es una forma rápida de hacer una copia de seguridad de la base de datos o de tablas individuales, pero solo puede ejecutarse en la misma máquina donde se encuentran los directorios de la base de datos. mariadb-hotcopy solo funciona para hacer copias de seguridad de tablas MyISAM y ARCHIVE. Se ejecuta en Unix y NetWare.

Para usar mariadb-hotcopy, debe tener acceso de lectura a los archivos de las tablas de las que está haciendo una copia de seguridad, el privilegio SELECT para esas tablas, el privilegio RELOAD (para poder ejecutar FLUSH TABLES) y el privilegio LOCK TABLES (para poder bloquear las tablas).

shell> mariadb-hotcopy nombre_bd [/ruta/a/nuevo_directorio]
shell> mariadb-hotcopy nombre_bd_1 ... nombre_bd_n /ruta/a/nuevo_directorio

Hacer copia de seguridad de tablas en la base de datos dada que coincidan con una expresión regular:

shell> mariadb-hotcopy nombre_bd./regex/

La expresión regular para el nombre de la tabla puede ser negada prefijándola con una tilde (“~”):

shell> mariadb-hotcopy nombre_bd./~regex/

mariadb-hotcopy admite las siguientes opciones, que pueden especificarse en la línea de comandos o en los grupos de archivos de opciones [mariadb-hotcopy] y [client].

•--help, -?

Muestra un mensaje de ayuda y sale.

•--addtodest

No renombra el directorio de destino (si existe); simplemente añade archivos a él.

•--allowold

No aborta si existe un destino; lo renombra añadiendo el sufijo _old.

•--checkpoint=nombre_bd.nombre_tabla

Inserta entradas de punto de control en la base de datos nombre_bd y tabla nombre_tabla especificada.

•--chroot=ruta

Directorio base de la cárcel chroot en la que opera mariadbd. El valor de ruta debe coincidir con el de la opción --chroot dada a mariadbd.

•--debug

Habilita la salida de depuración.

•--dryrun, -n

Informa sobre las acciones sin realizarlas.

•--flushlog

Vacía los registros después de bloquear todas las tablas.

•--host=nombre_host, -h nombre_host

El nombre de host de la máquina local a utilizar para establecer una conexión TCP/IP con el servidor local. Por defecto, la conexión se establece a localhost utilizando un archivo de socket de Unix.

•--keepold

No elimina el destino anterior (renombrado) al finalizar.

•--method=comando

El método para copiar archivos (cp o scp). El valor predeterminado es cp.

•--noindices

No incluye los archivos de índice completos para las tablas MyISAM en la copia de seguridad. Esto hace que la copia de seguridad sea más pequeña y rápida. Los índices para las tablas recargadas se pueden reconstruir más tarde con myisamchk -rq.

•--old-server

Conéctate a un servidor MySQL antiguo (anterior a v5.5) que no tiene FLUSH TABLES WITH READ LOCK completamente implementado.

•--password=contraseña, -pcontraseña

La contraseña a utilizar al conectarse al servidor. El valor de la contraseña no es opcional para esta opción, a diferencia de otros programas de MariaDB.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puede utilizar un archivo de opciones para evitar proporcionar la contraseña en la línea de comandos.

•--port=número_puerto, -P número_puerto

El número de puerto TCP/IP a utilizar al conectarse al servidor local.

•--quiet, -q

Sé silencioso excepto por los errores.

•--record_log_pos=nombre_bd.nombre_tabla

Registra el estado del maestro y del esclavo en la base de datos nombre_bd y tabla nombre_tabla especificadas.

•--regexp=exp

Copia todas las bases de datos cuyos nombres coincidan con la expresión regular dada.

•--resetmaster

Restablece el log binario después de bloquear todas las tablas.

•--resetslave

Restablece el archivo master.info después de bloquear todas las tablas.

•--socket=ruta, -S ruta

El archivo de socket de Unix a utilizar para las conexiones a localhost.

•--suffix=str

El sufijo a utilizar para los nombres de las bases de datos copiadas.

•--tmpdir=ruta

El directorio temporal. El valor predeterminado es /tmp.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor.

Utilice perldoc para obtener documentación adicional de mariadb-hotcopy, incluida información sobre la estructura de las tablas necesarias para las opciones --checkpoint y --record_log_pos:

shell> perldoc mariadb-hotcopy
