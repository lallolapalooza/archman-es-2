mysql_get_ssl_cipher(3) Conector/C de MariaDB mysql_get_ssl_cipher(3)

Nombre

mysql_get_ssl_cipher - devuelve el conjunto de cifrado en uso

Sinopsis

#include <mysql.h>
const char *mysql_get_ssl_cipher(MYSQL *mysql)

Descripción

Devuelve el nombre del conjunto de cifrado actualmente utilizado para la conexión segura, o NULL para conexiones no TLS.

Parámetro

•
mysql - un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).

Notas

•
Para usar mysql_get_ssl_cipher(), MariaDB Connector/C debe ser compilado con soporte TLS/SSL; de lo contrario, la función devolverá NULL.
•
`mysql_get_ssl_cipher()’ puede ser utilizado para determinar si la conexión cliente-servidor es segura.
•
Dependiendo de la biblioteca TLS en uso (OpenSSL, GnuTLS o Windows Schannel), el nombre de los conjuntos de cifrado puede variar. Por ejemplo, el conjunto de cifrado 0x002F (TLS_RSA_WITH_AES_128_CBC_SHA) tiene nombres diferentes: AES128-SHA para OpenSSL y Schannel, y TLS_RSA_AES_128_CBC_SHA1 para GnuTLS.

Valor de retorno

Devuelve una cadena terminada en cero que contiene el conjunto de cifrado utilizado para una conexión segura, o NULL si la conexión no utiliza TLS/SSL.
