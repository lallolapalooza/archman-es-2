mysql_refresh(3) Conector/C de MariaDB mysql_refresh(3)

Nombre

mysql_refresh - vacía información en el servidor

Sintaxis

#include <mysql.h>
int mysql_refresh(MYSQL * mysql, unsigned int options);

Descripción

Vacía diferentes tipos de información almacenada en el servidor. El parámetro con máscara de bits options especifica qué tipo de información se vaciará.

Parámetros

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
options - un entero compuesto con máscara de bits. Ver más abajo.

options puede ser cualquier combinación de las siguientes banderas:

Opción Descripción
REFRESH_GRANT Refresca las tablas de permisos.
REFRESH_LOG Vacía los registros.
REFRESH_TABLES Vacía la caché de tablas.
REFRESH_HOSTS Vacía la caché de hosts.
REFRESH_STATUS Reinicia las variables de estado.
REFRESH_THREADS Vacía la caché de hilos.
REFRESH_SLAVE Reinicia la información del servidor maestro y reinicia los esclavos.
REFRESH_MASTER Elimina los archivos de registro binarios.

Notas

•
Para combinar diferentes valores en el parámetro options, use el operador OR `|'.
•
mysql_reload() es un alias para mysql_refresh().

Valor de retorno

Devuelve cero si la operación tuvo éxito, de lo contrario, un valor distinto de cero.
