MARIADB-INSTALL-DB(1) Sistema de base de datos MariaDB MARIADB-INSTALL-DB(1)

NOMBRE

mariadb-install-db - inicializa el directorio de datos de MariaDB (mariadb-install-db es ahora un enlace simbólico a mariadb-install-db)

SINOPSIS

mariadb-install-db [opciones]

DESCRIPCIÓN

mariadb-install-db inicializa el directorio de datos de MariaDB y crea las tablas del sistema que contiene, si no existen.

Para invocar mariadb-install-db, usa la siguiente sintaxis:

shell> mariadb-install-db [opciones]

Como el servidor MariaDB, mariadbd, necesita acceder al directorio de datos cuando se ejecute más tarde, deberías ejecutar mariadb-install-db desde la misma cuenta que se usará para ejecutar mariadbd o ejecutarlo como root y usar la opción --user para indicar el nombre de usuario con el que se ejecutará mariadbd. Podría ser necesario especificar otras opciones como --basedir o --datadir si mariadb-install-db no usa las ubicaciones correctas para el directorio de instalación o el directorio de datos. Por ejemplo:

shell> bin/mariadb-install-db --user=mysql \
         --basedir=/opt/mysql/mysql \
         --datadir=/opt/mysql/mysql/data

mariadb-install-db necesita invocar mariadbd con las opciones --bootstrap y --skip-grant-tables (ver Sección 2.3.2, “Opciones de configuración típicas”). Si MariaDB se configuró con la opción --disable-grant-options, --bootstrap y --skip-grant-tables se deshabilitarán. Para manejar esto, establece la variable de entorno mariadbd_BOOTSTRAP con la ruta completa a un servidor que tenga todas las opciones habilitadas. mariadb-install-db usará ese servidor.

mariadb-install-db admite las siguientes opciones, que pueden especificarse en la línea de comandos o en los grupos de opciones [mariadb-install-db] y (si son comunes a mariadbd) [mariadbd].

•--basedir=ruta

La ruta al directorio de instalación de MariaDB.

•--builddir=ruta

Si usas --srcdir con compilaciones fuera del directorio, necesitarás establecer esto a la ubicación del directorio de compilación donde residen los archivos compilados.

•--cross-bootstrap

Para uso interno. Se usa al compilar las tablas del sistema de MariaDB en un host diferente al destino.

•--datadir=ruta, --ldata=ruta

La ruta al directorio de datos de MariaDB.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer opciones predeterminadas después de que se hayan leído los archivos globales de configuración. Debe darse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer opciones predeterminadas, reemplazando los archivos globales de configuración. Debe darse como la primera opción.

•--defaults-group-suffix=nombre

Además de los grupos dados, también lee grupos con este sufijo.

•--force

Causa que mariadb-install-db se ejecute incluso si DNS no funciona. En ese caso, las entradas de la tabla de concesiones que normalmente usan nombres de host usarán direcciones IP.

•--help

Muestra un mensaje de ayuda y sale.

•--no-defaults

No lee opciones predeterminadas de ningún archivo de opciones. Debe darse como el primer argumento.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe darse como el primer argumento.

•--rpm

Para uso interno. Esta opción es utilizada por los archivos RPM durante el proceso de instalación de MariaDB.

•--skip-name-resolve

Usa direcciones IP en lugar de nombres de host al crear entradas de tablas de concesión. Esta opción puede ser útil si tu DNS no funciona.

•--srcdir=ruta

Para uso interno. El directorio bajo el cual mariadb-install-db busca archivos de soporte como el archivo de mensajes de error y el archivo para poblar las tablas de ayuda.4.

•--user=nombre_usuario

El nombre de usuario de inicio de sesión para usar al ejecutar mariadbd. Los archivos y directorios creados por mariadbd serán propiedad de este usuario. Debes ser root para usar esta opción. Por defecto, mariadbd se ejecuta usando tu nombre de inicio de sesión actual y los archivos y directorios que cree serán propiedad tuya.

•--extra-file=ruta_archivo

Añade un archivo SQL definido por el usuario, que se ejecutará después de la inicialización normal de la base de datos.

•--verbose

Modo detallado. Imprime más información sobre lo que hace el programa.

•--windows

Para uso interno. Esta opción se utiliza para crear distribuciones de Windows.

Impulsado por Arch Linux

Bienvenido a Arch Linux

El sistema operativo Linux simple y ligero.

Arch Linux es una distribución Linux independiente, desarrollada activamente y orientada a usuarios expertos que buscan un sistema sencillo, ligero y flexible. Se basa en el principio KISS (Keep It Simple, Stupid - Mantenlo Simple, Maldito) y sigue un modelo de desarrollo rolling release, lo que significa que los paquetes se actualizan constantemente y solo se lanzan nuevas versiones estables de la distribución.

Características principales

  • Simplicidad: Arch Linux evita las configuraciones complejas y las herramientas de automatización excesivas, permitiendo al usuario tener un control total sobre el sistema.
  • Flexibilidad: El usuario es libre de instalar solo los componentes que necesita, construyendo un sistema a medida para sus requisitos específicos.
  • Actualizaciones continuas (Rolling Release): Los paquetes se actualizan constantemente, proporcionando acceso a las últimas versiones de software y características.
  • Gestor de paquetes Pacman: Pacman es un gestor de paquetes rápido y potente que facilita la instalación, actualización y eliminación de software.
  • Arch User Repository (AUR): Una vasta colección de descripciones de paquetes (PKGBUILDs) mantenida por la comunidad, que permite compilar e instalar fácilmente software no incluido en los repositorios oficiales.
  • Documentación exhaustiva: El ArchWiki es una fuente de información incomparable sobre Arch Linux y una referencia valiosa para cualquier usuario de Linux.

Instalación

La instalación de Arch Linux se realiza desde la línea de comandos utilizando un script de instalación interactivo. Esto proporciona una experiencia de aprendizaje profunda y permite personalizar completamente el sistema desde el principio. Se recomienda consultar el Arch Wiki para obtener instrucciones detalladas.

Comunidad

Arch Linux cuenta con una comunidad activa y solidaria. Puedes encontrar ayuda y discutir sobre Arch Linux en los foros, el canal de IRC y la lista de correo electrónico.
