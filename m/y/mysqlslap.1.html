MARIADB-SLAP(1) MariaDB Database System MARIADB-SLAP(1)

NOMBRE

mariadb-slap - cliente de emulación de carga (mariadb-slap es ahora un enlace simbólico a mariadb-slap)

SINOPSIS

mariadb-slap [opciones]

DESCRIPCIÓN

mariadb-slap es un programa de diagnóstico diseñado para emular la carga de clientes para un servidor MariaDB y para informar el tiempo de cada etapa. Funciona como si múltiples clientes estuvieran accediendo al servidor.

Invoque mariadb-slap de esta manera:

shell> mariadb-slap [opciones]

Algunas opciones como --create o --query le permiten especificar una cadena que contiene una declaración SQL o un archivo que contiene declaraciones. Si especifica un archivo, por defecto debe contener una declaración por línea. (Es decir, el delimitador de declaración implícito es el carácter de nueva línea). Use la opción --delimiter para especificar un delimitador diferente, lo que le permite especificar declaraciones que abarcan múltiples líneas o colocar múltiples declaraciones en una sola línea. No puede incluir comentarios en un archivo; mariadb-slap no los entiende.

mariadb-slap se ejecuta en tres etapas:

1. Crea el esquema, la tabla y opcionalmente cualquier programa almacenado o datos que desee utilizar para la prueba. Esta etapa utiliza una única conexión de cliente.
2. Ejecuta la prueba de carga. Esta etapa puede usar muchas conexiones de cliente.
3. Limpia (desconecta, elimina la tabla si se especifica). Esta etapa utiliza una única conexión de cliente.

Ejemplos:

Suministre sus propias declaraciones SQL de creación y consulta, con 50 clientes consultando y 200 selecciones para cada uno:

mariadb-slap --delimiter=";" \
  --create="CREATE TABLE a (b int);INSERT INTO a VALUES (23)" \
  --query="SELECT * FROM a" --concurrency=50 --iterations=200

Deje que mariadb-slap genere la declaración SQL de consulta con una tabla de dos columnas INT y tres columnas VARCHAR. Use cinco clientes consultando 20 veces cada uno. No cree la tabla ni inserte los datos (es decir, use el esquema y los datos de la prueba anterior):

mariadb-slap --concurrency=5 --iterations=20 \
  --number-int-cols=2 --number-char-cols=3 \
  --auto-generate-sql

Indique al programa que cargue las declaraciones SQL de creación, inserción y consulta desde los archivos especificados, donde el archivo create.sql tiene múltiples declaraciones de creación de tablas delimitadas por ';' y múltiples declaraciones de inserción delimitadas por ';'. El archivo --query tendrá múltiples consultas delimitadas por ';'. Ejecute todas las declaraciones de carga, luego ejecute todas las consultas en el archivo de consulta con cinco clientes (cinco veces cada uno):

mariadb-slap --concurrency=5 \
  --iterations=5 --query=query.sql --create=create.sql \
  --delimiter=";"

mariadb-slap admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-slap] y [client]. mariadb-slap también admite las opciones para procesar archivos de opciones.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--auto-generate-sql, -a

Genera declaraciones SQL automáticamente cuando no se suministran en archivos o mediante opciones de línea de comandos.

•--auto-generate-sql-add-autoincrement

Agrega una columna AUTO_INCREMENT a las tablas generadas automáticamente.

•--auto-generate-sql-execute-number=N

Especifica cuántas consultas generar automáticamente.

•--auto-generate-sql-guid-primary

Agrega una clave primaria basada en GUID a las tablas generadas automáticamente.

•--auto-generate-sql-load-type=tipo

Especifica el tipo de carga de prueba. Los valores permitidos son read (escanear tablas), write (insertar en tablas), key (leer claves primarias), update (actualizar claves primarias) o mixed (la mitad inserciones, la mitad selecciones de escaneo). El valor predeterminado es mixed.

•--auto-generate-sql-secondary-indexes=N

Especifica cuántos índices secundarios agregar a las tablas generadas automáticamente. Por defecto, no se agrega ninguno.

•--auto-generate-sql-unique-query-number=N

Cuántas consultas diferentes generar para pruebas automáticas. Por ejemplo, si ejecuta una prueba de clave que realiza 1000 selecciones, puede usar esta opción con un valor de 1000 para ejecutar 1000 consultas únicas, o con un valor de 50 para realizar 50 selecciones diferentes. El valor predeterminado es 10.

•--auto-generate-sql-unique-write-number=N

Cuántas consultas diferentes generar para --auto-generate-sql-write-number. El valor predeterminado es 10.

•--auto-generate-sql-write-number=N

Cuántas inserciones de filas realizar en cada hilo. El valor predeterminado es 100.

•--commit=N

Cuántas declaraciones ejecutar antes de confirmar. El valor predeterminado es 0 (no se realizan confirmaciones).

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos admiten compresión.

•--concurrency=N, -c N

El número de clientes a simular al emitir la declaración SELECT.

•--create=valor

El archivo o cadena que contiene la declaración a usar para crear la tabla.

•--create-schema=valor

El esquema en el que ejecutar las pruebas.

•--csv[=nombre_archivo]

Genera la salida en formato de valores separados por comas. La salida va al archivo nombrado, o a la salida estándar si no se proporciona ningún archivo.

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o,/tmp/mariadb-slap.trace'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info, -T

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre

Plugin del cliente para autenticación predeterminada a usar.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del cual leer las opciones predeterminadas después de que se hayan leído los archivos de opciones globales. Debe darse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del cual leer las opciones predeterminadas, anulando los archivos de opciones globales. Debe darse como la primera opción.

•--delimiter=str, -F str

El delimitador a usar en las declaraciones SQL suministradas en archivos o mediante opciones de línea de comandos.

•--detach=N

Separa (cierra y reabre) cada conexión después de cada N declaraciones. El valor predeterminado es 0 (las conexiones no se separan).

•--engine=nombre_motor, -e nombre_motor

Lista separada por comas de los motores de almacenamiento a usar para crear la tabla. La prueba se ejecuta para cada motor. También puede especificar una opción para un motor después de dos puntos, por ejemplo memory:max_row=2300.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host dado.

•--init-command=str

Comando SQL a ejecutar al conectarse al servidor MariaDB. Se volverá a ejecutar automáticamente al reconectar.

•--iterations=N, -i N

El número de veces que se ejecutarán las pruebas.

•--no-defaults

No lea opciones predeterminadas de ningún archivo de opciones. Esto debe darse como el primer argumento.

•--no-drop

No elimine ningún esquema creado durante la prueba después de la prueba

OPCIONES

•--number-char-cols=N, -x N

El número de columnas VARCHAR a utilizar si se especifica --auto-generate-sql.

•--number-int-cols=N, -y N

El número de columnas INT a utilizar si se especifica --auto-generate-sql.

•--number-of-queries=N

Limita cada cliente a aproximadamente este número de consultas. El recuento de consultas tiene en cuenta el delimitador de sentencias. Por ejemplo, si invoca mariadb-slap de la siguiente manera, se reconoce el delimitador ; de modo que cada instancia de la cadena de consulta cuenta como dos consultas. Como resultado, se insertan 5 filas (no 10).

shell> mariadb-slap --delimiter=";" --number-of-queries=10
         --query="use test;insert into t values(null)"
•--only-print

No se conecta a las bases de datos. mariadb-slap solo imprime lo que habría hecho.

•--password[=contraseña], -p[contraseña]

La contraseña a utilizar al conectarse al servidor. Si utiliza la forma corta de la opción (-p), no puede haber un espacio entre la opción y la contraseña. Si omite el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb-slap le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puede usar un archivo de opciones para evitar proporcionar la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctese al servidor a través de una tubería con nombre (named pipe). Esta opción solo se aplica si el servidor admite conexiones por tubería con nombre.

•--plugin-dir=nombre_dir

Directorio para los plugins del lado del cliente.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a utilizar para la conexión. Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--post-query=valor

El archivo o cadena que contiene la sentencia a ejecutar después de que las pruebas hayan finalizado. Esta ejecución no se cuenta para fines de medición del tiempo.

•--post-system=cadena

La cadena a ejecutar a través de system() después de que las pruebas hayan finalizado. Esta ejecución no se cuenta para fines de medición del tiempo.

•--pre-query=valor

El archivo o cadena que contiene la sentencia a ejecutar antes de ejecutar las pruebas. Esta ejecución no se cuenta para fines de medición del tiempo.

•--pre-system=cadena

La cadena a ejecutar a través de system() antes de ejecutar las pruebas. Esta ejecución no se cuenta para fines de medición del tiempo.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Esto debe darse como primer argumento.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a utilizar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente harían que se utilizara un protocolo diferente al que desea.

•--query=valor, -q valor

El archivo o cadena que contiene la sentencia SELECT a utilizar para recuperar datos.

•--shared-memory-base-name=nombre

En Windows, el nombre de memoria compartida a utilizar, para conexiones realizadas a través de memoria compartida a un servidor local. Esta opción solo se aplica si el servidor admite conexiones por memoria compartida.

•--silent, -s

Modo silencioso. Sin salida.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a utilizar, o, en Windows, el nombre de la tubería con nombre a utilizar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (activado automáticamente con otras opciones). Deshabilita con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consultar documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consultar documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consultar documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a utilizar (consultar documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consultar documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consultar documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consultar documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa. Esta opción se puede usar varias veces para aumentar la cantidad de información.

•--version, -V

Muestra la información de la versión y sale.
