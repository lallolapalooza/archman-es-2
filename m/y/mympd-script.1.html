NOMBRE

mympd-script - Herramienta de línea de comandos de mympd para ejecutar scripts

SINOPSIS

mympd-script <uri> <partición> <nombre_script> [argumentos]

DESCRIPCIÓN

mympd-script es una pequeña herramienta de línea de comandos para ejecutar scripts de myMPD.

OPCIONES

uri
URI de escucha de myMPD, por ejemplo, "https://localhost"
partición
Partición de MPD, por ejemplo, "default"
nombre_script
Script a ejecutar, usa "-" para leer el script desde la entrada estándar.
argumentos
Pares opcionales clave=valor separados por espacios para llenar la tabla de argumentos en el script Lua.
