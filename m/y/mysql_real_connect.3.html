mysql_real_connect(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_real_connect(3) Connector/C de MariaDB mysql_real_connect(3)

Nombre

mysql_real_connect - establece una conexión a un servidor de base de datos MariaDB

Sintaxis

MYSQL * mysql_real_connect(MYSQL *mysql,
                           const char *host,
                           const char *user,
                           const char *passwd,
                           const char *db,
                           unsigned int port,
                           const char *unix_socket,
                           unsigned long flags);

Descripción

Establece una conexión a un servidor de base de datos.

Parámetro

•
mysql - un manejador mysql, que fue previamente asignado por mysql_init(3)
•
host - puede ser un nombre de host o una dirección IP. Si se pasa NULL o la cadena “localhost” a este parámetro, se asume el host local. Siempre que sea posible, se usarán tuberías en lugar del protocolo TCP/IP. Desde la versión 3.3.0 también es posible proporcionar una lista de hosts separada por comas para una conmutación por error simple en caso de que uno o más hosts no estén disponibles.
•
user - el nombre de usuario. Si se especifica NULL o una cadena vacía “”, se utilizará el usuario actual.
•
passwd - Si se proporciona o es NULL, el servidor intentará autenticar al usuario contra aquellos registros de usuario que no tengan contraseña. Esto permite usar un nombre de usuario con diferentes permisos (dependiendo de si se proporciona una contraseña o no).
•
db - si se proporciona, especificará la base de datos predeterminada que se utilizará al realizar consultas.
•
port - especifica el número de puerto al que se intentará conectar al servidor.
•
unix_socket - especifica el socket o named pipe que debe usarse.
•
flags - las banderas permiten configurar varias opciones de conexión
Bandera Descripción
CLIENT_FOUND_ROWS Devuelve el número de filas coincidentes en lugar del número de filas modificadas.
CLIENT_NO_SCHEMA Prohíbe el uso de la sintaxis database.tablename.column y fuerza al analizador SQL a generar un error.
CLIENT_COMPRESS Utiliza el protocolo de compresión
CLIENT_IGNORE_SPACE Permite espacios después de los nombres de función. Todos los nombres de función se convertirán en palabras reservadas.
CLIENT_LOCAL_FILES Permite sentencias LOAD DATA LOCAL
CLIENT_MULTI_STATEMENTS Permite al cliente enviar múltiples sentencias en un solo comando. Las sentencias se dividirán por un punto y coma.
CLIENT_MULTI_RESULTS Indica que el cliente es capaz de manejar múltiples conjuntos de resultados de procedimientos almacenados o sentencias múltiples. Esta opción se establecerá automáticamente si se establece CLIENT_MULTI_STATEMENTS.
CLIENT_REMEMBER_OPTIONS Recuerda las opciones pasadas a mysql_optionsv(3) si un intento de conexión falló. Si la opción MYSQL_OPTIONS_RECONNECT se estableció en true, las opciones se guardarán y se utilizarán para la reconexión.

Valor de retorno

devuelve un manejador de conexión (el mismo que se pasó como 1er parámetro) o NULL en caso de error. En caso de error, consulte las funciones mysql_errno(3) y mysql_error(3) para obtener más información.

Notas

•
La contraseña no necesita ser cifrada antes de ejecutar mysql_real_connect(). Esto se manejará en el protocolo cliente-servidor.
•
El manejador de conexión no se puede reutilizar para establecer una nueva conexión. Debe cerrarse y reinicializarse antes.
•
mysql_real_connect() debe completarse con éxito antes de que pueda ejecutar cualquier otra función de API, excepto mysql_optionsv(3).
•
El parámetro host puede contener múltiples combinaciones de host/puerto (soportado desde la versión 3.3.0). Se requiere la siguiente sintaxis:
•
el nombre de host y el puerto deben estar separados por dos puntos (:)
•
las direcciones IPv6 deben encerrarse entre corchetes
•
los pares nombre de host:puerto deben estar separados por una coma (,)
•
si solo se especificó un host:puerto, la cadena host debe terminar con una coma.
•
si no se especificó puerto, se usará el puerto predeterminado.

Ejemplos de cadena de host para conmutación por error:

host=[::1]:3306,192.168.0.1:3306,test.example.com

host=127.0.0.1:3306,
