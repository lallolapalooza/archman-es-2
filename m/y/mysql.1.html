MARIADB(1) Sistema de Bases de Datos MariaDB MARIADB(1)

NOMBRE

mariadb - la herramienta de línea de comandos de MariaDB (mysql es ahora un enlace simbólico a mariadb)

SINOPSIS

mariadb [opciones] nombre_db

DESCRIPCIÓN

mariadb es un shell SQL simple (con capacidades GNU readline). Admite uso interactivo y no interactivo. Cuando se usa interactivamente, los resultados de las consultas se presentan en formato de tabla ASCII. Cuando se usa de forma no interactiva (por ejemplo, como un filtro), el resultado se presenta en formato separado por tabulaciones. El formato de salida se puede cambiar usando las opciones de comando.

Si tiene problemas debido a memoria insuficiente para conjuntos de resultados grandes, use la opción --quick. Esto obliga a mariadb a recuperar los resultados del servidor fila por fila en lugar de recuperar todo el conjunto de resultados y almacenarlo en memoria antes de mostrarlo. Esto se hace devolviendo el conjunto de resultados utilizando la función de la API C mariadb_use_result() en la biblioteca cliente/servidor en lugar de mysql_store_result().

Usar mariadb es muy fácil. Invocalo desde el prompt de tu intérprete de comandos de la siguiente manera:

shell> mariadb nombre_db

O:

shell> mariadb --user=nombre_usuario --password=tu_contraseña nombre_db

Luego escribe una declaración SQL, termínala con “;”, \g, o \G y presiona Enter.

Escribir Control-C hace que mariadb intente cancelar la declaración actual. Si esto no se puede hacer, o si se escribe Control-C nuevamente antes de que la declaración sea cancelada, mariadb se cerrará.

Puedes ejecutar sentencias SQL en un archivo de script (archivo batch) así:

shell> mariadb nombre_db < script.sql > salida.tab

OPCIONES MARIADB

mariadb admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de opciones [mariadb], [client], [client-server] o [client-mariadb]. mariadb también admite las opciones para procesar archivos de opciones.

•--help, -?, -I

Muestra un mensaje de ayuda y sale.

•--abort-source-on-error

Aborta las operaciones de 'source nombre_archivo' en caso de errores.

•--auto-rehash

Habilita el rehashing automático. Esta opción está activada por defecto, lo que habilita la autocompletación de nombres de base de datos, tablas y columnas. Usa --disable-auto-rehash, --no-auto-rehash o --skip-auto-rehash para deshabilitar el rehashing. Esto hace que mariadb inicie más rápido, pero debes ejecutar el comando rehash si deseas usar la autocompletación de nombres.

Para completar un nombre, ingresa la primera parte y presiona Tab. Si el nombre no es ambiguo, mariadb lo completa. De lo contrario, puedes presionar Tab nuevamente para ver los nombres posibles que comienzan con lo que has escrito hasta ahora. La autocompletación no ocurre si no hay una base de datos predeterminada.

•--auto-vertical-output

Cambia automáticamente al modo de salida vertical si el resultado es más ancho que el ancho de la terminal.

•--batch, -B

Imprime los resultados usando tabulación como separador de columnas, con cada fila en una nueva línea. Con esta opción, mariadb no usa el archivo de historial.

El modo batch resulta en un formato de salida no tabular y escapado de caracteres especiales. El escapado puede ser deshabilitado usando el modo raw; consulta la descripción de la opción --raw.

•--binary-mode

El modo binario permite que ciertas secuencias de caracteres se procesen como datos que de otro modo serían tratados con un significado especial por el analizador. Específicamente, este interruptor desactiva el análisis de todos los comandos del cliente excepto \C y DELIMITER en modo no interactivo (es decir, cuando el modo binario se combina con 1) entrada canalizada, 2) la opción --batch de mariadb, o 3) el comando 'source'). Además, en modo binario, las ocurrencias de '\r\n' y '\0' de ASCII se conservan dentro de las cadenas, mientras que por defecto, '\r\n' se traduce a '\n' y '\0' no está permitido en la entrada del usuario.

•--character-sets-dir=ruta

El directorio donde se instalan los conjuntos de caracteres.

•--column-names

Escribe los nombres de las columnas en los resultados.

•--column-type-info, -m

Muestra metadatos del conjunto de resultados.

•--comments, -c

Si conservar los comentarios en las sentencias enviadas al servidor. El valor predeterminado es --skip-comments (descarta comentarios), habilita con --comments (conserva comentarios).

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos admiten compresión.

•--connect-timeout=segundos

Establece el número de segundos antes de que expire la conexión. (Valor predeterminado: 0).

•--database=nombre_db, -D nombre_db

La base de datos a usar.

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o,/tmp/mysql.trace'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info, -T

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre

Plugin del cliente para autenticación predeterminada.

•--default-character-set=nombre_conjunto_caracteres

Usa nombre_conjunto_caracteres como el conjunto de caracteres predeterminado para el cliente y la conexión.

Un problema común que puede ocurrir cuando el sistema operativo usa utf8 u otro conjunto de caracteres multibyte es que la salida del cliente mariadb está formateada incorrectamente, debido a que el cliente MariaDB usa el conjunto de caracteres latin1 por defecto. Generalmente puedes solucionar estos problemas usando esta opción para forzar al cliente a usar el conjunto de caracteres del sistema en su lugar.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del cual leer opciones predeterminadas después de que se hayan leído los archivos de opciones predeterminadas globales. Debe proporcionarse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del cual leer opciones predeterminadas, anulando los archivos de opciones predeterminadas globales. Debe proporcionarse como la primera opción.

•--defaults-group-suffix=sufijo

Además de los grupos nombrados en la línea de comandos, lee grupos que tengan el sufijo dado.

•--delimiter=cadena

Establece el delimitador de sentencias. El valor predeterminado es el carácter punto y coma (“;”).

•--disable-named-commands

Deshabilita los comandos nombrados. Usa solo la forma \* o usa comandos nombrados solo al principio de una línea que termine con un punto y coma (“;”). mariadb se inicia con esta opción *habilitada* por defecto. Sin embargo, incluso con esta opción, los comandos de formato largo todavía funcionan desde la primera línea. Consulta la sección llamada “COMANDOS DE MARIADB”.

•--enable-cleartext-plugin

Opción obsoleta. Existe solo por compatibilidad con MySQL.

•--execute=sentencia, -e sentencia

Ejecuta la sentencia y sale. Deshabilita --force y el archivo de historial. El formato de salida predeterminado es similar al producido con --batch.

•--force, -f

Continúa incluso si ocurre un error SQL. Establece --abort-source-on-error a 0.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host dado.

•--html, -H

Produce salida HTML.

v>
•--ignore-spaces, -i

Ignora los espacios después de los nombres de funciones. Permite tener espacios (incluidos caracteres de tabulación y saltos de línea) entre el nombre de la función y el '('. La desventaja es que esto hace que las funciones integradas se conviertan en palabras reservadas.

•--init-command=cadena

Comando SQL a ejecutar al conectarse al servidor MariaDB. Se volverá a ejecutar automáticamente al reconectarse.

•--line-numbers

Escribe números de línea para los errores. Deshabilita esto con --skip-line-numbers.

•--local-infile[={0|1}]

Habilita o deshabilita la capacidad LOCAL para LOAD DATA INFILE. Sin valor, la opción habilita LOCAL. La opción se puede dar como --local-infile=0 o --local-infile=1 para deshabilitar o habilitar explícitamente LOCAL. Habilitar LOCAL no tiene ningún efecto si el servidor tampoco lo admite.

•--max-allowed-packet=número

Establece la longitud máxima de paquete para enviar o recibir del servidor. (El valor predeterminado es 16 MB, el máximo es 1 GB).

•--max-join-size=número

Establece el límite automático de filas en un join cuando se usa --safe-updates. (El valor predeterminado es 1,000,000).

•--named-commands, -G

Habilita los comandos mariadb con nombre. Se permiten comandos en formato largo, no solo en formato corto. Por ejemplo, tanto quit como \q son reconocidos. Usa --skip-named-commands para deshabilitar los comandos con nombre. Consulta la sección llamada "COMANDOS DE MARIADB". Deshabilitado por defecto.

••--net-buffer-length=tamaño

Establece el tamaño del búfer para la comunicación TCP/IP y de socket. (El valor predeterminado es 16 KB).

•--no-auto-rehash, -A

Esto tiene el mismo efecto que --skip-auto-rehash. Consulta la descripción de --auto-rehash.

•--no-beep, -b

No emitir pitido cuando ocurran errores.

•--no-defaults

No leer opciones predeterminadas de ningún archivo de opciones. Esto debe proporcionarse como primer argumento.

•--one-database, -o

Ignorar sentencias excepto aquellas que ocurren mientras la base de datos predeterminada es la que se nombra en la línea de comandos. Este filtrado es limitado y se basa solo en sentencias USE. Esto es útil para omitir actualizaciones a otras bases de datos en el log binario.

•--pager[=comando]

Utiliza el comando dado para paginar la salida de la consulta. Si se omite el comando, el paginador predeterminado es el valor de tu variable de entorno PAGER. Los paginadores válidos son less, more, cat [> nombre_archivo], y similares. Esta opción solo funciona en Unix y solo en modo interactivo. Para deshabilitar la paginación, usa --skip-pager. La sección llamada "COMANDOS DE MARIA DB" discute la paginación de salida más a fondo.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usas la forma corta de la opción (-p), no puedes tener un espacio entre la opción y la contraseña. Si omites el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb te pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puedes usar un archivo de opciones para evitar proporcionar la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctate al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor admite conexiones a través de tuberías con nombre.

•--plugin-dir=nombre_directorio

Directorio para los plugins del lado del cliente.

•--port=numero_puerto, -P numero_puerto

El número de puerto TCP/IP a usar para la conexión o 0 para usar el predeterminado, en orden de preferencia: my.cnf, $MYSQL_TCP_PORT, /etc/services, predeterminado integrado (3306). Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Esto debe proporcionarse como primer argumento.

•--progress-reports

Obtener informes de progreso para comandos de larga duración (como ALTER TABLE). (Activado por defecto; usa --skip-progress-reports para deshabilitar).

•--prompt=cadena_formato

Establece el prompt al formato especificado. Las secuencias especiales que el prompt puede contener se describen en la sección llamada "COMANDOS DE MARIA DB".

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente causarían que se use un protocolo diferente al que deseas.

•--quick, -q

No almacenar en caché el resultado de cada consulta, imprime cada fila a medida que se recibe. Esto puede ralentizar el servidor si la salida se suspende. Con esta opción, mariadb no utiliza el archivo de historial.

•--raw, -r

Para la salida tabular, el "enmarcado" alrededor de las columnas permite distinguir un valor de columna de otro. Para la salida no tabular (como la que se produce en modo batch o cuando se da la opción --batch o --silent), los caracteres especiales se escapan en la salida para que puedan identificarse fácilmente. Nueva línea, tabulación, NUL y barra invertida se escriben como \n, \t, \0 y \\. La opción --raw deshabilita este escape de caracteres.

El siguiente ejemplo demuestra la salida tabular frente a la no tabular y el uso del modo raw para deshabilitar el escape:

% mariadb
mariadb> SELECT CHAR(92);
+----------+
| CHAR(92) |
+----------+
| \        |
+----------+
% mariadb -s
mariadb> SELECT CHAR(92);
CHAR(92)
\\
% mariadb -s -r
mariadb> SELECT CHAR(92);
CHAR(92)
\
•--reconnect

Si se pierde la conexión con el servidor, intenta reconectar automáticamente. Se realiza un solo intento de reconexión cada vez que se pierde la conexión. Habilitado por defecto, para deshabilitar usa --skip-reconnect o --disable-reconnect.

•--safe-updates, --i-am-a-dummy, -U

Permite solo las sentencias UPDATE y DELETE que especifican qué filas modificar utilizando valores de clave. Si has establecido esta opción en un archivo de opciones, puedes anularla usando --safe-updates en la línea de comandos. Consulta la sección llamada "CONSEJOS DE MARIA DB" para obtener más información sobre esta opción.

•--secure-auth

No enviar contraseñas al servidor en formato antiguo (anterior a 4.1.1). Esto evita conexiones excepto para servidores que utilizan el formato de contraseña más nuevo.

•--select-limit=límite

Establece el límite automático para SELECT al usar --safe-updates. (El valor predeterminado es 1,000).

•--server-arg=nombre

Envía nombre como parámetro al servidor embebido.

•--show-warnings

Hace que las advertencias se muestren después de cada sentencia si las hay. Esta opción se aplica al modo interactivo y batch.

•--sigint-ignore

Ignora las señales SIGINT (típicamente el resultado de escribir Control-C).

•--silent, -s

Modo silencioso. Produce menos salida. Esta opción se puede dar varias veces para producir cada vez menos salida.

Esta opción resulta en un formato de salida no tabular y el escape de caracteres especiales. El escape puede ser deshabilitado usando el modo raw; consulta la descripción de la opción --raw.

•--skip-auto-rehash

Deshabilita el rehash automático. Sinónimo de --disable-auto-rehash.

•--skip-column-names, -N

No escribir nombres de columnas en los resultados.

•--skip-line-numbers, -L

No escribir números de línea para los errores. Útil cuando deseas comparar archivos de resultados que incluyen mensajes de error.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (habilitado automáticamente con otras banderas). Deshabilita con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a usar (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" (Nombre Común) del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--table, -t

Muestra la salida en formato de tabla. Este es el predeterminado para uso interactivo, pero se puede usar para producir salida en formato de tabla en modo batch.

•--tee=nombre_archivo

Añade una copia de la salida al archivo dado. Esta opción solo funciona en modo interactivo. La sección llamada "COMANDOS DE MARIA DB" discute los archivos tee más a fondo.

OPTIONS

The mariadb client supports the following command-line options.

•--auto-rehash, -F

Rebuild the name cache if it is out of date.

•--auto-vertical-output, -E

Convert output into vertical format if the output is wider than the screen. This is useful for displaying rows that contain many columns.

•--batch, -B

Print the values for each column separated by tabs. Produces tab-separated output. This option is useful for processing the output with other programs, such as awk.

With --batch, mariadb prints column names separated by tabs and rows separated by newlines. Use --skip-column-names (or -N) if you don't want column names.

•--bind-address=ip_address

Use the TCP/IP port with the specified local bind address when connecting to the MariaDB server. This option is useful if the host has more than one IP address.

•--character-sets-dir=dir_name

The directory in which to look for character set files.

•--column-names, -f

Write column names in results. This is the default. Use --skip-column-names to suppress them.

•--column-statistics

Display the number of columns, number of rows, and other statistics for the output. Produces output such as:

shell> mariadb --column-statistics -e "SELECT * FROM t1 LIMIT 1"
+----------+----------+
| col1     | col2     |
+----------+----------+
| 1        | abc      |
+----------+----------+
1 row in set (0.00 sec)

Column statistics:
  col1:  min: 1,  max: 1,  sum: 1,  avg: 1.0000, std: 0.0000
  col2:  min: abc,  max: abc,  sum: NULL,  avg: NULL, std: NULL
•--comments, -i

Write comments in the output (e.g., for --batch output). This option is the default. Use --skip-comments to suppress them.

•--compress, -C

Compresses information sent between the client and server if both support compression. This reduces network traffic at the cost of higher CPU usage on both client and server.

•--connect-timeout=N

The number of seconds to wait for a connect to the server to complete. Value is 0 to wait forever. (Default value is 0.)

•--database=db_name, -D db_name

The database to use.

•--debug[=debug_options], -tv[=debug_options]

Output a debugging-related message. The default debug area is ‘all’. The value if given is a string of the form: 'area,area,...=debug_level,...'.

•--default-auth=plugin_name

Use the specified authentication plugin.

•--delimiter=str

The string that separates SQL statements. The default is ‘;’.

•--enable-cleartext-plugin

Enable the cleartext authentication plugin. This plugin sends passwords in plain text and should be used only if the connection is encrypted. Available from MariaDB 10.1.7 onwards.

•--execute=statement, -e statement

Execute the given statement and then exit.

•--force, -f

Continue even if you get an SQL error. (Deprecated.)

•--histfile=histfile

The file that contains the history of commands entered at the mariadb> prompt. Defaults to $HOME/.mariadb_history.

•--histignore=pattern

Specify a pattern of commands to ignore when saving to the history file. This is a comma-separated list of patterns. For example, `--histignore="* --password=*,* --pwd=*,*"` will prevent commands with passwords from being saved.

•--host=host_name, -h host_name

Connect to the specified host.

•--html, -H

Produce an HTML table as output. Use with the --vertical option for HTML tables that are easier to read.

•--ignore-space, -i

Treat each consecutive input keyword sequence as a single keyword, even if it is followed by spaces. This is the default. Use --skip-ignore-space to disable this.

•--init-command=command

The command to execute in the MariaDB client after connecting to the server. This command is executed before processing any command-line arguments.

•--local-infile[=value]

Whether or not to allow the LOAD DATA LOCAL INFILE command. The value can be 0 or 1 (for false or true), or the strings 'file' or 'files'.

•--log-error[=name]

Log warnings and errors to the specified file. If no name is given, the default is to log to a file named based on the host with suffix '.err'.

•--login-path=name

Read user name and password from the named section in the my.cnf option file's login path section.

•--max-allowed-packet=size

The maximum size of one packet that can be sent to or received from a MariaDB server.

•--max-join-size=count

The maximum number of rows to return for a join. If the number of rows exceeds this value, mariadb prints a warning and discards the result.

•--net-buffer-length=size

The size of the buffer used for TCP/IP and socket communication.

•--no-auto-rehash

Do not rebuild the name cache if it is out of date.

•--no-pager, -n

Disable output paging. See the description for pager.

The --no-pager option works only in Unix.

•--no-warn

Suppress the generation of warning messages.

•--one-database, -o

Only allow one database to be selected at a time. If the client selects a database, it automatically deselects any previously selected database.

•--password[=password], -p[password]

The password to use when connecting to the server. If you specify the short option form (-p), you must provide the password value immediately following the option on the command line. Alternatively, if you specify the short option form and omit the value, mariadb prompts you for the password.

If you specify the long option form (--password), you can either provide the value immediately following the option on the command line, or omit the value to be prompted for it.

Providing a password on the command line can be insecure if your command history is not properly protected.

•--pipe, -P

Use a named pipe to connect to the server. This option applies only on Windows systems that support named pipes.

•--port=port_num, -P port_num

The TCP/IP port number to use when connecting to the server. (Default is 3306.)

•--prompt=prompt

Use the specified string as the prompt.

•--protocol=protocol

Use the specified connection protocol.

•--query-each-infile

The same as --batch. Allows you to run queries on files that contain data, but not necessarily SQL statements. It will buffer the file contents after each query.

•--user=user_name, -u user_name

The MariaDB user name to use when connecting to the server.

•--verbose, -v

Verbose mode. Produce more output about what the program does. This option can be given multiple times to produce more and more output. (For example, -v -v -v produces table output format even in batch mode.)

•--version, -V

Display version information and exit.

•--vertical, -E

Print query output rows vertically (one line per column value). Without this option, you can specify vertical output for individual statements by terminating them with \G.

•--wait, -w

If the connection cannot be established, wait and retry instead of aborting.

•--xml, -X

Produce XML output. The output when --xml is used with mariadb matches that of mariadb-dump --xml. See mariadb-dump(1) for details.

You can also set the following variables by using --var_name=value.

•connect_timeout

The number of seconds before connection timeout. (Default value is 0.)

•max_allowed_packet

The maximum packet length to send to or receive from the server. (Default value is 16MB.)

•max_join_size

The automatic limit for rows in a join when using --safe-updates. (Default value is 1,000,000.)

•net_buffer_length

The buffer size for TCP/IP and socket communication. (Default value is 16KB.)

•select_limit

The automatic limit for SELECT statements when using --safe-updates. (Default value is 1,000.)

On Unix, the mariadb client writes a record of executed statements to a history file. By default, this file is named .mariadb_history and is created in your home directory. For backwards compatibility .mariadb_history will be used if present and .mariadb_history is missing. To specify a different file, set the value of the MARIADB_HISTFILE environment variable. The environment variable MYSQL_HISTFILE will be used if MARIADB_HISTFILE isn't present.

The .mariadb_history should be protected with a restrictive access mode because sensitive information might be written to it, such as the text of SQL statements that contain passwords.

If you do not want to maintain a history file, first remove .mariadb_history if it exists, and then use either of the following techniques:

•Set the MARIADB_HISTFILE variable to /dev/null. To cause this setting to take effect each time you log in, put the setting in one of your shell's startup files.
•Create .mariadb_history as a symbolic link to /dev/null: 
shell> ln -s /dev/null $HOME/.mariadb_history

You need do this only once.

The delimiter can be specified as an unquoted or quoted argument. Quoting can be done with either single quote (') or double quote (") characters. To include a quote within a quoted string, either quote the string with the other quote character or escape the quote with a backslash (“\”) character. Backslash should be avoided outside of quoted strings because it is the escape character for MariaDB. For an unquoted argument, the delimiter is read up to the first space or end of line. For a quoted argument, the delimiter is read up to the matching quote on the line.

When the delimiter recognized by mariadb is set to something other than the default of “;”, instances of that character are sent to the server without interpretation. However, the server itself still interprets “;” as a statement delimiter and processes statements accordingly. This behavior on the server side comes into play for multiple-statement execution, and for parsing the body of stored procedures and functions, triggers, and events.

Aquí hay algunos consejos sobre el comando pager:

•Puedes usarlo para escribir en un archivo y los resultados solo van al archivo: 
mariadb> pager cat > /tmp/log.txt

También puede pasar cualquier opción para el programa que desee utilizar como paginador:

mariadb> pager less -n -i -S
•En el ejemplo anterior, observe la opción -S. Puede encontrarla muy útil para navegar por resultados de consultas amplios. A veces, un conjunto de resultados muy amplio es difícil de leer en la pantalla. La opción -S para less puede hacer que el conjunto de resultados sea mucho más legible porque puede desplazarse horizontalmente usando las teclas de flecha izquierda y derecha. También puede usar -S interactivamente dentro de less para activar y desactivar el modo de navegación horizontal. Para obtener más información, lea la página del manual de less: 
shell> man less
•Las opciones -F y -X se pueden usar con less para hacer que salga si la salida cabe en una pantalla, lo que es conveniente cuando no se necesita desplazamiento: 
mariadb> pager less -n -i -S -F -X
•Puede especificar comandos de paginación muy complejos para manejar la salida de consultas: 
mariadb> pager cat | tee /dr1/tmp/res.txt \
          | tee /dr2/tmp/res2.txt | less -n -i -S

En este ejemplo, el comando enviaría los resultados de la consulta a dos archivos en dos directorios diferentes en dos sistemas de archivos diferentes montados en /dr1 y /dr2, y aún así mostraría los resultados en pantalla a través de less.

También puede combinar las funciones tee y pager. Tenga un archivo tee habilitado y pager establecido en less, y podrá navegar por los resultados usando el programa less y aún así tener todo anexado a un archivo al mismo tiempo. La diferencia entre el tee de Unix utilizado con el comando pager y el comando tee incorporado de mariadb es que el tee incorporado funciona incluso si no tiene el tee de Unix disponible. El tee incorporado registra todo lo que se imprime en la pantalla, mientras que el tee de Unix utilizado con pager no registra tanto. Además, el registro del archivo tee se puede activar y desactivar interactivamente desde dentro de mariadb. Esto es útil cuando desea registrar algunas consultas en un archivo, pero no otras.

NAME

mariadb - MariaDB command-line client

SYNOPSIS

mariadb [options] [database]

DESCRIPTION

The mariadb client is a console program for accessing the MariaDB database server. It supports interactive command execution and can also be used to execute SQL statements read from a file.

This document describes the client's basic usage, options, and command-line help system. For details about SQL syntax and MariaDB administration, see the MariaDB documentation at https://mariadb.com/kb/.

The mariadb client supports the following commands:

  • \c - Clear the current input buffer and start over.
  • \G - Change the output format to vertical.
  • \h - Display this help.
  • \s - Display status information about the connection.
  • \? - Display help for MariaDB commands.
  • source filename - Execute commands from a file.

To see a list of all available commands, type help at the mariadb> prompt.

MARIADB OPTIONS

The mariadb client supports many command-line options. Some common ones are:

  • -A, --no-auto-rehash
    Do not automatically complete or expand table and column names.
  • -b, --binary-mode
    Force binary mode (disables character set conversions).
  • -C, --compress
    Compress client/server protocol messages.
  • -c, --skip-column-names
    Do not write column names in query results.
  • -e, --execute=query
    Execute the given query and exit.
  • -f, --force
    Continue even if SQL errors occur.
  • -H, --html
    Produce HTML output.
  • -i, --info
    Print server version and status information for each connection.
  • --max-allowed-packet=length
    Maximum size of a packet that can be sent to the server.
  • --max-join-size=length
    Maximum number of rows allowed for joins.
  • -o, --skip-optimizer-trace
    Turn off optimizer trace output.
  • -p, --password[=password]
    Password to use when connecting to the server.
  • -P, --port=port_num
    TCP/IP port number to use for connection.
  • -q, --quiet
    Suppress the normal output.
  • --safe-updates, -i-am-a-dummy
    Enable safe mode for updates and deletes.
  • -r, --raw
    Produce less/no tabular output.
  • -S, --socket=name

  • --server-arg=name

  • -t, --table

EXECUTING SQL STATEMENTS FROM A TEXT FILE

The mariadb client typically is used interactively, like this:

shell> mariadb db_name

However, it is also possible to put your SQL statements in a file and then tell mariadb to read its input from that file. To do so, create a text file text_file that contains the statements you wish to execute. Then invoke mariadb as shown here:

shell> mariadb db_name < text_file

If you place a USE db_name statement as the first statement in the file, it is unnecessary to specify the database name on the command line:

shell> mariadb < text_file

If you are already running mariadb, you can execute an SQL script file using the source command or \. command:

mariadb> source file_name
mariadb> \. file_name

Sometimes you may want your script to display progress information to the user. For this you can insert statements like this:

SELECT '<info_to_display>' AS ' ';

The statement shown outputs <info_to_display>.

You can also invoke mariadb with the --verbose option, which causes each statement to be displayed before the result that it produces.

mariadb ignores Unicode byte order mark (BOM) characters at the beginning of input files. Presence of a BOM does not cause mariadb to change its default character set. To do that, invoke mariadb with an option such as --default-character-set=utf8.

Using the --safe-updates Option

For beginners, a useful startup option is --safe-updates (or --i-am-a-dummy, which has the same effect). It is helpful for cases when you might have issued a DELETE FROM tbl_name statement but forgotten the WHERE clause. Normally, such a statement deletes all rows from the table. With --safe-updates, you can delete rows only by specifying the key values that identify them. This helps prevent accidents.

When you use the --safe-updates option, mariadb issues the following statement when it connects to the MariaDB server:

SET sql_safe_updates=1, sql_select_limit=1000, sql_max_join_size=1000000;

The SET statement has the following effects:

•You are not allowed to execute an UPDATE or DELETE statement unless you specify a key constraint in the WHERE clause or provide a LIMIT clause (or both). For example: 
UPDATE tbl_name SET not_key_column=val WHERE key_column=val;
UPDATE tbl_name SET not_key_column=val LIMIT 1;
•The server limits all large SELECT results to 1,000 rows unless the statement includes a LIMIT clause.
•The server aborts multiple-table SELECT statements that probably need to examine more than 1,000,000 row combinations.

To specify limits different from 1,000 and 1,000,000, you can override the defaults by using the --select-limit and --max-join-size options:

shell> mariadb --safe-updates --select-limit=500 --max-join-size=10000

Disabling mariadb Auto-Reconnect

If the mariadb client loses its connection to the server while sending a statement, it immediately and automatically tries to reconnect once to the server and send the statement again. However, even if mariadb succeeds in reconnecting, your first connection has ended and all your previous session objects and settings are lost: temporary tables, the autocommit mode, and user-defined and session variables. Also, any current transaction rolls back. This behavior may be dangerous for you, as in the following example where the server was shut down and restarted between the first and second statements without you knowing it:

mariadb> SET @a=1;
Query OK, 0 rows affected (0.05 sec)
mariadb> INSERT INTO t VALUES(@a);
ERROR 2006: MariaDB server has gone away
No connection. Trying to reconnect...
Connection id:    1
Current database: test
Query OK, 1 row affected (1.30 sec)
mariadb> SELECT * FROM t;
+------+
| a    |
+------+
| NULL |
+------+
1 row in set (0.05 sec)

The @a user variable has been lost with the connection, and after the reconnection it is undefined. If it is important to have mariadb terminate with an error if the connection has been lost, you can start the mariadb client with the --skip-reconnect option.
