mysql_server_end(3) Conector/C de MariaDB mysql_server_end(3)

Nombre

mysql_server_end - Llamada al finalizar el uso del Conector/C de MariaDB

Sintaxis

#include <mysql.h>
void mysql_server_end(void)

Descripción

Llamar al finalizar el uso de la biblioteca, como por ejemplo después de desconectarse del servidor. Para un programa cliente, solo realiza limpieza llevando a cabo tareas de gestión de memoria.

Notas

•
mysql_library_end() es un alias de mysql_server_end().
•
En las versiones 3.0.1 a 3.0.4 del Conector/C de MySQL no era posible llamar a mysql_server_init(3) y mysql_server_end() múltiples veces.
