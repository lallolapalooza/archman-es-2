mysql_optionsv(3) MariaDB Connector/C mysql_optionsv(3)

Nombre

mysql_optionsv - Se utiliza para establecer opciones de conexión adicionales y afectar el comportamiento de una conexión

Sinopsis

#include <mysql.h>
int mysql_optionsv(MYSQL * mysql,
                   enum mysql_option,
                   const void * arg,
                   ...);

Descripción

Se utiliza para establecer opciones de conexión adicionales y afectar el comportamiento de una conexión. Esta función puede ser llamada múltiples veces para establecer varias opciones. mysql_optionsv() debe ser llamada después de mysql_init(3).

Opciones

La siguiente tabla muestra qué tipo de variable usar para cada opción.

•
MYSQL_OPT_SSL_ENFORCE

Habilitar o deshabilitar TLS. Esta opción puede ser utilizada para habilitar TLS sin tener que proporcionar certificados, claves o CAs de TLS.

Nota: actualmente esto no fuerza TLS como sugeriría el nombre de la opción. Si el servidor no soporta TLS, el protocolo volverá a la comunicación sin cifrar. Para forzar el uso de TLS, usa MYSQL_OPT_SSL_VERIFY_SERVER_CERT en su lugar.

•
MYSQL_INIT_COMMAND

Comando(s) que se ejecutarán al conectar y reconectar al servidor.

•
MYSQL_OPT_COMPRESS

Utiliza el protocolo comprimido para la comunicación cliente-servidor. Si el servidor no soporta el protocolo comprimido, se utilizará el protocolo por defecto.

•
MYSQL_OPT_CONNECT_TIMEOUT

Tiempo de espera de conexión en segundos. Este valor se pasará como un parámetro unsigned ##int##.

•
MYSQL_OPT_LOCAL_INFILE

Habilita o deshabilita el uso de LOAD DATA LOCAL INFILE

•
MYSQL_OPT_NAMED_PIPE

Solo para sistemas operativos Windows: Utiliza tuberías con nombre para la comunicación cliente/servidor.

•
MYSQL_PROGRESS_CALLBACK

Especifica una función de devolución de llamada que podrá visualizar el progreso de ciertas sentencias de larga ejecución (es decir, LOAD DATA LOCAL INFILE o ALTER TABLE). La función de devolución de llamada debe definirse de la siguiente manera:

static void report_progress(const MYSQL *mysql __attribute__((unused)),
                            uint stage, uint max_stage,
                            double progress __attribute__((unused)),
                            const char *proc_info __attribute__((unused)),
                            uint proc_info_length __attribute__((unused)))
•
MYSQL_OPT_PROTOCOL

Especifica el tipo de protocolo cliente/servidor. Los valores posibles son: MYSQL_PROTOCOL_TCP, MYSQL_PROTOCOL_SOCKET, MYSQL_PROTOCOL_PIPE y MYSQL_PROTOCOL_MEMORY.

•
MYSQL_OPT_RECONNECT

Habilita o deshabilita la reconexión automática.

•
MYSQL_OPT_READ_TIMEOUT

Especifica el tiempo de espera en segundos para leer paquetes del servidor.

•
MYSQL_OPT_WRITE_TIMEOUT

Especifica el tiempo de espera en segundos para enviar paquetes al servidor.

•
MYSQL_READ_DEFAULT_FILE

Lee opciones del archivo de configuración especificado. Si se pasa una cadena vacía, se leerán los archivos de configuración por defecto (como /etc/my.cnf, /etc/mysql/my.cnf). Por defecto, los archivos de configuración no se procesan a menos que se especifique esta opción.

•
MYSQL_READ_DEFAULT_GROUP Lee opciones del grupo especificado dentro del archivo de configuración por defecto o del archivo especificado por MYSQL_READ_DEFAULT_FILE. Pasar una cadena vacía resultará en el procesamiento de todas las secciones. Si no se proporciona ningún archivo específico a través de MYSQL_READ_DEFAULT_FILE, se considerarán todos los archivos de configuración por defecto disponibles.

Nota: Además de un grupo especificado, los siguientes grupos siempre se procesarán:

•
[client]
•
[client-server]
•
[client-mariadb]
•
MYSQL_REPORT_DATA_TRUNCATION

Habilita o deshabilita la notificación de errores de truncamiento de datos para sentencias preparadas.

•
MYSQL_OPT_BIND

Especifica la interfaz de red desde la cual conectarse a MariaDB Server.

•
MYSQL_PLUGIN_DIR

Especifica la ubicación de los plugins del cliente.

•
MYSQL_OPT_NONBLOCK

Especifica el tamaño de la pila para operaciones no bloqueantes. El argumento para MYSQL_OPT_NONBLOCK es el tamaño de la pila utilizada para guardar el estado de una operación no bloqueante mientras espera E/S y la aplicación realiza otro procesamiento. Normalmente, las aplicaciones no necesitarán cambiar esto, y se puede pasar como cero para usar el valor por defecto.

•
MYSQL_OPT_NET_BUFFER_LENGTH

Tamaño inicial del búfer de red en bytes. El de

el valor por defecto es 16777216 (16MiB).

•
MYSQL_OPT_MAX_ALLOWED_PACKET

Longitud máxima de paquete permitida. El valor por defecto es 1073741824 (1GiB) en el lado del cliente. Si el límite es excedido por un paquete enviado por el servidor, se genera un error.

•
MARIADB_OPT_CONNECTION_HANDLER

Especifica el nombre de un plugin de manejo de conexión.

•
MARIADB_OPT_USERDATA

Agrupa datos de usuario a la conexión actual, por ejemplo, para su uso en plugins de manejo de conexión. Esta opción requiere 4 parámetros: conexión, opción, clave y valor:

mysql_optionsv(mysql, MARIADB_OPT_USERDATA, (void *)"my_key", (void *)value);
•
MARIADB_OPT_CONNECTION_READ_ONLY

Esta opción es utilizada por los plugins de manejo de conexión e indica que la conexión actual se utilizará solo para operaciones de lectura.

•
MYSQL_OPT_CAN_HANDLE_EXPIRED_PASSWORDS

Si esta opción está configurada, el cliente indica que podrá manejar contraseñas expiradas estableciendo el CLIENT_CAN_HANDLE_EXPIRED_PASSWORDS flag de capacidad. Si la contraseña ha expirado y CLIENT_CAN_HANDLE_EXPIRED_PASSWORDS está configurado, el servidor no devolverá un error al conectar, sino que pondrá la conexión en modo sandbox, donde todos los comandos devolverán el error 1820 (ER_MUST_CHANGE_PASSWORD) a menos que se establezca una nueva contraseña. Esta opción se añadió en MariaDB Connector/C 3.0.4

•
MARIADB_OPT_STATUS_CALLBACK

Especifica una función de callback que será llamada cada vez que el estado del servidor cambie o el servidor envíe información de seguimiento de sesión al cliente:

mysql_optionsv(mysql, MARIADB_OPT_STATUS_CALLBACK, function, data)

La función de callback debe definirse de la siguiente manera:

    void status_callback(void *data, enum enum_mariadb_status_info type, ..)

Parámetros:

    - data  Puntero pasado con el registro de la función de callback
            (generalmente un manejador de conexión)
    - type  Tipo de información  STATUS_TYPE o SESSION_TRACK_TYPE

Parámetros Variádicos:

 if (type == STATUS_TYPE):
    - estado del servidor (unsigned int)
 if (type == SESSION_TRACK_TYPE)
    - enum enum_session_state_type track_type - tipo de seguimiento de sesión
    if (track_type == SESSION_TRACK_SYSTEM_VARIABLES)
      - MARIADB_CONST_STRING *key
      - MARIADB_CONST_STRING *value
    else
      - MARIADB_CONST_STRING *value

` Nota: Especificar una función de callback sobrescribe la función interna de seguimiento de sesión, por lo que las funciones de la API mysql_session_track_get_first()/next() no se pueden utilizar.

Un ejemplo se puede encontrar en unittest/libmariadb/connection.c (test_status_callback)

Añadido en la versión 3.3.2

•
MARIADB_OPT_SKIP_READ_RESPONSE

No leer paquetes de respuesta en el protocolo binario.

Añadido en la versión 3.1.13

Opciones de API de Replicación/Binlog

•
MARIADB_OPT_RPL_REGISTER_REPLICA

Especifica el nombre de host y el puerto para Binlog/API. Cuando esta opción se configuró, rpl_open() registrará la réplica con server_id, host y puerto al servidor conectado. Esta información se puede recuperar mediante el comando SHOW SLAVE STATUS. Esta opción se añadió en la versión 3.3.1

Opciones de TLS/SSL y Seguridad

•
MYSQL_OPT_SSL_KEY

Especifica el nombre de una clave para una conexión segura. Si la clave está protegida con una contraseña, la contraseña debe especificarse con la opción MARIADB_OPT_PASSPHRASE.

•
MYSQL_OPT_SSL_CERT

Especifica el nombre de un certificado para una conexión segura.

•
MYSQL_OPT_SSL_CA

Especifica el nombre de un archivo que contiene una o más CA de confianza.

•
MYSQL_OPT_SSL_CAPATH

Especifica la ruta que contiene CA de confianza.

•
MYSQL_OPT_SSL_CIPHER

Especifica una o más suites de cifrado (SSLv3, TLSv1.0 o TLSv1.2) para cifrado TLS. Aunque Connector/C admite el protocolo TLSv1.3, aún no es posible especificar suites de cifrado TLSv1.3.

•
MYSQL_OPT_SSL_CRL

Especifica un archivo con una lista de revocación de certificados.

•
MYSQL_OPT_SSL_CRLPATH

Especifica un directorio que contiene archivos con listas de revocación de certificados.

•
MARIADB_OPT_SSL_FP

Especifica el hash de huella digital de un certificado de servidor para validación durante el handshake TLS. Para versiones anteriores a 3.4.0, el hash es un hash SHA1, para versiones 3.4.0 y posteriores SHA256, SHA384 o SHA512.

•
MARIADB_OPT_SSL_FP_LIST

Especifica un archivo que contiene uno o más hashes de huella digital de certificados de servidor para validación durante el handshake TLS. Para versiones anteriores a 3.4.0, el hash es un hash SHA1, para versiones 3.4.0 y posteriores SHA256, SHA384 o SHA512.

•
MARIADB_OPT_SSL_PASSPHRASE

Especifica una contraseña para una clave de cliente protegida por contraseña.

•
MYSQL_OPT_SSL_VERIFY_SERVER_CERT

Habilita (o deshabilita) la verificación del nombre de host contra el nombre común (CN) del certificado del host del servidor.

•
MYSQL_SERVER_PUBLIC_KEY

Especifica el nombre del archivo que contiene la clave pública RSA del servidor de la base de datos. El formato de este archivo debe ser PEM. Esta opción es utilizada por el plugin caching_sha2_password y se añadió en Connector/C 3.1.0

•
MARIADB_OPT_TLS_CIPHER_STRENGTH

Esta opción ya no está en uso.

•
MARIADB_OPT_RESTRICTED_AUTH

Especifica uno o más plugins de autenticación separados por comas que están permitidos para la autenticación. Si el servidor de base de datos solicita un plugin de autenticación no listado en esta opción, MariaDB Connector/C devolverá un error. Esta opción se añadió en MariaDB Connector/C 3.3.0

Configuración del Proxy

Según la especificación del protocolo proxy, el cliente que se conecta puede anteponer su primer paquete con una cabecera de protocolo proxy. El servidor analizará la cabecera y asumirá que la dirección IP del cliente es la establecida en la cabecera proxy. * MARIADB_OPT_PROXY_HEADER - especifica la cabecera proxy que se antepondrá al primer paquete. Los parámetros son void * para el búfer de prefijo y size_t para la longitud del búfer:

const char *hdr="PROXY TCP4 192.168.0.1 192.168.0.11 56324 443\r\n";
mysql_optionsv(mysql, MARIADB_OPT_PROXY_HEADER, hdr,  strlen(hdr));

Atributos de Conexión

Los atributos de conexión se almacenan en las tablas session_connect_attrs y session_account_connect_attrs del Performance Schema. Por defecto, MariaDB Connector/C envía los siguientes atributos de conexión al servidor: * _client_name: siempre “libmariadb” * _client_version: versión de MariaDB Connector/C * _os: sistema operativo * _pid: ID del proceso * _platform: por ejemplo, x86 o x64 * _server_host: el nombre del host (como se especifica en mysql_real_connect). Este atributo se añadió en Connector/C 3.0.5

Nota: Si el Performance Schema está deshabilitado, los atributos de conexión no se almacenarán en el servidor.

•
MYSQL_OPT_CONNECT_ATTR_DELETE

Elimina un atributo de conexión para la clave dada.

•
MYSQL_OPT_CONNECT_ATTR_ADD

Añade un par clave/valor a los atributos de conexión. La longitud total de los atributos de conexión almacenados está limitada a un máximo de 65535 bytes.

•
MYSQL_OPT_CONNECT_ATTR_RESET

Borra la lista actual de atributos de conexión.
