mysql_stmt_attr_set(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_stmt_attr_set(3) MariaDB Connector/C mysql_stmt_attr_set(3)

Nombre

mysql_stmt_attr_set - Establece el atributo de una sentencia

Sinopsis

#include <mysql.h>
my_bool mysql_stmt_attr_set(MYSQL_STMT * stmt,
                            enum enum_stmt_attr_type,
                            const void * attr);

Descripción

Se utiliza para modificar el comportamiento de una sentencia preparada. Esta función puede llamarse múltiples veces para establecer varios atributos. Devuelve cero si tiene éxito, distinto de cero si falla.

Parámetros

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
enum_stmt_attr_type - el atributo que desea establecer. Véase más abajo.
•
attr - el valor a asignar al atributo

Tipos de atributos

El atributo enum_stmt_attr_type puede tener uno de los siguientes valores:

Valor Tipo Descripción
STMT_ATTR_UPDATE_MAX_LENGTH my_bool * Si se establece a 1, mysql_stmt_store_result(3) actualizará el valor max_length de las estructuras MYSQL_FIELD.
STMT_ATTR_CURSOR_TYPE unsigned long * tipo de cursor cuando se invoca mysql_stmt_execute(3). Los valores posibles son CURSOR_TYPE_READ_ONLY o el valor por defecto CURSOR_TYPE_NO_CURSOR.
STMT_ATTR_PREFETCH_ROWS unsigned long * número de filas que se preseleccionarán. El valor por defecto es 1.
STMT_ATTR_PREBIND_PARAMS unsigned int * número de marcadores de parámetros al usar mariadb_stmt_execute_direct(3). Si el manejador de sentencia se reutiliza se restablecerá automáticamente al estado posterior a mysql_stmt_init(). Esta opción se añadió en Connector/C 3.0
STMT_ATTR_ARRAY_SIZE unsigned int * número de elementos de array. Esta opción se añadió en Connector/C 3.0 y requiere MariaDB 10.2 o posterior.
STMT_ATTR_ROW_SIZE size_t * especifica el tamaño de una estructura para la vinculación fila por fila. Esta longitud debe incluir espacio para todos los parámetros vinculados y cualquier relleno de la estructura o buffer para asegurar que cuando la dirección de un parámetro vinculado se incrementa con la longitud especificada, el resultado apuntará al principio del mismo parámetro en el siguiente conjunto de parámetros. Al usar el operador sizeof en C ANSI, este comportamiento está garantizado. Si el valor es cero se utilizará la vinculación columna por columna (por defecto). Esta opción se añadió en Connector/C 3.0 y requiere MariaDB 10.2 o posterior.

Notas

•
Si utiliza la opción MYSQL_STMT_ATTR_CURSOR_TYPE con MYSQL_CURSOR_TYPE_READ_ONLY, se abre un cursor para la sentencia cuando se invoca mysql_stmt_execute(3). Si ya existe un cursor abierto de una llamada anterior a mysql_stmt_execute(3), se cierra el cursor antes de abrir uno nuevo. mysql_stmt_reset(3) también cierra cualquier cursor abierto antes de preparar la sentencia para su reejecución.
•
Si abre un cursor para una sentencia preparada, no es necesario llamar a mysql_stmt_store_result(3).
•
mysql_stmt_free_result(3) cierra cualquier cursor abierto.
