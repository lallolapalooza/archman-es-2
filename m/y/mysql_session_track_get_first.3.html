mysql_session_track_get_first(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_session_track_get_first(3) MariaDB Connector/C mysql_session_track_get_first(3)

Nombre

mysql_session_track_get_first - recupera la información del primer cambio de estado de sesión

Sinopsis

#include <mysql.h>
int mysql_session_track_get_first(MYSQL * mysql,
                                  enum enum_session_state_type type,
                                  const char **data,
                                  size_t *length );

Descripción

mysql_session_track_get_first() recupera la primera información de cambio de estado de sesión recibida del servidor.

Dependiendo del tipo especificado, el puntero de datos de solo lectura contendrá la siguiente información: * SESSION_TRACK_SCHEMA: el nombre del esquema (base de datos) predeterminado * SESSION_TRACK_SYSTEM_VARIABLES: si se cambia una variable del sistema de sesión, la primera llamada contiene el nombre de la variable del sistema cambiada, la segunda llamada contiene el nuevo valor. Tanto el nombre como el valor se representan como cadenas. * SESSION_TRACK_STATE_CHANGE: muestra si el estado de la sesión ha cambiado. El valor se cambia como la cadena “1” (cambiado) o “0” (sin cambios).

Se pueden obtener datos adicionales llamando a mysql_session_track_get_next(3).

Parámetro

•
mysql - manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
type - tipo de información. Los valores válidos son
•
SESSION_TRACK_SYSTEM_VARIABLES
•
SESSION_TRACK_SCHEMA
•
SESSION_TRACK_STATE_CHANGE
•
SESSION_TRACK_GTIDS (no soportado)
•
data - puntero a los datos, que debe declararse como const char *
•
length - puntero a una variable size_t, que contendrá la longitud de los datos

Devuelve

Cero en caso de éxito, distinto de cero si no hay información de seguimiento de sesión disponible.

Historial

mysql_session_track_get_first() se añadió en Connector/C 3.0 y MariaDB Server 10.2.
