MYSQLROUTER_PLUGIN_INFO(1) MySQL Router MYSQLROUTER_PLUGIN_INFO(1)

NOMBRE

mysqlrouter_plugin_info - Información de Plugins de MySQL Router

SINOPSIS

mysqlrouter_plugin_info [opciones]

DESCRIPCIÓN

La utilidad mysqlrouter_plugin_info es una herramienta de depuración que inspecciona un plugin de MySQL Router en busca de posibles conflictos y problemas generales.

Información de uso:

$> ./mysqlrouter_plugin_info --help
Uso:
  ./mysqlrouter_plugin_info <archivo_plugin_mysqlrouter> <nombre_plugin_mysql>
Ejemplo:
  ./mysqlrouter_plugin_info /usr/lib/mysqlrouter/routing.so routing
Para imprimir información de ayuda:
  ./mysqlrouter_plugin_info --help
Para imprimir la versión de la aplicación:
  ./mysqlrouter_plugin_info --version
$> ./bin/mysqlrouter_plugin_info --version
MySQLRouter Plugin Info App 8.4.3

Ejemplo de uso:

$> ./bin/mysqlrouter_plugin_info lib/mysqlrouter/routing.so routing
{
    "abi-version": "2.0",
    "arch-descriptor": "i386/darwin//",
    "brief": "Enrutamiento de conexiones MySQL entre clientes/conectores MySQL y servidores",
    "plugin-version": "0.0.1",
    "requires": [],
    "conflicts": []
}
