Nombre

mysql_set_character_set - Establece el conjunto de caracteres por defecto para la conexión

Sinopsis

#include <mysql.h>
int mysql_set_character_set(MYSQL * mysql,
                            const char * csname);

Descripción

Establece el conjunto de caracteres por defecto para la conexión actual. Devuelve cero si tiene éxito, un valor distinto de cero si falla.

Parámetros

•
mysql - un manejador mysql, que fue previamente asignado por mysql_init(3) o mysql_real_connect(3).
•
csname - nombre del conjunto de caracteres ### Notas
•
Se recomienda encarecidamente usar mysql_set_character_set() en lugar de SET NAMES ... ya que mysql_real_escape_string(3) podría fallar o dar resultados inesperados.

Valor de retorno

Cero si tiene éxito, distinto de cero si ocurrió un error
