Nombre

mysql_use_result - devuelve un conjunto de resultados no almacenado en búfer

Sinopsis

#include <mysql.h>
MYSQL_RES * mysql_use_result(MYSQL * mysql);

Descripción

Se utiliza para iniciar la recuperación de un conjunto de resultados de la última consulta ejecutada utilizando la función mysql_real_query() en la conexión a la base de datos. Se debe llamar a esta función o a la función mysql_store_result(3) antes de que se puedan recuperar los resultados de una consulta, y se debe llamar a una de ellas para evitar que la siguiente consulta en esa conexión a la base de datos falle.

Parámetros

•
mysql es un identificador de conexión, que fue asignado previamente por mysql_init(3) y conectado por mysql_real_connect(3).

Notas

La función mysql_use_result() no transfiere el conjunto de resultados completo. Por lo tanto, no se pueden usar varias funciones como mysql_num_rows(3) o mysql_data_seek(3). mysql_use_result() bloqueará la conexión actual hasta que se recuperen todos los conjuntos de resultados o el conjunto de resultados sea liberado por mysql_free_result(3).

Valor de retorno

Devuelve un conjunto de resultados no almacenado en búfer o NULL si ocurrió un error.
