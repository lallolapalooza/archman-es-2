MARIADB-DUMPSLOW(1) Sistema de Bases de Datos MariaDB MARIADB-DUMPSLOW(1)

NOMBRE

mariadb-dumpslow - Resumir archivos de log de consultas lentas (mariadb-dumpslow es ahora un enlace simbólico a mariadb-dumpslow)

SINOPSIS

mariadb-dumpslow [opciones] [archivo_log ...]

DESCRIPCIÓN

El log de consultas lentas de MariaDB contiene información sobre consultas que tardan mucho tiempo en ejecutarse. mariadb-dumpslow analiza los archivos de log de consultas lentas de MariaDB e imprime un resumen de su contenido.

Normalmente, mariadb-dumpslow agrupa consultas que son similares excepto por los valores particulares de datos numéricos y de cadena. “Abstrae” estos valores a N y 'S' al mostrar la salida del resumen. Las opciones -a y -n se pueden usar para modificar el comportamiento de abstracción de valores.

Invoque mariadb-dumpslow de la siguiente manera:

shell> mariadb-dumpslow [opciones] [archivo_log ...]

mariadb-dumpslow admite las siguientes opciones.

•--help

Muestra un mensaje de ayuda y sale.

•-a

No abstraer todos los números a N y las cadenas a 'S'.

•--debug, -d

Ejecutar en modo de depuración.

•-g patrón

Considerar solo consultas que coincidan con el patrón (estilo grep).

•-h nombre_host

Nombre de host del servidor MariaDB para el nombre de archivo *-slow.log. El valor puede contener un comodín. El valor predeterminado es * (coincide con todos).

•-i nombre

Nombre de la instancia del servidor (si se usa el script de inicio mariadb.server).

•-l

No restar el tiempo de bloqueo del tiempo total.

•-n N

Abstraer números con al menos N dígitos dentro de los nombres.

•-r

Invertir el orden de clasificación.

•-s tipo_ordenación

Cómo ordenar la salida. El valor de tipo_ordenación debe elegirse de la siguiente lista:

•t, aa: Ordenar por filas afectadas o filas afectadas promedio
•l, ae: Ordenar por filas examinadas o filas examinadas agregadas
•l, at: Ordenar por tiempo de consulta o tiempo de consulta promedio
•l, al: Ordenar por tiempo de bloqueo o tiempo de bloqueo promedio
•s, as: Ordenar por filas enviadas o filas enviadas promedio
•c: Ordenar por recuento
•-t N

Mostrar solo las primeras N consultas en la salida.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa.

Ejemplo de uso:

shell> mariadb-dumpslow
Reading mariadb slow query log from /usr/local/mysql/data/mysqld51-apple-slow.log
Count: 1  Time=4.32s (4s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t2 select * from t1
Count: 3  Time=2.53s (7s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t2 select * from t1 limit N
Count: 3  Time=2.13s (6s)  Lock=0.00s (0s)  Rows=0.0 (0), root[root]@localhost
 insert into t1 select * from t1
