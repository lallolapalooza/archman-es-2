mysql_query(3) MariaDB Connector/C mysql_query(3)

Nombre

mysql_query - ejecuta una cadena de sentencia terminada en nulo

Sinopsis

#include <mysql.h>
int mysql_query(MYSQL * mysql,
                const char * query);

Descripción

Realiza una sentencia apuntada por la cadena terminada en nulo query contra la base de datos. A diferencia de mysql_real_query(3), mysql_query() no es segura para binarios.

Parámetro

•
mysql - un manejador mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
query - una cadena terminada en nulo que contiene la sentencia a ejecutar.

Notas

•
Para ejecutar múltiples sentencias, las sentencias dentro de la cadena terminada en nulo deben separarse por un punto y coma.
•
Si tu sentencia contiene datos binarios, deberías usar mysql_real_query(3) o escapar tus datos con mysql_hex_string(3).
•
Para determinar si una sentencia devolvió un conjunto de resultados, usa la función mysql_field_count(3).

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si falla.
