Nombre

mysql_stmt_fetch_column - Recupera una única columna en el búfer de enlace

Sinopsis

#include <mysql.h>
int mysql_stmt_fetch_column(MYSQL_STMT * stmt,
                            MYSQL_BIND * bind_arg,
                            unsigned int column,
                            unsigned long offset);

Descripción

Esta función se puede utilizar para recuperar datos grandes de una única columna en partes.

Parámetro

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
bind_arg - un puntero a una estructura MYSQL_BIND.
•
column - número de columna, la primera columna se numera cero.
•
offset - el desplazamiento en el que se debe comenzar a recuperar los datos.

Valor de retorno

Devuelve cero si tiene éxito, distinto de cero si falla.

Notas

•
El tamaño del búfer se especifica dentro de la estructura MYSQL_BIND.
