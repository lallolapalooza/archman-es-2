MARIADB-IMPORT(1) Sistema de Base de Datos MariaDB MARIADB-IMPORT(1)

NOMBRE

mariadb-import - un programa de importación de datos (mariadb-import es ahora un enlace simbólico a mariadb-import)

SINOPSIS

mariadb-import [opciones] nombre_db archivo_texto1 ...

DESCRIPCIÓN

El cliente mariadb-import proporciona una interfaz de línea de comandos a la declaración SQL LOAD DATA INFILE. La mayoría de las opciones de mariadb-import corresponden directamente a cláusulas de la sintaxis LOAD DATA INFILE.

Invoque mariadb-import de esta manera:

shell> mariadb-import [opciones] nombre_db archivo_texto1 [archivo_texto2 ...]

Para cada archivo de texto con nombre en la línea de comandos, mariadb-import elimina cualquier extensión del nombre del archivo y usa el resultado para determinar el nombre de la tabla en la que importar el contenido del archivo. Por ejemplo, los archivos llamados patient.txt, patient.text y patient se importarían todos en una tabla llamada patient.

mariadb-import admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-import] y [client]. mariadb-import también admite las opciones para procesar archivos de opciones.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--character-sets-dir=ruta

El directorio donde están instalados los conjuntos de caracteres.

•--columns=lista_columnas, -c lista_columnas

Esta opción toma una lista de nombres de columnas separada por comas como valor. El orden de los nombres de las columnas indica cómo hacer coincidir las columnas del archivo de datos con las columnas de la tabla.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos admiten la compresión.

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre_plugin

Plugin del cliente predeterminado para la autenticación.

•--default-character-set=nombre_juego_caracteres

Usa nombre_juego_caracteres como el conjunto de caracteres predeterminado.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos globales de opciones predeterminadas. Debe proporcionarse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas, reemplazando los archivos globales de opciones predeterminadas. Debe proporcionarse como la primera opción.

•--delete, -d

Vacía la tabla antes de importar el archivo de texto.

•--fields-terminated-by=..., --fields-enclosed-by=..., --fields-optionally-enclosed-by=..., --fields-escaped-by=...

Estas opciones tienen el mismo significado que las cláusulas correspondientes para LOAD DATA INFILE.

•--force, -f

Ignora los errores. Por ejemplo, si una tabla para un archivo de texto no existe, continúa procesando cualquier archivo restante. Sin --force, mariadb-import sale si una tabla no existe.

•--host=nombre_host, -h nombre_host

Importa datos al servidor MariaDB en el host proporcionado. El host predeterminado es localhost.

•--ignore, -i

Ver la descripción de la opción --replace.

•--ignore-foreign-keys, -k

Deshabilita las comprobaciones de claves foráneas mientras se importan los datos.

•--ignore-lines=N

Ignora las primeras N líneas del archivo de datos.

•--innodb-optimize-keys

Crea índices secundarios después de la carga de datos, lo que acelera la carga (solo InnoDB). Predeterminado activado; usa --skip-innodb-optimize-keys para desactivar.

•--lines-terminated-by=...

Esta opción tiene el mismo significado que la cláusula correspondiente para LOAD DATA INFILE. Por ejemplo, para importar archivos de Windows que tienen líneas terminadas con pares de retorno de carro/nueva línea, usa --lines-terminated-by="\r\n". (Puede que tengas que duplicar las barras invertidas, dependiendo de las convenciones de escape de tu intérprete de comandos.).

•--local, -L

Lee archivos de entrada localmente desde el host cliente.

•--lock-tables, -l

Bloquea todas las tablas para escritura antes de procesar cualquier archivo de texto. Esto asegura que todas las tablas estén sincronizadas en el servidor.

•--low-priority

Usa LOW_PRIORITY al cargar la tabla. Esto solo afecta a los motores de almacenamiento que usan solo bloqueos a nivel de tabla (como MyISAM, MEMORY y MERGE).

•--no-defaults

No lee opciones predeterminadas de ningún archivo de opciones. Debe proporcionarse como primer argumento.

•--parallel=N, -j N

Número de trabajos de LOAD DATA ejecutados en paralelo. --use-threads es un sinónimo.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usas la forma corta de la opción (-p), no puedes dejar un espacio entre la opción y la contraseña. Si omites el valor contraseña después de la opción --password o -p en la línea de comandos, mariadb-import te pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puedes usar un archivo de opciones para evitar proporcionar la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctate al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor admite conexiones por tubería con nombre.

•--plugin-dir=nombre


Directorio para plugins del lado del cliente.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar para la conexión. Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente causarían que se usara un protocolo diferente al que deseas.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe proporcionarse como el primer argumento.

•--replace, -r

Las opciones --replace y --ignore controlan el manejo de filas de entrada que duplican filas existentes en valores de clave únicos. Si especificas --replace, las nuevas filas reemplazan las filas existentes que tienen el mismo valor de clave única. Si especificas --ignore, se omiten las filas de entrada que duplican una fila existente en un valor de clave única. Si no especificas ninguna de las opciones, ocurre un error cuando se encuentra un valor de clave duplicado, y el resto del archivo de texto se ignora.

•--silent, -s

Modo silencioso. Produce salida solo cuando ocurren errores.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (automáticamente activado con otras opciones). Deshabilítelo con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a usar (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor.

•--use-threads=N

Carga archivos en paralelo usando N hilos. Sinónimo de -j, --parallel=num

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa.

•--version, -V

Muestra la información de la versión y sale.

Aquí hay una sesión de ejemplo que demuestra el uso de mariadb-import:

shell> mariadb -e 'CREATE TABLE imptest(id INT, n VARCHAR(30))' test
shell> ed
a
100     Max Sydow
101     Count Dracula
.
w imptest.txt
32
q
shell> od -c imptest.txt
0000000   1   0   0  \t   M   a   x       S   y   d   o   w  \n   1   0
0000020   1  \t   C   o   u   n   t       D   r   a   c   u   l   a  \n
0000040
shell> mariadb-import --local test imptest.txt
test.imptest: Records: 2  Deleted: 0  Skipped: 0  Warnings: 0
shell> mariadb -e 'SELECT * FROM imptest' test
+------+---------------+
| id   | n             |
+------+---------------+
|  100 | Max Sydow     |
|  101 | Count Dracula |
+------+---------------+
