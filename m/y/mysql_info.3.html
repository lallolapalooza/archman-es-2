mysql_info(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_info(3) MariaDB Connector/C mysql_info(3)

Nombre

mysql_info - proporciona información sobre la última sentencia ejecutada

Sinopsis

#include <mysql.h>
const char * mysql_info(MYSQL * mysql);

Descripción

La función mysql_info() devuelve una cadena que proporciona información sobre la última sentencia ejecutada.

Parámetro

•
mysql - un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).

Notas

Las sentencias que no entran en uno de los formatos anteriores no son compatibles (p. ej., SELECT). En estas situaciones, mysql_info() devolverá una cadena vacía.

Valor de retorno

Cadena de información terminada en nulo. La información depende del tipo de sentencia:

Tipo de consulta Cadena de resultado de ejemplo
INSERT INTO...SELECT... Registros: 100 Duplicados: 0 Advertencias: 0
INSERT INTO...VALUES (...),(...),(...) Registros: 3 Duplicados: 0 Advertencias: 0
LOAD DATA INFILE Registros: 1 Eliminados: 0 Omitidos: 0 Advertencias: 0
ALTER TABLE ... Registros: 3 Duplicados: 0 Advertencias: 0
UPDATE ... Filas coincidentes: 40 Cambiadas: 40 Advertencias: 0
