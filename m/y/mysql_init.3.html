mysql_init(3) MariaDB Connector/C mysql_init(3)

Nombre

mysql_init - Prepara e inicializa una estructura MYSQL

Sinopsis

#include <mysql.h>
MYSQL *mysql_init(MYSQL *mysql);

Descripción

Prepara e inicializa una estructura MYSQL para ser utilizada con mysql_real_connect(3). Si se pasó la dirección de una estructura MYSQL como parámetro, la estructura será inicializada; si se pasó NULL, se asignará y inicializará una nueva estructura.

Notas: * Si el parámetro mysql no es NULL, la función de API mysql_close(3) no liberará la memoria. * Cualquier llamada posterior a cualquier función (excepto mysql_optionsv(3)) fallará hasta que se haya llamado a mysql_real_connect(3). * La memoria asignada por mysql_init() debe liberarse con mysql_close(3).

Valor de retorno

La función mysql_init() devuelve la dirección de una estructura MYSQL, o NULL en caso de error de asignación de memoria.
