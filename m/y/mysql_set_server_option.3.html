mysql_set_server_option(3) MariaDB Connector/C mysql_set_server_option(3)

Nombre

mysql_set_server_option - Establece una opción del servidor

Sinopsis

#include <mysql.h>
int mysql_set_server_option(MYSQL * mysql,
                            enum enum_mysql_set_option);

Descripción

Establece una opción del servidor.

Parámetros

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
enum_mysql_set_option - opción del servidor (ver abajo) Opción del servidor, que puede ser uno de los siguientes valores:
Opción Descripción
MYSQL_OPTION_MULTI_STATEMENTS_OFF Deshabilita el soporte para múltiples sentencias
MYSQL_OPTION_MULTI_STATEMENTS_ON Habilita el soporte para múltiples sentencias

Valor de retorno

Devuelve cero en caso de éxito, distinto de cero en caso de fallo.
