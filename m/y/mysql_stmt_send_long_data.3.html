Nombre

mysql_stmt_send_long_data - Envía datos en fragmentos

Sintaxis

#include <mysql.h>
my_bool mysql_stmt_send_long_data(MYSQL_STMT * stmt,
                                  unsigned int,
                                  const char * data,
                                  unsigned long);

Descripción

Permite enviar datos de parámetros al servidor en piezas (o fragmentos), p. ej. si el tamaño de un blob excede el tamaño de max_allowed_packet. Esta función puede ser llamada múltiples veces para enviar las partes de un valor de datos de caracteres o binarios para una columna, que debe ser uno de los tipos de datos TEXT o BLOB.

Parámetro

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
param_no - indica a qué parámetro asociar los datos. Los parámetros se numeran comenzando desde 0.
•
data - un búfer que contiene los datos a enviar.
•
long - tamaño del búfer de datos.

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si ocurrió un error.

Notas

•
mysql_stmt_send_long_data() debe ser llamada antes de mysql_stmt_execute(3).
•
las variables enlazadas para esta columna serán ignoradas al llamar a mysql_stmt_execute(3).

Ver también

•
mysql_stmt_execute(3).
