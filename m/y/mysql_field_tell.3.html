Nombre

mysql_field_tell - Devuelve el desplazamiento del cursor de campo

Sinopsis

#include <mysql.h>
MYSQL_FIELD_OFFSET mysql_field_tell(MYSQL_RES * result);

Descripción

Devuelve el desplazamiento del cursor de campo utilizado para la última llamada a mysql_fetch_field(3). Este valor se puede utilizar como parámetro para la función mysql_field_seek(3).

Parámetro

•
result - un identificador de conjunto de resultados devuelto por mysql_store_result(3) o mysql_use_result(3).

Valor de retorno

Devuelve el desplazamiento actual del cursor de campo
