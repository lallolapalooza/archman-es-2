mysql_real_escape_string(3)

Licencias: GPL-2.0-only

mysql_real_escape_string(3) Conector/C de MariaDB mysql_real_escape_string(3)

Nombre

mysql_real_escape_string - escapa una cadena teniendo en cuenta el juego de caracteres de la conexión

Sinopsis

#include <mysql.h>
unsigned long mysql_real_escape_string(MYSQL * mysql,
                                       char * to,
                                       const char * from,
                                       unsigned long);

Descripción

Esta función se utiliza para crear una cadena SQL legal que puede usar en una sentencia SQL. La cadena dada se codifica en una cadena SQL escapada, teniendo en cuenta el juego de caracteres actual de la conexión.

Parámetro

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
to - búfer para la cadena codificada. El tamaño de este búfer debe ser longitud * 2 + 1 bytes: en el peor de los casos, cada carácter de la cadena from necesita ser escapado. Adicionalmente, se añadirá un carácter 0 final.
•
from - una cadena que será codificada por mysql_real_escape_string().
•
long - la longitud de la cadena from.

Valor de retorno

Devuelve la longitud de la cadena codificada (to).
