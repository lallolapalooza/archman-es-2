mysql_stmt_close(3) Conector/C de MariaDB mysql_stmt_close(3)

Nombre

mysql_stmt_close - Cierra una sentencia preparada

Sinopsis

#include <mysql.h>
my_bool mysql_stmt_close(MYSQL_STMT * stmt);

Descripción

Cierra una sentencia preparada y libera el manejador de la sentencia. Si la sentencia actual tiene resultados pendientes o no leídos, esta función los cancela para que se pueda ejecutar la siguiente consulta.

Parámetro

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si hay un error (al comunicarse con el servidor). La sentencia se libera, independientemente del error.

Notas

•
Si desea reutilizar el manejador de sentencia con un comando SQL diferente, use mysql_stmt_reset(3).
