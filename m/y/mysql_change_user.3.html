mysql_change_user(3) Conector/C de MariaDB mysql_change_user(3)

Nombre

mysql_change_user - cambia el usuario y la base de datos por defecto

Sinopsis

#include <mysql.h>
my_bool mysql_change_user(MYSQL * mysql,
                          const char * user,
                          const char * passwd,
                          const char * db);

Descripción

Cambia el usuario y la base de datos por defecto de la conexión actual.

Para poder cambiar de usuario con éxito, se deben proporcionar parámetros válidos de nombre de usuario y contraseña, y ese usuario debe tener suficientes permisos para acceder a la base de datos deseada. Si por alguna razón la autorización falla, la autenticación del usuario actual permanecerá.

Parámetros

•
mysql es un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
user - el nombre de usuario para la autenticación del servidor
•
passwd - la contraseña para la autenticación del servidor
•
db - la base de datos por defecto. Si se desea, se puede pasar el valor NULL, lo que resulta en solo cambiar el usuario y no seleccionar una base de datos. Para seleccionar una base de datos en este caso, use la función mysql_select_db(3).

Notas

•
mysql_change_user siempre hará que la conexión de base de datos actual se comporte como si fuera una conexión de base de datos completamente nueva, independientemente de si la operación se completó con éxito o no. Este reinicio incluye la realización de un rollback en cualquier transacción activa, el cierre de todas las tablas temporales y el desbloqueo de todas las tablas bloqueadas.
•
Para prevenir ataques de denegación de servicio y ataques de fuerza bruta, el servidor bloqueará la conexión si mysql_change_user() falló tres veces seguidas.

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si ocurrió un error.
