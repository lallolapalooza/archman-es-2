mysql_commit(3) MariaDB Connector/C mysql_commit(3)

Nombre

mysql_commit - Confirma la transacción actual

Sinopsis

#include <mysql.h>
my_bool mysql_commit(MYSQL * mysql);

Descripción

Confirma la transacción actual para la conexión de base de datos especificada. Devuelve cero si tiene éxito, un valor distinto de cero si ocurrió un error.

Parámetros

•
mysql es un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).

Notas

Ejecutar mysql_commit() no afectará el comportamiento de autocommit. Esto significa que cualquier sentencia de actualización o inserción posterior a mysql_commit() será revertida cuando se cierre la conexión.

== Ver también * mysql_autocommit(3) * mysql_rollback(3)
