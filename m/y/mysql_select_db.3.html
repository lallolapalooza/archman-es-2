Nombre

mysql_select_db - selecciona una base de datos como predeterminada

Sintaxis

#include <mysql.h>
int mysql_select_db(MYSQL * mysql,
                    const char * db);

Descripción

Selecciona una base de datos como predeterminada. Devuelve cero si tiene éxito, un valor distinto de cero si falla.

Parámetros

•
mysql es un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
db - el nombre de la base de datos predeterminada

Notas

•
Para obtener el nombre de la base de datos predeterminada, ejecute el comando SQL SELECT DATABASE() o recupere el valor a través de la función de API mariadb_get_infov(3).
•
La base de datos predeterminada también se puede establecer mediante el parámetro db en mysql_real_connect(3).

Ejemplos

SQL

# cambiar a la base de datos predeterminada test
USE test;
# comprobar la base de datos predeterminada
SELECT DATABASE();
+------------+
| database() |
+------------+
| test       |
+------------+

Connector/C de MariadDB

static int set_default_db(MYSQL *mysql)
{
  int rc;
  char *default_db;
  /* cambiar la base de datos predeterminada a test */
  rc= mysql_select_db(mysql, "test");
  if (rc)
    return rc;  /* Error */
  /* obtener la base de datos predeterminada */
  rc= mariadb_get_infov(mysql, MARIADB_CONNECTION_SCHEMA, &default_db);
  if (rc)
    return rc; /* Error */
  if (strcmp("test", default_db) != NULL)
  {
    printf("Base de datos predeterminada incorrecta\n");
    return 1;
  }
  printf("Base de datos predeterminada: %s", default_db);
  return 0;
}
