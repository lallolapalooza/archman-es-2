Nombre

mysql_fetch_field_direct - Devuelve un puntero a una estructura MYSQL_FIELD

Sinopsis

#include <mysql.h>
MYSQL_FIELD * mysql_fetch_field_direct(MYSQL_RES * res,
                                       unsigned int fieldnr);

Descripción

Devuelve un puntero a una estructura MYSQL_FIELD que contiene información de campo del conjunto de resultados especificado. ### Parámetros * res - un identificador de conjunto de resultados devuelto por mysql_store_result(3) o mysql_use_result(3). * fieldnr - el número de campo. Este valor debe estar dentro del rango de 0 al número de campos - 1 ### Notas * El número total de campos se puede obtener mediante mysql_field_count()

Valor de retorno

Puntero a una estructura MYSQL_FIELD o NULL si se especificó un número de campo inválido
