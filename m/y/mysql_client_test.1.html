MARIADB-CLIENT-TEST(1) Sistema de Bases de Datos MariaDB MARIADB-CLIENT-TEST(1)

NOMBRE

mariadb-client-test - prueba de la API del cliente (mariadb-client-test es ahora un enlace simbólico a mariadb-client-test)
mariadb-client-test-embedded - prueba de la API del cliente para el servidor embebido (mariadb-client-test-embedded es ahora un enlace simbólico a mariadb-client-test-embedded)

SINOPSIS

mariadb-client-test [opciones] [nombre_prueba] ...

mariadb-client-test-embedded [opciones] [nombre_prueba] ...

DESCRIPCIÓN

El programa mariadb-client-test se utiliza para probar aspectos de la API del cliente MariaDB que no se pueden probar utilizando mariadb-test y su lenguaje de prueba. mariadb-client-test-embedded es similar pero se utiliza para probar el servidor embebido. Ambos programas se ejecutan como parte del conjunto de pruebas.

El código fuente de los programas se puede encontrar en tests/mariadb-client-test.c en una distribución fuente. El programa sirve como una buena fuente de ejemplos que ilustran cómo usar varias características de la API del cliente.

mariadb-client-test se utiliza en una prueba con el mismo nombre en el conjunto principal de pruebas de mariadb-test-run.pl, pero también puede ejecutarse directamente. A diferencia de los otros programas enumerados aquí, no lee una descripción externa de qué pruebas ejecutar. En cambio, todas las pruebas están codificadas en el programa, que está escrito para cubrir todos los aspectos de la API del lenguaje C.

mariadb-client-test admite las siguientes opciones:

•--help, -?

Muestra un mensaje de ayuda y sale.

•--basedir=nombre_dir, -b nombre_dir

El directorio base para las pruebas.

•--count=conteo, -t conteo

El número de veces que se ejecutarán las pruebas.

•--database=nombre_bd, -D nombre_bd

La base de datos a utilizar.

•--debug[=opciones_debug], -#[opciones_debug]

Escribe un registro de depuración si MariaDB está compilado con soporte de depuración. El valor predeterminado de opciones_debug es 'd:t:o,/tmp/mariadb-client-test.trace'.

•--getopt-ll-test=opción, -g opción

Opción a utilizar para probar errores en la biblioteca getopt.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host dado.

•--password[=contraseña], -p[contraseña]

La contraseña a utilizar al conectarse al servidor. Si utiliza la forma corta de la opción (-p), *no puede* haber un espacio entre la opción y la contraseña. Si omite el valor de contraseña después de la opción --password o -p en la línea de comandos, se le solicitará una.

•--port=número_puerto, -P número_puerto

El número de puerto TCP/IP a utilizar para la conexión.

•--server-arg=arg, -A arg

Argumento a enviar al servidor embebido.

•--show-tests, -T

Muestra todos los nombres de las pruebas.

•--silent, -s

Ser más silencioso.

•--socket=ruta, -S ruta

El archivo de socket a utilizar al conectarse a localhost (que es el host predeterminado).

•--testcase, -c

La opción se utiliza cuando se llama desde mariadb-test-run.pl, de modo que mariadb-client-test pueda comportarse opcionalmente de manera diferente a como lo haría si se llamara manualmente, por ejemplo, omitiendo algunas pruebas. Actualmente, no hay diferencia en el comportamiento, pero la opción se incluye para hacer esto posible.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor.

•-v nombre_dir, --vardir=nombre_dir

El directorio de datos para las pruebas. El valor predeterminado es mariadb-test/var.
