mysql_autocommit(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_autocommit(3) MariaDB Connector/C mysql_autocommit(3)

Nombre

mysql_autocommit - Activa/desactiva el modo autocommit

Sinopsis

#include <mysql.h>
my_bool mysql_autocommit(MYSQL * mysql, my_bool auto_mode);

Descripción

Activa o desactiva el modo autocommit para la conexión de base de datos actual. El modo autocommit se establecerá si modo=1 o se desactivará si modo=0.

Parámetros:

•
mysql es un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
auto_mode - si se activa o no el autocommit.

Notas

•
El modo autocommit solo afecta a las operaciones en tipos de tabla transaccionales. Para determinar el estado actual del modo autocommit, use el comando SQL SELECT @@autocommit o compruebe el estado del servidor (vea el ejemplo a continuación).
•
Tenga en cuenta: la función [mysql_rollback()}(mysql_rollback() no funcionará si el modo autocommit está activado.

Ejemplos

SQL

# Desactivar autocommit
SET AUTOCOMMIT=0;
# Recuperar autocommit
SELECT @@autocommit;
+--------------+
| @@autocommit |
+--------------+
|            0 |
+--------------+

MariaDB Connector/C

static int test_autocommit(MYSQL *mysql)
{
  int rc;
  unsigned int server_status;
  /* Desactivar autocommit */
  rc= mysql_autocommit(mysql, 0);
  if (rc)
    return rc; /* Error */
  /* Si autocommit = 0 tuvo éxito, el último paquete OK actualizó el estado del servidor */
  rc= mariadb_get_infov(mysql, MARIADB_CONNECTION_SERVER_STATUS, &server_status);
  if (rc)
    return rc; /* Error */
  if (server_status & SERVER_STATUS_AUTOCOMMIT)
  {
    printf("Error: autocommit está activado\n");
    return 1;
  }
  printf("OK: autocommit está desactivado\n");
  return 0;
}
