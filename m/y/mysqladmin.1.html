MARIADB-ADMIN(1) Sistema de bases de datos MariaDB MARIADB-ADMIN(1)

NOMBRE

mariadb-admin - cliente para administrar un servidor MariaDB (mariadb-admin es ahora un enlace simbólico a mariadb-admin)

SINOPSIS

mariadb-admin [opciones] comando [argumento-comando] [comando [argumento-comando]] ...

DESCRIPCIÓN

mariadb-admin es un cliente para realizar operaciones administrativas. Puedes usarlo para verificar la configuración y el estado actual del servidor, para crear y eliminar bases de datos, y más.

Invoca mariadb-admin de la siguiente manera:

shell> mariadb-admin [opciones] comando [argumento-comando] [comando [argumento-comando]] ...

mariadb-admin soporta los siguientes comandos. Algunos de los comandos toman un argumento después del nombre del comando.

•create nombre_bd

Crea una nueva base de datos llamada nombre_bd.

•debug

Indica al servidor que escriba información de depuración en el registro de errores.

Esto también incluye información sobre el Programador de Eventos.

•drop nombre_bd

Elimina la base de datos llamada nombre_bd y todas sus tablas.

•extended-status

Muestra las variables de estado del servidor y sus valores.

•flush-all-statistics

Vacía todas las tablas de estadísticas.

•flush-all-status

Vacía todo el estado y las estadísticas.

•flush-binary-log

Vacía el registro binario.

•flush-client-statistics

Vacía las estadísticas del cliente.

•flush-engine-log

Vacía el registro del motor.

•flush-error-log

Vacía el registro de errores.

•flush-general-log

Vacía el registro general de consultas.

•flush-hosts

Vacía toda la información en la caché de hosts.

•flush-index-statistics

Vacía las estadísticas de índices.

•flush-logs

Vacía todos los registros.

•flush-privileges

Recarga las tablas de permisos (lo mismo que reload).

•flush-relay-log

Vacía el registro de retransmisión.

•flush-slow-log

Vacía el registro de consultas lentas.

•flush-ssl

Vacía los certificados SSL.

•flush-status

Borra las variables de estado.

•flush-table-statistics

Vacía las estadísticas de tablas.

•flush-tables

Vacía todas las tablas.

•flush-threads

Vacía la caché de hilos.

•flush-user-resources

Vacía los recursos de usuario.

•kill id,id,...

Termina hilos del servidor. Si se dan varios valores de ID de hilo, no debe haber espacios en la lista.

•old-password nueva-contraseña

Esto es como el comando password pero almacena la contraseña usando el formato de hash de contraseña antiguo (anterior a MySQL 4.1).

•password nueva-contraseña

Establece una nueva contraseña. Esto cambia la contraseña a nueva-contraseña para la cuenta que utilizas con mariadb-admin para conectarte al servidor. Por lo tanto, la próxima vez que invoques mariadb-admin (o cualquier otro programa cliente) usando la misma cuenta, necesitarás especificar la nueva contraseña.

Si el valor nueva-contraseña contiene espacios u otros caracteres especiales para tu intérprete de comandos, necesitas encerrarlo entre comillas. En Windows, asegúrate de usar comillas dobles en lugar de comillas simples; las comillas simples no se eliminan de la contraseña, sino que se interpretan como parte de la contraseña. Por ejemplo:

shell> mariadb-admin password "mi nueva contraseña"

Precaución
No uses este comando si el servidor se inició con la opción --skip-grant-tables. No se aplicará ningún cambio de contraseña. Esto es cierto incluso si precedes el comando de contraseña con flush-privileges en la misma línea de comandos para volver a habilitar las tablas de permisos, ya que la operación de vaciado ocurre después de que te conectas. Sin embargo, puedes usar mariadb-admin flush-privileges para volver a habilitar la tabla de permisos y luego usar un comando mariadb-admin password separado para cambiar la contraseña.
•ping

Verifica si el servidor está activo. El estado de retorno de mariadb-admin es 0 si el servidor está en ejecución, 1 si no lo está. Esto es 0 incluso en caso de un error como Acceso denegado, porque esto significa que el servidor está en ejecución pero rechazó la conexión, lo cual es diferente a que el servidor no esté en ejecución.

•processlist

Muestra una lista de hilos activos del servidor. Esto es como la salida de la sentencia SHOW PROCESSLIST. Si se proporciona la opción --verbose, la salida es como la de SHOW FULL PROCESSLIST.

•reload

Recarga las tablas de permisos.

•refresh

Vacía todas las tablas y cierra y abre los archivos de registro.

•shutdown

Detiene el servidor.

•start-all-slaves

Inicia todas las réplicas.

•start-slave

Inicia la replicación en un servidor esclavo.

•status

Muestra un breve mensaje de estado del servidor.

•stop-all-slaves

Detiene todas las réplicas.

•stop-slave

Detiene la replicación en un servidor esclavo.

•variables

Muestra las variables del sistema del servidor y sus valores.

•version

Muestra información de la versión del servidor.

Todos los comandos se pueden acortar a cualquier prefijo único. Por ejemplo:

shell> mariadb-admin proc stat
+----+-------+-----------+----+---------+------+-------+------------------+
| Id | User  | Host      | db | Command | Time | State | Info             |
+----+-------+-----------+----+---------+------+-------+------------------+
| 51 | monty | localhost |    | Query   | 0    |       | show processlist |
+----+-------+-----------+----+---------+------+-------+------------------+
Uptime: 1473624  Threads: 1  Questions: 39487
Slow queries: 0  Opens: 541  Flush tables: 1
Open tables: 19  Queries per second avg: 0.0268

El resultado del comando mariadb-admin status muestra los siguientes valores:

•Uptime

El número de segundos que el servidor MariaDB ha estado en ejecución.

•Threads

El número de hilos activos (clientes).

•Questions

El número de preguntas (consultas) de los clientes desde que se inició el servidor.

•Slow queries

El número de consultas que han tardado más de log_slow_query_time segundos.

•Opens

El número de tablas que el servidor ha abierto.

•Flush tables

El número de comandos flush-*, refresh y reload que el servidor ha ejecutado.

•Open tables

El número de tablas que están actualmente abiertas.

•Memory in use

La cantidad de memoria asignada directamente por mariadbd. Este valor solo se muestra cuando MariaDB ha sido compilado con --with-debug=full.

•Maximum memory used

La cantidad máxima de memoria asignada directamente por mariadbd. Este valor solo se muestra cuando MariaDB ha sido compilado con --with-debug=full.

Si ejecutas mariadb-admin shutdown al conectarte a un servidor local usando un archivo de socket Unix, mariadb-admin espera hasta que se haya eliminado el archivo de ID de proceso del servidor, para asegurar que el servidor se ha detenido correctamente.

NAME

mariadb-admin - MariaDB server administration utility

SYNOPSIS

mariadb-admin [-?|--help] [-C|--compress] [--character-sets-dir=path] [--connect-timeout=timeout] [-c|--count N] [-#|--debug[=debug_options]] [--debug-check] [--debug-info] [--default-auth=plugin] [--default-character-set=charset_name] [--defaults-extra-file=filename] [--defaults-file=filename] [-f|--force] [-h|--host=host_name] [-l|--local] [-b|--no-beep] [--no-defaults] [-p[password]|--password[=password]] [-W|--pipe] [-P|--port=port_num] [--print-defaults] [--protocol={TCP|SOCKET|PIPE|MEMORY}] [-r|--relative] [--shutdown-timeout=timeout] [-s|--silent] [-i|--sleep=delay] [-S|--socket=path] [--ssl] [--ssl-ca=name] [--ssl-capath=name] [--ssl-cert=name] [--ssl-cipher=name] [--ssl-key=name] [--ssl-crl=name] [--ssl-crlpath=name] [--ssl-verify-server-cert] [--tls-version=name] [-u|--user=user_name] [-v|--verbose] [-V|--version] [-E|--vertical] [-w[count]|--wait[=count]] [--wait-for-all-slaves] [--var_name[=value]] [other_options] [commands]

DESCRIPTION

The mariadb-admin utility is a client-side utility for administrating MariaDB servers. It can perform a variety of administrative tasks, such as managing databases, tables, users, and server status.

The program is invoked with a set of options that are specified on the command line or in the [mariadb-admin] and [client] option file groups.

•--help, -?

Muestra la ayuda y sale.

•--character-sets-dir=path

El directorio donde están instalados los conjuntos de caracteres.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos soportan la compresión.

•--connect-timeout=timeout

Equivalente a --connect_timeout, ver el final de esta sección.

•--count=N, -c N

El número de iteraciones a realizar para la ejecución repetida de comandos si se da la opción --sleep.

•--debug[=debug_options], -# [debug_options]

Escribe un registro de depuración. Una cadena típica de debug_options es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o,/tmp/mariadb-admin.trace'.

•--debug-check

Comprueba el uso de memoria y de archivos abiertos al salir.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU cuando el programa sale.

•--default-auth

El plugin del lado del cliente de autenticación predeterminado a usar.

•--default-character-set=charset_name

Usa charset_name como el conjunto de caracteres predeterminado.

•--defaults-extra-file=filename

Establece filename como el archivo del cual leer las opciones predeterminadas después de que se hayan leído los archivos de valores predeterminados globales. Debe darse como la primera opción.

•--defaults-file=filename

Establece filename como el archivo del cual leer las opciones predeterminadas, anula los archivos de valores predeterminados globales. Debe darse como la primera opción.

•--force, -f

No pide confirmación para el comando drop db_name. Con múltiples comandos, continúa incluso si ocurre un error.

•--host=host_name, -h host_name

Conéctate al servidor MariaDB en el host dado.

•--local, -l

Suprime que los comandos SQL se escriban en el log binario usando FLUSH LOCAL o habilitando sql_log_bin=0 para la sesión.

•--no-beep, -b

Suprime el pitido de advertencia que se emite por defecto para errores como fallos al conectarse al servidor.

•--no-defaults

No lee opciones predeterminadas de ningún archivo de opciones. Debe darse como el primer argumento.

•--password[=password], -p[password]

La contraseña a usar al conectarse al servidor. Si usas la forma corta de la opción (-p), *no* puedes dejar un espacio entre la opción y la contraseña. Si omites el valor de password después de la opción --password o -p en la línea de comandos, mariadb-admin te pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro.

•--pipe, -W

En Windows, conéctate al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor soporta conexiones por tubería con nombre.

•--port=port_num, -P port_num

El número de puerto TCP/IP a usar para la conexión o 0 para usar el predeterminado, en orden de preferencia: my.cnf, $MYSQL_TCP_PORT, /etc/services, predeterminado incorporado (3306). Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe darse como el primer argumento.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente causarían que se usara un protocolo diferente al que deseas.

•--relative, -r

Muestra la diferencia entre los valores actuales y anteriores cuando se usa con la opción --sleep. Actualmente, esta opción solo funciona con el comando extended-status.

•--shutdown-timeouttimeout

Equivalente a --shutdown_timeout, ver el final de esta sección.

•--silent, -s

Sale silenciosamente si no se puede establecer una conexión con el servidor.

•--sleep=delay, -i delay

Ejecuta comandos repetidamente, durmiendo durante delay segundos entre ellos. La opción --count determina el número de iteraciones. Si no se da --count, mariadb-admin ejecuta comandos indefinidamente hasta que se interrumpe.

•--socket=path, -S path

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (habilitado automáticamente con otras banderas). Deshabilítalo con --skip-ssl.

•--ssl-ca=name

Archivo CA en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-capath=name

Directorio CA (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cert=name

Certificado X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=name

Cifrado SSL a usar (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-key=name

Clave X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crl=name

Lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=name

Ruta de la lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--tls-version=name,

Acepta una lista separada por comas de versiones de protocolo TLS. Una versión de protocolo TLS solo se habilitará si está presente en esta lista. Todas las demás versiones de protocolo TLS no estarán permitidas.

•--user=user_name, -u user_name

El nombre de usuario de MariaDB a usar al conectarse al servidor.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa.

•--version, -V

Muestra información de la versión y sale.

•--vertical, -E

Imprime la salida verticalmente. Esto es similar a --relative, pero imprime la salida verticalmente.

•--wait[=count], -w[count]

Si la conexión no se puede establecer, espera y reintenta en lugar de abortar. Si se da un valor de count, indica el número de veces que se reintentará. El valor predeterminado es una vez.

•--wait-for-all-slaves

Espera a que el último evento de binlog se envíe a todos los esclavos conectados antes de apagar. Esta opción está deshabilitada por defecto.

También puedes establecer las siguientes variables usando --var_name=value

•connect_timeout

El número máximo de segundos antes de que expire la conexión. El valor predeterminado es 43200 (12 horas).

•shutdown_timeout

El número máximo de segundos a esperar para el apagado del servidor. El valor predeterminado es 3600 (1 hora).

NAME

mysqladmin - a client interface for administering MySQL server

SYNOPSIS

mysqladmin [OPTIONS] [COMMAND | VARIABLES]

mysqladmin OPTION ... [COMMAND | VARIABLES]

DESCRIPTION

mysqladmin is a client interface for administering a MySQL server. It supports a number of administrative tasks. You can use mysqladmin to check the server's configuration, to get information about the server's operational state, and to perform administrative operations. The following commands are available:

  • ping: Checks if the server is alive.
  • ping ...: Send a ping to the server.
  • shutdown: Shuts down the server.
  • reload: Reloads the grant tables.
  • refresh: Flushes tables and closes all open tables.
  • processlist: Lists the server's threads.
  • variables: Lists the server's variables.
  • status: Displays the server status.
  • extended-status: Displays the server's extended status.
  • create DATABASE: Creates a database.
  • drop DATABASE: Drops a database.
  • flush-hosts: Flushes the host cache.
  • flush-tables: Flushes tables.
  • flush-logs: Flushes logs.
  • flush-privileges: Reloads grant tables.
  • kill id: Kills a server thread.
  • password NEW-PASSWORD: Sets a new password for the current user.
  • old-password NEW-PASSWORD: Sets a new password for the current user (for older MySQL versions).
  • debug: Sets a debug variable.
  • shutdown: Shuts down the server.

You can also set variables using the SET command, e.g., mysqladmin SET variable=value.
