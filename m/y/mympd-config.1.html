NOMBRE

mympd-config - herramienta de configuración de myMPD

SINOPSIS

mympd-config [-b </usr/bin/mympd>] [-c </var/lib/mympd/config>] [-s <0|1>] [CONFIGURACIÓN VALOR ...]

DESCRIPCIÓN

mympd-config es una pequeña herramienta de línea de comandos para configurar ajustes básicos de myMPD.

OPCIONES

-b <//usr/bin/mympd>
Establece la ruta al ejecutable de myMPD.
-c </var/lib/mympd/config>
Establece la ruta al directorio de configuración de myMPD.
-s <0|1>
0 = myMPD se ejecuta con una cuenta de usuario normal de Linux 1 = myMPD se inicia con un usuario privado de systemd
CONFIGURACIÓN VALOR
Los valores válidos son las variables de entorno que respeta "mympd -c".

Referencia: https://jcorporation.github.io/myMPD/configuration/configuration-files
