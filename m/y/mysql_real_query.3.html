mysql_real_query(3) Conector/C de MariaDB mysql_real_query(3)

Nombre

mysql_real_query - ejecuta una sentencia (segura para binarios)

Sinopsis

#include <mysql.h>
int mysql_real_query(MYSQL * mysql,
                     const char * query,
                     unsigned long length);

Descripción

mysql_real_query() es la función segura para binarios para realizar una sentencia en el servidor de base de datos.

Parámetro

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
query - una cadena que contiene la sentencia a ser ejecutada.
•
length - longitud de la cadena.

Notas

•
Contrariamente a la función mysql_query(3), mysql_real_query es segura para binarios.
•
Para determinar si mysql_real_query devuelve un conjunto de resultados, utiliza la función mysql_num_fields(3).

Valor de retorno

Devuelve cero si tiene éxito, de lo contrario, un valor distinto de cero.
