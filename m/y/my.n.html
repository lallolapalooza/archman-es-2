my(n) Comandos TclOO my(n)

NOMBRE

my - invoca cualquier método del objeto actual

SINOPSIS

package require TclOO
my nombreMetodo ?arg ...?

DESCRIPCIÓN

El comando my se utiliza para permitir que los métodos de los objetos invoquen cualquier método del objeto (o su clase). En particular, el conjunto de valores válidos para nombreMetodo es el conjunto de todos los métodos soportados por un objeto y sus superclases, incluyendo aquellos que no están exportados. El objeto sobre el cual se invoca el método es siempre el que es el contexto actual del método (es decir, el objeto que devuelve self object) desde el cual se invoca el comando my.

Cada objeto tiene su propio comando my, contenido en su espacio de nombres de instancia.

EJEMPLOS

Este ejemplo muestra el uso básico de my para utilizar el método variables de la clase oo::object, que no es visible públicamente por defecto:

oo::class create c {
    method count {} {
        my variable counter
        puts [incr counter]
    }
}
c create o
o count              → imprime "1"
o count              → imprime "2"
o count              → imprime "3"
