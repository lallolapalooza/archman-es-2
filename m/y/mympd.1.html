NOMBRE

myMPD - cliente web autónomo y amigable para móviles de MPD

SINOPSIS

mympd [opciones]

DESCRIPCIÓN

myMPD es un cliente web de MPD autónomo y ligero. Está optimizado para un uso mínimo de recursos y solo requiere muy pocas dependencias. Por ello, myMPD es ideal para Raspberry Pis y dispositivos similares.

El backend está escrito en C y no tiene dependencias de bases de datos externas ni servidores web. La configuración se almacena en archivos de texto plano y todos los datos se extraen bajo demanda de MPD. La base de datos de MPD es la única fuente de verdad para myMPD.

El frontend es amigable para móviles, está escrito como una PWA y ofrece la misma funcionalidad en todos los dispositivos. Se comunica a través de AJAX y websockets utilizando el protocolo json-rpc 2.

myMPD también integra características extendidas como un modo de jukebox avanzado, temporizadores, disparadores y listas de reproducción inteligentes. Con el intérprete de lua integrado, las funciones de myMPD también se pueden programar.

OPCIONES

-c, --config
Crea la configuración y los certificados SSL y sale.
-d, --dump
Exporta la configuración predeterminada y sale.
-h, --help
Imprime todas las opciones válidas y sale.
-v, --version
Muestra la información de la versión.
-p, --pin
Establece un PIN para la configuración de myMPD.
-s, --syslog
Habilita el registro de syslog (facilidad: daemon).
-w, --workdir RUTA
Directorio de trabajo (predeterminado: /var/lib/mympd).
-a, --cachedir RUTA
Directorio de caché (predeterminado: /var/cache/mympd).
-p, --pin
Establece un PIN para la configuración de myMPD.
