mysql_kill(3) MariaDB Connector/C mysql_kill(3)

Nombre

mysql_kill - Mata una conexión

Sintaxis

#include <mysql.h>
int mysql_kill(MYSQL * mysql,
               unsigned long);

Descripción

Esta función se utiliza para solicitar al servidor que mate un hilo de MariaDB especificado por el parámetro processid. Este valor debe ser obtenido mediante [show-processlist()](SHOW PROCESSLIST]]. Si se intenta matar la propia conexión, se debe usar mysql_thread_id(3).

Parámetro

•
mysql - un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3). Devuelve 0 en caso de éxito, de lo contrario, no es cero.
•
long - id de proceso

Notas

•
Para detener un comando en ejecución sin matar la conexión, usa KILL QUERY.
•
La función mysql_kill() solo mata una conexión, no libera ninguna memoria; esto debe hacerse explícitamente llamando a mysql_close(3).

Valor de retorno

Devuelve cero en caso de éxito, distinto de cero en caso de error.
