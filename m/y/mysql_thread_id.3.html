Nombre

mysql_thread_id - Devuelve el ID del hilo de la conexión actual

Sinopsis

#include <mysql.h>
unsigned long mysql_thread_id(MYSQL * mysql);

Descripción

La función mysql_thread_id() devuelve el ID del hilo para la conexión actual.

Parámetro

•
mysql - un manejador mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3). ### Notas
•
La conexión actual puede ser terminada con mysql_kill(3).
•
Si la opción de reconexión está habilitada, el ID del hilo podría cambiar si el cliente se reconecta al servidor.

Valor de retorno

Devuelve el ID del hilo de la conexión actual.
