mysql_ssl_set(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_ssl_set(3) Conector/C de MariaDB mysql_ssl_set(3)

Nombre

mysql_ssl_set - Establece opciones TLS/SSL

Sintaxis

#include <mysql.h>
my_bool mysql_ssl_set(MYSQL *mysql,
                      const char *key,
                      const char *cert,
                      const char *ca,
                      const char *capath,
                      const char *cipher)

Descripción

Se utiliza para establecer una conexión TLS segura. Debe llamarse antes de intentar utilizar mysql_real_connect(3). El soporte TLS debe estar habilitado en la biblioteca cliente para que la función tenga algún efecto.

NULL se puede utilizar para un parámetro no utilizado. Siempre devuelve cero.

Para habilitar TLS sin especificar certificados, establezca todos los valores en NULL:

mysql_ssl_set(mysql, NULL, NULL, NULL, NULL, NULL)

Esto es lo mismo que mysql_optionsv(mysql, MYSQL_OPT_SSL_ENFORCE, &yes).

Parámetro

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3).
•
key - ruta al archivo de clave.
•
cert - ruta al archivo de certificado.
•
ca - ruta al archivo de autoridad de certificación.
•
capath - ruta al directorio que contiene los certificados de CA TLS de confianza en formato PEM.
•
cipher lista de conjuntos de cifrado permitidos (SSLv3, TLSv1.0 o TLSv1.2) para usar en la encriptación TLS.

Notas

•
mysql_real_connect(3) devolverá un error si se intenta conectar y TLS está mal configurado.
•
Aunque Connector/C soporta el protocolo TLSv1.3, todavía no es posible especificar conjuntos de cifrado TLSv1.3 a través del parámetro cipher.
