Nombre

mysql_stmt_bind_result - enlaza las columnas del resultado a variables

Sinopsis

#include <mysql.h>
my_bool mysql_stmt_bind_result(MYSQL_STMT * stmt,
                               MYSQL_BIND * bind);

Descripción

Enlaza las columnas del conjunto de resultados a variables. Devuelve cero si tiene éxito, distinto de cero si falla.

Parámetros

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
bind - un array de estructuras [MYSQL_BIND]]. El tamaño de este array debe ser igual al número de columnas en el conjunto de resultados.

Notas

•
Para determinar el número de columnas en el conjunto de resultados, use mysql_stmt_field_count(3).
•
Una columna puede ser enlazada o re-enlazada en cualquier momento, incluso después de que un conjunto de resultados haya sido recuperado parcialmente. El nuevo enlace surtirá efecto la próxima vez que se llame a mysql_stmt_fetch(3).
