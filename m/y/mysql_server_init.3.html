mysql_server_init(3) Conector/C de MariaDB mysql_server_init(3)

Nombre

mysql_server_init - Inicializa la biblioteca

Sinopsis

#include <mysql.h>
int mysql_library_init(int argc __attribute__((unused)),
                       char **argv __attribute__((unused)),
                       char **groups __attribute__((unused)))

Descripción

Se llama para inicializar la biblioteca antes de llamar a otras funciones.

Parámetros

Todos los parámetros no se utilizan, solo existen por motivos de compatibilidad.

Notas

•
Llame a mysql_server_end(3) para limpiar después de completar.
•
Si la biblioteca no fue inicializada explícitamente por mysql_server_init(), cualquier llamada a mysql_init(3) inicializará automáticamente la biblioteca.
•
mysql_library_init() es un alias de mysql_server_init()

Valor de retorno

Devuelve cero si tiene éxito, o un valor distinto de cero si ocurrió un error. ## Ver también * mysql_server_end(3)
