NOMBRE

mysql2dlf - convertir archivos de registro de mysql a formato dlf

SINOPSIS

mysql2dlf

DESCRIPCIÓN

mysql2dlf convierte un archivo de registro de consultas de MySQL a formato DLF. La información sobre MySQL se puede encontrar en http://www.mysql.org/. El archivo de registro de consultas se define mediante la opción --log[=archivo] de mysqld, o el ajuste log=archivo en el archivo de configuración de MySQL.

Dicho archivo de registro se ve, por ejemplo:

/usr/sbin/mysqld, Versión: 3.23.43-debug-log, iniciado con:
Puerto TCP: 3306  Socket Unix: /var/run/mysqld/mysqld.sock
Hora                 Id Comando    Argumento
011218 15:02:58       1 Conectar     root@localhost en
                      1 Consulta     SHOW VARIABLES LIKE 'pid_file'
                      1 Apagar
011226 21:35:59       6 Conectar     joe@localhost en
                      6 Iniciar DB     nmrshiftdb
                      6 Consulta     SHOW VARIABLES

o

    42401 Consulta     SELECT
    bannerID,
    banner,
    format,
    width,
    height,
    alt,
    url
FROM
    banners
WHERE
    act = 'true'  AND (keyw = 'fullsize' OR keyw = 'global')

El formato genérico de base de datos dlf se describe en database.xml.

EJEMPLOS

Para procesar un registro como el producido por MySQL:

$ mysql2dlf < mysql-log

mysql2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report mysql < /var/log/mysql-log

NOTAS

El analizador ha sido probado solo para archivos de registro de consultas de MySQL 3.23.46.

ERRORES

Este conversor almacena toda la información de los archivos de registro en una gran matriz anidada en memoria, antes de escribir. Por lo tanto, el consumo de memoria es lineal con el tamaño del registro.

VER TAMBIÉN

mysql(1), mysqld(1)
