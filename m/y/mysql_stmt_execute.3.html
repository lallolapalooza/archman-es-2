Nombre

mysql_stmt_execute - Ejecuta una sentencia preparada

Sinopsis

#include <mysql.h>
int mysql_stmt_execute(MYSQL_STMT * stmt);

Descripción

Ejecuta una sentencia preparada que fue preparada previamente por mysql_stmt_prepare(3). Al ejecutarse, cualquier marcador de parámetro existente se reemplazará automáticamente con los datos apropiados.

Parámetro

•
stmt - Un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si falla.

Notas

•
Si la sentencia es UPDATE, REPLACE, DELETE o INSERT, el número total de filas afectadas se puede determinar utilizando la función mysql_stmt_affected_rows(3). Del mismo modo, si la consulta produce un conjunto de resultados, se utiliza la función mysql_stmt_fetch(3).
