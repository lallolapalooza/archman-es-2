mysql_options4(3) Conector/C de MariaDB mysql_options4(3)

Nombre

mysql_options4 - Utilizado para establecer opciones de conexión adicionales y afectar el comportamiento de una conexión

Sintaxis

#include <mysql.h>
int mysql_options4(MYSQL * mysql,
                  enum mysql_option,
                  const void * arg1,
                  const void * arg2);

Descripción

Se utiliza para establecer opciones de conexión adicionales y afectar el comportamiento de una conexión. Esta función puede llamarse varias veces para establecer varias opciones. mysql_options() debe llamarse después de mysql_init(3).

Notas

Esta función está obsoleta; las nuevas implementaciones deberían usar la función de API mysql_optionsv(3) en su lugar.

Opciones

Se puede encontrar una descripción general de las opciones posibles en la descripción de la función de API mysql_optionsv(3).
