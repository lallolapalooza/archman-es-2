MARIADBD(8) Sistema de bases de datos MariaDB MARIADBD(8)

NOMBRE

mariadbd - el servidor MariaDB (mariadbd es ahora un enlace simbólico a mariadbd)

SINOPSIS

mariadbd [opciones]

DESCRIPCIÓN

mariadbd, también conocido como Servidor MariaDB, es el programa principal que realiza la mayor parte del trabajo en una instalación de MariaDB. El Servidor MariaDB gestiona el acceso al directorio de datos de MariaDB que contiene bases de datos y tablas. El directorio de datos es también la ubicación predeterminada para otra información, como archivos de registro y archivos de estado.

Cuando el servidor MariaDB se inicia, escucha conexiones de red de programas cliente y gestiona el acceso a las bases de datos en nombre de esos clientes.

El programa mariadbd tiene muchas opciones que se pueden especificar al inicio. Para obtener una lista completa de opciones, ejecute este comando:

shell> mariadbd --verbose --help

El Servidor MariaDB también tiene un conjunto de variables del sistema que afectan su funcionamiento mientras se ejecuta. Las variables del sistema se pueden establecer al inicio del servidor, y muchas de ellas se pueden cambiar en tiempo de ejecución para afectar la reconfiguración dinámica del servidor. El Servidor MariaDB también tiene un conjunto de variables de estado que proporcionan información sobre su funcionamiento. Puede monitorizar estas variables de estado para acceder a las características de rendimiento en tiempo de ejecución.

Para una descripción completa de las opciones de línea de comandos del Servidor MariaDB, las variables del sistema y las variables de estado, consulte la Base de Conocimientos de MariaDB.
