Nombre

mysql_row_seek - Posiciona el cursor de fila en una fila arbitraria

Sintaxis

#include <mysql.h>
MYSQL_ROW_OFFSET mysql_row_seek(MYSQL_RES * result,
                                MYSQL_ROW_OFFSET offset);

Descripción

Posiciona el cursor de fila en una fila arbitraria de un conjunto de resultados que se obtuvo mediante mysql_store_result(3).

Parámetro

•
result - un identificador de conjunto de resultados devuelto por mysql_store_result(3).
•
offset - desplazamiento de fila. Este valor se puede obtener mediante mysql_row_seek() o mysql_row_tell(3)

Notas

•
Esta función no funcionará si el conjunto de resultados se obtuvo mediante mysql_use_result(3).

Valor de retorno

Devuelve el desplazamiento de fila anterior.
