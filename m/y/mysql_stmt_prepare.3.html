mysql_stmt_prepare(3) Conector/C de MariaDB mysql_stmt_prepare(3)

Nombre

mysql_stmt_prepare - Prepara una cadena SQL

Sinopsis

#include <mysql.h>
int mysql_stmt_prepare(MYSQL_STMT * stmt,
                       const char * query,
                       unsigned long length);

Descripción

Prepara la consulta SQL.

Parámetro

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
query - sentencia SQL
•
length - longitud de la sentencia SQL

Valor de retorno

Cero si tiene éxito, distinto de cero si hay un error.

Notas

•
Los marcadores de parámetros deben estar enlazados a variables de aplicación usando mysql_stmt_bind_param(3).
•
El número máximo de parámetros es 65535 (0xFFFF).
•
Los marcadores solo son legales en ciertos lugares de las sentencias SQL. Por ejemplo, están permitidos en la lista VALUES() de una sentencia INSERT (para especificar los valores de las columnas para una fila), o en una comparación con una columna en una cláusula [select()](WHERE]] para especificar un valor de comparación. Sin embargo, no están permitidos en identificadores (como nombres de tabla o columna) en la lista de selección que nombra las columnas a ser devueltas por la sentencia SELECT, o para especificar ambos operandos de un operador binario como el signo igual. La última restricción es necesaria porque sería imposible determinar el tipo de parámetro. En general, los parámetros solo son legales en sentencias de Lenguaje de Manipulación de Datos (DML), y no en sentencias de Lenguaje de Definición de Datos (DDL).
