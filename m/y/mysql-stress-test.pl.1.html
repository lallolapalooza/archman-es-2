MARIADB-STRESS-TEST(1) Sistema de bases de datos MariaDB MARIADB-STRESS-TEST(1)

NOMBRE

mariadb-stress-test.pl - programa de prueba de estrés del servidor

SINOPSIS

mariadb-stress-test.pl [opciones]

DESCRIPCIÓN

El script Perl mariadb-stress-test.pl realiza pruebas de estrés del servidor MariaDB.

mariadb-stress-test.pl requiere una versión de Perl que se haya compilado con soporte para hilos.

Invoque mariadb-stress-test.pl de esta manera:

shell> mariadb-stress-test.pl [opciones]

mariadb-stress-test.pl admite las siguientes opciones:

•--help

Muestra un mensaje de ayuda y sale.

•--abort-on-error=N

Hace que el programa aborte si se encontró un error con una gravedad menor o igual a N. Establézcalo en 1 para abortar ante cualquier error.

•--check-tests-file

Comprueba periódicamente el archivo que enumera las pruebas a ejecutar. Si se ha modificado, vuelve a leer el archivo. Esto puede ser útil si actualiza la lista de pruebas a ejecutar durante una prueba de estrés.

•--cleanup

Forzar la limpieza del directorio de trabajo.

•--log-error-details

Registra los detalles del error en el archivo de registro de errores global.

•--loop-count=N

En el modo de prueba secuencial, el número de bucles a ejecutar antes de salir.

•--mariadb-test=ruta

El nombre de ruta del programa mariadb-test.

•--server-database=nombre_bd

La base de datos a utilizar para las pruebas. El valor predeterminado es test.

•--server-host=nombre_host

El nombre de host de la máquina local a utilizar para establecer una conexión TCP/IP con el servidor local. De forma predeterminada, la conexión se establece a localhost utilizando un archivo de socket Unix.

•--server-logs-dir=ruta

Esta opción es obligatoria. ruta es el directorio donde se almacenarán todos los registros de sesiones de cliente. Normalmente, este es el directorio compartido asociado con el servidor utilizado para las pruebas.

•--server-password=contraseña

La contraseña a utilizar al conectarse al servidor.

•--server-port=num_puerto

El número de puerto TCP/IP a utilizar para conectarse al servidor. El valor predeterminado es 3306.

•--server-socket=nombre_archivo

Para conexiones a localhost, el archivo de socket Unix a utilizar, o, en Windows, el nombre de la tubería con nombre a utilizar. El valor predeterminado es /tmp/mariadb.sock.

•--server-user=nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor. El valor predeterminado es root.

•--sleep-time=N

El retraso en segundos entre ejecuciones de pruebas.

•--stress-basedir=ruta

Esta opción es obligatoria. ruta es el directorio de trabajo para la ejecución de la prueba. Se utiliza como ubicación temporal para el seguimiento de resultados durante las pruebas.

•--stress-datadir=ruta

El directorio de archivos de datos a utilizar durante las pruebas. La ubicación predeterminada es el directorio de datos bajo la ubicación dada por la opción --stress-suite-basedir.

•--stress-init-file[=ruta]

nombre_archivo es la ubicación del archivo que contiene la lista de pruebas a ejecutar una vez para inicializar la base de datos para las pruebas. Si falta, el archivo predeterminado es stress_init.txt en el directorio del conjunto de pruebas.

•--stress-mode=modo

Esta opción indica el orden de las pruebas en modo de prueba de estrés. El valor de modo es random para seleccionar pruebas en orden aleatorio o seq para ejecutar pruebas en cada hilo en el orden especificado en el archivo de lista de pruebas. El modo predeterminado es random.

•--stress-suite-basedir=ruta

Esta opción es obligatoria. ruta es el directorio que tiene los subdirectorios t y r que contienen los archivos de casos de prueba y de resultados. Este directorio también es la ubicación predeterminada del archivo stress-test.txt que contiene la lista de pruebas. (Se puede especificar una ubicación diferente con la opción --stress-tests-file.)

•--stress-tests-file[=nombre_archivo]

Utilice esta opción para ejecutar las pruebas de estrés. nombre_archivo es la ubicación del archivo que contiene la lista de pruebas. Si se omite nombre_archivo, el archivo predeterminado es stress-test.txt en el directorio del conjunto de estrés. (Ver --stress-suite-basedir.)

•--suite=nombre_suite

Ejecuta el conjunto de pruebas con nombre. El nombre predeterminado es main (el conjunto de pruebas regular ubicado en el directorio mariadb-test).

•--test-count=N

El número de pruebas a ejecutar antes de salir.

•--test-duration=N

La duración de la prueba de estrés en segundos.

•--threads=N

El número de hilos. El valor predeterminado es 1.

•--verbose

Modo detallado. Imprime más información sobre lo que hace el programa.
