MYISAM_FTDUMP(1) Sistema de Bases de Datos MariaDB MYISAM_FTDUMP(1)

NOMBRE

myisam_ftdump - mostrar información de índices de texto completo

SINOPSIS

myisam_ftdump [opciones] nombre_tabla num_indice

DESCRIPCIÓN

myisam_ftdump muestra información sobre los índices FULLTEXT en tablas MyISAM. Lee directamente el archivo de índice MyISAM, por lo que debe ejecutarse en el host del servidor donde se encuentra la tabla. Antes de usar myisam_ftdump, asegúrate de ejecutar primero una sentencia FLUSH TABLES si el servidor está en ejecución.

myisam_ftdump escanea y vuelca todo el índice, lo cual no es particularmente rápido. Por otro lado, la distribución de palabras cambia con poca frecuencia, por lo que no es necesario ejecutarlo a menudo.

Invoca myisam_ftdump de esta manera:

shell> myisam_ftdump [opciones] nombre_tabla num_indice

El argumento nombre_tabla debe ser el nombre de una tabla MyISAM. También puedes especificar una tabla nombrando su archivo de índice (el archivo con el sufijo .MYI). Si no invocas myisam_ftdump en el directorio donde se encuentran los archivos de la tabla, el nombre del archivo de tabla o índice debe ir precedido por el nombre de la ruta al directorio de la base de datos de la tabla. Los números de índice comienzan con 0.

Ejemplo: Supongamos que la base de datos test contiene una tabla llamada mytexttablel con la siguiente definición:

CREATE TABLE mytexttable
(
  id   INT NOT NULL,
  txt  TEXT NOT NULL,
  PRIMARY KEY (id),
  FULLTEXT (txt)
);

El índice en id es el índice 0 y el índice FULLTEXT en txt es el índice 1. Si tu directorio de trabajo es el directorio de la base de datos test, invoca myisam_ftdump de la siguiente manera:

shell> myisam_ftdump mytexttable 1

Si el nombre de la ruta al directorio de la base de datos test es /usr/local/mysql/data/test, también puedes especificar el argumento nombre_tabla usando esa ruta. Esto es útil si no invocas myisam_ftdump en el directorio de la base de datos:

shell> myisam_ftdump /usr/local/mysql/data/test/mytexttable 1

Puedes usar myisam_ftdump para generar una lista de entradas de índice en orden de frecuencia de ocurrencia de esta manera:

shell> myisam_ftdump -c mytexttable 1 | sort -r

myisam_ftdump soporta las siguientes opciones:

•--help, -h -?

Muestra un mensaje de ayuda y sale.

•--count, -c

Calcula estadísticas por palabra (recuentos y pesos globales).

•--dump, -d

Vuelca el índice, incluyendo offsets de datos y pesos de palabras.

•--length, -l

Reporta la distribución de longitud.

•--stats, -s

Reporta estadísticas globales del índice. Esta es la operación por defecto si no se especifica ninguna otra operación.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa.
