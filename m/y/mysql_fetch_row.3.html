Nombre

mysql_fetch_row - recupera una fila de datos del conjunto de resultados

Sintaxis

#include <mysql.h>
MYSQL_ROW mysql_fetch_row(MYSQL_RES * result);

Descripción

Recupera una fila de datos del conjunto de resultados y la devuelve como un array de punteros a caracteres (MYSQL_ROW), donde cada columna se almacena en un índice a partir de 0 (cero). Cada llamada posterior a esta función devolverá la siguiente fila dentro del conjunto de resultados, o NULL si no hay más filas.

Parámetro

•
result - un identificador de conjunto de resultados devuelto por mysql_store_result(3) o mysql_use_result(3).

Notas

•
Si una columna contiene un valor NULL, el puntero a carácter correspondiente se establecerá en NULL.
•
La memoria asociada a MYSQL_ROW se liberará al llamar a la función mysql_free_result(3).

Valor de retorno

Una estructura MYSQL_ROW (array de punteros a caracteres) que representa los datos de la fila actual. Si no hay más filas disponibles, se devolverá NULL.
