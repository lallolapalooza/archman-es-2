NOMBRE

myisampack - generar tablas MyISAM comprimidas y de solo lectura

SINOPSIS

myisampack [opciones] nombre_archivo ...

DESCRIPCIÓN

La utilidad myisampack comprime tablas MyISAM. myisampack funciona comprimiendo cada columna de la tabla por separado. Generalmente, myisampack empaqueta el archivo de datos entre un 40% y un 70%.

Cuando la tabla se usa más tarde, el servidor lee en memoria la información necesaria para descomprimir las columnas. Esto resulta en un rendimiento mucho mejor al acceder a filas individuales, ya que solo necesitas descomprimir exactamente una fila.

MariaDB utiliza mmap() siempre que es posible para realizar mapeo de memoria en tablas comprimidas. Si mmap() no funciona, MariaDB recurre a operaciones de archivo normales de lectura/escritura.

Tenga en cuenta lo siguiente:

•Si el servidor mariadbd se inició con el bloqueo externo deshabilitado, no es recomendable invocar myisampack si la tabla podría ser actualizada por el servidor durante el proceso de empaquetado. Es más seguro comprimir las tablas con el servidor detenido.
•Después de empaquetar una tabla, se vuelve de solo lectura. Esto generalmente está previsto (por ejemplo, al acceder a tablas empaquetadas en un CD).

Invoque myisampack así:

shell> myisampack [opciones] nombre_archivo ...

Cada argumento de nombre de archivo debe ser el nombre de un archivo de índice (.MYI). Si no se encuentra en el directorio de la base de datos, debe especificar la ruta del archivo. Es permisible omitir la extensión .MYI.

Después de comprimir una tabla con myisampack, debe usar myisamchk -rq para reconstruir sus índices. myisamchk(1).

myisampack admite las siguientes opciones. También lee archivos de opciones y admite las opciones para procesarlos descritas en la Sección 4.2.3.3.1, "Opciones de línea de comandos que afectan el manejo de archivos de opciones".

•--help, -?

Muestra un mensaje de ayuda y sale.

•--backup, -b

Crea una copia de seguridad del archivo de datos de cada tabla con el nombre nombre_tabla.OLD.

•--character-sets-dir=ruta

El directorio donde están instalados los conjuntos de caracteres. Ver Sección 9.5, "Configuración del conjunto de caracteres".

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o'.

•--force, -f

Produce una tabla empaquetada incluso si se vuelve más grande que la original o si existe el archivo intermedio de una invocación anterior de myisampack. (myisampack crea un archivo intermedio llamado nombre_tabla.TMD en el directorio de la base de datos mientras comprime la tabla. Si detiene myisampack, el archivo .TMD podría no ser eliminado.) Normalmente, myisampack sale con un error si encuentra que nombre_tabla.TMD existe. Con --force, myisampack empaqueta la tabla de todos modos.

•--join=nombre_tabla_grande, -j nombre_tabla_grande

Une todas las tablas nombradas en la línea de comandos en una única tabla empaquetada nombre_tabla_grande. Todas las tablas que se van a combinar *deben* tener una estructura idéntica (mismos nombres y tipos de columna, mismos índices, etc.).

nombre_tabla_grande no debe existir antes de la operación de unión. Todas las tablas de origen nombradas en la línea de comandos para ser fusionadas en nombre_tabla_grande deben existir. Las tablas de origen se leen para la operación de unión pero no se modifican. La operación de unión no crea un archivo .frm para nombre_tabla_grande, por lo que después de que finaliza la operación de unión, copie el archivo .frm de una de las tablas de origen y nómbrelo nombre_tabla_grande.frm.

•--silent, -s

Modo silencioso. Escribe salida solo cuando ocurren errores.

•--test, -t

No empaqueta realmente la tabla, solo prueba a empaquetarla.

•--tmpdir=ruta, -T ruta

Usa el directorio nombrado como ubicación donde myisampack crea archivos temporales.

•--verbose, -v

Modo detallado. Escribe información sobre el progreso de la operación de empaquetado y su resultado.

•--version, -V

Muestra información de la versión y sale.

•--wait, -w

Espera y reintenta si la tabla está en uso. Si el servidor mariadbd se inició con el bloqueo externo deshabilitado, no es una buena idea invocar myisampack si la tabla podría ser actualizada por el servidor durante el proceso de empaquetado.

NAME

myisampack

compress MyISAM table files

SYNOPSIS

myisampack [options] filename...

DESCRIPTION

myisampack compresses MyISAM table files. It uses Huffman compression on columns that have a low number of distinct values and also compresses string columns that consist mainly of spaces or zeros.

A table can be compressed in two ways:

1. You can pack a table by running myisampack directly on the .MYD and .MYI files.

2. You can pack a table using the --pack option to myisamchk.

After you have packed a table, you should run myisamchk to check the table's integrity and update its statistics.

Here is a sample output from myisampack:

# /usr/sbin/myisampack /var/lib/mysql/test/t1
# /usr/sbin/myisamchk -dvv /var/lib/mysql/test/t1
- check key1;
- repair key1;
- Analyzing table structure...
- Compressing data...
- Re-writing...
- Compressing index...
- Re-writing...
Table was analyzed, based on the information I have:
Name: test/t1        Ip: possiblyinapplicable
79
9



•normal

El número de columnas para las que no se utiliza ningún empaquetado
    adicional.




•empty-space

El número de columnas que contienen valores que son solo espacios.
    Estos ocupan un bit.




•empty-zero

El número de columnas que contienen valores que son solo ceros
    binarios. Estos ocupan un bit.




•empty-fill

El número de columnas de enteros que no ocupan todo el rango de
    bytes de su tipo. Estos se cambian a un tipo más pequeño. Por ejemplo, una
    columna BIGINT (ocho bytes) se puede almacenar como una columna TINYINT
    (un byte) si todos sus valores están en el rango de -128 a 127.




•pre-space

El número de columnas decimales que se almacenan con espacios
    iniciales. En este caso, cada valor contiene un recuento del número de
    espacios iniciales.




•end-space

El número de columnas que tienen muchos espacios finales. En este
    caso, cada valor contiene un recuento del número de espacios finales.




•table-lookup

La columna tenía solo un pequeño número de valores diferentes,
    que se convirtieron a un ENUM antes de la compresión de Huffman.




•zero

El número de columnas para las que todos los valores son cero.




•Original trees

El número inicial de árboles de Huffman.




•After join

El número de árboles de Huffman distintos restantes después de
    unir árboles para ahorrar espacio en la cabecera.




Después de que una tabla ha sido comprimida, las líneas de Campo
    mostradas por myisamchk -dvv incluyen información adicional sobre
    cada columna:


•Type

El tipo de datos. El valor puede contener cualquiera de los
    siguientes descriptores:


•constant

Todas las filas tienen el mismo valor.




•no endspace

No almacenar endspace.




•no endspace, not_always

No almacenar endspace y no realizar compresión endspace para
    todos los valores.




•no endspace, no empty

No almacenar endspace. No almacenar valores vacíos.




•table-lookup

La columna se convirtió a un ENUM.




•zerofill(N)

Los N bytes más significativos del valor son siempre 0 y
    no se almacenan.




•no zeros

No almacenar ceros.




•always zero

Los valores cero se almacenan usando un bit.






•Huff tree

El número del árbol de Huffman asociado con la columna.




•Bits

El número de bits utilizados en el árbol de Huffman.




Después de ejecutar myisampack, debe ejecutar
    myisamchk para recrear cualquier índice. En este momento, también puede
    ordenar los bloques de índice y crear estadísticas necesarias para que el
    optimizador de MariaDB funcione de manera más eficiente:




shell> myisamchk -rq --sort-index --analyze tbl_name.MYI




Después de haber instalado la tabla empaquetada en el directorio
    de bases de datos de MariaDB, debe ejecutar mariadb-admin flush-tables
    para forzar que mariadbd comience a usar la nueva tabla.


Para desempaquetar una tabla empaquetada, use la opción
    --unpack de myisamchk.
