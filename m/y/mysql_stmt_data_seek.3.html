mysql_stmt_data_seek(3) MariaDB Connector/C mysql_stmt_data_seek(3)

Name

mysql_stmt_data_seek - Busca una fila arbitraria en el conjunto de resultados de la sentencia

Synopsis

#include <mysql.h>
void mysql_stmt_data_seek(MYSQL_STMT * stmt,
                          my_ulonglong offset);

Description

Busca una fila arbitraria en el conjunto de resultados de la sentencia obtenido por una llamada previa a mysql_stmt_store_result(3).

Parameter

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
offset - el desplazamiento de la fila. Este valor debe estar entre 0 y el número de filas - 1.

Return value

Devuelve void

Notes

•
El número de filas se puede obtener con la función mysql_stmt_num_rows(3).
