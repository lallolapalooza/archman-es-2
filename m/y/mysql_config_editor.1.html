MYSQL_CONFIG_EDITOR(1) Sistema de bases de datos MySQL MYSQL_CONFIG_EDITOR(1)

NOMBRE

mysql_config_editor - configurar información de autenticación para conectarse al servidor MySQL

SINOPSIS

mysql_config_editor opciones comando

DESCRIPCIÓN

La utilidad mysql_config_editor le permite almacenar credenciales de autenticación en un archivo de rutas de inicio de sesión ofuscado llamado .mylogin.cnf. La ubicación del archivo es el directorio %APPDATA%\MySQL en Windows y el directorio principal del usuario actual en sistemas que no son de Windows. El archivo puede ser leído posteriormente por programas cliente de MySQL para obtener credenciales de autenticación para conectarse al servidor MySQL.

El formato no ofuscado del archivo de rutas de inicio de sesión .mylogin.cnf consta de grupos de opciones, similar a otros archivos de opciones. Cada grupo de opciones en .mylogin.cnf se denomina "ruta de inicio de sesión", que es un grupo que permite solo ciertas opciones: host, user, password, port y socket. Piense en un grupo de opciones de ruta de inicio de sesión como un conjunto de opciones que especifican a qué servidor MySQL conectarse y con qué cuenta autenticarse. Aquí hay un ejemplo no ofuscado:

[client]
user = miusuario por defecto
password = micontraseña por defecto
host = 127.0.0.1
[miruta]
user = otrousuario
password = otracontraseña
host = localhost

Cuando invoca un programa cliente para conectarse al servidor, el cliente utiliza .mylogin.cnf junto con otros archivos de opciones. Su precedencia es mayor que la de otros archivos de opciones, pero menor que las opciones especificadas explícitamente en la línea de comandos del cliente. Para obtener información sobre el orden en que se utilizan los archivos de opciones, consulte la Sección 6.2.2.2, "Uso de archivos de opciones".

Para especificar un nombre de archivo de rutas de inicio de sesión alternativo, establezca la variable de entorno MYSQL_TEST_LOGIN_FILE. Esta variable es reconocida por mysql_config_editor, por los clientes MySQL estándar (mysql, mysqladmin y otros), y por la utilidad de prueba mysql-test-run.pl.

Los programas utilizan grupos en el archivo de rutas de inicio de sesión de la siguiente manera:

•mysql_config_editor opera en la ruta de inicio de sesión del cliente por defecto si no especifica la opción --login-path=nombre para indicar explícitamente qué ruta de inicio de sesión usar.
•Sin la opción --login-path, los programas cliente leen los mismos grupos de opciones del archivo de rutas de inicio de sesión que leen de otros archivos de opciones. Considere este comando: 
mysql

Por defecto, el cliente mysql lee los grupos [client] y [mysql] de otros archivos de opciones, por lo que también los lee del archivo de rutas de inicio de sesión.

•Con la opción --login-path, los programas cliente leen adicionalmente la ruta de inicio de sesión nombrada del archivo de rutas de inicio de sesión. Los grupos de opciones leídos de otros archivos de opciones siguen siendo los mismos. Considere este comando: 
mysql --login-path=miruta

El cliente mysql lee [client] y [mysql] de otros archivos de opciones, y [client], [mysql] y [miruta] del archivo de rutas de inicio de sesión.

•Los programas cliente leen el archivo de rutas de inicio de sesión incluso cuando se utiliza la opción --no-defaults, a menos que se establezca --no-login-paths. Esto permite que las contraseñas se especifiquen de una manera más segura que en la línea de comandos, incluso si --no-defaults está presente.

mysql_config_editor ofusca el archivo .mylogin.cnf para que no pueda ser leído como texto plano, y sus contenidos, cuando son no ofuscados por programas cliente, se utilizan solo en memoria. De esta manera, las contraseñas se pueden almacenar en un archivo en formato no de texto plano y usarse posteriormente sin necesidad de exponerse nunca en la línea de comandos o en una variable de entorno. mysql_config_editor proporciona un comando de impresión para mostrar el contenido del archivo de rutas de inicio de sesión, pero incluso en este caso, los valores de las contraseñas se enmascaran para que nunca aparezcan de una manera que otros usuarios puedan ver.

La ofuscación utilizada por mysql_config_editor evita que las contraseñas aparezcan en .mylogin.cnf como texto plano y proporciona una medida de seguridad al evitar la exposición inadvertida de contraseñas. Por ejemplo, si muestra un archivo de opciones my.cnf normal no ofuscado en la pantalla, cualquier contraseña que contenga será visible para que cualquiera la vea. Con .mylogin.cnf, eso no es cierto, pero la ofuscación utilizada no es probable que disuada a un atacante decidido y no debe considerarla irrompible. Un usuario que pueda obtener privilegios de administración del sistema en su máquina para acceder a sus archivos podría ofuscar el archivo .mylogin.cnf con algo de esfuerzo.

El archivo de rutas de inicio de sesión debe ser legible y escribible por el usuario actual, e inaccesible para otros usuarios. De lo contrario, mysql_config_editor lo ignora y los programas cliente tampoco lo utilizan.

Invoque mysql_config_editor de esta manera:

mysql_config_editor [opciones_programa] comando [opciones_comando]

Si el archivo de rutas de inicio de sesión no existe, mysql_config_editor lo crea.

Los argumentos del comando se proporcionan de la siguiente manera:

•opciones_programa consiste en opciones generales de mysql_config_editor.
•comando indica qué acción realizar en el archivo de rutas de inicio de sesión .mylogin.cnf. Por ejemplo, set escribe una ruta de inicio de sesión en el archivo, remove elimina una ruta de inicio de sesión y print muestra el contenido de la ruta de inicio de sesión.
•opciones_comando indica cualquier opción adicional específica del comando, como el nombre de la ruta de inicio de sesión y los valores a utilizar en la ruta de inicio de sesión.

La posición del nombre del comando dentro del conjunto de argumentos del programa es significativa. Por ejemplo, estas líneas de comando tienen los mismos argumentos, pero producen resultados diferentes:

mysql_config_editor --help set
mysql_config_editor set --help

La primera línea de comando muestra un mensaje de ayuda general de mysql_config_editor e ignora el comando set. La segunda línea de comando muestra un mensaje de ayuda específico para el comando set.

Supongamos que desea establecer una ruta de inicio de sesión de cliente que defina sus parámetros de conexión por defecto, y una ruta de inicio de sesión adicional llamada remote para conectarse al servidor MySQL en el host remote.example.com. Desea iniciar sesión de la siguiente manera:

•Por defecto, al servidor local con un nombre de usuario y contraseña de localuser y localpass
•Al servidor remoto con un nombre de usuario y contraseña de remoteuser y remotepass

Para configurar las rutas de inicio de sesión en el archivo .mylogin.cnf, use los siguientes comandos set. Ingrese cada comando en una sola línea e ingrese las contraseñas apropiadas cuando se le solicite:

$> mysql_config_editor set --login-path=client
         --host=localhost --user=localuser --password
Ingrese contraseña: ingrese la contraseña "localpass" aquí
$> mysql_config_editor set --login-path=remote
         --host=remote.example.com --user=remoteuser --password
Ingrese contraseña: ingrese la contraseña "remotepass" aquí

mysql_config_editor utiliza la ruta de inicio de sesión del cliente por defecto, por lo que la opción --login-path=client puede omitirse en el primer comando sin cambiar su efecto.

Para ver lo que mysql_config_editor escribe en el archivo .mylogin.cnf, use el comando print:

$> mysql_config_editor print --all
[client]
user = localuser
password = *****
host = localhost
[remote]
user = remoteuser
password = *****
host = remote.example.com

El comando print muestra cada ruta de inicio de sesión como un conjunto de líneas que comienzan con un encabezado de grupo que indica el nombre de la ruta de inicio de sesión entre corchetes, seguido de los valores de las opciones para la ruta de inicio de sesión. Los valores de las contraseñas se enmascaran y no aparecen como texto plano.

Si no especifica --all para mostrar todas las rutas de inicio de sesión o --login-path=nombre para mostrar una ruta de inicio de sesión con nombre, el comando print muestra la ruta de inicio de sesión del cliente por defecto, si la hay.

Como se muestra en el ejemplo anterior, el archivo de rutas de inicio de sesión puede contener múltiples rutas de inicio de sesión. De esta manera, mysql_config_editor facilita la configuración de múltiples "personalidades" para conectarse a diferentes servidores MySQL, o para conectarse a un servidor dado utilizando diferentes cuentas. Cualquiera de estas puede ser seleccionada por nombre posteriormente utilizando la opción --login-path cuando se invoca un programa cliente. Por ejemplo, para conectarse al servidor remoto, use este comando:

mysql --login-path=remote

Aquí, mysql lee los grupos de opciones [client] y [mysql] de otros archivos de opciones, y los grupos [client], [mysql] y [remote] del archivo de rutas de inicio de sesión.

Para conectarse al servidor local, use este comando:

mysql --login-path=client

Dado que mysql lee las rutas de inicio de sesión client y mysql por defecto, la opción --login-path no agrega nada en este caso. Ese comando es equivalente a este:

mysql

Las opciones leídas del archivo de rutas de inicio de sesión tienen precedencia sobre las opciones leídas de otros archivos de opciones. Las opciones leídas de los grupos de rutas de inicio de sesión que aparecen más adelante en el archivo de rutas de inicio de sesión tienen precedencia sobre las opciones leídas de grupos que aparecen antes en el archivo.

mysql_config_editor agrega rutas de inicio de sesión al archivo de rutas de inicio de sesión en el orden en que las crea, por lo que debe crear rutas de inicio de sesión más generales primero y rutas más específicas después. Si necesita mover una ruta de inicio de sesión dentro del archivo, puede eliminarla y luego recrearla para agregarla al final. Por ejemplo, una ruta de inicio de sesión de cliente es más general porque es leída por todos los programas cliente, mientras que una ruta de inicio de sesión de mysqldump solo es leída por mysqldump. Las opciones especificadas posteriormente anulan las opciones especificadas anteriormente, por lo que poner las rutas de inicio de sesión en el orden client, mysqldump permite que las opciones específicas de mysqldump anulen las opciones de cliente.

Cuando utiliza el comando set con mysql_config_editor para crear una ruta de inicio de sesión, no necesita especificar todos los valores de opción posibles (nombre de host, nombre de usuario, contraseña, puerto, socket). Solo los valores proporcionados se escriben en la ruta. Cualquier valor faltante requerido posteriormente se puede especificar cuando invoque una ruta de cliente para conectarse al servidor MySQL, ya sea en otros archivos de opciones o en la línea de comandos. Cualquier opción especificada en la línea de comandos anula las especificadas en el archivo de rutas de inicio de sesión u otros archivos de opciones. Por ejemplo, si las credenciales en la ruta de inicio de sesión remota también se aplican al host remote2.example.com, conéctese al servidor en ese host de la siguiente manera:

mysql --login-path=remote --host=remote2.example.com

Opciones Generales de mysql_config_editor

mysql_config_editor admite las siguientes opciones generales, que pueden usarse antes de cualquier comando nombrado en la línea de comandos. Para obtener descripciones de las opciones específicas del comando, consulte Comandos y Opciones Específicas de Comando de mysql_config_editor.

•--help, -?
Formato de Línea de Comandos --help

Muestra un mensaje de ayuda general y sale.

Para ver un mensaje de ayuda específico del comando, invoque mysql_config_editor de la siguiente manera, donde comando es un comando distinto de help:

mysql_config_editor comando --help
•--debug[=debug_options], -# debug_options
Formato de Línea de Comandos --debug[=debug_options]
Tipo String
Valor Predeterminado d:t:o

Escribe un registro de depuración. Una cadena típica de debug_options es d:t:o,nombre_archivo. El valor predeterminado es d:t:o,/tmp/mysql_config_editor.trace.

Esta opción solo está disponible si MySQL se compiló usando WITH_DEBUG. Los binarios de la versión de MySQL proporcionados por Oracle *no* se compilan usando esta opción.

•--verbose, -v
Formato de Línea de Comandos --verbose

Modo detallado. Imprime más información sobre lo que hace el programa. Esta opción puede ser útil para diagnosticar problemas si una operación no tiene el efecto esperado.

•--version, -V
Formato de Línea de Comandos --version

Muestra información de la versión y sale.

Comandos y Opciones Específicas de Comando de mysql_config_editor

Esta sección describe los comandos permitidos de mysql_config_editor y, para cada uno, las opciones específicas del comando permitidas después del nombre del comando en la línea de comandos.

Además, mysql_config_editor admite opciones generales que se pueden usar antes de cualquier comando. Para obtener descripciones de estas opciones, consulte Opciones Generales de mysql_config_editor.

mysql_config_editor admite estos comandos:

•help

Muestra un mensaje de ayuda general y sale. Este comando no toma opciones posteriores.

Para ver un mensaje de ayuda específico del comando, invoque mysql_config_editor de la siguiente manera, donde comando es un comando distinto de help:

mysql_config_editor comando --help
•print [opciones]

Imprime el contenido del archivo de rutas de inicio de sesión en forma no ofuscada, con la excepción de que las contraseñas se muestran como *****.

El nombre de ruta de inicio de sesión predeterminado es client si no se nombra ninguna ruta de inicio de sesión. Si se proporcionan tanto --all como --login-path, --all tiene precedencia.

El comando print permite estas opciones después del nombre del comando:

•--help, -?

Muestra un mensaje de ayuda para el comando print y sale.

Para ver un mensaje de ayuda general, use mysql_config_editor --help.

•--all

Imprime el contenido de todas las rutas de inicio de sesión en el archivo de rutas de inicio de sesión.

•--login-path=nombre, -G nombre

Imprime el contenido de la ruta de inicio de sesión con nombre.

•remove [opciones]

Elimina una ruta de inicio de sesión del archivo de rutas de inicio de sesión, o modifica una ruta de inicio de sesión eliminando opciones de ella.

Este comando elimina de la ruta de inicio de sesión solo aquellas opciones que se especifican con las opciones --host, --password, --port, --socket y --user. Si no se proporciona ninguna de esas opciones, remove elimina toda la ruta de inicio de sesión. Por ejemplo, este comando elimina solo la opción user de la ruta de inicio de sesión mypath en lugar de toda la ruta de inicio de sesión mypath:

mysql_config_editor remove --login-path=mypath --user

Este comando elimina toda la ruta de inicio de sesión mypath:

mysql_config_editor remove --login-path=mypath

El comando remove permite estas opciones después del nombre del comando:

•--help, -?

Muestra un mensaje de ayuda para el comando remove y sale.

Para ver un mensaje de ayuda general, use mysql_config_editor --help.

•--host, -h

Elimina el nombre de host de la ruta de inicio de sesión.

•--login-path=nombre, -G nombre

La ruta de inicio de sesión a eliminar o modificar. El nombre de ruta de inicio de sesión predeterminado es client si no se proporciona esta opción.

•--password, -p

Elimina la contraseña de la ruta de inicio de sesión.

•--port, -P

Elimina el número de puerto TCP/IP de la ruta de inicio de sesión.

•--socket, -S

Elimina el nombre del archivo de socket Unix de la ruta de inicio de sesión.

•--user, -u

Elimina el nombre de usuario de la ruta de inicio de sesión.

•--warn, -w

Advierte y solicita al usuario confirmación si el comando intenta eliminar la ruta de inicio de sesión predeterminada (client) y no se especificó --login-path=client. Esta opción está habilitada por defecto; use --skip-warn para deshabilitarla.

•reset [opciones]

Vacía el contenido del archivo de rutas de inicio de sesión.

El comando reset permite estas opciones después del nombre del comando:

•--help, -?

Muestra un mensaje de ayuda para el comando reset y sale.

Para ver un mensaje de ayuda general, use mysql_config_editor --help.

•set [opciones]

Escribe una ruta de inicio de sesión en el archivo de rutas de inicio de sesión.

Este comando escribe en la ruta de inicio de sesión solo aquellas opciones que se especifican con las opciones --host, --password, --port, --socket y --user. Si no se proporciona ninguna de esas opciones, mysql_config_editor escribe la ruta de inicio de sesión como un grupo vacío.

El comando set permite estas opciones después del nombre del comando:

•--help, -?

Muestra un mensaje de ayuda para el comando set y sale.

Para ver un mensaje de ayuda general, use mysql_config_editor --help.

•--host=host_name, -h host_name

El nombre de host a escribir en la ruta de inicio de sesión.

•--login-path=nombre, -G nombre

La ruta de inicio de sesión a crear. El nombre de ruta de inicio de sesión predeterminado es client si no se proporciona esta opción.

•--password, -p

Solicita una contraseña para escribir en la ruta de inicio de sesión. Después de que mysql_config_editor muestre el aviso, escriba la contraseña y presione Enter. Para evitar que otros usuarios vean la contraseña, mysql_config_editor no la muestra.

Para especificar una contraseña vacía, presione Enter en el aviso de contraseña. La ruta de inicio de sesión resultante escrita en el archivo de rutas de inicio de sesión incluye una línea como esta:

password =
•--port=port_num, -P port_num

El número de puerto TCP/IP a escribir en la ruta de inicio de sesión.

•--socket=file_name, -S file_name

El nombre del archivo de socket Unix a escribir en la ruta de inicio de sesión.

•--user=user_name, -u user_name

El nombre de usuario a escribir en la ruta de inicio de sesión.

•--warn, -w

Advierte y solicita al usuario confirmación si el comando intenta sobrescribir una ruta de inicio de sesión existente. Esta opción está habilitada por defecto; use --skip-warn para deshabilitarla.
