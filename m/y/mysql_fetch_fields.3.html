Nombre

mysql_fetch_fields - devuelve un array de campos

Sinopsis

#include <mysql.h>
MYSQL_FIELD * mysql_fetch_fields(MYSQL_RES * res);

Descripción

Esta función cumple un propósito idéntico a la función mysql_fetch_field(3) con la única diferencia de que, en lugar de devolver un campo a la vez por cada campo, los campos se devuelven como un array. Cada campo contiene la definición de una columna del conjunto de resultados.

Parámetros

•
res - un identificador de conjunto de resultados devuelto por mysql_store_result(3) o mysql_use_result(3).

Notas

El número total de campos se puede obtener mediante mysql_field_count(3).

Valor de retorno

un array de tipo MYSQL_FIELD.
