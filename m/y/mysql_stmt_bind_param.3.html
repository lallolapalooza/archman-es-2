Nombre

mysql_stmt_bind_param - Vincula un parámetro a una sentencia preparada

Sinopsis

#include <mysql.h>
my_bool mysql_stmt_bind_param(MYSQL_STMT * stmt,
                              MYSQL_BIND * bind);

Descripción

Vincula variables para los marcadores de parámetros en la sentencia preparada que se pasó a mysql_stmt_prepare(3). Devuelve cero si la operación es exitosa, distinto de cero si falla.

Parámetros

•
stmt - un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
bind - un array de estructuras MYSQL_BIND. El tamaño de este array debe ser igual al número de parámetros.

Notas

•
El número de parámetros se puede obtener con mysql_stmt_param_count(3).
•
Si el número de parámetros es desconocido, por ejemplo al usar mariadb_stmt_execute_direct(3), el número de parámetros debe ser especificado con la función mysql_stmt_attr_set(3).
