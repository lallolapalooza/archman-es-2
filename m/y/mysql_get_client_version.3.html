mysql_get_client_version(3) MariaDB Connector/C mysql_get_client_version(3)

Nombre

mysql_get_client_version - devuelve el número de versión del cliente

Sinopsis

unsigned long mysql_get_client_version(void);

Descripción

Devuelve un número que representa la versión de la biblioteca del cliente. El valor tiene el formato XXYYZZ: versión mayor * 10000 + versión menor * 100 + versión de parche. ### Notas * Para obtener una cadena que contenga la versión de la biblioteca del cliente, utilice la función mysql_get_client_info(3). * Nota: Desde MariaDB Server 10.2.6 y MariaDB Connector/C 3.0.1, la biblioteca del cliente se incluye con el paquete del servidor y devuelve la versión del paquete del servidor. Para obtener la versión del cliente del conector, utilice la constante MARIADB_PACKAGE_VERSION_ID

Valor de retorno

Un entero largo que representa la versión del cliente
