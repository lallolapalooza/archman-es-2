mysql_send_query(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mysql_send_query(3) MariaDB Connector/C mysql_send_query(3)

Nombre

mysql_send_query - envía una sentencia SQL sin esperar la respuesta del servidor

Sinopsis

#include <mysql.h>
int mysql_send_query(MYSQL * mysql,
                     const char *query,
                     unsigned long length);

Descripción

Envía una sentencia al servidor, sin esperar el paquete OK del servidor y/o el conjunto de resultados.

Parámetros

•
mysql - un manejador de mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).
•
query - sentencia SQL
•
length - longitud de la sentencia SQL

Notas

•
El paquete OK y el conjunto de resultados deben ser recuperados por la función mysql_read_query_result(3)
•
mysql_send_query() se puede utilizar para una operación semi asíncrona. Si bien la función en sí misma es bloqueante, una aplicación dirigida por eventos puede realizar otras tareas hasta que el conjunto de resultados esté disponible.

Ejemplo

Para un ejemplo de cómo usar ’mysql_send_query()` en un modelo dirigido por eventos, consulte el artículo de Jan Kneschke “Consultas MySQL asíncronas con la API C”.
