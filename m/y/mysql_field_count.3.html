Nombre

mysql_field_count - devuelve el número de columnas para la sentencia más reciente

Sintaxis

#include <mysql.h>
unsigned int mysql_field_count(MYSQL * mysql);

Descripción

Devuelve el número de columnas para la sentencia más reciente en la conexión representada por el parámetro link como un entero sin signo. Esta función puede ser útil al usar la función mysql_store_result(3) para determinar si la consulta debería haber producido un conjunto de resultados no vacío o no, sin conocer la naturaleza de la consulta.

Parámetros

•
mysql es un identificador de conexión, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).

Notas

La función mysql_field_count() debe ser utilizada para determinar si hay un conjunto de resultados disponible.

Valor de retorno:

El número de columnas para la sentencia más reciente. El valor es cero, si la sentencia no produjo un conjunto de resultados.
