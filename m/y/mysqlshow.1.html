MARIADB-SHOW(1) Sistema de bases de datos MariaDB MARIADB-SHOW(1)

NOMBRE

mariadb-show - mostrar información de bases de datos, tablas y columnas (mariadb-show es ahora un enlace simbólico a mariadb-show)

SINOPSIS

mariadb-show [opciones] [nombre_db [nombre_tabla [nombre_columna]]]

DESCRIPCIÓN

El cliente mariadb-show se puede utilizar para ver rápidamente qué bases de datos existen, sus tablas o las columnas o índices de una tabla.

mariadb-show proporciona una interfaz de línea de comandos para varias sentencias SQL SHOW. La misma información se puede obtener utilizando esas sentencias directamente. Por ejemplo, puedes ejecutarlas desde el programa cliente mariadb.

Invoca mariadb-show de la siguiente manera:

shell> mariadb-show [opciones] [nombre_db [nombre_tabla [nombre_columna]]]
•Si no se proporciona ningún nombre de base de datos, se muestra una lista de nombres de bases de datos.
•Si no se proporciona ningún nombre de tabla, se muestran todas las tablas coincidentes en la base de datos.
•Si no se proporciona ningún nombre de columna, se muestran todas las columnas y tipos de columna coincidentes en la tabla.

La salida muestra solo los nombres de aquellas bases de datos, tablas o columnas para las que tienes algún privilegio.

Si el último argumento contiene caracteres comodín de shell o SQL (“*”, “?”, “%”, o “_”), solo se muestran aquellos nombres que coinciden con el comodín. Si un nombre de base de datos contiene guiones bajos, estos deben escaparse con una barra invertida (algunos shells de Unix requieren dos) para obtener una lista de las tablas o columnas adecuadas. Los caracteres “*” y “?” se convierten en caracteres comodín SQL “%” y “_”. Esto puede causar cierta confusión cuando intentas mostrar las columnas de una tabla con un “_” en el nombre, ya que en este caso, mariadb-show solo te muestra los nombres de tabla que coinciden con el patrón. Esto se soluciona fácilmente añadiendo un “%” adicional al final de la línea de comandos como un argumento separado.

mariadb-show admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-show] y [client]. mariadb-show también admite las opciones para procesar archivos de opciones descritas.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--character-sets-dir=ruta, -c ruta

El directorio donde están instalados los juegos de caracteres.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos soportan la compresión.

•--count

Muestra el número de filas por tabla. Esto puede ser lento para tablas que no sean MyISAM.

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre

Plugin del lado del cliente de autenticación predeterminado a usar.

•--default-character-set=nombre_juego_caracteres

Usa nombre_juego_caracteres como el juego de caracteres predeterminado.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos de configuración globales. Debe proporcionarse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas, anulando los archivos de configuración globales. Debe proporcionarse como la primera opción.

•--defaults-group-suffix=sufijo

Además de los grupos nombrados en la línea de comandos, lee los grupos que tengan el sufijo dado.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host especificado.

•--keys, -k

Muestra los índices de las tablas.

•--no-defaults

No lee opciones predeterminadas de ningún archivo de configuración. Debe proporcionarse como el primer argumento.

•--password[=contraseña], -p[contraseña]

La contraseña a utilizar al conectarse al servidor. Si utilizas la forma corta de la opción (-p), *no* puedes dejar un espacio entre la opción y la contraseña. Si omites el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb-show te la pedirá.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puedes usar un archivo de opciones para evitar introducir la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctate al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor admite conexiones a través de tuberías con nombre.

•--plugin-dir=nombre_dir

Directorio para plugins del lado del cliente.

•--port=numero_puerto, -P numero_puerto

El número de puerto TCP/IP a utilizar para la conexión. Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a utilizar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente provocarían el uso de un protocolo diferente al que deseas.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe proporcionarse como el primer argumento.

•--show-table-type, -t

Muestra una columna que indica el tipo de tabla, como en SHOW FULL TABLES. El tipo es BASE TABLE o VIEW.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a utilizar, o, en Windows, el nombre de la tubería con nombre a utilizar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (activado automáticamente con otras banderas). Deshabilita con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a utilizar (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consulta la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por predeterminado.

•--status, -i

Muestra información adicional sobre cada tabla.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor.

•--verbose, -v

Modo detallado.

OPTIONS

--help, -?

Muestra un mensaje de ayuda y sale.

--verbose, -v

Imprime más información sobre lo que hace el programa. Esta opción se puede usar varias veces para aumentar la cantidad de información.

--version, -V

Muestra información de la versión y sale.
