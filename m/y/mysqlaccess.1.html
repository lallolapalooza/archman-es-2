MARIADB-ACCESS(1) Sistema de Bases de Datos MariaDB MARIADB-ACCESS(1)

NOMBRE

mariadb-access - cliente para comprobar privilegios de acceso (mariadb-access es ahora un enlace simbólico a mariadb-access)

SINOPSIS

mariadb-access [nombre_host [nombre_usuario [nombre_bd]]] [opciones]

DESCRIPCIÓN

mariadb-access es una herramienta de diagnóstico escrita por Yves Carlier. Comprueba los privilegios de acceso para una combinación de nombre de host, nombre de usuario y base de datos. Tenga en cuenta que mariadb-access comprueba el acceso utilizando solo las tablas user, db y host. No comprueba los privilegios de tablas, columnas o rutinas especificados en las tablas tables_priv, columns_priv o procs_priv.

Ejecute mariadb-access de la siguiente manera:

shell> mariadb-access [nombre_host [nombre_usuario [nombre_bd]]] [opciones]

mariadb-access soporta las siguientes opciones.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--brief, -b

Genera informes en formato tabular de una sola línea.

•--commit

Copia los nuevos privilegios de acceso de las tablas temporales a las tablas de concesión originales. Las tablas de concesión deben ser recargadas para que los nuevos privilegios surtan efecto. (Por ejemplo, ejecute un comando mariadb-admin reload).

•--copy

Recarga las tablas temporales de concesión desde las originales.

•--db=nombre_bd, -d nombre_bd

Especifica el nombre de la base de datos.

•--debug=N

Especifica el nivel de depuración. N puede ser un entero de 0 a 3.

•--host=nombre_host, -h nombre_host

El nombre de host a utilizar en los privilegios de acceso.

•--howto

Muestra algunos ejemplos que demuestran cómo usar mariadb-access.

•--old_server

Conéctese a un servidor MySQL muy antiguo (anterior a MySQL 3.21) que no sabe cómo manejar cláusulas WHERE completas.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si omite el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb-access le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Vea la Sección 5.3.2.2, “Pautas para el usuario final sobre la seguridad de las contraseñas”.

•--plan

Muestra sugerencias e ideas para futuras versiones.

•--preview

Muestra las diferencias de privilegios después de realizar cambios en las tablas temporales de concesión.

•--relnotes

Muestra las notas de la versión.

•--rhost=nombre_host, -H nombre_host

Conéctese al servidor MariaDB en el host especificado.

•--rollback

Deshace los cambios más recientes en las tablas temporales de concesión.

•--spassword[=contraseña], -P[contraseña]

La contraseña a usar al conectarse al servidor como superusuario. Si omite el valor de contraseña después de la opción --spassword o -p en la línea de comandos, mariadb-access le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Vea la Sección 5.3.2.2, “Pautas para el usuario final sobre la seguridad de las contraseñas”.

•--superuser=nombre_usuario, -U nombre_usuario

Especifica el nombre de usuario para conectarse como superusuario.

•--table, -t

Genera informes en formato de tabla.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario a utilizar en los privilegios de acceso.

•--version, -v

Muestra información de la versión y sale.

Si su distribución de MariaDB está instalada en una ubicación no estándar, debe cambiar la ubicación donde mariadb-access espera encontrar el cliente mariadb. Edite el script mariadb-access en la línea aproximada 18. Busque una línea que se parezca a esto:

$MYSQL     = '/usr/local/bin/mariadb';    # path to mariadb executable

Cambie la ruta para reflejar la ubicación donde mariadb está realmente almacenado en su sistema. Si no hace esto, ocurrirá un error de tubería rota (Broken pipe) cuando ejecute mariadb-access.
