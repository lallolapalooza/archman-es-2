NOMBRE

mwmrc — Archivo de Descripción de Recursos del Gestor de Ventanas Motif

DESCRIPCIÓN

El archivo mwmrc es un archivo de recursos suplementario que controla gran parte del comportamiento del gestor de ventanas Motif mwm. Contiene descripciones de recursos que no se pueden escribir fácilmente utilizando la sintaxis estándar de recursos del X Window System, Versión 11. El archivo de descripción de recursos contiene entradas a las que se hace referencia mediante recursos X en archivos de configuración por defecto (por ejemplo, /usr/X11R6/lib/X11/app-defaults/Mwm) o en la propiedad RESOURCE_MANAGER en la ventana raíz. Por ejemplo, el archivo de descripción de recursos le permite especificar diferentes tipos de menús de ventanas; sin embargo, se utiliza un recurso X para especificar qué menús de ventanas debe usar mwm para una ventana en particular.

Ubicación

El gestor de ventanas busca uno de los siguientes archivos de descripción de recursos, donde $LANG es el valor del entorno de idioma a nivel de usuario:

$HOME/$LANG/.mwmrc
$HOME/.mwmrc
/usr/X11R6/lib/X11/$LANG/system.mwmrc
/usr/X11R6/lib/X11/system.mwmrc

El primer archivo encontrado es el primero que se utiliza. Si no se encuentra ningún archivo, se utiliza un conjunto de especificaciones incorporadas. Se puede seleccionar un archivo de descripción de recursos particular utilizando el recurso configFile. El siguiente muestra cómo se puede especificar un archivo de descripción de recursos diferente desde la línea de comandos:

/usr/X11R6/bin/X11/mwm -xrm "mwm*configFile: mymwmrc"

Tipos de Recursos

Los siguientes tipos de recursos se pueden describir en el archivo de descripción de recursos de mwm:

Botones
Las funciones del gestor de ventanas se pueden enlazar (asociar) con eventos de botón.
Teclas
Las funciones del gestor de ventanas se pueden enlazar (asociar) con eventos de pulsación de teclas.
Menús
Los paneles de menú se pueden usar para el menú de ventana y otros menús mostrados con enlaces de teclas y enlaces de botones.

SINTAXIS DEL ARCHIVO DE DESCRIPCIÓN DE RECURSOS MWM

El archivo de descripción de recursos mwm es un archivo de texto estándar que contiene elementos de información separados por espacios, tabulaciones y caracteres de nueva línea. Las líneas en blanco se ignoran. Los elementos o caracteres se pueden citar para evitar una interpretación especial (por ejemplo, el carácter de comentario se puede citar para evitar que se interprete como carácter de comentario). Un elemento citado puede estar contenido entre comillas dobles (" "). Los caracteres individuales se pueden citar anteponiéndoles el carácter de barra invertida (\). Si una línea termina con una barra invertida, la línea siguiente se considera una continuación de esa línea. Todo texto desde un carácter # sin comillas hasta el final de la línea se considera un comentario y no se interpreta como parte de una descripción de recursos. Si ! es el primer carácter de una línea, la línea se considera un comentario.

Funciones del Gestor de Ventanas

Las funciones del gestor de ventanas se pueden acceder con enlaces de botones y teclas, y con menús del gestor de ventanas. Las funciones se indican como parte de las especificaciones para conjuntos de enlaces de botones y teclas, y paneles de menú. La especificación de la función tiene la siguiente sintaxis:

función = nombre_función [argumentos_función]
nombre_función = función_del_gestor_de_ventanas
argumentos_función = {elemento_citado | elemento_no_citado}

Se admiten las siguientes funciones. Si se especifica una función que no es una de las admitidas, mwm la interpreta como f.nop.

f.beep
Esta función produce un pitido.
f.circle_down [ icon | window]
Esta función coloca la ventana o icono que está en la parte superior de la pila de ventanas en la parte inferior de la pila de ventanas (para que ya no oculte ninguna otra ventana o icono). Esta función afecta solo a aquellas ventanas e iconos que ocultan otras ventanas e iconos, o que son ocultados por otras ventanas e iconos. Las ventanas secundarias (es decir, las ventanas transitorias) se reorganizan con su ventana primaria asociada. Las ventanas secundarias siempre permanecen encima de la ventana primaria asociada y no puede haber otras ventanas primarias entre las ventanas secundarias y su ventana primaria. Si se especifica un argumento de función icon, entonces la función se aplica solo a los iconos. Si se especifica un argumento de función window, entonces la función se aplica solo a las ventanas.
f.circle_up [ icon | window]
Esta función eleva la ventana o icono en la parte inferior de la pila de ventanas (para que no sea ocultada por ninguna otra ventana). Esta función afecta solo a aquellas ventanas e iconos que ocultan otras ventanas e iconos, o que son ocultados por otras ventanas e iconos. Las ventanas secundarias (es decir, las ventanas transitorias) se reorganizan con su ventana primaria asociada. Si se especifica un argumento de función icon, entonces la función se aplica solo a los iconos. Si se especifica un argumento de función window, entonces la función se aplica solo a las ventanas.
f.exec comando (o ! comando)
Esta función hace que se ejecute comando (utilizando el valor de la variable de entorno $MWMSHELL o $SHELL si está definida; de lo contrario, /bin/sh). La notación ! se puede usar en lugar del nombre de la función f.exec.
f.focus_color
Esta función establece el foco del mapa de colores en una ventana cliente. Si esta función se ejecuta en un contexto raíz, entonces se instala el mapa de colores por defecto (configurado por el X Window System para la pantalla donde se está ejecutando mwm) y no hay un foco de mapa de colores de ventana cliente específico. Esta función se trata como f.nop si colormapFocusPolicy no es explícito.
f.focus_key
Esta función establece el foco de entrada del teclado en una ventana o icono cliente. Esta función se trata como f.nop si keyboardFocusPolicy no es explícito o si la función se ejecuta en un contexto raíz.
f.kill
Esta función se utiliza para cerrar ventanas de aplicaciones. El procesamiento real que ocurre depende de los protocolos que la aplicación observe. La aplicación enumera los protocolos que observa en la propiedad WM_PROTOCOLS en su ventana de nivel superior. Si la aplicación observa el protocolo WM_DELETE_WINDOW, se le envía un mensaje que solicita que se elimine la ventana. Si la aplicación observa tanto WM_DELETE_WINDOW como WM_SAVE_YOURSELF, se le envía un mensaje solicitando que se elimine la ventana y otro mensaje indicándole que guarde su estado. Si la aplicación solo observa el protocolo WM_SAVE_YOURSELF, se le envía un mensaje indicándole que guarde su estado. Después de un retraso (especificado por el recurso quitTimeout), se termina la conexión de la aplicación con el servidor X. Si la aplicación no observa ninguno de estos protocolos, se termina su conexión con el servidor X.
f.lower [- client | within | freeFamily]
Esta función baja una ventana primaria a la parte inferior de la pila de ventanas global (donde no oculta ninguna otra ventana) y baja la ventana secundaria (ventana transitoria o cuadro de diálogo) dentro de la familia del cliente. Los argumentos para esta función son mutuamente excluyentes. El argumento client indica el nombre o la clase de un cliente para bajar. El nombre o la clase de un cliente aparece en la propiedad WM_CLASS en la ventana de nivel superior del cliente. Si no se especifica el argumento client, el contexto en el que se invocó la función indica la ventana o icono a bajar. Especificar within baja la ventana secundaria dentro de la familia (manteniéndose encima de la

f.maximize
Esta función hace que una ventana cliente se muestre con su tamaño máximo. Consulte los recursos maximumClientSize, maximumMaximumSize y limitResize en mwm(1).
f.menu nombre_menu
Esta función asocia un menú en cascada (desplegable) con una entrada de panel de menú o un menú con un botón o enlace de tecla. El argumento de función nombre_menu identifica el menú que se utilizará.
f.minimize
Esta función hace que una ventana cliente se minimice (se icone). Cuando una ventana se minimiza sin usar un cuadro de iconos y si el recurso lowerOnIconify tiene el valor True (el valor predeterminado), el icono se coloca en la parte inferior de la pila de ventanas (de modo que no oculte ninguna otra ventana). Si se utiliza un cuadro de iconos, el icono del cliente cambia a su forma iconizada dentro del cuadro de iconos. Las ventanas secundarias (es decir, las ventanas transitorias) se minimizan con su ventana primaria asociada. Solo hay un icono para una ventana primaria y todas sus ventanas secundarias.
f.move
Esta función inicia un movimiento interactivo de una ventana cliente.
f.next_cmap
Esta función instala el siguiente mapa de colores en la lista de mapas de colores para la ventana con el foco de mapa de colores.
f.next_key [ icono | ventana | transitorio]
Esta función establece el foco de entrada del teclado en la siguiente ventana/icono en el conjunto de ventanas/iconos administrados por el administrador de ventanas (el orden de este conjunto se basa en la pila de ventanas en la pantalla). Esta función se trata como f.nop si keyboardFocusPolicy no es explícito. El foco de entrada del teclado solo se mueve a las ventanas que no tienen una ventana secundaria asociada que sea modal de aplicación. Si se especifica el argumento transitorio, se recorren las ventanas transitorias (secundarias) (de lo contrario, si solo se especifica ventana, el recorrido se realiza solo a la última ventana enfocada en un grupo transitorio). Si se especifica un argumento de función icono, la función se aplica solo a los iconos. Si se especifica un argumento de función ventana, la función se aplica solo a las ventanas.
f.nop
Esta función no hace nada.
f.normalize
Esta función hace que una ventana cliente se muestre con su tamaño normal. Las ventanas secundarias (es decir, las ventanas transitorias) se colocan en su estado normal junto con su ventana primaria asociada.
f.normalize_and_raise
Esta función hace que una ventana cliente se muestre con su tamaño normal y se eleve a la parte superior de la pila de ventanas. Las ventanas secundarias (es decir, las ventanas transitorias) se colocan en su estado normal junto con su ventana primaria asociada.
f.pack_icons
Esta función se utiliza para reorganizar los iconos (basándose en la política de diseño utilizada) en la ventana raíz o en el cuadro de iconos. En general, esto hace que los iconos se "empaqueten" en la cuadrícula de iconos.
f.pass_keys
Esta función se utiliza para habilitar/deshabilitar (alternar) el procesamiento de enlaces de teclas para las funciones del administrador de ventanas. Cuando deshabilita el procesamiento de enlaces de teclas, todas las teclas se pasan a la ventana con el foco de entrada del teclado y no se invoca ninguna función del administrador de ventanas. Si la función f.pass_keys se invoca con un enlace de tecla para deshabilitar el procesamiento de enlaces de teclas, el mismo enlace de tecla se puede utilizar para habilitar el procesamiento de enlaces de teclas.
f.post_wmenu
Esta función se utiliza para mostrar el menú de la ventana. Si se utiliza una tecla para mostrar el menú de la ventana y hay un botón de menú de ventana, el menú de la ventana se coloca automáticamente con su esquina superior izquierda en la esquina inferior izquierda del botón del menú de ventana para la ventana cliente. Si no hay un botón de menú de ventana, el menú de la ventana se coloca en la esquina superior izquierda de la ventana cliente.
f.prev_cmap
Esta función instala el mapa de colores anterior en la lista de mapas de colores para la ventana con el foco de mapa de colores.
f.prev_key [ icono | ventana | transitorio]
Esta función establece el foco de entrada del teclado en la ventana/icono anterior en el conjunto de ventanas/iconos administrados por el administrador de ventanas (el orden de este conjunto se basa en la pila de ventanas en la pantalla). Esta función se trata como f.nop si keyboardFocusPolicy no es explícito. El foco de entrada del teclado solo se mueve a las ventanas que no tienen una ventana secundaria asociada que sea modal de aplicación. Si se especifica el argumento transitorio, se recorren las ventanas transitorias (secundarias) (de lo contrario, si solo se especifica ventana, el recorrido se realiza solo a la última ventana enfocada en un grupo transitorio). Si se especifica un argumento de función icono, la función se aplica solo a los iconos. Si se especifica un argumento de función ventana, la función se aplica solo a las ventanas.
f.quit_mwm
Esta función termina mwm (pero NO el sistema de ventanas X).
f.raise [-cliente | dentro | freeFamily]
Esta función eleva una ventana primaria a la parte superior de la pila global de ventanas (donde no está oculta por ninguna otra ventana) y eleva la ventana secundaria (ventana transitoria o cuadro de diálogo) dentro de la familia del cliente. Los argumentos para esta función son mutuamente excluyentes. El argumento cliente indica el nombre o la clase de un cliente para bajar. Si no se especifica el cliente, el contexto en el que se invocó la función indica la ventana o el icono para bajar. Especificar dentro eleva la ventana secundaria dentro de la familia pero no eleva la familia del cliente en la pila global de ventanas. Especificar freeFamily eleva la ventana a la parte superior de su pila local de familia y eleva la familia a la parte superior de la pila global de ventanas.
f.raise_lower [ dentro | freeFamily]
Esta función eleva una ventana primaria a la parte superior de la pila global de ventanas si está parcialmente oculta por otra ventana; de lo contrario, baja la ventana al final de la pila de ventanas. Los argumentos para esta función son mutuamente excluyentes. Especificar dentro eleva una ventana secundaria dentro de la familia (manteniéndose por encima de la ventana padre), si está parcialmente oculta por otra ventana en la familia de la aplicación; de lo contrario, baja la ventana al final de la pila de la familia. No tiene ningún efecto en el orden de apilamiento global de ventanas. Especificar freeFamily eleva la ventana a la parte superior de su pila local de familia, si está oculta por otra ventana, y eleva la familia a la parte superior de la pila global de ventanas; de lo contrario, baja la ventana al final de su pila local de familia y baja la familia al final de la pila global de ventanas.
f.refresh
Esta función hace que todas las ventanas se redibujen.
f.refresh_win
Esta función hace que una ventana cliente se redibuje.
f.resize
Esta función inicia un redimensionamiento interactivo de una ventana cliente.
f.restore
Esta función restaura el estado anterior de la ventana asociada a un icono. Si una ventana maximizada se icone, entonces f.restore la restaura a su estado maximizado. Si una ventana normal se icone, entonces f.restore la restaura a su estado normalizado.
f.restore_and_raise
Esta función restaura el estado anterior de la ventana asociada a un icono y eleva la ventana a la parte superior de la pila de ventanas. Si una ventana maximizada se icone, entonces f.restore_and_raise la restaura a su estado maximizado y la eleva a la parte superior de la pila de ventanas. Si una ventana normal se icone, entonces f.restore_and_raise la restaura a su estado normalizado y la eleva a la parte superior de la pila de ventanas.
f.restart
Esta función hace que mwm se reinicie (efectivamente, se termine y se vuelva a ejecutar). El reinicio es necesario para que mwm incorpore los cambios tanto en el archivo mwmrc como en los recursos X.
f.screen [ siguiente | anterior | atrás | numero_pantalla]
Esta función hace que el puntero se mueva a un número de pantalla específico o a la pantalla siguiente, anterior o visitada por última vez (atrás). Los argumentos para esta función son mutuamente excluyentes. El argumento numero_pantalla indica el número de pantalla al que se moverá el puntero. Las pantallas se numeran a partir de la pantalla 0. Especificar siguiente hace que el puntero se mueva a la siguiente pantalla administrada (saltándose cualquier pantalla no administrada). Especificar anterior hace que el puntero se mueva a la pantalla administrada anterior (saltándose cualquier pantalla no administrada). Especificar atrás hace que el puntero se mueva a la última pantalla visitada.
f.send_msg numero_mensaje
Esta función envía un XClientMessageEvent de tipo _MOTIF_WM_MESSAGES con tipo_mensaje establecido en numero_mensaje. El mensaje cliente solo se envía si numero_mensaje está incluido en la propiedad _MOTIF_WM_MESSAGES del cliente. Una etiqueta de elemento de menú se muestra en gris si el elemento de menú se utiliza para realizar f.send_msg de un mensaje que no está incluido en la propiedad _MOTIF_WM_MESSAGES del cliente.
f.separator
Esta función hace que se inserte un separador de menú en el panel de menú en la ubicación especificada (la etiqueta se ignora).
f.set_behavior
Esta función hace que el administrador de ventanas se reinicie con el comportamiento predeterminado (si se configura un comportamiento personalizado) o un comportamiento personalizado (si se configura un comportamiento predeterminado). Por defecto, esto está vinculado a Shift Ctrl Alt <Tecla>!.
f.title
Esta función inserta un título en el panel de menú en la ubicación especificada.
f.version
Esta función hace que el administrador de ventanas muestre su versión de lanzamiento en un cuadro de diálogo.

Restricciones de Función

Cada función puede estar restringida en cuanto a qué tipos de recursos pueden especificar la función (por ejemplo, panel de menú) y también en qué contexto se puede utilizar la función (por ejemplo, la función se realiza en la ventana cliente seleccionada). Los contextos de función son:

root
No se ha seleccionado ninguna ventana cliente ni icono como objeto para la función.
window
Se ha seleccionado una ventana cliente como objeto para la función. Esto incluye la barra de título y el marco de la ventana. Algunas funciones se aplican solo cuando la ventana está en su estado normalizado (por ejemplo, f.maximize) o en su estado maximizado (por ejemplo, f.normalize).
icon
Se ha seleccionado un icono como objeto para la función.

Si una función se especifica en un tipo de recurso donde no es compatible o se invoca en un contexto que no se aplica, la función se trata como f.nop. La siguiente tabla indica los tipos de recursos y contextos de función en los que se aplican las funciones del administrador de ventanas.

Los nombres de keysym se pueden encontrar en el archivo keysymdef.h (elimine el prefijo XK_).

ENLACES DE BOTONES

El valor del recurso buttonBindings es el nombre de un conjunto de enlaces de botones que se utilizan para configurar el comportamiento del administrador de ventanas. Una función del administrador de ventanas se puede realizar cuando ocurre una pulsación de botón con el puntero sobre una ventana cliente con marco, un icono o la ventana raíz. El contexto para indicar dónde se aplica la pulsación del botón es también el contexto para invocar la función del administrador de ventanas cuando se realiza la pulsación del botón (importante para las funciones que son sensibles al contexto). La sintaxis del enlace de botones es

Buttons bindings_set_name
{
    button    context    function
    button    context    function
    ...
    button    context    function
}

La sintaxis para la especificación del context es: context = object[| context] object = root | icon | window |

>título | marco | borde | app La especificación del contexto indica dónde debe estar el puntero para que la asociación de botones sea efectiva. Por ejemplo, un contexto de ventana indica que el puntero debe estar sobre una ventana del cliente o el marco de gestión de ventanas para que la asociación de botones sea efectiva. El contexto marco es para el marco de gestión de ventanas alrededor de una ventana del cliente (incluyendo el borde y la barra de título), el contexto borde es para la parte del borde del marco de gestión de ventanas (sin incluir la barra de título), el contexto título es para el área del título del marco de gestión de ventanas, y el contexto app es para la ventana de la aplicación (sin incluir el marco de gestión de ventanas). Si se especifica una función f.nop para una asociación de botones, la asociación de botones no se realiza.

ASOCIACIONES DE TECLAS

El valor del recurso keyBindings es el nombre de un conjunto de asociaciones de teclas que se utilizan para configurar el comportamiento del gestor de ventanas. Una función del gestor de ventanas puede ejecutarse cuando se presiona una tecla particular. El contexto en el que aplica la asociación de teclas se indica en la especificación de la asociación de teclas. Los contextos válidos son los mismos que se aplican a las asociaciones de botones. La sintaxis de la asociación de teclas es:

Teclas nombre_conjunto_asociaciones
{
    tecla    contexto    función
    tecla    contexto    función
    ...
    tecla    contexto    función
}

Si se especifica una función f.nop para una asociación de teclas, la asociación de teclas no se realiza. Si una función f.post_wmenu o f.menu está asociada a una tecla, mwm utiliza automáticamente la misma tecla para eliminar el menú de la pantalla después de que se haya mostrado. La sintaxis de la especificación contexto es la misma que para las asociaciones de botones, con una adición. El contexto ifkey puede especificarse para asociar teclas que pueden no estar disponibles en todas las pantallas. Si la tecla no está disponible y si ifkey está en el contexto, entonces la notificación del mensaje de error al registro de errores se suprime. Esta característica es útil para entornos heterogéneos y en red. Para las asociaciones de teclas, los contextos frame, title, border y app son equivalentes al contexto window. El contexto para un evento de tecla es la ventana o el icono que tiene el foco de entrada del teclado (root si ninguna ventana o icono tiene el foco de entrada del teclado).

PANELES DE MENÚ

Los menús se pueden mostrar utilizando las funciones del gestor de ventanas f.post_wmenu y f.menu. El contexto para las funciones del gestor de ventanas que se ejecutan desde un menú es root, icon o window, dependiendo de cómo se mostró el menú. En el caso del menú de ventana o los menús mostrados con una asociación de teclas, la ubicación del foco de entrada del teclado indica el contexto. Para los menús mostrados utilizando una asociación de botones, el contexto de la asociación de botones es el contexto del menú. La sintaxis de la especificación del panel de menú es:

Menu nombre_menu
{
    etiqueta  [mnemotecnia]  [acelerador ]   función
    etiqueta  [mnemotecnia]  [acelerador ]   función
    ...
    etiqueta  [mnemotecnia]  [acelerador ]   función
}

Cada línea en la especificación Menu identifica la etiqueta de un elemento del menú y la función que se ejecutará si se selecciona el elemento del menú. Opcionalmente, se puede especificar una mnemotecnia para el botón del menú y un acelerador de teclado para el botón del menú. Las mnemotecnias solo son funcionales cuando el menú se muestra y se aplica la navegación por teclado. La especificación de la etiqueta puede ser una cadena de texto o un archivo de mapa de bits. La sintaxis de la especificación de la etiqueta es:

etiqueta = texto | archivo_mapa_bits
archivo_mapa_bits = @nombre_archivo
texto = elemento_entre_comillas | elemento_sin_comillas

La codificación de cadenas para las etiquetas debe ser compatible con la fuente del menú que se utiliza. Las etiquetas se atenúan para los elementos del menú que ejecutan la función f.nop o una función inválida o una función que no se aplica en el contexto actual. La especificación de la mnemotecnia tiene la siguiente sintaxis:

mnemotecnia = _ carácter

El primer carácter coincidente en la etiqueta se subraya. Si no hay ningún carácter coincidente en la etiqueta, no se registra ninguna mnemotecnia con el gestor de ventanas para esa etiqueta. Aunque el carácter debe coincidir exactamente con un carácter de la etiqueta, la mnemotecnia no se ejecuta si se presiona algún modificador (como Shift) con la tecla del carácter. La especificación del acelerador es una especificación de evento de tecla con la misma sintaxis que se utiliza para las asociaciones de teclas a funciones del gestor de ventanas.

INCLUSIÓN DE ARCHIVOS

Puedes incluir otros archivos en tu archivo mwmrc utilizando la construcción include. Por ejemplo,

INCLUDE
{
    /usr/local/shared/mwm.menus
    /home/kmt/personal/my.bindings
}

hace que los archivos nombrados se lean e interpreten en orden como una parte adicional del archivo mwmrc. Include es una construcción de nivel superior. No se puede anidar dentro de otra construcción.
