MWRANK(1) Comandos de usuario MWRANK(1)

NOMBRE

mwrank - determina el rango de una curva elíptica E sobre Q mediante 2-descenso y la generación de puntos para E(Q) módulo torsión

DESCRIPCIÓN

mwrank está organizado como un bucle donde el usuario introduce curvas una por una y el programa muestra lo que puede calcular sobre ellas. Una curva elíptica se introduce proporcionando sus coeficientes de Weierstrass (que pueden ser enteros o racionales, ya sea como [a1,a2,a3,a4,a6] o como a1 a2 a3 a4 a6.

Aquí están las opciones de línea de comandos de mwrank (pueden estar en cualquier orden):

-h ayuda muestra esta información y sale

-q silencioso desactiva la visualización del banner

-v n verbosidad establece la verbosidad en n (por defecto=1)

-o salida PARI/GP activa la salida corta adicional de PARI/GP (por defecto está desactivada)

-p n precisión establece la precisión en n decimales (por defecto=15)

-b n límite cuártico límite en la búsqueda de puntos cuárticos (por defecto=10)

-x n n aux número de primos auxiliares utilizados para el tamizado (por defecto=6)

-l lista activa la listado de puntos (por defecto activado a menos que v=0)

-t traza activa el rastreo de la prueba de equivalencia cuártica (solo depuración)

-s selmer_only si está activado, calcula solo el rango de Selmer (por defecto: no activado)

-d skip_2nd_descent si está activado, omite el segundo descenso para curvas con 2-torsión (por defecto: no activado)

-S n sat_bd límite superior en los primos de saturación (por defecto=1000, -1 para automático)
