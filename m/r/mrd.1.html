mrd - eliminar un subdirectorio de MSDOS

Nota de advertencia

Esta página del manual ha sido generada automáticamente a partir de la documentación texinfo de mtools y puede que no sea completamente precisa o completa. Consulte el final de esta página del manual para obtener más detalles.

Descripción

El comando mrd se utiliza para eliminar un subdirectorio de MS-DOS. Su sintaxis es:

mrd [-v] directorio_msdos [ directorios_msdos... ]

Mrd elimina un directorio de un sistema de archivos MS-DOS. Se produce un error si el directorio no existe o no está vacío.
