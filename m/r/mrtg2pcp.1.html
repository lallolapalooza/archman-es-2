MRTG2PCP(1) Manual de Comandos Generales MRTG2PCP(1)

NOMBRE

mrtg2pcp - importar datos de MRTG y crear un archivo PCP

SINOPSIS

mrtg2pcp hostname devname timezone infile outfile

DESCRIPCIÓN

mrtg2pcp está diseñado para leer un archivo de registro de MRTG tal como lo crea mrtg(1) y traducirlo a un archivo Performance Co-Pilot (PCP) con el nombre base outfile. Los argumentos hostname, devname y timezone especifican información sobre el sistema para el cual se recopilaron las estadísticas.

El archivo PCP resultante puede usarse con todas las herramientas cliente de PCP para graficar subconjuntos de datos usando pmchart(1), realizar reducción y generación de informes de datos, filtrar con el motor de inferencia de PCP pmie(1), etc.

Se crearán una serie de archivos físicos con el prefijo outfile. Estos son outfile.0 (los datos de rendimiento), outfile.meta (los metadatos que describen los datos de rendimiento) y outfile.index (un índice temporal para mejorar la eficiencia de las operaciones de reproducción para el archivo). Si alguno de estos archivos ya existe, entonces mrtg2pcp **no** los sobrescribirá y saldrá con un mensaje de error de la forma

__pmLogNewFile: ``blah.0'' ya existe, no se sobrescribió

mrtg2pcp es un script de Perl que utiliza el wrapper de Perl PCP::LogImport en torno a la biblioteca libpcp_import de PCP y, como tal, podría usarse como ejemplo para desarrollar nuevas herramientas para importar otros tipos de datos de rendimiento y crear archivos PCP.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

mrtg(1), pmchart(1), pmie(1), pmlogger(1), LOGIMPORT(3) y PCP::LogImport(3).
