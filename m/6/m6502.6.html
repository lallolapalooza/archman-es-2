NOMBRE

m6502 - Emulador de Microprocesador 6502

SINOPSIS

m6502 [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id number][--mono] [--install] [--visual visual] [--file filename] [-displaytime seconds] [--fps]

DESCRIPCIÓN

El salvapantallas m6502 emula un microprocesador 6502. La familia de chips 6502 se utilizó durante los años 70 y 80 en máquinas como Atari 2600, Commodore PET, VIC20 y C64, Apple ][, y NES. Se incluyen algunos programas de ejemplo y también puede leer un archivo de ensamblador como entrada.

OPCIONES

m6502 acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id number
Dibuja en la ventana especificada.
--mono
Si está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--file filename
Permite cargar un archivo de ensamblador.
--displaytime seconds
Permite establecer el número de segundos para mostrar cada programa. El valor predeterminado es 60.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

RECURSOS X

Los recursos X notables admitidos incluyen los siguientes que corresponden a los controles de TV estándar: analogTVTint, analogTVColor, analogTVBrightness y analogTVContrast. Varían de 0 a 100, excepto el tinte que es un ángulo entre -180 y +180.

MARCAS REGISTRADAS

Estoy seguro de que algunos de los programas contienen marcas registradas.
