NOMBRE


mtx-base - Herramienta de gestión TDS de ConTeXt (también conocida como luatools)

SINOPSIS

mtxrun --script base [ OPCIONES ... ] [ NOMBRES-DE-ARCHIVO ]

DESCRIPCIÓN

Herramienta de gestión TDS de ConTeXt (también conocida como luatools)

OPCIONES

--generate
generar base de datos de archivos
--variables
mostrar variables de configuración
--configurations
mostrar orden de configuración
--expand-braces
expandir variable compleja
--expand-path
expandir variable (resolver rutas)
--expand-var
expandir variable (resolver referencias)
--show-path
mostrar expansión de ruta de ...
--var-value
informar el valor de la variable
--find-file
informar la ubicación del archivo
--find-path
informar la ruta del archivo
--make
[o --ini] crear formato luatex
--run
[o --fmt] ejecutar formato luatex
--compile
ensamblar y compilar archivo inifile de lua
--verbose
dar un poco más de información
--all
mostrar todos los archivos encontrados
--format=str
filtrar especificación de formato cf (por defecto 'tex', usar 'any' para coincidencia cualquiera)
--pattern=str
filtrar variables
--trackers=list
habilitar rastreadores dados

AUTOR

Se puede encontrar más información sobre ConTeXt y las herramientas que vienen con él en:

lista de correo: ntg-context@ntg.nl / http://www.ntg.nl/mailman/listinfo/ntg-context

página web: http://www.pragma-ade.nl / http://tex.aanhet.net

wiki: http://contextgarden.net
