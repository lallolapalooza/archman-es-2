mtx-update(1) Actualizador de Mínimos de ConTeXt mtx-update(1)

NOMBRE


mtx-update - Actualizador de Mínimos de ConTeXt

SINOPSIS

mtxrun --script update [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVO ]

DESCRIPCIÓN

Actualizador de Mínimos de ConTeXt

OPCIONES

--platform=string
plataforma (windows, linux, linux-64, osx-intel, osx-ppc, linux-ppc)
--server=string
url del repositorio (rsync://contextgarden.net)
--module=string
url del repositorio (minimals)
--repository=string
especificar versión (current, experimental)
--context=string
especificar versión (current, latest, beta, yyyy.mm.dd)
--rsync=string
binario rsync (rsync)
--texroot=string
directorio de instalación (no se adivina por el momento)
--engine=string
motor tex (luatex, pdftex, xetex)
--modules=string
módulos extra (puede ser una lista o 'all')
--fonts=string
fuentes adicionales (puede ser una lista o 'all')
--goodies=string
binarios extra (como scite y texworks)
--force
en lugar de una simulación, hazlo de verdad
--update
actualiza el árbol de mínimos
--make
también crea formatos y genera bases de datos de archivos
--keep
no elimines archivos no utilizados u obsoletos
--state
actualiza el árbol usando estado guardado
--cygwin
adapta las especificaciones de unidad a cygwin
--mingw
asume que se están utilizando binarios mingw
--silent
menos registro (o ninguno)
