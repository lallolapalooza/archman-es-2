mtype - mostrar el contenido de un archivo MSDOS

Nota de advertencia

Esta página del manual se ha generado automáticamente a partir de la documentación texinfo de mtools y puede que no sea completamente precisa o completa. Consulte el final de esta página del manual para obtener más detalles.

Descripción

El comando mtype se utiliza para mostrar el contenido de un archivo MS-DOS. Su sintaxis es:

mtype [-ts] archivo_msdos [ archivos_msdos... ]

Mtype muestra el archivo MS-DOS especificado en la pantalla.

Además de las opciones estándar, Mtype permite las siguientes opciones de línea de comandos:

t 
Visualización de archivos de texto. Mtype traduce los saltos de línea y retornos de carro entrantes a saltos de línea. La visualización se detiene en el carácter Control-Z.
s 
Mtype elimina el bit superior de los datos.

El comando mcd puede utilizarse para establecer el dispositivo y el directorio de trabajo actual (relativo a MS-DOS); de lo contrario, el valor predeterminado es A:/.

Mtype devuelve 0 en caso de éxito, 1 en caso de fallo total o 2 en caso de fallo parcial.

A diferencia de la versión MS-DOS de TYPE, mtype permite argumentos múltiples.
