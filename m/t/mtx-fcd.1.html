NOMBRE


mtx-fcd - Cambio Rápido de Directorio

SINOPSIS

mtxrun --script fcd [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Cambio Rápido de Directorio

OPCIONES

--clear
limpiar la caché
--clear
--history limpiar el historial [entrada]
--scan
limpiar la caché y agregar los directorios dados
--add
agregar los directorios dados
--find
encontrar el directorio dado (puede ser una subcadena)
--find
--nohistory encontrar el directorio dado (puede ser una subcadena) pero no usar el historial
--stub
imprimir el archivo stub de la plataforma
--list
mostrar las raíces de los directorios cacheados
--list
--history mostrar el historial de directorios elegidos
--help
mostrar esta ayuda
