mtx-fonts(1) Gestión de la base de datos de fuentes de ConTeXt mtx-fonts(1)

NOMBRE


mtx-fonts - Gestión de la base de datos de fuentes de ConTeXt

SINOPSIS

mtxrun --script fonts [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVO ]

DESCRIPCIÓN

Gestión de la base de datos de fuentes de ConTeXt

OPCIONES

--convertir
guardar fuente open type en tabla cruda
--desempaquetar
guardar un archivo tma en un formato más legible
--recargar
generar nueva base de datos de fuentes (usar --forzar cuando haya dudas)
--recargar
--simple: generar luatex-fonts-names.lua (¡no para context!)
--listar
--nombre: listar fuentes instaladas, filtrar por nombre [--patrón]
--listar
--espec: listar fuentes instaladas, filtrar por especificación [--filtro]
--listar
--archivo: listar fuentes instaladas, filtrar por archivo [--patrón]
--patrón=cadena
filtrar archivos usando patrón
--filtro=lista
pares clave-valor
--todos
mostrar todas las instancias encontradas (combinado con otras banderas)
--info
dar más detalles
--rastreadores=lista
habilitar rastreadores
--estadisticas
información sobre la base de datos
--nombres
usar nombre en lugar de unicodes
--cache=cadena
usar caché específico (otl o otf)
--patrón=cadena
filtrar archivos usando patrón
--cobertura=cadena
lista de caracteres

AUTOR
