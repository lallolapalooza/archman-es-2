NOMBRE


mtx-evohome - Recuperador de Evohome

SINOPSIS

mtxrun --script evohome [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Recuperador de Evohome

OPCIONES

--collect
recopilar datos del dispositivo
--update
actualizar datos del dispositivo
--presets
archivo con datos de autenticación
--auto
recuperar datos de temperatura cada hora
--port
puerto del servidor al ejecutar el servicio, por defecto: 8068
--host
host del servidor al ejecutar el servicio, por defecto: localhost
