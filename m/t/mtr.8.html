MTR(8) Administración del Sistema MTR(8)

NOMBRE

mtr - una herramienta de diagnóstico de red

SINOPSIS

mtr [-4|-6] [-F NOMBRE_ARCHIVO] [--report] [--report-wide] [--xml] [--gtk] [--curses] [--displaymode  MODO] [--raw] [--csv] [--json] [--split] [--no-dns] [--show-ips] [-o  CAMPOS] [-y  INF_IP] [--aslookup] [--ipinfo_provider4  DOMINIO] [--ipinfo_provider6  DOMINIO] [-i  INTERVALO] [-c  CUENTA] [-s  TAMAÑO_PAQUETE] [-B  PATRON_BIT] [-G  PERIODO_GRACIA] [-Q  TOS] [--mpls] [-I  NOMBRE] [-a  DIRECCION] [-f  TTL_INICIAL] [-m  TTL_MAX] [-U  MAX_DESCONOCIDOS] [-E  MAX_MOSTRAR_RUTA] [--udp] [--tcp] [--sctp] [-P  PUERTO] [-L  PUERTO_LOCAL] [-Z  TIEMPO_ESPERA] [-M  MARCA] NOMBRE_HOST

DESCRIPCIÓN

mtr combina la funcionalidad de los programas traceroute y ping en una única herramienta de diagnóstico de red.

Cuando mtr se inicia, investiga la conexión de red entre el host donde se ejecuta mtr y NOMBRE_HOST enviando paquetes con TTL deliberadamente bajos. Continúa enviando paquetes con TTL bajo, anotando el tiempo de respuesta de los enrutadores intermedios. Esto permite a mtr mostrar el porcentaje de respuesta y los tiempos de respuesta de la ruta de Internet hacia NOMBRE_HOST. Un aumento repentino en la pérdida de paquetes o en el tiempo de respuesta suele ser un indicio de un enlace malo (o simplemente sobrecargado).

Los resultados se informan generalmente como tiempos de respuesta de ida y vuelta en milisegundos y el porcentaje de pérdida de paquetes.

OPCIONES

-h, --help
Imprime el resumen de las opciones de argumentos de la línea de comandos.
-v, --version
Imprime la versión instalada de mtr.
-4
Usar solo IPv4.
-6
Usar solo IPv6. (Se puede usar IPv4 para búsquedas DNS.)
-F NOMBRE_ARCHIVO, --filename NOMBRE_ARCHIVO
Lee la lista de nombres de host del archivo especificado.
-r, --report
Esta opción pone a mtr en modo report (informe). Cuando está en este modo, mtr se ejecutará durante el número de ciclos especificado por la opción -c, y luego imprimirá estadísticas y saldrá.
Este modo es útil para generar estadísticas sobre la calidad de la red.
Tenga en cuenta que cada instancia en ejecución de mtr genera una cantidad significativa de tráfico de red. Usar mtr para medir la calidad de su red puede resultar en una disminución del rendimiento de la red.
-w, --report-wide
Esta opción pone a mtr en modo report-wide (informe amplio). Cuando está en este modo, mtr no cortará los nombres de host en el informe.
-x, --xml
Use esta opción para indicarle a mtr que use el formato de salida xml. Este formato es más adecuado para el procesamiento automatizado de los resultados de la medición.
-t, --curses
Use esta opción para forzar a mtr a usar la interfaz de terminal basada en curses (si está disponible). En caso de que la lista de saltos exceda la altura de su terminal, puede usar las teclas + y - para desplazarse hacia arriba y hacia abajo media página.

Ctrl-L borra mensajes de error espurios que puedan sobrescribir otras partes de la pantalla.

--displaymode MODO
Use esta opción para seleccionar el modo de visualización inicial: 0 (por defecto) selecciona estadísticas, 1 selecciona el gráfico de barras sin información de latencia, y 2 selecciona el gráfico de barras con información de latencia.
-g, --gtk
Use esta opción para forzar a mtr a usar la interfaz de ventana X11 basada en GTK+ (si está disponible). GTK+ debe haber estado disponible en el sistema cuando se compiló mtr para que esto funcione. Consulte la página web de GTK+ en http://www.gtk.org/ para más información sobre GTK+.
-l, --raw
Usa el formato de salida raw (crudo). Este formato es más adecuado para archivar los resultados de la medición. Podría ser analizado para ser presentado en cualquiera de los otros métodos de visualización.
Ejemplo del formato de salida raw: 
h 0 10.1.1.1
p 0 339
h 1 46.149.16.4
p 1 530
h 2 172.31.1.16
p 2 531
h 3 82.221.168.236
p 3 1523
h 5 195.130.211.8
p 5 1603
h 6 193.4.58.17
p 6 1127
h 7 193.4.58.17
d 7 www.isnic.is
-C, --csv
Usa el formato de salida Comma-Separated-Value (CSV). (Nota: el separador es en realidad un punto y coma ';').
Ejemplo del formato de salida CSV: 
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;1;r-76520-PROD.greenqloud.internal;288
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;2;46.149.16.4;2086
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;3;172.31.1.16;600
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;4;82.221.168.236;1163
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;5;???;0
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;6;rix-k2-gw.isnic.is;1654
MTR.0.86+git:16e39fc0;1435562787;OK;nic.is;7;www.isnic.is;1036
-j, --json
Use esta opción para indicarle a mtr que use el formato de salida JSON. Esta formato es más adecuado para el procesamiento automatizado de los resultados de la medición. La biblioteca Jansson debe haber estado disponible en el sistema cuando se compiló mtr para que esto funcione.
-p, --split
Use esta opción para configurar mtr para que emita un formato adecuado para una interfaz de usuario dividida.
-n, --no-dns
Use esta opción para forzar a mtr a mostrar números IP numéricos y no intentar resolver los nombres de host.
-b, --show-ips
Use esta opción para indicar a mtr que muestre tanto los nombres de host como los números IP numéricos. En modo dividido, esto agrega un campo adicional a la salida. En modo de informe, generalmente hay muy poco espacio para agregar las IP, y se truncarán. Use el modo de informe amplio (-w) para ver las IP en modo de informe.
-o CAMPOS, --order CAMPOS
Use esta opción para especificar qué campos mostrar y en qué orden. Puede usar uno o más espacios para separar los campos.
Campos disponibles:
L Ratio de pérdida
D Paquetes perdidos
R Paquetes recibidos
S Paquetes enviados
N RTT más reciente (ms)
B RTT Min/Mejor (ms)
A RTT Promedio (ms)
W RTT Max/Peor (ms)
V Desviación estándar
G Media geométrica
J Jitter actual
M Media/Promedio de jitter
X Peor jitter
I Jitter de interarrivals

Ejemplo: -o "LSD NBAW X"

-y n, --ipinfo n
Muestra información sobre cada salto IP. Los valores válidos para n son:
0 Muestra el número AS (equivalente a -z)
1 Muestra el prefijo IP
2 Muestra el código de país

-z, --aslookup
Habilita la búsqueda de AS (Sistema Autónomo). Esto se aplica a la información de IP-a-AS y busca el número AS del ISP que anuncia la ruta para el salto.
-P PUERTO, --port PUERTO
Use el puerto especificado para hacer ping a los hosts. Esto puede ser útil para probar el tráfico de red a través de puertos específicos (por ejemplo, el puerto 80 para HTTP).
-i INTERVALO, --interval INTERVALO
Esta opción especifica el intervalo en segundos entre cada ping. El valor predeterminado es 1 segundo.
-c CUENTA, --count CUENTA
Esta opción especifica el número de pings que se enviarán. El valor predeterminado es infinito.
-s TAMAÑO_PAQUETE, --packetsize TAMAÑO_PAQUETE
Establece el tamaño del paquete a enviar en bytes. El valor predeterminado es 56 bytes.
-B PATRON_BIT, --bitpattern PATRON_BIT
Establece el patrón de bits a usar para los paquetes. El valor predeterminado es 0.
-G PERIODO_GRACIA, --graceperiod PERIODO_GRACIA
Establece el período de gracia en segundos. El valor predeterminado es 3 segundos.
-Q TOS, --tos
Establece el valor TOS (Type of Service) para los paquetes. El valor predeterminado es 0.
--mpls
Habilita la visualización de etiquetas MPLS. Esto se aplica a la salida del rastreo de red y muestra cualquier etiqueta MPLS que se encuentre en los paquetes.
-I NOMBRE, --interface NOMBRE
Use la interfaz de red especificada. Esto puede ser útil si tiene varias interfaces de red y desea asegurarse de que mtr use una específica.
-a DIRECCION, --address DIRECCION
Use la dirección IP de origen especificada. Esto puede ser útil si tiene varias direcciones IP y desea asegurarse de que mtr use una específica.
-f TTL_INICIAL, --first-ttl TTL_INICIAL
Establece el valor TTL inicial. El valor predeterminado es 1.
-m TTL_MAX, --max-ttl TTL_MAX
Establece el valor TTL máximo. El valor predeterminado es 30.
-U MAX_DESCONOCIDOS, --max-unknown MAX_DESCONOCIDOS
Establece el número máximo de saltos desconocidos. El valor predeterminado es 5.
-E MAX_MOSTRAR_RUTA, --max-display-path MAX_MOSTRAR_RUTA
Establece el número máximo de saltos a mostrar en la ruta. El valor predeterminado es 10.
--udp
Use UDP para las sondas. Este es el protocolo predeterminado.
--tcp
Use TCP para las sondas. Cuando se usa TCP, se intenta una conexión TCP completa. Esto puede ser útil para determinar si los puertos TCP están abiertos o cerrados.
--sctp
Use SCTP para las sondas.
-P PUERTO, --port PUERTO
Use el puerto especificado para las sondas. El valor predeterminado es 0, que significa que se usa el puerto elegido aleatoriamente para cada salto. Este valor se usa para los protocolos UDP y TCP.
-L PUERTO_LOCAL, --localport PUERTO_LOCAL
Use el puerto local especificado para las sondas. El valor predeterminado es 0, que significa que se usa el puerto elegido aleatoriamente.
-Z TIEMPO_ESPERA, --timeout TIEMPO_ESPERA
Establece el tiempo de espera en milisegundos. El valor predeterminado es 5000.
-M MARCA, --mark
Establece la marca para los paquetes. El valor predeterminado es 0.

EJEMPLOS

Para determinar la ruta hacia el host www.google.com y mostrar la información de red en modo curses:

mtr --curses www.google.com

Para realizar un informe de 100 ciclos hacia el host www.google.com y salir:

mtr --report --cycles 100 www.google.com

Para realizar un informe de 100 ciclos hacia el host www.google.com, pero no intentar resolver las direcciones IP y mostrar la información completa del host en el informe:

mtr --report --no-dns --report-wide --cycles 100 www.google.com

Para obtener la ruta hacia el host www.google.com en formato XML:

mtr --xml www.google.com

Para obtener la ruta hacia el host www.google.com en formato CSV:

mtr --csv www.google.com

Para obtener la ruta hacia el host www.google.com en formato JSON:

mtr --json www.google.com

OPCIONES

--ipinfo
Esto habilitará la visualización de información de IP en la salida. La información de IP puede constar de hasta cuatro campos: 

        0.  AS number (Autonomous System)
        1.  IP address
        2.  RIR (Regional Internet Registry)
        3.  Allocation date of the IP prefix

La información se muestra en la forma que elija, de forma predeterminada con el uso de la clave y para ciclar entre los campos disponibles.
--ipinfo_provider
Esta opción establece el servidor utilizado para obtener la información de AS (Autonomous System) para las direcciones IP. El valor predeterminado es origin.asn.cymru.com.
-t, --type
Esto le permite seleccionar el tipo de destino para el traceroute. Las opciones válidas son:
IP
Busca información sobre la dirección IP. El valor predeterminado es origin.asn.cymru.com.
r
Busca información sobre el prefijo IP RIR (por ejemplo, ripe, arin, apnic... ). El valor predeterminado es rir.asn.cymru.com.
d
Busca la fecha de asignación del prefijo IP. El valor predeterminado es as.cymru.com.
A
Muestra el número AS de origen.

Es posible ciclar entre estos campos en tiempo de ejecución (usando la tecla y).

-z, --aslookup
Muestra el número del Sistema Autónomo (AS) junto a cada salto. Equivalente a --ipinfo 0.
Ejemplo (las columnas de la derecha no se muestran por claridad): 
1. AS???   r-76520-PROD.greenqloud.internal
2. AS51969 46.149.16.4
3. AS???   172.31.1.16
4. AS30818 82.221.168.236
5. ???
6. AS???   rix-k2-gw.isnic.is
7. AS1850  www.isnic.is
--ipinfo_provider4 DOMAIN
Proveedor para búsquedas de AS IPv4. El valor predeterminado es origin.asn.cymru.com.
--ipinfo_provider6 DOMAIN
Proveedor para búsquedas de AS IPv6. El valor predeterminado es origin6.asn.cymru.com.
-i SEGUNDOS, --interval SEGUNDOS
Utilice esta opción para especificar el número positivo de segundos entre solicitudes de ICMP ECHO. El valor predeterminado para este parámetro es un segundo. El usuario root puede elegir valores entre cero y uno.
-c CONTADOR, --report-cycles CONTADOR
Utilice esta opción para establecer el número de pings enviados para determinar tanto las máquinas en la red como la fiabilidad de esas máquinas. Cada ciclo dura un segundo.
-s TAMAÑOPAQUETE, --psize TAMAÑOPAQUETE
Esta opción establece el tamaño del paquete utilizado para sondeos. Está en bytes, incluyendo las cabeceras IP e ICMP.

Si se establece a un número negativo, cada iteración usará un tamaño de paquete aleatorio diferente hasta ese número.

-B NUM, --bitpattern NUM
Especifica el patrón de bits a usar en la carga útil. Debe estar en el rango 0 - 255. Si NUM es mayor que 255, se usa un patrón aleatorio.
-G SEGUNDOS, --gracetime SEGUNDOS
Utilice esta opción para especificar el número positivo de segundos a esperar por respuestas después de la última solicitud. El valor predeterminado es cinco segundos.
-Q NUM, --tos NUM
Especifica el valor para el campo tipo de servicio en la cabecera IP. Debe estar en el rango 0 - 255.
-e, --mpls
Utilice esta opción para indicar a mtr que muestre información de las extensiones ICMP para MPLS (RFC 4950) que están codificadas en los paquetes de respuesta.
-I NOMBRE, --interface NOMBRE
Utilice la interfaz de red con un nombre específico para enviar sondeos de red. Esto puede ser útil cuando tiene varias interfaces de red con rutas a su destino, por ejemplo, Ethernet cableada y WiFi, y desea probar una interfaz en particular.
-a DIRECCION, --address DIRECCION
Utilice esta opción para vincular el socket de salida a DIRECCION, de modo que todos los paquetes se envíen con DIRECCION como dirección de origen. Tenga en cuenta que esta opción no se aplica a las solicitudes DNS (lo que puede ser o no lo que desea).
-f NUM, --first-ttl NUM
Especifica con qué TTL comenzar. El valor predeterminado es 1.
-m NUM, --max-ttl NUM
Especifica el número máximo de saltos (valor máximo de tiempo de vida) que traceroute sondeará. El valor predeterminado es 30.
-U NUM, --max-unknown NUM
Especifica el número máximo de hosts desconocidos. El valor predeterminado es 5.
-E NUM, --max-display-path NUM
Especifica el número máximo de rutas ECMP a mostrar. El valor predeterminado es 8.
-u, --udp
Utiliza datagramas UDP en lugar de ICMP ECHO.
-T, --tcp
Utiliza paquetes TCP SYN en lugar de ICMP ECHO. TAMAÑOPAQUETE se ignora, ya que los paquetes SYN no pueden contener datos.
-S, --sctp
Utiliza paquetes del protocolo de transmisión de control de flujo (SCTP) en lugar de ICMP ECHO.
-P PUERTO, --port PUERTO
El número de puerto de destino para rastreos TCP/SCTP/UDP.
-L PUERTOORIGEN, --localport PUERTOORIGEN
El número de puerto de origen para rastreos UDP.
-Z SEGUNDOS, --timeout SEGUNDOS
El número de segundos que se deben mantener abiertos los sockets de sondeo antes de abandonar la conexión. El uso de valores grandes para esto, especialmente combinado con un intervalo corto, consumirá muchos descriptores de archivos.
-M MARCA, --mark MARCA
Establece la marca para cada paquete enviado a través de este socket, similar al objetivo MARK de netfilter pero basado en el socket. MARCA es un entero sin signo de 32 bits. Consulte socket(7) para una descripción completa de esta opción de socket.

AMBIENTE

mtr reconoce algunas variables de entorno.

MTR_OPTIONS
Esta variable de entorno permite especificar opciones, como si se hubieran pasado en la línea de comandos. Se analiza antes de leer las opciones reales de la línea de comandos, por lo que las opciones especificadas en MTR_OPTIONS se ven anuladas por las opciones de la línea de comandos.

Ejemplo:

MTR_OPTIONS="-4 -c 1" mtr -6 localhost

enviaría una sonda (debido a -c 1) hacia ::1 (debido a -6, que anula el -4 pasado en MTR_OPTIONS).

MTR_PACKET
Una ruta al ejecutable mtr-packet, que se utilizará para enviar y recibir sondeos de red. Si MTR_PACKET no está establecido, se utilizará el PATH para buscar un ejecutable mtr-packet.
DISPLAY
Especifica un servidor X11 para el frontend GTK+.

CONTROL INTERACTIVO

mtr puede controlarse mientras se ejecuta con las siguientes teclas:
?|h ayuda
p pausa (barra espaciadora para reanudar)
d cambia el modo de visualización
e activa/desactiva información MPLS
n activa/desactiva DNS
r reinicia todos los contadores
o str establece las columnas a mostrar, el valor predeterminado es str='LRS N BAWV'
j alterna estadísticas de latencia (LS NABWV) / jitter (DR AGJMXI)
c <n> informa el ciclo n, el valor predeterminado n=infinito
i <n> establece el intervalo de ping a n segundos, el valor predeterminado n=1
f <n> establece el tiempo de vida inicial (ttl), el valor predeterminado n=1
m <n> establece el tiempo de vida máximo, el valor predeterminado n= # de saltos
s <n> establece el tamaño del paquete a n o aleatorio (n<0)
b <c> establece el patrón de bits del ping a c (0..255) o aleatorio (c<0)
Q <t> establece el TOS del paquete de ping a t
u alterna entre datagramas ICMP ECHO y UDP
y alterna información IP
z activa/desactiva información ASN
q salir

ERRORES

Algunos enrutadores modernos dan una prioridad menor a los paquetes ICMP ECHO que a otro tráfico de red. En consecuencia, la fiabilidad de estos enrutadores informada por mtr será significativamente menor que la fiabilidad real de estos enrutadores.
