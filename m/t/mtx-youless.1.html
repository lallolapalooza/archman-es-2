NOMBRE


mtx-youless - Obtenedor de youless

SINOPSIS

mtxrun --script youless [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVOS ]

DESCRIPCIÓN

Obtenedor de youless

OPCIONES

--collect
recopilar datos del dispositivo
--nobackup
no hacer copia de seguridad del antiguo archivo de datos
--nofile
no escribir datos en el archivo (para comprobar)
--electricity
datos de electricidad recopilados (p)
--gas
datos de gas recopilados
--pulse
datos de electricidad recopilados (s)
--host
dirección IP del dispositivo
--auto
obtener (refrescar) todos los datos cada hora
