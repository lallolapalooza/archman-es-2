NOMBRE


mtx-kpse - Utilidad de comprobación KPSE de ConTeXt

SINOPSIS

mtxrun --script kpse [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Utilidad de comprobación KPSE de ConTeXt

OPCIONES: BÁSICAS

--progname
obligatorio, establece el nombre del programa (ej. pdftex)
--findfile
informa la ruta completa del archivo dado
--findfiles
informa una lista de todos los nombres completos del archivo dado
--expandpath
expande la variable de ruta dada
--expandvar
expande una variable
--expandbraces
expande una especificación de variable compleja
--varvalue
muestra el valor de una variable
--readablefile
informa si un archivo es legible
--filetypes
lista todos los formatos soportados

OPCIONES: ADICIONALES

--format
tipo de formato
--path
variable de ruta
--split
divide el resultado en líneas

AUTOR
