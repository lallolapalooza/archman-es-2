NAME


mtx-context - ConTeXt Process Management

SYNOPSIS

mtxrun --script context [ OPTIONS ... ] [ FILENAMES ]

DESCRIPTION

ConTeXt Process Management

OPTIONS: BASIC

--run
procesar (uno o más) archivos (acción por defecto)
--make
crear formatos de contexto
--ctx=name
usar archivo ctx (especificación de gestión de procesos)
--noctx
ignorar directivas y flags de ctx
--interface
usar la interfaz de usuario especificada (por defecto: en)
--autopdf
cerrar el archivo pdf en el visor e iniciar el visor de pdf después
--purge
purgar archivos o no después de una ejecución (--pattern=...)
--purgeall
purgar todos los archivos o no después de una ejecución (--pattern=...)
--usemodule=list
cargar el módulo o estilo dado, normalmente parte de la distribución
--environment=list
cargar primero el archivo de entorno dado (estilos de documento)
--mode=list
habilitar los modos dados (procesamiento condicional en estilos)
--path=list
consultar también las rutas dadas cuando se buscan archivos
--arguments=list
establecer variables que pueden ser consultadas durante una ejecución (pares clave/valor)
--randomseed=number
establecer la semilla aleatoria
--result=name
renombrar la salida resultante al nombre dado
--trackers=list
establecer variables de rastreo (mostrar lista con --showtrackers)
--directives=list
establecer variables de directivas (mostrar lista con --showdirectives)
--silent=list
deshabilitar categorías de registro (mostrar lista con --showlogcategories)
--strip
eliminar código Lua (solo para producción donde no se esperan errores)
--errors=list
mostrar errores al final de una ejecución, salir si están en la lista (también cuando --silent)
--htmlerrorpage
generar página de error html en su lugar (opcional: =scite)
--noconsole
deshabilitar el registro en la consola (solo archivo de registro)
--nodummy
no crear un archivo ficticio (puede confundir a los visores de pdf que mantienen el archivo en vista)
--purgeresult
purgar el archivo resultado antes de la ejecución
--find=string
buscar el patrón dado en las fuentes de documentación
--forcexml
forzar stub xml
--forcecld
forzar stub cld (documento lua de contexto)
--forcelua
forzar stub lua (como texlua)
--forcemp
forzar stub mp
--arrange
ejecutar pase de imposición adicional, dado que el estilo configura la imposición
--noarrange
ignorar las especificaciones de imposición en el estilo
--pages
reportar los números de página de las páginas nombradas y listar referencias (--page=... o --page=...)
--jit
usar luajittex con jit desactivado (solo usar la máquina virtual más rápida)
--jiton
usar luajittex con jit activado (en la mayoría de los casos no es más rápido, incluso más lento)
--once
ejecutar solo una vez (no se produce archivo de datos multipase)
--runs
procesar como máximo este número de veces
--forcedruns
procesar este número de veces (permite ejecuciones de prueba de optimización)
--batchmode
ejecutar sin detenerse y no mostrar mensajes en la consola
--nonstopmode
ejecutar sin detenerse
--nocompactfonts
volver al escalado de fuentes menos eficiente (tradicional)
--nosynctex
nunca inicializa synctex (para ejecuciones de producción)
--synctex
ejecutar con synctex habilitado (mejor usar tu synctex[state=start])
--nodates
omitir fechas de tiempo de ejecución en el archivo pdf (valor opcional: un número (desplazamiento de 1970) o cadena "YYYY-MM-DD HH:MM")
--nocompression
desactiva forzosamente la compresión en el backend
--trailerid
id de tráiler alternativo (o uno constante)
--generate
generar base de datos de archivos, etc. (como hace luatools)
--paranoid
no descender a .. y ../..
--version
reportar la versión de contexto instalada
--global
asumir que el archivo dado está presente en otro lugar
--nofile
usar archivo ficticio como nombre de trabajo
--forceinput
usar este archivo como archivo de entrada en lugar del dado
--expert
mostrar algunas opciones más

OPTIONS: EXPERT

--touch
actualizar el número de versión de contexto (también proporcionar --expert, opcionalmente proporcionar --basepath)
--nostatistics
omitir estadísticas de tiempo de ejecución al final de la ejecución
--profile
perfil del trabajo (usar: mtxrun --script profile --analyze)
--timing
generar resumen de tiempos y estadísticas
--keeptuc
mantener archivos tuc anteriores (jobname-tuc-[run].tmp)
--keeppdf
mantener archivos pdf anteriores (jobname-pdf-keep.tmp)
--keeplog
mantener archivos de registro anteriores (jobname-log-[run].tmp)
--notuc
no escribir un archivo tuc
--lmtx
forzar modo lmtx (cuando esté disponible)
