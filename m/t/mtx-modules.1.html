mtx-modules(1) Generadores de Documentación de Módulos de ConTeXt mtx-modules(1)

NOMBRE


mtx-modules - Generadores de Documentación de Módulos de ConTeXt

SINOPSIS

mtxrun --script modules [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Generadores de Documentación de Módulos de ConTeXt

OPCIONES

--convertir
convertir archivos fuente (tex, mkii, mkiv, mp, etc.) a archivos 'ted'
--procesar
procesar archivos fuente (tex, mkii, mkiv, mp, etc.) a archivos 'pdf'
--preparar
usar el nombre original con el sufijo 'prep' añadido
--directo
usar el método antiguo en lugar de extra

AUTOR
