mtx-pdf(1) Ayudantes de PDF de ConTeXt mtx-pdf(1)

NOMBRE


mtx-pdf - Ayudantes de PDF de ConTeXt

SINOPSIS

mtxrun --script pdf [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVO ]

DESCRIPCIÓN

Ayudantes de PDF de ConTeXt

OPCIONES

--info
mostrar información sobre el archivo dado
--metadata
mostrar el blob XML de metadatos
--formdata
mostrar datos de formulario
--pretty
reemplazar saltos de línea en metadatos
--fonts
mostrar fuentes usadas (--detail)
--object
mostrar objeto
--links
mostrar enlaces
--highlights
mostrar resaltados
--comments
mostrar comentarios
--sign
firmar documento (asume plantilla de firma)
--verify
verificar documento
--detail
imprimir detalles en la consola
--userdata
imprimir datos de usuario en la consola

AUTOR
