mtxrun(1) Herramienta de ejecución de ConTeXt TDS mtxrun(1)

NOMBRE


mtxrun - Herramienta de ejecución de ConTeXt TDS

SINOPSIS

mtxrun [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Herramienta de ejecución de ConTeXt TDS

OPCIONES

--script
ejecuta un script mtx (método preferido lua) (--noquotes), no tener script muestra una lista
--evaluate
ejecuta código pasado por línea de comandos (entre comillas) (=loop) (exit|quit abortan)
--execute
ejecuta un script o programa (método texmfstart) (--noquotes)
--resolve
resuelve argumentos con prefijo
--ctxlua
ejecuta internamente (usando librerías precargadas)
--internal
ejecuta un script usando librerías incorporadas (igual que --ctxlua)
--locate
localiza un archivo dado en la base de datos (por defecto) o en el sistema (--first --all --detail)
--tree=rutadelárbol
usa el árbol texmf dado (archivo por defecto: setuptex.tmf)
--path=rutadeejecución
ir a la ruta dada antes de la ejecución
--ifchanged=archivo
solo ejecuta si el archivo dado ha cambiado (checksum md)
--iftouched=viejo,nuevo
solo ejecuta si el archivo dado ha cambiado (marca de tiempo)
--makestubs
crea stubs para scripts (relacionados con context)
--removestubs
elimina stubs para scripts (relacionados con context)
--stubpath=rutabinaria
rutas donde se escribirán los stubs
--windows
crea stubs para windows (mswin)
--unix
crea stubs para unix (linux)
--addbinarypath
prepone la rutabinaria (encontrada) a los runners
--verbose
da un poco más de información
--trackers=lista
habilita los trackers dados
--progname=str
formato o backend
--systeminfo=str
muestra el sistema operativo actual, procesador, etc.
--edit
lanza el editor con el archivo encontrado
--launch
lanza archivos como manuales, asume soporte del SO (--all,--list)
--timedrun
ejecuta un script y mide su tiempo de ejecución
--autogenerate
regenera bases de datos si es necesario (útil cuando se usa para ejecutar context en un editor)
--usekpse
usa kpse como fallback (cuando no hay mkiv y la caché está instalada, a menudo más lento)
--forcekpse
fuerza el uso de kpse (útil cuando no hay mkiv y la caché no está instalada, pero con menos funcionalidad)
--prefixes
muestra los prefijos soportados
--generate
genera la base de datos de archivos
--variables
muestra las variables de configuración
--configurations
muestra el orden de configuración
--directives
muestra las directivas (conocidas)
--trackers
muestra los trackers (conocidos)
--experiments
muestra los experimentos (conocidos)
--expand-braces
expande variables complejas
--resolve-path
expande variable (resuelve completamente las rutas)
--expand-path
expande variable (resuelve rutas)
--expand-var
expande variable (resuelve referencias)
--show-path
muestra la expansión de ruta de ...
--var-value
reporta el valor de una variable
--find-file
reporta la ubicación de un archivo
--find-path
reporta la ruta de un archivo
--pattern=cadena
filtra variables
