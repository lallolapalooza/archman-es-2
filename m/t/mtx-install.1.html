NOMBRE


mtx-install - Instalador de ConTeXt

SINOPSIS

mtxrun --script install [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVO ]

DESCRIPCIÓN

Instalador de ConTeXt

OPCIONES

--platform=string
plataforma
--server=string
url del repositorio (rsync://contextgarden.net)
--modules=string
módulos extra (puede ser una lista o 'all')
--fonts=string
fuentes adicionales (puede ser una lista o 'all')
--goodies=string
binarios extra (como scite y texworks)
--install
instalar context
--update
actualizar context
--erase
borrar la caché
--identify
crear lista de archivos
--secure
usar curl para https

AUTOR

Más información sobre ConTeXt y las herramientas que vienen con él se puede encontrar en:

lista de correo: ntg-context@ntg.nl / http://www.ntg.nl/mailman/listinfo/ntg-context

página web: http://www.pragma-ade.nl / http://tex.aanhet.net

wiki: http://contextgarden.net
