mtx-interface(1) Utilidades relacionadas con la interfaz de ConTeXt mtx-interface(1)

NOMBRE


mtx-interface - Utilidades relacionadas con la interfaz de ConTeXt

SINOPSIS

mtxrun --script interface [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Utilidades relacionadas con la interfaz de ConTeXt

OPCIONES

--scite
generar interfaz scite
--bbedit
generar archivos de interfaz bbedit
--jedit
generar archivos de interfaz jedit
--textpad
generar archivos de interfaz textpad
--vim
generar archivos de interfaz vim
--text
crear archivos de texto para comandos y entornos
--raw
reportar comandos a la consola
--check
generar archivo de verificación
--meaning
reportar el significado de los comandos
--tokens
mostrar la representación interna de los comandos
--toutf
reemplazar caracteres nombrados por utf
--preprocess
preprocesar archivos mkvi a archivos tex [forzar,sufijo]
--suffix
usar el sufijo dado para los archivos de salida
--force
forzar acción incluso en caso de duda
--pattern
un patrón para búsquedas de significado

AUTOR

Se puede encontrar más información sobre ConTeXt y las herramientas que vienen con él en:
