NOMBRE


mtx-tools - Algunas utilidades relacionadas con archivos

SINOPSIS

mtxrun --script tools [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Algunas utilidades relacionadas con archivos

OPCIONES

--uncompress
descomprimir usando qpdf
--validate
validar usando verapdf
--check
comprobar resultado de la verificación
--convert
convertir usando contexto
--compare
comparar resultado con el original
--compactor
usar el compactador dado
--standard
usar el estándar dado
--pattern
procesar archivos según el patrón
--silent
suprimir mensajes
--once
ejecutar solo una vez
--resolution
usar esta resolución al comparar

AUTOR
