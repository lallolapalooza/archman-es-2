MAKEPKG.CONF(5) Manual de Pacman MAKEPKG.CONF(5)

NOMBRE

makepkg.conf - archivo de configuración de makepkg

SINOPSIS

/etc/makepkg.conf, $XDG_CONFIG_HOME/pacman/makepkg.conf, ~/.makepkg.conf

DESCRIPCIÓN

Las opciones de configuración para makepkg se almacenan en makepkg.conf. Este archivo se incluye, por lo que puede añadir cualquier bandera especial del compilador que desee utilizar. Esto es útil al compilar para diferentes arquitecturas o con diferentes optimizaciones. Sin embargo, solo las variables descritas a continuación se exportan al entorno de compilación.


Nota

Esto no garantiza que todos los Makefiles de los paquetes utilicen sus variables exportadas. Algunos de ellos no son estándar.

El archivo de configuración a nivel de sistema se encuentra en /etc/makepkg.conf. Se pueden colocar adiciones específicas (por ejemplo, banderas de compilación para idiomas adicionales) en /etc/makepkg.conf.d/*.conf.

Las opciones individuales pueden ser anuladas (o añadidas) por usuario en $XDG_CONFIG_HOME/pacman/makepkg.conf o ~/.makepkg.conf, teniendo la primera prioridad.

El archivo predeterminado está bastante bien comentado, por lo que puede resultar más fácil seguir las instrucciones dadas allí para personalizarlo.

OPCIONES

DLAGENTS=("protocolo::/ruta/al/comando [opciones]" ...)

Establece los agentes de descarga utilizados para obtener archivos fuente especificados con una URL en el archivo PKGBUILD(5). Se pueden especificar opciones para cada comando, y cualquier protocolo puede tener un agente de descarga. Se requiere escapar los espacios en los argumentos de las opciones para evitar que se dividan. Varios ejemplos se proporcionan en el makepkg.conf predeterminado.

Si está presente, %u se reemplazará con la URL de descarga. De lo contrario, la URL de descarga se colocará al final del comando. Si está presente, %o se reemplazará con el nombre del archivo local, más una extensión ".part", lo que permite a makepkg gestionar la reanudación de las descargas de archivos.

VCSCLIENTS=("protocolo::paquete" ...)

Establece los paquetes necesarios para obtener archivos fuente controlados por versión. Cuando sea necesario, makepkg comprobará que estos paquetes están instalados o se incluyen en los arrays depends o makedepends en el PKGBUILD.

CARCH="carch"

Especifica la arquitectura de su ordenador; los valores posibles incluyen cosas como "i686", "x86_64", "ppc", etc. Esto debería configurarse automáticamente en la instalación.

CHOST="chost"

Una cadena como "i686-pc-linux-gnu"; no toque esto a menos que sepa lo que está haciendo. La mayoría de los usuarios pueden comentar esto si lo desean.

CPPFLAGS="cppflags"

Banderas utilizadas para el preprocesador C; consulte CFLAGS para más información.

CFLAGS="cflags"

Banderas utilizadas para el compilador C. Esta es una parte clave del uso de makepkg. Normalmente se especifican varias opciones, y la cadena más común se parece a esto: "-march=i686 -O2 -pipe". Otra opción útil puede ser -mcpu en lugar de -march. Lea gcc(1) para obtener más detalles sobre la gran variedad de banderas del compilador disponibles.

CXXFLAGS="cxxflags"

Banderas utilizadas para el compilador C++; consulte CFLAGS para más información.

LDFLAGS="ldflags"

Banderas utilizadas para el enlazador. Se pueden especificar varias opciones con un uso común parecido a "-Wl,--hash-style=gnu". Lea ld(1) para obtener más detalles sobre las banderas del enlazador disponibles.

LTOFLAGS="ltoflags"

Banderas adicionales del compilador y enlazador añadidas a CFLAGS, CXXFLAGS y LDFLAGS al compilar con optimización en tiempo de enlace. Si está vacío, se utiliza "-flto".

MAKEFLAGS="makeflags"

Esto se usa a menudo para establecer el número de trabajos utilizados; por ejemplo, -j2. También se pueden pasar otras banderas que acepte make.

DEBUG_CFLAGS="debug_cflags"

Banderas del compilador adicionales añadidas a CFLAGS para usarlas en la depuración. Normalmente incluiría: "-g". Lea gcc(1) para obtener más detalles sobre la gran variedad de banderas del compilador disponibles.

DEBUG_CXXFLAGS="debug_cxxflags"

Banderas de depuración utilizadas para el compilador C++; consulte DEBUG_CFLAGS para más información.

BUILDENV=(!distcc !color !ccache check !sign)

Este array contiene opciones que afectan al entorno de compilación; se muestran los valores predeterminados. Todas las opciones siempre deben dejarse en el array; para habilitar o deshabilitar una opción, simplemente elimine o añada un "!" al principio de la opción. Si una opción se especifica varias veces, el último valor tiene prioridad. Cada opción funciona de la siguiente manera:

distcc

Utiliza el compilador distribuido C/C++/ObjC para repartir la compilación entre varias máquinas. Si esto está habilitado, DISTCC_HOSTS debe especificarse también.

color

Colorea los mensajes de salida, haciendo la salida más fácil de leer.

ccache

Utiliza ccache para almacenar en caché la compilación por defecto. Esto permite compilaciones más rápidas si recompila continuamente los mismos paquetes. Se puede deshabilitar para paquetes individuales colocando !ccache en el array de opciones del PKGBUILD.

check

Ejecuta la función check() si está presente en el PKGBUILD. Esto se puede habilitar o deshabilitar para paquetes individuales mediante el uso de las opciones --check y --nocheck de makepkg, respectivamente.

sign

Genera un archivo de firma PGP usando GnuPG. Esto ejecutará gpg --detach-sign en el paquete compilado para generar un archivo de firma separado, utilizando el agente GPG, si está disponible. El archivo de firma será el nombre completo del archivo del paquete con una extensión ".sig".

DISTCC_HOSTS="host1 ..."

Si se utiliza DistCC, esto se usa para especificar una lista separada por espacios de hosts que ejecutan en el clúster DistCC. Además, querrá modificar sus MAKEFLAGS.

BUILDDIR="/ruta/al/directorio"

Si este valor no está establecido, los paquetes se compilarán, por defecto, en subdirectorios del directorio desde el que se llama a makepkg. Esta opción permite establecer la ubicación de compilación en otro directorio. El uso incorrecto de $startdir en un PKGBUILD puede hacer que la compilación con esta opción falle.

GPGKEY=""

Especifica una clave a utilizar para la firma GPG en lugar de la clave predeterminada en el llavero. Puede ser anulada con la opción --key de makepkg.

OPTIONS=(!strip docs libtool staticlibs emptydirs ...)

Este array contiene opciones que afectan a los paquetes predeterminados. Son equivalentes a las opciones que se pueden colocar en el PKGBUILD; se muestran los valores predeterminados. Todas las opciones siempre deben dejarse en el array; para habilitar o deshabilitar una opción, simplemente elimine o añada un "!" al principio de la opción. Si una opción se especifica varias veces, el último valor tiene prioridad. Cada opción funciona de la siguiente manera:

strip

Elimina símbolos de binarios y bibliotecas. Si utiliza frecuentemente un depurador en programas o bibliotecas, puede ser útil deshabilitar esta opción.

docs

Guarda directorios de documentación. Si desea eliminar los directorios de documentación, especifique !docs en el array. Los directorios afectados se especifican mediante la variable DOC_DIRS.

libtool

Deja archivos libtool (.la) en los paquetes. Especifique !libtool para eliminarlos.

staticlibs

Deja archivos de biblioteca estática (.a) en los paquetes. Especifique !staticlibs para eliminarlos, si tienen una contraparte compartida.

emptydirs

Deja directorios vacíos en los paquetes.

zipman

Comprime las páginas de manual (man e info) con gzip. Los directorios afectados se especifican mediante la variable MAN_DIRS.

purge

Elimina los archivos especificados por la variable PURGE_TARGETS del paquete.

debug

Añade las banderas de depuración especificadas por el usuario

ags según se especifica en DEBUG_CFLAGS y DEBUG_CXXFLAGS a sus flags de compilación correspondientes. Crea un paquete separado que contiene los símbolos de depuración cuando se usa con «strip».

lto

Habilita la compilación de paquetes usando optimización en tiempo de enlace. Agrega los flags especificados en LTOFLAGS a CFLAGS, CXXFLAGS y LDFLAGS (o «-flto» si LTOFLAGS está vacío).

autodeps

Habilita la adición automática de bibliotecas a los arrays depends y provides. Los directorios de búsqueda de bibliotecas están controlados por la variable LIB_DIRS definida a continuación.

INTEGRITY_CHECK=(check1 ...)

Comprobaciones de integridad de archivos a utilizar. Se pueden especificar múltiples comprobaciones; esto afecta tanto a la generación como a la comprobación. Las opciones actualmente válidas son: ck, md5, sha1, sha224, sha256, sha384, sha512 y b2.

STRIP_BINARIES="--strip-all"

Opciones a utilizar al eliminar (stripping) binarios. Ver strip(1) para detalles.

STRIP_SHARED="--strip-unneeded"

Opciones a utilizar al eliminar bibliotecas compartidas o ejecutables PIE. Ver strip(1) para detalles.

STRIP_STATIC="--strip-debug"

Opciones a utilizar al eliminar bibliotecas estáticas. Ver strip(1) para detalles.

MAN_DIRS=({usr{,/local}{,/share},opt/*}/{man,info} ...)

Si se especifica zipman en el array OPTIONS, esta variable le indicará a makepkg dónde buscar para comprimir las páginas de manual (man y info). Si compila paquetes que se encuentran en opt/, puede que necesite añadir el directorio a este array. NOTA: No añada la barra inclinada inicial al nombre del directorio.

DOC_DIRS=(usr/{,share/}{doc,gtk-doc} ...)

Si se especifica !docs en el array OPTIONS, esta variable le indicará a makepkg dónde buscar para eliminar la documentación. Si compila paquetes que se encuentran en opt/, puede que necesite añadir el directorio a este array. NOTA: No añada la barra inclinada inicial al nombre del directorio.

LIB_DIRS=(lib:usr/lib ...)

Si se especifica autodeps en el array OPTIONS, esta variable le indicará a makepkg dónde buscar para encontrar bibliotecas que añadir al array provides. El formato es «prefijo:ruta», donde se añadirán las provisiones para las bibliotecas encontradas en «ruta» con el prefijo especificado añadido.

PURGE_TARGETS=(usr/{,share}/info/dir .podlist *.pod...)

Si se especifica purge en el array OPTIONS, esta variable le indicará a makepkg qué archivos eliminar del paquete. Esto es útil para archivos de índice que son añadidos por múltiples paquetes.

DBGSRCDIR="/usr/src/debug"

Si se especifican strip y debug en el array OPTIONS, esta variable le indicará a makepkg dónde colocar los archivos fuente para los binarios instalados. Los binarios se modificarán para enlazar este directorio para la ruta de búsqueda del depurador.

PKGDEST="/ruta/al/directorio"

Si este valor no está establecido, los paquetes, por defecto, se colocarán en el directorio actual (ubicación del PKGBUILD(5)). A mucha gente le gusta mantener todos sus paquetes en un solo lugar, por lo que esta opción permite este comportamiento. Una ubicación común es «/home/packages».

SRCDEST="/ruta/al/directorio"

Si este valor no está establecido, los archivos fuente descargados solo se almacenarán en el directorio actual. A mucha gente le gusta mantener todos los archivos fuente en una ubicación central para facilitar su limpieza, por lo que esta ruta se puede establecer aquí.

SRCPKGDEST="/ruta/al/directorio"

Si este valor no está establecido, los archivos de paquete fuente se almacenarán en el directorio actual. A mucha gente le gusta mantener todos los archivos de paquete fuente en una ubicación central para facilitar su limpieza, por lo que esta ruta se puede establecer aquí.

LOGDEST="/ruta/al/directorio"

Si este valor no está establecido, los archivos de registro se escriben en el directorio actual. Esto centraliza la ubicación del registro, facilitando su limpieza y compresión.

PACKAGER="Juan Pérez <juan@ejemplo.com>"

Este valor se utiliza al consultar un paquete para ver quién fue el constructor. El formato dado es necesario para la búsqueda de claves PGP a través de WKD. Se recomienda cambiarlo por su nombre y dirección de correo electrónico.

COMPRESSGZ="(gzip -c -f -n)", COMPRESSBZ2="(bzip2 -c -f)", COMPRESSXZ="(xz -c -z -)", COMPRESSZST="(zstd -c -z -)", COMPRESSLZO"(lzop -q)", COMPRESSLRZ="(lrzip -q)", COMPRESSLZ4="(lz4 -q)", COMPRESSZ="(compress -c -f)", COMPRESSLZ="(lzip -c -f)"

Establece el comando y las opciones utilizadas al comprimir paquetes compilados o fuente en el formato nombrado.

PKGEXT=".pkg.tar.gz", SRCEXT=".src.tar.gz"

Establece la compresión utilizada al crear paquetes compilados o fuente. Los sufijos válidos son .pkg o .src (para PKGEXT y SRCEXT respectivamente) seguidos de uno de .tar.gz, .tar.bz2, .tar.xz, .tar.zst, .tar.lzo, .tar.lrz, .tar.lz4, .tar.lz y .tar.Z, o simplemente .tar para deshabilitar la compresión completamente.

PACMAN_AUTH=()

Especifica un prefijo de comando para ejecutar pacman como root. Si no está establecido, makepkg verificará la presencia de sudo(8) y su(1) por turnos, y probará el primero que encuentre.

Si está presente, %c se reemplazará con la forma entre comillas del shell del comando a ejecutar. De lo contrario, el comando a ejecutar se añadirá al comando de autenticación.
