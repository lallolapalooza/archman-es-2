malloc_get_state(3) Manual de Funciones de Biblioteca malloc_get_state(3)

NOMBRE

malloc_get_state, malloc_set_state - registrar y restaurar el estado de la implementación de malloc

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <malloc.h>
void *malloc_get_state(void);
int malloc_set_state(void *state);

DESCRIPCIÓN

Nota: estas funciones fueron eliminadas en glibc 2.25.

La función malloc_get_state() registra el estado actual de todas las variables internas de contabilidad de malloc(3) (pero no el contenido real del heap ni el estado de los punteros de función de malloc_hook(3)). El estado se registra en una estructura de datos opaca dependiente del sistema asignada dinámicamente mediante malloc(3), y se devuelve un puntero a esa estructura de datos como resultado de la función. (Es responsabilidad del llamador liberar esta memoria con free(3)).

La función malloc_set_state() restaura el estado de todas las variables internas de contabilidad de malloc(3) a los valores registrados en la estructura de datos opaca apuntada por state.

VALOR DE RETORNO

En caso de éxito, malloc_get_state() devuelve un puntero a una estructura de datos opaca recién asignada. En caso de error (por ejemplo, si no se pudo asignar memoria para la estructura de datos), malloc_get_state() devuelve NULL.

En caso de éxito, malloc_set_state() devuelve 0. Si la implementación detecta que state no apunta a una estructura de datos correctamente formada, malloc_set_state() devuelve -1. Si la implementación detecta que la versión de la estructura de datos a la que se refiere state es una versión más reciente de la que esta implementación conoce, malloc_set_state() devuelve -2.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
malloc_get_state (), malloc_set_state () Seguridad de hilos MT-Safe

ESTANDARES

GNU.

NOTAS

Estas funciones son útiles cuando se utiliza esta implementación de malloc(3) como parte de una biblioteca compartida, y el contenido del heap se guarda/restaura mediante algún otro método. Esta técnica es utilizada por GNU Emacs para implementar su función de "volcado" ("dumping").

Los punteros de función de hook nunca son guardados o restaurados por estas funciones, con dos excepciones: si la comprobación de malloc (ver mallopt(3)) estaba en uso cuando se llamó a malloc_get_state(), entonces malloc_set_state() restablece los hooks de comprobación de malloc si es posible; si la comprobación de malloc no estaba en uso en el estado registrado, pero el llamador ha solicitado la comprobación de malloc, entonces los hooks se restablecen a 0.

VER TAMBIÉN

malloc(3), mallopt(3)
