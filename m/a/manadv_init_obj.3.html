manadv_init_obj(3) Manual de funciones de biblioteca manadv_init_obj(3)

NOMBRE

manadv_init_obj - Inicializar objeto de verbos directos de mana a partir de estructuras ibv_xxx

SINOPSIS”

#include <infiniband/manadv.h>
int manadv_init_obj(struct manadv_obj *obj, uint64_t obj_type);

DESCRIPCIÓN

manadv_init_obj() Esta función inicializará las estructuras manadv_xxx basándose en el tipo proporcionado. La información para la inicialización se toma de las estructuras ibv_xx proporcionadas como entrada.

ARGUMENTOS

obj
Las estructuras manadv_xxx a devolver.
struct manadv_qp {
    void        *sq_buf;
    uint32_t    sq_count;
    uint32_t    sq_size;
    uint32_t    sq_id;
    uint32_t    tx_vp_offset;
    void        *db_page;
};
struct manadv_cq {
    void        *buf;
    uint32_t    count;
    uint32_t    cq_id;
};
struct manadv_rwq {
    void        *buf;
    uint32_t    count;
    uint32_t    size;
    uint32_t    wq_id;
    void        *db_page;
};
struct manadv_obj {
    struct {
        struct ibv_qp       *in;
        struct manadv_qp    *out;
    } qp;
    struct {
        struct ibv_cq       *in;
        struct manadv_cq    *out;
    } cq;
    struct {
        struct ibv_wq       *in;
        struct manadv_rwq   *out;
    } rwq;
};
obj_type
Los tipos de las estructuras manadv_xxx a devolver.
enum manadv_obj_type {
    MANADV_OBJ_QP   = 1 << 0,
    MANADV_OBJ_CQ   = 1 << 1,
    MANADV_OBJ_RWQ  = 1 << 2,
};

VALOR DE RETORNO

0 en caso de éxito o el valor de errno en caso de error (que indica la razón del fallo).
