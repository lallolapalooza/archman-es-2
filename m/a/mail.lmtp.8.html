MAIL.LMTP(8) Manual del Administrador del Sistema MAIL.LMTP(8)

NOMBRE

mail.lmtp — entrega correo a través de LMTP

SINOPSIS

mail.lmtp [-d destino] [-f remitente] [-l lhlo] usuario ...

DESCRIPCIÓN

mail.lmtp lee la entrada estándar hasta un fin de archivo y la entrega a un servidor LMTP para cada dirección de usuario. El usuario debe ser un nombre de usuario o dirección de correo electrónico válido.

Las opciones son las siguientes:

-d destino
Especifica la dirección LMTP de destino.
-f remitente
Especifica el nombre o dirección de correo electrónico del remitente.
-l lhlo
Especifica el argumento LHLO utilizado en la sesión LMTP. Por defecto, mail.lmtp utilizará "localhost".

CÓDIGO DE SALIDA

La utilidad mail.lmtp sale 0 en caso de éxito y >0 si ocurre un error.

VER TAMBIÉN

mail(1), smtpd(8)
