NOMBRE

makechrootpkg - Compila un PKGBUILD en un entorno chroot dado

SINOPSIS

makechrootpkg [OPCIONES] -r <chrootdir> [--] [argumentos de makepkg]

DESCRIPCIÓN

Ejecuta este script en un directorio que contenga un PKGBUILD para compilar un paquete dentro de un chroot limpio. Los argumentos pasados a este script después del marcador de fin de opciones (--) se pasarán a makepkg.

El directorio chroot consta de los siguientes directorios: <chrootdir>/root, <chrootdir>/copy, pero solo "root" es requerido por defecto. La copia de trabajo se creará según sea necesario.

El directorio "root" del chroot debe crearse con el siguiente comando: mkarchroot <chrootdir>/root base-devel

Este script lee {SRC,SRCPKG,PKG,LOG}DEST, MAKEFLAGS y PACKAGER de makepkg.conf(5), si esas variables no forman parte del entorno.

Argumentos por defecto de makepkg: --syncdeps --noconfirm --log --holdver --skipinteg

OPCIONES

-h

Muestra este mensaje de uso

-c

Limpia el chroot antes de compilar

-d <dir>

Monta el directorio en el chroot de compilación como lectura-escritura

-D <dir>

Monta el directorio en el chroot de compilación como solo lectura

-t <dir>[:opts]

Monta un tmpfs en dir. Ver el argumento --tmpfs en systemd-nspawn(1) para más detalles.

-u

Actualiza la copia de trabajo del chroot antes de compilar. Esto es útil para recompilaciones sin ensuciar el chroot prístino.

-r <dir>

El directorio chroot a usar

-I <pkg>

Instala un paquete en la copia de trabajo del chroot

-l <copy>

El directorio a usar como copia de trabajo del chroot. Útil para mantener múltiples copias. Por defecto: $USER

-n

Ejecuta namcap en el paquete compilado

-C

Ejecuta checkpkg en el paquete compilado

-T

Compila en un directorio temporal

-U

Ejecuta makepkg como un usuario especificado

-x <when>

Inspecciona el chroot después de compilar. Modos posibles: never (por defecto), always o failure

VER TAMBIÉN

systemd-nspawn(1)
