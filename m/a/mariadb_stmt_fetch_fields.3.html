Nombre

mariadb_stmt_fetch_fields - Devuelve un array de campos que contienen las definiciones de las columnas ## Sinopsis

#include <mysql.h>
MYSQL_FIELD *mariadb_stmt_fetch_fields(MYSQL_STMT * stmt);

Descripción

Devuelve un array de campos. Cada campo contiene la definición de una columna del conjunto de resultados. Si la sentencia no tiene un conjunto de resultados, se devolverá un puntero NULL.

Parámetro

•
stmt - Un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).

Notas

El número de campos se puede obtener mediante mysql_stmt_field_count(3)

Historial

Esta función se añadió en MariaDB Connector/C 3.1.0

Ver también

*mysql_stmt_field_count(3)
