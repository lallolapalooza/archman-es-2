NOMBRE

mate-control-center - Configura los ajustes de MATE

SINOPSIS

mate-control-center [OPCIÓN...]

DESCRIPCIÓN

mate-control-center es una interfaz gráfica de usuario para configurar diversos aspectos de MATE.

Cuando se ejecuta sin argumentos, el shell muestra la vista general del centro de control, que muestra todos los paneles de configuración disponibles. La vista general permite abrir paneles individuales haciendo clic en ellos. También tiene un campo de búsqueda para encontrar paneles buscando palabras clave.

OPCIONES

-?, --help
Imprime las opciones de ayuda de la aplicación y sale.
--help-gtk
Imprime la ayuda de las opciones GTK y sale.
--help-all
Imprime la ayuda de la aplicación y de las opciones GTK y sale.
--hide
Ocultar al iniciar (útil para precargar el shell).
--display=PANTALLA
Pantalla X a usar.

Este programa acepta adicionalmente las opciones estándar de MATE y GTK (como las listadas con --help-gtk).

CÓDIGO DE SALIDA

En caso de éxito se devuelve 0, un código de error distinto de cero en caso contrario.
