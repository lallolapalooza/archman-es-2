mariadb_stmt_execute_direct(3)

Paquete: mariadb

Licencias: GPL-2.0-only

mariadb_stmt_execute_direct(3) Connector/C de MariaDB mariadb_stmt_execute_direct(3)

Nombre

mariadb_stmt_execute_direct - prepara y ejecuta una sentencia preparada

Sinopsis

#include <mysql.h>
int mariadb_stmt_execute_direct(MYSQL_STMT * stmt,
                                const char *query,
                                size_t length);

Descripción

Prepara y ejecuta una sentencia que fue previamente asignada por mysql_stmt_init(3), utilizando los valores actuales de las variables de parámetro si existen parámetros en la sentencia.

Parámetros

•
stmt - Un manejador de sentencia, que fue previamente asignado por mysql_stmt_init(3).
•
query Sentencia SQL
•
length Longitud de la sentencia SQL

Valor de retorno

Devuelve cero si tiene éxito, un valor distinto de cero si falla.

Notas

•
Dado que el número de parámetros de la sentencia es desconocido antes de la ejecución, es obligatorio establecer el número de parámetros a través de la función mysql_stmt_attr_set(3).
•
Si la sentencia SQL es una cadena terminada en nulo, también puedes pasar -1 como longitud.
•
El manejador de sentencia está destinado a una ejecución única. Reutilizar el manejador de sentencia puede llevar a un comportamiento inesperado.

Historial

Esta función se añadió en Connector/C 3.0 y requiere MariaDB 10.2 o versiones posteriores.

Ver también

•
mysql_stmt_attr_set(3)
•
mysql_stmt_bind_param(3)

Ejemplo

```C static int execute_direct_example(MYSQL mysql) { MYSQL_STMT stmt= mysql_stmt_init(mysql); MYSQL_BIND bind[2]; int intval= 1; int param_count= 2; char *strval= “execute_direct_example”;

/* Ejecución directa sin parámetros */ if (mariadb_stmt_execute_direct(stmt, “CREATE TABLE execute_direct (a int, b varchar(30))”, -1)) goto error;

memset(&bind, 0, sizeof(MYSQL_BIND) * 2); bind[0].buffer_type= MYSQL_TYPE_SHORT; bind[0].buffer= &intval; bind[1].buffer_type= MYSQL_TYPE_STRING; bind[1].buffer= strval; bind[1].buffer_length= strlen(strval);

/* establecer número de parámetros */ if (mysql_stmt_attr_set(stmt, STMT_ATTR_PREBIND_PARAMS, &param_count)) goto error;

/* enlazar parámetros */ if (mysql_stmt_bind_param(stmt, bind)) goto error;

if (mariadb_stmt_execute_direct(stmt, “INSERT INTO execute_direct VALUES (?,?)”, -1)) goto error;

mysql_stmt_close(stmt); return 0; error: printf(“Error: %s”, mysql_stmt_error(stmt)); mysql_stmt_close(stmt); return 1; }
