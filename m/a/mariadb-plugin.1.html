NOMBRE

mariadb-plugin - configura los plugins del servidor MariaDB (mariadb-plugin es ahora un enlace simbólico a mariadb-plugin)

SINOPSIS

mariadb-plugin [opciones] plugin {HABILITAR|DESHABILITAR}

DESCRIPCIÓN

La utilidad mariadb-plugin permite a los administradores de MariaDB gestionar qué plugins carga un servidor MariaDB. Proporciona una alternativa a especificar manualmente la opción --plugin-load al inicio del servidor o a usar las sentencias INSTALL PLUGIN y UNINSTALL PLUGIN en tiempo de ejecución.

Dependiendo de si mariadb-plugin se invoca para habilitar o deshabilitar plugins, inserta o elimina filas en la tabla mysql.plugin que sirve como registro de plugins. (Para realizar esta operación, mariadb-plugin invoca al servidor MariaDB en modo de arranque (bootstrap). Esto significa que el servidor no debe estar ya en ejecución). Para los inicios normales del servidor, el servidor carga y habilita automáticamente los plugins listados en mysql.plugin. Para un control adicional sobre la activación de plugins, utilice las opciones --nombre_plugin con nombres de plugins específicos.

Cada invocación de mariadb-plugin lee un archivo de configuración para determinar cómo configurar los plugins contenidos en un único archivo objeto de biblioteca de plugins. Para invocar mariadb-plugin, utilice esta sintaxis:

mariadb-plugin [opciones] plugin {HABILITAR|DESHABILITAR}

plugin es el nombre del plugin a configurar. HABILITAR o DESHABILITAR (no distingue mayúsculas y minúsculas) especifican si se deben habilitar o deshabilitar los componentes de la biblioteca de plugins nombrada en el archivo de configuración. El orden de los argumentos plugin y HABILITAR o DESHABILITAR no importa.

Por ejemplo, para configurar componentes de un archivo de biblioteca de plugins llamado myplugins.so en Linux o myplugins.dll en Windows, especifique un valor plugin de myplugins. Supongamos que esta biblioteca de plugins contiene tres plugins, plugin1, plugin2 y plugin3, todos los cuales deben configurarse bajo el control de mariadb-plugin. Por convención, los archivos de configuración tienen el sufijo .ini y el mismo nombre base que la biblioteca de plugins, por lo que el nombre de archivo de configuración predeterminado para esta biblioteca de plugins es myplugins.ini. El contenido del archivo de configuración se ve así:

myplugins
plugin1
plugin2
plugin3

La primera línea del archivo myplugins.ini es el nombre del archivo objeto de la biblioteca, sin ninguna extensión como .so o .dll. Las líneas restantes son los nombres de los componentes a habilitar o deshabilitar. Cada valor en el archivo debe estar en una línea separada. Las líneas en las que el primer carácter es '#' se consideran comentarios y se ignoran.

Para habilitar los plugins listados en el archivo de configuración, invoque mariadb-plugin de esta manera:

shell> mariadb-plugin myplugins HABILITAR

Para deshabilitar los plugins, use DESHABILITAR en lugar de HABILITAR.

Se producirá un error si mariadb-plugin no puede encontrar el archivo de configuración o el archivo de biblioteca de plugins, o si mariadb-plugin no puede iniciar el servidor MariaDB.

mariadb-plugin admite las siguientes opciones, que se pueden especificar en la línea de comandos o en el grupo [mariadbd] de cualquier archivo de opciones. Para las opciones especificadas en un grupo [mariadbd], mariadb-plugin reconoce las opciones --basedir, --datadir y --plugin-dir e ignora las demás.

Opciones de mariadb-plugin

•--help, -?

Muestra un mensaje de ayuda y sale.

•--basedir=ruta, -b ruta

El directorio base del servidor.

•--datadir=ruta, -d ruta

El directorio de datos del servidor.

•--my-print-defaults=ruta, -b ruta

La ruta al programa my_print_defaults.

•--mariadbd=ruta, -b ruta

La ruta al servidor mariadbd.

•--no-defaults, -p

No lee valores del archivo de configuración. Esta opción permite a un administrador omitir la lectura de valores predeterminados del archivo de configuración.

Con mariadb-plugin, esta opción no necesita darse primero en la línea de comandos, a diferencia de la mayoría de los otros programas de MariaDB que admiten --no-defaults.

•--plugin-dir=ruta, -p ruta

El directorio de plugins del servidor.

•--plugin-ini=nombre_archivo, -i nombre_archivo

El archivo de configuración de mariadb-plugin. Las rutas relativas se interpretan en relación con el directorio actual. Si no se proporciona esta opción, el valor predeterminado es plugin.ini en el directorio de plugins, donde plugin es el argumento plugin en la línea de comandos.

•--print-defaults, -P

Muestra los valores predeterminados del archivo de configuración. Esta opción hace que mariadb-plugin imprima los valores predeterminados para --basedir, --datadir y --plugin-dir si se encuentran en el archivo de configuración. Si no se encuentra ningún valor para una variable, no se muestra nada.

Con mariadb-plugin, esta opción no necesita darse primero en la línea de comandos, a diferencia de la mayoría de los otros programas de MariaDB que admiten --print-defaults.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa. Esta opción se puede utilizar varias veces para aumentar la cantidad de información.

•--version, -V

Muestra información de la versión y sale.

NAME

mariadb-plugin - list available MariaDB plugins

SYNOPSIS

mariadb-plugin [options]

DESCRIPTION

The mariadb-plugin program lists available MariaDB plugins. It can be used to view information about various types of plugins, such as authentication, storage, and general plugins.

OPTIONS

mariadb-plugin accepts the following options:

  • --help: Display a help message and exit.
  • --verbose: Show more detailed information about the plugins.
  • --type=plugin_type: Filter the list to show only plugins of the specified type. Common types include authentication, storage, parser, handler, info, audit, commit, log, compress, clone.

EXAMPLES

List all available plugins:

mariadb-plugin

List only authentication plugins:

mariadb-plugin --type=authentication

List all plugins with verbose output:

mariadb-plugin --verbose
