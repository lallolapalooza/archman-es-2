MAKEIVS-NG(1) Manual de Comandos Generales MAKEIVS-NG(1)

NOMBRE

makeivs - genera un archivo de volcado IVS ficticio con una clave WEP específica

SINOPSIS

makeivs <archivo ivs> <clave de 104 bits>

DESCRIPCIÓN

makeivs-ng es una herramienta diseñada para generar un archivo de volcado IVS con una clave WEP introducida. El objetivo de esta herramienta es proporcionar una forma de crear volcados con una clave de cifrado conocida para pruebas.

OPCIONES

Opciones comunes:
-b <bssid> o --bssid <bssid>
Establece la BSSID (MAC del Punto de Acceso).
-f <num> o --first <num>
Valor para el primer IV generado.
-k <clave> o --key <clave>
Clave WEP de la red objetivo en hexadecimal. Se aceptan separadores entre bytes, pero no son necesarios.
-s <num> o --seed <num>
Semilla utilizada para configurar el generador de números aleatorios. Puede usarse en combinación con -p o --prng.
-w <archivo> o --write <archivo>
Nombre del archivo donde se escribirán los IVs.
-c <num> o --count <num>
Cantidad de IVs a generar. Valor por defecto: 100000.
-d <num> o --dupe <num>
Porcentaje de IVs duplicados.
-e <num> o --error <num>
Porcentaje de secuencias de claves erróneas.
-l <num> o --length <num>
Tamaño de las secuencias de claves. Por defecto: 16 bytes.
-n o --nofms
Ignora IVs débiles.
-p o --prng
Utiliza valores aleatorios al generar IVs. Por defecto, utiliza valores secuenciales.
--help
Muestra la pantalla de ayuda.

EJEMPLO

makeivs makeivs -w out.ivs -k 123456789ABCDEF123456789AB
