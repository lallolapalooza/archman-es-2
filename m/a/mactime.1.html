NOMBRE

mactime - Crear una línea de tiempo de actividad de archivos en ASCII

SINOPSIS

mactime [-b cuerpo ] [-g archivo de grupo ] [-p archivo de contraseñas ] [-i (día|hora) archivo de índice ] [-dhmVy] [-z ZONA HORARIA ] [RANGO DE FECHAS]

DESCRIPCIÓN

mactime crea una línea de tiempo de actividad de archivos en ASCII basada en el archivo de cuerpo especificado con '-b' o desde STDIN. La línea de tiempo se escribe en STDOUT. El archivo de cuerpo debe estar en el formato de máquina del tiempo que se crea con 'ils -m', 'fls -m', o la herramienta mac-robber.

ARGUMENTOS

-b cuerpo
Especifica la ubicación de un archivo de cuerpo. Este archivo debe ser generado por una herramienta como 'fls -m' o 'ils -m'. Las herramientas 'mac-robber' y 'grave-robber' también se pueden usar para generar el archivo.
-g archivo de grupo
Especifica la ubicación del archivo de grupo. mactime mostrará el nombre del grupo en lugar del GID si se proporciona.
-p archivo de contraseñas
Especifica la ubicación del archivo passwd. mactime mostrará el nombre de usuario en lugar del UID si se proporciona.
-i día|hora archivo de índice
Especifica la ubicación de un archivo de índice para escribir. El primer argumento especifica la granularidad, ya sea un resumen horario o diario. Si se proporciona la bandera ´-d´, el resumen se separará por una ',' para importar a una hoja de cálculo.
-d
Muestra los archivos de línea de tiempo e índice en formato de coma delimitada. Esto se usa para importar los datos a una hoja de cálculo para presentaciones o gráficos.
-h
Muestra información de encabezado sobre la sesión, incluido el rango de tiempo, la fuente de entrada y los archivos passwd o group.
-V
Muestra la versión en STDOUT.
-m
El mes se da como un número en lugar de un nombre (no funciona con -y).
-y
La fecha se muestra en formato ISO8601.
-z ZONA HORARIA
La zona horaria de donde se recolectaron los datos. El nombre de este argumento depende del sistema (los ejemplos incluyen EST5EDT, GMT+1). No funciona con -y.
-z list
Lista las zonas horarias válidas.
RANGO DE FECHAS
El rango de fechas para crear la línea de tiempo. El formato estándar es aaaa-mm-dd para una fecha de inicio y ninguna fecha de fin. Para una fecha de fin, use aaaa-mm-dd..aaaa-mm-dd. La fecha puede contener hora, use el formato aaaa-mm-ddThh:mm:ss para la fecha de inicio y/o fin.
