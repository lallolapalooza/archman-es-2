macof(8)

Paquete: dsniff

Licencias: BSD

MACOF(8) Manual del Administrador del Sistema MACOF(8)

NOMBRE

macof - inunda una LAN conmutada con direcciones MAC aleatorias

SINOPSIS

macof [-i interfaz] [-s origen] [-d destino] [-e tha] [-x puerto_origen] [-y puerto_destino] [-n veces]

DESCRIPCIÓN


macof inunda la red local con direcciones MAC aleatorias (haciendo que algunos switches fallen abiertos en modo repetidor, facilitando el sniffing). Una versión directa en C del programa original macof de Net::RawIP de Perl, por Ian Vitek <ian.vitek@infosec.se>.

OPCIONES

-i interfaz
Especificar la interfaz de envío.
-s origen
Especificar la dirección IP de origen.
-d destino
Especificar la dirección IP de destino.
-e tha
Especificar la dirección de hardware de destino.
-x puerto_origen
Especificar el puerto de origen TCP.
-y puerto_destino
Especificar el puerto de destino TCP.
-n veces
Especificar el número de paquetes a enviar.

Los valores de las opciones no especificadas se generarán aleatoriamente.
