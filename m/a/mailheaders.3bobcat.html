FBB::MailHeaders(3bobcat) Cabeceras de correo SMTP FBB::MailHeaders(3bobcat)

NOMBRE

FBB::MailHeaders - Maneja cabeceras de correo SMTP

SINOPSIS

#include <bobcat/mailheaders>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::MailHeaders extraen líneas de cabecera de correos electrónicos. La lectura se detiene en (e incluye) la primera línea en blanco, que se convierte en el último elemento del objeto FBB::MailHeaders, interpretado como un vector. El contenido real del correo electrónico se deja sin leer en el archivo que lo contiene.

Cada línea almacenada en un objeto MailHeaders representa una línea de cabecera completa. Las cabeceras que continúan en varias líneas de entrada se concatenan en una sola línea recuperable de los objetos MailHeaders, separadas entre sí por caracteres de ’\n’ (nueva línea). La última línea que se une a una cabecera multilínea no se termina con un carácter de nueva línea.

ENUMERACIONES

Las siguientes enumeraciones y valores de enumeración se pueden usar con la clase FBB::MailHeaders:

enum Mode
Esta enumeración define dos valores:

o
READ:
Cuando este valor se especifica en el momento de la construcción, el constructor lee inmediatamente el correo electrónico.
o
DONT_READ:
Cuando este valor se especifica en el momento de la construcción, el correo electrónico se lee usando el miembro read (ver más abajo).

enum Match
Esta enumeración define los siguientes valores:

o
FULL:
Usado por setHeaderIterator (ver más abajo) para indicar que las cabeceras deben coincidir exactamente con un nombre de cabecera especificado.
o
INITIAL:
Usado por setHeaderIterator (ver más abajo) para indicar que la parte inicial de las cabeceras debe coincidir con el texto de cabecera especificado.
o
PARTIAL:
Usado por setHeaderIterator (ver más abajo) para indicar que las cabeceras deben contener el texto de cabecera especificado.
o
CASE_FULL:
Usado por setHeaderIterator (ver más abajo) para indicar que las cabeceras deben coincidir exactamente con un nombre de cabecera especificado. La comparación se realiza sin distinguir mayúsculas y minúsculas.
o
CASE_INITIAL:
Usado por setHeaderIterator (ver más abajo) para indicar que la parte inicial de las cabeceras debe coincidir con el texto de cabecera especificado. La comparación se realiza sin distinguir mayúsculas y minúsculas.
o
CASE_PARTIAL:
Usado por setHeaderIterator (ver más abajo) para indicar que las cabeceras deben contener el texto de cabecera especificado. La comparación se realiza sin distinguir mayúsculas y minúsculas.

TIPOS ANIDADOS

La clase MailHeaders define los siguientes tipos:

o
const_iterator:
Un iterador de entrada devuelto por begin y end (ver más abajo)
o
const_reverse_iterator:
Un iterador de entrada inverso devuelto por los miembros rbegin y rend (ver más abajo)
o
const_hdr_iterator:
Un iterador de entrada devuelto por los miembros beginh y endh (ver más abajo)
o
const_reverse_hdr_iterator:
Un iterador de entrada inverso devuelto por los miembros rbeginh y rendh (ver más abajo). Los objetos de estos dos tipos de iterador apuntan a líneas de cabecera. Su tipo desreferenciado es std::string.

CONSTRUCTORES

o
MailHeaders(std::istream &in, Mode mode = READ):
Este constructor define el archivo que contiene el correo electrónico a procesar. El segundo parámetro es por defecto MailHeaders::READ, lo que hace que el objeto comience a leer el correo electrónico inmediatamente. Si se establece en MailHeaders::DONT_READ, el correo electrónico no se lee. En ese caso, se puede llamar al miembro read para procesar el correo electrónico más tarde.

El constructor de movimiento y el operador de asignación de movimiento están disponibles.

OPERADORES SOBRECARGADOS

o
std::string const &operator[](size_t idx) const:
Devuelve la línea de cabecera número idx.

FUNCIONES MIEMBRO

o
const_iterator begin() const:
Devuelve un iterador a la primera línea de las cabeceras del correo.
o
const_hdr_iterator beginh() const:
Devuelve el iterador de inicio correspondiente a la primera cabecera seleccionada por el miembro setHeaderIterator.
o
const_iterator end() const:
Devuelve un iterador posterior a la última línea de las cabeceras del correo.
o
const_hdr_iterator endh() const:
Devuelve el iterador de fin que coincide con beginh. Tenga en cuenta que el nombre del miembro de la función termina en h, para distinguirlo del miembro vector<string>::end.
o
const_reverse_iterator rbegin() const:
Devuelve un iterador a la última línea de las cabeceras del correo.
o
const_reverse_hdr_iterator rbeginh() const:
Devuelve el iterador inverso de inicio correspondiente a la última cabecera seleccionada por el miembro setHeaderIterator.
o
void read():
Lee las cabeceras del correo del archivo pasado al constructor del objeto FBB::MailHeaders. Se lanzará un objeto FBB::Exception si las cabeceras ya se han leído o si el archivo está incompleto (es decir, no se encontró la línea en blanco (obligatoria)).
o
const_iterator rend() const:
Devuelve un iterador anterior a la primera línea de las cabeceras del correo.
o
const_reverse_hdr_iterator rendh() const:
Devuelve el iterador inverso de fin que coincide con rbeginh.
o
void setHeaderIterator(char const *header, Match match = FULL):
Establece los iteradores de cabecera a la header especificada. El parámetro match define el tipo de coincidencia a usar al seleccionar cabeceras. El valor por defecto FBB::MailHeaders::FULL, indica que el texto proporcionado en header debe coincidir exactamente con una cabecera de correo electrónico.
Al comparar cabeceras, los dos puntos que terminan la cabecera no se tienen en cuenta y, por lo tanto, no deben especificarse en setHeaderIterator.
Se utilizan estrategias de comparación alternativas cuando se especifican otros valores de la enumeración FBB::Match.
El miembro setHeaderIterator debe haberse llamado al menos una vez o los miembros beginh y rendh lanzarán una excepción FBB::Exception. También se lanzará una excepción FBB::Exception si se llama a setHeaderIterator cuando no hay cabeceras de correo disponibles.
o
size_t size() const:
Devuelve el número de líneas de encabezado.

EJEMPLO

El siguiente ejemplo muestra el uso normal de estos miembros:

                // crea un objeto MailHeader
    MailHeaders mh(cin, MailHeaders::DONT_READ);
    try
    {           // lee los encabezados
        mh.read();
    }
    catch (Exception &err)
    {
        cout << err.what() << endl;
    }
    cout << "Hay " << mh.size() << " líneas de encabezado\n";
                // busca los encabezados Received:
    mh.setHeaderIterator("Received");
                // muestra los encabezados Received
    copy(mh.beginh(), mh.endh(),
            ostream_iterator<std::string const>(cout, "\n"));
