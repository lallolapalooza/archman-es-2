MAN.CONF(5) Manual de formatos de archivo MAN.CONF(5)

NOMBRE

man.conf — archivo de configuración para man

DESCRIPCIÓN

Este es el archivo de configuración para las utilidades man(1), apropos(1) y makewhatis(8). Su presencia y todas las directivas son opcionales.

Este archivo es un archivo de texto ASCII. Los espacios en blanco al principio de las líneas, las líneas que comienzan con ‘#’ y las líneas en blanco se ignoran. Las palabras se separan por espacios en blanco. La primera palabra de cada línea es el nombre de una directiva de configuración.

Se admiten las siguientes directivas:

manpath ruta
Anula la ruta de búsqueda predeterminada para man(1), apropos(1) y makewhatis(8). Se puede utilizar varias veces para especificar varias rutas, y el orden determina el orden de búsqueda de las páginas del manual.

Cada ruta es un árbol que contiene subdirectorios cuyos nombres consisten en las cadenas ‘man’ y/o ‘cat’ seguidas de los nombres de las secciones, generalmente dígitos únicos. Las primeras deben contener páginas del manual sin formato en formato mdoc(7) y/o man(7); los nombres de archivo deben terminar con el nombre de la sección precedido por un punto. Las segundas deben contener páginas del manual preformateadas; los nombres de archivo deben terminar con ‘.0’.

Se recomienda crear una base de datos mandoc.db(5) con makewhatis(8) en cada directorio configurado con manpath, y es necesario para que apropos(1) funcione, y también para man(1) en sistemas operativos como OpenBSD que instalan cada página del manual con un solo nombre de archivo en el sistema de archivos, incluso si documenta varias utilidades o funciones.

salida opción [valor]
Configura el valor predeterminado de una opción de salida. Estas directivas son anuladas por las opciones de línea de comandos -O con los mismos nombres. Para más detalles, consulte el manual de mandoc(1).
opción valor utilizado por -T propósito
fragmento ninguno html imprimir solo el cuerpo
incluye cadena html ruta a los archivos de encabezado
indentacion entero ascii, utf8 margen izquierdo
man cadena html ruta para enlaces Xr
papel cadena ps, pdf tamaño del papel
estilo cadena html archivo CSS
toc ninguno html imprimir tabla de contenidos
ancho entero ascii, utf8 margen derecho

ARCHIVOS

/etc/man.conf
 

EJEMPLOS

El siguiente archivo de configuración reproduce los valores predeterminados: instalarlo es equivalente a no tener ningún archivo man.conf.

manpath /usr/share/man
manpath /usr/X11R6/man
manpath /usr/local/man

VER TAMBIÉN

apropos(1), man(1), makewhatis(8)

HISTORIA

Un formato de archivo man.conf relativamente complicado apareció por primera vez en 4.3BSD-Reno. Para OpenBSD 5.8, fue rediseñado desde cero, apuntando a la simplicidad.
