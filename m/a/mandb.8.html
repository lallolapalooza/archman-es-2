MANDB(8) Utilidades del paginador de manual MANDB(8)

NOMBRE

mandb - crea o actualiza las cachés de índices de las páginas del manual

SINOPSIS

mandb [-dqsucpt?V] [-C archivo] [manpath]
mandb [-dqsut] [-C archivo] -f nombre_archivo ...

DESCRIPCIÓN

mandb se utiliza para inicializar o actualizar manualmente las cachés de bases de datos de índices. Las cachés contienen información relevante para el estado actual del sistema de páginas del manual y la información almacenada en ellas es utilizada por las utilidades de man-db para mejorar su velocidad y funcionalidad.

Al crear o actualizar un índice, mandb advertirá sobre solicitudes de .so de ROFF incorrectas, nombres de archivo de páginas del manual erróneos y páginas del manual de las cuales no se puede analizar el whatis.

Proporcionar a mandb una ruta opcional separada por dos puntos anulará la ruta de búsqueda interna de la jerarquía del manual del sistema, determinada a partir de la información encontrada en el archivo de configuración de man-db.

CACHÉS DE BASES DE DATOS

mandb puede compilarse con soporte para cualquiera de los siguientes tipos de bases de datos.

Nombre Asíncrono Nombre de archivo
Berkeley db Sí index.bt
GNU gdbm Sí index.db
UNIX ndbm No index.(dir|pag)

Aquellos tipos de bases de datos que soportan actualizaciones asíncronas proporcionan una mayor velocidad a costa de una posible corrupción en caso de terminación inusual. En un caso inusual donde esto haya ocurrido, puede ser necesario volver a ejecutar mandb con la opción -c para recrear las bases de datos desde cero.

OPCIONES

-d, --debug
Imprime información de depuración.
-q, --quiet
No produce advertencias.
-s, --no-straycats
No dedica tiempo a buscar o añadir información a las bases de datos respecto a gatos sueltos (stray cats).
-p, --no-purge
No dedica tiempo a comprobar páginas del manual eliminadas y a purgarlas de las bases de datos.
-c, --create
Por defecto, mandb intentará actualizar cualquier base de datos creada previamente. Si una base de datos no existe, la creará. Esta opción fuerza a mandb a eliminar las bases de datos anteriores y recrearlas desde cero, e implica --no-purge. Esto puede ser necesario si una base de datos se corrompe o si se introduce un nuevo esquema de almacenamiento de bases de datos en el futuro.
-u, --user-db
Crea solo bases de datos de usuario, incluso con los permisos de escritura necesarios para crear bases de datos del sistema.
-t, --test
Realiza comprobaciones de corrección en las páginas del manual en la ruta de búsqueda de la jerarquía. Con esta opción, mandb no alterará las bases de datos existentes.
-f, --filename
Actualiza solo las entradas para el nombre de archivo dado. Esta opción no es para uso general; la utiliza internamente man cuando ha sido compilado con la opción MAN_DB_UPDATES y detecta que una página está desactualizada. Implica -p y deshabilita -c y -s.
-C archivo, --config-file=archivo
Utiliza este archivo de configuración de usuario en lugar del predeterminado ~/.manpath.
-?, --help
Muestra el mensaje de uso y sale.
--usage
Imprime un breve mensaje de uso y sale.
-V, --version
Muestra la versión y sale.

ESTADO DE SALIDA

0
Ejecución del programa exitosa.
1
Error de uso, sintaxis o archivo de configuración.
2
Error operativo.
3
Un proceso hijo falló.

DIAGNÓSTICOS

Los siguientes mensajes de advertencia pueden ser emitidos durante la creación de la base de datos.

<nombre_archivo>: parse de whatis para página(sec) fallido
Un intento de extraer líneas whatis del <nombre_archivo> dado falló. Esto se debe generalmente a una página del manual mal escrita, pero si se emiten muchos mensajes de este tipo, es probable que el sistema contenga páginas del manual no estándar que sean incompatibles con el analizador whatis de man-db. Consulte la sección ANÁLISIS DE WHATIS en lexgrog(1) para más información.
<nombre_archivo>: es un enlace simbólico colgante
<nombre_archivo> no existe pero está referenciado por un enlace simbólico. Generalmente se emiten diagnósticos adicionales para identificar el <nombre_archivo> del enlace ofensivo.
<nombre_archivo>: enlace simbólico o solicitud ROFF `.so` incorrecta
<nombre_archivo> es un enlace simbólico a, o contiene una solicitud de inclusión ROFF a, un archivo inexistente.
<nombre_archivo>: ignorando nombre de archivo erróneo
El <nombre_archivo> puede ser o no una página del manual válida pero su nombre es inválido. Esto se debe generalmente a que una página del manual con una extensión de sección <x> ha sido colocada en la sección de página del manual <y>.
<máscara_nombre_archivo>: extensiones competidoras
El comodín <máscara_nombre_archivo> no es único. Esto se causa generalmente por la existencia de una versión comprimida y una sin comprimir de la misma página del manual. Se ignoran todas excepto la más reciente.

ARCHIVOS

/etc/man_db.conf
Archivo de configuración de man-db.
/var/cache/man/index.(bt|db|dir|pag)
Una caché de base de datos índice global compatible con FHS.

Ubicaciones anteriores para la caché de la base de datos incluían:

/usr/man/index.(bt|db|dir|pag)
Una caché de base de datos índice global tradicional.
/var/catman/index.(bt|db|dir|pag)
Una caché de base de datos índice global alternativa o compatible con FSSTND.
