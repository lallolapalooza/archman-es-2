MARIADB-SHOW(1) Sistema de base de datos MariaDB MARIADB-SHOW(1)

NOMBRE

mariadb-show - mostrar información de bases de datos, tablas y columnas (mariadb-show es ahora un enlace simbólico a mariadb-show)

SINOPSIS

mariadb-show [opciones] [nombre_db [nombre_tabla [nombre_columna]]]

DESCRIPCIÓN

El cliente mariadb-show se puede usar para ver rápidamente qué bases de datos existen, sus tablas o las columnas o índices de una tabla.

mariadb-show proporciona una interfaz de línea de comandos para varias sentencias SQL SHOW. La misma información se puede obtener utilizando esas sentencias directamente. Por ejemplo, puede emitirlas desde el programa cliente mariadb.

Invoque mariadb-show de esta manera:

shell> mariadb-show [opciones] [nombre_db [nombre_tabla [nombre_columna]]]
•Si no se proporciona ninguna base de datos, se muestra una lista de nombres de bases de datos.
•Si no se proporciona ninguna tabla, se muestran todas las tablas coincidentes en la base de datos.
•Si no se proporciona ninguna columna, se muestran todas las columnas y tipos de columna coincidentes en la tabla.

La salida muestra solo los nombres de aquellas bases de datos, tablas o columnas para las que tiene algún privilegio.

Si el último argumento contiene caracteres comodín de shell o SQL (“*”, “?”, “%”, o “_”), solo se muestran los nombres que coinciden con el comodín. Si un nombre de base de datos contiene guiones bajos, estos deben ser escapados con una barra invertida (algunos shells de Unix requieren dos) para obtener una lista de las tablas o columnas adecuadas. Los caracteres “*” y “?” se convierten en los caracteres comodín SQL “%” y “_”. Esto puede causar cierta confusión cuando intenta mostrar las columnas de una tabla con un “_” en el nombre, porque en este caso, mariadb-show le muestra solo los nombres de tabla que coinciden con el patrón. Esto se soluciona fácilmente agregando un “%” adicional al final de la línea de comandos como un argumento separado.

mariadb-show admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-show] y [client]. mariadb-show también admite las opciones para procesar archivos de opciones descritos.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--character-sets-dir=ruta, -c ruta

El directorio donde están instalados los conjuntos de caracteres.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos admiten compresión.

•--count

Muestra el número de filas por tabla. Esto puede ser lento para tablas que no sean MyISAM.

•--debug[=opciones_debug], -# [opciones_debug]

Escribe un registro de depuración. Una cadena típica de opciones_debug es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre

Plugin cliente predeterminado de autenticación a usar.

•--default-character-set=nombre_conjunto_caracteres

Usa nombre_conjunto_caracteres como el conjunto de caracteres predeterminado.

•--defaults-extra-file=archivo

Establece archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos de opciones predeterminadas globales. Debe darse como la primera opción.

•--defaults-file=archivo

Establece archivo como el archivo del que leer las opciones predeterminadas, anula los archivos de opciones predeterminadas globales. Debe darse como la primera opción.

•--defaults-group-suffix=sufijo

Además de los grupos nombrados en la línea de comandos, lee los grupos que tengan el sufijo dado.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host dado.

•--keys, -k

Muestra los índices de tabla.

•--no-defaults

No leer opciones predeterminadas de ningún archivo de opciones. Debe darse como el primer argumento.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usa la forma corta de la opción (-p), no puede haber un espacio entre la opción y la contraseña. Si omite el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb-show le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puede usar un archivo de opciones para evitar dar la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctese al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor admite conexiones por tubería con nombre.

•--plugin-dir=nombre_dir

Directorio para plugins del lado del cliente.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar para la conexión. Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente causarían que se use un protocolo diferente al que desea.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe darse como el primer argumento.

•--show-table-type, -t

Muestra una columna que indica el tipo de tabla, como en SHOW FULL TABLES. El tipo es BASE TABLE o VIEW.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (se habilita automáticamente con otras banderas). Deshabilita con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a usar (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--status, -i

Muestra información adicional sobre cada tabla.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a usar al conectarse al servidor.

•--verbose, -v

Modo detallado

e. Imprime más información sobre lo que hace el programa. Esta opción se puede usar varias veces para aumentar la cantidad de información.

•--version, -V

Muestra la información de la versión y sale.
