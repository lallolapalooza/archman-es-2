makeinfo(1) Comandos de usuario makeinfo(1)

NOMBRE

texi2any - traduce documentos Texinfo

SINOPSIS

makeinfo [OPCIÓN]... ARCHIVO-TEXINFO...

DESCRIPCIÓN

Traduce la documentación fuente de Texinfo a varios otros formatos, por defecto archivos Info adecuados para leer en línea con Emacs o GNU Info autónomo.

Este programa se instala comúnmente tanto como `makeinfo' como `texi2any'; el comportamiento es idéntico y no depende del nombre de instalación.

Opciones generales:

--document-language=CADENA localidad a usar en la traducción de palabras clave de Texinfo
para el documento de salida (por defecto C).
--error-limit=NÚMERO
salir después de NÚMERO errores (por defecto 100).
--force
conservar la salida incluso si hay errores.
--help
mostrar esta ayuda y salir.
--no-validate
suprimir la validación de referencias cruzadas de nodos.
--no-warn
suprimir advertencias (pero no errores).
--conf-dir=DIR
buscar también archivos de inicialización en DIR.
--init-file=ARCHIVO
cargar ARCHIVO para modificar el comportamiento por defecto.
-c, --set-customization-variable VAR=VAL
establecer la variable de personalización VAR a VAL.
--trace-includes
imprimir nombres de archivos incluidos.
-v, --verbose
explicar lo que se está haciendo.
--version
mostrar información de versión y salir.

Selección del formato de salida (por defecto es producir Info):

--docbook
salida Docbook XML.
--html
salida HTML.
--epub3
salida EPUB 3.
--latex
salida LaTeX.
--plaintext
salida de texto plano en lugar de Info.
--xml
salida XML de Texinfo.
--dvi, --dvipdf, --ps, --pdf
llamar a texi2dvi para generar la salida dada, después de verificar la validez de ARCHIVO-TEXINFO.

Opciones generales de salida:

-E, --macro-expand=ARCHIVO
salida de código fuente con macros expandidas a ARCHIVO, ignorando cualquier @setfilename.
--no-headers
suprimir separadores de nodos, líneas de Nodo: y menús de la salida Info (produciendo así texto plano) o de HTML (produciendo así una salida más corta). También, si se produce Info, escribir a la salida estándar por defecto.
--no-split
suprimir cualquier división de la salida; generar solo un archivo de salida.
--[no-]number-sections
salida de números de capítulos y secciones; el valor por defecto está activado.
-o, --output=DESTINO
salida a DESTINO. Con salida dividida, crear DESTINO como un directorio y colocar los archivos de salida allí. Con salida no dividida, si DESTINO ya es un directorio o termina en /, colocar el archivo de salida allí. De lo contrario, DESTINO nombra el archivo de salida.
--disable-encoding
no generar caracteres acentuados y especiales en la salida Info y de texto plano basada en la codificación del documento.
--enable-encoding
anular --disable-encoding (por defecto).

Opciones para Info y texto plano:

--fill-column=NÚMERO
romper líneas de Info en NÚMERO columnas (por defecto 72).
--footnote-style=ESTILO
salida de notas al pie en Info según ESTILO: `separate' para ponerlas en su propio nodo; `end' para ponerlas al final del nodo, donde están definidas (este es el valor por defecto).
--paragraph-indent=VAL
indentar párrafos de Info por VAL espacios (por defecto 3). Si VAL es `none', no indentar; si VAL es `asis', preservar la indentación existente.
--split-size=NÚMERO
dividir archivos Info en tamaño NÚMERO (por defecto 300000).

Opciones para HTML:

--css-include=ARCHIVO
incluir ARCHIVO en la salida <style> HTML; leer stdin si ARCHIVO es -.
--css-ref=URL
generar referencia CSS a URL.
--internal-links=ARCHIVO
producir lista de enlaces internos en ARCHIVO.
--split=DIVISION
dividir en DIVISION, donde DIVISION puede ser `chapter', `section' o `node'.
--transliterate-file-names
usar nombres de archivo en transliteración ASCII.
--node-files
producir archivos de redirección para nodos y anclas; por defecto solo se establece si está dividido.

Opciones para DVI/PS/PDF:

--Xopt=OPT
pasar OPT a texi2dvi; puede repetirse.

Opciones del archivo de entrada:

-D VAR
definir la variable VAR, como con @set.
-D 'VAR VAL'
definir VAR a VAL (un argumento de shell).
-I DIR
añadir DIR a la ruta de búsqueda de @include.
-P DIR
preponer DIR a la ruta de búsqueda de @include.
-U VAR
eliminar la definición de la variable VAR, como con @clear.

Procesamiento condicional en la entrada:

--ifdocbook
procesar @ifdocbook y @docbook incluso si no se está generando Docbook.
--ifhtml
procesar @ifhtml y @html incluso si no se está generando HTML.
--ifinfo
procesar @ifinfo incluso si no se está generando Info.
--iflatex
procesar @iflatex y @latex.

DESCRIPCIÓN

--ifdocbook
procesar texto @ifdocbook y @docbook.
--ifhtml
procesar texto @ifhtml y @html.
--ifinfo
procesar texto @ifinfo.
--iflatex
procesar texto @iflatex y @latex.
--ifplaintext
procesar @ifplaintext incluso si no se está generando texto plano.
--iftex
procesar @iftex y @tex.
--ifxml
procesar @ifxml y @xml.
--no-ifdocbook
no procesar texto @ifdocbook y @docbook.
--no-ifhtml
no procesar texto @ifhtml y @html.
--no-ifinfo
no procesar texto @ifinfo.
--no-iflatex
no procesar texto @iflatex y @latex.
--no-ifplaintext
no procesar texto @ifplaintext.
--no-iftex
no procesar texto @iftex y @tex.
--no-ifxml
no procesar texto @ifxml y @xml.

Además, para las opciones --no-ifFORMAT, sí procesar texto @ifnotFORMAT.

Los valores predeterminados para los condicionales @if... dependen del formato de salida: si se genera Docbook, --ifdocbook está activado y los demás están desactivados; si se genera HTML, --ifhtml está activado y los demás desactivados; si se genera Info, --ifinfo está activado y los demás desactivados; si se genera texto plano, --ifplaintext está activado y los demás desactivados; si se genera LaTeX, --iflatex está activado y los demás desactivados; si se genera XML, --ifxml está activado y los demás desactivados.

EJEMPLOS

makeinfo foo.texi
escribir Info en @setfilename de foo
makeinfo --html foo.texi
escribir HTML en @setfilename
makeinfo --xml foo.texi
escribir XML Texinfo en @setfilename
makeinfo --docbook foo.texi
escribir XML Docbook en @setfilename
makeinfo --plaintext foo.texi
escribir texto plano en la salida estándar
makeinfo --pdf foo.texi
escribir PDF usando texi2dvi
makeinfo --html --no-headers foo.texi
escribir html sin líneas de nodo, menús
makeinfo --number-sections foo.texi
escribir Info con secciones numeradas
makeinfo --no-split foo.texi
escribir un solo archivo Info sin importar su tamaño
