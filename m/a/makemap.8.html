MAKEMAP(8) Manual del Administrador del Sistema MAKEMAP(8)

NOMBRE

makemap — crea mapas de bases de datos para smtpd

SINOPSIS

makemap [-U] [-d tipo_db] [-o archivo_db] [-t tipo] archivo

DESCRIPCIÓN

Los mapas proporcionan una interfaz genérica para asociar una clave de texto a un valor. Estas asociaciones pueden ser accedidas a través de un archivo de texto plano, una base de datos o DNS. El formato de estos tipos de archivo se describe a continuación. makemap crea los mapas de bases de datos utilizados por las búsquedas de mapas con clave especificadas en smtpd.conf(5).

makemap lee la entrada de archivo y escribe los datos en un archivo cuyo nombre se obtiene añadiendo un sufijo ".db" a archivo. La línea actual puede extenderse a lo largo de varias líneas usando una barra invertida ('\'). Los comentarios se pueden colocar en cualquier lugar del archivo usando una almohadilla ('#'), y se extienden hasta el final de la línea actual. Se debe tener cuidado al comentar texto multilínea: el comentario es efectivo hasta el final de todo el bloque. En todos los casos, makemap lee líneas compuestas por palabras separadas por espacios en blanco. La primera palabra de una línea es la clave de la base de datos; el resto representa el valor mapeado. La clave y el valor de la base de datos pueden estar opcionalmente separados por dos puntos.

Las opciones son las siguientes:

-d tipo_db
Especifica el formato de la base de datos. Los formatos disponibles son hash y btree. El valor predeterminado es hash.
-o archivo_db
Escribe la base de datos generada en archivo_db.
-t tipo
Especifica el formato del archivo de mapa resultante. El formato de mapa predeterminado es adecuado para almacenar asociaciones de cadenas simples y no estructuradas, de clave a valor. Sin embargo, si el valor mapeado tiene un significado especial, como en el caso de un archivo de dominios virtuales, se debe proporcionar un tipo adecuado. Los tipos de salida disponibles son:
aliases
El valor mapeado es una lista de destinos de correo separados por comas. Este formato se puede utilizar para construir alias de usuario y mapeos de usuario para archivos de dominios virtuales.
set
No hay valor mapeado; un mapa de este tipo solo permitirá la búsqueda de claves. Este formato se puede utilizar para construir mapas de dominios primarios.
-U
En lugar de generar un mapa de base de datos a partir de entrada de texto, volca el contenido de un mapa de base de datos como texto con la clave y el valor separados por una tabulación.

DOMINIOS PRIMARIOS

Los dominios primarios se pueden mantener en tablas. Para crear una tabla de dominios primarios, añada cada dominio primario en una línea separada por sí mismo.

Además de añadir una entrada al mapa de dominios primarios, se debe añadir una regla de filtro que acepte correo para el mapa de dominios, por ejemplo:

table domains db:/etc/smtpd/domains.db

action "local" mbox

match for domain <domains> action "local"

DOMINIOS VIRTUALES

Los dominios virtuales también se pueden mantener en tablas. Para crear una tabla de dominios virtuales, añada cada dominio virtual en una línea separada por sí mismo.

Los dominios virtuales esperan un mapeo de usuarios virtuales a usuarios reales para determinar si un destinatario es aceptado o no. El formato del mapeo es una extensión de aliases(5), que permite el uso de "usuario@dominio.tld" para aceptar al usuario solo en el dominio especificado, "usuario" para aceptar al usuario para cualquiera de los dominios virtuales, "@dominio.tld" para proporcionar un comodín para el dominio especificado y "@" para proporcionar un comodín global para todos los dominios. smtpd(8) realizará las búsquedas en ese orden específico.

Para crear una única dirección virtual, añada "usuario@ejemplo.com usuario" al mapa de usuarios. Para manejar todo el correo destinado a cualquier usuario en ejemplo.com, añada "@ejemplo.com usuario" al mapa virtual.

Además de añadir una entrada al mapa virtual, se debe añadir una regla de filtro que acepte correo para dominios virtuales, por ejemplo:

table vdomains db:/etc/smtpd/vdomains.db
table vusers db:/etc/smtpd/users.db

action "local" mbox virtual <vusers>

match for domain <vdomains> action "local"
match for domain "ejemplo.org" action "local"

ARCHIVOS

/etc/smtpd/aliases
Lista de alias de correo de usuario.
/etc/smtpd/secrets
Lista de credenciales de host remoto.

ESTADO DE SALIDA

La utilidad makemap sale con 0 en caso de éxito, y >0 si ocurre un error.

VER TAMBIÉN

aliases(5), smtpd.conf(5), table(5), newaliases(8), smtpd(8)

HISTORIA

El comando makemap apareció por primera vez en OpenBSD 4.6 como reemplazo del comando equivalente distribuido con sendmail.

    Nombre

    makemap - crea/actualiza mapas de autenticación y tabla de hashes

    Sintaxis

    makemap [-d|-f|-r] [-N] [-o nombre_archivo] [-v] [-Z] [maptype [mapname]]

    Descripción

    makemap crea una tabla de hashes en un archivo desde una lista de entradas textuales. El programa puede crear tablas de hashes para tcp_wrappers (hosts.allow y hosts.deny) y para programas que utilizan la biblioteca libwrap. La tabla de hashes es una tabla de consulta rápida que reduce el tiempo de acceso a la información en comparación con la lectura directa de archivos de texto.

    La entrada puede venir de la entrada estándar o de un archivo especificado. Por defecto, el programa opera sobre la entrada estándar y escribe en la salida estándar. El formato de la salida es binario, pero puede ser redirigido a un archivo.

    Opciones

    -d
    Crea una tabla de hashes para consultas de tipo "string a dirección". Útil para tablas de nombres de host a direcciones IP.
    -f
    Crea una tabla de hashes para consultas de tipo "string a string". Útil para mapear nombres de usuario, nombres de host, etc.
    -r
    Crea una tabla de hashes para consultas de tipo "regex a string". Útil para mapear patrones de nombres de host a direcciones IP, por ejemplo.
    -N
    Evita la resolución de nombres de host a direcciones IP. Si se especifica, los nombres de host se almacenarán como cadenas en lugar de direcciones IP.
    -o nombre_archivo
    Especifica el archivo de salida para la tabla de hashes. Si no se especifica, la salida se dirige a la salida estándar.
    -v
    Modo verboso. Muestra información sobre el proceso de creación de la tabla de hashes.
    -Z
    Indica que las entradas de la tabla deben ser de solo lectura.

    Argumentos

    maptype
    El tipo de mapa a crear. Puede ser host, user, network, hostu, userhost, hostuser, networkd. Si no se especifica, se intenta deducir del tipo de tabla de hashes (-d, -f, -r).
    mapname
    El nombre del archivo de entrada. Si no se especifica, se lee de la entrada estándar.

    Ejemplos

    Para crear una tabla de hashes de nombres de host a direcciones IP desde el archivo hosts.txt y guardarla en hosts.db: 

    makemap -d -o hosts.db hosts.txt

    Para crear una tabla de hashes de nombres de usuario a IDs de usuario desde la entrada estándar y mostrarla en la salida estándar: 

    makemap -f user < /etc/passwd

    Véase también

    hosts_access(5), hosts_options(5)

    Historial

    El programa makemap apareció por primera vez en COPS (Centralized Oracle Password Security). La versión actual se basa en la versión de TCP Wrappers.
