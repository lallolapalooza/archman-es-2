NOMBRE

mate-notification-properties - Configurar las opciones para las notificaciones del escritorio

SINOPSIS

mate-notification-properties

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando mate-notification-properties.

mate-notification-properties es una utilidad para configurar varias opciones relacionadas con las notificaciones del escritorio.

AUTOR

mate-notification-properties fue escrito por Jonh Wendell <wendell@ bani.com.br> y Perberos <perberos@gmail.com>.

Esta página del manual fue escrita por Francois Wendling <frwendling@free.fr> para el proyecto notification-properties en Debian (pero puede ser utilizada por otros) y adaptada para MATE por Stefano Karapetsas <stefano@karapetsas.com>.
