MATE-WM(1) Manual de comandos generales MATE-WM(1)

NOMBRE

mate-wm - Iniciar el gestor de ventanas configurado por el usuario

SINOPSIS

mate-wm [--default-wm=WINDOWMANAGER] [--sm-client-id=ID]

DESCRIPCIÓN

El programa mate-wm inicia el gestor de ventanas configurado por el usuario. Si el usuario no ha elegido un gestor de ventanas, lanzará un gestor de ventanas compatible con MATE.

USO

El usuario puede definir su gestor de ventanas preferido con la clave dconf /org/mate/desktop/session/required-components/windowmanager. El valor de esta clave debe ser el nombre del archivo .desktop del gestor de ventanas deseado, sin la extensión .desktop. Si esta clave se establece en mate-wm, entonces mate-wm simplemente buscará un gestor de ventanas adecuado. El usuario también puede anular la selección de un gestor de ventanas estableciendo la variable de entorno WINDOW_MANAGER.

Si se utiliza la opción --default-wm, mate-wm utilizará WINDOWMANAGER como gestor de ventanas si la variable de entorno WINDOW_MANAGER no está establecida y si la clave dconf /org/mate/desktop/session/required-components/windowmanager no define un gestor de ventanas específico, o si el gestor de ventanas configurado no se puede encontrar.

La opción --sm-client-id se traduce a una opción apropiada según qué gestor de ventanas se inicie.

OPCIONES

Se admiten las siguientes opciones:

--default-wm=WINDOWMANAGER
Define el gestor de ventanas predeterminado a iniciar si no hay ningún gestor de ventanas configurado o si el gestor de ventanas configurado no se puede encontrar.
--sm-client-id=ID
Especifica el ID de gestión de sesión al conectarse al gestor de sesión.

ENTORNO

mate-wm utiliza el valor de la variable de entorno WINDOW_MANAGER para permitir al usuario anular el gestor de ventanas configurado.

ERRORES

Si encuentra algún error, pueden ser reportados en:

http://github.com/mate-desktop/mate-session-manager/issues
