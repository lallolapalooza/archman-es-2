MARIADB-FIND-ROWS(1) Sistema de Base de Datos MariaDB MARIADB-FIND-ROWS(1)

NOMBRE

mariadb-find-rows - extrae sentencias SQL de archivos (mariadb-find-rows es ahora un enlace simbólico a mariadb-find-rows)

SINOPSIS

mariadb-find-rows [opciones] [nombre_archivo ...]

DESCRIPCIÓN

mariadb-find-rows lee archivos que contienen sentencias SQL y extrae sentencias que coinciden con una expresión regular dada o que contienen USE db_name o SET. La utilidad fue escrita para usarse con archivos de registro de actualización (como se usaba antes de MySQL 5.0) y como tal espera que las sentencias terminen con punto y coma (;). Puede ser útil con otros archivos que contienen sentencias SQL siempre que las sentencias terminen con punto y coma.

Invoque mariadb-find-rows de esta manera:

shell> mariadb-find-rows [opciones] [nombre_archivo ...]

Cada argumento nombre_archivo debe ser el nombre de un archivo que contenga sentencias SQL. Si no se proporcionan nombres de archivo, mariadb-find-rows lee la entrada estándar.

Ejemplos:

mariadb-find-rows --regexp=problem_table --rows=20 < update.log
mariadb-find-rows --regexp=problem_table  update-log.1 update-log.2

mariadb-find-rows admite las siguientes opciones:

•--help, --Information

Muestra un mensaje de ayuda y sale.

•--regexp=patrón

Muestra las consultas que coinciden con el patrón.

•--rows=N

Sale después de mostrar N consultas.

•--skip-use-db

No incluye sentencias USE db_name en la salida.

•--start_row=N

Comienza la salida desde esta fila.
