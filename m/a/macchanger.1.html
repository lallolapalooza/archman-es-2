NOMBRE

macchanger - Cambiador de MAC

SINOPSIS

macchanger [opciones] dispositivo

DESCRIPCIÓN

macchanger es una utilidad de GNU/Linux para ver/manipular la dirección MAC para interfaces de red.

OPCIONES

macchanger acepta las siguientes opciones:

-h, --help
Mostrar resumen de opciones.
-V, --version
Mostrar versión del programa.
-s, --show
Imprime la MAC actual. Esta es la acción predeterminada cuando no se especifica ninguna otra opción.
-e, --ending
No cambiar los bytes del proveedor.
-a, --another
Establecer una MAC aleatoria del proveedor del mismo tipo.
-A
Establecer una MAC aleatoria de cualquier tipo de proveedor.
-r, --random
Establecer una MAC completamente aleatoria.
-p, --permanent
Restaurar la dirección MAC a su valor original de hardware permanente.
-l, --list[=palabra_clave]
Imprimir proveedores conocidos (con la palabra clave en la cadena de descripción del proveedor).
-b, --bia
Al establecer una MAC completamente aleatoria, simular ser una dirección grabada en la fábrica (burned-in-address). Si no se usa, la MAC tendrá el bit administrado localmente establecido.
-m, --mac XX:XX:XX:XX:XX:XX, --mac=XX:XX:XX:XX:XX:XX
Establecer la MAC a XX:XX:XX:XX:XX:XX.

EJEMPLO

macchanger -A eth1

VER TAMBIÉN
