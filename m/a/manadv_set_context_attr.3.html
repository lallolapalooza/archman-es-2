NOMBRE

manadv_set_context_attr - Establecer atributos de contexto

SINOPSIS

#include <infiniband/manadv.h>
int manadv_set_context_attr(struct ibv_context *context,
                            enum manadv_set_ctx_attr_type attr_type,
                            void *attr);

DESCRIPCIÓN

manadv_set_context_attr permite establecer atributos específicos del proveedor en el contexto RDMA.

ARGUMENTOS

context
Contexto del dispositivo RDMA sobre el que trabajar.
attr_type
El tipo del atributo proporcionado.
attr
Puntero al atributo que se va a establecer.

attr_type

enum manadv_set_ctx_attr_type {
    /* Tipo de atributo uint8_t */
    MANADV_SET_CTX_ATTR_BUF_ALLOCATORS = 0,
};
MANADV_SET_CTX_ATTR_BUF_ALLOCATORS
Proporcionar un asignador de búfer externo
struct manadv_ctx_allocators {
    void *(*alloc)(size_t size, void *priv_data);
    void (*free)(void *ptr, void *priv_data);
    void *data;
};
alloc
Función utilizada para la asignación de búferes en lugar del método interno de libmana
free
Función utilizada para liberar búferes asignados por la función alloc
data
Metadatos que pueden ser utilizados por las funciones alloc y free

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o el valor de errno en caso de error (que indica el motivo del fallo).
