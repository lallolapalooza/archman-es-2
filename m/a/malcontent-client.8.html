NOMBRE

malcontent-client - Utilidad de acceso a control parental

SINOPSIS

malcontent-client get-app-filter [-q] [-n] [USUARIO]

malcontent-client check-app-filter [-q] [-n] [USUARIO] ARG

malcontent-client set-app-filter [-q] [-n] [USUARIO] ARG

malcontent-client oars-section [-q] [-n] [USUARIO] SECCIÓN

malcontent-client get-session-limits [-q] [-n] [USUARIO]

malcontent-client monitor [-q] [USUARIO]

DESCRIPCIÓN

malcontent-client es una utilidad para consultar y actualizar la configuración de control parental para los usuarios del sistema. Normalmente, requerirá acceso de administrador para hacer algo más que consultar el control parental del usuario actual.

Se comunica con accounts-service, que almacena los datos de control parental.

Su primer argumento es un comando a ejecutar. Los comandos admitidos se documentan a continuación.

La API de línea de comandos y el formato de salida son inestables y es probable que cambien en versiones futuras de malcontent-client.

OPCIONES DE get-app-filter

Obtener el filtro de aplicaciones para un usuario. Por ejemplo:

# malcontent-client get-app-filter timmy
USUARIO
Nombre de usuario o ID del usuario para el que obtener el filtro de aplicaciones. Si no se especifica, se utilizará el usuario actual por defecto.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)
-n, --no-interactive
No permitir la autorización interactiva con polkit. Si esto es necesario para completar la operación, la operación fallará. (Por defecto: Permitir la autorización interactiva.)

OPCIONES DE check-app-filter

Comprobar si a un programa, tipo de contenido o ref de flatpak dado se le permite ser utilizado por un usuario, de acuerdo con su filtro de aplicaciones actual. Por ejemplo:

# malcontent-client check-app-filter timmy $(which gnome-calculator)

# malcontent-client check-app-filter timmy x-scheme-handler/http

# malcontent-client check-app-filter timmy app/com.realm667.WolfenDoom_Blade_of_Agony/x86_64/stable

USUARIO
Nombre de usuario o ID del usuario para el que obtener el filtro de aplicaciones. Si no se especifica, se utilizará el usuario actual por defecto.
ARG
Ruta a un programa, tipo de contenido o ref de flatpak para comprobar contra el filtro de aplicaciones, para ver si está permitido para el usuario especificado.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)
-n, --no-interactive
No permitir la autorización interactiva con polkit. Si esto es necesario para completar la operación, la operación fallará. (Por defecto: Permitir la autorización interactiva.)

OPCIONES DE set-app-filter

Establecer el filtro de aplicaciones para un usuario, reemplazando todos los valores anteriores en él. Por ejemplo:

# malcontent-client set-app-filter timmy \
--disallow-user-installation \
$(which gnome-calculator) \
x-scheme-handler/http \
app/com.realm667.WolfenDoom_Blade_of_Agony/x86_64/stable
USUARIO
Nombre de usuario o ID del usuario para el que establecer el filtro de aplicaciones. Si no se especifica, se utilizará el usuario actual por defecto.
ARG
Elemento para filtrar en el filtro de aplicaciones del usuario. Podría ser la ruta absoluta o el ref de flatpak de un programa a bloquear; un tipo de contenido para bloquear todos los programas que manejan ese tipo; o un par sección=valor de OARS para bloquear la instalación de aplicaciones con una calificación más extrema para esa sección de OARS. Se pueden especificar varios elementos, y reemplazarán por completo el filtro de aplicaciones actual del usuario. Si se especifican cero elementos, se borra el filtro de aplicaciones.
--allow-user-installation
Permitir al usuario instalar flatpaks en su repositorio de usuario.
--disallow-user-installation
Denegar al usuario la instalación de flatpaks en su repositorio de usuario.
--allow-system-installation
Permitir al usuario instalar flatpaks en el repositorio del sistema.
--disallow-system-installation
Denegar al usuario la instalación de flatpaks en el repositorio del sistema.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)
-n, --no-interactive
No permitir la autorización interactiva con polkit. Si esto es necesario para completar la operación, la operación fallará. (Por defecto: Permitir la autorización interactiva.)

OPCIONES DE oars-section

Obtener el valor establecido para una sección OARS específica del filtro de aplicaciones del usuario dado. Por ejemplo:

# malcontent-client oars-section timmy language-profanity
USUARIO
Nombre de usuario o ID del usuario para el que obtener el filtro OARS. Si no se especifica, se utilizará el usuario actual por defecto.
SECCIÓN
Sección OARS de la que obtener el nivel de restricción del usuario dado. Por ejemplo, language-profanity.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)
-n, --no-interactive
No permitir la autorización interactiva con polkit. Si esto es necesario para completar la operación, la operación fallará. (Por defecto: Permitir la autorización interactiva.)

OPCIONES DE get-session-limits

Obtener los límites de sesión establecidos para un usuario. Por ejemplo:

# malcontent-client get-session-limits timmy
USUARIO
Nombre de usuario o ID del usuario para el que obtener los límites de sesión. Si no se especifica, se utilizará el usuario actual por defecto.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)
-n, --no-interactive
No permitir la autorización interactiva con polkit. Si esto es necesario para completar la operación, la operación fallará. (Por defecto: Permitir la autorización interactiva.)
--now aaaa-mm-ddThh:mm:ssZ
Comprobar los límites de sesión (en particular, la hora de expiración de la sesión) contra la fecha/hora dada, proporcionada en formato ISO 8601. (Por defecto: Fecha/hora actual.)

OPCIONES DE monitor

Monitorizar cambios en la configuración de control parental para un usuario específico. Por ejemplo:

# malcontent-client monitor timmy
USUARIO
Nombre de usuario o ID del usuario para el que monitorizar los controles parentales. Si no se especifica, se utilizará el usuario actual por defecto.
-q, --quiet
Mostrar solo mensajes de error y ningún mensaje informativo a medida que la operación progresa. (Por defecto: Mostrar mensajes informativos.)

ESTADO DE SALIDA

malcontent-client puede devolver uno de varios códigos de error si encuentra problemas.

0
No ocurrieron problemas. La utilidad se ejecutó y consultó correctamente el filtro de aplicaciones. Si se ejecuta el comando check-app-filter, la ruta dada, el tipo de contenido o la referencia de flatpak fueron permitidos para el usuario dado.
1
Se pasó una opción inválida a malcontent-client al inicio.
2
El usuario actual no estaba autorizado para consultar el filtro de aplicaciones para el usuario dado.
3
Si se ejecuta el comando check-app-filter, la ruta dada, el tipo de contenido o la referencia de flatpak *no* fueron permitidos para el usuario dado.
4
Malcontent está deshabilitado a nivel de sistema, y por lo tanto los controles parentales no están habilitados ni aplicados.
5
Una operación falló y no hay información de error más específica disponible.
