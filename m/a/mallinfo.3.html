mallinfo(3) Manual de Funciones de Biblioteca mallinfo(3)

NOMBRE

mallinfo, mallinfo2 - obtener información de asignación de memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <malloc.h>
struct mallinfo mallinfo(void);
struct mallinfo2 mallinfo2(void);

DESCRIPCIÓN

Estas funciones devuelven una copia de una estructura que contiene información sobre las asignaciones de memoria realizadas por malloc(3) y funciones relacionadas. La estructura devuelta por cada función contiene los mismos campos. Sin embargo, la función más antigua, mallinfo(), está obsoleta ya que el tipo utilizado para los campos es demasiado pequeño (ver BUGS).

Tenga en cuenta que no todas las asignaciones son visibles para estas funciones; vea BUGS y considere usar malloc_info(3) en su lugar.

La estructura mallinfo2 devuelta por mallinfo2() se define de la siguiente manera:


struct mallinfo2 {
    size_t arena;     /* Espacio no mapeado por mmap asignado (bytes) */
    size_t ordblks;   /* Número de bloques libres */
    size_t smblks;    /* Número de bloques fastbin libres */
    size_t hblks;     /* Número de regiones mmapped */
    size_t hblkhd;    /* Espacio asignado en regiones mmapped
                         (bytes) */
    size_t usmblks;   /* Ver abajo */
    size_t fsmblks;   /* Espacio en bloques fastbin liberados (bytes) */
    size_t uordblks;  /* Espacio total asignado (bytes) */
    size_t fordblks;  /* Espacio total libre (bytes) */
    size_t keepcost;  /* Bloque superior, liberable (bytes) */
};

La estructura mallinfo devuelta por la obsoleta función mallinfo() es exactamente la misma, excepto que los campos tienen el tipo int.

Los campos de la estructura contienen la siguiente información:

arena
La cantidad total de memoria asignada por medios distintos de mmap(2) (es decir, memoria asignada en el heap). Esta cifra incluye tanto bloques en uso como bloques en la lista de libres.
ordblks
El número de bloques libres ordinarios (es decir, no fastbin).
smblks
El número de bloques fastbin libres (ver mallopt(3)).
hblks
El número de bloques actualmente asignados usando mmap(2). (Ver la discusión de M_MMAP_THRESHOLD en mallopt(3).)
hblkhd
El número de bytes en bloques actualmente asignados usando mmap(2).
usmblks
Este campo no se utiliza y siempre es 0. Históricamente, era la "marca de alta agua" para el espacio asignado —es decir, la cantidad máxima de espacio que se asignó alguna vez (en bytes); este campo solo se mantenía en entornos no multihilo.
fsmblks
El número total de bytes en bloques fastbin libres.
uordblks
El número total de bytes utilizados por asignaciones en uso.
fordblks
El número total de bytes en bloques libres.
keepcost
La cantidad total de espacio libre liberable en la parte superior del heap. Este es el número máximo de bytes que idealmente (es decir, ignorando restricciones de alineación de página, etc.) podrían ser liberados por malloc_trim(3).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, vea attributes(7).

Interfaz Atributo Valor
mallinfo (), mallinfo2 () Seguridad de hilos MT-Unsafe init const:mallopt

mallinfo()/ mallinfo2() accedería a algunos objetos internos globales. Si se modifican de forma no atómica, se pueden obtener resultados inconsistentes. El identificador mallopt en const:mallopt significa que mallopt() modificaría los objetos internos globales de forma atómica, lo que garantiza que mallinfo()/ mallinfo2() sea lo suficientemente seguro; otros modificadores no atómicos pueden no serlo.

ESTANDARES

Ninguno.

HISTORIA

mallinfo()
glibc 2.0. SVID.
mallinfo2()
glibc 2.33.

BUGS

La información se devuelve solo para el área principal de asignación de memoria. Las asignaciones en otras áreas están excluidas. Consulte malloc_stats(3) y malloc_info(3) para alternativas que incluyan información sobre otras áreas.

Los campos de la estructura mallinfo que devuelve la función más antigua mallinfo() tienen el tipo int. Sin embargo, debido a que algunos valores internos de contabilidad pueden ser de tipo long, los valores reportados pueden desbordarse y, por lo tanto, ser inexactos.

EJEMPLOS

El siguiente programa utiliza mallinfo2() para recuperar estadísticas de asignación de memoria antes y después de asignar y liberar algunos bloques de memoria. Las estadísticas se muestran en la salida estándar.

Los dos primeros argumentos de línea de comandos especifican el número y el tamaño de los bloques que se asignarán con malloc(3).

Los tres argumentos restantes especifican cuáles de los bloques asignados deben liberarse con free(3). Estos tres argumentos son opcionales y especifican (en orden): el tamaño del paso que se utilizará en el bucle que libera bloques (el valor predeterminado es 1, lo que significa liberar todos los bloques en el rango); la posición ordinal del primer bloque que se liberará (predeterminado 0, lo que significa el primer bloque asignado); y un número mayor que la posición ordinal del último bloque que se liberará (el valor predeterminado es uno mayor que el número máximo de bloques). Si se omiten estos tres argumentos, los valores predeterminados harán que se liberen todos los bloques asignados.

mallinfo.3 - Arch Linux man pages

NAME

mallinfo, mallinfo2 – display allocator information

LIBRARY

Memory allocation family (-lm)

SYNOPSIS

#include <malloc.h>

struct mallinfo mallinfo(void);
struct mallinfo2 mallinfo2(void);

DESCRIPTION

The mallinfo() and mallinfo2() functions provide detailed information about the dynamic memory allocation behavior of the calling process. They return a structure containing various statistics about the memory allocator's internal state.

The structure returned by mallinfo() contains the following fields:

arena
Total size of memory obtained from the system in bytes (total allocatable space).
ordblks
Number of free chunks.
smblks
Number of free chunks (fastbins).
hblks
Number of free (sticky) blocks.
hblkhd
Total bytes in (sticky) blocks.
usmblks
Maximum total allocated space.
fsmblks
Total free space in fastbins.
uordblks
Total allocated space.
fordblks
Total free space.
keepcost
The difference between the total size of the arena and the total allocated space. It represents the amount of memory that could be freed by calling malloc_trim(0).

The structure returned by mallinfo2() contains the same fields as mallinfo(), but uses the size_t type for all its members.

The exact meaning of these fields can be somewhat obscure and may depend on the specific memory allocator implementation (e.g., the default glibc malloc implementation). The values represent the internal state of the allocator and are primarily useful for debugging and performance tuning.

Note that the values returned by these functions are not guaranteed to be exact or up-to-the-minute. They represent a snapshot of the allocator's state at the time the function is called.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

+--------------------+-------------------+
| Attribute          | Value             |
+--------------------+-------------------+
| Interface stability| Unstable          |
+--------------------+-------------------+

STANDARDS

mallinfo() is part of the Single UNIX Specification version 1 and later. mallinfo2() is a GNU extension.

HISTORY

mallinfo() first appeared in Version 7 Unix. mallinfo2() was added in glibc 2.10.

BUGS

The interpretation of the fields returned by mallinfo() and mallinfo2() can be complex and may vary between allocator versions. For more detailed and potentially more accurate information, consider using malloc_info(3) with the XML format option.

EXAMPLES

The following program demonstrates the usage of mallinfo2() to display memory allocation statistics before and after allocating and freeing memory blocks.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <malloc.h> // Required for mallinfo2()

static void
display_mallinfo2(void)
{
    struct mallinfo2 mi;
    mi = mallinfo2();
    printf("Total non-mmapped bytes (arena):       %zu\n", mi.arena);
    printf("# of free chunks (ordblks):            %zu\n", mi.ordblks);
    printf("# of free fastbin blocks (smblks):     %zu\n", mi.smblks);
    printf("# of mapped regions (hblks):           %zu\n", mi.hblks);
    printf("Bytes in mapped regions (hblkhd):      %zu\n", mi.hblkhd);
    printf("Max. total allocated space (usmblks):  %zu\n", mi.usmblks);
    printf("Free bytes held in fastbins (fsmblks): %zu\n", mi.fsmblks);
    printf("Total allocated space (uordblks):      %zu\n", mi.uordblks);
    printf("Total free space (fordblks):           %zu\n", mi.fordblks);
    printf("Topmost releasable block (keepcost):   %zu\n", mi.keepcost);
}

int
main(int argc, char *argv[])
{
#define MAX_ALLOCS 500000
    char *alloc[MAX_ALLOCS];
    size_t blockSize, numBlocks, freeBegin, freeEnd, freeStep;

    if (argc < 3 || strcmp(argv[1], "--help") == 0) {
        fprintf(stderr, "Usage: %s num-blocks block-size [free-step "
                "[start-free [end-free]]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    numBlocks = atoi(argv[1]);
    blockSize = atoi(argv[2]);
    freeStep = (argc > 3) ? atoi(argv[3]) : 1;
    freeBegin = (argc > 4) ? atoi(argv[4]) : 0;
    freeEnd = (argc > 5) ? atoi(argv[5]) : numBlocks;

    printf("============== Before allocating blocks ==============\n");
    display_mallinfo2();

    for (size_t j = 0; j < numBlocks; j++) {
        if (numBlocks >= MAX_ALLOCS) {
            fprintf(stderr, "Too many allocations\n");
            exit(EXIT_FAILURE);
        }
        alloc[j] = malloc(blockSize);
        if (alloc[j] == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
    }

    printf("\n============== After allocating blocks ==============\n");
    display_mallinfo2();

    for (size_t j = freeBegin; j < freeEnd; j += freeStep)
        free(alloc[j]);

    printf("\n============== After freeing blocks ==============\n");
    display_mallinfo2();

    exit(EXIT_SUCCESS);
}
