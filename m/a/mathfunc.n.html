DESCRIPCIÓN

El comando expr maneja funciones matemáticas de la forma sin($x) o atan2($y,$x) convirtiéndolas en llamadas de la forma [tcl::mathfunc::sin [expr {$x}]] o [tcl::mathfunc::atan2 [expr {$y}] [expr {$x}]]. Un número de funciones matemáticas están disponibles por defecto dentro del espacio de nombres ::tcl::mathfunc; estas funciones también están disponibles para código aparte de expr, invocando directamente los comandos dados.

Tcl soporta las siguientes funciones matemáticas en expresiones, todas las cuales funcionan únicamente con números de punto flotante a menos que se indique lo contrario:

abs	acos	asin	atan
atan2	bool	ceil	cos
cosh	double	entier	exp
floor	fmod	hypot	int
isqrt	log	log10	max
min	pow	rand	round
sin	sinh	sqrt	srand
tan	tanh	wide

Además de estas funciones predefinidas, las aplicaciones pueden definir funciones adicionales utilizando proc (o cualquier otro método, como interp alias o Tcl_CreateObjCommand) para definir nuevos comandos en el espacio de nombres tcl::mathfunc. Además, una interfaz obsoleta llamada Tcl_CreateMathFunc() está disponible para extensiones escritas en C. Esta última interfaz no se recomienda para implementaciones nuevas.

DEFINICIONES DETALLADAS

abs arg
Devuelve el valor absoluto de arg. Arg puede ser entero o de punto flotante, y el resultado se devuelve en la misma forma.
acos arg
Devuelve el arcocoseno de arg, en el rango [0,pi] radianes. Arg debe estar en el rango [-1,1].
asin arg
Devuelve el arcoseno de arg, en el rango [-pi/2,pi/2] radianes. Arg debe estar en el rango [-1,1].
atan arg
Devuelve el arcotangente de arg, en el rango [-pi/2,pi/2] radianes.
atan2 y x
Devuelve el arcotangente de y/x, en el rango [-pi,pi] radianes. x e y no pueden ser ambos 0. Si x es mayor que 0, esto es equivalente a “atan [expr {y/x}]”.
bool arg
Acepta cualquier valor numérico, o cualquier cadena aceptable para string is boolean, y devuelve el valor booleano correspondiente 0 o 1. Los números distintos de cero son verdaderos. Otros números son falsos. Las cadenas no numéricas producen valores booleanos de acuerdo con string is true y string is false.
ceil arg
Devuelve el valor de punto flotante integral más pequeño (es decir, con una parte fraccionaria cero) no menor que arg. El argumento puede ser cualquier valor numérico.
cos arg
Devuelve el coseno de arg, medido en radianes.
cosh arg
Devuelve el coseno hiperbólico de arg. Si el resultado causara un desbordamiento, se devuelve un error.
double arg
El argumento puede ser cualquier valor numérico. Si arg es un valor de punto flotante, devuelve arg, de lo contrario convierte arg a punto flotante y devuelve el valor convertido. Puede devolver Inf o -Inf cuando el argumento es un valor numérico que excede el rango de punto flotante.
entier arg
El argumento puede ser cualquier valor numérico. Se determina la parte entera de arg y se devuelve. El rango entero devuelto por esta función es ilimitado, a diferencia de int y wide que truncan su rango para ajustarse a anchos de almacenamiento particulares.
exp arg
Devuelve la exponencial de arg, definida como e**arg. Si el resultado causara un desbordamiento, se devuelve un error.
floor arg
Devuelve el valor integral de punto flotante más grande (es decir, con una parte fraccionaria cero) no mayor que arg. El argumento puede ser cualquier valor numérico.
fmod x y
Devuelve el resto de punto flotante de la división de x por y. Si y es 0, se devuelve un error.
hypot x y
Calcula la longitud de la hipotenusa de un triángulo rectángulo, aproximadamente “sqrt [expr {x*x+y*y}]” excepto por ser más estable numéricamente cuando los dos argumentos tienen magnitudes sustancialmente diferentes.
int arg
El argumento puede ser cualquier valor numérico. Se determina la parte entera de arg y luego se devuelven los bits de orden bajo de ese valor entero hasta el tamaño de palabra de la máquina como un valor entero. Como referencia, el número de bytes en la palabra de la máquina se almacena en el elemento wordSize del array tcl_platform.
isqrt arg
Calcula la parte entera de la raíz cuadrada de arg. Arg debe ser un valor positivo, ya sea un entero o un número de punto flotante. A diferencia de sqrt, que está limitada a la precisión de un número de punto flotante, isqrt devolverá un resultado de precisión arbitraria.
log arg
Devuelve el logaritmo natural de arg. Arg debe ser un valor positivo.
log10 arg
Devuelve el logaritmo base 10 de arg. Arg debe ser un valor positivo.
max arg ...
Acepta uno o más argumentos numéricos. Devuelve el argumento con el mayor valor.
min arg ...
Acepta uno o más argumentos numéricos. Devuelve el argumento con el menor valor.
