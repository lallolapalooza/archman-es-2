mako(5) Manual de formatos de archivo mako(5)

NOMBRE

mako - archivo de configuración

DESCRIPCIÓN

El archivo de configuración se encuentra en ~/.config/mako/config o en $XDG_CONFIG_HOME/mako/config. Las líneas de opciones se pueden especificar para configurar mako de la siguiente manera:

clave=valor

Las líneas vacías y las líneas que comienzan con # se ignoran.

OPCIONES DE CONFIGURACIÓN GLOBAL

max-history=n

Establece el número máximo de notificaciones caducadas a mantener en el búfer de historial en n. Si el búfer está lleno, las notificaciones caducadas recientemente reemplazan a las más antiguas. Si es 0, el historial se deshabilita.

Por defecto: 5

sort=+/-time | +/-priority

Ordena las notificaciones entrantes por tiempo y/o prioridad en orden ascendente (+) o descendente (-).

Por defecto: -time

include=ruta_config

Incluye una configuración en la ruta especificada. La ruta debe ser absoluta o, de lo contrario, comenzar con ~.

Por defecto: ninguna

OPCIONES DE ENLACE

Los enlaces permiten realizar una acción cuando se activa un evento.

Opciones soportadas:

on-button-left=acción

Realiza la acción cuando se presiona el botón izquierdo del puntero.

Por defecto: invoke-default-action

on-button-middle=acción

Realiza la acción cuando se presiona el botón central del puntero.

Por defecto: none

on-button-right=acción

Realiza la acción cuando se presiona el botón derecho del puntero.

Por defecto: dismiss

on-touch=acción

Realiza la acción cuando se toca con un dispositivo táctil.

Por defecto: dismiss

on-notify=acción

Realiza la acción cuando se abre la notificación.

Por defecto: none

Acciones soportadas:

none

No hacer nada.

dismiss [--no-history]

Descarta la notificación actual. Si se pasa --no-history, la notificación no se agregará al historial.

dismiss-all

Descarta todas las notificaciones.

dismiss-group

Descarta las notificaciones en el grupo actual.

invoke-action <acción>

Invoca la acción con nombre en la notificación.

Se enviará un token de activación xdg al cliente, permitiendo que el cliente solicite el foco al compositor. El compositor debe soportar el protocolo xdg_activation_v1 y permitir la solicitud de foco para que el siguiente ejemplo funcione correctamente:

[app-name="some-app-id" actionable]
on-button-left=invoke-action mail-reply-sender

invoke-default-action

Invoca la acción por defecto en la notificación.

exec <comando>

Ejecuta un comando de shell.

El comando se ejecutará en un shell POSIX. La variable de shell id se establecerá al ID de la notificación. Por ejemplo, la siguiente opción mostrará un menú de acción interactivo al hacer clic con el botón central:

on-button-middle=exec makoctl menu -n "$id" dmenu -p 'Seleccionar acción: '

La siguiente opción reproducirá un sonido cuando se abra una nueva notificación:

on-notify=exec mpv /usr/share/sounds/freedesktop/stereo/message.oga

OPCIONES DE ESTILO

font=fuente

Establece la fuente en fuente, como una descripción de fuente Pango. Para más información sobre descripciones de fuentes Pango, ver: https://docs.gtk.org/Pango/type_func.FontDescription.from_string.html#description

Por defecto: monospace 10

background-color=color

Establece el color de fondo en color. Ver COLORES para más información.

Por defecto: #285577FF

text-color=color

Establece el color del texto en color. Ver COLORES para más información.

Por defecto: #FFFFFFFF

width=px

Establece el ancho de los pop-ups de notificación.

Por defecto: 300

height=px

Establece la altura máxima de los pop-ups de notificación. Las notificaciones cuyo texto ocupa menos espacio se encogen para ajustarse.

Por defecto: 100

outer-margin=direccional

Establece el margen exterior de cada borde al tamaño especificado por direccional. Ver VALORES DIRECCIONALES para más información. Este margen se aplica al exterior de toda la lista de notificaciones.

Por defecto: 0

margin=direccional

Establece el margen de cada borde al tamaño especificado por direccional. Ver VALORES DIRECCIONALES para más información. Este margen se aplica a cada notificación individual. Tenga en cuenta que se aplica además del margen exterior, lo que significa que las notificaciones primera y última usarán la suma de ambos márgenes.

Por defecto: 10

padding=direccional

Establece el relleno en cada lado al tamaño especificado por direccional. Ver VALORES DIRECCIONALES para más información.

Por defecto: 5

border-size=px

Establece el tamaño del borde del pop-up en px píxeles.

Por defecto: 2

border-color=color

Establece el color del borde del pop-up en color. Ver COLORES para más información.

Por defecto: #4C7899FF

border-radius=direccional

Establece el radio de las esquinas del pop-up en cada lado al tamaño especificado por direccional. Ver VALORES DIRECCIONALES para más información.

Por defecto: 0

progress-color=[over|source] color

Establece el color del indicador de progreso del pop-up en color. Ver COLOR para más información. Para dibujar el indicador de progreso sobre el color de fondo, use el atributo over. Para reemplazar el color de fondo, use el atributo source (esto puede ser útil cuando la notificación es semitransparente).

El progreso se puede indicar en una notificación estableciendo una pista, "value", a un entero entre 0 y 100 inclusive.

Por defecto: over #5588AAFF

icons=0|1

Muestra iconos en las notificaciones.

Por defecto: 1

max-icon-size=px

Establece el tamaño máximo del icono en px píxeles.

Por defecto: 64

icon-path=ruta[:ruta...]

Rutas para buscar iconos cuando una notificación especifica un nombre en lugar de una ruta completa. Delimitado por dos puntos. Esto aproxima el algoritmo de búsqueda utilizado por la Especificación de Temas de Iconos XDG, pero no soporta ninguna de las metadatos del tema. Por lo tanto, si desea buscar temas padres, deberá agregarlos a la ruta manualmente.

La ruta debe ser la raíz del tema de iconos, se buscarán las categorías y resoluciones para la coincidencia más apropiada.

/usr/share/icons/hicolor y /usr/share/pixmaps siempre se buscan.

Por defecto: ""

icon-location=posición

Posición del icono en relación con el texto mostrado. Las opciones válidas son left, right, top y bottom.

Por defecto: left

icon-border-radius=px

Establece el radio de las esquinas del icono en px píxeles.

Por defecto: 0

markup=0|1

Si es 1, habilita el marcado Pango. Si es 0, deshabilita el marcado Pango. Si está habilitado, el marcado Pango se interpretará en su especificador de formato y en el cuerpo de las notificaciones.

Por defecto: 1

actions=0|1

Las aplicaciones pueden solicitar que se asocie una acción con la activación de una notificación. Deshabilitar esto hará que mako ignore estas solicitudes.

Por defecto: 1

history=0|1

Si se establece, mako guardará
