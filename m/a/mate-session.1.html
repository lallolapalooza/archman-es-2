MATE-SESSION(1) Manual de comandos generales MATE-SESSION(1)

NOMBRE

mate-session - Inicia el Entorno de Escritorio MATE.

SINOPSIS

mate-session [OPCIONES]

DESCRIPCIÓN

El programa mate-session inicia el entorno de escritorio MATE. Este comando es típicamente ejecutado por tu Gestor de Inicio/Pantalla (como GDM, LXDM, XDM, SLiM, o desde tus scripts de inicio de X como .xinitrc). Cargará tu sesión guardada, o proporcionará una sesión por defecto para el usuario según lo defina el administrador del sistema (o la instalación MATE por defecto en tu sistema).

La sesión por defecto se define en las claves de dconf bajo /org/mate/desktop/session/
Al guardar una sesión, mate-session guarda las aplicaciones en ejecución actualmente en el directorio ~/.config/mate-session/saved-session del /home del usuario.

mate-session es un gestor de sesiones X11. Puede gestionar aplicaciones MATE así como cualquier otra compatible con SM de X11.

OPCIONES

Las siguientes opciones son soportadas:

-a, --autostart=DIR
Inicia todas las aplicaciones definidas en "DIR", en lugar de iniciar las aplicaciones definidas en /org/mate/desktop/session/default-session
Se pueden pasar múltiples opciones --autostart.
-f, --failsafe
Ejecuta en modo de seguridad. Las aplicaciones especificadas por el usuario no se iniciarán.
--debug
Habilita el código de depuración.
--display=DISPLAY
Pantalla X a utilizar.
--version
Muestra la información de la versión y sale.
-?, -h, --help
Imprime las opciones estándar de la línea de comandos.
--help-all
Imprime todas las opciones de la línea de comandos.

ENTORNO

mate-session establece varias variables de entorno para el uso de sus procesos hijos:

SESSION_MANAGER

Esta variable es utilizada por los clientes conscientes del gestor de sesiones para contactar con mate-session.

DISPLAY

Esta variable se establece a la pantalla X que está siendo utilizada por mate-session. Tenga en cuenta que si se utiliza la opción --display, esta podría ser diferente de la configuración de la variable de entorno cuando se invoca mate-session.

ARCHIVOS

~/.config/autostart
/usr/share/autostart
/usr/share/mate/autostart
Las aplicaciones definidas en los directorios anteriores se iniciarán al iniciar sesión. Se puede utilizar mate-session-properties(1) para configurarlas fácilmente.

~/.config/mate-session/saved-session

Este directorio contiene la lista de aplicaciones de la sesión guardada.
