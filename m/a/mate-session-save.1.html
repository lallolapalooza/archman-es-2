MATE-SESSION-SAVE(1) Manual de Comandos Generales MATE-SESSION-SAVE(1)

NOMBRE

mate-session-save - Finalizar o guardar la sesión MATE actual

SINOPSIS

mate-session-save [--logout] [--force-logout] [--logout-dialog] [--shutdown-dialog] [--gui] [--kill [--silent]]

DESCRIPCIÓN

El programa mate-session-save se puede utilizar desde una sesión MATE para finalizar la sesión MATE actual o guardar una instantánea de las aplicaciones en ejecución en ese momento (pero no ambas cosas). Esta sesión se restaurará más tarde en tu próxima sesión MATE.

USO

La opción --gui informará de los errores en cuadros de diálogo en lugar de imprimirlos en stderr.

Si se llama con la opción --logout, se finalizará la sesión MATE actual, a menos que el cierre de sesión haya sido inhibido por una aplicación. La opción --force-logout se puede utilizar para finalizar la sesión independientemente del estado de inhibición.

Cuando se proporciona la opción --logout-dialog, se muestra el diálogo estándar que presenta las opciones de cierre de sesión. Cuando se proporciona la opción --shutdown-dialog, se muestra el diálogo estándar que presenta las opciones de apagado.

Las opciones --kill y --silent están obsoletas. La opción --kill es equivalente a la opción --logout-dialog. Si se usa --silent con --kill, se comportará como si se hubiera usado --logout.

La sesión no se guarda cuando se llama a mate-session-save con cualquiera de las opciones que finalizan la sesión.

OPCIONES

--logout
Cerrar sesión
--force-logout
Cerrar sesión, ignorando cualquier inhibidor existente
--logout-dialog
Mostrar diálogo de cierre de sesión
--shutdown-dialog
Mostrar diálogo de apagado
--gui

Usar cuadros de diálogo para errores
--display=DISPLAY
Pantalla X a usar.
--version
Mostrar información de la versión y salir.
-?, -h, --help
Imprimir opciones estándar de línea de comandos.
--help-all
Imprimir todas las opciones de línea de comandos.
