makoctl(1) Manual de comandos generales makoctl(1)

NOMBRE

makoctl - controla el demonio mako(1)

SINOPSIS

makoctl [comando] [opciones...]

DESCRIPCIÓN

Envía comandos IPC al demonio mako en ejecución a través de dbus.

COMANDOS

dismiss [-a|--all] [-g|--group] [-n <id>]

Descarta una notificación.

Opciones:

-a, --all

Descarta todas las notificaciones.

-g, --group

Descarta el primer grupo de notificaciones.

-h, --no-history

Descarta la notificación actual sin añadirla al historial.

-n <id>

Descarta la notificación con el id dado. Por defecto, la primera notificación.

restore

Restaura la notificación caducada más reciente del búfer de historial.

invoke [-n <id>] [acción]

Invoca una acción en una notificación. Si no se especifica acción, invoca la acción predeterminada. Los nombres de las acciones se pueden descubrir usando `makoctl list`.

Opciones:

-n <id>

Invoca la acción en la notificación con el id dado. Por defecto, la primera notificación.

menu [-n <id>] <programa> [argumento...]

Utiliza un programa para seleccionar una acción en una notificación. La lista de acciones se une con saltos de línea y se pasa a programa. El programa debe escribir la acción seleccionada en la salida estándar. Si se proporciona una acción, se invocará esa acción.

Si no se encuentra ninguna acción o no se selecciona ninguna acción, makoctl devolverá un valor distinto de cero.

Opciones:

-n <id>

Lista las acciones de la notificación con el id dado. Por defecto, la primera notificación.

Ejemplos:

makoctl menu dmenu -p 'Seleccionar Acción: '
makoctl menu -n 12345 wofi -d -p 'Elegir Acción: '

list

Recupera una lista de las notificaciones actuales.

history

Recupera una lista de las notificaciones descartadas.

reload

Recarga el archivo de configuración.

mode
mode -s <modo>...
mode [-a modo]... [-r modo]... [-t modo]... +
Cuando se ejecuta sin ninguna opción, recupera una lista de los modos actuales.

Cuando se ejecuta con la opción -s, reemplaza los modos actuales con la lista proporcionada.

Cuando se ejecuta con las opciones -a o -r, añade o elimina el modo proporcionado de los modos actuales.

Cuando se ejecuta con la opción -t, alterna el modo eliminándolo cuando está presente y añadiéndolo en caso contrario.

Consulte la sección MODES en mako(5) para obtener más información sobre los modos.

help, -h, --help

Muestra el mensaje de ayuda y sale.
