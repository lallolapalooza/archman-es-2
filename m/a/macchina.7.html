MACCHINA(7) Información Miscelánea Manual MACCHINA(7)

NOMBRE

macchina - tematización.

SINOPSIS

$XDG_CONFIG_HOME/macchina/themes, ~/.config/macchina/themes.

DESCRIPCIÓN

Los temas son tu interfaz para personalizar todos los aspectos visuales de macchina. La siguiente página del manual cubre todo lo que necesitas saber para diseñar tu propio tema.

OPCIONES GENERALES

Las opciones generales deben configurarse en la parte superior del archivo de configuración del tema, ya que no pertenecen a ninguna sección en particular.

espaciado

Define la cantidad de espacio a dejar entre el separador y el contenido adyacente, p. ej.:

espaciado = 1

relleno

Define la cantidad de relleno a dejar entre el contenido y su entorno, p. ej.:

relleno = 0

ocultar_ascii

Deshabilita la representación de ASCII, ya sea incorporado o personalizado, p. ej.:

ocultar_ascii = falso

preferir_pequeño_ascii

Para ASCII incorporados, usa siempre variantes más pequeñas, p. ej.:

preferir_pequeño_ascii = verdadero

separador

Define el glifo a usar para el separador, p. ej.:

separador = "-->"

color_clave

Define el color de las claves.

Acepta valores hexadecimales:

color = "#00FF00"

Valores indexados:

color = "046"

Nombres de color predefinidos, donde el uso de mayúsculas y minúsculas no distingue:

color = "Verde"

color_separador

Define el color del separador.

Acepta valores hexadecimales:

color = "#00FF00"

Valores indexados:

color = "046"

Nombres de color predefinidos, donde el uso de mayúsculas y minúsculas no distingue:

color = "Verde"

SECCIÓN DE PALETA

Esta sección, notada como [paleta], ofrece un componente visual que muestra y representa el esquema de colores activo de tu emulador de terminal.

tipo

Define el conjunto de colores a utilizar para la paleta, con valores posibles de "Oscuro", "Claro", "Completo" (distingue mayúsculas y minúsculas).

glifo

Define el glifo a utilizar para la paleta, p. ej.:

glifo = "() "

Deberías añadir un espacio para dejar algo de espacio entre los glifos.

visible

Define si mostrar u ocultar la paleta, p. ej.:

visible = verdadero

SECCIÓN DE BARRA

Esta sección, notada como [barra], reemplaza datos que varían de 0 a 100% con barras.

glifo

Define el glifo a utilizar para todas las barras, p. ej.:

glifo = "o"

símbolo_apertura

Define el carácter a utilizar para los delimitadores de apertura. Asegúrate

de rodear el valor con comillas simples y no comillas dobles, p. ej.:

símbolo_apertura = '('

símbolo_cierre

Define el carácter a utilizar para los delimitadores de cierre. Asegúrate de rodear el valor con comillas simples y no comillas dobles, p. ej.:

símbolo_cierre = ')'

visible

Define si mostrar u ocultar las barras, p. ej.:

visible = verdadero

ocultar_delimitadores

Define si mostrar u ocultar los delimitadores de las barras, es decir, los caracteres que rodean las barras, p. ej.:

ocultar_delimitadores = falso

SECCIÓN DE CAJA

La sección, notada como [caja], ofrece un componente de caja que se renderiza para rodear la información de tu sistema.

título

Define el título de la caja, p. ej.:

título = "Hidrógeno"

borde

Define el tipo de borde a usar para la caja, con valores posibles de "plano", "grueso", "redondeado" o "doble".

visible

Define si mostrar u ocultar la caja, p. ej.:

visible = verdadero

SECCIÓN MARGEN_INTERIOR_DE_CAJA

x

Define el margen horizontal a dejar entre el contenido y la caja, p. ej.:

x = 2

y

Define el margen vertical a dejar entre el contenido y la caja, p. ej.:

y = 1

SECCIÓN ASCII PERSONALIZADO

Esta sección, notada como [ascii_personalizado], permite especificar tu propio arte ASCII. Se admiten secuencias de escape ANSI.

color

Define el color del ASCII.

Acepta valores hexadecimales:

color = "#00FF00"

Valores indexados:

color = "046"

Nombres de color predefinidos (no distingue mayúsculas y minúsculas):

color = "Verde"

ruta

Define la ruta a un archivo en tu sistema de archivos que contiene el arte ASCII que deseas mostrar, p. ej.:

ruta = "~/ascii/arch_linux"

SECCIÓN ALEATORIZAR

Esta sección, notada como [aleatorizar], se utiliza para aleatorizar la selección de colores.

color_clave

Define si se debe aleatorizar el color de las claves, p. ej.:

color_clave = verdadero

color_separador

Define si se debe aleatorizar el color del separador, p. ej.:

color_separador = verdadero

RANDOMIZE SECTION

Esta sección, denotada como [randomize], te permite configurar la generación de colores aleatorios.

Actualmente, esta sección solo acepta un parámetro: mode.

El parámetro mode determina el tipo de color aleatorio del que se escogerá uno, con valores posibles de "hexadecimal", "indexed" o "base" (sin distinguir mayúsculas y minúsculas).

•Si se especifica "hexadecimal", obtendrás un color aleatorio en el rango
del #000000 al #FFFFFF.
•Si se especifica "indexed", obtendrás un color aleatorio en el rango del 0 al
255.
•Si se especifica "base", verás un color aleatorio del siguiente conjunto de
colores: "black", "white", "red", "green", "blue", "yellow", "magenta" y "cyan".

SECCIÓN DE CLAVES

Esta sección, denotada como [keys], te permite modificar el texto de cada clave.

Por ejemplo, la lectura "Processor", que por defecto aparece como "CPU" en la salida de macchina, puede renombrarse a lo que desees estableciendo la opción "cpu".

host

Define el texto de la lectura Host, por ejemplo:

host = "Host"

kernel

Define el texto de la lectura Kernel, por ejemplo:

kernel = "Kernel"

os

Define el texto de la lectura OperatingSystem, por ejemplo:

os = "OS"

machine

Define el texto de la lectura Machine, por ejemplo:

machine= "Machine"

de

Define el texto de la lectura DesktopEnvironment, por ejemplo:

de = "DE"

wm

Define el texto de la lectura WindowManager, por ejemplo:

wm = "WM"

distro

Define el texto de la lectura Distribution, por ejemplo:

distro = "Distro"

terminal

Define el texto de la lectura Terminal, por ejemplo:

terminal = "Term"

shell

Define el texto de la lectura Shell, por ejemplo:

shell = "Shell"

packages

Define el texto de la lectura Packages, por ejemplo:

packages = "Packages"

uptime

Define el texto de la lectura Uptime, por ejemplo:

uptime = "Uptime"

local_ip

Define el texto de la lectura LocalIP, por ejemplo:

local_ip = "Local IP"

memory

Define el texto de la lectura Memory, por ejemplo:

memory = "Memory"

battery

Define el texto de la lectura Battery, por ejemplo:

battery = "Battery"

backlight

Define el texto de la lectura Backlight, por ejemplo:

backlight = "Brightness"

resolution

Define el texto de la lectura Resolution, por ejemplo:

resolution = "Resolution"

cpu

Define el texto de la lectura Processor, por ejemplo:

cpu = "CPU"

cpu_load

Define el texto de la lectura ProcessorLoad, por ejemplo:

cpu_load = "CPU %"

gpu

Define el texto de la(s) lectura(s) GPU, por ejemplo:

gpu = "GPU"

disk_space

Define el texto de la lectura de espacio en disco, por ejemplo:

disk_space = "Disk Space"
