matherr(3) Manual de funciones de biblioteca matherr(3)

NOMBRE

matherr - Manejo de excepciones de la biblioteca matemática SVID

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
[[deprecated]] int matherr(struct exception *exc);
[[deprecated]] extern _LIB_VERSION_TYPE _LIB_VERSION;

DESCRIPCIÓN

Nota: el mecanismo descrito en esta página ya no es compatible con glibc. Antes de glibc 2.27, se había marcado como obsoleto. Desde glibc 2.27, el mecanismo se ha eliminado por completo. Las nuevas aplicaciones deberían utilizar las técnicas descritas en math_error(7) y fenv(3). Esta página documenta el mecanismo matherr() como ayuda para mantener y migrar aplicaciones antiguas.

La Definición de Interfaz System V (SVID) especifica que varias funciones matemáticas deben invocar una función llamada matherr() si se detecta una excepción matemática. Esta función se llama antes de que la función matemática devuelva; después de que matherr() retorna, el sistema retorna a la función matemática, que a su vez retorna al llamador.

Para emplear matherr(), el programador debe definir la macro de prueba de características _SVID_SOURCE (antes de incluir cualquier archivo de cabecera) y asignar el valor _SVID_ a la variable externa _LIB_VERSION.

El sistema proporciona una versión predeterminada de matherr(). Esta versión no hace nada y devuelve cero (ver más abajo la importancia de esto). El matherr() predeterminado puede ser reemplazado por una versión definida por el programador, que se invocará cuando ocurra una excepción. La función se invoca con un argumento, un puntero a una estructura exception, definida como sigue:


struct exception {
    int    type;      /* Tipo de excepción */
    char  *name;      /* Nombre de la función que causa la excepción */
    double arg1;      /* 1er argumento de la función */
    double arg2;      /* 2do argumento de la función */
    double retval;    /* Valor de retorno de la función */
}

El campo type tiene uno de los siguientes valores:

DOMINIO
Ocurrió un error de dominio (el argumento de la función estaba fuera del rango para el cual la función está definida). El valor de retorno depende de la función; errno se establece en EDOM.
POLO
Ocurrió un error de polo (el resultado de la función es infinito). El valor de retorno en la mayoría de los casos es HUGE (el mayor número de punto flotante de precisión simple), con el signo apropiado. En la mayoría de los casos, errno se establece en EDOM.
SOBREFLUJO
Ocurrió un desbordamiento. En la mayoría de los casos, se devuelve el valor HUGE y errno se establece en ERANGE.
SUBFLUJO
Ocurrió un subdesbordamiento. Se devuelve 0.0 y errno se establece en ERANGE.
PERDIDA_TOTAL
Pérdida total de significancia. Se devuelve 0.0 y errno se establece en ERANGE.
PERDIDA_PARCIAL
Pérdida parcial de significancia. Este valor no se utiliza en glibc (y en muchos otros sistemas).

Los campos arg1 y arg2 son los argumentos suministrados a la función (arg2 no está definido para funciones que solo toman un argumento).

El campo retval especifica el valor de retorno que la función matemática devolverá a su llamador. El matherr() definido por el programador puede modificar este campo para cambiar el valor de retorno de la función matemática.

Si la función matherr() devuelve cero, entonces el sistema establece errno como se describe anteriormente, y puede imprimir un mensaje de error en la salida estándar de error (ver más abajo).

Si la función matherr() devuelve un valor distinto de cero, entonces el sistema no establece errno y no imprime un mensaje de error.

NOMBRE

matherr - manejo de errores matemáticos

BIBLIOTECA

Biblioteca matemática (libm).

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <math.h>

int matherr(struct exception *exc);

DESCRIPCIÓN

Las funciones de punto flotante definidas en math.h(3) pueden generar varias condiciones de error. Tradicionalmente, la mayoría de estas funciones informan de errores estableciendo la variable global errno(3) y devolviendo un valor específico (por ejemplo, HUGE_VAL en caso de desbordamiento). Algunas funciones, como sqrt(3), también pueden devolver un valor específico en un caso de dominio de error (por ejemplo, NaN para la raíz cuadrada de un número negativo).

La función matherr() se utiliza para informar de los errores que se producen al calcular funciones matemáticas. Cuando se produce un error en una función matemática, se llama a matherr() con un puntero a una estructura de tipo struct exception. La estructura struct exception se define de la siguiente manera:

struct exception {
    int         type;   /* Tipo de error */
    char        *name;  /* Nombre de la función que falló */
    double      arg1;   /* Primer argumento de la función */
    double      arg2;   /* Segundo argumento de la función */
    double      retval; /* Valor devuelto por la función */
};

Los valores posibles para type son:

DOMAIN
El argumento de entrada está fuera del dominio de la función.
OVERFLOW
El resultado de la función es demasiado grande para ser representado como un valor de tipo double.
UNDERFLOW
El resultado de la función es demasiado pequeño para ser representado como un valor de tipo double distinto de cero.
SING
Se ha producido una singularidad (por ejemplo, división por cero).
TLOSS
Se ha producido una pérdida de significación total.
PLOSS
Se ha producido una pérdida de significación parcial.

El campo name apunta a una cadena que contiene el nombre de la función matemática que falló (por ejemplo, "log", "sqrt").

Los campos arg1 y arg2 contienen los argumentos pasados a la función matemática. Si la función solo tiene un argumento, arg2 se establece en 0.

El campo retval contiene el valor que la función matemática ha devuelto. Este valor puede ser modificado por matherr().

La función matherr() debe devolver un valor entero. Si devuelve 0, significa que el error ha sido manejado y que la función matemática debe devolver el valor especificado en exc->retval. Si matherr() devuelve un valor distinto de cero, significa que el error no ha sido manejado, y la función matemática seguirá su comportamiento predeterminado de manejo de errores (estableciendo errno(3) y devolviendo un valor de error específico).

EJEMPLOS

El programa de ejemplo demuestra el uso de matherr() al llamar a log(3). El programa toma hasta tres argumentos de línea de comandos. El primer argumento es el número de punto flotante que se pasará a log(3). Si se proporciona el segundo argumento opcional, entonces _LIB_VERSION se establece en _SVID_ para que se llame a matherr(), y el entero suministrado en el argumento de la línea de comandos se utiliza como valor de retorno de matherr(). Si se proporciona el tercer argumento opcional de la línea de comandos, especifica un valor de retorno alternativo que matherr() debe asignar como valor de retorno de la función matemática.

La siguiente ejecución de ejemplo, donde a log(3) se le da un argumento de 0.0, no utiliza matherr():


$ ./a.out 0.0
errno: Numerical result out of range
x=-inf

En la siguiente ejecución, se llama a matherr() y devuelve 0:


$ ./a.out 0.0 0
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
log: SING error
errno: Numerical argument out of domain
x=-340282346638528859811704183484516925440.000000

El mensaje "log: SING error" fue impreso por la biblioteca C.

En la siguiente ejecución, se llama a matherr() y devuelve un valor distinto de cero:


$ ./a.out 0.0 1
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
x=-340282346638528859811704183484516925440.000000

En este caso, la biblioteca C no imprimió ningún mensaje y errno no se estableció.

En la siguiente ejecución, se llama a matherr(), se cambia el valor de retorno de la función matemática y se devuelve un valor distinto de cero:


$ ./a.out 0.0 1 12345.0
matherr SING exception in log() function
        args:   0.000000, 0.000000
        retval: -340282346638528859811704183484516925440.000000
x=12345.000000

Código fuente del programa

#define _SVID_SOURCE
#include <errno.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
static int matherr_ret = 0;     /* Valor que matherr()
                                   debería devolver */
static int change_retval = 0;   /* ¿Debería matherr() cambiar
                                   el valor de retorno de la función? */
static double new_retval;       /* Nuevo valor de retorno de la función */
int
matherr(struct exception *exc)
{
    fprintf(stderr, "matherr %s exception in %s() function\n",
            (exc->type == DOMAIN) ?    "DOMAIN" :
            (exc->type == OVERFLOW) ?  "OVERFLOW" :
            (exc->type == UNDERFLOW) ? "UNDERFLOW" :
            (exc->type == SING) ?      "SING" :
            (exc->type == TLOSS) ?     "TLOSS" :
            (exc->type == PLOSS) ?     "PLOSS" : "???",
            exc->name);
    fprintf(stderr, "        args:   %f, %f\n",
            exc->arg1, exc->arg2);
    fprintf(stderr, "        retval: %f\n", exc->retval);
    if (change_retval)
        exc->retval = new_retval;
    return matherr_ret;
}
int
main(int argc, char *argv[])
{
    double x;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s <argval>"
                " [<matherr-ret> [<new-func-retval>]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (argc > 2) {
        _LIB_VERSION = _SVID_;
        matherr_ret = atoi(argv[2]);
    }
    if (argc > 3) {
        change_retval = 1;
        new_retval = atof(argv[3]);
    }
    x = log(atof(argv[1]));
    if (errno != 0)
        perror("errno");
    printf("x=%f\n", x);
    exit(EXIT_SUCCESS);
}
