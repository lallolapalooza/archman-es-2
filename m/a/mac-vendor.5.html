MAC-VENDOR(5) Manual de Formatos de Archivo MAC-VENDOR(5)

NOMBRE

mac-vendor - Archivo de vendedores de Ethernet para arp-scan

SINOPSIS

mac-vendor.txt

DESCRIPCIÓN

El archivo mac-vendor.txt contiene mapeos de MAC de Ethernet a cadenas de vendedor para arp-scan. Se utiliza además de las listas OUI de IEEE en ieee-oui.txt. Es para mapeos de MAC-vendedor que no están cubiertos por las listas de fabricantes de IEEE.

Cada línea en el archivo mac-vendor.txt contiene un mapeo MAC-vendedor en el formato:

<Prefijo-MAC><TAB><Vendedor>

Donde <Prefijo-MAC> es el prefijo de la dirección MAC en hexadecimal, y <Vendedor> es el nombre del vendedor. El prefijo puede ser de cualquier longitud, desde dos dígitos hexadecimales (un octeto) hasta doce dígitos hexadecimales (seis octetos, la dirección de hardware Ethernet completa).

Los caracteres hexadecimales alfabéticos [A-F] pueden usar mayúsculas o minúsculas, y los símbolos separadores como ":" , "-" y "." se ignoran. Esto permite el uso de direcciones MAC en formato estándar en este archivo.

Por ejemplo:

01:23:45 coincide con 01:23:45:xx:xx:xx, donde xx representa cualquier valor;
01:23:45:6 coincide con 01:23:45:6x:xx:xx; y
01:23:45:67 coincide con 01:23:45:67:xx:xx.

No incluya entradas de las listas OUI de IEEE, ya que estas ya están en el archivo ieee-oui.txt, que es utilizado automáticamente por arp-scan. Consulte get-oui(1) para obtener detalles sobre cómo actualizar las listas OUI.

El orden de las entradas en el archivo no es importante.

Las líneas en blanco y las líneas que comienzan con "#" se ignoran. arp-scan intentará hacer coincidir prefijos más grandes antes de intentar hacer coincidir prefijos más pequeños, y se detendrá en la primera coincidencia.

ARCHIVOS

/usr/local/share/arp-scan/mac-vendor.txt

EJEMPLO

# Del informe de error de Debian para nmap #369681 con fecha del 31 de mayo de 2006
52:54:00        QEMU
b0:c4:20        Bochs
# De RFC 2338: 00-00-5E-00-01-{VRID}
00:00:5e:00:01  VRRP (el último octeto es VRID)
# Microsoft WLBS (Windows NT Load Balancing Service)
# http://www.microsoft.com/technet/prodtechnol/acs/reskit/acrkappb.mspx
02:bf   Microsoft WLBS (los últimos cuatro octetos son la dirección IP)
# Cisco HSRP (Hot Standby Routing Protocol)
# 00-00-0c-07-ac-XX, donde XX es el número de grupo HSRP (0 a 255)
00:00:0c:07:ac  HSRP (el último octeto es el número de grupo)
