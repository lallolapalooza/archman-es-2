NOMBRE

makepkg-template - utilidad de plantillas para la construcción de paquetes

SINOPSIS

makepkg-template [opciones]

DESCRIPCIÓN

makepkg-template es un script para facilitar el mantenimiento de múltiples PKGBUILDs similares. Permite mover la mayor parte del código del PKGBUILD a un archivo de plantilla y utiliza marcadores para permitir la actualización in situ de los PKGBUILDs existentes si la plantilla ha sido cambiada.

Los archivos de plantilla pueden contener cualquier código permitido en un PKGBUILD. Puedes pensarlos como archivos externos incluidos con "." o "source", pero serán insertados en el PKGBUILD por makepkg-template para que no dependas del archivo de plantilla al construir el paquete.

Los marcadores son comentarios de bash en la forma:

# template start; key=valor; key2=valor2; ...

y

# template end;

Las claves utilizadas actualmente son: name (obligatoria) y version. Los nombres de las plantillas se limitan a alfanuméricos, "@", "+", ".", "-" y "_". Las versiones se limitan a números y ".".

Para la creación inicial, hay un atajo de una línea que no necesita un marcador de fin:

# template input; key=valor;

El uso de este atajo hará que makepkg-template lo reemplace con marcadores de inicio y fin y el código de la plantilla en la primera ejecución.

Los archivos de plantilla deben almacenarse en un directorio y los nombres de archivo deben ser "$nombre_plantilla-$version.template" con un enlace simbólico "$nombre_plantilla.template" que apunte a la plantilla más reciente. Si la versión no está establecida en el marcador, makepkg-template utilizará automáticamente el objetivo de "$nombre_plantilla.template", de lo contrario se usará la versión especificada. Esto permite una verificación más fácil de los PKGBUILDs no confiables si la plantilla es confiable. Verificas el código no de plantilla y luego usas un comando similar a este:

diff -u <(makepkg-template -o -) PKGBUILD

Los archivos de plantilla también pueden contener marcadores que conducen a plantillas anidadas en el PKGBUILD resultante. Si usas marcadores en una plantilla, por favor, establece la versión que usaste/probaste en el marcador de inicio/entrada para que otras personas puedan recrear correctamente a partir de las plantillas.

OPCIONES

-p, --input <script de construcción>

Lee el script de construcción en lugar del predeterminado.

-o, --output <script de construcción>

Escribe el archivo actualizado en el script de construcción en lugar de sobrescribir el archivo de entrada.

-n, --newest

Utiliza siempre el archivo de plantilla más reciente disponible.

--template-dir <dir>

Cambia el directorio donde buscamos los archivos de plantilla. Esta opción se puede dar varias veces, en cuyo caso los archivos encontrados en el directorio dado por último tendrán precedencia.

EJEMPLO PKGBUILD

pkgname=perl-config-simple
pkgver=4.58
pkgrel=1
pkgdesc="clase simple de archivo de configuración"
arch=('any')
license=('PerlArtistic' 'GPL')
depends=('perl')
source=("http://search.cpan.org/CPAN/authors/id/S/SH/SHERZODR/Config-Simple-${pkgver}.tar.gz")
sha256sums=('dd9995706f0f9384a15ccffe116c3b6e22f42ba2e58d8f24ed03c4a0e386edb4')
_distname="Config-Simple"
# template start; name=perl-module; version=1.0;
_distdir="${_distname}-${pkgver}"
url="https://metacpan.org/release/${_distname}"
options+=('!emptydirs')
build() {
        cd "$srcdir/$_distdir"
        perl Makefile.PL INSTALLDIRS=vendor
        make
}
check() {
        cd "$srcdir/$_distdir"
        make test
}
package() {
        cd "$srcdir/$_distdir"
        make DESTDIR="$pkgdir" install
}
# template end;
