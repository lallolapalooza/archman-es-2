MARIADB-INSTALL-DB(1) Sistema de bases de datos MariaDB MARIADB-INSTALL-DB(1)

NOMBRE

mariadb-install-db - inicializa el directorio de datos de MariaDB (mariadb-install-db es ahora un enlace simbólico a mariadb-install-db)

SINOPSIS

mariadb-install-db [opciones]

DESCRIPCIÓN

mariadb-install-db inicializa el directorio de datos de MariaDB y crea las tablas del sistema que contiene, si no existen.

Para invocar mariadb-install-db, usa la siguiente sintaxis:

shell> mariadb-install-db [opciones]

Dado que el servidor MariaDB, mariadbd, necesita acceder al directorio de datos cuando se ejecute posteriormente, deberías ejecutar mariadb-install-db desde la misma cuenta que se usará para ejecutar mariadbd o ejecutarlo como root y usar la opción --user para indicar el nombre de usuario con el que se ejecutará mariadbd. Puede ser necesario especificar otras opciones como --basedir o --datadir si mariadb-install-db no usa las ubicaciones correctas para el directorio de instalación o el directorio de datos. Por ejemplo:

shell> bin/mariadb-install-db --user=mysql \
         --basedir=/opt/mysql/mysql \
         --datadir=/opt/mysql/mysql/data

mariadb-install-db necesita invocar a mariadbd con las opciones --bootstrap y --skip-grant-tables (ver Sección 2.3.2, “Opciones de configuración típicas”). Si MariaDB se configuró con la opción --disable-grant-options, --bootstrap y --skip-grant-tables se deshabilitarán. Para manejar esto, establece la variable de entorno mariadbd_BOOTSTRAP al nombre de ruta completo de un servidor que tenga todas las opciones habilitadas. mariadb-install-db usará ese servidor.

mariadb-install-db soporta las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de opciones [mariadb-install-db] y (si son comunes a mariadbd) [mariadbd].

•--basedir=ruta

La ruta al directorio de instalación de MariaDB.

•--builddir=ruta

Si usas --srcdir con compilaciones fuera del directorio, necesitarás establecer esto a la ubicación del directorio de compilación donde residen los archivos compilados.

•--cross-bootstrap

Para uso interno. Se usa al compilar las tablas del sistema de MariaDB en un host diferente al objetivo.

•--datadir=ruta, --ldata=ruta

La ruta al directorio de datos de MariaDB.

•--defaults-extra-file=archivo

Establece archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos de valores predeterminados globales. Debe especificarse como primera opción.

•--defaults-file=archivo

Establece archivo como el archivo del que leer las opciones predeterminadas, anulando los archivos de valores predeterminados globales. Debe especificarse como primera opción.

•--defaults-group-suffix=nombre

Además de los grupos dados, también lee grupos con este sufijo.

•--force

Hace que mariadb-install-db se ejecute incluso si DNS no funciona. En ese caso, las entradas de tablas de concesión que normalmente usan nombres de host usarán direcciones IP.

•--help

Muestra un mensaje de ayuda y sale.

•--no-defaults

No leer opciones predeterminadas de ningún archivo de opciones. Debe especificarse como primer argumento.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe especificarse como primer argumento.

•--rpm

Para uso interno. Esta opción es utilizada por los archivos RPM durante el proceso de instalación de MariaDB.

•--skip-name-resolve

Usa direcciones IP en lugar de nombres de host al crear entradas de tablas de concesión. Esta opción puede ser útil si tu DNS no funciona.

•--srcdir=ruta

Para uso interno. El directorio bajo el cual mariadb-install-db busca archivos de soporte como el archivo de mensajes de error y el archivo para poblar las tablas de ayuda.4.

•--user=nombre_usuario

El nombre de usuario de inicio de sesión a usar para ejecutar mariadbd. Los archivos y directorios creados por mariadbd serán propiedad de este usuario. Debes ser root para usar esta opción. Por defecto, mariadbd se ejecuta usando tu nombre de inicio de sesión actual y los archivos y directorios que cree serán propiedad tuya.

•--extra-file=ruta_archivo

Añade un archivo SQL definido por el usuario, que se ejecutará después de la inicialización regular de la base de datos.

•--verbose

Modo detallado. Imprime más información sobre lo que hace el programa.

•--windows

Para uso interno. Esta opción se usa para crear distribuciones de Windows.
