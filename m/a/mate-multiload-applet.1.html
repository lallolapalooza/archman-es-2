NOMBRE

mate-multiload-applet - Applet de Multicarga (cpu, carga promedio, memoria, red, swap) para el panel de MATE.

SINOPSIS

mate-multiload-applet [ --activate-goad-server[=GOAD_ID] ]

DESCRIPCIÓN

mate-multiload-applet contiene 5 applets.

Applet de Carga de CPU. Para agregar este applet a un Panel, haga clic derecho en el Panel y elija Applets->Monitores->CPULoad

Applet de Carga Promedio. Para agregar este applet a un Panel, haga clic derecho en el Panel y elija Applets->Monitores->Load Average

Applet de Memoria. Para agregar este applet a un Panel, haga clic derecho en el Panel y elija Applets->Monitores->MemLoad

Applet de Red. Para agregar este applet a un Panel, haga clic derecho en el Panel y elija Applets->Monitores->NetLoad

Applet de Swap. Para agregar este applet a un Panel, haga clic derecho en el Panel y elija Applets->Monitores->SwapLoad

OPCIONES

--activate-goad-server
(Uso interno) ID del servidor GOAD para activar

GOAD_ID puede ser:

multiload_cpuload_applet inicia el applet de CPU.

multiload_loadavg_applet inicia el applet de carga promedio.

multiload_memload_applet inicia el applet de memoria.

multiload_netload_applet inicia el applet de red.

multiload_swapload_applet inicia el applet de swap.
