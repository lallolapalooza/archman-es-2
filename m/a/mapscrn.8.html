MAPSCRN(8) Manual del Administrador del Sistema MAPSCRN(8)

NOMBRE

mapscrn - cargar tabla de mapeo de salida de pantalla

SINOPSIS

mapscrn [opciones] archivo_mapa

DESCRIPCIÓN

El comando mapscrn está obsoleto; su función ahora está integrada en setfont. Sin embargo, por compatibilidad con versiones anteriores, todavía está disponible como un comando separado.

El comando mapscrn carga una tabla de mapeo de caracteres de salida definida por el usuario en el controlador de consola. El controlador de consola puede ponerse posteriormente en modo de uso de tabla de mapeo definida por el usuario al enviar una secuencia de escape especial al dispositivo de consola. Esta secuencia es <esc>(K para el conjunto de caracteres G0 y <esc>)K para el conjunto de caracteres G1. Cuando se proporciona la opción -o, el mapa antiguo se guarda en map.orig.

USO

Hay dos tipos de tablas de mapeo: tablas directas a fuente, que proporcionan una posición de fuente para cada valor de byte del usuario, y tablas de usuario a unicode que proporcionan un valor unicode para cada byte del usuario. El glifo correspondiente se encuentra ahora utilizando el índice unicode de la fuente. El comando

mapscrn trivial
configura una tabla directa a fuente uno a uno donde los bytes del usuario acceden directamente a la fuente. Esto es útil para fuentes que están en el mismo orden que el conjunto de caracteres que uno usa. Un comando como
mapscrn 8859-2
configura una tabla de usuario a unicode que asume que el usuario usa ISO 8859-2.

FORMATO DE ENTRADA

El comando mapscrn puede leer el mapa en uno de dos formatos:
1. Datos binarios de 256 o 512 bytes
2. Archivo de texto de dos columnas
El formato (1) es una imagen directa de la tabla de traducción. Las tablas de 256 bytes son directas a fuente, las tablas de 512 bytes son tablas de usuario a unicode. El formato (2) se utiliza para llenar la tabla de la siguiente manera: la celda con el desplazamiento mencionado en la primera columna se llena con el valor mencionado en la segunda columna. Cuando ocurren valores mayores que 255, o los valores se escriben utilizando la notación U+xxxx, se asume que la tabla es una tabla de usuario a unicode; de lo contrario, es una tabla directa a fuente.

Los valores en el archivo pueden especificarse en uno de varios formatos:
1. Decimal: Cadena de dígitos decimales que no comienzan con '0'
2. Octal: Cadena de dígitos octales que comienzan con '0'.
3. Hexadecimal: Cadena de dígitos hexadecimales precedidos por "0x".
4. Unicode: Cadena de cuatro dígitos hexadecimales precedidos por "U+".
5. Carácter: Carácter único entre comillas simples. (Y se usa el valor binario). Tenga en cuenta que el espacio en blanco, la coma, el carácter de tabulación y '#' no se pueden especificar con este formato.
6. Carácter UTF-8: Carácter único (posiblemente de varios bytes) UTF-8, entre comillas simples.

Tenga en cuenta que los caracteres de control (con códigos < 32) no se pueden reasignar con mapscrn porque tienen un significado especial para el controlador.

OPCIONES

-o, --output=ARCHIVO
guardar el mapa antiguo en el ARCHIVO.
-C, --console=DEV
el dispositivo de consola a utilizar.
-v, --verbose
ser más verboso.
-V, --version
mostrar número de versión.
-h, --help
mostrar este mensaje de uso.

ARCHIVOS

/usr/share/kbd/consoletrans
El directorio predeterminado para los mapeos de pantalla.
