NOMBRE

mate-dictionary - Buscar palabras en diccionarios

SINOPSIS

mate-dictionary
mate-dictionary [opciones]

o seleccione Dictionary del submenú Accessories del menú Applications.

DESCRIPCIÓN

MATE Dictionary proporciona definiciones de diccionario de palabras, utilizando una fuente de diccionario.

Para obtener documentación completa, consulte la ayuda en línea de MATE Dictionary.

OPCIONES

--look-up palabra
Busca la palabra especificada utilizando la fuente de diccionario predefinida.
--match palabra
Coincide con una o más palabras utilizando la fuente de diccionario predefinida.
-s fuente o --source fuente
Utiliza la fuente especificada para buscar palabras. Esto no afecta a la configuración global.
-n o --no-window
Usar este modificador con --look-up imprimirá las definiciones encontradas en la consola sin iniciar la GUI.
-D base_de_datos o --database base_de_datos
Utiliza la base de datos especificada para buscar palabras. Esto no afecta a la configuración global.
--help
Muestra información de ayuda.

CONFIGURACIÓN

Toda la configuración se gestiona utilizando GSettings.
