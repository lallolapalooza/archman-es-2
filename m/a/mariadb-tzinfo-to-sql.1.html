MARIADB-TZINFO-TO-SQL(1) Sistema de bases de datos MariaDB MARIADB-TZINFO-TO-SQL(1)

NOMBRE

mariadb-tzinfo-to-sql - cargar las tablas de zona horaria (mariadb-tzinfo-to-sql es ahora un enlace simbólico a mariadb-tzinfo-to-sql)

SINOPSIS

mariadb-tzinfo-to-sql argumentos

DESCRIPCIÓN

El programa mariadb-tzinfo-to-sql carga las tablas de zona horaria en la base de datos mysql. Se utiliza en sistemas que tienen una base de datos zoneinfo (el conjunto de archivos que describen las zonas horarias). Ejemplos de tales sistemas son Linux, FreeBSD, Solaris y Mac OS X. Una ubicación probable para estos archivos es el directorio /usr/share/zoneinfo (/usr/share/lib/zoneinfo en Solaris).

mariadb-tzinfo-to-sql se puede invocar de varias maneras:

shell> mariadb-tzinfo-to-sql tz_dir
shell> mariadb-tzinfo-to-sql tz_file tz_name
shell> mariadb-tzinfo-to-sql --leap tz_file
shell> mariadb-tzinfo-to-sql --skip-write-binlog tz_dir

Para la primera sintaxis de invocación, pase el nombre de la ruta del directorio zoneinfo a mariadb-tzinfo-to-sql y envíe la salida al programa mariadb. Por ejemplo:

shell> mariadb-tzinfo-to-sql /usr/share/zoneinfo | mariadb -u root mysql

mariadb-tzinfo-to-sql lee los archivos de zona horaria de su sistema y genera sentencias SQL a partir de ellos. mariadb procesa esas sentencias para cargar las tablas de zona horaria.

La segunda sintaxis hace que mariadb-tzinfo-to-sql cargue un único archivo de zona horaria tz_file que corresponde a un nombre de zona horaria tz_name:

shell> mariadb-tzinfo-to-sql tz_file tz_name | mariadb -u root mysql

Si su zona horaria necesita tener en cuenta los segundos bisiestos, invoque mariadb-tzinfo-to-sql utilizando la tercera sintaxis, que inicializa la información de segundos bisiestos. tz_file es el nombre de su archivo de zona horaria:

shell> mariadb-tzinfo-to-sql --leap tz_file | mariadb -u root mysql

Usar la opción --skip-write-binlog evita la escritura de cambios en el registro binario o en otros miembros del clúster Galera. Esto se puede usar con cualquier forma de ejecución de mariadb-tzinfo-to-sql.

Después de ejecutar mariadb-tzinfo-to-sql, es mejor reiniciar el servidor para que no continúe utilizando datos de zona horaria almacenados en caché previamente.
