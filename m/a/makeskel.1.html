makeskel(1) Generador de archivos de descripción de unidades FPC makeskel(1)

NOMBRE

makeskel - genera un archivo de descripción para fpdoc.

SINOPSIS

makeskel [--descr=nombrearchivo] [--disable-arguments] [--disable-errors] [--disable-function-results] [--disable-private] [--disable-protected] [--disable-seealso] [--emit-class-separator] [--help] [--lang=idioma] [--output=nombrearchivo] [--update] --package=nombre --input=cmdline

DESCRIPCIÓN

makeskel escanea un archivo fuente de unidad de Free Pascal y genera un archivo de descripción esqueleto para él. Genera nodos para todos los identificadores encontrados en la sección de interfaz de la unidad, aunque este comportamiento puede ajustarse con algunas opciones. También puede actualizar un archivo XML existente y, a continuación, emite solo los nodos para los identificadores para los que aún no existe un nodo.

USO

Puede invocar makeskel con los argumentos requeridos de entrada y paquete. Debe contener al menos el nombre del archivo de unidad para el cual se debe generar la documentación y el nombre del paquete al que pertenece la unidad. La salida de makeskel irá a la salida estándar por defecto.

OPCIONES

makeskel tiene muchas opciones, la mayoría de ellas opcionales, se utilizarán valores por defecto en la mayoría de los casos.

--descr=nombrearchivo
Esta opción debe usarse junto con la opción update. Especifica el nombre de un archivo de descripción nombrearchivo que debe ser actualizado. Tenga en cuenta que el archivo debe contener XML válido, o la actualización fallará. Esta opción se puede especificar más de una vez.
--disable-arguments
Si se especifica esta opción, makeskel no emitirá nodos para los argumentos de funciones y procedimientos. Por defecto, también se emiten nodos de documentación para funciones y procedimientos.
--disable-errors
Por defecto, cada nodo de documentación contendrá también un nodo errors (excepto para identificadores donde esto no tiene uso, como los argumentos de funciones). Si se especifica esta opción, no se generará ningún nodo errors.
--disable-function-results
Por defecto, para las funciones, se generará un nodo result, para describir el resultado de la función. Si se especifica esta opción, no se generará ningún nodo de resultado de función.
--disable-private
Por defecto, también se generan nodos de documentación para campos o métodos privados de una clase. Si se especifica esta opción, se omitirá la generación de nodos para campos o métodos privados.
--disable-protected
Por defecto, también se generan nodos de documentación para campos o métodos protegidos de una clase. Si se especifica esta opción, se omitirá la generación de nodos para campos o métodos protegidos.
--emit-class-separator
Si se especifica esta opción, se inserta un comentario visible con el nombre de la clase para la que seguirán los nodos de documentación, entre los nodos de dos clases, facilitando la navegación.
--help
Emite un texto de ayuda corto y sale.
--input=cmd
El archivo de entrada (fuente) a procesar. Se pueden especificar varios archivos de entrada. El comando puede contener opciones válidas del compilador; actualmente se reconocen las opciones -Fipath (ruta de búsqueda) y -dmacro (definir macro).
--lang=idioma
Establece el idioma para el archivo de salida. Esto principalmente establecerá las cadenas utilizadas para los encabezados en varias partes de los archivos de documentación (por defecto están en inglés). Actualmente, las opciones válidas son:
de
Alemán.
fr
Francés.
nl
Neerlandés.
--output=nombrearchivo
Esta opción indica a makeskel a dónde debe ir la salida. Si esta opción no se especifica, la salida se envía a la salida estándar (la pantalla).
--package=nombrepaquete
Esta opción es obligatoria. Especifica el nombre del paquete. Todos los nodos se generarán dentro de un nodo con el atributo name nombrepaquete.
--update
Activa el modo de actualización. En este modo, la salida es un archivo que contiene solo los nodos faltantes para completar la documentación de los archivos de entrada. Los nodos existentes deben especificarse con el argumento descr. Tenga en cuenta que el archivo de salida no puede ser el mismo que los nodos de entrada (descripción); se debe especificar un archivo separado (o ningún archivo, en cuyo caso la salida va a la salida estándar).
