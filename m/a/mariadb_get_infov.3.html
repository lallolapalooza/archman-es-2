mariadb_get_infov(3) MariaDB Connector/C mariadb_get_infov(3)

Nombre

mariadb_get_infov - recupera información genérica o relacionada con la conexión

Sinopsis

#include <mysql.h>
int mariadb_get_infov(MYSQL * mysql,
                      enum mariadb_value value,
                      void * arg,
                      ...);

Descripción

Recupera información genérica o específica de la conexión. arg (y los argumentos subsiguientes) deben ser un puntero a una variable del tipo apropiado para el argumento value. La siguiente tabla muestra qué tipo de variable usar para cada valor.

Tipos de Valor

Información Genérica

Para estos tipos de información, el parámetro mysql debe establecerse en NULL.

•
MARIADB_CHARSET_NAME

Recupera la información del juego de caracteres para un juego de caracteres por su representación literal.

•
MARIADB_CLIENT_ERRORS

Recupera el array de errores del cliente. Esto se puede usar en plugins para establecer mensajes de error globales (que no son exportados por MariaDB Connector/C).

•
MARIADB_CLIENT_VERSION

La versión del cliente en representación literal.

•
MARIADB_CLIENT_VERSION_ID

La versión del cliente en formato numérico.

•
MARIADB_MAX_ALLOWED_PACKET

Recupera el valor del tamaño máximo de paquete permitido.

•
MARIADB_NET_BUFFER_LENGTH

Recupera la longitud del búfer de red.

Para estos tipos de información, el parámetro mysql debe representar un manejador de conexión válido que fue asignado por mysql_init(3).

mariadb_get_infov(3) — MariaDB Connector/C 3.4

mariadb_get_infov

3 MariaDB C API

Description

This function retrieves information about the connection. The type of information is specified by the option argument.

•
MARIADB_CONNECTION_BUFFER_SIZE

Retrieves the maximum size of the internal buffer used by the connection.

•
MARIADB_CONNECTION_CHARSET_NAME

Retrieves the character set name for the connection.

•
MARIADB_CONNECTION_COMPRESSION_TYPE

Retrieves the compression type used for the connection.

•
MARIADB_CONNECTION_DB_NAME

Retrieves the name of the default database for the connection.

•
MARIADB_CONNECTION_FD

Retrieves the file descriptor for the connection.

•
MARIADB_CONNECTION_HOST_NAME

Retrieves the hostname used for the connection.

•
MARIADB_CONNECTION_LOCAL_ADDRESS

Retrieves the local address used for the connection.

•
MARIADB_CONNECTION_LOCAL_PORT

Retrieves the local port used for the connection.

•
MARIADB_CONNECTION_PORT

Retrieves the port used for the connection.

•
MARIADB_CONNECTION_PROTOCOL_NAME

Retrieves the protocol name used for the connection.

•
MARIADB_CONNECTION_REMOTE_ADDRESS

Retrieves the remote address used for the connection.

•
MARIADB_CONNECTION_REMOTE_PORT

Retrieves the remote port used for the connection.

•
MARIADB_CONNECTION_SERVER_VERSION

Retrieves the server version string.

•
MARIADB_CONNECTION_STATE

Retrieves the state of the connection. The state is represented by a numeric code.

•
MARIADB_CONNECTION_STATUS_STRING

Retrieves the status string of the connection.

•
MARIADB_TLS_CIPHER_NAME Retrieves the name of the cipher used in a TLS connection.
•
MARIADB_TLS_PROTOCOL_VERSION

Retrieves the TLS protocol version used in numeric format.

•
MARIADB_CONNECTION_UNIX_SOCKET

Retrieves the file name of the unix socket

•
MARIADB_CONNECTION_USER

Retrieves connection’s user name.

•
MARIADB_TLS_PEER_CERT_INFO Retrieves peer certificate information for TLS connections. The returned pointer to a MARIADB_X509_INFO structure becomes invalid after the connection has been closed. (Added in version 3.4.0)
•
MARIADB_TLS_VERIFY_STATUS Retrieves the status of a previous peer certificate verification. The status is represented as a combination of TLS verification flags. This option was added in version 3.4.1

Returns

Returns zero on success, non zero if an error occurred (e.g. if an invalid option was specified),

Source file

libmariadb/mariadb_lib.c

History

This function was added in MariaDB Connector/C 3.0,

Examples

/* get server port for current connection */
unsigned int port;
mariadb_get_infov(mysql, MARIADB_CONNECTION_PORT, (void *)&port);

/* get user name for current connection */
const char *user;
mariadb_get_infov(mysql, MARIADB_CONNECTION_USER, (void *)&user);
