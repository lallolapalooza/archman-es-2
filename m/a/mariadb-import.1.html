MARIADB-IMPORT(1) Sistema de Base de Datos MariaDB MARIADB-IMPORT(1)

NOMBRE

mariadb-import - un programa de importación de datos (mariadb-import es ahora un enlace simbólico a mariadb-import)

SINOPSIS

mariadb-import [opciones] nombre_base_datos archivo_texto1 ...

DESCRIPCIÓN

El cliente mariadb-import proporciona una interfaz de línea de comandos para la instrucción SQL LOAD DATA INFILE. La mayoría de las opciones de mariadb-import corresponden directamente a cláusulas de la sintaxis LOAD DATA INFILE.

Ejecuta mariadb-import de esta manera:

shell> mariadb-import [opciones] nombre_base_datos archivo_texto1 [archivo_texto2 ...]

Para cada archivo de texto nombrado en la línea de comandos, mariadb-import elimina cualquier extensión del nombre del archivo y usa el resultado para determinar el nombre de la tabla en la que importar el contenido del archivo. Por ejemplo, los archivos llamados paciente.txt, paciente.text y paciente se importarían todos en una tabla llamada paciente.

mariadb-import admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-import] y [client]. mariadb-import también admite las opciones para procesar archivos de opciones.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--character-sets-dir=ruta

El directorio donde están instalados los conjuntos de caracteres.

•--columns=lista_columnas, -c lista_columnas

Esta opción toma una lista de nombres de columna separados por comas como valor. El orden de los nombres de columna indica cómo hacer coincidir las columnas del archivo de datos con las columnas de la tabla.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos admiten la compresión.

•--debug[=opciones_depuracion], -# [opciones_depuracion]

Escribe un registro de depuración. Una cadena típica de opciones_depuracion es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o'.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-auth=nombre_plugin

Plugin del lado del cliente de autenticación predeterminado a usar.

•--default-character-set=nombre_conjunto_caracteres

Usa nombre_conjunto_caracteres como conjunto de caracteres predeterminado.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos de valores predeterminados globales. Debe proporcionarse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas, anulando los archivos de valores predeterminados globales. Debe proporcionarse como la primera opción.

•--delete, -d

Vacía la tabla antes de importar el archivo de texto.

•--fields-terminated-by=..., --fields-enclosed-by=..., --fields-optionally-enclosed-by=..., --fields-escaped-by=...

Estas opciones tienen el mismo significado que las cláusulas correspondientes para LOAD DATA INFILE.

•--force, -f

Ignora los errores. Por ejemplo, si no existe una tabla para un archivo de texto, continúa procesando cualquier archivo restante. Sin --force, mariadb-import sale si una tabla no existe.

•--host=nombre_host, -h nombre_host

Importa datos al servidor MariaDB en el host dado. El host predeterminado es localhost.

•--ignore, -i

Ver la descripción de la opción --replace.

•--ignore-foreign-keys, -k

Deshabilita las comprobaciones de claves externas mientras se importan los datos.

•--ignore-lines=N

Ignora las primeras N líneas del archivo de datos.

•--innodb-optimize-keys

Crea índices secundarios después de la carga de datos, lo que acelera la carga (solo InnoDB). Predeterminado; usa --skip-innodb-optimize-keys para deshabilitar.

•--lines-terminated-by=...

Esta opción tiene el mismo significado que la cláusula correspondiente para LOAD DATA INFILE. Por ejemplo, para importar archivos de Windows que tienen líneas terminadas con pares de retorno de carro/salto de línea, usa --lines-terminated-by="\r\n". (Es posible que tengas que duplicar las barras invertidas, dependiendo de las convenciones de escape de tu intérprete de comandos).

•--local, -L

Lee archivos de entrada localmente desde el host cliente.

•--lock-tables, -l

Bloquea todas las tablas para escritura antes de procesar cualquier archivo de texto. Esto asegura que todas las tablas estén sincronizadas en el servidor.

•--low-priority

Usa LOW_PRIORITY al cargar la tabla. Esto solo afecta a los motores de almacenamiento que usan solo bloqueos a nivel de tabla (como MyISAM, MEMORY y MERGE).

•--no-defaults

No lee opciones predeterminadas de ningún archivo de opciones. Debe proporcionarse como el primer argumento.

•--parallel=N, -j N

Número de trabajos de LOAD DATA ejecutados en paralelo. --use-threads es un sinónimo.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usa la forma corta de la opción (-p), no puede haber un espacio entre la opción y la contraseña. Si omite el valor de contraseña después de la opción --password o -p en la línea de comandos, mariadb-import solicitará una.

Se debe considerar inseguro especificar una contraseña en la línea de comandos. Puedes usar un archivo de opciones para evitar dar la contraseña en la línea de comandos.

•--pipe, -W

En Windows, conéctate al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor admite conexiones de tubería con nombre.

•--plugin-dir=nombre


Directorio para plugins del lado del cliente.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar para la conexión. Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión causarían normalmente el uso de un protocolo diferente al deseado.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Debe proporcionarse como el primer argumento.

•--replace, -r

Las opciones --replace y --ignore controlan el manejo de filas de entrada que duplican filas existentes en valores de clave únicos. Si especifica --replace, las filas nuevas reemplazan las filas existentes que tienen el mismo valor de clave único. Si especifica --ignore, las filas de entrada que duplican una fila existente en un valor de clave único se omiten. Si no especifica ninguna de las opciones, ocurre un error cuando se encuentra un valor de clave duplicado, y el resto del archivo de texto se ignora.

•--silent, -s

Modo silencioso. Produce salida solo cuando ocurren errores.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (automáticamente

mariadb-import(1) — MariaDB 11.8

NAME

mariadb-import

a database import utility

SYNOPSIS

mariadb-import [options] [--fields-xxx] [--lines-xxx] [db_name] [filename...]

DESCRIPTION

mariadb-import is a client utility for importing data into MariaDB tables. It acts as a frontend for the LOAD DATA INFILE SQL statement.

The utility supports importing multiple files into different tables at once. If the tables do not exist, they will be created automatically based on the filenames and the file contents.

Filenames generally should be in the format table_name.extension. The extension is used to determine the file format. Currently, only .txt is supported for text files. You can use --fields-terminated-by=... and other options to control how the data is parsed.

All options can be specified on the command line or in an option file.

The following options are available:

•--abort-on-error

Abort if an error occurs.

•--columns=col_name,...

List of columns to import data into. If not specified, all columns in the file are imported.

•--compress, -C

Use compression on the connection.

•--database=db_name, -D db_name

The database to use.

•--debug[=name], -# [name]

Output debugging information.

•--default-auth=method

Use the specified default authentication plugin.

•--defaults-file=name

Use only the given default file.

•--fields-binary=N

Field N is binary.

•--fields-enclosed-by=N

Fields are enclosed by N.

•--fields-optionally-enclosed-by=N

Fields are optionally enclosed by N.

•--fields-separated-by=N

Fields are separated by N.

•--fields-terminated-by=N

Fields are terminated by N.

•--fields-trailing-term

Fields have a trailing terminator.

•--fields-missing-ok

Allow missing fields.

•--force, -f

Continue even if sql_mode is not empty.

•--help, -?

Display this help and exit.

•--ignore-lines=N

Number of lines to ignore at the beginning of the file.

•--local, -L

Read files locally and send them to the server. Implies --use-ssl if SSL is enabled with other flags.

•--lines-terminated-by=N

Lines are terminated by N.

•--lines-starting-with=N

Lines starting with N.

•--password[=password], -p[password]

The password to use when connecting to the server. If password is not given, it is prompted.

•--pipe, -P

Use a pipe to communicate with the server.

•--port=N, -P N

The TCP/IP port number to use for the connection.

•--protocol=name

The protocol to use for the connection (ie, TCP, SOCKET, PIPE, MEMORY).

•--quiet, -q

Suppress output, except for errors.

•--replace

Replace existing rows that have the same primary key.

•--rows-with-signficant-fields=N

Number of fields that are considered significant for each row.

•--safe-updates, -safe-updates

Enable safe updates mode.

•--socket=name, -S name

The Unix socket file to use for the connection.

•--skip-ssl

Do not use SSL for the connection (default).

•--ssl

Enable SSL for the connection. This is the default when other SSL options are used.

•--ssl-ca=name

CA file in PEM format (check OpenSSL docs, implies --ssl).

•--ssl-capath=name

CA directory (check OpenSSL docs, implies --ssl).

•--ssl-cert=name

X509 cert in PEM format (check OpenSSL docs, implies --ssl).

•--ssl-cipher=name

SSL cipher to use (check OpenSSL docs, implies --ssl).

•--ssl-key=name

X509 key in PEM format (check OpenSSL docs, implies --ssl).

•--ssl-crl=name

Certificate revocation list (check OpenSSL docs, implies --ssl).

•--ssl-crlpath=name

Certificate revocation list path (check OpenSSL docs, implies --ssl).

•--ssl-verify-server-cert

Verify server's "Common Name" in its cert against hostname used when connecting. This option is disabled by default.

•--user=user_name, -u user_name

The MariaDB user name to use when connecting to the server.

•--use-threads=N

Load files in parallel using N threads. Synonym for -j, --parallel=num

•--verbose, -v

Verbose mode. Print more information about what the program does.

•--version, -V

Display version information and exit.

Here is a sample session that demonstrates use of mariadb-import:

shell> mariadb -e 'CREATE TABLE imptest(id INT, n VARCHAR(30))' test
shell> ed
a
100     Max Sydow
101     Count Dracula
.
w imptest.txt
32
q
shell> od -c imptest.txt
0000000   1   0   0  \t   M   a   x       S   y   d   o   w  \n   1   0
0000020   1  \t   C   o   u   n   t       D   r   a   c   u   l   a  \n
0000040
shell> mariadb-import --local test imptest.txt
test.imptest: Records: 2  Deleted: 0  Skipped: 0  Warnings: 0
shell> mariadb -e 'SELECT * FROM imptest' test
+------+---------------+
| id   | n             |
+------+---------------+
|  100 | Max Sydow     |
|  101 | Count Dracula |
+------+-+
