MARIADB-CONVERT-TABLE-FORMAT(1) Sistema de Bases de Datos MariaDB MARIADB-CONVERT-TABLE-FORMAT(1)

NOMBRE

mariadb-convert-table-format - convierte tablas para usar un motor de almacenamiento dado (mariadb-convert-table-format es ahora un enlace simbólico a mariadb-convert-table-format)

SINOPSIS

mariadb-convert-table-format [opciones] nombre_db

DESCRIPCIÓN

mariadb_convert_table_format convierte las tablas de una base de datos para usar un motor de almacenamiento particular (MyISAM por defecto). mariadb-convert-table-format está escrito en Perl y requiere que los módulos Perl DBI y DBD::MariaDB estén instalados (ver Sección 2.15, “Notas de Instalación de Perl”).

Invoque mariadb-convert-table-format de esta manera:

shell> mariadb-convert-table-format [opciones]nombre_db

El argumento nombre_db indica la base de datos que contiene las tablas a convertir.

mariadb-convert-table-format soporta las opciones descritas en la siguiente lista.

•--help

Muestra un mensaje de ayuda y sale.

•--force

Continúa incluso si ocurren errores.

•--host=nombre_host

Conecta al servidor MariaDB en el host dado.

•--password=contraseña

La contraseña a usar al conectar al servidor. Tenga en cuenta que el valor de la contraseña no es opcional para esta opción, a diferencia de otros programas de MariaDB.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puede usar un archivo de opciones para evitar dar la contraseña en la línea de comandos.

•--port=num_puerto

El número de puerto TCP/IP a usar para la conexión.

•--socket=ruta

Para conexiones a localhost, el archivo de socket Unix a usar.

•--type=nombre_motor

Especifica el motor de almacenamiento que deben usar las tablas convertidas. El valor predeterminado es MyISAM si no se proporciona esta opción.

•--user=nombre_usuario

El nombre de usuario de MariaDB a usar al conectar al servidor.

•--verbose

Modo detallado. Imprime más información sobre lo que hace el programa.

•--version

Muestra información de la versión y sale.
