NOMBRE

macpack - Empaquetador de Macintosh OS X para ensamblados gestionados con interfaz gráfica

SINOPSIS

macpack [opciones] ensamblado

DESCRIPCIÓN

macpack es una herramienta utilizada para empaquetar ensamblados gestionados (como System.Windows.Forms o Cocoa#) que requieren disponibilidad de interfaz gráfica para su despliegue en Mac OS X.

macpack preparará un paquete compatible con OS X a partir del ensamblado y los recursos proporcionados. El paquete incluirá el ensamblado especificado, así como cualquier recurso proporcionado (especificado con el interruptor -resource:).

Los desarrolladores pueden especificar el tipo de aplicación a producir utilizando el argumento -mode:. Esto controla cómo se configura el entorno en las bibliotecas de clases de Mono.

OPCIONES

-a ensamblado

Esta opción le indica a macpack dónde se encuentra el ensamblado gestionado que desea empaquetar. Esta opción también se utiliza para apuntar al script de shell a lanzar en el caso de una aplicación X11/Gtk#.

Es lo mismo que pasar simplemente el ensamblado como argumento.

-m [winforms,x11,console,cocoa] o -mode:[winforms,x11,console,cocoa]

Un valor que indica el tipo de aplicación: Winforms es una aplicación Winforms que se ejecuta en Quartz; X11 es una aplicación que requiere que el servidor X11 se ejecute; console es una aplicación no gráfica; cocoa es una aplicación basada en Cocoa#

-n NOMBRE o -appname:NOMBRE

Esta opción especifica el nombre de la aplicación del paquete emitido. Esto es lo que verá en Finder.

-o DIRECTORIO o -output:DIRECTORIO

Esta opción especifica la ruta para generar el paquete de la aplicación.

-r RECURSO o -resource:RECURSO

Esta opción se puede especificar varias veces. Colocará una copia de cada recurso en el directorio de recursos del paquete. Alternativamente, puede utilizar una lista de recursos separada por comas.
