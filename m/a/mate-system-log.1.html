NOMBRE

mate-system-log - el Visor de Registros del Sistema MATE

SINOPSIS

mate-system-log

o seleccione Registro del Sistema en el submenú Herramientas del Sistema del menú Aplicaciones.

DESCRIPCIÓN

Visor de Registros del Sistema MATE es una utilidad simple para mostrar los archivos de registro del sistema.

AUTOR

El Visor de Registros del Sistema MATE fue escrito por Cesar Miquel <miquel@df.uba.ar>.

Esta página del manual fue escrita por Jochen Voss <voss@mathematik.uni-kl.de>.

ARCHIVOS

/var/log/messages
El archivo de registro principal del sistema.
/etc/syslog.conf
Archivo de configuración para syslogd. Consulte syslog.conf(5) para obtener información exacta.

VER TAMBIÉN

syslogd(8), sysklogd(8), syslog.conf(5), syslogd-listfiles(8)
