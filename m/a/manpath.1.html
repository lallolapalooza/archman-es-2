MANPATH(1) utilidades de paginación manual MANPATH(1)

NOMBRE

manpath - determinar la ruta de búsqueda de las páginas del manual

SINOPSIS

manpath [-qgdc?V] [-m sistema[,...]] [-C archivo]

DESCRIPCIÓN

Si $MANPATH está configurado, manpath simplemente mostrará su contenido y emitirá una advertencia. Si no, manpath determinará una ruta de búsqueda de jerarquía de páginas del manual adecuada y mostrará los resultados.

La ruta delimitada por dos puntos se determina utilizando la información obtenida del archivo de configuración de man-db – (/etc/man_db.conf) y el entorno del usuario.

OPCIONES

-q, --quiet
No emitir advertencias.
-d, --debug
Imprimir información de depuración.
-c, --catpath
Producir una ruta de cat (`catpath`) en lugar de una ruta de manual (`manpath`). Una vez determinada la ruta de manual, cada elemento de la ruta se convierte a su ruta de cat relativa.
-g, --global
Producir una ruta de manual que consiste en todas las rutas nombradas como "global" dentro del archivo de configuración de man-db.
-m sistema[,...], --systems=sistema[,...]
Si este sistema tiene acceso a las jerarquías de manuales de otros sistemas operativos, esta opción se puede usar para incluirlas en la salida de manpath. Para incluir las jerarquías de páginas del manual de NewOS, use la opción -m NewOS.

El sistema especificado puede ser una combinación de nombres de sistemas operativos delimitados por comas. Para incluir las jerarquías de páginas del manual del sistema operativo nativo, el nombre del sistema man debe incluirse en la cadena de argumentos. Esta opción anulará la variable de entorno $SYSTEM.

-C archivo, --config-file=archivo
Usar este archivo de configuración de usuario en lugar del predeterminado ~/.manpath.
-?, --help
Imprimir un mensaje de ayuda y salir.
--usage
Imprimir un breve mensaje de uso y salir.
-V, --version
Mostrar información de la versión.

AMBIENTE

MANPATH
Si $MANPATH está configurado, manpath mostrará su valor en lugar de determinarlo sobre la marcha.

Consulte la sección RUTA DE BÚSQUEDA de manpath(5) para el comportamiento predeterminado y los detalles sobre cómo se maneja esta variable de entorno.

SYSTEM
Si $SYSTEM está configurado, tendrá el mismo efecto que si se hubiera especificado como argumento de la opción -m.

ARCHIVOS

/etc/man_db.conf
Archivo de configuración de man-db.

VER TAMBIÉN

apropos(1), man(1), whatis(1)
