MANADV(7) Manual de Verbos Directos de MANA MANADV(7)

NOMBRE

manadv - Verbos directos para dispositivos mana

Esto proporciona acceso de bajo nivel a dispositivos mana para realizar operaciones directas, sin la ramificación general realizada por libibverbs.

DESCRIPCIÓN

La API de libibverbs es abstracta. Es agnóstica a cualquier implementación específica del proveedor subyacente. Si bien esta abstracción tiene la ventaja de la portabilidad de las aplicaciones de usuario, tiene una penalización de rendimiento. Para algunas aplicaciones, optimizar el rendimiento es más importante que la portabilidad.

La API de verbos directos de mana está destinada a tales aplicaciones. Expone operaciones de bajo nivel específicas de mana, lo que permite a la aplicación omitir la API de libibverbs.

Esta versión del controlador admite un tipo de QP: IBV_QPT_RAW_PACKET. Para usar este tipo de QP, la aplicación debe usar manadv_set_context_attr() para establecer asignadores de memoria externos para asignar colas, y usar manadv_init_obj() para obtener toda la información de la cola. La aplicación implementa sus propias operaciones de cola, omitiendo la API de libibverbs para enviar/recibir tráfico a través de las colas. En la capa de hardware, el QP IBV_QPT_RAW_PACKET comparte el mismo recurso de hardware que el puerto Ethernet utilizado en el kernel. El software verifica el uso exclusivo del puerto Ethernet de hardware y fallará la creación del QP si el puerto ya está en uso. Para crear un IBV_QPT_RAW_PACKET en un puerto especificado, el usuario necesita configurar el sistema de tal manera que este puerto no sea utilizado por ningún otro software (incluido el Kernel). Si el puerto está en uso, ibv_create_qp() fallará con errno establecido en EBUSY.

La inclusión directa de manadv.h junto con el enlace a la biblioteca mana permitirá el uso de esta nueva interfaz.
