malloc_info(3) Manual de Funciones de Biblioteca malloc_info(3)

NOMBRE

malloc_info - exportar estado de malloc a un stream

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <malloc.h>
int malloc_info(int options, FILE *stream);

DESCRIPCIÓN

La función malloc_info() exporta una cadena XML que describe el estado actual de la implementación de asignación de memoria del llamador. La cadena se imprime en el stream de archivo stream. La cadena exportada incluye información sobre todas las arenas (ver malloc(3)).

Tal como está implementado actualmente, options debe ser cero.

VALOR DE RETORNO

En caso de éxito, malloc_info() devuelve 0. En caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
options no era cero.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
malloc_info () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

HISTORIA

glibc 2.10.

NOTAS

La información de asignación de memoria se proporciona como una cadena XML (en lugar de una estructura C) porque la información puede cambiar con el tiempo (según los cambios en la implementación subyacente). La cadena XML de salida incluye un campo de versión.

La función open_memstream(3) puede usarse para enviar la salida de malloc_info() directamente a un buffer en memoria, en lugar de a un archivo.

La función malloc_info() está diseñada para abordar las deficiencias de malloc_stats(3) y mallinfo(3).

EJEMPLOS

El programa a continuación toma hasta cuatro argumentos de línea de comandos, de los cuales los tres primeros son obligatorios. El primer argumento especifica el número de hilos que el programa debe crear. Todos los hilos, incluido el hilo principal, asignan el número de bloques de memoria especificado por el segundo argumento. El tercer argumento controla el tamaño de los bloques a asignar. El hilo principal crea bloques de este tamaño, el segundo hilo creado por el programa asigna bloques del doble de este tamaño, el tercer hilo asigna bloques de tres veces este tamaño, y así sucesivamente.

El programa llama a malloc_info() dos veces para mostrar el estado de la asignación de memoria. La primera llamada se realiza antes de que se creen hilos o se asigne memoria. La segunda llamada se realiza después de que todos los hilos hayan asignado memoria.

En el siguiente ejemplo, los argumentos de línea de comandos especifican la creación de un hilo adicional, y tanto el hilo principal como el hilo adicional asignan 10000 bloques de memoria. Después de que se han asignado los bloques de memoria, malloc_info() muestra el estado de dos arenas de asignación.

Código fuente del programa

#include <err.h>
#include <errno.h>
#include <malloc.h>
#include <pthread.h>
#include <stdlib.h>
#include <unistd.h>
static size_t        blockSize;
static size_t        numThreads;
static unsigned int  numBlocks;
static void *
thread_func(void *arg)
{
    int tn = (int) arg;
    /* El multiplicador '(2 + tn)' asegura que cada hilo (incluido
       el hilo principal) asigne una cantidad diferente de memoria.  */
    for (unsigned int j = 0; j < numBlocks; j++)
        if (malloc(blockSize * (2 + tn)) == NULL)
            err(EXIT_FAILURE, "malloc-thread");
    sleep(100);         /* Dormir hasta que el hilo principal termine.  */
    return NULL;
}
int
main(int argc, char *argv[])
{
    int        sleepTime;
    pthread_t  *thr;
    if (argc < 4) {
        fprintf(stderr,
                "%s num-hilos num-bloques tamaño-bloque [tiempo-dormir]\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    numThreads = atoi(argv[1]);
    numBlocks = atoi(argv[2]);
    blockSize = atoi(argv[3]);
    sleepTime = (argc > 4) ? atoi(argv[4]) : 0;
    thr = calloc(numThreads, sizeof(*thr));
    if (thr == NULL)
        err(EXIT_FAILURE, "calloc");
    printf("============ Antes de asignar bloques ============\n");
    malloc_info(0, stdout);
    /* Crear hilos que asignan diferentes cantidades de memoria.  */
    for (size_t tn = 0; tn < numThreads; tn++) {
        errno = pthread_create(&thr[tn], NULL, thread_func,
                               (void *) tn);
        if (errno != 0)
            err(EXIT_FAILURE, "pthread_create");
        /* Si agregamos un intervalo de suspensión después del inicio de cada
           hilo, es probable que los hilos no compitan por los mutex de malloc,
           y por lo tanto, no se asignarán arenas adicionales (ver malloc(3)).  */
        if (sleepTime > 0)
            sleep(sleepTime);
    }
    /* El hilo principal también asigna algo de memoria.  */
    for (unsigned int j = 0; j < numBlocks; j++)
        if (malloc(blockSize) == NULL)
            err(EXIT_FAILURE, "malloc");
    sleep(2);           /* Dar tiempo a todos los hilos para
                           completar las asignaciones.  */
    printf("\n============ Después de asignar bloques ============\n");
    malloc_info(0, stdout);
    exit(EXIT_SUCCESS);
}
