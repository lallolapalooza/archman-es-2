mallinfo(3) Manual de Funciones de Biblioteca mallinfo(3)

NOMBRE

mallinfo, mallinfo2 - obtener información de asignación de memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <malloc.h>
struct mallinfo mallinfo(void);
struct mallinfo2 mallinfo2(void);

DESCRIPCIÓN

Estas funciones devuelven una copia de una estructura que contiene información sobre las asignaciones de memoria realizadas por malloc(3) y funciones relacionadas. La estructura devuelta por cada función contiene los mismos campos. Sin embargo, la función más antigua, mallinfo(), está obsoleta ya que el tipo utilizado para los campos es demasiado pequeño (ver BUGS).

Tenga en cuenta que no todas las asignaciones son visibles para estas funciones; consulte BUGS y considere usar malloc_info(3) en su lugar.

La estructura mallinfo2 devuelta por mallinfo2() se define de la siguiente manera:


struct mallinfo2 {
    size_t arena;     /* Espacio sin mmap asignado (bytes) */
    size_t ordblks;   /* Número de fragmentos libres */
    size_t smblks;    /* Número de bloques fastbin libres */
    size_t hblks;     /* Número de regiones mmap */
    size_t hblkhd;    /* Espacio asignado en regiones mmap
                         (bytes) */
    size_t usmblks;   /* Ver abajo */
    size_t fsmblks;   /* Espacio en bloques fastbin liberados (bytes) */
    size_t uordblks;  /* Espacio total asignado (bytes) */
    size_t fordblks;  /* Espacio libre total (bytes) */
    size_t keepcost;  /* Espacio superior, liberable (bytes) */
};

La estructura mallinfo devuelta por la función obsoleta mallinfo() es exactamente la misma, excepto que los campos son de tipo int.

Los campos de la estructura contienen la siguiente información:

arena
La cantidad total de memoria asignada por medios distintos de mmap(2) (es decir, memoria asignada en el heap). Esta cifra incluye tanto los bloques en uso como los bloques en la lista de libres.
ordblks
El número de bloques libres ordinarios (es decir, no fastbin).
smblks
El número de bloques libres fastbin (ver mallopt(3)).
hblks
El número de bloques actualmente asignados usando mmap(2). (Ver la discusión de M_MMAP_THRESHOLD en mallopt(3).)
hblkhd
El número de bytes en bloques actualmente asignados usando mmap(2).
usmblks
Este campo no se utiliza y es siempre 0. Históricamente, era la "marca de agua alta" del espacio asignado — es decir, la cantidad máxima de espacio que se había asignado alguna vez (en bytes); este campo se mantenía solo en entornos no multihilo.
fsmblks
El número total de bytes en bloques libres fastbin.
uordblks
El número total de bytes utilizados por asignaciones en uso.
fordblks
El número total de bytes en bloques libres.
keepcost
La cantidad total de espacio libre liberable en la parte superior del heap. Este es el número máximo de bytes que idealmente (es decir, ignorando las restricciones de alineación de página, etc.) podrían ser liberados por malloc_trim(3).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
mallinfo (), mallinfo2 () Seguridad de hilos MT-Unsafe init const:mallopt

mallinfo()/ mallinfo2() accederían a algunos objetos internos globales. Si se modifican de forma no atómica, pueden producirse resultados inconsistentes. El identificador mallopt en const:mallopt significa que mallopt() modificaría los objetos internos globales de forma atómica, lo que garantiza que mallinfo()/ mallinfo2() sea lo suficientemente seguro, mientras que otras modificaciones no atómicas podrían no serlo.

ESTANDARES

Ninguno.

HISTORIA

BUGS

La información se devuelve solo para el área de asignación de memoria principal. Las asignaciones en otras áreas están excluidas. Vea malloc_stats(3) y malloc_info(3) para alternativas que incluyen información sobre otras áreas.

Los campos de la estructura mallinfo devuelta por la función más antigua mallinfo() son de tipo int. Sin embargo, dado que algunos valores de contabilidad interna pueden ser de tipo long, los valores informados pueden desbordarse a cero y, por lo tanto, ser inexactos.

EJEMPLOS

El siguiente programa utiliza mallinfo2() para recuperar estadísticas de asignación de memoria antes y después de asignar y liberar algunos bloques de memoria. Las estadísticas se muestran en la salida estándar.

Los dos primeros argumentos de línea de comandos especifican el número y el tamaño de los bloques que se asignarán con malloc(3).

Los tres argumentos restantes especifican cuáles de los bloques asignados deben liberarse con free(3). Estos tres argumentos son opcionales y especifican (en orden): el tamaño del paso a utilizar en el bucle que libera bloques (el valor predeterminado es 1, lo que significa liberar todos los bloques en el rango); la posición ordinal del primer bloque a liberar (predeterminado 0, lo que significa el primer bloque asignado); y un número mayor que la posición ordinal del último bloque a liberar (el valor predeterminado es uno mayor que el número máximo de bloques). Si se omiten estos tres argumentos, los valores predeterminados provocan que todos los bloques asignados se liberen.

EJEMPLOS

El siguiente programa demuestra el uso de mallinfo2. Asigna un número de bloques de memoria y luego libera algunos de ellos para mostrar cómo cambia la información del montón:

// Este programa es un fragmento de código C.
// Para ejecutarlo, guárdelo en un archivo (por ejemplo, mallinfo2_example.c)
// y compílelo con un compilador de C (como GCC):
//
// gcc mallinfo2_example.c -o mallinfo2_example
//
// Luego ejecútelo con argumentos. Por ejemplo:
//
// ./mallinfo2_example 10000 128 1000 5000
//
// Argumentos:
// num-blocks: Número total de bloques a asignar (ej. 10000)
// block-size: Tamaño de cada bloque en bytes (ej. 128)
// free-step: El paso para liberar bloques (ej. 1000)
// start-free: Índice del primer bloque a liberar (ej. 5000)
// end-free: Índice donde terminar de liberar bloques (ej. 10000)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <malloc.h> // Para mallinfo2

// Función para mostrar la información del montón usando mallinfo2
void
display_mallinfo2(void)
{
    struct mallinfo2 mi;

    mi = mallinfo2();
    printf("Total de bytes no mapeados (arena):       %zu\n", mi.arena);
    printf("# de bloques libres (ordblks):            %zu\n", mi.ordblks);
    printf("# de bloques fastbin libres (smblks):     %zu\n", mi.smblks);
    printf("# de regiones mapeadas (hblks):           %zu\n", mi.hblks);
    printf("Bytes en regiones mapeadas (hblkhd):      %zu\n", mi.hblkhd);
    printf("Máx. espacio total asignado (usmblks):  %zu\n", mi.usmblks);
    printf("Bytes libres en fastbins (fsmblks): %zu\n", mi.fsmblks);
    printf("Espacio total asignado (uordblks):      %zu\n", mi.uordblks);
    printf("Espacio total libre (fordblks):           %zu\n", mi.fordblks);
    printf("Bloque liberable más alto (keepcost):   %zu\n", mi.keepcost);
}

int
main(int argc, char *argv[])
{
#define MAX_ALLOCS 500000 // Límite máximo de asignaciones
    char *alloc[MAX_ALLOCS]; // Array para almacenar punteros a las asignaciones
    size_t blockSize, numBlocks, freeBegin, freeEnd, freeStep;

    // Verificar los argumentos de la línea de comandos
    if (argc < 3 || strcmp(argv[1], "--help") == 0) {
        fprintf(stderr, "%s num-blocks block-size [free-step "
                "[start-free [end-free]]]\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    // Parsear los argumentos
    numBlocks = atoi(argv[1]);
    blockSize = atoi(argv[2]);
    freeStep = (argc > 3) ? atoi(argv[3]) : 1; // Paso para liberar, por defecto 1
    freeBegin = (argc > 4) ? atoi(argv[4]) : 0; // Inicio del rango a liberar, por defecto 0
    freeEnd = (argc > 5) ? atoi(argv[5]) : numBlocks; // Fin del rango a liberar, por defecto numBlocks

    printf("============== Antes de asignar bloques ==============\n");
    display_mallinfo2(); // Mostrar información del montón antes de cualquier asignación

    // Asignar bloques de memoria
    for (size_t j = 0; j < numBlocks; j++) {
        // Verificar si el número de bloques excede el límite
        if (numBlocks >= MAX_ALLOCS) {
            fprintf(stderr, "Demasiadas asignaciones\n");
            exit(EXIT_FAILURE);
        }
        alloc[j] = malloc(blockSize); // Asignar memoria
        if (alloc[j] == NULL) {
            perror("malloc"); // Manejar error de asignación
            exit(EXIT_FAILURE);
        }
    }

    printf("\n============== Después de asignar bloques ==============\n");
    display_mallinfo2(); // Mostrar información del montón después de las asignaciones

    // Liberar bloques de memoria según los parámetros proporcionados
    for (size_t j = freeBegin; j < freeEnd; j += freeStep)
        free(alloc[j]); // Liberar memoria

    printf("\n============== Después de liberar bloques ==============\n");
    display_mallinfo2(); // Mostrar información del montón después de liberar bloques

    exit(EXIT_SUCCESS); // Salir exitosamente
}
