MARKDOWN(1) Manual de comandos generales MARKDOWN(1)

NOMBRE

markdown — herramienta de conversión de texto a html

SINOPSIS

markdown [-d] [-T] [-V] [-b base-url] [-C prefijo] [-F mapa-de-bits] [-f flags] [-n] [-o archivo] [-S] [-s texto] [-t texto] [-toc] [archivo-texto]

DESCRIPCIÓN

La utilidad markdown lee el archivo de texto con formato markdown(7) (o stdin si no se especifica), lo compila y escribe la salida html a stdout.

Las opciones son las siguientes:

-b base-url
Los enlaces en el origen que comiencen con / se antepondrán con base-url en la salida.
-C
Al procesar notas al pie de página estilo markdown extra, use el prefijo dado en lugar del predeterminado de fn.
-d
En lugar de escribir el archivo html, vuelque un árbol de análisis a stdout.
-f flags
Establece o borra varias banderas de traducción. Las banderas están en una lista separada por comas, con un prefijo opcional de + (habilitar), - (deshabilitar) o no (deshabilitar) en cada bandera.
links
Permitir enlaces.
image
Permitir imágenes.
smarty
Habilitar smartypants.
pants
Habilitar smartypants.
html
Permitir html sin formato.
strict
Deshabilitar superíndices, tachado y énfasis relajado.
ext
Habilitar pseudo-protocolos.
cdata
Generar código para xml ![CDATA[...]].
superscript
Habilitar procesamiento de superíndices.
emphasis
El énfasis ocurre en todas partes.
tables
No procesar tablas PHP Markdown Extra.
del
Habilitar ~~tachado~~.
strikethrough
Habilitar ~~tachado~~.
toc
Habilitar procesamiento de tabla de contenidos.
1.0
Compatibilidad con MarkdownTest_1.0
autolink
Convertir http://foo.com en un enlace incluso sin <>.
safelink
Comprobación paranoica del protocolo del enlace.
header
Procesar bloques de encabezado estilo pandoc.
tabstop
Expandir tabulaciones a 4 espacios.
divquote
Permitir bloques de >%clase%.
alphalist
Permitir listas alfabéticas.
definitionlist
Permitir listas de definición en general (predeterminado). Usar dldiscount y dlextra para controlar qué sintaxis se respeta.
dldiscount
Habilitar listas de definición estilo discount (predeterminado).
dlextra
Habilitar listas de definición estilo extra (no predeterminado). Ambos estilos pueden habilitarse simultáneamente.
footnote
Permitir notas al pie de página estilo markdown extra.
style
Extraer bloques <style> de la salida.
fencedcode
Permitir bloques de código cercados (no predeterminado).
idanchor
Usar id= anclas para enlaces de tabla de contenidos en lugar de <a name=/> (no predeterminado).
githubtags
Permitir guiones bajos y guiones en nombres de elementos pasados (no predeterminado).
urlencodedanchor
Usar caracteres codificados en URL para caracteres multibyte y no alfanuméricos en lugar de puntos en los enlaces de la tabla de contenidos.

Como ejemplo, la opción -f nolinks,smarty indica a markdown que no permita etiquetas <a y que realice el procesamiento de smarty pants.

-F mapa-de-bits
Establece banderas de traducción. Mapa-de-bits es un mapa de bits de varias opciones de configuración descritas en markdown(3) (los valores de las banderas se definen en mkdio.h)
-n
No escribir el html generado.
-o archivo
Escribe el html generado en archivo.
-S
Salida de bloques <style>.
-V
Mostrar el número de versión y los datos de configuración en tiempo de compilación.

Si la versión incluye la cadena DEBUG, markdown se configuró con depuración de asignación de memoria.

Si la versión incluye la cadena TAB, markdown se configuró para usar el punto de tabulación especificado.

-VV
Mostrar el número de versión, la configuración en tiempo de compilación y la configuración en tiempo de ejecución.
-t texto
Usar mkd_text(3) para formatear texto en lugar de procesar stdin con la función markdown(3).
-T
Si se ejecuta con la bandera de tabla de contenidos activada, volcar la tabla de contenidos antes del texto formateado.
-s texto
Usar la función markdown(3) para formatear texto.
-toc
Establecer la bandera de tabla de contenidos y luego volcar la tabla de contenidos antes del texto formateado (un atajo para --T --toc).

VALORES DE RETORNO

La utilidad markdown sale con 0 en caso de éxito y >0 si ocurre un error.

VER TAMBIÉN

markdown(3), markdown(7), mkd-extensions(7).

markdown(3)

NAME

markdown - Convierte un documento markdown en HTML.

SYNOPSIS

#include <markdown.h>

char *markdown(const char *text, size_t size, markdown_options flags);

DESCRIPTION

La función markdown convierte el texto en formato markdown dado en text, de longitud size, en su representación HTML equivalente. El argumento flags es una máscara de bits de opciones para controlar el comportamiento de la conversión. Las opciones disponibles se definen en la cabecera markdown.h y se describen en detalle en la página del manual de markdown_options.

La función devuelve un puntero a una cadena de caracteres que contiene el HTML generado. El llamante es responsable de liberar esta memoria utilizando free() cuando ya no sea necesaria.

Si ocurre un error durante la conversión, por ejemplo, debido a una asignación de memoria fallida, markdown devuelve NULL.

RETURN VALUES

Devuelve un puntero a la cadena de caracteres HTML generada, o NULL si ocurre un error. El llamante es responsable de liberar la memoria devuelta.

markdown_options(3)
