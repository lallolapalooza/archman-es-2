maze(6) Manual de XScreenSaver maze(6)

NOMBRE

maze - una demo automatizada de X11 que crea y resuelve repetidamente un laberinto aleatorio.

SINOPSIS

maze [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--install] [--visual visual] [--grid-size píxeles] [--live-color color] [--dead-color color] [--solve-delay usecs] [--pre-delay usecs] [--post-delay usecs] [--generator entero] [--max-length entero] [--fps]

DESCRIPCIÓN

El programa maze crea un laberinto "aleatorio" y luego lo resuelve con retroalimentación gráfica.

OPCIONES

maze acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--grid-size píxeles
El tamaño de cada bloque del laberinto, en píxeles; el valor predeterminado es 0, lo que significa que se elegirá un tamaño de cuadrícula aleatorio. El valor mínimo significativo es 2.
--live-color color
El color del camino.
--dead-color color
El color del camino fallido (también se marca con un patrón del 50%).
--skip-color color
El solucionador de laberintos elegirá no seguir un camino si puede "ver" (en línea recta) que es un callejón sin salida. Este es el color a usar para los caminos que se saltan por esta razón.
--surround-color color
Si el solucionador de laberintos alguna vez encierra completamente un área dentro del laberinto, entonces sabe que la salida no está allí (y de hecho, el interior de esa área podría no ser accesible). Marcará esas celdas usando este color.
--solve-delay entero
Retraso (en microsegundos) entre cada paso del camino de solución. Predeterminado 5000, o aproximadamente 1/200 de segundo.
--pre-delay entero
Retraso (en microsegundos) entre la generación de un laberinto y el inicio de su resolución. Predeterminado 2000000 (2 segundos).
--post-delay entero
Retraso (en microsegundos) después de resolver un laberinto y antes de generar uno nuevo. Predeterminado 4000000 (4 segundos).
--generator num
Establece el algoritmo que se utilizará para generar los laberintos. El valor predeterminado es -1, que selecciona aleatoriamente un algoritmo para cada laberinto que se genera. El generador 0 es el original y funciona caminando aleatoriamente hasta que golpeamos un lugar que hemos visitado antes, luego retrocedemos y probamos una nueva dirección en algún lugar. El generador 1 elige un punto aleatorio en el laberinto, luego dibuja una pared recta desde ese punto en una dirección aleatoria hasta que golpea otra pared (y continúa hasta que el laberinto está completo). El generador 2 se basa en conjuntos. Inicialmente, todas las celdas están en conjuntos diferentes. Luego se eligen dos celdas vecinas y si están en conjuntos diferentes, se unen sus conjuntos. Si estuvieran en el mismo conjunto, se construiría una pared entre ellas. Esto continúa hasta que el laberinto esté completo.

Todos los generadores generan laberintos con una cierta 'característica'. ¡Mira si puedes descubrirlas!

Los tres algoritmos son esencialmente Kruskal, Prim y un backtracker recursivo de profundidad.

--max-length num
Controla la longitud máxima de las paredes dibujadas de una vez por el generador 1.

Hacer clic con el ratón en la ventana del laberinto lo controla.

BotónIzquierdo
Borra la ventana y reinicia el laberinto.
BotónMedio
Pausa o reanuda el programa.
BotónDerecho
Salir.
--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

ERRORES

Los eventos Expose fuerzan un reinicio de maze.

Las acciones del ratón se basan en valores "crudos" (Button1, Button2 y Button3) en lugar de usar el mapa de puntero.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
