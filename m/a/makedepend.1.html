MAKEDEPEND(1) Manual de Comandos Generales MAKEDEPEND(1)

NOMBRE

makedepend - crear dependencias en makefiles

SINOPSIS

makedepend [ -Dnombre=definición ] [ -Dnombre ] [ -Idirectorio_inclusion ] [ -Ydirectorio_inclusion ]
[ -a ] [ -fmakefile ] [ -include archivo ] [ -osufijo_objeto ]
[ -pprefijo_objeto ] [ -scadena ] [ -wancho ] [ -v ] [ -m ]
[ -- otrasopciones -- ] archivo_fuente ...

DESCRIPCIÓN

El programa makedepend lee cada archivo_fuente en secuencia y lo analiza como un preprocesador C, procesando todas las directivas #include, #define, #undef, #ifdef, #ifndef, #endif, #if, #elif y #else para poder determinar correctamente qué directivas #include se usarían en una compilación. Cualquier directiva #include puede referenciar archivos que contengan otras directivas #include, y el análisis ocurrirá también en estos archivos.

Cada archivo que un archivo_fuente incluye, directa o indirectamente, es lo que makedepend llama una dependencia. Estas dependencias se escriben luego en un makefile de tal manera que make(1) sabrá qué archivos objeto deben ser recompilados cuando una dependencia ha cambiado.

Por defecto, makedepend coloca su salida en el archivo llamado makefile si existe, de lo contrario Makefile. Se puede especificar un makefile alternativo con la opción -f. Primero busca en el makefile la línea

# DO NOT DELETE THIS LINE -- make depend depends on it.

o una proporcionada con la opción -s, como delimitador para la salida de dependencias. Si la encuentra, eliminará todo lo que siga a esta línea hasta el final del makefile y colocará la salida después de ella. Si no la encuentra, el programa añadirá la cadena al final del makefile y colocará la salida después de eso. Por cada archivo_fuente que aparezca en la línea de comandos, makedepend insertará líneas en el makefile de la forma


archivo_fuente.o: archivo_dependencia ...

Donde archivo_fuente.o es el nombre del archivo de la línea de comandos con su sufijo reemplazado por ``.o'', y archivo_dependencia es una dependencia descubierta en una directiva #include al analizar archivo_fuente o uno de los archivos que incluye.

EJEMPLO

Normalmente, makedepend se utilizará en un objetivo de makefile para que al escribir ``make depend'' las dependencias se actualicen en el makefile. Por ejemplo,

    FUENTES= archivo1.c archivo2.c ...
    CFLAGS= -O -DHACK -I../foobar -xyz
    depend:
            makedepend -- $(CFLAGS) -- $(FUENTES)

OPCIONES

El programa ignorará cualquier opción que no entienda para que pueda utilizar los mismos argumentos que usaría para cc(1).

-Dnombre=definición o -Dnombre
Definir. Esto coloca una definición para nombre en la tabla de símbolos de makedepend. Sin =definición el símbolo se define como ``1''.
-Idirectorio_inclusion
Directorio de inclusión. Esta opción le indica a makedepend que añada directorio_inclusion al principio de su lista de directorios a buscar cuando se encuentra con una directiva #include. Por defecto, makedepend solo busca en los directorios de inclusión estándar (generalmente /usr/include y posiblemente un directorio dependiente del compilador).
-Ydirectorio_inclusion
Reemplaza todos los directorios de inclusión estándar con el único directorio de inclusión especificado; puede omitir directorio_inclusion para simplemente evitar buscar en los directorios de inclusión estándar.
-a
Añade las dependencias al final del archivo en lugar de reemplazarlas.
-fmakefile
Nombre de archivo. Esto le permite especificar un makefile alternativo en el cual makedepend puede colocar su salida. Especificar ``-'' como el nombre del archivo (es decir, -f-) envía la salida a la salida estándar en lugar de modificar un archivo existente.
-include archivo
Procesa el archivo como entrada, e incluye toda la salida resultante antes de procesar el archivo de entrada regular. Esto tiene el mismo efecto que si el archivo especificado fuera una declaración de inclusión que aparece antes de la primera línea del archivo de entrada regular.
-osufijo_objeto
Sufijo del archivo objeto. Algunos sistemas pueden tener archivos objeto cuyo sufijo es algo diferente de ``.o''. Esta opción le permite especificar otro sufijo, como ``.b'' con -o.b o ``:obj'' con -o:obj y así sucesivamente.
-pprefijo_objeto
Prefijo del archivo objeto. El prefijo se antepone al nombre del archivo objeto. Esto se usa generalmente para designar un directorio diferente para el archivo objeto. El valor predeterminado es la cadena vacía.
-scadena
Cadena de inicio delimitadora. Esta opción permite especificar una cadena diferente que makedepend buscará en el makefile.
-wancho
Ancho de línea. Normalmente, makedepend se asegurará de que cada línea de salida que escriba no tenga más de 78 caracteres de ancho por razones de legibilidad. Esta opción le permite cambiar este ancho.
-v
Operación detallada. Esta opción hace que makedepend emita la lista de archivos incluidos por cada archivo de entrada.
-m
Advertir sobre inclusión múltiple. Esta opción hace que makedepend produzca una advertencia si algún archivo de entrada incluye otro archivo más de una vez. En versiones anteriores de makedepend este era el comportamiento predeterminado; el valor predeterminado se ha cambiado para que coincida mejor con el comportamiento del compilador C, que no considera la inclusión múltiple como un error. Esta opción se proporciona por compatibilidad hacia atrás y para ayudar a depurar problemas relacionados con la inclusión múltiple.
-- opciones --
Si makedepend encuentra un doble guion (--) en la lista de argumentos, entonces cualquier argumento no reconocido que le siga será ignorado silenciosamente; un segundo doble guion termina este tratamiento especial. De esta manera, makedepend puede ser configurado para ignorar de forma segura argumentos esotéricos del compilador que normalmente se encontrarían en una macro make CFLAGS (ver la sección de EJEMPLO arriba). Todas las opciones que makedepend reconoce y que aparecen entre el par de dobles guiones se procesan normalmente.

ALGORITMO

El enfoque utilizado en este programa le permite ejecutarse una orden de magnitud más rápido que cualquier otro ``generador de dependencias'' que haya visto. Central para este rendimiento son dos suposiciones: que todos los archivos compilados por un solo makefile se compilarán con opciones -I y -D aproximadamente iguales; y que la mayoría de los archivos en un solo directorio incluirán en gran medida los mismos archivos.

Dados estos supuestos, makedepend espera ser llamado una vez por cada makefile, con todos los archivos fuente que son mantenidos por el makefile apareciendo en la línea de comandos. Analiza cada archivo fuente y de inclusión exactamente una vez, manteniendo una tabla de símbolos interna para cada uno. Por lo tanto, el primer archivo en la línea de comandos tomará una cantidad de tiempo proporcional a la cantidad de tiempo que toma un preprocesador C normal. Pero en archivos subsiguientes, si encuentra un archivo de inclusión que ya ha analizado, no lo analiza de nuevo.

Por ejemplo, imagine que está compilando dos archivos, archivo1.c y archivo2.c, cada uno incluye el archivo de cabecera cabecera.h, y el archivo cabecera.h a su vez incluye los archivos def1.h y def2.h. Al ejecutar el comando


makedepend archivo1.c archivo2.c

makedepend analizará archivo1.c y en consecuencia, cabecera.h y luego def1.h y def2.h. Luego decidirá que las dependencias para este archivo son


archivo1.o: header.h def1.h def2.h

Pero cuando el programa analiza file2.c y descubre que también incluye header.h, no analiza el archivo, sino que simplemente agrega header.h, def1.h y def2.h a la lista de dependencias para file2.o.

VER TAMBIÉN

cc(1), make(1)

ERRORES

makedepend analiza, pero actualmente no evalúa, la expresión del preprocesador SVR4 #predicate(token-list); tales expresiones se asumen simplemente como verdaderas. Esto puede causar que se evalúen directivas #include incorrectas.

Imagínese que está analizando dos archivos, digamos file1.c y file2.c, cada uno incluye el archivo def.h. La lista de archivos que incluye def.h podría ser realmente diferente cuando def.h es incluido por file1.c que cuando es incluido por file2.c. Pero una vez que makedepend llega a una lista de dependencias para un archivo, esta se fija permanentemente.
