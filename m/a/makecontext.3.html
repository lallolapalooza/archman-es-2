makecontext(3) Manual de Funciones de Librería makecontext(3)

NOMBRE

makecontext, swapcontext - manipular el contexto del usuario

BIBLIOTECA

Librería C estándar (libc, -lc)

SINOPSIS

#include <ucontext.h>
void makecontext(ucontext_t *ucp, typeof(void (int arg0, ...)) *func,
                 int argc, ...);
int swapcontext(ucontext_t *restrict oucp,
                 const ucontext_t *restrict ucp);

DESCRIPCIÓN

En un entorno tipo System V, se dispone del tipo ucontext_t (definido en <ucontext.h> y descrito en getcontext(3)) y las cuatro funciones getcontext(3), setcontext(3), makecontext() y swapcontext() que permiten la conmutación de contexto a nivel de usuario entre múltiples hilos de control dentro de un proceso.

La función makecontext() modifica el contexto apuntado por ucp (que se obtuvo de una llamada a getcontext(3)). Antes de invocar makecontext(), el llamador debe asignar una nueva pila para este contexto y asignar su dirección a ucp->uc_stack, y definir un contexto sucesor y asignar su dirección a ucp->uc_link.

Cuando este contexto se active posteriormente (usando setcontext(3) o swapcontext()), se llamará a la función func, y se le pasarán la serie de argumentos enteros (int) que siguen a argc; el llamador debe especificar el número de estos argumentos en argc. Cuando esta función retorne, se activará el contexto sucesor. Si el puntero del contexto sucesor es NULL, el hilo termina.

La función swapcontext() guarda el contexto actual en la estructura apuntada por oucp, y luego activa el contexto apuntado por ucp.

VALOR DE RETORNO

Cuando tiene éxito, swapcontext() no retorna. (Pero podemos retornar más tarde, en caso de que oucp sea activado, en cuyo caso parece que swapcontext() retorna 0.) En caso de error, swapcontext() retorna -1 y establece errno para indicar el error.

ERRORES

ENOMEM
Espacio de pila insuficiente.

ATRIBUTOS

ESTANDARES

Ninguno.

HISTORIA

glibc 2.1. SUSv2, POSIX.1-2001. Eliminado en POSIX.1-2008, citando problemas de portabilidad, y recomendando que las aplicaciones se reescriban para usar hilos POSIX en su lugar.

NOTAS

La interpretación de ucp->uc_stack es igual que en sigaltstack(2), es decir, esta estructura contiene el inicio y la longitud de un área de memoria para ser utilizada como pila, independientemente de la dirección de crecimiento de la pila. Por lo tanto, no es necesario que el programa del usuario se preocupe por esta dirección.

En arquitecturas donde los tipos int y puntero tienen el mismo tamaño (por ejemplo, x86-32, donde ambos tipos son de 32 bits), es posible que puedas salirte con la tuya pasando punteros como argumentos a makecontext() después de argc. Sin embargo, hacer esto no garantiza la portabilidad, no está definido según los estándares y no funcionará en arquitecturas donde los punteros son más grandes que los int. No obstante, a partir de glibc 2.8, glibc realiza algunos cambios en makecontext() para permitir esto en algunas arquitecturas de 64 bits (por ejemplo, x86-64).

EJEMPLOS

El siguiente programa de ejemplo demuestra el uso de getcontext(3), makecontext() y swapcontext(). Al ejecutar el programa se produce la siguiente salida:


$ ./a.out
main: swapcontext(&uctx_main, &uctx_func2)
func2: started
func2: swapcontext(&uctx_func2, &uctx_func1)
func1: started
func1: swapcontext(&uctx_func1, &uctx_func2)
func2: returning
func1: returning
main: exiting

Fuente del programa

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <ucontext.h>
static ucontext_t uctx_main, uctx_func1, uctx_func2;
static void
func1(void)
{
    printf("%s: started\n", __func__);
    printf("%s: swapcontext(&uctx_func1, &uctx_func2)\n", __func__);
    if (swapcontext(&uctx_func1, &uctx_func2) == -1)
        err(EXIT_FAILURE, "swapcontext");
    printf("%s: returning\n", __func__);
}
static void
func2(void)
{
    printf("%s: started\n", __func__);
    printf("%s: swapcontext(&uctx_func2, &uctx_func1)\n", __func__);
    if (swapcontext(&uctx_func2, &uctx_func1) == -1)
        err(EXIT_FAILURE, "swapcontext");
    printf("%s: returning\n", __func__);
}
int
main(int argc, char *argv[])
{
    char func1_stack[16384];
    char func2_stack[16384];
    if (getcontext(&uctx_func1) == -1)
        err(EXIT_FAILURE, "getcontext");
    uctx_func1.uc_stack.ss_sp = func1_stack;
    uctx_func1.uc_stack.ss_size = sizeof(func1_stack);
    uctx_func1.uc_link = &uctx_main;
    makecontext(&uctx_func1, func1, 0);
    if (getcontext(&uctx_func2) == -1)
        err(EXIT_FAILURE, "getcontext");
    uctx_func2.uc_stack.ss_sp = func2_stack;
    uctx_func2.uc_stack.ss_size = sizeof(func2_stack);
    /* Contexto sucesor es f1(), a menos que argc > 1 */
    uctx_func2.uc_link = (argc > 1) ? NULL : &uctx_func1;
    makecontext(&uctx_func2, func2, 0);
    printf("%s: swapcontext(&uctx_main, &uctx_func2)\n", __func__);
    if (swapcontext(&uctx_main, &uctx_func2) == -1)
        err(EXIT_FAILURE, "swapcontext");
    printf("%s: exiting\n", __func__);
    exit(EXIT_SUCCESS);
}
