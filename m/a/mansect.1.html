mansect(1) Manual de Comandos Generales mansect(1)

NOMBRE

mansect - imprime el código fuente de secciones de las páginas del manual

SINOPSIS

mansect sección [archivo ...]

DESCRIPCIÓN

El comando mansect imprime el código fuente de la sección de los archivos de página del manual especificados. Si no se especifican archivos, se utiliza la entrada estándar.

sección es una expresión regular PCRE2.

La línea TH se imprime incondicionalmente.

La salida de este programa es adecuada para ser enviada a la tubería de groff(1).

EJEMPLOS

$ man -w strtol strtoul | xargs mansect 'NAME|SEE ALSO';
.lf 1 /usr/local/man/man3/strtol.3
.TH strtol 3 2024-07-23 "Linux man-pages 6.9.1"
.SH NAME
strtol, strtoll, strtoq - convertir una cadena a un entero largo
.SH SEE ALSO
.BR atof (3),
.BR atoi (3),
.BR atol (3),
.BR strtod (3),
.BR strtoimax (3),
.BR strtoul (3)
.lf 1 /usr/local/man/man3/strtoul.3
.TH strtoul 3 2024-07-23 "Linux man-pages 6.9.1"
.SH NAME
strtoul, strtoull, strtouq - convertir una cadena a un entero largo sin signo
.SH SEE ALSO
.BR a64l (3),
.BR atof (3),
.BR atoi (3),
.BR atol (3),
.BR strtod (3),
.BR strtol (3),
.BR strtoumax (3)
