NOMBRE

mate-display-properties-install-systemwide - personalizar el comportamiento de la pantalla de MATE

SINOPSIS

mate-display-properties-install-systemwide <ARCHIVO_ORIGEN> <NOMBRE_DESTINO>

DESCRIPCIÓN

Este ejecutable es parte del paquete 'mate-control-center': El Centro de Control de MATE.

Esta herramienta de línea de comandos instala un perfil RANDR para configuraciones multimonitor en una ubicación del sistema. El perfil resultante será utilizado cuando el plugin RANDR se ejecute en mate-settings-daemon.

<ARCHIVO_ORIGEN>
una ruta completa, típicamente /home/usuario/.config/monitors.xml
<NOMBRE_DESTINO>
nombre relativo para el archivo instalado. Esto se colocará en el directorio del sistema para configuraciones RANDR, por lo que el resultado será típicamente /etc/mate-settings-daemon/xrandr/NOMBRE_DESTINO
