DESCRIPCIÓN

Los comandos del namespace ::tcl::mathop implementan el mismo conjunto de operaciones que soporta el comando expr. Todos son exportados del namespace, pero no se importan en ningún otro namespace por defecto. Tenga en cuenta que renombrar, reimplementar o eliminar cualquiera de los comandos en el namespace no altera la forma en que se comporta el comando expr, ni tampoco define nuevos comandos en el namespace ::tcl::mathop.

Los siguientes comandos de operador son compatibles:

~	!	+	-	*
/	%	**	&	|
^	>>	<<	==	eq
!=	ne	<	<=	>
>=	in	ni

OPERADORES MATEMÁTICOS

Los comportamientos de los comandos de operadores matemáticos son los siguientes:

! booleano
Devuelve la negación booleana de booleano, donde booleano puede ser cualquier valor numérico o cualquier otra forma de valor booleano (es decir, devuelve verdad si el argumento es falsedad o cero, y falsedad si el argumento es verdad o distinto de cero).
+ ?número ...?
Devuelve la suma de un número arbitrario de argumentos. Cada argumento número puede ser cualquier valor numérico. Si no se proporcionan argumentos, el resultado será cero (la identidad de la suma).
- número ?número ...?
Si solo se proporciona un argumento número, devuelve la negación de ese valor numérico. De lo contrario, devuelve el número que resulta cuando todos los valores numéricos subsiguientes se restan del primero. Todos los argumentos número deben ser valores numéricos. Se debe proporcionar al menos un argumento.
* ?número ...?
Devuelve el producto de un número arbitrario de argumentos. Cada número puede ser cualquier valor numérico. Si no se proporcionan argumentos, el resultado será uno (la identidad multiplicativa).
/ número ?número ...?
Si solo se proporciona un argumento número, devuelve el recíproco de ese valor numérico (es decir, el valor obtenido al dividir 1.0 por ese valor). De lo contrario, devuelve el número que resulta cuando el primer argumento numérico se divide por todos los argumentos numéricos subsiguientes. Todos los argumentos número deben ser valores numéricos. Se debe proporcionar al menos un argumento.

Tenga en cuenta que cuando los valores iniciales en la lista de argumentos son enteros, se utilizará la división entera para esos pasos iniciales (es decir, los resultados intermedios serán como si se aplicaran las funciones floor e int a ellos, en ese orden). Si todos los valores en la operación son enteros, el resultado será un entero.

% número número
Devuelve el módulo integral (es decir, el resto) del primer argumento con respecto al segundo. Cada número debe tener un valor integral. Además, el signo del resultado será el mismo que el signo del segundo número, que no debe ser cero.

Tenga en cuenta que Tcl define esta operación exactamente incluso para números negativos, de modo que el siguiente comando devuelve un valor verdadero (omitiendo el namespace para mayor claridad):

== [* [/ x y] y] [- x [% x y]]
** ?número ...?
Devuelve el resultado de elevar cada valor a la potencia del resultado de operar recursivamente con el resultado de procesar los siguientes argumentos, de modo que “** 2 3 4” es lo mismo que “** 2 [** 3 4]”. Cada número puede ser cualquier valor numérico, aunque el segundo número no debe ser fraccionario si el primero es negativo. El valor de exponente máximo que Tcl puede manejar si el primer número es un entero > 1 es 268435455. Si no se proporcionan argumentos, el resultado será uno, y si solo se proporciona un argumento, el resultado será ese argumento. El resultado tendrá un valor integral solo cuando todos los argumentos sean valores integrales.

OPERADORES DE COMPARACIÓN

Los comportamientos de los comandos de operadores de comparación (la mayoría de los cuales operan preferentemente sobre argumentos numéricos) son los siguientes:

== ?arg ...?
Devuelve si cada argumento es igual a los argumentos de cada lado en el sentido del operador == de expr (es decir, comparación numérica si es posible, comparación de cadenas exacta en caso contrario). Si se dan menos de dos argumentos, esta operación siempre devuelve un valor verdadero.
eq ?arg ...?
Devuelve si cada argumento es igual a los argumentos de cada lado usando comparación de cadenas exacta. Si se dan menos de dos argumentos, esta operación siempre devuelve un valor verdadero.
!= arg arg
Devuelve si los dos argumentos no son iguales entre sí, en el sentido del operador != de expr (es decir, comparación numérica si es posible, comparación de cadenas exacta en caso contrario).
ne arg arg
Devuelve si los dos argumentos no son iguales entre sí usando comparación de cadenas exacta.
< ?arg ...?
Devuelve si los argumentos arbitrarios están ordenados, y cada argumento después del primero debe ser estrictamente mayor que el anterior. Las comparaciones se realizan preferentemente sobre los valores numéricos, y de lo contrario se realizan utilizando la comparación de cadenas UNICODE. Si hay menos de dos argumentos, esta operación siempre devuelve un valor verdadero. Cuando los argumentos son numéricos pero deben compararse como cadenas, se debe usar el comando string compare en su lugar.
<= ?arg ...?
Devuelve si los argumentos arbitrarios están ordenados, y cada argumento después del primero debe ser igual o mayor que el anterior. Las comparaciones se realizan preferentemente sobre los valores numéricos, y de lo contrario se realizan utilizando la comparación de cadenas UNICODE. Si hay menos de dos argumentos, esta operación siempre devuelve un valor verdadero. Cuando los argumentos son numéricos pero deben compararse como cadenas, se debe usar el comando string compare en su lugar.
> ?arg ...?
Devuelve si los argumentos arbitrarios están ordenados, y cada argumento después del primero debe ser estrictamente menor que el anterior. Las comparaciones se realizan preferentemente sobre los valores numéricos, y de lo contrario se realizan utilizando la comparación de cadenas UNICODE. Si hay menos de dos argumentos, esta operación siempre devuelve un valor verdadero. Cuando los argumentos son numéricos pero deben compararse como cadenas, se debe usar el comando string compare en su lugar.
>= ?arg ...?
Devuelve si los argumentos arbitrarios están ordenados, y cada argumento después del primero debe ser igual o menor que el anterior. Las comparaciones se realizan preferentemente sobre los valores numéricos, y de lo contrario se realizan utilizando.
in arg lista
Devuelve si el primer argumento se encuentra en la lista de argumentos. Si se dan menos de dos argumentos, o si el primer argumento es una cadena vacía, entonces el valor de retorno es falso. El primer argumento es comparado con cada uno de los elementos de la lista utilizando la comparación de cadenas exacta.
ni arg lista
Devuelve si el primer argumento no se encuentra en la lista de argumentos. Si se dan menos de dos argumentos, o si el primer argumento es una cadena vacía, entonces el valor de retorno es verdadero. El primer argumento es comparado con cada uno de los elementos de la lista utilizando la comparación de cadenas exacta.
& ?número ...?
Devuelve el resultado de la operación AND a nivel de bits de los argumentos numéricos proporcionados. Si no se proporcionan argumentos, el resultado será -1 (el valor máximo de un entero con signo de 32 bits). Si se proporciona un argumento, se devuelve ese argumento.
| ?número ...?
Devuelve el resultado de la operación OR a nivel de bits de los argumentos numéricos proporcionados. Si no se proporcionan argumentos, el resultado será 0 (la identidad de la operación OR).
^ ?número ...?
Devuelve el resultado de la operación XOR a nivel de bits de los argumentos numéricos proporcionados. Si no se proporcionan argumentos, el resultado será 0.
<< número número
Devuelve el valor del primer argumento desplazado a la izquierda en el número de bits especificado por el segundo argumento. El segundo argumento debe ser un entero no negativo. Si el primer argumento no es un entero, se comportará como si fuera un entero.
>> número número
Devuelve el valor del primer argumento desplazado a la derecha en el número de bits especificado por el segundo argumento. El segundo argumento debe ser un entero no negativo. Si el primer argumento es un entero positivo o cero, se realizará un desplazamiento aritmético (conservando el bit de signo). Si el primer argumento es negativo, se realizará un desplazamiento lógico (rellenando con ceros). Si el primer argumento no es un entero, se comportará como si fuera un entero.

OPERADORES BIT A BIT

Los comportamientos de los comandos de operadores bit a bit (todos los cuales operan solo en argumentos enteros) son los siguientes:

~ número
Devuelve la negación bit a bit de número. Número puede ser un entero de cualquier tamaño. Tenga en cuenta que el resultado de esta operación siempre tendrá el signo opuesto al número de entrada.
& ?número ...?
Devuelve el AND bit a bit de cada uno de los argumentos, que pueden ser arbitrariamente muchos. Cada número debe tener un valor entero. Si no se proporcionan argumentos, el resultado será menos uno.
| ?número ...?
Devuelve el OR bit a bit de cada uno de los argumentos, que pueden ser arbitrariamente muchos. Cada número debe tener un valor entero. Si no se proporcionan argumentos, el resultado será cero.
^ ?número ...?
Devuelve el XOR bit a bit de cada uno de los argumentos, que pueden ser arbitrariamente muchos. Cada número debe tener un valor entero. Si no se proporcionan argumentos, el resultado será cero.
<< número número
Devuelve el resultado de desplazar bit a bit el primer argumento hacia la izquierda por el número de bits especificado en el segundo argumento. Cada número debe tener un valor entero.
>> número número
Devuelve el resultado de desplazar bit a bit el primer argumento hacia la derecha por el número de bits especificado en el segundo argumento. Cada número debe tener un valor entero.

OPERADORES DE LISTA

Los comportamientos de los comandos de operadores orientados a listas son los siguientes:

in arg lista
Devuelve si el valor arg está presente en la lista (según comparación exacta de cadenas de los elementos).
ni arg lista
Devuelve si el valor arg no está presente en la lista (según comparación exacta de cadenas de los elementos).

EJEMPLOS

La forma más sencilla de usar los operadores a menudo es usando namespace path para hacer disponibles los comandos. Esto tiene la ventaja de no afectar el conjunto de comandos definidos por el espacio de nombres actual.

namespace path {::tcl::mathop ::tcl::mathfunc}
# Calcular la suma de algunos números
set sum [+ 1 2 3]
# Calcular el promedio de una lista
set list {1 2 3 4 5 6}
set mean [/ [+ {*}$list] [double [llength $list]]]
# Probar la pertenencia a una lista
set gotIt [in 3 $list]
# Probar si un valor está dentro de un rango definido
set inRange [<= 1 $x 5]
# Probar si una lista está ordenada
set sorted [<= {*}$list]
