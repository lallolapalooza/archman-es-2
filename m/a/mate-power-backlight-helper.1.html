NOMBRE

mate-power-backlight-helper - aplicación auxiliar para el control de retroiluminación de la gestión de energía de MATE

SINOPSIS

mate-power-backlight-helper [ --help ] [ --set-brightness ] [ --get-brightness ] [ --get-max-brightness ]

DESCRIPCIÓN

mate-power-backlight-helper es una utilidad auxiliar para controlar la retroiluminación de las pantallas TFT a través del demonio del espacio de usuario de gestión de energía de MATE.

mate-power-backlight-helper requiere ser ejecutado con privilegios de root.

OPCIONES

--help
Muestra un resumen de las opciones.
--set-brightness NIVEL_DE_BRILLO
Establece el brillo dado.
--get-brightness
Obtiene el brillo actual.
--get-max-brightness
Obtiene el número de niveles de brillo admitidos.
