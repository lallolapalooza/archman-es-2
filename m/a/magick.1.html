magick(1) Manual de Comandos Generales magick(1)

NOMBRE

magick - convierte entre formatos de imagen, así como redimensiona una imagen, desenfoca, recorta, elimina motas, aplica tramado, dibuja sobre ella, la voltea, la une, la remuestrea y mucho más.

SINOPSIS

magick [opciones-de-entrada] archivo-de-entrada [opciones-de-salida] archivo-de-salida

DESCRIPCIÓN GENERAL

El programa magick es un miembro del conjunto de herramientas ImageMagick(1). Úsalo para convertir entre formatos de imagen, así como redimensionar una imagen, desenfocar, recortar, eliminar motas, aplicar tramado, dibujar sobre ella, voltearla, unirla, remuestrearla y mucho más.

Para más información sobre el comando magick, abre en tu navegador el archivo file:///usr/share/doc/ImageMagick-7/www/magick.html o https://imagemagick.org/script/magick.php.

magick(1) - Arch manual pages

NAME

magick - command-line interface to the ImageMagick image processing library

SYNOPSIS

magick [input-option ...] input-file ... [output-option ...] output-file

magick input-file ... operation ... output-file

magick -version

magick -help

OVERVIEW

The magick program is a command-line interface to the ImageMagick image processing library. It provides an interface to ImageMagick's powerful image processing capabilities, allowing users to manipulate images from the command line.

DESCRIPTION

The magick program can be used to convert, compose, or modify bitmap images. It can read, process, and write images in a variety of image formats. You can use magick to create composite images, reduce image file size, and convert between image formats. ImageMagick supports a vast number of file formats. Use the -list format option to see them all.

The general syntax for the magick command is:

magick [input-option ...] input-file ... [output-option ...] output-file
This syntax is used for simple image conversions and modifications. The input-options affect how the input images are read, and the output-options affect how the output image is written. There can be multiple input and output files.
magick input-file ... operation ... output-file
This syntax is used for more complex image processing tasks that involve multiple operations. The operations are applied in the order they appear on the command line.

Use any setting or operator as an output-option. Only a limited number of setting are input-option. They include: -antialias, -caption, -density, -define, -encoding, -font, -pointsize, -size, and -texture as well as any of the miscellaneous options.

By default, the image format of `file' is determined by its magic number. To specify a particular image format, precede the filename with an image format name and a colon (i.e. ps:image) or specify the image type as the filename suffix (i.e. image.ps). Specify 'file' as '-' for standard input or output.
