NOMBRE

mangohud - habilita MangoHud en cualquier aplicación

SINOPSIS

mangohud [--dlsym] COMANDO

DESCRIPCIÓN

MangoHud es una superposición Vulkan/OpenGL para monitorear FPS, temperaturas, carga de CPU/GPU y más.

USO

MangoHud se puede habilitar para aplicaciones Vulkan estableciendo MANGOHUD=1 como variable de entorno.
Para cargar MangoHud para cualquier aplicación, incluidas las aplicaciones OpenGL, se puede usar el ejecutable mangohud. Pre-carga una biblioteca a través de ld en la aplicación.
Nota: algunas aplicaciones OpenGL también pueden necesitar hooking de dlsym. Esto se puede hacer pasando la opción --dlsym o estableciendo MANGOHUD_DLSYM=1 como variable de entorno.

CONFIGURACIÓN

MangoHud viene con un archivo de configuración que se puede usar para establecer opciones de configuración globalmente o por aplicación. Las prioridades de los diferentes archivos de configuración son:

/ruta/a/la/aplicación/MangoHud.conf
$XDG_CONFIG_HOME/MangoHud/{nombre_aplicacion}.conf
$XDG_CONFIG_HOME/MangoHud/MangoHud.conf

Un archivo de configuración de ejemplo se encuentra en /usr/share/doc/mangohud/MangoHud.conf, que contiene todas las opciones disponibles.

Una ubicación de archivo de configuración personalizada también se puede especificar con la variable de entorno MANGOHUD_CONFIGFILE.
Las opciones de configuración también se pueden establecer con la variable de entorno MANGOHUD_CONFIG. Esto tiene prioridad sobre cualquier archivo de configuración.

EJEMPLOS

OpenGL: mangohud glxgears
Vulkan: MANGOHUD=1 vkcube
Steam: establezca su opción de lanzamiento a mangohud %command%
Lutris: agregue mangohud a la configuración de prefijo de comando
OpenGL con dlsym: mangohud --dlsym glxgears
Opciones de configuración personalizadas: MANGOHUD_CONFIG="gpu_stats=0,font_size=12" mangohud glxgears

ACERCA DE

El desarrollo de MangoHud tiene lugar en https://github.com/flightlessmango/MangoHud.
Las pruebas comparativas creadas con MangoHud se pueden cargar en https://flightlessmango.com.
