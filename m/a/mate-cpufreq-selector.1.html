MATE-CPUFREQ-SELECTOR(1) Manual de Comandos Generales MATE-CPUFREQ-SELECTOR(1)

NOMBRE

mate-cpufreq-selector - Una herramienta genérica de línea de comandos para cambiar la frecuencia de la CPU.

SINOPSIS

mate-cpufreq-selector [OPCIONES]

DESCRIPCIÓN

Esta herramienta forma parte del Applet Monitor de Escalado de Frecuencia de CPU para el Panel MATE. Puede ser llamada desde la línea de comandos cuando está instalada. mate-cpufreq-selector se utiliza para ajustar la configuración de frecuencia de la CPU si el sistema soporta el escalado.

Esta página del manual documenta brevemente el comando mate-cpufreq-selector.

OPCIONES

-c NÚMERO, --cpu=NÚMERO
Especifica el Número de CPU para ajustar la configuración. Si no se especifica ninguna CPU, se asume la CPU0.
-g GOBERNADOR, --governor=GOBERNADOR
Especifica un Gobernador de CPU válido para usar. (ej. conservative, ondemand, performance, powersave)
-f FREQ, --frequency=FREQ
Especifica una Frecuencia de CPU para establecer en KHz.
-?, -h, --help
Imprime las opciones estándar de la línea de comandos.

EJEMPLOS

mate-cpufreq-selector --cpu=1 -g powersave

Establece el Gobernador de escalado "Powersave" en la CPU1

mate-cpufreq-selector -f 1200000

Establece la Frecuencia máxima de CPU en 1200000KHz (1.2GHz) en la CPU0
