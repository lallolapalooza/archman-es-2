DESCRIPCIÓN

mathsPIC es un programa filtro de Perl para PiCTeX. mathsPIC tiene su propia capacidad de macros y bibliotecas de macros, y permite el uso de comandos de mathsPIC, PiCTeX, TeX y LaTeX. Una característica significativa de mathsPIC es que permite el acceso a la línea de comandos, y por lo tanto permite al usuario extender los comandos de mathsPIC llamando a Perl y otros programas escritos para realizar acciones de dibujo específicas. Consulte el manual del paquete para obtener detalles completos y ejemplos. La última versión se puede descargar de

CTAN: tex-archive/graphics/pictex/mathspic/perl

Los comandos que se pueden usar en el archivo de script de mathsPIC se dividen en cuatro grupos principales: (a) comandos de macro de mathsPIC (prefijados con %def), (b) comandos regulares de mathsPIC (no tienen una barra invertida), (c) comandos regulares de PiCTeX (todos tienen una barra invertida), y (d) comandos regulares de TeX y LaTeX (todos tienen una barra invertida).

Las siguientes funciones matemáticas se pueden utilizar (tenga en cuenta que las fracciones decimales con un valor absoluto menor que 1 deben tener un cero inicial). Tenga en cuenta también que todas las funciones trigonométricas requieren su argumento en radianes.

Trigonométricas: sin(), cos(), tan(), asin(), acos(), atan()

Resto: rem(); ej. var r=12 rem(5)

Entero: int(); ej. var r= int(3.87) --> 3

Signo (devuelve -1, 0, +1): sgn(); ej. var s=sgn(-3.27) --> -1

Raíz cuadrada: sqrt(); ej. var s = sqrt(14)

Exponenciación: **; ej. var j = r**2

Constante Pi (3.14159...): _Pi_ y _pi_

Constante e (2.71828...): _E_ y _e_

Grosor de línea: _linethickness_; ej. var t = _linethickness_

USO EN LÍNEA DE COMANDOS

perl mathspic.pl [-b] [-c] [-h] [-o <archivo_salida>] <archivo_entrada>

-b activa el pitido si mathsPIC detecta un error

-c deshabilita la escritura de comentarios en el archivo de salida

-h muestra el archivo de ayuda

-o define el nombre del archivo de salida

COMANDOS DE MACRO

Los comandos de definición de macro están prefijados con %def y pueden tomar 0, 1 o más parámetros. Las macros se usarán generalmente como parte de un comando var como se muestra a continuación. Las macros se eliminan usando el comando %undef.


-----sintaxis:
%def NOMBRE_MACRO(parámetros)<definición_macro>
%undef NOMBRE_MACRO(parámetros)


-----notas:
Notas: (a) los () deben usarse en la definición incluso si no se usan parámetros, (b) el nombre puede ser cualquier combinación de caracteres mayúsculas y minúsculas y números, (c) cuando la macro se usa en un comando, se prefija con un símbolo &, (d) es una buena idea colocar siempre un símbolo % al final de la definición, (e) los comentarios (prefijados con un símbolo %) se pueden colocar después de la definición de la macro al igual que en TeX o LaTeX.


-----ejemplos:
%def d2r()_pi_/180% % grados2radianes
%def AreaDeRectangulo(x,y)x*y% % ancho x, largo y
%undef d2r() % eliminar la macro


-----uso:
var j2= 6*(&d2r(45) + 23)
var a3 = 3*&AreaDeRectangulo(5,7)

COMANDOS GENERALES

EXPRESIONES NUMÉRICAS
Al tratar con comandos, nos referiremos frecuentemente al término `expresión numérica' por el cual se entiende (a) un número (entero o decimal), (b) una variable o constante numérica (definida usando el comando var o const), (c) cualquier función, macro o expresión matemática de mathsPIC que se evalúe a un número, o (d) un par de nombres de puntos (ej. AB) que representan la distancia pitagórica entre los dos puntos. Se debe usar un cero inicial con fracciones decimales menores que uno.


En general, si el argumento de un comando acepta un número, también aceptará una `expresión numérica' (<expr>) como se definió anteriormente. A veces, una <unidad> posterior se asocia con el número o la expresión numérica, en cuyo caso el número o la expresión numérica se pueden delimitar con un paréntesis redondo (o separar de la unidad con un <espacio>), como se muestra en los siguientes ejemplos.


-----ejemplos:
ArrowShape(3mm, 20,40)
var h=4
ArrowShape(h mm, 20, 40)
ArrowShape((2*h)mm,20,40)

BARRA INVERTIDA \
Una barra invertida inicial sin un espacio siguiente indica que es parte de un comando PiCTeX, TeX o LaTeX, en cuyo caso mathsPIC simplemente copia la línea completa literalmente en el archivo de salida. Una barra invertida inicial seguida de uno o más espacios hace que mathsPIC copie la línea completa literalmente en el archivo de salida pero sin la barra invertida.

USANDO EL PAQUETE COLOR
El paquete COLOR estándar se puede usar con mathsPIC, pero tenga en cuenta que es importante cargar el paquete COLOR después del paquete mathsPIC.


Es mejor colocar un símbolo de comentario % al final de los comandos LaTeX y TeX para limitar el espacio en blanco al final.


En caso de cualquier derrame de color de un diagrama a cualquier texto siguiente (esto solía ser un problema en las primeras implementaciones de TeX) considere usar el comando \normalcolor como delimitador dentro del entorno \beginpicture...\endpicture.

CONST
El comando const se utiliza para definir constantes escalares. Tenga en cuenta que un nombre de constante debe comenzar con una sola letra (mayúscula o minúscula) y puede tener hasta un máximo de tres dígitos siguientes. Tenga en cuenta que las constantes, variables y puntos tienen la misma estructura de nombre, y una constante podría tener el mismo nombre que un punto (y por lo tanto sugerimos que los puntos tengan letras mayúsculas y las variables y constantes tengan letras minúsculas). El argumento escalar puede ser cualquier expresión numérica. No se pueden reasignar nuevos valores a nombres de constantes existentes. Si esto ocurre, mathsPIC emitirá un mensaje de error.


-----sintaxis:
const nombre = <expr>


-----ejemplos:
const r = 20, r4 = r3*tan(0.3)

DashArray
El comando dasharray toma un número arbitrario de argumentos emparejados que se utilizan para especificar un patrón de guiones.


-----sintaxis
dasharray(d1 , g1 , d2 , g2 , ... )


-----notas
Los ds denotan la longitud de un guion y los gs denotan la longitud del espacio entre dos guiones consecutivos. Debe haber un número par de argumentos. Si se utiliza una variable o expresión, debe separarse de la unidad con un <espacio> o con paréntesis redondos ( ) como se muestra abajo.


-----ejemplo
dasharray(6pt, 2pt, 1pt, 2pt)
var d=2
dasharray(6pt, 2pt, 1pt, d pt)
dasharray(6pt, 2pt, 1pt, (d)pt)
dasharray(6pt, 2pt, 1pt, (3*d)pt)

wAngleArc
Este comando dibuja un arco en el ángulo especificado, a una distancia <radio> del ángulo. El ángulo es <interno> (menos de 180 grados) o <externo> (mayor de 180 grados). La dirección del arco es <en sentido horario> o <en sentido antihorario>, y esta dirección debe corresponder con la secuencia de letras especificadas para el ángulo. Se producirán resultados extraños e inesperados si los cuatro parámetros no son internamente consistentes. El orden de las opciones ángulo/radio/interno o externo/sentido horario o antihorario es importante. El parámetro <radio> puede ser cualquier expresión numérica.


-----sintaxis:
DrawAngleArc{ángulo(), radio(), externo, sentido_horario}


-----ejemplo:
DrawAngleArc{ángulo(ABC), radio(3), externo, sentido_horario}
var r=3
DrawAngleArc{ángulo(ABC), radio(r), externo, sentido_horario}

La dirección de la flecha es <en sentido horario> o <en sentido antihorario>, y esta dirección debe corresponder con la secuencia de letras especificadas para el ángulo. El parámetro <radio> puede ser cualquier expresión numérica.

InputFile
Este comando introduce un archivo de texto plano que contiene comandos de mathsPIC. Opcionalmente, el archivo puede ser introducido varias veces, en cuyo caso este comando funciona como un BUCLE DO. El <número_de_bucle> puede ser cualquier expresión numérica. Si el <número_de_bucle> no es un entero, mathsPIC redondeará el valor hacia abajo al entero más cercano. Ver también los comandos beginLOOP ... endLOOP.


-----sintaxis:
inputFile[*](<nombre_archivo>)[<número_de_bucle>]


-----notas:
El comando inputfile* se utiliza para introducir un archivo en modo verbatim, es decir, un archivo sin comandos de mathsPIC, por ejemplo, un archivo que solo contiene comandos de PiCTeX o puntos de datos para graficar, etc. Tenga en cuenta que el comando inputfile* no tiene opción de <número_de_bucle>. Tenga en cuenta también que PiCTeX requiere un número IMPAR de puntos.


-----ejemplos:
inputFile(mifile.dat)[4]
inputFile*(midatoscurva.dat)

LineThickness
Este comando establece un grosor de línea particular. El comando linethickness(default) restaura el grosor de línea de trabajo al valor predeterminado de 0.4pt. El valor actual del grosor de línea (en unidades actuales) se puede acceder usando el comando var (esto puede ser útil al dibujar figuras usando líneas gruesas).


-----sintaxis:
LineThickness(<expr><unidades>)
LineThickness(default)
var t = _linethickness_


-----notas:
Este comando también establece la fuente a cmr y el símbolo de punto a \CM . y también establece el grosor de la regla para dibujar líneas horizontales y verticales. Es importante incluir un cero inicial con fracciones decimales menores que uno.


-----ejemplos:
linethickness(2pt)
var t=3
linethickness((t)pt)
lineThickness((2*t)pt)
linethickness(default)
var t = _linethickness_


-----precaución:
Tenga en cuenta que existe un comando similar en PiCTeX con el mismo nombre (pero con una sintaxis diferente).

PAPER
Define el área de trazado en términos de las opciones units(), xrange(), yrange(), axes() y ticks(). El argumento units() debe contener un valor numérico y una unidad de longitud TeX válida mm, cm, pt, pc(pica), in(pulgada), bp(punto grande), dd(didot), cc(cícero), sp(punto escalado). Los ejes X e Y pueden tener unidades diferentes (ver segundo ejemplo abajo). Los argumentos axes() XYTBLR se refieren a los ejes X e Y, y a los ejes Superior, Inferior, Izquierdo y Derecho. Un * después de uno de los ejes deshabilita las marcas en ese eje. Los ejes X e Y pasan por los ceros.


-----ejemplos:
paper{units(1cm),xrange(0,10),yrange(0,10)}
paper{units(2cm,1cm),xrange(0,10),yrange(0,10),axes(LB)}
paper{units(1mm),xrange(0,100),yrange(0,100),axes(XY)}
paper{units(1cm),xrange(-5,5),yrange(-5,5),axes(LRTBXY),ticks(1,1)}
paper{units(1cm),xrange(-5,5),yrange(-5,5),axes(LRT*B*)}

POINT

Define un nuevo punto asignando coordenadas a un nuevo nombre de punto. El asterisco (*) reasigna coordenadas a un nombre de punto existente.

-----syntax:
POINT[*](<nombre>){<punto>}[symbol=<caracteres>, radius=<expresion>]
POINT[*](<nombre>){<ubicacion>}[symbol=<caracteres>, radius=<expresion>]

-----notas:
<nombre> una letra inicial más un máximo de tres dígitos posteriores.
<caracteres> cualquier cadena TeX permitida en un \hbox{}.
<expresion> cualquier expresión numérica.
La opción polar(r,theta) usa radianes por defecto para el ángulo theta. Para trabajar en grados, debe añadir <deg>, por ejemplo: polar(r,theta deg). Puede usar <direction()> y <directiondeg()> para reemplazar theta. Tenga en cuenta que el término vector(AB) significa usar el mismo (r, theta) que AB.

-----ejemplos:
point(A){5,5}
point(B2){22,46}[symbol=$\odot$]
point(B2){22,46}[symbol=circle(2),radius=5]
var r=3
point(B2){22,46}[symbol=square(3),radius=r]
point(B123){22,46}[radius=5]
point(D2){B2, shift(5,5)}
var s = 3
point(D2){B2, shift(2*s,4*s)}
point(D3){D2, polar(6,32 deg)}
point(D4){D2, polar(6,1.2 rad)}
point(D4){D2, polar(6, direction(AB))} %% radianes por defecto
point(D4){D2, polar(6, directiondeg(AB) deg)}
point(G2){Q, rotate(P, 23 deg)}
point(G2){Q, vector(AB)}
point(D2){intersection(AB,CD)}
point(F){PointOnLine(AB,5.3)}
point(G){perpendicular(P,AB)}
point(H){circumcircleCenter(ABC)}
point(J){incircleCenter(ABC)}
point(K){excircleCenter(ABC,BC)}
point*(A){6,3}
point*(P){Q}
point*(B){B, shift(5,0)}
point*(P){xcoord(J),ycoord(K)}

PointSymbol

Este comando permite cambiar el símbolo de punto por defecto \bullet (con radio libre de línea cero). El comando PointSymbol es particularmente útil cuando un conjunto de puntos utiliza el mismo símbolo de punto, por ejemplo, al dibujar gráficos. El símbolo de punto puede restablecerse al valor predeterminado \bullet usando el comando PointSymbol(default).

-----syntax:
PointSymbol(<símbolo>, <radio-libre-de-línea>)
PointSymbol(default)

-----notas:
El comando PointSymbol solo influye en los comandos de punto subsiguientes.
El corchete opcional del comando punto anula el comando PointSymbol.

-----ejemplos:
PointSymbol($\odot$, 0.7)
PointSymbol(default)

SHOW....

Este comando hace que mathsPIC devuelva el valor de un cálculo o parámetro especificado; por ejemplo, el valor de un ángulo particular o la longitud de una línea. El resultado se muestra en el archivo de salida como una línea comentada. Esto permite ajustar los comandos de mathsPIC a la luz de los cálculos. Actualmente hay cinco comandos de este tipo, como se indica a continuación.

-----syntax:
showLength(AB)
showAngle(ABC) % devuelve el ángulo en radianes
showAngledeg(ABC) % devuelve el ángulo en grados
showArea(ABC)
showPoints
showVariables

TEXT

Este comando coloca una cadena de texto en una ubicación específica. Por defecto, el texto se centra vertical y horizontalmente en el punto especificado. Opcionalmente, el texto se puede colocar en relación con un punto utilizando combinaciones apropiadas de las opciones de `posición' de PiCTeX l t r B b para alinear el borde (i)zquierdo, el borde (d)erecho, el borde (s)uperior, la (l)ínea base, el borde (i)nferior, respectivamente, de la caja de texto con la ubicación del punto.

Recuerde que las unidades predeterminadas para el argumento del ángulo de la expresión polar() son radianes; por lo tanto, DEBE añadir `deg' si desea trabajar en grados.

-----syntax:
text(<cadena>){<ubicacion>}[<opciones-posicion>]
text(<cadena>){<nombre-punto>, shift(<x>,<y>)}[]
text(<cadena>){<nombre-punto>, polar(<r>,<angulo>[rad])}[]

-----ejemplos:
text(A){5,6}
text($A_1$){A1, shift(2, 2)}
text(Z2){Z2, shift(5, -5)}[tr]
text(Z3){Z2, polar(5, 20 deg)}[Br]
text(Z4){Z2, polar(5, 1.34 rad)}
text(\framebox{Z5}){Z5}

VAR

El comando var se utiliza para definir variables escalares. Puede ser cualquier expresión numérica. Un nombre de variable debe comenzar con una sola letra (mayúscula o minúscula) y puede tener hasta un máximo de cuatro dígitos posteriores. Si se requiere un nombre de variable más detallado, una alternativa simple es usar una macro de mathsPIC, ya que cualquier cadena se puede asignar a través de macros (consulte el principio de este capítulo para obtener detalles sobre macros).

Tenga en cuenta que las variables, las constantes y los puntos tienen la misma estructura de nombre, y una variable puede tener el mismo nombre que un punto (y por lo tanto sugerimos que los puntos tengan letras mayúsculas y las variables y constantes tengan letras minúsculas). Se pueden reasignar nuevos valores a nombres de variable existentes; sin embargo, cuando esto ocurre, mathsPIC no emite un mensaje de advertencia para resaltar este hecho.

Si es importante recibir una advertencia si una variable potencial se reasigna accidentalmente, entonces se debe considerar el uso del comando const en su lugar (ya que mathsPIC genera un mensaje de error si se reasigna una constante).

-----syntax:
var <nombre> = <expresion>

-----notas:
Además de las funciones matemáticas, las funciones de mathsPIC que se pueden usar con el comando var son:

angle(<tres-puntos>) % devuelve el ángulo en radianes
angledeg(<tres-puntos>) % devuelve el ángulo en grados
area(<tres-puntos>)
xcoord(<punto>)
ycoord(<punto>)
direction(<dos-puntos>) % devuelve la dirección angular en radianes
