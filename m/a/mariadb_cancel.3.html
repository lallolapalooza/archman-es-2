Nombre

mariadb_cancel - Aborta inmediatamente una conexión

Sintaxis

#include <mysql.h>
int mariadb_cancel(MYSQL * mysql);

Descripción

Aborta inmediatamente una conexión haciendo que todas las operaciones posteriores de lectura/escritura fallen. mariadb_cancel() no invalida la memoria utilizada para la estructura mysql, ni cierra ningún canal de comunicación. Para liberar la memoria, se debe llamar a mysql_close(3). mariadb_cancel() es útil para interrumpir consultas largas en situaciones donde enviar KILL no es posible.

Parámetro

mysql - manejador mysql, que fue previamente asignado por mysql_init(3) y conectado por mysql_real_connect(3).

Valor de retorno

Devuelve cero si la operación es exitosa o un valor distinto de cero en caso de error.

Historial

mariadb_cancel() se añadió en Connector/C 3.0

Versión 3.4
