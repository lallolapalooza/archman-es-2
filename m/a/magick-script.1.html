NOMBRE

magick-script - lenguaje de scripting que convierte entre formatos de imagen, así como redimensiona una imagen, desenfoca, recorta, elimina manchas, difumina, dibuja sobre, voltea, une, remuestrea y mucho más.

SINOPSIS

magick-script [opciones-de-entrada] archivo-de-entrada [opciones-de-salida] archivo-de-salida

DESCRIPCIÓN GENERAL

El programa magick-script es miembro del conjunto de herramientas ImageMagick(1). Úselo para convertir entre formatos de imagen, así como para redimensionar una imagen, desenfocar, recortar, eliminar manchas, difuminar, dibujar sobre, voltear, unir, remuestrear y mucho más. Aquí hay un script de ejemplo:


#!/bin/env magick-script
-size 100x100 xc:red ( rose: -rotate -90 ) +append -write show:

Para más información sobre el comando magick-script, abra su navegador en file:///usr/share/doc/ImageMagick-7/www/magick-script.html o https://imagemagick.org/script/magick-script.php.

Opciones Misceláneas:
-debug events mostrar información de depuración copiosa
-help imprimir opciones del programa
-log format formato de la información de depuración
-list type imprimir una lista de argumentos de opción admitidos
-version imprimir información de la versión

Use cualquier configuración u operador como una opción-de-salida. Solo un número limitado de configuraciones son opción-de-entrada. Incluyen: -antialias, -caption, -density, -define, -encoding, -font, -pointsize, -size, y -texture, así como cualquiera de las opciones misceláneas.

Por defecto, el formato de imagen de `archivo' se determina por su número mágico. Para especificar un formato de imagen particular, preceda el nombre del archivo con un nombre de formato de imagen y dos puntos (es decir, ps:imagen) o especifique el tipo de imagen como sufijo del nombre del archivo (es decir, imagen.ps). Especifique `archivo' como '-' para la entrada o salida estándar.
