MASKTEST(1) Suite de pruebas MASKTEST(1)

NOMBRE

masktest - Busca diferencias en la coincidencia de comodines entre la implementación de Samba y la de un servidor remoto.

SINOPSIS

masktest {//servidor/recurso} [-U usuario%contraseña] [-d nivel_depuracion] [-W grupo_trabajo] [-n bucles] [-s semilla] [-a] [-E] [-M protocolo_max] [-f caracteres_archivo] [-m caracteres_mascara] [-v]

DESCRIPCIÓN

masktest es una utilidad para detectar diferencias en el comportamiento entre la implementación de Samba y la de un servidor remoto. Generará nombres de archivo/máscaras aleatorias y verificará si coinciden con los mismos archivos que lo hacen en el servidor de archivos local como lo hacen en el servidor remoto. Mostrará cualquier diferencia que encuentre.

Esta utilidad es utilizada por el equipo de Samba para encontrar diferencias de comportamiento entre Samba y los servidores de Windows.

OPCIONES

-U usuario%contraseña

Especifica el usuario y la contraseña a usar al iniciar sesión en los recursos compartidos. Este parámetro se puede especificar dos veces (una para el primer servidor, una para el segundo).

-s semilla

Siembra el generador de números aleatorios con el valor especificado.

-n numops

Establece el número de operaciones a realizar.

-a

Imprime las operaciones que se están realizando.

-M max_protocol

Protocolo máximo a usar.

-f

Especifica los caracteres que se pueden usar al generar nombres de archivo. Por defecto: abcdefghijklm.

-E

Aborta cuando se encuentra una diferencia en el comportamiento.

-m maskchars

Especifica los caracteres utilizados para comodines.

-v

Sea verboso.
