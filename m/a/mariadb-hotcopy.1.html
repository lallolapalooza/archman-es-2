MARIADB-HOTCOPY(1) Sistema de bases de datos MariaDB MARIADB-HOTCOPY(1)

NOMBRE

mariadb-hotcopy - un programa de copia de seguridad de bases de datos (mariadb-hotcopy es ahora un enlace simbólico a mariadb-hotcopy)

SINOPSIS

mariadb-hotcopy argumentos

DESCRIPCIÓN

mariadb-hotcopy es un script de Perl que fue escrito originalmente y contribuido por Tim Bunce. Utiliza FLUSH TABLES, LOCK TABLES y cp o scp para realizar una copia de seguridad de la base de datos. Es una forma rápida de hacer una copia de seguridad de la base de datos o de tablas individuales, pero solo se puede ejecutar en la misma máquina donde se encuentran los directorios de la base de datos. mariadb-hotcopy solo funciona para hacer copias de seguridad de tablas MyISAM y ARCHIVE. Se ejecuta en Unix y NetWare.

Para usar mariadb-hotcopy, debes tener acceso de lectura a los archivos de las tablas de las que estás haciendo una copia de seguridad, el privilegio SELECT para esas tablas, el privilegio RELOAD (para poder ejecutar FLUSH TABLES) y el privilegio LOCK TABLES (para poder bloquear las tablas).

shell> mariadb-hotcopy nombre_bd [/ruta/al/nuevo_directorio]
shell> mariadb-hotcopy nombre_bd_1 ... nombre_bd_n /ruta/al/nuevo_directorio

Haz una copia de seguridad de tablas en la base de datos dada que coincidan con una expresión regular:

shell> mariadb-hotcopy nombre_bd./regex/

La expresión regular para el nombre de la tabla puede ser negada prefijándola con una tilde (“~”):

shell> mariadb-hotcopy nombre_bd./~regex/

mariadb-hotcopy soporta las siguientes opciones, que pueden especificarse en la línea de comandos o en los grupos de archivos de opciones [mariadb-hotcopy] y [client].

•--help, -?

Muestra un mensaje de ayuda y sale.

•--addtodest

No renombrar el directorio de destino (si existe); simplemente añadir archivos a él.

•--allowold

No abortar si existe un destino; renombrarlo añadiendo un sufijo _old.

•--checkpoint=nombre_bd.nombre_tbl

Insertar entradas de punto de control en la base de datos nombre_bd y tabla nombre_tbl especificadas.

•--chroot=ruta

Directorio base de la cárcel chroot en la que opera mariadbd. El valor de ruta debe coincidir con el de la opción --chroot dada a mariadbd.

•--debug

Habilitar salida de depuración.

•--dryrun, -n

Informar acciones sin realizarlas.

•--flushlog

Vaciar registros después de que todas las tablas estén bloqueadas.

•--host=nombre_host, -h nombre_host

El nombre de host de la máquina local a usar para establecer una conexión TCP/IP con el servidor local. Por defecto, la conexión se realiza a localhost utilizando un archivo de socket Unix.

•--keepold

No eliminar el destino anterior (renombrado) al finalizar.

•--method=comando

El método para copiar archivos (cp o scp). El valor predeterminado es cp.

•--noindices

No incluir los archivos de índice completos para tablas MyISAM en la copia de seguridad. Esto hace que la copia de seguridad sea más pequeña y rápida. Los índices para tablas recargadas se pueden reconstruir más tarde con myisamchk -rq.

•--old-server

Conectarse a servidores MySQL antiguos (anteriores a v5.5) que no tienen FLUSH TABLES WITH READ LOCK completamente implementado.

•--password=contraseña, -pcontraseña

La contraseña a usar al conectarse al servidor. El valor de la contraseña no es opcional para esta opción, a diferencia de otros programas de MariaDB.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puedes usar un archivo de opciones para evitar dar la contraseña en la línea de comandos.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar al conectarse al servidor local.

•--quiet, -q

Ser silencioso excepto por los errores.

•--record_log_pos=nombre_bd.nombre_tbl

Registrar el estado maestro y esclavo en la base de datos nombre_bd y tabla nombre_tbl especificadas.

•--regexp=expresión

Copiar todas las bases de datos con nombres que coincidan con la expresión regular dada.

•--resetmaster

Restablecer el log binario después de bloquear todas las tablas.

•--resetslave

Restablecer el archivo master.info después de bloquear todas las tablas.

•--socket=ruta, -S ruta

El archivo de socket Unix a usar para conexiones a localhost.

•--suffix=str

El sufijo a usar para los nombres de las bases de datos copiadas.

•--tmpdir=ruta

El directorio temporal. El valor predeterminado es /tmp.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a usar al conectarse al servidor.

Usa perldoc para obtener documentación adicional de mariadb-hotcopy, incluyendo información sobre la estructura de las tablas necesarias para las opciones --checkpoint y --record_log_pos:

shell> perldoc mariadb-hotcopy

mariadb-hotcopy(1)

mariadb-hotcopy - Copia en caliente de tablas de bases de datos MySQL/MariaDB.

DESCRIPCIÓN

mariadb-hotcopy es una utilidad que realiza una copia en caliente de las tablas de una base de datos MySQL o MariaDB. Esto significa que las tablas se copian sin bloquearlas para operaciones de escritura, permitiendo que las aplicaciones continúen funcionando durante el proceso de copia.

La herramienta funciona realizando un bloqueo de lectura en las tablas que se van a copiar y luego copiando los archivos de datos correspondientes al directorio de destino. Al finalizar, se liberan los bloqueos.

mariadb-hotcopy es particularmente útil para realizar copias de seguridad de bases de datos que no pueden permitirse tiempos de inactividad significativos.
