MATE-TERMINAL(1) Comandos de usuario MATE-TERMINAL(1)

NOMBRE

mate-terminal - página del manual de MATE Terminal Emulator

DESCRIPCIÓN

Uso:

mate-terminal [OPCIÓN...]

Opciones de Ayuda:

-h, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda
--help-terminal
Mostrar opciones de terminal
--help-window-options
Mostrar opciones por ventana
--help-terminal-options
Mostrar opciones por terminal
--help-gtk
Mostrar opciones GTK+
--help-sm-client
Mostrar opciones de gestión de sesiones

Opciones para abrir nuevas ventanas o pestañas de terminal; se pueden especificar más de una de estas:

--window
Abrir una nueva ventana que contenga una pestaña con el perfil predeterminado
--tab
Abrir una nueva pestaña en la última ventana abierta con el perfil predeterminado

Opciones de ventana; si se usan antes del primer argumento --window o --tab, establecen el predeterminado para todas las ventanas:

--show-menubar
Activar la barra de menú
--hide-menubar
Desactivar la barra de menú
--maximize
Maximizar la ventana
--full-screen
Poner la ventana en pantalla completa
--geometry=GEOMETRÍA
Establecer el tamaño de la ventana; por ejemplo: 80x24, o 80x24+200+200 (COLSxROWS+X+Y)
--role=ROL
Establecer el rol de la ventana
--active
Establecer la última pestaña especificada como la activa en su ventana

Opciones de terminal; si se usan antes del primer argumento --window o --tab, establecen el predeterminado para todas las terminales:

-e, --command
Ejecutar el argumento de esta opción dentro de la terminal
-x, --execute
Ejecutar el resto de la línea de comandos dentro de la terminal
--profile=NOMBRE-PERFIL
Usar el perfil dado en lugar del perfil predeterminado
-t, --title=TÍTULO
Establecer el título de la terminal
--working-directory=NOMBRE-DIR
Establecer el directorio de trabajo
--zoom=ZOOM
Establecer el factor de zoom de la terminal (1.0 = tamaño normal)

Opciones GTK+

--class=CLASE
Clase del programa según la usa el gestor de ventanas
--name=NOMBRE
Nombre del programa según lo usa el gestor de ventanas
--screen=PANTALLA
Pantalla X a usar
--sync
Hacer que las llamadas X sean síncronas
--gtk-module=MÓDULOS
Cargar módulos GTK+ adicionales
--g-fatal-warnings
Hacer que todas las advertencias sean fatales

Opciones de gestión de sesiones:

--sm-client-disable
Desactivar la conexión con el gestor de sesiones
--sm-client-state-file=ARCHIVO
Especificar el archivo que contiene la configuración guardada
--sm-client-id=ID
Especificar el ID de gestión de sesiones

Opciones de aplicación:

--disable-factory
No registrarse en el servidor de nombres de activación, no reutilizar una terminal activa
--load-config=ARCHIVO
Cargar un archivo de configuración de terminal
--save-config=ARCHIVO
Guardar la configuración de la terminal en un archivo
--display=PANTALLA
Pantalla X a usar

La documentación completa de mate-terminal se mantiene como un manual de Texinfo.

Si los programas info y mate-terminal están correctamente instalados en su sitio, el comando

info mate-terminal

debería darle acceso al manual completo.

Puede encontrar más documentación de MATE Terminal en el menú Ayuda, o presionando la tecla F1.

También puede haber información adicional en: http://wiki.mate-desktop.org/docs
