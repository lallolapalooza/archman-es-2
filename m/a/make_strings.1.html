NOMBRE

make_strings - herramienta para construir listas de cadenas localizables a partir de archivos Objective-C

SINOPSIS

make_strings [--help] [--verbose] [--aggresive-import] [--aggressive-match] [--aggressive-remove] [-L idiomas] archivos.[hmc...]

DESCRIPCIÓN

make_strings analiza archivos Objective-C y construye listas de cadenas localizables. Luego crea nuevos archivos .strings o fusiona las cadenas con archivos .strings existentes. Es bastante inteligente al hacer coincidir cadenas antiguas y nuevas, y produce archivos .strings que son (supuestamente) fáciles de usar para un traductor.

make_strings acepta las siguientes opciones:

OPCIONES

--help
Imprime una breve lista de las opciones disponibles.
--verbose
Imprime información adicional mientras procesa.
-L idiomas
Especifica qué idiomas procesar. Se aceptan múltiples opciones -L, o varios idiomas definidos en un solo indicador -L.
--aggressive-import
Activa --aggresive-match y elimina automáticamente las entradas "dummy" que se agregan al importar archivos .strings que no fueron creados por el programa make_strings. Esta opción es adecuada cuando make_strings se ejecuta por primera vez y existe un archivo .strings que contiene una traducción bastante precisa.
--aggressive-match
Esta opción hará que make_strings asuma que las claves coincidentes deben tener traducciones coincidentes. Esto puede ahorrar mucho trabajo, pero aumenta el riesgo de traducciones erróneas.
--aggressive-remove
Elimina cadenas/claves obsoletas.

EJEMPLOS

make_strings -L "Inglés Sueco Ruso" *.[hm]
