NOMBRE

makeglossaries-lite - Llama a makeindex/xindy para documentos LaTeX que usan el paquete glossaries

SINOPSIS

makeglossaries [-o archivo] [-q] [-n] [-s archivo] [-t archivo] [-L idioma] [-c] [-g] [-l] [-p num] [-r] [-m archivo] [-x archivo] [--version] [--help] nombre_base

DESCRIPCIÓN

makeglossaries-lite es una alternativa Lua reducida al script de Perl makeglossaries. Está diseñado para usarse con documentos LaTeX que utilizan el paquete glossaries. Algunas opciones disponibles para makeglossaries no están disponibles con makeglossaries-lite. El argumento obligatorio nombre_base debe ser el nombre del documento LaTeX sin la extensión .tex. makeglossaries-lite leerá el archivo auxiliar para determinar si se debe llamar a makeindex o xindy. Toda la información requerida para ser pasada a la aplicación de indexación relevante también debe estar contenida en el archivo auxiliar, pero puede ser anulada por los argumentos de opción de makeglossaries-lite.

OPCIONES

-q
Modo silencioso. Reduce la salida a la salida estándar.
-n
Imprime los comandos que normalmente se ejecutarían, pero no los ejecuta.
-o archivo
Usa archivo como archivo de salida. (Solo adecuado para documentos que contienen un solo glosario, de lo contrario, cada glosario será sobrescrito).
-s archivo
Usa archivo como archivo de estilo. Tenga en cuenta que si usa esta opción, debe saber si se llamará a makeindex o xindy, ya que tienen archivos de estilo diferentes.
-t archivo
Usa archivo como archivo de transcripción.
-l
Ordenación por letras.
-L idioma
Esta opción solo tiene efecto si se llama a xindy. Establece el idioma. Consulte la documentación de xindy para obtener más detalles.
-c
Comprime los espacios intermedios (solo makeindex).
-g
Emplea ordenación de palabras alemana (solo makeindex).
-p num
Establece el número de página inicial a num (solo makeindex).
-r
Deshabilita la formación implícita de rangos de páginas (solo makeindex).
-m archivo
Especifica el nombre de ruta completo para makeindex a archivo en el caso de que makeindex no esté en la ruta del sistema operativo.
-x archivo
Especifica el nombre de ruta completo para xindy a archivo en el caso de que xindy no esté en la ruta del sistema operativo.
--version
Imprime el número de versión y sale.
--help
Imprime el mensaje de ayuda y sale.

REQUIERE

texlua y makeindex o xindy (dependiendo de las opciones del paquete glossaries).
