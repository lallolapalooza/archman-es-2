MAKEPKG(8) Manual de Pacman MAKEPKG(8)

NOMBRE

makepkg - utilidad para construir paquetes

SINOPSIS

makepkg [opciones] [VARENTORNO=valor] [VARENTORNO+=valor] ...

DESCRIPCIÓN

makepkg es un script para automatizar la construcción de paquetes. Los requisitos para usar el script son una plataforma *nix capaz de compilar y un script de compilación personalizado para cada paquete que desees compilar (conocido como PKGBUILD). Consulta PKGBUILD(5) para obtener detalles sobre cómo crear tus propios scripts de compilación.

La ventaja de una compilación basada en scripts es que el trabajo se realiza solo una vez. Una vez que tengas el script de compilación para un paquete, makepkg hará el resto: descargar y validar archivos fuente, verificar dependencias, configurar los ajustes de tiempo de compilación, compilar el paquete, instalar el paquete en una raíz temporal, realizar personalizaciones, generar metainformación y empaquetar todo para que pacman lo use.


Nota

makepkg utiliza tu configuración regional actual por defecto y no la desactiva al compilar paquetes. Si deseas compartir la salida de tu compilación con otros al solicitar ayuda o para otros fines, es posible que desees ejecutar "LC_ALL=C makepkg" para que tus registros y salida no estén localizados.

OPCIONES

-A, --ignorearch

Ignora un campo de arquitectura faltante o incompleto en el script de compilación. Esto es para recompilar paquetes desde el código fuente cuando el PKGBUILD puede estar ligeramente desactualizado y no actualizado con un campo arch=('tuarquitectura').

-c, --clean

Limpia los archivos y directorios de trabajo sobrantes después de una compilación exitosa.

--config <archivo>

Usa un archivo de configuración alternativo en lugar del predeterminado /etc/makepkg.conf.

-d, --nodeps

No realiza ninguna verificación de dependencias. Esto te permitirá anular e ignorar cualquier dependencia requerida. Hay una alta probabilidad de que esta opción rompa el proceso de compilación si todas las dependencias no están instaladas.

-e, --noextract

No extrae los archivos fuente ni ejecuta la función prepare() (si está presente); utiliza cualquier fuente que ya exista en el directorio $srcdir/. Esto es útil si deseas entrar en $srcdir/ y aplicar parches o modificar manualmente el código, luego crear un paquete con el resultado. Ten en cuenta que crear un parche puede ser una mejor solución para permitir que otros utilicen tu PKGBUILD.

--verifysource

Para cada archivo fuente en el array de fuentes del PKGBUILD, descarga el archivo si es necesario y realiza las comprobaciones de integridad. No se realiza ninguna extracción ni compilación. Las dependencias especificadas en el PKGBUILD no se manejarán a menos que se use --syncdeps. Útil para realizar compilaciones posteriores sin conexión.

-f, --force

makepkg no compilará un paquete si ya existe un paquete compilado en el directorio PKGDEST (establecido en makepkg.conf(5)), que puede ser el directorio actual por defecto. Esto permite sobrescribir el paquete compilado.

-g, --geninteg

Para cada archivo fuente en el array de fuentes del PKGBUILD, descarga el archivo si es necesario y genera comprobaciones de integridad. Las comprobaciones de integridad generadas se determinan por las comprobaciones presentes en el PKGBUILD, recurriendo al valor del array INTEGRITY_CHECK en makepkg.conf(5) si estas están ausentes. Esta salida se puede redirigir a tu PKGBUILD para la validación de fuentes usando "makepkg -g >> PKGBUILD".

--skipinteg

No realiza ninguna comprobación de integridad (suma de verificación y PGP) en los archivos fuente.

--skipchecksums

No verifica las sumas de verificación de los archivos fuente.

--skippgpcheck

No verifica las firmas PGP de los archivos fuente.

-h, --help

Muestra la sintaxis y las opciones de la línea de comandos.

--holdver

Al usar fuentes VCS (PKGBUILD(5)), cualquier fuente extraída actualmente no se actualizará a la última revisión.

-i, --install

Instala o actualiza el paquete después de una compilación exitosa usando pacman(8).

-L, --log

Habilita el registro. Esto usará el programa tee para enviar la salida de cada una de las funciones del PKGBUILD tanto a la consola como a un archivo de texto en el directorio de compilación llamado pkgbase-pkgver-pkgrel-arch-<función>.log. Como se mencionó anteriormente, los registros estarán localizados, por lo que es posible que desees configurar tu configuración regional en consecuencia si compartes la salida del registro con otros.

-m, --nocolor

Deshabilita el color en los mensajes de salida.

-o, --nobuild

Descarga y extrae archivos, ejecuta la función prepare(), pero no los compila. Útil con la opción --noextract si deseas modificar los archivos en $srcdir/ antes de compilar.

-p <scriptdecompilación>

Lee el script de compilación del paquete scriptdecompilación en lugar del predeterminado PKGBUILD; consulta PKGBUILD(5). El scriptdecompilación debe estar ubicado en el directorio desde el cual se llama a makepkg.

-r, --rmdeps

Tras una compilación exitosa, elimina cualquier dependencia instalada por makepkg durante la resolución e instalación automática de dependencias cuando se usa -s.

-R, --repackage

Reempaqueta el contenido del paquete sin reconstruirlo. Esto es útil si olvidaste, por ejemplo, una dependencia o un archivo de instalación en tu PKGBUILD y la compilación en sí no cambiará.

-s, --syncdeps

Instala las dependencias faltantes usando pacman. Cuando no se encuentran dependencias en tiempo de compilación o en tiempo de ejecución, pacman intentará resolverlas. Si tiene éxito, los paquetes faltantes se descargarán e instalarán.

-S, --source

No compila realmente el paquete, sino que crea un tarball solo de fuentes que no incluye las fuentes que se pueden obtener a través de una URL de descarga. Esto es útil para pasar un único tarball a otro programa, como un chroot, un compilador remoto o una carga de tarball. Debido a que se verifican las comprobaciones de integridad, todos los archivos fuente del paquete deben estar presentes o ser descargables.

-V, --version

Muestra información de la versión.

-C, --cleanbuild

Limpia los artefactos de compilación de ejecuciones anteriores de makepkg en el directorio actual eliminando $srcdir/ antes de compilar el paquete.

-D <dir>, --dir <dir>

Cambia al directorio <dir> antes de leer el PKGBUILD o hacer cualquier otra cosa.

--allsource

No compila realmente el paquete, sino que crea un tarball solo de fuentes que incluye todas las fuentes, incluidas aquellas que normalmente se descargan a través de makepkg. Esto es útil para pasar un único tarball a otro programa, como un chroot o un compilador remoto. También satisfará los requisitos de la GPL al distribuir paquetes binarios.

--check

Ejecuta la función check() en el PKGBUILD, anulando la configuración en makepkg.conf(5).

--noarchive

No crea el archivo al final del proceso de compilación. Esto puede ser útil para probar la función package() o si tu distribución de destino no usa pacman.

--nocheck

No ejecuta la función check() en el PKGBUILD ni maneja las checkdepends.

--noprepare

No ejecuta la función prepare() en el PKGBUILD.

--noverify

No ejecuta la función verify() en el PKGBUILD.

--sign

Firma el paquete resultante con gpg, anulando la configuración en makepkg.conf(5).

--nosign

No crea una firma para el paquete compilado.

--key <clave>

Especifica una clave para usar al firmar paquetes, anulando la configuración GPGKEY en makepkg.conf(5). Si no se especifica en ninguna ubicación, se utilizará la clave predeterminada del llavero.

--noconfirm

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

makepkg(8)

NAME

makepkg - Compiles packages and builds a package ready for installation with pacman

SYNOPSIS

makepkg [options] [PKGBUILD(5)]

DESCRIPTION

makepkg is a script used to compile packages and build installable Arch Linux package files. It automates the process of downloading, compiling, and packaging software. It reads instructions from a PKGBUILD(5) file which defines how the package is to be built.

The compiled package files have the extension makepkg.conf(5) and can be installed with pacman(8).

OPTIONS

makepkg accepts the following options:

-A, --nodeps
(Passed to pacman) Do not check for missing dependencies, nor abort on missing dependencies.
-c, --clean
Clean up leftover work files and directories after a successful build.
-C, --cleanbuild
Clean up work files and directories before building the package. This is useful for ensuring a clean build environment, or when disk space is limited.
-d, --nodeps
(Deprecated) Use -A instead.
-e, --noextract
Do not extract any sources. Use this if you plan to manually extract sources or if the build does not require extracted sources.
-f, --force
Force the build, even if the package has already been built. This will overwrite any existing package file.
-g, --geninteg
Generate checksums for the source files and print them to standard output. This option can be used to pre-fill the md5sums=(), sha1sums=(), sha256sums=(), sha384sums=(), sha512sums=(), or b2sums=() arrays in the PKGBUILD(5).
-h, --help
Display a help message and exit.
-i, --install
Install the package after a successful build using pacman(8).
-k, --skipchecksums
Skip checksum validation. This is useful if the source files are not available and checksums cannot be verified.
-m, --skipmake
Skip the make stage. Use this if the package build does not require compilation.
-n, --skippgpcheck
Skip PGP signature check.
-o, --log
Create a log of the build process, which will be stored in the directory specified by LOGDEST.
-p, --printsrcinfo
(Deprecated) Use --printsrcinfo instead.
-r, --rmdeps
(Passed to pacman) Remove dependencies after installation that are not required by other packages.
-s, --syncdeps
(Passed to pacman) Install missing dependencies using pacman.
-S, --check
Run the check() function in the PKGBUILD(5). This is usually done via tests using makepkg's -s option and the check() function in the PKGBUILD.
-u, --updpkgsums
Update the checksums for the source files in the PKGBUILD(5) file.
-v, --version
Display version information and exit.
-w, --skipbuild
Do not build the package. This is useful if you only want to download and prepare the sources.
-x, --extract
Extract sources only. Use this to download and extract sources without building.
--allfiles
Generate checksums for all files in the source array.
--arch
Build the package for the specified architecture. See CARCH in makepkg.conf(5).
--asdeps
(Passed to pacman) Install packages as non-explicitly installed (used with -i / --install).
--clean
Clean up leftover work files and directories after a successful build.
--cleanbuild
Clean up work files and directories before building the package. This is useful for ensuring a clean build environment, or when disk space is limited.
--config=path
Use an alternate config file instead of the /etc/makepkg.conf default.
--config=path
Use an alternate config file instead of the /etc/makepkg.conf default.
--deps
(Passed to pacman) Check for missing dependencies and install them if needed.
--gendeps
Print the dependencies required by the package to stdout.
--getpkgbuild
Download the PKGBUILD for the specified package.
--getsrc
Download sources for the specified package.
--install
Install the package after a successful build using pacman(8).
--log
Create a log of the build process, which will be stored in the directory specified by LOGDEST.
--needed
(Passed to pacman) Tell pacman not to reinstall a target if it is already up-to-date. (used with -i / --install).
--noconfirm
(Passed to pacman) Prevent pacman from waiting for user input before proceeding with operations.
--noprogressbar
(Passed to pacman) Prevent pacman from displaying a progress bar; useful if you are redirecting makepkg output to file.
--packagelist
List the package filenames that would be produced without building. Listed package filenames include PKGDEST and PKGEXT.
--printsrcinfo
Generate and print the SRCINFO file to stdout.
--rmdeps
(Passed to pacman) Remove dependencies after installation that are not required by other packages.
--skippgpcheck
Skip PGP signature check.
--skipchecksums
Skip checksum validation. This is useful if the source files are not available and checksums cannot be verified.
--skipmake
Skip the make stage. Use this if the package build does not require compilation.
--syncdeps
(Passed to pacman) Install missing dependencies using pacman.
--url=url
Use the specified URL as the base for downloading sources. This overrides the URLs defined in the PKGBUILD.

ADDITIONAL FEATURES

makepkg supports building development versions of packages without having to manually update the pkgver in the PKGBUILD. This was formerly done using the separate utility versionpkg. See PKGBUILD(5) for details on how to set up a development PKGBUILD.

REPRODUCIBILITY

makepkg is designed to be compatible with Reproducible Builds. If the SOURCE_DATE_EPOCH environment variable is set, it will be exported to subprocesses, and source and package file modification times and package metadata will be unified based on the timestamp specified.

If the SOURCE_DATE_EPOCH environment variable is not set, makepkg will use its own start date for internal use, but will not unify source file timestamps before building.

ENVIRONMENT VARIABLES

MAKEPKG_LIBRARY="/path/to/directory"

Use an alternative libmakepkg path instead of the /usr/share/makepkg default.

PACMAN

The command that will be used to check for missing dependencies and to install and remove packages. Pacman’s -Qq, -Rns, -S, -T, and -U operations must be supported by this command. If the variable is not set or empty, makepkg will fall back to ‘pacman’.

MAKEPKG_CONF="/path/to/file"

Use an alternate config file instead of the /etc/makepkg.conf default.

PKGDEST="/path/to/directory"

Directory where the resulting packages will be stored. Overrides the corresponding value defined in makepkg.conf(5).

SRCDEST="/path/to/directory"

Directory where the downloaded sources will be stored. Overrides the corresponding value defined in makepkg.conf(5).

SRCPKGDEST="/path/to/directory"

Directory where source package files will be stored. Overrides the corresponding value defined in makepkg.conf(5).

LOGDEST="/path/to/directory"

Directory where generated log files will be stored. Overrides the corresponding value defined in makepkg.conf(5).

PACKAGER="John Doe <john@doe.com>"

String to identify the creator of the resulting package. Overrides the corresponding value defined in makepkg.conf(5).

BUILDDIR="/path/to/directory"

Directory where the package will be built. Overrides the corresponding value defined in makepkg.conf(5).

CARCH="(i686|x86_64)"

Force build for a specific architecture. Useful for cross-compiling. Overrides the corresponding value defined in makepkg.conf(5).

PKGEXT=".pkg.tar.gz", SRCEXT=".src.tar.gz"

Sets the compression used when making compiled or source packages. Overrides the corresponding value defined in makepkg.conf(5).

GNUPGHOME="/path/to/directory"

Directory where the gpg keyring for signing the built package is stored.

GPGKEY="keyid"

Specify a key to use when signing packages, overriding the GPGKEY setting in makepkg.conf(5).

SOURCE_DATE_EPOCH="<date>"

Used for Reproducible Builds.

BUILDTOOL="<name>"

The name of a tool ecosystem used to set up the build environment. Used for defining a spec for reproducible builds, e.g. the makepkg.conf(5) used.

BUILDTOOLVER="<version>"

The version of the $BUILDTOOL used.

MAKEPKG_LINT_PKGBUILD=0

Setting to 0 disables PKGBUILD linting within makepkg. Useful on systems with slow bash subshell operations, or on PKGBUILDs with extreme amounts of package splitting.

CONFIGURATION

See makepkg.conf(5) for more details on configuring makepkg using the makepkg.conf file.

ERRORS

On exit, makepkg will return one of the following error codes.

0

Normal exit condition.

1

Unknown cause of failure.

2

Error in configuration file.

3

User specified an invalid option.

4

Error in user-supplied function in PKGBUILD.

5

Failed to create a viable package.

6

A source or auxiliary file specified in the PKGBUILD is missing.

7

The PKGDIR is missing.

8

Failed to install dependencies.

9

Failed to remove dependencies.

10

User attempted to run makepkg as root.

11

User lacks permissions to build or install to a given location.

12

Error parsing PKGBUILD.

13

A package has already been built.

14

The package failed to install.

15

Programs necessary to run makepkg are missing.

16

Specified GPG key does not exist or failed to sign package.

17

The local repository is not a clone of the source repository specified in PKGBUILD.

SEE ALSO

makepkg.conf(5), PKGBUILD(5), pacman(8)

makepkg(8) - 2023-07-30 - Arch Linux

NAME

makepkg - Compila e instala paquetes de Arch Linux

SYNOPSIS

makepkg [options] [--] [file...]

DESCRIPTION

makepkg es una utilidad para compilar paquetes de Arch Linux. Lee la información de compilación de un archivo PKGBUILD, descarga las fuentes si es necesario, las compila y crea un paquete binario .pkg.tar.zst que puede ser instalado con Pacman.

OPTIONS

Las siguientes opciones están disponibles:

  • -A, --nodeps No instala ni comprueba las dependencias de los paquetes.

  • --skipinteg No comprueba las sumas de verificación y las firmas de los archivos de fuentes.

  • --skippgp No comprueba las firmas PGP de los archivos de fuentes.

  • --skipchecksums No comprueba las sumas de verificación de los archivos de fuentes.

  • --verifysource Verifica las sumas de verificación y las firmas PGP de los archivos de fuentes.

  • --skipconf No pide confirmación antes de instalar los archivos de configuración.

  • -c, --clean Limpia los archivos de compilación y las dependencias después de la compilación.

  • -s, --syncdeps Instala las dependencias de compilación necesarias usando Pacman.

  • -r, --rmdeps Elimina las dependencias de compilación después de la instalación del paquete.

  • -m, --nomake Omite el paso make y construye el paquete con lo que haya en el directorio de trabajo.

  • -f, --force Recompila el paquete incluso si ya existe un paquete binario con el mismo nombre y versión.

  • -o, --nobuild Solo descarga las fuentes y prepara el entorno de compilación. No compila el paquete.

  • -p, --printsrcinfo Muestra el archivo .SRCINFO generado.

  • --keyring keyring Especifica el keyring a usar para la verificación de firmas PGP.

  • --cachedir dir Especifica el directorio de caché para los paquetes de dependencias.

  • --log Registra la salida de la compilación en un archivo.

  • --noconfirm No pide confirmación para ninguna operación.

  • -h, --help Muestra la ayuda y sale.

  • -V, --version Muestra la información de la versión y sale.

ENVIRONMENT VARIABLES

Se pueden configurar las siguientes variables de entorno:

  • BUILDDIR: Especifica el directorio de trabajo para la compilación.

  • PKGDEST: Especifica el directorio de destino para los paquetes binarios.

  • SRCDIR: Especifica el directorio donde se descargarán las fuentes.

  • CHROOTFILTER: Filtra los directorios que se incluirán en el entorno chroot.

CONFIGURATION

La configuración de makepkg se encuentra en /etc/makepkg.conf. Los usuarios pueden personalizar esta configuración para adaptar el comportamiento de makepkg a sus necesidades.

ERRORS

Los errores comunes incluyen problemas de dependencias, fallos en la compilación, permisos incorrectos o errores en el archivo PKGBUILD.
