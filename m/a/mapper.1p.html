Paquete: dnssec-tools

NOMBRE

mapper - Crear mapas gráficos de datos de zona DNS

SINOPSIS

mapper [opciones] archivo_zona1 nombre_dominio1 ... archivo_zonaN nombre_dominioN

DESCRIPCIÓN

Esta aplicación crea un mapa gráfico de uno o más archivos de zona. La salida ofrece una representación gráfica de una o varias zonas DNS. La salida se escribe en formato PNG. El resultado puede ser útil para obtener una visión más intuitiva de una o varias zonas. Es extremadamente útil para visualizar la implementación de DNSSEC dentro de una zona dada, así como para ayudar a descubrir puntos problemáticos.

OPCIONES

-h
Muestra un resumen de ayuda.
-o ARCHIVO_SALIDA.png
Guarda los resultados en un nombre de archivo dado. Si no se proporciona esta opción, el mapa se guardará como map.png.
-r
Enumera los registros de recursos asignados a cada nodo dentro del mapa.
-t TIPO,TIPO...
Añade la porción de datos de un registro de recursos a la información del nodo mostrado. Los tipos de datos proporcionados se convertirán automáticamente a mayúsculas para facilitar su uso.

Ejemplo de uso: -t A añadirá direcciones IPv4 a todos los nodos mostrados que tengan registros A.

-L
Añade una leyenda al mapa.
-l (neato|dot|twopi|circo|fdp)
Selecciona un formato de diseño. El predeterminado es neato, que tiene un patrón circular. Consulte la documentación del paquete GraphViz y el módulo Perl GraphViz para obtener más detalles.
--node-size=(none|small)
Si el tamaño del mapa es demasiado grande, es posible reducir considerablemente el tamaño del nodo (y el texto) usando --node-size=small o eliminar completamente los círculos, dejando solo las flechas usando --node-size=none. Esto puede dar lugar a diagramas visuales mejores de conjuntos de nodos muy complejos, aunque se pierde todo el etiquetado.
-a
Permite la superposición de nodos. Esto crea mapas más compactos con el inconveniente de que están algo abarrotados. Los mapas de zonas extremadamente grandes serán difíciles de descifrar si no se utiliza esta opción.
-e PESO
Asigna un peso a los bordes. En teoría, >1 significa más corto y <1 significa más largo, aunque puede que no tenga ningún efecto tal como está implementado. Esto debería funcionar mejor en el futuro.
-f ENTERO
Utiliza el valor ENTERO para el tamaño de la fuente con el que se imprimen los nombres de los nodos. El valor predeterminado es 10.
-w TIEMPO_AVISO
Especifica con cuánta antelación se habilitan las advertencias de expiración para los registros de recursos firmados. El valor predeterminado es 7 días. El tiempo de advertencia se mide en segundos.
-i REGEX
Ignora los tipos de registros que coinciden con una expresión regular REGEX.
-s TIPO,TIPO...
Especifica una lista de tipos de registros que no se analizarán ni se mostrarán en el mapa. Por defecto, esto se establece en NSEC y CNAME para reducir el desorden. Si se establece en "", se mostrarán de nuevo estos resultados.
-T TIPO,TIPO...
Restringe los tipos de registros que se procesarán a los del tipo TIPO. Esto es lo contrario de la opción -s. No es significativo usar -s y -t en la misma invocación. Sin embargo, ambos funcionarán a la vez, por lo que si -T especifica un tipo que -s excluye, no se mostrará.
-g
Intenta agrupar nodos alrededor del nombre de dominio. Para los diseños "dot", esto significa realmente dibujar un cuadro alrededor del grupo. Para los otros tipos, hace muy poca diferencia, si es que la hace.
-q
Evita la salida de advertencias o errores sobre registros que tienen firmas DNSSEC que están cerca o más allá de sus tiempos de vida de firma.
--dump-styles
Muestra la configuración de estilo actual tanto para nodos como para bordes.
--node-style=FORMATOS
--edge-style=FORMATOS
Permite utilizar configuraciones de estilo específicas al dibujar nodos y bordes. Las especificaciones de formato principales están delimitadas por barras '/' y los pares dentro de estas están delimitados por dos puntos ':'. Se espera que el primer token en una lista de dos puntos sea el nombre del registro.

Por ejemplo, para que todos los registros de direcciones A aparezcan como un cuadro rojo y todos los registros MX como un triángulo, utilice esta especificación:

--node-style=A:shape=box:fillcolor=red/MX:shape=triangle

Ejecute mapper con --dump-styles para mostrar su configuración predeterminada y/o cómo la ha modificado si se han utilizado las opciones.

EJEMPLO DE INVOCACIONES

mapper -s cname,nsec -i dhcp -L archivo_zona zona.com
Escribe en el archivo predeterminado (map.png) de una zona zone.com almacenada en archivo_zona. Excluye cualquier host cuyo nombre contenga dhcp e ignora cualquier registro de tipo CNAME o NSEC. Se incluye una leyenda en la salida.
mapper -s txt,hinfo,cname,nsec,a,aaaa,mx,rrsig -L archivo_zona zona.com archivo_zona2 sub.zona.com ...
Elimina muchos registros de la visualización para mostrar principalmente un mapa de la jerarquía de zonas.
mapper -l dot -s txt,hinfo,cname,nsec,a,aaaa,mx,rrsig -L archivo_zona zona.com archivo_zona2 sub.zona.com ...
Igual que el ejemplo anterior, pero este comando dibuja un gráfico de estilo árbol más vertical de la zona. Esto funciona bien para jerarquías bastante profundas pero estrechas. Los diagramas de estilo árbol rara vez quedan tan bien para zonas completas.
