MALLOC(3P) Manual de Programador POSIX MALLOC(3P)

PROLOGO

Esta página del manual es parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

malloc — un asignador de memoria

SINOPSIS

#include <stdlib.h>
void *malloc(size_t tamaño);

DESCRIPCION

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función malloc() asignará espacio no utilizado para un objeto cuyo tamaño en bytes se especifica por tamaño y cuyo valor no se especifica.

El orden y la contigüidad del almacenamiento asignado por llamadas sucesivas a malloc() no se especifican. El puntero devuelto si la asignación tiene éxito estará debidamente alineado para que pueda asignarse a un puntero de cualquier tipo de objeto y luego usarse para acceder a dicho objeto en el espacio asignado (hasta que el espacio se libere o reasigne explícitamente). Cada asignación de este tipo producirá un puntero a un objeto separado de cualquier otro objeto. El puntero devuelto apunta al inicio (dirección de byte más baja) del espacio asignado. Si no se puede asignar el espacio, se devolverá un puntero nulo.

Si el tamaño del espacio solicitado es 0, el comportamiento depende de la implementación: o bien se devolverá un puntero nulo, o bien el comportamiento será como si el tamaño fuera algún valor distinto de cero, excepto que el comportamiento no está definido si se utiliza el puntero devuelto para acceder a un objeto.

VALOR DE RETORNO

Al completarse con éxito con tamaño distinto de 0, malloc() devolverá un puntero al espacio asignado. Si tamaño es 0, entonces:

*
Se devolverá un puntero nulo y errno puede establecerse a un valor definido por la implementación, o
*
Se devolverá un puntero al espacio asignado. La aplicación se asegurará de que el puntero no se utilice para acceder a un objeto.

De lo contrario, devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

La función malloc() fallará si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.
