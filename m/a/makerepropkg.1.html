NOMBRE

makerepropkg - Reconstruye un paquete para ver si es reproducible

SINOPSIS

makerepropkg [OPCIONES] [<archivo_paquete|nombre_paquete>...]

DESCRIPCIÓN

Dada la ruta a uno o más paquetes de pacman ya construidos, intenta reconstruirlos usando el PKGBUILD en el directorio actual. El paquete se construirá en un entorno lo más parecido posible al entorno del paquete inicial, construyendo un chroot para que coincida con la información expuesta en el manifiesto BUILDINFO(5) del paquete. En caso de éxito, el paquete resultante se comparará con el paquete de entrada, y makerepropkg informará si los artefactos son idénticos.

Cuando se especifican varios paquetes, se asume que los archivos de paquete adicionales son paquetes divididos y se tratarán como artefactos adicionales para comparar durante el paso de verificación.

Se puede especificar un objetivo válido para pacman -S en su lugar, y makerepropkg lo descargará a la caché si es necesario. Esto es útil principalmente para especificar desde qué repositorio recuperar. Si no se especifican argumentos posicionales, los objetivos se obtendrán del PKGBUILD.

En cualquier caso, el nombre del paquete se convertirá en un nombre de archivo desde la caché, y makerepropkg procederá como si este nombre de archivo se hubiera especificado inicialmente.

Esto implementa un verificador para paquetes de pacman/libalpm de acuerdo con el proyecto de Construcciones Reproducibles https://reproducible-builds.org/.

OPCIONES

-d

Si los paquetes no son reproducibles, compáralos usando diffoscope.

-n

No ejecute la función check() en el PKGBUILD.

-c

Establece el directorio de caché de pacman.

-M <archivo>

Ubicación de un archivo de configuración de makepkg. Se pueden colocar adiciones específicas (por ejemplo, flags de compilación para idiomas adicionales) en <archivo>.d/*.conf.

-l <chroot>

El nombre del directorio a usar como espacio de nombres chroot. Útil para mantener múltiples copias. Por defecto: $USER

-h

Mostrar este mensaje de uso

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools

Por favor, informa de errores y solicitudes de funciones en el rastreador de incidencias. Haz todo lo posible por proporcionar un caso de prueba reproducible para los errores.
