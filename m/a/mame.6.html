MAME(6) MAME - Marco de emulación multiusos MAME(6)

NOMBRE

MAME - Marco de emulación multiusos

SINOPSIS

mame [opciones] nombrejuego

DESCRIPCIÓN

Iniciado en 1997 por Nicola Salmoria, MAME se concibió originalmente como una serie de emuladores para juegos individuales, que luego se combinaron en un único emulador multijuego. En los años siguientes, MAME creció una y otra vez hasta su tamaño actual, con más de 100 colaboradores en el proyecto.

OPCIONES

Comandos principales

-ayuda, -?
Muestra la versión actual de MAME y el aviso de copyright.
-validar, -valid
Realiza una validación interna en cada controlador del sistema. Ejecuta esto antes de enviar cambios para asegurar que no has violado ninguna de las reglas principales del sistema.

Comandos de configuración

-crearconfig, -cc
Crea el archivo mame.ini predeterminado en el directorio actual. Todas las opciones de configuración (no comandos) descritas a continuación pueden cambiarse permanentemente editando este archivo de configuración.
-mostrarconfig, -sc
Muestra la configuración actual.
-mostraruso, -su
Muestra un resumen de todas las opciones de línea de comandos. Para las opciones que no se mencionan aquí, el breve resumen dado por -mostraruso suele ser suficiente.

Comandos del frontend

Todos los comandos de listado a continuación escriben información en la pantalla. Si deseas escribir la información en un archivo de texto en su lugar, usa redirección. Por ejemplo, mame -listxml > ~/mamelist.xml escribe la lista completa de juegos compatibles en el archivo mamelist.xml en tu directorio personal.

-listxml, -lx [nombrejuego|comodín]
Lista detalles completos para todos los juegos compatibles. La salida es bastante larga, por lo que generalmente es mejor redirigirla a un archivo. La salida está en formato XML. Por defecto, se listan todos los juegos; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -listxml.
-listfull, -ll [nombrejuego|comodín]
Muestra una lista de nombres de controladores de juegos y descripciones. Por defecto, se listan todos los juegos; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -listfull.
-listsource, -ls [nombrejuego|comodín]
Muestra una lista de controladores y los nombres de los archivos fuente en los que residen sus controladores de juego. Útil para encontrar en qué controlador se ejecuta un juego para corregir errores. Por defecto, se listan todos los juegos; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -listsource.
-listclones, -lc [nombrejuego|comodín]
Muestra una lista de clones. Por defecto, se listan todos los clones; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -listclones.
-listbrothers, -lb [nombrejuego|comodín]
Muestra una lista de "hermanos" u otros controladores del mismo archivo fuente. Por defecto, se listan todos los juegos; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -listbrothers.
-listcrc
Muestra una lista completa de las CRC de todas las imágenes ROM referenciadas por todos los controladores dentro del código de MAME.
-listroms, -lr nombrejuego
Muestra una lista de imágenes ROM referenciadas por el juego especificado.
-listsamples nombrejuego
Muestra una lista de muestras referenciadas por el juego especificado.
-verifyroms [nombrejuego|comodín]
Comprueba si hay imágenes ROM inválidas o faltantes. Por defecto, se verifican todos los controladores que tienen archivos ZIP o directorios válidos en la ruta de ROMs; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -verifyroms.
-verifysamples [nombrejuego|comodín]
Comprueba si hay muestras inválidas o faltantes. Por defecto, se verifican todos los controladores que tienen archivos ZIP o directorios válidos en la ruta de muestras; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín después del comando -verifyroms.
-romident
Intenta identificar archivos ROM, si son conocidos por MAME, en el archivo .zip o directorio especificado. Este comando se puede usar para intentar identificar conjuntos de ROM tomados de placas desconocidas. Al salir, el nivel de error se devuelve como uno de los siguientes:
0 todos los archivos fueron identificados
7 todos los archivos fueron identificados excepto algunos archivos "no ROM"
8 algunos archivos fueron identificados
9 ningún archivo fue identificado
-listdevices, -ld
Muestra la lista de dispositivos referenciados por un juego o conjunto de juegos dado.
-listslots, -lslot
Muestra la lista de ranuras y dispositivos de ranura disponibles para el sistema.
-listmedia, -lm
Muestra la lista de medios disponibles para el sistema.
-listsoftware, -lsoft
Muestra la lista de software conocido para el sistema.
-verifysoftware, -vsoft [nombrejuego|comodín]
Comprueba si hay imágenes ROM inválidas o faltantes en tus listas de software. Por defecto, se verifican todos los controladores que tienen archivos ZIP o directorios válidos en la ruta de ROMs; sin embargo, puedes limitar esta lista especificando un nombre de controlador o un comodín específico.
-getsoftlist, -glist
Recupera la lista de software por nombre.
-verifysoftlist, -vlist [nombredelalista]
Comprueba una lista de software especificada en busca de imágenes ROM faltantes si existen archivos para el nombre de lista de software emitido. Por defecto, se verifican todos los controladores que tienen archivos ZIP o directorios válidos en la ruta de ROMs; sin embargo, puedes limitar esta lista especificando un nombre de lista de software específico (sin .XML).
-listmidi, -mlist
Crea una lista de los dispositivos de E/S MIDI disponibles para su uso con la emulación.
-listnetwork, -nlist
Lista los adaptadores de red disponibles.

Opciones de configuración

-[no]readconfig, -[no]rc
Habilita o deshabilita la lectura de los archivos de configuración. Cuando está habilitado (lo cual es el valor predeterminado), MAME lee los siguientes archivos de configuración en orden:
1. mame.ini
el archivo de configuración principal
2. nombre.ini
donde nombre es el nombre de tu ejecutable, es decir, mame a menos que lo hayas cambiado (por ejemplo, si renombraste mame a mame0137, el archivo analizado será mame0137.ini)
3. debug.ini, si el depurador está habilitado
4. vector.ini, solo para juegos vectoriales
5. [controlador].ini
basado en el nombre del archivo fuente del controlador del juego
6. [padre].ini
solo para clones, puede ser llamado rec
Recursivamente
7. [nombrejuego].ini
ten en cuenta que a veces esto se resuelve con el nombre del controlador de origen
La configuración en los últimos ini anula la de los ini anteriores. Así, por ejemplo, si quisieras deshabilitar los efectos de superposición en los juegos vectoriales, puedes crear un archivo vector.ini con la línea "effect none" y anulará cualquier valor de efecto que tengas en tu mame.ini. El valor predeterminado es ON (-readconfig).
-[no]writeconfig, -[no]wc
Escribe la configuración en [driver].ini al salir. El valor predeterminado es OFF (-nowriteconfig).

Opciones de ruta de búsqueda

Ten cuidado de usar las opciones de ruta, directorio y archivo en mame.ini SOLO. De lo contrario, el resultado puede ser impredecible y no consistente entre versiones.

-rompath, -rp, -biospath, -bp nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar imágenes de ROM o discos duros. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'roms' (es decir, un directorio "roms" en el mismo directorio que el ejecutable de MAME).
-hashpath nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos hash de software. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'hash' (es decir, un directorio 'hash' en el mismo directorio que el ejecutable de MAME).
-samplepath, -sp nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de muestra. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'samples' (es decir, un directorio "samples" en el mismo directorio que el ejecutable de MAME).
-artpath, -artwork_directory nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de arte. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'artwork' (es decir, un directorio "artwork" en el mismo directorio que el ejecutable de MAME).
-ctrlrpath, -ctrlr_directory nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de configuración específicos del controlador. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'ctrlr' (es decir, un directorio "ctrlr" en el mismo directorio que el ejecutable de MAME).
-inipath nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos .INI. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es '/etc/mame/'.
-fontpath nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de fuente .BDF. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es '.' (es decir, buscar en el mismo directorio que el ejecutable de MAME).
-cheatpath nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de trucos. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'cheat' (es decir, un directorio 'cheat' en el mismo directorio que el ejecutable de MAME).
-crosshairpath nombre_ruta
Especifica una lista de rutas dentro de las cuales buscar archivos de mira. Se pueden especificar varias rutas separándolas con punto y coma. El valor predeterminado es 'crosshair' (es decir, un directorio "crosshair" en el mismo directorio que el ejecutable de MAME). Si la Mira se establece en predeterminada en el menú, MAME buscará gamenameross#.png y luego cross#.png en el crosshairpath especificado, donde # es el número de jugador. Si falla, MAME utilizará las miras predeterminadas integradas.
-pluginspath nombre_ruta
Especifica una única ruta dentro de la cual buscar plugins. El valor predeterminado es 'plugins' (es decir, un directorio 'plugins' en el mismo directorio que el ejecutable de MAME).
-languagepath nombre_ruta
Especifica una única ruta dentro de la cual buscar archivos de idioma. El valor predeterminado es 'language' (es decir, un directorio 'language' en el mismo directorio que el ejecutable de MAME).

Opciones de directorio de salida

-cfg_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos de configuración. Los archivos de configuración almacenan configuraciones configurables por el usuario que se leen al inicio y se escriben cuando MAME se cierra. El valor predeterminado es 'cfg' (es decir, un directorio "cfg" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-nvram_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos NVRAM. Los archivos NVRAM almacenan el contenido de la EEPROM y la RAM no volátil (NVRAM) para los juegos que utilizaron este tipo de hardware. Estos datos se leen al inicio y se escriben cuando MAME se cierra. El valor predeterminado es 'nvram' (es decir, un directorio "nvram" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-input_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos de grabación de entrada. Las grabaciones de entrada se crean a través de la opción -record y se reproducen a través de la opción -playback. El valor predeterminado es 'inp' (es decir, un directorio "inp" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-state_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos de estado guardado. Los archivos de estado guardado se leen y se escriben a solicitud del usuario, o cuando se utiliza la opción -autosave. El valor predeterminado es 'sta' (es decir, un directorio "sta" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-snapshot_directory nombre_ruta
Especifica un único directorio donde se almacenan las instantáneas de pantalla, cuando las solicita el usuario. El valor predeterminado es 'snap' (es decir, un directorio "snap" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-diff_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos de diferencias de disco duro. Los archivos de diferencias de disco duro almacenan cualquier dato que se escriba de vuelta en una imagen de disco duro, para preservar la imagen original. Los archivos de diferencias se crean al inicio cuando un juego tiene una imagen de disco duro. El valor predeterminado es 'diff' (es decir, un directorio "diff" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.
-comment_directory nombre_ruta
Especifica un único directorio donde se almacenan los archivos de comentarios del depurador. Los archivos de comentarios del depurador son escritos por el depurador cuando se agregan comentarios al desensamblaje de un juego. El valor predeterminado es 'comments' (es decir, un directorio "comments" en el mismo directorio que el ejecutable de MAME). Si este directorio no existe, se creará automáticamente.

Opciones de estado/reproducción

-state ranura
Inmediatamente después de iniciar el juego especificado, cargará el estado guardado en la ranura especificada.
-[no]autosave
Cuando está habilitado, crea automáticamente un archivo de estado guardado al salir de MAME e intenta recargarlo automáticamente al iniciar MAME más tarde con el mismo juego. Esto solo funciona para juegos que han habilitado explícitamente el soporte de estado guardado en su controlador. El valor predeterminado es OFF (-noautosave).
-playback, -pb nombre_archivo
Especifica un archivo desde el cual reproducir una serie de entradas del juego. Esta función no funciona de manera confiable para todos los juegos, pero se puede utilizar para ver una sesión de juego grabada previamente de principio a fin. Para que las cosas sean consistentes, solo debes grabar y reproducir con todos los archivos de configuración (.cfg), NVRAM (.nv) y tarjeta de memoria eliminados. El valor predeterminado es NULL (sin reproducción).
-[no]exit_after_playback
Si la reproducción está habilitada (ver opción -playback), el programa sale cuando se llega al final del archivo. De lo contrario, la máquina continuará ejecutándose. El valor predeterminado es OFF (-noexit_after_playback).
-record, -rec nombre_archivo
Especifica un archivo para grabar toda la entrada de una sesión de juego. Esto se puede utilizar para grabar una sesión de juego para su posterior reproducción. Esta función no funciona de manera confiable para todos los juegos, pero se puede utilizar para ver una sesión de juego grabada previamente de principio a fin. Para que las cosas sean consistentes, solo debes grabar y reproducir con todos los archivos de configuración (.cfg), NVRAM (.nv) y tarjeta de memoria eliminados. El valor predeterminado es NULL (sin grabación).
-[no]record_timecode
Especifica si se debe crear un archivo de código de tiempo. Contiene una línea con los tiempos transcurridos en cada pulsación de la tecla de acceso directo del código de tiempo (predeterminado es F12). Esta opción solo funciona cuando el modo de grabación está habilitado (opción -record). El archivo se guarda en la carpeta inp. El valor predeterminado es OFF (-norecord_timecode).
-mngwrite nombre_archivo
Escribe cada fotograma de video en el nombre_archivo dado en formato MNG, produciendo una animación de la sesión de juego. Ten en cuenta que -mngwrite solo escribe fotogramas de video; no guarda ningún dato de audio. Usa -wavwrite para eso, y vuelve a ensamblar el audio/video usando herramientas fuera de línea. El valor predeterminado es NULL (sin grabación).
-aviwrite nombre_archivo

Opciones de grabación de vídeo

-aviwrite nombre_archivo
Transmite datos de vídeo y sonido al nombre_archivo dado en formato AVI, produciendo una animación de la sesión de juego completa con sonido. El valor predeterminado es NULL (sin grabación).
-wavwrite nombre_archivo
Escribe la salida final del mezclador al nombre_archivo dado en formato WAV, produciendo una grabación de audio de la sesión de juego. El valor predeterminado es NULL (sin grabación).
-snapname cadena
Describe cómo MAME debe nombrar los archivos para las capturas de pantalla. cadena proporciona una plantilla que se utiliza para generar un nombre de archivo. Se proporcionan tres sustituciones simples: el carácter / representa el separador de ruta en cualquier plataforma de destino (incluso Windows); el literal %g representa el nombre del driver del juego actual; y el literal %i representa un índice incremental. Si se omite %i, cada captura de pantalla tomada sobrescribirá la anterior; de lo contrario, MAME encontrará el siguiente valor vacío para %i y lo usará para un nombre de archivo. El valor predeterminado es %g/%i, que crea una carpeta separada para cada juego y nombra las capturas de pantalla debajo de ella comenzando con 0000 y aumentando a partir de ahí. Ejemplo: si usas mame robby -snapname foo/%g%i, las capturas de pantalla se guardarán como snaps/foo/robby0000.png, snaps/foo/robby0001.png y así sucesivamente.
-snapsize anchoxalto
Codifica el tamaño de las capturas de pantalla y la grabación de películas. Por defecto, MAME creará capturas de pantalla con la resolución actual del juego en píxeles crudos, y creará películas con la resolución inicial del juego en píxeles crudos. Si especificas esta opción, MAME creará tanto capturas de pantalla como películas con el tamaño especificado, y aplicará un filtro bilineal al resultado. Ten en cuenta que este tamaño no rota automáticamente si el juego está orientado verticalmente. El valor predeterminado es 'auto'.
-snapview internal|auto|nombre_vista
Especifica la vista a utilizar al renderizar capturas de pantalla y películas. Por defecto, ambos utilizan una vista especial 'interna', que renderiza una captura de pantalla separada por pantalla o renderiza películas solo de la primera pantalla. Al especificar esta opción, puedes anular este comportamiento predeterminado y seleccionar una única vista que se aplicará a todas las capturas de pantalla y películas. Ten en cuenta que nombre_vista no necesita ser una coincidencia perfecta; más bien, seleccionará la primera vista cuyo nombre coincida con todos los caracteres especificados por nombre_vista. Por ejemplo, -snapview native coincidirá con la vista "Native (15:14)" aunque no sea una coincidencia perfecta. nombre_vista también puede ser 'auto', que selecciona la primera vista con todas las pantallas presentes. El valor predeterminado es 'internal'.
-[no]snapbilinear
Especifica si la captura de pantalla/película debe tener aplicado un filtro bilineal. El valor predeterminado está ACTIVADO (-snapbilinear).
-statename cadena
Describe cómo MAME debe almacenar los archivos de estado de guardado, en relación con la ruta state_directory. cadena proporciona una plantilla que se utiliza para generar una ruta relativa. Se proporcionan dos sustituciones simples: el carácter / representa el separador de ruta en cualquier plataforma de destino (incluso Windows); el literal %g representa el nombre del driver del juego actual. El valor predeterminado es '%g', que crea una carpeta separada para cada juego. Ejemplo: si usas mame robby -statename foo/%g, los estados de guardado se almacenarán dentro de sta/foo/robby/.
-[no]burnin
Realiza un seguimiento del brillo de la pantalla durante el juego y, al final de la emulación, genera un PNG que se puede utilizar para simular efectos de quemado en otros juegos. El PNG resultante se crea de tal manera que las áreas menos utilizadas de la pantalla son completamente blancas (ya que las áreas quemadas son más oscuras, todas las demás áreas de la pantalla deben aclararse un poco). La intención es que este PNG se pueda cargar a través de un archivo de arte con un alfa bajo (por ejemplo, 0.1-0.2 funciona bien) y se mezcle sobre toda la pantalla. Los archivos PNG se guardan en el directorio snap dentro de gamename\burnin-<screen.name>.png. El valor predeterminado está DESACTIVADO (-noburnin).

Opciones de rendimiento

-[no]autoframeskip, -[no]afs
Determina automáticamente el nivel de frameskip mientras juegas, ajustándolo constantemente en un intento frenético de mantener el juego funcionando a toda velocidad. Activar esta opción anula el valor que has establecido para -frameskip a continuación. El valor predeterminado está DESACTIVADO (-noautoframeskip).
-frameskip, -fs valor
Especifica el valor de frameskip (autoframeskip debe estar deshabilitado). Este es el número de fotogramas de cada 12 a omitir al ejecutarse. Por ejemplo, si dices -frameskip 2, MAME mostrará 10 de cada 12 fotogramas. Al omitir esos fotogramas, puedes obtener velocidad completa en un juego que requiere más potencia que la que tiene tu ordenador. El valor predeterminado es 0, que no omite ningún fotograma.
-seconds_to_run, -str valor
Esta opción se puede utilizar para benchmarking y pruebas automatizadas. Indica a MAME que deje de ejecutarse después de un número fijo de segundos. Al combinar esto con un conjunto fijo de otras opciones de línea de comandos, puedes configurar un entorno consistente para evaluar el rendimiento de MAME. Además, al salir, la opción -str escribirá una captura de pantalla llamada final.png en el directorio de capturas de pantalla del juego.
-[no]throttle
Configura la configuración de limitación de velocidad predeterminada. Cuando la limitación de velocidad está activada, MAME intenta mantener el juego funcionando a la velocidad prevista del juego. Cuando la limitación de velocidad está desactivada, MAME ejecuta el juego lo más rápido que puede. Ten en cuenta que la velocidad más rápida es casi siempre limitada por tu tarjeta gráfica, especialmente en juegos más antiguos. El valor predeterminado está ACTIVADO (-throttle).
-[no]sleep
Permite a MAME devolver tiempo al sistema cuando se ejecuta con -throttle. Esto permite que otros programas tengan tiempo de CPU, asumiendo que el juego no está utilizando el 100% de tus recursos de CPU. Esta opción puede causar problemas de rendimiento si se ejecutan otros programas exigentes. El valor predeterminado está ACTIVADO (-sleep).
-speed valor
Controla la velocidad del juego, en relación con el tiempo real; los números más pequeños son más lentos. El valor predeterminado es 1.00.
-[no]refreshspeed, -[no]rs
Ajusta automáticamente el parámetro -speed para mantener la tasa de refresco efectiva por debajo de la tasa de refresco de pantalla más baja. El valor predeterminado está DESACTIVADO (-norefreshspeed).
-numprocessors, -np valor
Establece el número de procesadores; esto anula el número que informa el sistema.
-bench valor
Evalúa el rendimiento durante el número dado de segundos emulados; implica -video none -sound none -nothrottle.
-[no]sdlvideofps
Muestra el rendimiento del vídeo SDL. El valor predeterminado está DESACTIVADO (-nosdlvideofps).

Opciones de rotación

-[no]rotate
Gira el juego para que coincida con su estado normal (horizontal/vertical). Esto asegura que los juegos orientados vertical y horizontalmente se muestren correctamente sin necesidad de girar tu monitor. Si deseas mantener el juego mostrando en 'crudo' en la pantalla tal como habría estado en la recreativa, desactiva esta opción. El valor predeterminado está ACTIVADO (-rotate).
-[no]ror | -[no]rol
Gira la pantalla del juego a la derecha (en sentido horario) o a la izquierda (en sentido anti- horario) en relación con su estado normal (si se especifica -rotate) o su estado nativo (si se especifica -norotate). El valor predeterminado para ambos es DESACTIVADO (-noror -norol).
-[no]autoror | -[no]autorol
Estas opciones están diseñadas para usarse con pantallas pivotantes que solo giran en una dirección. Si tu pantalla solo pivota en sentido horario, usa -autorol para asegurarte de que el juego llene la pantalla horizontal o verticalmente en una de las direcciones que puedes manejar. Si tu pantalla solo pivota en sentido antihorario, usa -autoror. El valor predeterminado para ambos es DESACTIVADO (-noautoror -noautorol).
-[no]flipx -[no]flipy
Invierte (refleja) la pantalla del juego horizontalmente (-flipx) o verticalmente (-flipy). Las inversiones se aplican después de que se apliquen las opciones -rotate y -ror/-rol. El valor predeterminado para ambos es DESACTIVADO (-noflipx -noflipy).

Opciones de arte

-[no]artwork_crop, -[no]artcrop
Activa el recorte del arte solo al área de la pantalla del juego. Esta opción también se puede controlar a través del menú Opciones de vídeo en la interfaz de usuario. El valor predeterminado está DESACTIVADO (-noartwork_crop).
-[no]use_backdrops, -[no]backdrop
Activa/desactiva la visualización de fondos. El valor predeterminado está ACTIVADO (-use_backdrops).
-[no]use_overlays, -[no]overlay
