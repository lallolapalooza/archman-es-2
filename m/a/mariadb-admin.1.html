MARIADB-ADMIN(1) Sistema de Base de Datos MariaDB MARIADB-ADMIN(1)

NOMBRE

mariadb-admin - cliente para administrar un servidor MariaDB

SINOPSIS

mariadb-admin [opciones] comando [arg-comando] [comando [arg-comando]] ...

DESCRIPCIÓN

mariadb-admin es un cliente para realizar operaciones administrativas. Puede usarlo para verificar la configuración y el estado actual del servidor, para crear y eliminar bases de datos, y más.

Invoque mariadb-admin de la siguiente manera:

shell> mariadb-admin [opciones] comando [arg-comando] [comando [arg-comando]] ...

mariadb-admin admite los siguientes comandos. Algunos de los comandos toman un argumento después del nombre del comando.

•create nombre-db

Crea una nueva base de datos llamada nombre-db.

•debug

Indica al servidor que escriba información de depuración en el archivo de registro de errores.

Esto también incluye información sobre el Planificador de Eventos.

•drop nombre-db

Elimina la base de datos llamada nombre-db y todas sus tablas.

•extended-status

Muestra las variables de estado del servidor y sus valores.

•flush-all-statistics

Borra todas las tablas de estadísticas.

•flush-all-status

Borra todas las estadísticas y el estado.

•flush-binary-log

Borra el registro binario.

•flush-client-statistics

Borra las estadísticas del cliente.

•flush-engine-log

Borra el registro del motor.

•flush-error-log

Borra el registro de errores.

•flush-general-log

Borra el registro de consultas generales.

•flush-hosts

Borra toda la información en la caché de hosts.

•flush-index-statistics

Borra las estadísticas de índices.

•flush-logs

Borra todos los registros.

•flush-privileges

Recarga las tablas de concesión (igual que reload).

•flush-relay-log

Borra el registro de retransmisión.

•flush-slow-log

Borra el registro de consultas lentas.

•flush-ssl

Borra los certificados SSL.

•flush-status

Borra las variables de estado.

•flush-table-statistics

Borra las estadísticas de tablas.

•flush-tables

Borra todas las tablas.

•flush-threads

Borra la caché de hilos.

•flush-user-resources

Borra los recursos de usuario.

•kill id,id,...

Termina hilos del servidor. Si se proporcionan varios IDs de hilo, no debe haber espacios en la lista.

•old-password nueva-contraseña

Esto es similar al comando password pero almacena la contraseña utilizando el formato de hash de contraseña antiguo (anterior a MySQL 4.1).

•password nueva-contraseña

Establece una nueva contraseña. Esto cambia la contraseña a nueva-contraseña para la cuenta que usa con mariadb-admin para conectarse al servidor. Por lo tanto, la próxima vez que invoque mariadb-admin (o cualquier otro programa cliente) utilizando la misma cuenta, necesitará especificar la nueva contraseña.

Si el valor nueva-contraseña contiene espacios u otros caracteres que son especiales para su intérprete de comandos, deberá encerrarlo entre comillas. En Windows, asegúrese de usar comillas dobles en lugar de comillas simples; las comillas simples no se eliminan de la contraseña, sino que se interpretan como parte de la contraseña. Por ejemplo:

shell> mariadb-admin password "mi nueva contraseña"

Precaución
No utilice este comando si el servidor se inició con la opción --skip-grant-tables. No se aplicará ningún cambio de contraseña. Esto es cierto incluso si precede al comando de contraseña con flush-privileges en la misma línea de comandos para volver a habilitar las tablas de concesión, ya que la operación de borrado ocurre después de que se conecta. Sin embargo, puede usar mariadb-admin flush-privileges para volver a habilitar la tabla de concesión y luego usar un comando mariadb-admin password separado para cambiar la contraseña.
•ping

Comprueba si el servidor está activo. El estado de retorno de mariadb-admin es 0 si el servidor está en ejecución, 1 si no lo está. Esto es 0 incluso en caso de un error como Acceso denegado, porque esto significa que el servidor está en ejecución pero rechazó la conexión, lo que es diferente de que el servidor no esté en ejecución.

•processlist

Muestra una lista de hilos activos del servidor. Esto es similar a la salida de la sentencia SHOW PROCESSLIST. Si se proporciona la opción --verbose, la salida es similar a la de SHOW FULL PROCESSLIST.

•reload

Recarga las tablas de concesión.

•refresh

Borra todas las tablas y cierra y abre los archivos de registro.

•shutdown

Detiene el servidor.

•start-all-slaves

Inicia todos los esclavos.

•start-slave

Inicia la replicación en un servidor esclavo.

•status

Muestra un breve mensaje de estado del servidor.

•stop-all-slaves

Detiene todos los esclavos.

•stop-slave

Detiene la replicación en un servidor esclavo.

•variables

Muestra las variables del sistema del servidor y sus valores.

•version

Muestra información de la versión del servidor.

Todos los comandos se pueden acortar a cualquier prefijo único. Por ejemplo:

shell> mariadb-admin proc stat
+----+-------+-----------+----+---------+------+-------+------------------+
| Id | User  | Host      | db | Command | Time | State | Info             |
+----+-------+-----------+----+---------+------+-------+------------------+
| 51 | monty | localhost |    | Query   | 0    |       | show processlist |
+----+-------+-----------+----+---------+------+-------+------------------+
Uptime: 1473624  Threads: 1  Questions: 39487
Slow queries: 0  Opens: 541  Flush tables: 1
Open tables: 19  Queries per second avg: 0.0268

El resultado del comando mariadb-admin status muestra los siguientes valores:

•Uptime

El número de segundos que el servidor MariaDB ha estado en ejecución.

•Threads

El número de hilos activos (clientes).

•Questions

El número de preguntas (consultas) de los clientes desde que se inició el servidor.

•Slow queries

El número de consultas que han tardado más de log_slow_query_time segundos.

•Opens

El número de tablas que el servidor ha abierto.

•Flush tables

El número de comandos flush-*, refresh y reload que el servidor ha ejecutado.

•Open tables

El número de tablas que están actualmente abiertas.

•Memory in use

La cantidad de memoria asignada directamente por mariadbd. Este valor solo se muestra cuando MariaDB ha sido compilado con --with-debug=full.

•Maximum memory used

La cantidad máxima de memoria asignada directamente por mariadbd. Este valor solo se muestra cuando MariaDB ha sido compilado con --with-debug=full.

Si ejecuta mariadb-admin shutdown al conectarse a un servidor local usando un archivo socket de Unix, mariadb-admin espera hasta que se elimine el archivo de ID de proceso del servidor, para garantizar que el servidor se ha detenido correctamente.

OPCIONES

Las opciones de línea de comandos se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-admin] y [client].

•--help, -?

Muestra la ayuda y sale.

•--character-sets-dir=ruta

El directorio donde se instalan los conjuntos de caracteres.

•--compress, -C

Comprime toda la información enviada entre el cliente y el servidor si ambos soportan la compresión.

•--connect-timeout=timeout

Equivalente a --connect_timeout, ver el final de esta sección.

•--count=N, -c N

El número de iteraciones a realizar para la ejecución repetida de comandos si se proporciona la opción --sleep.

•--debug[=debug_options], -# [debug_options]

Escribe un registro de depuración. Una cadena típica de debug_options es 'd:t:o,nombre_archivo'. El valor predeterminado es 'd:t:o,/tmp/mariadb-admin.trace'.

•--debug-check

Comprueba el uso de memoria y archivos abiertos al salir.

•--debug-info

Imprime información de depuración y estadísticas de uso de memoria y CPU cuando el programa sale.

•--default-auth

Plugin de autenticación predeterminado del lado del cliente a usar.

•--default-character-set=nombre_conjunto_caracteres

Utiliza nombre_conjunto_caracteres como conjunto de caracteres predeterminado.

•--defaults-extra-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas después de que se hayan leído los archivos de opciones globales predeterminadas. Debe especificarse como la primera opción.

•--defaults-file=nombre_archivo

Establece nombre_archivo como el archivo del que leer las opciones predeterminadas, anulando los archivos de opciones globales predeterminadas. Debe especificarse como la primera opción.

•--force, -f

No pide confirmación para el comando drop nombre_db. Con múltiples comandos, continúa incluso si ocurre un error.

•--host=nombre_host, -h nombre_host

Conéctate al servidor MariaDB en el host especificado.

•--local, -l

Suprime la escritura de los comandos SQL en el log binario usando FLUSH LOCAL o habilitando sql_log_bin=0 para la sesión.

•--no-beep, -b

Suprime el pitido de advertencia que se emite por defecto para errores como la falla al conectarse al servidor.

•--no-defaults

No lee opciones predeterminadas de ningún archivo de opciones. Esto debe especificarse como el primer argumento.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usa la forma corta de la opción (-p), no puede haber un espacio entre la opción y la contraseña. Si omite el valor contraseña después de la opción --password o -p en la línea de comandos, mariadb-admin le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro.

•--pipe, -W

En Windows, conéctese al servidor a través de una tubería con nombre. Esta opción solo se aplica si el servidor soporta conexiones por tubería con nombre.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar para la conexión o 0 para el valor predeterminado, en orden de preferencia: my.cnf, $MYSQL_TCP_PORT, /etc/services, valor predeterminado integrado (3306). Fuerza --protocol=tcp cuando se especifica en la línea de comandos sin otras propiedades de conexión.

•--print-defaults

Imprime la lista de argumentos del programa y sale. Esto debe especificarse como el primer argumento.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión causarían normalmente el uso de un protocolo distinto al que desea.

•--relative, -r

Muestra la diferencia entre los valores actuales y anteriores cuando se usa con la opción --sleep. Actualmente, esta opción solo funciona con el comando extended-status.

•--shutdown-timeouttimeout

Equivalente a --shutdown_timeout, ver el final de esta sección.

•--silent, -s

Sale silenciosamente si no se puede establecer una conexión con el servidor.

•--sleep=retraso, -i retraso

Ejecuta comandos repetidamente, durmiendo durante retraso segundos entre ellos. La opción --count determina el número de iteraciones. Si no se proporciona --count, mariadb-admin ejecuta comandos indefinidamente hasta que se interrumpe.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar. Fuerza --protocol=socket cuando se especifica en la línea de comandos sin otras propiedades de conexión; en Windows, fuerza --protocol=pipe.

•--ssl

Habilita SSL para la conexión (activado automáticamente con otras banderas). Deshabilítalo con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a usar (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consultar la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Common Name" (Nombre Común) del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--tls-version=nombre,

Acepta una lista separada por comas de versiones de protocolo TLS. Una versión de protocolo TLS solo se habilitará si está presente en esta lista. Todas las demás versiones de protocolo TLS no estarán permitidas.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a usar al conectarse al servidor.

•--verbose, -v

Modo detallado. Imprime más información sobre lo que hace el programa.

•--version, -V

Muestra información de la versión y sale.

•--vertical, -E

Imprime la salida verticalmente. Esto es similar a --relative, pero imprime la salida verticalmente.

•--wait[=contador], -w[contador]

Si la conexión no se puede establecer, espera y reintenta en lugar de abortar. Si se proporciona un valor de contador, indica el número de veces que se reintentará. El valor predeterminado es una vez.

•--wait-for-all-slaves

Espera a que el último evento binlog sea enviado a todas las réplicas conectadas antes de apagar. Esta opción está deshabilitada por defecto.

También puedes establecer las siguientes variables usando --nombre_var=valor

•connect_timeout

El número máximo de segundos antes de que expire el tiempo de espera de la conexión. El valor predeterminado es 43200 (12 horas).

•shutdown_timeout

El número máximo de segundos para esperar el apagado del servidor. El valor predeterminado es 3600 (1 hora).
