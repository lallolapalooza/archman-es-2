mattrib - cambia las etiquetas de atributos de archivos MSDOS

Nota de advertencia

Descripción

Mattrib se utiliza para cambiar los bits de atributos de archivos MS-DOS. Tiene la siguiente sintaxis:

mattrib [-a|+a] [-h|+h] [-r|+r] [-s|+s] [-/] [-p] [-X] archivo_msdos [ archivos_msdos ... ]

Mattrib añade bits de atributo a un archivo MS-DOS (con el operador `+') o elimina bits de atributo (con el operador `-').

Mattrib soporta los siguientes bits de atributo:

a 
Bit de archivo. Usado por algunos programas de copia de seguridad para indicar un nuevo archivo.
r 
Bit de solo lectura. Usado para indicar un archivo de solo lectura. Los archivos con este bit activado no pueden ser borrados por DEL ni modificados.
s 
Bit de sistema. Usado por MS-DOS para indicar un archivo del sistema operativo.
h 
Bit oculto. Usado para hacer que los archivos sean ocultos para DIR.

Mattrib soporta las siguientes opciones de línea de comandos:

/ 
Recursivo. Lista recursivamente los atributos de los archivos en los subdirectorios.
X 
Conciso. Imprime los atributos sin ningún relleno de espacio en blanco. Si no se proporciona la opción "/" ni el archivo_msdos contiene un comodín, y solo hay un parámetro de archivo MS-DOS en la línea de comandos, solo se imprime el atributo y no el nombre del archivo. Esta opción es conveniente para scripts.
p 
Modo de repetición. Genera una serie de comandos mformat que reproducirán la situación actual, a partir de una situación tal como queda tras descomprimir el sistema de archivos MS-DOS. Los comandos solo se generan para configuraciones de atributos que difieren de los valores predeterminados (bit de archivo activado para archivos, desactivado para directorios). Esta opción está pensada para ser usada además de tar. El atributo readonly no se tiene en cuenta, ya que tar puede establecerlo él mismo.

Para generar una copia imprimible a partir de la documentación texinfo, ejecute los siguientes comandos: 
    ./configure; make dvi; dvips mtools.dvi

*   
Para generar una copia html, ejecute: 
    ./configure; make html

*   
Para generar una copia info (navegable con el modo info de emacs), ejecute: 
    ./configure; make info

La documentación texinfo se ve más bonita cuando se imprime o en formato html. De hecho, en la versión info, algunos ejemplos son difíciles de leer debido a las convenciones de citas utilizadas en info.
