NOMBRE

makeg - crear un ejecutable depurable

SINOPSIS

makeg [ opciones-de-make ... ] [ objetivos ... ]

DESCRIPCIÓN

El script makeg ejecuta make, pasándole ajustes de variables para crear un objetivo depurable cuando se utiliza con un Makefile generado por imake. Por ejemplo, se encarga de que el compilador C sea llamado con la opción -g.

ENTORNO

MAKE
El programa make a usar. Por defecto ``make''.
GDB
Establecido en un valor no nulo si se usa el depurador gdb en Solaris 2, lo cual requiere pasar opciones de depuración adicionales al compilador.

VER TAMBIÉN

make (1), imake (1)
