MARIADB-FIX-EXTENSIONS(1) Sistema de Base de Datos MariaDB MARIADB-FIX-EXTENSIONS(1)

NOMBRE

mariadb-fix-extensions - normaliza las extensiones de nombres de archivos de tablas (mariadb-fix-extensions es ahora un enlace simbólico a mariadb-fix-extensions)

SINOPSIS

mariadb-fix-extensions directorio_datos

DESCRIPCIÓN

Este script está obsoleto y será eliminado en una versión posterior.

mariadb-fix-extensions convierte las extensiones de los archivos de tablas MyISAM (o ISAM) a sus formas canónicas. Busca archivos con extensiones que coincidan con cualquier variante de mayúsculas/minúsculas de .frm, .myd, .myi, .isd e .ism y los renombra para que tengan las extensiones .frm, .MYD, .MYI, .ISD y .ISM, respectivamente. Esto puede ser útil después de transferir los archivos desde un sistema con nombres de archivo que no distinguen entre mayúsculas y minúsculas (como Windows) a un sistema con nombres de archivo que sí distinguen entre mayúsculas y minúsculas.

Invoque mariadb-fix-extensions de esta manera, donde directorio_datos es la ruta al directorio de datos de MariaDB.

shell> mariadb-fix-extensions directorio_datos
