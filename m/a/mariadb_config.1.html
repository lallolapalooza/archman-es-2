NOMBRE

mariadb-dump - obtener opciones de compilación para compilar clientes

SINOPSIS

mariadb-dump opciones

DESCRIPCIÓN

mariadb-dump le proporciona información útil para compilar su cliente MariaDB y conectarlo a MariaDB.

mariadb-dump admite las siguientes opciones.

•--cflags

Opciones del compilador para encontrar archivos de inclusión y opciones críticas del compilador y defines utilizados al compilar la biblioteca libmysqlclient. Las opciones devueltas están ligadas al compilador específico que se utilizó cuando se creó la biblioteca y podrían entrar en conflicto con la configuración de su propio compilador. Utilice --include para opciones más portátiles que solo contienen rutas de inclusión.

•--include

Opciones del compilador para encontrar archivos de inclusión de MariaDB.

•--libmysqld-libs, --embedded

Bibliotecas y opciones necesarias para enlazar con el servidor incrustado de MariaDB.

•--libs

Bibliotecas y opciones necesarias para enlazar con la biblioteca cliente de MariaDB.

•--libs_r

Bibliotecas y opciones necesarias para enlazar con la biblioteca cliente de MariaDB segura para hilos.

•--plugindir

El nombre de ruta del directorio de plugins predeterminado, definido al configurar MariaDB.

•--port

El número de puerto TCP/IP predeterminado, definido al configurar MariaDB.

•--socket

El archivo de socket Unix predeterminado, definido al configurar MariaDB.

•--variable=VAR

Ruta a los directorios de inclusión, bibliotecas y plugins de MariaDB. VAR es uno de `pkgincludedir`, `pkglibdir` y `plugindir`, respectivamente.

•--version

Número de versión de la distribución MariaDB.

Si invoca mariadb-dump sin opciones, muestra una lista de todas las opciones que admite y sus valores:

shell> mariadb-dump
Usage: /usr/local/mysql/bin/mariadb-dump [options]
Options:
  --cflags         [-I/usr/local/mysql/include/mysql -mcpu=pentiumpro]
  --include        [-I/usr/local/mysql/include/mysql]
  --libs           [-L/usr/local/mysql/lib/mysql -lmysqlclient -lz
                    -lcrypt -lnsl -lm -L/usr/lib -lssl -lcrypto]
  --libs_r         [-L/usr/local/mysql/lib/mysql -lmysqlclient_r
                    -lpthread -lz -lcrypt -lnsl -lm -lpthread]
  --socket         [/tmp/mysql.sock]
  --port           [3306]
  --version        [4.0.16]
  --libmysqld-libs [-L/usr/local/mysql/lib/mysql -lmysqld -lpthread -lz
                    -lcrypt -lnsl -lm -lpthread -lrt]

Puede utilizar mariadb-dump en una línea de comandos para incluir el valor que muestra para una opción particular. Por ejemplo, para compilar un programa cliente de MariaDB, utilice mariadb-dump de la siguiente manera:

shell> CFG=/usr/local/mysql/bin/mariadb-dump
shell> sh -c "gcc -o progname `$CFG --include` progname.c `$CFG --libs`"

Cuando utilice mariadb-dump de esta manera, asegúrese de invocarlo entre comillas invertidas (“`”). Eso indica al shell que lo ejecute y sustituya su salida en el comando que lo rodea.
