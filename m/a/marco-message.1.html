MARCO-MESSAGE(1) Manual de comandos generales MARCO-MESSAGE(1)

NOMBRE

marco-message - Un comando para enviar mensajes a Marco.

SINOPSIS

marco-message [OPCIONES]

DESCRIPCIÓN

El comando marco-message se utiliza para realizar algunas tareas sencillas del gestor de ventanas mientras Marco está en ejecución.

OPCIONES

reiniciar
Reinicia una instancia en ejecución de marco.
recargar-tema
Recarga el tema de bordes de ventana actual especificado en la base de datos dconf. (/org/mate/marco/general/theme)
habilitar-atajos
Habilita todos los atajos de teclado especificados en la base de datos dconf. (/org/mate/marco/)
deshabilitar-atajos
Deshabilita todos los atajos de teclado especificados en la base de datos dconf. (/org/mate/marco/)
conmutar-verboso
Habilita o deshabilita los mensajes de depuración para marco.
