NOMBRE

makeglossaries - Llama a makeindex/xindy para documentos LaTeX que usan el paquete glossaries

SINOPSIS

makeglossaries [-o archivo] [-q] [-Q] [-k] [-n] [-s archivo] [-t archivo] [-L idioma] [-c] [-g] [-l] [-p num] [-r] [-d dir aux] [-m archivo] [-x archivo] [-e] [--version] [--help] nombrebase

DESCRIPCIÓN

makeglossaries está diseñado para su uso con documentos LaTeX que utilizan el paquete glossaries. El argumento obligatorio nombrebase debe ser el nombre del documento LaTeX sin la extensión .tex. makeglossaries leerá el archivo auxiliar para determinar si se debe llamar a makeindex o xindy. Toda la información necesaria para pasar a la aplicación de indexación relevante también debe estar contenida en el archivo auxiliar, pero puede ser anulada por los argumentos de opción para makeglossaries.

OPCIONES

-e
No intentes reparar múltiples encapsulaciones o números de página ilegales (solo makeindex).
-c
Comprime los espacios intermedios (solo makeindex).
-d dir aux
Especifica el directorio donde se encuentran los archivos .aux, .glo, etc. Por defecto, es el directorio padre del archivo base nombrearchivo.
-g
Emplea ordenación de palabras alemana (solo makeindex).
-k
No intentes bifurcar con redirección canalizada. (Reduce el efecto de -q)
-l
Ordenación por letras.
-L idioma
Esta opción solo tiene efecto si se llama a xindy. Establece el idioma. Consulta la documentación de xindy para más detalles.
-m archivo
Especifica la ruta completa para que makeindex use el archivo archivo en caso de que makeindex no esté en la ruta del sistema operativo.
-n
Imprime los comandos que normalmente se ejecutarían pero no los ejecuta.
-o archivo
Usa archivo como archivo de salida. (Solo adecuado para documentos que contienen un solo glosario, de lo contrario, cada glosario se sobrescribirá).
-p num
Establece el número de página inicial a ser num (solo makeindex).
-q
Modo silencioso. Reduce la verbosidad a la salida estándar.
-Q
Silencia advertencias sobre la imposibilidad de bifurcar.
-r
Deshabilita la formación implícita de rangos de páginas (solo makeindex).
-s archivo
Usa archivo como archivo de estilo. Ten en cuenta que si usas esta opción, necesitas saber si se llamará a makeindex o xindy, ya que tienen diferentes archivos de estilo.
-t archivo
Usa archivo como archivo de transcripción.
-x archivo
Especifica la ruta completa para que xindy use el archivo archivo en caso de que xindy no esté en la ruta del sistema operativo.
--version
Imprime el número de versión y sale.
--help
Imprime el mensaje de ayuda y sale.

REQUIERE

Perl, Getopt::Std, y makeindex o xindy (dependiendo de las opciones del paquete glossaries).
