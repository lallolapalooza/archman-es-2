NOMBRE

marbling - Patrones similares a mármol o nubes.

SINOPSIS

marbling [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id number] [--delay number] [--scale number] [--iterations number] [--fps]

DESCRIPCIÓN

Esto genera un campo aleatorio con Ruido Perlin, luego lo permuta con Ruido Fractal Browniano para crear imágenes que se asemejan de alguna manera a nubes, o a las vetas del mármol, dependiendo de los parámetros seleccionados y los colores elegidos.

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--delay número
Retardo por fotograma, en microsegundos. Predeterminado: 10000 (0.01 segundos).
--scale número
Escala. 1 - 30. Predeterminado: 10.
--iterations número
Complejidad. 1 - 20. Predeterminado: 5.
--fps | --no-fps
Si se muestra o no una visualización de fotogramas por segundo en la parte inferior de la pantalla.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
