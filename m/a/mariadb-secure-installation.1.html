MARIADB-SECURE-INSTALLATION(1) Sistema de bases de datos MariaDB MARIADB-SECURE-INSTALLATION(1)

NOMBRE

mariadb-secure-installation - mejora la seguridad de la instalación de MariaDB (mariadb-secure-installation es ahora un enlace simbólico a mariadb-secure-installation)

SINOPSIS

mariadb-secure-installation

DESCRIPCIÓN

Este programa le permite mejorar la seguridad de su instalación de MariaDB de las siguientes maneras:

•Puede establecer una contraseña para las cuentas root.
•Puede eliminar las cuentas root que sean accesibles desde fuera del host local.
•Puede eliminar las cuentas de usuario anónimo.
•Puede eliminar la base de datos de prueba, que por defecto es accesible por usuarios anónimos.

mariadb-secure-installation puede invocarse sin argumentos:

shell> mariadb-secure-installation

El script le pedirá que determine qué acciones realizar.

mariadb-secure-installation acepta algunas opciones:

•--basedir=nombre_directorio

Directorio base.

•--defaults-extra-file=nombre_archivo

Archivo de opciones adicional.

•--defaults-file=nombre_archivo

Archivo de opciones.

•--no-defaults

No leer ningún archivo de configuración predeterminada.

Otras opciones no reconocidas se pasarán al servidor.
