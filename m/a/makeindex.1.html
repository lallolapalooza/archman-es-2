NOMBRE

makeindex - un procesador de índices de propósito general, independiente del formateador

SINOPSIS

makeindex [-c] [-g] [-i] [-l] [-o ind] [-p num] [-q] [-r] [-s sfile] [-t log] [-L] [-T] [idx0 idx1 idx2...]

DESCRIPCIÓN

El programa makeindex es un generador de índices jerárquicos de propósito general; acepta uno o más archivos de entrada (a menudo producidos por un formateador de texto como TeX (tex(1L)) o troff(1), ordena las entradas y produce un archivo de salida que puede ser formateado. El índice puede tener hasta tres niveles (0, 1 y 2) de anidamiento de subelementos. La forma en que las palabras son marcadas para indexar dentro del documento principal es específica del formateador utilizado; makeindex *no* automatiza el proceso de selección de estas palabras. Dado que el índice de salida es jerárquico, makeindex puede considerarse complementario al sistema make.index(1L) basado en awk(1) de Bentley y Kernighan, que es específico de troff(1), genera índices no jerárquicos y emplea una sintaxis mucho más simple para indicar las entradas del índice. Para ver ejemplos de uso con troff y TeX, consulte la sección EJEMPLOS a continuación.

Los formatos de los archivos de entrada y salida se especifican en un archivo de estilo; por defecto, se asume que la entrada es un archivo .idx, tal como lo genera LaTeX.

A menos que se especifique explícitamente, el nombre base del primer archivo de entrada (idx0) se utiliza para determinar los nombres de otros archivos. Para cada nombre de archivo de entrada especificado, se busca un archivo con ese nombre. Si no se encuentra este archivo y el nombre del archivo no tiene extensión, se le añade la extensión .idx. Si no se encuentra ningún archivo con este nombre, makeindex aborta.

Si solo se proporcionó un archivo de entrada y no se especificó ningún archivo de estilo explícito usando -s, makeindex utiliza un archivo con la extensión .mst como archivo de estilo por defecto (si está presente).

Para notas importantes sobre cómo seleccionar palabras clave de índice, consulte el documento de Lamport citado a continuación. Como cuestión separada de la selección de palabras clave de índice, se sugiere un mecanismo sistemático para colocar términos de índice en un documento en Index Preparation and Processing, un artículo citado a continuación.

OPCIONES

-c
Comprime los espacios intermedios (ignorando los espacios y tabulaciones iniciales y finales). Por defecto, los espacios en la clave del índice se conservan.
-g
Emplea el orden de palabras alemán de acuerdo con las reglas establecidas en DIN 5007. Por defecto, makeindex emplea un orden de palabras en el que la precedencia es: símbolos, números, letras mayúsculas, letras minúsculas. La secuencia en el orden de palabras alemán es: símbolos, letras minúsculas, letras mayúsculas, números. Además, esta opción permite a makeindex reconocer los comandos TeX alemanes {"a, "o, "u y "s} como {ae, oe, ue y ss} durante la ordenación de las entradas. El carácter de comillas debe ser redefinido en un archivo de estilo (por ejemplo, redefine quote como '+'). Si el carácter de comillas no se redefine, makeindex producirá un mensaje de error y abortará.
-i
Lee la entrada desde stdin. Cuando se especifica esta opción y no se usa -o, la salida se escribe en stdout.
-l
Ordenación por letras; por defecto, se utiliza la ordenación por palabras (ver la sección ORDENACIÓN).
-o ind
Utiliza ind como el archivo de índice de salida. Por defecto, el nombre del archivo se crea añadiendo la extensión .ind al nombre base del primer archivo de entrada (idx0).
-p num
Establece el número de página de inicio del archivo de índice de salida a num (útil cuando el archivo de índice se va a formatear por separado). El argumento num puede ser numérico o una de las siguientes opciones:
any
La página de inicio es el último número de página fuente más 1.
odd
La página de inicio es la primera página impar después del último número de página fuente.
even
La página de inicio es la primera página par después del último número de página fuente.
El último número de página fuente se obtiene buscando hacia atrás en el archivo de registro la primera aparición de un número incluido entre corchetes ([...]). Si falta un número de página o no se encuentra el archivo de registro, no se intentará establecer el número de página de inicio. El nombre del archivo de registro fuente se determina añadiendo la extensión .log al nombre base del primer archivo de entrada (idx0).
-q
Modo silencioso; no enviar mensajes a stderr. Por defecto, los mensajes de progreso y error se envían a stderr así como al archivo de transcripción.
-r
Desactiva la formación implícita de rangos de páginas; los rangos de páginas deben crearse utilizando operadores de rango explícitos; ver EFECTOS ESPECIALES a continuación. Por defecto, tres o más páginas sucesivas se abrevian automáticamente como un rango (por ejemplo, 1—5).
-s sty
Utiliza sty como archivo de estilo (sin valor por defecto). La variable de entorno INDEXSTYLE define la ruta donde se debe encontrar el archivo de estilo.
-t log
Utiliza log como archivo de transcripción. Por defecto, el nombre del archivo se crea añadiendo la extensión .ilg al nombre base del primer archivo de entrada (idx0).
-L
ordenar según la configuración regional. No disponible en todos los sistemas.
-T
soporte especial para documentos tailandeses. No disponible en todos los sistemas.

ARCHIVO DE ESTILO

El archivo de estilo informa a makeindex sobre el formato de los archivos de entrada .idx y el formato deseado del archivo de salida final; los ejemplos aparecen a continuación. Este archivo puede residir en cualquier lugar de la ruta definida por la variable de entorno INDEXSTYLE. El archivo de estilo contiene una lista de pares de <especificador, atributo>. Hay dos tipos de especificadores: entrada y salida. Los pares no tienen que aparecer en ningún orden particular. Una línea iniciada por `%` es un comentario. En la siguiente lista de especificadores y atributos, <string> es una cadena arbitraria delimitada por comillas dobles ("..."), <char> es una sola letra entre comillas simples ('...'), y <number> es un entero no negativo. La longitud máxima de un <string> es 2048. Una barra invertida literal o una comilla deben ser escapadas (con una barra invertida). A cualquier cosa no especificada en el archivo de estilo se le asignará un valor por defecto, que se muestra al principio de la columna más a la derecha.

EJEMPLOS

EJEMPLO DE TeX

El siguiente ejemplo muestra un archivo de estilo llamado book.ist, que define un índice para un libro que puede formatearse independientemente de la fuente principal:

preamble
"\\documentstyle[12pt]{book}
\\begin{document}
\\begin{theindex}
{\\small
"postamble
"\n\n}
\\end{theindex}
\\end{document}
"

Suponiendo que un estilo de libro particular requiere que el índice (así como cualquier capítulo) comience en un número de página impar, y que el archivo de entrada se llama foo.idx, la siguiente línea de comandos produce la salida en el archivo footmp.ind:

makeindex -s book.ist -o footmp.ind -p odd foo

Aquí se utiliza un nombre de archivo de salida no predeterminado para evitar sobrescribir la salida del libro en sí (¡presumiblemente foo.dvi, que habría sido el nombre predeterminado para el archivo de salida del índice!).

CREACIÓN DEL ARCHIVO DE ÍNDICE EN EL SHELL DE BOURNE

Para crear un archivo de entrada para makeindex, en el entorno del shell de Bourne, haga el equivalente en su sitio del comando:

psroff -ms -Tpsc -t sample.txt > /dev/null 2> sample.tmp

Algunos sitios requerirán ditroff en lugar de psroff. Para filtrar cualquier mensaje de error genuino, invoque grep(1):

grep '^IX: ' sample.tmp > sample.idx

CREACIÓN DEL ARCHIVO DE ÍNDICE USANDO EL ENHANCED TROFF/TRANSCRIPT DE UCSF

Con el Enhanced troff/TRANSCRIPT de UCSF, la opción -I de psroff(1L) puede producir tanto la salida del formateador como un archivo de índice:

psroff -ms -I sample.inp -Tpsc sample.txt

Si se desea suprimir la salida del formateador:

psroff -ms -I sample.inp -Tpsc -t sample.txt > /dev/null

COMPLETANDO EL ÍNDICE

Cualquiera de los procedimientos anteriores deja la entrada para makeindex en sample.inp. El siguiente paso es invocar makeindex:

makeindex -s sample.ist sample.idx

Esto deja la salida lista para troff(1) en el archivo sample.ind.

ORDENACIÓN

Por defecto, makeindex asume ordenación por palabra; si la opción -l está activa, se usa ordenación por letra. En la ordenación por palabra, un espacio precede a cualquier letra del alfabeto, mientras que en la ordenación por letra, no cuenta en absoluto. Esto se ilustra con el siguiente ejemplo:

orden por palabra orden por letra
sea lion seal
seal sea lion

Los números siempre se ordenan numéricamente. Por ejemplo,

9 (nueve), 123
10 (diez), ver Derek, Bo

Las letras se ordenan primero sin tener en cuenta las mayúsculas; cuando las palabras son idénticas, la versión en mayúsculas precede a su contraparte en minúsculas.

Se define aquí un símbolo especial para ser cualquier carácter que no aparezca en la unión de dígitos y caracteres alfabéticos ingleses. Los patrones que comienzan con símbolos especiales preceden a los números, que preceden a los patrones que comienzan con letras. Como caso especial, una cadena que comienza con un dígito pero mezclada con no dígitos se considera un patrón que comienza con un carácter especial.

EFECTOS ESPECIALES

Entradas como

\indexentry{alpha}{1}
\indexentry{alpha!beta}{3}
\indexentry{alpha!beta!gamma}{10}

en el archivo de entrada se convertirán en

\item alpha, 1
    \subitem beta, 3
        \subsubitem gamma, 10

en el archivo de índice de salida. Observe que el símbolo de nivel ('!') se usa arriba para delimitar los niveles jerárquicos.

Es posible hacer que un elemento aparezca en una forma designada usando el operador actual ('@'). Por ejemplo,

\indexentry{alpha@{\it alpha\/}}{1}

se convertirá en

\item {\it alpha\/}, 1

después del procesamiento. El patrón que precede a '@' se usa como clave de ordenación, mientras que el que le sigue se escribe en el archivo de salida. Tenga en cuenta que dos apariciones de la misma clave, una con y otra sin el operador actual, se consideran entradas distintas.

Los campos de elemento, subelemento y subsubelemento pueden tener claves de ordenación individuales:

\indexentry{aa@{\it aa\/}!bb@{\it bb\/}!cc@{\it cc\/}}{1}

Esto se convertirá en

\item {\it aa}, 1
    \subitem {\it bb}, 3
        \subsubitem {\it cc}, 10

Es posible encapsular un número de página con un comando designado usando el operador encap ('|'):

\indexentry{alpha|bold}{1}

se convertirá en

\item alpha, \bold{1}

donde, con una definición adecuada para TeX, \bold{n} se expandirá a {\bf n}. En este ejemplo, los tres atributos de salida asociados con la encapsulación de página encap_prefix, encap_infix y encap_suffix, corresponden a la barra invertida, la llave de apertura y la llave de cierre, respectivamente. Este mecanismo permite que los números de página se establezcan en diferentes fuentes. Por ejemplo, la página donde aparece la definición de una palabra clave puede estar en una fuente, la ubicación de un ejemplo principal puede estar en otra fuente, y otras apariciones en una tercera fuente.

El operador encap también se puede usar para crear referencias cruzadas en el índice:

\indexentry{alpha|see{beta}}{1}

se convertirá en

\item alpha, \see{beta}{1}

en el archivo de salida, donde

\see{beta}{1}

se expandirá a

{\it see\/} beta

Tenga en cuenta que en una referencia cruzada como esta, el número de página desaparece.

Un par de encap concatenado con range_open ('|(') y range_close ('|)') crea un rango de páginas explícito:

\indexentry{alpha|(}{1}
\indexentry{alpha|)}{5}

se convertirá en

\item alpha, 1—5

Las páginas intermedias indexadas con la misma clave se fusionarán implícitamente en el rango. Esto es especialmente útil cuando se va a indexar una sección completa sobre un tema particular, en cuyo caso solo se necesitan insertar los operadores de apertura y cierre de rango al principio y al final de la sección. La formación explícita de rangos de páginas también puede incluir un comando adicional para establecer el rango de páginas en una fuente designada:

\indexentry{alpha|(bold}{1}
\indexentry{alpha|)}{5}

se convertirá en

\item alpha, \bold{1--5}

Vale la pena mencionar varios problemas potenciales. Primero, entradas como

\indexentry{alpha|(}{1}
\indexentry{alpha|bold}{3}
\indexentry{alpha|)}{5}

se interpretarán como

\item alpha, \bold{3}, 1--5

pero con un mensaje de advertencia en la transcripción sobre la recepción de un encapsulador de página inconsistente. Un rango explícito que comienza con un número de página romano y termina en arábigo también se considera un error. En este caso, (si es posible) el rango se divide en dos subrangos, uno en romano y el otro en arábigo. Por ejemplo,

\indexentry{alpha|(}{i}
\indexentry{alpha}{iv}
\indexentry{alpha}{3}
\indexentry{alpha|)}{7}

se convertirá en

\item alpha, i--iv, 3--7

EFECTOS ESPECIALES

Con una advertencia en el archivo de transcripción quejándose de una formación de rango ilegal.

Cada símbolo especial mencionado en esta sección puede ser escapado por el operador quote (`"). Así

\indexentry{alpha"@beta}{1}

se convertirá realmente en

\item alpha@beta, 1

como resultado de la ejecución de makeindex. El poder de cita de quote se elimina si está inmediatamente precedido por escape (\). Por ejemplo,

\indexentry{f\"ur}{1}

se convierte en

\item f\"ur, 1

lo que representa una "u" acentuada con diéresis para la familia de procesadores TeX.

Un número de página puede ser una composición de uno o más campos separados por el delimitador enlazado a page_compositor (-), por ejemplo, II-12 para la página 12 del Capítulo II. Los números de página pueden contener hasta diez campos.

Desde la versión 2.11 de makeindex, el operador quote puede citar cualquier carácter en el rango 1 ... 255. El carácter 0 está excluido porque se utiliza internamente en el código fuente de makeindex como terminador de cadena. Con este cambio, se pueden crear claves de ordenación para todos los caracteres de ocho bits excepto el 0. El orden de ordenación es

caracteres de puntuación (en orden ASCII),
dígitos,
caracteres de control (1 ... 31),
espacio (32),
letras (ignorando mayúsculas y minúsculas),
caracteres 127 ... 255.
Aquí hay un ejemplo que muestra la indexación de todos los caracteres ASCII imprimibles distintos de letras y dígitos, asumiendo el formato TeX predeterminado. Para mayor comodidad, las referencias de los números de página son los valores ordinales ASCII correspondientes. 
\indexentry{" @"  (espacio)}{32}

Los caracteres en los campos reales después del carácter `@' que tienen un significado especial para TeX deben representarse como secuencias de control o como caracteres de modo matemático. Tenga en cuenta especialmente cómo se codifican las entradas para la arroba, las llaves izquierda y derecha, y la barra vertical.
