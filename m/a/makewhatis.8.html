MAKEWHATIS(8) Manual del Administrador del Sistema MAKEWHATIS(8)

NOMBRE

makewhatis — index de manuales de UNIX

SINOPSIS

makewhatis [-aDnpQ] [-T utf8] [-C archivo]

makewhatis [-aDnpQ] [-T utf8] directorio ...

makewhatis [-DnpQ] [-T utf8] -d directorio [archivo ...]

makewhatis [-Dnp] [-T utf8] -u directorio [archivo ...]

makewhatis [-DQ] -t archivo ...

DESCRIPCIÓN

La utilidad makewhatis extrae palabras clave de los manuales de UNIX y las indexa en una base de datos para su rápida recuperación por apropos(1), whatis(1) y la opción -k de man(1).

Por defecto, makewhatis crea una base de datos en cada directorio utilizando los archivos mansección/[arquitectura/]título.sección y catsección/[arquitectura/]título.0 en ese directorio. Las bases de datos existentes son reemplazadas. Si un directorio no contiene páginas de manual, no se crea ninguna base de datos en ese directorio. Si no se proporciona directorio, makewhatis utiliza las rutas por defecto estipuladas por man.conf(5).

Los argumentos son los siguientes:

-a
Utiliza todos los directorios y archivos encontrados debajo de directorio...
-C archivo
Especifica un archivo de configuración alternativo archivo en formato man.conf(5).
-D
Muestra todos los archivos añadidos o eliminados del índice. Con una segunda -D, también muestra todas las palabras clave añadidas para cada archivo.
-d directorio
Fusiona (elimina y vuelve a añadir) archivo... a la base de datos en directorio.
-n
No crea ni modifica ninguna base de datos; solo escanea y analiza, e imprime los nombres y descripciones de las páginas de manual a la salida estándar.
-p
Imprime advertencias sobre posibles problemas con las páginas de manual a la salida de error estándar.
-Q
Construye rápidamente bases de datos de tamaño reducido leyendo solo las secciones NAME de los manuales. Las bases de datos resultantes normalmente contendrán solo nombres y descripciones.
-T utf8
Utiliza la codificación UTF-8 en lugar de ASCII para las cadenas almacenadas en las bases de datos.
-t archivo ...
Comprueba los archivos dados en busca de posibles problemas. Implica -a, -n y -p. Todos los mensajes de diagnóstico se imprimen a la salida estándar; la salida de error estándar no se utiliza.
-u directorio
Elimina archivo... de la base de datos en directorio. Si esto hace que la base de datos quede vacía, también elimina el archivo de base de datos.

Si se encuentran errores de análisis fatales durante el análisis, se imprime el archivo infractor en stderr, se omite del índice y el análisis continúa con el siguiente archivo de entrada.

ENTORNO

MANPATH
Una lista de directorios separados por dos puntos para crear bases de datos en. Se ignora si se especifica un argumento de directorio o la opción -t.

ARCHIVOS

mandoc.db
Una base de datos de manpages relativa al directorio del archivo. Este archivo es portable entre arquitecturas y sistemas, siempre que la jerarquía de manpages que indexa no cambie.
/etc/man.conf
El archivo de configuración por defecto de man(1).

ESTADO DE SALIDA

La utilidad makewhatis sale con uno de los siguientes valores:

0
No ocurrieron errores.
5
Se especificaron argumentos de línea de comandos inválidos. No se han leído archivos de entrada.
6
Ocurrió un error del sistema operativo, por ejemplo, agotamiento de memoria o un error al acceder a los archivos de entrada. Tales errores hacen que makewhatis salga inmediatamente, posiblemente en medio del análisis o formateo de un archivo. Las bases de datos de salida están corruptas y deben eliminarse.

VER TAMBIÉN

apropos(1), man(1), whatis(1), man.conf(5)

HISTORIA

Una utilidad makewhatis apareció por primera vez en 2BSD. Fue reescrita en perl(1) para OpenBSD 2.7 y en C para OpenBSD 5.6.

El argumento directorio apareció por primera vez en NetBSD 1.0; las opciones -dpt en OpenBSD 2.7; la opción -u en OpenBSD 3.4; y las opciones -aCDnQT en OpenBSD 5.6.

AUTORES

Bill Joy escribió la makewhatis original de BSD en febrero de 1979, Marc Espie comenzó la versión de Perl en 2000, y la versión actual de makewhatis fue escrita por Kristaps Dzonsons <kristaps@bsd.lv> y Ingo Schwarze <schwarze@openbsd.org>.
