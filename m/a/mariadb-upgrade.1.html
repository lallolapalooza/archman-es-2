MARIADB-UPGRADE(1) Sistema de bases de datos MariaDB MARIADB-UPGRADE(1)

NOMBRE

mariadb-upgrade - verifica tablas para la actualización de MariaDB (mariadb-upgrade es ahora un enlace simbólico a mariadb-upgrade)

SINOPSIS

mariadb-upgrade [opciones]

DESCRIPCIÓN

mariadb-upgrade examina todas las tablas de todas las bases de datos en busca de incompatibilidades con la versión actual del Servidor MariaDB. mariadb-upgrade también actualiza las tablas del sistema para que pueda aprovechar los nuevos privilegios o capacidades que se hayan añadido.

Se debe ejecutar mariadb-upgrade cada vez que se actualice MariaDB.

Si se encuentra una tabla con una posible incompatibilidad, mariadb-upgrade realiza una verificación de tablas. Si se encuentran problemas, se intenta una reparación de la tabla.


Nota

En Windows Server 2008 y Windows Vista, debe ejecutar mariadb-upgrade con privilegios de administrador. Puede hacerlo ejecutando un Símbolo del sistema como Administrador y ejecutando el comando. Si no lo hace, la actualización podría no ejecutarse correctamente.


Precaución

Siempre debe hacer una copia de seguridad de su instalación actual de MariaDB antes de realizar una actualización.

Para usar mariadb-upgrade, asegúrese de que el servidor esté en ejecución e invóquelo de la siguiente manera:

shell> mariadb-upgrade [opciones]

Después de ejecutar mariadb-upgrade, detenga el servidor y vuelva a iniciarlo para que los cambios realizados en las tablas del sistema surtan efecto.

mariadb-upgrade ejecuta los siguientes comandos para verificar y reparar tablas y para actualizar las tablas del sistema:

mariadb-check --all-databases --check-upgrade --auto-repair
mariadb < fix_priv_tables
mariadb-check --all-databases --check-upgrade --fix-db-names --fix-table-names

Notas sobre los comandos anteriores:

•Dado que mariadb-upgrade invoca a mariadb-check con la opción --all-databases, procesa todas las tablas de todas las bases de datos, lo que puede llevar mucho tiempo. Cada tabla se bloquea y, por lo tanto, no está disponible para otras sesiones mientras se procesa. Las operaciones de verificación y reparación pueden consumir tiempo, especialmente para tablas grandes.
•Para obtener detalles sobre las verificaciones que implica la opción --check-upgrade, consulte la descripción de la opción FOR UPGRADE de la sentencia CHECK TABLE.
•fix_priv_tables representa un script generado internamente por mariadb-upgrade que contiene sentencias SQL para actualizar las tablas de la base de datos mysql.

Todas las tablas verificadas y reparadas se marcan con el número de versión actual de MariaDB. Esto garantiza que la próxima vez que ejecute mariadb-upgrade con la misma versión del servidor, pueda saber si hay alguna necesidad de verificar o reparar la tabla nuevamente.

mariadb-upgrade también guarda el número de versión de MariaDB en un archivo llamado mariadb-upgrade_info en el directorio de datos. Esto se utiliza para verificar rápidamente si todas las tablas se han verificado para esta versión, de modo que se puedan omitir las verificaciones de tablas. Para ignorar este archivo y realizar la verificación independientemente, use la opción --force.

Por esta razón, mariadb-upgrade necesita ejecutarse como un usuario con acceso de escritura al directorio de datos.

Si instala MariaDB desde paquetes RPM en Linux, debe instalar los RPM del servidor y del cliente. mariadb-upgrade está incluido en el RPM del servidor, pero requiere el RPM del cliente porque este último incluye mariadb-check.

mariadb-upgrade admite las siguientes opciones, que se pueden especificar en la línea de comandos o en los grupos de archivos de opciones [mariadb-upgrade] y [client]. Otras opciones se pasan a mariadb-check. Por ejemplo, puede ser necesario especificar la opción --password[=contraseña]. mariadb-upgrade también admite las opciones para procesar archivos de opciones.

•--help, -?

Muestra un breve mensaje de ayuda y sale.

•--basedir=ruta

Opción antigua aceptada por compatibilidad hacia atrás pero ignorada.

•--character-sets-dir=ruta

Opción antigua aceptada por compatibilidad hacia atrás pero ignorada.

•--check-if-upgrade-is-needed

Sale con un código de estado que indica si se necesita una actualización. Devuelve 0 si se necesita actualizar o si no se pudo determinar la versión actual, 1 cuando no se requiere ninguna acción.

•--datadir=ruta

Opción antigua aceptada por compatibilidad hacia atrás pero ignorada.

•--debug=ruta, -# ruta

Para compilaciones de depuración, genera un registro de depuración.

•--debug-check

Imprime información de depuración al salir del programa.

•--debug-info, -T

Imprime información de depuración y estadísticas de uso de memoria y CPU al salir del programa.

•--default-character-set=nombre

Opción antigua aceptada por compatibilidad hacia atrás pero ignorada.

•--force

Ignora el archivo mariadb-upgrade_info y fuerza la ejecución de mariadb-check incluso si mariadb-upgrade ya se ha ejecutado para la versión actual de MariaDB.

•--host

Conéctate a MariaDB en el host dado.

•--password[=contraseña], -p[contraseña]

La contraseña a usar al conectarse al servidor. Si usa la forma corta de la opción (-p), no puede haber un espacio entre la opción y la contraseña. Si omite el valor contraseña después de la opción --password o -p en la línea de comandos, mariadb-upgrade le pedirá una.

Especificar una contraseña en la línea de comandos debe considerarse inseguro. Puede usar un archivo de opciones para evitar dar la contraseña en la línea de comandos.

•--port=num_puerto, -P num_puerto

El número de puerto TCP/IP a usar para la conexión.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

El protocolo de conexión a usar para conectarse al servidor. Es útil cuando los otros parámetros de conexión normalmente provocarían el uso de un protocolo diferente al que desea.

•--silent

Imprime menos información.

•--socket=ruta, -S ruta

Para conexiones a localhost, el archivo de socket Unix a usar, o, en Windows, el nombre de la tubería con nombre a usar.

•--ssl

Habilita SSL para la conexión (habilitado automáticamente con otras banderas). Deshabilita con --skip-ssl.

•--ssl-ca=nombre

Archivo CA en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-capath=nombre

Directorio CA (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cert=nombre

Certificado X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-cipher=nombre

Cifrado SSL a usar (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-key=nombre

Clave X509 en formato PEM (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crl=nombre

Lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-crlpath=nombre

Ruta de la lista de revocación de certificados (consulte la documentación de OpenSSL, implica --ssl).

•--ssl-verify-server-cert

Verifica el "Nombre Común" del servidor en su certificado contra el nombre de host utilizado al conectarse. Esta opción está deshabilitada por defecto.

•--tmpdir=ruta, -t ruta

El nombre de la ruta del directorio a usar para crear archivos temporales.

•--upgrade-system-tables, -s

Actualiza las tablas del sistema de MariaDB (por ejemplo, las tablas de privilegios) para que sean compatibles con la versión actual del servidor.

•--verbose, -v

Modo detallado. Imprime información sobre qué hace el programa.

•--version, -V

Muestra la información de la versión y sale.

•--vertical, -E

Imprime la salida en formato vertical (una columna).

VER TAMBIÉN

OPTIONS

•--check, -c

Comprueba las tablas de la base de datos. No realiza ningún cambio.

•--databases

Sólo actualiza las tablas de la base de datos especificada. Las tablas en otras bases de datos no se comprueban ni se modifican.

•--help, -?

Muestra un mensaje de ayuda y sale.

•--init-file=archivo

Lee comandos de inicialización de este archivo.

•--login-path=nombre

Lee opciones de conexión de un archivo de configuración de cliente en la ruta especificada. Véase también la sección de opciones de [mclient(1)] sobre rutas de inicio de sesión.

•--prompt, -p

Sólo actualiza las tablas de la base de datos mysql. Las tablas en otras bases de datos no se comprueban ni se tocan.

•--user=nombre_usuario, -u nombre_usuario

El nombre de usuario de MariaDB a utilizar al conectarse al servidor y no usar el inicio de sesión actual.

•--verbose

Muestra más información sobre el proceso. Usarlo dos veces imprimirá los argumentos de conexión; usarlo 3 veces imprimirá todos los comandos CHECK, RENAME y ALTER TABLE utilizados durante la fase de comprobación; usarlo 4 veces (añadido en MariaDB 10.0.14) también escribirá todos los comandos mariadb-check utilizados; usarlo 5 veces imprimirá todos los comandos mariadb utilizados y sus resultados mientras se ejecuta el script mariadb-fix-privilege-tables.

•--version, -V

Muestra la información de la versión y sale.

•--version-check, -k

Ejecuta este programa sólo si su 'versión del servidor' coincide con la versión del servidor al que se está conectando. Nota: la 'versión del servidor' del programa es la versión del servidor MariaDB con la que fue compilado/distribuido. Por defecto está activado; utiliza --skip-version-check para desactivarlo.

•--write-binlog

Causa que el registro binario se habilite mientras se ejecuta mariadb-upgrade.
