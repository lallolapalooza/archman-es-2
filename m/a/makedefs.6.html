MAKEDEFS(6) Manual de Juegos MAKEDEFS(6)

NOMBRE

makedefs - Funciones diversas de compilación de NetHack

SINOPSIS

makedefs { -o | -d | -e | -m | -v | -p | -q | -r | -h | -z }

makedefs --entrada archivo --salida archivo --comando

DESCRIPCIÓN

Makedefs es una herramienta de compilación utilizada para una variedad de tareas de creación y modificación de archivos fuente de NetHack(6). Por razones históricas, makedefs acepta dos tipos de líneas de comando. Cuando se invoca con una opción corta, los archivos que se operan se determinan cuando se compila makedefs. Cuando se invoca con una opción larga, las opciones --entrada y --salida se utilizan para especificar los archivos para el --comando. Cada comando solo está disponible en uno de los dos formatos.

COMANDOS CORTOS

Se aceptan tanto mayúsculas como minúsculas para los comandos cortos.

-o
Genera onames.h.
-d
Genera data.base.
-e
Genera dungeon.pdf. El archivo de entrada dungeon.def se procesa a través de la misma lógica que la utilizada por el comando --grep; consulte la sección FUNCIONES MDGREP a continuación para obtener más detalles.
-m
Genera monster.c.
-v
Genera date.h y el archivo options. Leerá dat/gitinfo.txt, solo si está presente, para obtener información de githash= y gitbranch=
e incluirá las definiciones preprocesador relacionadas #defines en el archivo date.h.
-p
Genera pm.h
-q
Genera quest.dat.
-r
Genera el archivo rumors.
-s
Genera los archivos bogusmon, engrave y epitaph.
-h
Genera el archivo oracles.
-z
Genera vis_tab.c y vis_tab.h.

COMANDOS LARGOS

--debug
Muestra la salida de depuración.
--make [comando]
Ejecuta un comando corto. El comando se proporciona sin el guion previo.
--entrada archivo
Especifica el archivo de entrada para el comando (si es necesario). Si el archivo es -, se lee la entrada estándar.
--salida archivo
Especifica el archivo de salida para el comando (si es necesario). Si el archivo es -, se escribe la salida estándar.
--svs [delimitador]
Genera una cadena de versión en la salida estándar sin un salto de línea final. Si se especifica, el delimitador se utiliza entre cada parte de la cadena de versión.
--grep
Filtra el archivo de entrada al archivo de salida. Consulte la sección FUNCIONES MDGREP a continuación para obtener información sobre cómo controlar la operación de filtrado.
--grep-showvars
Muestra el nombre y el valor de cada variable conocida para la opción grep.
--grep-trace
Activa el rastreo de depuración para la función grep (debe especificarse también --grep).
--grep-define simbolo
Fuerza que el valor de simbolo sea "definido." Simbolo debe ser conocido previamente por makedefs.
--grep-undef simbolo
Fuerza que la definición de simbolo sea "indefinida." Simbolo debe ser conocido previamente por makedefs.

FUNCIONES MDGREP

El comando --grep (y otros comandos) filtran su entrada, línea por línea, según las líneas de control incrustadas en la entrada y la información obtenida de la configuración de NetHack(6). Esto permite realizar ciertos cambios, como incrustar documentación específica de la plataforma en los archivos maestros de documentación.

Reglas:

-
El estado condicional predeterminado es impresión habilitada.
-
Cualquier línea *NO* que comience con un signo de intercalación (^) se suprime o se pasa sin cambios según el estado condicional actual.
-
Cualquier línea que comience con un signo de intercalación es una línea de control; como en C, se pueden incrustar cero o más espacios en la línea casi en cualquier lugar (excepto inmediatamente después del signo de intercalación); sin embargo, el signo de intercalación debe estar en la columna 1.
-
Las condicionales pueden anidarse.
-
Makedefs saldrá con un código de error si se detectan errores; el procesamiento continuará (si puede) para permitir la detección de tantos errores como sea posible.
-
Los identificadores desconocidos se tratan como VERDADERO y como un error. Tenga en cuenta que --undef o #undef en la configuración de NetHack(6) son diferentes de desconocido.

Líneas de control:

^^
una línea que comienza con un signo de intercalación literal (único)
^#
un comentario
^?ID
si el ID está definido, establece el estado condicional a VERDADERO
^!ID
si el ID no está definido, establece el estado condicional a VERDADERO
^:
de lo contrario; invierte el estado condicional
^.
termina la condicional más reciente

mdgrep(1)

NAME

mdgrep - pattern searching program for Mesa documentation

SYNOPSIS

mdgrep [OPTION]... PATTERN [FILE]...

DESCRIPTION

mdgrep searches input files for lines containing a match to a given PATTERN. This program is a wrapper around the standard grep command, specifically tailored for searching within the Mesa documentation files. It provides some predefined options and behaviors suitable for this purpose.

OPTIONS

mdgrep accepts most of the standard grep options. Additionally, it has the following options:

--mesa-docs
Search only within files located in the Mesa documentation directory.
--source-code
Search only within Mesa source code files.
-H, --with-filename
Print the filename for each input file. This is the default if multiple files are specified.
-n, --line-number
Prefix each line of output with the 1-based line number within its input file.
-i, --ignore-case
Ignore case distinctions in patterns and input data.
-r, --recursive
Read all files under each directory, recursively. Note that if no file name is specified, mdgrep will start searching from the current directory.
-w, --word-regexp
Select only those lines containing matches that form whole words.
--help
Display a help message and exit.
--version
Output version information and exit.

For a complete list of options, please refer to the grep manual page (man grep).

EXAMPLES

Search for the string "vertex shader" in all documentation files in the Mesa docs directory, ignoring case: 

mdgrep -i --mesa-docs "vertex shader"

Search recursively for lines containing "glGenTextures" in the Mesa source code: 

mdgrep -r --source-code "glGenTextures"

Find lines containing the whole word "texture" in a specific documentation file: 

mdgrep -w "texture" /usr/share/doc/mesa/api/texture.txt

MDGREP FUNCTIONS

mdgrep essentially acts as a convenient frontend to grep. It constructs the appropriate grep command based on the provided arguments, potentially adding default paths for Mesa documentation or source code if --mesa-docs or --source-code options are used.
