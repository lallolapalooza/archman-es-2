MCDIFF(1) GNU Midnight Commander MCDIFF(1)

NOMBRE

mcdiff - Visor de diferencias interno de GNU Midnight Commander.

USO

mcdiff [-bcCdfhstVx?] archivo1 archivo2

DESCRIPCIÓN

mcdiff es un enlace a mc, el ejecutable principal de GNU Midnight Commander. Ejecutar GNU Midnight Commander con este nombre solicita iniciar el visor de diferencias interno que compara archivo1 y archivo2 especificados en la línea de comandos.

OPCIONES

-b
Forzar visualización en blanco y negro.
-c
Forzar el modo de color en terminales donde mcdiff utiliza blanco y negro por defecto.
-C <palabra_clave>=<color_delantera>,<color_de_fondo>,<atributos>:<palabra_clave>= ...
Especificar un conjunto de colores diferente. Ver la sección Colores en mc(1) para más información.
-d
Desactivar el soporte del ratón.
-f
Mostrar las rutas de búsqueda compiladas para los archivos de Midnight Commander.
-t
Usado solo si el código fue compilado con S-Lang y terminfo: hace que Midnight Commander use el valor de la variable TERMCAP para la información de la terminal en lugar de la información de la base de datos de terminales del sistema.
-V
Muestra la versión del programa.
-x
Forzar el modo xterm. Se usa al ejecutar en terminales compatibles con xterm (dos modos de pantalla y capaces de enviar secuencias de escape del ratón).

COLORES

Los colores por defecto se pueden cambiar añadiendo a la variable de entorno MC_COLOR_TABLE. Los pares de colores de primer plano y fondo pueden especificarse, por ejemplo, con:

MC_COLOR_TABLE="$MC_COLOR_TABLE:\
normal=lightgray,black:\
selected=black,green"

ARCHIVOS

/usr/share/mc/mc.hlp

El archivo de ayuda del programa.

/usr/share/mc/mc.ini

La configuración por defecto a nivel de sistema para GNU Midnight Commander, usada solo si el archivo ~/.config/mc/ini del usuario no existe.

/usr/share/mc/mc.lib

Configuraciones globales para Midnight Commander. Las configuraciones en este archivo afectan a todos los usuarios, tengan o no ~/.config/mc/ini.

~/.config/mc/ini

Configuración propia del usuario. Si este archivo está presente, la configuración se carga desde aquí en lugar del archivo de inicio a nivel de sistema.
