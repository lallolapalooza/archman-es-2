NOMBRE

mcedit - Editor de archivos interno de GNU Midnight Commander.

SINOPSIS

mcedit [-bcCdfhstVx?] [+número_línea] [archivo1] [archivo2] ...

mcedit [-bcCdfhstVx?] archivo1:número_línea[:] archivo2:número_línea[:] ...

DESCRIPCIÓN

mcedit es un enlace a mc, el ejecutable principal de GNU Midnight Commander. Ejecutar GNU Midnight Commander con este nombre inicia el editor interno y abre los archivos especificados en la línea de comandos. El editor se basa en la versión de terminal de cooledit, un editor independiente para el sistema X Window.

OPCIONES

+número_línea
Ir a la línea especificada por el número (no deje un espacio entre el signo + y el número). Se permiten varios números de línea, pero solo se utilizará el último, y se aplicará solo al primer archivo.
-b
Forzar visualización en blanco y negro.
-c
Forzar modo de color ANSI en terminales que no parecen tener soporte de color.
-C <palabra_clave>=<color_texto>,<color_fondo>,<atributos>:<palabra_clave>= ...
Especificar un conjunto de colores diferente. Consulte la sección Colores en mc(1) para obtener más información.
-d
Desactivar el soporte del ratón.
-f
Mostrar la ruta de búsqueda compilada para los archivos de datos de GNU Midnight Commander.
-t
Forzar el uso de la base de datos termcap en lugar de terminfo. Esta opción solo es aplicable si GNU Midnight Commander fue compilado con la biblioteca S-Lang con soporte para terminfo.
-V
Mostrar la versión del programa.
-x
Forzar modo xterm. Se utiliza al ejecutarse en terminales compatibles con xterm (dos modos de pantalla y capacidad de enviar secuencias de escape de ratón).

CARACTERÍSTICAS

El editor de archivos interno es un editor de ventanas con todas las funciones. Puede editar varios archivos a la vez. El tamaño máximo de cada archivo es de 64 megabytes. Es posible editar archivos binarios. Las características que soporta actualmente son: copiar, mover, eliminar, cortar, pegar bloques; deshacer tecla por tecla; menús desplegables; inserción de archivos; comandos macro; búsqueda y reemplazo con expresiones regulares; resaltado de texto con las teclas de flecha y Shift (si es compatible con la terminal); alternancia entre inserción/sobrescritura; autoindenta ción; tamaño de tabulación configurable; resaltado de sintaxis para varios tipos de archivos; y una opción para canalizar bloques de texto a través de comandos del shell como indent e ispell.

Cada archivo se abre en su propia ventana en modo de pantalla completa. El control de ventanas en mcedit es similar al control de ventanas en otros programas multitarea: doble clic en el título de la ventana maximiza la ventana a pantalla completa o restaura su tamaño y posición; clic izquierdo en el título de la ventana y arrastrar con el ratón mueve la ventana en el área del editor; clic izquierdo en la esquina inferior derecha del marco y arrastrar con el ratón redimensiona la ventana. Estas acciones se pueden realizar utilizando el menú "Ventana".

TECLAS

El editor es fácil de usar y se puede utilizar sin necesidad de aprenderlo. El menú desplegable se invoca presionando F9. Puede aprender otras teclas desde el menú y desde las etiquetas de la barra de botones.

Además de eso, Shift combinado con las flechas realiza el resaltado de texto (si es compatible con la terminal): Ctrl-Ins copia al archivo ~/.cache/mc/mcedit/mcedit.clip, Shift-Ins pega desde ~/.cache/mc/mcedit/mcedit.clip, Shift-Del corta a ~/.cache/mc/mcedit/mcedit.clip, y Ctrl-Del elimina el texto resaltado. El resaltado con el ratón también funciona en algunas terminales. Para usar el soporte estándar del ratón proporcionado por su terminal, mantenga presionada la tecla Shift. Tenga en cuenta que el soporte del ratón en la terminal no comparte el portapapeles con mcedit.

La tecla de autocompletar (generalmente Meta-Tab o Escape Tab) completa la palabra bajo el cursor utilizando las palabras utilizadas en el archivo.

MACRO

Para definir una macro, presione Ctrl-R y luego escriba las teclas que desea que se ejecuten. Presione Ctrl-R nuevamente cuando termine. La macro se puede asignar a cualquier tecla presionando esa tecla. La macro se ejecuta cuando presiona la tecla asignada.

Los comandos macro se almacenan en la sección [editor] del archivo ~/.local/share/mc/mc.macros.

Los scripts externos (filtros) se pueden asignar a cualquier tecla modificando mc.macros de la siguiente manera:

[editor]
ctrl-W=ExecuteScript:25;

Esto significa que la tecla ctrl-W inicia la acción ExecuteScript(25), luego el manejador del editor lo traduce a la ejecución del script de shell ~/.local/share/mc/mcedit/macros.d/macro.25.sh.

Los scripts externos se almacenan en el directorio ~/.local/share/mc/mcedit/macros.d/ y deben nombrarse como macro.XXXX.sh, donde XXXX es un número de 0 a 9999. Vea **Menú de Edición Archivo** para más detalles sobre el formato del script.

Se pueden usar las siguientes definiciones de macro y directivas:

#silent
Si esta directiva está configurada, el script se inicia sin subshell interactivo.
%c
El número de posición de la columna del cursor.
%i
La indentación de espacios en blanco, igual a la columna del cursor.
%y
El tipo de sintaxis del archivo actual.
%b
El nombre del archivo del bloque.
%f
El nombre del archivo actual.
%n
Solo el nombre del archivo actual sin la extensión.
%x
La extensión del nombre del archivo actual.
%d
El nombre del directorio actual.
%F
El archivo actual en el panel no seleccionado.
%D
El nombre del directorio del panel no seleccionado.
%t
Los archivos actualmente etiquetados.
%T
Los archivos etiquetados en el panel no seleccionado.
%u y %U
Similar a las macros %t y %T, pero además los archivos se desetiquetan. Puede usar esta macro solo una vez por entrada de menú o entrada de archivo de extensión, ya que la próxima vez no habrá archivos etiquetados.
%s y %S
Los archivos seleccionados: Los archivos etiquetados si los hay. De lo contrario, el archivo actual.

Siéntase libre de editar estos archivos si lo necesita. Aquí hay un ejemplo de script externo:

l       comentar selección
	TMPFILE=`mktemp ${MC_TMPDIR:-/tmp}/up.XXXXXX` || exit 1
	echo #if 0 > $TMPFILE
	cat %b >> $TMPFILE
	echo #endif >> $TMPFILE
	cat $TMPFILE > %b
	rm -f $TMPFILE

Si algunas teclas no funcionan, puede usar Aprender Teclas en el menú Opciones.

NAVEGACIÓN CÓDIGO

mcedit puede usarse para navegar a través de archivos de etiquetas creados con los comandos etags o ctags. Si no hay un archivo TAGS, la navegación de código no funcionará. Por ejemplo, en el caso de exuberant-ctags para el lenguaje C, el comando sería:

ctags -e --language-force=C -R ./

Meta-Enter muestra un cuadro de lista para seleccionar el elemento bajo el cursor (el cursor debe estar al final de la palabra).

Meta-Menos (donde menos es el símbolo "-") va a la función anterior en la lista de navegación (como el botón Atrás del navegador).

Meta-Igual (donde igual es el símbolo "=") va a la función siguiente en la lista de navegación (como el botón Adelante del navegador).

RESALTADO SINTAXIS

mcedit soporta el resaltado de sintaxis. Esto significa que las palabras clave y contextos (como comentarios de C, constantes de cadena, etc.) se resaltan en diferentes colores. La siguiente sección explica el formato del archivo ~/.local/share/mc/syntax/Syntax. Si este archivo no existe, se usa el archivo del sistema /usr/share/mc/syntax/Syntax. El archivo ~/.local/share/mc/mc/syntax/Syntax se vuelve a escanear al abrir cada nuevo archivo del editor. El archivo contiene reglas para el resaltado, cada una de las cuales se da en una línea separada, y define qué palabras clave serán resaltadas con qué color.

El archivo se divide en secciones, cada una comenzando con una línea con el comando file. Las secciones normalmente se colocan en archivos separ

archivos de sintaxis con el comando include.

El comando file tiene tres argumentos. El primer argumento es una expresión regular que se aplica al nombre del archivo para determinar si la siguiente sección se aplica al archivo. El segundo argumento es la descripción del tipo de archivo. Se utiliza en cooledit; las versiones futuras de mcedit pueden utilizarlo también. El tercer argumento opcional es una expresión regular para coincidir con la primera línea de texto del archivo. Las reglas de la siguiente sección se aplican si coincide el nombre del archivo o la primera línea de texto.

Una sección termina con el inicio de otra sección. Cada sección se divide en contextos y cada contexto contiene reglas. Un contexto es un ámbito dentro del texto al que pertenece un conjunto particular de reglas. Por ejemplo, el texto dentro de un comentario estilo C (es decir, entre /* y */) tiene su propio color. Este es un contexto, aunque no tiene reglas adicionales dentro de él porque probablemente no hay nada que queramos resaltar dentro de un comentario C.

Una sección trivial de programación C podría verse así:

file .\*\\.c C\sProgram\sFile (#include|/\\\*)
wholechars abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ_
# colores por defecto
define  comment   brown
context default
  keyword  whole  if       yellow
  keyword  whole  else     yellow
  keyword  whole  for      yellow
  keyword  whole  while    yellow
  keyword  whole  do       yellow
  keyword  whole  switch   yellow
  keyword  whole  case     yellow
  keyword  whole  static   yellow
  keyword  whole  extern   yellow
  keyword         {        brightcyan
  keyword         }        brightcyan
  keyword         '*'      green
# comentarios C
context /\* \*/ comment
# directivas de preprocesador C
context linestart # \n red
  keyword  \\\n  brightred
# cadenas de texto C
context " " green
  keyword  %d    brightgreen
  keyword  %s    brightgreen
  keyword  %c    brightgreen
  keyword  \\"   brightgreen

Cada contexto comienza con una línea de la forma:

context [exclusive] [whole|wholeright|wholeleft] [linestart] delimitador [linestart] delimitador [primerplano] [fondo] [atributos]

El primer contexto es una excepción. Debe comenzar con el comando

context default [primerplano] [fondo] [atributos]

de lo contrario, mcedit informará de un error. La opción linestart especifica que delimitador debe comenzar al principio de una línea. La opción whole indica que delimitador debe ser una palabra completa. Para especificar que una palabra debe comenzar solo en el límite de palabra por el lado izquierdo, puede usar la opción wholeleft, y de manera similar, una palabra que debe terminar en el límite de palabra se especifica con wholeright.

El conjunto de caracteres que constituyen una palabra completa se puede cambiar en cualquier punto del archivo con el comando wholechars. Los conjuntos de caracteres izquierdo y derecho se pueden establecer por separado con

wholechars [left|right] caracteres

La opción exclusive hace que el texto entre los delimitadores se resalte, pero no los delimitadores mismos.

Cada regla es una línea de la forma:

keyword [whole|wholeright|wholeleft] [linestart] cadena primerplano [fondo] [atributos]

Las cadenas de contexto o palabra clave se interpretan, por lo que puede incluir tabulaciones y espacios con las secuencias \t y \s. Los saltos de línea y las barras invertidas se especifican con \n y \\ respectivamente. Dado que el espacio en blanco se utiliza como separador, no se puede usar tal cual. Además, se debe usar \* para especificar un asterisco. El propio * es un comodín que coincide con cualquier longitud de caracteres. Por ejemplo,

  keyword         '*'      green

colorea en verde todas las constantes de caracteres individuales de C. También podría usar

  keyword         "*"      green

para colorear las constantes de cadena, pero la cadena coincidente no podría abarcar varios saltos de línea. El comodín se puede usar también dentro de los delimitadores de contexto, pero no puede tener un comodín como carácter final o inicial.

Es importante notar la línea

  keyword  \\\n  brightgreen

Esta línea define una palabra clave que contiene los caracteres de barra invertida y salto de línea. Dado que las palabras clave se comparan antes que los delimitadores de contexto, esta palabra clave evita que el contexto termine al final de las líneas que terminan en una barra invertida, permitiendo así que la directiva del preprocesador C continúe a través de múltiples líneas.

Los colores posibles son: black, gray, red, brightred, green, brightgreen, brown, yellow, blue, brightblue, magenta, brightmagenta, cyan, brightcyan, lightgray y white. La palabra clave especial "default" significa el valor predeterminado de la terminal. Otra palabra clave especial "base" significa los colores principales de mc, es útil como marcador de posición si desea especificar atributos sin modificar el color de fondo. Cuando hay 256 colores disponibles, se pueden especificar como color16 a color255, o como rgb000 a rgb555 y gray0 a gray23.

Si el archivo de sintaxis se comparte con cooledit, es posible especificar diferentes colores para mcedit y cooledit separándolos con una barra, por ejemplo.

keyword  #include  red/Orange

mcedit utiliza el color anterior a la barra. Consulte cooledit(1) para ver los colores admitidos por cooledit.

Los atributos pueden ser cualquiera de bold, italic, underline, reverse y blink, seguidos de un signo más si se desean varios.

Los comentarios pueden colocarse en una línea separada que comience con el signo de almohadilla (#).

Si está describiendo un lenguaje insensible a mayúsculas y minúsculas, necesita usar la directiva caseinsensitive. Debe especificarse al principio del archivo de sintaxis.

Debido a la simplicidad de la implementación, hay algunas complejidades que no se manejarán correctamente, pero son una molestia menor. En general, una amplia gama de situaciones bastante complicadas se manejan con estas reglas simples. Es una buena idea echar un vistazo al archivo de sintaxis para ver algunos de los trucos ingeniosos que puede hacer con un poco de imaginación. Si no puede arreglárselas con las reglas que he codificado, y cree que tiene una regla que sería útil, envíeme un correo electrónico con su solicitud. Sin embargo, no pida soporte para expresiones regulares, ya que es absolutamente imposible.

Una pista útil es trabajar tanto como sea posible con las cosas que puede hacer en lugar de intentar hacer cosas que esta implementación no puede manejar. También recuerde que el objetivo del resaltado de sintaxis es hacer que la programación sea menos propensa a errores, no hacer que el código se vea bonito.

El resaltado de sintaxis se puede activar/desactivar usando el atajo Ctrl-s.

COLORES

Los colores predeterminados se pueden cambiar agregando a la variable de entorno MC_COLOR_TABLE. Los pares de colores de primer plano y fondo se pueden especificar, por ejemplo, con:

MC_COLOR_TABLE="$MC_COLOR_TABLE:\
editnormal=lightgray,black:\
editbold=yellow,black:\
editmarked=black,cyan"

OPCIONES

La mayoría de las opciones se pueden establecer desde el cuadro de diálogo Opciones. Consulte el menú Opciones. Las siguientes opciones se definen en ~/.config/mc/ini y tienen contrapartidas obvias en el cuadro de diálogo. Puede modificarlas para cambiar el comportamiento del editor, editando el archivo. A menos que se especifique lo contrario, un 1 establece la opción en activada y un 0 la establece en desactivada, como de costumbre.

use_internal_edit
Esta opción se ignora al invocar mcedit.
editor_tab_spacing
Interpretar el carácter de tabulación con esta longitud. Por defecto es 8. Debe evitar usar valores distintos de 8, ya que la mayoría de los demás editores y visores de texto asumen un espaciado de tabulación de 8. Use editor_fake_half_tabs para simular un espaciado de tabulación menor.
editor_fill_tabs_with_spaces
Nunca insertar un carácter de tabulación. En su lugar, insertar espacios (ascii 32) para rellenar hasta el tamaño de tabulación deseado.
editor_return_does_auto_indent
Al presionar Intro, se tabulará para que coincida con la indentación de la primera línea anterior que contenga texto.
editor_backspace_through_tabs
Hacer que una sola pulsación de retroceso elimine todo el espacio hasta el margen izquierdo si no hay texto entre el cursor y el margen izquierdo.
editor_fake_half_tabs
Esto emulará una media tabulación para aquellos que quieran programar con un espaciado de tabulación de 4, pero no quieran cambiar el tamaño de la tabulación de 8 (para que el código se formatee igual cuando lo vean otros programas). Al editar entre texto y el margen izquierdo, el movimiento y la tabulación serán como si el espacio de tabulación fuera 4, mientras que en realidad se usarán espacios y tabulaciones normales para un relleno óptimo. Al editar en cualquier otro lugar, se insertará una tabulación normal.
editor_option_save_mode
Valores posibles 0, 1 y 2. El modo de guardado (ver también el menú de opciones) le permite cambiar el método de guardado de un archivo. El guardado rápido (0) guarda el archivo inmediatamente, truncando el archivo del disco a longitud cero (es decir, borrándolo) y luego escribiendo el contenido del editor en el archivo. Este método es rápido, pero peligroso, ya que un error del sistema durante el guardado de un archivo dejará el archivo solo parcialmente escrito, lo que podría hacer que los datos no se puedan recuperar. Al guardar, la opción de guardado seguro (1) habilita la creación de un archivo temporal en el que se escribe primero el contenido del archivo. En caso de problema, el archivo original no se ve afectado. Cuando el archivo temporal se escribe correctamente, se renombra al nombre del archivo original, reemplazándolo así. El método más seguro es crear copias de seguridad (2): se crea un archivo de copia de seguridad antes de realizar ningún cambio. Puede especificar su propia extensión de archivo de copia de seguridad en el cuadro de diálogo. Tenga en cuenta que guardar dos veces reemplazará su copia de seguridad y su archivo original.
editor_word_wrap_line_length
Longitud de línea para ajustar automáticamente. Por defecto es 72.
editor_backup_extension
Símbolo a agregar al nombre de los archivos de copia de seguridad. Por defecto es "~".
editor_line_state
Mostrar la línea de estado del editor. Actualmente muestra el número de línea actual (en el futuro podría mostrar cosas como plegado, puntos de interrupción

OPCIONES

editor_visible_spaces
Alternar "mostrar espacios finales visibles". Si editor_visible_spaces=1, se muestran como '.'
editor_visible_tabs
Alternar "mostrar tabulaciones visibles". Si editor_visible_tabs=1, las tabulaciones se muestran como '<---->'
editor_persistent_selections
No eliminar la selección de bloque después de mover el cursor.
editor_drop_selection_on_copy
Restablecer la selección después de copiar al portapapeles.
editor_cursor_beyond_eol
Permitir mover el cursor más allá del final de la línea.
editor_cursor_after_inserted_block
Permitir mover el cursor después del bloque insertado.
editor_syntax_highlighting
Habilitar resaltado de sintaxis.
editor_edit_confirm_save
Mostrar diálogo de confirmación al guardar.
editor_option_typewriter_wrap
por describir
editor_option_auto_para_formatting
por describir
editor_option_save_position
Guardar la posición del archivo al salir.
source_codepage
Representación simbólica del nombre de la página de códigos para el archivo (es decir, CP1251, ~ - predeterminado).
editor_group_undo
Combinar acciones de DESHACER para varios tipos de acciones del mismo tipo (inserción/sobrescritura, eliminación, navegación, escritura)
editor_wordcompletion_collect_entire_file
Buscar candidatos de autocompletado en todo el archivo (1) o solo desde el principio del archivo hasta la posición del cursor (0).
editor_wordcompletion_collect_all_files
Buscar candidatos de autocompletado en todos los archivos cargados (1, predeterminado), no solo en el archivo que se está editando actualmente (0).
spell_language
Idioma de corrección ortográfica (en, en-variant_0, ru, etc.) instalado con el paquete aspell (una lista completa se puede obtener con la utilidad 'aspell'). Utilice spell_language = NONE para deshabilitar el soporte de aspell. El valor predeterminado es 'en'. La opción debe ubicarse en la sección [Misc].
editor_stop_format_chars
Conjunto de caracteres para detener el formato de párrafo. Si se encuentra uno de esos caracteres al principio de la línea, esa línea y las siguientes del párrafo no se verán afectadas. El valor predeterminado es "-+*\,.;:&>".
editor_state_full_filename
Mostrar el nombre completo de la ruta en la línea de estado. Si está deshabilitado (predeterminado), solo se muestra el nombre base del archivo.

VARIOS

El editor también muestra caracteres no estadounidenses (160+). Al editar archivos binarios, debes configurar los bits de visualización en 7 bits en el menú de opciones de Midnight Commander para mantener un espaciado limpio.

ARCHIVOS

/usr/share/mc/help/mc.hlp

El archivo de ayuda del programa.

/usr/share/mc/mc.ini

La configuración predeterminada del sistema para GNU Midnight Commander, que solo se utiliza si el archivo ~/.config/mc/ini del usuario no existe.

/usr/share/mc/mc.lib

Configuración global para Midnight Commander. La configuración en este archivo afecta a todos los usuarios, tengan o no ~/.config/mc/ini.

/usr/share/mc/syntax/*

Los archivos de sintaxis predeterminados del sistema para mcedit, que solo se utilizan si el archivo correspondiente del usuario en ~/.local/share/mc/syntax/ no existe.

~/.config/mc/ini

La configuración propia del usuario. Si este archivo existe, la configuración se carga desde aquí en lugar del archivo de configuración del sistema.

~/.local/share/mc/mcedit/

Directorio propio del usuario donde se procesan y guardan los comandos de bloque y donde se encuentran los archivos de sintaxis del usuario.
