mcd - cambiar directorio de MSDOS

Nota de advertencia

Esta página del manual ha sido generada automáticamente a partir de la documentación texinfo de mtools y puede no ser completamente precisa o completa. Consulte el final de esta página del manual para obtener más detalles.

Descripción

El comando mcd se utiliza para cambiar el directorio de trabajo de mtools en el disco MS-DOS. Utiliza la siguiente sintaxis:

mcd [directorio_msdos]

Sin argumentos, mcd informa sobre el dispositivo y el directorio de trabajo actuales. De lo contrario, mcd cambia el dispositivo actual y el directorio de trabajo actual en relación con un sistema de archivos MS-DOS.

La variable de entorno MCWD se puede utilizar para localizar el archivo donde se almacena la información del dispositivo y del directorio de trabajo actual. El valor predeterminado es `$HOME/.mcwd'. La información de este archivo se ignora si el archivo tiene más de 6 horas de antigüedad.

Mcd devuelve 0 en caso de éxito o 1 en caso de error.

A diferencia de las versiones de MS-DOS de CD, mcd se puede utilizar para cambiar a otro dispositivo. Puede ser conveniente eliminar los archivos antiguos de `.mcwd' al cerrar la sesión.
