MCOOKIE(1) Comandos de usuario MCOOKIE(1)

NOMBRE

mcookie - generar galletas mágicas para xauth

SINOPSIS

mcookie [opciones]

DESCRIPCIÓN

mcookie genera un número hexadecimal aleatorio de 128 bits para usarlo con el sistema de autoridad X. Uso típico:

xauth add :0 . mcookie

El número "aleatorio" generado es en realidad el resumen del mensaje MD5 de información aleatoria proveniente de una de las fuentes de la llamada al sistema getrandom(2), /dev/urandom, /dev/random, o las *funciones pseudoaleatorias de libc*, en este orden de preferencia. Ver también la opción --file.

OPCIONES

-f, --file archivo

Usar este archivo como una fuente adicional de aleatoriedad (por ejemplo /dev/urandom). Cuando archivo es '-', se leen caracteres de la entrada estándar.

-m, --max-size número

Leer de archivo solo este número de bytes. Esta opción está pensada para usarse al leer aleatoriedad adicional de un archivo o dispositivo.

El argumento número puede ir seguido de los sufijos multiplicadores KiB=1024, MiB=1024*1024, y así sucesivamente para GiB, TiB, PiB, EiB, ZiB e YiB (la parte "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB") o los sufijos KB=1000, MB=1000*1000, y así sucesivamente para GB, TB, PB, EB, ZB y YB.

-v, --verbose

Informar de dónde provino la aleatoriedad, con la cantidad de entropía leída de cada fuente.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar versión y salir.

ARCHIVOS

/dev/urandom

/dev/random

ERRORES

Se asume que ninguna de las fuentes de aleatoriedad se bloqueará.

VER TAMBIÉN

md5sum(1), X(7), xauth(1), rand(3)
