MC-TOOL(1) Utilidades MC-TOOL(1)

NOMBRE

mc-tool - manipula cuentas de Mission Control desde la línea de comandos

SINOPSIS

mc-tool list

mc-tool add PERFIL NOMBRE-MOSTRADO [CONFIGURACIONES-PARAMETRO...]

mc-tool add ADMINISTRADOR/PROTOCOLO [CONFIGURACIONES-PARAMETRO...]

mc-tool update CUENTA [CONFIGURACIONES-PARAMETRO...]

mc-tool display CUENTA NOMBRE-MOSTRADO

mc-tool nick CUENTA APODO

mc-tool service CUENTA NOMBRE-SERVICIO

mc-tool icon CUENTA ICONO

mc-tool show CUENTA

mc-tool get CUENTA PARAMETRO [PARAMETRO...]

mc-tool auto-presence CUENTA ESTADO [MENSAJE]

mc-tool request CUENTA ESTADO [MENSAJE]

mc-tool auto-connect CUENTA on|off

mc-tool remove CUENTA

DESCRIPCIÓN

El uso de mc-tool depende de su primer argumento (el "comando")

ESPECIFICANDO CUENTAS

Donde se necesite un nombre de cuenta, se puede proporcionar como una ruta de objeto completa (por ejemplo, /org/freedesktop/Telepathy/Account/gabble/jabber/example), o como el sufijo único específico de la cuenta (por ejemplo, gabble/jabber/example).

ESPECIFICANDO CONFIGURACIONES DE PARÁMETRO

Muchos comandos toman argumentos que representan parámetros del gestor de conexión de Telepathy (consulte la Especificación de Telepathy para obtener detalles sobre estos). Cada argumento tiene el siguiente formato:

TIPO:NOMBRE=VALOR

donde TIPO es int, uint, bool o string (existen otros tipos de parámetros, pero actualmente no son soportados por mc-tool), NOMBRE es el nombre del parámetro del gestor de conexión (por ejemplo, account o password), y VALOR es el valor del parámetro (con enteros en decimal y booleanos como 0 o 1).

El comando update también acepta argumentos del formato clear:NOMBRE que eliminan el parámetro nombrado de la configuración de la cuenta.

LIST

mc-tool list lista las cuentas disponibles.

ADD

mc-tool add añade una cuenta. El gestor de conexión y el protocolo se pueden dar como el nombre de un perfil de Mission Control, (por ejemplo, gtalk), o como un nombre de gestor de conexión y protocolo separados por barras (por ejemplo, gabble/jabber).

DISPLAY

mc-tool display CUENTA NOMBRE-MOSTRADO establece la propiedad DisplayName de CUENTA a NOMBRE-MOSTRADO.

NICK

mc-tool nick CUENTA APODO establece la propiedad Nickname de CUENTA a APODO.

SERVICE

mc-tool service CUENTA NOMBRE-SERVICIO establece la propiedad Service de CUENTA a NOMBRE-SERVICIO.

ICON

mc-tool icon CUENTA ICONO establece la propiedad Icon de CUENTA a ICONO.

SHOW

mc-tool show CUENTA muestra información sobre CUENTA.

GET

mc-tool get CUENTA PARAMETRO [PARAMETRO...] muestra los valores de los parámetros dados de CUENTA.

ENABLE

mc-tool enable CUENTA establece la propiedad Enabled de CUENTA a True.

DISABLE

mc-tool disable CUENTA establece la propiedad Enabled de CUENTA a False.

AUTO-PRESENCE

mc-tool auto-presence CUENTA ESTADO [MENSAJE] establece la propiedad AutomaticPresence de CUENTA a ESTADO con el mensaje opcional MENSAJE.

REQUEST

mc-tool request CUENTA ESTADO [MENSAJE] establece la propiedad RequestedPresence de CUENTA a ESTADO con el mensaje opcional MENSAJE; así es como le indica a una cuenta que se conecte o se desconecte, por ejemplo.

AUTO-CONNECT

mc-tool auto-connect CUENTA on establece la propiedad ConnectAutomatically de CUENTA a True. mc-tool auto-connect CUENTA off la establece a False.
