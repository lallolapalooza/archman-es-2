mcv(1) Manual de usuario de Scotch mcv(1)

NOMBRE

mcv - convertidor de archivos de malla

SINOPSIS

mcv [opciones] [archivo_entrada] [archivo_salida_malla] [archivo_salida_geometria]

DESCRIPCIÓN

El programa mcv convierte archivos de malla Scotch de y hacia otros formatos de archivo externos.

El archivo archivo_entrada se convierte en el archivo de malla archivo_salida_malla, con datos de geometría opcionales que se colocan en el archivo de geometría archivo_salida_geometria, si está disponible.

Cuando no se especifican nombres de archivo, los datos se leen de la entrada estándar y se escriben en la salida estándar. Los flujos estándar también se pueden representar explícitamente con un guion '-'.

Cuando las bibliotecas adecuadas se han incluido en tiempo de compilación, mcv puede manejar directamente mallas comprimidas, tanto como entrada como salida. Un flujo se trata como comprimido siempre que su nombre tenga el sufijo de una extensión de archivo comprimido, como en 'brol.msh.bz2' o '-.gz'. Los formatos de compresión que se pueden admitir son el formato bzip2 ('.bz2'), el formato gzip ('.gz') y el formato lzma ('.lzma').

OPCIONES

-h
Muestra ayuda.
-i?formato_entrada
Establece el formato del archivo de malla de entrada, que puede ser:
b?num
Formato Boeing-Harwell. Este es un formato de matriz elemental. Solo se admiten matrices cuadradas. En caso de que el archivo contenga varias matrices, el parámetro num permite al usuario proporcionar el índice de la matriz a convertir, comenzando desde 0. Cuando no se establece el parámetro num, se asume que es 0.
s
Formato de malla Scotch.
-o?formato_salida
Establece el formato del archivo de malla de salida, que puede ser:
s
Formato de malla Scotch. Esta es la única opción posible en este momento.
-V
Muestra la versión del programa y los derechos de autor.

EJEMPLO

Convertir una malla elemental Harwell-Boeing a una malla Scotch.

    $ mcv -ib brol.hb brol.msh
