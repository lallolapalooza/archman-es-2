NOMBRE

mcpp - Matsui CPP, un preprocesador C alternativo

SINOPSIS

mcpp [opciones] [<archivo_entrada> [<archivo_salida>]]

DESCRIPCIÓN

mcpp es un preprocesador C/C++ con la mayor conformidad que implementa C90, C99 y C++98. mcpp tiene diagnósticos abundantes y muchos #pragma. Es útil para verificar la portabilidad de su programa y también para depurar macros complicadas. Esta es una página de manual para mcpp de la compilación independiente del compilador.

OPCIONES

mcpp espera dos nombres de archivo como argumentos, <archivo_entrada> y <archivo_salida>. Si no se especifican, <archivo_entrada> toma por defecto la entrada estándar y <archivo_salida> toma por defecto la salida estándar.

Toma las siguientes opciones.

Opciones de uso común:

-@MODO
Especifica el modo de preprocesamiento. MODO debe ser uno de estos 4:
-@std
Modo conforme al estándar. (por defecto)
-@poststd, -@post
modo especial de 'post-estándar'.
-@kr
Modo 1 K&R.
-@oldprep, -@old
Modo "old_preprocessor" (es decir, preprocesador "modelo Reiser").
-@compat
Modo 'compatible' con el estándar.
-C
Salida también de comentarios.
-D <macro>[=<valor>]
Define <macro> como <valor> (por defecto:1).
-D <macro(args)>[=<reemplazo>]
Define <macro(args)> como <reemplazo>.
-e <codificación>
Cambia la codificación de caracteres multibyte por defecto a una de: euc_jp, gb2312, ksc5601, big5, sjis, iso2022_jp, utf8.
-I <directorio>
Agrega <directorio> a la lista de búsqueda de #include.
-I-
Anula las directorios de inclusión específicos del sistema o sitio.
-j
No generar la línea de código fuente en los diagnósticos.
-k
Mantener los espacios en blanco de las líneas de entrada tal como están.
-M, -MM, -MD, -MMD, -MP, -MQ objetivo, -MT objetivo, -MF archivo
Generar línea de dependencia del archivo fuente para makefile.
-m32
Cambia la CPU de destino de x86_64, ppc64 a i386, ppc, respectivamente.
-m64
Cambia la CPU de destino de i386, ppc a x86_64, ppc64, respectivamente.
-[no-]mmx
Define/anula la definición de __MMX__.
-N
No predefinir ninguna macro no estándar.
-o <archivo>
Salida a <archivo>.
-P
No generar líneas #line.
-Q
Salida de diagnósticos a "mcpp.err" (por defecto: stderr).
-U <macro>
Anula la definición de <macro>.
-v
Mostrar la versión de mcpp.
-W <nivel>
Establece el nivel de advertencia a <nivel> (OR de {0,1,2,4,8,16}, por defecto:1).
-z
No generar el archivo incluido, solo definir macros.

Opciones disponibles con las opciones -@std (por defecto) o -@poststd:

-+
Procesa código fuente C++.
-2
Habilita dígrafos.
-h <n>
Redefine la macro predefinida __STDC_HOSTED__ como <n>.
-S <n>
Redefine __STDC__ a <n>, anula la definición de macros de estilo antiguo.
-V <n>
Redefine __STDC_VERSION__ o __cplusplus a <n>.
C con -V199901L especifica el modo C99.
C++ con -V199901L especifica el modo compatible con C99.

Opciones disponibles solo con la opción -@std (por defecto):

-@compat
Expande macros recursivas más allá del estándar.
-3
Habilita trígrafos.
-K
Incrusta anotaciones de macros en comentarios.

Opciones disponibles con las opciones -@std (por defecto), -@kr o -@oldprep:

-a
Procesa código fuente de "ensamblador".

PRAGMA

mcpp tiene las siguientes directivas #pragma.

#pragma once
Lee el archivo de cabecera solo una vez, incluso si se incluye varias veces.
#pragma __setlocale( "codificación")
Especifica la codificación de caracteres multibyte como "codificación". Consulte la opción -e para conocer las codificaciones.
#pragma MCPP put_defines
Genera todas las definiciones de macros actualmente válidas.
#pragma MCPP debug <args>
Comienza a generar información de depuración.
<args> debe ser uno o más de:
token expand macro_call path if expression memory getc
#pragma MCPP end_debug <args>
Deja de generar información de depuración.
<args> son los mismos que 'debug'.
Sin argumento especifica todos los argumentos.
#pragma MCPP push_macro( "MACRO")
Guarda la definición de la macro en la pila.
#pragma MCPP pop_macro( "MACRO")
Recupera la definición de la macro de la pila.
#pragma MCPP preprocess
"Preprocesa" los siguientes archivos de cabecera para mcpp.
#pragma MCPP warning any message
Genera la advertencia "any message".
