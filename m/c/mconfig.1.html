NOMBRE

mconfig, - Utilidad para modificar archivos de configuración .NET

SINOPSIS

mconfig [opciones] comando [parámetros_del_comando]

DESCRIPCIÓN

mconfig se puede usar para editar archivos de configuración .NET, añadiendo "características" (es decir, conjuntos de sentencias xml) definidas en uno de los archivos de configuración leídos por mconfig. El archivo de configuración también puede definir diseños de archivos de configuración por defecto, lo que puede ser útil para iniciar tus proyectos .NET.

Para ver la lista de comandos reconocidos, archivos de configuración y características por defecto, ejecuta mconfig sin pasar ningún parámetro.

OPCIONES

-c <archivo_config>, --config=<archivo_config>
Lee el archivo de configuración especificado después de leer los otros archivos de configuración preconfigurados para la utilidad. La configuración en el archivo especificado anula la encontrada en las otras ubicaciones de configuración.
-t {cualquiera | web | aplicacion}, --target={cualquiera | web | aplicacion}
Las características y los archivos de configuración por defecto definidos en los archivos de configuración de mconfig pueden asignarse a uno de los tres destinos: web (para características/archivos de configuración ASP.NET), aplicacion - para aplicaciones .NET, cualquiera - aplicable en ambos destinos anteriores. Por defecto es cualquiera.
-?, -h, --help
Muestra una pantalla de resumen de uso.
-v, --version
Muestra la versión de mconfig

COMANDOS

{añadircaracteristica, ac} <nombre_caracteristica> [ruta_archivo_config]
Añade la característica llamada <nombre_caracteristica> al archivo de configuración especificado. Si se omite [ruta_archivo_config], el nombre del archivo de configuración de salida se elegirá basándose en el destino seleccionado (ver la opción -t). El destino web genera la configuración en el archivo llamado Web.config, y el destino aplicacion genera en el archivo llamado application.exe.config. El destino cualquiera no tiene un archivo de salida por defecto.

Si el archivo de configuración especificado existe, la característica se insertará en las ubicaciones especificadas por la configuración de mconfig. Si el archivo de configuración de destino no existe, se creará y contendrá solo la característica especificada y todas sus dependencias.

{configpor defecto, cpd} [nombre_config [directorio_destino]]
Genera un archivo de configuración por defecto usando la entrada de configuración llamada [nombre_config] y genera el archivo de configuración resultante en el directorio dado por la opción [directorio_destino]. Si se omite [nombre_config], por defecto será Web.config para el destino web y el destino aplicacion. El destino cualquiera no especifica ningún nombre de archivo de configuración de salida por defecto. Si se omite el parámetro [directorio_destino], por defecto será el directorio actual.

El nombre del archivo de configuración de salida creado en [directorio_destino] se da en la definición del diseño del archivo de configuración.

ARCHIVOS

Los archivos de configuración se leen en el orden que se indica a continuación. Cada archivo subsiguiente puede anular la configuración encontrada en los archivos leídos antes que él.

$prefix/etc/mono/mconfig/config.xml
El archivo de configuración por defecto, distribuido con mconfig. $prefix es el prefijo de instalación de mconfig especificado en el momento de la compilación.
$config_dir/mconfig/config.xml
$config_dir es el directorio especificado en la variable de entorno XDG_CONFIG_HOME o,
si está vacío, en el directorio .config ubicado en el directorio personal del usuario. Este archivo no se distribuye con Mono.
./mconfig.xml
Archivo de configuración local que puede contener ajustes por aplicación.
