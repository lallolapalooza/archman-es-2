MQ_NOTIFY(3P) Manual del programador POSIX MQ_NOTIFY(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mq_notify — notificar al proceso que un mensaje está disponible (TIEMPO REAL)

SINOPIS

#include <mqueue.h>
int mq_notify(mqd_t mqdes, const struct sigevent *notification);

DESCRIPCIÓN

Si el argumento notification no es NULL, esta función registrará al proceso que llama para que se le notifique la llegada de mensajes a una cola de mensajes vacía asociada con el descriptor de cola de mensajes especificado, mqdes. La notificación especificada por el argumento notification se enviará al proceso cuando la cola de mensajes pase de vacía a no vacía. En cualquier momento, solo un proceso puede estar registrado para la notificación por una cola de mensajes. Si el proceso que llama o cualquier otro proceso ya se ha registrado para la notificación de llegada de mensajes a la cola de mensajes especificada, los intentos posteriores de registrarse para esa cola de mensajes fallarán.

Si notification es NULL y el proceso está actualmente registrado para la notificación por la cola de mensajes especificada, se eliminará el registro existente.

Cuando se envía la notificación al proceso registrado, se eliminará su registro. La cola de mensajes estará entonces disponible para el registro.

Si un proceso se ha registrado para la notificación de llegada de mensajes a una cola de mensajes y algún hilo está bloqueado en mq_receive() o mq_timedreceive() esperando recibir un mensaje cuando llega un mensaje a la cola, el mensaje que llega satisfará el mq_receive() o mq_timedreceive() apropiado, respectivamente. El comportamiento resultante es como si la cola de mensajes permaneciera vacía, y no se enviará ninguna notificación.

VALOR DE RETORNO

Al completarse con éxito, la función mq_notify() devolverá un valor de cero; de lo contrario, la función devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función mq_notify() fallará si:

EBADF
El argumento mqdes no es un descriptor de cola de mensajes válido.
EBUSY
Un proceso ya está registrado para la notificación por la cola de mensajes.

La función mq_notify() puede fallar si:

EINVAL
El argumento notification es NULL y el proceso no está actualmente registrado.

EJEMPLOS

El siguiente programa registra una solicitud de notificación para la cola de mensajes nombrada en su argumento de línea de comandos. La notificación se realiza creando un hilo. El hilo ejecuta una función que lee un mensaje de la cola y luego termina el proceso.

#include <pthread.h>
#include <mqueue.h>
#include <assert.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void                     /* Función de inicio del hilo */
tfunc(union sigval sv)
{
    struct mq_attr attr;
    ssize_t nr;
    void *buf;
    mqd_t mqdes = *((mqd_t *) sv.sival_ptr);
    /* Determinar el tamaño máximo del mensaje; asignar búfer para recibir el mensaje */
    if (mq_getattr(mqdes, &attr) == -1) {
        perror("mq_getattr");
        exit(EXIT_FAILURE);
    }
    buf = malloc(attr.mq_msgsize);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    nr = mq_receive(mqdes, buf, attr.mq_msgsize, NULL);
    if (nr == -1) {
        perror("mq_receive");
        exit(EXIT_FAILURE);
    }
    printf("Leído %ld bytes de la cola de mensajes\n", (long) nr);
    free(buf);
    exit(EXIT_SUCCESS);         /* Terminar el proceso */
}
int
main(int argc, char *argv[])
{
    mqd_t mqdes;
    struct sigevent not;
    assert(argc == 2);
    mqdes = mq_open(argv[1], O_RDONLY);
    if (mqdes == (mqd_t) -1) {
        perror("mq_open");
        exit(EXIT_FAILURE);
    }
    not.sigev_notify = SIGEV_THREAD;
    not.sigev_notify_function = tfunc;
    not.sigev_notify_attributes = NULL;
    not.sigev_value.sival_ptr = &mqdes;   /* Arg. para la función del hilo */
    if (mq_notify(mqdes, &not) == -1) {
        perror("mq_notify");
        exit(EXIT_FAILURE);
    }
    pause();    /* El proceso será terminado por la función del hilo */
}
