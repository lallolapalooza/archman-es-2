mq_notify(3) Manual de Funciones de Biblioteca mq_notify(3)

NOMBRE

mq_notify - registrarse para recibir notificación cuando hay un mensaje disponible

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <mqueue.h>
#include <signal.h>           /* Definición de constantes SIGEV_* */
int mq_notify(mqd_t mqdes, const struct sigevent *sevp);

DESCRIPCIÓN

mq_notify() permite al proceso que llama registrarse o anular el registro para la entrega de una notificación asíncrona cuando un nuevo mensaje llega a la cola de mensajes vacía referenciada por el descriptor de cola de mensajes mqdes.

El argumento sevp es un puntero a una estructura sigevent. Para la definición y detalles generales de esta estructura, consulte sigevent(3type).

Si sevp es un puntero no nulo, entonces mq_notify() registra el proceso que llama para recibir notificación de mensajes. El campo sigev_notify de la estructura sigevent a la que apunta sevp especifica cómo se realizará la notificación. Este campo tiene uno de los siguientes valores:

SIGEV_NONE
Una notificación "nula": el proceso que llama se registra como el objetivo de la notificación, pero cuando llega un mensaje, no se envía ninguna notificación.
SIGEV_SIGNAL
Notificar al proceso enviando la señal especificada en sigev_signo. Consulte sigevent(3type) para detalles generales. El campo si_code de la estructura siginfo_t se establecerá en SI_MESGQ. Además, si_pid se establecerá en el PID del proceso que envió el mensaje, y si_uid se establecerá en el ID de usuario real del proceso que envía.
SIGEV_THREAD
Al entregar el mensaje, invocar sigev_notify_function como si fuera la función de inicio de un nuevo hilo. Consulte sigevent(3type) para más detalles.

Solo un proceso puede registrarse para recibir notificación de una cola de mensajes.

Si sevp es NULL, y el proceso que llama está actualmente registrado para recibir notificaciones para esta cola de mensajes, entonces se elimina el registro; otro proceso puede entonces registrarse para recibir una notificación de mensajes para esta cola.

La notificación de mensajes ocurre solo cuando llega un nuevo mensaje y la cola estaba previamente vacía. Si la cola no estaba vacía en el momento en que se llamó a mq_notify(), entonces una notificación ocurrirá solo después de que la cola se vacíe y llegue un nuevo mensaje.

Si otro proceso o hilo está esperando leer un mensaje de una cola vacía usando mq_receive(3), entonces cualquier registro de notificación de mensajes se ignora: el mensaje se entrega al proceso o hilo que llama a mq_receive(3), y el registro de notificación de mensajes permanece en vigor.

La notificación ocurre una vez: después de que se entrega una notificación, el registro de notificación se elimina y otro proceso puede registrarse para la notificación de mensajes. Si el proceso notificado desea recibir la siguiente notificación, puede usar mq_notify() para solicitar una notificación adicional. Esto debe hacerse antes de vaciar todos los mensajes no leídos de la cola. (Poner la cola en modo no bloqueante es útil para vaciar la cola de mensajes sin bloquear una vez que esté vacía).

VALOR DE RETORNO

En caso de éxito, mq_notify() devuelve 0; en caso de error, devuelve -1 y errno se establece para indicar el error.

ERRORES

EBADF
El descriptor de cola de mensajes especificado en mqdes es inválido.
EBUSY
Otro proceso ya se ha registrado para recibir notificación para esta cola de mensajes.
EINVAL
sevp->sigev_notify no es uno de los valores permitidos; o sevp->sigev_notify es SIGEV_SIGNAL y sevp->sigev_signo no es un número de señal válido.
ENOMEM
Memoria insuficiente.

POSIX.1-2008 dice que una implementación puede generar un error EINVAL si sevp es NULL, y el llamador no está actualmente registrado para recibir notificaciones para la cola mqdes.

VERSIÓNES

Diferencias biblioteca C/núcleo

En la implementación de glibc, la función de biblioteca mq_notify() se implementa sobre la llamada al sistema del mismo nombre. Cuando sevp es NULL, o especifica un mecanismo de notificación distinto de SIGEV_THREAD, la función de biblioteca invoca directamente la llamada al sistema. Para SIGEV_THREAD, gran parte de la implementación reside dentro de la biblioteca, en lugar del núcleo. (Esto es necesariamente así, ya que el hilo involucrado en el manejo de la notificación es uno que debe ser gestionado por la implementación de hilos POSIX de la biblioteca C.) La implementación involucra el uso de un socket netlink(7) sin procesar y crea un nuevo hilo por cada notificación que se entrega al proceso.

EJEMPLOS

El siguiente programa registra una solicitud de notificación para la cola de mensajes nombrada en su argumento de línea de comandos. La notificación se realiza creando un hilo. El hilo ejecuta una función que lee un mensaje de la cola y luego termina el proceso.

Fuente del programa

#include <err.h>
#include <mqueue.h>
#include <pthread.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void                     /* Función de inicio del hilo */
tfunc(union sigval sv)
{
    struct mq_attr attr;
    ssize_t nr;
    void *buf;
    mqd_t mqdes = *((mqd_t *) sv.sival_ptr);
    /* Determinar el tamaño máximo del msg; asignar buffer para recibir el msg */
    if (mq_getattr(mqdes, &attr) == -1)
        err(EXIT_FAILURE, "mq_getattr");
    buf = malloc(attr.mq_msgsize);
    if (buf == NULL)
        err(EXIT_FAILURE, "malloc");
    nr = mq_receive(mqdes, buf, attr.mq_msgsize, NULL);
    if (nr == -1)
        err(EXIT_FAILURE, "mq_receive");
    printf("Leído %zd bytes de MQ\n", nr);
    free(buf);
    exit(EXIT_SUCCESS);         /* Terminar el proceso */
}
int
main(int argc, char *argv[])
{
    mqd_t mqdes;
    struct sigevent sev;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s <nombre_mq>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    mqdes = mq_open(argv[1], O_RDONLY);
    if (mqdes == (mqd_t) -1)
        err(EXIT_FAILURE, "mq_open");
    sev.sigev_notify = SIGEV_THREAD;
    sev.sigev_notify_function = tfunc;
    sev.sigev_notify_attributes = NULL;
    sev.sigev_value.sival_ptr = &mqdes;   /* Arg. para la función del hilo */
    if (mq_notify(mqdes, &sev) == -1)
        err(EXIT_FAILURE, "mq_notify");
    pause();    /* El proceso será terminado por la función del hilo */
}
