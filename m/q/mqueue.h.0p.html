mqueue.h(0P) Manual del programador POSIX mqueue.h(0P)

PRÓLOGO

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mqueue.h — colas de mensajes (TIEMPO REAL)

SINOPSIS

#include <mqueue.h>

DESCRIPCIÓN

La cabecera <mqueue.h> definirá el tipo mqd_t, que se utiliza para los descriptores de colas de mensajes. Este no es un tipo de matriz.

La cabecera <mqueue.h> definirá los tipos pthread_attr_t, size_t y ssize_t tal como se describe en <sys/types.h>.

La cabecera <mqueue.h> definirá la estructura struct timespec tal como se describe en <time.h>.

La etiqueta sigevent se declarará como un tipo de estructura incompleta, cuyo contenido se describe en la cabecera <signal.h>.

La cabecera <mqueue.h> definirá la estructura mq_attr, que se utiliza para obtener y establecer los atributos de una cola de mensajes. Los atributos se establecen inicialmente cuando se crea la cola de mensajes. Una estructura mq_attr tendrá al menos los siguientes campos:

long    mq_flags    Banderas de la cola de mensajes.
long    mq_maxmsg   Número máximo de mensajes.
long    mq_msgsize  Tamaño máximo del mensaje.
long    mq_curmsgs  Número de mensajes en cola actualmente.

Lo siguiente se declarará como funciones y también puede definirse como macros. Se proporcionarán prototipos de función.

int      mq_close(mqd_t);
int      mq_getattr(mqd_t, struct mq_attr *);
int      mq_notify(mqd_t, const struct sigevent *);
mqd_t    mq_open(const char *, int, ...);
ssize_t  mq_receive(mqd_t, char *, size_t, unsigned *);
int      mq_send(mqd_t, const char *, size_t, unsigned);
int      mq_setattr(mqd_t, const struct mq_attr *restrict,
             struct mq_attr *restrict);
ssize_t  mq_timedreceive(mqd_t, char *restrict, size_t,
             unsigned *restrict, const struct timespec *restrict);
int      mq_timedsend(mqd_t, const char *, size_t, unsigned,
             const struct timespec *);
int      mq_unlink(const char *);

La inclusión de la cabecera <mqueue.h> puede hacer visibles símbolos definidos en las cabeceras <fcntl.h>, <signal.h> y <time.h>.
