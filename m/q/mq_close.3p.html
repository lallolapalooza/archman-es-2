MQ_CLOSE(3P) Manual de programador de POSIX MQ_CLOSE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mq_close — cerrar una cola de mensajes (REALTIME)

SINOPSIS

#include <mqueue.h>
int mq_close(mqd_t mqdes);

DESCRIPCIÓN

La función mq_close() eliminará la asociación entre el descriptor de cola de mensajes, mqdes, y su cola de mensajes. Los resultados de usar este descriptor de cola de mensajes después de un retorno exitoso de esta mq_close(), y hasta el retorno de este descriptor de cola de mensajes de una mq_open() posterior, no están definidos.

Si el proceso ha adjuntado correctamente una solicitud de notificación a la cola de mensajes a través de este mqdes, esta adjunción se eliminará, y la cola de mensajes estará disponible para que otro proceso se adjunte para notificación.

VALOR DE RETORNO

Al completarse con éxito, la función mq_close() devolverá un valor de cero; de lo contrario, la función devolverá un valor de -1 y establecerá errno para indicar el error.

ERRORES

La función mq_close() fallará si:

EBADF
El argumento mqdes no es un descriptor de cola de mensajes válido.
