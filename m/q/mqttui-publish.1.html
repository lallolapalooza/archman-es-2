mqttui-publish(1) Manual de Comandos Generales mqttui-publish(1)

NOMBRE

mqttui-publish - Publicar un valor rápidamente

SINOPSIS

mqttui publish [-r|--retain] [-v|--verbose] [-b|--broker] [-u|--username] [--password] [-i|--client-id] [--client-cert] [--client-key] [--insecure] [-h|--help] <TEMA> [CARGA]

DESCRIPCIÓN

Publicar un valor rápidamente

OPCIONES

-r, --retain
Publicar el mensaje MQTT retenido
También puede especificarse con la variable de entorno MQTTUI_RETAIN.
-v, --verbose
Mostrar comunicación MQTT completa
-h, --help
Imprimir ayuda (ver un resumen con '-h')
<TEMA>
Tema al que publicar
[CARGA]
Carga a ser publicada.

Lee desde la entrada estándar cuando no se especifica. Esto permite enviar contenido de archivo a través de tuberías como esta (bash):

`mqttui publish algún/tema </etc/hostname`

`cowsay "Estuve aquí" | mqttui publish algún/tema`

CONEXIÓN MQTT

-b, --broker=URL [por defecto: mqtt://localhost]
URL que representa cómo conectarse al broker MQTT.

Ejemplos: `mqtt://localhost` `mqtt://localhost:1883` `mqtts://localhost` `mqtts://localhost:8883` `ws://localhost/path` `ws://localhost:9001/path` `wss://localhost/path` `wss://localhost:9001/path`

También puede especificarse con la variable de entorno MQTTUI_BROKER.
-u, --username=CADENA
Nombre de usuario para acceder al broker mqtt.

Acceso anónimo cuando no se proporciona.

También puede especificarse con la variable de entorno MQTTUI_USERNAME.
--password=CADENA
Contraseña para acceder al broker mqtt.

Considere usar una conexión con TLS al broker. De lo contrario, la contraseña se transportará en texto plano.

Pasar la contraseña a través de la línea de comandos no es seguro, ya que la contraseña puede leerse del historial. Debería pasarla a través de la variable de entorno.

También puede especificarse con la variable de entorno MQTTUI_PASSWORD.
-i, --client-id=CADENA
Especificar el ID de cliente con el que conectarse
También puede especificarse con la variable de entorno MQTTUI_CLIENTID.
--client-cert=RUTAARCHIVO
Ruta al archivo del certificado de cliente TLS.

Se usa junto con --client-key para habilitar la autenticación de cliente TLS. El archivo debe ser un certificado X.509 codificado en DER serializado a PEM.

También puede especificarse con la variable de entorno MQTTUI_CLIENT_CERTIFICATE.
--client-key=RUTAARCHIVO
Ruta a la clave privada del cliente TLS.

Se usa junto con --client-cert para habilitar la autenticación de cliente TLS. El archivo debe ser un archivo ASN.1 codificado en DER en formato PKCS#8 serializado a PEM.

También puede especificarse con la variable de entorno MQTTUI_CLIENT_PRIVATE_KEY.
--insecure
Permitir conexiones TLS inseguras
