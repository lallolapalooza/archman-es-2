mq_getattr(3) Manual de funciones de biblioteca mq_getattr(3)

NOMBRE

mq_getattr, mq_setattr - obtener/establecer atributos de cola de mensajes

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <mqueue.h>
int mq_getattr(mqd_t mqdes, struct mq_attr *attr);
int mq_setattr(mqd_t mqdes, const struct mq_attr *restrict newattr,
               struct mq_attr *restrict oldattr);

DESCRIPCIÓN

mq_getattr() y mq_setattr() obtienen y modifican, respectivamente, los atributos de la cola de mensajes a la que se hace referencia con el descriptor de cola de mensajes mqdes.

mq_getattr() devuelve una estructura mq_attr en el búfer apuntado por attr. Esta estructura se define como:


struct mq_attr {
    long mq_flags;       /* Banderas: 0 o O_NONBLOCK */
    long mq_maxmsg;      /* Máx. # de mensajes en la cola */
    long mq_msgsize;     /* Máx. tamaño del mensaje (bytes) */
    long mq_curmsgs;     /* # de mensajes actualmente en la cola */
};

El campo mq_flags contiene banderas asociadas con la descripción abierta de la cola de mensajes. Este campo se inicializa cuando la cola se crea mediante mq_open(3). La única bandera que puede aparecer en este campo es O_NONBLOCK.

Los campos mq_maxmsg y mq_msgsize se establecen cuando la cola de mensajes se crea mediante mq_open(3). El campo mq_maxmsg es un límite superior para el número de mensajes que se pueden colocar en la cola mediante mq_send(3). El campo mq_msgsize es un límite superior para el tamaño de los mensajes que se pueden colocar en la cola. Ambos campos deben tener un valor mayor que cero. Dos archivos de /proc que establecen límites máximos para los valores de estos campos se describen en mq_overview(7).

El campo mq_curmsgs devuelve el número de mensajes actualmente retenidos en la cola.

mq_setattr() establece los atributos de la cola de mensajes utilizando la información proporcionada en la estructura mq_attr apuntada por newattr. El único atributo que se puede modificar es el establecimiento de la bandera O_NONBLOCK en mq_flags. Los demás campos en newattr se ignoran. Si el campo oldattr no es NULL, entonces el búfer al que apunta se utiliza para devolver una estructura mq_attr que contiene la misma información que devuelve mq_getattr().

VALOR DEVUELTO

En caso de éxito, mq_getattr() y mq_setattr() devuelven 0; en caso de error, devuelven -1, y errno se establece para indicar el error.

ERRORES

EBADF
El descriptor de cola de mensajes especificado en mqdes es inválido.
EINVAL
newattr->mq_flags contenía bits establecidos distintos de O_NONBLOCK.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
mq_getattr (), mq_setattr () Seguridad de hilos MT-Safe

VERSIONES

En Linux, mq_getattr() y mq_setattr() son funciones de biblioteca superpuestas a la llamada del sistema mq_getsetattr(2).

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

EJEMPLOS

El siguiente programa se puede usar para mostrar los valores por defecto de mq_maxmsg y mq_msgsize que se asignan a una cola de mensajes creada con una llamada a mq_open(3) en la que el argumento attr es NULL. Aquí hay un ejemplo de ejecución del programa:


$ ./a.out /testq;
Número máximo de mensajes en cola:   10
Tamaño máximo del mensaje:             8192

Desde Linux 3.5, los siguientes archivos de /proc (descritos en mq_overview(7)) se pueden utilizar para controlar los valores por defecto:


$ uname -sr;
Linux 3.8.0
$ cat /proc/sys/fs/mqueue/msg_default;
10
$ cat /proc/sys/fs/mqueue/msgsize_default;
8192

Código fuente del programa

#include <err.h>
#include <fcntl.h>
#include <mqueue.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    mqd_t mqd;
    struct mq_attr attr;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s mq-name\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    mqd = mq_open(argv[1], O_CREAT | O_EXCL, 0600, NULL);
    if (mqd == (mqd_t) -1)
        err(EXIT_FAILURE, "mq_open");
    if (mq_getattr(mqd, &attr) == -1)
        err(EXIT_FAILURE, "mq_getattr");
    printf("Número máximo de mensajes en cola:   %ld\n", attr.mq_maxmsg);
    printf("Tamaño máximo del mensaje:             %ld\n", attr.mq_msgsize);
    if (mq_unlink(argv[1]) == -1)
        err(EXIT_FAILURE, "mq_unlink");
    exit(EXIT_SUCCESS);
}
