mq_close(3) Manual de funciones de biblioteca mq_close(3)

NOMBRE

mq_close - cerrar un descriptor de cola de mensajes

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <mqueue.h>
int mq_close(mqd_t mqdes);

DESCRIPCIÓN

mq_close() cierra el descriptor de cola de mensajes mqdes.

Si el proceso que llama ha adjuntado una solicitud de notificación (ver mq_notify(3)) a esta cola de mensajes a través de mqdes, entonces esta solicitud se elimina y otro proceso puede ahora adjuntar una solicitud de notificación.

VALOR DE RETORNO

En caso de éxito, mq_close() devuelve 0; en caso de error, devuelve -1, con errno establecido para indicar el error.

ERRORES

EBADF
El descriptor de cola de mensajes especificado en mqdes es inválido.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
mq_close () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Todas las colas de mensajes abiertas se cierran automáticamente al finalizar el proceso o al ejecutar execve(2).
