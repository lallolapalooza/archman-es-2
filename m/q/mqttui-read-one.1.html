NOMBRE

mqttui-read-one - Espera el primer mensaje en los temas dados y devuelve su carga útil a stdout

SINOPSIS

mqttui read-one [-r|--ignore-retained] [-p|--pretty] [-b|--broker] [-u|--username] [--password] [-i|--client-id] [--client-cert] [--client-key] [--insecure] [-h|--help] [TEMA]

DESCRIPCIÓN

Espera el primer mensaje en los temas dados y devuelve su carga útil a stdout.

Devuelve exactamente una carga útil del primer mensaje recibido en los temas dados. El tema del mensaje recibido se imprime en stderr. Esto significa que puedes manejar stdout y stderr por separado.

Esto puede ser útil para scripts para obtener la lectura de temperatura actual y enviarla a otro lugar:

`echo "La temperatura es $(mqttui read-one room/temp)"`

La salida es la carga útil exacta en su forma binaria. Esto podría ser ASCII / Unicode válido, pero también podría ser algo que no está destinado a ser mostrado en una terminal. Para un formato legible por humanos, usa `--pretty` o `mqttui log`.

OPCIONES

-r, --ignore-retained
No responder a un mensaje retenido al conectar, espera a que llegue otro mensaje.
-p, --pretty
Analiza la carga útil y la imprime en un formato bonito y legible.

Esto podría no ser útil para canalizar los datos.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
[TEMA] [predeterminado: #]
Temas a observar.
También se puede especificar con la variable de entorno MQTTUI_TOPIC.

CONEXIÓN MQTT

-b, --broker=URL [predeterminado: mqtt://localhost]
URL que representa cómo conectarse al broker MQTT.

Ejemplos: `mqtt://localhost` `mqtt://localhost:1883` `mqtts://localhost` `mqtts://localhost:8883` `ws://localhost/path` `ws://localhost:9001/path` `wss://localhost/path` `wss://localhost:9001/path`

También se puede especificar con la variable de entorno MQTTUI_BROKER.
-u, --username=CADENA
Nombre de usuario para acceder al broker mqtt.

Acceso anónimo cuando no se proporciona.

También se puede especificar con la variable de entorno MQTTUI_USERNAME.
--password=CADENA
Contraseña para acceder al broker mqtt.

Considere usar una conexión con TLS al broker. De lo contrario, la contraseña se transportará en texto plano.

Pasar la contraseña a través de la línea de comandos es inseguro, ya que la contraseña puede ser leída del historial. Deberías pasarla a través de una variable de entorno.

También se puede especificar con la variable de entorno MQTTUI_PASSWORD.
-i, --client-id=CADENA
Especifica el ID del cliente con el que conectarse.
También se puede especificar con la variable de entorno MQTTUI_CLIENTID.
--client-cert=RUTA_ARCHIVO
Ruta al archivo del certificado de cliente TLS.

Se usa junto con --client-key para habilitar la autenticación del cliente TLS. El archivo debe ser un certificado X.509 codificado en DER serializado a PEM.

También se puede especificar con la variable de entorno MQTTUI_CLIENT_CERTIFICATE.
--client-key=RUTA_ARCHIVO
Ruta a la clave privada del cliente TLS.

Se usa junto con --client-cert para habilitar la autenticación del cliente TLS. El archivo debe ser un archivo ASN.1 codificado en DER en formato PKCS#8 serializado a PEM.

También se puede especificar con la variable de entorno MQTTUI_CLIENT_PRIVATE_KEY.
--insecure
Permitir conexiones TLS inseguras.
