mqttui(1) Manual de Comandos Generales mqttui(1)

NOMBRE

mqttui - Suscríbete a un tema MQTT o publica algo rápidamente desde la terminal

SINOPSIS

mqttui [--payload-size-limit] [-b|--broker] [-u|--username] [--password] [-i|--client-id] [--client-cert] [--client-key] [--insecure] [-h|--help] [-V|--version] [TEMA] [subcomandos]

DESCRIPCIÓN

Suscríbete a un tema MQTT o publica algo rápidamente desde la terminal

OPCIONES

--payload-size-limit=TAMAÑO_LIMITE_PAYLOAD [por defecto: 8000]
Recorta los payloads almacenados al tamaño dado.

Los payloads más grandes que esto se recortan y no se inspeccionan en busca de formatos como JSON o MessagePack. Solo se puede ver el principio hasta la cantidad de bytes especificada. Aumentar este valor puede resultar en un mayor consumo de memoria, especialmente con el tiempo.

También se puede especificar con la variable de entorno MQTTUI_PAYLOAD_SIZE_LIMIT.
-h, --help
Imprime la ayuda (ver un resumen con '-h')
-V, --version
Imprime la versión
[TEMA] [por defecto: #]
Tema a observar
También se puede especificar con la variable de entorno MQTTUI_TOPIC.

CONEXIÓN MQTT

-b, --broker=URL [por defecto: mqtt://localhost]
URL que representa cómo conectarse al broker MQTT.

Ejemplos: `mqtt://localhost` `mqtt://localhost:1883` `mqtts://localhost` `mqtts://localhost:8883` `ws://localhost/path` `ws://localhost:9001/path` `wss://localhost/path` `wss://localhost:9001/path`

También se puede especificar con la variable de entorno MQTTUI_BROKER.
-u, --username=CADENA
Nombre de usuario para acceder al broker mqtt.

Acceso anónimo si no se proporciona.

También se puede especificar con la variable de entorno MQTTUI_USERNAME.
--password=CADENA
Contraseña para acceder al broker mqtt.

Considere usar una conexión con TLS al broker. De lo contrario, la contraseña se transportará en texto plano.

Pasar la contraseña a través de la línea de comandos es inseguro, ya que la contraseña se puede leer del historial. Debería pasarla a través de una variable de entorno.

También se puede especificar con la variable de entorno MQTTUI_PASSWORD.
-i, --client-id=CADENA
Especificar el ID del cliente con el que conectarse
También se puede especificar con la variable de entorno MQTTUI_CLIENTID.
--client-cert=RUTA_ARCHIVO
Ruta al archivo del certificado de cliente TLS.

Se usa junto con --client-key para habilitar la autenticación del cliente TLS. El archivo debe ser un certificado X.509 codificado en DER serializado a PEM.

También se puede especificar con la variable de entorno MQTTUI_CLIENT_CERTIFICATE.
--client-key=RUTA_ARCHIVO
Ruta a la clave privada del cliente TLS.

Se usa junto con --client-cert para habilitar la autenticación del cliente TLS. El archivo debe ser un archivo ASN.1 codificado en DER en formato PKCS#8 serializado a PEM.

También se puede especificar con la variable de entorno MQTTUI_CLIENT_PRIVATE_KEY.
--insecure
Permitir conexiones TLS inseguras

SUBCOMANDOS

mqttui-clean-retained(1)
Limpiar mensajes retenidos del broker
mqttui-log(1)
Registrar valores de los temas suscritos en stdout
mqttui-read-one(1)
Esperar el primer mensaje en los temas dados y devolver su payload a stdout
mqttui-publish(1)
Publicar un valor rápidamente
