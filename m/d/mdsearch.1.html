NOMBRE

mdsearch - Ejecutar búsquedas de Spotlight contra un servidor SMB

SINOPSIS

mdfine {servidor} {nombredelrecurso} {consulta} [-p, --ruta=CADENA] [-L, --en-vivo] [-?|--ayuda] [--uso] [-d|--nivel-depuracion=NIVELDEPURACION] [--depurar-salida-estandar] [--archivo-configuracion=ARCHIVO] [--opcion=nombre=valor] [-l|--base-nombre-registro=REGISTROBASE] [--informe-fugas] [--informe-fugas-completo] [-R|--resolucion-nombres=ORDENRESOLUCIONNOMBRES] [-O|--opciones-socket=OPCIONES SOCKET] [-m|--protocolo-maximo=MAXPROTOCOLO] [-n|--nombre-netbios=NOMBRENETBIOS] [--ambito-netbios=AMBITO] [-W|--grupo-trabajo=GRUPOTRABAJO] [--dominio=DOMINIO] [-U|--usuario=[DOMINIO/]USUARIO[%CONTRASEÑA]] [-N|--sin-contraseña] [--contraseña=CADENA] [--hash-nt-contraseña] [-A|--archivo-autenticacion=ARCHIVO] [-P|--contraseña-maquina] [--dn-enlace-simple=DN] [--usar-kerberos=deseado|requerido|desactivado] [--usar-krb5-ccache=CCACHE] [--usar-winbind-ccache] [--proteccion-cliente=firmar|cifrar|desactivar] [-V|--version]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(1).

mdsearch es una utilidad simple para ejecutar búsquedas de Spotlight contra un servidor SMB que ejecuta el servicio RPC de Spotlight mdssvc.

OPCIONES

servidor

El nombre o la dirección IP del servidor SMB al que conectarse.

nombredelrecurso

El nombre de un recurso compartido en el servidor.

consulta

La sintaxis de la expresión de consulta es una forma simplificada de globbing de nombres de archivo familiar a los usuarios de shell. Las consultas tienen el siguiente formato:

atributo=="valor"

Para consultas contra un servidor Samba con Spotlight habilitado usando el backend de Elasticsearch, la lista de atributos de metadatos admitidos se proporciona en el archivo de mapeo de atributos JSON, que normalmente se instala en /usr/share/samba/mdssvc/elasticsearch_mappings.json

-p RUTA, --ruta=RUTA

Ruta en el lado del servidor para buscar, por defecto es "/"

-L, --en-vivo

La consulta permanece en ejecución.

-?|--ayuda

Imprime un resumen de las opciones de la línea de comandos.

--uso

Muestra un breve mensaje de uso.

-d|--nivel-depuracion=nivel

nivel es un entero de 0 a 10. El valor por defecto si este parámetro no se especifica es 1 para aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán los errores críticos y las advertencias graves. El nivel 1 es un nivel razonable para el funcionamiento diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados para ser utilizados únicamente por desarrolladores y generan ENORMES cantidades de datos de registro, la mayor parte de los cuales es extremadamente críptica.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro nivel de registro en el archivo /etc/samba/smb.conf.

--depurar-salida-estandar

Esto redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes están registrando en STDERR.

--archivo-configuracion=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información en este archivo puede ser general para cliente y servidor o solo proporcionar opciones específicas del cliente como cliente smb cifrar. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración por defecto se determina en tiempo de compilación.

--opcion=<nombre>=<valor>

Establece la opción smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluyen un espacio, envuelva todo --opcion=nombre=valor entre comillas.

-l|--base-nombre-registro=directorio de registro

Nombre del directorio base para los archivos de registro/depuración. Se agregará la extensión ".nombreprograma" (por ejemplo, log.smbclient, log.smbd, etc.). El archivo de registro nunca es eliminado por el cliente.

--informe-fugas

Habilita el informe de fugas de talloc al salir.

--informe-fugas-completo

Habilita el informe completo de fugas de talloc al salir.

-V|--version

Imprime el número de versión del programa.

-U|--usuario=[DOMINIO\]USUARIO[%CONTRASEÑA]

Establece el nombre de usuario SMB o el nombre de usuario y la contraseña.

Si no se especifica %CONTRASEÑA, se le pedirá al usuario. El cliente primero verificará la variable de entorno USUARIO (que también puede contener la contraseña separada por un %), luego la variable LOGNAME (que no puede contener una contraseña) y si alguna existe, se utilizará el valor. Si estas variables de entorno no se encuentran, se puede usar el nombre de usuario encontrado en una caché de credenciales de Kerberos.

Una tercera opción es usar un archivo de credenciales que contenga la contraseña en texto plano del nombre de usuario y la contraseña. Esta opción se proporciona principalmente para scripts en los que el administrador no desea pasar las credenciales en la línea de comandos o a través de variables de entorno. Si se utiliza este método, asegúrese de que los permisos del archivo restrinjan el acceso de usuarios no deseados. Vea la opción -A para más detalles.

Tenga cuidado al incluir contraseñas en scripts o al pasar valores proporcionados por el usuario en la línea de comandos. Por seguridad, es mejor dejar que la herramienta cliente de Samba solicite la contraseña si es necesario, u obtener la contraseña una vez con kinit.

Aunque Samba intentará limpiar la contraseña del título del proceso (como se ve en ps), esto ocurre después del inicio y, por lo tanto, está sujeto a una condición de carrera.

-N|--sin-contraseña

Si se especifica, este parámetro suprime la solicitud normal de contraseña del cliente al usuario. Esto es útil al acceder a un servicio que no requiere contraseña.

A menos que se especifique una contraseña en la línea de comandos o se defina este parámetro, el cliente solicitará una contraseña.

Si se especifica una contraseña en la línea de comandos y esta opción también está definida, la contraseña de la línea de comandos se ignorará silenciosamente y no se utilizará ninguna contraseña.

--contraseña

Especifica la contraseña en la línea de comandos.

Tenga cuidado al incluir contraseñas en scripts o al pasar valores proporcionados por el usuario en la línea de comandos. Por seguridad, es mejor dejar que la herramienta cliente de Samba solicite la contraseña si es necesario, u obtener la contraseña una vez con kinit.

Si no se especifica --contraseña, la herramienta comprobará la variable de entorno PASSWD, seguida de PASSWD_FD, que se espera que contenga un número de descriptor de archivo (FD) abierto.

Finalmente, comprobará PASSWD_FILE (que contiene una ruta de archivo a abrir). El archivo solo debe contener la contraseña. ¡Asegúrese de que los permisos del archivo restrinjan el acceso de usuarios no deseados!

Aunque Samba intentará limpiar la contraseña del título del proceso (como se ve en ps), esto ocurre después del inicio y, por lo tanto, está sujeto a una condición de carrera.

--hash-nt-contraseña

La contraseña proporcionada es el hash NT.

-A|--archivo-autenticacion=nombre de archivo

Esta opción le permite especificar un archivo desde el cual leer el nombre de usuario y la contraseña utilizados en la conexión. El formato del archivo es: 
nombre de usuario = <valor>
contraseña = <valor>
dominio   = <valor>

¡Asegúrese de que los permisos del archivo restrinjan el acceso de usuarios no deseados!

-P|--contraseña-maquina

Utiliza la contraseña de cuenta de máquina almacenada.

--dn-enlace-simple=DN

DN a utilizar para un enlace simple.

--usar-kerberos=deseado|requerido|desactivado

Este parámetro determina si las herramientas cliente de Samba intentarán autenticarse mediante Kerberos. Para la autenticación Kerberos, debe utilizar nombres DNS en lugar de direcciones IP al conectarse a un servicio. Por defecto, las herramientas cliente de Samba intentarán utilizar la caché de credenciales Kerberos predeterminada (ccache). En caso de que la ccache no exista o se haya especificado la opción -U|--usuario, los clientes le pedirán que introduzca una contraseña y obtendrán un ticket Kerberos (kinit) para usted. Si desea utilizar una caché de credenciales Kerberos alternativa, utilice la opción --usar-krb5-ccache.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro cliente usar kerberos en el archivo /etc/samba/smb.conf.

--usar-krb5-ccache=CCACHE

Especifica la ubicación de la caché de credenciales para la autenticación Kerberos.
