MDB_STAT(1) Manual de Comandos Generales MDB_STAT(1)

NOMBRE

mdb_stat - Herramienta de estado del entorno LMDB

SINOPSIS

mdb_stat [-V] [-e] [-f[f[f]]] [-n] [-r[r]] [-a | -s subdb]  envpath

DESCRIPCIÓN

La utilidad mdb_stat muestra el estado de un entorno LMDB.

OPCIONES

-V
Escribe el número de versión de la biblioteca en la salida estándar y sale.
-e
Muestra información sobre el entorno de la base de datos.
-f
Muestra información sobre la lista de libres del entorno. Si se proporciona -ff, resume cada entrada de la lista de libres. Si se proporciona -fff, muestra la lista completa de IDs de página en la lista de libres.
-n
Muestra el estado de una base de datos LMDB que no utiliza subdirectorios.
-r
Muestra información sobre la tabla de lectores del entorno. Muestra el ID de proceso, el ID de hilo y el ID de transacción para cada ranura de lector activa. El ID de proceso y el ID de transacción están en decimal, el ID de hilo está en hexadecimal. El ID de transacción se muestra como "-" si el lector no tiene actualmente una transacción de lectura abierta. Si se proporciona -rr, comprueba si hay entradas obsoletas en la tabla de lectores y las borra. La tabla de lectores se imprimirá de nuevo después de que se realice la comprobación.
-a
Muestra el estado de todas las subbases de datos en el entorno.
-s subdb
Muestra el estado de una subbase de datos específica.

DIAGNÓSTICOS

El estado de salida es cero si no se producen errores. Los errores resultan en un estado de salida distinto de cero y un mensaje de diagnóstico escrito en la salida de error estándar.
