mdb_dump(1)

Paquete: lmdb

MDB_DUMP(1) Manual de comandos generales MDB_DUMP(1)

NOMBRE

mdb_dump - Herramienta de exportación de entornos LMDB

SINOPSIS

mdb_dump [-V] [-f archivo] [-l] [-n] [-p] [-a | -s subdb]  rutaenv

DESCRIPCIÓN

La utilidad mdb_dump lee una base de datos y escribe su contenido en la salida estándar utilizando un formato de texto plano portable entendido por la utilidad mdb_load(1).

OPCIONES

-V
Escribe el número de versión de la biblioteca en la salida estándar y sale.
-f archivo
Escribe en el archivo especificado en lugar de la salida estándar.
-l
Lista las bases de datos almacenadas en el entorno. Solo se listarán los nombres, no se generará ninguna salida de datos.
-n
Exporta una base de datos LMDB que no utiliza subdirectorios.
-p
Si los caracteres de las claves o los elementos de datos son caracteres imprimibles (según se define en isprint(3)), los imprime directamente. Esta opción permite a los usuarios utilizar editores de texto y herramientas estándar para modificar el contenido de las bases de datos.

Nota: diferentes sistemas pueden tener diferentes nociones sobre qué caracteres se consideran imprimibles, y las bases de datos exportadas de esta manera pueden ser menos portátiles a sistemas externos.

-a
Exporta todas las subbases de datos del entorno.
-s subdb
Exporta una subbase de datos específica. Si no se especifica ninguna base de datos, solo se exporta la base de datos principal.

DIAGNÓSTICOS

El estado de salida es cero si no ocurren errores. Los errores resultan en un estado de salida distinto de cero y un mensaje de diagnóstico escrito en la salida de error estándar.

La exportación y recarga de bases de datos que utilizan funciones de comparación definidas por el usuario resultarán en nuevas bases de datos que utilizan las funciones de comparación predeterminadas. En este caso es muy probable que la base de datos recargada quede dañada más allá de la reparación, no permitiendo ni el almacenamiento ni la recuperación de registros.

La única solución alternativa disponible es modificar el código fuente de la utilidad mdb_load(1) para cargar la base de datos utilizando las funciones de comparación correctas.
