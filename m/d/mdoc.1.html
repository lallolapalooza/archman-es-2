mdoc(1) Manual de comandos generales mdoc(1)

NOMBRE

mdoc - Herramienta de gestión de documentación de Mono

SINOPSIS

mdoc comando [opciones] [argumentos]

DESCRIPCIÓN GENERAL

mdoc es un sistema de gestión de documentación basado en ensamblados.

mdoc permite crear y actualizar stubs de documentación basados en el contenido de un ensamblado. No se basa en la documentación encontrada dentro del código fuente.

Las ventajas son:

*
Legibilidad del código. Una buena documentación es frecuentemente (a) verbosa y (b) llena de ejemplos. (A modo de comparación, compara la documentación de Microsoft .NET Framework, que a menudo es una página o más de documentación para cada miembro, con la documentación de JavaDoc, que a menudo puede ser una frase para cada miembro).

Insertar buena documentación en el código fuente puede hinchar frecuentemente el archivo fuente, ya que la documentación puede ser más larga que el método real que se está documentando.

*
Localización. Los formatos de documentación en código fuente (como csc /doc) no tienen soporte para múltiples idiomas humanos. Si necesitas soportar más de un idioma humano con fines de documentación, mdoc es útil ya que permite que la salida de cada idioma resida en su propio directorio, y mdoc puede agregar tipos/miembros para cada directorio de documentación separado.
*
Administración. No es raro tener equipos de documentación y desarrollo separados. También es posible que el equipo de documentación tenga una experiencia mínima con el lenguaje de programación que se está utilizando. En tales circunstancias, la documentación en línea no es deseable ya que el equipo de documentación podría insertar inadvertidamente un error en el código fuente al actualizar la documentación. Alternativamente, es posible que no desees que el equipo de documentación tenga acceso al código fuente por razones de seguridad. mdoc permite que la documentación se mantenga *completamente* separada y distinta del código fuente utilizado para crear el ensamblado.

La documentación puede generarse utilizando el comando mdoc update:

    mdoc update -o docs/en ProjectName.dll
Una vez que se hayan generado los stubs de documentación (y esperemos que más tarde se llenen con documentación real), hay tres formas de ver la documentación:
*
Para generar un directorio simple de páginas HTML (un archivo HTML por tipo), usa mdoc export-html: 
    mdoc export-html -o /srv/www/htdocs/ProjectName docs/en
*
Para usar una aplicación web ASP.NET para mostrar las fuentes, consulta: http://anonsvn.mono-project.com/source/trunk/monodoc/engine/web/.

Desde un checkout de fuentes de monodoc, puedes hacer esto:

    cd engine
    make web
Esto utilizará xsp(1) para servir la aplicación web ASP.NET; visita http://localhost:8080/ para ver la documentación.
*
Para utilizar el navegador de documentación monodoc(1), primero debes *ensamblar* la documentación: 
    mdoc assemble -o ProjectName docs/en
El comando anterior crea los archivos ProjectName.tree y ProjectName.zip. Se debe proporcionar un archivo adicional ProjectName.sources que describe dónde en el sistema de ayuda se debe vincular la documentación; es un archivo XML muy simple, como este: 
    <?xml version="1.0"?>
    <monodoc>
      <source provider="ecma" basefile="ProjectName"
        path="various" />
    </monodoc>
El archivo de configuración anterior describe que la documentación está en formato ECMA, que el nombre base del archivo es ProjectName y que debe vincularse en la parte "various" del árbol de documentación. Si deseas ver los diversos nodos definidos en la documentación, puedes consultar el archivo monodoc.xml que normalmente se instala en /usr/lib/monodoc/monodoc.xml.

Una vez que tengas todos los archivos requeridos (.zip, .tree y .sources) puedes instalarlos en el sistema con el siguiente comando:

    cp ProjectName.tree ProjectName.zip ProjectName.source \
      `pkg-config monodoc --variable sourcesdir`
Lo anterior copiará los archivos al directorio que Monodoc ha registrado; es posible que necesites permisos de root para hacerlo. El directorio real se devuelve con la invocación de pkg-config.

COMANDOS MDOC

mdoc assemble

Compila la documentación para su uso dentro del navegador monodoc(1).

Consulta la página del manual de mdoc-assemble(1) para obtener detalles.

mdoc export-html

Exporta la documentación a una estructura de directorios de archivos HTML.

Consulta la página del manual de mdoc-export-html(1) para obtener detalles.

mdoc export-msxdoc

Exporta la documentación al formato de Documentación XML de Microsoft de un solo archivo.

Consulta la página del manual de mdoc-export-msxdoc(1) para obtener detalles.

mdoc help

Muestra la ayuda interna para un comando dado. 
    mdoc help assemble

es equivalente a:

    mdoc assemble --help

Se pueden listar varios subcomandos a la vez:

    mdoc help assemble export-html update validate

mdoc update

Actualiza la documentación, agregando y eliminando miembros basándose en un ensamblado de referencia.

Consulta la página del manual de mdoc-update(1) para obtener detalles.

mdoc validate

Valida la documentación contra el esquema de documentación de Mono.

Consulta la página del manual de mdoc-validate(1) para obtener detalles.
