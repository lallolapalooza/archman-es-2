MD2HTML(1) Manual de Comandos Generales MD2HTML(1)

NOMBRE

md2html - convertir Markdown a HTML

SINOPSIS

md2html [OPCIÓN]... [ARCHIVO]

OPCIONES

Opciones generales:

-o, --output=ARCHIVO_SALIDA
Escribir la salida en ARCHIVO_SALIDA en lugar de stdout(3)
-f, --full-html
Generar un documento HTML completo, incluyendo la cabecera
-s, --stat
Medir el tiempo de análisis de la entrada
-h, --help
Mostrar ayuda y salir
-v, --version
Mostrar la versión y salir

Opciones de dialecto Markdown:

--commonmark
CommonMark (por defecto)
--github
Github Flavored Markdown

Nota: las opciones de dialecto son equivalentes a alguna combinación de las banderas siguientes.

Opciones de extensión Markdown:

--fcollapse-whitespace
Colapsar espacios en blanco no triviales
--fverbatim-entities
No traducir entidades
--fpermissive-atx-headers
Permitir encabezados ATX sin espacio delimitador
--fpermissive-url-autolinks
Permitir autovinculos de URL sin delimitadores "<" y ">"
--fpermissive-www-autolinks
Permitir autovinculos WWW sin ningún esquema (ej. "www.ejemplo.com")
--fpermissive-email-autolinks
Permitir autovinculos de correo electrónico sin "<", ">" y "mailto:"
--fpermissive-autolinks
Habilitar las 3 opciones de autovinculos permisivos anteriores
--fhard-soft-breaks
Forzar que todos los saltos de línea suaves actúen como saltos de línea duros
--fno-indented-code
Deshabilitar bloques de código indentados
--fno-html-blocks
Deshabilitar bloques HTML crudos
--fno-html-spans
Deshabilitar fragmentos HTML crudos
--fno-html
Igual que --fno-html-blocks --fno-html-spans
--ftables
Habilitar tablas
--fstrikethrough
Habilitar fragmentos de tachado
--ftasklists
Habilitar listas de tareas
