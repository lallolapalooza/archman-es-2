mdir - mostrar directorio de MSDOS

Descripción

El comando mdir se utiliza para mostrar un directorio de MS-DOS. Su sintaxis es:

mdir [-/] [-f] [-w] [-a] [-b] archivo_msdos [ archivos_msdos...]

Mdir muestra el contenido de los directorios de MS-DOS, o las entradas de algunos archivos de MS-DOS.

Mdir soporta las siguientes opciones de línea de comandos:

/ 
Salida recursiva, igual que la opción -s de MS-DOS
w 
Salida ancha. Con esta opción, mdir imprime los nombres de archivo a lo ancho de la página sin mostrar el tamaño del archivo o la fecha de creación.
a 
También lista los archivos ocultos.
f 
Rápido. No intente averiguar el espacio libre. En discos más grandes, averiguar la cantidad de espacio libre lleva una cantidad de tiempo no trivial, ya que toda la FAT debe leerse y escanearse. La bandera -f evita este paso. Esta bandera no es necesaria en sistemas de archivos FAT32, que almacenan el tamaño explícitamente.
b 
Listado conciso. Lista cada nombre de directorio o nombre de archivo, uno por línea (incluida la extensión del nombre de archivo). Este modificador no muestra información de encabezado ni resumen. Solo se muestra una lista de rutas separadas por saltos de línea.

Ocurre un error si un componente de la ruta no es un directorio.

*

    ./configure; make html

Para generar una copia en info (navegable usando el modo info de emacs), ejecute: 
    ./configure; make info
