NOMBRE

mdb2ppdb - Convierte el formato de archivo de depuración de Mono (MDB) al formato de archivo Portable Program Database (PPDB)

SINOPSIS

mdb2ppdb entrada.mdb salida.ppdb

DESCRIPCIÓN

mdb2ppdb es una herramienta que se puede usar para convertir información de depuración almacenada en el formato de archivo de depuración de Mono (archivos con la extensión .mdb) que utilizaban tanto el compilador de Mono como las herramientas que usaban el formato de archivo de depuración System.Reflection.Emit de Mono en Unix, al nuevo formato de depuración Portable Program Database (archivos con la extensión .ppdb).
