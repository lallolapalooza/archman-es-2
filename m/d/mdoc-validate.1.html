mdoc-validate(1) Manual de comandos generales mdoc-validate(1)

NOMBRE

mdoc validate - Valida documentos XML contra un esquema

SINOPSIS

mdoc validate [OPCIONES]* RUTAS+

DESCRIPCIÓN

mdoc validate valida las RUTAS especificadas contra un esquema de formato especificado.

OPCIONES

--formato=FORMATO
El formato de documentación contra el cual validar las RUTAS. Los formatos admitidos incluyen: ecma.

Consulte la sección FORMATOS a continuación para obtener más información sobre estos formatos.

El formato predeterminado (si no se especifica ninguno) es ecma.

-h, -?, --ayuda
Muestra un mensaje de ayuda y sale.

FORMATOS

Se admiten los siguientes formatos de documentación:

ecma

El Formato de Documentación ECMA de Mono valida toda la salida generada por mdoc-update(1) contra un esquema XML, incluyendo los archivos index.xml, ns-*.xml y NamespaceName/TypeName.xml.

Consulte mdoc(5) para obtener detalles sobre este formato de archivo.

EJEMPLOS

Para validar la salida de mdoc-update(1) almacenada dentro de un directorio (y toda la documentación dentro de ese directorio, recursivamente), use:

    mdoc validate /ruta/a/docs/ecma
