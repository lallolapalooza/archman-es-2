MD2(3) Manual de funciones de biblioteca MD2(3)

NOMBRE

MD2Init, MD2Update, MD2Pad, MD2Final, MD2Transform, MD2End, MD2File, MD2FileChunk, MD2Data — calcular el resumen de mensajes "MD2" de RSA Data Security, Inc.

BIBLIOTECA

Biblioteca de soporte para resúmenes de mensajes (MD4, MD5, etc.) (libmd, -lmd)

SINOPSIS

#include <sys/types.h>
#include <md2.h>

void
MD2Init(MD2_CTX *context);

void
MD2Update(MD2_CTX *context, const uint8_t *data, size_t len);

void
MD2Pad(MD2_CTX *context);

void
MD2Final(uint8_t digest[MD2_DIGEST_LENGTH], MD2_CTX *context);

void
MD2Transform(uint32_t state[4], uint8_t block[MD2_BLOCK_LENGTH]);

char *
MD2End(MD2_CTX *context, char *buf);

char *
MD2File(const char *filename, char *buf);

char *
MD2FileChunk(const char *filename, char *buf, off_t offset, off_t length);

char *
MD2Data(const uint8_t *data, size_t len, char *buf);

DESCRIPCIÓN

Las funciones MD2 calculan una suma de verificación criptográfica de 128 bits (resumen) para cualquier número de bytes de entrada. Una suma de verificación criptográfica es una función hash unidireccional, es decir, no se puede encontrar (excepto mediante búsqueda exhaustiva) la entrada correspondiente a una salida determinada. El resultado neto es una "huella digital" de los datos de entrada, que no revela la entrada real.

MD2 es el más lento, MD4 es el más rápido y MD5 está en un punto intermedio. MD2 solo se puede usar para Privacy-Enhanced Mail. MD4 ha sido criticado por ser demasiado débil, por lo que MD5 se desarrolló en respuesta como "MD4 con cinturones de seguridad". MD4 y MD5 han sido vulnerados; solo deben usarse cuando sea necesario por compatibilidad con versiones anteriores. Los ataques a MD4 y MD5 son del tipo de encontrar "colisiones", es decir, múltiples entradas que dan el mismo valor hash; aún es poco probable que un atacante pueda determinar la entrada original exacta dado un valor hash.

Las funciones MD2Init(), MD2Update() y MD2Final() son las funciones principales. Asigna un MD2_CTX, lo inicializa con MD2Init(), procesa los datos con MD2Update() y finalmente extrae el resultado usando MD2Final().

La función MD2Pad() se puede usar para aplicar relleno al resumen del mensaje como en MD2Final(), pero el contexto actual aún se puede usar con MD2Update().

La función MD2Transform() es utilizada por MD2Update() para procesar bloques de 512 bits y constituye el núcleo del algoritmo. La mayoría de los programas deberían usar la interfaz proporcionada por MD2Init(), MD2Update() y MD2Final() en lugar de llamar MD2Transform() directamente.

MD2End() es un envoltorio para MD2Final() que convierte el valor de retorno en una cadena ASCII de MD2_DIGEST_STRING_LENGTH caracteres (incluido el '\0' de terminación) que representa los 128 bits en hexadecimal.

MD2File() calcula el resumen de un archivo y utiliza MD2End() para devolver el resultado. Si el archivo no se puede abrir, se devuelve un puntero nulo.

MD2FileChunk() se comporta como MD2File() pero calcula el resumen solo para esa porción del archivo que comienza en offset y continúa durante length bytes o hasta el final del archivo, lo que ocurra primero. Se puede especificar una length cero para leer hasta el final del archivo. Se ignorará una length o offset negativa. MD2Data() calcula el resumen de un fragmento de datos en memoria y utiliza MD2End() para devolver el resultado.

Al usar MD2End(), MD2File(), MD2FileChunk() o MD2Data(), el argumento buf puede ser un puntero nulo, en cuyo caso la cadena devuelta se asigna con malloc(3) y posteriormente debe liberarse explícitamente usando free(3) después de su uso. Si el argumento buf no es nulo, debe apuntar a al menos MD2_DIGEST_STRING_LENGTH caracteres de espacio en el búfer.

NAME

md2, md4, md5 - message digest functions

LIBRARY

libmd

SYNOPSIS

#include <sys/types.h>
#include <md2.h>
#include <md4.h>
#include <md5.h>

unsigned char *
MD2_160(const unsigned char *d, unsigned len);

unsigned char *
MD4_128(const unsigned char *d, unsigned len);

unsigned char *
MD5_128(const unsigned char *d, unsigned len);

DESCRIPTION

These functions compute a cryptographic hash of the data specified by the argument d and len. MD2 produces a 160-bit (20-byte) message digest. MD4 and MD5 produce 128-bit (16-byte) message digests.

The functions return a pointer to a static array of unsigned char containing the message digest. This array will be overwritten by subsequent calls to any of the md2, md4, or md5 functions.

These functions are not thread-safe.

HISTORY

These functions appeared in OpenBSD 2.0 and NetBSD 1.3.

AUTHORS

The original MD2 routines were developed by RSA Data Security, Inc., and published in the above references. This code is derived from a public domain implementation written by Colin Plumb.

The MD2End(), MD2File(), MD2FileChunk(), and MD2Data() helper functions are derived from code written by Poul-Henning Kamp.

BUGS

Collisions have been found for the full versions of both MD4 and MD5. The use of sha2(3) is recommended instead.
