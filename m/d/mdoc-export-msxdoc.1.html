NOMBRE

mdoc export-msxdoc - Convertir XML de mdoc(5) a Documentación XML de Microsoft

SINOPSIS

mdoc export-msxdoc [OPCIÓN]* DIRECTORIOS

DESCRIPCIÓN

mdoc export-msxdoc crea Documentación XML de Microsoft (tal como la produce csc /doc) a partir de los archivos XML de documentación formateados en mdoc(5) dentro de DIRECTORIOS.

OPCIONES

-o, --out=ARCHIVO
El archivo XML a generar.

Si no se especifica, se utilizará un conjunto de archivos que coincida con los valores de //AssemblyInfo/AssemblyName dentro de la documentación.

Use - para escribir a la salida estándar.

-h, -?, --help
Mostrar un mensaje de ayuda y salir.
