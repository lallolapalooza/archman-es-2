NOMBRE

MD5Init, MD5Update, MD5Pad, MD5Final, MD5Transform, MD5End, MD5File, MD5FileChunk, MD5Data — calcular el resumen de mensaje "MD5" de RSA Data Security, Inc.

BIBLIOTECA

Biblioteca de soporte para resumen de mensajes (MD4, MD5, etc.) (libmd, -lmd)

SINOPSIS

void
MD5Pad(MD5_CTX *contexto);

void
MD5Final(uint8_t digest[MD5_DIGEST_LENGTH], MD5_CTX *contexto);

void
MD5Transform(uint32_t state[4], uint8_t block[MD5_BLOCK_LENGTH]);

char *
MD5End(MD5_CTX *contexto, char *buf);

char *
MD5File(const char *filename, char *buf);

char *
MD5FileChunk(const char *filename, char *buf, off_t offset, off_t length);

char *
MD5Data(const uint8_t *datos, size_t len, char *buf);

DESCRIPCIÓN

Las funciones MD5 calculan una suma de verificación criptográfica de 128 bits (resumen) para cualquier número de bytes de entrada. Una suma de verificación criptográfica es una función hash unidireccional, es decir, no se puede encontrar (excepto por búsqueda exhaustiva) la entrada que corresponde a una salida particular. El resultado neto es una "huella digital" de los datos de entrada, que no revela la entrada real.

MD2 es el más lento, MD4 es el más rápido y MD5 está en un punto intermedio. MD2 solo se puede usar para Privacy-Enhanced Mail. MD4 ha sido criticado por ser demasiado débil, por lo que MD5 se desarrolló en respuesta como "MD4 con cinturones de seguridad". MD4 y MD5 han sido vulnerados; solo deben usarse donde sea necesario por compatibilidad retroactiva. Los ataques tanto a MD4 como a MD5 son de la naturaleza de encontrar "colisiones", es decir, múltiples entradas que se resumen al mismo valor; todavía es poco probable que un atacante pueda determinar la entrada original exacta dada un valor de resumen.

Las funciones MD5Init(), MD5Update() y MD5Final() son las funciones centrales. Asigne un MD5_CTX, inicialícelo con MD5Init(), recorra los datos con MD5Update() y, finalmente, extraiga el resultado usando MD5Final().

La función MD5Pad() se puede usar para aplicar relleno al resumen del mensaje como en MD5Final(), pero el contexto actual aún se puede usar con MD5Update().

La función MD5Transform() es utilizada por MD5Update() para resumir bloques de 512 bits y forma el núcleo del algoritmo. La mayoría de los programas deben usar la interfaz proporcionada por MD5Init(), MD5Update() y MD5Final() en lugar de llamar a MD5Transform() directamente.

MD5End() es un envoltorio para MD5Final() que convierte el valor de retorno en una cadena ASCII de MD5_DIGEST_STRING_LENGTH caracteres (incluyendo el '\0' terminador) que representa los 128 bits en hexadecimal.

MD5File() calcula el resumen de un archivo y utiliza MD5End() para devolver el resultado. Si el archivo no se puede abrir, se devuelve un puntero nulo.

MD5FileChunk() se comporta como MD5File() pero calcula el resumen solo para esa porción del archivo que comienza en el offset y continúa durante length bytes o hasta el final del archivo, lo que ocurra primero. Se puede especificar una length cero para leer hasta el final del archivo. Se ignorarán una length o offset negativos. MD5Data() calcula el resumen de un fragmento de datos en memoria y utiliza MD5End() para devolver el resultado.

Al usar MD5End(), MD5File(), MD5FileChunk() o MD5Data(), el argumento buf puede ser un puntero nulo, en cuyo caso la cadena devuelta se asigna con malloc(3) y posteriormente debe desasignarse explícitamente usando free(3) después de su uso. Si el argumento buf no es nulo, debe apuntar a al menos MD5_DIGEST_STRING_LENGTH caracteres de espacio en el búfer.

DESCRIPTION

The MD5 algorithm is a cryptographically secure message-digest algorithm that produces a 128-bit hash value. The MD5 functions described here are based on RFC 1321.

The MD5 algorithm has been known to be vulnerable to collision attacks. Therefore, it is no longer considered secure. Use of SHA-2 or other secure hash algorithms is recommended.

The functions MD5_Init(), MD5_Update(), and MD5_End() are the core MD5 functions.

The MD5_Init() function initializes an MD5 context structure ctx.

The MD5_Update() function updates the hash state by processing len bytes of data starting at data.

The MD5_End() function finishes the hash computation. It appends padding to the message and writes the 16-byte (128-bit) message digest to the buffer pointed to by buf. The buffer should be at least 32 hexadecimal characters long. If buf is NULL, MD5_End() will return a pointer to a statically allocated buffer. Otherwise, it returns the value of buf. The caller is responsible for freeing this static buffer if it is used.

The MD5_Transform() function performs a single 64-byte MD5 transformation. The state parameter is a pointer to the four 32-bit state variables, and block is a pointer to the 64-byte message block.

The MD5_Update_CBC() function is a variant of MD5_Update() that uses Cipher Block Chaining (CBC) mode. It is not part of the standard MD5 algorithm and should generally not be used.

The helper functions MD5File(), MD5FileChunk(), and MD5Data() provide a simpler interface for computing MD5 message digests.

The MD5Data() function computes the MD5 digest of len bytes of data from data. If digest is not NULL, the 16-byte digest is written into the buffer pointed to by digest. Otherwise, a pointer to a statically allocated buffer is returned. The caller is responsible for freeing this static buffer if it is used.

The MD5File() function computes the MD5 digest of the entire file specified by filename. If digest is not NULL, the 16-byte digest is written into the buffer pointed to by digest. Otherwise, a pointer to a statically allocated buffer is returned. The caller is responsible for freeing this static buffer if it is used.

The MD5FileChunk() function computes the MD5 digest of a portion of the file specified by filename. The digest is computed for length bytes starting at offset bytes from the beginning of the file. If digest is not NULL, the 16-byte digest is written into the buffer pointed to by digest. Otherwise, a pointer to a statically allocated buffer is returned. The caller is responsible for freeing this static buffer if it is used.

The digest is returned as a 32-byte hexadecimal ASCII string.

AUTHORS

The original MD5 routines were developed by RSA Data Security, Inc., and published in the above references. This code is derived from a public domain implementation written by Colin Plumb.

The MD5End(), MD5File(), MD5FileChunk(), and MD5Data() helper functions are derived from code written by Poul-Henning Kamp.

BUGS

Collisions have been found for the full versions of both MD4 and MD5. The use of sha2(3) is recommended instead.
