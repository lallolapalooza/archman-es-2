mdoc-export-html(1) Manual General de Comandos mdoc-export-html(1)

NOMBRE

mdoc export-html - Convierte XML mdoc(5) a HTML.

SINOPSIS

mdoc export-html [OPCIÓN]* DIRECTORIOS

DESCRIPCIÓN

mdoc export-html crea archivos HTML a partir de los archivos XML de documentación con formato mdoc(5) dentro de DIRECTORIOS.

OPCIONES

--plantilla-predeterminada
Escribe la XSLT predeterminada a stdout.
--ext=EXTENSIÓN
La extensión de archivo a usar para los archivos creados.

Esto por defecto es html.

--forzar-actualizacion
Genera archivos nuevos siempre. Si no se especifica, solo generará un nuevo archivo de salida si el archivo de documentación de origen es más nuevo que el archivo de salida de destino.
-s, --salida=DIRECTORIO
Escribe los archivos creados dentro del directorio DIRECTORIO.
--plantilla=ARCHIVO
Un archivo XSLT para usar en la generación de los archivos creados.

Si no se especifica, usa la plantilla producida por --volcar-plantilla.

Consulta la sección FORMATO DE PLANTILLA más abajo para más información.

--con-perfil=PERFIL
Procesa solo tipos y miembros dentro del perfil .NET PERFIL. Puede ser especificado varias veces. Si no se especifica, se procesan todos los tipos y miembros, independientemente de la versión.

Los perfiles válidos son:

monotouch
net_1_0
net_1_1
net_2_0
net_3_0
net_3_5
net_4_0
silverlight
--con-version=VERSION
Procesa solo tipos y miembros dentro de la versión de ensamblado VERSION. Puede ser especificado varias veces. Si no se especifica, se procesan todos los tipos y miembros, independientemente de la versión.

VERSION es una versión de ensamblado, p. ej. 2.0.5.0.

-h, -?, --ayuda
Muestra un mensaje de ayuda y sale.

FORMATO DE PLANTILLA

El archivo de plantilla es una XSLT que necesita procesar el siguiente documento XML de entrada:

  <Page>
    <CollectionTitle>Título de la Colección</CollectionTitle>
    <PageTitle>Título de la Página</PageTitle>
    <Summary>Resumen de la Página</Summary>
    <Signature>Declaración del Tipo</Signature>
    <Remarks>Observaciones del Tipo</Remarks>
    <Members>Miembros del Tipo</Members>
    <Copyright>Copyright de la Documentación</Copyright>
  </Page>

El HTML generado también utiliza varias clases CSS. Puedes usar la plantilla nombrada create-default-style encontrada dentro de la salida de --volcar-plantilla para generar estas clases, o definir explícitamente las siguientes clases CSS:

.CollectionTitle
.PageTitle
.Summary
.Signature
.Remarks
.Members
.Copyright
.Section
.SectionBox
.NamespaceName
.NamespaceSummary
.MemberName
.MemberSignature
.MemberBox
.Subsection
.SubsectionBox
.SignatureTable
.EnumerationsTable
.CodeExampleTable
.MembersListing
.TypesListing
.InnerSignatureTable
.TypePermissionsTable

ENLACES HTML

Todos los miembros dentro del archivo HTML tienen un atributo id para permitir enlazar a un miembro específico. El valor del atributo id es el ID de Cadena del miembro especificado.

Consulta la sección FORMATO DE CREF de mdoc(5) para más información.
