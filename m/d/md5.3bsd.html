NOMBRE

MD5Init, MD5Update, MD5Pad, MD5Final, MD5Transform, MD5End, MD5File, MD5FileChunk, MD5Data — calcular el resumen de mensaje ``MD5'' de RSA Data Security, Inc.

BIBLIOTECA

char *

char *

char *
MD5Data(const uint8_t *datos, size_t len, char *buf);

DESCRIPCIÓN

Las funciones MD5 calculan una suma de verificación criptográfica de 128 bits (resumen) para cualquier número de bytes de entrada. Una suma de verificación criptográfica es una función hash unidireccional, es decir, no se puede encontrar (excepto por búsqueda exhaustiva) la entrada que corresponde a una salida particular. El resultado neto es una “huella digital” de los datos de entrada, que no revela la entrada real.

MD4 ha sido vulnerado; solo debe usarse donde sea necesario por compatibilidad retroactiva. MD5 aún no (1999-02-11) ha sido vulnerado, pero ataques recientes han sembrado dudas sobre sus propiedades de seguridad. Los ataques a MD4 y MD5 son de la naturaleza de encontrar “colisiones” — es decir, múltiples entradas que se resumen al mismo valor; todavía es poco probable que un atacante pueda determinar la entrada original exacta dado un valor hash.

Las funciones MD5Init(), MD5Update(), y MD5Final() son las funciones principales. Asigne un MD5_CTX, inicialícelo con MD5Init(), ejecútelo sobre los datos con MD5Update(), y finalmente extraiga el resultado usando MD5Final().

La función MD5Pad() puede usarse para aplicar relleno al resumen del mensaje como en MD5Final(), pero el contexto actual aún se puede usar con MD5Update().

La función MD5Transform() es utilizada por MD5Update() para resumir bloques de 512 bits y forma el núcleo del algoritmo. La mayoría de los programas deberían usar la interfaz proporcionada por MD5Init(), MD5Update() y MD5Final() en lugar de llamar a MD5Transform() directamente.

MD5End() es un envoltorio para MD5Final() que convierte el valor de retorno en una cadena ASCII de longitud MD5_DIGEST_STRING_LENGTH (incluyendo el '\0' terminador) que representa los 128 bits en hexadecimal.

MD5File() calcula el resumen de un archivo, y usa MD5End() para devolver el resultado. Si el archivo no se puede abrir, se devuelve un puntero nulo.

MD5FileChunk() se comporta como MD5File() pero calcula el resumen solo para esa porción del archivo comenzando en el offset y continuando durante longitud bytes o hasta el final del archivo, lo que ocurra primero. Se puede especificar una longitud cero para leer hasta el final del archivo. Se ignorará una longitud o offset negativa. MD5Data() calcula el resumen de un fragmento de datos en memoria, y usa MD5End() para devolver el resultado.

Al usar MD5End(), MD5File(), MD5FileChunk(), o MD5Data(), el argumento buf puede ser un puntero nulo, en cuyo caso la cadena devuelta se asigna con malloc(3) y posteriormente debe ser liberada explícitamente usando free(3) después de su uso. Si el argumento buf no es nulo, debe apuntar a al menos MD5_DIGEST_STRING_LENGTH caracteres de espacio de búfer.

md5.3bsd - Manual Page

NAME

MD5 - computation of the MD5 message digest

LIBRARY

Message digest (libmd)

SYNOPSIS

#include <md5.h>
u_char *
MD5(const u_char *data, size_t len, u_char *digest);
int
MD5Init(MD5_CTX *context);
int
MD5Update(MD5_CTX *context, const u_char *data, size_t len);
int
MD5Final(u_char digest[MD5_DIGEST_LENGTH], MD5_CTX *context);
u_char *
MD5End(MD5_CTX *context, u_char *result);
u_char *
MD5File(const char *filename, u_char *digest);
u_char *
MD5FileChunk(const char *filename, u_char *digest, off_t offset, off_t length);
u_char *
MD5Data(const char *data, size_t len, u_char *digest);

DESCRIPTION

The MD5() function computes the MD5 message digest of the len bytes of data pointed to by data. The digest is a 16-byte value. If digest is not NULL, the digest is stored in the buffer pointed to by digest. Otherwise, the digest is stored in a static buffer and a pointer to that buffer is returned. The static buffer is overwritten by subsequent calls to MD5(), MD5End(), MD5File(), MD5FileChunk(), or MD5Data().

The remaining functions provide an interface to the MD5 algorithm similar to the one provided by sha2(3). The MD5Init() function initializes an MD5_CTX structure. The MD5Update() function compresses len bytes of data. The MD5Final() function computes the digest from the buffer and zeroes out the MD5_CTX structure. The MD5End() function is similar to MD5Final() but also returns the computed digest in a static buffer, similar to MD5().

The MD5File() function computes the MD5 message digest of the file named filename. The digest is stored in the buffer pointed to by digest. If digest is NULL, a static buffer is used and returned. This is equivalent to calling MD5Init(), MD5Update() in a loop for the file contents, and MD5End().

The MD5FileChunk() function computes the MD5 message digest of the portion of the file named filename starting at offset and of size length. If length is -1, the rest of the file is used. Otherwise the digest is stored in the buffer pointed to by digest. If digest is NULL, a static buffer is used and returned.

The MD5Data() function is a convenience function that computes the MD5 message digest of the len bytes of data pointed to by data. The digest is stored in the buffer pointed to by digest. If digest is NULL, the digest is stored in a static buffer and a pointer to that buffer is returned. This function is equivalent to calling MD5Init(), MD5Update(), and MD5End().

MD5Init(), MD5Update(), and MD5Final() are thread-safe.

SEE ALSO

sha2(3), rmd160(3), sha1(3)

HISTORY

These functions first appeared in OpenBSD 2.0.

AUTHORS

The original MD5 routines were developed by RSA Data Security, Inc., and published in the above references. This code is derived from a public domain implementation written by Colin Plumb.

The MD5End(), MD5File(), MD5FileChunk(), and MD5Data() helper functions are derived from code written by Poul-Henning Kamp.

BUGS

Collisions have been found for the full versions of both MD4 and MD5 as well as strong attacks against the SHA-0 and SHA-1 family. The use of sha2(3), or rmd160(3) is recommended instead.
