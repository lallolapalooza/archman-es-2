NOMBRE

mdassembler - Compilar documentación para usarla en el navegador monodoc

SINOPSIS

mdassembler OPCIONES* DIRECTORIOS+

DESCRIPCIÓN

mdassembler ha sido obsoleto por mdoc(1). Consulte la página del manual de mdoc-assemble(1).

mdassembler es un programa que crea archivos .tree y .zip para usarlos en el navegador de documentación monodoc.

Los archivos .tree y .zip se copian en el directorio sources de monodoc y residen con un archivo .source que es utilizado por monodoc para especificar dónde se debe mostrar la documentación. El atributo /monodoc/source/@basefile del archivo .source especifica el prefijo del nombre de archivo para los archivos de documentación. Este debe ser el mismo prefijo que se usa con el parámetro --out.

OPCIONES

--ecma
La documentación encontrada dentro de DIRECTORIOS está en formato de documentación Mono ECMA. Consulte la sección Formato de Documentación Mono ECMA más abajo.
--ecmaspec
La documentación encontrada dentro de DIRECTORIOS está en formato de documentación de Especificación ECMA. Consulte la sección Formato de Documentación de Especificación ECMA Mono más abajo.
--error
La documentación encontrada dentro de DIRECTORIOS está en formato de "error". Consulte la sección Formato de Documentación de Errores más abajo.
--help
Mostrar información de argumentos del programa.
--man
La documentación encontrada dentro de DIRECTORIOS está en formato de página man. Consulte la sección Formato de Documentación de Páginas Man más abajo.
-o, --out PREFIJO
Especificar el prefijo del archivo de salida. mdassembler crea los archivos PREFIJO.zip y PREFIJO.tree.
--simple
La documentación encontrada dentro de DIRECTORIOS está en formato "simple". Consulte la sección Formato de Documentación Simple más abajo.
--xhtml, --hb
La documentación encontrada dentro de DIRECTORIOS está en formato XHTML. Consulte la sección Formato de Documentación XHTML más abajo.

FORMATOS

Se admiten los siguientes formatos de documentación:

Formato de Documentación Mono ECMA

Un formato de documentación XML con un archivo por tipo.

Consulte la página del manual de mdoc(5) para más información.

Formato de Documentación de Especificación ECMA Mono

Este no es el formato que está buscando.

Este es el formato utilizado para representar el estándar ECMA-334 (C#) dentro de monodoc. No se utiliza para mostrar la documentación de la biblioteca de clases; para la documentación de la biblioteca de clases, utilice el formato --ecma.

Formato de Documentación de Errores

Se utiliza para presentar mensajes de error detallados y se usa en el árbol de "Referencia de Errores del Compilador C#" de monodoc. DIRECTORIOS no es un directorio, sino un archivo de configuración que contiene el XML:

    <ErrorProviderConfig>
        <FilesPath>../../mcs/errors</FilesPath>
        <Match>cs????*.cs</Match>
        <ErrorNumSubstringStart>2</ErrorNumSubstringStart>
        <ErrorNumSubstringLength>4</ErrorNumSubstringLength>
        <FriendlyFormatString>CS{0:0###}</FriendlyFormatString>
    </ErrorProviderConfig>

/ErrorProviderConfig/FilesPath especifica dónde buscar los archivos, /ErrorProviderConfig/Match especifica el patrón de nombre de archivo a buscar dentro de /ErrorProviderConfig/FilesPath, /ErrorProviderConfig/ErrorNumSubstringStart y /ErrorProviderConfig/ErrorNumSubstringLength controlan qué parte del nombre de archivo se utiliza como número de error, y /ErrorProviderConfig/FriendlyFormatString controla el formato/visualización del nodo en el árbol de monodoc.

Para cada archivo encontrado, se convierte a HTML con coloreado de sintaxis C# aplicado.

Formato de Documentación Simple

Convierte archivos de texto a HTML traduciendo cada nueva línea en un elemento <br> de HTML.

Formato de Documentación de Páginas Man

Convierte páginas man a HTML para su visualización.

Formato de Documentación XHTML

Copia el archivo XHTML tal cual.

EJEMPLOS

Para instalar tu documentación para usarla con monodoc:

Crear un archivo PREFIX.source
con el contenido: 
<?xml version="1.0"?>
<monodoc>
  <source provider="FORMAT" basefile="PREFIX" path="PATH"/>
</monodoc>
donde FORMAT es el formato de documentación contenido en el archivo PREFIX.tree, por ejemplo, ecma o simple. PREFIX es el nombre base de los archivos .tree y .zip que crea mdassembler. PATH es la "ruta" en el árbol de monodoc que debe contener la documentación. Consulte el archivo @prefix@/lib/monodoc/monodoc.xml para obtener una lista de los valores de PATH (los valores //node/@name).

Véase también: http://www.mono-project.com/docs/tools+libraries/tools/monodoc/generating-documentation/

Crear tu documentación
Consulte también la página del manual de monodocer(1), por ejemplo, 
monodocer -assembly:foo.dll -path:foo/en
Ensamblar la documentación
mdassembler --ecma foo/en PREFIJO
Asegúrese de usar el mismo PREFIJO aquí que el que utilizó anteriormente.
Instalar la documentación usando el comando
cp PREFIJO.source PREFIJO.tree PREFIJO.zip \
`pkg-config monodoc --variable=sourcesdir`
(¡Note las comillas invertidas usadas en el comando pkg-config!) Esto copia los archivos .source, .tree y .zip al directorio sources de monodoc, lo que permitirá a monodoc mostrar la documentación.

NAME

mdassembler - a tool for assembling and disassembling meta-data for .NET.

SYNOPSIS

mdassembler [options] input_file

DESCRIPTION

The mdassembler is a tool for assembling and disassembling meta-data for .NET. It can be used to extract meta-data from an assembly into a text file, and to re-assemble it back into an assembly.
