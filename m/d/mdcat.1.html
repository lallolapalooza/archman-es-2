NOMBRE

mdcat - renderiza Markdown CommonMark a terminales de texto

SINOPSIS

mdcat [OPCIONES] [ARCHIVO]...

mdless [OPCIONES] [ARCHIVO]...

DESCRIPCIÓN

mdcat renderiza archivos ARCHIVOs de Markdown en dialecto CommonMark a terminales de texto con formato sofisticado. Si no se proporciona ningún ARCHIVO, o si ARCHIVO es '-', lee de la entrada estándar.

Si se invoca como mdless, utiliza automáticamente un paginador para mostrar la salida, véase abajo.

Soporte CommonMark y de terminal

mdcat soporta toda la sintaxis básica de CommonMark más algunas extensiones, resalta la sintaxis en bloques de código y muestra enlaces en línea e incluso imágenes en línea en algunos programas de terminal. En iTerm2 también añade marcas de salto para los encabezados de sección.

Ver la sección Soporte de terminal abajo para una lista de programas de terminal soportados y sus características.

Detección de terminal

Para habilitar extensiones de formato como imágenes en línea, mdcat necesita detectar el programa de terminal, comprobando las siguientes variables de entorno en el orden dado:

1.$TERM
2.$TERM_PROGRAM
3.$TERMINOLOGY

Para algunos terminales mdcat también comprueba $TERM_PROGRAM_VERSION para determinar si el terminal soporta el conjunto de características esperado.

Ver la sección ENTORNO abajo para una descripción detallada de cada variable de entorno.

Paginación

mdcat puede renderizar la salida en un paginador; este es el comportamiento por defecto cuando se ejecuta como mdless. Las variables de entorno $MDCAT_PAGER y $PAGER controlan el paginador utilizado.

Tenga en cuenta que los paginadores comunes no soportan códigos propietarios de terminal para, por ejemplo, soporte de imágenes, por lo que mdcat recurre a formato ANSI puro cuando la paginación está habilitada. En particular, esto deshabilita todo el soporte de imágenes que depende de códigos de escape propietarios.

Soporte de imágenes

En iTerm2, kitty, Terminology, WezTerm y VSCode (1.80 o más reciente) mdcat imprime imágenes en línea. mdcat soporta la mayoría de los formatos de píxeles estándar por defecto.

mdcat ignora silenciosamente imágenes de más de 100 MiB, bajo la suposición de que imágenes de ese tamaño no pueden renderizarse razonablemente en una terminal.

Soporte SVG

En Terminology, mdcat también renderiza imágenes SVG, utilizando el soporte incorporado de Terminology.

En iTerm2, kitty, VSCode y WezTerm, mdcat renderiza imágenes SVG en gráficos de píxeles utilizando la biblioteca resvg https://github.com/RazrFalcon/resvg. Actualmente esta biblioteca solo soporta SVG 1, y solo el subconjunto estático del mismo; ver Soporte SVG https://github.com/RazrFalcon/resvg#svg-support para detalles. Si bien esto es suficiente para la mayoría de las imágenes SVG simples, las imágenes SVG complejas pueden fallar al renderizarse o renderizarse de forma incompleta.

Para archivos SVG locales, mdcat se basa en la extensión del archivo para identificar las imágenes SVG. Para imágenes remotas de URLs HTTP(S), mdcat inspecciona la cabecera Content-Type para identificar las imágenes SVG.

Soporte HTTP/HTTPS

mdcat recupera imágenes de URLs HTTP(S) para renderizarlas si el terminal subyacente soporta la renderización de imágenes; pasa --local para deshabilitar esto y forzar a mdcat a usar solo imágenes del sistema de archivos local. En este caso, las imágenes remotas se renderizan como hipervínculos.

Tenga en cuenta que algunos terminales (por ejemplo, Terminology) renderizan directamente imágenes desde URLs y no requieren que mdcat recupere primero los datos de la imagen. En este caso, --local no tiene efecto: mdcat siempre pasa la URL al terminal y deja que el terminal se encargue de recuperarla.

OPCIONES

-p, --paginate

Pagina la salida de mdcat con un paginador como less.

Nota: Al paginar, mdcat solo utiliza formato ANSI estándar e hipervínculos, pero no imágenes ni otros códigos de formato propietarios, ya que los programas paginadores normalmente no soportan ninguno de estos.

Este es el comportamiento por defecto cuando se ejecuta como mdless.

-P, --no-pager

No paginar la salida.

Este es el comportamiento por defecto cuando se ejecuta como mdcat.

-c, --no-colour

Deshabilitar todos los colores y otros estilos.

--ansi

Omitir la detección de terminal y usar solo formato ANSI.

--columns=COLUMNAS

Número máximo de columnas a usar para la salida de texto. Por defecto es el tamaño del terminal subyacente si se omite.

-l, --local

No acceder a recursos remotos.

--fail

Fallar inmediatamente en el primer ARCHIVO que no se pueda leer. Por defecto, mdcat continúa con el siguiente archivo.

--detect-terminal

Detecta el programa de terminal, imprime su nombre y sale.

--completions=SHELL

Genera completados para SHELL a la salida estándar y sale. 
_SHELL_ puede ser uno de `bash`, `zsh`, `fish`, `powershell` o `elvish`.

-h, --help

Muestra un mensaje de ayuda al usuario y sale.

-V, --version

Muestra la versión de mdcat y sale. El indicador largo también incluye información sobre las características integradas.

ESTADO DE SALIDA

mdcat sale con 0 si no ocurrió ningún error, o 1 en caso contrario.

Si se ejecuta como mdless o si se proporciona --paginate y el paginador falla al iniciarse, mdcat sale con 128.

ENTORNO

TERM


mdcat primero verifica esta variable para identificar el programa de terminal (ver sección Detección de terminal). Comprende los siguientes valores.
•wezterm: WezTerm. Tenga en cuenta que WezTerm establece $TERM a xterm-256color por defecto, y solo usa wezterm para $TERM si se configura explícitamente para hacerlo.
•xterm-kitty: kitty
•xterm-ghostty: Ghostty

Para todos los demás valores, mdcat procede a comprobar $TERM_PROGRAM.

TERM_PROGRAM

Si $TERM no identifica de forma concluyente el programa de terminal, mdcat comprueba esta variable a continuación. Comprende los siguientes valores:
•iTerm.app: iTerm2
•WezTerm: WezTerm
•vscode: Terminal integrado de VSCode, pero solo si $TERM_PROGRAM_VERSION indica una versión suficiente para soportar todas las características requeridas.
•ghostty: Ghostty

Para todos los demás valores, mdcat procede a comprobar $TERMINOLOGY.

TERM_PROGRAM_VERSION

Si $TERM_PROGRAM es vscode, mdcat comprueba esta variable para determinar si VSCode tiene una versión suficiente para soportar todas las características requeridas.

TERMINOLOGY

Si esta variable es 1, mdcat asume que el terminal es Terminol

NOMBRE

mdcat — convierte el marcado a texto para la terminal

SINOPSIS

mdcat [ OPTION… ] [ FILE… ]

DESCRIPCIÓN

El marcado puede ser usado para formatear texto en la web, pero también en la terminal. Con mdcat puedes renderizar archivos de marcado en tu terminal usando estilo CommonMark.

En comparación con el comando cat, mdcat puede renderizar archivos markdown a la terminal. Si el formato de la terminal lo permite, mdcat usa colores, seudo-imágenes y enlaces para presentar el contenido del marcado de la forma más agradable posible.

El renderizado usa el conjunto de reglas de CommonMark Spec y los enlaces se muestran usando el protocolo OSC 8.

La salida se hace a STDOUT. Si no se proporcionan archivos, mdcat lee de STDIN. Si se proporcionan múltiples archivos, se concatenan.

Se puede especificar un paginador a través de la variable de entorno $MDCAT_PAGER o $PAGER, o con la opción --paginate.

OPCIONES

mdcat sigue la sintaxis estándar de GNU para la línea de comandos, con opciones largas que empiezan por dos guiones (‐‐) y opciones cortas que empiezan por un guion (‐).

Las opciones se listan a continuación, las cuales se aplican a todos los archivos de entrada:

‐‐no-bold
Desactiva el uso de formato en negrita.
‐‐no-italic
Desactiva el uso de formato en cursiva.
‐‐no-strike
Desactiva el uso de formato de tachado.
‐‐no-underline
Desactiva el uso de formato de subrayado.
‐‐no-colour
Desactiva el uso de colores. Equivalente a mdcat sin colores.
‐‐width=NUM
Establece el ancho de la terminal a NUM caracteres. Por defecto, mdcat intenta determinar el ancho de la terminal automáticamente.
‐‐height=NUM
Establece la altura de la terminal a NUM caracteres. Por defecto, mdcat intenta determinar la altura de la terminal automáticamente.
‐‐image-cache-dir=DIR
Establece el directorio del caché de imágenes a DIR. Por defecto, el caché se almacena en $XDG_CACHE_HOME/mdcat/images o ~/.cache/mdcat/images.
‐‐theme=THEME
Selecciona un tema de colores predefinido. Los temas disponibles son dark, light, y default.
‐‐no-images
Desactiva la renderización de imágenes. Esto también deshabilita el uso de protocolos específicos de la terminal para renderizar imágenes.
‐‐paginate
Usa un paginador para ver la salida. El paginador se determina a través de la variable de entorno $MDCAT_PAGER o $PAGER.
‐‐help
Muestra un mensaje de ayuda y sal.
‐‐version
Muestra información sobre la versión y sal.

ESTADO DE SALIDA

Cero si todo fue bien, y no-cero si ocurrió un error.

AMBIENTE

Las siguientes variables de entorno pueden afectar el comportamiento de mdcat:

COLORTERM

Si está configurada a truecolor o 24bit, mdcat intentará usar secuencias de escape de 24 bits para colorear. Si no está configurada, mdcat asumirá que la terminal solo es capaz de formateo ANSI estándar de 4 bits.

TERM

Esta variable se utiliza para la detección de la terminal, para determinar qué capacidades de formateo (incluyendo el uso de imágenes en línea) están disponibles.

Si mdcat no puede detectar la terminal (por ejemplo, si la variable TERM no está configurada o apunta a un tipo de terminal desconocido), se desactivará la detección de la terminal y se asumirá que la terminal solo es capaz de formateo ANSI estándar.

COLUMNS

El número de columnas de caracteres en la pantalla.

mdcat solo usa esta variable si falla al consultar el tamaño de la terminal subyacente.

ROWS

El número de filas de caracteres en la pantalla.

mdcat solo usa esta variable si falla al consultar el tamaño de la terminal subyacente.

MDCAT_PAGER

El programa paginador a usar para mdless o si se proporciona --paginate.

El programa paginador debe soportar secuencias básicas de formato ANSI, como por ejemplo less -r.

El valor de esta variable está sujeto a la división de palabras similar a la shell. **No** está sujeto a ningún tipo de expansión o sustitución (por ejemplo, expansión de parámetros, sustitución de procesos, etc.).

Si se establece a un valor vacío, mdcat deshabilita completamente la paginación.

PAGER

El programa paginador a usar si $MDCAT_PAGER no está definido.

Sujeto a las mismas reglas que $MDCAT_PAGER.

Si tanto $PAGER como $MDCAT_PAGER no están definidos, se usa less -r como paginador.

http_proxy, https_proxy, HTTPS_PROXY, all_proxy, ALL_PROXY, no_proxy, NO_PROXY

Configuraciones de proxy para solicitudes HTTP realizadas por mdcat para recuperar recursos remotos.

mdcat usa curl para sus transferencias de red, por lo tanto, consulta curl(1) para estas variables.

MDCAT_LOG

Directivas para configurar la salida de información de trazado.

Consulta https://docs.rs/tracing-subscriber/latest/tracing_subscriber/struct.EnvFilter.html#directives para detalles de sintaxis; usa MDCAT_LOG=trace para información completa de depuración, y MDCAT_LOG=pulldown_cmark_mdcat::render=trace para trazar solo el renderizado.

CONFORMANDO A

Soporte, extensiones y limitaciones de CommonMark

mdcat soporta la versión 0.30 de CommonMark Spec https://spec.commonmark.org/, además de Listas de tareas <https://github.github.com/gfm/#task-list-items-extension-> y tachado <https://github.github.com/gfm/#strikethrough-extension->, a través de pulldown-cmark https://github.com/raphlinus/pulldown-cmark.

mdcat aún no soporta notas al pie. El soporte para tablas <https://github.github.com/gfm/#tables-extension-> es limitado; el ajuste de texto y el marcado en línea en celdas de tabla aún no son compatibles. mdcat analiza bloques HTML y etiquetas en línea pero no aplica un renderizado especial; imprime HTML tal cual.

Soporte de terminal

A menos que se proporcione --no-colour, mdcat traduce texto CommonMark a texto con formato ANSI, con códigos de formato SGR estándar e hipervínculos. Utiliza formato en negrita (SGR 1), cursiva (SGR 3) y tachado (SGR 9), y las secuencias de color estándar de 4 bits, así como OSC 8 https://gist.github.com/egmontkob/eb114294efbcd5adb1944c9f3cb5feda para hipervínculos. No utiliza secuencias de color de 8 o 24 bits, aunque esto puede cambiar en futuras versiones.

Además, utiliza códigos de escape propietarios si detecta uno de los siguientes emuladores de terminal (ver secciones Detección de terminal y AMBIENTE para detalles):

•iTerm2 https://iterm2.com/: Imágenes en línea (protocolo iTerm2 https://iterm2.com/documentation-images.html) y Marcas https://iterm2.com/documentation-escape-codes.html.
•kitty https://github.com/kovidgoyal/kitty: Imágenes en línea (protocolo de gráficos kitty https://sw.kovidgoyal.net/kitty/graphics-protocol.html).
•Terminology http://terminolo.gy: Imágenes en línea (protocolo terminology).
•WezTerm https://wezfurlong.org/wezterm/: Imágenes en línea (protocolo de gráficos kitty, ver arriba).
•VSCode https://code.visualstudio.com/ 1.80 o más reciente, terminal integrada: Imágenes en línea (protocolo iTerm2, ver arriba)

ERRORES

Por favor, reporte errores en https://github.com/swsnr/mdcat/issues.

Actualmente no proporciona medios para personalizar estilos y colores.

EJEMPLOS

mdcat hello world

Renderiza el marcado en hello, luego lee de la entrada estándar, y finalmente de world.

mdless hello

Renderiza el marcado desde hello a través de un paginador.
