NOMBRE

mfsclrarchive - Herramientas de gestión del modo de almacenamiento de archivo de MooseFS

SINOPSIS

mfschkarchive [-?] [-n|-h|-H|-k|-m|-g] OBJETO...

mfsclrarchive [-?] [-n|-h|-H|-k|-m|-g] OBJETO...

mfssetarchive [-?] [-n|-h|-H|-k|-m|-g] OBJETO...

DESCRIPCIÓN

Estas herramientas operan sobre el bit de archivo de un objeto del sistema de archivos (archivo, archivo especial o directorio). Este bit se establece automáticamente según la definición de la clase de almacenamiento (ARCH_DELAY). Cuando este bit está establecido, se utilizan las etiquetas ARCH_LABELS de la definición de la clase de almacenamiento; de lo contrario, se utilizan las etiquetas KEEP_LABELS.

mfschkarchive imprime el valor actual del bit de *archivo* del/los objeto(s) dado(s). Si el *OBJETO* dado es un *DIRECTORIO*, imprime el valor actual del bit de *archivo* de todos los archivos contenidos (recursivamente).

mfsclrarchive y mfssetarchive borran/establecen el bit de *archivo* actual del/los objeto(s) dado(s). Al igual que en mfschkarchive, si el *OBJETO* es un *DIRECTORIO*, esta herramienta funciona recursivamente.

OPCIONES

La mayoría de las herramientas de MooseFS utilizan las opciones -n, -h, -H, -k, -m y -g para seleccionar el formato de los números impresos. -n causa que se impriman números exactos, -h utiliza prefijos binarios (Ki, Mi, Gi como 2^10, 2^20 etc.) mientras que -H utiliza prefijos SI (k, M, G como 10^3, 10^6 etc.). -k, -m y -g muestran números planos respectivamente en kibis (kilo binario - 1024), mebis (mega binario - 1024^2) y gibis (giga binario - 1024^3). Lo mismo se puede lograr configurando la variable de entorno MFSHRFORMAT a: 0 (números exactos), 1 o h (prefijos binarios), 2 o H (prefijos SI), 3 o h+ (números exactos y prefijos binarios), 4 o H+ (números exactos y prefijos SI). El valor predeterminado es imprimir solo números exactos.

La opción -? muestra un mensaje de uso corto.
