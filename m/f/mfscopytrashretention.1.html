NOMBRE

mfstrashretention - herramientas de gestión de retención de basura de MooseFS

SINOPSIS

mfsgettrashretention [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO...

mfssettrashretention [-?] [-r] [-n|-h|-H|-k|-m|-g] TIEMPO[+|-] OBJETO...

mfscopytrashretention [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO_ORIGEN OBJETO...

DESCRIPCIÓN

Estas herramientas operan sobre el valor de retención de basura de un objeto del sistema de archivos (archivo, archivo especial o directorio), es decir, el tiempo que el archivo se conserva en el directorio especial basura antes de ser eliminado finalmente del sistema de archivos. La retención de basura debe ser un valor entero no negativo.

mfsgettrashretention imprime el valor actual de retención de basura del objeto(s) dado(s). La opción -r habilita el modo recursivo, que funciona como de costumbre para cada archivo dado, pero para cada directorio dado, además, imprime el valor actual de retención de basura de todos los objetos contenidos (archivos y directorios).

mfssettrashretention cambia el valor actual de retención de basura del objeto(s) dado(s). Si el nuevo valor se especifica en forma de TIEMPO+, el valor de retención de basura se incrementa a TIEMPO para los objetos con un valor de retención de basura menor y se mantiene sin cambios para el resto. De manera similar, si el nuevo valor se especifica como TIEMPO-, el valor de retención de basura se reduce a TIEMPO para los objetos con un valor de retención de basura mayor y se mantiene sin cambios para el resto. La opción -r habilita el modo recursivo. Estas herramientas se pueden usar en cualquier archivo, directorio o archivo eliminado (en la basura).

La herramienta mfscopytrashretention se puede usar para copiar el valor de retención de basura de un objeto a otro.

El parámetro TIEMPO se especifica como un valor de tipo general de tiempo, con la unidad mínima siendo horas y con la posibilidad adicional de añadir un signo + o - al final; para más detalles sobre el formato de tiempo, consulte TIEMPO

OPCIONES

La mayoría de las herramientas de MooseFS usan las opciones -n, -h, -H, -k, -m y -g para seleccionar el formato de los números impresos. -n hace que se impriman números exactos, -h usa prefijos binarios (Ki, Mi, Gi como 2^10, 2^20, etc.) mientras que -H usa prefijos SI (k, M, G como 10^3, 10^6, etc.). -k, -m y -g muestran números simples respectivamente en kibis (kilo binario - 1024), mebis (mega binario - 1024^2) y gibis (giga binario - 1024^3). Lo mismo se puede lograr estableciendo la variable de entorno MFSHRFORMAT a: 0 (números exactos), 1 o h (prefijos binarios), 2 o H (prefijos SI), 3 o h+ (números exactos y prefijos binarios), 4 o H+ (números exactos y prefijos SI). El valor predeterminado es imprimir solo números exactos.

La opción -? muestra un mensaje de uso corto.

NOTAS

TIEMPO

Para las variables de tiempo, su valor puede definirse como un número de segundos u horas (entero), dependiendo de la unidad mínima de la variable, o como un período de tiempo en uno de los dos formatos posibles:

primer formato: #.#T donde T es uno de: s-segundos, m-minutos, h-horas, d-días o w-semanas; las fracciones de la unidad mínima se redondearán al valor entero

segundo formato: #s#m#h#d#w, se pueden omitir cualquier número de definiciones, pero las definiciones restantes deben estar en orden (por lo tanto, #d#h#m es una definición válida, pero #m#h#d no lo es); rangos: s, m: 0 a 59, h: 0 a 23, d: 0 a 6, w es ilimitado y la primera definición también es siempre ilimitada (es decir, para #d#h#m, d será ilimitado)

Si la unidad mínima de una variable es mayor que segundos, no se aceptarán las unidades inferiores a la unidad mínima. Por ejemplo, una variable que tiene horas como unidad mínima no aceptará unidades s y m.

Ejemplos:

1.5d es lo mismo que 1d12h, es lo mismo que 36h

2.5w es lo mismo que 2w3d12h, es lo mismo que 420h; 2w84h no es un período de tiempo válido (h no es la primera definición, por lo que está limitado por el rango de 0 a 23)

HERENCIA

Cuando se crea un nuevo objeto en MooseFS, la retención de basura se hereda del directorio padre. Un objeto recién creado hereda siempre el valor actual de la retención de basura de su padre. Cambiar la retención de basura de un directorio no afecta a sus hijos ya creados. Para cambiar la retención de basura de un directorio y todos sus hijos, use la opción -r.
