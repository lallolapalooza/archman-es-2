MFT(1) Manual de comandos generales MFT(1)

NOMBRE

mft - traduce código Metafont o MetaPost a código TeX para una impresión bonita

SINOPSIS

mft [OPCIONES] nombre_archivo_mf[.mf|.mp]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa mft crea un archivo TeX a partir de un programa Metafont o MetaPost. Se encarga adecuadamente de los detalles tipográficos como el diseño de la página y el uso de sangría, cursiva, negrita, etc., como se ilustra en el libro Computer Modern Typefaces. Las convenciones especiales en los comentarios de Metafont y MetaPost le permiten controlar cosas que de otro modo no saldrían bien; la sección 1 del programa fuente de MFT en el informe Metafontware explica estas reglas.

El programa mft utiliza un archivo de cambios opcional (que funciona igual que los archivos de cambios para tangle(1) y weave(1)) y uno o varios archivos de estilo (que se anteponen a todo). Si no se especifica ningún archivo de estilo, se utiliza automáticamente el archivo de estilo plain.mft para Metafont (o mplain.mft para MetaPost).

Los archivos nombre_archivo_mf, nombre_archivo_cambios opcional y nombre_archivo_estilo se buscan utilizando las variables de entorno MFINPUTS (para Metafont) o MPINPUTS (para MetaPost) y MFTINPUTS si las ha establecido, o bien los valores predeterminados del sistema correspondientes.

El nombre del archivo TeX de salida se forma utilizando .tex en lugar de la extensión de nombre_archivo_mf.

OPCIONES

-cambio=nombre_archivo_cambios[.ch]
Aplica el archivo de cambios nombre_archivo_cambios a nombre_archivo_mf.
-metapost
Asume que nombre_archivo_mf es un archivo fuente de MetaPost (esta es la opción predeterminada si nombre_archivo_mf tiene la extensión .mp).
-estilo=nombre_archivo_estilo[.mft]
Utiliza el archivo de estilo nombre_archivo_estilo en lugar de plain.mft (o mplain.mft); esta opción se puede dar más de una vez.

ARCHIVOS

mftmac.tex
Macros de TeX utilizadas por la salida de mft.
plain.mft, mplain.mft
Archivos de estilo predeterminados.
cmbase.mft
Archivo de estilo para Computer Modern.

VER TAMBIÉN

mf(1), weave(1).
Donald E. Knuth, Computer Modern Typefaces (Volumen E de Computers and Typesetting), Addison-Wesley, 1986, ISBN 0-201-13446-2.
Donald E. Knuth et al., Metafontware.

AUTORES

Donald E. Knuth escribió el programa y lo adaptó a Unix con la ayuda de Pierre MacKay y la adaptación a Unix de weave por Howard Trickey y Pavel Curtis. El programa se publica en el informe técnico Metafontware, disponible en el TeX Users Group.
