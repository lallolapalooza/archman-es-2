NOMBRE

mfseattr - Herramientas de gestión de atributos extra de MooseFS

SINOPSIS

mfsgeteattr [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO...

mfsseteattr [-?] [-r] [-n|-h|-H|-k|-m|-g] -f NOMBRE_ATTR [-f NOMBRE_ATTR ...] OBJETO...

mfsdeleattr [-?] [-r] [-n|-h|-H|-k|-m|-g] -a | -f NOMBRE_ATTR [-f NOMBRE_ATTR ...] OBJETO...

mfscopyeattr [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO_ORIGEN OBJETO...

DESCRIPCIÓN

Estas herramientas se utilizan para obtener, establecer o eliminar algunos atributos extra (flags).

mfsgeteattr muestra los atributos extra de un objeto especificado. Si se utiliza la opción -r, la herramienta mostrará estadísticas de uso de todos los atributos en todo el árbol de directorios especificado por OBJETO.

mfsseteattr establece el atributo especificado por -f. La opción -f se puede usar varias veces, de modo que se puedan establecer varios atributos con un solo comando. Si se utiliza la opción -r, los atributos especificados se establecerán de forma recursiva.

mfsdeleattr elimina (borra) el atributo especificado por -f. La opción -f se puede usar varias veces, de modo que se puedan eliminar varios atributos con un solo comando. Alternativamente, la opción -a se puede usar para eliminar todos los atributos extra existentes. Si se utiliza la opción -r, los atributos especificados se eliminarán de forma recursiva.

mfscopyeattr copia el conjunto actual de atributos de OBJETO_ORIGEN a OBJETO. Esta es una copia exacta, por lo que se borrarán los atributos que OBJETO tenga pero OBJETO_ORIGEN no. Si se utiliza la opción -r, los atributos se copiarán recursivamente.

OPCIONES

ATRIBUTOS

noowner Este flag significa que el objeto en particular pertenece al usuario actual (uid y gid son iguales a los valores uid y gid del proceso que accede). Solo root (uid=0) ve el uid y gid reales.

noattrcache Este flag significa que los atributos de archivo estándar como uid, gid, modo, longitud, etc., no se almacenarán en la caché del kernel.

noentrycache Este flag es similar al anterior. Evita que las entradas de directorio se cacheaden en el kernel.

nodatacache Este flag significa que los datos nunca deben conservarse en la caché del kernel (similar al flag de apertura O_DIRECT).

snapshot Este flag significa que el objeto se creó a través de un comando mfsmakesnapshot

undeletable Este flag evita la eliminación (solo para administradores; no se hereda)

appendonly Un objeto con este flag solo se puede añadir, no se permiten eliminaciones ni otras modificaciones (solo para administradores; no se hereda)

immutable Este flag evita cualquier cambio en el objeto dado (solo para administradores; no se hereda)

OPCIONES GENERALES

La mayoría de las herramientas de MooseFS utilizan las opciones -n, -h, -H, -k, -m y -g para seleccionar el formato de los números impresos. -n imprime números exactos, -h utiliza prefijos binarios (Ki, Mi, Gi como 2^10, 2^20 etc.) mientras que -H utiliza prefijos SI (k, M, G como 10^3, 10^6 etc.). -k, -m y -g muestran números planos respectivamente en kibis (kilo binario - 1024), mebis (mega binario - 1024^2) y gibis (giga binario - 1024^3). Lo mismo se puede lograr configurando la variable de entorno MFSHRFORMAT a: 0 (números exactos), 1 o h (prefijos binarios), 2 o H (prefijos SI), 3 o h+ (números exactos y prefijos binarios), 4 o H+ (números exactos y prefijos SI). Por defecto, se imprimen solo números exactos.

La opción -? muestra un breve mensaje de uso.

NOTAS

HERENCIA

Cuando se crea un nuevo objeto en MooseFS, los atributos extra se heredan del directorio padre. Un objeto recién creado hereda siempre el conjunto actual de atributos de su padre. Cambiar un atributo de directorio no afecta a sus hijos ya creados. Para cambiar un atributo de un directorio y todos sus hijos, use la opción -r.
