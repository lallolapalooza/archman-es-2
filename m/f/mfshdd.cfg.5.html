NOMBRE

mfshdd.cfg - lista de directorios de almacenamiento de MooseFS para mfschunkserver

DESCRIPCIÓN

El archivo mfshdd.cfg contiene la lista de directorios (puntos de montaje) utilizados para el almacenamiento de MooseFS.

SINTAXIS

La sintaxis es:

[*|<|>|~]RUTA [OPCIONES DE ESPACIO]

Las líneas que comienzan con el carácter # se ignoran como comentarios.

La ruta puede ir precedida de uno o más caracteres especiales. Estos caracteres funcionan como opciones adicionales.

*
significa que este disco (disco duro) está "marcado para eliminación" y todos los datos se replicarán en otros discos duros, generalmente en otros servidores de fragmentos.
<
significa que todos los datos de este disco duro deben moverse a otros discos duros locales.
>
significa que todos los datos de otros discos duros locales deben moverse a este disco duro.
~
significa que un cambio significativo (más del 10% en menos de un minuto) en el número total de bloques no marcará este disco como dañado (útil para sistemas de archivos comprimidos).

RUTA es la ruta al punto de montaje del directorio de almacenamiento, generalmente un disco duro individual.

OPCIONES DE ESPACIO permiten definir límites en el espacio utilizado y alterar el informe de uso del disco. Una OPCIÓN DE ESPACIO puede ser:

un límite de espacio positivo, que indica una definición de límite de espacio (es decir, solo esta cantidad de espacio en la ruta indicada debe utilizarse para el almacenamiento de fragmentos)
un límite de espacio negativo, que indica una definición de espacio reservado (es decir, al menos esta cantidad de espacio siempre debe quedar libre en la ruta indicada)
un signo igual '=', opcionalmente seguido de un indicador de límite de espacio

El límite de espacio puede ser una cantidad de espacio definida (formato: [0-9]*(.[0-9]*)?([kMGTPE]|[KMGTPE]i)?B?) o un porcentaje del tamaño total del dispositivo.

Un signo igual indica que un disco está "compartido" con otro proceso (ya sea otro proceso de servidor de fragmentos o un proceso no relacionado) y la cantidad de espacio utilizada en el disco no es necesariamente indicativa de la cantidad de espacio utilizada por los fragmentos. Además, se puede definir un indicador de límite de espacio. El porcentaje indica cuántos por ciento del espacio disponible en el disco se considerará disponible para el servidor de fragmentos. El tamaño indica cuánta cantidad exacta de espacio se considerará disponible para el servidor de fragmentos. Si el porcentaje o el tamaño son negativos, entonces definimos la cantidad de espacio no disponible en su lugar.

La presencia o ausencia de una OPCIÓN DE ESPACIO cambia la forma en que el servidor de fragmentos calcula el espacio disponible y utilizado en una ruta determinada.

Definamos 3 valores base:
total_hdd - tamaño total del dispositivo, según lo devuelto por statvfs
avail_hdd - espacio total disponible, según lo devuelto por statvfs
calc_size - espacio utilizado (suma del uso del disco de los fragmentos)

Cuando no se define ninguna OPCIÓN DE ESPACIO, el espacio total y disponible se informa de la siguiente manera:

- total reportado = total_hdd
- disponible reportado = avail_hdd

De lo contrario, el espacio disponible se calcula utilizando las siguientes fórmulas:

1. Con espacio reservado constante (límite de espacio negativo -X)
- disponible reportado = total_hdd - X - calc_size (o cero si X + calc_size > total_hdd)

2. Con porcentaje de espacio reservado (límite de espacio negativo -X%)
- disponible reportado = total_hdd - total_hdd*X/100 - calc_size (o cero si total_hdd*X/100 + calc_size > total_hdd)

3. Con límite de espacio constante (límite de espacio positivo X)
- disponible reportado = X - calc_size (o cero si calc_size > X)

4. Con límite de espacio porcentual (límite de espacio positivo X%)
- disponible reportado = total_hdd*X/100 - calc_size (o cero si calc_size > total_hdd*X/100)

5. Con indicador de espacio compartido (= signo)
- disponible reportado = avail_hdd

6. Con indicador de espacio compartido y límite de espacio (=X)
- disponible reportado = X (o avail_hdd si avail_hdd < X)

7. Con indicador de espacio compartido y porcentaje (=X%)
- disponible reportado = avail_hdd*X/100

8. Con indicador de espacio compartido y límite de espacio negativo (=-X)
- disponible reportado = avail_hdd - X (o 0, si X>avail_hdd)

9. Con indicador de espacio compartido y porcentaje negativo (=-X%)
- disponible reportado = avail_hdd - avail_hdd*X/100

En todos estos casos, el espacio total se calcula como:
- total reportado = disponible reportado + calc_size
