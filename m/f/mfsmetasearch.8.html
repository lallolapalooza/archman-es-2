NOMBRE

mfsmetasearch - utiliza los metadatos de MooseFS para encontrar archivos específicos

SINOPSIS

mfsmetasearch [-f J|C|C x] [-o archivo_salida] [-e expresion | -c archivo_id_bloque] archivo_metadatos

DESCRIPCIÓN

mfsmetasearch es una herramienta que encuentra archivos y otros objetos en los metadatos de MooseFS que coinciden con la expresión proporcionada (si se usa la opción -e) o que contienen uno o más de los números de bloque listados en formato hexadecimal en el archivo proporcionado (si se usa la opción -c).

OPCIONES

-f
cambia el formato de salida TXT predeterminado a JSON (J) o CSV (C); para CSV, si solo se especifica C, se usará el separador predeterminado (coma), si se especifica un segundo carácter, este se usará como separador en los datos CSV
-o
escribe la salida en archivo_salida en lugar de stdout
-e
expresión expresion que un archivo u objeto debe cumplir para ser listado en la salida
-c
archivo archivo_id_bloque que contiene los IDs de bloque, solo se listarán en la salida los archivos que contengan uno de estos bloques; los IDs de bloque deben estar listados en formato hexadecimal, solo se considerarán los últimos 56 bits de los valores leídos como IDs de bloque, lo que significa que los bits que denotan partes EC no tienen que ser eliminados en este caso
archivo_metadatos
ruta al archivo metadata.mfs

EXPRESIONES

La expresión puede consistir en una serie de símbolos, valores y operadores. Un símbolo es una propiedad de un archivo, un valor es el valor de esa propiedad para un archivo particular y los operadores construyen la expresión completa para indicar si una propiedad determinada debe coincidir, ser diferente, etc.

Símbolos y valores:

inodo		número de inodo (valor: numérico)
tipo			tipo de inodo (lista de constantes: file,directory,symlink,fifo,blockdev,chardev,socket,trash,sustained)
eattr		máscara de bits de atributos extra (lista de bits de constantes: noowner,noattrcache,noentrycache,nodatacache,snapshot,undeletable,appendonly,immutable)
sclass		número de clase de almacenamiento (valor: numérico; los números de clase se pueden verificar a través de la GUI o CLI)
uid			ID de usuario (valor: numérico)
gid			ID de grupo (valor: numérico)
mode			máscara de bits de modo de acceso (lista de bits de constantes: sticky,sgid,suid,ur,uw,ux,gr,gw,gx,or,ow,ox)
umode		máscara de bits de modo de acceso para uid (lista de bits de constantes: read,write,execute)
gmode		máscara de bits de modo de acceso para gid (lista de bits de constantes: read,write,execute)
omode		máscara de bits de modo de acceso para otros (lista de bits de constantes: read,write,execute)
atime		tiempo de acceso (valor: numérico - timestamp de Unix en segundos)
mtime		tiempo de modificación (valor: numérico - timestamp de Unix en segundos)
ctime		tiempo de cambio (valor: numérico - timestamp de Unix en segundos)
tretention	retención en papelera en horas (valor: numérico)
length		longitud del archivo (valor: numérico; cero para otros objetos)
major		ID mayor (valor: numérico; solo para blockdev y chardev)
minor		ID menor (valor: numérico; solo para blockdev y chardev)
chunkid		ID numérico del bloque (valor: numérico; la expresión se probará para todos los bloques del archivo y se aceptará si uno de ellos es verdadero)

Operadores aceptados (estilo C): - + * / % >> << < <= > >= == != ~ & ^ | ! && ^^ || ?:

EJEMPLOS

mfsmetasearch -e 'length<4096' /var/lib/mfs/metadata.mfs.back
esto mostrará todos los archivos más cortos que 4096 bytes (con un tamaño menor que 4096 bytes) y todos los objetos que no sean archivos
mfsmetasearch -e 'type==file && length<4096' /var/lib/mfs/metadata.mfs.back
esto mostrará todos los archivos más cortos que 4096 bytes (con un tamaño menor que 4096 bytes)
mfsmetasearch -e 'umode&execute && gmode&execute && !(omode&execute)' /var/lib/mfs/metadata.mfs.back
esto mostrará todos los inodos que tengan el bit de ejecución establecido tanto para el usuario como para el grupo, pero no para otros
mfsmetasearch -e 'chunkid==101020 || chunkid==0xFF77AA || chunkid==01234 || chunkid==0b1010101' /var/lib/mfs/metadata.mfs.back
esto mostrará todos los archivos que contengan el bloque con ID decimal 101020 o el bloque con ID hexadecimal FF77AA o el bloque con ID octal 1234 o el bloque con ID binario 1010101
mfsmetasearch -e 'sclass==11' /var/lib/mfs/metadata.mfs.back
esto mostrará todos los objetos que tengan la clase de almacenamiento establecida en la clase número 11
mfsmetasearch -c /tmp/misidbloques.txt /var/lib/mfs/metadata.mfs.back
esto mostrará todos los archivos que contengan uno de los bloques listados en el archivo de texto /tmp/misidbloques.txt
