NOMBRE

mfsmount.cfg - Archivo de configuración del demonio de montaje de MooseFS

DESCRIPCIÓN

Este es el archivo de configuración que será leído por el demonio mfsmount al iniciarse. Se puede usar para especificar valores predeterminados para mfsmount.

FORMATO

Las líneas vacías y las líneas que comienzan con el signo de almohadilla (#) se ignoran. Cada otra línea debe ser una de las siguientes:

una opción de montaje

varias opciones de montaje, separadas por comas

punto de montaje predeterminado, que debe comenzar con una barra diagonal ("/") y ser una ruta completa

Para obtener una lista de todas las opciones disponibles, consulte mfsmount(8)

EJEMPLOS

Ejemplo de configuración, que establece los parámetros nosuid y nodev, especifica el host maestro, la contraseña de conexión maestra y el punto de montaje:

nosuid,nodev
mfsmaster=mfsmaster
mfspassword=secret
/mnt/mfs
