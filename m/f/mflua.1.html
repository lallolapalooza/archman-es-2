MFLUA(1) Comandos de usuario MFLUA(1)

NOMBRE

MFLua - página del manual para MFLua 2.71828182-1.0.1-alpha (TeX Live 2025)

SINOPSIS

mflua [OPCIÓN]... [NOMBRE_MF[.mf]] [COMANDOS]
mflua [OPCIÓN]... LINEA_RST
mflua [OPCIÓN]... &BASE ARGS

DESCRIPCIÓN

Ejecuta MFLua sobre NOMBRE_MF, usualmente creando NOMBRE_MF.tfm y NOMBRE_MF.NNNNgf, donde NNNN es la resolución del modo especificado (2602 por defecto). Cualquier COMANDO posterior se procesa como entrada Metafont, después de leer NOMBRE_MF. Si la primera línea de NOMBRE_MF es %&BASE, y BASE es un archivo .base existente, se usa. De lo contrario, se usa `NOMBRE.base', donde NOMBRE es el nombre de invocación del programa, comúnmente `mf'.
Alternativamente, si el primer argumento no es una opción y comienza con una barra invertida, interpreta todos los argumentos no-opción como una línea de entrada Metafont.
Alternativamente, si el primer argumento no es una opción y comienza con un &, la siguiente palabra se toma como la BASE a leer, anulando todo lo demás. Los argumentos restantes se procesan como se describe arriba.
Si no se especifican argumentos u opciones, se solicita entrada.

-base=NOMBRE_BASE usa NOMBRE_BASE en lugar del nombre del programa o una línea %& [-no]-file-line-error deshabilita/habilita mensajes de estilo file:line:error -halt-on-error detiene el procesamiento al primer error -ini ser inimf, para volcar bases; esto es implícitamente

verdadero si el nombre del programa es `inimf'

-interaction=CADENA establece el modo de interacción (CADENA=batchmode/nonstopmode/

scrollmode/errorstopmode)

-jobname=CADENA establece el nombre del trabajo a CADENA -kpathsea-debug=NÚMERO establece las banderas de depuración de búsqueda de rutas según

los bits de NÚMERO

[-no]-mktex=FMT deshabilita/habilita la generación de mktexFMT (FMT=mflua) -output-directory=DIR usa DIR existente como el directorio para escribir archivos en [-no]-parse-first-line deshabilita/habilita el análisis de la primera línea del archivo de entrada -progname=CADENA establece el nombre del programa (y base) a CADENA -recorder habilita el grabador de nombres de archivo -translate-file=NOMBRE_TCX usa el archivo TCX NOMBRE_TCX -8bit hace que todos los caracteres sean imprimibles por defecto -help muestra esta ayuda y sale -version muestra información de versión y sale
