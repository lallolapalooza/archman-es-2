NOMBRE

mfscsstatsdump - volcar datos de uso del archivo de estadísticas del chunkserver en formato csv o png

SINOPSIS

mfscsstatsdump -f campos [-i archivo_estadisticas] [-r rango][-s separador] [-p nombre_archivo_png [-x ancho_grafico] [-y alto_grafico]] [-hHd]

DESCRIPCIÓN

mfscsstatsdump vuelca datos de uso del archivo de estadísticas del chunkserver. Estos son los mismos conjuntos de datos que se utilizan para crear los gráficos de la interfaz gráfica. La salida puede ser en formato de texto (csv) o en formato gráfico (png). Eso significa que las opciones -p, -x y -y son mutuamente excluyentes con las opciones -h, -H y -d.

El chunkserver de MooseFS guarda el archivo de estadísticas en el directorio DATA_PATH; consulta mfschunkserver.cfg(5)

SALIDA

Salida de texto: archivo de texto (csv) donde la primera columna es una marca de tiempo (o fecha si se especificó la opción -d), las columnas siguientes son las especificadas con las opciones -f, formateadas según las opciones utilizadas (ninguna, -s y -h o -H)

Salida gráfica: se crea un archivo png con un gráfico para cada campo especificado con la opción -f, según el esquema de nombres declarado con la opción -p. El tamaño se puede ajustar con las opciones -x y -y.

OPCIONES

-f
nombres de campos separados por ','; al menos un campo es obligatorio; si se usa un asterisco (*), se vuelcan todos los campos
-i
nombre del archivo binario de estadísticas de mfs (predeterminado: ruta_datos_predeterminada/csstats.mfs)
-r
tipo de rango: 0 - rango corto (minuto) 1 - rango medio (6 minutos) 2 - rango largo (30 minutos) 3 - rango muy largo (día)
-s
especificar separador de columnas (predeterminado: tabulador)
-p
nombre de archivo PNG opcional (se agregará el nombre del campo antes de .png; YYYY -> YYYY_CAMPO.png, YYYY.png -> YYYY_CAMPO.png)
-x
ancho del gráfico PNG (predeterminado: 1600)
-y
altura del gráfico PNG (debe ser divisible por 20; si no, se ajustará; predeterminado: 320)
-h
números "legibles por humanos" usando prefijos de base 2 (IEC 60027)
-H
números "legibles por humanos" usando prefijos de base 10 (SI)
-d
mostrar marcas de tiempo en formato YYYY-MM-DD HH:MM

CAMPOS

ucpu
Uso de CPU de usuario
scpu
Uso de CPU del sistema
cpu
Uso total de CPU (en csv, suma de scpu y ucpu; en png, muestra ambos en diferentes colores)
masterin
Datos recibidos del maestro
masterout
Datos enviados al maestro
csrepin
Datos recibidos por el replicador
csrepout
Datos enviados por el replicador
csservin
Datos recibidos por csserv
csservout
Datos enviados por csserv
bwin
Ancho de banda de entrada de datos (en csv, suma de csrepin y csservin; en png, muestra ambos en diferentes colores)
bwout
Ancho de banda de salida de datos (en csv, suma de csrepout y csservout; en png, muestra ambos en diferentes colores)
hdrbytesr
Bytes leídos (cabeceras)
hdrbytesw
Bytes escritos (cabeceras)
hdrllopr
Lecturas de bajo nivel (cabeceras)
hdrllopw
Escrituras de bajo nivel (cabeceras)
databytesr
Bytes leídos (datos)
databytesw
Bytes escritos (datos)
datallopr
Lecturas de bajo nivel (datos)
datallopw
Escrituras de bajo nivel (datos)
hddread
Lectura de HDD (en csv, suma de hdrbytesr y databytesr; en png, muestra ambos en diferentes colores)
hddwrite
Escritura de HDD (en csv, suma de hdrbytesw y databytesw; en png, muestra ambos en diferentes colores)
hddopsr
Lectura de bajo nivel de HDD (en csv, suma de hdrllopr y datallopr; en png, muestra ambos en diferentes colores)
hddopsw
Escritura de bajo nivel de HDD (en csv, suma de hdrllopw y datallopw; en png, muestra ambos en diferentes colores)
hlopr
Lecturas de alto nivel
hlopw
Escrituras de alto nivel
rtime
Tiempo de lectura
wtime
Tiempo de escritura
repl
Operaciones de replicación de fragmentos
create
Operaciones de creación de fragmentos
delete
Operaciones de eliminación de fragmentos
version
Operaciones de establecimiento de versión
duplicate
Operaciones de duplicación
truncate
Operaciones de truncamiento
duptrunc
Operaciones de duplicación+truncamiento
test
Operaciones de prueba de fragmentos
load
Carga del servidor
memoryrss
Uso de memoria residente
memoryvirt
Uso de memoria virtual
mem
Uso total de memoria (en csv es lo mismo que memoryvirt; en png muestra memoryrss y memoryvirt usando dos colores)
movels
Operaciones de movimiento a baja velocidad
movehs
Operaciones de movimiento a alta velocidad
move
Operaciones de movimiento a baja velocidad + alta velocidad (en png muestra movels y movehas usando dos colores)
change
Cambios de fragmentos en metadatos (suma de version + duplicate + truncate + duptrunc + split)
split
Operaciones de división
usedspace
Espacio de HDD utilizado en bytes (excluye la marca de eliminación)
totalspace
Espacio total de HDD en bytes (excluye la marca de eliminación)
space
Espacio total de HDD (en csv es lo mismo que totalspace; en png muestra usedspace y totalspace usando dos colores)
chunkcount
