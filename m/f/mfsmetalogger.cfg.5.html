NOMBRE

mfsmetalogger.cfg - archivo de configuración para mfsmetalogger

DESCRIPCIÓN

El archivo mfsmetalogger.cfg contiene la configuración del proceso metalogger de MooseFS.

SINTAXIS

La sintaxis es:

OPCIÓN = VALOR

Las líneas que comienzan con el carácter # se ignoran como comentarios.

OPCIONES DE ARRANQUE

Los cambios en esta sección requieren reiniciar el proceso.

WORKING_USER
usuario con el que se ejecutará el demonio
WORKING_GROUP
grupo con el que se ejecutará el demonio (opcional - si está vacío, se utilizará el grupo de usuario predeterminado)
SYSLOG_IDENT
nombre del proceso que se incluirá en los mensajes de syslog (el valor predeterminado es mfsmetalogger)
LOCK_MEMORY
si se realizará mlockall() para evitar que el proceso mfsmetalogger sea enviado a la memoria virtual (el valor predeterminado es 0, es decir, no)
LIMIT_GLIBC_MALLOC_ARENAS
limita las áreas de malloc a un valor dado - evita que el servidor utilice una gran cantidad de memoria virtual (solo Linux, el valor predeterminado es 4)
DISABLE_OOM_KILLER
desactiva el asesino de procesos por falta de memoria (OOM killer) (solo Linux, el valor predeterminado es 1)
NICE_LEVEL
nivel de nice con el que se ejecutará el demonio (el valor predeterminado es -19 si es posible; nota: el proceso debe iniciarse como root para aumentar la prioridad)
FILE_UMASK
establece el umask predeterminado para el grupo y otros; el usuario siempre tiene 0; el valor predeterminado es 027 - bloquea la escritura para el grupo y bloquea todo para otros
DATA_PATH
dónde almacenar los archivos de metadatos

OPCIONES EN TIEMPO DE EJECUCIÓN

Los cambios en esta sección solo requieren recargar el proceso.

BACK_LOGS
número de archivos de registro de cambios de metadatos (el valor predeterminado es 50)
BACK_META_KEEP_PREVIOUS
número de archivos de metadatos anteriores a conservar (el valor predeterminado es 3)
META_DOWNLOAD_FREQ
frecuencia de descarga de metadatos en horas (el valor predeterminado es 24, como máximo BACK_LOGS/2)
SYSLOG_MIN_LEVEL
nivel mínimo de mensajes que serán reportados por matalogger; niveles en orden de importancia: ERROR, WARNING, NOTICE, INFO, DEBUG (el valor predeterminado es INFO)
SYSLOG_ELEVATE_TO
los mensajes reportados de un nivel inferior al establecido por esta opción se elevarán a este nivel (por ejemplo, si SYSLOG_MIN_LEVEL está configurado como DEBUG y SYSLOG_ELEVATE_TO está configurado como NOTICE, todos los mensajes INFO y DEBUG se enviarán a syslog como NOTICE; el valor predeterminado es NOTICE)

OPCIONES DE CONEXIÓN AL MAESTRO

Los cambios en esta sección solo requieren recargar el proceso.

MASTER_RECONNECTION_DELAY
retraso en segundos antes de intentar reconectar al maestro después de la desconexión (el valor predeterminado es 5)
BIND_HOST
dirección local a utilizar para las conexiones al maestro; el valor predeterminado es *, es decir, la dirección local predeterminada
MASTER_HOST
dirección del host maestro de MooseFS con el que conectarse (el valor predeterminado es mfsmaster)
MASTER_PORT
número del puerto maestro de MooseFS con el que conectarse (el valor predeterminado es 9419)
MASTER_TIMEOUT
tiempo de espera (en segundos) para las conexiones al maestro (el valor predeterminado es 10)
