NOMBRE

mfstopology.cfg - Definiciones de topología de red de MooseFS

DESCRIPCIÓN

El archivo mfstopology.cfg asigna direcciones IP a ubicaciones de red. Este archivo es opcional. Si su red es muy pequeña (es decir, tiene solo un switch) o la topología de red no es necesaria, deje este archivo vacío.

SINTAXIS

La sintaxis es:

DIRECCIONES_IP RUTA_UBICACIÓN

Las líneas que comienzan con el carácter # se ignoran como comentarios.

DIRECCIÓN_IP se puede especificar de varias formas:

*	todas las direcciones
n.n.n.n	dirección IP única
n.n.n.n/b	clase IP especificada por dirección de red y número de bits
n.n.n.n/m.m.m.m	clase IP especificada por dirección de red y máscara
f.f.f.f-t.t.t.t	rango de IP especificado por direcciones de inicio a fin (inclusive)

RUTA_UBICACIÓN se puede especificar como una secuencia de palabras separadas por barras verticales.

NOTAS

Si una IP pertenece a más de una definición, se utiliza la última definición.

Cada conjunto de direcciones IP con una ruta de ubicación común se considera un rack. La información del rack y/o IP es utilizada por el maestro si CHUNKS_UNIQUE_MODE en mfsmaster.cfg está configurado con un valor mayor que 0 (consulte el manual de mfsmaster.cfg(5) para más información) y en las clases de almacenamiento si se utiliza la característica de distinción (consulte el manual de mfsscadmin(1) para más información).

La distancia entre números IP se define de la siguiente manera: 0 cuando los números IP son los mismos, 1 cuando los números IP son diferentes, pero las rutas especificadas por estos números son las mismas. En caso de rutas diferentes, la distancia se define como uno más el número máximo de elementos de ambas rutas después de la parte inicial común.

La distancia se utiliza para los siguientes propósitos:
Las copias de los chunks se envían al cliente (montaje) ordenadas según la distancia desde este cliente cuando se necesita un chunk para operaciones de E/S. Tenga en cuenta que el cliente puede alterar ese orden basándose en configuraciones internas (etiquetas preferidas o algoritmos internos que previenen la congestión; para más información sobre etiquetas preferidas, consulte el manual de mfsmount(8)).
En el maestro, la información de distancia y racks se utiliza cuando CREATIONS_RESPECT_TOPOLOGY y/o REPLICATIONS_RESPECT_TOPOLOGY están configurados con un valor mayor que 0. Para más información, consulte el manual de mfsmaster.cfg(5).

EJEMPLOS

192.168.1.0/24 US|CHICAGO|WTOWER|R1A

192.168.2.0-192.168.2.255 PL|WARSAW|GROCHOWSKA|R154

192.168.3.0/255.255.255.0 123

192.168.1.1 A|B|C

EJEMPLOS DE DISTANCIA

Distancias calculadas para dos números IP diferentes mapeados a las rutas de ubicación dadas:

d('US','DE') = 2

d('US','') = 2

d('US|PHOENIX|AT&T|RACK1','US|PHOENIX|AT&T|RACK2') = 2

d('US|PHOENIX|AT&T|RACK1','US|PHOENIX|ATM|RACK7') = 3

d('US|PHOENIX|AT&T|RACK1','US|CHICAGO|AT&T|RACK2') = 4

d('US|PHOENIX|AT&T|RACK1','US|ATM') = 4

d('US|PHOENIX|AT&T|RACK1','DE|BERLIN|ATM|RACK175') = 5
