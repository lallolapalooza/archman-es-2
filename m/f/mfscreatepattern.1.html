NOMBRE

mfspatadmin - herramienta de administración de patrones de MooseFS

SINOPSIS

mfscreatepattern [-?] [-M PUNTO_MONTAJE] -n patron [-u uid] [-g gid] [-p prioridad] [-c clase_almacenamiento] [-t retencion_papeleras] [-f eattr]

mfsdeletepattern [-?] [-M PUNTO_MONTAJE] -n patron [-u uid] [-g gid]

mfslistpattern [-?] [-M PUNTO_MONTAJE]

DESCRIPCIÓN

Este es un conjunto de herramientas para gestionar patrones, que se utilizan para anular clases de almacenamiento, retención de papeleras y/o atributos extra cada vez que se crea un nuevo archivo o se renombra uno existente.

mfscreatepattern añade una nueva definición de patrón, descrita a continuación.

mfsdeletepattern elimina una definición de patrón específica

mfslistpattern lista todas las definiciones de patrones

OPCIONES

-n define el patrón que se comparará con los nombres de archivo. Este es un formato GLOB simple (ver más abajo). Esta opción debe definirse para los comandos add y delete

-u define el ID de usuario que debe ser igual al ID de usuario efectivo del usuario que crea o renombra un archivo. Si no se especifica, el ID de usuario no se comprobará en la coincidencia.

-g define el ID de grupo que debe ser igual a uno de los IDs de grupo del usuario que crea o renombra un archivo. Si no se especifica, el ID de grupo no se comprobará en la coincidencia.

-p prioridad de la coincidencia. Cuando hay más patrones que coinciden con un nombre de archivo, los patrones con mayor prioridad tienen precedencia. La prioridad se puede definir como un valor entre 0 (más bajo) y 255 (más alto). Si no se especifica, se utiliza el valor predeterminado de 128. Si dos o más patrones con la misma prioridad coinciden con un nombre de archivo (con la máxima prioridad posible para ese archivo), solo se utilizará uno de ellos (no especificado).

-c nombre de la clase de almacenamiento que se establecerá al coincidir

-t valor de retención de papeleras que se establecerá al coincidir; la unidad mínima es horas, para el formato de valor consulta TIEMPO

-f nombres de banderas, separados por comas, que se establecerán al coincidir. Cada bandera debe ir precedida de un signo '+' o '-', lo que significa que esta bandera debe establecerse o desmarcarse, respectivamente. Para la descripción de las banderas consulta mfseattr(1).

-M punto de montaje de MooseFS, no es necesario especificarlo si la herramienta se ejecuta dentro de un directorio montado con MooseFS o si MooseFS está montado en /mnt/mfs/

-? muestra un mensaje de uso corto

Se debe definir al menos una de las opciones -c, -t, -f para el comando add.

NOTAS

TIEMPO

Para variables que definen tiempo sin requerir una única unidad específica, el tiempo se puede definir como un número de segundos u horas (entero), dependiendo de la unidad mínima para la variable, o como un período de tiempo en uno de dos formatos posibles:

primer formato: #.#T donde T es uno de: s-segundos, m-minutos, h-horas, d-días o w-semanas; las fracciones de la unidad mínima se redondearán

segundo formato: #w#d#h#m#s, se pueden omitir cualquier número de definiciones, pero las definiciones restantes deben estar en orden (por lo que #d#m sigue siendo una definición válida, pero #m#d no lo es); rangos: s,m: 0 a 59, h: 0 a 23, d: 0 a 6, w es ilimitado y la primera definición también es siempre ilimitada (es decir, para #d#h#m d será ilimitado)

Si la unidad mínima de una variable es mayor que segundos, las unidades por debajo de la unidad mínima no serán aceptadas. Por ejemplo, una variable que tiene horas como unidad mínima no aceptará unidades s y m.

Ejemplos:

1.5d es lo mismo que 1d12h, es lo mismo que 36h

2.5w es lo mismo que 2w3d12h, es lo mismo que 420h; 2w84h no es un período de tiempo válido (h no es la primera definición, por lo que está limitado por el rango 0 a 23)

DEFINICIÓN DE PATRÓN

Un patrón es una cadena con comodines opcionales (similar a glob de UNIX). Comodines reconocidos:

* - coincide con cualquier número de caracteres, incluidos ninguno

? - coincide con un solo carácter cualquiera

[abc] - coincide con un carácter dado entre corchetes

[DESDE-HASTA] - coincide con un carácter del rango dado entre corchetes

[!abc] - coincide con un carácter que no esté dado entre corchetes

[!DESDE-HASTA] - coincide con un carácter que no esté en el rango dado entre corchetes

Ejemplos de patrones:

nombreexacto - coincide solo con el archivo de nombre 'nombreexacto'

*.txt - coincide con cualquier archivo de 'texto' (formalmente archivo con sufijo de nombre '.txt').

miproyecto* - coincide con cualquier archivo con prefijo de nombre 'miproyecto'.

letra[0-9] - coincide con archivos con nombres 'letra0', 'letra1', 'letra2', ... 'letra9'.

[CBA]gato - coincide con archivos con nombres 'Cgato' y 'Bgato'.

[!0-9]* - coincide con archivos cuyos nombres no empiezan con un dígito
