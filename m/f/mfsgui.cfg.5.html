NOMBRE

mfsgui.cfg - archivo de configuración principal para mfsgui

DESCRIPCIÓN

El archivo mfsgui.cfg contiene la configuración del proceso del servidor GUI de MooseFS.

SINTAXIS

La sintaxis es:

OPCIÓN = VALOR

Las líneas que comienzan con el carácter # se ignoran como comentarios.

OPCIONES DE INICIO

Los cambios en esta sección requieren reiniciar el proceso.

USUARIO_TRABAJO
usuario con el que se ejecutará el demonio
GRUPO_TRABAJO
grupo con el que se ejecutará el demonio; valor opcional - si está vacío, se usará el grupo de usuario predeterminado
IDENTIFICADOR_SYSLOG
nombre del proceso a incluir en los mensajes de syslog; el valor predeterminado es mfsgui
BLOQUEAR_MEMORIA
si se realizará mlockall() para evitar el intercambio del proceso mfsgui; el valor predeterminado es 0, es decir, no
DESHABILITAR_OOM_KILLER
deshabilita el killer de falta de memoria (solo Linux, el valor predeterminado es 1)
NIVEL_NICE
nivel nice con el que se ejecutará el demonio; el valor predeterminado es -19; nota: el proceso debe iniciarse como root para aumentar la prioridad, si la configuración de la prioridad falla, el proceso conserva el nivel nice con el que se inició
UMASK_ARCHIVO
establece la umask predeterminada para grupo y otros (el usuario siempre tiene 0); el valor predeterminado es 027 - bloquea la escritura para el grupo y bloquea todo para otros
RUTA_DATOS
dónde almacenar el archivo de bloqueo del demonio

OPCIONES EN EJECUCIÓN

Los cambios en esta sección solo requieren recargar el proceso.

NIVEL_MINIMO_SYSLOG
nivel mínimo de mensajes que serán reportados por el chunkserver; niveles en orden de importancia: ERROR, WARNING, NOTICE, INFO, DEBUG (el valor predeterminado es INFO)
ELEVAR_SYSLOG_A
los mensajes reportados de nivel inferior al establecido por esta opción se elevarán a este nivel (por ejemplo, si NIVEL_MINIMO_SYSLOG está configurado a DEBUG y ELEVAR_SYSLOG_A está configurado a NOTICE, todos los mensajes INFO y DEBUG se enviarán a syslog como NOTICE; el valor predeterminado es NOTICE)

OPCIONES DE CONEXIÓN

Los cambios en esta sección solo requieren recargar el proceso.

HOST_ESCUCHA_GUISERV
dirección IP en la que escuchar las conexiones http entrantes (* significa cualquiera)
PUERTO_ESCUCHA_GUISERV
puerto en el que escuchar las conexiones http entrantes
TIEMPO_ESPERA_GUISERV
tiempo de espera de la conexión http, en segundos (el valor predeterminado es 300)

OPCIONES SERVIDOR HTTP

Los cambios en esta sección solo requieren recargar el proceso.

DIRECTORIO_RAIZ
directorio raíz de documentos para el servidor http
ARCHIVO_SOLICITUDES
archivo de configuración de solicitudes, ruta absoluta o ruta relativa a DIRECTORIO_RAIZ; el contenido de este archivo NUNCA debe ser modificado por el usuario
