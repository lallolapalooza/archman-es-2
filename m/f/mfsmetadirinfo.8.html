NOMBRE

mfsmetadirinfo - utiliza metadatos de MooseFS para calcular información precisa de directorios (similar a mfsdirinfo)

SINOPSIS

mfsmetadirinfo [-f J|C|C x] [-o archivo_salida] [-a nombre_suma] archivo_metadatos RUTA [RUTA...]

DESCRIPCIÓN

mfsmetadirinfo es una herramienta que se puede utilizar para calcular información precisa de directorios como número de inodos, número de fragmentos (chunks), longitud total de todos los archivos, tamaño, tamaño real, etc. La salida puede generarse como texto plano, CSV o JSON. Los datos para los cálculos se leen del archivo de metadatos maestro de mfs metadata.mfs indicado y se calculan para el(los) directorio(s) especificado(s) por el(los) parámetro(s) RUTA - relativo en la instancia de mfs. La salida predeterminada es texto plano legible por humanos, se puede seleccionar JSON o CSV usando las opciones.

Opciones:

-f
cambia el formato de salida a JSON (J) o CSV (C); para CSV, si solo se especifica C, se usará el separador predeterminado (coma), si se especifica el segundo carácter, este carácter se utilizará como separador en los datos CSV
-o
escribe la salida en archivo_salida en lugar de stdout
-a
parámetro opcional que indica que la herramienta debe calcular la información para todas las rutas proporcionadas juntas (una suma), este cálculo se indica mediante nombre_suma en los datos de salida
archivo_metadatos
ruta al archivo metadata.mfs

CAMPOS DE SALIDA

Para cada RUTA y, si se define, para nombre_suma, se indicará la siguiente información:

inodos
número de todos los inodos únicos (objetos del sistema de archivos)
archivos
número de todos los archivos únicos
directorios
número de todos los directorios únicos
fragmentos
número de todos los fragmentos únicos
fragmentos_mantener
número de todos los fragmentos únicos que usan la política KEEP
fragmentos_archivo
número de todos los fragmentos únicos que usan la política ARCH
longitud
longitud total de todos los archivos únicos
tamaño
tamaño total de todos los fragmentos únicos
tamaño_real
tamaño real total de todos los fragmentos únicos (número de copias tenidas en cuenta)
tamaño_mantener
tamaño real hipotético de todos los fragmentos únicos si todos usaran la política KEEP
tamaño_archivo
tamaño real hipotético de todos los fragmentos únicos si todos usaran la política ARCH
