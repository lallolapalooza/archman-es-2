NOMBRE

mfsdiagtools - **Herramientas de diagnóstico** de MooseFS

SINOPSIS

mfscheckfile [-?] [-n|-h|-H|-k|-m|-g] ARCHIVO...

mfsfileinfo [-?] [-n|-h|-H|-k|-m|-g] [-q|-c|-s] [-p] [-w] ARCHIVO...

mfsfilerepair [-?] [-n|-h|-H|-k|-m|-g] [-d] ARCHIVO...

mfsdirinfo [-?] [-n|-h|-H|-k|-m|-g] [-i|-d|-f|-c|-l|-s|-r] [-p] OBJETO...

mfsfilepaths [-?] OBJETO|INODO...

DESCRIPCIÓN

mfscheckfile comprueba e imprime el número de fragmentos y el número de copias de fragmentos pertenecientes a los archivos especificados. Se puede utilizar en cualquier archivo, incluido los eliminados (papelera).

mfsfileinfo imprime la ubicación (servidor de fragmentos y puerto) de cada copia de fragmento perteneciente a los archivos especificados. Se puede utilizar en cualquier archivo, incluido los eliminados (papelera). La opción -q activa el modo rápido (solo número de partes EC o copias válidas). La opción -c activa la recepción de sumas de verificación de fragmentos de los servidores de fragmentos y, finalmente, -s activa el cálculo de la firma del archivo (a partir de las sumas de verificación recibidas). La opción -p muestra la ruta al archivo de fragmento en el servidor de fragmentos para cada fragmento. La opción -w muestra solo fragmentos "incorrectos" (inválidos, faltantes, versión incorrecta).

mfsfilerepair se ocupa de archivos rotos (aquellos que causan errores de E/S en las operaciones de lectura) para hacerlos parcialmente legibles. En caso de discrepancia en la versión del fragmento, establece la versión del fragmento conocida por mfsmaster a la más alta encontrada en los servidores de fragmentos. En caso de que no haya ninguna copia disponible de un fragmento (todas las copias son inválidas o faltantes), el fragmento se marca como "leer como ceros" (la operación de lectura devolverá ceros, la operación de escritura fallará). Cuando/si un servidor de fragmentos con el fragmento faltante se conecta, el archivo estará completamente disponible nuevamente. Si se usa la opción -d, el fragmento faltante/inválido se pondrá a ceros permanentemente. Nota: es aconsejable hacer una copia (no una instantánea) de cualquier archivo reparado con esta herramienta, especialmente si existe la posibilidad de que servidores de fragmentos con más fragmentos existentes se conecten al sistema en el futuro (por ejemplo, después de una interrupción). Esto es para evitar el contenido inconsistente de fragmentos con la misma versión en un archivo.

mfsdirinfo es el equivalente extendido y específico de MooseFS del comando du -s. Imprime un resumen para cada objeto especificado (archivo único o árbol de directorios). Si solo desea ver un parámetro, agregue una de las opciones de visualización (consulte OPCIONES DE VISUALIZACIÓN). Por defecto, devuelve datos de los contadores internos del maestro (muy rápido, pero no preciso). Todos los nodos repetidos (enlaces duros) y fragmentos (instantáneas) se cuentan varias veces. Para contar las estadísticas con mayor precisión, puede usar el interruptor -p que activa un procedimiento lento y recursivo. En este modo, los nodos y fragmentos se cuentan solo una vez y el sistema utiliza el número actual de copias de fragmentos en lugar del objetivo/etiquetas. Los administradores del sistema podrían considerar usar mfsmetadirinfo (consulte mfsmetadirinfo(8)).

La herramienta mfsfilepaths se puede utilizar para encontrar todas las ocurrencias (enlaces duros) de un archivo dado en el sistema de archivos. También se puede utilizar para encontrar un archivo con un número de inodo dado. En caso de buscar un número de inodo, la herramienta debe ejecutarse en un directorio montado por mfs.

OPCIONES

OPCIONES GENERALES

La mayoría de las herramientas de MooseFS utilizan las opciones -n, -h, -H, -k, -m y -g para seleccionar el formato de los números impresos. -n hace que se impriman números exactos, -h utiliza prefijos binarios (Ki, Mi, Gi como 2^10, 2^20 etc.) mientras que -H utiliza prefijos SI (k, M, G como 10^3, 10^6 etc.). -k, -m y -g muestran números simples respectivamente en kibis (kilo binario - 1024), mebis (mega binario - 1024^2) y gibis (giga binario - 1024^3). Lo mismo se puede lograr configurando la variable de entorno MFSHRFORMAT a: 0 (números exactos), 1 o h (prefijos binarios), 2 o H (prefijos SI), 3 o h+ (números exactos y prefijos binarios), 4 o H+ (números exactos y prefijos SI). El valor predeterminado es imprimir solo números exactos.

La opción -? muestra un mensaje de uso corto.

OPCIONES DE VISUALIZACIÓN

-i
mostrar número de inodos
-d
mostrar número de directorios
-f
mostrar número de archivos
-c
mostrar número de fragmentos
-l
mostrar longitud (suma de longitudes de archivos)
-s
mostrar tamaño (suma de longitudes de fragmentos)
-r
mostrar tamaño real (uso estimado del disco duro simple - generalmente tamaño multiplicado por el objetivo actual)
