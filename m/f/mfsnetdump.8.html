NOMBRE

mfsnetdump - volcar el tráfico de red como paquetes mfs

SINOPSIS

mfsnetdump [-r PCAP_FILE] [-i INTERFACE] [-p PORT_RANGE] [-f PCAP_FILTER] [-c PCOUNT] [-s MBYTES] [-e COMMANDS] [-o COMMANDS] [-x] [-y] [-n]

DESCRIPCIÓN

mfsnetdump es una herramienta de diagnóstico interna similar a tcpdump, pero especializada para MooseFS.

OPCIONES

-r
especificar el archivo PCAP del cual leer los paquetes
-i
volcar paquetes usando la interfaz de red dada
-p
mostrar solo paquetes del rango de puertos dado (el rango por defecto es 9419-9422, por lo que por defecto solo se muestran paquetes MFS)
-f
definir el filtro pcap para filtrar paquetes
-c
volcar solo PCOUNT paquetes y salir
-s
volcar solo los primeros MBYTES bytes de cada paquete
-e
no mostrar los comandos dados
-o
mostrar solo los comandos dados
-x
no mostrar comandos de mantenimiento de mfs (como CSTOMA_SPACE o CLTOMA_FUSE_TIME_SYNC)
-y
no mostrar paquetes de apertura/cierre de conexiones
-n
mostrar el comando ANTOAN_NOP (deshabilitado por defecto)
