NOMBRE

mfscli - Contraparte de la GUI en modo TXT

SINOPSIS

mfscli [-jpn28] [-H master_host] [-P master_port] [-f 0..3] -S(IN|IG|IM|LI|IC|IL|MF|MU|CS|MB|HD|EX|MD|MS|MO|OF|AL|RP|SC|PA|QU|MC|CC) [-s separador] [-o id_orden [-r]] [-m id_modo] [-i id] [-a num_datos_master] [-b desc_datos_master] [-c num_datos_chunkserver] [-d desc_datos_chunkserver]

mfscli [-pn28] [-H master_host] [-P master_port] [-f 0..3] -C(RC/ip/puerto|BW/ip/puerto|M[01]/ip/puerto|RS/sessionid|TR/ip/puerto)

mfscli -h

DESCRIPCIÓN

mfscli es la contraparte de línea de comandos de la interfaz gráfica de MooseFS. Toda la información disponible en la GUI (excepto los paneles de Gráficos y Estado) se puede obtener a través de la CLI utilizando diferentes "opciones de monitoreo"; los datos de los gráficos se pueden obtener como texto.

OPCIONES

OPCIONES GENERALES

-h
muestra el mensaje de ayuda y sale
-j
muestra el resultado en formato JSON
-p
fuerza el formato de texto plano en dispositivos tty
-n
no resuelve direcciones IP (predeterminado cuando el dispositivo de salida no es tty)
-s separador
separador de campos a usar en formato de texto plano en dispositivos tty (fuerza -p)
-2
fuerza códigos de color de terminal de 256 colores
-8
fuerza códigos de color de terminal de 8 colores
-H master_host
dirección del master (predeterminado: mfsmaster)
-P master_port
puerto del cliente master (predeterminado: 9421)
-f 0..3
establece el conjunto de caracteres del marco a mostrar como marcos de tabla en modo ttymode;
0
marcos ASCII simples '+','-','|' (predeterminado)
1
marcos unicode gruesos
2
marcos unicode finos
3
marcos unicode dobles (estilo DOS)
-o id_orden
ordena los datos por la columna especificada por 'id_orden' (depende del conjunto de datos)
-r
invierte el orden de clasificación
-m id_modo
muestra los datos especificados por 'id_modo' (depende del conjunto de datos)
-i id
sessionid para -SOF o inodo para -SAL
-a num_datos_master
cuántas entradas de gráficos de datos del master (-SMC) se deben mostrar
-b desc_datos_master
define las columnas de los gráficos de datos del master (-SMC); prefija con '+' para datos brutos, (solo pro) prefija con 'ip:[puerto:]' para elegir servidor (por defecto se usará el master líder); usa 'all' como nombre de gráfico para todos los gráficos disponibles
-c num_datos_chunkserver
cuántas entradas de gráficos de datos de chunkserver (-SCC) se deben mostrar
-d desc_datos_chunkserver
define las columnas de los gráficos de datos de chunkserver (-SCC); prefija con '+' para datos brutos, prefija con 'ip:[puerto:]' para elegir servidor (por defecto se usarán todos los servidores); usa 'all' como nombre de gráfico para todos los gráficos disponibles

OPCIONES DE MONITOREO

-SIN
muestra información completa del master (incluye: SIG, SIM, SLI, SIC, SIL, SMF, SMU)
-SIG
muestra solo resumen general del clúster
-SIM
muestra solo estados de los masters
-SLI
(solo pro) muestra solo información de licencia
-SIC
muestra solo información de trozos (matrices de nivel de redundancia objetivo/actual)
-SIL
muestra solo bucles de autocomprobación (con mensajes)
-SMF
muestra solo trozos/archivos faltantes
-SMU
muestra solo uso de memoria del master
-SCS
muestra servidores de trozos conectados
-SMB
muestra servidores de copia de seguridad de metadatos conectados
-SHD
muestra datos de hdd
-SEX
muestra exportaciones
-SMD
muestra detalles de montajes (incluye: SMS, SMO, SOF, SAL)
-SMS
muestra solo montajes activos
-SMO
muestra solo contadores de operaciones
-SOF
muestra solo archivos abiertos
-SAL
muestra solo bloqueos adquiridos
-SRP
muestra la política de redundancia (incluye: SSC, SPA)
-SSC
muestra clases de almacenamiento
-SPA
muestra anulaciones de patrones
-SQU
muestra información de cuotas
-SMC
muestra datos de gráficos del master (usar con -a y -b)
-SCC
muestra datos de gráficos de chunkserver (usar con -c y -d)

COMANDOS

-CRC/ip/puerto
elimina el chunkserver seleccionado de la lista de chunkservers activos
-CTR/ip/puerto
elimina temporalmente el chunkserver seleccionado de la lista de chunkservers activos (solo master elect)
-CBW/ip/puerto
devuelve el chunkserver seleccionado al estado de trabajo (desde el estado de gracia)
-CM1/ip/puerto
cambia el chunkserver seleccionado al modo de mantenimiento
-CM0/ip/puerto
cambia el chunkserver seleccionado al modo estándar (desde el modo de mantenimiento)
-CRS/idsesion
elimina la sesión seleccionada

EJEMPLOS

mfscli -SIC -2
muestra una tabla con la matriz de estado de los chunks (número de chunks para cada combinación de copias válidas y objetivo establecido por el usuario) utilizando colores de terminal extendidos (256 colores)
mfscli -SCS -f 1
muestra una tabla con todos los chunkservers utilizando marcos gruesos unicode
mfscli -SMS -p -s ','
muestra las sesiones (montajes) actuales en formato de texto plano y coma como separador
mfscli -SOF -i 123
muestra los archivos abiertos por procesos utilizando la sesión (montaje) con id 123
mfscli -SMC -a 10 -b cpu,memoryrss,delete,replicate
muestra el uso de CPU del master, la cantidad de memoria residente utilizada por el master, el número de eliminaciones de chunks y el número de replicaciones de chunks durante los últimos diez minutos
mfscli -SCC -c 15 -d 192.168.1.10:9422:cpu,192.168.1.11:9422:cpu
muestra el uso de CPU de los chunkservers ubicados en las máquinas con IP 192.168.1.10 y 192.168.1.11 durante los últimos quince minutos
mfscli -SCC -d $(mfscli -SCS -p -s ',' | grep '^chunk' | awk -F ',' 'BEGIN {s=""} {printf "%s%s:%s:mem",s,$2,$3 ; s=","}')
muestra el uso de memoria residente de todos los chunkservers conectados (mfscli antiguo - antes de la versión 4.32.2)
mfscli -SCC -d mem
muestra el uso de memoria residente de todos los chunkservers conectados (mfscli actual)
mfscli -SIN -j
imprime información básica en formato JSON
