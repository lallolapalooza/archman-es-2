NOMBRE

mfsgui - iniciar, reiniciar o detener el servidor GUI de MooseFS

SINOPSIS

mfsgui [-c ARCHIVO_CONFIG] [-f] [-d] [-u] [-n] [-t TIEMPO_ESPERA_BLOQUEO] [ACCION]

mfsgui -v

mfsgui -h

DESCRIPCIÓN

mfsgui es el servidor GUI de MooseFS. Consiste en un servidor HTTP y scripts que componen la interfaz gráfica de MooseFS. El usuario puede acceder a la GUI a través de cualquier navegador web, utilizando la IP (o el nombre de dominio apropiado) y el puerto definidos en mfsgui.cfg.

OPCIONES

-v
imprime la información de la versión y sale
-h
imprime la información de uso y sale
-c ARCHIVO_CONFIG
especifica una ruta alternativa para el archivo de configuración (el valor predeterminado es mfsgui.cfg en el directorio de configuración del sistema)
-f
ejecutar en primer plano, no desvincularse
-d
ejecutar con opciones peligrosas (nombres: DANGEROUS_*)
-u
registrar valores de configuración no definidos (cuando se asume el valor predeterminado)
-n
no intentar aumentar el límite del tamaño del volcado del núcleo
-t TIEMPO_ESPERA_BLOQUEO
cuánto esperar por el archivo de bloqueo (en segundos; el valor predeterminado es 60 segundos)
ACCION
indica al servidor GUI de MooseFS que realice una de las siguientes acciones:
start
Inicia el proceso del servidor GUI de MooseFS si el proceso aún no se está ejecutando, de lo contrario, muestra un mensaje de error.
stop
Detiene el proceso del servidor GUI de MooseFS si el proceso se está ejecutando, de lo contrario, muestra un mensaje de error.
restart
(acción predeterminada) Si el proceso del servidor GUI de MooseFS se está ejecutando, lo reinicia; si no se está ejecutando, lo inicia.
reload
Envía una señal al proceso del servidor GUI de MooseFS para recargar los archivos de configuración.
info
Envía una señal al proceso del servidor GUI de MooseFS para volcar un archivo de información de depuración en el directorio de trabajo.
test
Muestra "mfsgui pid: PID" si el servidor GUI de MooseFS se está ejecutando (y devuelve 0) o "mfsgui no se está ejecutando" en caso contrario (y devuelve 1).
kill
Envía una señal de terminación al proceso del servidor GUI de MooseFS.
restore
No implementado.

ARCHIVOS

mfsgui.cfg
archivo de configuración para el proceso del servidor GUI de MooseFS; consulte el manual de mfsgui.cfg(5) para más detalles
.mfsgui.lock
archivo de bloqueo del proceso del servidor GUI de MooseFS en ejecución (creado en el directorio de datos)
scripts
varios archivos de python, javascript y otros (estáticos) utilizados para servir la interfaz GUI a través de HTTP; estos archivos se instalan en el directorio que sea el predeterminado en el momento de la instalación para ROOT_DIR en mfsgui.cfg
