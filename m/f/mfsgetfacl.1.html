NOMBRE

mfsfacl - Herramientas de gestión de listas de control de acceso (atributos extendidos) de archivos de MooseFS

SINOPSIS

mfsgetfacl [-?] [-adceEspn] OBJETO [OBJETO ...]

mfssetfacl [-?] [-bKknd] [{-s|-m|-x} ESPEC_ACL] [{-S|-M|-X} ARCHIVO_ACL] OBJETO [OBJETO ...]

DESCRIPCIÓN

Estas herramientas operan sobre el valor de la lista de control de acceso (ACL) de un objeto del sistema de archivos (archivo, archivo especial o directorio). Las ACL en MooseFS son compatibles con Linux, por lo que en Linux puedes usar los comandos setfacl y getfacl.

mfsgetfacl imprime el valor actual de la ACL del objeto(s) dado(s).

mfssetfacl establece/cambia/elimina el valor actual de la ACL del objeto(s) dado(s).

OPCIONES

Opciones de mfsgetfacl:


-a - muestra solo la lista de control de acceso del archivo


-d - muestra solo la lista de control de acceso predeterminada


-c - no mostrar la cabecera del comentario


-e - imprimir todos los derechos efectivos


-E - no imprimir derechos efectivos


-s - omitir archivos que solo tienen las entradas base


-p - no eliminar el '/' inicial en los nombres de ruta


-n - imprimir identificadores numéricos de usuario/grupo

Opciones de mfssetfacl:


-b - eliminar todas las entradas de ACL extendidas


-K - eliminar la ACL de acceso


-k - eliminar la ACL predeterminada


-n - no recalcular la máscara de derechos efectivos


-d - las operaciones se aplican a la ACL predeterminada


-s - establecer la ACL de los archivos, reemplazando la ACL actual


-S - leer las entradas de ACL para establecer desde un archivo


-m - modificar la(s) ACL(s) actual(es) de los archivos


-M - leer las entradas de ACL para modificar desde un archivo


-x - eliminar entradas de la(s) ACL(s) de los archivos


-X - leer las entradas de ACL para eliminar desde un archivo

opciones comunes:


-? - mostrar mensaje de uso corto

ESPECIFICACIÓN DE ACL

Para las opciones -S, -M y -X, el parámetro ARCHIVO_ACL debe ser una ruta a un archivo que contenga especificaciones de valor de ACL como se describe a continuación (una definición por línea, se permiten múltiples líneas, el contenido después del signo # se ignora, la salida del comando mfsgetfacl es siempre un contenido de archivo válido).

ESPEC_ACL debe ser una de las siguientes:

[d[efault]:][u[ser]:]uid[:perms]

[d[efault]:]g[roup]:gid[:perms]

[d[efault]:]m[ask][:][:perms]

[d[efault]:]o[ther][:][:perms]

d significa trabajar en los valores de ACL predeterminados en lugar de los valores de acceso. La siguiente parte indica si se deben establecer los permisos del usuario, del grupo o de otros, o la máscara. Si esa parte se omite y solo se proporciona el identificador, se asume que es el identificador de usuario. Si se indica usuario o grupo, si no hay identificador, se modifican los permisos predeterminados del usuario o del grupo. El identificador puede ser una cadena o un número. Los permisos pueden tener la forma de letras, cualquier subconjunto de rwx o un número. Cero, cadena vacía o guión significan sin permisos para -s y -m. Para -x, los permisos deben omitirse. Se pueden suministrar múltiples especificaciones, separadas por coma.
