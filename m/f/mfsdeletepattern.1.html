NOMBRE

mfspatadmin - herramienta de administración de patrones de MooseFS

SINOPSIS

mfscreatepattern [-?] [-M PUNTO_MONTAJE] -n patrón [-u uid] [-g gid] [-p prioridad] [-c clase_almacenamiento] [-t retencion_papelera] [-f eattr]

mfsdeletepattern [-?] [-M PUNTO_MONTAJE] -n patrón [-u uid] [-g gid]

mfslistpattern [-?] [-M PUNTO_MONTAJE]

DESCRIPCIÓN

Este es un conjunto de herramientas para administrar patrones, que se utilizan para anular clases de almacenamiento, retención de papelera y/o atributos adicionales cada vez que se crea un archivo nuevo o se renombra un archivo existente.

mfscreatepattern agrega una nueva definición de patrón, descrita a continuación.

mfsdeletepattern elimina una definición de patrón específica

mfslistpattern lista todas las definiciones de patrones

OPCIONES

-n define el patrón que se comparará con los nombres de archivo. Este es un formato GLOB simple (ver más abajo). Esta opción debe definirse para los comandos add y delete

-u define el ID de usuario que debe ser igual al ID de usuario efectivo del usuario que crea o renombra un archivo. Si no se especifica, no se verificará el ID de usuario en la coincidencia.

-g define el ID de grupo que debe ser igual a uno de los IDs de grupo del usuario que crea o renombra un archivo. Si no se especifica, no se verificará el ID de grupo en la coincidencia.

-p prioridad de coincidencia. Cuando hay más patrones que coinciden con un nombre de archivo, los patrones con mayor prioridad tienen precedencia. La prioridad se puede definir como un valor entre 0 (más bajo) y 255 (más alto). Si no se especifica, se utiliza el valor predeterminado de 128. Si dos o más patrones con la misma prioridad coinciden con un nombre de archivo (con la prioridad más alta posible para ese archivo), solo se usará uno (no especificado) de ellos.

-c nombre de la clase de almacenamiento que se establecerá al coincidir

-t valor de retención de papelera que se establecerá al coincidir; la unidad mínima son horas, para el formato del valor consulte TIEMPO

-f nombres de banderas, separados por comas, que se establecerán al coincidir. Cada bandera debe ir precedida por un signo '+' o '-', lo que significa que esta bandera debe establecerse o desactivarse, respectivamente. Para la descripción de las banderas, consulte mfseattr(1).

-M punto de montaje de MooseFS, no es necesario especificarlo si la herramienta se ejecuta dentro de un directorio montado por MooseFS o si MooseFS está montado en /mnt/mfs/

-? muestra un mensaje de uso corto

Al menos una de las opciones -c, -t, -f debe estar definida para el comando add.

NOTAS

TIEMPO

Para las variables que definen el tiempo sin requerir una unidad única y específica, el tiempo se puede definir como un número de segundos u horas (entero), dependiendo de la unidad mínima para la variable, o como un período de tiempo en uno de dos formatos posibles:

primer formato: #.#T donde T es uno de: s-segundos, m-minutos, h-horas, d-días o w-semanas; las fracciones de la unidad mínima se redondearán

segundo formato: #s#m#h#d#w, se puede omitir cualquier número de definiciones, pero las definiciones restantes deben estar en orden (por lo tanto, #d#m sigue siendo una definición válida, pero #m#d no lo es); rangos: s,m: 0 a 59, h: 0 a 23, d: 0 a 6, w es ilimitado y la primera definición también es siempre ilimitada (es decir, para #d#h#m d será ilimitado)

Si la unidad mínima de una variable es mayor que segundos, las unidades por debajo de la unidad mínima no serán aceptadas. Por ejemplo, una variable que tiene horas como unidad mínima no aceptará unidades s y m.

Ejemplos:

1.5d es lo mismo que 1d12h, es lo mismo que 36h

2.5w es lo mismo que 2w3d12h, es lo mismo que 420h; 2w84h no es un período de tiempo válido (h no es la primera definición, por lo que está limitado por el rango de 0 a 23)

DEFINICIÓN DE PATRÓN

Un patrón es una cadena con comodines opcionales (similar a los glob de UNIX). Comodines reconocidos:

* - coincide con cualquier número de caracteres, incluidos ninguno

? - coincide con un solo carácter cualquiera

[abc] - coincide con un solo carácter dado en el corchete

[DESDE-HASTA] - coincide con un solo carácter del rango dado en el corchete

[!abc] - coincide con un solo carácter que no está dado en el corchete

[!DESDE-HASTA] - coincide con un solo carácter que no está en el rango dado en el corchete

Ejemplos de patrones:

nombreexacto - coincide solo con el archivo con el nombre 'nombreexacto'.

*.txt - coincide con cualquier archivo 'texto' (formalmente archivo con sufijo de nombre '.txt').

mi proyecto* - coincide con cualquier archivo con prefijo de nombre 'mi proyecto'.

letra[0-9] - coincide con archivos con nombres 'letra0', 'letra1', 'letra2', ... 'letra9'.

[CG]ato - coincide con archivos con nombres 'Gato' y 'Cato'.

[!0-9]* - coincide con archivos cuyos nombres no comienzan con un dígito
