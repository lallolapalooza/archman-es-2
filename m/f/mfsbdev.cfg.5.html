NOMBRE

mfsbdev.cfg - archivo de configuración del demonio de dispositivos de bloque de MooseFS

DESCRIPCIÓN

Este es el archivo de configuración que puede ser leído por la herramienta mfbsdev si se proporcionó la opción -i junto con el comando start. El archivo contiene definiciones de dispositivos de bloque (uno por línea) que deben ser inicializados cuando se inicia la herramienta mfsbdev.

Se recomienda encarecidamente no crear este archivo desde cero. En su lugar, es mejor crear todos los dispositivos necesarios usando el comando mfsbdev y sus parámetros, como se describe en mfsbdev(8), y luego listarlos con el comando mfsbdev list -i y usar la salida para crear un archivo de configuración. La siguiente descripción se proporciona para explicar el contenido del archivo de configuración y permitir su ajuste si es necesario.

FORMATO

Las líneas vacías y las líneas que comienzan con un punto y coma (;) o un signo de almohadilla (#) se ignoran. Todas las demás líneas deben coincidir con el formato:

ruta [ dispositivo|* [ nombre_enlace|* [ tamaño|* [ tamaño_bloque|* [ flags ]]]]]

La información de ruta es obligatoria y debe ser una ruta a un archivo en MooseFS que se utilizará como dispositivo de bloque; la ruta debe ser relativa a la raíz de MooseFS o a la ruta definida con la opción -S al iniciar mfsbdev, no a la raíz de su sistema de archivos local.

La información de dispositivo es opcional, si se proporciona debe apuntar a una ruta de dispositivo de bloque de red (por ejemplo, /dev/nbd1); si no está presente o se proporciona *, se utilizará el primer dispositivo de bloque disponible.

La información de nombre_enlace es opcional, si se proporciona debe indicar el nombre del enlace simbólico creado en '/dev/mfs', apuntando al dispositivo de bloque de red creado por el comando map; si no está presente o se proporciona *, se utilizará el nombre de enlace predeterminado.

La información de tamaño es opcional, si se proporciona indica el tamaño del dispositivo de bloque; si no está presente o se proporciona *, se utiliza el tamaño del archivo indicado por el primer parámetro.

La información de tamaño_bloque es opcional, si se proporciona indica el tamaño del bloque; si no está presente o se proporciona *, se utilizan 4096 bytes de bloque.

La información de flags es opcional, puede contener los siguientes flags (separados por coma si se listan más de uno) ro - dispositivo de solo lectura, rw - dispositivo de lectura/escritura, lock - el dispositivo requiere un tipo de bloqueo apropiado (compartido para ro, exclusivo para rw), nolock - el dispositivo no requiere bloqueo (intentará obtenerlo, pero ignorará el fallo); si no se proporciona nada, se asume el valor predeterminado de rw, lock; si se proporcionan dos flags conflictivos (es decir, ro y rw o lock y nolock) prevalece el último.

EJEMPLOS

Crear dispositivos de lectura/escritura con ruta de dispositivo de bloque predeterminada, nombre de enlace predeterminado, usando el tamaño del archivo como tamaño del dispositivo, con tamaño de bloque predeterminado:

my_devices/device1

my_devices/device2 * * * * rw

Crear dispositivos de solo lectura con parámetros específicos:

my_devices/device1 /dev/nbd3 mfsdevice1 67108864 1024 ro

my_devices/device2 /dev/nbd7 mfsdevice2 64MiB 1024 ro,nolock
