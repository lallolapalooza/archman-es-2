NOMBRE

mftraining - entrenamiento de características para Tesseract

SINOPSIS

mftraining -U unicharset -O lang.unicharset ARCHIVO...

DESCRIPCIÓN

mftraining toma una lista de archivos .tr, de los cuales genera los archivos inttemp (los prototipos de formas), shapetable y pffmtable (el número de características esperadas para cada carácter). (Un cuarto archivo llamado Microfeat también es escrito por este programa, pero no se usa.)

OPCIONES

-U ARCHIVO

(Entrada) El conjunto de caracteres generado por unicharset_extractor(1)

-F archivo_propiedades_fuente

(Entrada) archivo de propiedades de fuentes, cada línea es de la siguiente forma, donde cada campo excepto el nombre de la fuente es 0 o 1: 
*nombre_fuente* *cursiva* *negrita* *espaciado_fijo* *serif* *fraktur*

-X archivo_alturas_x

(Entrada) archivo de alturas x, cada línea es de la siguiente forma, donde la altura x se calcula como la altura x en píxeles de un carácter dibujado a 32pt a 300 dpi. [ Es decir, si altura base + ascendentes + descendentes = 133, ¿cuánto es la altura x? ] 
*nombre_fuente* *altura_x*

-D dir

Directorio donde escribir los archivos de salida.

-O ARCHIVO

(Salida) El conjunto de caracteres de salida que se entregará a combine_tessdata(1)
