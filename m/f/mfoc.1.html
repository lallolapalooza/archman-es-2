MFOC(1) Manual de comandos generales MFOC(1)

NOMBRE

mfoc - cracker offline de MIFARE Classic

SINOPSIS

mfoc [ -h ] [ -k CLAVE ]... [ -O ARCHIVO ] [ -P NUM ] [ -T NUM ]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando mfoc.

mfoc es un programa que rompe el cifrado de un chip MIFARE Classic y vuelca las claves del chip y el contenido de memoria descifrado a un archivo. Para ejecutarlo, necesitas tener acceso a un lector NFC y, por supuesto, a una tarjeta equipada con un chip MIFARE Classic.

OPCIONES

A continuación se incluye un resumen de las opciones.

-h
Mostrar resumen de opciones.
-k CLAVE
Intentar inicialmente CLAVE además de las claves predeterminadas.
-O ARCHIVO
Volcar el contenido de la tarjeta a ARCHIVO.
-P NUM
Sondear cada sector hasta NUM veces. El valor predeterminado es 20.
-T NUM
Establecer la mitad del rango para una posible tolerancia de distancia a NUM. El valor predeterminado es 20 (para un rango total de 40).
