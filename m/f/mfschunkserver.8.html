NOMBRE

mfschunkserver - iniciar, reiniciar o detener el proceso chunkserver de MooseFS

SINOPSIS

mfschunkserver [-c ARCHIVO_CONFIG] [-f] [-d] [-u] [-n] [-t TIEMPO_ESPERA_BLOQUEO] [ACCION]

mfschunkserver -v

mfschunkserver -h

DESCRIPCIÓN

mfschunkserver es el servidor de datos de MooseFS.

OPCIONES

-v
muestra información de la versión y sale
-h
muestra información de uso y sale
-c ARCHIVO_CONFIG
especifica una ruta alternativa para el archivo de configuración (por defecto es mfschunkserver.cfg en el directorio de configuración del sistema)
-f
ejecutar en primer plano, no demonizar
-d
ejecutar con opciones peligrosas (nombres: DANGEROUS_*)
-u
registrar valores de configuración indefinidos (cuando se asume el valor por defecto)
-n
no intentar aumentar el límite del tamaño de volcado del núcleo (core dump)
-t TIEMPO_ESPERA_BLOQUEO
cuánto esperar por el archivo de bloqueo (en segundos; el valor por defecto es 60 segundos)
ACCION
indica al chunkserver que realice una de las siguientes acciones:
start
Inicia el proceso chunkserver si el proceso no se está ejecutando, de lo contrario, muestra un mensaje de error.
stop
Detiene el proceso chunkserver si el proceso está en ejecución, de lo contrario, muestra un mensaje de error.
restart
(acción por defecto) Si el proceso chunkserver está en ejecución, lo reinicia; si no está en ejecución, lo inicia.
reload
Envía una señal al proceso chunkserver para que recargue los archivos de configuración.
info
Envía una señal al proceso chunkserver para que genere un archivo de información de depuración en el directorio de trabajo.
test
Muestra "mfschunkserver pid: PID" si el chunkserver está en ejecución (y devuelve 0) o "mfschunkserver no está en ejecución" en caso contrario (y devuelve 1).
kill
Envía una señal de terminación al proceso chunkserver.
restore
No implementado.

ARCHIVOS

mfschunkserver.cfg
archivo de configuración para el proceso chunkserver de MooseFS; consulte la página del manual mfschunkserver.cfg(5) para obtener detalles
mfshdd.cfg
lista de directorios (puntos de montaje) utilizados para el almacenamiento de MooseFS; consulte la página del manual mfshdd.cfg(5) para obtener detalles
.mfschunkserver.lock
archivo de bloqueo del proceso chunkserver de MooseFS en ejecución (creado en el directorio de datos)
chunkserverid.mfs
ID del chunkserver, asignada por el maestro de MooseFS durante la primera conexión (creado en el directorio de datos)
csstats.mfs
estadísticas de gráficos del chunkserver (creado en el directorio de datos)
.mfschunkserver_info.txt
archivo de información del chunkserver, creado al enviar la señal INFO al proceso, con parámetros de trabajo que pueden usarse para depuración/soporte (creado en el directorio de datos)
