NOMBRE

mfssupervisor - herramienta para controlar el trabajo del proceso maestro de MooseFS

SINOPSIS

mfssupervisor [-xdfrc] [-l ip del nuevo líder] [-s modo] [-B dirección local] [-H nombre del host maestro] [-P puerto de supervisión del maestro]

mfssupervisor -v

mfssupervisor -h

DESCRIPCIÓN

mfssupervisor es el programa supervisor de MooseFS. Se puede utilizar para forzar ciertas acciones de los maestros de MooseFS, como guardar metadatos o cambiar el liderazgo. Cuando no se define ninguna acción (opciones -r, -l o -s), la herramienta simplemente mostrará información sobre el estado actual de los maestros.

OPCIONES

-v
imprimir información de versión y salir
-h
imprimir información de uso y salir
-x
producir una salida más detallada
-d
(solo pro) ejecución de prueba (imprimir información, pero no cambiar nada)
-f
(solo pro) forzar la elección de un seguidor no sincronizado; ver NOTAS
-r
(solo pro) intentar resolver la situación de estados del maestro; generalmente selecciona uno de los seguidores y establece su estado a ELECT si no hay líderes o elecciones presentes
-l
(solo pro) intentar cambiar el rol del maestro con la IP dada a líder;
-c
(solo pro) ejecutar verificación de consistencia de configuración; si hay inconsistencias, se informarán a través de syslog
-s
forzar el almacenamiento de metadatos o (solo pro) la verificación de metadatos en el grupo de maestros dado (la versión pro requiere especificar un modo, valores posibles: L - solo LÍDER, F - solo SEGUIDORES, A - todos los servidores con verificación CRC, C - solo verificación CRC de todos los servidores, sin almacenar metadatos en disco)
-B
dirección local a usar para conexiones maestras (por defecto: *, es decir, la dirección local por defecto)
-H
usar el host dado para encontrar tus servidores maestros (por defecto: mfsmaster)
-P
usar el puerto dado para conectarse a tus servidores maestros (por defecto: 9419)

NOTAS

Las opciones -s, -r y -l son mutuamente excluyentes

La opción -f solo se puede usar con la opción -r

La opción -d solo se puede usar con la opción -r o -l

La opción -f no debe usarse a menos que sea necesario en situaciones donde no todos los servidores maestros definidos en DNS estén conectados (es decir, después de una caída cuando una de las máquinas maestras está fuera de línea). En un entorno donde todas las máquinas maestras están presentes, el líder debería elegirse automáticamente.
