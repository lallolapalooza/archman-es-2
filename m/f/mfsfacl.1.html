NOMBRE

mfsfacl - herramientas de gestión de listas de control de acceso (atributos extendidos) de archivos de MooseFS

SINOPSIS

mfsgetfacl [-?] [-adceEspn] OBJETO [OBJETO ...]

mfssetfacl [-?] [-bKknd] [{-s|-m|-x} ACL_ESPEC] [{-S|-M|-X} ARCHIVO_ACL] OBJETO [OBJETO ...]

DESCRIPCIÓN

Estas herramientas operan sobre el valor de la lista de control de acceso (ACL) de un objeto del sistema de archivos (archivo, archivo especial o directorio). Las ACLs en MooseFS son compatibles con Linux, por lo que en Linux puedes usar los comandos setfacl y getfacl.

mfsgetfacl imprime el valor de ACL actual del(los) objeto(s) dado(s).

mfssetfacl establece/cambia/elimina el valor de ACL actual del(los) objeto(s) dado(s).

OPCIONES

Opciones de mfsgetfacl:


-a - mostrar solo la lista de control de acceso del archivo


-d - mostrar solo la lista de control de acceso predeterminada


-c - no mostrar la cabecera del comentario


-e - imprimir todos los derechos efectivos


-E - no imprimir ningún derecho efectivo


-s - omitir archivos que solo tienen las entradas base


-p - no eliminar el '/' inicial en los nombres de ruta


-n - imprimir identificadores numéricos de usuario/grupo

Opciones de mfssetfacl:


-b - eliminar todas las entradas de ACL extendidas


-K - eliminar la ACL de acceso


-k - eliminar la ACL predeterminada


-n - no recalcular la máscara de derechos efectivos


-d - las operaciones se aplican a la ACL predeterminada


-s - establecer la ACL del(los) archivo(s), reemplazando la ACL actual


-S - leer las entradas de ACL para establecer desde un archivo


-m - modificar la(s) ACL(s) actual(es) del(los) archivo(s)


-M - leer las entradas de ACL para modificar desde un archivo


-x - eliminar entradas de la(s) ACL(s) del(los) archivo(s)


-X - leer las entradas de ACL para eliminar desde un archivo

opciones comunes:


-? - mostrar mensaje de uso corto

ESPECIFICACIÓN DE ACL

Para la opción -S, -M y -X, el parámetro ARCHIVO_ACL debe ser una ruta a un archivo que contenga las especificaciones del valor de ACL tal como se describe a continuación (una definición por línea, múltiples líneas posibles, el contenido después del signo # se ignora, la salida del comando mfsgetfacl siempre es un contenido de archivo válido).

ACL_ESPEC debe ser una de las siguientes:

[d[efault]:][u[ser]:]uid[:perms]

[d[efault]:]g[roup]:gid[:perms]

[d[efault]:]m[ask][:][:perms]

[d[efault]:]o[ther][:][:perms]

d significa operar sobre los valores de ACL predeterminados en lugar de los de acceso. La siguiente parte indica si se deben establecer los permisos del usuario, grupo u otro, o la máscara. Si se omite esa parte y solo se proporciona un identificador, se asume que es un identificador de usuario. Si se indica usuario o grupo, y no hay identificador, se modifican los permisos predeterminados del usuario o grupo. El identificador puede ser una cadena o un número. Los permisos pueden tener la forma de letras, cualquier subconjunto de rwx o un número. Cero, cadena vacía o guion significan sin permisos para -s y -m. Para -x, los permisos deben omitirse. Se pueden suministrar múltiples especificaciones, divididas por comas.
