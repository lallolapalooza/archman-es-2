NOMBRE

mfstrashtime - Herramientas DEPRECADAS de gestión del tiempo de papelera de MooseFS (use las herramientas mfstrashretention en su lugar)

SINOPSIS

mfsgettrashtime [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO...

mfssettrashtime [-?] [-r] [-n|-h|-H|-k|-m|-g] SEGUNDOS[+|-] OBJETO...

mfscopytrashtime [-?] [-r] [-n|-h|-H|-k|-m|-g] OBJETO_ORIGEN OBJETO...

DESCRIPCIÓN

Estas herramientas operan sobre el valor de trashtime de un objeto del sistema de archivos (archivo, archivo especial o directorio), es decir, el número de segundos que el archivo se conserva en el directorio especial trash antes de ser eliminado finalmente del sistema de archivos. Trashtime debe ser un valor entero no negativo.

mfsgettrashtime imprime el valor actual de trashtime del(os) objeto(s) dado(s). La opción -r habilita el modo recursivo, que funciona como de costumbre para cada archivo dado, pero para cada directorio dado adicionalmente imprime el valor actual de trashtime de todos los objetos contenidos (archivos y directorios).

mfssettrashtime cambia el valor actual de trashtime del(os) objeto(s) dado(s). Si el nuevo valor se especifica en forma SEGUNDOS+, el valor de trashtime se incrementa a SEGUNDOS para los objetos con un valor de trashtime menor y permanece sin cambios para el resto. De manera similar, si el nuevo valor se especifica como SEGUNDOS-, el valor de trashtime disminuye a SEGUNDOS para los objetos con un valor de trashtime mayor y permanece sin cambios para el resto. La opción -r habilita el modo recursivo. Estas herramientas pueden usarse en cualquier archivo, directorio o archivo eliminado (trash).

La herramienta mfscopytrashtime se puede usar para copiar el valor de trashtime de un objeto a otro.

PRECISIÓN

Desde la versión 3.0 de MooseFS, trashtime se almacena en el sistema como el número de horas que se conserva el archivo en el directorio trash. El valor dado en segundos se redondea hacia arriba a horas.

OPCIONES

La mayoría de las herramientas de MooseFS usan las opciones -n, -h, -H, -k, -m y -g para seleccionar el formato de los números impresos. -n causa que se impriman números exactos, -h usa prefijos binarios (Ki, Mi, Gi como 2^10, 2^20 etc.) mientras que -H usa prefijos SI (k, M, G como 10^3, 10^6 etc.). -k, -m y -g muestran números simples respectivamente en kibis (kilo binario - 1024), mebis (mega binario - 1024^2) y gibis (giga binario - 1024^3). Lo mismo se puede lograr configurando la variable de entorno MFSHRFORMAT a: 0 (números exactos), 1 o h (prefijos binarios), 2 o H (prefijos SI), 3 o h+ (números exactos y prefijos binarios), 4 o H+ (números exactos y prefijos SI). El valor predeterminado es imprimir solo números exactos.

La opción -? muestra un mensaje de uso breve.

NOTAS

HERENCIA

Cuando se crea un nuevo objeto en MooseFS, el trashtime se hereda del directorio padre. Un objeto recién creado hereda siempre el valor actual del trashtime de su padre. Cambiar el trashtime de un directorio no afecta a sus hijos ya creados. Para cambiar el trashtime de un directorio y todos sus hijos, use la opción -r.
