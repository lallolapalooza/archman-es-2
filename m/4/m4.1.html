M4(1) Comandos de usuario M4(1)

NOMBRE

m4 - procesador de macros

SINOPSIS

m4 [OPCIÓN]... [ARCHIVO]...

DESCRIPCION

Procesa macros en ARCHIVOs. Si no se especifica ARCHIVO o si ARCHIVO es `-', se lee la entrada estándar.

Los argumentos obligatorios u opcionales para las opciones largas son obligatorios u opcionales también para las opciones cortas.

Modos de operación:

--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale
-E, --fatal-warnings
una vez: las advertencias se convierten en errores, dos veces: detiene la ejecución en el primer error
-i, --interactive
sin búfer de salida, ignora interrupciones
-P, --prefix-builtins
fuerza un prefijo `m4_' a todas las funciones integradas
-Q, --quiet, --silent
suprime algunas advertencias para funciones integradas
--warn-macro-sequence[=REGEXP]
advierte si la definición de macro coincide con REGEXP,
por defecto \$\({[^}]*}\|[0-9][0-9]+\)
-W, --word-regexp=REGEXP
usa REGEXP para la sintaxis del nombre de la macro

Características del preprocesador:

-D, --define=NOMBRE[=VALOR]
define NOMBRE como si tuviera VALOR, o vacío
-I, --include=DIRECTORIO
añade DIRECTORIO a la ruta de inclusión
-s, --synclines
genera líneas `#line NUM "ARCHIVO"'
-U, --undefine=NOMBRE
elimina la definición de NOMBRE

Control de límites:

-g, --gnu
anula -G para reactivar las extensiones de GNU
-G, --traditional
suprime todas las extensiones de GNU
-H, --hashsize=PRIMO
establece el tamaño de la tabla hash para búsqueda de símbolos [65537]
-L, --nesting-limit=NÚMERO
cambia el límite de anidamiento, 0 para ilimitado [0]

Archivos de estado congelado:

-F, --freeze-state=ARCHIVO
produce un estado congelado en ARCHIVO al final
-R, --reload-state=ARCHIVO
carga un estado congelado desde ARCHIVO al inicio

Depuración:

-d, --debug[=FLAGS]
establece el nivel de depuración (sin FLAGS implica `aeq')
--debugfile[=ARCHIVO]
redirige la salida de depuración y rastreo a ARCHIVO (stderr por defecto, descarta si es una cadena vacía)
-l, --arglength=NÚM
restringe el tamaño del rastreo de macros
-t, --trace=NOMBRE
rastrea NOMBRE cuando se define

FLAGS es cualquiera de:

a
muestra argumentos reales
c
muestra antes de recopilar, después de recopilar y después de llamar
e
muestra la expansión
f
dice el nombre del archivo de entrada actual
i
muestra cambios en los archivos de entrada
l
dice el número de línea de entrada actual
p
muestra resultados de búsquedas de ruta
q
entrecomilla valores según sea necesario, con la bandera a o e
t
rastrea todas las llamadas a macros, no solo las que tienen rastreo activado
x
añade un ID único de llamada de macro, útil con la bandera c
V
atajo para todas las banderas anteriores

Si está definida, la variable de entorno `M4PATH' es una lista de directorios separados por dos puntos que se incluyen después de los especificados con `-I'.

El estado de salida es 0 para éxito, 1 para fallo, 63 para desajuste de versión de archivo congelado, o cualquier valor que se haya pasado a la macro m4exit.
