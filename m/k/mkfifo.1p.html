PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mkfifo — crear archivos especiales FIFO

SINOPSIS

mkfifo [-m modo] archivo...

DESCRIPCIÓN

La utilidad mkfifo creará los archivos especiales FIFO especificados por los operandos, en el orden especificado.

Para cada operando archivo, la utilidad mkfifo realizará acciones equivalentes a la función mkfifo() definida en el volumen de Interfaces del Sistema de POSIX.1-2017, llamada con los siguientes argumentos:

1.
El operando archivo se utiliza como argumento path.
2.
El valor de la operación OR inclusiva a nivel de bits de S_IRUSR, S_IWUSR, S_IRGRP, S_IWGRP, S_IROTH y S_IWOTH se utiliza como argumento modo. (Si se especifica la opción -m, el valor del argumento modo de la llamada mkfifo() no está especificado, pero el FIFO no tendrá permisos menos restrictivos que el argumento de opción -m modo en ningún momento).

OPCIONES

La utilidad mkfifo cumplirá con el volumen de Definiciones Base de POSIX.1-2017, Sección 12.2, Directrices de sintaxis de utilidades.

Se soportará la siguiente opción:

-m modo
Establece los bits de permisos del archivo del FIFO recién creado al valor de modo especificado. El argumento de opción modo será el mismo que el operando modo definido para la utilidad chmod. En las cadenas de modo_simbólico, los caracteres de operación '+' y '-' se interpretarán en relación con un modo inicial supuesto de a=rw.

OPERANDOS

Se soportará el siguiente operando:

archivo
Una ruta del archivo especial FIFO a crear.

STDIN

No se usa.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de mkfifo:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1-2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

STDOUT

No se usa.

STDERR

El error estándar solo se utilizará para mensajes de diagnóstico.

FUNDAMENTO

Esta utilidad se añadió para permitir a las aplicaciones de shell crear archivos especiales FIFO.

La opción -m se añadió para controlar el modo del archivo, en consonancia con la funcionalidad similar proporcionada por la utilidad mkdir.

Las primeras propuestas incluían una opción -p similar a la opción mkdir -p que creaba directorios intermedios hasta el FIFO especificado por el componente final. Esto se eliminó porque no es comúnmente necesario y no es una práctica común con utilidades similares.

La funcionalidad de mkfifo se describe sustancialmente a través de una referencia a la función mkfifo() en el volumen de Interfaces del Sistema de POSIX.1-2017. Por ejemplo, por defecto, el modo del archivo FIFO se ve afectado por la máscara de creación de modo de archivo de acuerdo con el comportamiento especificado de la función mkfifo(). De esta manera, se requiere menos duplicación de esfuerzos para describir los detalles de la creación del archivo.
