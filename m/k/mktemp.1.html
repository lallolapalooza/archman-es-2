MKTEMP(1) Comandos de usuario MKTEMP(1)

NOMBRE

mktemp - crear un archivo o directorio temporal

SINOPSIS

mktemp [OPCIÓN]... [PLANTILLA]

DESCRIPCIÓN

Crear un archivo o directorio temporal, de forma segura, e imprimir su nombre. PLANTILLA debe contener al menos 3 'X's consecutivas en el último componente. Si no se especifica PLANTILLA, se usa tmp.XXXXXXXXXX, y se implica --tmpdir. Los archivos se crean con permisos u+rw, y los directorios u+rwx, menos las restricciones de umask.

-d, --directory
crear un directorio, no un archivo
-u, --dry-run
no crear nada; meramente imprimir un nombre (inseguro)
-q, --quiet
suprimir diagnósticos sobre fallos de creación de archivo/directorio
--suffix=SUFF
añadir SUFF a PLANTILLA; SUFF no debe contener una barra. Esta opción se implica si PLANTILLA no termina en X
-p DIR, --tmpdir[=DIR]
interpretar PLANTILLA relativo a DIR; si DIR no se especifica, usar $TMPDIR si está establecido, si no /tmp. Con esta opción, PLANTILLA no debe ser un nombre absoluto; a diferencia de con -t, PLANTILLA puede contener barras, pero mktemp crea solo el componente final
-t
interpretar PLANTILLA como un único componente de nombre de archivo, relativo a un directorio: $TMPDIR, si está establecido; si no, el directorio especificado mediante -p; si no /tmp [obsoleto]
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir
