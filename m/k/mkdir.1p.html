MKDIR(1P) Manual del programador de POSIX MKDIR(1P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

mkdir — crear directorios

SINOPSIS

mkdir [-p] [-m modo] dir...

DESCRIPCIÓN

La utilidad mkdir creará los directorios especificados por los operandos, en el orden especificado.

Para cada operando dir, la utilidad mkdir realizará acciones equivalentes a la función mkdir() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017, llamada con los siguientes argumentos:

1.
El operando dir se utiliza como argumento path.
2.
El valor de la OR inclusiva a nivel de bits de S_IRWXU, S_IRWXG y S_IRWXO se utiliza como argumento mode. (Si se especifica la opción -m, el valor del argumento mode de mkdir() no está especificado, pero el directorio no deberá tener permisos menos restrictivos que la opción -m mode en ningún momento).

OPCIONES

La utilidad mkdir se ajustará a las Guías de Sintaxis de Utilidades del volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2.

Se soportarán las siguientes opciones:

-m modo
Establece los bits de permisos de archivo de los directorios recién creados al valor mode especificado. El argumento de opción mode será el mismo que el operando mode definido para la utilidad chmod. En las cadenas modo_simbólico, los caracteres de operación '+' y '-' se interpretarán en relación con un modo inicial asumido de a=rwx; '+' añadirá permisos al modo por defecto, '-' eliminará permisos del modo por defecto.
-p
Crea los componentes de ruta intermedios que falten.

Para cada operando dir que no nombre un directorio existente, antes de realizar las acciones descritas en la DESCRIPCIÓN, la utilidad mkdir creará los componentes de ruta del prefijo de ruta de dir que no nombren un directorio existente realizando acciones equivalentes a llamar primero a la función mkdir() con los siguientes argumentos:

1.
Un nombre de ruta que nombre el componente de ruta faltante, terminando con una barra inclinada <slash> al final, como argumento path
2.
El valor cero como argumento mode

y luego llamando a la función chmod() con los siguientes argumentos:

1.
El mismo argumento path que en la llamada a mkdir()
2.
El valor (S_IWUSR|S_IXUSR|~filemask)&0777 como argumento mode, donde filemask es la máscara de creación de modo de archivo del proceso (consulte el volumen de Interfaces del Sistema de POSIX.1‐2017, umask())

Cada operando dir que nombre un directorio existente se ignorará sin generar error.

OPERANDOS

Se soportará el siguiente operando:

dir
Un nombre de ruta de un directorio a crear.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de mkdir:

LANG
Proporciona un valor por defecto para las variables de internacionalización que no están definidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en oposición a caracteres multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Todos los directorios especificados se crearon correctamente, o se especificó la opción -p y todos los directorios especificados ya existían o se crearon correctamente.
>0
Ocurrió un error.

CONSECUENCIAS DE LOS ERRORES

Por defecto.

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

El modo de archivo por defecto para los directorios es a=rwx (777 en la mayoría de los sistemas) con permisos seleccionados eliminados de acuerdo con la máscara de creación de modo de archivo. Para los componentes de ruta intermedios creados por mkdir, el modo es el valor por defecto modificado por u+wx para que los subdirectorios puedan crearse siempre, independientemente de la máscara de creación de modo de archivo; si se desean permisos finales diferentes para los directorios intermedios, se pueden modificar posteriormente con chmod.

Tenga en cuenta que es posible que se hayan creado algunos de los directorios solicitados, incluso si ocurre un error.

EJEMPLOS

Ninguno.

FUNDAMENTO

Se incluyó la opción -m de System V para controlar el modo de archivo.

Se incluyó la opción -p de System V para crear los directorios intermedios necesarios y para complementar la funcionalidad proporcionada por rmdir para eliminar directorios en el prefijo de ruta a medida que se vacían. Dado que no se produce ningún error si algún componente de ruta ya existe, la opción -p también es útil para garantizar que existe un directorio determinado.

La funcionalidad de mkdir se describe sustancialmente a través de una referencia a la función mkdir() en el volumen de Interfaces del Sistema de POSIX.1‐2017.
