MKTEXLSR(1) Comandos de usuario MKTEXLSR(1)

NOMBRE

mktexlsr - crear bases de datos ls-R

SINOPSIS

mktexlsr [directorios]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se encuentra en el archivo info o manual Kpathsea: A library for path searching.

mktexlsr se utiliza para generar las bases de datos ls-R utilizadas por la biblioteca kpathsea. Las creará para los directorios especificados o para una lista predeterminada si no se especifican directorios.

OPCIONES

mktexlsr acepta las siguientes opciones:

--help
Imprimir mensaje de ayuda y salir.
--version
Imprimir información de versión y salir.

REPORTE DE ERRORES

Reportar errores a: tex-k@tug.org (https://lists.tug.org/tex-k)
