MKPASSWD(1) Debian GNU/Linux MKPASSWD(1)

NOMBRE

mkpasswd - Interfaz sobrecargada de funciones para crypt(3)

SINOPSIS

mkpasswd CONTRASEÑA [SAL]

DESCRIPCIÓN

mkpasswd encripta la contraseña dada con la función crypt(3) de la libc, usando la sal dada.

OPCIONES

-S CADENA, --salt=CADENA
Usa la CADENA como sal. Si comienza con $, se pasará directamente a crypt(3) sin ninguna comprobación.
-R NÚMERO, --rounds=NÚMERO
Usa NÚMERO rondas. Este argumento se ignora si el método elegido no soporta rondas variables. Para el método OpenBSD Blowfish, este es el logaritmo del número de rondas. El comportamiento no está definido si esta opción se usa sin --method.
-m TIPO, --method=TIPO
Calcula la contraseña usando el método TIPO. Si TIPO es help, se imprimirá la lista de métodos disponibles. Si TIPO comienza y termina con caracteres $, la cadena se pasará a crypt_gensalt(3) tal cual.
-5
Similar a --method=md5crypt.
-P NUM, --password-fd=NUM
Lee la contraseña del descriptor de archivo NUM en lugar de usar getpass(3). Si el descriptor de archivo no está conectado a una tty, no se imprimirá ningún texto adicional en la salida estándar más que la contraseña hasheada.
-s, --stdin
Similar a --password-fd=0.

AMBIENTE

MKPASSWD_OPTIONS
Una lista de opciones que se evaluarán antes que las especificadas en la línea de comandos.

ERRORES

Si se usa la opción --stdin, es posible que las contraseñas que contienen algunos caracteres de control no se lean correctamente.

Este programa sufre de un mal caso de "featuritis" (exceso de funcionalidades).

VER TAMBIÉN

passwd(1), passwd(5), crypt(3), crypt(5), crypt_gensalt(3), getpass(3).
