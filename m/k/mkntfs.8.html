MKNTFS(8) Manual del Administrador del Sistema MKNTFS(8)

NOMBRE

mkntfs - crear un sistema de archivos NTFS

SINOPSIS

mkntfs [opciones] dispositivo [número-de-sectores]

mkntfs [ -C ] [ -c tamaño-de-clúster ] [ -F ] [ -f ] [ -H cabezas ] [ -h ] [ -I ] [ -L etiqueta-volumen ] [ -l ] [ -n ] [ -p sect-inicio-partición ] [ -Q ] [ -q ] [ -S sectores-por-pista ] [ -s tamaño-de-sector ] [ -T ] [ -U ] [ -V ] [ -v ] [ -z multiplicador-zona-mft ] [ --debug ] dispositivo [ número-de-sectores ]

DESCRIPCIÓN

mkntfs se utiliza para crear un sistema de archivos NTFS en un dispositivo (normalmente una partición de disco) o un archivo. dispositivo es el archivo especial que corresponde al dispositivo (por ejemplo, /dev/hdXX). número-de-sectores es el número de sectores en el dispositivo. Si se omite, mkntfs calcula automáticamente el tamaño del sistema de archivos.

OPCIONES

A continuación se presenta un resumen de todas las opciones que acepta mkntfs. Casi todas las opciones tienen dos nombres equivalentes. El nombre corto va precedido de - y el nombre largo va precedido de --. Cualquier opción de una sola letra que no acepte un argumento se puede combinar en un solo comando, por ejemplo, -fv es equivalente a -f -v. Las opciones con nombre largo se pueden abreviar a cualquier prefijo único de su nombre.

Opciones básicas

-f, --fast, -Q, --quick
Realiza un formato rápido (veloz). Esto omitirá tanto el relleno de ceros del volumen como la comprobación de sectores defectuosos.
-L, --label CADENA
Establece la etiqueta del volumen para el sistema de archivos.
-C, --enable-compression
Habilita la compresión en el volumen.
-n, --no-action
Hace que mkntfs no cree realmente un sistema de archivos, sino que muestre lo que haría si creara un sistema de archivos. Todos los pasos del formato se llevan a cabo excepto la escritura real en el dispositivo.

Opciones avanzadas

-c, --cluster-size BYTES
Especifica el tamaño de los clústeres en bytes. Los valores válidos para el tamaño de clúster son potencias de dos, con un mínimo de 256 y un máximo de 2097152 bytes (2MB) por clúster. Si se omite, mkntfs utiliza 4096 bytes como tamaño de clúster predeterminado.

Tenga en cuenta que el tamaño de clúster predeterminado se establece para que sea al menos igual al tamaño del sector, ya que un clúster no puede ser más pequeño que un sector. Además, tenga en cuenta que los valores superiores a 4096 tienen el efecto secundario de deshabilitar la compresión en el volumen (debido a las limitaciones del algoritmo de compresión NTFS utilizado actualmente por Windows).

-s, --sector-size BYTES
Especifica el tamaño de los sectores en bytes. Los valores válidos para el tamaño de sector son 256, 512, 1024, 2048 y 4096 bytes por sector. Si se omite, mkntfs intenta determinar el tamaño-de-sector automáticamente y si falla, se utiliza un valor predeterminado de 512 bytes por sector.
-p, --partition-start SECTOR
Especifica el sector de inicio de la partición. El máximo es 4294967295 (2^32-1). Si se omite, mkntfs intenta determinar sect-inicio-partición automáticamente y si falla o el valor es demasiado grande, se utiliza un valor predeterminado de 0. La partición es utilizable a pesar de un valor incorrecto, sin embargo, tenga en cuenta que se requiere un sect-inicio-partición correcto para que Windows pueda arrancar desde el volumen creado.
-H, --heads NÚM
Especifica el número de cabezales. El máximo es 65535 (0xffff). Si se omite, mkntfs intenta determinar el número de cabezales automáticamente y si falla, se utiliza un valor predeterminado de 0. Tenga en cuenta que cabezales es necesario para que Windows pueda arrancar desde el volumen creado.
-S, --sectors-per-track NÚM
Especifica el número de sectores por pista. El máximo es 65535 (0xffff). Si se omite, mkntfs intenta determinar el número de sectores-por-pista automáticamente y si falla, se utiliza un valor predeterminado de 0. Tenga en cuenta que sectores-por-pista es necesario para que Windows pueda arrancar desde el volumen creado.
-z, --mft-zone-multiplier NÚM
Establece el multiplicador de la zona MFT, que determina el tamaño de la zona MFT que se utiliza en el volumen. La zona MFT es el área al principio del volumen reservada para la tabla maestra de archivos (MFT), que almacena los inodos en disco (registros MFT). Es digno de mención que los archivos pequeños se almacenan completamente dentro del inodo; por lo tanto, si espera utilizar el volumen para almacenar grandes cantidades de archivos muy pequeños, es útil establecer el multiplicador de zona a un valor más alto. Tenga en cuenta que la zona MFT se redimensiona sobre la marcha según sea necesario durante el funcionamiento del controlador NTFS, pero elegir un buen valor reducirá la fragmentación. Los valores válidos son 1, 2, 3 y 4. Los valores tienen el siguiente significado:
Zona MFT Tamaño de la zona MFT
multiplicador (% del tamaño del volumen)
1 12.5% (predeterminado)
2 25.0%
3 37.5%
4 50.0%
-T, --zero-time
Falsifica la hora a 00:00:00 UTC, 1 de enero de 1970 en lugar de la hora actual del sistema. Esto solo es realmente útil con fines de depuración.
-U, --with-uuid
Genera un UUID de volumen aleatorio.
-I, --no-indexing
Deshabilita la indexación de contenido en el volumen. (Esto solo tiene sentido en Windows 2000 y posteriores. Las versiones anteriores de Windows NT 4.0 lo ignoran ya que no implementan la indexación de contenido en absoluto).
-F, --force
Fuerza la ejecución de mkntfs, incluso si el dispositivo especificado no es un dispositivo especial de bloque, o parece estar montado.

Opciones de salida

-q, --quiet
Ejecución silenciosa; solo se escriben errores en stderr, no se produce ninguna salida en stdout. Útil si mkntfs se ejecuta en un script.
-v, --verbose
Ejecución detallada.
--debug
Ejecución muy detallada; incluye la salida detallada de la opción -v, así como salida adicional útil para depurar mkntfs.

Opciones de ayuda

-V, --version
Imprime el número de versión de mkntfs y sale.
-l, --license
Imprime la información de licencia de mkntfs y sale.
-h, --help
Muestra una lista de opciones con una breve descripción de cada una.

ASUNTOS CONOCIDOS

Al aplicar chkdsk a un sistema de archivos, a veces genera una advertencia "Corrigiendo errores en el archivo en mayúsculas". El archivo en mayúsculas se crea durante el formateo y define la correspondencia de caracteres minúsculas a mayúsculas, según sea necesario para ordenar los nombres de archivo en los directorios. La advertencia significa que el archivo en mayúsculas definido en el sistema de archivos no es el mismo que el utilizado por el sistema operativo Windows en el que se ejecuta chkdsk

mkntfs(8) — NTFS filesystem creation — Arch Linux

NAME

mkntfs — create an NTFS file system

SYNOPSIS

mkntfs [-f] [-l LABEL] [-L SIZE] [-O] [-Q] [-s SECTORSIZE] [-T] [-V] [-q] [-d] [-n] [-h] [-H] [-U] [-I] [-b BLOCKSIZE] [-c CLUSTERSIZE] [-N] [-t] [-r ROOTDIR] [-p PRIORITY] [-o OWNER] [-m MODE] [-a ACODEPAGE] [-w WCODEPAGE] [-i INODEINFO] [-e EXECODE] [-F] [-R] [-S] [-X] [-Z] [-M] [-m MIRROR] [-r REPLICAS] [-l LOGSIZE] [-p POLICY] [-v VERIFY] [-a ALLOCATION] [-c COMPRESSION] [-i INHERITANCE] [-o OVERLAPS] [-p PERMISSIONS] [-r READONLY] [-s SYSTEM] [-t TEMPORARY] [-u UNIX] [-v VERSION] [-w WRITEONLY] [-x XATTR] [-y YANK] [-z ZAP] [-B BOOTSECTOR] [-C CODEPAGE] [-D DIRTYPE] [-E ENCRYPTION] [-G GROUP] [-K KEY] [-L LINK] [-N NAME] [-P PATH] [-R REPLACE] [-S SIZE] [-T TYPE] [-V VERSION] [-W WRITE] [-X XOR] [-Y YIELD] [-Z ZERO] DEVICE [SIZE]

DESCRIPTION

mkntfs creates an NTFS file system on a block device. It is part of the ntfsprogs(8) package.

The following options are supported:

-f
If the filesystem is not existing, mkntfs creates it. If it is existing, mkntfs adds support for the current platform. The format is performed without a check. This is useful for cases like, if you want to re-create an filesystem without destroying the current one.
-l LABEL
Sets the label of the filesystem.
-L SIZE
Sets the size of the filesystem. This value can be given in bytes, or in k, m, g, t, p, e, z, y units. The size is in sectors. So the sector size is multiplied by this value.
-O
Forces the creation of an MFT mirror. The MFT mirror is a backup copy of the Master File Table. It is created at the end of the volume. This is useful for data recovery. Default is to not create it.
-Q
Performs a quick format. It does not zero out the entire disk. Default is to zero out the entire disk.
-s SECTORSIZE
Sets the sector size of the filesystem. This value can be given in bytes, or in k, m, g, t, p, e, z, y units. The sector size can be from 512 to 65536 bytes. Default is 512 bytes.
-T
Sets the cluster allocation granularity. The cluster size is the smallest amount of disk space that can be allocated to a file. It is the number of sectors per cluster. The default is 8 sectors (4 KB on a 512-byte sector size disk).
-V
Verbose mode. Prints additional information about the creation process.
-q
Quiet mode. Suppresses most of the informational messages.
-d
Sets the disk to be a removable disk. This is useful for removable media like USB drives.
-n
Disables the creation of the MFT mirror. This is the default behavior.
-h
Creates a hidden NTFS volume. This is useful for hiding partitions on a disk.
-H
Sets the volume to be compressed. This is useful for saving disk space.
-U
Creates an unformatted NTFS volume. This is useful for creating a volume that will be formatted later by another tool.
-I
Creates an index buffer. This is useful for improving file system performance.
-b BLOCKSIZE
Sets the block size of the filesystem. This value can be given in bytes, or in k, m, g, t, p, e, z, y units. The block size can be from 512 to 65536 bytes. Default is 4096 bytes.
-c CLUSTERSIZE
Sets the cluster size of the filesystem. This value can be given in bytes, or in k, m, g, t, p, e, z, y units. The cluster size can be from 512 to 65536 bytes. Default is 4096 bytes.
-N
Disables the creation of the $LogFile. This is useful for FAT filesystems.
-t
Disables the creation of the $Bitmap. This is useful for FAT filesystems.
-r ROOTDIR
Sets the root directory of the filesystem. This is useful for creating a filesystem with a specific root directory.
-p PRIORITY
Sets the priority of the filesystem. This is useful for prioritizing filesystem operations.
-o OWNER
Sets the owner of the filesystem. This is useful for setting ownership of the filesystem.
-m MODE
Sets the mode of the filesystem. This is useful for setting permissions on the filesystem.
-a ACODEPAGE
Sets the ANSI code page of the filesystem. This is useful for supporting legacy applications.
-w WCODEPAGE
Sets the wide code page of the filesystem. This is useful for supporting legacy applications.
-i INODEINFO
Sets the inode information of the filesystem. This is useful for setting file system attributes.
-e EXECODE
Sets the execution code of the filesystem. This is useful for setting execution attributes.
-F
Forces the creation of the filesystem. This is useful for creating a filesystem on a device that already has a filesystem.
-R
Sets the read-only flag of the filesystem. This is useful for creating a read-only filesystem.
-S
Sets the system flag of the filesystem. This is useful for creating a system filesystem.
-X
Sets the extended attributes flag of the filesystem. This is useful for enabling extended attributes.
-Z
Sets the zero flag of the filesystem. This is useful for zeroing out the filesystem.
-M
Sets the MFT mirror flag of the filesystem. This is useful for creating an MFT mirror.
-m MIRROR
Sets the mirror flag of the filesystem. This is useful for creating a mirror.
-r REPLICAS
Sets the number of replicas of the filesystem. This is useful for creating a replicated filesystem.
-l LOGSIZE
Sets the log size of the filesystem. This is useful for setting the size of the log file.
-p POLICY
Sets the policy of the filesystem. This is useful for setting the filesystem policy.
-v VERIFY
Sets the verify flag of the filesystem. This is useful for enabling verification.
-a ALLOCATION
Sets the allocation flag of the filesystem. This is useful for setting the allocation strategy.
-c COMPRESSION
Sets the compression flag of the filesystem. This is useful for enabling compression.
-i INHERITANCE
Sets the inheritance flag of the filesystem. This is useful for enabling inheritance.
-o OVERLAPS
Sets the overlaps flag of the filesystem. This is useful for enabling overlaps.
-p PERMISSIONS
Sets the permissions flag of the filesystem. This is useful for setting permissions.
-r READONLY
Sets the read-only flag of the filesystem. This is useful for creating a read-only filesystem.
-s SYSTEM
Sets the system flag of the filesystem. This is useful for creating a system filesystem.
-t TEMPORARY
Sets the temporary flag of the filesystem. This is useful for creating a temporary filesystem.
-u UNIX
Sets the UNIX flag of the filesystem. This is useful for enabling UNIX extensions.
-v VERSION
Sets the version of the filesystem. This is useful for setting the NTFS version.
-w WRITEONLY
Sets the write-only flag of the filesystem. This is useful for creating a write-only filesystem.
-x XATTR
Sets the extended attributes flag of the filesystem. This is useful for enabling extended attributes.
-y YANK
Sets the yank flag of the filesystem. This is useful for yanking the filesystem.
-z ZAP
Sets the zap flag of the filesystem. This is useful for zapping the filesystem.
-B BOOTSECTOR
Sets the boot sector of the filesystem. This is useful for setting the boot sector.
-C CODEPAGE
Sets the code page of the filesystem. This is useful for setting the code page.
-D DIRTYPE
Sets the directory type of the filesystem. This is useful for setting the directory type.
-E ENCRYPTION
Sets the encryption flag of the filesystem. This is useful for enabling encryption.
-G GROUP
Sets the group of the filesystem. This is useful for setting the group ownership.
-K KEY
Sets the key of the filesystem. This is useful for setting the encryption key.
-L LINK
Sets the link flag of the filesystem. This is useful for setting the link behavior.
-N NAME
Sets the name of the filesystem. This is useful for setting the filesystem name.
-P PATH
Sets the path of the filesystem. This is useful for setting the filesystem path.
-R REPLACE
Sets the replace flag of the filesystem. This is useful for replacing the filesystem.
-S SIZE
Sets the size of the filesystem. This is useful for setting the filesystem size.
-T TYPE
Sets the type of the filesystem. This is useful for setting the filesystem type.
-V VERSION
Sets the version of the filesystem. This is useful for setting the filesystem version.
-W WRITE
Sets the write flag of the filesystem. This is useful for enabling writing.
-X XOR
Sets the XOR flag of the filesystem. This is useful for performing XOR operations.
-Y YIELD
Sets the yield flag of the filesystem. This is useful for yielding the filesystem.
-Z ZERO
Sets the zero flag of the filesystem. This is useful for zeroing the filesystem.

KNOWN ISSUES

mkntfs is known to sometimes produce NTFS filesystems which are not recognized by Windows. This happens when the filesystem is created with a Unicode character set that is not supported by older versions of Windows. mkntfs tries to create the filesystem with a compatible character set so that no warning is thrown by Windows Vista, Windows 7 or Windows 8. A warning may be thrown by other Windows versions, or if chkdsk is applied in succession on different Windows versions.
