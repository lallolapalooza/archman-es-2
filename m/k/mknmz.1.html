NOMBRE

mknmz - un indexador de Namazu

SINOPSIS

mknmz [opciones] <objetivo>...

DESCRIPCIÓN

mknmz 2.0.21, un indexador de Namazu.

Archivos objetivo:

-a, --all
objetivo para todos los archivos.
-t, --media-type=MTYPE
establecer el tipo de medio para todos los archivos objetivo a MTYPE.
-h, --mailnews
igual que --media-type='message/rfc822'
--mhonarc
igual que --media-type='text/html; x-type=mhonarc'
-F, --target-list=ARCHIVO
cargar ARCHIVO que contiene una lista de archivos objetivo.
--allow=PATRÓN
establecer PATRÓN para nombres de archivo que deben permitirse.
--deny=PATRÓN
establecer PATRÓN para nombres de archivo que deben denegarse.
--exclude=PATRÓN
establecer PATRÓN para nombres de ruta que deben excluirse.
-e, --robots
excluir archivos HTML que contengan <meta name="ROBOTS" content="NOINDEX">
-M, --meta
manejar etiquetas meta de HTML para búsqueda especificada por campo.
-r, --replace=CÓDIGO
establecer CÓDIGO para reemplazar URI.
--html-split
dividir un archivo HTML con anclas <a name="...">.
--mtime=NUM
limitar por mtime igual que la opción -mtime de find(1). ej., -50 para los últimos 50 días, +50 para más de 50.

Análisis Morfológico:

-b, --use-mecab
usar MeCab para analizar japonés.
-c, --use-chasen
usar ChaSen para analizar japonés.
-k, --use-kakasi
usar KAKASI para analizar japonés.
-m, --use-chasen-noun
usar ChaSen para extraer solo sustantivos.

-L, --indexing-lang=LANG indexar con procesamiento específico del idioma.

Operaciones de Texto:

-E, --no-edge-symbol
eliminar símbolos al borde de la palabra.
-G, --no-okurigana
eliminar Okurigana en la palabra.
-H, --no-hiragana
ignorar palabras que consisten solo en Hiragana.
-K, --no-symbol
eliminar símbolos.
--decode-base64
decodificar cuerpos base64 dentro de entidades multipart.

Resumen:

-U, --no-encode-uri
no codificar URI.

-x, --no-heading-summary no crear resumen con encabezados de HTML.

Construcción de Índice:

--update=ÍNDICE
establecer ÍNDICE para actualizar.
-z, --check-filesize
detectar cambios en el tamaño del archivo.
-Y, --no-delete
no detectar documentos eliminados.
-Z, --no-update
no detectar documentos actualizados y eliminados.

Varios:

-s, --checkpoint
activar el mecanismo de punto de control.
-C, --show-config
mostrar la configuración actual.
-f, --config=ARCHIVO
usar ARCHIVO como archivo de configuración.
-I, --include=ARCHIVO
incluir su ARCHIVO de personalización.
-O, --output-dir=DIR
establecer DIR para la salida del índice.
-T, --template-dir=DIR
establecer DIR que contiene NMZ.{head,foot,body}.*.
-q, --quiet
suprimir mensajes de estado durante la ejecución.
-v, --version
mostrar la versión de namazu y salir.
-V, --verbose
ser detallado.
-d, --debug
estar en modo de depuración.
--help
mostrar esta ayuda y salir.
--norc
no leer los archivos de inicialización personal.
--
Terminar la lista de opciones.
