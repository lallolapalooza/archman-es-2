MKINITCPIO.CONF(5) Manual de mkinitcpio MKINITCPIO.CONF(5)

NOMBRE

mkinitcpio.conf - Archivo de configuración de mkinitcpio

SINOPSIS

/etc/mkinitcpio.conf

DESCRIPCIÓN

mkinitcpio intentará leer de un archivo de configuración cada vez que se invoque, /etc/mkinitcpio.conf por defecto. Este archivo define varias variables que describen el contenido de la imagen a generar. Además del archivo de configuración "principal", se leen fragmentos de configuración adicionales de /etc/mkinitcpio.conf.d/*.conf. Estos fragmentos tienen mayor precedencia y anulan el archivo de configuración principal.

VARIABLES

MODULES

Define un array de módulos adicionales que deben añadirse a la imagen. Las dependencias (incluyendo otros módulos y firmware necesario) también se añadirán a la imagen. En tiempo de ejecución, los módulos de este array que se hayan añadido a la imagen con éxito se cargarán explícitamente.

FILES

Define un array de archivos adicionales que deben añadirse a la imagen. Los archivos se añaden tal cual, y los directorios padre se añadirán si es necesario. Los archivos especificados en esta variable anularán archivos previamente añadidos de la misma ruta.

BINARIES

Define un array de binarios adicionales que deben añadirse a la imagen. Se asume que son binarios ELF dinámicos, y las dependencias de bibliotecas compartidas necesarias se añadirán automáticamente. Sin embargo, no se considera un error especificar un binario no-ELF en esta variable. Los directorios padre se añadirán si es necesario. Los archivos especificados en esta variable anularán archivos previamente añadidos de la misma ruta.

HOOKS

Define un array de hooks (ganchos) que se ejecutarán durante el proceso de construcción. El orden es importante, ya que define el orden en que se ejecutarán los hooks durante el arranque. Utilice la opción -L de mkinitcpio para listar todos los hooks disponibles y la opción -H para mostrar el texto de ayuda de un hook específico.

COMPRESSION

Define un programa para filtrar la imagen generada. El kernel entiende los formatos de compresión producidos por los compresores zstd(1), gzip(1), bzip2(1), lz4(1), lzop(1), lzma(1) y xz(1). Si no se especifica, esta configuración por defecto usa compresión zstd para Linux ≥ 5.9 y compresión gzip para Linux < 5.9. Para crear una imagen sin comprimir, defina esta variable como cat.

No es difícil darse cuenta de que un filtro como tac o rev hará que mkinitcpio informe de éxito pero genere una imagen inútil. Del mismo modo, usar un programa de compresión no listado anteriormente puede generar una imagen igualmente inútil, a pesar de ser "válida".

COMPRESSION_OPTIONS

Define un array de opciones adicionales que se pasarán al programa de compresión. Esta opción generalmente no se utiliza. Puede ser potencialmente peligrosa y causar la generación de imágenes inválidas sin ninguna señal de error.

MODULES_DECOMPRESS

Interruptor (yes/no) para decidir si los módulos de kernel cargables y su firmware deben permanecer comprimidos o descomprimirse durante la creación del initramfs. Deshabilitado por defecto para evitar la recompresión de los archivos utilizando una compresión menor y para reducir el uso de RAM durante el arranque temprano. Habilítelo para permitir una mayor reducción del tamaño de la imagen al usar compresión alta (por ejemplo, xz -9e o zstd --long --ultra -22) a costa de un mayor uso de RAM al inicio del arranque.

Tenga en cuenta que cualquier archivo comprimido se colocará en el CPIO temprano descomprimido para evitar la doble compresión.
