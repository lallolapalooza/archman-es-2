NOMBRE

mkd2html — convertidor de markdown a html

SINOPSIS

mkd2html [-css archivo] [-header cadena] [-footer cadena] [archivo]

DESCRIPCIÓN

mkd2html es una utilidad que analiza un markdown(7) con formato de archivo de texto (o stdin si no se especifica) y genera una página web. Lee archivo o archivo.text
y escribe el resultado en archivo.html (donde archivo es el argumento pasado).

mkd2html es parte de discount.

OPCIONES

-css archivo
Especifica un archivo CSS.
-header cadena
Especifica una línea para añadir a la etiqueta <header>.
-footer cadena
Especifica una línea para añadir antes de la etiqueta <body>.

VALORES DE RETORNO

La utilidad mkd2html sale con 0 en caso de éxito, y >0 si ocurre un error.

VER TAMBIÉN

markdown(1), markdown(3), markdown(7), mkd-extensions(7).
