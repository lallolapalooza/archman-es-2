MKAF(1) Manual de Comandos Generales MKAF(1)

NOMBRE

mkaf - crear un folio de archivo Performance Co-Pilot

SINOPSIS

$PCP_BINADM_DIR/mkaf [-?] [opcionesfind] nombrearchivo ...

DESCRIPCIÓN

Una colección de uno o más archivos Performance Co-Pilot (ver PCPIntro(1)) pueden combinarse con mkaf para producir un folio de archivo PCP y el archivo de control del folio de archivo asociado. Algunas herramientas de PCP utilizan mkaf para crear folios de archivo, por ejemplo, la utilidad ``record'' en las herramientas pmchart(1) y pmview(1), para facilitar la reproducción con pmafm(1).

mkaf procesa cada argumento nombrearchivo, y si este es un archivo componente de un archivo PCP, dicho archivo se añade al folio.

Si nombrearchivo es un directorio, se busca recursivamente utilizando find(1). Cualquier argumento nombrearchivo que comience con un ``-'' se asume que es una opción de línea de comandos de find(1) (opcionesfind); el valor por defecto es -follow si no se especifican opcionesfind.

Se asume que el primer archivo del folio está asociado con el host por defecto para cualquier herramienta que intente reproducir múltiples archivos del folio.

El archivo de control del folio se escribe en la salida estándar y tiene el siguiente formato.

1.
La primera línea contiene la palabra PCPFolio.
2.
La segunda línea contiene la etiqueta Version: seguida del número de versión del formato (actualmente 1).
3.
Para las líneas subsiguientes, se ignoran las líneas en blanco y las líneas que comienzan con ``#''.
4.
La línea que comienza con la etiqueta Created: documenta dónde y cuándo se creó el folio.
5.
La línea que comienza con la etiqueta Creator: identifica la herramienta que creó el folio (y se asume que sabe cómo reproducir el folio de archivo). Si está presente, el segundo argumento es el nombre de un archivo de configuración que la herramienta creadora podría usar para reproducir el folio de archivo, por ejemplo, con el comando replay de pmafm(1). En el caso de mkaf (a diferencia de pmchart(1) o pmview(1)) no hay conocimiento del contenido de los archivos, por lo que el ``creador'' no puede reproducir el archivo, sin embargo pmchart(1) puede reproducir cualquier archivo, y por lo tanto esta herramienta se identifica como el Creator: para folios de archivo creados por mkaf(1).
6.
A continuación, siguen una o más líneas que comienzan con la etiqueta Archive: seguida del nombre de host y el nombre base del archivo.

Por ejemplo: $ mkaf mydir/gonzo
podría producir el siguiente archivo de control del folio.

PCPFolio
Version: 1
# use pmafm(1) to process this PCP archive folio
#
Created: on gonzo at Tue Jul  2 03:35:54 EST 1996
Creator: pmchart
#               Host                    Basename
#
Archive:        gonzo                   mydir/gonzo/960627
Archive:        gonzo                   mydir/gonzo/960628
Archive:        gonzo                   mydir/gonzo/960629
Archive:        gonzo                   mydir/gonzo/960630
Archive:        gonzo                   mydir/gonzo/960701
Archive:        gonzo                   mydir/gonzo/960701.00.10
Archive:        gonzo                   mydir/gonzo/960701.05.25
Archive:        gonzo                   mydir/gonzo/960702.00.10

OPCIONES

Las opciones disponibles en la línea de comandos son:

-?
Muestra el mensaje de uso y sale.
-opcionesfind
Opciones que se pasarán a find(1). El valor por defecto es -follow.

Se informan algunos mensajes informativos, advertencias y condiciones patológicas en el error estándar.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

find(1), PCPIntro(1), pmafm(1), pmchart(1), pmview(1), pcp.conf(5) y pcp.env(5).
