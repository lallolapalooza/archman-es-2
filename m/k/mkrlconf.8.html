NOMBRE

mkrlconf - Crear un archivo de configuración del kernel de Linux para rEFInd

SINOPSIS

mkrlconf [ --force ]

DESCRIPCIÓN

Para arrancar un kernel de Linux directamente, rEFInd normalmente debe pasar parámetros específicos del sistema para ayudar al kernel a localizar su disco RAM inicial (initrd), el sistema de archivos raíz de la instalación, etc. rEFInd almacena esta información en un archivo llamado refind_linux.conf, que se almacena en el mismo directorio que el(los) kernel(es) al(los) que se aplica. El script mkrlconf crea este archivo de configuración en /boot, utilizando las opciones de arranque actuales (de /proc/cmdline) para poblar /boot/refind_linux.conf con opciones de arranque que son probablemente (pero no con certeza) correctas.

El archivo creado de esta manera tiene tres líneas, que corresponden a tres entradas en el menú de subopciones de rEFInd. La primera entrada arranca usando las opciones encontradas en /proc/cmdline. La segunda entrada arranca usando las mismas opciones que la primera, pero con single añadido. La tercera entrada arranca con opciones mínimas de ro root={CURRENT_ROOT_DEVICE}, donde {CURRENT_ROOT_DEVICE} identifica el sistema de archivos raíz (/) actual. Los usuarios pueden editar manualmente el archivo refind_linux.conf para adaptarlo a sus necesidades, por supuesto.

OPCIONES

--force
Normalmente, si mkrlconf encuentra un archivo /boot/refind_linux.conf existente, se niega a reemplazarlo. La opción --force hace que mkrlconf reemplace el archivo existente en favor de uno que genera.
