NOMBRE

mkd_functions — accede y procesa documentos Markdown.

BIBLIOTECA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

int
mkd_compile(MMIOT *document, int flags);

int
mkd_css(MMIOT *document, char **doc);

int
mkd_generatecss(MMIOT *document, FILE *output);

int
mkd_document(MMIOT *document, char **doc);

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

DESCRIPCIÓN

El formato markdown soportado en esta implementación incluye bloques de cabecera y en línea <style> al estilo Pandoc, y las funciones estándar de markdown(3) no proporcionan acceso a los datos proporcionados por ninguna de esas extensiones. Estas funciones le dan acceso a esos datos, además de proporcionar una forma más granular de convertir documentos de Markdown a HTML.

Dado un MMIOT* generado por mkd_in() o mkd_string(), mkd_compile() compila el documento en secciones de <style>, Pandoc y html.

Una vez compilado, el documento puede ser examinado y escrito por las funciones mkd_css(), mkd_document(), mkd_generatecss(), mkd_generatehtml(), mkd_generatetoc(), mkd_toc(), mkd_xhtmlpage(), mkd_doc_title(), mkd_doc_author(), y mkd_doc_date().

mkd_css() asigna una cadena y la rellena con cualquier sección <style> proporcionada en el documento, mkd_generatecss() escribe cualquier sección <style> en la salida, mkd_document() apunta text al texto del documento y devuelve el tamaño del documento, mkd_generatehtml() escribe el resto del documento en la salida, y mkd_doc_title(), mkd_doc_author(), mkd_doc_date() se utilizan para leer el contenido de una cabecera Pandoc, si la hay.

mkd_xhtmlpage() escribe una página xhtml que contiene el documento. Se puede pasar el conjunto regular de flags.

mkd_toc() escribe un esquema del documento, en forma de colección de listas anidadas con enlaces a cada cabecera del documento, en una cadena asignada con malloc(), y devuelve el tamaño.

mkd_generatetoc() es como mkd_toc(), excepto que escribe el esquema del documento en el argumento FILE* dado.

mkd_cleanup() elimina un MMIOT* después de que se ha completado el procesamiento.

mkd_compile() acepta las mismas flags que markdown() y mkd_string() hacen;

MKD_NOIMAGE
No procesar `![]' y eliminar las etiquetas <img> de la salida.
MKD_NOLINKS
No procesar `[]' y eliminar las etiquetas <a> de la salida.
MKD_NOPANTS
No hacer el manejo de citas, guiones largos o elipses al estilo Smartypants.
MKD_TAGTEXT
Procesar la entrada como si estuviera dentro de una etiqueta html. Esto significa que no se generarán etiquetas html, y mkd_compile() intentará escapar cualquier cosa que pueda confundir terriblemente a un navegador web.
MKD_NO_EXT
No procesar ningún protocolo pseudo-markdown al manejar enlaces [][].
MKD_NOHEADER
No intentar analizar ninguna cabecera al estilo Pandoc.
MKD_TOC
Etiquetar todas las cabeceras para su uso con la función mkd_generatetoc().
MKD_1_COMPAT
Flag de compatibilidad con MarkdownTest_1.0; recortar espacios finales de la primera línea de los bloques de código y deshabilitar enlaces de referencia implícitos.
MKD_NOSTRIKETHROUGH
Deshabilitar el soporte para tachado.

VALORES DE RETORNO

La función mkd_compile() devuelve 1 en caso de éxito, o 0 si el documento ya está compilado. La función mkd_generatecss() devuelve el número de bytes escritos en caso de éxito, o EOF si ocurrió un error. La función mkd_generatehtml() devuelve 0 en caso de éxito, -1 en caso de fallo.
