MKFONTSCALE(1) Manual de Comandos Generales MKFONTSCALE(1)

NOMBRE

mkfontscale - crea un índice de archivos de fuentes escalables para X

SINOPSIS

mkfontscale [ -b ] [ -s ] [ -o archivo ] [ -x sufijo ] [ -a codificación ] ... [ -f fuzz ] [ -l ] [ -e directorio ] [ -p prefijo ] [ -r prefijo ] [ -n prefijo ] [ -u | -U ] [ -v ] [ -- ] [ directorio ] ...

DESCRIPCIÓN

Para cada directorio argumento, mkfontscale lee todos los archivos de fuentes escalables del directorio. Por cada archivo de fuente encontrado, se genera un nombre de fuente X11 (XLFD), y se escribe junto con el nombre del archivo en un archivo fonts.scale en el directorio.

El archivo fonts.scale resultante debe ser revisado y posiblemente editado manualmente antes de ser utilizado como entrada para el programa mkfontdir(1).

OPCIONES

-b
lee fuentes de mapa de bits. Por defecto, las fuentes de mapa de bits se ignoran.
-s
ignora fuentes escalables. Por defecto, se leen fuentes escalables. Si se establece -b, esta bandera tiene el efecto secundario de habilitar la lectura de archivos fonts.scale.
-o archivo
envía la salida del programa a archivo; el valor predeterminado es fonts.scale si no se están leyendo fuentes de mapa de bits, y fonts.dir si se están leyendo. Si archivo es relativo, se crea en el directorio que se está procesando. Si es el valor especial -, la salida se escribe en la salida estándar.
-x sufijo
excluye todos los archivos con el sufijo especificado.
-a codificación
agrega codificación a la lista de codificaciones buscadas.
-f fuzz
establece la fracción de caracteres que pueden faltar en codificaciones grandes a fuzz por ciento. El valor predeterminado es 2%.
-l
Escribe archivos fonts.dir adecuados para implementaciones que no pueden volver a codificar fuentes heredadas (BDF y PCF). Por defecto, se asume que la implementación puede volver a codificar fuentes heredadas codificadas en Unicode.
-e
especifica un directorio con archivos de codificación. Cada directorio de este tipo se escanea en busca de archivos de codificación, cuya lista se escribe en un archivo "encodings.dir" en cada directorio de fuentes.
-p
Especifica un prefijo que se antepone a los nombres de ruta de los archivos de codificación al escribirlos en el archivo "encodings.dir". El prefijo se antepone literalmente: si se requiere una `/` entre el prefijo y los nombres de ruta, debe proporcionarse explícitamente como parte del prefijo.
-r
Mantiene los directorios de codificación no absolutos en su forma relativa al escribir el archivo "encodings.dir". El valor predeterminado es convertir los directorios de codificación relativos a absolutos anteponiendo el directorio actual. La posición de esta opción es significativa, ya que esta opción solo se aplica a las opciones -e posteriores.
-n
no busca fuentes, no escribe archivos de directorio de fuentes. Esta opción es útil cuando solo se generan directorios de codificación.
-u, -U
deshabilita (-u) o habilita (-U) la indexación de las codificaciones de fuentes ISO 10646:1 (predeterminado: habilitado).
-v
imprime la versión del programa y sale.
--
fin de las opciones.

VER TAMBIÉN

X(7), Xserver(1), mkfontdir(1), ttmkfdir(1), xfs(1), xset(1)

NOTAS

El formato de los archivos fonts.scale, fonts.dir y encodings.dir está documentado en la página del manual de mkfontdir(1).

Mkfontscale sobrescribirá cualquier archivo fonts.scale incluso si ha sido editado manualmente.

mkfontscale -b -s -l es equivalente a mkfontdir.

AUTOR

La versión de mkfontscale incluida en esta versión de la Fundación X.Org fue escrita originalmente por Juliusz Chroboczek <jch@freedesktop.org> para el proyecto XFree86. La funcionalidad de este programa se inspiró en la utilidad ttmkfdir de Joerg Pommnitz.
