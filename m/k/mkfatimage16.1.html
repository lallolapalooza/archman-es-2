MKFATIMAGE16(1) Crea una imagen de disco duro para DOSEMU MKFATIMAGE16(1)

NOMBRE

mkfatimage16 - genera una imagen de disco duro adecuada para DOSEMU

SINOPSIS

mkfatimage16 [ -b archivo-sect-arranque ] [{ -t cilindros | -k Kbytes }] [ -l etiqueta-volumen ] [ -f archivo-salida ] [ -p ] [ archivo... ]

DESCRIPCIÓN

mkfatimage16 crea un archivo de imagen de disco duro para DOSEMU que está precargado con los archivos especificados en la línea de comandos. La salida se escribe en stdout (por lo tanto, no olvide añadir " > archivo-imagen-disco", de lo contrario verá basura en la pantalla) o en el archivo especificado por la opción -f. Para esta última opción, también puede usar la opción -p para forzar el relleno hasta el tamaño dado. Este relleno dará como resultado los llamados agujeros en un sistema de archivos ext2, por lo que el uso real del disco no será mayor. El archivo creado por mkfatimage16 puede ser utilizado como una unidad virtual, cuando se define en /etc/dosemu.conf. Mientras -k no se proporcione, el número de cabezales es siempre 4 y tiene 17 sectores por cabezal, de lo contrario se ajusta en consecuencia. Para variar el tamaño, puede usar la opción -t o especificar la cantidad total de Kbytes con la opción -k.

Todos los archivos proporcionados después de las opciones se copiarán en la imagen del disco. Además, se establece un registro de arranque maestro (MBR) adecuado para DOSEMU y, mediante la opción -b, puede especificar un sector de arranque que se insertará como el primer sector de la partición. Para acceder más tarde a la imagen del disco fuera de DOSEMU, debe usar mtools (parámetros de /etc/mtools.conf partition=1 y offset=128).

OPCIONES

-b archivo
Inserta los primeros 512 bytes de archivo en el sector de arranque de la partición.
-t num
Hace que el disco virtual tenga num cilindros. Esta es una forma de definir el tamaño del disco.
-k Kbytes
Hace que el disco virtual tenga un tamaño de Kbytes. El uso de -t y -k son mutuamente excluyentes.
-l etiqueta
Inserta etiqueta como etiqueta del volumen para el disco.
-f archivo-salida
La imagen del disco se escribe en archivo-salida en lugar de stdout.
-p
Rellena la imagen del disco con ceros hasta el tamaño total dado por -t o -k (solo en conjunción con -f).

AUTOR

Pasi Eronen (pe@iki.fi) y Peter Wainwright.

ERRORES

Este programa no soporta la transformación de nombres y realiza muy pocas comprobaciones para nombres de archivo no compatibles con DOS. La condición de disco lleno no se detecta (y probablemente causa un comportamiento errático). Los archivos duplicados no se detectan.

DISPONIBILIDAD

Viene con DOSEMU
