MKFONTDIR(1) Manual de Comandos Generales MKFONTDIR(1)

NOMBRE

mkfontdir - crea un índice de archivos de fuentes X en un directorio

SINOPSIS

mkfontdir [-n] [-x sufijo] [-r] [-p prefijo] [-e nombre-del-directorio-de-codificación] ... [--] [nombre-del-directorio ... ]

DESCRIPCIÓN

Para cada argumento de directorio, mkfontdir lee todos los archivos de fuentes del directorio buscando propiedades llamadas "FONT", o (en su defecto) el nombre del archivo despojado de su sufijo. Estos se convierten a minúsculas y se utilizan como nombres de fuentes, y junto con el nombre del archivo de fuente, se escriben en el archivo "fonts.dir" en el directorio. El servidor X y el servidor de fuentes utilizan "fonts.dir" para encontrar los archivos de fuentes.

Los tipos de archivos de fuentes leídos por mkfontdir dependen de los parámetros de configuración, pero típicamente incluyen PCF (sufijo ".pcf"), SNF (sufijo ".snf") y BDF (sufijo ".bdf"). Si una fuente existe en múltiples formatos, mkfontdir elegirá primero PCF, luego SNF y finalmente BDF.

La primera línea de fonts.dir indica el número de fuentes en el archivo. Las líneas restantes enumeran las fuentes mismas, una por línea, en dos campos. El primero es el nombre del archivo de fuente, seguido de un espacio y el nombre de la fuente.

FUENTES ESCALABLES

Debido a que los archivos de fuentes escalables no suelen incluir el nombre de la fuente X, el archivo "fonts.scale" se puede utilizar para nombrar las fuentes escalables en el directorio. Las fuentes listadas en él son copiadas a fonts.dir por mkfontdir. "fonts.scale" tiene el mismo formato que el archivo "fonts.dir", y puede ser creado con el programa mkfontscale(1).

ALIAS DE NOMBRES DE FUENTES

El archivo "fonts.alias", que se puede colocar en cualquier directorio de la ruta de fuentes, se utiliza para mapear nuevos nombres a fuentes existentes, y debe ser editado manualmente. El formato son dos columnas separadas por espacios en blanco, la primera contiene alias y la segunda contiene patrones de nombres de fuentes. Las líneas que comienzan con "!" son líneas de comentario y se ignoran.

Si ni el alias ni el valor especifican los campos de tamaño del nombre de la fuente, este es un alias escalable. Un nombre de fuente de cualquier tamaño que coincida con este alias se mapeará al mismo tamaño de la fuente a la que se resuelve el alias.

Cuando se utiliza un alias de fuente, el nombre al que hace referencia se busca de la manera normal, buscando en cada directorio de fuentes en secuencia. Esto significa que los alias no necesitan mencionar fuentes en el mismo directorio que el archivo de alias.

Para incrustar espacios en blanco en cualquier nombre, simplemente encerrarlo entre comillas dobles; para incrustar comillas dobles (o cualquier otro carácter), precederlos con una barra invertida:

"alias-mágico con espacios"	"nombre-de-fuente con comillas"
alias-regular			fixed

Si la cadena "FILE_NAMES_ALIASES" aparece sola en una línea, cada nombre de archivo en el directorio (despojado de su sufijo) se utilizará como un alias para esa fuente.

ARCHIVOS DE CODIFICACIÓN

La opción -e se puede utilizar para especificar un directorio con archivos de codificación. Cada directorio de este tipo se escanea en busca de archivos de codificación, la lista de los cuales se escribe en un archivo "encodings.dir" en cada directorio de fuentes. El archivo "encodings.dir" es utilizado por el servidor para encontrar información de codificación.

El archivo "encodings.dir" tiene el mismo formato que "fonts.dir". Mapea nombres de codificación (cadenas del formato CHARSET_REGISTRY-CHARSET_ENCODING ) a nombres de archivos de codificación.

OPCIONES

Las siguientes opciones son compatibles:

-e
Especifica un directorio que contiene archivos de codificación. La opción -e puede especificarse varias veces, y se leerán todos los directorios especificados. El orden de las entradas es significativo, ya que las codificaciones encontradas en directorios anteriores anulan las de directorios posteriores; los archivos de codificación en el mismo directorio se discriminan prefiriendo las versiones comprimidas.
-n
no escanea en busca de fuentes, no escribe archivos de directorio de fuentes. Esta opción es útil cuando se generan solo directorios de codificación.
-p
Especifica un prefijo que se antepone a los nombres de ruta de los archivos de codificación cuando se escriben en el archivo "encodings.dir". El prefijo se antepone tal cual. Si se requiere una `/` entre el prefijo y los nombres de ruta, debe proporcionarse explícitamente como parte del prefijo.
-r
Mantiene los directorios de codificación no absolutos en su forma relativa al escribir el archivo "encodings.dir". El valor predeterminado es convertir los directorios de codificación relativos a absolutos anteponiendo el directorio actual. La posición de esta opción es significativa, ya que esta opción solo se aplica a las opciones -e subsiguientes.
-x sufijo
Ignora los archivos de fuentes del tipo sufijo.
--
Fin de las opciones.

ARCHIVOS

fonts.dir
Lista de fuentes en el directorio y los archivos en los que están almacenadas. Creado por mkfontdir. Leído por el servidor X y el servidor de fuentes cada vez que se establece la ruta de fuentes (ver xset(1)).
fonts.scale
Lista de fuentes escalables en el directorio. El contenido se copia a fonts.dir por mkfontdir. Puede ser creado con mkfontscale(1).
fonts.alias
Lista de alias de nombres de fuentes. Leído por el servidor X y el servidor de fuentes cada vez que se establece la ruta de fuentes (ver xset(1)).
encodings.dir
Lista de codificaciones conocidas y los archivos en los que están almacenadas. Creado por mkfontdir. Leído por el servidor X y el servidor de fuentes cada vez que se abre una fuente con un juego de caracteres desconocido.
