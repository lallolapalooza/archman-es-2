NOMBRE

mkd-extensions — Extensiones a la sintaxis de formato de texto Markdown

DESCRIPCIÓN

Esta versión de markdown ha sido extendida de varias maneras, extendiendo el marcado existente, creando nuevo marcado desde cero y tomando prestado marcado de otros lenguajes de marcado.

Dimensiones de imagen

Las imágenes incrustadas en Markdown han sido extendidas para permitir especificar las dimensiones de la imagen añadiendo un nuevo argumento =/altura/x/ancho/ a la descripción del enlace.

La nueva sintaxis de imagen es

![texto alternativo](imagen =/altura/x/ancho/ "título")

protocolos pseudo

Se han añadido cinco pseudo-protocolos a los enlaces

id:
El texto alternativo se marca y se escribe en la salida, envuelto con <a id=id> y </a>.
clase:
El texto alternativo se marca y se escribe en la salida, envuelto con <span class=clase> y </span>.
crudo:
El título se escribe -- sin más procesamiento -- en la salida. El texto alternativo se descarta.
abbr:
El texto alternativo se marca y se escribe en la salida, envuelto con <abbr title=abbr> y </abbr>.
lang:
El texto alternativo se marca y se escribe en la salida, envuelto con <span lang=lang> y </span>.

Cabeceras Pandoc

El documento fuente de markdown puede tener una cabecera de Pandoc de 3 líneas en el formato

% título
% autor(es)
% fecha

que estará disponible para las funciones mkd_doc_title(), mkd_doc_author(), y mkd_doc_date().

Listas de definición

Un elemento de lista de definición se define como

=etiqueta=
    descripción

(es decir, un =, seguido de texto, otro =, un salto de línea, 4 espacios de indentación, y luego más texto.)

Alternativamente, los elementos de lista de definición se definen como

etiqueta
: descripción
(Este es el formato que usa PHP Markdown Extra.)

hojas de estilo incrustadas

Se pueden definir y modificar hojas de estilo en un bloque <style>. Un bloque de estilo se analiza como cualquier otro HTML a nivel de bloque; <style> comenzando en la columna 1, seguido de HTML crudo (o, en este caso, CSS), y terminando con un </style> al final de la línea o un </style> al principio de una línea posterior.

Tenga en cuenta que los bloques de estilo funcionan como los enlaces de notas al pie: sin importar dónde los defina, son válidos para todo el documento.

listas alfabéticas

Se admiten listas alfabéticas (como las listas numéricas regulares, pero con elementos alfabéticos). Así:

a. esto
b. es
c. una lista alfabética
d. lista

producirá:

<ol type=a>
<li>esto</li>
<li>es</li>
<li>una lista alfabética</li>
<li>lista</li>
</ol>

tablas

Se admiten tablas de PHP Markdown Extra; la entrada del tipo

encabezado|encabezado
------|------
 texto | texto

producirá:

<table>
<thead>
<tr>
<th>encabezado</th>
<th>encabezado</th>
</tr>
</thead>
<tbody>
<tr>
<td>texto</td>
<td>texto</td>
</tr>
</tbody>
</table>

La línea de guiones también puede contener caracteres : para el formato; si un : está al principio de una columna, le indica a discount que alinee el contenido de la celda a la izquierda; si está al final, alinea a la derecha, y si hay uno al principio y al final, lo centra.

tachado

Se admite una sintaxis de tachado de manera muy similar a como se usa ` para definir una sección de código. Si encierra texto con dos o más tildes, como ~~texto tachado~~ se escribirá como <del>texto tachado</del>. Al igual que con las secciones de código, puede usar tantas ~ como desee, pero debe haber tantas tildes de inicio como de cierre.

notas al pie estilo Markdown Extra

Se admiten las notas al pie de PHP Markdown Extra. Si un enlace de nota al pie comienza con una ^, el primer uso de esa nota al pie generará un enlace hasta el final del documento renderizado, que contendrá una nota al pie numerada con un enlace de vuelta a donde se llamó la nota al pie.
