MKTEXPK(1) Comandos de usuario MKTEXPK(1)

NOMBRE

mktexpk - crea un archivo PK para una fuente

SINOPSIS

mktexpk [opciones] fuente [redirección]

DESCRIPCIóN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se encuentra en el archivo info o en el manual Kpathsea: A library for path searching.

mktexpk se utiliza para generar un archivo pk a partir de los archivos fuente Metafont o de fuentes type1 para fuente, si es posible.

Si se proporciona redirección, debe ser una cadena del tipo >&n donde n es el número del descriptor de archivo que recibirá, en lugar de la salida estándar, el nombre del archivo generado.

mktexpk suele ser llamado por otros programas, en lugar de desde la línea de comandos.

OPCIONES

mktexpk acepta las siguientes opciones:

--bdpi num
Establece la resolución del dispositivo base.
--dpi num
Genera la fuente con una resolución de num.
--help
Imprime el mensaje de ayuda y sale.
--mag mag
La magnificación de Metafont que corresponde a la combinación de bdpi y dpi que se ha especificado.
--mfmode mode
El modo Metafont a utilizar.
--destdir dir
Un nombre de directorio. Si el directorio es absoluto, se utiliza tal cual. De lo contrario, se añade al directorio de destino raíz establecido en el script.
--version
Imprime la información de la versión y sale.

ERRORES

Si no se especifica el modo, mktexpk intenta determinarlo a partir de bdpi. La forma en que se hace esto es primitiva. Dado que bpdi no proporciona información suficiente para determinar unívocamente un modo, se recomienda encarecidamente que se especifique explícitamente.

Si el modo y bpdi no coinciden, se descarta el modo.

El parámetro dpi es redundante, pero no se comprueba su consistencia. Peor aún, el programa fallará si se especifica el dpi incorrecto.

VER TAMBIéN

mktexmf(1), mktextfm(1).
