NOMBRE

mkd_functions — acceder y procesar documentos Markdown.

LIBRERÍA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

int
mkd_compile(MMIOT *documento, int flags);

int
mkd_css(MMIOT *documento, char **doc);

int
mkd_generatecss(MMIOT *documento, FILE *salida);

int
mkd_document(MMIOT *documento, char **doc);

int
mkd_generatehtml(MMIOT *documento, FILE *salida);

int
mkd_xhtmlpage(MMIOT *documento, int flags, FILE *salida);

int
mkd_toc(MMIOT *documento, char **doc);

void
mkd_generatetoc(MMIOT *documento, FILE *salida);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

DESCRIPCIÓN

El formato markdown soportado en esta implementación incluye bloques de encabezado y en línea de estilo Pandoc <style>, y las funciones estándar de markdown(3) no proporcionan acceso a los datos proporcionados por ninguna de esas extensiones. Estas funciones le dan acceso a esos datos, además proporcionan una forma más detallada de convertir documentos de Markdown a HTML.

Dado un MMIOT* generado por mkd_in() o mkd_string(), mkd_compile() compila el documento en secciones <style>, Pandoc, y html.

Una vez compilado, el documento puede ser examinado y escrito por las funciones mkd_css(), mkd_document(), mkd_generatecss(), mkd_generatehtml(), mkd_generatetoc(), mkd_toc(), mkd_xhtmlpage(), mkd_doc_title(), mkd_doc_author(), y mkd_doc_date().

mkd_css() asigna una cadena y la puebla con cualquier sección <style> proporcionada en el documento, mkd_generatecss() escribe cualquier sección <style> en la salida, mkd_document() apunta text al texto del documento y devuelve el tamaño del documento, mkd_generatehtml() escribe el resto del documento en la salida, y mkd_doc_title(), mkd_doc_author(), mkd_doc_date() se usan para leer el contenido de un encabezado de Pandoc, si existe.

mkd_xhtmlpage() escribe una página xhtml que contiene el documento. Se puede pasar el conjunto regular de flags.

mkd_toc() escribe un esquema del documento, en forma de una colección de listas anidadas con enlaces a cada encabezado del documento, en una cadena asignada con malloc(), y devuelve el tamaño.

mkd_generatetoc() es como mkd_toc(), excepto que escribe el esquema del documento en el argumento FILE* dado.

mkd_cleanup() elimina un MMIOT* una vez finalizado el procesamiento.

mkd_compile() acepta los mismos flags que markdown() y mkd_string();

MKD_NOIMAGE
No procesar `![]' y eliminar las etiquetas <img> de la salida.
MKD_NOLINKS
No procesar `[]' y eliminar las etiquetas <a> de la salida.
MKD_NOPANTS
No hacer el procesamiento de SmartyPants para comillas, guiones o elipses.
MKD_TAGTEXT
Procesar la entrada como si estuviera dentro de una etiqueta html. Esto significa que no se generarán etiquetas html, y mkd_compile() intentará escapar cualquier cosa que pueda confundir terriblemente a un navegador web.
MKD_NO_EXT
No procesar ningún pseudo-protocolo de markdown al manejar enlaces [][].
MKD_NOHEADER
No intentar analizar ningún encabezado de estilo Pandoc.
MKD_TOC
Etiquetar todos los encabezados para su uso con la función mkd_generatetoc().
MKD_1_COMPAT
Flag de compatibilidad con MarkdownTest_1.0; recortar espacios finales de la primera línea de los bloques de código y deshabilitar los enlaces de referencia implícitos.
MKD_NOSTRIKETHROUGH
Deshabilitar el soporte para tachado.

VALORES DE RETORNO

La función mkd_compile() devuelve 1 en caso de éxito, o 0 si el documento ya está compilado. La función mkd_generatecss() devuelve el número de bytes escritos en caso de éxito, o EOF si ocurrió un error. La función mkd_generatehtml() devuelve 0 en caso de éxito, -1 en caso de fallo.

VER TAMBIÉN

markdown(1), markdown(3), mkd-line(3), markdown(7)

NAME

mkd_doc_date, mkd_doc_version, mkd_doc_url, mkd_doc_comment, mkd_doc_code, mkd_doc_list, mkd_doc_block, mkd_doc_line, mkd_doc_toc, mkd_doc_date_fmt — discount library document parsing

LIBRARY

Discount Library (libdiscount), linking with -l discount

Synopsis

#include <discount.h>

char *mkd_doc_date(time_t *t);
char *mkd_doc_version(void);
char *mkd_doc_url(void);
char *mkd_doc_comment(void);
char *mkd_doc_code(void);
char *mkd_doc_list(void);
char *mkd_doc_block(void);
char *mkd_doc_line(void);
char *mkd_doc_toc(void);
char *mkd_doc_date_fmt(const char *fmt, time_t *t);

DESCRIPTION

These functions are intended to return strings containing documentation snippets, primarily for use in man pages.

mkd_doc_date returns a string with the date of the last modification of the source code, in the format used by ctime(3). If t is not NULL, the time value is also stored in *t.

mkd_doc_version returns a string with the version of the Discount library.

mkd_doc_url returns a string with the URL where the Discount library may be found.

mkd_doc_comment returns a string with a brief description of the parsing of HTML comments.

mkd_doc_code returns a string with a brief description of the parsing of HTML code blocks.

mkd_doc_list returns a string with a brief description of the parsing of HTML lists.

mkd_doc_block returns a string with a brief description of the parsing of HTML blockquotes.

mkd_doc_line returns a string with a brief description of the parsing of HTML line breaks.

mkd_doc_toc returns a string with a brief description of the parsing of Table of Contents entries.

mkd_doc_date_fmt returns a string with the date of the last modification of the source code, formatted according to fmt. fmt follows the format conventions of strftime(3). If t is not NULL, the time value is also stored in *t.

RETURN VALUES

All functions return a pointer to a static string. The caller must not modify the string.
