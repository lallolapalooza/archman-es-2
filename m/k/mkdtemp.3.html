mkdtemp(3) Manual de funciones de biblioteca mkdtemp(3)

NOMBRE

mkdtemp - crear un directorio temporal único

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
char *mkdtemp(char *plantilla);
Requisitos de macro de prueba de características para glibc (véase feature_test_macros(7)):

mkdtemp():

    /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc 2.19 y anteriores: */ _BSD_SOURCE
        || /* Desde glibc 2.10: */ _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

La función mkdtemp() genera un nombre de directorio temporal único a partir de plantilla. Los últimos seis caracteres de plantilla deben ser XXXXXX y se reemplazan con una cadena que hace que el nombre del directorio sea único. Luego, el directorio se crea con permisos 0700. Dado que se modificará, plantilla no debe ser una cadena constante, sino que debe declararse como un array de caracteres.

VALOR DE RETORNO

La función mkdtemp() devuelve un puntero a la cadena de plantilla modificada en caso de éxito, y NULL en caso de error, en cuyo caso errno se establece para indicar el error.

ERRORES

EINVAL
Los últimos seis caracteres de plantilla no eran XXXXXX. Ahora plantilla no se ha modificado.

También véase mkdir(2) para otros valores posibles de errno.
