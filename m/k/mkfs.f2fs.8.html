NOMBRE

mkfs.f2fs - crear un sistema de archivos F2FS

SINOPSIS

mkfs.f2fs [ -a asignación-basada-en-montículo ] [ -c lista-de-dispositivos ] [ -d nivel-de-depuración ] [ -e lista-de-extensiones ] [ -E lista-de-extensiones ] [ -f ] [ -g opciones-predeterminadas ] [ -i ] [ -l etiqueta-del-volumen ] [ -m ] [ -o porcentaje-de-ratio-de-sobreaprovisionamiento ] [ -O lista-de-características ] [ -C codificación:indicadores ] [ -q ] [ -r ] [ -R propietario-root ] [ -s #-de-segmentos-por-sección ] [ -S ] [ -t nodiscard/discard ] [ -T marca-de-tiempo ] [ -w tamaño-de-sector-deseado ] [ -z #-de-secciones-por-zona ] [ -V ] dispositivo [sectores]

DESCRIPCIÓN

mkfs.f2fs se utiliza para crear un sistema de archivos f2fs (normalmente en una partición de disco). dispositivo es el archivo especial correspondiente al dispositivo (por ejemplo, /dev/sdXX). sectores se proporciona opcionalmente para especificar el tamaño del sistema de archivos.

El código de salida devuelto por mkfs.f2fs es 0 en caso de éxito y 1 en caso de error.

OPCIONES

-a asignación-basada-en-montículo
Especificar 1 o 0 para habilitar/deshabilitar la política de asignación de bloques basada en montículo. Si el valor es igual a 1, cada una de las áreas de registro activas se asigna inicialmente por separado según el tamaño total del volumen. El valor predeterminado es 1.
-c lista-de-dispositivos
Construir f2fs con estos dispositivos adicionales separados por comas, para que el usuario pueda ver todos los dispositivos como un gran volumen. Admite hasta 7 dispositivos excepto el dispositivo meta.
-d nivel-de-depuración
Especificar el nivel de las opciones de depuración. El número predeterminado es 0, que muestra mensajes básicos de depuración.
-e lista-de-extensiones
Especificar una lista de extensiones de archivos que f2fs tratará como archivos fríos. Los datos de los archivos con estas extensiones se almacenarán en el registro frío. La lista predeterminada incluye la mayoría de las extensiones de archivos multimedia, como jpg, gif, mpeg, mkv, etc.
-E lista-de-extensiones
Especificar una lista de extensiones de archivos que f2fs tratará como archivos calientes. Los datos de los archivos con estas extensiones se almacenarán en el registro caliente. La lista predeterminada incluye extensiones de archivos de bases de datos, como db.
-f
Forzar sobrescritura cuando se detecta un sistema de archivos existente en el dispositivo. Por predeterminado, mkfs.f2fs no escribirá en el dispositivo si sospecha que ya hay un sistema de archivos o tabla de particiones en el dispositivo.
-g opciones-predeterminadas
Usar un conjunto predeterminado de opciones. Se admiten los siguientes valores:
android
Usar opciones predeterminadas para Android con las opciones "-d1 -f -w 4096 -R 0:0 -O encrypt -O project_quota,extra_attr,{quota} -O verity".
-i
Habilitar el mapa de bits de nodos extendidos.
-l etiqueta-del-volumen
Especificar la etiqueta del volumen para la partición montada como F2FS.
-m
Especificar que el sistema de archivos f2fs admita la característica de zonas de bloques. Sin ella, el sistema de archivos no admite la característica.
-o porcentaje-de-ratio-de-sobreaprovisionamiento
Especificar el porcentaje del volumen que se utilizará como área de sobreaprovisionamiento. Esta área está oculta a los usuarios y es utilizada por el limpiador de F2FS. Si no se especifica, se asignará automáticamente el mejor número según el tamaño de la partición.
-O lista-de-características
Establecer características adicionales para el sistema de archivos. Las características se separan por comas y el indicador puede repetirse. Se admiten las siguientes características:
encrypt
Habilitar soporte para cifrado a nivel de sistema de archivos.
extra_attr
Habilitar la característica de atributos extra, necesaria para algunas de las otras características.
project_quota
Habilitar el seguimiento de ID de proyecto. Esto se utiliza para la contabilidad de cuotas de proyecto. Requiere atributos extra.
inode_checksum
Habilitar la suma de verificación de inodos. Requiere atributos extra.
flexible_inline_xattr
Habilitar xattr en línea flexible. Requiere atributos extra.
quota
Habilitar cuotas.
inode_crtime
Habilitar la característica de tiempo de creación de inodos. Requiere atributos extra.
lost_found
Habilitar la característica lost+found.
verity
Habilitar soporte para archivos protegidos por verity (también conocido como fs-verity).
sb_checksum
Habilitar la suma de verificación de superbloques.
casefold
Habilitar el soporte de distinción entre mayúsculas y minúsculas en el sistema de archivos. Se pueden pasar indicadores opcionales con -C
compression
Habilitar soporte para compresión a nivel de sistema de archivos. Requiere atributos extra.
-C codificación:indicadores
Admitir distinción entre mayúsculas y minúsculas con una codificación específica, con indicadores opcionales separados por comas.
codificación:
utf8
Usar UTF-8 para la distinción entre mayúsculas y minúsculas.
indicadores:
strict
Este indicador especifica que el sistema de archivos rechazará las cadenas no válidas. Por defecto está deshabilitado.
-q
Modo silencioso. Con él, mkfs.f2fs no muestra ningún mensaje, incluidos los mensajes básicos.
-r
Establece la semilla aleatoria de punto de control en 0.
-R
Proporciona la opción owner-root para la asignación inicial de uid/gid. El valor predeterminado se establece mediante getuid()/getgid() y se asigna mediante "-R $uid:$gid".
-s #-de-segmentos-por-sección
Especificar el número de segmentos por sección. Una sección consta de varios segmentos consecutivos y es la unidad de recolección de basura. El número predeterminado es 1, lo que significa que se asigna un segmento a una sección.
-S
Habilitar modo disperso.
-t 1/0
Especificar 1 o 0 para habilitar o deshabilitar la política de descarte, respectivamente. El valor predeterminado es 1.
-T marca-de-tiempo
Establecer los tiempos de los inodos a una marca de tiempo dada. Por defecto, se utilizará la hora actual. Este comportamiento corresponde al valor -1.
-w tamaño-de-sector-deseado
Especificar el tamaño del sector en bytes. Sin él, los sectores se calcularán según el tamaño del sector del dispositivo.
-z #-de-secciones-por-zona
Especificar el número de secciones por zona. Una zona consta de varias secciones. F2FS asigna segmentos para registros activos con zonas separadas tanto como sea posible. El número predeterminado es 1, lo que significa que una zona consta de una sección.
sectores
Número de sectores. El valor predeterminado lo determina el tamaño del dispositivo.

OPTIONS

-V
Imprime el número de versión y sale.
-h, --help
Imprime el uso y sale.
