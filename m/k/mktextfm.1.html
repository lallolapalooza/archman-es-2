MKTEXTFM(1) Comandos de usuario MKTEXTFM(1)

NOMBRE

mktextfm - crear un archivo TFM para una fuente

SINOPSIS

mktextfm [opciones] fuente

DESCRIPCIÓN

mktextfm se utiliza para generar un archivo tfm a partir de los archivos fuente de Metafont para fuente, o de hbf2gf(1), si es posible. Si se proporciona destdir, el archivo generado se instalará allí, de lo contrario se utiliza una heurística (bastante complicada). Si el archivo tfm ya existe en la ubicación de destino, se informa y no se hace nada.

Si también se genera un archivo de mapa de bits GF (Generic Font), como es típico con ΜF, se convierte a PK (Packed Font) y se instala de manera similar.

La ruta completa del archivo generado se imprime en la salida estándar.

Si está disponible, se utiliza la variante mf-nowin(1) de Metafont para generar fuentes y evitar la posibilidad de visualización en línea.

mktextfm suele ser llamado por otros programas, a través de Kpathsea, en lugar de desde la línea de comandos.

OPCIONES

mktextfm acepta las siguientes opciones:

--destdir dir
Un nombre de directorio. Si el directorio es absoluto, se usa tal cual. De lo contrario, se añade al directorio raíz de destino establecido en el script.
--help
Imprime el mensaje de ayuda y sale con éxito.
--version
Imprime la información de la versión y sale con éxito.

ENTORNO

Una variable de entorno es específica de mktextfm: MF_MODE_EXTRA_INFO. Si se establece en un valor no vacío, se invocará una macro de Metafont mode_include_extra_info cuando se cree la fuente. El archivo estándar modes.mf la define, a partir de la versión 4.0 de modes.mf, lanzada en 2020. Esto provoca que la llamada información del mundo Xerox, incluyendo notablemente el CODINGSCHEME para la fuente, se incluya en el archivo tfm. (Esto no se hace por defecto ya que es demasiado intrusivo redefinir los primitivos necesarios, según Don Knuth.) El programa mftrace(1), por ejemplo, puede usar esto para obtener una pista sobre la codificación de la fuente, aunque la información no siempre es perfectamente definitiva o inequívoca.

Para más información sobre las codificaciones de las fuentes de Metafont, consulte la sección ``Bitmap font encodings'' en el manual de Dvips (por ejemplo, https://tug.org/texlive/).

Las muchas otras variables de entorno y varios archivos de configuración que controlan un sistema TeX también afectan el comportamiento de mktextfm, como es habitual.
