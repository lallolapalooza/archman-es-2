mkmanifest(1) Manual de Comandos Generales mkmanifest(1)

Nombre

mkmanifest - crea una lista de nombres de archivo y su equivalente DOS 8+3

Nota de advertencia

Esta página del manual ha sido generada automáticamente a partir de la documentación texinfo de mtools y puede que no sea completamente precisa o completa. Consulte el final de esta página del manual para obtener más detalles.

Descripción

El comando mkmanifest se utiliza para crear un script de shell (lista de empaquetado) para restaurar nombres de archivo Unix. Su sintaxis es:

mkmanifest [ archivos ]

Mkmanifest crea un script de shell que ayuda a restaurar nombres de archivo Unix que fueron modificados por las restricciones de nombres de archivo de MS-DOS. Los nombres de archivo de MS-DOS están restringidos a 8 caracteres de nombre, 3 caracteres de extensión, solo mayúsculas, sin nombres de dispositivo y sin caracteres ilegales.

El programa mkmanifest es compatible con los métodos utilizados en pcomm, arc, y mtools para cambiar nombres de archivo Unix perfectamente válidos para adaptarlos a las restricciones de MS-DOS. Este comando solo es útil si el sistema de destino que leerá el disquete no puede manejar nombres largos VFAT.

Ejemplo

Quiere copiar los siguientes archivos Unix a un disquete MS-DOS (usando el comando mcopy).

  very_long_name
  2.many.dots
  illegal:
  good.c
  prn.dev
  Capital

ASCII convierte los nombres a:

  very_lon
  2xmany.dot
  illegalx
  good.c
  xprn.dev
  capital

El comando:

mkmanifest very_long_name 2.many.dots illegal: good.c prn.dev Capital >manifest

produciría lo siguiente:

  mv very_lon very_long_name
  mv 2xmany.dot 2.many.dots
  mv illegalx illegal:
  mv xprn.dev prn.dev
  mv capital Capital

Observe que "good.c" no requirió ninguna conversión, por lo que no apareció en la salida.

Supongamos que he copiado estos archivos del disquete a otro sistema Unix, y ahora quiero que los archivos vuelvan a sus nombres originales. Si el archivo "manifest" (la salida capturada arriba) se envió junto con esos archivos, podría usarse para convertir los nombres de archivo.

Errores

Los nombres cortos generados por mkmanifest siguen la convención antigua (de mtools-2.0.7) y no la de Windows 95 y mtools-3.0.
