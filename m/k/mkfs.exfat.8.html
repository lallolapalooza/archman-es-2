mkfs.exfat(8) Manual del Administrador del Sistema mkfs.exfat(8)

NOMBRE

mkfs.exfat - crear un sistema de archivos exFAT

SINOPSIS

mkfs.exfat [ -b alineacion_limite ] [ -s tamano_sector ] [ -c tamano_cluster ] [ -f ] [ -h ] [ -L etiqueta_volumen ] [ -U guid_volumen ] [ --pack-bitmap ] [ -v ] dispositivo
mkfs.exfat -V

DESCRIPCIÓN

mkfs.exfat crea un sistema de archivos exFAT escribiendo en un archivo especial utilizando los valores encontrados en los argumentos de la línea de comandos. Se invoca automáticamente por mkfs(8) cuando se le da la opción -t exfat.

Como ejemplo, para crear un sistema de archivos en la primera partición del primer disco SCSI, usa:

mkfs.exfat /dev/sda1

OPCIONES

-b, --boundary-align=alineacion
Especifica la alineación para la FAT y el inicio del heap de clústeres. El argumento alineacion se especifica en bytes o puede especificarse con el sufijo m/M para mebibytes o k/K para kibibytes y debe ser una potencia de dos. Algunos medios como las tarjetas SD necesitan esto para un rendimiento y resistencia óptimos, en cuyo caso alineacion debe establecerse en la mitad del tamaño de la unidad de límite nativa de la tarjeta. Si el tamaño de la unidad de límite nativa de la tarjeta no se conoce, consulte la siguiente tabla de tamaños de unidades de límite recomendados por la SD Card Association.
Rango de Capacidad de la Tarjeta Tamaño de Clúster Unidad de Límite

>8 MiB     ≤64 MiB     16 KiB   16 KiB 
>64 MiB     ≤256 MiB     16 KiB   32 KiB 
>256 MiB     ≤1 GiB     16 KiB   64 KiB 
>1 GiB     ≤2 GiB     32 KiB   64 KiB 
>2 GiB     ≤32 GiB     32 KiB   4 MiB 
>32 GiB     ≤128 GiB     128 KiB   16 MiB

El valor predeterminado es siempre 1 MiB.
-s, --sector-size=tamano
Especifica el tamaño del sector del sistema de archivos exFAT. El argumento tamano se especifica en bytes o puede especificarse con el sufijo k/K para kibibytes y debe ser 512, 1024, 2048 o 4096 bytes. El valor predeterminado es el tamaño del sector informado por el dispositivo, o 512 bytes si el tamaño del sector del dispositivo no se puede determinar.
-c, --cluster-size=tamano
Especifica el tamaño del clúster del sistema de archivos exFAT. El argumento tamano se especifica en bytes o puede especificarse con el sufijo m/M para mebibytes o k/K para kibibytes y debe ser una potencia de dos. El valor predeterminado se describe en la siguiente tabla:
Rango de Capacidad de la Tarjeta Tamaño de Clúster
     ≤256 MiB     4 KiB  
>256 MiB     ≤32 GiB     32 KiB  
>32 GiB          128 KiB  
-f, --full-format
Realiza un formateo completo. Esto pone a cero todo el dispositivo de disco al crear el sistema de archivos exFAT.
-h, --help
Imprime la ayuda y sale.
-L, --volume-label=etiqueta
Especifica la etiqueta del volumen que se asociará con el sistema de archivos exFAT.
-U, --volume-guid=guid
Especifica el GUID del volumen que se asociará con el sistema de archivos exFAT. Se puede proporcionar en el formato estándar de UUID con guiones como aaaabbbb-cccc-dddd-eeee-ffff00001111. Nota: El GUID del volumen no se puede utilizar para establecer el ID de 8 letras informado por blkid ni para usar como UUID del sistema de archivos en /etc/fstab.
--pack-bitmap
Intenta reubicar el mapa de bits de asignación de exFAT para que termine en el límite de alineación que sigue a la FAT, en lugar de comenzar en dicho límite. Esto viola estrictamente la especificación de la tarjeta SD pero puede mejorar el rendimiento y la resistencia en tarjetas SD y otros medios flash no diseñados para su uso con exFAT, al permitir que las actualizaciones de metadatos del sistema de archivos toquen menos unidades de asignación flash. Además, muchas tarjetas SD y otros dispositivos flash optimizan especialmente la unidad de asignación donde reside la FAT para admitir escrituras pequeñas con amplificación de escritura reducida, pero esperan solo escrituras más grandes en unidades de asignación subsiguientes – donde se colocaría el mapa de bits exFAT por defecto. Especificar --pack-bitmap intenta evitar los posibles problemas asociados con la emisión de muchas escrituras pequeñas al mapa de bits, haciendo que comparta una unidad de asignación con la FAT. Si no hay espacio suficiente para el mapa de bits allí, entonces esta opción no tendrá ningún efecto, y el mapa de bits se alineará en el límite como por defecto.
-q, --quiet
Imprime solo mensajes de error al crear el sistema de archivos exFAT.
-v, --verb

mkfs.exfat.8.en — exfatprogs

NAME

mkfs.exfat, mkfs.exfat.sh - create an exFAT filesystem

SYNOPSIS

mkfs.exfat [-h] [-V] [-v] [-L LABEL] [-n NAME] [-c] [-C CLUSTERSIZE] [-p PARTITION_TYPE] [-s SECTORS_PER_CLUSTER] [-N NUMBER_OF_CLUSTERS] [-r ROOT_DIR_CLUSTERS] [-f] [-O OPTION,...] [-U UUID] DEVICE [ SIZE ]

DESCRIPTION

The mkfs.exfat command creates an exFAT filesystem on the specified DEVICE. The optional SIZE argument specifies the size of the filesystem in 512-byte sectors. If omitted, it uses the entire device.

mkfs.exfat.sh is a shell wrapper script which calls mkfs.exfat with appropriate arguments for creating a filesystem on a partition.

OPTIONS

-h, --help
Print a usage message and exit.
-L, --label LABEL
Sets the volume label.
-n, --name NAME
Sets the volume name. This option is deprecated. Use -L instead.
-c
Check the device for bad blocks before creating the filesystem.
-C, --cluster-size CLUSTERSIZE
Sets the cluster size in bytes. The size must be a power of 2. If 0, a default size is chosen based on the filesystem size.
-p, --partition-type PARTITION_TYPE
Sets the partition type. Valid values are 0x07 (Microsoft basic data) and 0x0b (Microsoft large partition). The default is 0x07.
-s, --sectors-per-cluster SECTORS_PER_CLUSTER
Sets the number of sectors per cluster. This option overrides -C.
-N, --number-of-clusters NUMBER_OF_CLUSTERS
Sets the number of clusters in the filesystem. This option overrides -C and -s.
-r, --root-dir-clusters ROOT_DIR_CLUSTERS
Sets the number of clusters for the root directory. The default is 32.
-f, --force
Forces the creation of the filesystem, even if the device appears to contain a filesystem already.
-O, --options OPTION,...
A comma-separated list of options. Supported options are:
allocation bitmap Allocate blocks using the allocation bitmap.
large unit allocation Use large unit allocation.
volume label Enable volume label.
volume id Enable volume ID.
bitmap
Prints verbose debugging information while creating the exFAT filesystem.
-V, --version
Prints the version number and exits.
