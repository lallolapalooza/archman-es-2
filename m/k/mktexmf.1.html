NOMBRE

mktexmf - crea un archivo fuente de Metafont

SINOPSIS

mktexmf fuente

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Kpathsea: A library for path searching.

mktexmf se utiliza para generar el archivo fuente de Metafont para fuente, si es posible. Por ejemplo, ecrm1200 o cmr11.

El nombre del archivo generado se imprime en la salida estándar.

mktexmf suele ser llamado por otros programas, en lugar de desde la línea de comandos.

OPCIONES

mktexmf acepta las siguientes opciones:

--help
Imprime el mensaje de ayuda y sale.
--version
Imprime la información de la versión y sale.

VER TAMBIÉN

mktexpk(1), mktextfm(1).
