NOMBRE

mkfs.nilfs2 - crear un sistema de archivos NILFS2

SINOPSIS

mkfs -t nilfs2 [ -b tamaño-bloque ] [ -B bloques-por-segmento ] [ -c ] [ -f ] [ -K ] [ -L etiqueta-volumen ] [ -m porcentaje-segmentos-reservados ] [ -n ] [ -O característica[,...] ] [ -h ] [ -q ] [ -v ] [ -V ] dispositivo

mkfs.nilfs2 [ -b tamaño-bloque ] [ -B bloques-por-segmento ] [ -c ] [ -f ] [ -K ] [ -L etiqueta-volumen ] [ -m porcentaje-segmentos-reservados ] [ -n ] [ -O característica[,...] ] [ -h ] [ -q ] [ -v ] [ -V ] dispositivo

DESCRIPCIÓN

mkfs.nilfs2 se utiliza para crear un sistema de archivos nilfs2 (normalmente en una partición de disco). dispositivo es el archivo especial correspondiente al dispositivo (por ejemplo, /dev/sdXX). Normalmente mkfs.nilfs2 se invoca desde el programa frontal mkfs(8).

El código de salida devuelto por mkfs.nilfs2 es 0 en caso de éxito y 1 en caso de fallo.

OPCIONES

-b tamaño-bloque
Especificar el tamaño de los bloques en bytes. El tamaño de bloque válido es 1024, 2048, 4096, 8192 bytes, ..., y el tamaño máximo de bloque está restringido al tamaño de página del sistema. Para la mayoría de las máquinas, es de 4096 bytes. El tamaño de bloque predeterminado es de 4096 bytes.
-B bloques-por-segmento
Especificar el número de bloques en un segmento, donde el segmento (también llamado segmento completo) es una unidad de asignación de espacio en disco de NILFS. Este parámetro determina el tamaño del segmento y, en consecuencia, cuántos segmentos se alinean en el dispositivo especificado. El número predeterminado de bloques por segmento es 2048 (= 8MB con bloques de 4KB).
-c
Comprobar el dispositivo en busca de bloques defectuosos antes de crear el sistema de archivos.
-f
Forzar la sobrescritura cuando se detecta un sistema de archivos existente en el dispositivo. De forma predeterminada, mkfs.nilfs2 no escribirá en el dispositivo si sospecha que ya hay un sistema de archivos en él.
-h
Mostrar mensaje de ayuda y salir.
-K
Mantener, no intentar descartar bloques durante la creación del sistema de archivos (descartar bloques inicialmente es útil en unidades de estado sólido y almacenamiento escaso / aprovisionado de forma delgada).
-L nueva-etiqueta-volumen
Establecer la etiqueta del volumen para el sistema de archivos a nueva-etiqueta-volumen. La longitud máxima de la etiqueta del volumen es de 80 bytes.
-m porcentaje-segmentos-reservados
Especificar el porcentaje de segmentos reservados para la recolección de basura. El porcentaje predeterminado es del 5%.
-n
Hacer que mkfs.nilfs2 no cree realmente un sistema de archivos, sino que muestre lo que haría si creara un sistema de archivos.
-O característica[,...]
Crear un sistema de archivos con las características (opciones del sistema de archivos) dadas, anulando las opciones predeterminadas del sistema de archivos.

El conjunto de características del sistema de archivos consta de una lista de características, separadas por comas, que se habilitarán. Para deshabilitar una característica, simplemente prefije el nombre de la característica con un carácter de circunflejo ('^'). La característica pseudo-sistema de archivos "none" borrará todas las características del sistema de archivos.

contador_bloques
Habilitar contador de bloques por punto de control.
-q
Ejecución silenciosa. Útil si mkfs.nilfs2 se ejecuta en un script.
-v
Ejecución detallada.
-V
Imprimir el número de versión de mkfs.nilfs2 y salir.
