MKNOD(1) Comandos de Usuario MKNOD(1)

NOMBRE

mknod - crear archivos especiales de bloque o carácter

SINOPSIS

mknod [OPCIÓN]... NOMBRE TIPO [MAYOR MENOR]

DESCRIPCIÓN

Crea el archivo especial NOMBRE del TIPO dado.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-m, --mode=MODO
establecer los bits de permisos del archivo a MODO, no a=rw - umask
-Z
establecer el contexto de seguridad SELinux al tipo predeterminado
--contexto[=CTX]
igual que -Z, o si CTX está especificado entonces establece el contexto de seguridad SELinux o SMACK a CTX
--help
mostrar esta ayuda y salir
--version
mostrar información de versión y salir

Se deben especificar tanto MAYOR como MENOR cuando TIPO sea b, c, o u, y deben omitirse cuando TIPO sea p. Si MAYOR o MENOR comienzan con 0x o 0X, se interpretan como hexadecimal; de lo contrario, si comienzan con 0, como octal; de lo contrario, como decimal. TIPO puede ser:

b
crear un archivo especial de bloque (con búfer)
c, u
crear un archivo especial de carácter (sin búfer)
p
crear una FIFO

Tu shell puede tener su propia versión de mknod, que generalmente reemplaza a la versión descrita aquí. Por favor, consulta la documentación de tu shell para obtener detalles sobre las opciones que soporta.
