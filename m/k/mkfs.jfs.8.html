jfs_mkfs(8) Creación de sistema de archivos JFS jfs_mkfs(8)

NOMBRE

jfs_mkfs - crear una partición formateada con JFS

SINOPSIS

jfs_mkfs [opciones] dispositivo [ bloques ]

DESCRIPCIÓN

jfs_mkfs se utiliza para crear (formatear) una partición JFS. jfs_mkfs debe ejecutarse como root.

dispositivo es el nombre del archivo especial que corresponde al dispositivo real (por ejemplo, /dev/hdb1) en el que se creará un sistema de archivos JFS y/o un journal JFS. bloques es el número de bloques que se utilizarán para el sistema de archivos. Si se omite, jfs_mkfs calcula automáticamente el tamaño del sistema de archivos.

El tamaño de bloque predeterminado es 4096.

ADVERTENCIA

¡jfs_mkfs destruirá todos los datos del dispositivo especificado!

OPCIONES

-c
Comprueba el dispositivo en busca de bloques defectuosos antes de construir el sistema de archivos.
-j dispositivo_journal
Crea el journal JFS externo en dispositivo_journal, crea el sistema de archivos JFS en dispositivo y adjunta el journal externo al sistema de archivos.
-J opciones_journal
Crea el journal JFS en su propio dispositivo o adjunta un journal JFS externo al sistema de archivos JFS utilizando las opciones especificadas en la línea de comandos. Las siguientes opciones de journal son compatibles:
dispositivo_journal
Crea un journal JFS externo en el dispositivo dado.
dispositivo=journal_externo
Adjunta un journal JFS externo existente ubicado en journal_externo al sistema de archivos JFS que se creará en dispositivo. El journal externo ya debe haber sido creado usando el comando
jfs_mkfs -J dispositivo_journal journal_externo
Adjunta el journal externo al sistema de archivos que se está creando usando el comando
jfs_mkfs -J dispositivo=journal_externo dispositivo
En lugar de especificar un nombre de dispositivo directamente, journal_externo también puede especificarse como LABEL=etiqueta o UUID=UUID para localizar el journal externo por la etiqueta del volumen o el UUID almacenado en el superbloque de log externo JFS al inicio del journal. Usa jfs_tune(8) para mostrar la etiqueta del volumen y el UUID de un dispositivo de journal. (Ver las opciones -l, -L y -U de jfs_tune(8).)
Solo se puede dar una de las opciones dispositivo_journal o dispositivo= por cada ejecución de jfs_mkfs.
-L etiqueta_volumen
Establece la etiqueta del volumen para el dispositivo recién formateado.
Si se usa -L etiqueta_volumen junto con -J dispositivo_journal, la etiqueta del volumen del dispositivo de journal externo especificado se establecerá en etiqueta_volumen. De lo contrario, la etiqueta del volumen del sistema de archivos JFS se establecerá en etiqueta_volumen.
-O
Proporciona soporte insensible a mayúsculas y minúsculas para compatibilidad con OS/2.
-q
Ejecución silenciosa - no pide confirmación antes de crear el sistema de archivos.
-s tamano_log
Establece el tamaño del log (en megabytes) del log en línea. Si no se usa la opción -s, el tamaño del log predeterminado es el 0.4% del tamaño agregado.
-V
Imprime la información de la versión y sale (independientemente de cualquier otra opción elegida).

EJEMPLOS

Formatea la 3ª partición del 2º disco duro con la etiqueta de volumen "JFS_hdb3":

jfs_mkfs -L JFS_hdb3 /dev/hdb3

Formatea la 5ª partición del 1º disco duro, verificando cada bloque creado:

jfs_mkfs -c /dev/hda5

Formatea la 3ª partición del 2º disco duro como journal externo, formatea la 4ª partición del 1º disco duro como sistema de archivos JFS y adjunta el journal externo al sistema de archivos:

jfs_mkfs -j /dev/hdb3 /dev/hda4

INFORMACIÓN SOBRE ERRORES

Si encuentras un error en JFS o jfs_mkfs, por favor repórtalo a través del sistema de seguimiento de errores (sección "Report Bugs") del sitio web del proyecto JFS:

http://jfs.sourceforge.net/

Por favor, envía tanta información relevante como sea posible, incluyendo cualquier mensaje de error resultante de la ejecución de jfs_mkfs.
