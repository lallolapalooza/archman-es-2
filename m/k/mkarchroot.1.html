NOMBRE

mkarchroot - Crea un chroot de Arch en una ubicación especificada con un conjunto especificado de paquetes

SINOPSIS

mkarchroot [opciones] [ubicación] [paquetes]

DESCRIPCIÓN

mkarchroot es un script para crear un chroot de Arch Linux en una ubicación especificada con los paquetes especificados. Típicamente utilizado por makechrootpkg para crear chroots de compilación. Además de instalar los paquetes especificados, el chroot se crea con una localización en_US.UTF-8 y de_DE.UTF-8 y un ID de máquina generado.

OPCIONES

-U

Utiliza pacman -U para instalar paquetes.

-C <archivo>

Ubicación de un archivo de configuración de pacman.

-M <archivo>

Ubicación de un archivo de configuración de makepkg.

-c <dir>

Establece la caché de pacman.

-f <origen>[:<destino>]

Copia un archivo desde el host al chroot. Si no se proporciona destino, por defecto será origen dentro del chroot.

-s

No ejecutar setarch.

-h

Muestra las opciones de la línea de comandos.

VER TAMBIÉN
