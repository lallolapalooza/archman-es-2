MKWINPEIMG(1) Comandos de usuario MKWINPEIMG(1)

NOMBRE

mkwinpeimg - Crea una imagen de arranque personalizada de Windows PE

SINOPSIS

mkwinpeimg [OPCIONES] IMAGEN

DESCRIPCIÓN

mkwinpeimg es capaz de crear una imagen de arranque de Windows PE tomando archivos de una imagen ISO de instalación de Windows montada (Vista o posterior) o de la imagen ISO montada para el Kit de Instalación Automatizada de Windows (WAIK) o el suplemento del WAIK. Las opciones --windows-dir y --waik-dir se utilizan para especificar las ubicaciones de estas ISOs montadas. Solo necesita una u otra. Los archivos que mkwinpeimg recuperará son boot.wim, bootmgr, boot.sdi y bcd. Si se crea una imagen ISO, también se recupera el archivo etfsboot.com. Microsoft posee los derechos de estos archivos y no se distribuyen con wimlib.

mkwinpeimg puede crear dos tipos de imágenes de arranque. El valor predeterminado es crear una imagen de disco de arranque. La imagen no está particionada y se formatea en un sistema de archivos FAT. Se requiere syslinux(1) para crear este tipo de imagen, ya que se utiliza para cargar en cadena bootmgr. Además, se requiere mtools(1) para que el sistema de archivos FAT se pueda crear sin privilegios de root.

El otro tipo de imagen de arranque que mkwinpeimg puede crear es una imagen ISO de arranque. Para crear este tipo de imagen, proporcione la opción --iso. Se requiere mkisofs(1) para crear este tipo de imagen. En el modo --iso, puede especificar IMAGEN como "-" para escribir la imagen ISO en la salida estándar.

Si crea una imagen de disco, podría ponerla en una unidad USB, y si crea una imagen ISO, podría ponerla en un CD. Además, ambos tipos de imágenes pueden ser cargadas por los cargadores de arranque SYSLINUX o PXELINUX usando el módulo MEMDISK.

Windows PE en sí está contenido en el archivo boot.wim. mkwinpeimg puede modificar este archivo antes de incrustarlo en una imagen de arranque. La modificación más útil es especificar un ejecutable o un archivo batch para que Windows PE lo ejecute tan pronto como comience. Use la opción --start-script ARCHIVO para especificar dicho archivo. También puede agregar archivos arbitrarios a boot.wim poniéndolos en un directorio, y luego especificando la opción --overlay DIR. Sin embargo, para modificaciones más extensas, considere modificar el archivo boot.wim por separado usando wimmountrw(1) o wimupdate(1), luego proporcionándolo a mkwinpeimg usando la opción --wim.

mkwinpeimg también puede crear solo un boot.wim modificado, en lugar de una imagen de disco o ISO de arranque, si se da la opción --only-wim.

OPCIONES

-i, --iso
Crea una imagen ISO en lugar de una imagen de disco.
-o, --only-wim
No crea una imagen de disco ni una imagen ISO; en su lugar, solo crea un archivo boot.wim modificado.
-W, --windows-dir=DIR
Usa DIR como la ubicación de la imagen ISO de instalación de Windows montada. Si no se especifica ni --windows-dir ni --waik-dir, el script busca la ISO montada en las siguientes ubicaciones predeterminadas: /mnt/windows, /mnt/windows7, /mnt/windows8 y /mnt/windows10.
-A, --waik-dir=DIR
Obtiene los archivos de arranque y boot.wim de la ISO del Kit de Instalación Automatizada de Windows montada en DIR en lugar de una ISO de instalación de Windows. Esto también funciona si la ISO montada es para el suplemento del WAIK en lugar del WAIK mismo.
-s, --start-script=ARCHIVO
Agrega ARCHIVO al directorio raíz de la imagen de Windows PE y ajusta \Windows\System32\winpeshl.ini para ejecutar ARCHIVO cuando Windows PE se inicie.
-w, --wim=WIM
Usa WIM como el archivo "boot.wim". Por defecto, utiliza el archivo WIM apropiado de la ISO de Windows, WAIK o suplemento del WAIK.
-O, --overlay=DIR
Agrega todos los archivos en DIR a la imagen de Windows PE.
-t, --tmp-dir=DIR
Usa DIR para archivos temporales. Por defecto, usa un directorio creado con "mktemp -d".
-a, --arch=ARQUITECTURA
Usa la versión de Windows PE del Kit de Instalación Automatizada de Windows (o el suplemento del WAIK) que tiene la arquitectura de CPU ARQUITECTURA. Solo válido con --waik-dir. Valores posibles: "x86" o "amd64". Por defecto es "x86". Nota: el WAIK también contiene una imagen de Windows PE para la arquitectura ia64 (Itanium); sin embargo, este script no la soporta.
-h, --help
Muestra la ayuda.
-v, --version
Muestra información de la versión.

EJEMPLOS

Crea una imagen de disco de arranque de Windows PE desde los medios de instalación de Windows (Vista o posterior) montados en /media/windows:

mkwinpeimg --windows-dir=/media/windows winpe.img

Crea una ISO de arranque de Windows PE desde el WAIK (o suplemento del WAIK) montado en /media/waik, y agrega todos los archivos de "winpe_overlay" al sistema de archivos de Windows PE:

mkwinpeimg --iso --waik-dir=/media/waik --overlay=winpe_overlay winpe.iso

Crea una imagen de arranque de Windows PE desde los medios de instalación de Windows montados en /media/windows, agrega y hace que ejecute "install.cmd" cuando se inicie. En este ejemplo, la imagen se crea en el directorio raíz del servidor TFTP para el arranque por red.

mkwinpeimg --start-script=install.cmd --windows-dir=/media/windows /var/tftpboot/winpe.img

NOTAS

Las licencias de Microsoft pueden limitar las cosas para las que se puede usar Windows PE, y pueden limitar sus derechos para redistribuir versiones personalizadas de Windows PE.
