MKLOST+FOUND(8) Manual del Administrador del Sistema MKLOST+FOUND(8)

NOMBRE

mklost+found - crear un directorio lost+found en un sistema de archivos ext2/ext3/ext4 montado

SINOPSIS

mklost+found

DESCRIPCIÓN

mklost+found se utiliza para crear un directorio lost+found en el directorio de trabajo actual en un sistema de archivos ext2/ext3/ext4. Normalmente hay un directorio lost+found en el directorio raíz de cada sistema de archivos.

mklost+found preasigna bloques de disco al directorio lost+found para que, cuando se ejecute e2fsck(8) para recuperar un sistema de archivos, no necesite asignar bloques en el sistema de archivos para almacenar un gran número de archivos desenlazados. Esto asegura que e2fsck no tendrá que asignar bloques de datos en el sistema de archivos durante la recuperación.
