NOMBRE

mkd_callbacks — funciones que modifican objetivos de enlaces

BIBLIOTECA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

char*
(*mkd_callback_t)(const char*, const int, void*);

void
(*mkd_free_t)(char *, void*);

void
mkd_e_url(MMIOT *document, mkd_callback_t edit);

void
mkd_e_flags(MMIOT *document, mkd_callback_t edit);

void
mkd_e_free(MMIOT *document, mkd_free_t dealloc);

void
mkd_e_code(MMIOT *document, mkd_callback_t edit);

void
mkd_e_data(MMIOT *document, void *data);

DESCRIPCIÓN

Discount proporciona un pequeño conjunto de funciones de acceso a datos para permitir a un usuario de la biblioteca modificar el html generado.

mkd_e_url()

modifica el objetivo dado en un enlace `[]`;
mkd_e_flags()

añade indicadores adicionales a un enlace `[]`;
mkd_e_code()
te permite manipular el contenido de un bloque de código.

Las funciones de acceso a datos reciben un puntero de carácter a la URL que se está generando, el tamaño de la URL y un puntero de datos que apunta a un área de datos de usuario (establecida por la función mkd_e_data()). Después de que se llama a la función de devolución de llamada, se llama a la función de liberación de datos (si se proporciona) y se le pasa el puntero de carácter y el puntero de datos de usuario.

EJEMPLO

La función mkd_basename() (en el módulo basename.c) se implementa mediante devoluciones de llamada mkd; modifica URLs que comienzan con `/` para que comiencen con una URL base proporcionada por el usuario, asignando una nueva cadena y llenándola con la base + la URL. Discount inserta esa URL en lugar de la original, luego llama a la función de liberación de nombre base (solo lo hace cuando mkd_e_url() o mkd_e_flags() devuelve un valor distinto de cero) para liberar esta memoria.

Tenga en cuenta que solo se admite un nivel de devoluciones de llamada; si desea realizar múltiples devoluciones de llamada, debe escribir su propio código para manejarlas todas.
