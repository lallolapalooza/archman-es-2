Paquete: mk-configure

MKC_CHECK_CUSTOM(1) MKC_CHECK_CUSTOM(1)

NOMBRE

mkc_check_custom - ejecuta las comprobaciones personalizadas del usuario.

SINOPSIS

mkc_check_custom [-r] archivo_fuente
mkc_check_custom comando [argumentos...]
mkc_check_custom -h

DESCRIPCIÓN

Si comando es ejecutable, mkc_check_custom ejecuta comando argumentos. De lo contrario, intenta compilar archivo_fuente y devuelve 1 si la compilación tuvo éxito y 0 en caso contrario. Si se aplicó la opción -r, ejecuta un programa compilado. El tipo de compilador a utilizar depende de la extensión de archivo_fuente. '.c' corresponde a ${CC} (lenguaje C), '.cc', '.cxx', '.C' y '.cpp' corresponden a ${CXX} (lenguaje C++).

OPCIONES

-h
Muestra el mensaje de ayuda.
-r
Ejecuta el ejecutable compilado desde archivo_fuente.
-p texto
Prefijo del archivo de caché generado. El valor predeterminado es "custom".
-n texto
Parte del nombre del archivo de caché generado.
El valor predeterminado es `basename <archivo_fuente>`.
-m texto
Mensaje que muestra mkc_check_custom.
El valor predeterminado es "custom test archivo_fuente_o_comando".
-s
mkc_check_custom muestra el estado de salida de comando argumentos.
-d
Elimina los archivos temporales y de caché.
-D
Elimina los archivos de caché.
-e
Muestra 0 si el compilador/comando imprime algo en stderr.
-b
Muestra sí/no en lugar de 1/0.

ENTORNO

CC
Compilador de C
CXX
Compilador de C++
CPPFLAGS
Banderas del preprocesador para C y C++
CFLAGS
Banderas de compilación para C
CXXFLAGS
Banderas de compilación para C++
LDFLAGS
Banderas adicionales del enlazador
LDADD
Objetos adicionales
MKC_VERBOSE
Si se establece en 1, se muestran mensajes detallados en stderr.
MKC_SHOW_CACHED
Si se establece en 1 y MKC_VERBOSE se establece en 1, los resultados cacheados se muestran en stderr.
MKC_CACHEDIR
Directorio donde se crean los archivos temporales y de caché. Si no está establecido, se crean en el directorio actual.
MKC_NOCACHE
Todos los resultados se almacenan en caché a menos que la variable MKC_NOCACHE esté establecida en 1.
MKC_DELETE_TMPFILES
Si se establece en 1, se eliminan los archivos temporales.

EJEMPLOS

   mkc_check_custom alloca_in_stdlib.c
   mkc_check_custom custom_checks/cxx_foo_test.cc
   mkc_check_custom /full/path/to/yacc_need_liby
