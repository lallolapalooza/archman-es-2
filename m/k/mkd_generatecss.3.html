MKD_FUNCTIONS(3) Manual de funciones de la biblioteca MKD_FUNCTIONS(3)

NOMBRE

mkd_functions — accede y procesa documentos Markdown.

BIBLIOTECA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

int
mkd_compile(MMIOT *document, int flags);

int
mkd_css(MMIOT *document, char **doc);

int
mkd_generatecss(MMIOT *document, FILE *output);

int
mkd_document(MMIOT *document, char **doc);

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

DESCRIPCIÓN

El formato markdown soportado en esta implementación incluye bloques de cabecera al estilo Pandoc y bloques en línea de <style>, y las funciones estándar de markdown(3) no proporcionan acceso a los datos proporcionados por ninguna de esas extensiones. Estas funciones te dan acceso a esos datos, además de proporcionar una forma más granular de convertir documentos Markdown en HTML.

Dado un MMIOT* generado por mkd_in() o mkd_string(), mkd_compile() compila el documento en secciones <style>, Pandoc y html.

Una vez compilado, el documento puede ser examinado y escrito por las funciones mkd_css(), mkd_document(), mkd_generatecss(), mkd_generatehtml(), mkd_generatetoc(), mkd_toc(), mkd_xhtmlpage(), mkd_doc_title(), mkd_doc_author(), y mkd_doc_date().

mkd_css() asigna una cadena y la rellena con cualquier sección <style> proporcionada en el documento, mkd_generatecss() escribe cualquier sección <style> en la salida, mkd_document() apunta text al texto del documento y devuelve el tamaño del documento, mkd_generatehtml() escribe el resto del documento en la salida, y mkd_doc_title(), mkd_doc_author(), mkd_doc_date() se utilizan para leer el contenido de una cabecera Pandoc, si la hay.

mkd_xhtmlpage() escribe una página xhtml que contiene el documento. Se puede pasar el conjunto regular de banderas.

mkd_toc() escribe un índice del documento, en forma de una colección de listas anidadas con enlaces a cada cabecera del documento, en una cadena asignada con malloc(), y devuelve el tamaño.

mkd_generatetoc() es como mkd_toc(), excepto que escribe el índice del documento en el argumento FILE* dado.

mkd_cleanup() elimina un MMIOT* una vez finalizado el procesamiento.

mkd_compile() acepta las mismas banderas que markdown() y mkd_string() hacen;

MKD_NOIMAGE
No procesar `![]' y eliminar las etiquetas <img> de la salida.
MKD_NOLINKS
No procesar `[]' y eliminar las etiquetas <a> de la salida.
MKD_NOPANTS
No realizar la manipulación al estilo Smartypants de comillas, guiones o elipses.
MKD_TAGTEXT
Procesar la entrada como si estuvieras dentro de una etiqueta html. Esto significa que no se generarán etiquetas html, y mkd_compile() intentará escapar cualquier cosa que pueda confundir terriblemente a un navegador web.
MKD_NO_EXT
No procesar ningún pseudo-protocolo markdown al manejar enlaces [][].
MKD_NOHEADER
No intentar analizar ninguna cabecera al estilo Pandoc.
MKD_TOC
Etiquetar todas las cabeceras para su uso con la función mkd_generatetoc().
MKD_1_COMPAT
Bandera de compatibilidad MarkdownTest_1.0; recortar espacios finales de la primera línea de los bloques de código y deshabilitar los enlaces de referencia implícitos.
MKD_NOSTRIKETHROUGH
Deshabilitar el soporte para tachado.

VALORES DE RETORNO

La función mkd_compile() devuelve 1 en caso de éxito, o 0 si el documento ya está compilado. La función mkd_generatecss() devuelve el número de bytes escritos en caso de éxito, o EOF si ocurrió un error. La función mkd_generatehtml() devuelve 0 en caso de éxito, -1 en caso de fallo.

mkd_generatecss(3)

NAME

mkd_generatecss - Generate CSS for Markdown

LIBRARY

Math::Markdown::Parser (libmarkdown)

SYNOPSIS

#include <markdown.h>

char *mkd_generatecss(int flags);

DESCRIPTION

The mkd_generatecss function generates a CSS stylesheet for rendering Markdown documents. The flags argument can be used to modify the output. Currently, no flags are defined.

RETURN VALUES

On success, returns a pointer to a dynamically allocated string containing the CSS stylesheet. The caller is responsible for freeing this string using free(3). On failure, returns NULL.

SEE ALSO

markdown(3), mkd-extensions(7), mmap(2).

http://daringfireball.net/projects/markdown/syntax
