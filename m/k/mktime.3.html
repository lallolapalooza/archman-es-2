ctime(3) Manual de funciones de biblioteca ctime(3)

NOMBRE

asctime, ctime, gmtime, localtime, mktime, asctime_r, ctime_r, gmtime_r, localtime_r - transformar fecha y hora a tiempo desglosado o ASCII

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <time.h>
char *asctime(const struct tm *tm);
char *asctime_r(const struct tm *restrict tm,
                    char buf[restrict 26]);
char *ctime(const time_t *timep);
char *ctime_r(const time_t *restrict timep,
                    char buf[restrict 26]);
struct tm *gmtime(const time_t *timep);
struct tm *gmtime_r(const time_t *restrict timep,
                    struct tm *restrict result);
struct tm *localtime(const time_t *timep);
struct tm *localtime_r(const time_t *restrict timep,
                    struct tm *restrict result);
time_t mktime(struct tm *tm);

DESCRIPCIÓN

Las funciones ctime(), gmtime() y localtime() toman un argumento de tipo de datos time_t, que representa el tiempo calendario. Cuando se interpreta como un valor de tiempo absoluto, representa el número de segundos transcurridos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).

Las funciones asctime() y mktime() toman un argumento que representa el tiempo desglosado, que es una representación separada en año, mes, día y así sucesivamente.

El tiempo desglosado se almacena en la estructura tm, descrita en tm(3type).

La llamada ctime(t) es equivalente a asctime(localtime(t)). Convierte el tiempo calendario t en una cadena terminada en nulo del siguiente formato:


"Wed Jun 30 21:49:08 1993\n"

Las abreviaturas de los días de la semana son "Sun", "Mon", "Tue", "Wed", "Thu", "Fri" y "Sat". Las abreviaturas de los meses son "Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov" y "Dec". El valor de retorno apunta a una cadena estáticamente asignada que podría ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). La versión reentrante ctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debería tener espacio para al menos 26 bytes. No necesita establecer tzname, timezone y daylight.

La función gmtime() convierte el tiempo calendario timep a una representación de tiempo desglosado, expresada en Tiempo Universal Coordinado (UTC). Puede devolver NULL cuando el año no cabe en un entero. El valor de retorno apunta a una estructura estáticamente asignada que podría ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función gmtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario.

La función localtime() convierte el tiempo calendario timep a una representación de tiempo desglosado, expresada en relación con la zona horaria especificada por el usuario. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3). El valor de retorno apunta a una estructura estáticamente asignada que podría ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función localtime_r() hace lo mismo, pero almacena los datos en una estructura proporcionada por el usuario. No necesita establecer tzname, timezone y daylight.

La función asctime() convierte el valor de tiempo desglosado tm en una cadena terminada en nulo con el mismo formato que ctime(). El valor de retorno apunta a una cadena estáticamente asignada que podría ser sobrescrita por llamadas posteriores a cualquiera de las funciones de fecha y hora. La función asctime_r() hace lo mismo, pero almacena la cadena en un búfer proporcionado por el usuario que debería tener espacio para al menos 26 bytes.

La función mktime() convierte una estructura de tiempo desglosado, expresada como hora local, a una representación de tiempo calendario. La función ignora los valores proporcionados por el llamador en los campos tm_wday y tm_yday. El valor especificado en el campo tm_isdst informa a mktime() si el horario de verano (DST) está activo o no para la hora proporcionada en la estructura tm: un valor positivo significa que DST está activo; cero significa que DST no está activo; y un valor negativo significa que mktime() debe (utilizar información de zona horaria y bases de datos del sistema para) intentar determinar si DST está activo en el momento especificado. Ver timegm(3) para un equivalente UTC de esta función.

La función mktime() modifica los campos de la estructura tm de la siguiente manera: tm_wday y tm_yday se establecen con valores determinados a partir del contenido de los otros campos; si los miembros de la estructura están fuera de su intervalo válido, se normalizarán (de modo que, por ejemplo, 40 de octubre se cambie a 9 de noviembre); tm_isdst se establece (independientemente de su valor inicial) en un valor positivo o en 0, respectivamente, para indicar si DST está o no activo en el momento especificado. La función también establece las variables externas tzname, timezone y daylight como si hubiera llamado a tzset(3).

Si el tiempo desglosado especificado no se puede representar como tiempo calendario (segundos desde la Época), mktime() devuelve (time_t) -1 y no altera los miembros de la estructura de tiempo desglosado.

VALOR DE RETORNO

En caso de éxito, gmtime() y localtime() devuelven un puntero a una struct tm.

En caso de éxito, gmtime_r() y localtime_r() devuelven la dirección de la estructura apuntada por result.

En caso de éxito, asctime() y ctime() devuelven un puntero a una cadena.

En caso de éxito, asctime_r() y ctime_r() devuelven un puntero a la cadena apuntada por buf.

En caso de éxito, mktime() devuelve el tiempo calendario (segundos desde la Época), expresado como un valor de tipo time_t.

En caso de error, mktime() devuelve el valor (time_t) -1 y no modifica los miembros de la estructura tm->tm_wday. Las funciones restantes devuelven NULL en caso de error. En caso de error, errno se establece para indicar el error.

ERRORES

EOVERFLOW
El resultado no se puede representar.

DESCRIPCIÓN

La función mktime() convierte la estructura tm apuntada por tp, que representa la hora local, en un valor time_t. La estructura tm se define en <time.h> y debe contener valores apropiados para los campos tm_sec, tm_min, tm_hour, tm_mday, tm_mon, tm_year y tm_isdst. Si tm_isdst es negativo, el comportamiento es indefinido.

Si el valor devuelto es válido, la estructura tm se modifica en su lugar para representar la misma hora, pero en tiempo universal coordinado (UTC), y el campo tm_isdst se establece en 1 o 0 para indicar si se está aplicando el horario de verano. Si el campo original tm_isdst no es negativo, se conserva si es posible; de lo contrario, se establece en 1 o 0 para indicar si el horario de verano está en vigor en la hora especificada.

El valor del campo tm_year es el número de años desde 1900. Por ejemplo, 2003 se representa como 103. El valor del campo tm_mon es el número de meses desde enero, y está en el rango [0, 11]. El valor del campo tm_mday es el día del mes y está en el rango [1, 31]. El valor del campo tm_hour es la hora y está en el rango [0, 23]. El valor del campo tm_min es el minuto y está en el rango [0, 59]. El valor del campo tm_sec es el segundo y está en el rango [0, 60] (para permitir segundos intercalares).

El campo tm_wday es el día de la semana, en el rango [0, 6] (domingo es 0), y el campo tm_yday es el día del año, en el rango [0, 365]. Estos campos se calculan y se establecen en los valores devueltos si el valor devuelto no es -1.

La función mktime() interpreta los valores de la estructura tm como hora local. Utiliza la variable de entorno TZ para determinar la zona horaria y si se debe aplicar el horario de verano. Si TZ no está establecida, se utiliza la hora local predeterminada del sistema.

La función timegm() es lo opuesto a gmtime(). Convierte una estructura tm que representa el tiempo universal coordinado (UTC) en un valor time_t.

La función timelocal() es lo opuesto a localtime(). Convierte una estructura tm que representa la hora local en un valor time_t. Tenga en cuenta que timelocal() no es parte de POSIX.

Según POSIX.1, se requiere que localtime() se comporte como si se hubiera llamado a tzset(3), mientras que localtime_r() no tiene este requisito. Para código portable, se debería llamar a tzset(3) antes de localtime_r().

ADVERTENCIAS

Seguridad de hilos

Las cuatro funciones asctime(), ctime(), gmtime() y localtime() devuelven un puntero a datos estáticos y, por lo tanto, no son seguras para hilos. Las versiones seguras para hilos, asctime_r(), ctime_r(), gmtime_r() y localtime_r(), están especificadas por SUSv2.

POSIX.1 dice: "Las funciones asctime(), ctime(), gmtime() y localtime() devolverán valores en uno de los dos objetos estáticos: una estructura de tiempo desglosada y un array de tipo char. La ejecución de cualquiera de las funciones que devuelven un puntero a uno de estos tipos de objeto puede sobrescribir la información en cualquier objeto del mismo tipo al que apunte el valor devuelto por cualquier llamada anterior a cualquiera de ellas." Esto puede ocurrir en la implementación de glibc.

mktime()

(time_t) -1 puede representar un tiempo válido (un segundo antes de la Época). Para determinar si mktime() falló, se debe utilizar el campo tm_wday. Consulte el programa de ejemplo en EJEMPLOS.

El manejo de un tm_isdst no negativo en mktime() está mal especificado, y pasar un valor incorrecto para la hora especificada produce resultados indefinidos. Dado que mktime() es una de las pocas funciones que sabe cuándo está en vigor el horario de verano, proporcionar un valor correcto puede ser difícil. Una solución para esto es llamar a mktime() dos veces, una con tm_isdst establecido en cero, y otra con tm_isdst establecido en un valor positivo, y descartando los resultados de la llamada que lo cambia. Si ninguna de las llamadas cambia tm_isdst, entonces la hora especificada probablemente ocurra durante un período de retroceso donde el horario de verano comienza o termina, y ambos resultados son válidos pero representan dos horas diferentes. Si ambas llamadas lo cambian, eso podría indicar una transición de avance forzado, o alguna otra razón por la cual la hora especificada no existe.

La especificación de las zonas horarias y el horario de verano depende de los gobiernos regionales, cambia con frecuencia y puede incluir discontinuidades más allá de la capacidad de mktime para documentar un resultado. Por ejemplo, un cambio en la definición de la zona horaria puede hacer que una hora de reloj se repita o se omita sin un cambio correspondiente del horario de verano.

Código fuente del programa: mktime.c

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}
