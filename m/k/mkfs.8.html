MKFS(8) Administración del Sistema MKFS(8)

NOMBRE

mkfs - crear un sistema de archivos Linux

SINOPSIS

mkfs [opciones] [-t tipo] [opciones-fs] dispositivo [tamaño]

DESCRIPCIÓN

Este front-end de mkfs está obsoleto en favor de las utilidades mkfs.<tipo> específicas del sistema de archivos.

mkfs se utiliza para crear un sistema de archivos Linux en un dispositivo, generalmente una partición de disco duro. El argumento dispositivo es el nombre del dispositivo (por ejemplo, /dev/hda1, /dev/sdb2) o un archivo regular que contendrá el sistema de archivos. El argumento tamaño es el número de bloques que se utilizarán para el sistema de archivos.

El estado de salida devuelto por mkfs es 0 en caso de éxito y 1 en caso de fallo.

En realidad, mkfs es simplemente un front-end para los diversos creadores de sistemas de archivos (mkfs.tipo-fs) disponibles en Linux. El creador específico del sistema de archivos se busca a través de la configuración de su entorno PATH. Consulte las páginas del manual del creador específico del sistema de archivos para obtener más detalles.

OPCIONES

-t, --tipo tipo

Especifica el tipo de sistema de archivos a crear. Si no se especifica, se utiliza el tipo de sistema de archivos predeterminado (actualmente ext2).

opciones-fs

Opciones específicas del sistema de archivos que se pasarán al creador real del sistema de archivos.

-V, --verbose

Produce una salida detallada, incluyendo todos los comandos específicos del sistema de archivos que se ejecutan. Especificar esta opción más de una vez inhibe la ejecución de cualquier comando específico del sistema de archivos. Esto es realmente útil solo para pruebas.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale. (La opción -V mostrará información de la versión solo cuando sea el único parámetro, de lo contrario, funcionará como --verbose).

ERRORES

Todas las opciones genéricas deben preceder y no combinarse con opciones específicas del sistema de archivos. Algunos programas específicos del sistema de archivos no detectan automáticamente el tamaño del dispositivo y requieren que se especifique el parámetro tamaño.
