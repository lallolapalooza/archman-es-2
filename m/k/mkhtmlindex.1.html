NOMBRE

mkhtmlindex - genera archivos de índice para páginas de manual en HTML

SINOPSIS

mkhtmlindex htmlmandir

DESCRIPCIÓN

El programa mkhtmlindex genera archivos de índice para un directorio de páginas de manual en formato HTML. Busca archivos cuyos nombres tienen el formato "nombre.1.html", y genera los archivos de índice "manindex1.html", "manindex.2.html", y así sucesivamente, uno para cada volumen del manual. Los archivos de índice vacíos se eliminarán. Los nombres y descripciones se encuentran escaneando la primera sección <H2> de cada página.

OPCIONES

mkhtmlindex solo toma un argumento: el directorio a procesar.

NOTAS

Esta utilidad es actualmente bastante específica para las páginas de manual de X. En particular, el formato de los archivos de índice que genera no es configurable, ni lo es el formato HTML que espera de las páginas de manual.
