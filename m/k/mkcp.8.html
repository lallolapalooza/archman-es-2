NOMBRE

mkcp - crear un punto de control NILFS2

SINOPSIS

mkcp [opciones] [dispositivo]

DESCRIPCIÓN

mkcp es una utilidad para crear un punto de control o instantánea para el sistema de archivos NILFS2 que se encuentra en dispositivo. Cuando se omite dispositivo, intenta encontrar un sistema de archivos NILFS2 en /proc/mounts.

Este comando solo es válido para sistemas de archivos NILFS2 montados y fallará si el dispositivo no tiene montajes activos.

OPCIONES

-s, --snapshot
Crear una instantánea.
-p, --print
Imprimir el número de punto de control cuando se crea con éxito.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar versión y salir.

AUTOR

Koji Sato

DISPONIBILIDAD

mkcp es parte del paquete nilfs-utils y está disponible en https://nilfs.sourceforge.io.

VER TAMBIÉN

nilfs(8), lscp(1), chcp(8), rmcp(8), nilfs-tune(8).
