NOMBRE

mkbitmap - transforma imágenes en mapas de bits con escalado y filtrado

SINOPSIS

mkbitmap [opciones] [archivo...]

DESCRIPCIÓN

mkbitmap lee una imagen y le aplica una o más de las siguientes operaciones, en este orden: inversión, filtrado de paso alto, escalado y umbralización. Cada operación puede ser controlada individualmente y activada o desactivada.

El uso principal de mkbitmap es convertir imágenes en color o en escala de grises a un formato adecuado como entrada para otros programas, en particular el programa de trazado potrace(1). Es particularmente útil para convertir arte lineal escaneado, como dibujos animados, texto manuscrito, etc., a imágenes bitonales de alta resolución.

El filtrado de paso alto se puede utilizar para asegurar que las características del primer plano, como líneas y texto, se conserven, mientras que al mismo tiempo se compensa un fondo irregular. El desenfoque opcional se puede aplicar para suavizar la imagen y eliminar el ruido visual. El escalado es importante porque una imagen en escala de grises escaneada contiene más detalle visual que una imagen bitonal a la misma resolución. Al escalar la imagen a una resolución más alta (utilizando interpolación) antes de umbralizarla, se conserva parte de este detalle. La umbralización significa convertir una imagen en escala de grises a una imagen bitonal utilizando solo píxeles blancos y negros. Los píxeles que son más oscuros que un cierto valor umbral se convierten en negros. La inversión opcional es útil si la imagen de entrada muestra características brillantes sobre un fondo oscuro, como una fotografía de dibujos a tiza en una pizarra.

Los formatos de entrada compatibles son PNM (PBM, PGM, PPM) y BMP. Los formatos de salida son PBM para mapas de bits y PGM para mapas de grises.

OPCIONES

Opciones generales:

-h, --help
muestra el mensaje de ayuda y sale.
-v, --version
muestra la información de la versión y sale.
-l, --license
muestra la información de la licencia y sale.

Opciones de entrada/salida:

archivo
Si se proporcionan argumentos de archivo, mkbitmap creará por defecto un archivo de salida por cada nombre de archivo de entrada dado. El nombre del archivo de salida se obtiene del nombre del archivo de entrada cambiando su sufijo a ".pbm" o ".pgm". Si el nombre del archivo de entrada y el de salida fueran idénticos, se añadirá un sufijo adicional "-out" al nombre del archivo de salida. Si no se proporcionan argumentos de archivo, mkbitmap actúa como un filtro, leyendo de la entrada estándar y escribiendo en la salida estándar. Se puede proporcionar un nombre de archivo "-" para especificar la lectura de la entrada estándar; la salida para este argumento se escribirá en la salida estándar. Cada archivo de entrada puede contener una o más imágenes.
-o archivo, --output archivo
escribe la salida en este archivo. Toda la salida se concatena y se dirige al archivo especificado. Esto anula el comportamiento por defecto de crear un archivo de salida por cada archivo de entrada. Se puede proporcionar un nombre de archivo "-" para especificar la escritura en la salida estándar.

Opciones de procesamiento de imagen:

-x, --nodefaults
Desactiva las opciones por defecto. Normalmente, las siguientes opciones están preseleccionadas por defecto: -f 4 -s 2 -3 -t 0.45. La opción -x deshabilita estos valores por defecto; por lo tanto, mkbitmap -x no hace nada más que copiar una imagen en escala de grises de la entrada a la salida. Luego se pueden añadir otras opciones de procesamiento una por una; por ejemplo, mkbitmap -xf10 solo hace filtrado de paso alto, mkbitmap -xt0.5 solo hace umbralización, etc.
-i, --invert
Invierte la imagen de entrada. Si se elige esta opción, se aplica a la imagen antes de cualquier otra operación. Se utiliza para tratar con imágenes blanco sobre negro, como fotografías de dibujos a tiza en una pizarra. Tenga en cuenta que el comportamiento de esta opción no es en general el mismo que invertir el mapa de bits de salida, a menos que el valor umbral también se invierta.
-f n, --filter n
Aplica un filtro de paso alto a la imagen. Este filtro es aproximadamente Gaussiano y no direccional. El efecto es preservar los detalles pequeños mientras se compensan los gradientes del fondo. El parámetro n es un radio (en píxeles) que corresponde aproximadamente al tamaño de los detalles que deben conservarse. Más precisamente, el filtro se implementa restando una versión desenfocada de la imagen de la imagen original. El parámetro n es igual a la desviación estándar del desenfoque. La salida del paso de filtrado es una imagen normalizada cuyo brillo medio es exactamente 0.5. El radio del filtro por defecto es 4.
-n, --nofilter
Desactiva el filtrado de paso alto.
-b n, --blur n
Desenfoque la imagen. El efecto es suavizar los detalles finos y reducir el ruido visual en la imagen. El parámetro n es el radio de desenfoque y debe elegirse pequeño (1 es un buen valor para empezar). Esto se implementa como un desenfoque aproximadamente Gaussiano y no direccional con una desviación estándar proporcional a n. El desenfoque se aplica después del filtro de paso alto, pero antes del escalado y la umbralización. Si no se proporciona esta opción, el valor por defecto es no aplicar ningún desenfoque.
-s n, --scale n
Escala la imagen por un factor entero n>0. El escalado se realiza después del filtrado de paso alto, pero antes del paso de umbralización. Un factor de escala de 1 indica que no se debe realizar ningún escalado. De lo contrario, se utiliza interpolación para rellenar los píxeles intermedios. Si la salida de mkbitmap se va a utilizar como entrada para un programa de trazado como potrace, se recomienda un factor de escala de 2. Esto conserva la cantidad adecuada de detalle para que el algoritmo de trazado funcione bien. Si se utiliza un factor de escala de 1, se pierde demasiado detalle. Si se utiliza un factor de escala de 3 o superior, la interpolación tiende a "inventar" detalles que no estaban presentes en la imagen original, lo que impide que potrace haga un buen trabajo.
-1, --linear
Utiliza interpolación lineal al escalar a una resolución más alta. Esto es ligeramente más rápido, pero menos agradable, que la interpolación cúbica por defecto.
-3, --cubic
Utiliza interpolación cúbica al escalar a una resolución más alta. Este es el valor por defecto. Es más lento que la interpolación lineal, pero produce mejores resultados.
-t n, --threshold n
Establece el valor del gris umbral para la conversión bitonal. El parámetro n es un valor de brillo entre 0 para negro y 1 para blanco. Cualquier píxel por debajo de este brillo se convertirá en negro (por lo tanto, valores más pequeños de n darán como resultado una salida más blanca).
-g, --grey
Desactiva la conversión bitonal. Si se proporciona esta opción, el procesamiento se detiene después del paso de escalado y se produce un mapa de grises como salida.

ESTADO DE SALIDA

El estado de salida es 0 si la ejecución se completa correctamente, 1 si la línea de comandos es inválida y 2 si ocurre cualquier otro error.
