MKD_LINE(3) Manual de funciones de biblioteca MKD_LINE(3)

NOMBRE

mkd_line — realizar traducción de Markdown de elementos pequeños

BIBLIOTECA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

int
mkd_line(char *cadena, int tamaño, char **documento, int banderas);

int
mkd_generateline(char *cadena, int tamaño, FILE *salida, int banderas);

DESCRIPCIÓN

Ocasionalmente, uno podría querer realizar traducciones de markdown en fragmentos de datos, como el título de un artículo de blog, una fecha o una simple línea de firma. mkd_line y mkd_generateline le permiten realizar traducciones de markdown en pequeños bloques de texto. mkd_line asigna un búfer, luego escribe el texto traducido en ese búfer, y mkd_generateline escribe la salida en el FILE* especificado.

VER TAMBIÉN

markdown(1), markdown(3), markdown(7), mkd-extensions(7), mmap(2).

http://daringfireball.net/projects/markdown/syntax

ERRORES

El manejo de errores es, en el mejor de los casos, mínimo.
