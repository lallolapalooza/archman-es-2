NOMBRE

mkc_compiler_settings - genera la configuración inicial para el compilador C/C++

SINOPSIS

mkc_compiler_settings

DESCRIPCIÓN

mkc_compiler_settings comprueba las capacidades del compilador y almacena la configuración inicial requerida por mk-configure en los archivos
~/.mkcmake/mkc_imp.cc_${CC_TYPE}-${CC_VERSION}.mk o
~/.mkcmake/mkc_imp.cxx_${CXX_TYPE}-${CXX_VERSION}.mk para los compiladores C y C++ respectivamente.

AMBIENTE

CC
Compilador C a comprobar.
CXX
Compilador C++ a comprobar.
USE_CC_COMPILERS
Una lista de compiladores C separados por espacios para comprobar. Esta variable tiene mayor prioridad que CC.
USE_CXX_COMPILERS
Una lista de compiladores C++ separados por espacios para comprobar. Esta variable tiene mayor prioridad que CXX.
