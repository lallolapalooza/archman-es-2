MKRFC2734(1) Manual de Comandos Generales MKRFC2734(1)

NOMBRE

mkrfc2734 - Hacer que Linux 2.4 sea capaz de IP sobre IEEE 1394.

SINOPSIS

mkrfc2734

DESCRIPCIÓN

mkrfc2734 añade entradas a la ROM de configuración IEEE 1394 de Linux para describirse a sí mismo a otros nodos del bus como capaz de realizar funciones de IP sobre IEEE 1394 (RFC 2734). Esta utilidad no es necesaria para Linux 2.6, ya que hay una opción de configuración del kernel para habilitarla. Este comando no toma argumentos y requiere el módulo del kernel raw1394, la biblioteca libraw1394 y el archivo de dispositivo /dev/raw1394. Además, no tiene ningún sentido ejecutar esto a menos que también haya cargado el módulo del kernel eth1394, ¡las partes que hacen el trabajo real!
