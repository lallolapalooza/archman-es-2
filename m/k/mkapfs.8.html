NOMBRE

mkapfs - crear un sistema de archivos APFS

SINOPSIS

mkapfs [-sv] [-L etiqueta] [-U UUID] [-u UUID] [-F tier2] [-B bloques-tier2] dispositivo [bloques]

DESCRIPCIÓN

mkapfs es una herramienta experimental para crear un sistema de archivos APFS con un único volumen en el dispositivo dado. El número de bloques para el dispositivo se puede especificar en bloques, de lo contrario se utilizará todo el disco.

OPCIONES

-s
Habilitar la sensibilidad a mayúsculas/minúsculas para el volumen.
-z
Habilitar la sensibilidad a la normalización para el volumen.
-L etiqueta
Establecer una etiqueta para el volumen, con una longitud máxima de 255 bytes.
-U UUID
Especificar un UUID para el contenedor, en el formato estándar. Por defecto, el valor es elegido por /proc/sys/kernel/random/uuid.
-u UUID
Especificar un UUID para el volumen, en el formato estándar. Por defecto, el valor es elegido por /proc/sys/kernel/random/uuid.
-v
Imprimir el número de versión de mkapfs y salir.
-F tier2
Especificar el dispositivo de nivel 2 (tier 2) para una unidad fusionada (fusion drive).
-B bloques-tier2
Especificar el tamaño (en bloques) para el dispositivo de nivel 2 dado por la opción -F. Por defecto se utiliza todo el disco.

REPORTE DE ERRORES

Por favor, informe de los errores por correo electrónico o, si lo prefiere, cree un problema en github en https://github.com/eafer/apfsprogs/issues.
