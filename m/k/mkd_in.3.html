MARKDOWN(3) Manual de funciones de biblioteca MARKDOWN(3)

NOMBRE

markdown — procesar documentos Markdown

BIBLIOTECA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

MMIOT
*mkd_in(FILE *input, int flags);

MMIOT
*mkd_string(char *string, int size, int flags);

int
markdown(MMIOT *doc, FILE *output, int flags);

DESCRIPCIÓN

Estas funciones convierten documentos y cadenas de Markdown en HTML. markdown() procesa un documento completo, mientras que mkd_text() procesa una única cadena.

Para procesar un archivo, se pasa un FILE* a mkd_in(), y si devuelve un valor distinto de cero, se pasa a markdown(), que luego escribe el documento convertido en el FILE* especificado. Si la entrada ya se ha escrito en una cadena (entrada generada o un archivo abierto con mmap(2)) puede pasar esa cadena a mkd_string() y pasar su valor de retorno a markdown.()

Markdown() acepta los siguientes valores de bandera (combinados con OR si es necesario) para restringir cómo procesa la entrada:

MKD_NOLINKS
No realizar procesamiento de enlaces, bloquear etiquetas <a>.
MKD_NOIMAGE
No realizar procesamiento de imágenes, bloquear <img>.
MKD_NOPANTS
No ejecutar smartypants().
MKD_NOHTML
No permitir HTML sin procesar en absoluto.
MKD_STRICT
Desactivar superíndice y énfasis relajado.
MKD_TAGTEXT
Procesar texto para colocar dentro de una etiqueta html (ID=, NAME=, <title>, &tc); sin <em>, sin <bold>, sin html o expansión de [].
MKD_NO_EXT
No permitir pseudo-protocolos.
MKD_CDATA
Generar código para ![CDATA[...]] xml.
MKD_NOSUPERSCRIPT
No generar superíndices. El énfasis ocurre _en todas partes_
MKD_NOTABLES
No permitir tablas.
MKD_NOSTRIKETHROUGH
Prohibir ~~tachado~~.
MKD_TOC
Realizar procesamiento de tabla de contenidos.
MKD_1_COMPAT
Compatibilidad con MarkdownTest_1.0
MKD_AUTOLINK
Convertir http://foo.com en un enlace incluso sin s de <>.
MKD_SAFELINK
Comprobación paranoica del protocolo de enlace.
MKD_NOHEADER
No procesar bloques de encabezado.
MKD_TABSTOP
Expandir tabulaciones a 4 espacios.
MKD_NODIVQUOTE
Prohibir bloques >%class%.
MKD_NOALPHALIST
Prohibir listas alfabéticas.
MKD_NODLIST
Prohibir listas de definición.
MKD_NODLDISCOUNT
Desactivar el estilo de sintaxis de lista de definición de descuento.
MKD_DLEXTRA
Habilitar el estilo de sintaxis de lista de definición extra.
MKD_EXTRA_FOOTNOTE
Habilitar notas al pie estilo markdown extra.
MKD_NOSTYLE
No extraer (omitir) bloques de <style/> de la salida.
MKD_FENCEDCODE
Permitir bloques de código cercados.
MKD_IDANCHOR
Usar anclajes id= en lugar de <a name=/> para enlaces de tabla de contenidos.
MKD_GITHUBTAGS
Permitir guiones bajos y guiones en nombres de elementos pasados.
MKD_URLENCODEDANCHOR
Usar codificación html5 para caracteres multibyte y no alfanuméricos en lugar de expansión hexadecimal en enlaces de toc.

VALORES DE RETORNO

markdown() devuelve 0 en caso de éxito, 1 en caso de fallo. Las funciones mkd_in() y mkd_string() devuelven un MMIOT* en caso de éxito, nulo en caso de fallo.

VER TAMBIÉN

markdown(1), mkd-callbacks(3), mkd-functions(3), mkd-line(3), markdown(7), mkd-extensions(7), mmap(2).

http://daringfireball.net/projects/markdown/syntax

ERRORES

El manejo de errores es como mucho mínimo.

El MMIOT creado por mkd_string() es eliminado por la función markdown.
