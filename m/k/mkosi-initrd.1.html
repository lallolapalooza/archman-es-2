NOMBRE

mkosi-initrd — Construye initrds o imágenes de kernel unificadas para el sistema actual usando mkosi

SINOPSIS

mkosi-initrd [opciones...]

DESCRIPCIÓN

mkosi-initrd es un script de envoltura sobre mkosi para simplificar la generación de initrds e Imágenes de Kernel Unificadas para el sistema en ejecución actual.

OPCIONES

--kernel-version=
Versión del kernel donde buscar los módulos del kernel a incluir. Por defecto es la versión del kernel del sistema en ejecución (uname -r).
--format=, -t
Formato de salida. Uno de cpio (archivo CPIO), uki (una imagen de kernel unificada con la imagen en la sección PE .initrd) o directory (para generar una imagen directamente en un directorio local). Por defecto es cpio.
--output=, -o
Nombre a usar para el archivo o directorio de la imagen de salida generada. Por defecto es initrd.
--output-dir=, -O
Ruta a un directorio donde colocar todos los artefactos generados. Por defecto es el directorio de trabajo actual.
--debug=
Habilita salida de depuración adicional.
--debug-shell=
Lanza un shell de depuración en el sandbox si un comando en sandbox falla.
--version
Muestra la versión del paquete.
--help, -h
Muestra información breve de uso.
