NOMBRE

mkosi-addon — Construye complementos para imágenes de kernel unificadas para el sistema actual usando mkosi

SINOPSIS

mkosi-addon [opciones...]

DESCRIPCIÓN

mkosi-addon es un envoltorio sobre mkosi para simplificar la generación de complementos PE que contienen personalizaciones para imágenes de kernel unificadas específicas del sistema en ejecución o local. Incluirá entradas en /etc/crypttab marcadas con x-initrd.attach, y /etc/kernel/cmdline. Los módulos del kernel y los firmware para el hardware en ejecución pueden incluirse si se proporciona una configuración local con la opción KernelModulesIncludeHost=.

OPCIONES

--kernel-version=
Versión del kernel donde buscar los módulos del kernel a incluir. Por defecto, es la versión del kernel del sistema en ejecución (uname -r).
--output=, -o
Nombre a usar para el complemento de salida generado. Por defecto, es mkosi-local.addon.efi.
--output-dir=, -O
Ruta a un directorio donde colocar todos los artefactos generados. Por defecto, es el directorio de trabajo actual.
--debug=
Habilita la salida de depuración adicional.
--debug-shell=
Inicia una consola de depuración en el sandbox si falla un comando con sandboxing.
--version
Muestra la versión del paquete.
--help, -h
Muestra información de uso breve.
