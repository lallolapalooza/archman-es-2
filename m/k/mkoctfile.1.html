MKOCTFILE(1) Manual de Comandos Generales MKOCTFILE(1)

NOMBRE

mkoctfile - Compilar módulos cargables dinámicamente para GNU Octave

SINOPSIS

mkoctfile [OPCIÓN]... archivo...

DESCRIPCIÓN

mkoctfile se utiliza para compilar código fuente C, C++ o Fortran en un archivo .oct cargable dinámicamente para octave(1).

OPCIONES

-h, -?, --help
Imprime el mensaje de ayuda.
-Idir
Añade el directorio de inclusión dir a los comandos de compilación.
-idirafterdir
Añade el directorio de inclusión a la segunda ruta de búsqueda de inclusión después de '-I'.
-Ddef
Añade la definición def al comando del compilador.
-llib
Añade la biblioteca lib al comando de enlace.
-Ldir
Añade el directorio de bibliotecas dir al comando de enlace.
-Rdir
Pasa -Rdir al comando de enlace.
-g
Habilita la opción de depuración para todos los compiladores.
-pthread
Añade -pthread al comando de enlace.
-W...
Pasa flags al compilador como -Wa,OPCIÓN.
-Wl,...
Pasa flags al enlazador como -Wl,-rpath=...
-M, --depend
Genera archivos de dependencia (.d) para archivos fuente C y C++.
-c
Compila pero no enlaza.
--link-stand-alone
Enlaza un archivo ejecutable independiente.
-s, --strip
Elimina información de depuración del archivo de salida.
--mex
Crea un archivo MEX. Establece la extensión de salida predeterminada a .mex.
-o archivo, --output archivo
Nombre del archivo de salida. La extensión predeterminada es .oct (o .mex si se especifica --mex) a menos que se esté enlazando un ejecutable independiente.
-p VAR, --print VAR
Imprime la variable de configuración VAR. Hay tres categorías de variables:
Variables de configuración de Octave que los usuarios pueden anular con variables de entorno. Se utilizan en los comandos que mkoctfile ejecuta.
    ALL_CFLAGS                  INCLUDEDIR
    ALL_CXXFLAGS                LAPACK_LIBS
    ALL_FFLAGS                  LDFLAGS
    ALL_LDFLAGS                 LD_STATIC_FLAG
    BLAS_LIBS                   LFLAGS
    CC                          LIBDIR
    CFLAGS                      LIBOCTAVE
    CPICFLAG                    LIBOCTINTERP
    CPPFLAGS                    OCTAVE_LINK_OPTS
    CXX                         OCTINCLUDEDIR
    CXXFLAGS                    OCTAVE_LIBS
    CXXLD                       OCTAVE_LINK_DEPS
    CXXPICFLAG                  OCTLIBDIR
    DL_LDFLAGS                  OCT_LINK_DEPS
    F77                         OCT_LINK_OPTS
    F77_INTEGER8_FLAG           RDYNAMIC_FLAG
    FFLAGS                      SPECIAL_MATH_LIB
    FPICFLAG                    XTRA_CFLAGS
    INCFLAGS                    XTRA_CXXFLAGS
Variables de configuración de Octave como las anteriores, pero actualmente no utilizadas por mkoctfile.
Variables de configuración de Octave que se proporcionan solo con fines informativos. Excepto para OCTAVE_HOME y OCTAVE_EXEC_HOME, los usuarios no pueden anular estas variables.
    AR
    DEPEND_EXTRA_SED_PATTERN
    DEPEND_FLAGS
    FFTW3F_LDFLAGS
    FFTW3F_LIBS
    FFTW3_LDFLAGS
    FFTW3_LIBS
    FFTW_LIBS
    FLIBS
    LIBS
    RANLIB
    READLINE_LIBS
Si OCTAVE_HOME o OCTAVE_EXEC_HOME se establecen en el entorno, entonces otras variables se ajustan en consecuencia con OCTAVE_HOME o OCTAVE_EXEC_HOME sustituyendo el valor original del directorio especificado por las opciones --prefix o --exec-prefix que se utilizaron cuando Octave se configuró.
    API_VERSION                 LOCALARCHLIBDIR
    ARCHLIBDIR                  LOCALFCNFILEDIR
    BINDIR                      LOCALOCTFILEDIR
    CANONICAL_HOST_TYPE         LOCALSTARTUPFILEDIR
    DATADIR                     LOCALVERARCHLIBDIR
    DATAROOTDIR                 LOCALVERFCNFILEDIR
    DEFAULT_PAGER               LOCALVEROCTFILEDIR
    EXEC_PREFIX                 MAN1DIR
    EXEEXT                      MAN1EXT
    FCNFILEDIR                  MANDIR
    IMAGEDIR                    OCTAVE_EXEC_HOME
    INCLUDEDIR                  OCTAVE_HOME
    INFODIR                     OCTDATADIR
    INFOFILE                    OCTDOCDIR
    LIBDIR                      OCTFILEDIR
    LIBEXECDIR                  OCTFONTSDIR
    LOCALAPIARCHLIBDIR          OCTINCLUDEDIR
    LOCALAPIFCNFILEDIR          OCTLIBDIR
    LOCALAPIOCTFILEDIR          STARTUPFILEDIR
    LOCALAPIPKGDIR              VERSION
-v, --verbose
Repite los comandos a medida que se ejecutan.
archivo
Compila o enlaza archivo. Los tipos de archivo reconocidos son:
   .c    Fuente C
   .cc   Fuente C++
   .cp   Fuente C++
   .cpp  Fuente C++
   .CPP  Fuente C++
   .cxx  Fuente C++
   .c++  Fuente C++
   .C    Fuente C++
   .f    Fuente Fortran (forma fija)
   .F    Fuente Fortran (forma fija)
   .f90  Fuente Fortran (forma libre)
   .F90  Fuente Fortran (forma libre)
   .o    archivo objeto
   .a    archivo de biblioteca
