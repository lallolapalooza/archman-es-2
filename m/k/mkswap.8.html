MKSWAP(8) Administración del Sistema MKSWAP(8)

NOMBRE

mkswap - configurar un área de intercambio de Linux

SINOPSIS

mkswap [opciones] dispositivo [bloques]

mkswap [opciones] --size tamaño --file archivo

DESCRIPCIÓN

mkswap configura un área de intercambio de Linux en un dispositivo o en un archivo.

El argumento dispositivo normalmente será una partición de disco (algo como /dev/sdb7) pero también puede ser un archivo. El kernel de Linux no presta atención a los IDs de partición, pero muchos scripts de instalación asumirán que las particiones con el tipo hexadecimal 82 (LINUX_SWAP) están destinadas a ser particiones de intercambio. (Advertencia: Solaris también usa este tipo. Ten cuidado de no matar tus particiones de Solaris.)

El parámetro bloques es superflúo pero se conserva por compatibilidad con versiones anteriores. (Especifica el tamaño deseado del área de intercambio en bloques de 1024 bytes. mkswap usará la partición o archivo completo si se omite. Especificarlo es imprudente: un error tipográfico puede destruir tu disco.)

Después de crear el área de intercambio, necesitas el comando swapon(8) para empezar a usarla. Normalmente las áreas de intercambio se listan en /etc/fstab para que puedan ser activadas al arrancar mediante un comando swapon -a en algún script de arranque.

ADVERTENCIA

La cabecera de intercambio no toca el primer bloque. Un cargador de arranque o una etiqueta de disco pueden estar allí, pero no es una configuración recomendada. La configuración recomendada es usar una partición separada para un área de intercambio de Linux.

mkswap, al igual que muchas otras utilidades tipo mkfs, borra el primer bloque de la partición para hacer invisible cualquier sistema de archivos anterior.

Sin embargo, mkswap se niega a borrar el primer bloque en un dispositivo con una etiqueta de disco (SUN, BSD, ...).

OPCIONES

-c, --check

Comprueba el dispositivo (si es un dispositivo de bloques) en busca de bloques defectuosos antes de crear el área de intercambio. Si se encuentran bloques defectuosos, se imprimirá el recuento.

-F, --file

Crea un archivo de intercambio con los permisos de archivo apropiados y bloques poblados en disco.

-f, --force

Continúa incluso si el comando es estúpido. Esto permite la creación de un área de intercambio más grande que el archivo o partición en la que reside.

Además, sin esta opción, mkswap se negará a borrar el primer bloque en un dispositivo con una tabla de particiones.

-q, --quiet

Suprime la salida y los mensajes de advertencia.

-L, --label etiqueta

Especifica una etiqueta para el dispositivo, para permitir swapon(8) por etiqueta.

--lock[=modo]

Utiliza un bloqueo exclusivo BSD para el dispositivo o archivo en el que opera. El argumento opcional modo puede ser yes, no (o 1 y 0) o nonblock. Si se omite el argumento modo, por defecto es yes. Esta opción sobrescribe la variable de entorno $LOCK_BLOCK_DEVICE. Por defecto, no se utiliza ningún bloqueo, pero se recomienda evitar colisiones con systemd-udevd(8) u otras herramientas.

-p, --pagesize tamaño

Especifica el tamaño de página (en bytes) a usar. Esta opción normalmente es innecesaria; mkswap lee el tamaño del kernel.

-U, --uuid UUID

Especifica el UUID a utilizar. Por defecto, se genera un UUID. El formato del UUID es una serie de dígitos hexadecimales separados por guiones, así: "c1b9d5a2-f162-11cf-9ece-0020afc76f16". El parámetro UUID también puede ser uno de los siguientes:

clear

borra el UUID del sistema de archivos

random

genera un nuevo UUID generado aleatoriamente

time

genera un nuevo UUID basado en tiempo

-e, --endianness ENDIANNESS

Especifica la ENDIANNESS a utilizar, los argumentos válidos son native, little o big. Por defecto es native.

-o, --offset offset

Especifica el offset en el que escribir el área de intercambio.

-s, --size tamaño

Especifica el tamaño del archivo de intercambio creado en bytes y puede ir seguido de un sufijo multiplicador: KiB (=1024), MiB (=1024*1024), y así sucesivamente para GiB, TiB, PiB, EiB, ZiB e YiB (el "iB" es opcional, por ejemplo, "K" tiene el mismo significado que "KiB"). Si el archivo existe y es más grande que tamaño, se truncará a este tamaño. Esta opción solo tiene sentido cuando se usa con --file.

-v, --swapversion 1

Especifica la versión del espacio de intercambio. (Esta opción es actualmente inútil, ya que la antigua opción -v 0 ha quedado obsoleta y ahora solo se soporta -v 1. El kernel no ha soportado el formato de espacio de intercambio v0 desde 2.5.22 (junio de 2002). La nueva versión v1 se soporta desde 1.1.17 (agosto de 1998).)

--verbose

Ejecución detallada. Con esta opción mkswap mostrará más detalles sobre los problemas detectados durante la configuración del área de intercambio.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

ENTORNO

LIBBLKID_DEBUG=all

habilita la salida de depuración de libblkid.

LOCK_BLOCK_DEVICE=<modo>

usa bloqueo exclusivo BSD. El modo es "1" o "0". Vea --lock para más detalles.

NOTAS

El tamaño máximo útil de un área de intercambio depende de la arquitectura y de la versión del kernel.

El número máximo de páginas que es posible direccionar por la cabecera del área de intercambio es 4294967295 (entero sin signo de 32 bits). El espacio restante en el dispositivo de intercambio se ignora.

Actualmente, Linux permite 32 áreas de intercambio. Las áreas en uso pueden ser vistas en el archivo /proc/swaps.

mkswap se niega a crear áreas más pequeñas que 10 páginas.

Si no conoces el tamaño de página que utiliza tu máquina, puedes consultarlo con getconf PAGESIZE.

Desde la versión 2.41, mkswap --file establece el atributo nocow para los archivos recién creados para soportar archivos de intercambio en Btrfs.

# dd if=/dev/zero of=swapfile bs=1MiB count=$((8*1024))

para crear un archivo de intercambio de 8GiB.

En tal caso, por favor lee las notas de swapon(8) sobre las restricciones de uso de archivos de intercambio (agujeros, preasignación y problemas de copia en escritura).
