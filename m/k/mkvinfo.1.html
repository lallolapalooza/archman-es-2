MKVINFO(1) Comandos de usuario MKVINFO(1)

NOMBRE

mkvinfo - Muestra información sobre los elementos en archivos Matroska(TM)

SINOPSIS

mkvinfo [opciones] {nombre-archivo-fuente}

DESCRIPCIÓN

Este programa lista todos los elementos contenidos en un Matroska(TM). La salida se puede limitar a una lista de pistas en el archivo, incluyendo información sobre los códecs utilizados.

-a, --all

Por defecto mkvinfo(1) se detiene al encontrar el primer clúster. Adicionalmente, no muestra ciertos elementos que ocurren con frecuencia. Con esta opción mkvinfo(1) continuará procesando independientemente del nivel de verbosidad y mostrará todos los elementos.

-c, --checksums

Calcula y muestra la suma de verificación Adler-32 para cada fotograma. Útil solo para depuración.

-o, --continue

Por defecto mkvinfo(1) se detiene al encontrar el primer clúster. Con esta opción mkvinfo(1) continuará procesando independientemente del nivel de verbosidad.

-p, --hex-positions

Muestra las posiciones de todos los elementos en hexadecimal, independientemente del nivel de verbosidad.

-P, --positions

Muestra las posiciones de todos los elementos en decimal, independientemente del nivel de verbosidad.

-s, --summary

Solo muestra un resumen conciso de lo que mkvinfo(1) encuentra y no cada elemento.

-t, --track-info

Muestra estadísticas para cada pista en modo detallado. También establece la verbosidad a 1 si estaba en el nivel 0 antes.

-x, --hexdump

Muestra los primeros 16 bytes de cada fotograma como un volcado hexadecimal.

-X, --full-hexdump

Muestra todos los bytes de cada fotograma como un volcado hexadecimal.

-z, --size

Muestra el tamaño de cada elemento, incluyendo su encabezado.

--command-line-charset juego-de-caracteres

Establece el juego de caracteres desde el cual se convierten las cadenas dadas en la línea de comandos. Por defecto es el juego de caracteres dado por la configuración regional actual del sistema.

--output-charset juego-de-caracteres

Establece el juego de caracteres al cual se convierten las cadenas que se van a generar como salida. Por defecto es el juego de caracteres dado por la configuración regional actual del sistema.

-r, --redirect-output nombre-archivo

Escribe todos los mensajes en el archivo nombre-archivo en lugar de en la consola. Si bien esto se puede hacer fácilmente con redirección de salida, hay casos en los que esta opción es necesaria: cuando la terminal reinterpreta la salida antes de escribirla en un archivo. Se respeta el juego de caracteres establecido con --output-charset.

--ui-language código

Fuerza el uso de las traducciones para el idioma código (por ejemplo, 'de_DE' para las traducciones al alemán). Introducir 'list' como código hará que el programa genere una lista de las traducciones disponibles.

--abort-on-warnings

Indica al programa que aborte después de que se emita la primera advertencia. El código de salida del programa será 1.

--debug tema

Activa la depuración para una característica específica. Esta opción solo es útil para desarrolladores.

--engage característica

Activa características experimentales. Se puede solicitar una lista de características disponibles con mkvinfo --engage list. Estas características no están pensadas para ser utilizadas en situaciones normales.

--gui-mode

Activa el modo GUI. En este modo, se pueden generar líneas con formato especial que pueden indicar a una GUI controladora lo que está sucediendo. Estos mensajes siguen el formato '#GUI#mensaje'. El mensaje puede ir seguido de pares clave/valor como en '#GUI#mensaje#clave1=valor1#clave2=valor2...'. Ni los mensajes ni las claves se traducen nunca y siempre se generan en inglés.

-v, --verbose

Sea más detallado. Consulte la sección sobre niveles de verbosidad para obtener una descripción de qué información se generará en cada nivel.

-h, --help

Muestra información de uso y sale.

-V, --version

Muestra información de versión y sale.

@archivo-opciones.json

Lee argumentos de línea de comandos adicionales del archivo archivo-opciones. Para una explicación completa de los formatos admitidos para dichos archivos, consulte la sección llamada "Archivos de opciones" en la página del manual de mkvmerge(1).

NIVELES DE VERBOSIDAD

La opción -v se puede utilizar para aumentar el nivel de verbosidad de mkvinfo(1) e imprimir más información sobre el archivo actual.

En el nivel 0, mkvinfo(1) solo imprimirá los encabezados de pista que encuentre y sus tipos. mkvinfo(1) saldrá tan pronto como los encabezados se analicen completamente (más técnicamente: tan pronto como se encuentre el primer clúster). En este nivel, las entradas del encabezado de búsqueda y las señales (cues) no se mostrarán, incluso si se encuentran delante de la información de la pista.

En el nivel 1, mkvinfo(1) también imprimirá todos los elementos Matroska(TM) encontrados para el archivo completo, pero no las entradas del encabezado de búsqueda ni las entradas de señal. Si el modo resumen está habilitado, mkvinfo(1) generará la posición del fotograma. Esto también se puede lograr con la opción --continue.

En el nivel 2, mkvinfo(1) también imprimirá las entradas del encabezado de búsqueda, las entradas de señal y la posición del archivo donde se encuentra cada elemento Matroska(TM). Esto también se puede lograr con las opciones --all --positions.

En el nivel 3 y superiores, mkvinfo(1) imprimirá información que no está directamente conectada a un elemento Matroska(TM). Todos los demás elementos solo imprimen información sobre los elementos que se acaban de encontrar. El nivel 3 agrega metadatos para facilitar la depuración (es decir, está destinado solo a desarrolladores). Todas las líneas escritas por el nivel 3 están encerradas entre corchetes para facilitar su filtrado.

ARCHIVOS DE TEXTO Y CONVERSIONES DE JUEGOS DE CARACTERES

Para una discusión en profundidad sobre cómo todas las herramientas del conjunto MKVToolNix manejan las conversiones de juegos de caracteres, la codificación de entrada/salida, la codificación de línea de comandos y la codificación de consola, consulte la sección con el mismo nombre en la página del manual de mkvmerge(1).

CÓDIGOS DE SALIDA

mkvinfo(1) sale con uno de los tres códigos de salida:

•0 -- Este código de salida significa que la ejecución ha finalizado correctamente.
•1 -- En este caso, mkvinfo(1) ha generado al menos una advertencia, pero la ejecución continuó. Una advertencia está precedida por el texto 'Advertencia:'.
•2 -- Este código de salida

VARIABLES DE ENTORNO

mkvinfo(1) utiliza las variables predeterminadas que determinan la configuración regional del sistema (por ejemplo, LANG y la familia LC_*). Variables adicionales:

MKVINFO_DEBUG, MKVTOOLNIX_DEBUG y su forma corta MTX_DEBUG

El contenido se trata como si se hubiera pasado a través de la opción --debug.

MKVINFO_ENGAGE, MKVTOOLNIX_ENGAGE y su forma corta MTX_ENGAGE

El contenido se trata como si se hubiera pasado a través de la opción --engage.
