NOMBRE

mkcsmapper - Crear archivos de conversión csmapper para oficonv

SINOPSIS

mkcsmapper [-d] [-m | -p] [-o outfile] [infile]

DESCRIPCIÓN

La utilidad mkcsmapper genera datos de conversión binarios a partir de tablas de conversión de texto plano para la biblioteca oficonv. Los datos de conversión tienen tres componentes: el mapeo de conversión entre codificaciones de caracteres específicas, un directorio de archivos de mapeo disponibles y un archivo pivote, que contiene los pares de codificaciones de origen y destino posibles o el conjunto de mapeos a utilizar para una codificación compuesta.

PARÁMETROS

infile  archivo de entrada (desde oficonv/datasrc/csmapper) a convertir

OPCIONES

opciones generales

  -d    modo de depuración, imprime información de depuración
  -m    crear directorio de archivos de mapeo disponibles
  -p    crear archivo pivote
  -o    [f]ilename: string
        guardar la salida en el archivo f

ESTADO DE SALIDA

La utilidad mkcsmapper finaliza con 0 en caso de éxito y >0 si ocurre un error.
