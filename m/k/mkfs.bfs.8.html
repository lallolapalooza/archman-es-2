MKFS.BFS(8) Administración del Sistema MKFS.BFS(8)

NOMBRE

mkfs.bfs - crear un sistema de archivos bfs de SCO

SINOPSIS

mkfs.bfs [opciones] dispositivo [número-de-bloques]

DESCRIPCIÓN

mkfs.bfs crea un sistema de archivos bfs de SCO en un dispositivo de bloques (generalmente una partición de disco o un archivo accesible a través del dispositivo de bucle).

El parámetro número-de-bloques es el tamaño deseado del sistema de archivos, en bloques. Si no se especifica nada, se utilizará toda la partición.

OPCIONES

-N, --inodos número

Especifica el número deseado de inodos (como máximo 512). Si no se especifica nada, se elige un número predeterminado en el rango de 48-512, dependiendo del tamaño de la partición.

-V, --nombre-volumen etiqueta

Especifica la etiqueta del volumen. No tengo idea de si se usa o dónde.

-F, --nombre-archivo nombre

Especifica el nombre del sistema de archivos. No tengo idea de si se usa o dónde.

--lock[=modo]

Utiliza un bloqueo BSD exclusivo para el dispositivo o archivo en el que opera. El argumento opcional modo puede ser yes, no (o 1 y 0) o nonblock. Si se omite el argumento modo, se utiliza yes por defecto. Esta opción sobrescribe la variable de entorno $LOCK_BLOCK_DEVICE. La opción predeterminada es no utilizar ningún bloqueo, pero se recomienda evitar colisiones con systemd-udevd(8) u otras herramientas.

-v, --verboso

Explica lo que se está haciendo.

-c

Esta opción se ignora silenciosamente.

-l

Esta opción se ignora silenciosamente.

-h, --ayuda

Muestra el texto de ayuda y sale.

-V, --versión

Muestra la versión y sale. La opción -V solo funciona como --version cuando es la única opción.

ESTADO DE SALIDA

El estado de salida devuelto por mkfs.bfs es 0 cuando todo fue bien y 1 cuando algo salió mal.

VER TAMBIÉN

mkfs(8)

REPORTAR ERRORES

Para informes de errores, utiliza el rastreador de incidencias https://github.com/util-linux/util-linux/issues.

DISPONIBILIDAD

El comando mkfs.bfs es parte del paquete util-linux, que se puede descargar desde el Archivo del Kernel de Linux https://www.kernel.org/pub/linux/utils/util-linux/.
