Nombre

mkarchiso - Generador de ISO de Arch Linux

Sinopsis

mkarchiso [opciones] directorio_perfil

Descripción

mkarchiso crea una ISO, artefactos de netboot y un tarball bootstrap, y opcionalmente los firma.

Opciones

-A aplicacion
Establece un nombre de aplicación para la ISO.
Por defecto: 'mkarchiso iso'.
-C archivo
Archivo de configuración de pacman.
Por defecto: /etc/pacman.conf.
-D directorio_instalacion
Establece un directorio_instalacion. Todos los archivos se ubicarán aquí.
Por defecto: arch.
NOTA: Máximo 8 caracteres, usa solo a-z0-9.
-L etiqueta
Establece la etiqueta del volumen ISO.
Por defecto: MKARCHISO.
-P editor
Establece el editor de la ISO.
Por defecto: mkarchiso.
-c certificado_y_clave
Proporciona certificados para la firma de código de los artefactos de netboot, así como del artefacto rootfs.
Se proporcionan múltiples archivos como una lista entre comillas y separada por espacios.
El primer archivo se considera el certificado de firma, el segundo la clave y el tercero la autoridad de certificación opcional.
-g clave_gpg
Establece la ID de clave PGP a utilizar para firmar la imagen rootfs. Se pasa a gpg como el valor de --default-key.
-G mbox
Establece el firmante PGP (debe incluir una dirección de correo electrónico). Se pasa a gpg como el valor de --sender.
-h
Mensaje de ayuda.
-m modo
Modo(s) de construcción a utilizar (los modos válidos son: bootstrap, iso y netboot). Se proporcionan múltiples modos de construcción como una lista entre comillas y separada por espacios.
-o directorio_salida
Establece el directorio de salida.
Por defecto: ./out.
-p paquetes
Paquete(s) a instalar.
Se proporcionan múltiples paquetes como una lista entre comillas y separada por espacios.
-r
Elimina el directorio de trabajo al final.
-v
Habilita la salida detallada.
-w directorio_trabajo
Establece el directorio de trabajo.
Por defecto: ./work.

Ejemplos

Construir el perfil releng

mkarchiso /usr/share/archiso/configs/releng
