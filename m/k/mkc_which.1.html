mkc_which(1)

Paquete: mk-configure

Licencias: BSD

MKC_WHICH(1) MKC_WHICH(1)

NOMBRE

localiza un archivo de programa en la variable de entorno $PATH del usuario

SINOPSIS

mkc_which [-x] nombre

DESCRIPCIÓN

mkc_which toma un nombre y busca el archivo que se ejecutaría si este nombre se hubiera dado como un comando. El argumento se busca a lo largo de la variable PATH del usuario.

OPCIONES

-x
Si nombre no se encuentra o no es ejecutable, el estado de salida es cero.

ESTADO DE SALIDA

0
si el comando especificado se encuentra y es ejecutable
1
si el comando especificado no existe o no es ejecutable
2
si se especifica una opción inválida
