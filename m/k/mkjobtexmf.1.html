NOMBRE

mkjobtexmf -- Genera un árbol texmf para un trabajo particular

VERSIÓN

2011-11-10 v0.8

SINOPSIS

El programa mkjobtexmf ejecuta un programa e intenta encontrar los nombres de archivo utilizados. Hay dos métodos disponibles: la opción "-recorder" de TeX (Web2C) o el programa strace.

Luego genera un directorio con un árbol texmf. Comprueba los archivos encontrados e intenta clasificarlos en este árbol texmf.

Puede ser utilizado para fines de archivado o para acelerar las siguientes ejecuciones de TeX.

mkjobtexmf [opciones]

Esto ejecuta TeX, que puede ser configurado por las opciones. Ambos métodos para obtener los nombres de archivo utilizados están disponibles.

mkjobtexmf [opciones] -- <cmd> [args]

La última forma ejecuta el programa cmd con los argumentos args en lugar de TeX. Como método, solo el programa strace está disponible.

Opciones:

--jobname <nombre>     Nombre del trabajo (obligatorio).
                          Normalmente es el archivo TeX
                          sin extensión
--texname <archivo>    Archivo de entrada para TeX. Por defecto es el
                          nombre del trabajo con extensión '.tex'
--texopt <opción>      Opción para la ejecución de TeX
--destdir <directorio>  Directorio de destino,
                          por defecto es `<nombre_trabajo>.mjt'
--output               Incluir también los archivos de salida
--strace               Usar strace en lugar de la
                          opción -recorder de TeX
--copy                 Copiar archivos en lugar de crear
                          enlaces simbólicos
--flat                 Ignorar rutas, no crear directorios
                          dentro del directorio de destino
--(no)texhash          Ejecutar texhash, usar --notexhash para MiKTeX
--exclude-ext <ext>    Excluir archivos con extensión <ext>.
--cmd-tex <cmd>        Comando para el compilador TeX
--cmd-kpsewhich <cmd>  Comando para kpsewhich
--cmd-texhash <cmd>    Comando para texhash
--cmd-strace <cmd>     Comando para strace
--verbose              Salida detallada
--help                 Mensaje de ayuda breve
--man                  Documentación completa
--version              Mostrar identificación de la versión

DESCRIPCIÓN

Ejecución del programa

Primero mkjobtexmf ejecuta un programa, normalmente TeX. El compilador TeX se configura con la opción "--cmd-tex". La opción "--texname" puede ser usada si el nombre del archivo con la extensión difiere de .tex:

mkjobtexmf --jobname foo --texname foo.ltx

Incluso son posibles casos más complicados:

mkjobtexmf --jobname foo --texname '\def\abc{...}\input{foo}'

Si se debe usar otro programa que TeX (dvips, ...), entonces este programa puede ser proporcionado después de "--":

mkjobtexmf --jobname foo -- dvips foo

Registro de archivos

Hay dos métodos disponibles para obtener los nombres de archivo utilizados:

Grabador de TeX
Algunas distribuciones de TeX (por ejemplo, Web2C) soportan la opción -recorder para sus compiladores TeX. Entonces, el compilador TeX genera un archivo con la extensión .fls que registra los archivos de entrada y salida utilizados.
Programa strace
Este programa rastrea llamadas al sistema y señales. Se utiliza aquí para registrar los archivos utilizados.

Análisis y enlace/copia de archivos encontrados

Se genera el directorio de resultado nombre_trabajo.mjt. Dentro se crea el árbol TEXMF de resultado. Cada archivo encontrado se compara con una lista de rutas de árboles TEXMF. Si se encuentra una coincidencia, el archivo se enlaza/copia en el árbol TEXMF. La lista de rutas se genera con el programa kpsewhich.

Si el archivo no puede ser mapeado a un árbol TEXMF y el archivo es un nombre de archivo relativo, entonces se enlaza/copia directamente en el directorio de resultado nombre_trabajo.mjt. No se soportan nombres de archivo absolutos ni rutas con enlaces a directorios padre.

Por defecto se crean enlaces simbólicos. Los archivos se copian si se proporciona la opción "--copy" o si el enlace simbólico no está disponible.

OPCIONES

--jobname=<nombre_trabajo>
Es el nombre del trabajo. `<nombre_trabajo>.tex' sirve como valor por defecto para el archivo TeX y <nombre_trabajo> se usa para nombrar varios directorios y archivos. Ver sección "ARCHIVOS".
--texname=<nombre>
El nombre del archivo de entrada de TeX, si es diferente de <nombre_trabajo>.tex.
--texopt=<opt>
Opción adicional para el compilador TeX, ejemplos son "--ini" o "--shell-escape". Esta opción puede darse más de una vez.
--destdir=<directorio>
Especifica el nombre del directorio de destino donde se recopila el resultado. Por defecto, se genera un directorio en el directorio actual con el nombre del trabajo y la extensión `.mjt'.
--output
Incluir también los archivos de salida.
--strace
Usar el método con el programa strace, ver "DESCRIPCIÓN".
--copy
Los archivos se copian en lugar de crear enlaces simbólicos.
--flat
Los archivos se enlazan o copian sin elementos de ruta. El directorio de destino contendrá una lista plana de archivos o enlaces sin directorio.

Los archivos `ls-R' y `aliases' se ignoran.

--exclude-ext=<ext>
Se excluyen los archivos con extensión <ext>. La opción puede darse varias veces o puede usarse una lista de extensiones separadas por comas. Ejemplos: 
--exclude-ext aux --exclude-ext log --exclude-ext toc

es lo mismo que

--exclude-ext aux,log,toc
--(no)texhash
Por defecto, se genera el archivo `ls-R' en el árbol `texmf', ya que esta es la base de datos de nombres de archivo que podría usarse en TeX Live. Como MiKTeX usa un mecanismo diferente, su `texhash' no genera los archivos `ls-R' y "--notexhash" suprime la llamada a `texhash'.
--cmd-tex=<cmd>
Comando para el compilador TeX. Por defecto es pdflatex.
--cmd-kpsewhich=<cmd>
Comando para kpsewhich.
--cmd-texhash=<cmd>
Comando para actualizar la base de datos de nombres de archivo del árbol texmf generado. Por defecto es texmf.
--cmd-strace=<cmd>
Comando para strace.
--verbose
Mensajes detallados.
--help
Mostrar pantalla de ayuda.
-man
Mostrar página de manual.
--version
Mostrar identificación de la versión y salir.

EJEMPLOS

Archivo TeX test.tex usando el método grabador de TeX:

mkjobtexmf --jobname test

Archivo TeX test.tex usando LaTeX:

mkjobtexmf --jobname test --cmd-tex latex

Generación de formato:

mkjobtexmf --jobname test --texopt -ini --texname pdflatex.ini

Ejemplo de cómo se puede usar el nuevo árbol texmf (Linux/bash):

TEXMF=!!test.mjt/texmf pdflatex test

Ejemplo para generar un archivo zip (Linux/bash):

(cd test.mjt && zip -9r ../test .)

Ejemplo para generar un archivo tar:

tar cjhvf test.tar.bz2 -C test.mjt .

ARCHIVOS

El nombre del trabajo <jobname> se usa para nombrar los siguientes archivos y directorios:

jobname.mjt/
Directorio de destino con el árbol texmf generado.
jobname.mjt/texmf/
El árbol texmf.
jobname.fls
Archivo de registro de archivos si se usa el método recorder.
jobname.log
Archivo de registro de TeX.

PROBLEMAS NO RESUELTOS, ADVERTENCIAS, PENDIENTES

Software experimental
Las opciones, los valores predeterminados y el funcionamiento del programa pueden cambiar en futuras versiones.
Archivos texmf.cnf
Actualmente, el método con strace registra estos archivos. El grabador de TeX no lo hace. Son útiles los archivos texmf.cnf para la configuración de variables. Dado que solo tenemos un árbol TEXMF, las secciones de ruta probablemente deberían ser reescritas.
Configuraciones en variables de entorno
No se almacenan en absoluto.
Colisiones
El programa utiliza un directorio de destino y como máximo un árbol TEXMF para el resultado. Sin embargo, los archivos de origen pueden provenir de diferentes directorios y árboles TEXMF. Por lo tanto, las colisiones de nombres son posibles.

El programa sigue la estrategia de no eliminar archivos en el directorio de destino. Esto permite recopilar archivos de diferentes ejecuciones. Por lo tanto, las colisiones se resuelven de manera que la primera entrada que se realiza en el directorio de destino gana.

Archivo de configuración
Ahorraría al usuario tener que escribir las mismas opciones una y otra vez.
Grabación incompleta
Los errores en la grabación de archivos de TeX pueden dar lugar a una grabación incompleta de archivos (por ejemplo, pdfTeX 1.40.3 no graba archivos .pfb y .pk).
