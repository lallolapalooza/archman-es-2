mkostemp(3) Manual de Funciones de Biblioteca mkostemp(3)

NOMBRE

mkstemp, mkostemp, mkstemps, mkostemps - crear un archivo temporal único

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int mkstemp(char *plantilla);
int mkostemp(char *plantilla, int flags);
int mkstemps(char *plantilla, int longitud_sufijo);
int mkostemps(char *plantilla, int longitud_sufijo, int flags);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

mkstemp():

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

mkostemp():

    _GNU_SOURCE

mkstemps():

    /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

mkostemps():

    _GNU_SOURCE

DESCRIPCIÓN

La función mkstemp() genera un nombre de archivo temporal único a partir de plantilla, crea y abre el archivo, y devuelve un descriptor de archivo abierto para el archivo.

Los últimos seis caracteres de plantilla deben ser "XXXXXX" y estos se reemplazan con una cadena que hace que el nombre del archivo sea único. Dado que se modificará, plantilla no debe ser una cadena constante, sino que debe declararse como un array de caracteres.

El archivo se crea con permisos 0600, es decir, solo lectura y escritura para el propietario. El descriptor de archivo devuelto proporciona acceso tanto de lectura como de escritura al archivo. El archivo se abre con la bandera open(2) O_EXCL, garantizando que el llamador sea el proceso que crea el archivo.

La función mkostemp() es como mkstemp(), con la diferencia de que los siguientes bits (con el mismo significado que para open(2)) pueden especificarse en flags: O_APPEND, O_CLOEXEC y O_SYNC. Tenga en cuenta que al crear el archivo, mkostemp() incluye los valores O_RDWR, O_CREAT y O_EXCL en el argumento flags dado a open(2); incluir estos valores en el argumento flags dado a mkostemp() es innecesario y produce errores en algunos sistemas.

La función mkstemps() es como mkstemp(), excepto que la cadena en plantilla contiene un sufijo de longitud_sufijo caracteres. Por lo tanto, plantilla tiene el formato prefijoXXXXXXsufijo, y la cadena XXXXXX se modifica como para mkstemp().

La función mkostemps() es a mkstemps() como mkostemp() es a mkstemp().

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el descriptor de archivo del archivo temporal. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EEXIST
No se pudo crear un nombre de archivo temporal único. Ahora el contenido de plantilla no está definido.
EINVAL
Para mkstemp() y mkostemp(): Los últimos seis caracteres de plantilla no eran XXXXXX; ahora plantilla no se ha modificado.
Para mkstemps() y mkostemps(): plantilla tiene menos de (6 + longitud_sufijo) caracteres de longitud, o los últimos 6 caracteres antes del sufijo en plantilla no eran XXXXXX.

Estas funciones también pueden fallar con cualquiera de los errores descritos para open(2).

En las versiones 2.06 y anteriores de glibc, el archivo se crea con permisos 0666, es decir, lectura y escritura para todos los usuarios. Este comportamiento antiguo puede ser un riesgo de seguridad, especialmente dado que otras variantes de UNIX usan 0600, y alguien podría pasar por alto este detalle al portar programas. POSIX.1-2008 añade un requisito de que el archivo se cree con el modo 0600.

De forma más general, la especificación POSIX de mkstemp() no dice nada sobre los modos de archivo, por lo que la aplicación debe asegurarse de que su máscara de creación de modo de archivo (ver umask(2)) esté configurada adecuadamente antes de llamar a mkstemp() (y mkostemp()).

NAME

mkostemp - crear un archivo temporal seguro en modo de solo lectura

SYNOPSIS

#include <stdio.h>

int mkostemp(char *template);

DESCRIPTION

La función mkostemp crea un archivo temporal único utilizando template como parte de su nombre. El sufijo de template debe contener al menos tres caracteres 'X'. La función reemplazará estos caracteres 'X' con una cadena generada aleatoriamente para formar un nombre de archivo único.

El archivo se crea con permisos de solo lectura (0444). Si la creación tiene éxito, el descriptor de archivo del archivo abierto se devuelve. Si falla, se devuelve -1 y errno se establece adecuadamente.

A diferencia de mkstemp, mkostemp no establece ningún bit de permiso en el archivo creado, lo que permite al llamante controlar completamente los permisos del archivo.

RETURN VALUE

Al éxito, devuelve el descriptor de archivo del archivo temporal creado. En caso de error, devuelve -1 y establece errno para indicar la causa.

ERRORS

  • EEXIST: No se pudo crear el archivo porque ya existía uno con el mismo nombre.
  • EINVAL: El template no es válido.
  • ENFILE: Se ha alcanzado el límite máximo de archivos abiertos en el sistema.
  • ENOENT: No se pudo crear el directorio especificado en template.
  • ENOMEM: No había suficiente memoria disponible.
  • ENOSPC: No había espacio suficiente en el dispositivo para crear el archivo.

STANDARDS

mkostemp es una extensión de GNU y no está estandarizado por POSIX.

HISTORY

La función mkostemp apareció por primera vez en la biblioteca C de GNU.

SEE ALSO

mkstemp(3), tmpfile(3), mktemp(3)
