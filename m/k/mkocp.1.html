mkocp(1) Manual de Comandos Generales mkocp(1)

NOMBRE

mkocp - interfaz para otp2ocp(1)

SINOPSIS

mkocp ARCHIVOOTP

DESCRIPCIÓN

mkocp se utiliza para crear o recrear archivos de Proceso Compilado Omega (binario) a partir de archivos de Proceso de Traducción Omega (texto).

Los Procesos de Traducción Omega se utilizan para traducir un conjunto de caracteres a otro y para elegir entre caracteres con una o más variantes sensibles al contexto. Los OTP también podrían usarse para cambiar mayúsculas o guiones de texto.

Los OTP se definen en archivos de texto y se compilan en código binario (OCP) usando mkocp (este script) o directamente con otp2ocp(1).

ARCHIVOS

ARCHIVOOTP
Un archivo de filtro de Proceso de Tipografía Omega.

VER TAMBIÉN

omega(1), otp2ocp(1).

https://ctan.org/pkg/omega
