mkc_install(1)

Paquete: mk-configure

Licencias: BSD

MKC_INSTALL(1) MKC_INSTALL(1)

NOMBRE

install - instalar binarios

SINOPSIS

install -d [-o propio] [-g grp] [-m mod] dir1 dir2 ... dirN
install [-cs] [-l flags] [-o propio] [-g grp] [-m mod] archivo1 archivo2
install [-cs] [-l flags] [-o propio] [-g grp] [-m mod] [archivos...] dir

DESCRIPCIÓN

Los archivos se copian al archivo o directorio de destino. Si el destino es un directorio, el archivo se copia dentro del directorio con su nombre de archivo original.

OPCIONES

-c
Copiar el archivo. Este es el comportamiento por defecto; la bandera se mantiene solo por compatibilidad con versiones anteriores.
-d
Crear directorios. Los directorios padres faltantes se crean según sea necesario.
-g grupo
Especificar un grupo.
-l flags_enlace
En lugar de copiar el archivo, crear un enlace al origen. El tipo de enlace se determina por el argumento flags_enlace. Los flags_enlace válidos son: h (duro), s (simbólico).
-m modo
Especificar un modo alternativo. El modo por defecto se establece en rwxr-xr-x (0755). El modo especificado puede ser un valor octal o simbólico; véase chmod(1) para una descripción de los posibles valores de modo.
-o propietario
Especificar un propietario.
-s
install ejecuta el comando strip(1) para eliminar símbolos de los binarios, de modo que install pueda ser portable en un gran número de sistemas y tipos de binarios. Si la variable de entorno STRIP está establecida, se utiliza como el programa strip(1).

ENTORNO

STRIP
El programa utilizado para eliminar símbolos de los binarios instalados cuando se usa la opción -s. Si no se especifica, se usa strip.

ESTADO DE SALIDA


La utilidad install sale con 0 en caso de éxito, y >0 si ocurre un error.
