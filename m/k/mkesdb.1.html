NOMBRE

mkesdb - Crear archivos de base de datos de esquemas de codificación (esdb) para oficonv

SINOPSIS

mkesdb [-d] [-m] [-o outfile] infile

DESCRIPCIÓN

La utilidad mkesdb genera un catálogo de conversión para la biblioteca oficonv. Los datos generados incluyen una lista de codificaciones admitidas y sus características más importantes, como el módulo decodificador a utilizar.

PARÁMETROS

infile  archivo de entrada (de oficonv/datasrc/esdb) a convertir

OPCIONES

opciones generales

  -d    modo de depuración, imprime información de depuración
  -m    procesar un catálogo de directorios o un archivo alias,
        en lugar de una descripción de codificación
  -o    [f]nombre de archivo: cadena
        almacena la salida en el archivo f

ESTADO DE SALIDA

La utilidad mkesdb sale con 0 en caso de éxito y >0 si ocurre un error.
