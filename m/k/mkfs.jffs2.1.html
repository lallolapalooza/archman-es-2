MKFS.JFFS2(1) Manual de Comandos Generales MKFS.JFFS2(1)

NOMBRE

mkfs.jffs2 - Crear una imagen del sistema de archivos JFFS2 a partir de un directorio

SINOPSIS

mkfs.jffs2 [ -p,--pad[=TAMAÑO] ] [ -r,-d,--root directorio ] [ -s,--pagesize=TAMAÑO ] [ -e,--eraseblock=TAMAÑO ] [ -c,--cleanmarker=TAMAÑO ] [ -n,--no-cleanmarkers ] [ -o,--output imagen.jffs2 ] [ -l,--little-endian ] [ -b,--big-endian ] [ -D,--devtable=ARCHIVO ] [ -f,--faketime ] [ -q,--squash ] [ -U,--squash-uids ] [ -P,--squash-perms ] [ --with-xattr ] [ --with-selinux ] [ --with-posix-acl ] [ -m,--compression-mode=MODO ] [ -x,--disable-compressor=NOMBRE ] [ -X,--enable-compressor=NOMBRE ] [ -y,--compressor-priority=PRIORIDAD:NOMBRE ] [ -L,--list-compressors ] [ -t,--test-compression ] [ -h,--help ] [ -v,--verbose ] [ -V,--version ] [ -i,--incremental imagen.jffs2 ]

DESCRIPCIÓN

El programa mkfs.jffs2 crea una imagen del sistema de archivos JFFS2 (Second Journalling Flash File System) y escribe la imagen resultante en el archivo especificado por la opción -o o, por defecto, en la salida estándar, a menos que la salida estándar sea un dispositivo terminal, en cuyo caso mkfs.jffs2 abortará.

La imagen del sistema de archivos se crea utilizando los archivos y directorios contenidos en el directorio especificado por la opción -r o el directorio actual, si no se especifica la opción -r.

Cada bloque de los archivos que se colocarán en la imagen del sistema de archivos se comprimirá utilizando uno de los compresores disponibles, dependiendo del modo de compresión seleccionado.

Los sistemas de archivos se crean con la misma endianness que el host, a menos que se especifiquen las opciones -b o -l. El controlador JFFS2 en el kernel de Linux 2.4 solo admitía imágenes que tenían la misma endianness que la CPU. A partir de la versión 2.5.48, el kernel se puede cambiar con un #define para aceptar imágenes de endianness no nativa. No se planea un soporte completo bi-endian en el kernel.

Es poco probable que las imágenes JFFS2 sean útiles excepto en conjunción con los controladores MTD (Memory Technology Device) en el kernel de Linux, ya que el controlador del sistema de archivos JFFS2 en el kernel requiere dispositivos MTD.

OPCIONES

Las opciones que toman argumentos de TAMAÑO se pueden especificar como decimales (por ejemplo, 65536), octales (0200000) o hexadecimales (0x1000).

-p, --pad[=TAMAÑO]
Rellena la salida hasta TAMAÑO bytes con 0xFF. Si no se especifica TAMAÑO, la salida se rellena hasta el final del bloque de borrado final.
-r, -d, --root=DIR
Construye el sistema de archivos a partir del directorio DIR. El valor por defecto es el directorio actual.
-s, --pagesize=TAMAÑO
Utiliza el tamaño de página TAMAÑO. El valor por defecto es 4 KiB. Este tamaño es el tamaño máximo de un nodo de datos. Establécelo según el tamaño de página de gestión de memoria del sistema de destino (NOTA: esto NO está relacionado con el tamaño de página NAND).
-e, --eraseblock=TAMAÑO
Utiliza el tamaño de bloque de borrado TAMAÑO. El valor por defecto es 64 KiB. Si se utiliza un tamaño de bloque de borrado diferente al del dispositivo MTD de destino, JFFS2 puede no funcionar de manera óptima. Si el TAMAÑO especificado es inferior a 4096, se asume que las unidades están en KiB.
-c, --cleanmarker=TAMAÑO
Escribe nodos ´CLEANMARKER´ con el tamaño especificado. Normalmente no es apropiado especificar un tamaño distinto al valor por defecto de 12 bytes.
-n, --no-cleanmarkers
No escribe nodos ´CLEANMARKER´ al principio de cada bloque de borrado. Esta opción puede ser útil para crear imágenes JFFS2 para usar en memoria flash NAND, y para crear imágenes que se utilizarán en una variedad de hardware con diferentes tamaños de bloque de borrado.
-o, --output=ARCHIVO
Escribe la imagen JFFS2 en el archivo ARCHIVO. El valor por defecto es la salida estándar.
-l, --little-endian
Crea una imagen JFFS2 little-endian. El valor por defecto es crear una imagen con la misma endianness que el host.
-b, --big-endian
Crea una imagen JFFS2 big-endian. El valor por defecto es crear una imagen con la misma endianness que el host.
-D, --devtable=ARCHIVO
Utiliza el ARCHIVO nombrado como archivo de tabla de dispositivos, para incluir dispositivos y cambiar permisos en la imagen creada cuando el usuario no tiene permisos apropiados para crearlos en el sistema de archivos de origen.
-f, --faketime
Cambia todas las marcas de tiempo de los archivos a ´0´ para pruebas de regresión.
-q, --squash
Comprime permisos y propietarios, haciendo que todos los archivos pertenezcan a root y eliminando el permiso de escritura para ´grupo´ y ´otros´.
-U, --squash-uids
Comprime propietarios, haciendo que todos los archivos pertenezcan a root.
-P, --squash-perms
Comprime permisos, eliminando el permiso de escritura para ´grupo´ y ´otros´.
--with-xattr
Habilita xattr, introduce todas las entradas xattr en el archivo de imagen jffs2.
--with-selinux
Habilita xattr, introduce solo las etiquetas SELinux en el archivo de imagen jffs2.
--with-posix-acl
Habilita xattr, introduce solo las entradas POSIX ACL en el archivo de imagen jffs2.
-m, --compression-mode=MODO
Establece el modo de compresión por defecto. El modo por defecto es priority, que prueba los compresores en un orden predefinido y elige el primero que tiene éxito. Las alternativas son: none (mkfs no comprimirá) y size (mkfs probará todos los compresores y elegirá el que tenga el resultado más pequeño).
-x, --disable-compressor=NOMBRE
Deshabilita un compresor. Utiliza -L para ver la lista de compresores disponibles y su estado por defecto.
-X, --enable-compressor=NOMBRE
Habilita un compresor. Utiliza -L para ver la lista de compresores disponibles y su estado por defecto.
-y, --compressor-priority=PRIORIDAD:NOMBRE
Establece la prioridad de un compresor. Utiliza -L para ver la lista de compresores disponibles y su prioridad por defecto. Las prioridades se utilizan en el modo de compresión por prioridad.
-L, --list-compressors
Muestra la lista de compresores disponibles y sus estados.
-t, --test-compression
Llama a la descompresión después de cada compresión, compara el resultado con los datos originales y realiza otras comprobaciones.
-h, --help
Muestra el texto de ayuda.
-v, --verbose
Operación detallada.
-V, --version
Muestra la información de la versión.
-i, --incremental=ARCHIVO
Genera una imagen de apéndice para ARCHIVO. Si ARCHIVO se escribe en memoria flash y se le anexa la salida, parecerá que es una sola cosa.

LIMITACIONES

El formato y la sintaxis del archivo de tabla de dispositivos no permiten crear enlaces simbólicos cuando estos no están ya presentes en el directorio de trabajo raíz.

Sin embargo, los enlaces simbólicos se pueden especificar en el archivo de tabla de dispositivos utilizando el tipo l con el fin de establecer sus permisos y propiedad.

ERRORES

JFFS2 limita los números de mayor y menor de los dispositivos a 8 bits cada uno. Algunos consideran esto un error.
