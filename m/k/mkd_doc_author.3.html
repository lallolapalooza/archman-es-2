MKD_FUNCTIONS(3) Manual de Funciones de Librería MKD_FUNCTIONS(3)

NOMBRE

mkd_functions — acceder y procesar documentos Markdown.

LIBRERÍA

Markdown (libmarkdown, -lmarkdown)

SINOPSIS

#include <mkdio.h>

int
mkd_compile(MMIOT *documento, int flags);

int
mkd_css(MMIOT *documento, char **doc);

int
mkd_generatecss(MMIOT *documento, FILE *salida);

int
mkd_document(MMIOT *documento, char **doc);

int
mkd_generatehtml(MMIOT *documento, FILE *salida);

int
mkd_xhtmlpage(MMIOT *documento, int flags, FILE *salida);

int
mkd_toc(MMIOT *documento, char **doc);

void
mkd_generatetoc(MMIOT *documento, FILE *salida);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

DESCRIPCIÓN

El formato markdown soportado en esta implementación incluye bloques de encabezado y en línea de estilo Pandoc <style>, y las funciones estándar de markdown(3) no proporcionan acceso a los datos proporcionados por ninguna de esas extensiones. Estas funciones le dan acceso a esos datos, además de proporcionar una forma más granular de convertir documentos de Markdown a HTML.

Dado un MMIOT* generado por mkd_in() o mkd_string(), mkd_compile() compila el documento en secciones <style>, Pandoc y html.

Una vez compilado, el documento puede ser examinado y escrito por las funciones mkd_css(), mkd_document(), mkd_generatecss(), mkd_generatehtml(), mkd_generatetoc(), mkd_toc(), mkd_xhtmlpage(), mkd_doc_title(), mkd_doc_author(), y mkd_doc_date().

mkd_css() asigna una cadena y la rellena con cualquier sección <style> proporcionada en el documento, mkd_generatecss() escribe cualquier sección <style> en la salida, mkd_document() apunta texto al texto del documento y devuelve el tamaño del documento, mkd_generatehtml() escribe el resto del documento en la salida, y mkd_doc_title(), mkd_doc_author(), mkd_doc_date() se utilizan para leer el contenido de un encabezado de Pandoc, si lo hay.

mkd_xhtmlpage() escribe una página xhtml que contiene el documento. Se puede pasar el conjunto regular de banderas.

mkd_toc() escribe un esquema del documento, en forma de una colección de listas anidadas con enlaces a cada encabezado del documento, en una cadena asignada con malloc(), y devuelve el tamaño.

mkd_generatetoc() es como mkd_toc(), excepto que escribe el esquema del documento en el argumento FILE* dado.

mkd_cleanup() elimina un MMIOT* una vez finalizado el procesamiento.

mkd_compile() acepta las mismas banderas que markdown() y mkd_string() hacen;

MKD_NOIMAGE
No procesar `![]' y eliminar las etiquetas <img> de la salida.
MKD_NOLINKS
No procesar `[]' y eliminar las etiquetas <a> de la salida.
MKD_NOPANTS
No realizar la modificación de comillas, guiones o elipses al estilo Smartypants.
MKD_TAGTEXT
Procesar la entrada como si se estuviera dentro de una etiqueta html. Esto significa que no se generarán etiquetas html, y mkd_compile() intentará escapar cualquier cosa que pueda confundir terriblemente a un navegador web.
MKD_NO_EXT
No procesar ningún pseudo-protocolo de markdown al manejar enlaces [][].
MKD_NOHEADER
No intentar analizar ningún encabezado al estilo Pandoc.
MKD_TOC
Etiquetar todos los encabezados para su uso con la función mkd_generatetoc().
MKD_1_COMPAT
Bandera de compatibilidad MarkdownTest_1.0; recortar espacios finales de la primera línea de los bloques de código y deshabilitar enlaces de referencia implícitos.
MKD_NOSTRIKETHROUGH
Deshabilitar el soporte para tachado.

VALORES DE RETORNO

La función mkd_compile() devuelve 1 en caso de éxito, o 0 si el documento ya está compilado. La función mkd_generatecss() devuelve el número de bytes escritos en caso de éxito, o EOF si ocurrió un error. La función mkd_generatehtml() devuelve 0 en caso de éxito, -1 en caso de fallo.

mkd_doc_author(3) - Discount Markdown documentation

NAME

mkd_doc_author - Discount Markdown documentation

LIBRARY

libdiscount (libdiscount.so, -ldiscount)

SYNOPSIS

#include <discount.h>

char * mkd_doc_author(char *buf, int len);

DESCRIPTION

The documentation for the mkd_doc_author() function is embedded within the Markdown source file itself. This function is not intended to be called by users. It is part of the internal documentation generation process of the discount library.

The function signature suggests it might take a buffer and its length as input and potentially return a string related to the author's documentation, but its primary purpose is within the library's build or documentation system.

RETURN VALUES

The return value is not explicitly defined for user interaction, as this function is internal.
