MISSION-CONTROL-5(8) Servicios D-Bus MISSION-CONTROL-5(8)

NOMBRE

mission-control-5 - Gestor de cuentas/despachador de canales Telepathy

SINOPSIS

/usr/lib/telepathy/mission-control-5

DESCRIPCIÓN

Mission Control 5 implementa los servicios AccountManager y ChannelDispatcher descritos en la especificación D-Bus de Telepathy, permitiendo a clientes como empathy(1) almacenar detalles de cuentas, conectarse a cuentas, solicitar canales de comunicación y que los canales sean despachados a ellos.

Es un servicio D-Bus que se ejecuta en el bus de sesión, y normalmente debería iniciarse automáticamente por la activación de D-Bus. Sin embargo, podría ser útil iniciarlo manualmente para depuración.

OPCIONES

No hay opciones de línea de comandos.

ENTORNO

MC_DEBUG=all o MC_DEBUG=categoría[,categoría...]
Puede establecerse en "all" para obtener una salida de depuración completa de Mission Control y telepathy-glib, o varias categorías no documentadas (que pueden cambiar entre versiones) para filtrar la salida. Consulte el código fuente de Mission Control y telepathy-glib para ver las categorías disponibles.
MC_DEBUG=nivel
Establece un nivel de depuración numérico para el propio Mission Control (pero no para telepathy-glib). El nivel 0 no registra nada, el nivel 1 registra la mayoría de los mensajes y el nivel 2 registra todos los mensajes.
MC_TP_DEBUG=tipo
Puede establecerse en "all" para obtener una salida de depuración completa de telepathy-glib, o varias opciones no documentadas (que pueden cambiar entre versiones de telepathy-glib) para filtrar la salida. Consulte el código fuente de telepathy-glib para ver las opciones disponibles.
