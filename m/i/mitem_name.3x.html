mitem_name(3X) Llamadas de biblioteca mitem_name(3X)

NOMBRE

item_name, item_description - obtener los campos de nombre y descripción del elemento de menú

SINOPSIS

#include <menu.h>
const char *item_name(const ITEM *item);
const char *item_description(const ITEM *item);

DESCRIPCIÓN

La función item_name devuelve la parte del nombre del elemento dado.
La función item_description devuelve la parte de la descripción del elemento dado.

VALOR DE RETORNO

Estas rutinas devuelven un puntero (que puede ser NULL). No establecen errno.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran compatibles con las versiones 7 o BSD.

AUTORES

Juergen Pfeifer. Páginas del manual y adaptación para curses nuevas de Eric S. Raymond.

VER TAMBIÉN

curses(3X), menu(3X)
