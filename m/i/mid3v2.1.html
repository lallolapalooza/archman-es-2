NOMBRE

mid3v2 - editor de etiquetas de audio similar a 'id3v2'

SINOPSIS

mid3v2 [opciones] nombre_archivo ...

DESCRIPCIÓN

mid3v2 es un reemplazo basado en Mutagen para id3v2 de id3lib. Soporta ID3v2.4 y más marcos; tampoco tiene los numerosos errores que plagan a id3v2.

Este programa existe principalmente para compatibilidad con programas que quieren etiquetar archivos usando id3v2. Para una interfaz más utilizable, recomendamos Ex Falso.

OPCIONES

-q, --quiet
Silencioso: no mencione las operaciones de archivo que realizan la solicitud del usuario. Las advertencias aún se imprimirán.
-v, --verbose
Verboso: indique todas las operaciones realizadas. Esto es lo opuesto a --quiet. Este es el valor predeterminado.
-e, --escape
Habilita la interpretación de escapes de barra invertida para los valores de etiqueta. Permite escapar el separador de dos puntos en los valores TXXX, WXXX, COMM como '\:' e insertar secuencias de escape como '\n', '\t', etc.
-f, --list-frames
Muestra todos los marcos ID3v2.3/2.4 compatibles y sus significados.
-L, --list-genres
Lista todos los géneros numéricos de ID3v1. Estos se pueden usar para establecer marcos TCON, pero no se recomienda.
-l, --list
Lista todas las etiquetas en los archivos. El formato de salida *no* es el mismo que el de id3v2; en su lugar, es fácilmente analizable y legible. Algunas etiquetas pueden no tener representaciones legibles por humanos.
--list-raw
Lista todas las etiquetas en los archivos, en formato crudo. Aunque este formato es nominalmente legible por humanos, puede ser muy largo si la etiqueta contiene datos binarios incrustados.
-d, --delete-v2
Elimina las etiquetas ID3v2.
-s, --delete-v1
Elimina las etiquetas ID3v1.
-D, --delete-all
Elimina todas las etiquetas ID3.
--delete-frames=MARCOS
Elimina marcos ID3v2 específicos (o grupos de marcos) de los archivos. MARCOS es una lista de nombres de marcos separados por comas, por ejemplo: "TPE1,TALB"
-C, --convert
Convierte etiquetas ID3v1 a etiquetas ID3v2. Esto también ocurrirá automáticamente durante cualquier edición.
-a,--artist=ARTISTA
Establece la información del artista (TPE1).
-A,--album=ÁLBUM
Establece la información del álbum (TALB).
-t,--song=TÍTULO
Establece la información del título (TIT2).
-c,--comment=<DESCRIPCIÓN:COMENTARIO:IDIOMA>
Establece un comentario (COMM). El idioma y la descripción pueden omitirse, en cuyo caso el idioma por defecto es el inglés y la descripción una cadena vacía.
-p,--picture=<NOMBRE_ARCHIVO:DESCRIPCIÓN:TIPO_IMAGEN:TIPO_MIME>
Establece la imagen adjunta (APIC). Todo excepto el nombre del archivo puede omitirse, en cuyo caso se utilizarán los valores predeterminados.
-g,--genre=GÉNERO
Establece la información del género (TCON).
-y,--year=<AAAA>, --date=<AAAA-[MM-DD]>
Establece la información del año/fecha (TDRC).
-T,--track=<NÚM/NÚM>
Establece el número de pista (TRCK).

Cualquier marco de texto o URL (aquellos que comienzan con T o W) puede modificarse o agregarse anteponiendo el nombre del marco con "--". Por ejemplo, --TIT3 "Monkey!" establecerá el marco TIT3 (subtítulo) a Monkey!.

El marco TXXX tiene el formato <DESCRIPCIÓN:TEXTO>; se pueden establecer muchos marcos TXXX en el archivo siempre que tengan claves diferentes. Para establecer esta clave, simplemente separe el texto con dos puntos, por ejemplo, --TXXX "ALBUMARTISTSORT:Ejemplos, The". La descripción se puede omitir, en cuyo caso se establece por defecto a una cadena vacía.

El marco WXXX tiene el mismo formato que TXXX, pero dado que las URL suelen contener un ":", debe proporcionar una descripción o habilitar el escape (-e): --WXXX "desc:http://foo.bar" o -e --WXXX "http\\://foo.bar"

El marco USLT tiene el formato <DESCRIPCIÓN:TEXTO:IDIOMA>. El idioma y la descripción pueden omitirse, en cuyo caso el idioma por defecto es el inglés y la descripción una cadena vacía.

El marco especial POPM se puede establecer de manera similar: --POPM "bob@example.com:128:2" para establecer la calificación de Bob a 128/255 con 2 reproducciones.

ERRORES

No se realiza ninguna verificación de cordura en las operaciones de edición que usted realiza, por lo que mid3v2 aceptará felizmente --TSIZ al editar un marco ID3v2.4. Sin embargo, también lo desechará automáticamente durante la siguiente operación de edición.
