mididings(1) Manual de comandos generales mididings(1)

NOMBRE

mididings - Un enrutador y procesador MIDI basado en Python.

DESCRIPCIÓN

La herramienta de línea de comandos mididings ofrece varias formas de ejecutar parches sin escribir scripts completos de Python.

OPCIONES

--version

Muestra el número de versión de Python y mididings.

-h, --help

Muestra el mensaje de ayuda.

OPCIONES DE BACKEND

-A

Utiliza el secuenciador ALSA.

-J

Utiliza JACK MIDI (con búfer).

-R

Utiliza JACK MIDI (tiempo real).

-c nombre_cliente

Nombre del cliente ALSA o JACK.

-i puertos

Número de puertos de entrada.

-o puertos

Número de puertos de salida.

-I conexiones

Conexiones de puertos de entrada. Expresión regular.

-O conexiones

Conexiones de puertos de salida. Expresión regular.

OPCIONES GENERALES

-d retraso

Retraso (en segundos) antes de que comience el procesamiento.

-t desplazamiento

Desplazamiento de octava.

-z desplazamiento

Desplazamiento para números de puerto, canal y programa.

OPCIONES DE MODO

-f nombre_archivo

Nombre del archivo del script a ejecutar.

-s

Shell interactivo.

-S

Shell interactivo con ejecución automática de parches.

-p

Imprime eventos MIDI. No se realiza ningún procesamiento.

VER TAMBIÉN

Consulte la documentación en línea en https://mididings.github.io/mididings/ para obtener información actual sobre mididings y sus herramientas relacionadas.

ERRORES (INFORME)

¿Errores? Debes estar bromeando; no hay errores en este software. Pero si resulta que nos equivocamos, envía un informe de error con tantos detalles como sea posible en https://github.com/mididings/mididings/issues.
