mitem_current(3X) Llamadas a biblioteca mitem_current(3X)

NOMBRE

mitem_current - establecer y obtener el elemento_actual_del_menú

SINOPSIS

#include <menu.h>
int set_current_item(MENU *menu, ITEM *item);
ITEM *current_item(const MENU *menu);
int set_top_row(MENU *menu, int row);
int top_row(const MENU *menu);
int item_index(const ITEM *item);

DESCRIPCIÓN

La función set_current_item establece el elemento actual (el elemento en el que se posiciona el cursor del menú). current_item devuelve un puntero al elemento actual en el menú dado.

La función set_top_row establece la fila superior del menú para mostrar la fila dada (la fila superior es inicialmente 0 y se restablece a este valor cada vez que se alterna la opción O_ROWMAJOR). El elemento más a la izquierda en la fila dada se convierte en el actual. La función top_row devuelve el número de la fila superior del menú que se está mostrando.

La función item_index devuelve el índice (con origen cero) del item en la lista de punteros de elementos del menú.

VALOR DE RETORNO

current_item devuelve un puntero (que puede ser NULL). No establece errno.

top_row e item_index devuelven ERR (el valor general de error de curses) si su parámetro menu es NULL.

set_current_item y set_top_row devuelven uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_BAD_ARGUMENT
La rutina detectó un argumento incorrecto o fuera de rango.
E_BAD_STATE
La rutina fue llamada desde una función de inicialización o terminación.
E_NOT_CONNECTED
No hay elementos conectados al menú.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No fueron soportadas en las versiones 7 o BSD.

La documentación de la biblioteca de menús SVr4 especifica que el valor de error de top_row e index_item es -1 (que es el valor de ERR).

AUTORES
