NOMBRE

miniserve - Para cuando realmente solo quieres servir algunos archivos por HTTP ahora mismo!

SINOPSIS

miniserve [-v|--verbose] [--temp-directory] [--index] [--spa] [--pretty-urls] [-p|--port] [-i|--interfaces] [-a|--auth] [--auth-file] [--route-prefix] [--random-route] [-P|--no-symlinks] [-H|--hidden] [-S|--default-sorting-method] [-O|--default-sorting-order] [-c|--color-scheme] [-d|--color-scheme-dark] [-q|--qrcode] [-u|--upload-files] [--web-upload-files-concurrency] [--chmod] [--directory-size] [-U|--mkdir] [-m|--media-type] [-M|--raw-media-type] [-o|--on-duplicate-files] [-R|--rm-files] [-r|--enable-tar] [-g|--enable-tar-gz] [-z|--enable-zip] [-C|--compress-response] [-D|--dirs-first] [-t|--title] [--header] [-l|--show-symlink-info] [-F|--hide-version-footer] [--hide-theme-selector] [-W|--show-wget-footer] [--print-completions] [--print-manpage] [--tls-cert] [--tls-key] [--readme] [-I|--disable-indexing] [--enable-webdav] [--size-display] [--file-external-url] [-h|--help] [-V|--version] [RUTA]

DESCRIPCIÓN

Para cuando realmente solo quieres servir algunos archivos por HTTP ahora mismo!

OPCIONES

-v, --verbose
Ser verboso, incluye la emisión de registros de acceso
También se puede especificar con la variable de entorno MINISERVE_VERBOSE.
--temp-directory <DIRECTORIO_TEMPORAL_CARGAS>
La ruta donde se escribirán las cargas de archivos antes de moverlos a su ubicación correcta. Es aconsejable asegurarse de que este directorio se escribirá en disco y no en memoria.

Este valor solo se utilizará **SI** la carga de archivos está habilitada. Si esta opción no está configurada, se utilizará el directorio temporal predeterminado del sistema operativo.

También se puede especificar con la variable de entorno MINISERVER_TEMP_UPLOAD_DIRECTORY.
--index <ÍNDICE>
El nombre de un archivo de índice de directorio para servir, como "index.html"

Normalmente, cuando miniserve sirve un directorio, crea una lista de ese directorio. Sin embargo, si un directorio contiene este archivo, miniserve servirá ese archivo en su lugar.

También se puede especificar con la variable de entorno MINISERVE_INDEX.
--spa
Activar el modo SPA (Single Page Application)

Esto hará que el archivo dado por --index se sirva para todas las rutas de archivo inexistentes. En efecto, esto servirá el archivo de índice siempre que de otro modo ocurriría un 404, para permitir que el enrutador SPA maneje la solicitud.

También se puede especificar con la variable de entorno MINISERVE_SPA.
--pretty-urls
Activar el modo Pretty URLs

Esto hará que el servidor sirva el archivo `.html` equivalente indicado por la ruta.

`/about` intentará encontrar `about.html` y servirlo.

También se puede especificar con la variable de entorno MINISERVE_PRETTY_URLS.
-p, --port <PUERTO> [predeterminado: 8080]
Puerto a utilizar
También se puede especificar con la variable de entorno MINISERVE_PORT.
-i, --interfaces <INTERFACES>
Interfaz en la que escuchar
También se puede especificar con la variable de entorno MINISERVE_INTERFACE.
-a, --auth <AUTH>
Establecer autenticación

Formatos actualmente soportados: nombre de usuario:contraseña, nombre de usuario:sha256:hash, nombre de usuario:sha512:hash (ej. joe:123, joe:sha256:a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3)

También se puede especificar con la variable de entorno MINISERVE_AUTH.
--auth-file <ARCHIVO_AUTH>
Leer valores de autenticación de un archivo

Ejemplo de contenido del archivo:

joe:123 bob:sha256:a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3 bill:

También se puede especificar con la variable de entorno MINISERVE_AUTH_FILE.
--route-prefix <PREFIJO_RUTA>
Usar un prefijo de ruta específico
También se puede especificar con la variable de entorno MINISERVE_ROUTE_PREFIX.
--random-route
Generar una ruta aleatoria de 6 dígitos hexadecimales
También se puede especificar con la variable de entorno MINISERVE_RANDOM_ROUTE.
-P, --no-symlinks
Ocultar enlaces simbólicos en la lista y evitar que sean seguidos
También se puede especificar con la variable de entorno MINISERVE_NO_SYMLINKS.
-H, --hidden
Mostrar archivos ocultos
También se puede especificar con la variable de entorno MINISERVE_HIDDEN.
-S, --default-sorting-method <METODO_ORDENACION_PREDETERMINADO> [predeterminado: name]
Método de ordenación predeterminado para la lista de archivos

Valores posibles:

  • name: Ordenar por nombre
  • size: Ordenar por tamaño
  • date: Ordenar por fecha de última modificación (ordenación natural: sigue el orden alfanumérico)
También se puede especificar con la variable de entorno MINISERVE_DEFAULT_SORTING_METHOD.
-O, --default-sorting-order <ORDEN_ORDENACION_PREDETERMINADO> [predeterminado: desc]
Orden de ordenación predeterminado para la lista de archivos

Valores posibles:

  • asc: Orden ascendente
  • desc: Orden descendente
También se puede especificar con la variable de entorno MINISERVE_DEFAULT_SORTING_ORDER.
-c, --color-scheme <ESQUEMA_COLOR> [predeterminado: squirrel]
Esquema de color predeterminado

[valores posibles: squirrel, archlinux, zenburn, monokai]

También se puede especificar con la variable de entorno MINISERVE_COLOR_SCHEME.
-d, --color-scheme-dark <ESQUEMA_COLOR_OSCURO> [predeterminado: archlinux]
Esquema de color predeterminado

[valores posibles: squirrel, archlinux, zenburn, monokai]

También se puede especificar con la variable de entorno MINISERVE_COLOR_SCHEME_DARK.
-q, --qrcode
Habilitar visualización de código QR
También se puede especificar con la variable de entorno MINISERVE_QRCODE.
-u, --upload-files [<DIRECTORIO_PERMITIDO_CARGAS>]
Habilitar carga de archivos (y opcionalmente especificar para qué directorio)

También se puede especificar con la variable de entorno MINISERVE_ALLOWED_UPLOAD_DIR.
--web-upload-files-concurrency <WEB_UPLOAD_CONCURRENCY> [valor predeterminado: 0]
Configura la cantidad de cargas concurrentes al visitar el sitio web. Debe tener la opción 'upload-files' habilitada para que esta configuración tenga efecto.

Por ejemplo, un valor de 4 significaría que el navegador web solo cargará 4 archivos a la vez al servidor web cuando se utilice la interfaz del navegador web.

Cuando el valor se mantiene en 0, intenta resolver todas las cargas a la vez en el navegador web.

NOTA: Las páginas web tienen un límite en cuanto a la cantidad de conexiones HTTP activas que pueden tener abiertas al mismo tiempo, por lo que, aunque establezca un límite de concurrencia de 100, el navegador solo progresará en la cantidad máxima de conexiones que permite tener abiertas la página web.

También se puede especificar con la variable de entorno MINISERVE_WEB_UPLOAD_CONCURRENCY.
--chmod <CHMOD>
Establece los permisos de archivo de Unix para los archivos cargados.

Esto toma un número octal, por ejemplo 0600. Por defecto, se utiliza 0666 & ~umask para simular el comportamiento predeterminado del sistema.

También se puede especificar con la variable de entorno MINISERVE_CHMOD.
--directory-size
Habilita el cálculo recursivo del tamaño de los directorios.

Esto está deshabilitado por defecto porque es una operación potencialmente intensiva en E/S.

También se puede especificar con la variable de entorno MINISERVE_DIRECTORY_SIZE.
-U, --mkdir
Habilita la creación de directorios.
También se puede especificar con la variable de entorno MINISERVE_MKDIR_ENABLED.
-m, --media-type <MEDIA_TYPE>
Especifica los tipos de medios cargables.

[posibles valores: image, audio, video]

También se puede especificar con la variable de entorno MINISERVE_MEDIA_TYPE.
-M, --raw-media-type <MEDIA_TYPE_RAW>
Especifica directamente la expresión del tipo de medio cargable.
También se puede especificar con la variable de entorno MINISERVE_RAW_MEDIA_TYPE.
-o, --on-duplicate-files <ON_DUPLICATE_FILES> [valor predeterminado: error]
Qué hacer si existen archivos con el mismo nombre durante la carga de archivos.

Si habilita el cambio de nombre de archivos, el cambio de nombre se realizará agregando un sufijo numérico al nombre del archivo antes de la extensión final. Por ejemplo, `file.txt` se cargará como `file-1.txt`, el número se incrementará hasta que se encuentre un nombre de archivo disponible.

[posibles valores: error, overwrite, rename]

También se puede especificar con la variable de entorno MINISERVE_ON_DUPLICATE_FILES.
-R, --rm-files [<ALLOWED_RM_DIR>]
Habilita la eliminación de archivos y directorios (y opcionalmente especifica para qué directorio).
También se puede especificar con la variable de entorno MINISERVE_ALLOWED_RM_DIR.
-r, --enable-tar
Habilita la generación de archivos tar sin comprimir.
También se puede especificar con la variable de entorno MINISERVE_ENABLE_TAR.
-g, --enable-tar-gz
Habilita la generación de archivos tar comprimidos con gz.
También se puede especificar con la variable de entorno MINISERVE_ENABLE_TAR_GZ.
-z, --enable-zip
Habilita la generación de archivos zip.

ADVERTENCIA: Comprimir directorios grandes puede provocar una excepción de falta de memoria porque la generación de zip se realiza en memoria y no se puede enviar sobre la marcha.

También se puede especificar con la variable de entorno MINISERVE_ENABLE_ZIP.
-C, --compress-response
Comprime la respuesta.

ADVERTENCIA: Habilitar esta opción puede ralentizar las transferencias debido a la sobrecarga de la CPU, por lo que está deshabilitada por defecto.

Solo habilite esta opción si sabe que sus usuarios tienen conexiones lentas o si desea minimizar el uso de ancho de banda de su servidor.

También se puede especificar con la variable de entorno MINISERVE_COMPRESS_RESPONSE.
-D, --dirs-first
Lista los directorios primero.
También se puede especificar con la variable de entorno MINISERVE_DIRS_FIRST.
-t, --title <TITLE>
Se muestra en lugar del host en el título y encabezado de la página.
También se puede especificar con la variable de entorno MINISERVE_TITLE.
--header <HEADER>
Inserta encabezados personalizados en las respuestas. Especifique cada encabezado como un par 'Encabezado:Valor'. Este parámetro se puede utilizar varias veces para agregar múltiples encabezados.

Ejemplo: --header "Encabezado1:Valor1" --header "Encabezado2:Valor2" (Si un encabezado ya está establecido o se insertó previamente, no se sobrescribirá).

También se puede especificar con la variable de entorno MINISERVE_HEADER.
-l, --show-symlink-info
Visualiza los enlaces simbólicos en la lista de directorios.
También se puede especificar con la variable de entorno MINISERVE_SHOW_SYMLINK_INFO.
-F, --hide-version-footer
Oculta el pie de página de la versión.
También se puede especificar con la variable de entorno MINISERVE_HIDE_VERSION_FOOTER.
--hide-theme-selector
Oculta el selector de temas.
También se puede especificar con la variable de entorno MINISERVE_HIDE_THEME_SELECTOR.
-W, --show-wget-footer
Si está habilitado, muestra un comando `wget` para descargar recursivamente el directorio actual.
También se puede especificar con la variable de entorno MINISERVE_SHOW_WGET_FOOTER.
--print-completions <shell>
Genera un archivo de completado para un shell.

[posibles valores: bash, elvish, fish, powershell, zsh]

--print-manpage
Genera la página man.
--tls-cert <TLS_CERT>
Certificado TLS a utilizar.
También se puede especificar con la variable de entorno MINISERVE_TLS_CERT.
--tls-key <TLS_KEY>
Clave privada TLS a utilizar.
También se puede especificar con la variable de entorno MINISERVE_TLS_KEY.
--readme
Habilita la representación de README.md en los directorios.
También se puede especificar con la variable de entorno MINISERVE_README.
-I, --disable-indexing
Deshabilita la indexación.

Esto evitará que se generen listas de directorios y devolverá un error en su lugar.

También se puede especificar con la variable de entorno MINISERVE_DISABLE_INDEXING.
--enable-webdav
Habilita el soporte WebDAV de solo lectura (solicitudes PROPFIND).
También se puede especificar con la variable de entorno MINISERVE_ENABLE_WEBDAV.
--size-display <SIZE_DISPLAY> [valor predeterminado: human]
Muestra el tamaño del archivo servido en bytes exactos.

[posibles valores: human, exact]

También se puede especificar con la variable de entorno MINISERVE_SIZE_DISPLAY.
--file-external-url <FILE_EXTERNAL_URL>
URL externa opcional (por ejemplo, 'http://external.example.com:8081') que se antepone a los enlaces de archivos en las listas.

Permite servir archivos desde una URL diferente a la instancia de navegación. Útil para configuraciones como: una instancia autenticada para navegar, vinculando archivos (a través de esta opción) a una segunda instancia no indexada (-I) para descargas directas. Esto oculta la lista completa de archivos en el servidor de descargas, mientras que los usuarios aún pueden copiar URL de archivos directas para compartir. La URL externa se antepone literalmente a la ubicación relativa del archivo, incluido el protocolo. El usuario debe asegurarse de que esto resulte en una URL válida, no se realizan verificaciones adicionales.

También se puede especificar con la variable de entorno MINISERVE_FILE_EXTERNAL_URL.
-h, --help
Imprime la ayuda (ver un resumen con '-h').
-V, --version
Imprime la versión.
[PATH]
Qué ruta servir.
También se puede especificar con la variable de entorno MINISERVE_PATH.
variable.
