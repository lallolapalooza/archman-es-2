NOMBRE

mime.types - archivo de descripción de tipos mime para cups

DESCRIPCIÓN

El archivo mime.types define los tipos de archivo reconocidos.

Los tipos de archivo adicionales se especifican en archivos con la extensión .types en el directorio de configuración de CUPS.

Cada línea en el archivo mime.types es un comentario, está en blanco o es una línea de regla. Las líneas de comentario comienzan con el carácter #. Las líneas de regla comienzan con el tipo de medio MIME y, opcionalmente, van seguidas de una serie de reglas de reconocimiento de archivos:

    mime/type [ regla ... regla ]
Las reglas se pueden extender a lo largo de varias líneas usando el carácter de barra invertida (\): 
    mime/type [ regla-muy-muy-larga ... \
      regla ]
Los tipos de medio MIME especificados por el campo mime/type no distinguen entre mayúsculas y minúsculas y se ordenan en orden alfanumérico ascendente para fines de coincidencia. Consulte la sección "COINCIDENCIA DE TIPOS Y PRIORIDAD" para obtener más información.

Las reglas pueden agruparse usando paréntesis, unirse usando "+" para un AND lógico, unirse usando "," o espacios en blanco para un OR lógico, y negarse usando "!".

REGLAS

Las reglas tienen dos formas: una extensión de nombre de archivo por sí sola y funciones con valores de prueba entre paréntesis. Las siguientes funciones están disponibles:

match("patrón")
Verdadero si el nombre del archivo coincide con el patrón de comodín de shell dado.
ascii(desplazamiento,longitud)
Verdadero si los longitud bytes que comienzan en desplazamiento son ASCII imprimibles válidos (CR, NL, TAB, BS, 32-126). longitud no puede exceder los 8192 bytes.
printable(desplazamiento,longitud)
Verdadero si los longitud bytes que comienzan en desplazamiento son caracteres de 8 bits imprimibles (CR, NL, TAB, BS, 32-126, 128-254). longitud no puede exceder los 8192 bytes.
priority(número)
Especifica la prioridad relativa de este tipo de medio MIME. La prioridad predeterminada es 100. Los valores más grandes tienen mayor prioridad, mientras que los valores más pequeños tienen menor prioridad.
string(desplazamiento,"cadena")
Verdadero si los bytes que comienzan en desplazamiento son idénticos a cadena.
istring(desplazamiento,"cadena")
Verdadero si los bytes que comienzan en desplazamiento coinciden con cadena sin distinguir entre mayúsculas y minúsculas.
char(desplazamiento,valor)
Verdadero si el byte en desplazamiento es idéntico a valor.
short(desplazamiento,valor)
Verdadero si el entero de 16 bits big-endian en desplazamiento es idéntico a valor.
int(desplazamiento,valor)
Verdadero si el entero de 32 bits big-endian en desplazamiento es idéntico a valor.
locale("cadena")
Verdadero si la configuración regional actual coincide con cadena.
contains(desplazamiento,longitud,"cadena")
Verdadero si los bytes que comienzan en desplazamiento durante longitud bytes contienen cadena. longitud no puede exceder los 8192 bytes.

CONSTANTES DE CADENA

Las constantes de cadena se pueden especificar entre comillas ("") para cadenas que contienen espacios en blanco y entre corchetes (<>) para cadenas hexadecimales.

COINCIDENCIA DE TIPOS Y PRIORIDAD

Cuando CUPS necesita determinar el tipo de medio MIME de un archivo dado, comprueba cada tipo de medio MIME definido en los archivos .types. Cuando dos o más tipos coinciden con un archivo dado, el tipo elegido dependerá del nombre del tipo y la prioridad, y se utilizarán los tipos de mayor prioridad sobre los de menor prioridad. Si los tipos tienen la misma prioridad, los nombres de los tipos se ordenan alfanuméricamente en orden ascendente y se elige el primer tipo.

Por ejemplo, si los tipos "text/bar" y "text/foo" se definen para que coincidan con la extensión "doc", normalmente se elegirá el tipo "text/bar" ya que su nombre es alfanuméricamente menor que "text/foo". Sin embargo, si "text/foo" también define una prioridad mayor que "text/bar", se elegirá "text/foo" en su lugar.

ARCHIVOS

/etc/cups - Directorio de configuración típico de CUPS.

EJEMPLOS

Defina dos tipos de medios MIME para datos ráster, siendo uno un subconjunto con mayor prioridad:

    application/vnd.cups-raster  string(0,"RaSt") string(0,"tSaR") \
                                  string(0,"RaS2") string(0,"2SaR") \
                                  string(0,"RaS3") string(0,"3SaR")
    image/pwg-raster              string(0,"RaS2") + \
                                  string(4,PwgRaster<00>) priority(150)
