MISC_CONV(3) Manual de Linux-PAM MISC_CONV(3)

NOMBRE

misc_conv - función de conversación basada en texto

SINOPSIS

#include <security/pam_misc.h>

int misc_conv(int num_msg, const struct pam_message **msgm, struct pam_response **response, void *appdata_ptr);

DESCRIPCIÓN

La función misc_conv es parte de libpam_misc y no de la biblioteca estándar libpam. Esta función solicitará al usuario los comentarios apropiados y obtendrá las entradas adecuadas según lo dirijan los módulos de autenticación.

Además de encajar simplemente en la pam_conv(3) apropiada, esta función proporciona algunas instalaciones de tiempo de espera. La función exporta cinco variables que pueden ser utilizadas por un programador de aplicaciones para limitar la cantidad de tiempo que esta función de conversación tardará en esperar a que el usuario escriba algo. Las cinco variables son las siguientes:

time_t pam_misc_conv_warn_time;

Esta variable contiene el tiempo (tal como lo devuelve time(2)) en el que se debería advertir al usuario por primera vez que el tiempo se está acabando. Por defecto, tiene el valor 0, lo que indica que no se dará ninguna advertencia de este tipo. La aplicación puede establecer su valor en algún momento futuro, pero esto debe hacerse antes de pasar el control a la biblioteca Linux-PAM.

const char *pam_misc_conv_warn_line;

Utilizada junto con pam_misc_conv_warn_time, esta variable es un puntero a la cadena que se mostrará cuando llegue el momento de advertir al usuario que el tiempo de espera se acerca. Su valor predeterminado es una versión traducida de "......El tiempo se está acabando......", pero la aplicación puede cambiarlo antes de pasar el control a Linux-PAM.

time_t pam_misc_conv_die_time;

Esta variable contiene el tiempo (tal como lo devuelve time(2)) en el que se agotará el tiempo. Por defecto, tiene el valor 0, lo que indica que la función de conversación no se agotará. La aplicación puede establecer su valor en algún momento futuro, pero esto debe hacerse antes de pasar el control a la biblioteca Linux-PAM.

const char *pam_misc_conv_die_line;

Utilizada junto con pam_misc_conv_die_time, esta variable es un puntero a la cadena que se mostrará cuando la conversación se agote. Su valor predeterminado es una versión traducida de "......Lo siento, ¡tu tiempo se acabó!......", pero la aplicación puede cambiarlo antes de pasar el control a Linux-PAM.

int pam_misc_conv_died;

Después de un retorno de la biblioteca Linux-PAM, el valor de esta variable indica si la conversación se ha agotado. Un valor de 1 indica que ocurrió el agotamiento del tiempo.

Los dos punteros a función siguientes están disponibles para soportar indicaciones binarias en la función de conversación. Están optimizados para la encarnación actual de la biblioteca libpamc y están sujetos a cambios.

int (*pam_binary_handler_fn)(void *appdata, pamc_bp_t *prompt_p);

Este puntero a función se inicializa a NULL pero puede ser rellenado con una función que proporcione intercambio de mensajes máquina-máquina (ocultos). Está destinado a ser utilizado con protocolos de autenticación ocultos como RSA o intercambios de claves Diffie-Hellman. (Esto aún está en desarrollo).

int (*pam_binary_handler_free)(void *appdata, pamc_bp_t *delete_me);

Este puntero a función se inicializa a PAM_BP_RENEW(delete_me, 0, 0), pero puede ser redefinido según lo desee la aplicación.

VER TAMBIÉN

pam_conv(3), pam(8)

ESTÁNDARES

La función misc_conv es parte de la biblioteca libpam_misc y no está definida en ningún estándar.
