MINICOM(1) Versión 2.7 MINICOM(1)

NOMBRE

minicom - programa de comunicación serie amigable

SINOPSIS

minicom [opciones] [configuración]

DESCRIPCIÓN

minicom es un programa de comunicación que se parece un poco al programa shareware TELIX pero es gratuito con código fuente y se ejecuta en la mayoría de los sistemas Unix. Las características incluyen un directorio de marcado con redial automático, soporte para archivos de bloqueo de estilo UUCP en dispositivos serie, un intérprete de lenguaje de script separado, captura a archivo, usuarios múltiples con configuraciones individuales y más.

LÍNEA-DE-COMANDOS

-s, --setup
Setup. El superusuario edita los valores predeterminados del sistema en /etc/minirc.dfl con esta opción. Cuando se usa, minicom *no* inicializa, sino que te lleva directamente al menú de configuración. Esto es muy útil si minicom se niega a iniciarse debido a cambios en tu sistema, o si es la primera vez que ejecutas minicom. Para la mayoría de los sistemas, ya existen valores predeterminados razonables compilados.
-o, --noinit
No inicializar. Minicom omitirá el código de inicialización. Esta opción es útil si sales de minicom sin restablecer y luego quieres reiniciar una sesión. Sin embargo, es potencialmente peligrosa: no se realiza ninguna comprobación de archivos de bloqueo, etc., por lo que un usuario normal podría interferir con cosas como UUCP... quizás esto se elimine más adelante. Por ahora, se asume que los usuarios a los que se les da acceso a un módem son lo suficientemente responsables para sus acciones.
-m, --metakey
Anular la tecla de comando con la tecla Meta o ALT. Esta es la opción predeterminada en la versión 1.80 y también se puede configurar en uno de los menús de minicom, pero si utilizas terminales diferentes constantemente, algunos de los cuales no tienen tecla Meta o ALT, es útil establecer la tecla de comando predeterminada en Ctrl-A y usar esta opción cuando tengas un teclado que soporte teclas Meta o ALT. Minicom asume que tu tecla Meta envía el prefijo ESC, no la otra variante que establece el bit más alto del carácter.
-M, --metakey8
Igual que -m, pero asume que tu tecla Meta establece el bit 8 del carácter en alto (envía 128 + código del carácter).
-z, --statline
Usar la línea de estado del terminal. Esto solo funciona en terminales que lo soportan y que tienen la información relevante en su entrada de base de datos *termcap* o *terminfo*.
-l, --ansi
Traducción *literal* de caracteres con el bit alto establecido. Con esta opción activada, minicom intentará traducir los caracteres de línea de IBM a ASCII. Muchos clones de PC-Unix mostrarán los caracteres correctamente sin traducción (Linux en un modo especial, Coherent y SCO).
-L, --iso
Lo mismo, pero asume que la pantalla usa un conjunto de caracteres ISO8859.
-w, --wrap
Activa el ajuste de línea de forma predeterminada al inicio.
-H, --displayhex
Activa la salida en modo hexadecimal.
-a, --attrib=on/off
Uso de *A*tributos. Algunos terminales, notablemente los de Televideo, tienen un manejo de atributos deficiente (serie en lugar de paralelo). Por defecto, minicom usa '-a on', pero si estás usando un terminal de este tipo, puedes (¡debes!) proporcionar la opción '-a off'. Es necesario el 'on' o 'off' final.
-t, --term=TERM
Tipo de *T*erminal. Con esta bandera, puedes anular la variable de entorno TERM. Esto es útil para usar en la variable de entorno MINICOM; se puede crear una entrada termcap especial para usar con minicom en la consola, que inicializa la pantalla en modo raw para que, en conjunto con la bandera -l, los caracteres de línea de IBM se muestren sin traducir.
-c, --color=on/off
Uso de *C*olor. Los terminales (como la consola de Linux) soportan color con las secuencias de escape ANSI estándar. En caso de que no haya soporte para ello, el uso de color se puede deshabilitar con '-c off'. Estas, y la opción '-m', son buenos candidatos para poner en la variable de entorno MINICOM.
-S, --script=SCRIPT
*script*. Ejecuta el script nombrado al inicio. Hasta ahora, no se soporta el paso del nombre de usuario y la contraseña a un script de inicio. Si también usas la opción -d para empezar a marcar al inicio, el script -S se ejecutará ANTES de marcar las entradas especificadas con -d.
-d, --dial=ENTRY
*D*ial (marcar) una entrada del directorio de marcado al inicio. Puedes especificar un número de índice, pero también una subcadena del nombre de la entrada. Si especificas un nombre que tiene múltiples entradas en el directorio, todas ellas se marcan para marcar. También puedes especificar múltiples nombres o números de índice separándolos con comas. El marcado comenzará desde la primera entrada especificada después de que todos los demás procedimientos de inicialización del programa se hayan completado.
-p, --ptty=TTYP
Terminal *P*seudo a usar. Esto anula el puerto de terminal definido en los archivos de configuración, pero solo si es una TTY pseudo. El nombre de archivo proporcionado debe tener el formato (/dev/)tty[p-z/][0-f], (/dev/)pts[p-z/][0-f] o (/dev/)pty[p-z/][0-f]. Por ejemplo, /dev/ttyp1, pts/0 o /dev/ptyp2.
-C, --capturefile=FILE
Nombre de *archivo*. Abrir archivo de captura al inicio.
--capturefile-buffer-mode=MODE
Modo de búfer del archivo de captura. MODE puede ser uno de:
N Sin búfer (predeterminado).
L Búfer de línea.
F Búfer completo.
-F, --statlinefmt
Formato para la línea de estado. Los siguientes especificadores de formato están disponibles:
%H Tecla de escape para la pantalla de ayuda.
%V Cadena de versión de minicom.
%b Información sobre la conexión, como la velocidad en baudios.
%T Tipo de terminal.
%C Modo del cursor.
%D Ruta del dispositivo, posiblemente acortada al espacio disponible restante.
%t Tiempo en línea.
%% Carácter %.

Ejemplo: "%H para ayuda | %b | Minicom %V | %T | %C | %t"

-b, --baudrate
Especifica la velocidad en baudios, anulando el valor dado en el archivo de configuración.
-D, --device
Especifica el dispositivo, anulando el valor dado en el archivo de configuración.
-O, --option
Establecer una opción. El argumento puede ser una sola palabra, o un par clave=valor. Opciones reconocidas:

timestamp con valores simple, delta, persecond y extended. Si no se proporciona valor, se selecciona 'simple'.

-R, --remotecharset
Especifica el conjunto de caracteres que utiliza el sistema remoto y lo convierte al conjunto de caracteres del lado local. Un ejemplo podría ser 'latin1'.
-7, --7bit
Modo 7 bits para terminales que no son capaces de 8 bits. 8 bits es el predeterminado si el entorno está configurado para ello a través de LANG o LC_ALL, 7 bits en caso contrario.
-8, --8bit
Los caracteres de 8 bits pasan sin ninguna modificación. 'Continuous' significa que no se insertan secuencias de control de ubicación/atributo sin un cambio real de ubicación/atributo. Este modo sirve para mostrar caracteres multibyte de 8 bits, como el japonés. No es necesario en todos los idiomas con caracteres de 8 bits. (Por ejemplo, mostrar texto en finés no necesita esto).
-h, --help
Muestra la ayuda y sale.
-v, --version
Imprime la versión de minicom.

Si luego inicia sesión desde una terminal sin soporte de color, y ha configurado MINICOM en su archivo de inicio (.profile o equivalente), y no desea volver a configurar su variable de entorno, puede escribir 'minicom -c off' y ejecutar sin soporte de color para esa sesión.

configuración
El argumento de configuración es más interesante. Normalmente, minicom obtiene sus valores predeterminados de un archivo llamado "minirc.dfl". Si, sin embargo, proporciona un argumento a minicom, intentará obtener sus valores predeterminados de un archivo llamado "minirc.configuración". Por lo tanto, es posible crear múltiples archivos de configuración, para diferentes puertos, diferentes usuarios, etc. Lo más sensato es usar nombres de dispositivo, como tty1, tty64, sio2, etc. Si un usuario crea su propio archivo de configuración, aparecerá en su directorio de inicio como ".minirc.dfl" o ".minirc.configuración".

USO

Minicom está basado en ventanas. Para abrir una ventana con la función que desea, presione Control-A (de ahora en adelante, usaremos C-A para indicar Control-A), y luego la tecla de función (a-z o A-Z). Al presionar C-A primero y luego 'z', aparece una pantalla de ayuda con un resumen corto de todos los comandos. Esta tecla de escape puede ser modificada cuando minicom se configura (opción -s o C-A O), pero nos quedaremos con Control-A por ahora.

Para cada menú se pueden usar las siguientes teclas:

ARRIBA
flecha arriba o 'k'
ABAJO
flecha abajo o 'j'
IZQUIERDA
flecha izquierda o 'h'
DERECHA
flecha derecha o 'l'
ELEGIR
Enter
CANCELAR
ESCape.

La pantalla se divide en dos partes: las 24 líneas superiores son la pantalla del emulador de terminal. En esta ventana, se interpretan secuencias de escape ANSI o VT100. Si queda una línea en la parte inferior, se coloca una línea de estado allí. Si esto no es posible, la línea de estado se mostrará cada vez que presione C-A. En terminales que tienen una línea de estado especial, se utilizará si la información de termcap es completa Y se ha dado el indicador -k.

Los comandos posibles se enumeran a continuación, en orden alfabético.

C-A
Presionar C-A una segunda vez simplemente enviará un C-A al sistema remoto. Si ha cambiado su "carácter de escape" a algo diferente de C-A, esto funciona de manera análoga para ese carácter.
A
Activa/desactiva 'Añadir salto de línea'. Si está activado, se añade un salto de línea antes de cada retorno de carro mostrado en la pantalla.
B
Le proporciona un búfer de desplazamiento hacia atrás. Puede desplazarse hacia arriba con u, hacia abajo con d, una página hacia arriba con b, una página hacia abajo con f, y si los tiene, las teclas de flecha y página arriba/página abajo también pueden ser utilizadas. Puede buscar texto en el búfer con s (distingue mayúsculas de minúsculas) o S (no distingue mayúsculas de minúsculas). N encontrará la próxima ocurrencia de la cadena. c entrará en modo de cita. Aparecerá un cursor de texto y usted especificará la línea de inicio presionando la tecla Enter. Luego, el modo de desplazamiento hacia atrás finalizará y el contenido con el prefijo '>' se enviará.
C
Borra la pantalla.
D
Marca un número o va al directorio de marcación.
E
Activa o desactiva el eco local (si su versión de minicom lo soporta).
F
Se envía una señal de ruptura al módem.
G
Ejecuta script (Go). Ejecuta un script de inicio de sesión.
H
Cuelga.
I
Alterna el tipo de secuencia de escape que envían las teclas de cursor entre el modo normal y el modo de aplicaciones. (Ver también el comentario sobre la línea de estado a continuación).
J
Salta a un shell. Al regresar, se redibujará toda la pantalla.
K
Borra la pantalla, ejecuta kermit y redibuja la pantalla al regresar.
L
Activa o desactiva la captura de archivos. Si se activa, toda la salida enviada a la pantalla también se capturará en el archivo.
M
Envía la cadena de inicialización del módem. Si está en línea y la configuración de la línea DCD está activada, se le pedirá confirmación antes de inicializar el módem.
N
Alterna entre los modos de marca de tiempo a añadir a la salida. Están disponibles formatos de tiempo simples y extendidos para cada línea, un delta con respecto a la línea anterior, una visualización de tiempo cada segundo y sin marcas de tiempo (el valor predeterminado).
O
Configura minicom. Le lleva al menú de configuración.
P
Parámetros de comunicación. Le permite cambiar la velocidad en bps, la paridad y el número de bits.
Q
Sale de minicom sin reiniciar el módem. Si las macros cambiaron y no se guardaron, tendrá la oportunidad de hacerlo.
R
Recibe archivos. Elija entre varios protocolos (externos). Si tiene la ventana de selección de nombres de archivo y la indicación del directorio de descarga activadas, obtendrá una ventana de selección para elegir el directorio de descarga. De lo contrario, se utilizará el directorio de descarga definido en el menú Nombres de archivo y rutas.
S
Envía archivos. Elija el protocolo como lo hace con el comando de recepción. Si no tiene la ventana de selección de nombres de archivo activada (en el menú Protocolos de transferencia de archivos), simplemente tendrá que escribir el(los) nombre(s) de archivo en una ventana de diálogo. Si tiene la ventana de selección activada, aparecerá una ventana que muestra los nombres de archivo en su directorio de carga. Puede marcar y desmarcar archivos presionando la barra espaciadora, y mover el cursor hacia arriba o hacia abajo con las teclas del cursor o j/k. Los nombres de archivo seleccionados se muestran resaltados. Los nombres de directorio se muestran [entre corchetes] y puede moverse hacia arriba o hacia abajo en el árbol de directorios presionando la barra espaciadora dos veces. Finalmente, envíe los archivos presionando ENTER o salga presionando ESC.
T
Elige la emulación de terminal: Ansi(color) o vt100. También puede cambiar la tecla de retroceso aquí, activar o desactivar la línea de estado, y definir un retraso (en milisegundos) después de cada salto de línea si lo necesita.
U
Añade retorno de carro a cada línea recibida.
W
Activa o desactiva el ajuste de línea.
X
Sale de minicom, reinicia el módem. Si las macros cambiaron y no se guardaron, tendrá la oportunidad de hacerlo.
Y
Pega un archivo. Lee un archivo y envía su contenido como si se estuviera escribiendo.
Z
Abre la pantalla de ayuda.

DIRECTORIO DE MARCACIÓN

Al presionar C-A D, el programa lo lleva al directorio de marcación. Seleccione un comando presionando la letra en mayúscula o moviendo el cursor a la derecha/izquierda con las flechas o las teclas h/l y presionando Enter. Puede añadir, eliminar o editar entradas y moverlas hacia arriba o hacia abajo en la lista del directorio. Al elegir "marcar", se marcarán los números de teléfono de las entradas seleccionadas, o si nada está marcado, se marcará el número de la entrada resaltada. Mientras el módem está marcando, puede presionar escape para cancelar la marcación. Cualquier otra tecla cerrará la ventana de marcación, pero no cancelará la marcación en sí. Su directorio de marcación se guardará en el archivo ".dialdir" en su directorio de inicio. Puede desplazarse hacia arriba y hacia abajo con las flechas, pero también puede desplazarse por páginas completas presionando la tecla Página Arriba o Página Abajo. Si no las tiene, use Control-B (Atrás) y Control-F (Adelante). Puede usar la barra espaciadora para marcar un número de entradas y minicom rotará a través de esta lista si no se puede establecer una conexión. Se dibuja un símbolo '>' en el directorio antes de los nombres de las entradas marcadas.

El menú "editar" habla por sí mismo, pero lo discutiré brevemente aquí.

A - Nombre
El nombre para esta entrada
B - Número
y su número de teléfono.
C - Cadena de marcación #
Qué cadena de marcación específica desea usar para conectar. Hay tres cadenas de marcación diferentes (prefijos y sufijos) que se pueden configurar en el menú Módem y marcación.
D - Eco local
puede estar activado o desactivado para este sistema (si su versión de minicom lo soporta).
E - Script
El script que debe ejecutarse después de establecer una conexión exitosa (consulte el manual para runscript)
F - Nombre de usuario
El nombre de usuario que se pasa al programa runscript. Se pasa en la cadena de entorno "$LOGIN".
G - Contraseña
La contraseña se pasa como "$PASS".
H - Emulación de terminal
Utiliza emulación ANSI o VT100.
I - La tecla de retroceso envía
Qué código (Retroceso o Suprimir) envía la tecla de retroceso.
J - Ajuste de línea
Puede estar activado o desactivado.
K - Configuración de línea
Velocidad en bps, bits, paridad y número de bits de parada a utilizar para esta conexión. Puede elegir actual para la velocidad, de modo que utilice la velocidad que se esté utilizando en ese momento (útil si tiene múltiples módems).
L - Tabla de conversión
Puede especificar una tabla de conversión de caracteres que se cargará cada vez que responda esta entrada, antes de ejecutar el script de inicio de sesión. Si este campo está en blanco, la tabla de conversión permanece sin cambios.

El menú de edición también muestra la última fecha y hora en que llamó a esta entrada y el número total de llamadas realizadas, pero no le permite cambiarlos. Se actualizan automáticamente cuando se conecta.

El comando moVe le permite mover la entrada resaltada hacia arriba o hacia abajo en el directorio de marcación con las teclas de flecha arriba/abajo o las teclas k y j.

CONFIGURACIÓN

Al presionar C-A O te lanzarás al menú de configuración.

Nombres de archivo y rutas

Este menú define tus directorios predeterminados.
A - Directorio de descarga
a dónde van los archivos descargados.
B - Directorio de carga
desde dónde se leen los archivos cargados.
C - Directorio de scripts
Donde guardas tus scripts de inicio de sesión.
D - Programa de scripts
Qué programa usar como intérprete de scripts. Por defecto, el programa "runscript", pero si quieres usar algo más (por ejemplo, /bin/sh o "expect") es posible. La entrada estándar y la salida estándar se conectan al módem, el error estándar a la pantalla.
Si la ruta es relativa (es decir, no comienza con una barra) entonces es relativa a tu directorio principal, excepto para el intérprete de scripts.
E - Programa Kermit
Dónde encontrar el ejecutable para kermit y sus opciones. Algunas macros simples se pueden usar en la línea de comandos: '%l' se expande al nombre completo del archivo del dispositivo de salida, '%f' se expande al descriptor de archivo del puerto serie y '%b' se expande a la velocidad actual del puerto serie.
F - Opciones de registro
Opciones para configurar la escritura del archivo de registro.
A - Nombre del archivo
Aquí puedes introducir el nombre del archivo de registro. El archivo se escribirá en tu directorio principal y el valor predeterminado es "minicom.log". Si dejas el nombre en blanco, todo el registro se desactivará.
B - Registrar conexiones y desconexiones
Esta opción define si el archivo de registro se escribe o no cuando el extremo remoto responde a la llamada o se desconecta. O cuando tú mismo ejecutas el comando de desconexión o sales de minicom mientras estás en línea.
C - Registrar transferencias de archivos
¿Quieres entradas de registro de recepción y envío de archivos?
El comando 'log' en los scripts no se ve afectado por las opciones de registro B y C. Siempre se ejecuta si solo tienes definido el nombre del archivo de registro.

Protocolos de transferencia de archivos

Los protocolos definidos aquí aparecerán cuando se presione C-A s/r. "Nombre" al principio de la línea es el nombre que aparecerá en el menú. "Programa" es la ruta al protocolo. "Nombre" después define si el programa necesita un argumento, por ejemplo, un archivo a transmitir. U/D define si esta entrada debe aparecer en el menú de carga o descarga. Pantalla completa define si el programa debe ejecutarse en pantalla completa, o si minicom solo mostrará su salida de error en una ventana. Redirección E/S define si minicom debe adjuntar la entrada y salida estándar del programa al puerto del módem o no. "Multi" le dice a la ventana de selección de nombres de archivo si el protocolo puede enviar múltiples archivos con un solo comando o no. No tiene efecto en los protocolos de descarga, y también se ignora con los protocolos de carga si no utilizas la ventana de selección de nombres de archivo. Los antiguos sz y rz no son a pantalla completa y tienen Redirección E/S activada. Sin embargo, existen versiones basadas en curses de al menos rz que no quieren que se redirija su entrada y salida estándar y se ejecutan a pantalla completa. Todos los protocolos de transferencia de archivos se ejecutan con el UID del usuario y no con UID=root. '%l', '%f' y '%b' se pueden usar en la línea de comandos como con kermit. Dentro de este menú también puedes definir si quieres usar la ventana de selección de nombres de archivo cuando se te solicite archivos para cargar, y si quieres que se te pregunte por el directorio de descarga cada vez que se inicie la descarga automática. Si dejas deshabilitada la solicitud del directorio de descarga, se utilizará el directorio de descarga definido en el menú de archivos y directorios.

Configuración del puerto serie

A - Dispositivo serie
/dev/tty1 o /dev/ttyS1 para la mayoría de las personas. /dev/cua<n> sigue siendo posible en GNU/Linux, pero ya no se recomienda ya que estos dispositivos están obsoletos y muchos sistemas con kernel 2.2.x o más recientes no los tienen. Usa /dev/ttyS<n> en su lugar. También puedes tener /dev/modem como un enlace simbólico al dispositivo real.
Si tienes módems conectados a dos o más puertos serie, puedes especificarlos todos aquí en una lista separada por espacios, comas o punto y coma. Cuando Minicom se inicia, revisa la lista hasta que encuentra un módem disponible y lo usa. (Sin embargo, no puedes especificar diferentes cadenas de inicialización para ellos... al menos no todavía).
Para usar un socket UNIX para la comunicación, el nombre del dispositivo debe ir precedido de "unix#" seguido de la ruta completa y el nombre del archivo del socket. Minicom intentará entonces conectarse a este socket como un cliente. Mientras no pueda conectarse al socket, permanecerá 'desconectado'. Tan pronto como se establezca la conexión, minicom se pondrá 'en línea'. Si el servidor cierra el socket, minicom volverá a 'desconectado'.
B - Ubicación del archivo de bloqueo
En la mayoría de los sistemas, esto debería ser /usr/spool/uucp. Los sistemas GNU/Linux usan /var/lock. Si este directorio no existe, minicom no intentará usar archivos de bloqueo.
C - Programa de llamada entrante
Si tienes un uugetty o algo similar en tu puerto serie, puede ser que quieras ejecutar un programa para cambiar el módem o el puerto al modo de llamada entrante/saliente. Este es el programa para entrar en modo de llamada entrante.
D - Programa de llamada saliente
Y este para entrar en modo de llamada saliente.
E - Baudios/Paridad/Bits
Parámetros predeterminados al inicio.

Si una de las entradas está en blanco, no se utilizará. Por lo tanto, si no te preocupan los bloqueos y no tienes un getty ejecutándose en tu línea del módem, las entradas B - D deberían dejarse en blanco.

Módem y Marcación

Aquí se definen los parámetros de tu módem. No lo explicaré más porque los valores predeterminados son para módems Hayes genéricos y deberían funcionar siempre. Este archivo no es un tutorial de Hayes :-) Lo único que vale la pena notar es que los caracteres de control se pueden enviar precediéndolos con un '^', donde '^^' significa '^' mismo, y el carácter '\' también debe duplicarse como '\\', ya que la barra invertida se usa especialmente en las definiciones de macros. Algunas opciones, sin embargo, no tienen mucho que ver con el módem sino más con el comportamiento del propio minicom:
M - Tiempo de marcación
El número de segundos antes de que minicom agote el tiempo si no se establece ninguna conexión.
N - Retardo antes de volver a marcar
Minicom volverá a marcar si no se estableció ninguna conexión, pero primero espera un tiempo.
O - Número de intentos
Número máximo de veces que minicom intenta marcar.
P - Tiempo de caída de DTR
Si estableces esto a 0, minicom colgará enviando una secuencia de colgado tipo Hayes. Si especificas un valor distinto de cero, el colgado se hará soltando la línea DTR. El valor indica en segundos cuánto tiempo se mantendrá DTR abajo.
Q - Detección automática de baudios
Si esto está activado, minicom intenta igualar la velocidad de la parte marcada. Con la mayoría de los módems modernos, esto NO es deseable, ya que el módem almacena en búfer los datos y convierte la velocidad.
R - El módem tiene línea DCD
Si tu módem y tu sistema operativo admiten la línea DCD (que se activa cuando se establece una conexión), minicom la utilizará. Cuando tengas esta opción activada, minicom TAMPOCO comenzará a marcar mientras ya estés en línea.
S - La línea de estado muestra velocidad DTE / velocidad de línea
Puedes alternar la línea de estado para que muestre la velocidad DTE (la velocidad que minicom usa para comunicarse con tu módem) o la velocidad de línea (la velocidad que tu módem usa en la línea para comunicarse con el otro módem). Ten en cuenta que la velocidad de línea puede cambiar durante la conexión, pero solo verás la velocidad inicial con la que los módems comenzaron la conexión. Esto se debe a que el módem no le dice al programa si la velocidad ha cambiado. Además, para ver la velocidad de línea, necesitas tener el módem configurado para mostrarla en la cadena de conexión. De lo contrario, solo verás 0 como velocidad de línea.
T - Desmarcar multi-línea
Puedes activar la función para desmarcar entradas del directorio de marcación cuando se establece una conexión a un BBS multi-línea. Todas las entradas marcadas con el mismo nombre se desmarcan.
Ten en cuenta que se hace una excepción especial para este menú: cada usuario puede cambiar todos los parámetros aquí, pero algunos de ellos no se guardarán.

Pantalla y teclado

A - La tecla de comando es
la 'Tecla de Acceso' que te lleva al modo de comando. Si está configurada como 'ALT' o 'tecla meta', puedes llamar directamente a los comandos con alt-tecla en lugar de TeclaAcceso-tecla.
B - La tecla de retroceso envía
Todavía hay algunos sistemas que quieren que un VT100 envíe DEL en lugar de BS. Con esta opción puedes habilitar esa estupidez. (Eh, ¡incluso está activada por defecto!)
C - La línea de estado está
Habilitada o deshabilitada. Algunos terminales lentos (por ejemplo, terminales X) hacen que la línea de estado salte "arriba y abajo" al desplazarse, por lo que puedes desactivarla si lo deseas. Todavía se mostrará en modo de comando.
D - Sonido de alarma
Si está activado, minicom emitirá un sonido de alarma (solo en la consola) después de una conexión exitosa y cuando la carga/descarga se haya completado.
E - Color de primer plano (menú)
indica el color de primer plano a utilizar para todas las ventanas de configuración en minicom.
F - Color de fondo (menú)
indica el color de fondo a utilizar para todas las ventanas de configuración en minicom. Ten en cuenta que minicom no te permitirá establecer los colores de primer plano y fondo al mismo valor.
G - Color de primer plano (terminal)
indica el color de primer plano a utilizar en la ventana del terminal.
H - Color de fondo (terminal)
indica el color de fondo a utilizar en la ventana del terminal. Ten en cuenta que minicom no te permitirá establecer los colores de primer plano y fondo al mismo valor.
I - Color de primer plano (estado)
indica el color de primer plano a utilizar en la barra de estado.
J - Color de fondo (estado)
indica el color a utilizar en la barra de estado. Ten en cuenta que minicom te permitirá establecer los colores de primer plano y fondo de la barra de estado al mismo valor. Esto hará que la barra de estado sea invisible, pero si estas son tus intenciones, consulta la opción
K - Tamaño del búfer de historial
El número de líneas a mantener en el búfer de historial (para desplazamiento hacia atrás).
L - Archivo de macros
es la ruta completa al archivo que contiene las macros. Las macros te permiten definir una cadena que se enviará cuando presiones una tecla determinada. En minicom, puedes definir F1 a F12 para enviar hasta 256 caracteres [esto se establece en tiempo de compilación]. El nombre del archivo que especifiques se verifica tan pronto como presiones ENTER. Si no tienes permisos para crear el archivo especificado, aparecerá un mensaje de error y se te obligará a volver a editar el nombre del archivo. Si tienes permiso para crear el archivo, minicom
revisa si ya existe. Si es así, asume que es un archivo de macros y lo lee. Si no lo es, bueno, es tu problema :-) Si el archivo no existe, el nombre de archivo es aceptado.
M - Editar Macros
abre una nueva ventana que te permite editar las macros F1 a F12.
N - Macros habilitadas
- Sí o No. Si las macros están deshabilitadas, las teclas F1-F12 solo enviarán las secuencias de escape de las teclas de función VT100/VT220.
O - Conversión de caracteres
Aquí se muestra el nombre del archivo de la tabla de conversión activa. Si no ves ningún nombre, no hay ninguna conversión activa. Al presionar O, verás el menú de edición de la tabla de conversión.
Editar Macros
Aquí se definen las macros para F1 a F12. En la parte inferior de la ventana se muestra una leyenda de combinaciones de caracteres que tienen un significado especial. Permiten ingresar caracteres de control especiales con texto plano anteponiéndoles un '^', donde '^^' significa '^' en sí. Puedes enviar un retardo de 1 segundo con el código '^~'. Esto es útil cuando intentas iniciar sesión después de ftp o telnet a algún lugar. También puedes incluir tu nombre de usuario y contraseña actuales del directorio telefónico en las macros con '\u' y '\p', respectivamente. Si necesitas el carácter de barra invertida en la macro, escríbelo duplicado como '\\'. Para editar una macro, presiona el número o letra mostrado y te moverás al final de la macro. Al editar la línea, puedes usar las teclas de flecha izquierda y derecha, Inicio y Fin, Suprimir y Retroceso, y ESC y RETORNO. ESC cancela cualquier cambio realizado mientras que ENTER acepta los cambios.
Conversión de caracteres
Aquí puedes editar la tabla de conversión de caracteres. Si no eres estadounidense, sabes que en muchos idiomas hay caracteres que no están incluidos en el conjunto de caracteres ASCII, y en los viejos tiempos pueden haber reemplazado algunos caracteres menos importantes en ASCII y ahora a menudo se representan con códigos de caracteres superiores a 127. Y hay varias formas diferentes de representarlos. Aquí es donde puedes editar tablas de conversión para sistemas que utilizan un conjunto de caracteres diferente al de tu computadora.
A - Cargar tabla
Probablemente lo adivinaste. Este comando carga una tabla desde el disco. Se te pide un nombre de archivo para la tabla. Las tablas predefinidas .mciso, .mcpc8 y .mcsf7 deberían incluirse con el programa. La tabla .mciso no realiza ninguna conversión, .mcpc8 se utilizará para conexiones con sistemas que usan el conjunto de caracteres de PC de 8 bits, y .mcsf7 es para compatibilidad con sistemas que usan la buena codificación de 7 bits para reemplazar los caracteres {|}[]\ con los caracteres diacríticos utilizados en finés y sueco.
B - Guardar tabla
Este guarda la tabla activa en el nombre de archivo que especifiques.
C - editar carácter
Aquí puedes hacer tus propias modificaciones a la tabla existente. Primero se te pide el valor del carácter (en decimal) cuya conversión deseas cambiar. Luego, dirás qué carácter quieres que aparezca en tu pantalla cuando ese carácter provenga del mundo exterior. Y luego se te preguntará qué quieres que se envíe cuando ingreses ese carácter desde tu teclado.
D - siguiente pantalla
E - pantalla anterior
Sí, probablemente notaste que esta pantalla te muestra qué tipo de conversiones están activas. La pantalla simplemente es (generalmente) demasiado pequeña para mostrar la tabla completa a la vez en un formato fácil de entender. Así es como puedes desplazarte por la tabla hacia la izquierda y hacia la derecha.
F - convertir captura
Alterna si la tabla de conversión de caracteres se utiliza o no al escribir el archivo de captura.
Guardar configuración como dfl
Guarda los parámetros como los predeterminados para la próxima vez que se inicie el programa. En lugar de dfl, puede aparecer cualquier otro nombre de parámetro, dependiendo de cuál se usó al iniciar el programa.
Guardar configuración como..
Guarda los parámetros con un nombre especial. Siempre que Minicom se inicie con este nombre como argumento, usará estos parámetros. Esta opción está, por supuesto, reservada para root.
Salir
Salir de este menú sin guardar. Esto también se puede hacer con ESC.
Salir de minicom
Solo root verá esta entrada de menú, si inició minicom con la opción '-s'. De esta manera, es posible cambiar la configuración sin ejecutar realmente minicom.

LÍNEA DE ESTADO

La línea de estado tiene varios indicadores, que hablan por sí mismos. El misterioso indicador APP o NOR probablemente necesite explicación. Las teclas de cursor de VT100 pueden estar en dos modos: modo de aplicaciones y modo de cursor. Esto se controla mediante una secuencia de escape. Si descubres que las teclas del cursor no funcionan en, por ejemplo, vi cuando has iniciado sesión usando minicom, entonces puedes ver con este indicador si las teclas del cursor están en modo de aplicaciones o de cursor. Puedes alternar los dos con la combinación de teclas C-A I. Si las teclas del cursor funcionan entonces, probablemente sea un error en las cadenas de inicialización de termcap del sistema remoto (es).

LOCALIZACIONES

Minicom tiene soporte para idiomas locales. Esto significa que puedes cambiar la mayoría de los mensajes en inglés y otras cadenas a otro idioma estableciendo la variable de entorno LANG.

VARIOS

Si minicom se cuelga, mátalo con SIGTERM . (Esto significa kill -15, o ya que sigterm es el predeterminado, simplemente "kill ". Esto provocará una salida limpia de minicom, realizando restablecimientos y todo lo demás. Puedes matar minicom desde un script con el comando "! killall -9 minicom" sin colgar la línea. Sin el parámetro -9, minicom primero cuelga antes de salir.

Dado que muchas secuencias de escape comienzan con ESC (la flecha arriba es ESC [ A), Minicom no sabe si el carácter de escape que recibe es que presionaste la tecla de escape, o parte de una secuencia.

Una versión antigua de Minicom, V1.2, lo resolvió de una manera bastante burda: para obtener la tecla de escape, tenías que presionarla *dos veces*.

A partir de la versión 1.3, esto ha mejorado un poco: ahora hay un tiempo de espera de 1 segundo incorporado, como en vi. Para sistemas que tienen la llamada al sistema select() el tiempo de espera es de 0.5 segundos. Y... sorpresa: se agregó un *hack* especial dependiente de Linux :-). Ahora, minicom puede separar la tecla de escape y las secuencias de escape. Para ver lo sucio que se hizo esto, mira wkeys.c. ¡Pero funciona a la perfección!

ARCHIVOS

Minicom mantiene sus archivos de configuración en un directorio, generalmente /var/lib/minicom, /usr/local/etc o /etc. Para averiguar qué directorio predeterminado tiene compilado minicom, ejecuta el comando minicom -h. Probablemente también encontrarás los archivos de demostración para runscript(1), y los ejemplos de tablas de conversión de caracteres allí o en los subdirectorios de /usr/doc/minicom*. Las tablas de conversión se llaman algo como mc.* en ese directorio, pero probablemente querrás copiar las que necesites en tu directorio de inicio como algo que comience con un punto.

minirc.*
$HOME/.minirc.*
$HOME/.dialdir
$HOME/minicom.log
/usr/share/locale/*/LC_MESSAGES/minicom.mo

NOMBRE

minicom - un programa de emulación de terminal de propósito general

SINOPSIS

minicom [-a] [-b ] [-c ] [-d ] [-e ] [-f ] [-h] [-k] [-l ] [-m] [-p ] [-s] [-t ] [-v] [-w] [-x] [-Z ] [-C ] [--no-ansi] [--ansi] [--color=] [--disable-telnet-send-naws] [--enable-telnet-send-naws] [--force-ansi] [--help] [--iso-6429] [--no-escape] [--no-term-status] [--quiet] [--show-config] [--version]

DESCRIPCIÓN

minicom es un programa de emulación de terminal de propósito general fácil de usar. Está diseñado para ser fácil de usar para principiantes y, sin embargo, tiene suficientes características para satisfacer las necesidades de los usuarios avanzados.

minicom soporta la emulación de terminales como VT102/VT220 y TN3270. También soporta la transmisión de archivos usando protocolos como kermit, xmodem, ymodem, zmodem y lrzsz.

La configuración de minicom se almacena en archivos de configuración, que se pueden encontrar en /etc/minicom/ o en el directorio ~/.minicom/.

OPCIONES

A continuación se enumeran algunas de las opciones comunes de minicom:

  • -a: No usar control de hardware de flujo.
  • -b : Establece la velocidad de transmisión por defecto.
  • -c : Especifica la ruta del archivo de script.
  • -d : Usa el archivo dialer especificado.
  • -e : Especifica la ruta del archivo de configuración del script.
  • -f : Especifica la ruta del archivo de configuración del terminal.
  • -h: Muestra la ayuda.
  • -k: No envía el código de escape de la secuencia de interrupción.
  • -l : Especifica la ruta del archivo de registro.
  • -m: No usar el control de software de flujo.
  • -p : Especifica el puerto serie a usar.
  • -s: Permite la transferencia de archivos.
  • -t : Especifica el tipo de emulación de terminal.
  • -v: Muestra la versión.
  • -w: No envuelve la línea de salida.
  • -x: Muestra la salida de depuración.
  • -Z : Especifica la tabla de caracteres a usar.
  • -C : Especifica el archivo de configuración del directorio.
  • --no-ansi: Deshabilita el procesamiento de secuencias de escape ANSI.
  • --ansi: Habilita el procesamiento de secuencias de escape ANSI.
  • --color=: Establece los parámetros de color.
  • --disable-telnet-send-naws: Deshabilita el envío de TNAS por Telnet.
  • --enable-telnet-send-naws: Habilita el envío de TNAS por Telnet.
  • --force-ansi: Fuerza el procesamiento de secuencias de escape ANSI.
  • --help: Muestra el mensaje de ayuda y sale.
  • --iso-6429: Habilita el procesamiento de secuencias de escape ISO 6429.
  • --no-escape: No procesa secuencias de escape.
  • --no-term-status: No muestra la línea de estado del terminal.
  • --quiet: Suprime la mayoría de los mensajes.
  • --show-config: Muestra la configuración y sale.
  • --version: Muestra información de versión y sale.

COMBINACIONES DE TECLAS

minicom utiliza una serie de combinaciones de teclas para controlar sus funciones. La combinación de teclas principal es Ctrl+A. A continuación se muestran algunas combinaciones de teclas comunes:

  • Ctrl+A, Z: Muestra el menú de ayuda.
  • Ctrl+A, O: Muestra el menú de configuración.
  • Ctrl+A, X: Sale de minicom.
  • Ctrl+A, S: Inicia la transferencia de archivos.
  • Ctrl+A, R: Recibe un archivo.
  • Ctrl+A, P: Muestra la línea de estado.

CONFIGURACIÓN

minicom se configura mediante archivos de configuración. Los archivos de configuración predeterminados se encuentran en /etc/minicom/. Los usuarios pueden crear su propia configuración en el directorio ~/.minicom/.

Los archivos de configuración más importantes son:

  • minirc.dfl: Archivo de configuración predeterminado.
  • minirc.: Archivo de configuración específico para un perfil.

Estos archivos contienen directivas para configurar la velocidad del puerto serie, la emulación del terminal, los scripts, etc.

LÍNEA DE ESTADO

La línea de estado de minicom muestra información sobre el estado de la conexión, como la velocidad del puerto serie, el nombre del puerto y el estado de la transferencia de archivos. Se puede activar y desactivar con la combinación de teclas Ctrl+A, P.

LOCALES

minicom soporta diferentes configuraciones regionales para mostrar menús y mensajes en varios idiomas. El idioma se puede seleccionar configurando la variable de entorno LC_ALL o LANG.

MISCELÁNEO

minicom se puede usar para conectarse a sistemas remotos a través de módems o conexiones serie directas. También se puede usar para transferir archivos entre sistemas.

ARCHIVOS

  • /etc/minicom/minirc.dfl: Archivo de configuración predeterminado.
  • /etc/minicom/minirc.*: Otros archivos de configuración.
  • ~/.minicom/minirc.dfl: Archivo de configuración del usuario.
  • ~/.minicom/minirc.*: Otros archivos de configuración del usuario.
