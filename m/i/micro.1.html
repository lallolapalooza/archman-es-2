micro(1) Manual de comandos generales micro(1)

NOMBRE

micro - Un editor de texto moderno e intuitivo basado en terminal

SINOPSIS

micro [OPCIONES] [ARCHIVO]...

DESCRIPCIÓN

Micro es un editor de texto basado en terminal que tiene como objetivo ser fácil de usar e intuitivo, al mismo tiempo que aprovecha todas las capacidades de las terminales modernas. Viene como un único binario estático, incluido todo, sin dependencias.

Como su nombre indica, micro pretende ser algo así como un sucesor del editor nano al ser fácil de instalar y usar en un apuro, pero micro también pretende ser agradable de usar a tiempo completo, ya sea que trabajes en la terminal porque lo prefieres (como yo), o porque necesitas hacerlo (por ssh).

Usa Ctrl-q para salir, Ctrl-s para guardar y Ctrl-g para abrir el menú de ayuda dentro del editor.

OPCIONES

-clean

Limpia el directorio de configuración

-config-dir dir

Especifica una ubicación personalizada para el directorio de configuración

[ARCHIVO]:LÍNEA:COL

Especifica una línea y columna donde iniciar el cursor al abrir un búfer

-options

Muestra toda la ayuda de opciones

-debug

Habilita el modo de depuración (habilita el registro en ./log.txt)

-version

Muestra el número de versión e información

Los complementos de Micro se pueden administrar desde la línea de comandos con los siguientes comandos.

-plugin remove [PLUGIN]...

Elimina el/los complemento(s)

-plugin update [PLUGIN]...

Actualiza el/los complemento(s) (si no se proporciona ningún argumento, actualiza todos los complementos)

-plugin search [PLUGIN]...

Busca un complemento

-plugin list

Lista los complementos instalados

-plugin available

Lista los complementos disponibles

Las opciones de Micro también se pueden establecer a través de argumentos de línea de comandos para ajustes rápidos. Para una configuración real, por favor usa el archivo settings.json (ver 'help options').

-option valor

Establece `opción` a `valor` para esta sesión. Por ejemplo: `micro -syntax off file.c`

CONFIGURACIÓN

Micro usa $MICRO_CONFIG_HOME como directorio de configuración. Si esta variable de entorno no está establecida, usa $XDG_CONFIG_HOME/micro en su lugar. Si esa variable de entorno no está establecida, usa ~/.config/micro como directorio de configuración. En la documentación, usamos ~/.config/micro para referirnos al directorio de configuración (incluso si de hecho puede estar en otro lugar si has establecido alguna de las variables de entorno anteriores).

AVISO

Este manual solo pretende servir como una guía rápida para la invocación de micro y no pretende reemplazar la documentación completa incluida con micro, a la que se puede acceder desde dentro de micro. Micro te dice qué combinación de teclas presionar para obtener ayuda en la parte inferior derecha.

ERRORES

No se enumerará una lista exhaustiva de errores en esta página del manual. Consulta la página de Github en https://github.com/zyedidia/micro/issues para obtener una lista de errores conocidos y para informar sobre cualquier error nuevo que encuentres. Nos esforzamos por corregir los errores lo más rápido posible.
