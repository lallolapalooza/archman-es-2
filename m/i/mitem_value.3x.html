mitem_value(3X) Llamadas de biblioteca mitem_value(3X)

NOMBRE

set_item_value, item_value - establecer y obtener valores de elementos de menú

SINOPSIS

#include <menu.h>
int set_item_value(ITEM *item, bool value);
bool item_value(const ITEM *item);

DESCRIPCIÓN

Si desactiva la opción de menú O_ONEVALUE (por ejemplo, con set_menu_opts o menu_opts_off; véase menu_opts(3X)), el menú se vuelve multivaluado; es decir, más de un elemento puede ser seleccionado simultáneamente.

En un menú multivaluado, puede usar set_item_value para seleccionar el elemento de menú dado (segundo argumento TRUE) o deseleccionarlo (segundo argumento FALSE).

VALOR DE RETORNO

La función set_item_value devuelve uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).
E_REQUEST_DENIED
El controlador del menú no pudo procesar la solicitud.

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran compatibles con las versiones 7 o BSD.

AUTORES

Juergen Pfeifer. Páginas de manual y adaptación para new curses de Eric S. Raymond.
