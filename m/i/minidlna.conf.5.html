minidlna.conf(5) Manual de Formatos de Archivo minidlna.conf(5)

NOMBRE

minidlna

DESCRIPCIÓN

minidlna es un servidor DLNA ligero pero muy funcional. En la mayoría de los casos, los valores predeterminados no necesitan modificaciones. El archivo de configuración global es /etc/minidlna.conf, pero los usuarios locales sin acceso root al sistema pueden ejecutar minidlna con su propio archivo de configuración.

OPCIONES

Las siguientes son opciones configurables por el usuario en /etc/minidlna.conf. minidlna se ejecuta por defecto como el usuario nobody, así que asegúrese de que los permisos del sistema estén configurados correctamente para el acceso de lectura a los medios y el acceso de escritura a los directorios de caché y registro.

friendly_name
El nombre con el que desea que se vea su servidor multimedia, por ejemplo: friendly_name=Servidor Multimedia Casero
port
Puerto para el tráfico HTTP (descripciones, SOAP, transferencia de medios), etc., el valor predeterminado es 8200.
No debería ser necesario cambiar esto.
network_interface
Interfaces de red para servir, separadas por comas. El máximo es 8 interfaces. El valor predeterminado es todas.
strict_dlna
Establezca esto para cumplir estrictamente con los estándares DLNA.
Esto permitirá la reducción de escala en el lado del servidor de imágenes
JPEG muy grandes, lo que puede afectar el rendimiento de la entrega de JPEG
en (al menos) productos Sony DLNA.
notify_interval
Intervalo de notificación en segundos. El valor predeterminado es 895 segundos.
minissdpdsocket
Especifique la ruta al socket de MiniSSDPd,
por ejemplo: minissdpdsocket=/var/run/minissdpd.sock
serial
Número de serie que el demonio informará a los clientes en su descripción XML.
El valor predeterminado es 12345678
model
Número de modelo que el demonio informará a los clientes en su descripción XML.
El valor predeterminado es 1
media_dir
Ruta al directorio que contiene los archivos multimedia que minidlna debe
compartir. Utilice esta opción varias veces si tiene más de un
directorio para compartir.
Ejemplo:
 media_dir=/opt/multimedia/videos
 media_dir=/opt/multimedia/movies

También puede restringir una entrada a un tipo de medio específico, lo hace utilizando la siguiente sintaxis:

   la letra 'A', 'V' o 'P', seguida de una coma (','), seguida de la ruta.
   El significado de la primera letra es el siguiente:
                      'A' para archivos de audio
                      'V' para archivos de video
                      'P' para archivos de imagen
    Por ejemplo, si desea incluir solo archivos de video ubicados
    en el directorio /opt/multimedia/videos, y solo música
    en /opt/multimedia/music, entonces usaría
                       media_dir=V,/opt/multimedia/videos
                       media_dir=A,/opt/multimedia/music
    Otro ejemplo sería
                       media_dir=V,/opt/multimedia/videos
                       media_dir=V,/opt/multimedia/movies
                       media_dir=A,/opt/multimedia/music
    O, si no le importa el tipo que encuentre, entonces podría usar
                       media_dir=/opt/multimedia/videos
                       media_dir=/opt/multimedia/movies
                       media_dir=/opt/multimedia/music
    Puede mezclar, encontrar cualquier cosa en música, pero solo Videos, en
    videos y películas
                       media_dir=V,/opt/multimedia/videos
                       media_dir=V,/opt/multimedia/movies
                       media_dir=/opt/multimedia/music
presentation_url
La URL de presentación predeterminada es la dirección HTTP en el puerto 80
por ejemplo: presentation_url=http://www.mediaserver.lan/index.php
db_dir
Donde minidlna almacena los archivos de datos, incluidos los archivos de caché de álbumes, por defecto es /var/cache/minidlna
log_dir
Ruta al directorio donde se debe almacenar el archivo de registro upnp-av.log, el valor predeterminado es /var/log
log_level
Establezca esto para cambiar la verbosidad de la información que se registra. Cada sección puede usar un nivel diferente: off, fatal, error, warn, info o debug 
Ejemplo
log_level=general,artwork,database,inotify,scanner,metadata,http,ssdp,tivo=warn
inotify
Establezca en 'yes' para habilitar el monitoreo inotify de los archivos debajo de media_dir para descubrir automáticamente nuevos archivos. Establezca en 'no' para deshabilitar inotify.
album_art_names
Debería ser una lista de nombres de archivo para buscar arte y nombres de álbum, delimitados por una barra diagonal ("/"). 
Ejemplo
album_art_names=Cover.jpg/cover.jpg/AlbumArtSmall.jpg/albumartsmall.jpg/AlbumArt.jpg
/albumart.jpg/Album.jpg/album.jpg/Folder.jpg/folder.jpg/Thumb.jpg/thumb.jpg
enable_tivo
Establezca esto en yes para habilitar el soporte para transmitir archivos .jpg y .mp3 a un TiVo compatible con HMO, el valor predeterminado es no.
tivo_discovery
Establezca en 'beacon' para usar el método de descubrimiento de broadcast heredado de TiVo. El valor predeterminado es usar Bonjour si el soporte de Avahi está disponible.
root_container
Utilice un contenedor diferente como raíz del árbol expuesto a los clientes. 
Los valores posibles son:
             '.' para usar el contenedor estándar (este es el valor predeterminado)
             'B' para usar el contenedor "Browse Directory" (Explorar Directorio);
             'M' para usar el contenedor "Music" (Música);
             'V' para usar el contenedor "Video" (Video);
             'P' para usar el contenedor "Pictures" (Imágenes).
  Si especifica 'B' y el dispositivo cliente solo es de audio, entonces
  "Music/Folders" se usará como contenedor raíz y no verá Videos.
force_sort_criteria
Fuerza siempre SortCriteria a este valor, independientemente de SortCriteria pasado por el cliente. 
Puede anteponer el criterio de ordenación con "!" para alterar los títulos de los objetos de modo que
se ordenen alfanuméricamente en el orden que especifique aquí, para solucionar problemas con clientes que
realizan su propia ordenación alfanumérica.
Ejemplo
force_sort_criteria=+upnp:class,+upnp:originalTrackNumber,+dc:title
wide_links
Establezca en 'yes' para permitir enlaces simbólicos que apuntan fuera de los media_dirs definidos por el usuario. Por defecto, los enlaces simbólicos amplios no se siguen.
enable_subtitles
Establezca en 'no' para deshabilitar el soporte de subtítulos en clientes desconocidos. Por defecto, los subtítulos están habilitados para clientes desconocidos o genéricos.
