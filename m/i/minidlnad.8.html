NOMBRE

minidlnad - Servidor MiniDLNA DLNA/UPnP-AV

SINOPSIS

minidlnad opciones

DESCRIPCIÓN

minidlna es un servidor DLNA/UPnP-AV ligero pero muy funcional que permite compartir fácilmente tus archivos multimedia, incluidas imágenes, con cualquier dispositivo o cliente capaz en tu red local cableada e inalámbrica. El software común para PC como totem es una buena opción ligera y rápida para Linux/BSD; un software más completo para Linux, Windows y MAC es XBMC, también Mediahouse en Android, y cualquier DVR/TV compatible con el intercambio de medios, etc.

OPCIONES

Las opciones de minidlna se configuran normalmente desde el archivo global /etc/minidlna.conf.

Pero puede haber momentos en los que necesites alterar temporalmente algunas de estas
opciones, puedes hacerlo ejecutando minidlna con los siguientes modificadores de línea
de comandos.
-R Rescanear
Esto fuerza a minidlna a volver a escanear todos los directorios media_dir.
-f archivo_configuracion
Ejecuta minidlna con un archivo de configuración diferente al predeterminado global.
-p puerto
Permite ejecutar minidlna en un puerto diferente.
-w url_presentacion
Cambia la dirección URL de presentación predeterminada.
-d depuracion
minidlna se ejecutará en primer plano con salida de depuración.
-P archivo_pid
Especifica una ubicación para el archivo PID.
-m modelo
Fuerza a minidlna a reportar un número de modelo específico.
-s serial
Fuerza a minidlna a reportar un número de serie específico.
-t intervalo_notificacion
Cambia el intervalo de notificación, en segundos. Predeterminado: 895 segundos.
-h ayuda
Muestra las opciones básicas de modificadores para ejecutar minidlna.
-V Version
Muestra el número de versión del programa y sale.
