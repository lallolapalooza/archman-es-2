mitem_opts(3X) Llamadas a biblioteca mitem_opts(3X)

NOMBRE

set_item_opts, item_opts_on, item_opts_off, item_opts - establecer y obtener opciones de elementos del menú

SINOPSIS

#include <menu.h>
int set_item_opts(ITEM *item, Item_Options opts);
Item_Options item_opts(const ITEM *item);
int item_opts_on(ITEM *item, Item_Options opts);
int item_opts_off(ITEM *item, Item_Options opts);

DESCRIPCIÓN

La función set_item_opts establece todos los bits de opción del elemento dado (los bits de opción del menú pueden combinarse lógicamente con OR).

La función item_opts_on activa los bits de opción dados y deja los demás sin cambios.

La función item_opts_off desactiva los bits de opción dados y deja los demás sin cambios.

La función item_opts devuelve los bits de opción actuales del elemento.

Solo hay una máscara de bits de opción definida, O_SELECTABLE. Cuando esta está activada, el elemento puede ser seleccionado durante el procesamiento del menú. Esta opción está activada por defecto.

VALOR DE RETORNO

Excepto para item_opts, cada rutina devuelve uno de los siguientes:

E_OK
La rutina tuvo éxito.
E_SYSTEM_ERROR
Ocurrió un error del sistema (ver errno(3)).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran soportadas en las versiones Version 7 o BSD.

AUTORES
