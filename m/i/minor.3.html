makedev(3) Manual de funciones de biblioteca makedev(3)

NOMBRE

makedev, major, minor - gestionar un número de dispositivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/sysmacros.h>
dev_t makedev(unsigned int maj, unsigned int min);
unsigned int major(dev_t dev);
unsigned int minor(dev_t dev);

DESCRIPCIÓN

Un ID de dispositivo consta de dos partes: un ID mayor, que identifica la clase del dispositivo, y un ID menor, que identifica una instancia específica de un dispositivo en esa clase. Un ID de dispositivo se representa mediante el tipo dev_t.

Dados los ID de dispositivo mayor y menor, makedev() los combina para producir un ID de dispositivo, devuelto como resultado de la función. Este ID de dispositivo puede pasarse a mknod(2), por ejemplo.

Las funciones major() y minor() realizan la tarea inversa: dado un ID de dispositivo, devuelven, respectivamente, los componentes mayor y menor. Estas macros pueden ser útiles para, por ejemplo, descomponer los ID de dispositivo en la estructura devuelta por stat(2).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
makedev (), major (), minor () Seguridad de hilos MT-Safe

VERSIÓNES

Los BSD exponen las definiciones de estas macros a través de <sys/types.h>.

ESTÁNDARES

Ninguno.

HISTORIA

BSD, HP-UX, Solaris, AIX, Irix.

Estas interfaces se definen como macros. Desde glibc 2.3.3, han sido alias de tres funciones específicas de GNU: gnu_dev_makedev(), gnu_dev_major() y gnu_dev_minor(). Estos últimos nombres se exportan, pero los nombres tradicionales son más portátiles.

Dependiendo de la versión, glibc también expone definiciones para estas macros desde <sys/types.h> si se definen macros de prueba de características adecuadas. Sin embargo, este comportamiento fue obsoleto en glibc 2.25, y desde glibc 2.28, <sys/types.h> ya no proporciona estas definiciones.

VER TAMBIÉN

mknod(2), stat(2)
