minieap(1) Manual de comandos generales minieap(1)

NOMBRE

minieap - Cliente 802.1x extensible con soporte para Ruijie v3/v4

SINOPSIS

minieap [OPCIONES...]

DESCRIPCIÓN

minieap se puede utilizar como suplicante para métodos de autenticación 802.1x modificados como Ruijie.

OPCIONES

--help, -h
mostrar información de ayuda
--kill, -k [0|...]
mata otras instancias y sale. argumentos distintos de 0 significan matar otras instancias y seguir ejecutando.
--save, -w
guardar configuración actual
--username, -u <nombre de usuario>
nombre de usuario
--password, -p <nombre de usuario>
contraseña
--nic, -n <interfaz>
interfaz de red
--stage-timeout, -t <segundos>
tiempo de espera para cada autenticación [predeterminado es 5]
--wait-after-fail, -r <segundos>
tiempo de espera después de un fallo (pero comenzará inmediatamente si el servidor lo solicita) [predeterminado es 30]
--max-fail, -l <número>
número máximo de fallos [predeterminado es 3]
--no-auto-reauth, -x
no intentar de nuevo después de desconectado [predeterminado es sí]
--daemonize, -b <0-3>
0 = ejecutar en primer plano
1 = ejecutar como demonio, sin salida
2 = ejecutar como demonio, salida a la consola
3 = ejecutar como demonio, salida al registro
[predeterminado es 0]
--proxy-lan-iface, -z <interfaz>
la interfaz LAN si la autenticación es a través de proxy [predeterminado es ninguna]
--auth-round, -j <cuenta>
número de veces que necesita autenticarse [predeterminado es 1]
--max-retries <cuenta>
número máximo de reintentos [predeterminado es 3]
--pid-file <archivo pid>
establecer a ninguna para deshabilitar [predeterminado es /var/run/minieap.pid]
--conf-file <archivo conf>
archivo de configuración [predeterminado /etc/minieap.conf]
--if-impl <módulo>
elegir el módulo de red. La opción solo se puede usar una vez. [predeterminado es el primero disponible]
--pkt-plugin <plugin>
activar el modificador de paquete correspondiente. La opción se puede usar más de una vez. [predeterminado es ninguna]
--module <módulo>
activar el módulo correspondiente. La opción se puede usar más de una vez.

Si usa --module o --pkt-plugin en la línea de comandos, se ignorarán todas las líneas del archivo de configuración que contengan "module=".

Módulos de red disponibles

sockraw
un módulo que usa Socket RAW

Modificador de paquete disponible

printer
imprime todos los paquetes que pasan por él
rjv3
usa algoritmo de autenticación vía hyrathb@GitHub Ruijie V3
--heartbeat, -e <segundos>
segundos entre paquetes [predeterminado es 60]
--eap-bcast-addr, -a <0-1>
dirección de difusión de paquete de inicio [predeterminado BROADCAST_STANDARD] 0 = estándar 1 = dirección de Ruijie
--dhcp-type, -d <0-3>
métodos DHCP [predeterminado HCP_AFTER_AUTH]
0 = no usar DHCP
1 = autenticación secundaria
2 = DHCP post-autenticación
3 = DHCP pre-autenticación
--dhcp-script, -c <script>
ejecutar script entre autenticación secundaria y DHCP post-autenticación [predeterminado es ninguna]
--rj-option <tipo>:<valor>[:r]
personalizar secciones, el tipo y el valor deben estar en hexadecimal.

Por ejemplo, --rj-option 6a:000102 significa añadir una sección de tipo 0x6a, con el contenido de 0x00 0x01 0x02 .

:r significa reemplazar el valor predeterminado generado por este programa. Por ejemplo, --rj-option 6f:000102:r significa reemplazar el contenido del tipo 0x6f por 0x00 0x12 0x02 .

Si la línea de comandos y el archivo de configuración tienen ambos esta opción, ambas configuraciones funcionarán.

--service <servicio>
personalizar el nombre del servicio [predeterminado es internet]
--version-str <versión>
personalizar la cadena de versión [predeterminado es RG-SU For Linux V1.0]
--fake-dns1 <DNS>
personalizar la dirección DNS principal (IPv4 en notación decimal punteada) [obtendrá una dirección por defecto]
--fake-dns2 <DNS>
personalizar la dirección DNS secundaria (IPv4/IPv6)
--fake-serial <serial>
personalizar el serial del disco duro [se obtendrá por defecto]
--max-dhcp-count <cuenta>
el número de tiempos de espera permitidos al esperar DHCP en la autenticación secundaria [predeterminado es 3]

minieap - Un cliente EAP para la autenticación 802.1X

NAME

minieap - Un cliente EAP para la autenticación 802.1X

SYNOPSIS

minieap [-h] [-d] [-i interface] [-c config file] [-p pid file] [-l log file]

DESCRIPTION

minieap es un cliente ligero para el Protocolo de Autenticación Extensible (EAP). Se utiliza para autenticar un dispositivo en una red que utiliza autenticación 802.1X.

Este programa soporta varios métodos EAP comunes, como EAP-TLS, EAP-PEAP y EAP-TTLS.

OPTIONS

-h
Muestra un mensaje de ayuda y sale.
-d
Ejecuta minieap como un demonio (en segundo plano).
-i interface
Especifica la interfaz de red a utilizar para la autenticación.
-c config file
Especifica la ruta al archivo de configuración. Si no se proporciona, se utilizará el archivo de configuración predeterminado.
-p pid file
Especifica la ruta al archivo PID cuando se ejecuta como demonio.
-l log file
Especifica la ruta al archivo de registro. Si no se proporciona, los registros se enviarán a la salida estándar.

Available network modules

minieap puede cargar módulos de red dinámicamente. Los módulos disponibles se encuentran generalmente en /usr/lib/minieap/modules/.

Available package modifier

No aplica.
