MIDICOPY(1) Manual de Comandos Generales MIDICOPY(1)

NOMBRE

midicopy - Copia pistas, canales, intervalos de tiempo seleccionados de un archivo MIDI a otro archivo MIDI

SINOPSIS

midicopy [-ver] [-trks n1,n2,..] [-xtrks n1,n2,..] [-xchns n1,n2,..] [-chans n1,n2,...] [-from n (en pulsos MIDI)] [-to n (en pulsos MIDI)] [-fromsec %f n (en segundos)] [-tosec n (en segundos)] [-frombeat %f n (en tiempos)] [-tobeat n (en tiempos)] [-replace trk,loc,val] [-tempo %n] [-speed %f] [-drumfocus n m] [-mutenodrum [%d]] [-setdrumloudness n m] [-focusontrack n1,n2,... (desde 1)] [-focusonchannel n1,n2,... (desde 1)] [-attenuation n] [-nobends] [-indrums n1,n2,...] [-xdrums n1,n2,...] [-onlydrums] [-nodrums] [-transpose n (semitonos)] archivoentrada.mid archivossalida.mid

DESCRIPCIÓN

midicopy se utiliza para copiar parte de un archivo MIDI a otro archivo MIDI. Puedes seleccionar un intervalo de tiempo particular, canales particulares, y pistas particulares o cualquier combinación. Si se incluyen uno o ambos parámetros de tiempo de ejecución -from o -to, el programa devuelve el tiempo de reproducción en segundos del archivo de salida. Midicopy fue desarrollado por Seymour Shlien a partir de la distribución midifilelib disponible en http://www.harmony-central.com/MIDI/midifilelib.tar.gz.

OPCIONES

-ver
imprime el número de versión y luego sale
-trks n1,n2, etc
Selecciona las pistas a copiar, donde los números de pista comienzan desde 1. Si se especifica más de una pista, deben estar separadas por comas. Siempre debes copiar la pista 1 ya que, por convención, contiene información pertinente para todas las demás pistas. Por defecto, se copian todas las pistas a menos que especifiques pistas particulares usando este parámetro de tiempo de ejecución.
-xtrks n1,n2, etc
Lista las pistas a excluir de la copia. Todas las demás pistas se copian. Esta opción no funciona en combinación con -trks.
-xchns n1,n2, etc
Lista los canales a excluir de la copia. Todos los demás canales se copian. Esta opción no funciona en combinación con -chns.
-chns n
Al igual que arriba, especifica los canales MIDI a copiar. Por defecto, se copian todos los canales. Los números de canal también comienzan desde 1.
-from n
El programa copiará todos los comandos MIDI a partir del pulso MIDI número n. Por defecto, comenzará desde el tiempo cero o el principio del archivo MIDI.
-to n
Detiene la copia de todos los eventos después del pulso MIDI número n. Por defecto, el archivo se copia hasta el final.
-frombeat n
El programa copiará todos los comandos MIDI a partir del tiempo de corchea número n. Por defecto, comenzará desde el tiempo cero o el principio del archivo MIDI.
-tobeat n
Detiene la copia de todos los eventos después del tiempo de corchea número n. Por defecto, el archivo se copia hasta el final.
-fromsec n
El programa copiará todos los comandos MIDI a partir del tiempo n en segundos.
-tosec n
Detiene la copia de todos los eventos después del tiempo n en segundos. Estas dos opciones (-fromsec y -tosec) no funcionan con precisión si el archivo MIDI tiene más de un comando de tempo. Solo se utiliza el primero para convertir segundos en unidades de pulso MIDI. Por lo tanto, es preferible usar las opciones -from y -to.
-replace trk,loc,val
Esta opción debe usarse sola. Midicopy copiará todo el archivo tal cual, excepto que reemplazará un byte por val, donde el byte está ubicado en la pista especificada (trk) y la posición especificada (loc). Comúnmente, esta función se usa para cambiar un número de programa MIDI particular (instrumento) asociado con un canal. Necesitas conocer el conteo de bytes en la pista de ese parámetro para usar esta función.
-tempo notas de corchea/minuto
Todas las indicaciones de tempo en el archivo midi serán reemplazadas por el valor anterior.
-speed factor
Todas las indicaciones de tempo en el archivo midi serán multiplicadas por este factor. Los valores mayores que 1.0 acelerarán la música, mientras que los valores menores la ralentizarán. El factor es un valor de punto flotante.
-drumfocus código_de_batería velocidades_excluidas
La línea de batería seleccionada (especificada por el valor de tono del código de batería) se resalta reduciendo el volumen de todas las demás líneas de batería al valor de velocidades_excluidas. El valor del código de batería debe estar en el rango de 35 a 81 inclusive.
-mutenodrum [nivel]
Todos los canales que no sean el 9 (canal de batería) se atenúan al nivel dado. Si no se especifica el nivel, se asume cero.
-setdrumloudness n m
donde n está entre 35 y 81 inclusive y m es el volumen entre 0 y 127. El volumen de todas las instancias del tambor n se cambia a m.
-focusontrack n1,n2,...
Las velocidades de las notas en todas las pistas excepto n se atenúan.
-focusonchannel n1,n2,...
Las velocidades de las notas en todos los canales excepto n se atenúan.
-attenuation n
Especifica la cantidad en que se reducen las velocidades de las notas por -focusontracks o -focusonchannels. El valor predeterminado actual es 70.
-nobends
Suprime todos los comandos de pitchbend de canal.
-indrums n1,n2,...
Solo permite percusiones con códigos n1,n2,...
-xdrums n1,n2,...
Excluye las percusiones con códigos n1,n2,...
-onlydrums
Copia solo el canal de percusión.
-nodrums
Copia todos los canales excepto el canal de percusión.
-transpose n (semitonos)
Transpone el tono para todos los canales excepto la percusión en n semitonos.

EJEMPLO

midicopy.exe -trks 1,5 -from 2669 -to 8634 uzicko.mid fragment.mid Midicopy copiará las pistas 1 y 5 comenzando desde la posición de pulso MIDI 2669 y terminando en la posición de pulso MIDI 8634.

ABCMIDI(1)

NOMBRE

abcmidi - convierte archivos ABC a MIDI

SINOPSIS

abcmidi [-o output.mid] [input.abc]

DESCRIPCIÓN

El programa abcmidi lee un archivo en formato ABC (un formato de notación musical) y lo convierte a un archivo MIDI.

OPCIONES

-o output.mid
Especifica el nombre del archivo de salida MIDI. Si no se especifica, se utiliza la salida estándar.

EJEMPLO

Para convertir un archivo llamado melodia.abc a un archivo MIDI llamado melodia.mid:

abcmidi -o melodia.mid melodia.abc
