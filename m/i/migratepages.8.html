MIGRATEPAGES(8) Manual del Administrador de Linux MIGRATEPAGES(8)

NOMBRE

migratepages - Migra la ubicación física de las páginas de un proceso

SINOPSIS

migratepages pid from-nodes to-nodes

DESCRIPCIÓN

migratepages mueve la ubicación física de las páginas de un proceso sin realizar cambios en el espacio de direcciones virtual del proceso. Mover las páginas permite cambiar las distancias de un proceso a su memoria. El rendimiento puede optimizarse moviendo las páginas de un proceso al nodo donde se está ejecutando.

Si se especifican varios nodos para from-nodes o to-nodes, se intenta preservar la ubicación relativa de cada página en cada conjunto de nodos.

Por ejemplo, si movemos de los nodos 2-5 a 7,9,12-13, el modo de operación preferido es mover las páginas de 2->7, 3->9, 4->12 y 5->13. Sin embargo, esto solo es posible si hay suficiente memoria disponible.

Especificadores de nodo válidos
all Todos los nodos
número Número de nodo
número1{,número2} Nodo número1 y Nodo número2
número1-número2 Nodos desde el número1 hasta el número2
! nodos Invertir la selección de la siguiente especificación.

NOTAS

Requiere un kernel compatible con políticas NUMA con soporte para la migración de páginas (Linux 2.6.16 y posteriores).

migratepages solo moverá páginas que no sean compartidas con otros procesos si es llamado por un usuario sin privilegios administrativos (pero con el derecho a modificar el proceso).

migratepages moverá todas las páginas si se invoca como root (o un usuario con privilegios administrativos).

ARCHIVOS

/proc/<pid>/numa_maps para obtener información sobre el uso de memoria NUMA de un proceso.
