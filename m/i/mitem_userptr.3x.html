mitem_userptr(3X) Llamadas de biblioteca mitem_userptr(3X)

NOMBRE

set_item_userptr, item_userptr - asociar datos de aplicación con un elemento del menú

SINOPSIS

#include <menu.h>
int set_item_userptr(ITEM *item, void *userptr);
void *item_userptr(const ITEM *item);

DESCRIPCIÓN

Cada elemento del menú tiene un campo que puede usarse para almacenar datos específicos de la aplicación (es decir, el código del controlador de menú lo deja en paz). Estas funciones obtienen y establecen dicho campo.

VALOR DE RETORNO

La función item_userptr devuelve un puntero (posiblemente NULL). No establece errno.

set_item_userptr siempre devuelve E_OK (éxito).

PORTABILIDAD

Estas rutinas emulan la biblioteca de menús de System V. No eran compatibles con las versiones 7 o BSD.

El puntero de usuario es un puntero void. Elegimos no dejarlo como un puntero char por compatibilidad con SVr4.

AUTORES
