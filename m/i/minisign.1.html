NOMBRE

minisign - Una herramienta sencillísima para firmar archivos y verificar firmas.

SINOPSIS

minisign -G [-p archivo_clave_pub] [-s archivo_clave_sec] [-W]

minisign -R [-s archivo_clave_sec] [-p archivo_clave_pub]

minisign -C [-s archivo_clave_sec] [-W]

minisign -S [-H] [-x archivo_firma] [-s archivo_clave_sec] [-c comentario_no_confiable] [-t comentario_confiable] -m archivo [archivo ...]

minisign -V [-x archivo_firma] [-p clave_pub | -P clave_pub] [-o] [-q] -m archivo

DESCRIPCIÓN

Minisign es una herramienta sencillísima para firmar archivos y verificar firmas.

Es portátil, ligero y utiliza el sistema de firma de clave pública Ed25519 http://ed25519.cr.yp.to/, altamente seguro.

OPCIONES

Estas opciones controlan las acciones de minisign.

-G
Generar un nuevo par de claves
-C
Cambiar/eliminar la contraseña de una clave secreta
-R
Recrear un archivo de clave pública a partir de un archivo de clave secreta
-S
Firmar archivos
-V
Verificar que una firma es válida para un archivo dado
-H
Requiere que la entrada esté pre-hasheada
-l
Firmar usando el formato legado
-m <archivo>
Archivo a firmar/verificar
-o
Combinado con -V, muestra el contenido del archivo después de la verificación
-p <archivo_clave_pub>
Archivo de clave pública (por defecto: ./minisign.pub)
-P <clave_pub>
Clave pública, como una cadena base64
-s <archivo_clave_sec>
Archivo de clave secreta (por defecto: ~/.minisign/minisign.key)
-W
No cifrar/descifrar la clave secreta con una contraseña
-x <archivo_firma>
Archivo de firma (por defecto: <archivo>.minisig)
-c <comentario>
Añadir un comentario de una línea no confiable
-t <comentario>
Añadir un comentario de una línea confiable
-q
Modo silencioso, suprime la salida
-Q
Modo bastante silencioso, solo imprime el comentario confiable
-f
Forzar. Combinado con -G, sobrescribe un par de claves anterior
-v
Muestra el número de versión

EJEMPLOS

Crear un par de claves

minisign -G

La clave pública se imprime y se guarda en el archivo minisign.pub. La clave secreta se cifra y se guarda como un archivo llamado ~/.minisign/minisign.key.

Firmar archivos

$ minisign -Sm myfile.txt $ minisign -Sm myfile.txt myfile2.txt *.c

O para incluir un comentario en la firma, que será verificado y mostrado al verificar el archivo:

$ minisign -Sm myfile.txt -t ´Este comentario también se firmará´

La clave secreta se carga desde ${MINISIGN_CONFIG_DIR}/minisign.key, ~/.minisign/minisign.key, o su ruta se puede establecer explícitamente con el modificador de línea de comandos -s <ruta>.

Verificar un archivo

$ minisign -Vm myfile.txt -P <clave_pub>

o

$ minisign -Vm myfile.txt -p signature.pub

Esto requiere que la firma myfile.txt.minisig esté presente en el mismo directorio.

La clave pública puede residir en un archivo (./minisign.pub por defecto) o especificarse directamente en la línea de comandos.

Notas

Los archivos de firma incluyen una línea de comentario no confiable que se puede modificar libremente, incluso después de la creación de la firma.

También incluyen una segunda línea de comentario, que no se puede modificar sin la clave secreta.

Los comentarios confiables se pueden usar para añadir instrucciones o metadatos específicos de la aplicación (nombre de archivo previsto, marcas de tiempo, identificadores de recursos, números de versión para prevenir ataques de degradación).
