MIMETYPE(1p) Documentación de Perl contribuida por el usuario MIMETYPE(1p)

NOMBRE

mimetype - Determinar el tipo de archivo

SINOPSIS

mimetype [opciones] [-] archivos

DESCRIPCIÓN

Este script intenta determinar el tipo MIME de un archivo utilizando la base de datos Shared MIME-info. Está pensado como una especie de imitación de file(1), pero utiliza tipos MIME en lugar de descripciones.

Si se crea un enlace simbólico del comando file a mimetype, se comportará de forma un poco más compatible, ver "--file-compat". Las opciones de línea de comandos para especificar archivos mágicos alternativos no se implementan de la misma manera debido a los formatos de datos conflictivos. Además, la redacción de las descripciones será diferente.

Para nombrar los interruptores, seguí el manual de file(1) versión 4.02 cuando fue posible. Parecen diferir completamente de la especificación en el capítulo 'utilities' de IEEE Std 1003.1-2001 (POSIX).

OPCIONES

-a, --all
Mostrar la salida de todas las reglas que coinciden con el archivo.

TODO: este método ahora solo devuelve una coincidencia para cada método (globs, magic, etc.).

-b, --brief
No anteponer nombres de archivo a las líneas de salida (modo breve).
--database=mimedir:mimedir:...
Forzar al programa a buscar en estos directorios la base de datos shared mime-info. Los directorios especificados por la especificación basedir se ignoran.
-d, --describe
Imprimir descripciones de archivos en lugar de tipos MIME; este es el valor predeterminado cuando se usa "--file-compat".
-D, --debug
Imprimir información de depuración sobre cómo se determinó el tipo MIME.
-f archivo-nombres, --namefile=archivo-nombres
Leer los nombres de los archivos a examinar del archivo 'archivo-nombres' (uno por línea) antes de la lista de argumentos.
--file-compat
Hace que mimetype se comporte un poco más compatible con file(1). Esto se activa automáticamente cuando se llama a mimetype mediante un enlace llamado 'file'.

Un solo '-' ya no se considerará un separador entre opciones y nombres de archivo, sino que será idéntico a "--stdin". ( Todavía puedes usar '--' como separador, pero eso no es compatible con la versión anterior del comando file. ) Además, el valor predeterminado será imprimir descripciones en lugar de tipos MIME.

-F cadena, --separator=cadena
Usar la cadena como separador personalizado entre el nombre del archivo y su tipo MIME o descripción; el valor predeterminado es ':'.
-h, --help
-u, --usage
Imprimir un mensaje de ayuda y salir.
-i, --mimetype
Usar tipos MIME, lo opuesto a "--describe"; este es el valor predeterminado cuando _no_ se usa "--file-compat".
-L, --dereference
Seguir enlaces simbólicos.
-l código, --language=código
El atributo de idioma especifica un código de idioma de dos letras, esto hace que las descripciones se muestren en el idioma especificado.
-M, --magic-only
No verificar extensiones, globs o tipo de inodo, solo mirar el contenido del archivo. Esto es particularmente útil si por alguna razón no confías en el nombre o la extensión que tiene un archivo.
-N, --noalign
No alinear los campos de salida.
--output-format
Si desea un formato de salida alternativo, puede especificar una cadena de formato que contenga las siguientes secuencias de escape: 
%f para el nombre del archivo
%d descripción
%m tipo MIME

La alineación no está disponible cuando se usa esto; necesita procesar la salida posteriormente para hacerlo.

--stdin
Determinar el tipo de contenido desde STDIN, menos potente que la verificación normal de archivos porque solo usa la coincidencia de magia. Esto también ocurrirá si el identificador STDIN es una tubería.

Para usar esta opción, se debe instalar IO::Scalar.

-v, --version
Imprimir la versión del programa y salir.

AMBIENTE

XDG_DATA_HOME
XDG_DATA_DIRS
Estas variables pueden listar directorios base para buscar archivos de datos. Se esperará que el shared mime-info esté en el subdirectorio "mime" de uno de estos directorios. Si no están configuradas, se buscará en los siguientes directorios: 
$HOME/.local/share/mime
/usr/local/share/mime
/usr/share/mime

Ver también la "Especificación de directorios base XDG" http://freedes.org/Standards/basedir-spec

ARCHIVOS

El directorio base para todos los archivos de datos se determina mediante dos variables de entorno, ver "AMBIENTE".

BASE/mime/packages/SOURCE.xml
Todos los demás archivos se compilan a partir de estos archivos fuente. Para recompilarlos, use update-mime-database(1).
BASE/mime/globs
Información compilada sobre globs.
BASE/mime/magic
Información compilada sobre números mágicos.
BASE/mime/MEDIA/SUBTYPE.xml
Descripciones de un tipo MIME en múltiples idiomas, utilizado para el interruptor "--describe".

DIAGNÓSTICOS

Si un archivo tiene un tipo MIME o una descripción vacía, lo más probable es que el archivo no exista y el nombre dado no coincida con ningún glob. Una descripción vacía también puede significar que no hay ninguna descripción disponible en el idioma que especificó.

El programa sale con un valor de salida distinto de cero si fallaron los argumentos de la línea de comandos, no se encontró un módulo del que depende o no se pudo acceder a la base de datos shared mime-info. Consulte File::MimeInfo para obtener más detalles.
