MIDI2ABC(1) Manual de Comandos Generales MIDI2ABC(1)

NOMBRE

midi2abc - programa para convertir archivos en formato MIDI a notación abc

SINOPSIS

midi2abc -f infile [-xa] [-ga] [-a acbeats] [-m cifra_de_compas] [-ppu partes_por_unidad_abc] [-aul denominador_de_unidad_abc] [-gu] [-b compases] [-Q tempo] [-u pulsos] [-k tonalidad] [-c canal] [-obpl] [-bpl compases] [-bps compases] [-o nombre_archivo] [-s] [-sr unidades] [-sum] [-nb] [-nt] [-splitvoices] [-midigram] [-mftext] [-mftextpulses] [-nogr] [-title cadena] [-origin cadena]

DESCRIPCIÓN

midi2abc toma un archivo en formato MIDI y lo convierte a algo lo más cercano posible al formato de texto abc. El usuario deberá luego añadir campos de texto no presentes en la cabecera MIDI y posiblemente pulir la salida de notas abc.

La salida de midi2abc se imprime en pantalla. Para guardarla en un archivo, use el operador de redirección (p. ej., midi2abc -f file.mid > file.abc) o especifique el archivo de salida usando la opción -o.

Use solo una o ninguna de las opciones -u -gu, -b y -Q. Midi2abc normalmente convierte las unidades de tiempo MIDI a unidades cuánticas que normalmente corresponden a la nota de 1/16 o 1/32 de abc. Si ninguna de estas está presente, el programa usará la información PPQN de la cabecera MIDI para calcular el factor de conversión adecuado. Para la mayoría de los archivos MIDI en la web, se recomienda confiar en la información de la cabecera MIDI y no usar ninguna de las opciones distintas de las opciones de formato.

El programa extraerá la información de la cifra de compás del archivo MIDI si está presente. De lo contrario, asumirá 4/4 o puede especificarla con la opción -m.

Si la melodía tiene una anacrusa, puede usar la opción -ga o -xa para estimar su duración. Alternativamente, puede especificar su valor usando la opción -a. La anacrusa se especifica en longitudes de media unidad, donde la longitud de unidad se define por el campo L:. Por ejemplo, si L: 1/8, entonces una negra se indicaría con el valor 4 (4 unidades de 1/16).

OPCIONES

-a acbeats
donde acbeats especifica la anacrusa en longitudes de media unidad.
-xa
extrae la anacrusa del archivo encontrando la primera nota fuerte.
-ga
estima la anacrusa minimizando el número de ligaduras a través de compases.
-m cifra_de_compas
cifra de compás.
-b compases
número de compases deseados en la salida.
-Q tempo
tempo en negras por minuto.
-u pulsos
Permite especificar directamente el número de pulsos MIDI por unidad de tiempo abc.
-ppu partes_por_unidad_abc
Normalmente, la unidad de nota más pequeña que midi2abc puede extraer es la mitad de la longitud de la unidad L:. Esto se llama la unidad cuántica. Por lo tanto, para L: 1/8, midi2abc puede extraer notas de 1/16 pero no notas de 1/32. Puede cambiar esto especificando -ppu 4, por ejemplo. El número de partes debe ser una potencia de 2.
-aul denominador_de_unidad_abc
Normalmente, midi2abc elige una longitud de unidad de 1/8 o 1/16 dependiendo de la cifra de compás. Para cifras de compás menores a 3/4 se usa L: 1/16 y para cifras de compás mayores se usa L: 1/8. Puede especificar la longitud de unidad a usar con este parámetro. Así, -aul 32 hará que midi2abc use una longitud de unidad de nota de 1/32.
-gu
Indica a midi2abc que estime el número de pulsos MIDI por unidad de tiempo abc a partir de la duración o espaciado de las notas en el archivo MIDI.
-gk
Indica a midi2abc que adivine la armadura de clave minimizando el número de accidentales, incluso si la armadura de clave ya está especificada en el archivo MIDI. Por defecto, la armadura de clave es la especificada en el archivo MIDI. Si no se especifica, el programa adivina la armadura de clave minimizando los accidentales.
-k tonalidad
armadura de clave: -6 a 6 sostenidos.
-c canal
selecciona solo este canal MIDI.
-f archivo_entrada
archivo de entrada en formato MIDI.
-o archivo_salida
especifica el nombre del archivo abc de salida.
-s
no descarta notas muy cortas.
-sr unidades_cuanticas
no anota un silencio corto menor que el tamaño especificado después de una nota. Si el tamaño (en unidades cuánticas) es cero, no se hace nada. Para valores mayores, el silencio se absorbe en la nota precedente. En otras palabras, la nota precedente se alarga para incluir ese silencio.
-sum
imprime un resumen corto del archivo MIDI de entrada.
-nb
no busca ritmos rotos.
-nt
no busca tresillos.
-obpl
Imprime solo un compás por línea en lugar de 4. Para música compleja, esto mejora la legibilidad y evita algunos problemas con algunos conversores de abc a postscript. Esta opción está obsoleta.
-nogr
(Sin agrupamiento de notas) Inserta un espacio entre todas las notas. Hace un archivo postscript menos bonito pero es más fácil de editar.
-bpl ncompases
Imprime ncompases de música en cada línea seguidos de una barra invertida.
-bps ncompases
Cuando se han impreso ncompases (incluidas las líneas unidas por una continuación con barra invertida), pasa a una nueva línea (sin barra invertida).
-splitvoices
Este parámetro maneja acordes polifónicos dividiendo una voz entera en múltiples voces. (Un acorde polifónico es un acorde compuesto por notas que no comienzan o terminan al mismo tiempo.) Normalmente, midi2abc une las notas más largas con las notas del acorde siguiente usando ligaduras. Aquí hay un ejemplo: [Bd-]d [Bd-]d|. Esto debería separarse idealmente en dos voces: Bz Bz y d2 d2. Sin embargo, la separación no es única. Bz d2 y d2 Bz también están bien.
-midigram
Cuando aparece esta opción, se ignoran todas las demás opciones y no se produce ningún archivo abc. En su lugar, se imprime una lista de todas las notas en el archivo MIDI en un formato fijo. Cada línea representa un par de eventos MIDI de nota encendido/apagado. La línea contiene el tiempo de encendido/apagado de la nota, su número de pista, número de canal, tono MIDI y velocidad MIDI. El último registro indica la duración del archivo MIDI en unidades de pulso MIDI. La salida está diseñada para ser introducida en una interfaz gráfica de usuario que producirá una representación gráfica (piano roll).
-mftext
Cuando aparece esta opción, se ignoran todas las demás opciones y no se produce ningún archivo abc. En su lugar, se imprime una lista de todos los comandos MIDI. La salida está diseñada para ser introducida en una interfaz gráfica de usuario proporcionada por runabc.tcl.
-mftextpulses
Igual que -mftext excepto que la unidad de tiempo está en pulsos MIDI.
-title cadena
Reemplaza el campo de título predeterminado siguiente a T: con la cadena dada.
-origin cadena
Añade un campo O: con la cadena dada.

CARACTERÍSTICAS

* La tonalidad se elige para minimizar el número de accidentales. Alternativamente, el usuario puede especificar la tonalidad numéricamente (un número positivo es el número de sostenidos, un número negativo es menos el número de bemoles).

midi2abc(1)

NAME

midi2abc

convert MIDI files to ABC notation

SYNOPSIS

midi2abc [options] [infile ...]

DESCRIPTION

The midi2abc program converts MIDI files into the ABC music notation format. It attempts to create a sensible transcription, but does not guarantee perfection.

It is most suitable for monophonic MIDI files, such as those recorded directly from a keyboard. It can also handle simple polyphonic pieces, but complex arrangements may not be transcribed accurately.

The ABC header fields X:, K:, Q:, M: and L: are generated automatically. Other header fields and comments must be added manually.

OPTIONS

-a
Do not attempt to guess the length of the anacrusis. Use this if the automatic detection is not working correctly.
-c channel
Select only the specified MIDI channel. Events on other channels are ignored.
-d
Display debugging information during conversion.
-f
Force conversion, even if errors are encountered.
-h
Display a help message and exit.
-i
Invert the order of notes in chords. This may be useful for some transcriptions.
-m measures
Specify the number of measures in the anacrusis before the first barline.
-o outfile
Write the output to the specified file. If not provided, output goes to stdout.
-q tempo
Set the default tempo (quaver = X). The default is 4 (crotchet).
-s
Simplify accidentals. This may result in some pitch errors if barlines are added or deleted later.
-t time_signature
Specify the time signature (e.g., 4/4, 3/4). If not provided, it is deduced from the MIDI file.
-v
Display version information and exit.
-x
"Explain" mode. Output includes extra comments explaining the transcription process.
-xa
"Explain all" mode. Similar to -x, but with even more verbose output.
-xf
"Force" mode. Tries to convert even if it encounters errors.
-xL
Force default note length. See L: field in abc documentation.

FEATURES

* The beat is automatically deduced from the inter-note distances in the file. However, by default it is deduced in a heuristic manner from the inter-note distances. This means that you do not have to use the MIDI clock as a metronome when playing in a tune from a keyboard.

* Barlines are automatically inserted. The user specifies the number of measures in the anacrusis before the first barline and the time signature.

* The program can guess how the length of the anacrusis, either by looking for the first strong note or minimizing the number of notes split by a tie across a barline.

* Where a note extends beyond a bar break, it is split into two tied notes.

* The output has 4 bars per line.

* Enough accidental signs are put in the music to ensure that no pitch errors occur if a barline is added or deleted.

* The program attempts to group notes sensibly in each bar.

* Triplets and broken rhythm (a>b) are supported.

* Chords are identified.

* Text information from the original MIDI file is included as comments.

* The -c option can be used to select only 1 MIDI channel. Events on other channels are ignored.

LIMITATIONS

midi2abc does not ...

* Supply tune title, composer or any other field apart from X: , K:, Q:, M: and L: - these must be added by hand afterwards, though they may have been included in the text of the MIDI file.

* Support duplets, quadruplets, other esoteric features.

* Support mid-tune key or time signature changes.

* Deduce repeats. The output is just the notes in the input file.

* Recover an abc tune as supplied to abc2midi. However, if you want to do this, "midi2abc -xa -f file.mid" comes close.
