mincore(2) Manual de llamadas al sistema mincore(2)

NOMBRE

mincore - determinar si las páginas están residentes en memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/mman.h>
int mincore(void *addr, size_t length, unsigned char *vec);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

mincore():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

mincore() devuelve un vector que indica si las páginas de memoria virtual del proceso que llama están residentes en memoria principal (RAM), y por lo tanto no causarán un acceso a disco (fallo de página) si se referencian. El núcleo devuelve información de residencia sobre las páginas que comienzan en la dirección addr, y continúan durante length bytes.

El argumento addr debe ser un múltiplo del tamaño de página del sistema. El argumento length no necesita ser un múltiplo del tamaño de página, pero dado que se devuelve información de residencia para páginas completas, length se redondea efectivamente al siguiente múltiplo del tamaño de página. Se puede obtener el tamaño de página (PAGE_SIZE) usando sysconf(_SC_PAGESIZE).

El argumento vec debe apuntar a un array que contenga al menos (length+PAGE_SIZE-1) / PAGE_SIZE bytes. Al regresar, el bit menos significativo de cada byte se establecerá si la página correspondiente está actualmente residente en memoria, y estará claro en caso contrario. (La configuración de los otros bits en cada byte no está definida; estos bits están reservados para un posible uso futuro.) Por supuesto, la información devuelta en vec es solo una instantánea: las páginas que no están bloqueadas en memoria pueden entrar y salir en cualquier momento, y el contenido de vec puede estar obsoleto en el momento en que esta llamada regrese.

VALOR DEVUELTO

En caso de éxito, mincore() devuelve cero. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EAGAIN el núcleo está temporalmente sin recursos.

EFAULT
vec apunta a una dirección inválida.
EINVAL
addr no es un múltiplo del tamaño de página.
ENOMEM
length es mayor que (TASK_SIZE - addr). (Esto podría ocurrir si se especifica un valor negativo para length, ya que ese valor se interpretará como un entero sin signo grande). En Linux 2.6.11 y anteriores, se devolvía el error EINVAL para esta condición.
ENOMEM
addr a addr + length contenía memoria no mapeada.

ESTÁNDARES

Ninguno.

HISTORIA

Linux 2.3.99pre1, glibc 2.2.

Apareció por primera vez en 4.4BSD.

NetBSD, FreeBSD, OpenBSD, Solaris 8, AIX 5.1, SunOS 4.1.

ERRORES

Antes de Linux 2.6.21, mincore() no devolvía información correcta para mapeos MAP_PRIVATE, o para mapeos no lineales (establecidos usando remap_file_pages(2)).

VER TAMBIÉN

fincore(1), madvise(2), mlock(2), mmap(2), posix_fadvise(2), posix_madvise(3)
