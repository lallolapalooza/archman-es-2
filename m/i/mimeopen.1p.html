NOMBRE

mimeopen - Abrir archivos por mimetype

SINOPSIS

mimeopen [opciones] [-] archivos

DESCRIPCIÓN

Este script intenta determinar el mimetype de un archivo y abrirlo con la aplicación de escritorio predeterminada. Si no hay una aplicación predeterminada configurada, se le pedirá al usuario un menú de "abrir con" en la terminal.

Para usar este script, necesita la base de datos freedesktop mime-info y el paquete freedesktop desktop-file-utils. Ver File::MimeInfo::Applications(3) para más detalles.

OPCIONES

-a, --ask
No ejecute la aplicación predeterminada, sino pregunte qué aplicación ejecutar. Esto no cambia la aplicación predeterminada.
-d, --ask-default
Permita al usuario elegir un nuevo programa predeterminado para los archivos dados.
-n, --no-ask
No pregunte al usuario qué programa usar. Elija el programa predeterminado o el primer programa conocido que maneje el mimetype del archivo. Esto no establece la aplicación predeterminada.
-M, --magic-only
No compruebe extensiones, globs o tipo de inode, solo mire el contenido del archivo. Esto es particularmente útil si por alguna razón no confía en el nombre o la extensión que tiene un archivo.
--database=mimedir:mimedir:...
Fuerce al programa a buscar en estos directorios la base de datos compartida de mime-info. Los directorios especificados por la especificación de basedir se ignoran.
-D, --debug
Imprima información de depuración sobre cómo se determinó el mimetype.
-h, --help
-u, --usage
Imprima un mensaje de ayuda y salga.
-v, --version
Imprima la versión del programa y salga.

OPCIONES OBSOLETAS

-L, --dereference
Seguir enlaces simbólicos. Obsoleto porque este es el valor predeterminado lógico para este comando. Ignorado silenciosamente.

ERRORES

Si encuentra errores, por favor repórtelos en nuestro rastreador de problemas de Github en https://github.com/mbeijen/File-MimeInfo/issues.

Ver File::MimeInfo::Applications(3) y File::DesktopEntry(3) para algunas limitaciones.
