NOMBRE

miniupnpd - Demonio de UPnP para Dispositivo de Puerta de Enlace a Internet

SINOPSIS

miniupnpd [--version] [-f archivo_config] [-i nombre_interfaz_ext] [-I nombre_interfaz_ext6] [-o ip_ext] [-a ip_escucha] [-p puerto] [-d] [-U] [-S0] [-N] [-u uuid] [-s serial] [-m numero_modelo] [-t intervalo_notificacion] [-P archivo_pid] [-B descarga subida] [-w url] [-r intervalo_limpieza_reglas] [-A regla_permiso] [-b BOOTID] [-1]

DESCRIPCIÓN

miniupnpd actúa como un Dispositivo de Puerta de Enlace a Internet UPnP. Está diseñado para ejecutarse en la puerta de enlace entre Internet y una LAN con NAT. Proporciona una interfaz, tal como se define en el estándar UPnP, para que los clientes en la LAN soliciten redireccionamientos de puertos.

OPCIONES

-f archivo_config
carga la configuración desde el archivo.
-i nombre_interfaz_ext
interfaz utilizada para conectarse a Internet.
-o ip_ext
dirección utilizada para conectarse a Internet. Si no se especifica, se utilizará la dirección predeterminada de la interfaz.
-a ip_escucha
dirección en la LAN. La opción -a puede usarse varias veces si la LAN está subdividida en varias subredes.
-p puerto
puerto utilizado para HTTP.
-d
modo de depuración: no pasar a segundo plano, mostrar mensajes en la consola y no filtrar mensajes de baja prioridad.
-U
informar el tiempo de actividad del sistema en lugar del tiempo de actividad del demonio a los clientes.
-S0
desactivar el modo "seguro" para que los clientes solo puedan agregar mapeos a otras IPs.
-N
habilitar la funcionalidad NAT-PMP y PCP.
-u uuid
establecer el uuid del Dispositivo de Puerta de Enlace a Internet UPnP.
-s serial
número de serie para el Dispositivo de Puerta de Enlace a Internet UPnP.
-m numero_modelo
número de modelo para el Dispositivo de Puerta de Enlace a Internet UPnP.
-t intervalo_notificacion
intervalo de notificación SSDP en segundos. El valor predeterminado es 900 segundos. Los mensajes de anuncio SSDP se transmitirán a este intervalo.
-P archivo_pid
archivo pid. El predeterminado es /var/run/miniupnpd.pid
-B descarga subida
tasas de bits de descarga y subida informadas a los clientes.
-w url
url de presentación. El predeterminado es la primera dirección en la LAN, puerto 80.
-r intervalo_limpieza_reglas
intervalo (mínimo) entre comprobaciones de limpieza de reglas no utilizadas.
-A regla_permiso
utilizar la siguiente sintaxis para las reglas de permiso:
(permitir|denegar) (rango de puertos externos) ip/máscara (rango de puertos internos)
ejemplos:
"permitir 1024-65535 192.168.1.0/24 1024-65535"
"denegar 0-65535 0.0.0.0/0 0-65535"
-b BOOTID
establece el valor de la cabecera SSDP BOOTID.UPNP.ORG
-1
forzar la notificación de IGDv1 en rootDesc cuando se compila como IGDv2 *usar con precaución*
