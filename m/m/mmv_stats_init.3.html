mmv_stats_init(3)

Paquete: pcp

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

MMV_STATS_INIT(3) Manual de funciones de biblioteca MMV_STATS_INIT(3)

NOMBRE

mmv_stats_init, mmv_stats2_init - crear e inicializar archivo de valores mapeados en memoria

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/mmv_stats.h>

void *mmv_stats_init(const char *name,
int cluster, mmv_stats_flags_t flags, const mmv_metric_t *stats, int nstats, mmv_indom_t *indoms, int nindoms);

void *mmv_stats2_init(const char *name,
int cluster, mmv_stats_flags_t flags, const mmv_metric2_t *stats2, int nstats2, mmv_indom2_t *indoms2, int nindoms2);

cc ... -lpcp_mmv -lpcp

DESCRIPCIÓN

Nota: estas funciones están obsoletas; consulte mmv_stats_registry(3).

mmv_stats_init crea e inicializa el contenido del archivo MMV(5), devolviendo un manejador que se utiliza en posteriores llamadas a la API de MMV.

mmv_stats2_init es equivalente a mmv_stats_init, excepto que proporciona una opción para nombres de métricas e instancias más largos.

mmv_stats_stop realiza un cierre ordenado del manejador de mapeo devuelto por una llamada de inicialización anterior.

El archivo se crea en el directorio $PCP_TMP_DIR/mmv, el argumento name se espera que sea un nombre base del archivo, no la ruta completa. El contenido de metadatos del archivo no cambia después de que se haya creado el archivo.

El archivo antiguo se elimina incondicionalmente a menos que haya ocurrido un error.

cluster es el ID de clúster de PMDA MMV preferido que se usará para las métricas originadas de esta llamada a mmv_stats_init. Las flags proporcionan control adicional sobre el comportamiento del PMDA MMV; por ejemplo, el uso de MMV_FLAG_PROCESS garantizará que los valores solo se exporten cuando la aplicación instrumentada se esté ejecutando; esto se verifica en cada solicitud de nuevos valores.

stats es la matriz de elementos mmv_metric_t de longitud nstats. Cada elemento de la matriz describe una métrica PCP.

        typedef struct {
            char name[MMV_NAMEMAX];     /* Nombre de la métrica */
            __uint32_t item;            /* Componente de elemento de PMID */
            mmv_metric_type_t type;     /* Tipo de la métrica */
            mmv_metric_sem_t semantics; /* Semántica de la métrica */
            pmUnits dimension;          /* Dimensiones (TIEMPO, ESPACIO, etc.) */
            __uint32_t indom;           /* Identificador de dominio de instancia */
            char *shorttext;            /* Opcional, ayuda en una línea */
            char *helptext;             /* Opcional, texto de ayuda completo */
        } mmv_metric_t;

stats2 es la matriz de elementos mmv_metric2_t de longitud nstats2. Cada elemento de la matriz describe una métrica PCP; la única diferencia con stats es el levantamiento de la restricción en la longitud de los nombres de métrica (anteriormente MMV_NAMEMAX, que es de 64 bytes).

        typedef struct {
            char *name;                 /* Nombre de la métrica */
            __uint32_t item;            /* Componente de elemento de PMID */
            mmv_metric_type_t type;     /* Tipo de la métrica */
            mmv_metric_sem_t semantics; /* Semántica de la métrica */
            pmUnits dimension;          /* Dimensiones (TIEMPO, ESPACIO, etc.) */
            __uint32_t indom;           /* Identificador de dominio de instancia */
            char *shorttext;            /* Opcional, ayuda en una línea */
            char *helptext;             /* Opcional, texto de ayuda completo */
        } mmv_metric2_t;

Si indom no es cero y no es PM_INDOM_NULL, entonces la métrica tiene múltiples valores y debe haber una entrada indom correspondiente en la lista indom (identificada de forma única por el número de serial).

Las matrices stats y stats2 no pueden contener ningún elemento que no tenga nombre; esto se considera un error y no se exportarán métricas en este caso.

indoms es la matriz de elementos mmv_indom_t de longitud nindoms. Cada elemento de la matriz describe un dominio de instancia PCP.

        typedef struct {
            __int32_t internal;
            char external[MMV_NAMEMAX];
        } mmv_instances_t;
        typedef struct {
            __uint32_t serial;           /* Número de serie único */
            __uint32_t count;            /* Número de instancias */
            mmv_instances_t *instances;  /* IDs internos/externos */
            char *shorttext;             /* Texto de ayuda corto */
            char *helptext;              /* Texto de ayuda largo */
        } mmv_indom_t;

indoms2 es la matriz de elementos mmv_indom2_t de longitud nindoms2. Cada elemento de la matriz describe un dominio de instancia PCP, y la única diferencia con indoms es el levantamiento de la restricción en las longitudes de los nombres de instancia externos (anteriormente MMV_NAMEMAX, que es de 64 bytes).

        typedef struct {
            __int32_t internal;
            char *external;
        } mmv_instances2_t;
        typedef struct {
            __uint32_t serial;           /* Número de serie único */
            __uint32_t count;            /* Número de instancias */
            mmv_instances2_t *instances; /* IDs internos/externos */
            char *shorttext;             /* Texto de ayuda corto */
            char *helptext;              /* Texto de ayuda largo */
        } mmv_indom2_t;

VALORES DE RETORNO

Estas funciones devuelven la dirección de la región de memoria mapeada en caso de éxito. En caso de fallo, se devuelve NULL y errno se establece en un valor adecuado para ser decodificado con strerror(3).

VEA TAMBIÉN

mmv_stats_registry(3), mmv_lookup_value_desc(3), mmv_inc_value(3), strerror(3) y mmv(5).
