MMPFB(1) Manual de Comandos Generales MMPFB(1)

NOMBRE

mmpfb - crea fuentes de un solo maestro a partir de fuentes de múltiples maestros

SINOPSIS

mmpfb [OPCIONES...] fuente

DESCRIPCIÓN

Mmpfb crea una fuente PostScript normal de un solo maestro a partir de una fuente de múltiples maestros mediante interpolación. Le pasas una fuente PFB o PFA y opciones que especifican el punto de diseño que deseas; escribe la fuente PFB o PFA resultante a la salida estándar.

Las fuentes que crea mmpfb se interpolan a un nivel bajo para eliminar las instrucciones de múltiples maestros de los caracteres individuales. Por lo tanto, pueden ser utilizadas por programas que no comprenden normalmente las fuentes de múltiples maestros, como ps2pk(1).

Mmpfb admite fuentes con maestros intermedios, como Adobe Jenson y Kepler. También puede crear archivos AMCP (Adobe Multiple Master Conversion Program) para su uso por mmafm(1); consulte --amcp-info a continuación.

El argumento fuente es el nombre de un archivo de fuente PFA o PFB, o un nombre de fuente PostScript. Si proporcionas un nombre de fuente, mmpfb encontrará el archivo de contorno real utilizando la variable de entorno PSRESOURCEPATH. Esta ruta, separada por dos puntos, se busca en archivos `PSres.upr', un método de Adobe para indexar recursos PostScript.

También puedes dar el nombre de una instancia de fuente de múltiples maestros, como `MinionMM_367_400_12_'. Mmpfb analizará el nombre de la fuente y creará esa instancia para ti. Los archivos `PSres.upr' deben estar configurados para que esto funcione.

EJEMPLO

% mmpfb --weight=400 --width=600 MyriadMM.pfb > MyriadMM_400_600_.pfb

OPCIONES

Las opciones largas pueden abreviarse a sus prefijos únicos.

--output=archivo, -o archivo
Enviar la salida al archivo en lugar de a la salida estándar.
--pfb, -b
Generar una fuente PFB. Esta es la opción predeterminada.
--pfa, -a
Generar una fuente PFA.
--amcp-info
No crear una fuente; en su lugar, generar un archivo AMCP para su uso por mmafm(1). Se imprime un mensaje si la fuente no tiene maestros intermedios, en cuyo caso no es necesario ningún archivo AMCP.
--weight=N, -w N
Establecer el eje de peso en N.
--width=N, -W N
Establecer el eje de anchura en N.
--optical-size=N, -O N
Establecer el eje de tamaño óptico en N.
--style=N
Establecer el eje de estilo en N.
--1=N (--2=N, --3=N, --4=N)
Establecer el primer (segundo, tercer, cuarto) eje en N.
--precision=N, -p N
Establecer la precisión de salida en N. Valores más altos significan que los puntos de control en la fuente de salida estarán alineados de forma más exacta; valores más bajos (1 o 2) crean archivos de fuente de salida más pequeños y son lo suficientemente cercanos para la mayoría de los propósitos. Una precisión de N significa que cada punto estará a menos de 1/N unidades de fuente del valor interpolado exacto. (Una unidad de fuente es generalmente 1/7200 de pulgada para una fuente de 10 puntos.) El valor predeterminado es 5.
--subrs=N
Limitar la fuente de salida a un máximo de N subrutinas. 256 es un buen valor para N.
--no-minimize
No minimizar la definición de la fuente de salida. Por defecto, mmpfb elimina código PostScript y definiciones de diccionario adicionales de la fuente. Proporcione la opción --no-minimize para evitar este comportamiento.

SOLUCIÓN DE PROBLEMAS

El intérprete de fuentes Type 1 "IBM" que se distribuye como parte del servidor de fuentes X y ps2pk (entre otros) es inapropiadamente estricto con el código PostScript incrustado en una fuente. La opción --minimize (ahora predeterminada) soluciona este problema.

Algunas versiones de Adobe Acrobat Distiller pueden informar "Advertencia: no se puede incrustar la fuente X. Datos de contorno de caracteres no válidos" al destilar una instancia generada por mmpfb. Esto se debe a una limitación en el número de subrutinas de fuente que Distiller puede aceptar. (Las fuentes de múltiples maestros, y las fuentes de un solo maestro generadas por mmpfb, tienden a tener muchas subrutinas.) Intente limitar el número de subrutinas en la fuente generada con la opción --subrs.

VER TAMBIÉN

mmafm(1)

DIAGNÓSTICOS

reduciendo fuente al número mínimo de subrutinas (N)
Intentó reducir el número de subrutinas a menos de N usando la opción --subrs, pero la fuente necesita al menos N para funcionar. La fuente de salida tendrá N subrutinas.
