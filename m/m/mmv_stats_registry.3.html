MMV_STATS_REGISTRY(3) Manual de Funciones de Biblioteca MMV_STATS_REGISTRY(3)

NOMBRE

mmv_stats_registry, mmv_stats_start, mmv_stats_stop - Inicializa el archivo de valores mapeado en memoria

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/mmv_stats.h>

mmv_registry_t *mmv_stats_registry(const char *archivo,
int cluster, mmv_stats_flags_t flags);

void *mmv_stats_start(mmv_registry_t *registry);
void mmv_stats_stop(const char *fname,
void *addr);

cc ... -lpcp_mmv -lpcp

DESCRIPCIÓN

mmv_stats_registry inicializa una estructura opaca que define varios aspectos de un archivo mapeado en memoria. Este archivo se utiliza para la comunicación ligera entre procesos entre una aplicación instrumentada y pmdammv(1).

La interfaz mmv_stats_registry se utiliza para asignar un registro y permite establecer el nombre del archivo MMV(5), el identificador de cluster y las flags (si las hay). Devuelve un manejador que se utiliza en llamadas posteriores a la API de MMV al agregar métricas, indoms, instancias y etiquetas al registro, antes de crear realmente el archivo.

mmv_stats_start es la llamada que crea el archivo MMV(5) con el manejador devuelto por mmv_stats_registry. Devuelve el manejador de memoria mapeada utilizado en llamadas posteriores a la API de MMV, como mmv_inc_value(3).

mmv_stats_stop realiza un cierre ordenado del manejador de mapeo devuelto por una llamada de inicialización anterior y también libera la estructura del registro.

La combinación de mmv_stats_registry y mmv_stats_start hace lo mismo que las llamadas obsoletas mmv_stats2_init. Sin embargo, ahora, primero se debe llamar a mmv_stats_registry y luego a las llamadas a la API que agregan instancias, indoms, métricas y etiquetas. De esta manera, no es necesario saber de antemano qué versión del mapeo MMV (1|2|3) se utilizará, ya que se calcula automáticamente.

El archivo se crea en el directorio $PCP_TMP_DIR/mmv, se espera que el argumento nombre sea el nombre base del archivo, no la ruta completa. El contenido de metadatos del archivo no cambia después de que se ha creado el archivo.

El archivo antiguo se elimina incondicionalmente a menos que haya un error.

cluster es el ID de clúster PMDA de MMV preferido que se utilizará para las métricas que originan la llamada mmv_stats_start. Las flags proporcionan control adicional sobre el comportamiento del PMDA de MMV; por ejemplo, el uso de MMV_FLAG_PROCESS garantizará que los valores solo se exporten cuando la aplicación instrumentada esté en ejecución; esto se verifica en cada solicitud de nuevos valores.

Las siguientes secciones explican cómo agregar métricas, indoms, instancias y etiquetas.

AGREGAR MÉTRICAS

int mmv_stats_add_metric(mmv_registry_t *registry,
const char *nombre, int item, mmv_metric_type_t tipo, mmv_metric_sem_t sem, pmUnits unidades, int serie, const char *shorthelp, const char *longhelp);

Al agregar una métrica, internamente se maneja utilizando la siguiente estructura. sem coincide en la estructura son los semánticos. unidades coincide en la estructura son las dimensiones. serie coincide en la estructura es el indom.

        typedef struct {
            char *name;                 /* Nombre de la métrica */
            __uint32_t item;            /* Componente item del PMID */
            mmv_metric_type_t type;     /* Tipo de la métrica */
            mmv_metric_sem_t semantics; /* Semántica de la métrica */
            pmUnits dimension;          /* Dimensiones (TIEMPO, ESPACIO, etc.) */
            __uint32_t indom;           /* Identificador del dominio de instancia */
            char *shorttext;            /* Opcional, ayuda en una línea */
            char *helptext;             /* Opcional, texto de ayuda completo */
        } mmv_metric2_t;

AGREGAR INDOMS

int mmv_stats_add_indom(mmv_registry_t *registry,
int serie, const char *shorthelp, const char *longhelp);

Al agregar un indom, internamente se maneja utilizando la siguiente estructura.

        typedef struct {
            __uint32_t serial;           /* Número de serie único */
            __uint32_t count;            /* Número de instancias */
            mmv_instances2_t *instances; /* IDs internos/externos */
            char *shorttext;             /* Texto de ayuda corto */
            char *helptext;              /* Texto de ayuda largo */
        } mmv_indom2_t;

AGREGAR INSTANCIAS

int mmv_stats_add_instance(mmv_registry_t *registry,
int serie, int instid, const char *instname);

Al agregar una instancia, internamente se maneja utilizando la siguiente estructura. instid coincide en la estructura es interno mientras que instname es externo.

        typedef struct {
            __int32_t internal;
            char *external;
        } mmv_instances2_t;

Vale la pena mencionar que si no se encuentra el indom de la instancia, devuelve un error.

AGREGAR ETIQUETAS

int mmv_stats_add_registry_label(mmv_registry_t *registry,
const char *nombre, const char *valor, mmv_value_type_t tipo, int opcional);

int mmv_stats_add_indom_label(mmv_registry_t *registry,
int serie, const char *nombre, const char *valor, mmv_value_type_t tipo, int opcional);

int mmv_stats_add_metric_label(mmv_registry_t *registry,
int item, const char *nombre, const char *valor, mmv_value_type_t tipo, int opcional);

int mmv_stats_add_instance_label(mmv_registry_t *registry,
int serie, int instid, const char *nombre, const char *valor, mmv_value_type_t tipo, int opcional);

registry es el manejador obtenido de mmv_stats_registry. nombre y valor son las cadenas que formarán la etiqueta.

tipo especifica el tipo de valor que puede ser: MMV_STRING_TYPE, MMV_NUMBER_TYPE, MMV_BOOLEAN_TYPE, MMV_NULL_TYPE, MMV_ARRAY_TYPE y MMV_MAP_TYPE.

Por el momento hay una simple verificación de la corrección del valor. Después de agregar una etiqueta, se llama a una función para verificar si es correcta.

Adicionalmente, si opcional está configurado, se agrega la flag PM_LABEL_OPTIONAL.

serie es la serie del indom al agregar una etiqueta de indom o instancia. item es el identificador de métrica al agregar una etiqueta de métrica. Finalmente, al agregar una etiqueta de registro no es necesario proporcionar el ID del clúster porque se tomará de la estructura del registro interno ya creada.

mmv_stats_add_registry_label agrega un PM_LABEL_CLUSTER.

mmv_stats_add_indom_label agrega un PM_LABEL_INDOM.

mmv_stats_add_metric_label agrega un PM_LABEL_ITEM.

mmv_stats_add_instance_label agrega un PM_LABEL_INSTANCES.

VALORES DE RETORNO


Al agregar métricas, indoms, instancias y etiquetas, si es correcto devuelve 0
y si no, devuelve un código errno. Las otras funciones devuelven la dirección
de la región de memoria mapeada en caso de éxito. En caso de fallo, se devuelve NULL y
errno se establece en un valor adecuado para ser decodificado con strerror(3).
