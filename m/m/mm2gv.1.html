NOMBRE

mm2gv - Convertidores de Matrix Market a DOT

SINOPSIS

mm2gv [ -cluv? ] [ -Ui ] [ -oarchivo_salida ] [ archivo ]

DESCRIPCIÓN

mm2gv convierte una matriz dispersa del formato Matrix Market a un grafo en formato GV (anteriormente DOT). Si la matriz M no es cuadrada, el grafo se considera bipartito y la matriz se ve como una matriz de adyacencia de grafo bipartito, con las filas y columnas de la matriz especificando los dos conjuntos de vértices. Equivalentemente, la matriz se convierte en una matriz cuadrada simétrica

0 M
$M^{T}$ 0

una matriz de bloques con bloques cuadrados de 0's en la parte superior izquierda y la parte inferior derecha, siendo el bloque superior derecho M y el bloque inferior izquierdo la transpuesta de M. Esta matriz se ve luego como la matriz de adyacencia del grafo.

Para una matriz cuadrada, mm2gv la usa directamente como una matriz de adyacencia si su patrón de entradas distintas de cero es simétrico; de lo contrario, la tratará como un grafo bipartito, como en el caso de matrices no cuadradas. Este comportamiento se puede modificar con la opción -U.

OPCIONES

Se admiten las siguientes opciones:

-c
Esta bandera hace que mm2gv asigne colores a los bordes. El elemento de la matriz se escala al rango [0,1] dependiendo de dónde se encuentre entre los valores mínimo y máximo de la matriz establecida. Este valor escalado se utiliza como atributo "wt" del borde correspondiente. Además, este valor escalar se mapea a un valor RGB, que se almacena como el "color" del borde.
-l
Si se establece, mm2gv adjunta una etiqueta al grafo indicando el nombre base del archivo de entrada, y el número de nodos y bordes.
-u
Si se especifica, se asume que el grafo no está dirigido. Por defecto, el grafo generado está dirigido.
-v
Esta bandera hace que mm2gv almacene los valores de la matriz como el atributo "len" del borde correspondiente.
-Uindicador_b
Especifica cómo se manejan las matrices cuadradas. Si indicador_b es 0, una matriz cuadrada siempre se tratará como una matriz de adyacencia. Si indicador_b es 1 (el valor predeterminado), una matriz cuadrada con un patrón simétrico de entradas distintas de cero se usará como matriz de adyacencia; de lo contrario, se usará como un grafo bipartito. Si indicador_b es 2, una matriz simétrica se usará como matriz de adyacencia; de lo contrario, se usará como un grafo bipartito. Si indicador_b es 3, cualquier matriz de entrada se tratará como un grafo bipartito.
-oarchivo_salida
Imprime la salida en el archivo archivo_salida. Si no se proporciona, mm2gv usa la salida estándar.

OPERANDOS

Se admite el siguiente operando:

archivo
Nombre del archivo en formato MatrixMarket. Si no se especifica ningún operando archivo, se utilizará la entrada estándar.

CÓDIGOS DE RETORNO

Devuelve 0 si no hubo problemas durante la conversión; y un valor distinto de cero si ocurrió algún error.
