NOMBRE

mmdblookup - una utilidad para buscar una dirección IP en un archivo MaxMind DB

SINOPSIS

mmdblookup --file [RUTA_DEL_ARCHIVO] --ip [DIRECCIÓN_IP] [RUTA_DE_DATOS]

DESCRIPCIÓN

mmdblookup busca una dirección IP en el archivo MaxMind DB especificado. El registro de la dirección IP se muestra con {} para denotar mapas y [] para denotar arreglos. Los valores van seguidos de anotaciones de tipo. Esta salida *no* es JSON y no está diseñada para usarse como tal. Si necesita JSON, consulte mmdbinspect https://github.com/maxmind/mmdbinspect.

Si la entrada de datos de una IP se resuelve en un mapa o arreglo, puede proporcionar una ruta de búsqueda para mostrar solo una parte de esos datos.

Por ejemplo, dada una estructura JSON como esta:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

Podría buscar solo el nombre en inglés llamando a mmdblookup con una ruta de búsqueda de:

mmdblookup --file ... --ip ... names en

O podría buscar la segunda ciudad de la lista con:

mmdblookup --file ... --ip ... cities 1

La numeración de los arreglos comienza con cero (0).

Si no proporciona una ruta de búsqueda, se mostrará toda la información para una IP dada.

OPCIONES

Esta aplicación acepta las siguientes opciones:

-f, --file
La ruta al archivo MMDB. Requerido.
-i, --ip
La dirección IP a buscar. Requerido.
-v, --verbose
Activa la salida detallada. Específicamente, esto hace que esta aplicación muestre los metadatos de la base de datos.
--version
Imprime el número de versión del programa y sale.
-h, -?, --help
Muestra información de uso.
