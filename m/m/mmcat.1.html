NOMBRE

mmcat - Muestra el contenido de una partición en la salida estándar

SINOPSIS

mmcat [-t tipo_mm ] [-o desplazamiento ] [ -i tipo_img ] [-b tamaño_sector_dev] [-vV] imagen [imágenes] num_part

DESCRIPCIÓN

mmcat muestra el contenido de un volumen específico en la salida estándar. Esto te permite extraer el contenido de una partición a un archivo separado.

ARGUMENTOS

-t tipo_mm
Especifica el tipo de gestión de medios. Usa '-t list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento
Especifica el desplazamiento dentro de la imagen donde comienza el volumen que contiene el sistema de particiones. Se añadirá el desplazamiento relativo del sistema de particiones a este valor.
-b tamaño_sector_dev
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asume 512 bytes.
-i tipo_img
Identifica el tipo de archivo de imagen, como 'raw'. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-v
Salida detallada de sentencias de depuración a stderr
-V
Muestra la versión
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se indica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), se incluirán automáticamente los segmentos de imagen subsiguientes.
num_part
Dirección de la partición a procesar. Consulta la salida de mmls para determinar la dirección de las particiones.
