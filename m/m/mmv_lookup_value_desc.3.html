NOMBRE

mmv_lookup_value_desc - buscar un valor en el archivo Value Mapeado en Memoria

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/mmv_stats.h>

pmAtomValue *mmv_lookup_value_desc(void *addr,
const char *metric, const char *inst);

cc ... -lpcp_mmv -lpcp

DESCRIPCIÓN

mmv_lookup_value_desc busca el valor de la instancia identificada por el nombre de instancia externo inst de la métrica metric en el archivo MMV(5). addr es la dirección devuelta por mmv_stats_init().

El puntero devuelto apunta a una unión pmAtomValue, que se define de la siguiente manera:

    typedef union {
        __int32_t   l;      /* 32 bits con signo */
        __uint32_t  ul;     /* 32 bits sin signo */
        __int64_t   ll;     /* 64 bits con signo */
        __uint64_t  ull;    /* 64 bits sin signo */
        float       f;      /* punto flotante de 32 bits */
        double      d;      /* punto flotante de 64 bits */
        char         *cp;   /* puntero char */
	pmValueBlock *vbp;  /* puntero pmValueBlock */
    } pmAtomValue;

Los valores de cadena de MMV deben establecerse utilizando cualquiera de las rutinas mmv_set_string o mmv_set_strlen.

DEVUELVE

La función devuelve la dirección dentro de la región mapeada en memoria en caso de éxito o NULL en caso de fallo.

VER TAMBIÉN

mmv_stats_init(3), mmv_inc_value(3) y mmv(5).
