NOMBRE

mm-common-get - Copia archivos de mm-common a un módulo de enlace C++ que usa Meson

SINOPSIS

mm-common-get [OPCIÓN]... DIR-SCRIPT-DE-COMPILACION DIR-HERRAMIENTAS-DOCUMENTACION

DESCRIPCIÓN

Ejecute mm-common-get para copiar los archivos de soporte de compilación de mm-common al árbol de fuentes de un módulo de enlace C++.

OPCIONES

-f, --force
reemplazar forzosamente archivos existentes
--help
mostrar un mensaje de ayuda y salir
--version
mostrar información de versión y salir

CÓDIGO DE SALIDA

El código de salida es 0 si OK, o 1 si ocurrió un error.

ARCHIVOS

Los archivos de soporte de compilación copiados actualmente por mm-common-get se enumeran a continuación.

Scripts de compilación de Meson copiados a DIR-SCRIPT-DE-COMPILACION:
check-dllexport-usage.py
dist-build-scripts.py
dist-changelog.py
doc-reference.py
generate-binding.py
Utilidades de documentación copiadas a DIR-HERRAMIENTAS-DOCUMENTACION:
doc_install.py
doc_postprocess.py
doxygen.css
doxygen-extra.css
tagfile-to-devhelp2.xsl
