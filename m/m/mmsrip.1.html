NOMBRE

mmsrip - Extractor de MMS

SINOPSIS

mmsrip [-q] [-t] [-k] [-dRETRASO] [-gARCHIVO] <[-oARCHIVO] URL_del_stream> ...

DESCRIPCIÓN

mmsrip es un cliente para el protocolo propietario MMS://.

Guarda en un archivo el contenido que se está transmitiendo.

OPCIONES

-a, --about
Muestra información sobre mmsrip.
-dRETRASO, --delay=RETRASO
Guarda el stream durante RETRASO segundos y sale.
-gARCHIVO, --debug=ARCHIVO
Muestra información de depuración en el archivo especificado.
-h, --help
Muestra el mensaje de ayuda.
-k, --trick
Intenta engañar a servidores recalcitrantes enviando información local alternativa (mmsrip actuará como una versión antigua de MediaPlayer).
-oARCHIVO, --output=ARCHIVO
Envía el stream al archivo especificado. Esta opción debe repetirse antes de cada URL de stream.
-q, --quiet
Habilita el modo silencioso. Úsalo dos veces para eliminar también los mensajes de error.
-t, --test
Habilita el modo de prueba. mmsrip solo comprobará la disponibilidad del stream.
-v, --version
Muestra el número de versión.

CÓDIGOS DE ERROR

0
No ocurrió ningún error.
1
mmsrip no pudo extraer el stream (quizás la URL es incorrecta).
2
El stream no se extrajo por razones desconocidas. Por favor, intenta varias veces antes de rendirte, puedes escribir un script que se repita hasta que la extracción tenga éxito:
while mmsrip mms://servidor.com/stream.asf; do sleep 1; done
