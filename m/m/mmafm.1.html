MMAFM(1) Manual de Comandos Generales MMAFM(1)

NOMBRE

mmafm - crea métricas de fuentes AFM para fuentes multiple master

SINOPSIS

mmafm [OPCIONES...] fuente

DESCRIPCIÓN

Mmafm crea métricas de fuentes AFM para fuentes PostScript multiple master mediante interpolación. Le pasas un archivo AMFM (métricas de fuentes multiple master) y opciones que especifican el punto de diseño que deseas, y escribe el archivo AFM resultante en la salida estándar.

Cada argumento fuente es el nombre de archivo de un archivo de métricas de fuentes AFM o AMFM, o un nombre de fuente PostScript. Si das un nombre de fuente, mmafm buscará el archivo de métricas de fuentes real utilizando la variable de entorno PSRESOURCEPATH. Esta ruta, separada por dos puntos, se busca para encontrar archivos `PSres.upr', un método de Adobe para indexar recursos PostScript.

También puedes dar el nombre de una instancia de fuente multiple master, como `MinionMM_367_400_12_'. Mmafm analizará el nombre de la fuente y creará esa instancia por ti. Los archivos `PSres.upr' deben estar configurados para que esto funcione.

Cualquier fuente multiple master debe distribuirse con un único archivo AMFM y varios archivos AFM (uno por cada maestro). Para Myriad, por ejemplo, el archivo AMFM es MyriadMM.amfm y los archivos AFM son MyriadMM-LightCn.afm, MyriadMM-LightSemiEx.afm, MyriadMM-BlackCn.afm y MyriadMM-BlackSemiEx.afm. Mmafm necesita encontrar todos estos archivos para funcionar. Para fuentes de la biblioteca de tipos de Adobe, puedes descargar los archivos necesarios de http://www.lcdf.org/type; busca el paquete mm-metrics.

Siempre debes proporcionar el archivo AMFM (o su nombre de fuente) en la línea de comandos, pero mmafm buscará cualquier archivo AFM necesario que no proporciones tú mismo. Intenta con la variable de entorno PSRESOURCEPATH y también busca archivos llamados `NombreFuente.afm' o `NombreFuente.AFM' en el directorio que contenía el archivo AMFM. (Los nombres de archivo de Myriad dados arriba se ajustan a este patrón).

Mmafm soporta fuentes con maestros intermedios, como Adobe Jenson y Kepler. Si tu variable de entorno PSRESOURCEPATH está configurada, gestionará estas fuentes automáticamente. De lo contrario, primero debes ejecutar `mmpfb --amcp-info' en los archivos de contorno de la fuente para crear archivos AMCP auxiliares para estas fuentes. Cada archivo AMCP debe estar en el mismo directorio que su archivo AMFM correspondiente y debe tener el mismo nombre de archivo raíz, pero con una extensión `.amcp' en lugar de `.amfm'. Consulta mmpfb(1) para más información.

EJEMPLO

% mmafm --weight=400 --width=600 MyriadMM.amfm > MyriadMM_400_600_.afm

OPCIONES

Las opciones largas se pueden abreviar a sus prefijos únicos.

--output=archivo, -o archivo
Envía la salida al archivo en lugar de a la salida estándar.
--weight=N, -w N
Establece el eje de peso a N.
--width=N, -W N
Establece el eje de ancho a N.
--optical-size=N, -O N
Establece el eje de tamaño óptico a N.
--style=N
Establece el eje de estilo a N.
--1=N (--2=N, --3=N, --4=N)
Establece el primer (segundo, tercer, cuarto) eje a N.
--precision=N, -p N
Redondea los números de salida para que tengan como máximo N dígitos después del punto decimal. Los números más pequeños son menos precisos; `-p 0' redondea todos los números a enteros. La precisión predeterminada es 3.
--min-kern=N, -k N
Solo genera pares de kerning cuyo valor absoluto sea N o mayor. Los kerns mínimos más pequeños hacen el kerning más preciso y el archivo AFM de salida más grande. El kern mínimo predeterminado es 2.0.

SOLUCIÓN DE PROBLEMAS

Algunos programas, como fontinst de TeX, pueden fallar con archivos AFM que incluyen números fraccionarios. Por lo tanto, si tienes problemas con un archivo AFM, intenta ejecutar mmafm de nuevo con la opción --precision=0.
