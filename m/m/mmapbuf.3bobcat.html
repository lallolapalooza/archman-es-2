NOMBRE

FBB::MmapBuf - un std::streambuf usando mmap(2) para E/S de archivos

SINOPSIS

#include <bobcat/mmapbuf>

Opción de enlazado: -lbobcat

DESCRIPCIÓN

Las funciones mmap(2) mapean archivos en el espacio de direcciones virtuales del proceso que llama. Usar mmap en C++ es factible, pero complejo. La clase std::streambuf MmapBuf incrusta las características de mmap(2), permitiendo el uso de flujos de C++ en lugar de usar las llamadas mmap crudas. La clase FBB::Mmapbase define un std::streambuf que puede ser utilizado por objetos istream, ostream, e iostream.

Se lanzará una std::exception y se escribirá un mensaje de error en cerr si los detalles sobre el nombre de archivo especificado (ver sección CONSTRUCTORES no pueden ser determinados, o cuando mmap o munmap devuelvan errores.

NAMESPACE

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

HEREDA DE

CONSTRUCTORES

o
MmapBuf():
El constructor por defecto simplemente construye un objeto MmapBuf vacío. Para cambiarlo a un objeto utilizable, usa la asignación por movimiento;
o
MmapBuf(std::string const &fname, std::ios::openmode openMode, char const *bufSize = 0, mode_t mode = 0644):
El constructor inicializa el objeto MmapBuf para un archivo llamado fname. El openmode puede ser cualquier combinación de los valores de std::ios::openmode. Los valores requeridos suelen proporcionarse al construir objetos ImapStream, OmapStream, o IOmapStream (ver sección VER TAMBIÉN más abajo).
El parámetro openMode especifica cómo se usa fname. Los modos estándar ios::in, ios::out, ios::trunc, ios::app, y ios::ate son compatibles.
Por defecto, bfMmapBuf utiliza un tamaño de búfer de mapeo de 10 veces el tamaño de página estándar (ver sysconf(3) y el miembro pageSize más abajo). El tamaño del búfer de mapeo también se puede especificar usando el parámetro bufSize. Para especificarlo, usa un valor seguido de K, M, o G, que representan, respectivamente, 1024, 1024 * 1024 y 1024 * 1024 * 1024 bytes. El tamaño final del búfer es al menos igual al tamaño de página estándar. Cuando se especifica un valor mayor, el tamaño del búfer utilizado se establece en especificado / pageSize * pageSize.

El parámetro mode especifica el modo de acceso de usuario/grupo/otros que se utiliza cuando el archivo es creado por MmapBuf. Su valor por defecto especifica acceso de lectura/escritura para el usuario y acceso de lectura para otros. )

El constructor de movimiento y el operador de asignación de movimiento están disponibles.
El constructor de copia y el operador de asignación de copia no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::stringstream están disponibles, ya que FBB::MmapBuf hereda de esa clase.

o
size_t bufSize() const:
devuelve el tamaño del búfer t(mmap) utilizado;
o
size_t fileSize() const:
devuelve el tamaño del archivo utilizado. El tamaño se actualiza a uno mayor cuando se escribe más allá del tamaño actual del archivo. Una vez que los objetos MmapBuf dejan de existir, el tamaño del archivo utilizado se modifica al valor actual de fileSize. El tamaño de un archivo que solo se puede leer nunca se modifica.
o
size_t pageSize() const:
devuelve el tamaño de página más pequeño utilizado por t(mmap).
