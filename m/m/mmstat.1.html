MMSTAT(1) Manual de Comandos Generales MMSTAT(1)

NOMBRE

mmstat - Muestra detalles sobre el sistema de volúmenes (tablas de particiones)

SINOPSIS

mmstat [-t tipo_mm ] [-o desplazamiento ] [ -i tipo_img ] [-b tamaño_sectores_disp] [-vV] imagen [imágenes]

DESCRIPCIÓN

mmstat muestra los detalles generales de un sistema de volúmenes, que incluye tablas de particiones y etiquetas de disco. Principalmente, se proporciona el tipo.

ARGUMENTOS

-t tipo_mm
Especifica el tipo de gestión de medios. Usa '-t list' para listar los tipos soportados. Si no se proporciona, se usan métodos de autodetección.
-o desplazamiento
Especifica el desplazamiento dentro de la imagen donde comienza el volumen que contiene el sistema de particiones. El desplazamiento relativo del sistema de particiones se añadirá a este valor.
-b tamaño_sectores_disp
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asume 512 bytes.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se usan métodos de autodetección.
-v
Salida detallada de sentencias de depuración a stderr
-V
Muestra la versión
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se da con '-i'. Se pueden dar múltiples nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
