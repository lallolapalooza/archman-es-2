NOMBRE

mmls - Muestra el diseño de las particiones de un sistema de volúmenes (tablas de particiones)

SINOPSIS

mmls [-t tipo_mm ] [-o desplazamiento ] [ -i tipo_img ] [-b tamaño_sector_disp] [-BrvV] [-aAmM] imagen [imágenes]

DESCRIPCIÓN

mmls muestra el diseño de las particiones en un sistema de volúmenes, que incluye tablas de particiones y etiquetas de disco.

ARGUMENTOS

-t tipo_mm
Especifica el tipo de gestión de medios. Usa '-t list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento
Especifica el desplazamiento dentro de la imagen donde comienza el volumen que contiene el sistema de particiones. El desplazamiento relativo del sistema de particiones se añadirá a este valor.
-b tamaño_sector_disp
El tamaño, en bytes, de los sectores del dispositivo subyacente. Si no se proporciona, se utiliza el valor en el formato de imagen (si existe) o se asume 512 bytes.
-i tipo_img
Identifica el tipo de archivo de imagen, como raw. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-B
Incluye una columna con los tamaños de las particiones en bytes.
-r
Recorre las particiones DOS y busca otras tablas de particiones. Esta configuración ocurre frecuentemente cuando se instala Unix en sistemas x86.
-v
Salida detallada de las sentencias de depuración a stderr.
-V
Muestra la versión.
-a
Muestra volúmenes asignados.
-A
Muestra volúmenes no asignados.
-m
Muestra volúmenes de metadatos.
-M
Oculta volúmenes de metadatos.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen, y su nombre es el primero de una secuencia (por ejemplo, al terminar en '.001'), se incluirán automáticamente los segmentos de imagen subsiguientes.

´mmls´ es similar a 'fdisk -lu' en Linux con algunas diferencias. En concreto, mostrará qué sectores no se están utilizando para que puedan ser buscados en busca de datos ocultos. También proporciona el valor de longitud para que pueda ser insertado más fácilmente en 'dd' para extraer las particiones. También mostrará etiquetas de disco BSD para FreeBSD, OpenBSD y NetBSD y mostrará la salida en sectores y no en cilindros. Por último, funciona en sistemas que no son Linux.

Si no se proporciona ninguno de los argumentos -a, -A, -m o -M, entonces se listarán todos los tipos de volumen. Si se proporciona alguno de ellos, entonces solo se listarán los tipos especificados en la línea de comandos.

Los volúmenes asignados son aquellos que figuran en una tabla de particiones en el sistema de volúmenes Y pueden almacenar datos. Los volúmenes no asignados son creados virtualmente por mmls para mostrarle qué sectores no han sido asignados a un volumen. Los volúmenes de metadatos se superponen a los volúmenes asignados y no asignados y describen dónde se encuentran las tablas de particiones y otras estructuras de metadatos. En algunos sistemas de volúmenes, estas estructuras se encuentran en espacio asignado y en otros en espacio no asignado. En algunos sistemas de volúmenes, su ubicación se indica explícitamente en las tablas de particiones y en otros no.

EJEMPLOS

Para listar la tabla de particiones de un sistema Windows usando autodetección:

# mmls imagen_disco.dd

Para listar el contenido de un sistema BSD que comienza en el sector 12345 de una imagen dividida:

# mmls -t bsd -o 12345 -i split imagen-1.dd imagen-2.dd
