msr(4) Manual de Controladores de Dispositivos msr(4)

NOMBRE

msr - dispositivo de acceso a MSR de CPU x86

DESCRIPCIÓN

/dev/cpu/CPUNUM/msr proporciona una interfaz para leer y escribir los registros específicos del modelo (MSRs) de una CPU x86. CPUNUM es el número de la CPU a la que acceder, según se lista en /proc/cpuinfo.

El acceso al registro se realiza abriendo el archivo y buscando el número del MSR como desplazamiento en el archivo, y luego leyendo o escribiendo en bloques de 8 bytes. Una transferencia de E/S de más de 8 bytes significa lecturas o escrituras múltiples del mismo registro.

Este archivo está protegido de manera que solo puede ser leído y escrito por el usuario root, o miembros del grupo root.

NOTAS

El controlador msr no se carga automáticamente. En kernels modulares, es posible que necesite usar el siguiente comando para cargarlo explícitamente antes de su uso:


$ modprobe msr

VER TAMBIÉN

Intel Corporation Intel 64 and IA-32 Architectures Software Developer's Manual Volume 3B Appendix B, para una descripción general de los MSRs de CPU Intel.
