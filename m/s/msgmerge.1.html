MSGMERGE(1) Comandos de usuario MSGMERGE(1)

NOMBRE

msgmerge - fusionar catálogo de mensajes y plantilla

SINOPSIS

msgmerge [OPCIÓN] def.po ref.pot

DESCRIPCIÓN

Fusiona dos archivos .po de estilo Uniforum. El archivo def.po es un archivo PO existente con traducciones que se tomarán para el archivo recién creado siempre que sigan coincidiendo; se conservarán los comentarios, pero se descartarán los comentarios extraídos y las posiciones de archivo. El archivo ref.pot es el último archivo PO creado con referencias a fuentes actualizadas pero traducciones antiguas, o un archivo de plantilla PO (generalmente creado por xgettext); se descartarán todas las traducciones o comentarios en el archivo, sin embargo, se conservarán los comentarios de punto y las posiciones de archivo. Donde no se pueda encontrar una coincidencia exacta, se utilizará la coincidencia difusa para producir mejores resultados.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

def.po
traducciones que hacen referencia a fuentes antiguas
ref.pot
referencias a fuentes nuevas
-D, --directorio=DIRECTORIO
añade DIRECTORIO a la lista de búsqueda de archivos de entrada
-C, --compendio=ARCHIVO
biblioteca adicional de traducciones de mensajes, se puede especificar más de una vez

Modo de operación:

-U, --actualizar
actualiza def.po, no hace nada si def.po ya está actualizado

Ubicación del archivo de salida:

-o, --archivo-salida=ARCHIVO
escribe la salida al archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Ubicación del archivo de salida en modo de actualización: El resultado se escribe de nuevo en def.po.

--copia-seguridad=CONTROL
hace una copia de seguridad de def.po
--sufijo=SUFIJO
anula el sufijo de copia de seguridad habitual

El método de control de versiones se puede seleccionar mediante la opción --copia-seguridad o a través de la variable de entorno VERSION_CONTROL. Estos son los valores:

none, off
nunca hacer copias de seguridad (incluso si se da --copia-seguridad)
numbered, t
hacer copias de seguridad numeradas
existing, nil
numeradas si existen copias de seguridad numeradas, simples en caso contrario
simple, never
siempre hacer copias de seguridad simples

El sufijo de copia de seguridad es '~', a menos que se establezca con --sufijo o la variable de entorno SIMPLE_BACKUP_SUFFIX.

Modificadores de operación:

-m, --multi-dominio
aplica ref.pot a cada uno de los dominios en def.po
--para-msgfmt
produce salida para 'msgfmt', no para un traductor
-N, --sin-coincidencia-difusa
no usar coincidencia difusa
--anterior
mantener los msgids anteriores de los mensajes traducidos

Sintaxis del archivo de entrada:

-P, --entrada-propiedades
los archivos de entrada están en sintaxis de .properties de Java
--entrada-tabla-cadenas
los archivos de entrada están en sintaxis .strings de NeXTstep/GNUstep

Detalles de salida:

--idioma=NOMBRECATALOGO
establece el campo 'Language' en la entrada de encabezado
--color
usar colores y otros atributos de texto siempre
--color=CUANDO
usar colores y otros atributos de texto si CUANDO. CUANDO puede ser 'siempre', 'nunca', 'auto', o 'html'.
--estilo=ARCHIVESTILO
especifica el archivo de regla CSS para --color
-e, --sin-escapes
no usar escapes C en la salida (por defecto)
-E, --escapes
usar escapes C en la salida, sin caracteres extendidos
--forzar-po
escribe archivo PO incluso si está vacío
-i, --sangría
estilo de salida con sangría
--sin-ubicacion
suprimir líneas '#: nombrearchivo:línea'
-n, --añadir-ubicacion
conservar líneas '#: nombrearchivo:línea' (por defecto)
--estricto
estilo de salida estricto de Uniforum
-p, --salida-propiedades
escribe un archivo .properties de Java
--salida-tabla-cadenas
escribe un archivo .strings de NeXTstep/GNUstep
-w, --ancho=NÚMERO
establece el ancho de página de salida
--sin-salto-linea
no dividir líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --salida-ordenada
generar salida ordenada (obsoleto)
-F, --ordenar-por-archivo
ordenar la salida por ubicación de archivo

Salida informativa:

-h, --ayuda
muestra esta ayuda y sale
-V, --versión
muestra información de versión y sale
-v, --detallado
aumenta el nivel de verbosidad
-q, --silencioso, --callado
suprime los indicadores de progreso
