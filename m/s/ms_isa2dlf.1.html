NOMBRE

ms_isa2dlf - convierte registros del servidor ISA de Microsoft a DLF

SINOPSIS

ms_isa2dlf [archivo]

DESCRIPCIÓN

ms_isa2dlf convierte archivos de registro del servidor Microsoft Internet Security and Acceleration (ISA) en formato W3C Extended Log a formato DLF de proxy. Los archivos de registro de ISA se documentan en la sección "Campos de registro de proxy web y de firewall" en el documento "Microsoft Internet Security and Acceleration Server Enterprise Edition" en http://technet.microsoft.com/en-us/library/cc723430.aspx.

DEPURACIÓN

Como cualquier programa 2dlf de Lire, este programa necesita las variables LR_DBDIR, LR_DBFILE, LR_ID y PATH ajustadas. Estas se establecen en .../etc/lire/defaults y .../etc/lire/profile_lean. Después de ejecutar fuente de estos archivos manualmente, uno puede ejecutar este programa como una aplicación independiente, invocándolo, por ejemplo:

zcat ms_isa.log.gz | LR_ID=`date +%Y%m%d.%H%M%S` ./ms_isa2dlf > /tmp/dlf

.

EJEMPLOS

Para procesar un registro como el producido por el Servidor ISA de Microsoft:

$ ms_isa2dlf < ms_isa.log

ms_isa2dlf raramente se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report ms_isa < /var/log/ms_isa.log

AGRADECIMIENTOS

A Chainsaw en OPN irc, por proporcionar archivos de registro.
