MSGEN(1) Comandos de usuario MSGEN(1)

NOMBRE

msgen - crear catálogo de mensajes en inglés

SINOPSIS

msgen [OPCIÓN] ARCHIVO_ENTRADA

DESCRIPCIÓN

Crea un catálogo de traducción al inglés. El archivo de entrada es el último archivo PO en inglés creado, o un archivo Plantilla PO (generalmente creado por xgettext). Las entradas sin traducir reciben una traducción idéntica al msgid.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA
archivo PO o POT de entrada
-D, --directory=DIRECTORIO
añade DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si el archivo de entrada es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada está en sintaxis Java .properties
--stringtable-input
el archivo de entrada está en sintaxis NeXTstep/GNUstep .strings

Detalles de la salida:

--lang=NOMBRE_CATALOGO
establece el campo 'Language' en la entrada de cabecera
--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'always', 'never', 'auto', o 'html'.
--style=ARCHIVO_ESTILO
especifica el archivo de reglas CSS para --color
-e, --no-escape
no usa escapes C en la salida (por defecto)
-E, --escape
usa escapes C en la salida, sin caracteres extendidos
--force-po
escribe el archivo PO incluso si está vacío
-i, --indent
estilo de salida con sangría
--no-location
suprime las líneas '#: nombre_archivo:número_línea'
-n, --add-location
conserva las líneas '#: nombre_archivo:número_línea' (por defecto)
--strict
estilo de salida estricto de Uniforum
-p, --properties-output
escribe un archivo .properties de Java
--stringtable-output
escribe un archivo .strings de NeXTstep/GNUstep
-w, --width=NÚMERO
establece el ancho de página de salida
--no-wrap
no rompe las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --sort-output
genera salida ordenada
-F, --sort-by-file
ordena la salida por ubicación del archivo

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de versión y sale
