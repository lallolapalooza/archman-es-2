MSGCOMM(1) Comandos de usuario MSGCOMM(1)

NOMBRE

msgcomm - compara dos catálogos de mensajes

SINOPSIS

msgcomm [OPCIÓN] [ARCHIVO_ENTRADA]...

DESCRIPCIÓN

Encuentra mensajes que son comunes a dos o más de los archivos PO especificados. Usando la opción --more-than, se puede solicitar una mayor comunalidad antes de imprimir los mensajes. Inversamente, la opción --less-than se puede usar para especificar menos comunalidad antes de imprimir los mensajes (es decir, --less-than=2 solo imprimirá los mensajes únicos). Las traducciones, comentarios y comentarios extraídos se conservarán, pero solo del primer archivo PO que los defina. Las posiciones de archivo de todos los archivos PO se acumularán.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA ...
archivos de entrada
-f, --files-from=ARCHIVO
obtener la lista de archivos de entrada de ARCHIVO
-D, --directory=DIRECTORIO
agregar DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si el archivo de entrada es -, se leerá la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribir la salida al archivo especificado

Los resultados se escribirán en la salida estándar si no se especifica ningún archivo de salida o si es -.

Selección de mensajes:

-<, --less-than=NUMERO
imprimir mensajes con menos de esta cantidad de definiciones, por defecto infinito si no se establece
->, --more-than=NUMERO
imprimir mensajes con más de esta cantidad de definiciones, por defecto 1 si no se establece
-u, --unique
atajo para --less-than=2, solicita que solo se impriman mensajes únicos

Sintaxis del archivo de entrada:

-P, --properties-input
los archivos de entrada tienen la sintaxis Java .properties
--stringtable-input
los archivos de entrada tienen la sintaxis NeXTstep/GNUstep .strings

Detalles de salida:

--color
usar colores y otros atributos de texto siempre
--color=CUANDO
usar colores y otros atributos de texto si CUANDO. CUANDO puede ser 'siempre', 'nunca', 'auto' o 'html'.
--style=ARCHIVO_ESTILO
especificar archivo de reglas CSS para --color
-e, --no-escape
no usar escapes C en la salida (por defecto)
-E, --escape
usar escapes C en la salida, sin caracteres extendidos
--force-po
escribir archivo PO incluso si está vacío
-i, --indent
escribir el archivo .po usando estilo indentado
--no-location
no escribir líneas '#: nombre_archivo:línea'
-n, --add-location
generar líneas '#: nombre_archivo:línea' (por defecto)
--strict
escribir un archivo .po que cumpla estrictamente con Uniforum
-p, --properties-output
escribir un archivo Java .properties
--stringtable-output
escribir un archivo NeXTstep/GNUstep .strings
-w, --width=NUMERO
establecer el ancho de página de salida
--no-wrap
no dividir líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --sort-output
generar salida ordenada
-F, --sort-by-file
ordenar la salida por la ubicación del archivo
--omit-header
no escribir encabezado con la entrada 'msgid ""'

Salida informativa:

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir
