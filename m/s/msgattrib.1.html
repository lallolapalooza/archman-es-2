MSGATTRIB(1) Comandos de usuario MSGATTRIB(1)

NOMBRE

msgattrib - manipulación y coincidencia de atributos en catálogos de mensajes

SINOPSIS

msgattrib [OPCIÓN] [ARCHIVO_ENTRADA]

DESCRIPCIÓN

Filtra los mensajes de un catálogo de traducción según sus atributos y manipula los atributos.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA
archivo PO de entrada
-D, --directory=DIRECTORIO
añade DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica un archivo de salida o si es -.

Selección de mensajes:

--translated
mantener mensajes traducidos, eliminar mensajes no traducidos
--untranslated
mantener mensajes no traducidos, eliminar mensajes traducidos
--no-fuzzy
eliminar mensajes marcados como 'fuzzy'
--only-fuzzy
mantener mensajes marcados como 'fuzzy'
--no-obsolete
eliminar mensajes obsoletos #~
--only-obsolete
mantener mensajes obsoletos #~

Manipulación de atributos:

--set-fuzzy
establecer todos los mensajes como 'fuzzy'
--clear-fuzzy
establecer todos los mensajes como no 'fuzzy'
--set-obsolete
establecer todos los mensajes como obsoletos
--clear-obsolete
establecer todos los mensajes como no obsoletos
--previous
al establecer 'fuzzy', mantener los msgids anteriores de los mensajes traducidos.
--clear-previous
eliminar el "msgid anterior" de todos los mensajes
--empty
al eliminar 'fuzzy', también establecer msgstr vacío
--only-file=ARCHIVO.po
manipular solo las entradas listadas en ARCHIVO.po
--ignore-file=ARCHIVO.po
manipular solo las entradas no listadas en ARCHIVO.po
--fuzzy
sinónimo de --only-fuzzy --clear-fuzzy
--obsolete
sinónimo de --only-obsolete --clear-obsolete

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada tiene sintaxis Java .properties
--stringtable-input
el archivo de entrada tiene sintaxis NeXTstep/GNUstep .strings

Detalles de salida:

--color
usar colores y otros atributos de texto siempre
--color=CUÁNDO
usar colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'always' (siempre), 'never' (nunca), 'auto' (automático), o 'html'.
--style=ARCHIVO_ESTILO
especificar archivo de reglas CSS para --color
-e, --no-escape
no usar escapes C en la salida (predeterminado)
-E, --escape
usar escapes C en la salida, sin caracteres extendidos
--force-po
escribir archivo PO aunque esté vacío
-i, --indent
escribir el archivo .po usando estilo con sangría
--no-location
no escribir líneas '#: nombre_archivo:línea'
-n, --add-location
generar líneas '#: nombre_archivo:línea' (predeterminado)
--strict
escribir un archivo .po que cumpla estrictamente con Uniforum
-p, --properties-output
escribir un archivo Java .properties
--stringtable-output
escribir un archivo NeXTstep/GNUstep .strings
-w, --width=NÚMERO
establecer el ancho de página de salida
--no-wrap
no dividir líneas de mensajes largas, mayores que el ancho de página de salida, en varias líneas
-s, --sort-output
generar salida ordenada
-F, --sort-by-file
ordenar la salida por ubicación del archivo

Salida informativa:

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir
