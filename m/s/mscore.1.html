MSCORE(1) Manual de Comandos Generales MSCORE(1)

NOMBRE

mscore, musescore — Editor de partituras musicales MuseScore 4

SINOPSIS

mscore [-deFfhIiLmnOPRstvw] [-b | --bitrate tasa de bits] [-c | --config-folder ruta] [-D | --monitor-resolution DPI] [-E | --install-extension archivo de extensión] [-j | --job archivo.json] [-M | --midi-operations archivo] [-o | --export-to archivo] [-p | --plugin nombre] [-r | --image-resolution DPI] [-S | --style estilo] [-T | --trim-image margen] [-x | --gui-scaling factor] [--debug] [--diff] [--dump-midi-in] [--dump-midi-out] [--experimental] [--export-score-parts] [--factory-settings] [--force] [--help] [--layout-debug] [--load-icons] [--long-version] [--new-score] [--no-fallback-font] [--no-midi] [--no-synthesizer] [--raw-diff] [--revert-settings] [--run-test-script] [--save-online] [--score-media] [--highlight-config] [--score-mp3] [--score-parts] [--score-parts-pdf] [--score-transpose] [--template-mode] [--test-mode] [--transpose] [--version] [archivo ...]

DESCRIPCIÓN

MuseScore es un software de composición y notación musical multiplataforma, multilingüe, WYSIWYG, libre y de código abierto, publicado bajo la Licencia Pública General de GNU (GPLv2).

Ejecutar mscore sin opciones adicionales lanza el programa completo de MuseScore gráfico y abre cualquier archivo especificado en la línea de comandos.

Las opciones son las siguientes:

-b | --bitrate tasa de bits
Establece la tasa de bits de salida MP3 en kbit/s
-c | --config-folder ruta
Anula el directorio de configuración y ajustes
-D | --monitor-resolution DPI
Especifica la resolución del monitor (anula la autodetección)
-d | --debug
Inicia MuseScore en modo de depuración
-E | --install-extension archivo de extensión
Instala un archivo de extensión; las soundfonts se cargan por defecto a menos que también se especifique -e
-e | --experimental
Habilita funciones experimentales, como capas
-F | --factory-settings
Revierte todos los ajustes, atajos, espacios de trabajo, extensiones, traducciones, etc. a los valores predeterminados de fábrica; comparar con la opción -R
-f | --force
Ignora las advertencias de corrupción de partitura y discrepancia de versión en el "modo conversor"
-h | --help
Muestra un resumen de las instrucciones de invocación
-I | --dump-midi-in
Muestra toda la entrada MIDI en la consola
-i | --load-icons
Carga iconos desde el sistema de archivos; útil si deseas editar los iconos de MuseScore y previsualizar los cambios
-j | --job archivo.json
Procesa un trabajo de conversión (ver EJEMPLOS a continuación)
-L | --layout-debug
Inicia MuseScore en modo de depuración de diseño
-M | --midi-operations archivo
Especifica el archivo de operaciones de importación MIDI (ver EJEMPLOS a continuación)
-m | --no-midi
Deshabilita la entrada MIDI
-n | --new-score
Inicia con el asistente de Nueva Partitura independientemente de si está habilitado o deshabilitado en las preferencias del usuario
-O | --dump-midi-out
Muestra toda la salida MIDI en la consola
-o | --export-to archivo
Exporta el archivo dado (o el actualmente abierto) al archivo de salida especificado. El tipo de archivo depende de la extensión del nombre de archivo dado. Esta opción cambia al "modo conversor" y evita la interfaz gráfica de usuario.
-P | --export-score-parts
Al convertir a PDF con la opción -o, adjunta las páginas de cada parte al archivo PDF creado. Si la partitura no tiene partes, todas las partes predeterminadas se generarán temporalmente de forma automática.
-p | --plugin nombre
Ejecuta el plugin con el nombre especificado
-R | --revert-settings
Revierte las preferencias del usuario a los valores predeterminados de fábrica pero conserva los atajos, espacios de trabajo, extensiones, traducciones, etc.; comparar con -F.
-r | --image-resolution

EJEMPLOS

Convertir un archivo .mscz a PDF:

mscore -o score.pdf score.mscz

Convertir un archivo .mscx a PNG con una resolución de 300 DPI:

mscore -o score.png -r 300 score.mscx

Convertir un archivo .mscx a un archivo MIDI:

mscore -o score.mid score.mscx

Convertir una partitura con todas sus partes a PDF:

mscore -o full_score.pdf -P score.mscz

Revertir todos los ajustes a los valores predeterminados de fábrica:

mscore -F

Revertir solo las preferencias del usuario a los valores predeterminados de fábrica:

mscore -R

Ejecutar un trabajo de conversión de un archivo JSON:

mscore -j jobs.json

Importar un archivo MIDI especificando operaciones de transposición y tempo en un archivo de operaciones:

mscore -M midi_ops.json -o score_imported.mscx input.mid

Instalar un archivo de extensión:

mscore -E my_extension.qml

Formato JSON del trabajo de conversión por lotes

El argumento de la opción -j debe ser la ruta de un archivo que contenga un documento JSON válido que cumpla con la siguiente especificación:

  • El elemento de nivel superior debe ser un JSONArray, que puede estar vacío.
  • Cada elemento de la matriz debe ser un JSONObject con las siguientes claves:
    in
    El valor es el nombre del archivo de entrada (partitura a convertir), como JSONString.
    plugin
    El valor es el nombre de archivo de un plugin (con la extensión .qml), que se leerá de la ruta de plugins global o por usuario y se ejecutará antes de la salida de conversión, como JSONString. Opcional, pero se debe proporcionar al menos una de las opciones plugin o out.
    out
    El valor es el destino de la salida de conversión, como se define a continuación. Opcional, pero se debe proporcionar al menos una de las opciones plugin o out.
    transpose
    El valor es una JSONString con las opciones de transposición. Opcional.
  • El destino de la salida de conversión puede ser un nombre de archivo (con extensión, que decide el formato a convertir), como JSONString.
  • El destino de la salida de conversión puede ser un JSONArray de nombres de archivo como JSONString, como se describe anteriormente, lo que hará que la partitura se escriba en varios archivos de salida (en varios formatos de salida) secuencialmente, sin cerrarse, volver a abrirse y volver a procesarse en el medio.
  • Si el destino de la salida de conversión es un JSONArray, uno o más de sus elementos también pueden ser, cada uno, un JSONArray de dos JSONStrings (llamados primera y segunda mitad en la siguiente descripción). Esto provocará la extracción de partes: para cada tupla de dos elementos de este tipo, todas las partes existentes de la partitura se guardarán individualmente, con nombres de archivo compuestos por la concatenación de la primera mitad, el nombre (título) de la parte y la segunda mitad. La cadena resultante debe ser un nombre de archivo válido (con extensión, que determina el formato de salida). Si una partitura no tiene partes (extractos) definidas, esto se ignorará silenciosamente sin errores.
  • Las extensiones de archivo válidas para la salida son:
    flac
    Free Lossless Audio Codec (audio comprimido)
    metajson
    varios metadatos de partitura (JSON)
    mid
    archivo MIDI estándar
    midi
    archivo MIDI estándar
    mlog
    registro interno de verificación de coherencia de archivos (JSON)
    mp3
    MPEG Layer III (audio comprimido con pérdida)
    mpos
    posiciones de compás (XML)
    mscz
    Archivo MuseScore
    mscx
    Archivo sin comprimir de MuseScore
    mscs
    Archivo sin comprimir de MuseScore
    musicxml
    archivo MusicXML sin comprimir
    mxl
    archivo MusicXML comprimido
    ogg
    OGG Vorbis (audio comprimido con pérdida)
    pdf
    archivo de documento portátil (impresión)
    png
    gráficos de red portátiles (imagen)

    Se generarán archivos individuales, uno por página de partitura, con un guion seguido del número de página colocado antes de la extensión del archivo.

    spos
    posiciones de segmento (XML)
    svg
    gráficos vectoriales escalables (imagen)
    wav
    RIFF Waveform (audio sin comprimir)
    xml
    archivo MusicXML sin comprimir

Ver más abajo para un ejemplo.

NOMBRE

mscore — utilidad de línea de comandos de MuseScore

SINOPSIS

mscore [options] file.mscz

mscore -j job.json

DESCRIPCIÓN

mscore es la utilidad de línea de comandos de MuseScore. Permite exportar partituras a varios formatos de archivo, realizar operaciones por lotes y más, sin necesidad de la interfaz gráfica de usuario. Útil para la automatización y la conversión de archivos.

Cuando se llama sin la opción -j, mscore espera un nombre de archivo de partitura en file.mscz como argumento final. Si la exportación es exitosa, se creará un archivo en el directorio de trabajo actual, con el mismo nombre base que el archivo de entrada, pero con una extensión de archivo diferente para el formato de salida especificado por la opción -o. Si no se especifica la opción -o, el formato de salida se determinará por defecto a PDF.

Para operaciones por lotes, la opción -j toma un archivo JSON que contiene una lista de trabajos. Cada trabajo en la lista es un objeto JSON que especifica un archivo de entrada, uno o más archivos de salida y operaciones opcionales como la transposición o la ejecución de un plugin. Ver la sección EXAMPLES para obtener más detalles sobre el formato de archivo JSON.

AMBIENTE

MuseScore busca los archivos de configuración y los datos de soporte en una variedad de ubicaciones. Los directorios de configuración de usuario y datos se determinan a partir de las variables de entorno XDG_CONFIG_HOME y XDG_DATA_HOME, respectivamente. Si estas variables no están establecidas, los valores predeterminados son ~/.config/ y ~/.local/share/. La aplicación también puede leer la configuración del usuario desde $XDG_CONFIG_HOME/musescore/ y $XDG_DATA_HOME/musescore/. Las versiones de desarrollo usan $XDG_CONFIG_HOME/MuseScoreDevelopment/ y $XDG_DATA_HOME/MuseScoreDevelopment/.

Los directorios de documentos de usuario, música y descargas se determinan a partir de las variables de entorno XDG_DOCUMENTS_DIR, XDG_MUSIC_DIR y XDG_DOWNLOADS_DIR, respectivamente. Si estas variables no están establecidas, los valores predeterminados son ~/Documents/, ~/Music/ y ~/Downloads/. La aplicación puede usar estos directorios para almacenar partituras y otros archivos relacionados con el usuario, organizados bajo subdirectorios como MuseScore3/. Para las versiones de desarrollo, se utiliza MuseScore3Development/.

MuseScore también admite las variables de entorno normales de Qt, como QT_QPA_GENERIC_PLUGINS, QT_QPA_PLATFORM, QT_QPA_PLATFORMTHEME, QT_QPA_PLATFORM_PLUGIN_PATH, QT_STYLE_OVERRIDE, DISPLAY, etc.

ARCHIVOS

/usr/share/mscore-4.5/ contiene los datos de soporte de la aplicación (demos, instrumentos, localización, plugins del sistema, soundfonts, estilos, acordes, plantillas y fondos de pantalla). En los paquetes de Debian, los soundfonts del sistema se instalan en /usr/share/sounds/sf2/, /usr/share/sounds/sf3/ o /usr/share/sounds/sfz/, respectivamente, en su lugar.

Los datos por usuario (extensiones, plugins, soundfonts, estilos, plantillas) y archivos (imágenes, partituras) normalmente se instalan en subdirectorios bajo $XDG_DOCUMENTS_DIR/MuseScore3/ pero pueden cambiarse en la configuración. Tenga en cuenta que las versiones snapshot, alpha y beta utilizan MuseScore3Development en lugar de MuseScore3 en todas estas rutas.

$XDG_CONFIG_HOME/MuseScore/MuseScore3.ini contiene las preferencias del usuario, la lista de archivos usados recientemente y sus ubicaciones, tamaños y posiciones de ventana, etc. Ver arriba para las rutas de la versión de desarrollo.

$XDG_DATA_HOME/MuseScore/MuseScore3/ contiene archivos de localización actualizados descargados desde dentro del programa, información de plugins, partituras cacheadas, credenciales para el sitio de la comunidad musescore.com, información de sesión, configuraciones del sintetizador y atajos de teclado y compás personalizados. Ver arriba para las rutas de la versión de desarrollo.

EJEMPLOS

Convertir una partitura a PDF desde la línea de comandos:

mscore -o 'Mi Partitura.pdf' 'Mi Partitura.mscz'

Transponer y luego convertir una partitura a PDF desde la línea de comandos:

-o 'Mi Partitura Transpuesta.pdf' --transpose '{"mode": "by_interval",
"direction": "up", "transposeInterval": 12,
"transposeKeySignatures": true}' 'Mi Partitura.mscz'

Transponer a otra partitura desde la línea de comandos:

-o 'Mi Partitura Transpuesta.mscz' --transpose '{"mode": "diatonically",
"direction": "down", "transposeInterval": 3,
"useDoubleSharpsFlats": true}' 'Mi Partitura.mscz'

Ejecutar un trabajo por lotes convirtiendo múltiples documentos:

mscore -j job.json

Esto requiere que el archivo job.json en el directorio de trabajo actual tenga un contenido similar al siguiente:

[
  {
    "in": "Reunion.mscz",
    "out": "Reunion-coloured.pdf",
    "plugin": "colornotes.qml"
  },
  {
    "in": "Reunion.mscz",
    "out": [
      "Reunion.pdf",
      [ "Reunion (part for ", ").pdf" ],
      "Reunion.musicxml",
      "Reunion.mid"
    ]
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposed.mscz",
    "transpose":
	{
	  "mode": "by_interval",
	  "direction": "up",
	  "transposeInterval": 12,
	  "transposeKeySignatures": true
	}
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposed.pdf",
    "transpose":
	{
	  "mode": "diatonically",
	  "direction": "down",
	  "transposeInterval": 2,
	  "useDoubleSharpsFlats": true
	}
  },
  {
    "in": "Piece with excerpts.mscz",
    "out": [
      "Piece with excerpts (Partitura).pdf",
      [ "Piece with excerpts (part for ", ").pdf" ],
      "Piece with excerpts.mid"
    ]
  }
]

La última parte del trabajo, por ejemplo, provocaría la generación de archivos como “Piece with excerpts (part for Violin).pdf” junto con la partitura del director y un archivo MIDI con el sonido de la orquesta completa, mientras que la parte equivalente de la conversión de Reunion se ignoraría silenciosamente (porque la pieza de Reunion (una demo de MuseScore) no tiene extractos definidos).

https://musescore.org/sites/musescore.org/files/midi_import_options_0.xml es un archivo de ejemplo de operaciones de importación MIDI para la opción -M.

DIAGNÓSTICOS

La utilidad mscore sale con código 0 en caso de éxito y >0 si ocurre un error.

ESTANDARES

MuseScore intenta implementar los siguientes estándares:

  • MusicXML 4.0 (formato de intercambio de partituras)
  • SF2 (SoundFont 2.01)
  • SF3 (SoundFont con muestras comprimidas en OGG Vorbis)
  • SMuFL (Standard Music Font Layout 1.4)

ADVERTENCIAS

Las opciones de línea de comandos automáticas de Qt se eliminan del vector de argumentos antes de que la aplicación tenga la oportunidad de procesar las opciones; esto significa que una invocación como

mscore -S -reverse

no tiene posibilidad de funcionar porque Qt elimina -reverse primero.

ERRORES

MuseScore no respeta /etc/papersize.

Probablemente algunos más; consulte el rastreador de errores del proyecto (cf. VER TAMBIÉN).
