MSCP(1) Comandos de usuario MSCP(1)

NOMBRE

mscp - copia archivos a través de múltiples conexiones SSH

SINOPSIS

mscp [-46vqDpdNh] [-n NR_CONEXIONES] [-m MASCARA_CORES] [-u MAX_ARRANQUES] [-I INTERVALO] [-W PUNTO_CONTROL] [-R PUNTO_CONTROL] [-s TAMANO_MIN_BLOQUE] [-S TAMANO_MAX_BLOQUE] [-a NR_ADELANTE] [-b TAMANO_BUFFER] [-L LIMITE_TASA_BITS] [-l NOMBRE_INICIO_SESION] [-P PUERTO] [-F CONFIG_SSH] [-o OPCION_SSH] [-i IDENTIDAD] [-J DESTINO] [-c CIFRADO] [-M HMAC] [-C COMPRESION] [-g CONGESTION] fuente ... destino

DESCRIPCIÓN

mscp copia archivos a través de múltiples conexiones SSH (SFTP) mediante múltiples hilos. Permite transferir (1) múltiples archivos simultáneamente y (2) un archivo grande en paralelo, reduciendo el tiempo de transferencia para muchos/grandes archivos en redes.

El uso de mscp sigue el comando scp de OpenSSH, por ejemplo:

    $ mscp srcfile usuario@ejemplo.com:dstfile

Los hosts remotos solo necesitan ejecutar sshd estándar que soporte el subsistema SFTP, y los usuarios deben poder hacer ssh a los hosts como de costumbre. mscp no requiere nada más.

mscp utiliza libssh como su implementación SSH. Por lo tanto, las características SSH soportadas, por ejemplo, autenticación, cifrado y varias opciones en ssh_config, siguen lo que soporta libssh.

OPCIONES

-n NR_CONEXIONES
Especifica el número de conexiones SSH. El valor por defecto se calcula a partir del número de núcleos de CPU en el host con la siguiente fórmula: floor(log(nr_cores)*2)+1.
-m MASCARA_CORES
Configura los núcleos de CPU a utilizar mediante la máscara de bits hexadecimal. Por ejemplo, -m 0x25 fija hilos a los núcleos de CPU 0, 2 y 5. El valor por defecto no está especificado: se utilizan todos los núcleos de CPU y ningún hilo está fijado a ningún núcleo.
-u MAX_ARRANQUES
Especifica el número de intentos de conexión SSH concurrentes sin autenticación. sshd limita el número de intentos de conexión SSH simultáneos por MaxStartups en sshd_config. El valor por defecto de MaxStartups es 10; por lo tanto, establecemos MAX_STARTUPS por defecto en 8.
-I INTERVALO
Especifica el intervalo (en segundos) entre intentos de conexión SSH. Algunos productos de firewall tratan los intentos de conexión SSH desde una única dirección IP de origen durante un corto período como un ataque de fuerza bruta. Esta opción inserta intervalos entre los intentos para evitar ser determinado como un ataque. El valor por defecto es 0.
-W PUNTO_CONTROL
Especifica un archivo de punto de control para guardar el estado de una transferencia fallida. Cuando la transferencia falla debido a, por ejemplo, interrupción de la conexión o interrupción del usuario, mscp escribe la información sobre los archivos restantes y los bloques en el archivo de punto de control especificado. La opción -W con -D (modo de prueba) solo escribe un archivo de punto de control y sale.
-R PUNTO_CONTROL
Especifica un archivo de punto de control para reanudar una transferencia. Cuando se proporciona un archivo de punto de control, mscp lee el punto de control para cargar un host remoto, la dirección de copia y los archivos y sus bloques a transferir. Es decir, mscp puede reanudar una transferencia fallida anterior desde el punto de control. Reanudar con un punto de control no requiere los argumentos fuente ... destino. Otras opciones de conexión SSH, como el número de puerto y el archivo de configuración, deben especificarse como en la ejecución fallida. Además, los archivos de punto de control tienen rutas de archivo como rutas relativas. Por lo tanto, debe ejecutar mscp en el mismo directorio de trabajo que la ejecución fallida. Puede ver el contenido de un archivo de punto de control con el comando mscp -vv -D -R PUNTO_CONTROL (Modo de prueba). Tenga en cuenta que el archivo de punto de control no se elimina automáticamente después de que la transferencia reanudada finalice con éxito. Los usuarios deben verificar el valor de retorno de mscp y eliminar el punto de control si devuelve 0.
-s TAMANO_MIN_BLOQUE
Especifica el tamaño mínimo del bloque. mscp divide un solo archivo en bloques y copia los bloques en paralelo. El valor por defecto es 16M bytes.
-S TAMANO_MAX_BLOQUE
Especifica el tamaño máximo del bloque. El valor por defecto es el tamaño del archivo dividido por el número de conexiones y dividido por 4. Si el valor calculado es menor que el valor de TAMANO_MIN_BLOQUE, se usa TAMANO_MIN_BLOQUE.
-a NR_ADELANTE
Especifica el número de comandos SFTP en curso. El valor por defecto es 32.
-b TAMANO_BUFFER
Especifica el tamaño del búfer para E/S y transferencia sobre SFTP. El valor por defecto es 16384. Tenga en cuenta que la especificación SSH restringe el tamaño del búfer entregado sobre SSH. No se recomienda cambiar este valor en la actualidad.
-L LIMITE_TASA_BITS
Limita la tasa de bits, especificada con k (K), m (M) y g (G), por ejemplo, 100m indica 100 Mbps.
-4
Utiliza solo direcciones IPv4.
-6
Utiliza solo direcciones IPv6.
-v
Incrementa el nivel de salida detallado.
-q
Modo silencioso: desactiva toda la salida.
-D
Modo de prueba: escanea los archivos de origen a copiar, calcula los bloques, resuelve las rutas de los archivos de destino y sale. El modo de prueba con la opción -vv puede confirmar los archivos a copiar y sus rutas de destino.
-r
Sin efecto. mscp copia recursivamente si una ruta de origen es un directorio. Esta opción existe solo por compatibilidad.
-l NOMBRE_INICIO_SESION
Especifica el nombre de usuario para iniciar sesión en la máquina remota como con ssh(1).
-P PUERTO
Especifica el número de puerto al que conectarse en la máquina remota como con scp(1).
-F CONFIG_SSH
Especifica un archivo de configuración ssh alternativo por usuario. Tenga en cuenta que las opciones aceptables en el archivo de configuración son las que soporta libssh.
-o OPCION_SSH
Especifica opciones ssh en el formato utilizado en ssh_config. Tenga en cuenta que las opciones aceptables son las que soporta libssh.
-i IDENTIDAD
Especifica el archivo de identidad para la autenticación de clave pública.
-J DESTINO
Un atajo para definir una directiva de configuración ProxyJump. Cada sesión SFTP de mscp se conecta al host de destino haciendo primero una conexión ssh al host de salto descrito por destino.
-c CIFRADO
Selecciona el cifrado a utilizar para cifrar la transferencia de datos. Consulte mscp -h o Ciphers en características de libssh.
-M HMAC
Especifica algoritmos de hash MAC. Consulte mscp -h o MAC hashes en características de libssh.
-C COMPRESION
Habilita la compresión: sí, no, zlib, zlib@openssh.com. El valor por defecto es ninguno. Consulte características de libssh.
-g CONGESTION
Especifica el algoritmo de control de congestión TCP a utilizar (solo Linux). Consulte sysctl net.ipv4.tcp_allowed_congestion_control para ver los valores disponibles.

NAME

mscp - multi-threaded scp for fast file transfer

SYNOPSIS

mscp [-acdefgimn] [-o ssh_option] [-P port] [-p] [-W file] source ... destination

mscp [-acdefgimn] [-o ssh_option] [-P port] [-p] [-W file] [-] source ... user@host:destination

mscp [-acdefgimn] [-o ssh_option] [-P port] [-p] [-W file] user@host:source ... destination

DESCRIPTION

mscp is a multi-threaded implementation of the scp command, designed to maximize file transfer speed over SSH. It utilizes multiple SSH connections to transfer files in parallel, significantly improving performance on high-latency or high-bandwidth networks.

OPTIONS

The options are largely compatible with the standard scp command.

-a
Enables aggressive keep-alive messages. This option might improve transfer stability on unstable networks.
-c
Cipher specification. This option allows you to specify the encryption cipher to be used for the SSH connection. For example, -c aes128-gcm@openssh.com might offer better performance on certain hardware. The default cipher depends on the SSH configuration.
-d
Increments the ssh debug output level.
-e
Disable compression. Compression is enabled by default if the SSH server supports it.
-f
Enable compression. This option explicitly enables compression for the transfer.
-g
Allows remote hosts to read local files. This is generally not recommended for security reasons.
-h
Prints help.
-i
Selects a file from which to read the identity (private key) for public key authentication.
-m
Pins threads to specific CPU cores. The value is a bitmask, where each bit corresponds to a CPU core. For example, -m 0xffff pins threads to the first 16 cores.
-n
Specifies the number of parallel SSH connections to use. Increasing this number can improve performance on multi-core systems and high-latency networks. The default value is typically 16.
-o ssh_option
Allows specifying options directly to the underlying ssh command. For example, -o "StrictHostKeyChecking=no".
-P port
Port on remote host. Specifies the port number to connect to on the remote host. This overrides the default SSH port (22).
-p
Preserves modification times and access times (file mode bits are preserved by default).
-d
Increments the ssh debug output level.
-N
Enables Nagle's algorithm. It is disabled by default.
-h
Prints help.
-W file
Checkpoint file. Saves transfer progress to the specified file. This allows resuming interrupted transfers.
-R
Resume transfer from a checkpoint file specified with -W.
-D
Dump checkpoint file content and exit. Useful for inspecting the state of a checkpoint without resuming the transfer.

EXIT STATUS

Exit status is 0 on success, and >0 if an error occurs.

ENVIRONMENT

mscp recognizes the following environment variables.

MSCP_SSH_AUTH_PASSWORD
This environment variable passes a password for password authentication to establish SSH connections.
MSCP_SSH_AUTH_PASSPHRASE
This environment variable passes a passphrase for public-key authentication for establishing SSH connections.

NOTES

mscp uses glob(3) for globbing pathnames, including matching patterns for local and remote paths. However, globbing on the remote side does not work with musl libc (used in Alpine Linux and the single-binary version of mscp) because musl libc does not support GLOB_ALTDIRFUNC.

mscp does not support remote-to-remote copy, which scp supports.

EXAMPLES

Copy a local file to a remote host with different name:

    $ mscp ~/src-file 10.0.0.1:copied-file

Copy a local file and a directory to /tmp at a remote host:

    $ mscp ~/src-file dir1 10.0.0.1:/tmp

Save a checkpoint if transfer fails:

    $ mscp -W mscp.checkpoint many-large-files 10.0.0.1:dst/

Check the remaining files and chunks, and resume the failed transfer:

    # Dump the content of a checkpoint and exit (dry-run mode)
    $ mscp -vv -D -R mscp.checkpoint
    # resume transferring from the checkpoint
    $ mscp -R mscp.checkpoint

In a long fat network, following options might improve performance:

    $ mscp -n 64 -m 0xffff -a 64 -c aes128-gcm@openssh.com src 10.0.0.1:

-n increases the number of SSH connections than default, -m pins threads to specific CPU cores, -a increases asynchronous inflight SFTP WRITE/READ commands, and -c aes128-gcm@openssh.com will be faster than the default chacha20-poly1305 cipher, particularly on hosts that support AES-NI.

SEE ALSO

scp(1), ssh(1), sshd(8).
