MSGUNFMT(1) Comandos de usuario MSGUNFMT(1)

NOMBRE

msgunfmt - Descompilar catálogo de mensajes del formato binario

SINOPSIS

msgunfmt [OPCIÓN] [ARCHIVO]...

DESCRIPCIÓN

Convierte el catálogo de mensajes binario a un archivo .po de estilo Uniforum.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Modo de operación:

-j, --java
Modo Java: la entrada es una clase Java ResourceBundle
--csharp
Modo C#: la entrada es un archivo .dll de .NET
--csharp-resources
Modo de recursos C#: la entrada es un archivo .resources de .NET
--tcl
Modo Tcl: la entrada es un archivo .msg de tcl/msgcat

Ubicación del archivo de entrada:

ARCHIVO ...
archivos .mo de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de entrada en modo Java:

-r, --resource=RECURSO
nombre del recurso
-l, --locale=LOCALIZACIÓN
nombre de la localización, idioma o idioma_PAÍS

El nombre de la clase se determina añadiendo el nombre de la localización al nombre del recurso, separados por un guion bajo. La clase se localiza utilizando CLASSPATH.

Ubicación del archivo de entrada en modo C#:

-r, --resource=RECURSO
nombre del recurso
-l, --locale=LOCALIZACIÓN
nombre de la localización, idioma o idioma_PAÍS
-d DIRECTORIO
directorio base para archivos .dll dependientes de la localización

Las opciones -l y -d son obligatorias. El archivo .dll se localiza en un subdirectorio del directorio especificado, cuyo nombre depende de la localización.

Ubicación del archivo de entrada en modo Tcl:

-l, --locale=LOCALIZACIÓN
nombre de la localización, idioma o idioma_PAÍS
-d DIRECTORIO
directorio base de los catálogos de mensajes .msg

Las opciones -l y -d son obligatorias. El archivo .msg se localiza en el directorio especificado.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Detalles de salida:

--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'siempre', 'nunca', 'auto' o 'html'.
--style=ARCHIVODEESTILO
especifica el archivo de reglas CSS para --color
-e, --no-escape
no usar escapes C en la salida (por defecto)
-E, --escape
usar escapes C en la salida, sin caracteres extendidos
--force-po
escribe el archivo PO incluso si está vacío
-i, --indent
escribe en estilo de salida con sangría
--strict
escribe en estilo estricto de uniforum
-p, --properties-output
escribe un archivo Java .properties
--stringtable-output
escribe un archivo .strings de NeXTstep/GNUstep
-w, --width=NÚMERO
establece el ancho de página de salida
--no-wrap
no dividir líneas de mensajes largas, que exceden el ancho de página de salida, en varias líneas
-s, --sort-output
genera salida ordenada

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra la información de la versión y sale
-v, --verbose
aumenta el nivel de verbosidad
