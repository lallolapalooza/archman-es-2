MSGGET(3P) Manual de Programador de POSIX MSGGET(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

msgget — obtener el identificador de cola de mensajes XSI

SINOPSIS

#include <sys/msg.h>
int msgget(key_t key, int msgflg);

DESCRIPCIÓN

El procedimiento msgget() opera sobre colas de mensajes XSI (consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 3.226, Cola de Mensajes). No se especifica si esta función interactúa con las instalaciones de comunicación entre procesos en tiempo real definidas en la Sección 2.8, Tiempo Real.

El procedimiento msgget() devolverá el identificador de cola de mensajes asociado con el argumento key.

Se creará una cola de mensajes, una cola de mensajes asociada y una estructura de datos (consulte <sys/msg.h>) para el argumento key si se cumple alguna de las siguientes condiciones:

*
El argumento key es igual a IPC_PRIVATE.
*
El argumento key aún no tiene un identificador de cola de mensajes asociado, y (msgflg & IPC_CREAT) es distinto de cero.

Al crearse, la estructura de datos asociada con el nuevo identificador de cola de mensajes se inicializará de la siguiente manera:

*
msg_perm.cuid, msg_perm.uid, msg_perm.cgid y msg_perm.gid se establecerán al ID de usuario efectivo y al ID de grupo efectivo, respectivamente, del proceso que llama.
*
Los 9 bits de orden inferior de msg_perm.mode se establecerán a los 9 bits de orden inferior de msgflg.
*
msg_qnum, msg_lspid, msg_lrpid, msg_stime y msg_rtime se establecerán a 0.
*
msg_ctime se establecerá a la hora actual, como se describe en la Sección 2.7.1, Descripción General de IPC.
*
msg_qbytes se establecerá al límite del sistema.

VALOR DE RETORNO

Al completarse con éxito, msgget() devolverá un entero no negativo, es decir, un identificador de cola de mensajes. De lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

El procedimiento msgget() fallará si:

EACCES
Existe un identificador de cola de mensajes para el argumento key, pero el permiso de operación especificado por los 9 bits de orden inferior de msgflg no se concedería; consulte la Sección 2.7, Comunicación entre Procesos XSI.
EEXIST
Existe un identificador de cola de mensajes para el argumento key pero ((msgflg & IPC_CREAT) && (msgflg & IPC_EXCL)) es distinto de cero.
ENOENT
No existe un identificador de cola de mensajes para el argumento key y (msgflg & IPC_CREAT) es 0.
ENOSPC
Se va a crear un identificador de cola de mensajes pero se superaría el límite impuesto por el sistema en el número máximo de identificadores de cola de mensajes permitidos en todo el sistema.

USO DE APLICACIÓN

La Extensión de Tiempo Real de POSIX define interfaces alternativas para la comunicación entre procesos (IPC). Los desarrolladores de aplicaciones que necesiten utilizar rutinas de IPC deben diseñar sus aplicaciones de manera que los módulos que utilizan las rutinas de IPC descritas en la Sección 2.7, Comunicación entre Procesos XSI puedan modificarse fácilmente para utilizar las interfaces alternativas.
