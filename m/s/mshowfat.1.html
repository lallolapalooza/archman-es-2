Nombre

mshowfat - muestra los clústeres FAT asignados a un archivo

Nota de advertencia

Esta página del manual ha sido generada automáticamente a partir de la documentación texinfo de mtools y puede que no sea totalmente precisa o completa. Consulte el final de esta página del manual para obtener más detalles.

Descripción

El comando mshowfat se utiliza para mostrar las entradas FAT de un archivo. Sintaxis:

mshowfat [-o desplazamiento] archivos

Si no se proporciona ningún desplazamiento, se imprime una lista de todos los clústeres ocupados por el archivo. Si se proporciona un desplazamiento, solo se imprime el número del clúster que contiene dicho desplazamiento (en bytes).
