MSGUNIQ(1) Comandos de usuario MSGUNIQ(1)

NOMBRE

msguniq - unifica traducciones duplicadas en un catálogo de mensajes

SINOPSIS

msguniq [OPCIÓN] [ARCHIVO_ENTRADA]

DESCRIPCIÓN

Unifica traducciones duplicadas en un catálogo de traducciones. Encuentra traducciones duplicadas del mismo ID de mensaje. Dichos duplicados son una entrada inválida para otros programas como msgfmt, msgmerge o msgcat. Por defecto, los duplicados se fusionan. Al usar la opción --repeated, solo se muestran los duplicados y todos los demás mensajes se descartan. Los comentarios y comentarios extraídos se acumularán, excepto que si se especifica --use-first, se tomarán de la primera traducción. Las posiciones de archivo se acumularán. Al usar la opción --unique, los duplicados se descartan.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA
archivo PO de entrada
-D, --directory=DIRECTORIO
añade DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Selección de mensajes:

-d, --repeated
muestra solo duplicados
-u, --unique
muestra solo mensajes únicos, descarta duplicados

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada tiene sintaxis Java .properties
--stringtable-input
el archivo de entrada tiene sintaxis NeXTstep/GNUstep .strings

Detalles de salida:

-t, --to-code=NOMBRE
codificación para la salida
--use-first
usa la primera traducción disponible para cada mensaje, no fusiona varias traducciones
--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'always', 'never', 'auto', o 'html'.
--style=ARCHIVO_ESTILO
especifica el archivo de reglas CSS para --color
-e, --no-escape
no usa escapes C en la salida (predeterminado)
-E, --escape
usa escapes C en la salida, sin caracteres extendidos
--force-po
escribe archivo PO aunque esté vacío
-i, --indent
escribe el archivo .po usando estilo indentado
--no-location
no escribe líneas '#: nombre_archivo:línea'
-n, --add-location
genera líneas '#: nombre_archivo:línea' (predeterminado)
--strict
escribe un archivo .po estricto conforme a Uniforum
-p, --properties-output
escribe un archivo Java .properties
--stringtable-output
escribe un archivo NeXTstep/GNUstep .strings
-w, --width=NÚMERO
establece el ancho de página de salida
--no-wrap
no rompe las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --sort-output
genera salida ordenada
-F, --sort-by-file
ordena la salida por ubicación de archivo

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de versión y sale

NOMBRE

msguniq - Elimina las entradas duplicadas del archivo .po

SINOPSIS

msguniq [OPCIÓN...] [ARCHIVO]

DESCRIPCIÓN

msguniq lee un archivo PO y escribe el resultado en la salida estándar. Si se especifica un archivo de salida, se utiliza en su lugar. La operación principal es eliminar las entradas duplicadas, manteniendo la primera aparición de cada entrada. Si no se proporcionan archivos, se lee desde la entrada estándar.

OPCIONES

-o, --output-file=ARCHIVO
Escribe la salida en ARCHIVO en lugar de en la salida estándar.
-i, --ignore-translation
Ignora las traducciones vacías al buscar duplicados. Por defecto, las entradas sin traducción se consideran duplicadas si sus cadenas originales coinciden.
--help
Muestra la ayuda y sal.
--version
Muestra la información de la versión y sal.

EJEMPLO

Para eliminar duplicados de un archivo messages.po y guardar el resultado en messages_unique.po:

msguniq messages.po -o messages_unique.po
