MSGFMT(1) Comandos de usuario MSGFMT(1)

NOMBRE

msgfmt - compilar catálogo de mensajes a formato binario

SINOPSIS

msgfmt [OPCIÓN] archivo.po ...

DESCRIPCIÓN

Genera un catálogo de mensajes binario a partir de descripciones de traducción textuales.

Los argumentos obligatorios para opciones largas son también obligatorios para opciones cortas. Similarmente para argumentos opcionales.

Ubicación del archivo de entrada:

archivo.po ...
archivos de entrada
-D, --directorio=DIRECTORIO
añadir DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si el archivo de entrada es -, se lee la entrada estándar.

Modo de operación:

-j, --java
Modo Java: genera una clase Java ResourceBundle
--java2
igual que --java, y asume Java2 (JDK 1.2 o superior)
--csharp
Modo C#: genera un archivo .NET .dll
--csharp-resources
Modo de recursos C#: genera un archivo .NET .resources
--tcl
Modo Tcl: genera un archivo .msg de tcl/msgcat
--qt
Modo Qt: genera un archivo .qm de Qt
--desktop
Modo de entrada de escritorio: genera un archivo .desktop
--xml
Modo XML: genera archivo XML

Ubicación del archivo de salida:

-o, --archivo-salida=ARCHIVO
escribe la salida al archivo especificado
--strict
habilita el modo estricto Uniforum

Si el archivo de salida es -, la salida se escribe en la salida estándar.

Ubicación del archivo de salida en modo Java:

-r, --recurso=RECURSO
nombre del recurso
-l, --localidad=LOCALIDAD
nombre de la localidad, ya sea idioma o idioma_PAÍS
--source
produce un archivo .java, en lugar de un archivo .class
-d DIRECTORIO
directorio base de la jerarquía de directorios de clases

El nombre de la clase se determina añadiendo el nombre de la localidad al nombre del recurso, separado por un guión bajo. La opción -d es obligatoria. La clase se escribe bajo el directorio especificado.

Ubicación del archivo de salida en modo C#:

-r, --recurso=RECURSO
nombre del recurso
-l, --localidad=LOCALIDAD
nombre de la localidad, ya sea idioma o idioma_PAÍS
-d DIRECTORIO
directorio base para archivos .dll dependientes de la localidad

Las opciones -l y -d son obligatorias. El archivo .dll se escribe en un subdirectorio del directorio especificado cuyo nombre depende de la localidad.

Ubicación del archivo de salida en modo Tcl:

-l, --localidad=LOCALIDAD
nombre de la localidad, ya sea idioma o idioma_PAÍS
-d DIRECTORIO
directorio base de catálogos de mensajes .msg

Las opciones -l y -d son obligatorias. El archivo .msg se escribe en el directorio especificado.

Opciones del modo de entrada de escritorio:

-l, --localidad=LOCALIDAD
nombre de la localidad, ya sea idioma o idioma_PAÍS
-o, --archivo-salida=ARCHIVO
escribe la salida al archivo especificado
--plantilla=PLANTILLA
un archivo .desktop utilizado como plantilla
-d DIRECTORIO
directorio base de archivos .po
-kPALABRA, --palabra-clave=PALABRA
buscar PALABRA como palabra clave adicional
-k, --palabra-clave
no usar palabras clave predeterminadas

Las opciones -l, -o y --plantilla son obligatorias. Si se especifica -D, los archivos de entrada se leen del directorio en lugar de los argumentos de la línea de comandos.

Opciones del modo XML:

-l, --localidad=LOCALIDAD
nombre de la localidad, ya sea idioma o idioma_PAÍS
-L, --idioma=NOMBRE
reconoce el idioma XML especificado
-o, --archivo-salida=ARCHIVO
escribe la salida al archivo especificado
--plantilla=PLANTILLA
un archivo XML utilizado como plantilla
-d DIRECTORIO
directorio base de archivos .po
--reemplazar-texto
salida XML reemplazando el texto original con el texto traducido, en lugar de aumentarlo

Las opciones -l, -o y --plantilla son obligatorias. Si se especifica -D, los archivos de entrada se leen del directorio en lugar de los argumentos de la línea de comandos.

Sintaxis del archivo de entrada:

-P, --entrada-propiedades
los archivos de entrada están en sintaxis .properties de Java
--entrada-tabla-cadenas
los archivos de entrada están en sintaxis .strings de NeXTstep/GNUstep

Interpretación del archivo de entrada:

-c, --verificar
realiza todas las verificaciones implicadas por --verificar-formato, --verificar-encabezado, --verificar-dominio
--verificar-formato
verifica las cadenas de formato dependientes del idioma
--verificar-encabezado
verifica la presencia y el contenido de la entrada de encabezado
--verificar-dominio
verifica conflictos entre directivas de dominio y la opción --archivo-salida
-C, --verificar-compatibilidad
verifica que msgfmt de GNU se comporte como msgfmt de X/Open
--verificar-aceleradores[=CAR]
verifica la presencia de aceleradores de teclado para elementos de menú
-f, --usar-borradores
usa entradas borrador en la salida
>

Detalles de salida:

--no-convert
no convertir los mensajes a codificación UTF-8
--no-redundancy
no pre-expandir las macros de directiva de cadena de formato ISO C 99 <inttypes.h>
-a, --alignment=NÚMERO
alinear cadenas a NUMBER bytes (por defecto: 1)
--endianness=ORDEN_DE_BYTES
escribir números de 32 bits en el orden de bytes dado (big o little, el valor por defecto depende de la plataforma)
--no-hash
el archivo binario no incluirá la tabla hash

Salida informativa:

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de la versión y salir
--statistics
imprimir estadísticas sobre las traducciones
-v, --verbose
aumentar el nivel de verbosidad
