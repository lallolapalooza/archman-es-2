MSGCONV(1) Comandos de usuario MSGCONV(1)

NOMBRE

msgconv - conversión de conjuntos de caracteres para catálogos de mensajes

SINOPSIS

msgconv [OPCIÓN] [ARCHIVO_ENTRADA]

DESCRIPCIÓN

Convierte un catálogo de traducción a una codificación de caracteres diferente.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA
archivo PO de entrada
-D, --directorio=DIRECTORIO
añadir DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --archivo-salida=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Destino de la conversión:

-t, --a-codigo=NOMBRE
codificación para la salida

La codificación predeterminada es la codificación de la configuración regional actual.

Sintaxis del archivo de entrada:

-P, --entrada-propiedades
el archivo de entrada tiene la sintaxis de .properties de Java
--entrada-tabla-cadenas
el archivo de entrada tiene la sintaxis de .strings de NeXTstep/GNUstep

Detalles de salida:

--color
usa colores y otros atributos de texto siempre
--color=CUANDO
usa colores y otros atributos de texto si CUANDO. CUANDO puede ser 'siempre', 'nunca', 'auto' o 'html'.
--estilo=ARCHIVO_ESTILO
especifica el archivo de reglas CSS para --color
-e, --sin-escapes
no usa escapes C en la salida (predeterminado)
-E, --escapes
usa escapes C en la salida, sin caracteres extendidos
--forzar-po
escribe el archivo PO incluso si está vacío
-i, --indentado
estilo de salida con sangría
--sin-ubicacion
suprime las líneas '#: nombre_archivo:línea'
-n, --anadir-ubicacion
conserva las líneas '#: nombre_archivo:línea' (predeterminado)
--estricto
estilo de salida estricto de Uniforum
-p, --salida-propiedades
escribe un archivo .properties de Java
--salida-tabla-cadenas
escribe un archivo .strings de NeXTstep/GNUstep
-w, --ancho=NÚMERO
establece el ancho de página de salida
--sin-salto
no divide las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --salida-ordenada
genera salida ordenada
-F, --ordenar-por-archivo
ordena la salida por ubicación de archivo

Salida informativa:

-h, --ayuda
muestra esta ayuda y sale
-V, --versión
muestra información de versión y sale
