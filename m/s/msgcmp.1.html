MSGCMP(1) Comandos de usuario MSGCMP(1)

NOMBRE

msgcmp - compara un catálogo de mensajes y una plantilla

SINOPSIS

msgcmp [OPCIÓN] def.po ref.pot

DESCRIPCIÓN

Compara dos archivos .po estilo Uniforum para verificar que ambos contienen el mismo conjunto de cadenas msgid. El archivo def.po es un archivo PO existente con las traducciones. El archivo ref.pot es el último archivo PO creado, o un archivo plantilla PO (generalmente creado por xgettext). Esto es útil para verificar que has traducido todos y cada uno de los mensajes en tu programa. Cuando no se puede encontrar una coincidencia exacta, se utiliza la coincidencia difusa para producir mejores diagnósticos.

Los argumentos obligatorios para las opciones largas son obligatorios para las opciones cortas también.

Ubicación del archivo de entrada:

def.po
traducciones
ref.pot
referencias a las fuentes
-D, --directorio=DIRECTORIO
añade DIRECTORIO a la lista para la búsqueda de archivos de entrada

Modificadores de operación:

-m, --multi-dominio
aplica ref.pot a cada uno de los dominios de def.po
-N, --no-coincidencia-difusa
no usar coincidencia difusa
--usar-difuso
considerar entradas difusas
--usar-sin-traducir
considerar entradas sin traducir

Sintaxis del archivo de entrada:

-P, --entrada-propiedades
los archivos de entrada están en sintaxis Java .properties
--entrada-tabla-cadenas
los archivos de entrada están en sintaxis NeXTstep/GNUstep .strings

Salida informativa:

-h, --ayuda
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir
