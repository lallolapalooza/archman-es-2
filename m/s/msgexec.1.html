MSGEXEC(1) Comandos de usuario MSGEXEC(1)

NOMBRE

msgexec - procesa traducciones de catálogos de mensajes

SINOPSIS

msgexec [OPCIÓN] COMANDO [OPCIÓN-DE-COMANDO]

DESCRIPCIÓN

Aplica un comando a todas las traducciones de un catálogo de traducciones. El COMANDO puede ser cualquier programa que lea una traducción de la entrada estándar. Se invoca una vez por cada traducción. Su salida se convierte en la salida de msgexec. El código de retorno de msgexec es el código de retorno máximo entre todas las invocaciones.

Un comando especial incorporado llamado '0' imprime la traducción, seguido de un byte nulo. La salida de "msgexec 0" es adecuada como entrada para "xargs -0".

Entrada del comando:

--newline
añade una nueva línea al final de la entrada

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

Ubicación del archivo de entrada:

-i, --input=ARCHIVO_ENTRADA
archivo PO de entrada
-D, --directory=DIRECTORIO
añade DIRECTORIO a la lista para buscar archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada tiene sintaxis Java .properties
--stringtable-input
el archivo de entrada tiene sintaxis NeXTstep/GNUstep .strings

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra información de la versión y sale
