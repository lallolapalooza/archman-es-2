MSGCAT(1) Comandos de usuario MSGCAT(1)

NOMBRE

msgcat - combina varios catálogos de mensajes

SINOPSIS

msgcat [OPCIÓN] [ARCHIVOENTRADA]...

DESCRIPCIÓN

Concatena y fusiona los archivos PO especificados. Encuentra mensajes que son comunes a dos o más de los archivos PO especificados. Usando la opción --more-than, se puede solicitar una mayor comunidad antes de imprimir los mensajes. Por el contrario, la opción --less-than se puede usar para especificar una menor comunidad antes de imprimir los mensajes (es decir, --less-than=2 solo imprimirá los mensajes únicos). Las traducciones, comentarios, comentarios extraídos y posiciones de archivo se acumularán, excepto que si se especifica --use-first, se tomarán del primer archivo PO que los defina.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVOENTRADA ...
archivos de entrada
-f, --files-from=ARCHIVO
obtener la lista de archivos de entrada de ARCHIVO
-D, --directory=DIRECTORIO
agregar DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si el archivo de entrada es -, se leerá la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribir la salida al archivo especificado

Los resultados se escribirán en la salida estándar si no se especifica un archivo de salida o si este es -.

Selección de mensajes:

-<, --less-than=NÚMERO
imprimir mensajes con menos de esta cantidad de definiciones, el valor predeterminado es infinito si no se establece
->, --more-than=NÚMERO
imprimir mensajes con más de esta cantidad de definiciones, el valor predeterminado es 0 si no se establece
-u, --unique
atajo para --less-than=2, solicita que solo se impriman los mensajes únicos

Sintaxis del archivo de entrada:

-P, --properties-input
los archivos de entrada están en sintaxis de Java .properties
--stringtable-input
los archivos de entrada están en sintaxis de NeXTstep/GNUstep .strings

Detalles de salida:

-t, --to-code=NOMBRE
codificación para la salida
--use-first
usar la primera traducción disponible para cada mensaje, no fusionar varias traducciones
--lang=NOMBRECATALOGO
establecer el campo 'Language' en la entrada de encabezado
--color
usar colores y otros atributos de texto siempre
--color=CUANDO
usar colores y otros atributos de texto si CUANDO. CUANDO puede ser 'always', 'never', 'auto', o 'html'.
--style=ARCHIVOESTILO
especificar el archivo de reglas CSS para --color
-e, --no-escape
no usar escapes C en la salida (predeterminado)
-E, --escape
usar escapes C en la salida, sin caracteres extendidos
--force-po
escribir archivo PO aunque esté vacío
-i, --indent
escribir el archivo .po usando estilo indentado
--no-location
no escribir líneas '#: nombrearchivo:línea'
-n, --add-location
generar líneas '#: nombrearchivo:línea' (predeterminado)
--strict
escribir un archivo .po estricto que cumpla con Uniforum
-p, --properties-output
escribir un archivo .properties de Java
--stringtable-output
escribir un archivo .strings de NeXTstep/GNUstep
-w, --width=NÚMERO
establecer el ancho de página de salida
--no-wrap
no dividir las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --sort-output
generar salida ordenada
-F, --sort-by-file
ordenar la salida por ubicación de archivo

Salida informativa:

-h, --help
mostrar esta ayuda y salir
-V, --version
mostrar información de versión y salir

msgcat(1)

msgcat - concatenar y traducir archivos de mensajes

SINOPSIS

msgcat [OPCIONES]...

DESCRIPCIÓN

msgcat es una utilidad para concatenar y traducir archivos de mensajes, como los archivos.po o.gmo.

Permite combinar varios archivos de mensajes en uno solo, manteniendo el orden de los mensajes y resolviendo conflictos si existen entradas duplicadas.

También se puede utilizar para traducir archivos de mensajes a otros idiomas, aunque esta funcionalidad suele ser más común con herramientas dedicadas a la traducción.

OPCIONES

  • -h, --help: Muestra este mensaje de ayuda y sale.
  • -V, --version: Muestra información sobre la versión y sale.
  • -o, --output=FICHERO: Escribe la salida en FICHERO en lugar de la salida estándar.
  • -i, --input=FICHERO: Lee la entrada del FICHERO especificado. Se puede usar varias veces para especificar múltiples archivos de entrada.
  • -l, --language=IDIOMA: Especifica el idioma al que traducir.
  • -s, --sort: Ordena las entradas del mensaje antes de escribir la salida.
  • -p, --prefix=PREFIJO: Añade PREFIJO a cada clave de mensaje.
  • -S, --suffix=SUFIJO: Añade SUFIJO a cada clave de mensaje.

EJEMPLOS

Concatenar dos archivos de mensajes y guardar el resultado:

msgcat -i file1.po -i file2.po -o merged.po

Traducir un archivo de mensajes al francés (asumiendo que el archivo contiene traducciones para francés):

msgcat -i messages.po -l fr -o messages.fr.po
