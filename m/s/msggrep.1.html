MSGGREP(1) Comandos de usuario MSGGREP(1)

NOMBRE

msggrep - coincidencia de patrones en el catálogo de mensajes

SINOPSIS

msggrep [OPCIÓN] [ARCHIVO_ENTRADA]

DESCRIPCIÓN

Extrae todos los mensajes de un catálogo de traducción que coinciden con un patrón dado o pertenecen a algunos archivos fuente dados.

Los argumentos obligatorios para opciones largas son obligatorios también para las opciones cortas.

Ubicación del archivo de entrada:

ARCHIVO_ENTRADA
archivo PO de entrada
-D, --directorio=DIRECTORIO
añade DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --archivo-salida=ARCHIVO
escribe la salida en el archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

Selección de mensajes:

[-N ARCHIVO_FUENTE]... [-M NOMBRE_DOMINIO]... [-J PATRÓN_MSGCTXT] [-K PATRÓN_MSGID] [-T PATRÓN_MSGSTR] [-C COMENTARIO] [-X COMENTARIO_EXTRAIDO] [-W FLAG_FLUJO_TRABAJO] [-S FLAG_FIJA]

Se selecciona un mensaje si proviene de uno de los archivos fuente especificados, o si proviene de uno de los dominios especificados, o si se da -J y su contexto (msgctxt) coincide con PATRÓN_MSGCTXT, o si se da -K y su clave (msgid o msgid_plural) coincide con PATRÓN_MSGID, o si se da -T y su traducción (msgstr) coincide con PATRÓN_MSGSTR, o si se da -C y el comentario del traductor coincide con COMENTARIO, o si se da -X y el comentario extraído coincide con COMENTARIO_EXTRAIDO, o si se da -W y sus flags contienen FLAG_FLUJO_TRABAJO, o si se da -S y sus flags contienen FLAG_FIJA.

Cuando se especifica más de un criterio de selección, el conjunto de mensajes seleccionados es la unión de los mensajes seleccionados de cada criterio.

Sintaxis de PATRÓN_MSGCTXT o PATRÓN_MSGID o PATRÓN_MSGSTR o COMENTARIO o COMENTARIO_EXTRAIDO:

[-E | -F] [-e PATRÓN | -f ARCHIVO]...

Los PATRONES son expresiones regulares básicas por defecto, o expresiones regulares extendidas si se da -E, o cadenas fijas si se da -F.

-N, --ubicacion=ARCHIVO_FUENTE
selecciona mensajes extraídos de ARCHIVO_FUENTE
-M, --dominio=NOMBRE_DOMINIO
selecciona mensajes pertenecientes al dominio NOMBRE_DOMINIO
-J, --msgctxt
inicio de patrones para el msgctxt
-K, --msgid
inicio de patrones para el msgid
-T, --msgstr
inicio de patrones para el msgstr
-C, --comentario
inicio de patrones para el comentario del traductor
-X, --comentario-extraido
inicio de patrones para el comentario extraído
-E, --regexp-extendido
PATRÓN es una expresión regular extendida
-F, --cadenas-fijas
PATRÓN es un conjunto de cadenas separadas por saltos de línea
-e, --regexp=PATRÓN
usa PATRÓN como expresión regular
-f, --archivo=ARCHIVO
obtiene PATRÓN de ARCHIVO
-i, --ignorar-mayusculas
ignora distinciones entre mayúsculas y minúsculas
-W, --flag-flujo-trabajo=FLAG
selecciona mensajes con FLAG
-S, --flag-fija=FLAG
selecciona mensajes con FLAG
-v, --invertir-coincidencia
muestra solo los mensajes que no coinciden con ningún criterio de selección

Sintaxis del archivo de entrada:

-P, --entrada-propiedades
el archivo de entrada está en sintaxis .properties de Java
--entrada-stringtable
el archivo de entrada está en sintaxis .strings de NeXTstep/GNUstep

Detalles de salida:

--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'always', 'never', 'auto', o 'html'.
--estilo=ARCHIVO_ESTILO
especifica el archivo de reglas CSS para --color
--sin-escape
no usa escapes C en la salida (por defecto)
--escape
usa escapes C en la salida, sin caracteres extendidos
--forzar-po
escribe archivo PO incluso si está vacío
--indent
estilo de salida con sangría
--sin-ubicacion
suprime las líneas '#: nombre_archivo:número_línea'
-n, --añadir-ubicacion
conserva las líneas '#: nombre_archivo:número_línea' (por defecto)
--estricto
estilo de salida estricto Uniforum
-p, --salida-propiedades
escribe un archivo .properties de Java
--salida-stringtable
escribe un archivo .strings de NeXTstep/GNUstep
-w, --ancho=NÚMERO
establece el ancho de página de salida
--sin-salto
no divide las líneas de mensajes largas, que excedan el ancho de página de salida, en varias líneas
--salida-ordenada
genera salida ordenada
--ordenar-por-archivo
ordena la salida por ubicación del archivo

Información detallada:

-h, --ayuda
muestra esta ayuda y sale
-V, --versión
muestra información de versión y sale
