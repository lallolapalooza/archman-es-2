NOMBRE

msginit - inicializa un catálogo de mensajes

SINOPSIS

msginit [OPCIÓN]

DESCRIPCIÓN

Crea un nuevo archivo PO, inicializando la información meta con valores del entorno del usuario.

Los argumentos obligatorios para las opciones largas son obligatorios también para las opciones cortas.

Ubicación del archivo de entrada:

-i, --input=ARCHIVOENTRADA
archivo POT de entrada

Si no se proporciona ningún archivo de entrada, se busca el archivo POT en el directorio actual. Si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida al archivo PO especificado

Si no se proporciona ningún archivo de salida, depende de la opción --locale o de la configuración de la configuración regional del usuario. Si es -, los resultados se escriben en la salida estándar.

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada está en sintaxis de Java .properties
--stringtable-input
el archivo de entrada está en sintaxis .strings de NeXTstep/GNUstep

Detalles de salida:

-l, --locale=LL_CC[.CODIFICACIÓN]
establece la configuración regional de destino
--no-translator
asume que el archivo PO se genera automáticamente
--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'siempre', 'nunca', 'auto' o 'html'.
--style=ARCHIVODESTILO
especifica el archivo de reglas CSS para --color
-p, --properties-output
escribe un archivo Java .properties
--stringtable-output
escribe un archivo .strings de NeXTstep/GNUstep
-w, --width=NÚMERO
establece el ancho de página de salida
--no-wrap
no divide las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra la información de la versión y sale
