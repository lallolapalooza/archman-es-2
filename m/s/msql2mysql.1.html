MSQL2MYSQL(1) Sistema de Base de Datos MariaDB MSQL2MYSQL(1)

NOMBRE

msql2mysql - convierte programas mSQL para su uso con MariaDB

SINOPSIS

msql2mysqlarchivo-fuente-C ...

DESCRIPCIÓN

Inicialmente, la API C de MySQL se desarrolló para ser muy similar a la del sistema de bases de datos mSQL. Debido a esto, los programas mSQL a menudo se pueden convertir con relativa facilidad para su uso con MariaDB cambiando los nombres de las funciones de la API C.

La utilidad msql2mysql realiza la conversión de las llamadas a funciones de la API C de mSQL a sus equivalentes de MariaDB. msql2mysql convierte el archivo de entrada en el lugar, así que haga una copia del original antes de convertirlo. Por ejemplo, use msql2mysql de esta manera:

shell> cp cliente-prog.c cliente-prog.c.orig
shell> msql2mysql cliente-prog.c
cliente-prog.c convertido

Luego, examine cliente-prog.c y realice cualquier revisión post-conversión que pueda ser necesaria.

msql2mysql utiliza la utilidad replace para realizar las sustituciones de nombres de funciones. Véase replace(1).
