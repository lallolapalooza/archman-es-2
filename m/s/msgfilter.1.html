MSGFILTER(1) Comandos de usuario MSGFILTER(1)

NOMBRE

msgfilter - edita traducciones de catálogos de mensajes

SINOPSIS

msgfilter [OPCIÓN] FILTRO [OPCIÓN-FILTRO]

DESCRIPCIÓN

Aplica un filtro a todas las traducciones de un catálogo de traducciones.

Los argumentos obligatorios para las opciones largas son también obligatorios para las opciones cortas.

Ubicación del archivo de entrada:

-i, --input=ARCHIVOENTRADA
archivo PO de entrada
-D, --directory=DIRECTORIO
agrega DIRECTORIO a la lista para la búsqueda de archivos de entrada

Si no se proporciona ningún archivo de entrada o si es -, se lee la entrada estándar.

Ubicación del archivo de salida:

-o, --output-file=ARCHIVO
escribe la salida al archivo especificado

Los resultados se escriben en la salida estándar si no se especifica ningún archivo de salida o si es -.

El FILTRO puede ser cualquier programa que lea una traducción de la entrada estándar y escriba una traducción modificada en la salida estándar.

Filtro entrada y salida:

--newline
agrega una nueva línea al final de la entrada y elimina una nueva línea del final de la salida

Útiles OPCIONES-FILTRO cuando el FILTRO es 'sed':

-e, --expression=SCRIPT
agrega SCRIPT a los comandos a ejecutar
-f, --file=SCRIPTFILE
agrega el contenido de SCRIPTFILE a los comandos a ejecutar
-n, --quiet, --silent
suprime la impresión automática del espacio de patrones

Sintaxis del archivo de entrada:

-P, --properties-input
el archivo de entrada está en sintaxis de Java .properties
--stringtable-input
el archivo de entrada está en sintaxis de NeXTstep/GNUstep .strings

Detalles de salida:

--color
usa colores y otros atributos de texto siempre
--color=CUÁNDO
usa colores y otros atributos de texto si CUÁNDO. CUÁNDO puede ser 'always', 'never', 'auto', o 'html'.
--style=ARCHIVOPROGRAMA
especifica el archivo de reglas CSS para --color
--no-escape
no usa escapes C en la salida (por defecto)
-E, --escape
usa escapes C en la salida, sin caracteres extendidos
--force-po
escribe archivo PO incluso si está vacío
--indent
estilo de salida con sangría
--keep-header
mantiene la entrada de cabecera sin modificar, no la filtra
--no-location
suprime las líneas '#: archivo:línea'
-n, --add-location
preserva las líneas '#: archivo:línea' (por defecto)
--strict
estilo de salida estricto Uniforum
-p, --properties-output
escribe un archivo Java .properties
--stringtable-output
escribe un archivo .strings de NeXTstep/GNUstep
-w, --width=NÚMERO
establece el ancho de página de salida
--no-wrap
no divide las líneas de mensajes largas, más largas que el ancho de página de salida, en varias líneas
-s, --sort-output
genera salida ordenada
-F, --sort-by-file
ordena la salida por ubicación de archivo

Salida informativa:

-h, --help
muestra esta ayuda y sale
-V, --version
muestra la información de la versión y sale
