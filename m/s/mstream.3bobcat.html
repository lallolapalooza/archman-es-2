mstream(3bobcat) Manejo de mensajes mstream(3bobcat)

NOMBRE

FBB::Mstream - Flujo genérico para el manejo de mensajes

SINOPSIS

#include <bobcat/mstream>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los objetos de esta clase se utilizan para manejar mensajes de forma estandarizada. Los mensajes pueden ir precedidos de números de orden (línea) y/o etiquetas. Los mensajes generados por objetos Mstream pueden opcionalmente terminar lanzando una FBB::Exception (que es una std::exception), permitiendo una implementación sencilla de, por ejemplo, mensajes de error fatales.

La biblioteca BOBCAT proporciona cuatro flujos de mensajes que pueden utilizarse tras incluir el archivo de cabecera mstream. Todos ellos están definidos en el espacio de nombres FBB:

o
FBB::emsg para generar mensajes de error estándar (con etiqueta y número), por ejemplo: 
[Error 1] este es un mensaje de error
o
FBB::fmsg para generar mensajes de error fatales (con etiqueta), que terminan en una excepción, por ejemplo: 
[Fatal] este mensaje fatal va seguido de una excepción
El miembro what de la excepción contiene el valor del id de FBB::fmsg (ver el miembro id más abajo).
o
FBB::imsg para generar mensajes informativos sencillos, por ejemplo: 
este es un mensaje sencillo
o
FBB::wmsg para generar mensajes de advertencia (con etiqueta); 
[Warning] esta es una advertencia
Por defecto, todos los mensajes se insertan en el flujo de salida estándar, pero otros destinos (salida de error estándar, un archivo con nombre, etc.) pueden configurarse fácilmente.

Los objetos Mstream en sí mismos son objetos std::ostream, por lo que pueden usarse como objetos pasados a funciones que esperan argumentos ostream. Los mensajes insertados en objetos Mstream se almacenan en búfer hasta que el búfer se vacía por sus partes std::ostream o cuando se insertan FBB::endl o FBB::flush en el flujo de mensajes. Dado que estos manipuladores actúan como std::endl y std::flush cuando se insertan en otro tipo de objeto std::ostream, puede valer la pena considerar usar FBB::endl y FBB::flush. Además, cuando se especifica using namespace std y using namespace FBB, el manipulador FBB::endl y FBB::flush se utilizarán automáticamente con objetos Mstream.

Los mensajes insertados en objetos Mstream se consideran completados en la inserción de los manipuladores FBB::endl o FBB::flush. Las etiquetas de mensaje, las etiquetas de número de línea y los números de línea solo se mostrarán para la siguiente línea después de que se hayan insertado estos manipuladores y, si es necesario, se lanzarán excepciones desde estos manipuladores.

CONSTRUCTORES

o
Mstream():
El constructor por defecto genera mensajes utilizando el std::streambuf utilizado por std::cout. No hay límite para el número de mensajes que se pueden insertar. No se muestran números de mensaje ni de línea, ni se lanzan excepciones al insertar mensajes.
o
explicit Mstream(std::ostream &ostr, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Este constructor utiliza el std::streambuf que también utiliza el ostream ostr. Por defecto (utilizando los valores por defecto de los argumentos) no hay límite para el número de mensajes que se pueden insertar. No se muestran números de mensaje ni de línea, ni se lanzan excepciones al insertar mensajes. Especificar cualquier valor distinto de std::numeric_limits<size_t>::max() establecerá el número máximo de mensajes que se pueden insertar a ese valor. El tag define el texto de la etiqueta del mensaje (por ejemplo, Error).
Cuando throwing es true se lanza una excepción después de completar un mensaje. El miembro what de la excepción generada puede mostrar el id del objeto FBB::Mstream (ver más abajo en el miembro id) del objeto Mstream que lanza la excepción.
o
explicit Mstream(std::streambuf *buf, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Este constructor utiliza buf para insertar mensajes. Los parámetros restantes son idénticos a los del constructor anterior.
o
explicit Mstream(std::string const &name, size_t maxCount = std::numeric_limits<size_t>::max(), std::string const &tag = "", bool throwing = false):
Este constructor crea un std::ofstream a partir del parámetro name proporcionado. Lanza una excepción si no se puede abrir el flujo para escritura. Si ya existe un archivo con ese nombre, se sobrescribe. Los parámetros restantes son idénticos a los de los dos constructores anteriores.

Los constructores y operadores de asignación de copia y movimiento no están disponibles.

DESCRIPTION

The class Mstream is used for the creation of messages which are produced by a Mstream object.

Messages are sent to an Mstream object using the insertion operator <<. The message content is then written to a destination stream, to a file, or to a streambuf. The Mstream object itself manages the destination stream, a file, or the streambuf, as well as the message counter and potentially a message tag. If the object's throwing member is true, an exception is thrown after each completed message.

An Mstream object has a number of members which control its behavior, such as maxCount, tag, and throwing. The members on and off can be used to activate or deactivate the Mstream object.

MANIPULATORS

Note that the following two manipulators are not members of the class Mstream, but are free functions defined in the namespace FBB.

o
std::ostream &endl(std::ostream &out):
This manipulator inserts a newline character in the Mstream’s stream and then calls FBB::flush. This manipulator acts like std::endl and std::flush when inserted into another kind of std::ostream object.
o
std::ostream &flush(std::ostream &out):
This manipulator completes the message that is currently being inserted into an Mstream object. It flushes the object’s destination stream and prepares the object for the next message. When the object’s throws member returns true it throws an exception whose what member contains the id (see earlier for the member id) of the Mstream object throwing the exception. When used in combination with another kind of std::ostream object it acts like std::flush.
o
std::ostream &noid(std::ostream &out):
This manipulator completes the message that is currently being inserted into an Mstream object. It flushes the object’s destination stream and prepares the object for the next message. When the object’s throws member returns true it throws an exception whose what member does not contain the Mstream object’s ID. When used in combination with another kind of std::ostream object it acts like std::flush.
o
std::ostream &noidl(std::ostream &out):
This manipulator inserts a newline character in the Mstream’s stream and then calls FBB::noid. This manipulator acts like std::endl and std::flush when inserted into another kind of std::ostream object.

As the manipulators FBB::endl and FBB::flush act like, respectively, std::endl and std::flush when inserted into another kind of std::ostream object, using the declarations `using FBB::endl` and `using FBB::flush` might be worth considering. Also, when using namespace std and using namespace FBB is specified the FBB::endl and FBB::flush manipulator will automatically be called when inserting endl or flush into Mstream objects.

EXAMPLE

#include <iostream>
#include <algorithm>
#include <iterator>
#include <bobcat/mstream>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
try
{
    cout << sizeof(Mstream) << ’ ’ << sizeof(Mbuf) << ’\n’;
    imsg << "Informational: " << endl;
    imsg.off();
    cout << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    imsg << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    imsg << "The i-msg stream is now off. This message should appear once" <<
                                                                        endl;
    cout << "But this message is shown" << endl;
    wmsg << "Warning message" << endl;
    emsg << "Oops, this this is an error (not really)" << endl;
    emsg << "Oops, this goes wrong, too" << noid;
    imsg.on();
    imsg << "And another informational msg: " << emsg.count() <<
            " error messages\n" << flush;
    emsg << "Third error" << endl;
    emsg.setMaxCount(3);
    imsg << "Msg in between" << endl;
    imsg.setTag("tag");
    imsg << "tagged message" << endl;
    imsg.setTag("label");
    imsg << "labeled message" << endl;
    cerr << "(cerr) LineExcess: " << emsg.lineExcess() << ", count = " <<
            emsg.count() << endl;
    emsg << "Fourth error\n" << noid;       // no id is shown
    emsg << "Fourth error\n" << flush;      // shows id (remove the previous
                                            // statement)
    cerr << "(cerr) LineExcess: " << emsg.lineExcess() << ", count = " <<
            emsg.count() << endl;
    cerr << "Beyond\n";
}
catch(exception const &e)
{
    std::cerr << "Got a std::exception: " << e.what() << ’\n’;
}
catch(...)
{
    std::cerr << "Got an exception\n";
}
