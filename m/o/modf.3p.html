MODF(3P) Manual de Programador POSIX MODF(3P)

PROLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

modf, modff, modfl — descompone un número de punto flotante

SINOPSIS

#include <math.h>
double modf(double x, double *iptr);
float modff(float value, float *iptr);
long double modfl(long double value, long double *iptr);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones dividirán el argumento x en partes integral y fraccionaria, cada una con el mismo signo que el argumento. Almacenarán la parte integral como un double (para la función modf()), un float (para la función modff()), o un long double (para la función modfl()), en el objeto al que apunta iptr.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán la parte fraccionaria con signo de x.

Si x es NaN, se devolverá un NaN y *iptr se establecerá en un NaN.

Si x es ±Inf, se devolverá ±0 y *iptr se establecerá en ±Inf.

ERRORES

No se definen errores.

Ninguno.

USO DE APLICACIONES

La función modf() calcula el resultado de la función y *iptr de tal manera que:

a = modf(x, iptr) ;
x == a+*iptr ;

teniendo en cuenta las imprecisiones habituales de punto flotante.
