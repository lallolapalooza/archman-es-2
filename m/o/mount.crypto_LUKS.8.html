Nombre

mount.crypt - montar un volumen cifrado dm-crypt

Sintaxis

mount.crypt [-nrv] [-o opciones] dispositivo directorio

Opciones

-o opciones
Establecer opciones de montaje adicionales. mount.crypt tomará sus propias opciones que reconozca y pasará cualquier opción restante al programa de montaje subyacente. Ver abajo para las posibles opciones.
-n
No actualizar /etc/mtab. Tenga en cuenta que esto hace imposible desmontar el volumen nombrando el contenedor; deberá pasar el punto de montaje a umount.crypt.
-r
Configurar el dispositivo loop (si es necesario) y el dispositivo criptográfico en modo de solo lectura. (El montaje en sí necesariamente también será de solo lectura). Tenga en cuenta que hacer un remontaje usando `mount /mnt -o remount,rw` no hará que el montaje sea de lectura/escritura. Los dispositivos criptográficos y loop tendrán que ser desasociados primero.
-v
Activar la depuración y ser un poco más detallado.

Opciones de montaje

header
Un archivo de metadatos separado (desacoplado) donde se almacena la cabecera LUKS. Se correlaciona con la opción `cryptsetup --header`. Si se omite, no se utiliza la función de cabecera LUKS desacoplada.
allow_discard
Habilita el soporte de paso de descarte (discard). Esta opción no hace que el sistema de archivos se monte con descarte habilitado, pero permite que fstrim se ejecute manualmente.
no_read_workqueue
Evita la cola de trabajo interna y procesa las solicitudes de lectura de forma síncrona.
no_write_workqueue
Evita la cola de trabajo interna y procesa las solicitudes de escritura de forma síncrona.
cipher
El cifrado cryptsetup utilizado para el volumen cifrado. Esta opción es obligatoria para volúmenes PLAIN (no LUKS). pmt-ehd(8) por defecto crea volúmenes con "aes-cbc-essiv:sha256" como cifrado.
crypto_name
Selecciona el nombre del dispositivo criptográfico (opcional). Esta opción actualmente solo es utilizable con sistemas dm-crypt.
fsck
Ejecuta fsck en el contenedor antes de montarlo.
fsk_cipher
El cifrado OpenSSL utilizado para la clave del sistema de archivos. La palabra clave especial "none" puede usarse para omitir el descifrado y pasar el contenido del archivo directamente a libcryptsetup.
fsk_hash
El hash OpenSSL utilizado para producir la clave y el IV.
fstype
El tipo exacto de sistema de archivos en el contenedor cifrado. El valor predeterminado es dejar que el kernel lo autodetecte.
hash
El hash cryptsetup utilizado para el volumen cifrado. Por defecto no se usa ningún hash, ya que pam_mount asume volúmenes EHD con una generación de clave de archivo (fskey) sólida y simple.
keyfile
La ruta al archivo clave. Esta opción es obligatoria para volúmenes criptográficos "normales" y no debe usarse para volúmenes LUKS.
remount
Hace que el sistema de archivos se remonte con nuevas opciones. Tenga en cuenta que mount.crypt no puede cambiar el dispositivo loop subyacente (si corresponde) o el dispositivo criptográfico entre solo lectura y lectura/escritura una vez creado; solo se puede cambiar el montaje real del sistema de archivos, con límites. Si el dispositivo loop es de solo lectura, el dispositivo criptográfico será de solo lectura y cambiar el montaje a lectura/escritura será imposible. De manera similar, pasar de rw a ro solo marcará el montaje como de solo lectura, pero no el dispositivo criptográfico o loop, lo que hace imposible configurar el sistema de archivos en el que se encuentra el contenedor criptográfico como de solo lectura.
ro
Igual que la opción -r.
verbose
Igual que la opción -v.

Opciones de montaje obsoletas

Esta sección se proporciona a modo de referencia.

loop
Esta opción solía configurar un dispositivo loop, ya que cryptsetup(8) espera un dispositivo de bloque. La opción se ignora porque mount.crypt puede deducirlo por sí mismo.
