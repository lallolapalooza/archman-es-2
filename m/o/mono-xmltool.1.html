NOMBRE

mono-xmltool - Herramienta de validación y transformación XML de Mono.

SINOPSIS

mono-xmltool --validate [*.rng | *.rnc | *.nvdl | *.xsd] [instancias]

mono-xmltool --validate-rng gramática-relax-ng-xml [instancias]

mono-xmltool --validate-rnc archivo-gramática-compacta-relax-ng [instancias]

mono-xmltool --validate-nvdl script-nvdl-xml [instancias]

mono-xmltool --validate-xsd esquema-xml [instancias]

mono-xmltool --transform hoja-estilos xml-instancia

mono-xmltool --prettyprint [fuente [resultado]]

DESCRIPCIÓN

mono-xmltool es una interfaz de línea de comandos para diversas funciones disponibles en las bibliotecas de clases XML de Mono. Actualmente, ofrece validación con varios tipos diferentes de esquemas, transformaciones xslt e impresión bonita.

VALIDACIÓN XML

mono-xmltool puede validar un conjunto dado de archivos XML (el parámetro instancias) utilizando el archivo de esquema proporcionado. Los archivos de esquema actualmente soportados incluyen Relax NG (*.rng), Relax NG Compacto (*.rnc), Lenguaje de Despacho de Validación Basado en Namespace (*.nvdl) y Esquema XML (*.xsd).

Si se invoca con el argumento --validate, Mono utilizará la extensión del nombre de archivo para adivinar el tipo de validación requerida. Las banderas --validate-xxx forzarían un tipo específico de validación.

La siguiente lista muestra las banderas y la clase real que las implementa en Mono:

--validate-rng

Commons.Xml.Relaxng.RelaxNgPattern como esquema, y Commons.Xml.Relaxng.RelaxngValidatingReader como validador.

--validate-rnc
Commons.Xml.Relaxng.RncParser como esquema, y Commons.Xml.Relaxng.RelaxngValidatingReader como validador.
--validate-nvdl

Commons.Xml.Nvdl como esquema y Commons.Xml.NvdlValidatingReader como validador.

--validate-xsd
System.Xml.Schema.XmlSchema como esquema y utiliza System.Xml.XmlValidatingReader como validador.

TRANSFORMACIONES

Esto realiza una transformación XSLT. La hoja de estilos debe ser un archivo XSLT, xml-instancia es el documento a procesar. La salida se envía a la salida estándar.

IMPRESIÓN BONITA

Produce una representación bonita del archivo fuente. Si no se especifica, lee la entrada estándar. Si resultado no se especifica, la salida se envía a la salida estándar.
