NOMBRE

mono-configuration-crypto, - Utilidad de configuración de Mono para gestionar claves de cifrado y cifrar/descifrar secciones de archivos de configuración

SINOPSIS

mono-configuration-crypto <opciones>

DESCRIPCIÓN

mono-configuration-crypto es una utilidad para gestionar el almacén de claves de cifrado de mono y para cifrar/descifrar secciones de archivos de configuración.

OPCIONES

-h, -?, --help
Mostrar información de uso.
-v, --verbose
Mostrar información detallada (incluyendo rastreos de pila de excepciones).
-m, --machine, --global
Usar el almacén de máquina (global) para todas las acciones de clave. Tenga en cuenta que en máquinas Unix el almacén global se encuentra en /usr/share/.mono y modificarlo requiere permisos de usuario root.
-u, --user, --local
Usar el almacén local (del usuario) para todas las acciones de clave. El almacén de claves del usuario se encuentra en el directorio $HOME/.config/.mono. Esta es la ubicación predeterminada utilizada por mono-configuration-crypto.
-l, --list
Listar todos los nombres de contenedores de claves en el almacén. Tenga en cuenta que algunos nombres de contenedores podrían ser simplemente cadenas GUID.
-c, --create
Crea un par de claves RSA pública/privada. Si el contenedor especificado (ver la opción -f) ya existe, la operación fallará.
-i, --import
Importar clave a un contenedor. Importa una clave desde un archivo (especificado por la opción -f) y la coloca como la primera clave en el contenedor especificado (ver la opción -n). Si el contenedor existe, su primera clave se reemplaza. Si el contenedor no existe, se crea. No se realiza ninguna validación en el valor de la clave; esto se deja al proveedor de protección o al código de cifrado que utiliza la clave.
-x, --export
Exportar clave desde un contenedor. Exporta una clave desde el contenedor indicado (ver la opción -n) y la coloca en el archivo especificado (ver la opción -f) como XML. El archivo se puede usar posteriormente para importar la clave.
-r, --remove
Eliminar un contenedor. Elimina físicamente el archivo del contenedor del disco.
-f, --file=VALOR
Nombre del archivo para operaciones de importación o exportación. Todas las opciones que leen o escriben algo desde/hacia archivos requieren que esta opción esté presente en la línea de comandos.
-cf, --config-file=VALOR
Nombre del archivo de configuración. Especifica el nombre base del archivo de configuración, utilizado en operaciones de cifrado y descifrado. Los archivos se buscan sin distinción entre mayúsculas y minúsculas. El valor predeterminado es Web.config.
-n, --name=VALOR
Nombre del contenedor. Si esta opción está ausente en la línea de comandos, el valor predeterminado es MonoFrameworkConfigurationKey (el nombre de clave predeterminado utilizado por el código de cifrado/descifrado de secciones de System.Configuration).
-s, --size=VALOR
Tamaño de la clave. Especifica la longitud de la clave para la operación de creación (ver la opción -c). El valor predeterminado es 1024.
-p, --path=VALOR
Ruta física de la aplicación. Se utiliza al cifrar/descifrar secciones de archivos de configuración para especificar el directorio en el que reside el archivo de configuración (ver la opción -cf). El valor predeterminado es el directorio actual.
-d, --dec, --decrypt=VALOR
Descifrar sección de configuración. La sección de configuración debe seguir el formato utilizado al llamar a ConfigurationManager.GetSection, es decir: ruta/a/seccion. Solo se procesarán las secciones conocidas por el sistema de configuración.
-e, --enc, --encrypt=VALOR
Cifrar sección de configuración. La sección de configuración debe seguir el formato utilizado al llamar a ConfigurationManager.GetSection, es decir: ruta/a/seccion. Solo se procesarán las secciones conocidas por el sistema de configuración.
