NOMBRE

mousetweaks - Mejoras de accesibilidad para dispositivos apuntadores

SINOPSIS

mousetweaks [--dwell] [--ssc] [--dwell-time=FLOAT] [--ssc-time=FLOAT] [-m|--dwell-mode=STRING] [-c|--show-ctw] [-t|--threshold=INT] [-g|--geometry] [-s|--shutdown] [--daemonize] [-?|--help]

DESCRIPCIÓN

mousetweaks es una colección de mejoras de accesibilidad para dispositivos apuntadores. Esta página del manual describe el demonio de mousetweaks.

OPCIONES

--dwell
Realiza automáticamente clics del ratón sin usar un botón físico.
--ssc
Dispara el botón secundario del ratón cuando el botón primario se mantiene presionado durante un tiempo especificado.
--dwell-time=FLOAT
Tiempo que se mantiene el puntero inmóvil antes de realizar un clic de permanencia. Rango: 0.2 - 3.0 segundos.
--ssc-time=FLOAT
Tiempo que se mantiene presionado el botón primario del ratón antes de realizar un clic secundario simulado. Rango: 0.5 - 3.0 segundos.
-m, --dwell-mode=STRING
Selecciona un modo de permanencia. Opciones disponibles: window - Selecciona el tipo de clic desde una ventana o un applet del panel. gesture - Realiza diferentes clics moviéndose en diferentes direcciones.
-c, --show-ctw
Muestra la ventana de tipo de clic. Solo útil en combinación con --dwell-mode=window.
-t, --threshold=INT
Ignora pequeños movimientos del puntero. Rango: 0 - 30 píxeles.
-g, --geometry
Tamaño y posición de la ventana de tipo de clic. Espera una cadena de geometría estándar de X Window System. Ej. ANCHOxALTO+X+Y
-s, --shutdown
Detiene el demonio de mousetweaks.
--daemonize
Inicia mousetweaks en segundo plano, es decir, crea un proceso hijo.
--login
Inicia mousetweaks en modo de inicio de sesión. El modo de inicio de sesión habilita soluciones específicas para GDM. Actualmente no utilizado.

ARCHIVOS

mousetweaks.pid

El demonio crea un archivo de bloqueo en el directorio $XDG_RUNTIME_DIR para mantener un registro de su estado. En sistemas sin un directorio de tiempo de ejecución de usuario, se utiliza el directorio $XDG_CACHE_HOME.
