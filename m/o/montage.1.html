montage(1) Manual de comandos generales montage(1)

NOMBRE

montage - crea una imagen compuesta combinando varias imágenes separadas. Las imágenes se organizan en mosaico en la imagen compuesta, opcionalmente adornadas con un borde, marco, nombre de imagen y más.

SINOPSIS

magick montage [s]archivo[s]_entrada [opciones] archivo_salida

DESCRIPCIÓN

El programa montage es miembro del conjunto de herramientas ImageMagick(1). Úsalo para crear una imagen compuesta combinando varias imágenes separadas. Las imágenes se organizan en mosaico en la imagen compuesta, opcionalmente adornadas con un borde, marco, nombre de imagen y más.

Para obtener más información sobre el comando montage, abre tu navegador en file:///usr/share/doc/ImageMagick-7/www/montage.html o https://imagemagick.org/script/montage.php.

montage(1)

NOMBRE

montage - crea una hoja de contactos de imágenes o una imagen de composición gráfica.

SINOPSIS

montage [-backdrop color] [-background color] [-border geometry] [-bordercolor color] [-compose operator] [-geometry geometry] [-label label] [-matte] [-mattecolor color] [-monochrome] [-page page_layout] [-quantize space] [-shadow] [-tile grid] [-units type] [-texture filename] [-viewer command] [input_image]... output_image

DESCRIPCIÓN GENERAL

Montage es un programa de línea de comandos de ImageMagick que te permite crear una hoja de contactos de imágenes o una imagen de composición gráfica. Puede aplicar una serie de efectos a cada imagen de entrada, como bordes, etiquetas y sombras, antes de colocarlas en una hoja de contactos con un diseño especificado.

DESCRIPCIÓN

Montage toma una lista de archivos de imagen de entrada y los organiza en una sola imagen de salida. Puedes controlar el diseño de la imagen de salida, el tamaño y la apariencia de cada imagen individual, así como el aspecto general de la imagen compuesta.

Aquí hay una descripción más detallada de algunas de las opciones comunes:

  • -backdrop <color>: Especifica el color de fondo para las imágenes que no tienen transparencia.
  • -background <color>: Establece el color de fondo para la imagen de salida.
  • -border <geometry>: Define el tamaño del borde alrededor de cada imagen. Por ejemplo, -border 5x5 agrega un borde de 5 píxeles en todos los lados.
  • -bordercolor <color>: Especifica el color del borde.
  • -compose <operator>: Elige el método de composición que se utilizará.
  • -geometry <geometry>: Controla el tamaño y la colocación de cada imagen en la hoja de contactos. La sintaxis puede ser compleja, pero generalmente incluye el tamaño de la imagen y el desplazamiento.
  • -label <label>: Agrega una etiqueta a cada imagen.
  • -matte: Habilita el canal alfa (transparencia) para la imagen.
  • -mattecolor <color>: Especifica el color del canal alfa.
  • -monochrome: Convierte la imagen a escala de grises.
  • -page <page_layout>: Define el tamaño y la orientación de la página de salida.
  • -quantize <space>: Especifica el espacio de color para la cuantización.
  • -shadow: Agrega una sombra a cada imagen.
  • -tile <grid>: Especifica el número de filas y columnas para organizar las imágenes. Por ejemplo, -tile 4x3 creará una cuadrícula de 4 filas y 3 columnas.
  • -units <type>: Define las unidades para el tamaño de la imagen (por ejemplo, Pixels, Centimeters).
  • -texture <filename>: Aplica un archivo de textura a la imagen de salida.
  • -viewer <command>: Especifica un comando para ver la imagen de salida.

Los input_image son los archivos de imagen que se van a procesar, y output_image es el nombre del archivo de imagen resultante.
