NOMBRE

mount.glusterfs - script para montar volumen nativo GlusterFS

SINOPSIS

mount -t glusterfs [-o <opciones>] <servidor_volumen>:/<volumen>[/<subdirectorio>] <punto_montaje>

mount -t glusterfs [-o <opciones>] <servidor1>,<servidor2>,
<servidor3>,..<servidorN>:/<nombre_volumen>[/<subdirectorio>] <punto_montaje>
mount -t glusterfs [-o <opciones>] <ruta/al/archivo_volumen> <punto_montaje>

DESCRIPCION

Esta herramienta forma parte del paquete glusterfs(8), que se utiliza para montar utilizando el binario nativo de GlusterFS.

mount.glusterfs está destinado a ser utilizado por el comando mount(8) para montar el cliente nativo de GlusterFS. Sin embargo, este subcomando también se puede utilizar como un comando independiente con funcionalidad limitada.

OPCIONES

Opciones básicas

archivo-log=ARCHIVO-LOG
Archivo a usar para el registro [predeterminado: /var/log/glusterfs/glusterfs.log]
nivel-log=NIVEL-LOG
Severidad del registro. Las opciones válidas son TRACE, DEBUG, WARNING, ERROR, CRITICAL, INFO y NONE [predeterminado: INFO]
acl
Monta el sistema de archivos con soporte ACL POSIX
mantener-cache-apertura[=BOLEANO]
No purgar la caché al abrir un archivo (predeterminado: falso)
worm
Monta el sistema de archivos en modo 'worm'
montaje-gfid-aux
Habilita el acceso al sistema de archivos directamente a través de gfid
ro
Monta el sistema de archivos en modo de solo lectura
habilitar-ino32=BOLEANO
Utiliza inodos de 32 bits al montar para solucionar aplicaciones defectuosas que no admiten inodos de 64 bits
contabilidad-memoria
Habilita la contabilidad interna de memoria
capacidad
Habilita el establecimiento y la recuperación de capacidades de archivo
cliente-delgado
Habilita el montaje delgado y se conecta a través del daemon gfproxyd
registro-hora-local
Utiliza marcas de tiempo locales en lugar de UTC en las entradas de registro de montaje

Opciones avanzadas

timeout-atributos=SEGUNDOS
Establece el tiempo de espera de atributos en SEGUNDOS para inodos en el módulo del kernel fuse [predeterminado: 1]
timeout-entrada=SEGUNDOS
Establece el tiempo de espera de entrada en SEGUNDOS en el módulo del kernel fuse [predeterminado: 1]
qlen-fondo=N
Establece la longitud de la cola de fondo del módulo fuse en N [predeterminado: 64]
timeout-gid=SEGUNDOS
Establece el tiempo de espera de la lista de grupos auxiliares en SEGUNDOS para el traductor fuse [predeterminado: 0]
timeout-negativo=SEGUNDOS
Establece el tiempo de espera negativo en SEGUNDOS en el módulo del kernel fuse [predeterminado: 0]
nombre-volumen=NOMBRE-VOLUMEN
Nombre del volumen a utilizar para PUNTO_MONTAJE [predeterminado: el volumen más alto en ARCHIVO_VOLUMEN]
modo-io-directo=BOLEANO|auto
Especifica la estrategia de E/S directa de fuse [predeterminado: auto]
umbral-congestion=N
Establece el umbral de congestión del módulo fuse en N [predeterminado: 48]
montaje-subdirectorio=N
Establece la opción de montaje de subdirectorio [predeterminado: NULL, es decir, sin montaje de subdirectorio]
servidores-volumen-copia=LISTA-SERVIDORES
Proporciona una lista de servidores de volúmenes de copia de seguridad en el siguiente formato [predeterminado: Ninguno] Si se utiliza una dirección IPv6 en LISTA-SERVIDORES, se requiere usar '[' y ']' para rodear la dirección IPv6.

$ mount -t glusterfs -oservidores-volumen-copia=<servidor2>: <servidor3>:...:<servidorN> <servidor1>:/<nombre_volumen> <punto_montaje> $ mount -t glusterfs -oservidores-volumen-copia=<[ipv6_addr2]>: <[ipv6_addr3]>:...:<[ipv6_addrN]> <ipv6_addr1>:/<nombre_volumen> <punto_montaje>

servidor-archivo-volumen=SERVIDOR
Proporciona una lista de servidores de volúmenes de copia de seguridad en el siguiente formato [predeterminado: Ninguno]

$ mount -t glusterfs -oservidor-archivo-volumen=<servidor2> <servidor1>:/<nombre_volumen> <punto_montaje>

intentos-obtener=N
Opción **obsoleta** - colocada aquí para compatibilidad retroactiva [predeterminado: 1]
limite-lru=N
Establece el límite del módulo fuse para el número de inodos mantenidos en la lista LRU en N [predeterminado: 65536]
tamano-tabla-inodos=N
Establece el tamaño de la tabla hash de inodos en N - debe ser una potencia de 2 mayor o igual a 65536 y se redondeará al alza si no lo es [predeterminado: 65536]
limite-invalida=N
Suspende las invalidaciones de fuse implicadas por 'limite-lru' si el número de invalidaciones pendientes alcanza N
qlen-fondo=N
Establece la longitud de la cola de fondo del módulo fuse en N [predeterminado: 64]
sin-squash-root=BOLEANO
Deshabilita el aplastamiento de root para el cliente de confianza [predeterminado: desactivado]
squash-root=BOLEANO
Habilita el aplastamiento de root para el cliente de confianza [predeterminado: activado]
usar-readdirp=BOLEANO
Utiliza el modo readdirp() en el módulo del kernel fuse [predeterminado: activado]
volcar-fuse=RUTA
Vuelca el tráfico de fuse en RUTA
cache-escritura-kernel=BOLEANO
Habilita la caché de escritura diferida en el kernel de fuse [predeterminado: desactivado]
granularidad-tiempos-attr=NS
Declara la granularidad admitida de los atributos del archivo [predeterminado: 0]
invalida-auto=BOLEANO
Controla si el kernel de fuse puede invalidar automáticamente atributos, dentry y caché de página. Deshabilita esto solo si los mismos archivos/directorios no se acceden simultáneamente en dos montajes diferentes [predeterminado: activado]

ARCHIVOS

/etc/fstab
Una entrada típica de GlusterFS en /etc/fstab se ve así

servidor1:/mirror /mnt/mirror glusterfs archivo-log=/var/log/mirror.log,acl 0 0

/proc/mounts
Un ejemplo de entrada de un punto de montaje GlusterFS en /proc/mounts se ve así

servidor1:/mirror /mnt/glusterfs fuse.glusterfs rw,allow_other,default_permissions,max_read=131072 0 0
