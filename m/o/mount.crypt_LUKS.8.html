Nombre

mount.crypt - montar un volumen encriptado dm-crypt

Sintaxis

mount.crypt [-nrv] [-o opciones] dispositivo directorio

Opciones

-o opciones
Establecer opciones de montaje adicionales. mount.crypt tomará sus propias opciones reconocidas y pasará cualquier opción restante al programa de montaje subyacente. Ver más abajo para posibles opciones.
-n
No actualizar /etc/mtab. Tenga en cuenta que esto hace imposible desmontar el volumen nombrando el contenedor; tendrá que pasar el punto de montaje a umount.crypt.
-r
Configurar el dispositivo de bucle (si es necesario) y el dispositivo cripto en modo de solo lectura. (El montaje en sí mismo será necesariamente de solo lectura.) Tenga en cuenta que al realizar una remontada usando `mount /mnt -o remount,rw` no hará que el montaje sea de lectura/escritura. Los dispositivos cripto y de bucle tendrán que ser disociados primero.
-v
Activar la depuración y ser un poco más detallado.

Opciones de montaje

header
Un archivo de metadatos separado donde se almacena la cabecera LUKS. Se correlaciona con la opción `cryptsetup --header`. Si se omite, la característica de cabecera LUKS separada no se utiliza.
allow_discard
Habilita el soporte de paso de descarte. Esta opción no hace que el sistema de archivos se monte con el descarte habilitado, pero permite que fstrim se ejecute manualmente.
no_read_workqueue
Evita la cola de trabajo interna y procesa las solicitudes de lectura sincrónicamente.
no_write_workqueue
Evita la cola de trabajo interna y procesa las solicitudes de escritura sincrónicamente.
cipher
El cifrado cryptsetup utilizado para el volumen encriptado. Esta opción es obligatoria para volúmenes PLAIN (no LUKS). pmt-ehd(8) usa por defecto la creación de volúmenes con "aes-cbc-essiv:sha256" como cifrado.
crypto_name
Selecciona el nombre para el dispositivo cripto (opcional). Esta opción actualmente solo es utilizable con sistemas dm-crypt.
fsck
Ejecuta fsck en el contenedor antes de montarlo.
fsk_cipher
El cifrado OpenSSL utilizado para la clave del sistema de archivos. La palabra clave especial "none" se puede usar para omitir la desencriptación y pasar el contenido del archivo directamente a libcryptsetup.
fsk_hash
El hash OpenSSL utilizado para producir la clave y el IV.
fstype
El tipo exacto de sistema de archivos en el contenedor encriptado. El valor predeterminado es permitir que el kernel lo detecte automáticamente.
hash
El hash cryptsetup utilizado para el volumen encriptado. Esto se establece por defecto en sin hashing, porque pam_mount asume volúmenes EHD con generación de clave de sistema de archivos simple y fuerte.
keyfile
La ruta al archivo de clave. Esta opción es obligatoria para volúmenes cripto "normales" y no debe usarse para volúmenes LUKS.
remount
Provoca que el sistema de archivos se remonte con nuevas opciones. Tenga en cuenta que mount.crypt no puede cambiar el dispositivo de bucle subyacente (si aplica) o el dispositivo cripto entre solo lectura y lectura/escritura una vez que se crea; solo se puede cambiar el montaje real del sistema de archivos, con límites. Si el dispositivo de bucle está en modo de solo lectura, el dispositivo cripto estará en modo de solo lectura y cambiar el montaje a lectura/escritura será imposible. De manera similar, pasar de rw a ro solo marcará el montaje como de solo lectura, pero no el dispositivo cripto o de bucle, lo que hará imposible establecer el sistema de archivos en el que se encuentra el contenedor cripto en modo de solo lectura.
ro
Igual que la opción -r.
verbose
Igual que la opción -v.

Opciones de montaje obsoletas

Esta sección se proporciona como referencia.

loop
Esta opción solía configurar un dispositivo de bucle, porque cryptsetup(8) espera un dispositivo de bloque. La opción se ignora porque mount.crypt puede descubrir esto por sí mismo.
