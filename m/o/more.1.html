MORE(1) Comandos de usuario MORE(1)

NOMBRE

more - muestra el contenido de un archivo en una terminal

SINOPSIS

more [opciones] archivo ...

DESCRIPCIÓN

more es un filtro para paginar texto, una pantalla a la vez. Esta versión es especialmente primitiva. Los usuarios deben tener en cuenta que less(1) proporciona emulación de more(1) más extensas mejoras.

OPCIONES

Las opciones también se toman de la variable de entorno MORE (asegúrate de anteponerles un guion (-)), pero las opciones de línea de comandos las anularán.

-d, --silent

Muestra un mensaje de indicación "[Presiona espacio para continuar, 'q' para salir.]", y muestra "[Presiona 'h' para instrucciones.]" en lugar de hacer sonar el timbre cuando se presiona una tecla no válida.

-l, --logical

No pausar después de ninguna línea que contenga un ^L (salto de página).

-e, --exit-on-eof

Salir al final del archivo, habilitado por defecto si la variable de entorno POSIXLY_CORRECT no está configurada o si no se ejecuta en una terminal.

-f, --no-pause

Contar líneas lógicas, en lugar de líneas de pantalla (es decir, las líneas largas no se pliegan).

-p, --print-over

No desplazarse. En su lugar, borrar toda la pantalla y luego mostrar el texto. Tenga en cuenta que esta opción se activa automáticamente si el ejecutable se llama page.

-c, --clean-print

No desplazarse. En su lugar, dibuja cada pantalla desde la parte superior, borrando el resto de cada línea a medida que se muestra.

-s, --squeeze

Comprime varias líneas en blanco en una sola.

-u, --plain

Suprimir el subrayado. Esta opción se ignora silenciosamente por compatibilidad con versiones anteriores.

-n, --lines número

Especifica el número de líneas por pantalla. El argumento número es un entero decimal positivo. La opción --lines anulará cualquier valor obtenido de cualquier otra fuente, como el número de líneas informado por la terminal.

-número

Una opción numérica significa lo mismo que la opción --lines con argumento.

+número

Comienza a mostrar cada archivo en la línea número.

+/cadena

La cadena a buscar en cada archivo antes de comenzar a mostrarlo.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

COMANDOS

Los comandos interactivos para more se basan en vi(1). Algunos comandos pueden ir precedidos de un número decimal, llamado k en las descripciones a continuación. En las siguientes descripciones, ^X significa control-X.

h o ?

Ayuda; muestra un resumen de estos comandos. Si olvidas todos los demás comandos, recuerda este.

ESPACIO

Muestra las siguientes k líneas de texto. El valor por defecto es el tamaño de pantalla actual.

z

Muestra las siguientes k líneas de texto. El valor por defecto es el tamaño de pantalla actual. El argumento se convierte en el nuevo valor por defecto.

RETORNO

Muestra las siguientes k líneas de texto. El valor por defecto es 1. El argumento se convierte en el nuevo valor por defecto.

d o ^D

Desplázate k líneas. El valor por defecto es el tamaño de desplazamiento actual, inicialmente 11. El argumento se convierte en el nuevo valor por defecto.

q o Q o INTERRUPCIÓN

Salir.

s

Salta k líneas de texto hacia adelante. El valor por defecto es 1.

f

Salta k pantallas de texto hacia adelante. El valor por defecto es 1.

b o ^B

Salta k pantallas de texto hacia atrás. El valor por defecto es 1. Solo funciona con archivos, no con tuberías.

'

Ve al lugar donde comenzó la última búsqueda.

=

Muestra el número de línea actual.

/patrón

Busca la k-ésima ocurrencia de una expresión regular. El valor por defecto es 1.

n

Busca la k-ésima ocurrencia de la última expresión regular. El valor por defecto es 1.

!comando o :!comando

Ejecuta comando en un subshell.

v

Inicia un editor en la línea actual. El editor se toma de la variable de entorno VISUAL si está definida, o EDITOR si VISUAL no está definida, o por defecto a vi(1) si ni VISUAL ni EDITOR están definidas.

^L

Redibuja la pantalla.

:n

Ve al k-ésimo archivo siguiente. El valor por defecto es 1.

:p

Ve al k-ésimo archivo anterior. El valor por defecto es 1.

:f

Muestra el nombre del archivo actual y el número de línea.

.

Repite el comando anterior.

ENTORNO

El comando more respeta las siguientes variables de entorno, si existen:

MORE

Esta variable puede configurarse con opciones preferidas para more.

SHELL

Shell actual en uso (normalmente configurado por el shell al iniciar sesión).

TERM

El tipo de terminal utilizado por more para obtener las características del terminal necesarias para manipular la pantalla.

VISUAL

El editor que prefiere el usuario. Se invoca cuando se presiona la tecla de comando v.

EDITOR

El editor de elección cuando no se especifica VISUAL.

POSIXLY_CORRECT

Deshabilita la salida al final del archivo (ver opción -e para más detalles).

HISTORIAL

El comando more apareció en 3.0BSD. Esta página del manual documenta la versión 5.19 de more (Berkeley 29/06/88), que se utiliza actualmente en la comunidad Linux. La documentación se produjo utilizando varias otras versiones de la página del manual y una inspección exhaustiva del código fuente.

more.1.es

NOMBRE

more - El paginador de archivos más simple.

SINOPSIS

more [OPCIONES]... [FICHERO]...

DESCRIPCIÓN

more es un programa que permite al usuario ver el contenido de un archivo de texto, una página a la vez. Es un paginador, similar a less, pero con menos funcionalidad. Se utiliza principalmente para ver archivos de log grandes o archivos de configuración que son demasiado largos para caber en una sola pantalla.

Cuando se inicia more, muestra el contenido del primer archivo especificado en la terminal, deteniéndose cuando la pantalla está llena. El usuario puede entonces navegar por el archivo usando varias teclas:

  • Espacio: Avanza a la siguiente página.
  • Intro: Avanza a la siguiente línea.
  • b: Retrocede a la página anterior.
  • q: Sale de more.
  • /patrón: Busca el siguiente patrón.
  • ?patrón: Busca el patrón anterior.

Si se especifican varios archivos, more mostrará "nombre_archivo" al final de cada archivo. El usuario puede avanzar al siguiente archivo presionando la tecla 'f' o retroceder al anterior presionando la tecla 'b' (si es posible).

OPCIONES

-d
Inicia more en modo "estúpido". Muestra instrucciones para avanzar y retroceder en la parte inferior de la pantalla y espera la entrada del usuario antes de pasar a la siguiente pantalla o ir a la anterior.
-f
No divide las líneas largas. Las líneas largas se muestran completas sin envolver.
-p
No borra la pantalla antes de mostrar cada página. Esto puede ser útil para ver la salida de comandos que también imprimen texto en la pantalla.
-s
Comprime líneas en blanco consecutivas en una sola línea en blanco.
-u
Suprime las salidas de subrayado. Los caracteres de subrayado se muestran como si no estuvieran subrayados.
--help
Muestra un mensaje de ayuda y sale.
--version
Muestra información de la versión y sale.

COMANDOS

Los siguientes comandos se pueden usar dentro de more:

espacio o f
Avanza una pantalla.
z
Avanza una pantalla. El número de líneas avanzadas se puede cambiar con el comando -n.
intro o j
Avanza una línea.
d
Avanza media pantalla.
b o v
Retrocede una pantalla.
k
Retrocede una línea.
y
Retrocede una línea.
q o Q
Sale de more.
h
Muestra una pantalla de ayuda.
=
Muestra el número de línea actual y el porcentaje del archivo que se ha mostrado.
/patrón
Busca la siguiente ocurrencia del patrón.
?patrón
Busca la ocurrencia anterior del patrón.
n
Repite la última búsqueda (en la misma dirección).
N
Repite la última búsqueda (en la dirección opuesta).
!comando
Ejecuta el comando del shell.
q
Sale de more.

AMBIENTE

Se puede utilizar la variable de entorno MORE para establecer opciones predeterminadas para more. Por ejemplo, si se establece MORE="-f -s", entonces more siempre se ejecutará con las opciones -f y -s.
