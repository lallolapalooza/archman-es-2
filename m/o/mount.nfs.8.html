MOUNT.NFS(8) Manual del administrador del sistema MOUNT.NFS(8)

NOMBRE

mount.nfs, mount.nfs4 - montar un Sistema de Archivos de Red

SINOPSIS

mount.nfs remotetarget dir [-rvVwfnsh ] [-o opciones]

DESCRIPCIÓN

mount.nfs es parte del paquete de utilidades nfs(5), que proporciona funcionalidad de cliente NFS.

mount.nfs está diseñado para ser utilizado por el comando mount(8) para montar recursos compartidos NFS. Sin embargo, esta subcomando también puede ser utilizado como un comando independiente con funcionalidad limitada.

remotetarget es un recurso compartido del servidor, usualmente en el formato nombre_servidor:/ruta/al/recurso. dir es el directorio en el que se va a montar el sistema de archivos.

En las versiones 2.6.32 y posteriores del kernel de Linux, mount.nfs puede montar todas las versiones de los sistemas de archivos NFS. En versiones anteriores del kernel de Linux, se debe usar mount.nfs4 para montar sistemas de archivos NFSv4, mientras que mount.nfs se debe usar para NFSv3.

OPCIONES

-r
Montar el sistema de archivos en modo de solo lectura.
-v
Ser verboso.
-V
Mostrar versión.
-w
Montar el sistema de archivos en modo de lectura-escritura.
-f
Montaje simulado. No llamar realmente a la llamada del sistema de montaje.
-n
No actualizar /etc/mtab. Por defecto, se crea una entrada en /etc/mtab por cada sistema de archivos montado. Utilice esta opción para omitir la creación de una entrada.
-s
Tolerar opciones de montaje dudosas en lugar de fallar.
-h
Mostrar mensaje de ayuda.
opciones
Consulte las páginas del manual nfs(5) o mount(8).

NOTA

Para más información, consulte las páginas del manual nfs(5) y mount(8).
