NOMBRE

modgzip2dlf - convierte archivos de registro del servidor web en formato Common Log con extensiones mod_gzip a DLF

SINOPSIS

modgzip2dlf archivo

DESCRIPCIÓN

modgzip2dlf convierte el archivo de registro del servidor web en formato Common Log con extensiones para mod_gzip a DLF de www.

mod_gzip es una extensión de Apache desarrollada por RemoteCommunications, Inc. El código fuente está disponible gratuitamente en http://www.RemoteCommunications.com/apache/mod_gzip/mod_gzip. Se puede encontrar más información en http://www.RemoteCommunications.com/apache/mod_gzip/mod_gzip_faq.htm.

mod_gzip puede registrar información sobre la compresión de páginas configurando Apache para registrar usando el formato 'gzip', que se puede definir de la siguiente manera:

LogFormat "%h %l %u %t \"%r\" %>s %b %{mod_gzip_result}n %{mod_gzip_compression_ratio}n" gzip

EXTENSIONES DE MOD_GZIP

Las extensiones de mod_gzip agregan dos campos al Formato de Registro Común; ver common2dlf(1):

gzip_result compression_ratio
gzip_result
El código de resultado de gzip. Normalmente OK.
ratio_de_compresión
La relación por la cual se comprimió el contenido. Un número de 0 a 100.

Ejemplo de registro:

127.0.01 - - [11/03/2001 12:12:01 -0400] "GET / HTTP/1.0" 200 252 "-" "Mozilla/5.0" OK 49
dsl1.myprovider.com - francis [11/03/2001 12:14:01 -0400] "GET /secret/ HTTP/1.0" 200 300 "http://www.example.com/index.html" "Mozilla/5.0" OK 74

EJEMPLOS

Para procesar un registro como el producido en el formato de registro modgzip:

$ modgzip2dlf < common.log

modgzip2dlf se usará raramente por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report modgzip < /var/log/httpd/common.log
