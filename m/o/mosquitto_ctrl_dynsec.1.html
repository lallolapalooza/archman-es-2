NOMBRE

mosquitto_ctrl_dynsec - módulo de mosquitto_ctrl para controlar el plugin de seguridad dinámica de Mosquitto.

SINOPSIS

mosquitto_ctrl [opciones-de-conexión] dynsec comando-dynsec [opciones-de-comando]

DESCRIPCIÓN

Esta página describe el módulo dynsec para mosquitto_ctrl(1). Consulte la página del manual de mosquitto_ctrl para obtener detalles sobre las opciones para conectarse a brokers remotos, en particular, dado que este módulo funciona con autenticación y control de acceso, es crucial que se utilicen conexiones encriptadas seguras.

COMANDOS

Inicialización del archivo de configuración

•mosquitto_ctrl dynsec init nombre-archivo-configuración usuario-admin [contraseña-admin]

ERRORES

La información sobre errores de mosquitto se puede encontrar en https://github.com/eclipse/mosquitto/issues
