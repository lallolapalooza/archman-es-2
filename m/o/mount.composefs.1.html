NOMBRE

mount.composefs - montar una imagen de sistema de archivos composefs

SINOPSIS

mount.composefs [-o OPCIONES] IMAGEN DIRECTORIOTARGET

DESCRIPCIÓN

El proyecto composefs utiliza un archivo de imagen EROFS para almacenar metadatos, y uno o más directorios separados que contienen datos de respaldo dirigidos por contenido para archivos regulares.

mount.composefs monta un archivo EROFS de este tipo en combinación con un conjunto dado de directorios base en la ubicación especificada. Puede ser llamado directamente, o como un ayudante de montaje ejecutando mount -t composefs ....

OPCIONES

El argumento IMAGEN proporcionado debe ser una imagen de metadatos composefs (EROFS) válida. El DIRECTORIOTARGET se utilizará como destino de montaje.

mount.composefs acepta las siguientes opciones de montaje separadas por dos puntos cuando se pasan a través del argumento -o OPCIONES.

basedir=RUTA
Esta ruta se utilizará para resolver referencias de archivos no vacíos almacenados en la imagen de metadatos composefs. Un caso de uso principal es tener que esta sea la misma ruta que se proporciona a mkcomposefs --digest-store=RUTA.

Se pueden especificar varias rutas, separadas por :.

digest=DIGEST
Se valida que el archivo de imagen tenga el digest de fs-verity especificado antes de ser utilizado. Esto permite una cadena de confianza que asegura que solo los datos esperados estén siempre visibles en el montaje.

Esta opción también implica verity.

idmap=RUTA
Especifique una ruta a un espacio de nombres de usuario cuyo mapeo de ID deba utilizarse. El formato típico para este tipo de ruta es /proc/<pid>/ns/user
verity
Si se especifica esto, todos los archivos en la IMAGEN deben especificar un digest de fs-verity, y todos los archivos en los directorios base deben tener un digest de fs-verity coincidente.

Nota: Esto requiere soporte para la opción "verity" de overlayfs en el kernel, que se añadió en 6.6rc1.

ro
Monta el sistema de archivos de solo lectura. Esto es principalmente útil cuando se utiliza upperdir ya que las imágenes composefs sin capas son naturalmente de solo lectura.
rw
Anula una opción ro previa.
upperdir
Especifique un upper dir en el montaje overlayfs que utiliza composefs. Esto permite una capa escribible encima de la imagen composefs. Consulte la documentación de overlayfs para obtener detalles.
workdir
Especifica un workdir de overlayfs para acompañar a upperdir.
