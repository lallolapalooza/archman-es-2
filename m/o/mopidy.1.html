NOMBRE

mopidy - servidor de música

SINOPSIS

mopidy
[-h] [–version] [-q] [-v] [–config CONFIG_FILES] [-o CONFIG_OVERRIDES] [COMANDO] …

DESCRIPCIÓN

Mopidy es un servidor de música que puede reproducir música tanto de múltiples fuentes, como tu disco duro local, transmisiones de radio, y de Spotify y SoundCloud. Las búsquedas combinan resultados de todas las fuentes de música, y puedes mezclar pistas de todas las fuentes en tu cola de reproducción. Tus listas de reproducción de Spotify o SoundCloud también están disponibles para su uso.

El comando mopidy se utiliza para iniciar el servidor.

OPCIONES

--help, -h
Mostrar mensaje de ayuda y salir.
--version
Mostrar el número de versión de Mopidy y salir.
--quiet, -q
Mostrar menos salida: nivel de advertencia y superior.
--verbose, -v
Mostrar más salida. Repetir hasta cuatro veces para aún más.
--config <archivo|directorio>
Especificar archivos y directorios de configuración a utilizar. Para usar múltiples archivos de configuración o directorios, separarlos con dos puntos. Los archivos posteriores anulan a los anteriores si hay un conflicto. Al especificar un directorio, se utilizan todos los archivos que terminan en .conf en el directorio.
--option <opcion>, -o <opcion>
Especificar valores de configuración adicionales en el formato sección/clave=valor. Puede proporcionarse varias veces.

COMANDOS INTEGRADOS

config
Mostrar la configuración efectiva actual. Todas las fuentes de configuración se combinan para mostrar el documento efectivo. Los valores secretos, como las contraseñas, se enmascaran. La configuración para extensiones deshabilitadas no está incluida.
deps
Mostrar dependencias, sus versiones y ubicación de instalación.

COMANDOS DE EXTENSIÓN

Adicionalmente, las extensiones pueden proporcionar comandos extra. Ejecuta mopidy –help para obtener una lista de lo que está disponible en tu sistema y ayuda específica del comando. Los comandos para extensiones deshabilitadas se listarán, pero no se podrán ejecutar.

ARCHIVOS

/etc/mopidy/mopidy.conf
Archivo de configuración de Mopidy para todo el sistema.
~/.config/mopidy/mopidy.conf
Tu archivo de configuración personal de Mopidy. Anula cualquier configuración del archivo de configuración del sistema.

EJEMPLOS

Para iniciar el servidor de música, ejecuta:

mopidy

Para iniciar el servidor con un archivo de configuración adicional, que puede anular las configuraciones establecidas en los archivos de configuración predeterminados, ejecuta:

mopidy --config ./mi-config.conf

Para iniciar el servidor y cambiar un valor de configuración directamente en la línea de comandos, ejecuta:

mopidy --option mpd/enabled=false

La opción --option puede repetirse varias veces para cambiar múltiples configuraciones:

mopidy -o mpd/enabled=false -o spotify/bitrate=320
