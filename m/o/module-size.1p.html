MODULE-SIZE(1p) Documentación de Perl aportada por el usuario MODULE-SIZE(1p)

NOMBRE

module-size -- Muestra el tamaño estimado del código del módulo.

SINOPSIS

module-size Some::Module::Name [ Other::Module ]

DESCRIPCIÓN

Informa sobre el tamaño del proceso después de usar un módulo. Si se proporciona más de un nombre de módulo, los módulos se incluyen en orden, lo que te permite comparar (por ejemplo) el efecto incremental de agregar otros módulos a una aplicación existente.

VER TAMBIÉN
