NOMBRE

modem-manager-gui - interfaz gráfica sencilla para el demonio Modem Manager.

SINOPSIS

modem-manager-gui [ -i ] [ -m módulo ] [ -c módulo ] [ -l ]...

DESCRIPCIÓN

Este programa es una interfaz gráfica sencilla para los demonios Modem Manager 0.6/0.7, Wader y oFono, utilizando la interfaz dbus.

-i, --invisible
No mostrar ventana al inicio
-m, --mmmodule
Usar el módulo de gestión de módem especificado
-c, --cmmodule
Usar el módulo de gestión de conexión especificado
-l, --listmodules
Listar todos los módulos disponibles y salir
