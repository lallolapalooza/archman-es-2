NOMBRE

most - explorar o paginar un archivo de texto

SINOPSIS

most [ -1 ] [ -b ] [ -C ] [ -c ] [ -d ] [ -M ] [ -r ] [ -s ] [ -t ] [ -u ] [ -v ] [ -w ] [ -z ] [ +/cadena ] [ +número-de-línea ] [ +d ] [ +s ] [ +u ] [ archivo... ]

DESCRIPCIÓN

most es un programa de paginación que muestra, una ventana a la vez, el contenido de un archivo en una terminal. Hace una pausa después de cada ventana y muestra en la línea de estado de la ventana el nombre del archivo, el número de línea actual y el porcentaje del archivo mostrado hasta el momento.

A diferencia de otros programas de paginación, most es capaz de mostrar un número arbitrario de ventanas siempre que cada ventana ocupe al menos dos líneas de pantalla. Cada ventana puede contener el mismo archivo o uno diferente. Además, cada ventana tiene su propio modo. Por ejemplo, una ventana puede mostrar un archivo con sus líneas ajustadas mientras que otra puede estar truncando las líneas. Las ventanas pueden estar "bloqueadas" entre sí en el sentido de que si una de las ventanas bloqueadas se desplaza, todas las ventanas bloqueadas se desplazarán. most también es capaz de ignorar las líneas que están indentadas más allá de un valor especificado por el usuario. Esto es útil al ver programas de computadora para destacar las características generales del código. Consulte el comando `:o' para una descripción de esta característica.

Además de mostrar archivos de texto ordinarios, most también puede mostrar archivos binarios, así como archivos con caracteres ASCII arbitrarios. Cuando un archivo se lee en un búfer, most examina los primeros 32 bytes del archivo para determinar si es un archivo binario y luego cambia al modo apropiado. Sin embargo, esta característica puede deshabilitarse con la opción -k. Consulte la descripción de las opciones -b, -k, -v y -t para obtener más detalles.

Los archivos de texto pueden contener combinaciones de caracteres de subrayado y retroceso que hacen que una impresora subraye o sobrescriba. Cuando most reconoce esto, inserta las secuencias de escape apropiadas para lograr el efecto deseado. Además, algunos archivos hacen que la impresora sobrescriba algunos caracteres incrustando caracteres de retorno de carro en medio de una línea. Cuando esto ocurre, most muestra el carácter sobrescrito con un atributo en negrita. Esta característica facilita la lectura de las páginas del manual de UNIX o de un documento producido por runoff. En particular, ver este documento con most debería ilustrar este comportamiento siempre que los caracteres de subrayado no hayan sido eliminados. Esto se puede desactivar con la opción -v.

Por defecto, las líneas con más caracteres que el ancho de la terminal no se ajustan, sino que se truncan. Cuando ocurre el truncamiento, esto se indica con un `$' en la última columna de la pantalla de la terminal. Las teclas de flecha DERECHA e IZQUIERDA se pueden usar para ver líneas que se extienden más allá de los márgenes de la pantalla. La opción -w puede usarse para anular esta característica. Cuando una ventana se ajusta, el carácter `\' aparecerá en el borde derecho de la ventana.

Los comandos se enumeran a continuación.

SOPORTE DE COLOR

most ha soportado terminales de 256 colores y de color real de 24 bits desde la versión 5.2. No todas las terminales son capaces de generar colores arbitrarios de 24 bits. Si su terminal soporta colores de 24 bits, pero most no lo detecta, entonces establezca la variable de entorno

     COLORTERM=truecolor

para forzar el uso de colores reales de 24 bits.

OPCIONES

-1
Modo VT100. Esto solo es significativo en sistemas VMS. Esta opción debe usarse si la terminal es estrictamente una VT100. Esto implica que la terminal no tiene la capacidad de eliminar e insertar múltiples líneas. Las VT102 y superiores tienen esta capacidad.
-b
Modo binario. Use este interruptor cuando desee ver archivos que contengan caracteres de 8 bits. most mostrará el archivo con 16 bytes por línea en notación hexadecimal. Una línea típica se ve así: 
   01000000 40001575 9C23A020 4000168D     ....@..u.#. @...

Cuando se usa con la opción -v, la misma línea se ve así:

   ^A^@^@^@  @^@^U u 9C #A0    @^@^V8D     ....@..u.#. @...
-C
Deshabilitar el soporte de color.
-c
Hacer que las búsquedas distingan entre mayúsculas y minúsculas
-d
Omitir la marca de barra invertida que denota una línea ajustada.
-M
Deshabilitar el uso de mmap.
-r
Usar búsquedas de expresiones regulares por defecto
-s
Modo de compresión. Reemplazar múltiples líneas en blanco con una sola línea en blanco.
-t
Mostrar tabulaciones como ^I. Si esta opción va seguida inmediatamente de un entero, el entero establece el ancho de la tabulación, por ejemplo, -t4
-u
Deshabilitar el modo UTF-8 incluso si la configuración regional lo indica
+u
Forzar el modo UTF-8. Por defecto, most usará la configuración regional actual para determinar si se debe usar el modo UTF-8. Los interruptores +u y -u permiten anular el comportamiento
-v
Mostrar caracteres de control como en `^A' para control A. Normalmente most no interpreta caracteres de control.
-w
Ajustar líneas
-z
Deshabilitar la descompresión automática de gzip
+/cadena
Iniciar en la línea que contiene la primera ocurrencia de cadena
+nro-línea
Iniciar en el número de línea especificado
+d
Este interruptor solo debe usarse si desea la opción de eliminar un archivo mientras lo visualiza. Esto facilita la limpieza de archivos no deseados de un directorio. El archivo se elimina con la secuencia de teclas interactiva `:D' y luego confirmando con `y'.
+s
Modo seguro: sin editar, cambiar de directorio, shell, ni leer archivos que no estén ya listados en la línea de comandos.

USO DE COMANDOS

Los comandos surten efecto inmediatamente; no es necesario escribir un retorno de carro. En los siguientes comandos, i es un argumento numérico (1 por defecto).

ESPACIO, CTRL-D, SIGUIENTE_PANTALLA
Mostrar otra ventana, o saltar i ventanas si se especifica i.
INTRO, FLECHA_ABAJO, V, CTRL-N
Mostrar otra línea, o i líneas más, si se especifica.
FLECHA_ARRIBA, ^, CTRL-P
Mostrar línea anterior, o i líneas anteriores, si se especifica.
T, ESCAPE<
Moverse al principio del búfer.
B, ESCAPE>
Moverse al final del búfer.
FLECHA_DERECHA, TAB, >
Desplazar la ventana 60i columnas hacia la izquierda para ver líneas que están más allá del margen derecho de la ventana.
FLECHA_IZQUIERDA, CTRL-B, <
Desplazar la ventana 60i columnas hacia la derecha para ver líneas que están más allá del margen izquierdo de la ventana.
U, CTRL-U, SUPRIMIR, PANTALLA_ANTERIOR
Saltar hacia atrás i ventanas y luego mostrar una ventana.
R, CTRL-R
Redibujar la ventana.
J, G
Si no se especifica i, solicitar un número de línea y luego saltar a esa línea; de lo contrario, simplemente saltar a la línea i.
%
Si no se especifica i, solicitar un número de porcentaje y luego saltar a ese porcentaje del archivo; de lo contrario, simplemente saltar al i por ciento del archivo.
W, w
Si el ancho de pantalla actual es 80, cámbielo a 132 y viceversa. Para otros valores, este comando se ignora.
