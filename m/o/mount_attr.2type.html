mount_attr(2type) mount_attr(2type)

NOMBRE

mount_attr - qué propiedades de montaje establecer y borrar

BIBLIOTECA

Cabeceras del kernel de Linux

SINOPSIS

#include <sys/mount.h>
struct mount_attr {
    u64 attr_set;     /* Propiedades de montaje a establecer */
    u64 attr_clr;     /* Propiedades de montaje a borrar */
    u64 propagation;  /* Tipo de propagación de montaje */
    u64 userns_fd;    /* Descriptor de archivo del espacio de nombres de usuario */
    /* ... */
};

DESCRIPCIÓN

Especifica qué propiedades de montaje se deben cambiar con mount_setattr(2).

Los campos son los siguientes:

.attr_set
Este campo especifica qué banderas MOUNT_ATTR_* se deben establecer.
.attr_clr
Este campo especifica qué banderas MOUNT_ATTR_* se deben borrar.
.propagation
Este campo especifica qué propagación de montaje se aplicará. Los valores válidos para este campo son los mismos tipos de propagación descritos en mount_namespaces(7).
.userns_fd
Este campo especifica un descriptor de archivo que indica qué espacio de nombres de usuario se utilizará como referencia para montajes mapeados por ID con MOUNT_ATTR_IDMAP.

ESTÁNDARES

Linux.

HISTORIA

Linux 5.12. glibc 2.36.

Se pueden añadir campos adicionales a la estructura, con un valor cero en un nuevo campo que hará que el kernel se comporte como si esa extensión de campo no estuviera presente. Por lo tanto, un usuario debe poner a cero esta estructura al inicializarla.
