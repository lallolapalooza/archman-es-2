NOMBRE

moggsplit - divide flujos lógicos Ogg

SINOPSIS

moggsplit nombre_archivo ...

DESCRIPCIÓN

moggsplit divide un flujo Ogg multiplexado en archivos separados. Por ejemplo, puede separar un OGM en flujos Ogg DivX y Ogg Vorbis separados, o un archivo Ogg Vorbis encadenado en dos archivos separados.

OPCIONES

--extension
Usa la extensión proporcionada al generar nuevos archivos; el valor predeterminado es ogg.
--pattern
Usa el patrón proporcionado al generar nuevos archivos. Esta es una cadena de formato de palabra clave de Python con tres variables: base para el nombre base del archivo original, stream para el número de serie del flujo y ext para la extensión dada por --extension.

El valor predeterminado es %(base)s-%(stream)d.%(ext)s.

--m3u
Genera una lista de reproducción m3u junto con los archivos recién generados. Útil para Ogg encadenados grandes.
