MOTION(1) Motion Options and Config Files MOTION(1)

NOMBRE

motion - Detecta movimiento usando un dispositivo video4linux o una cámara de red

SINOPSIS

motion [ -hbnsm ] [ -c ruta/archivo/configuracion ] [ -d nivel ] [ -k nivel ] [ -p archivo/pid ][ -l archivo/log ]

DESCRIPCIÓN

Motion utiliza un dispositivo video4linux o una cámara de red para detectar movimiento. Si se detecta movimiento, se pueden tomar tanto imágenes normales como de movimiento. Motion también puede tomar acciones para notificarte si es necesario. La creación de instantáneas automatizadas también es posible.

OPCIONES

-c
Ruta completa y nombre del archivo de configuración. Por ejemplo: /home/kurt/motion.conf. El valor predeterminado es /usr/local/etc/motion a menos que se especifique de manera diferente al compilar Motion. Muchos paquetes RPM y Debian usarán /etc o /etc/motion como valor predeterminado.
-h
Muestra la pantalla de ayuda.
-b
Ejecutar en modo demonio.
-n
Ejecutar en modo no demonio.
-s
Ejecutar en modo de configuración. También fuerza el modo no demonio.
-d
Ejecutar con nivel de registro de mensajes 1-9.
-k
Ejecutar con tipo de registro de mensajes 1-9.
-l
Ruta completa y nombre del archivo de registro.
-p
Ruta completa y nombre del archivo de ID de proceso (archivo pid). Por ejemplo, /var/run/motion.pid. El valor predeterminado no está definido. El archivo pid solo se crea cuando Motion se inicia en modo demonio.
-m
Iniciar en modo de pausa.

OPCIONES DEL ARCHIVO DE CONFIGURACIÓN

Estas son las opciones que se pueden usar en el archivo de configuración. ¡Son anuladas por la línea de comandos! Todos los valores numéricos son números enteros (no se permiten decimales). Las opciones booleanas pueden ser activadas/desactivadas (los valores "1", "yes" y "on" significan verdadero y cualquier otro valor significa falso).

Valores: on/off
Por defecto: off
Descripción:
Cuando se especifica como ON, Motion entra en modo demonio (proceso en segundo plano) y libera la terminal.

Valores: on/off
Por defecto: off
Descripción:

Archivo para almacenar el ID del proceso, también llamado archivo pid.

Valores: Cadena especificada por el usuario
Por defecto: No definido
Descripción:
Archivo para guardar los mensajes de registro, si no se define se utiliza stderr y syslog.
log_level
Valores: 1 a 9 (EMG, ALR, CRT, ERR, WRN, NTC, INF, DBG, ALL)
Por defecto: 6 / NTC
Descripción:
Especifica el nivel de verbosidad en los mensajes enviados al registro.

Valores: COR, STR, ENC, NET, DBL, EVT, TRK, VID, ALL
Por defecto: ALL
Descripción:
Filtro para registrar mensajes por tipo.

Por defecto: on
Descripción:
No emitir pitidos al detectar movimiento.

Valores: booleano
Por defecto: on

Valores: Cadena especificada por el usuario
Por defecto: No definido
Descripción:
Cadena especificada por el usuario para describir la cámara.
camera_id
Valores: Número de identificación numérico para la cámara
Por defecto: El orden en que la cámara es abierta por Motion
Descripción:
Use esta opción para asignar un número a cada cámara que sea consistente cada vez que se inicia Motion. Por defecto, Motion asignará un número basado en la secuencia en que lee la configuración y esta secuencia puede no ser la misma cada vez que se inicia Motion.
camera
Valores: Cadena especificada por el usuario
Por defecto: No definido
Descripción:
Esta opción especifica la ruta completa y el nombre del archivo para archivos de cámara individuales. Esta opción se puede listar varias veces. Cada archivo de cámara debe contener las opciones que son únicas para esa cámara/dispositivo de video. Las opciones comunes se obtienen del archivo motion.conf y los valores se sobrescriben desde cada archivo de cámara. Mientras que motion.conf incluye cuatro archivos de cámara de ejemplo, el límite real de cámaras solo depende de las capacidades de la máquina. Recuerde: Si tiene más de una cámara, debe tener un archivo de cámara para cada una. Por ejemplo, 2 cámaras requerirían 3 archivos: El archivo motion.conf Y camera1.conf y camera2.conf. Solo coloque las opciones que son únicas para cada cámara en los archivos de configuración de cámara.

NOTAS

Instantánea
Una instantánea es una imagen tomada a intervalos regulares, independientemente de cualquier movimiento en la imagen.
Imagen en movimiento
Una imagen/película de "movimiento" muestra los píxeles que han cambiado realmente durante los últimos fotogramas. Estas imágenes no son muy útiles para la presentación normal al público, pero son bastante útiles para probar, ajustar y crear archivos de máscara, ya que puedes ver exactamente dónde el movimiento detecta algo moviéndose. El movimiento se muestra en tonos de gris. Si el etiquetado está habilitado, el área más grande se marca en azul. La máscara inteligente se muestra en rojo.
Imagen normal
Una imagen "normal" es la imagen real tomada por la cámara con texto superpuesto.
Cámaras y archivos de configuración
Si Motion se invocó con la opción de línea de comandos -c ruta, Motion esperará que el archivo de configuración esté especificado. Cuando especificas el archivo de configuración en la línea de comandos con -c, puedes llamarlo como quieras.
Si no especificas -c o el nombre de archivo que le das a Motion no existe, Motion buscará el archivo de configuración llamado 'motion.conf' en el siguiente orden:
1. Directorio actual desde donde se invocó Motion
2. Luego en un directorio llamado '.motion' en el directorio principal del usuario actual (variable de entorno shell $HOME). Por ejemplo, /home/goofy/.motion/motion.conf
3. El subdirectorio motion/ dentro del directorio definido por --sysconfdir=DIR al ejecutar .configure durante la instalación de Motion (si esta opción no se definió, el valor predeterminado es /usr/local/etc/)
Si tienes acceso de escritura a /usr/local/etc/motion, el editor recomienda tener un solo archivo motion.conf en el directorio predeterminado /usr/local/etc/motion.
Motion tiene un archivo de configuración en el paquete de distribución llamado motion-dist.conf. Cuando ejecutas 'make install', este archivo se copia al directorio /usr/local/etc/motion.
El archivo de configuración necesita ser renombrado de motion-dist.conf a motion.conf. El archivo original se llama motion-dist.conf para que tu archivo motion.conf que funciona perfectamente no se sobrescriba accidentalmente al reinstalar o actualizar a una nueva versión de Motion.
Si tienes más de una cámara, no deberías intentar invocar Motion más veces. Motion está diseñado para funcionar con más de una cámara de una manera muy elegante y la forma de hacerlo es crear un número de archivos de configuración de cámara. Motion creará entonces un hilo adicional de sí mismo para cada cámara. Si solo tienes una cámara, solo necesitas el archivo motion.conf. En el momento en que tengas dos o más cámaras, debes tener un archivo de configuración de cámara por cámara además del archivo motion.conf.
Por lo tanto, si tienes, por ejemplo, dos cámaras, necesitas motion.conf y dos archivos de configuración de cámara. Un total de 3 archivos de configuración.
Una opción común a todas las cámaras se puede colocar en motion.conf. (También puedes colocar todos los parámetros en los archivos de cámara, pero eso implica mucha edición cuando cambias algo común).
Una opción única para una cámara debe definirse en cada archivo de cámara.
La primera cámara se define en el primer archivo de cámara llamado desde motion.conf. La segunda cámara se define en el segundo archivo de cámara llamado desde motion.conf, etc.
Cualquier opción definida en motion.conf se utilizará para todas las cámaras, excepto para aquellas en las que la misma opción se define en un archivo de configuración de cámara.
Motion lee sus parámetros de configuración en la siguiente secuencia. Si el mismo parámetro existe en más de un lugar, el último leído gana.
1. Motion lee el archivo de configuración motion.conf desde el principio del archivo, línea por línea.
2. Si la opción "camera" está definida en motion.conf, se lee el/los archivo(s) de configuración de cámara.
3. Motion continúa leyendo el resto del archivo motion.conf. Cualquier opción de aquí anulará la misma opción definida previamente en un archivo de configuración de cámara.
4. Motion lee nuevamente la opción de línea de comandos, anulando cualquier opción definida previamente.
Por lo tanto, siempre llama a los archivos de configuración de cámara al final del archivo motion.conf. Si defines opciones en motion.conf DESPUÉS de las llamadas a los archivos de cámara, las mismas opciones en los archivos de cámara nunca se utilizarán. Así que siempre pon la llamada al archivo de cámara al final de motion.conf.
Si Motion se compila sin características específicas como ffmpeg, mysql, etc., ignorará las opciones que pertenecen a estas características. No tienes que eliminarlas ni comentarlas.
Si ejecutas el comando de control http http://host:port/0/config/writeyes, Motion sobrescribirá motion.conf y todos los archivos camera.conf con archivos de configuración autogenerados, bien formateados y solo con las características incluidas con las que se compiló Motion. Si más tarde recompilas Motion con más características o actualizas a una nueva versión, puedes usar tus archivos de configuración antiguos, ejecutar el comando motion.conf.write y tendrás nuevos archivos de configuración con las nuevas opciones incluidas, todas establecidas en sus valores predeterminados. Esto hace que las actualizaciones sean muy fáciles de realizar.
