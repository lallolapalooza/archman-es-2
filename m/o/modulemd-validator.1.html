MODULEMD-VALIDATOR(1) Comandos de usuario MODULEMD-VALIDATOR(1)

NOMBRE

modulemd-validator - valida documentos modulemd

SINOPSIS

modulemd-validator [--quiet|--verbose|--debug] ARCHIVO...
modulemd-validator [--quiet|--verbose|--debug] --type=TIPO ARCHIVO
modulemd-validator {--version|--help}

DESCRIPCIÓN

Esta herramienta valida documentos modulemd especificados con los argumentos posicionales utilizando un analizador libmodulemd.

Sin una opción --type, se reconocerán todos los tipos de documento que se puedan encontrar en un repositorio YUM. En este caso, cada ARCHIVO puede contener múltiples documentos modulemd.

De lo contrario, se debe proporcionar exactamente un ARCHIVO que contenga exactamente un documento modulemd y el documento se validará contra el TIPO dado.

OPCIONES

--type=TIPO
Restringe un tipo de documento. Los tipos reconocidos son:
modulemd-v1
Un formato obsoleto utilizado para construir e instalar módulos.
modulemd-v2
Un formato obsoleto para construir módulos y un formato contemporáneo para módulos construidos que se pueden colocar en un repositorio YUM e instalar por un gestor de paquetes.
modulemd-defaults-v1
Un formato para definir streams y perfiles predeterminados de un módulo. Se encuentra en repositorios YUM.
modulemd-obsoletes-v1
Un formato para definir streams que alcanzan o alcanzarán su fin de vida. También puede recomendar un nuevo stream que ha obsoleto el antiguo. Se encuentra en repositorios YUM.
modulemd-packager-v2
Un formato obsoleto para construir módulos.
modulemd-packager-v3
Un formato contemporáneo para construir módulos.
modulemd-translations-v1
Un formato contemporáneo para entregar textos localizados orientados al humano (por ejemplo, una descripción o un resumen) asociados con un módulo. Se encuentra en repositorios YUM.
Solo se admiten archivos de un solo documento. Por compatibilidad, si no se proporciona esta opción, se acepta cualquier tipo de documento que se pueda cargar en un índice modulemd (es decir, aquellos destinados a repositorios YUM).
--debug
Mostrar mensajes de depuración.
-q, --quiet
No imprimir ninguna salida.
-v, --verbose
Ser verboso.
-h, --help
Imprimir un texto de uso y luego salir.
-V, --version
Imprimir el número de versión y luego salir.

CÓDIGO DE SALIDA

Si los documentos proporcionados son válidos (y satisfacen la restricción --type), se devolverá un código de salida cero. De lo contrario, se emitirá un código distinto de cero.

INFORME DE ERRORES

Los errores y las solicitudes de características se pueden informar en la página principal de libmodulemd.

VER TAMBIÉN

La especificación de los documentos modulemd está disponible en el directorio yaml_spec en la página principal de libmodulemd.
