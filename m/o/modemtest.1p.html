NOMBRE

modemtest - Herramienta para examinar tu módem a través de Device::SerialPort de Perl

SINOPSIS

modemtest [OPCIONES] [DISPOSITIVO [BAUDIOS [DATOS [PARIDAD [PARADA [FLUJO]]]]]]

DISPOSITIVO    Dispositivo a usar como puerto serie (predeterminado: "/dev/modem")
BAUDIOS      Velocidad serie a usar            (predeterminado: 9600)
DATOS      Número de bits de datos a usar      (predeterminado: 8)
PARIDAD    Tipo de paridad a usar          (predeterminado: "none")
PARADA      Número de bits de parada a usar     (predeterminado: 1)
FLUJO      Tipo de control de flujo a usar    (predeterminado: "none")
-h, --help           Informe de ayuda
    --skip-status    Omitir pruebas de bits de estado del módem
    --hide-possible  No mostrar todas las configuraciones posibles

DESCRIPCIÓN

Algunos sistemas, puertos serie y módems se comportan de manera extraña. Para probar las capacidades de Device::SerialPort de Perl, esta herramienta consulta la configuración del sistema para el DISPOSITIVO dado, e intenta configurar el puerto y enviar la cadena de inicialización "ATE1" al módem, informando de los resultados observados.
