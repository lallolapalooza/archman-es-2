NOMBRE

mouse-test - una herramienta para determinar el tipo de ratón y el dispositivo al que está conectado.

SINTAXIS

mouse-test [ dispositivo ... ]

DESCRIPCIÓN

Esta aplicación experimental e incompleta intenta ayudar a detectar qué protocolo utiliza tu ratón. Es capaz de detectar dispositivos MouseMan y de elegir entre -t ms (con conocimiento de tres botones) y ratones serial de dos botones antiguos sin más.

ERRORES

Sé que la aplicación tiene errores, pero solo poseo un dispositivo de ratón. Si estás interesado en esta aplicación, solo llámame y despiértame de mi pereza.

OPCIONES

dispositivo
[ dispositivo ... ]

Comprueba este dispositivo en busca de un ratón. Si no se enumeran dispositivos, mouse-test intentará en todos los dispositivos posibles.

AUTOR

Alessandro Rubini <rubini@linux.it>

ARCHIVOS

/dev/*              Los dispositivos utilizados para buscar un ratón
