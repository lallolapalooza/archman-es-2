mode_t(3type) mode_t(3type)

NOMBRE

mode_t - atributos de archivo

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/types.h>
typedef /* ... */ mode_t;

DESCRIPCIÓN

Se utiliza para algunos atributos de archivo (por ejemplo, modo de archivo). Es un tipo de entero.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan este tipo: <fcntl.h>, <ndbm.h>, <spawn.h>, <sys/ipc.h>, <sys/mman.h> y <sys/stat.h>.

VER TAMBIÉN

chmod(2), mkdir(2), open(2), umask(2), stat(3type)
