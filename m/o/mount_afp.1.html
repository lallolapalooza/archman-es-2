MOUNT_AFP(8) Manual del Administrador del Sistema MOUNT_AFP(8)

NOMBRE

mount_afp — montar un sistema de archivos afp (AppleShare) usando FUSE

SINOPSIS

mount_afp [-o opciones] afp_url nodo

DESCRIPCIÓN

El comando mount_afp monta el volumen AFP denominado por la url afp afp://[usuario[;AUTH=uamname][:contraseña]@]host[:puerto]/nombrevolumen en el punto de montaje indicado por nodo.

Normalmente es un enlace simbólico al ejecutable afp_client(1), que es una implementación completa para montar volúmenes AFP utilizando la infraestructura FUSE. Se comunica con afpfsd, un demonio que gestiona sesiones AFP. Los argumentos y opciones son:

-o
Las opciones pasadas a mount(2) se especifican con la opción -o seguida de una cadena de opciones separadas por comas. Consulte la página del manual para ver las opciones posibles y sus significados. Las opciones adicionales admitidas por el Cliente AFP son las siguientes:
volpass=<contraseña>
La única opción disponible es "-o volpassword=XXX" para establecer la contraseña del volumen (ya que no hay una instalación para eso en una URL AFP).
rw
Montar el volumen como escribible. Este es el valor predeterminado, por lo que no tiene ningún efecto.
ro
Montar el volumen como de solo lectura.
group=<nombregrupo>
Montar el volumen como nombregrupo.
user=<nombreusuario>
Montar el volumen como nombreusuario.
afp_url
Hay dos formas de URL afp, una para TCP/IP y otra para AppleTalk:

afp://[usuario[;AUTH=uamname][:contraseña]@]host[:puerto]/volumen

afp:/at/[usuario[;AUTH=uamname][:contraseña]@]nombreservidor[:zonadeorigen]/volumen

Denota el servidor afp y el punto de acceso a compartir a montar. También puede contener el nombre de usuario y la contraseña necesarios para iniciar sesión en el servidor. uamname es el nombre del protocolo del método de autenticación. Si no se especifica el puerto, se utiliza el puerto 548.

nodo
Ruta al punto de montaje, que debe ser un directorio para el que el usuario tenga permisos de escritura.

EJEMPLOS

El siguiente ejemplo ilustra cómo montar el volumen afp server.company.com/nombrevolumen/ en el punto de montaje /Volumes/mntpnt:

mkdir /Volumes/mntpnt
mount_afp afp://usuario:contraseñausuario@servidor.empresa.com/nombrevolumen/ /Volumes/mntpnt
Este ejemplo muestra la URL correcta para montar el volumen guestVolume desde el servidor afp myserver como invitado: 
mkdir /Volumes/invitado
mount_afp "afp://;AUTH=No%20User%20Authent@myserver/guestVolume" /Volumes/invitado

El siguiente muestra cómo usar un nombre de usuario de "usuario:nombre" y una contraseña de "p@ssword":
server.company.com/nombrevolumen/ en el punto de montaje /Volumes/mntpnt:
mkdir /Volumes/mntpnt mount_afp afp://usuario::nombre:p@@ssword@servidor.empresa.com/nombrevolumen/ /Volumes/mntpnt
Este ejemplo muestra la URL correcta para montar el volumen myVolume desde el servidor afp myserver utilizando autenticación Kerberos: 
mkdir /Volumes/myVolume
mount_afp "afp://;AUTH=Client%20Krb%20v2@myserver/myVolume" /Volumes/myVolume

VER TAMBIÉN

afp_client(1) (para más comandos AFP), afpcmd(1) (para un cliente AFP de línea de comandos no FUSE),

HISTORIA

El comando mount_afp apareció por primera vez en la versión 10.0 de Mac OS X. La autenticación Kerberos se añadió en la versión 10.2 de Mac OS X. Esta sintaxis (y página de manual) se utilizó para la implementación FUSE de afpfs-ng.

VALORES DE RETORNO

0
mount_afp montó con éxito el directorio del volumen.
-1
No se pudo montar el volumen del servidor.

VER TAMBIÉN

afp_client(1), afpfsd(1)
