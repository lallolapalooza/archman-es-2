monodocs2html(1) Manual de Comandos Generales monodocs2html(1)

NOMBRE

monodocs2html - Traduce XML de Monodoc a HTML

SINOPSIS

monodocs2html -fuente:DIR_FUENTE -destino:DIR_DESTINO [OPCIONES]*

DESCRIPCIÓN

monodocs2html ha sido obsoleto por mdoc(1). Véase la página del manual de mdoc-export-html(1).

monodocs2html es un programa que crea documentación HTML a partir de los archivos XML de documentación de Monodoc.

OPCIONES

-destino:DIR_DESTINO
Escribe los archivos HTML en el directorio DIR_DESTINO.
-volcarplantilla
Vuelca la plantilla de página predeterminada a la salida estándar para que puedas usarla como base para una nueva plantilla para usar con la opción -plantilla.
-ext:EXTENSIÓN_ARCHIVO
EXTENSIÓN_ARCHIVO es la extensión de archivo para los archivos generados.

Por defecto es html.

-?, -ayuda
Muestra información sobre los argumentos del programa.
-solotipo:TIPO
Genera HTML solo para el tipo TIPO.
-fuente:DIR_FUENTE
DIR_FUENTE es el directorio base que contiene la documentación XML de Monodoc.

Este directorio debe contener un archivo index.xml, los archivos nombre-espacio.xml (uno por cada espacio de nombres) y directorios nombre-espacio (uno por cada espacio de nombres), que contendrán los archivos tipo.xml con la documentación de monodoc.

-plantilla:PLANTILLA
Genera HTML usando la plantilla de página PLANTILLA.
-V, -versión
Muestra la información de versión y licencia.

FORMATO DE PLANTILLA

El archivo de plantilla es un XSLT que necesita procesar el siguiente documento XML de entrada:

<Página>
  <TítuloColección>Título de la Colección</TítuloColección>
  <TítuloPágina>Título de la Página</TítuloPágina>
  <Resumen>Resumen de la Página</Resumen>
  <Firma>Declaración del Tipo</Firma>
  <Comentarios>Comentarios del Tipo</Comentarios>
  <Miembros>Miembros del Tipo</Miembros>
  <Copyright>Copyright de la Documentación</Copyright>
</Página>

El HTML generado también hace uso de las siguientes clases CSS, que deben definirse para que la salida tenga un formato agradable:

.TítuloColección
.TítuloPágina
.Resumen
.Firma
.Comentarios
.Miembros
.Copyright
.Sección
.CajaSección
.NombreEspacioNombre
.NombreEspacioResumen
.MiembroNombre
.MiembroFirma
.CajaMiembro
.Subsección
.CajaSubsección
.TablaFirma
.TablaEnumeraciones
.TablaEjemploCódigo
.ListadoMiembros
.ListadoTipos
.TablaFirmaInterna
.TablaPermisosTipo

ENLACES HTML

Todos los miembros dentro del archivo HTML tienen un atributo id para permitir el enlace a un miembro específico. El valor del atributo id es el ID de Cadena del miembro especificado. Véase la sección FORMATO DE ID DE CADENA de la página del manual de monodocer para más información.
