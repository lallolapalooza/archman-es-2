NOMBRE

mopidyctl - gestiona el servicio del sistema Mopidy music server

SINOPSIS

mopidyctl [cualquier opción de mopidy(1)]

DESCRIPCIÓN

El comando mopidyctl ejecuta subcomandos de mopidy en el mismo entorno en el que se está ejecutando el servicio del sistema Mopidy. Es decir, como el mismo usuario y con la misma configuración que está utilizando el servicio del sistema Mopidy.

OPCIONES

mopidyctl(8) toma las mismas opciones que mopidy(1).
