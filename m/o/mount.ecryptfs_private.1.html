NOMBRE

mount.ecryptfs_private - Utilidad auxiliar para montar directorios privados de eCryptfs.

SINOPSIS

mount.ecryptfs_private [ALIAS]

NOTA: Este programa no cargará dinámicamente las claves relevantes. Por esta razón, ¡se recomienda a los usuarios que utilicen ecryptfs-mount-private(1) en su lugar!

DESCRIPCIÓN

mount.ecryptfs_private es una utilidad auxiliar de montaje para que los usuarios no root monten criptográficamente un directorio privado, ~/Private por defecto.

Este programa toma opcionalmente un argumento, ALIAS. Si se omite ALIAS, el programa usará por defecto "Private" utilizando:
- $HOME/.Private como FUENTE
- $HOME/Private como DESTINO
- $HOME/.ecryptfs/Private.sig para las firmas de las claves.

Si se especifica ALIAS, el programa buscará una configuración al estilo fstab(5) en:
- $HOME/.ecryptfs/ALIAS.conf y las firmas de claves en:
- $HOME/.ecryptfs/ALIAS.sig

El montaje procederá si, y solo si:
- la contraseña requerida está en su keyring del kernel, y
- el usuario actual es propietario de ambos puntos de montaje FUENTE y DESTINO
- el DESTINO no está ya montado

Este programa:
- montará FUENTE sobre DESTINO
- como un sistema de archivos ecryptfs
- utilizando el cifrado AES
- con una longitud de clave de 16 bytes
- utilizando la contraseña cuya firma está en ~/.ecryptfs/Private.sig

La única operación setuid en este programa es la llamada a mount(8) o umount(8).

La utilidad ecryptfs-setup-private(1) creará los directorios ~/.Private y ~/Private, generará una contraseña de montaje, cifrará la contraseña y escribirá el archivo ~/.ecryptfs/Private.sig.

El administrador del sistema puede añadir el módulo pam_ecryptfs.so a la pila PAM, que utilizará automáticamente la contraseña de inicio de sesión para descifrar la contraseña de montaje, añadir la contraseña al keyring del kernel del usuario y realizar automáticamente el montaje. Véase pam_ecryptfs(8).

ARCHIVOS

~/.Private - directorio subyacente que contiene datos cifrados

~/Private - punto de montaje que contiene datos descifrados (cuando está montado)

~/.ecryptfs/Private.sig - archivo que contiene la firma de la contraseña del punto de montaje

~/.ecryptfs/wrapped-passphrase - contraseña de montaje, cifrada con la contraseña de inicio de sesión
