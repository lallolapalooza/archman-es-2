MODHEX(1) Manual de la biblioteca YubiKey C MODHEX(1)

NOMBRE

modhex - convierte datos a/desde codificación modhex

SINOPSIS

modhex [-d] [-h] DATOS

DESCRIPCIÓN

Codifica/decodifica los datos modhex DATOS a binario y hexadecimal.

OPCIONES

El string DATOS es la información a convertir.

-d

Decodifica datos (el valor predeterminado es codificar datos).

-h

Utiliza codificación hexadecimal para todos los datos que no sean modhex.

EJEMPLOS

Codificar la cadena ASCII "test" en ModHex:

modhex test

Decodificar datos ModHex "ifhgieif" a cadena ASCII:

modhex -d ifhgieif

Codificar datos codificados en hexadecimal "b565716f" en ModHex:

modhex -h b565716f

Decodificar datos ModHex "nghgibhv" e imprimir los datos codificados en hexadecimal:

modhex -d -h nghgibhv

VER TAMBIÉN

Las YubiKeys se pueden obtener de Yubico: http://www.yubico.com/
