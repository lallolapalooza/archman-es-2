NOMBRE

modinfo - Muestra información sobre un módulo del Kernel de Linux

SINOPSIS

modinfo [-0] [-F campo] [-k kernel] [nombre_módulo|nombre_archivo...]

modinfo -V

modinfo -h

DESCRIPCIÓN

modinfo extrae información de los módulos del Kernel de Linux dados en la línea de comandos. Si el nombre del módulo no es un nombre de archivo, entonces se busca en el directorio /lib/modules/ versión, como también lo hace modprobe(8) al cargar módulos del kernel.

Por defecto, modinfo lista cada atributo del módulo en forma nombrecampo : valor, para facilitar la lectura. El nombre del archivo se lista de la misma manera (aunque realmente no es un atributo).

Esta versión de modinfo puede entender módulos de cualquier arquitectura de Kernel de Linux.

OPCIONES

-V, --version

Imprime la versión de modinfo.

-F campo, --field=campo

Solo imprime este valor de campo, uno por línea. Esto es muy útil para scripts. Los nombres de los campos no distinguen mayúsculas de minúsculas. Los campos comunes (que pueden no estar en todos los módulos) incluyen author, description, license, parm, depends y alias. A menudo hay múltiples campos parm, alias y depends. El campo especial filename lista el nombre de archivo del módulo.

-b directorio_base, --basedir=directorio_base

Directorio raíz para los módulos, por defecto /.

-k kernel

Proporciona información sobre un kernel distinto al en ejecución. Esto es particularmente útil para distribuciones que necesitan extraer información de un conjunto de módulos del kernel recién instalado (pero aún no en ejecución). Por ejemplo, si desea averiguar qué archivos de firmware son necesarios para varios módulos en un nuevo kernel para el cual debe crear una imagen initrd/initramfs antes de arrancar.

-0, --null

Utiliza el carácter cero ASCII para separar los valores del campo, en lugar de una nueva línea. Esto es útil para scripts, ya que una nueva línea teóricamente puede aparecer dentro de un campo.

-a --author, -d --description, -l --license, -p --parameters, -n --filename

Estos son atajos para los argumentos author, description, license, parm y filename de la bandera --field, para facilitar la transición desde el antiguo modinfo de modutils.

-h, --help

Imprime el mensaje de ayuda y sale.
