EXFAT-FUSE(8) Manual del Administrador del Sistema EXFAT-FUSE(8)

NOMBRE

mount.exfat-fuse - montar un sistema de archivos exFAT

SINOPSIS

mount.exfat-fuse [ -d ] [ -n ] [ -o opciones ] [ -V ] [ -v ] dispositivo dir

DESCRIPCIÓN

mount.exfat-fuse es una implementación libre del sistema de archivos exFAT con soporte de escritura. exFAT es un sistema de archivos simple creado por Microsoft. Está destinado a reemplazar FAT32 eliminando algunas de sus limitaciones. exFAT es un FS estándar para tarjetas de memoria SDXC.

OPCIONES DE LÍNEA DE COMANDOS

Opciones de línea de comandos disponibles:

-d
Habilitar registro de depuración y no separarse del shell.
-n
Ignorado.
-o opciones
Opciones específicas del sistema de archivos. Para más detalles, consulte la sección OPCIONES DEL SISTEMA DE ARCHIVOS más abajo.
-V
Imprimir versión y copyright.
-v
Ignorado.

OPCIONES DEL SISTEMA DE ARCHIVOS

umask=valor
Establecer la máscara umask (la máscara de bits de los permisos que no están presentes, en octal). El valor predeterminado es 0.
dmask=valor
Establecer la máscara umask solo para directorios.
fmask=valor
Establecer la máscara umask solo para archivos.
uid=n
Establecer el propietario para todos los archivos y directorios. El valor predeterminado es el propietario del proceso actual.
gid=n
Establecer el grupo para todos los archivos y directorios. El valor predeterminado es el grupo del proceso actual.
ro
Montar el sistema de archivos en modo de solo lectura.
noatime
No actualizar la hora de acceso cuando se lee un archivo.

CÓDIGOS DE SALIDA

Se devuelve cero en caso de montaje exitoso. Cualquier otro código significa un error.

ERRORES

exFAT es un sistema de archivos insensible a mayúsculas y minúsculas. Algunas cosas pueden comportarse de manera inesperada, por ejemplo, renombrar directorios que solo cambian la capitalización de algunos caracteres:

$ mv FOO Foo
mv: no se puede mover ’FOO’ a un subdirectorio de sí mismo, ’Foo/FOO’

Esto ocurre porque mv detecta que el destino existe (para sistemas de archivos insensibles a mayúsculas y minúsculas, FOO y Foo son lo mismo) y agrega el nombre base de origen al destino. El sistema de archivos recibe la llamada del sistema rename("FOO", "Foo/FOO") y devuelve un error.
