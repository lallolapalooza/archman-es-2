mogrify(1) Manual de Comandos Generales mogrify(1)

NOMBRE

mogrify - redimensiona una imagen, desenfoca, recorta, elimina motas, difumina, dibuja sobre, invierte, re-muestrea y mucho más. Mogrify sobrescribe el archivo de imagen original, mientras que convert(1) escribe en un archivo de imagen diferente.

SINOPSIS

magick mogrify [opciones] archivo-entrada

DESCRIPCION

El programa mogrify es miembro del conjunto de herramientas ImageMagick(1). Úsalo para redimensionar una imagen, desenfocar, recortar, eliminar motas, difuminar, dibujar sobre, invertir, re-muestrear y mucho más. Esta herramienta es similar a convert(1) excepto que el archivo de imagen original es sobrescrito con cualquier cambio que solicites.

Para más información sobre el comando mogrify, abre file:///usr/share/doc/ImageMagick-7/www/mogrify.html en tu navegador o https://imagemagick.org/script/mogrify.php.

Por defecto, el formato de imagen de `archivo' se determina por su número mágico. Para especificar un formato de imagen particular, preceda el nombre del archivo con un nombre de formato de imagen y dos puntos (por ejemplo, ps:imagen) o especifique el tipo de imagen como sufijo del nombre del archivo (por ejemplo, imagen.ps). Especifique `archivo' como '-' para la entrada o salida estándar.
