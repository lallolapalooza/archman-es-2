modf(3) Manual de funciones de biblioteca modf(3)

NOMBRE

modf, modff, modfl - extraer valores integrales y fraccionarios con signo de un número de punto flotante

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double modf(double x, double *iptr);
float modff(float x, float *iptr);
long double modfl(long double x, long double *iptr);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

modff(), modfl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones descomponen el argumento x en una parte integral y una parte fraccionaria, cada una con el mismo signo que x. La parte integral se almacena en la ubicación apuntada por iptr.

VALOR DE RETORNO

Estas funciones devuelven la parte fraccionaria de x.

Si x es un NaN, se devuelve un NaN y *iptr se establece en un NaN.

Si x es infinito positivo (infinito negativo), se devuelve +0 (-0) y *iptr se establece en infinito positivo (infinito negativo).

ERRORES

No se producen errores.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
modf (), modff (), modfl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

VéASE TAMBIÉN

frexp(3), ldexp(3)
