NOMBRE

mokutil - utilidad para manipular las claves del propietario de la máquina

SINOPSIS

mokutil [--list-enrolled | -l]
([--mokx | -X])
mokutil [--list-new | -N]
([--mokx | -X])
mokutil [--list-delete | -D]
([--mokx | -X])

([--hash-file archivo_hash | -f archivo_hash] | [--root-pw | -P] |
[--mokx | -X] | [--ca-check] | [--ignore-keyring])
mokutil [--delete lista_claves | -d lista_claves]
([--hash-file archivo_hash | -f archivo_hash] | [--root-pw | -P] |
[--mokx |- X])
mokutil [--revoke-import]
([--mokx | -X])
mokutil [--revoke-delete]
([--mokx | -X])
mokutil [--export | -x]
mokutil [--password | -p]
([--hash-file archivo_hash | -f archivo_hash] | [--root-pw | -P])
mokutil [--clear-password | -c]
mokutil [--disable-validation]
mokutil [--enable-validation]
mokutil [--sb-state]
mokutil [--test-key archivo_clave | -t archivo_clave]
([--mokx | -X] | [--ca-check] | [--ignore-keyring])

([--hash-file archivo_hash | -f archivo_hash] | [--root-pw | -P] |
[--mok | -X])

mokutil [--use-db]

[--mokx | -X])
mokutil [--set-verbosity (true | false)]
mokutil [--set-fallback-verbosity (true | false)]

DESCRIPCIÓN

mokutil es una herramienta para importar o eliminar las claves del propietario de la máquina (MOK) almacenadas en la base de datos de shim.

OPCIONES

-l, --list-enrolled
Lista las claves ya almacenadas en la base de datos
-N, --list-new
Lista las claves a inscribir
-D, --list-delete
Lista las claves a eliminar
-i, --import
Recopila los siguientes archivos y forma una solicitud de inscripción para shim. Los archivos deben estar en formato DER.
-d, --delete
Recopila los siguientes archivos y forma una solicitud de eliminación para shim. Los archivos deben estar en formato DER.
--revoke-import
Revoca la solicitud de importación actual (MokNew)
--revoke-delete
Revoca la solicitud de eliminación actual (MokDel)
-x, --export
Exporta las claves almacenadas en MokListRT
-p, --password
Configura la contraseña para MokManager (MokPW)
-c, --clear-password
Borra la contraseña para MokManager (MokPW)
--disable-validation
Deshabilita el proceso de validación en shim
--enable-validation
Habilita el proceso de validación en shim
--sb-state
Muestra el estado de SecureBoot
-t, --test-key
Prueba si la clave está inscrita o no
--reset
Restablece la lista MOK
--generate-hash
Genera el hash de la contraseña
--hash-file
Usa el hash de la contraseña de un archivo específico
-P, --root-pw
Usa el hash de la contraseña de root de /etc/shadow
--ignore-db
Indica a shim que no use las claves en db para verificar imágenes EFI
--use-db
Indica a shim que use las claves en db para verificar imágenes EFI (por defecto)
-X, --mokx
Manipula la lista negra de MOK (MOKX) en lugar de la lista MOK
--import-hash
Crea una solicitud de inscripción para el hash de una clave en formato DER. Tenga en cuenta que este no es el hash de la contraseña.
--delete-hash
Crea una solicitud de eliminación para el hash de una clave en formato DER. Tenga en cuenta que este no es el hash de la contraseña.
--set-verbosity
Establece SHIM_VERBOSE para hacer que shim sea más o menos verboso
--set-fallback-verbosity
Establece FALLBACK_VERBOSE para hacer que el fallback sea más o menos verboso
--set-fallback-noreboot
Establece FB_NO_REBOOT para evitar que el fallback reinicie automáticamente el sistema
--pk
Lista las claves en la clave de plataforma pública (PK)
--kek
Lista las claves en la base de datos de firmas de claves de intercambio (KEK)
--db
Lista las claves en el almacén de firmas de arranque seguro (db)
--dbx
Lista las claves en el almacén de firmas de la lista negra de arranque seguro (dbx)
--list-sbat-revocations
Lista las entradas en el almacén de destino avanzado de arranque seguro (SBAT)
--set-sbat-policy (latest | automatic)
Establece la Variable UEFI SbatPolicy para que shim aplique las revocaciones SBAT más recientes o automáticas. Si Secure Boot de UEFI está deshabilitado, shim eliminará automáticamente las revocaciones SBAT.
--set-ssp-policy (latest | automatic | delete)
Establece la Variable UEFI SspPolicy para que shim aplique las políticas SkuSiPolicy más recientes o automáticas de Windows para gestionar las revocaciones de bootmgr. Dado que estas no son revocaciones nativas, shim no las eliminará automáticamente. Si esto es necesario, spp-policy se puede establecer en delete cuando Secure Boot esté deshabilitado. La política de eliminación no es persistente.
--timeout
Establece el tiempo de espera para la solicitud de MOK
--ca-check
Comprueba si la CA de la clave dada está ya inscrita o bloqueada en las bases de datos de claves.
--ignore-keyring
Ignora la comprobación de claves de keyring confiables integradas en el kernel al inscribir una clave en MokList
--trust-mok
Confía en las claves MOK dentro del keyring del kernel
--untrust-mok
No confía en las claves MOK dentro del keyring del kernel
