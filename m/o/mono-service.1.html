NOMBRE

mono-service, mono-service2 - Host de Mono ServiceProcess

SINOPSIS

mono-service [opciones] programa.exe

DESCRIPCIÓN

El mono-service es un host para ejecutar servicios creados con el ensamblado ServiceProcess.

Use mono-service para ejecutar servicios que usen los ensamblados 1.0 y use mono-service2 para ejecutar servicios que usen los ensamblados 2.0.

Los servicios pueden ser pausados enviando la señal SIGUSR1 al proceso, y la ejecución puede ser reanudada enviando la señal SIGUSR2. El servicio puede ser apagado limpiamente enviando la señal SIGTERM al proceso.

Las siguientes opciones pueden ser usadas para controlar el servicio:

-d:DIRECTORIO
Use esta opción para especificar el directorio de trabajo del servicio. El predeterminado es el directorio actual.
-l:ARCHIVO-DE-BLOQUEO
Especifica el archivo a usar para el bloqueo, el predeterminado es un nombre de archivo construido en /tmp basado en el nombre del programa que aloja el servicio.
-m:MENSAJE
Nombre a mostrar en syslog.
-n:NOMBRE
Use esto para especificar el servicio a lanzar (si el programa contiene más de un servicio). El predeterminado es ejecutar el primer servicio definido.
--debug
Use esta opción para evitar que mono-service redirija stdin y stdout y para evitar que el programa se ejecute en segundo plano. Equivalente a --no-daemon.
--no-daemon
Use esta opción para evitar que mono-service redirija stdin y stdout y para evitar que el programa se ejecute en segundo plano. Equivalente a --debug.

CONTROL

Puede controlar el servicio enviando señales al proceso, puede usar los siguientes comandos:

Pausando el servicio:
kill -USR1 `cat <archivo de bloqueo>`
Reanudando el servicio:
kill -USR2 `cat <archivo de bloqueo>`
Deteniendo el servicio:
kill `cat <archivo de bloqueo>`

EJEMPLOS

Iniciar el ensamblado MyService.exe, con un bloqueo en /root/service-lock:

mono-service -l:/root/service-lock MyService.exe

DEPURACIÓN

Los mensajes producidos por el servicio se registran en syslog.
