MOSQUITTO-TLS(7) Convenciones y miscelánea MOSQUITTO-TLS(7)

NOMBRE

mosquitto-tls - Configurar el soporte SSL/TLS para Mosquitto

DESCRIPCIÓN

mosquitto proporciona soporte SSL para conexiones de red cifradas y autenticación. Este manual describe cómo crear los archivos necesarios.


Nota

Es importante usar parámetros de sujeto de certificado diferentes para su CA, servidor y clientes. Si los certificados parecen idénticos, aunque se hayan generado por separado, el broker/cliente no podrá distinguirlos y experimentará errores difíciles de diagnosticar.

GENERACIÓN DE CERTIFICADOS

Las secciones siguientes proporcionan los comandos de openssl que se pueden usar para generar certificados, pero sin ningún contexto. El asciicast en https://asciinema.org/a/201826 ofrece una demostración completa de cómo usar esos comandos.

AUTORIDAD DE CERTIFICACIÓN

Generar un certificado y una clave de autoridad de certificación.

•openssl req -new -x509 -days <duración> -extensions v3_ca -keyout ca.key -out ca.crt

SERVIDOR

Generar una clave de servidor.

•openssl genrsa -aes256 -out server.key 2048

Generar una clave de servidor sin cifrado.

•openssl genrsa -out server.key 2048

Generar una solicitud de firma de certificado para enviar a la CA.

•openssl req -out server.csr -key server.key -new

Nota

Cuando se le solicite el CN (Nombre Común), introduzca el nombre de host o el nombre de dominio de su servidor (o broker).

Envíe la CSR a la CA, o fírmela con su clave de CA:

•openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out server.crt -days <duración>

CLIENTE

Generar una clave de cliente.

•openssl genrsa -aes256 -out client.key 2048

Generar una solicitud de firma de certificado para enviar a la CA.

•openssl req -out client.csr -key client.key -new

Envíe la CSR a la CA, o fírmela con su clave de CA:

•openssl x509 -req -in client.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out client.crt -days <duración>
