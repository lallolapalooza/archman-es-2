NOMBRE

mosquitto_passwd - gestiona archivos de contraseñas para mosquitto

SINOPSIS

mosquitto_passwd [-H hash] [-c | -D] archivo_contraseñas nombre_usuario

mosquitto_passwd [-H hash] -b archivo_contraseñas nombre_usuario contraseña

mosquitto_passwd -U archivo_contraseñas

DESCRIPCIÓN

mosquitto_passwd es una herramienta para gestionar archivos de contraseñas para el broker mosquitto MQTT.

Los nombres de usuario no deben contener ":". Las contraseñas se almacenan en un formato similar a crypt(3).

OPCIONES

-b

Ejecutar en modo batch. Esto permite proporcionar la contraseña en la línea de comandos, lo que puede ser conveniente pero debe usarse con cuidado ya que la contraseña será visible en la línea de comandos y en el historial de comandos.

-c

Crear un nuevo archivo de contraseñas. Si el archivo ya existe, se sobrescribirá.

-D

Eliminar el usuario especificado del archivo de contraseñas.

-H

Elegir el hash a utilizar. Puede ser uno de sha512-pbkdf2 o sha512. Por defecto es sha512-pbkdf2. La opción sha512 se proporciona para crear archivos de contraseñas para usar con Mosquitto 1.6 y anteriores.

-U

Esta opción se puede usar para actualizar/convertir un archivo de contraseñas con contraseñas en texto plano a uno que use contraseñas hasheadas. Modificará el archivo especificado. No detecta si las contraseñas ya están hasheadas, por lo que usarla en un archivo de contraseñas que ya contiene contraseñas hasheadas generará nuevos hashes basados en los hashes antiguos y hará que el archivo de contraseñas no sea utilizable.

archivo_contraseñas

El archivo de contraseñas a modificar.

nombre_usuario

El nombre de usuario a añadir/actualizar/eliminar.

contraseña

La contraseña a usar en modo batch.

ESTADO DE SALIDA

mosquitto_sub devuelve cero si tiene éxito, o un valor distinto de cero en caso de error. Si la conexión es rechazada por el broker a nivel MQTT, el código de salida es el código de razón CONNACK. Si ocurre otro error, el código de salida es un valor de retorno de libmosquitto.

Códigos CONNACK de MQTT v3.1.1:

•0 Éxito
•1 Conexión rechazada: Versión de protocolo incorrecta
•2 Conexión rechazada: Identificador rechazado
•3 Conexión rechazada: Servidor no disponible
•4 Conexión rechazada: Usuario/contraseña incorrectos
•5 Conexión rechazada: No autorizado

Códigos CONNACK de MQTT v5:

•0 Éxito
•128 Error no especificado
•129 Paquete mal formado
•130 Error de protocolo
•131 Error específico de la implementación
•132 Versión de protocolo no compatible
•133 ID de cliente no válido
•134 Nombre de usuario o contraseña incorrectos
•135 No autorizado
•136 Servidor no disponible
•137 Servidor ocupado
•138 Prohibido
•139 El servidor se está apagando
•140 Método de autenticación incorrecto
•141 Tiempo de espera de keep-alive agotado
•142 Sesión asumida
•143 Filtro de tema no válido
•144 Nombre de tema no válido
•147 Máximo de recepción excedido
•148 Alias de tema no válido
•149 Paquete demasiado grande
•148 Tasa de mensajes demasiado alta
•151 Cuota excedida
•152 Acción administrativa
•153 Formato de carga útil no válido
•154 Retención no admitida
•155 QoS no admitido
•156 Usar otro servidor
•157 Servidor movido
•158 Suscripciones compartidas no admitidas
•159 Tasa de conexión excedida
•160 Tiempo máximo de conexión
•161 IDs de suscripción no admitidos
•162 Suscripciones comodín no admitidas

EJEMPLOS

Añadir un usuario a un nuevo archivo de contraseñas:

•mosquitto_passwd -c /etc/mosquitto/passwd ral

Eliminar un usuario de un archivo de contraseñas

•mosquitto_passwd -D /etc/mosquitto/passwd ral

ERRORES

La información sobre errores de mosquitto se puede encontrar en https://github.com/eclipse/mosquitto/issues
