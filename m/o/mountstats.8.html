NOMBRE

mountstats - Muestra diversas estadísticas por montaje del cliente NFS

SINOPSIS

mountstats [-h|--help] [-v|--version] [-f|--file archivo_entrada] [-S|--since archivo_desde] [ [-n|--nfs] | [-r|--rpc] | [-R|--raw] | [-x|--xprt] ] [punto_montaje]...

mountstats iostat [-h|--help] [-v|--version] [-f|--file archivo_entrada] [-S|--since archivo_desde] [intervalo] [conteo] [punto_montaje]...

mountstats nfsstat [-h|--help] [-v|--version] [-f|--file archivo_entrada] [-S|--since archivo_desde] [-3] [-4] [punto_montaje]...

DESCRIPCIÓN

El comando mountstats muestra diversas estadísticas del cliente NFS para cada punto_montaje dado.

Si no se proporciona ningún punto_montaje, se mostrarán las estadísticas para todos los puntos de montaje NFS en el cliente.

Subcomandos

Los subcomandos válidos de mountstats(8) son:

mountstats
Muestra una combinación de estadísticas RPC por operación, recuentos de eventos NFS y recuentos de bytes NFS. Este es el subcomando predeterminado que se ejecutará si no se proporciona ningún subcomando.
iostat
Muestra estadísticas similares a iostat.
nfsstat
Muestra estadísticas similares a nfsstat.

OPCIONES

Opciones válidas para todos los subcomandos

-h, --help
muestra el mensaje de ayuda y sale
-v, --version
muestra el número de versión del programa y sale
-f archivo_entrada, --file archivo_entrada
Lee estadísticas de archivo_entrada en lugar de /proc/self/mountstats. archivo_entrada debe estar en el mismo formato que /proc/self/mountstats. Esto puede usarse con las opciones -S|--since para mostrar la delta entre dos puntos diferentes en el tiempo. Esto no puede usarse con las opciones intervalo o conteo del subcomando iostat.
-S archivo_desde, --since archivo_desde
Muestra la diferencia entre las estadísticas actuales y las de archivo_desde. archivo_desde debe estar en el mismo formato que /proc/self/mountstats. Esto puede usarse con las opciones -f|--file para mostrar la delta entre dos puntos diferentes en el tiempo. Esto no puede usarse con las opciones intervalo o conteo del subcomando iostat.

Opciones específicas del subcomando mountstats

-n, --nfs Muestra solo las estadísticas NFS

-r, --rpc
Muestra solo las estadísticas RPC
-R, --raw
Muestra solo las estadísticas crudas. Esto está pensado para usarse con las opciones -f|--file y -S|--since.
-x, --xprt
Muestra solo las estadísticas de transporte

Opciones específicas del subcomando iostat

intervalo
Especifica la cantidad de tiempo en segundos entre cada informe. El primer informe contiene estadísticas del tiempo transcurrido desde que se montó cada sistema de archivos. Cada informe subsiguiente contiene estadísticas recopiladas durante el intervalo desde el informe anterior. Esto no puede usarse con las opciones -f|--file o -S|--since.
conteo
Determina el número de informes generados a intervalos de intervalo segundos. Si se especifica el parámetro intervalo sin el parámetro conteo, el comando genera informes continuamente. Esto no puede usarse con las opciones -f|--file o -S|--since.

Opciones específicas del subcomando nfsstat

-3
Muestra solo estadísticas de NFS versión 3. El valor predeterminado es mostrar estadísticas de ambas versiones, 3 y 4.
-4
Muestra solo estadísticas de NFS versión 4. El valor predeterminado es mostrar estadísticas de ambas versiones, 3 y 4.
