NOMBRE

mfsmount - montar MooseFS

SINOPSIS

mfsmount [HOST[:PUERTO]:[RUTA]] [opciones] punto_montaje

mfsmount -h|--help

mfsmount -V|--version

Desde la versión 3.0.75 (solo Linux):

mount -t moosefs [opciones] [HOST[:PUERTO]:[RUTA]] punto_montaje

DESCRIPCIÓN

Monta MooseFS.

OPCIONES

OPCIONES GENERALES

-h, --help
muestra la ayuda y sale
-V
muestra información de la versión y sale

OPCIONES FUSE

-d, -o debug
habilita el modo de depuración (implica -f)
-f
operación en primer plano
-s
deshabilita la operación multihilo

OPCIONES MOOSEFS

-c ARCHIVO_CFG, -o mfscfgfile=ARCHIVO_CFG
carga el archivo con opciones de montaje adicionales
-m, --meta, -o mfsmeta
monta el sistema de archivos complementario MFSMETA en lugar del MooseFS principal
-n
omite las opciones de montaje predeterminadas (-o allow_other)
-p
solicita la contraseña (versión interactiva de -o mfspassword=CONTRASEÑA)
-H HOST, -o mfsmaster=HOST
conecta con el maestro de MooseFS en HOST (por defecto es mfsmaster)
-P PUERTO, -o mfsport=PUERTO
conecta con el maestro de MooseFS en PUERTO (por defecto es 9421)
-B IP, -o mfsbind=IP
dirección local a usar para conectar con el maestro en lugar de la predeterminada
-L IP, -o mfsproxy=IP
define la dirección IP de escucha del proxy maestro local para la comunicación con las herramientas (por defecto: 127.0.0.1)
-S RUTA, -o mfssubfolder=RUTA
monta el directorio especificado de MooseFS (por defecto es /, es decir, todo el sistema de archivos)
-o mfspassword=CONTRASEÑA
autenticarse en el maestro de MooseFS con CONTRASEÑA
-o mfspassfile=NOMBRE_ARCHIVO
autenticarse en el maestro de MooseFS con la contraseña almacenada en la primera línea del archivo apuntado por NOMBRE_ARCHIVO
-o mfsmd5pass=MD5
autenticarse en el maestro de MooseFS utilizando el MD5 proporcionado directamente (solo si la opción mfspassword no está especificada)
-o mfsdonotrememberpassword
no recordar la contraseña en memoria - más seguro, pero cuando la sesión se pierde entonces se crea una nueva sesión sin contraseña
-o mfsdebug
imprime información de depuración específica de MooseFS
-o mfsmemlock
intenta bloquear la memoria (toda la memoria asignada se mapeará a la RAM física - lo que también significa no paginación)
-o allowoomkiller
no deshabilitar el asesino de falta de memoria (solo Linux)
-o mfslimitarenas=N
si N>0 entonces limita las arenas de malloc de glibc (solo Linux - por defecto: 4)
-o mfsflattrash
usa una estructura de basura plana en meta (opción añadida por razones de compatibilidad - desde la versión 3.0.64 la basura se divide en 4096 subcarpetas lo que reduce problemas con basuras grandes)
-o mfsdelayedinit
la conexión con el maestro se realiza en segundo plano - con esta opción el montaje puede ejecutarse sin red (bueno para ser ejecutado desde fstab / scripts de inicio etc.)
-o mfsmkdircopysgid=N
el bit sgid debe copiarse durante la operación mkdir (el valor predeterminado depende del sistema operativo)
-o mfssugidclearmode=MODO_S
establece el modo de borrado sugid (ver MODOS DE BORRADO SUGID; el valor predeterminado depende del sistema operativo)
-o mfscachemode=MODO_C
establece el modo de caché (ver MODOS DE CACHÉ DE DATOS; por defecto es AUTO)
-o mfscachefiles
(obsoleto) preserva los datos de archivo en la caché (equivalente a '-o mfscachemode=YES')
-o mfsreaddirplusminto=SEG
establece el tiempo de espera mínimo de caché de entradas/atributos para readdirplus en segundos (por defecto: 0.0001)
-o mfsattrcacheto=SEG
establece el tiempo de espera de caché de atributos en segundos (por defecto: 1.0)
-o mfsxattrcacheto=SEG
establece el tiempo de espera de caché de atributos extendidos (xattr) en segundos (por defecto: 30.0)
-o mfsentrycacheto=SEG
establece el tiempo de espera de caché de entradas de archivo en segundos (por defecto: 0.0, es decir, sin caché)
-o mfsdirentrycacheto=SEG
establece el tiempo de espera de caché de entradas de directorio en segundos (por defecto: 1.0)
-o mfsnegentrycacheto=SEG
establece el tiempo de espera de caché de entradas negativas en segundos (por defecto: 0.0)
-o mfssymlinkcacheto=SEG
establece el tiempo de espera de caché de enlaces simbólicos en segundos (por defecto: 300.0)
-o mfsgroupscacheto=SEG
establece el tiempo de espera de caché de grupos suplementarios en segundos (por defecto: 300.0); establecer este valor a 0 deshabilita el soporte de grupos suplementarios
-o mfsrlimitnofile=N
intenta cambiar el límite de descriptores de archivo abiertos simultáneamente al inicio (por defecto: 100000)
-o mfsnice=NIVEL
intenta cambiar el nivel de prioridad a un valor especificado al inicio (por defecto: -19)
-o mfswritecachesize=N
especifica el tamaño de la caché de escritura en MiB (en el rango: 16..2048 - por defecto: 256)
-o mfsreadaheadsize=N
define el tamaño de todos los búferes de prelectura en MiB (en el rango: 16..2048 - por defecto: 256)
-o mfsreadaheadleng=N
define la cantidad de bytes a leer adicionalmente (en el rango: 128KiB..2MiB - por defecto: 1048576)
-o mfsreadaheadtrigger=N
define la cantidad de bytes leídos secuencialmente que activan la prelectura (por defecto: 10 * mfsreadaheadleng)
-o mfserroronlostchunk
cuando todos los servidores de fragmentos conocidos están conectados al maestro y el fragmento requerido falta, se finaliza inmediatamente la E/S y se devuelve un error
-o mfserroronnospace
cuando todos los servidores de fragmentos conocidos están conectados al maestro y no hay espacio libre, se finaliza inmediatamente la E/S y se devuelve un error
-o mfsioretries=N
especifica el número de reintentos antes de que se devuelva un error de E/S (por defecto: 30)
-o mfstimeout=N
define el tiempo de espera máximo en s

mount.moosefs(8) — MooseFS — Arch Linux

NAME

mfsmount - Mount a MooseFS file system

SYNOPSIS

mfsmount [-h|-V] [-o options] mountpoint

DESCRIPTION

The mfsmount command mounts the MooseFS distributed file system on the specified mountpoint. It uses FUSE (Filesystem in Userspace) to provide the file system interface.

The mount point must exist and be empty.

OPTIONS

This program follows the usual command line syntax, with long options starting with two dashes (-).

Here is a summary of some MooseFS specific mount options:

-o mfsdport=PORT
Metalogger daemon port (default: 9419)
-o mfsmaster=HOST[:PORT]
MooseFS master server hostname and optionally port (default: mfsmaster1)
-o mfsmasterlog=HOST[:PORT]
Metalogger server hostname and optionally port (default: mfsmaster1)
-o mfswarning=SEC
Time in seconds after which you'll get warning if you are not connected to master server (default: 10)
-o mfsnodnodir
Disables creation of directories.
-o mfsnodnodon
Disables creation of files.
-o mfsreadahead=N
Sets readahead value for files (default: 1048576 bytes)
-o mfsreaddirsize=N
Sets readdirsize value for directories (default: 4096 bytes)
-o mfsreadblocksize=N
Sets readblocksize value for files (default: 131072 bytes)
-o mfsmaxparallelchunks=N
Sets max parallel chunks for reading single file (default: 10)
-o mfsmaxparallelwrites=N
Sets max parallel writes to chunkservers (default: 5)
-o mfsmaxparallelreads=N
Sets max parallel reads from chunkservers (default: 10)
-o mfsmaxchunks=N
Maximum number of chunks for one file (default: 4096)
-o mfsmaxfiles=N
Maximum number of files in the namespace (default: 20000000)
-o mfsmaxdirs=N
Maximum number of directories in the namespace (default: 500000)
-o mfsmaxhardlinks=N
Maximum number of hard links for one file (default: 1024)
-o mfsmaxsymlinks=N
Maximum length of symlink (default: 4096)
-o mfsmaxextendedattrs=N
Maximum number of extended attributes for one file (default: 255)
-o mfsmaxextendedattrsize=N
Maximum size of extended attribute value (default: 65536)
-o mfsttl=SEC
Time to live for metadata entries (default: 30 seconds)
-o mfscachettl=SEC
Time to live for cached data (default: 10 seconds)
-o mfscachemode=MODE
Set data cache mode. Possible values: DIRECT, NO, YES, AUTO (default: AUTO). See DATA CACHE MODES below.
-o mfstoppcache=SEC
Stop caching files for SEC seconds after last access (default: 60)
-o mfsdisabledirchecksum
disables checksum checks for directory data
-o mfsdisablefilechecksum
disables checksum checks for file data
-o mfsuid=UID
set uid for all files and directories (default: 0)
-o mfsgid=GID
set gid for all files and directories (default: 0)
-o mfsmode=OCTAL_MODE
set mode for all files and directories (default: 0777)
-o mfssizecache=BYTES
size of data cache in bytes (default: 104857600)
-o mfsiodtimeout=SEC
timeout in seconds before I/O error is returned (default: 0 - which means no timeout)
-o mfslogretry=N
define minimal retry counter on which system will start log I/O messages (default: 5)
-o mfsfsyncmintime=SEC
force fsync before last file close when file was opened/created at least SEC seconds earlier (default: 0.0 - always do fsync before close)
-o mfspreflabels=LABELEXPR
specify preferred labels for choosing chunkservers during I/O
-o mfsnoxattrs
turn off xattr support
-o mfsnoposixlocks
turn off support for global posix locks (lockf + ioctl) - locks will work locally
-o mfsnobsdlocks
turn off support for global BSD locks (flock) - locks will work locally

MOUNT OPTIONS

General mount options (see mount(8) manual):

-o rw|-o ro
Mount file-system in read-write (default) or read-only mode respectively.
-o suid|-o nosuid
Enable or disable suid/sgid attributes to work.
-o dev|-o nodev
Enable or disable character or block special device files interpretation.
-o exec|-o noexec
Allow or disallow execution of binaries.

FILES

mfsmount.cfg
configuration file for MooseFS mount daemon; refer to mfsmount.cfg(5) manual for details

NOTES

SUGID CLEAR MODE

During attribute change file systems sometimes clear flags suid and/or sgid. Behavior is different on different file systems. MFS tries to mimic behavior of most popular file system on given operating systems.

NEVER
MFS will not change suid and sgid bit on chown
ALWAYS
clear suid and sgid on every chown - safest operation
OSX
standard behavior in OS X and Solaris (chown made by unprivileged user clear suid and sgid)
BSD
standard behavior in *BSD systems (like in OSX, but only when something is really changed)
EXT
standard behavior in most file systems on Linux (directories not changed, others: suid cleared always, sgid only when group exec bit is set)
XFS
standard behavior in XFS on Linux (like EXT but directories are changed by unprivileged users)

DATA CACHE MODES

There are four cache modes: DIRECT, NO, YES and AUTO. Default option is AUTO and you shuldn't change it unless you really know what you are doing. In AUTO mode data cache is managed automatically by mfsmaster.

DIRECT
forces direct io (bypasses cache)
NO,NONE or NEVER
never allow files data to be kept in cache (safest but can reduce efficiency)
YES or ALWAYS
always allow files data to be kept in cache (dangerous)
AUTO
file cache is managed by mfsmaster automatically (should be very safe and efficient)

LABEL EXPRESSIONS

LABELEXPR grammar:

LABELEXPR
-> S ; LABELEXPR | S
S
-> S + M | M
M
-> M L | L
L
-> a .. z | A .. Z | ( S ) | [ S ]

Subexpressions should be placed in priority order. Up to nine subexpressions (priorities) can be specified.

FSTAB

On most Unix systems mfsmount can be invoked automatically from /etc/fstab. Be aware that rw or ro option has to be specified in options. Also on many systems there should be option which informs the system that this mountpoint should be mounted after starting networking services (options such as _netdev or late).

Linux:

mfsmount mountpoint fuse options 0 0

*BSD:

mfsmount_magic mountpoint moosefs options,mountprog=/usr/local/bin/mfsmount 0 0

Since version 3.0.75 alternative form can be used:

Linux:

HOST[:PORT]:[PATH] mountpoint moosefs options 0 0

*BSD:

HOST[:PORT]:[PATH] mountpoint moosefs options,mountprog=/usr/local/bin/mfsmount 0 0
