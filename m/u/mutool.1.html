MUTOOL(1) Manual de Comandos Generales MUTOOL(1)

NOMBRE

mutool - herramienta todo terreno para trabajar con archivos PDF

SINOPSIS

mutool <sub-comando> [opciones]

VERSIÓN

mutool -v

Muestra la versión de MuPDF utilizada para compilar mutool.

DESCRIPCIÓN

mutool es una herramienta basada en MuPDF para trabajar con archivos documentales de diversas maneras. Hay varios subcomandos disponibles, como se describe a continuación.

DRAW

mutool draw [opciones] archivo [páginas]

El comando draw renderizará un documento a archivos de imagen, lo convertirá a otro formato vectorial o extraerá el contenido de texto.

Los formatos de documento de entrada compatibles son: pdf, xps, cbz y epub.

Los formatos de imagen de salida compatibles son: pbm, pgm, ppm, pam, png, pwg, pcl y ps. Los formatos vectoriales de salida compatibles son: svg, pdf y traza de depuración (como xml). Los formatos de texto de salida compatibles son: texto plano, html y texto estructurado (como xml).

-p contraseña
Utiliza la contraseña especificada si el archivo está cifrado.
-o salida
El formato de salida se infiere del nombre del archivo de salida. Incrusta %d en el nombre para indicar el número de página (por ejemplo: "page%d.png"). Se admiten modificadores de printf, por ejemplo "%03d". Si no se especifica salida, la salida irá a stdout.
-F formato
Forzar un formato de salida específico. Solo es necesario al enviar a stdout, ya que normalmente se utiliza el nombre del archivo de salida para inferir el formato de salida.
-q
Silencioso, no imprimir mensajes de progreso.
-R ángulo
Rotar en sentido horario por el número de grados dado.
-r resolución
Renderizar la página a la resolución especificada. La resolución por defecto es 72 dpi.
-w ancho
Renderizar la página con el ancho especificado (o, si se usa la bandera -r, renderizar con un ancho máximo).
-h alto
Renderizar la página con la altura especificada (o, si se usa la bandera -r, renderizar con una altura máxima).
-f
Ajustar exactamente; ignorar la relación de aspecto al hacer coincidir los anchos/altos especificados.
-b caja
Usar la caja de página con nombre (`MediaBox`, `CropBox`, `BleedBox`, `TrimBox`, o `ArtBox`), ver :ref:`cajas definidas<mutool_trim_defined_boxes>`.
-B altura_banda
Renderizar en modo de bandas con cada banda no más alta que la altura dada. Esto utiliza menos memoria durante la renderización. Solo compatible con los formatos de salida pam, pgm, ppm, pnm y png. La renderización por bandas y la comprobación de suma MD5 no se pueden usar al mismo tiempo.
-T hilos
Número de hilos a utilizar para la renderización (solo modo bandas).
-W ancho
Ancho de página en puntos para el diseño EPUB.
-H alto
Alto de página en puntos para el diseño EPUB.
-S tamaño
Tamaño de fuente en puntos para el diseño EPUB.
-U archivo
Hoja de estilo CSS de usuario para el diseño EPUB.
-X
Deshabilitar estilos de documento para el diseño EPUB.
-a
Deshabilitar el uso de archivos aceleradores.
-c espacio_de_color
Renderizar en el espacio de color especificado. Los espacios de color soportados son: mono, gray, grayalpha, rgb, rgbalpha, cmyk, cmykalpha. Se permiten algunas abreviaturas: m, g, ga, rgba, cmyka. La opción por defecto se elige según el formato de salida.
-e archivo
Archivo de perfil ICC de prueba para usar en la renderización.
-G gamma
Aplicar corrección gamma. Algunos valores típicos son 0.7 o 1.4 para adelgazar o oscurecer la renderización de texto.
-I
Invertir colores.
-s [mft5]
Mostrar varias informaciones: m para caché de glifos y uso total de memoria, f para características de página como si la página es escala de grises o color, t para tiempos de renderización por página y estadísticas, y 5 para sumas de verificación md5 de las imágenes renderizadas que se pueden usar para verificar si la renderización ha cambiado.
-A bits
Especificar cuántos bits de suavizado se utilizarán. El valor por defecto es 8.
-A bits/bits
Especificar cuántos bits de suavizado se utilizarán. El valor por defecto es 8. Los bits para gráficos están antes de la barra, los bits para texto después de la barra.
-l ancho
Ancho mínimo de línea trazada (en píxeles).
-K
No dibujar texto.
-KK
Solo dibujar texto.
-D
Deshabilitar el uso de listas de visualización. Puede causar ralentizaciones, pero debería reducir la cantidad de memoria utilizada.
-i
Ignorar errores.
-m límite
Limitar el uso de memoria en bytes.
-L
Modo de baja memoria (evitar el almacenamiento en caché de objetos borrando la caché después de cada página).
-P
Ejecutar la interpretación y la renderización al mismo tiempo.
-N
Deshabilitar el flujo de trabajo ICC.
-O sobreimpresión
Controlar la renderización de cuatricromía/sobreimpresión: 0 para sin renderización de cuatricromía, 1 para simulación de sobreimpresión (por defecto), o 2 renderización completa de cuatricromía.
-t idioma
Especificar idioma/script para OCR (por defecto: eng)
-d ruta-archivo-ocr
Especificar la ruta de los archivos OCR (por defecto: depender de la variable de entorno TESSDATA_PREFIX.
-k corrección
Establecer la corrección de inclinación, ya sea auto, 0 para aumentar el tamaño, 1 para mantener el tamaño, o 2 para disminuir el tamaño.
-k corrección,ángulo
Establecer la corrección de inclinación y el ángulo.
-y l
Imprimir las configuraciones de capas en stderr.
-y número_capa
Seleccionar la configuración de capas (por número de -y l).
-y número_capa,elemento1,elemento2,...
Seleccionar la configuración de capas (por número de -y l) y activar/desactivar los elementos listados.
-Y
Imprimir las capas individuales en stderr.
-z número_capa
Ocultar una capa individual.
-Z número_capa
Mostrar una capa individual.
páginas
Lista separada por comas de números y rangos de páginas (por ejemplo: 1,5,10-15,20-N), donde el carácter N denota la última página. Si no se especifican páginas, se renderizarán todas las páginas.

CLEAN

mutool clean [opciones] input.pdf [output.pdf] [páginas]

El comando clean formatea e reescribe la sintaxis de un archivo PDF. Se puede usar para reparar archivos dañados, expandir flujos comprimidos, filtrar un rango de páginas, etc.

Si no se especifica archivo de salida, escribirá el PDF limpiado en "out.pdf" en el directorio actual.

-p contraseña
Utiliza la contraseña especificada si el archivo está cifrado.
-g
Recolección de basura de objetos que no tienen referencias de otros objetos. Dar la opción dos veces para también renumerar todos los objetos y compactar la tabla de referencias cruzadas. Darle tres veces para también fusionar y reutilizar objetos duplicados. Darle cuatro veces para también fusionar y reutilizar flujos duplicados.
-s
Reescribir flujos de contenido.
-l
Linealizar salida. Ya no se soporta

MUTOOL

mutool - The methods utilities.

mutool is a collection of tools for working with PDF files. It can be used to clean, decompress, extract, convert, and display PDF files.

mutool is a command-line utility. The general syntax is:

mutool operation [options] file.pdf [arguments]

The following operations are supported:

clean
Clean and optimize PDF files.
run
Run a script.
trace
Trace graphics commands.
verify
Verify PDF syntax.
toc
List the table of contents.
pages
List the pages.
info
List the information about the PDF file.
show
Show the contents of objects.
extract
Extract images and fonts.
poster
Create a poster from a PDF file.
create
Create a PDF file from text files.
merge
Merge PDF files.
separate
Separate PDF files.
convert
Convert PDF files to other formats.

CREATE

mutool create [-o output.pdf] [options] page1.txt [page2.txt ...]

The create command creates a new PDF file with the contents created from one or more input files containing graphics commands.

-o output
If no output file is specified, it will write the created PDF to "out.pdf" in the current directory.
page.txt
A page is created for each input file, with the contents of the file copied into the content stream. Special comments in the input files are parsed to define the page dimensions and font and image resources:

%%MediaBox 0 0 500 800
%%Rotate 90
%%Font Tm Times-Roman
%%Font Fn0 path/to/font/file.ttf
%%Image Im0 path/to/image.png

-O options
Comma separated list of format specific output options, see OUTPUT OPTIONS below.

mutool pages [options] input.pdf [pages ...]

The pages command dumps information about the size and orientation of pages within the document.

-p password
Use the specified password if the file is encrypted.
pages
Comma separated list of page numbers and ranges (for example: 1,5,10-15,20-N), where the character N denotes the last page. If no pages are specified, then all pages will be included.

POSTER

mutool poster [options] input.pdf [output.pdf]

The poster command splits each page into tiles, and puts each tile on a page of its own. It's useful for printing a large page onto smaller pieces of paper that can then be glued together to create a large poster.

-p password
Use the specified password if the file is encrypted.
-m margin
Margin (overlap) between pages in points or percent.
-x factor
Split the page into this many horizontal pieces.
-y factor
Split the page into this many vertical pieces.
-r
Splits hoirzontally from right to left (default splits from left to right).

The output will have x times y number of pages for each input page.

EJECUTAR

mutool run script.js [argumentos]

Ejecuta un programa Javascript que tiene acceso a la mayoría de las características de la biblioteca MuPDF. El comando admite la sintaxis de ECMAScript 5 en modo estricto. Todos los constructores y funciones de MuPDF viven en el objeto global, y los argumentos de la línea de comandos son accesibles desde el objeto global argv.

Si se invoca sin ningún argumento, te llevará a un REPL (bucle de lectura-evaluación-impresión) interactivo. En el prompt interactivo, si prefijas una línea con el carácter igual, imprimirá automáticamente los resultados de la línea.

Consulta la documentación de MuPDF para obtener detalles sobre las interfaces de Javascript.

HORNEAR

mutool bake [opciones] input.pdf [output.pdf]

Normalmente, las anotaciones y los widgets de campos de formulario son flujos de contenido separados que se dibujan sobre el contenido de la página. Este comando incorpora las anotaciones y/o widgets en el contenido de la página, haciéndolos inseparables. Después de incorporar las anotaciones y los widgets, son solo representaciones visuales de cómo se veía la anotación/widget original; sus propiedades ya no se pueden editar ya que ya no existen como anotaciones/widgets adecuados.

-A
No incorporar anotaciones.
-F
No incorporar widgets de campos de formulario.
-O opciones
Una lista de opciones de PDF separadas por comas. Consulta *OPCIONES DE SALIDA* a continuación.

OPCIONES DE SALIDA

La configuración de la salida se realiza mediante una lista de opciones de salida separadas por comas.

Opciones de formato Raster
Se aplican a los formatos de salida: cbz, png, pnm, pgm, ppm, pam, pbm, pkm.
rotar=N
Rota las páginas renderizadas N grados en sentido antihorario.
resolucion=N
Establece tanto la resolución X como la Y en píxeles por pulgada.
x-resolucion=N
Establece la resolución X de las páginas renderizadas en píxeles por pulgada.
y-resolucion=N
Establece la resolución Y de las páginas renderizadas en píxeles por pulgada.
ancho=N
Renderiza páginas para que encajen en un ancho de N píxeles (ignora la opción de resolución).
alto=N
Renderiza páginas para que encajen en un alto de N píxeles (ignora la opción de resolución).
espacio_color=(gris|rgb|cmyk)
Renderiza páginas usando el espacio de color especificado.
alfa Renderiza páginas con canal alfa y fondo transparente.
graficos=(aaN|cop|app)
texto=(aaN|cop|app)
Establece el rasterizador a usar para gráficos o texto respectivamente:
aaN
Suavizado con N bits (0 a 8).
cop
Centro del píxel.
app
Cualquier parte del píxel.

decompress
Descomprime todos los flujos (excepto los de fuentes/imágenes comprimidas).
