NOMBRE

mutt_pgpring - Volcador de anillos de claves de Mutt

SINTAXIS

mutt_pgpring [ -k anillo-de-claves ] [ -2 | -5 ] [ -s ] [ -S ] [ -f ]

DESCRIPCIÓN

mutt_pgpring es un volcador de anillos de claves. Extrae información del anillo de claves binario de PGP y la emite en un formato de salida (casi) legible entendido por las rutinas de selección de claves de mutt. Este formato de salida imita el utilizado por GNU Privacy Guard (GPG).

OPCIONES

-k anillo-de-claves
Vuelca el contenido del anillo de claves especificado.
-2
Utiliza el anillo de claves predeterminado para PGP 2.x.
-5
Utiliza el anillo de claves predeterminado para PGP 5.
-s
Vuelca el anillo de claves secreto.
-S
Vuelca las firmas.
-f
Vuelca las huellas dactilares.

ENTORNO

HOME
Ruta completa del directorio de inicio del usuario.
PGPPATH
Directorio en el que se puede encontrar el anillo de claves público PGP del usuario.
