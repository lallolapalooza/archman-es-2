NOMBRE

mupen64plus — frontend de consola para el emulador de N64 Mupen64Plus

SINOPSIS

mupen64plus [parámetros] archivo_rom

DESCRIPCIÓN

mupen64plus es un emulador de N64 basado en plugins para Linux/Unix, OSX y Windows, capaz de ejecutar muchos juegos con precisión. Incluye cuatro emuladores de CPU MIPS R4300, con recompiladores dinámicos para sistemas x86 de 32 bits y amd64 de 64 bits, y los plugins necesarios para audio, renderizado gráfico (RDP), coprocesador de señal (RSP) y entrada. Hay varios plugins de video OpenGL disponibles:

  • Rice, incluido con la distribución
  • Glide64Mk2, incluido con la distribución
  • Arachnoid
  • Glide64 (antiguo)
  • Z64 (debe usarse con el plugin rsp-z64)

La documentación más actualizada se puede encontrar en la página principal del proyecto.

Las opciones son las siguientes:

-h, --help
Imprimir mensaje de ayuda.
--noosd
Desactivar la visualización en pantalla (OSD).
--osd
Activar la visualización en pantalla (OSD).
--fullscreen
Ejecutar el emulador en modo de pantalla completa.
--windowed
Ejecutar el emulador en modo de ventana.
--resolution res
Resolución de pantalla (640×480, 800×600, 1024×768, etc.)
--nospeedlimit
Desactivar el limitador de velocidad del núcleo. Esto debe usarse con el plugin de audio dummy.
--cheats espec_trucos
Activar o listar códigos de trucos para el archivo ROM dado.
--corelib ruta_archivo
Especifica un nombre de archivo (opcionalmente con una ruta de directorio previa) para cargar una biblioteca principal de mupen64plus específica.
--configdir directorio
Especifica un directorio donde buscar el archivo mupen64plus.cfg. El valor predeterminado es ~/.config/mupen64plus/.
--datadir directorio
Especifica un directorio donde buscar archivos de datos compartidos (fuentes, códigos de trucos, archivos .ini). El valor predeterminado es ${PREFIX}/share/mupen64plus/.
--plugindir directorio
Especifica un directorio donde buscar archivos de plugins. El valor predeterminado es ${PREFIX}/lib/mupen64plus/.
--sshotdir directorio
Especifica un directorio donde guardar las capturas de pantalla tomadas durante el juego. El valor predeterminado es ~/.local/share/mupen64plus/screenshot/.
--gfx espec_plugin
Especifica una espec_plugin para seleccionar un plugin gráfico para usar durante la emulación.
--audio espec_plugin
Especifica una espec_plugin para seleccionar un plugin de audio para usar durante la emulación.
--input espec_plugin
Especifica una espec_plugin para seleccionar un plugin de entrada para usar durante la emulación.
--rsp espec_plugin
Especifica una espec_plugin para seleccionar un plugin RSP para usar durante la emulación.
--emumode modo
Especifica en qué modo debe ejecutarse el núcleo del emulador. modo debe establecerse en uno de los siguientes números:
0
Intérprete Puro
1
Intérprete con Caché
2
Recompilador Dinámico (DynaRec)
--testshots lista
Tomar capturas de pantalla en los fotogramas indicados en la lista separada por comas lista, luego salir.
--core-compare-send
Utilizar la función de depuración de comparación de núcleos, en modo de envío de datos. Si el núcleo no fue compilado con soporte para la función de comparación de núcleos, el emulador saldrá con un error.
--core-compare-recv
Utilizar la función de depuración de comparación de núcleos, en modo de recepción de datos. Si el núcleo no fue compilado con soporte para la función de comparación de núcleos, el emulador saldrá con un error.
--set espec_param
Establecer el valor de un parámetro de configuración de mupen64plus. Esta opción se puede usar varias veces. El formato de espec_param es
Nombre_Seccion[Nombre_Parametro]=Valor
--nosaveoptions
No guardar las opciones de la línea de comandos dadas en el archivo de configuración de mupen64plus para usarlas como valores predeterminados en el futuro.
--verbose
Imprimir mucha información. Útil para depuración pero innecesario para el uso normal.

espec_plugin

(nombre_plugin)
Nombre del archivo (sin ruta) del plugin a usar. La aplicación buscará en varios directorios para encontrar un nombre de plugin coincidente.
(ruta_plugin)
Ruta completa del directorio y nombre del archivo del plugin.
'dummy'
Usar el plugin dummy.

espec_trucos

'list'
Mostrar todos los códigos de trucos disponibles.
'all'
Activar todos los códigos de trucos disponibles.
(lista_codigos)
Una lista separada por comas de números de códigos de trucos para activar.

COMANDOS

Las siguientes teclas de acceso rápido se pueden usar durante la emulación. Estos son los valores predeterminados de las teclas; casi todas se pueden configurar con teclas diferentes editando el archivo de configuración de mupen64plus.

Escape
Salir del emulador.
0-9
Seleccionar 'ranura' virtual para guardar/cargar estado.
F5
Guardar el estado del emulador en la ranura actual.
F7
Cargar el estado del emulador desde la ranura actual.
F9
Reiniciar el emulador.
F10
Disminuir la velocidad del emulador en un 5 por ciento.
F11
Aumentar la velocidad del emulador en un 5 por ciento.
F12
Tomar captura de pantalla.
Alt+Enter
Alternar modo de pantalla completa.

KEY COMMANDS

e
Esto no está soportado en Windows.
p o P
Pausa/reanuda la emulación.
m o M
Silenciar/activar sonido.
f o F
Avance rápido (reproducción al 250% de la velocidad normal mientras se mantiene pulsada la tecla).
g o G
Pulsar el botón GameShark (si los trucos están habilitados).
/ o ?
Avanzar un fotograma si está en pausa.
[
Disminuir volumen.
]
Aumentar volumen.

ARCHIVOS

La ubicación predeterminada del archivo de configuración de mupen64plus es ~/.config/mupen64plus/. La ubicación predeterminada de las capturas de pantalla guardadas es ~/.local/share/mupen64plus/screenshot/. La ubicación predeterminada de los estados guardados es ~/.local/share/mupen64plus/save/.
