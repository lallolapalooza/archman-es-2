NOMBRE

mupdf - MuPDF es un visor de PDF ligero escrito en C portable

SINOPSIS

mupdf [opciones] archivo[número_de_página]

DESCRIPCIÓN

MuPDF es un visor de documentos que puede mostrar formatos PDF, XPS, EPUB, XHTML, CBZ, y varios formatos de imagen como PNG, JPEG, GIF, y TIFF.

OPCIONES

A continuación se incluye una descripción de cada una de las opciones soportadas.

-b nombre-caja
Utiliza la caja de página dada (MediaBox, CropBox, BleedBox, TrimBox, o ArtBox)
-c archivo-perfil
Establece el perfil de color de la pantalla al que se encuentra en el archivo nombrado.
-p contraseña
Utiliza la contraseña dada para abrir un archivo PDF cifrado. La contraseña se intenta tanto como contraseña de usuario como de propietario.
-r resolución
Cambia el nivel de zoom inicial, especificado como la resolución en dpi. El valor predeterminado es 72.
-A bits
Cambia la calidad del suavizado (anti-aliasing), especificada como un número de bits entre 0 (apagado) y 8 (mejor). El valor predeterminado es 8.
-B RRGGBB
Establece el tinte negro de página completa usando sintaxis de color hexadecimal. El valor predeterminado es 303030.
-C RRGGBB
Establece el tinte blanco de página completa usando sintaxis de color hexadecimal. El valor predeterminado es FFFFF0.
-H altura
Altura de página en puntos para el diseño EPUB.
-I
Invierte los colores.
-J
Deshabilita JavaScript en formularios PDF.
-R opciones-extracción
Habilita el reajuste y establece las opciones de extracción de texto.
-S tamaño
Tamaño de fuente en puntos para el diseño EPUB.
-U archivo-CSS
Hoja de estilo de usuario para el diseño EPUB.
-W ancho
Ancho de página en puntos para el diseño EPUB.
-X
Deshabilita los estilos del documento para el diseño EPUB.
-Y factor
Establece el factor de escala de la interfaz de usuario.

COMPORTAMIENTO DEL RATÓN

Botón izquierdo del ratón
Un clic izquierdo en un hipervínculo sigue el enlace. En modo presentación, avanza a la página siguiente.
Botón derecho del ratón
En modo presentación, retrocede a la página anterior.
Arrastrar el botón izquierdo del ratón
Desplaza la página. Desplazarse más allá del borde inferior o superior irá a la página siguiente o anterior.
Arrastrar el botón derecho del ratón
Selecciona texto en un área. En X11, el texto seleccionado se puede pegar en otra aplicación con un clic central. Presiona Ctrl+C para copiar el texto seleccionado al portapapeles. En Windows, el texto seleccionado se copiará automáticamente al portapapeles.
Rueda de desplazamiento
Desplaza la página hacia arriba o hacia abajo. No cambia de página al llegar al borde inferior o superior.
Shift + Rueda de desplazamiento
Desplaza la página hacia la izquierda o hacia la derecha.
Control + Rueda de desplazamiento
Acerca o aleja la imagen.

ACCESOS DIRECTOS DEL TECLADO

Navegación de página:

. pgdn espacio
Ir a la página siguiente.
, pgup b
Ir a la página anterior.
123g
Ir a la página 123.
g, G
Ir a la primera o última página.
m
Marcar página actual para retroceder. Se pueden marcar hasta 256 páginas.
t
Retroceder un paso en el historial de marcas.
T
Avanzar un paso en el historial de marcas.
[0–9]m
Guardar el número de página actual en el registro numerado.
[0–9]t
Ir a la página guardada en el registro numerado.

Ajustar zoom y rotar:

+, -
Acercar o alejar.
W, H
Ajustar la página para que encaje exactamente en el ancho/alto de la ventana.
Z
Ajustar la página para que encaje en el ancho o alto de la ventana.
z
Restablecer el nivel de zoom.
[, ]
Rotar página a la izquierda (sentido antihorario) o a la derecha (sentido horario).
w
Ajustar la ventana al tamaño de la página.
f
Activa/desactiva el modo de pantalla completa.

Desplazamiento:

h, flecha izquierda, j, k, l, flecha derecha
Desplazar la página a la izquierda, abajo, arriba o derecha.

Búsqueda:

/, ?
Buscar texto hacia adelante o hacia atrás.
n, N
Encontrar el siguiente/anterior resultado de búsqueda.

Varios:

F1
Mostrar ayuda de accesos directos del teclado.
Escape
Detener la búsqueda y/o quitar el foco de la anotación/widget.
<, >
Aumentar/disminuir el tamaño de fuente de EPUB/XHTML.
r
Recargar archivo.
p
Activa/desactiva el modo presentación. (solo mupdf-x11)
c
Cambia entre renderizado en color y escala de grises. (solo mupdf-x11)
C
Activa/desactiva el tinte de color de página completa.
I
Cambia entre renderizado de color normal e invertido.
E
Activa/desactiva el modo de color ICC.
e
Activa/desactiva el modo de color directo.
A
Establece la cantidad de suavizado (anti-aliasing) a usar. El valor predeterminado es 8. 0 significa sin suavizado, 9 significa sin suavizado, regla del centro del píxel, 10 significa sin suavizado, regla de cualquier parte de un píxel.
P
Muestra el número de página y el número total de páginas.
i
Muestra un cuadro de diálogo con información sobre el documento abierto.
B
Cambia la caja de página utilizada. (MediaBox, CropBox, BleedBox, TrimBox, o ArtBox). La caja de página activa se menciona en el cuadro de diálogo de información.
o
Muestra/oculta el panel del esquema del documento.
a
Muestra/oculta el panel de anotaciones.
R
Muestra/oculta el panel de redacciones.
u
Muestra/oculta el panel de deshacer/rehacer.
Y
Muestra/oculta la lista de capas.
o
Inicia/detiene el resaltado de enlaces.
F
Inicia/detiene el resaltado de campos de formulario.
` F12
Muestra la consola JS.
S
Guarda el archivo de documento actualizado.
q
Salir.

NAME

mupdf-gl - a lightweight PDF viewer

SYNOPSIS

mupdf-gl [-A] [-c cookie] [-g] [-I] [-p password] [-r rectangle] [-R] [-s size] [-t time] [-U] [-v] [-w] [-x xpos] [-y ypos] [filename...]

DESCRIPTION

mupdf-gl is a lightweight PDF viewer. It is designed to be small, fast, and capable of displaying many document formats beyond PDF. This version uses OpenGL for rendering.

OPTIONS

-A
Allow the document to access network resources and local files. This is required for documents that use JavaScript or forms.
-c cookie
Pass a cookie string to the document. This is used for authentication with servers.
-g
Print the document's text in glyph-coded format.
-I
Enable hardware-accelerated rendering using OpenGL. This is the default behavior for mupdf-gl.
-p password
Specify the password for encrypted documents.
-r rectangle
Display only the specified rectangle of the page. The rectangle is specified as x0,y0,x1,y1.
-R
Render the document using software rendering. This is useful for debugging or when OpenGL is not available or performing poorly.
-s size
Set the initial page size. The size is specified as widthxheight.
-t time
Set the initial time. The time is specified as seconds since the epoch.
-U
Disable the document's ability to access network resources and local files.
-v
Print the document's version information and exit.
-w
Run in windowed mode. This is the default.
-x xpos
Set the initial horizontal position.
-y ypos
Set the initial vertical position.

MOUSE BEHAVIOR

Left-click and drag: Pan the document.

Right-click: Open context menu.

Scroll wheel: Zoom in/out.

KEY BINDINGS

Arrow keys: Pan the document.

Page Up/Down: Go to previous/next page.

Home/End: Go to the first/last page.

+/-: Zoom in/out.

f: Toggle fullscreen.

q: Quit.

SIGNALS

The mupdf-gl utility does not process any signals.
