MUSIXTEX(1) MUSIXTEX(1)

NOMBRE

musixtex - procesa archivos MusiXTeX, utilizando los preprocesadores prepmx, xml2pmx, pmxab y autosp según sea necesario, y luego elimina los archivos intermedios y de registro (a menos que se use -i)

SINOPSIS

[ texlua ] musixtex[.lua] { opción | nombre_trabajo [ .xml | .mtx | .pmx | .aspc | .tex | .ltx ] } ...

DESCRIPCIÓN

Si un argumento de nombre_trabajo tiene la extensión .tex, el efecto predeterminado es procesar el archivo usando
etex(1)
(primer pase)
musixflx(1)
(segundo pase)
etex(1)
(tercer pase)
dvips(1)
(dvi a Postscript)
ps2pdf(1)
(Postscript a Formato de Documento Portátil)
normalmente seguido de la eliminación de archivos intermedios y de registro. Se genera un registro musixtex.log, incluso si se eliminan otros archivos de registro.

Si un argumento de nombre_trabajo tiene la extensión .pmx, el archivo se preprocesa primero usando pmxab(1) y el archivo .tex resultante se procesa como se describe anteriormente.

Si un argumento de nombre_trabajo tiene la extensión .xml, el archivo se preprocesa primero usando xml2pmx(1) y el archivo .pmx resultante se procesa como se describe anteriormente.

Si un argumento de nombre_trabajo tiene la extensión .mtx, el archivo se preprocesa primero usando prepmx(1) y el archivo .pmx resultante se procesa como se describe anteriormente.

Si un argumento de nombre_trabajo tiene la extensión .ltx, el archivo se procesa usando latex(1) (o pdflatex(1)) en lugar de etex.

Si un argumento de nombre_trabajo tiene la extensión .aspc, el archivo se preprocesa primero usando autosp(1) y el archivo .tex o .ltx resultante se procesa como se describe anteriormente.

Si un argumento de nombre_trabajo no tiene ninguna de estas extensiones, el script buscará un archivo nombre_trabajo.xml o nombre_trabajo.mtx o nombre_trabajo.pmx o nombre_trabajo.aspc o nombre_trabajo.tex o nombre_trabajo.ltx, en ese orden, y lo procesará como se describe anteriormente.

OPCIONES

-v, -version, --version
muestra el nombre y número de versión del programa, y sale
-h, -help, --help
muestra el resumen de uso y sale
-l
asume fuente LaTeX; implícito si el archivo tiene extensión .ltx
-p
cambia el procesador TeX a pdfetex(1) o pdflatex(1) (y no ejecuta un procesador dvi)
-c
preprocesa el archivo pmx usando pmxchords(1)
-d
no genera archivo .ps y cambia el procesador dvi a dvipdfm(1)
-D dvix
usa dvix como procesador dvi; ej., -D "dvipdfm -m 0.9". Usa -d antes de -D para suprimir la generación de .ps.
-P ps2pdf
usa ps2pdf como procesador Postscript; ej., -P "ps2pdf -sPAPERSIZE=a4"
-F fmt
usa fmt como procesador TeX; ej., -F "luatex --output-format=dvi"
-m
detiene el procesamiento en el archivo pmx
-M mtxx
usa mtxx como preprocesador mtx; ej., -M "prepmx -i".
-X pmxx
usa pmxx como preprocesador pmx; ej., -X "./pmxab",
-A aspcx
usa aspcx como preprocesador aspc; ej., -A "autosp -l".
-L xmlx
usa xmlx como preprocesador xml; ej., -L "./XML2PMX".
-t
detiene el procesamiento en los archivos tex/mid
-s
detiene el procesamiento en el archivo dvi
-g
detiene el procesamiento en el archivo ps
-i
retiene los archivos intermedios y de registro
-1
procesamiento [pdf][la]tex en una sola pasada; es decir, sin llamar a musixflx
-x
llama a makeindex(1) para actualizar la base de datos de índices
-f
restaura el procesamiento predeterminado
-q
modo silencioso (solo mensajes propios de musixtex); otros mensajes se redirigen a un archivo temporal. Si ocurre un error en la etapa TeX, el procesamiento se detiene inmediatamente y la parte final del archivo de registro se envía a stderr. La información de versión se copia del archivo temporal al archivo de registro.
Las opciones afectan al procesamiento de todos los archivos MusiXTeX subsiguientes a menos que sean cambiadas por otra opción. Las banderas de opción no se pueden combinar; ej., usa -l -x en lugar de -lx.

Tenga en cuenta que hay cuatro motores TeX disponibles a través de las opciones -l y -p:


etex predeterminado

latex -l
pdfetex -p
pdflatex -l -p
Si se utiliza la opción -F, las opciones -l y -p deben establecerse si el nombre del motor no contiene "latex" y "pdf" respectivamente. Por ejemplo, los cuatro motores anteriores pueden reemplazarse por:

-F "luatex --output-format=dvi"
-F "lualatex --output-format=dvi"
-F "luatex" -p
-F "lualatex" -p
