MUMBLE(1) Manual de comandos generales MUMBLE(1)

NOMBRE

mumble - un programa de chat de voz de baja latencia y alta calidad

SINOPSIS

mumble [opciones] [<url>]

DESCRIPCIÓN

Mumble es un software de chat de voz de código abierto, de baja latencia y alta calidad, destinado principalmente a su uso en juegos.

OPCIONES

-h, --help
Muestra el texto de ayuda y sale.

-m, --multiple

Permite iniciar múltiples instancias del cliente.

-c, --config

Especifica un archivo de configuración alternativo. Si usa esto para ejecutar múltiples instancias de Mumble a la vez, asegúrese de establecer un valor de database alternativo en la configuración.

-n, --noidentity

Suprime la carga de archivos de identidad (es decir, certificados).

-jn, --jackname <argumento>

Establece un nombre de cliente Jack personalizado.

--license

Muestra la licencia de Mumble.

--authors

Muestra los autores de Mumble.

--third-party-licenses

Muestra las licencias del software de terceros utilizado por Mumble.

--window-title-ext <argumento>

Establece una extensión de título de ventana personalizada.

--dump-input-streams

Descarga flujos PCM en varias partes de la cadena de entrada (útil para fines de depuración).
•
entrada de micrófono cruda
•
reproducción de altavoz para cancelación de eco
•
entrada de micrófono procesada

--print-echocancel-queue

Imprime en la salida estándar el estado de la cola de cancelación de eco (útil para fines de depuración).

URL

<url> especifica una URL a la que conectarse después del inicio en lugar de mostrar la ventana de conexión, y tiene la siguiente forma:
mumble://[<nombre de usuario>[:<contraseña>]@]<host>[:<puerto>][/<canal>][/<subcanal>...][?version=<x.y.z>]

El parámetro de consulta de versión debe establecerse para invocar la versión correcta del cliente. Actualmente, por defecto es 1.2.0.

CONTROL RPC

Es posible controlar remotamente una instancia en ejecución de Mumble usando el siguiente comando:

mumble rpc [acción]

Donde acción es una de las siguientes:

mute
Silenciar a uno mismo
unmute
Desilenciar a uno mismo
deaf
Enmudecer a uno mismo
undeaf
Des-enmudecer a uno mismo
toggledeaf
Alternar el estado de enmudecimiento propio
starttalking
Empezar a hablar
stoptalking
Dejar de hablar

VER TAMBIÉN

mumble-overlay(1), murmurd(1).
