FBB::MultiBuf(3bobcat) Escritura de múltiples flujos FBB::MultiBuf(3bobcat)

NOMBRE

FBB::MultiBuf - Escribe selectivamente múltiples flujos

SINOPSIS

#include <bobcat/multibuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

La clase FBB::MultiBuf es una especialización de std::streambuf. Se puede usar para escribir selectivamente en múltiples std::ostreams. A cada std::ostream que se asocia con un MultiBuf se le asigna una etiqueta de modo que indica si el flujo debe usarse siempre al insertar información en el MultiBuf, solo una vez, o en absoluto. Cada una de las etiquetas de modo del flujo puede configurarse en cualquiera de los valores de etiqueta definidos.

Cuando se utiliza la dirección de un MultiBuf para inicializar un std::ostream, el std::ostream construido se convierte en un multiplexor de salida: al insertar información en el objeto std::ostream, todos los objetos std::ostream añadidos a su búfer MultiBuf que tengan un modo activo reciben esa información.

Un objeto MultiBuf debe sobrevivir a todos los flujos activos que estén asociados con él.

Los objetos MultiBuf se refieren a std::ostreams que se les pasan, y no a sus std::streambufs. Por lo tanto, es posible cambiar los std::streambufs de estos std::ostream sin reinstalar los std::ostreams mismos.

No se deben hacer suposiciones sobre el orden en el que se visitan los objetos std::ostream asociados con los objetos MultiBuf al insertar información.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf

ENUMERACIÓN

En la enumeración Mode se definen los siguientes valores:

o
OFF:
Un std::ostream con este modo no se utilizará al insertar información en un MultiBuf
o
ON:
Un std::ostream con este modo se utilizará al insertar información en un MultiBuf
o
ONCE:
Un std::ostream con este modo se utilizará una vez, hasta la próxima operación de vaciado, al insertar información en un MultiBuf
o
RESET:
Un std::ostream con este modo no se utilizará al insertar información en un MultiBuf. En una operación de vaciado, todos los modos ONCE se establecerán en RESET
o
ALL:
Este modo se utiliza en combinación con el miembro remove para eliminar todos los elementos std::ostream que coincidan con un argumento std::ostream especificado.

TIPOS

Los siguientes subtipos están definidos en la clase FBB:MultiBuf:

o
iterator:
Este es un sinónimo de std::vector<stream>::iterator
o
const_iterator:
Este es un sinónimo de std::vector<stream>::const_iterator

CLASE ANIDADA

La clase MultiBuf::stream está definida como una clase anidada de MultiBuf. Ofrece el siguiente constructor y miembros públicos:

o
stream(std::ostream &os, Mode mode = ON):
El constructor almacena un objeto std::ostream y le asocia un valor Mode.
o
void setMode(Mode mode):
Este miembro se utiliza para redefinir el valor Mode del stream.
o
void mode() const:
Este miembro devuelve el valor Mode del stream.
o
operator std::ostream &():
Este miembro devuelve el std::ostream del stream.

CONSTRUCTORES

o
MultiBuf():
El constructor predeterminado crea un objeto MultiBuf que no contiene objetos std::ostream asociados.
o
MultiBuf(std::ostream &os, Mode mode = ON):
Este constructor crea un objeto MultiBuf que se asocia inmediatamente con el std::ostream especificado como su primer argumento.
o
MultiBuf(std::vector<MultiBuf::stream> const &osvector):
Este constructor crea un objeto MultiBuf que se asocia inmediatamente con todos los objetos std::ostream que se almacenan en los elementos MultiBuf::stream del vector especificado.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

FUNCIONES MIEMBRO

Todos los miembros de std::ostringstream y std::exception están disponibles, ya que MultiBuf hereda de estas clases.

o
iterator begin():
Este miembro devuelve un iterador al primer elemento stream que se almacena en un objeto MultiBuf.
o
const_iterator begin():
Este miembro devuelve un iterador al primer elemento stream (no modificable) que se almacena en un objeto MultiBuf.
o
iterator end():
Este miembro devuelve un iterador que apunta más allá del último elemento stream que se almacena en un objeto MultiBuf.
o
const_iterator end():
Este miembro devuelve un iterador que apunta más allá del último elemento stream (no modificable) que se almacena en un objeto MultiBuf.
o
void insert(std::ostream &os, Mode mode = ON):
Este miembro añade el std::ostream especificado utilizando el Mode especificado al conjunto actual de objetos stream. Tenga en cuenta que si se llama varias veces para std::ostreams idénticos, estos objetos también se insertan varias veces.
o
void insert(std::vector<stream> const &os):
Este miembro añade todos los objetos stream almacenados en el vector os al conjunto actual de objetos stream.
o
bool remove(std::ostream &os, Mode mode = ONCE):
Si os está almacenado en el MultiBuf, se elimina y se devuelve true. Si se especifica el modo ALL, se eliminan todos los objetos os que estaban almacenados en el objeto MultiBuf (y se devuelve true). Si el objeto os no estaba almacenado, se devuelve false. Para determinar si os se ha almacenado en el objeto MultiBuf, su dirección se compara con las direcciones de los objetos std::ostream que están almacenados dentro del objeto MultiBuf: el (los) objeto(s) con las direcciones &os se elimina(n).
o
void void setOnce():
Este miembro restablecerá todos los valores Mode RESET de los objetos stream almacenados a ONCE.
o
size_t size() const:
El número de flujos atendidos actualmente por el objeto MultiBuf es devuelto.

EJEMPLO

#include <iostream>
#include <fstream>
#include <bobcat/multibuf>
using namespace std;
using namespace FBB;
int main()
{
    MultiBuf  msb(cout);
    ostream         os(&msb);
    ofstream        out("out");
    msb.insert(out, MultiBuf::ONCE);
    os << "Esto va en cout y out\n"
          "Esto solo va en cout\n";
    msb.setOnce();
    os << "Esto va en cout y out\n"
          "Esto solo va en cout\n";
}
