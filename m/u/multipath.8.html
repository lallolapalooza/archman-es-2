MULTIPATH(8) Manual del Administrador del Sistema MULTIPATH(8)

NOMBRE

multipath - Autoconfiguración de destino del mapeador de dispositivos.

SINOPSIS

multipath [-v nivel] [-B|-d|-i|-q|-r] [-b archivo] [-p política] [dispositivo]

multipath [-v nivel] [-R reintentos] -f dispositivo

multipath [-v nivel] [-R reintentos] -F

multipath [-v nivel] [-l|-ll] [dispositivo]

multipath [-v nivel] [-a|-w] dispositivo

multipath [-v nivel] -W

multipath [-v nivel] [-i] [-c|-C] dispositivo

multipath [-v nivel] [-i] [-u|-U]

multipath [-h|-t|-T]

DESCRIPCIÓN

multipath se utiliza para detectar y unificar múltiples rutas a dispositivos, para fines de conmutación por error o rendimiento.

ARGUMENTOS

El argumento dispositivo restringe la operación de multipath a los dispositivos que coinciden con la expresión dada. El argumento puede referirse a un mapa multipath o a sus componentes ("rutas"). La expresión puede tener uno de los siguientes formatos:

nodo de dispositivo
nombre de archivo de un nodo de dispositivo, p. ej., /dev/dm-10 o /dev/sda. Si el nodo se refiere a un dispositivo mapeador de dispositivos existente que representa un mapa multipath, esto selecciona el mapa o sus rutas, dependiendo del modo de operación. De lo contrario, selecciona un dispositivo de ruta.
ID de dispositivo
número de dispositivo del kernel especificado por números mayor:menor, p. ej., 65:16. Este formato solo se puede usar para dispositivos de ruta.
WWID
un Identificador Mundial (World Wide Identifier) que coincide con un mapa multipath o sus rutas. Para listar los WWID de los dispositivos presentes en el sistema, utilice, por ejemplo, el comando "multipath -d -v3 2>/dev/null".

MODOS DE OPERACIÓN

El modo de operación predeterminado es detectar y configurar mapas multipath a partir de los dispositivos encontrados en el sistema. Otros modos de operación se eligen utilizando uno de los siguientes modificadores de línea de comandos:

-f
Descarga (elimina) un mapa de dispositivo multipath especificado como parámetro, si no se utiliza. Esta operación se delega al demonio multipathd si se está ejecutando.
-F
Descarga (elimina) todos los mapas de dispositivos multipath no utilizados. Esta operación se delega al demonio multipathd si se está ejecutando.
-l
Muestra ("lista") la topología multipath actual a partir de la información obtenida de sysfs y el mapeador de dispositivos.
-ll
Muestra ("lista") la topología multipath actual a partir de toda la información disponible (sysfs, el mapeador de dispositivos, verificadores de rutas...).
-a
Añade el WWID del dispositivo especificado al archivo WWID.
-w
Elimina el WWID del dispositivo especificado del archivo WWID.
-W
Restablece el archivo WWID para que solo incluya los dispositivos multipath actuales.
-c
Comprueba si un dispositivo de bloque debe ser una ruta en un dispositivo multipath.
-C
Comprueba si un dispositivo multipath tiene rutas utilizables. Esto se puede utilizar para probar si la E/S en este dispositivo probablemente tendrá éxito. El comando en sí no intenta realizar E/S en el dispositivo.
-u
Comprueba si el dispositivo especificado en el entorno del programa debe ser una ruta en un dispositivo multipath.
-U
Comprueba si el dispositivo especificado en el entorno del programa es un dispositivo multipath con rutas utilizables. Véase -C.
-h
Muestra el texto de uso.
-t
Muestra la configuración actual de multipathd utilizada.
-T
Muestra la configuración actual de multipathd utilizada, limitando la salida a aquellos dispositivos realmente presentes en el sistema. Esto se puede utilizar como una plantilla para crear /etc/multipath.conf.

OPCIONES

-v nivel
Verbosidad de la información impresa en stdout en los modos de operación predeterminado y de "lista". El nivel predeterminado es -v 2.
0
No se imprime nada.
1
En modo predeterminado, se imprimen los nombres/WWID de los mapas multipath creados o modificados. En modo de lista, se imprimen los WWID de todos los mapas multipath.
2
En modo predeterminado, se imprime la topología de los mapas multipath creados o modificados. En modo de lista, se imprime la topología de todos los mapas multipath.
3
Se imprimen todas las rutas detectadas y la topología de todos los mapas multipath.

El nivel de verbosidad también controla el nivel de mensajes de registro y depuración impresos en stderr. El nivel predeterminado corresponde a LOG_NOTICE (mensajes importantes que no deben perderse en operación normal).

-d
Ejecución de prueba (dry run), no crea ni actualiza devmaps.
-e
Habilita todas las bibliotecas externas. Esto anula la opción enable_foreign de multipath.conf(5).
-i
Ignora el archivo WWID al procesar dispositivos. Si se establece find_multipaths strict o find_multipaths no en /etc/multipath.conf, multipath solo considera los dispositivos que están listados en el archivo WWID. Esta opción anula ese comportamiento. Para otros valores de find_multipaths, esta opción no tiene efecto. Vea la descripción de find_multipaths en /etc/multipath.conf(5). Esta opción solo debe usarse en circunstancias raras.
-B
Trata el archivo de enlaces (bindings) como de solo lectura.
-b archivo
(obsoleto, no usar) Establece la ubicación del archivo de enlaces user_friendly_names. El valor predeterminado es /etc/multipath/bindings.
-q
No desactiva la función del mapeador de dispositivos queue_if_no_path para mapas multipath. Normalmente, multipath lo haría si multipathd no se está ejecutando, porque solo un demonio multipath en ejecución garantiza que las rutas inutilizables se restablezcan cuando vuelven a ser utilizables.
-p política
Fuerza a los nuevos mapas a usar la política especificada, anulando la configuración en multipath.conf(5). Los valores posibles para política son los mismos que los valores para path_grouping_policy en multipath.conf(5). Los mapas existentes no se modifican.
-r
Fuerza la recarga de todos los mapas multipath existentes. Este comando se delega al demonio multipathd si se está ejecutando. En este caso, otros modificadores de línea de comandos del comando multipath no tienen efecto.
-R reintentos
Número de veces que se reintentará descargar los dispositivos multipath que están en uso. El valor predeterminado es 0.
