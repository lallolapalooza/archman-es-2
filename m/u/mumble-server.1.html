NOMBRE

mumble-server - Servidor VoIP.

SINOPSIS

mumble-server [-ini archivoini] [-fg] [-v]
mumble-server -supw contraseña [serverid]
mumble-server -readsupw [serverid]
mumble-server -disablesu [serverid]
mumble-server -limits
mumble-server -wipessl
mumble-server -wipelogs
mumble-server -loggroups
mumble-server -logacls
mumble-server -license
mumble-server -authors
mumble-server -third-party-licenses
mumble-server -version|--version
mumble-server -h|-help|--help

DESCRIPCIÓN

mumble-server es el componente de servidor de Mumble, una aplicación VoIP de baja latencia y alta calidad.

OPCIONES

-h, -help, --help
Muestra un resumen de las opciones.
-ini archivoini
Especifica qué archivo ini usar. Sin esta opción, mumble-server buscará un archivo murmur.ini y recurrirá a los valores predeterminados integrados si no se encuentra uno.
-fg
Ejecutar en primer plano (no hacer fork).
-v
Modo detallado, se registra información ligeramente más detallada.
-supw contraseña [serverid]
Establece la contraseña de SuperUsuario para un servidor. SuperUsuario es una cuenta especial (similar a root) que omite todos los controles de acceso. Este comando se puede usar mientras el servidor se está ejecutando. Opcionalmente, toma un serverid que representa el servidor virtual para el cual se establecerá la contraseña.
-readsupw [serverid]
Lee la contraseña de SuperUsuario desde la entrada estándar. Opcionalmente, toma un serverid que representa el servidor virtual para el cual se establecerá la contraseña.
-disablesu [serverid]
Deshabilita la cuenta de SuperUsuario. Opcionalmente, toma un serverid que representa el servidor virtual en el que se deshabilitará la cuenta de SuperUsuario.

Deshabilitar la cuenta de SuperUsuario hace imposible iniciar sesión como SuperUsuario hasta que se establezca una nueva contraseña. Puede establecer una nueva contraseña de SuperUsuario con el parámetro -supw.

-limits
Prueba y muestra cuántos descriptores de archivo e hilos se pueden crear. El propósito de esta opción es probar cuántos clientes puede manejar el servidor. El servidor saldrá después de esta prueba.
-wipessl
Elimina los certificados SSL de la base de datos.
-wipelogs
Elimina todas las entradas de registro de la base de datos.
-loggroups
Activa el registro de cambios de grupos para todos los servidores.
-logacls
Activa el registro de cambios de ACL para todos los servidores.
-license
Muestra la licencia de mumble-server.
-authors
Muestra los autores de mumble-server.
-third-party-licenses
Muestra las licencias del software de terceros utilizado por mumble-server.
-version, --version
Muestra información de la versión.

SEÑALES

SIGHUP
Realiza una rotación de registros. Esto hace que mumble-server reabra su archivo de registro.
SIGUSR1
Recarga con gracia la configuración TLS especificada en murmur.ini sin interrumpir el servicio.

Cuando se recibe esta señal, el servidor aplicará la nueva configuración TLS (certificado, clave privada y parámetros Diffie-Hellman) a todos los servidores virtuales que utilicen la configuración TLS de murmur.ini.

Los servidores virtuales que hayan anulado la configuración de murmur.ini no se verán afectados por esta señal. Esos servidores se pueden actualizar utilizando la llamada RPC updateCertificate.

VER TAMBIÉN

mumble(1), murmur-user-wrapper(1).

AUTORES
