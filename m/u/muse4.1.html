MUSE(1) Manual de comandos generales MUSE(1)

NOMBRE

MusE - Secuenciador MIDI/Audio

SINOPSIS

muse4 [ opciones ] [ archivo ]

DESCRIPCIÓN

MusE es un secuenciador MIDI/Audio que también puede grabar y editar archivos de sonido, aplicar efectos y filtros desde una interfaz gráfica intuitiva. Se basa en la interfaz ALSA específica de Linux para entrada/salida de audio. El Kit de Conexión de Audio Jack se utiliza para el enrutamiento. Los plugins compatibles con LADSPA permiten extender la lista de efectos disponibles.

El argumento opcional archivo denota un archivo de proyecto en formato interno de MusE que se carga al inicio. Los archivos de proyecto también se pueden cargar más tarde a través del menú gráfico.

OPCIONES

-a
Utiliza un backend de audio ficticio en lugar de entrada/salida de audio real.
-d
Inicia en modo de depuración sin hilos en tiempo real.
-D
Habilita mensajes de depuración detallados.
-h
Muestra información de uso.
-I
No intenta cargar ningún plugin DSSI.
-l xx
Fuerza la configuración regional al código de idioma/país xx.
-L
No utiliza LASH.
-m
Proporciona mensajes de depuración sobre eventos de entrada MIDI.
-M
Proporciona mensajes de depuración sobre eventos de salida MIDI.
-p
No intenta cargar ningún plugin LADSPA.
-P n
Establece la prioridad de planificación de los hilos en tiempo real a n (Solo ficticio, por defecto 40. De lo contrario, fijo por Jack.).
-s
Proporciona mensajes de depuración sobre eventos de sincronización.
-v
Imprime información de la versión.
-V
No intenta cargar ningún plugin VST.
-y
Habilita el soporte de control de Python.
-Y n
Fuerza la prioridad de tiempo real MIDI a n.

VER TAMBIÉN

MusE proporciona un sistema de ayuda integrado en la interfaz gráfica de usuario.
