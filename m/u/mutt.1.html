NOMBRE

mutt - El Agente de Usuario de Correo Mutt

SINOPSIS

mutt
[-nRyzZ] [-e comando] [-F archivo_rc] [-m tipo] [-f buzon]
mutt
[-Enx] [-e comando] [-F archivo_rc] [-H borrador] [-i archivo_incluir]
[-b dirección_bcc] [-c dirección_cc] [-s asunto]
[-a archivo ... --] dirección_destinatario ...
mutt
[-nx] [-e comando] [-F archivo_rc] [-b dirección_bcc] [-c dirección_cc]
[-s asunto] [-a archivo ... --] dirección_destinatario ... < mensaje
mutt
[-n] [-e comando] [-F archivo_rc] -p
mutt
[-n] [-e comando] [-F archivo_rc] -A alias
mutt
[-n] [-e comando] [-F archivo_rc] -Q variable
mutt
-v[v]
mutt
-D

DESCRIPCIÓN

Mutt es un programa pequeño pero muy potente basado en texto para leer y enviar correo electrónico en sistemas operativos Unix, incluyendo soporte para terminales de color, MIME, OpenPGP y un modo de ordenación por hilos.

Nota: Esta página del manual ofrece una breve descripción general de las opciones de línea de comandos del ejecutable mutt. Una copia del manual completo se encuentra en /usr/share/doc/mutt, en formato de texto, HTML y/o PDF. Consulte el manual para aprender a usar y configurar Mutt.

OPCIONES

-A alias
Imprime una versión expandida del alias dado y sale.
-a archivo ...
Adjunta un archivo usando MIME. Separar los argumentos de archivo y dirección_destinatario con “--” es obligatorio. Por ejemplo: 


mutt -a imagen.jpg -- dirección_destinatario
mutt -a img.jpg *.png -- dirección_destinatario-1 dirección_destinatario-2

La opción -a debe colocarse al final de las opciones de línea de comandos.

-b dirección_bcc
Especifica una dirección de copia carbón oculta (BCC).
-c dirección_cc
Especifica una dirección de copia carbón (CC).
-d nivel
Si Mutt fue compilado con +DEBUG, registra la salida de depuración en ~/.muttdebug0. Nivel puede variar de -5 a 5 y afecta la verbosidad. Un valor de cero deshabilita la depuración. Un valor menor que cero deshabilita la rotación automática del archivo de registro; el nivel de registro es entonces su valor absoluto. Se recomienda un valor de 2 (-2) para la mayoría de los diagnósticos.
-D
Imprime el valor de todas las opciones de configuración en stdout.
-E
Edita el archivo borrador especificado por -H o el archivo incluir especificado por -i durante la composición del mensaje.
-e comando
Especifica un comando de configuración que se ejecutará después de procesar los archivos de inicialización.
-f buzón
Especifica un buzón para cargar.
-F archivo_rc
Usa archivo_rc en lugar del archivo de configuración del usuario.
-h
Muestra un resumen corto de las opciones y sale.
-H borrador
Especifica un archivo borrador que contiene la cabecera y el cuerpo para enviar un mensaje. Si borrador es “-”, los datos se leen desde stdin. Se espera que el archivo de borrador contenga solo un correo electrónico RFC822 — cabeceras y un cuerpo. Aunque no es un archivo mbox, si hay una línea de encabezado de mbox “From ”, se descartará silenciosamente. Los archivos de borrador se procesan de la misma manera en modo interactivo y por lotes; no se pasan sin cambios. Por ejemplo, los archivos de borrador cifrados se descifrarán.
-i archivo_incluir
Especifica un archivo incluir que se insertará en el cuerpo de un mensaje. Se ignora si se establece -H. Si archivo_incluir es “-”, los datos se leen desde stdin.
-m tipo
Especifica un tipo de buzón predeterminado para las carpetas recién creadas. Puede ser uno de los siguientes: mbox, MMDF, MH o Maildir. Consulte también $mbox_type en el manual.
-n
No lee el archivo de configuración global de Muttrc.
-p
Reanuda un mensaje pospuesto. Sale inmediatamente si no hay mensajes pospuestos.
-Q variable
Consulta una variable de configuración. La consulta se realiza después de que se hayan analizado todos los archivos de configuración y se hayan ejecutado los comandos proporcionados en la línea de comandos.
-R
Abre un buzón en modo de solo lectura.
-s asunto
Especifica el asunto del mensaje. Debe ir entre comillas si contiene espacios.
-v
Muestra el número de versión de Mutt y las definiciones en tiempo de compilación.
-vv
Muestra información de licencia y derechos de autor.
-x
Emula el modo de composición de mailx(1).
-y
Inicia Mutt con una lista de todos los buzones especificados por el comando de configuración mailboxes.
-z
Sale inmediatamente con el código 1 si el buzón especificado por -f no contiene ningún mensaje.
-Z
Abre el primer buzón especificado por el comando de configuración mailboxes que contiene correo nuevo. Sale inmediatamente con el código 1 si no hay correo nuevo en ninguno de ellos.
--
Trata los argumentos restantes como dirección_destinatario incluso si comienzan con un guion. Consulte también -a arriba. Dirección_destinatario puede ser una dirección de correo local o de red, así como una URL mailto:.

AMBIENTE

EDITOR, VISUAL
Especifica el editor que se utilizará al componer mensajes. Si tanto EDITOR como VISUAL están definidos, VISUAL tiene prioridad. Si ninguno de los dos está definido, el predeterminado es vi(1).
EGDSOCKET, RANDFILE
Rutas utilizadas para inicializar el motor aleatorio para la biblioteca SSL.
EMAIL
La dirección de correo electrónico del usuario.
HOME
Ruta completa del directorio personal del usuario.
MAIL
Ruta completa del buzón de correo del usuario.
MAILDIR
Ruta completa del buzón de correo del usuario si MAIL no está definido. Comúnmente utilizado cuando el buzón de correo es una carpeta maildir(5).
MAILCAPS
Ruta para buscar archivos mailcap.
MM_NOASK
Si esta variable está definida, Mutt no pedirá confirmación al usuario antes de enviar un correo electrónico o realizar otras operaciones potencialmente destructivas. Por ejemplo, si Mutt está configurado para usar un sistema de correo que requiere confirmación, esta variable evitará la solicitud de confirmación.

ENVIRONMENT

EDITOR
The editor mutt will use to edit messages. If unset, vi is used.
EMAIL
Default email address for the sender. If unset, mutt tries to determine this from the environment.
LANG, LC_ALL, LC_CTYPE
Used to determine charset and locale to use.
MAILCAPS
A colon-separated list of files to search for mailcap entries. See mailcap(5). Mutt will first check this list of files, then the system-wide mailcap files, and finally the user's ~/.mailcap file. If MAILCAPS is set, the mailcap, and mailcap.mailcap files are always used without prompting first.
PGPPATH
Directory in which the user's PGP public keyring can be found. When used with the original PGP program, mutt and mutt_pgpring(1) rely on this being set.
REPLYTO
Default Reply-To address.
TMPDIR
Directory in which temporary files are created. If unset, /tmp is used. See also $tmpdir configuration variable.
TEXTDOMAINDIR
Directory containing translation files. If set, this path overwrite the Mutt installation directory. Used for testing translation changes.

FILES

~/.muttrc
~/.mutt/muttrc
$XDG_CONFIG_HOME/mutt/muttrc
User configuration files.
/etc/mutt/Muttrc or /usr/share/mutt/Muttrc
System-wide configuration file.
/tmp/muttXXXXXX
Temporary files created by Mutt.
~/.muttdebug0
File containing debugging output. Log files are automatically rotated by mutt changing the number at the end. See -d option above.
~/.mailcap
User definition for handling non-text MIME types.
/etc/mutt/mailcap
System definition for handling non-text MIME types.
~/.mime.types
User's personal mapping between MIME types and file extensions.
/etc/mutt/mime.types
System mapping between MIME types and file extensions.
/usr/bin/mutt_dotlock
The privileged dotlocking program.
/usr/share/doc/mutt/manual.txt
The Mutt manual.

BUGS

None. Mutts have fleas, not bugs.

FLEAS

Suspend/resume while editing a file with an external editor does not work under SunOS 4.x if you use the curses lib in /usr/5lib. It does work with the S-Lang library, however.

Resizing the screen while using an external pager causes Mutt to go haywire on some systems.

Suspend/resume does not work under Ultrix.

The help line for the index menu is not updated if you change the bindings for one of the functions listed while Mutt is running.

For a more up-to-date list of bugs, errm, fleas, please visit the mutt project's bug tracking system under https://gitlab.com/muttmua/mutt/issues.
