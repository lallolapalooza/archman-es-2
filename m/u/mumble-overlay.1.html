NOMBRE

mumble-overlay - carga el overlay OpenGL para Mumble.

SINOPSIS

ejecutable mumble-overlay

DESCRIPCIÓN

Este script de inicio cargará el overlay OpenGL para Mumble en la aplicación de tu elección. Esto te permite ver fácilmente quién está hablando incluso en juegos y aplicaciones a pantalla completa.

No se mostrará nada a menos que tengas Mumble ejecutándose y esté actualmente conectado a un servidor.

VARIABLES DE ENTORNO

MUMBLE_OVERLAY_DEBUG
Si esta variable de entorno está establecida, se generarán mensajes de depuración extendidos en la salida estándar. Solo es útil para depuración.

EJEMPLO

Para ejecutar glxgears con el mumble-overlay activo:

mumble-overlay glxgears

NOTAS

Esto solo funcionará con controladores OpenGL que soporten las especificaciones completas de OpenGL y GLX.
