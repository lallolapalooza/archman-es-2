NOMBRE

mungekey - Utilidad de gestión de claves de MUNGE

SINOPSIS

mungekey [-c] [-b bits] [-f] [-k archivo de clave] [-v]

DESCRIPCIÓN

El ejecutable mungekey es la utilidad de gestión de claves para MUNGE. Debe ser ejecutado por el mismo usuario que inicia el demonio munged.

Si no se especifican opciones, mungekey intentará crear una nueva clave utilizando la configuración predeterminada; esto fallará si el archivo de clave ya existe.

Todos los demonios munged dentro de un ámbito de seguridad deben usar la misma clave. En otras palabras, todos los hosts dentro de un grupo administrativo (o clúster) que utilicen MUNGE para la autenticación deben usar la misma clave; esta clave puede crearse en un host y luego copiarse de forma segura a todos los demás hosts.

OPCIONES

-b, --bits entero
Especificar el número de bits en la clave que se está creando [256-8192].
-c, --create
Crear un nuevo archivo de clave.
-f, --force
Forzar la sobrescritura del archivo de clave si ya existe.
-h, --help
Mostrar un resumen de las opciones de la línea de comandos.
-k, --keyfile ruta
Especificar la ruta del archivo de clave.
-L, --license
Mostrar información de licencia.
-v, --verbose
Ser verboso.
-V, --version
Mostrar información de la versión.

ARCHIVOS

/etc/munge/munge.key

Contiene la clave criptográfica compartida para los hosts dentro del ámbito de seguridad.
