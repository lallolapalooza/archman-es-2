MUNGE(1) Emporio de Cifrado de UID 'N' GID de MUNGE MUNGE(1)

NOMBRE

munge - codificador de credenciales MUNGE

SINOPSIS

munge [OPCION]...

DESCRIPCIÓN

El programa munge crea una credencial MUNGE que contiene el UID y GID del proceso que llama. También se pueden encapsular datos de carga útil adicionales (hasta 1 MB). La credencial devuelta se puede pasar a otro proceso que pueda validar su contenido (por ejemplo, a través del programa unmunge). Esto permite que un proceso no relacionado y potencialmente remoto determine la identidad del proceso que llama.

Por defecto, la entrada de la carga útil se lee desde stdin y la credencial se escribe en stdout.

OPCIONES

-h, --help
Muestra un resumen de las opciones de la línea de comandos.
-L, --license
Muestra información sobre la licencia.
-V, --version
Muestra información sobre la versión.
-n, --no-input
Descarta toda la entrada para la carga útil.
-s, --string cadena
Entrada de la carga útil desde la cadena especificada.
-i, --input ruta
Entrada de la carga útil desde el archivo especificado.
-o, --output ruta
Salida de la credencial al archivo especificado.
-c, --cipher cadena
Especifica el tipo de cifrado, ya sea por nombre o número.
-C, --list-ciphers
Muestra una lista de tipos de cifrado compatibles.
-m, --mac cadena
Especifica el tipo de MAC, ya sea por nombre o número.
-M, --list-macs
Muestra una lista de tipos de MAC compatibles.
-z, --zip cadena
Especifica el tipo de compresión, ya sea por nombre o número.
-Z, --list-zips
Muestra una lista de tipos de compresión compatibles.
-u, --restrict-uid uid
Especifica el nombre de usuario o UID permitido para decodificar la credencial. Esto se comparará con el ID de usuario efectivo del proceso que solicita la decodificación de la credencial.
-U, --uid uid
Especifica el nombre de usuario o UID bajo el cual se solicita la credencial. Esto requiere privilegios de root o la capacidad CAP_SETUID.
-g, --restrict-gid gid
Especifica el nombre de grupo o GID permitido para decodificar la credencial. Esto se comparará con el ID de grupo efectivo del proceso que solicita la decodificación de la credencial, así como con cada grupo suplementario del que el ID de usuario efectivo de ese proceso sea miembro.
-G, --gid gid
Especifica el nombre de grupo o GID bajo el cual se solicita la credencial. Esto requiere privilegios de root o la capacidad CAP_SETGID.
-t, --ttl segundos
Especifica el tiempo de vida (en segundos). Esto controla cuánto tiempo es válida la credencial una vez que ha sido codificada. Un valor de 0 selecciona el TTL predeterminado. Un valor de -1 selecciona el TTL máximo permitido. Tenga en cuenta que munged puede imponer un TTL máximo permitido para todas las credenciales, que puede ser menor que este valor.
-S, --socket ruta
Especifica el socket local para conectarse con munged.

ESTADO DE SALIDA

El programa munge devuelve un código de salida cero cuando la credencial se crea y devuelve con éxito. En caso de error, imprime un mensaje de error en stderr y devuelve un código de salida distinto de cero.
