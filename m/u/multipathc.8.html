MULTIPATHC(8) Manual del Administrador del Sistema MULTIPATHC(8)

NOMBRE

multipathc - Cliente interactivo para multipathd

SINOPSIS

multipathc [ tiempo_espera ]

DESCRIPCIÓN

La herramienta multipathc proporciona un shell interactivo para comunicarse con el demonio multipathd. El comando multipathd -k invoca a multipathc.

Todos los comandos documentados en multipathd(8) son compatibles. Los comandos disponibles se pueden ver introduciendo 'help'. Usa quit, exit o CTRL-D para salir del shell. Las palabras clave se pueden abreviar con las primeras letras (por ejemplo, shu para shutdown), si la abreviatura es única. Algunos comandos admiten la impresión formateada usando especificadores de formato estilo printf. Los especificadores de formato compatibles se pueden listar con el comando show wildcards. Dependiendo de las opciones de compilación, el shell interactivo puede proporcionar funciones de completado de comandos y expansión de historial.

El parámetro opcional tiempo_espera especifica el tiempo de espera para recibir una respuesta de multipathd, en milisegundos. El valor predeterminado es 4000 ms.

VER TAMBIÉN

multipathd(8)
