NOMBRE

munin-node - Un demonio para recopilar información en cooperación con el programa principal de Munin

SINOPSIS

munin-node [--opciones]

DESCRIPCIÓN

munin-node es un demonio para reportar estadísticas sobre el rendimiento del sistema.

No las produce él mismo, sino que se basa en una serie de plugins que son responsables de recopilar los datos que requieren y describir cómo deben ser graficados. De hecho, hace poco más que atender las solicitudes del maestro de Munin, ejecutar los plugins apropiados y devolver la salida que producen.

OPCIONES

--config <archivo_config>
Usa <archivo> como archivo de configuración. [/etc/munin/munin-node.conf]
--[sin]paranoia
Solo ejecuta plugins propiedad de root. Comprueba también los permisos. [--sinparanoia]
--ayuda
Muestra este mensaje de ayuda.
--[sin]debug
Muestra mensajes de depuración. Esto puede ser muy verboso.
--[sin]pidebug
Depuración de plugins. Establece la variable de entorno MUNIN_DEBUG a 1 para que los plugins puedan habilitar la depuración. [--sinpidebug]

ARCHIVOS

/etc/munin/plugins/*
/etc/munin/plugin-conf.d/*

VER TAMBIÉN

Para obtener información sobre las opciones de configuración, consulta la página del manual de munin-node.conf.

Muchos plugins pueden informar si pueden ser utilizados razonablemente en el nodo o no. "munin-node-configure" puede usar esta información para ayudar a administrar los plugins instalados.

El protocolo de red se documenta en http://munin-monitoring.org/wiki/network-protocol
