NOMBRE

munin-node-configure - Ver y modificar qué plugins están habilitados.

SINOPSIS

munin-node-configure [opciones]

DESCRIPCIÓN

munin-node-configure informa sobre los plugins que están activados en el nodo actual y sugiere cambios a esta lista.

Por defecto, este programa muestra los plugins que están activados en el sistema.

Si especificas "--suggest", presentará una tabla de plugins que probablemente funcionarán (según el comando de autoconfiguración de los plugins).

Si especificas "--snmp", seguido de una lista de hosts, presentará una tabla de plugins SNMP que soportan.

Si además especificas "--shell", se imprimirán comandos de shell para instalar esos mismos plugins. Estos pueden ser revisados o dirigidos directamente a un shell para instalar los plugins.

OPCIONES

--help
Muestra esta página de ayuda.
--version
Muestra información de la versión.
--debug
Imprime información de depuración sobre las operaciones de "munin-node-configure". Esto puede ser muy verboso.

Toda la salida de depuración se imprime en STDOUT, y cada línea está prefijada con '#'. Solo los errores se imprimen en STDERR.

--pidebug
Depuración de plugins. Establece la variable de entorno MUNIN_DEBUG a 1 para que los plugins puedan habilitar la depuración.
--config <archivo>
Anula el archivo de configuración [/etc/munin/munin-node.conf]
--servicedir <directorio>
Anula el directorio de plugins [/etc/munin/plugins/]
--sconfdir <directorio>
Anula el directorio de configuración de plugins [/etc/munin/plugin-conf.d/]
--libdir <directorio>
Anula la biblioteca de plugins [/usr/lib/munin/plugins/]
--suggest
Sugiere plugins que podrían ser añadidos o eliminados, en lugar de los que están actualmente habilitados.

OPCIONES DE SALIDA

Por defecto, "munin-node-configure" imprimirá una tabla que resume los resultados.

--shell
En lugar de una tabla, imprime comandos de shell para instalar las nuevas sugerencias de plugins.

Esto implica "--suggest", a menos que también se haya habilitado "--snmp". Por defecto, no intentará eliminar ningún plugin.

--remove-also
Cuando "--shell" está habilitado, también proporciona comandos para eliminar plugins que ya no son aplicables del directorio de servicios.

OPCIONES DE SELECCIÓN DE PLUGINS

--families <familia,...>
Anula la lista de familias que se utilizarán (auto, manual, contrib, snmpauto). Se pueden especificar varias familias como una lista separada por comas, repitiendo la opción "--families", o como una combinación de ambas.

Al listar plugins instalados, las familias por defecto son 'auto', 'manual' y 'contrib'. Solo se comprueban los plugins 'auto' para sugerencias. La sondeo SNMP solo se realiza en plugins 'snmpauto'.

--newer <versión>
Solo considera plugins añadidos al núcleo de Munin desde <versión>. Esta opción es útil al actualizar, ya que puede evitar que se reinstalen plugins que han sido eliminados manualmente. Esto solo se aplica a los plugins de la familia 'auto'.

Opciones SNMP

--snmp <host|cidr,...>
Sondea los agentes SNMP en el host o red CIDR (por ejemplo, "192.168.1.0/24") para ver qué plugins soportan. Esto puede llevar tiempo, especialmente si se especifican muchos hosts.

Esta opción se puede especificar varias veces, o como una lista separada por comas, para incluir más de un host/CIDR.

--snmpversion <ver>
La versión SNMP (1, 2c o 3) a utilizar. ['2c']
--snmpport <puerto>
El puerto SNMP a utilizar [161]
--snmpdomain <dominio>
El Dominio de Transporte a utilizar para intercambiar mensajes SNMP. El valor por defecto es UDP/IPv4. Valores posibles: 'udp', 'udp4', 'udp/ipv4'; 'udp6', 'udp/ipv6'; 'tcp', 'tcp4', 'tcp/ipv4'; 'tcp6', 'tcp/ipv6'.
Autenticación SNMP 1/2c
Las versiones SNMP 1 y 2c utilizan una "cadena de comunidad" para la autenticación. Esta es una contraseña compartida, enviada en texto plano a través de la red.
--snmpcommunity <cadena>
La cadena de comunidad para agentes de versión 1 y 2c. ['public'] (Si esto funciona, es probable que su dispositivo sea muy inseguro y necesite una revisión de seguridad).
Autenticación SNMP 3
SNMP v3 tiene tres niveles de seguridad. El más bajo es "noAuthNoPriv", que no proporciona ni autenticación ni cifrado. Si se proporcionan un nombre de usuario y una "authpassword", se eleva a "authNoPriv", y la conexión se autentica. Si también se proporciona "privpassword", el nivel de seguridad se convierte en "authPriv", y la conexión se autentica y cifra.

Nota: El cifrado puede ralentizar dispositivos de red lentos o muy cargados. Para la mayoría de los usos, "authNoPriv" será suficientemente seguro: la contraseña se envía a través de la red cifrada en cualquier caso.

Los ContextEngineIDs no son compatibles (todavía).

Para más información sobre los modelos de seguridad de SNMP v3, consulte RFC3414 y la documentación de Net::SNMP.

--snmpusername <nombre>
Nombre de usuario. No hay valor por defecto.
--snmpauthpassword <contraseña>
Contraseña de autenticación. Opcional cuando el cifrado también está habilitado, en cuyo caso toma por defecto la contraseña de privacidad ("--snmpprivpassword").
--snmpauthprotocol <protocolo>
Protocolo de autenticación. Uno de 'md5' o 'sha' (HMAC-MD5-96, RFC1321 y SHA-1/HMAC-SHA-96, NIST FIPS PIB 180, RFC2264). ['md5']
--snmpprivpassword <contraseña>
Contraseña de privacidad para habilitar el cifrado. No hay valor por defecto. Una contraseña vacía ('') se considera sin contraseña y no habilitará el cifrado.

La privacidad requiere un privprotocolo además de un authprotocolo y una authpassword, pero todos estos tienen valores por defecto (a 'des', 'md5' y el valor de privpassword, respectivamente) y, por lo tanto, pueden dejarse sin especificar.

--snmpprivprotocol <protocolo>
Si se establece la privpassword, esta opción controla qué tipo de cifrado se utiliza para lograr la privacidad en la sesión. Solo se admite oficialmente el método de cifrado 'des', muy débil. ['des']

NAME

munin-node-configure

auto-configure munin-node plugins

SYNOPSIS

munin-node-configure

--help
--version
--show-plugins
--suggest
--families
--size=SIZE
--output=FILE
--testing
--dry-run
--force
--debug
--munin-port=PORT
--munin-host=HOST
--user=USER
--pass=PASS
--authproto=PROTO
--authpass=PASS
--privproto=PROTO
--privpass=PASS
--conf=FILE
--shell=SHELL

DESCRIPTION

The munin-node-configure script is a utility that can be used to automatically configure the plugins for a munin-node. It detects which plugins are installed, and for those that are installed, determines whether they can be autoconfigured. If they can, it prints out a list of suggested configuration directives for the user to add to /etc/munin/munin-node.conf or a file in /etc/munin/plugin-conf.d/.

The script tries to be smart about it, and will only suggest configuration for plugins that it thinks are needed. It also has some heuristics to guess the correct values for some plugin configuration variables.

If munin-node-configure is run with no arguments, it will print suggestions for all installed and autoconfigurable plugins.

It is possible to specify the shell to be used for configuring plugins using the --shell option. The default shell is /bin/sh.

The script can also be used to generate a complete configuration file for a specific plugin using the --output option. This is useful if you want to create a configuration file for a plugin that is not yet supported by munin-node-configure.

The script supports configuring SNMPv3 using the following options:

--munin-port=PORT
Specifies the port on which the munin-node is listening. Defaults to 4949.
--munin-host=HOST
Specifies the hostname or IP address of the munin-node. Defaults to localhost.
--user=USER
Specifies the SNMPv3 username.
--pass=PASS
Specifies the SNMPv3 authentication password. If not specified, the script will prompt for it.
--authproto=PROTO
Specifies the SNMPv3 authentication protocol. Supported values are MD5 and SHA. Defaults to MD5.
--authpass=PASS
Specifies the SNMPv3 authentication passphrase. If not specified, the script will prompt for it.
--privproto=PROTO
Specifies the SNMPv3 privacy protocol. Supported values are DES and AES. Defaults to DES.
--privpass=PASS
Specifies the SNMPv3 privacy password. If not specified, the script will prompt for it.

The munin-node-configure script also supports '3des' (CBC-3DES-EDE, aka Triple-DES, NIST FIPS 46-3) as specified in IETF draft-reeder-snmpv3-usm-3desede. Whether or not this works with any particular device, we do not know.

FILES

/etc/munin/munin-node.conf
/etc/munin/plugin-conf.d/*
/etc/munin/plugins/*
/usr/lib/munin/plugins/plugins.history
/usr/lib/munin/plugins/*
