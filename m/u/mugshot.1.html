MUGSHOT(1) Comandos de usuario MUGSHOT(1)

NOMBRE

mugshot - utilidad ligera de configuración de usuario

DESCRIPCIÓN

Mugshot es una utilidad ligera de configuración de usuario. Mugshot te permite configurar fácilmente la imagen de perfil y los detalles del usuario para tu perfil de usuario y cualquier aplicación compatible.

SINOPSIS

mugshot [opciones]

OPCIONES

--version
mostrar el número de versión del programa y salir
-h, --help
mostrar este mensaje de ayuda y salir
-v, --verbose
Mostrar mensajes de depuración (-vv depura también mugshot_lib)

VER TAMBIÉN

La documentación completa para mugshot se mantiene en línea en el portal de documentación de los autores ⟨URL: https://github.com/bluesabre/mugshot/wiki ⟩.

ERRORES
