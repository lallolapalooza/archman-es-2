munge_enum(3)

Paquete: munge

Licencias: GPL-3.0-or-later, LGPL-3.0-or-later

MUNGE_ENUM(3) Emporio de Uid 'N' Gid de MUNGE MUNGE_ENUM(3)

NOMBRE

munge_enum_is_valid, munge_enum_int_to_str, munge_enum_str_to_int - Funciones de enumeración de MUNGE

SINOPSIS

#include <munge.h>

int munge_enum_is_valid (munge_enum_t type, int val);

const char * munge_enum_int_to_str (munge_enum_t type, int val);

int munge_enum_str_to_int (munge_enum_t type, const char *str);

cc `pkg-config --cflags --libs munge` -o foo foo.c

DESCRIPCIÓN

La función munge_enum_is_valid() comprueba si el valor dado val es una enumeración válida de MUNGE del tipo especificado type en la configuración del software tal como está compilada actualmente. Algunas enumeraciones corresponden a opciones que solo se pueden habilitar en tiempo de compilación.

La función munge_enum_int_to_str() convierte la enumeración de MUNGE val del tipo especificado type en una cadena de texto.

La función munge_enum_str_to_int() convierte la cadena de caracteres terminada en nulo y sin distinción entre mayúsculas y minúsculas str en la enumeración de MUNGE correspondiente del tipo especificado type.

VALOR DE RETORNO

La función munge_enum_is_valid() devuelve un valor distinto de cero si el valor dado val es una enumeración válida.

La función munge_enum_int_to_str() devuelve una cadena de texto constante terminada en nulo, o NULL en caso de error; el llamador no debe liberar ni modificar esta cadena.

La función munge_enum_str_to_int() devuelve una enumeración de MUNGE en caso de éxito (es decir, >= 0), o -1 en caso de error.

TIPOS DE ENUMERACIÓN

Los siguientes tipos de enumeración pueden ser especificados.

MUNGE_ENUM_CIPHER
Especifica enumeraciones para los tipos de cifrado disponibles.
MUNGE_ENUM_MAC
Especifica enumeraciones para los tipos de MAC disponibles.
MUNGE_ENUM_ZIP
Especifica enumeraciones para los tipos de compresión disponibles.

ERRORES

Consulte munge(3) para obtener una lista completa de errores.

EJEMPLO

El siguiente programa de ejemplo ilustra cómo se puede consultar una lista de tipos de cifrado disponibles.

#include <stdio.h>
#include <stdlib.h>
#include <munge.h>

int
main (int argc, char *argv[])
{
    int i;
    const char *p;
    munge_enum_t t = MUNGE_ENUM_CIPHER;
    for (i = 0; (p = munge_enum_int_to_str (t, i)) != NULL; i++) {
        if (munge_enum_is_valid (t, i)) {
            printf ("%2d = %s\n", i, p);
        }
    }
    exit (EXIT_SUCCESS);
}
