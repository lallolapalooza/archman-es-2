MULTIMON-NG(1) Manual de Comandos Generales MULTIMON-NG(1)

NOMBRE

multimon-ng - programa para decodificar transmisiones de radio

SINOPSIS

multimon-ng [opciones] [archivo_entrada]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando multimon-ng. Esta página del manual fue escrita para Debian porque el programa original no tiene una página del manual.

El software multimon-ng puede decodificar una variedad de modos de transmisión digital comúnmente encontrados en radio VHF/UHF. Se utiliza una tarjeta de sonido de PC estándar para adquirir la señal de un transceptor. La decodificación se realiza completamente en software. Actualmente, se admiten los siguientes modos:

•
AX.25
  • 1200 Baudios AFSK
  • 2400 Baudios AFSK (2 variantes)
  • 4800 Baudios HAPN
  • 9600 Baudios FSK (G3RUH)
•
POCSAG
  • 512 Baudios
  • 1200 Baudios
  • 2400 Baudios
•
Llamada selectiva
  • CCIR
  • EEA
  • EIA
•
Modulación por desplazamiento de frecuencia (FSK)
  • 1200 Baudios FSK (2200/1200 Hz)
  • 1200 Baudios FSK (2300/1100 Hz)
  • 1200 Baudios FMS FSK
•
Varios
  • DTMF
  • CW/Morse
  • EAS
  • FLEX
  • SCOPE
  • X10
  • ZVEI

Se puede ejecutar un conjunto arbitrario de los modos anteriores concurrentemente en la misma señal de entrada (siempre que la potencia de la CPU sea suficiente), por lo que no tiene que saber de antemano qué modo se utiliza. Tenga en cuenta, sin embargo, que algunos modos podrían requerir modificaciones en la radio (especialmente los modos FSK de 9600 baudios y POCSAG) para funcionar correctamente.

AX.25 - Formato de datagramas del protocolo Amateur Packet Radio.
DTMF - Dual Tone Multi Frequency. Comúnmente utilizado en la marcación telefónica en banda.
EAS - Emergency Alert System.
FLEX - un formato de buscapersonas.
POCSAG (Post Office Code Standards Advisory Group) es un formato común de transmisión de buscapersonas.
SCOPE - muestra muestras en una visualización rudimentaria de osciloscopio en un servidor X.
X10 - un protocolo de automatización del hogar.
ZVEI - La Asociación Alemana de Fabricantes de Electricidad y Electrónica (Zentralverband Elektrotechnik und Elektronikindustrie) - formato de tono de buscapersonas.

OPCIONES

-t <tipo>
Tipo de archivo de entrada (cualquier tipo que no sea raw requiere sox). Tipos permitidos: raw aiff au hcom sf voc cdr dat smp wav maud vwe.
-a <demod>
Añadir demodulador (ver abajo).
-s <demod>
Restar demodulador.
-c
Eliminar todos los demoduladores (deben añadirse con -a <demod>).
-q
Mensajes de salida silenciosos.
-v <num>
Nivel de verbosidad (0-10). Para POCSAG y MORSE_CW '-v1' imprime estadísticas de decodificación.
-h
Imprimir la ayuda.
-A
Modo APRS (salida de texto TNC2).
-m
Silenciar advertencias de SoX.
-m
Llamar a SoX en modo repetible (por ejemplo, semilla aleatoria fija para dithering).
-n
No vaciar stdout, aumenta el rendimiento.
-j
FMS: Solo salida de datos hexadecimales y CRC, sin análisis.
-e
POCSAG: Ocultar mensajes vacíos.
-u
POCSAG: Eliminar heurísticamente decodificaciones improbables.
-i
POCSAG: Invierte las muestras de entrada. Pruébalo si la decodificación falla.
-p
POCSAG: Mostrar mensajes parcialmente recibidos.
-f <modo>
POCSAG: Deshabilita la autodetección y fuerza la decodificación de los datos como <modo> (<modo> puede ser 'numeric', 'alpha', 'skyper' y 'auto')
-b <nivel>
POCSAG: Nivel de corrección de errores de bit BCH. Establecer 0 para desactivar, el valor predeterminado es 2. Niveles más bajos aumentan el rendimiento y reducen los falsos positivos.
-C <cs>
POCSAG: Establecer conjunto de caracteres (predeterminado: US), donde <cs> es uno de: US, FR, DE, SE, SI
-o <tiempo>
CW: Establecer umbral para la detección de dit (predeterminado: 500)
-d <tiempo>
CW: Duración del dit en ms (predeterminado: 50)
-g <tiempo>
CW: Duración del espacio en ms (predeterminado: 50)
-x
CW: Desactivar la detección automática de umbral
-y
CW: Desactivar la detección automática de tiempo
--timestamp
Añadir una marca de tiempo al principio de cada línea impresa
--label <etiqueta>
Añadir una etiqueta al principio de cada línea impresa

Donde <demod> es uno de: POCSAG512 POCSAG1200 POCSAG2400 FLEX EAS UFSK1200 CLIPFSK FMSFSK AFSK1200 AFSK2400 AFSK2400_2 AFSK2400_3 HAPN4800 FSK9600 DTMF ZVEI1 ZVEI2 ZVEI3 DZVEI PZVEI EEA EIA CCIR MORSE_CW DUMPCSV X10 SCOPE
Las opciones -a y -s se pueden dar varias veces para especificar la lista deseada de demoduladores.

EJEMPLO

Decodificar modulaciones de señal de un archivo de sonido /tmp/message.wav sin usar una pantalla SCOPE:
multimon-ng -s SCOPE -t wav /tmp/message.wav

Si no se especifica ningún archivo de entrada, el programa escucha directamente a la tarjeta de sonido usando PulseAudio. Por lo tanto, para decodificar (solo) tonos DTMF en la entrada de la tarjeta de sonido:
multimon-ng -a DTMF

AVISO

Tenga en cuenta que la monitorización de servicios comerciales puede estar prohibida en algunos países, por lo que este software solo debe utilizarse para monitorizar el servicio de radioaficionado.

ERRORES

Los decodificadores DTMF y ZVEI tienen informes de detección espúrea más frecuentes.
