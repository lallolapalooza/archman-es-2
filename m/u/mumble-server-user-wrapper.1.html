NOMBRE

mumble-server-user-wrapper - Script de envoltura de usuario para mumble-server.

SINOPSIS

mumble-server-user-wrapper [opciones]

DESCRIPCIÓN

mumble-server es el componente de servidor de Mumble, una aplicación VoIP de baja latencia y alta calidad. mumble-server-wrapper es un script de envoltura para facilitar que los usuarios normales configuren su propio servidor privado de Mumble.

OPCIONES

-d "directorio"
Establece el directorio a usar. Por defecto, el script de envoltura usa $HOME/murmur
-s
Comprueba si el proceso mumble-server está en ejecución.
-k
Termina el proceso mumble-server en ejecución.
-i
Solo inicializa, no inicia el servidor.
-p "contraseña"
Especifica la contraseña para la cuenta SuperUser y sale. SuperUser es el equivalente de root en mumble, un usuario especial que elude todas las restricciones de acceso.

NOTAS

Para crear tu propio servidor privado, primero querrás ejecutar

mumble-server-user-wrapper -i

Luego edita ~/murmur/murmur.ini para establecer los diversos ajustes de configuración. Lo más importante es probablemente el puerto; a menos que seas el único proceso mumble-server que se ejecuta en este servidor, necesitarás cambiarlo.

Cuando estés satisfecho con tus configuraciones, necesitas establecer la contraseña para SuperUser, que es tu cuenta de administrador.

mumble-server-user-wrapper -p <contraseña>

Una vez hecho esto, simplemente ejecuta

mumble-server-user-wrapper

para iniciar el servidor.

VER TAMBIÉN

mumble-server(1).
