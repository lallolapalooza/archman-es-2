pskc_get_key_profileid(3) libpskc pskc_get_key_profileid(3)

NOMBRE

pskc_get_key_profileid - Función API

SINOPSIS

#include <pskc.h>

const char * pskc_get_key_profileid(pskc_key_t * key);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().

DESCRIPCIÓN

Obtiene el valor PSKC KeyPackage Key KeyProfileId.

DEVOLUCIONES

una cadena constante (no debe ser liberada) que contiene el contenido, o NULL si no está establecido.
