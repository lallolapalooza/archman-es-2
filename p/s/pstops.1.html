PSTOPS(1) Comandos de usuario PSTOPS(1)

NOMBRE

pstops

SINOPSIS

pstops [OPCIÓN...] [ARCHIVO_ENTRADA [ARCHIVO_SALIDA]]

DESCRIPCIÓN

Reorganiza páginas de un documento PDF o PostScript. Los archivos PostScript deben seguir las Convenciones de Estructura de Documentos de Adobe.

Pstops se puede usar para realizar reorganizaciones arbitrarias de documentos. Para muchas tareas, es más sencillo usar las otras utilidades del conjunto PSUtils: véase psutils(1).

ARCHIVO_ENTRADA
`-' o sin argumento ARCHIVO_ENTRADA significa entrada estándar
ARCHIVO_SALIDA
`-' o sin argumento ARCHIVO_SALIDA significa salida estándar

OPCIONES

-S ESPEC, --specs ESPEC
especificaciones de página (ver más abajo)
-R RANGO_PAGINAS, --pages RANGO_PAGINAS
seleccionar los rangos de páginas dados
-e, --even
seleccionar páginas de salida pares
-o, --odd
seleccionar páginas de salida impares
-r, --reverse
invertir el orden de las páginas de salida
-p PAPEL, --paper PAPEL
nombre del papel de salida o dimensiones (ANCHOxALTO)
-P PAPEL_ENTRADA, --inpaper PAPEL_ENTRADA
nombre del papel de entrada o dimensiones (ANCHOxALTO)
-d [DIMENSION], --draw [DIMENSION]
dibujar una línea del ancho dado (relativo a la página original) alrededor de cada página [el argumento tiene un valor predeterminado de 1pt; el predeterminado es sin línea; el ancho es fijo para PDF]
-v, --version
mostrar el número de versión del programa y salir
-q, --quiet
no mostrar progreso

COMENTARIOS

PÁGINAS es una lista separada por comas de páginas y rangos de páginas.

ESPEC es una lista de especificaciones de página [el valor predeterminado es "0", que selecciona cada página en su orden normal].

Las especificaciones de página tienen la siguiente sintaxis:

especificaciones_de_pagina
= [modulo:]espec
espec
= pag_num[transformaciones...][@escala][(desfase_x,desfase_y)]
especificacion
= [-]num_pagina[transformacion...][@escala][(desfase_x,desfase_y)]
transformacion
= L|R|U|H|V

modulo es el número de páginas en cada bloque. El valor de modulo debe ser mayor que 0; el valor predeterminado es 1.

espec son las especificaciones de página para las páginas de cada bloque. El valor de num_pagina en cada especificacion debe estar entre 0 (para la primera página del bloque) y modulo-1 (para la última página de cada bloque) inclusive. Si solo hay una especificación de página, se puede omitir num_pagina (0).

Las dimensiones opcionales desfase_x y desfase_y desplazan la página la cantidad especificada. desfase_x y desfase_y pueden ser longitudes (ver psutils(1)) o seguidas por w o h para indicar un múltiplo del ancho o alto de la página de salida.

Las transformaciones opcionales L, R, U, H y V rotan la página a la izquierda, a la derecha o boca abajo alrededor de su esquina inferior izquierda, y voltean (reflejan) la página horizontal o verticalmente respectivamente. El parámetro opcional escala escala la página por el factor especificado. Si se especifica el signo menos opcional, el número de página es relativo al final del documento, en lugar del principio.

Las páginas cuyas especs están separadas por + se fusionarán en una sola página; de lo contrario, permanecerán como páginas separadas.

El desplazamiento, la rotación y el escalado se aplican a la matriz de transformación PostScript en ese orden, independientemente del orden en que aparezcan en la línea de comandos.

Los nombres de tamaño de papel se convierten a dimensiones utilizando paper(1). El tamaño de página de salida, si se establece, se utiliza (después del escalado) para establecer la ruta de recorte para cada página.

EJEMPLOS

Para colocar dos páginas de la serie A o B (por ejemplo, A4 o B5) en una hoja de papel, la especificación de página a usar es:


2:0L@.7(1w,0)+1L@.7(1w,0.5h)


Para seleccionar todas las páginas impares en orden inverso, use:


2:-0


Para reorganizar páginas para imprimir folletos de 2 páginas, use


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h)


para las caras delanteras, y


4:1L@.7(1w,0h)+-2L@.7(1w,0.5h)


para las caras inversas, o, para impresión dúplex de borde largo, una las dos especificaciones así:


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h),1L@.7(1w,0h)+-2L@.7(1w,0.5h)


Para dúplex de borde corto, la invocación es:


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h),1R@.7(0w,0.5h)+-2R@.7(0w,1h)
