pscp(1) Suite de herramientas PuTTY pscp(1)

NOMBRE

pscp - cliente de línea de comandos SCP (copia segura) / SFTP

SINOPSIS

pscp [opciones] [usuario@]host:fuente destino
pscp [opciones] fuente [fuente...] [usuario@]host:destino
pscp [opciones] -ls [usuario@]host:especificacion_archivo

DESCRIPCIÓN

pscp es un cliente de línea de comandos para los protocolos SCP (copia segura) y SFTP (protocolo seguro de transferencia de archivos) basados en SSH.

OPCIONES

Las opciones de línea de comandos soportadas por pscp son:

-V
Muestra la información de la versión y sale.
-pgpfp
Muestra las huellas digitales de las Claves Maestras PGP de PuTTY y sale, para ayudar a verificar nuevos archivos publicados por el equipo de PuTTY.
-ls
Listado de directorios remotos.
-p
Preserva los atributos del archivo.
-q
Silencioso, no muestra estadísticas.
-r
Copia directorios recursivamente.
-unsafe
Permite comodines del lado del servidor (PELIGROSO).
-v
Muestra mensajes detallados.
-load sesion
Carga la configuración desde una sesión guardada.
-P puerto
Conecta al puerto puerto.
-proxycmd comando
En lugar de realizar una conexión TCP, utiliza comando como proxy; el tráfico de red se redirigirá a la entrada y salida estándar de comando. comando debe ser una sola palabra, por lo que es probable que necesite ser citado por el shell.

Las cadenas especiales %host y %port en comando serán reemplazadas por el nombre de host y el número de puerto al que se desea conectar; para obtener un signo % literal, escriba %%.

También se admiten escapes de barra invertida, como secuencias como \n que se reemplazan por una nueva línea literal; para obtener una barra invertida literal, escriba \\. (Puede ser necesario un escapado adicional por parte del shell).

(Consulte el manual principal de PuTTY para obtener detalles completos de los tokens admitidos delimitados por % y barra invertida, aunque la mayoría de ellos probablemente no sean muy útiles en este contexto.)

-l usuario
Establece el nombre de usuario remoto a usuario.
-batch
Deshabilita las indicaciones interactivas.
-no-sanitise-stderr
Por defecto, PSCP filtrará caracteres de control del canal de error estándar del servidor, para evitar que procesos remotos envíen secuencias de escape confusas. Esta opción fuerza a que el canal de error estándar no sea filtrado.
-pwfile nombre_archivo
Abre el archivo especificado y utiliza la primera línea de texto leída de él como contraseña remota.
-pw contraseña
Establece la contraseña remota a contraseña. ¡ADVERTENCIA!: esto probablemente hará que la contraseña sea visible para otros usuarios de la máquina local (a través de comandos como `ps' o `w'). Utilice -pwfile en su lugar.
-1
Forzar el uso del protocolo SSH versión 1.
-2
Forzar el uso del protocolo SSH versión 2.
-ssh-connection
Forzar el uso del protocolo `bare ssh-connection'. Esto solo es probablemente útil cuando se conecta a un servidor psusan(1), muy probablemente con una ruta absoluta a un socket de dominio Unix en lugar de host.
-ssh
Forzar el uso del protocolo SSH. (Esto normalmente no es necesario; solo es probable que sea útil si necesita anular alguna otra configuración del protocolo `bare ssh-connection').
-4, -6
Forzar el uso de IPv4 o IPv6 para las conexiones de red.
-C
Habilitar la compresión SSH.
-i archivo_clave
Archivo de clave privada para autenticación de usuario. Para claves SSH-2, este archivo de clave debe estar en formato PPK de PuTTY, no en formato OpenSSH ni en ningún otro.

Si está utilizando un agente de autenticación, también puede especificar una clave pública aquí (en formato RFC 4716 o OpenSSH), para identificar cuál de las claves del agente utilizar.

-noagent
No intente usar un agente de autenticación.
-agent
Permitir el uso de un agente de autenticación. (Esta opción solo es necesaria para anular una configuración en una sesión guardada.)
-no-trivial-auth
Desconéctese de cualquier servidor SSH que acepte autenticación sin haber solicitado nunca ningún tipo de contraseña, firma o token. (Podría querer habilitar esto para un servidor que siempre espera desafiarlo, por ejemplo, para asegurarse de no escribir accidentalmente la contraseña de su archivo de clave en un servidor comprometido que suplanta el aviso de contraseña de PSCP.)
-hostkey clave
Especifique una clave pública de host aceptable. Esta opción puede especificarse varias veces; cada clave puede ser una huella digital (SHA256:AbCdE..., 99:aa:bb:..., etc.) o un blob codificado en base64 en el formato de una línea de OpenSSH.

Especificar esta opción anula la gestión automática de claves de host; solo se aceptarán las claves especificadas en la línea de comandos (a menos que una sesión guardada también anule las claves de host, en cuyo caso esas se añadirán), y la caché de claves de host no se escribirá.

-scp
Forzar el uso del protocolo SCP.
-sftp
Forzar el uso del protocolo SFTP.
-sshlog archivo_log
-sshrawlog archivo_log
Estas opciones hacen que pscp registre los detalles del protocolo en un archivo. (Algunos de estos pueden ser sensibles, aunque por defecto se hace un esfuerzo por suprimir contraseñas obvias.)

-sshlog registra paquetes SSH decodificados y otros eventos (aquellos que -v imprimiría). -sshrawlog registra adicionalmente los datos brutos de paquetes cifrados.

-logoverwrite
Si PSCP está configurado para escribir en un archivo de registro que ya existe, descarta el archivo existente.
-logappend
Si PSCP está configurado para escribir en un archivo de registro que ya existe, añade los nuevos datos de registro al archivo existente.
