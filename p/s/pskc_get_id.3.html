pskc_get_id(3) libpskc pskc_get_id(3)

NOMBRE

pskc_get_id - función de API

SINOPSIS

#include <pskc.h>

const char * pskc_get_id(pskc_t * container);

ARGUMENTOS

pskc_t * container
un manejador pskc_t, de pskc_init().

DESCRIPCIÓN

Obtiene el atributo Id del Contenedor de Clave PSKC.

RETORNA

una cadena constante (no debe ser liberada) que contiene el contenido, o NULL si no está establecida.

REPORTAR ERRORES
