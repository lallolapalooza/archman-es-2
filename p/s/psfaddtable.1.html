PSFADDTABLE(1) Manual de Comandos Generales PSFADDTABLE(1)

NOMBRE

psfaddtable - añade una tabla de caracteres Unicode a una fuente de consola

SINOPSIS

psfaddtable archivofuente archivotabla archivosalida

DESCRIPCIÓN

psfaddtable toma una fuente de consola en formato .psf proporcionada por archivofuente y la fusiona con la tabla de caracteres Unicode proporcionada por archivotabla para producir un archivo de fuente con una tabla de caracteres incrustada, que se escribe en archivosalida. Un nombre de archivo de entrada de "-" denota la entrada estándar, y un nombre de archivo de salida de "-" denota la salida estándar. Si el archivofuente ya contiene una tabla de caracteres incrustada, esta se ignora.

FORMATO DEL ARCHIVO DE TABLA

Cada línea en el archivotabla debe estar en blanco, contener un comentario (precedido por #), o contener una secuencia de números en formato decimal (predeterminado), octal (precedido por 0), o hexadecimal (precedido por 0x), separados por espacios o tabulaciones. El primer número en cada línea indica la ranura de glifo en la fuente a la que se hace referencia, esta está entre 0 y 0xff para una fuente de 256 caracteres y entre 0 y 0x1ff para una fuente de 512 caracteres. Cualquier número subsiguiente en la misma línea son Unicodes correspondientes a esta ranura de glifo específica. En lugar de un solo Unicode, se puede tener una secuencia de Unicodes separados por comas, para indicar que el glifo representa el símbolo compuesto correspondiente. Está permitido tener múltiples líneas para el mismo glifo.

VER TAMBIÉN
