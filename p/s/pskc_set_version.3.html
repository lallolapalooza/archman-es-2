pskc_set_version(3) libpskc pskc_set_version(3)

NOMBRE

pskc_set_version - función de API

SINOPSIS

#include <pskc.h>

void pskc_set_version(pskc_t * container, const char * version);

ARGUMENTOS

pskc_t * container
un manejador pskc_t, de pskc_init().
const char * version
puntero a la cadena de versión a establecer.

DESCRIPCIÓN

Establece el atributo Versión de PSKC KeyContainer. Normalmente, esta cadena siempre es "1.0" y un campo faltante es un error de sintaxis según el esquema PSKC.

El puntero se almacena en container, no una copia de los datos, por lo que no debe liberar los datos antes de otra llamada a esta función o la última llamada a cualquier función que utilice container.
