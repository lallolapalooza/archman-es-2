PS2PK(1) Manual de Comandos Generales PS2PK(1)

NOMBRE

ps2pk - crea un archivo pkfont TeX a partir de una fuente PostScript tipo 1

SINOPSIS

ps2pk [ -v ] [ -ecodificación ] [ -XresoluciónX ] [ -Eexpansión ] [ -Sinclinación ] [ -PtamañoPunto ] [ -RresoluciónBase ] [ -rrelaciónAspecto ] [ -YresoluciónY ] [ -aarchivoAFM ] [ -mmodo ] tipo1 [archivoPk]

DESCRIPCIÓN

Este programa procesa una fuente PostScript tipo 1 dada a un tamaño de punto (por defecto 10.0 puntos) y una resolución (por defecto 300 dpi) para crear un archivo pkfont TeX.

Para generar el archivo pkfont, ps2pk necesita un archivo de fuente tipo 1 válido (por ejemplo, Utopia-Regular, Utopia-Regula.pfb o Utopia-Regula.pfa) y su archivo AFM correspondiente (Utopia-Regular.afm) con las métricas de la fuente. El programa acepta tanto el formato binario tipo 1 (Utopia-Regula.pfb) como su equivalente en ASCII (Utopia-Regular o Utopia-Regula.pfa). Para localizar los archivos, ps2pk utiliza la biblioteca kpathsea (ver la página de información sobre kpathsea). Adicionalmente, los archivos pfb y pfa se buscan en el directorio especificado en la variable de entorno T1INPUTS, y los archivos afm se buscan en AFMFONTS, si están definidos (la opción -v informará sobre los nombres de archivo que se buscan).

El programa creará un archivo pkfont en el que los códigos de carácter se derivarán de sus valores definidos en AFM (Adobe Font Metrics). Esto puede ser anulado especificando un archivo de codificación explícito mediante la opción -e. El archivo de codificación codificación debe contener una codificación PostScript válida que contenga nombres PostScript como /hyphen. Aquí hay un ejemplo incompleto (ver afm2tfm para la sintaxis completa):

% Esta es la codificación EC.
/ECEncoding [          % ahora siguen 256 caracteres
% 0x00
  /grave /acute /circumflex /tilde /dieresis /hungarumlaut
  /ring /caron /breve /macron /dotaccent /cedilla
  /ogonek /quotesinglbase /guilsinglleft /guilsinglright
  (Resto de líneas omitidas.)
% 0xF0
  /eth /ntilde /ograve /oacute /ocircumflex /otilde
  /odieresis /oe /oslash /ugrave /uacute /ucircumflex
  /udieresis /yacute /thorn /germandbls ] def

Opciones y argumentos:

-aarchivoAFM
Anula el nombre que se utiliza para localizar el archivo AFM.
-ecodificación
Nombre de un archivo que contiene un esquema de codificación (por defecto, se utiliza la codificación nombrada en el archivo AFM). El nombre PostScript real del esquema de codificación se escribe como un "especial" al final del archivo pkfont.
-Eexpansión
El factor de expansión (valor real, por defecto 1.0).
-mmodo
Un nombre de modo como el que usaría METAFONT (por defecto "Unknown mode").
-PtamañoPunto
El tamaño de punto deseado (valor real, por defecto 10.0 puntos).
-RresoluciónBase
La resolución base deseada (valor entero, por defecto 300 dpi). Si esto difiere del valor de resoluciónX, se mostrará la magnificación apropiada en los "especiales" al final del archivo pkfont. Si es posible, se expresará como un magstep, de lo contrario como un número real. Por ejemplo, un archivo pkfont con una resoluciónX de 329, utilizando la resolución base predeterminada de 300, incluirá el texto "especial" "mag=magstep(0.5)" al final de la fuente.
-rrelaciónAspecto
La relación de aspecto deseada (expresión, enteroY/enteroX, por defecto 300/300). Esto se mostrará en los "especiales" al final del archivo pkfont. Establecer la relación de aspecto crea un valor para resoluciónY, pero un valor explícito de resoluciónY tendrá prioridad. El argumento debe ir entre comillas dobles si hay espacios alrededor de '/'.
-Sinclinación
La inclinación (valor real, por defecto 0.0).
-XresoluciónX
La resolución en la dirección X (valor entero, por defecto 300 dpi).
-YresoluciónY
La resolución en la dirección Y (valor entero, por defecto el valor de resoluciónX). Si resoluciónY difiere de resoluciónX, se escribirá un texto "especial" que indica la relación de aspecto al final del archivo pkfont.
-v
Opción detallada. (Indica lo que está haciendo el programa).
tipo1
El nombre de la fuente PostScript tipo 1. El nombre del archivo AFM se construirá a partir de este nombre eliminando la extensión (si se proporciona) y añadiendo ".afm". El "FontName" de PostScript se extrae del archivo AFM y se escribe en un "especial" al final del archivo pkfont.
[archivoPk]
El nombre del archivo pkfont resultante puede ser anulado con este nombre. El nombre por defecto del archivo pkfont se deriva del nombre base de la fuente tipo 1, el tamaño de punto y la resoluciónX. Por ejemplo, `ps2pk -P17.28 Utopia-Regular' resultará en `Utopia-Regular17.300pk'. Es necesario un valor explícito para el nombre del archivo pkfont cuando el nombre de la fuente tipo 1 ya muestra el tamaño del punto, de lo contrario, el valor de tamañoPunto se concatena al nombre base del archivo pkfont, lo cual generalmente no es lo deseado.

Los siguientes "especiales" de PK proporcionan una verificación interna de las características del archivo pkfont, de acuerdo con las recomendaciones del Grupo de Trabajo de TeX sobre el Estándar de Directorio TeX (TWG-TDS):
"fontid=NombreFuente", "codingscheme=Codificación", "fontfacebyte", "mag", "mode=(ps2pk)modo", "pixels-per-inch", y "aspect-ratio" si es distinto de la unidad.
