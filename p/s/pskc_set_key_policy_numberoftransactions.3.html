pskc_set_key_policy_numberoftransactions(3) libpskc pskc_set_key_policy_numberoftransactions(3)

NOMBRE

pskc_set_key_policy_numberoftransactions - función de la API

SINOPSIS

#include <pskc.h>

void pskc_set_key_policy_numberoftransactions(pskc_key_t * key, uint64_t uses);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, obtenido de pskc_get_keypackage().
uint64_t uses
el número de transacciones a establecer.

DESCRIPCIÓN

Establece el valor NumberOfTransactions de la Política de Clave del Paquete de Clave PSKC. El valor en este elemento indica el número máximo de veces que una clave contenida en el documento PSKC puede ser utilizada por una aplicación después de haberla recibido. Cuando este elemento se omite, no hay restricción en cuanto al número de veces que se puede usar una clave.

Tenga en cuenta que, si bien la especificación PSKC utiliza el tipo de datos XML "nonNegativeInteger" para esta variable, esta implementación restringe el tamaño del valor a enteros de 64 bits.
