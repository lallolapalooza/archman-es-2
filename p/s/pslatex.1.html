pslatex(1) Manual de Comandos Generales pslatex(1)

NOMBRE

pslatex - utilidad para componer archivos LaTeX usando fuentes PostScript

SINOPSIS

pslatex [ARGUMENTOS_LATEX] ARCHIVO_LATEX[.tex]

DESCRIPCIÓN

pslatex permite componer un archivo fuente de LaTeX usando fuentes básicas PostScript de Adobe Type 1 (Times, Helvetica y Courier) sin editar el archivo para cargar los paquetes necesarios.

Acepta cualquier argumento que latex(1) pueda aceptar.

OPCIONES

Ninguna.

ARCHIVOS

Muchos. Ver el archivo readme de pslatex.sty.

VER TAMBIÉN

latex(1), TEXMF/latex/pslatex/00readme.txt
