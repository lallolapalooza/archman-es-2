PSTREE(1) Comandos de Usuario PSTREE(1)

NOMBRE

pstree - mostrar un árbol de procesos

SINOPSIS

pstree [-a, --argumentos] [-c, --compactar-no] [-C, --color attr] [-g, --mostrar-pgids] [-h, --resaltar-todo, -H pid, --resaltar-pid pid] [-l, --largo] [-n, --orden-numerico] [-N, --ns-orden ns] [-p, --mostrar-pids] [-s, --mostrar-padres] [-S, --cambios-ns] [-t, --nombres-hilo] [-T, --ocultar-hilos] [-u, --cambios-uid] [-Z, --contexto-seguridad] [-A, --ascii, -G, --vt100, -U, --unicode] [pid, usuario]
pstree -V, --version

DESCRIPCIÓN

pstree muestra los procesos en ejecución como un árbol. El árbol se enraíza en pid o en init si se omite pid. Si se especifica un nombre de usuario, se muestran todos los árboles de procesos enraizados en procesos propiedad de ese usuario.

pstree fusiona visualmente ramas idénticas poniéndolas entre corchetes y prefijándolas con el recuento de repeticiones, por ejemplo:

    init-+-getty
         |-getty
         |-getty
         `-getty
se convierte en 
    init---4*[getty]

Los hilos hijos de un proceso se encuentran debajo del proceso padre y se muestran con el nombre del proceso entre llaves, por ejemplo:

    icecast2---13*[{icecast2}]

Si pstree se llama como pstree.x11, pedirá al usuario que presione retorno al final de la línea y no regresará hasta que eso haya sucedido. Esto es útil cuando pstree se ejecuta en una terminal x.

Ciertos parámetros del kernel o de montaje, como la opción hidepid para procfs, ocultarán información de algunos procesos. En estas situaciones pstree intentará construir el árbol sin esta información, mostrando los nombres de los procesos como signos de interrogación.

OPCIONES

-a
Mostrar los argumentos de la línea de comandos. Si la línea de comandos de un proceso está desocupada (swapped out), ese proceso se muestra entre paréntesis. -a deshabilita implícitamente la compactación para procesos pero no para hilos.
-A
Usar caracteres ASCII para dibujar el árbol.
-c
Deshabilitar la compactación de subárboles idénticos. Por defecto, los subárboles se compactan siempre que sea posible.
-C
Colorear el nombre del proceso según el atributo dado. Actualmente pstree solo acepta el valor age que colorea según la edad del proceso. Los procesos más nuevos de 60 segundos son verdes, más nuevos de una hora amarillos y los restantes rojos.
-g
Mostrar PGIDs. Los IDs de Grupo de Procesos se muestran como números decimales entre paréntesis después de cada nombre de proceso. Si se muestran tanto PIDs como PGIDs, los PIDs se muestran primero.
-G
Usar caracteres de dibujo de línea VT100.
-h
Resaltar el proceso actual y sus ancestros. Esto no tiene efecto si la terminal no soporta el resaltado o si ni el proceso actual ni ninguno de sus ancestros están en el subárbol que se está mostrando.
-H
Similar a -h, pero resaltar el proceso especificado en su lugar. A diferencia de con -h, pstree falla al usar -H si el resaltado no está disponible.
-l
Mostrar líneas largas. Por defecto, las líneas se truncan a la variable de entorno COLUMNS o al ancho de la pantalla. Si ninguno de estos métodos funciona, se utiliza el valor predeterminado de 132 columnas.
-n
Ordenar los procesos con el mismo padre por PID en lugar de por nombre. (Orden numérico.)
-N
Mostrar árboles individuales para cada espacio de nombres del tipo especificado. Los tipos disponibles son: ipc, mnt, net, pid, time, user, uts. Los usuarios normales no tienen acceso a la información de procesos de otros usuarios, por lo que la salida será limitada.
-p
Mostrar PIDs. Los PIDs se muestran como números decimales entre paréntesis después de cada nombre de proceso. -p deshabilita implícitamente la compactación.
-s
Mostrar procesos padres del proceso especificado.
-S
Mostrar transiciones de espacios de nombres. Al igual que con -N, la salida se limita cuando se ejecuta como un usuario normal.
-t
Mostrar nombres completos para hilos cuando estén disponibles.
-T
Ocultar hilos y solo mostrar procesos.
-u
Mostrar transiciones de uid. Siempre que la uid de un proceso difiera de la uid de su padre, la nueva uid se muestra entre paréntesis después del nombre del proceso.
-U
Usar caracteres de dibujo de línea UTF-8 (Unicode). En Linux 1.1-54 y posteriores, el modo UTF-8 se entra en la consola con echo -e ' 33%8' y se sale con echo -e ' 33%@'.
-V
Mostrar información de la versión.
-Z
Mostrar los atributos de seguridad actuales del proceso. Para sistemas SELinux, este será el contexto de seguridad.

FICHEROS

/proc
ubicación del sistema de archivos proc

ERRORES

Algunos conjuntos de caracteres pueden ser incompatibles con los caracteres VT100.

VER TAMBIÉN

ps(1), top(1), proc(5).

pstree(1)

NOMBRE

pstree - muestra los procesos en forma de árbol

SINOPSIS

pstree [-a] [-c] [-d max-depth] [-d max-depth] [-G] [-H pid] [-l] [-n] [-p] [-s] [-u] [-U] [pid|user]

DESCRIPCIÓN

pstree muestra los procesos en forma de árbol. Por defecto, imprime los procesos de la raíz del árbol. Imprime el nombre del comando en lugar de su PID.

También puede mostrar los árboles de procesos para un PID específico o para todos los procesos de un usuario específico.

OPCIONES

-a
Muestra los argumentos de la línea de comandos de los procesos.
-c
No comprime las ramas de árboles idénticas.
-d max-depth
Profundidad máxima del árbol a mostrar.
-G
Usa caracteres gráficos de línea para la salida.
-H pid
Establece el PID a ser la raíz del árbol.
-l
No acorta las líneas largas. Por defecto, las líneas se truncan en 80 caracteres.
-n
Ordena los hijos por PID en lugar de por orden de aparición.
-p
Muestra los PIDs de los procesos.
-s
Muestra la línea de comandos completa de cada proceso.
-u
Muestra el nombre de usuario de cada proceso.
-U
Usa caracteres Unicode para la salida.

EJEMPLOS

pstree: Muestra el árbol de procesos completo.

pstree -p: Muestra el árbol de procesos con PIDs.

pstree -a: Muestra el árbol de procesos con argumentos de línea de comandos.

pstree -u: Muestra el árbol de procesos con nombres de usuario.

pstree 1234: Muestra el árbol de procesos a partir del PID 1234.

pstree -p $(pidof systemd): Muestra el árbol de procesos a partir del PID de systemd.

VER TAMBIÉN

ps(1)
