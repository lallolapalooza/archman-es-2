PSENSOR-SERVER(1) Comandos de usuario PSENSOR-SERVER(1)

NOMBRE

psensor-server - Servidor Web de monitorización de temperatura y del sistema

SINOPSIS

psensor-server [OPCIÓN]...

DESCRIPCIÓN

psensor-server es un servidor HTTP para monitorizar sensores de hardware remotamente.

Proporciona un servicio Web JSON que puede ser utilizado por psensor(1) para monitorizar remotamente los sensores de hardware de un ordenador.

Puede proporcionar información sobre:
* la temperatura de los sensores de la placa base y de la CPU (usando lm-sensors).
* la temperatura de los discos duros (usando hddtemp).
* la velocidad de rotación de los ventiladores (usando lm-sensors).

También es posible conectarse a psensor-server con un navegador; una página Web simple muestra la información de los sensores y el uso de la CPU.

La URL http://hostname:3131/api/1.0/sensors/[id] devuelve un objeto JSON que contiene toda la información sobre un sensor. [id] es el identificador único del sensor.

Aquí hay un ejemplo del objeto JSON de tipo 'sensor':

{ "id": "lmsensor acpitz-virtual-0 temp1",
"name": "temp1",
"type": 257,
"min": 47.800000,
"max": 60.800000,
"measures": [ { "value": 47.800000, "time": 1311374873 },
{ "value": 49.800000, "time": 1311374878 },
{ "value": 49.800000, "time": 1311374883 } ],
"last_measure": { "value": 49.800000, "time": 1311374883 } }

Campos del tipo 'sensor':


* id: el identificador único del sensor.
* name: un nombre legible para humanos del sensor (puede no ser único).
* type: el tipo de sensor. Consulta src/lib/psensor.h para los
diferentes tipos.
* min: el valor mínimo del sensor.
* max: el valor máximo del sensor.
* measures: todas las mediciones del sensor.
* last_measure: el último valor del sensor.
* time: la hora de una medida como el número de segundos desde
1970/01/01.

La URL http://hostname:3131/api/1.0/sensors devuelve un array JSON que contiene todos los objetos JSON de tipo 'sensor'.

psensor-server puede detenerse enviando una solicitud HTTP con la URL 'http://hostname:port/api/1.0/server/stop'.

OPCIONES

-h, --help
muestra esta ayuda y sale
-v, --version
muestra la información de la versión y sale
-p,--port=PUERTO
puerto del servidor web
-w,--wdir=DIR
directorio que contiene las páginas del servidor web
-d, --debug=NIVEL
establece el nivel de depuración, un entero entre 0 y 3
-l, --log-file=RUTA
establece el archivo de registro a RUTA

--sensor-log-file=RUTA establece el archivo de registro de sensores a RUTA

--sensor-log-interval=S establece el intervalo de registro de sensores a S (segundos)

ARCHIVO DE REGISTRO DE SENSORES

Los sensores se pueden registrar usando la opción --sensor-log-file.

Utiliza un formato de texto, cada línea termina con un carácter de NUEVA LÍNEA.

La primera línea es: I,%D,%V

%D es la hora de inicio del registro expresada como el número de segundos desde EPOC.

%V es la versión de psensor-server.

Las líneas siguientes proporcionan la lista ordenada de sensores: S,%I,%T

%I es el identificador único del sensor.

%T es la representación hexadecimal del tipo de sensor.

Luego, se escriben los valores de todos los sensores: %D,%V...

%D es el número de segundos transcurridos desde la hora de inicio del registro.

%V... es la lista separada por comas de los valores actuales de todos los sensores. El orden es el mismo que el de la lista de identificadores de sensores.

El valor se expresa como un número flotante con una precisión de un dígito. Las temperaturas usan la unidad Celsius.

El valor solo se escribe si ha cambiado.

Ejemplo: I,1345974927,0.7.0.4 S,lmsensor coretemp-isa-0000 Physical id 0,101 S,lmsensor coretemp-isa-0000 Core 0,101 S,lmsensor coretemp-isa-0000 Core 1,101 0,37.0,37.0,36.0 5,36.0,,36.0

Cinco segundos después de que el registro se inicie, la temperatura del segundo sensor (Core 0) sigue siendo 37°C.

ADVERTENCIA

psensor-server no proporciona ninguna forma de restringir la conexión al servidor HTTP; peor aún, no se ha hecho ningún esfuerzo contra ataques HTTP maliciosos. Debes hacer que el puerto de psensor-server solo sea accesible desde una red o un ordenador en el que confíes, utilizando las herramientas de seguridad de red habituales del sistema (por ejemplo, iptables(8)).
