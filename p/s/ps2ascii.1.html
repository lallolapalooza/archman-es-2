NOMBRE

ps2ascii - Traductor de Ghostscript de PostScript o PDF a texto

SINOPSIS

ps2ascii [ entrada.ps [ salida.txt ] ]
ps2ascii entrada.pdf [ salida.txt ]

DESCRIPCIÓN

ps2ascii utiliza gs(1) para extraer texto de archivos PostScript(tm) o Portable Document Format (PDF) de Adobe. Si no se especifican archivos en la línea de comandos, gs lee de la entrada estándar. Si no se especifica archivo de salida, el texto ASCII se escribe en la salida estándar.

El antiguo programa ps2ascii.ps fue obsoleto y eliminado hace algunos años; los scripts ahora utilizan el dispositivo txtwrite para extraer texto de la entrada. Esto generalmente hace un mejor trabajo que el antiguo programa PostScript y puede extraer Unicode, no solo ASCII. Sin embargo, ya no soporta la característica COMPLEX.

VER TAMBIÉN

Se puede encontrar más documentación sobre el dispositivo txtwrite en https://ghostscript.readthedocs.io/en/latest/Devices.html#text-output

VERSIÓN

Este documento fue revisado por última vez para la versión de Ghostscript 10.04.0.
