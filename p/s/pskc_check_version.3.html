pskc_check_version(3) libpskc pskc_check_version(3)

NOMBRE

pskc_check_version - Función de API

SINOPSIS

#include <pskc.h>

const char * pskc_check_version(const char * req_version);

ARGUMENTOS

const char * req_version
cadena de versión a comparar, o NULL.

DESCRIPCIÓN

Comprueba la versión de la biblioteca PSKC.

Ver PSKC_VERSION para una cadena req_version adecuada.

Esta función es una de las pocas en la biblioteca que se puede usar sin una llamada exitosa a pskc_global_init().

VALOR DE RETORNO

Comprueba que la versión de la biblioteca sea como mínimo la dada como cadena en req_version y devuelve la cadena de versión real de la biblioteca; devuelve NULL si la condición no se cumple. Si se pasa NULL a esta función, no se realiza ninguna comprobación y solo se devuelve la cadena de versión.
