pskc_set_key_algparm_chall_max(3) libpskc pskc_set_key_algparm_chall_max(3)

NOMBRE

pskc_set_key_algparm_chall_max - función de API

SINOPSIS

#include <pskc.h>

void pskc_set_key_algparm_chall_max(pskc_key_t * key, uint32_t challmax);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
uint32_t challmax
la longitud máxima del desafío a establecer.

DESCRIPCIÓN

Establece el valor Máximo del Formato del Desafío de Parámetros del Algoritmo de Clave del Paquete de Clave PSKC (KeyPackage Key AlgorithmParameters ChallengeFormat Max). Este atributo define el tamaño máximo del desafío aceptado por el dispositivo para el modo CR y DEBE ser incluido. Si el atributo 'Encoding' está establecido a 'DECIMAL', 'HEXADECIMAL', o 'ALPHANUMERIC', este valor indica el número máximo de dígitos/caracteres. Si el atributo 'Encoding' está establecido a 'BASE64' o 'BINARY', este valor indica el número máximo de bytes del valor sin codificar.
