subrutina cpstrf (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( n ) piv, integer rank, real tol, real, dimension( 2*n ) work, integer info)

CPSTRF calcula la factorización de Cholesky con pivoteo completo de una matriz semidefinida positiva Hermitiana compleja A.

Propósito:

!>
!> CPSTRF calcula la factorización de Cholesky con pivoteo
!> completo de una matriz semidefinida positiva Hermitiana compleja A.
!>
!> La factorización tiene la forma
!>    P**T * A * P = U**H * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior, y
!> P se almacena como vector PIV.
!>
!> Este algoritmo no intenta comprobar si A es semidefinida positiva.
!> Esta versión del algoritmo llama a BLAS de nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz simétrica A se almacena.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz simétrica A. Si UPLO = 'U', la parte
!>          triangular superior de n por n de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la
!>          parte triangular inferior de n por n de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización
!>          de Cholesky como se describe arriba.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

PIV

!>          PIV es un array INTEGER, dimension (N)
!>          PIV es tal que las entradas distintas de cero son P( PIV(K), K ) = 1.
!>

RANK

!>          RANK es INTEGER
!>          El rango de A dado por el número de pasos completados por el
!>          algoritmo.
!>

TOL

!>          TOL es REAL
!>          Tolerancia definida por el usuario. Si TOL < 0, entonces se usará
!>          N*U*MAX( A(K,K) ). El algoritmo termina en el paso (K-1) si el
!>          pivote <= TOL.
!>

WORK

!>          WORK es un array REAL, dimension (2*N)
!>          Espacio de trabajo.
!>

INFO

!>          INFO es INTEGER
!>          < 0: Si INFO = -K, el K-ésimo argumento tenía un valor ilegal,
!>          = 0: el algoritmo se completó con éxito, y
!>          > 0: la matriz A es o bien de rango deficiente con rango calculado
!>               como el devuelto en RANK, o no es semidefinida positiva. Ver
!>               la Sección 7 de la Nota de Trabajo #161 de LAPACK para más
!>               información.
!>

LAPACK

Name

pstrf — computes the Cholesky factorization with complete pivoting of a real symmetric positive semidefinite matrix.

Synopsis

SUBROUTINE PSTRF(UPLO, N, A, LDA, PIV, RANK, TOL, WORK, INFO)
    CHARACTER(LEN=1)            UPLO
    INTEGER                     N
    REAL, DIMENSION(LDA, *)     A
    INTEGER                     LDA
    INTEGER, DIMENSION(*)       PIV
    INTEGER                     RANK
    REAL                        TOL
    REAL, DIMENSION(2*N)        WORK
    INTEGER                     INFO

Detailed Description

PSTRF computes the Cholesky factorization with complete pivoting of a real symmetric positive semidefinite matrix. The factorization has the form P**T * A * P = U**T * U , if UPLO = 'U', P**T * A * P = L * L**T, if UPLO = 'L', where U is an upper triangular matrix and L is lower triangular, and P is stored as vector PIV. This algorithm does not attempt to check that A is positive semidefinite. This version of the algorithm calls level 3 BLAS.

Parameters

UPLO CHARACTER(LEN=1) Specifies whether the upper or lower triangular part of the symmetric matrix A is stored. = 'U': Upper triangular = 'L': Lower triangular

N INTEGER The order of the matrix A. N >= 0.

A REAL, DIMENSION(LDA,*) On entry, the symmetric matrix A. If UPLO = 'U', the leading n by n upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If UPLO = 'L', the leading n by n lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced. On exit, if INFO = 0, the factor U or L from the Cholesky factorization as above.

LDA INTEGER The leading dimension of the array A. LDA >= max(1,N).

PIV INTEGER, DIMENSION(*) PIV is such that the nonzero entries are P( PIV(K), K ) = 1.

RANK INTEGER The rank of A given by the number of steps the algorithm completed.

TOL REAL User defined tolerance. If TOL < 0, then N*U*MAX( A(K,K) ) will be used. The algorithm terminates at the (K-1)st step if the pivot <= TOL.

WORK REAL, DIMENSION(2*N) Work space.

INFO INTEGER < 0: If INFO = -K, the K-th argument had an illegal value, = 0: algorithm completed successfully, and > 0: the matrix A is either rank deficient with computed rank as returned in RANK, or is not positive semidefinite. See Section 7 of LAPACK Working Note #161 for further information.
