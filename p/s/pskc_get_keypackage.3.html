NOMBRE

pskc_get_keypackage - función de API

SINOPSIS

#include <pskc.h>

pskc_key_t * pskc_get_keypackage(pskc_t * container, size_t i);

ARGUMENTOS

pskc_t * container
un manejador pskc_t, de pskc_init().
size_t i
número del paquete de claves a obtener.

DESCRIPCIÓN

Obtiene un manejador de paquete de claves PSKC pskc_key_t para el i-ésimo paquete de claves en container. i está basado en cero, es decir, 0 se refiere al primer paquete de claves, 1 se refiere al segundo paquete de claves, y así sucesivamente.

RETORNOS

NULL si no existe el i-ésimo paquete de claves, o un puntero válido pskc_key_t.

REPORTE DE ERRORES

Reporte errores a <oath-toolkit-help@nongnu.org>. Página principal de libpskc: https://oath-toolkit.codeberg.page/ Ayuda general para usar software GNU: http://www.gnu.org/gethelp/
