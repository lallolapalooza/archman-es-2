pskc_set_device_expirydate(3) libpskc pskc_set_device_expirydate(3)

NOMBRE

pskc_set_device_expirydate - función API

SINOPSIS

#include <pskc.h>

void pskc_set_device_expirydate(pskc_key_t * key, const struct tm * expirydate);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
const struct tm * expirydate
puntero a una estructura tm con la fecha de caducidad del dispositivo a establecer.

DESCRIPCIÓN

Establece la fecha de caducidad del dispositivo (ExpiryDate) del PSKC KeyPackage. Este elemento denota la fecha de fin de un dispositivo (como el de una tarjeta de pago, utilizado cuando los números de emisión no están impresos en las tarjetas).
