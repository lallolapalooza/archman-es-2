NOMBRE

pskc_get_cryptomodule_id - Función de la API

SINOPSIS

#include <pskc.h>

const char * pskc_get_cryptomodule_id(pskc_key_t * key);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().

DESCRIPCIÓN

Obtiene el valor del ID del Módulo Criptográfico del Paquete de Clave PSKC. Este elemento contiene un identificador único para el Módulo Criptográfico y es específico de la implementación. Como tal, ayuda a identificar un Módulo Criptográfico específico al que la clave se está aprovisionando o se aprovisionó.

VALOR DE RETORNO

una cadena constante (no debe ser liberada) que contiene el contenido, o NULL si no está establecido.
