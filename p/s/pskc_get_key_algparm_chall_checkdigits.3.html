NOMBRE

pskc_get_key_algparm_chall_checkdigits - Función de la API

SINOPSIS

#include <pskc.h>

int pskc_get_key_algparm_chall_checkdigits(pskc_key_t * key, int * present);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
int * present
variable de salida que indica si se proporcionaron datos o no.

DESCRIPCIÓN

Obtiene el valor PSKC KeyPackage Key AlgorithmParameters ChallengeFormat CheckDigits. Este atributo indica si un dispositivo necesita verificar el dígito de control Luhn añadido, tal como se define en [ISOIEC7812], contenido en un desafío. Esto solo es válido si el atributo 'Encoding' está establecido en 'DECIMAL'. Un valor de TRUE indica que el dispositivo verificará el dígito de control Luhn añadido en un desafío proporcionado. Un valor de FALSE indica que el dispositivo no verificará el dígito de control Luhn añadido en el desafío.

Si present no es NULL, será 0 si el campo no está presente o 1 si estaba presente.

RETORNA

1 para indicar un valor CheckDigits verdadero, o 0 para indicar falso.
