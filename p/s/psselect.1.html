PSSELECT(1) Comandos de usuario PSSELECT(1)

NOMBRE

psselect

SINOPSIS

psselect [OPCIÓN...] [PÁGINAS] [ARCHIVO_ENTRADA [ARCHIVO_SALIDA]]

DESCRIPCIÓN

psselect llama a pstops para hacer la reorganización. Selecciona páginas de un documento PDF o PostScript.

ARCHIVO_ENTRADA
`-' o ningún argumento ARCHIVO_ENTRADA significa entrada estándar
ARCHIVO_SALIDA
`-' o ningún argumento ARCHIVO_SALIDA significa salida estándar

OPCIONES

-R PÁGINAS, -p PÁGINAS, --pages PÁGINAS
selecciona los rangos de páginas dados
-e, --even
selecciona páginas de salida de número par
-o, --odd
selecciona páginas de salida de número impar
-r, --reverse
revierte el orden de las páginas de salida
-v, --version
muestra el número de versión del programa y sale
-q, --quiet
no muestra el progreso

COMENTARIOS

PÁGINAS es una lista separada por comas de páginas y rangos de páginas; consulta pstops(1) para más detalles.
