psktool(1) Comandos de usuario psktool(1)

NOMBRE

psktool - Herramienta PSK de GnuTLS

SINOPSIS

psktool [-flags] [-flag [valor]] [--option-name[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

Programa que genera claves aleatorias para su uso con TLS-PSK. Las claves se almacenan en formato hexadecimal en un archivo de claves.

OPCIONES

-d num, --debug=num

Habilita la depuración. Esta opción toma un número entero como argumento. El valor de num está restringido a estar: 
en el rango de 0 a 9999

Especifica el nivel de depuración.

-s num, --keysize=num

Especifica el tamaño de la clave en bytes (el valor predeterminado es de 32 bytes o 256 bits). Esta opción toma un número entero como argumento. El valor de num está restringido a estar: 
en el rango de 0 a 512

-u str, --username=str

Especifica el nombre de usuario a utilizar.
-p str, --pskfile=str

Especifica un archivo de clave precompartida.

Esta opción especificará el archivo de clave precompartida donde almacenar las claves generadas.

--passwd

Este es un alias para la opción --pskfile.

NOTA: ESTA OPCIÓN ESTÁ OBSOLETA

-v arg, --version=arg

Muestra la versión del programa y sale. El modo predeterminado es `v', una versión simple. El modo `c' mostrará información de derechos de autor y `n' mostrará el aviso de derechos de autor completo.
-h, --help

Muestra información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a través de un paginador.

EJEMPLOS

Para añadir un usuario 'psk_identity' en keys.psk para su uso con GnuTLS, ejecuta:



$ ./psktool -u psk_identity -p keys.psk
Generando una clave aleatoria para el usuario 'psk_identity'
Clave almacenada en keys.psk
$ cat keys.psk
psk_identity:88f3824b3e5659f52d00e959bacab954b6540344
$

Este comando creará keys.psk si no existe y añadirá el usuario 'psk_identity'.

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

La operación falló o la sintaxis del comando no fue válida.
