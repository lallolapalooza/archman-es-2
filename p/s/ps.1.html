PS(1) Manual de Comandos Generales PS(1)

NOMBRE

ps - reportar una instantánea de los procesos actuales.

SINOPSIS

ps [opción ...]

DESCRIPCIÓN

ps muestra información sobre una selección de los procesos activos. Si desea una actualización repetitiva de la selección y de la información mostrada, use top en su lugar.

Esta versión de ps acepta varios tipos de opciones.

•
Opciones de Unix, que pueden agruparse y deben precederse de un guion.
•
Opciones de BSD, que pueden agruparse y no deben usarse con un guion.
•
Opciones largas de GNU, que se preceden de dos guiones.

Las opciones de diferentes tipos pueden mezclarse libremente, pero pueden aparecer conflictos. Hay algunas opciones sinónimas, que son funcionalmente idénticas, debido a los muchos estándares e implementaciones de ps con los que esta ps es compatible.

Por defecto, ps selecciona todos los procesos con el mismo ID de usuario efectivo (euid=EUID) que el usuario actual y asociados con el mismo terminal que el invocador. Muestra el ID del proceso (pid=PID), el terminal asociado al proceso (tname=TTY), el tiempo de CPU acumulado en formato [DD-]hh:mm:ss (time=TIME) y el nombre del ejecutable (ucmd=CMD). La salida no está ordenada por defecto.

El uso de opciones de estilo BSD agregará el estado del proceso (stat=STAT) a la visualización por defecto y mostrará los argumentos del comando (args=COMMAND) en lugar del nombre del ejecutable. Puede anular esto con la variable de entorno PS_FORMAT. El uso de opciones de estilo BSD también cambiará la selección de procesos para incluir procesos en otros terminales (TTYs) que sean propiedad suya; alternativamente, esto puede ser descrito como establecer la selección para ser el conjunto de todos los procesos filtrados para excluir procesos propiedad de otros usuarios o que no están en un terminal. Estos efectos no se consideran cuando las opciones se describen como "idénticas" a continuación, por lo que -M se considerará idéntica a Z y así sucesivamente.

Excepto como se describe a continuación, las opciones de selección de procesos son aditivas. La selección por defecto se descarta, y luego se agregan los procesos seleccionados al conjunto de procesos a mostrar. Un proceso se mostrará si cumple alguno de los criterios de selección dados.

SELECCIÓN DE PROCESOS SIMPLE

a
Levanta la restricción de estilo BSD "solo tú mismo", que se impone al conjunto de todos los procesos cuando se usan algunas opciones de estilo BSD (sin guion) o cuando la configuración de personalidad de ps es de estilo BSD. El conjunto de procesos seleccionados de esta manera se agrega al conjunto de procesos seleccionados por otros medios. Una descripción alternativa es que esta opción hace que ps liste todos los procesos con un terminal (tty), o que liste todos los procesos cuando se usa junto con la opción x.
-A
Selecciona todos los procesos. Idéntico a -e.
-a
Selecciona todos los procesos excepto los líderes de sesión (ver getsid(2)) y los procesos no asociados con un terminal.
-d
Selecciona todos los procesos excepto los líderes de sesión.
--deselect
Selecciona todos los procesos excepto aquellos que cumplen las condiciones especificadas (niega la selección). Idéntico a -N.
-e
Selecciona todos los procesos. Idéntico a -A.
g
Realmente todos, incluso los líderes de sesión. Esta bandera es obsoleta y puede ser descontinuada en una futura versión. Normalmente es implícita por la bandera a, y solo es útil cuando se opera en la personalidad de sunos4.
-N
Selecciona todos los procesos excepto aquellos que cumplen las condiciones especificadas (niega la selección). Idéntico a --deselect.
T
Selecciona todos los procesos asociados con este terminal. Idéntico a la opción t sin ningún argumento.
r
Restringe la selección solo a los procesos en ejecución.
x
Levanta la restricción de estilo BSD "debe tener un tty", que se impone al conjunto de todos los procesos cuando se usan algunas opciones de estilo BSD (sin guion) o cuando la configuración de personalidad de ps es de estilo BSD. El conjunto de procesos seleccionados de esta manera se agrega al conjunto de procesos seleccionados por otros medios. Una descripción alternativa es que esta opción hace que ps liste todos los procesos de su propiedad (mismo EUID que ps), o que liste todos los procesos cuando se usa junto con la opción a.

NOTES

This ps works by reading the virtual files in /proc. This ps does not need to be setuid kmem or have any privileges to run. Do not give this ps any special permissions.

CPU usage is currently expressed as the percentage of time spent running during the entire lifetime of a process. This is not ideal, and it does not conform to the standards that ps otherwise conforms to. CPU usage is unlikely to add up to exactly 100%.

The SIZE and RSS fields don't count some parts of a process including the page tables, kernel stack, struct thread_info, and struct task_struct. This is usually at least 20 KiB of memory that is always resident. SIZE is the virtual size of the process (code+data+stack).

Processes marked <defunct> are dead processes (so-called "zombies") that remain because their parent has not destroyed them properly. These processes will be destroyed by init(8) if the parent process exits.

If the length of the username is greater than the width of the display column, the username will be truncated. See the -o and -O formatting options to customize length.

Commands options such as ps -aux are not recommended as it is a confusion of two different standards. According to the POSIX and Unix standards, the above command asks to display all processes with a TTY (generally the commands users are running) plus all processes owned by a user named x. If that user doesn't exist, then ps will assume you really meant "ps aux".

PROCESS FLAGS

The sum of these values is displayed in the "F" column, which is provided by the flags output specifier:

1 forked but didn't exec
4 used super-user privileges

PROCESS STATE CODES

Here are the different values that the s, stat and state output specifiers (header "STAT" or "S") will display to describe the state of a process:

D uninterruptible sleep (usually I/O)
I idle kernel thread
R running or runnable (on run queue)
S interruptible sleep (waiting for an event to complete)
T stopped by job control signal
t stopped by debugger during the tracing
W paging (not valid since Linux 2.6)
X dead (should never be seen)
Z defunct (“zombie”) process, terminated but not reaped by its parent

For BSD formats and when the stat keyword is used, additional characters may be displayed:

< high-priority (not nice to other users)
N low-priority (nice to other users)
L has pages locked into memory (for real-time and custom I/O)

NOMBRE

ps - mostrar información sobre los procesos en ejecución

SINOPSIS

ps [opciones] [opciones-de-selección] [modelo-de-salida]

DESCRIPCIÓN

El comando ps se utiliza para obtener una instantánea de los procesos que se están ejecutando actualmente en el sistema. Imprime información sobre los procesos seleccionados, que de otro modo no sería accesible con el comando kill o nice.

La salida de ps puede variar dependiendo de las opciones que se pasen al comando. Sin opciones, ps muestra información sobre los procesos que están asociados con la terminal de control actual del proceso. Un conjunto de opciones más completo es eF, que muestra todos los procesos de una manera más detallada.

La siguiente tabla describe algunos de los campos de salida comunes que se pueden encontrar al usar ps. Tenga en cuenta que la disponibilidad y el significado de algunos campos pueden depender del sistema operativo y de la configuración. La información sobre los campos de salida se puede ver utilizando ps --help o man 1 ps.

EJEMPLOS

  • ps aux - Mostrar todos los procesos en ejecución con información detallada.
  • ps -ef - Mostrar todos los procesos en ejecución con un formato diferente.
  • ps -p 1234 - Mostrar información sobre el proceso con PID 1234.
  • ps -u username - Mostrar todos los procesos que pertenecen a un usuario específico.
  • ps -o pid,ppid,cmd - Mostrar el PID, PPID y el comando para todos los procesos.

SELECCIÓN SIMPLE DE PROCESOS

Se pueden utilizar las siguientes opciones para seleccionar los procesos que se mostrarán:

-A, -e
Seleccionar todos los procesos.
-N
Seleccionar todos los procesos excepto los que están en un grupo de procesos determinado.
-a
Seleccionar todos los procesos excepto los líderes de sesión y los que no están asociados a una terminal.
-g lista-grupos
Seleccionar procesos cuyos identificadores de grupo estén en lista-grupos.
-p lista-pids
Seleccionar procesos cuyos identificadores de proceso estén en lista-pids.
-s lista-sesiones
Seleccionar procesos cuyas identificadores de sesión estén en lista-sesiones.
-t lista-terminales
Seleccionar procesos asociados con las terminales especificadas en lista-terminales.
-u lista-usuarios
Seleccionar procesos cuyos nombres de usuario o identificadores de usuario estén en lista-usuarios.
-U lista-usuarios
Seleccionar procesos cuyos nombres de usuario reales o identificadores de usuario estén en lista-usuarios.

SELECCIÓN DE PROCESOS POR LISTA

Las siguientes opciones se pueden utilizar para seleccionar procesos para su exclusión:

--deselect
Seleccionar los procesos que no coinciden con las otras opciones de selección.
--group lista-grupos
Excluir procesos cuyos identificadores de grupo estén en lista-grupos.
--pid lista-pids
Excluir procesos cuyos identificadores de proceso estén en lista-pids.
--session lista-sesiones
Excluir procesos cuyas identificadores de sesión estén en lista-sesiones.
--tty lista-terminales
Excluir procesos asociados con las terminales especificadas en lista-terminales.
--user lista-usuarios
Excluir procesos cuyos nombres de usuario o identificadores de usuario estén en lista-usuarios.
--realuser lista-usuarios
Excluir procesos cuyos nombres de usuario reales o identificadores de usuario estén en lista-usuarios.

CONTROL DE FORMATO DE SALIDA

Las siguientes opciones se pueden utilizar para controlar el formato de la salida:

-1
Salida de formato de una sola columna.
-F
Mostrar información de cabecera adicional.
-f
Salida de formato completo.
-i
No mostrar procesos inactivos.
-l
Salida de formato largo.
-n
No resolver nombres.
-o formato
Especificar un formato de salida personalizado.
-r
Filtrar procesos de solo lectura.
-u
Formato orientado al usuario.
-v
Salida de formato de VmSize.
--help
Mostrar un mensaje de ayuda y salir.

ERRORES

Los campos bsdstart y start solo mostrarán el nombre abreviado del mes en inglés. Los campos lstart y stime mostrarán el nombre abreviado del mes en la configuración regional configurada, pero pueden exceder el ancho de la columna debido a las diferentes longitudes de los nombres abreviados de mes y día entre idiomas.

AUTOR

ps fue escrito originalmente por Branko Lankester. Michael K. Johnson lo reescribió significativamente para usar el sistema de archivos proc, cambiando algunas cosas en el proceso. Michael Shields agregó la función de lista de pids. Charles Blake agregó la ordenación multinivel, la biblioteca de estilo dirent, la base de datos mapeada de nombres de dispositivos a números, la búsqueda binaria aproximada directamente en System.map, y muchas mejoras de código y documentación. David Mossberger-Tang escribió el soporte genérico BFD para psupdate. Albert Cahalan reescribió ps para un soporte completo de Unix98 y BSD, junto con algunas correcciones difíciles para sintaxis obsoleta y extranjera.

Por favor, envíe informes de errores a procps@freelists.org. No se requiere ni se sugiere suscripción.
