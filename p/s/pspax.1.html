PSPAX(1) Documentación para pax-utils PSPAX(1)

NOMBRE

pspax - lista información ELF/PaX sobre procesos en ejecución

SINOPSIS

pspax [opciones] ELFs

DESCRIPCIÓN

pspax es una utilidad de espacio de usuario que escanea el directorio proc y lista los tipos ELF, así como sus respectivos flags de PaX y nombres y atributos de archivo. Dependiendo de las opciones de compilación, puede mostrar adicionalmente las capacidades del conjunto en ejecución del proceso.

OPCIONES

-a, --all

Mostrar todos los procesos

-e, --header

Imprimir marcas GNU_STACK/PT_LOAD

-i, --ipaddr

Imprimir información de ipaddr si es compatible

-p, --pid PID

Procesar solo el ID de proceso especificado

-u, --user UID

Usuario/uid # del proceso

-g, --group GID

Grupo/gid # del proceso

-n, --nx

Mostrar solo procesos w^x

-w, --wx

Mostrar solo procesos w|x

-v, --verbose

Ser detallado (se puede usar más de una vez)

-B, --nobanner

No mostrar la cabecera

-h, --help

Mostrar uso condensado y salir

-V, --version

Imprimir versión y salir
