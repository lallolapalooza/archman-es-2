PSFXTABLE(1) Manual de Comandos Generales PSFXTABLE(1)

NOMBRE

psfxtable - manejar tablas de caracteres Unicode para fuentes de consola

SINOPSIS

psfxtable [-i fuenteentrada] [-o fuentesalida] [-it tablaentrada] [-ot tablasalida] [-nt]

DESCRIPCIÓN

psfxtable maneja la tabla de caracteres Unicode incrustada para fuentes de consola en formato .psf. Lee una fuente y posiblemente una tabla, y escribe una fuente y/o una tabla. psfaddtable(1), psfgettable(1) y psfstriptable(1) son enlaces a él.

Cada uno de los nombres de archivo fuenteentrada, fuentesalida, tablaentrada y tablasalida puede ser reemplazado por un solo guión (-), en cuyo caso se utiliza la entrada o salida estándar. Si no se proporciona la opción -i, la fuente se lee desde la entrada estándar. Si no se proporciona ninguna opción -it, -o o -ot, no se lee ninguna tabla de entrada ni se escribe ninguna fuente de salida o tabla de salida.

Por defecto, la fuente de salida (si existe) tendrá una tabla Unicode cuando la fuente de entrada tenga una, o se haya proporcionado una tabla explícita (que anula una tabla de fuente de entrada). La opción -nt provoca la salida de una fuente sin tabla. Cuando se solicita fuentesalida, esta obtendrá una cabecera psf1 si la fuente de entrada tiene una cabecera psf1 y tablaentrada no tiene secuencias, y una cabecera psf2 en caso contrario.

VER TAMBIÉN

setfont(8), psfaddtable(1), psfgettable(1), psfstriptable(1)
