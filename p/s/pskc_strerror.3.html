pskc_strerror(3) libpskc pskc_strerror(3)

NOMBRE

pskc_strerror - función de la API

SINOPSIS

#include <pskc.h>

const char * pskc_strerror(int err);

ARGUMENTOS

int err
código de error, un valor de pskc_rc.

DESCRIPCIÓN

Convierte el código de retorno en una explicación en texto legible de la razón del código de error específico.

Esta cadena puede usarse para mostrar un mensaje de diagnóstico al usuario.

Esta función es una de las pocas en la biblioteca que se puede utilizar sin una llamada exitosa a pskc_init().

VALOR DE RETORNO

Devuelve un puntero a una cadena asignada estáticamente que contiene una explicación del código de error err.
