NOMBRE

pskc_get_key_algparm_chall_min - Función de API

SINOPSIS

#include <pskc.h>

uint32_t pskc_get_key_algparm_chall_min(pskc_key_t * key, int * present);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
int * present
variable de salida que indica si se proporcionaron datos o no.

DESCRIPCIÓN

Obtiene el valor mínimo de Desafío (ChallengeFormat Min) de los Parámetros de Algoritmo de Clave del Paquete de Clave (Key Package Key AlgorithmParameters) de PSKC. Este atributo define el tamaño mínimo del desafío aceptado por el dispositivo para el modo CR y DEBE incluirse. Si el atributo 'Codificación' (Encoding) está configurado como 'DECIMAL', 'HEXADECIMAL' o 'ALFANUMÉRICO', este valor indica el número mínimo de dígitos/caracteres. Si el atributo 'Codificación' está configurado como 'BASE64' o 'BINARIO', este valor indica el número mínimo de bytes del valor sin codificar.

Si present no es NULL, será 0 si el campo no está presente o 1 si estaba presente.

DEVUELVE

un entero que contiene el contenido.
