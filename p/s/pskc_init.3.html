NOMBRE

pskc_init - Función de la API

SINOPSIS

#include <pskc.h>

int pskc_init(pskc_t ** container);

ARGUMENTOS

pskc_t ** container
puntero a un manejador pskc_t para inicializar.

DESCRIPCIÓN

Esta función inicializa el manejador del contenedor PSKC. La memoria asignada puede ser liberada llamando a pskc_done().

RETORNOS

En caso de éxito, se devuelve PSKC_OK (cero), en caso de errores de asignación de memoria se devuelve PSKC_MALLOC_ERROR.
