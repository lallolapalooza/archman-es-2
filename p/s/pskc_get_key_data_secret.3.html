NOMBRE

pskc_get_key_data_secret - función API

SINOPSIS

#include <pskc.h>

const char * pskc_get_key_data_secret(pskc_key_t * key, size_t * len);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
size_t * len
puntero a la variable de salida con la longitud de los datos devueltos.

DESCRIPCIÓN

Obtiene el valor Secreto de Datos de Clave del Paquete de Clave PSKC. Si len no está establecido, el llamante solo puede usar el valor devuelto para compararlo con NULL y verificar si el campo está presente o no.

DEVOLUCIONES

una cadena constante (no debe liberarse) que contiene el contenido de longitud *len, o NULL si no está establecido.
