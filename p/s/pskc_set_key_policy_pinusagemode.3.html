NOMBRE

pskc_set_key_policy_pinusagemode - función de la API

SINOPSIS

#include <pskc.h>

void pskc_set_key_policy_pinusagemode(pskc_key_t * key, pskc_pinusagemode pinusagemode);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
pskc_pinusagemode pinusagemode
el valor pskc_pinusagemode a establecer

DESCRIPCIÓN

Establece el valor PSKC KeyPackage Key Policy PINPolicy PINUsageMode. Este atributo obligatorio indica la forma en que se utiliza el PIN durante el uso de la clave.
