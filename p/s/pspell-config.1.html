PSPELL-CONFIG(1) Manual de usuario abreviado de Aspell PSPELL-CONFIG(1)

NOMBRE

pspell-config - imprime información sobre una instalación de libpspell

SINOPSIS

pspell-config [opciones]

DESCRIPCIÓN

pspell-config muestra información sobre la instalación de libpspell, principalmente para su uso en scripts de compilación. Tenga en cuenta que este script se proporciona por compatibilidad con versiones anteriores con programas que utilizan pspell. No lo utilice, ya que eventualmente desaparecerá.

OPCIONES

--version
muestra información de la versión de pspell instalado
--datadir
muestra el directorio de datos
--pkgdatadir
muestra el directorio de paquetes de aspell
