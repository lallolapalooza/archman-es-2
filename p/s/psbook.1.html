PSBOOK(1) Comandos de usuario PSBOOK(1)

NOMBRE

psbook

SINOPSIS

psbook [OPCIÓN...] [ARCHIVO_ENTRADA [ARCHIVO_SALIDA]]

DESCRIPCIÓN

psbook utiliza pstops para reorganizar las páginas de un documento PDF o PostScript en ‘firmas’ para imprimir libros o folletos, creando un nuevo archivo. Una ‘firma’, a menudo llamada ‘sección’ en encuadernación, es una serie de pliegos que se pliegan juntos para ser cosidos en la encuadernación del libro. Cada pliego tiene dos páginas por cara; el número de páginas de una firma debe ser, por lo tanto, un múltiplo de cuatro. Se añadirán páginas en blanco adicionales si el archivo no contiene un múltiplo de cuatro páginas.

La salida debe imprimirse 2-up (esto se puede lograr con psnup(1)) y a doble cara, como para la encuadernación de canto corto. Alternativamente, la salida de psnup puede pasarse a través del siguiente comando:

pstops '2:0(0,0),1U(1w,1h)'

para rotar la página verso boca abajo, y el resultado puede ser impreso a doble cara como para la encuadernación de canto largo. Reorganiza las páginas en un documento PDF o PostScript en firmas.

ARCHIVO_ENTRADA
`-' o ningún argumento ARCHIVO_ENTRADA significa entrada estándar
ARCHIVO_SALIDA
`-' o ningún argumento ARCHIVO_SALIDA significa salida estándar

OPCIONES

-s FIRMA, --signature FIRMA
número de páginas por firma; 0 = todas las páginas en una firma [por defecto]; 1 = no reorganizar las páginas; de lo contrario, un múltiplo de 4
-v, --version
mostrar número de versión del programa y salir
-q, --quiet
no mostrar progreso

COMENTARIOS

PÁGINAS es una lista separada por comas de páginas y rangos de páginas; ver pstops(1) para más detalles.
