NOMBRE

pskc_set_key_algparm_chall_checkdigits - Función de API

SINOPSIS

#include <pskc.h>

void pskc_set_key_algparm_chall_checkdigits(pskc_key_t * key, int checkdigit);

ARGUMENTOS

pskc_key_t * key
un manejador pskc_key_t, de pskc_get_keypackage().
int checkdigit
distinto de cero para indicar que se establece CheckDigit verdadero, 0 en caso contrario.

DESCRIPCIÓN

Establece el valor CheckDigits de ChallengeFormat de Parámetros de Algoritmo de Clave del Paquete de Clave PSKC. Este atributo indica si un dispositivo necesita verificar el dígito de control Luhn añadido, tal como se define en [ISOIEC7812], contenido en un desafío. Esto solo es válido si el atributo 'Encoding' está establecido en 'DECIMAL'. Un valor de TRUE indica que el dispositivo verificará el dígito de control Luhn añadido en un desafío proporcionado. Un valor de FALSE indica que el dispositivo no verificará el dígito de control Luhn añadido en el desafío.
