PSIGINFO(3P) Manual de Programador POSIX PSIGINFO(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

psiginfo, psignal — escribir información de señales en el flujo de error estándar

SINOPSIS

#include <signal.h>
void psiginfo(const siginfo_t *pinfo, const char *message);
void psignal(int signum, const char *message);

DESCRIPCIÓN

Las funciones psiginfo() y psignal() escribirán un mensaje lingüísticamente dependiente asociado con un número de señal en el flujo de error estándar de la siguiente manera:

*
Primero, si message no es un puntero nulo y no es una cadena vacía, la cadena apuntada por el argumento message se escribirá, seguida de dos puntos y un espacio.
*
Luego se escribirá la cadena de descripción de la señal asociada con signum o con la señal indicada por pinfo, seguida de un salto de línea.

Para psiginfo(), la aplicación se asegurará de que el argumento pinfo haga referencia a una estructura siginfo_t válida. Para psignal(), si signum no es un número de señal válido, el comportamiento es definido por la implementación.

Las funciones psiginfo() y psignal() no cambiarán la orientación del flujo de error estándar.

Las funciones psiginfo() y psignal() marcarán para actualización las marcas de tiempo de la última modificación de datos y del último cambio de estado del archivo asociados con el flujo de error estándar en algún momento entre su finalización exitosa y exit(), abort(), o la finalización de fflush() o fclose() en stderr.

Las funciones psiginfo() y psignal() no cambiarán la configuración de errno si son exitosas.

En caso de error, las funciones psiginfo() y psignal() establecerán el indicador de error para el flujo al que apunta stderr y establecerán errno para indicar el error.

Dado que no se devuelve ningún valor, una aplicación que desee comprobar situaciones de error debe establecer errno a 0, luego llamar a psiginfo() o psignal(), y luego comprobar errno.

VALOR DE RETORNO

Estas funciones no devolverán un valor.

ERRORES

Consulte fputc().

EJEMPLOS

Ninguno.

USO DE APLICACIÓN

Como alternativa a establecer errno a cero antes de la llamada y comprobar si es distinto de cero después, las aplicaciones pueden usar ferror() para detectar si psiginfo() o psignal() encontraron un error.

Una aplicación que desee utilizar este método para comprobar situaciones de error debe llamar a clearerr(stderr) antes de llamar a psiginfo() o psignal(), luego, si ferror(stderr) devuelve un valor distinto de cero, el valor de errno indicará qué error ocurrió.

RACIONALE

System V históricamente tiene psignal() y psiginfo() en <siginfo.h>. Sin embargo, la cabecera <siginfo.h> no está especificada en el volumen de Definiciones Base de POSIX.1‐2017, y el tipo siginfo_t se define en <signal.h>.
