PSENSOR(1) Comandos de usuario PSENSOR(1)

NOMBRE

psensor - Aplicación de monitorización de temperatura

SINOPSIS

psensor [OPCIÓN]...

DESCRIPCIÓN

Psensor es una aplicación GTK+ para monitorizar sensores de hardware, incluyendo temperaturas y velocidades de ventilador.

OPCIONES

-h, --help
muestra esta ayuda y sale
-v, --version
muestra la información de la versión y sale
-u, --url=URL
la URL del psensor-server, ejemplo: http://hostname:3131
-n, --new-instance
fuerza la creación de una nueva instancia de la aplicación Psensor
-d, --debug=NIVEL
establece el nivel de depuración, un entero entre 0 y 3
