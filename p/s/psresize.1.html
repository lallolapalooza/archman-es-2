PSRESIZE(1) Comandos de usuario PSRESIZE(1)

NOMBRE

psresize

SINOPSIS

psresize [OPCIÓN...] [ARCHIVO_ENTRADA [ARCHIVO_SALIDA]]

DESCRIPCIÓN

psresize utiliza psnup para cambiar el tamaño de página de un documento, escalándolo y centrándolo apropiadamente. Ver psutils(1) para las unidades disponibles. Cambia el tamaño de página de un documento PDF o PostScript.

ARCHIVO_ENTRADA
`-' o ningún argumento ARCHIVO_ENTRADA significa entrada estándar
ARCHIVO_SALIDA
`-' o ningún argumento ARCHIVO_SALIDA significa salida estándar

OPCIONES

-p PAPEL, --paper PAPEL
nombre o dimensiones del papel de salida (ANCHOxALTO)
-P PAPEL_ENTRADA, --inpaper PAPEL_ENTRADA
nombre o dimensiones del papel de entrada (ANCHOxALTO)
-v, --version
muestra el número de versión del programa y sale
-q, --quiet
no mostrar progreso

COMENTARIOS

PÁGINAS es una lista separada por comas de páginas y rangos de páginas; ver pstops(1) para más detalles.

EJEMPLOS

El siguiente comando convierte un documento de tamaño A4 a papel US Letter:

psresize -PA4 -pletter in.pdf out.pdf
