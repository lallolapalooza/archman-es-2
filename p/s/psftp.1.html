NOMBRE

psftp - cliente interactivo de SFTP (protocolo seguro de transferencia de archivos)

SINOPSIS

psftp [opciones] [usuario@]host

DESCRIPCIÓN

psftp es un cliente interactivo basado en texto para el protocolo SFTP (protocolo seguro de transferencia de archivos) basado en SSH.

OPCIONES

Las opciones de línea de comandos compatibles con psftp son:

-V
Muestra la información de la versión y sale.
-pgpfp
Muestra las huellas digitales de las Claves Maestras PGP de PuTTY y sale, para ayudar a verificar los nuevos archivos publicados por el equipo de PuTTY.
-b archivo_batch
Utiliza el archivo batch especificado.
-bc
Comandos del archivo batch de salida.
-be
No detener el procesamiento del archivo batch en caso de errores.
-v
Muestra mensajes detallados.
-load sesion
Carga la configuración desde la sesión guardada.
-P puerto
Conéctate al puerto puerto.
-proxycmd comando
En lugar de realizar una conexión TCP, utiliza comando como proxy; el tráfico de red se redirigirá a la entrada y salida estándar de comando. comando debe ser una sola palabra, por lo que es probable que necesite ser entrecomillado por el shell.

Las cadenas especiales %host y %port en comando se reemplazarán por el nombre de host y el número de puerto al que desea conectarse; para obtener un signo % literal, introduzca %%.

También se admiten escapes de barra invertida, como secuencias como \n que se reemplazan por un salto de línea literal; para obtener una barra invertida literal, introduzca \\. (Es posible que el shell requiera más entrecomillado).

(Consulte el manual principal de PuTTY para obtener detalles completos de los tokens compatibles delimitados por % y barra invertida, aunque la mayoría de ellos probablemente no sean muy útiles en este contexto).

-l usuario
Establece el nombre de usuario remoto a usuario.
-batch
Deshabilita las solicitudes interactivas.
-no-sanitise-stderr
Por defecto, PSFTP filtrará los caracteres de control del canal de error estándar del servidor, para evitar que los procesos remotos envíen secuencias de escape confusas. Esta opción fuerza a que el canal de error estándar no se filtre.
-pwfile nombre_archivo
Abre el archivo especificado y utiliza la primera línea de texto leída de él como contraseña remota.
-pw contraseña
Establece la contraseña remota a contraseña. PRECAUCIÓN: esto probablemente hará que la contraseña sea visible para otros usuarios de la máquina local (a través de comandos como `ps' o `w'). Utilice -pwfile en su lugar.
-1
Fuerza el uso del protocolo SSH versión 1.
-2
Fuerza el uso del protocolo SSH versión 2.
-ssh-connection
Fuerza el uso del protocolo `bare ssh-connection'. Esto solo será útil al conectarse a un servidor psusan(1), lo más probable es que con una ruta absoluta a un socket de dominio Unix en lugar de host.
-ssh
Fuerza el uso del protocolo SSH. (Esto generalmente no es necesario; solo será útil si necesita anular alguna otra configuración del protocolo `bare ssh-connection').
-4, -6
Fuerza el uso de IPv4 o IPv6 para las conexiones de red.
-C
Habilita la compresión SSH.
-i archivo_clave
Archivo de clave privada para autenticación de usuario. Para claves SSH-2, este archivo de clave debe estar en formato PPK de PuTTY, no en formato OpenSSH ni en ningún otro.

Si está utilizando un agente de autenticación, también puede especificar una clave pública aquí (en formato RFC 4716 u OpenSSH), para identificar cuál de las claves del agente usar.

-noagent
No intente usar un agente de autenticación.
-agent
Permite el uso de un agente de autenticación. (Esta opción solo es necesaria para anular una configuración en una sesión guardada).
-no-trivial-auth
Desconéctese de cualquier servidor SSH que acepte autenticación sin haber solicitado nunca ningún tipo de contraseña, firma o token. (Es posible que desee habilitar esto para un servidor que siempre espera desafiarlo, por ejemplo, para asegurarse de que no escriba accidentalmente la contraseña de su archivo de clave en un servidor comprometido que suplanta el aviso de contraseña de PSFTP).
-hostkey clave
Especifica una clave pública de host aceptable. Esta opción puede especificarse varias veces; cada clave puede ser una huella digital (SHA256:AbCdE..., 99:aa:bb:..., etc.) o un blob codificado en base64 en el formato de una línea de OpenSSH.

Especificar esta opción anula la gestión automatizada de claves de host; solo se aceptarán las claves especificadas en la línea de comandos (a menos que una sesión guardada también anule las claves de host, en cuyo caso se añadirán), y la caché de claves de host no se escribirá.

-sshlog archivo_log
-sshrawlog archivo_log
Estas opciones hacen que psftp registre detalles del protocolo en un archivo. (Algunos de estos pueden ser sensibles, aunque por defecto se intenta suprimir las contraseñas obvias).

-sshlog registra paquetes SSH decodificados y otros eventos (aquellos que -v imprimiría). -sshrawlog además registra los datos brutos del paquete cifrado.

-logoverwrite
Si PSFTP está configurado para escribir en un archivo de registro que ya existe, descarta el archivo existente.
-logappend
Si PSFTP está configurado para escribir en un archivo de registro que ya existe, anexa los nuevos datos de registro al archivo existente.

COMANDOS
