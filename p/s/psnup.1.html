PSNUP(1) Comandos de usuario PSNUP(1)

NOMBRE

psnup

SINOPSIS

psnup [OPCIÓN...] -NÚMERO [ARCHIVO_ENTRADA [ARCHIVO_SALIDA]]

DESCRIPCIÓN

psnup utiliza pstops para imponer múltiples páginas lógicas en cada hoja de papel física.

Los tamaños de papel pueden proporcionarse como un nombre (ver paper(1)) o como anchoxalto (ver psutils(1) para las unidades disponibles). Coloca varias páginas de un documento PostScript en una sola página.

-NÚMERO
número de páginas a imponer en cada página de salida
ARCHIVO_ENTRADA
`-' o ningún argumento ARCHIVO_ENTRADA significa entrada estándar
ARCHIVO_SALIDA
`-' o ningún argumento ARCHIVO_SALIDA significa salida estándar

OPCIONES

-p PAPEL, --paper PAPEL
nombre o dimensiones del papel de salida (ANCHOxALTO)
-P PAPEL_ENTRADA, --inpaper PAPEL_ENTRADA
nombre o dimensiones del papel de entrada (ANCHOxALTO)
-m DIMENSIÓN, --margin DIMENSIÓN
ancho del margen alrededor de cada página de salida [por defecto 0pt]; útil para hojas en miniatura, ya que los márgenes de la página original se reducirán
-b DIMENSIÓN, --border DIMENSIÓN
ancho del borde alrededor de cada página de entrada
-d [DIMENSIÓN], --draw [DIMENSIÓN]
dibuja una línea del ancho dado (relativo a la página original) alrededor de cada página [el argumento por defecto es 1pt; por defecto no hay línea; el ancho es fijo para PDF]
-l, --rotatedleft
las páginas de entrada están rotadas 90 grados a la izquierda
-r, --rotatedright
las páginas de entrada están rotadas 90 grados a la derecha
-f, --flip
intercambia el ancho y el alto de las páginas de salida
-c, --transpose
intercambia columnas y filas (orden mayor por columnas)
-t NÚMERO, --tolerance NÚMERO
área desperdiciada máxima en pt cuadrados [por defecto: 100000]
-v, --version
muestra el número de versión del programa y sale
-q, --quiet
no muestra el progreso

COMENTARIOS

psnup aborta con un error si no puede organizar las páginas de entrada de manera que se desperdicie menos del margen especificado.

El tamaño de página de salida por defecto es el tamaño de página de entrada; si no se especifica ninguno en el documento o en la línea de comandos, se utiliza el valor por defecto proporcionado por el comando `paper'.

El tamaño de página de entrada por defecto es el tamaño de página de salida.

En orden mayor por filas (el predeterminado), las páginas adyacentes se colocan en filas a lo ancho del papel; en orden mayor por columnas, se colocan en columnas a lo largo del papel.

EJEMPLOS

El uso potencial de esta utilidad es variado, pero un uso particular es en conjunción con psbook(1). Por ejemplo, usando groff para crear un documento PostScript y lpr como el spooler de impresión de UNIX, una línea de comandos típica podría ser:

groff -Tps -ms archivo | psbook | psnup -2 | lpr

donde archivo es un documento de 4 páginas; este comando dará como resultado un documento de dos páginas imprimiendo dos páginas de archivo por página y reorganiza el orden de las páginas para que coincida con las páginas de entrada 4 y 1 en la primera página de salida y las páginas 2 y 3 del documento de entrada en la segunda página de salida.
