PST2LDIF(1) Utilidades libpst - Versión 0.6 PST2LDIF(1)

NOMBRE

pst2ldif - extraer contactos de un archivo .pst de MS Outlook en formato .ldif

SINOPSIS

pst2ldif [-V] [-b base-ldap] [-c clase] [-d archivo-depuracion] [-l linea-extra] [-o] [-h] nombre-archivo-pst

OPCIONES

-V

Mostrar la versión del programa. Las opciones subsiguientes se ignoran.

-b base-ldap

Establece el valor base de ldap utilizado en los registros dn. Probablemente querrá usar algo como "o=organizacion, c=ES".

-c clase

Establece los valores de objectClass para los elementos de contacto. Esta clase debe estar definida en el esquema utilizado por su servidor LDAP, y como mínimo debe contener los atributos ldap dados a continuación. Esta opción puede especificarse varias veces para generar entradas con múltiples clases de objetos.

-d archivo-depuracion

Especificar el nombre del archivo de registro de depuración. El archivo de registro es ahora un archivo ascii, en lugar del archivo binario utilizado en versiones anteriores.

-l linea-extra

Especificar una línea adicional que se agregará a cada entrada ldap. Esta opción puede especificarse varias veces para agregar múltiples líneas a cada entrada ldap.

-o

Usar el esquema ldap antiguo, en lugar del esquema ldap nuevo por defecto. El esquema antiguo genera múltiples atributos postalAddress para una sola entrada. El esquema nuevo genera un único atributo postalAddress (y homePostalAddress cuando está disponible) con delimitadores $ según lo especificado en RFC4517. Usar el esquema antiguo también genera dos entradas iniciales adicionales, una para "dn:base-ldap", y otra para "dn: cn=root, base-ldap".

-h

Mostrar resumen de opciones. Las opciones subsiguientes se ignoran.

DESCRIPCIÓN

pst2ldif lee la información de contacto de un archivo .pst de MS Outlook y produce un archivo .ldif que puede usarse para importar esos contactos en una base de datos LDAP. Los siguientes atributos ldap se generan para el esquema ldap antiguo:

cn
givenName
sn
personalTitle
company
mail
postalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
Los siguientes atributos se generan para el esquema ldap nuevo:
cn
givenName
sn
title
o
mail
postalAddress
homePostalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
labeledURI
