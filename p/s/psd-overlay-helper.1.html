NOMBRE

psd-overlay-helper - Script para usar el sistema de archivos overlay para profile-sync-daemon.

DESCRIPCIÓN

Profile-sync-daemon (psd) es un pequeño pseudo-demonio diseñado para gestionar el perfil/perfiles del navegador en tmpfs y sincronizar periódicamente de vuelta al disco físico (HDD/SSD). Esto se logra mediante un uso innovador de rsync para mantener la sincronización entre una copia de tmpfs y una copia de respaldo en disco del perfil/perfiles del navegador. Adicionalmente, psd incluye varias características de recuperación ante fallos.

El script psd-overlay-helper se utiliza internamente para habilitar el uso de el sistema de archivos overlay. No debe ser llamado directamente por el usuario.
