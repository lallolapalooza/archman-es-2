NOMBRE

pip-wheel - descripción del comando pip wheel

DESCRIPCIÓN

Construye archivos Wheel para tus requisitos y dependencias.

Wheel es un formato de paquete precompilado y ofrece la ventaja de no recompilar tu software durante cada instalación. Para más detalles, consulta la documentación de wheel: https://wheel.readthedocs.io/en/latest/

'pip wheel' utiliza la interfaz del sistema de compilación descrita aquí: https://pip.pypa.io/en/stable/reference/build-system/

USO

python -m pip wheel [opciones] <especificador de requisito> ...
python -m pip wheel [opciones] -r <archivo de requisitos> ...
python -m pip wheel [opciones] [-e] <url del proyecto vcs> ...
python -m pip wheel [opciones] [-e] <ruta del proyecto local> ...
python -m pip wheel [opciones] <url/ruta del archivo> ...

OPCIONES

-w, --wheel-dir <directorio>
Construye ruedas en <directorio>, donde el valor predeterminado es el directorio de trabajo actual.

(variable de entorno: PIP_WHEEL_DIR)

--no-binary <control_formato>
No uses paquetes binarios. Se puede proporcionar varias veces, y cada vez se añade al valor existente. Acepta ":all:" para deshabilitar todos los paquetes binarios, ":none:" para vaciar el conjunto (nota los dos puntos), o uno o más nombres de paquetes separados por comas (sin dos puntos). Ten en cuenta que algunos paquetes son difíciles de compilar y pueden fallar al instalarlos cuando se usa esta opción.

(variable de entorno: PIP_NO_BINARY)

--only-binary <control_formato>
No uses paquetes de código fuente. Se puede proporcionar varias veces, y cada vez se añade al valor existente. Acepta ":all:" para deshabilitar todos los paquetes de código fuente, ":none:" para vaciar el conjunto, o uno o más nombres de paquetes separados por comas. Los paquetes sin distribuciones binarias fallarán al instalarlos cuando se usa esta opción.

(variable de entorno: PIP_ONLY_BINARY)

--prefer-binary
Prefiere paquetes binarios sobre paquetes de código fuente, incluso si los paquetes de código fuente son más recientes.

(variable de entorno: PIP_PREFER_BINARY)

--no-build-isolation
Deshabilita el aislamiento al construir una distribución fuente moderna. Las dependencias de compilación especificadas por PEP 518 deben estar ya instaladas si se utiliza esta opción.

(variable de entorno: PIP_NO_BUILD_ISOLATION)

--check-build-dependencies
Verifica las dependencias de compilación.

(variable de entorno: PIP_CHECK_BUILD_DEPENDENCIES)

-c, --constraint <archivo>
Restringe las versiones utilizando el archivo de restricciones dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_CONSTRAINT)

--build-constraint <archivo>
Restringe las dependencias de compilación utilizando el archivo de restricciones dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_BUILD_CONSTRAINT)

-e, --editable <ruta/url>
Instala un proyecto en modo editable (es decir, modo de desarrollo de setuptools) desde una ruta de proyecto local o una URL VCS.

(variable de entorno: PIP_EDITABLE)

-r, --requirement <archivo>
Instala desde el archivo de requisitos dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_REQUIREMENT)

--src <directorio>
Directorio donde se descargarán los proyectos editables. El valor predeterminado en un entorno virtual es "<ruta_del_entorno>/src". El valor predeterminado para las instalaciones globales es "<directorio_actual>/src".

(variables de entorno: PIP_SRC, PIP_SOURCE, PIP_SOURCE_DIR, PIP_SOURCE_DIRECTORY)

--ignore-requires-python
Ignora la información de Requires-Python.

(variable de entorno: PIP_IGNORE_REQUIRES_PYTHON)

--no-deps
No instales las dependencias del paquete.

(variables de entorno: PIP_NO_DEPS, PIP_NO_DEPENDENCIES)

--progress-bar <barra_progreso>
Especifica si se debe usar la barra de progreso. En el modo 'auto', --quiet suprimirá todas las barras de progreso. [auto, on, off, raw] (predeterminado: auto)

(variable de entorno: PIP_PROGRESS_BAR)

--no-verify
No verifiques si la rueda construida es válida.

(variable de entorno: PIP_NO_VERIFY)

-C, --config-settings <configuraciones>
Configuraciones que se pasarán al backend de compilación. Las configuraciones tienen el formato CLAVE=VALOR. Usa múltiples opciones --config-settings para pasar múltiples claves al backend.

(variable de entorno: PIP_CONFIG_SETTINGS)

--pre
Incluye versiones preliminares y de desarrollo. Por defecto, pip solo encuentra versiones estables.

(variable de entorno: PIP_PRE)

--require-hashes
Requiere un hash para verificar cada requisito, para instalaciones reproducibles. Esta opción se implica cuando cualquier paquete en un archivo de requisitos tiene una opción --hash.

(variable de entorno: PIP_REQUIRE_HASHES)

--group <[ruta:]grupo>
Instala un grupo de dependencias con nombre de un archivo "pyproject.toml". Si se proporciona una ruta, el nombre del archivo debe ser "pyproject.toml". Por defecto, utiliza "pyproject.toml" en el directorio actual.

(variable de entorno: PIP_GROUP)

--no-clean
No limpies los directorios de compilación.

(variable de entorno: PIP_NO_CLEAN)
