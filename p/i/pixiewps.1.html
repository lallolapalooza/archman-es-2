PIXIEWPS(1) Herramienta de fuerza bruta WPS offline PIXIEWPS(1)

NOMBRE

pixiewps - Herramienta de fuerza bruta WPS (Wi-Fi Protected Setup) offline

DESCRIPCIÓN

Pixiewps es una herramienta escrita en C utilizada para realizar fuerza bruta offline del método PIN de WPS, explotando la baja o inexistente entropía de algunos Puntos de Acceso, el llamado "ataque pixie-dust".
Está destinada únicamente a fines educativos.

SINOPSIS

pixiewps <argumentos>

ARGUMENTOS

ARGUMENTOS REQUERIDOS

-e, --pke

Clave pública DH del enrolado, encontrada en M1.

-r, --pkr

Clave pública DH del registrador, encontrada en M2. Puede evitarse especificando --dh-small tanto en Reaver como en pixiewps.
pixiewps -e <pke> -s <e-hash1> -z <e-hash2> -a <authkey> -n <e-nonce> -S

-s, --e-hash1

Hash 1 del enrolado, encontrado en M3. Es el hash de la primera mitad del PIN.

-z, --e-hash2

Hash 2 del enrolado, encontrado en M3. Es el hash de la segunda mitad del PIN.

-a, --authkey

Clave de sesión de autenticación. Aunque para este parámetro se necesita una versión modificada de Reaver o Bully, se puede evitar especificando claves Diffie-Hellman pequeñas tanto en Reaver como en pixiewps y proporcionando --e-nonce, --r-nonce y --e-bssid.
pixiewps -e <pke> -s <e-hash1> -z <e-hash2> -S -n <e-nonce> -m <r-nonce> -b <e-bssid>

-n, --e-nonce

Nonce del enrolado, encontrado en M1.

ARGUMENTOS OPCIONALES

-m, --r-nonce

Nonce del registrador, encontrado en M2. Se usa con otros parámetros para calcular las claves de sesión.

-b, --e-bssid

BSSID del enrolado. Se usa con otros parámetros para calcular las claves de sesión.

-S, --dh-small (obsoleto)

Claves Diffie-Hellman pequeñas. La misma opción debe especificarse también en Reaver. Algunos Puntos de Acceso parecen tener errores y no se comportan correctamente con esta opción. Evita usarla con Reaver cuando sea posible.

-v, --verbosity

Nivel de verbosidad de 1 a 3, 1 es el más silencioso, el valor predeterminado es 3.

-h

Muestra una pantalla de ayuda simple.

--help

Muestra ayuda detallada.

-V, --version

Muestra la versión y otra información.

--mode N[,... N]

Selecciona modos, separados por comas (los modos experimentales no se utilizan a menos que se especifiquen):
1 - RT/MT/CL
2 - eCos simple
3 - RTL819x
4 - eCos más simple [Experimental]
5 - eCos Knuth [Experimental]

--start [mm/]yyyy

--end [mm/]yyyy
Fechas de inicio y fin para el modo 3, son intercambiables.
Si solo se especifica una, se usará la hora actual para la otra. La fecha más temprana posible es 01/1970, correspondiente a 0 (tiempo de época Unix), la más tardía es 02/2038, correspondiente a 0x7FFFFFFF. Si se usa --force, pixiewps comenzará desde la hora actual y retrocederá hasta 0.

ARGUMENTOS MISCELÁNEOS

-7, --m7-enc

Ajustes cifrados, encontrados en M7. Recupera la WPA-PSK del enrolado y el nonce secreto 2. Esta función solo funciona en algunos Puntos de Acceso vulnerables al modo 3.
pixiewps -e <pke> -r <pkr> -n <e-nonce> -m <r-nonce> -b <e-bssid> -7 <enc7> --mode 3

-5, --m5-enc

Ajustes cifrados, encontrados en M5. Recupera el nonce secreto 1 del enrolado. Esta opción debe usarse junto con --m7-enc. Si también se especifican --e-hash1 y --e-hash2, pixiewps también recuperará el PIN WPS.
pixiewps -e <pke> -r <pkr> -n <e-nonce> -m <r-nonce> -b <e-bssid> -7 <enc7> -5 <enc5> --mode 3
pixiewps -e <pke> -r <pkr> -n <e-nonce> -m <r-nonce> -b <e-bssid> -7 <enc7> -5 <enc5> --mode 3 -s <e-hash1> -z <e-hash2>

EJEMPLOS

pixiewps --pke <pke> --pkr <pkr> --e-hash1 <e-hash1> --e-hash2 <e-hash2> --authkey <authkey> --e-nonce <e-nonce>

pixiewps -e <pke> -r <pkr> -s <e-hash1> -z <e-hash2> -a <authkey> -n <e-nonce>
