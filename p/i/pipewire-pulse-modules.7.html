NOMBRE

pipewire-pulse-modules - Módulos Pulseaudio de PipeWire

DESCRIPCIÓN

La emulación Pulseaudio de PipeWire implementa varios módulos Pulseaudio. Solo admite sus propios módulos integrados y no puede cargar módulos externos escritos para Pulseaudio.

CARGA DE MÓDULOS

Los módulos integrados se pueden cargar usando programas cliente de Pulseaudio, por ejemplo pactl load-module <nombre-del-módulo> <opciones-del-módulo>. También se pueden agregar a pipewire-pulse.conf, típicamente mediante un archivo de reemplazo en ~/.config/pipewire/pipewire-pulse.conf.d/ que contenga el nombre del módulo y sus argumentos.

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.cmd = [
    { cmd = "load-module" args = "module-null-sink sink_name=foo" flags = [ ] }
]

Para listar todos los módulos cargados actualmente, con sus argumentos:

pactl list modules

Para una lista corta de módulos cargados:

pactl list modules short

Los módulos se pueden descargar utilizando el nombre del módulo o su número de índice:

pactl load-module <nombre-del-módulo> <parámetros>
pactl unload-module <nombre-del-módulo|índice#>

OPCIONES COMUNES DE MÓDULOS

La mayoría de los módulos que crean flujos/dispositivos admiten las siguientes propiedades:

sink_name, source_name

Nombre para el sink (fuente de salida) (resp. source (fuente de entrada)). Los caracteres permitidos en el nombre son a-z, A-Z, números, punto (.) y guion bajo (_). La longitud debe ser de 1-128 caracteres.

formato

El formato de la muestra. Los formatos de audio admitidos son:

PCM

  • u8: entero sin signo de 8 bits
  • aLaw: entero codificado A-law de 8 bits
  • uLaw: entero codificado µ-law de 8 bits
  • s16le: entero con signo de 16 bits little-endian
  • s16be: entero con signo de 16 bits big-endian
  • s16, s16ne: alias de endianidad nativa para s16le o s16be
  • s16re: alias de endianidad inversa para s16le o s16be
  • float32le: flotante de 32 bits little-endian
  • float32be: flotante de 32 bits big-endian
  • float32, float32ne: alias de endianidad nativa para float32le o float32be
  • float32re: alias de endianidad inversa para float32le o float32be
  • s32le: entero con signo de 32 bits little-endian
  • s32be: entero con signo de 32 bits big-endian
  • s32, s32ne: alias de endianidad nativa para s32le o s32be
  • s32re: alias de endianidad inversa para s32le o s32be
  • s24le: entero con signo de 24 bits little-endian (nota: ALSA llama a esto "S24_3LE")
  • s24be: entero con signo de 24 bits big-endian (nota: ALSA llama a esto "S24_3BE")
  • s24, s24ne: alias de endianidad nativa para s24le o s24be
  • s24re: alias de endianidad inversa para s24le o s24be
  • s24-32le: entero con signo de 24 bits little-endian, empaquetado en un entero de 32 bits para que se ignoren los 8 bits más significativos (nota: ALSA llama a esto "S24_LE")
  • s24-32be: entero con signo de 24 bits big-endian, empaquetado en un entero de 32 bits para que se ignoren los 8 bits más significativos (nota: ALSA llama a esto "S24_BE")
  • s24-32, s24-32ne: alias de endianidad nativa para s24-32le o s24-32be
  • s24-32re: alias de endianidad inversa para s24-32le o s24-32be

Formatos de audio comprimidos

A continuación se muestra una lista de todos los formatos comprimidos admitidos. El código al principio de cada línea se utiliza siempre que se necesita un identificador textual para un formato (por ejemplo, en archivos de configuración o en la línea de comandos). Los formatos cuyos identificadores terminan en -iec61937 tienen que empaquetarse en marcos IEC 61937, lo que hace que el audio comprimido se comporte más como audio PCM normal.

  • ac3-iec61937: Dolby Digital (DD / AC-3 / A/52)
  • eac3-iec61937: Dolby Digital Plus (DD+ / E-AC-3)
  • mpeg-iec61937: MPEG-1 o MPEG-2 Parte 3 (no MPEG-2 AAC)
  • dts-iec61937: DTS
  • mpeg2-aac-iec61937: MPEG-2 AAC (admitido desde PulseAudio 4.0)
  • truehd-iec61937: Dolby TrueHD (añadido en PulseAudio 13.0, pero aún no funciona en la práctica)
  • dtshd-iec61937: DTS-HD Master Audio (añadido en PulseAudio 13.0, pero aún no funciona en la práctica)
  • pcm: PCM (no es un formato comprimido, pero se lista aquí porque pcm es uno de los identificadores de codificación reconocidos)
  • any: (identificador especial para indicar que se puede usar cualquier codificación)

tasa

La frecuencia de muestreo.

canales

Número de canales de audio.

mapa_de_canales

Un mapa de canales. Una lista de nombres de canales separados por comas. Los nombres de canal definidos actualmente son: left, right, mono, center, front-left, front-right, front-center, rear-center, rear-left, rear-right, lfe, subwoofer, front-left-of-center, front-right-of-center, side-left, side-right, aux0, aux1 hasta aux15, top-center, top-front-left, top-front-right, top-front-center, top-rear-left, top-rear-right, top-rear-center

propiedades_sink, propiedades_source

Establece propiedades adicionales del sink/source. Por ejemplo, puede establecer la descripción directamente cuando se carga el módulo estableciendo este parámetro.

load-module module-alsa-sink sink_name=headphones sink_properties=device.description=Headphones
