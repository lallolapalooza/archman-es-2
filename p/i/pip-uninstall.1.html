NOMBRE

pip-uninstall - descripción del comando pip uninstall

DESCRIPCIÓN

Desinstala paquetes.

pip es capaz de desinstalar la mayoría de los paquetes instalados. Las excepciones conocidas son:

  • Paquetes puramente distutils instalados con python setup.py install, que no dejan metadatos para determinar qué archivos fueron instalados.
  • Envoltorios de script instalados por python setup.py develop.

USO

python -m pip uninstall [opciones] <paquete> ...
python -m pip uninstall [opciones] -r <archivo de requisitos> ...

OPCIONES

-r, --requirement <archivo>
Desinstala todos los paquetes listados en el archivo de requisitos dado. Esta opción puede usarse varias veces.

(variable de entorno: PIP_REQUIREMENT)

-y, --yes
No pedir confirmación de las eliminaciones de desinstalación.

(variable de entorno: PIP_YES)

--root-user-action <accion_usuario_root>
Acción si pip se ejecuta como usuario root [warn, ignore] (predeterminado: warn)

(variable de entorno: PIP_ROOT_USER_ACTION)

--break-system-packages
Permite a pip modificar una instalación de Python EXTERNAMENTE_GESTIONADA

(variable de entorno: PIP_BREAK_SYSTEM_PACKAGES)
