NOMBRE

pip-search - descripción del comando pip search

DESCRIPCIÓN

Busca paquetes de PyPI cuyo nombre o resumen contenga <consulta>.

USO

python -m pip search [opciones] <consulta>

OPCIONES

-i, --index <url>
URL base del Índice de Paquetes de Python (predeterminado https://pypi.org/pypi)

(variable de entorno: PIP_INDEX)
