pidpersec.bt(8) Manual del Administrador del Sistema pidpersec.bt(8)

NOMBRE

pidpersec.bt - Cuenta procesos nuevos (vía fork()). Usa bpftrace/eBPF.

SINOPSIS

pidpersec.bt

DESCRIPCIÓN

pidpersec muestra cuántos procesos nuevos se crearon por segundo. Puede haber problemas de rendimiento causados por muchos procesos de corta duración, que pueden no ser visibles en herramientas de muestreo como top(1). pidpersec proporciona una forma de investigar este comportamiento.

Esto se hace rastreando el punto de rastreo:sched:sched_process_fork.

Dado que esto usa BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Contar procesos nuevos, imprimiendo resúmenes por segundo hasta que se presiona Ctrl-C:
# pidpersec.bt

CAMPOS

1ro
Conteo de procesos (después de "@")

SOBRECARGA

Esto rastrea las bifurcaciones del kernel y mantiene un conteo en el kernel que se lee de forma asíncrona desde el espacio de usuario. Como se espera que la tasa de esto sea generalmente baja (<< 1000/s), también se espera que la sobrecarga sea insignificante.

FUENTE

Esto es de bpftrace.

https://github.com/bpftrace/bpftrace

Busque también en la distribución de bpftrace un archivo acompañante _examples.txt que contenga ejemplos de uso, salida y comentarios para esta herramienta.

Esta es una versión de bpftrace de la herramienta bcc del mismo nombre. La herramienta bcc puede ofrecer más opciones y personalizaciones.

https://github.com/iovisor/bcc
