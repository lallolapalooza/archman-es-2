NOMBRE

pianobar - reproductor de música de consola para pandora.com

SINOPSIS

pianobar

DESCRIPCIÓN

pianobar es un reproductor de música ligero para la consola para la radio en línea personalizada pandora.com.

ARCHIVOS

$XDG_CONFIG_HOME/pianobar/config o ~/.config/pianobar/config

Archivo de configuración por usuario. Ver CONFIGURACIÓN.

/etc/libao.conf o ~/.libao

Configuración de salida de audio global/por usuario. Ver la documentación de libao en http://xiph.org/ao/doc/config.html

CONFIGURACIÓN

El archivo de configuración consiste en líneas simples de clave = valor, cada una terminada con un carácter de nueva línea (\n). Las claves distinguen entre mayúsculas y minúsculas.

Las claves act_* controlan los atajos de teclado de pianobar. Cada carácter de un byte, excepto \x00 y el valor especial disabled, es permitido aquí.

act_help = ?
Muestra los atajos de teclado.
act_songlove = +
Da "me gusta" a la canción reproducida actualmente.
act_songban = -
Bloquea la canción actual. No se reproducirá de nuevo y solo se puede eliminar usando la interfaz web de pandora.com.
act_stationaddmusic = a
Añade más música a la estación actual. Se te pedirá una cadena de búsqueda. Simplemente sigue las instrucciones. Si no tienes ni idea, prueba con '?' (sin comillas).
act_bookmark = b
Marca la canción o el artista actual como favorito.
act_stationcreate = c
Crea una nueva estación. Debes introducir una cadena de búsqueda y seleccionar la canción o el artista de tu elección.
act_stationdelete = d
Elimina la estación actual.
act_songexplain = e
Explica por qué se está reproduciendo esta canción.
act_stationaddbygenre = g
Añade una estación de género proporcionada por Pandora.
act_history = h
Muestra el historial.
act_songinfo = i
Imprime información sobre la canción/estación reproducida actualmente.
act_addshared = j
Añade una estación compartida por ID. El ID es un entero muy largo sin "sh" al principio.
act_managestation = =
Elimina semillas o comentarios de canciones/artistas.
act_songnext = n
Salta la canción actual.
act_songpause = S
Pausa la reproducción.
act_songpausetoggle = p
act_songpausetoggle2 = <Espacio>
Pausa/reanuda la reproducción.
act_songplay = P
Reanuda la reproducción.
act_quit = q
Sale de pianobar.
act_stationrename = r
Renombra la estación reproducida actualmente.
act_stationchange = s
Selecciona otra estación. La lista de estaciones se puede filtrar como la mayoría de las listas introduciendo una cadena de búsqueda en lugar de un número de estación.
act_songtired = t
Bloquea la canción durante un mes.
act_upcoming = u
Muestra las próximas canciones en la lista de reproducción.
act_stationcreatefromsong = v
Crea una nueva estación a partir de la canción o el artista actual.
act_stationselectquickmix = x
Selecciona estaciones de mezcla rápida (quickmix). Puedes alternar la selección con 't', seleccionar todas con 'a' o no seleccionar ninguna con 'n'.
act_voldown = (
Disminuye el volumen.
act_volreset = ^
Restablece el volumen.
act_volup = )
Aumenta el volumen.
act_settings = !
Cambia la configuración de Pandora.
at_icon = @
Reemplazo para %@ en la cadena de formato de estación. Es " @ " por defecto.
audio_quality = {high, medium, low}
Selecciona la calidad del audio.
audio_pipe = /ruta/a/fifo
Transmite audio sin procesar decodificado a una tubería (pipe) en lugar del dispositivo de audio predeterminado. Usa sample_rate para forzar una frecuencia de muestreo fija.
autoselect = {1,0}
Selecciona automáticamente el último elemento restante de una lista filtrada. Actualmente habilitado solo para la selección de estaciones.
autostart_station = stationid
Reproduce esta estación al iniciar. Puedes obtener el stationid presionando i o la tecla que hayas definido en act_songinfo.
ban_icon = </3
Icono para las canciones bloqueadas.
bind_to = {if!tunX,host!x.x.x.x,..}
Esto establece el nombre de la interfaz a usar como interfaz de red de salida. El nombre puede ser un nombre de interfaz, una dirección IP o un nombre de host. (de CURLOPT_INTERFACE)

Puede usarse como reemplazo de control_proxy en conjunción con la opción route-nopull de OpenVPN.

buffer_seconds = 5
Tamaño del búfer de audio en segundos.
ca_bundle = /etc/ssl/certs/ca-certificates.crt
Ruta al paquete de certificados CA, que contiene los certificados raíz e intermedios necesarios para validar el certificado SSL de Pandora.
control_proxy = http://usuario:contraseña@host:puerto/
Los usuarios no estadounidenses necesitan un proxy para usar pandora.com. Solo la interfaz xmlrpc utilizará este proxy. La música se transmite directamente.
decrypt_password = R=U!LH$O2B#
device = android-generic
encrypt_password = 6#26FRL$ZWD
event_command = ruta
Archivo que se ejecuta cuando ocurre un evento. Ver sección EVENTCMD
fifo = $XDG_CONFIG_HOME/pianobar/ctl
Ubicación de la tubería de control (fifo). Ver sección CONTROL REMOTO
