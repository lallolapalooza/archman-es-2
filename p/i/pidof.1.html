PIDOF(1) Manual de Comandos Generales PIDOF(1)

NOMBRE

pidof - encontrar el ID del proceso de un programa en ejecución

SINOPSIS

pidof [-s] [-c] [-q] [-w] [-x] [-o omitirpid[,...]] ... [-t] [-S separador] programa ...

DESCRIPCIÓN

Pidof encuentra los id's de proceso (pids) de los programas nombrados. Los imprime en la salida estándar.

OPCIONES

-s
Single shot (un solo disparo) - esto instruye al programa para que devuelva solo un pid.
-c
Solo devuelve los id's de proceso que se están ejecutando con el mismo directorio raíz. Esta opción se ignora para los usuarios que no son root, ya que no podrán verificar el directorio raíz actual de los procesos que no poseen.
-q
Modo silencioso, suprime cualquier salida y solo establece el estado de salida en consecuencia.
-w
Mostrar también procesos que no tienen línea de comandos visible (por ejemplo, hilos de trabajo del kernel).
-x
Scripts también - esto hace que el programa devuelva también los id's de proceso de los shells que ejecutan los scripts nombrados.
-o omitirpid
Le dice a pidof que omita los procesos con ese id de proceso. El id especial de proceso %PPID se puede usar para nombrar el proceso padre del programa pidof, en otras palabras, el shell o script de shell que lo llama.
-t
Muestra todos los id's de hilo en lugar de pids.
-S separador
Usa separador como separador entre los pids. Se usa solo cuando se imprimen más de un pid para el programa. La opción -d es un alias para esta opción para compatibilidad con el pidof de sysvinit.

ESTADO DE SALIDA

0
Se encontró al menos un programa con el nombre solicitado.
1
No se encontró ningún programa con el nombre solicitado.

ERRORES

Al usar la opción -x, pidof solo tiene un método simple para detectar scripts y omitirá scripts que, por ejemplo, usen env. Esta limitación se debe a cómo se ven los scripts en el sistema de archivos proc.

VER TAMBIÉN

pgrep(1), pkill(1)
