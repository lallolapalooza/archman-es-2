NOMBRE

pip-debug - descripción del comando pip debug

DESCRIPCIÓN

Muestra información de depuración.

USO

python -m pip debug <opciones>

Advertencia:

Este comando solo está destinado a la depuración. Sus opciones y salidas son provisionales y pueden cambiar sin previo aviso.

OPCIONES

--platform <plataforma>
Solo utiliza wheels compatibles con <plataforma>. Por defecto, usa la plataforma del sistema en ejecución. Utiliza esta opción varias veces para especificar varias plataformas compatibles con el intérprete de destino.

(variable de entorno: PIP_PLATFORM)

--python-version <version_python>
La versión del intérprete Python a utilizar para las comprobaciones de compatibilidad de wheels y "Requires-Python". Por defecto, usa una versión derivada del intérprete en ejecución. La versión se puede especificar utilizando hasta tres enteros separados por puntos (por ejemplo, "3" para 3.0.0, "3.7" para 3.7.0 o "3.7.3"). Una versión mayor-menor también puede darse como una cadena sin puntos (por ejemplo, "37" para 3.7.0).

(variable de entorno: PIP_PYTHON_VERSION)

--implementation <implementacion>
Solo utiliza wheels compatibles con la implementación de Python <implementacion>, por ejemplo, 'pp', 'jy', 'cp' o 'ip'. Si no se especifica, se utiliza la implementación del intérprete actual. Usa 'py' para forzar wheels independientes de la implementación.

(variable de entorno: PIP_IMPLEMENTATION)

--abi <abi>
Solo utiliza wheels compatibles con la abi de Python <abi>, por ejemplo, 'pypy_41'. Si no se especifica, se utiliza la etiqueta abi del intérprete actual. Utiliza esta opción varias veces para especificar múltiples abis compatibles con el intérprete de destino. Generalmente, necesitarás especificar --implementation, --platform y --python-version al usar esta opción.

(variable de entorno: PIP_ABI)
