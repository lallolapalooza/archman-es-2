NOMBRE

pius-party-worksheet - Generador de Hojas de Trabajo para Fiestas PIUS (PGP Individual UID Signer)

SINOPSIS

pius-party-worksheet [opciones] <keyring> > outfile.html

DESCRIPCIÓN

pius-party-worksheet es una pequeña utilidad para generar una hoja de trabajo para una fiesta de firma de claves. A los asistentes les resultará más fácil y rápido verificar claves e identidades usando esta hoja. Pueden usarla como guía para firmar claves después de la fiesta.

OPCIONES

-e, --extra-fields [CAMPO, ... ]
Lista de columnas adicionales separadas por comas. Útil si algunos participantes planean hacer algo adicional, como S/MIME o verificación de certificados CA.
-h, --help
Mostrar este mensaje de ayuda y salir.
-v, --version
Mostrar el número de versión del programa y salir.
