PIPE(3P) Manual de Programador POSIX PIPE(3P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pipe — crear un canal entre procesos

SINOPSIS

#include <unistd.h>
int pipe(int fildes[2]);

DESCRIPCIÓN

La función pipe() creará una tubería y colocará dos descriptores de archivo, uno en cada uno de los argumentos fildes[0] y fildes[1], que hacen referencia a las descripciones de archivo abiertas para los extremos de lectura y escritura de la tubería. Los descriptores de archivo se asignarán según se describe en la Sección 2.14, Asignación de Descriptores de Archivo. Las banderas O_NONBLOCK y FD_CLOEXEC estarán limpias en ambos descriptores de archivo. (La función fcntl() puede usarse para establecer ambas banderas).

Los datos se pueden escribir en el descriptor de archivo fildes[1] y leer desde el descriptor de archivo fildes[0]. Una lectura en el descriptor de archivo fildes[0] accederá a los datos escritos en el descriptor de archivo fildes[1] en orden de llegada (primero en entrar, primero en salir). No se especifica si fildes[0] también está abierto para escritura y si fildes[1] también está abierto para lectura.

Un proceso tiene la tubería abierta para lectura (respectivamente, escritura) si tiene un descriptor de archivo abierto que hace referencia al extremo de lectura, fildes[0] (extremo de escritura, fildes[1]).

El ID de usuario de la tubería se establecerá en el ID de usuario efectivo del proceso que llama.

El ID de grupo de la tubería se establecerá en el ID de grupo efectivo del proceso que llama.

Al completarse con éxito, pipe() marcará para actualización las marcas de tiempo del último acceso a datos, última modificación de datos y último cambio de estado del archivo de la tubería.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0; de lo contrario, se devolverá -1 y se establecerá errno para indicar el error, no se asignarán descriptores de archivo y el contenido de fildes quedará sin modificar.

ERRORES

La función pipe() fallará si:

EMFILE
Todos, o todos menos uno, de los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
El número de archivos abiertos simultáneamente en el sistema superaría un límite impuesto por el sistema.

EJEMPLOS

Uso de una Tubería para Pasar Datos entre un Proceso Padre y un Proceso Hijo

El siguiente ejemplo demuestra el uso de una tubería para transferir datos entre un proceso padre y un proceso hijo. Se excluye el manejo de errores, pero de lo contrario, este código demuestra buenas prácticas al usar tuberías: después de fork(), los dos procesos cierran los extremos no utilizados de la tubería antes de comenzar a transferir datos.

#include <stdlib.h>
#include <unistd.h>
...
int fildes[2];
const int BSIZE = 100;
char buf[BSIZE];
ssize_t nbytes;
int status;
status = pipe(fildes);
if (status == -1 ) {
    /* ocurrió un error */
    ...
}
switch (fork()) {
case -1: /* Manejar error */
    break;
case 0:  /* Hijo - lee de la tubería */
    close(fildes[1]);                       /* El extremo de escritura no se usa */
    nbytes = read(fildes[0], buf, BSIZE);   /* Obtener datos de la tubería */
    /* En este punto, una lectura adicional vería fin de archivo ... */
    close(fildes[0]);                       /* Terminado con la tubería */
    exit(EXIT_SUCCESS);
default:  /* Padre - escribe en la tubería */
    close(fildes[0]);                       /* El extremo de lectura no se usa */
    write(fildes[1], "Hello world\n", 12);  /* Escribir datos en la tubería */
    close(fildes[1]);                       /* El hijo verá EOF */
    exit(EXIT_SUCCESS);
}

Ninguno.

FUNDAMENTO

La redacción evita cuidadosamente el uso del verbo ``abrir'' para evitar cualquier implicación de uso de open(); véase también write().
