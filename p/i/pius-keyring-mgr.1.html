NOMBRE

pius-keyring-mgr - Gestor de anillos de claves PIUS (Firmante de UID PGP Individual)

SINOPSIS

pius-keyring-mgr <modo> [opciones]

DESCRIPCIÓN

pius-keyring-mgr tiene varios modos para gestionar anillos de claves. Fue diseñado para fiestas de firma, pero puede ser utilizado para cualquier anillo de claves PGP. El modo debe ser el primer argumento, con las opciones explicadas a continuación.

OPCIONES

-d, --debug
Habilitar salida de depuración.
-g RUTA, --gpg-path=RUTA
Ruta al binario de gpg. [por defecto: /usr/bin/gpg2]
-r ANILLO-CLAVES, --keyring=ANILLO-CLAVES
Usar este anillo de claves.
-v, --verbose
Imprimir resúmenes.

MODOS

El modo build se usa la mayor parte del tiempo. Puede analizar un archivo CSV, buscar claves automáticamente y enviar correos electrónicos a cualquiera cuya clave no se haya encontrado. Este modo también puede importar claves de un archivo mbox. Las opciones son:

-b ARCHIVO-MBOX, --mbox-file=ARCHIVO-MBOX
Analizar ARCHIVO-MBOX y examinar cada mensaje en busca de huellas digitales PGP o claves en formato ascii-armored. Decodifica los mensajes según sea necesario.
-c ARCHIVO-CSV, --csv-file=ARCHIVO-CSV
Analizar ARCHIVO-MBOX e importar claves. Casi con toda seguridad también querrás usar -D, -E, -F y -N.
-D DELIMITADOR, --delimiter=DELIMITADOR
Delimitador de campo a usar al analizar CSV. Solo tiene sentido con -c. [por defecto: ',']
-E COLUMNA-EMAIL, --email-field=COLUMNA-EMAIL
Número de columna con la dirección de correo electrónico en el archivo CSV. Solo tiene sentido con -c. [por defecto: 3]
-F COLUMNA-HUella, --fp-field=COLUMNA-HUella
Número de columna con la huella digital GPG en el archivo CSV. Solo tiene sentido con -c. [por defecto: 4]
-m EMAIL-REMITENTE, --mail=EMAIL-REMITENTE
Enviar correos electrónicos a las personas cuyas claves no se encontraron, usando EMAIL-REMITENTE como remitente.
-M ARCHIVO, --mail-text=ARCHIVO
Usar el texto en ARCHIVO como cuerpo del correo electrónico al enviar correos en lugar del texto por defecto. Para ver el texto por defecto usa --print-default-email. Requiere -m.
-N COLUMNA-NOMBRE, --name-field=COLUMNA-NOMBRE
Número de columna con el nombre en el archivo CSV. Solo tiene sentido con -c. [por defecto: 2]
-n EMAIL-DESTINATARIO, --override-email=EMAIL-DESTINATARIO
En lugar de enviar al usuario, enviar a esta dirección. Principalmente útil para depuración.
-p NOMBRE-EVENTO, --party=NOMBRE-EVENTO
El nombre del evento. Se imprimirá en el correo electrónico enviado. Solo útil con -m.
-s SERVIDOR-CLAVES, --keyservers=SERVIDOR-CLAVES
Intentar con este servidor de claves. Especificar una vez por cada servidor (-s foo -s bar). [por defecto: pool.sks-keyservers.net, pgp.mit.edu, keys.gnupg.net]
-t DIR-TEMPORAL, --tmp-dir=DIR-TEMPORAL
Directorio donde poner archivos temporales. [por defecto: /tmp/pius_keyring_mgr_tmp]
-T, --print-default-email
Imprimir el correo electrónico por defecto.
--ignore-emails=IGNORAR-EMAILS
Lista separada por comas de correos electrónicos a ignorar (sin espacios).
--ignore-fingerprints=IGNORAR-HUELLAS
Lista separada por comas de huellas digitales PGP a ignorar (sin espacios).

El modo prune abre un anillo de claves y, para cada clave, pregunta si se desea eliminarla. Útil después de un evento para recortar un anillo de claves de personas que no asistieron, y antes de distribuir el anillo de claves a quienes sí lo hicieron. No tiene opciones.

El modo raw pasa las opciones directamente a gpg. Útil al añadir claves manualmente. Tus opciones se añaden a las necesarias para trabajar de forma segura en el anillo de claves del evento. (No carga tu anillo de claves personal.) Tus opciones deben pasarse después de '--' para evitar que pius-keyring-manager las interprete como propias.

EJEMPLOS

Escanear un archivo CSV y un MBOX en busca de correos electrónicos y escribir a cualquiera cuya clave no se encontró, usando you@company.com como remitente:

/usr/bin/pius-keyring-mgr build --csv-file /tmp/report --mbox-file
/tmp/mbox --mail you@company.com

Descargar una clave y añadirla al anillo de claves del evento:

pius-keyring-mgr raw -r path/to/keyring.gpg -- --recv-key <keyid>
