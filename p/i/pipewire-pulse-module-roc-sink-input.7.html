NOMBRE

pipewire-pulse-module-roc-sink-input - ROC Sink Input

NOMBRE DEL MÓDULO

module-roc-sink-input

OPCIONES DEL MÓDULO

  • sink: nombre para el sink
  • sink_input_properties: propiedades para el sink_input
  • resampler_profile: empty>|high|medium|low
  • fec_code: empty>|disable|rs8m|ldpc
  • sess_latency_msec: latencia de red objetivo en milisegundos
  • local_ip: IP local del receptor
  • local_source_port: puerto local del receptor para paquetes de origen
  • local_repair_port: puerto local del receptor para paquetes de reparación
  • local_control_port: puerto local del receptor para paquetes de control
