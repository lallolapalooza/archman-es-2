NOMBRE

pigeonhole - Resumen del soporte de Pigeonhole Sieve para Dovecot

DESCRIPCIÓN

Pigeonhole añade soporte para el lenguaje Sieve (RFC 5228) y el protocolo ManageSieve (RFC 5804) a Dovecot (dovecot(1)).

En el sentido literal, un palomar (pigeonhole) es un agujero o hueco dentro de un palomar para que aniden las palomas. Sin embargo, también es el nombre de uno de una serie de compartimentos pequeños y abiertos en un archivador utilizado para archivar o clasificar correo. Como verbo, describe el acto de colocar un elemento en uno de esos palomares. Por lo tanto, el nombre "Pigeonhole" describe bien una parte importante de la funcionalidad que añade a Dovecot: clasificar y archivar mensajes de correo electrónico.

El lenguaje Sieve se utiliza para especificar cómo se deben procesar los correos electrónicos. Al escribir scripts Sieve, los usuarios pueden personalizar cómo se entregan los mensajes, por ejemplo, si se reenvían o se almacenan en carpetas especiales. Los mensajes no deseados pueden ser descartados o rechazados, y cuando el usuario no está disponible, el intérprete Sieve puede enviar una respuesta automática. Por encima de todo, el lenguaje Sieve está destinado a ser simple, extensible e independiente del sistema. Y, a diferencia de la mayoría de los otros lenguajes de scripting para filtrado de correo, no permite a los usuarios ejecutar programas arbitrarios. Esto es particularmente útil para evitar que los usuarios virtuales tengan acceso completo al almacén de correo. La intención del lenguaje es hacer imposible que los usuarios hagan algo más complejo (y peligroso) que escribir filtros de correo simples.

Utilizando el protocolo ManageSieve, los usuarios pueden cargar sus scripts Sieve de forma remota, sin necesidad de acceso directo al sistema de archivos a través de FTP o SCP. Además, un servidor ManageSieve siempre se asegura de que los scripts cargados sean válidos, evitando fallos de compilación en la entrega de correo.

Pigeonhole proporciona los siguientes elementos:

  • El plugin LDA Sieve para el Agente de Entrega Local (LDA) de Dovecot (dovecot-lda(1)) que facilita el filtrado Sieve real durante la entrega.
  • El servicio ManageSieve que implementa el protocolo ManageSieve a través del cual los usuarios pueden administrar de forma remota los scripts Sieve en el servidor.
  • Un plugin para la herramienta de línea de comandos doveadm(1) de Dovecot que añade nuevos comandos doveadm-sieve(1) para la gestión del filtrado Sieve.
  • El plugin de documentación imap-sieve, que proporciona la capacidad de adjuntar scripts Sieve que se ejecutan para eventos IMAP en sus buzones.
  • La documentación del plugin imap-filter-sieve que permite refiltrar correos en un buzón utilizando scripts Sieve.

La funcionalidad y configuración del plugin LDA Sieve y el servicio ManageSieve se describen en detalle en los archivos README e INSTALL que se encuentran en el paquete Pigeonhole y en sieve.

Las siguientes herramientas de línea de comandos están disponibles fuera de doveadm:

sievec(1)

Compila scripts Sieve en una representación binaria para su posterior ejecución.

sieve-test(1)

La herramienta universal de prueba Sieve para probar el efecto de un script Sieve en un mensaje particular.

sieve-filter(1)

Filtra todos los mensajes de un buzón de origen particular a través de un script Sieve.

sieve-dump(1)

Descarga el contenido de un archivo binario Sieve para fines de depuración (de desarrollo).
