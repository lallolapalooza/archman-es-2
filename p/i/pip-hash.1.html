NOMBRE

pip-hash - descripción del comando pip hash

DESCRIPCIÓN

Calcula un hash de un archivo local de paquete.

Estos se pueden usar con --hash en un archivo de requisitos para realizar instalaciones repetibles.

USO

python -m pip hash [opciones] <archivo> ...

OPCIONES

-a, --algorithm <algoritmo>
El algoritmo de hash a utilizar: uno de sha256, sha384, sha512

(variable de entorno: PIP_ALGORITHM)
