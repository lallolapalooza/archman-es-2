PINKY(1) Comandos de usuario PINKY(1)

NOMBRE

pinky - finger ligero

SINOPSIS

pinky [OPCIÓN]... [USUARIO]...

DESCRIPCIÓN

-l
produce salida en formato largo para los USUARIOS especificados
-b
omite el directorio personal y el shell del usuario en formato largo
-h
omite el archivo de proyectos del usuario en formato largo
-p
omite el archivo plan del usuario en formato largo
-s
produce salida en formato corto, este es el valor predeterminado
-f
omite la línea de encabezados de columna en formato corto
-w
omite el nombre completo del usuario en formato corto
-i
omite el nombre completo del usuario y el host remoto en formato corto
-q
omite el nombre completo del usuario, el host remoto y el tiempo de inactividad en formato corto
--lookup
intenta canonizar nombres de host a través de DNS
--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale

Un programa 'finger' ligero; imprime información del usuario. El archivo utmp será /var/run/utmp.
