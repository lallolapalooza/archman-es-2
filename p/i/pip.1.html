PIP(1) pip PIP(1)

NOMBRE

pip - gestor de paquetes para paquetes de Python

SINOPSIS

pip <comando> [opciones]

DESCRIPCIÓN

pip es el gestor de paquetes recomendado por PyPA para paquetes de Python

OPCIONES

-h, --help
Mostrar ayuda.

(variable de entorno: PIP_HELP)

--debug
Permitir que las excepciones no controladas se propaguen fuera de la subrutina principal, en lugar de registrarlas en stderr.

(variable de entorno: PIP_DEBUG)

--isolated
Ejecutar pip en modo aislado, ignorando las variables de entorno y la configuración del usuario.

(variable de entorno: PIP_ISOLATED)

--require-virtualenv
Permitir que pip se ejecute solo en un entorno virtual; de lo contrario, salir con un error.

(variable de entorno: PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Ejecutar pip con el intérprete de Python especificado.

(variable de entorno: PIP_PYTHON)

-v, --verbose
Dar más salida. La opción es aditiva y se puede usar hasta 3 veces.

(variable de entorno: PIP_VERBOSE)

-V, --version
Mostrar la versión y salir.

(variable de entorno: PIP_VERSION)

-q, --quiet
Dar menos salida. La opción es aditiva y se puede usar hasta 3 veces (correspondientes a los niveles de registro WARNING, ERROR y CRITICAL).

(variable de entorno: PIP_QUIET)

--log <ruta>
Ruta a un registro que se añadirá de forma detallada.

(variables de entorno: PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Desactivar la solicitud de entrada.

(variable de entorno: PIP_NO_INPUT)

--keyring-provider <proveedor_keyring>
Habilitar la búsqueda de credenciales a través de la biblioteca keyring si se permite la entrada del usuario. Especificar qué mecanismo usar [auto, disabled, import, subprocess]. (por defecto: auto)

(variable de entorno: PIP_KEYRING_PROVIDER)

--proxy <proxy>
Especificar un proxy en el formato esquema://[usuario:contraseña@]servidor.proxy:puerto.

(variable de entorno: PIP_PROXY)

--retries <reintentos>
Intentos máximos para establecer una nueva conexión HTTP. (por defecto: 5)

(variable de entorno: PIP_RETRIES)

--timeout <segundos>
Establecer el tiempo de espera del socket (por defecto 15 segundos).

(variables de entorno: PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <accion>
Acción por defecto cuando una ruta ya existe: (s)witch, (i)gnore, (w)ipe, (b)ackup, (a)bort.

(variable de entorno: PIP_EXISTS_ACTION)

--trusted-host <nombre_host>
Marcar este host o par host:puerto como confiable, aunque no tenga HTTPS válido o ninguno.

(variable de entorno: PIP_TRUSTED_HOST)

--cert <ruta>
Ruta al paquete de certificados CA codificados en PEM. Si se proporciona, anula el valor por defecto. Consulte 'Verificación de certificados SSL' en la documentación de pip para obtener más información.

(variable de entorno: PIP_CERT)

--client-cert <ruta>
Ruta al certificado de cliente SSL, un solo archivo que contiene la clave privada y el certificado en formato PEM.

(variable de entorno: PIP_CLIENT_CERT)

--cache-dir <dir>
Almacenar los datos de la caché en <dir>.

(variable de entorno: PIP_CACHE_DIR)

--no-cache-dir
Deshabilitar la caché.

(variable de entorno: PIP_NO_CACHE_DIR)

--disable-pip-version-check
No comprobar periódicamente PyPI para determinar si hay una nueva versión de pip disponible para descargar. Implícito con --no-index.

(variable de entorno: PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Suprimir la salida coloreada.

(variable de entorno: PIP_NO_COLOR)

--use-feature <característica>
Habilitar nueva funcionalidad, que puede ser incompatible con versiones anteriores.

(variable de entorno: PIP_USE_FEATURE)

--use-deprecated <característica>
Habilitar funcionalidad obsoleta, que se eliminará en el futuro.

(variable de entorno: PIP_USE_DEPRECATED)

--resume-retries <reintentos_reanudación>
Intentos máximos para reanudar o reiniciar una descarga incompleta. (por defecto: 5)

(variable de entorno: PIP_RESUME_RETRIES)

COMANDOS

pip-install(1)
Instalar paquetes.
pip-download(1)
Descargar paquetes.
pip-uninstall(1)
Desinstalar paquetes.
pip-freeze(1)
Mostrar paquetes instalados en formato de requisitos.
pip-lock(1)
Generar un archivo de bloqueo para los requisitos y sus dependencias.
pip-list(1)
Listar paquetes instalados.
pip-show(1)
Mostrar información sobre paquetes instalados.
pip-check(1)
Verificar que los paquetes instalados tienen dependencias compatibles.

Comandos

pip-search(1)
Buscar paquetes en PyPI.
pip-wheel(1)
Construir ruedas a partir de tus requisitos.
pip-hash(1)
Calcular hashes de archivos de paquetes.
pip-help(1)
Mostrar ayuda para los comandos de pip.
