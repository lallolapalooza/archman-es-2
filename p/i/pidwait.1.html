PGREP(1) General Commands Manual PGREP(1)

NOMBRE

pgrep, pkill, pidwait - buscar, señalar o esperar por procesos basándose en el nombre y otros atributos

SINOPSIS

pgrep [opción ...] patrón

pkill [opción ...] patrón

pidwait [opción ...] patrón

DESCRIPCIÓN

pgrep busca entre los procesos en ejecución actualmente y lista los IDs de proceso que coinciden con los criterios de selección en la salida estándar. Todos los criterios deben coincidir. Por ejemplo,

$ pgrep -u root sshd

solo listará los procesos cuyo nombre incluya sshd Y sean propiedad de root. Por otro lado,

$ pgrep -u root,daemon

listará los procesos propiedad de root O daemon.

pkill enviará la señal especificada (por defecto SIGTERM) a cada proceso en lugar de listarlos en la salida estándar.

pidwait esperará por cada proceso en lugar de listarlos en la salida estándar.

OPCIONES

-señal
--signal señal
Define la señal a enviar a cada proceso coincidente. Se puede usar el valor numérico o el nombre simbólico de la señal. En el modo pgrep o pidwait solo se puede usar la opción larga y no tiene efecto a menos que se use junto con --require-handler para filtrar a procesos con un manejador de señales en el espacio de usuario presente para una señal particular.
-c, --count
Suprime la salida normal; en su lugar imprime un recuento de los procesos coincidentes. Cuando el recuento no coincide con nada, por ejemplo, devuelve cero, el comando devolverá un valor distinto de cero. Tenga en cuenta que para pkill y pidwait, el recuento es el número de procesos coincidentes, no los procesos a los que se les envió una señal o se esperaron exitosamente.
-d, --delimiter delimitador
Establece la cadena utilizada para delimitar cada ID de proceso en la salida (por defecto, una nueva línea). (Solo pgrep).
-e, --echo
Muestra el nombre y el PID del proceso al que se le está enviando la señal. (Solo pkill).
-f, --full
El patrón normalmente solo se compara con el nombre del proceso. Cuando se activa -f, se utiliza la línea de comandos completa.
-g, --pgroup pgrp,...
Solo coincide con procesos en los grupos de procesos listados. El grupo de procesos 0 se traduce al grupo de procesos propio de pgrep, pkill o pidwait.
-G, --group gid,...
Solo coincide con procesos cuyo ID de grupo real está listado. Se puede usar el valor numérico o simbólico.
-i, --ignore-case
Compara procesos sin distinguir mayúsculas y minúsculas.
-l, --list-name
Lista el nombre del proceso además del ID del proceso. (Solo pgrep).
-a, --list-full
Lista la línea de comandos completa además del ID del proceso. (Solo pgrep).
-n, --newest
Selecciona solo los procesos coincidentes más nuevos (iniciados más recientemente).
-o, --oldest
Selecciona solo los procesos coincidentes más antiguos (iniciados menos recientemente).
-O, --older secs
Selecciona procesos más antiguos que secs.
-P, --parent ppid,...
Solo coincide con procesos cuyo ID de proceso padre está listado.
-s, --session sid,...
Solo coincide con procesos cuyo ID de sesión de proceso está listado. El ID de sesión 0 se traduce al ID de sesión propio de pgrep, pkill o pidwait.
-t, --terminal term,...
Solo coincide con procesos cuyo terminal de control está listado. El nombre del terminal debe especificarse sin el prefijo "/dev/".
-u, --euid euid,...
Solo coincide con procesos cuyo ID de usuario efectivo está listado. Se puede usar el valor numérico o simbólico.
-U, --uid uid,...
Solo coincide con procesos cuyo ID de usuario real está listado. Se puede usar el valor numérico o simbólico.
-v, --inverse
Niega la coincidencia. Esta opción se usa normalmente en el contexto de pgrep o pidwait. En el contexto de pkill, la opción corta está deshabilitada para evitar el uso accidental de la opción.
-w, --lightweight
Muestra todos los IDs de hilo en lugar de PIDs en el contexto de pgrep o pidwait. En el contexto de pkill, esta opción está deshabilitada.
-x, --exact
Solo coincide con procesos cuyos nombres (o líneas de comandos si se especifica -f) coinciden exactamente con el patrón.
-F, --pidfile archivo
Lee los PIDs del archivo. Esta opción es más útil para pkill o pidwait que para pgrep. El nombre de archivo "-" se puede usar para leer desde la entrada estándar.
-L, --logpidfile
Falla si el archivo PID (ver -F) no está bloqueado.
-r, --runstates D,R,S,Z,...
Coincide solo con procesos que coinciden con el estado del proceso.
-A, --ignore-ancestors
Ignora todos los ancestros de pgrep, pkill o pidwait. Por ejemplo, esto puede ser útil al elevar privilegios con sudo o herramientas similares.
-H, --require-handler
Coincide solo con procesos que tengan un manejador de señales en el espacio de usuario presente para la señal a enviar.
--cgroup nombre,...
Coincide con el nombre del grupo de control (cgroup) v2 proporcionado. Ver cgroups(8)
--env nombre[=valor],...
Coincide con procesos que tienen estas variables de entorno. Si el parámetro =valor no está definido, solo se compara el nombre de la variable.
--ns pid
Coincide con procesos que pertenecen a los mismos espacios de nombres. Se requiere ejecutar como root para coincidir con procesos de otros usuarios. Ver --nslist para saber cómo limitar los espacios de nombres a coincidir.
--nslist nombre,...
Coincide solo con los espacios de nombres proporcionados. Espacios de nombres disponibles: ipc, mnt, net, pid, user, uts.
-q, --queue valor
Usa sigqueue(3) en lugar de kill(2) y el argumento valor se utiliza para especificar un entero que se enviará con la señal. Si el proceso receptor ha instalado un manejador para esta señal usando el flag SA_SIGINFO para sigaction(2), entonces puede obtener estos datos a través del campo si_value de la estructura siginfo_t.
-V, --version
Muestra la información de la versión y sale.
-h, --help
Muestra la ayuda y sale.

OPERANDOS

patrón
Especifica una Expresión Regular Extendida para comparar con los nombres de proceso o las líneas de comandos.

pidwait(1) - Arch Linux man pages

NAME

pidwait - wait for a process to exit

SYNOPSIS

pidwait [-Ffhv] [-n N] [-O older] [-p pid…] [-t timeout] [-u user] [-x match…]

DESCRIPTION

The pidwait utility provides a way to wait for specific processes to exit.

It can select processes based on PID, user, or a pattern match against the command line. Once a process is selected, pidwait will wait for it to terminate.

This command can be used in shell scripts to ensure that certain processes have finished before proceeding.

OPTIONS

-f
Match against the full argument list of the process.
-F
Wait indefinitely for the selected process(es). This option supersedes the -t option.
-h
Print a help message and exit.
-n">N
Wait for the Nth matching process. By default, all matching processes are waited for.
-O">older
Wait for processes that are older than the specified time (in seconds). This option requires the process table to be in a consistent state and might fail silently if /proc is mounted with subset=pid.
-p">pid
Wait for the specified process ID (PID). This option can be specified multiple times.
-t">timeout
Wait for a maximum of timeout seconds. If the process has not exited within this time, pidwait will exit with status 1.
-u">user
Wait for processes owned by the specified user. This option can be specified multiple times.
-v
Select processes that do *not* match the given criteria.
-x">match
Match against the process name or command line (depending on -f). This option can be specified multiple times.

OPERANDS

None.

EXAMPLES

Example 1: Find the process ID of the named daemon:

$ pgrep -u root named

Example 2: Make syslog reread its configuration file:

$ pkill -HUP syslogd

Example 3: Give detailed information on all xterm processes:

$ ps -fp $(pgrep -d, -x xterm)

Example 4: Make all chrome processes run nicer:

$ renice +4 $(pgrep chrome)

Example 5: Wait for a process with a known PID to finish:

$ echo ${PID} | pidwait -F -

EXIT STATUS

0
One or more processes matched the criteria. For pkill and pidwait, one or more processes must also have been successfully signalled or waited for.
1
No processes matched or none of them could be signalled.
2
Syntax error in the command line.
3
Fatal error: out of memory etc.

NOTES

The process name used for matching is limited to the 15 characters present in the output of /proc/pid/stat. Use the -f option to match against the complete command line, /proc/pid/cmdline. Threads may not have the same process name as the parent process but will have the same command line.

The running pgrep, pkill, or pidwait process will never report itself as a match.

The -O --older option will silently fail if /proc is mounted with the subset=pid option.

BUGS

The options -n and -o and -v can not be combined. Let me know if you need to do this.

Defunct processes are reported.

pidwait requires the pidfd_open(2) system call which first appeared in Linux 5.3.
