PIP-LOCK(1) pip PIP-LOCK(1)

NOMBRE

pip-lock - descripción del comando pip lock

DESCRIPCIÓN

EXPERIMENTAL - Bloquea paquetes y sus dependencias de:

  • PyPI (y otros índices) usando especificadores de requisitos.
  • URLs de proyectos VCS.
  • Directorios de proyectos locales.
  • Archivos fuente locales o remotos.

pip también soporta el bloqueo desde "archivos de requisitos", que proporcionan una forma sencilla de especificar un entorno completo a instalar.

El archivo de bloqueo generado solo se garantiza que sea válido para la versión de python y plataforma actuales.

USO

python -m pip lock [opciones] [-e] <ruta del proyecto local> ...
python -m pip lock [opciones] <especificador de requisito> [opciones del índice de paquetes] ...
python -m pip lock [opciones] -r <archivo de requisitos> [opciones del índice de paquetes] ...
python -m pip lock [opciones] <url/ruta del archivo fuente> ...

OPCIONES

-o, --output <ruta>
Nombre del archivo de bloqueo (predeterminado=pylock.toml). Usar - para salida estándar.

(variable de entorno: PIP_OUTPUT)

-r, --requirement <archivo>
Instalar desde el archivo de requisitos dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_REQUIREMENT)

-c, --constraint <archivo>
Restringir versiones usando el archivo de restricciones dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_CONSTRAINT)

--build-constraint <archivo>
Restringir las dependencias de compilación usando el archivo de restricciones dado. Esta opción se puede usar varias veces.

(variable de entorno: PIP_BUILD_CONSTRAINT)

--no-deps
No instalar dependencias de paquetes.

(variable de entorno: PIP_NO_DEPS, PIP_NO_DEPENDENCIES)

--pre
Incluir versiones preliminares y de desarrollo. Por defecto, pip solo encuentra versiones estables.

(variable de entorno: PIP_PRE)

-e, --editable <ruta/url>
Instalar un proyecto en modo editable (es decir, modo "develop" de setuptools) desde una ruta de proyecto local o una URL VCS.

(variable de entorno: PIP_EDITABLE)

--src <directorio>
Directorio donde se descargarán los proyectos editables. El valor predeterminado en un entorno virtual es "<ruta del entorno virtual>/src". El valor predeterminado para instalaciones globales es "<directorio actual>/src".

(variable de entorno: PIP_SRC, PIP_SOURCE, PIP_SOURCE_DIR, PIP_SOURCE_DIRECTORY)

--ignore-requires-python
Ignorar la información Requires-Python.

(variable de entorno: PIP_IGNORE_REQUIRES_PYTHON)

--no-build-isolation
Deshabilitar el aislamiento al compilar una distribución fuente moderna. Las dependencias de compilación especificadas por PEP 518 deben estar ya instaladas si se utiliza esta opción.

(variable de entorno: PIP_NO_BUILD_ISOLATION)

--check-build-dependencies
Verificar las dependencias de compilación.

(variable de entorno: PIP_CHECK_BUILD_DEPENDENCIES)

-C, --config-settings <configuración>
Configuraciones a pasar al backend de compilación. Las configuraciones tienen el formato CLAVE=VALOR. Utilice múltiples opciones --config-settings para pasar múltiples claves al backend.

(variable de entorno: PIP_CONFIG_SETTINGS)

--no-binary <control_formato>
No usar paquetes binarios. Se puede proporcionar varias veces, y cada vez se añade al valor existente. Acepta tanto ":all:" para deshabilitar todos los paquetes binarios, ":none:" para vaciar el conjunto (nota los dos puntos), o uno o más nombres de paquetes separados por comas (sin dos puntos). Tenga en cuenta que algunos paquetes son difíciles de compilar y pueden fallar al instalarse cuando se utiliza esta opción en ellos.

(variable de entorno: PIP_NO_BINARY)

--only-binary <control_formato>
No usar paquetes fuente. Se puede proporcionar varias veces, y cada vez se añade al valor existente. Acepta tanto ":all:" para deshabilitar todos los paquetes fuente, ":none:" para vaciar el conjunto, o uno o más nombres de paquetes separados por comas. Los paquetes sin distribuciones binarias fallarán al instalarse cuando se utilice esta opción en ellos.

(variable de entorno: PIP_ONLY_BINARY)

--prefer-binary
Preferir paquetes binarios sobre paquetes fuente, incluso si los paquetes fuente son más recientes.

(variable de entorno: PIP_PREFER_BINARY)

--require-hashes
Requerir un hash para verificar cada requisito, para instalaciones repetibles. Esta opción se implica cuando cualquier paquete en un archivo de requisitos tiene una opción --hash.

(variable de entorno: PIP_REQUIRE_HASHES)

--progress-bar <barra_progreso>
Especifica si se debe usar la barra de progreso. En modo 'auto', --quiet suprimirá todas las barras de progreso. [auto, on, off, raw] (predeterminado: auto)

(variable de entorno: PIP_PROGRESS_BAR)

--group <[ruta:]grupo>
Instalar un grupo de dependencias con nombre desde un archivo "pyproject.toml". Si se proporciona una ruta, el nombre del archivo debe ser "pyproject.toml". Predeterminado es usar "pyproject.toml" en el directorio actual.

(variable de entorno: PIP_GROUP)

--no-clean
No limpiar los directorios de compilación.

(variable de entorno: PIP_NO_CLEAN)

pip(1) - Páginas del manual de Arch Linux

NOMBRE

pip - instalador de paquetes para Python

DESCRIPCIÓN

pip es el sistema de gestión de paquetes estándar para Python. Permite instalar y gestionar paquetes de software adicionales que no forman parte de la biblioteca estándar de Python. Estos paquetes se pueden descargar de los índices de paquetes de Python, como el Python Package Index (PyPI).

pip es fácil de usar y se integra bien con el ecosistema de Python. Se utiliza para instalar bibliotecas, marcos de trabajo y herramientas de línea de comandos.

USO

El uso básico de pip implica el uso de comandos para realizar diversas operaciones de gestión de paquetes. Aquí están algunos ejemplos comunes:

  • Instalar un paquete: pip install <nombre_del_paquete>
  • Instalar un paquete desde un archivo: pip install <ruta_al_archivo.whl o .tar.gz>
  • Desinstalar un paquete: pip uninstall <nombre_del_paquete>
  • Listar todos los paquetes instalados: pip list
  • Mostrar información sobre un paquete: pip show <nombre_del_paquete>
  • Actualizar un paquete: pip install --upgrade <nombre_del_paquete>
  • Generar un archivo de requisitos: pip freeze > requirements.txt
  • Instalar desde un archivo de requisitos: pip install -r requirements.txt

OPCIONES

pip ofrece una amplia gama de opciones para personalizar su comportamiento. Algunas opciones comunes incluyen:

  • -h, --help: Muestra un mensaje de ayuda.
  • --verbose: Muestra información detallada durante la ejecución.
  • --quiet: No muestra mensajes de registro.
  • -v, -vv, -vvv: Aumenta el nivel de detalle de los mensajes de registro.
  • --no-cache-dir: Deshabilita el uso de la caché.
  • --upgrade-strategy: Controla la estrategia de actualización de paquetes (por ejemplo, eager, only-if-needed).
  • --index-url: Especifica la URL del índice de paquetes a usar.
  • --extra-index-url: Especifica una URL de índice de paquetes adicional.
  • --trusted-host: Especifica hosts de confianza para la conexión segura.

Para obtener una lista completa de opciones, consulta la documentación oficial de pip o ejecuta pip --help.
