PIGZ(1) Manual general de comandos PIGZ(1)

NOMBRE

pigz, unpigz - comprime o descomprime archivos

SINOPSIS

pigz [ -cdfhikKlLmMnNqrRtz0..9,11 ] [ -b tamaño-bloque ] [ -p hilos ] [ -S sufijo ] [ nombre ... ]
unpigz [ -cfhikKlLmMnNqrRtz ] [ -b tamaño-bloque ] [ -p hilos ] [ -S sufijo ] [ nombre ... ]

DESCRIPCIÓN

Pigz comprime usando hilos para aprovechar múltiples procesadores y núcleos. La entrada se divide en bloques de 128 KB, cada uno comprimido en paralelo. El valor de verificación individual para cada bloque también se calcula en paralelo. Los datos comprimidos se escriben en orden en la salida, y se calcula un valor de verificación combinado a partir de los valores de verificación individuales.

El formato de datos comprimidos generado está en formato gzip, zlib o zip de entrada única utilizando el método de compresión deflate. La compresión produce flujos de datos deflate crudos parciales que son concatenados por un solo hilo de escritura y envueltos con la cabecera y el pie de página apropiados, donde el pie de página contiene el valor de verificación combinado.

Cada flujo de datos deflate crudo parcial se termina con un bloque almacenado vacío (utilizando la opción Z_SYNC_FLUSH de zlib), para finalizar ese flujo de bits parcial en un límite de bytes. Esto permite que los flujos parciales se concatenen simplemente como secuencias de bytes. Esto agrega una sobrecarga muy pequeña de cuatro a cinco bytes a la salida por cada bloque de entrada.

El tamaño de bloque de entrada predeterminado es 128K, pero puede cambiarse con la opción -b. El número de hilos de compresión se establece por defecto al número de procesadores en línea, que puede cambiarse usando la opción -p. Especificar -p 1 evita el uso de hilos por completo.

Los bloques de entrada, aunque comprimidos de forma independiente, cargan los últimos 32K del bloque anterior como un diccionario preestablecido para preservar la efectividad de la compresión de deflate en un solo hilo. Esto se puede desactivar usando la opción -i o --independent, para que los bloques puedan descomprimirse de forma independiente para la recuperación parcial de errores o para acceso aleatorio. Esto también inserta un bloque vacío adicional para marcar los bloques independientes, prefijando cada uno con la secuencia de nueve bytes (en hexadecimal): 00 00 FF FF 00 00 00 FF FF.

La descompresión no se puede paralelizar, al menos no sin flujos de datos deflate especialmente preparados para ese propósito. Como resultado, pigz utiliza un solo hilo (el hilo principal) para la descompresión, pero creará tres hilos más para la lectura, escritura y cálculo de verificación, lo que puede acelerar la descompresión en algunas circunstancias. La descompresión paralela se puede desactivar especificando un proceso ( -dp 1 o -tp 1 ).

Todas las opciones en la línea de comandos se procesan antes de procesar cualquier nombre. Si no se proporcionan nombres en la línea de comandos, o si se proporciona "-" como nombre (pero no después de "--"), entonces la entrada se toma de stdin. Si las variables de entorno GZIP o PIGZ están configuradas, entonces las opciones se toman de sus valores antes de que se procesen las opciones de la línea de comandos, primero de GZIP, luego de PIGZ.

Los archivos comprimidos se pueden restaurar a su forma original usando pigz -d o unpigz.

OPCIONES

-# --fast --best
Regula la velocidad de compresión usando el dígito especificado #, donde -1 o --fast indica el método de compresión más rápido (menos compresión) y -9 o --best indica el método de compresión más lento (mejor compresión). -0 es sin compresión. -11 proporciona un porcentaje mayor de compresión con un costo severo en tiempo de ejecución, utilizando el algoritmo zopfli de Jyrki Alakuijala. El valor predeterminado es -6.
-A --alias xxx
Usa xxx como nombre para cualquier entrada --zip desde stdin (el nombre predeterminado es "-").
-b --tamaño-bloque mmm
Establece el tamaño de bloque de compresión a mmmK (predeterminado 128KiB).
-c --stdout --a-stdout
Escribe toda la salida procesada a stdout (no la elimina).
-C --comentario ccc
Incluye el comentario proporcionado en la cabecera gzip o en la cabecera del archivo central zip.
-d --decomprimir --descomprimir
Descomprime la entrada comprimida.
-f --forzar
Forzar sobrescritura, comprimir .gz, enlaces y a la terminal.
-h --ayuda
Muestra una pantalla de ayuda y sale.
-H --huffman
Comprime usando la estrategia solo Huffman.
-i --independiente
Comprime bloques independientemente para recuperación de daños.
-k --conservar
No elimina el archivo original después del procesamiento.
-K --zip
Comprime en formato zip de entrada única PKWare (.zip).
-l --listar
Lista el contenido de la entrada comprimida.
-L --licencia
Muestra la licencia de pigz y sale.
-m --sin-tiempo
No almacena ni restaura la hora de modificación. -Nm almacenará o restaurará el nombre, pero no la hora de modificación. Tenga en cuenta que el orden de las opciones es importante.
-M --tiempo
Almacena o restaura la hora de modificación. -nM almacenará o restaurará la hora de modificación, pero no el nombre. Tenga en cuenta que el orden de las opciones es importante. Las horas de modificación solo se almacenan para archivos regulares, no para tuberías.
-n --sin-nombre
No almacena ni restaura el nombre del archivo ni la hora de modificación. Esto es lo predeterminado al descomprimir. Cuando el nombre del archivo no se restaura de la cabecera, el nombre del archivo comprimido con el sufijo eliminado es el nombre del archivo descomprimido. Cuando la hora de modificación no se restaura de la cabecera, se utiliza la hora de modificación del archivo comprimido (no la hora actual).
-N --nombre
Almacena o restaura tanto el nombre del archivo como la hora de modificación. Esto es lo predeterminado al comprimir.
-p --procesos n
Permite hasta n procesos (el predeterminado es el número de procesadores en línea)
-q --silencioso
No imprime mensajes, ni siquiera en caso de error.
-r --recursivo
Procesa el contenido de todos los subdirectorios.
-R --rsyncable
Ubicaciones de bloque determinadas por la entrada para rsync.
-S --sufijo .sss
Usa el sufijo .sss en lugar de .gz (para compresión).
-t --test
Prueba la integridad de la entrada comprimida.
-U --rle
Comprime usando la estrategia de codificación por longitud de repetición.
-v --verbose
Proporciona una salida más detallada.
-V --version
Muestra la versión de pigz. -vV también muestra la versión de zlib.
-z --zlib
Comprime en formato zlib (.zz) en lugar de gzip.
--
Todos los argumentos después de "--" se tratan como nombres de archivo (para nombres que comienzan con "-")
Estas opciones son exclusivas del nivel de compresión -11:
-F --primero
Realiza las iteraciones primero, antes de la división del bloque (el predeterminado es al final).
-I, --iteraciones n
Número de iteraciones para la optimización (predeterminado 15).
-J, --maxsplits n
Número máximo de bloques divididos (predeterminado 15).
-O --unbloque
No dividir en bloques más pequeños (el predeterminado es la división de bloques).
