NOMBRE

pipewire-pulse.conf - pipewire-pulse.conf

DESCRIPCIÓN

El archivo de configuración del servidor Pulseaudio de PipeWire

SINOPSIS

$XDG_CONFIG_HOME/pipewire/pipewire-pulse.conf

/etc/pipewire/pipewire-pulse.conf

/usr/share/pipewire/pipewire-pulse.conf

/usr/share/pipewire/pipewire-pulse.conf.d/

/etc/pipewire/pipewire-pulse.conf.d/

$XDG_CONFIG_HOME/pipewire/pipewire-pulse.conf.d/

DESCRIPCIÓN

Configuración del demonio compatible con PulseAudio de PipeWire.

El formato del archivo de configuración y la lógica de búsqueda son los mismos que para pipewire.conf(5).

Se pueden utilizar archivos de configuración de inclusión directa pipewire-pulse.conf.d/*.conf, y se recomiendan. Consulte pipewire.conf(5).

SECCIONES DEL ARCHIVO DE CONFIGURACIÓN

stream.properties

Diccionario. Estas propiedades configuran las propiedades del servidor Pulseaudio de PipeWire.

stream.rules

Diccionario. Estas propiedades configuran las propiedades del servidor Pulseaudio de PipeWire.

pulse.properties

Diccionario. Estas propiedades configuran las propiedades del servidor Pulseaudio de PipeWire.

pulse.cmd

Matriz de diccionarios. Un conjunto de comandos que se ejecutarán al inicio.

pulse.rules

Matriz de diccionarios. Un conjunto de reglas de coincidencia y acciones a aplicar a los clientes.

Consulte libpipewire-module-protocol-pulse(7) para obtener una descripción detallada.

Además, también se pueden especificar las secciones de configuración del contexto de PipeWire, consulte pipewire.conf(5).

PROPIEDADES DE STREAM

La sección stream.properties contiene propiedades para los streams creados por el servidor pipewire-pulse.

Las opciones disponibles se describen en pipewire-client.conf(5) stream.properties.

Algunas de estas propiedades se corresponden con las entradas de configuración de PulseAudio /etc/pulse/default.pa de la siguiente manera:

PulseAudio PipeWire Notas remixing-use-all-sink-channels channelmix.upmix remixing-produce-lfe channelmix.lfe-cutoff Establecer a > 0 para habilitar remixing-consume-lfe channelmix.mix-lfe lfe-crossover-freq channelmix.lfe-cutoff

Ejemplo

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
stream.properties = {
    #node.latency = 1024/48000
    #node.autoconnect = true
    #resample.disable = false
    #resample.quality = 4
    #monitor.channel-volumes = false
    #channelmix.disable = false
    #channelmix.min-volume = 0.0
    #channelmix.max-volume = 10.0
    #channelmix.normalize = false
    #channelmix.mix-lfe = true
    #channelmix.upmix = true
    #channelmix.upmix-method = psd  # none, simple
    #channelmix.lfe-cutoff = 150.0
    #channelmix.fc-cutoff = 12000.0
    #channelmix.rear-delay = 12.0
    #channelmix.stereo-widen = 0.0
    #channelmix.hilbert-taps = 0
    #dither.noise = 0
    #dither.method = none # rectangular, triangular, triangular-hf, wannamaker3, shaped5
    #debug.wav-path = ""
}

REGLAS DE STREAM

La sección stream.rules funciona igual que pipewire-client.conf(5) stream.rules.

PROPIEDADES DE PULSEAUDIO

Para la sección pulse.properties, consulte libpipewire-module-protocol-pulse(7) para ver las opciones disponibles.

REGLAS DE PULSEAUDIO

Para cada cliente, se pueden escribir un conjunto de reglas en la sección pulse.rules para configurar peculiaridades del cliente o para forzar alguna configuración de stream específica de pulse.

El aspecto general de esta sección es el siguiente y sigue el diseño de **reglas de coincidencia, consulte pipewire(1)**.

Consulte libpipewire-module-protocol-pulse(7) para ver las opciones disponibles.

Ejemplo

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.rules = [
    {
        # skype no quiere usar dispositivos que no tengan un formato de muestra S16.
        matches = [
             { application.process.binary = "teams" }
             { application.process.binary = "teams-insiders" }
             { application.process.binary = "skypeforlinux" }
        ]
        actions = { quirks = [ force-s16-info ] }
    }
    {
        # speech dispatcher pide una latencia demasiado pequeña y luego se desborda.
        matches = [ { application.name = "~speech-dispatcher*" } ]
        actions = {
            update-props = {
                pulse.min.req          = 1024/48000     # 21ms
                pulse.min.quantum      = 1024/48000     # 21ms
            }
        }
    }
]

COMANDOS DE PULSEAUDIO

Como parte del procedimiento de inicio del servidor, puede ejecutar algunos comandos adicionales con la sección pulse.cmd en pipewire-pulse.conf.

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.cmd = [
    { cmd = "load-module" args = "module-always-sink" flags = [ ] }
    { cmd = "load-module" args = "module-switch-on-connect" }
    { cmd = "load-module" args = "module-gsettings" flags = [ "nofail" ] }
]
...

También se pueden ejecutar comandos adicionales a través de la sección context.exec, consulte pipewire.conf(5).

Comandos compatibles:

load-module

Carga el módulo Pulseaudio especificado al inicio, como si se usara pactl(1) para cargar el módulo.

MÓDULOS DE PULSEAUDIO

Para el contenido de la sección pulse.modules, consulte pipewire-pulse-modules(7).
