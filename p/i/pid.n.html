NOMBRE

pid - Recuperar identificadores de procesos

SINOPSIS

pid ?fileId?

DESCRIPCIÓN

Si se proporciona el argumento fileId, normalmente debería referirse a una tubería de procesos creada con el comando open. En este caso, el comando pid devolverá una lista cuyos elementos son los identificadores de proceso de todos los procesos de la tubería, en orden. La lista estará vacía si fileId se refiere a un archivo abierto que no es una tubería de procesos. Si no se proporciona ningún argumento fileId, pid devolverá el identificador de proceso del proceso actual. Todos los identificadores de proceso se devuelven como cadenas decimales.

EJEMPLO

Imprimir información de procesos sobre los procesos de una tubería utilizando el programa ps de SysV antes de leer la salida de esa tubería:

set pipeline [open "| zcat somefile.gz | grep foobar | sort -u"]
# Imprimir información de procesos
exec ps -fp [pid $pipeline] >@stdout
# Imprimir un separador y luego la salida de la tubería
puts [string repeat - 70]
puts [read $pipeline]
close $pipeline
