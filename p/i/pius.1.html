PIUS(1) Manual de comandos generales PIUS(1)

NOMBRE

pius - Firmador individual de UIDs de PGP

SINOPSIS

pius [opciones] -s <keyid-firmante> <keyid> [ <keyid> ... ]
pius [opciones] -A -r <ruta-keyring> -s <keyid-firmante>

DESCRIPCIÓN

pius es una herramienta para firmar individualmente todos los UIDs en un conjunto de claves, y enviar por correo electrónico una copia cifrada de cada firma a la dirección de correo electrónico asociada con dicho UID.

Como resultado de este proceso, el destinatario puede elegir qué firmas importar. Además, las firmas de UIDs inactivos no se entregan. Esta herramienta reduce en gran medida el tiempo y los errores al firmar claves.

OPCIONES

--version
mostrar el número de versión del programa y salir
-h, --help
mostrar este mensaje de ayuda y salir
-A, --all-keys
Firmar todas las claves del keyring. Requiere -r.
-d, --debug
Habilitar la salida de depuración.
-b RUTA, --gpg-path=RUTA
Ruta al binario de gpg. [por defecto: /usr/bin/gpg2]
-e, --encrypt-outfiles
Cifrar los archivos de salida con las claves respectivas.
-H NOMBREHOST, --mail-host=NOMBREHOST
Nombre del host del servidor SMTP. [por defecto: localhost]
-I, --import
También importar las claves no firmadas del keyring al keyring predeterminado. Ignorado si no se especifica -r, o si es el mismo que el keyring predeterminado.
-m EMAIL-REMITENTE, --mail=EMAIL-REMITENTE
Enviar por correo electrónico las claves cifradas y firmadas a las direcciones de correo electrónico correspondientes usando EMAIL-REMITENTE como remitente. Ver también -H y -P.
-M ARCHIVO, --mail-text=ARCHIVO
Usar el texto en ARCHIVO como cuerpo del correo electrónico al enviar correos en lugar del texto predeterminado. Para ver el texto predeterminado, usar --print-default-email. Requiere -m.
-N, --no-sort-keyring
No ordenar el keyring por nombre.
-n EMAIL-DESTINATARIO, --override-email=EMAIL-DESTINATARIO
En lugar de enviar al usuario, enviar a esta dirección. Principalmente útil para depuración.
-o DIR-SALIDA, --out-dir=DIR-SALIDA
Directorio donde colocar las claves firmadas. [por defecto: /tmp/pius_out]
-O, --no-pgp-mime
No usar PGP/Mime al enviar correo electrónico.
-P PUERTO, --mail-port=PUERTO
Puerto del servidor SMTP. [por defecto: 587]
-r KEYRING, --keyring=KEYRING
El keyring a utilizar. Asegúrate de especificar la ruta completa o relativa. Un simple nombre de archivo hará que GPG asuma que está relativo a ~/.gnupg. [por defecto: ~/.gnupg/pubring.gpg]
-s KEYID-FIRMANTE, --signer=KEYID-FIRMANTE
La keyid con la que firmar (obligatorio).
-f KEYID, --force-signer=KEYID
Forzar a GnuPG a usar esta keyid exacta para firmar (no adivinar subclave)
-S, --no-mail-tls
No usar STARTTLS al comunicarse con el servidor SMTP.
-t DIR-TEMPORAL, --tmp-dir=DIR-TEMPORAL
Directorio donde colocar archivos temporales. [por defecto: /tmp/pius_tmp]
-T, --print-default-email
Imprimir el correo electrónico predeterminado.
-u USUARIO, --mail-user=USUARIO
Autenticarse en el servidor SMTP con el nombre de usuario USUARIO. Se le pedirá la contraseña.
-U URL-POLITICA, --policy-url=URL-POLITICA
URL de política a incluir en cada firma.
-v, --verbose
Ser más detallado.
