NOMBRE

piv-tool - utilidad de tarjeta inteligente para tarjetas PIV HSPD-12

SINOPSIS

piv-tool [OPCIONES]

La utilidad piv-tool puede usarse desde la línea de comandos para realizar operaciones diversas con tarjetas inteligentes en una tarjeta PIV HSPD-12, según se define en NIST 800-73-3. Está pensada para usarse solo con tarjetas de prueba. Puede usarse para cargar objetos y generar pares de claves, así como para enviar comandos APDU arbitrarios a una tarjeta después de haberse autenticado en la tarjeta utilizando la clave de tarjeta proporcionada por el proveedor de la tarjeta.

OPCIONES

--serial

Imprime el número de serie de la tarjeta derivado del objeto CHUID, si lo hay. La salida está en formato de bytes hexadecimales.

--name, -n

Imprime el nombre de la tarjeta insertada (controlador)

--admin argumento, -A argumento

Autenticarse en la tarjeta usando una clave 2DES, 3DES o AES. Se requiere el argumento con el formato 
 {A|M}:ref:alg

donde A usa "EXTERNAL AUTHENTICATION" y M usa "MUTUAL AUTHENTICATION". ref es normalmente 9B y alg es 03 para 3DES, 01 para 2DES, 08 para AES-128, 0A para AES-192 o 0C para AES-256. La clave es proporcionada por el proveedor de la tarjeta. La variable de entorno PIV_EXT_AUTH_KEY debe apuntar a un archivo binario que coincida con la longitud de la clave o a un archivo de texto que contenga la clave en el formato: XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX

--genkey argumento, -G argumento

Genera un par de claves en la tarjeta y exporta la clave pública. Se requiere el argumento con el formato 
ref:alg

donde ref es 9A, 9C, 9D o 9E y alg es 06, 07, 11 o 14 para RSA 1024, RSA 2048, ECC 256 o ECC 384 respectivamente.

--object ContainerID, -O ContainerID

Carga un objeto en la tarjeta. El ContainerID es tal como se define en NIST 800-73-n sin el prefijo 0x. Ejemplo: el objeto CHUID es 3000

--cert ref, -C ref

Carga un certificado en la tarjeta. ref es 9A, 9C, 9D o 9E

--compresscert ref, -Z ref

Carga un certificado que ha sido comprimido con gzip en la tarjeta. ref es 9A, 9C, 9D o 9E

--out archivo, -o archivo

Archivo de salida para cualquier operación que produzca salida.

--in archivo, -i archivo

Archivo de entrada para cualquier operación que requiera un archivo de entrada.

--key-slots-discovery archivo

Imprime las propiedades de las ranuras de clave. Requiere autenticación de 'admin'.

--send-apdu apdu, -s apdu

Envía un APDU arbitrario a la tarjeta en el formato AA:BB:CC:DD:EE:FF.... Esta opción puede repetirse.

--reader arg, -r arg

Número del lector a utilizar. Por defecto, se usa el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--wait, -w

Espera a que se inserte una tarjeta

--verbose, -v

Hace que piv-tool sea más verboso. Especifique este indicador varias veces para habilitar la salida de depuración en la biblioteca opensc.
