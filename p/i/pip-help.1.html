NOMBRE

pip-help - descripción del comando de ayuda de pip

DESCRIPCIÓN

Muestra la ayuda para los comandos

USO

python -m pip help <comando>

OPCIONES

-h, --help
Muestra la ayuda.

(variable de entorno: PIP_HELP)

--debug
Permite que las excepciones no manejadas se propaguen fuera de la subrutina principal, en lugar de registrarlas en stderr.

(variable de entorno: PIP_DEBUG)

--isolated
Ejecuta pip en modo aislado, ignorando las variables de entorno y la configuración del usuario.

(variable de entorno: PIP_ISOLATED)

--require-virtualenv
Permite que pip solo se ejecute en un entorno virtual; de lo contrario, saldrá con un error.

(variable de entorno: PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Ejecuta pip con el intérprete de Python especificado.

(variable de entorno: PIP_PYTHON)

-v, --verbose
Da más información. La opción es aditiva y se puede usar hasta 3 veces.

(variable de entorno: PIP_VERBOSE)

-V, --version
Muestra la versión y sale.

(variable de entorno: PIP_VERSION)

-q, --quiet
Da menos información. La opción es aditiva y se puede usar hasta 3 veces (correspondiente a los niveles de registro WARNING, ERROR y CRITICAL).

(variable de entorno: PIP_QUIET)

--log <ruta>
Ruta a un registro detallado que se irá añadiendo.

(variable de entorno: PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Deshabilita la solicitud de entrada.

(variable de entorno: PIP_NO_INPUT)

--keyring-provider <proveedor_keyring>
Habilita la búsqueda de credenciales a través de la biblioteca keyring si se permite la entrada del usuario. Especifica qué mecanismo usar [auto, disabled, import, subprocess]. (predeterminado: auto)

(variable de entorno: PIP_KEYRING_PROVIDER)

--proxy <proxy>
Especifica un proxy en el formato esquema://[usuario:contraseña@]servidor_proxy:puerto.

(variable de entorno: PIP_PROXY)

--retries <reintentos>
Intentos máximos para establecer una nueva conexión HTTP. (predeterminado: 5)

(variable de entorno: PIP_RETRIES)

--timeout <seg>
Establece el tiempo de espera del socket (predeterminado 15 segundos).

(variable de entorno: PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <accion>
Acción predeterminada cuando una ruta ya existe: (c)ambiar, (i)gnorar, (b)orrar, (g)uardar copia, (a)bortar.

(variable de entorno: PIP_EXISTS_ACTION)

--trusted-host <nombre_host>
Marca este host o par host:puerto como confiable, aunque no tenga HTTPS válido o no tenga nada.

(variable de entorno: PIP_TRUSTED_HOST)

--cert <ruta>
Ruta al paquete de certificados CA codificados en PEM. Si se proporciona, anula el predeterminado. Consulte 'SSL Certificate Verification' en la documentación de pip para más información.

(variable de entorno: PIP_CERT)

--client-cert <ruta>
Ruta al certificado de cliente SSL, un único archivo que contiene la clave privada y el certificado en formato PEM.

(variable de entorno: PIP_CLIENT_CERT)

--cache-dir <dir>
Almacena los datos de la caché en <dir>.

(variable de entorno: PIP_CACHE_DIR)

--no-cache-dir
Deshabilita la caché.

(variable de entorno: PIP_NO_CACHE_DIR)

--disable-pip-version-check
No compruebes periódicamente PyPI para determinar si hay una nueva versión de pip disponible para descargar. Implícito con --no-index.

(variable de entorno: PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Suprime la salida de color.

(variable de entorno: PIP_NO_COLOR)

--use-feature <característica>
Habilita una nueva funcionalidad, que puede ser incompatible con versiones anteriores.

(variable de entorno: PIP_USE_FEATURE)

--use-deprecated <característica>
Habilita una funcionalidad obsoleta, que se eliminará en el futuro.

(variable de entorno: PIP_USE_DEPRECATED)

--resume-retries <reintentos_continuar>
Intentos máximos para continuar o reiniciar una descarga incompleta. (predeterminado: 5)

(variable de entorno: PIP_RESUME_RETRIES)
