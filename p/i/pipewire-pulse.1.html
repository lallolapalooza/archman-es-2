NOMBRE

pipewire-pulse - El reemplazo de PipeWire para PulseAudio

SINOPSIS

pipewire-pulse [opciones]

DESCRIPCIÓN

pipewire-pulse inicia un demonio compatible con PulseAudio que se integra con el servidor multimedia PipeWire, ejecutando un proceso pipewire a través de un servicio systemd. Este demonio es un reemplazo directo del demonio PulseAudio.

OPCIONES

-h | --help

Muestra la ayuda.

-v | --verbose

Aumenta el nivel de verbosidad en uno. Esta opción se puede especificar varias veces.

--version

Muestra la información de la versión.

-c | --config=ARCHIVO

Carga el archivo de configuración dado (Por defecto: pipewire-pulse.conf).

VARIABLES DE ENTORNO

Se admiten las variables de entorno genéricas de pipewire(1).

Además:

PULSE_RUNTIME_PATH

XDG_RUNTIME_DIR

Directorio donde crear el socket nativo del protocolo pulseaudio.

PULSE_LATENCY_MSEC

Latencia de búfer adicional en milisegundos. Esto controla la lógica de búfer en libpulse y se puede establecer para que las aplicaciones cliente de PulseAudio ajusten su búfer. (Establecerlo en el servidor pipewire-pulse no tiene efecto.)

AUTORES

Los desarrolladores de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire está disponible en https://pipewire.org
