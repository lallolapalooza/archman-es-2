PIDSTAT(1) Manual del usuario de Linux PIDSTAT(1)

NOMBRE

pidstat - Informa estadísticas para tareas de Linux.

SINOPSIS

pidstat [ -d ] [ -H ] [ -h ] [ -I ] [ -l ] [ -R ] [ -r ] [ -s ] [ -t ] [ -U [ nombre_usuario ] ] [ -u ] [ -V ] [ -v ] [ -w ] [ -C comm ] [ -G nombre_proceso ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ -p { pid[,...] | SELF | ALL } ] [ -T { TASK | CHILD | ALL } ] [ intervalo [ conteo ] ] [ -e programa args ]

DESCRIPCIÓN

El comando pidstat se utiliza para monitorizar tareas individuales actualmente gestionadas por el kernel de Linux. Escribe en la salida estándar actividades para cada tarea seleccionada con la opción -p o para cada tarea gestionada por el kernel de Linux si se ha utilizado la opción -p ALL. No seleccionar ninguna tarea equivale a especificar -p ALL pero solo aparecerán en el informe las tareas activas (tareas con valores de estadísticas distintos de cero).

El comando pidstat también puede usarse para monitorizar los procesos hijos de las tareas seleccionadas. Lea la opción -T más abajo.

El parámetro intervalo especifica la cantidad de tiempo en segundos entre cada informe. Un valor de 0 (o ningún parámetro) indica que las estadísticas de las tareas se informarán desde el inicio del sistema (arranque). El parámetro conteo se puede especificar junto con el parámetro intervalo si este último no está establecido en cero. El valor de conteo determina el número de informes generados a intervalos de intervalo segundos. Si el parámetro intervalo se especifica sin el parámetro conteo, el comando pidstat genera informes continuamente.

Puede seleccionar información sobre actividades específicas de las tareas utilizando indicadores. No especificar ningún indicador selecciona solo la actividad de la CPU.

OPCIONES

-C comm
Mostrar solo tareas cuyo nombre de comando incluya la cadena comm. Esta cadena puede ser una expresión regular.
-d
Informar estadísticas de I/O (solo en kernels 2.6.20 y posteriores). Los siguientes valores pueden mostrarse:
UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
kB_rd/s
Número de kibibytes que la tarea ha causado a leer del disco por segundo.
kB_wr/s
Número de kibibytes que la tarea ha causado, o causará, a escribir en el disco por segundo.
kB_ccwr/s
Número de kibibytes cuya escritura en disco ha sido cancelada por la tarea. Esto puede ocurrir cuando la tarea trunca alguna página de caché sucia. En este caso, algunas E/S de las que otra tarea ha sido contabilizada no ocurrirán.
iodelay
Retraso de E/S de bloque de la tarea que se está monitorizando, medido en ticks de reloj. Esta métrica incluye los retrasos de espera para la finalización de E/S de bloque síncrona y para la finalización de E/S de bloque de swap.
Command
El nombre del comando de la tarea.
--dec={ 0 | 1 | 2 }
Especifica el número de decimales a usar (de 0 a 2, el valor por defecto es 2).
-e programa args
Ejecuta programa con los argumentos args dados y lo monitoriza con pidstat. pidstat se detiene cuando programa termina. Se debe especificar un valor distinto de cero para el parámetro intervalo.
-G nombre_proceso
Mostrar solo procesos cuyo nombre de comando incluya la cadena nombre_proceso. Esta cadena puede ser una expresión regular. Si la opción -t se usa junto con la opción -G, también se mostrarán los hilos pertenecientes a ese proceso (incluso si su nombre de comando no incluye la cadena nombre_proceso).
-H
Mostrar la marca de tiempo en segundos desde la época.
-h
Mostrar todas las actividades horizontalmente en una sola línea, sin estadísticas promedio al final del informe. Esto está destinado a facilitar el análisis por parte de otros programas.
--human
Imprimir tamaños en formato legible por humanos (p. ej., 1.0k, 1.2M, etc.). Las unidades mostradas con esta opción prevalecen sobre cualquier otra unidad por defecto (p. ej., kibibytes, sectores...) asociada con las métricas.
-I
En un entorno SMP, indicar que el uso de CPU de las tareas (mostrado con la opción -u) debe dividirse por el número total de procesadores.
-l
Mostrar el nombre del comando del proceso y todos sus argumentos.
-o JSON
Mostrar las estadísticas en formato JSON (JavaScript Object Notation). El orden de los campos de salida JSON no está definido y se pueden agregar nuevos campos en el futuro.
-p { pid[,...] | SELF | ALL }
Seleccionar tareas (procesos) para las que se deben informar las estadísticas. pid es el número de identificación del proceso. La palabra clave SELF indica que las estadísticas se deben informar para el propio proceso pidstat, mientras que la palabra clave ALL indica que las estadísticas se deben informar para todas las tareas gestionadas por el sistema.
-R
Informar la prioridad en tiempo real y la información de la política de planificación. Los siguientes valores pueden mostrarse:
UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
prio
La prioridad en tiempo real de la tarea que se está monitorizando.
policy
La política de planificación de la tarea que se está monitorizando.
Command
El nombre del comando de la tarea.
-r
Informar page faults y utilización de memoria.

Al informar estadísticas para tareas individuales, los siguientes valores pueden mostrarse:

UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
minflt/s
Número total de fallos menores que la tarea ha realizado por segundo, aquellos que no han requerido cargar una página de memoria del disco.
majflt/s
Número total de fallos mayores que la tarea ha realizado por segundo, aquellos que han requerido cargar una página de memoria del disco.
VSZ
Tamaño Virtual: El uso de memoria virtual de la tarea completa en kibibytes.
RSS
Tamaño del Conjunto Residente: La memoria física no intercambiada utilizada por la tarea en kibibytes.
%MEM
La cuota actual de memoria física disponible utilizada por la tarea.
Command
El nombre del comando de la tarea.
Al informar estadísticas globales para tareas y todos sus hijos, los siguientes valores pueden mostrarse:
UID
El número de identificación de usuario real de la tarea que se está monitorizando junto con sus hijos.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando junto con sus hijos.
PID
El número de identificación de la tarea que se está monitorizando junto con sus hijos.
minflt-nr
Número total de fallos menores cometidos por la tarea y todos sus hijos, y recopilados durante el intervalo de tiempo.
majflt-nr
Número total de fallos mayores cometidos por la tarea y todos sus hijos, y recopilados durante el intervalo de tiempo.
Command
El nombre del comando de la tarea que se está monitorizando junto con sus hijos.
-s
Informa sobre la utilización de la pila. Se pueden mostrar los siguientes valores:
UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
StkSize
La cantidad de memoria en kibibytes reservada para la tarea como pila, pero no necesariamente utilizada.
StkRef
La cantidad de memoria en kibibytes utilizada como pila, referenciada por la tarea.
Command
El nombre del comando de la tarea.
-T { TASK | CHILD | ALL }
Esta opción especifica qué debe ser monitorizado por el comando pidstat . La palabra clave TASK indica que se deben informar estadísticas para tareas individuales (esta es la opción predeterminada), mientras que la palabra clave CHILD indica que las estadísticas se informarán globalmente para las tareas seleccionadas y todos sus hijos. La palabra clave ALL indica que se deben informar estadísticas para tareas individuales y globalmente para las tareas seleccionadas y sus hijos.

Nota: Las estadísticas globales para tareas y todos sus hijos no están disponibles para todas las opciones de pidstat. Además, estas estadísticas no son necesariamente relevantes para el intervalo de tiempo actual: las estadísticas de un proceso hijo solo se recopilan cuando finaliza o se elimina.

-t
Mostrar también estadísticas para los hilos asociados con las tareas seleccionadas.

Esta opción agrega los siguientes valores a los informes:

TGID
El número de identificación del líder del grupo de hilos.
TID
El número de identificación del hilo que se está monitorizando.
-U [ username ]
Muestra el nombre de usuario real de las tareas que se están monitorizando en lugar del UID. Si se especifica username, solo se mostrarán las tareas que pertenecen al usuario especificado.
-u
Informa sobre la utilización de la CPU.

Al informar estadísticas para tareas individuales, se pueden mostrar los siguientes valores:

UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
%usr
Porcentaje de CPU utilizado por la tarea mientras se ejecuta en el nivel de usuario (aplicación), con o sin prioridad nice. Tenga en cuenta que este campo NO incluye el tiempo de ejecución de un procesador virtual.
%system
Porcentaje de CPU utilizado por la tarea mientras se ejecuta en el nivel del sistema (kernel).
%guest
Porcentaje de CPU consumido por la tarea en una máquina virtual (ejecutando un procesador virtual).
%wait
Porcentaje de CPU consumido por la tarea mientras espera para ejecutarse.
%CPU
Porcentaje total de tiempo de CPU utilizado por la tarea. En un entorno SMP, el uso de CPU de la tarea se dividirá por el número total de CPU si se ha introducido la opción -I en la línea de comandos.
CPU
Número de procesador al que está adjunta la tarea.
Command
El nombre del comando de la tarea.
Al informar estadísticas globales para tareas y todos sus hijos, se pueden mostrar los siguientes valores:
UID
El número de identificación de usuario real de la tarea que se está monitorizando junto con sus hijos.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando junto con sus hijos.
PID
El número de identificación de la tarea que se está monitorizando junto con sus hijos.
usr-ms
Número total de milisegundos que la tarea y todos sus hijos pasaron ejecutándose en el nivel de usuario (aplicación), con o sin prioridad nice, y recopilados durante el intervalo de tiempo. Tenga en cuenta que este campo NO incluye el tiempo de ejecución de un procesador virtual.
system-ms
Número total de milisegundos que la tarea y todos sus hijos pasaron ejecutándose en el nivel del sistema (kernel), y recopilados durante el intervalo de tiempo.
guest-ms
Número total de milisegundos que la tarea y todos sus hijos pasaron en una máquina virtual (ejecutando un procesador virtual).
Command
El nombre del comando de la tarea que se está monitorizando junto con sus hijos.
-V
Imprime el número de versión y sale.
-v
Informa los valores de algunas tablas del kernel. Se pueden mostrar los siguientes valores:
UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
threads
Número de hilos asociados con la tarea actual.
fd-nr
Número de descriptores de archivo asociados con la tarea actual.
Command
El nombre del comando de la tarea.
-w
Informa sobre la actividad de cambio de tareas (solo para kernels 2.6.23 y posteriores). Se pueden mostrar los siguientes valores:
UID
El número de identificación de usuario real de la tarea que se está monitorizando.
USER
El nombre del usuario real propietario de la tarea que se está monitorizando.
PID
El número de identificación de la tarea que se está monitorizando.
cswch/s
Número total de cambios de contexto voluntarios que la tarea realizó por segundo. Un cambio de contexto voluntario ocurre cuando una tarea se bloquea porque requiere un recurso que no está disponible.
nvcswch/s
Número total de cambios de contexto no voluntarios que la tarea realizó por segundo. Un cambio de contexto involuntario ocurre cuando una tarea se ejecuta durante la duración de su time slice y luego se ve obligada a ceder el procesador.
Command
El nombre del comando de la tarea.

ENTORNO

El comando pidstat tiene en cuenta las siguientes variables de entorno:

S_COLORS
Por defecto, las estadísticas se muestran en color cuando la salida está conectada a un terminal. Utilice esta variable para cambiar la configuración. Los valores posibles para esta variable son never, always o auto (este último es equivalente a la configuración predeterminada).
Tenga en cuenta que el color (ya sea rojo, amarillo o algún otro color) utilizado para mostrar un valor no indica ningún tipo de problema simplemente por el color. Solo indica diferentes rangos de valores.
S_COLORS_SGR
Especifique los colores y otros atributos utilizados para mostrar estadísticas en el terminal. Su valor es una lista de capacidades separadas por dos puntos que por defecto es I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22. Las capacidades admitidas son:
I=
Subcadena SGR (Select Graphic Rendition) para valores de elementos como PID, UID o número de CPU.
N=
Subcadena SGR para valores de estadísticas distintos de cero y para nombres de tareas.
W= (o M=)
Subcadena SGR para valores porcentuales en el rango de 75% a 90% (o en el rango de 10% a 25% dependiendo del significado de la métrica).
X= (o H=)
Subcadena SGR para valores porcentuales mayores o iguales al 90% (o menores o iguales al 10% dependiendo de la métrica

DESCRIPCIÓN

pidstat es una utilidad para recopilar y reportar estadísticas para procesos.

La información sobre los procesos es recopilada desde el sistema de archivos virtual /proc.

El comando pidstat no requiere ninguna opción para ejecutarse. Si no se especifican opciones de selección (PID, nombre de comando, UID, etc.) y no se especifica la opción -t, entonces las estadísticas para todos los procesos activos en el sistema serán mostradas.

Si no se especifica ningún contador de estadísticas (CPU, memoria, etc.) y no se especifica -t, entonces se mostrarán las estadísticas de la CPU.

El comando pidstat puede monitorear los procesos en tiempo real o puede reportar sobre un archivo de historial generado por sar.

Las estadísticas de la CPU se reportan en porcentaje de tiempo de CPU utilizado.

Las estadísticas de memoria se reportan en kilobytes (kB).

Las estadísticas de E/S de disco se reportan en bloques (1 bloque = 512 bytes).

El intervalo de tiempo entre dos reportes consecutivos es dado en segundos. El número de reportes a generar es también dado en segundos.

Cuando se le pide que reporte sobre un archivo de historial (-o), el comando pidstat leyendo el archivo hasta el final. Si el archivo de historial contiene estadísticas sobre hilos de CPU, entonces también se mostrarán las estadísticas de hilos.

OPCIONES

-a
Muestra las estadísticas de todos los procesos (por defecto, pidstat solo muestra estadísticas para procesos con el estado de CPU que no sea cero).
-A { full | process | task }
Este es el selector de modo de presentación de informes. El valor por defecto es process. El modo full mostrará estadísticas para el proceso principal y sus hijos. El modo process solo mostrará estadísticas para el proceso principal. El modo task mostrará estadísticas para el hilo principal y sus hilos.
-b
Informa sobre estadísticas de E/S de disco (lecturas/escrituras de bloques para los procesos).
-B { basic | detailed }
Este es el selector de modo de presentación de informes de memoria. El valor por defecto es basic. El modo detailed mostrará estadísticas adicionales para cada proceso, como RSS, Página de Trabajo, etc.
-c cpu_list
Especifica la lista de CPUs para las que se recopilarán las estadísticas. La lista está separada por comas y puede contener rangos. Por ejemplo, -c 0,1,4-7 seleccionará las CPUs 0, 1 y de 4 a 7.
-d
Informa sobre estadísticas de E/S de disco (lecturas/escrituras de bloques para los procesos).
-e
Informa sobre fallos de página (page faults) para los procesos.
-E ‐ --extend-field FIELD
Añade un campo extendido a la línea de informes. Los campos disponibles son: WCHAN, NOCTXT, NSIGNAL, NVCSW, OTH, CGROUP, E, PID, TID, CMD, CPU, COMMAND, RUNTIME, IORATE, MAJF, MINF, PID, USER
