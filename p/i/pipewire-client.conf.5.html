pipewire-client.conf(5) Manual de formatos de archivo pipewire-client.conf(5)

NOMBRE

pipewire-client.conf - client.conf

DESCRIPCIÓN

El archivo de configuración del cliente PipeWire.

SINOPSIS

$XDG_CONFIG_HOME/pipewire/client.conf

/etc/pipewire/client.conf

/usr/share/pipewire/client.conf

/usr/share/pipewire/client.conf.d/

/etc/pipewire/client.conf.d/

$XDG_CONFIG_HOME/pipewire/client.conf.d/

DESCRIPCIÓN

Configuración para clientes nativos de PipeWire y para el plugin ALSA de PipeWire.

Un programa cliente nativo de PipeWire selecciona la configuración predeterminada a cargar, y si no se especifica nada, normalmente carga client.conf.

El formato del archivo de configuración y la lógica de búsqueda son los mismos que para pipewire.conf(5).

Se pueden usar archivos de configuración de inclusión client.conf.d/*.conf, y se recomiendan. Ver pipewire.conf(5).

SECCIONES DE ARCHIVO DE CONFIGURACIÓN

stream.properties

Configura opciones para flujos de clientes.

stream.rules

Configura reglas para flujos de clientes.

alsa.properties

Configuración del cliente ALSA.

alsa.rules

Reglas de coincidencia del cliente ALSA.

Además, también se pueden especificar las secciones de configuración del contexto de PipeWire, ver pipewire.conf(5).

PROPIEDADES DE FLUJO

Los archivos de configuración del cliente contienen una sección stream.properties que configura las opciones para los flujos del cliente:

# ~/.config/pipewire/client.conf.d/custom.conf
stream.properties = {
    #node.latency = 1024/48000
    #node.autoconnect = true
    #resample.disable = false
    #resample.quality = 4
    #monitor.channel-volumes = false
    #channelmix.disable = false
    #channelmix.min-volume = 0.0
    #channelmix.max-volume = 10.0
    #channelmix.normalize = false
    #channelmix.lock-volume = false
    #channelmix.mix-lfe = true
    #channelmix.upmix = true
    #channelmix.upmix-method = psd  # none, simple
    #channelmix.lfe-cutoff = 150.0
    #channelmix.fc-cutoff  = 12000.0
    #channelmix.rear-delay = 12.0
    #channelmix.stereo-widen = 0.0
    #channelmix.hilbert-taps = 0
    #dither.noise = 0
    #dither.method = none # rectangular, triangular, triangular-hf, wannamaker3, shaped5
    #debug.wav-path = ""
}

Algunas de las propiedades se refieren a diferentes aspectos del flujo:

  • Propiedades generales del flujo para identificar el flujo.
  • Propiedades generales del flujo para clasificar el flujo.
  • Cómo será programado por el grafo.
  • Cómo será enlazado por el gestor de sesión.
  • Cómo se realizará el procesamiento interno.
  • Propiedades para configurar el formato multimedia.

Una lista de propiedades de objetos que se pueden aplicar a los flujos se encuentra en pipewire-props(7) Propiedades Comunes de Nodos y pipewire-props(7) Propiedades del Adaptador de Audio

REGLAS DE FLUJO

Puede añadir reglas de coincidencia, ver pipewire(1) para establecer propiedades para flujos y filtros específicos.

stream.rules y filter.rules proporcionan una acción update-props que toma un objeto con propiedades que se actualizan en el objeto nodo del flujo y filtro.

Añada una sección stream.rules o filter.rules en el archivo de configuración de esta manera:

# ~/.config/pipewire/client.conf.d/custom.conf
stream.rules = [
    {
        matches = [
            {
                # todas las claves deben coincidir con el valor. ! niega. ~ inicia regex.
                application.process.binary = "firefox"
            }
        ]
        actions = {
            update-props = {
                node.name = "Mi Nombre"
            }
        }
    }
]

Establecerá el nombre del nodo de Firefox a "Mi Nombre".

PROPIEDADES DEL CLIENTE ALSA

Se puede añadir una sección alsa.properties para configurar aplicaciones cliente que se conectan a través del plugin ALSA de PipeWire.

# ~/.config/pipewire/client.conf.d/custom.conf
alsa.properties = {
    #alsa.deny = false
    #alsa.format = 0
    #alsa.rate = 0
    #alsa.channels = 0
    #alsa.period-bytes = 0
    #alsa.buffer-bytes = 0
    #alsa.volume-method = cubic         # linear, cubic
}

alsa.deny

Niega el acceso ALSA para el cliente. Útil en reglas o variable de entorno PIPEWIRE_ALSA.

alsa.format

El formato ALSA a usar para el cliente. Este es un nombre de formato ALSA. Predeterminado 0, que permite todos los formatos.

alsa.rate

La tasa de muestreo a usar para el cliente. El valor predeterminado es 0, que permite todas las tasas.

alsa.channels

El número de canales para el cliente. El valor predeterminado es 0, que permite cualquier número de canales.

alsa.period-bytes

El número de bytes por período. El valor predeterminado es 0, que permite cualquier número de bytes por período.

alsa.buffer-bytes

El número de bytes en el búfer ALSA. El valor predeterminado es 0, que permite cualquier número de bytes.

alsa.volume-method = cubic | linear

Esto controla la curva de volumen utilizada en el mezclador ALSA. Los valores posibles son cubic y linear. El valor predeterminado es usar cubic.

REGLAS DEL CLIENTE ALSA

Es posible establecer propiedades específicas del cliente ALSA utilizando Reglas de coincidencia, ver pipewire(1). Puede establecer cualquiera de las propiedades ALSA anteriores o cualquiera de las stream.properties.

Ejemplo

# ~/.config/pipewire/client.conf.d/custom.conf
alsa.rules = [
    {   matches = [ { application.process.binary = "resolve" } ]
        actions = {
            update-props = {
                alsa.buffer-bytes = 131072
            }
        }
    }
]

VARIABLES DE ENTORNO

Ver pipewire(1) para variables de entorno comunes. Muchas de estas también se aplican a las aplicaciones cliente.

Las variables de entorno también influyen en las aplicaciones ALSA que utilizan el plugin ALSA de PipeWire.

PIPEWIRE_ALSA

Esto puede ser un objeto con propiedades de alsa.properties o stream.properties que se utilizarán para construir el cliente y los flujos.

Por ejemplo:

PIPEWIRE_ALSA='{ alsa.buffer-bytes=16384 node.name=foo }' aplay ...


Inicia aplay con propiedades personalizadas.

PIPEWIRE_NODE

Indica al cliente ALSA que se enlace a un objeto sink o source específico. serial o node.name.

Por ejemplo:

PIPEWIRE_NODE=alsa_output.pci-0000_00_1b.0.analog-stereo aplay ...


Hace que aplay reproduzca en el sink de audio dado.

pipewire-client.conf(5)

NOMBRE

pipewire-client.conf - Archivo de configuración del cliente PipeWire

DESCRIPCIÓN

Este archivo de configuración permite modificar el comportamiento de los clientes de PipeWire. Las opciones de configuración se dividen en varias secciones.

SINOPSIS

El archivo de configuración se encuentra típicamente en /etc/pipewire/client.conf o ~/.config/pipewire/client.conf.

DESCRIPCIÓN

La configuración se realiza mediante pares clave-valor. Los comentarios comienzan con #.

SECCIONES DEL ARCHIVO DE CONFIGURACIÓN

Las siguientes secciones están disponibles:

  • STREAM PROPERTIES
  • STREAM RULES
  • ALSA CLIENT PROPERTIES
  • ALSA CLIENT RULES
  • ENVIRONMENT VARIABLES

PROPIEDADES DE STREAM

Define las propiedades por defecto para los streams creados por los clientes.

default.clock.rate
Frecuencia de reloj por defecto en Hz.
default.clock.allowed-rates
Lista de frecuencias de reloj permitidas.
default.clock.quantum
Tamaño de quantum por defecto.
default.clock.min-quantum
Tamaño mínimo de quantum.
default.clock.max-quantum
Tamaño máximo de quantum.

REGLAS DE STREAM

Define reglas para aplicar propiedades a streams específicos basándose en sus metadatos.

Ejemplo:

stream.rule = {
    matches = [
        { key = "node.name" value = "builtin-audio-sink" }
    ]
    actions = {
        update-props = {
            audio.channels = 2
        }
    }
}

PROPIEDADES DEL CLIENTE ALSA

Define las propiedades por defecto para los clientes que utilizan la capa de compatibilidad ALSA.

alsa.buffer-size
Tamaño del buffer ALSA.
alsa.period-size
Tamaño del periodo ALSA.

REGLAS DEL CLIENTE ALSA

Define reglas para aplicar propiedades a clientes ALSA específicos.

VARIABLES DE ENTORNO

Las siguientes variables de entorno pueden ser utilizadas para influir en el comportamiento de PipeWire:

PIPEWIRE_CONFIG_DIR
Directorio donde buscar archivos de configuración.
PIPEWIRE_RUNTIME_DIR
Directorio para archivos de runtime.

AUTORES

El equipo de PipeWire.
