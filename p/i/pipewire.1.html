pipewire(1) Manual de comandos generales pipewire(1)

NOMBRE

pipewire - El servidor multimedia PipeWire

SINOPSIS

pipewire [opciones]

DESCRIPCIÓN

PipeWire es un servicio que facilita el intercambio de contenido multimedia entre dispositivos y aplicaciones.

El demonio pipewire lee un archivo de configuración que se documenta en la página del manual pipewire.conf(5).

OPCIONES

-h | --help

Muestra la ayuda.

-v | --verbose

Aumenta el nivel de verbosidad en uno. Esta opción puede especificarse varias veces.

--version

Muestra información de la versión.

-c | --config=ARCHIVO

Carga el archivo de configuración dado (Predeterminado: pipewire.conf).

-P | --properties=PROPIEDADES

Añade las propiedades dadas como un objeto JSON SPA al contexto.

CONFIGURACIÓN EN TIEMPO DE EJECUCIÓN

Un demonio de PipeWire también expondrá un objeto de metadatos de configuración que se puede utilizar para cambiar algunas configuraciones en tiempo de ejecución.

Normalmente, estas configuraciones pueden eludir cualquiera de las restricciones listadas en las opciones de configuración anteriores, como los valores de quantum y samplerate.

Las configuraciones se pueden modificar usando pw-metadata(1):

pw-metadata -n settings                  # listar configuraciones
pw-metadata -n settings 0                # listar configuraciones del servidor
pw-metadata -n settings 0 log.level 2    # modificar una configuración del servidor

log.level = ENTERO

Cambia el nivel de registro del demonio PipeWire.

clock.rate = ENTERO

La frecuencia de muestreo predeterminada.

clock.allowed-rates = [ TASA1 TASA2... ]

Las frecuencias de muestreo permitidas.

clock.force-rate = ENTERO

Fuerza temporalmente que el grafo opere a una frecuencia de muestreo fija. Tanto el procesamiento DSP como los dispositivos cambiarán a la nueva tasa inmediatamente. Los flujos de ejecución (aplicaciones PulseAudio, nativas y ALSA) se remuestrearán automáticamente para coincidir con la nueva tasa.

Establezca el valor a 0 para permitir que la frecuencia de muestreo varíe nuevamente.

clock.quantum = ENTERO

El quantum (tamaño del búfer) predeterminado.

clock.min-quantum = ENTERO

El quantum más pequeño a utilizar.

clock.max-quantum = ENTERO

El quantum más grande a utilizar.

clock.force-quantum = ENTERO

Fuerza temporalmente que el grafo opere a un quantum fijo.

Establezca el valor a 0 para permitir que el quantum varíe nuevamente.

VARIABLES DE ENTORNO

Directorios de sockets

PIPEWIRE_RUNTIME_DIR

XDG_RUNTIME_DIR

USERPROFILE

Se utiliza para encontrar el socket de PipeWire en el servidor (y clientes nativos).

PIPEWIRE_CORE

Nombre del socket a crear.

PIPEWIRE_REMOTE

Nombre del socket al que conectarse.

PIPEWIRE_DAEMON

Si se establece en true, el proceso se convierte en un nuevo servidor PipeWire.

Directorios de configuración, nombre de archivo de configuración y prefijo

PIPEWIRE_CONFIG_DIR

XDG_CONFIG_HOME

HOME

Se utiliza para encontrar los directorios de archivos de configuración.

PIPEWIRE_CONFIG_PREFIX

PIPEWIRE_CONFIG_NAME

Se utiliza para anular el prefijo de configuración y el nombre de configuración proporcionados por la aplicación.

PIPEWIRE_NO_CONFIG

Habilita (false) o deshabilita (true) la anulación de la configuración predeterminada.

Información del contexto

Como parte de un contexto de cliente, la siguiente información se recopila de las variables de entorno y se coloca en las propiedades del contexto:

LANG

El idioma actual en application.language.

XDG_SESSION_ID

Se establece como la propiedad application.process.session-id.

DISPLAY

Se establece como la propiedad window.x11.display.

Módulos

PIPEWIRE_MODULE_DIR

Establece el directorio donde encontrar los módulos de PipeWire.

SPA_SUPPORT_LIB

El nombre de la biblioteca de soporte SPA a cargar. Esto se puede usar para cambiar a una biblioteca de soporte alternativa, por ejemplo, para ejecutarse en el kernel en tiempo real EVL.

Opciones de registro

JOURNAL_STREAM

Se utiliza para analizar el flujo utilizado para el journal. Esto suele ser configurado por systemd.

PIPEWIRE_LOG_LINE

Habilita el registro de números de línea. Predeterminado true.

PIPEWIRE_LOG_TIMESTAMP

Tipo de marca de tiempo de registro: "local", "monotonic", "realtime", "none". Predeterminado "local".

PIPEWIRE_LOG

Especifica un archivo de registro a utilizar en lugar del registrador predeterminado.

PIPEWIRE_LOG_SYSTEMD

Habilita el uso de systemd para el registrador, predeterminado true.

Otras configuraciones

PIPEWIRE_CPU

Selecciona la CPU y las banderas. Esta es una máscara de bits de cualquiera de las banderas CPU

PIPEWIRE_VM

Selecciona la Máquina Virtual en la que se está ejecutando PipeWire. Este puede ser cualquiera de los tipos de VM

DISABLE_RTKIT

Deshabilita el uso de RTKit o el Portal en Tiempo Real para la programación en tiempo real.

NO_COLOR

Deshabilita el uso de colores en la salida de la consola.

Opciones de depuración

PIPEWIRE_DLCLOSE

Habilita (true) o deshabilita (false) el uso de dlclose cuando una biblioteca compartida ya no está en uso. Al depurar, puede tener sentido deshabilitar dlclose para poder obtener símbolos de depuración del objeto.

Opciones de flujo

PIPEWIRE_NODE

Hace que un flujo se conecte a un objeto.serial o node.name específico.

PIPEWIRE_PROPS

Añade propiedades adicionales a un flujo o filtro.

PIPEWIRE_QUANTUM

Fuerza una tasa y tamaño de búfer específicos para el flujo o filtro.

PIPEWIRE_LATENCY

Establece una latencia específica para un flujo o filtro. Esto es solo una sugerencia, pero la latencia configurada no será mayor.

PIPEWIRE_RATE

Establece una tasa para un flujo o filtro. Esto es solo una sugerencia. La tasa se cambiará cuando el grafo esté inactivo.

PIPEWIRE_AUTOCONNECT

Anula la configuración predeterminada de autoconexión de flujo.

Opciones de plugin

SPA_PLUGIN_DIR

Se utiliza para localizar plugins SPA.

SPA_DATA_DIR

Se utiliza para localizar archivos de configuración específicos del plugin. Esto lo utiliza actualmente el plugin de bluetooth para localizar

pipewire(1) — PipeWire — Arch Linux

NAME

pipewire - media server

SYNOPSIS

pipewire [options]

DESCRIPTION

PipeWire is a new server for Linux designed to manage audio and video streams. It aims to support professional audio use cases, reduce latency, and provide a modern API for applications.

PipeWire is designed to be a low-level multimedia framework that enables a wide range of use cases, from simple audio playback to complex video processing and virtual reality.

OPTIONS

The pipewire daemon can be configured through the configuration files in /etc/pipewire/, /usr/share/pipewire/ and user specific directories.

The following environment variables can be used to control the daemon:

RUNTIME SETTINGS

These settings are dynamic and can be changed at runtime using tools like pw-cli(1).

default.clock.rate
The sample rate. Default is 48000.

default.clock.allowed-rates
A comma-separated list of sample rates that are allowed.

default.clock.quantum
The default quantum or buffer size. Default is 1024.

default.clock.min-quantum
The minimum quantum. Default is 32.

default.clock.max-quantum
The maximum quantum. Default is 2048.

default.clock.rate-step
Quantum size is doubled when the rate difference is larger than this. Default is 2.

default.clock.allowed-quantum
A comma-separated list of allowed quantum sizes.

default.clock.trigger-timeout
Timeout in microseconds after which a clock is considered to have timed out. Default is 0 (disabled).

default.clock.can-be-live
Whether the clock can be live. Default is true.

default.clock.can-be-quantum
Whether the clock can be quantum. Default is true.

default.clock.can-be-rate
Whether the clock can be rate. Default is true.

core.default-permissions
A comma-separated list of default permissions.

core.introspection
Enable or disable introspection. Default is true.

core.exclusive-core
Enable or disable exclusive core. Default is false.

core.defer-server-start
Defer server start. Default is false.

default.profile.priority
The default profile priority. Default is 0.

default.profile.memlock
The default memlock limit. Default is 0.

default.audio.channels
The default number of audio channels. Default is 2.

default.audio.position
The default audio channel positions. Default is FrontLeft,FrontRight.

default.video.width
The default video width. Default is 640.

default.video.height
The default video height. Default is 480.

default.video.rate
The default video rate. Default is 30.

session.vacuum-interval-msec
Interval in milliseconds for vacuuming dead objects. Default is 1000.

session.suspend-timeout-seconds
Timeout in seconds after which idle clients are suspended. Default is 5.

session.idle-timeout-seconds
Timeout in seconds after which idle sessions are removed. Default is 300.

session.force-mmap
Force mmap for all clients. Default is false.

session.pa-login-timeout
Timeout in milliseconds for PulseAudio login. Default is 500.

session.pa-default-access
Default access mask for PulseAudio clients. Default is read,write,latency.

session.alsa-monitor.sync
Synchronize ALSA devices. Default is true.

session.alsa-monitor.rate
The ALSA monitor rate. Default is 1000.

session.screen-copy.allow-mksyscom
Allow screen copy using mksyscom. Default is false.

session.target
The session manager target. Default is default.

ENVIRONMENT VARIABLES

PIPEWIRE_DEBUG
Set the log level for PipeWire components. This can be used to enable debug messages. Levels are: 0 (error), 1 (warning), 2 (info), 3 (debug), 4 (trace).

PIPEWIRE_CONFIG_DIR
Set the directory where PipeWire looks for configuration files. The default is /etc/pipewire/.

PIPEWIRE_PLUGIN_DIR
Set the directory where PipeWire looks for plugins. The default is /usr/lib/pipewire/.

PIPEWIRE_LIB_DIR
Set the directory where PipeWire looks for libraries. The default is /usr/lib/.

SPA_DEBUG
Set the log level for SPA plugins. This is usually controlled by the PIPEWIRE_DEBUG variable when the plugins are managed by PipeWire but some standalone tools (like spa-inspect) uses this variable.

ACP_BUILDDIR
If set, the ACP profiles are loaded from the builddir.

ACP_PATHS_DIR

ACP_PROFILES_DIR
Used to locate the ACP paths and profile directories respectively.

LADSPA_PATH
Comma separated list of directories where the ladspa plugins can be found.

LIBJACK_PATH
Directory where the jack1 or jack2 libjack.so can be found.

AUTHORS

The PipeWire Developers https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire is available from https://pipewire.org
