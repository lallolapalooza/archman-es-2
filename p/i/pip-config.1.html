NOMBRE

pip-config - descripción del comando de configuración de pip

DESCRIPCIÓN

Gestionar la configuración local y global.

Subcomandos:

  • list: Listar la configuración activa (o del archivo especificado)
  • edit: Editar el archivo de configuración en un editor
  • get: Obtener el valor asociado con comando.opción
  • set: Establecer comando.opción=valor
  • unset: Eliminar el valor asociado con comando.opción
  • debug: Listar los archivos de configuración y los valores definidos en ellos

Las claves de configuración deben ser nombres de comando y opción separados por puntos, con el prefijo especial "global" que afecta a cualquier comando. Por ejemplo, "pip config set global.index-url https://example.org/" configuraría la URL del índice para todos los comandos, pero "pip config set download.timeout 10" configuraría un tiempo de espera de 10 segundos solo para los comandos "pip download".

Si no se pasan --user, --global y --site, se utiliza un archivo de configuración de entorno virtual si está activo y el archivo existe. De lo contrario, todas las modificaciones se realizan en el archivo de usuario por defecto.

USO

python -m pip config [<opción-archivo>] list
python -m pip config [<opción-archivo>] [--editor <ruta-editor>] edit
python -m pip config [<opción-archivo>] get comando.opción
python -m pip config [<opción-archivo>] set comando.opción valor
python -m pip config [<opción-archivo>] unset comando.opción
python -m pip config [<opción-archivo>] debug

OPCIONES

--editor <editor>
Editor a utilizar para editar el archivo. Utiliza las variables de entorno VISUAL o EDITOR si no se proporcionan.

(variable de entorno: PIP_EDITOR)

--global
Utilizar solo el archivo de configuración global del sistema.

(variable de entorno: PIP_GLOBAL)

--user
Utilizar solo el archivo de configuración del usuario.

(variable de entorno: PIP_USER)

--site
Utilizar solo el archivo de configuración del entorno actual.

(variable de entorno: PIP_SITE)
