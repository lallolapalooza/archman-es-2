NOMBRE

pip-check - descripción del comando pip check

DESCRIPCIÓN

Verifica que los paquetes instalados tengan dependencias compatibles.

USO

python -m pip check [opciones]

OPCIONES

-h, --help
Mostrar ayuda.

(variable de entorno: PIP_HELP)

--debug
Permitir que las excepciones no manejadas se propaguen fuera de la subrutina principal, en lugar de registrarlas en stderr.

(variable de entorno: PIP_DEBUG)

--isolated
Ejecutar pip en modo aislado, ignorando las variables de entorno y la configuración del usuario.

(variable de entorno: PIP_ISOLATED)

--require-virtualenv
Permitir que pip solo se ejecute en un entorno virtual; de lo contrario, salir con un error.

(variables de entorno: PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Ejecutar pip con el intérprete de Python especificado.

(variable de entorno: PIP_PYTHON)

-v, --verbose
Proporcionar más salida. La opción es aditiva y se puede usar hasta 3 veces.

(variable de entorno: PIP_VERBOSE)

-V, --version
Mostrar la versión y salir.

(variable de entorno: PIP_VERSION)

-q, --quiet
Proporcionar menos salida. La opción es aditiva y se puede usar hasta 3 veces (correspondiente a los niveles de registro WARNING, ERROR y CRITICAL).

(variable de entorno: PIP_QUIET)

--log <ruta>
Ruta a un registro de adición detallado.

(variables de entorno: PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Desactivar la solicitud de entrada.

(variable de entorno: PIP_NO_INPUT)

--keyring-provider <keyring_provider>
Habilitar la búsqueda de credenciales a través de la biblioteca keyring si la entrada del usuario está permitida. Especificar el mecanismo a utilizar [auto, disabled, import, subprocess]. (predeterminado: auto)

(variable de entorno: PIP_KEYRING_PROVIDER)

--proxy <proxy>
Especificar un proxy en el formato scheme://[user:passwd@]proxy.server:port.

(variable de entorno: PIP_PROXY)

--retries <retries>
Intentos máximos para establecer una nueva conexión HTTP. (predeterminado: 5)

(variable de entorno: PIP_RETRIES)

--timeout <sec>
Establecer el tiempo de espera del socket (predeterminado 15 segundos).

(variables de entorno: PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <action>
Acción predeterminada cuando una ruta ya existe: (s)witch, (i)gnore, (w)ipe, (b)ackup, (a)bort.

(variable de entorno: PIP_EXISTS_ACTION)

--trusted-host <hostname>
Marcar este host o par host:port como confiable, aunque no tenga HTTPS válido o ninguno.

(variable de entorno: PIP_TRUSTED_HOST)

--cert <ruta>
Ruta al paquete de certificados CA codificados en PEM. Si se proporciona, anula el valor predeterminado. Consulte 'SSL Certificate Verification' en la documentación de pip para obtener más información.

(variable de entorno: PIP_CERT)

--client-cert <ruta>
Ruta al certificado de cliente SSL, un único archivo que contiene la clave privada y el certificado en formato PEM.

(variable de entorno: PIP_CLIENT_CERT)

--cache-dir <dir>
Almacenar los datos de caché en <dir>.

(variable de entorno: PIP_CACHE_DIR)

--no-cache-dir
Desactivar la caché.

(variable de entorno: PIP_NO_CACHE_DIR)

--disable-pip-version-check
No comprobar periódicamente PyPI para determinar si hay una nueva versión de pip disponible para descargar. Implícito con --no-index.

(variable de entorno: PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Suprimir la salida con color.

(variable de entorno: PIP_NO_COLOR)

--use-feature <feature>
Habilitar nueva funcionalidad, que puede ser incompatible con versiones anteriores.

(variable de entorno: PIP_USE_FEATURE)

--use-deprecated <feature>
Habilitar funcionalidad obsoleta, que se eliminará en el futuro.

(variable de entorno: PIP_USE_DEPRECATED)

--resume-retries <resume_retries>
Intentos máximos para reanudar o reiniciar una descarga incompleta. (predeterminado: 5)

(variable de entorno: PIP_RESUME_RETRIES)
