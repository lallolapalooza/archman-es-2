NOMBRE

pip-download - descripción del comando pip download

DESCRIPCIÓN

Descarga paquetes de:

  • PyPI (y otros índices) usando especificadores de requisitos.
  • URLs de proyectos VCS.
  • Directorios de proyectos locales.
  • Archivos fuente locales o remotos.

pip también soporta la descarga de "archivos de requisitos", que proporcionan una forma fácil de especificar un entorno completo que se va a descargar.

USO

python -m pip download [opciones] <especificador de requisito> [opciones-del-índice-de-paquetes] ...
python -m pip download [opciones] -r <archivo de requisitos> [opciones-del-índice-de-paquetes] ...
python -m pip download [opciones] <url de proyecto vcs> ...
python -m pip download [opciones] <ruta de proyecto local> ...
python -m pip download [opciones] <url/ruta de archivo> ...

OPCIONES

-c, --constraint <archivo>
Restringe versiones usando el archivo de restricciones dado. Esta opción puede ser usada múltiples veces.

(variable de entorno: PIP_CONSTRAINT)

--build-constraint <archivo>
Restringe las dependencias de compilación usando el archivo de restricciones dado. Esta opción puede ser usada múltiples veces.

(variable de entorno: PIP_BUILD_CONSTRAINT)

-r, --requirement <archivo>
Instala desde el archivo de requisitos dado. Esta opción puede ser usada múltiples veces.

(variable de entorno: PIP_REQUIREMENT)

--no-deps
No instales dependencias de paquetes.

(variables de entorno: PIP_NO_DEPS, PIP_NO_DEPENDENCIES)

--no-binary <control_formato>
No uses paquetes binarios. Puede ser suministrado múltiples veces, y cada vez se añade al valor existente. Acepta ":all:" para deshabilitar todos los paquetes binarios, ":none:" para vaciar el conjunto (nota los dos puntos), o uno o más nombres de paquetes separados por comas (sin dos puntos). Ten en cuenta que algunos paquetes son difíciles de compilar y pueden fallar al instalarse cuando se usa esta opción en ellos.

(variable de entorno: PIP_NO_BINARY)

--only-binary <control_formato>
No uses paquetes fuente. Puede ser suministrado múltiples veces, y cada vez se añade al valor existente. Acepta ":all:" para deshabilitar todos los paquetes fuente, ":none:" para vaciar el conjunto, o uno o más nombres de paquetes separados por comas. Los paquetes sin distribuciones binarias fallarán al instalarse cuando se usa esta opción en ellos.

(variable de entorno: PIP_ONLY_BINARY)

--prefer-binary
Prefiere paquetes binarios sobre paquetes fuente, incluso si los paquetes fuente son más recientes.

(variable de entorno: PIP_PREFER_BINARY)

--src <dir>
Directorio en el que extraer proyectos editables. El valor predeterminado en un entorno virtual es "<ruta del venv>/src". El valor predeterminado para instalaciones globales es "<directorio actual>/src".

(variables de entorno: PIP_SRC, PIP_SOURCE, PIP_SOURCE_DIR, PIP_SOURCE_DIRECTORY)

--pre
Incluye versiones pre-release y de desarrollo. Por defecto, pip solo encuentra versiones estables.

(variable de entorno: PIP_PRE)

--require-hashes
Requiere un hash para verificar cada requisito, para instalaciones repetibles. Esta opción se implica cuando cualquier paquete en un archivo de requisitos tiene una opción --hash.

(variable de entorno: PIP_REQUIRE_HASHES)

--progress-bar <barra_progreso>
Especifica si se debe usar la barra de progreso. En modo 'auto', --quiet suprimirá todas las barras de progreso. [auto, on, off, raw] (predeterminado: auto)

(variable de entorno: PIP_PROGRESS_BAR)

--no-build-isolation
Deshabilita el aislamiento al compilar una distribución fuente moderna. Las dependencias de compilación especificadas por PEP 518 deben estar ya instaladas si se usa esta opción.

(variable de entorno: PIP_NO_BUILD_ISOLATION)

--check-build-dependencies
Verifica las dependencias de compilación.

(variable de entorno: PIP_CHECK_BUILD_DEPENDENCIES)

--ignore-requires-python
Ignora la información de Requires-Python.

(variable de entorno: PIP_IGNORE_REQUIRES_PYTHON)

-d, --dest <dir>
Descarga paquetes en <dir>.

(variables de entorno: PIP_DEST, PIP_DESTINATION_DIR, PIP_DESTINATION_DIRECTORY)

--platform <plataforma>
Solo usa wheels compatibles con <plataforma>. Predeterminado a la plataforma del sistema en ejecución. Usa esta opción múltiples veces para especificar múltiples plataformas compatibles con el intérprete de destino.

(variable de entorno: PIP_PLATFORM)

--python-version <version_python>
La versión del intérprete de Python a usar para la compatibilidad con wheel y "Requires-Python". Predeterminado a una versión derivada del intérprete en ejecución. La versión puede especificarse usando hasta tres enteros separados por puntos (por ejemplo, "3" para 3.0.0, "3.7" para 3.7.0, o "3.7.3"). Una versión mayor-menor también puede darse como una cadena sin puntos (por ejemplo, "37" para 3.7.0).

(variable de entorno: PIP_PYTHON_VERSION)

--implementation <implementación>
Solo usa wheels compatibles con la implementación de Python <implementación>, por ejemplo, 'pp', 'jy', 'cp', o 'ip'. Si no se especifica, se usa la implementación del intérprete actual. Usa 'py' para forzar wheels independientes de la implementación.

(variable de entorno: PIP_IMPLEMENTATION)

--abi <abi>
Solo usa wheels compatibles con el abi de Python <abi>, por ejemplo, 'pypy_41'. Si no se especifica, se usa la etiqueta abi del intérprete actual. Usa esta opción múltiples veces para especificar múltiples abis compatibles con el intérprete de destino. Generalmente necesitarás especificar --implementation, --platform y --python-version al usar esta opción.

(variable de entorno: PIP_ABI)

NAME

pip-download — Download packages from PyPI.

SYNOPSIS

pip-download [options] <package(s)>

DESCRIPTION

Download packages from PyPI without installing them.

This command downloads the specified package(s) and their dependencies from PyPI and places them in the current directory.

OPTIONS

-d, --download-dir <dir>
If specified, download packages to the given directory.
-r, --requirements-file <file>
Use a requirements file to specify packages to download.
-f, --find-links <url>
URL to look for packages.
-i, --index-url <url>
Base URL of Python Package Index (default: https://pypi.org).
--no-index
Ignore the index (PyPI).
--no-deps
Don't install package dependencies.
--no-source
Do not download source distributions.
--build <dir>
Specify where the build directory is. By default it is a temporary directory in the current directory.

(environment variable: PIP_BUILD)

--no-clean
Don't clean up build directories.

(environment variable: PIP_NO_CLEAN)
