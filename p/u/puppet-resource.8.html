NOMBRE

puppet-resource - Shell de la capa de abstracción de recursos

SINOPSIS

Utiliza la RAL de Puppet para interactuar directamente con el sistema.

USO

puppet resource [-h|--help] [-d|--debug] [-v|--verbose] [-e|--edit] [-p|--param parámetro] [-t|--types] [-y|--to_yaml] tipo [nombre] [atributo=valor ...]

DESCRIPCIÓN

Este comando proporciona utilidades sencillas para convertir el estado actual del sistema en código Puppet, junto con cierta capacidad para modificar el estado actual utilizando la RAL de Puppet.

Por defecto, debes proporcionar al menos un tipo para listar, en cuyo caso puppet resource te dirá todo lo que sabe sobre todos los recursos de ese tipo. Opcionalmente, puedes especificar un nombre de instancia, y puppet resource solo describirá esa única instancia.

Si se le proporciona un tipo, un nombre y una serie de pares atributo=valor, puppet resource modificará el estado del recurso especificado. Alternativamente, si se le proporciona un tipo, un nombre y la opción ´--edit´, puppet resource escribirá su salida en un archivo, abrirá ese archivo en un editor y luego aplicará el archivo guardado como una transacción de Puppet.

OPCIONES

Tenga en cuenta que cualquier ajuste válido en el archivo de configuración también es un argumento largo válido. Por ejemplo, ´ssldir´ es un ajuste válido, por lo que puede especificar ´--ssldir directorio´ como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para obtener la lista completa de parámetros aceptables. También puede generar una lista comentada de todas las opciones de configuración ejecutando puppet con ´--genconfig´.

--debug
Habilita la depuración completa.
--edit
Escribe los resultados de la consulta en un archivo, abre el archivo en un editor y lee el archivo de nuevo como un manifiesto de Puppet ejecutable.
--help
Imprime este mensaje de ayuda.
--param
Añade más parámetros que se mostrarán en las consultas.
--types
Lista todos los tipos disponibles.
--verbose
Imprime información adicional.
--to_yaml
Muestra los recursos encontrados en formato yaml, adecuados para usar con Hiera y create_resources.
--fail
Falla y devuelve un código de salida de 1 si el recurso no pudo ser modificado.

EJEMPLO

Este ejemplo utiliza puppet resource para devolver una configuración de Puppet para el usuario luke:

$ puppet resource user luke
user { ´luke´:
 home => ´/home/luke´,
 uid => ´100´,
 ensure => ´present´,
 comment => ´Luke Kanies,,,´,
 gid => ´1000´,
 shell => ´/bin/bash´,
 groups => [´sysadmin´,´audio´,´video´,´puppet´]
}
