NOMBRE

puppet-plugin - Interactuar con el sistema de plugins de Puppet.

SINOPSIS

puppet plugin acción

DESCRIPCIÓN

Este subcomando proporciona acceso de red al almacén de plugins del maestro de Puppet. El maestro de Puppet sirve código Ruby recopilado de los directorios lib de sus módulos. Estos plugins pueden ser utilizados en nodos agentes para extender Facter e implementar tipos y proveedores personalizados. Los plugins son descargados normalmente por el agente de Puppet durante la ejecución.

OPCIONES

Tenga en cuenta que cualquier configuración válida en el archivo de configuración también es un argumento largo válido, aunque puede o no ser relevante para la acción presente. Por ejemplo, server y run_mode son configuraciones válidas, por lo que puede especificar --server <nombre_servidor>, o --run_mode <modo_ejecucion> como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para la lista completa de parámetros aceptables. Una lista comentada de todas las opciones de configuración también se puede generar ejecutando puppet con --genconfig.

--render-as FORMATO
El formato en el que se renderizará la salida. Los formatos más comunes son json, s (string), yaml y console, pero otras opciones como dot a veces están disponibles.
--verbose
Si se debe registrar de forma detallada.
--debug
Si se deben registrar información de depuración.

ACCIONES

download - Descargar plugins del maestro de Puppet.
SINOPSIS
puppet plugin download
DESCRIPCIÓN
Descarga plugins del maestro de Puppet configurado. Cualquier plugin descargado de esta manera se utilizará en todas las actividades posteriores de Puppet. Esta acción modifica archivos en el disco.
RETORNA
Una lista de los archivos descargados, o una confirmación de que no se descargaron archivos. Cuando se utiliza desde la API de Ruby, esta acción devuelve una matriz de los archivos descargados, que estará vacía si no se recuperó ninguno.

EJEMPLOS

download

Recuperar plugins del maestro de Puppet:

$ puppet plugin download

Recuperar plugins del maestro de Puppet (ejemplo de API):

$ Puppet::Face[:plugin, ´0.0.1´].download
