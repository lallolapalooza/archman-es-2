punycode_decode(3)

Paquete: libidn

Licencias: GPL3, LGPL

punycode_decode(3) libidn punycode_decode(3)

NOMBRE

punycode_decode - Función de API

SINOPSIS

#include <punycode.h>

int punycode_decode(size_t longitud_entrada, const char [] entrada, size_t * longitud_salida, punycode_uint [] salida, unsigned char [] flags_de_caso);

ARGUMENTOS

size_t longitud_entrada
El número de puntos de código ASCII en el array entrada.
const char [] entrada
Un array de puntos de código ASCII (0..7F).
size_t * longitud_salida
El llamador pasa el número máximo de puntos de código que puede recibir en el array salida (que también es el número máximo de flags que puede recibir en el array
flags_de_caso, si flags_de_caso no es un puntero NULL). Al retornar con éxito, contendrá el número de puntos de código realmente salidos (que también es el número de flags realmente salidos, si flags_de_caso no es un puntero nulo). El decodificador nunca necesitará enviar más puntos de código que el número de puntos de código ASCII en la entrada, debido a la forma en que está definida la codificación. El número de puntos de código de salida no puede exceder el valor máximo posible de un punycode_uint, incluso si el
longitud_salida proporcionado es mayor que ese.
punycode_uint [] salida
Un array de puntos de código como el argumento de entrada de punycode_encode() (ver arriba).
unsigned char [] flags_de_caso
Un puntero NULL (si el llamador no necesita los flags) o un array de valores booleanos paralelo al array salida. Un valor distinto de cero (verdadero, con flag) sugiere que el carácter Unicode correspondiente sea forzado a mayúsculas por el llamador (si es posible), y cero (falso, sin flag) sugiere que sea forzado a minúsculas (si es posible). Los puntos de código ASCII (0..7F) se envían ya en la capitalización adecuada, pero sus flags se establecerán apropiadamente para que aplicar los flags no cause ningún daño.

DESCRIPCIÓN

Convierte Punycode a una secuencia de puntos de código (presumiblemente puntos de código Unicode).

Valor de retorno: El valor de retorno puede ser cualquiera de los valores Punycode_status definidos anteriormente. Si no es PUNYCODE_SUCCESS, entonces
longitud_salida , salida y flags_de_caso pueden contener basura.
