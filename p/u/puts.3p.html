PUTS(3P) Manual del programador POSIX PUTS(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

puts — escribir una cadena en la salida estándar

SINOPSIS

#include <stdio.h>
int puts(const char *s);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

La función puts() escribirá la cadena apuntada por s, seguida de un salto de línea (<newline>), en el flujo de salida estándar stdout. El byte nulo de terminación no se escribirá.

Las marcas de tiempo de la última modificación de datos y del último cambio de estado del archivo se marcarán para su actualización entre la ejecución exitosa de puts() y la próxima finalización exitosa de una llamada a fflush() o fclose() en el mismo flujo, o una llamada a exit() o abort().

VALOR DEVUELTO

Tras una finalización exitosa, puts() devolverá un número no negativo. De lo contrario, devolverá EOF, establecerá un indicador de error para el flujo y errno se establecerá para indicar el error.

ERRORES

Consulte fputc().

EJEMPLOS

Imprimir en la salida estándar

El siguiente ejemplo obtiene la hora actual, la convierte a una cadena usando localtime() y asctime(), y la imprime en la salida estándar usando puts(). Luego imprime el número de minutos hasta un evento al que se está esperando.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("La hora es ");
puts(asctime(localtime(&now)));
printf("Faltan %d minutos para el evento.\n",
    minutes_to_event);
...

USO POR LA APLICACIÓN

La función puts() añade un salto de línea (<newline>), mientras que fputs() no lo hace.

Este volumen de POSIX.1-2017 requiere que la finalización exitosa simplemente devuelva un entero no negativo. Existen al menos tres convenciones de implementación diferentes conocidas para este requisito:

*
Devolver un valor constante.
*
Devolver el último carácter escrito.
*
Devolver el número de bytes escritos. Tenga en cuenta que esta convención de implementación no puede cumplirse para cadenas más largas que {INT_MAX} bytes, ya que el valor no sería representable en el tipo de retorno de la función. Por compatibilidad con versiones anteriores, las implementaciones pueden devolver el número de bytes para cadenas de hasta {INT_MAX} bytes, y devolver {INT_MAX} para todas las cadenas más largas.
