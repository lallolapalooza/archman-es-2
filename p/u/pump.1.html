pump(1) Manual de Comandos Generales pump(1)

NOMBRE

pump - acelera la compilación remota con distcc

SINOPSIS

pump COMANDO-DE-COMPILACIÓN [ARGUMENTOS] ...

eval ` pump --startup `; COMANDO-DE-COMPILACIÓN [ARGUMENTOS] ... ; pump --shutdown

DESCRIPCIÓN

pump es parte de distcc. Se utiliza para el modo pump de distcc. El modo pump de Distcc acelera la compilación remota con distcc distribuyendo también el preprocesamiento a los servidores.

Para una descripción detallada del modo pump, incluyendo especialmente algunas restricciones importantes, consulte la página del manual de distcc(1), en particular la sección CÓMO FUNCIONA EL MODO PUMP y la sección RESTRICCIONES DEL MODO PUMP.

El uso más sencillo es la forma

pump COMANDO [ARGUMENTO] ...
Esto iniciará un servidor de inclusión para el modo "pump" de distcc; opcionalmente ejecutará lsdistcc para calcular la lista de hosts de distcc; establecerá algunas variables de entorno auxiliares; cambiará PATH para usar el cliente distcc en el mismo directorio que el script "pump"; ejecutará COMANDO con el/los ARGUMENTO(s) especificado(s); y luego detendrá el servidor de inclusión. El COMANDO es típicamente un comando de compilación paralela, como "make -j80", que realizará muchas invocaciones concurrentes de distcc.

Una forma alternativa de invocar pump es invocar explícitamente "pump --startup" para iniciar el servidor de inclusión y "pump --shutdown" para detenerlo. El comando "pump --startup" iniciará el servidor de inclusión y mostrará algunas configuraciones de variables de entorno. Estas variables de entorno se utilizan para la comunicación entre el cliente distcc del modo pump y el servidor de inclusión, y entre "pump --startup" y "pump --shutdown". El llamador de "pump --startup" es responsable de configurar estas variables de entorno antes de invocar "distcc" o "pump --shutdown".

Por ejemplo:

eval `pump --startup`
make -j80
pump --shutdown

Tenga en cuenta que el modo pump de distcc asume que los archivos fuente no serán
modificados durante la vida útil del servidor de inclusión, por lo que modificar archivos fuente durante una compilación puede causar resultados inconsistentes.

INVOCANDO LSDISTCC

Cuando se invoca en la forma simple " pump COMANDO [ARGUMENTO] ... ", o como " pump --startup ", el script pump invocará lsdistcc siempre que DISTCC_POTENTIAL_HOSTS esté establecido y DISTCC_HOSTS no lo esté. Pasará el valor de DISTCC_POTENTIAL_HOSTS a lsdistcc y usará la salida de lsdistcc para establecer DISTCC_HOSTS.

OPCIONES

--help
Muestra instrucciones resumidas.
--startup
Inicia un servidor de inclusión y genera las configuraciones de variables de entorno necesarias para que distcc(1) o pump --shutdown puedan acceder a él.
--shutdown
Detiene un servidor de inclusión iniciado por pump --startup.

VARIABLES DE ENTORNO

Todas las siguientes variables de entorno son opcionales.

DISTCC_LOCATION
La ubicación del directorio bin de distcc, que normalmente se infiere del dirname resuelto por enlace de argv[0]. Si esta ubicación es de hecho el directorio bin dentro de una instalación (como será el caso cuando el script pump de la instalación se ejecute), entonces los ejecutables de Python y el propio distcc se recuperarán del directorio padre de la ubicación.
DISTCC_MAX_DISCREPANCY
ver la página del manual de distcc(1).
DISTCC_POTENTIAL_HOSTS
Los servidores distcc que serán consultados por lsdistcc para producir un valor para DISTCC_HOSTS. Este valor puede no estar definido o ser nulo. En tales casos, no se invocará a lsdistcc y distcc usará DISTCC_HOSTS o el archivo de configuración de hosts de distcc, como se describe en la sección "Especificaciones de Host" de distcc(1).
DISTCC_HOSTS
Esta variable se pasa a distcc pero solo si DISTCC_POTENTIAL_HOSTS no está configurado.
LSDISTCC_ARGS
Argumentos adicionales para pasar a lsdistcc. Ver lsdistcc --help para más detalles.
INCLUDE_SERVER_ARGS
Argumentos adicionales para pasar al servidor de inclusión.
PYTHONOPTIMIZE
Si está configurado como "" (cadena vacía), entonces la optimización de Python está deshabilitada.

EJEMPLO

pump make -j20

ERRORES
