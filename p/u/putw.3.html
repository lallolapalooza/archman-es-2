getw(3) Manual de funciones de biblioteca getw(3)

NOMBRE

getw, putw - entrada y salida de palabras (enteros)

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
int getw(FILE *stream);
int putw(int w, FILE *stream);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

getw(), putw():

    Desde glibc 2.3.3:
        _XOPEN_SOURCE && ! (_POSIX_C_SOURCE >= 200112L)
            || /* glibc >= 2.19: */ _DEFAULT_SOURCE
            || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE
    Antes de glibc 2.3.3:
        _SVID_SOURCE || _BSD_SOURCE || _XOPEN_SOURCE

DESCRIPCIÓN

getw() lee una palabra (es decir, un int) de stream. Se proporciona para compatibilidad con SVr4. Recomendamos que utilice fread(3) en su lugar.

putw() escribe la palabra w (es decir, un int) en stream. Se proporciona para compatibilidad con SVr4, pero recomendamos que utilice fwrite(3) en su lugar.

VALOR DE RETORNO

Normalmente, getw() devuelve la palabra leída y putw() devuelve 0. En caso de error, devuelven EOF.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
getw (), putw () Seguridad en hilos MT-Safe

ESTÁNDARES

Ninguno.

HISTORIA

SVr4, SUSv2.

ERRORES

El valor devuelto en caso de error es también un valor de datos legítimo. ferror(3) se puede utilizar para distinguir entre los dos casos.

VER TAMBIÉN

ferror(3), fread(3), fwrite(3), getc(3), putc(3)
