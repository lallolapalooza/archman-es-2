putpwent(3) Manual de funciones de biblioteca putpwent(3)

NOMBRE

putpwent - escribir una entrada del archivo de contraseñas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <sys/types.h>
#include <pwd.h>
int putpwent(const struct passwd *restrict p, FILE *restrict stream);
Requisitos de macro de prueba de funciones para glibc (ver feature_test_macros(7)):

putpwent():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _SVID_SOURCE

DESCRIPCIÓN

La función putpwent() escribe una entrada de contraseña de la estructura p en el archivo asociado con stream.

La estructura passwd se define en <pwd.h> de la siguiente manera:


struct passwd {
    char    *pw_name;        /* nombre de usuario */
    char    *pw_passwd;      /* contraseña del usuario */
    uid_t    pw_uid;         /* ID de usuario */
    gid_t    pw_gid;         /* ID de grupo */
    char    *pw_gecos;       /* nombre real */
    char    *pw_dir;         /* directorio personal */
    char    *pw_shell;       /* programa de shell */
};

VALOR DE RETORNO

La función putpwent() devuelve 0 si tiene éxito. En caso de error, devuelve -1 y se establece errno para indicar el error.

ERRORES

EINVAL
Se proporcionó un argumento no válido (NULL).
