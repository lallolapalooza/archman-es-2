fputwc(3) Manual de funciones de biblioteca fputwc(3)

NOMBRE

fputwc, putwc - escribir un carácter ancho en un flujo FILE

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
#include <wchar.h>
wint_t fputwc(wchar_t wc, FILE *stream);
wint_t putwc(wchar_t wc, FILE *stream);

DESCRIPCIÓN

La función fputwc() es el equivalente de carácter ancho de la función fputc(3). Escribe el carácter ancho wc en stream. Si ferror(stream) se vuelve verdadero, devuelve WEOF. Si ocurre un error de conversión de carácter ancho, establece errno a EILSEQ y devuelve WEOF. De lo contrario, devuelve wc.

La función o macro putwc() funciona de manera idéntica a fputwc(). Puede implementarse como una macro y puede evaluar su argumento más de una vez. No hay ninguna razón para usarla.

Para contrapartes no bloqueantes, consulte unlocked_stdio(3).

VALOR DE RETORNO

En caso de éxito, la función fputwc() devuelve wc. De lo contrario, se devuelve WEOF y se establece errno para indicar el error.

ERRORES

Además de los habituales, existe

EILSEQ
La conversión de wc a la codificación del flujo falla.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
fputwc (), putwc () Seguridad de hilos MT-Safe

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

NOTAS

El comportamiento de fputwc() depende de la categoría LC_CTYPE de la configuración regional actual.

En ausencia de información adicional pasada a la llamada de fopen(3), es razonable esperar que fputwc() escriba realmente la secuencia multibyte correspondiente al carácter ancho wc.

VER TAMBIÉN

fgetwc(3), fputws(3), unlocked_stdio(3)
