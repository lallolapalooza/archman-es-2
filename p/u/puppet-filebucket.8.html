NOMBRE

puppet-filebucket - Almacenar y recuperar archivos en un filebucket

SINOPSIS

Un cliente independiente de filebucket de Puppet.

USO

puppet filebucket modo [-h|--help] [-V|--version] [-d|--debug] [-v|--verbose] [-l|--local] [-r|--remote] [-s|--server servidor] [-f|--fromdate fecha] [-t|--todate fecha] [-b|--bucket directorio] archivo archivo ...

Puppet filebucket puede operar en tres modos, con un solo modo por llamada:

backup: Envía uno o más archivos al filebucket especificado. Cada archivo enviado se imprime con su suma sha256 resultante.

get: Devuelve el texto asociado con una suma sha256. El texto se imprime en stdout, y solo se puede recuperar un archivo a la vez.

restore: Dado una ruta de archivo y una suma sha256, almacena el contenido asociado con la suma en la ruta de archivo especificada. Puede especificar una ruta completamente nueva para este argumento; no está restringido a restaurar el contenido a su ubicación original.

diff: Imprime una diferencia en formato unificado entre dos sumas de verificación en el filebucket o entre una suma de verificación y su archivo correspondiente.

list: Enumera todos los archivos en el filebucket local actual. No se permite enumerar filebuckets remotos.

DESCRIPCIÓN

Este es un cliente independiente de filebucket para enviar archivos a un filebucket local o central.

Tenga en cuenta que ´filebucket´ utiliza por defecto un filebucket basado en red disponible en el servidor llamado ´puppet´. Para usar esto, deberá ejecutarse como un usuario con certificados de Puppet válidos. Alternativamente, puede usar su filebucket local especificando ´--local´, o especificando ´--bucket´ con una ruta local.

Importante: Cuando habilita y usa la opción de copia de seguridad, y por extensión el recurso filebucket, debe asegurarse de que haya espacio en disco suficiente para las copias de seguridad de archivos. Generalmente, puede proporcionar el espacio en disco utilizando una de las siguientes dos opciones:

•
Use un comando find y una entrada crontab para conservar solo los últimos X días de copias de seguridad de archivos. Por ejemplo:
  find /opt/puppetlabs/server/data/puppetserver/bucket -type f -mtime +45 -atime +45 -print0 | xargs -0 rm
•
Restringir el directorio a un tamaño máximo después del cual se eliminan los elementos más antiguos.

OPCIONES

Tenga en cuenta que cualquier configuración válida en el archivo de configuración también es un argumento largo válido. Por ejemplo, ´ssldir´ es una configuración válida, por lo que puede especificar ´--ssldir directorio´ como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para obtener la lista completa de parámetros aceptables. También puede generarse una lista comentada de todas las opciones de configuración ejecutando puppet con ´--genconfig´.

--bucket
Especificar una ruta de filebucket local. Esto anula la ruta predeterminada establecida en ´$clientbucketdir´.
--debug
Habilitar depuración completa.
--fromdate
(solo list) Seleccionar archivos del bucket desde ´fromdate´.
--help
Imprimir este mensaje de ayuda.
--local
Usar el filebucket local. Esto utiliza la información de configuración predeterminada y el bucket ubicado en la configuración ´$clientbucketdir´ por defecto. Si se establece ´--bucket´, puppet utiliza esa ruta en su lugar.
--remote
Usar un filebucket remoto. Esto utiliza la información de configuración predeterminada y el bucket ubicado en la configuración ´$bucketdir´ por defecto.
--server_list
Una lista de servidores separados por comas; solo se utiliza la primera entrada para el almacenamiento de archivos. Esta configuración tiene precedencia sobre server.
--server
El servidor a utilizar para el almacenamiento de archivos. Esta configuración solo se utiliza si no se establece server_list.
--todate
(solo list) Seleccionar archivos del bucket hasta ´todate´.
--verbose
Imprimir información adicional.
--version
Imprimir información de la versión.

EJEMPLOS

## Copiar un archivo al filebucket, luego restaurarlo a un directorio temporal
$ puppet filebucket backup /etc/passwd
/etc/passwd: 429b225650b912a2ee067b0a4cf1e949
$ puppet filebucket restore /tmp/passwd 429b225650b912a2ee067b0a4cf1e949
## Diferencia entre dos archivos en el filebucket
$ puppet filebucket -l diff d43a6ecaa892a1962398ac9170ea9bf2 7ae322f5791217e031dc60188f4521ef
1a2
> again
## Diferencia entre el archivo en el filebucket y un archivo local
$ puppet filebucket -l diff d43a6ecaa892a1962398ac9170ea9bf2 /tmp/testFile
1a2
> again
## Copiar un archivo al filebucket y observar que mantiene cada copia de seguridad por separado
$ puppet filebucket -l list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
$ echo again >> /tmp/TestFile
$ puppet filebucket -l backup /tmp/TestFile
/tmp/TestFile: 7ae322f5791217e031dc60188f4521ef
$ puppet filebucket -l list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
## Listar archivos en un filebucket dentro de rangos de fechas
$ puppet filebucket -l -f 2015-01-01 -t 2015-01-11 list
<Salida vacía>
$ puppet filebucket -l -f 2015-05-10 list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
$ puppet filebucket -l -f "2015-05-11 09:30:00" list
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
$ puppet filebucket -l -t "2015-05-11 09:30:00" list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
## Gestionar archivos en un filebucket local específico
$ puppet filebucket -b /tmp/TestBucket backup /tmp/TestFile2
/tmp/TestFile2: d41d8cd98f00b204e9800998ecf8427e
$ puppet filebucket -b /tmp/TestBucket list
d41d8cd98f00b204e9800998ecf8427e 2015-05-11 09:33:22 /tmp/TestFile2
## Desde un servidor de Puppet, listar archivos en el bucketdir del servidor
$ puppet filebucket -b $(puppet config print bucketdir --section server) list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
