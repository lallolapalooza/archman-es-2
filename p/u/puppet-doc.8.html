NOMBRE

puppet-doc - Generar referencias de Puppet

SINOPSIS

Genera una referencia para todos los tipos de Puppet. Principalmente destinado a uso interno de Puppet Inc. (Obsoleto)

USO

puppet doc [-h|--help] [-l|--list] [-r|--reference nombre-referencia]

DESCRIPCION

Este comando obsoleto genera un documento Markdown en stdout describiendo todos los tipos de Puppet instalados o todos los argumentos permitidos para los ejecutables de puppet. Está destinado principalmente a uso interno y se utiliza para generar el documento de referencia disponible en el sitio web de Puppet Inc.

Para la documentación de módulos de Puppet (y todos los demás casos de uso), este comando ha sido reemplazado por el módulo "puppet-strings" - ver https://github.com/puppetlabs/puppetlabs-strings para más información.

Este comando (puppet-doc) será eliminado una vez que el pipeline interno de procesamiento de documentación de puppetlabs se base completamente en puppet-strings.

OPCIONES

--help
Imprime este mensaje de ayuda
--reference
Construye una referencia particular. Obtenga una lista de referencias ejecutando ´puppet doc --list´.

EJEMPLO

$ puppet doc -r type > /tmp/type_reference.markdown
