putgrent(3) Manual de funciones de biblioteca putgrent(3)

NOMBRE

putgrent - escribe una entrada de base de datos de grupo en un archivo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Véase feature_test_macros(7) */
#include <grp.h>
int putgrent(const struct group *restrict grp, FILE *restrict stream);

DESCRIPCIÓN

La función putgrent() es la contraparte de fgetgrent(3). La función escribe el contenido de la struct group proporcionada en el stream. La lista de miembros del grupo debe terminar en NULL o inicializarse a NULL.

La struct group se define de la siguiente manera:


struct group {
    char   *gr_name;      /* nombre del grupo */
    char   *gr_passwd;    /* contraseña del grupo */
    gid_t   gr_gid;       /* ID del grupo */
    char  **gr_mem;       /* miembros del grupo */
};

VALOR DE RETORNO

La función devuelve cero si tiene éxito y un valor distinto de cero si hay un error.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
putgrent () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU.

VER TAMBIÉN

fgetgrent(3), getgrent(3), group(5)
