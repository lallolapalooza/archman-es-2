NOMBRE

puppet-config - Interactuar con la configuración de Puppet.

SINOPSIS

puppet config acción [--section SECCIÓN_NOMBRE]

DESCRIPCIÓN

Este subcomando puede inspeccionar y modificar la configuración del archivo de configuración ´puppet.conf´ de Puppet. Para documentación sobre configuraciones individuales, véase https://puppet.com/docs/puppet/latest/configuration.html.

OPCIONES

Tenga en cuenta que cualquier configuración válida en el archivo de configuración también es un argumento largo válido, aunque puede ser o no relevante para la acción presente. Por ejemplo, server y run_mode son configuraciones válidas, por lo que puede especificar --server <nombre_servidor>, o --run_mode <modo_ejecución> como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para la lista completa de parámetros aceptables. También se puede generar una lista comentada de todas las opciones de configuración ejecutando puppet con --genconfig.

--render-as FORMATO
El formato en el que se renderizará la salida. Los formatos más comunes son json, s (string), yaml y console, pero otras opciones como dot a veces están disponibles.
--verbose
Si se registrará de forma detallada.
--debug
Si se registrará información de depuración.
--section NOMBRE_SECCIÓN
La sección del archivo de configuración puppet.conf con la que interactuar.
Las tres secciones más comúnmente usadas son ´main´, ´server´ y ´agent´. ´Main´ es el valor predeterminado y es utilizado por todas las aplicaciones de Puppet. Otras secciones pueden anular los valores de ´main´ para aplicaciones específicas --- la sección ´server´ afecta a Puppet Server, y la sección ´agent´ afecta a puppet agent.
Menos comúnmente utilizada es la sección ´user´, que afecta a puppet apply. Cualquier otra sección se tratará como el nombre de un entorno heredado (una característica obsoleta), y solo puede incluir las configuraciones ´manifest´ y ´modulepath´.

ACCIONES

delete - Eliminar una configuración de Puppet.
SINOPSIS
puppet config delete [--section NOMBRE_SECCIÓN] configuración
DESCRIPCIÓN
Elimina una configuración de la sección especificada. (El valor predeterminado es la sección ´main´).
NOTAS
Por defecto, esta acción elimina la configuración del dominio de configuración ´main´. Utilice las opciones ´--section´ para eliminar configuraciones de otros dominios de configuración.
print - Examinar las configuraciones actuales de Puppet.
SINOPSIS
puppet config print [--section NOMBRE_SECCIÓN] all | configuración [configuración ...]
DESCRIPCIÓN
Imprime el valor de una configuración única o una lista de configuraciones.
Esta acción es una interfaz de reemplazo para la información disponible con puppet <subcomando> --configprint.
NOTAS
Por defecto, esta acción lee la configuración general en la sección ´main´. Utilice las opciones ´--section´ y ´--environment´ para examinar otros dominios de configuración.
set - Establecer las configuraciones de Puppet.
SINOPSIS
puppet config set [--section NOMBRE_SECCIÓN] [nombre_configuración] [valor_configuración]
DESCRIPCIÓN
Actualiza valores en el archivo de configuración puppet.conf.
NOTAS
Por defecto, esta acción manipula la configuración en la sección ´main´. Utilice la opción ´--section´ para manipular otros dominios de configuración.

EJEMPLOS

delete

Eliminar la configuración ´nombre_configuración´ del dominio de configuración ´main´:

$ puppet config delete nombre_configuración

Eliminar la configuración ´nombre_configuración´ del dominio de configuración ´server´:

$ puppet config delete nombre_configuración --section server

print

Obtener el directorio de ejecución de puppet:

$ puppet config print rundir

Obtener una lista de directorios importantes de la configuración del servidor:

$ puppet config print all --section server | grep -E "(path|dir)"

set

Establecer el directorio de ejecución de puppet:

$ puppet config set rundir /var/run/puppetlabs

Establecer el directorio de datos (vardir) solo para el agente:

$ puppet config set vardir /opt/puppetlabs/puppet/cache --section agent
