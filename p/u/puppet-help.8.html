NOMBRE

puppet-help - Muestra la ayuda de Puppet.

SINOPSIS

puppet help acción

OPCIONES

Ten en cuenta que cualquier ajuste que sea válido en el archivo de configuración también es un argumento largo válido, aunque puede o no ser relevante para la acción presente. Por ejemplo, server y run_mode son ajustes válidos, por lo que puedes especificar --server <nombre_servidor>, o --run_mode <modo_ejecucion> como argumento.

Consulta la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para la lista completa de parámetros aceptables. También se puede generar una lista comentada de todas las opciones de configuración ejecutando puppet con --genconfig.

--render-as FORMATO
El formato en el que se renderizará la salida. Los formatos más comunes son json, s (string), yaml y console, pero otras opciones como dot a veces están disponibles.
--verbose
Si se debe registrar de forma detallada.
--debug
Si se deben registrar información de depuración.

ACCIONES

help - Muestra ayuda sobre los subcomandos de Puppet y sus acciones.
SINOPSIS
puppet help [--version VERSIÓN] [--ronn] [subcomando] [acción]
DESCRIPCIÓN
Muestra ayuda sobre los subcomandos de Puppet y sus acciones.
OPCIONES --ronn - Si se debe renderizar el texto de ayuda en formato ronn.
--version VERSIÓN - La versión del subcomando para la que se debe mostrar la ayuda.
RETORNA
Texto de ayuda corto para el subcomando o acción especificado.

EJEMPLOS

help

Obtener ayuda para una acción:

$ puppet help
