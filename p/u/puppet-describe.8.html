NOMBRE

puppet-describe - Muestra ayuda sobre los tipos de recursos

SINOPSIS

Imprime ayuda sobre los tipos de recursos, proveedores y metaparámetros de Puppet.

USO

puppet describe [-h|--help] [-s|--short] [-p|--providers] [-l|--list] [-m|--meta]

OPCIONES

--help
Imprime este texto de ayuda
--providers
Describe los proveedores en detalle para cada tipo
--list
Lista todos los tipos
--meta
Lista todos los metaparámetros
--short
Lista solo los parámetros sin detalle

EJEMPLO

$ puppet describe --list
$ puppet describe file --providers
$ puppet describe user -s -m
