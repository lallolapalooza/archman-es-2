NOMBRE

puppet-script - Ejecutar un manifiesto de puppet como un script sin compilar un catálogo

SINOPSIS

Ejecuta un script de lenguaje puppet sin compilar un catálogo.

USO

puppet script [-h|--help] [-V|--version] [-d|--debug] [-v|--verbose] [-e|--execute] [-l|--logdest syslog|eventlog|ARCHIVO|consola] [--noop] archivo

DESCRIPCIÓN

Esta es una herramienta independiente para ejecutar scripts de puppet; úsela para ejecutar código de puppet sin compilar un catálogo.

Cuando se proporciona un `modulepath`, a través de la línea de comandos o del archivo de configuración, `puppet script` puede cargar funciones, tipos, tareas y planes desde módulos.

OPCIONES

Tenga en cuenta que cualquier configuración válida en el archivo de configuración también es un argumento largo válido. Por ejemplo, `environment` es una configuración válida, por lo que puede especificar `--environment mytest` como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para obtener la lista completa de parámetros aceptables. También se puede generar una lista comentada de todas las opciones de configuración ejecutando puppet con `--genconfig`.

--debug
Habilita la depuración completa.
--help
Imprime este mensaje de ayuda
--logdest
A dónde enviar los mensajes de registro. Elija entre `syslog` (el servicio syslog POSIX), `eventlog` (el registro de eventos de Windows), `consola` o la ruta a un archivo de registro. Por defecto es `consola`. Se pueden establecer varios destinos usando una lista separada por comas (ej: /ruta/archivo1,consola,/ruta/archivo2)"
Una ruta que termina en `.json` recibirá salida estructurada en formato JSON. El archivo de registro no tendrá un `]` final escrito automáticamente debido a la naturaleza de adición de los registros. Debe agregarse manualmente para que el contenido sea JSON válido.
Una ruta que termina en `.jsonl` recibirá salida estructurada en formato JSON Lines.
--noop
Utiliza el modo `noop` donde Puppet se ejecuta en modo de no operación o de simulación. Esto es útil para ver qué cambios realizará Puppet sin ejecutar realmente los cambios. Se aplica solo a las tareas.
--execute
Ejecuta una pieza específica de código Puppet
--verbose
Imprime información adicional.

EJEMPLO

$ puppet script -l /tmp/manifest.log manifest.pp
$ puppet script --modulepath=/root/dev/modules -e ´notice("hola mundo")´
