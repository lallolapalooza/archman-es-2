NOMBRE

puppet-generate - Genera código Puppet a partir de definiciones Ruby.

SINOPSIS

puppet generate acción

OPCIONES

Tenga en cuenta que cualquier configuración válida en el archivo de configuración también es un argumento largo válido, aunque puede o no ser relevante para la acción actual. Por ejemplo, server y run_mode son configuraciones válidas, por lo que puede especificar --server <nombre_servidor>, o --run_mode <modo_ejecucion> como argumento.

Consulte la documentación del archivo de configuración en https://puppet.com/docs/puppet/latest/configuration.html para obtener la lista completa de parámetros aceptables. También puede generar una lista comentada de todas las opciones de configuración ejecutando puppet con --genconfig.

--render-as FORMATO
El formato en el que se renderizará la salida. Los formatos más comunes son json, s (cadena), yaml y console, pero otras opciones como dot a veces están disponibles.
--verbose
Si se debe registrar de forma detallada.
--debug
Si se deben registrar información de depuración.

ACCIONES

types - Genera código Puppet para tipos personalizados
SINOPSIS
puppet generate types [--format formato] [--force]
DESCRIPCIÓN
Genera definiciones para tipos de recursos personalizados utilizando código Puppet.
Los tipos definidos en código Puppet se pueden utilizar para aislar definiciones de tipos personalizados entre diferentes entornos.
OPCIONES --force - Fuerza la generación de archivos de salida (omite las comprobaciones de actualización).
--format <formato> - El formato de salida de generación a utilizar. Formatos admitidos: pcore.

EJEMPLOS

types

Genera definiciones de tipos Puppet para todos los tipos de recursos personalizados en el entorno actual:

$ puppet generate types

Genera definiciones de tipos Puppet para todos los tipos de recursos personalizados en el entorno especificado:

$ puppet generate types --environment development
