PUTC(3P) Manual del programador POSIX PUTC(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

putc — poner un byte en un flujo

SINTAXIS

#include <stdio.h>
int putc(int c, FILE *stream);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función putc() será equivalente a fputc(), excepto que si se implementa como una macro puede evaluar stream más de una vez, por lo que el argumento nunca debe ser una expresión con efectos secundarios.

VALOR DE RETORNO

Consulte fputc().

ERRORES

Consulte fputc().

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE APLICACIÓN

Dado que puede implementarse como una macro, putc() puede tratar incorrectamente un argumento stream con efectos secundarios. En particular, putc(c,*f++) no necesariamente funciona correctamente. Por lo tanto, no se recomienda el uso de esta función en tales situaciones; en su lugar, se debe usar fputc().
