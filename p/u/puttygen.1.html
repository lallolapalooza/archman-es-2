puttygen(1) Conjunto de herramientas de PuTTY puttygen(1)

NOMBRE

puttygen - generador de claves públicas para las herramientas de PuTTY

SINOPSIS

puttygen ( archivo-clave | -t tipo-clave [ -b bits ] [ --primes metodo ] [ -q ] )
         [ -C nuevo-comentario ] [ -P ] [ --reencrypt ]
         [ --certificate archivo-cert | --remove-certificate ]
         [ -O tipo-salida | -l | -L | -p | --dump | --cert-info ]
            [ --ppk-param clave=valor,... | -E tipo-huella ]
         [ -o archivo-salida ]

DESCRIPCIÓN

puttygen es una herramienta para generar y manipular pares de claves públicas y privadas SSH. Forma parte del conjunto de herramientas de PuTTY, aunque también puede interoperar con los formatos de clave utilizados por algunos otros clientes SSH.

Cuando ejecutas puttygen, realiza tres acciones. Primero, carga un archivo de clave existente (si especificaste archivo-clave) o genera una nueva clave (si especificaste tipo-clave). Luego, opcionalmente realiza modificaciones a la clave (como cambiar el comentario y/o la contraseña); finalmente, emite la clave, o alguna información sobre ella, a un archivo.

Las tres fases están controladas por las opciones descritas en la siguiente sección.

OPCIONES

En la primera fase, puttygen carga o genera una clave. Ten en cuenta que generar una clave requiere datos aleatorios, lo que puede hacer que puttygen se detenga, posiblemente durante algún tiempo si tu sistema no tiene mucha aleatoriedad disponible.

Las opciones para controlar esta fase son:

archivo-clave
Especifica un archivo de clave a cargar. (Usa `-' para leer un archivo de clave desde la entrada estándar).

Normalmente, será una clave privada, que puede estar en formato de clave SSH-1 (estándar de facto), o en formato de clave SSH-2 de PuTTY, o en cualquiera de los formatos de clave privada SSH-2 utilizados por OpenSSH y la implementación de ssh.com.

También puedes especificar un archivo que contenga solo una clave pública aquí. Las operaciones que puedes realizar están limitadas a emitir otra clave pública en formato (posiblemente eliminando un certificado adjunto primero), o una huella digital. Las claves públicas pueden estar en formato RFC 4716 u OpenSSH, o en formato SSH-1 estándar.

-t tipo-clave
Especifica un tipo de clave a generar. Los valores aceptables aquí son rsa, dsa, ecdsa, eddsa, ed25519 y ed448 (para generar claves SSH-2), y rsa1 (para generar claves SSH-1).
-b bits
Especifica el tamaño de la clave a generar, en bits. El valor predeterminado para las claves rsa y dsa es 2048.
--primes metodo
Método para generar números primos. Los valores aceptables aquí son probable (el valor predeterminado), proven y proven-even; los métodos posteriores son más lentos. (También se aceptan varios sinónimos para estos nombres de método).

El método de `números primos probables' suena inseguro, pero es la estrategia de generación de primos más comúnmente utilizada. Teóricamente, existe la posibilidad de que genere accidentalmente un número que no sea primo, pero el software realiza suficientes comprobaciones para que esa probabilidad sea insignificante (menos de 1 en 2^80, o 1 en 10^24). Así que, en la práctica, nadie se preocupa mucho por ello.

Los otros métodos hacen que PuTTYgen utilice números que está seguro que son primos, porque genera el número de salida junto con una prueba de su primalidad. Esto requiere más esfuerzo, pero elimina ese riesgo teórico del método probabilístico.

Podrías optar por cambiar de primos probables a probados si tienes un estándar de seguridad local que lo exija, o si no confías en el argumento probabilístico para la seguridad del método habitual.

--strong-rsa
Al generar una clave RSA, asegúrate de que los factores primos del módulo de la clave sean `primos fuertes'. Un primo fuerte es un número primo elegido para tener una estructura particular que hace que ciertos algoritmos de factorización sean más difíciles de aplicar, por lo que algunos estándares de seguridad recomiendan su uso. Sin embargo, los algoritmos de factorización más modernos no se ven afectados, por lo que es probable que esta opción no valga la pena activarla a menos que tengas un estándar local que la recomiende.
-q
Suprime la visualización del progreso al generar una nueva clave.
--old-passphrase archivo
Especifica un nombre de archivo; la primera línea se leerá de este archivo (eliminando cualquier salto de línea final) y se usará como la contraseña anterior. PRECAUCIÓN: Si la contraseña es importante, el archivo debería almacenarse en un sistema de archivos temporal o bien borrarse de forma segura después de su uso.
--random-device dispositivo
Especifica el dispositivo del que leer la entropía. Por defecto, puttygen usa /dev/urandom, recurriendo a /dev/random si es necesario.

En la segunda fase, puttygen altera opcionalmente las propiedades de la clave que ha cargado o generado. Las opciones para controlar esto son:

-C nuevo-comentario
Especifica una cadena de comentario para describir la clave. Esta cadena de comentario será utilizada por PuTTY para identificarte la clave (al pedirte la contraseña, por ejemplo, para que sepas qué contraseña escribir).
-P
Indica que quieres cambiar la contraseña de la clave. Esto es automático al generar una nueva clave, pero no al modificar una clave existente.
--certificate archivo-certificado
Añade un certificado estilo OpenSSH a la parte pública de la clave, de modo que el archivo de salida contenga una clave pública certificada con la misma clave privada. Si el archivo de entrada ya contenía un certificado, se reemplazará con el nuevo. (Usa `-' para leer un certificado desde la entrada estándar).
--remove-certificate
Elimina cualquier certificado que formara parte de la clave, para recuperar la versión no certificada de la clave subyacente.
--reencrypt
Para una clave privada existente guardada con contraseña, actualiza el cifrado sin cambiar la contraseña.

Esto es más probablemente útil con la opción --ppk-param, para cambiar algún aspecto del formato o cifrado del archivo de clave.

--ppk-param clave=valor,...
Al guardar un archivo PPK (el tipo de salida private predeterminado para claves SSH-2), ajusta los detalles del formato en disco.

Los aspectos a cambiar se especifican como una serie de pares clave=valor separados por comas. Las claves son:

version
La versión del formato PPK. Los valores posibles son 3 (el valor predeterminado) y 2 (que es menos resistente a la descifrado por fuerza bruta, pero que podrías necesitar si tu clave debe ser utilizada por versiones antiguas de las herramientas de PuTTY, u otros consumidores de PPK).

Las siguientes claves solo afectan a los archivos PPK versión 3.

kdf
La variante de la función de derivación de claves Argon2 a utilizar. Las opciones son argon2id (predeterminado y recomendado), argon2i y argon2d.

Es posible que cambie esto si considera que su exposición a ataques de canal lateral es diferente a la normal.

memoria
La cantidad de memoria necesaria para descifrar la clave, en Kbyte. El valor predeterminado es 8192 (es decir, 8 Mbyte).
tiempo
Tiempo aproximado, en esta máquina, necesario para intentar descifrar la clave, en milisegundos. El valor predeterminado es 100 (ms).
pases
Alternativa a tiempo: especifique explícitamente el número de pases de hash requeridos para intentar descifrar la clave.
paralelismo
Número de hilos paralelizados que se pueden utilizar para descifrar la clave. El valor predeterminado es 1 (fuerza a que el descifrado se ejecute en un solo hilo).

En la tercera fase, puttygen guarda la clave o información sobre ella. Las opciones para controlar esto son:

-O tipo-de-salida
Especifique el tipo de salida que desea que produzca puttygen. Las opciones aceptables son:
privada
Guarda la clave privada en un formato utilizable por PuTTY. Este será el formato de clave SSH-1 estándar o el formato de clave SSH-2 propio de PuTTY (`PPK'). Este es el valor predeterminado.
pública
Guarda solo la clave pública. Para claves SSH-1, se utilizará el formato de clave pública estándar (`1024 37 5698745...'). Para claves SSH-2, la clave pública se emitirá en el formato especificado por RFC 4716, que es un archivo de texto multilínea que comienza con la línea `---- BEGIN SSH2 PUBLIC KEY ----'.
public-openssh
Guarda solo la clave pública, en un formato utilizable por OpenSSH. Para claves SSH-1, este formato de salida se comporta de manera idéntica a pública. Para claves SSH-2, la clave pública se emitirá en el formato OpenSSH, que es una sola línea (`ssh-rsa AAAAB3NzaC1yc2...').
huella-digital
Imprime una huella digital de la clave pública. La opción -E le permite especificar qué algoritmo de huella digital utilizar. Se cree que todos los algoritmos son compatibles con OpenSSH.
private-openssh
Guarda una clave privada SSH-2 en el formato de OpenSSH, utilizando el formato más antiguo disponible para maximizar la compatibilidad retroactiva. Esta opción no está permitida para claves SSH-1.
private-openssh-new
Igual que private-openssh, excepto que fuerza el uso del formato más nuevo de OpenSSH incluso para claves RSA, DSA y ECDSA.
private-sshcom
Guarda una clave privada SSH-2 en el formato de ssh.com. Esta opción no está permitida para claves SSH-1.
cert-info
Guarda un volcado textual de información sobre el certificado en la clave, si lo hay: si es un certificado de host o de usuario, para qué host(s) o usuario(s) está certificado, su período de validez, ID y número de serie, y la huella digital de la CA firmante.
texto
Guarda un volcado textual de los componentes numéricos que componen la clave (tanto la parte pública como la privada, si están presentes). Útil para depuración o para usar PuTTYgen como generador de claves para aplicaciones que no sean SSH.

La salida consiste en una serie de líneas nombre=valor, donde cada valor es una cadena literal estilo C entre comillas dobles, un número hexadecimal que comienza con 0x..., o un bloque binario codificado en base64, denotado por b64("...").

Si no se especifica ningún tipo de salida, el valor predeterminado es privada.

-o archivo-de-salida
Especifique el archivo donde puttygen debe escribir su salida. Si esta opción no se especifica, puttygen asumirá que desea sobrescribir el archivo original si los tipos de archivo de entrada y salida son los mismos (cambiando un comentario o una frase de contraseña), y asumirá que desea emitir a stdout si está solicitando una clave pública, una huella digital o uno de los tipos de volcado textual. De lo contrario, la opción -o es obligatoria.
-l
Sinónimo de `-O huella-digital'.
-L
Sinónimo de `-O public-openssh'.
-p
Sinónimo de `-O pública'.
--cert-info
Sinónimo de `-O cert-info'.
--dump
Sinónimo de `-O texto'.
-E tipo-huella
Especifique el algoritmo a utilizar al generar una huella digital. Los algoritmos disponibles son sha256 (el predeterminado) y md5.

Por defecto, al mostrar la huella digital de una clave pública que incluye un certificado, puttygen no incluirá el certificado, de modo que la huella digital mostrada será la misma que la de la clave pública subyacente. Si desea la huella digital incluyendo el certificado (por ejemplo, para distinguir dos claves certificadas), puede especificar sha256-cert o md5-cert como tipo de huella digital.

--new-passphrase archivo
Especifique un nombre de archivo; se leerá la primera línea de este archivo (eliminando cualquier salto de línea final) y se utilizará como la nueva frase de contraseña. Si el archivo está vacío, la clave guardada no estará cifrada. PRECAUCIÓN: Si la frase de contraseña es importante, el archivo debe almacenarse en un sistema de archivos temporal o borrarse de forma segura después de su uso.

Las siguientes opciones no ejecutan PuTTYgen normalmente, sino que muestran mensajes informativos y luego salen:

-h, --help
Muestra un mensaje resumiendo las opciones disponibles.
-V, --version
Muestra la versión de PuTTYgen.
--pgpfp
Muestra las huellas digitales de las Claves Maestras PGP de PuTTY, para ayudar a verificar los nuevos archivos publicados por el equipo de PuTTY.

EJEMPLOS

Para generar un par de claves RSA SSH-2 y guardarlo en el formato propio de PuTTY (se le pedirá la frase de contraseña):

puttygen -t rsa -C "mi clave personal" -o mi_clave.ppk

Para generar una clave más grande (4096 bits):

puttygen -t rsa -b 4096 -C "mi clave personal" -o mi_clave.ppk

Para cambiar la frase de contraseña de una clave (se le pedirá la frase de contraseña antigua y la nueva):

puttygen -P mi_clave.ppk

Para cambiar el comentario de una clave:

puttygen -C "nuevo comentario" mi_clave.ppk

Para convertir una clave al formato de clave privada de OpenSSH:

puttygen mi_clave.ppk -O private-openssh -o mi_clave_openssh

Para convertir una clave *de* otro formato (puttygen detectará automáticamente el tipo de clave de entrada):

puttygen mi_clave_ssh.com -o mi_clave.ppk

Para mostrar la huella digital SHA-256 de una clave (algunos tipos de clave requieren una frase de contraseña para extraer incluso esta información):

puttygen -l mi_clave.ppk

Para añadir la mitad pública de una clave en formato OpenSSH a su archivo de claves autorizadas:

puttygen -L mi_clave.ppk >> $HOME/.ssh/authorized_keys
