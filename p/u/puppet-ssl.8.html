NOMBRE

puppet-ssl - Administrar claves y certificados SSL para clientes SSL de puppet

SINOPSIS

Administra claves y certificados SSL para clientes SSL que necesiten comunicarse con una infraestructura puppet.

USO

puppet ssl acción [-h|--help] [-v|--verbose] [-d|--debug] [--localca] [--target CERTNAME]

OPCIONES

  • --help: Imprime este mensaje de ayuda.
  • --verbose: Imprime información adicional.
  • --debug: Habilita la depuración completa.
  • --localca También limpia el certificado de CA local y la CRL.
  • --target CERTNAME Limpia el certificado del dispositivo especificado en lugar del certificado de este host.

ACCIONES

bootstrap
Realiza todos los pasos necesarios para solicitar y descargar un certificado de cliente. Si la firma automática está deshabilitada, puppet esperará cada waitforcert segundos a que su certificado sea firmado. Para intentar solo una vez y nunca esperar, especifica un tiempo de 0. Como waitforcert es una configuración de Puppet, puede especificarse como un intervalo de tiempo, como 30s, 5m, 1h.
submit_request
Genera una solicitud de firma de certificado (CSR) y la envía a la CA. Si ya existen un par de claves privada y pública, se utilizarán para generar la CSR. De lo contrario, se generará un nuevo par de claves. Si ya se ha enviado una CSR con el certname dado, la operación fallará.
generate_request
Genera una solicitud de firma de certificado (CSR). Si ya existen un par de claves privada y pública, se utilizarán para generar la CSR. De lo contrario, se generará un nuevo par de claves.
download_cert
Descarga un certificado para este host. Si la clave privada actual coincide con el certificado descargado, el certificado se guardará y se utilizará para solicitudes posteriores. Si ya existe un certificado, será sobrescrito.
verify
Verifica que la clave privada y el certificado estén presentes y coincidan, verifica que el certificado sea emitido por una CA de confianza y comprueba el estado de revocación.
clean
Elimina los archivos relacionados con la clave privada y el certificado para este host. Si se especifica --localca, también elimina la copia local de los certificados de CA y el paquete CRL de este host. Si se especifica --target CERTNAME, elimina los archivos para el dispositivo especificado en este host en lugar de este host.
show
Imprime la versión en texto completo del certificado de este host.
