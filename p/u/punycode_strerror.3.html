punycode_strerror(3) libidn punycode_strerror(3)

NOMBRE

punycode_strerror - función de la API

SINOPSIS

#include <punycode.h>

const char * punycode_strerror(Punycode_status rc);

ARGUMENTOS

Punycode_status rc
un código de retorno de Punycode_status.

DESCRIPCIÓN

Convierte un entero de código de retorno a una cadena de texto. Esta cadena se puede usar para mostrar un mensaje de diagnóstico al usuario.

PUNYCODE_SUCCESS

Operación exitosa. Este valor siempre será cero, los restantes solo garantizan contener valores distintos de cero, para fines de comparación lógica.

PUNYCODE_BAD_INPUT

La entrada no es válida.

PUNYCODE_BIG_OUTPUT

La salida excedería el espacio proporcionado.

PUNYCODE_OVERFLOW

La entrada necesita enteros más amplios para procesar.

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una descripción del error con el código de retorno rc.
