NOMBRE

putty - cliente gráfico SSH, Telnet, Rlogin y SUPDUP para X

SINOPSIS

putty [ opciones ] [ host ]

DESCRIPCIÓN

putty es un cliente gráfico SSH, Telnet, Rlogin y SUPDUP para X. Es una portación directa del cliente SSH para Windows del mismo nombre.

OPCIONES

Las opciones de línea de comandos compatibles con putty son:

--display nombre-pantalla
Especifica la pantalla X en la que abrir putty. (Nota: esta opción tiene un doble guion, aunque ninguna de las otras lo tiene. Esto se debe a que esta opción es suministrada automáticamente por GTK. Lo sentimos.)
-fn nombre-fuente
Especifica la fuente a usar para texto normal mostrado en el terminal. Por ejemplo, -fn fixed, -fn "Monospace 12".
-fb nombre-fuente
Especifica la fuente a usar para texto en negrita mostrado en el terminal. Si el recurso BoldAsColour está configurado a 1 (el valor por defecto), el texto en negrita se mostrará en colores diferentes en lugar de una fuente diferente, por lo que esta opción se ignorará. Si BoldAsColour está configurado a 0 o 2 y no especifica una fuente en negrita, putty sobrescribirá la fuente normal para que parezca más negrita.
-fw nombre-fuente
Especifica la fuente a usar para caracteres de doble ancho (típicamente texto chino, japonés y coreano) mostrado en el terminal.
-fwb nombre-fuente
Especifica la fuente a usar para caracteres de doble ancho en negrita (típicamente texto chino, japonés y coreano). Al igual que -fb, esto se ignorará a menos que el recurso BoldAsColour esté configurado a 0 o 2.
-geometry geometría
Especifica el tamaño del terminal, en filas y columnas de texto. Véase X(7) para más información sobre la sintaxis de las especificaciones de geometría.
-sl líneas
Especifica el número de líneas de scrollback a guardar por encima del terminal.
-fg color
Especifica el color de primer plano a usar para texto normal.
-bg color
Especifica el color de fondo a usar para texto normal.
-bfg color
Especifica el color de primer plano a usar para texto en negrita, si el recurso BoldAsColour está configurado a 1 (por defecto) o 2.
-bbg color
Especifica el color de primer plano a usar para texto en negrita de video inverso, si el recurso BoldAsColour está configurado a 1 (por defecto) o 2. (Este color se concibe mejor como la versión en negrita del color de fondo; por lo tanto, solo aparece cuando el texto se muestra *en* el color de fondo).
-cfg color
Especifica el color de primer plano a usar para el texto cubierto por el cursor.
-cbg color
Especifica el color de fondo a usar para el texto cubierto por el cursor. En otras palabras, este es el color principal del cursor.
-title título
Especifica el título inicial de la ventana del terminal. (Esto puede ser cambiado bajo control del servidor.)
-sb- o +sb
Indica a putty que no muestre una barra de desplazamiento.
-sb
Indica a putty que muestre una barra de desplazamiento: esto es lo opuesto a -sb-. Esta es la opción por defecto: probablemente solo necesite especificarla explícitamente si ha cambiado el valor por defecto usando el recurso ScrollBar.
-log archivo-registro, -sessionlog archivo-registro
Esta opción hace que putty registre toda la salida del terminal en un archivo además de mostrarla en el terminal.
-sshlog archivo-registro
-sshrawlog archivo-registro
Para conexiones SSH, estas opciones hacen que putty registre detalles del protocolo en un archivo. (Algunos de estos pueden ser sensibles, aunque por defecto se hace un esfuerzo por suprimir contraseñas obvias).

-sshlog registra paquetes SSH decodificados y otros eventos (aquellos que -v imprimiría). -sshrawlog registra además los datos brutos de los paquetes cifrados.

-logoverwrite
Si putty está configurado para escribir en un archivo de registro que ya existe, descarta el archivo existente.
-logappend
Si putty está configurado para escribir en un archivo de registro que ya existe, añade los nuevos datos de registro al archivo existente.
-cs conjunto-caracteres
Esta opción especifica el conjunto de caracteres en el que putty debe asumir que está operando la sesión. Este conjunto de caracteres se utilizará para interpretar todos los datos recibidos de la sesión, y toda la entrada que escriba o pegue en putty se convertirá a este conjunto de caracteres antes de ser enviada a la sesión.

Cualquier nombre de conjunto de caracteres que sea válido en una cabecera MIME (y compatible con putty) debería ser válido aquí (ejemplos son `ISO-8859-1', `windows-1252' o `UTF-8'). Además, cualquier codificación de caracteres que sea válida en una descripción de fuente lógica de X debería ser válida (`ibm-cp437', por ejemplo).

El comportamiento por defecto de putty es usar la misma codificación de caracteres que su fuente principal. Si proporciona una fuente Unicode (iso10646-1), por defecto usará el conjunto de caracteres UTF-8.

Los nombres de los conjuntos de caracteres no distinguen entre mayúsculas y minúsculas.

-nethack
Indica a putty que habilite el modo de teclado NetHack, en el cual el teclado numérico genera las teclas de dirección hjklyubn de NetHack. Esto le permite jugar NetHack con el teclado numérico sin tener que usar la opción number_pad de NetHack (que requiere que presione 'n' antes de cualquier cuenta de repetición). Así puede moverse con el teclado numérico y introducir cuentas de repetición con las teclas numéricas normales.
-help, --help
Muestra un mensaje resumiendo las opciones disponibles.
-pgpfp
Muestra las huellas digitales de las Claves PGP Maestras de PuTTY, para ayudar a verificar nuevos archivos publicados por el equipo de PuTTY.
-load sesión
Carga una sesión guardada por nombre. Esto le permite ejecutar una sesión guardada directamente desde la línea de comandos sin tener que pasar primero por el cuadro de configuración.
-ssh, -telnet, -rlogin, -supdup, -raw, -ssh-connection, -serial
Selecciona el protocolo que putty usará para establecer la conexión.
-proxycmd comando
En lugar de establecer una conexión TCP, usa comando como proxy; el tráfico de red se redirigirá a la entrada y salida estándar de comando. comando debe ser una sola palabra, por lo que es probable que necesite ser citada por el shell.

Las cadenas especiales %host y %port en comando serán reemplazadas por el nombre de host y el número de puerto al que desea conectarse; para obtener un signo % literal, introduzca %%.

También se admiten secuencias de escape de barra invertida, como secuencias como \n siendo reemplazadas por un salto de línea literal; para obtener una barra invertida literal, introduzca \\. (Puede ser necesario un mayor escape por parte del shell).

(Consulte el manual principal de PuTTY para obtener detalles completos de los tokens compatibles delimitados por % y barra invertida, aunque la mayoría de ellos probablemente no sean muy útiles en este contexto).

OPCIONES

-l nombre_usuario
Especifica el nombre de usuario a utilizar al iniciar sesión en el servidor.
-L [dir_origen:]puerto_origen:host_destino:puerto_destino
Configura un reenvío de puerto local: escucha en puerto_origen (o dir_origen:puerto_origen si se especifica), y reenvía cualquier conexión a través de la conexión SSH al destino host_destino:puerto_destino. Solo funciona en SSH.
-R [dir_origen:]puerto_origen:host_destino:puerto_destino
Configura un reenvío de puerto remoto: solicita al servidor SSH que escuche en puerto_origen (o dir_origen:puerto_origen si se especifica), y que reenvíe cualquier conexión de vuelta a través de la conexión SSH donde el cliente las pasará a la dirección de destino host_destino:puerto_destino. Solo funciona en SSH.
-D [dir_origen:]puerto_origen
Configura un reenvío de puerto dinámico. El cliente escucha en puerto_origen (o dir_origen:puerto_origen si se especifica) e implementa un servidor SOCKS. Por lo tanto, puedes apuntar aplicaciones conscientes de SOCKS a este puerto y automáticamente utilizarán la conexión SSH para tunelizar todas sus conexiones. Solo funciona en SSH.
-P puerto
Especifica el puerto al que conectarse al servidor.
-A, -a
Habilita (-A) o deshabilita (-a) el reenvío del agente SSH. Actualmente esto solo funciona con OpenSSH y SSH-1.
-X, -x
Habilita (-X) o deshabilita (-x) el reenvío de X11.
-T, -t
Habilita (-t) o deshabilita (-T) la asignación de un pseudo-terminal en el extremo del servidor.
-C
Habilita la compresión estilo zlib en la conexión.
-1, -2
Selecciona el protocolo SSH versión 1 o 2.
-4, -6
Fuerza el uso de IPv4 o IPv6 para las conexiones de red.
-i archivo_clave
Archivo de clave privada para la autenticación de usuario. Para claves SSH-2, este archivo de clave debe estar en formato PPK de PuTTY, no en formato OpenSSH ni en ningún otro.

Si estás utilizando un agente de autenticación, también puedes especificar una clave pública aquí (en formato RFC 4716 u OpenSSH), para identificar cuál de las claves del agente usar.

-noagent
No intentes usar un agente de autenticación para la autenticación local. (Esto no afecta al reenvío de agente).
-agent
Permite el uso de un agente de autenticación. (Esta opción solo es necesaria para anular una configuración en una sesión guardada).
-no-trivial-auth
Desconéctate de cualquier servidor SSH que acepte autenticación sin haber solicitado nunca ningún tipo de contraseña, firma o token. (Puede que desees habilitar esto para un servidor que esperas que siempre te desafíe, por ejemplo, para asegurarte de no escribir accidentalmente la frase de contraseña de tu archivo de clave en un servidor comprometido que se hace pasar por el aviso de frase de contraseña de PuTTY).
-hostkey clave
Especifica una clave pública de host aceptable. Esta opción puede especificarse múltiples veces; cada clave puede ser una huella digital (SHA256:AbCdE..., 99:aa:bb:..., etc.) o un blob codificado en base64 en el formato de una sola línea de OpenSSH.

Especificar esta opción anula la gestión automatizada de claves de host; *solo* se aceptarán las claves especificadas en la línea de comandos (a menos que una sesión guardada también anule las claves de host, en cuyo caso se añadirán), y la caché de claves de host no se escribirá.

-sercfg cadena_configuracion
Especifica los parámetros de configuración para el puerto serie, en modo -serial. cadena_configuracion debe ser una lista separada por comas de parámetros de configuración de la siguiente manera:
•
Cualquier dígito individual del 5 al 9 establece el número de bits de datos.
•
`1', `1.5' o `2' establecen el número de bits de parada.
•
Cualquier otra cadena numérica se interpreta como una velocidad en baudios.
•
Una letra minúscula individual especifica la paridad: `n' para ninguna, `o' para impar, `e' para par, `m' para marca y `s' para espacio.
•
Una letra mayúscula individual especifica el control de flujo: `N' para ninguno, `X' para XON/XOFF, `R' para RTS/CTS y `D' para DSR/DTR.

SESIONES GUARDADAS

Las sesiones guardadas se almacenan en un subdirectorio .putty/sessions en tu directorio personal.
