getutent(3) Manual de funciones de biblioteca getutent(3)

NOMBRE

getutent, getutid, getutline, pututline, setutent, endutent, utmpname - acceder a entradas del archivo utmp

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <utmp.h>
struct utmp *getutent(void);
struct utmp *getutid(const struct utmp *ut);
struct utmp *getutline(const struct utmp *ut);
struct utmp *pututline(const struct utmp *ut);
void setutent(void);
void endutent(void);
int utmpname(const char *path);

DESCRIPCIÓN

Las aplicaciones nuevas deben usar las versiones de estas funciones de "utmpx" especificadas por POSIX.1; véase ESTÁNDARES.

utmpname() establece la ruta del archivo de formato utmp para que las otras funciones utmp accedan. Si no se usa utmpname() para establecer la ruta antes de usar las otras funciones, estas asumen _PATH_UTMP, como se define en <paths.h>.

setutent() rebobina el puntero del archivo al principio del archivo utmp. Generalmente es una buena idea llamarla antes que cualquier otra función.

endutent() cierra el archivo utmp. Debería llamarse cuando el código del usuario haya terminado de acceder al archivo con las otras funciones.

getutent() lee una línea de la posición actual del archivo en el archivo utmp. Devuelve un puntero a una estructura que contiene los campos de la línea. La definición de esta estructura se muestra en utmp(5).

getutid() busca hacia adelante desde la posición actual del archivo en el archivo utmp basándose en ut. Si ut->ut_type es uno de RUN_LVL, BOOT_TIME, NEW_TIME o OLD_TIME, getutid() encontrará la primera entrada cuyo campo ut_type coincida con ut->ut_type. Si ut->ut_type es uno de INIT_PROCESS, LOGIN_PROCESS, USER_PROCESS o DEAD_PROCESS, getutid() encontrará la primera entrada cuyo campo ut_id coincida con ut->ut_id.

getutline() busca hacia adelante desde la posición actual del archivo en el archivo utmp. Escanea entradas cuyo ut_type sea USER_PROCESS o LOGIN_PROCESS y devuelve la primera cuyo campo ut_line coincida con ut->ut_line.

pututline() escribe la estructura utmp ut en el archivo utmp. Utiliza getutid() para buscar el lugar adecuado en el archivo para insertar la nueva entrada. Si no puede encontrar una ranura adecuada para ut, pututline() añadirá la nueva entrada al final del archivo.

VALOR DEVUELTO

getutent(), getutid() y getutline() devuelven un puntero a una struct utmp si tienen éxito, y NULL si fallan (lo que incluye el caso de "registro no encontrado"). Esta struct utmp se asigna en almacenamiento estático y puede ser sobrescrita por llamadas posteriores.

Si tiene éxito, pututline() devuelve ut; si falla, devuelve NULL.

utmpname() devuelve 0 si el nuevo nombre se almacenó correctamente, o -1 si falla.

En caso de fallo, estas funciones establecen errno para indicar el error.

ERRORES

ENOMEM
Memoria agotada.
ESRCH
Registro no encontrado.

setutent(), pututline() y las funciones getut*() también pueden fallar por las razones descritas en open(2).

ARCHIVOS

/var/run/utmp
base de datos de usuarios actualmente conectados
/var/log/wtmp
base de datos de inicios de sesión de usuarios pasados

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

En la tabla anterior, utent en race:utent indica que si alguna de las funciones setutent(), getutent(), getutid(), getutline(), pututline(), utmpname() o endutent() se utiliza en paralelo en diferentes hilos de un programa, podrían producirse carreras de datos.

ESTÁNDARES

Ninguno.

HISTORIA

XPG2, SVr4.

En XPG2 y SVID 2, la función pututline() se documenta como void, y eso es lo que hace en muchos sistemas (AIX, HP-UX). HP-UX introduce una nueva función _pututline() con el prototipo dado arriba para pututline().

Todas estas funciones están obsoletas ahora en sistemas no Linux. POSIX.1-2001 y POSIX.1-2008, siguiendo SUSv1, no tienen ninguna de estas funciones, sino que utilizan

#include <utmpx.h>
struct utmpx *getutxent(void);
struct utmpx *getutxid(const struct utmpx *);
struct utmpx *getutxline(const struct utmpx *);
struct utmpx *pututxline(const struct utmpx *);
void setutxent(void);
void endutxent(void);

Estas funciones son proporcionadas por glibc y realizan la misma tarea que sus equivalentes sin la "x", pero utilizan struct utmpx, que en Linux se define como igual a struct utmp. Para mayor completitud, glibc también proporciona utmpxname(), aunque esta función no está especificada por POSIX.1.

En algunos otros sistemas, la estructura utmpx es un superconjunto de la estructura utmp, con campos adicionales, y versiones más grandes de los campos existentes, y se mantienen archivos paralelos, a menudo /var/*/utmpx y /var/*/wtmpx.

Por otro lado, glibc de Linux no utiliza un archivo utmpx paralelo ya que su estructura utmp es lo suficientemente grande. Las funciones "x" enumeradas arriba son solo alias de sus contrapartes sin la "x" (por ejemplo, getutxent() es un alias de getutent()).

NOTAS

Notas de glibc

Las funciones anteriores no son seguras para hilos. glibc añade versiones reentrantes

#include <utmp.h>
int getutent_r(struct utmp *ubuf, struct utmp **ubufp);
int getutid_r(struct utmp *ut,
              struct utmp *ubuf, struct utmp **ubufp);
int getutline_r(struct utmp *ut,
                struct utmp *ubuf, struct utmp **ubufp);

Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

getutent_r(), getutid_r(), getutline_r():

    _GNU_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */    _SVID_SOURCE || _BSD_SOURCE

Estas funciones son extensiones de GNU, análogas a las funciones del mismo nombre sin el sufijo _r. El argumento ubuf proporciona a estas funciones un lugar para almacenar su resultado. En caso de éxito, devuelven 0, y un puntero al resultado se escribe en *ubufp. En caso de error, estas funciones devuelven -1. No existen equivalentes de utmpx para las funciones anteriores. (POSIX.1 no especifica tales funciones).

pututline(3) - manual page

NAME

pututline, setutent, endutent, getutent - add and remove utmp entries

LIBRARY

Standard Libraries (libc, -lc)

SYNOPSIS

#include <utmp.h>
int
pututline(const struct utmp *ut);
void
setutent(void);
struct utmp *
getutent(void);
void
endutent(void);

DESCRIPTION

The pututline(), setutent(), getutent(), and endutent() functions operate on the user accounting database, typically located at /var/run/utmp.

The setutent() function opens the database and rewinds the file pointer to the beginning. The database is opened read-write.

The getutent() function reads the next entry from the database. If the database is not currently open, it is opened implicitly.

The pututline() function writes the structure pointed to by ut to the database. The entry is written at the current file position, and the file position is advanced. If the database is not open, it is opened implicitly.

The endutent() function closes the database and frees any associated resources.

The utmp structure is defined in <utmp.h>. It contains at least the following fields:

ut_type
Type of entry. Possible values are:
EMPTY, RUN_LVL, BOOT_TIME, OLD_TIME, NEW_TIME, INIT_PROCESS, LOGIN_PROCESS, USER_PROCESS, DEAD_PROCESS, ACCOUNTING.
ut_pid
Process ID.
ut_line[UT_LINESIZE]
Name of the device associated with the entry (e.g., /dev/tty0).
ut_id[UT_IDSIZE]
Terminal line identifier. Used for identifying utmp entries.
ut_user[UT_NAMESIZE]
User name.
ut_host[UT_HOSTSIZE]
Hostname and possibly the communication device of a remote user.
ut_time
Time the entry was made.
ut_addr
Internet address of the remote host.

It is recommended to use getutxent(), pututxline(), setutxent(), and endutxent() instead. These functions work with utxline structures, which have a more portable layout and handle time fields correctly.

RETURN VALUE

On success, pututline() returns a pointer to the written structure. On failure, it returns NULL.

The getutent() function returns a pointer to the entry read, or NULL if the end of the file is reached or an error occurs.

The setutent() and endutent() functions do not return values.

ERRORS

These functions may fail for reasons described in open(2), read(2), write(2), and close(2).

FILES

/var/run/utmp: The user accounting database.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Conformancfe See attributes(7).

STANDARDS

The setutent, getutent, pututline, and endutent functions conform to the POSIX.1-2001 standard.

HISTORY

These functions first appeared in Version 1.31 of AT&T UNIX.

NOTES

The pututline() function may leave the file pointer in an indeterminate state if the write fails. Subsequent calls to getutent() may not behave as expected.

The ut_host field may not be null-terminated if the hostname is exactly UT_HOSTSIZE bytes long.

The ut_id field is used to identify sessions. It is often derived from the terminal line, for example, by taking the last component of the device name.

The ut_addr field is typically used to store the IP address of a remote host for login entries.

The utmp database is not typically updated atomically. Applications should be aware of potential race conditions if multiple processes are modifying the database simultaneously.

For most applications, it is recommended to use the utx* family of functions (getutxent, pututxline, etc.), which provide a more robust and portable interface to the utmp database.

EXAMPLES

The following example adds and removes a utmp record, assuming it is run from within a pseudo terminal. For usage in a real application, you should check the return values of getpwuid(3) and ttyname(3).

#include <err.h>
#include <pwd.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <utmp.h>
int
main(void)
{
    struct utmp entry;
    if (system("echo before adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = USER_PROCESS;
    entry.ut_pid = getpid();
    strcpy(entry.ut_line, ttyname(STDIN_FILENO) + strlen("/dev/"));
    /* only correct for ptys named /dev/tty[pqr][0-9a-z] */
    strcpy(entry.ut_id, ttyname(STDIN_FILENO) + strlen("/dev/tty"));
    entry.ut_time = time(NULL);
    strcpy(entry.ut_user, getpwuid(getuid())->pw_name);
    memset(entry.ut_host, 0, UT_HOSTSIZE);
    entry.ut_addr = 0;
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = DEAD_PROCESS;
    memset(entry.ut_line, 0, UT_LINESIZE);
    entry.ut_time = 0;
    memset(entry.ut_user, 0, UT_NAMESIZE);
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after removing entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    endutent();
    exit(EXIT_SUCCESS);
}
