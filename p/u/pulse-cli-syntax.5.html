NOMBRE

pulse-cli-syntax - Sintaxis de la línea de comandos de PulseAudio

SINOPSIS

~/.config/pulse/default.pa

/etc/pulse/default.pa

/etc/pulse/system.pa

DESCRIPCIÓN

PulseAudio proporciona un lenguaje simple de línea de comandos utilizado por scripts de configuración, el shell interactivo pacmd y los módulos module-cli y module-cli-protocol-{unix,tcp}. Las líneas vacías y las líneas que comienzan con un hashmark (#) se ignoran silenciosamente. Se admiten varios comandos.

Tenga en cuenta que cualquier argumento booleano puede darse positivamente como '1', 't', 'y', 'true', 'yes' u 'on'. Del mismo modo, los valores negativos pueden darse como '0', 'f', 'n', 'false', 'no' u 'off'. La capitalización se ignora.

COMANDOS GENERALES

help
Muestra una ayuda rápida sobre los comandos disponibles.

COMANDOS DE ESTADO

list-modules
Muestra todos los módulos cargados actualmente con sus argumentos.
list-cards
Muestra todas las tarjetas registradas actualmente
list-sinks o list-sources
Muestra todos los sinks (resp. sources) registrados actualmente.
list-clients
Muestra todos los clientes activos actualmente.
list-sink-inputs o list-source-outputs
Muestra todas las entradas de sink activas actualmente, también conocidas como streams de reproducción (resp. salidas de source, también conocidas como streams de grabación).
stat
Muestra algunas estadísticas simples sobre los bloques de memoria asignados y el espacio utilizado por ellos.
info o ls o list
Una combinación de todos los comandos de estado descritos anteriormente (los tres comandos son sinónimos).

GESTIÓN DE MÓDULOS

load-module nombre [argumentos...]
Carga un módulo especificado por su nombre y argumentos. Para la mayoría de los módulos, está bien que se carguen más de una vez.
unload-module índice|nombre
Descarga un módulo, especificado por su índice en la lista de módulos o su nombre.
describe-module nombre
Proporciona información sobre un módulo especificado por su nombre.

COMANDOS DE VOLUMEN

set-sink-volume|set-source-volume índice|nombre volumen
Establece el volumen del sink (resp. source) especificado. Puedes especificar el sink (resp. source) por su índice en la lista de sinks/sources o por su nombre. El volumen debe ser un valor entero mayor o igual que 0 (silenciado). El volumen 65536 (0x10000) es el volumen 'normal' o 100%. Los valores mayores que este amplifican la señal de audio (con recorte).
set-sink-mute|set-source-mute índice|nombre booleano
Silencia o desilencia el sink (resp. source) especificado. Puedes especificar el sink (resp. source) por su índice o por su nombre. El valor de silencio es 0 (no silenciado) o 1 (silenciado).
set-sink-input-volume|set-source-output-volume índice volumen
Establece el volumen de una entrada de sink (resp. salida de source) especificada por su índice. Las mismas reglas de volumen se aplican que con set-sink-volume.
set-sink-input-mute|set-source-output-mute índice booleano
Silencia o desilencia una entrada de sink (resp. salida de source) especificada por su índice. Las mismas reglas de silencio se aplican que con set-sink-mute.

COMANDOS DE CONFIGURACIÓN

set-default-sink|set-default-source índice|nombre
Convierte un sink (resp. source) en el predeterminado. Puedes especificar el sink (resp. source) por su índice en la lista de sinks (resp. sources) o por su nombre. Usa el nombre especial @NONE@ para deseleccionar el sink o source predeterminado definido por el usuario. En este caso, pulseaudio volverá a la selección del sink o source predeterminado basada en la prioridad.

Tenga en cuenta que los valores predeterminados pueden ser ignorados por varios módulos de política o por configuraciones de stream específicas.

set-card-profile índice|nombre nombre-del-perfil
Cambia el perfil de una tarjeta.
set-sink-port|set-source-port índice|nombre nombre-del-puerto
Cambia el perfil de un sink (resp. source).
set-port-latency-offset índice|nombre-de-tarjeta nombre-del-puerto desfase
Cambia el desfase de latencia de un puerto perteneciente a la tarjeta especificada
suspend-sink|suspend-source nombre|índice verdadero|falso
Suspende o reanuda el sink o source especificado (que puede ser especificado por su nombre o índice), dependiendo de si se pasa verdadero (suspender) o falso (reanudar) como último argumento. Suspender un sink pausará toda la reproducción y suspender un source pausará toda la captura. Dependiendo del módulo que implemente el sink o source, esto puede tener el efecto de que el dispositivo subyacente se cierre, haciéndolo disponible para que lo usen otras aplicaciones. El comportamiento exacto depende del módulo.
suspend booleano
Suspende todos los sinks y sources.

MOVER STREAMS

move-sink-input|move-source-output índice índice-de-sink|nombre-de-sink
Mueve una entrada de sink (resp. salida de source) a otro sink (resp. source).

LISTAS DE PROPIEDADES

update-sink-proplist|update-source-proplist índice|nombre propiedades
Actualiza las propiedades de un sink (resp. source) especificado por nombre o índice. La propiedad se especifica como, por ejemplo, device.description="Mi Nombre Preferido"
update-sink-input-proplist|update-source-output-proplist índice propiedades
Actualiza las propiedades de una entrada de sink (resp. salida de source) especificada por índice. Las propiedades se especifican como se indicó anteriormente.

CACHE DE MUESTRAS

list-samples
Lista el contenido del caché de muestras.
play-sample nombre índice-de-sink|nombre-de-sink
Reproduce una entrada del caché de muestras en un sink.

MOVING STREAMS

move-sink-input index target-index|target-name
Move a sink input to another sink. This is useful for redirecting the output of an application to a different device.
move-source-output index target-index|target-name
Move a source output to another source.

PROPERTY LISTS

Arguments that consist of multiple words are usually enclosed in double quotes. Properties may be set on objects of all types.

set-property object-type index property-name [property-value]
Set a property on the specified object. If property-value is not given the property is removed.
set-port-prop index port-name property-name [property-value]
Set a property on the specified port of a sink or source.
alias name index
Create an alias for an object.
unalias name
Remove an alias.

SAMPLE CACHE

remove-sample name
Remove an entry from the sample cache.
load-sample name filename
Load an audio file to the sample cache.
load-sample-lazy name filename
Create a new entry in the sample cache, but don't load the sample immediately. The sample is loaded only when it is first used. After a certain idle time it is freed again.
load-sample-dir-lazy path
Load all entries in the specified directory into the sample cache as lazy entries. A shell globbing expression (e.g. *.wav) may be appended to the path of the directory to add.

KILLING CLIENTS/STREAMS

kill-client index
Remove a client forcibly from the server. There is no protection against the client reconnecting immediately.
kill-sink-input|kill-source-output index
Remove a sink input (resp. source output) forcibly from the server. This will not remove the owning client or any other streams opened by the same client from the server.

LOG COMMANDS

set-log-level numeric-level
Change the log level.
set-log-meta boolean
Show source code location in log messages.
set-log-target target
Change the log target (null, auto, journal, syslog, stderr, file:PATH, newfile:PATH).
set-log-time boolean
Show timestamps in log messages.
set-log-backtrace num-frames
Show backtrace in log messages.

MISCELLANEOUS COMMANDS

play-file filename sink-index|sink-name
Play an audio file to a sink.
dump
Dump the daemon's current configuration in CLI commands.
dump-volumes
Debug: Shows the current state of all volumes.
shared
Debug: Show shared properties.
send-message recipient message message_parameters
Send a message to the specified recipient object. If applicable an additional string containing message parameters can be specified. A string is returned as a response to the message. For available messages see https://cgit.freedesktop.org/pulseaudio/pulseaudio/tree/doc/messaging_api.txt.
exit
Terminate the daemon. If you want to terminate a CLI connection ("log out") you might want to use ctrl+d

META COMMANDS

In addition to the commands described above there are a few meta directives supported by the command line interpreter.

.include filename|folder
Executes the commands from the specified script file or in all of the *.pa files within the folder.
.fail and .nofail
Enable (resp. disable) that following failing commands will cancel the execution of the current script file. This is ignored when used on the interactive command line.
.ifexists filename
Execute the subsequent block of commands only if the specified file exists. Typically filename indicates a module. Relative paths are resolved using the module directory as the base. By using an absolute path, the existence of other files can be checked as well.
.else and .endif
A block of commands is delimited by an .else or .endif meta command. Nesting conditional commands is not supported.
