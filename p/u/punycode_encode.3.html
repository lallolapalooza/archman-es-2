NOMBRE

punycode_encode - función de la API

SINOPSIS

#include <punycode.h>

int punycode_encode(size_t input_length, const punycode_uint [] input, const unsigned char [] case_flags, size_t * output_length, char [] output);

ARGUMENTOS

size_t input_length
El número de puntos de código en el array input y el número de indicadores en el array case_flags.
const punycode_uint [] input
Un array de puntos de código. Se presuponen puntos de código Unicode, pero eso no es estrictamente REQUERIDO. El array contiene puntos de código, no unidades de código. UTF-16 utiliza las unidades de código D800 a DFFF para referirse a los puntos de código 10000..10FFFF. Los puntos de código D800..DFFF no aparecen en ninguna cadena Unicode válida. Los puntos de código que pueden aparecer en cadenas Unicode (0..D7FF y E000..10FFFF) también se denominan valores escalares Unicode.
const unsigned char [] case_flags
Un puntero NULL o un array de valores booleanos paralelo al array input. Un valor distinto de cero (verdadero, marcado) sugiere que el carácter Unicode correspondiente se convierta a mayúsculas después de ser decodificado (si es posible), y cero (falso, sin marcar) sugiere que se convierta a minúsculas (si es posible). Los puntos de código ASCII (0..7F) se codifican literalmente, excepto que las letras ASCII se fuerzan a mayúsculas o minúsculas según los indicadores de caso correspondientes. Si case_flags es un puntero NULL, las letras ASCII se dejan como están, y los demás puntos de código se tratan como no marcados.
size_t * output_length
La aplicación llama con el número máximo de puntos de código ASCII que puede recibir. En caso de retorno exitoso, contendrá el número de puntos de código ASCII realmente producidos.
char [] output
Un array de puntos de código ASCII. *No* está terminado en nulo; contendrá ceros si y solo si el input contiene ceros. (Por supuesto, la aplicación puede dejar espacio para un terminador y añadir uno si es necesario).

DESCRIPCIÓN

Convierte una secuencia de puntos de código (presuntos puntos de código Unicode) a Punycode.

Valor de retorno: El valor de retorno puede ser cualquiera de los valores Punycode_status definidos anteriormente, excepto PUNYCODE_BAD_INPUT. Si no es PUNYCODE_SUCCESS, entonces output_size y output pueden contener basura.
