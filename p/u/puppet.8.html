PUPPET(8) Manual de Puppet PUPPET(8)

NOMBRE

puppet - una herramienta de gestión de configuración automatizada

SINOPSIS

puppet subcomando [opciones] acción [opciones]

DESCRIPCIÓN

Puppet, un motor administrativo automatizado para sus sistemas Linux, Unix y Windows, realiza tareas administrativas (como añadir usuarios, instalar paquetes y actualizar configuraciones de servidores) basándose en una especificación centralizada.

COMANDOS

Comunes

apply
    Aplica manifiestos de Puppet localmente

agent
    El demonio agente de puppet

config
    Interactúa con la configuración de Puppet.

help
    Muestra la ayuda de Puppet.

lookup
    Búsqueda interactiva de Hiera

module
    Crea, instala y busca módulos en el Puppet Forge.

resource
    El shell de la capa de abstracción de recursos

Especializados

strings
    Genera documentación de Puppet con YARD.

catalog
    Compila, guarda, visualiza y convierte catálogos.

describe
    Muestra ayuda sobre tipos de recursos

device
    Gestiona dispositivos de red remotos

doc
    Genera referencias de Puppet

epp
    Interactúa directamente con el analizador/renderizador de plantillas EPP.

facts
    Recupera y almacena hechos.

filebucket
    Almacena y recupera archivos en un filebucket

generate
    Genera código Puppet a partir de definiciones Ruby.

node
    Visualiza y gestiona definiciones de nodos.

parser
    Interactúa directamente con el analizador.

plugin
    Interactúa con el sistema de plugins de Puppet.

script
    Ejecuta un manifiesto de puppet como un script sin compilar un catálogo

ssl
    Gestiona claves SSL y certificados para clientes SSL de puppet

VER TAMBIÉN

Ver puppet help <subcomando> para obtener ayuda sobre un subcomando específico.

Ver puppet help <subcomando> <acción> para obtener ayuda sobre una acción de subcomando específica.
