NOMBRE

pkgctl-search - Buscar una expresión en el grupo de empaquetado de GitLab

SINOPSIS

pkgctl search [OPCIONES] CONSULTA

DESCRIPCIÓN

Busca una expresión en el grupo de empaquetado de GitLab.

Para usar un filtro, inclúyelo en tu consulta. Puedes usar comodines (*) para usar coincidencias de glob.

Filtros disponibles para el ámbito de los blobs: path, extension

Cada uso del comando de búsqueda debe ser autenticado. Consulta el comando 'pkgctl auth' para autenticarte con GitLab o ver el estado de autenticación.

CONSEJOS DE BÚSQUEDA

Sintaxis  Descripción    Ejemplo
───────────────────────────────────────
"       Búsqueda exacta   "gem sidekiq"
~       Búsqueda difusa   J~ Doe
|       O              display | banner
+       Y              display +banner
-       Excluir        display -banner
*       Parcial        bug error 50*
\       Escapar        \*md
#       ID de incidencia   #23456
!       Solicitud de fusión  !23456

OPCIONES

-h, --help

Muestra un texto de ayuda

OPCIONES DE FILTRO

--no-default-filter

No aplica el filtro predeterminado (como -path:keys/pgp/*.asc)

OPCIONES DE SALIDA

--json

Habilita la impresión en formato JSON; Abreviatura de '--format json'

-F, --format FORMATO

Controla el formato de los resultados; FORMATO es 'pretty', 'plain', o 'json' (predeterminado pretty)

-N, --no-line-number

No muestra números de línea al formatear resultados

VER TAMBIÉN
