PKTYPE(1) Manual de comandos generales PKTYPE(1)

NOMBRE

pktype - verifica y traduce un archivo de mapa de bits de fuente empaquetado a texto plano

SINOPSIS

pktype archivo_pk[pk]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se encuentra en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa pktype traduce un archivo de fuente empaquetado (pk) (generado, por ejemplo, por gftopk(1) a un archivo que los humanos puedan leer. También sirve como un programa de validación de archivos pk (es decir, si pktype puede leerlo, es correcto) y como un ejemplo de programa de lectura de pk para otro software que quiera leer archivos pk.

El archivo de entrada archivo_pk en la línea de comandos puede omitir el sufijo `pk. La traducción a texto plano siempre se escribe en la salida estándar.

El archivo de salida proporciona una codificación compacta de la codificación empaquetada, utilizando convenciones descritas en el código fuente. Las longitudes de ejecución de píxeles negros alternan con longitudes de ejecución de píxeles blancos entre paréntesis, y se utilizan corchetes para indicar cuándo se debe repetir una fila.

AMBIENTE

pktype busca archivo_pk en los lugares habituales según Kpathsea.

Consulte tex(1) para obtener detalles sobre la búsqueda.

VER TAMBIÉN

dvitype(1), gftopk(1), gftype(1).
Donald E. Knuth et al., Metafontware.

AUTORES
