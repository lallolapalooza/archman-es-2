NOMBRE

pkgctl-license-setup - Detecta y configura automáticamente una configuración básica de REUSE

SINOPSIS

pkgctl license setup [OPCIONES] [PKGBASE...]

DESCRIPCIÓN

Este subcomando automatiza la creación del archivo de licencia del paquete 0BSD de Arch Linux, así como una configuración básica de reuse(1) aplicando heurísticas simples. Resulta especialmente útil al configurar inicialmente las licencias de un paquete sin necesidad de escribir manualmente un archivo REUSE.toml.

Si se detectan archivos .patch y el PKGBUILD(5) tiene una sola entrada en el array license=(), este subcomando asume que los parches están licenciados bajo esa licencia y genera anotaciones para ellos.

En caso de que no haya parches, no se generan anotaciones adicionales.

Son necesarias anotaciones manuales en caso de que el subcomando no pueda generar una configuración que tenga en cuenta todos los archivos. En este caso, reuse lint fallará con un error descriptivo de qué archivos carecen de anotación.

Si no se especifica ningún PKGBASE, el comando utilizará por defecto el directorio de trabajo actual.

OPCIONES

-f, --force

Sobrescribe la configuración existente de reuse(1)

--no-check

No ejecuta pkgctl-license-check(1) después de la configuración

-h, --help

Muestra el texto de ayuda

VER TAMBIÉN

pkgctl-license(1) pkgctl-license-check(1) reuse(1) PKGBUILD(5)
