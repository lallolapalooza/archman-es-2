NOMBRE

pkgctl-repo-create - Crear un nuevo repositorio de paquetes en GitLab

SINOPSIS

pkgctl repo create [OPCIONES] [PKGBASE...]

DESCRIPCIÓN

Crea un nuevo repositorio de empaquetado Git en el namespace canónico de GitLab.

Este comando requiere una autenticación válida en la API de GitLab. Para configurar un nuevo token de GitLab o verificar el actual, consulta el subcomando auth para obtener más instrucciones.

Si se invoca sin un parámetro, intenta crear un repositorio de empaquetado basado en el PKGBUILD del directorio de trabajo actual.

OPCIONES

-c, --clone

Clonar el repositorio Git después de la creación

-h, --help

Mostrar un texto de ayuda

VER TAMBIÉN

pkgctl-auth(1) pkgctl-repo-clone(1) pkgctl-repo-configure(1)
