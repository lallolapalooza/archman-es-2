PKTOGF(1) Manual de Comandos Generales PKTOGF(1)

NOMBRE

pktogf - convertir archivos de fuentes empaquetadas a archivos de fuentes genéricas

SINOPSIS

pktogf [-v] nombre_archivo_pk [nombre_archivo_gf]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o manual Web2C: Una implementación de TeX.

El programa pktogf convierte un archivo de fuentes empaquetadas (pk) a un archivo de fuentes genéricas (gf). Los archivos de fuentes empaquetadas son mucho más pequeños que los archivos gf correspondientes, pero algunos lectores de DVI solo entienden archivos gf.

El nombre_archivo_pk en la línea de comandos debe ser completo. Debido a que la resolución forma parte de la extensión, no tendría sentido añadir una extensión predeterminada como se hace con el software de lectura de TeX o DVI. El nombre_archivo_gf por defecto es el mismo (sin la extensión) que el nombre_archivo_pk, y se coloca en el directorio de trabajo actual con el sufijo gf reemplazando a pk. Por ejemplo, el archivo de entrada io.300pk se convertiría en io.300gf.

OPCIONES

A menos que se indique la opción -v, pktogf opera en silencio. Con -v, el número de versión del programa y estadísticas sobre el desempaquetado se envían a la salida estándar (*stdout*).

ENTORNO

pktogf busca el nombre_archivo_pk utilizando la variable de entorno PKFONTS. Si esta no está configurada, utiliza la variable TEXPKS. Si esta no está configurada, utiliza TEXFONTS. Si esta no está configurada, utiliza la configuración predeterminada del sistema.

Consulte tex(1) para ver los detalles de la búsqueda.

VER TAMBIÉN

gftopk(1), gftype(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTORES

Tomas Rokicki escribió el programa. Pierre MacKay lo adaptó para la compilación con web2c.
