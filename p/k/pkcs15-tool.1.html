PKCS15-TOOL(1) Herramientas OpenSC PKCS15-TOOL(1)

NOMBRE

pkcs15-tool - utilidad para manipular estructuras de datos PKCS #15 en tarjetas inteligentes y otros tokens de seguridad

SINOPSIS

pkcs15-tool [OPCIONES]

DESCRIPCIÓN

La utilidad pkcs15-tool se utiliza para manipular las estructuras de datos PKCS #15 en tarjetas inteligentes y tokens de seguridad similares. Los usuarios pueden listar y leer PIN, claves y certificados almacenados en el token. La autenticación con PIN de usuario se realiza para aquellas operaciones que lo requieren.

OPCIONES

--version

Muestra la versión de la versión del paquete OpenSC.

--aid aid

Especifica en formato hexadecimal el AID de la aplicación PKCS#15 en la tarjeta a la que enlazarse.

--auth-id id, -a id

Especifica el ID de autenticación del PIN a utilizar para la operación. Esto es útil con la operación --change-pin.

--change-pin

Cambia un PIN o PUK almacenado en el token. Se requiere autenticación de usuario para esta operación.

--dump, -D

Lista todos los objetos de la tarjeta.

--list-info

Lista los objetos de la tarjeta.

--list-applications

Lista las aplicaciones PKCS#15 en la tarjeta.

--list-certificates, -c

Lista todos los certificados almacenados en el token.

--list-data-objects, -C

Lista todos los objetos de datos almacenados en el token. Para algunas tarjetas, los atributos PKCS#15 de los objetos de datos privados están protegidos para su lectura y requieren autenticación con el PIN de usuario. En este caso, se debe usar la opción --verify-pin.

--list-keys, -k

Lista todas las claves privadas almacenadas en el token. Se lista información general sobre cada clave privada (por ejemplo, nombre de la clave, ID y algoritmo). Los valores reales de las claves privadas no se muestran. Para algunas tarjetas, los atributos PKCS#15 de las claves privadas están protegidos para su lectura y requieren autenticación con el PIN de usuario. En este caso, se debe usar la opción --verify-pin.

--list-secret-keys

Lista todas las claves secretas (simétricas) almacenadas en el token. Se lista información general sobre cada clave secreta (por ejemplo, nombre de la clave, ID y algoritmo). Los valores reales de las claves secretas no se muestran. Para algunas tarjetas, los atributos PKCS#15 de las claves privadas están protegidos para su lectura y requieren autenticación con el PIN de usuario. En este caso, se debe usar la opción --verify-pin.

--list-pins

Lista todos los PIN almacenados en el token. Se lista información general sobre cada PIN (por ejemplo, nombre del PIN). Los valores reales de los PIN no se muestran.

--list-public-keys

Lista todas las claves públicas almacenadas en el token, incluyendo el nombre de la clave, el ID, el algoritmo y la información de longitud.

--short, -s

Muestra las listas en formato compacto.

--no-cache

Deshabilita el almacenamiento en caché de datos del token.

--clear-cache

Elimina el directorio de caché del usuario. En Windows, esta opción elimina además el directorio de caché del sistema (requiere privilegios de administrador).

--output archivo, -o archivo

Especifica dónde se deben escribir las claves. Si el archivo ya existe, se sobrescribirá. Si no se proporciona esta opción, las claves se imprimirán en la salida estándar.

--raw

Cambia cómo --read-data-object imprime el contenido en la salida estándar. Por defecto, cuando no se proporciona --raw, imprimirá el contenido en notación hexadecimal. Si se establece --raw, imprimirá los datos binarios directamente. Esto no afecta la salida que se escribe en el archivo especificado por la opción --output. Los datos escritos en un archivo estarán siempre en modo binario crudo.

--read-certificate cert

Lee el certificado con el ID dado.

--read-data-object datos, -R datos

Lee el objeto de datos con OID, nombre de aplicación o etiqueta. El contenido se imprime en la salida estándar en notación hexadecimal, a menos que se proporcione la opción --raw. Si se proporciona un archivo de salida con la opción --output, el contenido también se escribe en el archivo. La salida al archivo siempre se escribe en modo binario crudo, --raw solo afecta el comportamiento de la salida estándar.

--read-public-key id

Lee la clave pública con el ID id, permitiendo al usuario extraer y almacenar o usar la clave pública.

--read-ssh-key id

Lee la clave pública con el ID id, escribiendo la salida en un formato adecuado para $HOME/.ssh/authorized_keys.

La etiqueta de la clave, si la hay, se mostrará en el campo 'Comment'.

--rfc4716

Cuando se usa junto con la opción --read-ssh-key, el formato de salida de la clave pública sigue el rfc4716.

El formato de salida predeterminado es una sola línea (openssh).

--test-update, -T

Prueba si la tarjeta necesita una actualización de seguridad.

--update, -U

Actualiza la tarjeta con una actualización de seguridad.

--reader arg

Número del lector a utilizar. Por defecto, se utiliza el primer lector con una tarjeta presente. Si arg es un ATR, se elegirá el lector con una tarjeta coincidente.

--unblock-pin, -u

Desbloquea un PIN almacenado en el token. Se requiere el conocimiento de la Clave de Desbloqueo de PIN (PUK) para esta operación.

--verbose, -v

Hace que pkcs15-tool sea más detallado. Especifique este indicador varias veces para habilitar la salida de depuración en la biblioteca OpenSC.

--pin pin, --new-pin nuevopin, --puk puk

Estas opciones se pueden usar para especificar los valores de PIN/PUK en la línea de comandos. Si el valor se establece en env:VARIABLE, se utiliza el valor de la variable de entorno especificada. Por defecto, se solicitará el código en la línea de comandos si es necesario.

Tenga en cuenta que en la mayoría de los sistemas operativos, cualquier usuario puede ver la línea de comandos de cualquier proceso del sistema utilizando utilidades como ps(1). Por lo tanto, debería preferir pasar los códigos a través de una variable de entorno en un sistema no seguro.

--new-pin pin

Especifica el Nuevo PIN (al cambiar o desbloquear).

--verify-pin

Verifica el PIN después de enlazar la tarjeta y antes de emitir cualquier comando (sin 'auth-id', se verificará el primer PIN no SO, no de desbloqueo).

--test-session-pin

Equivalente a --verify-pin con generación adicional de PIN de sesión.

--wait, -w

Hace que pkcs15-tool espere la inserción de una tarjeta.

--use-pinpad

No solicitar al usuario; si no se proporcionan PIN, se utilizará el pinpad.

VER TAMBIÉN

pkcs15-init(1), pkcs15-crypt(1)
