NOMBRE

pkgctl-issue-view - Muestra información sobre un problema

SINÓPSIS

pkgctl issue view [OPCIONES]

DESCRIPCIÓN

Este comando está diseñado para mostrar información detallada sobre un problema específico en los proyectos de empaquetado de Arch Linux. Recopila e imprime de forma bonita todos los datos relevantes sobre el problema, proporcionando una vista completa que incluye la descripción del problema, el estado, así como las etiquetas y la fecha de creación.

Por defecto, el comando opera dentro del directorio actual, pero los usuarios tienen la opción de especificar una base de paquetes diferente. Además, los usuarios pueden optar por ver el problema en un navegador web para una experiencia más interactiva.

Para aquellos que requieren información más profunda, el comando también puede mostrar todos los comentarios y actividades relacionados con el problema, proporcionando un contexto histórico completo y discusiones en curso.

OPCIONES

-p, --package PKGBASE

Interactúa con PKGBASE en lugar del directorio actual

-c, --comments

Muestra los comentarios y actividades del problema

-w, --web

Abre el problema en un navegador

-h, --help

Muestra un texto de ayuda

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools

Por favor, informa de errores y solicitudes de funciones en el rastreador de problemas. Haz todo lo posible para proporcionar un caso de prueba reproducible para los errores.
