NOMBRE

pkgctl - Interfaz de línea de comandos unificada para devtools

SINOPSIS

pkgctl [SUBCOMANDO] [OPCIONES]

DESCRIPCIÓN

Utilidad de línea de comandos que sirve como una interfaz unificada para múltiples herramientas de desarrollo. Esta herramienta tiene como objetivo simplificar y optimizar las interacciones con devtools al ofrecer varios subcomandos para ejecutar tareas relacionadas con la gestión de paquetes, la gestión de repositorios, el control de versiones, entre otros.

El uso de pkgctl permite a los usuarios administrar eficientemente sus flujos de trabajo de desarrollo.

OPCIONES

-V, --version

Mostrar información de la versión de pkgctl

-h, --help

Mostrar un texto de ayuda

SUBCOMANDOS

pkgctl aur

Interactuar con el Arch User Repository

pkgctl auth

Autenticarse con servicios como GitLab

pkgctl build

Construir paquetes dentro de un chroot limpio

pkgctl db

Modificación de la base de datos de Pacman para actualizar, mover, etc. paquetes

pkgctl diff

Comparar archivos de paquetes utilizando diferentes modos

pkgctl issue

Trabajar con problemas de empaquetado de GitLab

pkgctl release

Paso de lanzamiento para confirmar, etiquetar y cargar artefactos de compilación

pkgctl repo

Administrar repositorios de empaquetado Git y su configuración

pkgctl search

Buscar una expresión en el grupo de empaquetado de GitLab

pkgctl version

Comprobar y administrar versiones de paquetes frente a upstream
