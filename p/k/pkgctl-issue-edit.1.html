NOMBRE

pkgctl-issue-edit - Editar y modificar un problema

SINOPSIS

pkgctl issue edit [OPCIONES] [IID]

DESCRIPCIÓN

El comando pkgctl issue edit se utiliza para modificar un problema existente en los proyectos de empaquetado de Arch Linux. Este comando permite a los usuarios actualizar el título, la descripción y varios atributos del problema, garantizando que la información del problema se mantenga precisa y actualizada. También proporciona una instalación simplificada para que los gestores de errores clasifiquen y prioricen los problemas de manera eficiente.

Para editar un problema, los usuarios deben especificar el ID del problema (IID). Por defecto, el comando opera dentro del directorio actual, pero los usuarios pueden especificar una base de paquetes diferente si es necesario.

El comando permite actualizaciones directas del título y la descripción del problema. Para cambios más extensos, los usuarios pueden editar estos detalles utilizando un editor de texto. El comando proporciona varias opciones para establecer o actualizar etiquetas y atributos como confidencialidad, prioridad, resolución, alcance, severidad y estado. Estas opciones ayudan a mantener una gestión de problemas clara y organizada.

En caso de un fallo en la ejecución, el comando puede recuperarse automáticamente para garantizar que el proceso de edición se complete sin pérdida de datos.

Este comando es particularmente útil para mantenedores y colaboradores que necesitan actualizar los detalles de un problema para reflejar nueva información o cambios de estado. Asegura que todos los detalles del problema se mantengan con precisión, facilitando el seguimiento y la resolución eficientes.

OPCIONES

-p, --package PKGBASE

Interactúa con PKGBASE en lugar del directorio actual

-t, --title TITLE

Utiliza el título proporcionado para el problema

-e, --edit

Edita el título y la descripción del problema usando un editor

--recover

Recupera automáticamente de un fallo

--confidentiality TYPE

Establece la confidencialidad del problema

--priority PRIORITY

Establece la etiqueta de prioridad

--resolution REASON

Establece la etiqueta de resolución

--scope SCOPE

Establece la etiqueta de alcance

--severity SEVERITY

Establece la etiqueta de severidad

--status STATUS

Establece la etiqueta de estado

-h, --help

Muestra un texto de ayuda
