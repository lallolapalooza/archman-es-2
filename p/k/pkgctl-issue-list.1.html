NOMBRE

pkgctl-issue-list - Listar incidencias del proyecto o grupo

SINOPSIS

pkgctl issue list [OPCIONES] [PKGBASE]

DESCRIPCIÓN

El comando pkgctl issue list se utiliza para listar las incidencias asociadas con un proyecto de empaquetado específico o con el subgrupo de empaquetado completo en Arch Linux. Este comando facilita una gestión eficiente de incidencias al permitir a los usuarios listar y filtrar incidencias según varios criterios.

Los resultados también se pueden mostrar directamente en un navegador web para una navegación y revisión más sencillas.

El comando ofrece opciones de filtrado para refinar los resultados. Los usuarios pueden incluir incidencias cerradas, filtrar exclusivamente por incidencias no confirmadas o centrarse en incidencias con etiquetas específicas, como prioridad, confidencialidad, resolución, alcance, severidad y estado.

Además, los usuarios pueden buscar dentro de los títulos o descripciones de las incidencias y filtrar las incidencias por el asignado o el autor. También hay atajos convenientes para filtrar incidencias asignadas o creadas por el usuario actual.

Este comando es particularmente útil para los mantenedores de paquetes y colaboradores de la comunidad de Arch Linux que necesitan rastrear y gestionar incidencias de manera eficiente. Proporciona una visión completa del panorama de incidencias del proyecto o grupo, lo que permite a los mantenedores abordar y priorizar las incidencias de manera efectiva.

OPCIONES

-g, --group

Obtener incidencias de todo el subgrupo de empaquetado

-w, --web

Ver resultados en el navegador

-h, --help

Mostrar texto de ayuda

OPCIONES DE FILTRADO

-A, --all

Obtener todas las incidencias, incluidas las cerradas

-c, --closed

Obtener solo incidencias cerradas

-U, --unconfirmed

Atajo para filtrar por etiqueta de estado no confirmado

--search BUSQUEDA

Buscar <cadena> en los campos definidos por --in

--in UBICACIÓN

Buscar en título o descripción (predeterminado: todo)

-l, --label NOMBRE

Filtrar incidencia por etiqueta <nombre>

--confidentiality TIPO

Filtrar por confidencialidad

--priority PRIORIDAD

Atajo para filtrar por etiqueta de prioridad

--resolution RAZÓN

Atajo para filtrar por etiqueta de resolución

--scope ALCANCE

Atajo para filtrar por etiqueta de alcance

--severity SEVERIDAD

Atajo para filtrar por etiqueta de severidad

--status ESTADO

Atajo para filtrar por etiqueta de estado

--assignee NOMBREDEUSUARIO

Filtrar incidencias asignadas al nombre de usuario dado

--assigned-to-me

Atajo para filtrar incidencias asignadas a ti

--author NOMBREDEUSUARIO

Filtrar incidencias creadas por el nombre de usuario dado

--created-by-me

Atajo para filtrar incidencias creadas por ti

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools

Por favor, informe de errores y solicitudes de funciones en el rastreador de incidencias. Haga todo lo posible para proporcionar un caso de prueba reproducible para los errores.
