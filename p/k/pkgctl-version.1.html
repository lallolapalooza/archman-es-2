NOMBRE

pkgctl-version - Comprobar y gestionar versiones de paquetes frente a upstream

SINOPSIS

pkgctl version [OPCIONES] [SUBCOMANDO]

DESCRIPCIÓN

Comandos relacionados con las versiones de los paquetes, incluidas las comprobaciones de paquetes desactualizados.

Utiliza nvchecker(1) y un archivo .nvchecker.toml ubicado junto al PKGBUILD.

CONFIGURACIÓN

El archivo .nvchecker.toml debe contener una sección que coincida con el pkgbase del paquete. La sección del pkgbase dentro del archivo .nvchecker.toml especifica la fuente y el método para comprobar la última versión del paquete correspondiente.

Utilice pkgctl-version-setup(1) para detectar y configurar automáticamente una configuración básica de nvchecker basada en el array source del PKGBUILD del paquete.

Para obtener información detallada sobre las diversas opciones de configuración disponibles para el archivo .nvchecker.toml, consulte la sección de archivos de configuración en nvchecker(1). Esta documentación proporciona información sobre las opciones posibles que se pueden utilizar para personalizar el proceso de comprobación de versiones.

Para proporcionar tokens de GitHub o GitLab a nvchecker, se debe colocar un archivo keyfile.toml en el directorio $XDG_CONFIG_HOME/nvchecker`. Este archivo de clave se utiliza para proporcionar los tokens de autenticación necesarios para acceder a la API de GitHub o GitLab.

OPCIONES

-h, --help

Muestra un texto de ayuda

SUBCOMANDOS

pkgctl version check

Compara las versiones locales de los paquetes con las de upstream

pkgctl version setup

Detecta y configura automáticamente una configuración básica de nvchecker

pkgctl version upgrade

Ajusta el PKGBUILD para que coincida con la última versión de upstream

VER TAMBIÉN

pkgctl-version-check(1) pkgctl-version-setup(1) pkgctl-version-upgrade(1)
