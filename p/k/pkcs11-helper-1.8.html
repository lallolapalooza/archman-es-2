NOMBRE

pkcs11-helper — API simplificada de la biblioteca PKCS#11.

DESCRIPCIÓN

pkcs11-helper es una API simplificada para acceder a tokens PKCS#11 para aplicaciones de usuario.

VER TAMBIÉN

Página principal de pkcs11-helper, https://github.com/OpenSC/pkcs11-helper/.
