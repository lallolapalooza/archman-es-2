NOMBRE

pktopbm - convertir fuente empaquetada (PK) a PBM

SINOPSIS

pktopbm archivo_pk[.pk] [ -x ancho ] [ -y alto ] [-c num] archivo_pbm ...

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pktopbm lee un archivo de fuente empaquetada (PK) como entrada y produce imágenes PBM como salida. Si se usa el nombre de archivo '-' para cualquiera de los nombres de archivo, se utilizará el flujo de entrada estándar (o la salida estándar, cuando corresponda). Si se especifica el ancho o la altura, este valor se utilizará para todos los mapas de bits producidos. También, si se especifican uno o ambos valores, el mapa de bits se reubicará con el hoffset y voffset dados en el archivo pk. El punto base se colocará en la esquina inferior izquierda del mapa de bits; si el mapa de bits es más grande que el tamaño especificado, se truncará en la parte superior o derecha.

OPCIONES

-c num
Establece el número de carácter del siguiente mapa de bits a escribir en num.
-x ancho
Establece el ancho de la imagen en columnas.
-y alto
Establece la altura de la imagen en filas.

VER TAMBIÉN
