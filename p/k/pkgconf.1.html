PKGCONF(1) Manual de Comandos Generales PKGCONF(1)

NOMBRE

pkgconf — un sistema para configurar información de dependencias de compilación

SINOPSIS

pkgconf [opciones] módulo ...

DESCRIPCIÓN

El programa pkgconf recupera información de configuración relacionada con los argumentos módulo de los archivos pc(5) instalados en el sistema e imprime partes de la información recuperada dependiendo de las opciones especificadas. El uso más común es imprimir las banderas del compilador y enlazador necesarias para compilar software que utiliza las bibliotecas dadas por los argumentos módulo.

Los archivos pc(5) se buscan a lo largo de una ruta construida a partir de la opción --with-path, las variables de entorno PKG_CONFIG_PATH y PKG_CONFIG_LIBDIR, y algunos directorios predeterminados compilados en el código. Los argumentos módulo corresponden a los nombres de archivo, pero sin la extensión de archivo .pc.

Varias de las opciones provocan una salida inmediata. Si se dan múltiples de estas opciones, solo la opción con la prioridad más alta surte efecto y las de menor prioridad se ignoran silenciosamente. Estas opciones son, ordenadas por prioridad descendente:

  1. Opciones sin módulo: --relocate, --dump-personality, --about, --version, --help, --atleast-pkgconfig-version, --list-all, y --list-package-names: Estas opciones hacen que se ignoren todos los argumentos.
  2. Opciones solo de argumento: --atleast-version, --exact-version, y --max-version: Estas opciones solo inspeccionan los módulos especificados explícitamente en la línea de comandos y no buscan dependencias.
  3. Opciones de salida limitada: --validate, --license, --uninstalled, y --env: Estas opciones realizan la resolución de dependencias, pero salen después de imprimir la información solicitada por la opción de mayor prioridad, ignorando otras opciones de salida que se hayan especificado.

Varias otras opciones requieren al menos un argumento módulo, producen salida, no provocan salida temprana, se pueden combinar entre sí, pero anulan y deshabilitan todas las opciones --cflags y --libs:

  1. Opciones de salida de módulo único: --path, --print-variables, --variable: Si se especifica alguna de estas opciones, solo se utiliza el primer argumento módulo, todos los demás argumentos se ignoran silenciosamente y no se intenta resolver dependencias.
  2. Opciones de salida de nivel uno: --print-provides, --modversion, --print-requires, y --print-requires-private: Si se especifica alguna de estas opciones, solo se inspeccionan los módulos especificados explícitamente en la línea de comandos y no se intenta resolver dependencias.
  3. Opciones de salida general: --simulate, --digraph, --solution, --fragment-tree: Estas opciones no limitan la resolución de dependencias.

Las opciones de salida más importantes --cflags y --libs se pueden combinar entre sí, pero son anuladas e ignoradas si se especifican alguna de las opciones enumeradas anteriormente.

La lista completa de opciones es la siguiente:

--about
Imprime el número de versión, el aviso de Copyright y la licencia del programa pkgconf en la salida estándar y sale. La mayoría de las otras opciones y todos los argumentos de la línea de comandos se ignoran.
--atleast-pkgconfig-version=versión
Sale con error si el número de versión solicitado es mayor que el número de versión del programa pkgconf, o con éxito en caso contrario. La mayoría de las otras opciones y todos los argumentos de la línea de comandos se ignoran.
--atleast-version=versión
Comprueba los argumentos de módulo en el orden dado. Sale con error tan pronto como un módulo no existe, y sale con éxito tan pronto como la versión de un módulo es mayor o igual al número de versión solicitado. Sale con error si la versión de cada módulo es menor que el número de versión solicitado.
--cflags, --cflags-only-I, --cflags-only-other
Imprime todas las banderas del compilador necesarias para compilar contra el módulo, o solo las banderas de ruta de inclusión (-I), o solo las banderas del compilador que no son de ruta de inclusión, respectivamente. Estas opciones implican --print-errors.
--debug
Imprime algunos mensajes de advertencia no fatales en la salida de error estándar que de otro modo se ignorarían silenciosamente. Esta opción también implica --print-errors. Si pkgconf se compiló sin definir la macro del preprocesador PKGCONF_LITE, esta opción también imprime muchos mensajes de depuración en la salida de error estándar.
--define-prefix
Intenta determinar la variable de prefijo a usar para las relocalizaciones de entrada de CFLAGS y LIBS. Esto es útil principalmente para plataformas donde los SDK de frameworks son reubicables, como Windows.
--define-variable=nombrevar=valor
Define nombrevar como valor. Las variables se utilizan en la salida de consulta, y los resultados de algunos módulos pueden cambiar según la presencia de una definición de variable.
--digraph
Exporta la solución del resolvedor de dependencias como un archivo ‘dot’ de graphviz. Esto se puede usar con graphviz para visualizar las interdependencias de los módulos. Esta opción solo está disponible si la macro del preprocesador PKGCONF_LITE no se definió durante la compilación.
--dont-define-prefix
Deshabilita la función ‘define-prefix’.
--dont-relocate-paths
Deshabilita la función de relocalización de rutas.
--dump-personality
Imprime algunas configuraciones predeterminadas en la salida estándar, en particular la ruta de búsqueda de módulos predeterminada que se utiliza cuando PKG_CONFIG_LIBDIR no está definido, la lista predeterminada de rutas de inclusión que se filtran cuando PKG_CONFIG_SYSTEM_INCLUDE_PATH no está definido, y la lista predeterminada de rutas de bibliotecas que se filtran cuando PKG_CONFIG_SYSTEM_LIBRARY_PATH no está definido, y sale. La mayoría de las otras opciones y todos los argumentos de la línea de comandos se ignoran. Esta opción solo está disponible si la macro del preprocesador PKGCONF_LITE no se definió durante la compilación.
--env=nombrevar
Imprime los valores solicitados como declaraciones de variables en un formato similar al comando env(1).
--env-only

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

Inicializa la ruta de búsqueda de módulos solo desde --with-path y PKG_CONFIG_PATH, ignorando PKG_CONFIG_LIBDIR y los directorios predeterminados compilados.
--errors-to-stdout
Imprime todos los mensajes de error, advertencia y depuración en la salida estándar en lugar de en la salida de error estándar.
--exact-version=version
Comprueba los argumentos module en el orden dado. Sale con error tan pronto como un module no existe, y sale con éxito tan pronto como el número de versión de un module es exactamente el número de version solicitado. Sale con error si el número de versión de cada module difiere del número de version solicitado.
--exists
Sale con un estado de salida distinto de cero si el resolvedor de dependencias no puede encontrar todos los modules solicitados. Esta opción está activa por defecto y no puede ser deshabilitada. Sin embargo, varias otras opciones hacen que pkgconf salga e informe de éxito o fracaso antes de que se hayan inspeccionado todos los argumentos.
--fragment-filter=types
Filtra las listas de fragmentos para los types especificados.
--help
Imprime un resumen de uso en la salida estándar y sale. La mayoría de las otras opciones y todos los argumentos de línea de comandos son ignorados.
--ignore-conflicts
Ignora las reglas de 'Conflicts' en los módulos.
--keep-system-cflags, --keep-system-libs
Mantiene los fragmentos de CFLAGS o de flags del enlazador que serían filtrados debido a estar incluidos por defecto en el compilador.
--libs, --libs-only-L, --libs-only-l, --libs-only-other
Imprime todas las flags del enlazador requeridas para enlazar contra el module, o solo las flags de ruta de la biblioteca (-L), o solo las flags de la biblioteca (-l), o solo las flags del enlazador que no son ni ruta de biblioteca ni flags de biblioteca, respectivamente. Estas opciones implican --print-errors.
--list-all
Recorre la ruta de búsqueda de módulos en orden de prioridad descendente. Para cada archivo pc(5) encontrado, imprime una línea en la salida estándar, conteniendo el nombre base del archivo sin la extensión, la propiedad Name, un guion (‘-’) y la propiedad Description. Esta opción implica --print-errors. Todos los argumentos de línea de comandos son ignorados.
--list-package-names
Realiza la misma búsqueda que --list-all, pero solo imprime el nombre base de cada archivo pc(5) sin la extensión, no el nombre del módulo y la descripción. Esta opción implica --print-errors. Todos los argumentos de línea de comandos son ignorados.
--log-file=file
Establece el nombre del archivo de salida file donde se registra la información sobre los módulos seleccionados, tanto los seleccionados por argumentos como las dependencias. Para cada módulo seleccionado, se imprime una línea, que contiene el nombre base del archivo pc(5) sin la extensión, opcionalmente un operador y un número de versión que describe el rango deseado de versiones, y ya sea el número de versión real entre corchetes o la cadena "NOT-FOUND". Si esta opción no se proporciona, el nombre del archivo de salida se toma de la variable de entorno PKG_CONFIG_LOG, y si tampoco se proporciona, este tipo de registro se deshabilita.
--max-version=version
Comprueba los argumentos module en el orden dado. Sale con error tan pronto como un module no existe, y sale con éxito tan pronto como el número de versión de un module es menor o igual al número de version solicitado. Sale con error si el número de versión de cada module es mayor que el número de version solicitado.
--maximum-traverse-depth=depth
Impone un límite a la profundidad permitida en el grafo de dependencias. Por ejemplo, una depth de 2 restringe al resolvedor a no actuar sobre dependencias secundarias de los módulos añadidos a la solución del resolvedor. Esta opción es anulada por la variable de entorno PKG_CONFIG_MAXIMUM_TRAVERSE_DEPTH y por las opciones --modversion, --path, --print-provides, --print-requires, --print-requires-private, --print-variables, y --variable.
--modversion
Para cada module especificado, imprime el número de versión en la salida estándar. Si la opción --verbose también está especificada, el nombre del respectivo module y dos puntos se imprimen antes de cada número de versión. Esta opción implica --print-errors y --maximum-traverse-depth=1 y anula y deshabilita todas las flags de --cflags y --libs.
--msvc-syntax
Utiliza sintaxis MSVC para la salida de --cflags, --env y --libs. Esta opción solo está disponible si el macro preprocesador PKGCONF_LITE no fue definido durante la compilación.
--no-cache
Omite el caché de paquetes cuando se cargan en el resolvedor interno. Esto puede resultar en la computación de un grafo de dependencias alternativo.
--no-provides
Ignora las reglas 'Provides' en los módulos al resolver dependencias.
--no-uninstalled
Prohíbe al resolvedor de dependencias considerar módulos 'no instalados' como parte de una solución.
--path
Para el primer module dado en la línea de comandos, deja que el resolvedor de dependencias encuentre el archivo pc(5) que describe ese módulo, imprime la ruta absoluta de ese archivo en la salida estándar y sale inmediatamente, ignorando la mayoría de las otras opciones y todos los demás argumentos.
--prefix-variable=variable
Establece la variable 'prefix' utilizada por la característica 'define-prefix'.
--print-errors
Imprime algunos mensajes sobre errores fatales en la salida de error estándar que de otro modo se omitirían. Esta opción está implícita en muchas otras opciones, pero no en todas. Puede ser anulada con --silence-errors.
--print-provides
Para cada module especificado, imprime una línea en la salida estándar que contiene la propiedad Name, un signo igual (‘=’) y la propiedad Version. Si el module contiene una o más propiedades Provides, imprime líneas adicionales en formato de lista de dependencias, un nombre por línea, cada nombre seguido opcionalmente por un operador y una versión. Esta opción implica --maximum-traverse-depth=1 y anula y deshabilita todas las flags de --cflags y --libs.
--print-requires, --print-requires-private
Para cada module especificado, imprime las propiedades Requires o Requires.private, respectivamente, en formato de lista de dependencias en la salida estándar. Ambas opciones implican --maximum-traverse-depth=1 y anulan y deshabilitan todas las flags de --cflags y --libs.
--print-variables
Para el primer module dado en la línea de comandos, imprime los nombres de todas las variables vistas en la salida estándar, una por línea. Los argumentos subsiguientes son ignorados silenciosamente. Esta opción implica --print-errors y --maximum-traverse-depth=1 y anula y deshabilita todas las flags de --cflags y --libs.
--pure
Trata el grafo de dependencias computado como si fuera puro. Esto está principalmente destinado para uso con la flag --static y no tiene efecto si --shared también está especificado.
--relocate=path
Reubica una ruta utilizando la API pkgconf_path_relocate. Esto se utiliza principalmente por la suite de pruebas para proporcionar una interfaz garantizada al backend de reubicación de rutas del sistema.

OPTIONS

--shared
Calcula un grafo de dependencias simple que solo es adecuado para enlazado compartido. Esta opción reemplaza a --static.
--short-errors
Al imprimir mensajes de error sobre módulos que no se encuentran o que entran en conflicto entre sí, evita imprimir instrucciones adicionales y detalladas que expliquen posibles métodos para resolver el problema.
--silence-errors
No imprime ningún mensaje de error, advertencia o depuración. Anula todos los comandos --debug, --errors-to-stdout y --print-errors. Esta opción se anula y deshabilita si la variable de entorno PKG_CONFIG_DEBUG_SPEW está configurada.
--simulate
Simula la resolución de un grafo de dependencias basado en los módulos solicitados en la línea de comandos. Volca una serie de árboles que denotan el estado del resolutor de pkgconf. Esta opción solo está disponible si la macro del preprocesador PKGCONF_LITE no se definió durante la compilación.
--solution
Imprime los nombres de los módulos solicitados con argumentos module y sus dependencias en la salida estándar. Esta opción solo está disponible si la macro del preprocesador PKGCONF_LITE no se definió durante la compilación.
--static
Calcula un grafo de dependencias más profundo y utiliza indicadores del compilador/enlazador destinados al enlazado estático. Esta opción se ve reemplazada por --shared.
--uninstalled
Sale con un resultado distinto de cero si el resolutor de dependencias utiliza un módulo "no instalado" como parte de su solución.
--validate package ...
Valida archivos ‘.pc’ específicos para verificar su corrección. Esta opción implica --print-errors y --errors-to-stdout.
--variable=varname
Para el primer module dado en la línea de comandos, imprime el valor de la variable con el nombre varname en la salida estándar. Cualquier argumento posterior se ignora silenciosamente. Esta opción implica --maximum-traverse-depth=1 y anula y deshabilita todos los indicadores --cflags y --libs.
--verbose
Esta opción solo tiene efecto si también se especifica --modversion. Imprime el nombre del respectivo module y dos puntos antes de cada número de versión.
--version
Imprime el número de versión del programa pkgconf en la salida estándar y sale. La mayoría de las otras opciones y todos los argumentos de la línea de comandos se ignoran.
--with-path=path
Antepone el directorio path a la ruta de búsqueda de módulos, dándole prioridad sobre todos los demás directorios, incluidos los de PKG_CONFIG_PATH y PKG_CONFIG_LIBDIR.

ENVIRONMENT

CPATH
Primera lista suplementaria de rutas de inclusión separadas por dos puntos, filtrada de la misma manera que PKG_CONFIG_SYSTEM_INCLUDE_PATH.
CPLUS_INCLUDE_PATH
Tercera lista suplementaria de rutas de inclusión separadas por dos puntos, filtrada de la misma manera que PKG_CONFIG_SYSTEM_INCLUDE_PATH.
C_INCLUDE_PATH
Segunda lista suplementaria de rutas de inclusión separadas por dos puntos, filtrada de la misma manera que PKG_CONFIG_SYSTEM_INCLUDE_PATH.
DESTDIR
Si se establece con el mismo valor que PKG_CONFIG_SYSROOT_DIR, se comporta de la misma manera que si se hubiera establecido PKG_CONFIG_FDO_SYSROOT_RULES. Si PKG_CONFIG_SYSROOT_DIR no está establecido o está establecido con un valor diferente, se ignora DESTDIR.
LIBRARY_PATH
Lista suplementaria de rutas de bibliotecas separadas por dos puntos, filtrada de la misma manera que PKG_CONFIG_SYSTEM_LIBRARY_PATH.
OBJC_INCLUDE_PATH
Cuarta lista suplementaria de rutas de inclusión separadas por dos puntos, filtrada de la misma manera que PKG_CONFIG_SYSTEM_INCLUDE_PATH.
PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
Si está establecida, esta variable tiene el mismo efecto que la opción --keep-system-cflags.
PKG_CONFIG_ALLOW_SYSTEM_LIBS
Si está establecida, esta variable tiene el mismo efecto que la opción --keep-system-libs.
PKG_CONFIG_DEBUG_SPEW
Si está establecida, anula y deshabilita la opción --silence-errors.
PKG_CONFIG_DISABLE_UNINSTALLED
Si está establecida, habilita el mismo comportamiento que el indicador --no-uninstalled.
PKG_CONFIG_DONT_DEFINE_PREFIX
Si está establecida, esta variable tiene el mismo efecto que la opción --dont-define-prefix.
PKG_CONFIG_DONT_RELOCATE_PATHS
Si está establecida, deshabilita la función de reubicación de rutas.
PKG_CONFIG_FDO_SYSROOT_RULES
Si está establecida, sigue las reglas de prefijo de sysroot que utiliza el pkg-config de freedesktop.org.
PKG_CONFIG_IGNORE_CONFLICTS
Si está establecida, ignora las reglas de Conflicts en los módulos. Tiene el mismo efecto que la opción --ignore-conflicts.
PKG_CONFIG_LIBDIR
Una lista separada por dos puntos de directorios de baja prioridad donde se buscan los archivos pc(5). La ruta de búsqueda de módulos se construye añadiendo esta lista a PKG_CONFIG_PATH, que tiene mayor prioridad. Si PKG_CONFIG_LIBDIR no está definida, se añade la lista predeterminada compilada en el programa pkgconf desde la macro del preprocesador PKG_DEFAULT_PATH. Si PKG_CONFIG_LIBDIR está definida pero vacía, no se añade nada.
PKG_CONFIG_LOG
Si está establecida, registra información sobre los módulos seleccionados en el archivo con el nombre almacenado en esta variable. Para más detalles, consulte la opción de línea de comandos --log-file, que anula esta variable.
PKG_CONFIG_MAXIMUM_TRAVERSE_DEPTH
Impone un límite a la profundidad permitida en el grafo de dependencias. Esta variable anula la opción --maximum-traverse-depth, pero se ve anulada por las otras opciones mencionadas allí.
PKG_CONFIG_MSVC_SYNTAX
Si está establecida, utiliza la sintaxis MSVC para la salida de --cflags, --env y --libs. Esta variable tiene el mismo efecto que la opción --msvc-syntax. Si la macro del preprocesador PKGCONF_LITE se definió durante la compilación, esta variable se ignora.
PKG_CONFIG_PATH
Una lista separada por dos puntos de directorios de alta prioridad donde se buscan los archivos pc(5). La ruta de búsqueda de módulos se construye anteponiendo el directorio especificado con --with-path, si existe, y a menos que se especifique --env-only, añadiendo PKG_CONFIG_LIBDIR o los directorios predeterminados compilados con menor prioridad.
PKG_CONFIG_PRELOADED_FILES
Lista separada por dos puntos de archivos pc(5) que se cargan antes que cualquier otro archivo pkg-config. Estos paquetes tienen la máxima prioridad sobre cualquier otro archivo pc(5) que de otro modo proporcionaría un paquete determinado.
PKG_CONFIG_PURE_DEPGRAPH
Si está establecida, habilita el mismo comportamiento que el indicador --pure.
PKG_CONFIG_RELOCATE_PATHS
Si está establecida, esta variable tiene el mismo efecto que la opción --define-prefix.

NAME

pkgconf — un framework de gestión de paquetes para ayudar a los desarrolladores de software a encontrar información de compilación y enlazado.

SYNOPSIS

pkgconf [-hV] [--`command`] [--print-errors] [--env-vars] [--paths] [--variables] [--exists] [--errors] [--validate] [--requires] [--uninstalled] [--static] [--features] [-d dir] [-m module] [--git-dir dir] [--git-file file] [--root dir] [--sysroot dir] [-I dir] [-L dir] [--define variable=value] [--static-libs] [--libs] [--libs-only-l] [--libs-only-L] [--libs-only-other] [--cflags] [--cflags-only-I] [--cflags-only-other] [--dep-CFLAGS] [--dep-LIBS] [--print-requires] [--print-requires-private] [--preferred-version version] [-W warning] [--atleast-version version] [--exact-version version] [--max-version version] [--disable-checks] [--define-variable variable=value] [--variable variable] [--builtin] [--no-system-vars] [-p spec] [--paths pkg] [--variables pkg] [--exists pkg] [--errors pkg] [--validate pkg] [--requires pkg] [--uninstalled pkg] [--static pkg] [--features pkg] [--dep-CFLAGS pkg] [--dep-LIBS pkg] [--print-requires pkg] [--print-requires-private pkg] [--preferred-version pkg] [-W pkg] [--atleast-version pkg] [--exact-version pkg] [--max-version pkg] [--disable-checks pkg] [--define-variable pkg] [--variable pkg] [--builtin pkg] [--no-system-vars pkg] [--print-errors pkg] [--env-vars pkg] [-p pkg] [--root dir] [--sysroot dir] [-I dir] [-L dir] [--define variable=value] [--static-libs] [--libs] [--libs-only-l] [--libs-only-L] [--libs-only-other] [--cflags] [--cflags-only-I] [--cflags-only-other] [--dep-CFLAGS] [--dep-LIBS] [--print-requires] [--print-requires-private] [--preferred-version version] [-W warning] [--atleast-version version] [--exact-version version] [--max-version version] [--disable-checks] [--define-variable variable=value] [--variable variable] [--builtin] [--no-system-vars] [-p spec] [pkg …]

DESCRIPTION

pkgconf es un gestor de paquetes de metadatos de compilación que pretende ser un reemplazo directo para pkg-config. Es un framework que permite a los desarrolladores de software encontrar información de compilación y enlazado para bibliotecas instaladas en un sistema.

La información se almacena en archivos .pc, que son archivos de texto plano con variables que pkgconf puede leer. Estos archivos suelen ser generados por sistemas de compilación como Meson o Autotools.

ENVIRONMENT

Las siguientes variables de entorno se utilizan por pkgconf:

FIG_SYSROOT_DIR
Si está configurada, esta variable define un directorio 'sysroot', que se antepondrá a cada variable de ruta que comience con la variable de prefijo en un archivo pc(5) dado. Útil para la compilación cruzada. El valor de esta variable de entorno también se copia a la variable global pc_sysrootdir.
PKG_CONFIG_SYSTEM_INCLUDE_PATH
Lista separada por dos puntos de rutas de inclusión que se filtran y no se imprimen por las opciones --cflags y --cflags-only-I porque se consideran rutas de inclusión del sistema. Si no está definida, se utiliza la lista predeterminada compilada en el programa pkgconf a partir de la macro del preprocesador SYSTEM_INCLUDEDIR. Esta variable es una extensión específica de pkgconf. También se filtran los directorios listados en las variables de entorno CPATH, C_INCLUDE_PATH, CPLUS_INCLUDE_PATH y OBJC_INCLUDE_PATH.
PKG_CONFIG_SYSTEM_LIBRARY_PATH
Lista separada por dos puntos de rutas de biblioteca que se filtran y no se imprimen por las opciones --libs y --libs-only-L porque se consideran rutas de biblioteca del sistema. Si no está definida, se utiliza la lista predeterminada compilada en el programa pkgconf a partir de la macro del preprocesador SYSTEM_LIBDIR. Esta variable es una extensión específica de pkgconf.
PKG_CONFIG_TOP_BUILD_DIR
El valor de la variable global pc_top_builddir. Si esta variable de entorno no está definida, la cadena "$(top_builddir)" se utiliza como valor de pc_top_builddir.

EXIT STATUS

La utilidad pkgconf sale con 0 en caso de éxito, y >0 si ocurre un error.

EXAMPLES

Mostrar los CFLAGS de un paquete:

$ pkgconf --cflags foo
-fPIC -I/usr/include/foo
