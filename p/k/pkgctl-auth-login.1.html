NOMBRE

pkgctl-auth-login - Autenticarse con la instancia de GitLab

SINOPSIS

pkgctl auth login [OPCIONES]

DESCRIPCIÓN

Autenticarse interactivamente con la instancia de GitLab.

Los ámbitos mínimos requeridos para el token son: api, write_repository.

El token de la API de GitLab puede almacenarse en un archivo de texto plano en $XDG_CONFIG_HOME/devtools/gitlab.conf, o proporcionarse a través de la variable de entorno DEVTOOLS_GITLAB_TOKEN usando cualquier comando (gpg, vault, gestor de contraseñas) declarando un alias de shell:

$ alias pkgctl='DEVTOOLS_GITLAB_TOKEN="$(comando para obtener token)" pkgctl'

OPCIONES

-g, --gen-access-token

Abrir la URL para generar un nuevo token de acceso personal

-h, --help

Mostrar el texto de ayuda
