NOMBRE

pki --gen - Genera una nueva clave privada RSA o ECDSA

SINOPSIS

pki --gen [--type tipo] [--size bits] [--safe-primes] [--shares n] [--threshold l] [--outform codificación] [--debug nivel]
pki --gen --options archivo
pki --gen -h | --help

DESCRIPCIÓN

Este subcomando de pki(1) se utiliza para generar una nueva clave privada RSA o ECDSA.

OPCIONES

-h, --help
Imprime información de uso con un resumen de las opciones disponibles.
-v, --debug nivel
Establece el nivel de depuración, por defecto: 1.
-+, --options archivo
Lee las opciones de la línea de comandos desde archivo.
-t, --type tipo
Tipo de clave a generar. Puede ser rsa, ecdsa, ed25519 o ed448, por defecto es rsa.
-s, --size bits
Longitud de la clave en bits. Por defecto es 2048 para rsa y 384 para ecdsa. Para ecdsa actualmente solo se admiten tres valores: 256, 384 y 521.
-p, --safe-primes
Genera primos seguros RSA.
-f, --outform codificación
Codificación de la clave privada generada. Puede ser der (ASN.1 DER) o pem (PEM Base64), por defecto es der.

CRIPTOGRAFÍA DE UMBRAL RSA

-n, --shares <n>
Número de partes de la clave privada RSA.
-l, --threshold <l>
Número mínimo de partes de clave RSA participantes.

PROBLEMAS EN HOSTS CON BAJA ENTROPÍA

Si se utiliza el plugin gmp para generar claves privadas RSA, el material de la clave se lee de /dev/random (a través del plugin random). Por lo tanto, el comando puede bloquearse si el pool de entropía del sistema está vacío. Para evitar esto, utilice un generador de números aleatorios de hardware para alimentar /dev/random o utilice OpenSSL (a través del plugin openssl o la línea de comandos), que no es tan estricto en cuanto a la calidad del material de la clave (lee de /dev/urandom si es necesario). También es posible configurar los dispositivos utilizados por el plugin random en strongswan.conf(5). Establecer libstrongswan.plugins.random.random a /dev/urandom fuerza al plugin a tratar los bytes leídos de /dev/urandom como datos aleatorios de alta calidad, evitando así el bloqueo. Por supuesto, esto no cambia el hecho de que el material de la clave generado de esta manera es de menor calidad.

EJEMPLOS

pki --gen --size 3072 > rsa_key.der
Genera una clave privada RSA de 3072 bits.
pki --gen --type ecdsa --size 256 > ecdsa_key.der
Genera una clave privada ECDSA de 256 bits.
