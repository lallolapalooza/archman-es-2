PKCON(1) Comandos de usuario PKCON(1)

NOMBRE

pkcon - Cliente de consola de PackageKit

SINOPSIS

pkcon [OPCIÓN...] [COMANDO]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando pkcon.

pkcon es el cliente de línea de comandos para PackageKit.

COMANDOS

pkcon conoce los siguientes comandos. Dependiendo del backend en uso, no todos pueden estar disponibles.

backend-details

Muestra información sobre el backend de PackageKit en uso.

get-roles

Lista los roles que puede tener una transacción.

get-groups

Lista los grupos de paquetes disponibles.

get-filters

Lista los filtros disponibles.

get-transactions

Lista las transacciones conocidas.

get-time ROL

Muestra el tiempo transcurrido desde la última transacción con el rol dado.

search [name|details|group|file] DATOS

Busca un paquete que coincida con los datos dados. La búsqueda se realiza en la información del paquete indicada por el primer argumento: nombre, detalles, grupo o archivos.

install PAQUETES

Instala los paquetes dados desde los repositorios.

install-local ARCHIVOS

Instala los paquetes dados desde el sistema de archivos local.

download DIRECTORIO PAQUETES

Descarga los paquetes dados desde los repositorios y los almacena en el directorio dado.

install-sig TIPO ID_CLAVE PAQUETE

Instala una firma de paquete. En este momento solo se admiten firmas GPG.

remove PAQUETE

Elimina el paquete dado.

update [PAQUETES]

Actualiza el sistema instalando las actualizaciones disponibles. Si se especifica una lista de paquetes, solo instala las actualizaciones para esos paquetes.

refresh [force]

Actualiza la información en caché sobre las actualizaciones disponibles.

resolve PAQUETE

Resuelve el nombre del paquete dado y muestra información sobre los paquetes o actualizaciones instalados o disponibles.

upgrade-system DISTRIBUCIÓN [minimal|default|complete]

Actualiza el sistema a la distribución dada.

get-updates

Lista las actualizaciones disponibles.

get-distro-upgrades

Lista las actualizaciones de distribución disponibles.

depends-on PAQUETE

Lista las dependencias del paquete dado.

required-by PAQUETE

Lista los paquetes que requieren el paquete dado.

get-details PAQUETE

Muestra detalles sobre el paquete disponible o instalado con el nombre dado.

get-details-local ARCHIVO

Muestra detalles sobre el paquete local.

get-files PAQUETE

Lista los archivos contenidos en el paquete dado.

get-files-local ARCHIVO

Lista los archivos contenidos en el paquete local.

get-update-detail PAQUETE

Muestra el registro de cambios del paquete para el paquete dado.

get-packages

Lista todos los paquetes disponibles e instalados.

repo-list

Lista todos los repositorios de paquetes configurados.

repo-enable REPOSITORIO

Habilita el repositorio dado.

repo-disable REPOSITORIO

Inhabilita el repositorio dado.

repo-set-data REPOSITORIO PARAMETRO DATOS

Establece el parámetro dado al valor dado para el repositorio.

repo-remove REPOSITORIO PARAMETRO

Elimina el repositorio y opcionalmente cualquier paquete instalado desde él.

what-provides CADENA

Lista los paquetes que proporcionan la cadena dada.

accept-eula ID_EULA

Acepta el EULA con el ID dado.

get-categories

Lista las categorías disponibles.

repair

Intenta reparar la base de datos de paquetes del sistema.

offline-get-prepared

Muestra información sobre la actualización sin conexión preparada. Si no hay ninguna actualización sin conexión preparada, sale con un código de salida de 1.

offline-trigger

Inicia una actualización sin conexión.

offline-status

Muestra información sobre el resultado de la última actualización sin conexión.

OPCIONES

Las siguientes opciones se pueden utilizar para influir en el comportamiento de pkcon.

--version

Muestra la versión del programa y sale.

-h, --help

Muestra las opciones de ayuda.

--help-all

Muestra todas las opciones de ayuda.

--filter FILTRO

Establece el filtro a usar.

-y, --noninteractive

Instala paquetes sin pedir confirmación.

--only-download

Prepara la transacción descargando solo los paquetes.

-n, --background

Ejecuta el comando utilizando ancho de banda de red inactivo y también utilizando menos energía.

-p, --plain

Muestra en pantalla una salida legible por máquina, en lugar de usar widgets animados.

-v, --verbose

Muestra información de depuración.

-c, --cache-age EDAD

Establece la edad máxima aceptable para los metadatos en caché, en segundos. Usa -1 para 'nunca'.

--allow-untrusted

Permite la instalación de paquetes no confiables.

--allow-downgrade

Permite la degradación de paquetes durante la transacción.

--allow-reinstall

Permite la reinstalación de paquetes durante la transacción.

VALORES DE RETORNO

0

Éxito

1

Falló con un error interno misceláneo.

3

Falló con un error de sintaxis o no se pudo analizar el comando.

4

Falló porque no se encontró un archivo o directorio.

5

No se hizo nada útil.

6

La configuración inicial falló, por ejemplo, al establecer el proxy de red.

7

La transacción falló, consulta el error detallado para más información.
