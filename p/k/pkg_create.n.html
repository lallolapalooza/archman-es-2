pkg::create(n) Comandos integrados de Tcl pkg::create(n)

NOMBRE

pkg::create - Construye un comando apropiado de 'package ifneeded' para una especificación de paquete dada

SINOPSIS

::pkg::create -name nombrePaquete -version versionPaquete ?-load especArch? ... ?-source especArch? ...

DESCRIPCIÓN

::pkg::create es un procedimiento de utilidad que forma parte de la biblioteca estándar de Tcl. Se utiliza para crear un comando apropiado de package ifneeded para una especificación de paquete dada. Puede usarse para construir un archivo pkgIndex.tcl para usarlo con el mecanismo de package.

OPCIONES

Los parámetros soportados son:

-name nombrePaquete
Este parámetro especifica el nombre del paquete. Es obligatorio.
-version versionPaquete
Este parámetro especifica la versión del paquete. Es obligatorio.
-load especArch
Este parámetro especifica una biblioteca binaria que debe cargarse con el comando load. especArch es una lista con dos elementos. El primer elemento es el nombre del archivo a cargar. El segundo elemento, opcional, es una lista de comandos suministrados al cargar ese archivo. Si la lista de procedimientos está vacía u omitida, ::pkg::create configurará la biblioteca para carga directa (ver pkg_mkIndex). Se pueden especificar cualquier número de parámetros -load.
-source especArch
Este parámetro es similar al parámetro -load, excepto que especifica una biblioteca Tcl que debe cargarse con el comando source. Se pueden especificar cualquier número de parámetros -source.

Se debe proporcionar al menos un parámetro -load o -source.
