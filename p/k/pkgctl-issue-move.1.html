NOMBRE

pkgctl-issue-move - Mover un ticket a otro proyecto

SINOPSIS

pkgctl issue move [OPCIONES] [IID] [PAQUETE_DESTINO]

DESCRIPCIÓN

El comando move permite a los usuarios transferir un ticket de un proyecto a otro dentro del grupo de empaquetado de Arch Linux. Esto es útil cuando se identifica que un ticket es más relevante o se maneja mejor en un proyecto diferente.

Por defecto, el comando opera dentro del directorio actual, pero los usuarios pueden especificar una base de paquete diferente desde la cual mover el ticket.

Los usuarios deben especificar el ID del ticket (IID) y el paquete de destino al que se debe mover el ticket. Se puede proporcionar un mensaje de comentario explicando la razón de la mudanza directamente a través de la línea de comandos. Para explicaciones más detalladas o contexto adicional, los usuarios tienen la opción de editar el comentario de mudanza usando un editor de texto antes de enviarlo.

OPCIONES

-p, --package PKGBASE

Mover desde PKGBASE en lugar del directorio actual

-m, --message MSG

Usar el mensaje proporcionado como comentario

-e, --edit

Editar el comentario usando un editor

-h, --help

Mostrar un texto de ayuda
