NOMBRE

pkttyagent - Ayudante de autenticación textual

SINOPSIS

pkttyagent [--version] [--help]

pkttyagent [--process { pid | pid-start-time } | --system-bus-name nombre-bus] [--notify-fd fd] [--fallback]

DESCRIPCIÓN

pkttyagent se utiliza para iniciar un agente de autenticación textual para el sujeto especificado por --process o --system-bus-name. Si no se proporcionan estas opciones, se utiliza el proceso padre.

Para recibir notificaciones cuando el agente de autenticación se haya registrado, escucha la señal D-Bus Changed o utiliza --notify-fd para pasar el número de un descriptor de archivo que se ha pasado al programa. Este descriptor de archivo se cerrará cuando el agente de autenticación se haya registrado correctamente.

Si se utiliza --fallback, el agente de autenticación textual no reemplazará un agente de autenticación existente.

VALOR DE RETORNO

Si no se pudo registrar el agente de autenticación, pkttyagent sale con un código de salida de 127. Se imprimen mensajes diagnósticos en la salida de error estándar.

Si una o más de las opciones proporcionadas están mal formadas, pkttyagent sale con un código de salida de 126. Si stdin es una tty, también se muestra esta página del manual.

Si el agente de autenticación se registró correctamente, pkttyagent seguirá ejecutándose, interactuando con el usuario según sea necesario. Cuando sus servicios ya no sean necesarios, el proceso puede ser terminado.

NOTAS

Dado que los identificadores de proceso pueden ser reciclados, el llamante siempre debe usar pid,pid-start-time al usar la opción --process. El valor de pid-start-time se puede determinar consultando, por ejemplo, el sistema de archivos de proc(5) dependiendo del sistema operativo. Si solo se pasa pid a la opción --process, entonces pkttyagent buscará la hora de inicio, pero ten en cuenta que esto puede ser problemático.
