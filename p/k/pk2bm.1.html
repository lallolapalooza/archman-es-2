NOMBRE

pk2bm - crear un mapa de bits a partir de un pkfont de TeX

SINOPSIS:

pk2bm [-bh] [-Wancho] [-Halto] -ccaracter pkfont

pk2bm [-bh] [-Wancho] [-Halto] -ooctalcaracter pkfont

DESCRIPCIÓN

Este programa genera un mapa de bits (archivo ASCII) que se puede utilizar para crear aplicaciones X11. El archivo de mapa de bits consta de todos los píxeles del carácter especificado (a través de la opción -c o -o) del pkfont dado. El formato se describe en bitmap(X11).

El pkfont es un archivo de fuente empaquetado generado por gftopk(TeX) a partir de un gffont. Un gffont es la salida de METAFONT, un programa para diseñar fuentes de forma independiente del dispositivo.

Con la bandera -b se genera un mapa de bits en el que todos los píxeles negros se dibujan como un `*' y todos los bits blancos como un `.'. Con la bandera -h se genera un volcado hexadecimal del mapa de bits.

Las opciones -W y/o -H se pueden usar para crear un mapa de bits de respectivamente `ancho' y `alto' píxeles. El pk-bitmap se centrará en este caso según estas nuevas dimensiones.

La salida se escribe en la salida estándar.
