NOMBRE

pkgctl-version-upgrade - Ajusta el PKGBUILD para que coincida con la última versión upstream

SINOPSIS

pkgctl version upgrade [OPCIONES] [PKGBASE...]

DESCRIPCIÓN

Simplifica el proceso de mantener los archivos PKGBUILD actualizados con las últimas versiones upstream.

Al ejecutarse, ajusta automáticamente el archivo PKGBUILD, asegurando que el campo `pkgver` se establezca para que coincida con la última versión disponible de la fuente upstream. Además de actualizar `pkgver`, este comando también restablece `pkgrel` a 1 y actualiza las sumas de verificación.

Muestra un resumen de los paquetes actualizados, los paquetes al día y cualquier fallo en las comprobaciones.

Esto simplifica el mantenimiento de los archivos PKGBUILD, reduciendo el esfuerzo manual requerido para rastrear e implementar cambios de versión de las fuentes upstream.

CONFIGURACIÓN

Utiliza nvchecker(1) y un archivo .nvchecker.toml ubicado junto al PKGBUILD. Consulta la sección de configuración en pkgctl-version(1).

OPCIONES

--no-update-checksums

Desactiva el cálculo y la actualización de las sumas de verificación

-v, --verbose

Muestra los resultados, incluidas las versiones al día

-h, --help

Muestra un texto de ayuda

VER TAMBIÉN

pkgctl-version(1) nvchecker(1)
