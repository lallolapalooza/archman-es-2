NOMBRE

pkgctl-build - Construir paquetes dentro de un chroot limpio

SINOPSIS

pkgctl build [OPCIONES] [RUTA...]

DESCRIPCIÓN

Construye paquetes en un entorno chroot limpio, ofreciendo varias opciones y funcionalidades para personalizar el proceso de construcción de paquetes.

Por defecto, los entornos chroot se encuentran en /var/lib/archbuild/.

OPCIONES DE CONSTRUCCIÓN

--arch ARQUITECTURA

Especifica las arquitecturas para las que construir (deshabilita la autodetección)

--repo REPO

Especifica el repositorio de destino para paquetes nuevos que no estén en ningún repositorio oficial. Se recurre a 'extra' al construir paquetes que aún no están presentes en ningún repositorio oficial. El uso de esta opción no está permitido si el paquete ya ha sido lanzado, ya que eludiría la salvaguarda de autodetección.

-s, --staging

Construye contra la contraparte de staging del repositorio autodetectado.

-t, --testing

Construye contra la contraparte de testing del repositorio autodetectado.

-o, --offload

Construye en un servidor remoto y transfiere los artefactos después.

-c, --clean

Recrea el chroot antes de construir.

--inspect CUÁNDO

Inicia un shell interactivo para inspeccionar el chroot después de la construcción. Útil para facilitar la depuración de la construcción de un paquete.
Los valores posibles para CUÁNDO son 'never', 'always' o 'failure'

-w, --worker SLOT

Nombre de la ranura del trabajador, útil para construcciones concurrentes. Por defecto, la ranura se asigna automáticamente al número de pts del tty actual. En caso de que el llamador no sea un tty, elige una ranura aleatoria entre 1 y el número de unidades de procesamiento disponibles.

--nocheck

No ejecuta la función check() en el PKGBUILD.

OPCIONES DE INSTALACIÓN

-I, --install-to-chroot ARCHIVO

Instala un paquete en la copia de trabajo del chroot.

-i, --install-to-host MODO

Instala los paquetes construidos en el sistema host. Útil cuando se desea verificar que el paquete funciona como se espera.
•Cuando MODO es all, esto instala todos los paquetes construidos.
•Cuando MODO es auto, esto instala todos los paquetes construidos que están actualmente instalados.

OPCIONES DE PKGBUILD

--pkgver=PKGVER

Establece pkgver, restablece pkgrel y actualiza las sumas de verificación.

--pkgrel=PKGREL

Establece pkgrel a un valor dado.

--rebuild

Incrementa la variable pkgrel actual.

--update-checksums

Fuerza el cálculo y la actualización de las sumas de verificación deshabilitando la autodetección.
Solo debe usarse en circunstancias especiales, como al agregar nuevos archivos de parche al array de fuentes. Durante las operaciones de empaquetado regulares, las sumas de verificación se actualizan automáticamente al actualizar un paquete usando --pkgver o deben permanecer inmutables durante las reconstrucciones.

-e, --edit

Edita el PKGBUILD antes de construir.

OPCIONES DE LANZAMIENTO

-r, --release

Confirma, etiqueta y lanza automáticamente después de construir.
Especificar esta opción es necesario cuando se utilizan las siguientes opciones en esta sección.

-m, --message MSG

Utiliza el <msg> dado como mensaje de confirmación.

-u, --db-update

Actualiza automáticamente la base de datos de pacman como última acción.

OPCIONES

-h, --help

Muestra un texto de ayuda.

VER TAMBIÉN

pkgctl-release(1) pkgctl-db-update(1)
