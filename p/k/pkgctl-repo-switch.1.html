NOMBRE

pkgctl-repo-switch - Cambiar un repositorio de paquetes a una versión especificada

SINOPSIS

pkgctl repo switch [OPCIONES] [VERSIÓN] [PKGBASE]...

DESCRIPCIÓN

Cambia un repositorio fuente de paquetes a una versión, etiqueta o rama especificada. El árbol de trabajo y el índice se actualizarán para coincidir con la referencia especificada.

Si se especifica un identificador de versión en el formato de versión de pacman, dicho identificador se traducirá automáticamente al nombre de etiqueta de Git en consecuencia.

Se utilizará el directorio de trabajo actual si no se especifica ningún PKGBASE.

OPCIONES

--discard-changes

Continuar aunque el índice o el árbol de trabajo difieran de HEAD. Tanto el índice como el árbol de trabajo se restaurarán para coincidir con el objetivo del cambio.

-f, --force

Un alias para --discard-changes.

-h, --help

Mostrar texto de ayuda.
