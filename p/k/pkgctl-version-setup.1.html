NOMBRE

pkgctl-version-setup - Detecta y configura automáticamente una configuración básica de nvchecker

SINOPSIS

pkgctl version setup [OPCIONES] [PKGBASE...]

DESCRIPCIÓN

Este subcomando automatiza la creación de un archivo de configuración básico de nvchecker(1) analizando el array de fuentes especificado en el archivo PKGBUILD(1) de un paquete. Este comando detecta de forma inteligente varias plataformas y API (por ejemplo, GitHub, GitLab, PyPI) utilizadas por las fuentes del paquete y genera una configuración .nvchecker.toml correspondiente basada en su mejor suposición.

Esto es particularmente útil para inicializar la configuración de nvchecker(1) para un paquete sin tener que crear manualmente el archivo .nvchecker.toml. Simplifica el proceso de configuración de comprobaciones de versiones, especialmente al migrar el monitoreo de un paquete de una plataforma de fuentes a otra o al iniciar comprobaciones de versiones para un paquete nuevo.

Si no se especifica PKGBASE, el comando usa por defecto el directorio de trabajo actual.

Para obtener una lista de fuentes compatibles y sus formatos de URL esperados, por favor consulte la sección de fuentes.

OPCIONES

-f, --force

Sobrescribe la configuración existente de nvchecker(1)

--prefer-platform-api

Prefiere la API específica de la plataforma GitHub/GitLab sobre git para casos complejos.

--url URL

Deriva el objetivo de la comprobación de la URL dada en lugar de las entradas del array de fuentes.

--no-check

No ejecuta pkgctl-version-check(1) después de la configuración.

--no-upstream

Configura un archivo en blanco para paquetes sin fuentes upstream, como los metapaquetes. Esto solo debe usarse para casos sin upstream. Por favor, póngase en contacto con el equipo de desarrolladores para obtener orientación sobre fuentes upstream difíciles de configurar.

-h, --help

Muestra un texto de ayuda.

EJEMPLOS

pkgctl version setup

Detecta la fuente desde el directorio actual del PKGBUILD(1) y configura un .nvchecker.toml básico.

pkgctl version setup --url https://github.com/example/project

Genera un .nvchecker.toml para el PKGBUILD(1) actual, pero anula la URL de la fuente con el proyecto de GitHub especificado.

NOMBRE

pkgctl-version-setup - Utilidad para ayudar a gestionar versiones de paquetes.

SINOPSIS

pkgctl version setup [OPCIONES]

DESCRIPCIÓN

pkgctl version setup es una herramienta diseñada para simplificar el proceso de configuración de versiones de paquetes en el entorno de Arch Linux. Permite automatizar tareas relacionadas con la gestión de las versiones de los paquetes, como el establecimiento de versiones predeterminadas, la actualización de versiones o la validación de la compatibilidad.

OPCIONES

Esta utilidad no tiene opciones específicas en esta versión.
