PKCS11-REGISTER(1) Herramientas de OpenSC PKCS11-REGISTER(1)

NOMBRE

pkcs11-register - Herramienta simple para instalar módulos PKCS#11 en aplicaciones conocidas.

SINOPSIS

pkcs11-register [OPCIONES]

DESCRIPCIÓN

La utilidad pkcs11-register se puede usar desde la línea de comandos para registrar módulos PKCS#11 en varias aplicaciones.

OPCIONES

--help, -h

Muestra el mensaje de ayuda en pantalla.

--version, -V

Imprime la versión de lanzamiento del paquete OpenSC.

--module archivo, -m archivo

Ruta al módulo PKCS#11 a cargar. El valor predeterminado es el módulo PKCS#11 de OpenSC.

--skip-chrome

No instale el módulo para el navegador Chrome. Por defecto, la herramienta intenta instalar el módulo para el navegador Chrome.

--skip-firefox

No instale el módulo para el navegador Firefox. Por defecto, la herramienta intenta instalar el módulo para el navegador Firefox.

--skip-thunderbird

No instale el módulo para el cliente de correo Thunderbird. Por defecto, la herramienta intenta instalar el módulo para el cliente de correo Thunderbird.

--skip-seamonkey

No instale el módulo para Seamonkey. Por defecto, la herramienta intenta instalar el módulo Seamonkey.

VER TAMBIÉN

pkcs11-tool(1) opensc.conf(5)
