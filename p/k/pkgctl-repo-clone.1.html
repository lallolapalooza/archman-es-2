NOMBRE

pkgctl-repo-clone - Clonar un repositorio de paquetes

SINOPSIS

pkgctl repo clone [OPCIONES] [NOMBREPAQUETE...]

DESCRIPCIÓN

Clona repositorios de empaquetado Git del espacio de nombres canónico.

Posteriormente se invoca al comando configure para sincronizar las especificaciones de la distribución y la configuración de makepkg.conf. La opción sin privilegios puede usarse para clonar repositorios de empaquetado sin acceso SSH utilizando HTTPS de solo lectura.

OPCIONES

-m, --maintainer NOMBRE

Clona todos los paquetes del mantenedor con el nombre indicado.

--protocol https

Clona el repositorio a través de https.

--universe

Clona todos los paquetes existentes, útil para calentar la caché.

--switch VERSIÓN

Cambia a una versión especificada. El árbol de trabajo y el índice se actualizan para coincidir con la versión.

-j, --jobs N

Ejecuta hasta N trabajos en paralelo. Por defecto, el número de trabajos es igual al número de unidades de procesamiento disponibles. Para procesamiento secuencial, esta opción debe pasarse con 1.

-h, --help

Muestra el texto de ayuda.

VER TAMBIÉN

pkgctl-repo-configure(1) pkgctl-repo-switch(1)
