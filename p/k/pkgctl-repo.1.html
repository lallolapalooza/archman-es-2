NOMBRE

pkgctl-repo - Gestiona repositorios de empaquetado de Git y su configuración

SINOPSIS

pkgctl repo [OPCIONES] [SUBCOMANDO]

DESCRIPCIÓN

Gestiona repositorios de empaquetado de Git y ayuda con su configuración según las especificaciones de la distribución.

La información del autor de Git y la clave de firma utilizada se configuran desde makepkg.conf, leída desde cualquier ubicación válida como /etc o XDG_CONFIG_HOME. El comando configure se puede usar para sincronizar las especificaciones de la distribución y la configuración de makepkg.conf para repositorios previamente clonados.

La opción no privilegiada se puede usar para clonar repositorios de empaquetado sin acceso SSH utilizando HTTPS de solo lectura.

OPCIONES

-h, --help

Muestra un texto de ayuda

SUBCOMANDOS

pkgctl repo clean

Elimina archivos no rastreados del árbol de trabajo

pkgctl repo clone

Clona un repositorio de paquetes

pkgctl repo configure

Configura una clonación según las especificaciones de la distribución

pkgctl repo create

Crea un nuevo repositorio de paquetes en GitLab

pkgctl repo switch

Cambia un repositorio de paquetes a una versión especificada

pkgctl repo web

Abre el sitio web del repositorio de empaquetado
