NOMBRE

pkgctl-license - Comprobar y gestionar el cumplimiento de licencias de paquetes

SINOPSIS

pkgctl license [OPCIONES] [SUBCOMANDO]

DESCRIPCIÓN

Comandos relacionados con las licencias de paquetes, incluyendo comprobaciones de cumplimiento.

Utiliza reuse(1) y un archivo REUSE.toml ubicado junto al PKGBUILD(5).

CONFIGURACIÓN

El archivo REUSE.toml debe contener anotaciones para todos los archivos regulares que se espera que estén presentes en un repositorio de paquetes de Arch Linux.

Utilice pkgctl-license-setup(1) para detectar y configurar automáticamente un archivo de configuración básico de REUSE basado en los archivos del repositorio de paquetes.

Para obtener información detallada sobre las diversas opciones de configuración disponibles para el archivo REUSE.toml, consulte la Especificación REUSE ( https://reuse.software/spec).

OPCIONES

-h, --help

Muestra un texto de ayuda

SUBCOMANDOS

pkgctl license check

Comprueba el cumplimiento de la licencia del paquete utilizando REUSE

pkgctl license setup

Detecta y configura automáticamente una configuración básica de REUSE

VER TAMBIÉN

pkgctl-license-check(1) pkgctl-license-setup(1) reuse(1) PKGBUILD(5)
