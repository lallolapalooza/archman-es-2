NOMBRE

pkgctl-diff - Compara archivos de paquetes usando diferentes modos.

SINOPSIS

pkgctl diff [OPCIONES] [MODOS] [ARCHIVO|NOMBREPAQUETE...]

DESCRIPCIÓN

Busca un paquete construido localmente que corresponda al PKGBUILD, y descarga la última versión de ese paquete de los repositorios de Pacman. Luego compara los archivos de los paquetes usando diferentes modos mientras utiliza una lista de contenido de tar simple por defecto.

Cuando se le da un paquete, úselo para comparar con el construido localmente. Cuando se le dan dos paquetes, compare ambos paquetes entre sí.

En cualquier caso, un nombre de paquete se convertirá en un nombre de archivo del caché o del pool, y pkgctl diff procederá como si este nombre de archivo se hubiera especificado inicialmente.

OPCIONES

-M, --makepkg-config

Establece un archivo de configuración alternativo de makepkg

-P, --pool=DIR

Busca el objetivo de diferencia en el directorio pool (por defecto '/srv/ftp/pool')

-v, --verbose

Proporciona una salida más detallada/sin filtrar

-h, --help

Muestra un texto de ayuda

OPCIONES DE SALIDA

--color[=CUÁNDO]

Colorea la salida; CUÁNDO es 'nunca', 'siempre', o 'auto'; --color solo significa --color=auto

-u, -U, --unified

Muestra 3 líneas de contexto unificado

-y, --side-by-side

Muestra en dos columnas

-W, --width[=NUM]

Muestra como máximo NUM (por defecto 'auto') columnas de impresión; NUM puede ser 'auto', 'columns' o un número. 'auto' se resolverá a la longitud máxima de línea de ambos archivos, garantizando que la diferencia no se corte.

MODOS

-l, --list

Activa el modo de comparación de lista de contenido de tar (por defecto)

-d, --diffoscope

Activa el modo de comparación de diffoscope

-p, --pkginfo

Activa el modo de comparación de .PKGINFO

-b, --buildinfo

Activa el modo de comparación de .BUILDINFO
