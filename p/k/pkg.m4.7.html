NOMBRE

pkg.m4 — macros de autoconf para usar pkgconf

SINOPSIS

PKG_PREREQ

PKG_PROG_PKG_CONFIG

PKG_CHECK_MODULES

PKG_CHECK_MODULES_STATIC

PKG_INSTALLDIR

PKG_NOARCH_INSTALLDIR

PKG_CHECK_VAR

PKG_WITH_MODULES

PKG_HAVE_WITH_MODULES

PKG_HAVE_DEFINE_WITH_MODULES

DESCRIPCIÓN

pkg.m4 es una colección de macros de autoconf que ayudan a configurar las opciones del compilador y el enlazador para bibliotecas de desarrollo. Esto permite a los sistemas de compilación detectar otras dependencias y usarlas con la cadena de herramientas del sistema.

MACROS DE AUTOCONF

PKG_PREREQ(VERSIÓN-MÍNIMA)

Comprueba que la versión de las macros de autoconf pkg.m4 en uso sea al menos VERSIÓN-MÍNIMA. Esto se puede usar para asegurar que una macro pkg.m4 en particular estará disponible.

PKG_PROG_PKG_CONFIG([VERSIÓN-MÍNIMA])

Busca una implementación de pkg-config que sea al menos VERSIÓN-MÍNIMA o más reciente.

PKG_CHECK_MODULES(PREFIJO-VARIABLE, MÓDULOS [,ACCIÓN-SI-ENCONTRADO [,ACCIÓN-SI-NO-ENCONTRADO]])

PKG_CHECK_MODULES_STATIC(PREFIJO-VARIABLE, MÓDULOS [,ACCIÓN-SI-ENCONTRADO [,ACCIÓN-SI-NO-ENCONTRADO]])

Comprueba si existe un conjunto dado de módulos y, si es así, define las variables CFLAGS y LIBS precedidas por PREFIJO-VARIABLE con la salida de --cflags y --libs respectivamente.

Los argumentos opcionales ACCIÓN-SI-ENCONTRADO y ACCIÓN-SI-NO-ENCONTRADO son fragmentos de shell que deben ejecutarse si el conjunto de módulos se encuentra o no.

Si $PKG_CONFIG no está definido, se ejecutará la macro PKG_PROG_PKG_CONFIG para localizar una implementación de pkg-config.

La macro PKG_CHECK_MODULES_STATIC proporciona el mismo comportamiento que PKG_CHECK_MODULES con la vinculación estática habilitada a través de la bandera --static.

PKG_INSTALLDIR(DIRECTORIO)

Define la variable $pkgconfigdir como la ubicación donde un paquete debe instalar los archivos .pc de pkg-config.

Por defecto, el directorio es $libdir/pkgconfig, pero el valor por defecto se puede cambiar pasando el parámetro DIRECTORIO.

Este valor se puede sobrescribir con el parámetro de configuración --with-pkgconfigdir.

PKG_NOARCH_INSTALLDIR(DIRECTORIO)

Define la variable $noarch_pkgconfigdir como la ubicación donde un paquete debe instalar los archivos .pc de pkg-config.

Por defecto, el directorio es $datadir/pkgconfig, pero el valor por defecto se puede cambiar pasando el parámetro DIRECTORIO.

Este valor se puede sobrescribir con el parámetro de configuración --with-noarch-pkgconfigdir.

PKG_CHECK_VAR(VARIABLE, MÓDULO, VARIABLE-CONFIGURACIÓN, [ACCIÓN-SI-ENCONTRADO], [ACCIÓN-SI-NO-ENCONTRADO])

Recupera el valor de la variable pkg-config VARIABLE-CONFIGURACIÓN de MÓDULO y lo almacena en la variable VARIABLE.

Tenga en cuenta que no se recomienda el uso repetido de VARIABLE, ya que la comprobación se omitirá si la variable ya está establecida.

PKG_WITH_MODULES(PREFIJO-VARIABLE, MÓDULOS, [ACCIÓN-SI-ENCONTRADO], [ACCIÓN-SI-NO-ENCONTRADO], [DESCRIPCIÓN], [DEFECTO])

Prepara una opción de configuración "--with-" usando el nombre PREFIJO-VARIABLE en minúsculas, fusionando el comportamiento de AC_ARG_WITH y PKG_CHECK_MODULES en una sola macro.

PKG_HAVE_WITH_MODULES(PREFIJO-VARIABLE, MÓDULOS, [DESCRIPCIÓN], [DEFECTO])

Macro de conveniencia para activar AM_CONDITIONAL después de una comprobación PKG_WITH_MODULES. PREFIJO-VARIABLE se exporta como una variable de make.

PKG_HAVE_DEFINE_WITH_MODULES(PREFIJO-VARIABLE, MÓDULOS, [DESCRIPCIÓN], [DEFECTO])

Macro de conveniencia para activar AM_CONDITIONAL y AC_DEFINE después de una comprobación PKG_WITH_MODULES. PREFIJO-VARIABLE se exporta como una variable de make.
