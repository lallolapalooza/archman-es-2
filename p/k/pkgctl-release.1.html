NOMBRE

pkgctl-release - Paso de lanzamiento para confirmar, etiquetar y subir artefactos de compilación

SINOPSIS

pkgctl release [OPCIONES] [RUTA...]

DESCRIPCIÓN

Los archivos modificados controlados por versión se prepararán primero para la confirmación, luego se creará una etiqueta Git que coincida con el pkgver y, finalmente, se subirán todos los artefactos de compilación.

Por defecto, el repositorio de pacman de destino se detectará automáticamente consultando el repositorio en el que está actualmente lanzado. Al añadir un nuevo paquete a los repositorios por primera vez, el repositorio de destino debe especificarse manualmente.

OPCIONES

-m, --message MENSAJE

Utiliza el <mensaje> dado como mensaje de confirmación

-r, --repo REPO

Especifica el repositorio de destino para paquetes nuevos que no están en ningún repositorio oficial. El uso de esta opción no está permitido si el paquete ya ha sido lanzado, ya que eludiría la salvaguarda de detección automática.

-s, --staging

Compila contra la contraparte de staging del repositorio detectado automáticamente

-t, --testing

Compila contra la contraparte de testing del repositorio detectado automáticamente

-u, --db-update

Actualiza automáticamente la base de datos de pacman después de subir

-h, --help

Muestra un texto de ayuda

VER TAMBIÉN

pkgctl-db-update(1)
