NOMBRE

pki --pkcs7 - Proporciona funciones de envoltura/desenvoltura PKCS#7

SINOPSIS

pki --pkcs7 --sign|--verify|--encrypt|--decrypt|--show [--in archivo] [--cert archivo] [--key archivo] [--digest digest] [--rsa-padding relleno] [--debug nivel]
pki --pkcs7 --options archivo
pki --pkcs7 -h | --help

DESCRIPCIÓN

Este subcomando de pki(1) proporciona funciones para envolver/desenvolver contenedores PKCS#7.

OPCIONES

-h, --help
Imprime información de uso con un resumen de las opciones disponibles.
-v, --debug nivel
Establece el nivel de depuración, por defecto: 1.
-+, --options archivo
Lee las opciones de la línea de comandos desde archivo.
-s, --sign
Crea datos firmados PKCS#7.
-u, --verify
Verifica datos firmados PKCS#7.
-e, --encrypt
Crea datos cifrados PKCS#7.
-e, --decrypt
Descifra datos cifrados PKCS#7.
-p, --show
Muestra información sobre el contenedor PKCS#7, lista los certificados.
-i, --in archivo
Archivo de entrada PKCS#7. Si no se proporciona, la entrada se lee desde STDIN.
-k, --key archivo
Clave privada utilizada para --sign y --decrypt.
-c, --cert archivo
Certificado para --sign, --verify y --encrypt. Puede utilizarse varias veces.
-g, --digest digest
Digest a utilizar para la creación de la firma. Uno de md5, sha1, sha224, sha256, sha384 o sha512. El valor por defecto se determina basándose en el tipo y tamaño de la clave de firma.
-R, --rsa-padding relleno
Relleno a utilizar para firmas RSA. Puede ser pkcs1 o pss, por defecto es pkcs1.
