NOMBRE

pkgctl-aur - Interactuar con el Arch User Repository (AUR)

SINOPSIS

pkgctl aur [OPCIONES] [SUBCOMANDO]

DESCRIPCIÓN

Proporciona un conjunto de herramientas diseñadas para gestionar e interactuar con el Arch User Repository (AUR). Simplifica varias tareas relacionadas con el AUR, incluyendo la importación de repositorios, la gestión de paquetes y la transición de paquetes entre los repositorios oficiales y el AUR.

OPCIONES

-h, --help

Mostrar texto de ayuda

SUBCOMANDOS

pkgctl aur drop-from-repo

Eliminar un paquete del repositorio oficial al AUR

VER TAMBIÉN

pkgctl-aur-drop-from-repo(1)
