NOMBRE

pkgctl-db - Utilidad de modificación de base de datos de Pacman para actualizaciones de paquetes, movimientos y más.

SINOPSIS

pkgctl db [OPCIONES] [SUBCOMANDO]

DESCRIPCIÓN

Gestiona la base de datos de Pacman y facilita la modificación de paquetes y sus metadatos dentro de la base de datos.

OPCIONES

-h, --help

Muestra información de uso y opciones disponibles.

SUBCOMANDOS

pkgctl db update

Actualiza el repositorio binario como paso final de liberación

pkgctl db move

Mueve paquetes entre repositorios binarios

pkgctl db remove

Elimina paquetes de repositorios binarios

VER TAMBIÉN

pkgctl-db-update(1) pkgctl-db-move(1) pkgctl-db-remove(1)
