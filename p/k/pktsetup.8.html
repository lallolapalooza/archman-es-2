PKTSETUP(8) Manual del Administrador del Sistema PKTSETUP(8)

NOMBRE

pktsetup - configurar y desmantelar asociaciones de dispositivos de paquetes

SINOPSIS

pktsetup dispositivo_paquete dispositivo_bloque
pktsetup -d dispositivo_paquete
pktsetup -s

DESCRIPCIÓN

Pktsetup se utiliza para asociar dispositivos de paquetes con dispositivos de bloque de CD o DVD, de modo que el dispositivo de paquete pueda ser montado y potencialmente utilizado como un sistema de archivos de lectura/escritura. Esto requiere soporte del kernel para el dispositivo de paquete y el sistema de archivos UDF.

Ver: HOWTO.udf (en el directorio de documentos de udftools)

ESTADO DE SALIDA

Pktsetup devuelve 0 en caso de éxito, un valor distinto de cero en caso de error.

OPCIONES

-d dispositivo_paquete
Elimina la asociación entre el dispositivo_paquete especificado y su dispositivo de bloque.
-s
Muestra el mapeo de dispositivos actual, un dispositivo por línea, en el formato
nombre : id_pktdev -> id_blkdev
(por ejemplo, "0 : 253:0 -> 22:0")

EJEMPLO

Los siguientes comandos proporcionan un ejemplo de uso del dispositivo de paquete.

cdrwtool -d /dev/sr0 -q
pktsetup 0 /dev/sr0
mount -t udf /dev/pktcdvd0 /mnt
 ...
umount /dev/pktcdvd0
pktsetup -d 0

ARCHIVOS

/dev/pktcdvd0,/dev/pktcdvd1,...  Dispositivos de paquetes de CD/DVD

DISPONIBILIDAD
