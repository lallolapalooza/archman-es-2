PKGFILE(1) Manual de pkgfile PKGFILE(1)

NOMBRE

pkgfile - un explorador de metadatos .files de alpm

SINOPSIS

Uso: pkgfile [operación] [opciones] objetivo

DESCRIPCIÓN

pkgfile busca en los metadatos .files creados por repo-add(8) para recuperar información de archivos sobre paquetes. Por defecto, el objetivo proporcionado se considera un nombre de archivo y pkgfile devolverá el(los) paquete(s) que contienen este archivo. Los repositorios que pkgfile busca se determinan por los habilitados en /etc/pacman.conf.

OPERACIONES

-l, --listar
El objetivo se considera un nombre de paquete en lugar de un nombre de archivo, y se devuelven los contenidos del paquete nombrado. Esto permite sintaxis de estilo repo/paquete (como "core/pacman") para limitar la amplitud de la búsqueda, pero solo cuando --listar se usa sin las opciones --glob o --regex.
-s, --buscar
Busca paquetes que contengan el objetivo proporcionado. Este es el modo de operación por defecto.
-u, --actualizar
Actualiza los archivos de metadatos almacenados. Se recomienda crear un trabajo cron diario con este comando para garantizar resultados precisos. Por defecto, solo se descargarán los repositorios que se encuentren más nuevos en el espejo. Pase esta opción dos veces para forzar la descarga de todos los repositorios.

COINCIDENCIA

-b, --binarios
Devuelve solo archivos que están contenidos dentro de un directorio bin o sbin.
-d, --directorios
Incluye directorios adicionales en los resultados de la búsqueda.
-g, --glob
Habilita la coincidencia de patrones de estilo shell. Ver glob(7). Tenga en cuenta que los comodines de shell * y ? nunca coincidirán con separadores de ruta. Por lo tanto, este tipo de coincidencia es útil para buscar entradas dentro de directorios, por ejemplo, /usr/bin/*.
-i, --ignorarmayusculas
Deshabilita la sensibilidad a mayúsculas y minúsculas en la coincidencia.
-r, --regex
Habilita la coincidencia de expresiones regulares. Ver pcre(3).
-R REPO, --repo=REPO
Busca solo en el repositorio específico.

SALIDA

-0, --nulo
Delimita la salida con bytes nulos en lugar de caracteres de nueva línea.
-q, --silencioso
Muestra menos. Esto se aplica a la operación --listar.
-v, --detallado
Muestra más. Esto se aplica a la operación --buscar.
-w, --crudo
Evita la justificación de la salida de 2 columnas.

DESCARGA

-z, --comprimir[=COMPRESION]
Repackea los repositorios descargados con el método de compresión opcionalmente suministrado, que puede ser uno de none, gzip, bzip2, lzop, lz4, lzma, xz, o zstd. Si se pasa esta bandera sin un método de compresión, se usará gzip por defecto. Si esta bandera no se pasa en absoluto, no se aplicará ninguna compresión. Aplicar cualquier forma de compresión disminuirá el rendimiento, pero puede ser deseable para preocupaciones de espacio en disco.

OPCIONES GENERALES

-C ARCHIVO, --config=ARCHIVO
Usa un archivo de configuración distinto del predeterminado /etc/pacman.conf.
-D DIRECTORIO, --cachedir=DIRECTORIO
Usa una ruta de caché distinta de la predeterminada en tiempo de compilación.
-h, --ayuda
Imprime la ayuda y sale.
-V, --version
Imprime la versión y sale.

HEURÍSTICAS DE COINCIDENCIA

En el modo --buscar y sin la opción --regex o --glob, pkgfile intentará hacer coincidir el objetivo proporcionado como un nombre de archivo exacto. Si el objetivo contiene un carácter '/', se intentará una coincidencia de ruta completa. Con la búsqueda habilitada con --regex y --glob, pkgfile siempre coincidirá con la ruta completa.

En el modo --listar y sin la opción --regex o --glob, pkgfile intentará hacer coincidir el objetivo proporcionado como un nombre de paquete exacto. Si el objetivo contiene un carácter '/', el texto anterior a la barra se asumirá como un repositorio y la búsqueda se restringirá.

HOOKS DE COMANDO NO ENCONTRADO

/usr/share/doc/pkgfile/command-not-found.bash
/usr/share/doc/pkgfile/command-not-found.zsh
/usr/share/doc/pkgfile/command-not-found.fish
Funciones compatibles con zsh, bash y fish que se pueden incluir en la inicialización del shell para ejecutar pkgfile cuando no se encuentra un comando ejecutado.

Si la variable de entorno PKGFILE_PROMPT_INSTALL_MISSING está configurada, y solo se encuentra un paquete, se mostrará una solicitud para instalar el paquete. NOTA: esta función requiere el programa sudo(8), y actualmente solo es compatible con la implementación de bash.

AUTOMATIZAR ACTUALIZACIONES

Se recomienda utilizar pkgfiled(1) para mantener las bases de datos de .files al día mientras se ejecuta `pacman -Fy` (ya sea por un usuario o por un cronjob/temporizador de systemd). pkgfiled se puede habilitar con:

systemctl enable --now pkgfiled

Alternativamente, pkgfile incluye unidades de temporizador y servicio de systemd para automatizar las actualizaciones periódicas de las bases de datos de .files. Suponiendo que pkgfile se compiló con soporte para systemd, esto se puede habilitar con:

systemctl enable --now pkgfile-update.timer

VER TAMBIÉN

pkgfiled(1), repo-add(8), pcre(3), glob(7), pacman.conf(5)

pkgfile(1)

NOMBRE

pkgfile - Busca archivos en los repositorios de paquetes de Arch Linux.

SINOPSIS

pkgfile [OPCIONES]... [ARCHIVO]...

pkgfile [OPCIONES]... -s [PATRÓN]...

pkgfile [OPCIONES]... -u

pkgfile [OPCIONES]... -c

pkgfile [OPCIONES]... --update

pkgfile [OPCIONES]... --clean

pkgfile [OPCIONES]... --update-db

pkgfile [OPCIONES]... --remove-db

pkgfile [OPCIONES]... --check-db

pkgfile [OPCIONES]... --verify-db

pkgfile [OPCIONES]... --download [ARCHIVO]...

pkgfile [OPCIONES]... --gen-db

pkgfile [OPCIONES]... --gen-db-arch [ARCHIVO]...

pkgfile [OPCIONES]... --gen-db-pkg [ARCHIVO]...

DESCRIPCIÓN

pkgfile es una utilidad para buscar archivos en los repositorios de paquetes de Arch Linux. Permite determinar en qué paquete se encuentra un archivo específico o listar todos los archivos de un paquete determinado.

OPCIONES

Estas son las opciones disponibles:

-h, --help
Muestra un mensaje de ayuda y sale.
-V, --version
Muestra información sobre la versión y sale.
-q, --quiet
Suprime los mensajes informativos.
-v, --verbose
Activa la salida detallada.
-u, --update
Actualiza la base de datos de archivos de paquetes.
-c, --clean
Limpia la base de datos de archivos de paquetes, eliminando entradas obsoletas.
--update-db
Actualiza la base de datos de archivos de paquetes.
--remove-db
Elimina la base de datos de archivos de paquetes.
--check-db
Comprueba la integridad de la base de datos de archivos de paquetes.
--verify-db
Verifica la base de datos de archivos de paquetes contra los repositorios actuales.
-s, --search
Busca archivos en la base de datos utilizando patrones.
-i, --ignorecase
Ignora mayúsculas y minúsculas al buscar.
-x, --regex
Interpreta los patrones como expresiones regulares.
-l, --local
Busca solo en la base de datos local.
-r, --remote
Busca solo en la base de datos remota (requiere actualización).
-f, --file=ARCHIVO
Busca el archivo especificado en la base de datos.
-p, --package=PAQUETE
Lista los archivos contenidos en el paquete especificado.
--download
Descarga los paquetes especificados.
--gen-db
Genera una base de datos de archivos de paquetes localmente.
--gen-db-arch
Genera una base de datos de archivos de paquetes para la arquitectura especificada.
--gen-db-pkg
Genera una base de datos de archivos de paquetes para el paquete especificado.

ARCHIVOS

/etc/pkgfile.conf: Archivo de configuración principal de pkgfile.

~/.cache/pkgfile/: Caché de la base de datos de archivos de paquetes.

EJEMPLO

Para buscar el paquete que contiene el archivo /usr/bin/ls:

pkgfile /usr/bin/ls

Para actualizar la base de datos de archivos de paquetes:

pkgfile -u

Para buscar todos los archivos que comiencen con lib (ignorando mayúsculas y minúsculas):

pkgfile -si lib

CONFIGURACIÓN

ARCHIVO DE CONFIGURACIÓN

La configuración de pkgfile se realiza principalmente a través del archivo /etc/pkgfile.conf. En este archivo, se pueden especificar las siguientes opciones:

  • --cachedir: Especifica el directorio donde se almacenará la caché de la base de datos.
  • --logfile: Especifica el archivo donde se registrarán los mensajes.
  • --repositories: Define los repositorios de paquetes a utilizar.
  • --arch: Define la arquitectura para la que se generarán las bases de datos.

VARIABLES DE ENTORNO

pkgfile también puede ser configurado mediante las siguientes variables de entorno:

  • PKGFILE_CACHEDIR: Equivalente a la opción --cachedir.
  • PKGFILE_LOGFILE: Equivalente a la opción --logfile.
  • PKGFILE_REPOSITORIES: Equivalente a la opción --repositories.
  • PKGFILE_ARCH: Equivalente a la opción --arch.

BÚSQUEDA DE ARCHIVOS

Para buscar un archivo específico, simplemente proporcione la ruta completa o parcial del archivo como argumento. pkgfile buscará en su base de datos y mostrará los paquetes que contienen ese archivo.

Se pueden usar comodines (*, ?) y expresiones regulares (con la opción -x) para realizar búsquedas más complejas.

BASE DE DATOS

ACTUALIZACIÓN DE LA BASE DE DATOS

Para que pkgfile pueda buscar archivos, necesita tener una base de datos actualizada de los archivos que contiene cada paquete. Utilice la opción -u o --update para descargar y actualizar esta base de datos desde los repositorios configurados.

pkgfile -u

LIMPIEZA DE LA BASE DE DATOS

Ocasionalmente, puede ser necesario limpiar la base de datos para eliminar entradas obsoletas o inconsistentes. Use la opción -c o --clean para realizar esta tarea.

pkgfile -c

SALIDA

La salida de pkgfile normalmente consiste en una lista de paquetes que contienen el archivo buscado. Si se usa la opción -p, se listarán los archivos de un paquete específico.

La salida detallada (opción -v) proporciona más información sobre el proceso de búsqueda y actualización.

DESCARGA

La opción --download permite descargar los paquetes especificados directamente desde los repositorios. Esto puede ser útil si desea instalar un paquete después de haberlo encontrado.

pkgfile --download <nombre_del_paquete>

OPCIONES GENERALES

Las opciones como -h, --help, -V, --version, -q, --quiet y -v, --verbose son comunes en muchas utilidades de línea de comandos y controlan el comportamiento general de la aplicación, como la visualización de ayuda o información detallada.

HEURÍSTICAS DE COINCIDENCIA

pkgfile utiliza una coincidencia exacta por defecto. Las opciones -i (ignorar mayúsculas y minúsculas) y -x (expresiones regulares) permiten modificar cómo se realizan las coincidencias para búsquedas más flexibles.

HOOKS DE COMANDO NO ENCONTRADO

pkgfile puede integrarse con el sistema command-not-found de Arch Linux. Si un comando no se encuentra, pkgfile puede sugerir el paquete que lo contiene, facilitando su instalación.

AUTOMATIZANDO ACTUALIZACIONES

Se recomienda automatizar la actualización de la base de datos de pkgfile para asegurar que las búsquedas sean siempre precisas. Esto se puede lograr programando un trabajo cron o utilizando un timer de systemd para ejecutar pkgfile -u periódicamente (por ejemplo, diariamente).

VER TAMBIÉN

pacman(8), makepkg(8)
