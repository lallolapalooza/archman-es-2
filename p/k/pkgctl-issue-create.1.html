NOMBRE

pkgctl-issue-create - Crear un nuevo ticket

SINOPSIS

pkgctl issue create [OPCIONES]

DESCRIPCIÓN

El comando create se utiliza para crear un nuevo ticket para un paquete de Arch Linux. Este comando es adecuado para informar de errores, regresiones, solicitudes de características o cualquier otro problema relacionado con un paquete. Proporciona una forma flexible de documentar y seguir nuevos tickets dentro del sistema de seguimiento de tickets del proyecto.

Por defecto, el comando opera dentro del directorio actual, pero los usuarios pueden especificar una base de paquetes diferente si es necesario.

Los usuarios pueden proporcionar un título para el ticket directamente a través de la línea de comandos. La descripción del ticket se puede suministrar desde un archivo o editar utilizando un editor de texto. Alternativamente, los usuarios pueden optar por continuar el proceso de creación del ticket utilizando la interfaz web para una experiencia más interactiva.

El comando permite establecer varias etiquetas y atributos para el ticket, como confidencialidad, prioridad, alcance, severidad y estado. Estas opciones ayudan a categorizar y priorizar el ticket adecuadamente dentro del sistema de seguimiento.

En caso de un fallo, el comando puede recuperarse automáticamente para garantizar que el proceso de creación del ticket se complete sin perder ningún dato.

Este comando es esencial para mantenedores, contribuidores y usuarios que necesitan informar de nuevos problemas relacionados con los paquetes de Arch Linux.

OPCIONES

-p, --package PKGBASE

Interactuar con PKGBASE en lugar del directorio actual

-t, --title TÍTULO

Utilizar el título proporcionado para el ticket

-F, --file ARCHIVO

Tomar la descripción del ticket de <archivo>

-e, --edit

Editar la descripción del ticket utilizando un editor

-w, --web

Continuar la creación del ticket con la interfaz web

--recover

Recuperarse automáticamente de un fallo

--confidentiality TIPO

Establecer la confidencialidad del ticket

--priority PRIORIDAD

Establecer la etiqueta de prioridad

--scope ALCANCE

Establecer la etiqueta de alcance

--severity SEVERIDAD

Establecer la etiqueta de severidad

--status ESTADO

Establecer la etiqueta de estado

-h, --help

Mostrar un texto de ayuda

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools
