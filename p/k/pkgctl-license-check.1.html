NOMBRE

pkgctl-license-check - Verifica el cumplimiento de licencias de paquetes usando REUSE

SINOPSIS

pkgctl license check [OPCIONES] [PKGBASE...]

DESCRIPCIÓN

Verifica el cumplimiento de licencias de paquetes usando REUSE y también verifica si existe un archivo LICENSE con el texto de licencia 0BSD específico de Arch Linux.

CONFIGURACIÓN

Utiliza reuse(1) y un archivo REUSE.toml ubicado junto al PKGBUILD(5). Consulte la sección de configuración en pkgctl-license(1).

Si no se especifica ningún PKGBASE, el comando usa por defecto el directorio de trabajo actual.

OPCIONES

-h, --help

Muestra un texto de ayuda

CÓDIGOS DE SALIDA

Al salir, devuelve uno de los siguientes códigos:

0

Condición de salida normal, todos los paquetes verificados cumplen

1

Causa desconocida de error

2

Condición de salida normal, pero algunos paquetes no cumplen

VER TAMBIÉN

pkgctl-license(1) reuse(1) PKGBUILD(5)

PÁGINA PRINCIPAL

https://gitlab.archlinux.org/archlinux/devtools
