NOMBRE

podman-ps - Imprimir información sobre contenedores

SINOPSIS

podman ps [opciones]

podman container ps [opciones]

podman container list [opciones]

podman container ls [opciones]

DESCRIPCIÓN

podman ps lista los contenedores en ejecución en el sistema. Utilice la opción --all para ver toda la información de los contenedores. Por defecto, lista:

  • el id del contenedor
  • el nombre de la imagen que utiliza el contenedor
  • el COMANDO que está ejecutando el contenedor
  • el tiempo en que se creó el contenedor
  • el estado del contenedor
  • los mapeos de puertos que utiliza el contenedor
  • nombres alternativos para el contenedor

OPCIONES

--all, -a

Mostrar todos los contenedores, por defecto solo los contenedores en ejecución.

Nota: Podman comparte el almacenamiento de contenedores con otras herramientas como Buildah y CRI-O. En algunos casos, estos contenedores externos también pueden existir en el mismo almacenamiento. Utilice la opción --external para ver estos contenedores externos. Los contenedores externos muestran el estado de 'storage'.

--external

Mostrar contenedores externos que no son controlados por Podman pero que están almacenados en el almacenamiento de contenedores. Estos contenedores externos generalmente se crean a través de otras tecnologías de contenedores como Buildah o CRI-O y pueden depender de las mismas imágenes de contenedor que Podman también utiliza. Los contenedores externos se denotan con 'buildah' o 'storage' en la columna COMANDO y ESTADO de la salida de ps.

--filter, -f

Filtrar qué contenedores se muestran en la salida. Se pueden dar múltiples filtros utilizando múltiples veces la opción --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
label! [Clave] o [Clave=Valor] Etiqueta NO asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizado para crear el contenedor (acepta regex)
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [DateTime] contenedor creado antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--format=formato

Imprimir contenedores formateados en JSON o usando una plantilla Go

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.AutoRemove Si es verdadero, los contenedores se eliminan al salir
.CIDFile Archivo de ID del contenedor
.Command Comando utilizado entre comillas
.Created ... Tiempo de creación del contenedor, A-M-D H:M:S
.CreatedAt Tiempo de creación del contenedor (igual que el anterior)
.CreatedHuman Tiempo de creación, relativo
.ExitCode Código de salida del contenedor
.Exited "true" si el contenedor ha salido
.ExitedAt Hora (segundos de época) en que salió el contenedor
.ExposedPorts ... Mapa de puertos expuestos en este contenedor
.ID ID del contenedor
.Image Nombre/ID de la imagen
.ImageID ID de la imagen
.IsInfra "true" si es un contenedor infra
.Label cadena Etiqueta especificada del contenedor
.Labels ... Todas las etiquetas asignadas al contenedor
.Mounts Volúmenes montados en el contenedor
.Names Nombre del contenedor
.Networks Mostrar todas las redes conectadas al contenedor
.Pid ID del proceso en el sistema anfitrión
.Pod Pod al que está asociado el contenedor (SHA)
.PodName Nombre del pod del contenedor
.Ports Puertos reenviados y expuestos
.Restarts Mostrar el recuento de reinicios del contenedor
.RunningFor Tiempo transcurrido desde que se inició el contenedor
.Size Tamaño del contenedor
.StartedAt Hora (segundos de época) en que se inició el contenedor
.State Descripción amigable del estado del contenedor
.Status Estado del contenedor

--help, -h

Imprimir el enunciado de uso

--last, -n

Imprimir los n últimos contenedores creados (todos los estados)

--latest, -l

Mostrar el último contenedor creado (todos los estados) (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excepto WSL2))

--namespace, --ns

Mostrar información de namespace

--no-trunc

No truncar la salida (por defecto false).

--noheading

Omitir las cabeceras de la tabla de la lista de contenedores.

--pod, -p

Mostrar los pods a los que están asociados los contenedores

--quiet, -q

Imprimir solo los IDs numéricos de los contenedores

--size, -s

Mostrar el tamaño total del archivo

--sort=created

Ordenar por comando, creado, id, imagen, nombres, runningfor, tamaño o estado", Nota: Elegir tamaño ordena por el tamaño de rootFs, no alfabéticamente como el resto de las opciones

--sync

Forzar una sincronización del estado del contenedor con el tiempo de ejecución OCI. En algunos casos, el estado de un contenedor en el tiempo de ejecución puede desincronizarse con el estado de Podman. Esto actualiza el estado de Podman basándose en lo que informa el tiempo de ejecución OCI. Forzar la sincronización es mucho más lento, pero puede resolver problemas de estado inconsistente.

--watch, -w

Actualizar la salida con los contenedores actuales en un intervalo en segundos.

EJEMPLOS

Listar contenedores en ejecución.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES
4089df24d4f

NOMBRE

podman-container-ps, ps, container-ps - Listar contenedores

SINOPSIS

Listar contenedores

podman container ps [options]

Listar contenedores (alias)

podman ps [options]

Listar contenedores

podman ps [options]

DESCRIPCIÓN

La utilidad `podman container ps` lista los contenedores que se están ejecutando actualmente en el sistema. La utilidad `podman ps` es un alias de esta utilidad.

Por defecto, solo se listan los contenedores que se están ejecutando. Para listar todos los contenedores, incluidos los que se han detenido, utilice la opción -a.

El resultado incluye la ID del contenedor, la imagen que se está utilizando, el comando que se está ejecutando dentro del contenedor, la hora en que se creó, la hora en que se inició por última vez, el estado del contenedor, los puertos expuestos por el contenedor y el nombre del contenedor.

OPCIONES

Las opciones disponibles incluyen:

-a, --all
No muestre solo los contenedores que se están ejecutando, sino todos los contenedores (tanto los que se están ejecutando como los que no).
--cert-dir dir
Ubicación de los certificados de confianza (por defecto: /etc/containers/certs.d/).
--chroot
Mostrar contenedores en modo chroot.
--cidfile path
Lea el ID del contenedor del archivo.
--contains
Filtrar los contenedores que contienen el nombre del contenedor especificado.
--dry-run
No ejecute el comando, solo imprima la salida.
--external
Mostrar contenedores creados por herramientas externas (no Podman).
--filter, -f map[string]string
Filtre la salida. El formato de filtro esclave=valor. Las claves disponibles son:
id
ID del contenedor
label, la
etiqueta de contenedor (formato:clave oclave=valor)
name
nombre del contenedor
network
ID o nombre de la red
status
estado del contenedor (ej.running,paused,exited,created)
volume
nombre del volumen
pod
ID o nombre del pod
--format Go template
Utilice una plantilla Go para dar formato a la salida. Los valores disponibles son:
.ID
ID del contenedor
.Image
Imagen utilizada por el contenedor
.Command
Comando que se está ejecutando en el contenedor
.CreatedAt
Hora en que se creó el contenedor
.StartedAt
Hora en que se inició el contenedor
.FinishedAt
Hora en que terminó el contenedor
.ExitCode
Código de salida del contenedor
.Status
Estado actual del contenedor
.VMLauncher
Indica si el contenedor se lanzó con un lanzador de VM.
.Ports
Puertos expuestos por el contenedor
.Labels
Etiquetas adjuntas al contenedor
.Mounts
Montajes de volúmenes para el contenedor
.Names
Nombre del contenedor
.Pod
ID del pod al que pertenece el contenedor
.PodName
Nombre del pod al que pertenece el contenedor
--last, -l
Muestre el último contenedor que se creó (con o sin -a).
--latest
Muestre el último contenedor creado (con o sin -a).
--no-trunc
No trunque la salida.
--pod
Incluir información sobre los pods a los que pertenecen los contenedores.
--size, -s
Mostrar el tamaño agregado de los archivos en la escritura del contenedor.
--sort key
Ordenar la salida. Las claves disponibles son:
createdat
Hora de creación
exitcode
Código de salida
id
ID
image
Imagen
names
Nombres
ports
Puertos
size
Tamaño
status
Estado
--namespace, --ns
Mostrar las particiones del kernel de los contenedores.
