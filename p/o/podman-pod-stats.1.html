NOMBRE

podman-pod-stats - Muestra un flujo en vivo de estadísticas de uso de recursos para contenedores en uno o más pods

SINOPSIS

podman pod stats [opciones] [pod]

DESCRIPCIÓN

Muestra un flujo en vivo de estadísticas de uso de recursos de contenedores en uno o más pods. La ejecución sin privilegios (rootless) solo se admite en cgroups v2.

OPCIONES

--all, -a

Muestra todos los contenedores. Solo se muestran los contenedores en ejecución de forma predeterminada.

--format=plantilla

Imprime estadísticas de contenedores en formato JSON o usando una plantilla de Go.

Los marcadores de posición válidos para la plantilla de Go se enumeran a continuación:

Marcador Descripción
.BlockIO Block IO
.CID ID del contenedor
.CPU Porcentaje de CPU
.Mem Porcentaje de memoria
.MemUsage Uso de memoria
.MemUsageBytes Uso de memoria (IEC)
.Name Nombre del contenedor
.NetIO Red IO
.PIDS Número de PIDs
.Pod ID del pod

Al usar una plantilla de Go, preceda el formato con table para imprimir encabezados.

--latest, -l

En lugar de proporcionar el nombre o ID del pod, utiliza el último pod creado. Nota: el último pod iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--no-reset

No borra la terminal/pantalla entre intervalos de informes.

--no-stream

Deshabilita la transmisión de estadísticas de pods y solo extrae el primer resultado, la configuración predeterminada es falsa.

EJEMPLOS

Lista estadísticas sobre todos los pods sin transmisión:

# podman pod stats -a --no-stream
ID             NOMBRE              CPU %   USO MEM / LÍMITE   % MEM   RED IO    BLOQUEO IO   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

Lista estadísticas sobre un pod especificado sin transmisión:

# podman pod stats --no-stream a9f80
ID             NOMBRE           CPU %   USO MEM / LÍMITE   % MEM   RED IO    BLOQUEO IO   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

Lista estadísticas sobre un pod especificado en formato JSON sin transmisión:

# podman pod stats --no-stream --format=json a9f80
[
    {
        "id": "a9f807ffaacd",
        "name": "frosty_hodgkin",
        "cpu_percent": "--",
        "mem_usage": "3.092MB / 16.7GB",
        "mem_percent": "0.02%",
        "netio": "-- / --",
        "blocki": "-- / --",
        "pids": "2"
    }
]

Lista estadísticas seleccionadas formateadas en una tabla sobre un pod especificado:

# podman pod stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NOMBRE           USO MEM / LÍMITE
6eae9e25a564   clever_bassi   3.031MB / 16.7GB
