postw32(1) Procesador posterior de ejecutables de 32 bits de Windows de FPC postw32(1)

NOMBRE

postw32 - Procesador posterior de ejecutables de 32 bits de Windows de Free Pascal.

SINOPSIS

postw32 [-vh] [-m subsystem] [-i archivo] [-V version] [-s tamano]

DESCRIPCIÓN

postw32 realiza un post-procesamiento en un archivo o biblioteca ejecutable de Windows de 32 bits. Puede establecer el subsistema de Windows, el tamaño de la pila y la versión del archivo.

USO

postw32 necesita al menos 2 opciones. Una es el nombre del archivo de entrada (opción -i) y la otra es una de las operaciones posibles, con sus argumentos.

OPCIONES

acepta las siguientes opciones en este momento:

-i archivo
especifica el archivo de entrada a procesar. Esta opción es una notación corta para la opción --input.
-h
Muestra un mensaje de ayuda corto. Esta opción es una notación corta para la opción --help.
-m subsistema
Establece el subsistema (el tipo de aplicación) en gui o console. Tenga en cuenta que una aplicación gui que escribe en la línea de comandos causará un error. Esta opción es una notación corta para la opción --subsystem.
-s tamano
Establece el tamaño de la pila en tamano bytes. Esta opción es una notación corta para la opción --stack.
-v
Sea detallado sobre las operaciones que se realizan. Esta opción es una notación corta para la opción --verbose.
-V M.N
Establece la versión del archivo a M.N, donde M y N son valores sin signo de 16 bits. Esta opción es una notación corta para la opción --version.
