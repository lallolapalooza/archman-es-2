NOMBRE

pong - Emulador de videojuego casero Pong

SINOPSIS

pong [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id number][--mono] [--install] [--visual visual] [--clock float] [--noise] [--fps]

DESCRIPCIÓN

El programa pong simula un antiguo videojuego casero Pong, así como varios artefactos de su visualización en un televisor en color.

OPCIONES

pong acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase de visual o el número de ID (decimal o hexadecimal) de un visual específico.
--clock
La puntuación del juego será la hora actual.
--noise float
Cuán ruidosa debe ser la señal de video (entre 0.0 y 4.0 aproximadamente).
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.
(-p1 | --p2) modo
Configura un jugador para que sea ai, mouse, tablet, kbleft (para W y S), o kbright (o simplemente kb, para las teclas de flecha).

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

RECURSOS X

Entre los recursos X notables soportados se incluyen los siguientes, que corresponden a los controles de TV estándar: analogTVTint, analogTVColor, analogTVBrightness y analogTVContrast. Varían de 0 a 100, excepto tint que es un ángulo entre -180 y +180.

MARCAS REGISTRADAS

Pong puede ser una marca registrada.
