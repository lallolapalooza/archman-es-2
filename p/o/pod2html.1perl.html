POD2HTML(1perl) Guía de referencia del programador de Perl POD2HTML(1perl)

NOMBRE

pod2html - convierte archivos .pod a archivos .html

SINOPSIS

pod2html --help --htmldir=<nombre> --htmlroot=<URL>
         --infile=<nombre> --outfile=<nombre>
         --podpath=<nombre>:...:<nombre> --podroot=<nombre>
         --cachedir=<nombre> --flush --recurse --norecurse
         --quiet --noquiet --verbose --noverbose
         --index --noindex --backlink --nobacklink
         --header --noheader --poderrors --nopoderrors
         --css=<URL> --title=<nombre>

DESCRIPCIÓN

Convierte archivos del formato pod (ver perlpod) al formato HTML.

ARGUMENTOS

pod2html acepta los siguientes argumentos:

backlink
--backlink
--nobacklink

Convierte las directivas =head1 en enlaces que apuntan a la parte superior del archivo HTML. --nobacklink (que es el comportamiento predeterminado) no crea estos enlaces de retroceso.

cachedir
--cachedir=nombre

Especifica qué directorio se utiliza para almacenar la caché. El directorio predeterminado es el directorio de trabajo actual.

css
--css=URL

Especifica la URL de la hoja de estilos en cascada para enlazar desde el archivo HTML resultante. El valor predeterminado es ninguna hoja de estilos.

flush
--flush

Vacía la caché.

header
--header
--noheader

Crea bloques de encabezado y pie de página que contienen el texto de la sección "NOMBRE". --noheader -- que es el comportamiento predeterminado -- no crea bloques de encabezado ni de pie de página.

help
--help

Muestra el mensaje de uso.

htmldir
--htmldir=nombre

Establece el directorio al que serán relativas todas las referencias cruzadas en el archivo HTML resultante. No pasar esto hace que todos los enlaces sean absolutos, ya que este es el valor que le dice a Pod::Html la raíz del árbol de documentación.

No uses esto y --htmlroot en la misma llamada a pod2html; son mutuamente excluyentes.

htmlroot
--htmlroot=URL

Establece la URL base para los archivos HTML. Cuando se hacen referencias cruzadas, la raíz HTML se antepone a la URL.

No uses esto si se desean enlaces relativos: usa --htmldir en su lugar.

No pases tanto este como --htmldir a pod2html; son mutuamente excluyentes.

index
--index

Genera un índice en la parte superior del archivo HTML (comportamiento predeterminado).

noindex
--noindex

No genera un índice en la parte superior del archivo HTML.

infile
--infile=nombre

Especifica el archivo pod a convertir. La entrada se toma de STDIN si no se especifica ningún archivo de entrada.

outfile
--outfile=nombre

Especifica el archivo HTML a crear. La salida va a STDOUT si no se especifica ningún archivo de salida.

poderrors
--poderrors
--nopoderrors

Incluye una sección "ERRORES DE POD" en el archivo de salida si hubo algún error de POD en el archivo de entrada (comportamiento predeterminado). --nopoderrors no crea esta sección "ERRORES DE POD".

podpath
--podpath=nombre:...:nombre

Especifica qué subdirectorios de podroot contienen archivos pod cuyos formularios convertidos a HTML se pueden enlazar en referencias cruzadas.

podroot
--podroot=nombre

Especifica el directorio base para encontrar pods de biblioteca.

quiet
--quiet
--noquiet

No muestres mensajes de advertencia mayormente inofensivos. --noquiet -- que es el comportamiento predeterminado -- sí muestra estos mensajes de advertencia mayormente inofensivos (pero esto no es lo mismo que el modo "verbose").

recurse
--recurse
--norecurse

Recorre recursivamente los subdirectorios especificados en podpath (comportamiento predeterminado). --norecurse no recorre recursivamente estos subdirectorios.

title
--title=título

Especifica el título del archivo HTML resultante.

verbose
--verbose
--noverbose

Muestra mensajes de progreso. --noverbose -- que es el comportamiento predeterminado -- no muestra estos mensajes de progreso.
