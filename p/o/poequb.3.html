CPOEQUB

Propósito:

!>
!> CPOEQUB calcula escalados de fila y columna destinados a equilibrar una
!> matriz Hermitiana definida positiva A y reducir su número de condición
!> (con respecto a la norma dos). S contiene los factores de escala,
!> S(i) = 1/sqrt(A(i,i)), elegidos de tal manera que la matriz escalada B con
!> elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal. Esta
!> elección de S pone el número de condición de B dentro de un factor N del
!> menor número de condición posible sobre todos los escalados diagonales
!> posibles.
!>
!> Esta rutina difiere de CPOEQU al restringir los factores de escala
!> a una potencia de la base. Salvo por desbordamiento superior e inferior,
!> el escalado por estos factores no introduce errores de redondeo adicionales.
!> Sin embargo, las entradas diagonales escaladas ya no son aproximadamente 1
!> sino que se encuentran entre sqrt(base) y 1/sqrt(base).
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz Hermitiana definida positiva N-por-N cuyos factores
!>          de escala se van a calcular. Solo se referencian los elementos
!>          diagonales de A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

S

!>          S es un array REAL, dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación del S(i) más pequeño con
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no vale la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está muy
!>          cerca del desbordamiento o muy cerca de la subdesbordamiento,
!>          la matriz debe escalarse.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i tuvo un valor ilegal
!>          > 0:  si INFO = i, el elemento diagonal i no es positivo.
!>

Detailed Description

POEQUB computes row and column scalings intended to equilibrate a Hermitian positive definite matrix A and reduce its condition number (with respect to the two-norm). S contains the scale factors, S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.

This routine differs from POEQU by restricting the scaling factors to a power of the radix. Barring over- and underflow, scaling by these factors introduces no additional rounding errors. However, the scaled diagonal entries are no longer approximately 1 but lie between sqrt(radix) and 1/sqrt(radix).

subroutine poequb (integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

POEQUB

Purpose:

!>
!> POEQUB computes row and column scalings intended to equilibrate a
!> Hermitian positive definite matrix A and reduce its condition number
!> (with respect to the two-norm).  S contains the scale factors,
!> S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with
!> elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal.  This
!> choice of S puts the condition number of B within a factor N of the
!> smallest possible condition number over all possible diagonal
!> scalings.
!>
!> This routine differs from POEQU by restricting the scaling factors
!> to a power of the radix.  Barring over- and underflow, scaling by
!> these factors introduces no additional rounding errors.  However, the
!> scaled diagonal entries are no longer approximately 1 but lie
!> between sqrt(radix) and 1/sqrt(radix).
!>

Parameters

N 
!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          The N-by-N Hermitian positive definite matrix whose scaling
!>          factors are to be computed.  Only the diagonal elements of A
!>          are referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

S

!>          S is REAL array, dimension (N)
!>          If INFO = 0, S contains the scale factors for A.
!>

SCOND

!>          SCOND is REAL
!>          If INFO = 0, S contains the ratio of the smallest S(i) to
!>          the largest S(i).  If SCOND >= 0.1 and AMAX is neither too
!>          large nor too small, it is not worth scaling by S.
!>

AMAX

!>          AMAX is REAL
!>          Absolute value of largest matrix element.  If AMAX is very
!>          close to overflow or very close to underflow, the matrix
!>          should be scaled.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element is nonpositive.
!>
