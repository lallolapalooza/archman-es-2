NOMBRE

podman image tree - Imprime la jerarquía de capas de una imagen en formato de árbol

SINOPSIS

podman image tree [opciones] imagen:etiqueta|id-imagen

DESCRIPCIÓN

Imprime la jerarquía de capas de una imagen en formato de árbol. Si no se proporciona una etiqueta, Podman utiliza latest por defecto para la imagen. Las capas se indican con etiquetas de imagen como Capa superior de, cuando la etiqueta se conoce localmente.

OPCIONES

--help, -h

Imprime el aviso de uso

--whatrequires

Muestra todas las imágenes secundarias y capas de la imagen especificada
