NOMBRE

povray - POV-Ray: The Persistence of Vision Ray Tracer

SINOPSIS

povray [+Oarchivo_salida] [+/-opción ...] [archivo_entrada]

povray [+Iarchivo_entrada] [+Oarchivo_salida] [+/-opción ...] [archivo_INI]

DESCRIPCIÓN

POV-Ray es un trazador de rayos gratuito y con todas las funciones, escrito y mantenido por un equipo de voluntarios en Internet. En la plataforma UNIX POV-Ray se puede compilar con soporte para capacidades de previsualización utilizando el sistema de ventanas X Window.

Esta página del manual solo enumera las características básicas de POV-Ray y las específicas de UNIX, así como las opciones de línea de comandos para esta versión de POV-Ray. Para una descripción completa de las características de POV-Ray y su lenguaje de descripción de escenas (también conocido como POV-Ray SDL), o para una mejor explicación del significado de las opciones de línea de comandos y archivos INI, consulte la documentación que debería acompañar a todas las versiones de POV-Ray. La documentación está instalada en PREFIX/share/doc/povray-3.7, donde PREFIX es /usr/local por defecto, o una ruta especificada al configurar el paquete fuente para compilar e instalar.

Algunas de las características específicas de UNIX son:

El soporte para la pantalla de X Window utiliza automáticamente la mejor clase visual y la mayor profundidad disponible. Para visualizaciones que no admiten 24 bits de color por píxel, se utiliza el tramado de difusión de errores de Floyd-Steinberg, junto con una paleta optimizada y asignada dinámicamente para producir la mejor pantalla posible con la visualización, profundidad y mapa de colores disponibles actuales.
El cumplimiento de ICCCM para la versión de X Window significa que la ventana de previsualización se comportará como los programas estándar de X Window, se comunicará correctamente con el gestor de ventanas y aceptará las opciones de línea de comandos estándar. Consulte X(1) para más información.
Los gráficos ASCII en la versión de modo de texto permiten una vista básica de la renderización actual en terminales de solo texto.
Un manejador de interrupciones permite interrumpir la renderización de forma segura, de modo que cualquier dato que no se haya escrito actualmente en disco se guardará antes de salir. Control-C o SIGINT provocarán una interrupción por parte del usuario y guardarán la renderización actual, antes de salir. Consulte kill(1) para más información.
La renderización independiente de la plataforma y la arquitectura significa que la misma escena se renderizará de la misma manera en todas las computadoras y sistemas operativos (con la excepción de la velocidad de renderización, por supuesto).

OPCIONES

Las opciones se pueden especificar con un '+' o un '-' inicial. Muchas opciones son conmutadores, lo que significa que un '+' activa la opción y un '-' la desactiva. Para otras opciones, no importa si se usa un '+' o un '-'. La mayoría de las opciones no pueden tener espacios, por lo que debe especificar +FN en lugar de +F N, y la combinación de opciones no está permitida, por lo que +SC es muy diferente de +S +C. Las opciones no distinguen entre mayúsculas y minúsculas.

Las opciones de línea de comandos se muestran a continuación con sus opciones correspondientes en archivos INI. Si la misma opción se especifica múltiples veces, ya sea en archivos INI o en la línea de comandos, la última opción de este tipo anula las anteriores, con la excepción de la opción +L o Library_Path, que es acumulativa.

Opciones de análisis:

I<nombre_archivo_entrada> o Input_File_Name=archivo
Especifica el archivo de entrada a utilizar. Si el nombre del archivo de entrada es '-', la descripción de la escena se leerá de la entrada estándar. El
HI<nombre_archivo_inclusión_cabecera> o Include_Header=archivo
Especifica un archivo como el primer archivo de inclusión de un archivo de escena. Esto se puede usar para incluir siempre un conjunto específico de archivos de inclusión predeterminados utilizados por todas sus escenas.
L<ruta_biblioteca> o Library_Path=ruta
Especifica un directorio para buscar archivos de entrada, archivos de inclusión, fuentes y mapas de imágenes, si el archivo especificado no está en el directorio actual. Esto puede especificarse varias veces para aumentar el número de directorios a buscar.
MVn.n o Version=flotante
Tratar los archivos de escena como si fueran de la versión n.n en lugar de la versión actual. Esto puede ser anulado desde dentro del archivo de escena.
SU o Split_Unions=booleano
Dividir uniones CSG delimitadas si los hijos son finitos. Esto permite la delimitación automática de objetos CSG.
UR o Remove_Bounds=booleano
Eliminar objetos de delimitación innecesarios. Esto permite la delimitación automática de archivos de escena antiguos.
BM1 o Bounding_Method=1
Habilitar la delimitación BVH (Jerarquía de Volumen Delimitador) (por defecto).
BM2 o Bounding_Method=2
Habilitar la delimitación de árbol BSP (Partición Binaria de Espacio).

Opciones de salida:

Hn o Height=entero
La imagen debe tener n píxeles de alto.
Wn o Width=entero
La imagen debe tener n píxeles de ancho.
SRn o Start_Row=entero
Comenzar la renderización en la fila n desde la parte superior de la pantalla.
SR0.n o Start_Row=flotante
Comenzar la renderización n por ciento desde la parte superior de la pantalla.
ERn o End_Row=entero
Finalizar la renderización en la fila n desde la parte superior de la pantalla.
ER0.n o End_Row=flotante
Finalizar la renderización al n por ciento desde la parte superior de la pantalla.
SCn o Start_Column=entero
Comenzar la renderización en la columna n desde la izquierda de la pantalla.
SC0.n o Start_Column=flotante
Comenzar la renderización al n por ciento desde la izquierda de la pantalla.
ECn o Start_Column=entero
Finalizar la renderización en la columna n desde la izquierda de la pantalla.
EC0.n o Start_Column=flotante
Finalizar la renderización al n por ciento desde la izquierda de la pantalla.
C o Continue_Trace=booleano
Continuar un trazado previamente interrumpido.
P o Pause_When_Done=booleano
Si se está previsualizando, pausar cuando la renderización esté completa antes de cerrar la ventana.
V o Verbose=booleano
Mostrar mensajes de estado detallados sobre el progreso de la renderización.
WLn o Warning_Level=entero
Establecer el nivel de advertencia en n.
X o Test_Abort=booleano
Habilitar las teclas 'q' y 'Q' para interrumpir una renderización en curso.
Xn o Test_Abort_Count=entero
Solo comprobar cada n píxeles para una interrupción del usuario.

Opciones de salida - relacionadas con la visualización:

D[0][GHT] o Display=booleano Palette=carácter
Mostrar la renderización en progreso, especificando opcionalmente la paleta. La única opción de paleta válida para X Window es G, que fuerza la previsualización en escala de grises. La paleta de X Window se basa en la visualización utilizada, ya sea seleccionada automáticamente por POV-Ray o especificada.

OPTIONS

The following command-line options are recognized by POV-Ray for UNIX.

Display options:

In or Display_N=integer
Use display type n. Type 0 is the default, using the appropriate display for the platform, and type 1 renders using the POV-Ray preview window.
MP or Display_Monitor_Palette=bool
Use the monitor's palette for rendering. This is normally used when rendering to the POV-Ray preview window or when rendering a palette file.
WPn or Display_Window_Palette=integer
Use palette n for the preview window. The value of n can range from 0 to 255. Note that the palette must be set before the display type is set. The palette is ignored when outputting to a file or when using POV-Ray's display type 0. Note also that the palette is ignored in the UNIX version when rendering to the POV-Ray preview window via the -visual option or via the -visual option. To specify the palette, you must first specify the display type (the second character, shown here as '0') for compatibility reasons, even though it is ignored in UNIX versions.
SPn or Preview_Start_Size=integer
Start mosaic preview with blocks n pixels square.
EPn or Preview_End_Size=integer
End mosaic preview with blocks n pixels square.
UD or Draw_Vistas=bool
Draw vista rectangles before rendering has been deprecated.

Output options - file related:

F[CEHJNPST][n] or Output_to_File=bool Output_File_Type=char
Store the rendered image using one of the available formats, namely Compressed TGA, OpenEXR, Radiance High Dynamic-Range, JPEG, PNG, PPM, System specific (PNG) and TGA.
O<output_file> or Output_File_Name=file
Write the output to the file named output_file, or the standard output if '-' is given as the output file name.
MIn or Max_Image_Buffer_Memory=n
Sets the allowable size of the output image cache in megabytes.

Tracing options:

MBn or Bounding=bool Bounding_Threshold=integer
Use automatic bounding slabs if more than n objects are in the scene.
Qn or Quality=integer
Render at quality n. Qualities range from 0 for rough images and 9 for complete ray-tracing and textures, and 10 and 11 add radiosity.
A0.n or Antialias=bool Antialias_Threshold=integer
Do antialiasing on the pixels until the difference between adjacent pixels is less that 0.n, or the maximum recursion depth is reached.
AMn or Sampling_Method=integer
Specify the method of antialiasing used, non-adaptive (n = 1), or adaptive antialiasing (n = 2).
Jn.n or Jitter=bool Jitter_Amount=float
Specify maximum radius, in pixels, that antialiased samples should be jittered from their true centers.
Rn or Antialias_Depth=integer
Set the maximum recursion depth for antialiased pixel sub-sampling.
UA or Output_Alpha=bool
Use alpha channel for transparency mask.
UL or Light_Buffer=bool
Use light buffer to speed up rendering has been deprecated.
UV or Vista_Buffer=bool
Use vista buffer to speed up rendering has been deprecated.

Animation options:

Kn.n or Clock=float
Render a single frame of an animation with the clock value n.n.
KFIn or Initial_Frame=integer
Specify the initial frame number for an animation.
KFFn or Final_Frame=integer
Specify the final frame number for an animation. This must be set at a value other that 1 in order to render multiple frames at once.
KIn.n or Initial_Clock=float
Specify the clock value for the initial frame of an animation.
KFn.n or Final_Clock=float
Specify the clock value for the frame final of an animation.
SFn or Subset_Start_Frame=integer
Render a subset of frames from an animation, starting at frame n.
SF0.n or Subset_Start_Frame=float
Render a subset of frames from an animation, starting n percent into the animation.
EFn or Subset_End_Frame=integer
Render a subset of frames from an animation, stopping at frame n.
EF0.n or Subset_End_Frame=float
Render a subset of frames from an animation, stopping n percent into the animation.
KC or Cyclic_Animation=bool
Generate clock values for a cyclic animation.
UF or Field_Render=bool
Render alternate frames using odd/even fields, suitable for interlaced output.
UO or Odd_Field=bool
Start a field rendered animation on the odd field, rather than the even field.

Redirecting options:

GI<name> or Create_Ini=bool or Create_Ini=file
Write all INI parameters to a file named after the input scene file, or one with the specified name.
G[ADFRSW]<name> or <Stream>_File=bool or <Stream>_File=file
Write the stream to the console and/or the specified file. The streams are All_File (except status), Debug_File, Fatal_File, Render_File, Statistics_File, and the Warning_File.

X Window System options:

In addition to the standard command-line options, POV-Ray recognizes additional command-line switches related to the X Window System. See X(1) for a complete description of these options.

-display <display_name>
Display preview on display_name rather than the default display. This is meant to be used to change the display to a remote host. The normal dispay option +d is still valid.
-geometry [WIDTHxHEIGHT][+XOFF+YOFF]
Render the image with WIDTH and HEIGHT as the dimensions, and locate the window XOFF from the left edge, and YOFF from the top edge of the screen (or if negative the right and bottom edges respectively). The WIDTH and HEIGHT, if given, override any previous Wn and Hn settings.
-help
Display the X Window System-specific options. Use -H by itself on the command-line to output the general POV-Ray options.
-icon
Start the preview window as an icon.
-title <window_title>
Override the default preview window title with window_title.
-visual <visual_type>
Use the deepest visual of visual_type, if available, instead of the automatically selected visual. Valid visuals are StaticGray, GrayScale, StaticColor, PseudoColor, TrueColor, or DirectColor.

RESOURCES

Currently no X resource or app-default files are supported for the X Window options.

FILES

POV-Ray for UNIX allows a povray.ini file in the current directory to override the individual setting in $HOME/.povray/3.7/povray.ini. POV-Ray looks for initial configuration information, like the Library_Path settings, which gives the location for the standard include files, first in the environment variable $POVINI, then in ./povray.ini, then in $HOME/.povray/3.7/povray.ini, then in PREFIX/etc/povray/3.7/povray.ini. The PREFIX directory can be changed at compile-time using the --prefix option of the configure script. For backward compatibility with POV-Ray version 3.5 and earlier, the $HOME/.povrayrc and $PREFIX/etc/povray.ini files are also searched for when none of the above files were found.

Since version 3.5 POV-Ray features an I/O Restriction mechanism. I/O Restrictions attempt to at least partially protect a machine running POV-Ray from having files read or written outside of a given set of directories. The settings are defined in two configuration files, a system-level PREFIX/etc/povray/3.7/povray.conf file and an user-level $HOME/.povray/3.7/povray.conf file with more restrictive settings. As of POV-Ray 3.6 the format of these configuration files has changed, and no backward compatibility is retained with the configuration files in POV-Ray 3.5. See the documentation for further details and examples of I/O Restriction settings.

povlegal.doc should accompany all installations of POV-Ray, and outlines specific conditions and restrictions on the POV-Ray software. A condition of povlegal.doc requires that documentation, INI and scene files be available to all users of POV-Ray. Scene and INI files are typically installed in PREFIX/share/povray-3.7,
