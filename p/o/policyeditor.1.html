policyeditor(1) Manual de Comandos Generales policyeditor(1)

NOMBRE

policyeditor - ver y modificar la configuración de seguridad para javaws y el plugin del navegador

SINOPSIS

policyeditor
policyeditor [-file] archivo_politica

DESCRIPCIÓN

policyeditor es una aplicación GUI con un pequeño soporte de línea de comandos para ver y editar la configuración de políticas de seguridad de applets utilizada por la implementación IcedTea-Web de javaws y el plugin del navegador. Está pensada como una alternativa más simple, fácil de usar y más accesible a la herramienta estándar JDK Policy Tool. Los administradores y usuarios avanzados que necesiten un control detallado sobre los archivos de política probablemente deberían usar Policy Tool en lugar de PolicyEditor.

Si se ejecuta sin argumentos, no se abre ningún archivo y al guardar el archivo se le pedirá dónde guardarlo. De lo contrario, si se proporciona una ruta de archivo como argumento de línea de comandos, esa ruta de archivo se abrirá y se analizará como un archivo de política.

OPCIONES

-codebase url
Especifica una URL de codebase de applet. Esto se puede usar con las otras opciones de selector para seleccionar una entrada de política al abrir el editor; si no existe tal identificador, se creará y luego se seleccionará. (Se espera exactamente un argumento)
-defaultfile
Especifica que se debe abrir el archivo de política predeterminado a nivel de usuario. Este es el archivo que normalmente utiliza IcedTea-Web para tomar decisiones sobre políticas y permisos personalizados para applets en tiempo de ejecución, a menos que se configure de otra manera. (No se espera argumento)
-file archivo_politica
Especifica una ruta de archivo de política para abrir. Si se proporciona exactamente un argumento, y no es esta bandera, se interpreta como una ruta de archivo para abrir, como si esta bandera se hubiera dado primero. Esta bandera existe principalmente para la compatibilidad con Policy Tool. (Se espera exactamente un argumento)
-help
Muestra información sobre los comandos compatibles y el uso básico. (No se espera argumento)
-principals nombre_clase nombre_principal
Especifica pares de nombre de clase/nombre de principal (separados por espacios) para el identificador de la entrada de política. Esto se puede usar con las otras opciones de selector para seleccionar una entrada de política al abrir el editor; si no existe tal identificador, se creará y luego se seleccionará. (Se espera un número par de argumentos con el formato param=valor como argumento válido)
-signedby alias_certificado
Especifica un alias de certificado para un certificado almacenado en el almacén de claves. Esto se puede usar con las otras opciones de selector para seleccionar una entrada de política al abrir el editor; si no existe tal identificador, se creará y luego se seleccionará. (Se espera exactamente un argumento)
-verbose
Habilita la salida detallada. (No se espera argumento)

EJEMPLOS

policyeditor
Muestra el editor GUI sin ningún archivo abierto.
policyeditor -file $XDG_CONFIG_HOME/icedtea-web/security/java.policy
Muestra la GUI y abre el archivo de política predeterminado.

ARCHIVOS

$XDG_CACHE_HOME/icedtea-web/cache/recently_used
Información adicional sobre los elementos en la caché
$XDG_CONFIG_HOME/icedtea-web/security/java.policy
Contiene los permisos concedidos para aplicaciones sin firmar seleccionadas. Controlado por deployment.user.security.policy

Donde $XDG_CONFIG_DIR, $XDG_CACHE_DIR y $XDG_RUNTIME_DIR se establecen como ~/.config, ~/.cache y /tmp o /var/tmp si no están definidos.

policyeditor(1)

NOMBRE

policyeditor - Editor de políticas de seguridad para Java

SINOPSIS

policyeditor [opciones] [archivo]

DESCRIPCIÓN

El policyeditor es una herramienta gráfica que permite modificar las políticas de seguridad de Java para aplicaciones de plugin de navegador. Permite a los usuarios otorgar o denegar permisos específicos a aplicaciones basándose en su código fuente (origin), su principal (principal) o su firma (signed by).

OPCIONES

No hay opciones específicas descritas para policyeditor en la documentación disponible.

EJEMPLOS

Para abrir el editor de políticas de seguridad:

policyeditor

Para abrir el editor y cargar una política de seguridad desde un archivo específico:

policyeditor /ruta/a/tu/archivo/java.policy

ARCHIVOS

~/.java.policy
Archivo de políticas de seguridad predeterminado del usuario.

ERRORES

No se han reportado errores específicos en la documentación disponible.

AUTOR

El policyeditor es parte del proyecto IcedTea-Web, que es una implementación de código abierto de las especificaciones Java Web Start y Java Network Protocol. Los autores principales y contribuidores se pueden encontrar en el sitio web del proyecto.
