NOMBRE

podman-machine-cp - Copia de forma segura contenido entre el host y la máquina virtual

SINOPSIS

podman machine cp [opciones] ruta_origen ruta_destino

DESCRIPCIÓN

Utiliza la copia segura (scp) para copiar archivos o directorios entre la máquina virtual y tu máquina host.

podman machine cp no admite la copia entre dos máquinas virtuales, lo que requeriría dos máquinas ejecutándose simultáneamente.

Además, podman machine cp realizará automáticamente una copia recursiva de archivos y directorios.

OPCIONES

--help

Imprime el aviso de uso.

--quiet, -q

Suprime la salida del estado de la copia.

EJEMPLOS

Copia un archivo desde tu host a la Máquina Podman en ejecución.

$ podman machine cp ~/configuration.txt podman-machine-default:~/configuration.txt
...
Copia Exitosa

Copia un archivo desde la Máquina Podman en ejecución a tu host.

$ podman machine cp podman-machine-default:~/logs/log.txt ~/logs/podman-machine-default.txt
...
Copia Exitosa

Copia un directorio desde tu host a la Máquina Podman en ejecución.

$ podman machine cp ~/.config podman-machine-default:~/.config
...
Copia Exitosa

Copia un directorio desde la Máquina Podman en ejecución a tu host.

$ podman machine cp podman-machine-default:~/.config ~/podman-machine-default.config
...
Copia Exitosa

VER TAMBIÉN

podman(1), podman-machine(1)
