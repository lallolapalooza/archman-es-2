NOMBRE

podman-wait - Espera a que uno o varios contenedores se detengan e imprime sus códigos de salida

SINOPSIS

podman wait [opciones] contenedor [...]

podman container wait [opciones] contenedor [...]

DESCRIPCIÓN

Espera a que uno o varios contenedores se detengan. El contenedor puede ser referenciado por su nombre o ID. En el caso de múltiples contenedores, Podman espera por cada uno de ellos consecutivamente. Una vez que todas las condiciones se cumplen, se imprimen los códigos de retorno de los contenedores separados por saltos de línea, en el mismo orden en que se proporcionaron al comando. Se emite un código de salida de -1 para todas las condiciones distintas de "detenido" (stopped) y "salido" (exited).

Al esperar contenedores con una política de reinicio de always (siempre) o on-failure (si falla), como los creados por podman kube play, los contenedores pueden salir y reiniciarse repetidamente, posiblemente con códigos de salida diferentes. podman wait solo mostrará y detectará la primera salida después de que se inició el comando de espera.

Al ejecutar un contenedor con podman run --rm, wait no espera a que el contenedor se elimine por completo. Para esperar la eliminación de un contenedor, usa --condition=removing.

OPCIONES

--condition=estado

Estado o condición del contenedor a esperar. Puede especificarse múltiples veces, donde al menos una condición debe coincidir para que el comando retorne. Los valores soportados son "configured" (configurado), "created" (creado), "exited" (salido), "healthy" (saludable), "initialized" (inicializado), "paused" (en pausa), "removing" (eliminando), "running" (en ejecución), "stopped" (detenido), "stopping" (deteniéndose), "unhealthy" (no saludable). La condición por defecto es "stopped".

--exit-first-match

Espera la salida del primer contenedor que coincida con las condiciones, ignora los demás.

--help, -h

Imprime el mensaje de uso

--ignore

Ignora los errores cuando un contenedor especificado no existe y marca su código de retorno como -1.

--interval, -i=duración

Intervalo de tiempo para esperar antes de consultar la finalización. Una cadena de duración es una secuencia de números decimales, cada uno con una fracción opcional y un sufijo de unidad, como "300ms", "-1.5h" o "2h45m". Las unidades de tiempo válidas son "ns", "us" (o "µs"), "ms", "s", "m", "h". La unidad de tiempo por defecto es "ms".

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

EJEMPLOS

Espera a que el contenedor especificado se detenga.

$ podman wait mywebserver
0

Espera a que el último contenedor se detenga. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman wait --latest
0

Espera a que el contenedor se detenga, comprobando cada dos segundos.

$ podman wait --interval 2s mywebserver
0

Espera al contenedor por ID. Este contenedor sale con código de error 1:

$ podman wait 860a4b23
1

Espera a que ambos contenedores especificados se detengan.

$ podman wait mywebserver myftpserver
0
125

Espera a que el contenedor con nombre se detenga, pero no falle si el contenedor no existe.

$ podman wait --ignore does-not-exist
-1
