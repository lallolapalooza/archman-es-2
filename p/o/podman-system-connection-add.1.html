NOMBRE

podman-system-connection-add - Registrar destino para el servicio Podman

SINOPSIS

podman system connection add [opciones] nombre destino

DESCRIPCIÓN

Registra el destino ssh para el(los) servicio(s) podman remoto(s). El destino ssh se proporciona como uno de los siguientes:
- [usuario@]nombrehost[:puerto]
- ssh://[usuario@]nombrehost[:puerto]
- unix://ruta
- tcp://nombrehost:puerto

Se le pedirá al usuario la contraseña de inicio de sesión ssh remota o la frase de contraseña del archivo de clave, según sea necesario. Se admite ssh-agent si se está ejecutando.

OPCIONES

--default, -d

Convierte el nuevo destino en el predeterminado para este usuario. El predeterminado es false.

--identity=ruta

Ruta al archivo de identidad ssh. Si el archivo de identidad ha sido cifrado, Podman le pedirá al usuario la frase de contraseña. Si no se proporciona ningún archivo de identidad y no se especifica ningún usuario, Podman utilizará por defecto el usuario que ejecuta el comando podman. Podman solicitará la contraseña de inicio de sesión en el servidor remoto.

--port, -p=puerto

Puerto para el destino ssh. El valor predeterminado es 22.

--socket-path=ruta

Ruta al socket del dominio Unix del servicio Podman en el host de destino ssh.

--tls-ca=ruta

Ruta a un archivo PEM que contiene el paquete de autoridad de certificación para verificar el certificado del servidor.

--tls-cert=ruta

Ruta a un archivo PEM que contiene el certificado de cliente TLS para presentar al servidor. También se debe proporcionar --tls-key.

--tls-key=ruta

Ruta a un archivo PEM que contiene la clave privada que coincide con --tls-cert. También se debe proporcionar --tls-cert.

EJEMPLO

Añadir una conexión de sistema con nombre:

$ podman system connection add QA podman.example.com

Añadir una conexión de sistema usando datos SSH:

$ podman system connection add --identity ~/.ssh/dev_rsa production ssh://root@server.example.com:2222

Añadir una conexión de sistema con nombre a un socket de dominio Unix local:

$ podman system connection add testing unix:///run/podman/podman.sock

Añadir una conexión de sistema con nombre a un socket TCP local:

$ podman system connection add debug tcp://localhost:8080

Añadir una conexión con un puerto personalizado:

$ podman system connection add --port 2222 staging user@staging.example.com

Añadir una conexión con una ruta de socket personalizada:

$ podman system connection add --socket-path /run/user/1000/podman/podman.sock remote-user user@remote.example.com

Añadir una conexión y hacerla la predeterminada:

$ podman system connection add --default production root@prod.example.com

Añadir una conexión de sistema con nombre a un socket TCP remoto protegido con TLS:

$ podman system connection add secure-debug --tls-cert=tls.crt --tls-key=tls.key --tls-ca=ca.crt tcp://podman.example.com:8443
