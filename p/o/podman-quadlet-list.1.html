NOMBRE

podman-quadlet-list - Listar quadlets instalados

SINOPSIS

podman quadlet list [opciones]

DESCRIPCIÓN

Lista todos los Quadlets configurados para el usuario actual.

OPCIONES

--filter, -f=filtro

Filtrar la salida según las condiciones dadas.

El formato del argumento filtros es de la forma clave=valor. Si hay más de un filtro, pase múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros soportados:

Filtro Descripción
name Filtrar por nombre de quadlet.

--format=formato

Imprimir la salida en formato JSON o usando una plantilla Go (por defecto "{{range .}}{{.Name}}\t{{.UnitName}}\t{{.Path}}\t{{.Status}}\n{{end -}}")

Imprime los resultados con una plantilla Go.

Marcador Descripción
.App Nombre de la aplicación si Quadlet es parte de una aplicación
.Name Nombre del archivo Quadlet
.Path Ruta del archivo Quadlet en el disco
.Status Estado del Quadlet correspondiente a la unidad de systemd
.UnitName Nombre de la unidad de systemd correspondiente al quadlet

EJEMPLOS

Comando de lista simple

$ podman quadlet list
NOMBRE                            NOMBRE DE UNIDAD                   RUTA EN DISCO                                                      ESTADO      APLICACIÓN
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  No cargado
sample-quadlet.container        sample-quadlet.service        /home/user/.config/containers/systemd/sample-quadlet.container        No cargado

Filtrar lista por nombre.

$ podman quadlet list --filter 'name=test*'
NOMBRE                            NOMBRE DE UNIDAD                   RUTA EN DISCO                                                      ESTADO      APLICACIÓN
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  No cargado

Formatear la salida de la lista para un campo específico.

$ podman quadlet list --format '{{ .UnitName }}'
NOMBRE DE UNIDAD
test-service-quadlet.service
sample-quadlet.service
