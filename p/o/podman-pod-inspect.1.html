NOMBRE

podman-pod-inspect - Muestra información que describe un pod

SINOPSIS

podman pod inspect [opciones] pod ...

DESCRIPCIÓN

Muestra la configuración y el estado de un pod determinado. También muestra información sobre los contenedores que pertenecen al pod.

OPCIONES

--format, -f=formato

Cambia el formato de salida predeterminado. Puede ser de un tipo soportado como 'json' o una plantilla Go. Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.BlkioDeviceReadBps Lectura de dispositivo de I/O de bloque, en bytes/segundo
.BlkioDeviceWriteBps Lectura de dispositivo de I/O de bloque, en bytes/segundo
.BlkioWeight Peso de I/O de bloque
.BlkioWeightDevice Peso de dispositivo de I/O de bloque
.CgroupParent Padre del cgroup del pod
.CgroupPath Ruta del cgroup del pod
.Containers Contenedores del pod
.CPUPeriod Período de CPU
.CPUQuota Cuota de CPU
.CPUSetCPUs CPUs del conjunto de CPU
.CPUSetMems Memoria del conjunto de CPU
.CPUShares Compartidos de CPU
.CreateCgroup Si se creó el cgroup
.CreateCommand Comando de creación
.Created ... Hora en que se creó el pod
.CreateInfra Si se creó la infraestructura
.Devices Dispositivos
.ExitPolicy Política de salida
.Hostname Nombre de host del pod
.ID ID del pod
.InfraConfig ... Configuración de la infraestructura (contiene campos adicionales)
.InfraContainerID ID de la infraestructura del pod
.InspectPodData ... Estructura anidada, solo para expertos
.Labels ... Etiquetas del pod
.LockNumber Número del bloqueo Libpod del pod
.MemoryLimit Límite de memoria, en bytes
.MemorySwap Límite de intercambio de memoria, en bytes
.Mounts Montajes
.Name Nombre del pod
.Namespace Espacio de nombres
.NumContainers Número de contenedores en el pod
.RestartPolicy Política de reinicio del pod
.SecurityOpts Opciones de seguridad
.SharedNamespaces Espacios de nombres compartidos del pod
.State Estado del pod
.VolumesFrom Volúmenes desde

--latest, -l

En lugar de proporcionar el nombre o ID del pod, usa el último pod creado. Nota: el último pod iniciado puede pertenecer a otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

EJEMPLO

Inspeccionar el pod especificado:

$ podman pod inspect foobar
[
     {
         "Id": "3513ca70583dd7ef2bac83331350f6b6c47d7b4e526c908e49d89ebf720e4693",
         "Name": "foobar",
         "Labels": {},
         "CgroupParent": "/libpod_parent",
         "CreateCgroup": true,
         "Created": "2018-08-08T11:15:18.823115347-05:00"
         "State": "created",
         "Hostname": "",
         "SharedNamespaces": [
              "uts",
              "ipc",
              "net"
         ]
         "CreateInfra": false,
         "InfraContainerID": "1020dd70583dd7ff2bac83331350f6b6e007de0d026c908e49d89ebf891d4699"
         "CgroupPath": ""
         "Containers": [
              {
                   "id": "d53f8bf1e9730281264aac6e6586e327429f62c704abea4b6afb5d8a2b2c9f2c",
                   "state": "configured"
              }
         ]
     }
]

Mostrar solo el nombre y el estado del pod:

$ podman pod inspect --format "{{.Name}}\t{{.State}}" mypod
mypod	Running

Mostrar el ID del pod y el número de contenedores:

$ podman pod inspect mypod --format "Pod {{.Name}} ({{.ID}}) tiene {{.NumContainers}} contenedores"
Pod mypod (605f5f776e101a6e0ad11ea802cae25eabf299da77122f2963fa65dc6ccf6717) tiene 2 contenedores

Mostrar la hora de creación del pod y los espacios de nombres compartidos:

$ podman pod inspect mypod --format "Creado: {{.Created}}\nCompartido: {{.SharedNamespaces}}"
Creado: 2025-08-14 21:16:05.861363099 +0000 UTC
Compartido: [net uts ipc]

Mostrar los límites de recursos del pod:

$ podman pod inspect --format "Memoria: {{.MemoryLimit}}, Período de CPU: {{.CPUPeriod}}, Cuota de CPU: {{.CPUQuota}}" mypod
Memoria: 1073741824, Período de CPU: 100000, Cuota de CPU: 50000

Mostrar los IDs de los contenedores dentro del pod:

$ podman pod inspect --format "{{range .Containers}}{{.Id}}: {{.State}} {{end}}" mypod
e907f7902decca9d6b600b4d3cca9541d9b89dd726b2af7ad2eba05d2a97083f: running c5a53050a31aed71c55cb6a31b9564c69a1009f77750f3f0e8093bd98fcd8918: running
