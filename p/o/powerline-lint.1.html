NOMBRE

powerline-lint - Verificador de configuración de Powerline.

SINOPSIS

powerline-lint [-pRUTA]… [-d]

DESCRIPCIÓN

-p, --config-path RUTA
Rutas donde se debe verificar la configuración, en orden. Debe proporcionar todas las rutas necesarias para que powerline funcione; no se admite la verificación de configuración parcial (por ejemplo, solo anulaciones de usuario).
-d, --debug
Mostrar información adicional. Se utiliza para depurar el propio powerline-lint, no para depurar la configuración.
-h, --help
Mostrar la ayuda y salir.
