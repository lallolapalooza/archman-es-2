NOMBRE

podman-farm-create - Crear una nueva granja

SINOPSIS

podman farm create nombre [conexiones]

DESCRIPCIÓN

Crea una nueva granja con conexiones que Podman conoce y que fueron añadidas a través del comando podman system connection add.

Se puede crear una granja vacía sin añadirle ninguna conexión. Añada o elimine conexiones de una granja a través del comando podman farm update.

EJEMPLOS

Crea la granja especificada sin conexiones:

$ podman farm create farm2

Crea una granja con conexiones:

$ podman farm create farm1 f37 f38
