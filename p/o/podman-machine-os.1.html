NOMBRE

podman-machine-os - Gestiona el sistema operativo de una máquina virtual de Podman

SINOPSIS

podman machine os subcomando

DESCRIPCIÓN

podman machine os es un conjunto de subcomandos que gestionan el sistema operativo de una máquina virtual de Podman.

SUBCOMANDOS

Comando Página del Manual Descripción
apply podman-machine-os-apply(1) Aplica una imagen OCI al sistema operativo de una máquina Podman

VER TAMBIÉN

podman(1), podman-machine(1), podman-machine-os-apply(1)
