NOMBRE

podman-system-migrate - Migra contenedores existentes a una nueva versión de podman

SINOPSIS

podman system migrate [opciones]

DESCRIPCIÓN

podman system migrate migra los contenedores a la última versión de podman.

podman system migrate se encarga de migrar los contenedores existentes a la última versión de podman si es necesario algún cambio.

"Podman sin root utiliza un proceso de pausa para mantener vivos los espacios de nombres no privilegiados. Esto evita que cualquier cambio en los archivos /etc/subuid y /etc/subgid se propague a los contenedores sin root mientras el proceso de pausa se está ejecutando.

Para que estos cambios se propaguen, es necesario primero detener todos los contenedores en ejecución asociados con el usuario y también detener el proceso de pausa y eliminar su archivo pid. En lugar de hacerlo manualmente, se puede usar podman system migrate para detener tanto los contenedores en ejecución como el proceso de pausa. Los archivos /etc/subuid y /etc/subgid se pueden editar o cambiar con usermod para recrear el espacio de nombres de usuario con las asignaciones recién configuradas.

OPCIONES

--new-runtime=runtime

Establece un nuevo runtime OCI para todos los contenedores. Esto se puede usar después de una actualización del sistema que cambie el runtime OCI predeterminado para mover todos los contenedores al nuevo runtime. No hay garantías de que los contenedores sigan funcionando bajo el nuevo runtime, ya que algunos runtimes admiten diferentes opciones y configuraciones.

EJEMPLOS

Invocación normal

### No se espera ninguna salida de este comando.
$ podman system migrate

Migración a un nuevo runtime OCI (por ejemplo, de crun a runc)

### Crea un contenedor usando el runtime predeterminado actual (por ejemplo, crun)
$ podman create --name test-alpine alpine
### Confirma el runtime actual
$ podman container inspect test-alpine | grep OCIRuntime
          "OCIRuntime": "crun",
### Migra todos los contenedores para usar un nuevo runtime (por ejemplo, runc)
$ podman system migrate --new-runtime runc
### Verifica que el contenedor ahora usa el nuevo runtime
$ podman container inspect test-alpine | grep OCIRuntime
          "OCIRuntime": "runc",
