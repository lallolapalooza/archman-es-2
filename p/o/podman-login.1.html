NOMBRE

podman-login - Iniciar sesión en un registro de contenedores

SINOPSIS

podman login [opciones] [registro]

DESCRIPCIÓN

podman login inicia sesión en un servidor de registro especificado con el nombre de usuario y la contraseña correctos. Si no se especifica el registro, se utiliza el primer registro bajo [registries.search] de registries.conf. podman login lee el nombre de usuario y la contraseña de la entrada estándar (STDIN). El nombre de usuario y la contraseña también se pueden establecer utilizando las opciones username y password. La ruta del archivo de autenticación puede ser especificada por el usuario estableciendo la opción authfile. La ruta predeterminada para leer y escribir credenciales es ${XDG_RUNTIME_DIR}/containers/auth.json. Podman utiliza las credenciales existentes si el usuario no proporciona un nombre de usuario. Podman busca primero el nombre de usuario y la contraseña en ${XDG_RUNTIME_DIR}/containers/auth.json, si no son válidos, Podman utiliza las credenciales existentes que se encuentren en $HOME/.docker/config.json. Si esas credenciales no están presentes, Podman crea ${XDG_RUNTIME_DIR}/containers/auth.json (si el archivo no existe) y luego almacena el nombre de usuario y la contraseña de STDIN como una cadena codificada en base64 en él. Para más detalles sobre el formato y las configuraciones del archivo auth.json, consulte containers-auth.json(5)

podman [OPCIONES GLOBALES]

podman login [OPCIONES GLOBALES]

podman login [OPCIONES] [REGISTRO] [OPCIONES GLOBALES]

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux y $HOME/.config/containers/auth.json en Windows/macOS. El archivo es creado por podman login. Si el estado de autorización no se encuentra allí, se comprueba $HOME/.docker/config.json, que se establece utilizando docker login.

Nota: También existe la opción de anular la ruta predeterminada del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--cert-dir=ruta

Utilice los certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. (Predeterminado: /etc/containers/certs.d) Para más detalles, consulte containers-certs.d(5). (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--compat-auth-file=ruta

En lugar de actualizar el archivo de credenciales predeterminado, actualice el que se encuentra en ruta y utilice un formato compatible con Docker.

--get-login

Devuelve el usuario que ha iniciado sesión para el registro. Devuelve un error si no se encuentra ningún inicio de sesión.

--help, -h

Imprime el enunciado de uso

--password, -p=contraseña

Contraseña para el registro

--password-stdin

Toma la contraseña de stdin

--secret=nombre

Lee la contraseña para el registro del secreto de Podman nombre. Si no se especifica --username, se utiliza --username=nombre.

--tls-verify

Requiere HTTPS y verifica los certificados al contactar con los registros (predeterminado: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino esté listado como un registro no seguro en containers-registries.conf(5)

--username, -u=nombredeusuario

Nombre de usuario para el registro

--verbose, -v

Imprime información detallada sobre el almacén de credenciales

EJEMPLOS

Agrega credenciales de inicio de sesión para el registro especificado al archivo de autenticación predeterminado; tenga en cuenta que, a diferencia del valor predeterminado de docker, las credenciales predeterminadas se encuentran en $XDG_RUNTIME_DIR, que es un subdirectorio de /run (un directorio efímero) y, por lo tanto, no persisten después del reinicio.

$ podman login quay.io
Nombre de usuario: umohnani
Contraseña:
¡Inicio de sesión correcto!

Para conservar explícitamente las credenciales después del reinicio, deberá especificar la ruta persistente predeterminada:

$ podman login --authfile ~/.config/containers/auth.json quay.io
Nombre de usuario: umohnani
Contraseña:
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión utilizando el nombre de usuario y la contraseña especificados para el registro local al archivo de autenticación predeterminado.

$ podman login -u testuser -p testpassword localhost:5000
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para una ruta de archivo de autenticación alternativa para el registro especificado.

$ podman login --authfile authdir/myauths.json quay.io
Nombre de usuario: umohnani
Contraseña:
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión utilizando un secreto de Podman para la contraseña.

$ echo -n MiSecreto! | podman secret create secretname -
a0ad54df3c97cf89d5ca6193c
$ podman login --secret secretname -u testuser quay.io
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para el usuario test con contraseña test al registro localhost:5000 deshabilitando el requisito de verificación tls.

$ podman login --tls-verify=false -u test -p test localhost:5000
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para el usuario foo con contraseña bar al registro localhost:5000 utilizando el directorio de certificados /etc/containers/certs.d.

$ podman login --cert-dir /etc/containers/certs.d/ -u foo -p bar localhost:5000
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para los registros especificados al archivo de autenticación predeterminado para el usuario dado con información de contraseña proporcionada a través de stdin desde un archivo en disco.

$ podman login -u testuser  --password-stdin < testpassword.txt docker.io
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para el registro especificado al archivo de autenticación predeterminado para el usuario dado con información de contraseña proporcionada a través de stdin desde una tubería.

$ echo $testpassword | podman login -u testuser --password-stdin quay.io
¡Inicio de sesión correcto!

Agrega credenciales de inicio de sesión para el registro especificado al archivo de autenticación predeterminado en modo detallado.

$ podman login quay.io --verbose
Nombre de usuario: myusername
Contraseña:
Usado: /run/user/1000/containers/auth.json
¡Inicio de sesión correcto!
