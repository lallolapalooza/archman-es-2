popen(3) Manual de funciones de biblioteca popen(3)

NOMBRE

popen, pclose - conectar un flujo a un proceso o desde un proceso

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
FILE *popen(const char *comando, const char *tipo);
int pclose(FILE *flujo);
Requisitos de Macro de Prueba de Funcionalidad para glibc (ver feature_test_macros(7)):

popen(), pclose():

    _POSIX_C_SOURCE >= 2
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función popen() abre un proceso creando una tubería, haciendo fork e invocando el shell. Dado que una tubería es por definición unidireccional, el argumento tipo solo puede especificar lectura o escritura, no ambas; el flujo resultante es correspondiente de solo lectura o de solo escritura.

El argumento comando es un puntero a una cadena terminada en nulo que contiene una línea de comando de shell. Este comando se pasa a /bin/sh usando la opción -c; la interpretación, si la hay, la realiza el shell.

El argumento tipo es un puntero a una cadena terminada en nulo que debe contener la letra 'r' para leer o la letra 'w' para escribir. Desde glibc 2.9, este argumento puede incluir adicionalmente la letra 'e', que hace que la bandera de cierre al ejecutar (FD_CLOEXEC) se establezca en el descriptor de archivo subyacente; ver la descripción de la bandera O_CLOEXEC en open(2) para conocer las razones por las cuales esto puede ser útil.

El valor de retorno de popen() es un flujo de E/S estándar normal en todos los aspectos excepto que debe cerrarse con pclose() en lugar de fclose(3). Escribir en dicho flujo escribe en la entrada estándar del comando; la salida estándar del comando es la misma que la del proceso que llamó a popen(), a menos que esto sea alterado por el comando mismo. A la inversa, leer del flujo lee la salida estándar del comando, y la entrada estándar del comando es la misma que la del proceso que llamó a popen().

Tenga en cuenta que los flujos de salida de popen() se búferizan por bloques (block buffered) por defecto.

La función pclose() espera a que el proceso asociado termine y devuelve el estado de salida del comando como lo devuelve wait4(2).

VALOR DE RETORNO

popen(): en caso de éxito, devuelve un puntero a un flujo abierto que puede usarse para leer o escribir en la tubería; si las llamadas fork(2) o pipe(2) fallan, o si la función no puede asignar memoria, se devuelve NULL.

pclose(): en caso de éxito, devuelve el estado de salida del comando; si wait4(2) devuelve un error, o se detecta algún otro error, se devuelve -1.

En caso de fallo, ambas funciones establecen errno para indicar el error.

ERRORES

La función popen() no establece errno si falla la asignación de memoria. Si falla la llamada subyacente a fork(2) o pipe(2), se establece errno para indicar el error. Si el argumento tipo es inválido, y esta condición se detecta, se establece errno a EINVAL.

Si pclose() no puede obtener el estado del hijo, se establece errno a ECHILD.

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
popen (), pclose () Seguridad de hilos MT-Safe

VERSIÓNES

El valor 'e' para tipo es una extensión de Linux.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

ADVERTENCIAS

Lea atentamente las Advertencias en system(3).

ERRORES DE PROGRAMACIÓN

Dado que el búfer de entrada estándar de un comando abierto para lectura comparte su desplazamiento de búsqueda con el proceso que llamó a popen(), si el proceso original ha realizado una lectura en búfer, la posición de entrada del comando puede no ser la esperada. De manera similar, la salida de un comando abierto para escritura puede mezclarse con la del proceso original. Esto último puede evitarse llamando a fflush(3) antes de popen().

El fallo en la ejecución del shell es indistinguible del fallo del shell en la ejecución del comando, o de una salida inmediata del comando. La única pista es un estado de salida de 127.

VER TAMBIÉN

    popen(3) - Arch Linux Manual Pages

    NOMBRE

    popen, pclose - programa de ejecución de comandos

    SINOPSIS

    #include <stdio.h>

FILE *popen(const char *command, const char *type);
int pclose(FILE *stream);

    DESCRIPCIÓN

    La función popen() abre una tubería hacia o desde un programa, devolviendo un puntero de archivo FILE* que puede ser utilizado para escribir en el proceso de comando o leer de él, respectivamente. El argumento command es una cadena de caracteres que contiene el comando a ejecutar.

    El argumento type es una cadena de caracteres que contiene un solo carácter, o 'r' para leer del flujo del comando, o 'w' para escribir en el flujo del comando.

    Si el tipo es 'r', el flujo devuelto se conecta a la salida estándar (stdout) del comando. Si el tipo es 'w', el flujo devuelto se conecta a la entrada estándar (stdin) del comando.

    La función pclose() cierra el flujo que fue abierto por una llamada anterior a popen(). Devuelve el estado de terminación del proceso asociado al flujo. Si el valor devuelto por popen() es un puntero de archivo válido, pclose() espera a que el proceso asociado termine y devuelve su estado de terminación.

    Si el tipo de popen() fue 'r', el valor devuelto por pclose() es el estado de terminación del comando. Si el tipo de popen() fue 'w', el valor devuelto por pclose() es el estado de terminación del comando.

    Si ocurre un error al iniciar el comando, popen() devuelve NULL y errno se establece apropiadamente.

    Si el tipo de popen() es 'r', el valor de retorno de pclose() es -1 y errno se establece si el comando no pudo ser ejecutado o si el flujo no pudo ser cerrado.

    Si el tipo de popen() es 'w', el valor de retorno de pclose() es -1 y errno se establece si el flujo no pudo ser cerrado.

    VALOR DE RETORNO

    Ver las descripciones de popen() y pclose().

    ERRORES

    Los siguientes valores pueden establecerse en errno:

    ECHILD
    No se pudo esperar al proceso hijo.
    EINVAL
    El tipo no es 'r' ni 'w'.
    ENOMEM
    No hay suficiente memoria para crear el proceso hijo.
    ENOSPC
    No hay espacio para crear el proceso hijo.
    EPIPE
    La tubería está rota.

    CONFORMIDAD

    POSIX.1-2001, POSIX.1-2008.

    VER TAMBIÉN

    fork(2), exec(3), pipe(2), signal(7)
