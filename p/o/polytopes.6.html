NOMBRE

polytopes - Dibuja uno de los seis politopos regulares 4D rotando en 4D.

SINOPSIS

polytopes [--display host:display.screen] [--install] [--visual visual] [--window] [--root] [--window-id número] [--delay usecs] [--fps] [-5-cell] [-8-cell] [-16-cell] [-24-cell] [-120-cell] [-600-cell] [--wireframe] [--surface] [--transparent] [--single-color] [--depth-colors] [--perspective-3d] [--orthographic-3d] [--perspective-4d] [--orthographic-4d] [--speed-wx float] [--speed-wy float] [--speed-wz float] [--speed-xy float] [--speed-xz float] [--speed-yz float]

DESCRIPCIÓN

El programa polytopes muestra uno de los seis politopos regulares 4D (5-celda, 8-celda, 16-celda, 24-celda, 120-celda o 600-celda) rotando en 4D. El programa proyecta el politopo 4D a 3D utilizando una proyección perspectiva u ortográfica. El politopo 3D proyectado puede ser proyectado a la pantalla de forma perspectiva u ortográfica. Hay tres modos de visualización para el politopo: malla (alámbrica), sólido o transparente. Además, los colores con los que se dibuja el politopo pueden ser de color único o coloreados según la "profundidad" 4D (la coordenada w) del politopo en su posición sin rotar. En el primer caso, el politopo se dibuja en rojo. Este coloreado combinado con transparencia da un bonito efecto visual de la estructura del politopo. El segundo modo dibuja el politopo con una rueda de colores completamente saturada en la que los bordes o las caras se colorean según su "profundidad" 4D promedio. Este modo se combina mejor con el modo de malla, donde permite ver cómo diferentes partes del politopo se mueven al "interior" del politopo proyectado en 3D. Por supuesto, en 4D, las celdas, caras y bordes del politopo tienen todos la misma distancia del centro del politopo. Solo la proyección crea la apariencia de que algunas de las celdas se encuentran "dentro" de la figura en 3D.

OPCIONES

polytopes acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número ID (decimal o hexadecimal) de un visual específico.
--delay microsegundos
Cuánto retardo se introduce entre pasos de la animación. Por defecto 25000, o 1/40 de segundo.

Las siguientes seis opciones son mutuamente excluyentes. Determinan qué politopo se muestra.

-5-cell
Muestra la 5-celda. La 5-celda es el análogo 4D de un tetraedro regular en 3D. Tiene 5 tetraedros regulares como celdas, 10 triángulos equiláteros como caras, 10 aristas y 5 vértices.
-8-cell
Muestra la 8-celda (también conocida como hipercubo o teseracto). La 8-celda es el análogo 4D de un cubo en 3D. Tiene 8 cubos como celdas, 24 cuadrados como caras, 32 aristas y 16 vértices.
-16-cell
Muestra la 16-celda. La 16-celda es el análogo 4D de un octaedro en 3D. Tiene 16 tetraedros regulares como celdas, 32 triángulos equiláteros como caras, 24 aristas y 8 vértices.
-24-cell
Muestra la 24-celda. La 24-celda no tiene análogo 3D. Tiene 24 octaedros regulares como celdas, 96 triángulos equiláteros como caras, 96 aristas y 24 vértices.
-120-cell
Muestra la 120-celda. La 120-celda no tiene análogo 3D. Tiene 120 dodecaedros regulares como celdas, 720 pentágonos regulares como caras, 1200 aristas y 600 vértices.
-600-cell
Muestra la 600-celda. La 600-celda no tiene análogo 3D. Tiene 600 tetraedros regulares como celdas, 1200 triángulos equiláteros como caras, 720 aristas y 120 vértices.

Las siguientes tres opciones son mutuamente excluyentes. Determinan cómo se muestra el politopo.

--wireframe
Muestra el politopo como una malla alámbrica.
--surface
Muestra el politopo como un objeto sólido.
--transparent
Muestra el politopo como un objeto transparente (por defecto).

Las siguientes dos opciones son mutuamente excluyentes. Determinan cómo se colorean los politopos.

--single-color
Muestra el politopo en rojo.
--depth-colors
Muestra el politopo con una rueda de colores completamente saturada en la que los bordes o las caras se colorean según su "profundidad" 4D promedio, es decir, la coordenada w de la posición sin rotar del politopo (por defecto).

Las siguientes dos opciones son mutuamente excluyentes. Determinan cómo se proyecta el politopo de 3D a 2D (es decir, a la pantalla).

--perspective-3d
Proyecta el politopo de 3D a 2D usando una proyección perspectiva (por defecto).
--orthographic-3d
Proyecta el politopo de 3D a 2D usando una proyección ortográfica.

Las siguientes dos opciones son mutuamente excluyentes. Determinan cómo se proyecta el politopo de 4D a 3D.

--perspective-4d
Proyecta el politopo de 4D a 3D usando una proyección perspectiva (por defecto).
--orthographic-4d
Proyecta el politopo de 4D a 3D usando una proyección ortográfica.

Las siguientes seis opciones determinan la velocidad de rotación del politopo alrededor de los seis planos hiperbólicos posibles. La velocidad de rotación se mide en grados por fotograma. Las velocidades deben establecerse en valores relativamente pequeños, por ejemplo, de magnitud inferior a 4.

--speed-wx float
Velocidad de rotación alrededor del plano wx (por defecto: 1.1).
--speed-wy float
Velocidad de rotación alrededor del plano wy (por defecto: 1.3).
--speed-wz float
Velocidad de rotación alrededor del plano wz (por defecto: 1.5).
--speed-xy float
Velocidad de rotación alrededor del plano xy (por defecto: 1.7).
--speed-xz float
Velocidad de rotación alrededor del plano xz (por defecto: 1.9).
--speed-yz float
Velocidad de rotación alrededor del plano yz (por defecto: 2.1).

INTERACCIÓN

Si ejecutas este programa en modo independiente, puedes rotar el politopo arrastrando el ratón mientras mantienes presionado el botón izquierdo. Esto rota el politopo en 3D, es decir, alrededor de los planos wx, wy y wz. Si mantienes presionada la tecla Shift mientras arrastras el ratón con el botón izquierdo presionado, el politopo se rota en 4D, es decir, alrededor de los planos xy, xz e yz. Para examinar el politopo a tu gusto, es mejor establecer todas las velocidades a 0. De lo contrario, el politopo rotará mientras el botón izquierdo del ratón no esté presionado. --fps Muestra la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los globales

xscreensaver.6 - X Version 11

NAME

xscreensaver-text - displays text from a file in the X screen saver window

SYNOPSIS

xscreensaver-text [options...] [-file filename] [-root]

DESCRIPTION

xscreensaver-text is a screen saver program that displays text from a given file in the X screen saver window. It's intended to be used as a replacement for the xscreensaver screensaver, for example, to display system status information, news feeds, or inspirational quotes.

The text is displayed in a scrolling manner. If the text file contains more lines than can fit on the screen, it will scroll vertically. The scrolling speed and direction can be configured through the xscreensaver-text preferences, which are typically accessed via the xscreensaver control panel.

If no file is specified, xscreensaver-text will look for a file named .xscreensaver-text in the user's home directory.

OPTIONS

-file filename
Specifies the file to read text from. If this option is not provided, xscreensaver-text will try to read from ~/.xscreensaver-text.
-root
Make the window appear on the root window. This is the default behavior if no window ID is specified.
-window window-id
Make the window appear on the specified window window-id. This is useful if you want to embed the text display in another application or window manager.
-delay seconds
Sets the delay between text updates in seconds. The default is 5 seconds.
-speed speed
Sets the scrolling speed. Higher values mean faster scrolling. The default is 3.
-font fontname
Sets the font to use for displaying the text. The default is a fixed-width font.
-color colorname
Sets the text color. The default is white.
-background colorname
Sets the background color. The default is black.
-help
Display a help message and exit.
-version
Display version information and exit.

INTERACTION

When run as a screensaver, xscreensaver-text will respond to standard screensaver exit events, such as mouse movement or keyboard input, by terminating itself and allowing the original X session to resume.

You can typically configure xscreensaver-text more finely using the xscreensaver-demo utility.

ENVIRONMENT

RESOURCE_MANAGER
Configuration options for xscreensaver-text can also be set via X resources. These are typically loaded from ~/.Xresources or ~/.Xdefaults. The specific resource names may vary, but they often correspond to the command-line options (e.g., XScreenSaver-text.file, XScreenSaver-text.delay).
XSCREENSAVER_WINDOW
The window ID to use with --root.
