NOMBRE

podman-images - Listar imágenes en el almacenamiento local

SINOPSIS

podman images [opciones] [imagen]

podman image list [opciones] [imagen]

podman image ls [opciones] [imagen]

DESCRIPCIÓN

Muestra las imágenes almacenadas localmente, sus nombres y sus identificadores.

OPCIONES

--all, -a

Mostrar todas las imágenes (por defecto, filtra las capas de imagen intermedias). El valor predeterminado es falso.

--digests

Mostrar los resúmenes de las imágenes

--filter, -f=filtro

Proporcionar valores de filtro.

El formato del argumento de filtros es de clave=valor o clave!=valor. Si hay más de un filtro, pase opciones múltiples: --filter foo=bar --filter bif=baz.

Filtros admitidos:

Filtro Descripción
id Filtrar por ID de imagen.
before Filtrar por imágenes creadas antes de la IMAGEN dada (nombre o etiqueta).
containers Filtrar por imágenes con un contenedor en ejecución.
dangling Filtrar por imágenes colgantes (sin usar).
digest Filtrar por resumen.
intermediate Filtrar por imágenes que son colgantes y no tienen hijos.
label Filtrar por imágenes con (o sin, en el caso de que se use label!=[...] ) las etiquetas especificadas.
manifest Filtrar por imágenes que son listas de manifiestos.
readonly Filtrar por imágenes de solo lectura o de lectura/escritura.
reference Filtrar por nombre de imagen.
after/since Filtrar por imágenes creadas después de la IMAGEN dada (nombre o etiqueta).
until Filtrar por imágenes creadas hasta la duración o tiempo dados.

El filtro id acepta la cadena del ID de la imagen.

El filtro before acepta formatos: <nombre-imagen>[:<etiqueta>], <id-imagen> o <imagen@resumen>.

El filtro containers muestra imágenes que tienen un contenedor en ejecución basado en esa imagen.

El filtro dangling muestra imágenes que ocupan espacio en disco y no sirven para nada. Una imagen colgante es una capa de sistema de archivos que se utilizó en una compilación anterior de una imagen y que ya no está referenciada por ninguna imagen. Se denotan con la etiqueta <none>, consumen espacio en disco y no sirven para ningún propósito activo.

El filtro digest acepta la cadena del resumen de la imagen.

El filtro intermediate muestra imágenes que son colgantes y no tienen hijos.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que muestra imágenes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que muestra imágenes sin las etiquetas especificadas.

El filtro manifest muestra imágenes que son listas de manifiestos.

El filtro readonly muestra, por defecto, imágenes de solo lectura y de lectura/escritura. Las imágenes de solo lectura se pueden configurar modificando los additionalimagestores en el archivo /etc/containers/storage.conf.

El filtro reference acepta el patrón de una referencia de imagen <nombre-imagen>[:<etiqueta>].

Los filtros after o since aceptan formatos: <nombre-imagen>[:<etiqueta>], <id-imagen> o <imagen@resumen>.

El filtro until acepta formatos: duración de golang, tiempo RFC3339 o una marca de tiempo Unix, y muestra todas las imágenes creadas hasta ese momento.

--format=formato

Cambiar el formato de salida predeterminado. Puede ser de un tipo admitido como 'json' o una plantilla Go. Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Containers Número de contenedores que utilizan esta imagen
.Created Tiempo transcurrido desde que se creó la imagen
.CreatedAt Hora en que se creó la imagen, AAAA-MM-DD HH:MM:SS +nnnn
.CreatedSince Igual que .Created
.CreatedTime Igual que .CreatedAt
.Dangling Igual que .IsDangling
.Digest Resumen de la imagen
.History Historial de la capa de la imagen
.ID ID de la imagen (truncado)
.Id ID de la imagen (SHA completo)
.IsDangling ¿Imagen colgante? (verdadero/falso)
.IsReadOnly ¿Imagen de solo lectura? (verdadero/falso)
.Labels ... map[] de etiquetas
.Names FQIN de la imagen
.ParentId SHA completo del ID de imagen padre, o null (cadena)
.ReadOnly Igual que .IsReadOnly
.RepoDigests map[] de cero o más cadenas repo/nombre@sha256:SHA
.Repository Repositorio de la imagen
.RepoTags map[] de cero o más cadenas FQIN para esta imagen
.SharedSize Siempre parece ser 0
.Size Tamaño de la capa en disco (cadena legible por humanos)
.Tag Etiqueta de la imagen
.VirtualSize Tamaño de la capa en disco (bytes)

--history

Mostrar el historial de nombres de imagen. Si una imagen se vuelve a etiquetar o se des-etiqueta, el historial de nombres de imagen se antepone (imagen más reciente primero). Esto es especialmente útil al deshacer una operación de etiquetado o cuando una imagen no contiene ningún nombre porque se ha des-etiquetado.

--no-trunc

No truncar la salida (predeterminado falso).

--noheading, -n

Omitir las cabeceras de tabla de la lista.

--quiet, -q

Lista solo los ID de imagen.

--sort=ordenar

Ordenar por created, id, repository, size o tag (predeterminado: created). Al ordenar por repository, también ordena por la tag como segundo criterio para proporcionar una salida estable.

NAME

podman-images - List images in local storage

SYNOPSIS

podman images [options] [image-name ...]

DESCRIPTION

Lists images that are stored locally on the system. The command can display images from all registries or specify particular image names to list. This includes images that have been created by containers but are not associated with a named image (dangling images).

OPTIONS

        See podman(1) for common options that are available on all podman commands,
        such as --config full_path, --log-level string, --help, etc.

        --all, -a
          Show all images, including dangling images. Default is to show only
          non-dangling images.
        --format string
          Pretty-print images using a Go template. Accepted verbs are {{.ID}},
          {{.Digest}}, {{.Repository}}, {{.Tag}}, {{.Created}}, {{.Size}},
          {{.Names}}.
        --help
          Print usage statement for command.
        --latest, -l
          Show only the latest numerical or alphabetical tag for the specified image.
        --no-trunc
          Do not truncate output. Default is to truncate output.
        --quiet, -q
          Only display the numeric IDs of images.
        --sort string
          Sort the list by the specified key. Valid keys are ID, Repository,
          Tag, Created, Size. Default is Repository.
        --filter, -f list
          Filter output based on conditions provided. Valid filters are:
          dangling=(true|false) - show dangling images
          label!= - show images whose label does not match the key
          label= - show images whose label matches the key
          shared=(true|false) - show images that are shared or not
