NOMBRE

podman-machine-inspect - Inspeccionar una o más máquinas virtuales

SINOPSIS

podman machine inspect [opciones] [nombre] ...

DESCRIPCIÓN

Inspeccionar una o más máquinas virtuales.

Obtener más detalles sobre las máquinas virtuales de Podman. Se pueden inspeccionar varias máquinas virtuales a la vez.

El nombre de máquina predeterminado es podman-machine-default. Si no se especifica un nombre de máquina como argumento, se inspeccionará podman-machine-default.

Solo sin raíz (Rootless).

OPCIONES

--format

Imprimir resultados con una plantilla de Go.

Marcador Descripción
.ConfigDir ... Ubicación del directorio de configuración de la máquina
.ConnectionInfo ... Información de conexión de la máquina
.Created ... Hora de creación de la máquina (cadena, ISO3601)
.LastUp ... Hora en que la máquina se inició por última vez
.Name Nombre de la máquina
.Resources ... Recursos utilizados por la máquina
.Rootful Si la máquina prefiere la ejecución de contenedores con o sin raíz
.Rosetta Si esta máquina utiliza Rosetta
.SSHConfig ... Información de configuración SSH para comunicarse con la máquina
.State Estado de la máquina
.UserModeNetworking Si esta máquina utiliza redes en modo de usuario

--help

Imprimir el enunciado de uso.

EJEMPLOS

Inspeccionar la máquina Podman especificada.

$ podman machine inspect podman-machine-default
[
     {
          "ConfigDir": {
               "Path": "/Users/jacksparrow/.config/containers/podman/machine/applehv"
          },
          "ConnectionInfo": {
               "PodmanSocket": {
                    "Path": "/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock"
               },
               "PodmanPipe": null
          },
          "Created": "2025-02-11T14:12:48.231836+05:30",
          "LastUp": "2025-08-12T19:31:19.391294+05:30",
          "Name": "podman-machine-default",
          "Resources": {
               "CPUs": 6,
               "DiskSize": 100,
               "Memory": 6144,
               "USBs": []
          },
          "SSHConfig": {
               "IdentityPath": "/Users/jacksparrow/.local/share/containers/podman/machine/machine",
               "Port": 53298,
               "RemoteUsername": "core"
          },
          "State": "running",
          "UserModeNetworking": true,
          "Rootful": false,
          "Rosetta": true
     }
]

Mostrar el nombre y estado de la máquina:

$ podman machine inspect --format "{{.Name}}\t{{.State}}"
podman-machine-default running

Mostrar información de recursos de la máquina:

$ podman machine inspect --format "Máquina: {{.Name}}\nCPUs: {{.Resources.CPUs}}\nMemoria: {{.Resources.Memory}} bytes\nDisco: {{.Resources.DiskSize}} bytes"
Máquina: podman-machine-default
CPUs: 6
Memoria: 6144 bytes
Disco: 100 bytes

Mostrar detalles de configuración de la máquina:

$ podman machine inspect --format "{{.Name}}: {{.State}} (Rootful: {{.Rootful}}, User Networking: {{.UserModeNetworking}})"
podman-machine-default: running (Rootful: false, User Networking: true)

Mostrar información del tiempo de actividad de la máquina:

$ podman machine inspect --format "Creada: {{.Created}}\nÚltimo inicio: {{.LastUp}}\nEstado: {{.State}}"
Creada: 2025-02-11 14:12:48.231836 +0000 UTC
Último inicio: 2025-08-12 19:31:19.391294 +0000 UTC
Estado: running

Mostrar información de conexión:

$ podman machine inspect --format "Socket: {{.ConnectionInfo.PodmanSocket}}\nDir. Config: {{.ConfigDir}}"
Socket: {/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock <nil>}
Dir. Config: {/Users/jacksparrow/.config/containers/podman/machine/applehv <nil>}
