pow(3) Manual de Funciones de Biblioteca pow(3)

NOMBRE

pow, powf, powl - funciones de potencia

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double pow(double x, double y);
float powf(float x, float y);
long double powl(long double x, long double y);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

powf(), powl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Estas funciones devuelven el valor de x elevado a la potencia de y.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor de x elevado a la potencia de y.

Si el resultado desborda, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el signo matemáticamente correcto.

Si el resultado se subdesborda y no es representable, ocurre un error de rango y se devuelve 0.0 con el signo apropiado.

Si x es +0 o -0, y y es un entero impar menor que 0, ocurre un error de polo y se devuelve HUGE_VAL, HUGE_VALF o HUGE_VALL, con el mismo signo que x.

Si x es +0 o -0, y y es menor que 0 y no es un entero impar, ocurre un error de polo y se devuelve +HUGE_VAL, +HUGE_VALF o +HUGE_VALL.

Si x es +0 (-0), y y es un entero impar mayor que 0, el resultado es +0 (-0).

Si x es 0, y y es mayor que 0 y no es un entero impar, el resultado es +0.

Si x es -1, y y es infinito positivo o infinito negativo, el resultado es 1.0.

Si x es +1, el resultado es 1.0 (incluso si y es un NaN).

Si y es 0, el resultado es 1.0 (incluso si x es un NaN).

Si x es un valor finito menor que 0, y y es un no entero finito, ocurre un error de dominio y se devuelve un NaN.

Si el valor absoluto de x es menor que 1, y y es infinito negativo, el resultado es infinito positivo.

Si el valor absoluto de x es mayor que 1, y y es infinito negativo, el resultado es +0.

Si el valor absoluto de x es menor que 1, y y es infinito positivo, el resultado es +0.

Si el valor absoluto de x es mayor que 1, y y es infinito positivo, el resultado es infinito positivo.

Si x es infinito negativo, y y es un entero impar menor que 0, el resultado es -0.

Si x es infinito negativo, y y es menor que 0 y no es un entero impar, el resultado es +0.

Si x es infinito negativo, y y es un entero impar mayor que 0, el resultado es infinito negativo.

Si x es infinito negativo, y y es mayor que 0 y no es un entero impar, el resultado es infinito positivo.

Si x es infinito positivo, y y es menor que 0, el resultado es +0.

Si x es infinito positivo, y y es mayor que 0, el resultado es infinito positivo.

Excepto como se especifica anteriormente, si x o y es un NaN, el resultado es un NaN.

ERRORES

Ver math_error(7) para información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es negativo y y es un no entero finito
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de polo: x es cero y y es negativo
errno se establece en ERANGE (pero ver BUGS). Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).
Error de rango: el resultado desborda
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).
Error de rango: el resultado subdesborda
errno se establece en ERANGE. Se genera una excepción de punto flotante de subdesbordamiento (FE_UNDERFLOW).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pow (), powf (), powl () Seguridad en hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

C99, POSIX.1-2001.

La variante que devuelve double también cumple con SVr4, 4.3BSD, C89.

ERRORES GRAVES

Errores históricos (ahora corregidos)

Antes de glibc 2.28, en algunas arquitecturas (por ejemplo, x86-64) pow() puede ser más de 10.000 veces más lento para algunas entradas que para otras entradas cercanas. Esto afecta solo a pow(), y no a powf() ni a powl(). Este problema se corrigió en glibc 2.28.

Una serie de errores en la implementación de glibc de pow() se corrigieron en glibc 2.16.

En glibc 2.9 y anteriores, cuando ocurre un error de polo, errno se establece en EDOM en lugar del ERANGE exigido por POSIX. Desde glibc 2.10, glibc hace lo correcto.

En glibc 2.3.2 y anteriores, cuando ocurre un error de desbordamiento o subdesbordamiento, pow() de glibc genera una excepción de punto flotante inválida (FE_INVALID) además de la excepción de desbordamiento o subdesbordamiento.

VER TAMBIÉN

cbrt(3), cpow(3), sqrt(3)

POW(3) Sección 3 de Manuales POW(3)

NOMBRE

pow - función de potencia exponencial

BIBLIOTECA

Matemáticas (libmath, -lm)

SINOPSIS

#include <math.h>

double pow(double x, double y);

float powf(float x, float y);

long double powl(long double x, long double y);

double powr(double x, double y);

DESCRIPCIÓN

La función pow() devuelve x elevado a la potencia y.

Las funciones powf() y powl() realizan el mismo cálculo, pero con tipos de punto flotante float y long double respectivamente.

La función powr() realiza el mismo cálculo que pow(), pero está garantizado que devuelve un resultado real cuando la base es negativa y el exponente es un entero.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor de xy.

Si x es negativo y y no es un entero, un error de dominio ocurre, y un NaN se devuelve.

Si x es cero y y es negativo, un error de dominio ocurre, y +inf se devuelve.

Si x es cero y y es cero, un error de dominio ocurre, y 1 se devuelve.

Si x es negativo y y es no entero, se genera una excepción de dominio de punto flotante, y NaN se devuelve.

Si x es negativo y y es no entero, se genera una excepción de dominio de punto flotante.

Si el resultado es demasiado grande para ser representado, se genera una excepción de rango de punto flotante, y +inf o -inf se devuelve.

Si x es 0 y y es 0, se genera una excepción de dominio de punto flotante, y 1 se devuelve.

Si x es 0 y y es negativo, se genera una excepción de dominio de punto flotante, y +inf se devuelve.

ERRORES

Se definen las siguientes condiciones de error:

  • EDOM: El valor de x es negativo y y no es un entero.
  • ERANGE: El resultado es demasiado grande para ser representado.

Además, las siguientes condiciones pueden generar un error:

  • x = 0 y y = 0
  • x = 0 y y < 0

ATRIBUTOS

Para obtener información sobre la semántica de las siguientes atributos, consulte attributes(7).

ESTÁNDARES

La función pow() está conforme a C99, C11, C17, C23.

HISTORIAL

La función pow() apareció en Version 1.

ERRORES

No se conocen errores.

VER TAMBIÉN

exp(3), exp2(3), hypot(3), log(3), log2(3), sqrt(3)
