POD2TEXI(1) Documentación de Perl aportada por el usuario POD2TEXI(1)

NOMBRE

pod2texi - convierte Pod a Texinfo

SINOPSIS

pod2texi [OPCIÓN]... POD...

DESCRIPCIÓN

Traduce archivos Pod a Texinfo. Hay dos modos básicos de operación. Primero, por defecto, cada Pod se traduce a un manual de Texinfo independiente.

Segundo, si "--base-level" se establece en un valor superior a 0, cada Pod se traduce a un archivo adecuado para @include, y se genera un archivo más con un menú principal y todas las @include.

OPCIONES

--appendix-sections
Utiliza comandos de sección de apéndice (@appendix, ...) en lugar de los comandos Texinfo de sección numerada por defecto (@-commands: @chapter, @section, ...).
--base-level=NUM|NOMBRE
Establece el nivel de los comandos "head1". Puede ser un entero o un comando de sección Texinfo (sin el "@"): 1 corresponde al nivel @chapter/@unnumbered, 2 al nivel @section, y así sucesivamente. El valor por defecto es 0, lo que significa que los comandos "head1" todavía se generan como capítulos, pero la salida se organiza como un manual independiente.

Si el nivel no es 0, el archivo Pod se renderiza como un fragmento de un manual Texinfo adecuado para @include. En este caso, cada archivo Pod tiene un comando de sección adicional que cubre todo el archivo, un nivel por encima del valor de "--base-level". Por lo tanto, para hacer que cada archivo Pod sea un capítulo en un manual grande, deberías usar "section" como nivel base.

Para un ejemplo de cómo generar Texinfo a partir de la documentación de Perl, consulta "contrib/perldoc-all" en la distribución fuente de Texinfo.

--debug=NUM
Establece el nivel de depuración en NUM.
--generate-setfilename
Genera una línea @setfilename para manuales independientes. Se puede negar con "--no-generate-setfilename". Ignorado si "--base-level" no es 0.
--headings-as-sections
Utiliza comandos de encabezado (@heading, ...) en lugar de los comandos Texinfo de sección numerada por defecto (@-commands: @chapter, @section, ...). El comando de sección que cubre todo el archivo de salida para cada archivo Pod si --base-level no es 0 es un comando numerado.
--help
Muestra la ayuda y sale.
--menus
Genera menús de nodos. Si hay un manual principal, su menú del nodo superior se genera siempre, ya que se genera un menú maestro. Los menús de otros nodos no se generan en el caso por defecto.
--outdir=NOMBRE
Si hay un manual principal con archivos de inclusión (cada uno correspondiente a un archivo Pod de entrada), entonces los archivos Texinfo generados se colocan en el directorio NOMBRE. El valor por defecto se basa en "--subdir".
--output=NOMBRE
Nombre para el primer manual, o para el manual principal si hay un manual principal. Por defecto, se escribe en la salida estándar.
--no-section-nodes
Utiliza anclas para las secciones en lugar de nodos.
--no-fill-section-gaps
No rellena los huecos de sección con archivos vacíos @unnumbered. Normalmente, es bueno mantener intacta la jerarquía de secciones.
--preamble=STR
Inserta STR como cabecera superior antes del menú e inclusiones. Si STR se establece en "-", lee la cabecera superior de la entrada estándar. La cabecera superior por defecto es un comienzo mínimo para un documento Texinfo.
--setfilename=STR
Utiliza STR en la cabecera superior antes del menú e inclusiones para @setfilename para el manual principal, si "--base-level" no está establecido en 0. Ignorado si "--base-level" es 0. No se genera @setfilename en el caso por defecto para el manual principal.
--subdir=NOMBRE
Si hay un manual principal con archivos de inclusión (cada uno correspondiente a un archivo Pod de entrada), entonces esos archivos de inclusión se incluirán desde NOMBRE.

Si se establece "--outdir", NOMBRE debería ser generalmente el directorio relativo entre el manual principal y el argumento "--outdir".

--unnumbered-sections
Utiliza comandos de sección sin numerar (@unnumbered, ...) en lugar de los comandos Texinfo de sección numerada por defecto (@-commands: @chapter, @section, ...).
--top=TOP
Nombre del elemento @top para el manual principal. Puede contener código Texinfo.
--version
Muestra la información de la versión y sale.
