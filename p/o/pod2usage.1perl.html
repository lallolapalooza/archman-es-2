POD2USAGE(1perl) Guía de referencia del programador de Perl POD2USAGE(1perl)

NOMBRE

pod2usage - imprime mensajes de uso desde documentación pod incrustada en archivos

SINOPSIS

pod2usage
[-help] [-man] [-exit valor_salida] [-output archivo_salida] [-verbose nivel] [-pathlist lista_directorios] [-formatter módulo] [-utf8] archivo

OPCIONES Y ARGUMENTOS

-help
Imprime un breve mensaje de ayuda y sale.
-man
Imprime la página de manual de este comando y sale.
-exit valor_salida
El valor de estado de salida a devolver.
-output archivo_salida
El archivo de salida donde imprimir. Si se utilizan los nombres especiales "-" o ">&1" o ">&STDOUT", se usa la salida estándar. Si se utiliza ">&2" o ">&STDERR", se usa el error estándar.
-verbose nivel
El nivel de verbosidad deseado a utilizar: 
1 : imprime solo SINOPSIS
2 : imprime secciones de SINOPSIS y cualquier sección de OPCIONES/ARGUMENTOS
3 : imprime la página de manual completa (similar a ejecutar pod2text)
-pathlist lista_directorios
Especifica uno o más directorios para buscar el archivo de entrada si no se proporcionó con una ruta absoluta. Cada ruta de directorio en la lista dada debe estar separada por ':' en Unix (';' en MSWin32 y DOS).
-formatter módulo
Qué formateador de texto usar. El valor predeterminado es Pod::Text. Una alternativa podría ser, por ejemplo, Pod::Text::Termcap.
-utf8
Esta opción asume que el formateador (ver arriba) entiende la opción "utf8". Activa la generación de salida utf8.
archivo
La ruta de un archivo que contiene documentación pod que se va a emitir en formato de mensaje de uso. Si se omite, se lee la entrada estándar, pero la salida se formatea solo con Pod::Text, a menos que se haya especificado un formateador específico con -formatter.

DESCRIPCIÓN

pod2usage leerá el archivo de entrada especificado buscando documentación pod y emitirá el mensaje de uso correspondiente. Si no se especifica ningún archivo de entrada, se lee la entrada estándar.

pod2usage invoca la función pod2usage() en el módulo Pod::Usage. Por favor, consulte "pod2usage()" en Pod::Usage.

VER TAMBIÉN

Pod::Usage, pod2text, Pod::Text, Pod::Text::Termcap, perldoc
