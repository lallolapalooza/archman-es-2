NOMBRE

podman-image-prune - Elimina todas las imágenes sin usar del almacén local

SINOPSIS

podman image prune [opciones]

DESCRIPCIÓN

podman image prune elimina todas las imágenes colgadas del almacén de almacenamiento local. Con la opción all, se eliminan todas las imágenes sin usar (es decir, las imágenes que no estén siendo utilizadas por ningún contenedor).

El comando de limpieza de imágenes no elimina imágenes de caché que solo usan capas necesarias para otras imágenes.

OPCIONES

--all, -a

Elimina imágenes colgadas e imágenes que no tienen contenedores asociados.

--build-cache

Elimina la caché de compilación persistente creada para --mount=type=cache.

--external

Elimina imágenes incluso cuando están siendo utilizadas por contenedores externos (por ejemplo, contenedores de compilación).

--filter=filtros

Proporciona valores de filtro.

El argumento filtros tiene el formato clave=valor. Si hay más de un filtro, pasa múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros soportados:

Filtro Descripción
label Solo elimina imágenes, con (o sin, en caso de usarse label!=[...] es usado) las etiquetas especificadas.
until Solo elimina imágenes creadas antes de la marca de tiempo dada.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina contenedores con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina contenedores sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

--force, -f

No proporciona una indicación interactiva para la eliminación del contenedor.

--help, -h

Imprime la declaración de uso.
