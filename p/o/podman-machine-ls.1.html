NOMBRE

podman-machine-list - Listar máquinas virtuales

SINOPSIS

podman machine list [opciones]

podman machine ls [opciones]

DESCRIPCIÓN

Lista las máquinas virtuales gestionadas por Podman.

Podman en MacOS y Windows requiere una máquina virtual. Esto se debe a que los contenedores son Linux - los contenedores no se ejecutan en ningún otro sistema operativo porque la funcionalidad principal de los contenedores está ligada al kernel de Linux. podman machine debe usarse para gestionar máquinas MacOS y Windows, pero puede usarse opcionalmente en Linux.

Solo sin root.

NOTA: El archivo de configuración de podman-machine se gestiona dentro del directorio $XDG_CONFIG_HOME/containers/podman/machine/. Cambiar la variable de entorno $XDG_CONFIG_HOME mientras las máquinas están en ejecución puede provocar un comportamiento inesperado. (ver podman(1))

OPCIONES

--all-providers

Mostrar máquinas de todos los proveedores

--format=formato

Cambiar el formato de salida predeterminado. Este puede ser de un tipo soportado como 'json' o una plantilla Go. Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.CPUs Número de CPUs
.Created Tiempo desde la creación de la VM
.Default Es la máquina predeterminada
.DiskSize Tamaño del disco de la máquina
.IdentityPath Ruta al archivo de identidad ssh
.LastUp Tiempo desde que la VM se ejecutó por última vez
.Memory Memoria asignada para la máquina
.Name Nombre de la VM
.Port Puerto SSH a utilizar para conectarse a la VM
.RemoteUsername Nombre de usuario de la VM para Podman sin root
.Running La máquina está en ejecución
.Stream Nombre del stream
.Swap Swap asignado para la máquina
.UserModeNetworking Si la máquina utiliza redes en modo usuario
.VMType Tipo de VM

--help

Imprimir declaración de uso.

--noheading, -n

Omitir las cabeceras de la tabla de la lista.

--quiet, -q

Solo imprimir el nombre de la máquina. Esto también implica que no se imprime ninguna cabecera de tabla.

EJEMPLOS

Listar todas las máquinas de Podman.

$ podman machine list
NOMBRE                    TIPO VM         CREADO      ÚLTIMA VEZ ARRIBA      CPUS        MEMORIA      TAMAÑO DISCO
podman-machine-default  qemu        Hace 2 semanas  Hace 2 semanas  1           2.147GB     10.74GB

Listar todas las máquinas de Podman utilizando el formato de tabla especificado.

$ podman machine ls --format "table {{.Name}}\t{{.VMType}}\t{{.Created}}\t{{.LastUp}}"
NOMBRE                    TIPO VM         CREADO      ÚLTIMA VEZ ARRIBA
podman-machine-default  qemu        Hace 2 semanas  Hace 2 semanas

Listar todas las máquinas de Podman en formato json.

$ podman machine ls --format json
[
    {
        "Name": "podman-machine-default",
        "Default": false,
        "Created": "2021-12-27T10:36:14.373347492-05:00",
        "Running": false,
        "LastUp": "2021-12-27T11:22:50.17333371-05:00",
        "Stream": "default",
        "VMType": "qemu",
        "CPUs": 1,
        "Memory": "2147483648",
        "DiskSize": "10737418240"
    }
]
