NOMBRE

podman-image-scp - Copia de forma segura una imagen de un host a otro

SINOPSIS

podman image scp [opciones] nombre[:etiqueta]

DESCRIPCIÓN

podman image scp copia imágenes de contenedores entre hosts en una red. Este comando puede copiar imágenes al host remoto o desde el host remoto, así como entre dos hosts remotos. Nota: se utiliza :: para especificar el nombre de la imagen dependiendo de si Podman está guardando o cargando. Las imágenes también se pueden transferir del almacenamiento rootful al rootless en la misma máquina sin usar sshd. Esta característica no es compatible con el cliente remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2).

podman image scp [OPCIONES GLOBALES]

podman image scp [OPCIONES] NOMBRE[:ETIQUETA] [HOSTNAME::]

podman image scp [OPCIONES] [HOSTNAME::]NOMBREIMAGEN

podman image scp [OPCIONES] [HOSTNAME::]NOMBREIMAGEN [HOSTNAME::]

OPCIONES

--help, -h

Imprime el enunciado de uso

--quiet, -q

Suprime la salida

EJEMPLOS

Copiar la imagen especificada al almacenamiento local:

$ podman image scp alpine
Loaded image: docker.io/library/alpine:latest

Copiar la imagen especificada desde el almacenamiento local a la conexión remota:

$ podman image scp alpine Fedora::/home/charliedoern/Documents/alpine
Getting image source signatures
Copying blob 72e830a4dff5 done
Copying config 85f9dc67c7 done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

Copiar la imagen especificada desde la conexión remota a la conexión remota:

$ podman image scp Fedora::alpine RHEL::
Loaded image: docker.io/library/alpine:latest

Copiar la imagen especificada a través de ssh al almacenamiento local:

$ podman image scp charliedoern@192.168.68.126:22/run/user/1000/podman/podman.sock::alpine
