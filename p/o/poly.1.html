POLY(1) Manual de Comandos Generales POLY(1)

NOMBRE

poly - la implementación de Standard ML de Poly/ML

SINOPSIS

poly

DESCRIPCIÓN

poly inicia el shell de Poly/ML. Poly/ML es una implementación de Standard ML escrita por David Matthews originalmente en la Universidad de Cambridge y mantenida como un proyecto apoyado por colaboradores.

OPCIONES

-v
Imprime la versión de Poly/ML y sale.
--help
Imprime una lista de los argumentos y sale.
-q
Suprime el mensaje de inicio.
-i
Modo interactivo. Muestra un prompt para cada línea de entrada. Este es el valor predeterminado si la entrada proviene de una terminal.
--use FILE
Lee la entrada de FILE como si ejecutara el comando ML 'use "FILE";' antes de que comience el shell ML.
--eval STRING
Compila y ejecuta STRING como ML antes de que comience el shell ML.
--error-exit
Normalmente, si el código ML lanza una excepción no manejada, el control regresa al shell ML. Con esta opción, el shell sale ante una excepción no manejada.
--with-markup
Incluye información de marcado adicional al imprimir. Esto solo es adecuado cuando Poly/ML se ejecuta en un entorno capaz de decodificar la información adicional.
--ideprotocol
Ejecuta el protocolo de comunicación IDE en lugar del bucle normal de lectura-evaluación-impresión. Solo adecuado para ejecutar dentro de un entorno de desarrollo.
--script
La entrada es un script de shell. Se omite la primera línea si comienza con #!.
-H tamaño
Establece el tamaño inicial del heap. El tamaño puede escribirse como un número seguido opcionalmente por K, M o G representando kilobytes, megabytes o gigabytes. Si no se especifica ninguno de estos, el número se toma como megabytes.
--minheap tamaño
Establece el tamaño mínimo del heap. El heap no se reducirá por debajo de este valor.
--maxheap tamaño
Establece el tamaño máximo del heap. El heap no crecerá por encima de este valor.
--gcpercent porcentaje
Establece el porcentaje objetivo de tiempo que el código debe pasar en el recolector de basura. El ajustador de heap intentará establecer el tamaño del heap para lograr este objetivo, de acuerdo con los tamaños de heap mínimo y máximo dados por los argumentos, y también de acuerdo con el control de la paginación.
--gcthreads hilos
Establece el número de hilos utilizados en el recolector de basura paralelo. Establecer esto en 1 fuerza que el recolector de basura sea monohilo. El valor 0, el predeterminado, se toma como el número de procesadores (núcleos) disponibles.
--debug opciones
Establece varias opciones de depuración para el sistema de ejecución.
