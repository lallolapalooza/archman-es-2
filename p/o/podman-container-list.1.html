NOMBRE

podman-ps - Imprime información sobre los contenedores

SINOPSIS

podman ps [opciones]

podman container ps [opciones]

podman container list [opciones]

podman container ls [opciones]

DESCRIPCIÓN

podman ps lista los contenedores en ejecución en el sistema. Utilice la opción --all para ver toda la información de los contenedores. Por defecto, lista:

  • el ID del contenedor
  • el nombre de la imagen que utiliza el contenedor
  • el COMANDO que está ejecutando el contenedor
  • la hora de creación del contenedor
  • el estado del contenedor
  • las asignaciones de puertos que utiliza el contenedor
  • nombres alternativos para el contenedor

OPCIONES

--all, -a

Mostrar todos los contenedores, por defecto solo los en ejecución.

Nota: Podman comparte el almacenamiento de contenedores con otras herramientas como Buildah y CRI-O. En algunos casos, estos contenedores externos también pueden existir en el mismo almacenamiento. Utilice la opción --external para ver estos contenedores externos. Los contenedores externos muestran el estado de 'storage'.

--external

Mostrar contenedores externos que no son controlados por Podman pero que están almacenados en el almacenamiento de contenedores. Estos contenedores externos se crean generalmente a través de otras tecnologías de contenedores como Buildah o CRI-O y pueden depender de las mismas imágenes de contenedores que Podman también está utilizando. Los contenedores externos se indican con 'buildah' o 'storage' en la columna COMANDO y ESTADO de la salida de ps.

--filter, -f

Filtra qué contenedores se muestran en la salida. Se pueden dar múltiples filtros usando la opción --filter varias veces. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia parcial de prefijo de CID por defecto; acepta expresiones regulares)
name [Nombre] Nombre del contenedor (acepta expresiones regulares)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
label! [Clave] o [Clave=Valor] Etiqueta NO asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizada para crear el contenedor (acepta expresiones regulares)
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [DateTime] contenedor creado antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--format=formato

Imprimir contenedores con formato JSON o usando una plantilla Go

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.AutoRemove Si es verdadero, los contenedores se eliminan al salir
.CIDFile Archivo de ID de contenedor
.Command Comando citado utilizado
.Created ... Hora de creación del contenedor, A-M-D H:M:S
.CreatedAt Hora de creación del contenedor (igual que la anterior)
.CreatedHuman Hora de creación, relativa
.ExitCode Código de salida del contenedor
.Exited "true" si el contenedor ha salido
.ExitedAt Hora (segundos de época) en que salió el contenedor
.ExposedPorts ... Mapa de puertos expuestos en este contenedor
.ID ID del contenedor
.Image Nombre/ID de la imagen
.ImageID ID de la imagen
.IsInfra "true" si es un contenedor de infraestructura
.Label string Etiqueta especificada del contenedor
.Labels ... Todas las etiquetas asignadas al contenedor
.Mounts Volúmenes montados en el contenedor
.Names Nombre del contenedor
.Networks Mostrar todas las redes conectadas al contenedor
.Pid ID de proceso en el sistema anfitrión
.Pod Pod al que está asociado el contenedor (SHA)
.PodName Nombre del pod del contenedor
.Ports Puertos reenviados y expuestos
.Restarts Mostrar el recuento de reinicios del contenedor
.RunningFor Tiempo transcurrido desde que se inició el contenedor
.Size Tamaño del contenedor
.StartedAt Hora (segundos de época) en que se inició el contenedor
.State Descripción amigable del estado del contenedor
.Status Estado del contenedor

--help, -h

Imprimir declaración de uso

--last, -n

Imprimir los n últimos contenedores creados (todos los estados)

--latest, -l

Mostrar el último contenedor creado (todos los estados) (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--namespace, --ns

Mostrar información del espacio de nombres

--no-trunc

No truncar la salida (por defecto false).

--noheading

Omitir los encabezados de tabla de la lista de contenedores.

--pod, -p

Mostrar los pods a los que están asociados los contenedores

--quiet, -q

Imprimir solo los IDs numéricos de los contenedores

--size, -s

Mostrar el tamaño total del archivo

--sort=created

Ordenar por comando, creado, id, imagen, nombres, runningfor, tamaño o estado", Nota: Elegir tamaño ordena por el tamaño de rootFs, no alfabéticamente como el resto de las opciones

--sync

Forzar una sincronización del estado del contenedor con el tiempo de ejecución OCI. En algunos casos, el estado de un contenedor en el tiempo de ejecución puede desincronizarse con el estado de Podman. Esto actualiza el estado de Podman basándose en lo que informa el tiempo de ejecución OCI. La sincronización forzada es mucho más lenta, pero puede resolver problemas de estado inconsistente.

--watch, -w

Actualizar la salida con los contenedores actuales en un intervalo de segundos.

EJEMPLOS

Listar contenedores en ejecución.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES
4089df24d

NAME

podman-container-list — List containers

SYNOPSIS

podman container list [options]

podman ps [options]

DESCRIPTION

The podman container list command outputs a list of containers. This command is an alias for podman ps.

By default, podman ps only lists running containers. Use the -a, --all option to see all containers. The container ID and image name are the only columns displayed by default.

OPTIONS

All the options that are available for podman ps command are also available for podman container list command.

-a, --all
Do not hide idle containers (processes in the exited state). Default is to only show containers that are currently running.
-c, --size
Display the size of the container. Note: this can take longer since Podman needs to calculate the size from the file system.
-f, --filter=filter
Filter output based on filters. Current filters are: ancestor, id, label, name, network, pod, status, volume.
--format=format
Pretty-print images using Go templates (when -a is used all containers can be printed in the template)
--help
Print usage statement for command
--ns, --namespaces
Display the namespaces of the containers.
-o, --latest
Instead of printing all containers, only show the most recently created container. This cannot be used with the -a or --all option.
-p, --pod
Display the pod name and pod ID for containers that are part of a pod.
-q, --quiet
Use only numeric output for container IDs.
-s, --sort=sort
Sort output by a particular field.
--external
Consider the objects external to Podman, i.e. containers that were not created by Podman. This command can list containers for example that were created by another container runtime. Default is to show containers created by Podman.
