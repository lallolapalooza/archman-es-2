NOMBRE

podman-network-update - Actualizar una red de Podman existente

SINOPSIS

podman network update [opciones] red

DESCRIPCIÓN

Permite realizar cambios en las redes de contenedores existentes. En este momento, solo se admiten los cambios en los servidores DNS utilizados por una red.

NOTA: Solo compatible con el backend de red netavark.

OPCIONES

--dns-add

Acepta una matriz de resolvedores DNS y la agrega a la lista existente de resolvedores configurados para una red.

--dns-drop

Acepta una matriz de resolvedores DNS y los elimina de la lista existente de resolvedores configurados para una red.

EJEMPLO

Actualizar una red:

$ podman network update network1 --dns-add 8.8.8.8,1.1.1.1

Actualizar una red y agregar/eliminar servidores DNS:

$ podman network update network1 --dns-drop 8.8.8.8 --dns-add 3.3.3.3

VER TAMBIÉN

podman(1), podman-network(1), podman-network-inspect(1), podman-network-ls(1)
