NOMBRE

podman-system-connection-list - Listar la(s) conexión(es) de destino para el servicio Podman

SINOPSIS

podman system connection list [opciones]

podman system connection ls [opciones]

DESCRIPCIÓN

Lista el(los) destino(s) ssh para el(los) servicio(s) de Podman.

OPCIONES

--format, -f=formato

Cambia el formato de salida predeterminado. Este puede ser de un tipo admitido como 'json' o una plantilla Go. Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Default Indica si la conexión es la predeterminada
.Identity Ruta al archivo que contiene la clave SSH
.Name Nombre/Identificador de la conexión
.ReadWrite Indica si esta conexión se puede modificar usando los comandos de conexión del sistema
.TLSCA Ruta a un archivo PEM que contiene el conjunto de autoridades de certificación para verificar el certificado del servidor.
.TLSCert Ruta a un archivo PEM que contiene el conjunto de autoridades de certificación para verificar el certificado del servidor.
.TLSKey Ruta a un archivo PEM que contiene la clave privada que coincide con .TLSCA
.URI URI al servicio de Podman. Los esquemas válidos son ssh://[usuario@]host[:puerto]socket de dominio Unix[?secure=True], unix://socket de dominio Unix, y tcp://localhost[:puerto]

--quiet, -q

Mostrar solo los nombres de las conexiones

EJEMPLO

Listar conexiones del sistema:

$ podman system connection list
Nombre URI                                                      Identidad	    Predeterminado  LecturaEscritura
deva ssh://root@example.com:/run/podman/podman.sock           ~/.ssh/id_rsa true     true
devb ssh://user@example.com:/run/user/1000/podman/podman.sock ~/.ssh/id_rsa false    true

Mostrar conexiones en formato JSON:

$ podman system connection list --format json
[
    {
        "Name": "podman-machine-default",
        "URI": "ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock",
        "Identity": "/Users/ragm/.local/share/containers/podman/machine/machine",
        "IsMachine": true,
        "Default": true,
        "ReadWrite": true
    },
    {
        "Name": "podman-machine-default-root",
        "URI": "ssh://root@127.0.0.1:53298/run/podman/podman.sock",
        "Identity": "/Users/ragm/.local/share/containers/podman/machine/machine",
        "IsMachine": true,
        "Default": false,
        "ReadWrite": true
    }
]

Mostrar nombres y URIs de conexiones:

$ podman system connection list --format "{{.Name}}\t{{.URI}}"
podman-machine-default	ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock
podman-machine-default-root	ssh://root@127.0.0.1:53298/run/podman/podman.sock

Mostrar todos los detalles de las conexiones en un formato completo:

$ podman system connection list --format "Nombre: {{.Name}}\nURI: {{.URI}}\nIdentidad: {{.Identity}}\nPredeterminado: {{.Default}}\nLecturaEscritura: {{.ReadWrite}}\n---"
Nombre: podman-machine-default
URI: ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock
Identidad: /Users/ragm/.local/share/containers/podman/machine/machine
Predeterminado: true
LecturaEscritura: true
---
Nombre: podman-machine-default-root
URI: ssh://root@127.0.0.1:53298/run/podman/podman.sock
Identidad: /Users/ragm/.local/share/containers/podman/machine/machine
Predeterminado: false
LecturaEscritura: true
---
