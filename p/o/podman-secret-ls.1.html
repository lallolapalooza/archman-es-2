NOMBRE

podman-secret-ls - Listar todos los secretos disponibles

SINOPSIS

podman secret ls [opciones]

DESCRIPCIÓN

Lista todos los secretos que existen. La salida puede formatearse como una plantilla Go utilizando la opción --format.

OPCIONES

--filter, -f=filtro=valor

Filtrar la salida según las condiciones dadas. Se pueden dar múltiples filtros utilizando la opción --filter varias veces.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
name [Nombre] Nombre del secreto (acepta expresiones regulares)
id [ID] ID completo o parcial del secreto

--format=formato

Formatear la salida de secretos utilizando una plantilla Go.

Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.CreatedAt Cuándo se creó el secreto (timestamp relativo, legible por humanos)
.Driver Nombre del controlador (cadena)
.ID ID del secreto
.Name Nombre del secreto
.UpdatedAt Cuándo se actualizó por última vez el secreto (timestamp relativo, legible por humanos)

--noheading, -n

Omitir los encabezados de la tabla de la lista.

--quiet, -q

Imprimir solo los ID de los secretos.

EJEMPLOS

Listar todos los secretos.

$ podman secret ls

Listar el campo de nombre de todos los secretos.

$ podman secret ls --format "{{.Name}}"

Listar todos los secretos cuyo nombre incluya la cadena especificada.

$ podman secret ls --filter name=confidencial

VER TAMBIÉN

podman(1), podman-secret(1)
