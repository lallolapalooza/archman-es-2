NOMBRE

podman-image-unmount - Desmontar el sistema de archivos raíz de una imagen

SINOPSIS

podman image unmount [opciones] imagen [...]

podman image umount [opciones] imagen [...]

DESCRIPCIÓN

Desmonta el sistema de archivos raíz de las imágenes especificadas, si ningún otro proceso lo está utilizando.

El almacenamiento de imágenes incrementa un contador de montaje cada vez que se monta una imagen. Cuando se desmonta una imagen, el contador de montaje se decrementa, y el sistema de archivos raíz de la imagen se desmonta físicamente solo cuando el contador de montaje llega a cero, lo que indica que ningún otro proceso está utilizando el montaje. Un desmontaje se puede forzar con la bandera --force.

OPCIONES

--all, -a

Se desmontan todas las imágenes que están montadas actualmente.

--force, -f

Fuerza el desmontaje del sistema de archivos raíz de las imágenes especificadas, incluso si otros procesos lo han montado.

Nota: Otros procesos que utilicen el sistema de archivos pueden fallar si el punto de montaje se elimina sin su conocimiento.

EJEMPLO

Desmontar la imagen con un ID dado:

podman image unmount ID_de_imagen

Desmontar múltiples imágenes con IDs dados:

podman image unmount ID_de_imagen1 ID_de_imagen2 ID_de_imagen3

Desmontar todas las imágenes:

podman image unmount --all

Forzar el desmontaje de la imagen con un ID dado:

podman image unmount --force ID_de_imagen

VER TAMBIÉN

podman(1), podman-image-mount(1), podman-mount(1)
