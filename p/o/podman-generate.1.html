NOMBRE

podman-generate - Genera datos estructurados basados en contenedores, pods o volúmenes

SINOPSIS

podman generate subcomando

DESCRIPCIÓN

El comando generate crea una salida estructurada (como YAML) basada en un contenedor, pod o volumen.

COMANDOS

Comando Página del manual Descripción
kube podman-kube-generate(1) Genera YAML de Kubernetes basado en contenedores, pods o volúmenes.
spec podman-generate-spec(1) Genera JSON de Specgen basado en contenedores o pods.
systemd podman-generate-systemd(1) [OBSOLETO] Genera archivo(s) de unidad systemd para un contenedor o pod.

VER TAMBIÉN

podman(1), podman-pod(1), podman-container(1)
