NOMBRE

podman-system-df - Mostrar uso de disco de podman

SINOPSIS

podman system df [opciones]

DESCRIPCIÓN

Mostrar el uso de disco de podman para imágenes, contenedores y volúmenes.

Nota: El tamaño RECLAMABLE que se informa para las imágenes puede ser incorrecto. Podría informar que puede reclamar más de lo que una limpieza realmente liberaría. Esto sucederá si está utilizando diferentes imágenes que comparten algunas capas.

OPCIONES

--format=formato

Imprimir imágenes de forma bonita usando una plantilla Go o JSON. Esta bandera no está permitida en combinación con --verbose

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Active Indica si el volumen está en uso
.RawReclaimable Tamaño bruto reclamable de cada Tipo
.RawSize Tamaño bruto de cada tipo
.Reclaimable Tamaño reclamable de cada tipo (legible por humanos)
.Size Tamaño de cada tipo (legible por humanos)
.Total Total de elementos para cada tipo
.Type Tipo de datos

--verbose, -v

Mostrar información detallada sobre el uso del espacio

EJEMPLO

Mostrar uso de disco:

$ podman system df
TIPO            TOTAL   ACTIVO  TAMAÑO    RECLAMABLE
Imágenes        6       2       281MB   168MB (59%)
Contenedores    3       1       0B      0B (0%)
Volúmenes Locales 1       1       22B     0B (0%)

Mostrar uso de disco en modo detallado:

$ podman system df -v

Mostrar solo el recuento total para cada tipo:

$ podman system df --format ""{{.Type}}\t{{.Total}}""
Imágenes          1
Contenedores      5
Volúmenes Locales 1

Mostrar uso de disco en formato JSON:

$ podman system df --format json
[
    {"Type":"Images","Total":12,"Active":3,"RawSize":13491151377,"RawReclaimable":922956674,"TotalCount":12,"Size":"13.49GB","Reclaimable":"923MB (7%)"},
    {"Type":"Containers","Total":4,"Active":0,"RawSize":209266,"RawReclaimable":209266,"TotalCount":4,"Size":"209.3kB","Reclaimable":"209.3kB (100%)"},
    {"Type":"Local Volumes","Total":6,"Active":1,"RawSize":796638905,"RawReclaimable":47800633,"TotalCount":6,"Size":"796.6MB","Reclaimable":"47.8MB (6%)"}
]

Mostrar tipo y tamaño en un formato personalizado:

$ podman system df --format ""{{.Type}}: {{.Size}} ({{.Reclaimable}} reclamable)""
Imágenes: 13.49GB (923MB (7%) reclamable)
Contenedores: 209.3kB (209.3kB (100%) reclamable)
Volúmenes Locales: 796.6MB (47.8MB (6%) reclamable)
