podman-save(1) Manual General de Comandos podman-save(1)

NOMBRE

podman-save - Guardar imagen(es) en un archivo

SINOPSIS

podman save [opciones] nombre[:etiqueta]

podman image save [opciones] nombre[:etiqueta]

DESCRIPCIÓN

podman save guarda una imagen en un archivo o directorio local. podman save escribe en STDOUT por defecto y puede ser redirigido a un archivo usando la opción output. La opción quiet suprime la salida cuando se activa. podman save guarda las capas padre de la(s) imagen(es) y la(s) imagen(es) pueden ser cargadas usando podman load. Para exportar los contenedores, usa podman export. Nota: : es un carácter restringido y no puede formar parte del nombre del archivo.

OPCIONES

--compress

Comprime las capas de imagen del archivo tar al enviarlas a un directorio usando el transporte 'dir'. (por defecto es el mismo tipo de compresión, comprimido o sin comprimir, que el origen)

Nota: Esta opción solo puede establecerse con --format=docker-dir.

--format=formato

Un formato de imagen a producir, uno de:

Formato Descripción
docker-archive Un archivo tar interoperable con docker load(1) (el valor por defecto)
oci-archive Un archivo tar usando el formato de imagen OCI
oci-dir Un directorio usando el formato de imagen OCI
docker-dir Transporte dir (ver containers-transports(5)) con tipo de manifiesto v2s2

--help, -h

Imprime el mensaje de uso

--multi-image-archive, -m

Permite la creación de archivos con más de una imagen. Los nombres adicionales se interpretan como imágenes en lugar de etiquetas. Solo soportado para --format=docker-archive. El valor por defecto para esta opción puede modificarse mediante el flag multi_image_archive="true"|"false" en containers.conf.

--output, -o=archivo

Escribe en un archivo, el valor por defecto es STDOUT

--quiet, -q

Suprime la salida

--uncompressed

Acepta capas sin comprimir al usar uno de los formatos OCI.

EJEMPLOS

Guarda la imagen en un archivo local sin mostrar el progreso.

$ podman save --quiet -o alpine.tar alpine:2.6

Guarda la imagen en stdout y redirige el contenido a través del shell.

$ podman save alpine > alpine-all.tar

Guarda la imagen en formato oci-archive en el archivo local.

$ podman save -o oci-alpine.tar --format oci-archive alpine

Guarda la imagen comprimida en formato docker-dir.

$ podman save --compress --format docker-dir -o alp-dir alpine
