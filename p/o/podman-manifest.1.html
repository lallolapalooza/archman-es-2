NOMBRE

podman-manifest - Crear y manipular listas de manifiestos e índices de imágenes

SINOPSIS

podman manifest subcomando

DESCRIPCIÓN

El comando podman manifest proporciona subcomandos que se pueden utilizar para:

* Crear una lista de manifiestos o un índice de imágenes de Docker en funcionamiento.

EJEMPLOS

Construcción de una lista de manifiestos multi-arquitectura a partir de un Containerfile

Suponiendo que las instrucciones RUN del Containerfile utilizan instrucciones, el host necesita una forma de ejecutar binarios no nativos. La configuración de esto está fuera del alcance de este ejemplo. La construcción de una lista de manifiestos multi-arquitectura shazam en paralelo en 4 hilos se puede hacer así:

    $ platarch=linux/amd64,linux/ppc64le,linux/arm64,linux/s390x
    $ podman build --jobs=4 --platform=$platarch --manifest shazam .

Nota: El argumento --jobs es opcional. No utilice la opción --tag (o -t) del comando podman build al construir una lista de manifiestos multi-arquitectura.

Ensamblaje de un manifiesto multi-arquitectura a partir de imágenes construidas por separado

Suponiendo que las imágenes example.com/example/shazam:$arch se construyen por separado en otros hosts y se empujan al registro example.com. Se pueden combinar en una lista de manifiestos y empujar usando un bucle simple:

    $ REPO=example.com/example/shazam
    $ podman manifest create $REPO:latest
    $ for IMGTAG in amd64 s390x ppc64le arm64; do   
              podman manifest add $REPO:latest docker://$REPO:IMGTAG;   
          done
    $ podman manifest push --all $REPO:latest

Nota: El orden de los argumentos de la instrucción add es <manifiesto> luego <imagen>. Además, la opción de empuje --all es necesaria para asegurar que se empujen todos los contenidos, no solo la plataforma/arquitectura nativa.

Eliminación y etiquetado de una lista de manifiestos antes de empujarla

Se necesita especial cuidado al eliminar y empujar listas de manifiestos, en contraposición a los contenidos. Casi siempre querrá usar los subcomandos manifest rm y manifest push --all. Por ejemplo, un cambio de nombre y un empuje se pueden realizar de la siguiente manera:

    $ podman tag localhost/shazam example.com/example/shazam
    $ podman manifest rm localhost/shazam
    $ podman manifest push --all example.com/example/shazam
