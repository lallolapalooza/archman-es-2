NOMBRE

podman-version - Muestra información de la versión de Podman

SINOPSIS

podman version [opciones]

DESCRIPCIÓN

Muestra la siguiente información: Versión de la API Remota, Versión, Versión de Go, Commit de Git, Hora de compilación, SO y Arquitectura.

OPCIONES

--format, -f=formato

Cambia el formato de salida a "json" o a una plantilla Go.

Marcador Descripción
.Client ... Versión del podman local
.Server ... Versión del podman remoto

Cada uno de los campos anteriores se ramifica en subcampos adicionales como .Version, .APIVersion, .GoVersion y más.

Ejemplo

Una salida de ejemplo del comando version:

$ podman version
Version:      2.0.0
API Version:  1
Go Version:   go1.14.2
Git Commit:   4520664f63c3a7f9a80227715359e20069d95542
Built:        Tue May 19 10:48:59 2020
OS/Arch:      linux/amd64

Filtrando solo la versión:

$ podman version --format '{{.Client.Version}}'
2.0.0

--help, -h

Imprime la declaración de uso
