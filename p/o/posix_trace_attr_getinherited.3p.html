POSIX_TRACE_ATTR_GETINHERITED(3P) Manual del programador POSIX POSIX_TRACE_ATTR_GETINHERITED(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_attr_getinherited, posix_trace_attr_getlogfullpolicy, posix_trace_attr_getstreamfullpolicy, posix_trace_attr_setinherited, posix_trace_attr_setlogfullpolicy, posix_trace_attr_setstreamfullpolicy — obtener y establecer el comportamiento de un flujo de rastreo (TRACING)

SINOPSIS

#include <trace.h>
int posix_trace_attr_getinherited(const trace_attr_t *restrict attr,
    int *restrict inheritancepolicy);
int posix_trace_attr_getlogfullpolicy(const trace_attr_t *restrict attr,
    int *restrict logpolicy);
int posix_trace_attr_getstreamfullpolicy(const trace_attr_t *restrict
    attr, int *restrict streampolicy);
int posix_trace_attr_setinherited(trace_attr_t *attr,
    int inheritancepolicy);
int posix_trace_attr_setlogfullpolicy(trace_attr_t *attr,
    int logpolicy);
int posix_trace_attr_setstreamfullpolicy(trace_attr_t *attr,
    int streampolicy);

DESCRIPCION

Las funciones posix_trace_attr_getinherited() y posix_trace_attr_setinherited() obtienen y establecen, respectivamente, la política de herencia almacenada en el atributo inheritance para los procesos rastreados en las operaciones fork() y spawn(). El atributo inheritance del objeto de atributos apuntado por el argumento attr se establecerá en uno de los siguientes valores definidos por constantes simbólicas en la cabecera <trace.h>:

POSIX_TRACE_CLOSE_FOR_CHILD

Después de una operación fork() o spawn(), el hijo no será rastreado y el rastreo del padre continuará.
POSIX_TRACE_INHERITED

Después de una operación fork() o spawn(), si el padre está siendo rastreado, su hijo será rastreado concurrentemente usando el mismo flujo de rastreo.

El valor predeterminado para el atributo inheritance es POSIX_TRACE_CLOSE_FOR_CHILD.

Las funciones posix_trace_attr_getlogfullpolicy() y posix_trace_attr_setlogfullpolicy() obtienen y establecen, respectivamente, la política de registro completo del registro de rastreo almacenada en el atributo log-full-policy del objeto de atributos apuntado por el argumento attr.

El atributo log-full-policy se establecerá en uno de los siguientes valores definidos por constantes simbólicas en la cabecera <trace.h>:

POSIX_TRACE_LOOP

El registro de rastreo se repetirá hasta que el flujo de rastreo asociado se detenga. Esta política significa que cuando el registro de rastreo se llena, el sistema de archivos reutilizará los recursos asignados a los eventos de rastreo más antiguos que se registraron. De esta manera, el registro de rastreo siempre contendrá los eventos de rastreo más recientes descargados.
POSIX_TRACE_UNTIL_FULL

El flujo de rastreo se descargará en el registro de rastreo hasta que el registro de rastreo esté lleno. Esta condición se puede deducir del estado del miembro posix_log_full_status (consulte la estructura posix_trace_status_info definida en <trace.h>). El último evento de rastreo registrado será el evento de rastreo POSIX_TRACE_STOP.
POSIX_TRACE_APPEND

El flujo de rastreo asociado se descargará en el registro de rastreo sin limitación de tamaño de registro. Si la aplicación especifica POSIX_TRACE_APPEND, la implementación ignorará el atributo log-max-size.

El valor predeterminado para el atributo log-full-policy es POSIX_TRACE_LOOP.

Las funciones posix_trace_attr_getstreamfullpolicy() y posix_trace_attr_setstreamfullpolicy() obtienen y establecen, respectivamente, la política de flujo de rastreo completo almacenada en el atributo stream-full-policy del objeto de atributos apuntado por el argumento attr.

El atributo stream-full-policy se establecerá en uno de los siguientes valores definidos por constantes simbólicas en la cabecera <trace.h>:

POSIX_TRACE_LOOP

El flujo de rastreo se repetirá hasta que se detenga explícitamente mediante la función posix_trace_stop(). Esta política significa que cuando el flujo de rastreo se llena, el sistema de rastreo reutilizará los recursos asignados a los eventos de rastreo más antiguos registrados. De esta manera, el flujo de rastreo siempre contendrá los eventos de rastreo más recientes registrados.
POSIX_TRACE_UNTIL_FULL

El flujo de rastreo se ejecutará hasta que se agoten los recursos del flujo de rastreo. Luego, el flujo de rastreo se detendrá. Esta condición se puede deducir de posix_stream_status y posix_stream_full_status (consulte la estructura posix_trace_status_info definida en <trace.h>). Cuando se lee este flujo de rastreo, se informará un evento de rastreo POSIX_TRACE_STOP después de informar el último evento de rastreo registrado. El sistema de rastreo reutilizará los recursos asignados a cualquier evento de rastreo ya informado —consulte las funciones posix_trace_getnext_event(), posix_trace_trygetnext_event() y posix_trace_timedgetnext_event()— o ya descargado para un flujo de rastreo activo con registro si la opción Registro de Rastreo es compatible; consulte la función posix_trace_flush(). El sistema de rastreo reiniciará el flujo de rastreo cuando esté vacío y puede reiniciarlo antes. Se informará un evento de rastreo POSIX_TRACE_START antes de informar el próximo evento de rastreo registrado.
POSIX_TRACE_FLUSH

Si la opción Registro de Rastreo es compatible, esta política es idéntica a la política de flujo de rastreo completo POSIX_TRACE_UNTIL_FULL, excepto que el flujo de rastreo se descargará regularmente como si se hubiera llamado explícitamente a posix_trace_flush(). Definir esta política para un flujo de rastreo activo sin registro será inválido.

El valor predeterminado para el atributo stream-full-policy será POSIX_TRACE_LOOP para un flujo de rastreo activo sin registro.

Si la opción Registro de Rastreo es compatible, el valor predeterminado para el atributo stream-full-policy será POSIX_TRACE_FLUSH para un flujo de rastreo activo con registro.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

Si se completa con éxito, la función posix_trace_attr_getinherited() almacenará el valor del atributo inheritance en el objeto apuntado por inheritancepolicy. De lo contrario, el contenido de este objeto es indefinido.

Si se completa con éxito, la función posix_trace_attr_getlogfullpolicy() almacenará el valor del atributo log-full-policy en el objeto apuntado por logpolicy. De lo contrario, el contenido de este objeto es indefinido.

Si se completa con éxito, la función posix_trace_attr_getstreamfullpolicy() almacenará el valor del atributo stream-full-policy en el objeto apuntado por streampolicy. De lo contrario, el contenido de este objeto es indefinido.

ERRORES

Estas funciones pueden fallar si:

EINVAL
El valor especificado por al menos uno de los argumentos no es válido.

NAME

posix_trace_attr_getinherited, posix_trace_attr_getlogfullpolicy, posix_trace_attr_getstreamfullpolicy, posix_trace_attr_setinherited, posix_trace_attr_setlogfullpolicy, posix_trace_attr_setstreamfullpolicy - query and set trace-event-id-related attributes

SYNOPSIS

```c
#include <trace.h>

int posix_trace_attr_getinherited(const posix_trace_attr_t *attr, int *inherited);
int posix_trace_attr_getlogfullpolicy(const posix_trace_attr_t *attr, int *policy);
int posix_trace_attr_getstreamfullpolicy(const posix_trace_attr_t *attr, int *policy);
int posix_trace_attr_setinherited(posix_trace_attr_t *attr, int inherited);
int posix_trace_attr_setlogfullpolicy(posix_trace_attr_t *attr, int policy);
int posix_trace_attr_setstreamfullpolicy(posix_trace_attr_t *attr, int policy);
```

DESCRIPTION

The value of the POSIX trace log size is determined by the posix_trace_attr_set_log_size() function. The trace log can be filled in a number of ways. This section describes how to query and set the policy for when the trace log becomes full.

The trace log attributes object is pointed to by attr.

The posix_trace_attr_getlogfullpolicy() function shall return the policy for when the trace log is full in the location referenced by the policy argument. The possible policies are:

POSIX_TRACE_LOG_FULL_HALT
The trace recording is stopped.
POSIX_TRACE_LOG_FULL_REPLACE
The oldest trace records are overwritten.

The posix_trace_attr_getstreamfullpolicy() function shall return the policy for when the trace stream is full in the location referenced by the policy argument. The possible policies are:

POSIX_TRACE_STREAM_FULL_HALT
The trace recording is stopped.
POSIX_TRACE_STREAM_FULL_REPLACE
The oldest trace records are overwritten.

The posix_trace_attr_setlogfullpolicy() function shall set the policy for when the trace log is full to the value specified by the policy argument. The policy argument must be one of the values defined above.

The posix_trace_attr_setstreamfullpolicy() function shall set the policy for when the trace stream is full to the value specified by the policy argument. The policy argument must be one of the values defined above.

The posix_trace_attr_getinherited() function shall return the inherited attribute for the trace attributes object in the location referenced by the inherited argument. The value returned is either 0 or 1.

The posix_trace_attr_setinherited() function shall set the inherited attribute for the trace attributes object to the value specified by the inherited argument. The inherited argument must be either 0 or 1.

RETURN VALUE

On success, these functions shall return 0.

On failure, they shall return a positive error number.

ERRORS

EINVAL
The value of attribute attr is invalid, or the value of policy or inherited is invalid.

ENOMEM
There was insufficient memory available to set the attribute.
