NOMBRE

podman-attach - Adjuntar a un contenedor en ejecución

SINOPSIS

podman attach [opciones] contenedor

podman container attach [opciones] contenedor

DESCRIPCIÓN

podman attach se adjunta a un contenedor en ejecución utilizando el nombre o ID del contenedor, ya sea para ver su salida continua o para controlarlo de forma interactiva.
Se puede desconectar el contenedor (dejándolo en ejecución) utilizando una secuencia de teclas configurable. La secuencia predeterminada es ctrl-p,ctrl-q. Configure la secuencia de teclas utilizando la OPCIÓN --detach-keys, o especificándola en el archivo containers.conf: vea containers.conf(5) para más información.

OPCIONES

--detach-keys=secuencia

Especifica la secuencia de teclas para desconectar un contenedor. El formato es un solo carácter [a-Z] o uno o más caracteres ctrl-<valor> donde <valor> es uno de: a-z, @, ^, [, , o _. Especificar "" deshabilita esta función. El valor predeterminado es ctrl-p,ctrl-q.

Esta opción también se puede configurar en el archivo containers.conf(5).

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--no-stdin

No adjuntar STDIN. El valor predeterminado es false.

--sig-proxy

Reenvía las señales recibidas al proceso del contenedor. SIGCHLD, SIGURG, SIGSTOP y SIGKILL no se reenvían.

El valor predeterminado es true.

EJEMPLOS

Adjuntar a un contenedor llamado "foobar".

$ podman attach foobar

Adjuntar al último contenedor creado. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman attach --latest

Adjuntar a un contenedor que comience con el ID "1234".

$ podman attach 1234

Adjuntar a un contenedor sin adjuntar STDIN.

$ podman attach --no-stdin foobar
