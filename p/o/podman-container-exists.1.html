NOMBRE

podman-container-exists - Comprueba si un contenedor existe en el almacenamiento local

SINOPSIS

podman container exists [opciones] contenedor

DESCRIPCIÓN

podman container exists comprueba si un contenedor existe en el almacenamiento local. Se utiliza el ID o nombre del contenedor como entrada. Podman devuelve un código de salida de **0** cuando se encuentra el contenedor. Se devuelve un **1** en caso contrario. Un código de salida de **125** indica que hubo un problema al acceder al almacenamiento local.

OPCIONES

--external

Comprueba también los contenedores externos además de los contenedores de Podman. Estos contenedores externos generalmente se crean a través de otra tecnología de contenedores como Buildah o CRI-O.
El valor predeterminado es **false**.

-h, --help

Muestra el mensaje de uso.
El valor predeterminado es **false**.

EJEMPLOS

Comprueba si un contenedor llamado "webclient" existe en el almacenamiento local. Aquí, el contenedor sí existe.

$ podman container exists webclient
$ echo $?
0

Comprueba si un contenedor llamado "webbackend" existe en el almacenamiento local. Aquí, el contenedor no existe.

$ podman container exists webbackend
$ echo $?
1

Comprueba si un contenedor llamado "ubi8-working-container" creado a través de Buildah existe en el almacenamiento local. Aquí, el contenedor no existe.

$ podman container exists --external ubi8-working-container
$ echo $?
1
