NOMBRE

podmansh - Ejecutar shell de inicio de sesión dentro del contenedor podmansh de Podman

SINOPSIS

podmansh

DESCRIPCIÓN

Ejecuta un shell de usuario dentro de un contenedor cuando el usuario inicia sesión en el sistema. El contenedor al que se añaden los usuarios se puede definir a través de un archivo Quadlet de Podman. Este usuario solo tiene acceso a los volúmenes y capacidades configurados en el archivo Quadlet.

Los administradores pueden crear un Quadlet en /etc/containers/systemd/users, que systemd iniciará para todos los usuarios cuando inicien sesión. El administrador puede crear un Quadlet específico con el nombre de contenedor podmansh, y luego permitir a los usuarios usar el shell de inicio de sesión /usr/bin/podmansh. Estos shells de inicio de sesión de usuario se ejecutan automáticamente dentro del contenedor podmansh a través de Podman.

Opcionalmente, el administrador puede colocar archivos Quadlet en el directorio /etc/containers/systemd/users/${UID} para un usuario. Solo este UID ejecutará estos servicios Quadlet cuando ese usuario inicie sesión.

El usuario está confinado al entorno del contenedor a través de todos los mecanismos de seguridad, incluido SELinux. La única información que estará disponible del sistema proviene de los volúmenes filtrados al contenedor.

Systemd creará automáticamente el contenedor cuando se inicie la sesión del usuario. Systemd detendrá el contenedor cuando se eliminen todas las conexiones a la sesión del usuario. Esto significa que los usuarios pueden iniciar sesión en el sistema varias veces, y cada sesión se conectará al mismo contenedor.

Los administradores pueden usar volúmenes para exponer datos específicos del host al usuario, sin que el usuario esté expuesto a otras partes del sistema.

El tiempo de espera para podmansh se puede establecer usando la opción podmansh_timeout en containers.conf.

Configuración

Cree una sesión de inicio de sesión de usuario usando useradd mientras se ejecuta como root.

# useradd -s /usr/bin/podmansh lockedu
# grep lockedu /etc/passwd
lockedu:x:4008:4008::/home/lockedu:/usr/bin/podmansh

Cree un archivo Podman Quadlet que se parezca a uno de los siguientes.

Contenedor completamente bloqueado, sin acceso al sistema operativo host.

# USERID=$(id -u lockedu)
# mkdir -p /etc/containers/systemd/users/${USERID}
# cat > /etc/containers/systemd/users/${USERID}/podmansh.container << _EOF
[Unit]
Description=The podmansh container
After=local-fs.target
[Container]
Image=registry.fedoraproject.org/fedora
ContainerName=podmansh
UserNS=keep-id
RunInit=yes
DropCapability=all
NoNewPrivileges=true
Exec=sleep infinity
[Install]
RequiredBy=default.target
_EOF

Alternativamente, mientras se ejecuta como root, cree un Quadlet donde al usuario se le permite convertirse en root dentro del espacio de nombres de usuario. También pueden leer/escribir permanentemente contenido de su directorio de inicio, que se monta como volumen desde la cuenta de usuario real del host, en lugar de estar dentro del contenedor.

# useradd -s /usr/bin/podmansh confinedu
# grep confinedu /etc/passwd
confinedu:x:4009:4009::/home/confinedu:/usr/bin/podmansh
# USERID=$(id -u confinedu)
# mkdir -p /etc/containers/systemd/users/${USERID}
# cat > /etc/containers/systemd/users/${USERID}/podmansh.container << _EOF
[Unit]
Description=The podmansh container
After=local-fs.target
[Container]
Image=registry.fedoraproject.org/fedora
ContainerName=podmansh
UserNS=keep-id
RunInit=yes
Volume=%h/data:%h:Z
Exec=sleep infinity
[Service]
ExecStartPre=/usr/bin/mkdir -p %h/data
[Install]
RequiredBy=default.target
_EOF

Otro ejemplo: mientras se ejecuta como root, cree un Quadlet donde a los usuarios dentro de este contenedor se les permite ejecutar contenedores con separación SELinux y pueden leer y escribir contenido en el directorio $HOME/data.

# useradd -s /usr/bin/podmansh fullu
# grep fullu /etc/passwd
fullu:x:4010:4010::/home/fullu:/usr/bin/podmansh
# USERID=$(id -u fullu)
# mkdir -p /etc/containers/systemd/users/${USERID}
# cat > /etc/containers/systemd/users/${USERID}/podmansh.container << _EOF
[Unit]
Description=The podmansh container
After=local-fs.target
[Container]
Image=registry.fedoraproject.org/fedora
ContainerName=podmansh
UserNS=keep-id
RunInit=yes
PodmanArgs=--security-opt=unmask=/sys/fs/selinux   
	--security-opt=label=nested   
	--security-opt=label=user:container_user_u   
	--security-opt=label=type:container_user_t   
	--security-opt=label=role:container_user_r   
	--security-opt=label=level:s0-s0:c0.c1023
Volume=%h/data:%h:Z
WorkingDir=%h
Volume=/sys/fs/selinux:/sys/fs/selinux
Exec=sleep infinity
[Service]
ExecStartPre=/usr/bin/mkdir -p %h/data
[Install]
RequiredBy=default.target
_EOF
