posix_memalign(3) Manual de funciones de la biblioteca posix_memalign(3)

NOMBRE

posix_memalign, aligned_alloc, memalign, valloc, pvalloc - asignar memoria alineada

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
int posix_memalign(void **memptr, size_t alignment, size_t size);
void *aligned_alloc(size_t alignment, size_t size);
[[deprecated]] void *valloc(size_t size);
#include <malloc.h>
[[deprecated]] void *memalign(size_t alignment, size_t size);
[[deprecated]] void *pvalloc(size_t size);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

posix_memalign():

    _POSIX_C_SOURCE >= 200112L

aligned_alloc():

    _ISOC11_SOURCE

valloc():

    Desde glibc 2.12:
        (_XOPEN_SOURCE >= 500) && !(_POSIX_C_SOURCE >= 200112L)
            || /* glibc >= 2.19: */ _DEFAULT_SOURCE
            || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE
    Antes de glibc 2.12:
        _BSD_SOURCE || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

posix_memalign() asigna size bytes y coloca la dirección de la memoria asignada en *memptr. La dirección de la memoria asignada será un múltiplo de alignment, que debe ser una potencia de dos y un múltiplo de sizeof(void *). Esta dirección puede pasarse posteriormente correctamente a free(3). Si size es 0, entonces el valor colocado en *memptr es NULL o un puntero único.

La función obsoleta memalign() asigna size bytes y devuelve un puntero a la memoria asignada. La dirección de la memoria será un múltiplo de alignment, que debe ser una potencia de dos.

aligned_alloc() es lo mismo que memalign(), excepto por la restricción adicional de que alignment debe ser una potencia de dos.

La función obsoleta valloc() asigna size bytes y devuelve un puntero a la memoria asignada. La dirección de la memoria será un múltiplo del tamaño de página. Es equivalente a memalign(sysconf(_SC_PAGESIZE),size).

La función obsoleta pvalloc() es similar a valloc(), pero redondea el tamaño de la asignación al siguiente múltiplo del tamaño de página del sistema.

Para todas estas funciones, la memoria no se pone a cero.

VALOR DE RETORNO

aligned_alloc(), memalign(), valloc() y pvalloc() devuelven un puntero a la memoria asignada en caso de éxito. En caso de error, se devuelve NULL y se establece errno para indicar el error.

posix_memalign() devuelve cero en caso de éxito, o uno de los valores de error listados en la siguiente sección en caso de fallo. El valor de errno no se establece. En Linux (y otros sistemas), posix_memalign() no modifica memptr en caso de fallo. Un requisito que estandariza este comportamiento se añadió en POSIX.1-2008 TC2.

ERRORES

EINVAL
El argumento alignment no era una potencia de dos, o no era un múltiplo de sizeof(void *).
ENOMEM
Sin memoria.

Cabeceras

Todos coinciden en que posix_memalign() se declara en <stdlib.h>.

En algunos sistemas, memalign() se declara en <stdlib.h> en lugar de <malloc.h>.

Según SUSv2, valloc() se declara en <stdlib.h>. glibc lo declara en <malloc.h>, y también en <stdlib.h> si se definen macros de prueba de características adecuadas (ver arriba).

NOTAS

En muchos sistemas existen restricciones de alineación, por ejemplo, en los búferes utilizados para E/S de bloques directos. POSIX especifica la llamada pathconf(path,_PC_REC_XFER_ALIGN) que indica qué alineación se necesita. Ahora se puede usar posix_memalign() para satisfacer este requisito.

posix_memalign() verifica que alignment cumpla con los requisitos detallados anteriormente. memalign() puede no comprobar que el argumento alignment sea correcto.

POSIX requiere que la memoria obtenida de posix_memalign() pueda ser liberada usando free(3). Algunos sistemas no proporcionan forma de recuperar memoria asignada con memalign() o valloc() (porque solo se puede pasar a free(3) un puntero obtenido de malloc(3), mientras que, por ejemplo, memalign() llamaría a malloc(3) y luego alinearía el valor obtenido). La implementación de glibc permite que la memoria obtenida de cualquiera de estas funciones sea recuperada con free(3).

El malloc(3) de glibc siempre devuelve direcciones de memoria alineadas de 8 bytes, por lo que estas funciones solo son necesarias si requiere valores de alineación mayores.
