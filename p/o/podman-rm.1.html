NOMBRE

podman-rm - Eliminar uno o más contenedores

SINOPSIS

podman rm [opciones] contenedor

podman container rm [opciones] contenedor

DESCRIPCIÓN

podman rm elimina uno o más contenedores del host. Se puede utilizar el nombre o la ID del contenedor. Esto no elimina imágenes. Los contenedores en ejecución o inutilizables no se eliminan sin la opción -f.

OPCIONES

--all, -a

Eliminar todos los contenedores. Se puede usar en conjunción con -f también.

--cidfile=archivo

Leer la ID del contenedor del archivo especificado y eliminar el contenedor. Se puede especificar varias veces.

El comando no falla cuando el archivo no existe y el usuario especificó --ignore.

--depend

Eliminar el contenedor seleccionado y eliminar recursivamente todos los contenedores que dependen de él.

--filter=filtro

Filtrar qué contenedores eliminar. Se pueden dar múltiples filtros utilizando varias veces la opción --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia parcial por prefijo de CID por defecto; acepta expresiones regulares)
name [Nombre] Nombre del contenedor (acepta expresiones regulares)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizada para crear el contenedor
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completa o parcial del pod
network [Red] nombre o ID completa de la red
until [DateTime] Contenedores creados antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--force, -f

Forzar la eliminación de contenedores en ejecución y pausados. Forzar la eliminación de un contenedor también elimina contenedores del almacén de contenedores incluso si el contenedor no es conocido por Podman. Por ejemplo, contenedores creados por otros motores de contenedores como Buildah. Además, se puede forzar para eliminar contenedores inutilizables, por ejemplo, contenedores cuyo runtime OCI se ha vuelto inaccesible.

--ignore, -i

Ignorar errores cuando los contenedores especificados no están en el almacén de contenedores. Un usuario podría haber decidido eliminar manualmente un contenedor, lo que lleva a un error durante la directiva ExecStop de un servicio systemd que hace referencia a ese contenedor.

Ignorar además cuando el --cidfile especificado no existe, ya que podría haber sido eliminado junto con el contenedor.

--latest, -l

En lugar de proporcionar el nombre o la ID del contenedor, usar el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--time, -t=segundos

Segundos a esperar antes de detener forzosamente el contenedor. Usar -1 para esperar indefinidamente.

Se debe especificar la opción --force para usar la opción --time.

--volumes, -v

Eliminar volúmenes anónimos asociados con el contenedor. Esto no incluye volúmenes nombrados creados con podman volume create, ni la opción --volume de podman run y podman create.

EJEMPLOS

Eliminar un contenedor con un nombre dado:

$ podman rm mi_servidor_web

Eliminar un contenedor con un nombre dado y todos los contenedores que dependen de él:

$ podman rm --depend mi_servidor_web

Eliminar múltiples contenedores con nombres o IDs dadas:

$ podman rm mi_servidor_web mi_servidor_flask 860a4b23

Eliminar múltiples contenedores con IDs leídas de archivos:

$ podman rm --cidfile ./cidfile-1 --cidfile /home/usuario/cidfile-2

Forzar la eliminación de un contenedor con una ID dada:

$ podman rm -f 860a4b23

Eliminar todos los contenedores independientemente de su estado de ejecución:

$ podman rm -f -a

Forzar la eliminación del último contenedor creado. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

$ podman rm -f --latest

Estado de Salida

0 Todos los contenedores especificados fueron eliminados

1 Uno de los contenedores especificados no existió, y no hubo otros fallos

2 Uno de los contenedores especificados está pausado o en ejecución

125 El comando falla por cualquier otra razón
