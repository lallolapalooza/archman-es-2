NOMBRE

podman-container-prune - Elimina todos los contenedores detenidos del almacenamiento local

SINOPSIS

podman container prune [opciones]

DESCRIPCIÓN

podman container prune elimina todos los contenedores detenidos del almacenamiento local.

OPCIONES

--filter=filtros

Proporciona valores de filtro.

El formato del argumento filtros es clave=valor. Si hay más de un filtro, pasa múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros admitidos:

Filtro Descripción
label Solo elimina contenedores, con (o sin, en el caso de que se use label!=[...] ) las etiquetas especificadas.
until Solo elimina contenedores creados antes de la marca de tiempo dada.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina contenedores con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina contenedores sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

--force, -f

No proporcione una indicación interactiva para la eliminación de contenedores.
El valor predeterminado es false.

-h, --help

Imprime la declaración de uso.
El valor predeterminado es false.
