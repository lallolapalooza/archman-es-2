POSIX_SPAWNATTR_SETSIGDEFAULT(3P) Manual del programador de POSIX POSIX_SPAWNATTR_SETSIGDEFAULT(3P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_spawnattr_setsigdefault — establecer el atributo spawn-sigdefault de un objeto de atributos de spawn (TIEMPO REAL AVANZADO)

SINOPSIS

#include <signal.h>
#include <spawn.h>
int posix_spawnattr_setsigdefault(posix_spawnattr_t *restrict attr,
    const sigset_t *restrict sigdefault);

DESCRIPCIÓN

Consulte posix_spawnattr_getsigdefault().
