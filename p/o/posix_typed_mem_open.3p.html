POSIX_TYPED_MEM_OPEN(3P) Manual pages del Programador de POSIX POSIX_TYPED_MEM_OPEN(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_typed_mem_open — abrir un objeto de memoria tipificada (TIEMPO REAL AVANZADO)

SINOPSIS

#include <sys/mman.h>
int posix_typed_mem_open(const char *name, int oflag, int tflag);

DESCRIPCIÓN

La función posix_typed_mem_open() establecerá una conexión entre el objeto de memoria tipificada especificado por la cadena apuntada por name y un descriptor de archivo. Creará una descripción de archivo abierta que se refiere al objeto de memoria tipificada y un descriptor de archivo que se refiere a esa descripción de archivo abierta. El descriptor de archivo se asignará según se describe en la Sección 2.14, Asignación de Descriptores de Archivo y podrá ser utilizado por otras funciones para referirse a ese objeto de memoria tipificada. Se desconoce si el nombre aparece en el sistema de archivos y es visible para otras funciones que toman rutas de acceso como argumentos. El argumento name se ajusta a las reglas de construcción para una ruta de acceso, excepto que la interpretación de los caracteres <barra> distintos de la barra <barra> inicial en name depende de la implementación, y que los límites de longitud para el argumento name dependen de la implementación y no necesitan ser los mismos que los límites de ruta {PATH_MAX} y {NAME_MAX}. Si name comienza con el carácter <barra>, los procesos que llamen a posix_typed_mem_open() con el mismo valor de name se referirán al mismo objeto de memoria tipificada. Si name no comienza con el carácter <barra>, el efecto depende de la implementación.

Cada objeto de memoria tipificada soportado en un sistema se identificará por un nombre que especifique no solo su grupo de memoria tipificada asociado, sino también la ruta o el puerto por el cual se accede a él. Es decir, el mismo grupo de memoria tipificada al que se accede a través de varios puertos diferentes tendrá varios nombres correspondientes diferentes. La vinculación entre nombres y objetos de memoria tipificada se establece de manera dependiente de la implementación. A diferencia de los objetos de memoria compartida, no hay forma dentro de POSIX.1-2008 para que un programa cree un objeto de memoria tipificada.

El valor de tflag determinará cómo se comporta el objeto de memoria tipificada cuando se mapea posteriormente mediante llamadas a mmap(). Como máximo, se puede especificar una de las siguientes banderas definidas en <sys/mman.h>:

POSIX_TYPED_MEM_ALLOCATE

Asignar en mmap().
POSIX_TYPED_MEM_ALLOCATE_CONTIG

Asignar de forma contigua en mmap().
POSIX_TYPED_MEM_MAP_ALLOCATABLE

Mapear en mmap(), sin afectar la asignabilidad.

Si tflag tiene la bandera POSIX_TYPED_MEM_ALLOCATE especificada, cualquier llamada posterior a mmap() utilizando el descriptor de archivo devuelto resultará en la asignación y el mapeo de memoria tipificada del grupo de memoria tipificada especificado. La memoria asignada puede ser un área contigua previamente no asignada del grupo de memoria tipificada o varias áreas contiguas previamente no asignadas (mapeadas a una porción contigua del espacio de direcciones del proceso). Si tflag tiene la bandera POSIX_TYPED_MEM_ALLOCATE_CONTIG especificada, cualquier llamada posterior a mmap() utilizando el descriptor de archivo devuelto resultará en la asignación y el mapeo de un área contigua única previamente no asignada del grupo de memoria tipificada (también mapeada a una porción contigua del espacio de direcciones del proceso). Si tflag no tiene ninguna de las banderas POSIX_TYPED_MEM_ALLOCATE o POSIX_TYPED_MEM_ALLOCATE_CONTIG especificadas, cualquier llamada posterior a mmap() utilizando el descriptor de archivo devuelto mapeará un área elegida por la aplicación del grupo de memoria tipificada especificado de tal manera que esta área mapeada se vuelva indisponible para la asignación hasta que sea desmapeada por todos los procesos. Si tflag tiene la bandera POSIX_TYPED_MEM_MAP_ALLOCATABLE especificada, cualquier llamada posterior a mmap() utilizando el descriptor de archivo devuelto mapeará un área elegida por la aplicación del grupo de memoria tipificada especificado sin afectar la disponibilidad de esa área para la asignación; es decir, mapear dicho objeto deja cada byte del área mapeada sin asignar si no estaba asignado antes del mapeo o asignado si estaba asignado antes del mapeo. Los privilegios apropiados para especificar la bandera POSIX_TYPED_MEM_MAP_ALLOCATABLE dependen de la implementación.

Si tiene éxito, posix_typed_mem_open() devolverá un descriptor de archivo para el objeto de memoria tipificada. La descripción de archivo abierta es nueva, y por lo tanto, el descriptor de archivo no la compartirá con ningún otro proceso. Se desconoce si se establece el desplazamiento del archivo. La bandera FD_CLOEXEC del descriptor de archivo asociada con el nuevo descriptor de archivo se borrará.

El comportamiento de msync(), ftruncate(), y todas las operaciones de archivo distintas de mmap(), posix_mem_offset(), posix_typed_mem_get_info(), fstat(), dup(), dup2(), y close(), se desconoce cuando se les pasa un descriptor de archivo conectado a un objeto de memoria tipificada por esta función.

Las banderas de estado del archivo de la descripción de archivo abierta se establecerán de acuerdo con el valor de oflag. Las aplicaciones especificarán exactamente una de las tres valores de modo de acceso descritos a continuación y definidos en la cabecera <fcntl.h>, como valor de oflag.

O_RDONLY
Abrir solo para acceso de lectura.
O_WRONLY
Abrir solo para acceso de escritura.
O_RDWR
Abrir para acceso de lectura o escritura.

VALOR DE RETORNO

Tras una finalización exitosa, la función posix_typed_mem_open() devolverá un entero no negativo que representa el descriptor de archivo. De lo contrario, devolverá -1 y establecerá errno para indicar el error.

ERRORES

La función posix_typed_mem_open() fallará si:

EACCES
El objeto de memoria tipificada existe y los permisos especificados por oflag son denegados.
EINTR
La operación posix_typed_mem_open() fue interrumpida por una señal.
EINVAL
Las banderas especificadas en tflag son inválidas (se especifica más de una de POSIX_TYPED_MEM_ALLOCATE, POSIX_TYPED_MEM_ALLOCATE_CONTIG o POSIX_TYPED_MEM_MAP_ALLOCATABLE).
EMFILE
Todos los descriptores de archivo disponibles para el proceso están actualmente abiertos.
ENFILE
Demasiados descriptores de archivo están actualmente abiertos en el sistema.
ENOENT
El objeto de memoria tipificada nombrado no existe.
EPERM
Al llamador le faltan los privilegios apropiados para especificar la bandera POSIX_TYPED_MEM_MAP_ALLOCATABLE en el argumento tflag.

La función posix_typed_mem_open() puede fallar si:

ENAMETOOLONG

La longitud del argumento name excede {_POSIX_PATH_MAX} en sistemas que no soportan la opción XSI o excede {_XOPEN_PATH_MAX} en sistemas XSI, o tiene un componente de ruta más largo que {_POSIX_NAME_MAX} en sistemas que no soportan la opción XSI o más largo que {_XOPEN_NAME_MAX} en sistemas XSI.
