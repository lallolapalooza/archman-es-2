subrutina cpotf2 (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CPOTF2 calcula la factorización de Cholesky de una matriz Hermitiana compleja definida positiva (algoritmo sin bloqueo).

Propósito:

!>
!> CPOTF2 calcula la factorización de Cholesky de una matriz compleja Hermitiana
!> positiva definida A.
!>
!> La factorización tiene la forma
!>    A = U**H * U ,  si UPLO = 'U', o
!>    A = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>
!> Esta es la versión sin bloqueo del algoritmo, que llama a BLAS de Nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la parte triangular superior o inferior de la
!>          matriz Hermitiana A está almacenada.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz Hermitiana A.  Si UPLO = 'U', la parte
!>          triangular superior de n x n principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior de n x n principal de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de Cholesky
!>          A = U**H *U  o A = L*L**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>          > 0: si INFO = k, el menor principal de orden k
!>               no es positivo, y la factorización no pudo completarse.
!>

NAME

spotf2, zpotf2 - compute the Cholesky factorization of a symmetric/Hermitian positive definite matrix (unblocked algorithm)

SYNOPSIS

    SUBROUTINE SPOTF2( UPLO, N, A, LDA, INFO )

    SUBROUTINE ZPOTF2( UPLO, N, A, LDA, INFO )

    CHARACTER UPLO
    INTEGER N, LDA, INFO
    REAL*4 A( LDA, * )  or  COMPLEX*16 A( LDA, * )

Purpose

SPOTF2 computes the Cholesky factorization of a real symmetric positive definite matrix A.

!>
!> SPOTF2 computes the Cholesky factorization of a real symmetric
!> positive definite matrix A.
!>
!> The factorization has the form
!>    A = U**T * U ,  if UPLO = 'U', or
!>    A = L  * L**T,  if UPLO = 'L',
!> where U is an upper triangular matrix and L is lower triangular.
!>
!> This is the unblocked version of the algorithm, calling Level 2 BLAS.
!>

ZPOTF2 computes the Cholesky factorization of a complex Hermitian positive definite matrix A.

!>
!> ZPOTF2 computes the Cholesky factorization of a complex Hermitian
!> positive definite matrix A.
!>
!> The factorization has the form
!>    A = U**H * U ,  if UPLO = 'U', or
!>    A = L  * L**H,  if UPLO = 'L',
!> where U is an upper triangular matrix and L is lower triangular.
!>
!> This is the unblocked version of the algorithm, calling Level 2 BLAS.
!>

Parameters

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric/Hermitian matrix A is stored.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL*4 or COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the symmetric/Hermitian matrix A.  If UPLO = 'U', the leading
!>          n by n upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading n by n lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>
!>          On exit, if INFO = 0, the factor U or L from the Cholesky
!>          factorization A = U**T *U  or A = L*L**T  (for SPOTF2)
!>          or A = U**H *U  or A = L*L**H (for ZPOTF2).
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>          > 0: if INFO = k, the leading principal minor of order k
!>               is not positive, and the factorization could not be
!>               completed.
!>
