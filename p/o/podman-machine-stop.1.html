NOMBRE

podman-machine-stop - Detener una máquina virtual

SINOPSIS

podman machine stop [nombre]

DESCRIPCIÓN

Detiene una máquina virtual.

El nombre de máquina predeterminado es podman-machine-default. Si no se especifica un nombre de máquina como argumento, se detendrá podman-machine-default.

Solo sin root.

Podman en MacOS y Windows requiere una máquina virtual. Esto se debe a que los contenedores son Linux; los contenedores no se ejecutan en ningún otro sistema operativo porque la funcionalidad principal de los contenedores está ligada al kernel de Linux. Se debe usar podman machine para administrar máquinas MacOS y Windows, pero se puede usar opcionalmente en Linux.

podman machine stop detiene una máquina virtual Linux donde se ejecutan los contenedores.

OPCIONES

--help

Imprime la declaración de uso.

EJEMPLOS

Detener una máquina podman llamada myvm.

$ podman machine stop myvm
