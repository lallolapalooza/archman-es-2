NOMBRE

podman-system-reset - Restablece el almacenamiento a su estado inicial

SINOPSIS

podman system reset [opciones]

DESCRIPCIÓN

podman system reset elimina todos los pods, contenedores, imágenes, redes y volúmenes, y máquinas. También elimina los directorios configurados graphRoot y runRoot. Asegúrese de que estos no estén configurados en algún directorio importante.

Este comando debe ejecutarse antes de modificar cualquiera de los siguientes campos en los archivos containers.conf o storage.conf: driver, static_dir, tmp_dir o volume_path.

podman system reset lee la configuración actual e intenta eliminar todas las configuraciones relevantes. Si el administrador modificó los archivos de configuración primero, es posible que podman system reset no pueda limpiar el almacenamiento anterior.

podman system reset no reinicia las unidades del sistema systemd podman.service y podman.socket. Es posible que necesite reiniciarla manualmente después de ejecutar este comando.

OPCIONES

--force, -f

No pida confirmación

--help, -h

Imprime el aviso de uso

EJEMPLOS

Restablece todo el almacenamiento a un estado inicial limpio.

$ podman system reset
ADVERTENCIA! Esto eliminará:
        - todos los contenedores
        - todos los pods
        - todas las imágenes
        - todas las redes
        - toda la caché de compilación
        - todas las máquinas
        - todos los volúmenes
        - el directorio graphRoot: /var/lib/containers/storage
        - el directorio runRoot: /run/containers/storage
¿Está seguro de que desea continuar? [y/N] y

Restablece forzadamente todo el almacenamiento a un estado inicial limpio.

$ podman system reset --force

Cambiar al usuario sin raíz del controlador VFS a overlay con fuse-overlayfs

Si el usuario ejecutó contenedores sin privilegios sin tener instalado el programa fuse-overlayfs, podman utiliza por defecto el almacenamiento vfs en su directorio de inicio. Si desean cambiar a fuse-overlay, deben instalar el paquete fuse-overlayfs. El usuario necesita restablecer el almacenamiento para usar overlayfs por defecto. Ejecute podman system reset como el usuario primero para eliminar el almacenamiento VFS. Ahora el usuario puede editar el archivo /etc/containers/storage.conf para realizar los cambios necesarios. Si la configuración predeterminada del sistema ya era overlay, entonces no se necesitan cambios para cambiar a fuse-overlayfs. Podman busca la existencia de fuse-overlayfs para usarlo cuando se establece en el controlador overlay, y solo recurre a vfs si el programa no existe. Los usuarios pueden ejecutar podman info para asegurarse de que Podman está usando fuse-overlayfs y el controlador overlay.
