NOMBRE

podman healthcheck run - Ejecuta una comprobación de estado de contenedor

SINOPSIS

podman healthcheck run contenedor

DESCRIPCIÓN

Ejecuta manualmente el comando de comprobación de estado definido en un contenedor en ejecución. Los códigos de error resultantes se definen de la siguiente manera:

  • 0 = el comando de comprobación de estado se completó correctamente
  • 1 = el comando de comprobación de estado falló
  • 125 = ha ocurrido un error

Los posibles errores que pueden ocurrir durante la comprobación de estado son: * no se puede encontrar el contenedor * el contenedor no tiene una comprobación de estado definida * el contenedor no está en ejecución

OPCIONES

--help

Imprime la declaración de uso

EJEMPLOS

Ejecuta comprobaciones de estado en el contenedor especificado:

$ podman healthcheck run miaplicacionweb

VER TAMBIÉN
