CPOSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!> CPOSVX utiliza la factorización de Cholesky A = U**H*U o A = L*L**H para
!> calcular la solución de un sistema complejo de ecuaciones lineales
!>    A * X = B,
!> donde A es una matriz Hermitiana positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan límites de error en la solución y una estimación
!> de condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Si el sistema se equilibrará o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrio, A se sobrescribe con diag(S)*A*diag(S)
!>    y B con diag(S)*B.
!>
!> 2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrio si FACT = 'E') como
!>       A = U**H* U,  si UPLO = 'U', o
!>       A = L * L**H,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!> 3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina regresa con INFO = i. De lo contrario, la forma
!>    factorizada de A se utiliza para estimar el número de condición de la
!>    matriz A. Si la inversa del número de condición es menor que la
!>    precisión de la máquina, INFO = N+1 se devuelve como una advertencia,
!>    pero la rutina aún continúa resolviendo X y calculando los límites de
!>    error como se describe a continuación.
!>
!> 4. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 5. Se aplica refinamiento iterativo para mejorar la solución calculada
!>    y calcular límites de error y estimaciones de error hacia atrás para
!>    ella.
!>
!> 6. Si se utilizó el equilibrio, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes
!>    del equilibrio.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz A se
!>          suministra en la entrada, y si no, si la matriz A debe ser
!>          equilibrada antes de ser factorizada.
!>          = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>                  Si EQUED = 'Y', la matriz A ha sido equilibrada
!>                  con factores de escala dados por S.  A y AF no
!>                  se modificarán.
!>          = 'N':  La matriz A se copiará a AF y se factorizará.
!>          = 'E':  La matriz A se equilibrará si es necesario, luego
!>                  se copiará a AF y se factorizará.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  La parte triangular superior de A está almacenada;
!>          = 'L':  La parte triangular inferior de A está almacenada.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de

!>

NRHS

!>          NRHS es INTEGER

!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es una matriz COMPLEX, dimensión (LDAF,N)
!>          Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>          contiene el factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, en el mismo formato de almacenamiento
!>          que A.  Si EQUED .ne. 'N', entonces AF es la forma factorizada

!>
!>          Si FACT = 'N', entonces AF es un argumento de salida y en la salida

PURPOSE

The purpose of this subroutine is to compute the solution to a system of linear equations A * X = B for PO matrices.

POSVX uses the Cholesky factorization A = U**T*U (or A = L*L**T) to compute the solution to a real system of linear equations A * X = B, where A is an N-by-N symmetric positive definite matrix and X and B are N-by-NRHS matrices.

Error bounds on the solution and a condition estimate are also provided.

The subroutine `CPOSVX` solves a complex system, while `IPOSVX` solves a system with integer entries.

DESCRIPTION

The following steps are performed:

  1. If FACT = 'E', real scaling factors are computed to equilibrate the system:

    diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B

    Whether or not the system will be equilibrated depends on the scaling of the matrix A, but if equilibration is used, A is overwritten by diag(S)*A*diag(S) and B by diag(S)*B.

  2. If FACT = 'N' or 'E', the Cholesky decomposition is used to factor the matrix A (after equilibration if FACT = 'E') as

    A = U**T* U, if UPLO = 'U', or

    A = L * L**T, if UPLO = 'L',

    where U is an upper triangular matrix and L is a lower triangular matrix.

  3. If the leading principal minor of order i is not positive, then the routine returns with INFO = i. Otherwise, the factored form of A is used to estimate the condition number of the matrix A. If the reciprocal of the condition number is less than machine precision, INFO = N+1 is returned as a warning, but the routine still goes on to solve for X and compute error bounds as described below.

  4. The system of equations is solved for X using the factored form of A.

  5. Iterative refinement is applied to improve the computed solution matrix and calculate error bounds and backward error estimates for it.

  6. If equilibration was used, the matrix X is premultiplied by diag(S) so that it solves the original system before equilibration.

PARAMETERS

FACT

CHARACTER*1. Specifies whether or not the factored form of the matrix A is supplied on entry, and if not, whether the matrix A should be equilibrated before it is factored.

Possible values:

'F': On entry, AF contains the factored form of A. If EQUED = 'Y', the matrix A has been equilibrated with scaling factors given by S. A and AF will not be modified.

'N': The matrix A will be copied to AF and factored.

'E': The matrix A will be equilibrated if necessary, then copied to AF and factored.

UPLO

CHARACTER*1. Indicates whether the upper or lower triangular part of the matrix A is stored.

'U': Upper triangle of A is stored.

'L': Lower triangle of A is stored.

N

INTEGER. The number of linear equations, i.e., the order of the matrix A. N >= 0.

NRHS

INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.

A

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (LDA,N).

On entry, the symmetric matrix A, except if FACT = 'F' and EQUED = 'Y', then A must contain the equilibrated matrix diag(S)*A*diag(S). If UPLO = 'U', the leading N-by-N upper triangular part of A contains the upper triangular part of the matrix A, and the strictly lower triangular part of A is not referenced. If UPLO = 'L', the leading N-by-N lower triangular part of A contains the lower triangular part of the matrix A, and the strictly upper triangular part of A is not referenced. A is not modified if FACT = 'F' or 'N', or if FACT = 'E' and EQUED = 'N' on exit.

On exit, if FACT = 'E' and EQUED = 'Y', A is overwritten by diag(S)*A*diag(S).

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,N).

AF

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (LDAF,N).

If FACT = 'F', then AF is an input argument and on entry contains the triangular factor U or L from the Cholesky factorization A = U**T*U or A = L*L**T, in the same storage format as A. If EQUED .ne. 'N', then AF is the factored form of the equilibrated matrix diag(S)*A*diag(S).

If FACT = 'N', then AF is an output argument and on exit returns the triangular factor U or L from the Cholesky factorization A = U**T*U or A = L*L**T of the original matrix A.

If FACT = 'E', then AF is an output argument and on exit returns the triangular factor U or L from the Cholesky factorization A = U**T*U or A = L*L**T of the equilibrated matrix A (see the description of A for the form of the equilibrated matrix).

LDAF

INTEGER. The leading dimension of the array AF. LDAF >= max(1,N).

EQUED

CHARACTER*1. Specifies the form of equilibration that was done.

'N': No equilibration (always true if FACT = 'N').

'Y': Equilibration was done, i.e., A has been replaced by diag(S) * A * diag(S).

EQUED is an input argument if FACT = 'F'; otherwise, it is an output argument.

S

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (N).

The scale factors for A; not accessed if EQUED = 'N'. S is an input argument if FACT = 'F'; otherwise, S is an output argument.

B

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (LDB,NRHS).

On entry, the N-by-NRHS righthand side matrix B.

On exit, if EQUED = 'Y', B is overwritten by diag(S) * B.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1,N).

X

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (LDX,NRHS).

If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to the original system of equations. Note that if EQUED = 'Y', A and B are modified on exit, and the solution to the equilibrated system is inv(diag(S))*X.

LDX

INTEGER. The leading dimension of the array X. LDX >= max(1,N).

RCOND

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX). The estimate of the reciprocal condition number of the matrix A after equilibration (if done). If RCOND is less than the machine precision (in particular, if RCOND = 0), the matrix is singular to working precision. This condition is indicated by a return code of INFO > 0.

FERR

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (NRHS).

The estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.

BERR

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (NRHS).

The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).

WORK

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (N) or (2*N).

SPOSVX: WORK(N)

DPOSVX: WORK(2*N)

CPOSVX: WORK(N)

IPOSVX: WORK(N)

Note the difference in dimension for DPOSVX.

RWORK

REAL (SPOSVX), DOUBLE PRECISION (DPOSVX), COMPLEX (CPOSVX), INTEGER (IPOSVX) array, dimension (N).

Note that `CPOSVX` and `IPOSVX` use REAL for `RWORK`.

IWORK

INTEGER array, dimension (N). Used by `DPOSVX` and `CPOSVX`.

INFO

INTEGER.

0: Successful exit.

< 0: If INFO = -i, the i-th argument had an illegal value.

> 0: If INFO = i, and i is

<= N: The leading principal minor of order i of A is not positive, so the factorization could not be completed, and the solution has not been computed. RCOND = 0 is returned.

= N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.

NAME

sposvx - ZPOSVX computes the solution to system of linear equations A * X = B for PO matrices

SYNOPSIS

SUBROUTINE SPOSVX(FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, EQUED, S, B, LDB, X, LDX, RCOND, FERR, BERR, WORK, IWORK, INFO)

CHARACTER(1) FACT, UPLO, EQUED
INTEGER N, NRHS, LDA, LDAF, LDB, LDX, INFO
REAL A(LDA, *), AF(LDAF, *), S(*), B(LDB, *), X(LDX, *), FERR(*), BERR(*), WORK(*)
INTEGER IWORK(*)

DESCRIPTION

The subroutine SPOSVX uses the Cholesky factorization A = UTU or A = LLT to compute the solution to a real system of linear equations:

   A * X = B

where A is an N-by-N symmetric positive definite matrix and X and B are N-by-NRHS matrices. Error bounds on the solution and a condition estimate are also provided.

The following steps are performed:

  1. If FACT = 'E', real scaling factors are computed to equilibrate the system: 
       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B

    Whether or not the system will be equilibrated depends on the scaling of the matrix A, but if equilibration is used, A is overwritten by diag(S)*A*diag(S) and B by diag(S)*B.

  2. If FACT = 'N' or 'E', the Cholesky decomposition is used to factor the matrix A (after equilibration if FACT = 'E') as 
       A = UTU,  if UPLO = 'U', or
   A = LLT,  if UPLO = 'L',

    where U is an upper triangular matrix and L is a lower triangular matrix.

  3. If the leading principal minor of order i is not positive, then the routine returns with INFO = i. Otherwise, the factored form of A is used to estimate the condition number of the matrix A. If the reciprocal of the condition number is less than machine epsilon, INFO = N+1 is returned as a warning, but the routine still goes on to solve for X and compute error bounds as described below.
  4. The system of equations is solved for X using the factored form of A.
  5. Iterative refinement is applied to improve the computed solution matrix and calculate error bounds and backward error estimates for it.
  6. If equilibration was used, the matrix X is premultiplied by diag(S) so that it solves the original system before equilibration.

Detailed Description

ZPOSVX is a double-precision complex subroutine to compute the solution to a complex system of linear equations A*X = B, where A is an n-by-n symmetric positive definite (Hermitian positive definite) matrix, optionally preconditioned using the diagonal matrix S, and X and B are n-by-rhs matrices.

This subroutine is called by the routines `zpgsvx`, `zpsvx`, `ztrsvx`, and `zssvx`.

Approximate condition number estimation is computed by the routine.

Option 

     FACT    CHARACTER*1.
             Specifies whether or not the factored form of the matrix A is
             provided on entry.
             = 'E':  On entry, AF contains the factored form of A.
                     A and AF may be modified on exit, and are not modified
                     if FACT = 'E'.
             = 'N':  On entry, A is the n-by-n coefficient matrix.  If FACT =
                     'N', the routine must first compute the factorizatio
                     of A and store it in AF.

B 

     B       COMPLEX*16 array, dimension (LDB,NRHS)
             On entry, the N-by-NRHS righthand side matrix B.
             On exit, if EQUED = 'N', B is not modified; if EQUED = 'Y',
             B is overwritten by diag(S) * B.

LDB 

     LDB     INTEGER
             The leading dimension of the array B.  LDB >= max(1,N).

X 

     X       COMPLEX*16 array, dimension (LDX,NRHS)
             If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to
             the original system of equations.  Note that if EQUED = 'Y',
             A and B are modified on exit, and the solution to the
             equilibrated system is inv(diag(S))*X.

LDX 

     LDX     INTEGER
             The leading dimension of the array X.  LDX >= max(1,N).

RCOND

             A after equilibration (if done).  If RCOND is less than the
             machine precision (in particular, if RCOND = 0), the matrix
             is singular to working precision.  This condition is
             indicated by a return code of INFO > 0.
