PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_eventset_add, posix_trace_eventset_del, posix_trace_eventset_empty, posix_trace_eventset_fill, posix_trace_eventset_ismember — manipular conjuntos de tipos de eventos de rastreo (TRACING)

SINOPSIS

#include <trace.h>
int posix_trace_eventset_add(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_del(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_empty(trace_event_set_t *set);
int posix_trace_eventset_fill(trace_event_set_t *set, int what);
int posix_trace_eventset_ismember(trace_event_id_t event_id,
    const trace_event_set_t *restrict set, int *restrict ismember);

DESCRIPCIÓN

Estas primitivas manipulan conjuntos de tipos de eventos de rastreo. Operan sobre objetos de datos accesibles por la aplicación, no sobre el filtro de eventos de rastreo actual de ningún flujo de rastreo.

Las funciones posix_trace_eventset_add() y posix_trace_eventset_del() añaden o eliminan, respectivamente, el tipo de evento de rastreo individual especificado por el valor del argumento event_id al conjunto de tipos de eventos de rastreo apuntado por el argumento set, o lo eliminan de él. Añadir un tipo de evento de rastreo que ya está en el conjunto o eliminar un tipo de evento de rastreo que no está en el conjunto no se considerará un error.

La función posix_trace_eventset_empty() inicializará el conjunto de tipos de eventos de rastreo apuntado por el argumento set de tal manera que todos los tipos de eventos de rastreo definidos, tanto del sistema como del usuario, queden excluidos del conjunto.

La función posix_trace_eventset_fill() inicializará el conjunto de tipos de eventos de rastreo apuntado por el argumento set, de tal manera que el conjunto de tipos de eventos de rastreo definidos por el argumento what se incluya en el conjunto. El valor del argumento what consistirá en uno de los siguientes valores, tal como se define en la cabecera <trace.h>:

POSIX_TRACE_WOPID_EVENTS

Se incluyen en el conjunto todos los tipos de eventos de rastreo del sistema definidos por la implementación y dependientes de la misma, que no están asociados a un PID.
POSIX_TRACE_SYSTEM_EVENTS

Se incluyen en el conjunto todos los tipos de eventos de rastreo del sistema definidos por la implementación, así como los definidos en POSIX.1‐2008.
POSIX_TRACE_ALL_EVENTS

Se incluyen en el conjunto todos los tipos de eventos de rastreo definidos, tanto del sistema como del usuario.

Las aplicaciones deben llamar a posix_trace_eventset_empty() o posix_trace_eventset_fill() al menos una vez para cada objeto de tipo trace_event_set_t antes de cualquier otro uso de dicho objeto. Si dicho objeto no se inicializa de esta manera, pero se proporciona como argumento a alguna de las funciones posix_trace_eventset_add(), posix_trace_eventset_del() o posix_trace_eventset_ismember(), los resultados no están definidos.

La función posix_trace_eventset_ismember() comprobará si el tipo de evento de rastreo especificado por el valor del argumento event_id es miembro del conjunto apuntado por el argumento set. El valor devuelto en el objeto apuntado por el argumento ismember es cero si el identificador del tipo de evento de rastreo no es miembro del conjunto y un valor distinto de cero si es miembro del conjunto.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

ERRORES

Estas funciones pueden fallar si:

EINVAL
El valor de uno de los argumentos es inválido.

NAME

posix_trace_eventset_add - añadir un evento a un conjunto de eventos de traza POSIX

SYNOPSIS


#include <trace.h>

int posix_trace_eventset_add(posix_trace_event_set_t *set,
       trace_event_id_t event_id);

DESCRIPTION

La función posix_trace_eventset_add() añade el identificador de evento event_id al conjunto de eventos de traza especificado por set.

Si event_id ya está presente en el conjunto set, la función no hace nada.

Los identificadores de evento válidos son aquellos definidos por el estándar POSIX.1-2001, y aquellos que no están en el rango de eventos de implementación definidos por <trace.h>.

El conjunto de eventos de traza set debe haber sido inicializado previamente usando posix_trace_event_set_alloc() o posix_trace_event_set_init().

RETURN VALUE

Al éxito, posix_trace_eventset_add() devuelve 0.

En caso de error, devuelve un número de error distinto de cero.

ERRORS

EINVAL
El argumento set es NULL, o event_id no es un identificador de evento válido.
ENOMEM
No hay suficiente memoria disponible para expandir el conjunto de eventos.

EXAMPLES

Añadiendo un evento a un conjunto de eventos:


#include <trace.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    posix_trace_event_set_t *event_set;
    int ret;

    // Inicializar un conjunto de eventos
    ret = posix_trace_event_set_alloc(&event_set);
    if (ret != 0) {
        perror("posix_trace_event_set_alloc");
        exit(EXIT_FAILURE);
    }

    // Añadir un evento (ejemplo: evento de creación de proceso)
    // El identificador real puede variar, consulta la documentación de tu sistema.
    // Aquí usamos un identificador genérico como ejemplo.
    trace_event_id_t process_create_event = 0x10; // Ejemplo de ID

    ret = posix_trace_eventset_add(event_set, process_create_event);
    if (ret != 0) {
        fprintf(stderr, "Error al añadir evento al conjunto: %d\n", ret);
        // Limpiar el conjunto si es necesario
        // posix_trace_event_set_free(event_set);
        exit(EXIT_FAILURE);
    }

    printf("Evento añadido con éxito al conjunto.\n");

    // ... usar el conjunto de eventos para la traza ...

    // Liberar el conjunto de eventos
    // posix_trace_event_set_free(event_set);

    return 0;
}
