NOMBRE

podman-pod-stop - Detener uno o más pods

SINOPSIS

podman pod stop [opciones] pod ...

DESCRIPCIÓN

Detiene los contenedores de uno o más pods. Puede usar IDs o nombres de pod como entrada.

OPCIONES

--all, -a

Detiene todos los pods

--ignore, -i

Ignora errores cuando los pods especificados no se encuentran en el almacén de contenedores. Un usuario podría haber decidido eliminar manualmente un pod, lo que genera un error durante la directiva ExecStop de un servicio systemd que hace referencia a ese pod.

--latest, -l

En lugar de proporcionar el nombre o ID del pod, usa el último pod creado. Nota: el último pod iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--pod-id-file=archivo

Lee el ID del pod del archivo especificado y detiene el pod. Se puede especificar varias veces.

--time, -t=segundos

Segundos para esperar antes de detener forzosamente los contenedores en ejecución dentro del pod. Usa -1 para espera infinita.

EJEMPLO

Detener un pod con un nombre dado.

$ podman pod stop mywebserverpod
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Detener varios pods con IDs dados.

$ podman pod stop 490eb 3557fb
490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab

Detener el último pod creado. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman pod stop --latest
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab

Detener todos los pods.

$ podman pod stop --all
19456b4cd557eaf9629825113a552681a6013f8c8cad258e36ab825ef536e818
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab
490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
70c358daecf71ef9be8f62404f926080ca0133277ef7ce4f6aa2d5af6bb2d3e9
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Detener dos pods a través de --pod-id-file.

$ podman pod stop --pod-id-file file1 --pod-id-file file2
19456b4cd557eaf9629825113a552681a6013f8c8cad258e36ab825ef536e818
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Detener todos los pods con un tiempo de espera de 1 segundo.

$ podman pod stop -a -t 1
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab
490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
