POSIX_SPAWNATTR_GETSCHEDPOLICY(3P) Manual del Programador de POSIX POSIX_SPAWNATTR_GETSCHEDPOLICY(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_spawnattr_getschedpolicy, posix_spawnattr_setschedpolicy — obtener y establecer el atributo spawn-schedpolicy de un objeto de atributos de spawn (TIEMPO REAL AVANZADO)

SINOPSIS

#include <spawn.h>
#include <sched.h>
int posix_spawnattr_getschedpolicy(const posix_spawnattr_t
    *restrict attr, int *restrict schedpolicy);
int posix_spawnattr_setschedpolicy(posix_spawnattr_t *attr,
    int schedpolicy);

DESCRIPCIÓN

La función posix_spawnattr_getschedpolicy() obtendrá el valor del atributo spawn-schedpolicy del objeto de atributos referenciado por attr.

La función posix_spawnattr_setschedpolicy() establecerá el atributo spawn-schedpolicy en un objeto de atributos inicializado referenciado por attr.

El atributo spawn-schedpolicy representa la política de planificación que se asignará a la nueva imagen de proceso en una operación de spawn (si POSIX_SPAWN_SETSCHEDULER está establecido en el atributo spawn-flags). El valor predeterminado de este atributo no está especificado.

VALOR DEVUELTO

Al completarse con éxito, posix_spawnattr_getschedpolicy() devolverá cero y almacenará el valor del atributo spawn-schedpolicy de attr en el objeto referenciado por el parámetro schedpolicy; de lo contrario, se devolverá un número de error para indicar el error.

Al completarse con éxito, posix_spawnattr_setschedpolicy() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones pueden fallar si:

EINVAL
El valor especificado por attr es inválido.

La función posix_spawnattr_setschedpolicy() puede fallar si:

EINVAL
El valor del atributo que se está estableciendo no es válido.
