NOMBRE

powerline-config - Script utilizado para obtener la configuración de powerline.

SINOPSIS

powerline-config [-pRUTA]… tmux ACCIÓN ( [-s |n )]
powerline-config [-pRUTA]… shell ACCIÓN [COMPONENTE] [-sSHELL]

DESCRIPCIÓN

-p, --config-path RUTA
Ruta al directorio de configuración. Si está presente, los archivos de configuración solo se buscarán en la ruta proporcionada. Puede ser proporcionada múltiples veces para buscar en una lista de directorios.
-h, --help
Muestra la ayuda y sale.

Argumentos específicos del subcomando tmux

ACCIÓN
Si la acción es source, se incluyen los archivos de configuración de tmux específicos de la versión; si es setenv, las variables de entorno globales especiales de tmux (precedidas por _POWERLINE) se llenan con datos de la configuración de powerline. La acción setup simplemente realiza setenv y luego source.
-s, --source
Al usar setup: usar siempre la inclusión de archivos de configuración. Por defecto, esto se determina automáticamente según la versión de tmux: este es el comportamiento predeterminado para tmux 1.8 y anteriores.
-n, --no-source
Al usar setup: en lugar de incluir directamente, ejecutar los archivos de configuración. Es decir, leer cada archivo de configuración específico de powerline necesario, sustituir las variables $_POWERLINE_… con los valores apropiados y ejecutar tmux config line. Este es el comportamiento predeterminado para tmux 1.9 y posteriores.
-h, --help
Muestra la ayuda y sale.

Argumentos específicos del subcomando shell

ACCIÓN
Si la acción es command, se emite el comando preferido de powerline; si es uses, el script powerline-config saldrá con 1 si el componente especificado está deshabilitado y con 0 en caso contrario.
COMPONENTE
Solo aplicable para el subcomando uses: hace que powerline-config salga con 0 si un componente específico está habilitado y con 1 en caso contrario. El componente tmux se refiere a las vinculaciones de tmux (por ejemplo, aquellas que notifican a tmux sobre los cambios en el directorio actual), el componente prompt se refiere al prompt del shell.
-s, --shell SHELL
Shell para el cual se ejecuta la consulta.
-h, --help
Muestra la ayuda y sale.
