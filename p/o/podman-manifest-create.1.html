NOMBRE

podman-manifest-create - Crear una lista de manifiestos o un índice de imágenes

SINOPSIS

podman manifest create [opciones] nombre_lista_o_indice [nombre_imagen ...]

DESCRIPCIÓN

Crea una nueva lista de manifiestos y la almacena como una imagen en el almacenamiento local utilizando el nombre especificado.

Si se especifican imágenes adicionales, se añaden a la lista o índice recién creados.

OPCIONES

--all

Si alguna de las imágenes añadidas a la nueva lista o índice son ellas mismas listas o índices, añade todos sus contenidos. Por defecto, solo se añade una imagen de dicha lista a la lista o índice recién creados.

--amend, -a

Si ya existe una lista de manifiestos llamada nombre_lista_o_indice, modifica la lista preexistente en lugar de salir con un error. Los contenidos de nombre_lista_o_indice no se modifican si no se proporcionan *nombre_imagen*s.

--annotation=valor

Establece una anotación en el índice de imágenes recién creado.

--tls-verify

Requiere HTTPS y verifica los certificados al contactar con los registros (por defecto: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino esté listado como un registro inseguro en containers-registries.conf(5)

EJEMPLOS

Crea el manifiesto especificado.

podman manifest create mylist:v1.11
9cfd24048d5fc80903f088f1531a21bff01172abe66effa8941a4c2308dc745f

Crea el manifiesto especificado o lo modifica si existía previamente.

podman manifest create --amend mylist:v1.11
9cfd24048d5fc80903f088f1531a21bff01172abe66effa8941a4c2308dc745f

Crea el manifiesto nombrado incluyendo la imagen especificada que coincide con la plataforma actual.

podman manifest create mylist:v1.11 docker://fedora
5c2bc76bfb4ba6665a7973f7e1c05ee0536b4580637f27adc9fa5a4b2bc03cf1

Crea el manifiesto nombrado incluyendo todas las imágenes referenciadas con la referencia de imagen especificada.

podman manifest create --all mylist:v1.11 docker://fedora
30330571e79c65288a4fca421d9aed29b0210d57294d9c2056743fdcf6e3967b
