Paquete: po4a

Licencias: GPL

PO4A-DISPLAY-POD(1) Herramientas Po4a PO4A-DISPLAY-POD(1)

NOMBRE

po4a-display-pod - visualización de un archivo POD traducido según un PO

SINOPSIS

po4a-display-pod -p  ARCHIVO_PO -m  ARCHIVO_POD [-o  PO4A_OPT]

DESCRIPCIÓN

Los traductores pueden usar po4a-display-pod para ver cómo se renderizará su traducción de una página de manual a los usuarios finales, sin tener que recompilar e reinstalar todo el proyecto. La mayor parte del tiempo, el archivo POD solo está disponible en el paquete fuente o incrustado en el script Perl.

OPCIONES

-p ARCHIVO_PO

El archivo PO que contiene las traducciones.

-m ARCHIVO_POD

El archivo POD original utilizado por po4a para generar el archivo PO.

-o PO4A_OPT

Algunas opciones para pasar a po4a-translate(1).

VER TAMBIÉN
