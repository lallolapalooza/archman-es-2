POWERCOM(8) Manual de NUT POWERCOM(8)

NOMBRE

powercom - controlador de SAI para equipos de SAI Powercom/Trust/Advice serie

SINOPSIS

powercom -h

powercom -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador powercom. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este controlador soporta muchos tipos similares de equipos SAI serie (así como algunos modelos SAI USB con adaptadores USB a serie). Los más comunes son los Trust 425/625, Powercom y Advice Partner/King PR750. Otros que utilizan el mismo protocolo también pueden funcionar. Para conexiones USB, es posible que necesite usbhid-ups(8).

Para obtener una guía más específica sobre qué controlador es aplicable para una conexión USB, consulte la Lista de Compatibilidad de Hardware (HCL) de NUT.

ARGUMENTOS ADICIONALES

Este controlador soporta las siguientes configuraciones opcionales en el archivo ups.conf(5):

linevoltage=valor

Un entero que especifica el voltaje de la línea. No se puede detectar automáticamente. Los valores aceptables están en el rango de 110-120 o 220-240. El valor predeterminado es 230.

manufacturer=nombre

Especifica el nombre del fabricante, que tampoco se puede detectar automáticamente. Esta es una cadena definida por el usuario, por lo que cualquier nombre es aceptable. El valor predeterminado es PowerCom.

modelname=nombre

Especifica el nombre del modelo, que tampoco se puede detectar automáticamente. Esta es una cadena definida por el usuario, por lo que cualquier nombre es aceptable. El valor predeterminado es Unknown.

serialnumber=valor

Al igual que modelname anterior, pero para el número de serie. El valor predeterminado es Unknown.

type=nombre

El tipo exacto del protocolo de comunicación dentro de la familia powercom, que se utilizará para comunicarse con el SAI. El tipo se denomina según el primer nombre de modelo que se codificó con ese protocolo. Los nombres aceptables son Trust, Egys, KP625AP, IMP, KIN, BNT, BNT-other y OPTI. El valor predeterminado es Trust.

BNT-other es un tipo especial para otros modelos BNT (como el 1500A a 120V y puede usarse para anular TODOS los modelos que usan TODOS los siguientes valores.

shutdownArguments={{minutos,segundos},si_los_minutos_deben_usarse}

Los minutos y segundos que el SAI debe esperar entre la recepción del comando de apagado y el apagado real. El otro argumento debe establecerse en el carácter n solo cuando el valor de los minutos deba omitirse y no enviarse al SAI. El valor predeterminado depende del tipo y se indica a continuación. Las llaves y las comas son obligatorias. Tenga en cuenta que no debe haber espacios en blanco.

numOfBytesFromUPS=valor

El número de bytes en un fotograma SAI: 16 es común, 11 para Trust. El valor predeterminado depende del tipo y se indica a continuación.

methodOfFlowControl=nombre

El método de control de flujo de comunicación serie que emplea el SAI. El valor predeterminado depende del tipo y se indica a continuación. Los nombres aceptables son dtr0rts1, dtr1 o no_flow_control.

validationSequence={{indice1,valor1},{indice2,valor2},{indice3,valor3}}

(Solo para tipos KP625AP, Trust, Egys.) 3 pares para ser utilizados para validar el SAI comparando bytes de los datos brutos con valores constantes. El índice selecciona el byte del SAI (ver numOfBytesFromUPS) y el valor es para hacer coincidir el byte. El valor predeterminado depende del tipo y se indica a continuación. Las llaves y las comas son obligatorias, al igual que la ausencia de espacios en blanco.

frequency={A,B}

(Solo para tipos KP625AP, Trust, Egys.) Un par para convertir los datos brutos de frecuencia en una lectura de frecuencia legible por humanos utilizando la función 1/(A*x+B). Si el valor bruto x ES la frecuencia, entonces establezca A=1/(x^2) y B=0. El valor predeterminado depende del tipo y se indica a continuación. Tenga en cuenta que las llaves y las comas son obligatorias, al igual que la ausencia de espacios en blanco.

loadPercentage={BatteryA,BatteryB,LineA,LineB}

(Solo para tipos KP625AP, Trust, Egys.) Un cuádruple para convertir los datos brutos de carga en una lectura de porcentaje de carga legible por humanos utilizando la función A*x+B. Si el valor bruto x ES el Porcentaje de Carga, entonces establezca A=1 y B=0. El valor predeterminado depende del tipo y se indica a continuación. Tenga en cuenta que las llaves y las comas son obligatorias, al igual que la ausencia de espacios en blanco.

batteryPercentage={Battery1,Battery2,Battery3,Line4,Line5}

(Solo para KP625AP, Trust, Egys.) Una 5-tupla para convertir los datos brutos de batería y línea en una lectura de porcentaje de batería y línea legible por humanos utilizando las funciones (Batería) A*x+B*y+C y (Línea) D*x+E. Si el valor bruto x ES el Porcentaje de Batería, entonces establezca A=1, B=0, C=0, D=1, E=0. El valor predeterminado depende del tipo y se indica a continuación. Tenga en cuenta que las llaves y las comas son obligatorias, al igual que la ausencia de espacios en blanco.

voltage={240A,240B,120A,120B}

(Solo para tipos KP625AP, Trust, Egys.) Un cuádruple que se utiliza para convertir los datos brutos de voltaje en una lectura de voltaje legible por humanos utilizando la función A*x+B. Si el valor bruto x ES LA MITAD del Voltaje, entonces establezca A=2, B=0. El valor predeterminado depende del tipo y se indica a continuación. Tenga en cuenta que las llaves y las comas son obligatorias, así como la ausencia de espacios en blanco.

nobt

Si esta bandera está presente, se omite la verificación de batería al inicio. Esto es útil para sistemas que tienden a sobrecargar el SAI al probar la batería al inicio del sistema, justo cuando el consumo de energía tiende a ser alto.

powercom(8) — Arch manual pages

NAME

powercom — Driver for Powercom UPS devices

SYNOPSIS

nutupsdrv -x vendor"powercom" -DD

SUPPORTED HARDWARE

All Powercom UPS models, that use the specified protocol

EXTRA ARGUMENTS

This driver supports the following extra arguments:

numOfBytesFromUPS
Number of bytes to be read from UPS. Defaults to 16.
methodOfFlowControl
Method of flow control. Can be "no_flow_control", "hardware" or "software". Defaults to "no_flow_control".
validationSequence
This parameter specifies the sequence of bytes that must be verified to accept the data. The sequence is a list of pairs { byte_number, byte_value }. Defaults to {{8,0},{8,0},{8,0}}.
shutdownArguments
This parameter specifies how to shut down the UPS. The argument is a list of pairs { byte_number, byte_value }. Defaults to {{1,30},y}. The default sequence means that after 30 seconds, the UPS will be shut down. The "y" means that the shut down command will be confirmed.
frequency
This parameter specifies the frequency of polling the UPS. The argument is a list of two numbers { polling_interval, polling_timeout }. Defaults to {0.00027778,0.0000}.
loadPercentage
This parameter specifies the load percentage. The argument is a list of four numbers { value1, value2, value3, value4 }. Defaults to {1.0000,0.0,1.0000,0.0}.
batteryPercentage
This parameter specifies the battery percentage. The argument is a list of five numbers { value1, value2, value3, value4, value5 }. Defaults to {1.0000,0.0000,0.0000,1.0000,0.0000}.
voltage
This parameter specifies the voltage. The argument is a list of four numbers { value1, value2, value3, value4 }. Defaults to {2.0000,0.0000,2.0000,0.0000}.

DEFAULT VALUES FOR THE EXTRA ARGUMENTS

The following example shows the default values for the extra arguments:

trol = no_flow_control
validationSequence = {{8,0},{8,0},{8,0}}
shutdownArguments = {{1,30},y}
frequency = {0.00027778,0.0000}
loadPercentage = {1.0000,0.0,1.0000,0.0}
batteryPercentage = {1.0000,0.0000,0.0000,1.0000,0.0000}
voltage = {2.0000,0.0000,2.0000,0.0000}

OPTI

numOfBytesFromUPS = 16
methodOfFlowControl = no_flow_control
validationSequence = {{5,0xFF},{7,0},{8,0}}
shutdownArguments = {{1,30},y}
