NOMBRE

podman-logout - Cerrar sesión en un registro de contenedores

SINOPSIS

podman logout [opciones] registro

DESCRIPCIÓN

podman logout cierra la sesión de un servidor de registro especificado eliminando las credenciales almacenadas en caché en el archivo auth.json. Si no se especifica el registro, se utiliza el primer registro bajo [registries.search] de registries.conf. El usuario puede anular la ruta del archivo de autenticación estableciendo la opción authfile. La ruta predeterminada utilizada es ${XDG_RUNTIME_DIR}/containers/auth.json. Para más detalles sobre el formato y las configuraciones de auth.json, consulte containers-auth.json(5). Todas las credenciales almacenadas en caché se pueden eliminar estableciendo la opción all.

podman [OPCIONES GLOBALES]

podman logout [OPCIONES GLOBALES]

podman logout [OPCIONES] REGISTRO [OPCIONES GLOBALES]

OPCIONES

--all, -a

Elimina las credenciales almacenadas en caché para todos los registros en el archivo de autenticación

--authfile=ruta

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux y $HOME/.config/containers/auth.json en Windows/macOS. El archivo es creado por podman login. Si no se encuentra el estado de autorización allí, se verifica $HOME/.docker/config.json, que se establece usando docker login.

Nota: También existe la opción de anular la ruta predeterminada del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--compat-auth-file=ruta

En lugar de actualizar el archivo de credenciales predeterminado, actualiza el que se encuentra en ruta y utiliza un formato compatible con Docker.

--help, -h

Imprime el enunciado de uso

EJEMPLOS

Elimina las credenciales de inicio de sesión para el registro docker.io del archivo de autenticación:

$ podman logout docker.io

Elimina las credenciales de inicio de sesión para el registro docker.io del archivo authdir/myauths.json:

$ podman logout --authfile authdir/myauths.json docker.io

Elimina las credenciales de inicio de sesión para todos los registros:

$ podman logout --all

VER TAMBIÉN

podman(1), podman-login(1), containers-auth.json(5)
