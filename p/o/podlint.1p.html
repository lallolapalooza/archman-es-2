NOMBRE

podlint - comprueba la corrección de POD utilizando Pod::POM

SINOPSIS

podlint MiArchivo.pm

DESCRIPCIÓN

Este script utiliza Pod::POM para analizar un documento Pod con todas las advertencias habilitadas, actuando efectivamente como un verificador de sintaxis y estructura.

La opción -f puede especificarse para que el Modelo de Objeto Pod analizado se imprima en STDOUT con cualquier error de marcado corregido. Tenga en cuenta que hay algunos errores críticos de análisis que el analizador no puede manejar y corregir, y en este caso el script terminará informando el error.
