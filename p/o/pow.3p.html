POW(3P) Manual del programador POSIX POW(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pow, powf, powl — función de potencia

SINOPSIS

#include <math.h>
double pow(double x, double y);
float powf(float x, float y);
long double powl(long double x, long double y);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán el valor de x elevado a la potencia y, xy. Si x es negativo, la aplicación deberá asegurarse de que y sea un valor entero.

Una aplicación que desee comprobar situaciones de error deberá establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, ha ocurrido un error.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán el valor de x elevado a la potencia y.

Para valores finitos de x < 0, y valores finitos no enteros de y, ocurrirá un error de dominio y se devolverá un NaN (si es representable) o un valor definido por la implementación.

Si el valor correcto causara un desbordamiento (overflow), ocurrirá un error de rango y pow(), powf(), y powl() devolverán ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL, respectivamente, con el mismo signo que el valor correcto de la función.

Si el valor correcto causara un desbordamiento negativo (underflow), y no es representable, puede ocurrir un error de rango, y pow(), powf(), y powl() devolverán 0.0, o (si no se soporta Floating-Point IEC 60559) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN, y LDBL_MIN, respectivamente.

Para y < 0, si x es cero, puede ocurrir un error de polo y pow(), powf(), y powl() devolverán ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL, respectivamente. En sistemas que soportan la opción de punto flotante IEC 60559, si x es ±0, ocurrirá un error de polo y pow(), powf(), y powl() devolverán ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL, respectivamente, si y es un entero impar, o HUGE_VAL, HUGE_VALF, y HUGE_VALL, respectivamente, si y no es un entero impar.

Si x o y es un NaN, se devolverá un NaN (a menos que se especifique lo contrario en esta descripción).

Para cualquier valor de y (incluido NaN), si x es +1, se devolverá 1.0.

Para cualquier valor de x (incluido NaN), si y es ±0, se devolverá 1.0.

Para cualquier valor entero impar de y > 0, si x es ±0, se devolverá ±0.

Para y > 0 y no un entero impar, si x es ±0, se devolverá +0.

Si x es -1, y y es ±Inf, se devolverá 1.0.

Para |x| < 1, si y es -Inf, se devolverá +Inf.

Para |x| > 1, si y es -Inf, se devolverá +0.

Para |x| < 1, si y es +Inf, se devolverá +0.

Para |x| > 1, si y es +Inf, se devolverá +Inf.

Para y entero impar < 0, si x es -Inf, se devolverá -0.

Para y < 0 y no entero impar, si x es -Inf, se devolverá +0.

Para y entero impar > 0, si x es -Inf, se devolverá -Inf.

Para y > 0 y no entero impar, si x es -Inf, se devolverá +Inf.

Para y < 0, si x es +Inf, se devolverá +0.

Para y > 0, si x es +Inf, se devolverá +Inf.

Si el valor correcto causara un desbordamiento negativo (underflow), y es representable, puede ocurrir un error de rango y se devolverá el valor correcto.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El valor de x es negativo y y es un número no entero finito.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se generará la excepción de punto flotante inválida.

Error de Polo
El valor de x es cero y y es negativo.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se generará la excepción de división por cero de punto flotante.

Error de Rango
El resultado desborda (overflow).

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se generará la excepción de desbordamiento de punto flotante.

Estas funciones pueden fallar si:

Error de Polo
El valor de x es cero y y es negativo.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se generará la excepción de división por cero de punto flotante.

Error de Rango
El resultado sufre un desbordamiento negativo (underflow).

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se generará la excepción de desbordamiento negativo de punto flotante.
