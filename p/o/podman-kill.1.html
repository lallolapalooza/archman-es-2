podman-kill(1) Manual de Comandos Generales podman-kill(1)

NOMBRE

podman-kill - Detiene el proceso principal en uno o más contenedores

SINOPSIS

podman kill [opciones] [contenedor ...]

podman container kill [opciones] [contenedor ...]

DESCRIPCIÓN

Se envía SIGKILL o cualquier señal especificada con la opción --signal al proceso principal dentro de cada contenedor especificado.

OPCIONES

--all, -a

Envía señales a todos los contenedores en ejecución y pausados.

--cidfile=archivo

Lee el ID del contenedor del archivo especificado y detiene el contenedor. Se puede especificar varias veces.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--signal, -s=señal

Señal a enviar al contenedor. Para más información sobre señales de Linux, consulte signal(7). El valor predeterminado es SIGKILL.

EJEMPLO

Detener un contenedor con un nombre dado:

podman kill mi_servidor_web

Detener un contenedor con un ID dado:

podman kill 860a4b23

Terminar un contenedor enviando la señal TERM:

podman kill --signal TERM 860a4b23

Detener el último contenedor. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

podman kill --latest

Terminar todos los contenedores enviando la señal KILL:

podman kill --signal KILL -a

Detener contenedores usando IDs especificados en archivos dados:

podman kill --cidfile /home/usuario/cidfile-1
podman kill --cidfile /home/usuario/cidfile-1 --cidfile ./cidfile-2

VER TAMBIÉN

podman(1), podman-stop(1)
