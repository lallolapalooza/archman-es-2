NOMBRE

pom2 - convertir POD a Texto, HTML, etc., con Pod::POM

SINOPSIS

pom2 texto MiArchivo.pm > MiArchivo.txt
pom2 html MiArchivo.pm > MiArchivo.html
pom2 pod  MiArchivo.pm > Miarchivo.pod
pom2 formato [opciones] MiArchivo.pm > Miarchivo.xyz

DESCRIPCIÓN

Este script utiliza "Pod::POM" para convertir un documento Pod a texto, HTML, de nuevo a Pod (por ejemplo, para normalizar un documento y corregir cualquier error de marcado), o cualquier otro formato para el que tengas un módulo de visualización.

Si el visualizador no es uno de los visualizadores incluidos con "Pod::POM", el script busca un módulo "Pod::POM::View" instalado que coincida con el formato especificado. Por ejemplo, si tienes "Pod::POM::View::DocBook" instalado, entonces podrías decir:

pod2 docbook MiArchivo.pm > MiArchivo.xml

Si se especifican opciones distintas a "--help", estas se pasan al método constructor de la clase de visualización. Por ejemplo:

pod2 docbook --root=chapter --titlecasing MiArchivo.pm > MiArchivo.xml

convertiría el documento Pod a un documento de capítulo DocBook con la opción de capitalización de títulos habilitada. Ten en cuenta que cualquier cadena prefijada por ""--"" se toma como una opción válida y se pasa al constructor; si no se especifica valor, se pasa 1.
