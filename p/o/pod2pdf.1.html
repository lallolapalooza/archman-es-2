POD2PDF(1) Documentación de Perl aportada por el usuario POD2PDF(1)

NOMBRE

pod2pdf - convierte Pod a formato PDF

DESCRIPCIÓN

pod2pdf convierte documentos escritos en formato POD (Plain Old Documentation) de Perl a archivos PDF.

Uso

pod2pdf [opciones] entrada.pod >salida.pdf

Si no se especifica ningún nombre de archivo de entrada, pod2pdf leerá desde STDIN, por ejemplo:

perldoc -u File::Find | pod2pdf [opciones] >File-Find.pdf

Opciones

pod2pdf acepta las siguientes opciones de línea de comandos:

"--output-file"
Establece el nombre del archivo de salida para el archivo PDF generado. Por defecto, pod2pdf generará a STDOUT.
"--page-size"
Establece el tamaño de página a utilizar en el archivo PDF, puede ser configurado a cualquiera de los tamaños de papel estándar (A4, A5, Carta, etc.). El valor por defecto es A4.
"--page-orientation"
Controla si las páginas se producen en formato horizontal (landscape) o vertical (portrait). El valor por defecto es 'portrait'.
"--page-width", "--page-height"
Establece el ancho y alto de las páginas generadas en puntos (para usar tamaños de papel no estándar).
"--left-margin", "--right-margin", "--top-margin", "--bottom-margin"
Permite establecer individualmente cada uno de los márgenes de la página (superior, inferior, izquierdo y derecho) en puntos.
"--margins"
Establece todos los márgenes de la página al mismo tamaño (especificado en puntos).
"--header", "--noheader"
Controla si se incluirá una cabecera (que contiene el título de la página y la marca de tiempo e icono opcionales) en cada página. El valor por defecto es activado, así que use "--noheader" para desactivarlo.
"--title"
Establece el título de la página (el valor por defecto es el nombre del archivo de entrada).
"--timestamp"
Opción booleana - si se establece, incluye la marca de tiempo de 'última modificación' del archivo de entrada en la cabecera de la página.
"--icon"
Nombre del archivo de un icono a mostrar en la esquina superior izquierda de cada página.
"--icon-scale"
Valor de escala para el icono de la cabecera (el valor por defecto es 0.25).
"--footer", "--nofooter"
Controla si se incluirá un pie de página (que contiene el número de página actual y una cadena de texto opcional) en cada página. Por defecto, se incluirá el pie de página, así que use "--nofooter" para desactivarlo.
"--footer-text"
Establece una cadena de texto opcional para el pie de página que se incluirá en la esquina inferior izquierda de cada página.
"--version"
Imprime el número de versión y sale.

Archivos de configuración

Conjuntos de opciones de línea de comandos pueden guardarse en archivos de configuración.

Un archivo de configuración contiene opciones en el mismo formato que usa pod2pdf en la línea de comandos, con una opción por cada línea del archivo, por ejemplo:

--page-size A5
--page-orientation landscape

Para usar un archivo de configuración, invoca pod2pdf con la opción "@/ruta/al/archivo.conf".

Por ejemplo, si siempre quisieras incluir un logotipo de empresa, marca de tiempo y aviso de derechos de autor en tus archivos PDF, crea un archivo miempresa.conf que contenga lo siguiente:

--icon "/ruta/a/tu/logo.png"
--footer-text "Copyright 2007 MiEmpresa Limitada"
--timestamp

Luego invoca pod2pdf como:

pod2pdf @/ruta/a/miempresa.conf entrada.pod >salida.pdf

Si creas un archivo de configuración llamado pod2pdf.conf y lo colocas en el mismo directorio que el script pod2pdf, se cargará como la configuración predeterminada.

EXTENCIONES POD

Además de los comandos POD estándar (ver perlpodspec), pod2pdf admite las siguientes extensiones al formato POD:

"=ff"
El comando "=ff" inserta un salto de página (avance de formulario) en el documento.
"O<...>"
El código de formato "O<...>" inserta un objeto externo (archivo) en el documento. Esto está pensado principalmente para incrustar imágenes, por ejemplo: 
O</ruta/a/figura1.jpg>

para insertar diagramas, etc., en la documentación.

pod2pdf admite los tipos de archivo JPG, GIF, TIFF, PNG y PNM para objetos incrustados.

DEPENDENCIAS

pod2pdf requiere que los siguientes módulos estén instalados:

PDF::API2
Pod::Escapes
Getopt::ArgvFile

Adicionalmente, para usar imágenes, los módulos File::Type e Image::Size deben estar instalados, y para especificar tamaños de página alternativos se requiere el módulo Paper::Specs.
