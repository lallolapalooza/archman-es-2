POSIX_TRACE_START(3P) Manual del programador POSIX POSIX_TRACE_START(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_start, posix_trace_stop — inicio y fin de trazado (TRACING)

SINOPSIS

#include <trace.h>
int posix_trace_start(trace_id_t trid);
int posix_trace_stop (trace_id_t trid);

DESCRIPCIÓN

Las funciones posix_trace_start() y posix_trace_stop(), respectivamente, inician y detienen el flujo de trazado identificado por el argumento trid.

El efecto de llamar a la función posix_trace_start() se registrará en el flujo de trazado como el evento de trazado del sistema POSIX_TRACE_START y el estado del flujo de trazado pasará a ser POSIX_TRACE_RUNNING. Si el flujo de trazado está en curso cuando se llama a esta función, el evento de trazado del sistema POSIX_TRACE_START no se registrará y el flujo de trazado continuará en ejecución. Si el flujo de trazado está lleno, el evento de trazado del sistema POSIX_TRACE_START no se registrará y el estado del flujo de trazado no cambiará.

El efecto de llamar a la función posix_trace_stop() se registrará en el flujo de trazado como el evento de trazado del sistema POSIX_TRACE_STOP y el estado del flujo de trazado pasará a ser POSIX_TRACE_SUSPENDED. Si el flujo de trazado está suspendido cuando se llama a esta función, el evento de trazado del sistema POSIX_TRACE_STOP no se registrará y el flujo de trazado permanecerá suspendido. Si el flujo de trazado está lleno, el evento de trazado del sistema POSIX_TRACE_STOP no se registrará y el estado del flujo de trazado no cambiará.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

ERRORES

Estas funciones fallarán si:

EINVAL
El valor del argumento trid no corresponde a un flujo de trazado activo y, por lo tanto, no se inició ni se detuvo ningún flujo de trazado.
EINTR
La operación fue interrumpida por una señal y, por lo tanto, el flujo de trazado no se inició ni se detuvo necesariamente.
