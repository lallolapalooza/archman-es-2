Paquete: po4a

PO4A-TRANSLATE.1P(1) Documentación de Perl aportada por el usuario PO4A-TRANSLATE.1P(1)

NOMBRE

po4a-translate - convierte un archivo PO de nuevo al formato de documentación

SINOPSIS

po4a-translate -f fmt -m master.doc -p XX.po -l XX.doc

(XX.doc es la salida, todos los demás son entradas)

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y más interesante aún, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaban, como la documentación.

El script po4a-translate se encarga de convertir la traducción (que se realizó en un archivo PO) de nuevo al formato de documentación. El archivo PO proporcionado debe ser la traducción del archivo POT que fue producido por po4a-gettextize(1).

OPCIONES

-f, --format
Formato de la documentación que desea manejar. Utilice la opción --help-format para ver la lista de formatos disponibles.
-a, --addendum
Añade un archivo al archivo resultante (para poner el nombre del traductor o una sección "Sobre esta traducción", por ejemplo). La primera línea del archivo a insertar debe ser una cabecera PO4A que indique dónde debe añadirse (ver sección CÓMO añadir texto adicional a las traducciones en po4a(7)).
-A, --addendum-charset
Juego de caracteres de los añadidos. Tenga en cuenta que todos los añadidos deben estar en el mismo juego de caracteres.
-m, --master
Archivo que contiene el documento maestro para traducir.
-M, --master-charset
Juego de caracteres del archivo que contiene el documento a traducir.
-l, --localized
Archivo donde se escribirá el documento localizado (traducido).
-L, --localized-charset
Juego de caracteres del archivo que contiene el documento localizado.
-p, --po
Archivo desde el cual se leerá el catálogo de mensajes.
-o, --option
Opciones adicionales para pasar al plugin de formato. Consulte la documentación de cada plugin para obtener más información sobre las opciones válidas y sus significados. Por ejemplo, podría pasar '-o tablecells' al analizador AsciiDoc, mientras que el analizador de texto aceptaría '-o tabs=split'.
-k, --keep
Umbral mínimo de porcentaje de traducción para conservar (es decir, escribir) el archivo resultante (predeterminado: 80). Es decir, por defecto, los archivos deben estar traducidos al menos al 80% para ser escritos.
-w, --width
Columna en la que se debe ajustar el archivo resultante si el formato lo soporta (predeterminado: 76). Si el valor proporcionado es 0 o negativo, entonces el archivo resultante no se ajustará en absoluto. Esto es útil con algunos formatos que podrían romperse al ser reajustados.
-h, --help
Muestra un breve mensaje de ayuda.
--help-format
Enumera los formatos de documentación entendidos por po4a.
-V, --version
Muestra la versión del script y sale.
-v, --verbose
Aumenta la verbosidad del programa.
-d, --debug
Muestra información de depuración.

Añadir contenido (además de traducciones) a los archivos generados

Para añadir contenido adicional al documento generado además de lo que ha traducido (como el nombre del traductor o una sección "Sobre esta traducción"), debe utilizar la opción --addendum.

La primera línea del añadido debe ser una cabecera que indique dónde ponerlo en el documento (puede ser antes o después de una parte dada del documento). El resto del archivo se añadirá textualmente al archivo resultante sin más procesamiento.

Tenga en cuenta que si po4a-translate no puede añadir uno de los archivos proporcionados, descarta toda la traducción (porque el archivo faltante podría ser el que indica el autor, lo que impediría que los usuarios lo contactaran para informar de errores en la traducción).

La cabecera tiene una sintaxis bastante rígida. Para más información sobre cómo usar esta característica y cómo funciona, consulte la página del manual po4a(7).

po4a-translate(1p)

NAME

po4a-translate - Translate documentation into another language

SYNOPSIS

po4a-translate [ -f format ] [ -L language ] [ -m master_file ] [ -p po_file ] [ -l translated_file ] [ --list-languages ] [ --previous-file previous_file ] [ --wrapper wrapper ] [ --pot-file pot_file ] [ --msgid-limit limit ] [ -h | --help ] [ -V | --version ]

DESCRIPTION

The po4a-translate script is a tool to help translators to translate documentation into another language. It can be used to generate a template file (PO file) from an original document, to merge translated PO files into the original document, or to list available languages.

OPTIONS

-f format, --format format
Specifies the input document format. This option is mandatory unless the format can be auto-detected. Supported formats include `asciidoc`, `latex`, `sgml`, `xml`, `man`.
-L language, --language language
Specifies the target language for translation. This option is mandatory when generating a PO file or merging a translated PO file.
-m master_file, --master-file master_file
Specifies the original document file. This option is mandatory when generating a PO file or merging a translated PO file.
-p po_file, --po-file po_file
Specifies the PO file to be used. This option is mandatory when merging a translated PO file.
-l translated_file, --translated-file translated_file
Specifies the output file for the translated document. This option is mandatory when merging a translated PO file.
--list-languages
Lists all supported languages.
--previous-file previous_file
Specifies a previous version of the translated file. This is used to detect fuzzy strings and avoid unnecessary translations.
--wrapper wrapper
Specifies a wrapper script to process the input and output files. This is useful for formats that require special handling.
--pot-file pot_file
Specifies the output PO template file (POT file). If not specified, the PO file will be created with the same name as the input file, but with a `.po` extension.
--msgid-limit limit
Specifies the maximum number of entries in the PO file. If the number of entries exceeds the limit, the PO file will be split into multiple files.
-h, --help
Display help message and exit.
-V, --version
Display version information and exit.
