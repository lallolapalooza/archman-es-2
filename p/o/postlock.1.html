POSTLOCK(1) Manual de comandos generales POSTLOCK(1)

NOMBRE

postlock - bloquea la carpeta de correo y ejecuta un comando

SINOPSIS

postlock [-c directorio_config] [-l estilo_bloqueo]
[-v] archivo comando...

DESCRIPCIÓN


El comando postlock(1) bloquea archivo para acceso exclusivo, y ejecuta comando. El método de bloqueo es compatible con el agente de entrega local de estilo UNIX de Postfix.

Opciones:

-c directorio_config
Lee el archivo de configuración main.cf en el directorio especificado en lugar del directorio de configuración predeterminado.
-l estilo_bloqueo
Anula el método de bloqueo especificado a través del parámetro de configuración mailbox_delivery_lock (ver más abajo).
-v
Habilita el registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado.

Argumentos:

archivo
Un archivo de buzón. El usuario debe tener permiso de lectura/escritura.
comando...
El comando a ejecutar mientras archivo está bloqueado para acceso exclusivo. El comando se ejecuta directamente, es decir, sin ser interpretado por un intérprete de comandos de shell.

DIAGNÓSTICOS


El estado de resultado es 75 (EX_TEMPFAIL) cuando postlock(1) no pudo realizar la operación solicitada. De lo contrario, el estado de salida es el estado de salida del comando.

ERRORES


Con sistemas de archivos remotos, la capacidad de adquirir un bloqueo no elimina necesariamente los conflictos de acceso. Evite el acceso a archivos por parte de procesos que se ejecutan en diferentes máquinas.

ENTORNO

MAIL_CONFIG
Directorio con archivos de configuración de Postfix.
MAIL_VERBOSE
Habilita el registro detallado con fines de depuración.

PARÁMETROS DE CONFIGURACIÓN

Los siguientes parámetros de main.cf son especialmente relevantes para este programa. El texto a continuación solo proporciona un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

CONTROLES DE BLOQUEO

deliver_lock_attempts (20)
El número máximo de intentos para adquirir un bloqueo exclusivo en un archivo de buzón o en el archivo de registro de bounce(8).
deliver_lock_delay (1s)
El tiempo entre intentos de adquirir un bloqueo exclusivo en un archivo de buzón o en el archivo de registro de bounce(8).
stale_lock_time (500s)
El tiempo después del cual se elimina un archivo de bloqueo de buzón exclusivo obsoleto.
mailbox_delivery_lock (ver salida de 'postconf -d')
Cómo bloquear un buzón de local(8) estilo UNIX antes de intentar la entrega.

CONTROLES DE RECURSOS Y TARIFAS

fork_attempts (5)
El número máximo de intentos para bifurcar() un proceso hijo.
fork_delay (1s)
El retraso entre intentos de bifurcar() un proceso hijo.

CONTROLES VARIOS

config_directory (ver salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
import_environment (ver salida de 'postconf -d')
La lista de variables de entorno que un proceso Postfix privilegiado importará de un proceso padre que no sea de Postfix, o reemplazos de entorno nombre=valor.

VER TAMBIÉN

postconf(5), parámetros de configuración
