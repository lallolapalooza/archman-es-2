POWERPROFILESCTL(1) Programa de Control de Power Profiles Daemon POWERPROFILESCTL(1)

NOMBRE

powerprofilesctl - Utilidad de línea de comandos para controlar Power Profiles Daemon

SINOPSIS

powerprofilesctl [-h] {list,list-holds,list-actions,get,set,configure-action,configure-battery-aware,query-battery-aware,launch,version} ...

ARGUMENTOS POSICIONALES

powerprofilesctl list

Listar los perfiles de energía disponibles

uso: powerprofilesctl list [-h]

powerprofilesctl list-holds

Listar las retenciones actuales del perfil de energía

uso: powerprofilesctl list-holds [-h]

powerprofilesctl list-actions

Listar las acciones de perfil de energía disponibles

uso: powerprofilesctl list-actions [-h]

powerprofilesctl get

Imprimir el perfil de energía actualmente activo

uso: powerprofilesctl get [-h]

powerprofilesctl set

Establecer el perfil de energía actualmente activo

uso: powerprofilesctl set [-h] {}

argumentos:

{}
Perfil a usar para el comando set

powerprofilesctl configure-action

Configurar la acción que se tomará para el perfil

uso: powerprofilesctl configure-action [-h] [--enable] [--disable] action

argumentos:

action
acción a cambiar para configure-action

opciones:

--enable
habilitar acción
--disable
deshabilitar acción

powerprofilesctl configure-battery-aware

Activar o desactivar cambios dinámicos según el nivel de la batería o el adaptador de corriente

uso: powerprofilesctl configure-battery-aware [-h] [--enable] [--disable]

opciones:

--enable
habilitar consciente de la batería
--disable
deshabilitar consciente de la batería

powerprofilesctl query-battery-aware

Consultar si los cambios dinámicos según el nivel de la batería o el adaptador de corriente están habilitados

uso: powerprofilesctl query-battery-aware [-h]

powerprofilesctl launch

Lanzar un comando mientras se mantiene un perfil de energía

uso: powerprofilesctl launch [-h] [--profile PROFILE] [--reason REASON]
[--appid APPID]
[argumentos ...]

Lanza el comando mientras se mantiene un perfil de energía, ya sea de rendimiento o de ahorro de energía. Por defecto, la retención del perfil es para el perfil de rendimiento, pero puede no estar disponible en todos los sistemas. Consulte el comando list para ver una lista de los perfiles disponibles.

argumentos:

argumentos
Comando a lanzar

opciones:

--profile PERFIL, -p PERFIL
Perfil a usar para el comando launch
--reason RAZÓN, -r RAZÓN
Razón a usar para el comando launch
--appid APPID, -i APPID
AppId a usar para el comando launch

powerprofilesctl version

Imprimir información de versión y salir

uso: powerprofilesctl version [-h]

COMENTARIOS

Use “powerprofilesctl COMANDO --help” para obtener ayuda detallada para comandos individuales
