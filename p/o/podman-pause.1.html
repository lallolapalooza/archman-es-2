NOMBRE

podman-pause - Pausa uno o más contenedores

SINOPSIS

podman pause [opciones] [contenedor...]

podman container pause [opciones] [contenedor...]

DESCRIPCIÓN

Pausa todos los procesos en uno o más contenedores. Puede usar IDs o nombres de contenedores como entrada.

OPCIONES

--all, -a

Pausa todos los contenedores en ejecución.

--cidfile=archivo

Lee el ID del contenedor del archivo especificado y pausa el contenedor. Se puede especificar varias veces.

--filter, -f=filtro

Filtra qué contenedores pausar. Se pueden dar múltiples filtros usando múltiples veces la opción --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizado para crear el contenedor
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [FechaHora] Contenedores creados antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

EJEMPLO

Pausar un contenedor específico:

podman pause miwebserver

Pausar contenedor por ID parcial:

podman pause 860a4b23

Pausar todos los contenedores en ejecución:

podman pause --all

Pausar contenedores usando IDs especificados en archivos dados:

podman pause --cidfile /home/usuario/cidfile-1
podman pause --cidfile /home/usuario/cidfile-1 --cidfile ./cidfile-2

Pausar el último contenedor. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

podman pause --latest

VER TAMBIÉN

podman(1), podman-unpause(1)
