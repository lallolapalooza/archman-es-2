NOMBRE

podman-pod-rm - Elimina uno o varios pods y contenedores detenidos

SINOPSIS

podman pod rm [opciones] pod

DESCRIPCIÓN

podman pod rm elimina uno o varios pods detenidos y sus contenedores del host. Se puede usar el nombre o ID del pod. La opción -f detiene todos los contenedores y luego los elimina antes de eliminar el pod. Si todos los contenedores añadidos por el usuario están en estado de salida, se elimina el pod.

OPCIONES

--all, -a

Elimina todos los pods. Se puede usar junto con -f.

--force, -f

Detiene los contenedores en ejecución y elimina todos los contenedores detenidos antes de la eliminación del pod.

--ignore, -i

Ignora errores cuando los pods especificados no están en el almacén de contenedores. Un usuario podría haber decidido eliminar manualmente un pod, lo que provocaría un fallo durante la directiva ExecStop de un servicio systemd que hace referencia a ese pod.

--latest, -l

En lugar de proporcionar el nombre o ID del pod, utiliza el último pod creado. Nota: el último pod iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--pod-id-file=archivo

Lee el ID del pod del archivo especificado y elimina el pod. Se puede especificar varias veces.

Si se especifica, el archivo de ID del pod se elimina junto con el pod.

--time, -t=segundos

Segundos a esperar antes de detener forzosamente los contenedores en ejecución dentro del pod. Usa -1 para esperar infinitamente.

La opción --force debe especificarse para usar la opción --time.

EJEMPLO

Elimina un pod con un nombre dado:

podman pod rm miwebservidorpod

Elimina múltiples pods con nombres y/o IDs dados:

podman pod rm miwebservidorpod miapiunicornio 860a4b23

Elimina forzosamente un pod con un ID dado:

podman pod rm -f 860a4b23

Elimina forzosamente todos los pods:

podman pod rm -f -a
podman pod rm -fa

Elimina un pod usando el ID especificado en un archivo dado:

podman pod rm --pod-id-file /ruta/al/archivo/id

Estado de salida

0 Todos los pods especificados eliminados

1 Uno de los pods especificados no existía, y no hubo otros fallos

2 Uno de los pods especificados está adjunto a un contenedor

125 El comando falla por cualquier otro motivo
