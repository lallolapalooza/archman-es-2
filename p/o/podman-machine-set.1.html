NOMBRE

podman-machine-set - Establecer una configuración de máquina virtual

SINOPSIS

podman machine set [opciones] [nombre]

DESCRIPCIÓN

Cambiar una configuración de máquina.

El nombre de máquina predeterminado es podman-machine-default. Si no se especifica un nombre de máquina como argumento, la configuración se aplicará a podman-machine-default.

Solo sin raíz (Rootless).

Las configuraciones predeterminadas de la máquina Podman se pueden establecer a través de la sección [machine] en el archivo containers.conf(5).

OPCIONES

--cpus=número

Número de CPUs. Solo compatible con máquinas QEMU.

--disk-size=número

Tamaño del disco para la VM invitada en GB. Solo se puede aumentar. Solo compatible con máquinas QEMU.

--help

Imprimir el enunciado de uso.

--memory, -m=número

Memoria (en MB). Solo compatible con máquinas QEMU.

--rootful

Si esta máquina prefiere la ejecución de contenedores con privilegios (true) o sin privilegios (false). Esta opción actualiza el valor predeterminado de la conexión remota de Podman actual si actualmente apunta al nombre de máquina especificado (o podman-machine-default si no se especifica ningún nombre).

A diferencia de [podman system connection default], esta opción hace que el socket API, si está disponible, se reenvíe al socket con o sin privilegios dentro de la VM.

Tenga en cuenta que cambiar esta opción significa que todos los contenedores/imágenes/volúmenes existentes, etc., ya no serán visibles con la conexión/socket predeterminado. Esto se debe a que los usuarios con y sin privilegios dentro de la VM están completamente separados y no comparten ningún almacenamiento. Sin embargo, los datos no se pierden y siempre puede volver a cambiar esta opción o usar la otra conexión para acceder a ellos.

--usb=bus=número,devnum=número o vendor=hexadecimal,product=hexadecimal o ""

Asignar un dispositivo USB del host a la VM. Solo compatible con Máquinas QEMU.

El dispositivo debe estar presente cuando la VM se inicie. El dispositivo debe tener los permisos adecuados para ser asignado a la máquina Podman.

Use una cadena vacía para eliminar todos los dispositivos USB establecidos previamente.

Tenga en cuenta que usar el número de bus y dispositivo es más simple, pero los valores pueden cambiar en cada arranque o cuando se desconecta el dispositivo. Usar el proveedor y el producto puede generar colisiones en el caso de múltiples dispositivos con el mismo valor de proveedor y producto; se asignará el primer dispositivo disponible.

--user-mode-networking

Esta opción solo se puede usar para el proveedor WSL en Windows. En todas las demás plataformas, esta opción se ignora y la red en modo de usuario siempre será true, ya que estos proveedores siempre dependen de gvproxy (nuestra herramienta de red en modo de usuario para las VMs).

En contraste, el backend de Windows/WSL tiene un valor predeterminado de false y sigue la configuración de red WSL estándar. Cambiar esta configuración a true en Windows/WSL informa a Podman que reemplace la configuración de red de WSL al iniciar esta instancia de máquina con una distribución de red en modo de usuario. Dado que WSL comparte el mismo kernel entre distribuciones, todas las demás distribuciones en ejecución reutilizan esta red. De manera similar, cuando se detiene la última instancia de máquina con una configuración true, se restaura la configuración de red original.

En algunas configuraciones de VPN, la VPN puede descartar el tráfico de interfaces de red alternativas, incluidos los dispositivos de red de VM. Al habilitar la red en modo de usuario, las VPN observan todo el tráfico de la máquina Podman como si proviniera del host, evitando el problema.

EJEMPLOS

Para cambiar la máquina Podman predeterminada de sin privilegios a con privilegios:

$ podman machine set --rootful

o más explícitamente, establezca con el valor true.

$ podman machine set --rootful=true

Cambiar la máquina Podman predeterminada de con privilegios a sin privilegios.

$ podman machine set --rootful=false

Cambiar la máquina Podman especificada de sin privilegios a con privilegios.

$ podman machine set --rootful myvm
