NOMBRE

podman-machine-reset - Restablece las máquinas y el entorno de Podman

SINOPSIS

podman machine reset [opciones]

DESCRIPCIÓN

Restablece el entorno de la máquina Podman. Este comando detiene cualquier máquina en ejecución y luego las elimina. Luego se eliminan los archivos de configuración y datos. Los archivos de datos incluirían las imágenes de disco de la máquina y cualquier imagen de caché previamente descargada. Cuando se ejecuta este comando, todas sus máquinas Podman habrán sido eliminadas.

OPCIONES

--force, -f

Restablece sin confirmación.

--help

Imprime la declaración de uso.

EJEMPLOS

$ podman machine reset
Advertencia: este comando eliminará todas las máquinas podman existentes
y todos los directorios de configuración y datos para las máquinas Podman
Las siguientes máquinas serán eliminadas:
dev
podman-machine-default
¿Está seguro de que desea continuar? [y/N] y
$

Restablece forzadamente sin confirmación.

$ podman machine reset --force
$
