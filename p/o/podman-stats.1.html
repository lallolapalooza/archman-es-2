podman-stats(1) Manual de Comandos Generales podman-stats(1)

NOMBRE

podman-stats - Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores

SINOPSIS

podman stats [opciones] [contenedor]

podman container stats [opciones] [contenedor]

DESCRIPCIÓN

Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores.

Nota: `podman stats` no funciona en entornos sin privilegios (rootless) que utilizan cgroups v1. `podman stats` se basa en la información de cgroup para las estadísticas, y cgroup v1 no es compatible con casos de uso sin privilegios.

Nota: Los entornos sin privilegios que utilizan cgroups v2 no pueden informar estadísticas sobre su uso de red.

OPCIONES

--all, -a

Mostrar todos los contenedores. Por defecto, solo se muestran los contenedores en ejecución.

--format=plantilla

Imprime formateadas las estadísticas de los contenedores a JSON o utilizando una plantilla Go.

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.AvgCPU CPU promedio, flotante de precisión completa.
.AVGCPU CPU promedio, formateado como un porcentaje.
.BlockInput Total de datos leídos del dispositivo de bloque.
.BlockIO Total de datos leídos/total de datos escritos en el dispositivo de bloque.
.BlockOutput Total de datos escritos en el dispositivo de bloque.
.ContainerID ID del contenedor, hash completo (sin truncar).
.ContainerStats ... Estructura anidada, solo para expertos.
.CPU CPU en porcentaje, flotante de precisión completa.
.CPUNano Uso de CPU, total, en nanosegundos.
.CPUPerc Porcentaje de CPU utilizado.
.CPUSystemNano Uso de CPU, kernel, en nanosegundos.
.Duration Igual que CPUNano.
.ID ID del contenedor, truncado.
.MemLimit Límite de memoria, en bytes.
.MemPerc Porcentaje de memoria utilizado.
.MemUsage Uso de memoria.
.MemUsageBytes Uso de memoria (IEC).
.Name Nombre del contenedor.
.NetIO IO de red.
.Network ... IO de red, separado por interfaz de red.
.PerCPU Tiempo de CPU consumido por todas las tareas [1].
.PIDs Número de PIDs.
.PIDS Número de PIDs (sí, sabemos que esto es un duplicado).
.SystemNano Fecha y hora actual del sistema, nanosegundos desde la época.
.Up Duración (CPUNano), en formato legible por humanos.
.UpTime Igual que Up.

[1] Solo Cgroups V1

Al usar una plantilla Go, precede el formato con table para imprimir encabezados.

--interval, -i=segundos

Tiempo en segundos entre informes de estadísticas, por defecto 5 segundos.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--no-reset

No borrar la terminal/pantalla entre intervalos de informes.

--no-stream

Desactivar el flujo de estadísticas y solo obtener el primer resultado, la configuración predeterminada es false.

--no-trunc

No truncar la salida.

EJEMPLO

Lista las estadísticas de todos los contenedores en ejecución sin modo de transmisión:

# podman stats -a --no-stream
ID             NAME              CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

Lista las estadísticas del contenedor especificado en modo de transmisión:

# podman stats a9f80
ID             NAME             CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

Lista las estadísticas especificadas sobre el contenedor especificado en formato de tabla:

$ podman stats --no-trunc 3667 --format 'table {{ .ID }} {{ .MemUsage }}'
ID                                                                MEM USAGE / LIMIT
3667c6aacb06aac2eaffce914c01736420023d56ef9b0f4cfe58b6d6a78b7503  49.15kB / 67.17GB

Lista las estadísticas del contenedor especificado en formato JSON:

# podman stats --no-stream --format=json a9f80
[
    {
	"id": "a9f807ffaacd",
	"name": "frosty_hodgkin",
	"cpu_percent": "--",
	"mem_usage": "3.092MB / 16.7GB",
	"mem_percent": "0.02%",
	"netio": "-- / --",
	"blocki": "-- / --",
	"pids": "2"
    }
]

Lista las estadísticas del contenedor especificado en formato de tabla:

# podman stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NAME           MEM USAGE / LIMIT
6eae9e25a564   clever_bassi   3.031MB / 16.7GB

Nota: Al usar una red slirp4netns con el controlador de puerto rootlesskit, el tráfico enviado a través del reenvío de puertos se contabiliza en el dispositivo lo. El tráfico contabilizado en lo no se contabiliza en la salida de estadísticas.
