NOMBRE

podman-tag - Añade un nombre adicional a una imagen local

SINOPSIS

podman tag imagen[:etiqueta] [nombre-destino[:etiqueta]...] [opciones]

podman image tag imagen[:etiqueta] [nombre-destino[:etiqueta]...] [opciones]

DESCRIPCIÓN

Asigna un nuevo nombre de imagen a una imagen existente. Un nombre completo se refiere a toda la imagen, incluyendo la etiqueta opcional después del símbolo :. Si no se proporciona ninguna etiqueta, entonces Podman utiliza por defecto latest tanto para la imagen como para el nombre-destino.

OPCIONES

--help, -h

Muestra el mensaje de uso

EJEMPLOS

Etiqueta una imagen especificada con un nombre de imagen que por defecto es :latest.

$ podman tag 0e3bbc2 fedora:latest

Etiqueta una imagen especificada con un nombre de imagen completamente especificado.

$ podman tag httpd myregistryhost:5000/fedora/httpd:v2

Etiqueta una imagen especificada con múltiples etiquetas.

$ podman tag mymariadb mycontainerregistry.io/namespace/mariadb:10 mycontainerregistry.io/namespace/mariadb:10.11 mycontainerregistry.io/namespace/mariadb:10.11.12
