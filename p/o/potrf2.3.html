subrutina recursiva cpotrf2 (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CPOTRF2

Propósito:

!>
!> CPOTRF2 calcula la factorización de Cholesky de una matriz hermítica
!> positiva definida A utilizando el algoritmo recursivo.
!>
!> La factorización tiene la forma
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>
!> Esta es la versión recursiva del algoritmo. Divide
!> la matriz en cuatro submatrices:
!>
!>        [  A11 | A12  ]  donde A11 es n1 por n1 y A22 es n2 por n2
!>    A = [ -----|----- ]  con n1 = n/2
!>        [  A21 | A22  ]       n2 = n-n1
!>
!> La subrutina se llama a sí misma para factorizar A11. Actualiza y escala A21
!> o A12, actualiza A22 y luego se llama a sí misma para factorizar A22.
!>
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz hermítica A. Si UPLO = 'U', la parte
!>          triangular superior de N por N de A contiene la parte
!>          triangular superior de la matriz A, y la parte estrictamente
!>          triangular inferior de A no se referencia. Si UPLO = 'L', la parte
!>          triangular inferior de N por N de A contiene la parte
!>          triangular inferior de la matriz A, y la parte estrictamente
!>          triangular superior de A no se referencia.
!>
!>          En la salida, si INFO = 0, el factor U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el menor principal principal de orden i
!>                no es positivo, y la factorización no pudo ser
!>                completada.
!>
