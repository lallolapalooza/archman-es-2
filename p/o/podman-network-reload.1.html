NOMBRE

podman-network-reload - Recarga la configuración de red para contenedores

SINOPSIS

podman network reload [opciones] [contenedor...]

DESCRIPCIÓN

Recarga la configuración de red de uno o más contenedores.

Podman con privilegios de root depende de las reglas de iptables para proporcionar conectividad de red. Si las reglas de iptables se eliminan, esto ocurre por ejemplo con firewall-cmd --reload, el contenedor pierde conectividad de red. Este comando restaura la conectividad de red.

OPCIONES

--all, -a

Recarga la configuración de red de todos los contenedores.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

EJEMPLO

Recargar la configuración de red después de una recarga del firewall:

# podman run -p 80:80 -d nginx
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
# curl 127.0.0.1
works
# sudo firewall-cmd --reload
success
# curl 127.0.0.1
hangs
# podman network reload b1b538e8bc40
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
# curl 127.0.0.1
works

Recargar la configuración de red para todos los contenedores:

# podman network reload --all
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
fe7e8eca56f844ec33af10f0aa3b31b44a172776e3277b9550a623ed5d96e72b
