POPAUTH(1) Comandos de usuario POPAUTH(1)

NOMBRE

popauth - página del manual para popauth (GNU Mailutils)

SINOPSIS

popauth [OPCIÓN...]

DESCRIPCIÓN

GNU popauth -- administra la base de datos de autenticación POP3

INFORMAR DE ERRORES

Reporte errores a <bug-mailutils@gnu.org>.

VER TAMBIÉN

La documentación completa para popauth se mantiene como un manual Texinfo. Si los programas info y popauth están correctamente instalados en su sitio, el comando

info popauth

debería darle acceso al manual completo.
