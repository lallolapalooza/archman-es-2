NOMBRE

podman-network-inspect - Muestra la configuración de red para una o más redes

SINOPSIS

podman network inspect [opciones] red [red ...]

DESCRIPCIÓN

Muestra la configuración de red (en formato JSON).

OPCIONES

--format, -f=formato

Imprime las redes en formato JSON o utilizando una plantilla Go.

Marcador Descripción
.Containers ... Contenedores en ejecución en esta red.
.Created ... Marca de tiempo cuando se creó la red
.DNSEnabled La red tiene DNS habilitado (booleano)
.Driver Controlador de red
.ID ID de la red
.Internal La red es interna (booleano)
.IPAMOptions ... Opciones IPAM de la red
.IPv6Enabled La red tiene subred IPv6 (booleano)
.Labels ... Etiquetas de la red
.Name Nombre de la red
.Network ... Tipo de red anidada
.NetworkDNSServers Array de servidores DNS utilizados en esta red
.NetworkInterface Nombre de la interfaz de red en el host
.Options ... Opciones de la red
.Routes Lista de rutas estáticas para esta red
.Subnets Lista de subredes en esta red

EJEMPLO

Inspecciona la red podman predeterminada.

$ podman network inspect podman
[
    {
        "name": "podman",
        "id": "2f259bab93aaaaa2542ba43ef33eb990d0999ee1b9924b557b7be53c0b7a1bb9",
        "driver": "bridge",
        "network_interface": "podman0",
        "created": "2021-06-03T12:04:33.088567413+02:00",
        "subnets": [
            {
                "subnet": "10.88.0.0/16",
                "gateway": "10.88.0.1"
            }
        ],
        "ipv6_enabled": false,
        "internal": false,
        "dns_enabled": false,
        "ipam_options": {
            "driver": "host-local"
        }
    }
]

Muestra la subred y la puerta de enlace para una red.

$ podman network inspect podman --format "{{range .Subnets}}Subnet: {{.Subnet}} Gateway: {{.Gateway}}{{end}}"
Subnet: 10.88.0.0/16 Gateway: 10.88.0.1
