CPOSVXX calcula la solución al sistema de ecuaciones lineales A * X = B para matrices PO

Propósito:

!>
!>    CPOSVXX utiliza la factorización de Cholesky A = U**T*U o A = L*L**T
!>    para calcular la solución a un sistema complejo de ecuaciones lineales
!>    A * X = B, donde A es una matriz Hermitiana positiva definida de N-por-N
!>    y X y B son matrices de N-por-NRHS.
!>
!>    Si se solicita, se devuelven límites de error tanto normativos como
!>    de componentes máximos. CPOSVXX devolverá una solución con un error
!>    garantizado pequeño (O(eps) donde eps es la precisión de la máquina
!>    de trabajo) a menos que la matriz sea muy mal condicionada, en cuyo
!>    caso se devuelve una advertencia. También se calculan y devuelven los
!>    números de condición relevantes.
!>
!>    CPOSVXX acepta factorizaciones y factores de equilibrado proporcionados
!>    por el usuario; consulte las definiciones de las opciones FACT y EQUED.
!>    Resolver con refinamiento y usar una factorización de una llamada previa
!>    a CPOSVXX también producirá una solución con errores O(eps) o advertencias,
!>    pero no podemos hacer esa afirmación para factorizaciones y factores de
!>    equilibrado generales proporcionados por el usuario si difieren de lo
!>    que CPOSVXX produciría por sí mismo.
!>

Descripción:

!>
!>    Se realizan los siguientes pasos:
!>
!>    1. Si FACT = 'E', se calculan factores de escala reales para equilibrar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se va a equilibrar o no depende de la escala de la matriz A,
!>    pero si se utiliza el equilibrado, A se sobrescribe por diag(S)*A*diag(S)
!>    y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después del equilibrado si FACT = 'E') como
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular
!>    inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    entonces la rutina retorna con INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A (ver argumento RCOND). Si la recíproca del número de condición
!>    es menor que la precisión de la máquina, la rutina continúa resolviendo
!>    para X y calculando los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residuo a
!>    al menos el doble de la precisión de trabajo.
!>
!>    6. Si se utilizó el equilibrado, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes del
!>    equilibrado.
!> 
!>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo
!>     los valores predeterminados son aceptables. Si los valores predeterminados
!>     son aceptables, los usuarios pueden pasar NPARAMS = 0, lo que evita que
!>     el código fuente acceda al argumento PARAMS.
!>

Parámetros

!>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona o no
!>     en la entrada, y si no, si la matriz A debe equilibrarse antes de
!>     factorizarse.
!>       = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A se ha equilibrado
!>               con factores de escala dados por S.
!>               A y AF no se modifican.
!>       = 'N':  La matriz A se copiará en AF y se factorizará.
!>       = 'E':  La matriz A se equilibrará si es necesario, luego
!>               se copiará en AF y se factorizará.
!>

!>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.

!>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.

NRHS

!>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas

A

!>          A es una matriz COMPLEX, de dimensión (LDA,N)
!>     En la entrada, la matriz Hermitiana A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz equilibrada
!>     diag(S)*A*diag(S). Si UPLO = 'U', la parte triangular superior
!>     de N-por-N de A contiene la parte triangular superior de la
!>     matriz A, y la parte estrictamente triangular inferior de A no
!>     se referencia. Si UPLO = 'L', la parte triangular inferior
!>     de N-por-N de A contiene la parte triangular inferior de la
!>     matriz A, y la parte estrictamente triangular superior de A no
!>     se referencia. A no se modifica si FACT = 'F' o 'N', o si FACT = 'E'
!>     y EQUED = 'N' en la salida.

!>     La dimensión principal de la matriz A.  LDA >= max(1,N).

LDAF

!>          LDAF es INTEGER

EQUED

!>          EQUED es CHARACTER*1
!>     Especifica la forma de equilibrado que se realizó.
!>       = 'N':  Sin equilibrado (siempre verdadero si FACT = 'N').
!>       = 'Y':  Equilibrado de filas y columnas, es decir, A ha sido
!>               reemplazado por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.

S

!>          S es un array REAL, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'Y', A se multiplica
!>     a la izquierda y a la derecha por diag(S). S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED
!>     = 'Y', cada elemento de S debe ser positivo. Si S es de salida, cada
!>     elemento de S es una potencia de la base. Si S es de entrada, cada elemento

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>     A la entrada, la matriz del lado derecho B de N-por-NRHS.

LDX

!>          LDX es INTEGER
!>     La dimensión principal del array X. LDX >= max(1,N).

RCOND

!>          RCOND es REAL
!>     Condición inversa escalada. Esta es una estimación de la
!>     condición inversa de Skeel de la matriz A después de
!>     el equilibrado (si se realizó). Si esto es menor que la precisión de
!>     la máquina (en particular, si es cero), la matriz es singular

!>          RPVGRW es REAL
!>     Crecimiento inverso del pivote. A la salida, contiene el recíproco

!>     0<INFO<=N, entonces esto contiene el factor de crecimiento inverso del pivote
!>     para las columnas principales INFO de A.

description: |-
  DPOSVXX computes the solution to the system of linear equations AX = B
  for symmetric positive definite matrices. It uses the Cholesky
  factorization A = U^T*U or A = L*L^T to solve the system, where U is
  upper triangular and L is lower triangular.

  The routine can optionally compute normwise and componentwise error bounds
  for the solution. It can also accept user-provided factorizations and
  equilibration factors, allowing for greater flexibility.

  DPOSVXX performs the following steps:
  1. If FACT = 'E', it equilibrates the system by scaling the matrix A
     and the right-hand side B.
  2. It computes the Cholesky factorization of A (or the equilibrated A).
  3. It estimates the condition number of A and returns its reciprocal in RCOND.
  4. It solves the system AX = B using the factored form of A.
  5. If requested and enabled by the PARAMS array, it uses iterative
     refinement to improve the accuracy of the solution.
  6. If equilibration was performed, it scales the solution X back to
     the original system.

  The PARAMS array allows users to control aspects of the iterative
  refinement process. If NPARAMS = 0, default settings are used.

  The routine returns an integer INFO indicating the status of the computation:
  - INFO = 0: Successful exit.
  - INFO < 0: An illegal value was returned for one of the input parameters.
  - INFO > 0: The leading principal minor of order INFO is not positive
              definite. The factorization could not be completed.

  Specific INFO values related to RCOND:
  - RCOND <= 0: The factorization is completed, but the factor U (or L)
                is exactly singular. The solution and error bounds cannot
                be computed. RCOND = 0 is returned.
  - INFO = N + J: The solution corresponding to the Jth right-hand side
                  is not guaranteed. This can happen if either the
                  normwise or componentwise error bound is not guaranteed
                  for that right-hand side. The routine reports the first
                  such right-hand side.

Parameters:
  FACT: CHARACTER*1
    Specifies whether to use a pre-computed factorization ('F'), compute
    a new factorization ('N'), or equilibrate and then compute a
    factorization ('E').
  UPLO: CHARACTER*1
    Specifies whether the upper ('U') or lower ('L') triangle of A is
    stored.
  N: INTEGER
    The number of linear equations (order of matrix A). N >= 0.
  NRHS: INTEGER
    The number of right-hand sides (number of columns in B and X). NRHS >= 0.
  A: DOUBLE PRECISION array, dimension (LDA, N)
    The symmetric matrix A. Modified if FACT = 'E' and equilibration is performed.
  LDA: INTEGER
    The leading dimension of the array A. LDA >= max(1, N).
  AF: DOUBLE PRECISION array, dimension (LDAF, N)
    The factored form of A. Contains U or L from the Cholesky factorization.
  LDAF: INTEGER
    The leading dimension of the array AF. LDAF >= max(1, N).
  EQUED: CHARACTER*1
    On entry (if FACT = 'F'), specifies if A has been equilibrated ('Y') or not ('N').
    On exit (if FACT = 'N' or 'E'), indicates if equilibration was performed.
  S: DOUBLE PRECISION array, dimension (N)
    The scale factors for equilibration. Input if FACT = 'F', output otherwise.
  B: DOUBLE PRECISION array, dimension (LDB, NRHS)
    The right-hand side matrix B. Modified if FACT = 'E' and equilibration is performed.
  LDB: INTEGER
    The leading dimension of the array B. LDB >= max(1, N).
  X: DOUBLE PRECISION array, dimension (LDX, NRHS)
    The solution matrix X. Contains the solution to AX = B.
  LDX: INTEGER
    The leading dimension of the array X. LDX >= max(1, N).
  RCOND: DOUBLE PRECISION
    The reciprocal of the condition number of A.
  RPVGRW: DOUBLE PRECISION
    Reciprocal pivot growth factor (relevant for some factorization routines,
    though less critical for Cholesky).
  BERR: DOUBLE PRECISION array, dimension (NRHS)
    Componentwise relative backward error for each right-hand side.
  N_ERR_BNDS: INTEGER
    The number of error bounds computed.

    zposvxx - solves a system of linear equations, optionally with
  iterative refinement, and computes error bounds and condition
  numbers.
    

    

    

    SYNOPSIS
    

    SUBROUTINE ZPOSVXX( FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, EQUED, S,
& B, LDB, X, LDX, RCOND, RPVGRW, BERR, N_ERR_BNDS, ERR_BNDS_NORM,
& ERR_BNDS_COMP, NPARAMS, PARAMS, WORK, RWORK, INFO )

    

    Arguments:
    

    

    CHARACTER
    

    FACT, UPLO, EQUED
    

    INTEGER
    

    N, NRHS, LDA, LDAF, LDB, LDX, N_ERR_BNDS, NPARAMS, INFO
    

    COMPLEX*16
    

    A( LDA, * ), AF( LDAF, * ), S( * ), B( LDB, * ), X( LDX, * ),
    WORK( * )
    

    DOUBLE PRECISION
    

    RCOND, RPVGRW, BERR( * ), ERR_BNDS_NORM( NRHS, * ),
    ERR_BNDS_COMP( NRHS, * ), PARAMS( * ), RWORK( * )
    

    

    

    

    DESCRIPTION
    

    ZPOSVXX solves a complex system of linear equations A*X = B,
  optionally with iterative refinement, and computes error bounds and condition
  numbers.
    

    A is an N-by-N Hermitian positive definite matrix and X and B are
  N-by-NRHS matrices.
    

    ZPOSVXX uses the Cholesky factorization A = U**H*U or A = L*L**H to
  compute the solution.
    

    If requested, both normwise and maximum componentwise error bounds
  are returned. ZPOSVXX will return a solution with a tiny guaranteed error
  (O(eps) where eps is the working machine precision) unless the matrix is very
  ill-conditioned, in which case a warning is returned. Relevant condition
  numbers also are calculated and returned.
    

    ZPOSVXX accepts user-provided factorizations and equilibration
  factors; see the definitions of the FACT and EQUED options.
    

    Solving with refinement and using a factorization other than LU
  is not supported.
    

    ZPOSVXX is similar to ZPOSVX, except for the arguments used to
  return error bounds and condition numbers.
    

    ZPOSVXX accepts user-provided factorizations and equilibration
  factors; see the definitions of the FACT and EQUED options.
    

    

    FACT
    

    !> FACT is CHARACTER*1
!> Specifies whether or not the factored form of the matrix A is supplied
!> on entry and whether the matrix A has been specified to befactored.
!> = 'F': On entry, AF contains the factored form of A.
!>        A is not modified and not referenced.
!> = 'N': The local copy AF of A will be factorized on 1st
!>        time the routine is called.
!>
    

    

    

    UPLO
    

    !> UPLO is CHARACTER*1
!> Specifies whether the matrix A is upper or lower triangular.
!> = 'U': Upper triangle of A is supplied.
!> = 'L': Lower triangle of A is supplied.
!>
    

    

    

    N
    

    !> N is INTEGER
!> The order of the matrix A.  N >= 0.
!>
    

    

    

    NRHS
    

    !> NRHS is INTEGER
!> The number of right hand sides, i.e., the number of columns of the
!> matrix B. NRHS >= 0.
!>
    

    

    

    A
    

    !> A is COMPLEX*16 array, dimension (LDA,N)
!> If FACT = 'F', then A is an input argument and on entry contains the
!>                factorization of A.
!>                The explicit details of SL and SU are known to the
!>                subroutine from the arguments FACT, UPLO and EQUED.
!> If FACT = 'N', then A is an output argument. On exit with INFO = 0,
!>                A contains the factorization of the original matrix.
!> The exact form of the factorization is determined by the arguments FACT,
!> UPLO and EQUED. See the description of AF below.
!>
    

    

    

    LDA
    

    !> LDA is INTEGER
!> The leading dimension of the array A.  LDA >= max(1,N).
!>
    

    

    

    AF
    

    !> AF is COMPLEX*16 array, dimension (LDAF,N)
!> If FACT = 'F', then AF is an input argument and on entry contains the
!>                factored form of the matrix A. The exact form of the
!>                factorization depends on the argument EQUED.
!> If FACT = 'N', then AF is an output argument. On exit with INFO = 0,
!>                AF contains the factored form of A.
!>
!> The factorization has the form U * ( D * U**H ) or L * ( D * L**H )
!>
!> If EQUED is not 'N', the lower or upper triangle of AF stores the
!> triangular factor L or U, and the diagonal array S stores the diagonal
!> elements of the diagonal matrix D. The upper or lower triangle respectively
!> of AF is not referenced.
!>
!> If EQUED is 'N', the diagonal matrix D is the identity matrix and is not
!> referenced. The diagonal elements of U or L are not referenced.
!>
    

    

    

    LDAF
    

    !> LDAF is INTEGER
!> The leading dimension of the array AF. LDAF >= max(1,N).
!>
    

    

    

    EQUED
    

    !> EQUED is CHARACTER*1
!> Specifies whether or not the matrix S contains equilibrium scaling
!> factors on entry.
!> = 'Y': The matrices A and B have been equilibrated with scaling
!>        factors in the array S. The solution X will be in the
!>        same scaled format as B.
!> = 'N': The matrices A and B have not been equilibrated.
!> = 'S': The solution is in the same scaled format as the input
!>        matrix S.
!>
    

    

    

    S
    

    !> S is DOUBLE PRECISION array, dimension (N)
!> If EQUED = 'Y', 'S', or 'X', then S contains the scaling factors
!>                for the rows of A and the vector B. The i-th row of A
!>                and the i-th element of B are multiplied by S(i).
!>                See the definition of EQUED.
!>
    

    

    

    B
    

    !> B is COMPLEX*16 array, dimension (LDB,NRHS)
!> The right hand side matrix B.  If EQUED = 'Y', B must have been
!> scaled by the vector S.
!>
    

    

    

    LDB
    

    !> LDB is INTEGER
!> The leading dimension of the array B. LDB >= max(1,N).
!>
    

    

    

    X
    

    !> X is COMPLEX*16 array, dimension (LDX,NRHS)
!> If FACT = 'F', then X is output argument containing the solution matrix X.
!> If FACT = 'N', then X is output argument containing the solution matrix X.
!> If EQUED = 'Y', the solution X is scaled by the vector S.
!>
    

    

    

    LDX
    

    !> LDX is INTEGER
!> The leading dimension of the array X. LDX >= max(1,N).
!>
    

    

    

    RCOND
    

    !> RCOND is DOUBLE PRECISION
!> The reciprocal of the condition number of the matrix A. The system
!> is ill-conditioned if RCOND is less than machine epsilon.
!>
    

    

    

    RPVGRW
    

    !> RPVGRW is DOUBLE PRECISION
!> The reciprocal of the pivot growth factor norm(A) / norm(diag(A)).
!> Satisfies RPVGRW >= 1. The system is ill-conditioned if RPVGRW is
!> large.
!>
    

    

    

    BERR
    

    !> BERR is DOUBLE PRECISION array, dimension (NRHS)
!> The componentwise backward error of the solution X for the k-th
!> right hand side in the k-th column of B. If K=1, 2, 3 and 4 then
!> BERR(k) is the componentwise backward error of the solution computed
!> by ZPOSV, ZPOSVX and ZPOSVXX respectively.
!>
    

    

    

    N_ERR_BNDS
    

    !> N_ERR_BNDS is INTEGER
!> The number of error bounds available in the arrays
!> ERR_BNDS_NORM and ERR_BNDS_COMP.
!>
    

    

    

    ERR_BNDS_NORM
    

    !> ERR_BNDS_NORM is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!> For each right hand side, this array contains information about
!> various error bounds and condition numbers corresponding to the
!> normwise relative error, which is defined as follows:
!>
!> Normwise relative error in the i-th solution vector:
!> max_j (abs(XTRUE(j,i) - X(j,i)))
!> ------------------------------
!> max_j abs(X(j,i))
!>
!> The array is indexed by the type of error information as described
!> below. There currently are up to three pieces of information
!> returned.
!>
!> The first index in ERR_BNDS_NORM(i,:) corresponds to the i-th
!> right hand side.
!>
!> The second index in ERR_BNDS_NORM(:,err) contains the following
!> three fields:
!> err = 1  boolean. Trust the answer if the
!>          reciprocal condition number is less than the threshold
!>          sqrt(N) * SLAMCH('Epsilon').
!>
!> err = 2  error bound: The estimated forward error,
!>          almost certainly within a factor of 10 of the true error
!>          so long as the next entry is greater than the threshold
!>          sqrt(N) * SLAMCH('Epsilon'). This error bound should only
!>          be trusted if the previous boolean is true.
!>
!> err = 3  Reciprocal condition number: Estimated normwise
!>          reciprocal condition number. Compared with the threshold
!>          sqrt(N) * SLAMCH('Epsilon') to determine if the error
!>          estimate is . These reciprocal condition
!>          numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>          appropriately scaled matrix Z.
!>          Let Z = S*A, where S scales each row by a power of the
!>          radix so all absolute row sums of Z are approximately 1.
!>
!> See Lapack Working Note 165 for further details and extra
!> cautions.
!>
    

    

    

    ERR_BNDS_COMP
    

    !> ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!> For each right hand side, this array contains information about
!> various error bounds and condition numbers corresponding to the
!> componentwise relative error, which is defined as follows:
!>
!> Componentwise relative error in the i-th solution vector:
!> max_j (abs(XTRUE(j,i) - X(j,i)) / abs(X(j,i)))
!>
!> The array is indexed by the right hand side i (on which the
!> componentwise relative error depends), and the type of error
!> information as described below. There currently are up to three
!> pieces of information returned for each right hand side. If
!> componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!> ERR_BNDS_COMP is not accessed. If N_ERR_BNDS < 3, then at most
!> the first (:,N_ERR_BNDS) entries are returned.
!>
!> The first index in ERR_BNDS_COMP(i,:) corresponds to the i-th
!> right hand side.
!>
!> The second index in ERR_BNDS_COMP(:,err) contains the following
!> three fields:
!> err = 1  boolean. Trust the answer if the
!>          reciprocal condition number is less than the threshold
!>          sqrt(N) * SLAMCH('Epsilon').
!>
!> err = 2  error bound: The estimated forward error,
!>          almost certainly within a factor of 10 of the true error
!>          so long as the next entry is greater than the threshold
!>          sqrt(N) * SLAMCH('Epsilon'). This error bound should only
!>          be trusted if the previous boolean is true.
!>
!> err = 3  Reciprocal condition number: Estimated componentwise
!>          reciprocal condition number. Compared with the threshold
!>          sqrt(N) * SLAMCH('Epsilon') to determine if the error
!>          estimate is . These reciprocal condition
!>          numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>          appropriately scaled matrix Z.
!>          Let Z = S*(A*diag(x)), where x is the solution for the
!>          current right hand side and S scales each row of
!>          A*diag(x) by a power of the radix so all absolute row
!>          sums of Z are approximately 1.
!>
!> See Lapack Working Note 165 for further details and extra
!> cautions.
!>
    

    

    

    NPARAMS
    

    !> NPARAMS is INTEGER
!> Specifies the number of parameters set in PARAMS. If <= 0, the
!> PARAMS array is never referenced and default values are used.
!>
    

    

    

    PARAMS
    

    !> PARAMS is DOUBLE PRECISION array, dimension NPARAMS
!> Specifies algorithm parameters. If an entry is < 0.0, then
!> that entry will be filled with default value used for that
!> parameter. Only positions up to NPARAMS are accessed; defaults
!> are used for higher-numbered parameters.
!>
!> PARAMS(LA_LINRX_ITREF_I = 1) : Whether to perform iterative
!>      refinement or not.
!>   Default: 1.0
!>      = 0.0: No refinement is performed, and no error bounds are
!>             computed.
!>      = 1.0: Use the double-precision refinement algorithm,
!>             possibly with doubled-single computations if the
!>             compilation environment does not support DOUBLE
!>             PRECISION.
!>        (other values are reserved for future use)
!>
!> PARAMS(LA_LINRX_ITHRESH_I = 2) : Maximum number of residual
!>      computations allowed for refinement.
!>   Default: 10
!>   Aggressive: Set to 100 to permit convergence using approximate
!>               factorizations or factorizations other than LU. If
!>               the factorization uses a technique other than
!>               Gaussian elimination, the guarantees in
!>               err_bnds_norm and err_bnds_comp may no longer be
!>               trustworthy.
!>
!> PARAMS(LA_LINRX_CWISE_I = 3) : Flag determining if the code
!>      will attempt to find a solution with small componentwise
!>      relative error in the double-precision algorithm. Positive
!>      is true, 0.0 is false.
!>   Default: 1.0 (attempt componentwise convergence)
!>
    

    

    

    WORK
    

    !> WORK is COMPLEX*16 array, dimension (4*N)
!>
    

    

    

    RWORK
    

    !> RWORK is DOUBLE PRECISION array, dimension (4*N)
!>
    

    

    

    INFO
    

    !> INFO is INTEGER
!> = 0: Successful exit. The solution to every right-hand side is
!>      guaranteed.
!> < 0: If INFO = -i, the i-th argument had an illegal value
!> > 0 and <= N: U(INFO,INFO) is exactly zero. The factorization
!>    has been completed, but the factor U is exactly singular, so
!>    the solution and error bounds could not be computed. RCOND = 0
!>    is returned.
!> = N+J: The solution corresponding to the Jth right-hand side is
!>    not guaranteed. The solutions corresponding to other right-
!>    hand sides K with K > J may not be guaranteed as well, but
!>    only the first such right-hand side is reported. If a small
!>    componentwise error is not requested (PARAMS(3) = 0.0) then
!>    the Jth right-hand side is the first with a normwise error
!>    bound that is not guaranteed (the smallest J such
!>    that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>    the Jth right-hand side is the first with either a normwise or
!>    componentwise error bound that is not guaranteed (the smallest
!>    J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>    ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>    ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>    about all of the right-hand sides check ERR_BNDS_NORM or
!>    ERR_BNDS_COMP.
!>

    DEFINITION
    

    Line 493 of spolvxx.f
    

    

    
!> La factorización de una llamada previa a ZPOSVXX también producirá una solución con errores
!> de O(eps) o advertencias, pero no podemos hacer esa afirmación para factorizaciones
!> generales proporcionadas por el usuario y factores de ecualización si difieren de lo que
!> ZPOSVXX produciría por sí mismo.
!>

    Descripción:

    !>
!> Los siguientes pasos se realizan:
!>
!>    1. Si FACT = 'E', se calculan factores de escala de doble precisión para ecualizar
!>    el sistema:
!>
!>      diag(S)*A*diag(S)     *inv(diag(S))*X = diag(S)*B
!>
!>    Si el sistema se ecualizará o no depende del escalado de la matriz A, pero si se utiliza la ecualización,
!>    A se sobrescribe por diag(S)*A*diag(S) y B por diag(S)*B.
!>
!>    2. Si FACT = 'N' o 'E', se utiliza la descomposición de Cholesky para
!>    factorizar la matriz A (después de la ecualización si FACT = 'E') como:
!>       A = U**T* U,  si UPLO = 'U', o
!>       A = L * L**T,  si UPLO = 'L',
!>    donde U es una matriz triangular superior y L es una matriz triangular inferior.
!>
!>    3. Si el menor principal principal de orden i no es positivo,
!>    la rutina devuelve INFO = i. De lo contrario, la forma factorizada
!>    de A se utiliza para estimar el número de condición de la matriz
!>    A (ver argumento RCOND). Si la inversa del número de condición
!>    es menor que la precisión de la máquina, la rutina aún continúa para
!>    resolver X y calcular los límites de error como se describe a continuación.
!>
!>    4. El sistema de ecuaciones se resuelve para X utilizando la forma factorizada
!>    de A.
!>
!>    5. Por defecto (a menos que PARAMS(LA_LINRX_ITREF_I) se establezca en cero),
!>    la rutina utilizará refinamiento iterativo para intentar obtener un error
!>    y límites de error pequeños. El refinamiento calcula el residuo
!>    al menos al doble de la precisión de trabajo.
!>
!>    6. Si se utilizó la ecualización, la matriz X se premultiplica por
!>    diag(S) para que resuelva el sistema original antes de
!>    la ecualización.
!> 
    !>     Algunos parámetros opcionales se agrupan en la matriz PARAMS. Estas
!>     configuraciones determinan cómo se realiza el refinamiento, pero a menudo los
!>     valores predeterminados son aceptables. Si los valores predeterminados son aceptables, los usuarios
!>     pueden pasar NPARAMS = 0, lo que evita que el código fuente acceda
!>     al argumento PARAMS.
!>

    Parámetros

    FACT 
    !>          FACT es CHARACTER*1
!>     Especifica si la forma factorizada de la matriz A se proporciona
!>     en la entrada, y si no, si la matriz A debe ser
!>     ecualizada antes de ser factorizada.
!>       = 'F':  En la entrada, AF contiene la forma factorizada de A.
!>               Si EQUED no es 'N', la matriz A ha sido
!>               ecualizada con factores de escala dados por S.
!>               A y AF no se modifican.
!>       = 'N':  La matriz A se copiará a AF y se factorizará.
!>       = 'E':  La matriz A se ecualizará si es necesario, luego
!>               se copiará a AF y se factorizará.
!>

    UPLO

    !>          UPLO es CHARACTER*1
!>       = 'U':  Se almacena el triángulo superior de A;
!>       = 'L':  Se almacena el triángulo inferior de A.
!>

    N

    !>          N es INTEGER
!>     El número de ecuaciones lineales, es decir, el orden de la
!>     matriz A.  N >= 0.
!>

    NRHS

    !>          NRHS es INTEGER
!>     El número de lados derechos, es decir, el número de columnas
!>     de las matrices B y X.  NRHS >= 0.
!>

    A

    !>          A es array COMPLEX*16, de dimensión (LDA,N)
!>     En la entrada, la matriz Hermitiana A, excepto si FACT = 'F' y EQUED =
!>     'Y', entonces A debe contener la matriz ecualizada
!>     diag(S)*A*diag(S).  Si UPLO = 'U', la parte triangular superior
!>     N por N principal de A contiene la parte triangular superior de
!>     la matriz A, y la parte estrictamente triangular inferior de A no se
!>     referencia. Si UPLO = 'L', la parte triangular inferior
!>     N por N principal de A contiene la parte triangular inferior de la
!>     matriz A, y la parte estrictamente triangular superior de A no se
!>     referencia. A no se modifica si FACT = 'F' o 'N', o si FACT = 'E' y EQUED =
!>     'N' en la salida.
!>
!>     En la salida, si FACT = 'E' y EQUED = 'Y', A se sobrescribe por
!>     diag(S)*A*diag(S).
!>

    LDA

    !>          LDA es INTEGER
!>     La dimensión principal del array A.  LDA >= max(1,N).
!>

    AF

    !>          AF es array COMPLEX*16, de dimensión (LDAF,N)
!>     Si FACT = 'F', entonces AF es un argumento de entrada y en la entrada
!>     contiene el factor triangular U o L de la descomposición de Cholesky
!>     A = U**T*U o A = L*L**T, en el mismo formato de almacenamiento
!>     que A. Si EQUED .ne. 'N', entonces AF es la forma factorizada
!>     de la matriz ecualizada diag(S)*A*diag(S).
!>
!>     Si FACT = 'N', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la descomposición de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz original
!>     A.
!>
!>     Si FACT = 'E', entonces AF es un argumento de salida y en la salida
!>     devuelve el factor triangular U o L de la descomposición de Cholesky
!>     A = U**T*U o A = L*L**T de la matriz ecualizada
!>     A (ver la descripción de A para la forma de la
!>     matriz ecualizada).
!>

    LDAF

    !>          LDAF es INTEGER
!>     La dimensión principal del array AF.  LDAF >= max(1,N).
!>

    EQUED

    !>          EQUED es CHARACTER*1
!>     Especifica la forma de ecualización que se realizó.
!>       = 'N':  Sin ecualización (siempre verdadero si FACT = 'N').
!>       = 'Y':  Ecualización tanto de filas como de columnas, es decir, A ha sido
!>               reemplazada por diag(S) * A * diag(S).
!>     EQUED es un argumento de entrada si FACT = 'F'; de lo contrario, es un
!>     argumento de salida.
!>

    S

    !>          S es array DOUBLE PRECISION, de dimensión (N)
!>     Los factores de escala de fila para A. Si EQUED = 'Y', A se multiplica a
!>     la izquierda y a la derecha por diag(S). S es un argumento de entrada si FACT =
!>     'F'; de lo contrario, S es un argumento de salida. Si FACT = 'F' y EQUED =
!>     'Y', cada elemento de S debe ser positivo. Si S es salida, cada
!>     elemento de S es una potencia de la base. Si S es entrada, cada elemento
!>     de S debe ser una potencia de la base para garantizar una solución fiable
!>     y estimaciones de error. El escalado por potencias de la base no causa
!>     errores de redondeo a menos que el resultado desborde o subdesborde.
!>     Los errores de redondeo durante el escalado conducen a un refinamiento con una matriz que
!>     no es equivalente a la matriz de entrada, produciendo estimaciones de error
!>     que pueden no ser fiables.
!>

    B

    !>          B es array COMPLEX*16, de dimensión (LDB,NRHS)
!>     En la entrada, la matriz del lado derecho B de N por NRHS.
!>     En la salida,
!>     si EQUED = 'N', B no se modifica;
!>     si EQUED = 'Y', B se sobrescribe por diag(S)*B;
!>

    LDB

    !>          LDB es INTEGER
!>     La dimensión principal del array B.  LDB >= max(1,N).
!>

    X

    !>          X es array COMPLEX*16, de dimensión (LDX,NRHS)
!>     Si INFO = 0, la matriz solución X de N por NRHS al sistema original
!>     de ecuaciones.  Tenga en cuenta que A y B se modifican en la salida si
!>     EQUED .ne. 'N', y la solución al sistema ecualizado es
!>     inv(diag(S))*X.
!>

    LDX

    !>          LDX es INTEGER
!>     La dimensión principal del array X.  LDX >= max(1,N).
!>

    RCOND

    !>          RCOND es DOUBLE PRECISION
!>     Condición inversa escalada.  Esta es una estimación de la
!>     condición inversa de Skeel de la matriz A después de
!>     la ecualización (si se realizó). Si esto es menor que la precisión
!>     de la máquina (en particular, si es cero), la matriz es singular
!>     a la precisión de trabajo. Tenga en cuenta que el error aún puede ser pequeño incluso
!>     si este número es muy pequeño y la matriz parece mal
!>     condicionada.
!>

    RPVGRW

    !>          RPVGRW es DOUBLE PRECISION
!>     Crecimiento de pivote recíproco. En la salida, esto contiene el factor
!>     de crecimiento de pivote recíproco norm(A)/norm(U). Se utiliza la
!>     norma. Si esto es mucho menor que 1, entonces la estabilidad de
!>     la factorización LU de la matriz A (ecualizada) podría ser pobre.
!>     Esto también significa que la solución X, los números de condición estimados
!>     y los límites de error podrían no ser fiables. Si la factorización falla con
!>     0<INFO<=N, entonces esto contiene el factor de crecimiento de pivote recíproco
!>     para las columnas INFO principales de A.
!>

    Detailed Description

    This subroutine is part of the LAPACK routines that compute the solution to a linear system of equations AX=B.

    posvxx computes the solution to a real system of equations AX=B, where A is an N-by-N complex matrix, the columns of B are NRHS right-hand sides, and the columns of X are the corresponding solutions.

    Two different approaches are supported to solve the system:

    1. iterative refinement: The routine uses iterative refinement to reduce the final error of the solution. The solution is computed in double precision and then the residual is computed in higher precision.
    2. componentwise accuracy: The routine attempts to find a solution X with a small componentwise relative error.

    In addition, the routine provides an estimate on the reciprocal condition number of the matrix A.

    The possible values of the argument PATH are:

    "Z"
    LAPACK routines that compute the solution to a linear system of equations.
    "P"
    LAPACK routines that compute the solution to a least squares problem.

    The possible values of the argument UPLO are:

    'U'
    Upper triangle of A is stored and NCOV is used.
    'L'
    Lower triangle of A is stored and NWCOV is used.

    ERR_BNDS_COMP

    !>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
!>     For each right-hand side, this array contains information about
!>     various error bounds and condition numbers corresponding to the
!>     componentwise relative error, which is defined as follows:
!>
!>     Componentwise relative error in the ith solution vector:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     The array is indexed by the right-hand side i (on which the
!>     componentwise relative error depends), and the type of error
!>     information as described below. There currently are up to three
!>     pieces of information returned for each right-hand side. If
!>     componentwise accuracy is not requested (PARAMS(3) = 0.0), then
!>     ERR_BNDS_COMP is not accessed.  If N_ERR_BNDS < 3, then at most
!>     the first (:,N_ERR_BNDS) entries are returned.
!>
!>     The first index in ERR_BNDS_COMP(i,:) corresponds to the ith
!>     right-hand side.
!>
!>     The second index in ERR_BNDS_COMP(:,err) contains the following
!>     three fields:
!>     err = 1  boolean. Trust the answer if the
!>              reciprocal condition number is less than the threshold
!>              sqrt(n) * dlamch('Epsilon').
!>
!>     err = 2  error bound: The estimated forward error,
!>              almost certainly within a factor of 10 of the true error
!>              so long as the next entry is greater than the threshold
!>              sqrt(n) * dlamch('Epsilon'). This error bound should only
!>              be trusted if the previous boolean is true.
!>
!>     err = 3  Reciprocal condition number: Estimated componentwise
!>              reciprocal condition number.  Compared with the threshold
!>              sqrt(n) * dlamch('Epsilon') to determine if the error
!>              estimate is . These reciprocal condition
!>              numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
!>              appropriately scaled matrix Z.
!>              Let Z = S*(A*diag(x)), where x is the solution for the
!>              current right-hand side and S scales each row of
!>              A*diag(x) by a power of the radix so all absolute row
!!>              sums of Z are approximately 1.
!>
!>     See Lapack Working Note 165 for further details and extra
!>     cautions.
!>
