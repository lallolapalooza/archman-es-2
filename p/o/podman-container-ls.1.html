NOMBRE

podman-ps - Imprime información sobre contenedores

SINOPSIS

podman ps [opciones]

podman container ps [opciones]

podman container list [opciones]

podman container ls [opciones]

DESCRIPCIÓN

podman ps lista los contenedores en ejecución en el sistema. Usa la opción --all para ver toda la información de los contenedores. Por defecto, lista:

  • id del contenedor
  • el nombre de la imagen que usa el contenedor
  • el COMANDO que ejecuta el contenedor
  • el tiempo en que se creó el contenedor
  • el estado del contenedor
  • mapeos de puertos que usa el contenedor
  • nombres alternativos para el contenedor

OPCIONES

--all, -a

Muestra todos los contenedores; por defecto, solo los contenedores en ejecución.

Nota: Podman comparte el almacenamiento de contenedores con otras herramientas como Buildah y CRI-O. En algunos casos, estos contenedores externos también pueden existir en el mismo almacenamiento. Usa la opción --external para ver estos contenedores externos. Los contenedores externos muestran el estado de 'almacenamiento' (storage).

--external

Muestra contenedores externos que no son controlados por Podman pero que están almacenados en el almacenamiento de contenedores. Estos contenedores externos se crean generalmente a través de otra tecnología de contenedores, como Buildah o CRI-O, y pueden depender de las mismas imágenes de contenedor que también usa Podman. Los contenedores externos se denotan con 'buildah' o 'storage' en las columnas COMMAND y STATUS de la salida de ps.

--filter, -f

Filtra qué contenedores se muestran en la salida. Se pueden dar múltiples filtros usando el flag --filter varias veces. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
label! [Clave] o [Clave=Valor] Etiqueta NO asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizada para crear el contenedor (acepta regex)
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [FechaHora] contenedor creado antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--format=formato

Imprime contenedores en formato JSON o usando una plantilla Go.

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.AutoRemove Si es verdadero, los contenedores se eliminan al salir.
.CIDFile Archivo de ID del contenedor
.Command Comando entre comillas utilizado
.Created ... Tiempo de creación del contenedor, A-M-D H:M:S
.CreatedAt Tiempo de creación del contenedor (igual que el anterior)
.CreatedHuman Tiempo de creación, relativo
.ExitCode Código de salida del contenedor
.Exited "true" si el contenedor ha salido
.ExitedAt Tiempo (segundos de época) en que el contenedor salió
.ExposedPorts ... Mapa de puertos expuestos en este contenedor
.ID ID del contenedor
.Image Nombre/ID de la imagen
.ImageID ID de la imagen
.IsInfra "true" si es un contenedor de infraestructura
.Label cadena Etiqueta especificada del contenedor
.Labels ... Todas las etiquetas asignadas al contenedor
.Mounts Volúmenes montados en el contenedor
.Names Nombre del contenedor
.Networks Muestra todas las redes conectadas al contenedor
.Pid ID del proceso en el sistema anfitrión
.Pod Pod al que está asociado el contenedor (SHA)
.PodName Nombre del pod del contenedor
.Ports Puertos reenviados y expuestos
.Restarts Muestra el recuento de reinicios del contenedor
.RunningFor Tiempo transcurrido desde que se inició el contenedor
.Size Tamaño del contenedor
.StartedAt Tiempo (segundos de época) en que se inició el contenedor
.State Descripción amigable del estado del contenedor
.Status Estado del contenedor

--help, -h

Imprime el enunciado de uso.

--last, -n

Imprime los n últimos contenedores creados (todos los estados).

--latest, -l

Muestra el último contenedor creado (todos los estados). (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--namespace, --ns

Muestra información del espacio de nombres.

--no-trunc

No trunca la salida (por defecto *falso*).

--noheading

Omite los encabezados de tabla de la lista de contenedores.

--pod, -p

Muestra los pods a los que están asociados los contenedores.

--quiet, -q

Imprime solo los IDs numéricos de los contenedores.

--size, -s

Muestra el tamaño total del archivo.

--sort=creado

Ordena por comando, creado, id, imagen, nombres, tiempo en ejecución, tamaño o estado". Nota: Elegir tamaño ordena por el tamaño del sistema de archivos raíz (rootFs), no alfabéticamente como el resto de las opciones.

--sync

Fuerza una sincronización del estado del contenedor con el runtime OCI. En algunos casos, el estado de un contenedor en el runtime puede desincronizarse con el estado de Podman. Esto actualiza el estado de Podman basándose en lo que informa el runtime OCI. La sincronización forzada es mucho más lenta, pero puede resolver problemas de estado inconsistentes.

--watch, -w

Actualiza la salida con los contenedores actuales en un intervalo de segundos.

EJEMPLOS

Listar contenedores en ejecución.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES

NOMBRE


podman-container-ls, podman ps - Listar contenedores






SINOPSIS


podman container ls [opciones] [selector ...]


podman ps [opciones] [selector ...]






DESCRIPCIÓN


Lista contenedores definidos en el sistema. Por defecto, solo se
    muestran los contenedores que están en ejecución.






OPCIONES


Las opciones específicas de Podman que no afectan a comandos
    similares de otros programas:




-a, --all


No mostrar solo los contenedores en ejecución, mostrar todos los
      contenedores (terminados también).


-f, --filter selector


Filtrar la salida basándose en un selector. El formato
      del selector es key=value. Los selectores
      disponibles son:
      

      
format

      
Un string de formato Go para imprimir información sobre los
          contenedores. El valor predeterminado para podman ps
          es
          {{.ID}\t{{.Image}\t{{.Command}\t{{.CreatedAt}\t{{.Status}\t{{.Ports}\t{{.Names}}}}}}.
          El valor predeterminado para podman ps -a es
          {{.ID}\t{{.Image}\t{{.Command}\t{{.CreatedAt}\t{{.Status}\t{{.Ports}\t{{.Names}}}}}}.

      
label

      
Filtra los contenedores por una etiqueta (label) establecida. El
          formato es label=key o
          label=key=value.
          podman ps -a --filter label=mylabel
          podman ps -a --filter label=mylabel=myvalue

      
network

      
Filtra los contenedores por una red especificada.
          podman ps --filter network=mynet

      
name

      
Filtra los contenedores por nombre.
          podman ps --filter name=webserver

      
pod

      
Filtra los contenedores por nombre de pod.
          podman ps --filter pod=mypod

      
status

      
Filtra los contenedores por estado. Los valores válidos son
          created, dead,
          running, paused,
          exited, all.
          podman ps --filter status=running
          podman ps -a --filter status=exited

      
volume

      
Filtra los contenedores por un volumen especificado.
          podman ps --filter volume=mydata

      

      
Hay más selectores disponibles que no están documentados
          aquí.

      
Los siguientes selectores solo funcionan cuando se utiliza
          la opción --pod:

      

      
pod

      
Filtra los contenedores por el ID del pod.
          podman ps --pod --filter pod=1234567890ab

      
podname

      
Filtra los contenedores por el nombre del pod.
          podman ps --pod --filter podname=web-pod

      

    


--format golang-template


Utilizar un template Go para dar formato a la salida. Los valores válidos
      para el template son:
      

      
.ID

      
El ID del contenedor.

      
.Image

      
La imagen que se utilizó para crear el contenedor.

      
.Command

      
El comando que se está ejecutando en el contenedor.

      
.CreatedAt

      
La hora en que se creó el contenedor.

      
.Status

      
El estado actual del contenedor.

      
.Ports

      
Los puertos que el contenedor está exponiendo.

      
.Names

      
El nombre del contenedor.

      
.Mounts

      
Los puntos de montaje del contenedor.

      
.Labels

      
Las etiquetas del contenedor.

      
.PID

      
El PID del proceso principal del contenedor.

      
.RootFSImage

      
La imagen del RootFS del contenedor.

      
.RunningFor

      
Cuánto tiempo ha estado ejecutándose el contenedor.

      
.Size

      
El tamaño del contenedor.

      
.PIDNS

      
El ID del namespace PID del contenedor.

      
.MntNS

      
El ID del namespace de montaje del contenedor.

      
.NetNS

      
El ID del namespace de red del contenedor.

      
.IpcNS

      
El ID del namespace IPC del contenedor.

      
.UTSNS

      
El ID del namespace UTS del contenedor.

      
.UserNS

      
El ID del namespace de usuario del contenedor.

      
.CgroupNS

      
El ID del namespace cgroup del contenedor.

      
.Pod

      
El ID del pod al que pertenece el contenedor.

      
.PodName

      
El nombre del pod al que pertenece el contenedor.

      

    


-s, --size


Mostrar el tamaño total de los contenedores en disco. Esto incluye la imagen
      y todas las capas de escritura de los contenedores.


--sort ordering


Ordena la salida. El valor predeterminado es created.
      Los valores disponibles son ID, Image,
      Command, CreatedAt, Status,
      Ports, Names, Size.


--external


Muestra contenedores externos, que son contenedores no gestionados por
      Podman. Solo se mostrarán los contenedores externos si se utiliza
      con --all.


--pod


Mostrar información sobre los pods de los contenedores. Esto incluye el ID
      del pod y el nombre del pod. También se pueden listar contenedores que no
      pertenecen a ningún pod.


--ns


Muestra información sobre los namespaces de los contenedores. Esto incluye
      el PID y el ID de cada namespace asociado al contenedor.




Opciones comunes:




--help


Imprime un mensaje de uso.
