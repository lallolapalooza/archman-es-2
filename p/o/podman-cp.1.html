NOMBRE

podman-cp - Copiar archivos/carpetas entre un contenedor y el sistema de archivos local

SINOPSIS

podman cp [opciones] [contenedor:]ruta_origen [contenedor:]ruta_destino

podman container cp [opciones] [contenedor:]ruta_origen [contenedor:]ruta_destino

DESCRIPCIÓN

podman cp permite copiar el contenido de ruta_origen a la ruta_destino. Los archivos pueden ser copiados de un contenedor a la máquina local y viceversa, o entre dos contenedores. Si se especifica - para RUTA_ORIGEN o RUTA_DESTINO, también se puede transmitir un archivo tar desde STDIN o a STDOUT.

Los contenedores pueden estar en ejecución o detenidos y la ruta_origen o ruta_destino pueden ser un archivo o directorio.

*IMPORTANTE: El comando podman cp asume que las rutas de los contenedores son relativas al directorio raíz del contenedor (/), lo que significa que proporcionar la barra inclinada inicial es opcional y, por lo tanto, considera compassionate_darwin:/tmp/foo/myfile.txt y compassionate_darwin:tmp/foo/myfile.txt como idénticos.*

Las rutas de la máquina local pueden ser un valor absoluto o relativo. El comando interpreta las rutas relativas de una máquina local como relativas al directorio de trabajo actual donde se ejecuta podman cp.

Asumiendo un separador de rutas de /, un primer argumento de ruta_origen y un segundo argumento de ruta_destino, el comportamiento es el siguiente:

ruta_origen especifica un archivo:
- ruta_destino no existe
- el archivo se guarda en un archivo creado en ruta_destino (ten en cuenta que el directorio padre debe existir).
- ruta_destino existe y es un archivo
- el destino se sobrescribe con el contenido del archivo de origen.
- ruta_destino existe y es un directorio
- el archivo se copia dentro de este directorio utilizando el nombre base de ruta_origen.

ruta_origen especifica un directorio:
- ruta_destino no existe
- ruta_destino se crea como un directorio y el contenido del directorio de origen se copia dentro de este directorio.
- ruta_destino existe y es un archivo
- Condición de error: no se puede copiar un directorio a un archivo.
- ruta_destino existe y es un directorio
- ruta_origen termina en /
- el directorio de origen se copia dentro de este directorio.
- ruta_origen termina en /. (es decir, barra seguida de punto)
- el contenido del directorio de origen se copia dentro de este directorio.

El comando requiere que ruta_origen y ruta_destino existan de acuerdo con las reglas anteriores.

Si ruta_origen es local y es un enlace simbólico, el objetivo del enlace simbólico se copia por defecto.

Dos puntos ( : ) se utilizan como delimitador entre un contenedor y su ruta; también se pueden usar al especificar rutas a una ruta_origen o ruta_destino en una máquina local, por ejemplo, archivo:nombre.txt.

*IMPORTANTE: al usar dos puntos ( : ) en una ruta de máquina local, se debe ser explícito con una ruta relativa o absoluta, por ejemplo: /ruta/al/archivo:nombre.txt o ./archivo:nombre.txt*

Usar - como ruta_origen transmite el contenido de STDIN como un archivo tar. El comando extrae el contenido del tar en la RUTA_DESTINO en el contenedor. En este caso, ruta_destino debe especificar un directorio. Usar - como ruta_destino transmite el contenido del recurso (puede ser un directorio) como un archivo tar a STDOUT.

Ten en cuenta que podman cp ignora los errores de permisos al copiar desde un contenedor sin root en ejecución. Los dispositivos TTY dentro de un contenedor sin root son propiedad del usuario root del host y, por lo tanto, no se pueden leer dentro del espacio de nombres de usuario del contenedor.

Además, ten en cuenta que podman cp no admite comodines (por ejemplo, cp dir/*.txt). Para copiar varios archivos del host al contenedor, usa xargs(1) o find(1) (o herramientas similares para encadenar comandos) junto con podman cp. Para copiar varios archivos del contenedor al host, usa podman mount CONTENEDOR y opera en el punto de montaje devuelto en su lugar (ver ALTERNATIVAS a continuación).

OPCIONES

--archive, -a

Modo archivo (copiar toda la información UID/GID). Cuando se establece en verdadero, los archivos copiados a un contenedor tienen su propiedad cambiada al UID/GID principal del contenedor. Cuando se establece en falso, mantiene el UID/GID de las fuentes del archivo en lugar de cambiarlos al UID/GID principal del contenedor de destino. El valor predeterminado es verdadero.

--overwrite

Permite sobrescribir directorios con no directorios y viceversa. Por defecto, podman cp genera un error al intentar sobrescribir, por ejemplo, un archivo regular con un directorio.

ALTERNATIVAS

Podman tiene capacidades mucho más potentes que solo podman cp para lograr la copia de archivos entre el host y los contenedores.

Usar podman-mount(1) y podman-unmount(1) estándar aprovecha toda la cadena de herramientas de Linux, en lugar de solo cp.

Copiar contenido de un contenedor o hacia un contenedor se puede lograr con algunos comandos simples. Por ejemplo:

Para copiar el directorio /etc/foobar de un contenedor al host en /tmp, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
cp -R ${mnt}/etc/foobar /tmp
podman umount CONTENEDORID

Para descomprimir un archivo tar en un contenedor, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
tar xf contenido.tgz -C ${mnt}
podman umount CONTENEDORID

Para instalar un paquete en un contenedor que no tiene dnf instalado, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
dnf install --installroot=${mnt} httpd
chroot ${mnt} rm -rf /var/log/dnf /var/cache/dnf
podman umount CONTENEDORID

Al usar podman mount y podman unmount, se pueden usar todas las herramientas estándar de Linux para mover archivos dentro y fuera de los contenedores, no solo el comando cp.

EJEMPLOS

Copiar un archivo del host a un contenedor:

podman cp /myapp/app.conf id_contenedor:/myapp/app.conf

Copiar un archivo de un contenedor a un directorio de otro contenedor:

podman cp id_contenedor1:/archivo.txt id_contenedor2:/tmp

Copiar un directorio en un contenedor a un directorio en el host:

podman cp id_contenedor:/myapp/ /myapp/

Copiar el contenido de un directorio en un contenedor a un directorio en el host:

podman cp id_contenedor:/home/miusuario/. /home/miusuario/

Copiar un directorio en un contenedor a un directorio en otro:

podman cp contenedorA:/myapp contenedorB:/newapp

Transmitir un archivo tar desde STDIN a un contenedor:

podman cp - id_contenedor:/misarchivos.tar.gz < misarchivos.tar.gz

VER TAMBIÉN

podman(1), podman-mount(1), podman-unmount(1)
