NOMBRE

podman-container-cleanup - Limpia la red y los puntos de montaje del contenedor

SINOPSIS

podman container cleanup [opciones] contenedor [contenedor ...]

DESCRIPCIÓN

podman container cleanup limpia los contenedores que han salido eliminando todos los puntos de montaje y configuraciones de red del host. Se puede usar el nombre o el ID del contenedor. El comando de limpieza no elimina los contenedores. Los contenedores en ejecución no se limpian.
A veces, los puntos de montaje y las pilas de red de los contenedores pueden permanecer si el comando podman fue interrumpido o si el contenedor se ejecutó en modo demonio. Este comando se ejecuta automáticamente cuando los contenedores se ejecutan en modo demonio por el proceso conmon cuando el contenedor sale.

OPCIONES

--all, -a

Limpia todos los contenedores.
El valor predeterminado es false.
IMPORTANTE: ESTA OPCIÓN no necesita un nombre o ID de contenedor como argumento de entrada.

--exec=sesión

Limpia una sesión de ejecución para un único contenedor. Solo se puede especificar si se está limpiando un único contenedor (por lo tanto, entra en conflicto con --all). Si no se especifica --rm, se limpian los archivos temporales de la sesión de ejecución; si se especifica, la sesión de ejecución se elimina del contenedor.
*IMPORTANTE: Entra en conflicto con --rmi ya que el contenedor no se está limpiando, por lo que la imagen no puede ser eliminada.*

--latest, -l

En lugar de proporcionar el ID o el nombre del contenedor, utiliza el último contenedor creado. El valor predeterminado es false. IMPORTANTE: ESTA OPCIÓN no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2). ESTA OPCIÓN no necesita un nombre o ID de contenedor como argumento de entrada.

--rm

Después de la limpieza, elimina completamente el contenedor.
El valor predeterminado es false.

--rmi

Después de la limpieza, elimina completamente la imagen.
El valor predeterminado es false.

EJEMPLOS

Limpia el contenedor "mywebserver".

$ podman container cleanup mywebserver

Limpia los contenedores con los nombres "mywebserver", "myflaskserver", "860a4b23".

$ podman container cleanup mywebserver myflaskserver 860a4b23
