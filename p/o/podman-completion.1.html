NOMBRE

podman-completion - Generar scripts de finalización de shell

SINOPSIS

podman completion [opciones] bash | zsh | fish | powershell

DESCRIPCIÓN

podman completion genera scripts de finalización de shell para una variedad de shells. Los shells compatibles son bash, zsh, fish y powershell.

Estos scripts son utilizados por el shell para proporcionar sugerencias y completar comandos cuando se escribe el comando y se presiona [TAB].

Normalmente, estos scripts se instalan automáticamente a través del gestor de paquetes.

OPCIONES

--archivo, -f=archivo

Escribir la salida generada a un archivo.

--no-desc

No proporcionar descripción en las completaciones.
El valor predeterminado es falso.

Instalación

BASH

Se debe instalar bash-completion en el sistema.

Para cargar el script de finalización en la sesión actual, ejecuta:

source <(podman completion bash)

Para que esté disponible para todas las sesiones de bash, ejecuta:

podman completion -f /etc/bash_completion.d/podman bash

ZSH

La finalización del shell debe estar habilitada en el entorno. Se puede ejecutar lo siguiente:

echo "autoload -U compinit; compinit" >> ~/.zshrc

Para que esté disponible para todas las sesiones de zsh, ejecuta:

podman completion -f "${fpath[1]}/_podman" zsh

Una vez que se reinicie el shell, la finalización automática funcionará.

FISH

Para cargar el script de finalización en la sesión actual, ejecuta:

podman completion fish | source

Para que esté disponible para todas las sesiones de fish, ejecuta:

podman completion -f ~/.config/fish/completions/podman.fish fish

POWERSHELL

Para cargar el script de finalización en la sesión actual, ejecuta:

podman.exe completion powershell | Out-String | Invoke-Expression

Para que esté disponible en todas las sesiones de powershell que tenga un usuario, escribe la salida de finalización en un archivo y haz que se cargue en el perfil de powershell del usuario. Más información sobre perfiles está disponible con Get-Help about_Profiles.

VER TAMBIÉN

podman(1), zsh(1), fish(1), powershell(1)
