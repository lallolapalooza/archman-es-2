NOMBRE

podman-generate-spec - Genera Specgen JSON basado en contenedores o pods

SINOPSIS

podman generate spec [opciones] *contenedor | pod

DESCRIPCIÓN

podman generate spec genera Specgen JSON a partir de Contenedores y Pods de Podman. Este JSON puede imprimirse en un archivo, directamente en la línea de comandos o en ambos.

Este JSON puede usarse como entrada para la API de Podman, específicamente para la creación de contenedores y pods de Podman. Specgen es la estructura interna de Podman para formular nuevas entidades relacionadas con contenedores.

OPCIONES

--compact, -c

Imprime la salida en un formato compacto de una sola línea. Esto es útil cuando se canalizan los datos a la API de Podman.

--filename, -f=nombre_archivo

Salida al archivo dado.

--name, -n

Renombra el pod o contenedor para que no entre en conflicto con la entidad existente. Esto es útil cuando el JSON se va a utilizar antes de que el pod o contenedor de origen sea eliminado.

Genera Specgen JSON basado en un contenedor. La salida es de una sola línea.

$ podman generate spec --compact container1
{"name":"container1-clone","command":["/bin/sh"],...
