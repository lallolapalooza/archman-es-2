POWERTOP(8) Administración del Sistema POWERTOP(8)

NOMBRE

powertop - una herramienta de diagnóstico de consumo de energía y gestión de energía.

SINOPSIS

powertop [opciones]

DESCRIPCIÓN

powertop es un programa que ayuda a diagnosticar varios problemas con el consumo de energía y la gestión de energía. También tiene un modo interactivo que permite experimentar con varias configuraciones de gestión de energía. Al invocar powertop sin argumentos, powertop se inicia en modo interactivo.

OPCIONES

--auto-tune
Establece todas las opciones ajustables a su configuración óptima sin interacción.
-c, --calibrate
Ejecuta powertop en modo de calibración. Al ejecutarse con batería, powertop puede rastrear el consumo de energía y la actividad del sistema. Cuando hay suficientes mediciones, powertop puede comenzar a informar estimaciones de energía. Se pueden obtener estimaciones más precisas utilizando esta opción para habilitar un ciclo de calibración. Esto recorrerá varios niveles de visualización y actividades de dispositivos USB y cargas de trabajo.
-C, --csv[=nombre_archivo]
Genera un informe CSV. Si no se especifica un nombre_archivo, se utiliza el nombre predeterminado powertop.csv. El informe CSV se puede utilizar para informes y análisis de datos.
--debug
Ejecutar en modo de depuración.
--extech=nodo_dispositivo
Utiliza el Analizador de Potencia Extech para mediciones. Esto permite especificar el nodo de dispositivo serie del adaptador de serie a USB que se conecta al Analizador de Potencia Extech, por ejemplo, /dev/ttyUSB0.
-r, --html[=nombre_archivo]
Genera un informe HTML. Si no se especifica un nombre_archivo, se utiliza el nombre predeterminado powertop.html. El informe HTML se puede enviar a otros para ayudar a diagnosticar problemas de energía.
-i, --iteration[=iteraciones]
Número de veces que se ejecutará cada prueba.
-q, --quiet
Suprimir la salida de stderr.
-t, --time[=segundos]
Genera un informe durante un número especificado de segundos.
-w, --workload[=carga_de_trabajo]
Ejecuta el archivo carga_de_trabajo como parte de la calibración antes de generar un informe.
-V, --version
Imprimir información de la versión y salir.
-h, --help
Mostrar el mensaje de ayuda y salir.

COMANDOS

En modo interactivo, las siguientes combinaciones de teclas están disponibles:

Tab Mostrar siguiente pestaña
Retroceso Tab Mostrar pestaña anterior
Flecha derecha Desplazar hacia la derecha
Flecha izquierda Desplazar hacia la izquierda
Flecha arriba, PageUp Desplazar hacia arriba o seleccionar elemento anterior
Flecha abajo, PageDown Desplazar hacia abajo o seleccionar elemento siguiente
Espacio, Intro Activar elemento actual
s Establecer tiempo de actualización
r Actualizar ventana
q, Ctrl-C, Escape Salir de powertop

ERRORES

Enviar informes de errores a powertop@lists.01.org

VER TAMBIÉN

El programa se describe más completamente en https://01.org/powertop
