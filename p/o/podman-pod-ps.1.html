NOMBRE

podman-pod-ps - Imprime información sobre los pods

SINOPSIS

podman pod ps [opciones]

DESCRIPCIÓN

podman pod ps lista los pods en el sistema. Por defecto, lista:

  • ID del pod
  • Nombre del pod
  • Hora de creación del pod
  • Número de contenedores adjuntos al pod
  • ID del contenedor de infraestructura del pod
  • Estado del pod, definido por la siguiente tabla
    Estado Descripción
    Created Ningún contenedor en ejecución ni detenido
    Running Al menos un contenedor en ejecución
    Stopped Al menos un contenedor detenido y ninguno en ejecución
    Exited Todos los contenedores detenidos en el pod
    Dead Error al recuperar el estado

OPCIONES

--ctr-ids

Muestra los IDs de los contenedores

--ctr-names

Muestra los nombres de los contenedores

--ctr-status

Muestra los estados de los contenedores

--filter, -f=filtro

Proporciona valores de filtro.

El formato del argumento filtros es de la forma clave=valor. Si hay más de un filtro, pase múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros soportados:

Filtro Descripción
ctr-ids Filtra por ID de contenedor dentro del pod. (Coincidencia de prefijo CID por defecto; acepta expresiones regulares)
ctr-names Filtra por nombre de contenedor dentro del pod.
ctr-number Filtra por número de contenedores en el pod.
ctr-status Filtra por estado de contenedor dentro del pod.
id Filtra por ID de pod. (Coincidencia de prefijo por defecto; acepta expresiones regulares)
label Filtra por contenedores con (o sin, en el caso de que se use label!=[...]) las etiquetas especificadas.
name Filtra por nombre de pod.
network Filtra por nombre de red o ID completo de la red.
status Filtra por estado del pod.
until Filtra por pods creados antes de una marca de tiempo dada.

Los filtros ctr-ids, ctr-names, id, name aceptan el formato regex.

El filtro ctr-status acepta los valores: created, running, paused, stopped, exited, unknown.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina contenedores con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina contenedores sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

El filtro status acepta los valores: stopped, running, paused, exited, dead, created, degraded.

--format=formato

Imprime contenedores en formato JSON o usando una plantilla de Go

Los marcadores válidos para la plantilla de Go se enumeran a continuación:

Marcador Descripción
.Cgroup Ruta del cgroup del pod
.ContainerIds Lista de IDs de contenedores en el pod, separada por comas
.ContainerNames Lista de nombres de contenedores en el pod, separada por comas
.ContainerStatuses Lista de estados de contenedores, separada por comas
.Created Hora de creación del pod
.ID ID del contenedor
.InfraID ID del contenedor de infraestructura del pod
.Label string Etiqueta especificada del pod
.Labels ... Todas las etiquetas asignadas al pod
.Name Nombre del pod
.Networks Muestra todas las redes conectadas al contenedor de infraestructura
.NumberOfContainers Muestra el número de contenedores adjuntos al pod
.Restarts Muestra el número total de reinicios de contenedores en un pod
.Status Estado del pod

--help, -h

Imprime la declaración de uso

--latest, -l

Muestra el último pod creado (todos los estados) (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excepto WSL2))

--namespace, --ns

Muestra la información del espacio de nombres del pod

--no-trunc

No truncar la salida (por defecto false).

--noheading, -n

Omitir los encabezados de la tabla de la lista.

--quiet, -q

Imprime solo los IDs numéricos de los pods

--sort

Ordenar por creado, ID, nombre, estado o número de contenedores

Por defecto: created

EJEMPLOS

Lista todos los pods en ejecución.

$ podman pod ps
POD ID         NAME              STATUS    CREATED          INFRA ID       # OF CONTAINERS
00dfd6fa02c0   jolly_goldstine   Running   31 hours ago     ba465ab0a3a4   1
f4df8692e116   nifty_torvalds    Created   10 minutes ago   331693bff40a   2

Lista todos los pods en ejecución junto con los nombres de los contenedores dentro de los pods.

$ podman pod ps --ctr-names
POD ID         NAME              STATUS    CREATED          INFRA ID       NAMES
00dfd6fa02c0   jolly_goldstine   Running   31 hours ago     ba465ab0a3a4   loving_archimedes
f4df8692e116   nifty_torvalds    Created   10 minutes ago   331693bff40a   thirsty_hawking,wizardly_golick

Lista todos los pods en ejecución junto con el estado, nombres e IDs.

$ podman pod ps --ctr-status --ctr-names --ctr-ids
POD ID         NAME              STATUS    CREATED          INFRA ID       IDS                         NAMES                             STATUS
00dfd6fa02c0   jolly_goldstine   Running   31 hours ago     ba465ab0a3a4   ba465ab0a3a4                loving_archimedes                 running
f4df8692e116   nifty_torvalds    Created   10 minutes ago   331693bff40a   331693bff40a,8e428daeb89e   thirsty_hawking,wizardly_golick   configured,configured

Lista todos los pods en ejecución e imprime el ID, los nombres de los contenedores y los cgroups.

$ podman pod ps --format "{{.ID}}  {{.ContainerNames}}  {{.Cgroup}}"
00dfd6fa02c0   loving_archimedes   /libpod_parent
f4df8692e116   thirsty_hawking,wizardly_golick   /libpod_parent

Lista todos los pods en ejecución con dos contenedores ordenados por ID de pod.

$ podman pod ps --sort id --filter ctr-number=2
POD ID         NAME             STATUS    CREATED          INFRA ID       # OF CONTAINERS
f4df8692e116   nifty_torvalds   Created   10 minutes ago   331693bff40a   2

Lista todos los pods en ejecución con sus IDs de contenedores.

$ podman pod ps  --ctr-ids
POD ID         NAME              STATUS    CREATED          INFRA ID       IDS
00dfd6fa02c0   jolly_goldstine   Running   31 hours ago     ba465ab0a3a4   ba465ab0a3a4
f4df8692e116   nifty_torvalds    Created   10 minutes ago   331693bff40a   331693bff40a,8e428daeb89e

Lista todos los pods en ejecución con IDs de contenedores sin truncar IDs.

$ podman pod ps --no-trunc --ctr-ids



NAME


podman-pod-ps, pod ps - Print a list of pods






SYNOPSIS


podman pod ps [options]


podman pod ps [options] [container...]






DESCRIPTION


The podman pod ps command prints a list of pods that are
  currently present on the system. The command retrieves the list of pods and
  displays their ID, name, status, creation time, infra container ID and
  number of containers in the pod.


By default, podman pod ps displays all pods that are
  currently present on the host, regardless of their status. You can use options
  to filter the list of pods displayed.


The command can also be used to filter the list of pods by
  container ID and display only those pods that contain the specified
  container ID.






OPTIONS


--all, -a


Do not omit any pods, show all pods that are present on the host.


--filter, -f filter=VALUE


Filter output based on a given expression.


The valid filters are:



  
id=ID - a pod ID, or a partial
    ID, of the pod to filter by.

  
label=label - a
    label key or key-value pair to filter by.

  
name=NAME - the name of
    the pod to filter by.

  
status=STATUS -
    status of the pod to filter by. Valid statuses are: created,
    running, stopped, paused, exited,
    degraded.

  
ctr-ids=CTR-IDS -
    a container ID or a partial container ID to filter by.

  
ctr-number=CTR-NUMBER
    - number of containers in the pod to filter by.

  
ctr-status=CTR-STATUS
    - status of the containers in the pod to filter by.

  
until=TEMPORAL -
    Pods created before or at a specified time. TEMPORAL is a duration like
    5s, 1m, 1h.




--format, -f format


Use a Go program to format the output. Examples for formatting
  are available in the podman-printf(5) man page.


--help, -h


Print usage statement for the command.


--last, -l


Display only the latest created pod.


--no-trunc


Do not truncate output.


--quiet, -q


Print only pod IDs.


--size


Optional: Produce JSON array of objects of pods.


--sort=ORDER


Sort output based on given key. The default ORDER is
  descending.


The valid keys are: id, name, status,
  created, infra container id, number of containers.


--ctr-names


Display the names of containers within each pod. This option is
  only used when the status is “created”.
