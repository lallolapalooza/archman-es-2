POSIX_TRACE_EVENTID_EQUAL(3P) Manual del programador POSIX POSIX_TRACE_EVENTID_EQUAL(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_eventid_equal, posix_trace_eventid_get_name, posix_trace_trid_eventid_open — manipular el identificador del tipo de evento de traza (TRAZADO)

SINOPSIS

#include <trace.h>
int posix_trace_eventid_equal(trace_id_t trid, trace_event_id_t event1,
    trace_event_id_t event2);
int posix_trace_eventid_get_name(trace_id_t trid,
    trace_event_id_t event, char *event_name);
int posix_trace_trid_eventid_open(trace_id_t trid,
    const char *restrict event_name,
    trace_event_id_t *restrict event);

DESCRIPCION

La función posix_trace_eventid_equal() compara los identificadores de tipo de evento de traza event1 y event2 del mismo flujo de traza o del mismo registro de traza identificado por el argumento trid. Si los identificadores de tipo de evento de traza event1 y event2 provienen de diferentes flujos de traza, el valor de retorno será indeterminado.

La función posix_trace_eventid_get_name() devuelve, en el argumento apuntado por event_name, el nombre del evento de traza asociado con el identificador de tipo de evento de traza identificado por el argumento event, para el flujo de traza o el registro de traza identificado por el argumento trid. El nombre del evento de traza tendrá un máximo de {TRACE_EVENT_NAME_MAX} caracteres (que tiene el valor mínimo {_POSIX_TRACE_EVENT_NAME_MAX}). Las llamadas sucesivas a esta función con el mismo identificador de tipo de evento de traza y el mismo identificador de flujo de traza devolverán el mismo nombre de evento.

La función posix_trace_trid_eventid_open() asocia un nombre de evento de traza de usuario con un identificador de tipo de evento de traza para un flujo de traza dado. El flujo de traza se identifica mediante el argumento trid, y debe ser un flujo de traza activo. El nombre del evento de traza es la cadena apuntada por el argumento event_name. Tendrá un máximo de {TRACE_EVENT_NAME_MAX} caracteres (que tiene el valor mínimo {_POSIX_TRACE_EVENT_NAME_MAX}). El número de identificadores de tipo de evento de traza de usuario que se pueden definir para cualquier proceso dado está limitado por el valor máximo {TRACE_USER_EVENT_MAX}, que tiene el valor mínimo {_POSIX_TRACE_USER_EVENT_MAX}.

Si la opción de herencia de traza no es compatible, la función posix_trace_trid_eventid_open() asociará el nombre de evento de traza de usuario apuntado por el argumento event_name con un identificador de tipo de evento de traza que sea único para el proceso que se está trazando en el flujo de traza identificado por el argumento trid, y se devolverá en la variable apuntada por el argumento event. Si el nombre de evento de traza de usuario ya se ha mapeado para el proceso trazado, se devolverá el identificador de tipo de evento de traza asignado previamente. Si se ha alcanzado el límite de nombres de eventos de traza de usuario por proceso representado por {TRACE_USER_EVENT_MAX}, se devolverá el evento de traza de usuario predefinido POSIX_TRACE_UNNAMED_USEREVENT (ver Tabla 2-7, Opción de Traza: Evento de Traza de Usuario).

Si la opción de herencia de traza es compatible, la función posix_trace_trid_eventid_open() asociará el nombre de evento de traza de usuario apuntado por el argumento event_name con un identificador de tipo de evento de traza que sea único para todos los procesos que se están trazando en el flujo de traza identificado por el argumento trid, y se devolverá en la variable apuntada por el argumento event. Si el nombre de evento de traza de usuario ya se ha mapeado para los procesos trazados, se devolverá el identificador de tipo de evento de traza asignado previamente. Si se ha alcanzado el límite de nombres de eventos de traza de usuario por proceso representado por {TRACE_USER_EVENT_MAX}, se devolverá el evento de traza de usuario predefinido POSIX_TRACE_UNNAMED_USEREVENT (ver Tabla 2-7, Opción de Traza: Evento de Traza de Usuario).

VALOR DE RETORNO

Al completarse con éxito, las funciones posix_trace_eventid_get_name() y posix_trace_trid_eventid_open() devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

La función posix_trace_eventid_equal() devolverá un valor distinto de cero si event1 y event2 son iguales; de lo contrario, se devolverá un valor de cero. No se definen errores. Si event1 o event2 no son identificadores de tipo de evento de traza válidos para el flujo de traza especificado por trid o si trid no es válido, el comportamiento será indeterminado.

La función posix_trace_eventid_get_name() almacena el valor del nombre del evento de traza en el objeto apuntado por event_name, si tiene éxito.

La función posix_trace_trid_eventid_open() almacena el valor del identificador del tipo de evento de traza en el objeto apuntado por event, si tiene éxito.

ERRORES

Las funciones posix_trace_eventid_get_name() y posix_trace_trid_eventid_open() fallarán si:

EINVAL
El argumento trid no era un identificador de flujo de traza válido.

La función posix_trace_trid_eventid_open() fallará si:

ENAMETOOLONG

El tamaño del nombre apuntado por el argumento event_name era más largo que el valor definido por la implementación {TRACE_EVENT_NAME_MAX}.

La función posix_trace_eventid_get_name() fallará si:

EINVAL
El identificador del tipo de evento de traza event no estaba asociado con ningún nombre.

posix_trace_eventid_equal(3p)

posix_trace_eventid_equal, posix_trace_eventid_get_name, posix_trace_eventid_get_id — comparar y obtener información de ID de evento de trazabilidad POSIX

NOMBRE

posix_trace_eventid_equal, posix_trace_eventid_get_name, posix_trace_eventid_get_id — comparar y obtener información de ID de evento de trazabilidad POSIX

SINOPSIS

#include <trace-cmd.h>

int posix_trace_eventid_equal(
    posix_trace_eventid_t id1,
    posix_trace_eventid_t id2);

int posix_trace_eventid_get_name(
    posix_trace_eventid_t id,
    char *name,
    size_t *size);

int posix_trace_eventid_get_id(
    const char *name,
    posix_trace_eventid_t *id);

DESCRIPCIÓN

La biblioteca de trazabilidad de eventos POSIX proporciona mecanismos para generar y consumir flujos de datos de trazabilidad. El concepto de un evento de trazabilidad se define por su ID y su nombre.

La función posix_trace_eventid_equal() compara dos IDs de evento de trazabilidad, id1 e id2. Devuelve un valor distinto de cero si los dos IDs son iguales, y 0 en caso contrario.

La función posix_trace_eventid_get_name() recupera el nombre asociado con un ID de evento de trazabilidad dado, id. El nombre se copia en el búfer name, que tiene un tamaño especificado por size. Si el búfer name es lo suficientemente grande como para contener el nombre del evento y el carácter nulo de terminación, la función copia el nombre y actualiza size con la longitud del nombre copiado (sin incluir el carácter nulo de terminación). Si el búfer name es demasiado pequeño, la función devuelve un error y el valor de size se establece en la longitud requerida del búfer (sin incluir el carácter nulo de terminación).

La función posix_trace_eventid_get_id() recupera el ID de evento de trazabilidad asociado con un nombre de evento dado, name. El ID recuperado se almacena en la ubicación a la que apunta id.

VALOR DE RETORNO

Para posix_trace_eventid_equal(): devuelve un valor distinto de cero si id1 e id2 son iguales, y 0 en caso contrario.

Para posix_trace_eventid_get_name(): en caso de éxito, devuelve 0. En caso de error, devuelve un número de error distinto de cero.

Para posix_trace_eventid_get_id(): en caso de éxito, devuelve 0. En caso de error, devuelve un número de error distinto de cero.

ERRORES

Los posibles errores para posix_trace_eventid_get_name() y posix_trace_eventid_get_id() incluyen:

EINVAL
El valor del argumento no es válido. Por ejemplo, un ID no válido o un puntero nulo.
ENAMETOOLONG
El búfer name proporcionado a posix_trace_eventid_get_name() es demasiado pequeño para contener el nombre del evento.
ENOENT
No se encontró ningún evento de trazabilidad con el nombre o ID especificado.

EJEMPLOS

Para obtener el nombre del evento con ID 1:

posix_trace_eventid_t event_id = 1;
char name_buffer[256];
size_t name_size = sizeof(name_buffer);
int ret;

ret = posix_trace_eventid_get_name(event_id, name_buffer, &name_size);
if (ret == 0) {
    printf("El nombre del evento es: %s\n", name_buffer);
} else {
    // Manejar el error
}

Para obtener el ID del evento llamado "syscall":

posix_trace_eventid_t event_id;
const char *event_name = "syscall";
int ret;

ret = posix_trace_eventid_get_id(event_name, &event_id);
if (ret == 0) {
    printf("El ID del evento '%s' es: %d\n", event_name, event_id);
} else {
    // Manejar el error
}

Para comparar dos IDs de evento:

posix_trace_eventid_t id1 = 1;
posix_trace_eventid_t id2 = 1;
posix_trace_eventid_t id3 = 2;

if (posix_trace_eventid_equal(id1, id2)) {
    printf("id1 e id2 son iguales.\n");
}

if (!posix_trace_eventid_equal(id1, id3)) {
    printf("id1 e id3 no son iguales.\n");
}

USO DE LA APLICACIÓN

Estas funciones son útiles para programas que interactúan con el sistema de trazabilidad POSIX. Permiten la comparación de IDs de eventos, la obtención de nombres de eventos a partir de sus IDs y viceversa. Esto es esencial para la manipulación y el análisis de datos de trazabilidad.

FUNDAMENTO

La trazabilidad del sistema es una herramienta poderosa para depurar y analizar el comportamiento de las aplicaciones. El estándar POSIX.1-2017 define una API para la trazabilidad de eventos. Las funciones posix_trace_eventid_equal(), posix_trace_eventid_get_name() y posix_trace_eventid_get_id() forman parte de esta API y proporcionan las utilidades necesarias para trabajar con los identificadores de eventos de trazabilidad.

DIRECCIONES FUTURAS

El futuro desarrollo de la trazabilidad POSIX podría incluir más funciones para filtrar eventos, gestionar la configuración de trazabilidad de forma más granular y mejorar el rendimiento.
