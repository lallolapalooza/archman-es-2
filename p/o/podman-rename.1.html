NOMBRE

podman-rename - Renombrar un contenedor existente

SINOPSIS

podman rename contenedor nuevonombre

podman container rename contenedor nuevonombre

DESCRIPCIÓN

Rename cambia el nombre de un contenedor existente. El nombre anterior se libera y queda disponible para su uso. Este comando se puede ejecutar en contenedores en cualquier estado. Sin embargo, los contenedores en ejecución pueden no recibir completamente los efectos hasta que se reinicien; por ejemplo, un contenedor en ejecución todavía puede usar el nombre anterior en sus registros. Actualmente, solo se admiten contenedores; los pods y volúmenes no se pueden renombrar.

OPCIONES

EJEMPLOS

Renombrar un contenedor con un nombre dado.

$ podman rename oldContainer unNuevoNombre

Renombrar un contenedor con un ID dado.

$ podman rename 717716c00a6b contenedorDePrueba

Crear un alias para un contenedor con un ID dado.

$ podman container rename 6e7514b47180 contenedorBaseDatos
