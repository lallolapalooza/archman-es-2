posix_madvise(3) Manual de funciones de biblioteca posix_madvise(3)

NOMBRE

posix_madvise - dar consejo sobre patrones de uso de memoria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/mman.h>
int posix_madvise(void addr[], size_t size, int advice);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

posix_madvise():

    _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La función posix_madvise() permite a una aplicación dar consejo al sistema sobre sus patrones esperados de uso de memoria en el rango de direcciones que comienza en addr y continúa durante size bytes. El sistema es libre de usar este consejo para mejorar el rendimiento de los accesos a memoria (o de ignorar el consejo por completo), pero llamar a posix_madvise() no afectará la semántica del acceso a la memoria en el rango especificado.

El argumento advice es uno de los siguientes:

POSIX_MADV_NORMAL
La aplicación no tiene ningún consejo especial con respecto a sus patrones de uso de memoria para el rango de direcciones especificado. Este es el comportamiento por defecto.
POSIX_MADV_SEQUENTIAL
La aplicación espera acceder al rango de direcciones especificado de forma secuencial, desde direcciones bajas a altas. Por lo tanto, las páginas en esta región pueden ser leídas anticipadamente de forma agresiva y pueden ser liberadas poco después de ser accedidas.
POSIX_MADV_RANDOM
La aplicación espera acceder al rango de direcciones especificado de forma aleatoria. Por lo tanto, la lectura anticipada puede ser menos útil de lo normal.
POSIX_MADV_WILLNEED
La aplicación espera acceder al rango de direcciones especificado en un futuro cercano. Por lo tanto, la lectura anticipada puede ser beneficiosa.
POSIX_MADV_DONTNEED
La aplicación espera no acceder al rango de direcciones especificado en un futuro cercano.

VALOR DE RETORNO

En caso de éxito, posix_madvise() devuelve 0. En caso de error, devuelve un número de error positivo.

ERRORES

EINVAL
addr no es un múltiplo del tamaño de página del sistema o size es negativo.
EINVAL
advice es inválido.
ENOMEM
Las direcciones en el rango especificado están parcial o completamente fuera del espacio de direcciones del llamante.

VERSIONES

POSIX.1 permite que una implementación genere un error si size es 0. En Linux, especificar size como 0 está permitido (como una operación nula exitosa).

En glibc, esta función se implementa utilizando madvise(2). Sin embargo, desde glibc 2.6, POSIX_MADV_DONTNEED se trata como una operación nula, ya que el valor correspondiente de madvise(2), MADV_DONTNEED, tiene una semántica destructiva.

ESTANDARES

POSIX.1-2008.

HISTORIA

glibc 2.2. POSIX.1-2001.

VER TAMBIÉN

madvise(2), posix_fadvise(2)
