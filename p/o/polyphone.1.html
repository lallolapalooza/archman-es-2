NOMBRE

polyphone - editor de soundfont

SINOPSIS

polyphone
polyphone [ARCHIVO]
polyphone [ARCHIVO_1] [ARCHIVO_2] ...
polyphone -1 [-i RUTA_ARCHIVO_ENTRADA] [-d DIRECTORIO_SALIDA] [-o NOMBRE_SALIDA]
polyphone -2 [-i RUTA_ARCHIVO_ENTRADA] [-d DIRECTORIO_SALIDA] [-o NOMBRE_SALIDA] [-c CONFIG]
polyphone -3 [-i RUTA_ARCHIVO_ENTRADA] [-d DIRECTORIO_SALIDA] [-o NOMBRE_SALIDA] [-c CONFIG]
polyphone -s [-i RUTA_ARCHIVO_ENTRADA] [-c CONFIG]

DESCRIPCIÓN

polyphone proporciona una interfaz simple y eficiente para crear y editar archivos .sf2. Este software incluye herramientas para facilitar y automatizar la edición de diferentes parámetros, permitiendo manejar una gran cantidad de datos.

Se admiten los formatos sf2, sf3, sfz (importar/exportar), sfArk (solo importar) y GrandOrgue (solo importar). Se pueden utilizar líneas de comandos para convertir archivos, abrir Polyphone en modo sintetizador o restablecer configuraciones en caso de problemas.

Se puede encontrar más información en https://www.polyphone.io .

OPCIONES

ARCHIVO
Especifica el archivo a abrir al iniciar polyphone. Se pueden cargar múltiples archivos si están separados por espacios. Se admiten los formatos sf2 (versión 2.01 o 2.04), sf3, sfz, sfArk (versión 1 o 2) y GrandOrgue.
-1
Utiliza polyphone para convertir un archivo al formato sf2.
-2
Utiliza polyphone para convertir un archivo al formato sf3.
-3
Utiliza polyphone para convertir un archivo al formato sfz.
-s
Abre polyphone en modo sintetizador.
[-i RUTA_ARCHIVO_ENTRADA]
Ruta del archivo de entrada a convertir o abrir. El formato del archivo de entrada debe ser sf2, sf3, sfz, sfArk u organ.
[-d DIRECTORIO_SALIDA]
Directorio de salida en el que se convertirá el archivo de entrada. Por defecto, es el mismo directorio que el archivo de entrada.
[-o NOMBRE_SALIDA]
Nombre de salida del archivo convertido. La extensión se añadirá automáticamente según la conversión. Por defecto, es el mismo nombre que el archivo de entrada.
[-c CONFIG]
Configuración de conversión, cuyo contenido depende del tipo de conversión. -r Elimina la configuración existente.

* Conversión a sf2
Sin configuración para esta conversión.

* Conversión a sf3
La configuración consta de un carácter que indica la calidad de la compresión. '0' para baja, '1' para media y '2' para alta calidad. El valor predeterminado es '1'.

* Conversión a sfz
La configuración consta de 3 valores separados por '|'. El primer valor es '1' si cada preset debe ir precedido por su número de preset, '0' en caso contrario. El segundo valor es '1' si se debe crear un directorio por banco, '0' en caso contrario. El tercer valor es '1' si se debe utilizar la clasificación general de midi para ordenar los presets, '0' en caso contrario. El valor predeterminado es '0|0|0'.

* Modo sintetizador
La configuración consta de 3 valores separados por '|'. El primer valor especifica el canal MIDI a escuchar, que puede ser un valor de 1 a 16. Un valor de 0 o "all" indica que se utilizarán todos los canales y se procesarán como un solo canal. Un valor de -1 o "each" escucha cada canal por separado, lo cual es un requisito previo para reproducir archivos MIDI, por ejemplo. El segundo valor es 'on' (activado) o 'off' (desactivado) para permitir la reproducción de varios presets a la vez. El tercer valor es 'on', 'off' o 'toggle' (alternar) para permitir activar o desactivar presets mediante las notas más bajas del teclado. El valor predeterminado es 'all|off|off'.

EJEMPLOS


* Conversión de sfArk a sf2:
polyphone -1 -i /ruta/al/archivo.sfArk

* Conversión de sf2 a sf3 (buena calidad):
polyphone -2 -i /ruta/al/archivo.sf2 -c 2

* Conversión de sf3 a sfz (subdirectorios por banco y clasificación gm):
polyphone -3 -i /ruta/al/archivo.sf3 -c '0|1|1'

* Abrir Polyphone en modo sintetizador, permitiendo el uso de las teclas de bajo para seleccionar el conjunto a reproducir con un teclado MIDI:
polyphone -s -i /ruta/al/archivo.sf2 -c 'all|off|toggle'
