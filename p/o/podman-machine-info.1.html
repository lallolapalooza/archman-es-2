NOMBRE

podman-machine-info - Muestra información de la máquina anfitriona

SINOPSIS

podman machine info

DESCRIPCIÓN

Muestra información relacionada con la máquina anfitriona. Solo sin privilegios, ya que todos los comandos podman machine solo pueden ser utilizados con Podman sin privilegios.

Nota: El campo DefaultMachine en la salida de Host no sugiere que se pueda establecer una máquina podman predeterminada a través de conexiones del sistema. Este valor representa la conexión del sistema activa actual asociada con una máquina podman. Independientemente de la conexión del sistema predeterminada, la máquina podman predeterminada siempre será podman-machine-default.

OPCIONES

--format, -f=formato

Cambia el formato de salida a "json" o a una plantilla Go.

Marcador Descripción
.Host ... Información del anfitrión para la máquina local
.Version ... Versión de la máquina

--help

Imprime el enunciado de uso.

EJEMPLOS

  Arch: amd64
  CurrentMachine: ""
  DefaultMachine: ""
  EventsDir: /run/user/3267/podman
  MachineConfigDir: /home/myusername/.config/containers/podman/machine/qemu
  MachineImageDir: /home/myusername/.local/share/containers/podman/machine/qemu
  MachineState: ""
  NumberOfMachines: 0
  OS: linux
  VMType: qemu
Version:
  APIVersion: 4.4.0
  Built: 1677097848
  BuiltTime: Wed Feb 22 15:30:48 2023
  GitCommit: aa196c0d5c9abd5800edf9e27587c60343a26c2b-dirty
  GoVersion: go1.20
  Os: linux
  OsArch: linux/amd64
  Version: 4.4.0

Muestra el campo Host.Arch de la máquina Podman predeterminada.

$ podman machine info --format "{{ .Host.Arch }}"
amd64
