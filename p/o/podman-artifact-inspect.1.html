NOMBRE

podman-artifact-inspect - Inspecciona un artefacto OCI

SINOPSIS

podman artifact inspect nombre

DESCRIPCIÓN

Inspecciona un artefacto en el almacén local y muestra los resultados en formato JSON. El artefacto puede ser referido mediante:

1.
Nombre completo del artefacto
2.
Digest completo o parcial del manifiesto del artefacto

La salida de la inspección incluye el manifiesto del artefacto con anotaciones. Todos los artefactos incluyen automáticamente una marca de tiempo de creación en la anotación org.opencontainers.image.created utilizando el formato RFC3339Nano, que muestra cuándo se creó inicialmente el artefacto.

OPCIONES

--format, -f=formato

Formatea la salida utilizando la plantilla Go dada. Las claves del JSON devuelto pueden usarse como valores para la bandera --format (ver ejemplos a continuación).

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Artifact ... Detalles del artefacto (estructura anidada)
.Digest Digest del artefacto (hash de 64 caracteres sha256:+)
.Manifest ... Detalles del manifiesto del artefacto (estructura)
.Name Nombre del artefacto (cadena)
.TotalSizeBytes Tamaño total del artefacto en bytes

--help, -h

Imprime la declaración de uso

EJEMPLOS

Inspecciona una imagen OCI en el almacén local.

$ podman artifact inspect quay.io/myartifact/myml:latest
{
     "Manifest": {
          "schemaVersion": 2,
          "mediaType": "application/vnd.oci.image.manifest.v1+json",
          "config": {
               "mediaType": "application/vnd.oci.empty.v1+json",
               "digest": "sha256:44136fa355b3678a1146ad16f7e8649e94fb4fc21fe77e8310c060f61caaff8a",
               "size": 2,
               "data": "e30="
          },
          "layers": [
               {
                    "mediaType": "text/plain; charset=utf-8",
                    "digest": "sha256:f2ca1bb6c7e907d06dafe4687e579fce76b37e4e93b7605022da52e6ccc26fd2",
                    "size": 5,
                    "annotations": {
                         "org.opencontainers.image.title": "foobar.txt"
                    }
               }
          ]
     },
     "Name": "quay.io/myartifact/mytxt:latest",
     "Digest": "sha256:6c28fa07a5b0a1cee29862c1f6ea38a66df982495b14da2c052427eb628ed8c6"
}

Inspecciona el digest del artefacto para el artefacto especificado:

$ podman artifact inspect quay.io/myartifact/mytxt:latest --format {{.Digest}}
sha256:6c28fa07a5b0a1cee29862c1f6ea38a66df982495b14da2c052427eb628ed8c6
