NOMBRE

podman-system-prune - Elimina todos los pods, contenedores, imágenes, redes y datos de volúmenes no utilizados

SINOPSIS

podman system prune [opciones]

DESCRIPCIÓN

podman system prune elimina todos los contenedores no utilizados (tanto colgados como no referenciados), contenedores de compilación, pods, redes y, opcionalmente, volúmenes del almacenamiento local.

Utilice la opción --all para eliminar todas las imágenes no utilizadas. Las imágenes no utilizadas son imágenes colgadas, así como cualquier imagen que no tenga ningún contenedor basado en ella.

Por defecto, los volúmenes no se eliminan para evitar que se borren datos importantes si actualmente no hay ningún contenedor utilizando el volumen. Utilice la bandera --volumes al ejecutar el comando para eliminar también los volúmenes.

Por defecto, los contenedores de compilación no se eliminan para evitar interferencias con las compilaciones en curso. Utilice la bandera --build al ejecutar el comando para eliminar también los contenedores de compilación.

OPCIONES

--all, -a

Elimina recursivamente todos los pods, contenedores, imágenes, redes y datos de volúmenes no utilizados. (Máximo 50 iteraciones.)

--build

Elimina cualquier contenedor de compilación que se haya creado durante la compilación, pero que no se haya eliminado porque la compilación se interrumpió inesperadamente.

Nota: Esta no es una operación segura y solo debe ejecutarse cuando no haya compilaciones en curso. Puede interferir con las compilaciones en curso.

--external

Intenta limpiar los restos de contenedores o capas anteriores que no están referenciados en los archivos JSON de almacenamiento. Esto puede ocurrir en caso de cierres inesperados o reinicios regulares en modo de almacenamiento transitorio.

Sin embargo, al usar el modo de almacenamiento transitorio, la base de datos de Podman no persiste. Esto significa que los contenedores dejan las capas escribibles en el disco después de un reinicio. Al usar un almacén transitorio, se recomienda ejecutar el comando podman system prune --external durante el arranque.

Esta opción es incompatible con --all y --filter y anula el comportamiento predeterminado de eliminar recursos no utilizados.

--filter=filtros

Proporciona valores de filtro.

El formato del argumento filtros es de clave=valor. Si hay más de un filtro, pase múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros admitidos:

Filtro Descripción
label Solo elimina contenedores e imágenes con (o sin, en el caso de label!=[...] ) las etiquetas especificadas.
until Solo elimina contenedores e imágenes creados antes de la marca de tiempo dada.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina contenedores e imágenes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina contenedores e imágenes sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

--force, -f

No pedir confirmación

--help, -h

Imprimir el enunciado de uso

--volumes

Elimina volúmenes no utilizados actualmente por ningún contenedor

Elimina todos los contenedores, pods, redes e imágenes colgadas.

$ podman system prune

	- todos los contenedores parados
	- todas las redes no utilizadas por al menos un contenedor
	- todas las imágenes colgadas
	- toda la caché de compilación colgada
