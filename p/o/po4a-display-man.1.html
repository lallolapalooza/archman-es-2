po4a-display-man(1)

PO4A-DISPLAY-MAN(1) Herramientas Po4a PO4A-DISPLAY-MAN(1)

NOMBRE

po4a-display-man - muestra una página de manual traducida según un PO

SINOPSIS

po4a-display-man -p ARCHIVO_PO [-m ARCHIVO_MAESTRO] [-o OPCION_PO4A]

DESCRIPCIÓN

Los traductores pueden usar po4a-display-man para ver cómo se renderizará su traducción de una página de manual a los usuarios finales, sin tener que recompilar e reinstalar todo el proyecto.

Este script solo funciona con páginas de manual escritas directamente en nroff y manejadas por el módulo man de po4a. Las páginas de manual generadas a partir de otros formatos, como DocBook o POD, no son soportadas. Consulte po4a-display-pod(1) para un equivalente que soporte documentos POD.

OPCIONES

-p ARCHIVO_PO

El archivo PO que contiene las traducciones.

-m ARCHIVO_MAESTRO

La página de manual original. Puede ser la ruta absoluta o relativa a la página de manual original (comprimida o no), el nombre de la página de manual, o el nombre y sección de la página de manual (usando el formato man.seccion). Cuando el documento maestro no se proporciona con la opción -m, po4a-display-man intenta encontrar la página de manual original basándose en la referencia de línea de la primera cadena en el PO.

-o OPCION_PO4A

Algunas opciones para pasar a po4a-translate(1).

VER TAMBIÉN

po4a-display-pod(1)
