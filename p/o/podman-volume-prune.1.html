NOMBRE

podman-volume-prune - Elimina todos los volúmenes no utilizados

SINOPSIS

podman volume prune [opciones]

DESCRIPCIÓN

Elimina volúmenes no utilizados. Por defecto, se eliminan todos los volúmenes no utilizados, se puede usar la bandera --filter para filtrar volúmenes específicos. Se le pedirá al usuario que confirme la eliminación de todos los volúmenes no utilizados. Para omitir la confirmación, use la bandera --force.

OPCIONES

--filter

Proporciona valores de filtro.

El formato del argumento de filtros es clave=valor. Si hay más de un filtro, pase múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros compatibles:

Filtro Descripción
dangling [Bool] Solo elimina volúmenes no referenciados por ningún contenedor
driver [String] Solo elimina volúmenes con el controlador dado
label [String] Solo elimina volúmenes, con (o sin, en el caso de que se use label!=[...]) las etiquetas especificadas.
name [String] Solo elimina el volumen con el nombre dado
opt [String] Solo elimina volúmenes creados con las opciones dadas
scope [String] Solo elimina volúmenes con el ámbito dado
until [DateTime] Solo elimina volúmenes creados antes de la marca de tiempo dada.
after/since [Volumen] Filtra por volúmenes creados después del VOLUMEN (nombre o etiqueta) dado

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina volúmenes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina volúmenes sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

--force, -f

No pedir confirmación.

--help

Imprimir declaración de uso

EJEMPLOS

Eliminar todos los volúmenes no utilizados.

$ podman volume prune

Eliminar todos los volúmenes. Nota: este comando también eliminará todos los contenedores que estén utilizando un volumen.

$ podman volume prune --force

Eliminar todos los volúmenes que contengan la etiqueta especificada.

$ podman volume prune --filter label=mylabel=mylabelvalue
