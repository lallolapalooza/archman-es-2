NOMBRE

podman-diff - Inspeccionar cambios en el sistema de archivos de un contenedor o imagen

SINOPSIS

podman diff [opciones] contenedor|imagen [contenedor|imagen]

DESCRIPCIÓN

Muestra los cambios en el sistema de archivos de un contenedor o imagen. El contenedor o imagen se compara con su capa padre o con el segundo argumento cuando se proporciona.

La salida se prefija con los siguientes símbolos:

Símbolo Descripción
A Se agregó un archivo o directorio.
D Se eliminó un archivo o directorio.
C Se modificó un archivo o directorio.

OPCIONES

--format

Modifica la salida a un formato diferente. El único formato válido para podman diff es json.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, se utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

EJEMPLOS

Mostrar archivos modificados por el contenedor en comparación con la imagen del contenedor:

$ podman diff container1
A /myscript.sh

Mostrar archivos modificados por el contenedor en comparación con la imagen del contenedor en formato JSON:

$ podman diff --format json myimage
{
  "changed": [
    "/usr",
    "/usr/local",
    "/usr/local/bin"
  ],
  "added": [
    "/usr/local/bin/docker-entrypoint.sh"
  ]
}

Mostrar la diferencia entre el contenedor especificado y la imagen:

$ podman diff container1 image1
A /test

VER TAMBIÉN

podman(1), podman-container-diff(1), podman-image-diff(1)
