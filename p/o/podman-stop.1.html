podman-stop(1) Manual de Comandos Generales podman-stop(1)

NOMBRE

podman-stop - Detiene uno o más contenedores en ejecución

SINOPSIS

podman stop [opciones] contenedor ...

podman container stop [opciones] contenedor ...

DESCRIPCIÓN

Detiene uno o más contenedores utilizando IDs de contenedor o nombres como entrada. La opción --time especifica el número de segundos a esperar antes de detener forzosamente el contenedor después de que se emita el comando de detención al contenedor. El valor predeterminado es 10 segundos. Por defecto, los contenedores se detienen con SIGTERM y luego SIGKILL después del tiempo de espera. El valor predeterminado de SIGTERM puede ser anulado por la imagen utilizada para crear el contenedor y también a través de la línea de comandos al crear el contenedor.

OPCIONES

--all, -a

Detiene todos los contenedores en ejecución. Esto no incluye los contenedores en pausa.

--cidfile=archivo

Lee el ID del contenedor desde el archivo especificado y detiene el contenedor. Se puede especificar varias veces.

El comando no falla cuando archivo no se encuentra y el usuario especificó --ignore.

--filter, -f=filtro

Filtra qué contenedores se detendrán. Se pueden dar varios filtros con múltiples usos de la opción --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizado para crear el contenedor
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados desde este contenedor
volume [NombreVolumen] o [DestinoMonte] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [FechaHora] Contenedores creados antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--ignore, -i

Ignora los errores cuando los contenedores especificados no están en el almacén de contenedores. Un usuario podría haber decidido eliminar manualmente un contenedor, lo que provoca un error durante la directiva ExecStop de un servicio systemd que hace referencia a ese contenedor.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--time, -t=segundos

Segundos a esperar antes de detener forzosamente el contenedor. Use -1 para esperar indefinidamente.

EJEMPLOS

Detener el contenedor especificado por su nombre.

$ podman stop mywebserver

Detener el contenedor por su id.

$ podman stop 860a4b235279

Detener varios contenedores.

$ podman stop mywebserver 860a4b235279

Detener el contenedor identificado en el cidfile.

$ podman stop --cidfile /home/user/cidfile-1

Detener los contenedores identificados en los cidfiles.

$ podman stop --cidfile /home/user/cidfile-1 --cidfile ./cidfile-2

Detener el contenedor especificado en 2 segundos.

$ podman stop --time 2 860a4b235279

Detener todos los contenedores en ejecución.

$ podman stop -a

Detener el último contenedor creado (esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman stop --latest

Detener por etiqueta.

$ podman stop --filter label=app=frontend
9351ccb3ef4272532bc0c188bd4f0ddfc2b0de217732cd108259ea126b014647

Detener por nombre.

$ podman stop --filter name=db-replica
6c2680da61d54690718ac3aecdb04a8aad95ae353e42cc942736823bd05c8a1d

Detener por etiqueta de rol.

$ podman stop --filter label=role=primary
bb3ff91d969a8dc622d627e4a8d76c18bdbd417d317c5e7e66543c0b0c8ed1e8
