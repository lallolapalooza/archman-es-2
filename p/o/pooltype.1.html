POOLTYPE(1) Manual de Comandos Generales POOLTYPE(1)

NOMBRE

pooltype - muestra un archivo de pool WEB

SINOPSIS

pooltype nombre_archivo_pool

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se encuentra en el archivo de información o manual Web2C: Una implementación de TeX.

El programa pooltype traduce un archivo de pool de cadenas Web (orientado al programa) a un archivo de texto (orientado al humano).

El nombre_archivo_pool debe ser completo; no se agregan extensiones predeterminadas ni se realiza búsqueda de rutas.

VER TAMBIÉN

tangle(1).

AUTORES

Donald E. Knuth escribió el programa y lo portó originalmente a Unix. Fue publicado como parte del informe técnico TeXware, disponible en el TeX Users Group.
