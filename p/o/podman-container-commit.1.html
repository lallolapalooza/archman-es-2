NOMBRE

podman-commit - Crear una nueva imagen basada en el contenedor modificado

SINOPSIS

podman commit [opciones] contenedor [imagen]

podman container commit [opciones] contenedor [imagen]

DESCRIPCIÓN

podman commit crea una imagen basada en un contenedor modificado. El autor de la imagen se puede establecer usando la opción --author. Varias instrucciones de imagen se pueden configurar con la opción --change y un mensaje de commit se puede establecer usando la opción --message. El contenedor y sus procesos no se pausan mientras se confirma la imagen. Si esto no es deseado, la opción --pause se puede establecer en true. Cuando se completa el commit, Podman imprime el ID de la nueva imagen.

Si imagen no comienza con un componente de nombre de registro, se agrega localhost al nombre. Si imagen no se proporciona, los valores para los valores de REPOSITORIO y TAG de la imagen creada se establecen en <none>.

OPCIONES

--author, -a=autor

Establece el autor de la imagen confirmada.

--change, -c=instrucción

Aplica las siguientes instrucciones posibles a la imagen creada:

  • CMD
  • ENTRYPOINT
  • ENV
  • EXPOSE
  • LABEL
  • ONBUILD
  • STOPSIGNAL
  • USER
  • VOLUME
  • WORKDIR

Se puede establecer varias veces.

--config=ArchivoBlobConfig

Fusiona la configuración del contenedor del archivo especificado en la configuración de la imagen mientras se está confirmando. El contenido del archivo debe ser una versión codificada en JSON de una estructura Schema2Config, que se define en https://github.com/containers/image/blob/v5.29.0/manifest/docker_schema2.go#L67.

--format, -f=oci | docker

Establece el formato del manifiesto y metadatos de la imagen. Los formatos actualmente compatibles son oci y docker.
El valor predeterminado es oci.

--iidfile=ArchivoIDImagen

Escribe el ID de la imagen en el archivo.

--include-volumes

Incluye en la imagen confirmada cualquier volumen agregado al contenedor mediante las opciones --volume o --mount de los comandos podman create y podman run.
El valor predeterminado es false.

--message, -m=mensaje

Establece el mensaje de commit para la imagen confirmada.
IMPORTANTE: El campo de mensaje no es compatible con el formato oci.

--pause, -p

Pausa el contenedor al crear una imagen.
El valor predeterminado es false.

--quiet, -q

Suprime la salida.
El valor predeterminado es false.

--squash, -s

Combina las capas recién creadas en una única capa nueva.
El valor predeterminado es false.

EJEMPLOS

Crear imagen a partir de contenedor con entrypoint y etiqueta:

$ podman commit --change CMD=/bin/bash --change ENTRYPOINT=/bin/sh --change "LABEL blue=image" reverent_golick image-committed
Getting image source signatures
Copying blob sha256:b41deda5a2feb1f03a5c1bb38c598cbc12c9ccd675f438edc6acd815f7585b86
 25.80 MB / 25.80 MB [======================================================] 0s
Copying config sha256:c16a6d30f3782288ec4e7521c754acc29d37155629cb39149756f486dae2d4cd
 448 B / 448 B [============================================================] 0s
Writing manifest to image destination
Storing signatures
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear imagen a partir de contenedor con mensaje de commit:

$ podman commit -q --message "committing container to image"
reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear imagen a partir de contenedor con autor:

$ podman commit -q --author "firstName lastName" reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Pausar contenedor en ejecución mientras se crea la imagen:

$ podman commit -q --pause=true containerID image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear imagen a partir de contenedor con etiqueta de imagen predeterminada:

$ podman commit containerID
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear imagen a partir de contenedor con capacidades requeridas predeterminadas:

$ podman commit -q --change LABEL=io.containers.capabilities=setuid,setgid epic_nobel privimage
400d31a3f36dca751435e80a0e16da4859beb51ff84670ce6bdc5edb30b94066
