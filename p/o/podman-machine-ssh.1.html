NOMBRE

podman-machine-ssh - Conéctate por SSH a una máquina virtual

SINOPSIS

podman machine ssh [opciones] [nombre] [comando [arg ...]]

DESCRIPCIÓN

Conéctate por SSH a una máquina virtual gestionada por Podman y opcionalmente ejecuta un comando en la máquina virtual. A menos que se utilice la máquina virtual predeterminada, el primer argumento debe ser el nombre de la máquina virtual. El comando opcional a ejecutar puede seguir a continuación. Si no se proporciona ningún comando, se establecerá una sesión interactiva con la máquina virtual.

El código de salida del comando ssh se reenvía al llamador de podman machine ssh, ver Códigos de Salida ⟨#Códigos-de-Salida⟩.

El nombre de la máquina predeterminada es podman-machine-default. Si no se especifica un nombre de máquina como argumento, se conectará por SSH a podman-machine-default.

Solo sin root.

OPCIONES

--help

Imprime el enunciado de uso.

--username=nombre

Nombre de usuario a utilizar al conectarse por SSH a la VM.

Códigos de Salida

El código de salida de podman machine ssh proporciona información sobre por qué falló el comando. Cuando los comandos de podman machine ssh salen con un código distinto de cero, los códigos de salida siguen el estándar de chroot, véase abajo:

125 El error es con podman en sí

$ podman machine ssh --foo; echo $?
Error: unknown flag: --foo
125

126 Ejecutando un comando contenido y el comando no se puede invocar

$ podman machine ssh /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 Ejecutando un comando contenido y el comando no se puede encontrar

$ podman machine ssh foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

Código de salida código de salida del comando contenido

$ podman machine ssh /bin/sh -c 'exit 3'; echo $?
3

EJEMPLOS

Para obtener una sesión interactiva con la máquina Podman predeterminada:

Conéctate por SSH a la máquina Podman predeterminada.

$ podman machine ssh

Ejecuta un comando dentro de la máquina Podman predeterminada a través de ssh.

$ podman machine ssh myvm

Ejecuta un comando dentro de la máquina Podman especificada a través de ssh.

$ podman machine ssh myvm rpm -q podman
