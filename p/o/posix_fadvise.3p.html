POSIX_FADVISE(3P) Manual de Programador POSIX POSIX_FADVISE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_fadvise — información de asesoramiento de archivos (TIEMPO REAL AVANZADO)

SINOPSIS

#include <fcntl.h>
int posix_fadvise(int fd, off_t offset, off_t len, int advice);

DESCRIPCIÓN

La función posix_fadvise() asesorará a la implementación sobre el comportamiento esperado de la aplicación con respecto a los datos en el archivo asociado con el descriptor de archivo abierto, fd, comenzando en offset y continuando durante len bytes. El rango especificado no necesita existir actualmente en el archivo. Si len es cero, se especifican todos los datos que siguen a offset. La implementación puede utilizar esta información para optimizar el manejo de los datos especificados. La función posix_fadvise() no tendrá ningún efecto sobre la semántica de otras operaciones en los datos especificados, aunque puede afectar el rendimiento de otras operaciones.

El asesoramiento que se aplicará a los datos se especifica mediante el parámetro advice y puede ser uno de los siguientes valores:

POSIX_FADV_NORMAL

Especifica que la aplicación no tiene ningún asesoramiento que dar sobre su comportamiento con respecto a los datos especificados. Es la característica por defecto si no se da ningún asesoramiento para un archivo abierto.
POSIX_FADV_SEQUENTIAL

Especifica que la aplicación espera acceder a los datos especificados secuencialmente desde offsets más bajos a offsets más altos.
POSIX_FADV_RANDOM

Especifica que la aplicación espera acceder a los datos especificados de forma aleatoria.
POSIX_FADV_WILLNEED

Especifica que la aplicación espera acceder a los datos especificados en un futuro cercano.
POSIX_FADV_DONTNEED

Especifica que la aplicación espera no acceder a los datos especificados en un futuro cercano.
POSIX_FADV_NOREUSE

Especifica que la aplicación espera acceder a los datos especificados una vez y luego no reutilizarlos después.

Estos valores están definidos en <fcntl.h>.

VALOR DE RETORNO

Al completarse con éxito, posix_fadvise() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función posix_fadvise() fallará si:

EBADF
El argumento fd no es un descriptor de archivo válido.
EINVAL
El valor de advice es inválido, o el valor de len es menor que cero.
ESPIPE
El argumento fd está asociado con una tubería (pipe) o FIFO.
