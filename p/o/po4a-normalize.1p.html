NOMBRE

po4a-normalize - normaliza un archivo de documentación analizándolo con po4a y volviéndolo a escribir.

SINOPSIS

po4a-normalize -f fmt master.doc

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y, lo que es más interesante, el mantenimiento de las traducciones) utilizando herramientas gettext en áreas donde no se esperaba, como la documentación.

El script po4a-normalize es una herramienta de depuración que se utiliza para asegurarse de que po4a no modifica el documento cuando no debe hacerlo. Úselo solo si está desarrollando un nuevo módulo o si duda de la corrección de las herramientas.

El documento generado se escribirá en po4a-normalize.output mientras que el archivo POT generado se escribirá en po4a-normalize.po por defecto, pero puede usar las opciones --localized y --pot para cambiar esto.

OPCIONES

-o, --option
Opción(es) adicional(es) para pasar al plugin de formato. Consulte la documentación de cada plugin para obtener más información sobre las opciones válidas y sus significados. Por ejemplo, podría pasar '-o tablecells' al analizador AsciiDoc, mientras que el analizador de texto aceptaría '-o tabs=split'.
-w, --width
Columna en la que se debe ajustar la línea del archivo resultante si el formato lo admite (predeterminado: 76). Si el valor proporcionado es 0 o negativo, el archivo resultante no se ajustará en absoluto. Esto es útil con algunos formatos que podrían romperse al volver a ajustarse.
-b, --blank
Crea un documento traducido en blanco. El documento traducido generado se creará asumiendo que todos los mensajes se traducen con un espacio o una nueva línea.

Esto es útil para comprobar qué partes del documento no se pueden traducir.

Ni --blank ni --capitalize se pueden especificar al mismo tiempo.

-C, --capitalize
Crea un documento traducido y un archivo po correspondiente con las cadenas originales traducidas como sus versiones en mayúsculas.

Esto es útil para comprobar qué partes del documento no se pueden traducir y para generar datos de prueba para po4a.

Ni --blank ni --capitalize se pueden especificar al mismo tiempo.

-h, --help
Muestra un breve mensaje de ayuda.
--help-format
Enumera los formatos de documentación que entiende po4a.
-f, --format
Formato de la documentación que desea manejar. Utilice la opción --help-format para ver la lista de formatos disponibles.
-M, --master-charset
Juego de caracteres del archivo que contiene el documento a traducir.
-l, --localized
Nombre del archivo normalizado a producir (po4a-normalize.output por defecto).
-p, --pot
Archivo pot a producir (po4a-normalize.po por defecto).
-V, --version
Muestra la versión del script y sale.
