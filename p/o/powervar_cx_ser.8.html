NOMBRE

powervar_cx_ser - Controlador para equipos de SAI de la serie UPM de Powervar con conexión Serie

SINOPSIS

powervar_cx_ser -h

powervar_cx_ser -a NOMBRE_SAI [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del controlador Powervar. Para obtener información sobre el controlador principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este controlador soporta la familia de SAI UPM de Powervar (dispositivos con conexión de puerto serie). Para dispositivos de la serie UPM conectados por USB, consulte también powervar_cx_usb(8).

ARGUMENTOS ADICIONALES

Este controlador soporta las siguientes opciones de configuración en el archivo ups.conf(5):

startdelay=número

Cambia el tiempo de retraso de inicio desde el valor predeterminado de 1 segundo.

offdelay=número

Cambia el tiempo de retraso de apagado desde el valor predeterminado de 0 segundos.

disptesttime=número

Cambia el tiempo de prueba de pantalla desde el valor predeterminado de 10 segundos.

COMANDOS INSTANTÁNEOS

Este controlador soporta los siguientes Comandos Instantáneos (consulte upscmd(8)):

Todas las unidades GTS y UPM de SAI

beeper.disable

Deshabilita el zumbador del SAI.

beeper.enable

Habilita el zumbador del SAI.

beeper.mute

Silencia temporalmente el zumbador del SAI.

shutdown.return

Apaga la carga posiblemente después de un retraso y regresa cuando la energía se restablece.

shutdown.stop

Detiene un apagado en curso.

shutdown.reboot

Apaga brevemente la carga mientras reinicia el SAI.

shutdown.stayoff

Apaga la carga y permanece apagada.

test.battery.start.deep

Inicia una prueba de batería "profunda". Esta prueba ejecuta el SAI hasta el punto de batería baja y luego regresa a la línea de CA.

test.battery.start.quick

Inicia una prueba de batería "rápida". El tiempo predeterminado es de 2 minutos. Este tiempo se puede configurar en el archivo ups.conf. Consulte testime arriba.

test.battery.stop

Detiene una prueba de batería en curso.

test.failure.start

Inicia una simulación de un fallo de energía de entrada.

test.failure.stop

Detiene una simulación de un fallo de energía de entrada.

Todas las unidades UPM de SAI

test.panel.start

Inicia la prueba del panel del SAI.

reset.input.minmax

Restablece el estado del voltaje de entrada mínimo y máximo.

VARIABLES ESCRIBIBLES

Consulte upsrw(8) para ver qué variables son escribibles para el SAI.
