subrutina cpoequ (integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

CPOEQU

Propósito:

!>
!> CPOEQU calcula escalados de fila y columna destinados a equilibrar una
!> matriz hermitiana definida positiva A y reducir su número de condición
!> (con respecto a la norma dos). S contiene los factores de escala,
!> S(i) = 1/sqrt(A(i,i)), elegidos para que la matriz escalada B con
!> elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la diagonal. Esta
!> elección de S pone el número de condición de B dentro de un factor N del
!> número de condición posible más pequeño sobre todos los escalados diagonales
!> posibles.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          La matriz hermitiana definida positiva N-por-N cuyos factores de
!>          escala se van a calcular. Solo se hace referencia a los elementos
!>          diagonales de A.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

S

!>          S es un array REAL, dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación del S(i) más pequeño con
!>          el S(i) más grande.  Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no merece la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande.  Si AMAX está muy
!>          cerca de desbordamiento o muy cerca de subdesbordamiento, la matriz
!>          debería escalarse.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal es no positivo.
!>

NAME


poequ – equilibrate a general matrix






SYNOPSIS


    SUBROUTINE POEQU(N, A, LDA, S, SCOND, AMAX, INFO)
        INTEGER :: N
        REAL, DIMENSION(LDA, *) :: A
        INTEGER :: LDA
        REAL, DIMENSION(*) :: S
        REAL :: SCOND
        REAL :: AMAX
        INTEGER :: INFO
    END SUBROUTINE POEQU



    SUBROUTINE ZPOEQU(N, A, LDA, S, SCOND, AMAX, INFO)
        INTEGER :: N
        COMPLEX*16, DIMENSION(LDA, *) :: A
        INTEGER :: LDA
        REAL, DIMENSION(*) :: S
        REAL :: SCOND
        REAL :: AMAX
        INTEGER :: INFO
    END SUBROUTINE ZPOEQU







Detailed Description


The purpose of POEQU and ZPOEQU is to compute row and column
    scalings intended to equilibrate a Hermitian positive definite matrix A
    and reduce its condition number (with respect to the two-norm). S contains
    the scale factors, S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix
    B with elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal. This
    choice of S puts the condition number of B within a factor N of the
    smallest possible condition number over all possible diagonal scalings.


The subroutine POEQU and ZPOEQU cannot be used if the matrix is
    not positive definite. For other matrices, use the routines SGEEQU, SGEEQUF,
    DGEEQU, DGEEQUF, CGEEQU, CGEEQUF, ZGEEQU, ZGEEQUF.




Parameters




N




N is INTEGER, the order of the matrix A. N >= 0.




A




A is REAL or COMPLEX*16 array, dimension (LDA,N). The N-by-N
    Hermitian positive definite matrix whose scaling factors are to be
    computed. Only the diagonal elements of A are referenced.




LDA




LDA is INTEGER. The leading dimension of the array A. LDA >=
    max(1,N).




S




S is REAL array, dimension (N). If INFO = 0, S contains the
    scale factors for A.




SCOND




SCOND is REAL. If INFO = 0, S contains the ratio of the
    smallest S(i) to the largest S(i). If SCOND >= 0.1 and AMAX is
    neither too large nor too small, it is not worth scaling by S.




AMAX




AMAX is REAL. Absolute value of largest matrix element. If
    AMAX is very close to overflow or very close to underflow, the matrix
    should be scaled.




INFO




INFO is INTEGER.




= 0: successful exit


< 0: if INFO = -i, the i-th argument had an
    illegal value


> 0: if INFO = i, the i-th diagonal element is
    nonpositive.
