NOMBRE

podman-init - Inicializa uno o más contenedores

SINOPSIS

podman init [opciones] contenedor [contenedor...]

podman container init [opciones] contenedor [contenedor...]

DESCRIPCIÓN

Inicializa uno o más contenedores. Puede utilizar IDs o nombres de contenedor como entrada. La inicialización de un contenedor realiza todas las tareas necesarias para iniciar el contenedor (montar sistemas de archivos, crear una especificación OCI, inicializar la red del contenedor) pero no inicia el contenedor. Si un contenedor no está inicializado, los comandos podman start y podman run lo inicializan automáticamente antes de iniciarlo. Este comando está diseñado para ser utilizado para inspeccionar el sistema de archivos o la especificación OCI de un contenedor antes de iniciarlo. Esto se puede usar para inspeccionar el contenedor antes de que se ejecute, o para depurar por qué un contenedor no se inicia.

OPCIONES

--all, -a

Inicializa todos los contenedores. Los contenedores que ya se han inicializado (incluidos los que se han iniciado y se están ejecutando) se ignoran.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

EJEMPLOS

Inicializa el contenedor especificado con un ID dado.

$ podman init 35480fc9d568

Inicializa el contenedor especificado con un nombre dado.

$ podman init test1

Inicializa el último contenedor. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman init --latest

Inicializa todos los contenedores.
