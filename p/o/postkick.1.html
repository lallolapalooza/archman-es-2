POSTKICK(1) Manual de comandos generales POSTKICK(1)

NOMBRE

postkick - expulsar un servicio de Postfix

SINOPSIS

postkick [-c directorio_config] [-v] clase servicio petición

DESCRIPCIÓN


El comando postkick(1) envía la petición al servicio especificado a través de un canal de transporte local. Este comando hace que la IPC privada de Postfix sea accesible para su uso, por ejemplo, en scripts de shell.

Opciones:

-c directorio_config
Lee el archivo de configuración main.cf en el directorio indicado en lugar del directorio de configuración predeterminado.
-v
Activa el registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado.

Argumentos:

clase
Nombre de una clase de puntos finales de canal de transporte local, ya sea public (accesible por cualquier usuario local) o private (solo acceso administrativo).
servicio
El nombre de un punto final de transporte local dentro de la clase indicada.
petición
Una cadena de texto. La lista de peticiones válidas es específica del servicio.

DIAGNÓSTICOS


Los problemas y las transacciones se registran en el flujo de error estándar.

ENTORNO

MAIL_CONFIG
Directorio con los archivos de configuración de Postfix.
MAIL_VERBOSE
Activa el registro detallado con fines de depuración.

PARÁMETROS DE CONFIGURACIÓN

Los siguientes parámetros de main.cf son especialmente relevantes para este programa. El texto a continuación proporciona solo un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

config_directory (ver salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
application_event_drain_time (100s)
Cuánto tiempo espera el comando postkick(1) a que una petición entre en el búfer de entrada del proceso demonio de Postfix antes de rendirse.
import_environment (ver salida de 'postconf -d')
La lista de variables de entorno que un proceso privilegiado de Postfix importará de un proceso padre no Postfix, o anulaciones de entorno nombre=valor.
queue_directory (ver salida de 'postconf -d')
La ubicación del directorio de cola principal de Postfix.
