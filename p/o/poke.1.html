POKE(1) Comandos de usuario POKE(1)

NOMBRE

poke - El editor binario extensible de GNU

SINOPSIS

poke [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

Editor interactivo para archivos binarios.

-l, --load=ARCHIVO
carga el pickle dado al inicio
-L ARCHIVO
carga el pickle dado y sale

Comandos para poke desde la línea de comandos:

-c, --command=COMANDO
ejecuta el comando dado
-s, --source=ARCHIVO
ejecuta comandos desde ARCHIVO

Estilizado de la salida de texto:

--color=(sí|no|auto|html|test) emite salida estilizada

--style=ARCHIVO_ESTILO
archivo de estilo a usar al estilizar
--style-dark
usa el estilo predeterminado para fondos oscuros
--style-bright
usa el estilo predeterminado para fondos claros
-q, --no-init-file
no carga un archivo de inicialización
--no-auto-map
desactiva el mapa automático
--no-hserver
no ejecuta el servidor de hipervínculos
--no-stdtypes
no define tipos estándar
--quiet
ser lo más conciso posible
--help
imprime un mensaje de ayuda y sale
--version
muestra la versión y sale

Las siguientes variables de entorno, si están establecidas, son usadas por poke:

POKE_LOAD_PATH
Lista de rutas de archivos separadas por dos puntos (:) que se anteponen a la ruta de carga cuando poke se inicia
