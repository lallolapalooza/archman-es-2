NOMBRE

podman-image - Gestionar imágenes

SINOPSIS

podman image subcomando

DESCRIPCIÓN

El comando image permite la gestión de imágenes.

COMANDOS

Comando Página del manual Descripción
build podman-build(1) Construir un contenedor utilizando un Dockerfile.
diff podman-image-diff(1) Inspeccionar cambios en el sistema de archivos de una imagen.
exists podman-image-exists(1) Comprobar si una imagen existe en el almacenamiento local.
history podman-history(1) Mostrar el historial de una imagen.
import podman-import(1) Importar un tarball y guardarlo como una imagen del sistema de archivos.
inspect podman-image-inspect(1) Mostrar la configuración de una imagen.
list podman-images(1) Listar las imágenes de contenedor en el sistema. (alias ls)
load podman-load(1) Cargar una imagen desde el archivo de docker.
mount podman-image-mount(1) Montar el sistema de archivos raíz de una imagen.
prune podman-image-prune(1) Eliminar todas las imágenes no utilizadas del almacén local.
pull podman-pull(1) Descargar una imagen de un registro.
push podman-push(1) Enviar una imagen desde el almacenamiento local a otro lugar.
rm podman-rmi(1) Eliminar una o más imágenes almacenadas localmente.
save podman-save(1) Guardar una imagen en formato docker-archive u oci.
scp podman-image-scp(1) Copiar de forma segura una imagen de un host a otro.
search podman-search(1) Buscar una imagen en un registro.
sign podman-image-sign(1) Crear una firma para una imagen.
tag podman-tag(1) Añadir un nombre adicional a una imagen local.
tree podman-image-tree(1) Imprimir la jerarquía de capas de una imagen en formato de árbol.
trust podman-image-trust(1) Gestionar la política de confianza de imágenes del registro de contenedores.
unmount podman-image-unmount(1) Desmontar el sistema de archivos raíz de una imagen.
untag podman-untag(1) Eliminar uno o más nombres de una imagen almacenada localmente.
