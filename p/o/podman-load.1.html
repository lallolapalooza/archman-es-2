NOMBRE

podman-load - Carga imagen(es) de un archivo tar en el almacenamiento de contenedores

SINOPSIS

podman load [opciones]

podman image load [opciones]

DESCRIPCIÓN

podman load carga una imagen desde un archivo oci-archive o docker-archive almacenado en la máquina local en el almacenamiento de contenedores. podman load lee desde stdin por defecto o desde un archivo si se establece la opción input. podman load se usa para cargar desde el archivo generado por podman save, que incluye las capas padre de la imagen. Para cargar el archivo del sistema de archivos del contenedor creado por podman export, use podman import.

El cliente local también admite la carga de un oci-dir o un docker-dir como se creó con podman save (1).

La opción quiet suprime la salida de progreso cuando se establece. Nota: : es un carácter restringido y no puede formar parte del nombre del archivo.

OPCIONES

--help, -h

Imprime el enunciado de uso

--input, -i=input

Carga el archivo de entrada especificado en lugar de stdin. El archivo puede estar en el sistema de archivos local o en un servidor (por ejemplo, https://server.com/archive.tar). También admite la carga de archivos comprimidos.

El cliente remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2), requiere el uso de esta opción.

NOTA: Utilice la variable de entorno TMPDIR para cambiar la ubicación de almacenamiento temporal de las imágenes de contenedor. Podman utiliza por defecto /var/tmp.

--quiet, -q

Suprime la salida de progreso

EJEMPLOS

Crea una imagen a partir de un archivo tar comprimido, sin mostrar progreso.

$ podman load --quiet -i fedora.tar.gz

Crea una imagen desde el archivo archive.tar extraído de una URL, sin mostrar progreso.

$ podman load -q -i https://server.com/archive.tar

Crea una imagen desde stdin usando redirección bash desde un archivo tar.

$ podman load < fedora.tar
