POSIX_TRACE_EVENT(3P) Manual de programador POSIX POSIX_TRACE_EVENT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_event, posix_trace_eventid_open — funciones de rastreo para instrumentar código de aplicación (TRACING)

SINOPSIS

#include <sys/types.h>
#include <trace.h>
void posix_trace_event(trace_event_id_t event_id,
    const void *restrict data_ptr, size_t data_len);
int posix_trace_eventid_open(const char *restrict event_name,
    trace_event_id_t *restrict event_id);

DESCRIPCIÓN

La función posix_trace_event() registrará el event_id y los datos del usuario apuntados por data_ptr en el flujo de rastreo en el que se está rastreando el proceso que llama y en el que event_id no está filtrado. Si el tamaño total de los datos del evento de rastreo de usuario representados por data_len no es mayor que el tamaño máximo declarado para los datos del evento de rastreo de usuario, entonces el atributo truncation-status del evento de rastreo registrado es POSIX_TRACE_NOT_TRUNCATED. De lo contrario, los datos del evento de rastreo de usuario se truncan a este tamaño máximo declarado y el atributo truncation-status del evento de rastreo registrado es POSIX_TRACE_TRUNCATED_RECORD.

Si no se ha creado ningún flujo de rastreo para el proceso o si el flujo de rastreo creado no se está ejecutando, o si el evento de rastreo especificado por event_id está filtrado en el flujo de rastreo, la función posix_trace_event() no tendrá ningún efecto.

La función posix_trace_eventid_open() asociará un nombre de evento de rastreo de usuario con un identificador de tipo de evento de rastreo para el proceso que llama. El nombre del evento de rastreo es la cadena apuntada por el argumento event_name. Tendrá un máximo de {TRACE_EVENT_NAME_MAX} caracteres (que tiene el valor mínimo {_POSIX_TRACE_EVENT_NAME_MAX}). El número de identificadores de tipo de evento de rastreo de usuario que se pueden definir para cualquier proceso dado está limitado por el valor máximo {TRACE_USER_EVENT_MAX}, que tiene el valor mínimo {POSIX_TRACE_USER_EVENT_MAX}.

Si la opción de Herencia de Rastreo no es compatible, la función posix_trace_eventid_open() asociará el nombre del evento de rastreo de usuario apuntado por el argumento event_name con un identificador de tipo de evento de rastreo que sea único para el proceso rastreado, y se devolverá en la variable apuntada por el argumento event_id. Si el nombre del evento de rastreo de usuario ya se ha mapeado para el proceso rastreado, se devolverá el identificador de tipo de evento de rastreo asignado previamente. Si se ha alcanzado el límite de nombres de eventos de rastreo de usuario por proceso representado por {TRACE_USER_EVENT_MAX}, se devolverá el evento de rastreo de usuario predefinido POSIX_TRACE_UNNAMED_USEREVENT (consulte la Tabla 2-7, Opción de Rastreo: Evento de Rastreo de Usuario).

Si la opción de Herencia de Rastreo es compatible, la función posix_trace_eventid_open() asociará el nombre del evento de rastreo de usuario apuntado por el argumento event_name con un identificador de tipo de evento de rastreo que sea único para todos los procesos que se rastrean en el mismo flujo de rastreo, y se devolverá en la variable apuntada por el argumento event_id. Si el nombre del evento de rastreo de usuario ya se ha mapeado para los procesos rastreados, se devolverá el identificador de tipo de evento de rastreo asignado previamente. Si se ha alcanzado el límite de nombres de eventos de rastreo de usuario por proceso representado por {TRACE_USER_EVENT_MAX}, se devolverá el evento de rastreo de usuario predefinido POSIX_TRACE_UNNAMED_USEREVENT (Tabla 2-7, Opción de Rastreo: Evento de Rastreo de Usuario).

Nota:
El procedimiento anterior, junto con el hecho de que múltiples procesos solo pueden rastrearse en el mismo flujo de rastreo por herencia, garantiza que todos los procesos que se rastrean en un flujo de rastreo tengan el mismo mapeo de nombres de eventos de rastreo a identificadores de tipos de eventos de rastreo.

Si no se ha creado ningún flujo de rastreo, la función posix_trace_eventid_open() almacenará esta información para flujos de rastreo futuros creados para este proceso.

VALOR DE RETORNO

No se define ningún valor de retorno para la función posix_trace_event().

Al completarse con éxito, la función posix_trace_eventid_open() devolverá un valor de cero. De lo contrario, devolverá el número de error correspondiente. La función posix_trace_eventid_open() almacena el valor del identificador del tipo de evento de rastreo en el objeto apuntado por event_id, si tiene éxito.

ERRORES

La función posix_trace_eventid_open() fallará si:

ENAMETOOLONG

La longitud del nombre apuntado por el argumento event_name fue mayor que el valor definido por la implementación {TRACE_EVENT_NAME_MAX}.
