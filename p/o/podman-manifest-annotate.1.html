NOMBRE

podman-manifest-annotate - Añade y actualiza información sobre una imagen o artefacto en una lista de manifiestos o índice de imágenes

SINOPSIS

podman manifest annotate [opciones] nombredeimagendeindicedemanifiesto digestedelmanifiestodeimagenoimagenoartefacto

DESCRIPCIÓN

Añade o actualiza información sobre una imagen o artefacto incluido en una lista de manifiestos o índice de imágenes.

OPCIONES

--annotation=anotación=valor

Establece una anotación en la entrada para la imagen o artefacto especificado.

Si también se especifica --index, establece la anotación en el índice de imágenes completo.

--arch=arquitectura

Anula la arquitectura que la lista o índice registra como requisito para la imagen. Esto se recupera automáticamente de la información de configuración de la imagen, por lo que rara vez es necesario usar esta opción.

--features=característica

Especifica la lista de características que la lista o índice registra como requisitos para la imagen. Esta opción se usa raramente.

--index

Trata los argumentos de la opción --annotation como valores de anotación que se establecerán en el propio índice de imágenes en lugar de en una entrada del índice de imágenes. Implícito para --subject.

--os=SO

Anula el SO que la lista o índice registra como requisito para la imagen. Esto se recupera automáticamente de la información de configuración de la imagen, por lo que rara vez es necesario usar esta opción.

--os-features=característica

Especifica la lista de características del SO que la lista o índice registra como requisitos para la imagen. Esta opción se usa raramente.

--os-version=versión

Especifica la versión del SO que la lista o índice registra como requisito para la imagen. Esta opción se usa raramente.

--subject=nombredeimagen

Establece el campo subject en el índice de imágenes para marcar el índice de imágenes como asociado con la imagen especificada de alguna manera. Un índice de imágenes solo puede asociarse con, como máximo, un sujeto.

--variant

Especifica la variante que la lista o índice registra para la imagen. Esta opción se usa típicamente para distinguir entre múltiples entradas que comparten el mismo valor de arquitectura, pero que esperan diferentes versiones de su conjunto de instrucciones.

EJEMPLOS

Actualizar la información de arquitectura y variante para la lista de manifiestos dada para la imagen:

podman manifest annotate --arch arm64 --variant v8 mylist:v1.11 sha256:59eec8837a4d942cc19a52b8c09ea75121acc38114a2c68b98983ce9356b8610
