NOMBRE

podman-top - Muestra los procesos en ejecución de un contenedor

SINOPSIS

podman top [opciones] contenedor [descriptores-de-formato]

podman container top [opciones] contenedor [descriptores-de-formato]

DESCRIPCIÓN

Muestra los procesos en ejecución del contenedor. Los descriptores-de-formato son descriptores de formato AIX compatibles con ps (1) pero extendidos para imprimir información adicional, como el modo seccomp o las capacidades efectivas de un proceso dado. Los descriptores pueden pasarse como argumentos separados o como un único argumento separado por comas. Tenga en cuenta que también se pueden especificar opciones y/o flags de ps(1); en este caso, Podman recurre a la ejecución de ps(1) del host con los argumentos y flags especificados en el espacio de nombres del contenedor. Si el contenedor tiene la capacidad CAP_SYS_PTRACE, ejecutaremos ps(1) en el contenedor, por lo que debe estar instalado allí. Para extraer información relacionada con el host, utilice los descriptores "h*". Por ejemplo, podman top $nombre hpid huser para mostrar el PID y el usuario de los procesos en el contexto del host.

OPCIONES

--help, -h

Imprime el aviso de uso

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

DESCRIPTORES DE FORMATO

Los siguientes descriptores son compatibles además de los descriptores de formato AIX mencionados en ps (1):

args, capbnd, capeff, capinh, capprm, comm, etime, group, groups, hgroup, hgroups, hpid, huser, label, nice, pcpu, pgid, pid, ppid, rgroup, ruser, seccomp, state, time, tty, user, vsz

capbnd

Conjunto de capacidades de bounding. Ver capabilities (7) para más información.

capeff

Conjunto de capacidades efectivas. Ver capabilities (7) para más información.

capinh

Conjunto de capacidades heredables. Ver capabilities (7) para más información.

capprm

Conjunto de capacidades permitidas. Ver capabilities (7) para más información.

group

El grupo efectivo del proceso.

groups

Los grupos suplementarios del proceso.

hgroup

El grupo efectivo correspondiente de un proceso de contenedor en el host.

hgroups

Los grupos suplementarios correspondientes de un proceso de contenedor en el host.

hpid

El PID del host correspondiente de un proceso de contenedor.

huser

El usuario efectivo correspondiente de un proceso de contenedor en el host.

label

Atributos de seguridad actuales del proceso.

seccomp

Modo seccomp del proceso (es decir, deshabilitado, estricto o filtro). Ver seccomp (2) para más información.

state

Códigos de estado del proceso (por ejemplo, R para en ejecución, S para dormido). Ver proc(5) para más información.

stime

Hora de inicio del proceso (por ejemplo, "2019-12-09 10:50:36 +0100 CET).

EJEMPLOS

Por defecto, podman-top imprime datos similares a ps -ef.

$ podman top f5a62a71b07
USER   PID   PPID   %CPU    ELAPSED         TTY     TIME   COMMAND
root   1     0      0.000   20.386825206s   pts/0   0s     sh
root   7     1      0.000   16.386882887s   pts/0   0s     sleep
root   8     1      0.000   11.386886562s   pts/0   0s     vi

La salida se puede controlar especificando descriptores de formato como argumentos después del contenedor.

$ podman top -l pid seccomp args %C
PID   SECCOMP   COMMAND     %CPU
1     filter    sh          0.000
8     filter    vi /etc/    0.000

Podman recurre a la ejecución de ps(1) del host en el espacio de nombres del contenedor si se especifica un descriptor desconocido.

$ podman top -l -- aux
USER   PID   PPID   %CPU    ELAPSED             TTY   TIME   COMMAND
root   1     0      0.000   1h2m12.497061672s   ?     0s     sleep 100000
