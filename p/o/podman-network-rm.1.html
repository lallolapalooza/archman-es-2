NOMBRE

podman-network-rm - Elimina una o más redes

SINOPSIS

podman network rm [opciones] [red...]

DESCRIPCIÓN

Elimina una o más redes de Podman.

OPCIONES

--force, -f

La opción force elimina todos los contenedores que utilizan la red especificada. Si el contenedor se está ejecutando, se detiene y se elimina.

--time, -t=segundos

Segundos a esperar antes de detener forzosamente los contenedores en ejecución que utilizan la red especificada. La opción --force debe ser especificada para usar la opción --time. Use -1 para esperar infinitamente.

EJEMPLOS

Eliminar la red especificada:

# podman network rm podman9
podman9

Eliminar la red especificada y todos los contenedores asociados con la red:

# podman network rm -f fred
fred

Eliminar la red especificada y todos los contenedores asociados con la red después de esperar hasta 15 segundos:

# podman network rm --force --time 15 fred
fred

ESTATUS DE SALIDA

0 Todas las redes especificadas fueron eliminadas

1 Una de las redes especificadas no existía, y no hubo otros fallos

2 La red está en uso por un contenedor o un Pod

125 El comando falla por cualquier otra razón

VER TAMBIÉN

podman(1), podman-network(1)
