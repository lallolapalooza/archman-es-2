NOMBRE

podman-pod-start - Inicia uno o más pods

SINOPSIS

podman pod start [opciones] pod ...

DESCRIPCIÓN

Inicia contenedores en uno o más pods. Puede usar IDs o nombres de pod como entrada. El pod debe tener un contenedor adjunto para poder iniciarse.

OPCIONES

--all, -a

Inicia todos los pods

--latest, -l

En lugar de proporcionar el nombre o ID del pod, usa el último pod creado. Nota: el último pod iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--pod-id-file=archivo

Lee el ID del pod desde el archivo especificado e inicia el pod. Se puede especificar varias veces.

EJEMPLO

Inicia un pod con un nombre dado:

podman pod start miwebserverpod

Inicia pods con IDs dados:

podman pod start 860a4b23 5421ab4

Inicia el último pod. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

podman pod start --latest

Inicia todos los pods:

podman pod start --all

Inicia un pod usando el ID especificado en un archivo dado:

podman pod start --pod-id-file /ruta/al/archivo/de/id

VER TAMBIÉN

podman(1), podman-pod(1), podman-pod-stop(1)
