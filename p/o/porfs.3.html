CPORFS

Propósito:

!>
!> CPORFS mejora la solución calculada de un sistema de ecuaciones
!> lineales cuando la matriz de coeficientes es hermitiana definida positiva,
!> y proporciona cotas de error y estimaciones de error hacia atrás para la
!> solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          La matriz hermitiana A.  Si UPLO = 'U', la parte triangular
!>          superior N por N de A contiene la parte triangular superior
!>          de la matriz A, y la parte triangular estrictamente inferior de A
!>          no se referencia.  Si UPLO = 'L', la parte triangular inferior
!>          N por N de A contiene la parte triangular inferior
!>          de la matriz A, y la parte triangular estrictamente superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

AF

!>          AF es array COMPLEX, dimension (LDAF,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, tal como fue calculada por CPOTRF.
!>

LDAF

!>          LDAF es INTEGER
!>          La dimensión principal del array AF.  LDAF >= max(1,N).
!>

B

!>          B es array COMPLEX, dimension (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEX, dimension (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como fue calculada por CPOTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimension (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimension (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el menor cambio relativo en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es array COMPLEX, dimension (2*N)
!>

RWORK

!>          RWORK es array REAL, dimension (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el argumento i-ésimo tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>

NAME

porfs - estimate the error bounds for the solution of a symmetric positive definite system of linear equations

SYNOPSIS

   SUBROUTINE DPORFS( UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, X, LDX,
                        FERR, BERR, WORK, IWORK, INFO )

      CHARACTER *1 UPLO
      INTEGER N, NRHS, LDA, LDAF, LDB, LDX, INFO
      DOUBLE PRECISION A( LDA, * ), AF( LDAF, * ), B( LDB, * ),
     $                 X( LDX, * ), FERR( * ), BERR( * ), WORK( * )
      INTEGER IWORK( * )

   SUBROUTINE SPORFS( UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, X, LDX,
                        FERR, BERR, WORK, IWORK, INFO )

      CHARACTER *1 UPLO
      INTEGER N, NRHS, LDA, LDAF, LDB, LDX, INFO
      REAL A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * ),
     $             FERR( * ), BERR( * ), WORK( * )
      INTEGER IWORK( * )

   SUBROUTINE ZPORFS( UPLO, N, NRHS, A, LDA, AF, LDAF, B, LDB, X, LDX,
                        FERR, BERR, WORK, RWORK, INFO )

      CHARACTER *1 UPLO
      INTEGER N, NRHS, LDA, LDAF, LDB, LDX, INFO
      COMPLEX*16 A( LDA, * ), AF( LDAF, * ), B( LDB, * ), X( LDX, * ),
     $                           WORK( * )
      DOUBLE PRECISION FERR( * ), BERR( * ), RWORK( * )

DESCRIPTION

The subroutines compute error bounds and backward error estimates for the solution of a system of linear equations A*X = B where A is a symmetric positive definite (or Hermitian positive definite in the case of ZPORFS) matrix. The factorizations of A are computed by DPOTRF, SPOTRF, or ZPOTRF and may be provided on entry. Iterative refinement is used to improve the computed solution X, and error bounds are computed for the columnwise error.

For each column of B, a forward error bound is computed for the corresponding column of X. The backward error vector is computed and then used to refine the solution X.

The subroutine DPORFS is described in this manual. SPORFS and ZPORFS are the single-precision and double-precision complex versions, respectively.

The condition number of the matrix A is estimated in RCOND and used to compute the forward error bound.

If the form of A is:

 A =  U * U**T  (if UPLO = 'U')
 or
 A =  L * L**T  (if UPLO = 'L')

where U is upper triangular and L is lower triangular, the factorizations are computed by DPOTRF.

If the form of A is:

 A =  U * U**H  (if UPLO = 'U')
 or
 A =  L * L**H  (if UPLO = 'L')

where U is upper triangular and L is lower triangular, the factorizations are computed by ZPOTRF.

The argument RCOND is an estimate of the reciprocal of the condition number of A. If RCOND is small, the matrix A is close to singular, and the solution X may be inaccurate.

DPORFS

Purpose:

!>
!> DPORFS improves the computed solution to a system of linear
!> equations when the coefficient matrix is symmetric positive definite,
!> and provides error bounds and backward error estimates for the
!> solution.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The symmetric matrix A.  If UPLO = 'U', the leading N-by-N
!>          upper triangular part of A contains the upper triangular part
!>          of the matrix A, and the strictly lower triangular part of A
!>          is not referenced.  If UPLO = 'L', the leading N-by-N lower
!>          triangular part of A contains the lower triangular part of
!>          the matrix A, and the strictly upper triangular part of A is
!>          not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

AF

!>          AF is DOUBLE PRECISION array, dimension (LDAF,N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**T*U or A = L*L**T, as computed by DPOTRF.
!>

LDAF

!>          LDAF is INTEGER
!>          The leading dimension of the array AF.  LDAF >= max(1,N).
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          The right hand side matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is DOUBLE PRECISION array, dimension (LDX,NRHS)
!>          On entry, the solution matrix X, as computed by DPOTRS.
!>          On exit, the improved solution matrix X.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>

FERR

!>          FERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

Internal Parameters:

!>  ITMAX is the maximum number of steps of iterative refinement.
!>

Author
