NOMBRE

podman-stats - Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores

SINOPSIS

podman stats [opciones] [contenedor]

podman container stats [opciones] [contenedor]

DESCRIPCIÓN

Muestra un flujo en vivo de las estadísticas de uso de recursos de uno o más contenedores.

Nota: Podman stats no funciona en entornos sin privilegios (rootless) que utilizan cgroups v1. Podman stats depende de la información de cgroup para las estadísticas, y cgroup v1 no es compatible con casos de uso sin privilegios.

Nota: Los entornos sin privilegios que utilizan cgroups v2 no pueden informar estadísticas sobre su uso de red.

OPCIONES

--all, -a

Muestra todos los contenedores. Por defecto, solo se muestran los contenedores en ejecución.

--format=plantilla

Imprime las estadísticas de los contenedores en formato JSON o utilizando una plantilla de Go.

Los marcadores válidos para la plantilla de Go se enumeran a continuación:

Marcador Descripción
.AvgCPU CPU promedio, flotante de precisión completa
.AVGCPU CPU promedio, formateado como porcentaje
.BlockInput Total de datos leídos del dispositivo de bloque
.BlockIO Total de datos leídos / Total de datos escritos en el dispositivo de bloque
.BlockOutput Total de datos escritos en el dispositivo de bloque
.ContainerID ID del contenedor, hash completo (sin truncar)
.ContainerStats ... Estructura anidada, solo para expertos
.CPU Porcentaje de CPU, flotante de precisión completa
.CPUNano Uso de CPU, total, en nanosegundos
.CPUPerc Porcentaje de CPU utilizado
.CPUSystemNano Uso de CPU, kernel, en nanosegundos
.Duration Igual que CPUNano
.ID ID del contenedor, truncado
.MemLimit Límite de memoria, en bytes
.MemPerc Porcentaje de memoria utilizado
.MemUsage Uso de memoria
.MemUsageBytes Uso de memoria (IEC)
.Name Nombre del contenedor
.NetIO Entrada/Salida de red
.Network ... Entrada/Salida de red, separada por interfaz de red
.PerCPU Tiempo de CPU consumido por todas las tareas [1]
.PIDs Número de PIDs
.PIDS Número de PIDs (sí, sabemos que esto es un duplicado)
.SystemNano Fecha y hora actual del sistema, nanosegundos desde la época
.Up Duración (CPUNano), en formato legible por humanos
.UpTime Igual que Up

[1] Solo Cgroups V1

Al usar una plantilla de Go, precede el formato con table para imprimir encabezados.

--interval, -i=segundos

Tiempo en segundos entre informes de estadísticas, por defecto 5 segundos.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--no-reset

No borrar la terminal/pantalla entre intervalos de informes.

--no-stream

Deshabilita el streaming de estadísticas y solo recupera el primer resultado, el valor predeterminado es falso.

--no-trunc

No truncar la salida.

EJEMPLO

Lista las estadísticas de todos los contenedores en ejecución sin modo de streaming:

# podman stats -a --no-stream
ID             NOMBRE              CPU %   USO MEM / LÍMITE   % MEM   ENTRADA/SALIDA RED   ENTRADA/SALIDA BLOQUE   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

Lista las estadísticas del contenedor especificado en modo de streaming:

# podman stats a9f80
ID             NOMBRE             CPU %   USO MEM / LÍMITE   % MEM   ENTRADA/SALIDA RED   ENTRADA/SALIDA BLOQUE   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

Lista las estadísticas especificadas del contenedor especificado en formato de tabla:

$ podman stats --no-trunc 3667 --format 'table {{ .ID }} {{ .MemUsage }}'
ID                                                                USO MEM / LÍMITE
3667c6aacb06aac2eaffce914c01736420023d56ef9b0f4cfe58b6d6a78b7503  49.15kB / 67.17GB

Lista las estadísticas del contenedor especificado en formato JSON:

# podman stats --no-stream --format=json a9f80
[
    {
	"id": "a9f807ffaacd",
	"name": "frosty_hodgkin",
	"cpu_percent": "--",
	"mem_usage": "3.092MB / 16.7GB",
	"mem_percent": "0.02%",
	"netio": "-- / --",
	"blocki": "-- / --",
	"pids": "2"
    }
]

Lista las estadísticas del contenedor especificado en formato de tabla:

# podman stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NOMBRE           USO MEM / LÍMITE
6eae9e25a564   clever_bassi   3.031MB / 16.7GB

Nota: Al usar una red slirp4netns con el controlador de puertos rootlesskit, el tráfico enviado a través del reenvío de puertos se contabiliza en el dispositivo lo. El tráfico contabilizado en lo no se tiene en cuenta en la salida de estadísticas.
