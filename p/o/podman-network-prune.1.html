NOMBRE

podman network prune - Eliminar todas las redes no utilizadas

SINOPSIS

podman network prune [opciones]

DESCRIPCIÓN

Elimina todas las redes no utilizadas. Una red no utilizada se define como una red que no tiene contenedores conectados o configurados para conectarse a ella. No elimina la llamada red predeterminada, que tiene el nombre podman.

OPCIONES

--filter

Proporciona valores de filtro.

El formato del argumento filtros es clave=valor. Si hay más de un filtro, pasa múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros compatibles:

Filtro Descripción
label Solo elimina redes, con (o sin, en el caso de que se use label!=[...] es decir) las etiquetas especificadas.
until Solo elimina redes creadas antes de la marca de tiempo dada.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que elimina redes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que elimina redes sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo con formato de fecha o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

--force, -f

No pedir confirmación

EJEMPLO

Poda de redes:

podman network prune

Poda de todas las redes no creadas en las últimas dos horas:

podman network prune --filter until=2h

podman(1), podman-network(1), podman-network-rm(1)
