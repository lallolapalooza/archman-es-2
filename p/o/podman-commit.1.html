NOMBRE

podman-commit - Crear una nueva imagen basada en el contenedor modificado

SINOPSIS

podman commit [opciones] contenedor [imagen]

podman container commit [opciones] contenedor [imagen]

DESCRIPCIÓN

podman commit crea una imagen basándose en un contenedor modificado. El autor de la imagen se puede establecer usando la opción --author. Se pueden configurar varias instrucciones de imagen con la opción --change y un mensaje de confirmación se puede establecer usando la opción --message. El contenedor y sus procesos no se pausan mientras se confirma la imagen. Si esto no se desea, la opción --pause se puede establecer en true. Cuando la confirmación se completa, Podman imprime el ID de la nueva imagen.

Si imagen no comienza con un componente de nombre de registro, se agregará localhost al nombre. Si imagen no se proporciona, los valores para los valores de REPOSITORY y TAG de la imagen creada se establecerán en <none>.

OPCIONES

--author, -a=autor

Establecer el autor de la imagen confirmada.

--change, -c=instrucción

Aplicar las siguientes posibles instrucciones a la imagen creada:

  • CMD
  • ENTRYPOINT
  • ENV
  • EXPOSE
  • LABEL
  • ONBUILD
  • STOPSIGNAL
  • USER
  • VOLUME
  • WORKDIR

Se puede establecer varias veces.

--config=ArchivoBlobConfig

Fusionar la configuración del contenedor del archivo especificado en la configuración de la imagen mientras se confirma. El contenido del archivo debe ser una versión codificada en JSON de una estructura Schema2Config, que se define en https://github.com/containers/image/blob/v5.29.0/manifest/docker_schema2.go#L67.

--format, -f=oci | docker

Establecer el formato del manifiesto y metadatos de la imagen. Los formatos actualmente compatibles son oci y docker.
El valor predeterminado es oci.

--iidfile=ArchivoIDImagen

Escribir el ID de la imagen en el archivo.

--include-volumes

Incluir en la imagen confirmada cualquier volumen agregado al contenedor mediante las opciones --volume o --mount a los comandos podman create y podman run.
El valor predeterminado es false.

--message, -m=mensaje

Establecer el mensaje de confirmación para la imagen confirmada.
IMPORTANTE: El campo de mensaje no es compatible con el formato oci.

--pause, -p

Pausar el contenedor al crear una imagen.
El valor predeterminado es false.

--quiet, -q

Suprimir la salida.
El valor predeterminado es false.

--squash, -s

Comprimir las capas recién construidas en una sola capa nueva.
El valor predeterminado es false.

EJEMPLOS

Crear una imagen a partir de un contenedor con punto de entrada y etiqueta:

$ podman commit --change CMD=/bin/bash --change ENTRYPOINT=/bin/sh --change "LABEL blue=image" reverent_golick image-committed
Getting image source signatures
Copying blob sha256:b41deda5a2feb1f03a5c1bb38c598cbc12c9ccd675f438edc6acd815f7585b86
 25.80 MB / 25.80 MB [======================================================] 0s
Copying config sha256:c16a6d30f3782288ec4e7521c754acc29d37155629cb39149756f486dae2d4cd
 448 B / 448 B [============================================================] 0s
Writing manifest to image destination
Storing signatures
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear una imagen a partir de un contenedor con mensaje de confirmación:

$ podman commit -q --message "committing container to image"
reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear una imagen a partir de un contenedor con autor:

$ podman commit -q --author "firstName lastName" reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Pausar el contenedor en ejecución mientras se crea la imagen:

$ podman commit -q --pause=true containerID image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear una imagen a partir de un contenedor con etiqueta de imagen predeterminada:

$ podman commit containerID
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Crear una imagen a partir de un contenedor con las capacidades predeterminadas requeridas:

$ podman commit -q --change LABEL=io.containers.capabilities=setuid,setgid epic_nobel privimage
400d31a3f36dca751435e80a0e16da4859beb51ff84670ce6bdc5edb30b94066
