NOMBRE

postdrop - Utilidad de publicación de correo de Postfix

SINOPSIS

postdrop [-rv] [-c directorio_config]

DESCRIPCIÓN


El comando postdrop(1) crea un archivo en el directorio maildrop y copia su entrada estándar al archivo.

Opciones:

-c directorio_config
El archivo de configuración main.cf se encuentra en el directorio especificado en lugar del directorio de configuración predeterminado. Vea también la configuración del entorno MAIL_CONFIG a continuación.
-r
Utiliza un protocolo interno de Postfix para leer el mensaje de la entrada estándar y para informar sobre el estado en la salida estándar. Este es actualmente el único método soportado.
-v
Habilita el registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado. A partir de Postfix 2.3, esta opción solo está disponible para el superusuario.

SEGURIDAD

El comando está diseñado para ejecutarse con privilegios de grupo establecidos, de modo que pueda escribir en el directorio de la cola maildrop y para que pueda conectarse a los procesos demonio de Postfix.

DIAGNÓSTICO


Errores fatales: entrada mal formada, error de E/S, falta de memoria. Los problemas se registran en syslogd(8) o postlogd(8) y en el flujo de error estándar. Cuando la entrada está incompleta, o cuando el proceso recibe una señal HUP, INT, QUIT o TERM, el archivo de cola se elimina.

ENTORNO

MAIL_CONFIG
Directorio con el archivo main.cf. Para evitar la explotación de los privilegios de grupo establecidos, solo se permite un directorio no estándar si:
  • El nombre está listado en el archivo estándar main.cf con el parámetro de configuración alternate_config_directories.
  • El comando es invocado por el superusuario.

PARÁMETROS DE CONFIGURACIÓN

Los siguientes parámetros de main.cf son especialmente relevantes para este programa. El texto a continuación proporciona solo un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

alternate_config_directories (vacío)
Una lista de directorios de configuración de Postfix no predeterminados que pueden especificarse con "-c directorio_config" en la línea de comandos (en el caso de sendmail(1), con la opción "-C"), o a través del parámetro del entorno MAIL_CONFIG.
config_directory (ver la salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
import_environment (ver la salida de 'postconf -d')
La lista de variables de entorno que un proceso privilegiado de Postfix importará de un proceso padre que no sea de Postfix, o anulaciones de entorno nombre=valor.
queue_directory (ver la salida de 'postconf -d')
La ubicación del directorio de cola de nivel superior de Postfix.
syslog_facility (mail)
La instalación de syslog del registro de Postfix.
syslog_name (ver la salida de 'postconf -d')
Un prefijo que se antepone al nombre del proceso en los registros de syslog, de modo que, por ejemplo, "smtpd" se convierte en "prefijo/smtpd".
trigger_timeout (10s)
El límite de tiempo para enviar un disparador a un demonio de Postfix (por ejemplo, el demonio pickup(8) o qmgr(8)).

Disponible en Postfix versión 2.2 y posteriores:

authorized_submit_users (estático:cualquiera)
Lista de usuarios autorizados para enviar correo con el comando sendmail(1) (y con el comando auxiliar privilegiado postdrop(1)).

Disponible en Postfix versión 3.6 y posteriores:

local_login_sender_maps (estático:*)
Una lista de tablas de búsqueda que se buscan por el nombre de inicio de sesión de UNIX, y que devuelven una lista de patrones de remitente de sobre permitidos separados por espacio o coma.
empty_address_local_login_sender_maps_lookup_key (<>)
La clave de búsqueda que se utilizará en las tablas local_login_sender_maps, en lugar de la dirección de remitente nula.
recipient_delimiter (vacío)
El conjunto de caracteres que pueden separar un nombre de parte local de dirección de correo electrónico, un nombre de usuario o el nombre de un archivo .forward de su extensión.
