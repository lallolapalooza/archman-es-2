NOMBRE

podman-network-connect - Conecta un contenedor a una red

SINOPSIS

podman network connect [opciones] red contenedor

DESCRIPCIÓN

Conecta un contenedor a una red. Un contenedor puede ser conectado a una red por nombre o por ID. Una vez conectado, el contenedor puede comunicarse con otros contenedores en la misma red.

OPCIONES

--alias=nombre

Añade un alias con ámbito de red para el contenedor. Si la red tiene DNS activado (podman network inspect -f {{.DNSEnabled}} <NOMBRE>), estos alias pueden usarse para la resolución de nombres en la red dada. Se pueden especificar múltiples opciones --alias. NOTA: Al usar CNI, un contenedor solo tiene acceso a alias en la primera red a la que se une. Esta limitación no existe con netavark/aardvark-dns.

--ip=dirección

Establece una dirección IP estática para este contenedor en esta red.

--ip6=dirección

Establece una dirección IPv6 estática para este contenedor en esta red.

--mac-address=dirección

Establece una dirección MAC estática para este contenedor en esta red.

EJEMPLOS

Conectar el contenedor especificado a una red nombrada:

podman network connect test web

Conectar el contenedor especificado a una red nombrada con dos alias:

podman network connect --alias web1 --alias web2 test web

Conectar el contenedor especificado a una red nombrada con una IP estática:

podman network connect --ip 10.89.1.13 test web

Conectar el contenedor especificado a una red nombrada con una dirección MAC estática:

podman network connect --mac-address 92:d0:c6:0a:29:33 test web

VER TAMBIÉN

podman(1), podman-network(1), podman-network-inspect(1), podman-network-disconnect(1)
