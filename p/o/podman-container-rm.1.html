NOMBRE

podman-rm - Eliminar uno o más contenedores

SINOPSIS

podman rm [opciones] contenedor

podman container rm [opciones] contenedor

DESCRIPCIÓN

podman rm elimina uno o más contenedores del host. Se puede utilizar el nombre o ID del contenedor. Esto no elimina imágenes. Los contenedores en ejecución o inutilizables no se eliminan sin la opción -f.

OPCIONES

--all, -a

Eliminar todos los contenedores. Se puede usar en conjunción con -f también.

--cidfile=archivo

Leer el ID del contenedor del archivo especificado y eliminar el contenedor. Se puede especificar varias veces.

El comando no falla cuando el archivo no existe y el usuario especificó --ignore.

--depend

Eliminar el contenedor seleccionado y eliminar recursivamente todos los contenedores que dependen de él.

--filter=filtro

Filtrar qué contenedores eliminar. Se pueden dar múltiples filtros con múltiples usos de la bandera --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta expresiones regulares)
name [Nombre] Nombre del contenedor (acepta expresiones regulares)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizada para crear el contenedor
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados después de este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [FechaHora] Contenedores creados antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--force, -f

Forzar la eliminación de contenedores en ejecución y en pausa. Forzar la eliminación de un contenedor también elimina contenedores del almacenamiento de contenedores, incluso si el contenedor no es conocido por Podman. Por ejemplo, contenedores creados por diferentes motores de contenedores como Buildah. Además, forzar se puede usar para eliminar contenedores inutilizables, por ejemplo, contenedores cuyo runtime OCI se ha vuelto inaccesible.

--ignore, -i

Ignorar errores cuando los contenedores especificados no están en el almacén de contenedores. Un usuario podría haber decidido eliminar manualmente un contenedor, lo que lleva a un fallo durante la directiva ExecStop de un servicio systemd que hace referencia a ese contenedor.

Ignorar adicionalmente cuando el --cidfile especificado no existe, ya que puede haber sido eliminado junto con el contenedor.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utilice el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--time, -t=segundos

Segundos para esperar antes de detener forzosamente el contenedor. Utilice -1 para esperar indefinidamente.

La opción --force debe especificarse para usar la opción --time.

--volumes, -v

Eliminar volúmenes anónimos asociados con el contenedor. Esto no incluye volúmenes nombrados creados con podman volume create, o la opción --volume de podman run y podman create.

EJEMPLOS

Eliminar contenedor con un nombre dado:

$ podman rm miwebserver

Eliminar contenedor con un nombre dado y todos los contenedores que dependen de él:

$ podman rm --depend miwebserver

Eliminar múltiples contenedores con nombres o IDs dados:

$ podman rm miwebserver miflaserver 860a4b23

Eliminar múltiples contenedores con IDs leídos de archivos:

$ podman rm --cidfile ./cidfile-1 --cidfile /home/user/cidfile-2

Forzar la eliminación de contenedor con un ID dado:

$ podman rm -f 860a4b23

Eliminar todos los contenedores independientemente de su estado de ejecución:

$ podman rm -f -a

Forzar la eliminación del último contenedor creado. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

$ podman rm -f --latest

NOMBRE

podman-container-rm - Eliminar uno o más contenedores

SINOPSIS

podman container rm [OPTIONS] CONTAINER [CONTAINER ...]

DESCRIPCIÓN

Elimina uno o más contenedores. El contenedor debe estar detenido para poder ser eliminado. Si el contenedor está en ejecución, puedes usar la opción -f o --force para forzar la eliminación del contenedor.

OPCIONES

-f, --force : Forzar la eliminación de un contenedor en ejecución.

-v, --volumes : Eliminar los volúmenes asociados con el contenedor.

EJEMPLOS

Eliminar un contenedor llamado mycontainer:

$ podman container rm mycontainer

Eliminar varios contenedores:

$ podman container rm mycontainer container2 container3

Eliminar un contenedor en ejecución:

$ podman container rm -f mycontainer

Eliminar un contenedor y sus volúmenes:

$ podman container rm -v mycontainer

Estado de salida

0 éxito, >0 error.
