NOMBRE

podman-attach - Conectarse a un contenedor en ejecución

SINOPSIS

podman attach [opciones] contenedor

podman container attach [opciones] contenedor

DESCRIPCIÓN

podman attach se conecta a un contenedor en ejecución utilizando el nombre o ID del contenedor, para ver su salida continua o para controlarlo interactivamente.
El contenedor puede ser desconectado (y dejarlo ejecutándose) utilizando una secuencia de teclas configurable. La secuencia por defecto es ctrl-p,ctrl-q. Configura la secuencia de teclas utilizando la OPCIÓN --detach-keys, o especificándola en el archivo containers.conf: consulta containers.conf(5) para más información.

OPCIONES

--detach-keys=secuencia

Especifica la secuencia de teclas para desconectar un contenedor. El formato es un solo carácter [a-Z] o uno o más caracteres ctrl-<valor> donde <valor> es uno de: a-z, @, ^, [, , o _. Especificar "" deshabilita esta función. El valor por defecto es ctrl-p,ctrl-q.

Esta opción también se puede configurar en el archivo containers.conf(5).

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--no-stdin

No adjuntar STDIN. El valor por defecto es false.

--sig-proxy

Propaga las señales recibidas al proceso del contenedor. SIGCHLD, SIGURG, SIGSTOP y SIGKILL no se propagan.

El valor por defecto es true.

EJEMPLOS

Conectarse a un contenedor llamado "foobar".

$ podman attach foobar

Conectarse al último contenedor creado. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

$ podman attach --latest

Conectarse a un contenedor que comience con el ID "1234".

$ podman attach 1234

Conectarse a un contenedor sin adjuntar STDIN.

$ podman attach --no-stdin foobar
