posix_openpt(3) Manual de Funciones de Biblioteca posix_openpt(3)

NOMBRE

posix_openpt - abrir un dispositivo de pseudoterminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
#include <fcntl.h>
int posix_openpt(int flags);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

posix_openpt():

    _XOPEN_SOURCE >= 600

DESCRIPCIÓN

La función posix_openpt() abre un dispositivo maestro de pseudoterminal no utilizado, devolviendo un descriptor de archivo que puede ser utilizado para referirse a ese dispositivo.

El argumento flags es una máscara de bits que une cero o más de las siguientes banderas:

O_RDWR
Abre el dispositivo tanto para lectura como para escritura. Es habitual especificar esta bandera.
O_NOCTTY
No convierta este dispositivo en la terminal de control para el proceso.

VALOR DE RETORNO

En caso de éxito, posix_openpt() devuelve un descriptor de archivo (un entero no negativo) que es el descriptor de archivo no utilizado con el número más bajo. En caso de error, devuelve -1 y se establece errno para indicar el error.

ERRORES

Ver open(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
posix_openpt () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.2.1. POSIX.1-2001.

Es parte del soporte de pseudoterminales de UNIX 98 (ver pts(4)).

NOTAS

Algunas implementaciones antiguas de UNIX que soportan pseudoterminales System V (también conocidas como UNIX 98) no tienen esta función, pero puede implementarse fácilmente abriendo el dispositivo multiplexor de pseudoterminales:


int
posix_openpt(int flags)
{
    return open("/dev/ptmx", flags);
}

Llamar a posix_openpt() crea un nombre de ruta para el dispositivo esclavo de pseudoterminal correspondiente. El nombre de ruta del dispositivo esclavo puede obtenerse utilizando ptsname(3). El nombre de ruta del dispositivo esclavo solo existe mientras el dispositivo maestro está abierto.

VER TAMBIÉN

open(2), getpt(3), grantpt(3), ptsname(3), unlockpt(3), pts(4), pty(7)
