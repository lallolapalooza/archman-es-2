NOMBRE

podman-network-ls - Muestra un resumen de las redes

SINOPSIS

podman network ls [opciones]

DESCRIPCIÓN

Muestra una lista de las redes de podman existentes.

OPCIONES

--filter, -f=filtro=valor

Proporciona valores de filtro.

El formato del argumento filtros es clave=valor. Si hay más de un filtro, pasa múltiples OPCIONES: --filter foo=bar --filter bif=baz.

Filtros soportados:

Filtro Descripción
driver Filtra por tipo de driver.
id Filtra por ID de red completo o parcial.
label Filtra por redes con (o sin, en el caso de que se use label!=[...] ) las etiquetas especificadas.
name Filtra por nombre de red (acepta regex).
until Filtra por redes creadas antes de la marca de tiempo dada.
dangling Filtra por redes sin contenedores adjuntos.

El filtro driver acepta los valores: bridge, macvlan, ipvlan.

El filtro label acepta dos formatos. Uno es label=clave o label=clave=valor, que muestra imágenes con las etiquetas especificadas. El otro formato es label!=clave o label!=clave=valor, que muestra imágenes sin las etiquetas especificadas.

El filtro until puede ser marcas de tiempo Unix, marcas de tiempo formateadas como fecha, o cadenas de duración de Go (por ejemplo, 10m, 1h30m) calculadas en relación con la hora de la máquina.

El filtro dangling acepta los valores true o false.

--format=formato

Cambia el formato de salida predeterminado. Este puede ser de un tipo soportado como 'json' o una plantilla Go. Los marcadores de posición válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Created ... Marca de tiempo cuando se creó la red
.DNSEnabled La red tiene DNS habilitado (booleano)
.Driver Driver de la red
.ID ID de la red
.Internal La red es interna (booleano)
.IPAMOptions ... Opciones IPAM de la red
.IPv6Enabled La red tiene subred IPv6 (booleano)
.Labels Etiquetas de la red
.Name Nombre de la red
.NetworkDNSServers Array de servidores DNS utilizados en esta red
.NetworkInterface Nombre de la interfaz de red en el host
.Options ... Opciones de red
.Routes Lista de rutas estáticas para esta red
.Subnets Lista de subredes en esta red

--no-trunc

No truncar el ID de la red.

--noheading, -n

Omitir los encabezados de tabla de la lista.

--quiet, -q

La opción quiet restringe la salida solo a los nombres de red.

EJEMPLO

Mostrar redes:

$ podman network ls
ID DE RED      NOMBRE         DRIVER
88a7120ee19d  podman       bridge
6dd508dbf8cd  podman6  bridge
8e35c2cd3bf6  podman5  macvlan

Mostrar solo nombres de red:

$ podman network ls -q
podman
podman2
outside
podman9

Mostrar el nombre de la red que soporta el plugin bridge:

$ podman network ls --filter driver=bridge --format {{.Name}}
podman
podman2
podman9

Listar redes con sus subredes:

$ podman network ls --format "{{.Name}}: {{range .Subnets}}{{.Subnet}} {{end}}"
podman: 10.88.0.0/16
podman3: 10.89.30.0/24 fde4:f86f:4aab:e68f::/64
macvlan:
