NOMBRE

podman-system-connection - Gestionar los destinos para los servicios de Podman

SINOPSIS

podman system connection subcomando

DESCRIPCIÓN

Gestiona los destinos para los servicios de Podman.

Se le pedirá al usuario la contraseña de inicio de sesión SSH o la frase secreta del archivo de clave, según sea necesario. El ssh-agent es compatible si está en ejecución.

Podman gestiona la conexión del sistema escribiendo y leyendo el archivo podman-connections.json ubicado en $XDG_CONFIG_HOME/containers o, si la variable de entorno no está establecida, por defecto será $HOME/.config/containers. O bien, la variable de entorno PODMAN_CONNECTIONS_CONF puede establecerse en una ruta de archivo completa que podman utilizará en su lugar. Este archivo es gestionado por los comandos de podman y nunca debe ser editado directamente por los usuarios. Para configurar manualmente las conexiones, utilice service_destinations en containers.conf.

Si la columna ReadWrite en la salida de podman system connection list está establecida en true, la conexión se almacena en el archivo podman-connections.json; de lo contrario, se almacena en containers.conf y, por lo tanto, no se puede editar con los comandos podman system connection.

COMANDOS

Comando Página del manual Descripción
add podman-system-connection-add(1) Registrar destino para el servicio Podman
default podman-system-connection-default(1) Establecer destino con nombre como predeterminado para el servicio Podman
list podman-system-connection-list(1) Listar el destino para los servicios de Podman
remove podman-system-connection-remove(1) Eliminar destino con nombre
rename podman-system-connection-rename(1) Renombrar el destino para el servicio Podman

EJEMPLO

Listar conexiones del sistema:

$ podman system connection list
Nombre URI                                           Identidad	      Predeterminado  LecturaEscritura
devl ssh://root@example.com/run/podman/podman.sock ~/.ssh/id_rsa  true     true
