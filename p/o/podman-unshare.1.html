NOMBRE

podman-unshare - Ejecuta un comando dentro de un espacio de nombres de usuario modificado

SINOPSIS

podman unshare [opciones] [comando]

DESCRIPCIÓN

Lanza un proceso (por defecto, $SHELL) en un nuevo espacio de nombres de usuario. El espacio de nombres de usuario se configura de modo que el UID y el GID principal del usuario que invoca aparezcan como UID 0 y GID 0, respectivamente. Cualquier rango que coincida con ese usuario y grupo en /etc/subuid y /etc/subgid también se mapea como ellos mismos con la ayuda de los ayudantes newuidmap(1) y newgidmap(1).

podman unshare es útil para solucionar problemas de operaciones no privilegiadas y para limpiar manualmente el almacenamiento y otros datos relacionados con imágenes y contenedores.

También es útil usar el comando podman mount. Si un usuario no privilegiado quiere montar y trabajar con un contenedor, entonces necesita ejecutar podman unshare. La ejecución de podman mount falla para usuarios no privilegiados a menos que el usuario se esté ejecutando dentro de una sesión de podman unshare.

La sesión de unshare define dos variables de entorno:

  • CONTAINERS_GRAPHROOT: la ruta a los datos persistentes del contenedor.
  • CONTAINERS_RUNROOT: la ruta a los datos volátiles del contenedor.

IMPORTANTE: Este comando no está disponible con el cliente remoto de Podman.

OPCIONES

--help, -h

Imprime la declaración de uso

--rootless-netns

Se une al espacio de nombres de red sin privilegios utilizado para la red netavark. Se puede utilizar para conectarse a un contenedor sin privilegios a través de la dirección IP (red de puentes). Esto de lo contrario no es posible desde el espacio de nombres de red del host.

Códigos de Salida

El código de salida de podman unshare proporciona información sobre por qué el contenedor no se pudo ejecutar o por qué salió. Cuando los comandos podman unshare salen con un código distinto de cero, los códigos de salida siguen el estándar chroot, ver abajo:

125 El error es con el propio podman

$ podman unshare --foo; echo $?
Error: unknown flag: --foo
125

126 Ejecutando un comando contenido y el comando no se puede invocar

$ podman unshare /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 Ejecutando un comando contenido y el comando no se puede encontrar

$ podman unshare foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

Código de salida código de salida del comando contenido

$ podman unshare /bin/sh -c 'exit 3'; echo $?
3

EJEMPLO

Ejecuta el comando especificado en el espacio de nombres de usuario sin privilegios:

$ podman unshare id
uid=0(root) gid=0(root) groups=0(root),65534(nobody)

Muestra los mapeos del espacio de nombres de usuario para contenedores sin privilegios:

$ podman unshare cat /proc/self/uid_map /proc/self/gid_map
         0       1000          1
         1      10000      65536
         0       1000          1
         1      10000      65536
