NOMBRE

podman-port - Listar mapeos de puertos de un contenedor

SINOPSIS

podman port [opciones] contenedor [puerto-privado[/proto]]

podman container port [opciones] contenedor [puerto-privado[/proto]]

DESCRIPCIÓN

Lista los mapeos de puertos para el contenedor o busca el puerto público al que se aplica NAT el puerto-privado.

OPCIONES

--all, -a

Listar todos los mapeos de puertos conocidos para contenedores en ejecución; al usar esta opción, no se pueden usar nombres de contenedor o filtros de puertos/protocolos privados.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

EJEMPLO

Listar todos los mapeos de puertos:

# podman port -a
b4d2f05432e482e017b1a4b2eae15fa7b4f6fb7e9f65c1bde46294fdef285906
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

Listar los mapeos de puertos para un contenedor específico:

# podman port b4d2f054
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

Listar los mapeos de puertos especificados para un contenedor específico:

# podman port b4d2f054 80
 0.0.0.0:44327
#

Listar los mapeos de puertos para un contenedor específico para el puerto 80 y el protocolo tcp:

# podman port b4d2f054 80/tcp
0.0.0.0:44327
#

podman(1), podman-inspect(1)
