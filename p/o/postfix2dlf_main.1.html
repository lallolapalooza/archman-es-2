POSTFIX2DLF_MAIN.IN(1) Documentación de Lire de LogReport POSTFIX2DLF_MAIN.IN(1)

NOMBRE

postfix2dlf_main - convierte la salida de postfix2dlf_pre a dlf de correo electrónico

SINOPSIS

postfix2dlf_main archivo_volcado

DESCRIPCIÓN

postfix2dlf_main espera un archivo de registro postfix preprocesado, tal como lo escribe postfix2dlf_pre(1) en STDIN. Imprime un archivo DLF de correo electrónico de Lire en stdout, utilizando una base de datos Berkeley en archivo_volcado, que contiene un mapeo de nombre_host-id_cola a número_de_líneas_con_este_id.

DESARROLLADORES

Las estructuras de datos son las mismas que las de sendmail2dlf.

%msg almacena toda la información del registro que se está procesando actualmente. En sendmail2dlf, esta tabla hash está indexada por ids_dlf:

$dlfid = $log->{'hostname'} . $log->{'queueid'}

. En postfix2dlf usamos solo el id_cola, por ahora.

Valores escalares:

$msg{$dlfid} = {
  logrelay        => ...,
  queueid         => ...,
  time            => ...,
  nrcpts          => ...,
  from_user       => ...,
  from_domain     => ...,
  from_relay_host => ...,
  from_relay_ip   => ...,
  size            => ...,
  msgid           => ...,
};

Además:

$del = $msg{$dlfid}->{deliveries}{$to};

$to es una dirección de correo electrónico tal como la devuelve &Lire::Email::sanitize_tos .

$del->{to_user}   = ....;
$del->{to_domain} = ....;

Otras claves de $del con valores escalares:

to_relay_host
to_relay_ip
delay
xdelay
stat
xstat

.

La referencia de tabla hash $msg{$dlfid} a menudo se asigna a `$cur'.

EJEMPLOS

postfix2dlf_main rara vez se usa de forma independiente: es llamado por postfix2dlf(1). Consulte la página del manual de postfix2dlf para ver ejemplos e información de uso.

VER TAMBIÉN

postfix2dlf(1), postfix2dlf_pre(1), sendmail2dlf(1)
