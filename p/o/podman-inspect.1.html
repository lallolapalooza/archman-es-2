podman-inspect(1)

podman-inspect(1) Manual de Comandos Generales podman-inspect(1)

NOMBRE

podman-inspect - Muestra la configuración de artefactos, contenedores, imágenes, volúmenes, redes o pods

SINOPSIS

podman inspect [opciones] nombre [...]

DESCRIPCIÓN

Esto muestra información de bajo nivel sobre artefactos, contenedores e imágenes identificados por nombre o ID. Por defecto, esto renderiza todos los resultados en un array JSON. Si el tipo de inspección es 'all', el orden de inspección es: contenedores, imágenes, volúmenes, redes, pods, artefactos.
Si un contenedor tiene el mismo nombre que una imagen, se devuelve el JSON del contenedor, y así sucesivamente.
Si se especifica un formato, la plantilla dada se ejecuta para cada resultado.

Para más opciones de inspección, consulta también podman-artifact-inspect(1), podman-container-inspect(1), podman-image-inspect(1), podman-network-inspect(1), podman-pod-inspect(1) y podman-volume-inspect(1).

OPCIONES

--format, -f=formato

Formatea la salida utilizando la plantilla Go dada. Las claves del JSON devuelto se pueden usar como valores para la bandera --format (ver ejemplos a continuación).

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--size, -s

Además de la salida normal, muestra el tamaño total del archivo si el tipo es un contenedor.

--type, -t=tipo

Devuelve JSON para el tipo especificado. El tipo puede ser 'artifact', 'container', 'image', 'volume', 'network', 'pod' o 'all' (por defecto: all) (Solo tiene significado cuando se invoca como podman inspect)

Inspecciona la imagen especificada con el especificador de formato ImageName:

# podman inspect a04 --format "{{.ImageName}}"
fedora

Inspecciona la imagen especificada para el especificador de formato GraphDriver:

# podman inspect a04 --format "{{.GraphDriver.Name}}"
overlay

Inspecciona la imagen especificada para su especificador de formato Size:

# podman image inspect --format "size: {{.Size}}" alpine
size:   4405240

Inspecciona el último contenedor creado para el especificador de formato EffectiveCaps. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)):

podman container inspect --latest --format {{.EffectiveCaps}}
[CAP_CHOWN CAP_DAC_OVERRIDE CAP_FSETID CAP_FOWNER CAP_SETGID CAP_SETUID CAP_SETFCAP CAP_SETPCAP CAP_NET_BIND_SERVICE CAP_KILL]

Inspecciona el pod especificado para el especificador de formato Name:

# podman inspect myPod --type pod --format "{{.Name}}"
myPod

Inspecciona el volumen especificado para el especificador de formato Name:

# podman inspect myVolume --type volume --format "{{.Name}}"
myVolume

Inspecciona la red especificada para el especificador de formato Name:

# podman inspect nyNetwork --type network --format "{{.name}}"
myNetwork

Inspecciona el artefacto especificado:

# podman inspect quay.io/myimage/myartifact:latest --type artifact
{
