NOMBRE

podman-cp - Copiar archivos/carpetas entre un contenedor y el sistema de archivos local

SINOPSIS

podman cp [opciones] [contenedor:]ruta_origen [contenedor:]ruta_destino

podman container cp [opciones] [contenedor:]ruta_origen [contenedor:]ruta_destino

DESCRIPCIÓN

podman cp permite copiar el contenido de ruta_origen a ruta_destino. Los archivos pueden copiarse desde un contenedor a la máquina local y viceversa, o entre dos contenedores. Si se especifica - para RUTA_ORIGEN o RUTA_DESTINO, también se puede transmitir un archivo tar desde STDIN o a STDOUT.

Los contenedores pueden estar en ejecución o detenidos, y la ruta_origen o ruta_destino pueden ser un archivo o un directorio.

*IMPORTANTE: El comando podman cp asume que las rutas del contenedor son relativas al directorio raíz del contenedor (/), lo que significa que proporcionar la barra inclinada inicial es opcional y, por lo tanto, considera compassionate_darwin:/tmp/foo/myfile.txt y compassionate_darwin:tmp/foo/myfile.txt como idénticos.*

Las rutas de la máquina local pueden ser un valor absoluto o relativo. El comando interpreta las rutas relativas de la máquina local como relativas al directorio de trabajo actual donde se ejecuta podman cp.

Asumiendo un separador de ruta de /, un primer argumento de ruta_origen y un segundo argumento de ruta_destino, el comportamiento es el siguiente:

ruta_origen especifica un archivo:
- ruta_destino no existe
- el archivo se guarda en un archivo creado en ruta_destino (tenga en cuenta que el directorio padre debe existir).
- ruta_destino existe y es un archivo
- el destino se sobrescribe con el contenido del archivo de origen.
- ruta_destino existe y es un directorio
- el archivo se copia dentro de este directorio usando el nombre base de ruta_origen.

ruta_origen especifica un directorio:
- ruta_destino no existe
- ruta_destino se crea como un directorio y el contenido del directorio de origen se copia dentro de este directorio.
- ruta_destino existe y es un archivo
- Condición de error: no se puede copiar un directorio a un archivo.
- ruta_destino existe y es un directorio
- ruta_origen termina en /
- el directorio de origen se copia dentro de este directorio.
- ruta_origen termina en /. (es decir, barra seguida de punto)
- el contenido del directorio de origen se copia dentro de este directorio.

El comando requiere que ruta_origen y ruta_destino existan de acuerdo con las reglas anteriores.

Si ruta_origen es local y es un enlace simbólico, el destino del enlace simbólico se copia por defecto.

Se utiliza dos puntos ( : ) como delimitador entre un contenedor y su ruta; también se puede utilizar al especificar rutas a una ruta_origen o ruta_destino en una máquina local, por ejemplo, archivo:nombre.txt.

*IMPORTANTE: al usar dos puntos ( : ) en una ruta de máquina local, se debe ser explícito con una ruta relativa o absoluta, por ejemplo: /ruta/al/archivo:nombre.txt o ./archivo:nombre.txt*

Usar - como ruta_origen transmite el contenido de STDIN como un archivo tar. El comando extrae el contenido del tar en el RUTA_DESTINO en el contenedor. En este caso, ruta_destino debe especificar un directorio. Usar - como ruta_destino transmite el contenido del recurso (puede ser un directorio) como un archivo tar a STDOUT.

Tenga en cuenta que podman cp ignora los errores de permiso al copiar desde un contenedor sin root en ejecución. Los dispositivos TTY dentro de un contenedor sin root son propiedad del usuario root del host y, por lo tanto, no se pueden leer dentro del espacio de nombres de usuario del contenedor.

Además, tenga en cuenta que podman cp no admite patrones glob (por ejemplo, cp dir/*.txt). Para copiar varios archivos del host al contenedor, use xargs(1) o find(1) (o herramientas similares para encadenar comandos) junto con podman cp. Para copiar varios archivos del contenedor al host, utilice podman mount CONTENEDOR y opere en el punto de montaje devuelto en su lugar (ver ALTERNATIVAS a continuación).

OPCIONES

--archive, -a

Modo archivo (copiar toda la información UID/GID). Cuando se establece en true, los archivos copiados a un contenedor tienen su propiedad cambiada al UID/GID principal del contenedor. Cuando se establece en false, se mantienen los UID/GID de las fuentes del archivo en lugar de cambiarlos al UID/GID principal del contenedor de destino. El valor predeterminado es true.

--overwrite

Permite sobrescribir directorios con elementos que no son directorios y viceversa. Por defecto, podman cp genera un error al intentar sobrescribir, por ejemplo, un archivo regular con un directorio.

ALTERNATIVAS

Podman tiene capacidades mucho más potentes que solo podman cp para lograr la copia de archivos entre el host y los contenedores.

El uso de los comandos estándar podman-mount(1) y podman-unmount(1) aprovecha toda la cadena de herramientas de Linux, en lugar de solo cp.

Copiar contenido fuera de un contenedor o dentro de un contenedor se puede lograr con unos pocos comandos simples. Por ejemplo:

Para copiar el directorio /etc/foobar fuera de un contenedor y colocarlo en /tmp en el host, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
cp -R ${mnt}/etc/foobar /tmp
podman umount CONTENEDORID

Para descomprimir un archivo tar dentro de un contenedor, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
tar xf content.tgz -C ${mnt}
podman umount CONTENEDORID

Para instalar un paquete en un contenedor que no tiene dnf instalado, se pueden ejecutar los siguientes comandos:

mnt=$(podman mount CONTENEDORID)
dnf install --installroot=${mnt} httpd
chroot ${mnt} rm -rf /var/log/dnf /var/cache/dnf
podman umount CONTENEDORID

Al usar podman mount y podman unmount, se pueden usar todas las herramientas estándar de Linux para mover archivos dentro y fuera de los contenedores, no solo el comando cp.

EJEMPLOS

Copiar un archivo del host a un contenedor:

podman cp /myapp/app.conf containerID:/myapp/app.conf

Copiar un archivo de un contenedor a un directorio en otro contenedor:

podman cp containerID1:/myfile.txt containerID2:/tmp

Copiar un directorio en un contenedor a un directorio en el host:

podman cp containerID:/myapp/ /myapp/

Copiar el contenido de un directorio en un contenedor a un directorio en el host:

podman cp containerID:/home/myuser/. /home/myuser/

Copiar un directorio en un contenedor a un directorio en otro:

podman cp containerA:/myapp containerB:/newapp

Transmitir un archivo tar desde STDIN a un contenedor:

podman cp - containerID:/myfiles.tar.gz < myfiles.tar.gz

VER TAMBIÉN

podman(1), podman-mount(1), podman-unmount(1)

DESCRIPCIÓN

Copiar archivos y directorios entre un contenedor y el sistema de archivos local.

El comando podman-container-cp copia archivos y directorios entre un contenedor y el sistema de archivos local. La sintaxis es similar a la del comando cp.

La ruta de origen o destino puede ser una ruta en el sistema de archivos local o una ruta dentro del contenedor. Las rutas dentro del contenedor deben prefijarse con el nombre del contenedor, seguido de dos puntos (:), y luego la ruta absoluta dentro del contenedor.

Por ejemplo, para copiar el archivo /tmp/foo.txt del host al contenedor mycontainer en /var/lib/foo.txt, usaría:

podman-container-cp /tmp/foo.txt mycontainer:/var/lib/foo.txt

Para copiar el archivo /var/lib/bar.txt del contenedor mycontainer al host en /tmp/bar.txt, usaría:

podman-container-cp mycontainer:/var/lib/bar.txt /tmp/bar.txt

OPCIONES

--archive, -a

Modo de archivo. Copia recursivamente, preservando los permisos, propiedad y marcas de tiempo.

--follow-link, -L

Siempre sigue los enlaces simbólicos; ambos argumentos de origen y destino son enlaces simbólicos.

ALTERNATIVAS

podman cp

EJEMPLOS

Copiar un archivo del host al contenedor:

$ podman container cp mycontainer:/etc/passwd ./passwd.host

Copiar un archivo del contenedor al host:

$ podman container cp ./my-app.conf mycontainer:/etc/app/my-app.conf

Copiar un directorio del host al contenedor:

$ podman container cp -a ./my-dir mycontainer:/opt/

Copiar un directorio del contenedor al host:

$ podman container cp -a mycontainer:/var/log ./logs.host

podman(1), podman-cp(1)
