podman-ps(1) Manual de comandos generales podman-ps(1)

NOMBRE

podman-ps - Imprime información sobre contenedores

SINOPSIS

podman ps [opciones]

podman container ps [opciones]

podman container list [opciones]

podman container ls [opciones]

DESCRIPCIÓN

podman ps lista los contenedores en ejecución en el sistema. Utilice la opción --all para ver toda la información de los contenedores. Por defecto, lista:

  • ID del contenedor
  • el nombre de la imagen que utiliza el contenedor
  • el COMANDO que ejecuta el contenedor
  • la hora de creación del contenedor
  • el estado del contenedor
  • las asignaciones de puertos que utiliza el contenedor
  • nombres alternativos para el contenedor

OPCIONES

--all, -a

Muestra todos los contenedores, el valor predeterminado es solo los contenedores en ejecución.

Nota: Podman comparte el almacenamiento de contenedores con otras herramientas como Buildah y CRI-O. En algunos casos, estos contenedores externos también pueden existir en el mismo almacenamiento. Utilice la opción --external para ver estos contenedores externos. Los contenedores externos muestran el estado de 'almacenamiento'.

--external

Muestra contenedores externos que no son controlados por Podman pero que se almacenan en el almacenamiento de contenedores. Estos contenedores externos generalmente se crean a través de otra tecnología de contenedor como Buildah o CRI-O y pueden depender de las mismas imágenes de contenedor que Podman también está utilizando. Los contenedores externos se denominan con 'buildah' o 'storage' en las columnas de COMANDO y ESTADO de la salida de ps.

--filter, -f

Filtra qué contenedores se muestran en la salida. Se pueden dar múltiples filtros utilizando múltiples usos del indicador --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
label! [Clave] o [Clave=Valor] Etiqueta NO asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizado para crear el contenedor (acepta regex)
before [ID] o [Nombre] Contenedores creados antes de este contenedor
since [ID] o [Nombre] Contenedores creados desde este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [DateTime] contenedor creado antes de la duración o tiempo dado.
command [Comando] el comando que ejecuta el contenedor, solo se toma argv[0]

--format=formato

Imprime contenedores bonitos en JSON o usando una plantilla de Go

Los marcadores de posición válidos para la plantilla de Go se enumeran a continuación:

Marcador Descripción
.AutoRemove Si es verdadero, los contenedores se eliminan al salir
.CIDFile Archivo de ID del contenedor
.Command Comando utilizado entre comillas
.Created ... Tiempo de creación del contenedor, A-M-D H:M:S
.CreatedAt Tiempo de creación del contenedor (igual que el anterior)
.CreatedHuman Tiempo de creación, relativo
.ExitCode Código de salida del contenedor
.Exited "true" si el contenedor ha salido
.ExitedAt Hora (segundos de época) en que salió el contenedor
.ExposedPorts ... Mapa de puertos expuestos en este contenedor
.ID ID del contenedor
.Image Nombre/ID de la imagen
.ImageID ID de la imagen
.IsInfra "true" si es un contenedor infra
.Label cadena Etiqueta especificada del contenedor
.Labels ... Todas las etiquetas asignadas al contenedor
.Mounts Volúmenes montados en el contenedor
.Names Nombre del contenedor
.Networks Muestra todas las redes conectadas al contenedor
.Pid ID de proceso en el sistema anfitrión
.Pod Pod al que está asociado el contenedor (SHA)
.PodName Nombre del pod del contenedor
.Ports Puertos reenviados y expuestos
.Restarts Muestra el número de reinicios del contenedor
.RunningFor Tiempo transcurrido desde que se inició el contenedor
.Size Tamaño del contenedor
.StartedAt Hora (segundos de época) en que se inició el contenedor
.State Descripción amigable del estado del contenedor
.Status Estado del contenedor

--help, -h

Imprime la declaración de uso

--last, -n

Imprime los n últimos contenedores creados (todos los estados)

--latest, -l

Muestra el último contenedor creado (todos los estados) (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--namespace, --ns

Muestra información del espacio de nombres

--no-trunc

No trunca la salida (predeterminado false).

--noheading

Omite los encabezados de la tabla de la lista de contenedores.

--pod, -p

Muestra los pods a los que están asociados los contenedores

--quiet, -q

Imprime solo los IDs numéricos de los contenedores

--size, -s

Muestra el tamaño total del archivo

--sort=created

Ordena por comando, creado, id, imagen, nombres, runningfor, tamaño o estado", Nota: Elegir tamaño ordena por el tamaño de rootFs, no alfabéticamente como el resto de las opciones

--sync

Fuerza una sincronización del estado del contenedor con el tiempo de ejecución OCI. En algunos casos, el estado de un contenedor en el tiempo de ejecución puede dejar de estar sincronizado con el estado de Podman. Esto actualiza el estado de Podman basándose en lo que informa el tiempo de ejecución OCI. Sincronizar a la fuerza es mucho más lento, pero puede resolver problemas de estado inconsistentes.

--watch, -w

Actualiza la salida con los contenedores actuales en un intervalo de segundos.
