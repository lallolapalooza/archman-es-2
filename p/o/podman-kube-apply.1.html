NOMBRE

podman-kube-apply - Aplicar YAML de Kubernetes basado en contenedores, pods o volúmenes a un clúster de Kubernetes

SINOPSIS

podman kube apply [opciones] [contenedor... | pod... | volumen...]

DESCRIPCIÓN

podman kube apply despliega un contenedor, pod o volumen de podman en un clúster de Kubernetes. Utilice la opción --file para desplegar también un archivo YAML de Kubernetes (especificación v1) en un clúster de Kubernetes.

Tenga en cuenta que el archivo YAML de Kubernetes puede ser utilizado para ejecutar el despliegue en Podman a través de podman-play-kube(1).

OPCIONES

--ca-cert-file=archivo certificado ca ruta | inseguro

La ruta al archivo de certificado CA para el clúster de Kubernetes. Normalmente, el kubeconfig contiene los datos del archivo de certificado CA y generate kube lo recoge automáticamente si está disponible en el kubeconfig. Si no hay datos de archivo de certificado CA disponibles, establezca esto en insecure para omitir la verificación del certificado.

--file, -f=ruta archivo yaml kube

Ruta al archivo yaml de kubernetes para desplegar en el clúster de kubernetes. Este archivo puede ser generado usando el comando podman kube generate. La entrada puede ser en forma de archivo yaml o stdin. Para stdin, use --file=-.

--kubeconfig, -k=ruta archivo kubeconfig

Ruta al archivo kubeconfig que se utilizará al desplegar el kube yaml generado en el clúster de Kubernetes. La variable de entorno KUBECONFIG también puede usarse para establecer la ruta del archivo kubeconfig. Nota: Un kubeconfig puede tener múltiples configuraciones de clúster, pero kube generate siempre elige la primera configuración de clúster en el kubeconfig dado.

--ns=namespace

El namespace o proyecto donde desplegar las cargas de trabajo del kube yaml generado en el clúster de Kubernetes.

--service, -s

Se utiliza para crear un servicio para el contenedor o pod correspondiente que se despliega en el clúster. En particular, si el contenedor o pod tiene enlaces de puertos, la especificación del servicio incluye una declaración NodePort para exponer el servicio. Podman asigna un puerto aleatorio en la especificación del servicio que se despliega en el clúster.

EJEMPLOS

Aplicar un volumen y un contenedor de podman al namespace "default" en un clúster de Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig myvol vol-test-1
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods
NAME             READY   STATUS    RESTARTS   AGE
vol-test-1-pod   1/1     Running   0          9m

Aplicar un archivo YAML de Kubernetes al namespace "default" en un clúster de Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig -f vol.yaml
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods
NAME             READY   STATUS    RESTARTS   AGE
vol-test-2-pod   1/1     Running   0          9m

Aplicar un archivo YAML de Kubernetes al namespace "test1" en un clúster de Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig --ns test1 vol-test-3
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods --namespace test1
NAME             READY   STATUS    RESTARTS   AGE
vol-test-3-pod   1/1     Running   0          9m
