POSIX_TRACE_ATTR_GETLOGSIZE(3P) Manual del programador POSIX POSIX_TRACE_ATTR_GETLOGSIZE(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_attr_getlogsize, posix_trace_attr_getmaxdatasize, posix_trace_attr_getmaxsystemeventsize, posix_trace_attr_getmaxusereventsize, posix_trace_attr_getstreamsize, posix_trace_attr_setlogsize, posix_trace_attr_setmaxdatasize, posix_trace_attr_setstreamsize — recuperar y establecer atributos de tamaño de flujo de rastreo (TRACING)

SINOPSIS

#include <sys/types.h>
#include <trace.h>
int posix_trace_attr_getlogsize(const trace_attr_t *restrict attr,
    size_t *restrict logsize);
int posix_trace_attr_getmaxdatasize(const trace_attr_t *restrict attr,
    size_t *restrict maxdatasize);
int posix_trace_attr_getmaxsystemeventsize(
    const trace_attr_t *restrict attr,
    size_t *restrict eventsize);
int posix_trace_attr_getmaxusereventsize(
    const trace_attr_t *restrict attr,
    size_t data_len, size_t *restrict eventsize);
int posix_trace_attr_getstreamsize(const trace_attr_t *restrict attr,
    size_t *restrict streamsize);
int posix_trace_attr_setlogsize(trace_attr_t *attr,
    size_t logsize);
int posix_trace_attr_setmaxdatasize(trace_attr_t *attr,
    size_t maxdatasize);
int posix_trace_attr_setstreamsize(trace_attr_t *attr,
    size_t streamsize);

DESCRIPCIÓN

La función posix_trace_attr_getlogsize() copia el tamaño del registro, en bytes, del atributo log-max-size del objeto de atributos apuntado por el argumento attr a la variable apuntada por el argumento logsize. Este tamaño de registro es el total máximo de bytes que se asignarán para eventos de rastreo del sistema y del usuario en el registro de rastreo. El valor predeterminado para el atributo log-max-size depende de la implementación.

La función posix_trace_attr_setlogsize() establece el tamaño máximo permitido, en bytes, en el atributo log-max-size del objeto de atributos apuntado por el argumento attr, utilizando el valor de tamaño proporcionado por el argumento logsize.

El tamaño del registro de rastreo se utilizará si el atributo log-full-policy está configurado en POSIX_TRACE_LOOP o POSIX_TRACE_UNTIL_FULL. Si el atributo log-full-policy está configurado en POSIX_TRACE_APPEND, la implementación ignorará el atributo log-max-size.

La función posix_trace_attr_getmaxdatasize() copia el tamaño máximo de datos del evento de rastreo del usuario, en bytes, del atributo max-data-size del objeto de atributos apuntado por el argumento attr a la variable apuntada por el argumento maxdatasize. El valor predeterminado para el atributo max-data-size depende de la implementación.

La función posix_trace_attr_getmaxsystemeventsize() calcula el tamaño máximo de memoria, en bytes, necesario para almacenar un solo evento de rastreo del sistema. Este valor se calcula para el objeto de atributos de flujo de rastreo apuntado por el argumento attr y se devuelve en la variable apuntada por el argumento eventsize.

Los valores devueltos como tamaños máximos de memoria de los eventos de rastreo del usuario y del sistema serán tales que si la suma de los tamaños máximos de memoria de un conjunto de eventos de rastreo que pueden registrarse en un flujo de rastreo es menor o igual que el atributo stream-min-size de dicho flujo de rastreo, el sistema proporcionará los recursos necesarios para registrar todos esos eventos de rastreo, sin pérdidas.

La función posix_trace_attr_getmaxusereventsize() calcula el tamaño máximo de memoria, en bytes, necesario para almacenar un solo evento de rastreo del usuario generado por una llamada a posix_trace_event() con un parámetro data_len igual al valor data_len especificado en esta llamada. Este valor se calcula para el objeto de atributos de flujo de rastreo apuntado por el argumento attr y se devuelve en la variable apuntada por el argumento eventsize.

La función posix_trace_attr_getstreamsize() copia el tamaño del flujo, en bytes, del atributo stream-min-size del objeto de atributos apuntado por el argumento attr a la variable apuntada por el argumento streamsize.

Este tamaño de flujo es el tamaño total actual de memoria reservado para eventos de rastreo del sistema y del usuario en el flujo de rastreo. El valor predeterminado para el atributo stream-min-size depende de la implementación. El tamaño del flujo se refiere a la memoria utilizada para almacenar registros de eventos de rastreo. Otros datos del flujo (por ejemplo, valores de atributos de rastreo) no se incluirán en este tamaño.

La función posix_trace_attr_setmaxdatasize() establece el tamaño máximo permitido, en bytes, en el atributo max-data-size del objeto de atributos apuntado por el argumento attr, utilizando el valor de tamaño proporcionado por el argumento maxdatasize. Este tamaño máximo es el tamaño máximo permitido para el argumento de datos del usuario que puede pasarse a posix_trace_event(). Se permitirá que la implementación trunque los datos pasados a trace_user_event que sean más largos que maxdatasize.

La función posix_trace_attr_setstreamsize() establece el tamaño mínimo permitido, en bytes, en el atributo stream-min-size del objeto de atributos apuntado por el argumento attr, utilizando el valor de tamaño proporcionado por el argumento streamsize.

VALOR DE RETORNO

Tras una finalización exitosa, estas funciones devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

La función posix_trace_attr_getlogsize() almacena el tamaño máximo permitido del registro de rastreo en el objeto apuntado por logsize, si tiene éxito.

La función posix_trace_attr_getmaxdatasize() almacena el tamaño máximo de memoria del registro de eventos de rastreo en el objeto apuntado por maxdatasize, si tiene éxito.

La función posix_trace_attr_getmaxsystemeventsize() almacena el tamaño máximo de memoria para almacenar un solo evento de rastreo del sistema en el objeto apuntado por eventsize, si tiene éxito.

La función posix_trace_attr_getmaxusereventsize() almacena el tamaño máximo de memoria para almacenar un solo evento de rastreo del usuario en el objeto apuntado por eventsize, si tiene éxito.

La función posix_trace_attr_getstreamsize() almacena el tamaño máximo permitido del flujo de rastreo en el objeto apuntado por streamsize, si tiene éxito.

ERRORES

Estas funciones pueden fallar si:

EINVAL
El valor especificado por uno de los argumentos es inválido.
