POSTCAT(1) Manual de comandos generales POSTCAT(1)

NOMBRE

postcat - mostrar el contenido de los archivos de cola de Postfix

SINOPSIS

postcat [-bdefhnoqv] [-c dir_config] [archivos...]

DESCRIPCIÓN


El comando postcat(1) imprime el contenido de los archivos nombrados de forma legible para humanos. Se espera que los archivos estén en formato de archivo de cola de Postfix. Si no se especifican archivos en la línea de comandos, el programa lee desde la entrada estándar.

Por defecto, postcat(1) muestra el sobre y el contenido del mensaje, como si se hubieran especificado las opciones -beh. Para ver solo el contenido del mensaje, especifique -bh (Postfix 2.7 y posteriores).

Opciones:

-b
Mostrar contenido del cuerpo. La opción -b comienza a producir salida en la primera línea que no es de encabezado y se detiene cuando se llega al final del mensaje.

Esta característica está disponible en Postfix 2.7 y posteriores.

-c dir_config
El archivo de configuración main.cf se encuentra en el directorio nombrado en lugar del directorio de configuración predeterminado.
-d
Imprimir el tipo decimal de cada registro.
-e
Mostrar contenido del sobre del mensaje.

Esta característica está disponible en Postfix 2.7 y posteriores.

-f
Anteponer el nombre del archivo a cada línea de salida.

Esta característica está disponible en Postfix 3.10 y posteriores.

-h
Mostrar contenido del encabezado del mensaje. La opción -h produce salida desde el principio del mensaje hasta, pero sin incluir, la primera línea que no es de encabezado.

Esta característica está disponible en Postfix 2.7 y posteriores.

-o
Imprimir el desplazamiento del archivo de cola de cada registro.
-q
Buscar en la cola de Postfix los archivos nombrados en lugar de tomar los nombres literalmente.

Esta característica está disponible en Postfix 2.0 y posteriores.

-r
Imprimir registros en orden de archivo, no seguir registros de puntero.

Esta característica está disponible en Postfix 3.7 y posteriores.

-s desplazamiento
Saltar al desplazamiento del archivo de cola especificado.

Esta característica está disponible en Postfix 3.7 y posteriores.

-v
Habilitar registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado.

DIAGNÓSTICOS


Los problemas se informan al flujo de error estándar.

AMBIENTE

MAIL_CONFIG
Directorio con archivos de configuración de Postfix.

PARÁMETROS DE CONFIGURACIÓN

Los siguientes parámetros de main.cf son especialmente relevantes para este programa.

El texto a continuación solo proporciona un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

config_directory (ver la salida de 'postconf -d')
La ubicación predeterminada de los archivos de configuración main.cf y master.cf de Postfix.
import_environment (ver la salida de 'postconf -d')
La lista de variables de entorno que un proceso privilegiado de Postfix importará de un proceso padre que no sea de Postfix, o anulaciones de entorno nombre=valor.
queue_directory (ver la salida de 'postconf -d')
La ubicación del directorio de cola principal de Postfix.
