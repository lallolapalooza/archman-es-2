NOMBRE

podman-image-mount - Montar el sistema de archivos raíz de una imagen

SINOPSIS

podman image mount [opciones] [imagen ...]

DESCRIPCIÓN

Monta el sistema de archivos raíz de las imágenes especificadas en una ubicación que puede ser accedida desde el host, y devuelve su ubicación.

El comando podman image mount sin argumentos lista todas las imágenes montadas actualmente.

El modo sin privilegios (rootless) solo soporta el montaje del driver VFS, a menos que podman se ejecute en un espacio de nombres de usuario. Utilice el comando podman unshare para entrar al espacio de nombres de usuario. Todos los demás drivers de almacenamiento fallan al montar.

VALOR DE RETORNO

La ubicación del sistema de archivos montado. En caso de error se devuelve una cadena vacía y el código errno.

OPCIONES

--all, -a

Montar todas las imágenes.

--format=formato

Imprimir las imágenes montadas en el formato especificado (json).

EJEMPLOS

Montar múltiples imágenes. Nota: En modo sin privilegios, el montaje de imágenes solo funciona después de ejecutar el comando podman unshare para entrar al espacio de nombres de usuario.

podman image mount fedora ubi8-init
/var/lib/containers/storage/overlay/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
/var/lib/containers/storage/overlay/0ff7d7ca68bed1ace424f9df154d2dd7b5a125c19d887f17653cbcd5b6e30ba1/merged

podman image mount
