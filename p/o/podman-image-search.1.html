NOMBRE

podman-search - Buscar una imagen en un registro

SINOPSIS

podman search [opciones] término

DESCRIPCIÓN

podman search busca en un registro o una lista de registros una imagen coincidente. El usuario puede especificar qué registro buscar prefijando el registro en el término de búsqueda (por ejemplo, registry.fedoraproject.org/fedora). Por defecto, se utilizan todos los registros no cualificados de búsqueda en containers-registries.conf(5).

El número por defecto de resultados es 25. El número de resultados puede limitarse usando la opción --limit. Si se buscan varios registros, el límite se aplica a cada registro. La salida puede filtrarse usando la opción --filter. Para obtener todas las imágenes disponibles en un registro sin un término de búsqueda específico, el usuario puede simplemente introducir el nombre del registro con una barra inclinada al final (ejemplo: registry.fedoraproject.org/).

Tenga en cuenta que podman search no es una forma fiable de determinar la presencia o existencia de una imagen. El comportamiento de búsqueda de la API de distribución de Docker v1 y v2 es específico de la implementación de cada registro. Algunos registros pueden no admitir la búsqueda en absoluto. Además, la búsqueda sin un término de búsqueda solo funciona para los registros que implementan la API v2.

podman [OPCIONES GENERALES]

podman search [OPCIONES GENERALES]

podman search [OPCIONES] TÉRMINO

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. Por defecto es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux, y $HOME/.config/containers/auth.json en Windows/macOS. El archivo se crea con podman login. Si el estado de autorización no se encuentra allí, se comprueba $HOME/.docker/config.json, que se establece con docker login.

Nota: También existe la opción de anular la ruta por defecto del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--cert-dir=ruta

Utilizar certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. (Por defecto: /etc/containers/certs.d) Para más detalles, véase containers-certs.d(5). (Esta opción no está disponible con el cliente Podman remoto, incluidos los ordenadores Mac y Windows (excluyendo WSL2))

--compatible

Después del nombre y la descripción, mostrar también los descriptores de estrellas, oficiales y automatizados como hace Docker. Podman no muestra estos descriptores por defecto ya que no son compatibles con la mayoría de los registros de contenedores públicos.

--creds=[usuario[:contraseña]]

El [usuario[:contraseña]] a utilizar para autenticarse en el registro, si es necesario. Si uno o ambos valores no se suministran, aparece un prompt en la línea de comandos y se puede introducir el valor. La contraseña se introduce sin eco.

Tenga en cuenta que las credenciales especificadas solo se utilizan para autenticarse en los registros de destino. No se utilizan para espejos o cuando el registro se reescribe (ver containers-registries.conf(5)); para autenticarse en estos casos, considere usar un archivo containers-auth.json(5).

--filter, -f=filtro

Filtrar la salida basándose en las condiciones proporcionadas (por defecto [])

Los filtros admitidos son:

  • stars (int) - número mínimo de estrellas requeridas para que se muestren las imágenes
  • is-automated (booleano - true | false) - si la imagen está automatizada o no
  • is-official (booleano - true | false) - si la imagen es oficial o no

--format=formato

Cambiar el formato de salida a una plantilla Go

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Automated "[OK]" si la imagen está automatizada
.Description Descripción de la imagen
.Index Registro
.Name Nombre de la imagen
.Official "[OK]" si la imagen es oficial
.Stars Número de estrellas de la imagen
.Tag Etiqueta del repositorio

Nota: use .Tag solo si --list-tags está establecido.

--help, -h

Imprimir el mensaje de uso

--limit=límite

Limitar el número de resultados (por defecto 25). Nota: Los resultados de cada registro se limitan a este valor. Ejemplo: si el límite es 10 y se buscan dos registros, el número total de resultados es 20, 10 de cada uno (si hay al menos 10 coincidencias en cada uno). El orden de los resultados de la búsqueda es el orden en que el punto final de la API devuelve los resultados.

--list-tags

Listar las etiquetas disponibles en el repositorio para la imagen especificada. Nota: --list-tags requiere que el término de búsqueda sea un nombre de imagen completamente especificado. El resultado contiene el nombre de la imagen y su etiqueta, una línea por cada etiqueta asociada a la imagen.

--no-trunc

No truncar la salida (por defecto false).

--tls-verify

Requerir HTTPS y verificar certificados al contactar con los registros (por defecto: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino esté listado como un registro inseguro en containers-registries.conf(5)

ARCHIVOS

registries.conf (/etc/containers/registries.conf)

registries.conf es el archivo de configuración que especifica qué registros de contenedores se consultan al completar nombres de imágenes que no incluyen una porción de registro o dominio.

podman-image-search.1.en

NAME

podman-image-search, podman image search - Search registries for images

SYNOPSIS

podman image search [ -h | --help ] [ -f | --filter filter ] [ -l | --limit limit ] [ -n | --no-trunc ] [ --tls-verify bool ] [ -v | --verbose ] term

DESCRIPTION

Search for container images in a registry. The search term is used to query the registry for matching images. The default registry is docker.io.

OPTIONS

-f, --filter
Filter output based on conditions provided.
-l, --limit
Maximum number of results to return.
-n, --no-trunc
Do not truncate output.
--tls-verify
Require TLS certificate validation (default: true).
-v, --verbose
Show verbose output for the search results.
-h, --help
Print usage statement for the command.

EXAMPLES

Search for the image alpine on the docker.io registry:

$ podman image search alpine

Search for the image ubuntu and limit the results to 5:

$ podman image search --limit 5 ubuntu

Search for the image redis and show verbose output:

$ podman image search --verbose redis
