PORTALS.CONF(5) Manual de Formatos de Archivo PORTALS.CONF(5)

NOMBRE

portals.conf - Configuración de portales de escritorio XDG

SINOPSIS

$XDG_CONFIG_HOME/xdg-desktop-portal/{*-}portals.conf

$XDG_CONFIG_DIRS/xdg-desktop-portal/{*-}portals.conf

/etc/xdg-desktop-portal/{*-}portals.conf

$XDG_DATA_HOME/xdg-desktop-portal/{*-}portals.conf

$XDG_DATA_DIRS/xdg-desktop-portal/{*-}portals.conf

/usr/share/xdg-desktop-portal/{*-}portals.conf

DESCRIPCIÓN

xdg-desktop-portal utiliza un archivo de configuración para determinar qué backend de portal se debe utilizar para proporcionar la implementación de la interfaz solicitada. Este mecanismo es muy similar a la especificación de freedesktop.org para "Asociación entre tipos MIME y aplicaciones" (mime-apps).

Los entornos de escritorio y los proveedores de sistemas operativos deben proporcionar una configuración predeterminada para sus backends de portal elegidos en /usr/share/xdg-desktop-portal/DESKTOP-portals.conf, donde DESKTOP es el nombre del entorno de escritorio tal como aparecería en la variable de entorno XDG_CURRENT_DESKTOP, después de convertir a minúsculas las mayúsculas ASCII. Por ejemplo, KDE debería proporcionar /usr/share/xdg-desktop-portal/kde-portals.conf.

Los usuarios pueden anular esos valores predeterminados, o proporcionar configuración para un entorno de escritorio no compatible, escribiendo un archivo ~/.config/xdg-desktop-portal/portals.conf. Los usuarios de más de un entorno de escritorio pueden usar nombres de archivo específicos del entorno de escritorio como kde-portals.conf que solo se usarán en el entorno de escritorio apropiado.

Del mismo modo, los administradores del sistema pueden proporcionar una configuración predeterminada para todos los usuarios en /etc/xdg-desktop-portal/DESKTOP-portals.conf o /etc/xdg-desktop-portal/portals.conf.

Se buscan los siguientes lugares para la configuración, con la mayor precedencia primero:

  • $XDG_CONFIG_HOME, por defecto ~/.config
  • cada directorio en $XDG_CONFIG_DIRS, por defecto /etc/xdg
  • el sysconfdir de compilación para xdg-desktop-portal, usualmente /etc
  • $XDG_DATA_HOME, por defecto ~/.local/share (solo se busca por consistencia con otras especificaciones, no se recomienda escribir configuración aquí)
  • cada directorio en $XDG_DATA_DIRS, por defecto /usr/local/share:/usr/share
  • el datadir de compilación para xdg-desktop-portal, usualmente /usr/share

En cada uno de esos lugares, para cada nombre de entorno de escritorio listado en la variable de entorno XDG_CURRENT_DESKTOP, xdg-desktop-portal busca xdg-desktop-portal/DESKTOP-portals.conf, donde DESKTOP es el nombre del entorno de escritorio en minúsculas. Si no se encuentra un archivo de configuración específico del entorno de escritorio, se leerá un archivo no específico del entorno de escritorio xdg-desktop-portal/portals.conf. Por ejemplo, si XDG_CURRENT_DESKTOP está establecido a Budgie:GNOME, entonces xdg-desktop-portal buscará xdg-desktop-portal/budgie-portals.conf, xdg-desktop-portal/gnome-portals.conf y xdg-desktop-portal/portals.conf en ese orden.

Solo se lee el primer archivo de configuración encontrado, y los archivos de configuración de menor precedencia se ignoran. Todos los archivos de configuración posibles dentro de un directorio se prueban antes de pasar al siguiente directorio, por lo que, por ejemplo, ~/.config/xdg-desktop-portal/portals.conf tiene mayor precedencia que /usr/share/xdg-desktop-portal/kde-portals.conf.

FORMATO DEL ARCHIVO

El formato del archivo de configuración de portales es el mismo formato .ini utilizado por los archivos de unidad de systemd o los archivos de escritorio de aplicaciones.

[preferred]

El grupo de configuración principal para portales preferidos.

Las siguientes claves pueden estar presentes en el grupo preferred:

default (cadena)

El backend de portal predeterminado para usar en cada interfaz, a menos que la interfaz se liste explícitamente.

org.freedesktop.impl.portal.* (cadena)

Una de las implementaciones válidas del portal expuestas por xdg-desktop-portal.

Cada clave en el grupo contiene una lista separada por punto y coma de implementaciones de backend de portal, para buscar una implementación de la interfaz solicitada, en el mismo orden especificado en el archivo de configuración. Adicionalmente, los valores especiales none y * pueden ser usados:

none

No proporcionar una implementación de portal para esta interfaz.

*

Usar la primera implementación de portal encontrada, en orden lexicográfico.

EJEMPLO

[preferred]
# Usar xdg-desktop-portal-gtk para cada interfaz de portal...
default=gtk
# ... excepto para la interfaz ScreenCast
org.freedesktop.impl.portal.ScreenCast=gnome

AMBIENTE

XDG_CURRENT_DESKTOP

Una lista separada por dos puntos de entornos de escritorio, el más específico primero, utilizada para elegir una configuración de portal específica del entorno de escritorio. El valor predeterminado es una lista vacía.

XDG_CONFIG_HOME

El archivo portals.conf por usuario se encuentra en este directorio. El valor predeterminado es $HOME/.config.

XDG_CONFIG_DIRS

Una lista separada por dos puntos de directorios de configuración del sistema y directorios de configuración secundarios por usuario. El valor predeterminado es /etc/xdg.

XDG_DATA_HOME

Un directorio de datos por usuario, buscado por consistencia con otras especificaciones. El valor predeterminado es $HOME/.local/share.

XDG_DATA_DIRS

Una lista separada por dos puntos de directorios de datos del sistema y directorios de datos secundarios por usuario. El valor predeterminado es /usr/local/share:/usr/share.
