podman-container(1) Manual de comandos generales podman-container(1)

NOMBRE

podman-container - Gestionar contenedores

SINOPSIS

podman container subcomando

DESCRIPCIÓN

El comando container permite la gestión de contenedores.

COMANDOS

Comando Página del manual Descripción
attach podman-attach(1) Conecta a un contenedor en ejecución.
checkpoint podman-container-checkpoint(1) Punto de control de uno o más contenedores en ejecución.
cleanup podman-container-cleanup(1) Limpia la red y los puntos de montaje del contenedor.
clone podman-container-clone(1) Crea una copia de un contenedor existente.
commit podman-commit(1) Crea una nueva imagen basada en el contenedor modificado.
cp podman-cp(1) Copia archivos/carpetas entre un contenedor y el sistema de archivos local.
create podman-create(1) Crea un nuevo contenedor.
diff podman-container-diff(1) Inspecciona cambios en el sistema de archivos de un contenedor.
exec podman-exec(1) Ejecuta un comando en un contenedor en ejecución.
exists podman-container-exists(1) Comprueba si un contenedor existe en el almacenamiento local.
export podman-export(1) Exporta el contenido del sistema de archivos de un contenedor como un archivo tar.
init podman-init(1) Inicializa un contenedor.
inspect podman-container-inspect(1) Muestra la configuración de un contenedor.
kill podman-kill(1) Detiene el proceso principal en uno o más contenedores.
list podman-ps(1) Lista los contenedores en el sistema. (alias ls)
logs podman-logs(1) Muestra los registros de un contenedor.
mount podman-mount(1) Monta el sistema de archivos raíz de un contenedor en funcionamiento.
pause podman-pause(1) Pausa uno o más contenedores.
port podman-port(1) Lista los mapeos de puertos para el contenedor.
prune podman-container-prune(1) Elimina todos los contenedores detenidos del almacenamiento local.
ps podman-ps(1) Imprime información sobre los contenedores.
rename podman-rename(1) Renombra un contenedor existente.
restart podman-restart(1) Reinicia uno o más contenedores.
restore podman-container-restore(1) Restaura uno o más contenedores a partir de un punto de control.
rm podman-rm(1) Elimina uno o más contenedores.
run podman-run(1) Ejecuta un comando en un contenedor.
runlabel podman-container-runlabel(1) Ejecuta un comando según lo descrito por una etiqueta de imagen de contenedor.
start podman-start(1) Inicia uno o más contenedores.
stats podman-stats(1) Muestra una transmisión en vivo de las estadísticas de uso de recursos de uno o más contenedores.
stop podman-stop(1) Detiene uno o más contenedores en ejecución.
top podman-top(1) Muestra los procesos en ejecución de un contenedor.
unmount podman-unmount(1) Desmonta el sistema de archivos raíz de un contenedor en funcionamiento. (Alias unmount)
unpause podman-unpause(1) Reanuda uno o más contenedores.
update podman-update(1) Actualiza la configuración de cgroup de un contenedor dado.
wait podman-wait(1) Espera a que uno o más contenedores se detengan e imprime sus códigos de salida.

VER TAMBIÉN

podman(1), podman-exec(1), podman-run(1)
