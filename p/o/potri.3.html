subrutina cpotri (carácter uplo, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CPOTRI

Propósito:

!>
!> CPOTRI calcula la inversa de una matriz compleja Hermítica positiva definida
!> A utilizando la factorización de Cholesky A = U**H*U o A = L*L**H
!> calculada por CPOTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, el factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, tal como se calculó por
!>          CPOTRF.
!>          En la salida, el triángulo superior o inferior de la inversa (Hermítica)
!>          de A, sobrescribiendo el factor de entrada U o L.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el elemento (i,i) del factor U o L es
!>                cero, y la inversa no pudo ser calculada.
!>

NAME

POTRI - POTRI computes the inverse of a real or complex `dpbtrf`.

  SUBROUTINE CPOTRI( UPLO, N, A, LDA, INFO )

      CHARACTER*1       UPLO

      INTEGER           N

      COMPLEX*16        A( LDA, * )

      INTEGER           LDA

      INTEGER           INFO

TOP LEFT SIDE OF THE ARRAY A

Detailed Description

POTRI computes the inverse of a real or complex `dpbtrf`.

This routine is intended to follow calls to `dpbtrf`, `cpbtrf`, `dpbttf`, or `cpbttf`. If the inverse is required after a different factorization (e.g. `dpotrf` or `cpotrf`), use `dpotri` or `cpotri`.

Arguments

UPLO

CHARACTER*1. On entry, UPLO specifies whether the vector of diagonal entries of the triangular factor is stored in the upper or lower triangular part of the array A.

UPLO = 'U' only

UPLO = 'L' only

N

INTEGER.

The order of the matrix

N >= 0.

A

DOUBLE PRECISION or COMPLEX*16.

On entry, the triangular factor of the matrix A as computed by dpbtrf or cpbtrf.

On exit, the upper or lower triangle of the inverse of A. The other part of A is used for workspace.

LDA

INTEGER.

The leading dimension of the array A.

LDA >= max(1, N).

INFO

INTEGER.

INFO = 0. Normal execution.

INFO < 0. If INFO = -i, then the i-th argument had an illegal value.

INFO > 0. If INFO = i, then i-th diagonal element of the factor is zero, and the inversion could not be completed.
