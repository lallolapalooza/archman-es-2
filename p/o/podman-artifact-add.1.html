NOMBRE

podman-artifact-add - Añade un artefacto OCI al almacén local de artefactos

SINOPSIS

podman artifact add [opciones] nombre-artefacto archivo [archivo ...]

DESCRIPCIÓN

Añade un artefacto OCI al almacén local desde el sistema de archivos local. Debe proporcionar al menos un archivo para crear el artefacto, pero también se pueden añadir varios.

Los artefactos incluyen automáticamente una marca de tiempo de creación en la anotación org.opencontainers.image.created en formato RFC3339Nano. Al usar la opción --append, se conserva la marca de tiempo de creación original.

OPCIONES

--annotation=anotacion=valor

Establece una anotación en la entrada para la imagen o artefacto especificado.

Nota: Establezca anotaciones para cada archivo que se añada. La anotación "org.opencontainers.image.title" se utiliza para nombrar la capa cuando se monta en un contenedor, este título debe ser único para cada capa de artefacto.

--append, -a

Añade archivos a un artefacto existente. Esta opción no se puede utilizar con la opción --type.

--file-type

Establece el tipo de medio del archivo de artefacto en lugar de permitir que la detección determine el tipo.

--help

Imprime el enunciado de uso.

--replace

Si ya existe un artefacto con el mismo nombre, lo reemplaza y lo elimina. El valor predeterminado es false. Esta opción no se puede utilizar con la opción --append.

--type

Establece un tipo para el artefacto que se está añadiendo.

EJEMPLOS

Añadir un solo archivo a un artefacto

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

Añadir un artefacto OCI al almacén con tipo:

$ podman artifact add --artifact-type application/com.example.ai --file-type application/vnd.gguf quay.io/myimage/myartifact:latest /home/user/model.gguf

Reemplazar un artefacto existente con el mismo nombre

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

Añadir varios archivos a un artefacto

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar1.ml /tmp/foobar2.ml
1487acae11b5a30948c50762882036b41ac91a7b9514be8012d98015c95ddb78

Añadir archivos a un artefacto OCI existente

$ podman artifact add --append quay.io/myimage/myartifact:latest /home/user/config.yaml

Crear un artefacto con el nombre de título de capa reemplazado, y luego montarlo en un contenedor.

podman artifact add --annotation org.opencontainers.image.title=smollm2 quay.io/myreg/smollm2:latest blobs/sha256-4d2396b16114669389d7555c15a1592aad584750310f648edad5ca8c4eccda17
podman run --mount type=artifact,source=quay.io/myreg/smollm2:latest,destination=/mnt fedora ls -l /mnt
smollm2
