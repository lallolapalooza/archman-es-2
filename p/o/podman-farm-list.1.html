podman-farm-list(1) Manual de comandos generales podman-farm-list(1)

NOMBRE

podman-farm-list - Lista las granjas existentes

SINOPSIS

podman farm list [opciones]

podman farm ls [opciones]

DESCRIPCIÓN

Lista todas las granjas existentes.

OPCIONES

--format=formato

Cambia el formato de salida predeterminado. Puede ser de un tipo compatible como 'json' o una plantilla Go. Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Connections Lista de todas las conexiones del sistema en la granja
.Default Indica si la granja es la predeterminada
.Name Nombre de la granja
.ReadWrite Indica si esta granja se puede modificar utilizando los comandos podman farm

EJEMPLO

Lista todas las granjas:

$ podman farm list
Nombre        Conexiones  Predeterminado  Lectura/Escritura
farm1       [f38 f37]    false       true
farm2       [f37]        true        true

Muestra las granjas en formato JSON:

$ podman farm list --format json
[
  {
    "Nombre": "farm1",
    "Conexiones": [
      "f38",
      "f37"
    ],
    "Predeterminado": false,
    "Lectura/Escritura": true
  },
  {
    "Nombre": "farm2",
    "Conexiones": [
      "f37"
    ],
    "Predeterminado": true,
    "Lectura/Escritura": true
  }
]

Muestra solo los nombres de las granjas:

$ podman farm list --format "{{.Name}}"
farm1
farm2

Muestra información detallada de la granja:

$ podman farm list --format "Granja: {{.Name}} (Predeterminada: {{.Default}}, Lectura/Escritura: {{.ReadWrite}})\nConexiones: {{.Connections}}"
Granja: farm1 (Predeterminada: false, Lectura/Escritura: true)
Conexiones: [f38 f37]
Granja: farm2 (Predeterminada: true, Lectura/Escritura: true)
Conexiones: [f37]
