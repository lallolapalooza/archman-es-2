POSIX_SPAWNATTR_GETSIGDEFAULT(3P) Manual del Programador POSIX POSIX_SPAWNATTR_GETSIGDEFAULT(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación en Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_spawnattr_getsigdefault, posix_spawnattr_setsigdefault — obtener y establecer el atributo spawn-sigdefault de un objeto de atributos de spawn (TIEMPO REAL AVANZADO)

SINOPSIS

#include <signal.h>
#include <spawn.h>
int posix_spawnattr_getsigdefault(const posix_spawnattr_t
    *restrict attr, sigset_t *restrict sigdefault);
int posix_spawnattr_setsigdefault(posix_spawnattr_t *restrict attr,
    const sigset_t *restrict sigdefault);

DESCRIPCIÓN

La función posix_spawnattr_getsigdefault() obtendrá el valor del atributo spawn-sigdefault del objeto de atributos al que hace referencia attr.

La función posix_spawnattr_setsigdefault() establecerá el atributo spawn-sigdefault en un objeto de atributos inicializado al que hace referencia attr.

El atributo spawn-sigdefault representa el conjunto de señales que se forzarán al manejo de señales por defecto en la nueva imagen de proceso (si POSIX_SPAWN_SETSIGDEF está establecido en el atributo spawn-flags) mediante una operación de spawn. El valor por defecto de este atributo será un conjunto de señales vacío.

VALOR DE RETORNO

Al completarse con éxito, posix_spawnattr_getsigdefault() devolverá cero y almacenará el valor del atributo spawn-sigdefault de attr en el objeto al que hace referencia el parámetro sigdefault; de lo contrario, se devolverá un número de error para indicar el error.

Al completarse con éxito, posix_spawnattr_setsigdefault() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones pueden fallar si:

EINVAL
El valor especificado por attr no es válido.

La función posix_spawnattr_setsigdefault() puede fallar si:

EINVAL
El valor del atributo que se está estableciendo no es válido.
