CPOCON

Propósito:

!>
!> CPOCON estima el recíproco del número de condición (en la
!> norma 1) de una matriz compleja Hermitiana definida positiva
!> cuya factorización de Cholesky A = U**H*U o A = L*L**H fue calculada por CPOTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y el recíproco del
!> número de condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': el triángulo superior de A está almacenado;
!>          = 'L': el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, tal como fue calculada por CPOTRF.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 (o norma infinito) de la matriz Hermitiana A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

NAME

pocon - estimates the reciprocal of the condition number of a general band matrix.

Detailed Description

This subroutine estimates the reciprocal of the condition number of a general band matrix A in either the real-time or the complex-time domain. The condition number is computed using the 1-norm.

The condition number is a measure of the sensitivity of the solution of a linear system of equations to errors in the data. A large condition number indicates that the system is ill-conditioned and may be sensitive to small changes in the input data.

The routine uses the Cholesky factorization of A computed by GPOTRF, SPOTRF, DPOTRF, CPOTRF, or ZPOTRF. If A is not positive definite, the routine returns with an error.

The estimate is obtained by computing the 1-norm of the inverse of A and then computing the reciprocal of the condition number as 1 / (ANORM * norm(inv(A))), where ANORM is the 1-norm of A.

The routines are available in both single and double precision, as well as real and complex versions.

Function Documentation

GPOCON

Purpose:

!>
!> GPOCON estimates the reciprocal of the condition number (in the
!> 1-norm) of a general band matrix A using the L*L**H or U**H*U factorization
!> computed by GPOTRF.
!>
!> RCOND is an estimate of the reciprocal switches between 1.0 / (ANORM *
!>       norm(inv(A)))
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangle of A is stored and will be used.
!>          = 'L': Lower triangle of A is stored and will be used.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

NB

!>          NB is INTEGER
!>          The number of subdiagonals within the band.
!>

KB

!>          KB is INTEGER
!>          The number of superdiagonals within the band.
!>

A

!>          A is REAL*8 array, dimension (LDA, N)
!>          On entry, the factors L and U from the factorization A = P*L*U
!>          as computed by GPOTRF.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N)
!>

ANORM

!>          ANORM is REAL*8
!>          The 1-norm of the original band matrix A.
!>

RCOND

!>          RCOND is REAL*8
!>          On exit, an estimate of the reciprocal of the condition number
!>          of A.
!>

WORK

!>          WORK is REAL*8 array, dimension (2*N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>
