NOMBRE

podman-unmount - Desmontar el sistema de archivos raíz de un contenedor en ejecución

SINOPSIS

podman unmount [opciones] contenedor [...]

podman umount [opciones] contenedor [...]

podman container unmount [opciones] contenedor [...]

podman container umount [opciones] contenedor [...]

DESCRIPCIÓN

Desmonta el sistema de archivos raíz de los contenedores especificados, si no hay otros procesos que lo estén utilizando.

El almacenamiento de contenedores incrementa un contador de montaje cada vez que se monta un contenedor. Al desmontar un contenedor, el contador de montaje se decrementa y el sistema de archivos raíz del contenedor solo se desmonta físicamente cuando el contador de montaje llega a cero, lo que indica que ningún otro proceso está utilizando el montaje. Se puede forzar un desmontaje con la opción --force.

Nota: Podman puede usarse para desmontar contenedores de Podman, así como contenedores externos. Los contenedores externos son contenedores creados en el almacenamiento de contenedores por otras herramientas como Buildah y CRI-O.

OPCIONES

--all, -a

Se desmontan todos los contenedores actualmente montados.

--force, -f

Fuerza el desmontaje del sistema de archivos raíz de los contenedores especificados, incluso si otros procesos lo han montado.

Nota: Otros procesos pueden fallar si el punto de montaje que están utilizando se elimina sin su conocimiento.

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, se utiliza el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excluido WSL2))

EJEMPLO

Desmontar un contenedor con un ID dado:

podman container unmount ID_del_contenedor

Desmontar varios contenedores con IDs dados:

podman unmount ID_del_contenedor1 ID_del_contenedor2 ID_del_contenedor3

Desmontar todos los contenedores:

podman unmount --all

Forzar el desmontaje de un contenedor con un ID dado:

podman umount --force ID_del_contenedor

VER TAMBIÉN

podman(1), podman-mount(1), podman-image-mount(1)
