NOMBRE

podman-pod-top - Muestra los procesos en ejecución de los contenedores en un pod

SINOPSIS

podman pod top [opciones] pod [descriptores-formato]

DESCRIPCIÓN

Muestra los procesos en ejecución de los contenedores en un pod. Los descriptores-formato son descriptores de formato AIX compatibles con ps (1) pero extendidos para imprimir información adicional, como el modo seccomp o las capacidades efectivas de un proceso dado. Los descriptores se pueden pasar como argumentos separados o como un único argumento separado por comas.

OPCIONES

--help, -h

Imprime el aviso de uso

--latest, -l

En lugar de proporcionar el nombre o ID del pod, usa el último pod creado. Nota: el último pod iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

DESCRIPTORES DE FORMATO

Para obtener una lista completa de los descriptores disponibles, consulta podman-top(1)

EJEMPLOS

Imprime datos de top para el pod especificado. Por defecto, podman-pod-top imprime datos similares a ps -ef:

$ podman pod top b031293491cc
USER   PID   PPID   %CPU    ELAPSED             TTY   TIME   COMMAND
root   1     0      0.000   2h5m38.737137571s   ?     0s     top
root   8     0      0.000   2h5m15.737228361s   ?     0s     top

La salida se puede controlar especificando descriptores de formato como argumentos después del pod.

Imprime los campos de datos de top del pod pid, seccomp, args y %C en el último pod creado. (Esta opción -l no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman pod top -l pid seccomp args %C
PID   SECCOMP   COMMAND   %CPU
1     filter    top       0.000
1     filter    /bin/sh   0.000

VER TAMBIÉN

podman(1), podman-pod(1), ps(1), seccomp(2), proc(5), capabilities(7)
