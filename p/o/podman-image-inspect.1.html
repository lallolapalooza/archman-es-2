NOMBRE

podman-image inspect - Muestra la configuración de una imagen

SINOPSIS

podman image inspect [opciones] imagen [imagen ...]

DESCRIPCIÓN

Esto muestra la información de bajo nivel sobre las imágenes identificadas por nombre o ID. Por defecto, esto renderiza todos los resultados en un array JSON. Si se especifica un formato, se ejecuta la plantilla dada para cada resultado.

OPCIONES

--format, -f=formato

Formatea la salida utilizando la plantilla Go dada. Las claves del JSON devuelto se pueden usar como valores para la bandera --format (ver ejemplos a continuación).

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Annotations ... Información de anotaciones incluida en la imagen
.Architecture Arquitectura del software en la imagen
.Author Autor de la imagen
.Comment Comentario de la imagen
.Config ... Estructura con información de configuración
.Created ... Hora de creación de la imagen (cadena, ISO3601)
.Digest Digest de la imagen (hash de +64 caracteres sha256)
.GraphDriver ... Estructura para la información del driver de grafos
.HealthCheck ... Estructura para la información de verificación de salud
.History Información del historial almacenada en la imagen
.ID ID de la imagen (hash completo de 64 caracteres)
.Labels ... Información de etiquetas incluida en la imagen
.ManifestType Tipo de manifiesto de la imagen
.NamesHistory Información del historial de nombres almacenada en la imagen
.Os Sistema operativo del software en la imagen
.Parent Imagen padre de la imagen especificada
.RepoDigests Digests del repositorio para la imagen
.RepoTags Tags del repositorio para la imagen
.RootFS ... Estructura para la información del sistema de archivos raíz
.Size Tamaño de la imagen, en bytes
.User Usuario por defecto para ejecutar la imagen
.Version Versión de la imagen
.VirtualSize Tamaño virtual de la imagen, en bytes

Arch Linux

Acerca de

Arch Linux es una distribución de Linux independiente, optimizada para x86-64 y enfocada en la simplicidad, la modernidad, el pragmatismo, el centrismo del usuario y la versatilidad.

Para lograr estos objetivos, Arch Linux sigue una filosofía de desarrollo KISS (Keep It Simple, Stupid), usa un modelo de lanzamiento continuo y mantiene un enfoque en el software libre y de código abierto.

Instalación

La instalación de Arch Linux se realiza principalmente a través de la línea de comandos. El proceso de instalación es manual y requiere que el usuario configure todos los componentes del sistema, incluido el particionado del disco, la configuración de la red y la instalación del entorno de escritorio deseado.

Gestor de Paquetes

Arch Linux utiliza el gestor de paquetes pacman. Pacman es una herramienta potente y rápida que maneja la instalación, actualización y eliminación de paquetes de software.

Además de los repositorios oficiales, Arch Linux cuenta con el Arch User Repository (AUR), una comunidad de usuarios que mantiene un repositorio de paquetes no oficiales. El AUR permite a los usuarios compilar e instalar software que no está disponible en los repositorios oficiales.

Comunidad y Documentación

Arch Linux tiene una comunidad activa y útil. La Arch Wiki es una fuente de documentación extensa y de alta calidad, considerada una de las mejores wikis de distribuciones de Linux.
