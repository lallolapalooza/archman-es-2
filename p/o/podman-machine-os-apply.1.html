NOMBRE

podman-machine-os-apply - Aplica una imagen OCI al sistema operativo de una máquina Podman

SINOPSIS

podman machine os apply [opciones] imagen [vm]

DESCRIPCIÓN

Aplica cambios en el sistema operativo de la máquina desde una imagen OCI.

Las VM que utilizan sistemas operativos basados en rpm-ostree tienen la capacidad de rebasarse a sí mismas a partir del contenido de una imagen OCI. podman machine image apply toma una imagen OCI con funcionalidad ostree nativa de contenedor y se rebasará sobre esa imagen.

Por defecto, las máquinas Podman en Mac, Linux y Windows Hyper-V utilizan una distribución personalizada basada en rpm-ostree (Fedora CoreOS). Las máquinas basadas en Microsoft WSL utilizan una distribución Fedora personalizada y no pueden actualizarse con este comando.

Nota: Las máquinas basadas en WSL se pueden actualizar utilizando el comando podman machine ssh <nombre_máquina> seguido de sudo dnf update. Sin embargo, esto puede dar lugar a resultados inesperados en las diferencias de versiones del cliente y servidor de Podman.

Las imágenes de la máquina Podman se almacenan como imágenes OCI en quay.io/podman/machine-os. Al aplicar una imagen utilizando este comando, se debe utilizar el nombre de referencia OCI completo, incluyendo la etiqueta, donde la etiqueta es la versión de Podman que se encuentra dentro de la VM. Por defecto, Podman intentará extraer solo la versión declarada como tal.

Para más información, consulte la documentación de rpm-ostree.

El nombre de máquina predeterminado es podman-machine-default. Si no se especifica un nombre de máquina como argumento, los cambios del sistema operativo se aplicarán a podman-machine-default.

OPCIONES

--help

Imprime el enunciado de uso.

--restart

Reinicia la VM después de aplicar los cambios.

EJEMPLOS

Actualiza la máquina Podman predeterminada a la última versión de desarrollo de la imagen OCI arrancable.

Nota: Esto puede resultar en tener una versión de Podman más reciente dentro de la máquina que el cliente. Pueden ocurrir resultados inesperados.

Actualiza la máquina Podman predeterminada a la imagen OCI arrancable más reciente de Podman 5.4.

$ podman machine os apply quay.io/podman/machine-os:5.4

Actualiza la máquina Podman especificada a la imagen OCI arrancable más reciente de Podman 5.3.

$ podman machine os apply quay.io/podman/machine-os:5.3 mymachine
