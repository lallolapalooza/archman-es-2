NOMBRE

podman-history - Mostrar el historial de una imagen

SINOPSIS

podman history [opciones] imagen[:etiqueta|@digest]

podman image history [opciones] imagen[:etiqueta|@digest]

DESCRIPCIÓN

podman history muestra el historial de una imagen imprimiendo información sobre cada capa utilizada en la imagen. La información impresa para cada capa incluye Creado (hora y fecha), Creado por, Tamaño y Comentario. La salida puede ser truncada o no usando la bandera --no-trunc. Si la bandera --human está activada, la hora de creación y el tamaño se imprimen en un formato legible por humanos. La bandera --quiet muestra solo el ID de la imagen cuando está activada, y la bandera --format se usa para imprimir la información utilizando la plantilla Go proporcionada por el usuario.

OPCIONES

--format=formato

Modifica la salida para un formato como 'json' o una plantilla Go.

Los marcadores válidos para la plantilla Go se enumeran a continuación:

Marcador Descripción
.Comment Comentario para la capa
.Created si es --human, tiempo transcurrido desde la creación, de lo contrario, marca de tiempo de creación
.CreatedAt Hora en que se creó la capa de imagen
.CreatedBy Comando utilizado para crear la capa
.CreatedSince Tiempo transcurrido desde que se creó la capa de imagen
.ID ID de la imagen
.Size Tamaño de la capa en disco
.Tags Etiquetas de la imagen

--help, -h

Imprimir declaración de uso

--human, -H

Mostrar tamaños y fechas en formato legible por humanos (por defecto true).

--no-trunc

No truncar la salida (por defecto false).

--quiet, -q

Imprimir solo los IDs numéricos (por defecto false).

EJEMPLOS

Mostrar el historial de la imagen especificada:

$ podman history debian
ID              CREADO      CREADO POR                                      TAMAÑO      COMENTARIO
b676ca55e4f2c   hace 9 semanas   /bin/sh -c #(nop) CMD ["bash"]                  0 B
<faltante>       hace 9 semanas   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45.14 MB

Mostrar el historial de la imagen especificada sin truncar el contenido y usando datos sin procesar:

$ podman history --no-trunc=true --human=false debian
ID              CREADO                 CREADO POR                                      TAMAÑO      COMENTARIO
b676ca55e4f2c   2017-07-24T16:52:55Z   /bin/sh -c #(nop) CMD ["bash"]                  0
<faltante>       2017-07-24T16:52:54Z   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45142935

Mostrar el historial formateado de la imagen especificada:

$ podman history --format "{{.ID}} {{.Created}}" debian
b676ca55e4f2c   hace 9 semanas
<faltante>       hace 9 semanas

Mostrar el historial en formato JSON para la imagen especificada:

$ podman history --format json debian
