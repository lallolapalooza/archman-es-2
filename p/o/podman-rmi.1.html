NOMBRE

podman-rmi - Eliminar una o más imágenes almacenadas localmente

SINOPSIS

podman rmi [opciones] imagen [...]

podman image rm [opciones] imagen [...]

DESCRIPCIÓN

Elimina una o más imágenes almacenadas localmente. Pasar un argumento imagen la elimina, junto con cualquiera de sus imágenes padre huérfanas. Una imagen huérfana es una imagen sin etiqueta y sin ser referenciada por otra imagen.

Nota: Para eliminar una imagen de un registro remoto, utiliza el comando skopeo delete. Algunos registros no permiten a los usuarios eliminar una imagen de forma remota a través de una CLI.

OPCIONES

--all, -a

Elimina todas las imágenes en el almacenamiento local.

--force, -f

Esta opción hace que Podman elimine todos los contenedores que estén utilizando la imagen antes de eliminar la imagen del sistema.

--ignore, -i

Si una imagen especificada no existe en el almacenamiento local, ignórala y no generes un error.

--no-prune

Esta opción no elimina las imágenes padre huérfanas de la imagen especificada.

EJEMPLOS

Eliminar una imagen por su ID corto

$ podman rmi c0ed59d05ff7

Eliminar una imagen y sus contenedores asociados.

$ podman rmi --force ID_IMAGEN

Eliminar múltiples imágenes por sus IDs acortados.

$ podman rmi c4dfb1609ee2 93fd78260bd1 c0ed59d05ff7

Eliminar todas las imágenes y contenedores.

$ podman rmi -a -f

Eliminar una imagen ausente con y sin el indicador --ignore.

$ podman rmi --ignore nada
$ podman rmi nada
Error: nada: imagen desconocida

Eliminar una imagen pero conservar sus imágenes padre.

podman rmi --no-prune d29200bf974d
Eliminado: d29200bf974dbc48dc66c23c4031548531b6b5943e5f25ee7bda232e3b6b27f4

Estado de Salida

0 Todas las imágenes especificadas fueron eliminadas

1 Una de las imágenes especificadas no existía, y no hubo otros fallos

2 Una de las imágenes especificadas tiene imágenes hijas o está siendo utilizada por un contenedor

125 El comando falla por cualquier otro motivo
