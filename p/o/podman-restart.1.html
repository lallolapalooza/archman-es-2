NOMBRE

podman-restart - Reinicia uno o más contenedores

SINOPSIS

podman restart [opciones] contenedor ...

podman container restart [opciones] contenedor ...

DESCRIPCIÓN

El comando restart permite reiniciar contenedores usando su ID o nombre. Los contenedores en ejecución se detienen y se reinician. Los contenedores detenidos se inician.

OPCIONES

--all, -a

Reinicia todos los contenedores independientemente de su estado actual.

--cidfile

Lee el ID del contenedor desde el archivo especificado y reinicia el contenedor. Se puede especificar varias veces.

--filter, -f=filtro

Filtra qué contenedores se reinician. Se pueden dar varios filtros utilizando varias veces la opción --filter. Los filtros con la misma clave funcionan de forma inclusiva, con la única excepción de label, que es exclusiva. Los filtros con claves diferentes siempre funcionan de forma exclusiva.

Los filtros válidos se enumeran a continuación:

Filtro Descripción
id [ID] ID del contenedor (coincidencia parcial de prefijo CID por defecto; acepta regex)
name [Nombre] Nombre del contenedor (acepta regex)
label [Clave] o [Clave=Valor] Etiqueta asignada a un contenedor
exited [Int] Código de salida del contenedor
status [Estado] Estado del contenedor: 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NombreImagen] Imagen o descendiente utilizado para crear el contenedor
before [ID] o [Nombre] Contenedores creados antes que este contenedor
since [ID] o [Nombre] Contenedores creados después que este contenedor
volume [NombreVolumen] o [PuntoMontajeDestino] Volumen montado en el contenedor
health [Estado] healthy o unhealthy
pod [Pod] nombre o ID completo o parcial del pod
network [Red] nombre o ID completo de la red
until [FechaHora] Contenedores creados antes de la duración o hora dada.
command [Comando] el comando que está ejecutando el contenedor, solo se toma argv[0]

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, usa el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2)).

--running

Reinicia todos los contenedores que ya se encuentran en el estado running.

--time, -t=segundos

Segundos a esperar antes de detener forzosamente el contenedor. Usa -1 para una espera infinita.

EJEMPLOS

Reiniciar el último contenedor.

$ podman restart -l
ec588fc80b05e19d3006bf2e8aa325f0a2e2ff1f609b7afb39176ca8e3e13467

Reiniciar un contenedor específico por ID parcial del contenedor.

$ podman restart ff6cf1
ff6cf1e5e77e6dba1efc7f3fcdb20e8b89ad8947bc0518be1fcb2c78681f226f

Reiniciar dos contenedores por nombre con un tiempo de espera de 4 segundos.

$ podman restart --time 4 test1 test2
c3bb026838c30e5097f079fa365c9a4769d52e1017588278fa00d5c68ebc1502
17e13a63081a995136f907024bcfe50ff532917988a152da229db9d894c5a9ec

Reiniciar todos los contenedores en ejecución.

$ podman restart --running

Reiniciar todos los contenedores.

$ podman restart --all

Reiniciar contenedor usando el ID especificado en los archivos dados.

$ podman restart --cidfile /home/user/cidfile-1
$ podman restart --cidfile /home/user/cidfile-1 --cidfile ./cidfile-2

Reiniciar contenedor por nombre.

$ podman restart --filter name=id-name-test

Reiniciar contenedor por etiqueta.

$ podman restart --filter label=app=label-test

Reiniciar contenedor por código de salida.

$ podman restart --filter exited=0

Reiniciar contenedor por estado.

$ podman restart --filter status=running

Reiniciar contenedor por imagen ancestral.

$ podman restart --filter ancestor=nginx

Reiniciar contenedores creados antes que otro.

$ podman restart --filter before=second

Reiniciar contenedores creados después que otro.

$ podman restart --filter since=first

Reiniciar contenedor por volumen.

$ podman restart --filter volume=vol-filter

Reiniciar contenedores en un pod.

$ podman restart --filter pod=mypod

Reiniciar contenedor por red.

$ podman restart --filter network=net-filter

Reiniciar contenedores creados hasta una hora.

$ podman restart --filter until=10s
