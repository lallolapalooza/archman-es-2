NOMBRE

podman-quadlet-rm - Elimina un quadlet instalado

SINOPSIS

podman quadlet rm [opciones] quadlet [quadlet]...

DESCRIPCIÓN

Elimina uno o más Quadlets instalados del usuario actual. El siguiente comando también toma el nombre de la aplicación como entrada y elimina todos los Quadlets que pertenecen a esa aplicación específica.

Nota: Si un quadlet forma parte de una aplicación, la eliminación de ese quadlet específico eliminará toda la aplicación. Cuando un quadlet se instala desde un directorio, todos los archivos instalados desde ese directorio —incluyendo archivos de quadlet y no de quadlet— se consideran parte de una única aplicación.

OPCIONES

--all, -a

Elimina todos los Quadlets para el usuario actual.

--force, -f

Elimina los quadlets en ejecución.

--ignore, -i

No genera error para los Quadlets que no existen.

--reload-systemd

Recarga systemd después de eliminar los Quadlets (valor predeterminado: true). Para deshabilitarlo, los usuarios deben establecer manualmente el valor de este indicador a false.

EJEMPLOS

$ podman quadlet rm myquadlet.container
myquadlet.container
