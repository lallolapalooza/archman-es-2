NOMBRE

postgis_restore - restaura una base de datos PostGIS desde un archivo de archivo creado por pg_dump

SINTAXIS

postgis_restore [-v] [-L TOC] [-s esquema] archivo_de_volcado

DESCRIPCIÓN

El comando postgis_restore permite extraer sentencias SQL para recrear objetos encontrados en un volcado personalizado de una base de datos habilitada para PostGIS, omitiendo los objetos específicos de PostGIS.

Esto solo es útil para volcados de bases de datos en las que PostGIS se habilitó cargando el script postgis.sql. Los volcados tomados de bases de datos en las que PostGIS se habilitó a través de CREATE EXTENSION no contendrán objetos PostGIS, por lo que se pueden restaurar directamente con pg_restore.

Tenga en cuenta que este comando solo funciona con volcados que utilizan el formato personalizado, que son los creados con pg_dump -Fc.

USO

La información de uso se imprime cuando se invoca el script sin argumentos.

EJEMPLOS

Crear un volcado personalizado de olddb:

pg_dump -Fc olddb > olddb.dump

Crear una nueva base de datos newdb:

createdb newdb

Habilitar PostGIS en la nueva base de datos:

psql -c 'CREATE EXTENSION postgis' newdb

Restaurar sus datos:

postgis_restore.pl olddb.dump | psql newdb
