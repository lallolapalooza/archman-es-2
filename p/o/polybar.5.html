POLYBAR(5) Manual de usuario de Polybar POLYBAR(5)

NOMBRE

polybar - archivo de configuración para polybar(1)

DESCRIPCIÓN

[nombre_seccion]
; Un comentario
# Otro comentario
background = #ff992a
width = 90%
monitor = HDMI-0
screenchange-reload = false
; Usa comillas dobles si quieres mantener el espacio circundante.
text = " Algún texto "

Cuando se inicia, polybar buscará el archivo de configuración en varios lugares en el siguiente orden:

  • Si se especifica el argumento de línea de comandos -c o --config, se utilizará la ruta indicada allí.
  • $XDG_CONFIG_HOME/polybar/config
  • $XDG_CONFIG_HOME/polybar/config.ini
  • $HOME/.config/polybar/config
  • $HOME/.config/polybar/config.ini
  • $XDG_CONFIG_DIRS/polybar/config.ini
  • /etc/xdg/polybar/config.ini (solo si XDG_CONFIG_DIRS no está configurado)
  • /etc/polybar/config.ini

SINTAXIS

Toda la configuración es por líneas, por lo que todo está limitado a una sola línea. Esto significa que no hay valores multilínea ni otras construcciones multilínea (excepto las secciones). Cada línea tiene uno de cuatro tipos:

  • Vacía
  • Comentario
  • Encabezado de sección
  • Clave

Los espacios al principio y al final de cada línea se ignorarán.

NOTA:

En este contexto, "espacios" incluyen el carácter de espacio normal, así como el carácter de tabulación y cualquier otro carácter para el cual isspace(3) devuelve true (por ejemplo, \r).

Cualquier línea que no se ajuste a uno de estos cuatro tipos es un error de sintaxis.

NOTA:

Se recomienda que los nombres de las secciones y los nombres de las claves solo utilicen caracteres alfanuméricos, así como guiones (-), guiones bajos (_) y barras diagonales (/).

En la práctica, se permiten todos los caracteres excepto los espacios y cualquiera de estos: "'=;#[](){}:.$\%

Encabezados de Sección

Las secciones se utilizan para agrupar opciones de configuración. Por ejemplo, cada módulo se define en su propia sección.

Una sección se define colocando el nombre de la sección entre corchetes ([ y ]). Por ejemplo:

[module/wm]

Esto declara una sección con el nombre module/wm y todas las claves definidas después de esta línea pertenecerán a esa sección hasta que se declare una nueva sección.

ADVERTENCIA:

La primera línea no vacía y no comentario en el archivo de configuración principal debe ser un encabezado de sección. No puede ser una clave porque esa clave no pertenecería a ninguna sección.

NOTA:

Los siguientes nombres de sección están reservados y no se pueden usar dentro de la configuración: self, root y BAR.

Claves

Las claves se definen asignando un valor a un nombre como este:

nombre = valor

Esto asigna valor a la clave nombre en la sección en la que se encuentre esta línea. Los nombres de clave deben ser únicos por sección. Si el valor está entre comillas dobles ("), las comillas se ignorarán. Por lo tanto, lo siguiente todavía asigna valor a nombre:

nombre = "valor"

Los espacios alrededor del signo igual se ignoran, los siguientes son todos equivalentes:

nombre=valor
nombre = valor
nombre =      valor

Dado que los espacios al principio y al final de la línea también se ignoran, si desea que su valor comience y/o termine con un espacio, el valor debe estar entre comillas dobles:

nombre = " valor "

Aquí el valor de la clave nombre tiene un espacio inicial y final.

Para tratar los caracteres con significado especial como caracteres literales, debe anteponerles el carácter de escape de barra invertida (\):

nombre = "valor\\valor\\valor"

El valor de esta clave nombre resulta en valor\valor\valor.

NOTA:

El único carácter con un significado especial en este momento es el carácter de barra invertida (\), que sirve como carácter de escape. Se añadirán más en el futuro.

Líneas Vacías & Comentarios

Las líneas vacías y las líneas de comentarios se ignoran al leer el archivo de configuración, no afectan el comportamiento de polybar. Las líneas de comentarios comienzan con el carácter ; o #.

NOTA:

Los comentarios en línea no son compatibles. Por ejemplo, la siguiente línea no termina con un comentario, el valor de nombre se establece en realidad en valor ; comentario: 
nombre = valor ; comentario
