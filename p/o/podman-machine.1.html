NOMBRE

podman-machine - Gestionar la máquina virtual de Podman

SINOPSIS

podman machine subcomando

DESCRIPCIÓN

podman machine es un conjunto de subcomandos que gestionan la máquina virtual de Podman.

Podman en MacOS y Windows requiere una máquina virtual. Esto se debe a que los contenedores son Linux; los contenedores no se ejecutan en ningún otro sistema operativo porque la funcionalidad principal de los contenedores está ligada al kernel de Linux. Podman machine debe usarse para gestionar máquinas MacOS y Windows, pero puede usarse opcionalmente en Linux.

Todos los comandos de podman machine son solo para usuarios sin privilegios (rootless).

NOTA: El archivo de configuración de podman-machine se gestiona en el directorio $XDG_CONFIG_HOME/containers/podman/machine/. Cambiar la variable de entorno $XDG_CONFIG_HOME mientras las máquinas están en ejecución puede provocar un comportamiento inesperado.

El comportamiento de Podman machine puede modificarse a través de la sección [machine] en el archivo containers.conf(5).
