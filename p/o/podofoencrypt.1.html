NOMBRE

podofoencrypt - cifra archivos PDF y establece la configuración de seguridad de PDF

SINOPSIS

podofoencrypt [--rc4v1] [--rc4v2] [--aes] [-u <contraseña_usuario>] -o <contraseña_propietario> <archivo_entrada> <archivo_salida>

DESCRIPCIÓN

podofoencrypt es una de las herramientas de línea de comandos de la biblioteca PoDoFo que proporciona varias operaciones útiles para trabajar con archivos PDF. Puede cifrar archivos PDF utilizando codificación RC4 o AES y puede establecer la configuración de seguridad de PDF.

OPCIONES

--help

Muestra el texto de ayuda

Algoritmo:

--rc4v1
Usa cifrado rc4v1

--rc4v2

Usa cifrado rc4v2 (Valor predeterminado)

--aes

Usa cifrado aes (actualmente no soportado)

Contraseñas:

-u <contraseña>
Una contraseña de usuario opcional

-o <contraseña>

La contraseña de propietario requerida

Permisos:

--print

Permite imprimir el documento

--edit

Permite la modificación del documento además de anotaciones, campos de formulario o cambio de páginas

--copy

Permite la extracción de texto y gráficos

--editnotes

Añadir o modificar anotaciones de texto o campos de formulario (si ePdfPermissions_Edit también está establecido, permite la creación de campos de formulario interactivos, incluida la firma)

--fillandsign

Rellena campos de formulario o de firma existentes

--accessible

Extrae texto y gráficos para ayudar a usuarios con discapacidades

--assemble

Ensambla el documento: inserta, crea, rota, elimina páginas o añade marcadores

--highprint

Imprime una versión de alta resolución del documento
