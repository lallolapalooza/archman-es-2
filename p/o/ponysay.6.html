PONYSAY(6) Manual de Juegos PONYSAY(6)

NOMBRE

ponysay - Reimplementación de Cowsay para ponis

SINOPSIS

ponysay [opciones] [--] [mensaje]
ponythink [opciones] [--] [mensaje]

DESCRIPCIÓN

ponysay muestra una imagen de un poni diciendo un texto proporcionado por el usuario en una terminal. Si no se proporciona mensaje, acepta la entrada estándar, envuelve el mensaje dado en aproximadamente 60 columnas y muestra al poni diciendo el mensaje dado en la salida estándar.

Si no se proporcionan argumentos, el programa solo acepta la entrada estándar dirigida desde otro programa, un archivo o mediante here documents o here strings (ver bash(1) para más detalles sobre here document/string.)

ponythink es para ponysay lo que cowthink es para cowsay.

Para una documentación extensa, ejecuta `info ponysay`.

OPCIONES

A continuación se incluye un resumen de las opciones.

-h, --help
Muestra el resumen de opciones.
-v, --version
Muestra la versión del programa.
-f, --file, --pony nombre
Selecciona un poni (ya sea un nombre de archivo o un nombre de poni), puedes usar esta opción varias veces, y uno de ellos será seleccionado al azar.
+f, ++file, ++pony nombre
Selecciona un poni fuera de My Little Pony: Friendship is Magic (ya sea un nombre de archivo o un nombre de poni), puedes usar estas opciones varias veces, y uno de ellos será seleccionado al azar.
-F, --any-file, --anyfile, --anypony --any-pony nombre
Esta opción combina -f y +f.
--f, --files, --ponies [nombre...]
Variante variádica de -f, lo que significa que todos los argumentos añadidos después de este serán analizados como un argumento para esta opción.
++f, ++files, ++ponies [nombre...]
Variante variádica de +f, lo que significa que todos los argumentos añadidos después de este serán analizados como un argumento para esta opción.
--F, --any-files, --anyfiles, --anyponies --any-ponies nombre
Esta opción combina --f y ++f.
-q, --quote [nombre...]
Usando esta opción, se imprimirá un poni con citas de su personaje en My Little Pony: Friendship is Magic. El poni se seleccionará al azar, a menos que se añada al menos un poni como argumento a -q. Si se añaden más de un poni como argumento a -q, el poni se seleccionará al azar de ese conjunto de ponis.
--q, --quotes [nombre...]
Variante variádica de -q, lo que significa que todos los argumentos añadidos después de este serán analizados como un argumento para esta opción. Adicionalmente, esas opciones se añaden a -q.
-b, --bubble, --balloon estilo
Especifica el estilo de globo que debe usarse, este puede ser un nombre de archivo o un nombre de globo impreso por ponysay -B.
-W, --wrap columna
La columna de la pantalla donde se debe ajustar el mensaje, teniendo en cuenta el ancho adicional del globo. Si el argumento no es un número, sino que empieza con n, no se realiza ajuste, y si empieza con i se usa el ancho de la terminal.
-c, --compress, --compact [color-ANSI]
Comprime el mensaje de la misma manera que lo hace cowsay, es decir, básicamente sin espacios múltiples y solo separaciones de párrafos.
-l, --list
Lista los archivos de ponis.
-L, --symlist, --altlist
Lista los archivos de ponis con nombres alternativos entre corchetes.
+l, ++list
Lista los archivos de ponis que no son de MLP:FiM.
+L, ++symlist, ++altlist
Lista los archivos de ponis que no son de MLP:FiM con nombres alternativos entre corchetes.
-B, --bubblelist, --balloonlist estilo
Imprime una lista de todos los estilos de globo.
-A, --all
Lista todos los archivos de ponis, tanto de MLP:FiM como no-MLP:FiM, en este caso la primera lista son de MLP:FiM y la segunda de no-MLP:FiM.
+A, ++all, --symall, --altall
Lista todos los archivos de ponis, incluyendo nombres alternativos entre corchetes, los de MLP:FiM y los no-MLP:FiM; la primera lista son los de MLP:FiM y la segunda los no-MLP:FiM.
-o, --pony-only, --ponyonly
Solo imprime el poni, nada más como el globo de diálogo.
-i, --info
Al añadir esta bandera se obtendrá metadatos de un poni impresos, en lugar del poni mismo.
+i, ++info
Esto funciona igual que la opción -i, excepto que el poni usará la salida como su mensaje en lugar de simplemente imprimir esa información.
-r, --restriction
Esta opción se utiliza para restringir qué ponis pueden ser seleccionados aleatoriamente basándose en sus metadatos. Un valor en el argumento es una combinación del nombre de la etiqueta y el valor de la etiqueta en formato NOMBRE=VALOR.
-X, --256-colours, --256colours, --x-colours
Usa el soporte de 256 colores de xterm (soportado por la mayoría de las terminales X11), independientemente de las compatibilidades reales de tu terminal.
-V, --tty-colours, --ttycolours, --vt-colours
Usa las compatibilidades de VT (Linux) sin utilización de KMS, independientemente de las compatibilidades reales de tu terminal.
-K, --kms-colours, --kmscolours
Usa las compatibilidades de VT (Linux) con utilización de KMS, independientemente de las compatibilidades reales de tu terminal. (Puede que no funcione con todas las tarjetas gráficas KMS)
+c, --colour [color-ANSI]
Colorea el globo, incluyendo el enlace y el mensaje. Para más funciones de coloreado, consulta el manual de info. El argumento, color-ANSI, debe ser una secuencia de color ANSI sin el CSI inicial y sin la 'm' final, por ejemplo, 1;31 lo pondrá en rojo y en negrita (o brillante dependiendo de la terminal).
--colour-bubble, --colour-balloon [color-ANSI]
Igual que --colour, pero solo colorea el globo, sin el mensaje ni el enlace.
--colour-link [color-ANSI]
Igual que --colour, pero solo colorea el enlace del globo.
--colour-msg, --colour-message [color-ANSI]
Igual que --colour, pero solo colorea el mensaje.
--colour-pony [color-ANSI]
Igual que --colour, pero colorea el poni. Este coloreado no tiene efecto en los archivos de ponis regulares, ya que estos tienen su propio coloreado.
--colour-wrap, --colour-hyphen [color-ANSI]
Igual que --colour, pero colorea el guion añadido por el ajuste de línea. Si quieres sin color usa 0, el valor por defecto es 31.

ponysay(6) — Arch Linux manual pages

NAME

ponysay — prints a message from a pony

SYNOPSIS

ponysay [OPTION...] [PONY] [BALLOON_STYLE]

ponysay [OPTION...] [-f FILE]

DESCRIPTION

ponysay is a program that prints a message from a pony, similar to cowsay(1). It is distributed with a set of pony ASCII art and balloon styles. See ponysay-tool(6) for more information on managing these.

OPTIONS

-f, --file FILE
Use the pony from FILE. This can be used to specify a custom pony artwork file.
-l, --list
List all available ponies.
-b, --list-styles
List all available balloon styles.
-e, --eyes EYES
Use EYES instead of the default eyes in the pony graphic. For example, -e ^^.
-t, --think
Make the pony think instead of speaking. This changes the speech balloon to a thought balloon.
-n, --no-wrap
Do not wrap the message. This will print the message on a single line, potentially causing it to extend beyond the terminal width.
-W, --width MAX_WIDTH
Wrap the message lines to be at most MAX_WIDTH characters long. Default is 80 characters.
-p, --pony PONY
Use the specified PONY artwork. Use -l to list available ponies.
-S, --style BALLOON_STYLE
Use the specified BALLOON_STYLE. Use -b to list available styles.
-L, --less-sound
Use less blank lines when printing the pony and message.
-h, --help
Show a help message and exit.
-v, --version
Print version information and exit.

ENVIRONMENT

PONYSAY_SHELL_LINES
You can export PONYSAY_SHELL_LINES with the value of how many blank lines you want.
PONYSAY_FULL_WIDTH
You can export PONYSAY_FULL_WIDTH with the value yes, y or 1, if you do not want the output to be truncated on the width to fit the terminal.
PONYSAY_TRUNCATE_HEIGHT
Export PONYSAY_TRUNCATE_HEIGHT with the value yes, y or 1, if you want to truncate the output on the height even if you are not running ponysay under TTY.
PONYSAY_UCS_ME
Export PONYSAY_UCS_ME with the value yes, y or 1, if you want [simulated] symlink to pony files using Universal Character Set in their names.
PONYSAY_KMS_PALETTE, PONYSAY_KMS_PALETTE_CMD
PONYSAY_KMS_PALETTE or PONYSAY_KMS_PALETTE_CMD is used to tell ponysay how your TTY palette looks, this feature lets you get the best images in TTY if you have Kernel Mode Setting (KMS) support.
PONYSAY_TYPO_LIMIT
ponysay is able to auto-correct misspelled pony names and balloon style name. Without consideration for transpositioning, by default if the weighted distance is greater than 5 for the closest words, auto-correction ignored. This limit can be changed by exporting the limit to PONYSAY_TYPO_LIMIT; setting the limit to zero will disable auto-correction.
PONYSAY_WRAP_HYPHEN
You can export what ponysay should use instead of a hyphen when wrapping messages.
PONYSAY_WRAP_LIMIT
Defines how long a word must be to be hyphenated. This is used to wrap words that are long so the output gets as pretty as possible. This is not the only condition under which a word can be hyphenated, it can also be hyphenated if the word cannot fit otherwise.
PONYSAY_WRAP_EXCEED
Defines how much a word must exceed the wrapping point to be hyphenated. This setting is used together with PONYSAY_WRAP_LIMIT.

BUG

Bugs can be reported in https://github.com/erkin/ponysay/issues.
