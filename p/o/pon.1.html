PON(1) PPPD de Debian PON(1)

NOMBRE

pon, poff, plog - inicia, cierra o lista el registro de conexiones PPP

SINOPSIS

pon [ nombre-isp [ opciones ] ]
poff [ -r ] [ -d ] [ -c ] [ -a ] [ -h ] [ nombre-isp ]
plog [ argumentos ]

DESCRIPCION

Esta página del manual describe los scripts pon, plog y poff, que permiten a los usuarios controlar las conexiones PPP.

pon

pon, invocado sin argumentos, ejecuta el archivo /etc/ppp/ppp_on_boot, si existe y es ejecutable. De lo contrario, se iniciará una conexión PPP utilizando la configuración de /etc/ppp/peers/provider. Este es el comportamiento predeterminado a menos que se proporcione un argumento nombre-isp.

Por ejemplo, para usar la configuración de ISP "miisp", ejecute:

pon miisp

pon utilizará entonces el archivo de opciones /etc/ppp/peers/miisp. También puede pasar opciones adicionales después del nombre del ISP. pon se puede utilizar para ejecutar múltiples conexiones PPP simultáneas.

poff

poff cierra una conexión PPP. Si existe más de una conexión PPP, la que se nombre en el argumento de poff será terminada, por ejemplo:

poff mi-proveedor2

terminará la conexión a mi-proveedor2, y dejará las conexiones PPP a, por ejemplo, "mi-proveedor1" o "mi-proveedor3" activas.

poff acepta las siguientes opciones de línea de comandos:

-r
provoca que la conexión se vuelva a marcar después de ser desconectada.
-d
alterna el estado de la opción de depuración de pppd.
-c
provoca que pppd(8) renegocie la compresión.
-a
detiene todas las conexiones ppp en ejecución. Si se proporciona el argumento nombre-isp, se ignorará.
-h
muestra información de ayuda.
-v
imprime la versión y sale.

Si no se proporciona ningún argumento, poff detendrá o señalará pppd si y solo si hay exactamente una conexión en ejecución. Si hay más de una conexión activa, saldrá con un código de error de 1.

plog

plog le muestra las últimas líneas de /var/log/ppp.log. Si ese archivo no existe, le muestra las últimas líneas de su archivo /var/log/syslog, pero excluyendo las líneas no generadas por pppd. Este script utiliza el comando tail(1), por lo que los argumentos que se pueden pasar a tail(1) también se pueden pasar a plog.

Nota: el script plog solo puede ser utilizado por root u otro administrador del sistema del grupo "adm", por razones de seguridad. Además, para tener toda la información generada por pppd en un solo archivo de registro que plog pueda mostrar, necesita la siguiente línea en su archivo /etc/syslog.conf:

local2.* -/var/log/ppp.log

ARCHIVOS

/etc/ppp/options
Archivo de opciones del sistema PPPd.
/etc/ppp/pap-secrets
Archivo de contraseñas PAP del sistema.
/etc/ppp/chap-secrets
Archivo de contraseñas CHAP del sistema.
/etc/ppp/peers/
Directorio que contiene los archivos de opciones de pares. El archivo predeterminado se llama provider.
/etc/chatscripts/provider
El script de chat invocado desde el predeterminado /etc/ppp/peers/provider.
/var/log/ppp.log
El archivo de registro PPP predeterminado.
