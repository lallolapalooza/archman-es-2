NOMBRE

po2xml - Traduce un archivo XML de DocBook usando un archivo PO

SINOPSIS

po2xml [XML-original PO-traducido]

DESCRIPCIÓN

po2xml es una herramienta de línea de comandos que traduce el archivo XML de DocBook XML-original utilizando el archivo de mensajes gettext PO-traducido. El archivo XML traducido resultante se envía a la salida estándar.

Esta utilidad forma parte del Kit de Desarrollo de Software de KDE.

VER TAMBIÉN

split2po(1), swappo(1), xml2pot(1)
