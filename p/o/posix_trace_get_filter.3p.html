POSIX_TRACE_GET_FILTER(3P) Manual del programador POSIX POSIX_TRACE_GET_FILTER(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_trace_get_filter, posix_trace_set_filter — recuperar y establecer el filtro de un flujo de rastreo inicializado (TRACING)

SINOPSIS

#include <trace.h>
int posix_trace_get_filter(trace_id_t trid, trace_event_set_t *set);
int posix_trace_set_filter(trace_id_t trid,
    const trace_event_set_t *set, int how);

DESCRIPCIÓN

La función posix_trace_get_filter() recuperará, en el argumento apuntado por set, el filtro de eventos de rastreo real del flujo de rastreo especificado por trid.

La función posix_trace_set_filter() cambiará el conjunto de tipos de eventos de rastreo filtrados después de que se cree un flujo de rastreo identificado por el argumento trid. Esta función puede ser llamada antes de iniciar el flujo de rastreo, o mientras el flujo de rastreo está activo. Por defecto, si no se realiza ninguna llamada a posix_trace_set_filter(), se registrarán todos los eventos de rastreo (es decir, no se filtrará ninguno de los tipos de eventos de rastreo).

Si se llama a esta función mientras el rastreo está en curso, se registrará un evento de rastreo del sistema especial, POSIX_TRACE_FILTER, en el rastreo indicando los conjuntos antiguo y nuevo de tipos de eventos de rastreo filtrados (véase la Tabla 2-4, Opciones de filtrado de eventos de rastreo y rastreo: Eventos de rastreo del sistema y la Tabla 2-6, Opciones de filtrado de eventos de rastreo, registro de rastreo y rastreo: Eventos de rastreo del sistema).

Si la función posix_trace_set_filter() es interrumpida por una señal, se devolverá un error y el filtro no se cambiará. En este caso, el estado del flujo de rastreo no se modificará.

El valor del argumento how indica la forma en que se debe cambiar el conjunto y tendrá uno de los siguientes valores, según se define en la cabecera <trace.h>:

POSIX_TRACE_SET_EVENTSET

El conjunto resultante de tipos de eventos de rastreo que se filtrarán será el conjunto de tipos de eventos de rastreo apuntado por el argumento set.
POSIX_TRACE_ADD_EVENTSET

El conjunto resultante de tipos de eventos de rastreo que se filtrarán será la unión del conjunto actual y el conjunto de tipos de eventos de rastreo apuntado por el argumento set.
POSIX_TRACE_SUB_EVENTSET

El conjunto resultante de tipos de eventos de rastreo que se filtrarán serán todos los tipos de eventos de rastreo del conjunto actual que no estén en el conjunto apuntado por el argumento set; es decir, eliminar cada elemento del conjunto especificado del filtro actual.

VALOR DE RETORNO

Al completarse con éxito, estas funciones devolverán un valor de cero. De lo contrario, devolverán el número de error correspondiente.

La función posix_trace_get_filter() almacena el conjunto de tipos de eventos de rastreo filtrados en set, si tiene éxito.

ERRORES

Estas funciones fallarán si:

EINVAL
El valor del argumento trid no corresponde a un flujo de rastreo activo o el valor del argumento apuntado por set es inválido.
EINTR
La operación fue interrumpida por una señal.
