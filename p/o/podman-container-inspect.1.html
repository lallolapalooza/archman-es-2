NOMBRE

podman-container-inspect - Mostrar la configuración de un contenedor

SINOPSIS

podman container inspect [opciones] contenedor [contenedor ...]

DESCRIPCIÓN

Esto muestra la información de bajo nivel de los contenedores identificados por nombre o ID. Por defecto, esto representa todos los resultados en una matriz JSON. Si se especifica un formato, se ejecuta la plantilla dada para cada resultado.

OPCIONES

--format, -f=formato

Formatea la salida usando la plantilla Go dada. Las claves del JSON devuelto pueden ser usadas como los valores para la opción --format (ver ejemplos más abajo).

Los marcadores válidos para la plantilla Go se listan a continuación:

Marcador Descripción
.AppArmorProfile Perfil de AppArmor (cadena)
.Args Argumentos de línea de comandos (matriz de cadenas)
.BoundingCaps Conjunto de capacidades de límite (matriz de cadenas)
.Config ... Estructura con información de configuración
.ConmonPidFile Ruta al archivo que contiene el PID de conmon (cadena)
.Created ... Tiempo de creación del contenedor (cadena, ISO3601)
.Dependencies Dependencias (matriz de cadenas)
.Driver Controlador de almacenamiento (cadena)
.EffectiveCaps Conjunto de capacidades efectivas (matriz de cadenas)
.ExecIDs IDs de ejecución (matriz de cadenas)
.GraphDriver ... Detalles adicionales del controlador de gráficos (struct)
.HostConfig ... Detalles de configuración del host (struct)
.HostnamePath Ruta al archivo que contiene el hostname (cadena)
.HostsPath Ruta al archivo /etc/hosts del contenedor (cadena)
.ID ID del contenedor (hash completo de 64 caracteres)
.Image ID de la imagen del contenedor (hash de 64 caracteres)
.ImageDigest Digest de la imagen del contenedor (sha256:+hash de 64 caracteres)
.ImageName Nombre de la imagen del contenedor (cadena)
.IsInfra ¿Es este un contenedor de infraestructura? (cadena: true/false)
.IsService ¿Es este un contenedor de servicio? (cadena: true/false)
.KubeExitCodePropagation Propagación del código de salida de Kube (cadena)
.LockNumber Número del bloqueo de contenedor de Libpod
.MountLabel Etiqueta SELinux del montaje (cadena)
.Mounts Montajes (matriz de cadenas)
.Name Nombre del contenedor (cadena)
.Namespace Namespace del contenedor (cadena)
.NetworkSettings ... Configuración de red (struct)
.OCIConfigPath Ruta al archivo de configuración OCI (cadena)
.OCIRuntime Nombre del runtime OCI (cadena)
.Path Ruta al comando del contenedor (cadena)
.PidFile Ruta al archivo que contiene el PID del contenedor (cadena)
.Pod Pod padre (cadena)
.ProcessLabel Etiqueta SELinux del proceso (cadena)
.ResolvConfPath Ruta al archivo resolv.conf del contenedor (cadena)
.RestartCount Número de veces que el contenedor ha sido reiniciado (int)
.Rootfs Rootfs del contenedor (cadena)
.SizeRootFs Tamaño del rootfs, en bytes [1]
.SizeRw Tamaño de la capa superior (R/W) del contenedor, en bytes [1]
.State ... Información del estado del contenedor (struct)
.StaticDir Ruta al directorio de metadatos del contenedor (cadena)
.UseImageHostname ¿Usar /etc/hostname de la imagen si existe? (cadena: true/false)
.UseImageHosts ¿Usar /etc/hosts de la imagen? (cadena: true/false)

[1] Este especificador de formato requiere la opción --size

--latest, -l

En lugar de proporcionar el nombre o ID del contenedor, use el último contenedor creado. Nota: el último contenedor iniciado puede ser de otros usuarios de Podman en la máquina host. (Esta opción no está disponible con el cliente remoto de Podman, incluidas las máquinas Mac y Windows (excepto WSL2)).

--size, -s

Además de la salida normal, muestra el tamaño total del archivo si el tipo es un contenedor.

$ podman container inspect --format='{{.Name}} {{.Id}}' foobar
/foobar 99f66530fe9c7249f7cf29f78e8661669d5831cbe4ee80ea757d5e922dd6a8a6

Muestra el nombre del contenedor y su estado.

$ podman container inspect --format='{{.Name}} {{.State.Status}}' foobar
/foobar running

Inspeccione el contenedor especificado para ver el nombre de la imagen en la que se basa.

$ podman container inspect nervous_fermi --format "{{.ImageName}}"
registry.access.redhat.com/ubi8:latest

Inspeccione el contenedor especificado para ver el nombre de GraphDriver con el que se está ejecutando.

$ podman container inspect foobar --format "{{.GraphDriver.Name}}"
overlay

Inspeccione el último contenedor creado para su campo EffectiveCaps. (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

$ podman container inspect --latest --format {{.EffectiveCaps}}
[CAP_CHOWN CAP_DAC_OVERRIDE CAP_FOWNER CAP_FSETID CAP_KILL CAP_NET_BIND_SERVICE CAP_SETFCAP CAP_SETGID CAP_SETPCAP CAP_SETUID]
