NOMBRE

podman-artifact-pull - Descarga un artefacto de un registro y lo almacena localmente

SINOPSIS

podman artifact pull [opciones] fuente

DESCRIPCIÓN

podman artifact pull copia un artefacto de un registro a la máquina local.

FUENTE

FUENTE es la ubicación desde la cual se obtiene la imagen del artefacto.

# Descargar desde un registro
$ podman artifact pull quay.io/foobar/artifact:special

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux, y $HOME/.config/containers/auth.json en Windows/macOS. El archivo se crea con podman login. Si no se encuentra el estado de autorización allí, se verifica $HOME/.docker/config.json, que se establece usando docker login.

Nota: También existe la opción de anular la ruta predeterminada del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--cert-dir=ruta

Utiliza certificados en ruta (*.crt, *.cert, *.key) para conectarse al registro. (Predeterminado: /etc/containers/certs.d) Para obtener detalles, consulta containers-certs.d(5). (Esta opción no está disponible con el cliente Podman remoto, incluidas las máquinas Mac y Windows (excluyendo WSL2))

--creds=[nombredeusuario[:contraseña]]

El [nombredeusuario[:contraseña]] a utilizar para autenticarse con el registro, si es necesario. Si no se proporcionan uno o ambos valores, aparece una indicación en la línea de comandos y se puede introducir el valor. La contraseña se introduce sin eco.

Ten en cuenta que las credenciales especificadas solo se utilizan para autenticarse en los registros de destino. No se utilizan para espejos ni cuando se reescribe el registro (ver containers-registries.conf(5)); para autenticarse en ellos, considera usar un archivo containers-auth.json(5).

--decryption-key=clave[:contraseña]

La [clave[:contraseña]] que se utilizará para descifrar imágenes. La clave puede apuntar a claves y/o certificados. Se intenta el descifrado con todas las claves. Si la clave está protegida por una contraseña, esta debe pasarse en el argumento y omitirse en caso contrario.

--help, -h

Imprime la declaración de uso.

--quiet, -q

Suprime la información de salida al descargar imágenes

--retry=intentos

Número de veces que se intentará descargar o subir imágenes entre el registro y el almacenamiento local en caso de fallo. El valor predeterminado es 3.

--retry-delay=duración

Duración del retraso entre intentos de reintento al descargar o subir imágenes entre el registro y el almacenamiento local en caso de fallo. El valor predeterminado es comenzar con dos segundos y luego aumentar exponencialmente. El retraso se utiliza cuando se establece este valor y no se produce ningún retroceso exponencial.

--tls-verify

Requiere HTTPS y verifica los certificados al contactar los registros (predeterminado: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino figure como un registro inseguro en containers-registries.conf(5)
