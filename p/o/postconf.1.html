POSTCONF(1) Manual de comandos generales POSTCONF(1)

NOMBRE

postconf - Utilidad de configuración de Postfix

SINOPSIS

Gestión de main.cf:

postconf [-dfhHnopqvx] [-c directorio_config] [-C clase,...] [parámetro ...]

postconf [-epv] [-c directorio_config] parámetro=valor ...

postconf -# [-pv] [-c directorio_config] parámetro ...

postconf -X [-pv] [-c directorio_config] parámetro ...

Gestión de entradas de servicio de master.cf:

postconf -M [-foqvx] [-c directorio_config] [servicio[/tipo] ...]

postconf -M [-ev] [-c directorio_config] servicio/tipo=valor ...

postconf -M# [-v] [-c directorio_config] servicio/tipo ...

postconf -MX [-v] [-c directorio_config] servicio/tipo ...

Gestión de campos de servicio de master.cf:

postconf -F [-fhHoqvx] [-c directorio_config] [servicio[/tipo[/campo]] ...]

postconf -F [-ev] [-c directorio_config] servicio/tipo/campo=valor ...

Gestión de parámetros de servicio de master.cf:

postconf -P [-fhHoqvx] [-c directorio_config] [servicio[/tipo[/parámetro]] ...]

postconf -P [-ev] [-c directorio_config] servicio/tipo/parámetro=valor ...

postconf -PX [-v] [-c directorio_config] servicio/tipo/parámetro ...

Gestión de plantillas de mensajes de rebote:

postconf -b [-v] [-c directorio_config] [archivo_plantilla]

postconf -t [-v] [-c directorio_config] [archivo_plantilla]

Gestión de características TLS:

postconf -T modo [-v] [-c directorio_config]

Gestión de otra configuración:

postconf -a|-A|-l|-m [-v] [-c directorio_config]

DESCRIPCIÓN


Por defecto, el comando postconf(1) muestra los valores de los parámetros de configuración de main.cf, y advierte sobre posibles nombres de parámetros mal escritos (Postfix 2.9 y posteriores). El comando también puede cambiar los valores de los parámetros de configuración de main.cf, o mostrar otra información de configuración sobre el sistema de correo Postfix.

Opciones:

-a
Lista los tipos de plugin SASL disponibles para el servidor SMTP de Postfix. El tipo de plugin se selecciona con el parámetro de configuración smtpd_sasl_type especificando uno de los nombres listados a continuación.
cyrus
Este plugin del servidor está disponible cuando Postfix se compila con soporte Cyrus SASL.
dovecot
Este plugin del servidor utiliza el servidor de autenticación Dovecot, y está disponible cuando Postfix se compila con cualquier forma de soporte SASL.
Esta característica está disponible con Postfix 2.3 y posteriores.
-A
Lista los tipos de plugin SASL disponibles para el cliente SMTP de Postfix. El tipo de plugin se selecciona con los parámetros de configuración smtp_sasl_type o lmtp_sasl_type especificando uno de los nombres listados a continuación.
cyrus
Este plugin del cliente está disponible cuando Postfix se compila con soporte Cyrus SASL.
Esta característica está disponible con Postfix 2.3 y posteriores.
-b [archivo_plantilla]
Muestra el texto del mensaje que aparece al principio de los mensajes de notificación de estado de entrega (DSN), expandiendo las expresiones $nombre con valores reales como se describe en bounce(5).

Para anular la configuración del parámetro bounce_template_file, especifique un nombre de archivo de plantilla al final de la línea de comandos de "postconf -b". Especifique un nombre de archivo vacío para mostrar las plantillas integradas (en lenguaje de shell: "").

Esta característica está disponible con Postfix 2.3 y posteriores.

-c directorio_config
El archivo de configuración main.cf se encuentra en el directorio especificado en lugar del directorio de configuración predeterminado.
-C clase,...
Al mostrar los parámetros de main.cf, seleccione solo los parámetros de las clases especificadas:
builtin
Parámetros con nombres integrados.
service
Parámetros con nombres definidos por el servicio (el primer campo de una entrada de master.cf más un sufijo definido por Postfix).
user
Parámetros con nombres definidos por el usuario.
all
Todas las clases anteriores.
El valor predeterminado es como si se especificara "-C all".

Esta característica está disponible con Postfix 2.9 y posteriores.

-d
Imprime la configuración predeterminada de los parámetros de main.cf en lugar de la configuración real. Especifique -df para plegar líneas largas para facilitar la lectura humana (Postfix 2.9 y posteriores).
-e
Edita el archivo de configuración main.cf y actualiza la configuración de los parámetros con los pares "nombre=valor" en la línea de comandos de postconf(1).

Con -M, edita el archivo de configuración master.cf y reemplaza una o más entradas de servicio con nuevos valores especificados con "servicio/tipo=valor" en la línea de comandos de postconf(1).

Con -F, edita el archivo de configuración master.cf y reemplaza uno o más campos de servicio con nuevos valores especificados con "servicio/tipo/campo=valor" en la línea de comandos de postconf(1). Actualmente, el campo "comando" contiene el nombre del comando y sus argumentos. Esto puede cambiar en un futuro próximo, para que el campo "comando" contenga solo el nombre del comando, y un nuevo pseudocampo "argumentos" contenga los argumentos del comando.

Con -P, edita el archivo de configuración master.cf y agrega o actualiza una o más configuraciones de parámetros de servicio (-o parámetro=valor) con nuevos valores especificados con "servicio/tipo/parámetro=valor" en la línea de comandos de postconf(1).

En todos los casos, el archivo se copia a un archivo temporal y luego se renombra. Especifique comillas para proteger caracteres especiales y espacios en blanco en la línea de comandos de postconf(1).

La opción -e ya no es necesaria con Postfix versión 2.8 y posteriores, ya que se asume cada vez que se especifica un valor (vacío o no vacío).

-f
Plegar líneas largas al imprimir entradas del archivo de configuración de main.cf o master.cf, para facilitar la lectura humana.

Esta característica está disponible con Postfix 2.9 y posteriores.

-F
Mostrar la configuración de campos por entrada de master.cf (por defecto todos los servicios y todos los campos), formateado como "servicio/tipo/campo=valor", uno por línea. Especifique -Ff para plegar líneas largas.

Especifique una o más instancias de "servicio/tipo/campo" en la línea de comandos de postconf(1) para

o limitar la salida a campos de interés. Los campos de nombre de parámetro o tipo de servicio finales que se omitan se tratarán como campos comodín ""*"".

Esta función está disponible con Postfix 2.11 y versiones posteriores.

-h
Muestra los valores de los parámetros o atributos sin la etiqueta "nombre=" que normalmente precede al valor.
-H
Muestra los nombres de los parámetros o atributos sin el "= valor" que normalmente sigue al nombre.

Esta función está disponible con Postfix 3.1 y versiones posteriores.

-l
Enumera los nombres de todos los métodos de bloqueo de buzón admitidos. Postfix admite los siguientes métodos:
flock
Un método de bloqueo consultivo basado en el kernel solo para archivos locales. Este método de bloqueo está disponible en sistemas con una biblioteca compatible con BSD.
fcntl
Un método de bloqueo consultivo basado en el kernel para archivos locales y remotos.
dotlock
Un método de bloqueo a nivel de aplicación. Una aplicación bloquea un archivo llamado nombre_archivo creando un archivo llamado nombre_archivo.lock. Se espera que la aplicación elimine su propio archivo de bloqueo, así como los archivos de bloqueo obsoletos que quedaron después de una terminación anormal del programa.
-m
Enumera los nombres de todos los tipos de tablas de consulta admitidos. En los archivos de configuración de Postfix, las tablas de consulta se especifican como tipo:nombre, donde tipo es uno de los tipos enumerados a continuación. La sintaxis del nombre de la tabla depende del tipo de tabla de consulta, como se describe en el documento DATABASE_README.
btree
Una estructura de árbol ordenada y equilibrada. Disponible en sistemas con soporte para bases de datos Berkeley DB.
cdb
Una estructura optimizada para lectura sin soporte para actualizaciones incrementales. Disponible en sistemas con soporte para bases de datos CDB.

Esta función está disponible con Postfix 2.2 y versiones posteriores.

cidr
Una tabla que asocia valores con patrones de Classless Inter-Domain Routing (CIDR). Esto se describe en cidr_table(5).

Esta función está disponible con Postfix 2.2 y versiones posteriores.

dbm
Un tipo de archivo indexado basado en hashing. Disponible en sistemas con soporte para bases de datos DBM.
environ
El array de entorno del proceso UNIX. La clave de consulta es el nombre de la variable de entorno; se ignora el nombre de la tabla. Implementado originalmente para pruebas, alguien podría encontrarlo útil algún día.
fail
Una tabla que falla de forma fiable todas las solicitudes. El nombre de la tabla de consulta se utiliza para el registro. Esta tabla existe para simplificar las pruebas de errores de Postfix.

Esta función está disponible con Postfix 2.9 y versiones posteriores.

hash
Un tipo de archivo indexado basado en hashing. Disponible en sistemas con soporte para bases de datos Berkeley DB.
inline (solo lectura)
Una tabla de consulta en memoria no compartida. Ejemplo: "inline:{ clave=valor, { clave = texto con espacios o coma }}". Los pares clave-valor están separados por espacios o comas; con un par clave-valor dentro de "{}", se ignoran los espacios después de la abertura "{", alrededor del "=" entre la clave y el valor, y antes del cierre "}". Las tablas en línea eliminan la necesidad de crear un archivo de base de datos solo para unos pocos elementos fijos. Consulte también el tipo de mapa static:.

Esta función está disponible con Postfix 3.0 y versiones posteriores.

internal
Una tabla hash en memoria no compartida. Su contenido se pierde cuando un proceso termina.
lmdb
Base de datos LMDB de OpenLDAP (un archivo persistente mapeado en memoria). Disponible en sistemas con soporte para bases de datos LMDB. Esto se describe en lmdb_table(5).

Esta función está disponible con Postfix 2.11 y versiones posteriores.

ldap (solo lectura)
Cliente de base de datos LDAP. Esto se describe en ldap_table(5).
memcache
Cliente de base de datos Memcache. Esto se describe en memcache_table(5).

Esta función está disponible con Postfix 2.9 y versiones posteriores.

mongodb
Cliente de base de datos MongoDB. Esto se describe en mongodb_table(5).

Esta función está disponible con Postfix 3.9 y versiones posteriores.

mysql (solo lectura)
Cliente de base de datos MySQL. Disponible en sistemas con soporte para bases de datos MySQL. Esto se describe en mysql_table(5).
pcre (solo lectura)
Una tabla de consulta basada en expresiones regulares compatibles con Perl. El formato del archivo se describe en pcre_table(5).
pgsql (solo lectura)
Cliente de base de datos PostgreSQL. Esto se describe en pgsql_table(5).

Esta función está disponible con Postfix 2.1 y versiones posteriores.

pipemap (solo lectura)
Una tabla de consulta que construye una tubería de tablas. Ejemplo: "pipemap:{tipo_1:nombre_1, ..., tipo_n:nombre_n}". Cada consulta "pipemap:" se entrega a la primera tabla. Cada resultado de consulta se convierte en la consulta para la siguiente tabla en la tubería, y la última tabla produce el resultado final. Cuando la consulta de cualquier tabla no produce resultado, la tubería no produce resultado. El primer y último carácter del nombre de la tabla "pipemap:" deben ser "{" y "}". Dentro de estos, los mapas individuales se separan con una coma o un espacio en blanco.

Esta función está disponible con Postfix 3.0 y versiones posteriores.

proxy
Cliente Postfix proxymap(8) para acceso compartido a bases de datos Postfix. La sintaxis del nombre de la tabla es tipo:nombre.

Esta función está disponible con Postfix 2.0 y versiones posteriores.

randmap (solo lectura)
Una tabla en memoria que realiza una selección aleatoria. Ejemplo: "randmap:{resultado_1, ..., resultado_n}". Cada consulta de tabla devuelve una opción aleatoria de los resultados especificados. El primer y último carácter del nombre de la tabla "randmap:" deben ser "{" y "}". Dentro de estos, los resultados individuales se separan con una coma o un espacio en blanco. Para dar a un resultado específico más peso, especifíquelo varias veces.

Esta función está disponible con Postfix 3.0 y versiones posteriores.

regexp (solo lectura)
Una tabla de consulta basada en expresiones regulares. El formato del archivo se describe en regexp_table(5).
sdbm
Un tipo de archivo indexado basado en hashing. Disponible en sistemas con soporte para bases de datos SDBM.

Esta función está disponible con Postfix 2.2 y versiones posteriores.

socketmap (solo lectura)
Cliente socketmap estilo Sendmail. El nombre de la tabla es inet:host:puerto:nombre para un servidor TCP/IP, o unix:ruta_archivo:nombre para un servidor de dominio UNIX. Esto se describe en socketmap_table(5).

Esta función está disponible con Postfix 2.10 y versiones posteriores.

sqlite (solo lectura)
Base de datos SQLite. Esto se describe en sqlite_table(5).

Esta función está disponible con Postfix 2.8 y versiones posteriores.

static (solo lectura)
Una tabla que siempre devuelve su nombre como resultado de consulta. Por ejemplo, static:foobar siempre devuelve la cadena foobar como resultado de consulta. Especifique "static:{ texto con espacios }" cuando el resultado contenga espacios; esta forma ignora los espacios después de la apertura "{" y antes del cierre "}". Consulte también el mapa inline:.

La forma "static:{texto} está disponible con Postfix 3.0 y versiones posteriores.

tcp (solo lectura)
Cliente TCP/IP. El protocolo se describe en tcp_table(5).
texthash (solo lectura)
Produce resultados similares a los archivos hash:, excepto que no necesita ejecutar el comando postmap(1) antes de poder usar el archivo, y que no detecta cambios después de leer el archivo.

Esta función está disponible con Postfix 2.8 y versiones posteriores.

unionmap (solo lectura)
Una tabla que envía cada consulta a múltiples tablas de consulta y que concatena todos los resultados encontrados, separados por comas. La sintaxis del nombre de la tabla es la misma que para pipemap.

Esta función está disponible con Postfix 3.0 y versiones posteriores.

unix (solo lectura)
Una vista limitada de la base de datos de autenticación de UNIX. Se implementan las siguientes tablas:
unix:passwd.byname
La tabla es la base de datos de contraseñas de UNIX. La clave es un nombre de inicio de sesión. El resultado es una entrada del archivo de contraseñas en passwd(5).

DESCRIPCIÓN

El comando postconf recupera valores de parámetros de configuración de Postfix de los archivos main.cf y master.cf. Por defecto, recupera los parámetros de main.cf. Cuando se utilizan opciones de línea de comandos, postconf muestra los valores de los parámetros de configuración de manera predeterminada, o los valores de los parámetros de configuración con las actualizaciones o anulaciones especificadas.

La siguiente es una lista de tablas de búsqueda que pueden estar disponibles, dependiendo de cómo se compiló Postfix:

unix:passwd.byname
La tabla es la base de datos de usuarios de UNIX. La clave es un nombre de usuario. El resultado es una entrada de archivo de contraseña en formato passwd(5).
unix:group.byname
La tabla es la base de datos de grupos de UNIX. La clave es un nombre de grupo. El resultado es una entrada de archivo de grupo en formato group(5).
Pueden existir otros tipos de tablas dependiendo de cómo se compiló Postfix.
-M
Mostrar el contenido del archivo master.cf en lugar del contenido del archivo main.cf. Especificar -Mf para plegar líneas largas para facilitar la lectura humana.

Especificar cero o más argumentos, cada uno con un par de nombre-servicio o nombre-servicio/tipo-servicio, donde nombre-servicio es el primer campo de una entrada de master.cf y tipo-servicio es uno de (inet, unix, fifo, o pass).

Si se especifica nombre-servicio o nombre-servicio/tipo-servicio, solo se mostrarán las entradas de master.cf coincidentes. Por ejemplo, "postconf -Mf smtp" mostrará todos los servicios llamados "smtp", y "postconf -Mf smtp/inet" mostrará solo el servicio smtp que escucha en la red. Los campos finales de tipo de servicio que se omitan se tratarán como campos comodín "*".

Esta característica está disponible en Postfix 2.9 y versiones posteriores. La sintaxis se cambió de "nombre.tipo" a "nombre/tipo", y el soporte de comodines "*" se añadió con Postfix 2.11.

-n
Mostrar solo los parámetros de configuración que tienen ajustes explícitos de nombre=valor en main.cf. Especificar -nf para plegar líneas largas para facilitar la lectura humana (Postfix 2.9 y posteriores). Para mostrar solo los ajustes que difieren de los valores predeterminados integrados, use la siguiente sintaxis de bash: 
    LANG=C comm -23 <(postconf -n) <(postconf -d)
Reemplace "-23" con "-12" para mostrar ajustes que duplican los valores predeterminados integrados.
-o nombre=valor
Anular los ajustes de parámetros de main.cf. Esto le permite ver el efecto que tendría el cambio de un parámetro cuando se usa en otros parámetros de configuración, por ejemplo: 
    postconf -x -o stress=yes

Esta característica está disponible en Postfix 2.10 y versiones posteriores.

-p
Mostrar los ajustes de parámetros de main.cf. Este es el valor predeterminado.

Esta característica está disponible en Postfix 2.11 y versiones posteriores.

-P
Mostrar los ajustes de parámetros de servicio de master.cf (por defecto todos los servicios y todos los parámetros), formateados como "servicio/tipo/parámetro=valor", uno por línea. Especificar -Pf para plegar líneas largas.

Especifique una o más instancias de "servicio/tipo/parámetro" en la línea de comandos de postconf(1) para limitar la salida a los parámetros de interés. Los campos finales de nombre de parámetro o tipo de servicio que se omitan se tratarán como campos comodín "*".

Esta característica está disponible en Postfix 2.11 y versiones posteriores.

-q
No registrar advertencias para parámetros obsoletos o no utilizados.

Esta característica está disponible en Postfix 3.9 y versiones posteriores.

-t [archivo_plantilla]
Mostrar las plantillas para el texto que aparece al principio de los mensajes de notificación de estado de entrega (DSN), sin expandir las expresiones de $nombre.

Para anular el ajuste del parámetro bounce_template_file, especifique un nombre de archivo de plantilla al final de la línea de comandos "postconf -t". Especifique un nombre de archivo vacío para mostrar las plantillas integradas (en lenguaje shell: "").

Esta característica está disponible en Postfix 2.3 y versiones posteriores.

-T modo
Si Postfix se compila sin soporte TLS, la opción -T no produce ninguna salida. De lo contrario, si se especifica un modo inválido, la opción -T informa un error y sale con un código de estado distinto de cero. Los modos válidos son:
compile-version
Mostrar la versión de OpenSSL con la que se compiló Postfix (es decir, la versión de OpenSSL en un archivo de cabecera). El formato de salida es el mismo que con el comando "openssl version".
run-version
Mostrar la versión de OpenSSL con la que Postfix está enlazado en tiempo de ejecución (es decir, la versión de OpenSSL en una biblioteca compartida).
public-key-algorithms
Mostrar los nombres en minúsculas de los algoritmos de clave pública compatibles, uno por línea.
Esta característica está disponible en Postfix 3.1 y versiones posteriores.
-v
Habilitar el registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado.
-x
Expandir $nombre en los valores de los parámetros de main.cf o master.cf. La expansión es recursiva.

Esta característica está disponible en Postfix 2.10 y versiones posteriores.

-X
Editar el archivo de configuración main.cf y eliminar los parámetros nombrados en la línea de comandos de postconf(1). Especificar una lista de nombres de parámetros, no pares de "nombre=valor".

Con -M, editar el archivo de configuración master.cf y eliminar una o más entradas de servicio según se especifica con "servicio/tipo" en la línea de comandos de postconf(1).

Con -P, editar el archivo de configuración master.cf y eliminar uno o más ajustes de parámetros de servicio (ajustes -o parameter=value) según se especifica con "servicio/tipo/parámetro" en la línea de comandos de postconf(1).

En todos los casos, el archivo se copia a un archivo temporal y luego se renombra en su lugar. Especificar comillas para proteger caracteres especiales en la línea de comandos de postconf(1).

No existe un comando postconf(1) para realizar la operación inversa.

Esta característica está disponible en Postfix 2.10 y versiones posteriores. El soporte para -M y -P se añadió con Postfix 2.11.

-#
Editar el archivo de configuración main.cf y comentar los parámetros nombrados en la línea de comandos de postconf(1), de modo que esos parámetros vuelvan a sus valores predeterminados. Especificar una lista de nombres de parámetros, no pares de "nombre=valor".

Con -M, editar el archivo de configuración master.cf y comentar una o más entradas de servicio según se especifica con "servicio/tipo" en la línea de comandos de postconf(1).

En todos los casos, el archivo se copia a un archivo temporal y luego se renombra en su lugar. Especificar comillas para proteger caracteres especiales en la línea de comandos de postconf(1).

No existe un comando postconf(1) para realizar la operación inversa.

Esta característica está disponible en Postfix 2.6 y versiones posteriores. El soporte para -M se añadió con Postfix 2.11.
