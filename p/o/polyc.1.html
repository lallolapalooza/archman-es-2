NOMBRE

polyc - Compila y enlaza un programa Standard ML usando Poly/ML

SINOPSIS

polyc archivo_fuente

DESCRIPCIÓN

polyc es un script que compila un programa Standard ML usando el compilador Poly/ML y crea un programa ejecutable a partir de él. También se puede usar para enlazar archivos objeto creados usando la función PolyML.export con las bibliotecas de Poly/ML o para producir un archivo objeto. Cuando se usa para compilar un programa Standard ML, espera que la función principal se llame "main", por ejemplo: fun main() = print "Hello World\n";

Si el archivo fuente es un archivo de texto, se asume que es código ML. Si es un archivo binario, se asume que es un archivo objeto y se enlazará con la biblioteca de Poly/ML.

OPCIONES

-c Compila pero no enlaza. El archivo objeto se escribe en un archivo cuyo nombre se basa en el nombre del archivo fuente, reemplazando cualquier extensión por .o

-o salida
Escribe el archivo ejecutable en "salida".
--help
Escribe una lista de los argumentos y sale.
