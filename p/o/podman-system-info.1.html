podman-info(1) Manual de comandos generales podman-info(1)

NOMBRE

podman-info - Mostrar información relacionada con Podman

SINOPSIS

podman info [opciones]

podman system info [opciones]

DESCRIPCIÓN

Muestra información pertinente al host, estadísticas actuales de almacenamiento, registros de contenedores configurados y la compilación de podman.

OPCIONES

--format, -f=formato

Cambia el formato de salida a "json" o a una plantilla Go.

Marcador Información relativa a...
.Host ... ...el host en el que se ejecuta podman
.Plugins ... ...plugins externos
.Registries ... ...registros configurados
.Store ... ...el controlador de almacenamiento y las rutas
.Version ... ...la versión de podman

Cada una de las ramas anteriores se ramifica en subcampos adicionales, más de los que se pueden enumerar razonablemente en este documento.

Extrayendo la lista de registros de contenedores con una plantilla de Go


Si la finalización automática del shell está habilitada, escribe podman info
    --format={{. y luego presiona [TAB] dos veces.


$ podman info --format={{.
{{.Host.         {{.Plugins.      {{.Registries}}  {{.Store.        {{.Version.


Presiona R [TAB] [ENTER] para imprimir la información de los registros.


$ podman info -f {{.Registries}}
map[search:[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]]
$


La salida todavía contiene un mapa y un array. El valor del mapa se puede extraer con


$ podman info -f '{{index .Registries "search"}}'
[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]


El array se puede imprimir como una entrada por línea


$ podman info -f '{{range index .Registries "search"}}{{.}}\n{{end}}'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io






Extrayendo la lista de registros de contenedores de JSON con jq


El procesador JSON de línea de comandos jq se puede usar para extraer
    la lista de registros de contenedores.


$ podman info -f json | jq '.registries["search"]'
[
  "registry.fedoraproject.org",
  "registry.access.redhat.com",
  "docker.io",
  "quay.io"
]


El array se puede imprimir como una entrada por línea


$ podman info -f json | jq -r '.registries["search"] | .[]'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io


Nota, los campos de la estructura de la plantilla de Go comienzan con mayúsculas. Al
    ejecutar podman info o podman info --format=json, los mismos
    nombres comienzan con minúsculas.
