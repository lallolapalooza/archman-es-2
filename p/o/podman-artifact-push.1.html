NOMBRE

podman-artifact-push - Empuja un artefacto OCI desde el almacenamiento local a un registro de imágenes

SINOPSIS

podman artifact push [opciones] imagen

DESCRIPCIÓN

Empuja un artefacto desde el almacén de artefactos local a un registro de imágenes.

# Empujar artefacto a un registro de contenedores
$ podman artifact push quay.io/artifact/foobar1:latest

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. Por defecto es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux, y $HOME/.config/containers/auth.json en Windows/macOS. El archivo es creado por podman login. Si el estado de autorización no se encuentra allí, se revisa $HOME/.docker/config.json, que se establece usando docker login.

Nota: También existe la opción de anular la ruta por defecto del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--cert-dir=ruta

Utiliza certificados en ruta (*.crt, *.cert, *.key) para conectarte al registro. (Por defecto: /etc/containers/certs.d) Para más detalles, consulta containers-certs.d(5). (Esta opción no está disponible con el cliente remoto de Podman, incluyendo máquinas Mac y Windows (excluyendo WSL2))

--creds=[usuario[:contraseña]]

El [usuario[:contraseña]] a usar para autenticarse con el registro, si es necesario. Si no se proporciona uno o ambos valores, aparece un aviso en la línea de comandos y se puede introducir el valor. La contraseña se introduce sin mostrarse.

Ten en cuenta que las credenciales especificadas solo se utilizan para autenticarse contra los registros de destino. No se utilizan para espejos ni cuando el registro se reescribe (ver containers-registries.conf(5)); para autenticarse contra ellos considera usar un archivo containers-auth.json(5).

--digestfile=Digestfile

Después de copiar la imagen, escribe el digest de la imagen resultante en el archivo.

--quiet, -q

Al escribir la imagen de salida, suprime la salida de progreso

--retry=intentos

Número de veces que se intentará descargar o empujar imágenes entre el registro y el almacenamiento local en caso de fallo. Por defecto es 3.

--retry-delay=duración

Duración del retraso entre intentos de reintento al descargar o empujar imágenes entre el registro y el almacenamiento local en caso de fallo. Por defecto se inicia en dos segundos y luego se retrocede exponencialmente. El retraso se utiliza cuando este valor está establecido y no ocurre ningún retroceso exponencial.

--sign-by=clave

Añade una firma de "firma simple" en el destino usando la clave especificada. (Esta opción no está disponible con el cliente remoto de Podman, incluyendo máquinas Mac y Windows (excluyendo WSL2))

--sign-by-sigstore=archivo-parámetros

Añade una firma sigstore basada en opciones adicionales especificadas en un archivo de parámetros de firma sigstore de un contenedor, archivo-parámetros. Consulta containers-sigstore-signing-params.yaml(5) para más detalles sobre el formato del archivo.

--sign-by-sigstore-private-key=ruta

Añade una firma sigstore en el destino usando una clave privada en la ruta especificada. (Esta opción no está disponible con el cliente remoto de Podman, incluyendo máquinas Mac y Windows (excluyendo WSL2))

--sign-by-sq-fingerprint=huella

Añade una firma de "firma simple" usando una clave Sequoia-PGP con la huella especificada. (Esta opción no está disponible con el cliente remoto de Podman, incluyendo máquinas Mac y Windows (excluyendo WSL2))

--sign-passphrase-file=ruta

Si se está firmando la imagen (usando --sign-by, sign-by-sq-fingerprint o --sign-by-sigstore-private-key), lee la contraseña a usar desde la ruta especificada.

--tls-verify

Requiere HTTPS y verifica certificados al contactar registros (por defecto: true). Si se establece explícitamente como true, se utiliza la verificación TLS. Si se establece como false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino esté listado como un registro inseguro en containers-registries.conf(5)

EJEMPLO

Empuja la imagen especificada a un registro de contenedores:

$ podman artifact push quay.io/baude/artifact:single
Obteniendo firmas de origen de la imagen
Copiando blob 3ddc0a3cdb61 hecho   |
Copiando config 44136fa355 hecho   |
Escribiendo manifiesto al destino de la imagen
