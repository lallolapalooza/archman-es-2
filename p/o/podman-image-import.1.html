NOMBRE

podman-import - Importar un tarball y guardarlo como una imagen del sistema de archivos

SINOPSIS

podman import [opciones] ruta [referencia]

podman image import [opciones] ruta [referencia]

DESCRIPCIÓN

podman import importa un tarball (posiblemente comprimido usando Gzip, Bzip2, XZ o Zstd) y lo guarda como una imagen del sistema de archivos. Se pueden especificar tarballs remotos usando una URL. Varias instrucciones de imagen se pueden configurar con el flag --change y un mensaje de commit se puede establecer usando el flag --message. referencia, si está presente, es una etiqueta para asignar a la imagen. podman import se utiliza para importar desde el archivo generado por podman export, que incluye el sistema de archivos del contenedor. Para importar el archivo de capas de imagen creadas por podman save, use podman load. Nota: : es un carácter restringido y no puede formar parte del nombre del archivo.

OPCIONES

--arch

Establece la arquitectura de la imagen importada.

--change, -c=instrucción

Aplica las siguientes instrucciones posibles a la imagen creada: CMD | ENTRYPOINT | ENV | EXPOSE | LABEL | STOPSIGNAL | USER | VOLUME | WORKDIR

Se puede establecer varias veces

--help, -h

Imprime la declaración de uso

--message, -m=mensaje

Establece el mensaje de commit para la imagen importada

--os

Establece el sistema operativo de la imagen importada.

--quiet, -q

Muestra el progreso de la importación

--variant

Establece la variante de la imagen importada.

$ cat ctr.tar | podman -q import --message "importing the ctr.tar file" - image-imported
