NOMBRE

powerline - Script de prompt y línea de estado de Powerline.

SINOPSIS

powerline EXT [SIDE] [-rMODULE] [-wWIDTH] [--last-exit-code=INT]
          [--last-pipe-status=LIST] [--jobnum=INT]
          [-cKEY.KEY=VALUE]… [-tTHEME.KEY.KEY=VALUE]… [-RKEY=VAL]…
          [-pPATH]… [--socket=ADDRESS]

DESCRIPCIÓN

EXT
Extensión: aplicación para la cual se lanza el comando powerline (generalmente shell o tmux). También soporta extensiones wm.: wm.awesome.
SIDE
Lado: left y right representan el lado izquierdo y derecho respectivamente, above emite líneas que deben imprimirse justo encima del prompt y aboveleft es como concatenar above con left con la excepción de que solo se usa una instancia de Python en este caso. Se puede omitir para extensiones wm.*.
-r, --renderer-module MODULE
Módulo renderizador. Generalmente algo como .bash o .zsh (con punto inicial) que es powerline.renderers.{ext}{MODULE}, también puede ser el nombre completo del módulo (debe contener al menos un punto o terminar con un punto en caso de ser un módulo de nivel superior) o un submódulo de powerline.renderers (en caso de que no haya puntos).
-w, --width WIDTH
Ancho máximo del prompt. Desencadena la truncación de algunos segmentos.
--last-exit-code INT
Último código de salida.
--last-pipe-status LIST
Como el anterior, pero se supone que contendrá una matriz de estados separada por espacios, que representa los estados de salida de los comandos en una tubería.
--jobnum INT
Número de trabajos.
-c, --config-override KEY.KEY=VALUE
Anulaciones de configuración para config.json. Se traduce a un diccionario y se fusiona con el diccionario obtenido de la configuración JSON real: KEY.KEY=VALUE se traduce a {"KEY": {"KEY": VALUE}} y luego se fusiona recursivamente. VALUE puede ser cualquier valor JSON, los valores que no son null, true, false, comienzan con un dígito, {, [ se tratan como cadenas. Si VALUE se omite, se elimina la clave correspondiente.
-t, --theme-override THEME.KEY.KEY=VALUE
Igual que el anterior, pero específico del tema. THEME debe apuntar a un tema existente y en uso para tener algún efecto, pero está bien usar cualquier tema aquí.
-R, --renderer-arg KEY=VAL
Igual que el anterior, pero proporciona un argumento para el renderizador. Se supone que solo lo usarán las vinculaciones de shell para proporcionar diversos datos como el último código de salida o el último estado de tubería (no usan --renderer-arg por razones históricas: --renderer-arg se agregó más tarde).
-p, --config-path PATH
Ruta al directorio de configuración. Si está presente, los archivos de configuración solo se buscarán en la ruta proporcionada. Se puede proporcionar múltiples veces para buscar en una lista de directorios.
--socket ADDRESS
Dirección del socket a utilizar en los clientes demonio. Siempre es un socket de dominio UNIX en linux y un socket de archivo en Mac OS X. No se usa aquí, presente solo por compatibilidad con otros clientes de powerline. Este argumento siempre debe ser el primero y tener el formato --socket ADDRESS: sin = ni forma corta permitida (en otros clientes de powerline, no aquí).
-h, --help
Mostrar ayuda y salir.
