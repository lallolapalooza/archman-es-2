NOMBRE

po4a-updatepo - actualizar la traducción (en formato PO) de la documentación

SINOPSIS

po4a-updatepo -f fmt (-m master.doc)+ (-p XX.po)+

(XX.po son las salidas, todos los demás son entradas)

DESCRIPCIÓN

El objetivo del proyecto po4a (PO para cualquier cosa) es facilitar las traducciones (y lo que es más interesante, el mantenimiento de las traducciones) utilizando las herramientas gettext en áreas donde no se esperaban, como la documentación.

El script po4a-updatepo se encarga de actualizar los archivos PO para que reflejen los cambios realizados en el archivo de documentación original. Para ello, convierte el archivo de documentación a un archivo POT y llama a msgmerge(1) sobre este nuevo POT y sobre los archivos PO proporcionados.

Es posible proporcionar más de un archivo PO (si desea actualizar varios idiomas a la vez) y varios archivos de documentación (si desea almacenar las traducciones de varios documentos en el mismo archivo PO).

Si el documento maestro tiene caracteres no ASCII, este script convertirá los archivos PO a UTF-8 (si aún no lo estaban), para un manejo transparente de caracteres no estándar.

OPCIONES

-f, --format
Formato de la documentación que desea manejar. Utilice la opción --help-format para ver la lista de formatos disponibles.
-m, --master
Archivo(s) que contienen el documento maestro a traducir.
-M, --master-charset
Juego de caracteres de los archivos que contienen el documento a traducir. Tenga en cuenta que todos los archivos deben tener el mismo juego de caracteres.
-p, --po
Archivo(s) PO a actualizar. Si estos archivos no existen, son creados por po4a-updatepo.
-o, --option
Opciones adicionales para pasar al plugin de formato. Consulte la documentación de cada plugin para obtener más información sobre las opciones válidas y sus significados. Por ejemplo, podría pasar '-o tablecells' al analizador AsciiDoc, mientras que el analizador de texto aceptaría '-o tabs=split'.
--no-previous
Esta opción elimina --previous de las opciones pasadas a msgmerge. Esto ayuda a soportar versiones antiguas de gettext (anteriores a la v0.16).
--previous
Esta opción añade --previous a las opciones pasadas a msgmerge. Requiere gettext 0.16 o posterior, y está activada por defecto.
--msgmerge-opt opciones
Opciones adicionales para msgmerge(1).
-h, --help
Mostrar un mensaje de ayuda corto.
--help-format
Listar los formatos de documentación entendidos por po4a.
-V, --version
Mostrar la versión del script y salir.
-v, --verbose
Aumentar la verbosidad del programa.
-d, --debug
Mostrar información de depuración.
--porefs tipo[,wrap|nowrap]
Especificar el formato de referencia. El argumento tipo puede ser uno de never para no producir ninguna referencia, file para especificar solo el archivo sin el número de línea, counter para reemplazar el número de línea por un contador incremental y full para incluir referencias completas (por defecto: full).

El argumento puede ir seguido de una coma y la palabra clave wrap o nowrap. Las referencias se escriben por defecto en una sola línea. La opción wrap envuelve las referencias en varias líneas, para imitar las herramientas de gettext (xgettext y msgmerge). Esta opción se convertirá en la opción por defecto en una futura versión, ya que es más sensata. La opción nowrap está disponible para que los usuarios que quieran mantener el comportamiento anterior puedan hacerlo.

--wrap-po no|newlines|number (por defecto: 76)
Especificar cómo se debe envolver el archivo po. Esto da la opción de archivos que se envuelven bien pero que podrían generar conflictos de git, o archivos que son más fáciles de manejar automáticamente, pero más difíciles de leer para los humanos.

Históricamente, la suite gettext reformateaba los archivos po en la columna 77 por motivos estéticos. Esta opción especifica el comportamiento de po4a. Si se establece en un valor numérico, po4a envolverá el archivo po después de esta columna y después de las nuevas líneas en el contenido. Si se establece en newlines, po4a solo dividirá el msgid y msgstr después de las nuevas líneas en el contenido. Si se establece en no, po4a no envolverá el archivo po en absoluto. El ajuste de los comentarios de referencia se controla mediante la opción --porefs.

Tenga en cuenta que esta opción no tiene impacto en cómo se envuelven msgid y msgstr, es decir, en cómo se añaden nuevas líneas al contenido de estas cadenas.

--msgid-bugs-address email@address
Establecer la dirección de informe para los errores de msgid. Por defecto, los archivos POT creados no tienen campos Report-Msgid-Bugs-To.
--copyright-holder string
Establecer el titular de los derechos de autor en la cabecera del POT. El valor por defecto es "Free Software Foundation, Inc."
--package-name string
Establecer el nombre del paquete para la cabecera del POT. El valor por defecto es "PACKAGE".
--package-version string
Establecer la versión del paquete para la cabecera del POT. El valor por defecto es "VERSION".
