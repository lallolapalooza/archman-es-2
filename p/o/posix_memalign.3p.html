POSIX_MEMALIGN(3P) Manual de Programador POSIX POSIX_MEMALIGN(3P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

posix_memalign — asignación de memoria alineada (TIEMPO REAL AVANZADO)

SINOPSIS

#include <stdlib.h>
int posix_memalign(void **memptr, size_t alignment, size_t size);

DESCRIPCIÓN

La función posix_memalign() asignará size bytes alineados en un límite especificado por alignment, y devolverá un puntero a la memoria asignada en memptr. El valor de alignment será una potencia de dos múltiplo de sizeof(void *).

Al completarse con éxito, el valor apuntado por memptr será un múltiplo de alignment.

Si el tamaño del espacio solicitado es 0, el comportamiento es definido por la implementación: se devolverá un puntero nulo en memptr, o el comportamiento será como si el tamaño fuera algún valor distinto de cero, excepto que el comportamiento no está definido si el valor devuelto en memptr se utiliza para acceder a un objeto.

La función free() liberará la memoria que haya sido previamente asignada por posix_memalign().

VALOR DE RETORNO

Al completarse con éxito, posix_memalign() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error y el contenido de memptr se dejará sin modificar o se establecerá a un puntero nulo.

Si size es 0, entonces:

*
posix_memalign() no intentará asignar ningún espacio, en cuyo caso se devolverá un número de error definido por la implementación, o se devolverá cero con un puntero nulo en memptr, o
*
posix_memalign() intentará asignar algún espacio y, si la asignación tiene éxito, se devolverá cero y se devolverá un puntero al espacio asignado en memptr. La aplicación garantizará que el puntero no se utiliza para acceder a un objeto.

ERRORES

La función posix_memalign() fallará si:

EINVAL
El valor del parámetro de alineación no es una potencia de dos múltiplo de sizeof(void *).
ENOMEM
No hay suficiente memoria disponible con la alineación solicitada.

Las siguientes secciones son informativas.

EJEMPLOS

El siguiente ejemplo muestra cómo las aplicaciones pueden obtener un comportamiento consistente en caso de error estableciendo *memptr a ser un puntero nulo antes de llamar a posix_memalign().

void *ptr = NULL;
...
// hacer algo de trabajo, que podría ir a error
if (posix_memalign(&ptr, align, size))
    goto error;
// hacer algo más de trabajo, que podría ir a error
...
error:
    free(ptr);
    // más limpieza;

USO DE LA APLICACIÓN

La función posix_memalign() forma parte de la opción de Información Asesora y puede que no se proporcione en todas las implementaciones.
