poll.h(0P) Manual del programador de POSIX poll.h(0P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

poll.h — definiciones para la función poll()

SINOPSIS

#include <poll.h>

DESCRIPCIÓN

El encabezado <poll.h> definirá la estructura pollfd, la cual incluirá al menos los siguientes miembros:

int    fd       El descriptor que se está consultando.
short  events   Las banderas de eventos de entrada (ver abajo).
short  revents  Las banderas de eventos de salida (ver abajo).

El encabezado <poll.h> definirá el siguiente tipo mediante typedef:

nfds_t
Un tipo entero sin signo utilizado para el número de descriptores de archivo.

La implementación soportará uno o más entornos de programación en los que el ancho de nfds_t no sea mayor que el ancho del tipo long. Los nombres de estos entornos de programación se pueden obtener utilizando la función confstr() o la utilidad getconf.

El encabezado <poll.h> definirá las siguientes constantes simbólicas, cero o más de las cuales pueden combinarse con un OR para formar los miembros events o revents en la estructura pollfd:

POLLIN
Se pueden leer datos que no sean de alta prioridad sin bloqueo.
POLLRDNORM
Se pueden leer datos normales sin bloqueo.
POLLRDBAND
Se pueden leer datos de prioridad sin bloqueo.
POLLPRI
Se pueden leer datos de alta prioridad sin bloqueo.
POLLOUT
Se pueden escribir datos normales sin bloqueo.
POLLWRNORM
Equivalente a POLLOUT.
POLLWRBAND
Se pueden escribir datos de prioridad.
POLLERR
Ha ocurrido un error (solo revents).
POLLHUP
El dispositivo ha sido desconectado (solo revents).
POLLNVAL
Miembro fd inválido (solo revents).

La significación y semántica de los datos normales, de prioridad y de alta prioridad son específicas del archivo y del dispositivo.

Lo siguiente se declarará como una función y también puede definirse como una macro. Se proporcionará un prototipo de función.

int   poll(struct pollfd [], nfds_t, int);
