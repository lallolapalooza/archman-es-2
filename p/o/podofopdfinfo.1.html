NOMBRE

podofopdfinfo - proporciona información sobre un archivo PDF

SINOPSIS

podofopdfinfo [DCPON] [archivo_entrada]

DESCRIPCIÓN

podofopdfinfo es una de las herramientas de línea de comandos de la biblioteca PoDoFo que proporciona varias operaciones útiles para trabajar con archivos PDF. Puede proporcionar una serie de datos sobre un documento PDF de acuerdo con las instrucciones de formato. Si no se proporcionan las instrucciones, se muestra información completa.

OPCIONES

D

muestra Información del Documento.

C

muestra Metadatos Clásicos.

P

muestra Información de Página.

O

muestra Contenido.

N

muestra Nombres.

[archivo_entrada]

Archivo PDF de entrada.
