POSTLOG(1) Manual de Comandos Generales POSTLOG(1)

NOMBRE

postlog - Utilidad de registro compatible con Postfix

SINOPSIS

postlog [-iv] [-c directorio_config] [-p prioridad] [-t etiqueta] [texto...]

DESCRIPCIÓN


El comando postlog(1) implementa una interfaz de registro compatible con Postfix para usarla, por ejemplo, en scripts de shell.

Por defecto, postlog(1) registra el texto proporcionado en la línea de comandos como un registro. Si no se especifica texto en la línea de comandos, postlog(1) lee de la entrada estándar y registra cada línea de entrada como un registro.

El registro se envía a syslogd(8) o postlogd(8), y al flujo de error estándar (con Postfix < 3.8, postlog(1) escribe en el flujo de error estándar solo si dicho flujo está conectado a una terminal).

Las siguientes opciones están implementadas:

-c directorio_config
Lee el archivo de configuración main.cf en el directorio especificado en lugar del directorio de configuración por defecto.
-i (obsoleto)
Incluye el ID del proceso en la etiqueta de registro. Esta bandera se ignora a partir de Postfix 3.4, donde el PID siempre se incluye.
-p prioridad (por defecto: info)
Especifica la severidad del registro: info, warn, error, fatal o panic. Con Postfix 3.1 y posteriores, el programa se detendrá durante 1 segundo después de informar una condición fatal o panic, al igual que otros programas de Postfix.
-t etiqueta
Especifica la etiqueta de registro, es decir, el nombre identificativo que aparece al principio de cada registro. Se utiliza una etiqueta por defecto cuando no se especifica ninguna.
-v
Habilita el registro detallado con fines de depuración. Múltiples opciones -v hacen que el software sea cada vez más detallado.

SEGURIDAD

El comando postlog(1) está diseñado para ejecutarse con privilegios set-groupid, de modo que pueda conectarse al proceso demonio postlogd(8) (Postfix 3.7 y posteriores; implementaciones anteriores de este comando no deben tener permisos set-groupid ni set-userid).

MEDIO AMBIENTE

MAIL_CONFIG
Directorio con el archivo main.cf.

PARÁMETROS DE CONFIGURACIÓN

Los siguientes parámetros de main.cf son especialmente relevantes para este programa.

El texto a continuación proporciona solo un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluyendo ejemplos.

config_directory (ver salida de 'postconf -d')
La ubicación por defecto de los archivos de configuración main.cf y master.cf de Postfix.
import_environment (ver salida de 'postconf -d')
La lista de variables de entorno que un proceso privilegiado de Postfix importará de un proceso padre que no sea de Postfix, o reemplazos de entorno nombre=valor.
syslog_facility (mail)
La instalación de syslog para el registro de Postfix.
syslog_name (ver salida de 'postconf -d')
Un prefijo que se antepone al nombre del proceso en los registros de syslog, de modo que, por ejemplo, "smtpd" se convierta en "prefijo/smtpd".

Disponible en Postfix 3.4 y posteriores:

maillog_file (vacío)
El nombre de un archivo de registro opcional que es escrito por el servicio postlogd(8) de Postfix.
postlog_service_name (postlog)
El nombre de la entrada de servicio postlogd(8) en master.cf.

Disponible en Postfix 3.9 y posteriores:

maillog_file_permissions (0600)
Los permisos de acceso de archivo que se establecerán cuando el archivo $maillog_file se cree por primera vez, o cuando el archivo se cree después de que un archivo existente sea rotado.
