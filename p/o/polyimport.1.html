NOMBRE

polyimport - el programa de importación de Poly/ML

SINOPSIS

polyimport archivo_de_importacion

DESCRIPCIÓN

polyimport lee y ejecuta un archivo de importación de Poly/ML. Los archivos de importación se generan utilizando la función PolyML.exportPortable.

OPCIONES

-H tamaño Establece el tamaño inicial del montículo (heap). El tamaño puede escribirse como un número opcionalmente seguido de K, M o G representando kilobytes, megabytes o gigabytes. Si no se indica ninguno de estos, el número se toma como megabytes.

--minheap tamaño
Establece el tamaño mínimo del montículo. El montículo no se reducirá por debajo de este valor.
--maxheap tamaño
Establece el tamaño máximo del montículo. El montículo no crecerá por encima de este valor.
--gcpercent porcentaje
Establece el porcentaje objetivo del tiempo que el código debería pasar en el recolector de basura. El ajustador del montículo intentará establecer el tamaño del montículo para lograr este objetivo de acuerdo con los tamaños mínimo y máximo del montículo dados por los argumentos y también de acuerdo con el control de la paginación.
--gcthreads hilos
Establece el número de hilos utilizados en el recolector de basura paralelo. Establecer esto en 1 fuerza al recolector de basura a ser monohilo. El valor 0, que es el predeterminado, se toma como el número de procesadores (núcleos) disponibles.
--debug opciones
Establece varias opciones de depuración para el sistema de ejecución.
