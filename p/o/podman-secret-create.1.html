NOMBRE

podman-secret-create - Crea un nuevo secreto

SINOPSIS

podman secret create [opciones] nombre archivo|-

DESCRIPCIÓN

Crea un secreto utilizando la entrada estándar o desde un archivo para el contenido del secreto.

Create acepta una ruta a un archivo, o -, lo que indica a podman que lea el secreto desde la entrada estándar.

Un secreto es un bloque de datos sensibles que un contenedor necesita en tiempo de ejecución pero que no se almacena en la imagen ni en el control de versiones, como nombres de usuario y contraseñas, certificados y claves TLS, claves SSH u otros contenidos genéricos sensibles o binarios importantes (hasta 512 kB de tamaño).

Los secretos no se confirman en una imagen con podman commit, y no se confirman en el archivo creado por un comando podman export.

Los secretos también se pueden utilizar para almacenar contraseñas para que podman login se autentifique contra los registros de contenedores.

OPCIONES

--driver, -d=driver

Especifica el controlador de secretos (por defecto file).

--driver-opts=clave1=valor1,clave2=valor2

Especifica opciones específicas del controlador.

--env=false

Lee datos secretos de una variable de entorno.

--help

Imprime el enunciado de uso.

--ignore=false

Si ya existe un secreto con el mismo nombre, no devuelvas un error y devuelve el ID del secreto existente en lugar de crear uno nuevo. No se puede usar con --replace. El valor por defecto es false.

--label, -l=clave=valor1,clave2=valor2

Añade una etiqueta al secreto. Estas etiquetas se pueden ver en podman secret inspect o ls.

--replace=false

Si ya existe un secreto con el mismo nombre, actualiza el secreto. La opción --replace no cambia los secretos dentro de los contenedores existentes, solo los contenedores de nueva creación. No se puede usar con --ignore.
El valor por defecto es false.

CONTROLADORES DE SECRETOS

file

El secreto reside en un archivo protegido contra lectura.

pass

El secreto reside en un archivo cifrado con GPG.

shell

El secreto es gestionado por scripts personalizados. Se pasa una variable de entorno SECRET_ID a los scripts (excepto para list), y los secretos se comunican a través de stdin/stdout (cuando sea aplicable). Las opciones del controlador list, lookup, store y delete sirven para instalar los scripts:

[secrets]
driver = "shell"
[secrets.opts]
list =
lookup =
store =
delete =

EJEMPLOS

Crea el secreto especificado basándose en un archivo local.

echo -n mysecret > ./secret.txt
$ podman secret create my_secret ./secret.txt

Crea el secreto especificado a través de la entrada estándar.

$ printf <secreto> | podman secret create my_secret -

Crea o rota un secreto aleatorio criptográficamente seguro justo por debajo del máximo de 512000 bytes a través de la entrada estándar.

openssl rand -base64 378000 | podman secret create --replace my_secret -

Monta de forma segura un secreto local basado en archivos en un contenedor.

podman run --rm --secret source=my_secret,type=mount,uid=1001,gid=1001,mode=440 docker.io/library/alpine ls -l /run/secrets/my_secret

Crea un secreto cifrado con gpg basado en un archivo local usando el controlador pass.

$ podman secret create --driver=pass my_secret ./secret.txt.gpg

Crea un secreto a partir de una variable de entorno llamada 'MYSECRET'.

$ podman secret create --env=true my_secret MYSECRET
