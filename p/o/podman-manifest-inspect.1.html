NOMBRE

podman-manifest-inspect - Muestra una lista de manifiestos o un índice de imágenes

SINOPSIS

podman manifest inspect [opciones] nombredeíndiceonombredelista

DESCRIPCIÓN

Muestra la lista de manifiestos o el índice de imágenes almacenado utilizando el nombre de imagen especificado.

VALOR DE RETORNO

Una representación JSON formateada de la lista de manifiestos o el índice de imágenes.

OPCIONES

--authfile=ruta

Ruta del archivo de autenticación. El valor predeterminado es ${XDG_RUNTIME_DIR}/containers/auth.json en Linux y $HOME/.config/containers/auth.json en Windows/macOS. El archivo es creado por podman login. Si el estado de autorización no se encuentra allí, se comprueba $HOME/.docker/config.json, que se establece con docker login.

Nota: También existe la opción de anular la ruta predeterminada del archivo de autenticación estableciendo la variable de entorno REGISTRY_AUTH_FILE. Esto se puede hacer con export REGISTRY_AUTH_FILE=ruta.

--tls-verify

Requerir HTTPS y verificar certificados al contactar con los registros (predeterminado: true). Si se establece explícitamente en true, se utiliza la verificación TLS. Si se establece en false, no se utiliza la verificación TLS. Si no se especifica, se utiliza la verificación TLS a menos que el registro de destino aparezca como un registro inseguro en containers-registries.conf(5)

EJEMPLOS

Inspecciona el manifiesto de mylist:v1.11.

podman manifest inspect mylist:v1.11

VER TAMBIÉN

podman(1), podman-manifest(1)
