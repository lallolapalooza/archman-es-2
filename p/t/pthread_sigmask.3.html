pthread_sigmask(3) Manual de Funciones de Biblioteca pthread_sigmask(3)

NOMBRE

pthread_sigmask - examina y cambia la máscara de señales bloqueadas

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <signal.h>
int pthread_sigmask(int how, const sigset_t *set, sigset_t *oldset);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

pthread_sigmask():

    _POSIX_C_SOURCE >= 199506L || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

La función pthread_sigmask() es idéntica a sigprocmask(2), con la diferencia de que su uso en programas multihilo está explícitamente especificado por POSIX.1. Otras diferencias se señalan en esta página.

Para una descripción de los argumentos y el funcionamiento de esta función, ver sigprocmask(2).

VALOR DE RETORNO

En caso de éxito, pthread_sigmask() devuelve 0; en caso de error, devuelve un número de error.

ERRORES

Ver sigprocmask(2).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_sigmask () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Un nuevo hilo hereda una copia de la máscara de señales de su creador.

La función pthread_sigmask() de glibc ignora silenciosamente los intentos de bloquear las dos señales de tiempo real que se utilizan internamente por la implementación de hilos NPTL. Ver nptl(7) para más detalles.

EJEMPLOS

El siguiente programa bloquea algunas señales en el hilo principal, y luego crea un hilo dedicado para capturar esas señales mediante sigwait(3). La siguiente sesión de shell demuestra su uso:


$ ./a.out &
[1] 5423
$ kill -QUIT %1
Signal handling thread got signal 3
$ kill -USR1 %1
Signal handling thread got signal 10
$ kill -TERM %1
[1]+  Terminated              ./a.out

Código fuente del programa

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
/* Funciones sencillas de manejo de errores */
static void *
sig_thread(void *arg)
{
    sigset_t *set = arg;
    int s, sig;
    for (;;) {
        s = sigwait(set, &sig);
        if (s != 0)
            errc(EXIT_FAILURE, s, "sigwait");
        printf("Signal handling thread got signal %d\n", sig);
    }
}
int
main(void)
{
    pthread_t thread;
    sigset_t set;
    int s;
    /* Bloquear SIGQUIT y SIGUSR1; otros hilos creados por main()
       heredarán una copia de la máscara de señales.  */
    sigemptyset(&set);
    sigaddset(&set, SIGQUIT);
    sigaddset(&set, SIGUSR1);
    s = pthread_sigmask(SIG_BLOCK, &set, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_sigmask");
    s = pthread_create(&thread, NULL, &sig_thread, &set);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    /* El hilo principal continúa para crear otros hilos y/o hacer
       otro trabajo.  */
    pause();            /* Pausa simulada para poder probar el programa */
}
