Nombre

ptcli - Una CLI para interactuar con phosh-thumbnailer.

SINOPSIS

ptcli [OPCIÓN…] /ruta/al/directorio

ptcli [OPCIÓN…] /ruta/al/archivo_1 /ruta/al/archivo_2 …

ptcli [OPCIÓN…] --stop

DESCRIPCIÓN

ptcli se puede utilizar para interactuar con el servicio phosh-thumbnailer(8). Se utiliza principalmente para crear miniaturas según el Estándar de Gestión de Miniaturas https://specifications.freedesktop.org/thumbnail-spec/latest/.

-h, --help
Imprime las opciones de ayuda y sale.
-s, --stop
Detiene la operación de creación de miniaturas en curso.
-v, --version
Imprime la versión y sale.

EJEMPLOS

Para crear miniaturas para todos los archivos en el directorio actual:

ptcli .

Para crear miniaturas para todos los archivos en $HOME/Pictures:

ptcli $HOME/Pictures

Para crear miniaturas para un conjunto de archivos:

ptcli $HOME/Pictures/foo.png bar.txt ../spam.ogg

Para detener la operación de creación de miniaturas en curso:

ptcli --stop

VER TAMBIÉN

phosh-thumbnailer(8)
