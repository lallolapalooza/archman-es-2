PTHREAD_SIGMASK(3P) Manual del Programador POSIX PTHREAD_SIGMASK(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_sigmask, sigprocmask — examinar y cambiar señales bloqueadas

SINOPSIS

#include <signal.h>
int pthread_sigmask(int how, const sigset_t *restrict set,
    sigset_t *restrict oset);
int sigprocmask(int how, const sigset_t *restrict set,
    sigset_t *restrict oset);

DESCRIPCION

La función pthread_sigmask() examinará o cambiará (o ambas cosas) la máscara de señales del hilo que realiza la llamada, independientemente del número de hilos en el proceso. La función será equivalente a sigprocmask(), sin la restricción de que la llamada se realice en un proceso de un solo hilo.

En un proceso de un solo hilo, la función sigprocmask() examinará o cambiará (o ambas cosas) la máscara de señales del hilo que realiza la llamada.

Si el argumento set no es un puntero nulo, apunta a un conjunto de señales que se utilizará para cambiar el conjunto actualmente bloqueado.

El argumento how indica la forma en que se cambia el conjunto, y la aplicación deberá asegurarse de que consta de uno de los siguientes valores:

SIG_BLOCK
El conjunto resultante será la unión del conjunto actual y el conjunto de señales apuntado por set.
SIG_SETMASK
El conjunto resultante será el conjunto de señales apuntado por set.
SIG_UNBLOCK
El conjunto resultante será la intersección del conjunto actual y el complemento del conjunto de señales apuntado por set.

Si el argumento oset no es un puntero nulo, la máscara anterior se almacenará en la ubicación apuntada por oset. Si set es un puntero nulo, el valor del argumento how no es significativo y la máscara de señales del hilo no se modificará; por lo tanto, la llamada puede usarse para consultar las señales actualmente bloqueadas.

Si hay señales pendientes no bloqueadas después de la llamada a sigprocmask(), se entregará al menos una de esas señales antes de que la llamada a sigprocmask() retorne.

No es posible bloquear aquellas señales que no pueden ser ignoradas. El sistema aplicará esto sin causar un error.

Si las señales SIGFPE, SIGILL, SIGSEGV o SIGBUS se generan mientras están bloqueadas, el resultado no está definido, a menos que la señal haya sido generada por la acción de otro proceso, o por una de las funciones kill(), pthread_kill(), raise() o sigqueue().

Si sigprocmask() falla, la máscara de señales del hilo no se modificará.

El uso de la función sigprocmask() no está especificado en un proceso multihilo.

VALOR DE RETORNO

Al completarse con éxito, pthread_sigmask() devolverá 0; de lo contrario, devolverá el número de error correspondiente.

Al completarse con éxito, sigprocmask() devolverá 0; de lo contrario, se devolverá -1, se establecerá errno para indicar el error y la máscara de señales del proceso no se modificará.

ERRORES

Las funciones pthread_sigmask() y sigprocmask() fallarán si:

EINVAL
El valor del argumento how no es igual a uno de los valores definidos.

La función pthread_sigmask() no devolverá un código de error de [EINTR].

EJEMPLOS

Señalización en un proceso multihilo

Este ejemplo muestra el uso de pthread_sigmask() para tratar las señales en un proceso multihilo. Proporciona un marco bastante general que podría adaptarse/ampliarse fácilmente.

#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <signal.h>
#include <string.h>
#include <errno.h>
...

static sigset_t   signal_mask;  /* señales a bloquear         */

int main (int argc, char *argv[])
{
    pthread_t  sig_thr_id;      /* ID del hilo manejador de señales */
    int        rc;              /* código de retorno              */

    sigemptyset (&signal_mask);
    sigaddset (&signal_mask, SIGINT);
    sigaddset (&signal_mask, SIGTERM);
    rc = pthread_sigmask (SIG_BLOCK, &signal_mask, NULL);
    if (rc != 0) {
        /* manejar error */
        ...
    }
    /* cualquier hilo recién creado hereda la máscara de señales */

    rc = pthread_create (&sig_thr_id, NULL, signal_thread, NULL);
    if (rc != 0) {
        /* manejar error */
        ...
    }

    /* CÓDIGO DE LA APLICACIÓN */
    ...
}

void *signal_thread (void *arg)
{
    int       sig_caught;    /* señal capturada       */
    int       rc;            /* código de retorno       */

    rc = sigwait (&signal_mask, &sig_caught);
    if (rc != 0) {
        /* manejar error */
    }
    switch (sig_caught)
    {
    case SIGINT:     /* procesar SIGINT  */
        ...
        break;
    case SIGTERM:    /* procesar SIGTERM */
        ...
        break;
    default:         /* normalmente no debería ocurrir */
        fprintf (stderr, "\nSeñal inesperada %d\n", sig_caught);
        break;
    }
}

USO DE LA APLICACIÓN

Ninguno.

RACIONAMIENTO

Cuando la máscara de señales de un hilo se cambia en una función que captura señales e instalada por sigaction(), la restauración de la máscara de señales al retornar de la función que captura señales anula ese cambio (ver sigaction()). Si la función que captura señales fue instalada con signal(), no está especificado si esto ocurre.

Ver kill() para una discusión del requisito de entrega de señales.
