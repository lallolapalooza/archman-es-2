PTKSH(1) Documentación de perl/Tk PTKSH(1)

NOMBRE

ptksh - Script de Perl/Tk para proporcionar una interfaz gráfica de usuario para probar comandos y scripts de Perl/Tk.

SINOPSIS

% ptksh  ?archivo_script?
... información de versión ...
ptksh> $b=$mw->Button(-text=>'Hola',-command=>sub{print 'Hola'})
ptksh> $b->pack
ptksh> o $b
... lista de opciones ...
ptksh> help
... información de ayuda ...
ptksh> exit
%

DESCRIPCIÓN

ptksh es una shell de perl/Tk para introducir comandos perl interactivamente. Cuando se inicia ptksh, se crea automáticamente una MainWindow, junto con una ventana de comandos ptksh. Se puede acceder a la ventana principal escribiendo comandos usando la variable $mw en el prompt 'ptksh> ' de la ventana de comandos.

ptksh admite edición de línea de comandos e historial. Simplemente escriba "<Arriba>" en el prompt de comandos para ver una lista del historial. Los últimos 50 comandos introducidos se guardan y luego se recargan en la lista de historial la próxima vez que inicie ptksh.

ptksh admite algunos comandos convenientes para inspeccionar widgets Tk. Ver más abajo.

Para salir de ptksh use: "exit".

ptksh *no* es un depurador simbólico completo. Para depurar programas perl/Tk a bajo nivel, utilice el depurador de perl, más potente. (Simplemente escriba ``O tk'' en la línea de comandos del depurador para iniciar el bucle de eventos de Tk.)

CARACTERÍSTICAS

Historial

Presione <Arriba> (la flecha Arriba) en la ventana de perlwish para obtener una lista de historial basada en GUI. Presione <Enter> en cualquier línea del historial para introducirla en la ventana de perlwish. Luego presione enter. Así, por ejemplo, repetir el último comando es <Arriba><Enter><Enter>. Puede salir de la ventana de historial con <Escape>. NOTA: el historial solo se guarda si la salida es "grácil" (es decir, mediante el comando "exit" desde la consola o al cerrar todas las ventanas principales, NO mediante interrupción).

Soporte de depuración

ptksh proporciona algunas funciones de conveniencia para facilitar la navegación en widgets perl/Tk:

?, o h
muestra un breve resumen de ayuda.
d, o x ?args, ...?
Vuelca recursivamente los argumentos a stdout. (ver Data::Dumper). Debe tener <Data::Dumper> instalado para admitir esta característica.

x se introdujo para compatibilidad con el depurador de perl.

p ?arg, ...?
añade "|\n" a cada uno de sus argumentos y lo imprime. Si el valor es undef, se imprime '(undef)' en stdout.
o $widget ?-opción ...?
imprime la(s) opción(es) de $widget una por línea. Si no se proporcionan opciones, se enumeran todas las opciones del widget. Consulte Tk::options para obtener más detalles sobre el formato y el contenido de la lista devuelta.
o $widget /expresión_regular/
Enumera las opciones de $widget que coinciden con la expresión regular expresión_regular.
u ?clase?
Si no se proporciona ningún argumento, enumera los módulos cargados por los comandos que ha ejecutado o desde la última vez que llamó a "u".

Si el argumento es una cadena vacía, enumera todos los módulos cargados por ptksh.

Si el argumento es una cadena, ``text'', intenta hacer un ``use Tk::Text;''.

Paquetes

Ptksh se compila en el paquete Tk::ptksh. Su código se evalúa en el paquete main. La ventaja de esto es que su código evaluado no debería interferir con ptksh en sí.

Comandos multilínea

ptksh aceptará comandos multilínea. Simplemente coloque un carácter "\" inmediatamente antes del salto de línea, y ptksh continuará su comando en la siguiente línea.

Soporte de archivo fuente

Si tiene un script perl/Tk en el que desea depurar, intente ejecutar el comando

ptksh> do 'mi_script';
 -- o (en el prompt de comandos de shell) --
% ptksh mi_script

Luego use los comandos perl/Tk para probar diferentes operaciones en su script.

ENTORNO

Busca su .ptksh_history en el directorio especificado por la variable de entorno $HOME (directorio $HOMEPATH en sistemas Win32).

ARCHIVOS

.ptksh_init
Si se encuentra en el directorio actual, se lee y evalúa después de que se crea la ventana principal $mw. .ptksh_init puede contener cualquier código perl válido.
~/.ptksh_history
Contiene las últimas 50 líneas introducidas en sesiones de ptksh.

TRAMPAS

Es mejor no usar "my" en los comandos que escribe en ptksh. Por ejemplo, "my $v" hará que $v sea local solo al comando o comandos introducidos hasta que se presione <Enter>. Por una razón relacionada, no hay variables "my" con alcance de archivo en el propio código de ptksh (de lo contrario, el usuario podría tropezar con ellas por accidente).

ERRORES

La función Tk::MainLoop introducida interactivamente o incluida en un archivo de inicialización o script bloqueará ptksh.

SYNOPSIS

ptksh [ file ... ]

DESCRIPTION

ptksh is a shell interface to the Tk toolkit. It can be used to embed Tk applications into a shell, or to create shell commands that have Tk graphical user interfaces.

ARGUMENTS

file
One or more script files to be executed by ptksh. If no files are specified, ptksh will read commands from standard input.

SEE ALSO

tk(1), tcl(1)

HISTORY

The ptksh command was introduced in Tk 8.0.

BUGS

None reported.
