PTHREAD_RWLOCK_TRYWRLOCK(3P) Manual del programador POSIX PTHREAD_RWLOCK_TRYWRLOCK(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_rwlock_trywrlock, pthread_rwlock_wrlock — bloquear un objeto de bloqueo de lectura-escritura para escritura

SINOPSIS

#include <pthread.h>
int pthread_rwlock_trywrlock(pthread_rwlock_t *rwlock);
int pthread_rwlock_wrlock(pthread_rwlock_t *rwlock);

DESCRIPCIÓN

La función pthread_rwlock_trywrlock() aplica un bloqueo de escritura como la función pthread_rwlock_wrlock(), con la excepción de que la función fallará si algún hilo actualmente mantiene rwlock (para lectura o escritura).

La función pthread_rwlock_wrlock() aplica un bloqueo de escritura al bloqueo de lectura-escritura al que se refiere rwlock. El hilo llamante adquirirá el bloqueo de escritura si ningún hilo (lector o escritor) mantiene el bloqueo de lectura-escritura rwlock. De lo contrario, si otro hilo mantiene el bloqueo de lectura-escritura rwlock, el hilo llamante se bloqueará hasta que pueda adquirir el bloqueo. Si ocurre una condición de interbloqueo o el hilo llamante ya posee el bloqueo de lectura-escritura para escritura o lectura, la llamada se interbloqueará o devolverá [EDEADLK].

Los resultados no están definidos si alguna de estas funciones se llama con un bloqueo de lectura-escritura no inicializado.

Si se entrega una señal a un hilo que espera un bloqueo de lectura-escritura para escritura, al regresar del manejador de señales, el hilo reanudará la espera del bloqueo de lectura-escritura para escritura como si no hubiera sido interrumpido.

VALOR DE RETORNO

La función pthread_rwlock_trywrlock() devolverá cero si se adquiere el bloqueo para escritura en el objeto de bloqueo de lectura-escritura al que se refiere rwlock. De lo contrario, se devolverá un número de error para indicar el error.

Si tiene éxito, la función pthread_rwlock_wrlock() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_rwlock_trywrlock() fallará si:

EBUSY
El bloqueo de lectura-escritura no pudo ser adquirido para escritura porque ya estaba bloqueado para lectura o escritura.

La función pthread_rwlock_wrlock() puede fallar si:

EDEADLK
Se detectó una condición de interbloqueo o el hilo actual ya posee el bloqueo de lectura-escritura para escritura o lectura.

Estas funciones no devolverán un código de error de [EINTR].

USO EN APLICACIONES

Las aplicaciones que utilizan estas funciones pueden estar sujetas a inversión de prioridades, como se discute en el volumen de Definiciones Base de POSIX.1‐2017, Sección 3.291, Inversión de Prioridades.

FUNDAMENTO

Si una implementación detecta que el valor especificado por el argumento rwlock a pthread_rwlock_trywrlock() o pthread_rwlock_wrlock() no se refiere a un objeto de bloqueo de lectura-escritura inicializado, se recomienda que la función falle y reporte un error [EINVAL].
