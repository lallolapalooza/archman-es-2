PTHREAD_MUTEXATTR_GETTYPE(3P) Manual de programador POSIX PTHREAD_MUTEXATTR_GETTYPE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_mutexattr_gettype, pthread_mutexattr_settype — obtener y establecer el atributo de tipo de mutex

SINOPSIS

#include <pthread.h>
int pthread_mutexattr_gettype(const pthread_mutexattr_t *restrict attr,
    int *restrict type);
int pthread_mutexattr_settype(pthread_mutexattr_t *attr, int type);

DESCRIPCIÓN

Las funciones pthread_mutexattr_gettype() y pthread_mutexattr_settype(), respectivamente, obtienen y establecen el atributo de tipo de mutex. Este atributo se establece en el parámetro type de estas funciones. El valor predeterminado del atributo type es PTHREAD_MUTEX_DEFAULT.

El tipo de mutex se contiene en el atributo type de los atributos del mutex. Los tipos de mutex válidos incluyen:

PTHREAD_MUTEX_NORMAL PTHREAD_MUTEX_ERRORCHECK PTHREAD_MUTEX_RECURSIVE PTHREAD_MUTEX_DEFAULT

El tipo de mutex afecta el comportamiento de las llamadas que bloquean y desbloquean el mutex. Consulte pthread_mutex_lock() para obtener más detalles. Una implementación puede mapear PTHREAD_MUTEX_DEFAULT a uno de los otros tipos de mutex.

El comportamiento no está definido si el valor especificado por el argumento attr en pthread_mutexattr_gettype() o pthread_mutexattr_settype() no se refiere a un objeto de atributos de mutex inicializado.

VALOR DE RETORNO

Al completarse con éxito, la función pthread_mutexattr_gettype() devolverá cero y almacenará el valor del atributo type de attr en el objeto al que hace referencia el parámetro type. De lo contrario, se devolverá un error para indicar el error.

Si tiene éxito, la función pthread_mutexattr_settype() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_mutexattr_settype() fallará si:

EINVAL
El valor type es inválido.

Estas funciones no devolverán un código de error de [EINTR].

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE APLICACIONES

Se recomienda que una aplicación no utilice un mutex PTHREAD_MUTEX_RECURSIVE con variables de condición porque el desbloqueo implícito realizado para una llamada pthread_cond_timedwait() o pthread_cond_wait() puede no liberar realmente el mutex (si se hubiera bloqueado varias veces). Si esto sucede, ningún otro hilo puede satisfacer la condición del predicado.

FUNDAMENTO RACIONAL

Si una implementación detecta que el valor especificado por el argumento attr en pthread_mutexattr_gettype() o pthread_mutexattr_settype() no se refiere a un objeto de atributos de mutex inicializado, se recomienda que la función falle y reporte un error [EINVAL].
