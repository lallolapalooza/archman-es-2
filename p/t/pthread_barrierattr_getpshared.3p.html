PTHREAD_BARRIERATTR_GETPSHARED(3P) Manual del programador POSIX PTHREAD_BARRIERATTR_GETPSHARED(3P)

PROLOGO

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_barrierattr_getpshared, pthread_barrierattr_setpshared — obtener y establecer el atributo de compartición entre procesos de la información de atributos de barrera

SINOPSIS

#include <pthread.h>
int pthread_barrierattr_getpshared(const pthread_barrierattr_t
    *restrict attr, int *restrict pshared);
int pthread_barrierattr_setpshared(pthread_barrierattr_t *attr,
    int pshared);

DESCRIPCION

La función pthread_barrierattr_getpshared() obtendrá el valor del atributo de compartición entre procesos del objeto de atributos referenciado por attr. La función pthread_barrierattr_setpshared() establecerá el atributo de compartición entre procesos en un objeto de atributos inicializado referenciado por attr.

El atributo de compartición entre procesos se establece en PTHREAD_PROCESS_SHARED para permitir que una barrera sea operada por cualquier hilo que tenga acceso a la memoria donde se asigna la barrera. Vea la Sección 2.9.9, Copias de objetos de sincronización y mapeos alternativos para obtener más requisitos. El valor predeterminado del atributo será PTHREAD_PROCESS_PRIVATE. Ambas constantes PTHREAD_PROCESS_SHARED y PTHREAD_PROCESS_PRIVATE están definidas en <pthread.h>.

Los atributos adicionales, sus valores predeterminados y los nombres de las funciones asociadas para obtener y establecer esos valores de atributo dependen de la implementación.

El comportamiento es indefinido si el valor especificado por el argumento attr para pthread_barrierattr_getpshared() o pthread_barrierattr_setpshared() no se refiere a un objeto de atributos de barrera inicializado.

VALOR DE RETORNO

Si tiene éxito, la función pthread_barrierattr_getpshared() devolverá cero y almacenará el valor del atributo de compartición entre procesos de attr en el objeto referenciado por el parámetro pshared. De lo contrario, se devolverá un número de error para indicar el error.

Si tiene éxito, la función pthread_barrierattr_setpshared() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_barrierattr_setpshared() puede fallar si:

EINVAL
El nuevo valor especificado para el atributo de compartición entre procesos no es uno de los valores legales PTHREAD_PROCESS_SHARED o PTHREAD_PROCESS_PRIVATE.

Estas funciones no devolverán un código de error de [EINTR].

USO DE APLICACION

Las funciones pthread_barrierattr_getpshared() y pthread_barrierattr_setpshared() son parte de la opción de Sincronización Compartida entre Procesos de Hilos y no es necesario que se proporcionen en todas las implementaciones.

RACIONALE

Si una implementación detecta que el valor especificado por el argumento attr a pthread_barrierattr_getpshared() o pthread_barrierattr_setpshared() no se refiere a un objeto de atributos de barrera inicializado, se recomienda que la función falle y reporte un error [EINVAL].
