PTHREAD_ATTR_GETGUARDSIZE(3P) Manual del programador de POSIX PTHREAD_ATTR_GETGUARDSIZE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_attr_getguardsize, pthread_attr_setguardsize — obtener y establecer el atributo guardsize del hilo

SINOPSIS

#include <pthread.h>
int pthread_attr_getguardsize(const pthread_attr_t *restrict attr,
    size_t *restrict guardsize);
int pthread_attr_setguardsize(pthread_attr_t *attr,
    size_t guardsize);

DESCRIPCIÓN

La función pthread_attr_getguardsize() obtiene el atributo guardsize en el objeto attr. Este atributo se devolverá en el parámetro guardsize.

La función pthread_attr_setguardsize() establece el atributo guardsize en el objeto attr. El nuevo valor de este atributo se obtendrá del parámetro guardsize. Si guardsize es cero, no se proporcionará un área de guarda para los hilos creados con attr. Si guardsize es mayor que cero, se proporcionará un área de guarda de al menos guardsize bytes para cada hilo creado con attr.

El atributo guardsize controla el tamaño del área de guarda para la pila del hilo creado. El atributo guardsize proporciona protección contra el desbordamiento del puntero de pila. Si la pila de un hilo se crea con protección de guarda, la implementación asigna memoria adicional en el extremo de desbordamiento de la pila como un búfer contra el desbordamiento de la pila del puntero de pila. Si una aplicación se desborda en este búfer, se producirá un error (posiblemente una señal SIGSEGV se entregará al hilo).

Una implementación compatible puede redondear el valor contenido en guardsize a un múltiplo de la variable del sistema configurable {PAGESIZE} (consulte <sys/mman.h>). Si una implementación redondea el valor de guardsize a un múltiplo de {PAGESIZE}, una llamada a pthread_attr_getguardsize() especificando attr almacenará en el parámetro guardsize el tamaño de guarda especificado por la llamada anterior a la función pthread_attr_setguardsize().

El valor predeterminado del atributo guardsize lo define la implementación.

Si el atributo stackaddr ha sido establecido (es decir, el llamador está asignando y gestionando sus propias pilas de hilos), el atributo guardsize se ignorará y la implementación no proporcionará protección. En este caso, es responsabilidad de la aplicación gestionar el desbordamiento de la pila junto con la asignación y gestión de la pila.

El comportamiento no está definido si el valor especificado por el argumento attr a pthread_attr_getguardsize() o pthread_attr_setguardsize() no se refiere a un objeto de atributos de hilo inicializado.

VALOR DE RETORNO

Si se realiza con éxito, las funciones pthread_attr_getguardsize() y pthread_attr_setguardsize() devolverán cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones fallarán si:

EINVAL
El parámetro guardsize no es válido.

Estas funciones no devolverán un código de error de [EINTR].

Las siguientes secciones son informativas.

EJEMPLOS

Recuperación del atributo guardsize

Este ejemplo muestra cómo obtener el atributo guardsize de un objeto de atributos de hilo.

#include <pthread.h>
pthread_attr_t thread_attr;
size_t  guardsize;
int     rc;
/* código para inicializar thread_attr */
...
rc = pthread_attr_getguardsize (&thread_attr, &guardsize);
if (rc != 0)  {
    /* manejar error */
    ...
}
else {
    if (guardsize > 0) {
    /* se proporciona un área de guarda de al menos guardsize bytes */
    ...
    }
    else {
    /* no se proporciona área de guarda */
    ...
    }
}

USO DE APLICACIÓN

Ninguno.

FUNDAMENTO

El atributo guardsize se proporciona a la aplicación por dos razones:

1.
La protección contra desbordamientos puede potencialmente resultar en un desperdicio de recursos del sistema. Una aplicación que crea un gran número de hilos, y que sabe que sus hilos nunca desbordan su pila, puede ahorrar recursos del sistema desactivando las áreas de guarda.
2.
Cuando los hilos asignan grandes estructuras de datos en la pila, pueden ser necesarias grandes áreas de guarda para detectar el desbordamiento de la pila.

El tamaño predeterminado del área de guarda se deja a la definición de la implementación, ya que en sistemas que soportan tamaños de página muy grandes, la sobrecarga podría ser sustancial si se requiere al menos una página de guarda por defecto.

Si una implementación detecta que el valor especificado por el argumento attr a pthread_attr_getguardsize() o pthread_attr_setguardsize() no se refiere a un objeto de atributos de hilo inicializado, se recomienda que la función falle e informe de un error [EINVAL].

NAME

pthread_attr_getguardsize, pthread_attr_setguardsize - get and set thread guard size attribute

SYNOPSIS

#include <pthread.h>

int pthread_attr_getguardsize(const pthread_attr_t *attr, size_t *guardsize);
int pthread_attr_setguardsize(pthread_attr_t *attr, size_t guardsize);

DESCRIPTION

The pthread_attr_getguardsize() function shall return the value of the guard size attribute that is currently set for the thread attributes object referred to by attr.

The pthread_attr_setguardsize() function shall set the guard size attribute in the thread attributes object referred to by attr to the value specified by guardsize.

The guard size attribute shall control the size of the guard land allocated for the thread stack. The minimum guard size is PTHREAD_GUARDSIZE_MIN and the maximum guard size is PTHREAD_GUARDSIZE_MAX. If the specified guardsize is less than PTHREAD_GUARDSIZE_MIN, the implementation shall set the guard size to PTHREAD_GUARDSIZE_MIN. If the specified guardsize is greater than PTHREAD_GUARDSIZE_MAX, the implementation shall set the guard size to PTHREAD_GUARDSIZE_MAX. If guardsize is 0, the implementation shall disable the guard land for the thread stack.

The size of the guard land allocated for a thread stack is implementation-dependent and is at least the system's page size. The maximum guard size is implementation-dependent. The default guard size is 0, meaning that guards are disabled by default.

The guardsize parameter is a size_t value. The value 0 means that the guard size is set to the system's page size. The value PTHREAD_GUARDSIZE_pthread_get_min_stack is also defined.

RETURN VALUE

On success, pthread_attr_getguardsize() and pthread_attr_setguardsize() shall return 0. Otherwise, they shall return an error number to indicate the error.

ERRORS

pthread_attr_getguardsize() shall fail if:

EINVAL
The value specified by attr is invalid.
ENOMEM
Insufficient memory to allocate for the attribute object.

pthread_attr_setguardsize() shall fail if:

EINVAL
The value specified by attr is invalid.
ENOMEM
Insufficient memory to allocate for the attribute object.
