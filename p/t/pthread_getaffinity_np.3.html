pthread_setaffinity_np(3) Manual de Funciones de Biblioteca pthread_setaffinity_np(3)

NOMBRE

pthread_setaffinity_np, pthread_getaffinity_np - establecer/obtener la afinidad de CPU de un hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
int pthread_setaffinity_np(pthread_t thread, size_t cpusetsize,
                           const cpu_set_t *cpuset);
int pthread_getaffinity_np(pthread_t thread, size_t cpusetsize,
                           cpu_set_t *cpuset);

DESCRIPCIÓN

La función pthread_setaffinity_np() establece la máscara de afinidad de CPU del hilo thread al conjunto de CPU apuntado por cpuset. Si la llamada es exitosa, y el hilo no se está ejecutando actualmente en una de las CPU del conjunto cpuset, entonces se migra a una de esas CPU.

La función pthread_getaffinity_np() devuelve la máscara de afinidad de CPU del hilo thread en el búfer apuntado por cpuset.

Para más detalles sobre máscaras de afinidad de CPU, ver sched_setaffinity(2). Para una descripción de un conjunto de macros que pueden ser usadas para manipular e inspeccionar conjuntos de CPU, ver CPU_SET(3).

El argumento cpusetsize es la longitud (en bytes) del búfer apuntado por cpuset. Típicamente, este argumento se especificaría como sizeof(cpu_set_t). (Puede ser algún otro valor, si se usan las macros descritas en CPU_SET(3) para asignar dinámicamente un conjunto de CPU.)

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

EFAULT
Una dirección de memoria proporcionada era inválida.
EINVAL
(pthread_setaffinity_np()) La máscara de bits de afinidad mask no contiene procesadores que estén actualmente físicamente en el sistema y permitidos para el hilo de acuerdo con cualquier restricción que pueda ser impuesta por el mecanismo "cpuset" descrito en cpuset(7).
EINVAL
(pthread_setaffinity_np()) cpuset especificó una CPU que estaba fuera del conjunto soportado por el kernel. (La opción de configuración del kernel CONFIG_NR_CPUS define el rango del conjunto soportado por el tipo de dato del kernel utilizado para representar conjuntos de CPU.)
EINVAL
(pthread_getaffinity_np()) cpusetsize es menor que el tamaño de la máscara de afinidad utilizada por el kernel.
ESRCH
No se encontró ningún hilo con el ID thread.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor

ESTANDARES

GNU; de ahí el sufijo "_np" (no portable) en los nombres.

HISTORIAL

glibc 2.3.4.

En glibc 2.3.3 solamente, se proporcionaron versiones de estas funciones que no tenían un argumento cpusetsize. En su lugar, el tamaño del conjunto de CPU dado a las llamadas del sistema subyacentes era siempre sizeof(cpu_set_t).

NOTAS

Después de una llamada a pthread_setaffinity_np(), el conjunto de CPU en el que el hilo se ejecutará realmente es la intersección del conjunto especificado en el argumento cpuset y el conjunto de CPU presentes realmente en el sistema. El sistema puede restringir aún más el conjunto de CPU en el que se ejecuta el hilo si se está utilizando el mecanismo "cpuset" descrito en cpuset(7). Estas restricciones sobre el conjunto real de CPU en el que se ejecutará el hilo son impuestas silenciosamente por el kernel.

Estas funciones se implementan sobre las llamadas del sistema sched_setaffinity(2) y sched_getaffinity(2).

Un nuevo hilo creado por pthread_create(3) hereda una copia de la máscara de afinidad de CPU de su creador.

EJEMPLOS

En el siguiente programa, el hilo principal usa pthread_setaffinity_np() para establecer su máscara de afinidad de CPU para incluir las CPU 0 a 7 (que puede que no todas estén disponibles en el sistema), y luego llama a pthread_getaffinity_np() para verificar la máscara de afinidad de CPU resultante del hilo.

#define _GNU_SOURCE
#include <err.h>
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    int s;
    cpu_set_t cpuset;
    pthread_t thread;
    thread = pthread_self();
    /* Establecer la máscara de afinidad para incluir las CPU 0 a 7.  */
    CPU_ZERO(&cpuset);
    for (size_t j = 0; j < 8; j++)
        CPU_SET(j, &cpuset);
    s = pthread_setaffinity_np(thread, sizeof(cpuset), &cpuset);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setaffinity_np");
    /* Comprobar la máscara de afinidad real asignada al hilo.  */
    s = pthread_getaffinity_np(thread, sizeof(cpuset), &cpuset);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getaffinity_np");
    printf("El conjunto devuelto por pthread_getaffinity_np() contenía:\n");
    for (size_t j = 0; j < CPU_SETSIZE; j++)
        if (CPU_ISSET(j, &cpuset))
            printf("    CPU %zu\n", j);
    exit(EXIT_SUCCESS);
}
