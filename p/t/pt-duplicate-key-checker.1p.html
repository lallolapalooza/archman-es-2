NOMBRE

pt-duplicate-key-checker - Encuentra índices y claves foráneas duplicadas en tablas MySQL.

SINOPSIS

Uso: pt-duplicate-key-checker [OPCIONES] [DSN]

pt-duplicate-key-checker examina tablas MySQL en busca de índices y claves foráneas duplicadas o redundantes. Las opciones de conexión se leen de archivos de opciones de MySQL.

pt-duplicate-key-checker --host host1

RIESGOS

Percona Toolkit es maduro, probado en el mundo real y bien verificado, pero todas las herramientas de bases de datos pueden representar un riesgo para el sistema y el servidor de la base de datos. Antes de usar esta herramienta, por favor:

  • Lea la documentación de la herramienta
  • Revise los "BUGS" conocidos de la herramienta
  • Pruebe la herramienta en un servidor no productivo
  • Haga una copia de seguridad de su servidor de producción y verifique las copias de seguridad

DESCRIPCIÓN

Este programa examina la salida de SHOW CREATE TABLE en tablas MySQL, y si encuentra índices que cubren las mismas columnas que otro índice en el mismo orden, o cubren un prefijo izquierdo exacto de otro índice, imprime los índices sospechosos. Por defecto, los índices deben ser del mismo tipo, por lo que un índice BTREE no es un duplicado de un índice FULLTEXT, incluso si tienen las mismas columnas. Puede anular esto.

También busca claves foráneas duplicadas. Una clave foránea duplicada cubre las mismas columnas que otra en la misma tabla y referencia la misma tabla padre.

La salida termina con un breve resumen que incluye una estimación del tamaño total, en bytes, que utilizan los índices duplicados. Esto se calcula multiplicando la longitud del índice por el número de filas en sus respectivas tablas.

OPCIONES

Esta herramienta acepta argumentos adicionales en la línea de comandos. Consulte la "SINOPSIS" y la información de uso para obtener detalles.

--all-structs
Compara índices con diferentes estructuras (BTREE, HASH, etc.).

Por defecto, esto está deshabilitado, porque un índice BTREE que cubre las mismas columnas que un índice FULLTEXT no es realmente un duplicado, por ejemplo.

--ask-pass
Solicita una contraseña al conectarse a MySQL.
--charset
forma corta: -A; tipo: string

Juego de caracteres por defecto. Si el valor es utf8, activa el binmode de Perl en STDOUT a utf8, pasa la opción mysql_enable_utf8 a DBD::mysql y ejecuta SET NAMES UTF8 después de conectarse a MySQL. Cualquier otro valor activa el binmode en STDOUT sin la capa utf8, y ejecuta SET NAMES después de conectarse a MySQL.

--[no]clustered
por defecto: yes

Las columnas PK añadidas a claves secundarias son duplicadas.

Detecta cuándo un sufijo de una clave secundaria es un prefijo izquierdo de la clave primaria y lo trata como una clave duplicada. Solo detecta esta condición en motores de almacenamiento cuyas claves primarias están agrupadas (actualmente InnoDB, TokuDB y MyRocks).

Los motores de almacenamiento agrupados añaden de todos modos las columnas de la clave primaria a los nodos hoja de todas las claves secundarias, por lo que podría considerar redundante que aparezcan también en los nodos internos. Por supuesto, también puede quererlas en los nodos internos, ya que solo tenerlas en los nodos hoja no ayuda para algunas consultas. Sin embargo, sí ayuda para las consultas con índice de cobertura.

Aquí hay un ejemplo de una clave que se considera redundante con esta opción:

PRIMARY KEY  (`a`)
KEY `b` (`b`,`a`)

El uso de tales índices es bastante sutil. Por ejemplo, suponga que tiene la siguiente consulta:

SELECT ... WHERE b=1 ORDER BY a;

Esta consulta realizará un filesort si eliminamos el índice en "b,a". Pero si acortamos el índice en "b,a" a solo "b" y también eliminamos el ORDER BY, la consulta debería devolver los mismos resultados.

La herramienta sugiere acortar las claves agrupadas duplicadas eliminando la clave y volviéndola a añadir sin el prefijo de clave primaria. La clave agrupada acortada puede seguir duplicando otra clave, pero la herramienta actualmente no puede detectar cuándo ocurre esto sin ser ejecutada una segunda vez para volver a comprobar las claves agrupadas recién acortadas. Por lo tanto, si acorta alguna clave agrupada duplicada, debe volver a ejecutar la herramienta.

--config
tipo: Array

Lee esta lista de archivos de configuración separados por comas; si se especifica, esta debe ser la primera opción en la línea de comandos.

--databases
forma corta: -d; tipo: hash

Comprueba solo esta lista de bases de datos separadas por comas.

--defaults-file
forma corta: -F; tipo: string

Lee solo las opciones de mysql del archivo dado. Debes proporcionar una ruta de archivo absoluta.

--engines
forma corta: -e; tipo: hash

Comprueba solo las tablas cuyos motores de almacenamiento estén en esta lista separada por comas.

--help
Muestra la ayuda y sale.
--host
forma corta: -h; tipo: string

Conectar al host.

--ignore-databases
tipo: Hash

Ignora esta lista de bases de datos separadas por comas.

--ignore-engines
tipo: Hash

Ignora esta lista de motores de almacenamiento separados por comas.

--ignore-order
Ignora el orden de los índices, de modo que KEY(a,b) duplique a KEY(b,a).
--ignore-tables
tipo: Hash

Ignora esta lista de tablas separadas por comas. Los nombres de tabla pueden ir calificados con el nombre de la base de datos.

--key-types
tipo: string; por defecto: fk

Comprueba duplicados de f=claves foráneas, k=claves o fk=ambos.

--password
forma corta: -p; tipo: string

Contraseña a usar al conectarse. Si la contraseña contiene comas, deben escaparse con una barra invertida: "exam\,ple"

--pid
tipo: string

Crea el archivo PID dado. La herramienta no se iniciará si el archivo PID ya existe y el PID que contiene es diferente del PID actual. Sin embargo, si el archivo PID existe y el PID que contiene ya no se está ejecutando, la herramienta sobrescribirá el archivo PID con el PID actual. El archivo PID se elimina automáticamente cuando la herramienta finaliza.

--port
forma corta: -P; tipo: int

Número de puerto a usar para la conexión.

--set-vars
tipo: Array

Establece las variables de MySQL en esta lista separada por comas de pares "variable=valor".

Por defecto, la herramienta establece:

wait_timeout=10000

Las variables especificadas en la línea de comandos anulan estos valores predeterminados. Por ejemplo, especificar "--set-vars wait_timeout=500" anula el valor predeterminado de 10000.

La herramienta muestra una advertencia y continúa si una variable no se puede establecer.

--socket
forma corta: -S; tipo: string

Archivo de socket a usar para la conexión.

--[no]sql
por defecto: yes

Imprime la sentencia DROP KEY para cada clave duplicada. Por defecto se imprime una sentencia ALTER TABLE DROP KEY debajo de cada clave duplicada para que, si deseas eliminar la clave duplicada, puedas copiar y pegar la sentencia en MySQL.

Para deshabilitar la impresión de estas sentencias, especifica "--no-sql".

--[no]summary
por defecto: yes

Imprime un resumen de los índices al final de la salida.
