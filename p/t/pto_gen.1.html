NOMBRE

pto_gen - Generar un archivo de proyecto Hugin a partir de una lista de imágenes.

SINOPSIS

pto_gen [opciones] imagen [...]

DESCRIPCIÓN

pto_gen ensambla un archivo de proyecto Hugin .pto que es adecuado como entrada para otras herramientas como el generador de puntos de control cpfind, o para abrirlo con la propia GUI de Hugin. La funcionalidad es similar a match-n-shift.

USO

pto_gen *.jpg

Esto crea un archivo de proyecto a partir de todas las imágenes jpg, en la misma carpeta que la primera foto. El archivo de proyecto se llama primero_archivo-ultimo_archivo.pto, utilizando la misma convención que la GUI de Hugin.

OPCIONES

-o|--output archivo
Archivo de salida Hugin PTO.
-p|--projection número
Tipo de proyección (por defecto: 0)
-f|--fov flotante
Campo de visión horizontal de las imágenes (por defecto: 50)
-c|--crop=izquierda,derecha,arriba,abajo
Establece el recorte de las imágenes de entrada (especialmente para lentes ojo de pez)
-s|--stacklength número
Número de imágenes en la pila (por defecto: detección automática)
-l|--linkstacks
Vincula las posiciones de las imágenes en las pilas
--distortion
Intenta cargar información de distorsión de la base de datos de lentes
--vignetting
Intenta cargar información de viñeteo de la base de datos de lentes
-h|--help
muestra la ayuda
