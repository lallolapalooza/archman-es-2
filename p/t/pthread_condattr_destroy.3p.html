PTHREAD_CONDATTR_DESTROY(3P) Manual del programador POSIX PTHREAD_CONDATTR_DESTROY(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_condattr_destroy, pthread_condattr_init — destruir e inicializar el objeto de atributos de la variable de condición

SINOPSIS

#include <pthread.h>
int pthread_condattr_destroy(pthread_condattr_t *attr);
int pthread_condattr_init(pthread_condattr_t *attr);

DESCRIPCIÓN

La función pthread_condattr_destroy() destruye un objeto de atributos de variable de condición; el objeto se vuelve, en efecto, no inicializado. Una implementación puede hacer que pthread_condattr_destroy() establezca el objeto referenciado por attr en un valor inválido. Un objeto de atributos attr destruido puede ser reinicializado usando pthread_condattr_init(); los resultados de referenciar de otra manera el objeto después de haber sido destruido no están definidos.

La función pthread_condattr_init() inicializa un objeto de atributos de variable de condición attr con el valor predeterminado para todos los atributos definidos por la implementación.

Los resultados no están definidos si se llama a pthread_condattr_init() especificando un objeto de atributos attr ya inicializado.

Después de que un objeto de atributos de variable de condición se ha utilizado para inicializar una o más variables de condición, cualquier función que afecte al objeto de atributos (incluida su destrucción) no afectará a las variables de condición inicializadas previamente.

Este volumen de POSIX.1‐2017 requiere dos atributos, el atributo clock y el atributo process-shared.

Los atributos adicionales, sus valores predeterminados y los nombres de las funciones asociadas para obtener y establecer los valores de esos atributos son definidos por la implementación.

El comportamiento no está definido si el valor especificado por el argumento attr a pthread_condattr_destroy() no se refiere a un objeto de atributos de variable de condición inicializado.

VALOR DE RETORNO

Si tiene éxito, las funciones pthread_condattr_destroy() y pthread_condattr_init() devolverán cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_condattr_init() fallará si:

ENOMEM
No hay memoria suficiente para inicializar el objeto de atributos de la variable de condición.

Estas funciones no devolverán un código de error de [EINTR].

FUNDAMENTO

Se ha definido un atributo process-shared para las variables de condición por la misma razón por la que se ha definido para los mutexes.

Si una implementación detecta que el valor especificado por el argumento attr a pthread_condattr_destroy() no se refiere a un objeto de atributos de variable de condición inicializado, se recomienda que la función falle y reporte un error [EINVAL].

Ver también pthread_attr_destroy() y pthread_mutex_destroy().
