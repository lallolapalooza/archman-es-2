FBB::PtrIter(3bobcat) Iterador que apunta a punteros FBB::PtrIter(3bobcat)

NOMBRE

FBB::PtrIter - Iterador que devuelve un puntero al ser desreferenciado

SINOPSIS

#include <bobcat/ptriter>

DESCRIPCIÓN

La plantilla de clase PtrIter implementa un iterador de entrada cuyo operator* devuelve la dirección del elemento al que apunta el iterador. Considere un std::unordered_map<std::string, DataType>. Su miembro begin devuelve un iterador cuyo operator* devuelve un std::pair<std::string, DataType> (const) &. Esto es generalmente lo que se desea, pero ahora supongamos que queremos mostrar el contenido del mapa, ordenado por sus claves. La ordenación se puede realizar simplemente definiendo un vector de soporte que contenga punteros a los elementos del mapa y luego ordenando las cadenas a las que apuntan los punteros.

PtrIter es una herramienta que se puede utilizar para construir dicho vector de soporte, como se muestra en la sección EJEMPLO.

Los usuarios de PtrIter no tienen que especificar el tipo de plantilla de PtrIter. La plantilla de función ptrIter, cuando se le proporciona un iterador, devuelve el objeto PtrIter correspondiente.

PtrIter es una plantilla de clase que requiere un parámetro de tipo de plantilla: Iterator, el tipo del iterador (por ejemplo, vector<string>::iterator)

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::iterator<std::input_iterator_tag, ...>

FUNCIÓN LIBRE

o
PtrIter<Iterator> ptrIter(Iterator const &iter):
esta plantilla de función devuelve un objeto PtrIter para el argumento Iterator de la función. Esta plantilla de función simplifica la construcción de un PtrIter ya que no es necesario especificar parámetros de plantilla (ver también la sección EJEMPLO).

CONSTRUCTORES

o
PtrIter(Iterator const &iter):
El parámetro iter debe inicializarse con un iterador de entrada existente, que ofrezca operator*, operator++, operator== y operator!=. Como PtrIter es una plantilla de clase, sus parámetros de tipo de plantilla deben especificarse al definir un objeto PtrIter. Por ejemplo, 
    PtrIter<set<string>::iterator> PtrIter(mySet.begin());

Los constructores y operadores de asignación de copia y movimiento (y operadores de asignación) están disponibles.

OPERADORES SOBRECARGADOS

o
PtrType operator*() const:
se devuelve la dirección de la entidad a la que apunta el iterador;
o
PtrIter &operator++():
el iterador se incrementa (preincremento) a la siguiente posición;
o
bool operator==(PtrIter const &other) const:
se devuelve true si los dos iteradores son iguales;
o
bool operator!=(PtrIter const &other) const:
se devuelve true si los dos iteradores son desiguales;

DECLARACIÓN USING

La plantilla de clase PtrIter define PtrType:

o
using PtrType = decltype(&*Iterator()):

FUNCIONES MIEMBRO

Todos los miembros de std::iterator<std:::input_iterator_tag, ...> están disponibles, ya que FBB::PtrIter hereda de esta clase.

EJEMPLO

#include <algorithm>
#include <unordered_map>
#include <vector>
#include <cstring>
#include <iostream>
#include <bobcat/ptriter>
using namespace std;
using namespace FBB;
int main()
{
    cout << "Introduce líneas, la primera palabra será la clave del mapa; "
                                            "^D cuando hayas terminado.\n";
    string key;
    string line;
    unordered_map<string, string> map;
    while (cin >> key && getline(cin, line))    // llenar el mapa
        map[key] = line;
    cout << ’\n’;
                                        // inicializar un vector de
    vector<decltype(&*map.begin())>     // soporte, usando ptrIter
        support(ptrIter(map.begin()), ptrIter(map.end()));
                                        // ordenar ’soporte’
    typedef unordered_map<string, string>::value_type VT;
    sort(support.begin(), support.end(),
        [&](VT const *p1, VT const *p2)
        {
            return strcasecmp(p1->first.c_str(), p2->first.c_str()) < 0;
        }
    );
    for(auto &element: support)         // mostrar ordenado por clave
        cout << element->first << ’ ’ << element->second << ’\n’;
}
