pthread_testcancel(3) Manual de Funciones de Biblioteca pthread_testcancel(3)

NOMBRE

pthread_testcancel - solicitar la entrega de cualquier solicitud de cancelación pendiente

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
void pthread_testcancel(void);

DESCRIPCIÓN

Llamar a pthread_testcancel() crea un punto de cancelación dentro del hilo llamante, de modo que un hilo que esté ejecutando código que no contenga puntos de cancelación responda a una solicitud de cancelación.

Si la cancelabilidad está deshabilitada (usando pthread_setcancelstate(3)), o no hay ninguna solicitud de cancelación pendiente, entonces una llamada a pthread_testcancel() no tiene efecto.

VALOR DE RETORNO

Esta función no devuelve ningún valor. Si el hilo llamante es cancelado como consecuencia de una llamada a esta función, la función no devuelve.

ERRORES

Esta función siempre tiene éxito.

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_testcancel () Seguridad de hilo MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIA

glibc 2.0. POSIX.1-2001.

EJEMPLOS

Ver pthread_cleanup_push(3).

VER TAMBIÉN

pthread_cancel(3), pthread_cleanup_push(3), pthread_setcancelstate(3), pthreads(7)
