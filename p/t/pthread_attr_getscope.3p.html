PTHREAD_ATTR_GETSCOPE(3P) Manual de programador POSIX PTHREAD_ATTR_GETSCOPE(3P)

PRÓLOGO

Esta página del manual forma parte del Manual de programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_attr_getscope, pthread_attr_setscope — obtener y establecer el atributo contentionscope (HILOS EN TIEMPO REAL)

SINOPSIS

#include <pthread.h>
int pthread_attr_getscope(const pthread_attr_t *restrict attr,
    int *restrict contentionscope);
int pthread_attr_setscope(pthread_attr_t *attr, int contentionscope);

DESCRIPCIÓN

Las funciones pthread_attr_getscope() y pthread_attr_setscope(), respectivamente, obtienen y establecen el atributo contentionscope en el objeto attr.

El atributo contentionscope puede tener los valores PTHREAD_SCOPE_SYSTEM, que indica ámbito de contención de planificación del sistema, o PTHREAD_SCOPE_PROCESS, que indica ámbito de planificación del proceso. Los símbolos PTHREAD_SCOPE_SYSTEM y PTHREAD_SCOPE_PROCESS están definidos en la cabecera <pthread.h>.

El comportamiento no está definido si el valor especificado por el argumento attr para pthread_attr_getscope() o pthread_attr_setscope() no se refiere a un objeto de atributos de hilo inicializado.

VALOR DEVUELTO

Si tiene éxito, las funciones pthread_attr_getscope() y pthread_attr_setscope() devolverán cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_attr_setscope() fallará si:

ENOTSUP
Se intentó establecer el atributo a un valor no compatible.

La función pthread_attr_setscope() puede fallar si:

EINVAL
El valor de contentionscope no es válido.

Estas funciones no devolverán un código de error de [EINTR].

USO EN LA APLICACIÓN

Una vez establecidos estos atributos, se puede crear un hilo con los atributos especificados utilizando pthread_create(). El uso de estas rutinas no afecta al hilo en ejecución actual.

Consulte la Sección 2.9.4, Planificación de hilos para obtener más detalles sobre los atributos de planificación de hilos y sus configuraciones predeterminadas.

FUNDAMENTO

Si una implementación detecta que el valor especificado por el argumento attr para pthread_attr_getscope() o pthread_attr_setscope() no se refiere a un objeto de atributos de hilo inicializado, se recomienda que la función falle y devuelva un error [EINVAL].
