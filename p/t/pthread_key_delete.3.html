pthread_key_create(3) Manual de Funciones de Biblioteca pthread_key_create(3)

NOMBRE

pthread_key_create, pthread_key_delete, pthread_setspecific, pthread_getspecific - gestión de datos específicos de hilos

SINOPSIS

#include <pthread.h>
int pthread_key_create(pthread_key_t *key,
                       typeof(void (void *)) *destr_function;
int pthread_key_delete(pthread_key_t key);
int pthread_setspecific(pthread_key_t key, const void *pointer);
void * pthread_getspecific(pthread_key_t key);

DESCRIPCIÓN

Los programas a menudo necesitan variables globales o estáticas que tienen diferentes valores en diferentes hilos. Dado que los hilos comparten un espacio de memoria, esto no se puede lograr con variables normales. Los datos específicos de hilo son la respuesta de POSIX threads a esta necesidad.

Cada hilo posee un bloque de memoria privado, el área de datos específicos de hilo, o área TSD para abreviar. Esta área se indexa mediante claves TSD. El área TSD asocia valores de tipo void * a las claves TSD. Las claves TSD son comunes a todos los hilos, pero el valor asociado con una clave TSD dada puede ser diferente en cada hilo.

Para ser concretos, las áreas TSD pueden verse como arreglos de punteros void *, las claves TSD como índices enteros en estos arreglos, y el valor de una clave TSD como el valor del elemento correspondiente del arreglo en el hilo que llama.

Cuando se crea un hilo, su área TSD asocia inicialmente NULL con todas las claves.

pthread_key_create() asigna una nueva clave TSD. La clave se almacena en la ubicación apuntada por key. Existe un límite de PTHREAD_KEYS_MAX en el número de claves asignadas en un momento dado. El valor asociado inicialmente con la clave devuelta es NULL en todos los hilos que se ejecutan actualmente.

El argumento destr_function, si no es NULL, especifica una función destructora asociada con la clave. Cuando un hilo termina a través de pthread_exit() o por cancelación, destr_function se llama con argumentos el valor asociado con la clave en ese hilo. La destr_function no se llama si ese valor es NULL. El orden en que se llaman las funciones destructoras al terminar el hilo no está especificado.

Antes de que se llame a la función destructora, se asocia el valor NULL con la clave en el hilo actual. Sin embargo, una función destructora podría reasociar valores no NULL a esa clave o a otra clave. Para lidiar con esto, si después de que todas las destructoras se hayan llamado para todos los valores no NULL, todavía existen algunos valores no NULL con destructoras asociadas, entonces el proceso se repite. La implementación de glibc detiene el proceso después de PTHREAD_DESTRUCTOR_ITERATIONS iteraciones, incluso si permanecen algunos valores no NULL con descriptores asociados. Otras implementaciones pueden entrar en un bucle infinito.

pthread_key_delete() libera una clave TSD. No verifica si hay valores no NULL asociados con esa clave en los hilos que se ejecutan actualmente, ni llama a la función destructora asociada con la clave.

pthread_setspecific() cambia el valor asociado con key en el hilo que llama, almacenando el pointer dado en su lugar.

pthread_getspecific() devuelve el valor actualmente asociado con key en el hilo que llama.

VALOR DE RETORNO

pthread_key_create(), pthread_key_delete() y pthread_setspecific() devuelven 0 en caso de éxito y un código de error distinto de cero en caso de fallo. Si tiene éxito, pthread_key_create() almacena la clave recién asignada en la ubicación apuntada por su argumento key.

pthread_getspecific() devuelve el valor asociado con key en caso de éxito, y NULL en caso de error.

ERRORES

pthread_key_create() devuelve el siguiente código de error en caso de error:

EAGAIN
Ya se han asignado PTHREAD_KEYS_MAX claves.

pthread_key_delete() y pthread_setspecific() devuelven el siguiente código de error en caso de error:

EINVAL
key no es una clave TSD válida y asignada.

pthread_getspecific() devuelve NULL si key no es una clave TSD válida y asignada.

VER TAMBIÉN

pthread_create(3), pthread_exit(3), pthread_testcancel(3).

EJEMPLO

El siguiente fragmento de código asigna un búfer de 100 caracteres específico del hilo, con la recuperación automática al salir del hilo:

/* Clave para el búfer específico del hilo */
static pthread_key_t buffer_key;
/* Inicialización de la clave una sola vez */
static pthread_once_t buffer_key_once = PTHREAD_ONCE_INIT;
/* Asigna el búfer específico del hilo */
void buffer_alloc(void)
{
  pthread_once(&buffer_key_once, buffer_key_alloc);
  pthread_setspecific(buffer_key, malloc(100));
}
/* Devuelve el búfer específico del hilo */
char * get_buffer(void)
{
  return (char *) pthread_getspecific(buffer_key);
}
/* Asigna la clave */
static void buffer_key_alloc()
{
  pthread_key_create(&buffer_key, buffer_destroy);
}
/* Libera el búfer específico del hilo */
static void buffer_destroy(void * buf)
{
  free(buf);
}
