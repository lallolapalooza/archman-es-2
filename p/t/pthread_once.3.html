pthread_once(3) Manual de funciones de biblioteca pthread_once(3)

NOMBRE

pthread_once - inicialización de ejecución única

SINOPSIS

#include <pthread.h>

pthread_once_t once_control = PTHREAD_ONCE_INIT;

int pthread_once(pthread_once_t *once_control, typeof(void (void)) *init_routine;

DESCRIPCIÓN

El propósito de pthread_once() es asegurar que un fragmento de código de inicialización se ejecute como máximo una vez. El argumento once_control apunta a una variable estática o externa inicializada estáticamente a PTHREAD_ONCE_INIT.

La primera vez que se llama a pthread_once() con un argumento once_control dado, llama a init_routine sin argumentos y cambia el valor de la variable once_control para registrar que se ha realizado la inicialización. Las llamadas posteriores a pthread_once() con el mismo argumento once_control no hacen nada.

VALOR DE RETORNO

pthread_once() siempre devuelve 0.

ERRORES

Ninguno.
