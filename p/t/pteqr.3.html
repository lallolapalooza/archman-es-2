CPTEQR

Propósito:

!>
!> CPTEQR calcula todos los valores propios y, opcionalmente, los vectores
!> propios de una matriz tridiagonal simétrica positiva definida, primero
!> factorizando la matriz usando SPTTRF y luego llamando a CBDSQR para
!> calcular los valores singulares del factor bidiagonal.
!>
!> Esta rutina calcula los valores propios de la matriz tridiagonal positiva
!> definida con alta precisión relativa. Esto significa que si los valores
!> propios abarcan varios órdenes de magnitud en tamaño, entonces los
!> valores propios pequeños y los vectores propios correspondientes se
!> calcularán con mayor precisión que, por ejemplo, con el método QR estándar.
!>
!> Los vectores propios de una matriz hermitiana positiva definida completa
!> o de banda también se pueden encontrar si se han utilizado CHETRD, CHPTRD
!> o CHBTRD para reducir esta matriz a forma tridiagonal. (Sin embargo, la
!> reducción a forma tridiagonal puede impedir la posibilidad de obtener
!> alta precisión relativa en los valores propios pequeños de la matriz
!> original, si estos valores propios abarcan varios órdenes de magnitud).
!>

Parámetros

COMPZ 
!>          COMPZ es CHARACTER*1
!>          = 'N':  Solo calcular valores propios.
!>          = 'V':  Calcular también los vectores propios de la matriz
!>                  hermitiana original. El array Z contiene la matriz
!>                  unitaria utilizada para reducir la matriz original a
!>                  forma tridiagonal.
!>          = 'I':  Calcular también los vectores propios de la matriz
!>                  tridiagonal.
!>

N

!>          N es ENTERO
!>          El orden de la matriz.  N >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz
!>          tridiagonal.
!>          En la salida normal, D contiene los valores propios, en orden
!>          descendente.
!>

E

!>          E es un array REAL, dimensión (N-1)
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal.
!>          En la salida, E ha sido destruido.
!>

Z

!>          Z es un array COMPLEJO, dimensión (LDZ, N)
!>          En la entrada, si COMPZ = 'V', la matriz unitaria utilizada en
!>          la reducción a forma tridiagonal.
!>          En la salida, si COMPZ = 'V', los vectores propios ortonormales
!>          de la matriz hermitiana original;
!>          si COMPZ = 'I', los vectores propios ortonormales de la matriz
!>          tridiagonal.
!>          Si INFO > 0 en la salida, Z contiene los vectores propios
!>          asociados solo a los valores propios almacenados.
!>          Si COMPZ = 'N', entonces Z no se referencia.
!>

LDZ

!>          LDZ es ENTERO
!>          La dimensión principal del array Z.  LDZ >= 1, y si
!>          COMPZ = 'V' o 'I', LDZ >= max(1,N).
!>

WORK

!>          WORK es un array REAL, dimensión (4*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa.
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, y i es:
!>                <= N  la factorización de Cholesky de la matriz no se pudo
!>                      realizar porque el menor principal principal de orden i
!>                      no fue positivo.
!>                > N   el algoritmo SVD no convergió;
!>                      si INFO = N+i, i elementos fuera de la diagonal del
!>                      factor bidiagonal no convergieron a cero.
!>

NAME


dpteqr, spteqr, zpteqr – Computes the eigenvalues and eigenvectors of a symmetric positive definite tridiagonal matrix.






SYNOPSIS


   subroutine dpteqr(character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer info)

   subroutine spteqr(character compz, integer n, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldz, * ) z, integer ldz, real, dimension( * ) work, integer info)

   subroutine zpteqr(character compz, integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, complex*16, dimension( ldz, * ) z, integer ldz, double precision, dimension( * ) work, integer info)







DESCRIPTION


The routines compute all the eigenvalues and, optionally, the
    corresponding eigenvectors of a real symmetric positive definite tridiagonal
    matrix. The eigenvalues are computed to high relative accuracy, and the
    eigenvectors are computed in an order that depends on the algorithm.
    The routines first factorize the tridiagonal matrix using SPTTRF (for
    single precision) or DPTTRF (for double precision), and then use SBDSQR
    (for single precision) or ZBDSQR (for double precision) to compute the
    singular values of the bidiagonal factor.


The routines can also compute the eigenvectors of a full or band
    symmetric positive definite matrix if the matrix has been reduced to
    tridiagonal form using SSYTRD, SSPTRD, or SSBTRD (for single precision) or
    Dsytrd, DspRtrd, or DgbRtrd (for double precision). Note that the reduction
    to tridiagonal form may lead to a loss of accuracy in the computed eigenvalues
    if they range over many orders of magnitude.




Parameters




COMPZ


CHARACTER*1. Specifies whether to compute eigenvectors.




'N'


Compute eigenvalues only.


'V'


Compute eigenvalues and eigenvectors of the original symmetric matrix.
        The array Z must contain the orthogonal matrix used to
        reduce the original matrix to tridiagonal form.


'I'


Compute eigenvalues and eigenvectors of the tridiagonal matrix.






N


INTEGER. The order of the matrix. N >= 0.




D


DOUBLE PRECISION array, dimension (N). On entry, the diagonal
        elements of the tridiagonal matrix. On normal exit, contains the
        eigenvalues in descending order.




E


DOUBLE PRECISION array, dimension (N-1). On entry, the subdiagonal
        elements of the tridiagonal matrix. On exit, this array is destroyed.




Z


DOUBLE PRECISION array, dimension (LDZ, N). On entry, if
        COMPZ = 'V', the orthogonal matrix used in the reduction
        to tridiagonal form. On exit, if COMPZ = 'V', contains the
        orthonormal eigenvectors of the original symmetric matrix; if
        COMPZ = 'I', contains the orthonormal eigenvectors of the
        tridiagonal matrix. If INFO > 0 on exit, Z
        contains the eigenvectors associated with only the stored eigenvalues.
        If COMPZ = 'N', then Z is not referenced.




LDZ


INTEGER. The leading dimension of the array Z.
        LDZ >= 1. If COMPZ = 'V' or 'I',
        LDZ >= max(1, N).




WORK


DOUBLE PRECISION array, dimension (4*N).




INFO


INTEGER.
        
    
        
  • = 0: successful exit.
    • 
        
  • < 0: if INFO = -i, the i-th argument had an illegal
            value.
    • 
        
  • > 0: if INFO = i, and i is:
            
      
            
    • <= N: the Cholesky factorization of the matrix could not be
                performed because the leading principal minor of order i was
                not positive.
      • 
            
    • > N: the SVD algorithm failed to converge; if
                INFO = N+i, i off-diagonal elements of the
                bidiagonal factor did not converge to zero.

SPTEQR


Purpose:




!>
!> SPTEQR computes all eigenvalues and, optionally, eigenvectors of a
!> symmetric positive definite tridiagonal matrix by first factoring the
!> matrix using SPTTRF, and then calling SBDSQR to compute the singular
!> values of the bidiagonal factor.
!>
!> This routine computes the eigenvalues of the positive definite
!> tridiagonal matrix to high relative accuracy.  This means that if the
!> eigenvalues range over many orders of magnitude in size, then the
!> small eigenvalues and corresponding eigenvectors will be computed
!> more accurately than, for example, with the standard QR method.
!>
!> The eigenvectors of a full or band symmetric positive definite matrix
!> can also be found if SSYTRD, SSPTRD, or SSBTRD has been used to
!> reduce this matrix to tridiagonal form. (The reduction to tridiagonal
!> form, however, may preclude the possibility of obtaining high
!> relative accuracy in the small eigenvalues of the original matrix, if
!> these eigenvalues range over many orders of magnitude.)
!> 




Parameters


COMPZ

!>          COMPZ is CHARACTER*1
!>          = 'N':  Compute eigenvalues only.
!>          = 'V':  Compute eigenvectors of original symmetric
!>                  matrix also.  Array Z contains the orthogonal
!>                  matrix used to reduce the original matrix to
!>                  tridiagonal form.
!>          = 'I':  Compute eigenvectors of tridiagonal matrix also.
!> 


N


!>          N is INTEGER
!>          The order of the matrix.  N >= 0.
!> 


D


!>          D is REAL array, dimension (N)
!>          On entry, the n diagonal elements of the tridiagonal
!>          matrix.
!>          On normal exit, D contains the eigenvalues, in descending
!>          order.
!> 


E


!>          E is REAL array, dimension (N-1)
!>          On entry, the (n-1) subdiagonal elements of the tridiagonal
!>          matrix.
!>          On exit, E has been destroyed.
!> 


Z


!>          Z is REAL array, dimension (LDZ, N)
!>          On entry, if COMPZ = 'V', the orthogonal matrix used in the
!>          reduction to tridiagonal form.
!>          On exit, if COMPZ = 'V', the orthonormal eigenvectors of the
!>          original symmetric matrix;
!>          if COMPZ = 'I', the orthonormal eigenvectors of the
!>          tridiagonal matrix.
!>          If INFO > 0 on exit, Z contains the eigenvectors associated
!>          with only the stored eigenvalues.
!>          If  COMPZ = 'N', then Z is not referenced.
!> 


LDZ


!>          LDZ is INTEGER
!>          The leading dimension of the array Z.  LDZ >= 1, and if
!>          COMPZ = 'V' or 'I', LDZ >= max(1,N).
!> 


WORK


!>          WORK is REAL array, dimension (4*N)
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = i, and i is:
!>                <= N  the Cholesky factorization of the matrix could
!>                      not be performed because the leading principal
!>                      minor of order i was not positive.
!>                > N   the SVD algorithm failed to converge;
!>                      if INFO = N+i, i off-diagonal elements of the
!>                      bidiagonal factor did not converge to zero.
!>
