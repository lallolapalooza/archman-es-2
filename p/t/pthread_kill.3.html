pthread_kill(3) Manual de funciones de biblioteca pthread_kill(3)

NOMBRE

pthread_kill - enviar una señal a un hilo

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <signal.h>
int pthread_kill(pthread_t thread, int sig);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

pthread_kill():

    _POSIX_C_SOURCE >= 199506L || _XOPEN_SOURCE >= 500

DESCRIPCIÓN

La función pthread_kill() envía la señal sig al hilo thread, un hilo en el mismo proceso que el que llama. La señal se dirige asíncronamente al hilo thread.

Si sig es 0, no se envía ninguna señal, pero la verificación de errores aún se realiza.

VALOR DE RETORNO

En caso de éxito, pthread_kill() devuelve 0; en caso de error, devuelve un número de error y no se envía ninguna señal.

ERRORES

EINVAL
Se especificó una señal inválida.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_kill () Seguridad de hilos MT-Safe

VERSIÓNES

La implementación de glibc de pthread_kill() produce un error (EINVAL) en los intentos de enviar señales en tiempo real utilizadas internamente por la implementación de hilos NPTL. Consulte nptl(7) para obtener detalles.

POSIX.1-2008 recomienda que si una implementación detecta el uso de un ID de hilo después del final de su vida útil, pthread_kill() debe devolver el error ESRCH. La implementación de glibc devuelve este error en los casos en que se puede detectar un ID de hilo inválido. Pero tenga en cuenta también que POSIX dice que un intento de usar un ID de hilo cuya vida útil ha terminado produce un comportamiento indefinido, y un intento de usar un ID de hilo inválido en una llamada a pthread_kill() puede, por ejemplo, causar un fallo de segmentación.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Las disposiciones de las señales son a nivel de proceso: si se instala un manejador de señales, el manejador se invocará en el hilo thread, pero si la disposición de la señal es "detener", "continuar" o "terminar", esta acción afectará a todo el proceso.

VER TAMBIÉN

kill(2), sigaction(2), sigpending(2), pthread_self(3), pthread_sigmask(3), raise(3), pthreads(7), signal(7)
