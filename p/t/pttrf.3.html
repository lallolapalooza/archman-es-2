subrutina cpttrf (entero n, real, dimensión( * ) d, complex, dimensión( * ) e, entero info)

CPTTRF

Propósito:

!>
!> CPTTRF calcula la factorización L*D*L**H de una matriz tridiagonal
!> hermítica compleja y definida positiva A. La factorización también
!> puede considerarse que tiene la forma A = U**H *D*U.
!>

Parámetros

N 
!>          N es ENTERO
!>          El orden de la matriz A. N >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          En la entrada, los n elementos diagonales de la matriz tridiagonal
!>          A. En la salida, los n elementos diagonales de la matriz diagonal
!>          D de la factorización L*D*L**H de A.
!>

E

!>          E es un array COMPLEX, dimensión (N-1)
!>          En la entrada, los (n-1) elementos subdiagonales de la matriz
!>          tridiagonal A. En la salida, los (n-1) elementos subdiagonales
!>          del factor bidiagonal unitario L de la factorización L*D*L**H de A.
!>          E también puede considerarse como la superdiagonal del factor
!>          bidiagonal unitario U de la factorización U**H *D*U de A.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tuvo un valor ilegal
!>          > 0: si INFO = k, el menor principal principal de orden k
!>               no es positivo; si k < N, la factorización no pudo
!>               completarse, mientras que si k = N, la factorización fue
!>               completada, pero D(N) <= 0.
!>

NAME

pttrf - zpttrf

SYNOPSIS

 SUBROUTINE ZPTTRF( N, D, E, INFO )
  CHARACTER*1 D(*)
  COMPLEX*16 D( N )
  COMPLEX*16 E( N-1 )
  INTEGER INFO

Detailed Description

This subroutine is the LAPACK implementation of the algorithm.

Purpose:

ZPTTRF computes the factorization of a complex Hermitian positive definite tridiagonal matrix A in the form A = U * D * U**H and stores the factors U and D in the arrays U and D respectively. U is a real unit bidiagonal matrix and D is a real diagonal matrix. E is not used.

The factorization is computed by the method of Bunch-Kaufman, Bunch-Parlett, or Westlake-Arquilla as described in Section 5.4 of the LAPACK Users' Guide.

Arguments: 

 N       (input) INTEGER
         The order of the matrix A. N >= 0.

 D       (output) COMPLEX*16 array, dimension at least (N)
         On exit, D contains the diagonal blocks of the factorization.
         The diagonal blocks are of order 1. If D(i) is the i-th diagonal
         block, then D(i) is stored in D(i).

 E       (output) COMPLEX*16 array, dimension at least (N-1)
         On exit, E contains the super-diagonal blocks of the
         factorization. The j-th super-diagonal block is stored in E(j).

 INFO    (output) INTEGER
         = 0: successful exit
         < 0: if INFO = -k, the k-th argument had an illegal value
         > 0: if INFO = k, the leading principal minor of order k
              is not positive; if k < N, the factorization could not
              be completed, while if k = N, the factorization was
              completed, but D(N) <= 0.
