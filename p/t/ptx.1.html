PTX(1) Comandos de usuario PTX(1)

NOMBRE

ptx - produce un índice permutado del contenido de archivos

SINOPSIS

ptx [OPCIÓN]... [ENTRADA]... (sin -G)
ptx -G [OPCIÓN]... [ENTRADA [SALIDA]]

DESCRIPCIÓN

Genera un índice permutado, incluyendo contexto, de las palabras en los archivos de entrada.

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-A, --auto-reference
genera automáticamente referencias
-G, --traditional
comportarse más como 'ptx' de System V
-F, --flag-truncation=CADENA
usa CADENA para marcar truncamientos de línea. El valor predeterminado es '/'
-M, --macro-name=CADENA
nombre de macro a usar en lugar de 'xx'
-O, --format=roff
genera salida como directivas roff
-R, --right-side-refs
coloca las referencias a la derecha, no se cuentan en -w
-S, --sentence-regexp=EXPREG
para el final de líneas o el final de frases
-T, --format=tex
genera salida como directivas TeX
-W, --word-regexp=EXPREG
usa EXPREG para emparejar cada palabra clave
-b, --break-file=ARCHIVO
caracteres de separación de palabras en este ARCHIVO
-f, --ignore-case
convierte mayúsculas a minúsculas para la ordenación
-g, --gap-size=NÚMERO
tamaño del espacio en columnas entre campos de salida
-i, --ignore-file=ARCHIVO
lee la lista de palabras a ignorar de ARCHIVO
-o, --only-file=ARCHIVO
lee la lista de palabras a incluir solo de este ARCHIVO
-r, --references
el primer campo de cada línea es una referencia

-t, --typeset-mode - no implementado -

-w, --width=NÚMERO
ancho de salida en columnas, referencia excluida
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale
