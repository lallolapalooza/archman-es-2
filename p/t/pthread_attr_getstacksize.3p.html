PTHREAD_ATTR_GETSTACKSIZE(3P) Manual del programador POSIX PTHREAD_ATTR_GETSTACKSIZE(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_attr_getstacksize, pthread_attr_setstacksize — obtener y establecer el atributo de tamaño de pila

SINOPSIS

#include <pthread.h>
int pthread_attr_getstacksize(const pthread_attr_t *restrict attr,
    size_t *restrict stacksize);
int pthread_attr_setstacksize(pthread_attr_t *attr, size_t stacksize);

DESCRIPCIÓN

Las funciones pthread_attr_getstacksize() y pthread_attr_setstacksize(), respectivamente, obtienen y establecen el atributo de tamaño de pila (stacksize) en el objeto attr para la creación de hilos.

El atributo stacksize definirá el tamaño mínimo de pila (en bytes) asignado a la pila de los hilos creados.

El comportamiento no está definido si el valor especificado por el argumento attr a pthread_attr_getstacksize() o pthread_attr_setstacksize() no se refiere a un objeto de atributos de hilo inicializado.

VALOR DE RETORNO

Al completarse con éxito, pthread_attr_getstacksize() y pthread_attr_setstacksize() devolverán un valor de 0; de lo contrario, se devolverá un número de error para indicar el error.

La función pthread_attr_getstacksize() almacena el valor del atributo stacksize en stacksize si tiene éxito.

ERRORES

La función pthread_attr_setstacksize() fallará si:

EINVAL
El valor de stacksize es menor que {PTHREAD_STACK_MIN} o excede un límite impuesto por el sistema.

Estas funciones no devolverán un código de error de [EINTR].

RACIONALE

Si una implementación detecta que el valor especificado por el argumento attr a pthread_attr_getstacksize() o pthread_attr_setstacksize() no se refiere a un objeto de atributos de hilo inicializado, se recomienda que la función falle y reporte un error [EINVAL].
