PTHREAD_GETSPECIFIC(3P) Manual del programador POSIX PTHREAD_GETSPECIFIC(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_getspecific, pthread_setspecific — gestión de datos específicos de hilo

SINOPSIS

#include <pthread.h>
void *pthread_getspecific(pthread_key_t key);
int pthread_setspecific(pthread_key_t key, const void *value);

DESCRIPCIÓN

La función pthread_getspecific() devolverá el valor actualmente enlazado a la key especificada en nombre del hilo que la llama.

La función pthread_setspecific() asociará un value específico del hilo con una key obtenida mediante una llamada previa a pthread_key_create(). Diferentes hilos pueden enlazar valores diferentes a la misma clave. Estos valores son típicamente punteros a bloques de memoria asignada dinámicamente que se han reservado para su uso por el hilo que llama.

El efecto de llamar a pthread_getspecific() o pthread_setspecific() con un valor de key no obtenido de pthread_key_create() o después de que la key haya sido eliminada con pthread_key_delete() es indefinido.

Ambas pthread_getspecific() y pthread_setspecific() pueden llamarse desde una función destructora de datos específicos del hilo. Una llamada a pthread_getspecific() para la clave de datos específicos del hilo que se está destruyendo devolverá el valor NULL, a menos que el valor se cambie (después de que el destructor comience) mediante una llamada a pthread_setspecific(). Llamar a pthread_setspecific() desde una rutina destructora de datos específicos del hilo puede resultar en la pérdida de almacenamiento (después de al menos PTHREAD_DESTRUCTOR_ITERATIONS intentos de destrucción) o en un bucle infinito.

Ambas funciones pueden implementarse como macros.

VALOR DE RETORNO

La función pthread_getspecific() devolverá el dato específico del hilo asociado a la key dada. Si no hay ningún dato específico del hilo asociado a key, entonces se devolverá el valor NULL.

Si tiene éxito, la función pthread_setspecific() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

No se devuelven errores desde pthread_getspecific().

La función pthread_setspecific() fallará si:

ENOMEM
No hay suficiente memoria para asociar el valor no NULL con la clave.

La función pthread_setspecific() no devolverá un código de error de [EINTR].

FUNDAMENTO

El rendimiento y la facilidad de uso de pthread_getspecific() son críticos para las funciones que dependen del mantenimiento del estado en datos específicos del hilo. Dado que no se requiere que detecte errores, y dado que el único error que podría detectarse es el uso de una clave inválida, la función para pthread_getspecific() ha sido diseñada para favorecer la velocidad y la simplicidad sobre la notificación de errores.

Si una implementación detecta que el valor especificado por el argumento key a pthread_setspecific() no se refiere a una clave obtenida de pthread_key_create() o se refiere a una clave que ha sido eliminada con pthread_key_delete(), se recomienda que la función falle y reporte un error [EINVAL].
