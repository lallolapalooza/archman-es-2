PTSNAME(3P) Manual del Programador POSIX PTSNAME(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

ptsname — obtener el nombre del dispositivo esclavo de terminales pseudo

SINOPSIS

#include <stdlib.h>
char *ptsname(int fildes);

DESCRIPCIÓN

La función ptsname() devolverá el nombre del dispositivo terminal pseudo esclavo asociado a un dispositivo terminal pseudo maestro. El argumento fildes es un descriptor de archivo que se refiere al dispositivo maestro. La función ptsname() devolverá un puntero a una cadena que contiene la ruta del dispositivo esclavo correspondiente.

La función ptsname() no es necesariamente segura para hilos.

VALOR DE RETORNO

Al completarse con éxito, ptsname() devolverá un puntero a una cadena que es el nombre del dispositivo esclavo de terminal pseudo. En caso de error, ptsname() devolverá un puntero nulo y puede establecer errno. Esto podría ocurrir si fildes es un descriptor de archivo inválido o si el nombre del dispositivo esclavo no existe en el sistema de archivos.

La aplicación no debe modificar la cadena devuelta. El puntero devuelto puede invalidarse o el contenido de la cadena puede sobrescribirse con una llamada posterior a ptsname(). El puntero devuelto y el contenido de la cadena también pueden invalidarse si el hilo que llama termina.

ERRORES

La función ptsname() puede fallar si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
ENOTTY
El archivo asociado con el argumento fildes no es un dispositivo terminal pseudo maestro.
