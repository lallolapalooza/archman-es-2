PTO_VAR("1") HUGIN PTO_VAR("1")

NOMBRE

pto_var - cambiar variables de imagen dentro de archivos de proyecto Hugin .pto

SINOPSIS

pto_var [opciones] --opt|--link|--unlink|--set "lista de variables de imagen archivo.pto

DESCRIPCIÓN

pto_var es una herramienta de línea de comandos, adecuada para incluir en scripts de shell, y permite el cambio de variables de imagen dentro de un archivo de proyecto Hugin .pto. Las variables de optimización se pueden establecer, alterar, enlazar y desenlazar. Las siguientes variables de imagen están permitidas:

parámetros de posición: y, p, r, TrX, TrY, TrZ parámetros de lente: v, a, b, c, d, e, g, t parámetros fotométricos: EeV, Er, Eb, Vb, Vc, Vd, Vx, Vy, Ra, Rb, Rc, Rd, Re (los parámetros de viñeteado y respuesta se tratarán como un grupo).

Los números de imagen comienzan con cero. Si falta el número, esto se aplica a las variables de todas las imágenes (en este caso, se aplica un tratamiento especial a la posición de la imagen de anclaje). Un signo de exclamación antes de la variable eliminará la variable de la lista de variables a optimizar.

OPCIONES

-o|--output = archivo.pto
Archivo de salida Hugin PTO. Por defecto: <nombre de archivo>_var.pto
-h|--help
Muestra la ayuda
--opt listavar
Cambiar variables del optimizador
--modify-opt
Modificar las variables del optimizador existentes
(sin pto_var comenzará con un conjunto de variables vacío)
Ejemplos:
--opt=y,p,r           Optimizar guiñada, cabeceo y alabeo de todas las imágenes
                      (se aplica un tratamiento especial a la imagen de anclaje)
--opt=v0,b2           Optimizar el HFOV de la imagen 0 y la distorsión de barril
                      de la imagen 2
--opt=v,!v0           Optimizar el campo de visión para todas las imágenes excepto
                      la primera
--modify-opt --opt=!v no optimizará el campo de visión.
--opt=!a,!b,!c        No optimizar la distorsión (solo funciona con
                      el modificador --modify-opt)
--link listavar
Ejemplo:
--link=v3          Enlazar HFOV de la imagen 3
--link=a1,b1,c1    Enlazar parámetros de distorsión para la imagen 1
--unlink listavar
Ejemplos:
--unlink=v5        Desenlazar HFOV para la imagen 5
--unlink=a2,b2,c2  Desenlazar parámetros de distorsión para la imagen 2
--set listavar
Ejemplos:
--set=y0=0,r0=0,p0=0  Restablece la posición de la imagen 0
--set=Vx4=-10,Vy4=10  Establece el desplazamiento de viñeteado para la imagen 4
--set=v=20            Establece el campo de visión a 20 para todas las imágenes
--set=y=val+20        Aumenta la guiñada en 20 grados para todas las imágenes
--set=v=val*1.1       Aumenta el FOV en un 10% para todas las imágenes
--set=y=i*20        Establece la guiñada a 0, 20, 40, ...
--set-from-file nombrearchivo
Establece variables a nuevos valores
Lee la lista de variables desde un archivo
