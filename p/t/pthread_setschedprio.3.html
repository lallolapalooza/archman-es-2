pthread_setschedprio(3) Manual de funciones de la biblioteca pthread_setschedprio(3)

NOMBRE

pthread_setschedprio - establecer la prioridad de planificación de un hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_setschedprio(pthread_t thread, int prio);

DESCRIPCIÓN

La función pthread_setschedprio() establece la prioridad de planificación del hilo thread al valor especificado en prio. (Por el contrario, pthread_setschedparam(3) cambia tanto la política de planificación como la prioridad de un hilo.)

VALOR DE RETORNO

En caso de éxito, esta función devuelve 0; en caso de error, devuelve un número de error distinto de cero. Si pthread_setschedprio() falla, la prioridad de planificación de thread no se modifica.

ERRORES

EINVAL
prio no es válido para la política de planificación del hilo especificado.
EPERM
El llamante no tiene los privilegios adecuados para establecer la prioridad especificada.
ESRCH
No se encontró ningún hilo con el ID thread.

POSIX.1 también documenta un error ENOTSUP ("se intentó establecer la prioridad a un valor no soportado") para pthread_setschedparam(3).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_setschedprio () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIA

glibc 2.3.4. POSIX.1-2001.

NOTAS

Para obtener una descripción de los permisos requeridos y del efecto de cambiar la prioridad de planificación de un hilo, así como detalles de los rangos permitidos para las prioridades en cada política de planificación, consulte sched(7).
