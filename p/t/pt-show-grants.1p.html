NOMBRE

pt-show-grants - Canoniza e imprime las concesiones de MySQL para que puedas replicarlas, compararlas y controlarlas eficazmente.

SINOPSIS

Uso: pt-show-grants [OPCIONES] [DSN]

pt-show-grants muestra las concesiones (privilegios de usuario) de un servidor MySQL.

Ejemplos:

pt-show-grants
pt-show-grants --separate --revoke | diff othergrants.sql -

RIESGOS

Percona Toolkit es maduro, probado en el mundo real y bien testeado, pero todas las herramientas de base de datos pueden suponer un riesgo para el sistema y el servidor de base de datos. Antes de usar esta herramienta, por favor:

  • Lea la documentación de la herramienta.
  • Revise los "BUGS" conocidos de la herramienta.
  • Pruebe la herramienta en un servidor no productivo.
  • Haga una copia de seguridad de su servidor de producción y verifique las copias de seguridad.

DESCRIPCIÓN

pt-show-grants extrae, ordena e imprime las concesiones para las cuentas de usuario de MySQL.

¿Por qué querría esto? Hay varias razones.

La primera es replicar fácilmente usuarios de un servidor a otro; puede simplemente extraer las concesiones del primer servidor y pasar la salida directamente a otro servidor.

El segundo uso es colocar sus concesiones en control de versiones. Si realiza una copia de seguridad automatizada diaria de las concesiones en el control de versiones, obtendrá muchos conjuntos de cambios inútiles para concesiones que no cambian, porque MySQL imprime las concesiones reales en un orden aparentemente aleatorio. Por ejemplo, un día dirá

GRANT DELETE, INSERT, UPDATE ON `test`.* TO 'foo'@'%';

Y luego, otro día dirá

GRANT INSERT, DELETE, UPDATE ON `test`.* TO 'foo'@'%';

Las concesiones no han cambiado, pero el orden sí. Este script ordena las concesiones dentro de la línea, entre 'GRANT' y 'ON'. Si hay varias filas de SHOW GRANTS, también ordena las filas, excepto que siempre imprime la fila con la contraseña del usuario primero, si existe. Esto elimina tres tipos de inconsistencias que obtendrá al ejecutar SHOW GRANTS y evita conjuntos de cambios inútiles en el control de versiones.

Tercero, si desea comparar concesiones entre servidores, será difícil sin "canonizarlas", lo cual pt-show-grants hace. La salida es completamente comparable.

Con las opciones "--revoke", "--separate" y otras, pt-show-grants también facilita la revocación de privilegios específicos de los usuarios. Esto es tedioso de otra manera.

OPCIONES

Esta herramienta acepta argumentos de línea de comandos adicionales. Consulte la sección "SINOPSIS" y la información de uso para obtener detalles.

--ask-pass
Solicitar una contraseña al conectarse a MySQL.
--charset
forma corta: -A; tipo: string

Juego de caracteres predeterminado. Si el valor es utf8, establece el modo binario de Perl en STDOUT en utf8, pasa la opción mysql_enable_utf8 a DBD::mysql y ejecuta SET NAMES UTF8 después de conectarse a MySQL. Cualquier otro valor establece el modo binario en STDOUT sin la capa utf8 y ejecuta SET NAMES después de conectarse a MySQL.

--config
tipo: Array

Leer esta lista de archivos de configuración separados por comas; si se especifica, debe ser la primera opción en la línea de comandos.

--database
forma corta: -D; tipo: string

La base de datos a utilizar para la conexión.

--defaults-file
forma corta: -F; tipo: string

Solo leer opciones de mysql del archivo dado. Debe proporcionar una ruta de acceso absoluta.

--drop
Añadir DROP USER antes de cada usuario en la salida.
--flush
Añadir FLUSH PRIVILEGES después de la salida.

Es posible que necesite esto en servidores pre-4.1.1 si desea eliminar un usuario por completo.

--[no]encabezado
predeterminado: sí

Imprimir encabezado de volcado.

El encabezado precede a las concesiones volcadas. Se ve así:

-- Grants dumped by pt-show-grants 1.0.19
-- Dumped from server Localhost via UNIX socket, MySQL 5.0.82-log at 2009-10-26 10:01:04

Ver también "--[no]timestamp".

--help
Mostrar ayuda y salir.
--host
forma corta: -h; tipo: string

Conectar al host.

--ignore
tipo: array

Ignorar esta lista de usuarios separados por comas.

--only
tipo: array

Mostrar solo concesiones para esta lista de usuarios separados por comas.

--convert-MariaDB
Convertir sintaxis propietaria de MariaDB a formato MySQL válido.
--password
forma corta: -p; tipo: string

Contraseña a usar al conectarse. Si la contraseña contiene comas, deben escaparse con una barra invertida: "exam\,ple"

--pid
tipo: string

Crear el archivo PID dado. La herramienta no se iniciará si el archivo PID ya existe y el PID que contiene es diferente del PID actual. Sin embargo, si el archivo PID existe y el PID que contiene ya no se está ejecutando, la herramienta sobrescribirá el archivo PID con el PID actual. El archivo PID se elimina automáticamente cuando la herramienta sale.

--port
forma corta: -P; tipo: int

Número de puerto a usar para la conexión.

--revoke
Añadir sentencias REVOKE por cada sentencia GRANT.
--separate
Listar cada GRANT o REVOKE por separado.

La salida predeterminada del comando SHOW GRANTS de MySQL lista muchos privilegios en una sola línea. Con "--flush", coloca un FLUSH PRIVILEGES después de cada usuario, en lugar de una vez al final de toda la salida.

--set-vars
tipo: Array

Establecer las variables de MySQL en esta lista separada por comas de pares "variable=valor".

Por defecto, la herramienta establece:

wait_timeout=10000

Las variables especificadas en la línea de comandos anulan estos valores predeterminados. Por ejemplo, especificar "--set-vars wait_timeout=500" anula el valor predeterminado de 10000.

La herramienta imprime una advertencia y continúa si una variable no se puede establecer.

--[no]incluir-roles-no-utilizados
Al volcar roles de MySQL 8+, incluir roles no utilizados.
--socket
forma corta: -S; tipo: string

Archivo de socket a usar para la conexión.

--[no]marca-tiempo
predeterminado: sí

Añadir marca de tiempo al encabezado del volcado.

Ver también "--[no]encabezado".

--user
forma corta: -u; tipo: string

Usuario para iniciar sesión si no es el usuario actual.

--version
Mostrar versión y salir.

OPCIONES DSN

Estas opciones DSN se utilizan para crear un DSN. Cada opción se da como "opcion=valor". Las opciones distinguen entre mayúsculas y minúsculas, por lo que P y p no son la misma opción. No puede haber espacios en blanco antes o después del "=" y si el valor contiene espacios en blanco debe entrecomillarse. Las opciones DSN están separadas por comas. Consulte la página del manual de percona-toolkit para obtener detalles completos.

  • A

    dsn: charset; copia: sí

    Juego de caracteres predeterminado.

  • D

    dsn: database; copia: sí

    Base de datos predeterminada.

  • F

    dsn: mysql_read_default_file; copia: sí

    Solo leer opciones predeterminadas del archivo dado.

  • h

    dsn: host; copia: sí

    NAME

    pt-show-grants - display MySQL privileges for users

    SYNOPSIS

    pt-show-grants [OPTIONS] [DSN_OPTIONS] [USER [USER ...]]

    RISKS

    This tool requires the privileges it is displaying. If you specify a user who doesn't have the privileges to see all the privileges of another user, then the output will be incomplete. For example, if you run the tool as a user who cannot see the privileges for user "root", the output for "root" will be incomplete.

    The tool might expose passwords if you are not careful. See "ATTENTION".

    DESCRIPTION

    pt-show-grants displays the MySQL privileges for the specified users. If no users are specified, it displays privileges for all users on the server.

    The output is formatted as a series of GRANT statements that can be used to recreate the privileges.

    By default, pt-show-grants connects to the local MySQL server using a socket file. You can override this with DSN options.

    OPTIONS

    The tool accepts the following command-line arguments:

    • --ask-pass

      Prompt for a password before connecting to the database.

    • --defaults-file FILE

      Only read default options from FILE. Relevant options are [client] and [pt-show-grants]. See section "Using option files" in percona-prealloc.1.

    • --dry-run

      Print theGRANT statements to STDOUT, but don’t execute them.

    • --host HOST, -h HOST

      Connect to the MySQL server at HOST.

    • --password PASSWORD, -p PASSWORD

      Password to use when connecting. If password contains commas they must be escaped with a backslash: "exam\,ple"

    • --port PORT, -P PORT

      Port number to use for connection.

    • --socket SOCKET, -S SOCKET

      Socket file to use for connection.

    • --user USER, -u USER

      User for login if not current user.

    • --help

      Show help and exit.

    • --version

      Show program version and exit.

    DSN OPTIONS

    Percona Toolkit supports DSN (Data Source Name) options for connecting to MySQL. These are connection parameters that can be passed on the command line as parameters, and they are equivalent to DSN options. For example, the "host" DSN option is equivalent to the "-h" or "--host" command-line arguments.

    DSN options can be specified on the command line, or in the [client] or [pt-show-grants] sections of an option file.

    • h

      dsn: host; copy: yes

      Host to connect to.

    • p

      dsn: password; copy: yes

      Password to use when connecting. If password contains commas they must be escaped with a backslash: "exam\,ple"

    • P

      dsn: port; copy: yes

      Port number to use for connection.

    • S

      dsn: mysql_socket; copy: yes

      Socket file to use for connection.

    • u

      dsn: user; copy: yes

      User for login if not current user.

    • s

      dsn: mysql_ssl; copy: yes

      Create SSL connection

    ENVIRONMENT

    The environment variable "PTDEBUG" enables verbose debugging output to STDERR. To enable debugging and capture all output to a file, run the tool like:

    PTDEBUG=1 pt-show-grants ... > FILE 2>&1

    Be careful: debugging output is voluminous and can generate several megabytes of output.

    ATTENTION

    Using <PTDEBUG> might expose passwords. When debug is enabled, all command line parameters are shown in the output.

    SYSTEM REQUIREMENTS

    You need Perl, DBI, DBD::mysql, and some core packages that ought to be installed in any reasonably new version of Perl.
