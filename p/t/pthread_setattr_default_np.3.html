pthread_getattr_default_np(3) Manual de Funciones de Biblioteca pthread_getattr_default_np(3)

NOMBRE

pthread_getattr_default_np, pthread_setattr_default_np, - obtener o establecer atributos predeterminados de creación de hilos

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* ver feature_test_macros(7) */
#include <pthread.h>
int pthread_getattr_default_np(pthread_attr_t *attr);
int pthread_setattr_default_np(const pthread_attr_t *attr);

DESCRIPCIÓN

La función pthread_setattr_default_np() establece los atributos predeterminados utilizados para la creación de un nuevo hilo —es decir, los atributos que se utilizan cuando pthread_create(3) se llama con un segundo argumento que es NULL. Los atributos predeterminados se establecen utilizando los atributos proporcionados en *attr, un objeto de atributos de hilo inicializado previamente. Tenga en cuenta los siguientes detalles sobre el objeto de atributos proporcionado:

•
Los ajustes de atributos en el objeto deben ser válidos.
•
El atributo de dirección de pila no debe estar establecido en el objeto.
•
Establecer el atributo de tamaño de pila a cero significa dejar el tamaño de pila predeterminado sin cambios.

La función pthread_getattr_default_np() inicializa el objeto de atributos de hilo al que se refiere attr para que contenga los atributos predeterminados utilizados para la creación de hilos.

ERRORES

EINVAL
(pthread_setattr_default_np()) Una de las configuraciones de atributos en attr es inválida, o el atributo de dirección de pila está establecido en attr.
ENOMEM
(pthread_setattr_default_np()) Memoria insuficiente.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_getattr_default_np (), pthread_setattr_default_np () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU; de ahí el sufijo "_np" (no portable) en sus nombres.

HISTORIA

glibc 2.18.

EJEMPLOS

El siguiente programa utiliza pthread_getattr_default_np() para obtener los atributos de creación de hilos predeterminados y luego muestra varias configuraciones del objeto de atributos de hilo devuelto. Al ejecutar el programa, vemos la siguiente salida:


$ ./a.out;
Tamaño de pila:          8388608
Tamaño de guarda:          4096
Política de planificación:   SCHED_OTHER
Prioridad de planificación: 0
Estado de separación:       JOINABLE
Herencia de planificador:   INHERIT

Fuente del programa

#define _GNU_SOURCE
#include <err.h>
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
static void
display_pthread_attr(pthread_attr_t *attr)
{
    int s;
    size_t stacksize;
    size_t guardsize;
    int policy;
    struct sched_param schedparam;
    int detachstate;
    int inheritsched;
    s = pthread_attr_getstacksize(attr, &stacksize);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstacksize");
    printf("Tamaño de pila:          %zu\n", stacksize);
    s = pthread_attr_getguardsize(attr, &guardsize);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("Tamaño de guarda:          %zu\n", guardsize);
    s = pthread_attr_getschedpolicy(attr, &policy);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedpolicy");
    printf("Política de planificación:   %s\n",
           (policy == SCHED_FIFO) ? "SCHED_FIFO" :
           (policy == SCHED_RR) ? "SCHED_RR" :
           (policy == SCHED_OTHER) ? "SCHED_OTHER" : "[desconocido]");
    s = pthread_attr_getschedparam(attr, &schedparam);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedparam");
    printf("Prioridad de planificación: %d\n", schedparam.sched_priority);
    s = pthread_attr_getdetachstate(attr, &detachstate);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getdetachstate");
    printf("Estado de separación:       %s\n",
           (detachstate == PTHREAD_CREATE_DETACHED) ? "DETACHED" :
           (detachstate == PTHREAD_CREATE_JOINABLE) ? "JOINABLE" :
           "???");
    s = pthread_attr_getinheritsched(attr, &inheritsched);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getinheritsched");
    printf("Herencia de planificador:   %s\n",
           (inheritsched == PTHREAD_INHERIT_SCHED) ? "INHERIT" :
           (inheritsched == PTHREAD_EXPLICIT_SCHED) ? "EXPLICIT" :
           "???");
}
int
main(void)
{
    int s;
    pthread_attr_t attr;
    s = pthread_getattr_default_np(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getattr_default_np");
    display_pthread_attr(&attr);
    exit(EXIT_SUCCESS);
}
