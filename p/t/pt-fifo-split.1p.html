NOMBRE

pt-fifo-split - Divide archivos y canaliza líneas a una fifo sin dividir realmente.

SINOPSIS

Uso: pt-fifo-split [OPCIONES] [ARCHIVO]

pt-fifo-split divide ARCHIVO y canaliza líneas a una fifo. Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Lee hugefile.txt en fragmentos de un millón de líneas sin dividirlo físicamente:

pt-fifo-split --lines 1000000 hugefile.txt
while [ -e /tmp/pt-fifo-split ]; do cat /tmp/pt-fifo-split; done

DESCRIPCIÓN

pt-fifo-split le permite leer de un archivo como si solo contuviera algunas de las líneas del archivo. Cuando lo vuelve a leer, contiene el siguiente conjunto de líneas; cuando ha pasado por él por completo, el archivo desaparece. Esto solo funciona en sistemas operativos tipo Unix.

Puede especificar varios archivos en la línea de comandos. Si no especifica ninguno, o si usa el nombre de archivo especial "-", las líneas se leen de la entrada estándar.

OPCIONES

Esta herramienta acepta argumentos adicionales de línea de comandos. Consulte la "SINOPSIS" y la información de uso para obtener detalles.

--config
tipo: Array

Lea esta lista de archivos de configuración separados por comas; si se especifica, debe ser la primera opción en la línea de comandos.

--fifo
tipo: cadena; predeterminado: /tmp/pt-fifo-split

El nombre de la fifo desde la cual se pueden leer las líneas.

--force
Elimina la fifo si ya existe, y luego la crea de nuevo.
--help
Muestra la ayuda y sale.
--lines
tipo: entero; predeterminado: 1000

El número de líneas a leer en cada fragmento.

--offset
tipo: entero; predeterminado: 0

Comienza en la N-ésima línea. Si el argumento es 0, se imprimen todas las líneas en la fifo. Si es 1, entonces comenzando desde la primera línea, se imprimen las líneas (exactamente lo mismo que 0). Si es 2, se omite la primera línea y se imprimen la segunda y subsiguientes líneas en la fifo.

--pid
tipo: cadena

Crea el archivo PID dado. La herramienta no se iniciará si el archivo PID ya existe y el PID que contiene es diferente del PID actual. Sin embargo, si el archivo PID existe y el PID que contiene ya no se está ejecutando, la herramienta sobrescribirá el archivo PID con el PID actual. El archivo PID se elimina automáticamente cuando la herramienta sale.

--statistics
Imprime estadísticas entre fragmentos. Las estadísticas son el número de fragmentos, el número de líneas, el tiempo transcurrido y las líneas por segundo en general y durante el último fragmento.
--version
Muestra la versión y sale.

ENTORNO

La variable de entorno "PTDEBUG" habilita la salida detallada de depuración en STDERR. Para habilitar la depuración y capturar toda la salida en un archivo, ejecute la herramienta como:

PTDEBUG=1 pt-fifo-split ... > ARCHIVO 2>&1

Tenga cuidado: la salida de depuración es voluminosa y puede generar varios megabytes de salida.

ATENCIÓN

El uso de <PTDEBUG> podría exponer contraseñas. Cuando la depuración está habilitada, todos los parámetros de la línea de comandos se muestran en la salida.

REQUISITOS DEL SISTEMA
