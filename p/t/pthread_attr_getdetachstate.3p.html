PTHREAD_ATTR_GETDETACHSTATE(3P) Manual del Programador POSIX PTHREAD_ATTR_GETDETACHSTATE(3P)

PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_attr_getdetachstate, pthread_attr_setdetachstate — obtener y establecer el atributo detachstate

SINOPSIS

#include <pthread.h>
int pthread_attr_getdetachstate(const pthread_attr_t *attr,
    int *detachstate);
int pthread_attr_setdetachstate(pthread_attr_t *attr, int detachstate);

DESCRIPCIÓN

El atributo detachstate controla si el hilo se crea en un estado separado (detached). Si el hilo se crea separado, entonces el uso del ID del hilo recién creado por la función pthread_detach() o pthread_join() es un error.

Las funciones pthread_attr_getdetachstate() y pthread_attr_setdetachstate(), respectivamente, obtienen y establecen el atributo detachstate en el objeto attr.

Para pthread_attr_getdetachstate(), detachstate se establecerá en PTHREAD_CREATE_DETACHED o PTHREAD_CREATE_JOINABLE.

Para pthread_attr_setdetachstate(), la aplicación establecerá detachstate en PTHREAD_CREATE_DETACHED o PTHREAD_CREATE_JOINABLE.

Un valor de PTHREAD_CREATE_DETACHED provocará que todos los hilos creados con attr estén en estado separado, mientras que usar un valor de PTHREAD_CREATE_JOINABLE provocará que todos los hilos creados con attr estén en estado unible. El valor predeterminado del atributo detachstate será PTHREAD_CREATE_JOINABLE.

El comportamiento no está definido si el valor especificado por el argumento attr de pthread_attr_getdetachstate() o pthread_attr_setdetachstate() no se refiere a un objeto de atributos de hilo inicializado.

VALOR DE RETORNO

Al completarse con éxito, pthread_attr_getdetachstate() y pthread_attr_setdetachstate() devolverán un valor de 0; de lo contrario, se devolverá un número de error para indicar el error.

La función pthread_attr_getdetachstate() almacena el valor del atributo detachstate en detachstate si tiene éxito.

ERRORES

La función pthread_attr_setdetachstate() fallará si:

EINVAL
El valor de detachstate no era válido

Estas funciones no devolverán un código de error de [EINTR].

Las siguientes secciones son informativas.

EJEMPLOS

Recuperación del atributo detachstate

Este ejemplo muestra cómo obtener el atributo detachstate de un objeto de atributos de hilo.

#include <pthread.h>
pthread_attr_t thread_attr;
int            detachstate;
int            rc;
/* código para inicializar thread_attr */
...
rc = pthread_attr_getdetachstate (&thread_attr, &detachstate);
if (rc!=0) {
    /* manejar error */
    ...
}
else {
    /* los valores legales para detachstate son:
     * PTHREAD_CREATE_DETACHED o PTHREAD_CREATE_JOINABLE
     */
     ...
}

USO POR LA APLICACIÓN

Ninguno.

FUNDAMENTACIÓN

Si una implementación detecta que el valor especificado por el argumento attr de pthread_attr_getdetachstate() o pthread_attr_setdetachstate() no se refiere a un objeto de atributos de hilo inicializado, se recomienda que la función falle y reporte un error [EINVAL].

Ninguna.
