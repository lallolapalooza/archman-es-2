pthread_mutexattr_getpshared(3) Manual de funciones de biblioteca pthread_mutexattr_getpshared(3)

NOMBRE

pthread_mutexattr_getpshared, pthread_mutexattr_setpshared - obtener/establecer atributo de mutex compartido entre procesos

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_mutexattr_getpshared(
                      const pthread_mutexattr_t *restrict attr,
                      int *restrict pshared);
int pthread_mutexattr_setpshared(pthread_mutexattr_t *attr,
                      int pshared);

DESCRIPCIÓN

Estas funciones obtienen y establecen el atributo compartido entre procesos en un objeto de atributos de mutex. Este atributo debe configurarse correctamente para garantizar el funcionamiento correcto y eficiente de un mutex creado con este objeto de atributos.

El atributo compartido entre procesos puede tener uno de los siguientes valores:

PTHREAD_PROCESS_PRIVATE
Los mutexes creados con este objeto de atributos solo deben compartirse entre hilos del mismo proceso que inicializó el mutex. Este es el valor predeterminado para el atributo de mutex compartido entre procesos.
PTHREAD_PROCESS_SHARED
Los mutexes creados con este objeto de atributos pueden compartirse entre cualquier hilo que tenga acceso a la memoria que contiene el objeto, incluidos hilos en diferentes procesos.

pthread_mutexattr_getpshared() coloca el valor del atributo compartido entre procesos del objeto de atributos de mutex al que se refiere attr en la ubicación a la que apunta pshared.

pthread_mutexattr_setpshared() establece el valor del atributo compartido entre procesos del objeto de atributos de mutex al que se refiere attr al valor especificado en pshared.

Si attr no se refiere a un objeto de atributos de mutex inicializado, el comportamiento es indefinido.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven un número de error positivo.

ERRORES

pthread_mutexattr_setpshared() puede fallar con los siguientes errores:

EINVAL
El valor especificado en pshared no es válido.
ENOTSUP
pshared es PTHREAD_PROCESS_SHARED pero la implementación no admite mutexes compartidos entre procesos.

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

VER TAMBIÉN
