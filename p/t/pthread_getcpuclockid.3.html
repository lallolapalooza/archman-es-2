pthread_getcpuclockid(3) Manual de funciones de biblioteca pthread_getcpuclockid(3)

NOMBRE

pthread_getcpuclockid - obtener el ID del reloj de tiempo de CPU de un hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
#include <time.h>
int pthread_getcpuclockid(pthread_t thread, clockid_t *clockid);

DESCRIPCIÓN

La función pthread_getcpuclockid() obtiene el ID del reloj de tiempo de CPU del hilo cuyo ID se proporciona en thread, y lo devuelve en la ubicación apuntada por clockid.

VALOR DE RETORNO

En caso de éxito, esta función devuelve 0; en caso de error, devuelve un número de error distinto de cero.

ERRORES

ENOENT
Los relojes de tiempo de CPU por hilo no son compatibles con el sistema.
ESRCH
No se encontró ningún hilo con el ID thread.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_getcpuclockid () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.2. POSIX.1-2001.

NOTAS

Cuando thread se refiere al hilo que llama, esta función devuelve un identificador que se refiere al mismo reloj manipulado por clock_gettime(2) y clock_settime(2) cuando se le da el ID de reloj CLOCK_THREAD_CPUTIME_ID.

EJEMPLOS

El siguiente programa crea un hilo y luego utiliza clock_gettime(2) para obtener el tiempo de CPU total del proceso, y el tiempo de CPU por hilo consumido por los dos hilos. La siguiente sesión de terminal muestra un ejemplo de ejecución:


$ ./a.out;
Hilo principal durmiendo
Subproceso iniciando bucle infinito
El hilo principal consume algo de tiempo de CPU...
Tiempo de CPU total del proceso:    1.368
Tiempo de CPU del hilo principal:      0.376
Tiempo de CPU del subproceso:        0.992

Fuente del programa

/* Enlazar con "-lrt" */
#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/time.h>
#include <time.h>
#include <unistd.h>
static void *
thread_start(void *arg)
{
    printf("Subproceso iniciando bucle infinito\n");
    for (;;)
        continue;
}
static void
pclock(char *msg, clockid_t cid)
{
    struct timespec ts;
    printf("%s", msg);
    if (clock_gettime(cid, &ts) == -1)
        err(EXIT_FAILURE, "clock_gettime");
    printf("%4jd.%03ld\n", (intmax_t) ts.tv_sec, ts.tv_nsec / 1000000);
}
int
main(void)
{
    pthread_t thread;
    clockid_t cid;
    int s;
    s = pthread_create(&thread, NULL, thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    printf("Hilo principal durmiendo\n");
    sleep(1);
    printf("El hilo principal consume algo de tiempo de CPU...\n");
    for (unsigned int j = 0; j < 2000000; j++)
        getppid();
    pclock("Tiempo de CPU total del proceso: ", CLOCK_PROCESS_CPUTIME_ID);
    s = pthread_getcpuclockid(pthread_self(), &cid);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getcpuclockid");
    pclock("Tiempo de CPU del hilo principal:   ", cid);
    /* Las cuatro líneas de código anteriores podrían haber sido reemplazadas por:
       pclock("Tiempo de CPU del hilo principal:   ", CLOCK_THREAD_CPUTIME_ID); */
    s = pthread_getcpuclockid(thread, &cid);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getcpuclockid");
    pclock("Tiempo de CPU del subproceso: 1    ", cid);
    exit(EXIT_SUCCESS);         /* Termina ambos hilos */
}

VER TAMBIÉN

clock_gettime(2), clock_settime(2), timer_create(2), clock_getcpuclockid(3), pthread_self(3), pthreads(7), time(7)
