pthread_mutexattr_setrobust(3) Manual de Funciones de Biblioteca pthread_mutexattr_setrobust(3)

NOMBRE

pthread_mutexattr_getrobust, pthread_mutexattr_setrobust - obtener y establecer el atributo de robustez de un objeto de atributos de mutex

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_mutexattr_getrobust(const pthread_mutexattr_t *attr,
                                int *robustness);
int pthread_mutexattr_setrobust(pthread_mutexattr_t *attr,
                                int robustness);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

pthread_mutexattr_getrobust(), pthread_mutexattr_setrobust():

    _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

La función pthread_mutexattr_getrobust() coloca el valor del atributo de robustez del objeto de atributos de mutex al que se refiere attr en *robustness. La función pthread_mutexattr_setrobust() establece el valor del atributo de robustez del objeto de atributos de mutex al que se refiere attr al valor especificado en *robustness.

El atributo de robustez especifica el comportamiento del mutex cuando el hilo propietario muere sin desbloquear el mutex. Los siguientes valores son válidos para robustness:

PTHREAD_MUTEX_STALLED
Este es el valor predeterminado para un objeto de atributos de mutex. Si un mutex se inicializa con el atributo PTHREAD_MUTEX_STALLED y su propietario muere sin desbloquearlo, el mutex permanece bloqueado y cualquier intento futuro de llamar a pthread_mutex_lock(3) en el mutex se bloqueará indefinidamente.
PTHREAD_MUTEX_ROBUST
Si un mutex se inicializa con el atributo PTHREAD_MUTEX_ROBUST y su propietario muere sin desbloquearlo, cualquier intento futuro de llamar a pthread_mutex_lock(3) en este mutex tendrá éxito y devolverá EOWNERDEAD para indicar que el propietario original ya no existe y que el mutex está en un estado inconsistente. Normalmente, después de que se devuelve EOWNERDEAD, el siguiente propietario debe llamar a pthread_mutex_consistent(3) en el mutex adquirido para dejarlo consistente nuevamente antes de usarlo.
Si el siguiente propietario desbloquea el mutex usando pthread_mutex_unlock(3) antes de hacerlo consistente, el mutex será inutilizable permanentemente y cualquier intento posterior de bloquearlo usando pthread_mutex_lock(3) fallará con el error ENOTRECOVERABLE. La única operación permitida en dicho mutex es pthread_mutex_destroy(3).
Si el siguiente propietario termina antes de llamar a pthread_mutex_consistent(3), las operaciones posteriores de pthread_mutex_lock(3) en este mutex seguirán devolviendo EOWNERDEAD.

Tenga en cuenta que el argumento attr de pthread_mutexattr_getrobust() y pthread_mutexattr_setrobust() debe referirse a un objeto de atributos de mutex que fue inicializado por pthread_mutexattr_init(3), de lo contrario, el comportamiento es indefinido.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven un número de error positivo.

En la implementación de glibc, pthread_mutexattr_getrobust() siempre devuelve cero.

ERRORES

EINVAL
Se pasó un valor distinto de PTHREAD_MUTEX_STALLED o PTHREAD_MUTEX_ROBUST a pthread_mutexattr_setrobust().

VERSIONES

En la implementación de Linux, cuando se utilizan mutex robustos que comparten procesos, un hilo en espera también recibe la notificación EOWNERDEAD si el propietario de un mutex robusto realiza un execve(2) sin desbloquear primero el mutex. POSIX.1 no especifica este detalle, pero el mismo comportamiento también ocurre en al menos otras implementaciones.

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.12. POSIX.1-2008.

Antes de la adición de pthread_mutexattr_getrobust() y pthread_mutexattr_setrobust() a POSIX, glibc definía las siguientes funciones no estándar equivalentes si se definía _GNU_SOURCE:

[[deprecated]]
int pthread_mutexattr_getrobust_np(const pthread_mutexattr_t *attr,
                                   int *robustness);
[[deprecated]]
int pthread_mutexattr_setrobust_np(const pthread_mutexattr_t *attr,
                                   int robustness);

Correspondientemente, las constantes PTHREAD_MUTEX_STALLED_NP y PTHREAD_MUTEX_ROBUST_NP también se definieron.

Estas API específicas de GNU, que aparecieron por primera vez en glibc 2.4, están hoy obsoletas y no deben usarse en programas nuevos; desde glibc 2.34, estas API están marcadas como obsoletas.

El siguiente programa demuestra el uso del atributo de robustez de un objeto de atributos de mutex. En este programa, un hilo que posee el mutex muere prematuramente sin desbloquear el mutex. Posteriormente, el hilo principal adquiere el mutex con éxito y recibe el error EOWNERDEAD, después de lo cual hace que el mutex sea consistente.

ERRORS

La función pthread_mutexattr_setrobust puede fallar por los siguientes motivos:

EINVAL
El valor especificado en robustattr no es válido.

VERSIONS

La constante PTHREAD_MUTEX_ROBUST fue añadida a glibc en la versión 2.12.

STANDARDS

pthread_mutexattr_setrobust es una extensión de POSIX.1-2008.

HISTORY

La característica de robustez de las condiciones de error de los mutexes fue introducida por primera vez en FreeBSD 7.0.

EXAMPLES

El siguiente fragmento de código muestra cómo establecer el atributo de robustez de un mutex a PTHREAD_MUTEX_ROBUST:

#include <pthread.h>
#include <stdlib.h>
#include <stdio.h>

// ...

pthread_mutexattr_t attr;
int ret;

// Inicializar atributos del mutex
ret = pthread_mutexattr_init(&attr);
if (ret != 0) {
    fprintf(stderr, "pthread_mutexattr_init() failed\n");
    exit(EXIT_FAILURE);
}

// Establecer el atributo de robustez
ret = pthread_mutexattr_setrobust(&attr, PTHREAD_MUTEX_ROBUST);
if (ret != 0) {
    fprintf(stderr, "pthread_mutexattr_setrobust() failed\n");
    // Limpiar atributos antes de salir
    pthread_mutexattr_destroy(&attr);
    exit(EXIT_FAILURE);
}

// ... usar attr para inicializar un mutex ...

// Un ejemplo de manejo de errores (simplificado) en el lado del lock
int s = pthread_mutex_lock(&your_mutex);
if (s != 0) {
    // Manejar error, por ejemplo, si el mutex está en estado robusto
    // de un proceso anterior.
    // En un programa real, deberías manejar los diferentes valores de s
    // como EOWNERDEAD, EDEADLK, etc.
    fprintf(stderr, "pthread_mutex_lock() unexpectedly failed\n");
    errc(EXIT_FAILURE, s, "pthread_mutex_lock");
}
