subrutina cptts2 (entero iuplo, entero n, entero nrhs, real, dimension( * ) d, complejo, dimension( * ) e, complejo, dimension( ldb, * ) b, entero ldb)

CPTTS2 resuelve un sistema tridiagonal de la forma AX=B usando la factorización L D LH calculada por spttrf.

Propósito:

!>
!> CPTTS2 resuelve un sistema tridiagonal de la forma
!>    A * X = B
!> usando la factorización A = U**H*D*U o A = L*D*L**H calculada por CPTTRF.
!> D es una matriz diagonal especificada en el vector D, U (o L) es una matriz
!> bidiagonal unitaria cuya superdiagonal (subdiagonal) se especifica en
!> el vector E, y X y B son matrices N por NRHS.
!>

Parámetros

IUPLO 
!>          IUPLO es ENTERO
!>          Especifica la forma de la factorización y si el vector E es
!>          la superdiagonal del factor bidiagonal superior U o la
!>          subdiagonal del factor bidiagonal inferior L.
!>          = 1:  A = U**H *D*U, E es la superdiagonal de U
!>          = 0:  A = L*D*L**H, E es la subdiagonal de L
!>

N

!>          N es ENTERO
!>          El orden de la matriz tridiagonal A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

D

!>          D es un array REAL, dimension (N)
!>          Los n elementos diagonales de la matriz diagonal D de la
!>          factorización A = U**H *D*U o A = L*D*L**H.
!>

E

!>          E es un array COMPLEJO, dimension (N-1)
!>          Si IUPLO = 1, los (n-1) elementos superdiagonales del factor
!>          bidiagonal unitario U de la factorización A = U**H*D*U.
!>          Si IUPLO = 0, los (n-1) elementos subdiagonales del factor
!>          bidiagonal unitario L de la factorización A = L*D*L**H.
!>

B

!>          B es un array COMPLEJO, dimension (LDB,NRHS)
!>          En la entrada, los vectores del lado derecho B para el sistema de
!>          ecuaciones lineales.
!>          En la salida, los vectores solución, X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

NAME


ptts2 - solves a tridiagonal system of the form AX=B using the L D LH
    factorization computed by spttrf.






SYNOPSIS


subroutine ptts2(iuplo, n, nrhs, d, e, b, ldb)
    integer, intent(in) :: iuplo, n, nrhs, ldb
    double precision, dimension(*) :: d
    complex*16, dimension(*) :: e
    complex*16, dimension(ldb, *) :: b







Detailed Description


Purpose:




!>
!> ZPTTS2 solves a tridiagonal system of the form
!>    A * X = B
!> using the factorization A = U**H *D*U or A = L*D*L**H computed by ZPTTRF.
!> D is a diagonal matrix specified in the vector D, U (or L) is a unit
!> bidiagonal matrix whose superdiagonal (subdiagonal) is specified in
!> the vector E, and X and B are N by NRHS matrices.
!> 




Parameters


IUPLO

!>          IUPLO is INTEGER
!>          Specifies the form of the factorization and whether the
!>          vector E is the superdiagonal of the upper bidiagonal factor
!>          U or the subdiagonal of the lower bidiagonal factor L.
!>          = 1:  A = U**H *D*U, E is the superdiagonal of U
!>          = 0:  A = L*D*L**H, E is the subdiagonal of L
!> 


N


!>          N is INTEGER
!>          The order of the tridiagonal matrix A.  N >= 0.
!> 


NRHS


!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!> 


D


!>          D is DOUBLE PRECISION array, dimension (N)
!>          The n diagonal elements of the diagonal matrix D from the
!>          factorization A = U**H *D*U or A = L*D*L**H.
!> 


E


!>          E is COMPLEX*16 array, dimension (N-1)
!>          If IUPLO = 1, the (n-1) superdiagonal elements of the unit
!>          bidiagonal factor U from the factorization A = U**H*D*U.
!>          If IUPLO = 0, the (n-1) subdiagonal elements of the unit
!>          bidiagonal factor L from the factorization A = L*D*L**H.
!> 


B


!>          B is COMPLEX*16 array, dimension (LDB,NRHS)
!>          On entry, the right hand side vectors B for the system of
!>          linear equations.
!>          On exit, the solution vectors, X.
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>
