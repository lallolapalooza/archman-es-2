pthread_mutexattr_setrobust(3) Manual de funciones de biblioteca pthread_mutexattr_setrobust(3)

NOMBRE

pthread_mutexattr_getrobust, pthread_mutexattr_setrobust - obtener y establecer el atributo de robustez de un objeto de atributos de mutex

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_mutexattr_getrobust(const pthread_mutexattr_t *attr,
                                int *robustness);
int pthread_mutexattr_setrobust(pthread_mutexattr_t *attr,
                                int robustness);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

pthread_mutexattr_getrobust(), pthread_mutexattr_setrobust():

    _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

La función pthread_mutexattr_getrobust() coloca el valor del atributo de robustez del objeto de atributos de mutex al que se refiere attr en *robustness. La función pthread_mutexattr_setrobust() establece el valor del atributo de robustez del objeto de atributos de mutex al que se refiere attr al valor especificado en *robustness.

El atributo de robustez especifica el comportamiento del mutex cuando el hilo propietario muere sin desbloquear el mutex. Los siguientes valores son válidos para robustness:

PTHREAD_MUTEX_STALLED
Este es el valor predeterminado para un objeto de atributos de mutex. Si un mutex se inicializa con el atributo PTHREAD_MUTEX_STALLED y su propietario muere sin desbloquearlo, el mutex permanece bloqueado posteriormente y cualquier intento futuro de llamar a pthread_mutex_lock(3) en el mutex se bloqueará indefinidamente.
PTHREAD_MUTEX_ROBUST
Si un mutex se inicializa con el atributo PTHREAD_MUTEX_ROBUST y su propietario muere sin desbloquearlo, cualquier intento futuro de llamar a pthread_mutex_lock(3) en este mutex tendrá éxito y devolverá EOWNERDEAD para indicar que el propietario original ya no existe y el mutex está en un estado inconsistente. Normalmente, después de que se devuelve EOWNERDEAD, el siguiente propietario debería llamar a pthread_mutex_consistent(3) en el mutex adquirido para hacerlo consistente nuevamente antes de usarlo más.
Si el siguiente propietario desbloquea el mutex usando pthread_mutex_unlock(3) antes de hacerlo consistente, el mutex será permanentemente inutilizable y cualquier intento posterior de bloquearlo usando pthread_mutex_lock(3) fallará con el error ENOTRECOVERABLE. La única operación permitida en dicho mutex es pthread_mutex_destroy(3).
Si el siguiente propietario termina antes de llamar a pthread_mutex_consistent(3), las operaciones posteriores de pthread_mutex_lock(3) en este mutex seguirán devolviendo EOWNERDEAD.

Tenga en cuenta que el argumento attr de pthread_mutexattr_getrobust() y pthread_mutexattr_setrobust() debería referirse a un objeto de atributos de mutex que fue inicializado por pthread_mutexattr_init(3), de lo contrario, el comportamiento es indefinido.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. En caso de error, devuelven un número de error positivo.

En la implementación de glibc, pthread_mutexattr_getrobust() siempre devuelve cero.

ERRORES

EINVAL
Se pasó un valor distinto de PTHREAD_MUTEX_STALLED o PTHREAD_MUTEX_ROBUST a pthread_mutexattr_setrobust().

VERSIONES

En la implementación de Linux, al usar mutex robustos compartidos por procesos, un hilo en espera también recibe la notificación EOWNERDEAD si el propietario de un mutex robusto realiza una llamada a execve(2) sin desbloquear primero el mutex. POSIX.1 no especifica este detalle, pero el mismo comportamiento también ocurre al menos en otras implementaciones.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.12. POSIX.1-2008.

Antes de la adición de pthread_mutexattr_getrobust() y pthread_mutexattr_setrobust() a POSIX, glibc definía las siguientes funciones no estándar equivalentes si se definía _GNU_SOURCE:

[[deprecated]]
int pthread_mutexattr_getrobust_np(const pthread_mutexattr_t *attr,
                                   int *robustness);
[[deprecated]]
int pthread_mutexattr_setrobust_np(const pthread_mutexattr_t *attr,
                                   int robustness);

Correspondientemente, las constantes PTHREAD_MUTEX_STALLED_NP y PTHREAD_MUTEX_ROBUST_NP también se definían.

Estas APIs específicas de GNU, que aparecieron por primera vez en glibc 2.4, están hoy en día obsoletas y no deben usarse en programas nuevos; desde glibc 2.34 estas APIs están marcadas como obsoletas.

EJEMPLOS

El programa a continuación demuestra el uso del atributo de robustez de un objeto de atributos de mutex. En este programa, un hilo que posee el mutex muere prematuramente sin desbloquearlo. Posteriormente, el hilo principal adquiere el mutex con éxito y recibe el error EOWNERDEAD, después de lo cual hace que el mutex sea consistente.

La siguiente sesión de shell muestra lo que vemos al ejecutar este programa:


$ ./a.out;
[original owner] Setting lock...
[original owner] Locked.  Now exiting without unlocking.
[main] Attempting to lock the robust mutex.
[main] pthread_mutex_lock() returned EOWNERDEAD
[main] Now make the mutex consistent
[main] Mutex is now consistent; unlocking

Código fuente del programa

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static pthread_mutex_t mtx;
static void *
original_owner_thread(void *ptr)
{
    printf("[original owner] Setting lock...\n");
    pthread_mutex_lock(&mtx);
    printf("[original owner] Locked.  Now exiting without unlocking.\n");
    pthread_exit(NULL);
}
int
main(void)
{
    pthread_t thr;
    pthread_mutexattr_t attr;
    int s;
    pthread_mutexattr_init(&attr);
    pthread_mutexattr_setrobust(&attr, PTHREAD_MUTEX_ROBUST);
    pthread_mutex_init(&mtx, &attr);
    pthread_create(&thr, NULL, original_owner_thread, NULL);
    sleep(2);
    /* "original_owner_thread" debería haber terminado para entonces.  */
    printf("[main] Attempting to lock the robust mutex.\n");
    s = pthread_mutex_lock(&mtx);
    if (s == EOWNERDEAD) {
        printf("[main] pthread_mutex_lock() returned EOWNERDEAD\n");
        printf("[main] Now make the mutex consistent\n");
        s = pthread_mutex_consistent(&mtx);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_mutex_consistent");
        printf("[main] Mutex is now consistent; unlocking\n");
        s = pthread_mutex_unlock(&mtx);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_mutex_unlock");
        exit(EXIT_SUCCESS);
    } else if (s == 0) {
        printf("[main] pthread_mutex_lock() unexpectedly succeeded\n");
        exit(EXIT_FAILURE);
    } else {
        printf("[main] pthread_mutex_lock() unexpectedly failed\n");
        errc(EXIT_FAILURE, s, "pthread_mutex_lock");
    }
}
