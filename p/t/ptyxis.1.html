Ptyxis(1) Manual de Comandos Generales Ptyxis(1)

NOMBRE

ptyxis - una terminal orientada a contenedores

SINOPSIS

ptyxis [OPCIÓN]... [-- PROGRAMA ARGUMENTOS]

DESCRIPCIÓN

ptyxis es una terminal orientada a contenedores, diseñada para el escritorio GNOME. Proporciona una integración estrecha con podman, toolbox, distrobox y jhbuild para simplificar el desarrollo y la gestión del sistema basados en contenedores.

--version
Muestra la versión del programa.
--preferences
Muestra la ventana de preferencias.
--new-window
Abre una nueva ventana en una instancia existente de Ptyxis. Si Ptyxis no se está ejecutando, se inicia una nueva instancia.

Se puede combinar con las opciones --working-directory, --execute y --title.

--tab
Abre una nueva pestaña en la ventana más recientemente utilizada de una instancia existente de Ptyxis. Si Ptyxis no se está ejecutando, se inicia una nueva instancia.

Se puede combinar con las opciones --working-directory, --execute y --title.

-x, --execute
Ejecuta un comando personalizado.

Esto es similar a usar -- para proporcionar el comando personalizado, excepto que toda la línea de comandos debe proporcionarse como un único argumento.

En general, deberías usar -- en lugar de esta opción. Esto está disponible principalmente para ser similar a bash -c 'comando'

Se puede combinar con las opciones --working-directory y --title.

-d, --working-directory
Establece el directorio de trabajo actual para una nueva pestaña [--tab], ventana [--window] o comando personalizado [-- COMMAND...].
--title=TÍTULO
Establece el título para una nueva página de terminal creada con --tab o --new-window.
--maximize
Maximiza una ventana recién creada.
--fullscreen
Pon en pantalla completa una ventana recién creada.
--tab-with-profile=PERFIL
Crea una nueva pestaña en una instancia existente utilizando el perfil especificado. El perfil debe ser una cadena de UUID que se puede encontrar en el editor de perfiles del diálogo de preferencias.
-s, --standalone
Inicia una nueva instancia de Ptyxis, en modo de instancia única, ignorando cualquier instancia ya en ejecución.

El modo de instancia única se implica al ejecutar un comando --.

-s, --gapplication-app-id=ID
Anula el ID de la aplicación en modo de instancia única.
-h, --help
Muestra un resumen de las opciones.
Otras opciones estándar de GNOME no listadas aquí también son compatibles.
