Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_mutex_getprioceiling, pthread_mutex_setprioceiling — obtener y establecer el techo de prioridad de un mutex (HILOS EN TIEMPO REAL)

SINOPSIS

#include <pthread.h>
int pthread_mutex_getprioceiling(const pthread_mutex_t *restrict mutex,
    int *restrict prioceiling);
int pthread_mutex_setprioceiling(pthread_mutex_t *restrict mutex,
    int prioceiling, int *restrict old_ceiling);

DESCRIPCIÓN

La función pthread_mutex_getprioceiling() devolverá el techo de prioridad actual del mutex.

La función pthread_mutex_setprioceiling() intentará bloquear el mutex como si fuera una llamada a pthread_mutex_lock(), excepto que el proceso de bloqueo del mutex no tiene por qué seguir el protocolo de protección de prioridad. Al adquirir el mutex, cambiará el techo de prioridad del mutex y luego liberará el mutex como si fuera una llamada a pthread_mutex_unlock(). Cuando el cambio sea exitoso, el valor anterior del techo de prioridad se devolverá en old_ceiling.

Si la función pthread_mutex_setprioceiling() falla, el techo de prioridad del mutex no se cambiará.

VALOR DE RETORNO

Si se ejecutan correctamente, las funciones pthread_mutex_getprioceiling() y pthread_mutex_setprioceiling() devolverán cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Estas funciones fallarán si:

EINVAL
El atributo de protocolo de mutex es PTHREAD_PRIO_NONE.
EPERM
La implementación requiere privilegios apropiados para realizar la operación y el llamante no tiene los privilegios apropiados.

La función pthread_mutex_setprioceiling() fallará si:

EAGAIN
No se pudo adquirir el mutex porque se ha superado el número máximo de bloqueos recursivos para mutex.
EDEADLK
El tipo de mutex es PTHREAD_MUTEX_ERRORCHECK y el hilo actual ya posee el mutex.
EINVAL
El mutex se creó con el atributo de protocolo que tiene el valor PTHREAD_PRIO_PROTECT y la prioridad del hilo llamante es superior al techo de prioridad actual del mutex, y la implementación se adhiere al protocolo de protección de prioridad en el proceso de bloqueo del mutex.
ENOTRECOVERABLE

El mutex es un mutex robusto y el estado protegido por el mutex no es recuperable.
EOWNERDEAD

El mutex es un mutex robusto y el proceso que contiene el hilo propietario anterior terminó mientras mantenía el bloqueo del mutex. El bloqueo del mutex será adquirido por el hilo llamante y depende del nuevo propietario hacer que el estado sea consistente (ver pthread_mutex_lock()).

La función pthread_mutex_setprioceiling() puede fallar si:

EDEADLK
Se detectó una condición de interbloqueo.
EINVAL
La prioridad solicitada por prioceiling está fuera de rango.
EOWNERDEAD

El mutex es un mutex robusto y el hilo propietario anterior terminó mientras mantenía el bloqueo del mutex. El bloqueo del mutex será adquirido por el hilo llamante y depende del nuevo propietario hacer que el estado sea consistente (ver pthread_mutex_lock()).

Estas funciones no devolverán un código de error de [EINTR].

pthread_mutex_getprioceiling

pthread_mutex_getprioceiling - obtener el techo de prioridad de un mutex

Nombre

pthread_mutex_getprioceiling - obtener el techo de prioridad de un mutex

Sintaxis

#include <pthread.h>

int pthread_mutex_getprioceiling(pthread_mutex_t *restrict mutex,
                                int *restrict prioceiling);

Descripción

La función pthread_mutex_getprioceiling devolverá el valor del techo de prioridad del mutex especificado por mutex en la variable apuntada por prioceiling.

El techo de prioridad de un mutex se establece durante la inicialización del mutex (con pthread_mutex_init) o al crear el mutex (con pthread_mutexattr_setprioceiling y pthread_mutex_setprioceiling).

Valor devuelto

En caso de éxito, pthread_mutex_getprioceiling devuelve 0.

En caso de error, devuelve un número de error distinto de cero.

Errores

EINVAL
El valor especificado para mutex o prioceiling no es válido.

Ejemplos

No hay ejemplos disponibles para esta función.
