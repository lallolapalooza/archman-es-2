NOMBRE

pt-replica-find - Encuentra e imprime el árbol de jerarquía de réplicas de MySQL.

SINOPSIS

Uso: pt-replica-find [OPCIONES] [DSN]

pt-replica-find encuentra e imprime un árbol jerárquico de réplicas de MySQL.

Ejemplos:

pt-replica-find --host host-fuente

RIESGOS

Percona Toolkit es maduro, probado en el mundo real y bien verificado, pero todas las herramientas de bases de datos pueden suponer un riesgo para el sistema y el servidor de bases de datos. Antes de usar esta herramienta, por favor:

  • Lea la documentación de la herramienta
  • Revise los "BUGS" conocidos de la herramienta
  • Pruebe la herramienta en un servidor no productivo
  • Haga una copia de seguridad de su servidor de producción y verifique las copias de seguridad

DESCRIPCIÓN

pt-replica-find se conecta a una fuente de replicación de MySQL y encuentra sus réplicas. Actualmente, lo único que puede hacer es imprimir una vista en forma de árbol de la jerarquía de replicación.

El host fuente se puede especificar utilizando uno de los dos métodos. El primer método es usar las opciones de línea de comandos relacionadas con la conexión estándar: "--defaults-file", "--password", "--host", "--port", "--socket" o "--user".

El segundo método para especificar el host fuente es un DSN. Un DSN es una sintaxis especial que puede ser simplemente un nombre de host (como "servidor.dominio.com" o 1.2.3.4), o una cadena "clave=valor,clave=valor". Las claves son de una sola letra:

CLAVE SIGNIFICADO
=== ==========
h   Conectar al host
P   Número de puerto a usar para la conexión
S   Archivo de socket a usar para la conexión
u   Usuario para iniciar sesión si no es el usuario actual
p   Contraseña a usar al conectar
F   Leer solo las opciones predeterminadas del archivo dado

"pt-replica-find" lee todos los archivos de opciones normales de MySQL, como ~/.my.cnf, por lo que es posible que no necesite especificar el nombre de usuario, la contraseña y otras opciones comunes.

ESTADO DE SALIDA

Un estado de salida de 0 (a veces también llamado valor de retorno o código de retorno) indica éxito. Cualquier otro valor representa el estado de salida del propio proceso de Perl.

OPCIONES

Esta herramienta acepta argumentos adicionales de línea de comandos. Consulte la "SINOPSIS" y la información de uso para obtener detalles.

--ask-pass
Solicitar una contraseña al conectarse a MySQL.
--charset
forma corta: -A; tipo: cadena

Juego de caracteres predeterminado. Si el valor es utf8, establece el modo binario de Perl en STDOUT a utf8, pasa la opción mysql_enable_utf8 a DBD::mysql y ejecuta SET NAMES UTF8 después de conectarse a MySQL. Cualquier otro valor establece el modo binario en STDOUT sin la capa utf8 y ejecuta SET NAMES después de conectarse a MySQL.

--config
tipo: Array

Leer esta lista separada por comas de archivos de configuración; si se especifica, esta debe ser la primera opción en la línea de comandos.

--database
tipo: cadena; forma corta: -D

Base de datos a usar.

--defaults-file
forma corta: -F; tipo: cadena

Leer solo las opciones de mysql del archivo dado. Debe proporcionar una ruta de archivo absoluta.

--help
Mostrar ayuda y salir.
--host
forma corta: -h; tipo: cadena

Conectar al host.

--password
forma corta: -p; tipo: cadena

Contraseña a usar al conectar. Si la contraseña contiene comas, deben escaparse con una barra invertida: "ejem\,plo"

--pid
tipo: cadena

Crear el archivo PID dado. La herramienta no se iniciará si el archivo PID ya existe y el PID que contiene es diferente al PID actual. Sin embargo, si el archivo PID existe y el PID que contiene ya no se está ejecutando, la herramienta sobrescribirá el archivo PID con el PID actual. El archivo PID se elimina automáticamente cuando la herramienta sale.

--port
forma corta: -P; tipo: int

Número de puerto a usar para la conexión.

--recurse
tipo: int

Número de niveles a recursar en la jerarquía. El valor predeterminado es infinito.

Ver "--recursion-method".

--recursion-method
tipo: array; predeterminado: processlist,hosts

Método de recursión preferido utilizado para encontrar réplicas.

Los métodos posibles son:

METODO       USA
===========  ==================
processlist  SHOW PROCESSLIST
hosts        SHOW REPLICAS (SHOW SLAVE HOSTS antes de MySQL 8.1)
none         No encontrar réplicas

El método de la lista de procesos es el preferido porque SHOW REPLICAS no es confiable. Sin embargo, el método de hosts es necesario si el servidor utiliza un puerto no estándar (no 3306). Por lo general, pt-replica-find hace lo correcto y encuentra las réplicas, pero puede proporcionar un método preferido y se usará primero. Si no encuentra ninguna réplica, se intentarán los otros métodos.

--report-format
tipo: cadena; predeterminado: summary

Establece qué información sobre las réplicas se imprime. El formato del informe puede ser uno de los siguientes:

  • hostname

    Imprime solo el nombre de host de las réplicas. Se ve así:

    127.0.0.1:12345
+- 127.0.0.1:12346
   +- 127.0.0.1:12347
  • summary

    Imprime un resumen de la configuración de cada réplica. Este informe muestra más información sobre cada réplica, como:

    127.0.0.1:12345
Version         5.1.34-log
Server ID       12345
Uptime          04:56 (iniciado 2010-06-17T11:21:22)
Replication     No es una réplica, tiene 1 réplicas conectadas
Filters
Binary logging  STATEMENT
Slave status
Slave mode      STRICT
Auto-increment  increment 1, offset 1
+- 127.0.0.1:12346
   Version         5.1.34-log
   Server ID       12346
   Uptime          04:54 (iniciado 2010-06-17T11:21:24)
   Replication     Es una réplica, tiene 1 réplicas conectadas
   Filters
   Binary logging  STATEMENT
   Slave status    0 segundos de retraso, en ejecución, sin errores
   Slave mode      STRICT
   Auto-increment  increment 1, offset 1
--resolve-address
Resuelve la dirección IP a nombre de host. El informe imprimirá tanto la IP como el nombre de host.

Ejemplo:

10.10.7.14 (dbase1.sample.net)

Puede retrasar la ejecución unos segundos.

--slave-user
tipo: cadena

Esta opción está obsoleta y se eliminará en futuras versiones. Use "--replica-user" en su lugar.

--slave-password
tipo: cadena

Esta opción está obsoleta y se eliminará en futuras versiones. Use "--replica-password" en su lugar.

--replica-user
tipo: cadena

Establece el usuario que se utilizará para conectarse a las réplicas. Este parámetro le permite tener un usuario diferente con menos privilegios en las réplicas, pero ese usuario debe existir en todas las réplicas.

--replica-password
tipo: cadena

Establece la contraseña que se utilizará para conectarse a las réplicas. Se puede usar con --replica-user y la contraseña del usuario debe ser la misma en todas las réplicas.

--set-vars
tipo: Array

Establece las variables de MySQL en esta lista separada por comas de pares "variable=valor".

Por defecto, la herramienta establece:

wait_timeout=10000

pt-replica-find(1p) — Arch Linux manual pages

NAME

pt-replica-find

Finds MySQL replicas

SYNOPSIS

pt-replica-find [OPTIONS] [DSN --dsn] [DSN --dsn]

RISKS

This tool does not change any data, so the risks are minimal. However, it does connect to servers and query them. Depending on the MySQL version, version, or configuration, this could have an effect on server performance. See the Percona Toolkit manpage for a more complete explanation of the risks.

DESCRIPTION

This tool finds MySQL replicas and prints their DSNs. A replica is defined as a server that has a SHOW SLAVE STATUS output that indicates it is replicating. It can connect to any MySQL server, find all of its replicas, and then find all of the replicas of those replicas, etc. The default behavior is to find all replicas on the same MySQL servers that are running the script.

The tool can connect to any MySQL server, find all its replicas, and then find all the replicas of those replicas, and so on. By default, it finds replicas on the same MySQL servers on which the script is running.

This tool is useful for finding replicas in large, complex MySQL environments, or for verifying that replication is set up correctly.

EXIT STATUS

The exit status of pt-replica-find is 0 if it succeeds, and non-zero otherwise. See the Percona Toolkit manpage for a more complete explanation of exit statuses.

OPTIONS

--[no]allow-slaves-to-be-master
type: boolean; default: yes

When searching for replicas, if this option is enabled, pt-replica-find will assume that a replica might also be a master and will search for its replicas. If disabled, it will only search for replicas of masters.

-p
type: boolean; default: no

Prompt for a MySQL password.

-A
type: string

Default character set.

-C
type: string

Read this configuration file. Any options specified on the command line override values in the configuration file.

-d
type: boolean; default: no

Run in the background.

-D
type: string

Connect to this database.

-F
type: string

Only read default options from the given file.

-h
Show help and exit.
-h
short form: -h; type: string

Connect to host.

-i
type: integer; default: 1

Number of times to repeat the scan. A value of 0 repeats indefinitely.

-p
short form: -p; type: string

Password for login.

-P
short form: -P; type: integer

Port number to use for connection.

--print-only-matched-databases
type: boolean; default: no

Only print databases that match the given patterns.

--print-summary
type: boolean; default: yes

Print a summary of the scan results.

-o
type: string

Set variables in name=value pairs. For example, "--set-vars wait_timeout=500" overrides the default value of 10000.

The tool prints a warning and continues if a variable cannot be set.

--socket
short form: -S; type: string

Socket file to use for connection.

--user
short form: -u; type: string

User for login if not current user.

--version
Show version and exit.

DSN OPTIONS

These DSN options are used to create a DSN. Each option is given like "option=value". The options are case-sensitive, so P and p are not the same option. There cannot be whitespace before or after the "=" and if the value contains whitespace it must be quoted. DSN options are comma-separated. See the percona-toolkit manpage for full details.

  • A

    dsn: charset; copy: yes

    Default character set.

  • D

    dsn: database; copy: yes

    Default database.

  • F

    dsn: mysql_read_default_file; copy: yes

    Only read default options from the given file

  • h

    dsn: host; copy: yes

    Connect to host.

  • p

    dsn: password; copy: yes

    Password to use when connecting. If password contains commas they must be escaped with a backslash: "exam\,ple"

  • P

    dsn: port; copy: yes

    Port number to use for connection.

  • S

    dsn: mysql_socket; copy: yes

    Socket file to use for connection.

  • u

    dsn: user; copy: yes

    User for login if not current user.

  • s

    dsn: mysql_ssl; copy: yes

    Create SSL connection

ENVIRONMENT

The environment variable "PTDEBUG" enables verbose debugging output to STDERR. To enable debugging and capture all output to a file, run the tool like:

PTDEBUG=1 pt-replica-find ... > FILE 2>&1

Be careful: debugging output is voluminous and can generate several megabytes of output.

ATTENTION

Using <PTDEBUG> might expose passwords. When debug is enabled, all command line parameters are shown in the output.

SYSTEM REQUIREMENTS

You need Perl, DBI, DBD::mysql, and some core packages that ought to be installed in any reasonably new version of Perl.
