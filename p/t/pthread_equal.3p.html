PTHREAD_EQUAL(3P) Manual del programador POSIX PTHREAD_EQUAL(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual correspondiente de Linux para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_equal — compara IDs de hilo

SINOPSIS

#include <pthread.h>
int pthread_equal(pthread_t t1, pthread_t t2);

DESCRIPCIÓN

Esta función compara los IDs de hilo t1 y t2.

VALOR DE RETORNO

La función pthread_equal() devolverá un valor distinto de cero si t1 y t2 son iguales; de lo contrario, se devolverá cero.

Si t1 o t2 no son IDs de hilo válidos, el comportamiento es indefinido.

ERRORES

No se definen errores.

La función pthread_equal() no devolverá un código de error de [EINTR].

RACIONALE

Las implementaciones pueden optar por definir un ID de hilo como una estructura. Esto permite una mayor flexibilidad y robustez en comparación con el uso de un int. Por ejemplo, un ID de hilo podría incluir un número de secuencia que permita la detección de ``IDs colgantes'' (copias de un ID de hilo que se ha desacoplado). Dado que el lenguaje C no admite la comparación de tipos de estructura, se proporciona la función pthread_equal() para comparar IDs de hilo.
