NOMBRE

pto_lensstack - modifica lentes y pilas asignadas en archivos pto

SINOPSIS

pto_lensstack [opciones] entrada.pto

DESCRIPCIÓN

pto_lensstack puede manipular lentes y pilas en archivos de proyecto Hugin .pto. Esto está destinado para su uso en scripting.

USO

pto_lensstack --output=salida.pto --new-lens|--new-stack|--change-lens|--change-stack imágenes entrada.pto

OPCIONES

--new-lens
--new-stack
Para asignar una nueva lente o pila a una imagen, proporcione una lista de números de imagen. El conteo comienza en cero. Se pueden dar varias imágenes al mismo tiempo. Sepárelas con una coma.

Ejemplos:
pto_lensstack --new-lens i1,i3 entrada.pto
pto_lensstack --new-stack i2,i4 entrada.pto

asignará una nueva lente a las imágenes 1 y 3 y una nueva pila a las imágenes 2 y 4.

--change-lens
--change-stack
Para cambiar la lente o la pila, proporcione una lista de números de imagen y el número de la nueva lente/pila. Para ambos, el conteo comienza en cero y puede proporcionar varias imágenes separadas por una coma al mismo tiempo.

Ejemplos:
pto_lensstack --change-lens i1=4,i5=1 entrada.pto
pto_lensstack --change-stack i2=0,i4=0 entrada.pto

-o|--output
Genera un archivo pto con el nombre de archivo dado. Si no se proporciona, se agregará "_lens" al nombre del archivo de entrada.
-h|--help
Muestra la ayuda
