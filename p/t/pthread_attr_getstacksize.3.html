pthread_attr_setstacksize(3) Manual de funciones de biblioteca pthread_attr_setstacksize(3)

NOMBRE

pthread_attr_setstacksize, pthread_attr_getstacksize - establecer/obtener el atributo de tamaño de pila en el objeto de atributos de hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_attr_setstacksize(pthread_attr_t *attr, size_t stacksize);
int pthread_attr_getstacksize(const pthread_attr_t *restrict attr,
                              size_t *restrict stacksize);

DESCRIPCIÓN

La función pthread_attr_setstacksize() establece el atributo de tamaño de pila del objeto de atributos de hilo al que se refiere attr al valor especificado en stacksize.

El atributo de tamaño de pila determina el tamaño mínimo (en bytes) que se asignará para los hilos creados utilizando el objeto de atributos de hilo attr.

La función pthread_attr_getstacksize() devuelve el atributo de tamaño de pila del objeto de atributos de hilo al que se refiere attr en el búfer apuntado por stacksize.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

pthread_attr_setstacksize() puede fallar con el siguiente error:

EINVAL
El tamaño de la pila es inferior a PTHREAD_STACK_MIN (16384) bytes.

En algunos sistemas, pthread_attr_setstacksize() puede fallar con el error EINVAL si stacksize no es un múltiplo del tamaño de página del sistema.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_attr_setstacksize (), pthread_attr_getstacksize () Seguridad de hilos MT-Safe

VERSIONES

Estas funciones se proporcionan desde glibc 2.1.

ESTÁNDARES

POSIX.1-2001, POSIX.1-2008.

NOTAS

Para obtener detalles sobre el tamaño de pila predeterminado de los nuevos hilos, consulte pthread_create(3).

El tamaño de la pila de un hilo se fija en el momento de la creación del hilo. Solo el hilo principal puede aumentar dinámicamente su pila.

La función pthread_attr_setstack(3) permite a una aplicación establecer tanto el tamaño como la ubicación de una pila asignada por el llamante que se utilizará para un hilo.

ERRORES DE PROGRAMACIÓN

A partir de glibc 2.8, si el stacksize especificado no es un múltiplo de STACK_ALIGN (16 bytes en la mayoría de las arquitecturas), puede redondearse hacia abajo, en violación de POSIX.1, que dice que la pila asignada tendrá al menos stacksize bytes.

EJEMPLOS

Consulte pthread_create(3).

VER TAMBIÉN

getrlimit(2), pthread_attr_init(3), pthread_attr_setguardsize(3), pthread_attr_setstack(3), pthread_create(3), pthreads(7)
