pthread_detach(3) Manual de funciones de biblioteca pthread_detach(3)

NOMBRE

pthread_detach - separar un hilo

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_detach(pthread_t thread);

DESCRIPCIÓN

La función pthread_detach() marca el hilo identificado por thread como separado. Cuando un hilo separado termina, sus recursos se liberan automáticamente de nuevo al sistema sin necesidad de que otro hilo se una al hilo terminado.

Intentar separar un hilo ya separado resulta en un comportamiento no especificado.

VALOR DE RETORNO

En caso de éxito, pthread_detach() devuelve 0; en caso de error, devuelve un número de error.

ERRORES

EINVAL
thread no es un hilo unible.
ESRCH
No se encontró ningún hilo con el ID thread.

ATRIBUTOS

Para una explicación de los términos usados en esta sección, véase attributes(7).

Interfaz Atributo Valor
pthread_detach () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Una vez que un hilo ha sido separado, no se puede unir con pthread_join(3) ni volver a ser un hilo unible.

Un nuevo hilo puede crearse en estado separado utilizando pthread_attr_setdetachstate(3) para establecer el atributo de separación del argumento attr de pthread_create(3).

El atributo de separación solo determina el comportamiento del sistema cuando el hilo termina; no evita que el hilo sea terminado si el proceso termina usando exit(3) (o de forma equivalente, si el hilo principal retorna).

Se debe llamar a pthread_join(3) o pthread_detach() para cada hilo que una aplicación cree, para que los recursos del sistema para ese hilo puedan ser liberados. (Pero ten en cuenta que los recursos de cualquier hilo para el que no se haya realizado una de estas acciones se liberarán cuando el proceso termine).

EJEMPLOS

La siguiente instrucción separa el hilo que la llama:


pthread_detach(pthread_self());

VER TAMBIÉN

pthread_attr_setdetachstate(3), pthread_cancel(3), pthread_create(3), pthread_exit(3), pthread_join(3), pthreads(7)
