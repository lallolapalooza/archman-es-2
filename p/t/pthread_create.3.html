pthread_create(3) Manual de Funciones de Biblioteca pthread_create(3)

NOMBRE

pthread_create - crear un nuevo hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_create(pthread_t *restrict thread,
                   const pthread_attr_t *restrict attr,
                   typeof(void *(void *)) *start_routine,
                   void *restrict arg);

DESCRIPCIÓN

La función pthread_create() inicia un nuevo hilo en el proceso llamante. El nuevo hilo comienza su ejecución invocando start_routine(); arg se pasa como el único argumento de start_routine().

El nuevo hilo termina de una de las siguientes maneras:

•
Llama a pthread_exit(3), especificando un valor de estado de salida que está disponible para otro hilo en el mismo proceso que llama a pthread_join(3).
•
Retorna de start_routine(). Esto es equivalente a llamar a pthread_exit(3) con el valor suministrado en la instrucción de retorno.
•
Es cancelado (ver pthread_cancel(3)).
•
Cualquiera de los hilos en el proceso llama a exit(3), o el hilo principal realiza un retorno desde main(). Esto provoca la terminación de todos los hilos en el proceso.

El argumento attr apunta a una estructura pthread_attr_t cuyos contenidos se utilizan en el momento de la creación del hilo para determinar los atributos del nuevo hilo; esta estructura se inicializa utilizando pthread_attr_init(3) y funciones relacionadas. Si attr es NULL, entonces el hilo se crea con atributos predeterminados.

Antes de retornar, una llamada exitosa a pthread_create() almacena el ID del nuevo hilo en el búfer apuntado por thread; este identificador se utiliza para referirse al hilo en llamadas posteriores a otras funciones pthreads.

El nuevo hilo hereda una copia de la máscara de señales del hilo llamante (pthread_sigmask(3)). El conjunto de señales pendientes para el nuevo hilo está vacío (sigpending(2)). El nuevo hilo no hereda la pila de señales alternativa del hilo llamante (sigaltstack(2)).

El nuevo hilo hereda el entorno de punto flotante del hilo llamante (fenv(3)).

El valor inicial del reloj de tiempo de CPU del nuevo hilo es 0 (ver pthread_getcpuclockid(3)).

Detalles específicos de Linux

El nuevo hilo hereda copias de los conjuntos de capacidades del hilo llamante (ver capabilities(7)) y la máscara de afinidad de CPU (ver sched_setaffinity(2)).

VALOR DE RETORNO

En caso de éxito, pthread_create() retorna 0; en caso de error, retorna un número de error y el contenido de *thread es indefinido.

ERRORES

EAGAIN
Recursos insuficientes para crear otro hilo.
EAGAIN
Se encontró un límite impuesto por el sistema en el número de hilos. Hay una serie de límites que pueden desencadenar este error: se alcanzó el límite de recursos blandos RLIMIT_NPROC (establecido con setrlimit(2)), que limita el número de procesos e hilos para un ID de usuario real; se alcanzó el límite del sistema a nivel de kernel para el número de procesos e hilos, /proc/sys/kernel/threads-max (ver proc(5)); o se alcanzó el número máximo de PIDs, /proc/sys/kernel/pid_max (ver proc(5)).
EINVAL
Configuraciones inválidas en attr.
EPERM
No hay permiso para establecer la política y los parámetros de programación especificados en attr.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_create () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Ver pthread_self(3) para más información sobre el ID de hilo devuelto en *thread por pthread_create(). A menos que se estén empleando políticas de programación en tiempo real, después de una llamada a pthread_create(), es indeterminado qué hilo —el llamante o el nuevo hilo— se ejecutará a continuación.

Un hilo puede ser unible o separado. Si un hilo es unible, entonces otro hilo puede llamar a pthread_join(3) para esperar a que el hilo termine y obtener su estado de salida. Solo cuando un hilo terminadoy unible ha sido unido, los últimos de sus recursos se liberan al sistema. Cuando un hilo separado termina, sus recursos se liberan automáticamente al sistema: no es posible unir al hilo para obtener su estado de salida. Hacer que un hilo sea separado es útil para algunos tipos de hilos demonio cuyo estado de salida la aplicación no necesita observar. Por defecto, un nuevo hilo se crea en estado unible, a menos que attr se establezca para crear el hilo en un estado separado (usando pthread_attr_setdetachstate(3)).

Bajo la implementación de hilos NPTL, si el límite de recursos blando RLIMIT_STACK en el momento en que comenzó el programa tiene un valor distinto de "ilimitado", entonces determina el tamaño predeterminado de la pila de los nuevos hilos. Usando pthread_attr_setstacksize(3), el atributo del tamaño de la pila puede establecerse explícitamente en el argumento attr utilizado para crear un hilo, con el fin de obtener un tamaño de pila distinto del predeterminado. Si el límite de recursos RLIMIT_STACK se establece en "ilimitado", se utiliza un valor por arquitectura para el tamaño de la pila: 2 MB en la mayoría de las arquitecturas; 4 MB en POWER y Sparc-64.

ERRORES CONOCIDOS

En la implementación obsoleta de LinuxThreads, cada uno de los hilos en un proceso tiene un ID de proceso diferente. Esto viola la especificación de hilos POSIX y es la causa de muchas otras no conformidades con el estándar; ver pthreads(7).

EJEMPLOS

El siguiente programa demuestra el uso de pthread_create(), así como una serie de otras funciones de la API de pthreads.

En la siguiente ejecución, en un sistema que proporciona la implementación de hilos NPTL, el tamaño de la pila toma por defecto el valor dado por el límite de recursos de "tamaño de pila":


$ ulimit -s
8192            # El límite del tamaño de la pila es de 8 MB (0x800000 bytes)
$ ./a.out hola salut servus
Hilo 1: parte superior de la pila cerca de 0xb7dd03b8; argv_string=hola
Hilo 2: parte superior de la pila cerca de 0xb75cf3b8; argv_string=salut
Hilo 3: parte superior de la pila cerca de 0xb6dce3b8; argv_string=servus
Unido con el hilo 1; el valor de retorno fue HOLA
Unido con el hilo 2; el valor de retorno fue SALUT
Unido con el hilo 3; el valor de retorno...

NAME

pthread_create - create a new thread

LIBRARY

Realtime Threads Library (libpthread, -lpthread)

SYNOPSIS

#include <pthread.h>
int pthread_create(pthread_t *restrict thread,
                   const pthread_attr_t *restrict attr,
                   void *(*start_routine) (void *),
                   void *restrict arg);

DESCRIPTION

The pthread_create() function starts a new thread in the calling process. The new thread begins execution at the specified start address, start_routine, and continues execution until start_routine returns. The return value from start_routine is provided to any thread that successfully joins with the new thread (see pthread_join(3)). The terminating function of a thread is its last invoked function. If that function invokes pthread_exit(3), then the thread terminates, and its return value is the value passed to pthread_exit(3). Otherwise, when the last invoked function returns, the thread terminates, and its return value is the return value of that last function.

The thread is created with attributes specified by attr. If attr is NULL, default thread attributes are used. The default stack size is architecture-dependent and implementation-dependent. See pthread_attr_init(3) and pthread_attr_setstacksize(3) for more information on thread attributes.

The arg argument is the argument that is passed to the new thread beginning at start_routine.

The thread ID of the new thread is stored in the location pointed to by thread, unless thread is NULL. The thread ID is a unique, nonnegative integer value of type pthread_t. It is unique within the lifetime of the process. If a thread is terminated, its thread ID may be reused.

The new thread inherits copies of the calling thread's signal mask, priority, and scheduling policy. Threads created by pthread_create() are joinable by default. See pthread_attr_setdetachstate(3).

RETURN VALUE

On success, pthread_create() returns 0 and places the ID of the new thread into the location referenced by thread. On failure, it returns an error number, and the contents of the location referenced by thread are undefined.

ERRORS

The pthread_create() function will fail if:

EAGAIN
Insufficient system resources would be allocated to create the requested thread. The system limit on the total number of processes and threads may have been reached.
EINVAL
The value specified by attr is invalid.
ENOMEM
Insufficient memory is available to create the thread.

ATTRIBUTES

Multithreading Effects

The pthread_create() function is thread-safe.

CONFORMING TO

POSIX.1-2001, POSIX.1-2008.

SEE ALSO

getrlimit(2), pthread_attr_init(3), pthread_cancel(3), pthread_detach(3), pthread_equal(3), pthread_exit(3), pthread_getattr_np(3), pthread_join(3), pthread_self(3), pthread_setattr_default_np(3), pthreads(7)

HISTORY

The pthread_create(3) function first appeared in FreeBSD 3.0.

STANDARDS

POSIX.1-2001, POSIX.1-2008.

NOTES

The default stack size is at least PTHREAD_STACK_MIN bytes, and it is recommended that you do not set the stack size to less than this value.

The start_routine function is executed in the new thread. The argument arg is passed to this function. The return value of start_routine is used as the return value of the new thread.

The stack is allocated by the system and the address of the top of the stack can be found by taking the address of any variable declared within the start_routine.

If attr is NULL, the default thread attributes are used. These defaults are implementation-dependent.

If the thread is created successfully, the thread ID is returned in thread. If an error occurs, thread is left unchanged.

When a thread is created, it inherits copies of the calling thread's signal mask, scheduling policy, and priority.

It is important to note that when using pthread_create(), the calling thread is not blocked. The new thread starts executing concurrently with the calling thread.

BUGS

None significant.

EXAMPLES

The following example demonstrates the use of pthread_create() and pthread_join(). It creates three threads, each of which prints its stack top and then returns an uppercase version of its command-line argument.

A run without explicit stack size setting:

$ ./a.out hola salut servus
Thread 1: top of stack near 0xb7d723b8; argv_string=hola
Thread 2: top of stack near 0xb7c713b8; argv_string=salut
Thread 3: top of stack near 0xb7b703b8; argv_string=servus
Joined with thread 1; returned value was HOLA
Joined with thread 2; returned value was SALUT
Joined with thread 3; returned value was SERVUS

In the next run, the program explicitly sets a stack size of 1 MB (using pthread_attr_setstacksize(3)) for the created threads:


$ ./a.out -s 0x100000 hola salut servus
Thread 1: top of stack near 0xb7d723b8; argv_string=hola
Thread 2: top of stack near 0xb7c713b8; argv_string=salut
Thread 3: top of stack near 0xb7b703b8; argv_string=servus
Joined with thread 1; returned value was HOLA
Joined with thread 2; returned value was SALUT
Joined with thread 3; returned value was SERVUS

Program source

#include <ctype.h>
#include <err.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <unistd.h>
struct thread_info {    /* Used as argument to thread_start() */
    pthread_t thread_id;        /* ID returned by pthread_create() */
    int       thread_num;       /* Application-defined thread # */
    char     *argv_string;      /* From command-line argument */
};
/* Thread start function: display address near top of our stack,
   and return upper-cased copy of argv_string.  */
static void *
thread_start(void *arg)
{
    struct thread_info *tinfo = arg;
    char *uargv;
    printf("Thread %d: top of stack near %p; argv_string=%s\n",
           tinfo->thread_num, (void *) &tinfo, tinfo->argv_string);
    uargv = strdup(tinfo->argv_string);
    if (uargv == NULL)
        err(EXIT_FAILURE, "strdup");
    for (char *p = uargv; *p != '\0'; p++)
        *p = toupper(*p);
    return uargv;
}
int
main(int argc, char *argv[])
{
    int                 s, opt;
    void                *res;
    size_t              num_threads;
    ssize_t             stack_size;
    pthread_attr_t      attr;
    struct thread_info  *tinfo;
    /* The "-s" option specifies a stack size for our threads.  */
    stack_size = -1;
    while ((opt = getopt(argc, argv, "s:")) != -1) {
        switch (opt) {
        case 's':
            stack_size = strtoul(optarg, NULL, 0);
            break;
        default:
            fprintf(stderr, "Usage: %s [-s stack-size] arg...\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    num_threads = argc - optind;
    /* Initialize thread creation attributes.  */
    s = pthread_attr_init(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_init");
    if (stack_size > 0) {
        s = pthread_attr_setstacksize(&attr, stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setstacksize");
    }
    /* Allocate memory for pthread_create() arguments.  */
    tinfo = calloc(num_threads, sizeof(*tinfo));
    if (tinfo == NULL)
        err(EXIT_FAILURE, "calloc");
    /* Create one thread for each command-line argument.  */
    for (size_t tnum = 0; tnum < num_threads; tnum++) {
        tinfo[tnum].thread_num = tnum + 1;
        tinfo[tnum].argv_string = argv[optind + tnum];
        /* The pthread_create() call stores the thread ID into
           corresponding element of tinfo[].  */
        s = pthread_create(&tinfo[tnum].thread_id, &attr,
                           &thread_start, &tinfo[tnum]);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_create");
    }
    /* Destroy the thread attributes object, since it is no
       longer needed.  */
    s = pthread_attr_destroy(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_destroy");
    /* Now join with each thread, and display its returned value.  */
    for (size_t tnum = 0; tnum < num_threads; tnum++) {
        s = pthread_join(tinfo[tnum].thread_id, &res);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_join");
        printf("Joined with thread %d; returned value was %s\n",
               tinfo[tnum].thread_num, (char *) res);
        free(res);      /* Free memory allocated by thread */
    }
    free(tinfo);
    exit(EXIT_SUCCESS);
}
