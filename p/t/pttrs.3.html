CPTTRS

Propósito:

!>
!> CPTTRS resuelve un sistema tridiagonal de la forma
!>    A * X = B
!> utilizando la factorización A = U**H*D*U o A = L*D*L**H calculada por CPTTRF.
!> D es una matriz diagonal especificada en el vector D, U (o L) es una matriz unitaria
!> bidiagonal cuya superdiagonal (subdiagonal) está especificada en
!> el vector E, y X y B son matrices de N por NRHS.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          Especifica la forma de la factorización y si el
!>          vector E es la superdiagonal del factor bidiagonal superior
!>          U o la subdiagonal del factor bidiagonal inferior L.
!>          = 'U':  A = U**H*D*U, E es la superdiagonal de U
!>          = 'L':  A = L*D*L**H, E es la subdiagonal de L
!>

N

!>          N es ENTERO
!>          El orden de la matriz tridiagonal A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

D

!>          D es un array REAL, dimensión (N)
!>          Los n elementos diagonales de la matriz diagonal D de la
!>          factorización A = U**H*D*U o A = L*D*L**H.
!>

E

!>          E es un array COMPLEJO, dimensión (N-1)
!>          Si UPLO = 'U', los (n-1) elementos superdiagonales del factor bidiagonal unitario
!>          U de la factorización A = U**H*D*U.
!>          Si UPLO = 'L', los (n-1) elementos subdiagonales del factor bidiagonal unitario
!>          L de la factorización A = L*D*L**H.
!>

B

!>          B es un array COMPLEJO, dimensión (LDB,NRHS)
!>          En la entrada, los vectores del lado derecho B para el sistema de
!>          ecuaciones lineales.
!>          En la salida, los vectores solución, X.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>

NAME

pttrs - solves a tridiagonal system of linear equations.

SYNOPSIS

    character uplo
    integer n
    integer nrhs

    complex*16 e(*)
    complex*16 b(ldb, *)
    integer ldb
    integer info
end

Detailed Description

This subroutine solves a tridiagonal system of the form:

    A * X = B

using the factorization of A computed by SPTTRF or ZPTTRF.

A is an N by N tridiagonal matrix and X and B are N by NRHS matrices.

Function Documentation

subroutine spttrs (character uplo, integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldb, * ) b, integer ldb, integer info)

SPTTTR

Purpose:

!>
!> SPTTRS solves a tridiagonal system of the form
!>    A * X = B
!> using the factorization A = U**T*D*U or A = L*D*L**T computed by SPTTRF.
!> D is a diagonal matrix specified in the vector D, U (or L) is a unit
!> bidiagonal matrix whose superdiagonal (subdiagonal) is specified in
!> the vector E, and X and B are N by NRHS matrices.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies the form of the factorization and whether the
!>          vector E is the superdiagonal of the upper bidiagonal factor
!>          U or the subdiagonal of the lower bidiagonal factor L.
!>          = 'U':  A = U**T *D*U, E is the superdiagonal of U
!>          = 'L':  A = L*D*L**T, E is the subdiagonal of L
!>

N

!>          N is INTEGER
!>          The order of the tridiagonal matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>          The n diagonal elements of the diagonal matrix D from the
!>          factorization A = U**T *D*U or A = L*D*L**T.
!>

E

!>          E is REAL array, dimension (N-1)
!>          If UPLO = 'U', the (n-1) superdiagonal elements of the unit
!>          bidiagonal factor U from the factorization A = U**T*D*U.
!>          If UPLO = 'L', the (n-1) subdiagonal elements of the unit
!>          bidiagonal factor L from the factorization A = L*D*L**T.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side vectors B for the system of
!>          linear equations.
!>          On exit, the solution vectors, X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>
