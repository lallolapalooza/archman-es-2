pthread_attr_setaffinity_np(3) Manual de funciones de la biblioteca pthread_attr_setaffinity_np(3)

NOMBRE

pthread_attr_setaffinity_np, pthread_attr_getaffinity_np - establecer/obtener el atributo de afinidad de CPU en el objeto de atributos de hilo

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
int pthread_attr_setaffinity_np(pthread_attr_t *attr,
                   size_t cpusetsize, const cpu_set_t *cpuset);
int pthread_attr_getaffinity_np(const pthread_attr_t *attr,
                   size_t cpusetsize, cpu_set_t *cpuset);

DESCRIPCIÓN

La función pthread_attr_setaffinity_np() establece la máscara de afinidad de CPU del objeto de atributos de hilo al que se refiere attr al valor especificado en cpuset. Este atributo determina la máscara de afinidad de CPU de un hilo creado utilizando el objeto de atributos de hilo attr.

La función pthread_attr_getaffinity_np() devuelve la máscara de afinidad de CPU del objeto de atributos de hilo al que se refiere attr en el búfer al que apunta cpuset.

El argumento cpusetsize es la longitud (en bytes) del búfer al que apunta cpuset. Típicamente, este argumento se especificaría como sizeof(cpu_set_t).

Para más detalles sobre las máscaras de afinidad de CPU, ver sched_setaffinity(2). Para una descripción de un conjunto de macros que se pueden utilizar para manipular e inspeccionar conjuntos de CPU, ver CPU_SET(3).

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

EINVAL
(pthread_attr_setaffinity_np()) cpuset especificó una CPU que estaba fuera del conjunto soportado por el kernel. (La opción de configuración del kernel CONFIG_NR_CPUS define el rango del conjunto soportado por el tipo de datos del kernel utilizado para representar conjuntos de CPU).
EINVAL
(pthread_attr_getaffinity_np()) Una CPU en la máscara de afinidad del objeto de atributos de hilo al que se refiere attr se encuentra fuera del rango especificado por cpusetsize (es decir, cpuset/cpusetsize es demasiado pequeño).
ENOMEM
(pthread_attr_setaffinity_np()) No se pudo asignar memoria.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_attr_setaffinity_np (), pthread_attr_getaffinity_np () Seguridad de hilos MT-Safe

ESTANDARES

GNU; de ahí el sufijo "_np" (no portable) en los nombres.

HISTORIA

glibc 2.3.4.

NOTAS

En glibc 2.3.3 solamente, se proporcionaron versiones de estas funciones que no tenían un argumento cpusetsize. En su lugar, el tamaño del conjunto de CPU dado a las llamadas al sistema subyacentes era siempre sizeof(cpu_set_t).

VER TAMBIÉN

sched_setaffinity(2), pthread_attr_init(3), pthread_setaffinity_np(3), cpuset(7), pthreads(7)
