ptsname(3) Manual de funciones de biblioteca ptsname(3)

NOMBRE

ptsname, ptsname_r - obtener el nombre del pseudoterminal esclavo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdlib.h>
char *ptsname(int fd);
int ptsname_r(size_t size;
              int fd, char buf[size], size_t size);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

ptsname():

    Desde glibc 2.24:
        _XOPEN_SOURCE >= 500
    glibc 2.23 y anteriores:
        _XOPEN_SOURCE

ptsname_r():

    _GNU_SOURCE

DESCRIPCIÓN

La función ptsname() devuelve el nombre del dispositivo de pseudoterminal esclavo que corresponde al maestro al que se refiere el descriptor de archivo fd.

La función ptsname_r() es el equivalente reentrante de ptsname(). Devuelve el nombre del dispositivo de pseudoterminal esclavo como una cadena terminada en nulo en el búfer apuntado por buf. El argumento size especifica el número de bytes disponibles en buf.

VALOR DE RETORNO

En caso de éxito, ptsname() devuelve un puntero a una cadena en almacenamiento estático que será sobrescrito por llamadas posteriores. Este puntero no debe ser liberado. En caso de error, se devuelve NULL.

En caso de éxito, ptsname_r() devuelve 0. En caso de error, se devuelve un número de error para indicar el error.

ERRORES

EINVAL
(Solo ptsname_r()) buf es NULL. (Este error se devuelve solo para glibc 2.25 y anteriores).
ENOTTY
fd no se refiere a un dispositivo maestro de pseudoterminal.
ERANGE
(Solo ptsname_r()) buf es demasiado pequeño.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
ptsname () Seguridad de hilos MT-Unsafe race:ptsname
ptsname_r () Seguridad de hilos MT-Safe

VERSIONES

Una versión de ptsname_r() está documentada en Tru64, HP-UX y FreeBSD, pero en esas implementaciones, se devuelve -1 en caso de error, con errno establecido para indicar el error. Evite usar esta función en programas portátiles.

ESTANDARES

ptsname():
POSIX.1-2008.
ptsname_r():
POSIX.1-2024.

HISTORIA

ptsname():
POSIX.1-2001. glibc 2.1.

ptsname() es parte del soporte de pseudoterminales UNIX 98 (ver pts(4)).

ptsname_r():
GNU.

VER TAMBIÉN

grantpt(3), posix_openpt(3), ttyname(3), unlockpt(3), pts(4), pty(7)
