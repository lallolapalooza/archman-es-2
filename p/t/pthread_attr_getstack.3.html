pthread_attr_setstack(3) Manual de Funciones de Biblioteca pthread_attr_setstack(3)

NOMBRE

pthread_attr_setstack, pthread_attr_getstack - establecer/obtener atributos de pila en un objeto de atributos de hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_attr_setstack(pthread_attr_t *attr,
                          const void *stackaddr,
                          size_t stacksize);
int pthread_attr_getstack(const pthread_attr_t *restrict attr,
                          void **restrict stackaddr,
                          size_t *restrict stacksize);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

pthread_attr_getstack(), pthread_attr_setstack():

    _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

La función pthread_attr_setstack() establece las direcciones de pila y los atributos de tamaño de pila del objeto de atributos de hilo referido por attr a los valores especificados en stackaddr y stacksize, respectivamente. Estos atributos especifican la ubicación y el tamaño de la pila que deben ser utilizados por un hilo que se crea usando el objeto de atributos de hilo attr.

stackaddr debe apuntar al byte direccionable más bajo de un búfer de stacksize bytes que fue asignado por el llamante. Las páginas del búfer asignado deben ser tanto legibles como escribibles.

La función pthread_attr_getstack() devuelve las direcciones de pila y los atributos de tamaño de pila del objeto de atributos de hilo referido por attr en los búferes apuntados por stackaddr y stacksize, respectivamente.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

pthread_attr_setstack() puede fallar con el siguiente error:

EINVAL
stacksize es menor que PTHREAD_STACK_MIN (16384) bytes. En algunos sistemas, este error también puede ocurrir si stackaddr o stackaddr + stacksize no están adecuadamente alineados.

POSIX.1 también documenta un error EACCES si el área de pila descrita por stackaddr y stacksize no es legible ni escribible por el llamante.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_attr_setstack (), pthread_attr_getstack () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

glibc 2.2. POSIX.1-2001.

NOTAS

Estas funciones se proporcionan para aplicaciones que deben asegurarse de que la pila de un hilo se coloque en una ubicación particular. Para la mayoría de las aplicaciones, esto no es necesario y se debe evitar el uso de estas funciones. (Use pthread_attr_setstacksize(3) si una aplicación simplemente requiere un tamaño de pila distinto del predeterminado).

Cuando una aplicación emplea pthread_attr_setstack(), se hace cargo de la asignación de la pila. Cualquier tamaño de guarda establecido mediante pthread_attr_setguardsize(3) se ignora. Si se considera necesario, es responsabilidad de la aplicación asignar un área de guarda (una o más páginas protegidas contra lectura y escritura) para manejar la posibilidad de desbordamiento de pila.

La dirección especificada en stackaddr debe estar adecuadamente alineada: para portabilidad completa, alinéela en un límite de página (sysconf(_SC_PAGESIZE)). posix_memalign(3) puede ser útil para la asignación. Probablemente, stacksize también debería ser un múltiplo del tamaño de página del sistema.

Si attr se utiliza para crear varios hilos, el llamante debe cambiar el atributo de dirección de pila entre las llamadas a pthread_create(3); de lo contrario, los hilos intentarán usar la misma área de memoria para sus pilas, y se producirá un caos.
