PTHREAD_ATTR_GETSCHEDPARAM(3P) Manual del programador POSIX PTHREAD_ATTR_GETSCHEDPARAM(3P)

PRÓLOGO

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_attr_getschedparam, pthread_attr_setschedparam — obtener y establecer el atributo schedparam

SINOPSIS

#include <pthread.h>
int pthread_attr_getschedparam(const pthread_attr_t *restrict attr,
    struct sched_param *restrict param);
int pthread_attr_setschedparam(pthread_attr_t *restrict attr,
    const struct sched_param *restrict param);

DESCRIPCIÓN

Las funciones pthread_attr_getschedparam() y pthread_attr_setschedparam() , respectivamente, obtienen y establecen los atributos de parámetro de planificación en el argumento attr. El contenido de la estructura param se define en la cabecera <sched.h>. Para las políticas SCHED_FIFO y SCHED_RR, el único miembro requerido de param es sched_priority.

Para la política SCHED_SPORADIC, los miembros requeridos de la estructura param son sched_priority, sched_ss_low_priority, sched_ss_repl_period, sched_ss_init_budget, y sched_ss_max_repl. El sched_ss_repl_period especificado debe ser mayor o igual que el sched_ss_init_budget especificado para que la función tenga éxito; si no lo es, la función fallará. El valor de sched_ss_max_repl debe estar dentro del rango inclusivo [1,{SS_REPL_MAX}] para que la función tenga éxito; si no lo está, la función fallará. No se especifica si los valores de sched_ss_repl_period y sched_ss_init_budget se almacenan tal como los proporciona esta función o se redondean para alinearse con la resolución del reloj que se está utilizando.

El comportamiento no está definido si el valor especificado por el argumento attr a pthread_attr_getschedparam() o pthread_attr_setschedparam() no se refiere a un objeto de atributos de hilo inicializado.

VALOR DE RETORNO

Si tiene éxito, las funciones pthread_attr_getschedparam() y pthread_attr_setschedparam() devolverán cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_attr_setschedparam() fallará si:

ENOTSUP
Se intentó establecer el atributo a un valor no soportado.

La función pthread_attr_setschedparam() puede fallar si:

EINVAL
El valor de param no es válido.

Estas funciones no devolverán un código de error de [EINTR].

USO DE LA APLICACIÓN

Después de que estos atributos hayan sido establecidos, un hilo puede crearse con los atributos especificados usando pthread_create(). El uso de estas rutinas no afecta al hilo en ejecución actual.

RACIONAMIENTO

Si una implementación detecta que el valor especificado por el argumento attr a pthread_attr_getschedparam() o pthread_attr_setschedparam() no se refiere a un objeto de atributos de hilo inicializado, se recomienda que la función falle e informe un error [EINVAL].
