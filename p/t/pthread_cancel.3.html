pthread_cancel(3) Manual de funciones de biblioteca pthread_cancel(3)

NOMBRE

pthread_cancel - enviar una solicitud de cancelación a un hilo

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_cancel(pthread_t thread);

DESCRIPCIÓN

La función pthread_cancel() envía una solicitud de cancelación al hilo thread. Si el hilo de destino reacciona a la solicitud de cancelación y cuándo lo hace, depende de dos atributos que están bajo el control de ese hilo: su estado de cancelabilidad estado y tipo.

El estado de cancelabilidad de un hilo, determinado por pthread_setcancelstate(3), puede ser habilitado (el valor por defecto para hilos nuevos) o deshabilitado. Si un hilo tiene la cancelación deshabilitada, entonces una solicitud de cancelación permanece en cola hasta que el hilo habilite la cancelabilidad. Si un hilo tiene la cancelación habilitada, entonces su tipo de cancelabilidad determina cuándo ocurre la cancelación.

El tipo de cancelabilidad de un hilo, determinado por pthread_setcanceltype(3), puede ser asíncrono o diferido (el valor por defecto para hilos nuevos). La cancelabilidad asíncrona significa que el hilo puede ser cancelado en cualquier momento (generalmente de inmediato, pero el sistema no lo garantiza). La cancelabilidad diferida significa que la cancelación se retrasará hasta que el hilo llame a una función que sea un punto de cancelación. Una lista de funciones que son o pueden ser puntos de cancelación se proporciona en pthreads(7).

Cuando se atiende una solicitud de cancelación, los siguientes pasos ocurren para thread (en este orden):

(1)
Se extraen (en orden inverso al que fueron insertados) y se llaman los manejadores de limpieza de cancelación. (Ver pthread_cleanup_push(3).)
(2)
Se llaman los destructores de datos específicos del hilo, en un orden no especificado. (Ver pthread_key_create(3).)
(3)
El hilo se termina. (Ver pthread_exit(3).)

Los pasos anteriores ocurren de forma asíncrona con respecto a la llamada pthread_cancel(); el estado de retorno de pthread_cancel() simplemente informa al llamante si la solicitud de cancelación se puso en cola correctamente.

Después de que un hilo cancelado ha terminado, unirse con ese hilo usando pthread_join(3) obtiene PTHREAD_CANCELED como el estado de salida del hilo. (Unirse con un hilo es la única forma de saber que la cancelación ha completado.)

VALOR DE RETORNO

En caso de éxito, pthread_cancel() devuelve 0; en caso de error, devuelve un número de error distinto de cero.

ERRORES

ESRCH
No se encontró ningún hilo con el ID thread.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_cancel () Seguridad de hilos MT-Safe

VERSIONES

En Linux, la cancelación se implementa utilizando señales. Bajo la implementación de hilos NPTL, se utiliza la primera señal real (es decir, señal 32) para este propósito. En LinuxThreads, se utiliza la segunda señal real, si las señales reales están disponibles; de lo contrario, se usa SIGUSR2.

ESTANDARES

POSIX.1-2008.

HISTORIA

glibc 2.0 POSIX.1-2001.

EJEMPLOS

El programa a continuación crea un hilo y luego lo cancela. El hilo principal se une con el hilo cancelado para verificar que su estado de salida fue PTHREAD_CANCELED. La siguiente sesión de shell muestra lo que sucede cuando ejecutamos el programa:


$ ./a.out
thread_func(): started; cancelation disabled
main(): sending cancelation request
thread_func(): about to enable cancelation
main(): thread was canceled

Fuente del programa

#include <err.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void *
thread_func(void *ignored_argument)
{
    int s;
    /* Disable cancelation for a while, so that we don't
       immediately react to a cancelation request.  */
    s = pthread_setcancelstate(PTHREAD_CANCEL_DISABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    printf("%s(): started; cancelation disabled\n", __func__);
    sleep(5);
    printf("%s(): about to enable cancelation\n", __func__);
    s = pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    /* sleep() is a cancelation point.  */
    sleep(1000);        /* Should get canceled while we sleep */
    /* Should never get here.  */
    printf("%s(): not canceled!\n", __func__);
    return NULL;
}
int
main(void)
{
    pthread_t thr;
    void *res;
    int s;
    /* Start a thread and then send it a cancelation request.  */
    s = pthread_create(&thr, NULL, &thread_func, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    sleep(2);           /* Give thread a chance to get started */
    printf("%s(): sending cancelation request\n", __func__);
    s = pthread_cancel(thr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_cancel");
    /* Join with thread to see what its exit status was.  */
    s = pthread_join(thr, &res);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_join");
    if (res == PTHREAD_CANCELED)
        printf("%s(): thread was canceled\n", __func__);
    else
        printf("%s(): thread wasn't canceled (shouldn't happen!)\n",
               __func__);
    exit(EXIT_SUCCESS);
}

NAME

pthread_cancel - request a thread to terminate

LIBRARY

libpthread - POSIX Threads Library

SYNOPSIS

#include <pthread.h>

int pthread_cancel(pthread_t thread);

DESCRIPTION

The pthread_cancel function sends a cancellation request to the thread specified by thread.

The thread can choose to act on this request at different points, known as cancellation points. These are typically functions that might block, such as read, write, select, poll, pthread_join, pthread_cond_wait, etc.

When a thread receives a cancellation request, it can either:

  • Cancel immediately (if cancellation is enabled and asynchronous).
  • Cancel at the next cancellation point (if cancellation is enabled and deferred).
  • Ignore the request (if cancellation is disabled).

The thread's cancellation type and state can be controlled using pthread_setcanceltype and pthread_setcancelstate.

RETURN VALUE

On success, pthread_cancel returns 0.

On error, it returns a non-zero error number.

ERRORS

ESRCH

The thread ID specified by thread does not refer to an existing thread.

EINVAL

The thread ID specified by thread is not a joinable thread.

VERSIONS

HISTORY
