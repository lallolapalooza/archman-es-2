pthread_attr_setsigmask_np(3) Manual de Funciones de Biblioteca pthread_attr_setsigmask_np(3)

NOMBRE

pthread_attr_setsigmask_np, pthread_attr_getsigmask_np - establecer/obtener la máscara de señales en el objeto de atributos de hilo

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
int pthread_attr_setsigmask_np(pthread_attr_t *attr,
                               const sigset_t *sigmask);
int pthread_attr_getsigmask_np(const pthread_attr_t *attr,
                               sigset_t *sigmask);

DESCRIPCIÓN

La función pthread_attr_setsigmask_np() establece la máscara de señales del objeto de atributos de hilo al que se refiere attr al valor especificado en *sigmask. Si sigmask se especifica como NULL, entonces se anula cualquier atributo de máscara de señales existente en attr.

La función pthread_attr_getsigmask_np() devuelve la máscara de señales del objeto de atributos de hilo al que se refiere attr en el búfer apuntado por sigmask. Si el atributo de máscara de señales no está establecido actualmente, esta función devuelve el valor especial PTHREAD_ATTR_NO_SIGMASK_NP como resultado.

VALOR DE RETORNO

La función pthread_attr_setsigmask_np() devuelve 0 en caso de éxito, o un número de error distinto de cero en caso de fallo.

La función pthread_attr_getsigmask_np() devuelve 0 o PTHREAD_ATTR_NO_SIGMASK_NP. Cuando se devuelve 0, la máscara de señales se devuelve a través de sigmask. Un valor de retorno de PTHREAD_ATTR_NO_SIGMASK_NP indica que el atributo de máscara de señales no está establecido en attr.

En caso de error, estas funciones devuelven un número de error positivo.

ERRORES

ENOMEM
(pthread_attr_setsigmask_np()) No se pudo asignar memoria.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_attr_setsigmask_np (), pthread_attr_getsigmask_np () Seguridad de hilos Seguro para MT (Thread-Safe)

ESTANDARES

GNU; de ahí el sufijo "_np" (no portátil) en los nombres.

HISTORIAL

glibc 2.32.

NOTAS

El atributo de máscara de señales determina la máscara de señales que se asignará a un hilo creado utilizando el objeto de atributos de hilo attr. Si este atributo no está establecido, un hilo creado utilizando attr heredará una copia de la máscara de señales del hilo creador.

Para más detalles sobre máscaras de señales, ver sigprocmask(2). Para una descripción de un conjunto de macros que se pueden utilizar para manipular e inspeccionar conjuntos de señales, ver sigsetops(3).

En ausencia de pthread_attr_setsigmask_np() es posible crear un hilo con una máscara de señales deseada de la siguiente manera:

•
El hilo creador utiliza pthread_sigmask(3) para guardar su máscara de señales actual y establecer su máscara para bloquear todas las señales.
•
El nuevo hilo se crea utilizando pthread_create(); el nuevo hilo heredará la máscara de señales del hilo creador.
•
El nuevo hilo establece su máscara de señales al valor deseado utilizando pthread_sigmask(3).
•
El hilo creador restaura su máscara de señales al valor original.

Siguiendo los pasos anteriores, no hay posibilidad de que el nuevo hilo reciba una señal antes de que haya ajustado su máscara de señales al valor deseado.

VER TAMBIÉN

sigprocmask(2), pthread_attr_init(3), pthread_sigmask(3), pthreads(7), signal(7)
