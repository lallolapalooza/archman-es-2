PT-SUMMARY(1p) Documentación aportada por el usuario de Perl PT-SUMMARY(1p)

NOMBRE

pt-summary - Resumir información del sistema de forma agradable.

SINOPSIS

Uso: pt-summary

pt-summary resume convenientemente el estado y la configuración de un servidor. No es una herramienta de ajuste ni de diagnóstico. Produce un informe que es fácil de comparar y se puede pegar en correos electrónicos sin perder el formato. Esta herramienta funciona bien en muchos tipos de sistemas Unix.

Descargar y ejecutar:

wget http://percona.com/get/pt-summary
bash ./pt-summary

RIESGOS

Percona Toolkit es maduro, probado en el mundo real y bien probado, pero todas las herramientas de bases de datos pueden suponer un riesgo para el sistema y el servidor de bases de datos. Antes de usar esta herramienta, por favor:

  • Lea la documentación de la herramienta
  • Revise los "BUGS" conocidos de la herramienta
  • Pruebe la herramienta en un servidor no productivo
  • Haga una copia de seguridad de su servidor de producción y verifique las copias

DESCRIPCIÓN

pt-summary ejecuta una gran variedad de comandos para inspeccionar el estado y la configuración del sistema, guarda la salida en archivos en un directorio temporal y luego ejecuta comandos de Unix sobre estos resultados para formatearlos de forma agradable. Funciona mejor cuando se ejecuta como un usuario privilegiado, pero también funcionará sin privilegios, aunque es posible que parte de la salida no se pueda generar sin ser root.

SALIDA

Muchas de las salidas de esta herramienta se redondean deliberadamente para mostrar su magnitud pero no el detalle exacto. Esto se llama redondeo difuso (fuzzy-rounding). La idea es que no importa si un contador particular es 918 o 921; una variación tan pequeña es insignificante y solo hace que la salida sea difícil de comparar con otros servidores. El redondeo difuso redondea en incrementos mayores a medida que aumenta la entrada. Comienza redondeando al múltiplo de 5 más cercano, luego al de 10, al de 25, y luego repite por un factor de 10 mayor (50, 100, 250), y así sucesivamente, a medida que la entrada crece.

NAME

pt-summary

collect and display system status summary

SYNOPSIS

pt-summary [OPTIONS]

RISKS

This tool is not considered dangerous. There are no known risks associated with its use. It is a read-only tool that gathers information from the system and presents it in a human-readable format.

DESCRIPTION

This tool collects and displays system status information that is useful for diagnosing performance problems. It gathers information from various sources, including:

  • Mounted filesystems and disk usage
  • Network interfaces and configuration
  • Top processes by CPU usage
  • Output of "vmstat 1 5"

The output is divided into sections, each summarizing a different aspect of the system status.

OUTPUT

The tool's output is divided into several sections. The exact sections displayed depend on the options used. Below is an example of the output:

OPTIONS

--config
type: string

Read this comma-separated list of config files. If specified, this must be the first option on the command line.

--help
Print help and exit.
--read-samples
type: string

Create a report from the files in this directory.

--save-samples
type: string

Save the collected data in this directory.

--sleep
type: int; default: 5

How long to sleep when gathering samples from vmstat.

--summarize-mounts
default: yes; negatable: yes

Report on mounted filesystems and disk usage.

--summarize-network
default: yes; negatable: yes

Report on network controllers and configuration.

--summarize-processes
default: yes; negatable: yes

Report on top processes and "vmstat" output.

--version
Print tool's version and exit.

ENVIRONMENT

This tool does not use any environment variables.

SYSTEM REQUIREMENTS

This tool requires the Bourne shell (/bin/sh).
