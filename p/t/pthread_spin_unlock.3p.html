PRÓLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux) o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_spin_unlock — desbloquear un objeto de bloqueo giratorio

SINOPSIS

#include <pthread.h>
int pthread_spin_unlock(pthread_spinlock_t *lock);

DESCRIPCIÓN

La función pthread_spin_unlock() liberará el bloqueo giratorio referenciado por lock, que fue bloqueado mediante las funciones pthread_spin_lock() o pthread_spin_trylock().

Los resultados no están definidos si el bloqueo no lo tiene el hilo llamante.

Si hay hilos girando en el bloqueo cuando se llama a pthread_spin_unlock(), el bloqueo se vuelve disponible y un hilo giratorio no especificado adquirirá el bloqueo.

Los resultados no están definidos si esta función se llama con un bloqueo giratorio de hilo no inicializado.

VALOR DEVOLUCIÓN

Al completarse con éxito, la función pthread_spin_unlock() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

Esta función no devolverá un código de error de [EINTR].

USO APLICACIÓN

RACIONAMIENTO

Si una implementación detecta que el valor especificado por el argumento lock de pthread_spin_unlock() no se refiere a un objeto de bloqueo giratorio inicializado, se recomienda que la función falle y reporte un error [EINVAL].

Si una implementación detecta que el valor especificado por el argumento lock de pthread_spin_unlock() se refiere a un objeto de bloqueo giratorio para el cual el hilo actual no tiene el bloqueo, se recomienda que la función falle y reporte un error [EPERM].
