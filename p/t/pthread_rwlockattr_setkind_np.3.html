pthread_rwlockattr_setkind_np(3) Manual de funciones de biblioteca pthread_rwlockattr_setkind_np(3)

NOMBRE

pthread_rwlockattr_setkind_np, pthread_rwlockattr_getkind_np - establecer/obtener el tipo de bloqueo de lectura-escritura del objeto de atributo de bloqueo de lectura-escritura de hilos

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_rwlockattr_setkind_np(pthread_rwlockattr_t *attr,
                       int pref);
int pthread_rwlockattr_getkind_np(
                       const pthread_rwlockattr_t *restrict attr,
                       int *restrict pref);
Requisitos de Macro de Prueba de Funcionalidades para glibc (ver feature_test_macros(7)):

pthread_rwlockattr_setkind_np(), pthread_rwlockattr_getkind_np():

    _XOPEN_SOURCE >= 500 || _POSIX_C_SOURCE >= 200809L

DESCRIPCIÓN

La función pthread_rwlockattr_setkind_np() establece el atributo de "tipo de bloqueo" del objeto de atributo de bloqueo de lectura-escritura al que se refiere attr al valor especificado en pref. El argumento pref puede establecerse en una de las siguientes opciones:

PTHREAD_RWLOCK_PREFER_READER_NP
Este es el valor predeterminado. Un hilo puede mantener múltiples bloqueos de lectura; es decir, los bloqueos de lectura son recursivos. Según The Single Unix Specification, el comportamiento no está especificado cuando un lector intenta colocar un bloqueo, y no hay bloqueo de escritura pero hay escritores esperando. Dar preferencia al lector, como se establece con PTHREAD_RWLOCK_PREFER_READER_NP, implica que el lector recibirá el bloqueo solicitado, incluso si un escritor está esperando. Mientras haya lectores, el escritor será desatendido.
PTHREAD_RWLOCK_PREFER_WRITER_NP
Esta opción está destinada a ser el análogo del bloqueo de escritura de PTHREAD_RWLOCK_PREFER_READER_NP. glibc la ignora porque el requisito de POSIX de admitir bloqueos de lectura recursivos haría que esta opción creara deadlocks triviales; en su lugar, use PTHREAD_RWLOCK_PREFER_WRITER_NONRECURSIVE_NP, que garantiza que el desarrollador de la aplicación no tomará bloqueos de lectura recursivos, evitando así los deadlocks.
PTHREAD_RWLOCK_PREFER_WRITER_NONRECURSIVE_NP
Establecer el tipo de bloqueo en esta opción evita la desatención del escritor, siempre y cuando no se realice ningún bloqueo de lectura de forma recursiva.

La función pthread_rwlockattr_getkind_np() devuelve el valor del atributo de tipo de bloqueo del objeto de atributo de bloqueo de lectura-escritura al que se refiere attr en el puntero pref.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0. Dados argumentos de puntero válidos, pthread_rwlockattr_getkind_np() siempre tiene éxito. En caso de error, pthread_rwlockattr_setkind_np() devuelve un número de error distinto de cero.

ERRORES

EINVAL
pref especifica un valor no admitido.

ESTÁNDARES

GNU; de ahí el sufijo "_np" (no portátil) en los nombres.

HISTORIAL

glibc 2.1.

VER TAMBIÉN
