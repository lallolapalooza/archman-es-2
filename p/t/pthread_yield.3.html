pthread_yield(3) Manual de Funciones de Biblioteca pthread_yield(3)

NOMBRE

pthread_yield - ceder el procesador

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
[[deprecated]] int pthread_yield(void);

DESCRIPCIÓN

Nota: Esta función está obsoleta; ver abajo.

pthread_yield() hace que el hilo que la llama renuncie a la CPU. El hilo se coloca al final de la cola de ejecución para su prioridad estática y se programa otro hilo para que se ejecute. Para más detalles, ver sched_yield(2)

VALOR DE RETORNO

En caso de éxito, pthread_yield() devuelve 0; en caso de error, devuelve un número de error.

ERRORES

En Linux, esta llamada siempre tiene éxito (pero las aplicaciones portátiles y a prueba de futuro aún así deben manejar una posible devolución de error).

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_yield () Seguridad de hilos MT-Safe

VERSIÓNES

En Linux, esta función se implementa como una llamada a sched_yield(2).

ESTÁNDARES

Ninguno.

HISTORIAL

Obsoleto desde glibc 2.34. Usar el estandarizado sched_yield(2) en su lugar.

NOTAS

pthread_yield() está destinada a su uso con políticas de planificación en tiempo real (es decir, SCHED_FIFO o SCHED_RR). El uso de pthread_yield() con políticas de planificación no deterministas como SCHED_OTHER no está especificado y es muy probable que signifique que el diseño de su aplicación es defectuoso.

VER TAMBIÉN

sched_yield(2), pthreads(7), sched(7)
