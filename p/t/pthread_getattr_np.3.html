pthread_getattr_np(3) Manual de funciones de biblioteca pthread_getattr_np(3)

NOMBRE

pthread_getattr_np - obtener atributos del hilo creado

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
int pthread_getattr_np(pthread_t thread, pthread_attr_t *attr);

DESCRIPCIÓN

La función pthread_getattr_np() inicializa el objeto de atributos del hilo al que se refiere attr para que contenga los valores de atributos reales que describen el hilo en ejecución thread.

Los valores de atributos devueltos pueden diferir de los valores de atributos correspondientes pasados en el objeto attr que se utilizó para crear el hilo usando pthread_create(3). En particular, los siguientes atributos pueden diferir:

•
el estado de desvinculación (detach state), ya que un hilo unible puede haberse desvinculado después de la creación;
•
el tamaño de la pila (stack size), que la implementación puede alinear a un borde adecuado.
•
y el tamaño de la guarda (guard size), que la implementación puede redondear hacia arriba a un múltiplo del tamaño de página, o ignorar (es decir, tratar como 0), si la aplicación está asignando su propia pila.

Además, si el atributo de dirección de la pila no se estableció en el objeto de atributos del hilo utilizado para crear el hilo, el objeto de atributos del hilo devuelto informará la dirección real de la pila que la implementación seleccionó para el hilo.

Cuando el objeto de atributos del hilo devuelto por pthread_getattr_np() ya no sea necesario, debe destruirse usando pthread_attr_destroy(3).

VALOR DE RETORNO

En caso de éxito, esta función devuelve 0; en caso de error, devuelve un número de error distinto de cero.

ERRORES

ENOMEM
Memoria insuficiente.

Además, si thread se refiere al hilo principal, pthread_getattr_np() puede fallar debido a errores de varias llamadas subyacentes: fopen(3), si no se puede abrir /proc/self/maps; y getrlimit(2), si el límite de recursos RLIMIT_STACK no es compatible.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_getattr_np () Seguridad de hilos (Thread safety) MT-Safe

ESTÁNDARES

GNU; de ahí el sufijo "_np" (no portátil) en el nombre.

HISTORIA

glibc 2.2.3.

EJEMPLOS

El siguiente programa demuestra el uso de pthread_getattr_np(). El programa crea un hilo que luego utiliza pthread_getattr_np() para recuperar y mostrar sus atributos de tamaño de guarda, dirección de pila y tamaño de pila. Se pueden usar argumentos de línea de comandos para establecer estos atributos a valores distintos de los predeterminados al crear el hilo. Las sesiones de shell a continuación demuestran el uso del programa.

En la primera ejecución, en un sistema x86-32, se crea un hilo utilizando atributos predeterminados:


$ ulimit -s      # Sin límite de pila ==> tamaño de pila predeterminado es 2 MB
unlimited
$ ./a.out
Atributos del hilo creado:
        Tamaño de guarda          = 4096 bytes
        Dirección de pila       = 0x40196000 (EOS = 0x40397000)
        Tamaño de pila          = 0x201000 (2101248) bytes

En la siguiente ejecución, vemos que si se especifica un tamaño de guarda, se redondea al siguiente múltiplo del tamaño de página del sistema (4096 bytes en x86-32):


$ ./a.out -g 4097
Objeto de atributos del hilo después de inicializaciones:
        Tamaño de guarda          = 4097 bytes
        Dirección de pila       = (nil)
        Tamaño de pila          = 0x0 (0) bytes
Atributos del hilo creado:
        Tamaño de guarda          = 8192 bytes
        Dirección de pila       = 0x40196000 (EOS = 0x40397000)
        Tamaño de pila          = 0x201000 (2101248) bytes

En la última ejecución, el programa asigna manualmente una pila para el hilo. En este caso, el atributo de tamaño de guarda se ignora.


$ ./a.out -g 4096 -s 0x8000 -a
Pila de hilo asignada en 0x804d000
Objeto de atributos del hilo después de inicializaciones:
        Tamaño de guarda          = 4096 bytes
        Dirección de pila       = 0x804d000 (EOS = 0x8055000)
        Tamaño de pila          = 0x8000 (32768) bytes
Atributos del hilo creado:
        Tamaño de guarda          = 0 bytes
        Dirección de pila       = 0x804d000 (EOS = 0x8055000)
        Tamaño de pila          = 0x8000 (32768) bytes

static void
display_stack_related_attributes(pthread_attr_t *attr, char *prefix)
{
    int s;
    size_t stack_size, guard_size;
    void *stack_addr;
    s = pthread_attr_getguardsize(attr, &guard_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("%sTamaño de guarda          = %zu bytes\n", prefix, guard_size);
    s = pthread_attr_getstack(attr, &stack_addr, &stack_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstack");
    printf("%sDirección de pila       = %p", prefix, stack_addr);
    if (stack_size > 0)
        printf(" (EOS = %p)", (char *) stack_addr + stack_size);
    printf("\n");
    printf("%sTamaño de pila          = %#zx (%zu) bytes\n",
           prefix, stack_size, stack_size);
}
static void
display_thread_attributes(pthread_t thread, char *prefix)
{
    int s;
    pthread_attr_t attr;
    s = pthread_getattr_np(thread, &attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getattr_np");
    display_stack_related_attributes(&attr, prefix);
    s = pthread_attr_destroy(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_destroy");
}
static void *           /* Función de inicio para el hilo que creamos */
thread_start(void *arg)
{
    printf("Atributos del hilo creado:\n");
    display_thread_attributes(pthread_self(), "\t");
    exit(EXIT_SUCCESS);         /* Terminar todos los hilos */
}
static void
usage(char *pname, char *msg)
{
    if (msg != NULL)
        fputs(msg, stderr);
    fprintf(stderr, "Uso: %s [-s tamaño-pila [-a]]"
            " [-g tamaño-guarda]\n", pname);
    fprintf(stderr, "\t\t-a significa que el programa debe asignar la pila\n");
    exit(EXIT_FAILURE);
}
