pthread_setname_np(3) Manual de funciones de biblioteca pthread_setname_np(3)

NOMBRE

pthread_setname_np, pthread_getname_np - establecer/obtener el nombre de un hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#define _GNU_SOURCE             /* Ver feature_test_macros(7) */
#include <pthread.h>
int pthread_setname_np(pthread_t thread, const char *name);
int pthread_getname_np(size_t size;
                       pthread_t thread, char name[size], size_t size);

DESCRIPCIÓN

Por defecto, todos los hilos creados usando pthread_create() heredan el nombre del programa. La función pthread_setname_np() puede ser usada para establecer un nombre único para un hilo, lo cual puede ser útil para depurar aplicaciones multihilo. El nombre del hilo es una cadena significativa en lenguaje C, cuya longitud está restringida a 16 caracteres, incluyendo el byte nulo de terminación ('\0'). El argumento thread especifica el hilo cuyo nombre se va a cambiar; name especifica el nuevo nombre.

La función pthread_getname_np() puede ser usada para recuperar el nombre del hilo. El argumento thread especifica el hilo cuyo nombre se va a recuperar. El búfer name se usa para devolver el nombre del hilo; size especifica el número de bytes disponibles en name. El búfer especificado por name debe tener al menos 16 caracteres de longitud. El nombre del hilo devuelto en el búfer de salida estará terminado en nulo.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

La función pthread_setname_np() puede fallar con el siguiente error:

ERANGE
La longitud de la cadena especificada apuntada por name excede el límite permitido.

La función pthread_getname_np() puede fallar con el siguiente error:

ERANGE
El búfer especificado por name y size es demasiado pequeño para contener el nombre del hilo.

Si alguna de estas funciones falla al abrir /proc/self/task/tid/comm, la llamada puede fallar con uno de los errores descritos en open(2).

ATRIBUTOS

Para una explicación de los términos usados en esta sección, ver attributes(7).

Interfaz Atributo Valor
pthread_setname_np (), pthread_getname_np () Seguridad de hilos MT-Safe

ESTÁNDARES

GNU; de ahí el sufijo "_np" (no portable) en los nombres.

HISTORIA

glibc 2.12.

NOTAS

pthread_setname_np() escribe internamente en el archivo comm específico del hilo bajo el sistema de archivos /proc: /proc/self/task/tid/comm. pthread_getname_np() lo recupera de la misma ubicación.

EJEMPLOS

El siguiente programa demuestra el uso de pthread_setname_np() y pthread_getname_np().

La siguiente sesión de shell muestra una ejecución de ejemplo del programa:


$ ./a.out;
Created a thread.  Default name is: a.out
The thread name after setting it is THREADFOO.
^Z                           # Suspender el programa
[1]+  Stopped           ./a.out
$ ps H -C a.out -o 'pid tid cmd comm'
  PID   TID CMD                         COMMAND
 5990  5990 ./a.out                     a.out
 5990  5991 ./a.out                     THREADFOO
$ cat /proc/5990/task/5990/comm
a.out
$ cat /proc/5990/task/5991/comm
THREADFOO

Código fuente del programa

#define _GNU_SOURCE
#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#define NAMELEN 16
static void *
threadfunc(void *parm)
{
    sleep(5);          // permitir al programa principal establecer el nombre del hilo
    return NULL;
}
int
main(int argc, char *argv[])
{
    pthread_t thread;
    int rc;
    char thread_name[NAMELEN];
    rc = pthread_create(&thread, NULL, threadfunc, NULL);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_create");
    rc = pthread_getname_np(thread, thread_name, NAMELEN);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_getname_np");
    printf("Created a thread.  Default name is: %s\n", thread_name);
    rc = pthread_setname_np(thread, (argc > 1) ? argv[1] : "THREADFOO");
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_setname_np");
    sleep(2);
    rc = pthread_getname_np(thread, thread_name, NAMELEN);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_getname_np");
    printf("The thread name after setting it is %s.\n", thread_name);
    rc = pthread_join(thread, NULL);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_join");
    printf("Done\n");
    exit(EXIT_SUCCESS);
}
