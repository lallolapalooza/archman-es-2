pthread_cleanup_push(3) Manual de Funciones de Biblioteca pthread_cleanup_push(3)

NOMBRE

pthread_cleanup_push, pthread_cleanup_pop - apilar y desapilar manejadores de limpieza de cancelación de hilos

BIBLIOTECA

Biblioteca POSIX de hilos (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
void pthread_cleanup_push(typeof(void (void *)) *routine, void *arg);
void pthread_cleanup_pop(int execute);

DESCRIPCIÓN

Estas funciones manipulan la pila de manejadores de limpieza de cancelación de hilos del hilo que realiza la llamada. Un manejador de limpieza es una función que se ejecuta automáticamente cuando se cancela un hilo (o en varias otras circunstancias descritas a continuación); podría, por ejemplo, desbloquear un mutex para que esté disponible para otros hilos en el proceso.

La función pthread_cleanup_push() apila routine en la cima de la pila de manejadores de limpieza. Cuando routine se invoca más tarde, se le pasará arg como argumento.

La función pthread_cleanup_pop() elimina el manejador de la cima de la pila de manejadores de limpieza y opcionalmente lo ejecuta si execute es distinto de cero.

Un manejador de limpieza de cancelación se desapila y ejecuta en las siguientes circunstancias:

•
Cuando se cancela un hilo, todos los manejadores de limpieza apilados se desapilan y ejecutan en el orden inverso al que se apilaron.
•
Cuando un hilo termina llamando a pthread_exit(3), todos los manejadores de limpieza se ejecutan como se describe en el punto anterior. (Los manejadores de limpieza *no* se llaman si el hilo termina realizando un *return* desde la función de inicio del hilo).
•
Cuando un hilo llama a pthread_cleanup_pop() con un argumento execute distinto de cero, se desapila y ejecuta el manejador de limpieza más superior.

POSIX.1 permite que pthread_cleanup_push() y pthread_cleanup_pop() se implementen como macros que se expanden a texto que contiene '{' y '}', respectivamente. Por esta razón, el llamador debe asegurarse de que las llamadas a estas funciones estén emparejadas dentro de la misma función y en el mismo nivel de anidamiento léxico. (En otras palabras, un manejador de limpieza solo se establece durante la ejecución de una sección de código específica).

Llamar a longjmp(3) (siglongjmp(3)) produce resultados indefinidos si se ha realizado alguna llamada a pthread_cleanup_push() o pthread_cleanup_pop() sin la llamada correspondiente del par desde que se llenó el búfer de salto con setjmp(3) (sigsetjmp(3)). De manera similar, llamar a longjmp(3) (siglongjmp(3)) desde dentro de un manejador de limpieza produce resultados indefinidos a menos que el búfer de salto también se haya llenado con setjmp(3) (sigsetjmp(3)) dentro del manejador.

VALOR DE RETORNO

Estas funciones no devuelven ningún valor.

ERRORES

No hay errores.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_cleanup_push (), pthread_cleanup_pop () Seguridad de hilos MT-Safe

VERSIONES

En glibc, las funciones pthread_cleanup_push() y pthread_cleanup_pop() *están* implementadas como macros que se expanden a texto que contiene '{' y '}', respectivamente. Esto significa que las variables declaradas dentro del alcance de las llamadas emparejadas a estas funciones serán visibles solo dentro de ese alcance.

POSIX.1 dice que el efecto de usar return, break, continue o goto para salir prematuramente de un bloque delimitado por pthread_cleanup_push() y pthread_cleanup_pop() es indefinido. Las aplicaciones portátiles deben evitar hacer esto.

ESTANDARES

POSIX.1-2008.

HISTORIAL

EJEMPLOS

El programa que se muestra a continuación proporciona un ejemplo sencillo del uso de las funciones descritas en esta página. El programa crea un hilo que ejecuta un bucle delimitado por pthread_cleanup_push() y pthread_cleanup_pop(). Este bucle incrementa una variable global, cnt, una vez cada segundo. Dependiendo de los argumentos de la línea de comandos que se proporcionen, el hilo principal envía una solicitud de cancelación al otro hilo, o establece una variable global que hace que el otro hilo salga de su bucle y termine normalmente (haciendo un *return*).

En la siguiente sesión de shell, el hilo principal envía una solicitud de cancelación al otro hilo:


$ ./a.out;
New thread started
cnt = 0
cnt = 1
Canceling thread
Called clean-up handler
Thread was canceled; cnt = 0

De lo anterior, vemos que el hilo fue cancelado y que el manejador de limpieza de cancelación fue llamado y restableció el valor de la variable global cnt a 0.

En la siguiente ejecución, el programa principal establece una variable global que hace que el otro hilo termine normalmente:


$ ./a.out x;
New thread started
cnt = 0
cnt = 1
Thread terminated normally; cnt = 2

De lo anterior, vemos que el manejador de limpieza no se ejecutó (porque cleanup_pop_arg era 0) y, por lo tanto, el valor de cnt no se restableció.

En la siguiente ejecución, el programa principal establece una variable global que hace que el otro hilo termine normalmente y proporciona un valor distinto de cero para cleanup_pop_arg:


$ ./a.out x 1;
New thread started
cnt = 0
cnt = 1
Called clean-up handler
Thread terminated normally; cnt = 0

En lo anterior, vemos que aunque el hilo no fue cancelado, el manejador de limpieza se ejecutó, porque el argumento dado a pthread_cleanup_pop() era distinto de cero.

Fuente del programa

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
static int done = 0;
static int cleanup_pop_arg = 0;
static int cnt = 0;
static void
cleanup_handler(void *arg)
{
    printf("Called clean-up handler\n");
    cnt = 0;
}
static void *
thread_start(void *arg)
{
    time_t curr;
    printf("New thread started\n");
    pthread_cleanup_push(cleanup_handler, NULL);
    curr = time(NULL);
    while (!done) {
        pthread_testcancel();           /* Un punto de cancelación */
        if (curr < time(NULL)) {
            curr = time(NULL);
            printf("cnt = %d\n", cnt);  /* Un punto de cancelación */
            cnt++;
        }
    }
    pthread_cleanup_pop(cleanup_pop_arg);
    return NULL;
}
int
main(int argc, char *argv[])
{
    pthread_t thr;
    int s;
    void *res;
    s = pthread_create(&thr, NULL, thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    sleep(2);           /* Permitir que el nuevo hilo se ejecute un rato */
    if (argc > 1) {
        if (argc > 2)
            cleanup_pop_arg = atoi(argv[2]);
        done = 1;
    } else {
        printf("Canceling thread\n");
        s = pthread_cancel(thr);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_cancel");
    }
    s = pthread_join(thr, &res);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_join");
    if (res == PTHREAD_CANCELED)
        printf("Thread was canceled; cnt = %d\n", cnt);
    else
        printf("Thread terminated normally; cnt = %d\n", cnt);
    exit(EXIT_SUCCESS);
}

EJEMPLOS

La siguiente llamada de ejemplo a pthread_cleanup_pop(3)
elimina un manejador de limpieza sin ejecutarlo:

#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>

/* La función de limpieza del ejemplo */
static void
cleanup_handler(void *arg)
{
    printf("En el manejador de limpieza: %s\n", (char *)arg);
}

static void *
thread_func(void *arg)
{
    const char *msg_cleanup_push = "Este mensaje se imprimirá si se ejecuta el manejador";
    const *msg_cleanup_pop = "Este mensaje se imprimirá si se ejecuta el manejador";

    /* Poner un manejador de limpieza */
    pthread_cleanup_push(cleanup_handler, (void *)msg_cleanup_push);

    /* Hacer algo de trabajo ... */
    pthread_testcancel();

    /* Sacar el manejador de limpieza sin ejecutarlo */
    pthread_cleanup_pop(0);
    /* A partir de aquí, el manejador de limpieza ya no está en la pila. */

    /* Hacer algo de trabajo ... */
    pthread_testcancel();

    /* Poner otro manejador de limpieza */
    pthread_cleanup_push(cleanup_handler, (void *)msg_cleanup_pop);

    /* Sacar el manejador de limpieza y ejecutarlo */
    pthread_cleanup_pop(1);

    return NULL;
}

int
main(void)
{
    pthread_t tid;
    int cnt;

    if (pthread_create(&tid, NULL, thread_func, NULL) != 0) {
        perror("pthread_create");
        exit(EXIT_FAILURE);
    }

    if (pthread_join(tid, (void **)NULL) != 0) {
        perror("pthread_join");
        exit(EXIT_FAILURE);
    }

    return 0;
}
