pthread_attr_init(3) Manual de funciones de biblioteca pthread_attr_init(3)

NOMBRE

pthread_attr_init, pthread_attr_destroy - inicializar y destruir objeto de atributos de hilo

BIBLIOTECA

Biblioteca de hilos POSIX (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
int pthread_attr_init(pthread_attr_t *attr);
int pthread_attr_destroy(pthread_attr_t *attr);

DESCRIPCIÓN

La función pthread_attr_init() inicializa el objeto de atributos de hilo apuntado por attr con valores de atributos por defecto. Después de esta llamada, los atributos individuales del objeto se pueden establecer utilizando varias funciones relacionadas (listadas en VER TAMBIÉN), y luego el objeto se puede usar en una o más llamadas a pthread_create(3) que crean hilos.

Llamar a pthread_attr_init() en un objeto de atributos de hilo que ya ha sido inicializado resulta en un comportamiento indefinido.

Cuando un objeto de atributos de hilo ya no es necesario, debe ser destruido utilizando la función pthread_attr_destroy(). Destruir un objeto de atributos de hilo no tiene efecto en los hilos que fueron creados usando ese objeto.

Una vez que un objeto de atributos de hilo ha sido destruido, puede ser reinicializado usando pthread_attr_init(). Cualquier otro uso de un objeto de atributos de hilo destruido tiene resultados indefinidos.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven 0; en caso de error, devuelven un número de error distinto de cero.

ERRORES

POSIX.1 documenta un error ENOMEM para pthread_attr_init(); en Linux estas funciones siempre tienen éxito (pero las aplicaciones portátiles y preparadas para el futuro deben, sin embargo, manejar una posible devolución de error).

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_attr_init (), pthread_attr_destroy () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

El tipo pthread_attr_t debe tratarse como opaco: cualquier acceso al objeto que no sea a través de las funciones pthreads no es portable y produce resultados indefinidos.

EJEMPLOS

El siguiente programa utiliza opcionalmente pthread_attr_init() y varias funciones relacionadas para inicializar un objeto de atributos de hilo que se utiliza para crear un solo hilo. Una vez creado, el hilo utiliza la función pthread_getattr_np(3) (una extensión GNU no estándar) para recuperar los atributos del hilo y luego muestra esos atributos.

Si el programa se ejecuta sin ningún argumento de línea de comandos, pasa NULL como argumento attr de pthread_create(3), de modo que el hilo se crea con atributos por defecto. Ejecutando el programa en Linux/x86-32 con la implementación de hilos NPTL, vemos lo siguiente:


$ ulimit -s       # Sin límite de pila ==> tamaño de pila por defecto es 2 MB
unlimited
$ ./a.out
Atributos del hilo:
        Estado de desvinculación        = PTHREAD_CREATE_JOINABLE
        Ámbito               = PTHREAD_SCOPE_SYSTEM
        Planificación de herencia   = PTHREAD_INHERIT_SCHED
        Política de planificación   = SCHED_OTHER
        Prioridad de planificación = 0
        Tamaño de guarda          = 4096 bytes
        Dirección de pila       = 0x40196000
        Tamaño de pila          = 0x201000 bytes

Cuando proporcionamos un tamaño de pila como argumento de línea de comandos, el programa inicializa un objeto de atributos de hilo, establece varios atributos en ese objeto y pasa un puntero al objeto en la llamada a pthread_create(3). Ejecutando el programa en Linux/x86-32 con la implementación de hilos NPTL, vemos lo siguiente:


$ ./a.out 0x3000000
posix_memalign() asignado en 0x40197000
Atributos del hilo:
        Estado de desvinculación        = PTHREAD_CREATE_DETACHED
        Ámbito               = PTHREAD_SCOPE_SYSTEM
        Planificación de herencia   = PTHREAD_EXPLICIT_SCHED

        Prioridad de planificación = 0

        Dirección de pila       = 0x40197000

static void
display_pthread_attr(pthread_attr_t *attr, char *prefix)
{
    int s, i;
    size_t v;
    void *stkaddr;
    struct sched_param sp;
    s = pthread_attr_getdetachstate(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getdetachstate");
    printf("%sEstado de desvinculación        = %s\n", prefix,
           (i == PTHREAD_CREATE_DETACHED) ? "PTHREAD_CREATE_DETACHED" :
           (i == PTHREAD_CREATE_JOINABLE) ? "PTHREAD_CREATE_JOINABLE" :
           "???");
    s = pthread_attr_getscope(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getscope");
    printf("%sÁmbito               = %s\n", prefix,
           (i == PTHREAD_SCOPE_SYSTEM)  ? "PTHREAD_SCOPE_SYSTEM" :
           (i == PTHREAD_SCOPE_PROCESS) ? "PTHREAD_SCOPE_PROCESS" :
           "???");
    s = pthread_attr_getinheritsched(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getinheritsched");
    printf("%sPlanificación de herencia   = %s\n", prefix,
           (i == PTHREAD_INHERIT_SCHED)  ? "PTHREAD_INHERIT_SCHED" :
           (i == PTHREAD_EXPLICIT_SCHED) ? "PTHREAD_EXPLICIT_SCHED" :
           "???");
    s = pthread_attr_getschedpolicy(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedpolicy");
    printf("%sPolítica de planificación   = %s\n", prefix,
           (i == SCHED_OTHER) ? "SCHED_OTHER" :
           (i == SCHED_FIFO)  ? "SCHED_FIFO" :
           (i == SCHED_RR)    ? "SCHED_RR" :
           "???");
    s = pthread_attr_getschedparam(attr, &sp);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedparam");
    printf("%sPrioridad de planificación = %d\n", prefix, sp.sched_priority);
    s = pthread_attr_getguardsize(attr, &v);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("%sTamaño de guarda          = %zu bytes\n", prefix, v);
    s = pthread_attr_getstack(attr, &stkaddr, &v);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstack");
    printf("%sDirección de pila       = %p\n", prefix, stkaddr);
    printf("%sTamaño de pila          = %#zx bytes\n", prefix, v);
}

       primer argumento. */
    s = pthread_getattr_np(pthread_self(), &gattr);

    display_pthread_attr(&gattr, "\t");

EJEMPLOS

El siguiente código crea un hilo con un tamaño de pila especificado por el primer argumento de la línea de comandos:

        s = pthread_attr_init(&attr);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_init");
        s = pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setdetachstate");
        s = pthread_attr_setinheritsched(&attr, PTHREAD_EXPLICIT_SCHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setinheritsched");
        stack_size = strtoul(argv[1], NULL, 0);
        s = posix_memalign(&sp, sysconf(_SC_PAGESIZE), stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "posix_memalign");
        printf("posix_memalign() allocated at %p\n", sp);
        s = pthread_attr_setstack(&attr, sp, stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setstack");
    }
    s = pthread_create(&thr, attrp, &thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    if (attrp != NULL) {
        s = pthread_attr_destroy(attrp);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_destroy");
    }
    pause();    /* Terminates when other thread calls exit() */
}
