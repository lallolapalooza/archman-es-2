NOMBRE

pt-fingerprint - Convierte consultas en huellas dactilares.

SINOPSIS

Uso: pt-fingerprint [OPCIONES] [ARCHIVOS]

pt-fingerprint convierte consultas en huellas dactilares. Con la opción --query, convierte el valor de la opción en una huella dactilar. Sin opciones, trata los argumentos de la línea de comandos como ARCHIVOS y lee y convierte consultas separadas por punto y coma de los ARCHIVOS. Cuando ARCHIVO es -, lee la entrada estándar.

Convertir una sola consulta:

pt-fingerprint --query "select a, b, c from users where id = 500"

Convertir un archivo lleno de consultas:

pt-fingerprint /ruta/al/archivo.txt

RIESGOS

Percona Toolkit es maduro, probado en el mundo real y bien probado, pero todas las herramientas de bases de datos pueden suponer un riesgo para el sistema y el servidor de bases de datos. Antes de usar esta herramienta, por favor:

  • Lea la documentación de la herramienta
  • Revise los "BUGS" conocidos de la herramienta
  • Pruebe la herramienta en un servidor no productivo
  • Haga una copia de seguridad de su servidor de producción y verifique las copias de seguridad

DESCRIPCIÓN

Una huella dactilar de consulta es la forma abstracta de una consulta, lo que permite agrupar consultas similares. La abstracción de una consulta elimina valores literales, normaliza el espacio en blanco, etc. Por ejemplo, considere estas dos consultas:

SELECT name, password FROM user WHERE id='12823';
select name,   password from user
   where id=5;

Ambas consultas se convertirán en la huella dactilar:

select name, password from user where id=?

Una vez que se conoce la huella dactilar de la consulta, podemos hablar de una consulta como si representara a todas las consultas similares.

La creación de huellas dactilares de consultas admite una gran cantidad de casos especiales, que han demostrado ser necesarios en el mundo real. Por ejemplo, una lista IN con 5 literales es realmente equivalente a una con 4 literales, por lo que las listas de literales se colapsan en una sola. Si desea comprender mejor cómo y por qué se manejan todos estos casos, revise los casos de prueba en el repositorio de Github. Si encuentra algo que no se indexa correctamente, envíe un informe de error con un caso de prueba reproducible. Aquí hay una lista de transformaciones durante la creación de huellas dactilares, que puede no ser exhaustiva:

  • Agrupar todas las consultas SELECT de mysqldump juntas, incluso si son contra tablas diferentes. Lo mismo para todas las consultas de checksum de pt-table-checksum.
  • Acortar sentencias INSERT de varios valores a una sola lista VALUES().
  • Eliminar comentarios.
  • Abstraer las bases de datos en sentencias USE, para que todas las sentencias USE se agrupen juntas.
  • Reemplazar todos los literales, como cadenas entre comillas. Para eficiencia, el código que reemplaza números literales es algo no selectivo, y podría reemplazar algunas cosas como números cuando realmente no lo son. Los literales hexadecimales también se reemplazan. NULL se trata como un literal. Los números incrustados en identificadores también se reemplazan, por lo que las tablas con nombres similares se indexarán con los mismos valores (por ejemplo, users_2009 y users_2010 se indexarán idénticamente).
  • Colapsar todo el espacio en blanco en un solo espacio.
  • Convertir toda la consulta a minúsculas.
  • Reemplazar todos los literales dentro de las listas IN() y VALUES() con un solo marcador de posición, independientemente de la cardinalidad.
  • Colapsar múltiples consultas UNION idénticas en una sola.

OPCIONES

Esta herramienta acepta argumentos de línea de comandos adicionales. Consulte la "SINOPSIS" y la información de uso para obtener detalles.

--config
tipo: Array

Leer esta lista de archivos de configuración separados por comas; si se especifica, esta debe ser la primera opción en la línea de comandos.

--help
Mostrar ayuda y salir.
--match-embedded-numbers
Coincidir números incrustados en palabras y reemplazarlos como valores únicos. Esta opción hace que la herramienta sea más cuidadosa al coincidir números, de modo que las palabras con números, como "catch22", se coincidan y reemplacen como un solo marcador de posición "?". De lo contrario, el patrón de coincidencia de números predeterminado reemplazará "catch22" como "catch?".

Esto es útil si los nombres de bases de datos o tablas contienen números.

--match-md5-checksums
Coincidir sumas de verificación MD5 y reemplazarlas como valores únicos. Esta opción hace que la herramienta sea más cuidadosa al coincidir números, de modo que las sumas de verificación MD5 como "fbc5e685a5d3d45aa1d0347fdb7c4d35" se coincidan y reemplacen como un solo marcador de posición "?". De lo contrario, el patrón de coincidencia de números predeterminado reemplazará "fbc5e685a5d3d45aa1d0347fdb7c4d35" como "fbc?".
--query
tipo: string

La consulta a convertir en una huella dactilar.

--version
Mostrar versión y salir.

ENTORNO

La variable de entorno "PTDEBUG" habilita la salida de depuración detallada a STDERR. Para habilitar la depuración y capturar toda la salida en un archivo, ejecute la herramienta así:

PTDEBUG=1 pt-fingerprint ... > ARCHIVO 2>&1

Tenga cuidado: la salida de depuración es voluminosa y puede generar varios megabytes de salida.

ATENCIÓN

Usar <PTDEBUG> podría exponer contraseñas. Cuando la depuración está habilitada, todos los parámetros de la línea de comandos se muestran en la salida.

REQUISITOS DEL SISTEMA

Necesita Perl, DBI, DBD::mysql y algunos paquetes centrales que deberían estar instalados en cualquier versión razonablemente nueva de Perl.

BUGS

Para obtener una lista de errores conocidos, consulte https://jira.percona.com/projects/PT/issues.

Por favor, informe de errores en https://jira.percona.com/projects/PT. Incluya la siguiente información en su informe de error:

  • Comando completo utilizado para ejecutar la herramienta
  • "--version" de la herramienta
  • Versión de MySQL de todos los servidores involucrados
  • Salida de la herramienta, incluido STDERR
  • Archivos de entrada (registros/volcados/archivos de configuración, etc.)

Si es posible, incluya la salida de depuración ejecutando la herramienta con "PTDEBUG"; consulte "ENTORNO".
