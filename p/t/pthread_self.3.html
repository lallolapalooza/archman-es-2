pthread_self(3) Manual de Funciones de Biblioteca pthread_self(3)

NOMBRE

pthread_self - obtener el ID del hilo que llama

BIBLIOTECA

Biblioteca POSIX threads (libpthread, -lpthread)

SINOPSIS

#include <pthread.h>
pthread_t pthread_self(void);

DESCRIPCIÓN

La función pthread_self() devuelve el ID del hilo que llama. Este es el mismo valor que se devuelve en *thread en la llamada pthread_create(3) que creó este hilo.

VALOR DE RETORNO

Esta función siempre tiene éxito, devolviendo el ID del hilo que llama.

ERRORES

Esta función siempre tiene éxito.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
pthread_self () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001.

NOTAS

POSIX.1 permite una gran libertad a la implementación en la elección del tipo utilizado para representar un ID de hilo; por ejemplo, se permite la representación utilizando un tipo aritmético o una estructura. Por lo tanto, las variables de tipo pthread_t no se pueden comparar de forma portable utilizando el operador de igualdad C (==); utilice pthread_equal(3) en su lugar.

Los identificadores de hilo deben considerarse opacos: cualquier intento de usar un ID de hilo que no sea en llamadas pthreads es no portable y puede dar lugar a resultados no especificados.

Los IDs de hilo solo se garantizan que sean únicos dentro de un proceso. Un ID de hilo puede reutilizarse después de que un hilo terminado haya sido unido, o un hilo desvinculado haya terminado.

El ID de hilo devuelto por pthread_self() no es lo mismo que el ID de hilo del kernel devuelto por una llamada a gettid(2).

VER TAMBIÉN

pthread_create(3), pthread_equal(3), pthreads(7)
