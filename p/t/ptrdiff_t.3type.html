ptrdiff_t(3type) ptrdiff_t(3type)

NOMBRE

ptrdiff_t - recuento de elementos o índice de matriz

BIBLIOTECA

Biblioteca estándar de C (libc)

SINOPSIS

#include <stddef.h>
typedef /* ... */  ptrdiff_t;

DESCRIPCIÓN

Se utiliza para contar elementos o como índice de matriz. Es el resultado de restar dos punteros. Es un tipo de entero con signo capaz de almacenar valores en el rango [PTRDIFF_MIN, PTRDIFF_MAX].

El modificador de longitud para ptrdiff_t para las familias de funciones printf(3) y scanf(3) es t, lo que resulta comúnmente en %td o %ti para imprimir valores ptrdiff_t.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

C89, POSIX.1-2001.
