CPTSVX calcula la solución del sistema de ecuaciones lineales A * X = B para matrices PT

Propósito:

!>
!> CPTSVX utiliza la factorización A = L*D*L**H para calcular la solución
!> de un sistema complejo de ecuaciones lineales A*X = B, donde A es una
!> matriz tridiagonal hermitiana positiva definida de N por N y X y B
!> son matrices de N por NRHS.
!>
!> También se proporcionan cotas de error para la solución y una estimación
!> de la condición.
!>

Descripción:

!>
!> Se realizan los siguientes pasos:
!>
!> 1. Si FACT = 'N', la matriz A se factoriza como A = L*D*L**H, donde L
!>    es una matriz bidiagonal inferior unitaria y D es diagonal. La
!>    factorización también puede considerarse que tiene la forma
!>    A = U**H*D*U.
!>
!> 2. Si el menor principal principal de orden i no es positivo,
!>    entonces la subrutina retorna con INFO = i. De lo contrario, la
!>    forma factorizada de A se utiliza para estimar el número de
!>    condición de la matriz A. Si el recíproco del número de condición
!>    es menor que la precisión de la máquina, se retorna INFO = N+1 como
!>    una advertencia, pero la subrutina aún procede a resolver para X y
!>    calcular las cotas de error como se describe a continuación.
!>
!> 3. El sistema de ecuaciones se resuelve para X utilizando la forma
!>    factorizada de A.
!>
!> 4. Se aplica refinamiento iterativo para mejorar la matriz de solución
!>    calculada y calcular cotas de error y estimaciones de error hacia atrás
!>    para ella.
!>

Parámetros

FACT 
!>          FACT es CHARACTER*1
!>          Especifica si la forma factorizada de la matriz
!>          A se proporciona en la entrada o no.
!>          = 'F':  En la entrada, DF y EF contienen la forma factorizada de A.
!>                  D, E, DF y EF no se modificarán.
!>          = 'N':  La matriz A se copiará en DF y EF y
!>                  se factorizará.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

D

!>          D es un array REAL, de dimensión (N)
!>          Los n elementos diagonales de la matriz tridiagonal A.
!>

E

!>          E es un array COMPLEX, de dimensión (N-1)
!>          Los n-1 elementos subdiagonales de la matriz tridiagonal A.
!>

DF

!>          DF es un array REAL, de dimensión (N)
!>          Si FACT = 'F', entonces DF es un argumento de entrada y en la
!>          entrada contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces DF es un argumento de salida y en la
!>          salida contiene los n elementos diagonales de la matriz diagonal D
!>          de la factorización L*D*L**H de A.
!>

EF

!>          EF es un array COMPLEX, de dimensión (N-1)
!>          Si FACT = 'F', entonces EF es un argumento de entrada y en la
!>          entrada contiene los n-1 elementos subdiagonales del factor
!>          bidiagonal unitario L de la factorización L*D*L**H de A.
!>          Si FACT = 'N', entonces EF es un argumento de salida y en la
!>          salida contiene los n-1 elementos subdiagonales del factor
!>          bidiagonal unitario L de la factorización L*D*L**H de A.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX, de dimensión (LDX,NRHS)
!>          Si INFO = 0 o INFO = N+1, la matriz solución X de N por NRHS.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

RCOND

!>          RCOND es REAL
!>          El número de condición recíproco de la matriz A. Si RCOND
!>          es menor que la precisión de la máquina (en particular, si
!>          RCOND = 0), la matriz es singular con precisión de trabajo.
!>          Esta condición se indica con un código de retorno INFO > 0.
!>

FERR

!>          FERR es un array REAL, de dimensión (NRHS)
!>          La cota de error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j).
!>

BERR

!>          BERR es un array REAL, de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada
!>          vector solución X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga de X(j) una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (N)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, y i es
!>                <= N:  el menor principal principal de orden i de A
!>                       no es positivo, por lo que la factorización no pudo
!>                       completarse y la solución no se ha calculado. Se
!>                       devuelve RCOND = 0.
!>                = N+1: U es no singular, pero RCOND es menor que la
!>                       precisión de la máquina, lo que significa que la
!>                       matriz es singular con precisión de trabajo.
!>                       Sin embargo, la solución y las cotas de error se
!>                       calculan porque hay una serie de situaciones en las
!>                       que la solución calculada puede ser más precisa que
!>                       lo que sugeriría el valor de RCOND.
!>

subroutine sptsvx (character fact, integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( * ) df, real, dimension( * ) ef, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer info)

SPTSVX computes the solution to system of linear equations A * X = B for PT matrices

Purpose:

!>
!> SPTSVX uses the factorization A = L*D*L**T to compute the solution
!> to a real system of linear equations A*X = B, where A is an
!> N-by-N symmetric positive definite tridiagonal matrix and X and B
!> are N-by-NRHS matrices.
!>
!> Error bounds on the solution and a condition estimate are also
!> provided.
!>

Description:

!>
!> The following steps are performed:
!>
!> 1. If FACT = 'N', the matrix A is factored as A = L*D*L**T, where L
!>    is a unit lower bidiagonal matrix and D is diagonal.  The
!>    factorization can also be regarded as having the form
!>    A = U**T*D*U.
!>
!> 2. If the leading principal minor of order i is not positive,
!>    then the routine returns with INFO = i. Otherwise, the factored
!>    form of A is used to estimate the condition number of the matrix
!>    A.  If the reciprocal of the condition number is less than machine
!>    precision, INFO = N+1 is returned as a warning, but the routine
!>    still goes on to solve for X and compute error bounds as
!>    described below.
!>
!> 3. The system of equations is solved for X using the factored form
!>    of A.
!>
!> 4. Iterative refinement is applied to improve the computed solution
!>    matrix and calculate error bounds and backward error estimates
!>    for it.
!>

Parameters

FACT 
!>          FACT is CHARACTER*1
!>          Specifies whether or not the factored form of the matrix
!>          A is supplied on entry.
!>          = 'F':  On entry, DF and EF contain the factored form of A.
!>                  D, E, DF, and EF will not be modified.
!>          = 'N':  The matrix A will be copied to DF and EF and
!>                  factored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>          The n diagonal elements of the tridiagonal matrix A.
!>

E

!>          E is REAL array, dimension (N-1)
!>          The (n-1) subdiagonal elements of the tridiagonal matrix A.
!>

DF

!>          DF is REAL array, dimension (N)
!>          If FACT = 'F', then DF is an input argument and on entry
!>          contains the n diagonal elements of the diagonal matrix D
!>          from the L*D*L**T factorization of A.
!>          If FACT = 'N', then DF is an output argument and on exit
!>          contains the n diagonal elements of the diagonal matrix D
!>          from the L*D*L**T factorization of A.
!>

EF

!>          EF is REAL array, dimension (N-1)
!>          If FACT = 'F', then EF is an input argument and on entry

!>
!> ZPTSVX uses the factorization A = L*D*L**H to compute the solution

NAME

PTSVX - solve the symmetric positive definite tridiagonal system of linear equations A*X = B, and compute an error bound for the computed solution.

SYNOPSIS

Detailed Description

PTSVX solves the symmetric positive definite tridiagonal system of linear equations A*X = B, and compute an error bound for the computed solution.

A tridiagonal matrix A is a matrix that has, apart from the main diagonal, only two non-zero diagonals.

This subroutine is called when the driver routines call routines like ZPTSVX.
