PTHREAD_CONDATTR_GETCLOCK(3P) Manual del programador POSIX PTHREAD_CONDATTR_GETCLOCK(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_condattr_getclock, pthread_condattr_setclock — obtener y establecer el atributo de selección de reloj de una variable de condición

SINOPSIS

#include <pthread.h>
int pthread_condattr_getclock(const pthread_condattr_t *restrict attr,
    clockid_t *restrict clock_id);
int pthread_condattr_setclock(pthread_condattr_t *attr,
    clockid_t clock_id);

DESCRIPCIÓN

La función pthread_condattr_getclock() obtendrá el valor del atributo clock del objeto de atributos referenciado por attr.

La función pthread_condattr_setclock() establecerá el atributo clock en un objeto de atributos inicializado referenciado por attr. Si se llama a pthread_condattr_setclock() con un argumento clock_id que se refiere a un reloj de tiempo de CPU, la llamada fallará.

El atributo clock es el ID del reloj que se utilizará para medir el servicio de tiempo de espera de pthread_cond_timedwait(). El valor predeterminado del atributo clock se referirá al reloj del sistema.

El comportamiento es indefinido si el valor especificado por el argumento attr en pthread_condattr_getclock() o pthread_condattr_setclock() no se refiere a un objeto de atributos de variable de condición inicializado.

VALOR DE RETORNO

Si tiene éxito, la función pthread_condattr_getclock() devolverá cero y almacenará el valor del atributo de reloj de attr en el objeto referenciado por el argumento clock_id. De lo contrario, se devolverá un número de error para indicar el error.

Si tiene éxito, la función pthread_condattr_setclock() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_condattr_setclock() puede fallar si:

EINVAL
El valor especificado por clock_id no se refiere a un reloj conocido, o es un reloj de tiempo de CPU.

Estas funciones no devolverán un código de error de [EINTR].

RACIONALE

Si una implementación detecta que el valor especificado por el argumento attr en pthread_condattr_getclock() o pthread_condattr_setclock() no se refiere a un objeto de atributos de variable de condición inicializado, se recomienda que la función falle e informe un error [EINVAL].
