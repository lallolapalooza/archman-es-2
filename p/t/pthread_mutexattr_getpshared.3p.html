PTHREAD_MUTEXATTR_GETPSHARED(3P) Manual de Programador POSIX PTHREAD_MUTEXATTR_GETPSHARED(3P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_mutexattr_getpshared, pthread_mutexattr_setpshared — obtener y establecer el atributo shared-process

SINOPSIS

#include <pthread.h>
int pthread_mutexattr_getpshared(const pthread_mutexattr_t
    *restrict attr, int *restrict pshared);
int pthread_mutexattr_setpshared(pthread_mutexattr_t *attr,
    int pshared);

DESCRIPCIÓN

La función pthread_mutexattr_getpshared() obtiene el valor del atributo process-shared del objeto de atributos referenciado por attr.

La función pthread_mutexattr_setpshared() establece el atributo process-shared en un objeto de atributos inicializado referenciado por attr.

El atributo process-shared se establece en PTHREAD_PROCESS_SHARED para permitir que un mutex sea operado por cualquier hilo que tenga acceso a la memoria donde se asigna el mutex, incluso si el mutex se asigna en memoria que es compartida por múltiples procesos. Ver Sección 2.9.9, Copias de Objetos de Sincronización y Mapeos Alternativos para requisitos adicionales. El valor predeterminado del atributo será PTHREAD_PROCESS_PRIVATE.

El comportamiento no está definido si el valor especificado por el argumento attr a pthread_mutexattr_getpshared() o pthread_mutexattr_setpshared() no se refiere a un objeto de atributos de mutex inicializado.

VALOR DE RETORNO

Tras la finalización exitosa, pthread_mutexattr_setpshared() devolverá cero; de lo contrario, se devolverá un número de error para indicar el error.

Tras la finalización exitosa, pthread_mutexattr_getpshared() devolverá cero y almacenará el valor del atributo process-shared de attr en el objeto referenciado por el parámetro pshared. De lo contrario, se devolverá un número de error para indicar el error.

ERRORES

La función pthread_mutexattr_setpshared() puede fallar si:

EINVAL
El nuevo valor especificado para el atributo está fuera del rango de valores legales para dicho atributo.

Estas funciones no devolverán un código de error de [EINTR].

JUSTIFICACIÓN

Si una implementación detecta que el valor especificado por el argumento attr a pthread_mutexattr_getpshared() o pthread_mutexattr_setpshared() no se refiere a un objeto de atributos de mutex inicializado, se recomienda que la función falle e informe de un error [EINVAL].
