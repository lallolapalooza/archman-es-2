PROLOG

Esta página del manual es parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pthread_mutex_setprioceiling — cambiar el techo de prioridad de un mutex (HILOS EN TIEMPO REAL)

SINAPSIS

#include <pthread.h>
int pthread_mutex_setprioceiling(pthread_mutex_t *restrict mutex,
    int prioceiling, int *restrict old_ceiling);

DESCRIPCIÓN

Consulte pthread_mutex_getprioceiling().
