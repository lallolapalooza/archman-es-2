PMDAHACLUSTER(1) Manual de comandos generales PMDAHACLUSTER(1)

NOMBRE

pmdahacluster - PMDA de clúster de alta disponibilidad

SINOPSIS

$PCP_PMDAS_DIR/hacluster/pmdahacluster [-D debug]

DESCRIPCIÓN

pmdahacluster es capaz de recopilar información métrica para permitir la monitorización de clústeres HA basados en Pacemaker a través de Performance Co-Pilot.

El PMDA recopila sus datos métricos de los siguientes componentes que conforman un clúster HA basado en Pacemaker: Pacemaker, Corosync, SBD, DRBD.

Para obtener información más detallada sobre las métricas disponibles, consulte el archivo pmns y el archivo de ayuda incluidos con el PMDA.

INSTALACIÓN

Instale el PMDA de HA Cluster utilizando el script de Instalación como root:

# cd $PCP_PMDAS_DIR/hacluster
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/hacluster
# ./Remove

pmdahacluster es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMDAS_DIR/hacluster/help
archivo de texto de ayuda predeterminado para las métricas del clúster HA
$PCP_PMDAS_DIR/hacluster/Install
script de instalación para el agente pmdahacluster
$PCP_PMDAS_DIR/hacluster/Remove
script para deshacer la instalación del agente pmdahacluster
$PCP_LOG_DIR/pmcd/hacluster.log
archivo de registro predeterminado para mensajes de error de pmdahacluster

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede ser utilizada para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1) y pmstore(1).
