PMLOADNAMESPACE(3) Manual de funciones de biblioteca PMLOADNAMESPACE(3)

NOMBRE

pmLoadNameSpace - cargar un PMNS local para una aplicación

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmLoadNameSpace(const char *filename);

cc ... -lpcp

DESCRIPCIÓN

Si la aplicación desea forzar el uso de un Espacio de Nombres de Métricas de Rendimiento (PMNS) local en lugar de un PMNS distribuido, debe cargar el PMNS usando pmLoadNameSpace o pmLoadASCIINameSpace(3). Si la aplicación va a utilizar un PMNS distribuido, NO debe realizar una llamada para cargar el PMNS explícitamente.

La mayoría de las aplicaciones que utilizan un contexto de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) (de cualquier tipo, como PM_CONTEXT_HOST o PM_CONTEXT_ARCHIVE o PM_CONTEXT_LOCAL) no deberían necesitar llamar a pmLoadNameSpace.

El argumento filename designa el PMNS de interés. Para aplicaciones que no requieren un PMNS adaptado, se puede usar el valor especial PM_NS_DEFAULT para filename, para forzar la carga del PMNS local por defecto.

El PMNS local por defecto se encuentra en el archivo $PCP_VAR_DIR/pmns/root a menos que la variable de entorno PMNS_DEFAULT esté configurada, en cuyo caso el valor se asume como la ruta al archivo que contiene el PMNS local por defecto.

Externamente, un PMNS se almacena en formato ASCII como se describe en PMNS(5). Sin embargo, tenga en cuenta que pmLoadNameSpace asume que filename no contiene comentarios de estilo C, directivas de preprocesador o macros; si este no es el caso, se debe usar pmLoadASCIINameSpace(3) en su lugar.

A partir de la versión 3.10.3 de PCP, por defecto, se permiten múltiples nombres en el PMNS asociados a un único Identificador de Métricas de Rendimiento (PMID) y esto es permitido incondicionalmente por pmLoadNameSpace. pmLoadASCIINameSpace(3) proporciona una interfaz alternativa con control definido por el usuario sobre el manejo de nombres duplicados para el mismo PMID en el PMNS.

pmLoadNameSpace devuelve cero si tiene éxito.

DIAGNÓSTICOS

Los errores de sintaxis y otros errores al analizar el PMNS se informan en stderr con un mensaje de la forma ``Error Parsing ASCII PMNS: ...''.

PM_ERR_DUPPMNS

Es un error intentar cargar más de un PMNS, o llamar a pmLoadNameSpace y/o pmLoadASCIINameSpace(3) más de una vez.

PM_ERR_PMNS

Error de sintaxis en el archivo PMNS.

ARCHIVOS

$PCP_VAR_DIR/pmns/root
el PMNS local por defecto, cuando la variable de entorno PMNS_DEFAULT no está configurada

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores de estas variables se pueden obtener programáticamente utilizando la función pmGetConfig(3).

VER TAMBIÉN

PMAPI(3), pmGetConfig(3), pmLoadASCIINameSpace(3), pmTrimNameSpace(3), pcp.conf(5), pcp.env(5) y PMNS(5).
