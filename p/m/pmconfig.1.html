PMCONFIG(1) Manual de comandos generales PMCONFIG(1)

NOMBRE

pmconfig - Parámetros de configuración de Performance Co-Pilot

SINOPSIS

$PCP_BINADM_DIR/pmconfig [-alLs?] [nombre ...]

DESCRIPCIÓN

pmconfig muestra los valores de algunos o todos los parámetros de configuración de la instalación local del conjunto de herramientas Performance Co-Pilot.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a, --all
Informa todos los parámetros de configuración en el formato predeterminado.
-l, --list
Sinónimo de la opción -a, informa el mismo formato (predeterminado).
-L, --library
Esta opción cambia el modo de informe predeterminado para que se informen las capacidades de la biblioteca de PCP, en lugar del entorno de PCP.
-s, --shell
Un formato de salida adecuado para ser incluido en scripts de shell, que asegura que la información de configuración esté entre comillas y precedida por una declaración de exportación. Cuando no se informan las capacidades de la biblioteca, este modo producirá una declaración que no anula una configuración existente en el entorno para las variables de configuración de PCP.
-?, --help
Muestra el mensaje de uso y sale.

En el modo de operación predeterminado, pmconfig se usa a menudo junto con la variable de entorno $PCP_DIR para configurar scripts que se ejecutan bajo el sistema operativo Windows, donde la jerarquía del sistema de archivos difiere considerablemente de la de los sistemas operativos basados en Linux/UNIX.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

pmGetConfig(3), pcp.conf(5) y pcp.env(5).
