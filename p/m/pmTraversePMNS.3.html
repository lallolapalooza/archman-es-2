PMTRAVERSEPMNS(3) Manual de funciones de biblioteca PMTRAVERSEPMNS(3)

NOMBRE

pmTraversePMNS, pmTraversePMNS_r - recorrer el espacio de nombres de métricas de rendimiento

SINOPSIS C

#include <pcp/pmapi.h>

int pmTraversePMNS(const char *name,
void (*dometric)(const char *));
int pmTraversePMNS_r(const char *name,
void (*dometric_r)(const char *, void *), void *closure);

cc ... -lpcp

DESCRIPCIÓN

La rutina pmTraversePMNS puede usarse para realizar un recorrido en profundidad del espacio de nombres de métricas de rendimiento (PMNS).

El recorrido comienza en el nodo identificado por name; si name es una cadena vacía (es decir, ""), el recorrido comienza en la raíz del PMNS. Normalmente name sería la ruta de acceso a un nodo no terminal en el PMNS.

Para cada nodo terminal (es decir, métrica de rendimiento) encontrado en el recorrido, se llama a la rutina proporcionada por el usuario dometric con la ruta completa de esa métrica en el PMNS como único argumento. Este argumento termina en nulo y se construye a partir de un búfer que es administrado internamente por pmTraversePMNS. En consecuencia, el valor solo es válido durante la llamada a dometric; si se necesita conservar la ruta de acceso, debe copiarse usando strdup(3) antes de devolver desde dometric.

La rutina pmTraversePMNS_r realiza la misma función, excepto que el método de devolución de llamada func_r tiene un parámetro adicional que será closure de la llamada inicial a pmTraversePMNS_r. El parámetro adicional a pmTraversePMNS_r y el método de devolución de llamada permiten al llamador pasar contexto a través de pmTraversePMNS_r y hacia el método de devolución de llamada func_r, lo que hace que el servicio sea más útil para aplicaciones multihilo donde los datos privados del hilo se pueden acceder en el método de devolución de llamada a través del argumento closure.

En caso de éxito, pmTraversePMNS y pmTraversePMNS_r devuelven el número de nodos terminales encontrados en el recorrido, que será uno (1) si name es un nodo terminal, una métrica derivada o un nodo no terminal con un solo hijo. Si name es un nodo no terminal, el valor devuelto será cero o mayor (cero se devuelve en el caso especial en que name es un nodo raíz dinámico que actualmente no tiene hijos). En todos los casos, las métricas derivadas presentes en el subárbol PMNS debajo de name se cuentan como nodos terminales. Si ocurre un error, pmTraversePMNS y pmTraversePMNS_r devolverán un código de error negativo, como se describe en la sección DIAGNÓSTICOS.

DIAGNÓSTICOS

PM_ERR_NOPMNS
Fallo al acceder a un PMNS para la operación. Tenga en cuenta que si la aplicación no ha llamado previamente a pmLoadNameSpace(3) y desea utilizar el PMNS distribuido, entonces una llamada a pmTraversePMNS debe realizarse dentro de un contexto actual.
PM_ERR_NAME
La ruta de acceso inicial name no es válida en el PMNS actual.
PM_ERR_*
Otros diagnósticos son para fallos de protocolo al acceder al PMNS distribuido.

VER TAMBIÉN

PMAPI(3) y pmGetChildren(3).
