PMDANAMED(1) Performance Co-Pilot PMDANAMED(1)

NOMBRE

pmdanamed - PMDA de BIND (named)

DESCRIPCIÓN

pmdanamed es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores de métricas del servidor DNS BIND. Se pueden encontrar más detalles sobre BIND en http://isc.org/.

INSTALACIÓN

Si desea acceso a los nombres y valores de las métricas de rendimiento de named, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/named
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/named
# ./Remove

pmdanamed es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts de Instalación y Eliminación notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

/var/named/data/named_stats.txt
archivo de estadísticas que muestra los valores exportados por named
/var/named/chroot/var/named/data/named_stats.txt
variante chroot del archivo de estadísticas que muestra los valores exportados por named
$PCP_PMDAS_DIR/named/Install
script de instalación para el agente pmdanamed
$PCP_PMDAS_DIR/named/Remove
script para deshacer la instalación del agente pmdanamed
$PCP_LOG_DIR/pmcd/named.log
archivo de registro predeterminado para mensajes de error de pmdanamed

VER TAMBIÉN

pmcd(1), named.conf(5), named(8).
