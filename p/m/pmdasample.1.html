PMDASAMPLE(1) Manual de comandos generales PMDASAMPLE(1)

NOMBRE

pmdasample - agente de dominio de métricas de rendimiento de muestra (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/pmdasample [-D debug] [-d dominio] [-i puerto] [-l logfile] [-p] [-u socket] [-U username]

DESCRIPCIÓN

pmdasample es un agente de dominio de métricas de rendimiento (PMDA) de ejemplo que exporta una variedad de métricas de rendimiento sintéticas.

Este PMDA se desarrolló como parte de las pruebas de aseguramiento de calidad para el producto PCP, pero tiene otros usos, especialmente en el desarrollo de nuevos clientes PCP.

Las métricas exportadas por el PMDA de ejemplo cubren todo el rango de tipos de datos, semánticas de datos, cardinalidad de valores, estabilidad del dominio de instancias y condiciones de error que se encuentran en los PMDA reales.

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdasample:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento dominio especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-i
Espera que PMCD se conecte a pmdasample en el puerto TCP/IP especificado. puerto puede ser un número de puerto o un nombre de puerto.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado sample.log en el directorio actual de pmcd(1) cuando se inicia pmdasample, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se envía al error estándar en su lugar.
-p
Espera que PMCD cree una tubería y la conexión a pmdasample sea a través de la entrada y salida estándar. Este es el modo de conexión predeterminado.
-u
Espera que PMCD se conecte a pmdasample en el socket de dominio Unix llamado socket.
-U
Cuenta de usuario bajo la cual ejecutar el agente. El valor predeterminado es la cuenta no privilegiada "pcp" en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta superusuario ("root") por defecto.

Se puede especificar como máximo una de las opciones -i, -p y -u.

INSTALACIÓN

Si desea acceder a los nombres, textos de ayuda y valores para las métricas de rendimiento de ejemplo, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sample
# ./Install

Tenga en cuenta que el script de instalación también instala la versión DSO del PMDA de ejemplo, por lo que en realidad hay dos PMDA instalados y dos conjuntos de métricas de rendimiento, a saber, sample.* y sampledso.*.

Si desea deshacer la instalación (y eliminar ambos PMDA), haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sample
# ./Remove

pmdasample es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdasample
$PCP_PMDAS_DIR/sample/help
archivo de texto de ayuda predeterminado para las métricas de ejemplo
$PCP_PMDAS_DIR/sample/Install
script de instalación para el agente pmdasample
$PCP_PMDAS_DIR/sample/Remove
script para deshacer la instalación del agente pmdasample
$PCP_LOG_DIR/pmcd/sample.log
archivo de registro predeterminado para mensajes de error y otra información de pmdasample

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdasample son las siguientes:

Opción Descripción
appl0 diagnósticos detallados para dominios de instancias dinámicos y mapeo de métricas
