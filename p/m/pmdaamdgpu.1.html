PMDAAMDGPU(1) Manual de comandos generales PMDAAMDGPU(1)

NOMBRE

pmdaamdgpu - Agente de dominio de métricas de GPU AMD (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/amdgpu/pmdaamdgpu [-D debug] [-d dominio] [-l logfile] [-t intervalo]

DESCRIPCIÓN

pmdaamdgpu es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen las métricas disponibles en las tarjetas GPU de AMD a través de la biblioteca DRM.

El PMDA amdgpu exporta métricas que miden la actividad de la GPU, utilización de memoria, temperatura, etc. en GPUs AMD GCN 1.2+.

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdaamdgpu:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y coherente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado amdgpu.log en el directorio actual de pmcd(1) cuando se inicia pmdaamdgpu, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.
-t
Habilita y establece un intervalo de muestreo para la actualización automática de los valores métricos. La funcionalidad está deshabilitada por defecto, sin embargo, esta opción permite especificar un intervalo de tiempo en el que se muestrean todos los valores: esto tiene el efecto de actualizar constantemente las métricas acumulativas, con el objetivo de ayudar a herramientas cliente como pcp-atop(1) y pmlogger(1) a observar cambios de estado de la GPU y del proceso en el tiempo sub-muestreo. Típicamente, estas herramientas tienen intervalos de muestreo más largos y, por lo tanto, pueden "perderse" la actividad que ocurre durante su intervalo de muestreo.

INSTALACIÓN

El PMDA amdgpu no está instalado y disponible por defecto. Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/amdgpu
# ./Remove

Si desea establecer acceso a los nombres, textos de ayuda y valores para las métricas de rendimiento de la GPU AMD una vez más, después de la eliminación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/amdgpu
# ./Install

pmdaamdgpu es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdaamdgpu
$PCP_PMDAS_DIR/amdgpu/help
archivo de texto de ayuda por defecto para las métricas de amdgpu
$PCP_PMDAS_DIR/amdgpu/Install
script de instalación para el agente pmdaamdgpu
$PCP_PMDAS_DIR/amdgpu/Remove
script para deshacer la instalación del pmdaamdgpu
$PCP_LOG_DIR/pmcd/amdgpu.log
archivo de registro por defecto para mensajes de error y otra información de pmdaamdgpu

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para configurar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdaamdgpu son las siguientes:

Opción Descripción
appl0 interacción con pmcd(1)
appl2 traza de llamadas a select(2)
