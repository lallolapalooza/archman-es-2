PMNAMEINDOMARCHIVE(3) Manual de Funciones de Librería PMNAMEINDOMARCHIVE(3)

NOMBRE

pmNameInDomArchive - traduce un identificador de instancia a un nombre de instancia

SINOPSIS C

#include <pcp/pmapi.h>

int pmNameInDomArchive(pmInDom indom,
int inst, char **name);

cc ... -lpcp

DESCRIPCIÓN

Siempre que el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) esté asociado a un conjunto de archivos, pmNameInDomArchive examinará la unión de todos los metadatos del dominio de instancias para el dominio de instancias indom, localizará la primera instancia con el identificador de instancia interno dado por inst y devolverá la identificación externa completa de la instancia a través de name.

Esta rutina es una versión especializada de la rutina PMAPI más general pmNameInDom.

El valor del dominio de instancias indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

El espacio para el valor de name será asignado en pmNameInDomArchive con malloc(3), y es responsabilidad del llamador liberar (free(3)) el espacio cuando ya no sea necesario.

pmNameInDomArchive devuelve cero en caso de éxito.

DIAGNÓSTICOS

PM_ERR_NOTARCHIVE
el contexto PMAPI actual no está asociado a un conjunto de archivos
PM_ERR_INDOM_LOG
indom no es un identificador de dominio de instancias definido para el conjunto de archivos
PM_ERR_INST_LOG
el identificador de instancia inst no es conocido para el dominio de instancias indom en el conjunto de archivos

VER TAMBIÉN

PMAPI(3), pmGetConfig(3), pmGetInDomArchive(3), pmLookupInDomArchive(3), pmNameInDom(3), pcp.conf(5) y pcp.env(5).
