pmGetVersion(3)

Paquete: pcp

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMGETVERSION(3) Manual de funciones de biblioteca PMGETVERSION(3)

NOMBRE

pmGetVersion - obtener el número de versión de PCP instalado

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetVersion(void);

cc ... -lpcp

DESCRIPCIÓN

pmGetVersion devuelve una codificación binaria del número de versión de PCP instalado localmente.

Esto puede usarse junto con las macros relacionadas PM_VERSION(a,b,c) y PM_VERSION_CURRENT que generan números de versión de PCP en el mismo formato. Consulte el ejemplo a continuación.

La codificación utiliza un byte para cada una de las partes del número de versión del paquete PCP instalado, es decir, el número mayor, el número menor y el número de revisión. Por lo tanto, la versión de PCP 3.10.5 se codifica como 0x30a05.

El formato de cadena del número de versión del paquete PCP instalado también está disponible en pmGetConfig con el argumento PCP_VERSION.

pmGetVersion se introdujo en PCP 3.10.5.

EJEMPLO

El siguiente fragmento de C demuestra el uso de las macros en tiempo de compilación y la función en tiempo de ejecución pmGetVersion para una aplicación que no debe compilarse para versiones de PCP anteriores a 3.10.5, pero después de eso hay dos implementaciones alternativas con una variante más nueva (más rápida, mejor, más pequeña) del servicio XYZ que solo estará disponible en PCP 4.0.0.

#include <pcp/pmapi.h>
#ifdef PM_VERSION_CURRENT
#if PM_VERSION_CURRENT < PM_VERSION(3,10,5)
    /* no existe pmGetVersion() antes de PCP 3.10.5 */
    printf("Versión de PCP 0x%x demasiado antigua\n", PM_VERSION_CURRENT);
#endif
    version = pmGetVersion();
    if (version >= PM_VERSION(4,0,0) {
	/* V2 del servicio XYZ introducida en PCP 4.0.0 */
	printf("Usando V2 del servicio XYZ\n")
	...
    }
    else {
	printf("Usando V1 del servicio XYZ\n")
	...
    }
#else
    {
	char *ver = pmGetConfig("PCP_VERSION");
	/* la única opción es extraer el número de versión de la cadena devuelta */
	...
    }
#endif

VER TAMBIÉN

PMAPI(3) y pmGetConfig(3).
