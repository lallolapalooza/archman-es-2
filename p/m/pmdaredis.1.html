PMDAREDIS(1) Manual de Comandos Generales PMDAREDIS(1)

NOMBRE

pmdaredis - agente de dominio de métricas de rendimiento de Redis (PMDA)

DESCRIPCIÓN

Este PMDA extrae datos de rendimiento enviando el comando INFO a un servidor Redis (redis.io), que incluye:

•
Información general sobre el servidor Redis
•
Conexiones de clientes
•
Consumo de memoria
•
Estadísticas de persistencia
•
Estadísticas de replicación
•
Estadísticas de consumo de CPU
•
Estadísticas de comandos de Redis
•
Estadísticas del clúster de Redis
•
Estadísticas relacionadas con la base de datos

El nombre de host (localhost), el puerto (6379 por defecto) y otra información de configuración deben especificarse en el archivo $PCP_PMDAS_DIR/redis/redis.conf.

# cd $PCP_PMDAS_DIR/redis
# [ editar redis.conf ]
  host=localhost.localdomain:6379

Una vez configurado, puede acceder a los nombres y valores de las métricas de rendimiento de Redis haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/redis
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/redis
# ./Remove

pmdaredis es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se desinstala.

ARCHIVOS

$PCP_PMDAS_DIR/redis/redis.conf
archivo de configuración obligatorio que lista las instancias de redis monitoreadas
$PCP_PMDAS_DIR/redis/Install
script de instalación para el agente pmdaredis
$PCP_PMDAS_DIR/redis/Remove
script de desinstalación para el agente pmdaredis
$PCP_LOG_DIR/pmcd/redis.log
archivo de registro predeterminado para mensajes de error de pmdaredis

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
