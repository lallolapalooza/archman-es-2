PMIPUTMARK(3) Manual de funciones de la biblioteca PMIPUTMARK(3)

NOMBRE

pmiPutMark - escribe un registro <mark> en un archivo PCP

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutMark(void);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiPutMark();

DESCRIPCIÓN

Como parte de la API de Importación de Registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiPutMark escribe un registro <mark> en el archivo de salida PCP actual. Esto es necesario cuando hay una discontinuidad temporal entre la fuente de entrada actual y la siguiente fuente de entrada, si la hay, y debe llamarse después de la última llamada a pmiWrite(3) para la entrada actual. Si no hay más entradas que procesar o no hay brecha temporal entre fuentes, entonces el registro <mark> no es necesario.

El registro <mark> se utiliza para indicar una brecha temporal, de modo que al reproducir el archivo PCP de salida, la interpolación de valores métricos no se realice entre la última marca de tiempo de la fuente de entrada actual y la primera marca de tiempo de la siguiente fuente de entrada, es decir, a través del registro <mark>.

DIAGNÓSTICO

pmiPutMark devuelve cero en caso de éxito y un valor negativo en caso contrario, que puede convertirse en un mensaje de error llamando a pmiErrStr(3).
