NOMBRE

pmcd_wait - esperar a que PMCD acepte conexiones de clientes

SINOPSIS

$PCP_BINADM_DIR/pmcd_wait [-v?] [-D debug] [-h host] [-t timeout]

DESCRIPCIÓN

pmcd_wait espera a que el Demonio Recolector de Métricas de Rendimiento (PMCD) esté en ejecución y aceptando conexiones de clientes.

A menos que se dirija a otro host con la opción -h, pmcd_wait intentará contactar pmcd(1) en el host local.

pmcd_wait caducará y abandonará el intento de conexión a pmcd después de 60 segundos. Este intervalo de tiempo de espera predeterminado puede cambiarse usando la opción -t, donde el argumento intervalo sigue la sintaxis descrita en PCPIntro(1) y en su forma más simple puede ser un entero sin signo (las unidades implícitas en este caso son segundos).

Al conectarse exitosamente a pmcd se devuelve un estado de salida de cero.

Si ocurre un error o una caducidad, se devuelve un estado de salida distinto de cero, como se describe a continuación.

OPCIONES

Las opciones disponibles en la línea de comandos son:

-h host, --host=host
Conecta pmcd(1) en host, en lugar del que está en el localhost predeterminado.
-t tiempo_de_espera, --interval=tiempo_de_espera
Caduca después de tiempo_de_espera segundos si no se conecta. El valor de tiempo de espera predeterminado es 60 segundos.
-v, --verbose
Esta opción activa el modo verboso. Con el modo verboso desactivado (que es el predeterminado), no se generará ninguna salida. Con el modo verboso activado, se mostrarán mensajes de error en stderr.
-?, --help
Muestra el mensaje de uso y sale.

DIAGNÓSTICOS

Los mensajes de error se mostrarán en stderr solo si el modo verboso está activado.

Los siguientes códigos de estado de salida se devuelven:

0
pmcd_wait pudo conectarse exitosamente a pmcd dentro del período de tiempo de espera.
1
Ocurrió un error de uso, usa -v para más detalles.
2
No se realizó ninguna conexión en el intervalo de tiempo de espera. Esto ocurrirá si pmcd se está ejecutando pero tarda demasiado en completar la conexión del cliente, o si pmcd no se está ejecutando y todos los intentos de conexión en el intervalo de tiempo de espera fallaron con el error ECONNREFUSED.
3
Ocurrió un error de UNIX, usa -v para más detalles.
4
Ocurrió un error de PCP, usa -v para más detalles.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; usa pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1), pcp.conf(5) y pcp.env(5).
