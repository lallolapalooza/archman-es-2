NOMBRE

pmdapostgresql - PMDA de la base de datos PostgreSQL

DESCRIPCIÓN

pmdapostgresql es un Agente de Dominio de Métricas de Rendimiento (PMDA) de Performance Co-Pilot (PCP) que extrae datos de rendimiento en vivo de un servidor de base de datos PostgreSQL en ejecución.

Muchas de las estadísticas disponibles de un servidor PostgreSQL pueden no estar habilitadas por defecto. Consulte la documentación en línea https://www.postgresql.org/docs/current/static/monitoring-stats.html que describe cada uno de los parámetros disponibles relacionados con la recopilación de estadísticas y cómo habilitarlos.

CONFIGURACIÓN

pmdapostgresql lee un archivo de configuración obligatorio estilo ini:

$PCP_PMDAS_DIR/postgresql/postgresql.conf

Este archivo actualmente contiene solo una sección [authentication] que especifica los valores para las siguientes configuraciones (sus valores predeterminados se muestran entre paréntesis):

host (local)
Nombre del host al que conectarse.
port (5432)
Número de puerto a usar.
dbname (postgres)
Nombre de la base de datos.
username (postgres)
Nombre de usuario con el que ejecutar y con el que conectarse a la base de datos.
password (password)
Contraseña para conectarse a la base de datos.
osuser (unset)
Usuario del sistema operativo con el que se ejecuta el PMDA.

Los valores predeterminados (como se indicó anteriormente) resultarán en que el PMDA se ejecute como el usuario actual, utilizando una conexión de socket de dominio UNIX al servidor PostgreSQL en localhost.

Si osuser no se especifica en el archivo de configuración, el PMDA se ejecutará como el usuario actual. Una especificación de host de local usará un socket de dominio UNIX, que utiliza autenticación peer, consulte los comentarios en el archivo pg_hba.conf. En este caso, la configuración de osuser probablemente debería establecerse en postgres.

Generalmente no es necesario modificar el archivo de configuración predeterminado para monitorear la instancia local del servidor PostgreSQL con una configuración de servidor predeterminada. Tenga en cuenta que el número de puerto es necesario incluso para una conexión de dominio UNIX porque es usado como nombre de archivo de socket por el servidor.

INSTALACIÓN

Para instalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/postgresql
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/postgresql
# ./Remove

pmdapostgresql es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

pmdapostgresql intentará reconectarse automáticamente al servidor PostgreSQL si su conexión se pierde, por ejemplo, si se reinicia el servicio PostgreSQL.

VERSIÓNES SOPORTADAS

Esta versión de pmdapostgresql ha sido probada y verificada con la versión del servidor PostgreSQL 10.2 y anteriores. Las versiones posteriores probablemente también funcionarán correctamente porque el PMDA sondea las diversas tablas de rendimiento al inicio para determinar el orden de las columnas. También tolera tablas y/o columnas faltantes o renombradas.

ARCHIVOS

$PCP_PMDAS_DIR/postgresql/pmdapostgresql.conf
archivo de configuración para el agente pmdapostgresql
$PCP_PMDAS_DIR/postgresql/Install
script de instalación para el agente pmdapostgresql
$PCP_PMDAS_DIR/postgresql/Remove
script para deshacer la instalación del agente pmdapostgresql
$PCP_LOG_DIR/pmcd/postgresql.log
archivo de registro predeterminado para mensajes del agente pmdapostgresql

Tenga en cuenta que el valor habitual/predeterminado para $PCP_PMDAS_DIR es /var/lib/pcp/pmdas y el predeterminado para $PCP_LOG_DIR es /var/log/pcp, pero estas configuraciones dependen de la plataforma.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1) y https://www.postgresql.org/docs/current/static/monitoring-stats.html.
