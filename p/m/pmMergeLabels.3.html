PMMERGELABELS(3) Manual de funciones de biblioteca PMMERGELABELS(3)

NOMBRE

pmMergeLabels, pmMergeLabelSets - fusionar conjuntos de etiquetas de métricas de rendimiento

C SINOPSIS

#include <pcp/pmapi.h>

int pmMergeLabels(char **sets,
int nsets, char *buffer, int length);

int pmMergeLabelSets(pmLabelSet **sets,
int nsets, char *buffer, int length, int (*filter) (const pmLabel *, const char *, void *), void *arg);

cc ... -lpcp

PYTHON SINOPSIS

from pcp import pmapi

buffer = pmapi.pmContext().pmMergeLabels(sets)
buffer = pmapi.pmContext().pmMergeLabelSets(sets, filter)

DESCRIPCIÓN

pmMergeLabels toma múltiples conjuntos (nsets) de etiquetas de métricas de rendimiento y los fusiona en un único buffer de resultado de length bytes. Tanto los sets de entrada como el buffer de resultado son pares nombre:valor en el formato "JSONB" descrito en pmLookupLabels(3).

La interfaz pmMergeLabelSets cumple el mismo propósito, pero permite fusionar sets de etiquetas indexados. El formato de la estructura de datos pmLabelSet se describe en detalle en pmLookupLabels(3).

Aunque los nombres pueden repetirse en los sets de etiquetas proporcionados, no se permiten nombres duplicados en el buffer final. Cualquier nombre de etiqueta que aparezca en más de uno de los sets de etiquetas de entrada se reduce a uno solo usando las reglas descritas en la sección "PRECEDENCIA" de pmLookupLabels. La posición de cada elemento en el array sets es significativa en términos de las reglas de precedencia: las posiciones anteriores se consideran de menor precedencia que las posteriores.

Los valores deben ser entidades JSON primitivas (p. ej., números, cadenas), arrays unidimensionales o mapas (es decir, arrays asociativos simples).

Además de utilizar sets de etiquetas indexados, la interfaz pmMergeLabelSets proporciona una función de callback filter opcional. Si no es NULL, esta función se llamará para cada etiqueta que se añadiría al buffer de salida, permitiendo un control más detallado sobre el conjunto fusionado final. Este mecanismo se puede usar para *filtrar* etiquetas individuales basándose en su nombre, valor y/o indicadores. Si la función filter devuelve cero (falso), la etiqueta dada se filtra del conjunto resultante. Cualquier valor de retorno distinto de cero indica que la etiqueta debe incluirse en el buffer.

EJEMPLO PYTHON

import sys
import json
from pcp import pmapi
import cpmapi as c_api
def merge_callback(label, jsondata, data=None):
    d = json.loads(jsondata)
    labelsD.update(d)
    return 0
ctx = pmapi.pmContext()
for metric in sys.argv[1:]:
    pmid = ctx.pmLookupName(metric)[0]
    lset = ctx.pmLookupLabels(pmid)
    labelsD = {}
    ctx.pmMergeLabelSets(lset, merge_callback)
    print("== %s ===" % metric)
    for n,v in labelsD.items():
        print("    %s = %s" % (n,v))
    ctx.pmFreeLabelSets(lset)

DIAGNÓSTICO

En caso de éxito, tanto pmMergeLabels como pmMergeLabelSets devuelven el número de bytes escritos en el buffer proporcionado.

El fallo al analizar las cadenas de entrada, el fallo al asignar memoria o cualquier inconsistencia interna encontrada resultarán en un código de retorno negativo.
