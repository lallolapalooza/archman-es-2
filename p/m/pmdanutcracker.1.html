PMDANUTCRACKER(1) Manual de comandos generales PMDANUTCRACKER(1)

NOMBRE

pmdanutcracker - agente de dominio de métricas de NutCracker (PMDA)

DESCRIPCIÓN

Este PMDA extrae datos de rendimiento de NutCracker (o TwemProxy), un proxy rápido y ligero para los protocolos memcached y Redis.

INSTALACIÓN

Configure para exportar estadísticas a través de su interfaz de estadísticas (consulte la opción --stats-port del servidor nutcracker). La configuración correspondiente debe reflejarse en el archivo $PCP_PMDAS_DIR/nutcracker/nutcracker.conf.

# cd $PCP_PMDAS_DIR/nutcracker
# [ editar nutcracker.conf ]

Una vez configurado, puede acceder a los nombres y valores de las métricas de rendimiento de nutcracker haciéndolo como root:

# cd $PCP_PMDAS_DIR/nutcracker
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/nutcracker
# ./Remove

pmdanutcracker es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/nutcracker/nutcracker.conf
archivo de configuración obligatorio que enumera las instancias de memcache o Redis monitoreadas
$PCP_PMDAS_DIR/nutcracker/Install
script de instalación para el agente pmdanutcracker
$PCP_PMDAS_DIR/nutcracker/Remove
script para deshacer la instalación del agente pmdanutcracker
$PCP_LOG_DIR/pmcd/nutcracker.log
archivo de registro predeterminado para mensajes de error de pmdanutcracker

AMBIENTE PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmdamemcache(1) y pmdaredis(1).
