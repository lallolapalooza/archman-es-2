PMDALIBVIRT(1) Manual de Comandos Generales PMDALIBVIRT(1)

NOMBRE

pmdalibvirt - PMDA de libvirt

DESCRIPCIÓN

pmdalibvirt es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae datos de rendimiento en vivo del hipervisor libvirt y dominios (VMs).

Consulte la documentación de libvirt para una descripción detallada de cada métrica.

INSTALACIÓN

pmdalibvirt lee un archivo de configuración opcional en estilo ini

•
$PCP_PMDAS_DIR/libvirt/libvirt.conf

Este archivo puede contener en su sección [pmda] valores de reemplazo para las siguientes opciones del PMDA:

  • user
  • uri
  • backing

Por defecto, root, qemu:///system y False se usan como valores para estas opciones, respectivamente.

La opción backing se puede usar para expandir la información del dispositivo de bloque para cubrir las cadenas de respaldo con versiones recientes de libvirt.

La opción old API se puede usar en entornos donde las adiciones recientes de la API de libvirt no están disponibles (por ejemplo, RHEL 6 / libvirt-0.10.2) para proporcionar algunas de las métricas disponibles con la API más nueva. Independientemente de la versión de la API, no se necesita ningún agente invitado para las métricas.

Tenga en cuenta que el uso de un usuario que no sea root normalmente también requiere configuración del lado de libvirt; consulte la documentación de libvirt para obtener más detalles sobre esto.

Una vez que la configuración necesaria esté lista, puede probar la conexión e instalar el PMDA para habilitar el acceso a los nombres y valores de las métricas de rendimiento de libvirt. Para instalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/libvirt
# ./connect
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/libvirt
# ./Remove

pmdalibvirt es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/libvirt/libvirt.conf
archivo de configuración para el agente pmdalibvirt
$PCP_PMDAS_DIR/libvirt/connect
utilidad de prueba de conexión que utiliza la configuración del agente pmdalibvirt
$PCP_PMDAS_DIR/libvirt/Install
script de instalación para el agente pmdalibvirt
$PCP_PMDAS_DIR/libvirt/Remove
script para deshacer la instalación del agente pmdalibvirt
$PCP_LOG_DIR/pmcd/libvirt.log
archivo de registro predeterminado para mensajes del agente pmdalibvirt

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
