NOMBRE

pmdahdb - PMDA de SAP HANA

DESCRIPCIÓN

pmdahdb es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores de métricas sobre una base de datos SAP HANA (High-performance ANalytic Appliance), una base de datos multimodelo que almacena datos en memoria en lugar de mantenerlos en disco.

Este PMDA se puede usar en escenarios de escalado horizontal. Todas las métricas son conscientes del Host y del Puerto. El Host y el Puerto se incluyen en los nombres de instancia (<host>.<puerto>.<instancia>).

pmdahdb actualmente no soporta sistemas de Contenedor de Base de Datos Multitenant (MDC). El agente solo puede apuntar a un único contenedor de base de datos en este momento (este contenedor puede ser una base de datos tenant).

INSTALACIÓN

La configuración de hdb se mantiene con hdb.conf. Actualmente solo hay una sección hdb que contiene los parámetros de conexión de SAP HANA. Se admiten contraseñas entre comillas. Para más información sobre contraseñas entre comillas, véase: https://help.sap.com/docs/SAP_HANA_ONE/

Instale el PMDA de hdb utilizando el script de Instalación como root:

# cd $PCP_PMDAS_DIR/hdb
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/hdb
# ./Remove

pmdahdb es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts de Instalación y Eliminación notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_SYSCONF_DIR/hdb/hdb.conf
archivo de configuración para el agente pmdahdb
$PCP_PMDAS_DIR/hdb/Install
script de instalación para el agente pmdahdb
$PCP_PMDAS_DIR/hdb/Remove
script para deshacer la instalación del agente pmdahdb
$PCP_LOG_DIR/pmcd/hdb.log
archivo de registro predeterminado para mensajes de error de pmdahdb

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
