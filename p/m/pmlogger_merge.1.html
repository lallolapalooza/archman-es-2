NOMBRE

pmlogger_merge - script auxiliar para fusionar archivos de Performance Co-Pilot

SINOPSIS

$PCP_BINADM_DIR/pmlogger_merge [-fNVE?] [nombre-base-entrada ... nombre-salida]

DESCRIPCIÓN

pmlogger_merge es un script auxiliar que es utilizado por pmlogger_daily(1) al fusionar todos los archivos de Performance Co-Pilot (PCP) para un solo host en un solo día en un archivo PCP combinado.

pmlogger_merge es un script envoltorio para pmlogextract(1) que fusiona todos los archivos que coinciden con los argumentos nombre-base-entrada y crea un nuevo archivo utilizando nombre-salida como nombre base para los archivos físicos que constituyen un archivo. Los argumentos nombre-base-entrada pueden contener caracteres meta en el estilo de sh(1).

Si alguno de los archivos que son componentes de los archivos nombre-base-entrada ha sido comprimido, entonces, al éxito, pmlogger_merge comprimirá nombre-salida usando pmlogcompress(1).

OPCIONES

Las opciones de línea de comandos disponibles son:

-f, --force
Esta opción provoca la eliminación de todos los archivos de entrada una vez que se ha creado el archivo de salida.
-N, --showme
Ejecuta pmlogger_merge en modo "muéstrame" o "simulación" donde se informan las tareas que se realizarían, pero no se realizan cambios. Esto se usa típicamente para depuración en combinación con una (verbosa) o dos (muy verbosas) opciones -V.
-V, --verbose
Aumenta la verbosidad en el informe de progreso de salida.
-E, --expunge
Cuando se encuentran diferencias de metadatos métricos entre los archivos a fusionar, el comportamiento predeterminado es que pmlogger_merge falle con un error fatal y el archivo nombre-salida no se crea. El indicador -E en su lugar emite una advertencia y excluye las métricas afectadas del archivo de salida fusionado. Esto está destinado a la rotación automatizada de archivos diarios donde es muy deseable que la fusión, reescritura y compresión de archivos diarios no atendidos tengan éxito. Ver también pmlogger_daily(1) y la opción -x de pmlogextract(1).
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
