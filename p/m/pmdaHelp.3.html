PMDAHELP(3) Manual de funciones de biblioteca PMDAHELP(3)

NOMBRE

pmdaOpenHelp, pmdaGetHelp, pmdaGetInDomHelp, pmdaCloseHelp - Soporte de texto de ayuda para un PMDA

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaOpenHelp(const char *fname);
char *pmdaGetHelp(int handle, pmID pmid, int type);
char *pmdaGetInDomHelp(int handle, pmInDom indom, int type);
void pmdaCloseHelp(int handle);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA) (ver PMDA(3)), este grupo de rutinas se utiliza para implementar el procesamiento de la información de ayuda de métricas de un PMDA.

Estas rutinas están realmente destinadas a uso interno y no deberían necesitar ser llamadas directamente desde ningún código PMDA.

Brevemente, el nombre base del archivo de texto de ayuda (tal como lo crea newhelp(1)) se pasa a través de una opción de línea de comandos -h para un PMDA daemon o como argumento para pmdaDaemon(3) o pmdaDSO(3). Luego, pmdaInit(3) llama a pmdaOpenHelp y devuelve un *handle* que se utiliza en llamadas posteriores para identificar una colección de texto de ayuda particular (cada PMDA típicamente tiene solo una colección de este tipo).

Las solicitudes de texto de ayuda se pasan a pmdaText(3) que llama a pmdaGetHelp o pmdaGetInDomHelp según sea necesario.

Aparte de los casos de error en pmdaOpenHelp, pmdaCloseHelp no se llama.

ADVERTENCIA

El PMDA debe estar utilizando PMDA_INTERFACE_2 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICOS

pmdaOpenHelp devuelve un valor negativo en caso de fallo, adecuado para decodificar con pmErrStr(3). pmdaGetHelp y pmdaGetInDomHelp devuelven NULL si el texto de ayuda correspondiente no existe.

VER TAMBIÉN

newhelp(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaInit(3), pmdaText(3) y pmErrStr(3).
