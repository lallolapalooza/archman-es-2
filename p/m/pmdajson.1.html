NOMBRE

pmdajson - PMDA JSON

DESCRIPCIÓN

pmdajson es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta métricas de fuentes arbitrarias que generan sintaxis de Notación de Objetos de JavaScript (JSON).

Se requiere al menos un par de entradas JSON para que pmdajson proporcione métricas para los clientes de PCP; una que describe los metadatos de las métricas y otra que contiene los datos de los valores de las métricas. Los metadatos se leen una vez de un archivo al inicio del PMDA, mientras que los datos se leen cada vez que un cliente de PCP solicita los valores de las métricas. Los datos se leen de un archivo JSON o de un comando externo que genera salida JSON. Se pueden usar más de un par de entradas JSON para soportar un número arbitrario de fuentes de métricas en diferentes directorios configurados.

La descripción general del formato JSON se encuentra en http://www.json.org/.

FUENTES DE DATOS JSON

pmdajson lee un archivo de configuración JSON obligatorio

•
$PCP_PMDAS_DIR/json/config.json

Este archivo puede contener las siguientes opciones del PMDA utilizando la sintaxis JSON:

  • directory_list
  • trusted_directory_list

pmdajson busca en los directorios listados para estas opciones archivos llamados metadata.json y (por defecto) data.json. Los archivos de metadatos JSON describen los nombres de las métricas, los tipos y otros detalles de los datos JSON de métricas asociados. El nombre del archivo de datos JSON es configurable y también puede ser un comando externo en lugar de un archivo de datos actualizado periódicamente (por herramientas externas).

Cada uno de estos pares de archivo/comando JSON encontrados forma una fuente de datos JSON.

Por ejemplo, supongamos el siguiente archivo de datos JSON simple que contiene valores para dos métricas, una de tipo cadena y otra numérica:

  {
    "string_value": "testing, 1, 2, 3",
    "read_count": 0
  }

Para estas métricas, el archivo de metadatos necesario para pmdajson sería:

  {
    "metrics": [
      {
        "name": "string_value",
        "pointer": "/string_value",
        "type": "string"
      },
      {
        "name": "read_count",
        "pointer": "/read_count",
        "type": "integer",
        "description": "Veces que se leyeron los valores"
      }
    ]
  }

Para más detalles sobre el formato de metadatos JSON y las opciones, consulte el archivo README incluido como parte de la instalación de pmdajson.

MODELO DE SEGURIDAD

Las fuentes de datos JSON listadas para la opción directory_list no son de confianza, lo que significa que si se utilizan comandos externos para generar los datos JSON necesarios, estos comandos se ejecutan como el usuario nobody.

Las fuentes de datos JSON listadas para la opción trusted_directory_list son de confianza, lo que significa que si se utilizan comandos externos para generar los datos JSON necesarios, estos comandos se ejecutan como el usuario root.

Para más detalles sobre seguridad y descripción de la ejecución de comandos externos, consulte el archivo README incluido como parte de la instalación de pmdajson.

INSTALACIÓN

Instale el PMDA JSON utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/json
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/json
# ./Remove

pmdajson es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
