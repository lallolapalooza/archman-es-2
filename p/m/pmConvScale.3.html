PMCONVSCALE(3) Manual de funciones de biblioteca PMCONVSCALE(3)

NOMBRE

pmConvScale - reescala el valor de una métrica de rendimiento

C SINOPSIS

#include <pcp/pmapi.h>

int pmConvScale(int type,
const pmAtomValue *ival, const pmUnits *iunit, pmAtomValue *oval, const pmUnits *ounit);

cc ... -lpcp

DESCRIPCIÓN

Todos los valores de métricas de rendimiento pueden codificarse en una unión pmAtomValue, definida de la siguiente manera;

typedef union {
    __int32_t    l;     /* 32 bits con signo */
    __uint32_t   ul;    /* 32 bits sin signo */
    __int64_t    ll;    /* 64 bits con signo */
    __uint64_t   ull;   /* 64 bits sin signo */
    float        f;     /* Punto flotante de 32 bits */
    double       d;     /* Punto flotante de 64 bits */
    char         *cp;   /* puntero char */
    pmValueBlock *vbp;  /* puntero pmValueBlock */
} pmAtomValue;

La codificación de la dimensionalidad y la escala de una métrica de rendimiento utiliza una estructura pmUnits; consulte pmLookupDesc(3).

Dado un valor de métrica de rendimiento apuntado por ival, multiplíquelo por un factor de escala y devuelva el valor en oval. El escalado se realiza desde las unidades definidas por iunit a las unidades definidas por ounit. Las unidades de entrada y salida deben tener la misma dimensionalidad.

El tipo de métrica de rendimiento tanto para los valores de entrada como de salida lo determina type, cuyo valor normalmente se extrae de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

pmConvScale es más útil cuando los valores devueltos a través de pmFetch(3) (y posiblemente extraídos usando pmExtractValue(3)) necesitan ser normalizados a alguna escala y unidades canónicas para fines de cálculo.

Como caso especial, si todos los componentes de la dimensión son cero, se trata como sinónimo de una dimensión de "conteo" de uno, y por lo tanto los componentes de escala de "conteo" determinan el escalado relativo. Esto acomoda el caso donde las métricas de rendimiento no tienen dimensión, sin necesidad de manejo especial por parte del llamador.

DIAGNÓSTICOS

PM_ERR_CONV

iunit y ounit tienen dimensionalidad diferente o tienen un type inapropiado.

PM_ERR_UNIT

Parámetro iunit u ounit inapropiado.
