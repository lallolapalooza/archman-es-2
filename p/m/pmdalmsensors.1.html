NOMBRE

pmdalmsensors - Agente de dominio de métricas de rendimiento (PMDA) de monitoreo de hardware de Linux

SINOPSIS

$PCP_PMDAS_DIR/lmsensors/pmdalmsensors [debug]

DESCRIPCIÓN

pmdalmsensors es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen el estado del hardware utilizando el software lm-sensors en placas base compatibles.

El PMDA lmsensors exporta métricas que miden velocidades de ventiladores y temperaturas de núcleos.

INSTALACIÓN

Si desea acceso a los nombres, texto de ayuda y valores para las métricas de rendimiento de lmsensors, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/lmsensors
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/lmsensors
# ./Remove

pmdalmsensors.python suele ser lanzado por pmcd (1), y no se ejecuta directamente. La ejecución directa se utiliza principalmente para fines de depuración.

Los scripts Install y Remove notifican a pmcd (1) cuando el agente se instala o se elimina.

OPCIONES

pmdalmsensors.python soporta las siguientes opciones.

-i, --inject
inyecta datos desde un archivo en lugar de usar sensores
-d, --debug
nivel de depuración: 0 (predeterminado), 1 o 2
-h, --help
muestra un mensaje de ayuda

Para usar opciones cuando pmdalmsensors.python es ejecutado por PMCD, puede usar 'args' en el script 'Install', por ejemplo

args="-i /ruta/salida_sensores_estatica.txt"

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos usadas para lanzar pmdalmsensors
$PCP_PMDAS_DIR/lmsensors/help
archivo de texto de ayuda predeterminado para las métricas de lmsensors
$PCP_PMDAS_DIR/lmsensors/Install
script de instalación para el agente pmdalmsensors
$PCP_PMDAS_DIR/lmsensors/Remove
script para deshacer la instalación del agente pmdalmsensors

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
