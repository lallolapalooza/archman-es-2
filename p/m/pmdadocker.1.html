PMDADOCKER(1) Manual de Comandos Generales PMDADOCKER(1)

NOMBRE

pmdadocker - Agente de dominio de métricas de rendimiento de docker (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/docker/pmdadocker [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

pmdadocker es un Agente de Dominio de Métricas de Rendimiento (PMDA) para docker que expone métricas de rendimiento reportadas desde la API Remota de Docker.

A continuación se presenta una breve descripción de las opciones de línea de comandos de pmdadocker:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado docker.log en el directorio actual de pmcd(1) cuando se inicia pmdadocker, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en la salida de error estándar.

Las solicitudes de métricas de la API Remota se activan automáticamente y se obtienen periódicamente. Este temporizador es representado por pmdadocker a través de docker.control.timing. Por defecto, pmdadocker se configurará para obtener los datos en un intervalo de 1 segundo.

pmdadocker iterará a través de tres llamadas diferentes a la API Remota de docker:

/containers/$ID/json
Métricas del contenedor relativas al estado actual del contenedor. Como PID, nombre o si el contenedor se está ejecutando.
/version
Métricas básicas de versión sobre el demonio de docker actual en uso.
/containers/$ID/stats?stream=0
Métricas de memoria y CPU más detalladas del contenedor.

INSTALACIÓN

Si desea acceder a los nombres, texto de ayuda y valores para las métricas de rendimiento de docker, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/docker
# ./Install

Si desea deshacer la instalación (y eliminar ambos PMDAs), haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/docker
# ./Remove

pmdadocker es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdadocker
$PCP_PMDAS_DIR/docker/help
archivo de texto de ayuda predeterminado para las métricas de docker
$PCP_PMDAS_DIR/docker/Install
script de instalación para el agente pmdadocker
$PCP_PMDAS_DIR/docker/Remove
script para deshacer la instalación del agente pmdadocker
$PCP_LOG_DIR/pmcd/docker.log
archivo de registro predeterminado para mensajes de error y otra información de pmdadocker

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista de opciones de depuración separadas por comas; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdadocker son las siguientes:

Opción Descripción
appl1 reporta fallo al obtener estadísticas vía http
