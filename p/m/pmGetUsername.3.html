PMGETUSERNAME(3) Manual de funciones de biblioteca PMGETUSERNAME(3)

NOMBRE

pmGetUsername - obtener nombre de usuario especial de PCP

C SINOPSIS

#include <pcp/pmapi.h>

int pmGetUsername(char **username);

cc ... -lpcp

DESCRIPCIÓN

Dentro del Performance Co-Pilot (PCP), algunas aplicaciones utilizan un nombre de usuario especial (no root) para permitir el acceso, por ejemplo, para escribir archivos de registro en directorios protegidos.

pmGetUsername devuelve el nombre a través de username.

El nombre de variable PCP_USER se obtiene utilizando pmGetOptionalConfig(3). Si esto tiene éxito, pmGetUsername devuelve 1. De lo contrario, username se establece en el valor por defecto de pcp y pmGetUsername devuelve 0.

pmGetUsername se usa con mayor frecuencia en conjunto con pmSetProcessIdentity(3) al inicio del proceso.

VER TAMBIÉN

PMAPI(3), pmGetOptionalConfig(3) y pmSetProcessIdentity(3).
