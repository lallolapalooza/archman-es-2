PMDADESC(3) Manual de funciones de biblioteca PMDADESC(3)

NOMBRE

pmdaDesc - obtener la descripción de una métrica de un PMDA

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaDesc(pmID pmid, pmDesc *desc, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

pmdaDesc utiliza las estructuras de datos estándar de PMDA(3) para devolver la descripción pmDesc en desc para la métrica identificada por pmid.

ADVERTENCIA

El PMDA debe estar utilizando PMDA_INTERFACE_2 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICOS

Si el pmid no corresponde a ninguna métrica soportada por este PMDA, pmdaDesc devuelve PM_ERR_PMID.

VER TAMBIÉN

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) y pmLookupDesc(3).
