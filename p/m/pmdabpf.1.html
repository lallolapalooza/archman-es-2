NOMBRE

pmdabpf - PMDA de eBPF

SINOPSIS

$PCP_PMDAS_DIR/bpf/pmdabpf [-D depuración]

DESCRIPCIÓN

pmdabpf es un Agente de Dominio de Métricas de Rendimiento (PMDA) de Performance Co-Pilot (PCP) que extrae datos de rendimiento en vivo de programas eBPF utilizando BPF CO-RE (libbpf y BTF).

pmdabpf carga y actúa como puente para cualquier número de módulos PMDA bpf configurados y separados. Debería ser posible utilizar herramientas libbpf existentes con los módulos PMDA bpf con un esfuerzo razonable.

Consulte la documentación de eBPF, libbpf y BPF CO-RE para obtener descripciones detalladas.

CONFIGURACIÓN

pmdabpf lee un archivo de configuración obligatorio estilo ini:

$PCP_PMDAS_DIR/bpf/bpf.conf

Cada sección del archivo corresponde a un módulo PMDA bpf. Las siguientes opciones globales están disponibles para cada módulo (sus valores predeterminados se muestran entre paréntesis):

enabled (unset)
Un valor booleano para especificar si este módulo PMDA bpf debe iniciarse o no.

Los módulos también pueden admitir opciones de configuración adicionales específicas del módulo; consulte el archivo de configuración predeterminado para conocer las opciones admitidas.

INSTALACIÓN

Para instalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/bpf
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/bpf
# ./Remove

pmdabpf es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

Algunos módulos comenzarán a proporcionar valores solo después de haber recopilado datos de la actividad del sistema relacionada.

ARCHIVOS

$PCP_PMDAS_DIR/bpf/bpf.conf
archivo de configuración para el agente pmdabpf
$PCP_PMDAS_DIR/bpf/modules/*.{o,so}
módulos PMDA bpf disponibles para el agente pmdabpf
$PCP_PMDAS_DIR/bpf/Install
script de instalación para el agente pmdabpf
$PCP_PMDAS_DIR/bpf/Remove
script para deshacer la instalación del agente pmdabpf
$PCP_LOG_DIR/pmcd/bpf.log
archivo de registro predeterminado para mensajes del agente pmdabpf

Tenga en cuenta que el valor habitual/predeterminado para $PCP_PMDAS_DIR es /var/lib/pcp/pmdas y el valor predeterminado para $PCP_LOG_DIR es /var/log/pcp, pero esta configuración depende de la plataforma.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. depuración es una lista separada por comas de opciones de depuración; utilice pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), bpf(1) y pmcd(1).
