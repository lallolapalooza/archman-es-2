PMPARSEINTERVAL(3) Manual de Funciones de Librería PMPARSEINTERVAL(3)

NOMBRE

pmParseInterval - convertir cadena de intervalo a estructura de tiempo binaria

SINOPSIS

#include <pcp/pmapi.h>

int pmParseInterval(const char *string,
struct timespec *rslt, char **errmsg);

cc ... -lpcp

DESCRIPCIÓN

pmParseInterval analiza el argumento string especificando un intervalo de tiempo y rellena los componentes tv_sec y tv_nsec de la estructura rslt para representar dicho intervalo (precisión de nanosegundos).

La cadena string de entrada es más comúnmente el argumento siguiente a una opción de línea de comandos -t de una aplicación PCP, y la sintaxis se describe completamente en PCPIntro(1).

DIAGNÓSTICOS

pmParseInterval devuelve 0 y errmsg no está definido si el análisis es exitoso.

Si la cadena string dada no se ajusta a la sintaxis requerida, pmParseInterval devuelve -1 y un mensaje de error asignado dinámicamente en errmsg. El mensaje de error termina con un salto de línea e incluye el texto de la cadena de entrada string junto con un indicador de la posición en la que se detectó el error, por ejemplo:

4minutes 30mumble
^ -- valor inesperado

En caso de error, el llamador es responsable de llamar a free(3) para liberar el espacio asignado para errmsg.

COMPATIBILIDAD

Antes de PCP 7.0, el argumento rslt era una struct timeval. Para soportar la transición de PMAPI, la interfaz y la semántica antiguas pueden ser utilizadas si las aplicaciones se recompilan con -DPMAPI_VERSION=2.

Durante un tiempo en PCP 6.x, existió una rutina con la misma semántica que la actual pmParseInterval llamada pmParseHighResInterval, aunque ahora está obsoleta y el soporte en tiempo de compilación para pmParseHighResInterval se eliminará en una futura versión.

VER TAMBIÉN

PCPIntro(1), free(3), PMAPI(3) y pmParseTimeWindow(3).
