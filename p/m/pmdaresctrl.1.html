PMDARESCTRL(1) Manual de Comandos Generales PMDARESCTRL(1)

NOMBRE

pmdaresctrl - agente de dominio de métricas de rendimiento resctrl (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/pmdaresctrl [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

pmdaresctrl es un Agente de Dominio de Métricas de Rendimiento (PMDA) de resctrl que expone los valores de las métricas de rendimiento de la interfaz /sys/fs/resctrl para proporcionar información sobre la caché de último nivel.


Se pueden encontrar más detalles sobre el soporte de Linux para las métricas de caché de último nivel en https://github.com/torvalds/linux/tree/master/Documentation/arch/x86/resctrl.rst.

INSTALACIÓN

Si desea acceso a los nombres, textos de ayuda y valores de las métricas de rendimiento de resctrl, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/resctrl
# ./Install

Si desea deshacer la instalación (y eliminar ambos PMDAs), haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/resctrl
# ./Remove

pmdaresctrl es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos usadas para lanzar pmdaresctrl
$PCP_PMDAS_DIR/resctrl/help
archivo de texto de ayuda predeterminado para las métricas de resctrl
$PCP_PMDAS_DIR/resctrl/Install
script de instalación para el agente pmdaresctrl
$PCP_PMDAS_DIR/resctrl/Remove
script para deshacer la instalación del agente pmdaresctrl

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). En particular, $PCP_RESCTRL_DIR puede establecerse para cambiar el directorio predeterminado de /sys/fs/resctrl.

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1), pcp.conf(5), pcp.env(5) y resctrl(1).
