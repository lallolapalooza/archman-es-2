NOMBRE

pmieconf - muestra y establece variables de reglas configurables de pmie

SINOPSIS

pmieconf [-cFv?] [-f archivo] [-r rutadereglas] [comando [args...]]

DESCRIPCIÓN

pmieconf es una utilidad para ver y configurar variables de reglas generalizadas de pmie(1). El conjunto de reglas generalizadas se lee desde rutadereglas, y el archivo de salida archivo producido por pmieconf es un archivo de entrada válido para pmie.

OPCIONES

Las opciones de línea de comandos disponibles son:

-c
Cuando se ejecuta desde procesos automatizados de configuración de pmie, esta opción se utiliza para agregar un mensaje específico y una marca de tiempo indicando que este es el caso. A menos que se anule con la opción -f, el archivo de configuración predeterminado que se escribirá o actualizará cuando se proporcione la opción -c y pmieconf sea ejecutado por el usuario root, es $PCP_VAR_DIR/config/pmie/config.default. Este es también el archivo de configuración predeterminado utilizado por el servicio pmie, consulte pmie_daily(1). Esta opción no es apropiada cuando se usa la herramienta interactivamente.
-f archivo, --config=archivo
Cualquier modificación de reglas resultante de la manipulación de valores de variables por parte de pmieconf se escribirá en archivo. El valor predeterminado de archivo depende del ID de usuario: para el usuario root (cuando la opción -c *no* se proporciona también, ver arriba) el archivo es $PCP_SYSCONF_DIR/pmie/config.default. Para otros usuarios, el predeterminado es $HOME/.pcp/pmie/config.pmie.
-F, --force
Fuerza la creación (o actualización) del archivo de salida de pmieconf archivo, después de lo cual pmieconf sale inmediatamente.
-r rutadereglas, --rules=rutadereglas
Permite cambiar el origen de las reglas generalizadas de pmie - rutadereglas es una lista separada por dos puntos de archivos de reglas pmieconf(5) y/o subdirectorios. El valor predeterminado para rutadereglas es $PCP_VAR_DIR/config/pmieconf. El uso de esta opción anula la variable de entorno PMIECONF_PATH que tiene una función similar.
-v, --verbose
Habilita el modo detallado. Las variables asociadas se mostrarán. Esta es la lista completa de variables que afectan a cualquier regla dada (por predeterminado, las variables globales no se muestran con la regla).
-?, --help
Muestra el mensaje de uso y sale.

Los comandos de pmieconf permiten mostrar o modificar información relacionada con las diversas reglas y variables configurables. Si no se presentan comandos de pmieconf en la línea de comandos, pmieconf solicita comandos interactivamente.

LENGUAJE DE COMANDOS

El lenguaje de comandos de pmieconf se describe aquí:

help [ { . | all | global | <regla> | <grupo> } [<variable>] ]
Sin argumentos, el comando help muestra la sintaxis de todos los comandos disponibles de pmieconf. Con un argumento, se muestra una descripción de una o más reglas generalizadas. Con dos argumentos, se muestra una descripción de una variable específica relacionada con una o más reglas generalizadas.
rules [ enabled | disabled ]
Muestra el nombre y un resumen corto para todas las reglas generalizadas encontradas en rutadereglas. Cada uno de los nombres de regla puede usarse en lugar de la palabra clave <regla> en esta descripción de sintaxis de comando. Las opciones enabled y disabled pueden usarse para filtrar el conjunto de reglas mostradas a solo aquellas que están habilitadas o deshabilitadas respectivamente.
groups
Muestra el nombre de todos los grupos de reglas encontrados en rutadereglas. Cada uno de los nombres de grupo puede usarse en lugar de la palabra clave <grupo> en esta descripción de comando, lo que aplica el comando a todas las reglas dentro del grupo de reglas.
status
Muestra información de estado relacionada con la sesión actual de pmieconf, incluyendo una lista de procesos de pmie en ejecución que están utilizando actualmente archivo.
enable { . | all | <regla> | <grupo> }
Habilita la regla o grupo de reglas especificado. Una regla habilitada es una que se incluirá en el archivo de configuración de pmie generado por pmieconf. Las "acciones" habilitadas se agregarán al "predicado" de la regla, de manera que cumpla con la sintaxis de pmie (las "acciones" se pueden ver usando el comando list global, descrito a continuación).
disable { . | all | <regla> | <grupo> }
Deshabilita la regla o grupo de reglas especificado. Si la regla estaba previamente habilitada, se eliminará del archivo de configuración de pmie generado por pmieconf, y por lo tanto ya no se evaluará cuando se reinicie pmie (usar pmieconf no afecta a ningún proceso pmie existente que use archivo).
list { . | all | global | <regla> | <grupo> } [<variable>]
Muestra los valores para una variable de regla específica; o para todas las variables de una regla, un grupo de reglas, todas las reglas o las variables globales.
modify { . | all | global | <regla> | <grupo> } <variable> <valor>
Habilita, deshabilita o cambia de otra manera el valor de una o más variables de regla. Este valor debe ser consistente con el tipo de la variable, que se puede inferir del formato del valor impreso; por ejemplo, las cadenas de texto se encerrarán entre comillas dobles, los porcentajes tendrán el símbolo ``%'' adjunto, etc. Tenga en cuenta que ciertas variables de regla no se pueden modificar a través de pmieconf; por ejemplo, "predicate" y "help".
undo { . | all | global | <regla> | <grupo> } [<variable>]
Aplicable solo a una variable cuyo valor ha sido modificado: este comando simplemente revierte al valor predeterminado para la variable dada.
quit
Guarda los cambios realizados en archivo y luego sale de pmieconf.
abort
Sale de pmieconf inmediatamente sin guardar ningún cambio en archivo.

Cada uno de los comandos anteriores se puede acortar usando simplemente el primer carácter del nombre del comando, y también ``?'' para ayuda.

El uso de la palabra clave all hace que el comando se aplique a todas las reglas. La palabra clave global se refiere a aquellas variables que se aplican a cada regla. Dichas variables se pueden cambiar tanto globalmente como localmente, por ejemplo:

  pmieconf> modify global delta "5 minutes"
  pmieconf> modify memory delta "1 minute"

esto hace que todas las reglas se evalúen una vez cada cinco minutos, excepto las reglas del grupo "memory" que se evaluarán una vez por minuto.

El carácter ``.'' es especial para pmieconf; se refiere al último valor de all, global, <regla> o <grupo> utilizado con éxito.

EJEMPLOS

Especificar que todas las reglas del grupo "memory" deben ser evaluadas:

  pmieconf> modify memory enabled yes

Cambiar de opinión y volver a usar solo las reglas "memory" que estaban habilitadas por defecto:

  pmieconf> undo memory enabled

Especificar que la notificación de reglas que se evalúan como verdaderas debe enviarse a syslogd(1):

  pmieconf> modify global syslog_action yes

Especificar que las reglas del grupo "per_cpu" deben usar un período de espera diferente al de otras reglas:

  pmieconf> modify per_cpu holdoff "30 seconds"
pmieconf(5)

NAME

pmieconf - Performance Metrics Instrumentation Engine (PMIE) configuration language

SYNOPSIS

pmieconf [-r directory] [-i file] [-P prog] [-p prog] [-s] [-S] [-v] [-h]

DESCRIPTION

The Performance Metrics Instrumentation Engine (PMIE) monitors system performance metrics and performs actions based on predefined rules. The pmieconf utility is used to interactively create, modify, and inspect the configuration rules used by PMIE.

The configuration language is described in more detail in the pmieconf(5) manual page.

OPTIONS

-r directory
Specify a directory containing PMIE configuration files. If not specified, PMIE will search the directories specified by the PMIECONF_PATH environment variable, or fall back to a set of default system and user configuration directories.
-i file
Specify a single configuration file to load. If this option is used, only the specified file will be loaded, overriding any search paths.
-P prog
Specify the default PMIE program to use. This is useful if you have multiple PMIE instances running or want to target a specific PMIE instance.
-p prog
Same as -P, but for the interpreter program.
-s
Start PMIE in a non-interactive mode, reading commands from standard input and writing output to standard output. This is useful for scripting.
-S
Start PMIE in a non-interactive mode, similar to -s, but also apply changes immediately without requiring explicit confirmation.
-v
Print version information and exit.
-h
Print a help message and exit.

COMMAND LANGUAGE

The pmieconf utility uses a domain-specific language for defining and manipulating PMIE rules. Key concepts include:

rule
A named set of conditions and actions. Rules can be generic (applied to all instances) or specific (e.g., per-CPU).
predicate
A condition that, when true, triggers the rule's actions. Predicates often involve comparing metric values against thresholds.
action
An operation to perform when a rule's predicate is true. Actions can include logging messages, sending alerts, or executing commands.
variable
A parameter within a rule that can be modified. Common variables include `threshold`, `holdoff`, and `action_delay`.

Commands typically follow the pattern:

  pmieconf> command rule [variable] [value]

Common commands include:

help
Display help information for a command or variable.
list (or l)
List the details of a rule or variable.
modify (or m)
Modify the value of a variable for a rule.

EXAMPLES

Get help on the `holdoff` variable for generic rules:

  pmieconf> help global holdoff
    rule: global  [generic parameters applied to all rules]
     var: holdoff
    help: Once the predicate is true and the action is executed,
	  this variable allows suppression of further action
	  execution until the specified interval has elapsed.
	  A value of zero enables execution of the action if
	  the rule predicate is true at the next sample. Default
	  units are seconds and common units are "second", "sec",
	  "minute", "min" and "hour".

Set the `holdoff` interval for the `per_cpu` rule to 1 hour:

  pmieconf> modify per_cpu holdoff "1 hour"

Lower the threshold associated with a particular variable for a specified rule:

  pmieconf> l cpu.syscall predicate
    rule: cpu.syscall  [High aggregate system call rate]
      predicate =
	      some_host (
		  ( kernel.all.syscall $hosts$ )
		    > $threshold$ count/sec * hinv.ncpu $hosts$
	      )
  pmieconf> m . threshold 7000
  pmieconf> l . threshold
    rule: cpu.syscall  [High aggregate system call rate]
	    threshold = 7000

FILES

$PCP_VAR_DIR/config/pmieconf/*/*
generalized system resource monitoring rules
$PCP_SYSCONF_DIR/pmie/config.pmie
default super-user settings for system resource monitoring rules
$HOME/.pcp/pmie/config.pmie
default user settings for system resource monitoring rules

ENVIRONMENT

The environment variable PMIECONF_PATH has a similar function to the -r option described above, and if set will be used provided no -r option is presented.

PCP ENVIRONMENT

Environment variables with the prefix PCP_ are used to parameterize the file and directory names used by PCP. On each installation, the file /etc/pcp.conf contains the local values for these variables. The $PCP_CONF variable may be used to specify an alternative configuration file, as described in pcp.conf(5).
