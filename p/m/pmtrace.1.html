PMTRACE(1) Manual de Comandos Generales PMTRACE(1)

NOMBRE

pmtrace - instrumentación de rendimiento en línea de comandos

SINOPSIS

pmtrace [-q?] [-c valor | -e comando | -v valor] [-h host] [-S estado] etiqueta

DESCRIPCIÓN

pmtrace proporciona una interfaz simple de línea de comandos para el Agente de Dominio de Métricas de Rendimiento de Trazas (PMDA) y la biblioteca asociada pcp_trace.

El comportamiento predeterminado de pmtrace es proporcionar datos de traza de punto al PMDA de traza, utilizando el argumento etiqueta como el nombre identificador asociado con cada punto de traza. La etiqueta se convierte entonces en un identificador de instancia dentro del conjunto de métricas trace.point.

OPCIONES

Las opciones de línea de comandos disponibles son:

-c valor
Permite que un contador arbitrario valor se exporte a través de las métricas trace.count.
-e comando
Permite que un comando arbitrario se ejecute. Este comando se medirá como una transacción, ya que tiene puntos de inicio y fin bien definidos. La información se pone a disposición a través de las métricas trace.transact.
-h host
Envía los datos de traza al PMDA de traza que se ejecuta en host, en lugar de en localhost. Esto anula el uso de la variable de entorno PCP_TRACE_HOST.
-q
Suprime los mensajes de una traza exitosa, para que pmtrace se ejecute en silencio.
-S estado
Habilita la depuración y el rastreo internos. El valor de estado es una combinación a nivel de bits de banderas de depuración, según se define en pmtracestate(3), y puede especificarse utilizando la sintaxis decimal o hexadecimal prescrita por strtol(3).
-v valor
Permite que un valor de punto flotante arbitrario valor se exporte a través de las métricas trace.observe.
-?
Muestra el mensaje de uso y sale.

DIAGNÓSTICOS

Todos se generan en la salida de error estándar y están diseñados para ser autoexplicativos.

El estado de salida de pmtrace siempre es cero, excepto cuando la opción -e está en uso, en cuyo caso se devuelve el estado de salida del comando.

ARCHIVOS

$PCP_DEMOS_DIR/trace/pmtrace.c
código fuente de pmtrace

ENTORNO

Dado que pmtrace utiliza las rutinas de la biblioteca libpcp_trace, se respetan las variables de entorno PCP_TRACE_HOST, PCP_TRACE_PORT y PCP_TRACE_TIMEOUT. Consulte pmdatrace(3) para obtener una descripción detallada de la semántica de cada una.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
