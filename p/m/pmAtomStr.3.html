PMATOMSTR(3) Manual de funciones de biblioteca PMATOMSTR(3)

NOMBRE

pmAtomStr, pmAtomStr_r - convertir un valor de métrica de rendimiento en una cadena

SINOPSIS EN C

#include <pcp/pmapi.h>

const char *pmAtomStr(const pmAtomValue *avp, int type);
char *pmAtomStr_r(const pmAtomValue *avp,
int type, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Todos los valores de métrica de rendimiento pueden ser codificados en una unión pmAtomValue, definida de la siguiente manera;

typedef union {
    __int32_t    l;     /* 32-bit firmado */
    __uint32_t   ul;    /* 32-bit sin signo */
    __int64_t    ll;    /* 64-bit firmado */
    __uint64_t   ull;   /* 64-bit sin signo */
    float        f;     /* punto flotante de 32 bits */
    double       d;     /* punto flotante de 64 bits */
    char         *cp;   /* puntero a char */
    pmValueBlock *vbp;  /* puntero a pmValueBlock */
} pmAtomValue;

Dado el valor de la métrica de rendimiento apuntado por avp, y un tipo de métrica de rendimiento definido por type, pmAtomStr generará el valor de métrica correspondiente como una cadena, adecuado para salida de diagnóstico o de informe. La función pmAtomStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos 80 bytes.

El valor para type se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Si el type es PM_TYPE_STRING, los valores más largos que 38 caracteres se truncarán después de 34 caracteres, y el truncamiento se mostrará con puntos suspensivos ``...'' al final del valor.

Si el type es PM_TYPE_AGGREGATE, se mostrarán hasta los tres primeros palabras de 32 bits como valores hexadecimales.

Si el type es PM_TYPE_EVENT, se generará un resumen del número de registros de eventos encontrados en el valor.

El valor de retorno de pmAtomStr se mantiene en un único búfer estático, por lo que el valor devuelto solo es válido hasta la próxima llamada a pmAtomStr.

NOTAS

pmAtomStr devuelve un puntero a un búfer estático y, por lo tanto, no es seguro para subprocesos. Las aplicaciones multihilo deben usar pmAtomStr_r en su lugar.

VER TAMBIÉN

PMAPI(3), pmConvScale(3), pmExtractValue(3), pmLookupDesc(3), pmPrintValue(3), pmTypeStr(3) y pmUnitsStr(3).
