pmErrStr(3)

Paquete: pcp

PMERRSTR(3) Manual de funciones de biblioteca PMERRSTR(3)

NOMBRE

pmErrStr, pmErrStr_r - convertir un código de error PMAPI en una cadena

SINOPSIS C

#include <pcp/pmapi.h>

const char *pmErrStr(int code);
char *pmErrStr_r(int code, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Traduce un código de error en una cadena de texto, adecuado para generar un mensaje de diagnóstico. La función pmErrStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos PM_MAXERRMSGLEN bytes.

Por convención, todos los códigos de error son negativos. Los valores pequeños se suponen que son las versiones negadas de los códigos de error de Unix, tal como se definen en <errno.h>, y las cadenas devueltas son las especificadas en strerror(3). Los códigos de error de Performance Metrics Application Programming Interface (PMAPI) más grandes y negativos son condiciones de error de PMAPI y pmErrStr(3) devuelve una cadena de error PMAPI apropiada, según lo determinado por code.

NOTAS

pmErrStr devuelve un puntero a un búfer estático, por lo que el valor devuelto solo es válido hasta la próxima llamada a pmErrStr y, por lo tanto, no es seguro para hilos. Las aplicaciones multihilo deben usar pmErrStr_r en su lugar.

VER TAMBIÉN

pmerr(1), PMAPI(3) y perror(3).
