PMIPUTTEXT(3) Manual de funciones de biblioteca PMIPUTTEXT(3)

NOMBRE

pmiPutText - añadir texto de ayuda para una métrica o dominio de instancia

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutText(unsigned int type,
unsigned int class, unsigned int id, const char *content);

cc ... -lpcp_import -lpcp

SINOPSIS Perl

use PCP::LogImport;

pmiPutText($type, $class, $id, $content);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiPutText añade texto de ayuda para una métrica o dominio de instancia dados.

El type debe ser uno de PM_TEXT_PMID o PM_TEXT_INDOM.

El class debe ser uno de PM_TEXT_ONELINE o PM_TEXT_HELP.

Si type es PM_TEXT_PMID, entonces id debe coincidir con un pmid definido anteriormente en una llamada a pmiAddMetric(3). Si type es PM_TEXT_INDOM, entonces id debe coincidir con un dominio de instancia definido anteriormente en una llamada a pmiAddMetric(3).

content es una cadena que contiene el contenido del texto de ayuda.

No se escribirán datos hasta que se llame a pmiWrite(3), por lo que normalmente se utilizan varias llamadas a pmiPutText para acumular texto de ayuda para varias métricas o dominios de instancia antes de llamar a pmiWrite(3).

DIAGNÓSTICOS

pmiPutText devuelve cero en caso de éxito, de lo contrario, un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutResult(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutLabel(3) y pmiWrite(3).
