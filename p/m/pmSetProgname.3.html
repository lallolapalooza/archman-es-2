PMSETPROGNAME(3) Manual de funciones de la biblioteca PMSETPROGNAME(3)

NOMBRE

pmSetProgname, pmGetProgname - servicios de nombre de aplicación

SINOPSIS C

#include <pcp/pmapi.h>

void pmSetProgname(const char *programa);
char *pmGetProgname(void);

cc ... -lpcp

DESCRIPCIÓN

Dentro de las bibliotecas de tiempo de ejecución de Performance Co-Pilot (PCP) se mantiene el nombre de una aplicación en ejecución para ser utilizado en mensajes de error y diagnóstico.

El nombre de aplicación predeterminado es pcp.

pmSetProgname puede usarse para establecer el nombre de la aplicación a programa después de eliminar cualquier componente inicial que comience con el separador de nombres de ruta del sistema de archivos (``/'' para sistemas tipo Unix).

Es responsabilidad del llamante asegurarse de que la memoria apuntada por programa permanezca disponible durante la vida útil de la aplicación. Típicamente, el valor pasado como programa para un programa C sería argv[0]. Si programa es NULL, se restaura el nombre de aplicación predeterminado.

pmGetProgname puede usarse para devolver el nombre de la aplicación actual.
