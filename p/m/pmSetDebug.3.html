PMSETDEBUG(3) Manual de Funciones de Biblioteca PMSETDEBUG(3)

NOMBRE

pmSetDebug, pmDebug, pmGetDebug, pmClearDebug - manipular opciones de control de depuración de PCP

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmSetDebug(const char *spec);
int pmDebug(const char *spec);
char *pmGetDebug(void);
int pmClearDebug(const char *spec);

cc ... -lpcp

DESCRIPCIÓN

Dentro de las bibliotecas y aplicaciones del Performance Co-Pilot (PCP) existe un extenso conjunto de opciones de depuración que pueden ser habilitadas o deshabilitadas en tiempo de ejecución.

pmSetDebug, pmDebug y pmClearDebug analizan spec asumiendo que es una lista separada por comas de nombres de opciones de depuración de PCP.

Los nombres de las opciones disponibles se pueden encontrar usando el argumento -l de pmdbg(1).

Como caso especial, el nombre ``all'' se trata como un sinónimo para identificar todos los nombres de opciones.

pmSetDebug establecerá las opciones correspondientes, mientras que pmClearDebug borrará las opciones correspondientes.

pmDebug se utiliza para probar si las opciones han sido establecidas y devuelve 1 si al menos una de las opciones en spec ha sido establecida, de lo contrario devuelve 0.

Las llamadas consecutivas a pmSetDebug o pmClearDebug serán aditivas. Por ejemplo, los siguientes fragmentos de código son equivalentes en términos del estado final de las opciones de depuración.

sts = pmClearDebug("all");
sts = pmSetDebug("appl0");
sts = pmSetDebug("pdu,fetch");
sts = pmSetDebug("fetch,profile,context");
sts = pmClearDebug("appl0");

sts = pmClearDebug("all");
sts = pmSetDebug("pdu,fetch,profile,context");

Para aplicaciones que utilizan pmGetOptions(3) para procesar opciones y argumentos de línea de comandos, establecer la variable de entorno $PCP_DEBUG proporciona un mecanismo alternativo para establecer banderas de depuración, como se describe en PCPIntro(1).

pmGetDebug devuelve el conjunto actual de opciones de depuración habilitadas como una lista separada por comas. Si no hay opciones establecidas, el resultado es una cadena vacía. Si todas las opciones están establecidas, el resultado es ``all''. El resultado es asignado por malloc(3) y el llamador es responsable de llamar a free(3) cuando el resultado ya no sea necesario.

DIAGNÓSTICOS

Si tienen éxito, las rutinas pmSetDebug, pmDebug y pmClearDebug devuelven 0 o 1, de lo contrario, la devolución es PM_ERR_CONV para indicar un error al analizar spec.

Para pmGetDebug, un valor de retorno de NULL indica un fallo de malloc(3).

VER TAMBIÉN

PCPIntro(1), pmdbg(1), free(3) y malloc(3).
