NOMBRE

pmxchords - Este script procesa archivos pmx con símbolos de acordes, permitiendo transposiciones de tonalidad.

SINOPSIS

[ texlua ] pmxchords { opción | nombre-trabajo [ .pmx ] } ...

El efecto predeterminado es preprocesar cada archivo pmx para que los acordes se transpondrán según sea necesario, generando un archivo pmx temporal que luego es procesado por pmxab. Finalmente, el archivo tex resultante se renombra para que tenga el nombre de trabajo original. El nombre de archivo predeterminado para el archivo temporal es <nombre-trabajo>_chtr.pmx.

OPCIONES

-v
muestra el nombre y número de versión del programa, y sale.
-h
muestra el resumen de uso y sale.
-s
detenerse después del primer paso (de producir un archivo pmx temporal con símbolos de acordes transpuestos).

VER TAMBIÉN
