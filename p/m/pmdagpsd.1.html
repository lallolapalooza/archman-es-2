PMDAGPSD(1) Performance Co-Pilot PMDAGPSD(1)

NOMBRE

pmdagpsd - agente de dominio de métricas de rendimiento (PMDA) para gpsd

DESCRIPCIÓN

pmdagpsd es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores del demonio gpsd.

INSTALACIÓN

Si desea acceso a los nombres y valores de gpsd, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/gpsd
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/gpsd
# ./Remove

pmdagpsd es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o elimina.

ARCHIVOS

$PCP_PMDAS_DIR/gpsd/Install
script de instalación para el agente pmdagpsd
$PCP_PMDAS_DIR/gpsd/Remove
script para deshacer la instalación del agente pmdagpsd
$PCP_LOG_DIR/pmcd/gpsd.log
archivo de registro predeterminado para mensajes de error de pmdagpsd

VER TAMBIÉN

pmcd(1).
