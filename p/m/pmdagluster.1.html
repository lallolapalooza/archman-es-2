NOMBRE

pmdagluster - PMDA de Gluster Filesystem

DESCRIPCIÓN

pmdagluster es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos sobre sistemas de archivos gluster montados utilizando el comando gluster(8). Este PMDA exporta métricas sobre volúmenes y bricks, tanto locales como remotos al nodo donde se está ejecutando pmdagluster.

El sistema de archivos gluster admite un control detallado sobre la activación de estadísticas en volúmenes individuales, de modo que los valores se activan o desactivan opcionalmente en sistemas donde no se desea supervisarlos.

El comando pmstore(1) se puede utilizar para activar y desactivar la generación de perfiles de volúmenes. Utilizando las instancias individuales de la métrica gluster.volume.profile, se pueden establecer sus valores (y la generación de perfiles asociada) en activado (1) o desactivado (0). Además, pminfo(1) puede informar sobre el estado actual de la generación de perfiles de cada volumen.

# pminfo ‐f gluster.volume.profile
gluster.volume.profile
    inst [0 o "gv0"] value 0
    inst [1 o "gv1"] value 1
# pmstore ‐i "gv0" gluster.volume.profile 1
gluster.volume.profile inst [0 o "gv0"] valor antiguo=0 nuevo valor=1

Se pueden encontrar más detalles sobre el sistema de archivos gluster en http://www.gluster.org.

INSTALACIÓN

Instale el PMDA de gluster utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/gluster
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/gluster
# ./Remove

pmdagluster es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/gluster/Install
script de instalación para el agente pmdagluster
$PCP_PMDAS_DIR/gluster/Remove
script de desinstalación para el agente pmdagluster
$PCP_LOG_DIR/pmcd/gluster.log
archivo de registro predeterminado para mensajes de error de pmdagluster

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
