NOMBRE

pmrepconf - crear/editar un archivo de configuración de pmrep

SINOPSIS

pmrepconf [-crvV?] [-D debug] [-d directoriodegrupos] [-g etiqueta de grupo] [-o opción] [-h host] archivoconfig

DESCRIPCIÓN

pmrepconf puede usarse para crear y modificar un archivo de configuración genérico para pmrep(1) y utilidades relacionadas en el formato pmrep.conf(5).

Si archivoconfig no existe, pmrepconf creará un archivo de configuración genérico con un conjunto de métricas descubiertas en una sección [metrics].

Una vez creado, archivoconfig puede usarse con la opción -c para pmrep(1) y utilidades relacionadas como pcp2elasticsearch(2) y pcp2spark(2).

Si archivoconfig existe, pmrepconf solicitará al usuario que habilite o deshabilite grupos de métricas de rendimiento relacionadas.

La selección de grupos requiere una simple respuesta de s (sí) o n (no) a la pregunta ¿Registrar este grupo?.

Otras respuestas en este punto pueden usarse para seleccionar funciones de control adicionales de la siguiente manera:

m
Informar los nombres de las métricas en el grupo actual.
q
Terminar con la selección de grupos (salir) y no realizar más cambios en este grupo ni en ninguno posterior.
/patrón
No hacer cambios en este grupo pero buscar un grupo que contenga patrón en la descripción del grupo o los nombres de las métricas asociadas.

Cuando se ejecuta desde procesos de configuración automatizados, la opción -c se usa para indicar que pmrepconf está en modo de creación automática y no se realiza ningún diálogo interactivo. El archivo de configuración de salida tiene un mensaje de comentario adicional y una marca de tiempo que indican este hecho, para que pueda ser identificado y actualizado posteriormente usando -c de nuevo. Esta opción no es apropiada para el uso interactivo de la herramienta.

Se puede habilitar una salida más detallada con la opción -v.

ARCHIVOS DE CONFIGURACIÓN DE GRUPOS

Cuando se crea un archivoconfig inicial, las especificaciones predeterminadas provienen de un conjunto de archivos de grupo debajo del directoriodegrupos especificado con la opción -d (el directoriodegrupos predeterminado es $PCP_VAR_DIR/config/pmlogconf, que es lo más comúnmente correcto, por lo que la opción -d rara vez se usa en la práctica).

La estructura de directorios y el formato de los archivos debajo de directoriodegrupos se comparten con la utilidad pmlogconf(1) y se describen en detalle en esa página del manual. Cuando es utilizado por pmrepconf, todas las configuraciones de intervalo se ignoran.

OPCIONES

Las opciones de línea de comandos disponibles son:

-c
Habilita el modo de creación automática no interactivo.
-d directoriodegrupos, --grupos=directoriodegrupos
Especifica la ruta al directorio directoriodegrupos.
-g etiqueta de grupo, --grupo=etiqueta de grupo
Consulta el estado de registro para el grupo específico llamado etiqueta de grupo.
-h host, --host=host
La fuente de métricas de rendimiento es pmcd(1) en host, en lugar de el localhost predeterminado.
-o opción, --opción=opción
Especifica una opción que se agregará a la sección [opción] del archivo pmrep.conf(5) generado. Esta opción de línea de comandos se puede presentar múltiples veces para agregar múltiples líneas en la sección [opción].
-r, --reprobe
Reconsidera cada grupo para su inclusión en el archivoconfig.
-v, --verbose
Habilita el modo detallado.
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

pmrepconf anula cualquier variable de entorno $PCP_DERIVED_CONFIG a una cadena vacía, por razones de rendimiento.

pmrepconf respeta la variable de entorno $PMCD_WAIT_TIMEOUT al sondear y crear nuevos archivos de configuración de pmrep. Utiliza un valor de tiempo de espera predeterminado de 10 segundos para esto, en ausencia de una configuración de entorno.

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
