PMIESTATUS(1) Manual de Comandos Generales PMIESTATUS(1)

NOMBRE

pmiestatus - mostrar información del archivo de estadísticas de pmie

SINOPSIS

pmiestatus archivo_de_estadisticas [...]

DESCRIPCIÓN

pmiestatus muestra información utilizada para identificar un proceso pmie(1) en ejecución. Lo utilizan principalmente pmie_check(1) y pmie_daily(1) cuando buscan instancias de pmie para comprobar contra el archivo de control.

ARCHIVOS

$PCP_TMP_DIR/pmie/*
archivos de estadísticas de pmie

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

pmie(1), pmie_check(1), pmie_daily(1), pcp.conf(5) y pcp.env(5).
