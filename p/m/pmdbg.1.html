NOMBRE

pmdbg - informa sobre las opciones de depuración de Performance Co-Pilot

SINOPSIS

pmdbg [-l]

DESCRIPCIÓN

Los componentes de Performance Co-Pilot (PCP) utilizan un mecanismo global para controlar la salida de diagnóstico y depuración.

pmdbg imprime todas las opciones de depuración disponibles con el nombre de la opción y un texto descriptivo.

La opción -l no hace nada, pero se incluye por compatibilidad con versiones anteriores de pmdbg.

La mayoría de las aplicaciones que utilizan las facilidades de PCP admiten la sintaxis de comando -D nombre[,nombre ...] para habilitar el control de depuración utilizando el (los) nombre(s) de las opciones de depuración deseadas.

Alternativamente, el valor inicial de las banderas de control de depuración puede establecerse en una lista separada por comas si se utilizan nombres de opción en la variable de entorno $PCP_DEBUG, siempre que las aplicaciones utilicen pmGetOptions(3) para procesar las opciones y argumentos de la línea de comandos. Si se utilizan ambos mecanismos, el efecto es aditivo, por lo que las banderas resultantes son las establecidas a través de $PCP_DEBUG combinadas con las establecidas a través de cualquier opción de línea de comandos -D.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

COMPATIBILIDAD

Antes de PCP 7.0, las opciones de depuración se mantenían en un doble estado con un entero codificado en binario de estilo antiguo (más un nombre de macro para los programadores), y un nombre de cadena de estilo nuevo para cada opción de depuración.

En PCP 7.0 se eliminó el soporte para el estilo antiguo.
