PMDASMART(1) Manual de comandos generales PMDASMART(1)

NOMBRE

pmdasmart - PMDA de datos S.M.A.R.T.

SINOPSIS

$PCP_PMDAS_DIR/smart/pmdasmart [-D debug]

DESCRIPCIÓN

pmdasmart es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos para Device Mapper en el sistema local.

Este PMDA recopila sus datos a través de la utilidad smartctl(8) y requiere que el programa esté instalado para funcionar.

Más detalles sobre smartctl y smartmontools se pueden encontrar en https://smartmontools.org.

INSTALACIÓN

Instale el PMDA SMART utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/smart
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/smart
# ./Remove

pmdasmart es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/smart/help
archivo de ayuda predeterminado para las métricas smart
$PCP_PMDAS_DIR/smart/Install
script de instalación para el agente pmdasmart
$PCP_PMDAS_DIR/smart/Remove
script para deshacer la instalación del agente pmdasmart
$PCP_LOG_DIR/pmcd/smart.log
archivo de registro predeterminado para mensajes de error de pmdasmart

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1) y smartctl(8).
