PMADELTAINDOM(3) Manual de funciones de biblioteca PMADELTAINDOM(3)

NOMBRE

pmaDeltaInDom - generar un "delta indom" si dos observaciones de un dominio de instancia son diferentes

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaDeltaInDom(__pmLogInDom *old,
__pmLogInDom *new, __pmLogInDom *new_delta);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas en las diferentes versiones, y pueden no funcionar, o proporcionar una semántica diferente en algún momento futuro.

DESCRIPCIÓN

Comprueba si dos observaciones del mismo dominio de instancia son idénticas y, si no lo son, intenta generar un "delta indom" para describir las diferencias.

El código asume (a) old->indom == new->indom y (b) que ambos dominios de instancia están ordenados en secuencia ascendente de identificador de instancia interno; ver pmaSortInDom(3) para ver cómo hacer que la segunda condición sea verdadera.

El formato "delta indom" solo se admite para archivos de la versión 3 y es responsabilidad del llamador determinar si llamar a pmaDeltaInDom es apropiado, en lugar de llamar a pmaSameInDom(3), que es el método preferido para archivos V2.

pmaDeltaInDom devuelve 0 si los dominios de instancia old y new son iguales.

Un valor de retorno de 1 indica que los dominios de instancia son diferentes y que el formato "delta indom" no es más eficiente; en este caso, new_delta no se modifica.

Un valor de retorno de 2 indica que los dominios de instancia son diferentes y que new_delta se ha configurado para describir la codificación "delta indom" de las diferencias; en este caso, el llamador es responsable de liberar new_delta->instlist y new_delta->namelist.

Los dominios de instancia se consideran diferentes si se cumple alguna de las siguientes condiciones:

1.
old->numinst != new->numinst
2.
Para algún i, old->instlist[i] != new->instlist[i]
3.
Para algún i, las cadenas apuntadas por old->namelist[i] y new->instlist[i] no son idénticas

FORMATO DELTA INDOM

Al igual que para un dominio de instancia normal, new_delta->numinst define el número de especificaciones de instancia.

Si new_delta->namelist[i] == NULL, la instancia identificada por new_delta->instlist[i] ha sido eliminada del dominio de instancia.

Si new_delta->namelist[i] != NULL, la instancia identificada por new_delta->instlist[i] ha sido añadida al dominio de instancia.

Dado que es probable que el "delta indom" solo tenga relevancia a corto plazo para el llamador, las entradas new_delta->namelist[i] que no sean NULL apuntarán a old->namelist[j] o new->namelist[k], por lo que old y new no deben liberarse hasta que el llamador haya terminado con new_delta.

VER TAMBIÉN

PMAPI(3), pmaSortInDom(3) y pmaSameInDom(3).
