PMIDSTR(3) Manual de funciones de biblioteca PMIDSTR(3)

NOMBRE

pmIDStr, pmIDStr_r - convertir un identificador de métrica de rendimiento en una cadena

SINOPSIS C

#include <pcp/pmapi.h>

const char *pmIDStr(pmID pmid);
char *pmIDStr_r(pmID pmid, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Para su uso en mensajes de error y diagnóstico, pmIDStr devuelve una versión "legible por humanos" del Identificador de Métrica de Rendimiento (PMID) especificado. La función pmIDStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debería tener espacio para al menos 20 bytes.

Internamente, un PMID se codifica con tres campos: dominio, clúster e ítem. pmIDStr devuelve una cadena con cada uno de los campos que aparecen como números decimales, separados por puntos.

El resultado del valor de cadena de pmIDStr se mantiene en un único búfer estático, por lo que el valor devuelto solo es válido hasta la próxima llamada a pmIDStr.

NOTAS

pmIDStr devuelve un puntero a un búfer estático y, por lo tanto, no es seguro para hilos. Las aplicaciones multihilo deben usar pmIDStr_r en su lugar.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores de estas variables se pueden obtener programáticamente utilizando la función pmGetConfig(3).
