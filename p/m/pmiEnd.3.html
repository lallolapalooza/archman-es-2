PMIEND(3) Manual de funciones de biblioteca PMIEND(3)

NOMBRE

pmiEnd - finalizar un archivo LOGIMPORT

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiEnd(void);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiEnd();

DESCRIPCIÓN

Como parte de la API de Importación de Registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiEnd cierra el contexto actual, forzando la escritura de los registros del tráiler en los archivos de registro de PCP, y luego estos archivos se cierran.

En operaciones normales, una aplicación incluiría una llamada a pmiEnd al final del procesamiento para cada contexto creado con una llamada a pmiStart(3).

DIAGNÓSTICOS

pmiEnd devuelve cero en caso de éxito, de lo contrario, un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3) y pmiStart(3).
