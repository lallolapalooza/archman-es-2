PMIE2COL(1) Manual de comandos generales PMIE2COL(1)

NOMBRE

pmie2col - convierte la salida de pmie a formato de múltiples columnas

SINOPSIS

pmie2col [-?] [-d delimitador] [-p precisión] [-w ancho]

DESCRIPCIÓN

pmie2col es una herramienta sencilla que convierte la salida de pmie(1) a un formato de columna regular. Cada columna tiene 7 caracteres de ancho (por defecto, puede cambiarse con la opción -w) con un solo espacio entre columnas. Ese espacio único puede ser sustituido por un delimitador alternativo usando la opción -d (esto es útil para importar los datos en una hoja de cálculo, por ejemplo).

La precisión de los valores tabulados de pmie puede ser especificada con la opción -p (el valor por defecto es 2 decimales). Esta opción puede y anulará cualquier configuración de ancho para presentar la precisión solicitada.

La configuración de pmie(1) debe seguir estas reglas:

(1)
Cada expresión de pmie(1) tiene la forma ``NOMBRE = expr;''. NOMBRE se utilizará como encabezado de columna y no debe contener espacios en blanco, aunque los caracteres especiales pueden escaparse encerrando NOMBRE entre comillas simples.
(2)
El ``expr'' debe ser una expresión válida de pmie(1) que produzca un valor singular.

Además, pmie(1) debe ejecutarse con la opción de línea de comandos -v.

También es posible usar la línea de comandos -e para pmie(1) y las líneas de salida serán prefijadas con una marca de tiempo.

OPCIONES

Las opciones de línea de comandos disponibles son:

-d carácter, --delimitador=carácter
Usa carácter como delimitador de salida.
-p N, --precision=N
Usa n como precisión de punto flotante de salida.
-w N, --ancho=N
Usa n como ancho de columna de salida.
-?, --ayuda
Muestra el mensaje de uso y sale.

EJEMPLOS

Dado este archivo de configuración de pmie(1) (config): 

loadav = kernel.all.load #'1 minute';
'%usr' = kernel.all.cpu.user;
'%sys' = kernel.all.cpu.sys;
'%wio' = kernel.all.cpu.wait.total;
'%idle' = kernel.all.cpu.idle;
'max-iops' = max_inst(disk.dev.total);


Entonces esta tubería de comandos: 

$ pmie -v -t 5 <config | pmie2col -w 8


Produce una salida como esta: 

   loadav     %usr     %sys     %wio    %idle max-iops
     0.21        ?        ?        ?        ?        ?
     0.36     0.49     0.03     0.18     0.29    25.40
     0.49     0.41     0.10     0.36     0.13    51.00
     0.69     0.49     0.10     0.05     0.37    43.20
     0.71     0.39     0.08     0.04     0.49    14.00
     0.83     0.63     0.15     0.00     0.21    32.30
     1.09     0.60     0.02     0.10     0.27    47.00
     0.92     0.01     0.00     0.00     0.99     2.40


ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
