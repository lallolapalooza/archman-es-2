PMDAMEMCACHE(1) Manual de Comandos Generales PMDAMEMCACHE(1)

NOMBRE

pmdamemcache - agente de dominio de métricas de rendimiento de memcached (PMDA)

DESCRIPCIÓN

Este PMDA extrae datos de rendimiento de memcached, un demonio de caché de memoria distribuida comúnmente utilizado para mejorar el rendimiento de los servidores web. Un conjunto de procesos memcached en múltiples servidores puede ser utilizado por una única aplicación web, aumentando el tamaño total de la caché de objetos disponible y reduciendo la carga de la base de datos asociada con tamaños de caché más pequeños. Este sistema se describe en detalle en http://www.danga.com/memcached.

INSTALACIÓN

Configure pmdamemcache para extraer los valores de un conjunto de hosts utilizados en el conjunto de memcache. Estos hosts pueden ser listados en el archivo $PCP_PMDAS_DIR/memcache/memcache.conf, en el formato (es decir, array de Perl) descrito en la parte superior de pmdamemcache.pl. Una tasa de actualización personalizada también se puede configurar utilizando este mecanismo.

# cd $PCP_PMDAS_DIR/memcache
# [ editar memcache.conf ]

Una vez que esto esté configurado, puede acceder a los nombres y valores de las métricas de rendimiento de memcache haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/memcache
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/memcache
# ./Remove

pmdamemcache es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/memcache/memcache.conf
archivo de configuración opcional que lista las instancias de memcache supervisadas
$PCP_PMDAS_DIR/memcache/Install
script de instalación para el agente pmdamemcache
$PCP_PMDAS_DIR/memcache/Remove
script para deshacer la instalación del agente pmdamemcache
$PCP_LOG_DIR/pmcd/memcache.log
archivo de registro predeterminado para mensajes de error de pmdamemcache

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
