PMISETHOSTNAME(3) Manual de funciones de la biblioteca PMISETHOSTNAME(3)

NOMBRE

pmiSetHostname - establece el nombre del host de origen para un archivo LOGIMPORT

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiSetHostname(const char *value);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiSetHostname($value);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (véase LOGIMPORT(3)), pmiSetHostname establece el nombre del host de origen en el contexto actual a value.

En ausencia de una llamada a pmiSetHostname, el nombre del host de origen se establece por defecto en el nombre del host de localhost.

DIAGNÓSTICOS

pmiSetHostname devuelve cero si tiene éxito, de lo contrario, un valor negativo que se puede convertir en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN
