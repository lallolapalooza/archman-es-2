PMGETCONFIG(3) Manual de Funciones de Biblioteca PMGETCONFIG(3)

NOMBRE

pmGetConfig, pmGetOptionalConfig, pmGetAPIConfig - devolver valores para variables de configuración de Performance Co-Pilot

SINOPSIS C

#include <pcp/pmapi.h>

char *pmGetConfig(const char *variable);
char *pmGetOptionalConfig(const char *variable);
char *pmGetAPIConfig(const char *feature);

cc ... -lpcp

DESCRIPCIÓN

Las funciones pmGetConfig y pmGetOptionalConfig buscan la variable primero en el entorno y luego, si no se encuentra, en el archivo de configuración de Performance Co-Pilot (PCP) y devuelven el resultado de la cadena. Si la variable aún no está en el entorno, se añade con una llamada a setenv(3) antes de devolverla.

La función pmGetOptionalConfig permite fallos: ya sea porque la variable no está configurada en absoluto, o debido a que el archivo de configuración no se encuentra. pmGetConfig es menos tolerante a un archivo de configuración faltante, el cual trata como un fallo crítico de instalación de PCP; consulte la sección ``VALOR DE RETORNO'' a continuación para más detalles.

La ubicación predeterminada del archivo de configuración de PCP es /etc/pcp.conf, pero esto puede cambiarse estableciendo PCP_CONF en el entorno a una nueva ubicación, como se describe en pcp.conf(5).

La función pmGetAPIConfig informa sobre las características de la biblioteca PCP. Puede usarse para consultar soporte para multihilo, extensiones de seguridad y otras características.

La utilidad pmconfig(1) proporciona acceso desde la línea de comandos a ambas interfaces, y también proporciona un mecanismo para listar todas las variables y características disponibles que son argumentos válidos para estas rutinas.

VALOR DE RETORNO

Si la variable no se encuentra ni en el entorno ni en el archivo de configuración de PCP, o si el archivo de configuración es inaccesible, entonces pmGetOptionalConfig devuelve NULL.

Si la variable no se encuentra ni en el entorno ni en el archivo de configuración de PCP, entonces pmGetConfig devuelve una cadena vacía. Si no se encuentra el archivo de configuración de PCP, se imprime un mensaje de error fatal y el proceso saldrá (exit(2); aunque esto suene drástico, es la única acción posible ya que la configuración/instalación de PCP se considera fatalmente defectuosa.

La rutina pmGetAPIConfig devuelve NULL si falla la búsqueda de la característica solicitada. No modifica el entorno y devuelve un puntero a una cadena estática de solo lectura.

El valor devuelto por todas estas rutinas es un puntero estático o un puntero al entorno, por lo que modificarlo es una mala idea.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables pueden obtenerse programáticamente utilizando la función pmGetConfig(3).
