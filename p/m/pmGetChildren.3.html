NOMBRE

pmGetChildren - devuelve los nodos descendientes de un nodo PMNS

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetChildren(const char *name, char ***offspring);

cc ... -lpcp

DESCRIPCIÓN

Dado un nombre de ruta completamente calificado de un nodo en el Espacio de Nombres de Métricas de Rendimiento (PMNS) actual, identificado por name, pmGetChildren devuelve a través de offspring una lista de los nombres relativos de todos los nodos descendientes inmediatos de name en el PMNS actual.

Como caso especial, si name es una cadena vacía (es decir, ""), se devolverán los descendientes inmediatos del nodo raíz en el PMNS.

Normalmente, pmGetChildren devolverá el número de nombres descendientes descubiertos; de lo contrario, un valor menor que cero para un error. El valor cero indica que name es un nombre de métrica válido, es decir, está asociado con un nodo hoja en el PMNS.

La lista resultante de punteros offspring y los valores (los nombres relativos) a los que apuntan los punteros habrán sido asignados por pmGetChildren con una sola llamada a malloc(3), y es responsabilidad del que llama a pmGetChildren llamar a free(offspring) para liberar el espacio cuando ya no se necesite.

Cuando ocurre un error, o name es un nodo hoja (es decir, el resultado de pmGetChildren es menor que uno), offspring no está definido (no se habrá asignado espacio, y por lo tanto llamar a free(3) es una muy mala idea).

DIAGNÓSTICOS

PM_ERR_NOPMNS
Error al acceder a un PMNS para la operación. Tenga en cuenta que si la aplicación no ha llamado previamente a pmLoadNameSpace(3) y desea utilizar el PMNS distribuido, entonces se debe realizar una llamada a pmGetChildren dentro de un contexto actual.
PM_ERR_NAME
La ruta name no es válida en el PMNS actual
PM_ERR_*
Otros diagnósticos son para fallos de protocolo al acceder al PMNS distribuido.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables se pueden obtener mediante programación utilizando la función pmGetConfig(3).
