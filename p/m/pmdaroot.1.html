PMDAROOT(1) Manual de Comandos Generales PMDAROOT(1)

NOMBRE

pmdaroot - un agente de dominio de métricas de rendimiento (PMDA) auxiliar privilegiado

SINOPSIS

$PCP_PMDAS_DIR/root/pmdaroot [-D depuración] [-d dominio] [-l archivo_registro] [-s nombre_socket]

DESCRIPCIÓN

pmdaroot es un Agente de Dominio de Métricas de Rendimiento (PMDA) especial que coopera estrechamente con pmcd(1) y otros PMDAs para proporcionar servicios privilegiados limitados a estos procesos no privilegiados.

En este rol, se utiliza para descubrir contenedores del sistema operativo que se ejecutan en el host local. También permite el acceso a datos de rendimiento desde dentro de esos contenedores por parte de otros PMDAs que se ejecutan en el host físico, utilizando la interfaz pmdaRootConnect(3) y las interfaces de espacio de nombres asociadas.

Como todos los demás PMDAs, también exporta métricas de rendimiento del dominio que controla. Actualmente, esto se limita a información sobre los contenedores en el sistema local; actualmente se pueden detectar contenedores Docker y LXC.

Si se está utilizando un nombre de cgroup padre de Docker no predeterminado, este valor se puede indicar a pmdaroot mediante la adición de una variable $PCP_SYSTEMD_CGROUP en el archivo /etc/pcp.conf.

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado root.log en el directorio actual de pmcd(1) cuando se inicia pmdaroot, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no se puede escribir, la salida se escribe en la salida de error estándar.
-s
Ubicación del socket de dominio unix(7) para la comunicación con clientes que solicitan operaciones privilegiadas. Por defecto, se utiliza un archivo de socket llamado $PCP_TMP_DIR/pmcd/root.socket.

INSTALACIÓN

El acceso a los nombres, textos de ayuda y valores de las métricas de rendimiento del kernel está disponible por defecto; a diferencia de la mayoría de los otros agentes, no se requiere ninguna acción para habilitarlos y no deben eliminarse.

ARCHIVOS

$PCP_PMDAS_DIR/root/help
archivo de texto de ayuda predeterminado para las métricas exportadas por el PMDA raíz.
$PCP_LOG_DIR/pmcd/root.log
archivo de registro predeterminado para mensajes de error y otra información del PMDA raíz.
$PCP_VAR_DIR/pmcd/root.socket
archivo de socket predeterminado para la comunicación con clientes del PMDA raíz.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. depuración es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdaroot son las siguientes:

Opción Descripción
appl0 interacciones con pmcd(1)
appl1 procesamiento de inicio de PMDA

VER TAMBIÉN

PCPIntro(1), pmcd(1), PMDA(3), pmdaRootConnect(3), pcp.conf(5) y unix(7).
