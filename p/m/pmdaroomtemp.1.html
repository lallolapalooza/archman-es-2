PMDAROOMTEMP(1) Manual de Comandos Generales PMDAROOMTEMP(1)

NOMBRE

pmdaroomtemp - agente de dominio de métricas de rendimiento de temperatura ambiente (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/roomtemp/pmdaroomtemp [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

pmdaroomtemp es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta la temperatura de uno o más sensores construidos con los chipsets DS2480 y DS1280 y la tecnología MicroLAN de Dallas Semiconductor Corporation.

El PMDA roomtemp exporta métricas que reflejan las temperaturas de uno o más de estos dispositivos, tanto en grados Celsius como Fahrenheit. Cada métrica tiene una instancia para cada dispositivo sensor de temperatura. Los identificadores de instancia externos son los números de serie (en hexadecimal) de los chips DS1280 descubiertos cuando se sondeó MicroLAN.

A continuación, se ofrece una breve descripción de las opciones de línea de comandos de pmdaroomtemp:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado roomtemp.log en el directorio actual de pmcd(1) cuando se inicia pmdaroomtemp, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.

INSTALACIÓN

Si desea acceder a los nombres, textos de ayuda y valores de las métricas de rendimiento de roomtemp, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/roomtemp
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/roomtemp
# ./Remove

pmdaroomtemp es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts de Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos usadas para lanzar pmdaroomtemp
$PCP_PMDAS_DIR/roomtemp/help
archivo de texto de ayuda por defecto para las métricas de roomtemp
$PCP_PMDAS_DIR/roomtemp/Install
script de instalación para el agente pmdaroomtemp
$PCP_PMDAS_DIR/roomtemp/Remove
script para deshacer la instalación del agente pmdaroomtemp
$PCP_LOG_DIR/pmcd/roomtemp.log
archivo de registro por defecto para mensajes de error y otra información de pmdaroomtemp

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
