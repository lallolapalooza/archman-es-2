NOMBRE

pmclient, pmclient_fg - un cliente simple de métricas de rendimiento

SINOPSIS

pmclient [-PVz?] [-a archivo] [-A alineación] [-D depuración] [-h host] [-n archivopmns] [-O origen] [-s muestras] [-S horainicio] [-t intervalo] [-T horafin] [-Z zona]

pmclient_fg ...

DESCRIPCIÓN

pmclient y pmclient_fg son clientes simples que utilizan la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) para reportar algunas métricas de rendimiento del sistema de alto nivel.

El valor real de estas herramientas es como clientes de ejemplo que utilizan las interfaces de PMAPI(3) y, a tal fin, el código fuente se incluye con el paquete Performance Co-Pilot (PCP) (ver PCPIntro(1)), y normalmente se instala en /usr/share/pcp/demos/pmclient.

El programa pmclient_fg se diferencia de pmclient en que utiliza la extensión de la API fetchgroup a la PMAPI, ver pmFetchGroup(3).

Normalmente pmclient opera en el Espacio de Nombres de Métricas de Rendimiento (PMNS) distribuido, sin embargo, si se especifica la opción -n, se carga un PMNS local alternativo desde el archivo archivopmns.

A menos que se dirija a otro host con la opción -h, o a un archivo con la opción -a, pmclient contactará al Demonio Recolector de Métricas de Rendimiento (PMCD) en el host local para obtener la información requerida. El argumento de -a es una lista separada por comas de nombres, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos. Las opciones -a y -h son mutuamente excluyentes.

Por defecto, pmclient reporta la hora del día según la zona horaria local del sistema donde se ejecuta pmclient. La opción -Z cambia la zona horaria a zona en el formato de la variable de entorno TZ, como se describe en environ(7). La opción -z cambia la zona horaria a la zona horaria local del host que es la fuente de las métricas de rendimiento, según se identifica a través de las opciones -h o -a.

La salida de pmclient se dirige a la salida estándar y enumera

+
Utilización agregada de la CPU, en el rango de 0 a 1.
+
Si el sistema tiene más de 1 CPU, el número ordinal de la CPU más ocupada, en el rango de 0 a ...
+
Si el sistema tiene más de 1 CPU, la utilización de la CPU para la CPU más ocupada.
+
Memoria libre real en Mbytes.
+
Operaciones de E/S de disco físico agregadas por segundo (IOPS).
+
Promedio de carga durante el último minuto y durante los últimos 15 minutos.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a archivo, --archivo=archivo
Los valores de las métricas de rendimiento se recuperan del conjunto de archivos de archivo de Performance Co-Pilot (PCP) identificados por el argumento archivo, que es una lista separada por comas de nombres, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos.
-A alineación, --alineación=alineación
Forzar que la muestra inicial se alinee en el límite de una unidad de tiempo natural alineación. Consulte PCPIntro(1) para una descripción completa de la sintaxis de alineación.
-h host, --host=host
Recuperar métricas de rendimiento de pmcd(1) en host, en lugar de del host local por defecto.
-n archivopmns, --namespace=archivopmns
Cargar un Espacio de Nombres de Métricas de Rendimiento (PMNS(5)) alternativo desde el archivo archivopmns.
-O origen, --origen=origen
Al reportar métricas archivadas, comenzar a reportar en origen dentro de la ventana de tiempo (ver -S y -T). Consulte PCPIntro(1) para una descripción completa de la sintaxis de origen.
-P, --pausa
El comportamiento por defecto para reproducir un conjunto de archivos es reproducir a máxima velocidad. La opción -P puede usarse en conjunción con un conjunto de archivos, para solicitar que se aplique el retraso de tiempo real prevaleciente entre muestras (ver -t) para efectuar una pausa.
-s muestras, --muestras=muestras
El argumento muestras define el número de muestras a recuperar y reportar. Si muestras es 0 o no se especifica -s, pmclient tomará muestras y reportará continuamente (en modo de tiempo real) o hasta el final del conjunto de archivos PCP (en modo de archivo).
-S horainicio, --inicio=horainicio
La opción -S puede usarse en conjunción con un conjunto de archivos para solicitar que la visualización comience en horainicio desde el inicio del archivo(s). Consulte PCPIntro(1) para una descripción completa de la sintaxis de horainicio.
-t intervalo, --intervalo=intervalo
Establece el intervalo de reporte a algo diferente a los 5 segundos por defecto. El argumento intervalo sigue la sintaxis descrita en PCPIntro(1), y en su forma más simple puede ser un entero sin signo (las unidades implícitas en este caso son segundos).
-T horafin, --fin=horafin
Al reportar métricas archivadas, el reporte se restringirá a aquellos registros registrados antes o en horafin. Consulte PCPIntro(1) para una descripción completa de la sintaxis de horafin.
-V, --version
Mostrar número de versión y salir.
-z, --zonahost
Usar la zona horaria local del host que es la fuente de las métricas de rendimiento, según lo identificado por las opciones -h o -a. El valor por defecto es usar la zona horaria del host local.
-Z zona, --zona=zona
Usar zona para la fecha y hora. Zona está en el formato de la variable de entorno TZ como se describe en environ(7).
-?, --ayuda
Mostrar mensaje de uso y salir.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para variables de entorno que afectan a las herramientas de PCP, ver pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. depuración es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
