PMDAZSWAP(1) Manual de Comandos Generales PMDAZSWAP(1)

NOMBRE

pmdazswap - PMDA de zswap (swap comprimido)

DESCRIPCIÓN

pmdazswap es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos sobre la operación de swap comprimido, tal como es rastreado por el módulo del kernel de Linux zswap.

Zswap es una caché ligera comprimida para páginas de swap. Toma páginas que están en proceso de ser enviadas al swap y trata de comprimirlas en un pool de memoria basado en RAM asignado dinámicamente. Zswap intercambia ciclos de CPU por una reducción potencial de E/S de swap. Este intercambio también puede resultar en una mejora del rendimiento si las lecturas de la caché comprimida son más rápidas que las lecturas de un dispositivo de swap.

Este PMDA exporta métricas sobre el tamaño del pool, el número de páginas almacenadas y varios contadores de las razones por las que las páginas son rechazadas.

INSTALACIÓN

Instale el PMDA de zswap utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/zswap
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/zswap
# ./Remove

pmdazswap es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMDAS_DIR/zswap/Install
script de instalación para el agente pmdazswap
$PCP_PMDAS_DIR/zswap/Remove
script para deshacer la instalación del agente pmdazswap
$PCP_LOG_DIR/pmcd/zswap.log
archivo de log por defecto para mensajes de error de pmdazswap

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede ser usada para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
