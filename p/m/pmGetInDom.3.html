PMGETINDOM(3) Manual de funciones de la biblioteca PMGETINDOM(3)

NOMBRE

pmGetInDom - obtener identificadores de instancia para un dominio de instancia de métricas de rendimiento

C SINOPSIS

#include <pcp/pmapi.h>

int pmGetInDom(pmInDom indom,
int **instlist, char ***namelist);

cc ... -lpcp

DESCRIPCIÓN

En el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI), localiza la descripción del dominio de instancia indom y devuelve a través de instlist los identificadores de instancia internos para todas las instancias, y a través de namelist los identificadores externos completos para todas las instancias. El número de instancias encontradas se devuelve como valor de la función (o menos de uno para indicar un error).

El valor del dominio de instancia indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Las listas resultantes de identificadores de instancia (instlist y namelist), y los nombres a los que apuntan los elementos de namelist, habrán sido asignados por pmGetInDom con dos llamadas a malloc(3), y es responsabilidad del llamador llamar a free(instlist) y free(namelist) para liberar el espacio cuando ya no se necesite.

Cuando el resultado de pmGetInDom es menor que uno, tanto instlist como namelist no están definidos (no se habrá asignado espacio, por lo que llamar a free(3) es una muy mala idea).

DIAGNÓSTICOS

PM_ERR_INDOM
indom no es un identificador de dominio de instancia válido

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables pueden obtenerse programáticamente utilizando la función pmGetConfig(3).
