PMGETINDOMARCHIVE(3) Manual de funciones de biblioteca PMGETINDOMARCHIVE(3)

NOMBRE

pmGetInDomArchive - obtener identificadores de instancia para un dominio de instancia de métricas de rendimiento

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetInDomArchive(pmInDom indom,
int **instlist, char ***namelist);

cc ... -lpcp

DESCRIPCIÓN

Siempre que el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) esté asociado con un conjunto de archivos, pmGetInDomArchive examinará la unión de todos los metadatos del dominio de instancia para el dominio de instancia indom, y devolverá a través de instlist los identificadores de instancia internos para todas las instancias, y a través de namelist los identificadores externos completos para todas las instancias.

Esta rutina es una versión especializada de la rutina PMAPI más general pmGetInDom.

El número de instancias encontradas se devuelve como valor de la función (o menos de uno para indicar un error).

El valor para el dominio de instancia indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Las listas resultantes de identificadores de instancia (instlist y namelist), y los nombres a los que apuntan los elementos de namelist, habrán sido asignados por pmGetInDomArchive con dos llamadas a malloc(3), y es responsabilidad del llamante llamar a free(instlist) y free(namelist) para liberar el espacio cuando ya no se necesite.

Cuando el resultado de pmGetInDomArchive es menor que uno, tanto instlist como namelist no están definidos (no se habrá asignado espacio, por lo que llamar a free(3) es una idea singularmente mala).

DIAGNÓSTICOS

PM_ERR_NOTARCHIVE
el contexto PMAPI actual no está asociado con un conjunto de archivos
PM_ERR_INDOM_LOG
indom no es un identificador de dominio de instancia definido para el conjunto de archivos

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables se pueden obtener programáticamente usando la función pmGetConfig(3).
