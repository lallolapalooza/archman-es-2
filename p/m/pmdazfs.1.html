PMDAZFS(1) Manual de Comandos Generales PMDAZFS(1)

NOMBRE

pmdazfs - Agente de dominio de métricas de rendimiento del sistema de archivos ZFS (PMDA) para Linux

SINOPSIS

$PCP_PMDAS_DIR/linux_zfs/pmdazfs [-D debug] [-d dominio] [-l archivolog]

DESCRIPCIÓN

pmdazfs es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen el estado del sistema de archivos ZFS desde los archivos de estadísticas ubicados en /proc.

El PMDA zfs exporta métricas que miden información sobre el almacenamiento en caché (ARC, L2ARC, ZIL, VDEV), el almacenamiento en búfer, RAIDZ, operaciones de dnode y E/S de pools.

Una breve descripción de las opciones de línea de comandos de pmdazfs es la siguiente:

-d
El número de dominio de métricas de rendimiento debe establecerse en un valor único.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado zfs.log en el directorio actual de pmcd(1) cuando se inicia pmdazfs, es decir, en $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se redirige al error estándar.

INSTALACIÓN

OpenZFS no está incluido en PCP y debe instalarse en el sistema desde los paquetes disponibles o desde el código fuente. Una vez que OpenZFS esté instalado y configurado, los archivos de estadísticas deberían aparecer en /proc y el PMDA se puede agregar a PMCD usando el script Install:

# cd $PCP_PMDAS_DIR/zfs
# ./Install

Para eliminar el PMDA use el script Remove:

# cd $PCP_PMDAS_DIR/zfs
# ./Remove

OPCIONES DE DEPURACIÓN

Las opciones -D o --debug habilitan la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdazfs son las siguientes:

Opción Descripción
appl0 advierte si no se encuentra alguno de los archivos de estadísticas de ZFS

VER TAMBIÉN
