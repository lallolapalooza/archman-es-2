NOMBRE

pmdaText - extraer texto de ayuda de métricas para un PMDA

SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaText(int ident,
int type, char **buffer, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA, por sus siglas en inglés) (ver PMDA(3)), pmdaText utiliza las estructuras de datos estándar de PMDA(3) para devolver el texto de ayuda de la métrica ident en buffer. El texto de ayuda debe estar ubicado en archivos de texto de ayuda creados con newhelp(1), y los archivos asociados son abiertos automáticamente por pmdaInit(3).

La ruta (nombre base de los archivos) de los archivos de texto de ayuda puede establecerse en las llamadas a pmdaDSO(3) o pmdaDaemon(3) y anularse mediante la opción de línea de comandos -h en pmdaGetOpt(3).

La codificación de ident sigue el esquema interno utilizado por debajo de las rutinas pmLookupText(3) y pmLookupInDomText(3), es decir, ident codifica un identificador de métrica o un identificador de dominio de instancia, según el valor de type.

El argumento type es una máscara de bits que codifica la interpretación de ident y la forma solicitada de texto de ayuda, de la siguiente manera: ya sea PM_TEXT_PMID si ident es un identificador de métrica, o PM_TEXT_INDOM si ident es un identificador de dominio de instancia, más ya sea PM_TEXT_ONELINE para el texto de ayuda de una línea o PM_TEXT_HELP para el texto de ayuda completo.

El buffer es gestionado internamente (generalmente se almacena en caché), y el llamador de pmdaText no debe liberarlo o desasignarlo.

ADVERTENCIA

El PMDA debe estar usando PMDA_INTERFACE_2 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICO

Si no se pudo obtener el texto de ayuda solicitado, pmdaText devolverá PM_ERR_TEXT.

VER TAMBIÉN

newhelp(1), malloc(3), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaInit(3), pmLookupInDomText(3) y pmLookupText(3).
