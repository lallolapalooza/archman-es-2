NOMBRE

pmLookupInDomArchive - traducir un nombre de instancia a un identificador de instancia

SINOPSIS

#include <pcp/pmapi.h>

int pmLookupInDomArchive(pmInDom indom, const char *name);

cc ... -lpcp

DESCRIPCIÓN

Siempre que el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) esté asociado con un conjunto de archivos, pmLookupInDomArchive escaneará la unión de todos los metadatos del dominio de instancias para el dominio de instancias indom, localizará la primera instancia con la identificación externa dada por name y devolverá el identificador de instancia interno.

Esta rutina es una versión especializada de la rutina PMAPI más general pmLookupInDom.

Solo los caracteres iniciales que no sean espacios de name se utilizarán para identificar la instancia.

El valor para el dominio de instancias indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

pmLookupInDomArchive devolverá un identificador de instancia positivo en caso de éxito.

DIAGNÓSTICOS

PM_ERR_NOTARCHIVE
el contexto PMAPI actual no está asociado con un conjunto de archivos
PM_ERR_INDOM_LOG
indom no es un identificador de dominio de instancia definido para el conjunto de archivos
PM_ERR_INST_LOG
la instancia externa name no es conocida para el dominio de instancia indom en el conjunto de archivos
