PMOPENLOG(3) Manual de funciones de biblioteca PMOPENLOG(3)

NOMBRE

pmOpenLog - crear un archivo de registro para diagnóstico y salida de depuración

SINOPSIS

#include <pcp/pmapi.h>

FILE *pmOpenLog(const char *progname,
const char *logname, FILE *oldstream, int *status);

cc ... -lpcp

DESCRIPCIÓN

pmOpenLog reasigna el flujo de E/S estándar oldstream (normalmente stderr) para que se asocie con el archivo logname.

Si logname no es "-" y el archivo ya existe, se renombrará a logname.prev o se eliminará. Debido a restricciones de permisos, el renombrado o la eliminación pueden no tener éxito, pero en los casos de uso comunes logname.prev contendrá los contenidos de la versión anterior de logname. Luego, se recreará logname si es posible (para asegurar la propiedad y los permisos correctos por parte del llamador de pmOpenLog).

Como caso especial, si logname es "-", no se realiza ningún renombrado, eliminación ni reapertura, y la función simplemente establece status en 1 y devuelve oldstream. Esto es útil cuando el llamador desea diagnósticos en el flujo oldstream (normalmente stderr) en lugar de un archivo, por ejemplo, pmlogger -l- o pmcd -f -l-. Registrar en stderr también es útil para los PMDA en un entorno contenedorizado donde es beneficioso que todos los registros del PMDA se escriban en el flujo stderr de pmcd (y, por lo tanto, a un único destino), ya sea un archivo como pmcd.log o el flujo original heredado del shell.

Al regresar, el valor de la función es el flujo de E/S estándar, posiblemente reemplazando oldstream. En caso de error, el valor de retorno será oldstream sin cambios y status será 0.

Para éxito, status es 1, y se escribe una cabecera estándar en logname: Log for progname on hostname started date and time
y se instala un manejador atexit(3) para escribir el mensaje de postdata en logname: Log finished date and time
cuando el proceso finalice.

progname solo se utiliza para anotar mensajes.

VER TAMBIÉN

atexit(3) y freopen(3).
