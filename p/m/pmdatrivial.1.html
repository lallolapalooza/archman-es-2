PMDATRIVIAL(1) Manual de Comandos Generales PMDATRIVIAL(1)

NOMBRE

pmdatrivial - agente de dominio de métricas de rendimiento trivial (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/trivial/pmdatrivial [-D debug] [-d dominio] [-l logfile] [-U username]

DESCRIPCIÓN

pmdatrivial es el Agente de Dominio de Métricas de Rendimiento (PMDA) más simple posible que exporta una única métrica de rendimiento, el tiempo en segundos desde el 1 de enero de 1970.

El PMDA trivial se distribuye como código fuente y está diseñado para ayudar a los desarrolladores de PMDA.

A continuación se incluye una breve descripción de las opciones de línea de comandos de pmdatrivial:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, el dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, un archivo de registro llamado trivial.log se escribe en el directorio actual de pmcd(1) cuando se inicia pmdatrivial, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en la salida de error estándar en su lugar.
-U
Cuenta de usuario bajo la cual ejecutar el agente. Por defecto, es la cuenta no privilegiada "pcp" en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

INSTALACIÓN

Si desea acceder a los nombres, texto de ayuda y valores de las métricas de rendimiento triviales, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/trivial
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/trivial
# ./Remove

pmdatrivial es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdatrivial
$PCP_PMDAS_DIR/trivial/help
archivo de texto de ayuda predeterminado para las métricas triviales
$PCP_PMDAS_DIR/trivial/Install
script de instalación para el agente pmdatrivial
$PCP_PMDAS_DIR/trivial/Remove
script para deshacer la instalación del agente pmdatrivial
$PCP_LOG_DIR/pmcd/trivial.log
archivo de registro predeterminado para mensajes de error y otra información de pmdatrivial

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación para desarrolladores en lugar de usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
