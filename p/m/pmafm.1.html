PMAFM(1) Manual de comandos generales PMAFM(1)

NOMBRE

pmafm - gestor de folios de archivo Performance Co-Pilot

SINOPSIS

pmafm nombre_folio [comando [arg ...]]

DESCRIPCIÓN

Una colección de uno o más archivos Performance Co-Pilot (PCP) puede combinarse con un archivo de control para producir un folio de archivos PCP. Los folios de archivos se crean usando mkaf(1) o los servicios interactivos de ``modo de grabación'' de clientes PCP como pmchart(1).

pmafm proporciona una serie de servicios que pueden usarse para procesar folios. En particular, proporciona soporte para la ejecución de herramientas PCP utilizando uno o más de los archivos componentes dentro de un folio de archivos.

El folio objetivo se identifica mediante el archivo de control del folio nombre_folio. La sintaxis de un archivo de control de folio se describe en mkaf(1).

Si están presentes, el comando y los argumentos que siguen a nombre_folio se interpretan y ejecutan como un solo comando; de lo contrario, los comandos se leen de la entrada estándar.

Los siguientes comandos son compatibles.

archivos
Los comandos subsiguientes se aplican a todos los archivos del folio.
archivos N[,...]
Los archivos dentro de un folio se numeran 1, 2, etc. Los comandos subsiguientes se restringen a aplicarse solo a los archivos designados.
archivos nombre[,...]
Los archivos dentro de un folio tienen nombres únicos. Los comandos subsiguientes se restringen a aplicarse solo a los archivos designados.
comprobar
Valida la presencia y el formato de cada archivo en el folio y los archivos componentes.
ayuda

Un breve recordatorio de la sintaxis del comando. ? es un sinónimo de ayuda.
hosts

Los comandos subsiguientes se aplican a todos los archivos del folio.
hosts nombre_host[,...]
Los comandos subsiguientes se restringen a aplicarse solo a aquellos archivos que coincidan con los nombres de host designados.
listar [verboso]
Muestra el contenido del folio. Por defecto, la cabecera de control y el número ordinal, nombre de host y nombre base del archivo de cada archivo en el folio. La opción verboso hace que pmafm vuelque el registro de etiquetas de cada archivo usando pmlogdump -l.
El primer archivo nombrado en el folio se asume asociado con el host predeterminado para cualquier herramienta que intente reproducir varios archivos del folio.
salir

Sale de pmafm.
eliminar

Muestra en la salida estándar los comandos de sh(1) necesarios para eliminar todos los archivos físicos asociados con este folio de archivos.
repetir herramienta [arg ...]
Ejecuta la herramienta PCP conocida una vez por archivo seleccionado. Por ejemplo, el comando
repetir pmval -t60 kernel.all.load
ejecutaría pmval(1) una vez por archivo, con un argumento apropiado -a.
reproducir

Algunos folios de archivos son creados por herramientas (por ejemplo, pmchart(1)) que proporcionan información suficiente para permitir que toda la información de todos los archivos de un folio se reproduzca.
[ejecutar] herramienta [arg ...]
Ejecuta la herramienta PCP conocida en los archivos seleccionados. Algunas herramientas PCP son capaces de procesar múltiples archivos concurrentes, y en este caso la herramienta se ejecuta una vez con la lista de todos los archivos seleccionados pasados a través de un argumento -a. De lo contrario, este comando es sinónimo de repetir.
selecciones
Muestra los archivos que serían seleccionados para el procesamiento con un comando repetir, reproducir o ejecutar.

Las restricciones a través de cualquier comando hosts y archivos se combinan. Estas restricciones sirven para limitar los archivos específicos procesados en los comandos subsiguientes repetir, reproducir y ejecutar y selecciones. Por defecto, se seleccionan todos los archivos.

Las palabras clave en los comandos pueden abreviarse siempre que no se introduzca ambigüedad, por ejemplo, ayuda, ayud y ayu son sinónimos, pero a es ambiguo.

ARCHIVOS

$PCP_VAR_DIR/config/pmafm/*
Archivos de control que definen el comportamiento de cada herramienta PCP conocida por pmafm. Esta información puede personalizarse o extenderse; consulte mkaf(1) para obtener documentación sobre la sintaxis y semántica de estos archivos.
$HOME/.pcp/pmafm/*
Personalización por el usuario de los archivos de control. Todos los archivos en este directorio se tratan de la misma manera que los archivos de control en el directorio $PCP_VAR_DIR/config/pmafm.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
