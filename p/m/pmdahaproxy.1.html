NOMBRE

pmdahaproxy - Agente de dominio de métricas de HAProxy

DESCRIPCIÓN

pmdahaproxy es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae datos de rendimiento en vivo del socket de estadísticas de HAProxy o de una URL.

Por defecto, se utiliza el socket de estadísticas de HAProxy para obtener la métrica, pero si se configura la opción de URL opcional (ver más abajo), se utiliza la URL de HAProxy en su lugar.

Consulte la documentación de HAProxy para obtener una descripción detallada de cada métrica.

INSTALACIÓN

pmdahaproxy lee un archivo de configuración opcional de estilo ini:

•
$PCP_PMDAS_DIR/haproxy/haproxy.conf

Este archivo puede contener, en su sección [pmda], valores que anulan las siguientes opciones del PMDA:

•
usuario
•
socket

Por defecto, se utilizan root y /var/lib/haproxy/stats como valores para estas opciones, respectivamente.

La sección también puede contener los siguientes parámetros:

  • url
  • auth
  • pass

Cuando se define la opción url, se utiliza la conexión por URL a HAProxy. pmdahaproxy espera datos CSV de la URL de HAProxy; un ejemplo de URL compatible es http://127.0.0.1:9000/?stats;csv.

Tenga en cuenta que el socket de estadísticas y/o la URL de HAProxy deben habilitarse por separado en el archivo de configuración de HAProxy; consulte la documentación de configuración de HAProxy para obtener más detalles. Dependiendo del sistema y la configuración de HAProxy, también puede ser posible utilizar un usuario no root, especialmente con conexiones basadas en URL.

Una vez que la configuración necesaria esté lista, puede probar la conexión e instalar el PMDA para habilitar el acceso a los nombres y valores de las métricas de rendimiento de HAProxy. Para instalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/haproxy
# ./connect
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/haproxy
# ./Remove

pmdahaproxy es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/haproxy/haproxy.conf
archivo de configuración para el agente pmdahaproxy
$PCP_PMDAS_DIR/haproxy/connect
utilidad de prueba de conexión que utiliza la configuración del agente pmdahaproxy
$PCP_PMDAS_DIR/haproxy/Install
script de instalación para el agente pmdahaproxy
$PCP_PMDAS_DIR/haproxy/Remove
script para deshacer la instalación del agente pmdahaproxy
$PCP_LOG_DIR/pmcd/haproxy.log
archivo de registro predeterminado para mensajes del agente pmdahaproxy

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
