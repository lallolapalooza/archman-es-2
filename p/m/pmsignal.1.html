PMSIGNAL(1) Manual de comandos generales PMSIGNAL(1)

NOMBRE

pmsignal - enviar una señal a uno o más procesos

SINOPSIS

$PCP_BINADM_DIR/pmsignal [-alnp] [-s señal] [PID ...|nombre ...]

DESCRIPCIÓN

pmsignal proporciona un mecanismo de señalización de eventos multiplataforma para su uso con herramientas del conjunto de herramientas Performance Co-Pilot. Se puede utilizar para enviar una señal con nombre (solo se aceptan HUP, USR1, TERM y KILL) a uno o más procesos.

Los procesos se especifican directamente usando PIDs o como nombres de programa (con las opciones -a o -p). En el caso all, se busca en el conjunto de todos los procesos en ejecución una coincidencia de basename(1) con nombre. En el caso program, los identificadores de proceso se extraen de archivos en el directorio $PCP_RUN_DIR donde los nombres de archivo coinciden con nombre.pid.

La opción -n informa la lista de identificadores de proceso que habrían sido señalados, pero en realidad no se envían señales.

Si no se especifica una señal, se enviará la señal TERM. La lista de señales compatibles se informa al usar la opción -l.

En las plataformas Linux y UNIX, pmsignal es un simple envoltorio para el comando kill(1). En Windows, no existe un equivalente directo a este mecanismo, por lo que se ha implementado un mecanismo alternativo; sin embargo, esto solo lo respetan las herramientas de PCP, no todas las utilidades de Windows.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a, --all
Enviar señal a todos los procesos nombrados.
-l, --list
Listar señales compatibles.
-n, --dry-run
Listar procesos que se verían afectados.
-p, --program
Extraer programas de los archivos PID de ejecución de PCP.
-s señal, --signal=señal
Especificar la señal a enviar, una de: HUP, USR1, TERM, KILL.
-?, --help
Mostrar mensaje de uso y salir.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

basename(1), kill(1), killall(1), pcp.conf(5) y pcp.env(5).
