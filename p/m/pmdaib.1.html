PMDAIB(1) Manual de comandos generales PMDAIB(1)

NOMBRE

pmdaib - Agente de dominio de métricas de rendimiento de Infiniband (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/infiniband/pmdaib [-c archivo_config] [-D debug] [-d dominio] [-l archivo_log] [-w]

DESCRIPCIÓN

pmdaib es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta información y métricas de rendimiento de los HCA Infiniband locales y GUIDs de Infiniband locales o remotos.

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdaib:

-c
Ubicación del archivo de configuración. Por defecto, el archivo de configuración se llama $PCP_PMDAS_DIR/infiniband/config. Consulte ARCHIVO DE CONFIGURACIÓN para obtener más información.
-d
Especifica un número de dominio de métricas de rendimiento alternativo. Casi nunca es necesario.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado ib.log en $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se envía al error estándar.
-w
Escribe el archivo de configuración por defecto en $PCP_PMDAS_DIR/infiniband y sale inmediatamente. El archivo de configuración escrito contendrá los puertos HCA locales. No sobrescribirá un archivo existente. Este argumento solo debe usarse para crear el archivo de configuración de plantilla y nunca debe aparecer en pmcd.conf. Consulte ARCHIVO DE CONFIGURACIÓN para obtener más información sobre el formato del archivo y sobre el monitoreo de GUIDs remotos.

ARCHIVO DE CONFIGURACIÓN

Por defecto, el PMDA operará sin usar un archivo de configuración. En este modo de operación, se monitorearán los puertos HCA locales. Tenga en cuenta que si se agrega un nuevo HCA a la máquina, el nombre de instancia puede cambiar, ya que siempre se basará en la nomenclatura del kernel.

En casos donde esto no sea aceptable, o en el caso de monitorear puertos Infiniband remotos, se debe crear un archivo de configuración. Se puede crear un archivo de "plantilla" ejecutando el demonio pmdaib con el argumento -w. Esto creará un archivo de configuración con los puertos y GUIDs locales.

Si el archivo de configuración es ejecutable, se ejecutará y la salida se usará como archivo de configuración.

El archivo de configuración se compone de registros basados en líneas. Las líneas en blanco y todo lo que sigue al carácter de hash (#) se ignoran. Cada línea tiene 6 campos:

[nombreInst] [guidPuerto] [numPuerto] vía [nombrePuertoLocal]:[numPuertoLocal]

El primer campo se utiliza para asignar un nombre de instancia estático al puerto Infiniband que tiene un GUID específico. Todos los demás campos deben especificarse correctamente para monitorear un puerto particular.

Por ejemplo, para monitorear el puerto 1 del HCA local llamado 'mthca0', una posible línea de archivo de configuración sería:

miPuerto1 0xdeadbeef01234567 1 via mthca0:1

Los puertos remotos se pueden monitorear fácilmente especificando el GUID del HCA o el switch y el número de puerto remoto. La tupla nombrePuertoLocal:numPuertoLocal especifica qué HCA y puerto local se utilizarán como el "primer salto" para contactar el GUID remoto. Por ejemplo, para monitorear el puerto 13 de un switch remoto que está conectado a la red en el primer puerto del segundo HCA:

switch13 0xfeeffeefabcdabcd 13 via mthca1:1

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
