PMQUERY(1) Manual de comandos generales PMQUERY(1)

NOMBRE

pmconfirm, pmmessage, pmquery - caja de diálogo de propósito general

SINOPSIS

pmconfirm [-c] [-b nombre-botón] [-B nombre-botón-predeterminado] [-t cadena] [-file nombre-archivo] [-icon tipo-icono] [-font fuente] [-header cadena-barra-título] [-useslider] [-noslider] [-noframe] [-exclusive]

pmmessage [-buttons etiqueta1[:valor1][,etiqueta2[:valor2][,...]]] [-center] [-nearmouse] [-default botón] [-file nombre-archivo] [-print] [-timeout seg] mensaje...

pmquery [-input] [todas las opciones anteriores...] [mensaje...]

DESCRIPCIÓN

pmquery proporciona una implementación compatible con opciones de línea de comandos de las herramientas xconfirm y xmessage, utilizando una apariencia coherente con pmchart. Se han realizado varias extensiones a la funcionalidad de las herramientas originales, para mejorar su utilidad específica para pmchart, pero siempre que sea posible, se mantienen las semánticas originales.

pmconfirm muestra una línea de texto por cada opción -t especificada (o un archivo cuando se usa la opción -file), y un botón por cada opción -b especificada. Cuando se presiona uno de los botones, la etiqueta de ese botón se escribe en la salida estándar de pmquery. Esto proporciona un medio de comunicación/retroalimentación desde scripts de shell y un medio para mostrar información útil a un usuario desde una aplicación.

pmmessage muestra una ventana que contiene un mensaje desde la línea de comandos, un archivo o la entrada estándar. Adicionalmente, permite asociar botones con un estado de salida, y solo opcionalmente escribirá la etiqueta del botón en la salida estándar.

pmquery extiende las herramientas anteriores para admitir además una entrada de usuario limitada, como texto libre. En este modo -input, cualquier texto ingresado se mostrará cuando se presione el botón predeterminado. Se puede ingresar un texto predeterminado utilizando los mismos mecanismos que las otras herramientas.

Las opciones de línea de comandos están disponibles para especificar el estilo de fuente, el estilo del marco, la modalidad y uno de varios iconos diferentes para presentar una retroalimentación visual personalizada al usuario.

OPCIONES

Las opciones de línea de comandos disponibles son:

-c, -center
Centra la ventana en la pantalla.
-nearmouse
Muestra la ventana cerca del cursor del ratón.
-b nombre-botón
Muestra un botón con la etiqueta nombre-botón. Si nombre-botón es una cadena vacía, el botón en esa posición no se muestra. Si no hay opciones -b presentes, la predeterminada es un botón con la etiqueta Continuar. El estado de salida asociado con nombre-botón es cero.
-B nombre-botón
Muestra un botón con la etiqueta nombre-botón y lo especifica como el botón que se activará al presionar enter. El estado de salida asociado con nombre-botón es cero.
-buttons botón,botón,...
Esta opción creará un botón por cada opción botón separada por comas. Cada botón consta de una etiqueta seguida opcionalmente por dos puntos y un valor de salida. El valor de salida se devolverá si se selecciona ese botón. El valor de salida predeterminado es 100 más el número del botón. Los botones se numeran de izquierda a derecha comenzando con uno.
-default etiqueta
Define el botón con una etiqueta coincidente como el predeterminado. Si no se especifica, no hay predeterminado. El recurso correspondiente es defaultButton. Al presionar Intro en cualquier lugar de la ventana de xmessage se activará el botón predeterminado. El botón predeterminado tiene un borde más ancho que los demás.
-t mensaje
Muestra el mensaje. Se puede listar cualquier número de cadenas en la línea de comandos (cada una debe ir precedida de la opción -t).
-file nombre-archivo
Muestra el archivo nombre-archivo. Se ignorarán todas las opciones -t. Un nombre-archivo de `-' lee de la entrada estándar.
-icon tipo-icono
Muestra el icono tipo-icono donde tipo-icono es uno de: info, error, question, warning, critical. action también se acepta como sinónimo de error para compatibilidad con versiones anteriores. pmquery introduce los tipos de iconos adicionales archive y host, así como los tipos originales de xconfirm mencionados anteriormente.
-font nombre-fuente
Usa nombre-fuente como fuente. Esta opción solo está disponible cuando se usa el sistema de ventanas X.
-header cadena
Usa cadena como título de la ventana.
-print
Esto hace que el programa escriba la etiqueta del botón presionado en la salida estándar. Es el comportamiento predeterminado para pmconfirm y pmquery.
-noprint
Esto hace que el programa no escriba la etiqueta del botón presionado en la salida estándar. Es el comportamiento predeterminado para pmmessage.
-geometry cadena-geometría
Esto proporciona a la herramienta una especificación de cadena de geometría compatible con X. Esta opción solo está disponible cuando se usa el sistema de ventanas X.
-useslider
Al mostrar un archivo, siempre usa un deslizador en lugar de determinar automáticamente si es necesario un deslizador.
-noslider
No crea un deslizador y recorta el texto al tamaño de la ventana, en lugar de determinar automáticamente si es necesario un deslizador.
-noframe
No muestra un marco alrededor del contenido.
-exclusive
Captura el teclado/puntero y no permite más entrada hasta que se presione un botón.
-timeout seg
Sale con el estado 0 después de seg segundos si el usuario aún no ha hecho clic en un botón. El recurso correspondiente es timeout.
-?, -h, -help
Muestra el mensaje de uso y sale.

EJEMPLOS

El siguiente script de shell mostrará una ventana con un icono de información, haciendo al usuario una pregunta de sí o no con "Sí" como predeterminado.

 #! /bin/sh
 case `pmquery -t "¿Realmente apagar?" -b No -B Yes -icon question
 in
   Yes) shutdown;;
   No) ;;
 esac

Un segundo ejemplo, que solicita un nombre de host y luego inicia un terminal con una sesión ssh conectada al host solicitado.

 #! /bin/sh
 host=`pmquery -input -icon host -b Cancel -B OK \
               -header "Terminal Remoto - Secure Shell"
 [ "$host" = "Cancel" -o -z "$host" ] && exit
 gnome-terminal -e "ssh $host"

ENTORNO

pmquery es una excelente opción de utilidad para el parámetro de configuración PCP_XCONFIRM_PROG de Performance Co-Pilot (consulte pcp.conf(5) para más detalles).

Tenga en cuenta que PCP_XCONFIRM_PROG se establecerá automáticamente en pmquery dentro de herramientas como pmchart, a menos que PCP_XCONFIRM_PROG ya esté establecido en el entorno.

ESTADO DE SALIDA

Si detecta un error, pmquery siempre devuelve 1, por lo que este valor no debe asociarse con un botón. A menos que no se haya utilizado la opción -button, el código de retorno será cero en caso de éxito.
