PMHOSTNAME(1) Manual de Comandos Generales PMHOSTNAME(1)

NOMBRE

pmhostname - reportar nombre de host

SINOPSIS

pmhostname [-D depuracion] [-?] [nombrehost]

DESCRIPCIÓN

pmhostname reporta el nombre del host nombrehost tal como lo devuelve gethostbyname(3).

Si no se especifica nombrehost, entonces se recupera el nombre del host local usando gethostname(2) y este se pasa a gethostbyname(3).

pmhostname proporciona un servicio para scripts de shell que imita la lógica utilizada anteriormente por las aplicaciones Performance Co-Pilot al intentar determinar el nombre oficial de un host. Las aplicaciones de PCP ya no utilizan heurísticas basadas en DNS, y por lo tanto, este comando está obsoleto.

Si gethostbyname(3) falla, se reporta el nombre de host de entrada (ya sea nombrehost o el resultado de llamar a gethostname(2)).

OPCIONES

Las opciones de línea de comandos disponibles son:

-?, --help
Muestra el mensaje de uso y sale.

AMBIENTE PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. depuracion es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmhostname son las siguientes:

Opción Descripción
appl0 diagnósticos detallados, por ejemplo, resultado de llamar a gethostname(2) y rutinas PMAPI
