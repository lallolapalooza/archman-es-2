PMNOTIFYERR(3) Manual de funciones de biblioteca PMNOTIFYERR(3)

NOMBRE

pmNotifyErr, pmSyslog - manejo estándar de mensajes de error

S SINTAXIS

#include <pcp/pmapi.h>

void pmNotifyErr(int prioridad, const char *mensaje, ...);
void pmSyslog(int onoff);

cc ... -lpcp

DESCRIPCIÓN

Estas rutinas proporcionan un manejo estándar de mensajes de error desde el interior de los demonios de Performance Co-Pilot (PCP) y los Agentes de Dominio de Métricas de Rendimiento (PMDAs).

pmNotifyErr es una función estilo printf(3) que formateará mensaje (y cualquier argumento subsiguiente) con un prefijo que incluye la fecha y hora actuales de ctime(3), el nombre de la aplicación de pmGetProgname(3), el ID del proceso de getpid(2) y la prioridad.

prioridad debe ser uno de los macros de nivel LOG_ definidos para syslog(3). Lo más habitual sería LOG_INFO, LOG_WARNING o LOG_ERR.

pmNotifyErr escribe en la salida de error estándar, que para demonios y PMDAs probablemente ha sido redirigida a un archivo de registro usando pmOpenLog(3). Adicionalmente, mensaje (y cualquier argumento subsiguiente) puede ser reenviado a syslog(3) si pmSyslog ha sido llamado previamente con onoff teniendo un valor distinto de cero.

El reenvío a syslog(3) puede ser deshabilitado en cualquier momento llamando a pmSyslog con onoff teniendo un valor cero, y este es el estado inicial para cada aplicación PCP.

Al estilo de syslog(3), mensaje no necesita incluir un carácter de nueva línea de terminación (se añadirá uno si es necesario).

VER TAMBIÉN

getpid(2), ctime(3), PMAPI(3), pmGetProgname(3), pmOpenLog(3), printf(3) y syslog(3).
