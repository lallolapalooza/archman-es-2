PMDASOCKETS(1) Manual de Comandos Generales PMDASOCKETS(1)

NOMBRE

pmdasockets - PMDA de estadísticas de sockets

SINOPSIS

$PCP_PMDAS_DIR/sockets/pmdasockets [-D depuración]

DESCRIPCIÓN

pmdasockets es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos para los sockets actuales en el sistema local.

Actualmente, este PMDA recopila sus datos a través de la utilidad ss(8) y requiere que el programa esté instalado para funcionar. Esta dependencia puede cambiar en el futuro.

INSTALACIÓN

Para instalar (habilitar) el PMDA de sockets, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sockets
# ./Install

Para desinstalar (deshabilitar), haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sockets
# ./Remove

pmdasockets es iniciado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

CONFIGURACIÓN DEL FILTRO

La métrica de tipo cadena network.persocket.filter especifica el filtro de ss(1) que se aplicará para seleccionar opcionalmente estados de sockets, direcciones IP y otras opciones que pmdasockets recopilará (para poblar su dominio de instancia). Esto se carga al inicio del PMDA desde el archivo $(PCP_SYSCONF_DIR)/sockets/filter.conf (típicamente /etc/pcp/sockets/filter.conf) y por defecto es state connected, lo que significa que solo se incluirán los sockets en estado connected. Esto se puede cambiar de forma persistente editando filter.conf como usuario root. El filtro también se puede cambiar dinámicamente después de que el PMDA haya comenzado utilizando pmstore(1) para almacenar una nueva cadena de filtro en la métrica network.persocket.filter. Por ejemplo, 

# pmstore network.persocket.filter "state all"

cambiará el filtro para incluir sockets en todos los estados. Tenga en cuenta que un filtro almacenado dinámicamente no persiste después de reinicios del PMDA o reinicios del sistema (edite el archivo de configuración para un cambio persistente). Para más detalles sobre la sintaxis y las opciones del filtro, consulte ss(8).

CONFIGURACIÓN DEL REGISTRO

El archivo de configuración de pmlogconf(1) para pmdasockets es $PCP_VAR_DIR/config/pmlogconf/networking/persocket-linux (donde $PCP_VAR_DIR es típicamente /var/lib/pcp) que especifica registrar todas las métricas debajo de network.persocket en el espacio de nombres de PCP con un intervalo de muestreo predeterminado de 60 segundos. El intervalo de registro y las métricas a registrar se pueden cambiar editando ese archivo y luego reiniciando el servicio pmlogger. Para ver detalles de la sintaxis, consulte pmlogconf(1).

MÉTRICAS

Las métricas y metadatos soportados por pmdasockets corresponden a los campos reportados por ss -noemitauOH y también están disponibles como texto de ayuda proporcionado por el PMDA, por ejemplo, para listar todas las métricas, descriptores de metadatos y texto de ayuda: 

# pminfo -fmdtT network.persocket

Tenga en cuenta que el PMDA debe estar instalado (habilitado) para que este comando funcione correctamente, vea arriba.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. depuración es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdasockets son las siguientes:

Opción Descripción
appl0 carga del filtro de estado del socket desde $PCP_SYSCONF_DIR/filter.conf y fuente de datos
appl1 análisis de la salida de la fuente de datos

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmlogger(1) y ss(8).
