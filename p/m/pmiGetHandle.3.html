pmiGetHandle(3)

Paquete: pcp

PMIGETHANDLE() PMIGETHANDLE()

NOMBRE

pmiGetHandle - define un identificador para un par métrica-instancia

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiGetHandle(const char *name, const char *instance);

cc ... -lpcp_import -lpcp

SINOPSIS Perl

use PCP::LogImport;

$handle = pmiGetHandle($name, $instance);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiGetHandle crea un identificador para una métrica e instancia dadas. El identificador se devuelve como valor de la llamada pmiGetHandle y puede usarse en llamadas posteriores a pmiPutValueHandle(3).

El nombre de la métrica debe coincidir con uno definido previamente en una llamada a pmiAddMetric(3).

Para métricas singulares (aquellas definidas con un dominio de instancia de PM_INDOM_NULL), instance debe ser NULL o una cadena vacía, de lo contrario, instance debe coincidir con el nombre de una instancia definida previamente en una llamada a pmiAddInstance(3) para el dominio de instancia de la métrica.

Cuando se combina con pmiPutValueHandle(3), el uso de identificadores proporciona una mejora de rendimiento sobre la búsqueda alternativa del nombre de una métrica y el nombre de una instancia para cada valor de datos que se requiere para pmiPutValue(3).

DIAGNÓSTICOS

En caso de fallo, pmiGetHandle devuelve un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3) y pmiPutValueHandle(3).
