PMDAOVERHEAD(1) Manual de Comandos Generales PMDAOVERHEAD(1)

NOMBRE

pmdaoverhead - agente de dominio de métricas de rendimiento (PMDA) que exporta el consumo de recursos para grupos de procesos

SINOPSIS

$PCP_PMDAS_DIR/overhead/pmdaoverhead [-C] [-c config] [-D debug] [-d dominio] [-l logfile] [-R intervalo]

DESCRIPCIÓN

pmdaoverhead es un Agente de Dominio de Métricas de Rendimiento (PMDA) configurable para exportar el consumo de recursos de grupos de procesos relacionados.

Las opciones de línea de comandos de pmdaoverhead son:

-C
analiza el(los) archivo(s) de configuración y sale después de informar cualquier error.
-c
archivo(s) de configuración, config puede ser un archivo o un directorio; en este último caso, se asume que todos los archivos dentro de config son archivos de configuración para pmdaoverhead y todos serán procesados.

Cada archivo de configuración define uno o más ``grupos'' de procesos de interés, utilizando la sintaxis descrita en la sección ``CONFIGURACIÓN'' a continuación.

Por defecto, se utilizan todos los archivos de configuración debajo del directorio $PCP_SYSCONF_DIR/overhead/conf.d/.

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado overhead.log en el directorio actual de pmcd(1) cuando se inicia pmdaoverhead, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.
-R
El PMDA utiliza un hilo separado para escanear periódicamente todos los procesos para determinar qué procesos se consideran ``interesantes'' en cada grupo, y extraer el consumo de recursos de esos procesos. El intervalo (en segundos) determina la frecuencia con la que se realiza este escaneo y cálculo de recursos, el valor predeterminado es 60 (segundos).

CONFIGURACIÓN

Cada archivo de configuración define uno o más ``grupos'' de procesos. El formato del archivo es simple y sigue las siguientes reglas.

1.
Las líneas que comienzan con una almohadilla ``#'' se tratan como comentarios. Más generalmente, excepto para la cláusula pattern: descrita a continuación, todo el texto entre una almohadilla y el final de línea se trata como un comentario.
2.
Se requieren espacios en blanco (espacios o tabulaciones o saltos de línea) para separar los componentes léxicos. Los espacios y tabulaciones se ignoran de lo contrario. Aparte de terminar comentarios y el regex en una cláusula pattern:, los saltos de línea también se ignoran.
3.
Cada grupo se introduce con una cláusula group que tiene el formato
group nombre { parámetros }
donde nombre es un nombre único para el grupo en todos los grupos en los archivos de configuración de pmdaoverhead. Como nombre se incrusta en el Espacio de Nombres de Métricas de Rendimiento (PMNS), debe seguir las reglas para los componentes de nombres de métricas, como se describe en PMNS(5), es decir, comenzar con un carácter alfabético, seguido de cero o más caracteres extraídos de los alfabéticos, numéricos y el carácter de subrayado ``_''.
4.
Los parámetros deben incluir una cláusula id: y una cláusula pattern:.
5.
Una cláusula id: tiene el formato
id: identificador
donde identificador es un número de identificador único para el grupo en todos los grupos en los archivos de configuración de pmdaoverhead. Los valores válidos para identificador están en el rango de 0 a 4094 (inclusive).
6.
Una cláusula pattern: tiene el formato
pattern: regex
donde regex es una notación de expresión regular extendida al estilo de egrep(1). El regex comienza en el primer carácter que no sea un espacio en blanco después de pattern: y se extiende hasta el siguiente salto de línea.

Los procesos que se consideran miembros del grupo son aquellos para los cuales el nombre del comando, tal como lo informa
$ pminfo -f proc.psinfo.cmd
coincide con el regex más todos los descendientes de esos procesos. Así, por ejemplo, el regex ^pmcd$ coincidirá con pmcd(1) y todos los procesos PMDA iniciados por pmcd(1) y cualquiera de sus hijos, etc.

INSTALACIÓN

Si desea acceso a los nombres, texto de ayuda y valores de las métricas de rendimiento de sobrecarga, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/overhead
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/overhead
# ./Remove

pmdaoverhead es lanzado por pmcd y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdaoverhead
$PCP_PMDAS_DIR/overhead/Install
script de instalación para el agente pmdaoverhead
$PCP_PMDAS_DIR/overhead/Remove
script para deshacer la instalación del agente pmdaoverhead
$PCP_LOG_DIR/pmcd/overhead.log
archivo de registro predeterminado para mensajes de error y otra información de pmdaoverhead
$PCP_SYSCONF_DIR/overhead/conf.d
directorio que contiene archivos de configuración para las métricas de sobrecarga

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a resolver problemas, aunque la información a veces es críptica y está destinada principalmente a brindar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdaoverhead son las siguientes:

Opción Descripción
appl0 Análisis del archivo de configuración (configfile)
appl1 Marcas de tiempo de inicio y fin de refresh()
appl2 Selección de /proc en refresh()
