PMISETTIMEZONE(3) Manual de funciones de biblioteca PMISETTIMEZONE(3)

NOMBRE

pmiSetTimezone - establece la zona horaria de origen para un archivo LOGIMPORT

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiSetTimezone(const char *value);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiSetTimezone($value);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiSetTimezone establece la zona horaria de origen en el contexto actual a value.

En ausencia de una llamada a pmiSetTimezone, la zona horaria de origen se establece por defecto a la zona horaria de la máquina local.

DIAGNÓSTICOS

pmiSetTimezone devuelve cero si tiene éxito, de lo contrario, un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiErrStr(3), pmiSetHostname(3), pmiSetVersion(3) y pmiStart(3).
