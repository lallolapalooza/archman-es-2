PMDARSYSLOG(1) Manual de comandos generales PMDARSYSLOG(1)

NOMBRE

pmdarsyslog - PMDA de rsyslog (syslog confiable y extendido)

DESCRIPCIÓN

pmdarsyslog es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos del servidor rsyslogd(8).

Se pueden encontrar más detalles sobre rsyslog en http://www.rsyslog.com/.

INSTALACIÓN

Si desea acceso a los nombres y valores de las métricas de rendimiento de rsyslog, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/rsyslog
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/rsyslog
# ./Remove

pmdarsyslog es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

Para poder usar este agente, la recopilación de estadísticas de rsyslog debe estar habilitada. Esto se hace añadiendo las líneas:

module(load="impstats" interval="10" severity="7")
if $syslogtag contains 'rsyslogd-pstats' then {
    action(
        name="pstats-for-pcp"
        type="ompipe"
        template="RSYSLOG_FileFormat"
        pipe="/var/log/pcp/rsyslog/stats"
    )
    stop
}

a su archivo de configuración de rsyslog.conf(5) después de instalar el PMDA.

ARCHIVOS

$PCP_LOG_DIR/rsyslog/stats
tubería con nombre que contiene estadísticas exportadas de rsyslog, generalmente creada por el script de instalación del PMDA.
$PCP_PMDAS_DIR/rsyslog/rsyslog.conf
archivo de configuración opcional para pmdarsyslog
$PCP_PMDAS_DIR/rsyslog/Install
script de instalación para el agente pmdarsyslog
$PCP_PMDAS_DIR/rsyslog/Remove
script para deshacer la instalación del agente pmdarsyslog
$PCP_LOG_DIR/pmcd/rsyslog.log
archivo de registro predeterminado para mensajes de error de pmdarsyslog

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1) y rsyslogd(1).
