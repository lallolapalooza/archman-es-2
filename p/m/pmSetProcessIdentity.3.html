NOMBRE

pmSetProcessIdentity - establecer la identificación de usuario y grupo del proceso

SINOPSIS C

#include <pcp/pmapi.h>

int pmSetProcessIdentity(const char *username);

cc ... -lpcp

DESCRIPCIÓN

pmSetProcessIdentity proporciona un método independiente de la plataforma para establecer el ID de usuario de un proceso al que coincide con username.

Si es posible (cuando el llamador ya se está ejecutando como root) pmSetProcessIdentity establecerá el ID de grupo del proceso al del usuario coincidente, por ejemplo, usando username y getpwnam(3).

Un valor de retorno de 0 indica éxito, de lo contrario, el valor de retorno es un código de error que puede ser decodificado con pmErrStr(3).

pmSetProcessIdentity se utiliza con mayor frecuencia junto con pmGetUsername(3) al inicio del proceso.

VER TAMBIÉN

getpwnam(3), PMAPI(3), pmErrStr(3), pmGetUsername(3), setgid(3) y setuid(3).
