PMSEARCHTEXTINDOM(3) Manual de funciones de biblioteca PMSEARCHTEXTINDOM(3)

NOMBRE

pmSearchTextInDom - buscar todas las entidades relacionadas con el dominio de instancia dado

S C SINTAXIS

#include <pcp/pmwebapi.h>

int pmSearchTextInDom(pmSearchSettings *settings,
pmSearchTextRequest *request, void *arg);

cc ... -lpcp_web

DESCRIPCIÓN

Ejecuta una búsqueda de todas las métricas, instancias y dominios de instancia, que están relacionados con el dominio de instancia dado según se especifica en request:

consulta
Dominio de instancia de destino.
cantidad
Limita el número de resultados. Por defecto es 10.
desplazamiento
Desplazamiento de la búsqueda. Por defecto es 0.

Los resultados se ordenan por tipo en orden ascendente.

Cada entidad que coincida con el request anterior se pasará a la devolución de llamada on_text_result proporcionada por settings.

DIAGNÓSTICOS

Esta función siempre devuelve cero si tiene éxito. En caso de error, se devuelve un código de error PMAPI negativo.

VER TAMBIÉN

pmproxy(1), pmlogger(1), pmsearch(1), pmSearchSetup(3), PMAPI(3) y PMWEBAPI(3).
