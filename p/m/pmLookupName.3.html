PMLOOKUPNAME(3) Manual de funciones de la biblioteca PMLOOKUPNAME(3)

NOMBRE

pmLookupName - traducir nombres de métricas de rendimiento a PMIDs

C SINOPSIS

#include <pcp/pmapi.h>

int pmLookupName(int numpmid,
const char **namelist, pmID *pmidlist);

cc ... -lpcp

DESCRIPCIÓN

Dada una lista en namelist que contiene numpmid nombres completos de métricas de rendimiento de un Espacio de Nombres de Métricas de Rendimiento (PMNS), pmLookupName devuelve la lista de Identificadores de Métricas de Rendimiento (PMIDs) asociados a través de pmidlist.

El resultado de pmLookupName depende de la presencia de cualquier fallo de búsqueda, su gravedad y el número de métricas que se están buscando.

1.
Si no hay fallos de búsqueda, el valor de retorno será numpmid.
2.
Si se encuentra un error fatal, el valor de retorno será menor que 0. Por ejemplo PM_ERR_TOOSMALL, PM_ERR_NOPMNS o PM_ERR_IPC.
3.
Si numpmid es mayor que uno y se encuentran errores no fatales, el valor de retorno es el número de nombres de métricas que se han buscado con éxito (mayor o igual que cero y menor o igual que numpmid).
4.
Si numpmid es uno y se encuentra un error no fatal, el valor de retorno es el código de error (menor que cero).

Cuando se encuentran errores, cualquier métrica que no se pueda buscar resulta en que el elemento correspondiente de pmidlist se establezca en PM_ID_NULL.

El protocolo de error ligeramente complicado permite búsquedas en lotes, y luego la indagación de más detalles de error en caso de un fallo específico, como se muestra en la sección EJEMPLO a continuación.

Tenga en cuenta que el protocolo de error garantiza que existe una relación 1:1 entre los elementos de namelist y pmidlist, por lo tanto, ambas listas contienen exactamente numpmid elementos. Por esta razón, se espera que el llamador haya preasignado una matriz de tamaño adecuado para pmidlist.

EJEMPLO

#include <pcp/pmapi.h>
#define NUMPMID (sizeof(names)/sizeof(const char *))
const char *names[] = {
		     "sample.bin",
		     "sample",
		     "sample.bog",
		     "sample.secret.bar",
		     "sample.secret.bar.bad"
		   };
pmID pmids[NUMPMID];
int
main(int argc, char **argv)
{
    int	sts;
    int	numpmid = NUMPMID;
    pmNewContext(PM_CONTEXT_HOST, "local:");
    sts = pmLookupName(numpmid, names, pmids);
    if (sts < 0) {
	fprintf(stderr, "pmLookupName falló: %s0, pmErrStr(sts));
	exit(1);
    }
    if (sts != numpmid) {
	/*
	 * algunas de las búsquedas fallaron ... informa los motivos
	 */
	int	i;
	for (i = 0; i < numpmid; i++) {
	    if (pmids[i] != PM_ID_NULL) continue;
	    /* esta falló */
	    sts = pmLookupName(1, &names[i], &pmids[i]);
	    fprintf(stderr, "%s: búsqueda fallida: %s0, names[i], pmErrStr(sts));
	}
	exit(1);
    }
    /* todo bien ... */
    ...
}

DIAGNÓSTICOS

PM_ERR_TOOSMALL
numpmid debe ser al menos 1
PM_ERR_NOPMNS
No se pudo acceder a un PMNS para la operación. Tenga en cuenta que si la aplicación no ha llamado previamente a pmLoadNameSpace(3) y desea utilizar el PMNS distribuido, entonces se debe realizar una llamada a pmLookupName después de la creación de un contexto (consulte pmNewContext(3)).
PM_ERR_NAME
namelist[0] no corresponde a un nombre de métrica válido en el PMNS.
PM_ERR_NONLEAF
namelist[0] se refiere a un nodo en el PMNS pero no era un nodo hoja.
PM_ERR_*
Otros diagnósticos son para fallos de protocolo al acceder al PMNS distribuido.
