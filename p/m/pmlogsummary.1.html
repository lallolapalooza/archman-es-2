NOMBRE

pmlogsummary - calcula promedios de métricas almacenadas en un conjunto de archivos PCP

SINOPSIS

pmlogsummary [-abfFHiIlmMNsvVxyz?] [-B nbins] [-D debug] [-n pmnsfile] [-p precision] [-S starttime] [-T endtime] [-Z timezone] archivo [nombre_metrica ...]

DESCRIPCIÓN

pmlogsummary imprime información estadística sobre métricas de tipo numérico contenidas en los archivos de un conjunto de archivos de Performance Co-Pilot (PCP). La salida por defecto imprime promedios de tiempo tanto para métricas de contador como para métricas que no son de contador. El conjunto de archivos se identifica mediante archivo, que es una lista separada por comas de nombres, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos. Los archivos se crean típicamente usando pmlogger(1).

Las métricas de interés se nombran en los argumentos nombre_metrica. Si nombre_metrica es un nodo no terminal en el Espacio de Nombres de Métricas de Rendimiento (PMNS(5)), entonces pmlogsummary descenderá recursivamente el PMNS e informará sobre todos los nodos terminales. Si no se proporciona ningún argumento nombre_metrica, se usa la raíz del espacio de nombres.

Las métricas con semántica de contador se convierten a tasas antes de ser evaluadas.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a, --all
Imprime toda la información. Esto es equivalente a -blmMy.
-b
Imprime ambas formas de promediación, es decir, promediación estocástica y de tiempo.
-B nbins, --bins=nbins
Imprime la distribución aproximada de valores, utilizando nbins bins para el histograma de forma que el rango de valores (mínimo - máximo) para cada métrica se divide equitativamente en nbins bins, y cada bin acumula la frecuencia de valores observados en el rango correspondiente. Consulte la sección ``FORMATO DE SALIDA'' a continuación para una descripción de cómo se informa la distribución de valores).
-f
Formato de hoja de cálculo: el carácter de tabulación se utiliza para delimitar cada campo impreso. Esta opción está destinada a permitir que la salida de pmlogsummary se importe directamente en aplicaciones de hoja de cálculo comunes.
-F
Formato de hoja de cálculo: el carácter de coma se utiliza para delimitar cada campo impreso. Esta opción está destinada a permitir que la salida de pmlogsummary se importe directamente en aplicaciones de hoja de cálculo comunes que admitan el formato de valores separados por comas (.csv).
-H, --header
Imprime una línea de encabezado al principio que muestra qué representa cada campo.
-i, --mintime
Imprime también la hora en que se registró el valor mínimo. El formato de esta marca de tiempo se describe en la sección ``FORMATO DE SALIDA'' a continuación.
-I, --maxtime
Imprime también la hora en que se registró el valor máximo. El formato de esta marca de tiempo se describe en la sección ``FORMATO DE SALIDA'' a continuación.
-l, --label
Imprime también la etiqueta del archivo, mostrando la versión del formato del archivo, la hora y la fecha del inicio y el final de la ventana de tiempo del archivo, y el host del que se recopilaron los valores de las métricas de rendimiento.
-m, --minimum
Imprime también el valor mínimo registrado para cada métrica.
-M, --maximum
Imprime también el valor máximo registrado para cada métrica.
-n pmnsfile, --namespace=pmnsfile
Carga un Espacio de Nombres de Métricas de Rendimiento (PMNS(5)) alternativo del archivo pmnsfile.
-N
Suprime cualquier advertencia resultante de la obtención individual de archivos (por defecto).
-p precision, --precision=precision
Imprime todos los números de punto flotante con precision dígitos después del punto decimal.
-s, --sum
Imprime (solo) la suma de todos los valores registrados para cada métrica.
-S starttime, --start=starttime
Establece la starttime de la ventana de tiempo. Consulte PCPIntro(1) para una descripción completa de la sintaxis de starttime.
-T endtime, --finish=endtime
Establece la endtime de la ventana de tiempo. Consulte PCPIntro(1) para una descripción completa de la sintaxis de endtime.
-v, --verbose
Informa (detalladamente) sobre las advertencias resultantes de la obtención individual de archivos.
-V, --version
Muestra el número de versión y sale.
-x
Imprime promedios estocásticos en lugar del valor predeterminado (promedios de tiempo).
-y, --samples
Imprime también el número de muestras encontradas en el conjunto de archivos para cada métrica.
-z, --hostzone
Cambia la zona horaria a la zona horaria local en el host que es la fuente de las métricas de rendimiento, como se especifica en el registro de etiqueta del archivo.
-Z timezone, --timezone=timezone
Por defecto, pmlogsummary informa la hora del día según la zona horaria local en el sistema donde se ejecuta pmlogsummary. Cambia la zona horaria a timezone en el formato de la variable de entorno TZ como se describe en environ(7).
-?, --help
Muestra el mensaje de uso y sale.

FORMATO DE SALIDA

El formato de salida de pmlogsummary es espartano ya que está destinado a ser post-procesado con herramientas estándar. Esto significa que no hay anotaciones asociadas a cada campo de salida que dificulten el procesamiento. La intención es que la salida de pmlogsummary se manipule en un formato que pueda ser utilizado por un programa de hoja de cálculo, sea adecuado para su inclusión en una página web, o cualquier otro propósito.

Para cada métrica, pmlogsummary produce una única línea de salida de la siguiente manera:


nombre_metrica  valor(es) unidades

Para métricas con múltiples instancias, pmlogsummary produce múltiples líneas de salida de la siguiente manera:


nombre_metrica ["instancia 1"] valor(es) unidades
nombre_metrica ["instancia 2"] valor(es) unidades
nombre_metrica ["instancia N"] valor(es) unidades

Los valor(es) impresos para cada métrica siempre siguen este orden: promedio estocástico, promedio de tiempo, mínimo, marca de tiempo mínima, máximo, marca de tiempo máxima, conteo, [rango bin 1], conteo bin 1, ... [rango bin nbins], conteo bin nbins. Los valores individuales para cada métrica están separados por espacios (a menos que se use la opción -f).

Todas las métricas de contador que se miden en unidades de tiempo se convertirán a segundos antes de ser convertidas a tasa y utilizadas en los cálculos de pmlogsummary. Los valores calculados para estas métricas también se imprimen en segundos.

Las unidades se mostrarán en el formato descrito por pmUnitsStr(3).

Dado alguna de las opciones -i o -I, pmlogsummary produce dos formatos de marca de tiempo diferentes, dependiendo del intervalo sobre el cual se ejecuta. Para un intervalo mayor a 24 horas, la fecha se muestra además de la hora en que ocurrieron los máximos y/o mínimos. Si la extensión de los datos que se están revisando es menor a 24 horas, se utiliza un formato más preciso (la hora se muestra con precisión de milisegundos, pero sin la fecha).

NOTAS

El promedio para una métrica individual se calcula de la siguiente manera:

Las métricas no contadoras se promedian utilizando promediado estocástico: cada observación tiene el mismo peso en el cálculo del promedio (la suma de todos los valores dividida por el número total de valores, para cada métrica).

Las métricas contadoras se promedian utilizando promediado de tiempo (por defecto), pero la opción -x se puede usar para especificar que los contadores se promedien utilizando el método estocástico en su lugar. Al calcular un promedio de tiempo, la suma del producto de cada valor de muestra multiplicado por la diferencia de tiempo entre cada muestra, se divide por el tiempo total durante el cual se registró esa métrica.

Las métricas contadoras cuyas mediciones no abarcan el 90% del conjunto de archivos se imprimirán con el nombre de la métrica precedido por un asterisco (*).

ARCHIVOS

$PCP_VAR_DIR/pmns/*
archivos de especificación PMNS por defecto
$PCP_LOG_DIR/pmlogger/<hostname>
Directorio por defecto para los archivos PCP que contienen valores de métricas de rendimiento recopilados del host <hostname>.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmlogsummary son las siguientes:

Opción Descripción
appl0 informar métricas en archivo, métricas seleccionadas, valores de métrica-instancia, marcar registros, inicio de la segunda iteración
appl1 detalles de desbordamiento de contador, datos brutos para extremos y promedios
appl2 seguimiento de valores máximos y mínimos
