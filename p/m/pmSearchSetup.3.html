PMSEARCHSETUP(3) Manual de funciones de biblioteca PMSEARCHSETUP(3)

NOMBRE

pmSearchSetup, pmSearchSetSlots, pmSearchSetEventLoop, pmSearchSetConfiguration, pmSearchSetMetricRegistry, pmSearchClose - servicios de búsqueda rápidos, escalables y capaces de texto completo

SINOPSIS C

#include <pcp/pmwebapi.h>

int pmSearchSetup(pmSearchModule *module, void *arg);

int pmSearchSetSlots(pmSearchModule *module, void *slots);
int pmSearchSetEventLoop(pmSearchModule *module, void *events);
int pmSearchSetConfiguration(pmSearchModule *module,
struct dict *config);

int pmSearchSetMetricRegistry(pmSearchModule *module,
struct mmv_registry *registry);

int pmSearchClose(pmSearchModule *module);

cc ... -lpcp_web

DESCRIPCIÓN

pmSearchSetup y las funciones de API relacionadas preparan una aplicación para acceder a la funcionalidad de búsqueda rápida y escalable de métricas, instancias y dominios de instancia, capaz de texto completo, del Performance Co-Pilot (PCP).

Esta funcionalidad se proporciona a través de API asíncronas, que funcionan en modo dirigido por eventos. La interfaz descrita aquí prepara un módulo de búsqueda dado, que asocia rutinas de devolución de llamada con ciertos eventos asíncronos que ocurren como parte del servicio de las solicitudes de búsqueda.

Como patrón general, todas las interfaces en estas API que necesitan invocar callbacks (devoluciones de llamada) proporcionadas por el programa que llama tomarán un parámetro arg opaco (puntero void *). Este puntero se pasará sin cambios y típicamente se usará para acceder a una estructura de datos que mantiene el estado dentro del programa llamador.

Donde pmSearchSetup requiera configuración asíncrona, su finalización se indicará mediante el uso de la devolución de llamada on_setup, que forma parte de la estructura pmSearchModule pasada. Esta estructura también proporciona manejo de diagnósticos personalizados, a través de la devolución de llamada on_info. Estas son autoexplicativas; consulte <pcp/pmwebapi.h> para conocer las convenciones exactas de llamada.

Las callbacks (devoluciones de llamada) registradas por pmSearchSetup para manejar eventos son las siguientes:

pmSearchTextResultCallBack on_text_result
La devolución de llamada se llama una vez por cada elemento del resultado de búsqueda que coincide con un query (consulta) dado pasado por pmSearchTextInDom(3), pmSearchTextQuery(3), pmSearchTextSuggest(3).
pmSearchMetricsCallBack on_metrics
La devolución de llamada se llama para los resultados de una llamada a pmSearchInfo(3).
pmSearchDoneCallBack on_done
Al completar todas las interfaces asíncronas que devuelven éxito (código de retorno cero), se llamará a esta devolución de llamada. Proporciona un código de estado que indica el éxito general (cero) o el fallo (código de error negativo de PMAPI) de la operación.

Las funciones auxiliares pmSearchSetSlots (servidor clave-valor), pmSearchSetEventLoop (libuv), pmSearchSetConfiguration (archivo de configuración) y pmSearchSetMetricRegistry (instrumentación MMV) proporcionan un mecanismo para pasar el estado de cada uno de los subsistemas asociados.

Finalmente, una llamada a pmSearchClose se utiliza para finalizar los servicios disponibles de un módulo de búsqueda previamente establecido a través de pmSearchSetup.

Dentro de PCP, las utilidades pmproxy(1) y pmsearch(1) son los principales usuarios de las interfaces, proporcionando respectivamente servicios de API REST y de búsqueda en línea de comandos.

DIAGNÓSTICOS

Donde estas funciones devuelven un código de estado, este es siempre cero en caso de éxito. En caso de fallo se devuelve un código de error PMAPI negativo.
