pmGetHostName(3)

Paquete: pcp

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMGETCONTEXTHOSTNAME(3) Manual de funciones de biblioteca PMGETCONTEXTHOSTNAME(3)

NOMBRE

pmGetHostName, pmGetContextHostName, pmGetContextHostName_r - devuelve el nombre de host asociado con un contexto de Performance Co-Pilot

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetHostName(int id, char *buf, int buflen);
const char *pmGetContextHostName(int id);
char *pmGetContextHostName_r(int id, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Dado un identificador de contexto PCP válido creado previamente con pmNewContext(3) o pmDupContext(3), la función pmGetContextHostName devuelve el nombre de host asociado con id. La función pmGetContextHostName_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos MAXHOSTNAMELEN bytes. La función pmGetHostName se comporta de manera similar nuevamente, pero devuelve un código de estado para indicar éxito o fracaso.

Si el contexto id está asociado con una fuente de datos de archivo, el nombre de host devuelto se extrae de la etiqueta del archivo utilizando pmGetArchiveLabel(3).

Para contextos en vivo, primero se intentará recuperar el nombre de host del sistema colector PCP utilizando pmFetch(3) con la métrica pmcd.hostname. Esto permite que las herramientas cliente que utilizan esta interfaz recuperen un identificador de host preciso incluso en presencia de reenvío de puertos y conexiones tunelizadas.

Si esto no tiene éxito, se utilizará un método de respaldo. Para contextos locales - entendiendo local como cualquiera de DSO, "localhost" o conexión de socket de dominio Unix - se buscará un nombre de host a través de gethostname(3). Para otros contextos, se utilizará el nombre de host extraído de la especificación inicial del host del contexto.

VALOR DE RETORNO

Si id no es un identificador de contexto PCP válido, el nombre de host devuelto es una cadena de longitud cero.

En caso de fallo, el código de retorno de pmGetHostName es un código de error PMAPI negativo que puede ser procesado por pmErrStr_r(3) para obtener diagnósticos relacionados con el fallo al obtener el nombre de host del contexto.

NOTAS

pmGetContextHostName devuelve un puntero a un búfer estático, por lo que el valor devuelto solo es válido hasta la próxima llamada a pmGetContextHostName y, por lo tanto, no es seguro para subprocesos. Las aplicaciones multihilo deben usar pmGetHostName o pmGetContextHostName_r en su lugar.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables pueden obtenerse programáticamente utilizando la función pmGetConfig(3).
