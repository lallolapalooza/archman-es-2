NOMBRE

pmSpecLocalPMDA - procesar argumento de línea de comandos para la tabla de PMDAs DSO

SINOPSIS C

#include "pmapi.h"
#include "libpcp.h"

char *pmSpecLocalPMDA(const char *spec);

cc ... -lpcp

DESCRIPCIÓN

Para aplicaciones Performance Co-Pilot (PCP), los contextos de tipo PM_CONTEXT_LOCAL son utilizados por clientes que desean obtener métricas directamente de uno o más PMDAs en el host local sin involucrar a pmcd(1).

pmSpecLocalPMDA proporciona un envoltorio de conveniencia para ser utilizado por aplicaciones que deseen usar un argumento de línea de comandos (generalmente con -K) para controlar los PMDAs DSO que están disponibles para un contexto PM_CONTEXT_LOCAL.

El argumento spec especifica acciones para uno o más PMDAs DSO utilizando hasta cuatro campos separados por comas (``,''), a saber:

  • un código de operación con uno de los valores add (añadir una nueva entrada), del (eliminar una entrada existente) o clear (limpiar todas las entradas de la tabla).
  • el número de dominio del PMDA
  • la ruta al DSO del PMDA (puede ser absoluta o relativa al directorio $PCP_VAR_DIR/pmdas y el sufijo DSO es opcional), y
  • el nombre de la rutina de inicialización del PMDA.

Todos los campos son requeridos para añadir una nueva entrada. Para eliminar una entrada, se requiere el código de operación más uno o ambos de los campos de número de dominio y ruta. Para limpiar todas las entradas, solo se requiere el código de operación.

Si spec se analiza correctamente, la tabla DSO se actualizará con los campos extraídos.

VALOR DE RETORNO

En caso de éxito, pmSpecLocalPMDA devolverá NULL.

En caso de error o fallo, pmSpecLocalPMDA devolverá un puntero a un mensaje de error estático.

EJEMPLOS

Algunos ejemplos de cadenas spec válidas:

clear
Elimina todas las entradas de la tabla DSO.
add,123,foo/foo_pmda,foo_init
Añade el PMDA ``foo'' usando el dominio 123. El DSO del PMDA probablemente está en el directorio $PCP_PMDAS_DIR y se llama foo/foo_pmda.so (para plataformas tipo ELF) o foo/foo_pmda.dylib (para plataformas tipo BSD) o foo\foo_pmda.dll (para plataformas tipo Windows). La rutina de inicialización para el PMDA ``foo'' es foo_init().
del,123
Elimina la entrada para el DSO con dominio 123.
del,,foo/foo_pmda
Elimina la entrada con una ruta al DSO que coincida con foo/foo_pmda.
del,123,foo/foo_pmda
Elimina la entrada para el DSO con dominio 123 y/o una ruta al DSO que coincida con foo/foo_pmda.

VER TAMBIÉN

pmcd(1), PMAPI(3) y pmNewContext(3).
