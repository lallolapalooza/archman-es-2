PMSEARCH(1) Manual de comandos generales PMSEARCH(1)

NOMBRE

pmsearch - búsqueda de ayuda y nombres para métricas, instancias y dominios de instancias

SINOPSIS

pmsearch [-CdinqsStTV?] [-c config] [-D debug] [-h host] [-p port] [-N número] [-O offset] [consulta | indom]

DESCRIPCIÓN

pmsearch realiza consultas de búsqueda de texto completo para encontrar métricas utilizando nombres y textos de ayuda de métricas, dominios de instancias e instancias.

Utiliza las capacidades del servicio Performance Co-Pilot (PCP) pmproxy(1), el almacén de clave-valor distribuido Valkey y el módulo asociado ValkeySearch.

Tenga en cuenta que para poder utilizar estos servicios, es **obligatorio** que pmproxy se comunique con un servidor de clave-valor de Valkey que tenga cargado el módulo valkey-search.so. Cuando está configurado para hacerlo, pmproxy indexará automáticamente nombres de métricas de PCP, nombres de instancias, textos de ayuda de métricas y dominios de instancias en el almacén de ValkeySearch, a partir de los archivos de PCP que descubra localmente. Consulte pmlogger(1) y pmlogger_daily(1) para obtener más detalles.

Por defecto, pmsearch se comunica con un servidor de clave-valor local, sin embargo, las opciones -h y -p pueden usarse para especificar una instancia Valkey alternativa. Si esta instancia es un nodo de un clúster de Valkey, todas las demás instancias del clúster se descubrirán y se usarán automáticamente.

OPCIONES

-c config, --config=config
Especifica el archivo config a utilizar.
-C, --no-colour
Sin resaltado en el texto de los resultados.
-d, --docid
Reporta el ID del documento de cada resultado de búsqueda. Los documentos se identifican mediante un hash SHA-1 único que siempre se muestra en un formato legible por humanos de 40 dígitos hexadecimales.
-h host, --host=host
Conéctate al servidor de clave-valor en host, en lugar de al localhost.
-i, --info
Reporta métricas internas del motor de búsqueda.
-n, --indom
Realiza una búsqueda de entidades relacionadas con el dominio de instancias (instance domain).
-N N, --number=N
Devuelve como máximo N resultados de búsqueda.
-O N, --offset=N
Resultados paginados desde el offset dado.
-p port, --port=port
Conéctate al servidor de clave-valor en port, en lugar del predeterminado 6379.
-q, --query
Realiza una búsqueda general de texto (predeterminada).
-s, --suggest
Realiza una búsqueda de sugerencias de nombres.
-S, --score
Reporta la puntuación (ranking) de cada resultado.
-T, --total
Reporta el número total de resultados de búsqueda.
-t, --times
Reporta el tiempo de ejecución de la búsqueda.
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

EJEMPLOS

$ pmsearch kernel idle
Tipo: métrica
Nombre: kernel.all.cpu.idle
Una línea: tiempo total de CPU idle desde /proc/stat para todas las CPU
Tipo: métrica
Nombre: kernel.all.idletime
Una línea: tiempo que el kernel actual ha estado idle desde el arranque
Tipo: métrica
Nombre: kernel.percpu.cpu.idle
InDom: 60.0
Una línea: métrica de tiempo de CPU idle por núcleo desde /proc/stat

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug activa la salida de diagnósticos adicionales en stderr para ayudar a depurar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
