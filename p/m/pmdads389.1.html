PMDADS389(1) Manual de Comandos Generales PMDADS389(1)

NOMBRE

pmdads389 - PMDA del servidor de directorios 389

DESCRIPCIÓN

pmdads389 es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae datos de rendimiento en vivo de una instancia del servidor de directorios 389 en ejecución.

Consulte la Guía de Administración del Servidor de Directorios de Red Hat para obtener una descripción de cada métrica.

INSTALACIÓN

pmdads389 lee un archivo de configuración opcional

$PCP_PMDAS_DIR/ds389/ds389.conf

Este archivo puede contener valores anulados (código Perl) para la configuración listada al principio de pmdads389.pl, a saber:

  • Servidor LDAP
  • DN de enlace
  • Contraseña de enlace
  • Ámbito de búsqueda predeterminado
  • Base de búsqueda predeterminada
  • Filtro de búsqueda predeterminado
  • Intervalo de consulta
  • Lista de fuentes
  • Lista de atributos a mostrar para cada fuente

Por favor, utilice el ds389.conf.example proporcionado como punto de partida. Una vez configurado esto, puede acceder a los nombres y valores de las métricas de rendimiento de 389 DS haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/ds389
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/ds389
# ./Remove

pmdads389 es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts de Instalación y Eliminación notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/ds389/ds389.conf.example
archivo de configuración de ejemplo para el agente pmdads389
$PCP_PMDAS_DIR/ds389/ds389.conf
archivo de configuración para el agente pmdads389
$PCP_PMDAS_DIR/ds389/Install
script de instalación para el agente pmdads389
$PCP_PMDAS_DIR/ds389/Remove
script para deshacer la instalación del agente pmdads389
$PCP_LOG_DIR/pmcd/ds389.log
archivo de registro predeterminado para mensajes de error de pmdads389

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
