PMDAOPENLOG(3) Manual de funciones de biblioteca PMDAOPENLOG(3)

NOMBRE

pmdaOpenLog - redirigir stderr a un archivo de registro

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

void pmdaOpenLog(pmdaInterface * dispatch);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

pmdaOpenLog redirige stderr al archivo de registro especificado en la estructura dispatch, establecido por la llamada anterior a pmdaDaemon(3) o pmdaGetOpt(3). La primera línea del archivo de registro detallará el nombre del proceso que llama, el host en el que se está ejecutando el proceso y la hora actual. Además, el registro se completa con la hora de salida del proceso mediante una rutina registrada con atexit(3).

ADVERTENCIA

El PMDA debe estar utilizando PMDA_INTERFACE_2 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores de estas variables pueden obtenerse programáticamente utilizando la función pmGetConfig(3).

VER TAMBIÉN

pmcd(1), atexit(2), PMAPI(3), PMDA(3), pmdaDaemon(3) y pmdaGetOpt(3).
