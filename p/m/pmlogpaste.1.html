PMLOGPASTE(1) Manual de Comandos Generales PMLOGPASTE(1)

NOMBRE

pmlogpaste - pegar texto en una métrica en un archivo PCP

SINOPSIS

pmlogpaste [-?] [-f archivo] [-h nombrehost] [-l etiqueta] [-m métrica] [-o archivo_salida] [-t zona_horaria]

DESCRIPCIÓN

pmlogpaste toma texto de entrada de un archivo o de la línea de comandos, y lo escribe como un valor métrico en un nuevo archivo PCP. Este valor métrico se marca con la hora actual y se almacena como una métrica de tipo cadena.

El propósito principal de esta herramienta es tomar la salida capturada y preservarla en un archivo PCP. Esto permite, por ejemplo, que la salida de la ejecución de un benchmark se almacene junto con las métricas de rendimiento capturadas durante esa ejecución, en un único archivo. Los archivos se pueden fusionar usando la utilidad pmlogextract(1).

pmlogpaste utiliza internamente las interfaces de la biblioteca LOGIMPORT(3), que admiten la creación de archivos a partir de fuentes externas de datos de rendimiento.

OPCIONES

Las opciones disponibles en la línea de comandos son:

-f archivo, --file=archivo
Archivo con el texto de entrada a archivar, o ``-'' para la entrada estándar.
-h nombrehost, --hostname=nombrehost
Nombre del host de origen para el archivo. El valor predeterminado es el nombre del host local, o ``localhost'' si no se puede obtener.
-l etiqueta, --label=etiqueta
Añade etiquetas de contexto al archivo generado. Esta opción se puede presentar varias veces para producir múltiples etiquetas en el archivo. La etiqueta debe tener el formato nombre:valor.
-m métrica, --metric=métrica
Nombre de la métrica para el archivo. El nombre de métrica predeterminado es paste.value.
-o archivo_salida, --outfile=archivo_salida
Archivo de salida del archivo. El nombre de archivo predeterminado es paste.
-t zona_horaria, --timezone=zona_horaria
Zona horaria de origen para el archivo. El valor predeterminado es la zona horaria local.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmlogextract(1) y LOGIMPORT(3).
