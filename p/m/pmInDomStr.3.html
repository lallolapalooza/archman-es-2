PMINDOMSTR(3) Manual de funciones de biblioteca PMINDOMSTR(3)

NOMBRE

pmInDomStr, pmInDomStr_r - convertir un identificador de dominio de instancia de métrica de rendimiento en una cadena

SINOPSIS C

#include <pcp/pmapi.h>

const char *pmInDomStr(pmInDom indom);
char *pmInDomStr_r(pmInDom indom, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Para su uso en mensajes de error y diagnóstico, pmInDomStr devuelve una versión 'legible por humanos' del identificador de dominio de instancia especificado. La función pmInDomStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos 20 bytes.

El valor para el dominio de instancia indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Internamente, un identificador de dominio de instancia se codifica con dos campos: dominio y serie.

pmInDomStr devuelve una cadena con cada uno de los campos que aparecen como números decimales, separados por puntos.

El valor de cadena devuelto por pmInDomStr se mantiene en un único búfer estático, por lo que el valor devuelto solo es válido hasta la siguiente llamada a pmInDomStr.

NOTAS

pmInDomStr devuelve un puntero a un búfer estático y, por lo tanto, no es seguro para subprocesos. Las aplicaciones multihilo deben usar pmInDomStr_r en su lugar.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables se pueden obtener programáticamente utilizando la función pmGetConfig(3).
