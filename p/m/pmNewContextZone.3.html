PMNEWCONTEXTZONE(3) Manual de funciones de biblioteca PMNEWCONTEXTZONE(3)

NOMBRE

pmNewContextZone - establecer una zona horaria de informe basada en un contexto PMAPI

SINTAXIS C

#include <pcp/pmapi.h>

int pmNewContextZone(void);

cc ... -lpcp

DESCRIPCIÓN

La zona horaria de informe actual afecta la zona horaria utilizada por pmCtime(3) y pmLocaltime(3).

Si el contexto PMAPI actual es un archivo, pmNewContextZone utiliza la zona horaria del registro de etiquetas del archivo para establecer la zona horaria de informe actual.

Si el contexto PMAPI actual corresponde a una fuente de métricas del host, pmNewContextZone ejecuta un pmFetch(3) para recuperar el valor de la métrica pmcd.timezone y lo utiliza para establecer la zona horaria de informe actual.

En ambos casos, pmNewContextZone devuelve un valor para identificar la zona horaria de informe actual que puede ser utilizada en una llamada posterior a pmUseZone(3) para restaurar esta zona horaria de informe.

DIAGNÓSTICOS

PM_ERR_NOCONTEXT
el contexto PMAPI actual no es válido
otro
un valor de retorno menor que cero indica un error fatal de una llamada del sistema, lo más probable es que sea malloc(3)
