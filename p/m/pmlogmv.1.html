PMLOGMV(1) Manual de Comandos Generales PMLOGMV(1)

NOMBRE

pmlogmv, pmlogcp - mover (renombrar) o copiar archivos de archivo de Performance Co-Pilot

SINOPSIS

pmlogmv [-cfNV?] [-D debug] nombre_fuente nombre_destino
pmlogcp [-cfNV?] [-D debug] nombre_fuente nombre_destino

DESCRIPCIÓN

Un archivo de Performance Co-Pilot (PCP) consta de múltiples archivos como los creados por pmlogger(1). pmlogmv permite que todos los archivos de un único archivo PCP sean movidos o renombrados como un grupo en una sola operación. De manera similar, pmlogcp copia todos los archivos de un único archivo PCP en una sola operación.

El argumento nombre_fuente identifica el archivo objetivo, y puede ser tanto el nombre base común a todos los archivos de ese archivo como uno de los archivos del archivo.

El nuevo nombre base del archivo es nombre_destino, excepto cuando nombre_destino es un directorio existente, en cuyo caso los archivos se mueven o copian dentro de nombre_destino utilizando el mismo nombre base de archivo que nombre_fuente.

Dado que los archivos PCP son registros importantes de la actividad del sistema, se toman precauciones especiales para garantizar la integridad de los archivos de un archivo. Para problemas recuperables encontrados durante la ejecución de pmlogmv o pmlogcp, se conservarán todos los archivos asociados con nombre_fuente, y no se crearán nuevos archivos con el prefijo nombre_destino. Los "problemas recuperables" incluyen señales que pueden ser capturadas (como SIGHUP, SIGINT, SIGQUIT y SIGTERM), problemas de permisos, existencia previa de nuevos archivos, eventos de sistema de archivos lleno, etc.

La implementación de pmlogmv intenta usar enlaces duros en el sistema de archivos y sigue las restricciones semánticas de ln(2) que para la mayoría de los sistemas significa que los directorios que contienen tanto los archivos del archivo PCP de nombre_fuente como los de nombre_destino deben estar dentro del mismo sistema de archivos. Cuando esto no es posible, pmlogmv recurre al uso de cp(1) para copiar nombre_fuente a nombre_destino.

pmlogcp siempre utiliza cp(1).

OPCIONES

Las opciones de línea de comandos disponibles son:

-c, --checksum
Modo de verificación paranoica cuando se necesita cp(1) y se calcula la suma de verificación de cada archivo original y del archivo copiado, y las sumas de verificación deben coincidir antes de que la copia se considere aceptable. El comando de suma de verificación se elige intentando los siguientes en orden hasta que se encuentre uno ejecutable: md5sum(1), sha256sum(1), sha1sum(1) y sum(1). Si no se encuentra ningún comando de suma de verificación ejecutable, se emite una advertencia y se omite la verificación de la suma de verificación.
-f, --force
Normalmente, pmlogmv y pmlogcp adoptan una postura conservadora respecto a nombre_destino y no procederán si nombre_destino contiene caracteres que probablemente causen un problema para sh(1). Esto incluye caracteres de "glob" como ``?'' , ``*'' y ``['', meta-caracteres de sintaxis de shell como ``('', ``|'', ``;'' y ``&'', caracteres de redirección de E/S del shell como ``<'' y ``>'', el signo de dólar, un espacio, etc.

La bandera -f fuerza la continuación del renombrado o la copia, incluso si nombre_destino contiene alguno de estos caracteres "inseguros".

-N, --showme
Realiza una ejecución de prueba, verificando e informando qué cambios se harían sin realizar ningún cambio.
-V, --verbose
Habilita el modo detallado.
-?, --help
Muestra el mensaje de uso y sale.

DIAGNÓSTICO

Todos los mensajes de error y advertencia están diseñados para ser fácilmente comprensibles y los errores producen un estado de salida no cero.

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a triar problemas, aunque la información es a veces críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

cp(1), ln(1), md5sum(1), PCPIntro(1), pmlogger(1), sha1sum(1), sha256sum(1) y LOGARCHIVE(5).
