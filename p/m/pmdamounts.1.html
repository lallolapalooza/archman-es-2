PMDAMOUNTS(1) Manual de comandos generales PMDAMOUNTS(1)

NOMBRE

pmdamounts - agente de dominio de métricas de rendimiento de montajes de sistemas de archivos (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/mounts/pmdamounts [-D debug] [-d dominio] [-l logfile] [-U username]

DESCRIPCIÓN

pmdamounts es un Agente de Dominio de Métricas de Rendimiento (PMDA) simple que monitoriza la disponibilidad de un conjunto dado de montajes de sistemas de archivos.

El PMDA mounts exporta métricas que reflejan si los sistemas de archivos configurados están montados ("activos") o no. La lista de puntos de montaje a monitorizar se especifica a través del archivo $PCP_PMDAS_DIR/mounts/mounts.conf, que simplemente contiene una línea por cada punto de montaje.

A continuación se incluye una breve descripción de las opciones de línea de comandos de pmdamounts:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado mounts.log en el directorio actual de pmcd(1) cuando se inicia pmdamounts, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se redirige a la salida de error estándar.
-U
Cuenta de usuario bajo la cual se ejecutará el agente. Por defecto, es la cuenta no privilegiada "pcp" en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

INSTALACIÓN

Si desea acceso a los nombres, texto de ayuda y valores de las métricas de rendimiento de montajes, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/mounts
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/mounts
# ./Remove

pmdamounts es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdamounts
$PCP_PMDAS_DIR/mounts/help
archivo de texto de ayuda predeterminado para las métricas de montajes
$PCP_PMDAS_DIR/mounts/Install
script de instalación para el agente pmdamounts
$PCP_PMDAS_DIR/mounts/Remove
script para deshacer la instalación del agente pmdamounts
$PCP_LOG_DIR/pmcd/mounts.log
archivo de registro predeterminado para mensajes de error y otra información de pmdamounts

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN
