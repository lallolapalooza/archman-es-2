PMADDDERIVEDTEXT(3) Manual de funciones de biblioteca PMADDDERIVEDTEXT(3)

NOMBRE

pmAddDerivedText - añadir texto de ayuda para una métrica derivada

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmAddDerivedText(const char *name,
int type, const char *text);

cc ... -lpcp

DESCRIPCIÓN

Las métricas derivadas proporcionan una forma de extender el Espacio de Nombres de Métricas de Rendimiento (PMNS) con nuevas métricas definidas en el lado del cliente de PCP utilizando expresiones sobre las métricas de rendimiento existentes. Las métricas derivadas globales se definen usando pmRegisterDerived(3) o pmRegisterDerivedMetric(3) o pmLoadDerivedConfig(3), y las métricas derivadas por contexto se definen usando pmAddDerived(3) o pmAddDerivedMetric(3).

Una vez que se ha definido una métrica derivada, se puede usar pmAddDerivedText para asociar el text de ayuda con la métrica derivada identificada por name.

El texto de ayuda puede ser un resumen de "una línea" o un bloque de texto más detallado de "varias líneas", y type debe ser PM_TEXT_ONELINE o PM_TEXT_HELP respectivamente. Para asociar ambos estilos de texto de ayuda con una métrica derivada, habría que llamar a pmAddDerivedText dos veces con valores diferentes para type.

Una vez que un tipo particular de texto de ayuda ha sido asociado con una métrica derivada, no se puede eliminar ni redefinir.

Las aplicaciones que utilizan la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) pueden recuperar el texto de ayuda para métricas específicas utilizando pmLookupText(3).

DIAGNÓSTICOS

pmAddDerivedText devuelve cero si tiene éxito, de lo contrario, un código de error.

El valor de retorno PM_ERR_NAME indica que name no corresponde a una métrica derivada definida previamente.

Las llamadas repetidas para el mismo name y type resultarán en un valor de retorno de PM_ERR_TEXT.

Un valor de retorno de PM_ERR_ARG indica que type no es uno de los valores esperados.

VER TAMBIÉN
