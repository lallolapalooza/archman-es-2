Paquete: pam_mount

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later

pmvarrun(8) pam_mount pmvarrun(8)

Nombre

pmvarrun - actualiza /var/run/pam_mount/usuario

Sintaxis

pmvarrun -u usuario [opciones]

Descripción

Se necesita un programa separado para que /var/run/pam_mount/usuario pueda crearse con un contexto de seguridad específico de pam_mount (de lo contrario, la política SELinux entrará en conflicto con gdm, que también crea archivos en /var/run).

pmvarrun es flexible y puede ejecutarse en una serie de configuraciones de seguridad diferentes:

root-root

Cuando pmvarrun se invoca como root, la configuración de permisos de /var/run/pam_mount puede ser tan estricta como sea necesario; normalmente (0755,root,root) es una buena opción, ya que otorga a los usuarios control de depuración sobre su recuento de referencias. Los archivos de recuento de referencias reciben sus propietarios respectivos (cambiados al usuario que inicia sesión).

usuario-usuario

Cuando se invoca como el usuario que inicia sesión, /var/run/pam_mount necesita los permisos adecuados para crear un archivo, lo que significa que debe estar configurado el bit de escritura. También se sugiere encarecidamente establecer el bit pegajoso en este caso, para que otros usuarios no manipulen su recuento de referencias.

root-usuario

Algunos programas o ayudantes de inicio de sesión llaman incorrectamente a la pila PAM de una manera que la fase de inicio de sesión se realiza como root y la fase de cierre de sesión como un usuario normal. Sin embargo, pmvarrun soporta esto, y se pueden usar los mismos permisos que en root-root. Aunque el usuario puede no ser capaz de eliminar su archivo de /var/run/pam_mount, se truncará para indicar el mismo estado.

Opciones

--ayuda, -h
Mostrar ayuda.
--usuario usuario, -u usuario
Usuario a gestionar, debe ser un nombre de usuario válido.
--operación número, -o número
Incrementa el recuento de volúmenes en número.
-d
Activa la depuración.
