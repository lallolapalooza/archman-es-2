PMDANFSCLIENT(1) Manual de comandos generales PMDANFSCLIENT(1)

NOMBRE

pmdanfsclient - agente de dominio de estadísticas del cliente NFS (PMDA)

DESCRIPCIÓN

pmdanfsclient es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores de métricas de la interfaz /proc/self/mountstats para proporcionar información sobre montajes NFS.

INSTALACIÓN

Instale el PMDA de cliente NFS utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/nfsclient
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/nfsclient
# ./Remove

pmdanfsclient es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/nfsclient/Install
script de instalación para el agente pmdanfsclient
$PCP_PMDAS_DIR/nfsclient/Remove
script para deshacer la instalación del agente pmdanfsclient
$PCP_LOG_DIR/pmcd/nfsclient.log
archivo de registro predeterminado para mensajes de error de pmdanfsclient

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1), nfs(5) y mountstats(8).
