PMWEBTIMERREGISTER(3) Manual de funciones de biblioteca PMWEBTIMERREGISTER(3)

NOMBRE

pmWebTimerRegister, pmWebTimerRelease, pmWebTimerSetMetricRegistry - gestión de listas de temporizadores segura para hilos

SINOPSIS C

#include <pcp/pmwebapi.h>

typedef void (*pmWebTimerCallBack)(void *data);
int pmWebTimerRegister(pmWebTimerCallBack callback, void *data);

int pmWebTimerRelease(int seq);
int pmWebTimerSetMetricRegistry(struct mmv_registry *registry);

cc ... -lpcp_web

DESCRIPCIÓN

pmWebTimerRegister y las funciones de API relacionadas proporcionan una API cómoda y segura para hilos para que las aplicaciones administren una lista de callbacks impulsados por temporizadores. En la primera llamada a pmWebTimerRegister o pmWebTimerSetMetricRegistry, se configura un temporizador interno y se inicializa para que se dispare cada 1.0 segundo. Cada vez que se dispara el temporizador, todas las funciones de callback registradas actualmente se llamarán en serie con el puntero data opaco que se proporcionó al registrar cada función. El typedef pmWebTimerCallBack proporciona un prototipo de función de callback adecuado.

Todas las funciones de callback registradas deben ser no bloqueantes y ejecutarse de forma rápida y síncrona. Las funciones de callback típicas incluyen la actualización de instrumentación, el cálculo y la actualización de valores de métricas de rendimiento, la recolección de basura periódica y cualquier otra función local que requiera ejecución regular.

La función pmWebTimerSetMetricRegistry proporciona una forma conveniente para que una aplicación pase un puntero a un registry de libpcp_mmv(3) que ha sido inicializado adecuadamente por la aplicación que llama. Este registry se utilizará para crear dinámicamente seis métricas de recursos del servidor llamadas NAME.mem.datasz, NAME.mem.maxrss, NAME.cpu.total, NAME.cpu.sys, NAME.cpu.user y NAME.pid, donde NAME es el nombre raíz del conjunto de nombres de PMNS(5) configurado por la aplicación que llama. Estas métricas deberían ser razonablemente autoexplicativas; proporcionan métricas de uso de recursos de la aplicación / servidor que llama y utilizan getrusage(2), times(2) y getpid(2).

VALOR DE RETORNO

La función pmWebTimerRegister devuelve un identificador de entero positivo que posteriormente puede usarse en una llamada a pmWebTimerRelease para eliminar un temporizador de la lista de temporizadores interna. Cuando se elimina un temporizador con una llamada a pmWebTimerRelease, se liberan las estructuras de datos internas. Sin embargo, el llamante es responsable de liberar el data asociado (ya que puede o no ser asignado dinámicamente).

DIAGNÓSTICOS

En caso de error, se devuelve un código de error PMAPI negativo en todos los casos.

VER TAMBIÉN

pmproxy(1), mmv_stats_registry(3), PMAPI(3) y PMWEBAPI(3).
