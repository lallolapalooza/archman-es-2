PM-GAWK(1) Comandos de utilidad PM-GAWK(1)

NOMBRE

gawk de memoria persistente - datos y funciones persistentes

SINOPSIS

truncate -s tamaño heap.pma
export GAWK_PERSIST_FILE=heap.pma
gawk ...

truncate -s tamaño heap.pma
GAWK_PERSIST_FILE=heap.pma gawk ...

truncate -s tamaño heap.pma
alias pm='GAWK_PERSIST_FILE=heap.pma'
pm gawk ...                       # conciso

unset GAWK_PERSIST_FILE   # deshabilitar persistencia

export GAWK_PERSIST_FILE=other_heap.pma  # cambiar heap

rm heap.pma               # eliminar heap

DESCRIPCIÓN

Gawk 5.2 y versiones posteriores admiten una característica de memoria persistente que puede almacenar variables y funciones definidas por el script en un archivo para su uso posterior. La característica, llamada pm-gawk, se describe en GAWK: Effective AWK Programming y en Persistent Memory gawk User Manual.

pm-gawk se activa pasando a gawk el nombre de un archivo heap inicialmente vacío (con bytes cero), a través de la variable de entorno GAWK_PERSIST_FILE. pm-gawk retiene las variables y funciones definidas por el script en el archivo heap para su uso en invocaciones posteriores de gawk.

pm-gawk ofrece al menos dos ventajas en comparación con la extensión existente rwarray: ofrece acceso en tiempo constante (``tiempo O(1)'') a elementos individuales de arrays asociativos persistentes, y puede almacenar funciones definidas por el script además de variables.

EJEMPLOS

Demostración de variables persistentes:

$ truncate -s 1G heap.pma            # crear archivo heap
$ export GAWK_PERSIST_FILE=heap.pma  # variable de entorno "ambiental"
$ gawk 'BEGIN { print ++i }'
1
$ gawk 'BEGIN { print ++i }'
2
$ gawk 'BEGIN { print ++i }'
3

Para pasar la variable de entorno por comando:

$ unset GAWK_PERSIST_FILE
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
4
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
5
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
6

Para reducir el desorden visual al pasar la variable de entorno por comando:

$ alias pm='GAWK_PERSIST_FILE=heap.pma'
$ pm gawk 'BEGIN { print ++i }'
7
$ pm gawk 'BEGIN { print ++i }'
8

Para abstenerse de activar la persistencia:

$ unset GAWK_PERSIST_FILE
$ gawk 'BEGIN { print ++i }'
1
$ gawk 'BEGIN { print ++i }'
1

Para "olvidar" permanentemente el contenido del archivo heap:

$ rm heap.pma

VARIABLES DE ENTORNO

GAWK_PERSIST_FILE contiene el nombre de un archivo heap donde se almacenan las variables y funciones definidas por el script. Si esta variable de entorno no es visible para gawk, la característica de persistencia no se activa y gawk se comporta de manera tradicional.

INFORMACIÓN DE VERSIÓN

Gawk de memoria persistente se lanzó por primera vez en gawk 5.2.

AUTORES

Arnold Robbins, el mantenedor de gawk, implementó pm-gawk utilizando un asignador de memoria persistente (pma) proporcionado por Terence Kelly. Un prototipo anterior de prueba de concepto de gawk persistente fue desarrollado por Haris Volos, Zi Fan Tan y Jianan Li utilizando un fork de las fuentes oficiales de gawk.

ADVERTENCIAS

El sistema de archivos CIFS de GNU/Linux es conocido por causar problemas al asignador de memoria persistente. No utilice un archivo de respaldo en dicho sistema de archivos con pm-gawk.

REPORTES DE ERRORES

Siga los procedimientos en GAWK: Effective AWK Programming y en Persistent Memory gawk User Manual. Para posibles errores relacionados con la persistencia (en lugar de otros errores de gawk no relacionados con la persistencia), envíe también un correo electrónico a Terence Kelly a una o más de estas direcciones: tpkelly@acm.org, tpkelly@eecs.umich.edu, o tpkelly@cs.princeton.edu.

VER TAMBIÉN

gawk(1), GAWK: Effective AWK Programming y Persistent Memory gawk User Manual. Los dos manuales deberían estar disponibles en el subsistema Info si Info está instalado en su sistema.

Vea https://web.eecs.umich.edu/~tpkelly/pma/ para el código fuente y manual más reciente.
