PMSTRNCAT(3) Manual de funciones de biblioteca PMSTRNCAT(3)

NOMBRE

pmstrncat - concatenación segura de cadenas

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmstrncat(char *dest, size_t destlen, char *src);

cc ... -lpcp

DESCRIPCIÓN

pmstrncat es una rutina de concatenación de cadenas segura con semántica similar a strncat(3).

Las principales diferencias entre pmstrncat y strncat(3) son:

  • src debe terminar en nulo para pmstrncat
  • destlen es la longitud del búfer de destino (dest) para pmstrncat, no el número máximo de bytes que no son nulos para copiar de src, como lo es para strncat
  • el argumento de longitud tiene la misma semántica para pmstrncat y pmstrncpy(3), a diferencia de strncat(3) y strncpy(3).
  • el valor de retorno de pmstrncat es útil
  • el orden de los argumentos para pmstrncat se ha cambiado deliberadamente con respecto al orden de los argumentos para strncat(3) para evitar el uso indebido accidental que un compilador pueda detectar fácilmente

En caso de éxito, pmstrncat devuelve 0; de lo contrario, -1 indica que src es demasiado grande y el resultado se ha truncado para garantizar que dest no se haya desbordado.

HISTORIA

strncat(3) apareció por primera vez en la Edición 7 de Unix de AT&T alrededor de 1979. Fue diseñado específicamente para construir nombres de ruta de archivos (que debían terminar en nulo) a partir de nombres de componentes de entradas de directorio en disco que tenían un tamaño máximo fijo y podían tener cero, uno o más bytes nulos de cola.

Los intentos posteriores de usar strncat(3) para operaciones de concatenación de cadenas más generales han estado plagados de abusos y problemas de seguridad; pmstrncat es un intento de abordar estos problemas.

VER TAMBIÉN

PMAPI(3), pmstrncpy(3), strncat(3) y strncpy(3).
