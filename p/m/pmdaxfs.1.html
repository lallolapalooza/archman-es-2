PMDAXFS(1) Manual de Comandos Generales PMDAXFS(1)

NOMBRE

pmdaxfs - agente de dominio de métricas de rendimiento del sistema de archivos XFS (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/xfs/pmdaxfs [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

pmdaxfs es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen el estado del sistema de archivos XFS del kernel de Linux.

El PMDA xfs exporta métricas que miden información sobre el uso de búferes de metadatos, el journal, operaciones btree, operaciones de inodos, atributos extendidos, directorios, cuotas, recuentos de operaciones de lectura y escritura y, por supuesto, el rendimiento.

El PMDA proporciona una instalación para restablecer los valores de todos los contadores a cero usando pmstore(1) con la métrica xfs.control.reset.

A continuación, se presenta una breve descripción de las opciones de línea de comandos de pmdaxfs:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado xfs.log en el directorio actual de pmcd(1) cuando se inicia pmdaxfs, es decir, en $PCP_LOG_DIR/pmcd. Si no se puede crear el archivo de registro o no se puede escribir en él, la salida se escribe en la salida de error estándar.

INSTALACIÓN

El PMDA xfs está instalado y disponible por defecto en Linux. Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/xfs
# ./Remove

Si desea restablecer el acceso a los nombres, texto de ayuda y valores de las métricas de rendimiento de XFS una vez más, después de la eliminación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/xfs
# ./Install

pmdaxfs es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos usadas para lanzar pmdaxfs
$PCP_PMDAS_DIR/xfs/help
archivo de texto de ayuda predeterminado para las métricas xfs
$PCP_PMDAS_DIR/xfs/Install
script de instalación para el agente pmdaxfs
$PCP_PMDAS_DIR/xfs/Remove
script para deshacer la instalación del agente pmdaxfs
$PCP_LOG_DIR/pmcd/xfs.log
archivo de registro predeterminado para mensajes de error y otra información de pmdaxfs

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
