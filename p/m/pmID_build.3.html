PMID_BUILD(3) Manual de funciones de biblioteca PMID_BUILD(3)

NOMBRE

pmID_build, pmID_domain, pmID_cluster, pmID_item - métodos auxiliares para manipular PMIDs

SINOPSIS C

#include <pcp/pmapi.h>

pmID pmID_build(unsigned int domain,
unsigned int cluster, unsigned int item);

unsigned int pmID_domain(pmID pmid);
unsigned int pmID_cluster(pmID pmid);
unsigned int pmID_item(pmID pmid);

cc ... -lpcp

DESCRIPCIÓN

Dentro de Performance Co-Pilot (PCP), a cada métrica se le asigna un Identificador Único de Métrica de Rendimiento (pmID). Internamente, un pmID se construye a partir de 3 campos: el número de dominio (del Agente de Dominio de Métricas de Rendimiento asociado, o PMDA), el número de clúster y el número de ítem (los dos últimos son asignados por el PMDA).

pmID_build construye un pmID a partir de domain, cluster e item.

pmID_domain, pmID_cluster y pmID_item devuelven los campos respectivos de pmid.

VER TAMBIÉN

PMAPI(3) y pmIDStr(3).
