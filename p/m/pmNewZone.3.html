PMNEWZONE(3) Manual de funciones de biblioteca PMNEWZONE(3)

NOMBRE

pmNewZone - establecer una zona horaria de reporte

SINOPSIS

#include <pcp/pmapi.h>

int pmNewZone(const char *tz);

cc ... -lpcp

DESCRIPCIÓN

La zona horaria de reporte actual afecta la zona horaria utilizada por pmCtime(3) y pmLocaltime(3).

El argumento tz define una cadena de zona horaria, en el formato descrito para la variable de entorno TZ, consulte environ(7).

pmNewZone establece la zona horaria de reporte actual y devuelve un valor que puede usarse en una llamada posterior a pmUseZone(3) para restaurar esta zona horaria de reporte.

DIAGNÓSTICOS

Un valor de retorno menor que cero indica un error fatal de una llamada al sistema, muy probablemente malloc(3).

VER TAMBIÉN

PMAPI(3), pmCtime(3), pmGetConfig(3), pmLocaltime(3), pmNewContextZone(3), pmUseZone(3), pmWhichZone(3), pcp.conf(5), pcp.env(5) y environ(7).
