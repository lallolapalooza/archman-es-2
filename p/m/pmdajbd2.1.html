PMDAJBD2(1) Manual de comandos generales PMDAJBD2(1)

NOMBRE

pmdajbd2 - agente de dominio de métricas de dispositivo de bloque con registro (JBD) (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/jbd2/pmdajbd2 [-D debug] [-d dominio] [-l archivo_log] [-j ruta] [-U nombre_usuario]

DESCRIPCIÓN

pmdajbd2 es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento del subsistema de dispositivo de bloque con registro (JBD) (versión 2) en el kernel de Linux. Estas métricas son exportadas por el kernel en archivos de procfs, un archivo por dispositivo de bloque. El subsistema JBD2 es utilizado por varios sistemas de archivos, incluyendo ext3, ext4 y ocfs2.

El PMDA jbd2 exporta métricas que miden información detallada de transacciones del registro, como el tiempo de espera y bloqueo, tasas de solicitud, bloques utilizados, etc.

A continuación se presenta una breve descripción de las opciones de línea de comandos de pmdajbd2 (estas solo son relevantes cuando se ejecuta el PMDA como un demonio y no como una biblioteca compartida):

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, el dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, cuando se ejecuta como un demonio, se escribe un archivo de registro llamado jbd2.log en el directorio actual desde el que se inició pmdajbd2, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no puede ser creado o no es escribible, la salida se escribe en el error estándar en su lugar. Cuando se ejecuta en modo de biblioteca compartida, la información de diagnóstico se escribirá en el archivo de registro de pmcd, a saber, $PCP_LOG_DIR/pmcd/pmcd.log.
-j
Permite especificar una ruta alternativa a los archivos de estadísticas de jbd2. La ruta por defecto es /proc/fs/jbd2.
-U
Cuenta de usuario bajo la cual se ejecutará el agente. Por defecto es la cuenta no privilegiada "pcp" en versiones actuales de PCP, pero en versiones anteriores se usaba la cuenta de superusuario ("root") por defecto.

INSTALACIÓN

Este PMDA se instala por defecto y en modo de biblioteca compartida (en lugar de como un demonio separado para pmcd(1)). Por lo tanto, los nombres, el texto de ayuda y los valores para las métricas de rendimiento de jbd2 deberían estar siempre disponibles.

Si no utiliza estas métricas, puede eliminar este PMDA haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/jbd2
# ./Remove

Si desea habilitar la instalación nuevamente, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/jbd2
# ./Install

pmdajbd2 es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdajbd2
$PCP_PMDAS_DIR/jbd2/help
archivo de texto de ayuda por defecto para las métricas jbd2
$PCP_PMDAS_DIR/jbd2/Install
script de instalación para el agente pmdajbd2
$PCP_PMDAS_DIR/jbd2/Remove
script para deshacer la instalación del agente pmdajbd2
$PCP_LOG_DIR/pmcd/jbd2.log
archivo de registro por defecto para mensajes de error y otra información de pmdajbd2

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
