PMDELPROFILE(3) Manual de funciones de biblioteca PMDELPROFILE(3)

NOMBRE

pmDelProfile - eliminar instancia(s) del perfil de instancia PMAPI actual

SINOPSIS C

#include <pcp/pmapi.h>

int pmDelProfile(pmInDom indom, int numinst, int *instlist);

cc ... -lpcp

DESCRIPCIÓN

El conjunto de instancias para métricas de rendimiento devueltas por una llamada a pmFetch(3) puede ser filtrado o restringido usando un perfil de instancia. Hay un perfil de instancia por cada contexto que la aplicación crea en la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI), y cada perfil de instancia puede incluir instancias de uno o más dominios de instancia (ver pmLookupDesc(3)).

pmDelProfile puede ser utilizado para eliminar especificaciones de instancia del perfil de instancia del contexto PMAPI actual.

En la variante más simple, la lista de instancias identificadas por el argumento instlist para el dominio de instancia indom se elimina del perfil de instancia. La lista de identificadores de instancia contiene numinst valores.

El valor indom normalmente se extraería de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular, y las instancias en instlist típicamente se determinarían mediante llamadas a pmGetInDom(3) o pmLookupInDom(3).

Si indom es igual a PM_INDOM_NULL y numinst es cero, entonces se seleccionan todos los dominios de instancia para su eliminación. Si instlist es NULL, entonces todas las instancias en el(los) dominio(s) seleccionado(s) se eliminan del perfil.

Para deshabilitar todas las instancias disponibles en todos los dominios, use pmDelProfile(PM_INDOM_NULL, 0, NULL). Esta es la única situación en la que indom puede ser PM_INDOM_NULL.

ADVERTENCIA

Es posible eliminar dominios de instancia inexistentes e instancias inexistentes de un perfil de instancia. Ninguna de las rutinas que usan el perfil de instancia emitirá un error si hace esto. El costo de verificar, cuando la verificación es posible, supera cualquier beneficio.

DIAGNÓSTICOS

PM_ERR_PROFILESPEC
indom era PM_INDOM_NULL y instlist no estaba vacío
