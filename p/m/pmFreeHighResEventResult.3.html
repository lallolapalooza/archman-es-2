pmFreeHighResEventResult(3)

PMFREEEVENTRESULT(3) Manual de funciones de biblioteca PMFREEEVENTRESULT(3)

NOMBRE

pmFreeHighResEventResult, pmFreeEventResult - liberar el almacenamiento asignado para registros de eventos desempaquetados

C SINOPSIS

#include <pcp/pmapi.h>

void pmFreeHighResEventResult(pmResult **hrset);
void pmFreeEventResult(pmResult_v2 **rset);

cc ... -lpcp

DESCRIPCIÓN

Al procesar registros de eventos, si pmUnpackHighResEventRecords(3) se utiliza para desempaquetar registros de eventos de una métrica dentro de una estructura pmResult con un valor de tipo PM_TYPE_HIGHRES_EVENT, entonces la estructura devuelta por pmUnpackHighResEventRecords(3) es un array de punteros a estructuras pmResult, terminado en NULL, uno por cada registro de evento.

pmFreeHighResEventResult es un método de conveniencia que libera todas las estructuras pmResult y el array de punteros (hrset).

De manera similar, pmFreeEventResult puede usarse para liberar las estructuras pmResult_v2 y el array devuelto por la rutina pmUnpackEventRecords al usar métricas de tipo PM_TYPE_EVENT.

VER TAMBIÉN

PMAPI(3) y pmUnpackEventRecords(3).
