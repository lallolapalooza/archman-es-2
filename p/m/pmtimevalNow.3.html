PMTIMEVALNOW(3) Manual de funciones de biblioteca PMTIMEVALNOW(3)

NOMBRE

pmtimevalNow, pmtimevalInc, pmtimevalDec, pmtimevalAdd, pmtimevalSub, pmtimevalToReal, pmtimevalFromReal, pmtimevalTotimespec, pmtimevalPrint - rutinas auxiliares para tiempo almacenado como struct timeval

SINOPSIS C

#include <pcp/pmapi.h>

void pmtimevalNow(struct timeval *tv);
void pmtimevalInc(struct timeval *ap, const struct timeval *bp);
void pmtimevalDec(struct timeval *ap, const struct timeval *bp);
double pmtimevalAdd(const struct timeval *ap,
const struct timeval *bp);

double pmtimevalSub(const struct timeval *ap,
const struct timeval *bp);

double pmtimevalToReal(const struct timeval *val);
void pmtimevalFromReal(double secs, struct timeval *val);
void pmtimevalTotimespec(struct timeval *tvp, struct timespec *tsp);
void pmtimevalPrint(FILE *f, const struct timeval *tp);

cc ... -lpcp

DESCRIPCIÓN

pmtimevalNow es un método independiente de la plataforma que devuelve la hora actual del sistema desde la Época en tv.

pmtimevalInc suma el tiempo en ap al tiempo en bp y almacena el resultado en ap. De forma similar, pmtimevalDec resta el tiempo en bp del tiempo en ap y almacena el resultado en ap.

pmtimevalAdd (y pmtimevalSub) suman (y restan) tiempos y devuelven el resultado como un valor doble. El tiempo en el argumento ap no se modifica.

pmtimevalToReal convierte el tiempo en tp a un valor doble equivalente. pmtimevalFromReal proporciona la conversión inversa, tomando el tiempo en secs y devolviendo el tiempo equivalente en val.

pmtimevalTotimespec convierte el struct timeval tvp en un struct timespec tsp equivalente (módulo redondeo de microsegundos a nanosegundos).

pmtimevalPrint imprime la marca de tiempo de tp en el flujo f en la hora local (tal como la devuelve pmLocaltime(3)) con el formato HH:MM:SS.XXX.

NOTAS

Para variantes de estas interfaces que utilizan precisión de nanosegundos y la estructura timespec, consulte pmtimespecNow(3).

COMPATIBILIDAD

Antes de PCP 7.0, la rutina pmtimevalPrint se llamaba pmPrintStamp. Para dar soporte a la transición de PMAPI, la rutina antigua aún se puede usar si las aplicaciones se recompilan con -DPMAPI_VERSION=2.

pmPrintStamp está ahora obsoleto y el soporte en tiempo de compilación para este nombre de rutina se eliminará en una futura versión.

VER TAMBIÉN

gettimeofday(2), time(2), PMAPI(3), pmLocaltime(3) y pmtimespecNow(3).
