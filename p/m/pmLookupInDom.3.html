NOMBRE

pmLookupInDom - traduce el nombre de una instancia a un identificador de instancia

SINOPSIS C

#include <pcp/pmapi.h>

int pmLookupInDom(pmInDom indom, const char *name);

cc ... -lpcp

DESCRIPCIÓN

Para el dominio de instancias indom, en el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI), localiza la instancia con la identificación externa dada por name y devuelve el identificador de instancia interno.

Solo los caracteres iniciales no espaciados de name se usarán para identificar la instancia.

El valor del dominio de instancias indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

pmLookupInDom devolverá un identificador de instancia positivo en caso de éxito.

DIAGNÓSTICOS

PM_ERR_INDOM
indom no es un identificador de dominio de instancia válido
PM_ERR_INST
La instancia externa name no se conoce para el dominio de instancia indom en el contexto actual de PMAPI

VER TAMBIÉN
