NOMBRE

pmaRewriteMeta - intenta cambiar la versión de un registro de metadatos de archivo

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaRewriteMeta(__pmLogCtl *inlcp,
__pmLogCtl *outlcp, __int32_t *rbuf);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que garantizan permanecer fijas en diferentes versiones, y pueden no funcionar o proporcionar una semántica diferente en algún momento en el futuro.

DESCRIPCIÓN

Un registro de metadatos físico del archivo de entrada identificado por inlcp se pasa a través de rbuf y se reforma si es necesario para producir el registro de metadatos equivalente para el archivo de salida identificado por outlcp.

Junto con las versiones de los archivos de entrada y salida, el tipo del registro de metadatos (tal como se extrae de rbuf) se utiliza para decidir si; para algunos tipos de registros y cambios de versión, no se requiere ninguna reescritura.

pmaRewriteMeta está diseñado para ser utilizado en casos donde las versiones de archivo de inlcp y outlcp son diferentes. La única opción sensata de versiones de archivo hoy en día es PM_LOG_VERS02 para inlcp y PM_LOG_VERS03 para outlcp, lo que solicitaría una reescritura del formato de la versión 2 del archivo al formato de la versión 3 del archivo (ya que actualmente solo se admiten las versiones 2 y 3).

Si se realiza la reescritura, el antiguo rbuf se habrá liberado y se habrá asignado un nuevo rbuf con malloc(3). Es responsabilidad del llamante asegurarse de que esta posible liberación y asignación sea segura, por ejemplo, sin referencias colgantes a los contenidos de rbuf, o pasar una copia del registro si es valioso.

DIAGNÓSTICOS Y VALORES DE RETORNO

En varios lugares, los errores fatales activarán un mensaje de error y forzarán la salida de la aplicación.

Si no existe una traducción definida para las versiones de inlcp y outlcp, entonces pmaRewriteMeta devuelve PM_ERR_APPVERSION (una ligera perversión de este código de error).

Si no se realiza ninguna reescritura, el valor de retorno es 0, de lo contrario, un valor de retorno de 1 indica que se ha realizado una reescritura y rbuf ha sido realocado.

VER TAMBIÉN

free(3), malloc(3), PMAPI(3), y pmaRewriteData(3).
