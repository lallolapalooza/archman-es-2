PMLOGSIZE(1) Manual de comandos generales PMLOGSIZE(1)

NOMBRE

pmlogsize - informa sobre los tamaños de partes de archivo(s) PCP

SINOPSIS

pmlogsize [-drv?] [-D debug] [-x umbral] archivo [...]

DESCRIPCIÓN

pmlogsize imprime información sobre el tamaño de los índices, metadatos y secciones de datos de un archivo de Performance Co-Pilot (PCP). La salida está destinada a guiar mejoras en el formato de codificación de archivos para los desarrolladores de PCP y a ayudar a recortar los archivos de configuración de pmlogger(1) para eliminar métricas que inflan los archivos PCP con datos de bajo valor en entornos de producción.

Los argumentos archivo pueden ser cualquier mezcla de nombres de los archivos físicos de un archivo PCP o el nombre base que es común a todos los archivos físicos componentes de un solo archivo. En este último caso, archivo se reemplaza por una lista de todos los nombres de archivo componentes coincidentes.

Tenga en cuenta que la semántica es un poco diferente a otras herramientas de PCP, ya que foo.meta significa **solo** el archivo foo.meta, no foo.index, foo.meta, foo.0, etc.

OPCIONES

Las opciones de línea de comandos disponibles son:

-d, --detalle
Habilita informes detallados. Esto significa espacio por dominio de instancia en un archivo de metadatos y espacio por métrica (para valores) en un archivo de datos.
-r, --replicacion
Muestra información adicional sobre posibles valores replicados en el archivo de datos e instancias replicadas en el archivo de metadatos. Esta opción implica -d.
-x umbral, --umbral=umbral
Con -d (o -r), corta el informe después de que al menos el umbral por ciento del espacio asociado (valores de métricas o dominios de instancia) se haya informado. El comportamiento predeterminado es equivalente a establecer el umbral en 100.
-v, --verboso
Habilita el modo verboso. Esta opción se puede proporcionar más de una vez para una verbosidad adicional.
-?, --ayuda
Muestra el mensaje de uso y sale.

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmlogcheck(1), pmlogdump(1) y pmlogger(1).
