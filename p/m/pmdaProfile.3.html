PMDAPROFILE(3) Manual de funciones de biblioteca PMDAPROFILE(3)

NOMBRE

pmdaProfile - actualiza el perfil de instancia para el PMDA en preparación para la próxima obtención de PMCD

SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaProfile(pmProfile *prof, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA) (ver PMDA(3)), pmdaProfile es la llamada de retorno predeterminada que maneja la recepción de un pmProfile de pmcd(1). Un perfil describe las instancias que pmcd requiere en la estructura pmResult devuelta por la próxima obtención. pmdaProfile simplemente almacena el nuevo perfil.

ADVERTENCIA

El PMDA debe estar usando PMDA_INTERFACE_2 o posterior, según se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

VER TAMBIÉN

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) y pmdaFetch(3).
