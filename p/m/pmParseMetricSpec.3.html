pmParseMetricSpec(3)

Paquete: pcp

Licencias: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMPARSEMETRICSPEC(3) Manual de funciones de biblioteca PMPARSEMETRICSPEC(3)

NOMBRE

pmParseMetricSpec, pmFreeMetricSpec - analizador uniforme de especificación de métricas

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmParseMetricSpec(const char *string,
int isarch, char *source, pmMetricSpec **rsltp, char **errmsg);

void pmFreeMetricSpec(pmMetricSpec *rslt);

cc ... -lpcp

DESCRIPCIÓN

pmParseMetricSpec acepta una cadena que especifica el nombre de una métrica de rendimiento de PCP, y opcionalmente la fuente (ya sea un nombre de host o un nombre de archivo de archivo de PCP) y las instancias para esa métrica. La sintaxis se describe en PCPIntro(1).

Si no se proporciona el componente host ni el componente archive de la especificación de métrica, los argumentos isarch y source se utilizan para rellenar la estructura pmMetricSpec devuelta.

La estructura pmMetricSpec que se devuelve a través de rsltp representa la cadena analizada y tiene la siguiente declaración:

    typedef struct {
        int     isarch;      /* tipo de fuente: 0 -> host en vivo, 1 -> archivo, 2 -> contexto local */
        char    *source;     /* nombre de la fuente o archivo */
        char    *metric;     /* nombre de la métrica */
        int     ninst;       /* número de instancias, 0 -> todas */
        char    *inst[1];    /* matriz de nombres de instancias */
    } pmMetricSpec;

pmParseMetricSpec devuelve 0 si la cadena dada se analizó correctamente. En este caso, todo el almacenamiento asignado por pmParseMetricSpec puede liberarse con una sola llamada a free(3) utilizando la dirección devuelta de pmMetricSpec a través de rsltp. La macro de conveniencia pmFreeMetricSpec es un envoltorio disimulado para free(3).

pmParseMetricSpec devuelve PM_ERR_GENERIC y una cadena de mensaje de error asignada dinámicamente en errmsg, si la cadena dada no se analiza. Asegúrese de free(3) la cadena del mensaje de error en esta situación.

En caso de error, rsltp no está definido. En caso de éxito, errmsg no está definido. Si rsltp->ninst es 0, entonces rsltp->inst[0] no está definido.

VER TAMBIÉN

PMAPI(3) y pmLookupName(3).
