pmt-ehd(8) pam_mount pmt-ehd(8)

Nombre

pmt-ehd - crear una imagen de disco cifrada

Sintaxis

pmt-ehd [-DFx] [-c cifrado_fs] [-h hash] [-k bits_clave_fs] [-t tipo_fs] [-H ruta_cabecera] -f ruta_contenedor -s tamaño_en_mb

Opciones

Las opciones obligatorias que falten se preguntarán interactivamente, y pmt-ehd saldrá si la entrada estándar no es una terminal.

-D
Activar cadenas de depuración.
-F
Forzar una operación que de otro modo pediría confirmación interactiva. Se pueden especificar varios -F para aplicar más fuerza.
-c cifrado
El cifrado a utilizar para el sistema de archivos. Puede tomar cualquier valor que reconozca cryptsetup(8), generalmente en la forma de "cifrado-modo[-extras]". Se recomiendan aes-cbc-essiv:sha256 (este es el valor predeterminado) o aes-xts-essiv:sha256.
-f ruta
Almacenar la nueva imagen de disco en ruta. Si el archivo ya existe, pmt-ehd preguntará antes de sobrescribir a menos que se proporcione -F. Si ruta se refiere a un enlace simbólico, pmt-ehd actuará de forma aún más cautelosa.
-H ruta
Almacenar un archivo de metadatos separado (desvinculado) con una nueva cabecera LUKS en ruta. Si el archivo ya existe, pmt-ehd preguntará antes de sobrescribir a menos que se proporcione -F. Si ruta se refiere a un enlace simbólico, pmt-ehd actuará de forma aún más cautelosa. El valor predeterminado es no usar una cabecera separada. Se correlaciona con la opción `cryptsetup --header`.
-h hash
Resumen/hash de mensaje utilizado para la derivación de claves en la etapa PBKDF2. El valor predeterminado es sha512.
-i cifrado
(Esta opción fue eliminada en pam_mount/pmt_ehd 2.11.)
-k bits_clave
El tamaño de clave para el cifrado especificado con -c. Algunos cifrados admiten múltiples tamaños de clave, AES, por ejemplo, está disponible con al menos los tamaños de clave 192 y 256. El valor predeterminado es 256 (para coincidir con aes-cbc-essiv). Tenga en cuenta que XTS usa dos claves, pero se obtienen del mismo material de clave, por lo que aes-cbc-256 es equivalente a aes-xts-512, y aes-cbc-128 es a aes-xts-256.
-p ruta
(Esta opción fue eliminada en pam_mount/pmt_ehd 2.11.)
-s tamaño
El tamaño inicial del sistema de archivos cifrado, en megabytes. Esta opción se ignora cuando el sistema de archivos se crea en un dispositivo de bloque.
-t tipo_fs
Sistema de archivos a utilizar para el sistema de archivos cifrado. El valor predeterminado es xfs.
-u usuario
Asignar los archivos de contenedor y fskey a usuario (debido a que el programa normalmente se ejecuta como root, y los archivos retendrían la propiedad de root de lo contrario).
-x
No inicializar el contenedor con bytes aleatorios. Esto puede afectar la seguridad.

Descripción

pmt-ehd puede usarse para crear un nuevo contenedor cifrado y reemplaza el script mkehd anterior, así como cualquier HOWTO que explique cómo hacerlo manualmente. Sin argumentos, pmt-ehd pedirá interactivamente todos los parámetros faltantes. Para crear un contenedor con un tamaño de 256 MB, use:

pmt-ehd -f /home/user.cont -s 256
