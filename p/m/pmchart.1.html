PMCHART(1) Manual de Comandos Generales PMCHART(1)

NOMBRE

pmchart - herramienta de gráfico de tiras para Performance Co-Pilot

SINOPSIS

pmchart [-CLVWz?] [-a archivo] [-A alineación] [--archive-folio folio] [-c archivo de configuración] [-D depuración] [-f familia de fuentes] [-F tamaño de fuente] [-g geometría] [-h host] [-n archivo de pmns] [-o archivo de salida] [-O desplazamiento] [-p puerto] [-s muestras] [-S hora de inicio] [-t intervalo] [-T hora de fin] [-v visible] [-Z zona horaria] [-geometry geometría] [fuentes...]

DESCRIPCIÓN

pmchart es una utilidad gráfica que dibuja valores de métricas de rendimiento disponibles a través de las instalaciones de Performance Co-Pilot (PCP). Se pueden mostrar varios gráficos simultáneamente, ya sea alineados en el eje de tiempo unificado (eje X) y mediante el uso de múltiples pestañas de interfaz.

Los valores de las métricas se pueden obtener de uno o más hosts en vivo (simultáneamente). Alternativamente, se pueden usar uno o más conjuntos de archivos de PCP como fuente de datos históricos. Consulte PCPIntro(1) para una discusión en profundidad de las capacidades del marco PCP, muchas de las cuales son utilizadas por pmchart.

Muchos aspectos del comportamiento de pmchart se pueden personalizar a través de la interfaz. En particular, el uso de "vistas" (consulte la sección que describe las VISTAS más adelante en este documento) permite almacenar conjuntos predefinidos de métricas y parámetros de gráficos como colores, escalado, títulos, leyendas, etc., para su uso posterior o para usar con diferentes hosts y conjuntos de archivos. Además, el diálogo de Preferencias permite guardar y restaurar personalizaciones del resto de la interfaz de usuario de pmchart entre diferentes invocaciones de la herramienta. Esto permite configurar el color de fondo predeterminado, el color de resaltado, el contenido y la ubicación de la barra de herramientas, y muchos otros aspectos.

pmchart utiliza extensivamente la utilidad pmtime(1) para el control del tiempo; consulte la página del manual de pmtime para obtener más detalles sobre su funcionamiento.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a archivo, --archive=archivo
Los valores de métricas de rendimiento se recuperan del conjunto de archivos de Performance Co-Pilot (PCP) identificados por esta opción, por defecto. El argumento es una lista de nombres separada por comas, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos. El conjunto resultante de archivos será la fuente de las métricas de rendimiento. La pestaña inicial creada será una pestaña en modo de archivo. Se pueden presentar múltiples opciones -a, y la lista resultante de conjuntos de archivos se utiliza para obtener valores de métricas. Se asume que cualquier fuente listada en la línea de comandos son conjuntos de archivos si se utiliza esta opción.
-A alineación, --align=alineación
Forzar que la muestra inicial se alinee en el límite de una unidad de tiempo natural alineación. Consulte PCPIntro(1) para una descripción completa de la sintaxis de alineación.
--archive-folio=folio
Leer archivos fuente de métricas del folio de archivos PCP.
-c archivo de configuración, --view=archivo de configuración
archivo de configuración especifica una vista inicial para cargar, utilizando la fuente predeterminada de métricas. Se pueden especificar múltiples vistas -c, y todas se abrirán en la pestaña predeterminada con la fuente predeterminada de métricas.
-c, --check
Usado con -c, las vistas se analizan, se informan los errores y la herramienta se cierra. Esto está destinado principalmente a fines de prueba. Si se presenta una segunda opción -C, pmchart también se conecta a pmcd(1) para verificar la semántica de las métricas.
-f familia, --font-family=familia
Especifica la familia de fuentes predeterminada que se utilizará en varios componentes del gráfico, como el título del gráfico, la leyenda y la etiqueta del eje Y. El valor predeterminado es "Sans Serif". Esta configuración no afecta al resto de la interfaz de usuario, donde el valor se hereda del entorno en el que opera pmchart, y difiere según el aspecto y la sensación de cada plataforma.
-F punto, --font-size=punto
Especifica el punto de tamaño de fuente predeterminado que se utilizará en varios componentes del gráfico, como el título del gráfico, la leyenda y la etiqueta del eje Y. El valor predeterminado depende de la plataforma, pero es 7, 8 o 9. Esta configuración no afecta al resto de la interfaz de usuario.
-g geometría, --geometry=geometría
Genera una imagen con la geometría especificada (ancho y alto). Esta opción solo es útil cuando se usa junto con la opción -o para generar una imagen de salida. El argumento geometría tiene el formato "WxH" (por ejemplo, 240x120). Cuando NO se utiliza la bandera -o, para especificar la geometría de la ventana de visualización, use -geometry geometría, donde geometría especifica el ancho, alto y colocación opcional deseados de la ventana.
-h host, --host=host
Los valores de métricas de rendimiento actuales se recuperan de la máquina host nominada por defecto. Se pueden presentar múltiples opciones -h, y la lista de hosts se utiliza para obtener valores de métricas. Se asume que cualquier fuente listada en la línea de comandos son hosts si se utiliza esta opción.
-H ruta, --hostsfile=ruta
Especifica la ruta a un archivo que contiene un conjunto de nombres de host donde se está ejecutando pmcd(1), en lugar de usar el localhost predeterminado.
-K espec, --spec-local=espec
Al obtener métricas de un contexto local (ver -L), la opción -K puede usarse para controlar los PMDA de DSO que deben ser accesibles. El argumento espec se ajusta a la sintaxis descrita en pmSpecLocalPMDA(3). Se puede usar más de una opción -K.
-L, --local-PMDA
Utiliza un contexto local para recopilar métricas de PMDA de DSO en el host local sin PMCD. Ver también -K.
-n archivo de pmns, --namespace=archivo de pmns
Carga un Espacio de Nombres de Métricas de Rendimiento (PMNS) alternativo (PMNS(5)) desde el archivo archivo de pmns.
-o archivo de salida, --output=archivo de salida
Genera un archivo de imagen llamado archivo de salida y luego sale. Esto es más útil cuando se ejecuta con un conjunto de archivos y una o más vistas. La imagen generada estará en el formato especificado como la extensión del archivo (determinado automáticamente a partir de archivo de salida). Si no se puede determinar una extensión, se utiliza el formato GIF y el archivo generado se nombra con esta extensión. Los formatos de archivo de imagen compatibles incluyen: bmp, jpeg, jpg, png, ppm, tif, tiff, xbm y xpm.
-O origen, --origin=origen
Al informar métricas archivadas, comience a informar en origen dentro de la ventana de tiempo (ver -S y -T). Consulte PCPIntro(1) para una descripción completa de la sintaxis de origen.
-p puerto, --guiport=puerto
Número de puerto para la conexión a un proceso de control de tiempo pmtime existente.
-s muestras, --samples=muestras
Especifica el número de muestras que se retendrán antes de descartar datos antiguos (reemplazados por nuevos valores en la posición de tiempo actual). Este valor se puede modificar posteriormente a través del diálogo Editar pestaña.

VISTAS

La configuración principal de pmchart es la "vista", que permite guardar metadatos asociados con uno o más gráficos en el sistema de archivos. Estos metadatos describen todos los aspectos de los gráficos, incluyendo qué métricas e instancias de PCP se utilizarán, qué hosts, qué colores, los títulos de los gráficos, el uso de leyendas de gráficos y mucho más.

Desde un punto de vista conceptual, hay dos clases de vistas. Estas vistas comparten el mismo formato de archivo de configuración; consulte una sección posterior para una descripción completa de este formato. Las diferencias radican en dónde se instalan y cómo se manipulan.

La primera clase, la vista "del sistema", es simplemente cualquier vista que se instala como parte del paquete pmchart. Estas se almacenan en $PCP_VAR_DIR/config/pmchart. Cuando se muestra el diálogo Archivo → Abrir Vista, estas son las vistas que se listan inicialmente. Las vistas del sistema no pueden ser modificadas por un usuario normal, y no deben ser modificadas incluso por un usuario con los privilegios adecuados, ya que serán sobrescritas durante una actualización.

La segunda clase de vista es la vista "de usuario". Estas vistas se crean sobre la marcha utilizando el diálogo Archivo → Guardar Vista. Este es un mecanismo para que los usuarios individuales guarden sus vistas de uso común. El acceso a estas vistas se logra a través del diálogo Archivo → Abrir Vista, al igual que con las vistas del sistema. Una vez que se abre el diálogo, la lista de vistas se puede alternar entre vistas de usuario y del sistema haciendo clic en los dos botones de alternancia en la esquina superior derecha. Las vistas de usuario se almacenan en $HOME/.pcp/pmchart.

PESTAÑAS

pmchart proporciona el concepto común de interfaz de usuario de la Pestaña, que es más prevalente en los navegadores web modernos. Las pestañas permiten a pmchart actualizar muchos más gráficos de los que permite el espacio de pantalla disponible, al proporcionar un mecanismo de interfaz de usuario para apilar (y alternar entre) diferentes conjuntos verticales de gráficos. El cambio entre Pestañas se logra haciendo clic en las etiquetas de Pestaña, que se encuentran en la parte superior de la pantalla debajo de las barras de Menú y Herramientas).

Cada Pestaña tiene un modo de operación (en vivo o de archivo - pmchart puede soportar ambos modos simultáneamente), el número total de muestras y puntos visibles actualmente, y una etiqueta que describe la Pestaña y que se muestra en la parte superior de la ventana de pmchart. Se pueden crear nuevas Pestañas utilizando el diálogo Archivo → Añadir Pestaña.

Para ahorrar espacio vertical en pantalla, tenga en cuenta que el elemento de la interfaz de usuario para cambiar entre diferentes Pestañas (y su etiqueta) solo se muestra cuando existen más de una Pestaña. Una Pestaña se puede descartar usando el menú Archivo → Cerrar Pestaña, que elimina la Pestaña actual y todos los gráficos que contenía.

IMÁGENES y IMPRESIÓN

Se puede capturar una copia estática de la serie vertical de gráficos que se muestra actualmente de dos maneras.

Cuando el dispositivo de visualización previsto es la pantalla, se debe utilizar la opción de menú Archivo → Exportar. Esto permite exportar los gráficos en una variedad de formatos de imagen, incluyendo PNG, JPEG, GIF y BMP. El tamaño de la imagen se puede escalar hacia arriba o hacia abajo en cualquier dimensión.

Alternativamente, cuando el dispositivo de visualización previsto es el papel, se puede utilizar la opción de menú Archivo → Imprimir. Esto soporta el conjunto habitual de opciones de impresión (elección de impresora, escala de grises/color, horizontal/vertical, escalado a diferentes tamaños de papel, etc.), y además permite imprimir a los formatos de impresora intermedios de PostScript y Formato de Documento Portátil (PDF).

GRABACIÓN

Es posible realizar una grabación de un conjunto de gráficos mostrados, para su posterior reproducción a través de pmchart o cualquiera de las otras herramientas de Performance Co-Pilot. La funcionalidad Grabar → Iniciar es simple de configurar a través de la interfaz de usuario, y permite afinar el proceso de grabación (incluyendo frecuencias de grabación que difieren del intervalo de actualización de pmchart, ubicaciones alternativas de archivos, etc.).

pmchart produce grabaciones compatibles con el mecanismo de reproducción de pmafm(1) de PCP, para su posterior reproducción a través de una nueva instancia de pmchart. Además, al grabar a través de pmchart también se puede reproducir la grabación inmediatamente, ya que al finalizar la grabación (a través del elemento de menú Grabar → Detener), se creará una pestaña en modo de archivo con la vista capturada.

Una vez que la grabación está activa en una Pestaña en Vivo, el botón de estado Control de Tiempo en la esquina inferior izquierda de la ventana de pmchart se muestra con un punto rojo distintivo. En cualquier momento durante una sesión de grabación de pmchart, la cantidad de espacio utilizado en el sistema de archivos por esa grabación se puede mostrar utilizando el elemento de menú Grabar → Consultar.

Finalmente, la opción de menú Grabar → Desvincular proporciona un mecanismo por el cual el proceso de grabación puede ser completamente separado del proceso en ejecución de pmchart, y permitirle continuar cuando pmchart salga. Se presenta un diálogo que muestra el tamaño actual y la tasa estimada de crecimiento de la grabación. Por otro lado, si pmchart se termina mientras la grabación está en proceso, el proceso de grabación le pedirá al usuario que elija la detención inmediata de la grabación o que continúe de forma independiente.

Todos los servicios en modo de grabación disponibles en pmchart se implementan con la ayuda de los servicios de registro básicos de Performance Co-Pilot; consulte pmlogger(1) y pmafm(1) para una descripción exhaustiva de las capacidades de estas herramientas.

SINTAXIS DEL ARCHIVO DE CONFIGURACIÓN

pmchart carga configuraciones de gráficos predefinidas (o "vistas") de archivos externos que se ajustan a las siguientes reglas. En las descripciones a continuación, las palabras clave (mostradas en negrita) pueden aparecer en mayúsculas, minúsculas o combinadas, los elementos mostrados en [cosas] son opcionales, y los elementos proporcionados por el usuario se muestran como <otras cosas>. Una barra vertical (|) se utiliza donde los elementos sintácticos son alternativas. Las comillas (") se pueden usar para delimitar elementos léxicos que pueden contener espacios en blanco, como títulos, etiquetas y nombres de instancias.

1.
La primera línea define el tipo de archivo de configuración y debe ser 
#kmchart
aunque pmchart proporciona retrocompatibilidad con los formatos de vista pmchart más antiguos con una línea inicial de 
#pmchart
2.
Después de la primera línea, las líneas que comienzan con "#" como primer carácter que no sea un espacio en blanco se tratan como comentarios y se ignoran. De manera similar, las líneas en blanco se ignoran.
3.
La siguiente línea debe ser 
version <n> <host-clause>
donde <n> depende del tipo de archivo de configuración, y es 1 para pmchart, de lo contrario 1.1, 1.2 o 2.0 para pmchart.
La parte <host-clause> es opcional (e ignorada) para los archivos de configuración de pmchart, pero es obligatoria para los archivos de configuración de pmchart, y tiene la forma 
host literal
o 
host dynamic
4.
Una configuración contiene uno o más gráficos definidos de la siguiente manera: 
chart [title <título>] style <estilo> <opciones>
Si se especifica, el título aparecerá centrado y encima del área del gráfico. El <título> generalmente está entre comillas (") y si contiene la secuencia "%h", esta será reemplazada por la forma corta del nombre de host de la fuente predeterminada de métricas en el momento en que se cargó este gráfico. Alternativamente, "%H" se puede usar para insertar el nombre de host completo. Si el nombre de host parece ser una dirección inet o IPv6, no se intentará acortar; se utilizará

pmchart

pmchart es un visor de gráficos de métricas de rendimiento del Kernel de Rendimiento de PC (PCP).

La sintaxis de un archivo de configuración de vista de pmchart es la siguiente:

view: <viewname>
[
[ title: <title> ]
[
[ global
  [ width <width> ]
  [ height <height> ]
  [ points <points> ]
  [ xpos <xpos> ]
  [ ypos <ypos> ]
]
[ style <style> ]
[ options
  [ scale [ from ] <ymin> [ to ] <ymax> ]
  [ legend [ on | off ] ]
]
chart
  [ title <title> ]
  [ legend <title> ]
  [ color <colorspec> ]
  [ host <hostspec> ]
  plot
    [ legend <title> ]
    [ color <colorspec> ]
    [ host <hostspec> ]
    metric <metricname>
    [ instance <inst> | matching <pat> | not-matching <pat> ]
...
]
...
[ tab <label> [ host <host> ] [ points <points> [ samples <samples> ] ] ]
...
1.
La directiva view: debe ser la primera línea del archivo de configuración y declara el nombre de la vista. <viewname> es un nombre arbitrario para la vista.
2.
El title: es opcional y declara el título de la ventana de la vista. Si se omite, no se mostrará ningún título en la barra de título de la ventana. El título se muestra a menudo entre comillas dobles.
3.
La directiva global es opcional y especifica los valores predeterminados para los gráficos dentro de esta vista. Los valores se aplican a menos que se anulen explícitamente en la directiva chart. Las directivas válidas dentro de global son:
width
Define el ancho de la ventana gráfica en píxeles. El valor predeterminado es 575.
height
Define la altura de la ventana gráfica en píxeles. El valor predeterminado es 400.
points
Define el número de puntos de datos que se mostrarán en el gráfico. El valor predeterminado es 64.
xpos
Define la posición X inicial de la ventana en la pantalla. El valor predeterminado es 0.
ypos
Define la posición Y inicial de la ventana en la pantalla. El valor predeterminado es 0.
4.
Las directivas style y options son opcionales y solo se pueden usar una vez en una vista. Si se especifican, deben seguir a la directiva global (si está presente) y preceder a la primera directiva chart. Controlan el estilo de trazado inicial y las opciones de escala y leyenda para todos los gráficos de la vista.
style
Controla el estilo de trazado inicial del gráfico y debe ser una de las palabras clave plot (gráfico de líneas), bar, stacking (barras apiladas), area o utilization. Después de cargar la vista, el estilo de trazado se puede cambiar usando la lista desplegable Estilo en el diálogo Editar→Gráfico.
options
Cero o más de los siguientes elementos opcionales:
[scale [from] <ymin> [to] <ymax>]
Si se especifica scale, la escala vertical se establece para todas las gráficas del gráfico a un rango y definido por <ymin> y <ymax>. De lo contrario, el eje vertical se autoescalará según los valores que se estén trazando actualmente.
[legend <onoff>]
donde <onoff> es una de las palabras clave on u off. La cláusula legend controla la presencia o ausencia de la leyenda del gráfico debajo del área del gráfico. El valor predeterminado es que la leyenda se muestre. Después de cargar la vista, la visibilidad de la leyenda se puede activar/desactivar usando el botón Mostrar Leyenda en el diálogo Editar→Gráfico.
5.
pmchart admite una cláusula global para especificar las dimensiones de la ventana de nivel superior (usando las palabras clave width y height), el número de puntos visibles (palabra clave points) y las posiciones iniciales de los ejes X e Y en la pantalla (palabras clave xpos y ypos). Cada uno de estos atributos global toma un valor entero como único calificador.

La visibilidad y configuración del título se pueden manipular después de cargar la vista usando el cuadro de texto Título del gráfico en el diálogo Editar→Gráfico.

6.
Cada chart tiene una o más gráficas asociadas con él, según se define en una de las siguientes especificaciones: 
plot
    [legend <title>] [color <colorspec>] [host <hostspec>]
    metric <metricname>
    [ instance <inst> | matching <pat> | not-matching <pat> ]

La palabra clave plot puede ser reemplazada por la palabra clave optional-plot, en cuyo caso, si la fuente de datos de rendimiento no incluye la métrica y/o instancia de rendimiento especificada, esa gráfica se eliminará silenciosamente del gráfico.

Si se especifica, el título aparecerá en la leyenda del gráfico. El <title> generalmente se encierra entre comillas (") y puede contener uno o más caracteres comodín que se expandirán utilizando el nombre de la métrica, el nombre de la instancia y el nombre del host para la gráfica. Los comodines son "%i" (nombre de instancia corto único, hasta el primer espacio en blanco), "%I" (nombre de instancia completo), "%h" (nombre de host corto, hasta el primer punto), %H (nombre de host completo), "%m" (nombre de métrica reducido a los dos últimos componentes de PMNS) y "%M" (nombre de métrica completo).

Para archivos de configuración más antiguos de pmchart, la palabra clave title debe usarse en lugar de legend. Actualmente, pmchart admite cualquiera de las dos palabras clave.

La cláusula color es opcional para los archivos de configuración más nuevos de pmchart, pero era obligatoria en el formato original del archivo de configuración de pmchart. <colorspec> puede ser una de las siguientes:

#-cycle
rgbi:rr:gg:bb
#rgb
#rrggbb
#rrrgggbbb
#rrrrggggbbbb
<Xcolor>
donde cada uno de r, g y b son dígitos hexadecimales (0-9 y A-F) que representan respectivamente los componentes de color rojo, verde y azul. <Xcolor> es uno de los nombres de color de la base de datos de colores X, por ejemplo, red o steelblue, consulte también la salida de showrgb(1).

El color #-cycle especifica que pmchart debe usar el siguiente color de una paleta de colores que utiliza cíclicamente para cada gráfico. Este es el valor predeterminado si se omite la cláusula color.

El <hostspec> en la cláusula host puede ser un nombre de host, una dirección IP o un asterisco (*); este último se utiliza para significar la fuente predeterminada de métricas de rendimiento. Para archivos de configuración más antiguos de pmchart, la cláusula host debe estar presente, para archivos de configuración nuevos de pmchart es opcional, y si falta se usará la fuente predeterminada de métricas de rendimiento.

La especificación opcional de instancia:

(a)
se omite, en cuyo caso se creará una gráfica para cada instancia de la métrica <metricname>.
(b)
comienza con instance, en cuyo caso solo se trazará la instancia llamada <inst>.
(c)
comienza con matching, en cuyo caso se trazarán todas las instancias cuyos nombres coincidan con el patrón <pat>; el patrón utiliza la notación de expresiones regulares extendidas al estilo de egrep(1) (consulte la vista PMCD para ver un ejemplo).
(d)
comienza con not-matching, en cuyo caso se trazarán todas las instancias cuyos nombres no coincidan con el patrón <pat>; el patrón utiliza la notación de expresiones regulares extendidas al estilo de egrep(1) (consulte la vista Netbytes para ver un ejemplo).

pmchart utiliza una notación sintáctica peculiar donde <inst> y <pat> se extienden desde el primer carácter que no es un espacio en blanco hasta el final de la línea de entrada. Para los archivos de configuración de pmchart, estos elementos están delimitados por espacios en blanco o entrecomillados (").

7.
La directiva opcional tab se puede usar para crear vistas con varios gráficos que abarcan varias pestañas. La sintaxis es la siguiente: 
tab <label> [host <host>] [points <points> [samples <samples>]]



Todas las especificaciones de gráfico que siguen a esta palabra clave se crearán
en la nueva Pestaña, hasta el final del archivo de configuración o hasta que
se encuentre otra palabra clave tab.








ENTORNO PCP


Las variables de entorno con el prefijo PCP_ se utilizan para
    parametrizar los nombres de archivos y directorios utilizados por PCP. En cada
    instalación, el archivo /etc/pcp.conf contiene los valores locales
    para estas variables. La variable $PCP_CONF se puede utilizar para
    especificar un archivo de configuración alternativo, como se describe en
    pcp.conf(5).


En particular, la configuración de $PCP_XCONFIRM_PROG es
    anulada explícita e incondicionalmente por pmchart. Esto se establece
    en la utilidad pmconfirm(1), para que
    algunos diálogos emergentes (particularmente en el área de Grabación)
    mantengan una apariencia y sensación consistentes con el resto de la
    aplicación pmchart.






OPCIONES DE DEPURACIÓN


La opción -D o --debug habilita la salida de
    diagnósticos adicionales en stderr para ayudar a diagnosticar
    problemas, aunque la información a veces es críptica y está destinada
    principalmente a guiar a los desarrolladores en lugar de a los
    usuarios finales. debug es una lista separada por comas de opciones de
    depuración; use pmdbg(1) con la opción -l para
    obtener una lista de las opciones de depuración disponibles y su significado.


Las opciones de depuración específicas para pmchart son las
    siguientes:



  

    Opción
    Descripción
  

  

    appl2
    análisis y carga de vistas
  

  

    appl3
    escáner léxico del análisis de vistas

pmchart(1)

                

NOMBRE


pmchart - herramienta gráfica de monitorización de rendimiento.



SINOPSIS


pmchart [-?] [-h] [-V] [-a archivo] [-c config] [-d dims] [-D debug] [-f frecuencia] [-H host] [-i intervalo] [-l longitud] [-n nombres] [-o outfmt] [-P puerto] [-q cola] [-r regs] [-s salida] [-t tiempo] [-T tasa] [-u usuario] [-w ancho] [-x extradir] [-y dims]



DESCRIPCIÓN


pmchart es una herramienta de monitorización de rendimiento interactiva que puede mostrar un número configurable de métricas de rendimiento en gráficos en tiempo real o almacenar los datos en un archivo.



OPCIONES


Las siguientes opciones están disponibles:


    

  • -?, -h, --help: Muestra información de ayuda.
    • 

  • -V, --version: Muestra la versión de pmchart.
    • 

  • -a archivo, --archive archivo: Lee métricas de rendimiento del archivo de archivo especificado.
    • 

  • -c config, --config config: Especifica un archivo de configuración para pmchart.
    • 

  • -d dims, --dims dims: Especifica las dimensiones para los contadores, en el formato ``contador [=dimensión]'' .
    • 

  • -D debug, --debug debug: Habilita las opciones de depuración especificadas.
    • 

  • -f frecuencia, --freq frecuencia: Establece la frecuencia de actualización de la pantalla en segundos.
    • 

  • -H host, --host host: Especifica el host de donde obtener las métricas de rendimiento.
    • 

  • -i intervalo, --interval intervalo: Especifica el intervalo de tiempo en segundos para la recopilación de métricas.
    • 

  • -l longitud, --length longitud: Especifica la longitud de la ventana de tiempo a mostrar en el gráfico.
    • 

  • -n nombres, --names nombres: Especifica el archivo de nombres de métricas de rendimiento.
    • 

  • -o outfmt, --output-format outfmt: Especifica el formato de salida.
    • 

  • -P puerto, --port puerto: Especifica el puerto de red para la comunicación con pmcd.
    • 

  • -q cola, --queue cola: Especifica el tamaño de la cola de eventos.
    • 

  • -r regs, --regs regs: Especifica el número de registros de eventos.
    • 

  • -s salida, --save salida: Guarda las métricas de rendimiento en el archivo especificado.
    • 

  • -t tiempo, --time tiempo: Especifica el tiempo de inicio para la recopilación de métricas.
    • 

  • -T tasa, --rate tasa: Especifica la tasa de muestreo de métricas.
    • 

  • -u usuario, --user usuario: Especifica el usuario que ejecuta pmchart.
    • 

  • -w ancho, --width ancho: Especifica el ancho del gráfico en píxeles.
    • 

  • -x extradir, --extra-dir extradir: Especifica un directorio adicional para buscar archivos de configuración y métricas.
    • 

  • -y dims, --dims-config dims: Especifica un archivo de configuración para las dimensiones de los contadores.
    • 




VISTAS


pmchart puede mostrar las métricas de rendimiento en diferentes vistas:


    

  • graph: Muestra las métricas en un gráfico de líneas.
    • 

  • text: Muestra las métricas en formato de texto.
    • 

  • histogram: Muestra un histograma de las métricas.
    • 




PANELES


Se pueden configurar múltiples paneles para mostrar diferentes métricas o vistas.



IMÁGENES y PULSO


pmchart puede generar imágenes de los gráficos o enviar pulsos para indicar la actividad.



GRABACIÓN


Los datos de rendimiento recopilados se pueden grabar en un archivo para su posterior análisis.



SINTAXIS DEL ARCHIVO DE CONFIGURACIÓN


El archivo de configuración de pmchart utiliza una sintaxis simple para definir las métricas a mostrar, las vistas y otras opciones.



ENTORNO PCP


pmchart utiliza el sistema Performance Co-Pilot (PCP) para recopilar métricas de rendimiento. Se pueden configurar variables de entorno para controlar el comportamiento de PCP.



OPCIONES DE DEPURACIÓN


Se pueden habilitar varias opciones de depuración para diagnosticar problemas con pmchart.



VER TAMBIÉN


pmcd(1), pmlogger(1), pmrep(1)
