PMDADSO(3) Manual de funciones de biblioteca PMDADSO(3)

NOMBRE

pmdaDSO - inicializa la PMDA para que se ejecute como una DSO

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaDSO(pmdaInterface *dispatch,
int interface, char *name, char *helptext);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

pmdaDSO inicializa la estructura pmdaInterface para usar las extensiones de interface, asumiendo que la PMDA(3) se ejecutará como una DSO. La estructura pmdaInterface se inicializa con:

name
El nombre del agente.
helptext
La ruta predeterminada al texto de ayuda (ver pmdaText(3)). Si no se instala ningún texto de ayuda, o si no está utilizando pmdaText(3), esto debe establecerse en NULL, de lo contrario, helptext se copiará, por lo que el almacenamiento asociado con helptext puede liberarse después de la llamada a pmdaDSO.

Las devoluciones de llamada se inicializan a pmdaProfile(3), pmdaFetch(3), pmdaDesc(3), pmdaText(3), pmdaInstance(3) y pmdaStore(3).

La estructura interface también contiene el domain de la PMDA(3), que se define en el archivo de configuración de pmcd(1). El domain se utiliza para inicializar los descriptores de métricas e instancias (ver pmdaInit(3)).

ADVERTENCIA

La PMDA debe estar usando PMDA_INTERFACE_2 o posterior.

Una vez que se ha llamado a pmdaDSO, se espera que la estructura pmdaInterface apuntada por dispatch permanezca accesible para las rutinas de libpcp_pmda (no se recupere de la pila, no se libere ni se revoque de ninguna otra manera, etc.). Si el llamador necesita mover o reubicar la estructura pmdaInterface por cualquier motivo, después de moverla se debe llamar a pmdaInterfaceMoved(3) para restablecer la integridad interna de la estructura pmdaInterface en la nueva ubicación antes de llamar a cualquier otra rutina de libpcp_pmda.

DIAGNÓSTICOS

Versión incompatible de pmcd detectada
Cuando pmcd(1) crea la estructura pmdaInterface, el campo dispatch.comm.version se establece en el protocolo más alto que pmcd(1) entiende. Este mensaje indica que el proceso pmcd(1) no entiende el protocolo utilizado por pmdaDSO.
No se puede asignar memoria para la estructura pmdaExt
Además, dispatch->status se establece en un valor menor que cero.

VER TAMBIÉN

pmcd(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaInit(3), pmdaInterfaceMoved(3) y pmdaText(3).
