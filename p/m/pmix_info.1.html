pmix_info — Muestra información sobre la instalación de PMIx

SINOPSIS

pmix_info [opciones]

DESCRIPCIÓN

pmix_info proporciona información detallada sobre la instalación de PMIx. Puede ser útil para al menos tres escenarios comunes:

1.
Comprobar la configuración local y ver cómo se instaló PMIx.
2.
Enviar informes de errores / solicitudes de ayuda a la comunidad de PMIx (ver Obtener ayuda).
3.
Ver una lista de los plugins de PMIx instalados y consultar qué parámetros MCA admiten.

OPCIONES

pmix_info acepta las siguientes opciones:

  • -h | --help <arg0>: Muestra el mensaje de ayuda. Si no se proporciona el argumento opcional, se devuelve un mensaje de ayuda generalizado similar a la información proporcionada aquí. Si se proporciona un argumento, se devuelve un mensaje de ayuda más detallado para esa opción de línea de comandos específica.
  • -v | --verbose: Habilita la salida de depuración.
  • -V | --version: Imprime la versión y sale.
  • -a | --all: Muestra todas las opciones de configuración y parámetros MCA.
  • --arch: Muestra la arquitectura en la que se compiló PMIx.
  • -c | --config: Muestra las opciones de configuración
  • --hostname: Muestra el nombre del host en el que se configuró y compiló PMIx.
  • --internal: Muestra los parámetros MCA internos (no destinados a ser modificados por los usuarios).
  • --param <arg0>:<arg1>,<arg2>: Muestra los parámetros MCA. El primer parámetro es el framework (o la palabra clave “all”); el segundo parámetro es una lista separada por comas de nombres de componentes específicos (si solo se proporciona <arg0>, se informarán todos los componentes).
  • --path <type>: Muestra las rutas con las que se configuró PMIx. Acepta los siguientes parámetros: prefix, bindir, libdir, incdir, pkglibdir, sysconfdir.
  • --pretty-print: Cuando se usa junto con otros parámetros, la salida se muestra en formato “prettyprint” (predeterminado)
  • --parsable: Cuando se usa junto con otros parámetros, la salida se muestra en un formato legible por máquina
  • --parseable: Sinónimo de --parsable
  • --show-failed: Muestra los componentes que fallaron al cargarse junto con la razón por la que fallaron
  • --selected-only: Muestra solo variables de los componentes seleccionados.

ESTADO DE SALIDA

Devuelve 0 si tiene éxito, un valor distinto de cero si se produce un error

EJEMPLOS

Ejemplos de uso de este comando.

Mostrar la salida predeterminada de opciones y la lista de componentes instalados en formato legible para humanos / prettyprint:

pmix_info

Mostrar la salida predeterminada de opciones y la lista de componentes instalados en formato legible por máquina:

pmix_info --parsable

Mostrar los parámetros MCA del componente PNET “opa” en formato legible para humanos / prettyprint:

pmix_info --param pnet opa

Mostrar el “bindir” con el que se configuró PMIx:

pmix_info --path bindir

Mostrar la versión de los números de versión de PMIx en formato prettyprint:

pmix_info --version

Mostrar *toda* la información sobre la instalación de PMIx, incluyendo todos los componentes que se pueden encontrar, todos los parámetros MCA que admiten, las versiones de PMIx y los componentes, etc.:

pmix_info --all
