PMIWRITE(3) Manual de funciones de biblioteca PMIWRITE(3)

NOMBRE

pmiWrite - vaciar datos a un archivo LOGIMPORT

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiWrite(int sec, int usec);

cc ... -lpcp_import -lpcp

PERL SINOPSIS

use PCP::LogImport;

pmiWrite($sec, $usec);

DESCRIPCIÓN

Como parte de la API de Importación de Registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiWrite fuerza los valores de datos acumulados a ser escritos en el archivo PCP.

Los valores de datos y metadatos asociados se han construido previamente mediante llamadas a pmiAddMetric(3), pmiAddInstance(3), pmiPutValue(3) y pmiPutValueHandle(3).

El conjunto actual de valores de datos y cualquier metadato nuevo se escribe en el archivo con una marca de tiempo de sec y usec en la zona horaria de origen del archivo, ver pmiSetTimezone(3).

DIAGNÓSTICOS

pmiWrite devuelve cero en caso de éxito, de lo contrario, un valor negativo que se puede convertir en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3), pmiPutLabel(3) y pmiSetTimezone(3).
