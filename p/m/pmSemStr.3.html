PMSEMSTR(3) Manual de funciones de biblioteca PMSEMSTR(3)

NOMBRE

pmSemStr, pmSemStr_r - convertir una semántica de métrica de rendimiento a una cadena

C SINOPSIS

#include <pcp/pmapi.h>

const char *pmSemStr(int sem);
char *pmSemStr_r(int sem, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Dada una semántica de métrica de rendimiento, pmSemStr produce un equivalente ASCII conciso, adecuado para su uso en mensajes de error y diagnóstico. La función pmSemStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos 20 bytes.

El valor de sem se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Los ejemplos son counter (para sem igual a PM_SEM_COUNTER), discrete (para sem igual a PM_SEM_DISCRETE), instant (para sem igual a PM_SEM_INSTANT), etc.

NOTAS

Ambas rutinas son seguras para llamar desde aplicaciones con hilos.

VER TAMBIÉN

PMAPI(3), pmAtomStr(3), pmConvScale(3), pmExtractValue(3), pmLookupDesc(3), pmPrintValue(3), pmIDStr(3), pmInDomStr(3), pmTypeStr(3) y pmUnitsStr(3).
