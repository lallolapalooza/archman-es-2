PMDABPFTRACE(1) Manual de Comandos Generales PMDABPFTRACE(1)

NOMBRE

pmdabpftrace - PMDA de bpftrace

DESCRIPCIÓN

pmdabpftrace es un Agente de Dominio de Métricas de Rendimiento (PMDA) de Performance Co-Pilot (PCP) que exporta métricas de scripts de bpftrace(8).

CONFIGURACIÓN

pmdabpftrace lee un archivo de configuración opcional de estilo ini:

$PCP_PMDAS_DIR/bpftrace/bpftrace.conf

Este archivo puede contener secciones [bpftrace] y [dynamic_scripts]. Si habilita la funcionalidad de scripts dinámicos, consulte https://pcp.io/docs/lab.auth.html sobre cómo configurar la autenticación. Esto es altamente recomendado, ya que de lo contrario cualquiera podría ejecutar cualquier script de bpftrace(8) como root.

La sección [bpftrace] especifica valores para la siguiente configuración (sus valores predeterminados se muestran entre paréntesis):

bpftrace_path (bpftrace)
Ruta al ejecutable de bpftrace(8).
script_expiry_time (60)
Los scripts sin nombre se eliminan después de este período de tiempo (en segundos) en caso de que no haya habido solicitudes de sus valores.
max_throughput (2097152)
Rendimiento máximo de los scripts de bpftrace en bytes.

La sección [dynamic_scripts] especifica valores para la siguiente configuración (sus valores predeterminados se muestran entre paréntesis):

enabled (false)
Un valor booleano para especificar si el script debe iniciarse bajo demanda, ejecutando pmStore (3) bpftrace.control.register. Esta función debe estar habilitada para la fuente de datos PCP bpftrace en grafana-pcp.
auth_enabled (true)
Un valor booleano para especificar si se requiere autenticación o no. Por favor, consulte la nota anterior sobre la configuración de autenticación.
allowed_users (root)
Una lista de nombres de usuario separados por comas que tienen permitido registrar scripts de bpftrace(8).

INSTALACIÓN

Para instalar, se deben realizar los siguientes pasos como root:

# cd $PCP_PMDAS_DIR/bpftrace
# ./Install

Para desinstalar, se deben realizar los siguientes pasos como root:

# cd $PCP_PMDAS_DIR/bpftrace
# ./Remove

pmdabpftrace es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/bpftrace/bpftrace.conf
archivo de configuración para el agente pmdabpftrace
$PCP_PMDAS_DIR/bpftrace/Install
script de instalación para el agente pmdabpftrace
$PCP_PMDAS_DIR/bpftrace/Remove
script para deshacer la instalación del agente pmdabpftrace
$PCP_LOG_DIR/pmcd/bpftrace.log
archivo de registro predeterminado para mensajes del agente pmdabpftrace

Tenga en cuenta que el valor habitual/predeterminado para $PCP_PMDAS_DIR es /var/lib/pcp/pmdas y el predeterminado para $PCP_LOG_DIR es /var/log/pcp, pero estas configuraciones dependen de la plataforma.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1) y bpftrace(8).
