PMHTTPNEWCLIENT(3) Manual de funciones de biblioteca PMHTTPNEWCLIENT(3)

NOMBRE

pmhttpNewClient, pmhttpFreeClient, pmhttpClientFetch - interfaces simples de cliente HTTP

SINTAXIS C

#include <pcp/pmapi.h>
#include <pcp/pmhttp.h>

struct http_client *pmhttpNewClient(void);
void pmhttpFreeClient(struct http_client *client);
int pmhttpClientFetch(struct http_client *client,
const char *url, char *bodybuf, size_t bodylen, char *typebuf, size_t typelen);

cc ... -lpcp_web

DESCRIPCIÓN

pmhttpNewClient asigna e inicializa un cliente HTTP opaco que está listo para realizar solicitudes desde un servidor.

La interfaz de solicitud de URL pmhttpClientFetch emite una solicitud HTTP GET al servidor especificado en la url proporcionada. El cuerpo de la respuesta se devuelve en el búfer bodybuf proporcionado por el llamador, con una longitud de bodylen bytes. Opcionalmente, se puede proporcionar un búfer typebuf, de typelen bytes de longitud, y (si no es NULL) contendrá el valor del encabezado content-type devuelto por el servidor.

El parámetro url es una URL en formato RFC1630. Esto normalmente irá precedido por "http://", sin embargo, estas interfaces también soportan sockets de dominio Unix. Estos estarán precedidos por "unix://", seguido de la ruta completa del sistema de archivos al socket de dominio Unix deseado.

Para liberar los recursos asociados con un cliente HTTP, incluido el cierre de cualquier conexión persistente con el servidor que se haya establecido anteriormente, se utiliza la rutina pmhttpFreeClient.

DIAGNÓSTICOS

pmhttpNewClient devolverá NULL en caso de fallo, lo que solo puede ocurrir cuando no es posible la asignación de memoria.

pmhttpClientFetch devolverá el número de bytes colocados en el búfer bodybuf, o un código de error negado que indica la naturaleza del fallo.

VER TAMBIÉN

pmdaapache(1), pmjsonInit(3), PMAPI(3), PMWEBAPI(3) y https://tools.ietf.org/html/rfc1630.
