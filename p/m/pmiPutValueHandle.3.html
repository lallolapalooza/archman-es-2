PMIPUTVALUEHANDLE(3) Manual de funciones de la biblioteca PMIPUTVALUEHANDLE(3)

NOMBRE

pmiPutValueHandle - agregar un valor para un par métrica-instancia a través de un manejador

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutValueHandle(int handle, const char *value);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiPutValueHandle($handle, $value);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiPutValueHandle agrega un valor único al registro de salida actual para una métrica e instancia dadas, utilizando el handle definido por una llamada anterior a pmiGetHandle(3).

El value debe estar en un formato consistente con el tipo de la métrica tal como se define en la llamada a pmiAddMetric(3).

No se escribirán datos hasta que se llame a pmiWrite(3), por lo que generalmente se usan múltiples llamadas a pmiPutValueHandle o pmiPutValue(3) para acumular valores de datos para varios pares métrica-instancia antes de llamar a pmiWrite(3).

DIAGNÓSTICOS

pmiPutValueHandle devuelve cero en caso de éxito; de lo contrario, devuelve un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiErrStr(3), pmiGetHandle(3), pmiPutResult(3), pmiPutValue(3), pmiPutText(3), pmiPutLabel(3) y pmiWrite(3).
