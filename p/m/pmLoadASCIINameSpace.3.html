NOMBRE

pmLoadASCIINameSpace - establecer un PMNS local para una aplicación

C SINOPSIS

#include <pcp/pmapi.h>

int pmLoadASCIINameSpace(const char *filename, int dupok);

cc ... -lpcp

DESCRIPCIÓN

Si la aplicación desea forzar el uso de un Espacio de Nombres de Métricas de Rendimiento (PMNS) local en lugar de un PMNS distribuido, debe cargar el PMNS usando pmLoadASCIINameSpace o pmLoadNameSpace(3). Si la aplicación desea usar un PMNS distribuido, entonces NO debe llamar a la función para cargar el PMNS explícitamente.

La mayoría de las aplicaciones que utilizan un contexto de Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) (de cualquier tipo, ya sea PM_CONTEXT_HOST, PM_CONTEXT_ARCHIVE o PM_CONTEXT_LOCAL) no deberían necesitar llamar a pmLoadASCIINameSpace.

El argumento filename designa el PMNS de interés. Para aplicaciones que no requieren un PMNS personalizado, se puede usar el valor especial PM_NS_DEFAULT para filename, para forzar la carga del PMNS local por defecto.

El PMNS local por defecto se encuentra en el archivo $PCP_VAR_DIR/pmns/root a menos que la variable de entorno PMNS_DEFAULT esté configurada, en cuyo caso se asume que el valor es la ruta al archivo que contiene el PMNS local por defecto.

pmLoadASCIINameSpace es una variante de pmLoadNameSpace(3) en la que el argumento dupok se puede utilizar para controlar el manejo de múltiples nombres en el PMNS que pueden estar asociados con un único Identificador de Métrica de Rendimiento (PMID). Un valor de 0 prohíbe duplicados, cualquier otro valor permite duplicados y este último es el comportamiento por defecto de pmLoadNameSpace(3) a partir de la versión 3.10.3 de PCP.

La otra diferencia es que cuando se usa pmLoadASCIINameSpace y filename no es PM_NS_DEFAULT, el archivo PMNS siempre se preprocesará con pmcpp(1) como se describe en PMNS(5). Esto permite que un archivo PMNS que contenga comentarios estilo C, directivas del preprocesador o macros se procese correctamente antes de analizar el PMNS.

pmLoadASCIINameSpace devuelve cero si tiene éxito.

DIAGNÓSTICOS

Los errores de sintaxis y otros errores al analizar el PMNS se informan en stderr con un mensaje de la forma ``Error Parsing ASCII PMNS: ...''.

PM_ERR_DUPPMNS

Es un error intentar cargar más de un PMNS, o llamar a pmLoadASCIINameSpace y/o pmLoadNameSpace(3) más de una vez.

PM_ERR_PMNS

Error de sintaxis en un PMNS de formato ASCII.

ARCHIVOS

$PCP_VAR_DIR/pmns/root
el PMNS local por defecto, cuando la variable de entorno PMNS_DEFAULT no está establecida.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables se pueden obtener programáticamente utilizando la función pmGetConfig(3).
