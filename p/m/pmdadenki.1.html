PMDADENKI(1) Manual de comandos generales PMDADENKI(1)

NOMBRE

pmdadenki - métricas relacionadas con el consumo eléctrico del sistema

SINOPSIS

$PCP_PMDAS_DIR/denki/pmdadenki [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

pmdadenki es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento relacionadas con la electricidad.

Actualmente, las métricas de la función de CPU Intel Running Average Power Limit (RAPL) y los valores de carga de la batería están disponibles, si son compatibles con el hardware.

-l Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado denki.log en el directorio actual de pmcd(1) cuando se inicia pmdadenki, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.

INSTALACIÓN

El PMDA denki se instala y está disponible por defecto en Linux. Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/denki
# ./Remove

Si desea restablecer el acceso a los nombres, texto de ayuda y valores para las métricas de denki una vez más, después de la desinstalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/denki
# ./Install

pmdadenki es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o desinstala.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos usadas para lanzar pmdadenki
$PCP_PMDAS_DIR/denki/help
archivo de texto de ayuda predeterminado para las métricas de denki
$PCP_PMDAS_DIR/denki/Install
script de instalación para el agente pmdadenki
$PCP_PMDAS_DIR/denki/Remove
script para deshacer la instalación del agente pmdadenki
$PCP_LOG_DIR/pmcd/denki.log
archivo de registro predeterminado para mensajes de error y otra información de pmdadenki

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista de opciones de depuración separadas por comas; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas de pmdadenki son las siguientes:

Opción Descripción
appl0 diagnósticos detallados
