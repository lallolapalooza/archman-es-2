PMDAEVENTCLIENT(3) Manual de funciones de biblioteca PMDAEVENTCLIENT(3)

NOMBRE

pmdaEventNewClient, pmdaEventEndClient, pmdaEventClients - interfaces de seguimiento de contexto de cliente para colas de eventos

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaEventNewClient(int context);
int pmdaEventEndClient(int context);
int pmdaEventClients(pmAtomValue *avp);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta registros de eventos necesita rastrear qué clientes están conectados a él, para poder rastrear qué eventos se han enviado a qué clientes hasta ahora. Solo una vez que un evento ha sido enviado a todas las herramientas de monitorización que registraron un interés, el evento puede ser descartado y cualquier memoria recuperada.

La biblioteca PMDA(3) proporciona rutinas de retrollamada para que los desarrolladores de PMDA proporcionen un manejo personalizado de las conexiones y desconexiones de clientes. Si el PMDA está utilizando el mecanismo de cola de eventos proporcionado por pmdaEventNewQueue(3) y similares, las conexiones y desconexiones de clientes deben rastrearse mediante llamadas a pmdaEventNewClient y pmdaEventEndClient respectivamente. Esto permite a la biblioteca realizar un seguimiento de cuándo se pueden descartar los eventos de una cola, por ejemplo, para el context especificado. Este parámetro se pasa directamente a la rutina de retrollamada e_endCallBack, y para otras rutinas de retrollamada está disponible a través del campo e_context de la estructura pmdaExt. Además, se puede consultar en cualquier momento utilizando pmdaGetContext(3).

A veces es útil para el PMDA exportar una métrica que indique el recuento actual de clientes adjuntos; esto está disponible utilizando la rutina pmdaEventClients, que rellenará la estructura pmAtomValue avp en nombre de una rutina de retrollamada de obtención de PMDA.

VER TAMBIÉN

pmdaEventNewArray(3), pmdaEventNewQueue(3), PMAPI(3), PMDA(3) y pmEventFlagsStr(3).
