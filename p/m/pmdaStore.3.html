PMDASTORE(3) Manual de funciones de biblioteca PMDASTORE(3)

NOMBRE

pmdaStore - almacenar un valor en una métrica para un PMDA

SINTAXIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaStore(pmResult *result, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA) (ver PMDA(3)), pmdaStore es la devolución de llamada genérica para almacenar un valor en una métrica. pmdaStore suele ser una operación nula ya que, por defecto, no se pueden modificar métricas. Además, la implementación de una devolución de llamada de almacenamiento que sí permite que las métricas sean modificadas por pmstore(1) depende mucho de la aplicación.

ADVERTENCIA

El PMDA debe estar utilizando PMDA_INTERFACE_2 o posterior, tal como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICOS

pmdaStore devuelve PM_ERR_PERMISSION para indicar que no se pueden modificar métricas.

VER TAMBIÉN

pmstore(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) y pmStore(3).
