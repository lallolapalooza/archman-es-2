PMIERRSTR(3) Manual de funciones de biblioteca PMIERRSTR(3)

NOMBRE

pmiErrStr, pmiErrStr_r - convertir un código de error de LOGIMPORT a una cadena

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/import.h>

const char *pmiErrStr(int code);
char *pmiErrStr_r(int code, char buf, int buflen);

cc ... -lpcp_import -lpcp

Perl SINOPSIS

use PCP::LogImport;

pmiErrStr($code);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiErrStr traduce los códigos de error devueltos por las otras rutinas de la biblioteca Log Import a mensajes de error imprimibles.

code normalmente tendría un valor negativo. Como caso especial, si code es -1, se utilizará el código de error devuelto por la última rutina llamada en la biblioteca LOGIMPORT para este contexto.

La función pmiErrStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos PMI_MAXERRMSGLEN bytes.

El conjunto de códigos y mensajes de error posibles son todos aquellos definidos por pmErrStr(3) y PCPIntro(3), más los adicionales definidos en <pcp/import.h> con nombres de código de error de la forma PMI_ERR_....

VER TAMBIÉN

LOGIMPORT(3), PCPIntro(3) y pmErrStr(3).
