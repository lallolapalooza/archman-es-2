PMDAUWSGI(1) Manual de comandos generales PMDAUWSGI(1)

NOMBRE

pmdauwsgi - agente de dominio de métricas de rendimiento de uwsgi (PMDA)

DESCRIPCIÓN

pmdauwsgi es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta métricas de rendimiento de uwsgi. uWSGI se utiliza a menudo junto con servidores web como Nginx, que ofrecen soporte directo para el protocolo nativo uwsgi de uWSGI, para servir aplicaciones web de Python como Django.

pmdauwsgi lee un archivo de configuración opcional estilo ini:

$PCP_SYSCONF_DIR/uwsgi/uwsgi.conf

Este archivo tiene una sección [pmda]

[pmda]

host = (127.0.0.1)
Conectar el servidor de estadísticas de uwsgi en el nombre de host proporcionado.
port = (9051)
Conectar al servidor de estadísticas de uwsgi en el puerto proporcionado.

INSTALACIÓN

Este PMDA requiere que uwsgi se esté ejecutando en el host local con un servidor de estadísticas de uwsgi ejecutándose en el puerto TCP 9051 (por defecto) y con stats-http habilitado.

Instale el PMDA de uwsgi utilizando el script Install como root:

  # cd $PCP_PMDAS_DIR/uwsgi
  # ./Install

Para desinstalar, haga lo siguiente como root:

  # cd $PCP_PMDAS_DIR/uwsgi
  # ./Remove

pmdauwsgi es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/uwsgi/Install
script de instalación para el agente pmdauwsgi
$PCP_PMDAS_DIR/uwsgi/Remove
script para deshacer la instalación del agente pmdauwsgi
$PCP_LOG_DIR/pmcd/uwsgi.log
archivo de registro por defecto para mensajes de error de pmdauwsgi
$PCP_SYSCONF_DIR/uwsgi/uwsgi.conf
archivo de configuración opcional para el agente pmdauwsgi

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
