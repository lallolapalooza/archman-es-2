PMDANVIDIA(1) Manual de comandos generales PMDANVIDIA(1)

NOMBRE

pmdanvidia - agente de dominio de métricas de gpu nvidia (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/nvidia/pmdanvidia [-D debug] [-d dominio] [-l logfile] [-t intervalo]

DESCRIPCIÓN

pmdanvidia es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen las métricas disponibles en las tarjetas GPU NVIDIA a través de la biblioteca NVML.

El PMDA de nvidia exporta métricas que miden la actividad de la GPU, la utilización de la memoria, la velocidad del ventilador, etc. en las tarjetas NVIDIA Tesla y Quadro. Es poco probable que las métricas estén disponibles para tarjetas de clase de consumidor.

A continuación se presenta una breve descripción de las opciones de línea de comandos de pmdanvidia:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado nvidia.log en el directorio actual de pmcd(1) cuando se inicia pmdanvidia, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no se puede escribir, la salida se escribe en el error estándar en su lugar.
-t
Habilita y establece un intervalo de muestreo para la actualización automática de los valores métricos. La funcionalidad está deshabilitada por defecto, sin embargo, esta opción permite especificar un intervalo de tiempo en el que se muestrean todos los valores. Esto tiene el efecto de actualizar constantemente las métricas acumulativas, con el objetivo de ayudar a herramientas cliente como pcp-atop(1) y pmlogger(1) a observar cambios de tiempo sub-muestrales en el estado de la GPU y del proceso. Típicamente, estas herramientas tienen intervalos de muestreo más largos y, por lo tanto, pueden "perderse" la actividad que ocurre durante su intervalo de muestreo.

INSTALACIÓN

El PMDA de nvidia no se instala y no está disponible por defecto. Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/nvidia
# ./Remove

Si desea restablecer el acceso a los nombres, el texto de ayuda y los valores de las métricas de rendimiento de nvidia una vez más, después de la eliminación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/nvidia
# ./Install

pmdanvidia es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdanvidia
$PCP_PMDAS_DIR/nvidia/help
archivo de texto de ayuda predeterminado para las métricas de nvidia
$PCP_PMDAS_DIR/nvidia/Install
script de instalación para el agente pmdanvidia
$PCP_PMDAS_DIR/nvidia/Remove
script para deshacer la instalación del agente pmdanvidia
$PCP_LOG_DIR/pmcd/nvidia.log
archivo de registro predeterminado para mensajes de error y otra información de pmdanvidia

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas de pmdanvidia son las siguientes:

Opción Descripción
appl0 interacción con pmcd(1)
appl1 carga de la DSO libnvidia-ml
appl2 trazado de llamadas a select(2)
