PMDASENDMAIL(1) Manual de comandos generales PMDASENDMAIL(1)

NOMBRE

pmdasendmail - agente de dominio de métricas de rendimiento de sendmail (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/sendmail/pmdasendmail [-D debug] [-d dominio] [-l logfile] [-U username]

DESCRIPCIÓN

pmdasendmail es un Agente de Dominio de Métricas de Rendimiento (PMDA) de sendmail que exporta estadísticas de tráfico de correo según lo recopilado por sendmail(1).

Antes de que el PMDA de sendmail pueda exportar alguna métrica, sendmail(1) debe tener habilitada la recopilación de estadísticas. Esto implica verificar el nombre del archivo de estadísticas, según lo proporcionado por las líneas de control OS o O StatusFile en /etc/sendmail.cf, y luego crear este archivo si aún no existe. Eliminar el archivo terminará la recopilación de estadísticas por parte de sendmail(1) y, por lo tanto, del PMDA de sendmail.

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdasendmail:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, un archivo de registro llamado sendmail.log se escribe en el directorio actual de pmcd(1) cuando se inicia pmdasendmail, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no se puede escribir, la salida se escribe en el error estándar en su lugar.
-U
Cuenta de usuario bajo la cual ejecutar el agente. Por defecto, es la cuenta no privilegiada "pcp" en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

No hay opciones de comunicación, ya que el script Install garantiza que el PMDA de sendmail se conectará a PMCD mediante una tubería.

INSTALACIÓN

Si desea acceso a los nombres, texto de ayuda y valores de las métricas de rendimiento de sendmail, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sendmail
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/sendmail
# ./Remove

pmdasendmail es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para iniciar pmdasendmail
$PCP_PMDAS_DIR/sendmail/help
archivo de texto de ayuda predeterminado para las métricas de sendmail
$PCP_PMDAS_DIR/sendmail/Install
script de instalación para el agente pmdasendmail
$PCP_PMDAS_DIR/sendmail/Remove
script para deshacer la instalación del agente pmdasendmail
$PCP_LOG_DIR/pmcd/sendmail.log
archivo de registro predeterminado para mensajes de error y otra información de pmdasendmail
/etc/sendmail.cf
archivo de configuración de sendmail para identificar el nombre del archivo de estadísticas

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdasendmail son las siguientes:

Opción Descripción
appl0 diagnósticos detallados, particularmente de map_stats()
