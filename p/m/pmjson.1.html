PMJSON(1) Manual de Comandos Generales PMJSON(1)

NOMBRE

pmjson - Utilidad de volcado JSON de Performance Co-Pilot

SINOPSIS

pmjson [-mnpqyV?] [-D debug] [-i infile] [-o outfile]

DESCRIPCIÓN

pmjson se utiliza para manipular texto con formato JSON (JavaScript Object Notation) utilizado en el conjunto de herramientas Performance Co-Pilot (PCP). Puede producir formatos de salida mínimos y legibles para humanos cuando se le proporciona una entrada JSON válida.

OPCIONES

Las opciones de línea de comandos disponibles son:

-i infile, --in=infile
Entrada con formato JSON infile - ruta a un archivo del cual se deben leer los datos. Si se omite esta opción, pmjson leerá del flujo de entrada estándar.
-m, --minimal
Produce una salida JSON con todo el espacio en blanco superfluo eliminado de la cadena JSON resultante.
-o outfile, --out=outfile
La salida formateada se escribe en el outfile especificado. Si se omite esta opción, pmjson escribirá en el flujo de salida estándar.
-n, --not-pretty
Produce una salida JSON en formato crudo y monocromático (por defecto si la salida se envía a un archivo).
-p, --pretty
Produce una salida JSON en un formato amigable para humanos (por defecto si la salida es para una terminal).
-q, --quiet
Verifica que la entrada sea JSON válido solamente, no se produce ninguna salida.
-V, --version
Muestra el número de versión y sale.
-y, --yaml
Produce una salida similar a YAML, un formato legible con menos sintaxis que JSON.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PMWEBAPI(3), pcp.conf(5) y pcp.env(5).
