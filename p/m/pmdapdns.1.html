PMDAPDNS(1) Performance Co-Pilot PMDAPDNS(1)

NOMBRE

pmdapdns - Agente de dominio de métricas de rendimiento de PowerDNS (PMDA)

DESCRIPCIÓN

pmdapdns es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos del demonio autoritativo de PowerDNS así como del resolvedor recursivo.

INSTALACIÓN

Si desea acceso a los nombres y valores de las métricas de rendimiento de PowerDNS, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/pdns
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/pdns
# ./Remove

pmdapdns es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/pdns/Install
script de instalación para el agente pmdapdns
$PCP_PMDAS_DIR/pdns/Remove
script para deshacer la instalación del agente pmdapdns
$PCP_LOG_DIR/pmcd/pdns.log
archivo de registro predeterminado para mensajes de error de pmdapdns

VER TAMBIÉN

pmcd(1), pdns_control(8), y rec_control(1).
