PMDAPODMAN(1) Manual de comandos generales PMDAPODMAN(1)

NOMBRE

pmdapodman - agente de dominio de métricas de rendimiento de contenedores podman (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/podman/pmdapodman [-D debug] [-d dominio] [-l logfile]

DESCRIPCIÓN

podman(1) es una utilidad para gestionar pods, contenedores e imágenes de contenedores, siguiendo el concepto de pod de contenedores popularizado por Kubernetes. pmdapodman es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento que describen el estado de los contenedores y pods gestionados por podman.

El PMDA de podman exporta métricas que miden información sobre contenedores individuales y grupos de contenedores, llamados pods.

Una breve descripción de las opciones de línea de comandos de pmdapodman sigue:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, un archivo de registro llamado podman.log se escribe en el directorio actual de pmcd(1) cuando se inicia pmdapodman, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.

INSTALACIÓN

El PMDA de podman está instalado y disponible por defecto en Linux. Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/podman
# ./Remove

Si desea restablecer el acceso a los nombres, el texto de ayuda y los valores para las métricas de rendimiento de podman una vez más, después de la eliminación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/podman
# ./Install

pmdapodman es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts de Instalación y Eliminación notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdapodman
$PCP_PMDAS_DIR/podman/help
archivo de texto de ayuda predeterminado para las métricas de podman
$PCP_PMDAS_DIR/podman/Install
script de instalación para el agente pmdapodman
$PCP_PMDAS_DIR/podman/Remove
script para deshacer la instalación del agente pmdapodman
$PCP_LOG_DIR/pmcd/podman.log
archivo de registro predeterminado para mensajes de error y otra información de pmdapodman

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN
