NOMBRE

pmseries_import - importar archivos de archivo PCP para consultas de series temporales históricas

SINOPSIS

$PCP_BINADM_DIR/pmseries_import [-h] [--archives ruta] [--json archivo] [--import-timeout tiempo] [--noop] [--poll-interval delta] [-p puerto] [-Z TZ]

DESCRIPCIÓN

pmseries_import monitoriza una ruta dada en busca de archivos de archivo PCP y carga automáticamente su contenido en un servidor de claves (como Valkey o Redis). Esto es adecuado para consultas rápidas de series temporales utilizando el lenguaje pmseries(1), tal como lo proporcionan la herramienta de línea de comandos y los servicios de API REST de PCP de pmproxy(1).

pmseries_import utiliza una técnica simple de sondeo, comprobando el directorio de archivos en busca de nuevos archivos cada 10 segundos.

Esta utilidad se utiliza más comúnmente dentro de un contenedor que proporciona una configuración automatizada de paneles de Grafana para archivos PCP arbitrarios. Este enfoque proporciona un entorno que contiene un servidor systemd(1) para habilitar esta utilidad de monitoreo de archivos, con grafana-server(1), valkey-server(1) y servicios de API REST de pmproxy(1) preconfigurados.

OPCIONES

--archives=ruta
Especifica una ruta alternativa para buscar nuevos archivos PCP. El valor predeterminado es /archives.
--jsonfile=archivo
Especifica un archivo alternativo en formato JSON para actualizar cada vez que se observe un cambio en los límites de la ventana de tiempo. Este archivo debe contener contenido JSON, incluido un mapa JSON llamado "time" con los campos "start" y "end" donde se escribirán las marcas de tiempo de cadena. El valor predeterminado es /usr/local/var/lib/grafana/dashboards/pcp-archive-analysis.json.
-h, --help
Muestra el mensaje de uso del comando y sale.
--import-timeout=tiempo
Especifica el número de segundos permitidos para que se complete la importación de cualquier archivo individual, a través del comando de carga pmseries para ese archivo. El valor de tiempo predeterminado es 600 segundos (5 minutos).
--noop
Omite todas las operaciones de escritura (con fines de depuración o prueba), informando solo mensajes de diagnóstico en su lugar.
--poll-interval=delta
La frecuencia con la que se escaneará el directorio de archivos. El delta predeterminado es una vez cada 10 segundos.
-p puerto, --port=puerto
Un puerto opcional al que pmseries debe conectarse al servidor de claves. El puerto predeterminado es 6379.
-Z TZ, --timezone=TZ
Un valor TZ opcional que indica la zona horaria a la que pmseries debe convertir todas las marcas de tiempo del archivo al enviar valores al servidor de claves.

VER TAMBIÉN

grafana-server(1), systemd(1), valkey-server(1), pmproxy(1) y pmseries(1).
