PMGETPMNSLOCATION(3) Manual de funciones de biblioteca PMGETPMNSLOCATION(3)

NOMBRE

pmGetPMNSLocation - determinar la ubicación del PMNS utilizado actualmente

SINTAXIS C

#include <pcp/pmapi.h>

int pmGetPMNSLocation(void);

cc ... -lpcp

DESCRIPCIÓN

Si una aplicación necesita saber de dónde proviene el Espacio de Nombres de Métricas de Rendimiento (PMNS), pmGetPMNSLocation devolverá si proviene de un archivo, PMNS_ARCHIVE, o de un archivo PMNS local, PMNS_LOCAL, o de un pmcd remoto, PMNS_REMOTE.

Esta información puede ser útil para determinar un mensaje de error apropiado dependiendo de la ubicación del PMNS.

DIAGNÓSTICOS

PM_ERR_NOPMNS
Si no es posible determinar la ubicación del PMNS. Esto podría deberse a problemas con el contexto actual o a la imposibilidad de cargar un PMNS local.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores para estas variables pueden obtenerse mediante programación utilizando la función pmGetConfig(3).
