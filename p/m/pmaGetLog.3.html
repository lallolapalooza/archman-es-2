PMAGETLOG(3) Manual de funciones de biblioteca PMAGETLOG(3)

NOMBRE

pmaGetLog - lectura directa del siguiente registro de un archivo de archivo

C SINOSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaGetLog(__pmArchCtl *acp,
int vol, __int32_t **rbuf);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas entre lanzamientos, y pueden no funcionar, o pueden proporcionar una semántica diferente en algún momento en el futuro.

DESCRIPCIÓN

Esta es una versión reducida de __pmLogRead(3) de libpcp, que lee el siguiente registro físico del volumen vol del archivo identificado por acp.

Si vol es PM_LOG_VOL_META, se lee el siguiente registro de metadatos; de lo contrario, se lee el siguiente registro del volumen de datos vol.

El registro se devuelve en rbuf, que se asigna aquí; por lo que el llamador tendrá que llamar a free(3) cuando ya no sea necesario.

Se comprueba la longitud de la cabecera y el remolque del registro, pero por lo demás rbuf no se procesa y, en particular, el registro permanece en orden de bytes de red.

DIAGNÓSTICOS Y VALORES DE RETORNO

El valor de retorno es 0 si todo está bien, de lo contrario PM_ERR_EOL para fin de archivo, de lo contrario algún otro código de error menor que cero.

VER TAMBIÉN

free(3), pmaPutLog(3), PMAPI(3) y __pmLogRead(3).
