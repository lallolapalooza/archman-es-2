PMLOGREDACT(1) Manual de comandos generales PMLOGREDACT(1)

NOMBRE

pmlogredact - elimina información sensible de los archivos de PCP

SINOPSIS

pmlogredact [-vx?] [-D debug] [-c config] inarch [outarch]

DESCRIPCIÓN

Los archivos de Performance Co-Pilot (PCP) pueden contener una gran cantidad de información recopilada de todos los componentes de un sistema.

Parte de esta información puede considerarse sensible fuera del contexto de la recopilación original para el análisis del rendimiento del sistema. Ejemplos de información sensible podrían incluir nombres de usuarios, rutas a directorios de inicio de usuarios (que pueden implicar nombres de usuarios), nombres de host, direcciones IP, direcciones MAC, argumentos de línea de comandos, variables de entorno de procesos, etc.

pmlogredact puede usarse para eliminar información sensible antes de que los archivos se envíen a otra organización, o se almacenen en otra geografía, o para cumplir con las normativas de privacidad o reglamentarias. El archivo de salida outarch es la versión redactada del archivo de entrada inarch.

pmlogredact es un envoltorio ligero para pmlogrewrite(1), por lo que los archivos de configuración para pmlogredact siguen la misma sintaxis que los archivos de configuración para pmlogrewrite(1).

Existe un conjunto predeterminado de reglas de redacción en los archivos $PCP_VAR_DIR/config/pmlogredact/*. Estas reglas eliminan algunas métricas, reescriben los dominios de instancia de algunas métricas y reescriben los valores de algunas métricas. La opción -x (o --exclude-std) puede usarse para **no** usar el conjunto predeterminado de reglas.

Se pueden especificar archivos de configuración adicionales (o alternativos) con una o más opciones -c (o --config), donde cada config es un archivo o un directorio (lo que implica todos los archivos dentro de ese directorio).

La opción -v (o --verbose) añade verbosidad (y se pasa directamente a pmlogrewrite(1)).

La opción -? (o --help) muestra un mensaje de uso y sale.

ARCHIVOS

$PCP_VAR_DIR/config/pmlogredact/*
reglas de redacción predeterminadas

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

pmlogrewrite(1), pcp.conf(5) y pcp.env(5).
