PMDAMYSQL(1) Manual de comandos generales PMDAMYSQL(1)

NOMBRE

pmdamysql - PMDA de base de datos MySQL y MariaDB

DESCRIPCIÓN

pmdamysql es un PMDA de Performance Co-Pilot que extrae datos de rendimiento en vivo de una base de datos MySQL o MariaDB en ejecución.

INSTALACIÓN

pmdamysql utiliza un archivo de configuración de (en este orden):

  • /etc/pcpdbi.conf
  • $PCP_PMDAS_DIR/mysql/mysql.conf

Este archivo puede contener valores anulados (código Perl) para la configuración listada al principio de pmdamysql.pl, a saber:

  • nombre de la base de datos (ver DBI(3) para detalles, por defecto es "DBI:mysql:mysql")
  • nombre de usuario de la base de datos (por defecto es "dbmonitor")
  • contraseña de la base de datos (por defecto es "dbmonitor")
  • cuenta de inicio de sesión (por defecto es "pcp")

En algunas versiones de MariaDB (10+) el esquema de rendimiento está desactivado por defecto y debe habilitarse para que el PMDA funcione. Esto se logra añadiendo la cadena "performance_schema" a la sección "[mysqld]" del archivo de configuración de MariaDB (ya sea my.cnf o my.ini). La sentencia SQL "SHOW ENGINES" muestra soporte para el esquema de rendimiento.

Una vez completadas estas acciones de configuración iniciales, puede acceder a los nombres y valores de las métricas de rendimiento de mysql haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/mysql
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/mysql
# ./Remove

pmdamysql es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

Valores de estado binarios en texto

Algunos de los valores de estado están en formato SÍ/NO o ENCENDIDO/APAGADO.

Dado que estas no pueden ser interpretadas por herramientas como pmie(1), han sido duplicadas con una extensión _num y los valores de 1 (SÍ/ENCENDIDO) o 0 (NO/APAGADO).

Ej:

  • mysql.slave_status.slave_io_running
  • mysql.slave_status.slave_io_running_num

ARCHIVOS

/etc/pcpdbi.conf
archivo de configuración para todos los monitores de base de datos PCP
$PCP_PMDAS_DIR/mysql/mysql.conf
archivo de configuración para pmdamysql
$PCP_PMDAS_DIR/mysql/Install
script de instalación para el agente pmdamysql
$PCP_PMDAS_DIR/mysql/Remove
script para deshacer la instalación del agente pmdamysql
$PCP_LOG_DIR/pmcd/mysql.log
archivo de registro por defecto para mensajes de error de pmdamysql

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmdadbping(1), pmie(1) y DBI(3).
