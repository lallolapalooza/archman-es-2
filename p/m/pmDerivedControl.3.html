PMDERIVEDCONTROL(3) Manual de funciones de biblioteca PMDERIVEDCONTROL(3)

NOMBRE

pmGetDerivedControl, pmSetDerivedControl - obtener y establecer controles para métricas derivadas

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetDerivedControl(int what, int *valuep);
int pmSetDerivedControl(int what, int value);

cc ... -lpcp

DESCRIPCIÓN

Estas rutinas pueden usarse para influir en el comportamiento de los servicios de métricas derivadas que se activan para métricas derivadas globales utilizando pmRegisterDerived(3), pmRegisterDerivedMetric(3) y pmLoadDerivedConfig(3), o métricas derivadas por contexto utilizando pmAddDerived(3) y pmAddDerivedMetric(3).

El argumento what selecciona un control, el argumento value proporciona un valor para pmSetDerivedControl y el argumento valuep se utiliza para devolver el valor para pmGetDerivedControl.

El argumento what tiene uno de los siguientes valores:

PCP_DERIVED_GLOBAL_LIMIT
El número máximo de métricas derivadas globales que se pueden definir. El valor -1 indica sin límite.
PCP_DERIVED_CONTEXT_LIMIT
El número máximo de métricas derivadas por contexto que se pueden definir. El valor -1 indica sin límite.
PCP_DERIVED_DEBUG_SYNTAX
Diagnósticos de depuración durante el análisis de la expresión de métricas derivadas. El valor 1 habilita los diagnósticos, el valor 0 los deshabilita.
PCP_DERIVED_DEBUG_SEMANTICS
Diagnósticos de depuración para comprobaciones semánticas durante la vinculación de métricas en la expresión de métricas derivadas con las métricas disponibles en un nuevo contexto PMAPI. El valor 1 habilita los diagnósticos, el valor 0 los deshabilita.
PCP_DERIVED_DEBUG_EVAL
Diagnósticos de depuración cuando se utilizan métricas derivadas en operaciones PMAPI como pmFetch(3), pmGetChildren(3), pmGetChildrenStatus(3), pmLookupDesc(3), pmLookupName(3), pmNameAll(3), pmNameID(3) y pmTraversePMNS(3).

VALORES DE RETORNO

Ambas rutinas devuelven 0 en caso de éxito, de lo contrario un valor menor que 0 que puede ser decodificado usando pmErrStr(3).

VER TAMBIÉN

PCPIntro(1), pmAddDerived(3), pmAddDerivedMetric(3), PMAPI(3), pmErrStr(3), pmLoadDerivedConfig(3), pmRegisterDerived(3), pmRegisterDerivedMetric(3) y PMNS(5).
