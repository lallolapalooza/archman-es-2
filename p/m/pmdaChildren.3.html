NOMBRE

pmdaChildren - traduce un PMID a un conjunto de nombres de métricas de rendimiento dinámicas

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaChildren(char *name,
int traverse, char ***offspring, int **status, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA) (ver PMDA(3)), pmdaChildren es la llamada de retorno genérica para devolver nombres de métricas dinámicas (y su estado) que son descendientes de name.

Debido a que la implementación de métricas de rendimiento dinámicas requiere soporte específico del PMDA, y la instalación es un componente opcional de un PMDA (la mayoría de los PMDA no admiten métricas de rendimiento dinámicas), pmdaChildren es una implementación esquelética que devuelve PM_ERR_NAME.

Un PMDA que admite métricas de rendimiento dinámicas proporcionará una llamada de retorno privada que reemplaza a pmdaChildren (mediante asignación a version.four.children de la estructura pmdaInterface) y toma el nombre de métrica inicial name y devuelve nombres a través de offspring[] y el estado de hoja o no hoja de cada uno a través de status[].

Si traverse es 0, entonces el comportamiento es similar a pmGetChildren(3) y offspring[] contiene el componente de nombre relativo para los descendientes inmediatos de name.

Si traverse es 1, entonces el comportamiento es similar a pmTraversePMNS(3) y offspring[] contiene los nombres absolutos de todas las métricas dinámicas que son descendientes de name.

La lista resultante de punteros offspring y los valores de cadena (los nombres) a los que apuntan los punteros habrán sido asignados por pmdaChildren con una sola llamada a malloc(3), y el llamador de pmdaChildren llamará a free(offspring) para liberar el espacio cuando ya no se requiera. Lo mismo aplica para la matriz status, es decir, el llamador de pmdaChildren llamará a free(status) para liberar el espacio cuando ya no se requiera.

ADVERTENCIA

El PMDA debe estar usando PMDA_INTERFACE_4 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICOS

pmdaChildren devuelve PM_ERR_NAME si el nombre no es reconocido o no se puede traducir, de lo contrario, el número de nombres de métricas descendientes encontrados.

VER TAMBIÉN

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaMain(3), pmGetChildren(3) y pmTraversePMNS(3).
