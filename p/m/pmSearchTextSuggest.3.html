PMSEARCHTEXTSUGGEST(3) Manual de funciones de biblioteca PMSEARCHTEXTSUGGEST(3)

NOMBRE

pmSearchTextSuggest - buscar sugerencias de nombres de métricas o instancias usando los servicios de búsqueda de PCP

SINOPSIS C

#include <pcp/pmwebapi.h>

int pmSearchTextSuggest(pmSearchSettings *settings,
pmSearchTextRequest *request, void *arg);

cc ... -lpcp_web

DESCRIPCIÓN

Ejecuta una búsqueda de texto completo para nombres de métricas o instancias adecuados para autocompletado, especificados por request:

consulta
Cadena de consulta que se utilizará para la búsqueda.
conteo
Limita el número de resultados. Por defecto es 10.

Las palabras con una longitud inferior a 2 se omiten.

Esta búsqueda coincide con términos dentro del nombre de la entidad que tienen el prefijo consulta o que están a una distancia de Levenshtein de 1, teniendo las primeras una prioridad ligeramente mayor que las segundas.

Cada entidad que coincida con la solicitud anterior se pasará a la devolución de llamada on_text_result proporcionada por settings.

DIAGNÓSTICOS

Esta función siempre devuelve cero si tiene éxito. En caso de error, se devuelve un código de error PMAPI negativo.

VER TAMBIÉN

pmproxy(1), pmlogger(1), pmsearch(1), pmSearchSetup(3), PMAPI(3) y PMWEBAPI(3).
