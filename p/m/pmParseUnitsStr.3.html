PMPARSEUNITSSTR(3) Manual de funciones de biblioteca PMPARSEUNITSSTR(3)

NOMBRE

pmParseUnitsStr - analizar especificación de unidades

SINOPSIS

#include <pcp/pmapi.h>

int pmParseUnitsStr(const char *string,
struct pmUnits *out, double *outMult, char **errMsg);

cc ... -lpcp

DESCRIPCIÓN

pmParseUnitsStr está diseñado para encapsular la interpretación de una especificación de unidades (dimensión y escala) en las opciones de línea de comandos para su uso por las herramientas cliente de PCP.

Se espera que esta función sea llamada con la especificación de unidad/escala como string. Esta especificación tiene la forma general producida por pmUnitsStr(3). Brevemente, el formato permite un divisor y un dividendo separados por /, cada uno listando dimensiones/escalas separadas por espacios a lo largo de los ejes de espacio, tiempo y conteo. También hay algunas posibilidades adicionales:

Primero, se aceptan múltiples conjuntos equivalentes de palabras clave para las dimensiones de tiempo y espacio, insensibles a mayúsculas y minúsculas. Por ejemplo, "microseconds", "microsecond", "microsec", "us" se consideran sinónimos, al igual que "kilobytes", "KB", "KiB", "kiloByte", y así sucesivamente.

Segundo, las unidades pueden ofrecerse en cualquier orden, por ejemplo, ms kb count x 10^3 o count x 10^3 kb ms. No se pueden repetir dentro del denominador o dentro del numerador. Cada palabra clave de escala/unidad puede ir seguida inmediatamente de exponentes positivos o negativos, por ejemplo, ^-4.

Tercero, se pueden suministrar factores de escala numéricos. Estos se combinan junto con las conversiones de escala implícitas en el resultado final outMult.

Los valores out y outMult deben ser asignados antes de llamar a pmParseUnitsStr(3). Si la conversión es exitosa, pmParseUnitsStr devuelve 0 y llena out y outMult con la unidad/escala definida por el parámetro de entrada. Si las cadenas de argumento no pudieron ser analizadas, devuelve un código de estado negativo.

EJEMPLOS

string out outMult
2 count {0,1,0,0,0,0} 0.5
count / 7.5 nanosecond {0,1,-1,0,0,0} 7.5
10 kilobytes / 2.5e2 count x 10^3 {1,-1,0,1,3,0} 25
millisecond / second^2 {0,0,-1,0,0,3} 1000
mib/s {1,0,-1,2,0,3} 1

ERRORES

Por compatibilidad hacia atrás, esta interfaz interpreta varias interpretaciones tradicionales de la informática de unidades de espacio de forma incorrecta según el estándar del Sistema Internacional de Unidades (SI).

La cadena de unidad aceptada —en forma singular o plural— y la interpretación de pmParseUnitsStr para cada una son: megabyte (es realmente mebibyte), gigabyte (es realmente gibibyte), terabyte (es realmente tebibyte), petabyte (es realmente pebibyte), exabyte (es realmente exbibyte), zettabyte (es realmente zebibyte) y yottabyte (es realmente yobibyte).

VALOR DE RETORNO

Un estado cero indica éxito. Un estado negativo indica un error, en cuyo caso el puntero errMsg contendrá un mensaje de error textual, que el llamador debería luego free(3).

VER TAMBIÉN

PMAPI(3), pmUnitsStr(3), pmConvScale(3), y pmLookupDesc(3).
