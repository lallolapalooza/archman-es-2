PMTYPESTR(3) Manual de Funciones de Biblioteca PMTYPESTR(3)

NOMBRE

pmTypeStr, pmTypeStr_r - convertir un tipo de métrica de rendimiento en una cadena

SINOPSIS C

#include <pcp/pmapi.h>

const char *pmTypeStr(int type);
char *pmTypeStr_r(int type, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

Dado un type (tipo) de métrica de rendimiento, pmTypeStr produce un equivalente ASCII conciso, adecuado para usar en mensajes de error y diagnóstico. La función pmTypeStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos 20 bytes.

El valor para type se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

Los ejemplos son 32 (para type igual a PM_TYPE_32), U64 (para type igual a PM_TYPE_U64), STRING (para type igual a PM_TYPE_STRING), etc.

NOTAS

Ambas funciones se pueden llamar de forma segura desde contextos con hilos (threaded contexts).

VER TAMBIÉN

PMAPI(3), pmAtomStr(3), pmConvScale(3), pmExtractValue(3), pmLookupDesc(3), pmPrintValue(3), pmIDStr(3), pmInDomStr(3), pmSemStr(3) y pmUnitsStr(3).
