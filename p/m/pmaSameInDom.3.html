PMASAMEINDOM(3) Manual de funciones de biblioteca PMASAMEINDOM(3)

NOMBRE

pmaSameInDom - comprueba si dos observaciones de un dominio de instancia son iguales`

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaSameInDom(__pmLogInDom *old, __pmLogInDom *new);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que se garantiza que permanecerán fijas entre versiones, y pueden no funcionar, o pueden proporcionar una semántica diferente en algún momento en el futuro.

DESCRIPCIÓN

Comprueba si dos observaciones del mismo dominio de instancia son idénticas. El código asume que (a) old->indom == new->indom y (b) ambos dominios de instancia están ordenados en secuencia ascendente de identificador de instancia interno; consulte pmaSortInDom(3) para ver cómo hacer que la segunda condición sea verdadera.

pmaSameInDom devuelve 1 si son iguales, devuelve 0 en caso contrario.

Los dominios de instancia se consideran diferentes si se cumple alguna de las siguientes condiciones:

1.
old->numinst != new->numinst
2.
Para algún i, old->instlist[i] != new->instlist[i]
3.
Para algún i, las cadenas a las que apuntan old->namelist[i] y new->instlist[i] no son idénticas

Para los archivos de la versión 3 con soporte de "delta indom", es más probable que pmaDeltaInDom(3) sea más útil que pmaSameInDom, ya que el primero combina la comprobación de si dos observaciones de un dominio de instancia son iguales con la creación opcional del formato "delta indom" si esa es la codificación más eficiente.

VER TAMBIÉN

pmaDeltaInDom(3), PMAPI(3) y pmaSortInDom(3).
