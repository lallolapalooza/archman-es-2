PMDACIFS(1) Manual de comandos generales PMDACIFS(1)

NOMBRE

pmdacifs - PMDA de Common Internet Filesystem (CIFS)

SINOPSIS

$PCP_PMDAS_DIR/cifs/pmdacifs [-D debug]

DESCRIPCIÓN

pmdacifs es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos sobre recursos compartidos CIFS montados desde el directorio /proc/fs/cifs. Este PMDA requiere al menos el módulo del kernel CIFS cargado para devolver algunos valores métricos y al menos un recurso compartido CIFS montado para proporcionar datos para todas las métricas.

INSTALACIÓN

Instale el PMDA de CIFS utilizando el script de instalación como root:

# cd $PCP_PMDAS_DIR/cifs
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/cifs
# ./Remove

pmdacifs es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/cifs/help
archivo de texto de ayuda predeterminado para las métricas CIFS
$PCP_PMDAS_DIR/cifs/Install
script de instalación para el agente pmdacifs
$PCP_PMDAS_DIR/cifs/Remove
script para deshacer la instalación del agente pmdacifs
$PCP_LOG_DIR/pmcd/cifs.log
archivo de registro predeterminado para mensajes de error de pmdacifs

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1), pmstore(1) y mount.cifs(8).
