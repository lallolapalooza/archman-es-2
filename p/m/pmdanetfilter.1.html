PMDANETFILTER(1) Manual de Comandos Generales PMDANETFILTER(1)

NOMBRE

pmdanetfilter - agente de dominio de métricas de rendimiento (PMDA) para el seguimiento de conexiones IP netfilter de Linux

DESCRIPCIÓN

pmdanetfilter es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos del módulo de seguimiento de conexiones IP en el kernel de Linux.

INSTALACIÓN

Instale el PMDA de netfilter usando el script Install como root:

# cd $PCP_PMDAS_DIR/netfilter
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/netfilter
# ./Remove

pmdanetfilter es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/netfilter/Install
script de instalación para el agente pmdanetfilter
$PCP_PMDAS_DIR/netfilter/Remove
script para deshacer la instalación del agente pmdanetfilter
$PCP_LOG_DIR/pmcd/netfilter.log
archivo de registro predeterminado para mensajes de error de pmdanetfilter

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede ser utilizada para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
