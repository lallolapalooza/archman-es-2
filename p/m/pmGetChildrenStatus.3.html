PMGETCHILDRENSTATUS(3) Manual de funciones de biblioteca PMGETCHILDRENSTATUS(3)

NOMBRE

pmGetChildrenStatus - devuelve los nodos descendientes de un nodo PMNS y su estado respectivo

SINOPSIS C

#include <pcp/pmapi.h>

int pmGetChildrenStatus(const char *name,
char ***offspring, int **status);

cc ... -lpcp

DESCRIPCIÓN

Dado un nombre de ruta completo de un nodo en el Espacio de Nombres de Métricas de Rendimiento (PMNS) actual, identificado por name, pmGetChildrenStatus devuelve a través de offspring una lista de los nombres relativos de todos los nodos descendientes inmediatos de name en el PMNS actual.

Como caso especial, si name es una cadena vacía (es decir,""), se devolverán los descendientes inmediatos del nodo raíz en el PMNS.

Si status no es NULL, entonces pmGetChildrenStatus también devolverá el estado de cada hijo a través de status. El estado hará referencia a un nodo hoja (con el valor PMNS_LEAF_STATUS) o a un nodo no hoja (con el valor PMNS_NONLEAF_STATUS).

Normalmente, pmGetChildrenStatus devolverá el número de nombres descendientes descubiertos, de lo contrario, un valor menor que cero indicará un error. El valor cero indica que name es un nombre de métrica válido, es decir, está asociado con un nodo hoja en el PMNS.

La lista resultante de punteros offspring y los valores (los nombres relativos) a los que apuntan los punteros habrán sido asignados por pmGetChildrenStatus con una única llamada a malloc(3), y es responsabilidad del llamador de pmGetChildrenStatus llamar a free(offspring) para liberar el espacio cuando ya no sea necesario. Lo mismo ocurre con la matriz status.

Cuando ocurre un error, o name es un nodo hoja (es decir, el resultado de pmGetChildrenStatus es menor que uno), tanto offspring como status no están definidos (no se habrá asignado espacio y, por lo tanto, llamar a free(3) es una muy mala idea).

DIAGNÓSTICOS

PM_ERR_NOPMNS
Error al acceder a un PMNS para la operación. Tenga en cuenta que si la aplicación no ha llamado previamente a pmLoadNameSpace(3) y desea utilizar el PMNS distribuido, debe realizar una llamada a pmGetChildrenStatus dentro de un contexto actual.
PM_ERR_NAME
La ruta name no es válida en el PMNS actual
PM_ERR_*
Otros diagnósticos se refieren a fallos de protocolo al acceder al PMNS distribuido.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). Los valores de estas variables se pueden obtener mediante programación utilizando la función pmGetConfig(3).
