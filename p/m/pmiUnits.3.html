PMIUNITS(3) Manual de funciones de biblioteca PMIUNITS(3)

NOMBRE

pmiUnits, pmiID, pmiInDom - construir estructuras de datos de métricas principales

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

pmID pmiID(int domain, int cluster, int item);
pmInDom pmiInDom(int domain, int serial);
pmUnits pmiUnits(int dimSpace,
int dimTime, int dimCount, int scaleSpace, int scaleTime, int scaleCount);

cc ... -lpcp_import -lpcp

SINOPSIS Perl

use PCP::LogImport;

$pmid = pmiID($domain, $cluster, $item);
$indom = pmiInDom($domain, $serial);
$units = pmiUnits($dimSpace,
$dimTime, $dimCount, $scaleSpace, $scaleTime, $scaleCount);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), estas rutinas proporcionan métodos de conveniencia (especialmente para uso en scripts) para construir las estructuras pmID, pmInDom y pmUnits respectivamente, para ser usadas en llamadas posteriores a pmiAddMetric(3) y pmiAddInstance(3).

Consulte pmLookupDesc(3) para obtener una descripción completa de los valores y semánticas de los componentes de una estructura pmUnits, y por lo tanto, los valores válidos de los argumentos para pmiUnits.

VER TAMBIÉN

LOGIMPORT(3), pmiAddMetric(3), pmiAddInstance(3) y pmLookupDesc(3).
