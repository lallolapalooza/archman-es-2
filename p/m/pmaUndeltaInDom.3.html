NOMBRE

pmaUndeltaInDom - encontrar el dominio de instancia "completo" que coincide con un dominio de instancia "delta"

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

__pmLogInDom *pmaUndeltaInDom(__pmLogCtl *lcp,
__int32_t *buf);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno por parte de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que garantizan permanecer fijas entre versiones, y pueden no funcionar, o proporcionar semánticas diferentes en algún momento futuro.

DESCRIPCIÓN

Encuentra el dominio de instancia "completo" cargado que coincide con un dominio de instancia "delta".

El llamador se asegura de que el registro de metadatos físicos del dominio de instancia "delta" se haya leído en buf. La estructura de control del archivo asociada se identifica mediante lcp, lo que implica que el archivo de entrada también se abrió con pmNewContext(3).

pmaUndeltaInDom comienza extrayendo la marca de tiempo y el número del dominio de instancia del dominio de instancia "delta" de buf. Con esta información, se llama a __pmLogSearchInDom(3) para encontrar el dominio de instancia cargado coincidente, que habrá sido convertido de un dominio de instancia "delta" a un dominio de instancia "completo" en el proceso.

pmaUndeltaInDom es más útil para aplicaciones que leen registros de metadatos físicos y necesitan operar en dominios de instancia "completos", en lugar de los dominios de instancia "delta" que aparecen en los archivos de la Versión 3.

DIAGNÓSTICOS Y VALORES DE RETORNO

Mucha verborrea de advertencia si no se puede encontrar el dominio de instancia cargado coincidente, y el valor de retorno es NULL en este caso.
