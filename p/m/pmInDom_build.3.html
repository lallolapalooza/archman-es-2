PMINDOM_BUILD(3) Manual de funciones de biblioteca PMINDOM_BUILD(3)

NOMBRE

pmInDom_build, pmInDom_domain, pmInDom_serial - métodos auxiliares para manipular identificadores de dominio de instancia

C SINOPSIS

#include <pcp/pmapi.h>

pmInDom pmInDom_build(unsigned int domain, unsigned int serial);
unsigned int pmInDom_domain(pmInDom indom);
unsigned int pmInDom_serial(pmInDom indom);

cc ... -lpcp

DESCRIPCIÓN

Dentro de Performance Co-Pilot (PCP) a cada dominio de instancia se le asigna un Identificador de Dominio de Instancia (pmInDom) único. Internamente un pmInDom se construye a partir de 2 campos: el número de dominio (del Agente de Dominio de Métricas de Rendimiento, o PMDA, asociado) y el número de serie (asignado por el PMDA).

pmInDom_build construye un pmInDom a partir de domain y serial.

pmInDom_domain y pmInDom_serial devuelven los campos respectivos de indom.

VER TAMBIÉN

PMAPI(3) y pmInDomStr(3).
