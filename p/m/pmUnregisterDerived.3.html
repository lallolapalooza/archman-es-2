NOMBRE

pmUnregisterDerived - anular el registro de una métrica derivada

SINOPSIS C

#include <pcp/pmapi.h>

int pmUnregisterDerived(char *name);

cc ... -lpcp

DESCRIPCIÓN

Las métricas derivadas proporcionan una forma de extender el Espacio de Nombres de Métricas de Rendimiento (PMNS) con nuevas métricas definidas en el lado del cliente de PCP utilizando expresiones sobre las métricas de rendimiento existentes.

Las métricas derivadas globales se crean llamando a pmRegisterDerived(3), pmRegisterDerivedMetric(3) o pmLoadDerivedConfig(3). Las métricas derivadas por contexto se crean llamando a pmAddDerived(3) o pmAddDerivedMetric(3).

pmUnregisterDerived elimina la definición de la métrica derivada name del conjunto de métricas derivadas globales y de cada contexto PMAPI activo.

DIAGNÓSTICOS

En caso de éxito, pmUnregisterDerived devuelve un valor mayor o igual a cero, que es el número de contextos de los que se eliminó name.

En caso contrario, pmUnregisterDerived devuelve un error de PMAPI y la aplicación debe llamar a pmErrStr(3) para obtener el mensaje de error correspondiente.

VER TAMBIÉN

PCPIntro(1), PMAPI(3), pmAddDerived(3), pmAddDerivedMetric(3), pmErrStr(3), pmLoadDerivedConfig(3), pmRegisterDerived(3), pmRegisterDerivedMetric(3) y PMNS(5).
