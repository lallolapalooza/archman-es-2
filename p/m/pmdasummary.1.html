PMDASUMMARY(1) Manual de Comandos Generales PMDASUMMARY(1)

NOMBRE

pmdasummary - agente de dominio de métricas de rendimiento de resumen (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/summary/pmdasummary [-D debug] [-d dominio] [-h archivo_ayuda] [-l archivo_log] [-U usuario] línea_comandos_pmie

DESCRIPCIÓN

pmdasummary es un Agente de Dominio de Métricas de Rendimiento (PMDA) que deriva valores de métricas de rendimiento a partir de valores que otros PMDAs ponen a disposición. pmdasummary consta de dos procesos:

proceso pmie
El motor de inferencia para valores de rendimiento pmie(1) se utiliza para muestrear periódicamente valores para las métricas base y calcular los valores derivados. Este proceso es iniciado con los argumentos línea_comandos_pmie proporcionados por el proceso principal, descrito a continuación.
proceso principal
El proceso principal lee y almacena en búfer los valores calculados por pmie(1) y los pone a disposición del demonio recolector de métricas de rendimiento pmcd(1).

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdasummary:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en un host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-h
Esta opción especifica un archivo de texto de ayuda alternativo archivo_ayuda para describir las métricas que representa pmdasummary.
-l
Ubicación del archivo de log. Por defecto, un archivo de log llamado summary.log se escribe en el directorio actual de pmcd(1) cuando se inicia pmdasummary, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de log no se puede crear o no es escribible, la salida se dirige a la salida de error estándar en su lugar.
-U
Cuenta de usuario bajo la cual ejecutar el agente. Por defecto es la cuenta no privilegiada "pcp" en versiones actuales de PCP, pero en versiones anteriores la cuenta superusuario ("root") se usaba por defecto.

INSTALACIÓN

Si desea acceder a los nombres, el texto de ayuda y los valores de las métricas de rendimiento de resumen, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/summary
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/summary
# ./Remove

pmdasummary es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para iniciar pmdasummary
$PCP_PMDAS_DIR/summary/expr.pmie
expresiones predeterminadas de pmie(1) que definen las métricas de resumen
$PCP_PMDAS_DIR/summary/help
texto de ayuda predeterminado para las métricas de resumen
$PCP_PMDAS_DIR/summary/Install
script de instalación para el agente pmdasummary
$PCP_PMDAS_DIR/summary/Remove
script para deshacer la instalación del agente pmdasummary
$PCP_LOG_DIR/pmcd/summary.log
archivo de log predeterminado para mensajes de error y otra información de pmdasummary

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a depurar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
