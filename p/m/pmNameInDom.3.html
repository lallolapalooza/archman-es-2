PMNAMEINDOM(3) Manual de funciones de biblioteca PMNAMEINDOM(3)

NOMBRE

pmNameInDom - traducir un identificador de instancia a un nombre de instancia

SINOPSIS C

#include <pcp/pmapi.h>

int pmNameInDom(pmInDom indom, int inst, char **name);

cc ... -lpcp

DESCRIPCIÓN

Para el dominio de instancia indom, en el contexto actual de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI), localice la instancia con el identificador de instancia interno dado por inst, y devuelva la identificación externa completa de la instancia a través de name.

El valor para el dominio de instancia indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

El espacio para el valor de name habrá sido asignado en pmNameInDom con malloc(3), y es responsabilidad del llamante liberar (free(3)) el espacio cuando ya no sea necesario.

pmNameInDom devuelve cero si tiene éxito.

DIAGNÓSTICO

PM_ERR_INDOM
indom no es un identificador de dominio de instancia válido
PM_ERR_INST
El identificador de instancia inst no es conocido para el dominio de instancia indom en el contexto actual de PMAPI

VER TAMBIÉN

PMAPI(3), pmGetConfig(3), pmGetInDom(3), pmLookupInDom(3), pmNameInDomArchive(3), pcp.conf(5) y pcp.env(5).
