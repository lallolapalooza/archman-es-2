PMDESTROYCONTEXT(3) Manual de funciones de la biblioteca PMDESTROYCONTEXT(3)

NOMBRE

pmDestroyContext - destruir un contexto PMAPI

C SINOPSIS

#include <pcp/pmapi.h>

int pmDestroyContext(int handle);

cc ... -lpcp

DESCRIPCIÓN

Una aplicación que utiliza la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) puede manipular varios contextos concurrentes, cada uno asociado con una fuente de métricas de rendimiento, por ejemplo, pmcd(1) en algún host, o un archivo de métricas de rendimiento como los creados por pmlogger(1).

pmDestroyContext destruye el contexto PMAPI identificado por handle. Típicamente esto implicaría la terminación de una conexión a un PMCD o el cierre de un archivo de registro, y una limpieza ordenada.

El contexto debe haber sido creado previamente usando pmNewContext(3) o pmDupContext(3).

En caso de éxito, pmDestroyContext devuelve cero. Si handle era el contexto PMAPI actual, entonces el contexto actual se vuelve indefinido. Esto significa que la aplicación debe restablecer explícitamente un contexto PMAPI válido con pmUseContext(3), o crear un nuevo contexto con pmNewContext(3) o pmDupContext(3), antes de la próxima operación PMAPI que requiera un contexto PMAPI.

DIAGNÓSTICOS

PM_ERR_NOCONTEXT

handle no identifica un contexto PMAPI válido

VER TAMBIÉN

PMAPI(3), pmDupContext(3), pmNewContext(3), pmUseContext(3) y pmWhichContext(3).
