PMSEARCHINFO(3) Manual de funciones de biblioteca PMSEARCHINFO(3)

NOMBRE

pmSearchInfo - métricas de diagnóstico de los servicios de búsqueda de PCP

C SINOPSIS

#include <pcp/pmwebapi.h>

int pmSearchInfo(pmSearchSettings *settings,
sds key, void *arg);

cc ... -lpcp_web

DESCRIPCIÓN

Métricas de diagnóstico relacionadas con los servicios de búsqueda rápidos, escalables y de texto completo del Performance Co-Pilot (PCP).

Actualmente, como todos los servicios relacionados con texto completo utilizan un único índice ValkeySearch, las métricas de diagnóstico se pueden solicitar pasando en key un valor de `text'. Los resultados se pasarán a la devolución de llamada on_metrics proporcionada por settings.

DIAGNÓSTICOS

Esta función siempre devuelve cero si tiene éxito. En caso de fallo, se devuelve un código de error negativo de la API de PM.

VER TAMBIÉN

pmproxy(1), pmlogger(1), pmsearch(1), pmSearchSetup(3), PMAPI(3) y PMWEBAPI(3).
