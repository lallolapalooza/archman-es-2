PMAREWRITEDATA(3) Manual de funciones de biblioteca PMAREWRITEDATA(3)

NOMBRE

pmaRewriteData - intenta cambiar la versión de un registro de datos de archivo

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaRewriteData(int invers,
int outvers __int32_t *rbuf);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las APIs de PCP que se garantiza que permanecerán fijas entre versiones, y es posible que no funcionen o que proporcionen una semántica diferente en algún momento futuro.

DESCRIPCIÓN

Se pasa un registro de datos físico de una versión de archivo invers a través de rbuf y se reformatea si es necesario para producir el registro de datos equivalente para una versión de archivo outvers.

Los registros de datos de archivo proporcionan la codificación de un pmResult para un volumen de datos de archivo.

La única opción razonable de invers y outvers hoy en día es PM_LOG_VERS02 y PM_LOG_VERS03 respectivamente, lo que solicitaría una reescritura del formato de la versión 2 del archivo al formato de la versión 3 del archivo (ya que actualmente solo se admiten las versiones 2 y 3).

Si se realiza la reescritura, el antiguo rbuf se habrá liberado y se habrá asignado uno nuevo con malloc(3). Es responsabilidad del llamador asegurarse de que esta posible liberación y asignación sea segura, por ejemplo, sin referencias colgadas en el contenido de rbuf, o pasar una copia del registro si es valioso.

DIAGNÓSTICOS Y VALORES DE RETORNO

En varios lugares, los errores fatales activarán un mensaje de error y forzarán la salida de la aplicación.

Si no existe una traducción definida de invers a outvers, pmaRewriteData devuelve PM_ERR_APPVERSION (una ligera perversión de este código de error).

Si no se realiza ninguna reescritura, el valor de retorno es 0, de lo contrario, un valor de retorno de 1 indica que se ha realizado una reescritura y rbuf ha sido realocado.

VEASE TAMBIÉN

free(3), malloc(3), PMAPI(3), y pmaRewriteMeta(3).
