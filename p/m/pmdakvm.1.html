PMDAKVM(1) Manual de comandos generales PMDAKVM(1)

NOMBRE

pmdakvm - agente de dominio de métricas de rendimiento de virtualización de Linux (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/kvm/pmdakvm [-D debug]

DESCRIPCIÓN

pmdakvm es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos del subsistema de virtualización KVM (Kernel Virtual Machine) de Linux.

Las métricas de rastreo de KVM por procesador, provenientes de los eventos del kernel enumerados en /sys/kernel/debug/tracing/events/kvm, pueden configurarse estáticamente usando el archivo de configuración de pmdakvm, /etc/pcp/kvm/kvm.conf.

INSTALACIÓN

Opcionalmente, configure puntos de rastreo en el archivo de configuración, luego instale el PMDA de KVM usando el script Install como root:

# cd $PCP_PMDAS_DIR/kvm
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/kvm
# ./Remove

pmdakvm es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o elimina.

ADVERTENCIAS

Cuando pmdakvm se está ejecutando, mantiene referencias a recursos del kernel dentro del controlador de dispositivos KVM. Por lo tanto, no es posible descargar o recargar el módulo del controlador del dispositivo mientras el PMDA se está ejecutando. El procedimiento ideal a seguir para recargar el módulo del kernel es el inverso al descrito en la sección ``INSTALACIÓN'' de arriba, es decir, primero ejecute ./Remove, luego recargue el módulo del kernel, luego ejecute ./Install.

ARCHIVOS

$PCP_SYSCONF_DIR/kvm/kvm.conf
archivo de configuración para el agente pmdakvm
$PCP_PMDAS_DIR/kvm/Install
script de instalación para el agente pmdakvm
$PCP_PMDAS_DIR/kvm/Remove
script para deshacer la instalación del agente pmdakvm
$PCP_LOG_DIR/pmcd/kvm.log
archivo de registro predeterminado para mensajes de error de pmdakvm

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN

PCPIntro(1), pmcd(1) y kvm(1).
