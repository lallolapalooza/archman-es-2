cc ... -lpcp_web

DESCRIPCIÓN

Las funciones pmSeriesSetup y sus relacionadas API preparan una aplicación para acceder a la funcionalidad de consulta de series temporales rápida y escalable del Performance Co-Pilot (PCP).

Esta funcionalidad se proporciona a través de APIs asíncronas, que funcionan de forma basada en eventos. Las interfaces descritas aquí preparan un módulo de series temporales dado que asocia rutinas de devolución de llamada con ciertos eventos asíncronos que ocurren como parte del servicio de solicitudes de series temporales.

Como patrón general, todas las interfaces en estas APIs que necesitan invocar callbacks (devoluciones de llamada) proporcionadas por el programa que llama tomarán un parámetro opaco (puntero void *), arg. Este puntero se pasará sin cambios y típicamente se usa para acceder a una estructura de datos que mantiene el estado dentro del programa que llama.

Donde se requiere configuración asíncrona por parte de pmSeriesSetup, su finalización se indicará mediante el uso de la devolución de llamada on_setup, que forma parte de la estructura pmSeriesModule pasada. Esta estructura también proporciona el manejo de diagnósticos personalizados, a través de la devolución de llamada on_info. Estas son autoexplicativas, consulte <pcp/pmwebapi.h> para conocer las convenciones de llamada exactas.

Las callbacks (devoluciones de llamada) registradas por pmSeriesSetup para manejar eventos son las siguientes:

pmSeriesMatchCallBack on_match
Cuando una consulta de series temporales descubre identificadores de series temporales que coinciden con la consulta, la devolución de llamada on_match se llamará una vez por cada identificador de serie (SID). El SID es una representación ASCII única de 40 bytes de un hash SHA.
pmSeriesDescCallBack on_desc
Las solicitudes de descriptores de métricas de pmSeriesDescs(1) invocarán esta devolución de llamada una vez por cada identificador de serie.
pmSeriesInstCallBack on_inst
Devolución de llamada de identificación de instancia: identificadores de instancia internos (numéricos) y externos (cadena), así como identificadores SHA1 de series temporales y de origen (host). Se llama una vez por cada instancia. El identificador de serie asociado también se proporciona a la devolución de llamada.
pmSeriesLabelCallBack on_labelmap
Proporciona etiquetas de métricas (mapeos de nombre y valor) para cada identificador de serie pasado a pmSeriesLabels(1).
pmSeriesStringCallBack on_instance
Proporciona un nombre de instancia para una llamada a pmSeriesInstances(1) - la devolución de llamada se llama una vez por cada nombre de instancia. El identificador de serie asociado también se proporciona a la devolución de llamada.
pmSeriesStringCallBack on_context
Proporciona un nombre de contexto para una llamada a pmSeriesSources(1) - la devolución de llamada se llama una vez por cada origen (nombre de host o archivo). El identificador de origen asociado también se proporciona a la devolución de llamada.
pmSeriesStringCallBack on_metric
Proporciona un nombre de métrica para una llamada a pmSeriesMetrics(1) - la devolución de llamada se llama una vez por cada nombre de métrica. El identificador de serie asociado también se proporciona a la devolución de llamada.
pmSeriesStringCallBack on_label
Proporciona un nombre de etiqueta para una llamada a pmSeriesLabels(1) - la devolución de llamada se llama una vez por cada nombre de etiqueta. El identificador de serie asociado también se proporciona a la devolución de llamada.
pmSeriesValueCallBack on_value
Las llamadas a la interfaz pmSeriesQuery que proporcionan una ventana de tiempo pueden resultar en que se encuentren valores para series temporales coincidentes. La devolución de llamada on_value se invocará una vez por cada valor de serie temporal, proporcionando también la marca de tiempo de la muestra (tanto en formato de cadena como binario, como tiempo en nanosegundos desde la época). El identificador de serie asociado también se proporciona a la devolución de llamada.
pmSeriesDoneCallBack on_done
Al completar todas las interfaces asíncronas que devuelven éxito (código de retorno cero), se llamará a esta devolución de llamada. Proporciona un código de estado que indica el éxito general (cero) o el fallo (código de error PMAPI negativo) de la operación.

Las funciones auxiliares pmSeriesSetSlots (servidor clave-valor), pmSeriesSetEventLoop (libuv), pmSeriesSetConfiguration (archivo de configuración) y pmSeriesSetMetricRegistry (instrumentación MMV) proporcionan un mecanismo para pasar el estado de cada uno de los subsistemas asociados.

Finalmente, una llamada a pmSeriesClose se utiliza para finalizar los servicios disponibles desde un módulo de series establecido previamente a través de pmSeriesSetup.

Dentro de PCP, las utilidades pmproxy(1) y pmseries(1) son los principales usuarios de estas interfaces, proporcionando la API REST y los servicios de consulta de series temporales desde la línea de comandos, respectivamente.

DIAGNÓSTICOS

Donde estas funciones devuelven un código de estado, este es siempre cero en caso de éxito. En caso de fallo, se devuelve un código de error negativo de la PMAPI.

pmSeriesSetup(3)

NAME

pmSeriesSetup - set up performance monitoring for a series.

SYNOPSIS

#include <pcp/pmapi.h>

int pmSeriesSetup(const char *<em>metric</em>, const char *<em>selector</em>, int <em>flags</em>);

DESCRIPTION

This function is used to set up performance monitoring for a series of performance metrics. It takes the metric name, an optional selector string, and a set of flags as arguments. The metric name specifies the performance metric to be monitored, and the selector string can be used to further qualify the metric (e.g., by specifying instance names or specific values). The flags argument can be used to control the behavior of the monitoring setup, such as enabling or disabling certain features.

RETURN VALUES

On success, pmSeriesSetup returns a non-negative integer representing the series identifier. On failure, it returns a negative error code.

ERRORS

Possible error codes include:

  • PMPROBE_EINVAL: Invalid arguments provided.
  • PMPROBE_ENOMEM: Insufficient memory available.
  • PMPROBE_EPERM: Insufficient privileges to access the metric.
  • PMPROBE_UNKNOWN: The specified metric is unknown.
