PMFREERESULT(3) Manual de funciones de biblioteca PMFREERESULT(3)

NOMBRE

pmFreeResult - liberar el almacenamiento asignado para los valores de métricas de rendimiento

SINOPSIS

#include <pcp/pmapi.h>

void pmFreeResult(pmResult *result);

cc ... -lpcp

DESCRIPCIÓN

Los resultados de tamaño variable devueltos por pmFetch(3) se asignan debajo de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) utilizando una combinación de estrategias de asignación dinámica (es decir, malloc(3)) y especializadas.

Las aplicaciones deben llamar a pmFreeResult para liberar el almacenamiento previamente asignado para result por pmFetch(3), cuando la aplicación ya no requiera acceso a la estructura pmResult.

Bajo ninguna circunstancia una aplicación debe usar free(result) para liberar el almacenamiento previamente asignado para un pmResult por pmFetch(3).

COMPATIBILIDAD

Antes de PCP 7.0, el campo timestamp en la estructura pmResult era una struct timeval. Para soportar la transición de PMAPI, la interfaz y la semántica antiguas se pueden usar si las aplicaciones se recompilan con -DPMAPI_VERSION=2.

Durante un tiempo en PCP 6.x hubo una rutina con la misma semántica que el actual pmFreeResult llamada pmFreeHighResResult, aunque ahora está obsoleta y el soporte en tiempo de compilación para pmFreeHighResResult se eliminará en una versión futura.

VER TAMBIÉN

PMAPI(3), malloc(3) y pmFetch(3).
