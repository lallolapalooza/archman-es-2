PMDALABEL(3) Manual de Funciones de Librería PMDALABEL(3)

NOMBRE

pmdaLabel, pmdaSetLabelCallBack - llenar estructuras pmLabelSet con etiquetas de métricas

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaLabel(int ident,
int type, pmLabelSet **sets, pmdaExt *pmda);

int pmdaSetLabelCallBack(pmdaInterface *dispatch,
pmdaLabelCallBack callback);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

Como parte de la API del Agente de Dominio de Métricas de Rendimiento (PMDA) (ver PMDA(3)), pmdaLabel utiliza las estructuras de datos PMDA(3) estándar para devolver las etiquetas del dominio de rendimiento, dominio de instancia, métrica o instancias individuales en formato "JSONB" en la estructura de datos sets dada.

El argumento type determina la interpretación de ident y la forma de etiqueta solicitada, como sigue:

PM_LABEL_DOMAIN
cuando ident es un identificador de dominio PMDA,
PM_LABEL_CLUSTER
cuando ident es un identificador de métrica y se solicitan etiquetas para el clúster que contiene esa métrica.
PM_LABEL_ITEM
cuando ident es un identificador de métrica,
PM_LABEL_INDOM
cuando ident es un identificador de dominio de instancia, o
PM_LABEL_INSTANCES
cuando ident es un identificador de métrica y se solicitan etiquetas para todas las instancias de esa métrica.

El puntero de etiqueta sets debe inicializarse a NULL antes de llamar a pmdaLabel y el espacio solo debe asignarse cuando las etiquetas estén presentes y se devuelvan. En este caso, el código de retorno debe indicar el número de sets de etiquetas que se han asignado. Esto solo será mayor que uno en el caso de PM_LABEL_INSTANCES.

Este es uno de los pocos callbacks genéricos en libpcp_pmda (ver PMDA(3)) que está incompleto, requiriendo un método pmdaLabelCallBack adicional propio. El callback adicional debe registrarse usando pmdaSetLabelCallBack y el método pmdaLabelCallBack tiene el siguiente prototipo:

int func(pmInDom indom, unsigned int inst, pmLabelSet **set)

El propósito de la rutina pmdaLabelCallBack es devolver la(s) etiqueta(s) para una instancia individual inst de un dominio de instancia dado, indom. Su código de retorno exitoso difiere significativamente de pmdaLabel, como se describe a continuación.

ADVERTENCIA

El PMDA debe estar usando PMDA_INTERFACE_7 o posterior, como se especifica en la llamada a pmdaDSO(3) o pmdaDaemon(3).

DIAGNÓSTICOS

En caso de éxito, pmdaLabel devuelve el número de sets de etiquetas creados. Esto suele ser cero o uno, excepto en el caso de PM_LABEL_INSTANCES donde a menudo se devolverán más de un set de etiquetas, uno por cada instancia de la métrica solicitada.

Por el contrario, en caso de éxito de la rutina pmdaLabelCallBack se debe devolver el número de etiquetas añadidas con éxito al puntero de conjunto de etiquetas proporcionado (y no el número total de sets de etiquetas).

Si las etiquetas para la entidad solicitada no pudieron obtenerse debido a un fallo catastrófico, como una condición de falta de memoria, estas rutinas devolverán un código de error negativo.

VER TAMBIÉN
