pmNumberStr(3)

PMNUMBERSTR(3) Manual de funciones de biblioteca PMNUMBERSTR(3)

NOMBRE

pmNumberStr, pmNumberStr_r - formato de salida de ancho fijo para números

SINOPSIS C

#include <pcp/pmapi.h>

const char *pmNumberStr(double value);
char *pmNumberStr_r(double value, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

pmNumberStr devuelve la dirección de un búfer de 8 bytes que contiene una representación de value terminada en nulo, adecuada para su salida con campos de ancho fijo. La función pmNumberStr_r hace lo mismo, pero almacena el resultado en un búfer proporcionado por el usuario buf de longitud buflen, que debe tener espacio para al menos 8 bytes.

El valor se escala utilizando multiplicadores en potencias de "mil" (el "kilo" decimal) y tiene un sesgo que proporciona mayor precisión para números positivos en comparación con los números negativos.

El formato depende del signo y la magnitud de value como sigue (d representa un dígito decimal):

rango de value formato
> 999995000000000 inf?
999995000000000 - 999995000000 ddd.ddT
999995000000 - 999995000 ddd.ddG
999995000 - 999995 ddd.ddM
999995 - 999.995 ddd.ddK
999.995 - 0.005 ddd.dd
0.005 - -0.005 0.00
-0.005 - -99.95 -dd.dd
-99.995 - -99995 -dd.ddK
-99995 - -99995000 -dd.ddM
-99995000 - -99995000000 -dd.ddG
-99995000000 - -99995000000000 -dd.ddT
< -99995000000000 -inf?

En los puntos límite de los rangos, el formato elegido conservará el número máximo de dígitos significativos.

NOTAS

pmNumberStr devuelve un puntero a un búfer estático y, por lo tanto, no es seguro para subprocesos. Las aplicaciones multihilo deben usar pmNumberStr_r en su lugar.
