PMIPUTVALUE(3) Manual de funciones de la biblioteca PMIPUTVALUE(3)

NOMBRE

pmiPutValue - añadir un valor para un par métrica-instancia

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutValue(const char *name,
const char *instance, const char *value);

cc ... -lpcp_import -lpcp

SINOPSIS Perl

use PCP::LogImport;

pmiPutValue($name, $instance, $value);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiPutValue añade un único valor al registro de salida actual para una métrica e instancia dadas.

El nombre de la métrica debe coincidir con uno definido anteriormente en una llamada a pmiAddMetric(3).

Para métricas singulares (aquellas definidas con un dominio de instancia de PM_INDOM_NULL), instance debe ser NULL o una cadena vacía; de lo contrario, instance debe coincidir con el nombre de una instancia definida anteriormente en una llamada a pmiAddInstance(3) para el dominio de instancias de la métrica.

El valor debe estar en un formato consistente con el tipo de métrica tal como se define en la llamada a pmiAddMetric(3).

No se escribirán datos hasta que se llame a pmiWrite(3), por lo que las llamadas múltiples a pmiPutValue o pmiPutValueHandle(3) se utilizan típicamente para acumular valores de datos para varios pares métrica-instancia antes de llamar a pmiWrite(3).

DIAGNÓSTICOS

pmiPutValue devuelve cero si tiene éxito, de lo contrario, devuelve un valor negativo que puede convertirse en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutResult(3), pmiPutValueHandle(3), pmiPutText(3), pmiPutLabel(3) y pmiWrite(3).
