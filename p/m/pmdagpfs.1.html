PMDAGPFS(1) Manual de comandos generales PMDAGPFS(1)

NOMBRE

pmdagpfs - agente de dominio de métricas de rendimiento (PMDA) de estadísticas del sistema de archivos gpfs

DESCRIPCIÓN

pmdagpfs es un Agente de Dominio de Métricas (PMDA) que exporta valores métricos del programa /usr/lpp/mmfs/bin/mmpmon para proporcionar información sobre los sistemas de archivos gpfs montados.

INSTALACIÓN

Instale el PMDA de gpfs utilizando el script de instalación como root:

# cd $PCP_PMDAS_DIR/gpfs
# ./Install

Para desinstalar, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/gpfs
# ./Remove

pmdagpfs es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/gpfs/Install
script de instalación para el agente pmdagpfs
$PCP_PMDAS_DIR/gpfs/Remove
script para deshacer la instalación del agente pmdagpfs
$PCP_LOG_DIR/pmcd/gpfs.log
archivo de registro predeterminado para mensajes de error de pmdagpfs

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1) y mmpmon(8).
