NOMBRE

pmFreeLabelSets - liberar el almacenamiento asignado para las etiquetas de métricas de rendimiento

SINOPSIS C

#include <pcp/pmapi.h>

void pmFreeLabelSets(pmLabelSet *sets, int nsets);

cc ... -lpcp

DESCRIPCIÓN

El array de conjuntos de etiquetas (label sets) devuelto por pmLookupLabels(3) y APIs relacionadas se asignan por debajo de la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) mediante una variedad de llamadas a las interfaces de asignación de memoria dinámica del sistema (es decir, malloc(3)).

Las aplicaciones deben llamar a pmFreeLabelSets para liberar el almacenamiento previamente asignado para el array de conjuntos de etiquetas (label sets) cuando ya no se necesite acceso a la estructura. El valor de retorno de pmLookupLabels indica el número de elementos en el array de conjuntos de etiquetas (label sets), y este debe pasarse a través del parámetro nsets.

Bajo ninguna circunstancia una aplicación debe usar free(labelset) para liberar el almacenamiento previamente asignado para un pmLabelSet por pmLookupLabels(3) o APIs relacionadas.

Para simplificar el manejo de errores, si sets es NULL, entonces pmFreeLabelSets simplemente retorna sin liberar ningún almacenamiento.

VER TAMBIÉN

malloc(3), PMAPI(3) y pmLookupLabels(3).
