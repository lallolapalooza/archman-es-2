PMWHICHCONTEXT(3) Manual de funciones de biblioteca PMWHICHCONTEXT(3)

NOMBRE

pmWhichContext - identificar el contexto actual de PMAPI

SINOPSIS EN C

#include <pcp/pmapi.h>

int pmWhichContext(void);

cc ... -lpcp

DESCRIPCIÓN

Una aplicación que utiliza la Interfaz de Programación de Aplicaciones de Métricas de Rendimiento (PMAPI) puede manipular varios contextos concurrentes, cada uno asociado con una fuente de métricas de rendimiento, por ejemplo, pmcd(1) en algún host, o un archivo de métricas de rendimiento creado por pmlogger(1).

pmWhichContext devuelve un identificador para el contexto actual de PMAPI, que puede ser utilizado en las rutinas asociadas de PMAPI que requieren un identificador para especificar un contexto de PMAPI.

DIAGNÓSTICOS

PM_ERR_NOCONTEXT
sin contexto actual

VER TAMBIÉN

PMAPI(3), pmDestroyContext(3), pmDupContext(3), pmNewContext(3) y pmUseContext(3).
