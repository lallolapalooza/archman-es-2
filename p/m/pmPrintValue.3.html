PMPRINTVALUE(3) Manual de funciones de la biblioteca PMPRINTVALUE(3)

NOMBRE

pmPrintValue - imprimir el valor de una métrica de rendimiento

SINOPSIS C

#include <stdio.h>
#include <pcp/pmapi.h>

void pmPrintValue(FILE *f,
int valfmt, int type, const pmValue *val, int minwidth);

cc ... -lpcp

DESCRIPCIÓN

El valor de una única métrica de rendimiento (tal como se identifica por val) se imprime en el flujo de E/S estándar identificado por f.

El valor de la métrica de rendimiento se interpreta de acuerdo con el formato de val según lo define valfmt (de un pmValueSet dentro de una estructura pmResult; ver pmFetch(3)) y la descripción genérica del tipo de métrica pasada a través de type.

El valor para type se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

La salida se rellenará opcionalmente para que tenga al menos minwidth caracteres de ancho.

pmPrintValue es más útil para mostrar los valores de las métricas de rendimiento de pmFetch(3) (que devuelve un conjunto de pares valfmt y val para cada métrica solicitada), basándose en el tipo de métrica devuelto por pmLookupDesc(3).

AMBIENTE

La salida de los valores de métricas de cadena puede controlarse adicionalmente usando PCP_SQUASH_NEWLINES. Cuando se establece en el entorno del proceso que llama, y el type se establece en PM_TYPE_STRING o PM_TYPE_AGGREGATE, entonces se garantiza que el valor de salida estará libre de caracteres de nueva línea incrustados. Si el valor dado contenía dichos caracteres, habrán sido reemplazados por un espacio antes de imprimirse.
