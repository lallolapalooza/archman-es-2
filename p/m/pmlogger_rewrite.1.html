PMLOGGER_REWRITE(1) Manual de comandos generales PMLOGGER_REWRITE(1)

NOMBRE

pmlogger_rewrite - script auxiliar para reescribir archivos de Performance Co-Pilot

SINOPSIS

$PCP_BINADM_DIR/pmlogger_rewrite [-dNsVvw?] [-c config] archivo ...

DESCRIPCIÓN

pmlogger_rewrite es un script auxiliar que es utilizado por pmlogger_daily(1) al reescribir archivos de Performance Co-Pilot (PCP). La reescritura suele ser necesaria para acomodar cambios evolutivos en metadatos, de modo que los archivos antiguos puedan actualizarse y luego fusionarse con los archivos actuales.

pmlogger_rewrite es un script de envoltura para pmlogrewrite(1) que potencialmente reescribirá todos los archivos que coincidan con los argumentos de archivo. Cada argumento de archivo puede ser un nombre de archivo de archivo PCP, el nombre base para los archivos en un archivo PCP o un directorio (en cuyo caso todos los archivos PCP subordinados se encuentran mediante descenso recursivo).

pmlogrewrite se ejecuta con la opción -i para que la reescritura se realice "en el lugar". También se utiliza la opción -q, de modo que si no se requiere ninguna reescritura, no se realizan cambios en los archivos del archivo.

OPCIONES

Las siguientes opciones se pasan a pmlogrewrite: -c (o --config), -d (o --desperate), -s (o --scale), -v (o --verbose) y -w (o --warnings). Consulte pmlogrewrite(1) para conocer el significado de estas opciones.

Las opciones restantes son:

-N, --showme
Ejecuta pmlogger_rewrite en modo "mostrarme" o "simulacro", donde se informan las tareas que se realizarían, pero no se realizan cambios. Esto se usa típicamente para depuración en combinación con una (verbosa) o dos (muy verbosa) opciones -V.
-V, --verbose
Aumenta la verbosidad de la salida del script.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmlogger(1), pmlogger_daily(1) y pmlogrewrite(1).
