PMDABASH(1) Manual de comandos generales PMDABASH(1)

NOMBRE

pmdabash - Agente de dominio de métricas de rendimiento de rastreo de la shell Bourne-Again SHell

SINOPSIS

$PCP_PMDAS_DIR/bash/pmdabash [-C] [-D debug] [-d dominio] [-l archivo_log] [-I intervalo] [-t tiempo_espera] [-U nombre_usuario] archivo_config

DESCRIPCIÓN

pmdabash es un Agente de Dominio de Métricas de Rendimiento (PMDA) experimental que exporta eventos "xtrace" de un proceso bash(1) rastreado. Esto incluye la información de ejecución de comandos que normalmente se enviaría a la salida estándar de error con la opción set -x para la shell.

Se exportan métricas de eventos que muestran cada comando ejecutado, el nombre de la función y el número de línea en el script, y una marca de tiempo. Además, se exportan el identificador del proceso para la shell y su proceso padre.

Esto requiere bash versión 4 o posterior.

A continuación, se presenta una breve descripción de las opciones de línea de comandos de pmdabash:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado bash.log en el directorio actual de pmcd(1) cuando se inicia pmdabash, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no se puede escribir en él, la salida se escribe en la salida estándar de error en su lugar.
-s
Cantidad de tiempo (en segundos) entre evaluaciones subsecuentes de los descriptores de archivo de rastreo de la shell. El valor predeterminado es 2 segundos.
-m
Cantidad máxima de memoria permitida para cada cola de eventos (una por proceso rastreado). El valor predeterminado es 2 megabytes.
-U
Cuenta de usuario bajo la cual ejecutar el agente. El valor predeterminado es la cuenta no privilegiada "pcp" en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

INSTALACIÓN

Para que un host exporte los nombres, el texto de ayuda y los valores de las métricas de rendimiento de bash, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/bash
# ./Install

Tan pronto como se ejecute un script de shell instrumentado (ver selección de INSTRUMENTACIÓN a continuación), con el rastreo habilitado, aparecerán nuevos valores de métricas; no se requiere ninguna configuración adicional del agente.

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/bash
# ./Remove

pmdabash es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

INSTRUMENTACIÓN

Para permitir el flujo de datos de eventos entre un script de bash(1) y pmdabash, el script debe realizar las siguientes acciones:

#!/bin/sh
source $PCP_DIR/etc/pcp.env
source $PCP_SHARE_DIR/lib/bashproc.sh
pcp_trace on $@       # habilita el rastreo
echo "awoke, $count"
pcp_trace off         # deshabilita el rastreo

El rastreo se puede habilitar y deshabilitar cualquier número de veces por el script. Tras la instalación exitosa del agente, estarán disponibles varias métricas:

$ pminfo bash
bash.xtrace.numclients
bash.xtrace.maxmem
bash.xtrace.queuemem
bash.xtrace.count
bash.xtrace.records
bash.xtrace.parameters.pid
bash.xtrace.parameters.parent
bash.xtrace.parameters.lineno
bash.xtrace.parameters.function
bash.xtrace.parameters.command

Cuando se está ejecutando un script instrumentado, la generación de registros de eventos se puede verificar utilizando el comando pmevent(1), de la siguiente manera:

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para iniciar pmdabash
$PCP_PMDAS_DIR/bash/help
archivo de texto de ayuda predeterminado para las métricas de bash
$PCP_PMDAS_DIR/bash/Install
script de instalación para el agente pmdabash
$PCP_PMDAS_DIR/bash/Remove
script de desinstalación para pmdabash
$PCP_LOG_DIR/pmcd/bash.log
archivo de registro predeterminado para mensajes de error y otra información de pmdabash

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdabash son las siguientes:

Opción Descripción
appl0 registro detallado de eventos de interés
