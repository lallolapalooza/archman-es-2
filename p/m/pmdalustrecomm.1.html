PMDALUSTERCOMM(1) Manual de comandos generales PMDALUSTERCOMM(1)

NOMBRE

pmdalustrecomm - Agente de dominio de métricas de rendimiento de comunicación del sistema de archivos Lustre (PMDA)

SINOPSIS

$PCP_PMDAS_DIR/lustrecomm/pmdalustrecomm [-D debug] [-d dominio] [-l logfile] [-U username]

DESCRIPCIÓN

pmdalustrecomm es un Agente de Dominio de Métricas de Rendimiento (PMDA) que extrae métricas de rendimiento del sistema de archivos procfs de Linux sobre el estado de varios aspectos del sistema de archivos Lustre.

El PMDA lustrecomm exporta métricas que se centran en la comunicación distribuida en el sistema de archivos, incluidas métricas relacionadas con tiempos de espera, caídas de red, información de envío/recepción y longitudes de ruta. Sin embargo, también cubre el uso de memoria de algunos de los componentes del sistema de archivos Lustre.

A continuación, se incluye una breve descripción de las opciones de línea de comandos de pmdalustrecomm:

-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y se debe usar el mismo número de dominio para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado lustrecomm.log en el directorio actual de pmcd(1) cuando se inicia pmdalustrecomm, es decir, en $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se envía al error estándar en su lugar.
-U
Cuenta de usuario bajo la cual ejecutar el agente. Por defecto, es la cuenta "pcp" sin privilegios en las versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

INSTALACIÓN

Si desea acceder a los nombres, el texto de ayuda y los valores de las métricas de rendimiento de lustrecomm, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/lustrecomm
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/lustrecomm
# ./Remove

pmdalustrecomm es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
opciones de línea de comandos utilizadas para lanzar pmdalustrecomm
$PCP_PMDAS_DIR/lustrecomm/help
archivo de texto de ayuda predeterminado para las métricas de lustrecomm
$PCP_PMDAS_DIR/lustrecomm/Install
script de instalación para el agente pmdalustrecomm
$PCP_PMDAS_DIR/lustrecomm/Remove
script para deshacer la instalación del agente pmdalustrecomm
$PCP_LOG_DIR/pmcd/lustrecomm.log
archivo de registro predeterminado para mensajes de error y otra información de pmdalustrecomm

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

VER TAMBIÉN
