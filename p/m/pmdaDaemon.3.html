PMDADAEMON(3) Manual de funciones de biblioteca PMDADAEMON(3)

NOMBRE

pmdaDaemon - inicializa la PMDA para que se ejecute como un demonio

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

void pmdaDaemon(pmdaInterface *dispatch,
int interface, const char *name, int domain, const char *logfile, const char *helptext);

cc ... -lpcp_pmda -lpcp

DESCRIPCIÓN

pmdaDaemon inicializa la estructura pmdaInterface para usar las extensiones de interface asumiendo que la PMDA(3) se ejecutará como un demonio. La estructura pmdaInterface se inicializa con:

name
El nombre del agente.
domain
El número de dominio predeterminado del agente que identifica de forma única esta PMDA de otras PMDAs en ejecución. Esto puede cambiarse posteriormente mediante la opción de línea de comandos -d (ver pmdaGetOpt(3)).
logfile
La ruta predeterminada al archivo de registro. Esto puede ser reemplazado por la opción de línea de comandos -l si se usa pmdaGetOpt. logfile se copiará con strdup(3), por lo que el almacenamiento asociado con logfile puede liberarse después de la llamada a pmdaDaemon.
helptext
La ruta predeterminada al texto de ayuda (ver pmdaText(3). Esto puede ser reemplazado por la opción de línea de comandos -h si se usa pmdaGetOpt(3). Si no hay texto de ayuda instalado, o no estás usando pmdaText(3), entonces esto debe establecerse a NULL, de lo contrario helptext se copiará con strdup(3), por lo que el almacenamiento asociado con helptext puede liberarse después de la llamada a pmdaDaemon.

Las devoluciones de llamada se inicializan a pmdaProfile(3), pmdaFetch(3), pmdaDesc(3), pmdaText(3), pmdaInstance(3) y pmdaStore(3).

ADVERTENCIA

La PMDA debe estar usando PMDA_INTERFACE_2 o posterior.

Una vez que se ha llamado a pmdaDaemon, se espera que la estructura pmdaInterface apuntada por dispatch permanezca accesible para las rutinas en libpcp_pmda (no se recupere de la pila, no se libere o se desaloje de otra manera, etc.). Si el llamador necesita mover o reubicar la estructura pmdaInterface por cualquier motivo, entonces después de la mudanza pmdaInterfaceMoved(3) debe ser llamada para restablecer la integridad interna de la estructura pmdaInterface en la nueva ubicación antes de que se pueda llamar a cualquier otra rutina en libpcp_pmda.

DIAGNÓSTICOS

Imposible asignar memoria para la estructura pmdaExt
Además, el campo dispatch->status se establece a un valor menor que cero.
La versión de la interfaz PMDA interface no es compatible
La versión interface no es compatible con pmdaDaemon.

VER TAMBIÉN

PMAPI(3), PMDA(3), pmdaDSO(3), pmdaGetOpt(3), pmdaInterfaceMoved(3) y pmdaText(3).
