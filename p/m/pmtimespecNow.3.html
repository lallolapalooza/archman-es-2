NOMBRE

pmtimespecNow, pmtimespecInc, pmtimespecDec, pmtimespecAdd, pmtimespecSub, pmtimespecToReal, pmtimespecFromReal, pmtimespecTotimeval, pmtimespecPrint, pmtimespecPrintInterval - rutinas auxiliares para el tiempo almacenado como un struct timespec

C SINOPSIS

#include <pcp/pmapi.h>

void pmtimespecNow(struct timespec *tp);
void pmtimespecInc(struct timespec *ap, const struct timespec *bp);
void pmtimespecDec(struct timespec *ap, const struct timespec *bp);
double pmtimespecAdd(const struct timespec *ap,
const struct timespec *bp);

double pmtimespecSub(const struct timespec *ap,
const struct timespec *bp);

double pmtimespecToReal(const struct timespec *tp);
void pmtimespecFromReal(double secs, struct timespec *tp);
void pmtimespecTotimeval(struct timespec *tsp, struct timeval *tvp);
void pmtimespecPrint(FILE *f, const struct timespec *tp);
void pmtimespecPrintInterval(FILE *f, const struct timespec *tp);

cc ... -lpcp

DESCRIPCIÓN

pmtimespecNow es un método independiente de la plataforma que devuelve el tiempo actual del sistema desde la Época en tp.

pmtimespecInc suma el tiempo en ap al tiempo en bp y almacena el resultado en ap. De forma similar, pmtimespecDec resta el tiempo en bp del tiempo en ap y almacena el resultado en ap.

pmtimespecAdd (y pmtimespecSub) suman (y restan) tiempos y devuelven el resultado como un valor double. El tiempo en el argumento ap no se modifica.

pmtimespecToReal convierte el tiempo en tp a un valor double equivalente. pmtimespecFromReal proporciona la conversión inversa, tomando el tiempo en secs y devolviendo el tiempo equivalente en tp.

pmtimespecTotimeval convierte el struct timespec tsp en un struct timeval tvp equivalente (módulo truncamiento de nanosegundos a microsegundos).

Para pmtimespecAdd, pmtimespecSub, pmtimespecToReal y pmtimespecFromReal existe un problema de precisión numérica. Si el resultado o el operando double tiene más de 6 dígitos decimales de precisión en la parte de segundos del valor, entonces el valor fraccionario se convierte a microsegundos antes de los cálculos aritméticos, por lo que el campo de nanosegundos solo es preciso hasta 6 dígitos decimales en este caso.

pmtimespecPrint imprime la marca de tiempo de tp en el flujo f en la hora local (según lo devuelto por pmLocaltime(3)) en el formato HH:MM:SS.XXXXXXXXX.

pmtimespecPrintInterval imprime el intervalo de tp en el flujo f en un formato minimalista [[HHh]MMm]SS[.XXXXXXXXX]s donde las horas, minutos y nanosegundos solo se informan si son distintos de cero, y los ceros finales en los nanosegundos se omiten. Por ejemplo, si tp->tv_sec era 75 y tp->tv_nsec era 51000000, la salida sería 1h15.51s.

NOTAS

Para variantes de estas interfaces que utilizan precisión de microsegundos y la estructura timeval, consulte pmtimevalNow(3).

COMPATIBILIDAD

Antes de PCP 7.0, la rutina pmtimespecPrint se llamaba pmPrintHighResStamp. Para admitir la transición de PMAPI, la rutina antigua aún se puede usar si las aplicaciones se recompilan con -DPMAPI_VERSION=2.

pmPrintHighResStamp ahora está obsoleta y el soporte en tiempo de compilación para este nombre de rutina se eliminará en una futura versión.

VEASE TAMBIÉN

PMAPI(3), pmLocaltime(3) y pmtimevalNow(3).
