PMDAMSSQL(1) Manual de comandos generales PMDAMSSQL(1)

NOMBRE

pmdamssql - PMDA de base de datos Microsoft SQL Server

DESCRIPCIÓN

pmdamssql es un Agente de Dominio de Métricas de Rendimiento (PMDA) de Performance Co-Pilot (PCP) que extrae datos de rendimiento en vivo de un servidor de base de datos Microsoft SQL Server en ejecución.

CONFIGURACIÓN

En primer lugar, pmdamssql requiere la instalación de estos paquetes de soporte:

mssql-server
El paquete principal de la base de datos Microsoft SQL Server.
msodbcsql18, msodbcsql17 o msodbcsql
Enlaces ODBC de Microsoft SQL Server.
pyodbc
Módulo ODBC general de Python con soporte para Microsoft SQL Server habilitado.

A continuación, pmdamssql lee un archivo de configuración opcional de estilo ini:

$PCP_PMDAS_DIR/mssql/mssql.conf

Actualmente, este archivo permite dos secciones, una para configurar la biblioteca que se conecta al servidor SQL y otra para autenticarse con el servidor SQL.

La sección [connection] especifica los valores para los siguientes ajustes (sus valores predeterminados se muestran entre paréntesis):

driver ({ODBC Driver 17 for SQL Server})
Cadena del controlador ODBC.
server (tcp:localhost)
Cadena de conexión del socket de SQL Server.
timeout (2)
Ajuste del tiempo de espera de conexión, en segundos.

La sección [authentication] especifica los valores para los dos modos de autenticación compatibles con SQL Server.

Por defecto, se utiliza la autenticación de SQL Server, que requiere un nombre de usuario y una contraseña. Estos son los siguientes ajustes de configuración (sus valores predeterminados se muestran entre paréntesis):

username (pcp)
Nombre de usuario para conectarse a la base de datos.
password (vacío)
Contraseña para conectarse a la base de datos.

Tenga en cuenta que si se encuentra un archivo de configuración de la API de evaluaciones de SQL Server en /var/opt/mssql/secrets/assessment, entonces pmdamssql leerá el nombre de usuario y la contraseña de ese archivo de forma preferente. El formato es simplemente un archivo de texto de dos líneas, la primera contiene el nombre de usuario y la segunda la contraseña.

La segunda opción es el modo de autenticación de Windows, donde los inicios de sesión se crean en SQL Server sin basarse en cuentas de usuario del sistema operativo.

trusted (false)
Establezca en true para usar la autenticación de Windows al conectarse a la base de datos.

Esta es una conexión de estilo Kerberos y las credenciales deben estar disponibles antes de que se inicie el PMDA (consulte kinit(1) para más detalles).

INSTALACIÓN

Para instalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/mssql
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/mssql
# ./Remove

pmdamssql es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

pmdamssql intentará automáticamente reconectarse al servidor SQL si se pierde su conexión, por ejemplo, si se reinicia el servicio del servidor SQL.

ARCHIVOS

$PCP_PMDAS_DIR/mssql/mssql.conf
archivo de configuración para el agente pmdamssql
$PCP_PMDAS_DIR/mssql/Install
script de instalación para el agente pmdamssql
$PCP_PMDAS_DIR/mssql/Remove
script para deshacer la instalación del agente pmdamssql
$PCP_LOG_DIR/pmcd/mssql.log
archivo de registro predeterminado para mensajes del agente pmdamssql

Tenga en cuenta que el valor habitual/predeterminado para $PCP_PMDAS_DIR es /var/lib/pcp/pmdas y el predeterminado para $PCP_LOG_DIR es /var/log/pcp, pero estas configuraciones dependen de la plataforma.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
