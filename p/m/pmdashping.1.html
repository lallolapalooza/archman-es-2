PMDASHPING(1) Manual de comandos generales PMDASHPING(1)

NOMBRE

pmdashping - Agente de dominio de métricas de rendimiento "shell-ping"

SINOPSIS

$PCP_PMDAS_DIR/shping/pmdashping [-C] [-D debug] [-d dominio] [-l logfile] [-I intervalo] [-t timeout] [-U usuario] configfile

DESCRIPCIÓN

pmdashping es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta mediciones de calidad de servicio y tiempo de respuesta para comandos arbitrarios que se ejecutarían desde un shell como sh(1).

Estas mediciones están destinadas a cuantificar la calidad del servicio y la disponibilidad del servicio para aquellos servicios que son críticos para la misión o que actúan como indicadores tempranos de un rendimiento adverso del sistema.

La configuración de ejemplo monitoriza comandos de shell simples (exit y date(1)), una tarea computacionalmente intensiva corta usando sum(1), una compilación C corta, consulta DNS a través de nslookup(1), consulta YP a través de ypcat(1), servicio bind/portmapper usando rpcbind(1), SMTP conectándose al puerto telnet 25 y enviando una solicitud "expn root", y NNTP conectándose al puerto telnet 119 y ejecutando un comando "listgroup".

Se espera que otros comandos sigan los ejemplos del archivo de configuración de muestra, y la mayoría de las implementaciones del PMDA pmdashping se espera que utilicen un archivo de configuración personalizado.

A continuación, una breve descripción de las opciones de línea de comandos de pmdashping:

-C
Analiza configfile, informando cualquier error y saliendo con un estado distinto de cero si el archivo contiene errores sintácticos.
-d
Es absolutamente crucial que el número de dominio de métricas de rendimiento especificado aquí sea único y consistente. Es decir, dominio debe ser diferente para cada PMDA en el mismo host, y el mismo número de dominio debe usarse para el mismo PMDA en todos los hosts.
-l
Ubicación del archivo de registro. Por defecto, se escribe un archivo de registro llamado shping.log en el directorio actual de pmcd(1) cuando se inicia pmdashping, es decir, $PCP_LOG_DIR/pmcd. Si el archivo de registro no se puede crear o no es escribible, la salida se escribe en el error estándar en su lugar.
-I
Tiempo (en segundos) entre ejecuciones subsiguientes de la lista de comandos proporcionados a través del archivo de configuración configfile. El valor predeterminado es 2 minutos.
-t
Tiempo (en segundos) a esperar antes de agotar el tiempo de espera de una respuesta para un comando de configfile. El valor predeterminado es 20 segundos.
-U
Cuenta de usuario bajo la cual ejecutar el agente y todos los comandos. El valor predeterminado es la cuenta no privilegiada "pcp" en versiones actuales de PCP, pero en versiones anteriores se utilizaba la cuenta de superusuario ("root") por defecto.

El configfile requerido especifica pares de "etiqueta" y "comando", cada uno en una línea separada. Todos los comandos se ejecutan uno tras otro, con todo el grupo reprogramado para ejecutarse una vez por intervalo. Para cada comando que se ejecuta, pmdashping registra información relacionada con el éxito (o tiempo de espera), el estado de salida, el tiempo transcurrido y el tiempo de CPU (sistema y usuario), y esta información es exportada por el PMDA. Las etiquetas se utilizan para identificar los comandos individuales entre los valores exportados por el PMDA, y forman los identificadores de instancia externos para las métricas de pmdashping que se relacionan con cada comando.

INSTALACIÓN

Para que un host exporte los nombres, el texto de ayuda y los valores para las métricas de rendimiento de shping, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/shping
# ./Install

El conjunto de pares de "etiqueta" y "comando" puede especificarse desde un archivo de configuración predeterminado (muestra), un archivo personalizado o ingresarse interactivamente como parte del script Install.

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/shping
# ./Remove

pmdashping es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMCDCONF_PATH
Opciones de línea de comandos utilizadas para iniciar pmdashping
$PCP_PMDAS_DIR/shping/help
Archivo de texto de ayuda predeterminado para las métricas de shping
$PCP_PMDAS_DIR/shping/sample.conf
Archivo de configuración de ejemplo con una serie de comandos comunes
$PCP_PMDAS_DIR/shping/Install
Script de instalación para el agente pmdashping
$PCP_PMDAS_DIR/shping/Remove
Script para deshacer la instalación de pmdashping
$PCP_LOG_DIR/pmcd/shping.log
Archivo de registro predeterminado para mensajes de error y otra información de pmdashping

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información es a veces críptica y está destinada principalmente a orientar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; utilice pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmdashping son las siguientes:

Opción Descripción
appl0 manejo de salida
appl1 análisis de configfile, tiempos de espera, ciclo de actualización
appl2 anexa comandos y argumentos a shping.out a medida que se ejecutan
