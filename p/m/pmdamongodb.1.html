PMDAMONGODB(1) Manual de comandos generales PMDAMONGODB(1)

NOMBRE

pmdamongodb - métricas de la base de datos MongoDB

DESCRIPCIÓN

pmdamongodb es un Agente de Dominio de Métricas de Rendimiento (PMDA) de Performance Co-Pilot (PCP) que extrae datos de rendimiento en vivo de un servidor de base de datos MongoDB en ejecución.

CONFIGURACIÓN

En primer lugar, pmdamongodb requiere la instalación de los paquetes de soporte de pymongo, un módulo Python de propósito general para consultar MongoDB.

A continuación, pmdamongodb lee un archivo de configuración opcional de estilo ini:

$PCP_PMDAS_DIR/mongodb/mongodb.conf

Este archivo permite actualmente dos secciones, una para configurar la conexión del socket de MongoDB y otra para la autenticación.

[connection]

host (localhost)
Conectar al socket de MongoDB en el nombre de host dado.
port (27017)
Conectar al socket de MongoDB en el puerto dado.

[authentication]

username (vacío)
Nombre de usuario para conectarse a la base de datos.
password (vacío)
Contraseña para conectarse a la base de datos.

INSTALACIÓN

Para instalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/mongodb
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/mongodb
# ./Remove

pmdamongodb es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/mongodb/mongodb.conf
archivo de configuración para el agente pmdamongodb
$PCP_PMDAS_DIR/mongodb/Install
script de instalación para el agente pmdamongodb
$PCP_PMDAS_DIR/mongodb/Remove
script para deshacer la instalación del agente pmdamongodb
$PCP_LOG_DIR/pmcd/mongodb.log
archivo de registro predeterminado para mensajes del agente pmdamongodb

Tenga en cuenta que el valor habitual/predeterminado para $PCP_PMDAS_DIR es /var/lib/pcp/pmdas y el predeterminado para $PCP_LOG_DIR es /var/log/pcp, pero estas configuraciones dependen de la plataforma.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
