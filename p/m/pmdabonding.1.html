PMDABONDING(1) Manual de comandos generales PMDABONDING(1)

NOMBRE

pmdabonding - agente del dominio de métricas de rendimiento de interfaces agrupadas (PMDA) de Linux

DESCRIPCIÓN

pmdabonding es un Agente del Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos de las interfaces de red agrupadas en el kernel de Linux.

INSTALACIÓN

Instale el PMDA de bonding utilizando el script Install como root:

# cd $PCP_PMDAS_DIR/bonding
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/bonding
# ./Remove

pmdabonding es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/bonding/Install
script de instalación para el agente pmdabonding
$PCP_PMDAS_DIR/bonding/Remove
script para deshacer la instalación del agente pmdabonding
$PCP_LOG_DIR/pmcd/bonding.log
archivo de registro predeterminado para mensajes de error de pmdabonding

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN
