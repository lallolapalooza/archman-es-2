NOMBRE

pmLookupInDomText - devuelve texto que describe un dominio de instancia de métricas de rendimiento

C SINOPSIS

#include <pcp/pmapi.h>

int pmLookupInDomText(pmInDom indom,
int level, char **buffer);

cc ... -lpcp

DESCRIPCIÓN

Recupera texto descriptivo sobre el dominio de instancias de métricas de rendimiento identificado por indom.

El valor del dominio de instancia indom se extrae típicamente de una estructura pmDesc, después de una llamada a pmLookupDesc(3) para una métrica de rendimiento particular.

El argumento level debe ser PM_TEXT_ONELINE para un resumen de una línea, o PM_TEXT_HELP para una descripción más detallada, adecuada para un cuadro de diálogo de ayuda.

El espacio apuntado por buffer habrá sido asignado en pmLookupInDomText con malloc(3), y es responsabilidad del llamante liberar (free(3)) el espacio cuando ya no sea necesario.

pmLookupInDomText devuelve cero si tiene éxito.

DIAGNÓSTICOS

PM_ERR_NOTHOST
Para archivos creados con versiones de PCP anteriores a la 4.0, si el contexto actual de PMAPI es un archivo (el texto de ayuda y de una línea no se mantenía anteriormente en los archivos)
