PMPATHSEPARATOR(3) Manual de funciones de biblioteca PMPATHSEPARATOR(3)

NOMBRE

pmPathSeparator - devuelve el carácter separador de ruta del sistema de archivos

SINOPSIS C

#include <pcp/pmapi.h>

int pmPathSeparator(void);

cc ... -lpcp

DESCRIPCIÓN

pmPathSeparator es un método de conveniencia que devuelve ``/'' en el mundo civilizado. Para plataformas Windows, puede obtener ``/'' o ``\'' dependiendo del entorno de ejecución.

El escenario de uso más común es usar pmPathSeparator para construir el nombre de ruta completo de un archivo a partir de un nombre de directorio conocido y un nombre de archivo relativo.
