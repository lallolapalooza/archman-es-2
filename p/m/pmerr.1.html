NOMBRE

pmerr - traduce códigos de error de Performance Co-Pilot a mensajes de error

SINOPSIS

pmerr [-?] código ...
pmerr -l

DESCRIPCIÓN

pmerr acepta códigos de error estándar de Performance Co-Pilot (PCP) a través del argumento(s) código y genera el texto de error correspondiente.

Cada código puede ser un entero, un valor hexadecimal o un valor hexadecimal prefijado por ``0x'' o ``0X''.

Los códigos de error deben ser menores que cero, por lo que si código es un número positivo, se produce un mensaje de advertencia y se utiliza el valor negado.

OPCIONES

Las opciones disponibles de línea de comandos son:

-l, --list
Esta invocación alternativa hace que se listen todos los códigos de error conocidos, junto con sus nombres simbólicos y texto de error.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VéASE TAMBIÉN

PMAPI(3), pmErrStr(3), pcp.conf(5) y pcp.env(5).
