PMUNITSSTR(3) Manual de Funciones de Biblioteca PMUNITSSTR(3)

NOMBRE

pmUnitsStr, pmUnitsStr_r - convertir las unidades de una métrica de rendimiento a una cadena

SINOPSIS

#include <pcp/pmapi.h>

const char *pmUnitsStr(const pmUnits *pu);
char *pmUnitsStr_r(const pmUnits *pu, char *buf, int buflen);

cc ... -lpcp

DESCRIPCIÓN

La codificación de la dimensionalidad y escala de una métrica de rendimiento utiliza una estructura pmUnits; véase pmLookupDesc(3).

Como ayuda para etiquetar gráficos y tablas, o para mensajes de error, pmUnitsStr tomará una especificación de dimensión y escala según pu, y devolverá la cadena de texto correspondiente. La función pmUnitsStr_r hace lo mismo, pero almacena el resultado en un búfer suministrado por el usuario buf de longitud buflen, que debe tener espacio para al menos 60 bytes. Si buflen es menor que 60, entonces pmUnitsStr_r devuelve NULL y buf no se modifica.

Por ejemplo, {1, -2, 0, PM_SPACE_MBYTE, PM_TIME_SEC, 0}, como el valor de *pu da como resultado la cadena Mbyte / sec^2.

El resultado del valor de cadena de pmUnitsStr se mantiene en un único búfer estático, por lo que el valor devuelto solo es válido hasta la próxima llamada a pmUnitsStr.

Si la dimensión de ``count'' no es cero, y la escala de ``count'' no es cero, entonces la cadena de texto incluirá un factor de escala decimal, por ejemplo, count x 10^6.

Como caso especial, si todos los componentes de la dimensión son cero, entonces se utiliza la escala de ``count'' para producir el texto. Si esta escala es cero, el resultado es una cadena vacía, de lo contrario el resultado tiene el formato x1 0^2.

NOTAS

pmUnitsStr devuelve un puntero a un búfer estático y, por lo tanto, no es seguro para subprocesos. Las aplicaciones multihilo deben usar en su lugar pmUnitsStr_r.
