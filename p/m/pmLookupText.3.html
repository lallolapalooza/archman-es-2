NOMBRE

pmLookupText - devuelve texto que describe una métrica de rendimiento

SINOPSIS

#include <pcp/pmapi.h>

int pmLookupText(pmID pmid, int level, char **buffer);

cc ... -lpcp

DESCRIPCIÓN

Recupera texto descriptivo sobre la métrica de rendimiento identificada por pmid.

El argumento level debe ser PM_TEXT_ONELINE para un resumen de una línea, o PM_TEXT_HELP para una descripción más detallada, adecuada para un diálogo de ayuda.

El espacio apuntado por buffer habrá sido asignado en pmLookupText con malloc(3), y es responsabilidad del llamador liberar (free(3)) el espacio cuando ya no se necesite.

pmLookupText devuelve cero en caso de éxito.

DIAGNÓSTICOS

PM_ERR_NOTHOST
Para archivos creados con versiones de PCP anteriores a la 4.0, si el contexto actual de PMAPI es un archivo (el texto de ayuda y de una línea no se mantenía previamente en los archivos)
