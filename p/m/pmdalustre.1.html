PMDALUSTRE(1) Manual de comandos generales PMDALUSTRE(1)

NOMBRE

pmdalustre - agente de dominio de métricas de rendimiento de estadísticas del sistema de archivos lustre (PMDA)

DESCRIPCIÓN

pmdalustre es un Agente de Dominio de Métricas de Rendimiento (PMDA) que lee y exporta valores métricos de las interfaces de estadísticas de un sistema de archivos Lustre.

pmdalustre busca interfaces de estadísticas desde varias ubicaciones, que varían según la versión de Lustre instalada localmente.

Las versiones recientes de Lustre (v2.12 y posteriores) exportan estadísticas desde el sistema de archivos pseudo debugfs del kernel, en los directorios /sys/kernel/debug/lustre/llite y /sys/kernel/debug/lnet. Si estas interfaces no se encuentran durante el inicio, pmdalustre verificará automáticamente si las interfaces de estadísticas están disponibles desde el sistema de archivos pseudo procfs debajo de los directorios /proc/fs/lustre/llite y /proc/sys/lnet. Estas son las ubicaciones predeterminadas de las estadísticas para las versiones de Lustre anteriores a la v2.12.

Si no se detecta ninguna de las interfaces del sistema de archivos anterior, o si el usuario desea anular las ubicaciones predeterminadas, pmdalustre también admite un archivo de configuración opcional llamado $PCP_PMDAS_DIR/lustre/lustre.conf. Tenga en cuenta que $PCP_PMDAS_DIR se establece en /var/lib/pcp/pmdas en la mayoría de los sistemas basados en Linux. El archivo de configuración admite la sintaxis de asignación de variables de perl(1). Un archivo de configuración de ejemplo adecuado para Lustre v2.12 y posteriores es: 

$LLITE_PATH="/sys/kernel/debug/lustre/llite/";
$LNET_PATH="/sys/kernel/debug/lustre/lnet/";
Consulte los comentarios en el archivo lustre.conf enviado para obtener más detalles. De forma predeterminada, este archivo se instala con todo comentado (y por lo tanto, no tiene ningún efecto a menos que se edite) porque las heurísticas integradas utilizadas por pmdalustre deberían ser suficientes.

Finalmente, anulando todo lo anterior, las variables de entorno LUSTRE_LLITE_PATH y LUSTRE_LNET_PATH pueden establecerse (y exportarse) para especificar las ubicaciones de directorio de las interfaces de estadísticas que se utilizarán. Este mecanismo que utiliza variables de entorno está destinado únicamente a fines de desarrollo y pruebas.

El proceso pmdalustre se ejecuta como usuario root porque los directorios debugfs normalmente no son legibles por usuarios no privilegiados.

INSTALACIÓN

Instale pmdalustre utilizando el script Install como usuario root:

# cd $PCP_PMDAS_DIR/lustre
# ./Install

Si desea deshacer la instalación, haga lo siguiente como root:

# cd $PCP_PMDAS_DIR/lustre
# ./Remove

pmdalustre es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/lustre/Install
script de instalación para el agente pmdalustre
$PCP_PMDAS_DIR/lustre/Remove
script para deshacer la instalación del agente pmdalustre
$PCP_LOG_DIR/pmcd/lustre.log
archivo de registro predeterminado para mensajes de error de pmdalustre
$PCP_PMDAS_DIR/lustre/lustre.conf
Archivo de configuración para anular los directorios de estadísticas predeterminados utilizados por pmdalustre.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
