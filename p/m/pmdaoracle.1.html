PMDAORACLE(1) Manual de Comandos Generales PMDAORACLE(1)

NOMBRE

pmdaoracle - PMDA de base de datos Oracle

DESCRIPCIÓN

pmdaoracle es un PMDA de Performance Co-Pilot que extrae datos de rendimiento en vivo de una base de datos Oracle en ejecución.

INSTALACIÓN

pmdaoracle utiliza un archivo de configuración de (en este orden):

  • /etc/pcpdbi.conf
  • $PCP_PMDAS_DIR/oracle/oracle.conf
  • ./oracle.conf

Este archivo puede contener valores anulados (código Perl) para la configuración que se lista al inicio de pmdaoracle.pl, por ejemplo:

  • $username - nombre de usuario para conectarse a la base de datos [por defecto: 'SYSTEM']
  • $password - contraseña para conectarse a la base de datos [por defecto: 'manager']
  • $host - host en el que se está ejecutando la base de datos [por defecto: 'localhost']
  • $port - puerto en el que está escuchando la base de datos [por defecto: '1521']
  • $os_user - nombre de usuario del sistema operativo (el PMDA se ejecutará con el ID de usuario correspondiente) [por defecto: oracle]
  • @sids - un array de identificadores de base de datos $ORACLE_SID [por defecto: ('master')]

Para probar tu configuración local, se proporciona un script simple que se conectará y desconectará de la base de datos, verificando que la configuración fundamental esté en su lugar antes de continuar. Si el script $PCP_PMDAS_DIR/oracle/connect.pl no puede conectarse, no procedas con la instalación del PMDA, ya que será infructuosa. Corrige tu configuración local primero.

Una vez configurado esto, puedes acceder a los nombres y valores de las métricas de rendimiento de Oracle haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/oracle
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/oracle
# ./Remove

pmdaoracle es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ESTADO DE CONEXIÓN

Por defecto, pmdaoracle intentará agresivamente mantener conexiones persistentes con Oracle para asegurar respuestas oportunas a sus consultas, y se reconectará automáticamente si una conexión se interrumpe.

Sin embargo, en ciertas circunstancias esto puede ser indeseable, por lo que se proporciona un mecanismo manual de pmStore(3) para controlar explícitamente la desconexión y reconexión a una instancia de Oracle. Esto se puede usar, por ejemplo, para asegurar que pmdaoracle no esté conectado al apagar, para asegurar un proceso de apagado limpio de Oracle.

El comando pmstore (1) se puede usar para desconectar y reconectar. Usando las instancias individuales de la métrica oracle.control.connected, se puede establecer el estado de conexión a activo (1) o inactivo (0). Adicionalmente, pminfo(1) puede informar sobre el estado actual de las conexiones de Oracle.

# pminfo ‐f oracle.control.connected
oracle.control.connected
    inst [0 o "master"] value 1
# pmstore oracle.control.connected 0
oracle.control.connected inst [0 o "master"] valor anterior=1 valor nuevo=0

ARCHIVOS

/etc/pcpdbi.conf
archivo de configuración para todos los monitores de base de datos PCP
$PCP_PMDAS_DIR/oracle/oracle.conf
archivo de configuración para pmdaoracle
$PCP_PMDAS_DIR/oracle/sample.conf
archivo de configuración de ejemplo para pmdaoracle usando $LD_LIBRARY_PATH
$PCP_PMDAS_DIR/oracle/connect.pl
script de prueba de configuración para la conectividad de la base de datos Oracle
$PCP_PMDAS_DIR/oracle/Install
script de instalación para el agente pmdaoracle
$PCP_PMDAS_DIR/oracle/Remove
script para deshacer la instalación del agente pmdaoracle
$PCP_LOG_DIR/pmcd/oracle.log
archivo de registro predeterminado para mensajes de error de pmdaoracle

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
