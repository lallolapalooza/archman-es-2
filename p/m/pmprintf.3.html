PMPRINTF(3) Manual de funciones de biblioteca PMPRINTF(3)

NOMBRE

pmprintf, pmflush - imprimir salida formateada en una ventana o en la salida de error estándar

SINOPSIS

#include <pcp/pmapi.h>

int pmprintf(const char *fmt, ... /*args*/);
int pmflush(void);

cc ... -lpcp

DESCRIPCIÓN

La combinación de pmprintf y pmflush produce salida ya sea en una ventana de xconfirm(1), en el flujo de error estándar, o a un archivo de manera similar a fprintf(3). El argumento fmt se utiliza para controlar la conversión, el formato y la impresión de la lista de argumentos variables args. La técnica de salida se controla a través de una variable de entorno.

pmprintf añade la cadena de mensaje formateada a un búfer interno compartido por las dos rutinas, sin producir realmente ninguna salida.

pmflush hace que el búfer interno se muestre en una ventana, se imprima en la salida de error estándar, o se vacíe a un archivo y se limpie el búfer interno.

DIAGNÓSTICOS

En caso de éxito, pmprintf devuelve el número de caracteres transmitidos, mientras que pmflush devuelve un valor de cero en caso de éxito.

Para cualquiera de las rutinas, se devuelve un valor negativo si se encontró un error, y este puede pasarse a pmErrStr(3) para obtener el mensaje de error asociado.

ARCHIVOS

pmprintf utiliza la función mkstemp(3) para crear un archivo temporal. Este archivo temporal se elimina cuando se llama a pmflush.

ENTORNO

La variable de entorno PCP_STDERR controla la técnica de salida utilizada por pmflush:

Si PCP_STDERR no está definida, el texto se escribe en el flujo stderr del llamador.

Si PCP_STDERR está establecida en la palabra reservada literal DISPLAY, el texto se mostrará como un cuadro de diálogo gráfico usando xconfirm(1).

Si PCP_STDERR se establece en cualquier otro valor, entonces pmflush interpreta el valor como un nombre de archivo y añade el texto a ese archivo. El archivo se crea si no existe, y en este caso si la creación del archivo falla, entonces se usa stderr en su lugar).

VER TAMBIÉN

pmdbg(1), fprintf(3), mkstemp(3), pmErrStr(3) y PMAPI(3).
