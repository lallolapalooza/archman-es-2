PMDAGFS2(1) Manual de comandos generales PMDAGFS2(1)

NOMBRE

pmdagfs2 - PMDA de GFS2 (Sistema de archivos global v2)

SINOPSIS

$PCP_PMDAS_DIR/gfs2/pmdagfs2 [-D debug]

DESCRIPCIÓN

pmdagfs2 es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores de métricas sobre sistemas de archivos GFS2 montados desde el sistema de archivos debugfs. Este PMDA requiere debugfs junto con al menos un sistema de archivos GFS2 montado para poder proporcionar datos de métricas.

Este PMDA puede usarse con sistemas de archivos GFS2 que estén montados tanto como sistemas de archivos locales como sistemas de archivos montados como almacenamiento compartido dentro de un entorno de clúster. Sin embargo, hay algunas métricas que requieren específicamente que GFS2 esté configurado en un entorno de clúster para poder proporcionar datos de métricas. Esto se debe a que esperan que los mensajes de bloqueo se pasen a través del gestor de bloqueo distribuido (DLM) entre nodos de un clúster para generar su salida.

Estas métricas exclusivas del entorno de clúster se pueden distinguir por la inclusión de sus métricas de control correspondientes para que puedan habilitarse o deshabilitarse opcionalmente en sistemas donde no se desea supervisarlas o no son compatibles.

pmstore(3) se puede usar para asignar valores a estas métricas de control para habilitarlas (1) o deshabilitarlas (0). Este mecanismo también es útil en distribuciones que actualmente no tienen soporte completo para los puntos de rastreo de GFS2 o que proporcionan versiones antiguas del controlador GFS2.

INSTALACIÓN

Instala el PMDA de GFS2 usando el script de Instalación como root:

# cd $PCP_PMDAS_DIR/gfs2
# ./Install

Para desinstalar, haz lo siguiente como root:

# cd $PCP_PMDAS_DIR/gfs2
# ./Remove

pmdagfs2 es iniciado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd cuando el agente se instala o elimina.

ARCHIVOS

$PCP_PMDAS_DIR/gfs2/help
archivo de texto de ayuda predeterminado para las métricas GFS2
$PCP_PMDAS_DIR/gfs2/Install
script de instalación para el agente pmdagfs2
$PCP_PMDAS_DIR/gfs2/Remove
script de deshacer instalación para el agente pmdagfs2
$PCP_LOG_DIR/pmcd/gfs2.log
archivo de registro predeterminado para mensajes de error de pmdagfs2

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5). [-D debug]

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a solucionar problemas, aunque la información a veces es críptica y está destinada principalmente a guiar a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; usa pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.
