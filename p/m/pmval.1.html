PMVAL(1) Manual de comandos generales PMVAL(1)

NOMBRE

pmval, pmevent - volcado de valor de métrica de rendimiento arbitraria

SINOPSIS

pmval [-dgLrvVXz?] [-a archivo] [-A alineación] [--container=nombre] [-D depuración] [--derived=archivo] [-f N] [-h host] [-i instancias] [-K espec] [-n archivonombres] [-O desfase] [-p puerto] [-s muestras] [-S tiempocomienzo] [-t intervalo] [-T tiempofin] [-U archivo] [-w ancho] [-x patrón] [-Z zona-horaria] nombremetrica

pmevent ...

DESCRIPCIÓN

pmval imprime los valores actuales o archivados para la métrica de rendimiento nominada. La métrica de interés se nombra en el argumento nombremetrica, sujeta a cualificación de instancia con el indicador -i como se describe a continuación.

A menos que se dirija a otro host con la opción -h, o a un conjunto de archivos con las opciones -a o -U, pmval se pondrá en contacto con el Demonio Recolector de Métricas de Rendimiento (PMCD) en el host local para obtener la información requerida.

El argumento nombremetrica también puede darse en la sintaxis de especificación de métrica, como se describe en PCPIntro(1), donde la fuente, la métrica y la instancia pueden incluirse todas en el nombremetrica, por ejemplo, thathost:kernel.all.load["1 minute"]. Cuando se utiliza este formato, ninguna de las opciones -h, -a o -U puede especificarse.

Al usar la sintaxis de especificación de métrica, el «hostname» @ se trata de forma especial y hace que pmval utilice un contexto local para recopilar métricas de los PMDA locales sin PMCD. Solo algunas métricas están disponibles en este modo.

Al procesar un conjunto de archivos, pmval puede ceder su propio control de tiempo y operar bajo el control de un proceso pmtime(1) que utiliza un diálogo gráfico para proporcionar control de tiempo. En este caso, se debe usar la opción -g para iniciar pmval como el único cliente de una nueva instancia de pmtime(1), o se debe usar -p para adjuntar pmval a una instancia existente de pmtime(1) a través del canal IPC identificado por el argumento puerto.

Las opciones -S, -T, -O y -A se pueden usar para definir una ventana de tiempo para restringir las muestras recuperadas, establecer un origen inicial dentro de la ventana de tiempo, o especificar una alineación «natural» de los tiempos de las muestras; consulte PCPIntro(1) para una descripción completa de estas opciones.

La salida de pmval se dirige a la salida estándar. Los siguientes símbolos pueden aparecer ocasionalmente, en lugar de un valor de métrica, en la salida de pmval: Un símbolo de interrogación (?) indica que un valor ya no está disponible para esa instancia de métrica. Un símbolo de exclamación (!) indica que un contador de 64 bits se desbordó durante la muestra.

pmevent es un alias para pmval.

OPCIONES

Las opciones de línea de comandos disponibles son:

-a archivo, --archive=archivo
Los valores de métricas de rendimiento se recuperan del conjunto de archivos de archivo Performance Co-Pilot (PCP) identificados por el argumento archivo, que es una lista separada por comas de nombres, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos. Ver también -U.
-A alineación, --align=alineación
Forzar que la muestra inicial se alinee en el límite de una unidad de tiempo natural alineación. Consulte PCPIntro(1) para una descripción completa de la sintaxis de alineación.
--container=contenedor
Especificar un contenedor individual para ser consultado.
-d, --delay
Al reproducir desde un archivo, esta opción solicita que se aplique la demora en tiempo real predominante entre muestras (ver -t) para efectuar una pausa, en lugar del comportamiento predeterminado de reproducir a toda velocidad.
--derived=archivo
Cargar definiciones de métricas derivadas del archivo.
-f precisión, --precision=precisión
Los números se informan en notación de «punto fijo», en lugar de la notación científica predeterminada, utilizando precisión dígitos para la precisión. Cada número tendrá hasta el ancho de columna determinado por la heurística predeterminada, o la opción -w si se especifica, e incluirá precisión dígitos después del punto decimal. Por lo tanto, las opciones -f 3 -w 8 producirían números del tipo 9999.999. Un valor de cero para precisión omite el punto decimal y cualquier dígito fraccional.
-g, --guimode
Iniciar pmval como el único cliente de un nuevo proceso servidor pmtime(1) para la reproducción de datos de rendimiento archivados utilizando la interfaz gráfica de usuario de pmtime(1).
-h host, --host=host
Obtener métricas de rendimiento de pmcd(1) en host, en lugar de del localhost predeterminado.
-i instancias, --instances=instancias
Especificar una lista de uno o más nombres de instancias para la métrica de rendimiento nominada; solo se recuperarán y reportarán estas instancias (el valor predeterminado es reportar todas las instancias). La lista debe ser un solo argumento, con los elementos de la lista separados por comas y/o espacios en blanco.

El nombre de la instancia puede entrecomillarse con comillas simples (') o dobles (") para aquellos casos en que el nombre de la instancia contenga espacios en blanco o comas.

Se permiten múltiples opciones -i como forma alternativa de especificar más de una instancia de interés.

Como ejemplo, lo siguiente es equivalente:

$ pmval -i "'1 minute','5 minute'" kernel.all.load
$ pmval -i '"1 minute","5 minute"' kernel.all.load
$ pmval -i "'1 minute' '5 minute'" kernel.all.load
$ pmval -i "'1 minute'" -i "'5 minute'" kernel.all.load
$ pmval 'localhost:kernel.all.load["1 minute","5 minute"]'


-K espec, --spec-local=espec
Al obtener métricas de un contexto local (ver -L), la opción -K puede usarse para controlar los PMDA DSO que deben hacerse accesibles. El argumento espec se ajusta a la sintaxis descrita en pmSpecLocalPMDA(3). Se pueden usar múltiples opciones -K.
-L, --local-PMDA
Usar un contexto local para recopilar métricas de PMDA DSO en el host local sin PMCD. Ver también -K.
-n archivonombres, --namespace=archivonombres
Cargar un Espacio de Nombres de Métricas de Rendimiento (PCP) alternativo (PMNS(5)) desde el archivo archivonombres.
-O origen, --origin=origen
Al reportar métricas archivadas, comenzar a reportar en origen dentro de la ventana de tiempo (ver -S y -T). Consulte PCPIntro(1) para una descripción completa de la sintaxis de origen.
-p puerto, --guiport=puerto
Adjuntar pmval a una instancia existente del proceso de control de tiempo pmtime(1) a través del canal IPC identificado por el argumento puerto. Esta opción normalmente solo la usan otras herramientas, por ejemplo, pmchart(1), cuando inician pmval con control de tiempo sincronizado.
-r, --raw
Imprimir valores brutos para métricas de contador acumulativo. Normalmente, las métricas de contador acumulativo se convierten a tasas. Por ejemplo, las transferencias de disco se reportan como número de transferencias de disco por segund

-s muestras, --samples=muestras
El argumento muestras define el número de muestras que se obtendrán y se informarán. Si muestras es 0 o no se especifica -s, pmval tomará muestras e informará continuamente (en modo de tiempo real) o hasta el final del conjunto de archivos PCP (en modo de archivo).
-S tiempodeinicio, --start=tiempodeinicio
Al informar métricas archivadas, el informe se limitará a aquellos registros registrados en o después de tiempodeinicio. Consulte PCPIntro(1) para una descripción completa de la sintaxis de tiempodeinicio.
-t intervalo, --interval=intervalo
Establezca el intervalo de informes a algo diferente del segundo predeterminado. El argumento intervalo sigue la sintaxis descrita en PCPIntro(1), y en su forma más simple puede ser un entero sin signo (las unidades implícitas en este caso son segundos).
-T tiempodefin, --finish=tiempodefin
Al informar métricas archivadas, el informe se limitará a aquellos registros registrados antes o en tiempodefin. Consulte PCPIntro(1) para una descripción completa de la sintaxis de tiempodefin.
-U archivo, --nointerp=archivo
Los valores de métricas de rendimiento se obtienen del archivo archivo de Performance Co-Pilot (PCP). El argumento es una lista separada por comas de nombres, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos. Sin embargo, a diferencia de -a, se informa cada valor registrado en el archivo para la métrica e instancias seleccionadas (por lo tanto, no hay modo de interpolación y se ignora el intervalo de muestra (opción -t). Véase también -a.

Se puede especificar como máximo una de las opciones -a y -U.

-v, --verbose
Habilita el modo detallado.
-V, --version
Muestra el número de versión y sale.
-w ancho, --width=ancho
Establece el ancho de cada columna de salida a ancho columnas. Si no se especifica, las columnas son lo suficientemente anchas como para acomodar el valor más grande del tipo que se está imprimiendo.
-x patron, --filter=patron
El patron dado se envía al agente del dominio de métricas de rendimiento para nombre_metrica solicitada antes de solicitar cualquier valor. Esto sirve para dos propósitos. En primer lugar, proporciona un mecanismo para el filtrado de eventos en el lado del servidor que es personalizable para flujos de eventos individuales. Además, algunos agentes del dominio de métricas de rendimiento también utilizan el mecanismo de almacenamiento de PMCD para proporcionar un modelo de seguridad básico (por ejemplo, para archivos de registro sensibles, solo un host cliente con acceso a pmStore(3) podría acceder al flujo de eventos).

Como el patron puede ser procesado por regcomp(3), debe ser una cadena no vacía. Use . (punto) para un patrón de "coincidir todo".

-X, --timestamp
Al reproducir desde un archivo, esta opción solicita que la marca de tiempo se informe con información de fecha adicional y mayor precisión (microsegundos con un solo -X, nanosegundos con un -X adicional), por ejemplo Sáb 22 may 20:32:20.971633 2021 en lugar del formato predeterminado, por ejemplo 20:32:20.971.
-z, --hostzone
Utiliza la zona horaria local del host que es la fuente de las métricas de rendimiento, según lo identificado por las opciones -h, -a o -U. El valor predeterminado es usar la zona horaria del host local.
-Z zonahoraria, --timezone=zonahoraria
Utiliza zonahoraria para la fecha y hora. Zonahoraria tiene el formato de la variable de entorno TZ como se describe en environ(7).
-?, --help
Muestra el mensaje de uso y sale.

CAVEATS

Por defecto, pmval intenta mostrar valores numéricos no enteros de una manera que no distorsione la precisión inherente (rara vez más de 4 dígitos significativos), y trata de mantener un formato tabular en la salida. Estos objetivos a veces entran en conflicto.

En ausencia de la opción -f (descrita anteriormente), la siguiente tabla describe los formatos utilizados para diferentes rangos de valores numéricos para cualquier métrica que sea de tipo PM_TYPE_FLOAT o PM_TYPE_DOUBLE, o cualquier métrica que tenga la semántica de un contador (para la cual pmval informa el valor convertido de la tasa):

Formato Rango de valores
! No hay valores disponibles
9.999E-99 < 0.1
0.0    0
9.9999 > 0 y <= 0.9999
9.999  > 0.9999 y < 9.999
99.99   > 9.999 y < 99.99
999.9    > 99.99 y < 999.9
9999.     > 999.9 y < 9999
9.999E+99 > 9999

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información a veces es críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales. debug es una lista separada por comas de opciones de depuración; use pmdbg(1) con la opción -l para obtener una lista de las opciones de depuración disponibles y su significado.

Las opciones de depuración específicas para pmval son las siguientes:

Opción Descripción
appl0 posicionamiento inicial de la línea de tiempo cuando se usa -a
