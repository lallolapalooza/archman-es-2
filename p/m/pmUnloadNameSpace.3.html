PMUNLOADNAMESPACE(3) Manual de funciones de biblioteca PMUNLOADNAMESPACE(3)

NOMBRE

pmUnloadNameSpace - descargar un espacio de nombres de métricas de rendimiento local para una aplicación

SINOPSIS

#include <pcp/pmapi.h>

void pmUnloadNameSpace(void);

cc ... -lpcp

DESCRIPCIÓN

Si se ha cargado previamente un espacio de nombres local usando pmLoadNameSpace(3) o pmLoadASCIINameSpace(3), entonces llamar a pmUnloadNameSpace(3) liberará la memoria asociada con el espacio de nombres y forzará a que todas las llamadas posteriores a las rutinas PMNS utilicen el PMNS distribuido. Si se llama a pmUnloadNameSpace(3) antes de llamar a pmLoadNameSpace(3) o pmLoadASCIINameSpace(3), entonces efectivamente no hará nada.

VER TAMBIÉN

PMAPI(3), pmLoadASCIINameSpace(3), pmLoadNameSpace(3) y PMNS(5).
