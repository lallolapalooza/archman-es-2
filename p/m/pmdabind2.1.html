PMDABIND2(1) Manual de Comandos Generales PMDABIND2(1)

NOMBRE

pmdabind2 - Agente de dominio de métricas de rendimiento de BIND (PMDA)

DESCRIPCIÓN

Este PMDA extrae datos de rendimiento de BIND (Berkeley Internet Name Domain). Permite la recopilación de la mayoría de las métricas de estadísticas del servidor Bind versión 9 o posterior, que incluye:

•
estadísticas generales de memoria
•
estadísticas generales por consulta (consultas generales, respuestas truncadas/EDNS, mensajes Update/Notify/AXFR/IXFR)
•
estadísticas generales de errores (rechazados, SERVFAIL, fallos de Update/XFR ...)
•
estadísticas generales por protocolo de transporte, EDNS y por versión del protocolo IP
•
estadísticas del resolvedor (éxitos, errores, tiempos de ida y vuelta en varios rangos)
•
estadísticas detalladas por socket con respecto al protocolo de transporte y la versión de IP, incluidos los errores
•
estadísticas detalladas por descriptor de archivo, incluidos los errores

El PMDA realiza una recopilación por segundo de todo el conjunto de datos (148 métricas en el entorno de prueba) con requisitos modestos (2% de uso de CPU en Intel i7-4700MQ @2.4 GHz, aprox. 30 MB de RAM).

Si se realizan más de 1 solicitud/segundo, se utilizan los valores en memoria caché para que la interfaz de estadísticas del servidor Bind no se sobrecargue.

INSTALACIÓN

Configure BIND para exportar estadísticas XML a través de su interfaz REST. Esto requiere que la configuración de BIND habilite la exportación de estadísticas localmente (al menos).

statistics-channels {
    inet 127.0.0.1 port 8080 allow { 127.0.0.1; };
}
options { zone-statistics yes; }
# ./Install

El nombre de host (localhost), el puerto (8080 arriba) y otra información de configuración deben especificarse tanto en el archivo de configuración de BIND como en el archivo $PCP_PMDAS_DIR/bind2/bind2.conf.

# cd $PCP_PMDAS_DIR/bind2
# [ editar bind2.conf ]
  host=localhost.localdomain:8080

Una vez configurado esto, puede acceder a los nombres y valores de las métricas de rendimiento de bind2 haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/bind2
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/bind2
# ./Remove

pmdabind2 es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/bind2/bind2.conf
archivo de configuración obligatorio que enumera las instancias de bind2 supervisadas
$PCP_PMDAS_DIR/bind2/Install
script de instalación para el agente pmdabind2
$PCP_PMDAS_DIR/bind2/Remove
script de desinstalación para el agente pmdabind2
$PCP_LOG_DIR/pmcd/bind2.log
archivo de registro predeterminado para mensajes de error de pmdabind2

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
