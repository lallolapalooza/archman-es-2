PMLOCK(1) Manual de Comandos Generales PMLOCK(1)

NOMBRE

pmlock - mutex simple basado en archivos

SINOPSIS

$PCP_BINADM_DIR/pmlock [-i ident] [-v] archivo

DESCRIPCIÓN

pmlock intenta adquirir un bloqueo exclusivo creando un archivo de tamaño cero con un modo de 0.

La opción -i cambia el comportamiento para escribir ident en archivo, seguido de una nueva línea, y el modo del archivo es 0444. ident es una cadena arbitraria, pero por convención es el ID del proceso del bloqueador seguido del nombre o identificación del comando o script que bloquea.

El estado de salida es 0 para éxito, 1 para fallo.

Para liberar el bloqueo, elimine archivo con rm(1) o unlink(2).

En caso de fallo, la opción -v produce un mensaje explicativo en stderr.

VER TAMBIÉN

rm(1) y unlink(2).
