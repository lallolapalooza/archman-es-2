NOMBRE

pmaSortInDom - ordenar un dominio de instancia

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

void pmaSortInDom(__pmLogInDom *lidp);

cc ... -lpcp_archive -lpcp

ADVERTENCIA

Esta documentación está destinada al uso interno de los desarrolladores de Performance Co-Pilot (PCP).

Estas interfaces no forman parte de las API de PCP que se garantiza que permanecerán fijas en las diferentes versiones, y es posible que no funcionen o que proporcionen una semántica diferente en algún momento futuro.

DESCRIPCIÓN

El dominio de instancia identificado por lidp se ordena en valor ascendente de identificador de instancia interno. Tanto la matriz lidp->instlist[] como la matriz correspondiente lidp->namelist[] se ordenan.

Dado que los dominios de instancia suelen estar ordenados (en su fuente por un PMDA), se utiliza un ordenamiento de burbuja. Esto significa que si el llamador no está seguro de si el dominio de instancia está ordenado (pero en realidad ya está ordenado), llamar a pmaSortInDom es tan rápido como verificar si el dominio de instancia está ordenado, por lo que en caso de duda, simplemente llame a pmaSortInDom.

DIAGNÓSTICOS Y VALORES DE RETORNO

Ninguno.
