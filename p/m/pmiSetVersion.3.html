PMISETVERSION(3) Manual de funciones de biblioteca PMISETVERSION(3)

NOMBRE

pmiSetVersion - establece la versión del archivo para un archivo LOGIMPORT

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiSetVersion(int valor);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiSetVersion($valor);

SINOPSIS PYTHON

from pcp import pmi

log = pmi.pmiLogImport(ruta).pmiSetVersion(valor)

DESCRIPCIÓN

Como parte de la API de Importación de Registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiSetVersion establece la versión del archivo de salida en el contexto actual a valor.

En ausencia de una llamada a pmiSetVersion, la versión predeterminada actualmente es el formato tradicional v2. En una futura versión principal de PCP, será el formato v3 por defecto.

DIAGNÓSTICOS

pmiSetVersion devuelve cero en caso de éxito, de lo contrario devuelve un valor negativo que puede ser convertido en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiErrStr(3), pmiSetHostname(3), pmiSetTimezone(3) y pmiStart(3).
