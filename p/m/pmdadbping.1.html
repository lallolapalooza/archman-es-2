PMDADBPING(1) Manual de comandos generales PMDADBPING(1)

NOMBRE

pmdadbping - PMDA de tiempo de respuesta y disponibilidad de bases de datos

DESCRIPCIÓN

pmdadbping es un PMDA de medición del tiempo de respuesta de bases de datos.

pmdadbping ejecuta dbprobe(1) y exporta las mediciones de rendimiento que realiza como métricas de PCP.

dbprobe(1) debe configurarse para utilizar el tipo de DBI apropiado para la base de datos local, lo que incluye: el sabor de RDBMS, el usuario/contraseña, el retraso entre las solicitudes de "ping" y la sentencia SQL a utilizar.

INSTALACIÓN

Configure dbprobe(1); utiliza un archivo de configuración de (en este orden):

  • /etc/pcpdbi.conf
  • $PCP_PMDAS_DIR/dbping/dbprobe.conf

Este archivo puede contener valores reemplazados (código Perl) para la configuración enumerada al inicio de dbprobe.pl, a saber:

  • nombre de la base de datos (ver DBI(3) para más detalles)
  • nombre de usuario de la base de datos
  • contraseña de la base de datos
  • sentencia SQL para medir (sondeo)
  • retraso entre sondeos

Una vez que esto esté configurado, puede acceder a los nombres y valores de las métricas de rendimiento de dbping haciendo lo siguiente como root:

# cd $PCP_PMDAS_DIR/dbping
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/dbping
# ./Remove

pmdadbping es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente se instala o se elimina.

ARCHIVOS

$PCP_PMDAS_DIR/dbping/dbprobe.conf
archivo de configuración del sondeo para dbprobe(1), utilizado indirectamente por pmdadbping
$PCP_PMDAS_DIR/dbping/Install
script de instalación para el agente pmdadbping
$PCP_PMDAS_DIR/dbping/Remove
script para deshacer la instalación del agente pmdadbping
$PCP_LOG_DIR/pmcd/dbping.log
archivo de registro predeterminado para mensajes de error de pmdadbping

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1), dbprobe(1) y DBI(3).
