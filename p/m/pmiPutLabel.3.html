PMIPUTLABEL(3) Manual de Funciones de Biblioteca PMIPUTLABEL(3)

NOMBRE

pmiPutLabel - agregar etiquetas a un archivo de salida

SINOPSIS C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutLabel(unsigned int type,
unsigned int id, unsigned int instance, const char *name, const char *value);

cc ... -lpcp_import -lpcp

SINOPSIS PERL

use PCP::LogImport;

pmiPutLabel($type,
$id, $instance, $name, $value);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co-Pilot (ver LOGIMPORT(3)), pmiPutLabel agrega una etiqueta para el contexto global o para un dominio, clúster, elemento, dominio de instancia o instancia dada.

El type debe ser uno de PM_LABEL_CONTEXT, PM_LABEL_DOMAIN, PM_LABEL_CLUSTER, PM_LABEL_ITEM, PM_LABEL_INDOM, o PM_LABEL_INSTANCES.

Si type es PM_LABEL_CONTEXT, entonces id e instance se ignoran. De lo contrario, id debe coincidir con un dominio, clúster, métrica o dominio de instancia definido previamente en una llamada a pmiAddMetric(3).

Si type es PM_LABEL_INSTANCES, entonces instance debe coincidir con un número de instancia del dominio seleccionado. De lo contrario instance se ignora.

name es una cadena que contiene el nombre de la etiqueta a agregar.

value es una cadena que contiene el valor de la etiqueta a agregar.

No se escribirán datos hasta que se llame a pmiWrite(3), por lo que generalmente se usan múltiples llamadas a pmiPutLabel para acumular varias etiquetas antes de llamar a pmiWrite(3).

DIAGNÓSTICOS

pmiPutLabel devuelve cero si tiene éxito, de lo contrario, un valor negativo que se puede convertir en un mensaje de error llamando a pmiErrStr(3).

VER TAMBIÉN

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutResult(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3) y pmiWrite(3).
