PMDANGINX(1) Manual de comandos generales PMDANGINX(1)

NOMBRE

pmdanginx - agente de dominio de métricas de rendimiento de nginx (PMDA)

DESCRIPCIÓN

pmdanginx es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta métricas de rendimiento desde nginx(8), un servidor HTTP y proxy inverso, un servidor proxy de correo y un servidor proxy TCP genérico.

INSTALACIÓN

Este PMDA requiere que el módulo stub_status de nginx esté activo y disponible en http://localhost/nginx_status.

Para habilitar este módulo, la sección "server" del archivo de configuración nginx.conf debería contener lo siguiente.


location /nginx_status {
    stub_status on;
    access_log off;
    allow 127.0.0.1;
    allow ::1;
    deny all;
}

La disponibilidad de instrumentación se puede verificar usando estos comandos (verificación en tiempo de compilación y luego en tiempo de ejecución):

# nginx -V 2>&1 | grep -o with-http_stub_status_module
# curl http://localhost/nginx_status

Instale el PMDA de nginx usando el script Install como root:

# cd $PCP_PMDAS_DIR/nginx
# ./Install

Para desinstalar, se debe hacer lo siguiente como root:

# cd $PCP_PMDAS_DIR/nginx
# ./Remove

pmdanginx es lanzado por pmcd(1) y nunca debe ser ejecutado directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMDAS_DIR/nginx/nginx.conf
archivo de configuración opcional para pmdanginx
$PCP_PMDAS_DIR/nginx/Install
script de instalación para el agente pmdanginx
$PCP_PMDAS_DIR/nginx/Remove
script para deshacer la instalación del agente pmdanginx
$PCP_LOG_DIR/pmcd/nginx.log
archivo de registro predeterminado para mensajes de error de pmdanginx

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pmcd(1) y nginx(8).
