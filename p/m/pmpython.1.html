PMPYTHON(1) Manual de Comandos Generales PMPYTHON(1)

NOMBRE

pmpython - ejecutar un script de python usando una variante de python preferida

SINOPSIS

pmpython [argumentos-de-python-y-script]

DESCRIPCIÓN

pmpython proporciona una forma de ejecutar scripts de python utilizando un intérprete de python personalizable, en lugar de incrustar el nombre de una versión particular de python en cada script.

Esto puede ser útil ya que permite que el código de python independiente de la versión se ejecute en cualquier lugar. Todos los módulos de python distribuidos con PCP admiten las versiones 2.6 y posteriores (en la serie de versiones 2 de python), y 3.3 y posteriores (en la serie de versiones 3 de python).

Debido a que los scripts de monitoreo y recolección de python son relativamente simples en PCP (no requieren módulos nuevos, características de lenguaje, etc.), ha sido posible garantizar que funcionen para todas las versiones de python mencionadas anteriormente.

Sin embargo, el nombre del intérprete de python no siempre es el mismo, por lo tanto, es común que los scripts de python de PCP utilicen una línea “shebang” que lanza el intérprete python indirectamente de la siguiente manera:


#!/usr/bin/env pmpython

env(1) se utiliza para encontrar la ruta correcta para el ejecutable pmpython desde el $PATH del usuario.

Por defecto, el nombre del intérprete de python se obtiene del valor de $PCP_PYTHON_PROG del entorno (si está configurado) o de /etc/pcp.conf. Este último es el caso más típico donde este valor se basa en algunas heurísticas sobre la plataforma en el momento de compilar los paquetes de PCP y favorece el uso de python3 en todas las versiones recientes de PCP (para las plataformas que lo admiten).

Esto permite utilizar un nombre apropiado para el intérprete de python en lugar de un nombre de versión de python codificado, al tiempo que permite al usuario anular el intérprete de python de la siguiente manera:


$ PCP_PYTHON_PROG=python3 pmpython --version
Python 3.4.2
$ PCP_PYTHON_PROG=python2 pmpython --version
Python 2.7.9

Esto es conveniente para distribuir scripts idénticos en múltiples plataformas, y para probar diferentes versiones de python con el mismo script (por ejemplo, en el caso donde se instalan múltiples versiones de python, PCP_PYTHON_PROG se puede establecer en el entorno local para anular la configuración global).

pmpython es un reemplazo para una herramienta anterior con una función similar, a saber, pcp-python(1).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

env(1), pcp(1), pcp-python(1) y PCPIntro(1).
