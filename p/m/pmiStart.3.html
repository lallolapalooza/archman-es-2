PMISTART(3) Manual de funciones de la biblioteca PMISTART(3)

NOMBRE

pmiStart - establecer un nuevo contexto LOGIMPORT

C SINOPSIS

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiStart(const char *archive, int inherit);

cc ... -lpcp_import -lpcp

Perl SINOPSIS

use PCP::LogImport;

pmiStart($archive, $inherit);

DESCRIPCIÓN

Como parte de la API de importación de registros de Performance Co- Pilot (ver LOGIMPORT(3)), pmiStart crea un nuevo contexto. Cada contexto mantiene el siguiente estado y metadatos:

  • El nombre base (archive) para los archivos físicos que constituyen el archivo PCP de salida.
  • El nombre de host de origen para los datos que se escribirán en el archivo PCP. Por defecto es el nombre de host de la máquina local, pero puede establecerse usando pmiSetHostname(3).
  • La zona horaria de origen para el archivo PCP. Por defecto es la zona horaria de la máquina local, pero puede establecerse usando pmiSetTimezone(3).
  • El número de versión del archivo de salida para el archivo PCP. Por defecto es el formato tradicional de versión 2, pero puede establecerse usando pmiSetVersion(3).
  • Métricas y dominios de instancias, según lo definido por pmiAddMetric(3).
  • Instancias para cada dominio de instancia, según lo definido por pmiAddInstance(3).
  • Identificadores según lo definido por pmiGetHandle(3). Cada identificador es un par métrica-instancia, y cada par métrica-instancia puede tener un valor asociado en cada registro escrito en el archivo PCP de salida.
  • Un conjunto opcional de valores de datos para uno o más pares métrica-instancia (listos para que el siguiente registro se escriba en el archivo PCP de salida) según lo definido por llamadas a pmiPutValue(3) o pmiPutValueHandle(3).

Si inherit es verdadero, el nuevo contexto heredará cualquier metadato (métricas, dominios de instancias, instancias e identificadores) del contexto actual; de lo contrario, el nuevo contexto se crea sin metadatos. El nombre base para el archivo PCP de salida, el nombre de host de origen, la zona horaria de origen y cualquier valor de datos del contexto actual **no** se heredan. Si esta es la primera llamada a pmiStart, los metadatos estarán vacíos independientemente del valor de inherit.

Dado que no se crearán archivos físicos para el archivo PCP de salida hasta la primera llamada a pmiWrite(3) o pmiPutResult(3), archive podría ser NULL para crear un contexto de conveniencia que se poblará con metadatos que serán heredados por contextos posteriores.

El valor de retorno es un identificador de contexto que podría usarse en una llamada posterior a pmUseContext(3), y el nuevo contexto se convierte en el contexto actual que persiste para todas las llamadas posteriores hasta otra llamada a pmiStart o una llamada a pmUseContext(3) o una llamada a pmiEnd(3).

DIAGNÓSTICOS

Es un error si los archivos físicos archive.0 y/o archive.index y/o archive.meta ya existen, pero esto no se descubre hasta el primer intento de generar datos llamando a pmiWrite(3) o pmiPutResult(3), por lo que pmiStart siempre devuelve un identificador de contexto positivo.
