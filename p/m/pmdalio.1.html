PMDALIO(1) Manual de Comandos Generales PMDALIO(1)

NOMBRE

pmdalio - PMDA del subsistema LIO de Linux

DESCRIPCIÓN

pmdalio es un Agente de Dominio de Métricas de Rendimiento (PMDA) que exporta valores métricos sobre el subsistema de destino de E/S (I/O) de Linux, que proporciona protocolos como iSCSI, FCP, FCoE. Estos permiten que el almacenamiento disponible en un host se exporte y sea consumido por otros hosts utilizando protocolos estándar de la industria.

Este PMDA exporta métricas de resumen que son agregaciones de valores de rendimiento y configuración por instancia de destino LIO. Adicionalmente, proporciona métricas de rendimiento por LUN que incluyen IOPS y rendimiento de LECTURA y ESCRITURA.

La configuración de LIO se mantiene dentro del sistema de archivos virtual configfs del kernel. El módulo python-rtslib proporciona una interfaz a configfs, permitiendo a herramientas como pmdalio interactuar con la configuración y metadatos contenidos en configfs.

INSTALACIÓN

Instala el PMDA de LIO usando el script Install como root:

# cd $PCP_PMDAS_DIR/lio
# ./Install

Para desinstalar, haz lo siguiente como root:

# cd $PCP_PMDAS_DIR/lio
# ./Remove

pmdalio es lanzado por pmcd(1) y nunca debe ejecutarse directamente. Los scripts Install y Remove notifican a pmcd(1) cuando el agente es instalado o removido.

ARCHIVOS

$PCP_PMDAS_DIR/lio/Install
script de instalación para el agente pmdalio
$PCP_PMDAS_DIR/lio/Remove
script para deshacer la instalación del agente pmdalio
$PCP_LOG_DIR/pmcd/lio.log
archivo de registro predeterminado para mensajes de error de pmdalio

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
