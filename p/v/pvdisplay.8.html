DESCRIPCIÓN

pvdisplay muestra los atributos de los PV, como el tamaño, el tamaño del extento físico, el espacio utilizado para el área del descriptor del VG, etc.

pvs(8) es una alternativa preferida que muestra la misma información y más, utilizando un formato de salida más compacto y configurable.

USO

pvdisplay

[ -m|--maps ]
[ -s|--short ]
[ OPCIONES_COMUNES ]
[ PV|Etiqueta ... ]

OPCIONES

--aligned
Usar con --separator para alinear las columnas de salida.
-a|--all
Mostrar información sobre dispositivos que no han sido inicializados por LVM, es decir, no son PVs.
--binary
Usar valores binarios "0" o "1" en lugar de valores literales descriptivos para columnas que tienen exactamente dos valores válidos que informar (sin contar el valor "desconocido" que denota que el valor no pudo ser determinado).
-c|--colon
Generar salida separada por dos puntos para facilitar el análisis en scripts o programas. Véase también pvs(8), que proporciona un control considerablemente mayor sobre la salida. Los valores son:
  • Nombre del dispositivo del volumen físico
  • Nombre del grupo de volúmenes
  • Tamaño del volumen físico en sectores
  • Número interno del volumen físico (obsoleto)
  • Estado del volumen físico
  • Volumen físico (no) asignable
  • Número actual de volúmenes lógicos en este volumen físico
  • Tamaño del extento físico en kilobytes
  • Número total de extentos físicos
  • Número de extentos físicos libres
  • Número de extentos físicos asignados
-C|--columns
Mostrar salida en columnas. El equivalente de pvs(8). Las opciones listadas son las mismas que las opciones dadas en pvs(8).
--commandprofile Cadena
El perfil de comando a usar para la configuración del comando. Véase lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuración para el comando. Estas anulan la configuración de lvm.conf(5). La cadena de argumentos usa el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Véase lvm.conf(5) para más información sobre la configuración.
--configreport log|vg|lv|pv|pvseg|seg
Véase lvmreport(7).
-d|--debug ...
Establecer el nivel de depuración. Repetir de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados serán a

Opciones

--devices String
Una lista separada por comas de dispositivos que LVM debe usar. Los dispositivos especificados aquí anulan los que se encuentran en el archivo de configuración de LVM o los que parecen faltar. Esta opción puede repetirse o aceptar una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile String
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar el mapeador de dispositivos. Para pruebas y depuración.
--foreign
Informar/mostrar VGs (Volumenes Grupales) externas que de otro modo se omitirían. Consulte lvmsystemid(7) para obtener más información sobre VGs externas.
--headings none|abbrev|full|0|1|2
Tipo de encabezados a usar en la salida del informe. none o 0: Sin encabezados. abbrev o 1: Abreviaturas de nombres de columna. full o 2: Nombres de columna completos.
-h|--help
Mostrar texto de ayuda.
--ignorelockingfailure
Permite que un comando continúe con operaciones de metadatos de solo lectura después de fallos de bloqueo.
--journal String
Registrar información en el journal de systemd. Esta información se suma a la información habilitada por la configuración de log/journal de lvm.conf. command: registrar información sobre el comando. output: registrar la salida predeterminada del comando. debug: registrar depuración completa del comando.
--lockopt String
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--logonly
Suprimir la salida del informe del comando y mostrar solo el informe de log.
--longhelp
Mostrar texto de ayuda extendido.
-m|--maps
Mostrar el mapeo de extents físicos a LVs y extents lógicos.
--nameprefixes
Agrega un prefijo "LVM2_" seguido del nombre del campo a la salida. Útil con --noheadings para producir una lista de pares campo=valor que pueden usarse para establecer variables de entorno (por ejemplo, en reglas de udev).
--noheadings
Suprimir la línea de encabezados que normalmente es la primera línea de la salida. Útil si se busca en la salida (grep).
--nohints
No usar el archivo de pistas para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se usan pistas. El comando aún realizará la invalidación estándar del archivo de pistas cuando sea apropiado.
--nolocking
Deshabilitar el bloqueo. Úselo con precaución, los comandos concurrentes pueden producir resultados incorrectos.
--nosuffix
Suprimir el sufijo en los tamaños de salida. Úselo con --units (excepto h y H) si procesa la salida.
-o|--options String
Lista de campos separados por comas y ordenados para mostrar en columnas. La sintaxis del argumento String es: [+|-|#]Campo1[,Campo2...] El prefijo + agregará los campos especificados a los campos predeterminados, - eliminará los campos especificados de los campos predeterminados y # compactará los campos especificados (eliminándolos cuando estén vacíos para todas las filas). Use -o help para ver la lista de todos los campos disponibles. Use listas separadas de campos para agregar, eliminar o compactar repitiendo la opción -o: -o+campo1,campo2 -o-campo3,campo4 -o#campo5. Estas listas se evalúan de izquierda a derecha. Use el nombre del campo lv_all para ver todos los campos de LV, vg_all todos los campos de VG, pv_all todos los campos de PV, seg_all todos los campos de segmento de LV y pvseg_all todos los campos de segmento de PV. Consulte la sección de informes de lvm.conf(5) para obtener más opciones de configuración. Consulte lvmreport(7) para obtener más información sobre informes.
--profile String
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprimir la salida y los mensajes de log. Anula --debug y --verbose. Repita una vez para suprimir también cualquier solicitud con la respuesta 'no'.
--readonly
Evita que el comando realice cambios, incluida la activación y las actualizaciones de metadatos. (Ver --permission r para LVs de solo lectura).
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se prefija con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que cumple más con el estándar JSON. Consulte lvmreport(7) para obtener más información.
--rows
Columnas de salida como filas.
--segments
-S|--select String
Selecciona objetos para procesamiento e informes basándose en criterios especificados. La sintaxis de los criterios se describe en --select help y lvmreport(7). Para los comandos de informes, se muestra una fila por cada objeto que cumpla los criterios. Consulte --options help para ver los campos de objetos seleccionables. Las filas se pueden mostrar con un campo adicional "selected" (-o selected) que muestra 1 si la fila cumple la selección y 0 en caso contrario. Para los comandos que no son de informes y que procesan entidades de LVM, la selección se utiliza para elegir los elementos a procesar.
--separator String
Cadena a utilizar para separar cada columna. Útil si se busca en la salida.
--shared
Informar/mostrar VGs compartidas que de otro modo se omitirían cuando lvmlockd no se está utilizando en el host. Consulte lvmlockd(8) para obtener más información sobre VGs compartidas.
-s|--short
Mostrar solo el tamaño de los PVs dados.
-O|--sort String
Lista ordenada de columnas separadas por comas para ordenar. Reemplaza la selección predeterminada. Anteponer un signo - a cualquier columna para ordenar en orden inverso en esa columna.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán los metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de varias etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
--unbuffered
Producir salida inmediatamente sin ordenar ni alinear las columnas correctamente.
--units [Número]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Todos los tamaños se muestran en estas unidades: legibles por humanos (r) con indicador de redondeo '<', legibles por (h)umanos, (b)ytes, (s)ectores, (k)ilobytes, (m)egabytes, (g)igabytes, (t)erabytes, (p)etabytes, (e)xabytes. Ponga en mayúscula para usar múltiplos de 1000 (S.I.) en lugar de 1024. Se pueden especificar unidades personalizadas, por ejemplo, --units 3M.
--unquoted
Cuando se usa con --nameprefixes, los valores de salida en los pares campo=valor no se citarán.
-v|--verbose ...
Establecer el nivel de detalle. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Mostrar información de la versión.
-y|--yes
No preguntar por confirmación interactivamente, sino asumir siempre la respuesta sí. Úselo con extrema precaución. (Para un "no" automático, consulte -qq).

VARIABLES

PV
Nombre del Volumen Físico, una ruta de dispositivo bajo /dev. Para comandos que gestionan extents físicos, un argumento posicional PV generalmente acepta un sufijo que indica un rango (o múltiples rangos) de extents físicos (PEs). Cuando se omite el primer PE, se toma por defecto el inicio del dispositivo, y cuando se omite el último PE, se toma por defecto el final.
Rango de inicio y fin (inclusive): PV[:PE-PE] ...
Rango de inicio y longitud (contando desde 0): PV[:PE+PE] ...
Tag
Nombre de etiqueta. Consulte lvm(8) para obtener información sobre nombres de etiquetas y el uso de etiquetas en lugar de un VG, LV o PV.
String
Consulte la descripción de la opción para obtener información sobre el contenido de la cadena.
Size[UNIT]
El tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIT. UNIT representa otras unidades de entrada posibles: b|B es bytes, s|S es sectores de 512 bytes, k|K es KiB, m|M es MiB,

NAME

pvdisplay — Display information about physical volumes

SYNOPSIS

pvdisplay [-a|--all] [-c|--colon] [--devices devices] [--select arg] [--separator separator] [-v|--verbose] [--version] [PhysicalVolume[s]]

DESCRIPTION

pvdisplay is used to display information about one or more physical volumes (PVs).

If PhysicalVolume[s] are specified, only the information about these PVs is displayed.

Otherwise, information about all PVs in the system is displayed.

OPTIONS

--all
Display information about all physical volumes including unusable PVs (e.g. PVs that are not associated with any Volume Group).
-c, --colon
Create colon-separated output. This is useful for easy parsing by other programs. The first line is the header. See also --separator.
--devices devices
Comma-separated list of devices. If this list is given, pvdisplay will scan only devices in this list. If this list is empty, pvdisplay will scan all devices in /proc/devices.

This option is useful for systems with a very large number of devices.

--select arg
Select physical volumes matching the given arg argument based on attributes.

See lvm(8) for more information about the attribute selection.

--separator separator
String used to separate the fields in colon-separated output. Default is ":". Use "" for no separator.
-v, --verbose
Verbose mode.
--version
Display this program's version and exit.

VARIABLES

The following environment variables are also honored by this command:

  • LVM_VG_NAME
    If set, PVs belonging to this VG will be displayed.

See also lvm(8) for more information about environment variables.

The following units are used for sizes:

g
GiB, t is TiB, p is PiB, e is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
