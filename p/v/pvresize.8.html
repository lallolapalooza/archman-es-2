NOMBRE

pvresize — Cambiar el tamaño de volúmenes físicos

SINOPSIS

pvresize args_posicionales
args_opcionales

DESCRIPCIÓN

pvresize cambia el tamaño de un PV (Physical Volume). El PV ya puede estar en un VG (Volume Group) y puede tener LVs (Logical Volumes) activos asignados en él.

USO

pvresize PV ...

[ -A|--autobackup y|n ]
[ --reportformat basic|json|json_std ]
[ --setphysicalvolumesize Tamaño[unidad] ]

OPCIONES

-A|--autobackup y|n
Especifica si se deben hacer copias de seguridad de metadatos automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Ver vgcfgbackup(8) para más información.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Ver lvm.conf(5) para más información sobre perfiles.
--config Cadena
Configuraciones para el comando. Estas anulan los ajustes de lvm.conf(5). La cadena de argumento utiliza el mismo formato que lvm.conf(5), o puede utilizar sintaxis de sección/campo. Ver lvm.conf(5) para más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repita de 1 a 6 veces para aumentar el detalle de los mensajes enviados al archivo de registro y/o syslog (si está configurado).
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán faltar. Esta opción se puede repetir, o acepta una lista de dispositivos separados por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que lista los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se gestiona con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el journal de systemd. Esta información se añade a la información habilitada por la configuración log/journal de lvm.conf. command: registra información sobre el comando. output: registra la salida predeterminada del comando. debug: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Ver lvmlockd(8) para más información.
--longhelp
Muestra el texto de ayuda largo.
--nohints
No utiliza el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan sugerencias. El comando seguirá realizando la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Usar con precaución, comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para también suprimir cualquier aviso respondiendo 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para los informes, que se define globalmente por la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe se precede con el nombre del informe para su identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más compatible con el estándar JSON. Ver lvmreport(7) para más información.
--setphysicalvolumesize Tamaño[unidad]
Anula el tamaño detectado automáticamente del PV. Usar con cuidado, o antes de reducir el tamaño físico del dispositivo.
-t|--test
Ejecutar en modo de prueba. Los comandos no actualizarán metadatos. Esto se implementa deshabilitando toda escritura de metadatos pero devolviendo éxito a la función que llama. Esto puede llevar a mensajes de error inusuales en operaciones de múltiples etapas si una herramienta depende de leer metadatos que cree que han cambiado pero no lo han hecho.
-v|--verbose ...
Establece el nivel de verbosidad. Repita de 1 a 4 veces para aumentar el detalle de los mensajes enviados a stdout y stderr.
--version
Muestra la información de la versión.
-y|--yes
No solicitar confirmación de forma interactiva, sino asumir siempre la respuesta sí. Usar con extrema precaución. (Para un no automático, ver -qq.)

VARIABLES

PV
Nombre del Volumen Físico, una ruta de dispositivo bajo /dev. Para comandos que gestionan extents físicos, un argumento posicional PV generalmente acepta un sufijo que indica un rango (o múltiples rangos) de extents físicos (PEs). Cuando el primer PE se omite, se usa por defecto el inicio del dispositivo, y cuando el último PE se omite, se usa por defecto el final.
Rango de inicio y fin (inclusivo): PV[:PE-PE] ...
Rango de inicio y longitud (contando desde 0): PV[:PE+PE] ...
Cadena
Ver la descripción de la opción para obtener información sobre el contenido de la cadena.
Tamaño[unidad]
Tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren ambos a 1024. La unidad de entrada predeterminada se especifica por letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B es bytes, s|S es sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. VARIABLES

--setphysicalvolumesize Size
Sets the size of the Physical Volume device to Size. The size is specified in bytes or with a suffix like K, M, G, T, P, E, Z, Y (or their multiples).

VARIABLES DE ENTORNO

Consulte lvm(8) para obtener información sobre las variables de entorno utilizadas por lvm. Por ejemplo, LVM_VG_NAME puede sustituir generalmente a un parámetro de VG requerido.

NOTAS

pvresize se negará a reducir un PV si tiene extensiones asignadas más allá del nuevo final.

EJEMPLOS

Expandir un PV después de agrandar la partición.
pvresize /dev/sda1

Reducir un PV antes de reducir la partición (asegúrese de que el tamaño del PV sea apropiado para el nuevo tamaño de partición previsto).
pvresize --setphysicalvolumesize 40G /dev/sda1
