NOMBRE

pvremove — Elimina etiquetas de volumen físico (PV) de LVM.

SINOPSIS

pvremove argumentos_posicionales
[ argumentos_opcionales ]

DESCRIPCIÓN

pvremove borra la etiqueta de un dispositivo para que LVM ya no lo reconozca como un PV.

Un PV no puede ser eliminado de un VG mientras está siendo usado por un LV activo.

Repita la opción de forzar (-ff) para eliminar forzadamente un PV que pertenece a un VG existente. Normalmente, se debe usar vgreduce(8) en su lugar.

USO

pvremove PV ...

[ -f|--force ... ]
[ --reportformat basic|json|json_std ]

VARIABLES

PV
Nombre del Volumen Físico, una ruta de dispositivo bajo /dev. Para comandos que gestionan extensiones físicas, un argumento posicional PV generalmente acepta un sufijo que indica un rango (o múltiples rangos) de extensiones físicas (PEs). Cuando se omite la primera PE, por defecto es el inicio del dispositivo, y cuando se omite la última PE, por defecto es el final.
Rango de inicio y fin (inclusivo): PV[:PE-PE] ...
Rango de inicio y longitud (contando desde 0): PV[:PE+PE] ...
Cadena
Ver la descripción de la opción para información sobre el contenido de la cadena.
Tamaño[UNIDAD]
Tamaño es un número de entrada que acepta una unidad opcional. Las unidades de entrada siempre se tratan como valores de base dos, independientemente de la capitalización, por ejemplo, 'k' y 'K' se refieren a 1024. La unidad de entrada predeterminada se especifica con una letra, seguida de |UNIDAD. UNIDAD representa otras unidades de entrada posibles: b|B es bytes, s|S son sectores de 512 bytes, k|K es KiB, m|M es MiB, g|G es GiB, t|T es TiB, p|P es PiB, e|E es EiB. (Esto no debe confundirse con el control de salida --units, donde las letras mayúsculas significan múltiplos de 1000.)

pvremove(8)

NOMBRE

pvremove

SINOPSIS

pvremove [opciones] [dispositivo...

DESCRIPCIÓN

El comando pvremove elimina un dispositivo físico (PV) de un grupo de volúmenes (VG) LVM.

Si el PV está actualmente en uso por un VG LVM, pvremove primero moverá los datos a otro PV en el VG si es posible.

USO

Por ejemplo, para eliminar el dispositivo físico /dev/sdb1:

pvremove /dev/sdb1

También puedes eliminar múltiples PVs a la vez:

pvremove /dev/sdc1 /dev/sdc2

OPCIONES

Las opciones generales de LVM (como -v para verboso, -d para depurar, etc.) también están disponibles. Consulta lvm(8) para más información.

No hay opciones específicas para pvremove.

VARIABLES

Las variables de entorno utilizadas por LVM están descritas en lvm(8). Por ejemplo, LVM_VG_NAME puede ser generalmente sustituido por un parámetro VG requerido.
