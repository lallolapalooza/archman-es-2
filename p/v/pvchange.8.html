PVCHANGE(8) Manual del Administrador del Sistema PVCHANGE(8)

NOMBRE

pvchange — Cambiar atributos de volumen(es) físico(s)

SINOPSIS

pvchange argumentos_opciones argumentos_posicionales
[ argumentos_opciones ]

DESCRIPCIÓN

pvchange cambia los atributos de PV en el VG.

Para las opciones listadas entre paréntesis, se requiere cualquiera de ellas, después de lo cual las demás son opcionales.

USO

Cambiar propiedades de todos los PV.

pvchange -a|--all

( -u|--uuid
-x|--allocatable y|n
--addtag Etiqueta
--deltag Etiqueta
--metadataignore y|n )
[ OPCIONES_COMUNES ]

—

Cambiar propiedades de PV especificados.

pvchange

( -u|--uuid
-x|--allocatable y|n
--addtag Etiqueta
--deltag Etiqueta
--metadataignore y|n )
PV|Seleccionar ...
[ -S|--select Cadena ]
[ OPCIONES_COMUNES ]

—

Opciones comunes para el comando:

[ -A|--autobackup y|n ]
[ -f|--force ... ]
[ --reportformat basic|json|json_std ]

Opciones comunes para lvm:

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile Cadena ]
[ --config Cadena ]
[ --devices PV ]
[ --devicesfile Cadena ]
[ --driverloaded y|n ]
[ --journal Cadena ]
[ --lockopt Cadena ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile Cadena ]
[ --version ]

OPCIONES

--addtag Etiqueta
Añade una etiqueta a un PV, VG o LV. Esta opción se puede repetir para añadir múltiples etiquetas a la vez. Consulte lvm(8) para obtener información sobre las etiquetas.
-a|--all
Cambia todos los PV visibles.
-x|--allocatable y|n
Habilita o deshabilita la asignación de extents físicos en este PV.
-A|--autobackup y|n
Especifica si las metadatos deben ser respaldadas automáticamente después de un cambio. ¡Se recomienda encarecidamente habilitar esto! Consulte vgcfgbackup(8) para obtener más información.
--commandprofile Cadena
El perfil de comando a utilizar para la configuración del comando. Consulte lvm.conf(5) para obtener más información sobre perfiles.
--config Cadena
Configuración del comando. Estas anulan los ajustes de lvm.conf(5). La cadena de argumento utiliza el mismo formato que lvm.conf(5), o puede usar la sintaxis de sección/campo. Consulte lvm.conf(5) para obtener más información sobre la configuración.
-d|--debug ...
Establece el nivel de depuración. Repetir de 1 a 6 veces para aumentar el nivel de detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--deltag Etiqueta
Elimina una etiqueta de un PV, VG o LV. Esta opción se puede repetir para eliminar múltiples etiquetas a la vez. Consulte lvm(8) para obtener información sobre las etiquetas.
--devices PV
Restringe los dispositivos que son visibles y accesibles para el comando. Los dispositivos no listados parecerán estar ausentes. Esta opción se puede repetir, o acepta una lista de dispositivos separada por comas. Esto anula el archivo de dispositivos.
--devicesfile Cadena
Un archivo que enumera los dispositivos que LVM debe usar. El archivo debe existir en /etc/lvm/devices/ y se administra con el comando lvmdevices(8). Esto anula la configuración devices/devicesfile y devices/use_devicesfile de lvm.conf(5).
--driverloaded y|n
Si se establece en no, el comando no intentará usar device-mapper. Para pruebas y depuración.
-f|--force ...
Anula varias comprobaciones, confirmaciones y protecciones. Usar con extrema precaución.
-h|--help
Muestra el texto de ayuda.
--journal Cadena
Registra información en el diario del sistema. Esta información se suma a la información habilitada por la configuración de registro/diario de lvm. comando: registra información sobre el comando. salida: registra la salida predeterminada del comando. depuración: registra la depuración completa del comando.
--lockopt Cadena
Se utiliza para pasar opciones para casos especiales a lvmlockd. Consulte lvmlockd(8) para obtener más información.
--longhelp
Muestra el texto de ayuda largo.
--metadataignore y|n
Especifica la propiedad metadataignore de un PV. Si es sí, las áreas de metadatos en el PV se ignoran, y lvm no almacenará metadatos en las áreas de metadatos del PV. Si es no, lvm almacenará metadatos en el PV.
--nohints
No utilizar el archivo de sugerencias para localizar dispositivos para PVs. Un comando puede leer más dispositivos para encontrar PVs cuando no se utilizan las sugerencias. El comando aún realizará la invalidación estándar del archivo de sugerencias cuando sea apropiado.
--nolocking
Deshabilita el bloqueo. Usar con precaución, comandos concurrentes pueden producir resultados incorrectos.
--profile Cadena
Un alias para --commandprofile o --metadataprofile, dependiendo del comando.
-q|--quiet ...
Suprime la salida y los mensajes de registro. Anula --debug y --verbose. Repetir una vez para suprimir también cualquier solicitud con respuesta 'no'.
--reportformat basic|json|json_std
Anula el formato de salida actual para informes que se define globalmente mediante la configuración report/output_format en lvm.conf(5). basic es el formato original con columnas y filas. Si hay más de un informe por comando, cada informe va precedido del nombre del informe para identificación. json produce la salida del informe en formato JSON. json_std produce la salida del informe en formato JSON que es más conforme con el estándar JSON. Consulte lvmreport(7) para obtener más información.
-S|--select Cadena
Selecciona objetos para procesamiento y generación de informes basándose en criterios especificados. La sintaxis de criterios se describe en --select help y lvmreport(7). Para los comandos de generación de informes, se muestra una fila por cada objeto que coincide con los criterios. Consulte --options help para ver los campos de objeto seleccionables. Las filas pueden mostrarse con un campo adicional "selected" (-o selected) que muestra 1 si la fila coincide con la selección y 0 en caso contrario. Para los comandos que no generan informes y que procesan entidades LVM
-t|--test
Ejecuta el comando en modo de prueba, simulando la operación sin realizar cambios reales.
-u|--uuid
Cambia el UUID de un PV.
-v|--verbose ...
Establece el nivel de detalle del mensaje. Repetir de 1 a 6 veces aumenta el nivel de detalle de los mensajes enviados al archivo de registro y/o a syslog (si está configurado).
--version
Muestra información de la versión del programa e información sobre las licencias y los derechos de autor.
-y|--yes
No preguntar. Asume 'sí' a todas las preguntas que se le hagan. Usar con extrema precaución.

NAME

pvchange — Change attributes of a physical volume

SYNOPSIS

pvchange [-a|--allocatable {y|n}] [-k|--setphysicalvolumesize Size] [-M|--metadatatype type] [-p|--partial] [-t|--test] [-u|--uuid] [-v|--verbose] [PhysicalVolume[:PE-PE]...]

DESCRIPTION

Changes the attributes of one or more physical volumes.

USAGE

pvchange [-a|--allocatable {y|n}] [-k|--setphysicalvolumesize Size] [-M|--metadatatype type] [-p|--partial] [-t|--test] [-u|--uuid] [-v|--verbose] [PhysicalVolume[:PE-PE]...]

The following options are supported:

OPTIONS

-a|--allocatable {y|n}
Set the allocation of physical extents (PEs) on the PV. If set to y (yes), PEs on the PV are available for allocation. If set to n (no), PEs on the PV are not available for allocation. This can be useful for disks that have failed or are about to be removed. PVs marked as not allocatable will not be chosen by tools like vgcreate(8) or vgextend(8).
-k|--setphysicalvolumesize Size
The PV size is usually determined automatically by the device size. If this option is used, the PV size is set to the specified value. The size must be greater than or equal to the size of the metadata area. If the specified value is smaller than the metadata area, the metadata area size is used. The size is given in bytes and may be followed by one of the following scaling suffixes:
b|B to one byte, s|S to one sector (512 bytes), k|K to 1 MiB, m|M to 1 MiB, g|G to 1 GiB, t|T to 1 TiB, p|P to 1 PiB, e|E to 1 EiB.
-M|--metadatatype type
Sets the metadata type for the physical volume. This can be lvm1 or lvm2. LVM2 is the default.
-p|--partial
Allow operations on a partial VG. See vgimport(8) for more information on partial VGs.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
-u|--uuid
Generate new random UUID for specified PVs.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

PV
Physical Volume name, a device path under /dev. For commands managing physical extents, a PV positional arg generally accepts a suffix indicating a range (or multiple ranges) of physical extents (PEs). When the first PE is omitted, it defaults to the start of the device, and when the last PE is omitted it defaults to end.
Start and end range (inclusive): PV[:PE-PE] ...
Start and length range (counting from 0): PV[:PE+PE] ...
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

EXAMPLES

Disallow the allocation of physical extents on a PV (e.g. because of disk errors, or because it will be removed after freeing it).
pvchange -x n /dev/sdk1
