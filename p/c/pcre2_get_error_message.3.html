pcre2_get_error_message(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_GET_ERROR_MESSAGE(3) Manual de funciones de biblioteca PCRE2_GET_ERROR_MESSAGE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_get_error_message(int errorcode, PCRE2_UCHAR *buffer,
  PCRE2_SIZE bufflen);

DESCRIPCIÓN

Esta función proporciona un mensaje de error textual para cada código de error de PCRE2. Los errores de compilación son números positivos; los errores de formato UTF y los errores de coincidencia son números negativos. Los argumentos son:


errorcode un código de error (positivo o negativo)
buffer dónde colocar el mensaje
bufflen la longitud del búfer (unidades de código)

La función devuelve la longitud del mensaje en unidades de código, excluyendo el cero final, o el código de error negativo PCRE2_ERROR_NOMEMORY si el búfer es demasiado pequeño. En este caso, el mensaje devuelto se trunca (pero aún con un cero final). Si errorcode no contiene un número de código de error reconocido, se devuelve el valor negativo PCRE2_ERROR_BADDATA.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
