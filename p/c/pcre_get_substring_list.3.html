pcre_get_substring_list(3)

Paquete: pcre

Licencias: BSD

PCRE_GET_SUBSTRING_LIST(3) Manual de funciones de biblioteca PCRE_GET_SUBSTRING_LIST(3)

NOMBRE

PCRE - Expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_get_substring_list(const char *subject,
     int *ovector, int stringcount, const char ***listptr);

int pcre16_get_substring_list(PCRE_SPTR16 subject,
     int *ovector, int stringcount, PCRE_SPTR16 **listptr);

int pcre32_get_substring_list(PCRE_SPTR32 subject,
     int *ovector, int stringcount, PCRE_SPTR32 **listptr);

DESCRIPCIÓN

Esta es una función de conveniencia para extraer una lista de todas las subcadenas capturadas. Los argumentos son:


subject Sujeto que ha sido emparejado con éxito
ovector Vector de desplazamiento que utilizó pcre[16|32]_exec
stringcount Valor devuelto por pcre[16|32]_exec
listptr Dónde poner un puntero a la lista

La memoria en la que se colocan las subcadenas y la lista se obtiene llamando a pcre[16|32]_malloc(). La función de conveniencia pcre[16|32]_free_substring_list() se puede utilizar para liberarla cuando ya no sea necesaria. Se coloca un puntero a una lista de punteros en la variable cuya dirección está en listptr. La lista termina con un puntero NULL. El resultado de la función es cero si tiene éxito o PCRE_ERROR_NOMEMORY si no se pudo obtener suficiente memoria.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
