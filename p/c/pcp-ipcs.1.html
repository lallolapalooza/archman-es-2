PCP-IPCS(1) Manual de comandos generales PCP-IPCS(1)

NOMBRE

pcp-ipcs - proporciona información sobre las instalaciones IPC

SINOPSIS

pcp [opciones de pcp] ipcs [-luV?] [formato-de-salida]

DESCRIPCIÓN

pcp-ipcs proporciona información sobre las instalaciones de comunicación entre procesos para las cuales el proceso que llama tiene acceso de lectura.

OPCIONES

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -Z/--timezone y varias opciones de pcp adicionales están indirectamente disponibles; consulte PCPIntro(1) para una descripción completa de estas opciones.

Las opciones de línea de comandos adicionales disponibles para pcp-ipcs son:

-V, --version
Muestra la información de la versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

Formatos de salida

-l, --limits
Muestra los límites de recursos.
-u, --summary
Muestra un resumen del estado.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).
