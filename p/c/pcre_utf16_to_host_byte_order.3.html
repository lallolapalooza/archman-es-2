pcre_utf16_to_host_byte_order(3)

Paquete: pcre

Licencias: BSD

PCRE_UTF16_TO_HOST_BYTE_ORDER(3) Manual de Funciones de Librería PCRE_UTF16_TO_HOST_BYTE_ORDER(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre16_utf16_to_host_byte_order(PCRE_UCHAR16 *output,
     PCRE_SPTR16 input, int length, int *host_byte_order,
     int keep_boms);

DESCRIPCIÓN

Esta función, que solo existe en la librería de 16 bits, convierte una cadena UTF-16 al orden correcto para el host actual, teniendo en cuenta las marcas de orden de bytes (BOMs) dentro de la cadena. Sus argumentos son:


puntero output al buffer de salida, puede ser el mismo que input
puntero input al buffer de entrada
length número de unidades de 16 bits en la entrada, o negativo para
una cadena terminada en nulo
host_byte_order un valor NULL o un valor distinto de cero apuntado significa
empezar en orden de bytes del host
keep_boms si es distinto de cero, las BOMs se copian a la cadena de salida

El resultado de la función es el número de unidades de 16 bits colocadas en el buffer de salida, incluido el terminador cero si la cadena estaba terminada en cero.

Si host_byte_order no es NULL, se establece para indicar el orden de bytes que está actual al final de la cadena.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
