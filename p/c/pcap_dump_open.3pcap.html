pcap_dump_open.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_DUMP_OPEN(3PCAP) PCAP_DUMP_OPEN(3PCAP)

NOMBRE

pcap_dump_open, pcap_dump_open_append, pcap_dump_fopen - abrir un archivo para escribir paquetes

SINOPSIS

#include <pcap/pcap.h>

pcap_dumper_t *pcap_dump_open(pcap_t *p, const char *fname);
pcap_dumper_t *pcap_dump_open_append(pcap_t *p, const char *fname);
pcap_dumper_t *pcap_dump_fopen(pcap_t *p, FILE *fp);

DESCRIPCIÓN

pcap_dump_open() se llama para abrir un "archivo de guardado" para escritura. fname especifica el nombre del archivo a abrir. El archivo tendrá el mismo formato que los utilizados por tcpdump(1) y tcpslice(1). Si el archivo no existe, se creará; si el archivo existe, se truncará y se sobrescribirá. El nombre "-" es un sinónimo de stdout.

pcap_dump_fopen() se llama para escribir datos en un flujo existente y abierto fp; este flujo se cerrará mediante una llamada posterior a pcap_dump_close(3PCAP). Se asume que el flujo está al principio de un archivo que ha sido creado o truncado recientemente, por lo que las escrituras comenzarán al principio del archivo. Tenga en cuenta que en Windows, ese flujo debe abrirse en modo binario.

p es un manejador de captura o de "archivo de guardado" devuelto por una llamada anterior a pcap_create(3PCAP) y activado por una llamada anterior a pcap_activate(3PCAP), o devuelto por una llamada anterior a pcap_open_offline(3PCAP), pcap_open_live(3PCAP) o pcap_open_dead(3PCAP). La precisión de la marca de tiempo, el tipo de capa de enlace y la longitud de la instantánea de p se utilizan como el tipo de capa de enlace y la longitud de la instantánea del archivo de salida.

pcap_dump_open_append() es como pcap_dump_open() pero, si el archivo ya existe, y es un archivo pcap con el mismo orden de bytes que el host que abre el archivo, y tiene la misma precisión de marca de tiempo, tipo de encabezado de capa de enlace y longitud de instantánea que p, escribirá nuevos paquetes al final del archivo.

VALOR DE RETORNO

Se devuelve un puntero a una estructura pcap_dumper_t para usar en llamadas posteriores a pcap_dump(3PCAP) y pcap_dump_close(3PCAP). Se devuelve NULL en caso de error. Si se devuelve NULL, se puede usar pcap_geterr(3PCAP) para obtener el texto del error.

COMPATIBILIDAD HACIA ATRÁS

La función pcap_dump_open_append() estuvo disponible en la versión 1.7.2 de libpcap. En versiones anteriores, no hay soporte para añadir paquetes a un archivo de guardado existente.

VER TAMBIÉN
