NOMBRE

pcap_activate - activar un manejador de captura

SINOPSIS

#include <pcap/pcap.h>
int pcap_activate(pcap_t *p);

DESCRIPCIÓN

pcap_activate() se utiliza para activar un manejador de captura de paquetes para examinar paquetes en la red, con las opciones que se establecieron en el manejador en efecto.

VALOR DE RETORNO

pcap_activate() devuelve 0 si tiene éxito sin advertencias, un valor positivo distinto de cero si tiene éxito con advertencias, y un valor negativo si ocurre un error. Un valor de retorno distinto de cero indica qué condición de advertencia o error ocurrió.

Los posibles valores de advertencia son:

PCAP_WARNING_PROMISC_NOTSUP
Se solicitó el modo promiscuo, pero la fuente de captura no admite el modo promiscuo.
PCAP_WARNING_TSTAMP_TYPE_NOTSUP
El tipo de marca de tiempo especificado en una llamada anterior a pcap_set_tstamp_type(3PCAP) no es compatible con la fuente de captura (el tipo de marca de tiempo se deja como el predeterminado).
PCAP_WARNING
Ocurrió otra condición de advertencia; se puede llamar a pcap_geterr(3PCAP) o pcap_perror(3PCAP) con p como argumento para obtener o mostrar un mensaje que describa la condición de advertencia.

Los posibles valores de error son:

PCAP_ERROR_ACTIVATED
El manejador ya ha sido activado.
PCAP_ERROR_NO_SUCH_DEVICE
La fuente de captura especificada cuando se creó el manejador no existe.
PCAP_ERROR_PERM_DENIED
El proceso no tiene permiso para abrir la fuente de captura.
PCAP_ERROR_PROMISC_PERM_DENIED
El proceso tiene permiso para abrir la fuente de captura pero no tiene permiso para ponerla en modo promiscuo.
PCAP_ERROR_RFMON_NOTSUP
Se especificó el modo monitor pero la fuente de captura no admite el modo monitor.
PCAP_ERROR_IFACE_NOT_UP
El dispositivo de la fuente de captura no está activo.
PCAP_ERROR_CAPTURE_NOTSUP
La captura de paquetes no es compatible con la fuente de captura.
PCAP_ERROR
Ocurrió otro error. Se puede llamar a pcap_geterr() o pcap_perror() con p como argumento para obtener o mostrar un mensaje que describa el error.

Si se devuelve PCAP_WARNING_PROMISC_NOTSUP, PCAP_ERROR_NO_SUCH_DEVICE, PCAP_ERROR_PERM_DENIED, o PCAP_ERROR_CAPTURE_NOTSUP, se puede llamar a pcap_geterr() o pcap_perror() con p como argumento para obtener o mostrar un mensaje que proporcione detalles adicionales sobre el problema que podrían ser útiles para depurarlo si es inesperado.

Es posible que se agreguen códigos de advertencia y error adicionales en el futuro; un programa debe verificar los códigos de retorno positivos, negativos y cero, y tratar todos los códigos de retorno positivos como advertencias y todos los códigos de retorno negativos como errores. Se puede llamar a pcap_statustostr(3PCAP), con un código de advertencia o error como argumento, para obtener un mensaje que describa el código de advertencia o error.

Si pcap_activate() falla, el pcap_t * no se cierra ni se libera; debe cerrarse usando pcap_close(3PCAP).
