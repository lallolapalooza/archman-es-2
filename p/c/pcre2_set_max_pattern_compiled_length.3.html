pcre2_set_max_pattern_compiled_length(3)

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_MAX_PATTERN_COMPILED_LENGTH(3) Manual de funciones de biblioteca PCRE2_SET_MAX_PATTERN_COMPILED_LENGTH(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_set_max_pattern_compiled_length(
  pcre2_compile_context *ccontext, PCRE2_SIZE value);

DESCRIPCIÓN

Esta función establece, en un contexto de compilación, el tamaño máximo (en bytes) para la memoria necesaria para almacenar la versión compilada de un patrón que está utilizando este contexto. El resultado es siempre cero. Si un patrón que se pasa a pcre2_compile() haciendo referencia a este contexto necesita más memoria, se genera un error. El valor predeterminado es el número más grande que una variable PCRE2_SIZE puede almacenar, que es efectivamente ilimitado.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
