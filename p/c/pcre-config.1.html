PCRE-CONFIG(1) Manual de comandos generales PCRE-CONFIG(1)

NOMBRE

pcre-config - programa para devolver la configuración de PCRE

SINOPSIS

pcre-config [--prefix] [--exec-prefix] [--version] [--libs]
            [--libs16] [--libs32] [--libs-cpp] [--libs-posix]
            [--cflags] [--cflags-posix]

DESCRIPCIÓN

pcre-config devuelve la configuración de las bibliotecas PCRE instaladas y las opciones necesarias para compilar un programa que las utilice. Algunas de las opciones se aplican solo a las bibliotecas de 8 bits, 16 bits o 32 bits, respectivamente, y no están disponibles si solo se ha compilado una de estas bibliotecas. Si se encuentra una opción no disponible, se mostrará la información de "uso".

OPCIONES

--prefix
Escribe en la salida estándar el prefijo del directorio utilizado en la instalación de PCRE para archivos independientes de la arquitectura (/usr en muchos sistemas, /usr/local en algunos sistemas).
--exec-prefix
Escribe en la salida estándar el prefijo del directorio utilizado en la instalación de PCRE para archivos dependientes de la arquitectura (normalmente el mismo que --prefix).
--version
Escribe en la salida estándar el número de versión de las bibliotecas PCRE instaladas.
--libs
Escribe en la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE de 8 bits (-lpcre en muchos sistemas).
--libs16
Escribe en la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE de 16 bits (-lpcre16 en muchos sistemas).
--libs32
Escribe en la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE de 32 bits (-lpcre32 en muchos sistemas).
--libs-cpp
Escribe en la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca de envoltorio C++ de PCRE (-lpcrecpp -lpcre en muchos sistemas).
--libs-posix
Escribe en la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca de envoltorio de API POSIX de PCRE (-lpcreposix -lpcre en muchos sistemas).
--cflags
Escribe en la salida estándar las opciones de línea de comandos necesarias para compilar archivos que utilizan PCRE (esto puede incluir algunas opciones -I, pero está vacío en muchos sistemas).
--cflags-posix
Escribe en la salida estándar las opciones de línea de comandos necesarias para compilar archivos que utilizan la biblioteca de envoltorio de API POSIX de PCRE (esto puede incluir algunas opciones -I, pero está vacío en muchos sistemas).
