pcre2_set_glob_escape(3)

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_GLOB_ESCAPE(3) Manual de funciones de biblioteca PCRE2_SET_GLOB_ESCAPE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_set_glob_escape(pcre2_convert_context *cvcontext,
  uint32_t escape_char);

DESCRIPCIÓN

Esta función forma parte de un conjunto experimental de funciones de conversión de patrones. Establece el carácter de escape que se utiliza al convertir globs. El segundo argumento debe ser cero (lo que significa que no hay carácter de escape) o un carácter de puntuación cuyo punto de código sea menor que 256. El valor predeterminado es la tilde grave si se ejecuta en Windows, de lo contrario, la barra invertida. El resultado de la función es cero para el éxito o PCRE2_ERROR_BADDATA si el segundo argumento no es válido.

Las funciones de conversión de patrones se describen en la documentación de pcre2convert.
