NOMBRE

pcp-reboot-init - Script auxiliar de Performance Co-Pilot después del reinicio del sistema

SINOPSIS

$PCP_BINADM_DIR/pcp-reboot-init

DESCRIPCIÓN

pcp-reboot-init realiza la inicialización de "un solo intento" después del reinicio del sistema para los diversos componentes de Performance Co-Pilot (PCP).

El script normalmente se llama desde los scripts de init(1) o systemd(1) antes de iniciar otros componentes de PCP. No necesita ser ejecutado en otros momentos, pero es idempotente, por lo que la ejecución repetida es inofensiva, pero inútil.

pcp-reboot-init está destinado a ser ejecutado por el usuario "root", y fallará de lo contrario.

ENTORNO PCP

El archivo /etc/pcp.conf contiene los valores locales para las variables PCP_ utilizadas en este script.

VER TAMBIÉN

init(1), PCPIntro(1), systemd(1), pcp.conf(5) y pcp.env(5).
