pcre_jit_exec(3)

Paquete: pcre

Licencias: BSD

PCRE_EXEC(3) Manual de funciones de biblioteca PCRE_EXEC(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_jit_exec(const pcre *code, const pcre_extra *extra,
     const char *subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

int pcre16_jit_exec(const pcre16 *code, const pcre16_extra *extra,
     PCRE_SPTR16 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

int pcre32_jit_exec(const pcre32 *code, const pcre32_extra *extra,
     PCRE_SPTR32 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

DESCRIPCIÓN

Esta función compara una expresión regular compilada que ha sido estudiada con éxito con una de las opciones JIT contra una cadena de asunto dada, utilizando un algoritmo de comparación similar al de Perl. Es una interfaz de "vía rápida" a JIT y omite algunas de las comprobaciones de sanidad que aplica pcre_exec(). Devuelve los desplazamientos de las subcadenas capturadas. Sus argumentos son:


code Puntero al patrón compilado
extra Puntero a una estructura pcre[16|32]_extra asociada,
o es NULL
subject Puntero a la cadena del asunto
length Longitud de la cadena del asunto, en bytes
startoffset Desplazamiento en bytes en el asunto donde comenzar
la comparación
options Bits de opciones
ovector Puntero a un vector de enteros para los desplazamientos de resultados
ovecsize Número de elementos en el vector (un múltiplo de 3)
jstack Puntero a una pila JIT

Las opciones permitidas son:


PCRE_NOTBOL La cadena del asunto no es el principio de una línea
PCRE_NOTEOL La cadena del asunto no es el final de una línea
PCRE_NOTEMPTY Una cadena vacía no es una coincidencia válida
PCRE_NOTEMPTY_ATSTART Una cadena vacía al principio del asunto
no es una coincidencia válida
PCRE_NO_UTF16_CHECK No comprobar la validez de UTF-16 del asunto
(solo relevante si se estableció PCRE_UTF16
en tiempo de compilación)
PCRE_NO_UTF32_CHECK No comprobar la validez de UTF-32 del asunto
(solo relevante si se estableció PCRE_UTF32
en tiempo de compilación)
PCRE_NO_UTF8_CHECK No comprobar la validez de UTF-8 del asunto
(solo relevante si se estableció PCRE_UTF8
en tiempo de compilación)
PCRE_PARTIAL ) Devolver PCRE_ERROR_PARTIAL para una coincidencia parcial
PCRE_PARTIAL_SOFT ) si no se encuentran coincidencias completas
PCRE_PARTIAL_HARD Devolver PCRE_ERROR_PARTIAL para una coincidencia parcial
si se encuentra antes de una coincidencia completa

Sin embargo, las opciones PCRE_NO_UTF[8|16|32]_CHECK no tienen ningún efecto, ya que esta comprobación nunca se aplica. Para obtener detalles sobre la coincidencia parcial, consulte la página pcrepartial. Una estructura pcre_extra contiene los siguientes campos:


flags Bits que indican qué campos están establecidos
study_data Datos opacos de pcre[16|32]_study()
match_limit Límite de uso de recursos internos
match_limit_recursion Límite de profundidad de recursión interna
callout_data Datos opacos que se devuelven a las llamadas externas
tables Puntero a tablas de caracteres o es NULL
mark Para devolver un puntero *MARK
executable_jit Datos opacos de la compilación JIT

Los bits de los indicadores son PCRE_EXTRA_STUDY_DATA, PCRE_EXTRA_MATCH_LIMIT, PCRE_EXTRA_MATCH_LIMIT_RECURSION, PCRE_EXTRA_CALLOUT_DATA, PCRE_EXTRA_TABLES, PCRE_EXTRA_MARK y PCRE_EXTRA_EXECUTABLE_JIT.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API JIT en la página pcrejit.
