pcre2_substring_list_get(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_LIST_GET(3) Manual de Funciones de Biblioteca PCRE2_SUBSTRING_LIST_GET(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_substring_list_get(pcre2_match_data *match_data,
  PCRE2_UCHAR ***listptr, PCRE2_SIZE **lengthsptr);

DESCRIPCIÓN

Esta es una función de conveniencia para extraer todas las subcadenas capturadas después de una coincidencia de patrón. Construye una lista de punteros a las cadenas y (opcionalmente) una segunda lista que contiene sus longitudes (en unidades de código), excluyendo un cero terminador que se agrega a cada una de ellas. Todo esto se hace en un solo bloque de memoria que se obtiene utilizando la misma función de asignación de memoria que se usó para obtener el bloque de datos de coincidencia. La función de conveniencia pcre2_substring_list_free() se puede usar para liberarlo cuando ya no sea necesario. Los argumentos son:


match_data El bloque de datos de coincidencia
listptr Dónde colocar un puntero a la lista
lengthsptr Dónde colocar un puntero a las longitudes, o NULL

Se coloca un puntero a una lista de punteros en la variable cuya dirección está en listptr. La lista se termina con un puntero NULL. Si lengthsptr no es NULL, se crea una lista de longitudes coincidente y su dirección se coloca en lengthsptr. El resultado de la función es cero en caso de éxito o PCRE2_ERROR_NOMEMORY si no se pudo obtener suficiente memoria.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
