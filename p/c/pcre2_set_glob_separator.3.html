pcre2_set_glob_separator(3)

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_GLOB_SEPARATOR(3) Manual de funciones de biblioteca PCRE2_SET_GLOB_SEPARATOR(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_set_glob_separator(pcre2_convert_context *cvcontext,
  uint32_t separator_char);

DESCRIPCIÓN

Esta función es parte de un conjunto experimental de funciones de conversión de patrones. Establece el carácter separador de componentes que se utiliza al convertir globs. El segundo argumento debe ser uno de los caracteres barra inclinada (/), barra invertida (\) o punto (.). El valor predeterminado es la barra invertida cuando se ejecuta en Windows, de lo contrario, la barra inclinada. El resultado de la función es cero para el éxito o PCRE2_ERROR_BADDATA si el segundo argumento es inválido.

Las funciones de conversión de patrones se describen en la documentación de pcre2convert.
