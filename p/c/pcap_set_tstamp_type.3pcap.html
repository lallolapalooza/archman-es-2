PCAP_SET_TSTAMP_TYPE(3PCAP) PCAP_SET_TSTAMP_TYPE(3PCAP)

NOMBRE

pcap_set_tstamp_type - establecer el tipo de marca de tiempo a usar por un dispositivo de captura

SINOPSIS

#include <pcap/pcap.h>
int pcap_set_tstamp_type(pcap_t *p, int tstamp_type);

DESCRIPCIÓN

pcap_set_tstamp_type() establece el tipo de marca de tiempo deseada para los paquetes capturados en el descriptor pcap al tipo especificado por tstamp_type. Debe llamarse en un descriptor pcap creado por pcap_create(3PCAP) que aún no haya sido activado por pcap_activate(3PCAP). pcap_list_tstamp_types(3PCAP) proporcionará una lista de los tipos de marca de tiempo compatibles con un dispositivo de captura dado. Consulte pcap-tstamp(7) para obtener una lista de todos los tipos de marca de tiempo.

VALOR DE RETORNO

pcap_set_tstamp_type() devuelve 0 si la operación tuvo éxito y el tipo de marca de tiempo especificado se espera que sea compatible con el dispositivo de captura, PCAP_WARNING_TSTAMP_TYPE_NOTSUP si el tipo de marca de tiempo especificado no es compatible con el dispositivo de captura, PCAP_ERROR_ACTIVATED si se llama en un manejador de captura que ha sido activado, y PCAP_ERROR_CANTSET_TSTAMP_TYPE si el dispositivo de captura no admite el establecimiento del tipo de marca de tiempo (solo las versiones anteriores de libpcap devolverán eso; las versiones más nuevas siempre permitirán que el tipo de marca de tiempo se establezca en el tipo predeterminado).

COMPATIBILIDAD CON VERSIONES ANTERIORES

Esta función estuvo disponible en la versión 1.2.1 de libpcap. En versiones anteriores, no se puede establecer el tipo de marca de tiempo; solo está disponible el tipo de marca de tiempo predeterminado ofrecido por una fuente de captura.
