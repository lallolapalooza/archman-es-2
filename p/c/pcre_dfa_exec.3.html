pcre_dfa_exec(3)

Paquete: pcre

Licencias: BSD

PCRE_DFA_EXEC(3) Manual de funciones de biblioteca PCRE_DFA_EXEC(3)

NOMBRE

PCRE - Expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_dfa_exec(const pcre *code, const pcre_extra *extra,
     const char *subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

int pcre16_dfa_exec(const pcre16 *code, const pcre16_extra *extra,
     PCRE_SPTR16 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

int pcre32_dfa_exec(const pcre32 *code, const pcre32_extra *extra,
     PCRE_SPTR32 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

DESCRIPCIÓN

Esta función compara una expresión regular compilada contra una cadena de asunto dada, usando un algoritmo de comparación alternativo que escanea la cadena de asunto solo una vez (no compatible con Perl). Tenga en cuenta que la función principal, compatible con Perl, es pcre[16|32]_exec(). Los argumentos para esta función son:


code Puntero a la expresión regular compilada
extra Puntero a una estructura pcre[16|32]_extra asociada,
o es NULL
subject Puntero a la cadena de asunto
length Longitud de la cadena de asunto
startoffset Desplazamiento en el asunto en el que comenzar la comparación
options Bits de opciones
ovector Puntero a un vector de enteros para los desplazamientos de resultado
ovecsize Número de elementos en el vector
workspace Puntero a un vector de enteros utilizado como espacio de trabajo
wscount Número de elementos en el vector

Las unidades para length y startoffset son bytes para pcre_exec(), elementos de datos de 16 bits para pcre16_exec(), y elementos de 32 bits para pcre32_exec(). Las opciones son:


PCRE_ANCHORED Coincidir solo en la primera posición
PCRE_BSR_ANYCRLF \R coincide solo con CR, LF o CRLF
PCRE_BSR_UNICODE \R coincide con todos los finales de línea Unicode
PCRE_NEWLINE_ANY Reconocer cualquier secuencia de final de línea Unicode
PCRE_NEWLINE_ANYCRLF Reconocer CR, LF y CRLF como secuencias de final de línea
PCRE_NEWLINE_CR Reconocer CR como la única secuencia de final de línea
PCRE_NEWLINE_CRLF Reconocer CRLF como la única secuencia de final de línea
PCRE_NEWLINE_LF Reconocer LF como la única secuencia de final de línea
PCRE_NOTBOL El asunto no es el inicio de una línea
PCRE_NOTEOL El asunto no es el final de una línea
PCRE_NOTEMPTY Una cadena vacía no es una coincidencia válida
PCRE_NOTEMPTY_ATSTART Una cadena vacía al inicio del asunto
no es una coincidencia válida
PCRE_NO_START_OPTIMIZE No realizar optimizaciones de "inicio de coincidencia"
PCRE_NO_UTF16_CHECK No verificar la validez de UTF-16 del asunto
(solo relevante si PCRE_UTF16
se estableció al compilar)
PCRE_NO_UTF32_CHECK No verificar la validez de UTF-32 del asunto
(solo relevante si PCRE_UTF32
se estableció al compilar)
PCRE_NO_UTF8_CHECK No verificar la validez de UTF-8 del asunto
(solo relevante si PCRE_UTF8
se estableció al compilar)
PCRE_PARTIAL ) Devolver PCRE_ERROR_PARTIAL para una coincidencia parcial
PCRE_PARTIAL_SOFT ) si no se encuentran coincidencias completas
PCRE_PARTIAL_HARD Devolver PCRE_ERROR_PARTIAL para una coincidencia parcial
incluso si también hay una coincidencia completa
PCRE_DFA_SHORTEST Devolver solo la coincidencia más corta
PCRE_DFA_RESTART Reiniciar después de una coincidencia parcial

Existen restricciones sobre lo que puede aparecer en una expresión regular al usar esta función de comparación. Los detalles se proporcionan en la documentación de pcrematching. Para obtener detalles sobre la comparación parcial, consulte la página pcrepartial.

Una estructura pcre[16|32]_extra contiene los siguientes campos:


flags Bits que indican qué campos están establecidos
study_data Datos opacos de pcre[16|32]_study()
match_limit Límite de uso de recursos internos
match_limit_recursion Límite de profundidad de recursión interna
callout_data Datos opacos devueltos a las llamadas externas
tables Puntero a tablas de caracteres o NULL
mark Para devolver un puntero *MARK
executable_jit Datos opacos de la compilación JIT

Los bits de bandera son PCRE_EXTRA_STUDY_DATA, PCRE_EXTRA_MATCH_LIMIT, PCRE_EXTRA_MATCH_LIMIT_RECURSION, PCRE_EXTRA_CALLOUT_DATA, PCRE_EXTRA_TABLES, PCRE_EXTRA_MARK y PCRE_EXTRA_EXECUTABLE_JIT. Para esta función de comparación, los campos match_limit y match_limit_recursion no se utilizan y no deben establecerse. La bandera PCRE_EXTRA_EXECUTABLE_JIT y la variable correspondiente se ignoran.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
