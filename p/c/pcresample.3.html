NOMBRE

PCRE - Expresiones regulares compatibles con Perl

PROGRAMA DE EJEMPLO PCRE

Un programa simple y completo para empezar a usar PCRE se suministra en el archivo pcredemo.c de la distribución PCRE. Una lista de este programa se incluye en la documentación de pcredemo. Si no tienes una copia de la distribución PCRE, puedes guardar esta lista para recrear pcredemo.c.

El programa de demostración, que utiliza la biblioteca original de 8 bits de PCRE, compila la expresión regular que es su primer argumento y la compara con la cadena de sujeto en su segundo argumento. No se establecen opciones de PCRE y se utilizan tablas de caracteres predeterminadas. Si la coincidencia tiene éxito, el programa muestra la parte del sujeto que coincidió, junto con el contenido de cualquier subcadena capturada.

Si se proporciona la opción -g en la línea de comandos, el programa continúa comprobando si hay más coincidencias de la misma expresión regular en la misma cadena de sujeto. La lógica es un poco complicada debido a la posibilidad de coincidir con una cadena vacía. Los comentarios en el código explican lo que está sucediendo.

Si PCRE está instalado en los directorios de inclusión y biblioteca estándar de su sistema operativo, debería poder compilar el programa de demostración usando este comando:


gcc -o pcredemo pcredemo.c -lpcre

Si PCRE está instalado en otro lugar, es posible que necesite agregar opciones adicionales a la línea de comandos. Por ejemplo, en un sistema tipo Unix que tiene PCRE instalado en /usr/local, puede compilar el programa de demostración usando un comando como este:


gcc -o pcredemo -I/usr/local/include pcredemo.c \
-L/usr/local/lib -lpcre

En un entorno Windows, si desea enlazar estáticamente el programa contra un archivo pcre.a no DLL, debe descomentar la línea que define PCRE_STATIC antes de incluir pcre.h, ya que de lo contrario las funciones exportadas pcre_malloc() y pcre_free() se declararán como __declspec(dllimport), con resultados no deseados.

Una vez que haya compilado y enlazado el programa de demostración, puede ejecutar pruebas simples como estas:


./pcredemo 'cat|dog' 'el gato se sentó en la alfombra'
./pcredemo -g 'cat|dog' 'el perro se sentó en el gato'

Tenga en cuenta que existe un programa de prueba mucho más completo, llamado pcretest, que admite muchas más instalaciones para probar expresiones regulares y ambas bibliotecas de PCRE. El programa pcredemo se proporciona como un ejemplo de codificación simple.

Si intenta ejecutar pcredemo cuando PCRE no está instalado en el directorio de bibliotecas estándar, puede obtener un error como este en algunos sistemas operativos (por ejemplo, Solaris):


ld.so.1: a.out: fatal: libpcre.so.0: open failed: No such file or directory

Esto es causado por la forma en que funciona el soporte de bibliotecas compartidas en esos sistemas. Debe agregar


-R/usr/local/lib

(por ejemplo) al comando de compilación para solucionar este problema.
