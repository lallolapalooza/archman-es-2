NOMBRE

pcap_offline_filter - comprueba si un filtro coincide con un paquete

SINOPSIS

#include <pcap/pcap.h>
int pcap_offline_filter(const struct bpf_program *fp,
    const struct pcap_pkthdr *h, const u_char *pkt);

DESCRIPCIÓN

pcap_offline_filter() comprueba si un filtro coincide con un paquete. fp es un puntero a una estructura bpf_program, normalmente el resultado de una llamada a pcap_compile(3PCAP). h apunta a la estructura pcap_pkthdr para el paquete, y pkt apunta a los datos del paquete.

VALOR DE RETORNO

pcap_offline_filter() devuelve el valor de retorno del programa de filtro. Este será cero si el paquete no coincide con el filtro y distinto de cero si el paquete coincide con el filtro.
