pcre2_next_match(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_NEXT_MATCH(3) Manual de Funciones de Biblioteca PCRE2_NEXT_MATCH(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_next_match(pcre2_match_data *match_data,
  PCRE2_SIZE *pstart_offset, uint32_t *poptions);

DESCRIPCIÓN

Esta función puede ser llamada después de una de las funciones de coincidencia (pcre2_match(), pcre2_dfa_match(), o pcre2_jit_match()), y debe ser provista con el mismo parámetro match_data. Genera los parámetros apropiados para buscar la siguiente coincidencia en la misma cadena de asunto, y es adecuada para aplicaciones que proporcionan un comportamiento de coincidencia "global" (por ejemplo, reemplazando todas las coincidencias en el asunto, o dividiendo el asunto en todas las coincidencias, o simplemente contando el número de coincidencias).

Devuelve 0 ("falso") si no hay necesidad de realizar ningún intento de coincidencia adicional, o 1 ("verdadero") si se debe intentar otra coincidencia.

El *pstart_offset y el *poptions se establecen si la función devuelve 1. El *pstart_offset debe pasarse directamente al siguiente intento de coincidencia, y el *poptions debe pasarse al siguiente intento de coincidencia combinándolo con las opciones de coincidencia de la aplicación mediante OR.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
