NOMBRE

PCRE2DEMO - Un programa de demostración en C para PCRE2

CODIGO FUENTE

/*************************************************
*           PROGRAMA DE DEMOSTRACIÓN PCRE2         *
*************************************************/
/* Este es un programa de demostración para ilustrar una forma sencilla de
utilizar la biblioteca de expresiones regulares PCRE2 desde un programa C. Vea la
documentación de pcre2sample para una breve discusión ("man pcre2sample" si tiene
las páginas del manual de PCRE2 instaladas). PCRE2 es una API revisada para la biblioteca, y es
incompatible con la API original de PCRE.
En realidad, hay tres bibliotecas, cada una compatible con un ancho de unidad de código diferente. Este programa de demostración utiliza la biblioteca de 8 bits. El valor predeterminado es
procesar cada unidad de código como un carácter separado, pero si el patrón comienza con
"(*UTF)", tanto él como el sujeto se tratan como cadenas UTF-8, donde
los caracteres pueden ocupar varias unidades de código.
En entornos similares a Unix, si PCRE2 está instalado en las bibliotecas estándar del sistema, deberías poder compilar este programa usando este comando:
cc -Wall pcre2demo.c -lpcre2-8 -o pcre2demo
Si PCRE2 no está instalado en una ubicación estándar, es probable que esté instalado
con soporte para el mecanismo pkg-config. Si tienes pkg-config, puedes
compilar este programa usando este comando:
cc -Wall pcre2demo.c `pkg-config --cflags --libs libpcre2-8` -o pcre2demo
Si no tienes pkg-config, es posible que tengas que usar algo como esto:
cc -Wall pcre2demo.c -I/usr/local/include -L/usr/local/lib \
  -R/usr/local/lib -lpcre2-8 -o pcre2demo
Reemplace "/usr/local/include" y "/usr/local/lib" con donde se encuentran los archivos de inclusión y
biblioteca de PCRE2 en su sistema. Solo algunos sistemas operativos (Solaris es uno) usan la opción -R.
Construcción en Windows:
Si desea vincular estáticamente este programa contra un archivo .a que no sea DLL, debe
definir PCRE2_STATIC antes de incluir pcre2.h, por lo que en este entorno, descomente
la siguiente línea. */
/* #define PCRE2_STATIC */
/* La macro PCRE2_CODE_UNIT_WIDTH debe definirse antes de incluir pcre2.h.
Para un programa que utiliza solo un ancho de unidad de código, configurarlo en 8, 16 o 32
permite usar nombres de funciones genéricos como pcre2_compile(). Tenga en cuenta
que solo cambiar 8 por 16 (por ejemplo) no es suficiente para convertir este
programa para procesar caracteres de 16 bits. Incluso en un entorno completamente de 16 bits, donde
las funciones de manejo de cadenas como strcmp() y printf() funcionan con caracteres de 16 bits,
el código para manejar la tabla de subcadenas con nombre aún necesitará
ser modificado. */
#define PCRE2_CODE_UNIT_WIDTH 8
#include <stdio.h>
#include <string.h>
#include <pcre2.h>
/**************************************************************************
* Aquí está el programa. La API incluye el concepto de "contextos" para     *
* configurar requisitos de interfaz inusuales para compilar y hacer coincidir,   *
* como gestores de memoria personalizados y definiciones de nueva línea no estándar.    *
* Este programa no hace nada de esto, por lo que no utiliza contextos,   *
* pasando siempre NULL donde se podría dar un contexto.                     *
**************************************************************************/
int main(int argc, char **argv)
{
pcre2_code *re;
PCRE2_SPTR pattern;     /* PCRE2_SPTR es un puntero a unidades de código sin signo de */
PCRE2_SPTR subject;     /* el ancho apropiado (en este caso, 8 bits). */
PCRE2_SPTR name_table;
int errornumber;
int find_all, caseless_match;
int i;
int rc;
uint32_t namecount;
uint32_t name_entry_size;
PCRE2_SIZE erroroffset;
PCRE2_SIZE *ovector;
PCRE2_SIZE ovector_last[2];
PCRE2_SIZE subject_length;
pcre2_match_data *match_data;
/**************************************************************************
* Primero, clasifica la línea de comandos. Opciones:                              *
* - "-g" para solicitar coincidencias repetidas para encontrar todas las ocurrencias,            *
*   como la opción /g de Perl. Establecemos la variable find_all a un valor distinto de cero     *
*   si la opción -g está presente.                                    *
* - "-i" para solicitar coincidencias sin distinción entre mayúsculas y minúsculas, como la opción /i de Perl.  Establecemos la *
*   variable caseless_match a PCRE2_CASELESS si la opción -i está         *
*   presente.                                                              *
**************************************************************************/
find_all = 0;
caseless_match = 0;
for (i = 1; i < argc; i++)
  {
  if (strcmp(argv[i], "-g") == 0) find_all = 1;
  else if (strcmp(argv[i], "-i") == 0) caseless_match = PCRE2_CASELESS;
  else if (argv[i][0] == '-')
    {
    printf("Opción no reconocida %s\n", argv[i]);
    return 1;
    }
  else break;
  }
/* Después de las opciones, requerimos exactamente dos argumentos, que son el patrón,
y la cadena sujeto. */
if (argc - i != 2)
  {
  printf("Se requieren exactamente dos argumentos: una expresión regular y una cadena sujeto\n");
  return 1;
  }
/* El patrón y el sujeto son argumentos char, por lo que se pueden convertir directamente
a PCRE2_SPTR porque estamos trabajando con unidades de código de 8 bits. La longitud del sujeto
se convierte a PCRE2_SIZE por completitud, aunque PCRE2_SIZE se define de hecho como size_t. */
pattern = (PCRE2_SPTR)argv[i];
subject = (PCRE2_SPTR)argv[i+1];
subject_length = (PCRE2_SIZE)strlen((char *)subject);
/*************************************************************************
* Ahora vamos a compilar el patrón de expresión regular, y manejar       *
* cualquier error que se detecte.                                          *
*************************************************************************/
re = pcre2_compile(
  pattern,               /* el patrón */
  PCRE2_ZERO_TERMINATED, /* indica que el patrón termina en cero */
  caseless_match,        /* posiblemente habilitar sin distinción de mayúsculas/minúsculas */
  &errornumber,          /* para el número de error */
  &erroroffset,          /* para el desplazamiento del error */
  NULL);                 /* usar contexto de compilación predeterminado */
/* La compilación falló: imprime el mensaje de error y sal. */
if (re == NULL)
  {
  PCRE2_UCHAR buffer[256];
  pcre2_get_error_message(errornumber, buffer, sizeof(buffer));
  printf("La compilación de PCRE2 falló en el desplazamiento %d: %s\n", (int)erroroffset,
    buffer);
  return 1;
  }
/*************************************************************************
* Si la compilación tuvo éxito, llamamos a PCRE2 nuevamente, para hacer una   *
* coincidencia del patrón contra la cadena sujeto. Esto hace solo UNA coincidencia. Si *
* se necesitan más coincidencias, se harán a continuación. Antes de ejecutar la coincidencia, debemos configurar un bloque match_data para ho
/************************************************************************* * pcre2_match_data_create_from_pattern() asegura que el bloque sea * exactamente del tamaño correcto para el número de paréntesis de captura en el * patrón. Si necesita conocer el tamaño real de un bloque match_data como * un número de bytes, puede encontrarlo así: * * PCRE2_SIZE match_data_size = pcre2_get_match_data_size(match_data); *************************************************************************/ match_data = pcre2_match_data_create_from_pattern(re, NULL); /* Ahora ejecuta la coincidencia. */ rc = pcre2_match( re, /* el patrón compilado */ subject, /* la cadena de asunto */ subject_length, /* la longitud del asunto */ 0, /* comenzar en el desplazamiento 0 en el asunto */ 0, /* opciones predeterminadas */ match_data, /* bloque para almacenar el resultado */ NULL); /* usar contexto de coincidencia predeterminado */ /* La coincidencia falló: maneja los casos de error */ if (rc < 0) { switch(rc) { case PCRE2_ERROR_NOMATCH: printf("No match\n"); break; /* Maneja otros casos especiales si lo deseas */ default: printf("Matching error %d\n", rc); break; } pcre2_match_data_free(match_data); /* Libera la memoria utilizada para la coincidencia */ pcre2_code_free(re); /* datos y el patrón compilado. */ return 1; } /* Coincidencia exitosa. Obtiene un puntero al vector de salida, donde los desplazamientos de cadena * se almacenan. */ ovector = pcre2_get_ovector_pointer(match_data); printf("Match succeeded at offset %d\n", (int)ovector[0]); /************************************************************************* * Hemos encontrado la primera coincidencia dentro de la cadena de asunto. Si el vector * de salida no era lo suficientemente grande, indícalo. Luego muestra las subcadenas que * fueron capturadas. *************************************************************************/ /* El vector de salida no era lo suficientemente grande. Esto no debería suceder, porque usamos * pcre2_match_data_create_from_pattern() anteriormente. */ if (rc == 0) printf("ovector was not big enough for all the captured substrings\n"); /* Desde la versión 10.38, PCRE2 ha bloqueado el uso de \K en aserciones lookaround * Esto es el comportamiento recomendado. Sin embargo, la opción * PCRE2_EXTRA_ALLOW_LOOKAROUND_BSK permite a las aplicaciones volver a habilitar el comportamiento anterior * antiguo. Si está configurado, es posible ejecutar patrones como /(?=.\K)/ que * usan \K en una aserción para establecer el inicio de una coincidencia después de su final. En este * programa de demostración, mostramos cómo detectar este caso, aunque no puede ocurrir * porque la opción nunca se establece. */ if (ovector[0] > ovector[1]) { printf("\\K was used in an assertion to set the match start after its end.\n" "From end to start the match was: %.*s\n", (int)(ovector[0] - ovector[1]), (char *)(subject + ovector[1])); printf("Run abandoned\n"); pcre2_match_data_free(match_data); pcre2_code_free(re); return 1; } /* Muestra las subcadenas almacenadas en el vector de salida por número. Obviamente, en una aplicación real * podrías querer hacer otras cosas además de imprimirlas. */ for (i = 0; i < rc; i++) { PCRE2_SPTR substring_start = subject + ovector[2*i]; PCRE2_SIZE substring_length = ovector[2*i+1] - ovector[2*i]; printf("%2d: %.*s\n", i, (int)substring_length, (char *)substring_start); } /************************************************************************** * Eso concluye la parte básica de este programa de demostración. Hemos * compilado un patrón y realizado una única coincidencia. El código que sigue * muestra primero cómo acceder a subcadenas con nombre y luego cómo codificar para * coincidencias repetidas en el mismo asunto. **************************************************************************/ /* Comprueba si hay subcadenas con nombre y, si es así, muéstralas por nombre. Primero * tenemos que extraer el recuento de paréntesis con nombre del patrón. */ (void)pcre2_pattern_info( re, /* el patrón compilado */ PCRE2_INFO_NAMECOUNT, /* obtener el número de subcadenas con nombre */ &namecount); /* dónde poner la respuesta */ if (namecount == 0) printf("No named substrings\n"); else { PCRE2_SPTR tabptr; printf("Named substrings\n"); /* Antes de poder acceder a las subcadenas, debemos extraer la tabla para * traducir nombres a números, y el tamaño de cada entrada en la tabla. */ (void)pcre2_pattern_info( re, /* el patrón compilado */ PCRE2_INFO_NAMETABLE, /* dirección de la tabla */ &name_table); /* dónde poner la respuesta */ (void)pcre2_pattern_info( re, /* el patrón compilado */ PCRE2_INFO_NAMEENTRYSIZE, /* tamaño de cada entrada en la tabla */ &name_entry_size); /* dónde poner la respuesta */ /* Ahora podemos escanear la tabla y, para cada entrada, imprimir el número, el nombre, * y la subcadena misma. En la biblioteca de 8 bits, el número se almacena en dos * bytes, primero el más significativo. */ tabptr = name_table; for (i = 0; i < namecount; i++) { int n = (tabptr[0] << 8) | tabptr[1]; printf("(%d) %*s: %.*s\n", n, name_entry_size - 3, tabptr + 2, (int)(ovector[2*n+1] - ovector[2*n]), subject + ovector[2*n]); tabptr += name_entry_size; } } /************************************************************************* * Si se dio la opción "-g" en la línea de comandos, queremos continuar * buscando coincidencias adicionales en la cadena de asunto, de manera similar * a la opción /g en Perl. Esto resulta ser más complicado de lo que parece * debido a la posibilidad de coincidir con una cadena vacía. * * Para ayudar con esta tarea, PCRE2 proporciona la utilidad pcre2_next_match(). *************************************************************************/ if (!find_all) /* Comprobar si hay -g */ { pcre2_match_data_free(match_data); /* Libera la memoria que se utilizó */ pcre2_code_free(re); /* para los datos de coincidencia y el patrón. */ return 0; /* Sale del programa. */ } /* Bucle para la segunda y subsiguientes coincidencias */ ovector_last[0] = ovector[0]; ovector_last[1] = ovector[1]; for (;;) { PCRE2_SIZE start_offset; uint32_t options; /* Después de cada coincidencia exitosa, usamos pcre2_next_match() para obtener la coincidencia * parámetros para intentos de coincidencia posteriores. */ if (!pcre2_next_match(match_data, &start_offset, &options)) break; /* Ejecuta la siguiente operación de coincidencia */ rc = pcre2_match( re, /* el patrón compilado */ subject, /* la cadena de asunto */ subject_length, /* la longitud del asunto */ start_offset, /* desplazamiento de inicio en el asunto */ options, /* opciones */ match_data, /* bloque para almacenar el resultado */ NULL); /* usar contexto de coincidencia predeterminado */ /* Si este intento de coincidencia falla, sal del bucle para coincidencias posteriores. */ if (rc == PCRE2_ERROR_NOMATCH) break; /* Otros errores de coincidencia no son recuperables. */ if (rc < 0) { printf("Matching error %d\n", rc); pcre2_match_data_free(match_data); pcre2_code_free(re); return 1; } /* Este programa de demostración depende de pcre2_next_match() para asegurar que el * bucle para la segunda y subsiguientes coincidencias no se ejecute indefinidamente. Sin embargo, * sería una práctica robusta para una aplicación de producción verificar esto. El siguiente * bloque de código muestra cómo hacerlo. Este caso de error no es alcanzable a menos que * haya un error en PCRE2. * Debido a que este programa no establece la opción PCRE2_EXTRA_ALLOW_LOOKAROUND_BSK, * la lógica es simple. Verificamos que ovector[1] ha avanzado, o que tenemos * una coincidencia vacía tocando el final de una coincidencia no vacía anterior. Ver la * documentación de la API para obtener orientación si y */ pcre2demo(3) - Arch Linux

      }
    }
  }      /* End of loop to find second and subsequent matches */
printf("\n");
pcre2_match_data_free(match_data);
pcre2_code_free(re);
return 0;
}
