pcre_free_study(3)

Paquete: pcre

Licencias: BSD

PCRE_FREE_STUDY(3) Manual de funciones de la biblioteca PCRE_FREE_STUDY(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

void pcre_free_study(pcre_extra *extra);

void pcre16_free_study(pcre16_extra *extra);

void pcre32_free_study(pcre32_extra *extra);

DESCRIPCIÓN

Esta función se utiliza para liberar la memoria utilizada para los datos generados por una llamada a pcre[16|32]_study() cuando ya no se necesita. El argumento debe ser el resultado de dicha llamada.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
