pcap_list_datalinks.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_LIST_DATALINKS(3PCAP) PCAP_LIST_DATALINKS(3PCAP)

NOMBRE

pcap_list_datalinks, pcap_free_datalinks - obtener una lista de los tipos de cabecera de capa de enlace admitidos por un dispositivo de captura, y liberar esa lista

SINOPSIS

#include <pcap/pcap.h>
int pcap_list_datalinks(pcap_t *p, int **dlt_buf);
void pcap_free_datalinks(int *dlt_list);

DESCRIPCIÓN

pcap_list_datalinks() se utiliza para obtener una lista de los tipos de cabecera de capa de enlace admitidos de la interfaz asociada con el descriptor pcap. pcap_list_datalinks() asigna una matriz para contener la lista y establece *dlt_buf para que apunte a esa matriz.

El llamador es responsable de liberar la matriz con pcap_free_datalinks(), que libera la lista de tipos de cabecera de capa de enlace apuntada por dlt_list.

No se debe llamar en un descriptor pcap creado por pcap_create(3PCAP) que aún no haya sido activado por pcap_activate(3PCAP).

VALOR DE RETORNO

pcap_list_datalinks() devuelve el número de tipos de cabecera de capa de enlace en la matriz en caso de éxito, PCAP_ERROR_NOT_ACTIVATED si se llama en un manejador de captura que ha sido creado pero no activado, y PCAP_ERROR en otros errores. Si se devuelve PCAP_ERROR, se puede llamar a pcap_geterr(3PCAP) o pcap_perror(3PCAP) con p como argumento para obtener o mostrar el texto del error.

VER TAMBIÉN

pcap(3PCAP), pcap_datalink_val_to_name(3PCAP), pcap-linktype(7)
