PCP-BUDDYINFO(1) Manual de comandos generales PCP-BUDDYINFO(1)

NOMBRE

pcp-buddyinfo - informa estadísticas del algoritmo buddy del kernel de Linux

SINOPSIS

pcp [opciones-pcp] buddyinfo [-uVz?] [-s muestras] [-a archivo] [-Z zona-horaria]

DESCRIPCIÓN

El comando pcp-buddyinfo se utiliza para ver diferentes estadísticas relacionadas con buddyinfo. Ayuda a los usuarios a analizar el comportamiento dinámico del algoritmo buddy utilizado en el subsistema de memoria virtual del kernel de Linux. La información incluye el número total de zonas que están actualmente activas, recuentos de páginas de diferentes órdenes, etc. Por defecto, pcp-buddyinfo informa datos en vivo para el host local.

Las estadísticas que se muestran son las siguientes:

DESCRIPCIÓN DE LA CABECERA
_ _
Zonas normales disponibles
Nodos de nodos disponibles
Páginas disponibles de orden 0
Páginas disponibles de orden 1
Páginas disponibles de orden 2
Páginas disponibles de orden 3
Páginas disponibles de orden 4
Páginas disponibles de orden 5
Páginas disponibles de orden 6
Páginas disponibles de orden 7
Páginas disponibles de orden 8
Páginas disponibles de orden 9
Páginas disponibles de orden 10

Cada columna representa el número de páginas de un cierto orden (un cierto tamaño) que están disponibles en cualquier momento dado. Por ejemplo, para la zona DMA (acceso directo a memoria), hay 90 fragmentos de memoria de 2^(0*PAGE_SIZE). De manera similar, hay 6 fragmentos de 2^(1*PAGE_SIZE) y 2 fragmentos de 2^(2*PAGE_SIZE) de memoria disponibles.

La fila DMA hace referencia a los primeros 16 MB en un sistema, la fila HighMem hace referencia a toda la memoria superior a 4 GB en un sistema, y la fila Normal hace referencia a toda la memoria intermedia.

OPCIONES

-a archivo, --archivo=archivo
Obtiene las métricas de buddyinfo del archivo PCP especificado.
-s contador, --muestras=contador
Limita el informe a contador muestras de estadísticas de buddyinfo.
-u, --no-interpol
deshabilita el modo de interpolación predeterminado al reproducir un archivo. Con la opción -u, la generación de informes interpolados se deshabilita y cada muestra se informa de acuerdo con los intervalos de muestreo nativos en el archivo. En este modo, la opción -t se ignora. Además, la reproducción no interpolada solo tiene sentido al reproducir un archivo (usando la opción -a descrita anteriormente), por lo que la opción -a es obligatoria cuando se especifica -u.
-z, --zona-horaria-host
Usa la zona horaria local del host que es la fuente de las métricas de rendimiento, según lo identificado por las opciones -h o -a. Por defecto, se utiliza la zona horaria del host local.
-Z zona-horaria, --zona-horaria=zona-horaria
Utiliza zona-horaria para la fecha y hora. zona-horaria está en el formato de la variable de entorno TZ como se describe en environ(7).
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

NOTAS

pcp-buddyinfo informa información extraída del archivo /proc/buddyinfo del procfs del kernel de Linux.

Si se deshabilita el modo de interpolación predeterminado, es posible que algunas métricas (registradas en diferentes intervalos) se informen como que tienen valores faltantes para algunas muestras, incluso si fueron registradas.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN
