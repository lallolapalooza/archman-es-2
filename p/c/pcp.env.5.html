PCP.ENV(5) Manual de formatos de archivo PCP.ENV(5)

NOMBRE

pcp.env - script para establecer variables de entorno de ejecución de Performance Co-Pilot

SINOPSIS

/etc/pcp.env

DESCRIPCIÓN

El script pcp.env es incluido por varios scripts y utilidades de Performance Co-Pilot (PCP) para definir las variables de entorno de operación de PCP. El conjugado para programas ejecutables que usan las librerías de PCP es la función pmGetConfig(3).

Uso típico de pcp.env en un script es como sigue :


#! /bin/sh


# incluir las variables de entorno de PCP
. /etc/pcp.env
resto del script ...

La sintaxis y semántica completas del archivo pcp.conf y la función pmGetConfig se describen en sus respectivas páginas de referencia.

Si el archivo $HOME/.pcp/pcp.conf existe, entonces será procesado después del archivo pcp.conf a nivel de sistema. Esto proporciona un mecanismo para modificar o aumentar selectivamente la configuración del entorno para los scripts de PCP, lo que puede ser útil si los scripts se ejecutan con sudo(1), que limpia el entorno de configuraciones importantes que son necesarias para asegurar la ejecución correcta de los scripts de PCP, por ejemplo, $PATH o $PERL5LIB.

ENTORNO

La variable de entorno PCP_CONF especifica una ruta alternativa al archivo pcp.conf.

VER TAMBIÉN

PCPIntro(1), sudo(1), PCPIntro(3), PMAPI(3), pmGetConfig(3) y pcp.conf(5).
