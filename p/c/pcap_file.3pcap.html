NOMBRE

pcap_file - obtener el flujo de E/S estándar de un archivo de guardado que se está leyendo

SINOPSIS

#include <pcap/pcap.h>
FILE *pcap_file(pcap_t *p);

DESCRIPCIÓN

pcap_file() devuelve el flujo de E/S estándar del ``archivo de guardado'', si se abrió un ``archivo de guardado'' con pcap_open_offline(3PCAP), o NULL, si se abrió un dispositivo de red con pcap_create(3PCAP) y pcap_activate(3PCAP), o con pcap_open_live(3PCAP).

Tenga en cuenta que la biblioteca Packet Capture generalmente se compila con soporte para archivos grandes, por lo que el flujo de E/S estándar del ``archivo de guardado'' puede referirse a un archivo de más de 2 gigabytes; las aplicaciones que utilizan pcap_file() deben, si es posible, utilizar llamadas que soporten archivos grandes en el valor devuelto por pcap_file() o el valor devuelto por fileno(3) cuando se le pasa el valor devuelto por pcap_file().
