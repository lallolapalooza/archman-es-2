pcre_study(3)

Paquete: pcre

Licencias: BSD

PCRE_STUDY(3) Manual de funciones de la biblioteca PCRE_STUDY(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

pcre_extra *pcre_study(const pcre *code, int options,
     const char **errptr);

pcre16_extra *pcre16_study(const pcre16 *code, int options,
     const char **errptr);

pcre32_extra *pcre32_study(const pcre32 *code, int options,
     const char **errptr);

DESCRIPCIÓN

Esta función estudia un patrón compilado, para ver si se puede extraer información adicional que podría acelerar la coincidencia. Sus argumentos son:


code Una expresión regular compilada
options Opciones para pcre[16|32]_study()
errptr Dónde poner un mensaje de error

Si la función tiene éxito, devuelve un valor que puede pasarse a pcre[16|32]_exec() o pcre[16|32]_dfa_exec() a través de sus argumentos extra.

Si la función devuelve NULL, o no pudo encontrar información adicional, o hubo un error. Puedes distinguir la diferencia mirando el valor de error. Es NULL en el primer caso.

La única opción es PCRE_STUDY_JIT_COMPILE. Solicita la compilación just-in-time si es posible. Si PCRE se ha compilado sin soporte JIT, esta opción se ignora. Consulte la página pcrejit para obtener más detalles.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
