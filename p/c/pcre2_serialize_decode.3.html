pcre2_serialize_decode(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SERIALIZE_DECODE(3) Manual de Funciones de Librería PCRE2_SERIALIZE_DECODE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int32_t pcre2_serialize_decode(pcre2_code **codes,
  int32_t number_of_codes, const uint8_t *bytes,
  pcre2_general_context *gcontext);

DESCRIPCIÓN

Esta función decodifica un conjunto serializado de patrones compilados de vuelta a una lista de patrones individuales. Esto solo es posible en un host que esté ejecutando la misma versión de PCRE2, con la misma anchura de unidad de código, y el host también debe tener la misma endianidad, anchura de puntero y tipo PCRE2_SIZE. Los argumentos para pcre2_serialize_decode() son:


codes puntero a un vector en el que construir la lista
number_of_codes número de ranuras en el vector
bytes el flujo de bytes serializado
gcontext puntero a un contexto general o NULL

El argumento bytes debe apuntar a un bloque de datos que fue creado originalmente por pcre2_serialize_encode(), aunque haya podido ser guardado en disco o en otro lugar mientras tanto. Si hay más códigos en los datos serializados que ranuras en la lista, solo se decodifican aquellos patrones compilados que quepan. El resultado de la función es el número de patrones decodificados, o uno de los siguientes códigos de error negativos:


PCRE2_ERROR_BADDATA number_of_codes es cero o menor
PCRE2_ERROR_BADMAGIC desajuste de bytes de id en bytes
PCRE2_ERROR_BADMODE desajuste de tamaño de unidad variable o versión de PCRE
PCRE2_ERROR_NOMEMORY fallo en la asignación de memoria
PCRE2_ERROR_NULL codes o bytes es NULL

PCRE2_ERROR_BADMAGIC puede significar que los datos están corruptos, o que fueron compilados en un sistema con diferente endianidad.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de las funciones de serialización en la página pcre2serialize.
