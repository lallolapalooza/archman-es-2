PCRE2_CONFIG(3) Manual de funciones de biblioteca PCRE2_CONFIG(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_config(uint32_t what, void *where);

DESCRIPCIÓN

Esta función permite a un programa cliente averiguar qué características opcionales están disponibles en la versión de la biblioteca PCRE2 que está utilizando. Los argumentos son los siguientes:


what Un código que especifica qué información se requiere
where Puntero a dónde colocar la información

Si where es NULL, la función devuelve la cantidad de memoria necesaria para la información solicitada. Cuando la información es una cadena, el valor está en unidades de código; para otros tipos de datos está en bytes.

Si where no es NULL, para PCRE2_CONFIG_JITTARGET, PCRE2_CONFIG_UNICODE_VERSION y PCRE2_CONFIG_VERSION debe apuntar a un búfer que sea lo suficientemente grande como para contener la cadena. Para todos los demás códigos debe apuntar a una variable entera uint32_t. Los códigos disponibles son:


PCRE2_CONFIG_BSR Indica qué coincide con \R por defecto:
PCRE2_BSR_UNICODE
PCRE2_BSR_ANYCRLF
PCRE2_CONFIG_COMPILED_WIDTHS Qué soporte de 8/16/32 fue compilado
PCRE2_CONFIG_DEPTHLIMIT Límite de retroceso por defecto
PCRE2_CONFIG_EFFECTIVE_LINKSIZE Cuántos bytes se usan para el tamaño del enlace
PCRE2_CONFIG_HEAPLIMIT Límite de memoria del montón por defecto
PCRE2_CONFIG_JIT Disponibilidad del compilador just-in-time
soporte (1=sí 0=no)
PCRE2_CONFIG_JITTARGET Información (una cadena) sobre la arquitectura
de destino para el compilador JIT
PCRE2_CONFIG_LINKSIZE Tamaño de enlace interno configurado (2, 3, 4)
PCRE2_CONFIG_MATCHLIMIT Límite de recursos interno por defecto
PCRE2_CONFIG_NEVER_BACKSLASH_C Si \C está deshabilitado o no
PCRE2_CONFIG_NEWLINE Código para la secuencia de nueva línea por defecto:
PCRE2_NEWLINE_CR
PCRE2_NEWLINE_LF
PCRE2_NEWLINE_CRLF
PCRE2_NEWLINE_ANY
PCRE2_NEWLINE_ANYCRLF
PCRE2_NEWLINE_NUL
PCRE2_CONFIG_PARENSLIMIT Límite de anidamiento de paréntesis por defecto
PCRE2_CONFIG_RECURSIONLIMIT Obsoleto: usar PCRE2_CONFIG_DEPTHLIMIT
PCRE2_CONFIG_STACKRECURSE Obsoleto: siempre devuelve 0
PCRE2_CONFIG_UNICODE Disponibilidad de soporte Unicode
(1=sí 0=no)
PCRE2_CONFIG_UNICODE_VERSION La versión de Unicode (una cadena)
PCRE2_CONFIG_VERSION La versión de PCRE2 (una cadena)

La función devuelve un valor no negativo en caso de éxito o el valor negativo PCRE2_ERROR_BADOPTION en caso contrario. Este es también el resultado para el código PCRE2_CONFIG_JITTARGET si el soporte JIT no está disponible. Cuando se solicita una cadena, la función devuelve el número de unidades de código utilizadas, incluido el cero de terminación.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
