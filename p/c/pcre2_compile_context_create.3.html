Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_COMPILE_CONTEXT_CREATE(3) Manual de funciones de la biblioteca PCRE2_COMPILE_CONTEXT_CREATE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

pcre2_compile_context *pcre2_compile_context_create(
  pcre2_general_context *gcontext);

DESCRIPCIÓN

Esta función crea e inicializa un nuevo contexto de compilación. Si su argumento es NULL, se utiliza malloc() para obtener la memoria necesaria; de lo contrario, se utiliza la función de asignación de memoria dentro del contexto general. El resultado es NULL si no se pudo obtener la memoria.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
