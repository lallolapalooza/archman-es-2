pcre_jit_stack_free(3)

Paquete: pcre

Licencias: BSD

PCRE_JIT_STACK_FREE(3) Manual de funciones de biblioteca PCRE_JIT_STACK_FREE(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

void pcre_jit_stack_free(pcre_jit_stack *stack);

void pcre16_jit_stack_free(pcre16_jit_stack *stack);

void pcre32_jit_stack_free(pcre32_jit_stack *stack);

DESCRIPCIÓN

Esta función se utiliza para liberar una pila JIT que se creó mediante pcre[16|32]_jit_stack_alloc() cuando ya no se necesita. Para más detalles, consulte la página pcrejit.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
