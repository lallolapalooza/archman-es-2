PCAP_DUMP_FILE(3PCAP) PCAP_DUMP_FILE(3PCAP)

NOMBRE

pcap_dump_file - obtener el flujo de E/S estándar de un archivo de guardado que se está escribiendo

SINOPSIS

#include <pcap/pcap.h>
FILE *pcap_dump_file(pcap_dumper_t *p);

DESCRIPCIÓN

pcap_dump_file() devuelve el flujo de E/S estándar del ``archivo de guardado'' abierto por pcap_dump_open(3PCAP).

VER TAMBIÉN
