PCP.CONF(5) Manual de Formatos de Archivo PCP.CONF(5)

NOMBRE

pcp.conf - archivo de configuración y entorno de Performance Co-Pilot

SINOPSIS

/etc/pcp.conf

DESCRIPCIÓN

Al usar las herramientas y utilidades de Performance Co-Pilot (PCP) y al llamar a funciones de la biblioteca PCP, se define un conjunto estándar de variables de entorno en /etc/pcp.conf. Estas variables se usan generalmente para especificar la ubicación de varias partes de PCP en el sistema de archivos y pueden cargarse en scripts de shell mediante el script de shell /etc/pcp.env(5) y consultarse mediante programas C/C++ utilizando la función de biblioteca pmGetConfig(3). Si una variable ya está definida en el entorno, los valores de pcp.conf no anulan esos valores, es decir, los valores de pcp.conf solo sirven como valores predeterminados de instalación.

Se espera que los archivos pcp.env y pcp.conf se encuentren en /etc por defecto. Si es necesario, el archivo pcp.conf puede reubicarse y establecerse PCP_CONF en el entorno para especificar la ruta completa a la nueva ubicación. El archivo pcp.env no se puede reubicar (este es el único camino codificado que requiere PCP).

Las reglas de sintaxis para pcp.conf son las siguientes:

1.
la sintaxis general es

PCP_NOMBRE_VARIABLE=valor de variable hasta el final de la línea
2.
las líneas que comienzan con # y todas las líneas en blanco se ignoran.
3.
todas las variables deben prefijarse con PCP_. Este es un problema de seguridad: las variables que no tienen este prefijo se ignorarán silenciosamente.
4.
no debe haber espacio entre el nombre de la variable y el literal = ni espacio entre el = y el valor de la variable (a menos que el valor realmente comience con un espacio). Esto es necesario porque el archivo pcp.conf puede ser interpretado directamente por Makefiles, así como por el script pcp.env y la función pmGetConfig.
5.
los valores de las variables pueden contener espacios y no deben estar entre comillas. El script pcp.env cita automáticamente todos los valores de las variables desde el carácter inmediatamente posterior al = hasta el final de la línea.

Para obtener más detalles y una explicación del uso de cada variable, consulte los comentarios en el propio archivo /etc/pcp.conf.

ENTORNO

La variable de entorno PCP_CONF especifica una ruta alternativa al archivo pcp.conf.

VER TAMBIÉN

PCPIntro(1), pmconfig(1), PCPIntro(3), PMAPI(3), pmGetConfig(3) y pcp.env(5).
