PCRE2_JIT_COMPILE(3) Manual de funciones de la biblioteca PCRE2_JIT_COMPILE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_jit_compile(pcre2_code *code, uint32_t options);

DESCRIPCIÓN

Esta función solicita la compilación JIT, que, si el compilador just-in-time está disponible, procesa aún más un patrón compilado en código máquina que se ejecuta mucho más rápido que la función de coincidencia interpretada pcre2_match(). Los detalles completos se dan en la documentación de pcre2jit.

La disponibilidad de soporte JIT se puede probar llamando a pcre2_compile_jit() con una única opción PCRE2_JIT_TEST_ALLOC (el argumento code se ignora, por lo que se acepta un valor NULL). Dicha llamada devuelve cero si JIT está disponible y tiene un asignador que funciona. De lo contrario, devuelve PCRE2_ERROR_NOMEMORY si JIT está disponible pero no puede asignar memoria ejecutable, o PCRE2_ERROR_JIT_UNSUPPORTED si el soporte JIT no está compilado.

De lo contrario, el primer argumento debe ser un puntero devuelto por una llamada exitosa a pcre2_compile(), y el segundo debe contener uno o más de los siguientes bits:


PCRE2_JIT_COMPLETE compila código para coincidencias completas
PCRE2_JIT_PARTIAL_SOFT compila código para coincidencias parciales suaves
PCRE2_JIT_PARTIAL_HARD compila código para coincidencias parciales duras

También existe una opción obsoleta llamada PCRE2_JIT_INVALID_UTF, que ha sido sustituida por la opción PCRE2_MATCH_INVALID_UTF de pcre2_compile(). La opción antigua está obsoleta y puede eliminarse en el futuro.

El resultado de la función cuando se llama con cualquiera de las tres opciones anteriores es 0 para el éxito, o un código de error negativo en caso contrario. En particular, PCRE2_ERROR_JIT_BADOPTION se devuelve si JIT no es compatible o si se establece un bit desconocido en options. La función también puede devolver PCRE2_ERROR_NOMEMORY si JIT no puede asignar memoria ejecutable para el compilador, incluso si fue debido a una restricción de seguridad del sistema. En algunos casos, la función puede devolver PCRE2_ERROR_JIT_UNSUPPORTED para características no compatibles.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
