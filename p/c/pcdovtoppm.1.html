NOMBRE

pcdovtoppm - crear imagen de índice para un CD de fotos

SINOPSIS

pcdovtoppm [-m ancho] [-s tamaño] [-a a_lo_ancho] [-c colores] [-f fuente] [-b|-w] [archivo_pcd]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

Este programa genera una imagen de índice en formato PPM para un CD de fotos, basándose en el archivo de vista general del CD de fotos.

Puedes lograr un resultado similar con hpcdtoppm -Overview seguido de pnmindex -black en las imágenes PPM generadas.

OPCIONES

-wancho
Ancho máximo de la imagen resultante (por defecto: 1152).
-stamaño
Tamaño máximo de cada una de las imágenes (por defecto: 192).
-aa_lo_ancho
Número máximo de imágenes a lo ancho (por defecto: 6).
-ccolores
Número máximo de colores, o n

para indicar que no hay cuantificación

-ffuente
Fuente a utilizar para la anotación (por defecto: fuente interna).
-b
Color de fondo negro (por defecto).
-w
Color de fondo blanco.

EJEMPLOS

pcdovtoppm -m 768 -s 96 -f smallfont.pbm overview.pcd > overview.ppm
pcdovtoppm /cdrom/photo_cd/overview.pcd | ppmtojpeg > overview.jpg

HISTORIA

Anteriormente, este programa se llamaba pcdindex, lo que no se ajustaba a las convenciones de nombres de Netpbm.
