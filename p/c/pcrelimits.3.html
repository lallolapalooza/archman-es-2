NOMBRE

PCRE - expresiones regulares compatibles con Perl

TAMAÑO Y OTRAS LIMITACIONES

Existen algunas limitaciones de tamaño en PCRE, pero se espera que en la práctica nunca sean relevantes.

La longitud máxima de un patrón compilado es aproximadamente 64K unidades de datos (bytes para la biblioteca de 8 bits, unidades de 16 bits para la biblioteca de 16 bits y unidades de 32 bits para la biblioteca de 32 bits) si PCRE se compila con el tamaño de enlace interno predeterminado, que es de 2 bytes para las bibliotecas de 8 y 16 bits, y de 4 bytes para la biblioteca de 32 bits. Si desea procesar expresiones regulares verdaderamente enormes, puede compilar PCRE con un tamaño de enlace interno de 3 o 4 (al compilar la biblioteca de 16 o 32 bits, 3 se redondea a 4). Consulte el archivo README en la distribución fuente y la documentación de pcrebuild para obtener más detalles. En estos casos, el límite es sustancialmente mayor. Sin embargo, la velocidad de ejecución es más lenta.

Todos los valores en cuantificadores repetitivos deben ser menores que 65536.

No hay límite en el número de subpatrones entre paréntesis, pero no puede haber más de 65535 subpatrones de captura. Sin embargo, hay un límite en la profundidad de anidamiento de subpatrones entre paréntesis de todo tipo. Esto se impone para limitar la cantidad de pila del sistema utilizada en tiempo de compilación. El límite se puede especificar al compilar PCRE; el valor predeterminado es 250.

Existe un límite en el número de referencias directas a subpatrones posteriores de alrededor de 200.000. Las referencias directas repetidas con límites superiores fijos, por ejemplo, (?2){0,100} cuando el subpatrón número 2 está a la derecha, se incluyen en el recuento. No hay límite en el número de referencias inversas.

La longitud máxima del nombre para un subpatrón con nombre es de 32 caracteres, y el número máximo de subpatrones con nombre es de 10000.

La longitud máxima de un nombre en un verbo (*MARK), (*PRUNE), (*SKIP) o (*THEN) es de 255 para la biblioteca de 8 bits y de 65535 para las bibliotecas de 16 y 32 bits.

La longitud máxima de una cadena de sujeto es el número positivo más grande que puede contener una variable entera. Sin embargo, al usar la función de coincidencia tradicional, PCRE utiliza recursión para manejar subpatrones y repeticiones indefinidas. Esto significa que el espacio de pila disponible puede limitar el tamaño de una cadena de sujeto que puede ser procesada por ciertos patrones. Para una discusión sobre problemas de pila, consulte la documentación de pcrestack.
