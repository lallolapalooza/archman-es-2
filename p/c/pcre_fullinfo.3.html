pcre_fullinfo(3)

Paquete: pcre

Licencias: BSD

PCRE_FULLINFO(3) Manual de funciones de biblioteca PCRE_FULLINFO(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_fullinfo(const pcre *code, const pcre_extra *extra,
     int what, void *where);

int pcre16_fullinfo(const pcre16 *code, const pcre16_extra *extra,
     int what, void *where);

int pcre32_fullinfo(const pcre32 *code, const pcre32_extra *extra,
     int what, void *where);

DESCRIPCIÓN

Esta función devuelve información sobre un patrón compilado. Sus argumentos son:


code Expresión regular compilada
extra Resultado de pcre[16|32]_study() o NULL
what Qué información se requiere
where Dónde poner la información

La siguiente información está disponible:


PCRE_INFO_BACKREFMAX Número de referencia inversa más alta
PCRE_INFO_CAPTURECOUNT Número de subpatrones de captura
PCRE_INFO_DEFAULT_TABLES Puntero a las tablas predeterminadas
PCRE_INFO_FIRSTBYTE Unidad de datos fija para una coincidencia, o
-1 para inicio de cadena
o después de una nueva línea, o
-2 de lo contrario
PCRE_INFO_FIRSTTABLE Tabla de primeras unidades de datos (después de estudiar)
PCRE_INFO_HASCRORLF Devuelve 1 si existen coincidencias explícitas de CR o LF
PCRE_INFO_JCHANGED Devuelve 1 si se usó (?J) o (?-J)
PCRE_INFO_JIT 1 después de una compilación JIT exitosa
PCRE_INFO_JITSIZE Tamaño del código compilado JIT
PCRE_INFO_LASTLITERAL Unidad de datos literal final requerida
PCRE_INFO_MINLENGTH Límite inferior de la longitud de las cadenas coincidentes
PCRE_INFO_MATCHEMPTY Devuelve 1 si el patrón puede coincidir con una cadena vacía,
0 de lo contrario
PCRE_INFO_MATCHLIMIT Límite de coincidencia si se estableció, de lo contrario PCRE_RROR_UNSET
PCRE_INFO_MAXLOOKBEHIND Longitud (en caracteres) de la aserción de mirada hacia atrás más larga
PCRE_INFO_NAMECOUNT Número de subpatrones con nombre
PCRE_INFO_NAMEENTRYSIZE Tamaño de la entrada de la tabla de nombres
PCRE_INFO_NAMETABLE Puntero a la tabla de nombres
PCRE_INFO_OKPARTIAL Devuelve 1 si se pueden intentar coincidencias parciales
(siempre devuelve 1 después de la versión 8.00)
PCRE_INFO_OPTIONS Bits de opción utilizados para la compilación
PCRE_INFO_SIZE Tamaño del patrón compilado
PCRE_INFO_STUDYSIZE Tamaño de los datos de estudio
PCRE_INFO_FIRSTCHARACTER Unidad de datos fija para una coincidencia
PCRE_INFO_FIRSTCHARACTERFLAGS Devuelve
1 si hay un conjunto de caracteres de datos inicial, que
puede recuperarse usando PCRE_INFO_FIRSTCHARACTER,
2 si el primer carácter está al inicio de la cadena
de datos o después de una nueva línea, y
0 de lo contrario
PCRE_INFO_RECURSIONLIMIT Límite de recursión si se estableció, de lo contrario PCRE_ERROR_UNSET
PCRE_INFO_REQUIREDCHAR Unidad de datos literal final requerida
PCRE_INFO_REQUIREDCHARFLAGS Devuelve 1 si se establece el último carácter de datos (que puede entonces
ser recuperado usando PCRE_INFO_REQUIREDCHAR); 0 de lo contrario

El argumento where debe apuntar a una variable entera, excepto para los siguientes valores de what:


PCRE_INFO_DEFAULT_TABLES const uint8_t *
PCRE_INFO_FIRSTCHARACTER uint32_t
PCRE_INFO_FIRSTTABLE const uint8_t *
PCRE_INFO_JITSIZE size_t
PCRE_INFO_MATCHLIMIT uint32_t
PCRE_INFO_NAMETABLE PCRE_SPTR16 (biblioteca de 16 bits)
PCRE_INFO_NAMETABLE PCRE_SPTR32 (biblioteca de 32 bits)
PCRE_INFO_NAMETABLE const unsigned char * (biblioteca de 8 bits)
PCRE_INFO_OPTIONS unsigned long int
PCRE_INFO_SIZE size_t
PCRE_INFO_STUDYSIZE size_t
PCRE_INFO_RECURSIONLIMIT uint32_t
PCRE_INFO_REQUIREDCHAR uint32_t

El resultado de la función es cero si tiene éxito o:


PCRE_ERROR_NULL el argumento code era NULL
el argumento where era NULL
PCRE_ERROR_BADMAGIC no se encontró el "número mágico"
PCRE_ERROR_BADOPTION el valor de what era inválido
PCRE_ERROR_UNSET la opción no estaba configurada

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
