NOMBRE

pcp-htop - visor interactivo de procesos

SINOPSIS

htop [-dCFhpustvH]
pcp-htop [-dCFhpustvH] [--host/-h host]

DESCRIPCIÓN

htop es un visor de procesos multiplataforma basado en ncurses.

Es similar a top, pero permite desplazarse vertical y horizontalmente, e interactuar usando un dispositivo señalador (ratón). Puede observar todos los procesos que se ejecutan en el sistema, junto con los argumentos de su línea de comandos, así como verlos en formato de árbol, seleccionar múltiples procesos y actuar sobre ellos a la vez.

Las tareas relacionadas con los procesos (matar, cambiar prioridad) se pueden realizar sin necesidad de introducir sus PID.

pcp-htop es una versión de htop compilada usando la API de Métricas de Performance Co-Pilot (PCP) (ver PCPIntro(1), PMAPI(3)), lo que permite extender htop para mostrar valores de métricas arbitrarias. Ver la sección de abajo titulada ARCHIVOS DE CONFIGURACIÓN para más detalles.

OPCIONES DE LÍNEA DE COMANDOS

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-d --delay=RETRASO
Retraso entre actualizaciones, en décimas de segundo. Si el valor del retraso es menor que 1, se incrementa a 1, es decir, 1/10 de segundo. Si el valor del retraso es mayor que 100, se decrementa a 100, es decir, 10 segundos.
-C --no-color --no-colour
Iniciar htop en modo monocromático
-F --filter=FILTRO
Filtrar procesos por términos que coincidan con los comandos. Los términos se comparan sin distinción de mayúsculas y minúsculas y como cadenas fijas (no expresiones regulares). Puedes separar múltiples términos con "|".
--no-function-bar
Ocultar la barra de funciones
-h --help
Mostrar un mensaje de ayuda y salir
-p --pid=PID,PID...
Mostrar solo los PID dados
-s --sort-key COLUMNA
Ordenar por esta columna (usar --sort-key help para una lista de columnas). Esto forzará una vista de lista a menos que especifiques -t al mismo tiempo. La ordenación en modo árbol se aplica a los hijos directos de cada proceso.
-u --user[=NOMBREDEUSUARIO|UID]
Mostrar solo los procesos de un usuario dado, o el propio si se omite
-U --no-unicode
No usar caracteres unicode sino ASCII para los medidores gráficos
-M --no-mouse
Deshabilitar el soporte del control del ratón
--no-meters
Ocultar los medidores gráficos
--readonly
Deshabilitar todas las funciones de cambio de sistema y de procesos
-V --version
Mostrar información de la versión y salir
-t --tree
Mostrar procesos en vista de árbol. Esto se puede usar para forzar una vista de árbol al solicitar un orden de clasificación con -s. Seleccionar una vista de clasificación saldrá de la vista de árbol.
-H --highlight-changes=RETRASO
Resaltar procesos nuevos y antiguos
--drop-capabilities[=off|basic|strict]
Solo Linux; esta opción debe haber sido habilitada en tiempo de compilación y requiere soporte de libcap en tiempo de ejecución.
Eliminar capacidades de Linux innecesarias. En modo estricto, las funciones como matar, cambiar prioridades de procesos y leer información de contabilidad de retrasos de procesos no funcionarán debido a la menor cantidad de capacidades que se mantienen.

COMANDOS INTERACTIVOS

Los siguientes comandos son compatibles mientras se está en htop:

Tab, Shift-Tab
Seleccionar la pestaña de pantalla siguiente / anterior para mostrar. Puedes habilitar la visualización de los nombres de las pestañas de pantalla en la pantalla de Configuración (F2).
Arriba, Alt-k
Seleccionar (resaltar) el proceso anterior en la lista de procesos. Desplazar la lista si es necesario.
Abajo, Alt-j
Seleccionar (resaltar) el proceso siguiente en la lista de procesos. Desplazar la lista si es necesario.
Izquierda, Alt-h
Desplazar la lista de procesos hacia la izquierda.
Derecha, Alt-l
Desplazar la lista de procesos hacia la derecha.
RePág, AvPág
Desplazar la lista de procesos hacia arriba o hacia abajo una ventana.
Inicio
Desplazarse a la parte superior de la lista de procesos y seleccionar el primer proceso.
Fin
Desplazarse a la parte inferior de la lista de procesos y seleccionar el último proceso.
Ctrl-A, ^
Desplazarse a la izquierda hasta el principio de la entrada del proceso (es decir, al principio de la línea).
Ctrl-E, $
Desplazarse a la derecha hasta el final de la entrada del proceso (es decir, al final de la línea).
Espacio
Marcar o desmarcar un proceso. Los comandos que pueden operar sobre múltiples procesos, como "kill", se aplicarán a la lista de procesos marcados, en lugar del proceso actualmente resaltado.
c
Marcar el proceso actual y sus hijos. Los comandos que pueden operar sobre múltiples procesos, como "kill", se aplicarán a la lista de procesos marcados, en lugar del proceso actualmente resaltado.
U
Desmarcar todos los procesos (eliminar todas las marcas añadidas con las teclas Espacio o c).
s
Rastrear llamadas al sistema del proceso: si strace(1) está instalado, presionar esta tecla lo adjuntará al proceso seleccionado actualmente, presentando una actualización en vivo de las llamadas al sistema emitidas por el proceso.
l
Mostrar los archivos abiertos para un proceso: si lsof(1) está instalado, presionar esta tecla mostrará la lista de descriptores de archivos abiertos por el proceso.
w
Mostrar la línea de comandos del proceso seleccionado en una pantalla separada, ajustada en múltiples líneas según sea necesario.
x
Mostrar los bloqueos de archivos activos del proceso seleccionado en una pantalla separada.
F1, h, ?
Ir a la pantalla de ayuda
F2, S
Ir a la pantalla de configuración, donde puedes configurar los medidores que se muestran en la parte superior de la pantalla, establecer varias opciones de visualización, elegir entre esquemas de color y seleccionar qué columnas se muestran, en qué orden.
F3, /
Buscar incrementalmente las líneas de comandos de todos los procesos mostrados. El comando actualmente seleccionado (resaltado) se actualizará a medida que escribas. Mientras estás en modo de búsqueda, presionar F3 recorrerá las ocurrencias coincidentes. Presionar Shift-F3 recorrerá hacia atrás.

Alternativamente, la búsqueda se puede iniciar simplemente escribiendo el comando que estás buscando, aunque para el primer carácter, las combinaciones de teclas normales tienen prioridad.

F4, 
Filtrado incremental de procesos: escribe parte de la línea de comandos de un proceso y solo se mostrarán los procesos que coincidan. Para cancelar el filtrado, vuelve a entrar en la opción Filtro y presiona Esc. La coincidencia se realiza sin distinción de mayúsculas y minúsculas. Los términos son cadenas fijas (sin expresiones regulares). Puedes separar múltiples términos con "|".
F5, t
Vista de árbol: organiza los procesos por parentesco y presenta las relaciones entre ellos como un árbol. Alternar la tecla cambiará entre la vista de árbol y la vista de ordenación seleccionada previamente. Seleccionar una vista de ordenación saldrá de la vista de árbol.
F6, <, >
Selecciona un campo para ordenar, también accesible a través de < y >. El campo de ordenación actual se indica con un resaltado en la cabecera.
F7, ]
Aumentar la prioridad del proceso seleccionado.

COLUMNAS

Las siguientes columnas pueden mostrar datos sobre cada proceso. Un valor de '-' en todas las filas indica que una columna no es compatible en tu sistema o que actualmente no está implementada en htop. Los nombres a continuación son los que se utilizan en la sección "Columnas Disponibles" de la pantalla de configuración. Si se muestra un nombre diferente en la pantalla principal de htop, se muestra a continuación entre paréntesis.

Comando
La línea de comando completa del proceso (es decir, nombre del programa y argumentos).

Si la opción 'Fusionar exe, comm y cmdline en Comando' (activada por la tecla 'm') está activa, la ruta del ejecutable (/proc/[pid]/exe) y el nombre del comando (/proc/[pid]/comm) también se muestran fusionados con la línea de comando, si están disponibles.

El nombre base del programa se resalta si está configurado. Se pueden configurar resaltados adicionales para ejecutables obsoletos (ver columna EXE a continuación).

La columna Comando debe ser la última columna en cada pantalla, ya que puede ser muy larga y se beneficia de poder extender su longitud dinámicamente.

Resaltado de color adicional:

•
Magenta: nombres de comando de procesos regulares
•
Azul negrita: nombres de hilos de espacio de usuario
•
Gris negrita: hilos del kernel o procesos sin nombre de comando
COMM
El nombre del comando del proceso obtenido de /proc/[pid]/comm, si es legible.

Requiere kernel de Linux 2.6.33 o posterior.

EXE
El nombre base abreviado del ejecutable del proceso, obtenido de /proc/[pid]/exe, si es legible. htop puede leer este archivo en linux para TODOS los procesos solo si tiene la capacidad CAP_SYS_PTRACE o privilegios de root.

El nombre base se marca en rojo si el ejecutable utilizado para ejecutar el proceso ha sido reemplazado o eliminado del disco desde que el proceso se inició. La información se obtiene procesando el contenido de /proc/[pid]/exe.

Además, el nombre base se marca en amarillo si alguna biblioteca se reporta como reemplazada o eliminada del disco desde que se cargó por última vez. La información se obtiene procesando el contenido de /proc/[pid]/maps.

Al decidir el color, el reemplazo del ejecutable principal siempre tiene prioridad sobre el reemplazo de cualquier otra biblioteca. Si solo el mapa de memoria indica un reemplazo del ejecutable principal, esto se mostrará como si cualquier otra biblioteca hubiera sido reemplazada o eliminada.

Este marcado de color adicional se puede configurar en la sección "Opciones de Visualización" de la pantalla de configuración.

Mostrar EXE requiere CAP_SYS_PTRACE y PTRACE_MODE_READ_FSCRED.

CONFIG FILES

The configuration files for htop and pcp-htop are stored in the user's home directory, under $HOME/.config/htop/. The file htop.cfg stores user-specific settings. The configuration files for pcp-htop are also stored in this directory.

The following configuration files are used by pcp-htop:

htop.cfg
Stores the user's htop settings, including column definitions, sorting order, screen setup, and tag configuration. This file is read and written by htop itself.
pcp-htop.conf
This file contains configuration settings specific to pcp-htop. It allows customization of which Performance Co-Pilot (PCP) metrics are displayed, how they are named, and their display order. Refer to pcp-htop(5) for a detailed description of the format and available options for defining metrics, columns, or screen configuration.

These pcp-htop configuration files are read once at startup. The format of these files is described in detail in the pcp-htop(5) manual page.

This functionality makes available many thousands of Performance Co-Pilot metrics for display by pcp-htop, as well as the ability to display custom metrics added at individual sites. Applications and services instrumented using the OpenMetrics format https://openmetrics.io can also be displayed by pcp-htop if the pmdaopenmetrics(1) component is configured.

The configuration for both htop and pcp-htop is only saved when a clean exit is performed. Sending any signal will cause all configuration changes to be lost.

MEMORY SIZES

Memory sizes in htop are displayed in a human-readable form. Sizes are printed in powers of 1024 using binary IEC units. If no suffix is shown the units are implicitly K as in KiB (kibibyte, 1 KiB = 1024 bytes).

The decision to use this convention was made in order to conserve screen space and make memory size representations consistent throughout htop as allocations are granular to full memory pages (4 KiB for most platforms).
