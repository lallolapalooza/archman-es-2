pcre_compile(3)

Paquete: pcre

Licencias: BSD

PCRE_COMPILE(3) Manual de Funciones de Biblioteca PCRE_COMPILE(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

pcre *pcre_compile(const char *patrón, int opciones,
     const char **ptr_error, int *offset_error,
     const unsigned char *ptr_tabla);

pcre16 *pcre16_compile(PCRE_SPTR16 patrón, int opciones,
     const char **ptr_error, int *offset_error,
     const unsigned char *ptr_tabla);

pcre32 *pcre32_compile(PCRE_SPTR32 patrón, int opciones,
     const char **ptr_error, int *offset_error,
     const unsigned char *ptr_tabla);

DESCRIPCIÓN

Esta función compila una expresión regular en una forma interna. Es lo mismo que pcre[16|32]_compile2(), excepto por la ausencia del argumento ptr_error_code. Sus argumentos son:


patrón Una cadena terminada en cero que contiene la
expresión regular a compilar
opciones Cero o más bits de opción
ptr_error Dónde poner un mensaje de error
offset_error Desplazamiento en el patrón donde se encontró el error
ptr_tabla Puntero a tablas de caracteres, o NULL para
usar la predeterminada incorporada

Los bits de opción son:


PCRE_ANCHORED Forzar anclaje del patrón
PCRE_AUTO_CALLOUT Compilar callouts automáticos
PCRE_BSR_ANYCRLF \R coincide solo con CR, LF o CRLF
PCRE_BSR_UNICODE \R coincide con todos los finales de línea Unicode
PCRE_CASELESS Coincidencia sin distinción de mayúsculas y minúsculas
PCRE_DOLLAR_ENDONLY $ no coincide con nueva línea al final
PCRE_DOTALL . coincide con cualquier cosa, incluyendo NL
PCRE_DUPNAMES Permitir nombres duplicados para subpatrones
PCRE_EXTENDED Ignorar espacios en blanco y comentarios #
PCRE_EXTRA Características adicionales de PCRE
(actualmente de poca utilidad)
PCRE_FIRSTLINE Forzar que la coincidencia sea anterior a una nueva línea
PCRE_JAVASCRIPT_COMPAT Compatibilidad con JavaScript
PCRE_MULTILINE ^ y $ coinciden con nuevas líneas dentro de los datos
PCRE_NEVER_UTF Bloquear UTF, por ejemplo, vía (*UTF)
PCRE_NEWLINE_ANY Reconocer cualquier secuencia de nueva línea Unicode
PCRE_NEWLINE_ANYCRLF Reconocer CR, LF y CRLF como secuencias de
nueva línea
PCRE_NEWLINE_CR Establecer CR como secuencia de nueva línea
PCRE_NEWLINE_CRLF Establecer CRLF como secuencia de nueva línea
PCRE_NEWLINE_LF Establecer LF como secuencia de nueva línea
PCRE_NO_AUTO_CAPTURE Desactivar paréntesis de captura numerados
(los nombrados están disponibles)
PCRE_NO_AUTO_POSSESS Desactivar posesión automática
PCRE_NO_START_OPTIMIZE Desactivar optimizaciones de inicio en tiempo de coincidencia
PCRE_NO_UTF16_CHECK No verificar el patrón para validez UTF-16
(solo relevante si
PCRE_UTF16 está establecido)
PCRE_NO_UTF32_CHECK No verificar el patrón para validez UTF-32
(solo relevante si
PCRE_UTF32 está establecido)
PCRE_NO_UTF8_CHECK No verificar el patrón para validez UTF-8
(solo relevante si
PCRE_UTF8 está establecido)
PCRE_UCP Usar propiedades Unicode para \d, \w, etc.
PCRE_UNGREEDY Invertir la codicia de los cuantificadores
PCRE_UTF16 Ejecutar en modo UTF-16 de pcre16_compile()
PCRE_UTF32 Ejecutar en modo UTF-32 de pcre32_compile()
PCRE_UTF8 Ejecutar en modo UTF-8 de pcre_compile()

PCRE debe compilarse con soporte UTF para poder usar PCRE_UTF8/16/32 y PCRE_NO_UTF8/16/32_CHECK, y con soporte UCP si se usa PCRE_UCP.

El resultado de la función es un puntero a una estructura de datos privada que contiene el patrón compilado, o NULL si se detectó un error. Tenga en cuenta que compilar expresiones regulares con una versión de PCRE para usar con una versión diferente no está garantizado que funcione y puede causar fallos.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
