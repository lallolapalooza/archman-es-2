PCRE2_SERIALIZE_GET_NUMBER_OF_CODES(3) Manual de funciones de biblioteca PCRE2_SERIALIZE_GET_NUMBER_OF_CODES(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int32_t pcre2_serialize_get_number_of_codes(const uint8_t *bytes);

DESCRIPCIÓN

El argumento bytes debe apuntar a un flujo de bytes serializado que fue creado originalmente por pcre2_serialize_encode() (aunque puede haber sido guardado en disco o en otro lugar mientras tanto). La función devuelve el número de patrones serializados en el flujo de bytes, o uno de los siguientes códigos de error negativos:


PCRE2_ERROR_BADMAGIC diferencia de bytes de identificación en bytes
PCRE2_ERROR_BADMODE diferencia del tamaño de unidad variable o versión de PCRE
PCRE2_ERROR_NULL el argumento es NULL

PCRE2_ERROR_BADMAGIC puede significar que los datos están corruptos, o que fueron compilados en un sistema con diferente orden de bytes (endianness).

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de las funciones de serialización en la página pcre2serialize.
