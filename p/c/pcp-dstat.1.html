PCP-DSTAT(1) Manual de Comandos Generales PCP-DSTAT(1)

NOMBRE

pcp-dstat - herramienta versátil para generar estadísticas de recursos del sistema

SINOPSIS

pcp [opciones de pcp] dstat [-acdfghilmnpqrstuvVy?] [-C cpus] [-G gpus] [-D discos] [-L dispositivos DM] [-M dispositivos MD] [-P particiones] [-I interrupciones] [-N interfaces] [-o archivo-de-salida] [-S dispositivos-de-intercambio] [--bits] [--bw] [--color] [--float] [--integer] [--nocolor] [--noheaders] [--nomissed] [--noupdate] [--list] [--pidfile archivo-pid] [--plugin] [--all-plugins] [retraso [cuenta]]

DESCRIPCIÓN

pcp-dstat es una herramienta general de análisis de rendimiento que permite visualizar múltiples recursos del sistema instantáneamente, por ejemplo, puede comparar el uso del disco en combinación con las interrupciones de un controlador de disco, o comparar las cifras de ancho de banda de red directamente con el rendimiento del disco (en el mismo intervalo).

También proporciona de forma inteligente la información más detallada en columnas e indica claramente en qué magnitud y unidad se está mostrando la salida. Menos confusión, menos errores, más eficiencia.

El retraso es el retraso en segundos entre cada actualización, y la cuenta es el número de actualizaciones a mostrar antes de salir. El retraso predeterminado es de 1 segundo y la cuenta no se especifica (se ejecuta hasta que se interrumpe o se llega al final del archivo).

Esta última generación de Dstat, pcp-dstat, permite el análisis de datos históricos de rendimiento (en formato de archivo PCP creado por pmlogger(1)), así como el análisis de sistemas distribuidos de datos de rendimiento en vivo desde hosts remotos que ejecutan el proceso pmcd(1).

La noción original de Dstat de "plugins" es reemplazada por el uso de métricas con nombre en un Espacio de Nombres de Métricas de Rendimiento (PMNS(5)) suministrado por Agentes de Dominio de Métricas de Rendimiento (PMDAs). Las métricas y otra información de formato ahora se especifican como archivos de configuración de plugins en formato pcp-dstat(5). Este nuevo estilo de plugin está incorporado (solo para informes relacionados con el tiempo) o se obtiene de la ubicación del sistema ($PCP_SYSCONF_DIR/dstat) y/o de un conjunto de plugins personales de un usuario individual ($HOME/.pcp/dstat).

La lista de todos los plugins disponibles se puede ver utilizando la opción de línea de comandos --list de dstat.

INTERMEDIATE UPDATES

When invoking pcp-dstat with a delay greater than 1 second and without the --noupdate option, it will show intermediate updates, i.e., the first time a 1 second average, the second update a 2 second average, etc. until the delay has been reached.

So in case you specified a delay of 10, the 9 intermediate updates are NOT snapshots, they are averages over the time that passed since the last final update. The end result is that you get a 10 second average on a new line, just like with vmstat(1).

EXAMPLES

Using pcp-dstat to relate disk-throughput with network-usage (eth0), total CPU-usage and system counters: 

$ pcp dstat -dnyc -N eth0 -C total -f 5


Using the time plugin together with cpu, net, disk, system, load and proc plugins: 

$ pcp dstat -tcndylp


This is identical to: 

$ pcp dstat --time --cpu --net --disk --sys --load --proc


Using pcp-dstat to report 10 samples from metrics recorded in a PCP archive 20180729 from 2:30 AM:

$ pcp --origin '@02:30' -a 20180729 dstat --time --cpu-adv --sys 1 10

Examine the same metrics live from a remote host: 

$ pcp --host www.acme.com dstat --time --cpu-adv --sys 1 10

PCP ENVIRONMENT

Environment variables with the prefix PCP_ are used to parameterize the file and directory names used by PCP. On each installation, the file /etc/pcp.conf contains the local values for these variables. The $PCP_CONF variable may be used to specify an alternative configuration file, as described in pcp.conf(5).

For environment variables affecting PCP tools, see pmGetOptions(3).
