pcap_datalink_val_to_name.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_DATALINK_VAL_TO_NAME(3PCAP) PCAP_DATALINK_VAL_TO_NAME(3PCAP)

NOMBRE

pcap_datalink_val_to_name, pcap_datalink_val_to_description, pcap_datalink_val_to_description_or_dlt - obtener un nombre o descripción para un valor de tipo de cabecera de capa de enlace

SINOPSIS

#include <pcap.h>
const char *pcap_datalink_val_to_name(int dlt);
const char *pcap_datalink_val_to_description(int dlt);
const char *pcap_datalink_val_to_description_or_dlt(int dlt);

DESCRIPCIÓN

pcap_datalink_val_to_name() traduce un valor de tipo de cabecera de capa de enlace al nombre de tipo de cabecera de capa de enlace correspondiente, que es el nombre DLT_ para el valor de tipo de cabecera de capa de enlace con el DLT_ eliminado. Se devuelve NULL si el valor del tipo no corresponde a un valor DLT_ conocido.

pcap_datalink_val_to_description() traduce un valor de tipo de cabecera de capa de enlace a una breve descripción de ese tipo de cabecera de capa de enlace. Se devuelve NULL si el valor del tipo no corresponde a un valor DLT_ conocido.

pcap_datalink_val_to_description_or_dlt() traduce un valor de tipo de cabecera de capa de enlace a una breve descripción de ese tipo de cabecera de capa de enlace, igual que pcap_datalink_val_to_description(). Si el valor del tipo no corresponde a un valor DLT_ conocido, se devuelve la cadena "DLT n", donde n es el valor del argumento dlt.

COMPATIBILIDAD HACIA ATRÁS

La función pcap_datalink_val_to_description_or_dlt() estuvo disponible por primera vez en la versión 1.9.1 de libpcap. En versiones anteriores, se tenía que llamar a pcap_datalink_val_to_description() y, si devolvía NULL, se debía construir una cadena predeterminada.
