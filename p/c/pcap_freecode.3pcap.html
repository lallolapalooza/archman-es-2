NOMBRE

pcap_freecode - liberar un programa BPF

SINOPSIS

#include <pcap/pcap.h>
void pcap_freecode(struct bpf_program *);

DESCRIPCIÓN

pcap_freecode() se utiliza para liberar la memoria asignada apuntada por una estructura bpf_program generada por pcap_compile(3PCAP) cuando ese programa BPF ya no es necesario, por ejemplo, después de que se haya establecido como el programa de filtro para una estructura pcap mediante una llamada a pcap_setfilter(3PCAP).
