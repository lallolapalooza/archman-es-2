PCP-PYTHON(1) Manual de comandos generales PCP-PYTHON(1)

NOMBRE

pcp-python - ejecuta un script de python usando una variante de python preferida

SINOPSIS

pcp python [SCRIPT [ARG] ...]

DESCRIPCIÓN

pcp-python ha sido reemplazado por pmpython(1), que es preferido. Sin embargo, pcp-python todavía se instala para proporcionar compatibilidad con versiones anteriores.

pcp-python proporciona una forma de ejecutar scripts de python utilizando un binario de python personalizable, en lugar de incrustar cualquier versión particular de python en cada script.

Esto puede ser útil ya que permite ejecutar código python independiente de la versión en cualquier lugar. Todos los módulos de python distribuidos con PCP admiten las versiones 2.6 y posteriores (en la serie python2), y 3.3 y posteriores (en la serie de lanzamientos de python3).

Debido a que los scripts de monitorización y recopilación de python son relativamente sencillos en PCP (no requieren nuevos módulos, características del lenguaje, etc.), ha sido posible garantizar que funcionen para todas las versiones de python anteriores. Por lo tanto, es común que los scripts de python de PCP utilicen una línea de "shebang" que invoca a pcp-python de la siguiente manera:


#!/usr/bin/pcp python

Esto permite inyectar la configuración personalizada en lugar de una versión de python codificada, al tiempo que permite al usuario anular la versión de python de la siguiente manera:


$ PCP_PYTHON_PROG=python3 /usr/bin/pcp python --version
Python 3.3.2
$ PCP_PYTHON_PROG=python2 /usr/bin/pcp python --version
Python 2.7.5

Esto es conveniente para distribuir scripts idénticos en múltiples plataformas y para probar diferentes versiones de python con el mismo script (por ejemplo, en el caso de que se instalen varias versiones de python, PCP_PYTHON_PROG se puede establecer en el entorno local para anular la configuración global).

Por defecto, se utilizará el valor de PCP_PYTHON_PROG de /etc/pcp.conf. El valor por defecto de este parámetro de configuración se establece en función de algunas heurísticas sobre la plataforma de compilación de destino. Estas heurísticas favorecen el uso de python3 en todas las versiones recientes de PCP, para aquellas plataformas que lo admiten.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
