PCRE2_SUBSTRING_NUMBER_FROM_NAME(3) Manual de funciones de la biblioteca PCRE2_SUBSTRING_NUMBER_FROM_NAME(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_substring_number_from_name(const pcre2_code *code,
  PCRE2_SPTR name);

DESCRIPCIÓN

Esta función de conveniencia busca el número de un paréntesis de captura de subcadena con nombre en un patrón compilado, siempre que sea un nombre único. Los argumentos de la función son:


code Expresión regular compilada
name Nombre del que se requiere el número

El resultado de la función es el número del paréntesis si se encuentra el nombre, o PCRE2_ERROR_NOSUBSTRING si no se encuentra. Cuando se permiten nombres duplicados (se establece PCRE2_DUPNAMES), si el nombre no es único, se devuelve PCRE2_ERROR_NOUNIQUESUBSTRING. Puede obtener la lista de números con el mismo nombre llamando a pcre2_substring_nametable_scan().

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
