pcre_compile2(3)

Paquete: pcre

Licencias: BSD

PCRE_COMPILE2(3) Manual de funciones de la biblioteca PCRE_COMPILE2(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

pcre *pcre_compile2(const char *pattern, int options,
     int *errorcodeptr,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre16 *pcre16_compile2(PCRE_SPTR16 pattern, int options,
     int *errorcodeptr,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre32 *pcre32_compile2(PCRE_SPTR32 pattern, int options,
     int *errorcodeptr,£
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

DESCRIPCIÓN

Esta función compila una expresión regular en una forma interna. Es igual a pcre[16|32]_compile(), excepto por la adición del argumento errorcodeptr. Los argumentos son:


pattern Una cadena terminada en cero que contiene la
expresión regular a compilar
options Cero o más bits de opciones
errorcodeptr Dónde poner un código de error
errptr Dónde poner un mensaje de error
erroffset Desplazamiento en el patrón donde se encontró el error
tableptr Puntero a tablas de caracteres, o NULL para
usar la predeterminada incorporada

Los bits de opciones son:


PCRE_ANCHORED Forzar anclaje del patrón
PCRE_AUTO_CALLOUT Compilar llamadas automáticas (callouts)
PCRE_BSR_ANYCRLF \R coincide solo con CR, LF o CRLF
PCRE_BSR_UNICODE \R coincide con todos los finales de línea Unicode
PCRE_CASELESS Coincidencia sin distinguir mayúsculas y minúsculas
PCRE_DOLLAR_ENDONLY $ no coincide con nueva línea al final
PCRE_DOTALL . coincide con cualquier cosa, incluyendo NL
PCRE_DUPNAMES Permitir nombres duplicados para subpatrones
PCRE_EXTENDED Ignorar espacios en blanco y comentarios #
PCRE_EXTRA Características adicionales de PCRE
(no de mucha utilidad actualmente)
PCRE_FIRSTLINE Forzar la coincidencia antes de una nueva línea
PCRE_JAVASCRIPT_COMPAT Compatibilidad con JavaScript
PCRE_MULTILINE ^ y $ coinciden con nuevas líneas dentro de los datos
PCRE_NEVER_UTF Bloquear UTF, por ejemplo, mediante (*UTF)
PCRE_NEWLINE_ANY Reconocer cualquier secuencia de nueva línea Unicode
PCRE_NEWLINE_ANYCRLF Reconocer CR, LF y CRLF como secuencias de
nueva línea
PCRE_NEWLINE_CR Establecer CR como la secuencia de nueva línea
PCRE_NEWLINE_CRLF Establecer CRLF como la secuencia de nueva línea
PCRE_NEWLINE_LF Establecer LF como la secuencia de nueva línea
PCRE_NO_AUTO_CAPTURE Deshabilitar paréntesis de captura numerados
(los nombrados están disponibles)
PCRE_NO_AUTO_POSSESS Deshabilitar posesividad automática
PCRE_NO_START_OPTIMIZE Deshabilitar optimizaciones de inicio en tiempo de coincidencia
PCRE_NO_UTF16_CHECK No verificar la validez de UTF-16 del patrón
(solo relevante si se establece
PCRE_UTF16)
PCRE_NO_UTF32_CHECK No verificar la validez de UTF-32 del patrón
(solo relevante si se establece
PCRE_UTF32)
PCRE_NO_UTF8_CHECK No verificar la validez de UTF-8 del patrón
(solo relevante si se establece
PCRE_UTF8)
PCRE_UCP Usar propiedades Unicode para \d, \w, etc.
PCRE_UNGREEDY Invertir la codicia de los cuantificadores
PCRE_UTF16 Ejecutar pcre16_compile() en modo UTF-16
PCRE_UTF32 Ejecutar pcre32_compile() en modo UTF-32
PCRE_UTF8 Ejecutar pcre_compile() en modo UTF-8

PCRE debe compilarse con soporte UTF para poder usar PCRE_UTF8/16/32 y PCRE_NO_UTF8/16/32_CHECK, y con soporte UCP si se usa PCRE_UCP.

El resultado de la función es un puntero a una estructura de datos privada que contiene el patrón compilado, o NULL si se detectó un error. Tenga en cuenta que compilar expresiones regulares con una versión de PCRE para usarla con una versión diferente no está garantizado que funcione y puede causar fallos.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
