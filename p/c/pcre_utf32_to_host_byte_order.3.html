pcre_utf32_to_host_byte_order(3)

Paquete: pcre

Licencias: BSD

PCRE_UTF32_TO_HOST_BYTE_ORDER(3) Manual de funciones de biblioteca PCRE_UTF32_TO_HOST_BYTE_ORDER(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre32_utf32_to_host_byte_order(PCRE_UCHAR32 *output,
     PCRE_SPTR32 input, int length, int *host_byte_order,
     int keep_boms);

DESCRIPCIÓN

Esta función, que solo existe en la biblioteca de 32 bits, convierte una cadena UTF-32 al orden correcto para el host actual, teniendo en cuenta cualquier marca de orden de bytes (BOM) dentro de la cadena. Sus argumentos son:


*output puntero al búfer de salida, puede ser el mismo que *input
*input puntero al búfer de entrada
*length* número de unidades de 32 bits en la entrada, o negativo para
una cadena terminada en cero
*host_byte_order* un valor NULL o un valor distinto de cero apuntado indica
que se debe empezar en el orden de bytes del host
*keep_boms* si no es cero, las BOM se copian a la cadena de salida

El resultado de la función es el número de unidades de 32 bits colocadas en el búfer de salida, incluido el terminador cero si la cadena estaba terminada en cero.

Si *host_byte_order no es NULL, se establece para indicar el orden de bytes que está activo al final de la cadena.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
