pcre_refcount(3)

Paquete: pcre

Licencias: BSD

PCRE_REFCOUNT(3) Manual de funciones de biblioteca PCRE_REFCOUNT(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_refcount(pcre *code, int adjust);

int pcre16_refcount(pcre16 *code, int adjust);

int pcre32_refcount(pcre32 *code, int adjust);

DESCRIPCIÓN

Esta función se utiliza para mantener un contador de referencias dentro de un bloque de datos que contiene un patrón compilado. Sus argumentos son:


code Expresión regular compilada
adjust Ajuste del valor de referencia

El resultado de la función es el valor de referencia ajustado, que está limitado entre 0 y 65535.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
