pcre_version(3)

Paquete: pcre

Licencias: BSD

PCRE_VERSION(3) Manual de Funciones de Biblioteca PCRE_VERSION(3)

NOMBRE

PCRE — expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

const char *pcre_version(void);

const char *pcre16_version(void);

const char *pcre32_version(void);

DESCRIPCIÓN

Esta función (incluso en las bibliotecas de 16 y 32 bits) devuelve una cadena de caracteres de 8 bits terminada en cero que contiene el número de versión de la biblioteca PCRE y la fecha de su lanzamiento.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.

24 de junio de 2012 PCRE 8.30
