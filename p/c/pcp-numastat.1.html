PCP-NUMASTAT(1) Manual de comandos generales PCP-NUMASTAT(1)

NOMBRE

pcp-numastat - informar sobre la asignación de memoria NUMA

SINOPSIS

pcp [opciones de pcp] numastat [-mnV?] [-w ancho]

DESCRIPCIÓN

pcp-numastat muestra estadísticas de asignación NUMA del asignador de memoria del kernel. Cada proceso tiene políticas NUMA que especifican en qué nodo se asignan las páginas. Los contadores de rendimiento en el kernel rastrean en qué nodos se asigna la memoria y estos valores son muestreados e informados por pcp-numastat.

Se mantienen contadores individualmente para cada nodo NUMA. Los detalles de la semántica de cada métrica informada se pueden obtener utilizando el siguiente comando:

# pminfo ‐dt mem.numa.alloc

OPCIONES

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -Z/--timezone y varias opciones de pcp más se vuelven indirectamente disponibles; consulte PCPIntro(1) para una descripción completa de estas opciones.

Las opciones adicionales de la línea de comandos disponibles para pcp-numastat son:

-m, --meminfo
Muestra el uso de memoria en todo el sistema similar a meminfo.
-n, --numastat
Muestra la información de estadísticas de numastat.
-V, --version
Muestra la versión actual del comando.
-w ancho, --width=ancho
Limita la visualización a ancho.
-?, --help
Muestra el mensaje de uso y sale.

NOTAS

pcp-numastat está inspirado en el comando numastat(1) y produce exactamente la misma salida.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN

PCPIntro(1), pcp(1) y numastat(1).
