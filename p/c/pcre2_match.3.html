pcre2_match(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_MATCH(3) Manual de funciones de biblioteca PCRE2_MATCH(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_match(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext);

DESCRIPCIÓN

Esta función compara una expresión regular compilada contra una cadena sujeto dada, utilizando un algoritmo de coincidencia similar al de Perl. Devuelve los desplazamientos de lo que ha coincidido y de las subcadenas capturadas a través del bloque match_data, que puede ser procesado por funciones con nombres que comienzan con pcre2_get_ovector_...() o pcre2_substring_...(). El valor de retorno de pcre2_match() es uno más que el par de captura con el número más alto que se ha establecido (por ejemplo, 1 si no hay capturas), cero si el vector de desplazamientos es demasiado pequeño, o un código de error negativo para no coincidencia y otros errores. Los argumentos de la función son:


code Puntero al patrón compilado
subject Puntero a la cadena sujeto
length Longitud de la cadena sujeto
startoffset Desplazamiento en el sujeto donde comenzar la coincidencia
options Bits de opción
match_data Puntero a un bloque de datos de coincidencia, para resultados
mcontext Puntero a un contexto de coincidencia, o es NULL

Solo se necesita un contexto de coincidencia si desea:


Configurar una función de llamada (callout)
Establecer un límite de desplazamiento de coincidencia
Cambiar el límite de memoria del montón (heap)
Cambiar el límite de coincidencia de retroceso (backtracking)
Cambiar el límite de profundidad de retroceso
Establecer gestión de memoria personalizada específicamente para la coincidencia

Los valores de length y startoffset son unidades de código, no caracteres. La longitud se puede dar como PCRE2_ZERO_TERMINATED para un sujeto que termina con una unidad de código cero binario. Las opciones son:


PCRE2_ANCHORED Coincidir solo en la primera posición
PCRE2_COPY_MATCHED_SUBJECT
En caso de éxito, hacer una copia privada del sujeto
PCRE2_DISABLE_RECURSELOOP_CHECK
Solo útil en casos raros; usar con cuidado
PCRE2_ENDANCHORED El patrón puede coincidir solo al final del sujeto
PCRE2_NOTBOL La cadena sujeto no es el principio de una línea
PCRE2_NOTEOL La cadena sujeto no es el final de una línea
PCRE2_NOTEMPTY Una cadena vacía no es una coincidencia válida
PCRE2_NOTEMPTY_ATSTART Una cadena vacía al principio del sujeto
no es una coincidencia válida
PCRE2_NO_JIT No usar coincidencia JIT
PCRE2_NO_UTF_CHECK No verificar la validez UTF del sujeto
(solo relevante si PCRE2_UTF
se estableció en el momento de la compilación)
PCRE2_PARTIAL_HARD Devolver PCRE2_ERROR_PARTIAL para una coincidencia parcial
incluso si hay una coincidencia completa
PCRE2_PARTIAL_SOFT Devolver PCRE2_ERROR_PARTIAL para una coincidencia parcial
si no se encuentran coincidencias completas

Para obtener detalles sobre la coincidencia parcial, consulte la página pcre2partial. Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
