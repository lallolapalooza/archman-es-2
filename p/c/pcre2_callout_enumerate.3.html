pcre2_callout_enumerate(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_COMPILE(3) Manual de funciones de biblioteca PCRE2_COMPILE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_callout_enumerate(const pcre2_code *code,
  int (*callback)(pcre2_callout_enumerate_block *, void *),
  void *callout_data);

DESCRIPCIÓN

Esta función escanea una expresión regular compilada y llama a la función callback() para cada llamada de aviso dentro del patrón. El resultado de la función es cero si tiene éxito y distinto de cero en caso contrario. Los argumentos son:


code Puntero al patrón compilado
callback La función de llamada de aviso
callout_data Datos de usuario que se pasan a la llamada de aviso

A la función callback() se le pasa un puntero a un bloque de datos que contiene los siguientes campos (no necesariamente en este orden):


uint32_t version Número de versión del bloque
uint32_t callout_number Número para las llamadas de aviso numeradas
PCRE2_SIZE pattern_position Desplazamiento al siguiente elemento en el patrón
PCRE2_SIZE next_item_length Longitud del siguiente elemento en el patrón
PCRE2_SIZE callout_string_offset Desplazamiento a la cadena dentro del patrón
PCRE2_SIZE callout_string_length Longitud de la cadena de llamada de aviso
PCRE2_SPTR callout_string Puntero a la cadena de llamada de aviso o es NULL

El segundo argumento que se pasa a la función callback() son los datos de llamada de aviso que se pasaron a pcre2_callout_enumerate(). La función callback() debe devolver cero si tiene éxito. Cualquier otro valor hace que el escaneo del patrón se detenga, y el valor se devuelve como resultado de pcre2_callout_enumerate().

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
