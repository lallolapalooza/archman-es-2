pciconfig_read(2) Manual de llamadas al sistema pciconfig_read(2)

NOMBRE

pciconfig_read, pciconfig_write, pciconfig_iobase - manejo de información de dispositivos pci

BIBLIOTECA

Biblioteca estándar de C (libc, -lc)

SINOPSIS

#include <pci.h>
int pciconfig_read(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_write(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_iobase(int which, unsigned long bus,
                   unsigned long devfn);

DESCRIPCIÓN

La mayor parte de la interacción con dispositivos PCI ya es manejada por la capa PCI del kernel, y por lo tanto, estas llamadas normalmente no deberían ser accedidas desde el espacio de usuario.

pciconfig_read()
Lee desde buf del dispositivo dev en el desplazamiento off el valor.
pciconfig_write()
Escribe desde buf al dispositivo dev en el desplazamiento off el valor.
pciconfig_iobase()
Se le pasa un par bus/devfn y se obtiene una dirección física para el desplazamiento de memoria (para cosas como prep, es 0xc0000000), la base de E/S para ciclos PIO, o los huecos ISA si los hay.

VALOR DEVUELTO

pciconfig_read()
En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.
pciconfig_write()
En caso de éxito, se devuelve cero. En caso de error, se devuelve -1 y se establece errno para indicar el error.
pciconfig_iobase()
Devuelve información sobre las ubicaciones de varias regiones de E/S en memoria física de acuerdo con el valor de which. Los valores para which son: IOBASE_BRIDGE_NUMBER, IOBASE_MEMORY, IOBASE_IO, IOBASE_ISA_IO, IOBASE_ISA_MEM.

ERRORES

EINVAL
El valor de size no es válido. Esto no se aplica a pciconfig_iobase().
EIO
Error de E/S.
ENODEV
Para pciconfig_iobase(), el valor "hose" es NULL. Para las otras llamadas, no se pudo encontrar una ranura.
ENOSYS
El sistema no ha implementado estas llamadas (no se definió CONFIG_PCI).
EOPNOTSUPP
Este valor de retorno solo es válido para pciconfig_iobase(). Se devuelve si el valor para which no es válido.
EPERM
El usuario no tiene la capacidad CAP_SYS_ADMIN. Esto no se aplica a pciconfig_iobase().

ESTÁNDARES

Linux.
