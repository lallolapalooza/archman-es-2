NOMBRE

pcap_tstamp_type_name_to_val - obtener el valor del tipo de marca de tiempo correspondiente a un nombre de tipo de marca de tiempo

SINOPSIS

#include <pcap/pcap.h>
int pcap_tstamp_type_name_to_val(const char *name);

DESCRIPCIÓN

pcap_tstamp_type_name_to_val() traduce un nombre de tipo de marca de tiempo al valor del tipo de marca de tiempo correspondiente. La traducción no distingue entre mayúsculas y minúsculas.

VALOR DEVUELTO

pcap_tstamp_type_name_to_val() devuelve el valor del tipo de marca de tiempo en caso de éxito y PCAP_ERROR en caso de fallo.

COMPATIBILIDAD HACIA ATRÁS

Esta función estuvo disponible en la versión 1.2.1 de libpcap.

VER TAMBIÉN

pcap(3PCAP), pcap_tstamp_type_val_to_name(3PCAP)
