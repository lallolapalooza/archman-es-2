pcre2_substring_copy_bynumber(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_COPY_BYNUMBER(3) Manual de funciones de la biblioteca PCRE2_SUBSTRING_COPY_BYNUMBER(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_substring_copy_bynumber(pcre2_match_data *match_data,
  uint32_t number, PCRE2_UCHAR *buffer,
  PCRE2_SIZE *bufflen);

DESCRIPCIÓN

Esta es una función de conveniencia para extraer una subcadena capturada a un buffer dado. Los argumentos son:


match_data Bloque de datos de coincidencia para la coincidencia
number Número de la subcadena requerida
buffer Buffer para recibir la cadena
bufflen Longitud del buffer

La variable bufflen se actualiza con la longitud de la cadena extraída, excluyendo el cero terminador. El resultado de la función es cero para éxito o uno de los siguientes números de error:


PCRE2_ERROR_NOSUBSTRING no hay grupos con ese número
PCRE2_ERROR_UNAVAILBLE el ovector era demasiado pequeño para ese grupo
PCRE2_ERROR_UNSET el grupo no participó en la coincidencia
PCRE2_ERROR_NOMEMORY el buffer es demasiado pequeño

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
