NOMBRE

pcap_fileno - obtener el descriptor de archivo para una captura en vivo

SINOPSIS

#include <pcap/pcap.h>
int pcap_fileno(pcap_t *p);

DESCRIPCIÓN

Si p se refiere a un dispositivo de red que se abrió para una captura en vivo utilizando una combinación de pcap_create(3PCAP) y pcap_activate(3PCAP), o utilizando pcap_open_live(3PCAP), pcap_fileno() devuelve el descriptor de archivo desde el cual se leen los paquetes capturados.

Si p se refiere a un ``savefile'' que se abrió utilizando funciones como pcap_open_offline(3PCAP) o pcap_fopen_offline(3PCAP), un pcap_t ``muerto'' abierto utilizando pcap_open_dead(3PCAP), o un pcap_t que se creó con pcap_create() pero que aún no se ha activado con pcap_activate(), devuelve PCAP_ERROR.
