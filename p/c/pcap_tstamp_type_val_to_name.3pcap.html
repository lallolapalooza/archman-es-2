pcap_tstamp_type_val_to_name.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_TSTAMP_TYPE_VAL_TO_NAME(3PCAP) PCAP_TSTAMP_TYPE_VAL_TO_NAME(3PCAP)

NOMBRE

pcap_tstamp_type_val_to_name, pcap_tstamp_type_val_to_description - obtener un nombre o descripción para un valor de tipo de marca de tiempo

SINOPSIS

#include <pcap.h>
const char *pcap_tstamp_type_val_to_name(int tstamp_type);
const char *pcap_tstamp_type_val_to_description(int tstamp_type);

DESCRIPCIÓN

pcap_tstamp_type_val_to_name() traduce un valor de tipo de marca de tiempo al nombre del tipo de marca de tiempo correspondiente. Se devuelve NULL en caso de fallo.

pcap_tstamp_type_val_to_description() traduce un valor de tipo de marca de tiempo a una breve descripción de ese tipo de marca de tiempo. Se devuelve NULL en caso de fallo.

COMPATIBILIDAD HACIA ATRÁS

Estas funciones estuvieron disponibles por primera vez en la versión 1.2.1 de libpcap.

VER TAMBIÉN

pcap(3PCAP), pcap_tstamp_type_name_to_val(3PCAP)
