pcap_list_tstamp_types.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_LIST_TSTAMP_TYPES(3PCAP) PCAP_LIST_TSTAMP_TYPES(3PCAP)

NOMBRE

pcap_list_tstamp_types, pcap_free_tstamp_types - obtener una lista de tipos de marcas de tiempo compatibles con un dispositivo de captura y liberar esa lista

SINOPSIS

#include <pcap/pcap.h>
int pcap_list_tstamp_types(pcap_t *p, int **tstamp_typesp);
void pcap_free_tstamp_types(int *tstamp_types);

DESCRIPCIÓN

pcap_list_tstamp_types() se utiliza para obtener una lista de los tipos de marcas de tiempo compatibles de la interfaz asociada con el descriptor pcap. pcap_list_tstamp_types() asigna un array para contener la lista y establece *tstamp_typesp para que apunte al array. Consulte pcap-tstamp(7) para obtener una lista de todos los tipos de marcas de tiempo.

El llamador es responsable de liberar el array con pcap_free_tstamp_types(), que libera la lista apuntada por tstamp_types.

VALOR DE RETORNO

pcap_list_tstamp_types() devuelve el número de tipos de marcas de tiempo en el array en caso de éxito y PCAP_ERROR en caso de fallo. Un valor de retorno de uno significa que el único tipo de marca de tiempo compatible es el de la lista, que es el tipo de marca de tiempo predeterminado del dispositivo de captura. Un valor de retorno de cero significa que el único tipo de marca de tiempo compatible es PCAP_TSTAMP_HOST, que es el tipo de marca de tiempo predeterminado del dispositivo de captura (solo las versiones anteriores de libpcap devolverán eso; las versiones más recientes siempre devolverán uno o más tipos). Si se devuelve PCAP_ERROR, se puede llamar a pcap_geterr(3PCAP) o pcap_perror(3PCAP) con p como argumento para obtener o mostrar el texto del error.

COMPATIBILIDAD HACIA ATRÁS

Estas funciones estuvieron disponibles en la versión 1.2.1 de libpcap. En versiones anteriores, el tipo de marca de tiempo no se puede establecer; solo está disponible el tipo de marca de tiempo predeterminado ofrecido por una fuente de captura.
