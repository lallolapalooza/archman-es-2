PCP-MPSTAT(1) Manual de comandos generales PCP-MPSTAT(1)

NOMBRE

pcp-mpstat - Informa estadísticas relacionadas con la CPU e interrupciones.

SINOPSIS

pcp [opciones de pcp] mpstat [ -A ] [ -u ] [ -V ] [ -I { SUMA | CPU | SCPU | TODO } ] [ -P { cpu1,cpu2 [,...] | EN | TODO } ] [ -t intervalo ] [ -s conteo ] [ -a archivo ] [ -? ]

DESCRIPCIÓN

El comando pcp-mpstat escribe en la salida estándar las actividades de cada procesador disponible, siendo el procesador 0 el primero. Si no se ha seleccionado ninguna actividad/opción, el informe predeterminado es el informe de utilización de la CPU (-u).

El parámetro intervalo especifica la cantidad de tiempo en segundos entre cada informe. El valor predeterminado es un segundo. El valor del parámetro conteo determina el número de muestras a mostrar. El valor predeterminado es continuo.

OPCIONES

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone y varias otras opciones de pcp están disponibles indirectamente; consulte PCPIntro(1) para una descripción completa de estas opciones.

Las opciones adicionales de línea de comandos disponibles para pcp-mpstat son:

-A
Esta opción es equivalente a especificar -u -I TODO -P TODO
-I { SUMA | CPU | SCPU | TODO }
Informa estadísticas de interrupciones.
Con la palabra clave SUMA, el comando pcp-mpstat informa el número total de interrupciones por procesador. Se muestran los siguientes valores:

CPU

Número de procesador. La palabra clave todo indica que las estadísticas se calculan como promedios entre todos los procesadores.

intr/s

Muestra el número total de interrupciones recibidas por segundo por la CPU o CPUs.

Con la palabra clave CPU, se muestra el número de cada interrupción individual recibida por segundo por la CPU o CPUs. Las interrupciones son las que se encuentran bajo el árbol de métricas kernel.percpu.interrupts.

Con la palabra clave SCPU, se muestra el número de cada interrupción de software individual recibida por segundo por la CPU o CPUs. Las interrupciones de software son las que se encuentran bajo el árbol de métricas kernel.percpu.softirqs

La palabra clave TODO es equivalente a especificar todas las palabras clave anteriores y, por lo tanto, se mostrarán todas las estadísticas de interrupciones.

-P { cpu1,cpu2[,...] | EN | TODO }
Indica el número de procesador para el cual se informarán las estadísticas. cpu1 y cpu2 son los números de procesador. Se puede proporcionar una lista de números de procesador requeridos. Tenga en cuenta que el procesador 0 es el primer procesador.

La palabra clave EN indica que se informarán estadísticas para cada procesador en línea, mientras que la palabra clave TODO indica que se informarán estadísticas para todos los procesadores.

-u
Informa la utilización de la CPU. Se muestran los siguientes valores:

CPU

Número de procesador. La palabra clave TODO indica que las estadísticas se calculan como promedios entre todos los procesadores.

%usr

Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba en nivel de usuario (aplicación).

%nice

Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba en nivel de usuario con prioridad nice.

%sys

Muestra el porcentaje de utilización de la CPU que ocurrió mientras se ejecutaba en nivel de sistema (kernel). Tenga en cuenta que esto no incluye el tiempo dedicado a atender interrupciones de hardware y software.

%iowait

Muestra el porcentaje de tiempo que la CPU o CPUs estuvieron inactivas durante el cual el sistema tenía una solicitud de E/S de disco pendiente.

%irq

Muestra el porcentaje de tiempo que la CPU o CPUs dedicaron a atender interrupciones de hardware.

%soft

Muestra el porcentaje de tiempo que la CPU o CPUs dedicaron a atender interrupciones de software.

%steal

Muestra el porcentaje de tiempo que la CPU o CPUs virtuales pasaron en espera involuntaria mientras el hipervisor atendía a otro procesador virtual.

%guest

Muestra el porcentaje de tiempo que la CPU o CPUs dedicaron a ejecutar un procesador virtual.

%gnice

Muestra el porcentaje de tiempo que la CPU o CPUs dedicaron a ejecutar un invitado con prioridad nice.

%idle

Muestra el porcentaje de tiempo que la CPU o CPUs estuvieron inactivas y el sistema no tenía una solicitud de E/S de disco pendiente.

Nota: En máquinas SMP, un procesador que no tiene ninguna actividad es un procesador deshabilitado (fuera de línea).

-s  N , --samples = N
Establece el número de muestras a mostrar. Dado que la primera muestra se utiliza para la conversión de tasa de algunas de las métricas, el número total de muestras informadas es N menos uno. Por defecto es continuo.
-t DELTA , --interval = DELTA
Establece el intervalo entre dos muestras. El valor predeterminado es un segundo.
-a ARCHIVO , --archive = ARCHIVO
Hace que pcp-mpstat utilice el archivo especificado en lugar de conectarse a PMCD. El argumento de -a es una lista de nombres separados por comas, cada uno de los cuales puede ser el nombre base de un archivo o el nombre de un directorio que contiene uno o más archivos.
-V , --version
Imprime el número de versión y sale.
-? , --help
Imprime el mensaje de uso y sale.

EJEMPLOS

pcp-mpstat -t 2 -s 5

Muestra cuatro informes de estadísticas globales entre todos los procesadores a intervalos de dos segundos.

pcp mpstat -P TODO -t 2 -s 5

Muestra cuatro informes de estadísticas para todos los procesadores a intervalos de dos segundos.

NOTAS

pcp-mpstat está inspirado en el comando mpstat(1) y pretende ser compatible con él en cuanto a línea de comandos y salida.

ENTORNO

Las variables de entorno TZ y LC_TIME se pueden utilizar para anular el formato de visualización de fecha predeterminado para pcp-mpstat.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

pcp-mpstat(1)

NAME
pcp-mpstat - reporting program for processor-related statistics
SYNOPSIS

pcp-mpstat [interval [count]]
pcp-mpstat [-A [active_processors]]
pcp-mpstat [-u | -S | -N | -m | -p | -t | -l | -c | -T]
pcp-mpstat [-o file]
pcp-mpstat [-V]

DESCRIPTION

This utility is a front-end to the Performance Co-Pilot (PCP) system for collecting and reporting processor-related statistics. It can display a wide variety of performance metrics related to CPU utilization, context switches, interrupts, and more.

OPTIONS
-A [active_processors]
Report activity for all processors (logical and physical). If active_processors is specified, report only for the specified number of active processors.
-u
Report CPU utilization.
-S
Report context switches and interrupts.
-N
Report processor state (running, sleeping, etc.).
-m
Report processor migration statistics.
-p
Report processor utilization by process.
-t
Report thread statistics.
-l
Report load average.
-c
Report CPU frequency.
-T
Report processor topology.
-o file
Read performance metrics from the specified PCP archive file.
-V
Print version information and exit.
EXAMPLES

To report CPU utilization every 2 seconds, 5 times:

pcp-mpstat 2 5

To report context switches and interrupts indefinitely:

pcp-mpstat -S

To report processor topology:

pcp-mpstat -T
NOTES

This utility relies on the Performance Co-Pilot (PCP) infrastructure to collect and process performance data. Ensure that PCP daemons are running and configured correctly for real-time monitoring.

ENVIRONMENT

No specific environment variables are required for basic operation, but PCP-specific environment variables can influence its behavior (see PCP_ENVIRONMENT).

PCP ENVIRONMENT

PCP_LOG/-V/-EDIR
See pmcd.conf(5) for more information on the PCP environment.
