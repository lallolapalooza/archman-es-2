PCP-SHPING(1) Manual de comandos generales PCP-SHPING(1)

NOMBRE

pcp-shping - informa sobre la disponibilidad y respuesta del servicio shell

SINOPSIS

pcp [opciones de pcp] shping [-cl?] etiqueta ...

DESCRIPCIÓN

pcp-shping muestrea e informa sobre las métricas del servicio shell-ping exportadas por el agente pmdashping(1).

El informe predeterminado de pcp-shping muestra dos columnas para cada etiqueta de servicio, la primera muestra el estado del servicio (cero indicando éxito) y la segunda el tiempo de respuesta del servicio, para el último ciclo de actualización del comando pmdashping.

Cuando se invoca a través del comando pcp(1), las opciones de pcp como -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone y varias otras están indirectamente disponibles; consulte PCPIntro(1) para sus descripciones.

OPCIONES

Las opciones disponibles en la línea de comandos son:

-c, --status
Muestra un resumen del colector shell-ping actual, incluyendo información sobre el intervalo de actualización del servicio, la configuración actual del tiempo de espera del comando, el recuento de actualizaciones y la línea de comandos completa asociada con cada etiqueta.
-l, --tags
Muestra las etiquetas válidas.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

VER TAMBIÉN

PCPIntro(1), pcp(1) y pmdashping(1).
