pcre2_general_context_create(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_GENERAL_CONTEXT_CREATE(3) Manual de funciones de la biblioteca PCRE2_GENERAL_CONTEXT_CREATE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

pcre2_general_context *pcre2_general_context_create(
  void *(*private_malloc)(size_t, void *),
  void (*private_free)(void *, void *), void *memory_data);

DESCRIPCIÓN

Esta función crea e inicializa un contexto general. Los argumentos definen funciones personalizadas de gestión de memoria y un valor de datos que se pasa a ellas cuando se llaman. La función private_malloc() se utiliza para obtener memoria para el contexto. Si alguno de los dos primeros argumentos es NULL, se utiliza la función de gestión de memoria del sistema. El resultado es NULL si no se pudo obtener memoria.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
