PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3) Manual de funciones de la biblioteca PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_set_substitute_case_callout(pcre2_match_context *mcontext,
  PCRE2_SIZE (*callout_function)(PCRE2_SPTR, PCRE2_SIZE,
                                 PCRE2_UCHAR *, PCRE2_SIZE,
                                 int, void *),
  void *callout_data);

DESCRIPCIÓN

Esta función establece los campos de llamada de sustitución de mayúsculas/minúsculas en un contexto de coincidencia (el primer argumento). El segundo argumento especifica una función de llamada y el tercer argumento es un elemento de datos opaco que se le pasa. El resultado de esta función es siempre cero.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
