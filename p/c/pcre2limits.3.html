NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

TAMAÑO Y OTRAS LIMITACIONES

Existen algunas limitaciones de tamaño en PCRE2, pero se espera que nunca sean relevantes en la práctica.

El tamaño máximo de un patrón compilado es de aproximadamente 64 mil unidades de código para las bibliotecas de 8 y 16 bits si PCRE2 se compila con un tamaño de enlace interno predeterminado, que es de 2 bytes para estas bibliotecas. Si desea procesar expresiones regulares verdaderamente enormes, puede compilar PCRE2 con un tamaño de enlace interno de 3 o 4 (al compilar la biblioteca de 16 bits, 3 se redondea a 4). Consulte el archivo README en la distribución fuente y la documentación de pcre2build para obtener detalles. En estos casos, el límite es sustancialmente mayor. Sin embargo, la velocidad de ejecución es más lenta. En la biblioteca de 32 bits, el tamaño de enlace interno siempre es 4.

La longitud máxima de una cadena de patrón fuente es esencialmente ilimitada; es el número más grande que puede contener una variable PCRE2_SIZE. Sin embargo, el programa que llama a pcre2_compile() puede especificar un límite menor.

La longitud máxima (en unidades de código) de una cadena sujeto es uno menos que el número más grande que puede contener una variable PCRE2_SIZE. PCRE2_SIZE es un tipo de entero sin signo, generalmente definido como size_t. Su valor máximo (es decir, ~(PCRE2_SIZE)0) se reserva como un indicador especial para cadenas terminadas en nulo y desplazamientos no establecidos.

Todos los valores en cuantificadores repetidos deben ser menores de 65536.

Existen dos límites diferentes que se aplican a las ramas de las asericiones de lookbehind. Si cada rama en dicha aserción coincide con un número fijo de caracteres, la longitud máxima de cualquier rama es de 65535 caracteres. Si alguna rama coincide con un número variable de caracteres, entonces la longitud máxima de coincidencia para cada rama está limitada. El límite predeterminado se establece en el momento de la compilación, por defecto 255, pero puede ser cambiado por el programa que llama.

No hay límite en el número de grupos entre paréntesis, pero no puede haber más de 65535 grupos de captura, y hay un límite en la profundidad de anidamiento de subpatrones entre paréntesis de todo tipo. Esto se impone para limitar la cantidad de pila del sistema utilizada en el momento de la compilación. El límite predeterminado se puede especificar al compilar PCRE2; si no, el valor predeterminado se establece en 250. Una aplicación puede cambiar este límite llamando a pcre2_set_parens_nest_limit() para establecer el límite en un contexto de compilación.

La longitud máxima del nombre para un grupo de captura con nombre, así como el número de dichos grupos, es configurable en el momento de la compilación. La longitud máxima del nombre por defecto es de 128 unidades de código, y el número máximo de dichos grupos es de 10000.

La longitud máxima de un nombre en un verbo (*MARK), (*PRUNE), (*SKIP) o (*THEN) es de 255 unidades de código para la biblioteca de 8 bits y 65535 unidades de código para las bibliotecas de 16 y 32 bits.

La longitud máxima de una cadena de argumento para una llamada de atención es el número más grande que puede contener un entero sin signo de 32 bits.

La cantidad máxima de memoria del montón utilizada para la coincidencia se controla mediante el límite del montón, que se puede establecer en un patrón o en un contexto de coincidencia. El valor predeterminado es un número muy grande, efectivamente ilimitado.
