pcap_open_dead.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_OPEN_DEAD(3PCAP) PCAP_OPEN_DEAD(3PCAP)

NOMBRE

pcap_open_dead, pcap_open_dead_with_tstamp_precision - abrir un pcap_t falso para compilar filtros o abrir una captura para salida

SINOPSIS

#include <pcap/pcap.h>
pcap_t *pcap_open_dead(int linktype, int snaplen);
pcap_t *pcap_open_dead_with_tstamp_precision(int linktype, int snaplen,
    u_int precision);

DESCRIPCIÓN

pcap_open_dead() y pcap_open_dead_with_tstamp_precision() se utilizan para crear una estructura pcap_t para usar al llamar a las otras funciones en libpcap. Típicamente se usa cuando solo se usa libpcap para compilar código BPF; también se puede usar si se utilizan pcap_dump_open(3PCAP), pcap_dump(3PCAP), y pcap_dump_close(3PCAP) para escribir un archivo de guardado si no hay un pcap_t que proporcione los paquetes a escribir.

linktype especifica el tipo de capa de enlace para el pcap_t.

snaplen especifica la longitud de la instantánea para el pcap_t.

Cuando se usa pcap_open_dead_with_tstamp_precision() para crear un pcap_t para usar con pcap_dump_open(), precision especifica la precisión de la marca de tiempo para los paquetes; se debe especificar PCAP_TSTAMP_PRECISION_MICRO si los paquetes a escribir tienen marcas de tiempo en segundos y microsegundos, y se debe especificar PCAP_TSTAMP_PRECISION_NANO si los paquetes a escribir tienen marcas de tiempo en segundos y nanosegundos. Su valor no afecta a pcap_compile(3PCAP).

COMPATIBILIDAD ANTERIOR

La función pcap_open_dead_with_tstamp_precision() estuvo disponible en la versión 1.5.1 de libpcap. En versiones anteriores, no había mecanismo para abrir un archivo de guardado para escritura con marcas de tiempo dadas en segundos y nanosegundos.
