pcre2_dfa_match(3)

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_DFA_MATCH(3) Manual de funciones de biblioteca PCRE2_DFA_MATCH(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_dfa_match(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext,
  int *workspace, PCRE2_SIZE wscount);

DESCRIPCIÓN

Esta función compara una expresión regular compilada con una cadena sujeto dada, utilizando un algoritmo de coincidencia alternativo que escanea la cadena sujeto solo una vez (excepto al procesar aserciones de mirada hacia atrás). Esta función *no* es compatible con Perl (la función de coincidencia compatible con Perl es pcre2_match()). Los argumentos para esta función son:


code Puntero al patrón compilado
subject Puntero a la cadena sujeto
length Longitud de la cadena sujeto
startoffset Desplazamiento en el sujeto donde comenzar la coincidencia
options Bits de opciones
match_data Puntero a un bloque de datos de coincidencia, para resultados
mcontext Puntero a un contexto de coincidencia, o es NULL
workspace Puntero a un vector de enteros utilizado como espacio de trabajo
wscount Número de elementos en el vector

El tamaño del vector de salida necesario para contener todos los resultados depende del número de coincidencias simultáneas, no del número de paréntesis en el patrón. Por lo tanto, no se recomienda usar pcre2_match_data_create_from_pattern() para crear el bloque de datos de coincidencia cuando se utiliza esta función.

Se necesita un contexto de coincidencia solo si desea configurar una función de llamada o especificar el límite de memoria o los límites de profundidad de coincidencia o recursión. Los valores de length y startoffset son unidades de código, no caracteres. Las opciones son:


PCRE2_ANCHORED Coincidir solo en la primera posición
PCRE2_COPY_MATCHED_SUBJECT
En caso de éxito, crear una copia privada del sujeto
PCRE2_ENDANCHORED El patrón solo puede coincidir al final del sujeto
PCRE2_NOTBOL El sujeto no es el principio de una línea
PCRE2_NOTEOL El sujeto no es el final de una línea
PCRE2_NOTEMPTY Una cadena vacía no es una coincidencia válida
PCRE2_NOTEMPTY_ATSTART Una cadena vacía al principio del sujeto
no es una coincidencia válida
PCRE2_NO_UTF_CHECK No comprobar la validez UTF del sujeto
(solo relevante si PCRE2_UTF
se estableció en tiempo de compilación)
PCRE2_PARTIAL_HARD Devolver PCRE2_ERROR_PARTIAL para una coincidencia
parcial incluso si hay una coincidencia completa
PCRE2_PARTIAL_SOFT Devolver PCRE2_ERROR_PARTIAL para una coincidencia
parcial si no se encuentran coincidencias completas
PCRE2_DFA_RESTART Reiniciar después de una coincidencia parcial
PCRE2_DFA_SHORTEST Devolver solo la coincidencia más corta

Existen restricciones sobre lo que puede aparecer en un patrón al utilizar esta función de coincidencia. Los detalles se dan en la documentación de pcre2matching. Para obtener detalles sobre la coincidencia parcial, consulte la página pcre2partial. Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
