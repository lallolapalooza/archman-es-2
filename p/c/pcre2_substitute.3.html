PCRE2_SUBSTITUTE(3) Manual de funciones de biblioteca PCRE2_SUBSTITUTE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_substitute(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext, PCRE2_SPTR replacement,
  PCRE2_SIZE rlength, PCRE2_UCHAR *outputbuffer,
  PCRE2_SIZE *outlengthptr);

DESCRIPCIÓN

Esta función compara una expresión regular compilada con una cadena de sujeto dada, utilizando un algoritmo de comparación similar al de Perl. Luego, realiza una copia del sujeto, sustituyendo una cadena de reemplazo por lo que se encontró. Sus argumentos son:


code Puntero al patrón compilado
subject Puntero a la cadena del sujeto
length Longitud de la cadena del sujeto
startoffset Desplazamiento en el sujeto donde comenzar la comparación
options Bits de opciones
match_data Puntero a un bloque de datos de coincidencia, o es NULL
mcontext Puntero a un contexto de coincidencia, o es NULL
replacement Puntero a la cadena de reemplazo
rlength Longitud de la cadena de reemplazo
outputbuffer Puntero al búfer de salida
outlengthptr Puntero a la longitud del búfer de salida

Se necesita un bloque de datos de coincidencia solo si desea inspeccionar los datos de la coincidencia final que se devuelve en ese bloque o si se establece PCRE2_SUBSTITUTE_MATCHED. Se necesita un contexto de coincidencia solo si desea:


Configurar una función de llamada
Establecer un límite de desplazamiento de coincidencia
Cambiar el límite de coincidencia de retroceso
Cambiar el límite de profundidad de retroceso
Establecer una gestión de memoria personalizada en el contexto de coincidencia

Los valores de length, startoffset y rlength son unidades de código, no caracteres, al igual que el contenido de la variable apuntada por outlengthptr. Esta variable debe contener la longitud del búfer de salida cuando se llama a la función. Si la función tiene éxito, el valor se cambia a la longitud de la nueva cadena, excluyendo el cero final que se agrega automáticamente.

Las longitudes del sujeto y el reemplazo se pueden proporcionar como PCRE2_ZERO_TERMINATED para cadenas terminadas en cero. Las opciones son:


PCRE2_ANCHORED Coincidir solo en la primera posición
PCRE2_ENDANCHORED Coincidir solo al final del sujeto
PCRE2_NOTBOL El sujeto no es el principio de una
línea
PCRE2_NOTEOL El sujeto no es el final de una línea
PCRE2_NOTEMPTY Una cadena vacía no es una
coincidencia válida
PCRE2_NOTEMPTY_ATSTART Una cadena vacía al principio del
sujeto no es una coincidencia válida
PCRE2_NO_JIT No usar coincidencia JIT
PCRE2_NO_UTF_CHECK No verificar la validez UTF en
el sujeto o reemplazo
(solo relevante si se estableció PCRE2_UTF
en tiempo de compilación)
PCRE2_SUBSTITUTE_EXTENDED Procesar reemplazos extendidos
PCRE2_SUBSTITUTE_GLOBAL Reemplazar todas las ocurrencias en el
sujeto
PCRE2_SUBSTITUTE_LITERAL La cadena de reemplazo es literal
PCRE2_SUBSTITUTE_MATCHED Usar datos de coincidencia preexistentes para
la primera coincidencia
PCRE2_SUBSTITUTE_OVERFLOW_LENGTH Si hay desbordamiento, calcular la longitud necesaria
PCRE2_SUBSTITUTE_REPLACEMENT_ONLY Devolver solo cadena(s) de reemplazo
PCRE2_SUBSTITUTE_UNKNOWN_UNSET Tratar grupo desconocido como no establecido
PCRE2_SUBSTITUTE_UNSET_EMPTY Inserción simple de no establecido = cadena vacía

Si se establece PCRE2_SUBSTITUTE_LITERAL, se ignoran PCRE2_SUBSTITUTE_EXTENDED, PCRE2_SUBSTITUTE_UNKNOWN_UNSET y PCRE2_SUBSTITUTE_UNSET_EMPTY.

Si se establece PCRE2_SUBSTITUTE_MATCHED, match_data debe ser no nulo; su contenido debe ser el resultado de una llamada a pcre2_match() (o pcre2_jit_match()) utilizando el mismo patrón, puntero al sujeto, longitud efectiva del sujeto, desplazamiento de inicio y opciones de coincidencia.

La función devuelve el número de sustituciones, que puede ser cero si no hay coincidencias. El resultado puede ser mayor que uno solo cuando se establece PCRE2_SUBSTITUTE_GLOBAL. En caso de error, se devuelve un código de error negativo.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
