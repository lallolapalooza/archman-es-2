PCP-UPTIME(1) Manual de Comandos Generales PCP-UPTIME(1)

NOMBRE

pcp-uptime - indica cuánto tiempo lleva funcionando el sistema

SINOPSIS

pcp [opciones de pcp] uptime [-V?]

DESCRIPCIÓN

pcp-uptime proporciona una visualización en una sola línea de la siguiente información. La hora actual, cuánto tiempo lleva funcionando el sistema, cuántos usuarios están conectados actualmente y las cargas promedio del sistema durante los últimos 1, 5 y 15 minutos.

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -Z/--timezone y varias opciones de pcp se vuelven indirectamente disponibles.

OPCIONES

Las opciones de línea de comandos disponibles son:

-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

Al reproducir desde un archivo usando la opción -a, la información requerida puede no estar disponible en la hora de inicio predeterminada, en cuyo caso los valores informados serán ``?''. En este caso, use las opciones -S u -O para mover la hora de inicio a un punto en el archivo donde la información requerida esté disponible.

NOTAS

pcp-uptime está inspirado en el comando uptime(1) y pretende ser compatible con él en línea de comandos y salida.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para conocer las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN

PCPIntro(1), pcp(1), uptime(1) y environ(7).
