pcre_maketables(3)

Paquete: pcre

Licencias: BSD

PCRE_MAKETABLES(3) Manual de Funciones de Biblioteca PCRE_MAKETABLES(3)

NOMBRE

PCRE - Expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

const unsigned char *pcre_maketables(void);

const unsigned char *pcre16_maketables(void);

const unsigned char *pcre32_maketables(void);

DESCRIPCIÓN

Esta función construye un conjunto de tablas de caracteres para valores de caracteres menores que 256. Estas pueden pasarse a pcre[16|32]_compile() para anular las tablas internas integradas de PCRE (que fueron creadas por pcre[16|32]_maketables() cuando se compiló PCRE). Puede que quieras hacer esto si estás usando una configuración regional no estándar. La función devuelve un puntero a las tablas.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
