NOMBRE

pcap_can_set_rfmon - comprobar si el modo monitor puede ser establecido para un manejador de captura no activado aún

SINOPSIS

#include <pcap/pcap.h>
int pcap_can_set_rfmon(pcap_t *p);

DESCRIPCIÓN

pcap_can_set_rfmon() comprueba si el modo monitor podría ser establecido en un manejador de captura cuando el manejador sea activado.

VALOR DE RETORNO

pcap_can_set_rfmon() devuelve 0 si el modo monitor no pudo ser establecido, 1 si el modo monitor pudo ser establecido, y un valor negativo en caso de error. Un valor de retorno negativo indica qué condición de error ocurrió. Los valores de error posibles son:

PCAP_ERROR_NO_SUCH_DEVICE
La fuente de captura especificada al crear el manejador no existe.
PCAP_ERROR_PERM_DENIED
El proceso no tiene permiso para comprobar si el modo monitor podría ser soportado.
PCAP_ERROR_ACTIVATED
El manejador de captura ya ha sido activado.
PCAP_ERROR
Ocurrió otro error. Se puede llamar a pcap_geterr(3PCAP) o pcap_perror(3PCAP) con p como argumento para obtener o mostrar un mensaje que describa el error.

Se pueden añadir códigos de error adicionales en el futuro; un programa debe comprobar si los valores de retorno son 0, 1 y negativos, y tratar todos los códigos de retorno negativos como errores. Se puede llamar a pcap_statustostr(3PCAP), con un código de advertencia o error como argumento, para obtener un mensaje que describa el código de advertencia o error.

VER TAMBIÉN

pcap(3PCAP), pcap_create(3PCAP), pcap_activate(3PCAP), pcap_set_rfmon(3PCAP)
