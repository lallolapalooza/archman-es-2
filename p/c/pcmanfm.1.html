NOMBRE

PCManFM - Gestor de archivos ligero basado en Gtk+ para X Window.

SINOPSIS

pcmanfm [ opciones ] [ directorios ]

DESCRIPCIÓN

PCMan File Manager (PCManFM) es un gestor de archivos extremadamente rápido, ligero, pero rico en funciones con navegación por pestañas. Es el gestor de archivos predeterminado para el entorno de escritorio ligero, LXDE.
Características:
* Extremadamente rápido y ligero
* Puede iniciarse en un segundo en una máquina normal
* Navegación por pestañas (similar a Firefox)
* Manejo de arrastrar y soltar con soporte XDS (guardado directo X)
* Los archivos se pueden arrastrar entre pestañas
* Carga directorios grandes en tiempo razonable
* Soporte de asociación de archivos (con configuración de aplicación predeterminada)
* Soporte básico de miniaturas con soporte EXIF opcional
* Soporte de marcadores
* Maneja nombres de archivo codificados que no son UTF-8 correctamente
* Proporciona vista de iconos y vista de lista detallada
* Cumple con los estándares (sigue las especificaciones FreeDesktop.org)
* Interfaz limpia y fácil de usar (GTK+ 2.0)
* Gestión completa del escritorio
* Puede establecer fondos de pantalla individuales para cada espacio de trabajo
* Soporte de montaje de medios extraíbles
* Acceso transparente a sistemas de archivos remotos como sftp, smb y ftp
* Soporte de papelera

OPCIONES

Opciones globales:

-d, --daemon-mode
ejecuta PCManFM como un demonio (ignorado si otro PCManFM ya está en ejecución)
-p perfil, --profile=perfil
carga un perfil de configuración diferente en lugar de "default"
--no-desktop
para compatibilidad con Nautilus

Opciones por instancia:

--desktop
inicia el gestor de escritorio (ignora -d)
--desktop-off
desactiva el gestor de escritorio si está en ejecución
--desktop-pref
abre el diálogo de preferencias del escritorio
--one-screen
gestiona el escritorio solo en la pantalla X actual (solo si se usa --desktop)
-n, --new-win
abre directorios en una ventana nueva
--role
establece el rol X para la ventana (solo si se usa -n)
--wallpaper-mode=modo
Establece el modo del fondo de pantalla del escritorio, modo es:
color (rellenar con color sólido),
stretch (estirar para llenar todo el monitor),
fit (estirar para ajustar al tamaño del monitor),
center (colocar en el centro del monitor),
tile (repetir para llenar todo el monitor),
crop (estirar y recortar para llenar el monitor), o
screen (estirar para llenar toda la pantalla)
-w archivo, --set-wallpaper=archivo
establece el fondo de pantalla del escritorio desde el archivo de imagen archivo
--show-pref n
abre el diálogo de preferencias en la página n
-f, --find-files
abre una ventana de diálogo de búsqueda de archivos
directorios
directorios a abrir

GESTIÓN DEL ESCRITORIO

El gestor de archivos PCMan puede administrar tu escritorio. Esto incluye dibujar un fondo en él y mostrar iconos de la carpeta Escritorio. Para activar la gestión del escritorio, pcmanfm debe ejecutarse con la opción --desktop. Otra opción que afecta a este modo es --one-screen. Puedes cambiar los parámetros del gestor de escritorio en ejecución ejecutando pcmanfm con la opción --desktop-pref, que abre una ventana con las preferencias, o utilizando los parámetros de línea de comandos para las opciones --set-wallpaper o --wallpaper-mode. La ejecución pcmanfm --desktop-off termina la gestión del escritorio.

Mientras pcmanfm gestiona el escritorio, muestra iconos en él. El comportamiento de los iconos se asemeja a la vista de carpetas en la ventana principal de pcmanfm, pero los iconos en el escritorio pueden "recordar" su posición. Si tienes dos o más monitores, el fondo de escritorio y el conjunto de iconos se mostrarán en cada uno de ellos. Las posiciones de los iconos se recordarán individualmente para cada monitor.

ENTORNO

XDG_CURRENT_DESKTOP
El entorno de escritorio actual. Esta variable afecta a los elementos que se mostrarán en la carpeta menu://applications/.
XDG_MENU_PREFIX
El prefijo para el archivo XML de definición del menú XDG. Esta variable afecta al diseño de los elementos que se muestran en la carpeta menu://applications/.

ARCHIVOS

~/.config/pcmanfm/default
El directorio de perfil de configuración predeterminado
~/.config/pcmanfm/default/pcmanfm.conf
El archivo de configuración principal
~/.config/pcmanfm/default/desktop-items-0.conf
La disposición de los elementos del escritorio para la pantalla 0 (pantalla principal)
