pcap_open_offline.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_OPEN_OFFLINE(3PCAP) PCAP_OPEN_OFFLINE(3PCAP)

NOMBRE

pcap_open_offline, pcap_open_offline_with_tstamp_precision, pcap_fopen_offline, pcap_fopen_offline_with_tstamp_precision - abrir un archivo de captura guardado para lectura

SINOPSIS

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_open_offline(const char *fname, char *errbuf);
pcap_t *pcap_open_offline_with_tstamp_precision(const char *fname,
    u_int precision, char *errbuf);
pcap_t *pcap_fopen_offline(FILE *fp, char *errbuf);
pcap_t *pcap_fopen_offline_with_tstamp_precision(FILE *fp,
    u_int precision, char *errbuf);

DESCRIPCIÓN

pcap_open_offline() y pcap_open_offline_with_tstamp_precision() se llaman para abrir un "savefile" para lectura.

fname especifica el nombre del archivo a abrir. El archivo puede tener el formato de archivo pcap descrito en pcap-savefile(5), que es el formato de archivo utilizado por, entre otros programas, tcpdump(1) y tcpslice(1), o puede tener el formato de archivo pcapng, aunque no todos los archivos pcapng pueden ser leídos. El nombre "-" es un sinónimo de stdin.

pcap_open_offline_with_tstamp_precision() toma un argumento adicional precision especificando la precisión de marca de tiempo deseada; si se especifica PCAP_TSTAMP_PRECISION_MICRO, las marcas de tiempo de los paquetes se proporcionarán en segundos y microsegundos, y si se especifica PCAP_TSTAMP_PRECISION_NANO, las marcas de tiempo de los paquetes se proporcionarán en segundos y nanosegundos. Si las marcas de tiempo en el archivo no tienen la misma precisión que la precisión solicitada, se escalarán hacia arriba o hacia abajo según sea necesario antes de ser proporcionadas.

Alternativamente, puede llamar a pcap_fopen_offline() o pcap_fopen_offline_with_tstamp_precision() para leer datos volcados de un flujo abierto existente fp. pcap_fopen_offline_with_tstamp_precision() toma un argumento adicional precision como se describe anteriormente. Tenga en cuenta que en Windows, ese flujo debe abrirse en modo binario.

errbuf es un búfer lo suficientemente grande como para contener al menos PCAP_ERRBUF_SIZE caracteres.

VALOR DE RETORNO

pcap_open_offline(), pcap_open_offline_with_tstamp_precision(), pcap_fopen_offline(), y pcap_fopen_offline_with_tstamp_precision() devuelven un pcap_t * en caso de éxito y NULL en caso de fallo. Si se devuelve NULL, errbuf se rellena con un mensaje de error apropiado.

COMPATIBILIDAD RETROACTIVA

pcap_open_offline_with_tstamp_precision() y pcap_fopen_offline_with_tstamp_precision() estuvieron disponibles en la versión 1.5.1 de libpcap. En versiones anteriores, las marcas de tiempo de un savefile siempre se dan en segundos y microsegundos.
