pcre_assign_jit_stack(3)

Paquete: pcre

Licencias: BSD

PCRE_ASSIGN_JIT_STACK(3) Manual de Funciones de Librería PCRE_ASSIGN_JIT_STACK(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

void pcre_assign_jit_stack(pcre_extra *extra,
     pcre_jit_callback callback, void *data);

void pcre16_assign_jit_stack(pcre16_extra *extra,
     pcre16_jit_callback callback, void *data);

void pcre32_assign_jit_stack(pcre32_extra *extra,
     pcre32_jit_callback callback, void *data);

DESCRIPCIÓN

Esta función proporciona control sobre la memoria utilizada como pila en tiempo de ejecución por una llamada a pcre[16|32]_exec() con un patrón que ha sido compilado exitosamente con optimización JIT. Los argumentos son:


extra el puntero de datos devuelto por pcre[16|32]_study()
callback una función de callback
data una pila JIT o un valor a pasar a la función de callback
función

Si callback es NULL y data es NULL, se utiliza un bloque interno de 32K en la pila de la máquina.

Si callback es NULL y data no es NULL, data debe ser una pila JIT válida, el resultado de llamar a pcre[16|32]_jit_stack_alloc().

Si callback no es NULL, se llama con data como argumento al inicio de la coincidencia, para configurar una pila JIT. Si el resultado es NULL, se utiliza la pila interna de 32K; de lo contrario, el valor de retorno debe ser una pila JIT válida, el resultado de llamar a pcre[16|32]_jit_stack_alloc().

Puede asignar de forma segura la misma pila JIT a múltiples patrones, siempre que todos ellos se utilicen en el mismo hilo. En una aplicación multihilo, cada hilo debe usar su propia pila JIT. Para más detalles, consulte la página pcrejit.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
