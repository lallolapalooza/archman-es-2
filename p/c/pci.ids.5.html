pci.ids(5) Las Utilidades PCI pci.ids(5)

NOMBRE

pci.ids - lista de identificadores conocidos relacionados con dispositivos PCI

INTRODUCCIÓN

Los dispositivos en el bus PCI se identifican mediante una combinación de un ID de proveedor (asignado por el PCI SIG) y un ID de dispositivo (asignado por el proveedor). Ambos IDs son enteros de 16 bits y el propio dispositivo no proporciona ninguna traducción a una cadena legible por humanos.

Además del proveedor y el dispositivo, los dispositivos también informan varios identificadores más:

  • Clase y subclase del dispositivo (dos números hexadecimales de 8 bits)
  • Interfaz de programación (número de 8 bits, cuyo significado es específico para la subclase)
  • Subsistema, que identifica el ensamblaje en el que se encuentra el dispositivo. Un ejemplo típico es una tarjeta adicional de Ethernet: el dispositivo es el chip controlador de Ethernet, mientras que la tarjeta juega el papel del subsistema. Los subsistemas tienen su ID de proveedor (del mismo espacio de nombres que los proveedores de dispositivos) y su ID de subsistema. Generalmente, el significado del ID de subsistema depende del dispositivo, pero hay casos en los que un solo ID de subsistema se utiliza para muchos dispositivos, por ejemplo, placas base de portátiles.

    Las utilidades PCI utilizan el archivo pci.ids para traducir todos estos IDs numéricos a cadenas.

MANTENER LA LISTA ACTUALIZADA

El archivo pci.ids se genera a partir de la base de datos de IDs PCI, que se mantiene en https://pci-ids.ucw.cz/. Si encuentra algún ID que falte en la lista, por favor, contribúyalo a la base de datos.

Puede utilizar el comando update-pciids para descargar la versión actual de la lista.

Alternativamente, puede usar lspci -q para consultar la base de datos en línea.

FORMATO DEL ARCHIVO

El archivo pci.ids es un archivo de texto en ASCII plano, interpretado línea por línea. Las líneas que comienzan con el signo de almohadilla (#) se tratan como comentarios y se ignoran. Los comentarios relativos a una entrada específica se escriben inmediatamente antes de la entrada.

Las entradas de proveedor comienzan con un ID de proveedor hexadecimal de 4 dígitos, seguido de uno o más espacios, y el nombre del proveedor que se extiende hasta el final de la línea.

Las entradas de dispositivo se colocan debajo de la entrada del proveedor. Cada entrada de dispositivo consta de un único carácter TAB, un ID de dispositivo hexadecimal de 4 dígitos, seguido de uno o más espacios, y el nombre del dispositivo que se extiende hasta el final de la línea.

Las entradas de subsistema se colocan debajo de la entrada del dispositivo. Comienzan con dos caracteres TAB, un ID de proveedor hexadecimal de 4 dígitos (que debe definirse en otro lugar de la lista), un solo espacio, un ID de subsistema hexadecimal de 4 dígitos, uno o más espacios y el nombre del subsistema que se extiende hasta el final de la línea.

Las entradas de clase consisten en "C", un espacio, ID de clase hexadecimal de 2 dígitos, uno o más espacios y el nombre de la clase. Las subclases se colocan debajo de la clase correspondiente, indentadas por un solo TAB, seguidas de un ID de subclase hexadecimal de 2 dígitos, uno o más espacios y el nombre de la subclase. Las interfaces de programación están debajo de la subclase, indentadas por dos TABs, seguidas de un ID de interfaz de programación hexadecimal de 2 dígitos, uno o más espacios y el nombre.

Puede haber IDs de subsistema independientes del dispositivo, aunque la interfaz web de la base de datos aún no los admite. Comienzan con una línea de ID de proveedor de subsistema que consiste en "S", un espacio y un ID de proveedor hexadecimal de 4 dígitos (que debe corresponder a un proveedor ya listado). Los subsistemas siguen en líneas posteriores, cada uno indentado por un TAB, seguido de un ID de subsistema hexadecimal de 4 dígitos, uno o más espacios y el nombre del subsistema.

Para garantizar la extensibilidad del formato, las líneas que comienzan con una letra no reconocida seguida de un solo espacio se ignoran, al igual que todas las líneas indentadas con TAB subsiguientes.
