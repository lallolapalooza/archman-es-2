NOMBRE

pcap-config - escribe las opciones del compilador y enlazador de libpcap en la salida estándar

SINOPSIS

pcap-config [ --help ] [ --version ] [ --cflags ] [ --libs | --additional-libs ] [ --static | --static-pcap-only ]

DESCRIPCIÓN

pcap-config escribe en la salida estándar varias opciones del compilador y enlazador requeridas para construir un programa de usuario con libpcap. Por defecto, escribe opciones apropiadas para construir con una versión enlazada dinámicamente de libpcap; véase más abajo para el enlazado estático. Dependiendo de la forma de instalación de libpcap, algunas opciones o sus combinaciones pueden producir una salida vacía - esto es por diseño.

OPCIONES

--help
Muestra un mensaje de ayuda y sale.
--version
Muestra la versión de libpcap y sale. La versión es el contenido del archivo VERSION en el árbol fuente de libpcap en lugar del resultado de pcap_lib_version(3PCAP).
--cflags
Escribe la opción del compilador -I requerida para incluir los archivos de cabecera de libpcap.
--libs
Escribe las opciones del enlazador -L y -l requeridas para enlazar con libpcap, incluyendo las opciones -l para las librerías requeridas por libpcap.
--additional-libs
Escribe las opciones del enlazador -L y -l para las librerías requeridas por libpcap, pero no la opción -l para enlazar con libpcap en sí.
--static
Esta opción hace que --libs y --additional-libs produzcan opciones de enlazador apropiadas para el enlazado estático con libpcap.
--static-pcap-only
Esta opción hace que --libs y --additional-libs produzcan opciones de enlazador apropiadas para el enlazado estático con libpcap y enlazado dinámico con todas las demás librerías, incluyendo las librerías requeridas por libpcap.

ESTADO DE SALIDA

pcap-config sale con un estado distinto de cero cuando se invoca con una opción de línea de comandos inválida, y con estado 0 en caso contrario.

COMPATIBILIDAD HACIA ATRÁS

Antes de la versión 1.10.2 de libpcap, pcap-config no trataba las opciones de línea de comandos inválidas como un error. La opción --static-pcap-only estuvo disponible a partir de la versión 1.10.2 de libpcap. La opción --static estuvo disponible a partir de la versión 1.1.0 de libpcap.
