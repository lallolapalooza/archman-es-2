PCP-XSOS(1) Manual de Comandos Generales PCP-XSOS(1)

NOMBRE

pcp-xsos - informes resumidos de alto nivel para un sistema

SINOPSIS

pcp [opciones de pcp] xsos [--all] [-dmnNopx] [-u unidades]

DESCRIPCIÓN

pcp-xsos proporciona un informe resumido de un sistema utilizando un archivo PCP o valores métricos en vivo de ese sistema.

Está diseñado para ser rápido y realiza una sola muestra, similar a herramientas como ps(1). Por lo tanto, el nivel de detalle en los informes se sacrifica en favor de la velocidad de ejecución. pcp-xsos está diseñado como una herramienta inicial de triaje de rendimiento que informa rápidamente a un operador sobre las vías de investigación que pueden resultar más fructíferas. En este momento, el enfoque está completamente en las métricas del sistema operativo, sin embargo, esto no es un requisito y con el tiempo puede extenderse para informar sobre cualquier dominio de rendimiento con métricas PCP asociadas.

Cuando se invoca a través del comando pcp(1), las opciones de pcp -h/--host, -a/--archive, -O/--origin se vuelven indirectamente disponibles, consulte PCPIntro(1) para sus descripciones.

El informe predeterminado sin opciones de línea de comandos es la visión general del sistema operativo.

OPCIONES

Las opciones de línea de comandos disponibles son:

--all
informar iterativamente cada subsección, una tras otra.
-o, --os
mostrar el informe predeterminado con información del kernel de alto nivel, incluida la versión, el tiempo de actividad, el número de usuarios, los estados de los procesos y la utilización agregada del procesador.
-d, --disks
Informar información de almacenamiento del archivo o del host en vivo, incluida la capacidad total para cada dispositivo de bloque, así como el espacio libre del sistema de archivos para cada sistema de archivos montado.
-m, --memory
Informe detallado de memoria, incluido el porcentaje de memoria total utilizada para diversas funciones del sistema operativo, uso de swap y, opcionalmente, información sobre páginas gigantes y globos de máquinas virtuales.
-n, --netdev
Estadísticas para cada interfaz de red configurada, incluidas las tasas de transferencia de paquetes y bytes (desde el arranque), errores, caídas, etc. Además, también se informan estadísticas de sockets con esta opción de línea de comandos, para TCP y UDP en bruto (IPv4 e IPv6).
-N, --netstats
Informar estadísticas de red agregadas, como varios contadores de errores y tiempos de espera de ICMP y TCP.
-p, --ps
Inspeccionar procesos en ejecución de manera similar a ps. Estos se agrupan y filtran para mostrar los procesos más importantes en términos de uso de recursos (CPU, memoria), así como procesos en estados zombi o bloqueados.
-u unidad, --units=unidad
Cambiar la visualización de bytes para varios informes. Los valores válidos para unidad son "b" (bytes), "k" (kibibytes), "m" (mebibytes), "g" (gibibytes) o "t" (tebibytes).
-x, --nocolor
Mostrar informes sin usar colores para resaltar varios aspectos de cada subsistema.
-?, --help
Mostrar mensaje de uso y salir.

NOTAS

pcp-xsos se inspira en la utilidad xsos, tiene como objetivo ser compatible con la línea de comandos con ella siempre que sea posible y también proporcionar un estilo de salida coherente.

AMBIENTE PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivo y directorio utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para variables de entorno que afectan a las herramientas PCP, consulte pmGetOptions(3), que proporciona la funcionalidad pmgetopt(1) utilizada por pcp-xsos.

VER TAMBIÉN

PCPIntro(1), pcp(1), ps(1), pmgetopt(1), pmGetOptions(3) y environ(7).
