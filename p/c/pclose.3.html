popen(3) Manual de Funciones de Biblioteca popen(3)

NOMBRE

popen, pclose - canalizar flujo hacia o desde un proceso

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
FILE *popen(const char *command, const char *type);
int pclose(FILE *stream);
Requisitos de las Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

popen(), pclose():

    _POSIX_C_SOURCE >= 2
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función popen() abre un proceso creando un pipe, haciendo un fork y invocando al shell. Dado que un pipe es unidireccional por definición, el argumento type solo puede especificar lectura o escritura, no ambas; el flujo resultante es correspondientemente de solo lectura o de solo escritura.

El argumento command es un puntero a una cadena terminada en nulo que contiene una línea de comandos del shell. Este comando se pasa a /bin/sh usando la opción -c; la interpretación, si la hay, la realiza el shell.

El argumento type es un puntero a una cadena terminada en nulo que debe contener la letra 'r' para lectura o la letra 'w' para escritura. Desde glibc 2.9, este argumento puede incluir adicionalmente la letra 'e', que hace que la bandera close-on-exec (FD_CLOEXEC) se establezca en el descriptor de archivo subyacente; ver la descripción de la bandera O_CLOEXEC en open(2) para conocer las razones por las que esto puede ser útil.

El valor de retorno de popen() es un flujo de E/S normal en todos los aspectos excepto que debe cerrarse con pclose() en lugar de con fclose(3). Escribir en dicho flujo escribe en la entrada estándar del comando; la salida estándar del comando es la misma que la del proceso que llamó a popen(), a menos que esto sea modificado por el propio comando. A la inversa, leer del flujo lee la salida estándar del comando, y la entrada estándar del comando es la misma que la del proceso que llamó a popen().

Tenga en cuenta que los flujos de salida de popen() tienen un búfer de bloque por defecto.

La función pclose() espera a que el proceso asociado termine y devuelve el estado de salida del comando tal como lo devuelve wait4(2).

VALOR DE RETORNO

popen(): en caso de éxito, devuelve un puntero a un flujo abierto que puede usarse para leer o escribir en el pipe; si las llamadas a fork(2) o pipe(2) fallan, o si la función no puede asignar memoria, se devuelve NULL.

pclose(): en caso de éxito, devuelve el estado de salida del comando; si wait4(2) devuelve un error, o se detecta algún otro error, se devuelve -1.

En caso de fallo, ambas funciones establecen errno para indicar el error.

ERRORES

La función popen() no establece errno si falla la asignación de memoria. Si el fork(2) o pipe(2) subyacente falla, se establece errno para indicar el error. Si el argumento type es inválido, y esta condición se detecta, se establece errno a EINVAL.

Si pclose() no puede obtener el estado del hijo, errno se establece a ECHILD.

VERSIÓNES

El valor 'e' para type es una extensión de Linux.

ESTÁNDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

PRECAUCIONES

Lea cuidadosamente las Precauciones en system(3).

ERRORES DEL PROGRAMA

Dado que la entrada estándar de un comando abierto para lectura comparte su desplazamiento de búsqueda con el proceso que llamó a popen(), si el proceso original ha realizado una lectura con búfer, la posición de entrada del comando puede no ser la esperada. Similarmente, la salida de un comando abierto para escritura puede mezclarse con la del proceso original. Esto último se puede evitar llamando a fflush(3) antes de popen().

El fallo al ejecutar el shell es indistinguible del fallo del shell al ejecutar el comando, o una salida inmediata del comando. La única pista es un estado de salida de 127.
