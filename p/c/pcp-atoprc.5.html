PCP-ATOPRC(5) Manual de formatos de archivo PCP-ATOPRC(5)

NOMBRE

pcp-atoprc - archivo de recursos de pcp-atop y pcp-atopsar

DESCRIPCIÓN

Esta página del manual documenta el archivo de recursos de los comandos pcp-atop y pcp-atopsar. Estos comandos se pueden utilizar para monitorizar la carga del sistema y de los procesos en un sistema.

El archivo pcp-atoprc contiene los ajustes predeterminados. Estos ajustes se leen durante el inicio, primero desde el archivo rc de todo el sistema /etc/atoprc y después desde el archivo rc específico del usuario ~/.atoprc (por lo que los ajustes de todo el sistema pueden ser anulados por un usuario individual). Las opciones en ambos archivos rc son idénticas.

OPCIONES

El archivo rc contiene pares clave-valor, uno en cada línea (las líneas en blanco y las líneas que comienzan con un signo # se ignoran).
Se pueden especificar las siguientes claves:

flags
Aquí se puede definir una lista de indicadores predeterminados para pcp-atop. Los indicadores permitidos son 'B', 'H', 'g', 'm', 'd', 'n', 'u', 'p', 's', 'c', 'v', 'C', 'M', 'D', 'N', 'A', 'a', 'y', 'f', 'F', 'G', 'R', '1', 'e', 'E' y 'x'.
intervalo
El valor del intervalo predeterminado en segundos.
longitud-linea
La longitud de una línea de pantalla al enviar la salida a un archivo o tubería (predeterminado 80).
nombre-usuario
La expresión regular predeterminada para los usuarios cuyos procesos activos se mostrarán.
nombre-proceso
La expresión regular predeterminada para los nombres de procesos que se mostrarán.
max-linea-cpu
El número máximo de CPUs activas que se mostrarán.
max-linea-gpu
El número máximo de GPUs activas que se mostrarán.
max-linea-lvm
El número máximo de volúmenes lógicos activos que se mostrarán.
max-linea-mdd
El número máximo de dispositivos múltiples activos que se mostrarán.
max-linea-disco
El número máximo de discos activos que se mostrarán.
max-linea-nfsm
El número máximo de montajes NFS que se mostrarán en un cliente NFS.
max-linea-intf
El número máximo de interfaces de red activas que se mostrarán.
max-linea-cont
El número máximo de contenedores activos que se mostrarán.
porcentaje-critico-cpu
El porcentaje de uso considerado crítico para un procesador (ver sección COLORES en la página del manual del comando pcp-atop). Este porcentaje se utiliza para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos en modo texto. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
porcentaje-critico-disco
El porcentaje de uso considerado crítico para un disco (ver sección COLORES en la página del manual del comando pcp-atop). Este porcentaje se utiliza para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos en modo texto. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
porcentaje-critico-red
El porcentaje de uso considerado crítico para una interfaz de red (ver sección COLORES en la página del manual del comando pcp-atop). Este porcentaje se utiliza para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos en modo texto. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
porcentaje-critico-mem
El porcentaje considerado crítico para la utilización de memoria (ver sección COLORES en la página del manual del comando pcp-atop). Este porcentaje se utiliza para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos en modo texto. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
porcentaje-critico-swp
El porcentaje de ocupación considerado crítico para el espacio de intercambio (ver sección COLORES en la página del manual del comando pcp-atop). Este porcentaje se utiliza para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
seg-crit-swpout
El número de páginas intercambiadas por segundo considerado crítico para la utilización de memoria (ver sección COLORES en la página del manual del comando pcp-atop). Este umbral se utiliza en combinación con 'porcentaje-critico-mem' para determinar un porcentaje ponderado para la coloración de líneas y la ordenación de procesos activos. Cuando este valor es cero, no se realiza coloración de líneas ni ordenación automática para este recurso.
casi-critico
Un porcentaje del porcentaje crítico para determinar si el recurso está casi crítico (ver sección COLORES en la página del manual del comando pcp-atop). Cuando este valor es cero, no se realiza coloración de líneas para `casi crítico'.
ancho-barra-cpu
Número de columnas usadas por barra en el gráfico de barras del procesador. El valor predeterminado es 0, lo que significa que el ancho de la barra se escalará automáticamente (cuanto más ancho sea el terminal, más columnas por barra, hasta un máximo de tres). Con los valores 1, 2 o 3, el número de barras se puede fijar estáticamente a ese número de columnas, con una columna de espacio en blanco entre las barras.
info-color
Definición del nombre del color para mensajes de información (predeterminado: verde) en modo texto.
Los colores permitidos son: rojo verde amarillo azul magenta cian negro blanco.
hilo-color
Definición del nombre del color para líneas específicas de hilos al usar la opción 'y' (predeterminado: amarillo).
Los colores permitidos son: rojo verde amarillo azul magenta cian negro blanco.
casi-color
Definición del nombre del color para recursos casi críticos (predeterminado: cian) en modo texto.
Los colores permitidos son: rojo verde amarillo azul magenta cian negro blanco.
critico-color
Definición del nombre del color para recursos críticos (predeterminado: rojo) en modo texto.
Los colores permitidos son: rojo verde amarillo azul magenta cian negro blanco.
indicadores-pcp-atopsar
Aquí se puede definir una lista de indicadores predeterminados para pcp-atopsar. Los indicadores permitidos son 'S', 'x', 'C', 'M', 'H', 'a', 'A' y los indicadores para seleccionar uno o más informes específicos.

Un ejemplo del archivo /etc/atoprc o ~/.atoprc:

 

flags         Aaf
intervalo    5
nombre-usuario
nombre-proceso
max-linea-cpu    4
max-linea-disco   10
max-linea-intf   5
porcentaje-critico-cpu   80
casi-critico    90
indicadores-pcp-atopsar  CMH
linea-propia-proceso PID:50 VGROW:40 RGROW:45 COMMAND-LINE:50
linea-propia-pagina  PAGSCAN:3 BLANKBOX:0 PAGSWIN:3 PAGSWOUT:7

Las claves 'linea-propia-proceso' y 'linea-propia-pagina' se explican en la siguiente sección.

DESCRIPTION

The pcp-atop(1) command can be configured by means of an rc-file. This file is searched for in the directory $HOME/pcp/atoprc. If not found, the system-wide rc-file /etc/pcp/atoprc is used.

OWN DEFINITION OF OUTPUT LINE

The layout of an output-line can be defined as follows (notice that this should be specified as one line in the rcfile):

   keyword   <columnid>:<prio> [<columnid>:<prio> ...]

The columnid is the symbolic name of a column that should shown at this position in the output line.
The prio is a positive integer value that determines which columns have precedence whenever not all specified columns fit into the current screen-width. The higher value, the higher priority.
The column-specifications should be separated by a space. The order in which columns have been specified is the order in which they will be shown, with respect to their priority (columns that do not fit, will be dropped dynamically).

A special columnid for system lines is 'BLANKBOX'. This indicates that an empty column is required at this position. Also this special columnid is followed by a priority (usually low).

The following definition can be specified for process information:

ownprocline
The columnids are the names of the columns that are shown in the normal output of the process-related lines that are shown by pcp-atop such as 'PID', 'CMD', 'S', .... The only exception is the special columnid 'SORTITEM' that is used to show one of the columns CPU%/DSK%/MEM%/NET%, depending on the chosen sort-criterion.
An example of a user-defined process line:
 
ownprocline   PID:20 PPID:10 SYSCPU:15 USRCPU:15 VGROW:14 VSIZE:12 RGROW:14 RSIZE:12 ST:8 EXC:7 S:11 SORTITEM:18 CMD:20
