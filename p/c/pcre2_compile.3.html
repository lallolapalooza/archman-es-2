pcre2_compile(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_COMPILE(3) Manual de Funciones de Biblioteca PCRE2_COMPILE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

pcre2_code *pcre2_compile(PCRE2_SPTR patron, PCRE2_SIZE longitud,
  uint32_t opciones, int *cod_error, PCRE2_SIZE *desplazamiento_error,
  pcre2_compile_context *contexto_compilacion);

DESCRIPCIÓN

Esta función compila un patrón de expresión regular en un formato interno. Sus argumentos son:


patron Una cadena que contiene la expresión a compilar
longitud La longitud de la cadena o PCRE2_ZERO_TERMINATED
opciones Bits de opción primarios
cod_error Dónde poner un código de error
desplazamiento_error Dónde poner un desplazamiento de error
contexto_compilacion Puntero a un contexto de compilación o NULL

La longitud del patrón y cualquier desplazamiento de error que se devuelva están en unidades de código, no en caracteres. Un patrón NULL con longitud cero se trata como una cadena vacía. Se necesita un contexto de compilación solo si desea proporcionar funciones de asignación de memoria personalizadas, o para proporcionar una función externa para la verificación del tamaño de la pila del sistema (consulte pcre2_set_compile_recursion_guard()), o para cambiar uno o más de estos parámetros:


Qué coincide \R (nuevas líneas Unicode, o solo CR, LF, CRLF);
Tablas de caracteres de PCRE2;
La secuencia de caracteres de nueva línea;
El límite de paréntesis anidados en tiempo de compilación;
La longitud máxima del patrón (en unidades de código) que está permitida;
Los bits de opciones adicionales.

Los bits de opción primarios son:


PCRE2_ANCHORED Forzar anclaje del patrón
PCRE2_ALLOW_EMPTY_CLASS Permitir clases vacías
PCRE2_ALT_BSUX Manejo alternativo de \u, \U y \x
PCRE2_ALT_CIRCUMFLEX Manejo alternativo de ^ en modo multilínea
PCRE2_ALT_EXTENDED_CLASS Sintaxis alternativa de clase de caracteres extendida
PCRE2_ALT_VERBNAMES Procesar barras invertidas en nombres de verbos
PCRE2_AUTO_CALLOUT Compilar callouts automáticos
PCRE2_CASELESS Realizar coincidencias sin distinción entre mayúsculas y minúsculas
PCRE2_DOLLAR_ENDONLY $ no coincidirá con nueva línea al final
PCRE2_DOTALL . coincide con cualquier cosa, incluida NL
PCRE2_DUPNAMES Permitir nombres duplicados para subpatrones
PCRE2_ENDANCHORED El patrón solo puede coincidir al final del sujeto
PCRE2_EXTENDED Ignorar espacios en blanco y comentarios #
PCRE2_FIRSTLINE Forzar la coincidencia a ser anterior a la nueva línea
PCRE2_LITERAL Los caracteres del patrón son todos literales
PCRE2_MATCH_INVALID_UTF Habilitar soporte para coincidencias de UTF no válidas
PCRE2_MATCH_UNSET_BACKREF Coincidir con retroreferencias no establecidas
PCRE2_MULTILINE ^ y $ coinciden con nuevas líneas dentro de los datos
PCRE2_NEVER_BACKSLASH_C Bloquear el uso de \C en patrones
PCRE2_NEVER_UCP Bloquear PCRE2_UCP, por ejemplo, a través de (*UCP)
PCRE2_NEVER_UTF Bloquear PCRE2_UTF, por ejemplo, a través de (*UTF)
PCRE2_NO_AUTO_CAPTURE Deshabilitar paréntesis de captura numerados
(los nombrados están disponibles)
PCRE2_NO_AUTO_POSSESS Deshabilitar la posesión automática
PCRE2_NO_DOTSTAR_ANCHOR Deshabilitar el anclaje automático para .*
PCRE2_NO_START_OPTIMIZE Deshabilitar optimizaciones de inicio en tiempo de coincidencia
PCRE2_NO_UTF_CHECK No verificar la validez UTF del patrón
(solo relevante si PCRE2_UTF está configurado)
PCRE2_UCP Usar propiedades Unicode para \d, \w, etc.
PCRE2_UNGREEDY Invertir la "codicia" de los cuantificadores
PCRE2_USE_OFFSET_LIMIT Habilitar límite de desplazamiento para coincidencias sin anclar
PCRE2_UTF Tratar el patrón y los sujetos como cadenas UTF

PCRE2 debe compilarse con soporte Unicode (por defecto) para poder utilizar PCRE2_UTF, PCRE2_UCP y opciones relacionadas.

Se pueden configurar opciones adicionales en el contexto de compilación a través de la función pcre2_set_compile_extra_options.

Si alguno de los argumentos cod_error o desplazamiento_error es NULL, la función devuelve NULL inmediatamente. De lo contrario, el resultado de esta función es un puntero a una estructura de datos privada que contiene el patrón compilado, o NULL si se detectó un error. En caso de error, se puede obtener un mensaje de error de texto pasando el valor devuelto a través del argumento cod_error a la función pcre2_get_error_message(). El desplazamiento (en unidades de código) donde se encontró el error se devuelve a través del argumento desplazamiento_error.

Si no hay error, el valor pasado a través de cod_error devuelve el mensaje "sin error" si se pasa a pcre2_get_error_message(), y el valor pasado a través de desplazamiento_error es cero.

Hay una descripción completa de la API nativa de PCRE2, con más detalle sobre cada opción, en la página pcre2api, y una descripción de la API POSIX en la página pcre2posix.
