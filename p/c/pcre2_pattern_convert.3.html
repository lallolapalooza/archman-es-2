pcre2_pattern_convert(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_CONVERT(3) Manual de funciones de biblioteca PCRE2_PATTERN_CONVERT(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_pattern_convert(PCRE2_SPTR pattern, PCRE2_SIZE length,
  uint32_t options, PCRE2_UCHAR **buffer,
  PCRE2_SIZE *blength, pcre2_convert_context *cvcontext);

DESCRIPCIÓN

Esta función forma parte de un conjunto experimental de funciones de conversión de patrones. Convierte un patrón externo (por ejemplo, un glob) en un patrón de expresión regular PCRE2. Sus argumentos son:


pattern El patrón externo
length La longitud del patrón de entrada o PCRE2_ZERO_TERMINATED
options Bits de opción
buffer Puntero a puntero a buffer de salida, o NULL
blength Puntero al campo de longitud de salida
cvcontext Puntero a un contexto de conversión o NULL

La longitud del patrón convertido (excluyendo el terminador cero) se devuelve a través de blength. Si buffer es NULL, la función simplemente devuelve la longitud de salida. Si buffer apunta a un puntero NULL, se obtiene memoria del heap para el patrón convertido, usando el asignador en el contexto si está presente (o malloc() en su defecto), y el campo apuntado por buffer se actualiza. Si buffer apunta a un campo no NULL, este debe apuntar a un buffer cuyo tamaño está en la variable apuntada por blength. Este valor se actualiza.

Los bits de opción son:


PCRE2_CONVERT_UTF La entrada es UTF
PCRE2_CONVERT_NO_UTF_CHECK No comprobar la validez de UTF
PCRE2_CONVERT_POSIX_BASIC Convertir patrón POSIX básico
PCRE2_CONVERT_POSIX_EXTENDED Convertir patrón POSIX extendido
PCRE2_CONVERT_GLOB ) Convertir
PCRE2_CONVERT_GLOB_NO_WILD_SEPARATOR ) varios tipos
PCRE2_CONVERT_GLOB_NO_STARSTAR ) de glob

El valor de retorno de pcre2_pattern_convert() es cero en caso de éxito o un código de error PCRE2 distinto de cero.

Las funciones de conversión de patrones se describen en la documentación de pcre2convert.
