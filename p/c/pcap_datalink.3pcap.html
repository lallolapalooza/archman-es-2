NOMBRE

pcap_datalink - obtener el tipo de encabezado de capa de enlace

SINOPSIS

#include <pcap/pcap.h>
int pcap_datalink(pcap_t *p);

DESCRIPCIÓN

pcap_datalink() devuelve el tipo de encabezado de capa de enlace para la captura en vivo o el archivo de guardado especificado por p.

No se debe llamar en un descriptor pcap creado por pcap_create(3PCAP) que aún no haya sido activado por pcap_activate(3PCAP).

https://www.tcpdump.org/linktypes.html enumera los valores que pcap_datalink() puede devolver y describe los formatos de paquete que corresponden a esos valores.

NO asuma que los paquetes para una captura dada o archivo de guardado tendrán un tipo de encabezado de capa de enlace dado, como DLT_EN10MB para Ethernet. Por ejemplo, el dispositivo "any" en Linux tendrá un tipo de encabezado de capa de enlace DLT_LINUX_SLL o DLT_LINUX_SLL2 incluso si todos los dispositivos del sistema en el momento en que se abre el dispositivo "any" tienen otro tipo de enlace de datos, como DLT_EN10MB para Ethernet.

VALOR DEVUELTO

pcap_datalink() devuelve el tipo de encabezado de capa de enlace en caso de éxito y PCAP_ERROR_NOT_ACTIVATED si se llama en un manejador de captura que ha sido creado pero no activado.

VER TAMBIÉN

pcap(3PCAP), pcap-linktype(7)
