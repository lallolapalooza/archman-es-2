PCSC_SCAN(1) Manual de Comandos Generales PCSC_SCAN(1)

NOMBRE

pcsc_scan - escanea regularmente todos los lectores PC/SC conectados al host

SINOPSIS

pcsc_scan [opciones]

DESCRIPCIÓN

Esta página del manual documenta el comando pcsc_scan.

pcsc_scan es un programa que escanea regularmente todos los lectores PC/SC conectados al host y muestra el estado de las tarjetas insertadas en los lectores.

La forma normal de salir del programa es usar Control-C.

Cuando se inicia pcsc_scan, solicita a la Capa PC/SC la lista de lectores de tarjetas inteligentes disponibles. La lista se imprime. Se imprime un número de secuencia antes de cada lector.

Ejemplo:
Escáner de dispositivos PC/SC
V 1.6.2 (c) 2001-2022, Ludovic Rousseau <ludovic.rousseau@free.fr>
Escaneando lectores presentes...
0: Lector Gemalto PC Twin

Cuando se inserta una tarjeta en cualquier lector, se imprime información:

fecha y hora:
Lun Oct 2 21:01:40 2023
nombre del lector:
Lector 0: Lector Gemalto PC Twin
estado de la tarjeta y evento ocurrido:
Estado de la tarjeta: Tarjeta insertada,
ATR en caso de inserción de tarjeta:
ATR: 3B 82 00 86 1E
imprimir un análisis ATR si el comando ATR_analysis está disponible:

ATR: 3B 82 00 86 1E
+ TS = 3B --> Convención Directa
+ T0 = 82, Y(1): 1000, K: 2 (bytes históricos)
TD(1) = 00 --> Y(i+1) = 0000, Protocolo T = 0
-----
+ Bytes históricos: 86 1E

OPCIONES

-h
imprimir ayuda
-V
imprimir número de versión
-n
no imprimir análisis ATR. Úselo si ATR_analysis no está disponible, por ejemplo.
-r
imprime la lista de lectores y sale.
-c
imprime la lista de tarjetas y sale.
-s
modo estrés. Envía comandos APDU a la tarjeta indefinidamente (hasta que la tarjeta o el lector sea retirado).
-t secs
especifica el tiempo que el programa debe ejecutarse, en segundos. El programa terminará cuando haya transcurrido este tiempo.
-q
silencioso: imprime mensajes mínimos.
-v
verboso: imprime mensajes adicionales (por defecto).
-d
depuración: imprime lo que cambió entre los campos .dwCurrentState y .dwEventState para cada lector.
-p
Plug and Play: fuerza el uso del lector específico "\\?PnP?\\Notification".

VER TAMBIÉN

pcscd(8), ATR_analysis(1)
