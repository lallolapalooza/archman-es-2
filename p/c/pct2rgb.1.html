NOMBRE

pct2rgb - Convierte una imagen paletizada de 8 bits a RGB de 24 bits.

SINOPSIS

pct2rgb [--ayuda] [--ayuda-general]
           [-of formato] [-b banda] [-rgba] [-pct archivo_paleta] <archivo_fuente> <archivo_destino>

DESCRIPCIÓN

Esta utilidad convertirá una banda de pseudocolor en el archivo de entrada en un archivo RGB de salida del formato deseado.

NOTA:

pct2rgb es una utilidad de Python y solo está disponible si los enlaces de Python de GDAL están disponibles.
--ayuda
Muestra este mensaje de ayuda y sale.
--ayuda-general
Ofrece un breve mensaje de uso para las opciones generales de la línea de comandos de GDAL y sale.
-of <formato>
Selecciona el formato de salida. Si no se especifica, el formato se adivina por la extensión. Usa el nombre corto del formato.
-b <banda>
Banda a convertir a RGB, por defecto es 1.
-rgba
Genera un archivo RGBA (en lugar de un archivo RGB por defecto).
-pct <archivo_paleta>
Extrae la tabla de colores de <archivo_paleta> en lugar de obtenerla de <archivo_fuente>. Se puede usar para tener una tabla de colores consistente para múltiples archivos. El <archivo_paleta> debe ser un archivo ráster en un formato compatible con GDAL con una paleta o un archivo de color en un formato compatible (txt, qml, qlr).
<archivo_fuente>
El archivo de entrada.
<archivo_destino>
El archivo RGB de salida que se creará.

La opción '-expand rgb|rgba' de gdal_translate deja obsoleta esta utilidad.
