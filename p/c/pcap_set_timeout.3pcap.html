NOMBRE

pcap_set_timeout - establece el tiempo de espera del búfer de paquetes para un manejador de captura no activado

SINOPSIS

#include <pcap/pcap.h>
int pcap_set_timeout(pcap_t *p, int to_ms);

DESCRIPCIÓN

pcap_set_timeout() establece el tiempo de espera del búfer de paquetes que se utilizará en un manejador de captura cuando el manejador se active a to_ms, que está en unidades de milisegundos. (Consulte pcap(3PCAP) para obtener una explicación del tiempo de espera del búfer de paquetes).

El comportamiento, si no se especifica el tiempo de espera, no está definido, al igual que el comportamiento si el tiempo de espera se establece en cero o en un valor negativo. Recomendamos establecer siempre el tiempo de espera a un valor distinto de cero a menos que se establezca el modo inmediato, en cuyo caso el tiempo de espera no tiene ningún efecto.

VALOR DE RETORNO

pcap_set_timeout() devuelve 0 si tiene éxito o PCAP_ERROR_ACTIVATED si se llama en un manejador de captura que ha sido activado.

VER TAMBIÉN

pcap_create(3PCAP), pcap_activate(3PCAP), pcap_set_immediate_mode(3PCAP)
