PCP-ROCESTAT(1) Manual de comandos generales PCP-ROCESTAT(1)

NOMBRE

pcp-rocestat - Informa estadísticas para dispositivos RoCE de nVidia.

SINOPSIS

pcp [opciones-pcp] rocestat [--hw_stats|--lane_stats]

DESCRIPCIÓN

La herramienta pcp-rocestat utiliza los contadores de ethtool para cada dispositivo e informa el rendimiento por cola de prioridad. Por defecto, pcp-rocestat informa datos en vivo para el host local. Tiene la capacidad de analizar también datos de archivos PDP.

OPCIONES

--hw_stats
Muestra los contadores de hardware.
--lane_stats
Muestra las estadísticas de carriles.
-a archivo, --archivo=archivo
Especifica el archivo PCP a examinar.
-s muestras, --muestras=muestras
Especifica el número de muestras a informar.
-S horainicio, --inicio=horainicio
Informa las muestras del archivo desde la hora dada.
-T horafin, --fin=horafin
Informa muestras del archivo hasta la hora dada.
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN

PCPIntro(1), pcp(1), pmParseInterval(3) y environ(7).
