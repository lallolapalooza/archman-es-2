NOMBRE

pcp-geolocate - descubre etiquetas geográficas del sistema recolector

SINOPSIS

pcp geolocate

DESCRIPCIÓN

pcp-geolocate informa la latitud y longitud del host recolector local de Performance Co-Pilot en formato JSON. Esta información de geolocalización se obtiene del archivo caché $PCP_SYSCONF_DIR/labels/optional/geolocate si existe, de lo contrario, se intenta realizar la geolocalización basándose en la dirección IP del host, a través de varias fuentes en línea (APIs REST).

La salida de este comando es adecuada para almacenarla como etiquetas de métricas guardándola en el archivo caché mencionado anteriormente.

La unidad de servicio systemd(1) opcional para este comando proporciona un descubrimiento de ubicación automatizado para las etiquetas de métricas de PCP.

ETIQUETAS DE MÉTRICAS

La salida JSON es el formato preferido para almacenar la ubicación geográfica como etiquetas de métricas de PCP. Cada métrica de PCP disponible desde este host será etiquetada con las etiquetas de latitud y longitud, lo que permitirá a las herramientas que la utilizan, como el panel geomap de Grafana.

Para obtener más información sobre las etiquetas de métricas, consulte las entradas del manual de pmcd(1), pminfo(1), pmlogger(1) y pmLookupLabels(3).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).
