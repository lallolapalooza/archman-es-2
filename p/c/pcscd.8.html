PCSCD(8) PC/SC Lite PCSCD(8)

NOMBRE

pcscd - Demonio PC/SC para tarjetas inteligentes

SINOPSIS

pcscd [-acfTdeCvHSI] [--apdu] [--config dir] [--foreground] [--color] [--debug] [--info] [--error] [--critical] [--force-reader-polling] [-t número] [--max-thread número] [-s número] [--max-card-handle-per-thread número] [-r número] [--max-card-handle-per-reader número] [--version] [--hotplug] [--reader-name-no-serial] [--reader-name-no-interface] [--disable-polkit]
pcscd -h
pcscd --help

OPCIONES

-a, --apdu
registra APDU y SW usando el método de depuración (ver --debug).
-c, --config dir
Especifica el directorio dir como una ubicación alternativa para /etc/reader.conf.d/. El argumento también puede ser un único archivo de configuración (para compatibilidad con versiones anteriores).
-f, --foreground
Ejecuta pcscd en primer plano y envía los mensajes de registro a stderr en lugar de a syslog(3).
-T, --color
fuerza el uso de registros coloreados.
-d, --debug
usa el nivel de registro más bajo. Cualquier mensaje de registro de este nivel o superior se enviará a stderr o syslog(3) dependiendo del uso de --foreground.
--info
usa el nivel de registro info. Este es el nivel de registro predeterminado.
-e, --error
usa el nivel de registro error.
-C, --critical
usa el nivel de registro critical.

Los niveles de registro están ordenados como: debug < info < error < critical. Usar un nivel de registro l registrará este nivel y todos los niveles superiores.

--force-reader-polling
ignora la capacidad del lector IFD_GENERATE_HOTPLUG
-t, --max-thread número
número máximo de hilos (por defecto 200).

Este es el número máximo de clientes (SCardEstablishContext) que pcscd puede manejar.

-s, --max-card-handle-per-thread número
número máximo de manejadores de tarjetas por hilo (por defecto: 200).

Este es el número máximo de manejadores de tarjetas (SCardConnect) por cliente (SCardEstablishContext).

-r, --max-card-handle-per-reader número
número máximo de manejadores de tarjetas por lector (por defecto: 200)

Este es el número máximo de manejadores de tarjetas (SCardConnect) por lector.

-h, --help
Muestra información sobre la línea de comandos de pcscd
-v, --version
Muestra el número de versión del programa
-H, --hotplug
Pide a pcscd que relea los archivos /etc/reader.conf.d/my_reader.conf para detectar lectores no USB añadidos o eliminados (serie o PCMCIA).
-x, --auto-exit
pcscd se cerrará después de 60 segundos de inactividad tras la liberación del último contexto PC/SC. Esto se usa cuando pcscd se inicia bajo demanda por systemd.
-S, --reader-name-no-serial
No incluir el número de serie USB en el nombre del lector.
-I, --reader-name-no-interface
No incluir el nombre de la interfaz USB en el nombre del lector.
--disable-polkit
Ignora las reglas de polkit. Se permiten todos los accesos.

DESCRIPCIÓN

pcscd es el programa demonio para pcsc-lite. Es un gestor de recursos que coordina las comunicaciones con los lectores de tarjetas inteligentes y las tarjetas inteligentes y tokens criptográficos que están conectados al sistema.

Permite a las aplicaciones acceder a tarjetas inteligentes y lectores utilizando la API WinSCard pero sin conocer los detalles de la tarjeta o el lector.

pcscd coordina la carga de controladores para los lectores de tarjetas.

CONTROLADORES DE LECTORES DE TARJETAS INTELIGENTES SERIE

Los controladores de lectores de tarjetas inteligentes se colocan en el directorio /usr/lib/pcsc/drivers. Cada controlador es simplemente un archivo .so. pcscd localiza el controlador usando los archivos /etc/reader.conf.d/my_reader.conf. Consulte la página del manual reader.conf(5) para obtener más información.

Algunos controladores están disponibles en https://muscle.apdu.fr/musclecard.com/drivers.html.

CONTROLADORES DE LECTORES DE TARJETAS INTELIGENTES USB

Los controladores de lectores de tarjetas inteligentes USB se encuentran en el directorio /usr/lib/pcsc/drivers como un paquete. NO debe añadir un controlador USB en un archivo /etc/reader.conf.d/my_reader.conf.

ARCHIVO DE CONFIGURACIÓN

Es posible establecer argumentos que serán utilizados por pcscd con el archivo de configuración /etc/default/pcscd. Por ejemplo, puede aumentar el nivel de depuración usando:

PCSCD_ARGS=--debug

O establecer variables de entorno como:

PCSCLITE_FILTER_IGNORE_READER_NAMES="Twin"
PCSCLITE_FILTER_EXTEND_READER_NAMES=" $HOSTNAME"

Consulte https://blog.apdu.fr/posts/2021/08/pcsc-lite-configuration-using/ para obtener más detalles.

FILTRADO DE LECTORES USB UDEV (SOLO LINUX)

Si el soporte de udev está habilitado, establecer la propiedad de udev PCSCLITE_IGNORE=1 en un dispositivo USB hará que ese lector sea ignorado. Por ejemplo, para ignorar cualquier lector conectado al puerto USB 3 del bus 1, añada lo siguiente a un archivo foobar.rules en el directorio /etc/udev/rules.d/:

ACTION!="remove|unbind", SUBSYSTEM=="usb", KERNEL=="1-3", ENV{PCSCLITE_IGNORE}="1"

ARCHIVOS

/etc/default/pcscd : archivo de configuración del demonio

/etc/reader.conf.d/* : archivos de configuración de lectores serie

/run/pcscd/pcscd.pid : id del proceso del pcscd en ejecución

/usr/lib/pcsc/drivers/ : directorio que contiene paquetes para controladores USB

VER TAMBIÉN

reader.conf(5), syslog(3), udev(7)
