NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

PROGRAMA DE EJEMPLO PCRE2

Un programa de demostración simple y completo para empezar a usar PCRE2 se proporciona en el archivo pcre2demo.c en el directorio src de la distribución de PCRE2. Una lista de este programa se incluye en la documentación de pcre2demo. Si no tiene una copia de la distribución de PCRE2, puede guardar esta lista para recrear el contenido de pcre2demo.c.

El programa de demostración compila la expresión regular que es su primer argumento y la compara con la cadena sujeto en su segundo argumento. No se establecen opciones de PCRE2 y se utilizan tablas de caracteres predeterminadas. Si la coincidencia tiene éxito, el programa muestra la parte del sujeto que coincidió, junto con el contenido de cualquier subcadena capturada.

Si se proporciona la opción -g en la línea de comandos, el programa procede a comprobar si hay más coincidencias de la misma expresión regular en la misma cadena sujeto. La lógica es un poco complicada debido a la posibilidad de que coincida una cadena vacía. Los comentarios en el código explican lo que está sucediendo.

El código en pcre2demo.c es un programa de 8 bits que utiliza la biblioteca PCRE2 de 8 bits. Maneja cadenas y caracteres que se almacenan en unidades de código de 8 bits. Por defecto, un carácter corresponde a una unidad de código, pero si el patrón comienza con "(*UTF)", tanto él como el sujeto se tratan como cadenas UTF-8, donde los caracteres pueden ocupar varias unidades de código.

Si PCRE2 está instalado en los directorios de inclusión y biblioteca estándar para su sistema operativo, debería poder compilar el programa de demostración utilizando un comando como este:


cc -o pcre2demo pcre2demo.c -lpcre2-8

Si PCRE2 está instalado en otro lugar, es posible que necesite agregar opciones adicionales a la línea de comandos. Por ejemplo, en un sistema similar a Unix que tiene PCRE2 instalado en /usr/local, puede compilar el programa de demostración utilizando un comando como este:


cc -o pcre2demo -I/usr/local/include pcre2demo.c \
-L/usr/local/lib -lpcre2-8

Una vez que haya compilado el programa de demostración, puede realizar pruebas simples como estas:


./pcre2demo 'cat|dog' 'el gato se sentó en la alfombra'
./pcre2demo -g 'cat|dog' 'el perro se sentó en el gato'
./pcre2demo -i 'cat' 'el perro se sentó en el GATO'

Tenga en cuenta que existe un programa de prueba mucho más completo, llamado pcre2test, que admite muchas más instalaciones para probar expresiones regulares utilizando las tres bibliotecas de PCRE2 (8 bits, 16 bits y 32 bits, aunque no es necesario instalar las tres). El programa pcre2demo se proporciona como un ejemplo de codificación relativamente simple.

Si intenta ejecutar pcre2demo cuando PCRE2 no está instalado en el directorio de bibliotecas estándar, puede recibir un error como este en algunos sistemas operativos (por ejemplo, Solaris):


ld.so.1: pcre2demo: fatal: libpcre2-8.so.0: open failed: No such file or directory

Esto es causado por la forma en que funciona el soporte de bibliotecas compartidas en esos sistemas. Necesita agregar


-R/usr/local/lib

(por ejemplo) al comando de compilación para resolver este problema.
