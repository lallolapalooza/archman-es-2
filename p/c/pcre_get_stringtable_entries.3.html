pcre_get_stringtable_entries(3)

Paquete: pcre

Licencias: BSD

PCRE_GET_STRINGTABLE_ENTRIES(3) Manual de funciones de biblioteca PCRE_GET_STRINGTABLE_ENTRIES(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_get_stringtable_entries(const pcre *code,
     const char *name, char **first, char **last);

int pcre16_get_stringtable_entries(const pcre16 *code,
     PCRE_SPTR16 name, PCRE_UCHAR16 **first, PCRE_UCHAR16 **last);

int pcre32_get_stringtable_entries(const pcre32 *code,
     PCRE_SPTR32 name, PCRE_UCHAR32 **first, PCRE_UCHAR32 **last);

DESCRIPCIÓN

Esta función de conveniencia busca, para un patrón compilado, las entradas primera y última para un nombre dado en la tabla que traduce los nombres de los paréntesis de captura a números. Cuando se requiere que los nombres sean únicos (PCRE_DUPNAMES no está establecido), generalmente es más fácil usar pcre[16|32]_get_stringnumber() en su lugar.


code Expresión regular compilada
name Nombre cuyas entradas se requieren
first Dónde devolver un puntero a la primera entrada
last Dónde devolver un puntero a la última entrada

El resultado de la función es la longitud de cada entrada, o PCRE_ERROR_NOSUBSTRING si no se encuentra ninguna.

Hay una descripción completa de la API nativa de PCRE, incluido el formato de las entradas de la tabla, en la página pcreapi, y una descripción de la API POSIX en la página pcreposix.
