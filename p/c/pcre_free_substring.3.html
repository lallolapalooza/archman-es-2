pcre_free_substring(3)

Paquete: pcre

Licencias: BSD

PCRE_FREE_SUBSTRING(3) Manual de funciones de biblioteca PCRE_FREE_SUBSTRING(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

void pcre_free_substring(const char *stringptr);

void pcre16_free_substring(PCRE_SPTR16 stringptr);

void pcre32_free_substring(PCRE_SPTR32 stringptr);

DESCRIPCIÓN

Esta es una función de conveniencia para liberar el almacenamiento obtenido por una llamada anterior a pcre[16|32]_get_substring() o pcre[16|32]_get_named_substring(). Su único argumento es un puntero a la cadena.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
