PCRE2-CONFIG(1) Manual General de Comandos PCRE2-CONFIG(1)

NOMBRE

pcre2-config - programa para obtener la configuración de PCRE2

SINOPSIS

pcre2-config [--prefix] [--exec-prefix] [--version]
             [--libs8] [--libs16] [--libs32] [--libs-posix]
             [--cflags] [--cflags-posix]

DESCRIPCIÓN

pcre2-config devuelve la configuración de las bibliotecas PCRE2 instaladas y las opciones necesarias para compilar un programa que las utilice. Algunas de las opciones se aplican solo a las bibliotecas de 8, 16 o 32 bits, respectivamente, y no están disponibles para bibliotecas que no se hayan compilado. Si se encuentra una opción no disponible, se muestra la información de "uso".

OPCIONES

--prefix
Escribe el prefijo del directorio utilizado en la instalación de PCRE2 para archivos independientes de la arquitectura (/usr en muchos sistemas, /usr/local en algunos sistemas) a la salida estándar.
--exec-prefix
Escribe el prefijo del directorio utilizado en la instalación de PCRE2 para archivos dependientes de la arquitectura (normalmente el mismo que --prefix) a la salida estándar.
--version
Escribe el número de versión de las bibliotecas PCRE2 instaladas a la salida estándar.
--libs8
Escribe a la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE2 de 8 bits (-lpcre2-8 en muchos sistemas).
--libs16
Escribe a la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE2 de 16 bits (-lpcre2-16 en muchos sistemas).
--libs32
Escribe a la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca PCRE2 de 32 bits (-lpcre2-32 en muchos sistemas).
--libs-posix
Escribe a la salida estándar las opciones de línea de comandos necesarias para enlazar con la biblioteca de envoltura de la API POSIX de PCRE2 (-lpcre2-posix -lpcre2-8 en muchos sistemas).
--cflags
Escribe a la salida estándar las opciones de línea de comandos necesarias para compilar archivos que utilicen PCRE2 (esto puede incluir algunas opciones -I, pero está en blanco en muchos sistemas).
--cflags-posix
Escribe a la salida estándar las opciones de línea de comandos necesarias para compilar archivos que utilicen la biblioteca de envoltura de la API POSIX de PCRE2 (esto puede incluir algunas opciones -I, pero está en blanco en muchos sistemas).
