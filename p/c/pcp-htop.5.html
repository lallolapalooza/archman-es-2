NOMBRE

pcp-htop - archivo de configuración de pcp-htop

DESCRIPCIÓN

pcp-htop es una herramienta personalizable para la generación de informes de métricas de rendimiento. Tiene una arquitectura dinámica, donde un conjunto de archivos de configuración proporciona medidores y columnas adicionales y opcionales para extender el conjunto fijo de opciones de visualización proporcionadas por el htop normal.

Estos archivos de configuración se pueden proporcionar tanto desde ubicaciones a nivel de sistema (primero /etc/pcp/htop luego /usr/share/pcp/htop) como desde el directorio principal del usuario (generalmente ~/.config/htop). Dentro de estas ubicaciones, se escanean los directorios meters y columns en busca de especificaciones dinámicas de Medidores y Columnas.

Los medidores se muestran en la parte superior de la ventana de pcp-htop, y las columnas se muestran en la parte inferior. Los medidores tienden a mostrar métricas de todo el sistema, y las columnas muestran métricas sobre procesos individuales.

Los formatos son similares pero tienen requisitos ligeramente diferentes. Ambos formatos siguen el estilo ini común. Las líneas en blanco se ignoran. Las líneas que comienzan con el carácter "#" se tratan como comentarios.

MEDIDORES

El siguiente es un ejemplo de configuración para un nuevo medidor de Redis:

[redisclient]
caption = Clientes de Redis
type = bar
blocked.metric = redis.blocked_clients
blocked.color = blue
blocked.label = blk
clients.metric = redis.connected_clients
clients.color = green
clients.label = conn

Un archivo de configuración puede contener múltiples definiciones de medidor. Cada definición comienza con un nombre identificador entre corchetes, como redisclient en este ejemplo. El nombre se utiliza internamente dentro de pcp-htop y debe ser único, comenzar con un carácter alfabético y, posteriormente, solo puede contener caracteres alfanuméricos o el carácter de guion bajo. No se permiten espacios en blanco ni otros caracteres.

Hay varios parámetros que definen la forma en que se mostrará el medidor al usuario.

caption
Este valor se muestra en la pantalla de Configuración una vez que se ha seleccionado el medidor. Una versión truncada del caption también se mostrará (seguida de dos puntos) en la pantalla principal mientras el medidor se está actualizando.
description
Esto se puede utilizar para proporcionar más detalles durante el proceso de selección del medidor en la pantalla de Configuración, y si está presente, se muestra en la columna "Medidores Disponibles". Si no está presente, se utilizará el caption para esto. Si ninguno está presente, se utilizará el name interno (obligatorio).
type
Esta configuración permite especificar un tipo de medidor predeterminado preferido. El valor asociado debe ser uno de bar, text, graph o led. Si no se proporciona ningún valor para un medidor dinámico, se utilizará el valor predeterminado de text.
maximum
También se puede establecer un valor numérico para dimensionar el medidor, de modo que los valores (por ejemplo, para una visualización de medidor de tipo bar) se escalarán dentro del rango de cero a maximum.

La sintaxis restante de la definición describe las métricas individuales que se utilizarán para animar el medidor. Se deben especificar una o más métricas para cada medidor y hay varias propiedades asociadas con cada una. Una vez más, estas métricas deben tener nombre (se aplican las mismas reglas descritas anteriormente para los medidores aquí) y se pueden configurar las siguientes propiedades:

name.metric
Este es el único campo obligatorio y asocia una métrica PCP con el medidor. Los valores muestreados para cada métrica en tiempo de ejecución proporcionan la animación visible en la pantalla de pcp-htop. La especificación de la métrica puede ser un nombre de métrica PCP como los listados por pminfo(1) o una expresión de métrica "derivada". El formato de las expresiones de métricas derivadas se describe en la página del manual de pmRegisterDerived(3).
name.color
Establece el color a utilizar al renderizar los valores de las métricas. Los valores posibles son red, green, blue, cyan, magenta, yellow, gray, darkgray o white.
name.label
Una etiqueta opcional y corta para mostrar antes del valor de la métrica. El carácter ":" se añadirá a la label antes de la parte del valor de la métrica de la pantalla.
name.suffix
Un sufijo opcional y corto para mostrar después del valor de la métrica. Se usa comúnmente para indicar valores como un porcentaje usando un valor de suffix "%" y para proporcionar la unidad base de medida. Tenga en cuenta que dado que PCP mantiene unidades para las métricas, para aquellas métricas que tienen dimensión en "espacio" (bytes, kilobytes, megabytes, etc.), se añadirá automáticamente un sufijo.

COLUMNAS

El siguiente es un ejemplo de configuración para una nueva columna que muestra los descriptores de archivo abiertos para cada proceso:

[openfds]
heading = FDS
caption = FDCOUNT
description = Descriptores de archivo abiertos
metric = proc.fd.count
width = 3

Un archivo de configuración puede contener múltiples definiciones de columna. Cada definición comienza con un nombre identificador entre corchetes, como openfds en este ejemplo, y se aplican las mismas reglas que se describen anteriormente para los nombres de medidores.

Cada columna debe especificar una métrica. También se pueden establecer parámetros opcionales.

metric
Al igual que con los medidores, el valor de la métrica debe ser un nombre de métrica PCP como los listados por pminfo(1) o una métrica derivada. La métrica debe tener un dominio de instancia (conjunto de valores) y ese dominio de instancia debe mapearse al conjunto de procesos siendo el identificador de instancia los PID (identificadores de proceso). Típicamente, estas serán métricas del espacio de nombres proc o hotproc (pmdaproc(1)), pero las métricas de otros dominios (pmdabpf(1), etc.) que tienen valores por proceso son igualmente aplicables.
width
Ancho de columna a utilizar al mostrar valores para la métrica. Se puede usar un valor negativo para especificar la alineación a la izquierda. Se aplica un límite superior de columna de 28 caracteres. El ancho de columna predeterminado es de 5 caracteres.
heading
El título corto que se mostrará en la cabecera de la columna, generalmente una cadena corta, críptica y en mayúsculas.
caption
Una palabra identificativa corta presentada a los usuarios en la pantalla de Configuración bajo las listas de Columnas Disponibles y Activas.
description
Texto que ayuda a los usuarios a comprender el significado de esta columna cuando se presenta a través de la pantalla de Configuración en la lista de Columnas Disponibles.
