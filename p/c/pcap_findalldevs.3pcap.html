NOMBRE

pcap_findalldevs, pcap_freealldevs - obtener una lista de dispositivos de captura y liberar esa lista

SINOPSIS

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
int pcap_findalldevs(pcap_if_t **alldevsp, char *errbuf);
void pcap_freealldevs(pcap_if_t *alldevs);

DESCRIPCIÓN

pcap_findalldevs() construye una lista de dispositivos de red que se pueden abrir con pcap_create(3PCAP) y pcap_activate(3PCAP) o con pcap_open_live(3PCAP). (Tenga en cuenta que puede haber dispositivos de red que no se puedan abrir por el proceso que llama a pcap_findalldevs(), porque, por ejemplo, ese proceso no tiene suficientes privilegios para abrirlos para captura; si es así, esos dispositivos no aparecerán en la lista.) alldevsp es un puntero a un pcap_if_t *; errbuf es un búfer lo suficientemente grande como para contener al menos PCAP_ERRBUF_SIZE caracteres.

Si pcap_findalldevs() tiene éxito, el puntero apuntado por alldevsp se establece para apuntar al primer elemento de la lista, o a NULL si no se encontraron dispositivos (esto se considera un éxito). Cada elemento de la lista es de tipo pcap_if_t y tiene los siguientes miembros:

next
si no es NULL, un puntero al siguiente elemento de la lista; NULL para el último elemento de la lista
name
un puntero a una cadena que da un nombre al dispositivo para pasarlo a pcap_open_live()
description
si no es NULL, un puntero a una cadena que da una descripción legible por humanos del dispositivo
addresses
un puntero al primer elemento de una lista de direcciones de red para el dispositivo, o NULL si el dispositivo no tiene direcciones
flags
indicadores del dispositivo:
PCAP_IF_LOOPBACK
establecido si el dispositivo es una interfaz de loopback
PCAP_IF_UP
establecido si el dispositivo está activo
PCAP_IF_RUNNING
establecido si el dispositivo está funcionando
PCAP_IF_WIRELESS
establecido si el dispositivo es una interfaz inalámbrica; esto incluye IrDA así como redes basadas en radio como IEEE 802.15.4 e IEEE 802.11, por lo que no se refiere solo a Wi-Fi
PCAP_IF_CONNECTION_STATUS
una máscara de bits para indicar si el adaptador está conectado o no; para interfaces inalámbricas, "conectado" significa "asociado a una red"
Los posibles valores para los bits de estado de conexión son:
PCAP_IF_CONNECTION_STATUS_UNKNOWN
se desconoce si el adaptador está conectado o no
PCAP_IF_CONNECTION_STATUS_CONNECTED
el adaptador está conectado
PCAP_IF_CONNECTION_STATUS_DISCONNECTED
el adaptador está desconectado
PCAP_IF_CONNECTION_STATUS_NOT_APPLICABLE
la noción de "conectado" y "desconectado" no se aplica a esta interfaz; por ejemplo, no se aplica a un dispositivo de loopback

Cada elemento de la lista de direcciones es de tipo pcap_addr_t y tiene los siguientes miembros:

next
si no es NULL, un puntero al siguiente elemento de la lista; NULL para el último elemento de la lista
addr
un puntero a una struct sockaddr que contiene una dirección
netmask
si no es NULL, un puntero a una struct sockaddr que contiene la máscara de red correspondiente a la dirección apuntada por addr
broadaddr
si no es NULL, un puntero a una struct sockaddr que contiene la dirección de broadcast correspondiente a la dirección apuntada por addr; puede ser NULL si el dispositivo no soporta broadcasts
dstaddr
si no es NULL, un puntero a una struct sockaddr que contiene la dirección de destino correspondiente a la dirección apuntada por addr; puede ser NULL si la interfaz no es de punto a punto

Tenga en cuenta que las direcciones de la lista de direcciones pueden ser direcciones IPv4, direcciones IPv6 o algún otro tipo de direcciones, por lo que debe comprobar el miembro sa_family de la struct sockaddr antes de interpretar el contenido de la dirección; no suponga que todas las direcciones son direcciones IPv4, o incluso solo direcciones IPv4 o IPv6. Las direcciones IPv4 tienen el valor AF_INET, las direcciones IPv6 tienen el valor AF_INET6 (que los sistemas operativos más antiguos que no soportan IPv6 podrían no definir), y otras direcciones tienen otros valores. Si se devuelven otras direcciones y qué tipos pueden tener depende de la plataforma. En concreto, las direcciones de capa de enlace, como las direcciones MAC Ethernet, tienen el valor AF_PACKET (en Linux) o AF_LINK (en AIX, FreeBSD, Haiku, illumos, macOS, NetBSD y OpenBSD) o no se devuelven en absoluto (en GNU/Hurd y Solaris).

Para direcciones IPv4, el puntero struct sockaddr se puede interpretar como si apuntara a una struct sockaddr_in; para direcciones IPv6, se puede interpretar como si apuntara a una struct sockaddr_in6. Para direcciones de capa de enlace, se puede interpretar como si apuntara a una struct sockaddr_ll (para AF_PACKET) o a una struct sockaddr_dl (para AF_LINK).

La lista de dispositivos debe liberarse con pcap_freealldevs(3PCAP), que libera la lista apuntada por alldevs.

VALOR DE RETORNO

pcap_findalldevs() devuelve 0 si tiene éxito y PCAP_ERROR si falla; como se indicó, no encontrar ningún dispositivo se considera un éxito, no un fallo, por lo que se devolverá 0 en ese caso. Si se devuelve PCAP_ERROR, errbuf se rellena con un mensaje de error apropiado y el puntero apuntado por alldevsp se establece en NULL.

COMPATIBILIDAD RETROACTIVA

Las constantes PCAP_IF_UP y PCAP_IF_RUNNING estuvieron disponibles a partir de la versión 1.6.1 de libpcap. Las constantes PCAP_IF_WIRELESS, PCAP_IF_CONNECTION_STATUS, PCAP_IF_CONNECTION_STATUS_UNKNOWN, PCAP_IF_CONNECTION_STATUS_CONNECTED, PCAP_IF_CONNECTION_STATUS_DISCONNECTED y PCAP_IF_CONNECTION_STATUS_NOT_APPLICABLE estuvieron disponibles a partir de la versión 1.9.0 de libpcap.

NAME

pcap_findalldevs, pcap_findalldevs_ex - get a list of currently available input devices

SYNOPSIS

#include <pcap.h>

char **pcap_findalldevs(char *errbuf);

int pcap_findalldevs_ex(const char *source, pcap_if_t **alldevs, char *errbuf);

DESCRIPTION

pcap_findalldevs() is a function that returns a list of available network devices on which you can capture packets.

The `errbuf` argument is a buffer that will be filled with an error message if an error occurs. The buffer must be at least PCAP_ERRBUF_SIZE bytes in size.

If successful, pcap_findalldevs() returns a pointer to an array of character pointers. Each character pointer in the array is the name of a network device. The array is terminated by a NULL pointer.

If an error occurs, pcap_findalldevs() returns NULL and fills `errbuf` with an error message.

The memory for the array and the strings is allocated by pcap_findalldevs() and must be freed by the caller using pcap_freealldevs().

pcap_findalldevs_ex() is a more modern version that allows specifying a `source` to search for devices. If `source` is NULL, it behaves like pcap_findalldevs(). The list of devices is returned in `alldevs` as a linked list of pcap_if_t structures. This structure is defined in pcap/pcap.h as:

typedef struct pcap_if {
    struct pcap_if *next;
    char *name;         /* name to pass to pcap_open_live() */
    char *description;  /* textual description of the device, or NULL */
    struct pcap_addr *addresses; /* first address of the device, or NULL */
    u_int flags;        /* PCAP_IF_ interface flags */
} pcap_if_t;

The `alldevs` argument is a pointer to a pointer to a pcap_if_t structure. If successful, it will point to the head of the linked list of devices. The list is terminated by a NULL pointer in the `next` field of the last structure.

If an error occurs, pcap_findalldevs_ex() returns -1 and fills `errbuf` with an error message. If successful, it returns 0.

The memory for the linked list and the strings within it is allocated by pcap_findalldevs_ex() and must be freed by the caller using pcap_freealldevs().

RETURN VALUE

pcap_findalldevs() returns a pointer to an array of strings on success, or NULL on error. The array is terminated by a NULL pointer.

pcap_findalldevs_ex() returns 0 on success, or -1 on error.

BACKWARD COMPATIBILITY

The pcap_findalldevs() function is deprecated and has been replaced by pcap_findalldevs_ex(). The older function is still available for backward compatibility but new code should use the newer function.
