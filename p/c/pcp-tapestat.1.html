PCP-TAPESTAT(1) Manual de comandos generales PCP-TAPESTAT(1)

NOMBRE

pcp-tapestat - informa sobre estadísticas de E/S de cinta

SINOPSIS

pcp [opciones de pcp] tapestat [-u?] [-G método] [-P precisión] [-R patrón] [-x [t][,h][,noidle]]

DESCRIPCIÓN

pcp-tapestat informa sobre estadísticas de E/S para dispositivos de cinta.

OPCIONES

Cuando se invoca a través del comando pcp(1), las opciones de pcp -A/--align, -a/--archive, -h/--host, -O/--origin, -S/--start, -s/--samples, -t/--interval, -T/--finish, -V/--version, -Z/--timezone y -z/--hostzone están indirectamente disponibles; consulte PCPIntro(1) para una descripción completa de estas opciones.

Las opciones adicionales de línea de comandos disponibles para pcp-tapestat son:

-G método, --aggregate=método
Especifica que las estadísticas para nombres de dispositivos que coinciden con la expresión regular especificada con la opción -R regex deben agregarse según el método. Tenga en cuenta que esta es una agregación basada en la coincidencia de nombres de dispositivos (no agregación temporal). Cuando se usa -G, la columna del nombre del dispositivo se informa como método(regex), por ejemplo, si se especifica -G sum -R 'st(0|1)$', la columna del dispositivo será sum(st(0|1)$) y se informarán estadísticas sumadas para st0 y st1 en las columnas restantes. Si se especifica -G pero no se especifica -R, entonces la regex predeterminada es .*, es decir, coincide con todos los nombres de dispositivos. Si método es sum entonces las estadísticas se suman. Si método es avg entonces las estadísticas se suman y luego se promedian dividiendo por el número de nombres de dispositivos coincidentes. Si método es min o max, se informan las estadísticas mínima o máxima para los dispositivos coincidentes, respectivamente.
-P N, --precision=N
Esto indica la precisión (número de lugares decimales) a informar. La precisión predeterminada N puede establecerse en algo distinto del valor predeterminado (2). Tenga en cuenta que los campos avgrq-sz y avgqu-sz siempre se informan con N+1 decimales de precisión. Estos campos suelen tener valores inferiores a 1.
-R patrón, --regex=patrón
Esto restringe el informe a los nombres de dispositivos que coinciden con una expresión regular patrón. El patrón dado se busca como una expresión regular de estilo perl, y coincidirá con cualquier parte de un nombre de dispositivo. Por ejemplo, '^st[0-9]+' coincidirá con todos los nombres de dispositivos que comienzan con 'st' seguidos de uno o más números. Por ejemplo, '^st(0|1)$' solo coincidirá con 'st0' y 'st1'. Por ejemplo, 'st0$' coincidirá con 'st0' pero no con 'st1'. Consulte también la opción -G para opciones de agregación.
-u, --no-interpolation
Al reproducir un conjunto de archivos, de forma predeterminada, los valores se informan según el intervalo de muestra solicitado (opción -t), no según el intervalo real registrado en los archivos. Sin esta opción, PCP interpola los valores a informar basándose en los registros del conjunto de archivos, lo que es particularmente útil cuando se usa la opción -t para reproducir un conjunto de archivos con un intervalo de muestreo más largo que aquel con el que se grabó originalmente el/los archivo(s). Con la opción -u, se habilita la presentación sin interpolación: cada valor se informa según el intervalo de grabación nativo en el conjunto de archivos. Cuando se especifica la opción -u, la opción -t no tiene sentido y es incompatible porque el intervalo de reproducción es siempre el mismo que el intervalo de grabación en el conjunto de archivos. Además, -u solo tiene sentido al reproducir archivos, consulte la opción -a en PCPIntro(1), y por lo tanto, si se especifica -u, entonces también se debe especificar -a.
-V, --version
Muestra el número de versión y sale.
-x opciones-separadas-por-comas
Especifica una lista separada por comas de una o más opciones de informes extendidos como las siguientes:
t - anteponer a cada línea del informe una marca de tiempo en formato ctime(3),
h - omitir el encabezado, que de lo contrario se informa cada 24 muestras,
noidle - No mostrar estadísticas para dispositivos inactivos.
-?, --help
Muestra el mensaje de uso y sale.

INFORME

Las columnas en el informe de pcp-tapestat tienen la siguiente interpretación:

Marca de tiempo
Cuando se especifica la opción -x t, esta columna es la marca de tiempo en formato ctime(3).
Dispositivo
Especifica el nombre del dispositivo de cinta. Cuando se especifica -G, se reemplaza por el método de agregación y la expresión regular; consulte las opciones -G y -R anteriores.
r/s
El número de lecturas emitidas expresado como el número por segundo promediado durante el intervalo.
w/s
El número de escrituras emitidas expresado como el número por segundo promediado durante el intervalo.
kb_r/s
La cantidad de datos leídos expresada en kilobytes por segundo promediada durante el intervalo.
kb_w/s
La cantidad de datos escritos expresada en kilobytes por segundo promediada durante el intervalo.
r_pct
Porcentaje de espera de lectura: el porcentaje de tiempo durante el intervalo dedicado a esperar a que se completen las solicitudes de lectura. El tiempo se mide desde que se despacha la solicitud a la capa intermedia de SCSI hasta que señala que se ha completado.
w_pct
Porcentaje de espera de escritura: el porcentaje de tiempo durante el intervalo dedicado a esperar a que se completen las solicitudes de escritura. El tiempo se mide desde que se despacha la solicitud a la capa intermedia de SCSI hasta que señala que se ha completado.
o_pct
Porcentaje de espera general: el porcentaje de tiempo durante el intervalo dedicado a esperar a que se complete cualquier solicitud de E/S (lectura, escritura y otras).
Rs/s
El número de E/S, expresado como el número por segundo promediado durante el intervalo, donde se encontró un valor residual distinto de cero.
o_cnt
El número de E/S, expresado como el número por segundo promediado durante el intervalo, que se incluyeron como "otra". Otras E/S incluyen llamadas ioctl realizadas al controlador de cinta y operaciones implícitas realizadas por el controlador de cinta, como rebobinar al cerrar (para dispositivos de cinta que implementan rebobinar al cerrar). No incluye ninguna E/S realizada a través de métodos fuera del controlador de cinta (por ejemplo, a través de ioctls sg).

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede usar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para conocer las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug de pcp habilita la salida de diagnósticos adicionales en stderr para ayudar a diagnosticar problemas, aunque la información es a veces críptica y está destinada principalmente a proporcionar orientación a los desarrolladores en lugar de a los usuarios finales.
