PCAP_SET_SNAPLEN(3PCAP) PCAP_SET_SNAPLEN(3PCAP)

NOMBRE

pcap_set_snaplen - establecer la longitud de instantánea para un controlador de captura no activado

SINOPSIS

#include <pcap/pcap.h>
int pcap_set_snaplen(pcap_t *p, int snaplen);

DESCRIPCIÓN

pcap_set_snaplen() establece la longitud de instantánea que se utilizará en un controlador de captura cuando el controlador se active en snaplen.

VALOR DE RETORNO

pcap_set_snaplen() devuelve 0 si tiene éxito o PCAP_ERROR_ACTIVATED si se llama en un controlador de captura que ha sido activado.

VER TAMBIÉN

pcap(3PCAP), pcap_create(3PCAP), pcap_activate(3PCAP)
