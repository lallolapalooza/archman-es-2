pcre_config(3)

Paquete: pcre

Licencias: BSD

PCRE_CONFIG(3) Manual de funciones de biblioteca PCRE_CONFIG(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_config(int what, void *where);

int pcre16_config(int what, void *where);

int pcre32_config(int what, void *where);

DESCRIPCIÓN

Esta función permite que un programa cliente descubra qué características opcionales están disponibles en la versión de la biblioteca PCRE que está utilizando. Los argumentos son los siguientes:


what Un código que especifica qué información se requiere
where Puntero a dónde colocar los datos

El argumento where debe apuntar a una variable entera, excepto para PCRE_CONFIG_MATCH_LIMIT, PCRE_CONFIG_MATCH_LIMIT_RECURSION, y PCRE_CONFIG_PARENS_LIMIT, cuando debe apuntar a un entero sin signo largo, y para PCRE_CONFIG_JITTARGET, cuando debe apuntar a un puntero a char constante. Los códigos disponibles son:


PCRE_CONFIG_JIT Disponibilidad del compilador just-in-time
(1=sí 0=no)
PCRE_CONFIG_JITTARGET Cadena que contiene información sobre la
arquitectura de destino para el compilador JIT,
o NULL si no hay soporte JIT
PCRE_CONFIG_LINK_SIZE Tamaño de enlace interno: 2, 3 o 4
PCRE_CONFIG_PARENS_LIMIT Límite de anidamiento de paréntesis
PCRE_CONFIG_MATCH_LIMIT Límite de recursos internos
PCRE_CONFIG_MATCH_LIMIT_RECURSION
Límite de profundidad de recursión interna
PCRE_CONFIG_NEWLINE Valor de la secuencia de fin de línea predeterminada:
13 (0x000d) para CR
10 (0x000a) para LF
3338 (0x0d0a) para CRLF
-2 para ANYCRLF
-1 para ANY
PCRE_CONFIG_BSR Indica qué coincide con \R por defecto:
0 todos los finales de línea Unicode
1 solo CR, LF o CRLF
PCRE_CONFIG_POSIX_MALLOC_THRESHOLD
Umbral de ranuras de retorno, por encima del cual
se utiliza malloc() por la API POSIX
PCRE_CONFIG_STACKRECURSE Implementación de recursión (1=pila 0=montón)
PCRE_CONFIG_UTF16 Disponibilidad de soporte UTF-16 (1=sí
0=no); opción para pcre16_config()
PCRE_CONFIG_UTF32 Disponibilidad de soporte UTF-32 (1=sí
0=no); opción para pcre32_config()
PCRE_CONFIG_UTF8 Disponibilidad de soporte UTF-8 (1=sí 0=no);
opción para pcre_config()
PCRE_CONFIG_UNICODE_PROPERTIES
Disponibilidad de soporte de propiedades Unicode
(1=sí 0=no)

La función devuelve 0 en caso de éxito o PCRE_ERROR_BADOPTION en caso contrario. Ese error también se produce si PCRE_CONFIG_UTF16 o PCRE_CONFIG_UTF32 se pasan a pcre_config(), si PCRE_CONFIG_UTF8 o PCRE_CONFIG_UTF32 se pasan a pcre16_config(), o si PCRE_CONFIG_UTF8 o PCRE_CONFIG_UTF16 se pasan a pcre32_config().

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
