NOMBRE

pcp-dmcache, pcp-lvmcache - Informar sobre cachés de dispositivos de almacenamiento lógicos

SINOPSIS

pcp [opciones-pcp] dmcache [-iRV?] [dispositivo ...]

DESCRIPCIÓN

pcp-dmcache informa sobre la actividad de cualquier destino de caché configurado en Device Mapper. La información informada incluye IOPs del dispositivo, utilización del dispositivo de caché y metadatos, así como tasas y ratios de aciertos y fallos tanto para lecturas como para escrituras para cada dispositivo de caché.

pcp-lvmcache (caché del Gestor de Volúmenes Lógicos) es un sinónimo exacto de pcp-dmcache (caché de Device Mapper).

Por defecto, pcp-dmcache informa sobre todos los dispositivos de destino de caché disponibles (una línea cada uno, por muestra), pero esto se puede restringir a dispositivos específicos en la línea de comandos.

OPCIONES

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone y varias otras opciones de pcp están indirectamente disponibles; consulte PCPIntro(1) para una descripción completa de estas opciones.

Las opciones adicionales de línea de comandos disponibles para pcp-dmcache son:

-i, --iops
muestra operaciones totales de lectura y escritura en lugar de la ratio de aciertos de caché por defecto.
-R, --repeat
cambia la frecuencia con la que se muestra el encabezado de la columna. Por defecto, se muestra un encabezado después de cada décima muestra.
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

AMBIENTE PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN
