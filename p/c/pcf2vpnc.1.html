NOMBRE

pcf2vpnc - convierte archivos de configuración VPN de formato pcf a formato vpnc

SINOPSIS

pcf2vpnc <archivo pcf> [archivo vpnc]

DESCRIPCIÓN

Este script acompaña a vpnc. Intenta convertir archivos de configuración *.pcf, que a menudo se distribuyen con clientes VPN propietarios (es decir, Cisco), a archivos de configuración vpnc, normalmente llamados *.conf.

Si no se especifica [archivo vpnc], el resultado se imprimirá en STDOUT. Si se especifica, se escribirá en ese archivo. ¡Asegúrese de que tenga los permisos adecuados, ya que puede contener datos sensibles!
