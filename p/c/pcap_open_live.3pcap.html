NOMBRE

pcap_open_live - abrir un dispositivo para captura

SINOPSIS

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_open_live(const char *device, int snaplen,
    int promisc, int to_ms, char *errbuf);

DESCRIPCIÓN

pcap_open_live() se utiliza para obtener un manejador de captura de paquetes para observar paquetes en la red. device es una cadena que especifica el dispositivo de red a abrir; en todos los sistemas Linux soportados, así como en versiones recientes de macOS y Solaris, un argumento device de "any" o NULL puede usarse para capturar paquetes de todas las interfaces de red. Este último no debe confundirse con todos los dispositivos de captura disponibles según lo visto por pcap_findalldevs(3PCAP), que también puede incluir D-Bus, USB, etc.

snaplen especifica la longitud de la instantánea que se establecerá en el manejador. Si los datos del paquete no deben truncarse al final, un valor de 262144 debería ser suficiente para la mayoría de los dispositivos, pero los dispositivos D-Bus requieren un valor de 128 MB (128 * 1024 * 1024).

promisc especifica si la interfaz debe ponerse en modo promiscuo. Si promisc es distinto de cero, se establecerá el modo promiscuo, de lo contrario, no se establecerá.

to_ms especifica el tiempo de espera del búfer de paquetes, como un valor no negativo, en milisegundos. (Consulte pcap(3PCAP) para una explicación del tiempo de espera del búfer de paquetes).

errbuf es un búfer lo suficientemente grande como para alojar al menos PCAP_ERRBUF_SIZE caracteres.

VALOR DE RETORNO

pcap_open_live() devuelve un pcap_t * en caso de éxito y NULL en caso de fallo. Si se devuelve NULL, errbuf se rellena con un mensaje de error apropiado. errbuf también puede establecerse con texto de advertencia cuando pcap_open_live() tiene éxito; para detectar este caso, la llamada debe almacenar una cadena de longitud cero en errbuf antes de llamar a pcap_open_live() y mostrar la advertencia al usuario si errbuf ya no es una cadena de longitud cero.

VER TAMBIÉN
