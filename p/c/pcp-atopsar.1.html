PCP-ATOPSAR(1) Manual de Comandos Generales PCP-ATOPSAR(1)

NOMBRE

pcp-atopsar - Informe avanzado de actividad del sistema (relacionado con pcp-atop)

SINOPSIS

pcp [opciones pc p] atopsar [opciones atop] [-r archivo|fecha] [-h host] [-R cnt] [-b [AAAAMMDD]hh:mm[ss]] [-e [AAAAMMDD]hh:mm[ss]]
pcp [opciones pc p] atopsar [opciones atop] intervalo [muestras]

DESCRIPCIÓN

El programa pcp-atopsar se puede utilizar para informar sobre estadísticas a nivel de sistema.

En la primera línea de la sinopsis (sin intervalo de muestreo especificado), pcp-atopsar extrae datos de un archivo de registro sin procesar que ha sido grabado previamente por pmlogger(1) (o a través de la opción -w del programa pcp-atop).
Puedes especificar el nombre del archivo de registro con la opción -r del programa pcp-atopsar. Cuando se utiliza un archivo de registro diario de pmlogger, llamado $PCP_LOG_DIR/pmlogger/[host]/AAAAMMDD (donde AAAAMMDD refleja la fecha), la fecha requerida con el formato AAAAMMDD se puede especificar con la opción -r en lugar del nombre del archivo, o se puede usar el nombre simbólico 'y' para el archivo de registro diario de ayer (esto se puede repetir, por lo que 'yyyy' indica el archivo de registro de hace cuatro días). Si la opción -r no se especifica en absoluto, se utiliza el archivo de registro diario de hoy por defecto.
Por defecto, se utilizará el nombre de host de la máquina local al resolver archivos de pmlogger, sin embargo, se puede especificar un host alternativo usando la opción -h.
La hora de inicio y fin del informe se pueden definir utilizando las opciones -b y -e seguidas de un argumento de tiempo con el formato [AAAAMMDD]hh:mm[ss].

En la segunda línea de la sinopsis, pcp-atopsar lee los contadores de actividad reales del kernel con el intervalo especificado (en segundos) y el número de muestras especificado (opcionalmente). Cuando pcp-atopsar se activa de esta manera, envía inmediatamente la salida de cada informe solicitado a la salida estándar. Si solo se solicita un tipo de informe, la cabecera se imprime una vez y después de cada intervalo segundos se muestran los contadores estadísticos para ese período. Si se solicitan varios informes, se imprime una cabecera por muestra seguida de los contadores estadísticos para ese período.

Cuando se invoca a través del comando pcp(1), las opciones -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone y varias otras opciones de pcp se vuelven indirectamente disponibles; consulta PCPIntro(1) para sus descripciones.

Algunas banderas genéricas se pueden especificar para influir en el comportamiento del programa pcp-atopsar:

-S
Por defecto, la marca de tiempo al principio de una línea se suprime si se muestran más líneas para un intervalo. Con esta bandera, se proporciona una marca de tiempo para cada línea de salida (más fácil para el postprocesamiento).
-a
Por defecto, ciertos recursos como discos e interfaces de red solo se muestran cuando estuvieron activos durante el intervalo. Con esta bandera, se muestran todos los recursos de un tipo dado, incluso si estuvieron inactivos durante el intervalo.
-x
Por defecto, pcp-atopsar solo utiliza colores si la salida se dirige a una terminal (ventana). Estos colores pueden indicar que se ha alcanzado un porcentaje de ocupación crítico (rojo) o casi crítico (cian) para un recurso particular. Consulta la página del manual de atop para una descripción detallada de esta función (sección COLORES).
Con la bandera -x, el uso de colores se suprime incondicionalmente.
-C
Por defecto, pcp-atopsar solo utiliza colores si la salida se dirige a una terminal (ventana). Estos colores pueden indicar que se ha alcanzado un porcentaje de ocupación crítico (rojo) o casi crítico (cian) para un recurso particular. Consulta la página del manual de atop para una descripción detallada de esta función (sección COLORES).
Con la bandera -C, los colores siempre se usarán, incluso si la salida no se dirige a una terminal.
-M
Utiliza marcadores al final de una línea para indicar que se ha alcanzado un porcentaje de ocupación crítico ('*') o casi crítico ('+') para recursos particulares. El marcador '*' es similar al color rojo y el marcador '+' al color cian. Consulta la página del manual de atop para una descripción detallada de estos colores (sección COLORES).
-H
Repite la línea de cabecera dentro de un informe por cada N líneas de detalle. El valor de N se determina dinámicamente en caso de salida a un tty/ventana (dependiendo del número de líneas); para la salida a un archivo o tubería, este valor es 23.
-R
Resume cnt muestras en una sola muestra. Cuando el archivo de registro contiene, por ejemplo, muestras de 10 minutos, el uso de la bandera '-R 6' muestra un informe con una muestra por cada hora.

-P
Informe sobre procesos.
-m

-s
Informe sobre actividad de paginación y swapping, y sobrecontratación.
-B

-l

-f
Informe sobre la utilización de múltiples dispositivos.
-d
Informe sobre la utilización de discos.
-n
Informe sobre sistemas de archivos montados en NFS en el cliente NFS.
-j
Informe sobre la actividad del cliente NFS.
-J
Informe sobre la actividad del servidor NFS.
-i
Informe sobre las interfaces de red.
-I
Informe sobre errores para interfaces de red.
-w
Informe sobre el tráfico de red de la versión IP 4.
-W
Informe sobre errores para el tráfico de la versión IP 4.
-y
Informe general sobre la actividad de la capa ICMP versión 4.
-Y
Informe por tipo sobre la actividad de la capa ICMP versión 4.
-u
Informe sobre el tráfico de red UDP versión 4.
-z
Informe sobre el tráfico de red de la versión IP 6.
-Z
Informe sobre errores para el tráfico de la versión IP 6.
-k

-K
Informe por tipo sobre la actividad de la capa ICMP versión 6.
-U
Informe sobre el tráfico de red UDP versión 6.
-t
Informe sobre el tráfico de red TCP.
-T
Informe sobre errores para el tráfico TCP.
-h
Informe sobre la utilización de Infiniband.

La salida para el indicador -s contiene información sobre la frecuencia del intercambio (swapping):

pagescan/s
Número de páginas escaneadas por segundo debido a que la memoria libre cae por debajo de un umbral particular.
swapin/s
El número de páginas de memoria que el sistema lee del dispositivo de intercambio por segundo.
swapout/s
El número de páginas de memoria que el sistema escribe al dispositivo de intercambio por segundo.
oomkill
El número de procesos que se eliminan durante el último intervalo debido a la falta de memoria/intercambio. El valor -1 significa que este contador no es compatible con la versión actual del kernel.
commitspc
El espacio de memoria virtual comprometido, es decir, el espacio virtual reservado para todas las asignaciones de espacio de memoria privada para los procesos.
commitlim
El límite máximo para el espacio comprometido, que por defecto es el tamaño del intercambio más el 50% del tamaño de la memoria. El kernel solo verifica si el espacio comprometido excede el límite si se configura el manejo estricto de sobrecompromiso (vm.overcommit_memory es 2).

La salida para el indicador -B contiene la Información de Presión de Parada (PSI):

cpusome
Porcentaje de presión promedio durante el intervalo para la categoría 'CPU some'.
memsome
Porcentaje de presión promedio durante el intervalo para la categoría 'memory some'.
memfull
Porcentaje de presión promedio durante el intervalo para la categoría 'memory full'.
iosome
Porcentaje de presión promedio durante el intervalo para la categoría 'I/O some'.
iofull
Porcentaje de presión promedio durante el intervalo para la categoría 'I/O full'.

La salida para los indicadores -l (LVM), -f (MD) y -d (disco duro) contiene las siguientes columnas por unidad activa:

disk
Nombre.
busy
Porcentaje de ocupación de la unidad (es decir, la porción de tiempo que el dispositivo estuvo ocupado manejando solicitudes).
read/s
Número de solicitudes de lectura emitidas por segundo en esta unidad.
KB/read
Número promedio de Kbytes transferidos por solicitud de lectura para esta unidad.
writ/s
Número de solicitudes de escritura (incluidas las de descarte) emitidas por segundo en esta unidad.
KB/writ
Número promedio de Kbytes transferidos por solicitud de escritura para esta unidad.
avque
Número promedio de solicitudes pendientes en la cola durante el tiempo que la unidad está ocupada.
avserv
Número promedio de milisegundos necesarios por una solicitud en esta unidad (búsqueda, latencia y transferencia de datos).

La salida para el indicador -n contiene información sobre la actividad en sistemas de archivos montados en NFS (cliente):

mounted_device
Dispositivo montado que contiene el nombre del servidor y el directorio del servidor que se está montando.
physread/s
Kilobytes de datos leídos físicamente del servidor NFS por procesos que se ejecutan en el cliente NFS.
KBwrite/s
Kilobytes de datos escritos físicamente al servidor NFS por procesos que se ejecutan en el cliente NFS.
Cuando el sistema de archivos NFS se montó durante el intervalo, se muestra el estado 'M'.

Nombre de la interfaz.

Porcentaje de ocupación de esta interfaz. Si la velocidad de línea de esta interfaz no se pudo determinar (por ejemplo, para interfaces virtuales), se muestra un signo de interrogación.
ipack/s
Número de paquetes recibidos de esta interfaz por segundo.
opack/s
Número de paquetes transmitidos a esta interfaz por segundo.
iKbyte/s
Número de Kbytes recibidos de esta interfaz por segundo.
oKbyte/s
Número de Kbytes transmitidos a través de esta interfaz por segundo.
imbps/s
Número efectivo de megabits recibidos por segundo.
ombps/s
Número efectivo de megabits transmitidos por segundo.
maxmbps/s
Velocidad de línea como número de megabits por segundo. Si la velocidad de línea no se pudo determinar (por ejemplo, interfaces virtuales), se muestra el valor 0.
La velocidad de línea va seguida de la indicación 'f' (full duplex) o 'h' (half duplex).

Número de colisiones encontradas por segundo al transmitir paquetes.
idrop/s

odrop/s
Número de paquetes transmitidos descartados por segundo debido a la falta de espacio en el búfer en el sistema local.
iframe/s
Número de errores de alineación de trama encontrados por segundo en paquetes recibidos.
ocarrier/s
Número de errores de portadora encontrados por segundo en paquetes transmitidos.

EJEMPLOS

Para ver la actividad de CPU de hoy hasta el momento (suponiendo que atop está registrando en segundo plano):

  pcp-atopsar

Para ver la ocupación de memoria del 5 de junio de 2018 entre las 10:00 y las 12:30 (suponiendo que pmlogger ha estado registrando diariamente en segundo plano en el host acme.com):

  pcp-atopsar -m -r $PCP_LOG_DIR/pmlogger/acme.com/20180605 -b 10:00 -e 12:30

 
o
  pcp-atopsar -m -r 20180605 -b 10:00 -e 12:30

 
o, supongamos que es el 8 de junio de 2018 en este momento
  pcp-atopsar -m -r yyy -b 10:00 -e 12:30

Escribir un archivo de registro con atop para registrar el comportamiento del sistema durante 30 minutos (30 muestras de un minuto) y producir todos los informes disponibles después:

  pcp-atop -w /tmp/atoplog 60 30
  pcp-atopsar -A -r /tmp/atoplog

Para observar la actividad TCP evolutiva durante diez minutos (10 muestras con un intervalo de sesenta segundos):

  pcp-atopsar -t 60 10

Para observar las líneas de encabezado ('_' como último carácter) de todos los informes con solo las líneas de detalle que muestran el consumo de recursos críticos (marcador '*' o '+' como último carácter):

  pcp-atopsar -AM | grep '[_*+]$'

ARCHIVOS

/etc/atoprc
Archivo de configuración que contiene valores predeterminados para todo el sistema (principalmente banderas). Consulte la página de manual relacionada.
~/.atoprc
Archivo de configuración que contiene valores predeterminados personales (principalmente banderas). Consulte la página de manual relacionada.
$PCP_LOG_DIR/pmlogger/HOST/YYYYMMDD
Archivo de datos diario, donde YYYYMMDD son dígitos que representan la fecha, y HOST es el nombre del host de la máquina que se está registrando.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF se puede utilizar para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

OPCIONES DE DEPURACIÓN

La opción -D o --debug de pcp habilita la salida de pcp-atopsar(1)

DEBUGGING OPTIONS

The pcp-atopsar(1) utility produces additional diagnostics on stderr to help triage problems, although the information is sometimes cryptic and primarily intended to provide guidance for developers rather end-users. debug is a comma separated list of debugging options; use pmdbg(1) with the -l option to obtain a list of the available debugging options and their meaning.
