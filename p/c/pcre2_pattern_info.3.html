pcre2_pattern_info(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_INFO(3) Manual de funciones de biblioteca PCRE2_PATTERN_INFO(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int pcre2_pattern_info(const pcre2_code *code, uint32_t what,
   void *where);

DESCRIPCIÓN

Esta función recupera información sobre un patrón compilado. Sus argumentos son:


code Puntero a un patrón de expresión regular compilado
what Qué información se requiere
where Dónde colocar la información

Los valores reconocidos para el argumento what, y la información que solicitan son los siguientes:


PCRE2_INFO_ALLOPTIONS Opciones finales después de compilar
PCRE2_INFO_ARGOPTIONS Opciones pasadas a pcre2_compile()
PCRE2_INFO_BACKREFMAX Número máximo de referencia inversa
PCRE2_INFO_BSR Lo que coincide con \R:
PCRE2_BSR_UNICODE: finales de línea Unicode
PCRE2_BSR_ANYCRLF: solo CR, LF o CRLF
PCRE2_INFO_CAPTURECOUNT Número de subpatrones de captura
PCRE2_INFO_DEPTHLIMIT Límite de profundidad de retroceso si está establecido,
de lo contrario PCRE2_ERROR_UNSET
PCRE2_INFO_EXTRAOPTIONS Opciones adicionales que se pasaron en el
contexto de compilación
PCRE2_INFO_FIRSTBITMAP Mapa de bits de las primeras unidades de código, o NULL
PCRE2_INFO_FIRSTCODETYPE Tipo de información de inicio de coincidencia
0 nada establecido
1 primera unidad de código establecida
2 inicio de la cadena o después de una nueva línea
PCRE2_INFO_FIRSTCODEUNIT Primera unidad de código cuando el tipo es 1
PCRE2_INFO_FRAMESIZE Tamaño del marco de retroceso
PCRE2_INFO_HASBACKSLASHC Devuelve 1 si el patrón contiene \C
PCRE2_INFO_HASCRORLF Devuelve 1 si existen coincidencias explícitas de CR o LF
en el patrón
PCRE2_INFO_HEAPLIMIT Límite de memoria del montón si está establecido,
de lo contrario PCRE2_ERROR_UNSET
PCRE2_INFO_JCHANGED Devuelve 1 si se usó (?J) o (?-J)
PCRE2_INFO_JITSIZE Tamaño del código compilado por JIT, o 0
PCRE2_INFO_LASTCODETYPE Tipo de información obligatoria
0 nada establecido
1 unidad de código establecida
PCRE2_INFO_LASTCODEUNIT Última unidad de código cuando el tipo es 1
PCRE2_INFO_MATCHEMPTY 1 si el patrón puede coincidir con una cadena
vacía, 0 en caso contrario
PCRE2_INFO_MATCHLIMIT Límite de coincidencias si está establecido,
de lo contrario PCRE2_ERROR_UNSET
PCRE2_INFO_MAXLOOKBEHIND Longitud (en caracteres) de la aserción de mirada
hacia atrás más larga
PCRE2_INFO_MINLENGTH Límite inferior de longitud de las cadenas coincidentes
PCRE2_INFO_NAMECOUNT Número de subpatrones nombrados
PCRE2_INFO_NAMEENTRYSIZE Tamaño de las entradas de la tabla de nombres
PCRE2_INFO_NAMETABLE Puntero a la tabla de nombres
PCRE2_CONFIG_NEWLINE Código para la secuencia de nueva línea:
PCRE2_NEWLINE_CR
PCRE2_NEWLINE_LF
PCRE2_NEWLINE_CRLF
PCRE2_NEWLINE_ANY
PCRE2_NEWLINE_ANYCRLF
PCRE2_NEWLINE_NUL
PCRE2_INFO_RECURSIONLIMIT Sinónimo obsoleto de PCRE2_INFO_DEPTHLIMIT
PCRE2_INFO_SIZE Tamaño del patrón compilado

Si where es NULL, la función devuelve la cantidad de memoria necesaria para la información solicitada, en bytes. De lo contrario, el argumento where debe apuntar a un entero sin signo de 32 bits (variable uint32_t), excepto para los siguientes valores de what, cuando debe apuntar a una variable del tipo que se muestra:


PCRE2_INFO_FIRSTBITMAP const uint8_t *
PCRE2_INFO_JITSIZE size_t
PCRE2_INFO_NAMETABLE PCRE2_SPTR
PCRE2_INFO_SIZE size_t

El resultado de la función es cero en caso de éxito o:


PCRE2_ERROR_NULL el argumento code es NULL
PCRE2_ERROR_BADMAGIC el "número mágico" no se encontró
PCRE2_ERROR_BADOPTION el valor de what es inválido
PCRE2_ERROR_BADMODE el patrón se compiló en el modo incorrecto
PCRE2_ERROR_UNSET la información solicitada no está establecida

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de la API POSIX en la página pcre2posix.
