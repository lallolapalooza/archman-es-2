pcap_create.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_CREATE(3PCAP) PCAP_CREATE(3PCAP)

NOMBRE

pcap_create - crear un manejador de captura en vivo

SINOPSIS

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_create(const char *source, char *errbuf);

DESCRIPCIÓN

pcap_create() se utiliza para crear un manejador de captura de paquetes para examinar paquetes en la red. source es una cadena que especifica el dispositivo de red a abrir; en sistemas Linux con kernels 2.2 o posteriores, se puede usar un argumento source de "any" o NULL para capturar paquetes de todas las interfaces.

El manejador devuelto debe ser activado con pcap_activate(3PCAP) antes de que se puedan capturar paquetes con él; las opciones para la captura, como el modo promiscuo, se pueden establecer en el manejador antes de activarlo.

VALOR DE RETORNO

pcap_create() devuelve un pcap_t * en caso de éxito y NULL en caso de error. Si se devuelve NULL, errbuf se rellena con un mensaje de error apropiado.
