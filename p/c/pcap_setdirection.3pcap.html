NOMBRE

pcap_setdirection - establecer la dirección para la que se capturarán los paquetes

SINOPSIS

#include <pcap/pcap.h>
int pcap_setdirection(pcap_t *p, pcap_direction_t d);

DESCRIPCIÓN

pcap_setdirection() se utiliza para especificar una dirección para la que se capturarán los paquetes. d es una de las constantes PCAP_D_IN, PCAP_D_OUT o PCAP_D_INOUT. PCAP_D_IN solo capturará los paquetes recibidos por el dispositivo, PCAP_D_OUT solo capturará los paquetes enviados por el dispositivo y PCAP_D_INOUT capturará los paquetes recibidos o enviados por el dispositivo. PCAP_D_INOUT es la configuración predeterminada si no se llama a esta función.

pcap_setdirection() no es necesariamente compatible al 100% en todas las plataformas; algunas plataformas pueden devolver un error para todos los valores, y otras pueden no admitir PCAP_D_OUT.

Esta operación no es compatible si se está leyendo un ``savefile'' (archivo guardado).

VALOR DE RETORNO

pcap_setdirection() devuelve 0 si tiene éxito, PCAP_ERROR_NOT_ACTIVATED si se llama en un manejador de captura que ha sido creado pero no activado, o PCAP_ERROR en otros errores. Si se devuelve PCAP_ERROR, se puede llamar a pcap_geterr(3PCAP) o pcap_perror(3PCAP) con p como argumento para obtener o mostrar el texto del error.
