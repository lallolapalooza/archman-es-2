NOMBRE

pcp-zoneinfo - Informar estadísticas de zonas NUMA

SINOPSIS

pcp [opciones-pcp] zoneinfo [-Vz?] [-s muestras] [-a archivo] [-S hora_inicio] [-T hora_fin] [-Z zona_horaria]

DESCRIPCIÓN

El comando pcp-zoneinfo se utiliza para ver los diferentes tipos de estadísticas relacionadas con los nodos NUMA. Usando varias opciones, ayuda al usuario a analizar información útil relacionada con la disponibilidad de zonas para diferentes nodos NUMA. Esto es útil para analizar el comportamiento de la memoria virtual. Por defecto, pcp-zoneinfo informa datos en vivo para el host local.

Las estadísticas que se muestran son las siguientes:

OPCIONES

-a archivo, --archive=archivo
Obtener /proc/zoneinfo para un archivo de archivo especificado
-s cuenta, --samples=cuenta
Obtener las estadísticas de zoneinfo para el número de muestras cuenta especificado
-S, --start=tiempo
Filtrar las muestras del archivo desde la hora dada
-T, --finish=tiempo
Filtrar las muestras del archivo hasta la hora dada
-V, --version
Mostrar el número de versión y salir.
-z, --hostzone
Usar la zona horaria local del host que es la fuente de las métricas de rendimiento, tal como se identifica mediante las opciones -h o -a. Por defecto se utiliza la zona horaria del host local.
-Z zona_horaria, --timezone=zona_horaria
Usar zona_horaria para la fecha y hora. Zona_horaria tiene el formato de la variable de entorno TZ como se describe en environ(7).
-?, --help
Mostrar mensaje de uso y salir.

NOTAS

pcp-zoneinfo recopila información de /proc/zoneinfo.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN

PCPIntro(1), pcp(1), pmParseInterval(3) y environ(7).

pcp-zoneinfo(1)

NOMBRE

pcp-zoneinfo - muestra información de la zona horaria de Performance Co-Pilot

SINOPSIS

pcp-zoneinfo [-h]

DESCRIPCIÓN

pcp-zoneinfo es un script de utilidad que se utiliza para recuperar y mostrar información sobre las zonas horarias disponibles en el sistema. Esta información se presenta en un formato que puede ser utilizado por otras herramientas de Performance Co-Pilot (PCP).

OPCIONES

-h
Muestra un mensaje de ayuda y sale.

NOTAS

Este comando se basa en la información de la zona horaria proporcionada por el sistema operativo subyacente. La disponibilidad y precisión de la información de la zona horaria dependen de la configuración del sistema.

ENTORNO PCP

Las variables de entorno siguientes pueden afectar el comportamiento de los comandos de PCP:

PCP_CONFIG_PATH
Especifica una lista de directorios donde buscar archivos de configuración de PCP.
PCP_LOG_DIR
Especifica el directorio donde se almacenan los archivos de registro de PCP.

VER TAMBIÉN

pcp.conf(5), pcpd(1), pmtime(1)
