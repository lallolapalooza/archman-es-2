pcre_jit_stack_alloc(3)

Paquete: pcre

Licencias: BSD

PCRE_JIT_STACK_ALLOC(3) Manual de funciones de biblioteca PCRE_JIT_STACK_ALLOC(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

pcre_jit_stack *pcre_jit_stack_alloc(int startsize,
     int maxsize);

pcre16_jit_stack *pcre16_jit_stack_alloc(int startsize,
     int maxsize);

pcre32_jit_stack *pcre32_jit_stack_alloc(int startsize,
     int maxsize);

DESCRIPCIÓN

Esta función se utiliza para crear una pila para usarla con el código compilado por la optimización JIT de pcre[16|32]_study(). Los argumentos son un tamaño inicial para la pila y un tamaño máximo al que se permite crecer. El resultado se puede pasar al código de tiempo de ejecución JIT mediante pcre[16|32]_assign_jit_stack(), o esa función puede configurar una devolución de llamada para obtener una pila. Un tamaño máximo de pila de 512K a 1M debería ser más que suficiente para cualquier patrón. Para más detalles, consulte la página pcrejit.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
