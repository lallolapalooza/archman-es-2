pcre_get_stringnumber(3)

Paquete: pcre

Licencias: BSD

PCRE_GET_STRINGNUMBER(3) Manual de funciones de biblioteca PCRE_GET_STRINGNUMBER(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_get_stringnumber(const pcre *code,
     const char *name);

int pcre16_get_stringnumber(const pcre16 *code,
     PCRE_SPTR16 name);

int pcre32_get_stringnumber(const pcre32 *code,
     PCRE_SPTR32 name);

DESCRIPCIÓN

Esta función de conveniencia encuentra el número de un paréntesis de captura de subcadena con nombre en un patrón compilado. Sus argumentos son:


code Expresión regular compilada
name Nombre del cual se requiere el número

El resultado de la función es el número del paréntesis si se encuentra el nombre, o PCRE_ERROR_NOSUBSTRING en caso contrario. Cuando se permiten nombres duplicados (se establece PCRE_DUPNAMES), no se define cuál de los números será devuelto por pcre[16|32]_get_stringnumber(). Puede obtener la lista completa llamando a pcre[16|32]_get_stringtable_entries().

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
