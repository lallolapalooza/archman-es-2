pcre2_serialize_encode(3)

Paquete: pcre2

Licencias: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SERIALIZE_ENCODE(3) Manual de funciones de biblioteca PCRE2_SERIALIZE_ENCODE(3)

NOMBRE

PCRE2 - expresiones regulares compatibles con Perl (API revisada)

SINOPSIS

#include <pcre2.h>

int32_t pcre2_serialize_encode(const pcre2_code **codes,
  int32_t number_of_codes, uint8_t **serialized_bytes,
  PCRE2_SIZE *serialized_size, pcre2_general_context *gcontext);

DESCRIPCIÓN

Esta función codifica una lista de patrones compilados en un flujo de bytes que se puede guardar en disco o en otro lugar. Tenga en cuenta que este no es un formato abstracto como Java o .NET. La conversión del flujo de bytes de nuevo a patrones compilados utilizables solo puede ocurrir en un host que esté ejecutando la misma versión de PCRE2, con la misma anchura de unidades de código, y el host también debe tener la misma endianidad, anchura de punteros y tipo PCRE2_SIZE. Los argumentos para pcre2_serialize_encode() son:


codes puntero a un vector que contiene la lista
number_of_codes número de ranuras en el vector
serialized_bytes establecido para apuntar al flujo de bytes serializado
serialized_size establecido al número de bytes en el flujo de bytes
gcontext puntero a un contexto general o NULL

El argumento de contexto se utiliza para obtener memoria para el flujo de bytes. Cuando los datos serializados ya no se necesiten, deben liberarse llamando a pcre2_serialize_free(). El resultado de la función es el número de patrones serializados, o uno de los siguientes códigos de error negativos:


PCRE2_ERROR_BADDATA number_of_codes es cero o menos
PCRE2_ERROR_BADMAGIC falta de bytes de identificación en uno de los patrones
PCRE2_ERROR_MEMORY la asignación de memoria falló
PCRE2_ERROR_MIXEDTABLES los patrones no utilizan todas las mismas tablas
PCRE2_ERROR_NULL un argumento que no sea gcontext es NULL

PCRE2_ERROR_BADMAGIC significa que el código de un patrón se ha corrompido, o que una ranura en el vector no apunta a un patrón compilado.

Hay una descripción completa de la API nativa de PCRE2 en la página pcre2api y una descripción de las funciones de serialización en la página pcre2serialize.
