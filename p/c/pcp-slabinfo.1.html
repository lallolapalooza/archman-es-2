PCP-SLABINFO(1) Manual de Comandos Generales PCP-SLABINFO(1)

NOMBRE

pcp-slabinfo - Informa sobre estadísticas del asignador slab del kernel

SINOPSIS

pcp [opciones de pcp] slabinfo [-a archivo] [-s muestras] [-Z zona horaria]

DESCRIPCIÓN

El comando pcp-slabinfo se utiliza para ver diferentes estadísticas relacionadas con slab. Ayuda a los usuarios a analizar información útil relacionada con el asignador slab. La información incluye el número total de objetos que están actualmente activos, objetos asignados, páginas por slab, etc. Por defecto, pcp-slabinfo informa datos en vivo para el host local.

Las estadísticas que se muestran son las siguientes:

ENCABEZADO DESCRIPCIÓN
active_objs El número de objetos que están actualmente activos (es decir, en uso)
num_objs El número total de objetos asignados (es decir, objetos que están en uso y no en uso).
objsize El tamaño de los objetos en este slab, en bytes.
objperslab El número de objetos almacenados en cada slab.
pagesperslab El número de páginas asignadas para cada slab
active_slabs El número de slabs activos.
num_slabs El número total de slabs.

OPCIONES

-a archivo, --archive=archivo
Obtener /proc/slabinfo para un archivo de archivo especificado
-s contador, --samples=contador
Obtener las estadísticas de slabinfo para el número de muestras especificado contador
-V, --version
Mostrar el número de versión y salir.
-z, --hostzone
Usar la zona horaria local del host que es la fuente de las métricas de rendimiento, según lo identificado por las opciones -h o -a. El valor predeterminado es usar la zona horaria del host local.
-Z zona horaria, --timezone=zona horaria
Usar la zona horaria para la fecha y hora. La zona horaria está en el formato de la variable de entorno TZ, como se describe en environ(7).
-?, --help
Mostrar mensaje de uso y salir.

NOTAS

pcp-slabinfo recopila información de /proc/slabinfo.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede usarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).
