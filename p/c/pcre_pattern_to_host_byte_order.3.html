pcre_pattern_to_host_byte_order(3)

Paquete: pcre

Licencias: BSD

PCRE_PATTERN_TO_HOST_BYTE_ORDER(3) Manual de funciones de biblioteca PCRE_PATTERN_TO_HOST_BYTE_ORDER(3)

NOMBRE

PCRE - expresiones regulares compatibles con Perl

SINOPSIS

#include <pcre.h>

int pcre_pattern_to_host_byte_order(pcre *code,
     pcre_extra *extra, const unsigned char *tables);

int pcre16_pattern_to_host_byte_order(pcre16 *code,
     pcre16_extra *extra, const unsigned char *tables);

int pcre32_pattern_to_host_byte_order(pcre32 *code,
     pcre32_extra *extra, const unsigned char *tables);

DESCRIPCIÓN

Esta función asegura que los bytes en valores de 2 y 4 bytes en un patrón compilado estén en el orden correcto para el host actual. Es útil cuando un patrón compilado en un host se transfiere a otro que podría tener una diferente configuración de endianidad. Los argumentos son:


code Una expresión regular compilada
extra Puntero a una estructura pcre[16|32]_extra asociada,
o es NULL
tables Puntero a tablas de caracteres, o NULL para
establecer el predeterminado incorporado

El resultado es 0 para éxito, o un valor negativo PCRE_ERROR_xxx en caso contrario.

Hay una descripción completa de la API nativa de PCRE en la página pcreapi y una descripción de la API POSIX en la página pcreposix.
