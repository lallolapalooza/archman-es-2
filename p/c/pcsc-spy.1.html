PCSC-SPY(1) Documentación de Perl aportada por el usuario PCSC-SPY(1)

NOMBRE

pcsc-spy - Un comando de espionaje PC/SC

SINOPSIS

pcsc-spy [-n|--nocolor] [-d|--diffable] [-h|--help] [-v|--version] [-t|--thread] [nombre_archivo_fifo]

DESCRIPCIÓN

pcsc-spy muestra las llamadas PC/SC de una aplicación. Debe usarse con la biblioteca libpcscspy.so.0.

Para poder espiar la capa PC/SC, el flujo de la aplicación debe ser modificado usando "LIBPCSCLITE_DELEGATE" para que todas las llamadas PC/SC sean redirigidas.

OPCIONES

-d, --diffable
Elimina las partes variables (como los valores de los manejadores) de la salida para que dos ejecuciones puedan compararse más fácilmente.
-h, --help
Muestra un breve texto de ayuda.
-n, --nocolor
Desactiva la colorización de la salida (si desea redirigir la salida a un archivo, por ejemplo).
-v, --version
Imprime la versión del programa pcsc-spy además de un copyright, una lista de autores.
-t, --thread
Añade un número de hilo antes de cada línea de registro para identificar las llamadas del mismo hilo.

EJEMPLOS

Usaremos la variable de entorno "LIBPCSCLITE_DELEGATE" para cargar nuestra biblioteca de espionaje.

Ejemplo:

sh /usr/share/doc/libpcsclite-dev/setup_spy.sh
export LIBPCSCLITE_DELEGATE=/lib/x86_64-linux-gnu/libpcscspy.so.0
LIBPCSCLITE_DELEGATE=/lib/x86_64-linux-gnu/libpcscspy.so.0 mi_aplicacion

Iniciando la herramienta de espionaje

pcsc-spy

Si se pasa un argumento de comando, lo usamos en lugar del archivo FIFO predeterminado ~/pcsc-spy. Entonces es posible grabar un registro de ejecución y usar pcsc-spy varias veces en el mismo registro.

Para crear el archivo de registro, simplemente haga:

mkfifo ~/pcsc-spy
cat ~/pcsc-spy > archivo_log

y ejecute su aplicación PC/SC.

ARCHIVOS

El archivo FIFO ~/pcsc-spy es utilizado por libpcscspy.so.0 para enviar las líneas de registro crudas.
