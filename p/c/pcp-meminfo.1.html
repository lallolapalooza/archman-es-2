PCP-MEMINFO(1) Manual de Comandos Generales PCP-MEMINFO(1)

NOMBRE

pcp-meminfo - Informar estadísticas de la memoria del sistema.

SINOPSIS

pcp [opciones pcp] meminfo [-s muestras] [-a archivo] [-S hora_inicio] [-T hora_fin]

DESCRIPCIÓN

El comando pcp-meminfo se utiliza para ver los diferentes tipos de estadísticas relacionadas con la memoria. Utilizando varias opciones, ayuda al usuario a analizar información útil relacionada con la disponibilidad de memoria. Esta información incluye memoria total, memoria disponible, memoria compartida, etc. Por defecto, pcp-meminfo informa datos en vivo para el host local.

OPCIONES

-a, --archive
Obtener /proc/meminfo de un archivo de archivo especificado
-s, --samples
Obtener meminfo para el número de muestras especificado
-S, --start HORA
Filtrar las muestras del archivo desde la hora dada
-T, --finish HORA
Filtrar las muestras del archivo hasta la hora dada
-V, --version
Mostrar número de versión y salir.
-?, --help
Mostrar mensaje de uso y salir.

NOTAS

pcp-meminfo recopila información de /proc/meminfo y pretende ser compatible con él en línea de comandos y salida.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para conocer las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).

VER TAMBIÉN
