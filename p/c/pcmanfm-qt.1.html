NOMBRE

PCManFM-Qt - Un gestor de archivos ligero basado en Qt para X Window.

SINOPSIS

pcmanfm-qt [OPCIÓN...] [ARCHIVO1, ARCHIVO2,...]

DESCRIPCIÓN

PCMan File Manager Qt (PCManFM-Qt) es un gestor de archivos extremadamente rápido, ligero y rico en funciones con navegación por pestañas. Es el gestor de archivos predeterminado para el entorno de escritorio ligero LXQt.

OPCIONES

Opciones de ayuda:

-h, --help
Mostrar opciones de ayuda

Opciones de aplicación:

-p, --profile=PERFIL
Establecer el nombre del perfil de configuración
-d, --daemon-mode
Ejecutar PCManFM como demonio
--quit
Salir de PCManFM
--desktop
Iniciar el gestor de escritorio
--desktop-off
Desactivar el gestor de escritorio si está en ejecución
--desktop-pref=NOMBRE
Abrir el diálogo de preferencias del escritorio en la página con el nombre especificado
-w, --set-wallpaper=ARCHIVO
Establecer el fondo de escritorio a partir de la imagen ARCHIVO
--wallpaper-mode=MODO
Establecer el modo del fondo de escritorio. MODO=(color|stretch|fit|center|tile)
--show-pref=NOMBRE
Abrir el diálogo de Preferencias en la página con el nombre especificado
-n, --new-window
Abrir una nueva ventana
-f, --find-files
Abrir la utilidad Buscar Archivos
