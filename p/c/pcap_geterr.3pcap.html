pcap_geterr.3pcap

Paquete: libpcap

Licencias: BSD-3-Clause

PCAP_GETERR(3PCAP) PCAP_GETERR(3PCAP)

NOMBRE

pcap_geterr, pcap_perror - obtener o imprimir el texto del mensaje de error de libpcap

SINOPSIS

#include <pcap/pcap.h>
char *pcap_geterr(pcap_t *p);
void pcap_perror(pcap_t *p, const char *prefix);

DESCRIPCIÓN

pcap_geterr() devuelve el texto del error relativo al último error de la biblioteca pcap. NOTA: el puntero que devuelve dejará de apuntar a una cadena de mensaje de error válida después de que se cierre el pcap_t pasado; debes usar o copiar la cadena antes de cerrar el pcap_t.

pcap_perror() imprime el texto del último error de la biblioteca pcap en stderr, precedido por prefix.

VER TAMBIÉN

pcap(3PCAP)
