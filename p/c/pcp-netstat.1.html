PCP-NETSTAT(1) Manual de Comandos Generales PCP-NETSTAT(1)

NOMBRE

pcp-netstat - Informar estadísticas para diferentes protocolos de red e interfaces de red.

SINOPSIS

pcp [opciones de pcp] netstat [--statistics] [-p [TCP|IP|UDP|ICMP]] [-i] [-s muestras] [-a archivo] [-S hora_inicio] [-T hora_fin]

DESCRIPCIÓN

El comando pcp-netstat se utiliza para ver los diferentes tipos de estadísticas relacionadas con los protocolos de red y las interfaces de red. Esta herramienta es útil para verificar el estado de sus interfaces de red, conexiones de red y para solucionar problemas de red. Esta herramienta también se puede utilizar para analizar estadísticas de red para todos los protocolos disponibles, incluidos los protocolos TCP, UDP, ICMP e IP.

Por defecto, pcp-netstat informa datos en vivo para el host local. Tiene la capacidad de analizar datos en los archivos también.

OPCIONES

--statistics
muestra una salida similar a netstat -s, que muestra estadísticas resumidas para cada protocolo
-i
muestra una salida similar a netstat -i -a -n, que muestra una tabla de todas las interfaces de red
-p, --TCP|IP|UDP|ICMP
filtra estadísticas de red específicas de un protocolo
-a archivo, --archive=archivo
Obtiene /proc/netstat para un archivo de archivo especificado archivo
-s conteo, --samples=conteo
Obtiene las estadísticas de red para el número especificado de muestras conteo
-S, --start=tiempo
Filtra las muestras del archivo desde el tiempo dado
-T, --finish=tiempo
Filtra las muestras del archivo hasta el tiempo dado
-V, --version
Muestra el número de versión y sale.
-?, --help
Muestra el mensaje de uso y sale.

ENTORNO PCP

Las variables de entorno con el prefijo PCP_ se utilizan para parametrizar los nombres de archivos y directorios utilizados por PCP. En cada instalación, el archivo /etc/pcp.conf contiene los valores locales para estas variables. La variable $PCP_CONF puede utilizarse para especificar un archivo de configuración alternativo, como se describe en pcp.conf(5).

Para ver las variables de entorno que afectan a las herramientas de PCP, consulte pmGetOptions(3).
