NOMBRE

pam_mail - Informar sobre el correo disponible

SINOPSIS

pam_mail.so [close] [debug] [dir=maildir] [empty] [hash=count] [noenv] [nopen] [quiet] [standard]

DESCRIPCIÓN

El módulo PAM pam_mail proporciona el servicio de "tienes correo nuevo" al usuario. Puede conectarse a cualquier aplicación que tenga ganchos de credenciales o de sesión. Ofrece un único mensaje que indica la novedad de cualquier correo que encuentre en la carpeta de correo del usuario. Este módulo también establece la variable de entorno PAM, MAIL, al directorio de correo del usuario.

Si el archivo de cola de correo (ya sea /var/mail/$USER o una ruta proporcionada con el parámetro dir=) es un directorio, entonces pam_mail asume que está en formato Maildir.

OPCIONES

close

Indica si el usuario tiene correo también al cerrar sesión.

debug

Imprime información de depuración.

dir=maildir

Busca el correo del usuario en una ubicación alternativa definida por maildir/<login>. La ubicación predeterminada para el correo es /var/mail/<login>. Tenga en cuenta que si maildir suministrado está precedido por un '~', el directorio se interpreta como un archivo en el directorio de inicio del usuario.

empty

También imprime un mensaje si el usuario no tiene correo.

hash=count

Profundidad de hash del directorio de correo. Por ejemplo, un hashcount de 2 haría que el archivo de correo sea /var/spool/mail/u/s/user.

noenv

No establece la variable de entorno MAIL.

nopen

No imprime ninguna información de correo al iniciar sesión. Esta bandera es útil para que se establezca la variable de entorno MAIL, pero sin mostrar ninguna información al respecto.

quiet

Solo informa cuando hay correo nuevo.

standard

Formato antiguo de "Tienes..." que no muestra la cola de correo utilizada. Esto también implica "empty".

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo session y auth (en el establecimiento y eliminación de credenciales).

VALORES DE RETORNO

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_SERVICE_ERR

Argumentos mal formados.

PAM_SUCCESS

Éxito.

PAM_USER_UNKNOWN

Usuario desconocido.

EJEMPLOS

Añada la siguiente línea a /etc/pam.d/login para indicar que el usuario tiene correo nuevo cuando inicia sesión en el sistema.

session  optional  pam_mail.so standard

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)
