PAM(3) Manual de Linux-PAM PAM(3)

NOMBRE

pam - Biblioteca de Módulos de Autenticación Conectables

SINOPSIS

#include <security/pam_appl.h>
#include <security/pam_modules.h>
#include <security/pam_ext.h>

DESCRIPCIÓN

PAM es un sistema de bibliotecas que manejan las tareas de autenticación de las aplicaciones (servicios) en el sistema. La biblioteca proporciona una interfaz de programación de aplicaciones (API) general y estable a la que los programas que otorgan privilegios (como login(1) y su(1)) recurren para realizar tareas de autenticación estándar.

Inicialización y Limpieza

La función pam_start(3) crea el contexto PAM e inicia la transacción PAM. Es la primera de las funciones PAM que debe ser llamada por una aplicación. El estado de la transacción está contenido enteramente dentro de la estructura identificada por este manejador, por lo que es posible tener múltiples transacciones en paralelo. Pero no es posible utilizar el mismo manejador para transacciones diferentes; se necesita uno nuevo para cada contexto nuevo.

La función pam_end(3) termina la transacción PAM y es la última función que una aplicación debe llamar en el contexto PAM. Tras el retorno, el manejador pamh ya no es válido y toda la memoria asociada con él será inválida. Puede ser llamada en cualquier momento para terminar una transacción PAM.

Autenticación

La función pam_authenticate(3) se utiliza para autenticar al usuario. Se requiere que el usuario proporcione un token de autenticación dependiendo del servicio de autenticación; generalmente es una contraseña, pero también podría ser una huella dactilar.

La función pam_setcred(3) gestiona las credenciales del usuario.

Gestión de Cuentas

La función pam_acct_mgmt(3) se utiliza para determinar si la cuenta del usuario es válida. Comprueba la expiración del token de autenticación y de la cuenta, y verifica las restricciones de acceso. Típicamente se llama después de que el usuario ha sido autenticado.

Gestión de Contraseñas

La función pam_chauthtok(3) se utiliza para cambiar el token de autenticación de un usuario dado a petición o porque el token ha expirado.

Gestión de Sesiones

La función pam_open_session(3) configura una sesión de usuario para un usuario previamente autenticado con éxito. La sesión debe terminarse posteriormente con una llamada a pam_close_session(3).

Conversación

La biblioteca PAM utiliza una devolución de llamada definida por la aplicación para permitir una comunicación directa entre un módulo cargado y la aplicación. Esta devolución de llamada se especifica mediante la estructura struct pam_conv pasada a pam_start(3) al inicio de la transacción. Consulte pam_conv(3) para obtener detalles.

Objetos de Datos

Las funciones pam_set_item(3) y pam_get_item(3) permiten a las aplicaciones y a los módulos de servicio PAM establecer y recuperar información de PAM.

La función pam_get_user(3) es el método preferido para obtener el nombre de usuario.

Las funciones pam_set_data(3) y pam_get_data(3) permiten a los módulos de servicio PAM establecer y recuperar datos de forma libre entre invocaciones.

Gestión de Entorno y Errores

Las funciones pam_putenv(3), pam_getenv(3) y pam_getenvlist(3) son para mantener un conjunto de variables de entorno privadas.

La función pam_strerror(3) devuelve un puntero a una cadena que describe el código de error PAM dado.

VALORES DE RETORNO

Los siguientes códigos de retorno son conocidos por PAM:

PAM_ABORT

Error crítico, aborto inmediato.

PAM_ACCT_EXPIRED

La cuenta del usuario ha expirado.

PAM_AUTHINFO_UNAVAIL

El servicio de autenticación no puede recuperar la información de autenticación.

PAM_AUTHTOK_DISABLE_AGING

El envejecimiento del token de autenticación está deshabilitado.

PAM_AUTHTOK_ERR

Error en la manipulación del token de autenticación.

PAM_AUTHTOK_EXPIRED

El token de autenticación ha expirado.

PAM_AUTHTOK_LOCK_BUSY

El bloqueo del token de autenticación está ocupado.

PAM_AUTHTOK_RECOVERY_ERR

No se puede recuperar la información de autenticación.

PAM_AUTH_ERR

Fallo de autenticación.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CONV_ERR

Fallo de conversación.

PAM_CRED_ERR

Fallo al establecer las credenciales del usuario.

PAM_CRED_EXPIRED

Las credenciales del usuario han expirado.

PAM_CRED_INSUFFICIENT

Credenciales insuficientes para acceder a los datos de autenticación.

PAM_CRED_UNAVAIL

El servicio de autenticación no puede recuperar las credenciales del usuario.

PAM_IGNORE

El valor de retorno debe ser ignorado por la distribución de PAM.

PAM_MAXTRIES

Se ha agotado el número máximo de reintentos para el servicio.

PAM_MODULE_UNKNOWN

El módulo es desconocido.

PAM_NEW_AUTHTOK_REQD

El token de autenticación ya no es válido; se requiere uno nuevo.

PAM_NO_MODULE_DATA

No hay datos específicos del módulo presentes.

PAM_OPEN_ERR

Error al cargar el módulo.

PAM_PERM_DENIED

Permiso denegado.

PAM_SERVICE_ERR

Error en el módulo de servicio.

PAM_SESSION_ERR

No se puede crear o eliminar una entrada para la sesión especificada.

PAM_SUCCESS

Éxito.

PAM_SYMBOL_ERR

Símbolo no encontrado.

PAM_SYSTEM_ERR

Error del sistema.

PAM_TRY_AGAIN

Fallo en la comprobación preliminar por el servicio de contraseñas.

PAM_USER_UNKNOWN

El usuario es desconocido para el módulo de autenticación subyacente.
