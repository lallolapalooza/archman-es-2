PATCHWORK(1) Manual de Comandos Generales PATCHWORK(1)

NOMBRE

patchwork - filtro para dibujar grafos agrupados como treemaps

SINOPSIS

patchwork [-(G|N|E)nombre=valor] [-Tidioma] [-larchivolib] [-oarchivosalida] [-O] [-P] [-v] [-V] [archivos]

DESCRIPCIÓN

patchwork dibuja grafos agrupados usando un diseño de treemap cuadrado. Como entrada, toma cualquier grafo en formato dot. A cada agrupación se le da un área basada en las áreas especificadas por las agrupaciones y nodos que contiene. Las áreas de los nodos y las agrupaciones vacías se pueden especificar mediante el atributo area. El valor predeterminado es 1.

El grafo raíz se dibuja como un cuadrado. Luego, recursivamente, la región de una agrupación o grafo se particiona entre sus nodos y agrupaciones de nivel superior, cada uno recibiendo una subregión aproximadamente cuadrada con su área especificada.

FORMATOS DE SALIDA

Patchwork utiliza un mecanismo de plugins extensible para sus renderizadores de salida, por lo que para ver qué formatos de salida soporta su instalación de patchwork, puede usar ``patchwork -Txxx'' (donde xxx es un formato improbable) y comprobar el mensaje de advertencia. Además, el mecanismo de plugins soporta múltiples implementaciones de los formatos de salida. Para ver qué variantes están disponibles, use, por ejemplo: ``patchwork -Tpng:'' y para forzar una variante particular, use, por ejemplo: ``patchwork -Tpng:gd''

Tradicionalmente, patchwork soporta los siguientes: -Tps (PostScript), -Tsvg -Tsvgz (Gráficos Vectoriales Escalables), -Tfig (Gráficos XFIG), -Tmif (Gráficos FrameMaker), -Thpgl (trazadores HP), y -Tpcl (impresoras Laserjet), -Tpng -Tgif (gráficos de mapa de bits), -Timap (archivos de mapa de imagen para servidores httpd para cada nodo o arista que tenga un atributo "href" no nulo.), -Tcmapx (mapa de imagen del lado del cliente para usar en html y xhtml). Formatos de salida adicionales menos comunes o más específicos se pueden encontrar en https://www.graphviz.org/doc/info/output.html.)

Se pueden encontrar plugins alternativos que proporcionan soporte para un formato de salida dado en el mensaje de error resultante de agregar un ':' al formato. por ejemplo, -Tpng: El primer plugin listado es siempre el predeterminado.

LENGUAJE DE ARCHIVO DE GRAFO

Aquí hay una sinopsis del lenguaje de archivos de grafo, normalmente usando la extensión .gv, para grafos:

[strict] (graph|digraph) nombre { lista-de-sentencias }
Es el grafo de nivel superior. Si el grafo es strict entonces no se permiten múltiples aristas entre los mismos pares de nodos. Si es un grafo dirigido, indicado por digraph, entonces el operador-de-arista debe ser "->". Si es un graph no dirigido, entonces el operador-de-arista debe ser "--". Las sentencias pueden ser:

nombre=valor;
node [nombre=valor];
edge [nombre=valor];
Establece el atributo predeterminado de grafo, nodo o arista nombre a valor. Cualquier subgrafo, nodo o arista que aparezca después de esto hereda los nuevos atributos predeterminados.

n0 [nombre0=valor0,nombre1=valor1,...]; Crea el nodo n0 (si aún no existe) y establece sus atributos según la lista opcional.

n0 operador-de-arista n1 operador-de-arista ... operador-de-arista nn [nombre0=valor0,nombre1=valor1,...];
Crea aristas entre los nodos n0, n1, ..., nn y establece sus atributos según la lista opcional. Crea nodos según sea necesario.

[subgraph nombre] { lista-de-sentencias }
Crea un subgrafo. Los subgrafos se pueden usar en lugar de n0, ..., nn en las sentencias anteriores para crear aristas. [subgraph nombre] es opcional; si se omite, al subgrafo se le asigna un nombre interno.

Los comentarios pueden ser /*similares a C*/ o //similares a C++.

Los nombres y valores de los atributos son cadenas de caracteres ordinarias (estilo C). Las siguientes secciones describen los atributos que controlan el diseño del grafo.

ATRIBUTOS DEL GRAFO

size="x,y" establece el cuadro delimitador del dibujo en pulgadas.

page="x,y" establece la unidad de paginación PostScript.

ratio=f establece la relación de aspecto a f, que puede ser un número de punto flotante, o una de las palabras clave fill, compress, o auto.

pagedir=[TBLR][TBLR] establece el orden principal y secundario de la paginación.

rotate=90 establece el modo horizontal. (orientation=land es compatible con versiones anteriores pero obsoleto.)

center=n un valor distinto de cero centra el dibujo en la página.

layers="id:id:id:id" es una secuencia de identificadores de capas para diagramas de superposición. La variable de matriz PostScript layercolorseq establece la asignación de colores a las capas. El índice más bajo es 1 y cada elemento debe ser una matriz de 3 elementos para ser interpretada como una coordenada de color.

color=valorcolor establece el color del primer plano (bgcolor para el fondo).

href="url" la url predeterminada para los archivos de mapa de imagen; en archivos PostScript, la url base para todas las urls relativas, según lo reconocido por Acrobat Distiller 3.0 y posteriores.

URL="url" ("URL" es un sinónimo de "href".)

stylesheet="archivo.css" incluye una referencia a una hoja de estilos en las salidas -Tsvg y -Tsvgz. Ignorado por otros formatos.

splines. Si se establece en true, las aristas se dibujan como splines. Si se establece en polyline, las aristas se dibujan como polilíneas. Si se establece en ortho, las aristas se dibujan como polilíneas ortogonales. En todos estos casos, los nodos no pueden solaparse. Si splines=false o splines=line, las aristas se dibujan como segmentos de línea. El valor predeterminado es false.

ATRIBUTOS DE NODO

height=d o width=d establece la altura o anchura mínimas. Agregar fixedsize=true fuerza que estos sean el tamaño real (las etiquetas de texto se ignoran).

shape=record polygon epsf polígonopredefinido
polígonopredefinido es uno de: plaintext ellipse oval circle egg triangle box diamond trapezium parallelogram house hexagon octagon note tab box3d component. (Los polígonos se definen o modifican por los siguientes atributos de nodo: regular, peripheries, sides, orientation, distortion y skew.) epsf utiliza el atributo shapefile del nodo como el nombre de ruta de un archivo EPSF externo que se cargará automáticamente para la forma del nodo.

label=texto donde texto puede incluir saltos de línea escapados \n, \l, o \r para líneas centradas, alineadas a la izquierda y a la derecha. El valor de la cadena '\N' será reemplazado por el nombre del nodo. El valor de la cadena '\G' será reemplazado por el nombre del grafo. Las etiquetas de registro pueden contener listas recursivas de cajas delimitadas por { | }. Los identificadores de puerto en las etiquetas se separan por corchetes angulares < >. En el archivo de grafo, use dos puntos (como, nodo0:puerto28).

fontsize=n establece el tamaño del tipo de la etiqueta a n puntos.

fontname=nombre establece el nombre de la familia de fuentes de la etiqueta.

color=valorcolor establece el color del contorno y el color de relleno predeterminado si style=filled y no se especifica fillcolor.

fillcolor=valorcolor establece el color de relleno cuando style=filled. Si no se especifica, el fillcolor cuando style=filled es por defecto el mismo que el color del contorno.

fontcolor=valorcolor establece el color del texto de la etiqueta.

Un valorcolor puede ser "h,s,v" (tono, saturación, brillo) números de punto flotante entre 0 y 1, o un nombre de color X11 como white black red green blue yellow magenta cyan o burlywood, o un valor "#rrggbb" (rojo, verde, azul, 2 caracteres hexadecimales cada uno).

style=filled solid dashed dotted bold invis o cualquier código Postscript.

layer=id o id:id o "all" establece las capas activas del nodo. La cadena vacía significa sin capas (invisible).

Los siguientes atributos se aplican solo a los nodos de forma poligonal:

regular=n si n es distinto de cero, entonces el polígono se regulariza, es decir, se simetriza respecto a los ejes x e y; de lo contrario, el polígono adopta la relación de aspecto de la etiqueta. Los builtin_polygons que no son regulares se regularizan con este atributo. Los builtin_polygons que ya son regulares no se ven afectados (es decir, no se pueden hacer asimétricos).

peripheries=n establece el número de líneas de periferia dibujadas alrededor del polígono. Este valor reemplaza el número de líneas de periferia de los builtin_polygons.

sides=n establece el número de lados del polígono. n<3 resulta en una elipse. Este atributo es ignorado por los builtin_polygons.

orientation=f establece la orientación del primer vértice del polígono en sentido antihorario desde la vertical, en grados. f puede ser un número de punto flotante. La orientación de las etiquetas no se ve afectada por este atributo. Este atributo se añade a la orientación inicial de los builtin_polygons.

distortion=f establece la cantidad de ensanchamiento de la parte superior y estrechamiento de la parte inferior del polígono (en relación con su orientación). Se sugieren valores de punto flotante entre -1 y +1. Este atributo es ignorado por los builtin_polygons.

skew=f establece la cantidad de desplazamiento hacia la derecha de la parte superior y desplazamiento hacia la izquierda de la parte inferior del polígono (en relación con su orientación). Se sugieren valores de punto flotante entre -1 y +1. Este atributo es ignorado por los builtin_polygons.

href="url" establece la URL para el nodo en archivos imagemap, PostScript y SVG. Las subcadenas '\N' y '\G' se sustituyen de la misma manera que para el atributo de etiqueta de nodo. Adicionalmente, la subcadena '\L' se sustituye por la cadena de la etiqueta del nodo.

URL="url" ("URL" es un sinónimo de "href".)

target="target" es una cadena de destino para imagemaps del lado del cliente y SVG, efectiva cuando los nodos tienen una URL. La cadena de destino se utiliza para determinar qué ventana del navegador se utiliza para la URL. Establecerla en "_graphviz" abrirá una nueva ventana si aún no existe, o la reutilizará si existe. Si la cadena de destino está vacía, por defecto, no se incluye ningún atributo de destino en la salida. Las subcadenas '\N' y '\G' se sustituyen de la misma manera que para el atributo de etiqueta de nodo. Adicionalmente, la subcadena '\L' se sustituye por la cadena de la etiqueta del nodo.

tooltip="tooltip" es una cadena de ayuda emergente para imagemaps del lado del cliente y SVG, efectiva cuando los nodos tienen una URL. La cadena de ayuda emergente tiene por defecto el mismo valor que la cadena de etiqueta, pero este atributo permite que los nodos sin etiquetas tengan aún así cadenas de ayuda emergentes, permitiendo así grafos más densos. Las subcadenas '\N' y '\G' se sustituyen de la misma manera que para el atributo de etiqueta de nodo. Adicionalmente, la subcadena '\L' se sustituye por la cadena de la etiqueta del nodo.

OPCIONES DE LÍNEA DE COMANDOS

-G establece un atributo de grafo por defecto.
-N establece un atributo de nodo por defecto.
-E establece un atributo de arista por defecto. Ejemplo: -Gsize="7,8" -Nshape=box -Efontsize=8

-larchivo carga archivos de biblioteca PostScript personalizados. Por lo general, estos definen formas o estilos personalizados. Si se proporciona solo -l, se omite la biblioteca estándar.

-Tidioma establece el idioma de salida como se describe anteriormente.

-O genera automáticamente nombres de archivo de salida basados en el nombre de archivo de entrada y el formato -T.

-oarchivo escribe la salida en archivo.

-x reduce el grafo.

-Lg no utiliza la cuadrícula.

-LO utiliza la fuerza atractiva antigua.

-Lni establece el número de iteraciones a i.

-LUi establece el factor no escalado a i.

-LCv establece el factor de expansión de superposición a v.

-LT[*]v establece la temperatura (factor de temperatura) a v.

-v (verboso) imprime diversa información útil para la depuración.

-V (versión) imprime información de la versión y sale.

-? imprime la ayuda y sale.

GRÁFICOS Y SUBGRÁFICOS

Los atributos de grafo se aplican al grafo en su totalidad. Los atributos de subgrafo se aplican al subgrafo y sus descendientes (nodos y aristas). Los atributos de grafo se establecen mediante la palabra clave graph, seguidas de una lista de atributos entre corchetes. Los atributos de subgrafo se establecen mediante la palabra clave subgraph, seguidas de un identificador opcional y una lista de atributos entre corchetes.

Los atributos de grafo pueden afectar a los atributos de los nodos y aristas que se establezcan posteriormente, estableciendo sus valores por defecto. Los atributos de subgrafo pueden afectar a los atributos de los nodos y aristas dentro del subgrafo.

Los atributos de grafo siguientes se aplican a los grafos:

size="width,height" establece el tamaño del grafo en pulgadas. El valor por defecto es "32,32".

ratio=f establece la relación de aspecto del grafo. Si f es mayor que 0, se garantiza que la relación de aspecto de la salida se ajustará a f. Si f es igual a 0, se utiliza la relación de aspecto de la etiqueta. Si f es una cadena, es la relación de aspecto de la etiqueta.

label=text establece una etiqueta para el grafo.

labelloc="t" o "b" establece la ubicación de la etiqueta (arriba o abajo).

fontsize=n establece el tamaño de la fuente para la etiqueta.

fontname=name establece la familia de fuentes para la etiqueta.

fontcolor=colorvalue establece el color de la fuente para la etiqueta.

bgcolor=colorvalue establece el color de fondo del grafo.

bb="llx,lly,urx,ury" establece el cuadro delimitador del grafo.

sides=n establece el número de lados a usar para los polígonos dentro del grafo. El valor por defecto es 0.

peripheries=n establece el número de líneas de periferia a usar para los polígonos dentro del grafo. El valor por defecto es 1.

orientation=f establece la orientación del primer vértice de los polígonos dentro del grafo.

distortion=f establece la distorsión de los polígonos dentro del grafo.

skew=f establece la inclinación de los polígonos dentro del grafo.

cluster se utiliza para agrupar nodos en subgrafos. Los subgrafos con prefijo "cluster" se dibujan en un cuadro delimitador con el nombre del subgrafo como etiqueta.

href="url" establece la URL para el grafo en archivos imagemap, PostScript y SVG. Las subcadenas '\N' y '\G' se sustituyen de la misma manera que para el atributo de etiqueta de nodo. Adicionalmente, la subcadena '\L' se sustituye por la cadena de la etiqueta del grafo.

URL="url" ("URL" es un sinónimo de "href".)

target="target" es una cadena de destino para imagemaps del lado del cliente y SVG, efectiva cuando los grafos tienen una URL.

tooltip="tooltip" es una cadena de ayuda emergente para imagemaps del lado del cliente y SVG, efectiva cuando los grafos tienen una URL.

Los atributos de los subgrafos son los mismos que los de los grafos. Sin embargo, los atributos de subgrafo solo afectan a los nodos y aristas dentro del subgrafo.

EJEMPLOS

graph G {
  node[style=filled]
  subgraph cluster0 {
    subgraph cluster0_0 {
      style=filled
      fillcolor=green
      a b[area=3 fillcolor=yellow]
    }
    subgraph cluster0_1 {
       area=2
       bgcolor=yellow
    }
    c [style=filled
      fillcolor=red ]
  }
  subgraph cluster1 {
    e f
  }
}

ERRORES

Actualmente, patchwork ignora los bordes y no proporciona pistas visuales para indicar la anidación. Dichas pistas podrían consistir en cajas anidadas o contornos rectangulares más gruesos. Además, sería bueno si se pudiera mostrar alguna etiqueta de clúster.

Patchwork no tiene un mecanismo para ajustar las etiquetas dentro del cuadro proporcionado.
