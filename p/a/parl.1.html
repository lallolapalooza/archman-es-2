NOMBRE

parl - Cargador binario de PAR

SINOPSIS

(Por favor, consulta pp para conocer formas convenientes de crear ejecutables autocontenidos, scripts o archivos PAR a partir de programas de Perl.)

Para crear una distribución PAR a partir de una distribución de módulo CPAN:

% parl -p                 # crear una distribución PAR bajo la ruta actual
% parl -p Foo-0.01        # asumir distribución CPAN desempaquetada en Foo-0.01/

Para manipular una distribución PAR:

% parl -i Foo-0.01-i386-freebsd-5.8.0.par   # instalar
% parl -i http://foo.com/Foo-0.01           # añade automáticamente el nombre de arquitectura + versión de perl
% parl -i cpan://AUTRIJUS/PAR-0.74          # usa el directorio del autor de CPAN
% parl -u Foo-0.01-i386-freebsd-5.8.0.par   # desinstalar
% parl -s Foo-0.01-i386-freebsd-5.8.0.par   # firmar
% parl -v Foo-0.01-i386-freebsd-5.8.0.par   # verificar

Para usar Hello.pm desde ./foo.par:

% parl -A./foo.par -MHello 
% parl -A./foo -MHello      # la parte .par es opcional

Lo mismo, pero busca foo.par en la lista @INC;

% parl -Ifoo.par -MHello 
% parl -Ifoo -MHello        # lo mismo

Ejecuta test.pl o script/test.pl desde foo.par:

% parl foo.par test.pl      # busca 'main.pl' por defecto,
                            # de lo contrario ejecuta 'test.pl'

Para crear un ejecutable autocontenido que contenga un archivo PAR:

% parl -O./foo foo.par
% ./foo test.pl             # lo mismo que arriba

Para incrustar los módulos y objetos compartidos no esenciales necesarios para la ejecución de PAR (como "Zlib", "IO", "Cwd", etc.), usa el flag -b:

% parl -b -O./foo foo.par
% ./foo test.pl             # se ejecuta en cualquier lugar con los módulos principales instalados

Si también deseas incrustar módulos principales, usa el flag -B en su lugar:

% parl -B -O./foo foo.par
% ./foo test.pl             # se ejecuta en cualquier lugar con el intérprete de perl

Esto es particularmente útil al crear ejecutables binarios independientes; consulta pp para obtener más detalles.

DESCRIPCIÓN

Este comando independiente ofrece aproximadamente la misma funcionalidad que "perl -MPAR", excepto que toma los archivos .par precargados a través de "-Afoo.par" en lugar de "-MPAR=foo.par".

Además, te permite convertir una distribución CPAN a una distribución PAR, así como manipular dichas distribuciones. Para más información sobre las distribuciones PAR, consulta PAR::Dist.

Puedes usarlo para ejecutar archivos .par:

# ejecuta script/run.pl en el archivo, usa su lib/* como bibliotecas
% parl myapp.par run.pl     # ejecuta run.pl o script/run.pl en myapp.par
% parl otherapp.pl          # también ejecuta scripts normales de perl

Sin embargo, si el archivo .par contiene main.pl o script/main.pl, se usa en su lugar:

% parl myapp.par run.pl     # ejecuta main.pl, con 'run.pl' como @ARGV

Finalmente, la opción "-O" crea un ejecutable binario independiente a partir de un archivo PAR:

% parl -B -Omyapp myapp.par
% ./myapp                   # ejecútalo en cualquier lugar sin binarios de perl

Con el flag "--par-options", los binarios generados pueden actuar como "parl" para empaquetar nuevos binarios:

% ./myapp --par-options -Omyap2 myapp.par   # idéntico a ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # ahora con un PAR diferente

Para una explicación del formato de ejecutable independiente, consulta par.pl.
