NOMBRE

pam_debug - Módulo PAM para depurar la pila PAM

SINOPSIS

pam_debug.so [auth=valor] [cred=valor] [acct=valor] [prechauthtok=valor] [chauthtok=valor] [auth=valor] [open_session=valor] [close_session=valor]

DESCRIPCIÓN

El módulo PAM pam_debug está destinado a ser una ayuda de depuración para determinar cómo está operando la pila PAM. Este módulo devuelve lo que sus argumentos de módulo le indican que devuelva.

OPCIONES

auth=valor

La función pam_sm_authenticate(3) devolverá valor.

cred=valor

La función pam_sm_setcred(3) devolverá valor.

acct=valor

La función pam_sm_acct_mgmt(3) devolverá valor.

prechauthtok=valor

La función pam_sm_chauthtok(3) devolverá valor si se establece el indicador PAM_PRELIM_CHECK.

chauthtok=valor

La función pam_sm_chauthtok(3) devolverá valor si el indicador PAM_PRELIM_CHECK no está establecido.

open_session=valor

La función pam_sm_open_session(3) devolverá valor.

close_session=valor

La función pam_sm_close_session(3) devolverá valor.

Donde valor puede ser uno de: success, open_err, symbol_err, service_err, system_err, buf_err, perm_denied, auth_err, cred_insufficient, authinfo_unavail, user_unknown, maxtries, new_authtok_reqd, acct_expired, session_err, cred_unavail, cred_expired, cred_err, no_module_data, conv_err, authtok_err, authtok_recover_err, authtok_lock_busy, authtok_disable_aging, try_again, ignore, abort, authtok_expired, module_unknown, bad_item, conv_again, incomplete.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulo (auth, account, password y session).

VALORES DE RETORNO

PAM_SUCCESS

Código de retorno predeterminado si no se especificó ningún otro valor, de lo contrario, el valor de retorno especificado.

EJEMPLOS

auth    requisite       pam_permit.so
auth    [success=2 default=ok]  pam_debug.so auth=perm_denied cred=success
auth    [default=reset]         pam_debug.so auth=success cred=perm_denied
auth    [success=done default=die] pam_debug.so
auth    optional        pam_debug.so auth=perm_denied cred=perm_denied
auth    sufficient      pam_debug.so auth=success cred=success

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)

AUTOR
