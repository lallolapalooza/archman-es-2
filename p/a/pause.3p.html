PRÓLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pause — suspende el hilo hasta que se reciba una señal

SINOPSIS

#include <unistd.h>
int pause(void);

DESCRIPCIÓN

La función pause() suspenderá el hilo que la llama hasta la entrega de una señal cuya acción sea ejecutar una función de captura de señales o terminar el proceso.

Si la acción es terminar el proceso, pause() no devolverá.

Si la acción es ejecutar una función de captura de señales, pause() devolverá después de que la función de captura de señales retorne.

VALOR DE RETORNO

Dado que pause() suspende la ejecución del hilo indefinidamente a menos que sea interrumpido por una señal, no hay un valor de retorno de éxito. Se devolverá un valor de -1 y se establecerá errno para indicar el error.

ERRORES

La función pause() fallará si:

EINTR
Una señal es capturada por el proceso que llama y el control se devuelve de la función de captura de señales.

USO POR PARTE DE LA APLICACIÓN

Muchos usos comunes de pause() tienen ventanas de tiempo. El escenario implica comprobar una condición relacionada con una señal y, si la señal no se ha producido, llamar a pause(). Cuando la señal se produce entre la comprobación y la llamada a pause(), el proceso a menudo se bloquea indefinidamente. Las funciones sigprocmask() y sigsuspend() pueden utilizarse para evitar este tipo de problemas.
