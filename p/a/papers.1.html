NOMBRE

papers - visor de documentos GNOME

La aplicación Papers Document Viewer para el entorno de escritorio GNOME

SINTAXIS

papers [--help] [--page-label=PÁGINA | --page-index=NÚMERO | --named-dest=DEST] [--fullscreen] [--presentation] [nombre_archivo(s)...]

DESCRIPCIÓN

Papers es un visor de documentos capaz de mostrar formatos de documentos de varias y una página como PDF y DjVu. Para obtener más información general sobre Papers, visite nuestro sitio web en https://apps.gnome.org/Papers/

OPCIONES

-?, -h, --help
Muestra las opciones de la línea de comandos.
-p, --page-label=PÁGINA
Abre el documento en la página con la etiqueta de página especificada (o número de página).
-i, --page-index=NÚMERO
Abre el documento en la página con el índice de página especificado (este es el número de página exacto, no una etiqueta de página).
-n, --named-dest=DEST
Abre el documento en el destino con nombre especificado.
-f, --fullscreen
Ejecuta Papers en modo de pantalla completa.
-s, --presentation
Ejecuta Papers en modo de presentación.
nombre_archivo(s)...
Especifica el archivo a abrir cuando se inicia Papers. Si no se especifica, Papers abrirá una ventana en blanco. Se pueden cargar varios archivos si están separados por espacios. Papers también soporta el manejo de archivos remotos. Por ejemplo, puede pasar la ubicación en la web o cargar un archivo desde un servidor FTP, como "ftp://adobe.com/sample.pdf".

ERRORES

Si encuentra un error, por favor repórtelo en https://gitlab.gnome.org/GNOME/papers/issues.
