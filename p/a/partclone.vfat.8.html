PARTCLONE(8) Partclone User Manual PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (APPLE MAC OS), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], muy similar a fsck o mkfs. Por ejemplo, para respaldar /restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos          partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS No Soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo Fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de tu acción. Normalmente, la fuente de respaldo es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos desde una tubería (pipe) solo se admite para restaurar; omite la opción -s o usa '-' para recibir datos desde la entrada estándar.

-o ARCHIVO, --output ARCHIVO

Archivo de Salida. El ARCHIVO puede ser un archivo de imagen (partclone generará) o un dispositivo, dependiendo de tu acción. Normalmente, la salida de respaldo es a un archivo de imagen y la salida de restauración es a un dispositivo.

El envío de datos a una tubería (pipe) también solo se admite para respaldar; omite la opción -o o usa '-' para enviar datos a la salida estándar.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, lo sobrescribe si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, tanto la fuente como la salida son dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloques usadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restore_raw_file

Creando archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Coloca la ruta especial para registrar la información del registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de la comprobación crc.

-F, --force

Forzar progreso.

-f seg, --UI-fresh seg

Establece un intervalo especial en segundos.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactiva el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

2: xxHash, algoritmo hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques

-w, --skip_write_error

Continúa la restauración durante errores de escritura

--write-direct-io

Escribe datos en la partición DESTINO sin caché

--read-direct-io

Lee datos de la partición FUENTE sin caché

-B, --no_block_detail

Muestra el mensaje de progreso sin detalles de bloque

--binary-prefix

Muestra el progreso con tamaño en bits (por defecto es MB, GB...)

--prog-second

Muestra el progreso en segundos (por defecto es minuto)

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA

-T, --btfiles

Restaura el bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura el bloque como archivo para ClonezillaBT pero solo genera el torrent.

-n, --note NOTA

Muestra un Mensaje de Nota (128 palabras).

-h, --help

Muestra el resumen de las opciones.

-v, --version

Muestra la versión

NOMBRE

partclone.ext3 - una utilidad para clonar y restaurar particiones ext3.

SINOPSIS

partclone.ext3 [ -C | -c | -r ] [ -s source ] [ -o output ] [ -d ] [ -R ] [ -P ] [ -N ] [ -v ] [ -b ] [ -i ] [ -p percentage ] [ -a file_to_append ] [ -Z number_of_streams ] [ -? ]

DESCRIPCIÓN

partclone.ext3 es una herramienta para clonar y restaurar particiones ext3.

Esta utilidad puede clonar un sistema de archivos ext3 en un archivo de imagen o en otro dispositivo. También puede restaurar un sistema de archivos ext3 desde un archivo de imagen o desde otro dispositivo. Usa la librería partclone para realizar estas operaciones. La extensión `.ext3` indica que la herramienta está especializada para sistemas de archivos ext3, pero puede funcionar con otros sistemas de archivos ext2/ext3/ext4.

OPCIONES

-c
Clonar la partición de origen en el archivo de salida.
-r
Restaurar la partición desde el archivo de origen al dispositivo de salida.
-s source
Especifica el dispositivo de origen o el archivo de imagen de origen.
-o output
Especifica el dispositivo de salida o el archivo de imagen de salida.
-d
Activa la información de depuración detallada.
-R
Permite la restauración en un dispositivo de origen más pequeño que el tamaño de la imagen (solo si los datos caben).
-P
Permite la restauración en un dispositivo de origen más pequeño que el tamaño de la partición original (si los datos caben).
-N
No pedir confirmación antes de sobrescribir el dispositivo de destino.
-v
Muestra información detallada sobre el progreso.
-b
Realiza una copia de seguridad en modo binario (útil para algunos tipos de archivos).
-i
Ignora la comprobación del sistema de archivos antes de realizar la operación.
-p percentage
Establece el porcentaje de compresión (ej: -p 1 para la compresión máxima).
-a file_to_append
Añade el contenido de este archivo al final del archivo de imagen (útil para imágenes divididas).
-Z number_of_streams
Especifica el número de flujos a utilizar para la clonación/restauración paralela.
-?
Muestra la ayuda y sale.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone

EJEMPLOS

 Clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 Restaurar imagen desde clonezilla (dividida, gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden ser emitidos en stderr:

partclone proporciona algunos códigos de retorno, que pueden ser utilizados en scripts:

Código Diagnóstico
0 El programa salió exitosamente.
1 La clonación o restauración parecen haber fallado.
