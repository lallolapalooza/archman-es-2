PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de los bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se utilizan e2fslibs para leer el bloque utilizado de la partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], de forma muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de archivos                 partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de tu acción. Normalmente, la fuente de copia de seguridad es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos de una tubería (pipe) es compatible SÓLO para la restauración, simplemente ignora la opción -s o usa '-' que significa recibir datos desde stdin.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (partclone generará) o un dispositivo dependiendo de tu acción. Normalmente, la salida de copia de seguridad es un archivo de imagen y la salida de restauración es un dispositivo.

El envío de datos a una tubería también es compatible SÓLO para copias de seguridad, simplemente ignora la opción -o o usa '-' que significa enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe el ARCHIVO, si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo loop.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restore_raw_file

Crea un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Coloca una ruta especial para registrar la información de registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de los errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de verificación crc.

-F, --force

Fuerza el progreso.

-f seg, --UI-fresh seg

Establece un intervalo de segundos diferente para la actualización de la interfaz de usuario.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactiva los mensajes de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápida de calcular, detección básica)

2: xxHash algoritmo hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continúa la restauración durante errores de escritura.

--write-direct-io

Escribe datos en la partición de DESTINO sin caché.

--read-direct-io

Lee datos de la partición de ORIGEN sin caché.

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques.

--binary-prefix

Muestra el progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Muestra el progreso en segundos (por defecto es minutos).

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaura el bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura el bloque como archivo para ClonezillaBT pero solo genera el torrent.

-n, --note NOTA

Muestra un Mensaje de Nota (128 palabras).

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión

partclone.ext2(8) — Partclone documentation

NAME

partclone.ext2

save and restore ext2 filesystem

SYNOPSIS

partclone.ext2 [-c|-r] [-s source] [-o output] [-d] [-N] [-v] [-b] [-Z number] [-F number] [-P number]

DESCRIPTION

Partclone is a tool that allows you to save and restore disk images. It is similar to the well-known tool Clonezilla. Partclone has been developed to save and restore partitions. It has the ability to save and restore partitions in different formats. Partclone is designed to be used with Clonezilla and other similar tools. Partclone works with various file systems and can save and restore them.

Partclone has the ability to save and restore the partition table and the partition contents. It can also save and restore the boot loader. Partclone is a powerful tool that can be used for various purposes, such as system backup, system recovery, and system deployment.

The partclone.ext2 program is specifically designed to save and restore ext2 file systems. It supports various options that allow you to customize the saving and restoring process.

OPTIONS

-c, --clone
Clone the source partition to the output file or device. This option is used to save the partition.
-r, --restore
Restore the source image file or device to the output partition. This option is used to restore the partition.
-s, --source source
Specify the source partition or image file. This can be a device name (e.g., /dev/sda1) or an image file name (e.g., sda1.img).
-o, --output output
Specify the output partition or image file. This can be a device name (e.g., /dev/sda1) or an image file name (e.g., sda1.img).
-d, --debug
Enable debug output. This option is useful for troubleshooting.
-N, --no_part_type
Do not save or restore the partition type. This option is useful when working with partitions that do not have a standard type.
-v, --verbose
Enable verbose output. This option provides more detailed information about the process.
-b, --backup
Backup the partition. This option is similar to -c, but it also creates a backup of the partition table.
-Z, --max_file_size number
Set the maximum size of the output image file. This option is useful when splitting large images into smaller files.
-F, --force_file_system number
Force the file system type. This option is used when partclone cannot detect the file system type automatically.
-P, --part_type number
Set the partition type. This option is used when creating a new partition.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
