NOMBRE

pam_env.conf, entorno - los archivos de configuración de variables de entorno

DESCRIPCIÓN

El archivo /etc/security/pam_env.conf especifica las variables de entorno que serán establecidas, eliminadas o modificadas por pam_env(8). Cuando alguien inicia sesión, este archivo se lee y las variables de entorno se establecen en consecuencia.

Cada línea comienza con el nombre de la variable, luego hay dos opciones posibles para cada variable: DEFAULT y OVERRIDE. DEFAULT permite a un administrador establecer el valor de la variable a algún valor predeterminado, si no se proporciona ninguno, se asume la cadena vacía. La opción OVERRIDE le dice a pam_env que debe ingresar su valor (anulando el valor predeterminado) si hay uno para usar. Cuando OVERRIDE no se usa, se asume "" y no se realizará ninguna anulación.

VARIABLE [DEFAULT=[valor]] [OVERRIDE=[valor]]

Las variables de entorno (posiblemente inexistentes) pueden usarse en los valores usando la sintaxis ${cadena} y los elementos PAM_ITEMs (posiblemente inexistentes) así como HOME y SHELL pueden usarse en los valores usando la sintaxis @{cadena}. Tanto el carácter $ como @ pueden escaparse con barra inversa para ser usados como valores literales. Los valores pueden ser delimitados con ""; las comillas escapadas no son compatibles. Tenga en cuenta que muchas variables de entorno que le gustaría usar pueden no estar establecidas cuando se llama al módulo. Por ejemplo, ${HOME} se usa a continuación varias veces, pero muchas aplicaciones PAM no lo ponen a disposición cuando lo necesita. Las variables especiales @{HOME} y @{SHELL} se expanden a los valores del usuario desde la entrada correspondiente de passwd.

El carácter "#" al inicio de la línea (sin espacio delante) se puede usar para marcar esta línea como una línea de comentario.

El archivo /etc/environment especifica las variables de entorno que serán establecidas. El archivo debe consistir en pares simples NOMBRE=VALOR en líneas separadas. El módulo pam_env(8) leerá el archivo después del archivo pam_env.conf.

EJEMPLOS

Estas son algunas líneas de ejemplo que podrían especificarse en /etc/security/pam_env.conf.

Establecer la variable REMOTEHOST para cualquier host que sea remoto, con un valor predeterminado de "localhost" en lugar de no estar establecida.

      REMOTEHOST     DEFAULT=localhost OVERRIDE=@{PAM_RHOST}

Establecer la variable DISPLAY si parece razonable

      DISPLAY        DEFAULT=${REMOTEHOST}:0.0 OVERRIDE=${DISPLAY}

Ahora algunas variables simples

      PAGER          DEFAULT=less
      MANPAGER       DEFAULT=less
      LESS           DEFAULT="M q e h15 z23 b80"
      NNTPSERVER     DEFAULT=localhost
      PATH           DEFAULT=${HOME}/bin:/usr/local/bin:/bin\
      :/usr/bin:/usr/local/bin/X11:/usr/bin/X11
      XDG_DATA_HOME  DEFAULT=@{HOME}/share/

Ejemplos tontos de variables escapadas, solo para mostrar cómo funcionan.

      DOLLAR         DEFAULT=\$
      DOLLARDOLLAR   DEFAULT=        OVERRIDE=\$${DOLLAR}
      DOLLARPLUS     DEFAULT=\${REMOTEHOST}${REMOTEHOST}
      ATSIGN         DEFAULT=""      OVERRIDE=\@
