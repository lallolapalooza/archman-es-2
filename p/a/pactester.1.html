pactester(1)

Paquete: pacparser

Licencias: LGPL

pactester(1) pactester(1)

NOMBRE

pactester - Herramienta para probar archivos de configuración de proxy automática (pac).

SINOPSIS

pactester <-p archivo.pac> <-u url> [-h host] [-c ip_cliente] [-e]

pactester <-p archivo.pac> <-f lista_urls> [-c ip_cliente] [-e]

DESCRIPCIÓN

pactester es una herramienta para probar archivos de configuración de proxy automática (pac). Devuelve la cadena de configuración del proxy para la URL dada y el archivo pac. pactester utiliza la biblioteca C pacparser para la mayor parte de su funcionalidad.

OPCIONES

-p archivo.pac
Archivo PAC a probar. Especifique "-" para leer de la entrada estándar.
-u url
URL para probar el archivo PAC.
-h host
Parte del host de la URL. Si no se especifica, se determina a partir de la URL.
-c ip_cliente
Dirección IP del cliente (tal como la devuelve la función myIpAddress() en los archivos PAC). Si no se especifica, se utiliza por defecto la dirección IP de la máquina en la que se está ejecutando esta herramienta.
-e
Habilita las extensiones PAC de Microsoft (dnsResolveEx, myIpAddressEx, isResolvableEx).
-f lista_urls
Un archivo que contiene la lista de URLs a probar. Esto es útil para probar un archivo PAC contra un conjunto de URLs.

EJEMPLOS

Para averiguar la cadena de configuración del proxy para el archivo pac "wpad.dat" y la URL "http://www.google.com":

$ pactester -p wpad.dat -u http://www.google.com

Para un cliente con dirección IP 10.0.12.123:

$ pactester -p wpad.dat -c 10.0.12.123 -u http://www.google.com

Para un archivo pac alojado en http://wpad/wpad.dat:

$ curl -s http://wpad/wpad.dat | pactester -p - -u http://google.com

ERRORES

Si ha encontrado un error en pactester, envíe un informe de error en http://github.com/pacparser/pacparser/issues.
