NOMBRE

pam_exec - Módulo PAM que llama a un comando externo

SINOPSIS

pam_exec.so [debug] [expose_authtok] [seteuid] [quiet] [quiet_log] [stdout] [log=archivo] [type=tipo] comando [...]

DESCRIPCIÓN

pam_exec es un módulo PAM que se puede utilizar para ejecutar un comando externo.

El entorno del hijo se establece a la lista de entorno PAM actual, tal como la devuelve pam_getenvlist(3). Además, los siguientes elementos de PAM se exportan como variables de entorno: PAM_RHOST, PAM_RUSER, PAM_SERVICE, PAM_TTY, PAM_USER y PAM_TYPE, que contiene uno de los tipos de módulo: account, auth, password, open_session y close_session.

Los comandos llamados por pam_exec necesitan ser conscientes de que el usuario puede tener control sobre el entorno.

OPCIONES

debug

Imprime información de depuración.

expose_authtok

Durante la autenticación y el cambio de contraseña, el comando llamador puede leer la contraseña de stdin(3). Solo los primeros PAM_MAX_RESP_SIZE bytes de una contraseña se proporcionan al comando.

log=archivo

La salida del comando se adjunta al archivo

type=tipo

Solo ejecuta el comando si el tipo de módulo coincide con el tipo dado.

stdout

Por defecto, la salida del comando ejecutado se escribe en /dev/null. Con esta opción, la salida estándar del comando ejecutado se redirige a la aplicación que llama. Es responsabilidad de esta aplicación lo que sucede con la salida. La opción log se ignora.

quiet

Por defecto, pam_exec.so mostrará el estado de salida del comando externo si falla. Especificar esta opción suprimirá el mensaje.

quiet_log

Por defecto, pam_exec.so registrará el estado de salida del comando externo si falla. Especificar esta opción suprimirá el mensaje de registro.

seteuid

Por defecto, pam_exec.so ejecutará el comando externo con el ID de usuario real del proceso llamador. Especificar esta opción significa que el comando se ejecuta con el ID de usuario efectivo.

TIPOS DE MÓDULO PROPORCIONADOS

Todos los tipos de módulo (auth, account, password y session) se proporcionan.

VALORES DE RETORNO

PAM_SUCCESS

El comando externo se ejecutó correctamente.

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación no pudo obtener el nombre de usuario.

PAM_INCOMPLETE

El método de conversación proporcionado por la aplicación devolvió PAM_CONV_AGAIN.

PAM_SERVICE_ERR

No se proporcionó ningún argumento o se dio un número incorrecto de argumentos.

PAM_SYSTEM_ERR

Ocurrió un error del sistema o el comando a ejecutar falló.

PAM_IGNORE

Se llamó a pam_setcred, que no ejecuta el comando. O bien, el valor proporcionado para el parámetro type= no coincidió con el tipo de módulo.

EJEMPLOS

Agregue la siguiente línea a /etc/pam.d/passwd para reconstruir la base de datos NIS después de cada cambio de contraseña local:

        password optional pam_exec.so seteuid /usr/bin/make -C /var/yp

Esto ejecutará el comando

make -C /var/yp

con el ID de usuario efectivo.

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)
