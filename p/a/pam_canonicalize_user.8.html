NOMBRE

pam_canonicalize_user - Obtener nombre de usuario y canonizarlo

SINOPSIS

pam_canonicalize_user.so

DESCRIPCIÓN

Este módulo PAM utiliza el nombre de usuario obtenido a través de pam_get_user(3) como clave para consultar la base de datos de contraseñas, y reemplaza PAM_USER con el valor pw_name que ha sido devuelto.

OPCIONES

Este módulo no reconoce ninguna opción.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_IGNORE

El nombre de usuario se estableció correctamente.

PAM_USER_UNKNOWN

No se encontró al usuario.

PAM_SYSTEM_ERR

La aplicación no proporcionó ni un nombre de usuario ni un método de conversación.

PAM_INCOMPLETE

El método de conversación proporcionado por la aplicación está esperando un evento.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación no pudo obtener el nombre de usuario.

PAM_ABORT

Error al reanudar una conversación antigua.

PAM_BUF_ERR

Error en el búfer de memoria.

EJEMPLOS

Preceda la pila de autenticación de PAM con la siguiente línea para canonizar el nombre de usuario antes de la autenticación:

        auth required pam_canonicalize_user.so

VER TAMBIÉN

pam_get_user(3), pam_get_item(3), pam_set_item(3), getpwnam(3), pam.conf(5), pam.d(5), pam(8)
