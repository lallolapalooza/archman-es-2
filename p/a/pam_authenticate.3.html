NOMBRE

pam_authenticate - autenticación de cuenta

SINOPSIS

#include <security/pam_appl.h>

int pam_authenticate(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_authenticate se utiliza para autenticar al usuario. Se requiere que el usuario proporcione un token de autenticación dependiendo del servicio de autenticación, normalmente es una contraseña, pero también podría ser una huella dactilar.

El módulo de servicio PAM puede solicitar que el usuario introduzca su nombre de usuario a través del mecanismo de conversación (ver pam_start(3) y pam_conv(3)). El nombre del usuario autenticado estará presente en el ítem PAM PAM_USER. Este ítem puede recuperarse con una llamada a pam_get_item(3).

El argumento pamh es un manejador de autenticación obtenido por una llamada previa a pam_start(). El argumento flags es el OR binario de cero o más de los siguientes valores:

PAM_SILENT

No emitir ningún mensaje.

PAM_DISALLOW_NULL_AUTHTOK

El servicio del módulo PAM debe devolver PAM_AUTH_ERR si el usuario no tiene un token de autenticación registrado.

VALORES DE RETORNO

PAM_ABORT

La aplicación debe salir inmediatamente después de llamar a pam_end(3) primero.

PAM_AUTH_ERR

El usuario no fue autenticado.

PAM_CRED_INSUFFICIENT

Por alguna razón, la aplicación no tiene credenciales suficientes para autenticar al usuario.

PAM_AUTHINFO_UNAVAIL

Los módulos no pudieron acceder a la información de autenticación. Esto podría deberse a un fallo de red o de hardware, etc.

PAM_MAXTRIES

Uno o más de los módulos de autenticación han alcanzado su límite de intentos de autenticar al usuario. No intente de nuevo.

PAM_SUCCESS

El usuario fue autenticado con éxito.

PAM_USER_UNKNOWN

Usuario desconocido para el servicio de autenticación.

VER TAMBIÉN

pam_start(3), pam_setcred(3), pam_chauthtok(3), pam_strerror(3), pam(8)
