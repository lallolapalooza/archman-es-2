NOMBRE

pam_acct_mgmt - gestión de validación de cuenta PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_acct_mgmt(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_acct_mgmt se utiliza para determinar si la cuenta del usuario es válida. Comprueba la expiración del token de autenticación y de la cuenta, y verifica las restricciones de acceso. Típicamente se llama después de que el usuario ha sido autenticado.

El argumento pamh es un manejador de autenticación obtenido por una llamada previa a pam_start(). Los indicadores (flags) son el resultado de un OR binario de cero o más de los siguientes valores:

PAM_SILENT

No emitir ningún mensaje.

PAM_DISALLOW_NULL_AUTHTOK

El servicio del módulo PAM debe devolver PAM_NEW_AUTHTOK_REQD si el usuario tiene un token de autenticación nulo.

VALORES DE RETORNO

PAM_ACCT_EXPIRED

La cuenta del usuario ha expirado.

PAM_AUTH_ERR

Fallo de autenticación.

PAM_NEW_AUTHTOK_REQD

La cuenta del usuario es válida pero su token de autenticación está expirado. La respuesta correcta a este valor de retorno es requerir que el usuario cumpla con la función pam_chauthtok() antes de obtener el servicio. Puede que no sea posible para algunas aplicaciones hacer esto. En tales casos, se debe denegar el acceso al usuario hasta que pueda actualizar su contraseña.

PAM_PERM_DENIED

Permiso denegado.

PAM_SUCCESS

El token de autenticación se actualizó con éxito.

PAM_USER_UNKNOWN

Usuario desconocido para el servicio de contraseñas.

VER TAMBIÉN

pam_start(3), pam_authenticate(3), pam_chauthtok(3), pam_strerror(3), pam(8)
