NOMBRE

pacsync - actualizar bases de datos de sincronización

SINOPSIS

pacsync [opciones] [<syncdb>]...
pacsync (--help|--version)

DESCRIPCIÓN

Actualiza las bases de datos de sincronización. Si no se proporcionan nombres de syncdb, se actualizarán todas las bases de datos.

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbext=extensión
Establece una extensión alternativa para la base de datos de sincronización.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--logfile=ruta
Establece una ruta alternativa para el archivo de registro.
--no-timeout
Desactiva los tiempos de espera de baja velocidad para las descargas.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--debug
Muestra información de depuración adicional.
--updated
Devuelve verdadero solo si una base de datos fue realmente actualizada.
--force
Actualiza las bases de datos incluso si ya están al día.
--help
Muestra información de uso y sale.
--version
Muestra información de la versión y sale.
