PAM_PUTENV(3) Manual de Linux-PAM PAM_PUTENV(3)

NOMBRE

pam_putenv - establecer o cambiar una variable de entorno PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_putenv(pam_handle_t *pamh, const char *name_value);

DESCRIPCIÓN

La función pam_putenv se utiliza para añadir o cambiar el valor de las variables de entorno de PAM asociadas con el manejador pamh.

El argumento pamh es un manejador de autenticación obtenido mediante una llamada previa a pam_start(). El argumento name_value es una única cadena terminada en NULO de una de las siguientes formas:

NOMBRE=valor de la variable

En este caso, la variable de entorno del NOMBRE dado se establece al valor indicado: valor de la variable. Si esta variable ya es conocida, se sobrescribe. De lo contrario, se añade al entorno de PAM.

NOMBRE=

Esta función establece la variable a un valor vacío. Se enumera por separado para indicar que esta es la forma correcta de lograr dicha configuración.

NOMBRE

Sin un '=', la función pam_putenv() eliminará la variable correspondiente del entorno de PAM.

pam_putenv() opera sobre una copia de name_value, lo que significa que, a diferencia de putenv(3), la aplicación es responsable de liberar los datos.

VALORES DE RETORNO

PAM_PERM_DENIED

El argumento name_value proporcionado es un puntero NULL.

PAM_BAD_ITEM

La variable solicitada (para eliminación) no está actualmente establecida.

PAM_ABORT

El manejador pamh está corrupto.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_SUCCESS

La variable de entorno se actualizó correctamente.

VER TAMBIÉN
