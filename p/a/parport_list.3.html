PARPORT_LIST(3) Estructuras PARPORT_LIST(3)

NOMBRE

parport_list - una colección de puertos paralelos

SINOPSIS

#include <ieee1284.h>

DESCRIPCIÓN

Una estructura parport_list es simplemente un vector de estructuras parport.

MIEMBROS DE LA ESTRUCTURA

La estructura tiene los siguientes miembros:

struct parport_list {
  /* Número de elementos en el vector. */
  int portc;
  /* Los puertos. */
  struct parport **portv;
};
