NOMBRE

pam_shells - Módulo PAM para comprobar si la shell de inicio de sesión es válida

SINOPSIS

pam_shells.so

DESCRIPCIÓN

pam_shells es un módulo PAM que solo permite el acceso al sistema si la shell del usuario está listada en /etc/shells.

También comprueba si los archivos necesarios (p.ej., /etc/shells) son archivos planos y no son escribibles por todos.

OPCIONES

Este módulo no reconoce ninguna opción.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo auth y account.

VALORES DE RETORNO

PAM_AUTH_ERR

Se denegó el acceso al sistema.

PAM_SUCCESS

La shell de inicio de sesión del usuario estaba listada como una shell válida en /etc/shells.

PAM_USER_UNKNOWN

El usuario no existe o no se pudo determinar la shell de inicio de sesión del usuario.

PAM_SERVICE_ERR

El módulo no pudo obtener el nombre del usuario.

EJEMPLOS

auth  required  pam_shells.so

VER TAMBIÉN

shells(5), pam.conf(5), pam.d(5), pam(8)
