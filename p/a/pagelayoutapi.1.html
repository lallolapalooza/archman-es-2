PAGELAYOUTAPI(1) PAGELAYOUTAPI(1)

NOMBRE

pagelayoutapi - API para la clase LaTeX pagelayout

SINOPSIS

pagelayoutapi getwidth % ARCHIVO

pagelayoutapi getheight % ARCHIVO

pagelayoutapi optimize % ARCHIVO % NOMBRE_ARCHIVO % EXTENSION % ANCHO_ORIGINAL % ALTO_ORIGINAL % RECORTAR_IZQ % RECORTAR_DER % RECORTAR_SUP % RECORTAR_INF % DENSIDAD % ANCHO % ALTO % UMBRAL_REDUCCION % ENFOQUE % CALIDAD

pagelayoutapi makeshadow % NOMBRE_ARCHIVO % DESVIACION_ESTANDAR % OPACIDAD % COLOR % ANCHO % ALTO % ANCHO_MARCO % ALTO_MARCO % MARGEN % RADIO_BORDE

pagelayoutapi start [% import % [RUTA_GRAFICOS]] [% turbo % NOMBRE_TRABAJO]

pagelayoutapi batchoptimize % LISTA_PROCESO_LOTE

DESCRIPCIÓN

Este script proporciona una API para la clase LaTeX pagelayout.

pagelayoutapi getwidth
Devuelve el ancho en píxeles para el archivo de imagen dado.
pagelayoutapi getheight
Devuelve el alto en píxeles para el archivo de imagen dado.
pagelayoutapi optimize
Crea una imagen recortada, redimensionada, enfocada y comprimida y la almacena en el directorio de caché.
pagelayoutapi makeshadow
Crea una imagen de sombra y la almacena en el directorio de caché.
pagelayoutapi start
El parámetro import activa la importación de imágenes (ver el capítulo "Optimización de imágenes" del manual de pagelayout). Ejecutar el comando con el parámetro turbo, donde el nombre del trabajo es el nombre del archivo del documento, procesa el documento en un modo de lote especial, que crea una lista de lotes y llama al comando pagelayoutapi batchoptimize.
pagelayoutapi batchoptimize
Optimiza múltiples imágenes en paralelo.

OPCIONES

--help
Imprime un mensaje de ayuda.
--version
Imprime información de la versión.

PARÁMETROS

ARCHIVO
nombre del archivo con extensión (ej. IMG1234.JPEG)
NOMBRE_ARCHIVO
nombre del archivo sin extensión (ej. IMG1234)
EXTENSION
extensión del archivo optimizado (.jpg|.png)
DENSIDAD
densidad en ppi (ej. 72)
UMBRAL_REDUCCION
umbral de reducción (entero >= 100)
ENFOQUE
filtro de enfoque (ej. 2x1)
CALIDAD
calidad (entero > 0, <= 100)
DESVIACION_ESTANDAR
desviación estándar (decimal > 0.0)
OPACIDAD
opacidad (decimal >= 0.0, <= 1.0)
COLOR
cadena de color (ej. rosa)
RUTA_GRAFICOS
lista de directorios (ej. {images/}{tmp/})
NOMBRE_TRABAJO
nombre del archivo LaTeX sin extensión (ej. mi-documento)
LISTA_PROCESO_LOTE
una lista plana de elementos de lote donde cada elemento de lote es una lista plana de los 15 parámetros requeridos por el comando `pagelayoutapi optimize`

Todos los demás parámetros son dimensiones de longitud. El comando pagelayoutapi optimize espera valores enteros en la unidad LaTeX sp (ej. 65536). El comando pagelayoutapi makeshadow espera valores decimales en una unidad compatible con SVG (ej. 420.0pt).

ENTORNO

pagelayoutapi requiere ImageMagick 7.0 o posterior y Inkscape 1.0 o posterior.

PAGELAYOUT_IMPORT_DIRECTORY
Define un directorio de importación a nivel de sistema.
