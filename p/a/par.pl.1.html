PAR(1) Documentación de Perl contribuida por el usuario PAR(1)

NOMBRE

par.pl - Crea y ejecuta Archivos Perl

SINOPSIS

(Por favor, consulta pp para formas convenientes de crear ejecutables, scripts o archivos PAR autocontenidos a partir de programas Perl.)

Para crear una distribución PAR a partir de una distribución de módulo CPAN:

% par.pl -p                 # crea una distribución PAR bajo la ruta actual
% par.pl -p Foo-0.01        # asume una distribución CPAN descomprimida en Foo-0.01/

Para manipular una distribución PAR:

% par.pl -i Foo-0.01-i386-freebsd-5.8.0.par # instalar
% par.pl -i http://foo.com/Foo-0.01         # añade automáticamente el nombre de la arquitectura y la versión de Perl
% par.pl -i cpan://AUTRIJUS/PAR-0.74        # utiliza el directorio del autor de CPAN
% par.pl -u Foo-0.01-i386-freebsd-5.8.0.par # desinstalar
% par.pl -s Foo-0.01-i386-freebsd-5.8.0.par # firmar
% par.pl -v Foo-0.01-i386-freebsd-5.8.0.par # verificar

Para usar Hello.pm desde ./foo.par:

% par.pl -A./foo.par -MHello
% par.pl -A./foo -MHello    # la parte .par es opcional

Lo mismo, pero busca foo.par en @INC;

% par.pl -Ifoo.par -MHello
% par.pl -Ifoo -MHello      # lo mismo

Ejecuta test.pl o script/test.pl desde foo.par:

% par.pl foo.par test.pl    # busca 'main.pl' por defecto,
                            # de lo contrario ejecuta 'test.pl'

Para crear un script autocontenido que contenga un archivo PAR:

% par.pl -O./foo.pl foo.par
% ./foo.pl test.pl          # lo mismo que arriba

Para incrustar los módulos y objetos compartidos no principales necesarios para la ejecución de PAR (como "Zlib", "IO", "Cwd", etc.), usa la opción -b:

% par.pl -b -O./foo.pl foo.par
% ./foo.pl test.pl          # se ejecuta en cualquier lugar con los módulos principales instalados

Si también deseas incrustar módulos principales, usa la opción -B en su lugar:

% par.pl -B -O./foo.pl foo.par
% ./foo.pl test.pl          # se ejecuta en cualquier lugar con el intérprete de Perl

Esto es particularmente útil al crear ejecutables binarios autocontenidos; consulta pp para más detalles.

DESCRIPCIÓN

Este comando autocontenido ofrece aproximadamente la misma funcionalidad que "perl -MPAR", excepto que toma los archivos .par precargados a través de "-Afoo.par" en lugar de "-MPAR=foo.par".

Además, te permite convertir una distribución CPAN en una distribución PAR, así como manipular dichas distribuciones. Para más información sobre distribuciones PAR, consulta PAR::Dist.

Cargador PAR binario (parl)

Si tienes un compilador C, o un paquete binario precompilado de PAR está disponible para tu plataforma, una versión binaria de par.pl también se instalará automáticamente como parl. Puedes usarlo para ejecutar archivos .par:

# ejecuta script/run.pl en el archivo, usa sus lib/* como bibliotecas
% parl myapp.par run.pl     # ejecuta run.pl o script/run.pl en myapp.par
% parl otherapp.pl          # también ejecuta scripts normales de Perl

Sin embargo, si el archivo .par contiene main.pl o script/main.pl, se usa en su lugar:

% parl myapp.par run.pl     # ejecuta main.pl, con 'run.pl' como @ARGV

Finalmente, la opción "-O" crea un ejecutable binario autocontenido a partir de un archivo PAR:

% parl -B -Omyapp myapp.par
% ./myapp                   # ejecútalo en cualquier lugar sin binarios de Perl

Con la opción "--par-options", los binarios generados pueden actuar como "parl" para empaquetar nuevos binarios:

% ./myapp --par-options -Omyap2 myapp.par   # idéntico a ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # ahora con un PAR diferente

Formato de ejecutable autocontenido

El formato para el ejecutable autocontenido es simplemente la concatenación de los siguientes elementos:

  • El ejecutable en sí

    Ya sea en formato de texto plano (par.pl) o formato de ejecutable nativo (parl o parl.exe).

  • Cualquier número de archivos incrustados

    Estos se usan típicamente para arrancar varias dependencias XS de PAR. Cada sección contiene:

La cadena mágica ""FILE""
Longitud del nombre del archivo en formato pack('N') más 9
8 bytes de CRC32 codificado en hexadecimal del contenido del archivo
Una barra simple (""/"")
El nombre del archivo (sin ruta)
Longitud del archivo en formato pack('N')
El contenido del archivo (sin comprimir)
  • Un archivo PAR

    Este es solo un archivo zip que comienza con la cadena mágica ""PK\003\004"".

  • Sección final

    El nombre de caché precalculado. Una cadena pack('Z40') del valor de -T (--tempcache) o el hash del archivo, seguido de "\0CACHE". El hash del archivo se calcula con Digest::SHA.

    Un número pack('N') de la longitud total de las secciones FILE y PAR, seguido de una cadena mágica de 8 bytes: ""\012PAR.pm\012"".
