NOMBRE

pam_setcred - establecer / eliminar credenciales de usuario

SINOPSIS

#include <security/pam_appl.h>

int pam_setcred(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_setcred se utiliza para establecer, mantener y eliminar las credenciales de un usuario. Debe llamarse para establecer las credenciales después de que un usuario haya sido autenticado y antes de que se abra una sesión para el usuario (con pam_open_session(3)). Las credenciales deben eliminarse después de que se haya cerrado la sesión (con pam_close_session(3)).

Una credencial es algo que posee el usuario. Es una propiedad, como un ticket de Kerberos, o una membresía de grupo suplementaria que compone la singularidad de un usuario determinado. En un sistema Linux, el UID y los GID del usuario también son credenciales. Sin embargo, se ha decidido que estas propiedades (junto con los grupos suplementarios por defecto de los que el usuario es miembro) son credenciales que deben ser establecidas directamente por la aplicación y no por PAM. Dichas credenciales deben ser establecidas, por la aplicación, antes de una llamada a esta función. Por ejemplo, initgroups(2) (o su equivalente) debería haberse realizado.

Las flags válidas, cualquiera de las cuales puede combinarse lógicamente con PAM_SILENT, son:

PAM_ESTABLISH_CRED

Inicializa las credenciales para el usuario.

PAM_DELETE_CRED

Elimina las credenciales del usuario.

PAM_REINITIALIZE_CRED

Re-inicializa completamente las credenciales del usuario.

PAM_REFRESH_CRED

Extiende la vida útil de las credenciales existentes.

VALORES DE RETORNO

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_CRED_ERR

Error al establecer las credenciales del usuario.

PAM_CRED_EXPIRED

Las credenciales del usuario han expirado.

PAM_CRED_UNAVAIL

Error al recuperar las credenciales del usuario.

PAM_SUCCESS

Los datos se almacenaron correctamente.

PAM_SYSTEM_ERR

Se envió un puntero NULL como manejador de PAM, la función fue llamada por un módulo o ocurrió otro error del sistema.

PAM_USER_UNKNOWN

El usuario no es conocido por un módulo de autenticación.

VER TAMBIÉN
