NOMBRE

pacreport - muestra un resumen de los paquetes instalados

SINOPSIS

pacreport [opciones]
pacreport (--ayuda|--version)

DESCRIPCIÓN

Genera un informe de los paquetes instalados que incluye:

paquetes innecesarios instalados explícitamente
paquetes innecesarios instalados como dependencias
paquetes innecesarios en un ciclo de dependencias
paquetes instalados que no están en un repositorio
paquetes que faltan en grupos especificados
archivos de paquete faltantes
archivos de copia de seguridad no fusionados
archivos sin propietario
tamaños del directorio de caché

Los tamaños de los paquetes incluyen las dependencias que no son necesarias para otros paquetes.

Los paquetes precedidos por un asterisco ("*") son dependencias opcionales para otro paquete.

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración de pacman.
--dbext=extensión
Establece una extensión alternativa para la base de datos de sincronización.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--cachedir=ruta
Establece una ruta alternativa para el directorio de caché.
--backups
Busca archivos .pac{save,orig,new}. Por defecto se busca en /etc y se comprueban todos los archivos de configuración conocidos; pasa dos veces para buscar fuera de /etc.
--group=nombre
Muestra cualquier paquete del grupo nombre que no esté instalado actualmente. Se puede especificar varias veces.
--missing-files
Comprueba si faltan archivos de paquete.
--unowned-files
Comprueba si hay archivos sin propietario. Ver /etc/pacreport.conf en ARCHIVOS para más información.
--optional-for
Muestra qué paquetes dependen opcionalmente de los paquetes listados.
--optional-deps
Tiene en cuenta las dependencias opcionales al listar paquetes innecesarios y bucles de dependencias.
--help
Muestra la información de uso y sale.
--version
Muestra la información de la versión y sale.

ARCHIVOS

/etc/pacreport.conf
Archivo de configuración estilo INI que lista las rutas a ignorar al ejecutar con --unowned-files. Las rutas que siempre deben ignorarse pueden especificarse con "IgnoreUnowned" en la sección "Options". Las rutas que solo deben ignorarse si un paquete en particular está instalado pueden listarse bajo la sección "PkgIgnoreUnowned" usando el nombre del paquete como nombre de la opción y la ruta a ignorar como valor. Todas las opciones se pueden especificar varias veces. Las rutas pueden incluir comodines estilo shell. La raíz de instalación no debe incluirse en las rutas. 
[Options]
IgnoreUnowned = home/*
IgnoreUnowned = proc/*
IgnoreUnowned = mnt/*
[PkgIgnoreUnowned]
linux = boot/initramfs-linux.img
linux = boot/initramfs-linux-fallback.img
