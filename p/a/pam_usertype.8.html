NOMBRE

pam_usertype - comprueba si el usuario autenticado es una cuenta del sistema o una cuenta normal

SINOPSIS

pam_usertype.so [bandera...] {condición}

DESCRIPCIÓN

pam_usertype.so está diseñado para tener éxito o fallar la autenticación basándose en el tipo de cuenta del usuario autenticado. El tipo de cuenta se decide con la ayuda de la configuración de SYS_UID_MAX en /etc/login.defs. Un uso es seleccionar si cargar otros módulos basándose en esta prueba.

Al módulo solo se le debe dar una condición como argumento del módulo. La autenticación solo tendrá éxito si se cumple la condición.

OPCIONES

Se admiten las siguientes banderas:

use_uid

Evalúa las condiciones usando la cuenta del usuario cuya UID está ejecutando la aplicación en lugar del usuario que se está autenticando.

audit

Registra usuarios desconocidos en el registro del sistema.

Las condiciones disponibles son:

issystem

Éxito si el usuario es un usuario del sistema.

isregular

Éxito si el usuario es un usuario normal.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulos (account, auth, password y session).

VALORES DE RETORNO

PAM_SUCCESS

La condición fue verdadera.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación no pudo obtener el nombre de usuario.

PAM_INCOMPLETE

El método de conversación proporcionado por la aplicación devolvió PAM_CONV_AGAIN.

PAM_AUTH_ERR

La condición fue falsa.

PAM_SERVICE_ERR

Se produjo un error de servicio o los argumentos no se pudieron analizar correctamente.

PAM_USER_UNKNOWN

El usuario no fue encontrado.

EJEMPLOS

Omitir los módulos restantes si el usuario es un usuario del sistema:

account sufficient pam_usertype.so issystem

VER TAMBIÉN

login.defs(5), pam(8)
