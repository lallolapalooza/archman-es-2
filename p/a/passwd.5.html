PASSWD(5) Formatos de Archivo y Configuración PASSWD(5)

NOMBRE

passwd - el archivo de contraseñas

DESCRIPCIÓN

/etc/passwd contiene una línea por cada cuenta de usuario, con siete campos delimitados por dos puntos (“:”). Estos campos son:

•nombre de inicio de sesión
•contraseña cifrada opcional
•ID de usuario numérico
•ID de grupo numérico
•nombre de usuario o campo de comentarios
•directorio personal del usuario
•intérprete de comandos opcional del usuario

Si el campo de la contraseña es una “x” minúscula, entonces la contraseña cifrada se almacena en el archivo shadow(5) en su lugar; debe haber una línea correspondiente en el archivo /etc/shadow, o de lo contrario la cuenta de usuario no será válida.

El campo de la contraseña cifrada puede estar vacío, en cuyo caso no se requiere ninguna contraseña para autenticarse con el nombre de inicio de sesión especificado. Sin embargo, algunas aplicaciones que leen el archivo /etc/passwd pueden decidir no permitir ningún acceso en absoluto si el campo de la contraseña está en blanco.

Un campo de contraseña que comience con un signo de exclamación significa que la contraseña está bloqueada. Los caracteres restantes en la línea representan el campo de la contraseña antes de que la contraseña fuera bloqueada.

Consulte crypt(3) para obtener detalles sobre cómo se interpreta esta cadena.

Si el campo de contraseña contiene alguna cadena que no sea un resultado válido de crypt(3), por ejemplo ! o *, el usuario no podrá utilizar una contraseña de Unix para iniciar sesión (pero el usuario podrá iniciar sesión en el sistema por otros medios).

El campo de comentarios, también conocido como campo gecos, es utilizado por varias utilidades del sistema, como finger(1). El uso de un ampersand aquí será reemplazado por el nombre de inicio de sesión en mayúsculas cuando el campo sea utilizado o mostrado por dichas utilidades del sistema.

El campo del directorio personal proporciona el nombre del directorio de trabajo inicial. El programa login utiliza esta información para establecer el valor de la variable ambiental $HOME.

El campo del intérprete de comandos proporciona el nombre del intérprete de lenguaje de comandos del usuario, o el nombre del programa inicial a ejecutar. El programa login utiliza esta información para establecer el valor de la variable ambiental $SHELL. Si este campo está vacío, se utiliza por defecto /bin/sh.

ARCHIVOS

/etc/passwd

Información de cuentas de usuario.

/etc/shadow

archivo opcional de contraseñas cifradas

/etc/passwd-

Archivo de respaldo para /etc/passwd.

Tenga en cuenta que este archivo es utilizado por las herramientas del conjunto de herramientas shadow, pero no por todas las herramientas de gestión de usuarios y contraseñas.

VER TAMBIÉN
