NOMBRE

passt-repair - Ayudante para configurar opciones de socket TCP_REPAIR para passt(1)

SINOPSIS

passt-repair RUTA

DESCRIPCIÓN

passt-repair es un ayudante privilegiado que configura y desactiva el modo de reparación en sockets TCP en nombre de passt(1), según lo instruido a través de comandos de un solo byte por un socket de dominio UNIX.

Puede ser utilizado para migrar conexiones TCP entre invitados sin otorgar capacidades adicionales a passt(1): para migrar conexiones TCP, passt(1) utiliza el modo de reparación, que necesita la capacidad CAP_NET_ADMIN (ver capabilities(7)) para ser configurada o desconfigurada.

Si RUTA representa un socket de dominio UNIX, passt-repair(1) intenta conectarse a él. Si es un directorio, passt-repair(1) espera hasta que aparezca un archivo que termine en .repair en él, y luego intenta conectarse a él.

PROTOCOLO

passt-repair(1) se conecta a passt(1) usando el socket especificado a través de la opción --repair-path en passt(1). Por defecto, el nombre es el mismo que el socket de dominio UNIX utilizado para la comunicación con el invitado, con el sufijo .repair.

Los mensajes consisten en un entero con signo de 8 bits que puede ser TCP_REPAIR_ON (1), TCP_REPAIR_OFF (0), o TCP_REPAIR_OFF_NO_WP (-1), tal como se define en la API de usuario del kernel de Linux, y de uno a SCM_MAX_FD (253) sockets como mensaje auxiliar SCM_RIGHTS (ver unix(7)), enviado por el servidor, passt(1).

El cliente, passt-repair(1), responde con el mismo byte (y sin mensaje auxiliar) para indicar éxito, y cierra la conexión en caso de fallo.

El servidor cierra la conexión en caso de error o finalización.

NOTAS

passt-repair(1) puede tener concedida la capacidad CAP_NET_ADMIN (preferido, ya que limita los privilegios a los estrictamente necesarios), o puede ejecutarse como root.
