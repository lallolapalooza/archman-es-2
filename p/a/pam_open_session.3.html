NOMBRE

pam_open_session - iniciar la gestión de sesiones PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_open_session(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_open_session prepara una sesión de usuario para un usuario que ha tenido una autenticación exitosa previamente. La sesión debe ser terminada posteriormente con una llamada a pam_close_session(3).

Cabe señalar que el UID efectivo, geteuid(2), de la aplicación debe tener privilegios suficientes para realizar tareas como crear o montar el directorio personal del usuario, por ejemplo.

El argumento flags es el OR binario de cero o más de los siguientes valores:

PAM_SILENT

No emitir ningún mensaje.

VALORES DE RETORNO

PAM_ABORT

Fallo general.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_SESSION_ERR

Fallo de sesión.

PAM_SUCCESS

La sesión se creó con éxito.

VER TAMBIÉN

pam_close_session(3), pam_strerror(3)
