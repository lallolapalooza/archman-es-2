NOMBRE

pam_wheel - Solo permite el acceso root a los miembros del grupo wheel

SINOPSIS

pam_wheel.so [debug] [deny] [group=nombre] [root_only] [trust] [use_uid]

DESCRIPCIÓN

El módulo PAM pam_wheel se utiliza para aplicar el llamado grupo wheel. Por defecto, permite el acceso al usuario destino si el usuario solicitante es miembro del grupo wheel. Si no existe ningún grupo con este nombre, el módulo utiliza el grupo con el ID de grupo 0.

OPCIONES

debug

Imprime información de depuración.

deny

Invierte el sentido de la operación de autenticación: si el usuario está intentando obtener acceso UID 0 y es miembro del grupo wheel (o del grupo especificado en la opción group), deniega el acceso. Por el contrario, si el usuario no está en el grupo, devuelve PAM_IGNORE (a menos que también se haya especificado trust, en cuyo caso devuelve PAM_SUCCESS).

group=nombre

En lugar de comprobar los grupos wheel o GID 0, utiliza el grupo nombre para realizar la autenticación.

root_only

La comprobación de la membresía en el grupo wheel se realiza solo cuando el UID del usuario destino es 0.

trust

El módulo pam_wheel devolverá PAM_SUCCESS en lugar de PAM_IGNORE si el usuario es miembro del grupo wheel (por lo tanto, con un poco de juego al apilar los módulos, los miembros del grupo wheel pueden convertirse en root sin que se les pida una contraseña).

use_uid

La comprobación se realizará contra el uid real del proceso llamante, en lugar de intentar obtener el usuario de la sesión de inicio de sesión asociada a la terminal en uso.

TIPOS DE MÓDULOS PROPORCIONADOS

Se proporcionan los tipos de módulos auth y account.

VALORES DE RETORNO

PAM_AUTH_ERR

Fallo de autenticación.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_IGNORE

El valor de retorno debe ser ignorado por el dispatch de PAM.

PAM_PERM_DENY

Permiso denegado.

PAM_SERVICE_ERR

No se puede determinar el nombre de usuario.

PAM_SUCCESS

Éxito.

PAM_USER_UNKNOWN

Usuario desconocido.

EJEMPLOS

La cuenta root obtiene acceso por defecto (rootok), solo los miembros del grupo wheel pueden convertirse en root (wheel) pero Unix autentica a los solicitantes que no son root.

su      auth     sufficient     pam_rootok.so
su      auth     required       pam_wheel.so
su      auth     required       pam_unix.so
