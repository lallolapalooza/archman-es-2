NOMBRE

pam_time - Módulo PAM para control de tiempo de acceso

SINOPSIS

pam_time.so [conffile=archivo-conf] [debug] [noaudit]

DESCRIPCIÓN

El módulo PAM pam_time no autentica al usuario, sino que restringe el acceso a un sistema y/o aplicaciones específicas en varios momentos del día y en días específicos o a través de varias líneas de terminal. Este módulo puede configurarse para denegar el acceso a usuarios (individuales) basándose en su nombre, la hora del día, el día de la semana, el servicio al que están aplicando y su terminal desde el que realizan su solicitud.

Por defecto, las reglas de acceso por tiempo/puerto se toman del archivo de configuración /etc/security/time.conf. Se puede especificar un archivo alternativo con la opción conffile.

Si Linux PAM está compilado con soporte de auditoría, el módulo informará cuando deniegue el acceso.

OPCIONES

conffile=/ruta/a/time.conf

Indica un archivo de configuración alternativo estilo time.conf para anular el predeterminado.

debug

Se imprime información de depuración con syslog(3).

noaudit

No informar los inicios de sesión en horarios no permitidos al subsistema de auditoría.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo account.

VALORES DE RETORNO

PAM_SUCCESS

Se concedió el acceso.

PAM_ABORT

No se pudieron obtener todos los datos relevantes.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_PERM_DENIED

No se concedió el acceso.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

ARCHIVOS

/etc/security/time.conf

Archivo de configuración predeterminado

EJEMPLOS

#%PAM-1.0
#
# aplica contabilidad pam_time a las solicitudes de inicio de sesión
#
login  account  required  pam_time.so

VER TAMBIÉN

time.conf(5), pam.d(5), pam(8).
