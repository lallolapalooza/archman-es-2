LIBPACK(3) Manual de funciones de biblioteca LIBPACK(3)

NOMBRE

libpack - soporte para componentes conectados

SINOPSIS

#include <graphviz/pack.h>
typedef enum { l_clust, l_node, l_graph, l_array} pack_mode;
typedef struct {
	float aspect;		 /* relación de aspecto deseada */
	int sz;			     /* tamaño de fila/columna */
	unsigned int margin; /* margen izquierdo alrededor de los objetos, en puntos */
	int doSplines;		 /* usar splines en la construcción de la forma del grafo */
	pack_mode mode;		 /* granularidad y método */
	boolean *fixed;		 /* fixed[i] == true implica que g[i] no debe moverse */
	packval_t* vals;	 /* para matrices, números de ordenación */
	int flags;       
} pack_info;
point*     putRects(int ng, boxf* bbs, pack_info* pinfo);
int        packRects(int ng, boxf* bbs, pack_info* pinfo);
point*     putGraphs (int, Agraph_t**, Agraph_t*, pack_info*);
int        packGraphs (int, Agraph_t**, Agraph_t*, pack_info*);
int        packSubgraphs (int, Agraph_t**, Agraph_t*, pack_info*);
pack_mode  getPackMode (Agraph_t*, pack_mode dflt);
int        getPack (Agraph_t*, int, int);
int        isConnected (Agraph_t*);
Agraph_t** ccomps (Agraph_t*, int*, char*);
Agraph_t** pccomps (Agraph_t*, int*, char*, boolean*);
int        nodeInduce (Agraph_t*);

DESCRIPCIÓN

libpack soporta el uso de componentes conectados en el contexto del diseño de grafos utilizando otras bibliotecas de graphviz. Un conjunto de funciones puede usarse para tomar un único grafo y dividirlo en componentes conectados. Un conjunto complementario de funciones toma una colección de grafos (no necesariamente componentes de un solo grafo) que han sido diseñados por separado, y los empaqueta juntos.

Dado que esta biblioteca está pensada para usarse con libcommon, depende de Agraphinfo_t, Agnodeinfo_t y Agedgeinfo_t utilizados en esa biblioteca. Las dependencias específicas se detallan a continuación en las descripciones de las funciones.

Creación de componentes

Agraph_t** ccomps (Agraph_t* g, int* cnt, char* pfx)

La función ccomps toma un grafo g y devuelve una matriz de punteros a subgrafos de g que son sus componentes conectados. cnt se establece al número de componentes. Si pfx no es NULL, se utiliza como prefijo para los nombres de los subgrafos; de lo contrario, se utiliza la cadena ``_cc_''. Tenga en cuenta que los subgrafos solo contienen los nodos relevantes, no las aristas correspondientes. Dependiendo del uso, esto permite al llamante recuperar la información de las aristas del grafo raíz.

La matriz devuelta se obtiene mediante malloc y debe ser liberada por el llamante. La función depende del campo mark en Agnodeinfo_t.

Agraph_t** pccomps (Agraph_t* g, int* cnt, char* pfx, boolean* pinned)

Esto es idéntico a ccomps excepto que coloca todos los nodos fijos en el primer componente devuelto. Además, si pinned no es NULL, se establece en verdadero si se encuentran nodos fijos y falso en caso contrario.

int nodeInduce (Agraph_t* g)

Esta función toma un subgrafo g y encuentra todas las aristas en su grafo raíz cuyos dos puntos finales están en g. Devuelve el número de dichas aristas y, si esta arista aún no está en el subgrafo, se añade.

int isConnected (Agraph_t* g)

Esta función devuelve un valor distinto de cero si el grafo g está conectado.

Empaquetado de componentes

point* putGraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info ip)

putGraphs empaqueta una colección de grafos diseñados en un único diseño que evita cualquier superposición. Toma como entrada ng grafos gs. Para cada grafo, se asume que todos los nodos han sido posicionados usando pos, y que los campos xsize e ysize han sido establecidos.

Si root no es NULL, se toma como el grafo raíz de los subgrafos gs y se utiliza para encontrar las aristas. De lo contrario, putGraphs utiliza las aristas encontradas en cada grafo gs[i].

Para los modos l_node, l_clust y l_graph, el empaquetado se realiza utilizando el algoritmo basado en poliminoes de Freivalds et al. Esto permite un empaquetado bastante ajustado, en el que una parte convexa de un grafo podría insertarse en la parte cóncava de otro. La granularidad de los poliminoes utilizados depende del valor de ip->mode. Si es l_node, se construye un polimino para aproximar los nodos y las aristas. Si es l_clust, el polimino trata los clústeres de nivel superior como rectángulos individuales, unidos a los poliminoes para los nodos y aristas restantes. Si el valor es l_graph, el polimino para un grafo es un único rectángulo que corresponde al cuadro delimitador del grafo.

El modo l_node especifica que los grafos deben ser empaquetados como una matriz.

Si ip->doSplines es verdadero, la función utiliza la información de splines en el campo spl de una arista, si existe. De lo contrario, el algoritmo representa una arista como un segmento de línea recta que conecta los centros de los nodos.

El parámetro ip->margin especifica un borde de margin puntos que se permitirá alrededor de cada nodo. Debe ser no negativo.

El parámetro ip->fixed, si no es nulo, debe apuntar a una matriz de ng booleanos. Si ip->fixed[i] es verdadero, el grafo gs[i] debe dejarse en su posición original. El empaquetado colocará primero todos los grafos fijos, y luego rellenará con los grafos restantes.

La función devuelve una matriz de puntos que pueden usarse como origen del cuadro delimitador de cada grafo. Si los grafos se traducen a estas posiciones, ninguno de los componentes del grafo se superpondrá. La matriz devuelta se obtiene mediante malloc y debe ser liberada por el llamante. Si ocurre algún problema, putGraphs devuelve NULL. Como efecto secundario, al inicio, putGraphs establece el campo bb de cada grafo para reflejar su diseño inicial. Tenga en cuenta que putGraphs no realiza ninguna traducción ni cambia los grafos de entrada de ninguna otra manera que no sea establecer el campo bb.

Esta función utiliza el campo bb en Agraphinfo_t, los campos pos, xsize e ysize en nodehinfo_t y el campo spl en Aedgeinfo_t.

int packGraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info* ip)

Esta función toma ng subgrafos gs de un grafo raíz root y llama a putGraphs con los argumentos dados para generar un empaquetado de los subgrafos. Si tiene éxito, luego invoca traslada los subgrafos a sus nuevas posiciones. Devuelve 0 si tiene éxito.

int packSubgraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info* ip)

Esta función simplemente llama a packGraphs con los argumentos dados, y luego recalcula el cuadro delimitador del grafo root.

int pack_graph(int ng, Agraph_t** gs, Agraph_t* root, boolean* fixed)

utiliza packSubgraphs para colocar los subgrafos individuales en un diseño único con los parámetros obtenidos de getPackInfo. Si tiene éxito, se llama a dotneato_postprocess en el grafo raíz.

point* putRects (int ng, boxf* bbs, pack_info* ip)

Esta es la versión de putGraphs que trabaja con rectángulos en lugar de grafos. Toma ng rectángulos bbs y los empaqueta en un solo diseño sin superposiciones.

Los campos aspect, sz, margin, doSplines, mode, fixed y vals de ip se utilizan para controlar el empaquetado.

Si ip->fixed no es NULL, los rectángulos para los cuales ip->fixed[i] es verdadero no se moverán.

La función devuelve una matriz de puntos que representan los orígenes de los rectángulos empaquetados. La matriz devuelta se obtiene mediante malloc y debe ser liberada por el llamante. Si ocurre algún problema, putRects devuelve NULL.

int packRects (int ng, boxf* bbs, pack_info* ip)

Esta función llama a putRects y luego traslada los rectángulos a sus nuevas posiciones. Devuelve 0 si tiene éxito.

pack_mode getPackMode (Agraph_t* g, pack_mode dflt)

Determina el modo de empaquetado para el grafo g. Si el atributo ``packmode'' está definido para el grafo, su valor se utiliza. De lo contrario, se utiliza el valor predeterminado dflt.

int getPack (Agraph_t* g, int xsize, int ysize)

Si los atributos ``pack'' o ``packnum'' están definidos para el grafo g, esta función devuelve el número de nodos a empaquetar. Si no, devuelve -1.

pack_info getPackInfo (Agraph_t* g)

Construye y devuelve una estructura pack_info a partir de los atributos del grafo g.

pack_info freePackInfo (pack_info* ip)

Libera la memoria asignada para la estructura pack_info.

BUGS

La función pccomps no maneja correctamente las aristas que conectan nodos en diferentes componentes. El manejo de tales aristas es incidental y puede dar lugar a resultados inesperados.

La funcionalidad de empaquetado de arreglos de putGraphs y putRects no está completamente implementada.

NAME

pack, packRects, pack_mode_parsePackModeInfo, pack_mode_getPackModeInfo, pack_mode_getPackMode, pack_mode_getPackInfo, pack_mode_getPack - pack rectangles or graphs

SYNOPSIS

int
packRects(int ng, boxf* bbs, pack_info* ip);
pack_mode
parsePackModeInfo(char* p, pack_mode dflt, pack_info* pinfo);
pack_mode
getPackModeInfo(Agraph_t* g, pack_mode dflt, pack_info* pinfo);
pack_mode
getPackMode(Agraph_t* g, pack_mode dflt);
int
getPack(Agraph_t* g, int not_def, int dflt);
pack_mode
getPackInfo(Agraph_t* g, pack_mode dflt, int dfltMargin, pack_info* pinfo);

DESCRIPTION

putRects empaqueta una colección de rectángulos en un único diseño que evita cualquier superposición. Toma como entrada ng rectángulos bbs.

Su comportamiento y valor de retorno son análogos a los de putGraphs. Sin embargo, los modos l_node y l_clust son ilegales. Los campos fixed y doSplines de ip no se utilizan.

int packRects (int ng, boxf* bbs, pack_info* ip)

packRects es análogo a packGraphs: llama a putRects y, si esto es exitoso, traduce los rectángulos en bbs apropiadamente.

Funciones de utilidad

La biblioteca proporciona varias funciones que se pueden utilizar para adaptar el empaquetado en función de los atributos del grafo.

pack_mode parsePackModeInfo(char* p, pack_mode dflt, pack_info* pinfo)

analiza p como una representación de cadena del modo de empaquetado, almacenando la información en pinfo. Si p es "cluster", devuelve l_clust; para "graph", devuelve l_graph; para "node", devuelve l_node; para "array", devuelve l_array; para "aspect", devuelve l_aspect; de lo contrario, devuelve dflt. Los datos relacionados también se almacenan en pinfo.

pack_mode getPackModeInfo(Agraph_t * g, pack_mode dflt, pack_info* pinfo)

Esta función procesa el atributo "packmode" del grafo, almacenando la información en pinfo. Devuelve pinfo->mode. El atributo se procesa utilizando parsePackModeInfo con dflt pasado como argumento predeterminado.

pack_mode getPackMode (Agraph_t* g, pack_mode dflt)

Esta función devuelve un pack_mode asociado con g.

int getPack (Agraph_t* g, int not_def, int dflt)

Esta función consulta el atributo del grafo "pack". Si se define como un entero no negativo, se devuelve el entero; si se define como "true", se devuelve el valor dflt; de lo contrario, se devuelve el valor not_def.

pack_mode getPackInfo(Agraph_t * g, pack_mode dflt, int dfltMargin, pack_info* pinfo)

Esta función llama a getPackModeInfo y getPack, almacenando la información en pinfo. dfltMargin se utiliza para ambos argumentos enteros de getPack, con el resultado guardado como pinfo->margin. Devuelve pinfo->mode.
