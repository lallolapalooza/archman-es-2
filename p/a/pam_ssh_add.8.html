NOMBRE

pam_ssh_add - Módulo PAM para cargar automáticamente claves ssh en un agente

DESCRIPCIÓN

pam_ssh_add proporciona módulos de autenticación y sesión que permiten a los usuarios iniciar su sesión con un ssh-agent en ejecución con tantas claves ssh cargadas como sea posible.

Si se utiliza, el módulo de autenticación simplemente almacena el token de autenticación para su uso posterior por el módulo de sesión. Debido a que este módulo no realiza ninguna autenticación real, devuelve PAM_CRED_INSUFFICIENT en éxito y siempre debe ir acompañado de un módulo de autenticación real en su configuración de pam.

Por defecto, el módulo de sesión iniciará un nuevo ssh-agent y ejecutará ssh-add, cargando todas las claves que existan en la ruta predeterminada para el usuario recién iniciado sesión. Si alguna clave solicita una contraseña, y se almacenó un token de autenticación con éxito, ese token se proporcionará como la contraseña.

OPCIONES

debug

Esta opción activará el registro de depuración en syslog.

EJEMPLOS

        auth     required  pam_unix.so
        auth     optional  pam_ssh_add.so
        session  optional  pam_ssh_add.so
