NOMBRE

partclone.chkimg - La utilidad para comprobar la imagen creada por partclone

SINOPSIS

partclone.chkimg {[-s | --source] fuente} [[-dX | --debug=X] [-N | --ncurses] [-f | --UI-fresh] [-F | --force] [--ignore_crc] [-C | --no_check] [-B | --no_block_detail] [-z | --buffer_size] [-L | --logfile] archivo_log]

DESCRIPCIÓN

partclone.chkimg es parte del proyecto Partclone para verificar archivos de imagen. Partclone proporciona utilidades para hacer copias de seguridad de bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se utilizan e2fslibs para leer el bloque utilizado de una partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT, EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Todas las utilidades de partclone se pueden ejecutar como partclone.xxx, son sistemas de archivos muy similares a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restauración de hfsplus, simplemente ejecute partclone.hfsp.

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de su acción. Normalmente, la fuente de copia de seguridad es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos de una tubería está soportada SÓLO para la restauración, simplemente omita la opción -s o use '-' para recibir datos de la entrada estándar.

-L ARCHIVO, --logfile ARCHIVO

Ponga una ruta especial para registrar la información del registro de partclone. (por defecto /var/log/partclone.log)

-C, --no_check

No compruebe el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-X, --dialog

Muestra el mensaje en formato de diálogo.

--ignore_crc

Ignora el error de verificación de crc.

-F, --force

Fuerza el progreso.

-f seg, --UI-fresh seg

Establece un intervalo de segundos para la actualización de la interfaz de usuario.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión del programa.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone.chkimg

EJEMPLOS

 comprobar si el archivo part.img es correcto o no.
   partclone.chkimg -d -s partclone.img

DIAGNÓSTICOS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone.chkimg proporciona algunos códigos de retorno, que pueden ser utilizados en scripts:

Código Diagnóstico
0 El programa terminó con éxito.
1 La clonación o restauración parecen haber fallado.
