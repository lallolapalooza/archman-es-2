NOMBRE

pam_loginuid - Registrar el uid de inicio de sesión del usuario en el atributo del proceso

SINOPSIS

pam_loginuid.so [require_auditd]

DESCRIPCIÓN

El módulo pam_loginuid establece el atributo de proceso loginuid para el proceso que fue autenticado. Esto es necesario para que las aplicaciones sean auditadas correctamente. Este módulo PAM solo debe usarse para aplicaciones de punto de entrada como: login, sshd, gdm, vsftpd, crond y atd. Probablemente haya otras aplicaciones de punto de entrada además de estas. No deberías usarlo para aplicaciones como sudo o su, ya que eso desvirtúa el propósito al cambiar el loginuid a la cuenta a la que acaban de cambiar.

OPCIONES

require_auditd

Esta opción, cuando se proporciona, hará que este módulo consulte el estado del demonio de auditoría y deniegue los inicios de sesión si no se está ejecutando.

TIPOS DE MÓDULOS PROPORCIONADOS

Solo se proporciona el tipo de módulo session.

VALORES DE RETORNO

PAM_SUCCESS

El valor de loginuid se establece y auditd se está ejecutando si se solicitó la verificación.

PAM_IGNORE

El archivo /proc/self/loginuid no está presente en el sistema o el proceso de inicio de sesión se ejecuta dentro de un espacio de nombres de uid y el kernel no admite la sobrescritura de loginuid.

PAM_SESSION_ERR

Cualquier otro error impidió establecer loginuid o auditd no se está ejecutando.

EJEMPLOS

#%PAM-1.0
auth       required     pam_unix.so
auth       required     pam_nologin.so
account    required     pam_unix.so
password   required     pam_unix.so
session    required     pam_unix.so
session    required     pam_loginuid.so
