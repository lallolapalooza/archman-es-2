NOMBRE

pamtodjvurle - convierte una imagen Netpbm a formato DjVu Color RLE

SINOPSIS

pamtodjvurle

[-transparente color] [archivo_netpbm [archivo_rle]]

Se aceptan las abreviaturas mínimas únicas de las opciones.

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pamtodjvurle lee una imagen Netpbm (PNM o equivalente PAM de PNM) como entrada y produce el formato DjVu Color RLE como salida.

OPCIONES

-transparente nombrecolor
Esta opción indica qué color de la imagen debe considerarse transparente.

Especifique el color (color) como se describe para la rutina de biblioteca de argumento ppm_parsecolor().

El valor predeterminado es 'blanco'.

HISTORIAL

pamtodjvurle era nuevo en Netpbm 10.22 (abril de 2004), pero un programa que hacía casi lo mismo, llamado ppmtodjvurle, estaba en Netpbm 10.21 (marzo de 2004). Este último fue escrito y contribuido a Netpbm por Scott Pakin <scott+pbm@pakin.org>. pamtodjvurle utiliza técnicas tomadas de ppmtodjvurle, pero no se copia código entre ellos.
