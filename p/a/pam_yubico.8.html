PAM_YUBICO(8) Manual del módulo PAM de Yubico PAM_YUBICO(8)

NOMBRE

pam_yubico - Módulo para autenticación de YubiKey

SINOPSIS

pam_yubico [...]

DESCRIPCIÓN

El módulo sirve para la autenticación de YubiKeys, ya sea con validación en línea de OTP, o validación sin conexión con respuesta a desafío HMAC-SHA1.

OPCIONES

debug

Activa la depuración.

debug_file=archivo

Nombre del archivo al que escribir la depuración, el archivo debe existir y ser un archivo regular. Por defecto es stdout.

mode=[cliente|respuesta-a-desafio]

Modo de operación, cliente para validación OTP y respuesta-a-desafio para validación respuesta-a-desafio. Por defecto es cliente.

authfile=archivo

Ubicación del archivo que contiene las correspondencias de los IDs de token de YubiKey a nombres de usuario. El formato es nombre_usuario:primer_id_publico:segundo_id_publico:... La ubicación por defecto del archivo es $HOME/.yubico/authorized_yubikeys.

id=id

Su identidad de cliente API para el servidor de validación.

key=clave

Su clave de cliente en formato base64. La clave de cliente también se conoce como clave API, y proporciona integridad en la comunicación entre el cliente (usted) y el servidor de validación. Si desea obtener una para usar con el servicio predeterminado de YubiCloud, por favor vaya a: https://upgrade.yubico.com/getapikey/

alwaysok

Éxito con todos los intentos de autenticación (peligroso, modo de presentación).

try_first_pass

Antes de solicitar al usuario su contraseña, el módulo intenta primero la contraseña del módulo apilado anterior en caso de que satisfaga a este módulo también.

use_first_pass

Fuerza al módulo a usar la contraseña de un módulo apilado anterior y nunca solicitará al usuario; si no hay contraseña disponible o la contraseña no es apropiada, se le denegará el acceso al usuario.

always_prompt

Si se establece, no intente realizar una búsqueda para determinar si el usuario tiene una YubiKey configurada, sino que solicite una sin importar qué. Esto es útil en el caso en que ldap_bind_as_user esté habilitado pero este módulo se esté utilizando para leer la contraseña del usuario (en un escenario de autenticación YubiKey+OTP).

nullok

No falle cuando no haya tokens declarados para el usuario en los archivos de mapeo de autorización o en LDAP. Esto se puede usar para hacer que la autenticación YubiKey sea opcional a menos que el usuario tenga tokens asociados.

ldap_starttls

Si se establece, emita un comando STARTTLS a la conexión LDAP antes de intentar enlazarla. Esta es una configuración común para servidores que solo escuchan en el puerto 389 pero aún requieren TLS.

ldap_bind_as_user

Utilice el usuario que inicia sesión para enlazar a ldap. Esto utilizará la contraseña proporcionada por el usuario a través de PAM. Si esto se establece, ldapdn y uid_attr también deben establecerse. Habilitar esto provocará que ldap_bind_user y ldap_bind_password se ignoren.

urllist=lista

Lista de plantillas de URL a utilizar. Esto se establece llamando a ykclient_set_url_bases. La lista debe tener el formato: https://api1.example.com/wsapi/2.0/verify;https://api2.example.com/wsapi/2.0/verify

url=url

Esta opción no debe usarse, use la opción urllist en su lugar. Establezca la plantilla de URL a usar, esto se establece llamando a ykclient_set_url_template. La URL debe establecerse en el formato https://api.example.com/wsapi/2.0/verify?id=%d&otp=%s

capath=ruta

La ruta donde se almacenan los certificados X509. Esto es requerido si se usan https o ldaps en url y ldap_uri, respectivamente.

cainfo=archivo

Opción para permitir el uso de un paquete de CA en lugar de una ruta.

proxy=proxy

El proxy para conectarse al servidor de validación. Los esquemas válidos son http://, https://, socks4://, socks4a://, socks5:// o socks5h://. Socks5h le pide al proxy que resuelva el DNS. Si no se especifica esquema ni puerto, se utilizará el puerto de proxy HTTP 1080. Ejemplo: socks5h://usuario:contraseña@10.10.0.1:1080

verbose_otp

Muestra la Contraseña de un Solo Uso cuando se introduce, es decir, para habilitar el eco en la terminal de los caracteres introducidos. Se le aconseja no usar esto si está utilizando autenticación de dos factores porque mostrará su contraseña en la pantalla. Esto requiere que el servicio que utiliza el módulo PAM muestre campos personalizados. Esta opción no se puede usar con OpenSSH.

ldap_uri=uri

La URI del servidor LDAP (por ejemplo, ldap://localhost).

ldap_server=servidor

El host del servidor LDAP (se utiliza el puerto LDAP predeterminado). Obsoleto. Utilice ldap_uri en su lugar.

ldapdn=dn

El nombre distinguido (DN) donde se almacenan los usuarios (por ejemplo: ou=usuarios,dc=dominio,dc=com). Si se utiliza ldap_filter, esta es la base desde la cual se realizará la búsqueda en el subárbol.

ldap_clientcertfile=certificadocliente

La ruta a un archivo de certificado de cliente para usar al comunicarse con el servidor LDAP. Tenga en cuenta que esto requiere que ldap_clientkeyfile también esté configurado.

ldap_clientkeyfile=clavecertificadocliente

La ruta a una clave que se utilizará con el certificado de cliente al comunicarse con el servidor LDAP. Tenga en cuenta que esto requiere que ldap_clientcertfile también esté configurado.

user_attr=attr

El atributo LDAP utilizado para almacenar nombres de usuario (por ejemplo: cn).

yubi_attr=attr

El atributo LDAP utilizado para almacenar el ID de YubiKey.

yubi_attr_prefix=prefijo

El prefijo del valor del atributo LDAP, en caso de un atributo genérico, utilizado para almacenar varios tipos de IDs.

token_id_length=longitud

Longitud del ID que precede al OTP (esto es 12 si se usa YubiCloud).

ldap_bind_user=usuario

El usuario con el que intentar un enlace LDAP.

ldap_bind_password=contraseña

La contraseña a usar en el enlace LDAP.

ldap_filter=filtro

Un filtro LDAP a utilizar para intentar encontrar el objeto correcto en LDAP. En esta cadena %u se reemplazará con el nombre de usuario.

ldap_cacertfile=archivocertificadoautorizacion

Archivo de certificado CA para la conexión LDAP.

chalresp_path=ruta

Ruta de un directorio a nivel de sistema donde se pueden encontrar archivos de respuesta a desafío para los usuarios. La ubicación predeterminada es $HOME/.yubico/.

mysql_server=servidormysql

Nombre de host/Dirección del servidor mysql. Ejemplo 10.0.0.1

mysql_port=puertomysql

Puerto de red del servidor mysql.

mysql_user=usuariomysql

Usuario para acceder a la base de datos. Se recomienda encarecidamente usar un usuario específico con acceso de solo lectura.

mysql_password=contraseñamysql

Contraseña mysql asociada al usuario.

mysql_database=basedatosmysql

el nombre de la base de datos. Ejemplo: otp

EJEMPLOS

auth sufficient pam_yubico.so id=16 debug
auth required pam_yubico.so mode=challenge-response
auth required pam_yubico.so id=16 ldap_uri=ldaps://ldap.example.com ldap_filter=(uid=%u) yubi_attr=yubiKeyId

ARCHIVOS

$HOME/.yubico/authorized_yubikeys

Si no se establece authfile, este archivo se utiliza para la correspondencia entre el ID público de YubiKey y en modo cliente.

$HOME/.yubico/challenge, $HOME/.yubico/challenge-numero_de_serie

Si no se establece chalresp_path, estos archivos se utilizan
