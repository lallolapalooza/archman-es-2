PATCHVIEW(1) Páginas del manual PATCHVIEW(1)

NOMBRE

patchview - Sin opciones, muestra los archivos numerados modificados por el parche. Con opciones, se comporta como filterdiff.

SINOPSIS

patchview [[-n] | [--line-number]] [[-p n] | [--strip-match=n]] [--strip=n] [--addprefix=PREFIJO] [[-s] | [--status]] [[-E] | [--empty-files-as-removed]] [[-i PATRON] | [--include=PATRON]] [[-x PATRON] | [--exclude=PATRON]] [[-z] | [--decompress]] [[-# RANGO] | [--hunks=RANGO]] [--lines=RANGO] [[-FRANGO] | [--files=RANGO]] [[-H] | [--with-filename]] [[-h] | [--no-filename]] [[-v] | [--verbose]...] [archivo...]

patchview {[--help] | [--version] | [--filter ...] | [--grep ...]}

DESCRIPCIÓN

¿Qué es patchview? Es un envoltorio de filterdiff para usar con archivos numerados.

patchview

(sin argumentos) es equivalente a: lsdiff --number

patchview -F2-

(o con cualquier otro argumento) es equivalente a: filterdiff -F2- (o cualquier argumento que se proporcione)

Hay dos scripts para trabajar con git (gitdiff y gitdiffview) y dos para svn (svndiff y svndiffview).

svndiff
gitdiff

(sin argumentos) dará la lista de archivos modificados.

svndiff -F1
gitdiff -F1

mostrará el parche del archivo #1.

svndiffview
gitdiffview

redirige todos los parches a través de filterdiff a vim - -R (en modo de solo lectura, fácil de salir), mostrando el parche completo con color.

svndiffview -F2
gitdiffview -F2

(o cualquier otro argumento) redirigirá el parche del archivo #2 a vim - -R.

OPCIONES

-n, --line-number

Muestra el número de línea en el que comienza cada parche. Si se solicita una salida detallada (usando -nv), cada "hunk" de cada parche también se lista.

Para cada archivo que se modifica, se genera una línea que contiene el número de línea del inicio del parche, seguido de un carácter de tabulación, seguido del nombre del archivo que se modifica. Si se proporciona -v una vez, después de cada una de estas líneas habrá una línea por cada "hunk", que consta de un carácter de tabulación, el número de línea en el que comienza el "hunk", otra tabulación, la cadena "Hunk #", y el número del "hunk" (comenzando en 1).

Si se proporciona -v dos veces junto con -n (es decir, -nvv), el formato es ligeramente diferente: se muestra texto descriptivo a nivel de "hunk" después de cada número de "hunk", y se habilita la opción --number-files.

-N, --number-files

Se listan los números de archivo, comenzando en 1, antes de cada nombre de archivo.

-# RANGO, --hunks=RANGO

Lista solo los "hunks" dentro del RANGO especificado. Los "hunks" se numeran a partir de 1, y el rango es una lista separada por comas de números o intervalos "primero-último", opcionalmente precedida por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del intervalo para indicar que no hay límite en esa dirección.

--lines=RANGO

Lista solo los "hunks" que contienen líneas del archivo original que se encuentran dentro del RANGO especificado. Las líneas se numeran a partir de 1, y el rango es una lista separada por comas de números o intervalos "primero-último", opcionalmente precedida por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del intervalo para indicar que no hay límite en esa dirección.

-F=RANGO, --files=RANGO

Lista solo los archivos indicados por el RANGO especificado. Los archivos se numeran a partir de 1 en el orden en que aparecen en la entrada del parche, y el rango es una lista separada por comas de números o intervalos "primero-último", opcionalmente precedida por un modificador 'x' que invierte todo el rango; se puede omitir el primero o el último del intervalo para indicar que no hay límite en esa dirección.

-p n, --strip-match=n

Al coincidir, ignora los primeros n componentes de la ruta del archivo.

--strip=n

Elimina los primeros n componentes de la ruta del archivo antes de mostrarla.

--addprefix=PREFIJO

Antepone PREFIJO a la ruta del archivo antes de mostrarla.

-s, --status

Muestra las adiciones, modificaciones y eliminaciones de archivos. Una adición de archivo se indica con un "+", una eliminación con un "-", y una modificación con un "!".

-E, --empty-files-as-removed

Trata los archivos vacíos como ausentes para el propósito de mostrar adiciones, modificaciones y eliminaciones de archivos.

-i PATRON, --include=PATRON

Incluye solo archivos que coincidan con PATRON.

-x PATRON, --exclude=PATRON

Excluye archivos que coincidan con PATRON.

-z, --decompress

Descomprime archivos con extensiones .gz y .bz2.

-H, --with-filename

Imprime el nombre del archivo de parche que contiene cada parche.

-h, --no-filename

Suprime el nombre del archivo de parche que contiene cada parche.

-v, --verbose

Salida detallada.

--help

Muestra un breve mensaje de uso.

--version

Muestra el número de versión de patchview.

--filter

Comportarse como filterdiff(1) en su lugar.

--grep

Comportarse como grepdiff(1) en su lugar.

VER TAMBIÉN

lsdiff(1),filterdiff(1), grepdiff(1)

EJEMPLOS

Podemos crear el siguiente script de una línea con el nombre difftotrunk.sh, para ver las diferencias de dos directorios o repositorios svn (trunk y .)

diff ../trunk . -ru -x .svn | patchview "$@"
./difftotrunk.sh , mostrará todos los archivos diferentes y su número.
./difftotrunk.sh -F3,4 , mostrará solo las diferencias de los archivos #3 y #4.
./difftotrunk.sh -F3 -#1 , mostrará solo el "hunk" #1 del archivo #3.
./difftotrunk.sh -F3 -#x1 , mostrará las diferencias del archivo #3 sin el "hunk" #1 (x significa excluir).
