PASYSTRAY(1) Manual de comandos generales PASYSTRAY(1)

NOMBRE

pasystray - Controlador de PulseAudio para la bandeja del sistema

SINOPSIS

pasystray [opciones]

DESCRIPCIÓN

pasystray permite controlar varios ajustes del servidor PulseAudio desde la bandeja del sistema X11. Hacer clic en el icono de la bandeja mostrará un menú gráfico, permitiendo al usuario:

•
ajustar el volumen de las transmisiones y las salidas/entradas
•
transferir transmisiones entre salidas/entradas
•
cambiar la salida/entrada predeterminada
•
establecer el servidor predeterminado (PULSE_SERVER)
•
detectar servicios PulseAudio de red
•
renombrar dispositivos

ASOCIACIONES DEL RATÓN

Icono de estado:

•
Clic central / Alt + Clic izquierdo: alternar silenciar, salida predeterminada
•
Ctrl + Clic central / Ctrl + Alt + Clic izquierdo: alternar silenciar, entrada predeterminada
•
Desplazamiento hacia arriba/abajo: ajustar volumen, salida predeterminada
•
Ctrl + Desplazamiento hacia arriba/abajo: ajustar volumen, entrada predeterminada

Elemento del menú de entrada/salida:

•
Desplazamiento hacia arriba/abajo: ajustar volumen
•
Clic izquierdo: establecer como entrada/salida predeterminada
•
Clic central / Alt + Clic izquierdo: alternar silenciar
•
Clic derecho: abrir menú para mover todas las salidas/entradas a esta entrada/salida o renombrarla

Elemento del menú de transmisión de reproducción/grabación:

•
Desplazamiento hacia arriba/abajo: ajustar volumen
•
Clic central: alternar silenciar

MÓDULOS PULSEAUDIO OPCIONALES

pasystray puede utilizar los siguientes módulos de PulseAudio:

•
module-device-manager - renombrado de dispositivos
•
module-zeroconf-discover - descubrimiento de dispositivos de red

Estos módulos pueden necesitar ser cargados, usando por ejemplo pactl(1) o el propio pasystray.

SALIDAS/ENTRADAS REMOTAS

Para detectar salidas/entradas remotas, además de habilitar module-zeroconf-discover localmente, module-zeroconf-publish debe estar habilitado en el servidor remoto.

SERVIDOR REMOTO

Al igual que con la mayoría de las aplicaciones conscientes de PulseAudio, la variable de entorno PULSE_SERVER puede establecerse en la dirección de un host remoto para usar pasystray para controlar el servidor que se ejecuta en ese host.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-').

-V, --version
Mostrar la versión del programa.
-d, --debug
Imprimir información de depuración.
-m, --volume-max=N
Establecer el volumen máximo (en porcentaje).
-i, --volume-inc=N
Establecer el incremento de volumen.
-r, --reverse-scroll
Invertir la dirección del ajuste de volumen con la rueda del ratón.
-t, --no-icon-tooltip
Deshabilitar la información sobre herramientas del icono de estado para el estado conectado.
-n, --no-notify
Deshabilitar todas las notificaciones. Obsoleto; usar --notify=none en su lugar.
-a, --always-notify
Habilitar notificaciones para todos los cambios en pulsaudio. Obsoleto; usar --notify=all en su lugar.
--include-monitors
Mostrar fuentes monitoras.
-g, --key-grabbing
Habilitar el control de volumen del teclado y las teclas de silencio para ajustar la configuración de volumen.
-N, --notify=option
Establecer opciones de notificación; usar --notify=help para obtener una lista de opciones válidas.

VER TAMBIÉN

pulseaudio(1), pactl(1).
