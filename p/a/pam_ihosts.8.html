pam_ihosts(8) Manual del Administrador del Sistema pam_ihosts(8)

NOMBRE

pam_ihosts - Permitir o bloquear el inicio de sesión basándose en la dirección MAC, la dirección IP o el registrador/región de IP.

SINOPSIS

pam_ihosts.so [usuario=<nombre de usuario>] [syslog] [permitir-dispositivo=<dispositivo>] [permitir-mac=<dirección mac>] [permitir-ip=<dirección ip>] [permitir-región=<región>] [archivos-región=<rutas>] [script=<ruta>]

DESCRIPCIÓN

pam_ihosts considera la IP remota de un usuario para prevenir/permitir el inicio de sesión de usuarios que ya han proporcionado las credenciales correctas.

pam_ihosts.so puede usar los archivos de "estadísticas" que los registradores de internet regionales proporcionan para buscar el registrador y el país al que está registrada una IP, permitiendo una forma de geolocalización rudimentaria.

pam_ihosts.so establece las siguientes variables de entorno al iniciar sesión. La dirección IP de origen de la conexión se almacena en "IHOSTS_ADDRESS", la dirección MAC de origen en "IHOSTS_MAC" y la información de la región se almacena en la variable de entorno "IHOSTS_REGION" para su uso por parte de los programas después del inicio de sesión.

Cuidado. pam_ihosts.so deniega el inicio de sesión por defecto para cualquier usuario que esté configurado para manejar. Se deben proporcionar opciones para indicar la dirección MAC, la dirección IP, el código de país o la región de los hosts que tienen permitido iniciar sesión.

OPCIONES

Las opciones de PAM que se pueden aplicar a los archivos de configuración en /etc/pam.d son las siguientes:

usuario=[patrones de usuario]
Lista separada por comas de patrones fnmatch (estilo shell) que identifican a los usuarios a los que se aplica esta regla. Para coincidir con todos los usuarios, omita esto, déjelo en blanco o establézcalo explícitamente como "usuario=*". Un carácter '!' al principio del patrón permite la inversión, por lo que para coincidir con todos los usuarios excepto root use: "usuario=!root"
archivo-conf=[ruta]
Especifica una ruta a un archivo de configuración que puede contener cualquier opción de pam_ihosts. El archivo de configuración solo se aplica a la línea actual en la configuración de pam, por lo que puede tener, por ejemplo, varias entradas en la configuración de PAM que tengan diferentes coincidencias de usuario= y diferentes archivos de configuración.
syslog
Registrar eventos a través de mensajes de syslog
script=[ruta]
Ejecutar script cuando una conexión es denegada o permitida. Los argumentos pasados al script serán "PERMITIR/DENEGAR" "Usuario", "IP", "Dirección MAC", "Dispositivo" y "Región". "Región" estará en el formato "<registrador>:<códigopaís>" así, por ejemplo, "ripencc:GB".
permitir-ip=[ip]
Una lista separada por comas de patrones fnmatch que coinciden con direcciones IP permitidas para iniciar sesión.
permitir-hosts=[host]
Una lista separada por comas de patrones que coinciden con nombres de host (buscados desde la dirección IP) que tienen permitido iniciar sesión.
permitir-dyndns=[host]
Una lista separada por comas de nombres de host (no patrones) que tienen permitido iniciar sesión (ver 'DYNDNS' a continuación).
permitir-mac=[mac]
Una lista separada por comas de patrones fnmatch que coinciden con direcciones MAC permitidas para iniciar sesión.
permitir-dev=[dev]
Una lista separada por comas de patrones fnmatch que coinciden con nombres de dispositivos de red a los que llega la conexión. Este es el adaptador de red en su máquina que está *recibiendo* la conexión del host remoto.
permitir-región=[región]
Una lista separada por comas de patrones fnmatch que coinciden con cadenas de región buscadas en archivos de registradores de IP. Las cadenas de región están en el formato "<registrador>:<códigopaís>. Esta opción requiere que proporcione las rutas a los archivos de región con la opción "archivos-región". Para más detalles, consulte "REGIONES" a continuación.
archivos-región=[rutas]
Una lista separada por comas de rutas a archivos que contienen asignaciones de registradores de IP. Cada ruta puede prefijarse con "mmap:" en cuyo caso el programa utilizará un mmap compartido del archivo (ver ARCHIVOS CON MAPA DE MEMORIA a continuación). Para más detalles, consulte "REGIONES" a continuación.
lista-negra=[rutas]
Una lista separada por comas de rutas a archivos que contienen direcciones IP, direcciones MAC o nombres de host que están en la *lista negra* (inicio de sesión denegado). Los archivos deben contener un elemento (dirección IP) por línea. Cada ruta puede prefijarse con "mmap:" en cuyo caso el programa utilizará un mmap compartido del archivo (ver ARCHIVOS CON MAPA DE MEMORIA a continuación).
lista-blanca=[rutas]
Una lista separada por comas de rutas a archivos que contienen direcciones IP, direcciones MAC o nombres de host que están en la *lista blanca* (inicio de sesión permitido). Los archivos deben contener un elemento (dirección IP) por línea. Cada ruta puede prefijarse con "mmap:" en cuyo caso el programa utilizará un mmap compartido del archivo (ver ARCHIVOS CON MAPA DE MEMORIA a continuación).
lista-negra-dns=[dominios]
Una lista separada por comas de dominios para usar en búsquedas de lista negra DNS. Por ejemplo, "lista-negra-dns=zen.spamhaus.org,bots.abuse.net" verificaría si el host está presente en las listas negras DNS zen.spamhaus.org o bots.abuse.net. Los elementos para los que se devuelve una entrada coincidente tienen el inicio de sesión DENEGADO. Las búsquedas DNS no se ejecutan en paralelo sino una tras otra, por lo que desafortunadamente el inicio de sesión puede volverse lento si se consultan muchas listas.
lista-blanca-dns=[dominios]
Una lista separada por comas de dominios para usar en búsquedas de lista blanca DNS. Por ejemplo, "lista-blanca-dns=whitelist.spamhaus.org,mylist.local" verificaría si el host está presente en whitelist.spamhaus.org o mylist.local. Los elementos para los que se devuelve una entrada coincidente tienen el inicio de sesión PERMITIDO. Las búsquedas DNS no se ejecutan en paralelo sino una tras otra, por lo que desafortunadamente el inicio de sesión puede volverse lento si se consultan muchas listas.

DYNDNS

Los nombres de host utilizados en el tipo de regla "permitir-host" se buscan desde la dirección IP desde la que proviene el intento de inicio de sesión. Sin embargo, para el tipo de regla "permitir-dyndns", las búsquedas van en la otra dirección. Cada nombre de host enumerado en la regla se busca y se verifica si tiene la misma dirección IP que la dirección que está iniciando sesión. Esto es para permitir el uso de servicios de DNS dinámico que permiten que los hosts que cambian su dirección IP (ya sea porque el host es móvil o porque su ISP le asigna su IP y cambia con frecuencia) contra un nombre de host. Normalmente, estos hosts tendrán un nombre de host "real" controlado por el ISP, y el nombre DNS dinámico es un nombre secundario. Por lo tanto, buscar el nombre de host para la IP devolverá el nombre de host primario "real", por lo que la verificación debe realizarse buscando la IP del nombre de host dinámico y verificando si coincide con la IP desde la que se está iniciando sesión.

ARCHIVOS REGIÓN

La información de la región se busca en archivos proporcionados por los Registros Regionales de Internet. Estos archivos se pueden descargar en las siguientes direcciones:

http://ftp.lacnic.net/pub/stats/lacnic/delegated-lacnic-latest # América Latina
http://ftp.ripe.net/ripe/stats/delegated-ripencc-latest # Europa, Rusia, Oriente Medio
http://ftp.arin.net/pub/stats/arin/delegated-arin-extended-latest # América del Norte
http://ftp.afrinic.net/pub/stats/afrinic/de # África
http://ftp.apnic.net/stats/apnic/delegated-apnic-latest # Asia y el Pacífico

ARCHIVOS CON MAPA DE MEMORIA

Los archivos de texto plano que contienen listas de direcciones IP, MAC o nombres de host, o las tablas de asignación de IP a región, pueden ser muy grandes y, por lo tanto, lentos para ser leídos cada vez que se accede a ellos. Si se antepone "mmap:" a la ruta de un archivo, se intentará mapear el archivo en la memoria utilizando mmap(2). Si esto tiene éxito, el acceso al archivo será mucho más rápido, ya que todo el archivo se cargará en la memoria una vez. La asignación de memoria se comparte entre todos los procesos que utilizan el mismo archivo, por lo que solo se requiere una asignación de memoria.

Por supuesto, el tamaño del archivo del mapa de memoria será mayor que el tamaño original del archivo, y su uso de memoria estará reservado hasta que el programa se cierre. Para evitar el uso excesivo de memoria, el módulo solo asignará el archivo si es lo suficientemente grande (actualmente, mayor de 50 KB).

EJEMPLO

Si desea permitir que el usuario "alice" inicie sesión desde cualquier parte de China, el usuario "bob" solo desde su casa (suponiendo que su IP es 192.168.0.1), y permitir que cualquier otro usuario inicie sesión desde cualquier host con el nombre de host "mypc.example.org", podría tener lo siguiente en su archivo de configuración de PAM (por ejemplo, /etc/pam.d/system-login):

auth required pam_ihosts.so user=alice allow-region=apnic:CN\
    user=bob allow-ip=192.168.0.1\
    allow-hosts=mypc.example.org

También puede desear registrar los eventos de denegación de inicio de sesión en syslog:

auth required pam_ihosts.so syslog allow-ip=127.0.0.1

Para bloquear el inicio de sesión desde direcciones IP en la lista negra de Spamhaus, y permitir solo el inicio de sesión desde los EE. UU.:

auth required pam_ihosts.so blacklist=/etc/security/ihosts.blacklist\
    allow-region=arin:US

Para permitir el inicio de sesión solo desde hosts en su red privada (192.168.0.0/24), y permitir la conexión solo a través de la interfaz de red "eth0":

auth required pam_ihosts.so allow-ip=192.168.0.0/24 allow-dev=eth0

REGION FILES

Region files are used to look up IP addresses and determine their region or RIR (Regional Internet Registry). These files are typically downloaded from the RIRs themselves.

AFRINIC
http://ftp.afrinic.net/pub/stats/afrinic/delegated-afrinic-latest # Africa
http://ftp.apnic.net/stats/apnic/delegated-apnic-latest # Asia Pacific

BLACKLISTS/WHITELISTS

Los archivos de lista negra/lista blanca contienen direcciones IP, nombres de host o direcciones MAC que se deniegan o se permite el inicio de sesión. Un elemento por línea. Los tres tipos de elemento pueden estar presentes en el mismo archivo. Los archivos de lista negra se comprueban primero y luego pueden ser anulados por archivos de lista blanca. Como pam_ihosts deniega el inicio de sesión por defecto, se puede utilizar un archivo de lista blanca por sí solo. Para usar solo un archivo de lista negra, uno tendría que especificar "allow-ip=*" y luego especificar un archivo de lista negra, lo que tendría el efecto de permitir todo excepto lo que está en el archivo de lista negra.

ARCHIVOS MMAPPED

Las rutas de los archivos de lista negra, lista blanca y región pueden estar precedidas por "mmap:" En este caso, pam_ihosts utiliza un mapeo de memoria compartida del archivo. Siempre que otro programa tenga actualmente el archivo mapeado, pam_ihosts no tendrá que cargar el archivo del disco, ya que ya estará disponible como memoria compartida. Esto puede mejorar significativamente el rendimiento de archivos grandes, a costa de algo de memoria. Si ningún otro programa tiene el archivo mapeado, entonces pam_ihosts lo carga en memoria compartida, pero tiene que asumir el coste de rendimiento de cargarlo desde el disco. Por lo tanto, para que este sistema aporte un beneficio, algún programa de larga duración tiene que mantener los archivos mapeados.

EJEMPLOS

Permitir el inicio de sesión de root solo desde 192.168.0.x

account    required  pam_ihosts.so user=root syslog allow-ip=192.168.0.*

Para todos los usuarios, permitir el inicio de sesión solo desde dos direcciones MAC

account    required  pam_ihosts.so user=* allow-mac=ff:c0:a8:e4:99:31,ff:c0:a8:f9:cc:01

Para todos los usuarios excepto root, permitir el inicio de sesión solo desde direcciones IP de Gran Bretaña.

account    required  pam_ihosts.so user=!root region-files=/etc/ip-lists/delegated-afrinic-latest,/etc/ip-lists/delegated-lacnic-latest,/etc/ip-lists/delegated-apnic-latest,/etc/ip-lists/delegated-ripencc-latest allow-region=ripencc:GB

Para todos los usuarios, permitir el inicio de sesión solo desde IPs de Asia-Pacífico.

account    required  pam_ihosts.so user=* region-files=/etc/ip-lists/delegated-afrinic-latest,/etc/ip-lists/delegated-lacnic-latest,/etc/ip-lists/delegated-apnic-latest,/etc/ip-lists/delegated-ripencc-latest allow-region=apnic:*

Igual que arriba, pero quizás más eficiente, solo buscar regiones en el archivo apnic.

account    required  pam_ihosts.so user=* region-files=/etc/ip-lists/delegated-apnic-latest allow-region=apnic:*

Para todos los usuarios, permitir el inicio de sesión solo desde IPs de Asia-Pacífico. Usar memoria compartida mmap para los archivos afrinic y lacnic.

account    required  pam_ihosts.so user=* region-files=mmap:/etc/ip-lists/delegated-afrinic-latest,mmap:/etc/ip-lists/delegated-lacnic-latest,/etc/ip-lists/delegated-apnic-latest,/etc/ip-lists/delegated-ripencc-latest allow-region=apnic:*
