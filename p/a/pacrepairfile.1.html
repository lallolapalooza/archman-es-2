Paquete: pacutils

Licencias: MIT

PACREPAIRFILE(1) pacrepairfile PACREPAIRFILE(1)

NOMBRE

pacrepairfile - restablece las propiedades de los archivos gestionados por alpm

SINOPSIS

pacrepairfile [opciones] (--gid|--mode|--mtime|--uid)... <archivo>...
pacrepairfile (--help|--version)

DESCRIPCIÓN

Restablece las propiedades de los archivos para los archivos gestionados por alpm basándose en datos MTREE.

Si stdin no está conectado a una terminal, los archivos se leerán desde stdin.

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Consulte pacutils-sysroot(7).
--quiet
No mostrar información de progreso.
--package=nombre_paquete
Busca las propiedades del archivo en nombre_paquete. Se puede especificar varias veces. Si no se especifica --package, se buscarán todos los paquetes instalados.
--help
Muestra información de uso y sale.
--version
Muestra información de la versión y sale.

Campos

--gid
Restablece el ID del grupo propietario del archivo.
--mode
Restablece los permisos del archivo.
--mtime
Restablece la hora de modificación del archivo.
--uid
Restablece el ID del usuario propietario del archivo.

ADVERTENCIAS

pacrepairfile determina si debe leer archivos desde stdin basándose en una comprobación ingenua utilizando isatty(3). Si pacrepairfile se llama en un entorno, como una función de shell o un script que se utiliza en una tubería, donde stdin no está conectado a una terminal pero no contiene archivos para restablecer, pacrepairfile debe llamarse con stdin cerrado. Para shells compatibles con POSIX, esto se puede hacer con "<&-".

Para que pacrepairfile pueda restablecer las propiedades de un archivo, el paquete que posee el archivo debe tener datos MTREE.
