NOMBRE

pam_umask - módulo PAM para establecer la máscara de creación de modo de archivo

SINOPSIS

pam_umask.so [debug] [silent] [usergroups] [nousergroups] [umask=máscara]

DESCRIPCIÓN

pam_umask es un módulo PAM para establecer la máscara de creación de modo de archivo del entorno actual. La umask afecta a los permisos predeterminados asignados a los archivos recién creados.

El módulo PAM intenta obtener el valor de umask de los siguientes lugares y en el siguiente orden:

•entrada umask= en el campo GECOS del usuario (ver más abajo para más detalles)
•argumento umask=
•entrada UMASK de /etc/login.defs
•entrada UMASK= de /etc/default/login

El campo GECOS se divide en caracteres coma ','. Las entradas deben establecerse en su campo 'other' (subcampo), lo que podría hacerse, por ejemplo, utilizando chfn --other. Además de la entrada umask=, el módulo también reconoce la entrada pri=, que establece el valor de prioridad nice para la sesión, y la entrada ulimit=, que establece el tamaño máximo de los archivos que los procesos de la sesión pueden crear.

OPCIONES

debug

Imprime información de depuración.

silent

No imprime mensajes informativos.

usergroups

Si el usuario no es root y el nombre de usuario es el mismo que el nombre del grupo primario, los bits de grupo de la umask se establecen para ser iguales a los bits del propietario (ejemplos: 022 -> 002, 077 -> 007).

nousergroups

Este es lo opuesto a la opción usergroups descrita anteriormente, lo que puede ser útil en caso de que pam_umask se haya compilado con usergroups habilitado por defecto y desee deshabilitarlo en tiempo de ejecución.

umask=máscara

Establece la máscara de creación de modo de archivo (umask) del proceso que llama a máscara & 0777. El valor se interpreta como Octal.

TIPOS DE MÓDULOS PROPORCIONADOS

Solo se proporciona el tipo session.

VALORES DE RETORNO

PAM_SUCCESS

La nueva umask se estableció correctamente.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación falló al obtener el nombre de usuario.

PAM_INCOMPLETE

El método de conversación proporcionado por la aplicación devolvió PAM_CONV_AGAIN.

PAM_SERVICE_ERR

No se proporcionó ningún nombre de usuario.

PAM_USER_UNKNOWN

Usuario desconocido.

EJEMPLOS

Agregue la siguiente línea a /etc/pam.d/login para establecer la umask específica del usuario al iniciar sesión:

        session optional pam_umask.so umask=0022
