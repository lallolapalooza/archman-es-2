DESCRIPCIÓN

Las funciones del sistema PAPPL proporcionan acceso al objeto del sistema. Los sistemas son creados y eliminados por la aplicación impresora mientras que el ciclo de vida del objeto pappl_system_t se gestiona automáticamente para la aplicación impresora. La función papplSystemCreate crea un nuevo sistema mientras que la función papplSystemDelete elimina un sistema.

La función papplSystemRun inicia un sistema mientras que la función papplSystemShutdown detiene un sistema en ejecución.

Las funciones papplSystemGet obtienen los valores actuales asociados con un sistema mientras que las funciones papplSystemSet establecen los valores actuales asociados con un sistema.

papplSystemAddListeners

Añadir oyentes de red o de socket de dominio.

bool  papplSystemAddListeners (
    pappl_system_t *system,
    const char *name
);

Esta función añade oyentes de socket. El parámetro "name" especifica la dirección del oyente. Los nombres que empiezan con una barra (/) especifican una ruta de socket de dominio UNIX, de lo contrario el nombre se trata como un nombre de dominio completamente cualificado o una dirección numérica IPv4 o IPv6. Si name es NULL, se utilizan las direcciones "any" ("0.0.0.0" y "[::]").

No se pueden añadir oyentes después de llamar a papplSystemRun.

papplSystemAddMIMEFilter

Añadir un filtro de archivos al sistema.

void papplSystemAddMIMEFilter (
    pappl_system_t *system,
    const char *srctype,
    const char *dsttype,
    pappl_mime_filter_cb_t cb,
    void *data
);

Esta función añade un filtro de archivos al sistema para ser utilizado en el procesamiento de diferentes tipos de datos de documentos en los trabajos de impresión. Los argumentos "srctype" y "dsttype" especifican los tipos de medios MIME de origen y destino como cadenas constantes. Un tipo de medio MIME de destino de "image/pwg-raster" especifica un filtro que usa la interfaz raster del controlador. Otros tipos de destino implican la presentación directa al dispositivo de salida utilizando las funciones papplDeviceXxx.

5
Nota: Esta función no se puede llamar mientras el sistema se está ejecutando.

papplSystemAddTimerCallback

Añadir una llamada de retorno de temporizador a un sistema.

bool  papplSystemAddTimerCallback (
    pappl_system_t *system,
    time_t start,
    int interval,
    pappl_timer_cb_t cb,
    void *cb_data
);

Esta función programa una función que se llamará en el hilo del bucle principal de ejecución en el momento especificado y, opcionalmente, cada "interval" segundos a partir de entonces. La precisión del tiempo es típicamente de unos pocos milisegundos, pero no está garantizada. Dado que la llamada de retorno se ejecuta en el hilo del bucle principal de ejecución, las funciones deben crear un nuevo hilo para cualquier operación de larga duración.

La función de llamada de retorno recibe los punteros "system" y "cb_data" y devuelve true para repetir el temporizador o false para eliminarlo:

    bool my_timer_cb(pappl_system_t *system, void *cb_data)
    {
      ... hacer tarea periódica ...
      return (true); // repetir el temporizador
    }

papplSystemCreate

Crear un objeto de sistema.

pappl_system_t * papplSystemCreate (
    pappl_soptions_t options,
    const char *name,
    int port,
    const char *subtypes,
    const char *spooldir,
    const char *logfile,
    pappl_loglevel_t loglevel,
    const char *auth_service,
    bool tls_only
);

Esta función crea un nuevo objeto de sistema, que es responsable de gestionar todas las impresoras, trabajos y recursos utilizados por la aplicación de impresión.

El argumento "options" especifica qué opciones están habilitadas para el servidor:

  • PAPPL_SOPTIONS_NONE: Sin opciones.
  • PAPPL_SOPTIONS_DNSSD_HOST: Al resolver colisiones de nombres de servicio DNS-SD,
    usa el nombre de host DNS-SD en lugar de un número de serie o UUID.
  • PAPPL_SOPTIONS_WEB_LOG: Incluir la página web del archivo de registro.
  • PAPPL_SOPTIONS_MULTI_QUEUE: Soportar múltiples impresoras.
  • PAPPL_SOPTIONS_WEB_NETWORK: Incluir la página web de configuración de red.
  • PAPPL_SOPTIONS_RAW_SOCKET: Aceptar trabajos a través de sockets RAW comenzando en el puerto
    9100 (todos excepto Windows).
  • PAPPL_SOPTIONS_WEB_REMOTE: Permitir la gestión remota de colas.
  • PAPPL_SOPTIONS_WEB_SECURITY: Incluir la página web de configuración de seguridad.
  • PAPPL_SOPTIONS_WEB_INTERFACE: Incluir las páginas web estándar de monitorización de impresoras y trabajos
    .
  • PAPPL_SOPTIONS_WEB_TLS: Incluir la página de configuración TLS.
  • PAPPL_SOPTIONS_USB_PRINTER: Aceptar trabajos a través de USB para la impresora predeterminada
    (solo Linux embebido).

El argumento "name" especifica un nombre legible por humanos para el sistema.

El argumento "port" especifica el número de puerto al que enlazar. Un valor de 0 hará que se asigne un número de puerto disponible cuando se añada el primer oyente con la función papplSystemAddListeners.

El argumento "subtypes" especifica uno o más subtipos de servicio DNS-SD delimitados por comas, como "_print" y "_universal".

El argumento "spooldir" especifica la ubicación de los archivos de trabajo. Si es NULL, se crea un directorio temporal.

El argumento "logfile" especifica dónde enviar los mensajes de registro. Si es NULL, los mensajes de registro se escriben en un archivo temporal.

El argumento "loglevel" especifica el nivel de registro inicial.

El argumento "auth_service" especifica un nombre de servicio de autenticación PAM. Si es NULL, no se proporcionará autenticación de usuario.

El argumento "tls_only" controla si la aplicación de impresión aceptará conexiones sin cifrar. En general, este argumento siempre debe ser false (permitir conexiones sin cifrar) ya que no todos los clientes soportan la impresión cifrada.

papplSystemGetMaxLogSize

Obtiene el tamaño máximo del archivo de registro.

size_t  papplSystemGetMaxLogSize (
    pappl_system_t *system
);

Esta función obtiene el tamaño máximo del archivo de registro, que solo se utiliza al registrar directamente en un archivo. Cuando se alcanza el límite, el archivo de registro actual se renombra a "filename.O" y se crea un nuevo archivo de registro. Establezca el tamaño máximo en 0 para deshabilitar la rotación del archivo de registro.

El tamaño máximo predeterminado del archivo de registro es 1MiB o 1048576 bytes.

papplSystemSetWiFiCallbacks

Set Wi-Fi callbacks.

void papplSystemSetWiFiCallbacks (
    pappl_system_t *system,
    pappl_wifi_join_cb_t join_cb,
    pappl_wifi_list_cb_t list_cb,
    pappl_wifi_status_cb_t status_cb,
    void *data
);

This function sets the 802.11 Wi-Fi interface callbacks for the system. The "join_cb" is used to join a Wi-Fi network, the "list_cb" is used to list available networks, and the "status_cb" is used to query the current Wi-Fi network connection status and Secure Set Identifier (SSID). The "join_cb" and "status_cb" functions are used to support getting and setting the IPP "printer-wifi-state", "printer-wifi-ssid", and "printer-wifi-password" attributes, while the "list_cb" function enables changing the Wi-Fi network from the network web interface, if enabled.

Note: The Wi-Fi callbacks can only be set prior to calling papplSystemRun.
