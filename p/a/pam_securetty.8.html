NOMBRE

pam_securetty - Limita el inicio de sesión de root a dispositivos especiales

SINOPSIS

pam_securetty.so [debug]

DESCRIPCIÓN

pam_securetty es un módulo PAM que permite el inicio de sesión de root solo si el usuario está iniciando sesión en una tty "segura", tal como se define en la lista del archivo securetty. pam_securetty comprueba primero si existe /etc/securetty. Si no, y si se compiló con soporte vendordir, utilizará /securetty. pam_securetty también comprueba que los archivos securetty sean archivos normales y no escribibles por todos. También permitirá inicios de sesión de root en la tty especificada con el interruptor console= en la línea de comandos del kernel y en las ttys de /sys/class/tty/console/active.

Este módulo no tiene efecto en usuarios que no sean root y requiere que la aplicación complete correctamente el elemento PAM_TTY.

Para un uso canónico, debe incluirse como un método de autenticación requerido antes de cualquier método de autenticación suficiente.

OPCIONES

debug

Imprime información de depuración.

noconsole

No permita automáticamente los inicios de sesión de root en el dispositivo de consola del kernel, según se especifica en la línea de comandos del kernel o en el archivo sys, si no está también especificado en el archivo securetty.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_SUCCESS

Se permite al usuario continuar la autenticación. O bien el usuario no es root, o el usuario root está intentando iniciar sesión en un dispositivo aceptable.

PAM_AUTH_ERR

La autenticación es rechazada. O bien root está intentando iniciar sesión a través de un dispositivo inaceptable, o el archivo securetty es escribible por todos o no es un archivo normal.

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación no pudo obtener el nombre de usuario.

PAM_INCOMPLETE

El método de conversación proporcionado por la aplicación devolvió PAM_CONV_AGAIN.

PAM_SERVICE_ERR

Ocurrió un error mientras el módulo determinaba el nombre de usuario o la tty, o el módulo no pudo abrir el archivo securetty.

PAM_USER_UNKNOWN

El módulo no pudo encontrar el nombre de usuario en el archivo /etc/passwd para verificar si el usuario tenía un UID de 0. Por lo tanto, los resultados de la ejecución de este módulo se ignoran.

EJEMPLOS

auth  required  pam_securetty.so
auth  required  pam_unix.so

VER TAMBIÉN

securetty(5), pam.conf(5), pam.d(5), pam(8)
