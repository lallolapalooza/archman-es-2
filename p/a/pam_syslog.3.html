NOMBRE

pam_syslog, pam_vsyslog - enviar mensajes al registrador del sistema

SINOPSIS

#include <syslog.h>
#include <security/pam_ext.h>

void pam_syslog(const pam_handle_t *pamh, int priority, const char *fmt, ...);

void pam_vsyslog(const pam_handle_t *pamh, int priority, const char *fmt, va_list args);

DESCRIPCIÓN

La función pam_syslog registra mensajes usando syslog(3) y está destinada para uso interno de Linux-PAM y los módulos de servicio PAM. El argumento priority se forma combinando (mediante OR) los valores de instalación y nivel, como se documenta en la página del manual syslog(3).

La función pam_vsyslog realiza la misma tarea que pam_syslog(), con la diferencia de que toma un conjunto de argumentos que se han obtenido utilizando las macros de lista de argumentos variables de stdarg(3).

VER TAMBIÉN

pam(8)

ESTÁNDARES

Las funciones pam_syslog y pam_vsyslog son extensiones de Linux-PAM.
