PACKETFORGE-NG(1) Manual de comandos generales PACKETFORGE-NG(1)

NOMBRE

packetforge-ng - forjar paquetes: ARP, UDP, ICMP o paquetes personalizados.

SINOPSIS

packetforge-ng <modo> <opciones>

DESCRIPCIÓN

packetforge-ng es una herramienta para crear paquetes cifrados que posteriormente pueden ser utilizados para inyección. Puede crear varios tipos de paquetes como solicitudes ARP, UDP, ICMP y paquetes personalizados. El uso más común es crear solicitudes ARP para inyección posterior.

Para crear un paquete cifrado, debe tener un archivo PRGA (algoritmo de generación pseudoaleatoria). Este se utiliza para cifrar el paquete que crea. Normalmente se obtiene de los ataques chopchop o de fragmentación de aireplay-ng.

OPCIONES

-H, --help
Muestra la pantalla de ayuda.
-p <fctrl>
Establece la palabra de control de trama (hexadecimal)
-a <bssid>
Establece la dirección MAC del Punto de Acceso
-c <dmac>
Establece la dirección MAC de destino
-h <smac>
Establece la dirección MAC de origen
-j
Establece el bit FromDS
-o
Borra el bit ToDS
-e
deshabilita el cifrado WEP
-k <ip:[puerto]>
Establece la IP (y el puerto) de destino
-l <ip:[puerto]>
Establece la IP (y el puerto) de origen
-w <archivo>
Escribe el paquete en este archivo pcap
-r <archivo>
Lee el paquete de este archivo pcap
-y <archivo>
Lee PRGA de este archivo
-t <ttl>
Establece el Tiempo de Vida en la cabecera IP
-s <tamaño>
Establece el tamaño del paquete nulo generado.
-0, --arp
Forjar un paquete ARP
-1, --udp
Forjar un paquete UDP
-2, --icmp
Forjar un paquete ICMP
-3, --null
Forjar un paquete llc nulo
-9, --custom
Construir un paquete personalizado, requiere -r para leer un trama sin cifrar de un archivo pcap.

EJEMPLO

packetforge-ng -y test.xor -a 00:09:5b:12:40:cc -h 00:10:2a:cb:30:14 -k 192.168.1.100 -l 192.168.1.1 -w arp-request.cap
