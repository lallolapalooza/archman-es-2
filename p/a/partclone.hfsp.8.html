PARTCLONE(8) Manual del usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - Utilidad para clonar y restaurar particiones.

SINOPSIS

partclone.[tipo_sistema_archivos] {[-c | --clonar] [-r | --restaurar] [-b | --dev-a-dev]} {[-s | --fuente] fuente} {[[-o | --salida] [-O | --sobrescribir]] destino} [[-dX | --depurar=X] [--restaurar_archivo_raw] [-z | --tamano_buffer] [-N | --ncurses] [-q | --silencioso] [-f | --UI-refrescar] [-F | --forzar] [-I | --ignorar_verificacion_fs] [-i | --ignorar_crc] [-C | --sin_verificacion] [-R | --rescatar] [-L | --archivo_log] archivo_log [-R | --rescatar] [-L | --archivo_log] archivo_log [-X | --comando_compresion] [-D | --dominio] [--offset_dominio] [-aX | --modo_checksum=X] [-kX | --bloques_por_checksum=X] [-K | --sin_resembrar] [-w | --ignorar_errores_escritura] [-E | --offset=X] [-T | --archivos_bt] [-t | --torrent_archivos_bt] [-n | --nota] [-B | --sin_detalle_bloques] [--prefijo_binario] [--segundo_progreso] [--escritura_directa_io] [--lectura_directa_io]]

DESCRIPCIÓN

partclone.[tipo_sistema_archivos] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS DE APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_sistema_archivos], similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos           partclone.[tipo_sistema_archivos]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (Sistemas de Archivos No Soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --fuente ARCHIVO

ARCHIVO fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de tu acción. Normalmente, la fuente de la copia de seguridad es un dispositivo, la fuente de la restauración es un archivo de imagen.

La recepción de datos desde una tubería (pipe) está soportada SÓLO para restaurar, simplemente ignora la opción -s o usa '-' para recibir datos desde la entrada estándar (stdin).

-o ARCHIVO, --salida ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de tu acción. Normalmente, la salida de la copia de seguridad va a un archivo de imagen y la salida de la restauración va a un dispositivo.

El envío de datos a una tubería (pipe) también está soportado SÓLO para copias de seguridad, simplemente ignora la opción -o o usa '-' para enviar datos a la salida estándar (stdout).

-O ARCHIVO, --sobrescribir ARCHIVO

Sobrescribe el ARCHIVO, si existe.

-W ARCHIVO, --restaurar_archivo_raw ARCHIVO

Crea un archivo raw especial para el dispositivo de bucle (loop device).

-c, --clonar

Guarda la partición en el formato de imagen especial.

-r, --restaurar

Restaura la partición desde el formato de imagen especial.

-b, --dev-a-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --dominio

Crea un archivo de log de dominio GNU Ddrescue a partir del dispositivo fuente. Este es un archivo legible por humanos en el que + marca áreas usadas y ? marca áreas libres.

--offset_dominio=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de log de dominio.

--restaurar_archivo_raw

Creando un archivo raw especial para el dispositivo de bucle.

-L ARCHIVO, --archivo_log ARCHIVO

Coloca una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescatar

Continúa después de errores de lectura del disco.

-C, --sin_verificacion

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usa una interfaz de usuario de texto Ncurses.

-I, --ignorar_verificacion_fs

Ignora la verificación del sistema de archivos.

-i, --ignorar_crc

Ignora el error de verificación CRC.

-F, --forzar

Fuerza el progreso.

-f seg, --UI-refrescar seg

Establece un intervalo de segundos para refrescar la interfaz.

-z tamano, --tamano_buffer tamano

Tamaño del buffer de lectura/escritura (por defecto: 1048576)

-q, --silencioso

Desactiva los mensajes de progreso.

-dnivel, --depurar nivel

Establece el nivel de depuración [1|2|3]

-x, --comando_compresion CMD

Inicia CMD como una tubería (pipe) de salida para comprimir la imagen clonada.

-aX, --modo_checksum=X

Fórmula de checksum a utilizar para añadir detección de errores.

donde X:

0: Sin checksum (sin ralentización, imagen más pequeña)

1: CRC32 (Cálculo rápido, detección básica)

2: xxHash, algoritmo de hash no criptográfico extremadamente rápido

-kX, --bloques_por_checksum=X

Escribe un checksum por cada X bloques.

-w, --ignorar_errores_escritura

Continúa la restauración mientras hay errores de escritura.

--escritura_directa_io

Escribe datos en la partición de DESTINO sin caché.

--lectura_directa_io

Lee datos de la partición FUENTE sin caché.

-B, --sin_detalle_bloques

Muestra mensajes de progreso sin detalle de bloques.

--prefijo_binario

Muestra el progreso con tamaño de bits (por defecto es MB, GB...).

--segundo_progreso

Muestra el progreso en segundos (por defecto es minutos).

-E, --offset=X

Añade un offset X (bytes) a la SALIDA.

-T, --archivos_bt

Restaura bloques como archivos para ClonezillaBT.

-t, --torrent_archivos_bt

Restaura bloques como archivos para ClonezillaBT, pero solo genera el torrent.

-n, --nota NOTA

Muestra un mensaje de NOTA (128 palabras).

-h, --ayuda

Muestra un resumen de las opciones.

-v, --version

Muestra la versión

partclone.ext3(8)

NAME

partclone.ext3

a tool to clone, save, restore and check ext3 file system

SYNOPSIS

partclone.ext3 [ -c | -r ] [ -s <source> ] [ -o <destination> ] [ -L <logfile> ] [ -d ] [ -z <compress_level> ] [ -N <number_of_files> ]

DESCRIPTION

partclone.ext3 is a tool to clone, save, restore and check ext3 file system. It is designed to save and restore partitions. It works only on ext3 file system. It is part of the partclone package.

partclone.ext3 saves and restores the used blocks of the partition. It means it can save files system from a partition to a file, or restore a file system from a file to a partition. It supports checking, compression and splitting the image file.

For more details, please refer to the partclone man page.

OPTIONS

-c
Clone/save the file system.
-r
Restore the file system.
-s source
The source device or file name.
-o destination
The destination device or file name.
-L logfile
The log file.
-d
Display debug information.
-z compress_level
Compression level (0-9). 0 means no compression.
-N number_of_files
Split the image file into a specified number of files.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
