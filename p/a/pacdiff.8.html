PACDIFF(8) Manual de Pacman-contrib PACDIFF(8)

NOMBRE

pacdiff - utilidad de mantenimiento de pacorig, pacnew y pacsave

SINOPSIS

pacdiff [opciones]

DESCRIPCIÓN

pacdiff es un script que busca archivos pacorig, pacnew y pacsave de las entradas de copia de seguridad encontradas en la base de datos local de pacman. Para cada archivo encontrado, se ofrece la opción de ver, fusionar, omitir, diferenciar, eliminar o sobrescribir el archivo pacorig, pacnew o pacsave encontrado.

OPCIONES

Opciones de búsqueda

-f, --find

Escanea usando find.

-l, --locate

Escanea usando locate.

-p, --pacmandb

Escanea los archivos de configuración activos de la base de datos de pacman. (predeterminado)

Opciones generales

-b, --backup

Al sobrescribir, guarda los archivos antiguos con .bak.

-c, --cachedir <dir>

Escanea dir en lugar de la caché de pacman como candidatos para la base de la fusión de 3 vías.

-h, --help

Muestra la sintaxis y las opciones de la línea de comandos.

--nocolor

No colorear la salida.

-o, --output

Imprime archivos en lugar de fusionarlos.

-s, --sudo

Usa sudo y sudoedit para fusionar/eliminar archivos.

-3, --threeway

Muestra diferencias en modo de 3 vías si el paquete base está disponible en la caché. Si no, recurre a la diferencia normal de 2 vías.

-V, --version

Muestra información de la versión.

ENTORNO

DIFFPROG

Anula el programa de diferencias predeterminado vim -d, o nvim -d si EDITOR=nvim.

DIFFSEARCHPATH

Anula la ruta de búsqueda predeterminada /etc, solo cuando se usa find.

MERGEPROG

Anula el programa de fusión de 3 vías predeterminado diff3 -m. Una alternativa posible es git merge-file -p.

VER TAMBIÉN

pacman(8), pacman.conf(5)
