pause(2) Manual de llamadas al sistema pause(2)

NOMBRE

pause - esperar señal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int pause(void);

DESCRIPCIÓN

pause() hace que el proceso (o hilo) que llama duerma hasta que se entregue una señal que termine el proceso o provoque la invocación de una función de captura de señales.

VALOR DE RETORNO

pause() retorna solo cuando se capturó una señal y la función de captura de señales retornó. En este caso, pause() retorna -1 y errno se establece en EINTR.

ERRORES

EINTR
se capturó una señal y la función de captura de señales retornó.

ESTÁNDARES

POSIX.1-2024.

HISTORIAL

POSIX.1-2001, SVr4, 4.3BSD.

VER TAMBIÉN

kill(2), select(2), signal(2), sigsuspend(2)
