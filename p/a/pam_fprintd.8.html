NOMBRE

pam_fprintd - Módulo PAM para autenticarse contra fprintd, el demonio de huellas dactilares

SINOPSIS

pam_fprintd.so [debug|debug=[on|off|true|false|1|0]] [max-tries=MAX_TRIES] [timeout=TIMEOUT]

DESCRIPCIÓN

El módulo pam_fprintd se utiliza para verificar las huellas dactilares de un usuario contra las huellas dactilares inscritas utilizando fprintd, el demonio de gestión de huellas dactilares.

OPCIONES

debug
debug=[on|off|true|false|1|0]
Si se activa o desactiva la depuración. Los mensajes de depuración se generarán utilizando pam_syslog, lo que significa que se guardarán en el journal de systemd por defecto.
max-tries=MAX_TRIES
El número de intentos de autenticación por huella dactilar a probar antes de devolver un fallo de autenticación. El número mínimo de intentos es 1, mientras que el valor por defecto es 3.

Utilice un valor negativo para no establecer ningún límite, de modo que el módulo nunca devuelva un error por múltiples reintentos, pero en tal caso se sugiere que el cargador del módulo maneje esto.

timeout=TIMEOUT
El tiempo antes de devolver un fallo de autenticación. El tiempo de espera por defecto es de 30 segundos, con 1 segundo como mínimo.

Utilice un valor negativo para no establecer ningún límite, de modo que la autenticación por huella dactilar esté siempre activa mientras este módulo esté cargado.

LIMITACIONES

La pila PAM es, por diseño, una autenticación serializada, por lo que no es posible que pam_fprintd permita la autenticación a través de contraseñas y huellas dactilares al mismo tiempo.

Corresponde a la aplicación que utiliza los servicios PAM implementar procesos PAM separados y ejecutar pilas de autenticación separadas de forma independiente. Esta es la forma en que se ponen a disposición múltiples métodos de autenticación para los usuarios de gdm, por ejemplo.
