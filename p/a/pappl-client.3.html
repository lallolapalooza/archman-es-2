DESCRIPCIÓN

Las funciones del cliente PAPPL proporcionan acceso a las conexiones del cliente. Las conexiones del cliente y el ciclo de vida de los objetos pappl_client_t son gestionados automáticamente por el objeto del sistema para la aplicación de la impresora.

Las funciones papplClientGet obtienen los valores actuales de varios datos de solicitud proporcionados por el cliente.

RESPUESTA A LAS SOLICITUDES DEL CLIENTE

La función papplClientRespond inicia una respuesta HTTP a una solicitud del cliente. Las funciones papplClientHTMLHeader y papplClientHTMLFooter envían encabezados y pies de página HTML estándar para la interfaz web configurada de la aplicación de la impresora, mientras que las funciones papplClientHTMLEscape, papplClientHTMLPrintf, papplClientHTMLPuts y papplClientHTMLStartForm envían mensajes o cadenas HTML. Utilice las funciones papplClientGetHTTP y (CUPS) httpWrite2 para enviar datos arbitrarios en una respuesta del cliente. Las cookies se pueden incluir en las solicitudes del navegador web utilizando la función papplClientSetCookie.

La función papplClientRespondIPP inicia una respuesta IPP. Utilice las diversas funciones ippAdd de CUPS para agregar atributos al mensaje de respuesta.

La función papplClientRespondRedirect envía una respuesta de redirección al cliente.

FORMULARIOS HTML

PAPPL proporciona las funciones papplClientGetCSRFToken, papplClientGetForm, papplClientHTMLStartForm y papplClientValidateForm para gestionar de forma segura los formularios HTML.

La función papplClientHTMLStartForm inicia un formulario HTML e inserta una variable oculta que contiene un token CSRF que fue generado por PAPPL a partir de una clave de sesión segura que se actualiza periódicamente. Al recibir una solicitud de envío de formulario posterior, las funciones papplClientGetForm y papplClientValidateForm se pueden utilizar para leer de forma segura los datos del formulario (incluidos los archivos adjuntos) y validar el token CSRF oculto.

AUTENTICACIÓN Y AUTORIZACIÓN

PAPPL admite tanto la autenticación basada en usuarios utilizando módulos PAM como un mecanismo simple de autenticación por contraseña basada en cookies que se utiliza para limitar el acceso administrativo a través de la interfaz web.

La función papplHTMLAuthorize autoriza el acceso a la interfaz web y se encarga de mostrar un formulario de autenticación en el navegador web del cliente. El valor de retorno indica si el cliente está autorizado a acceder a la página web.

La función papplIsAuthorized se puede utilizar para determinar si el cliente actual está autorizado a realizar operaciones administrativas y normalmente solo se utiliza para clientes IPP. Los usuarios locales siempre están autorizados, mientras que los usuarios remotos deben proporcionar credenciales (típicamente un nombre de usuario y una contraseña) para acceder. Esta función devolverá un código de estado HTTP que se puede proporcionar a la función httpClientSendResponse. El valor HTTP_STATUS_CONTINUE indica que la autorización se concede y la solicitud debe continuar. La función papplGetUsername se puede utilizar para obtener la identidad del usuario autenticado.

FUNCIONES

papplClientGetCSRFToken

Obtiene un token único de prevención de falsificación de solicitudes entre sitios (CSRF)
cadena.

char * papplClientGetCSRFToken (
    pappl_client_t *client,
    char *buffer,
    size_t bufsize
);

Esta función genera y devuelve una cadena de token único de prevención de falsificación de solicitudes entre sitios (CSRF) para ser utilizada como el valor de una variable oculta en todos los formularios HTML enviados en la respuesta y luego comparada al validar los datos del formulario en la solicitud subsiguiente.

El valor se basa en la clave de sesión del sistema actual y la dirección del cliente para hacer que los ataques de repetición sean inviables.

5
Nota: La función papplClientHTMLStartForm agrega automáticamente la
5
variable CSRF oculta, y la función papplClientIsValidForm
5
valida el valor.

papplClientGetCookie

Obtiene una cookie del cliente.

char * papplClientGetCookie (
    pappl_client_t *client,
    const char *name,
    char *buffer,
    size_t bufsize
);

Esta función obtiene el valor de una "cookie" HTTP de la solicitud del cliente. Se devuelve NULL si no se ha establecido ninguna cookie en una solicitud anterior, o si el usuario ha deshabilitado o eliminado la cookie.

Utilice la función papplClientSetCookie para establecer una cookie en una re

esponse to a request.

5
Note: Cookies set with papplClientSetCookie will not be available to
5
this function until the following request.

papplClientGetForm

Get form data from the web client.

int  papplClientGetForm (
    pappl_client_t *client,
    cups_option_t **form
);

For HTTP GET requests, the form data is collected from the request URI. For HTTP POST requests, the form data is read from the client.

The returned form values must be freed using the cupsFreeOptions function.

5
Note: Because the form data is read from the client connection, this
5
function can only be called once per request.

DESCRIPTION

These functions are used by web applications to communicate with web browser clients.

Use the pappl_client_t type to represent the client connection. All functions require a pointer to a valid pappl_client_t object.

The papplClientHTMLPrintf function sends formatted text to the web browser client using printf-style formatting codes. The format string itself is not escaped to allow for embedded HTML, however strings inserted using the '%c' or %s codes are escaped properly for HTML - "&" is sent as &amp;, etc.

Use papplClientHTMLPuts to send a HTML string to the client without performing any escaping of special characters.

The papplClientHTMLStartForm function starts a HTML form with the specified "action" path and includes the CSRF token as a hidden variable. If the "multipart" argument is true, the form is annotated to support file attachments up to 2MiB in size.

Use the papplClientIsValidForm function to validate the contents of a HTML form using the CSRF token included as a hidden variable. When sending a HTML form you should use the papplClientStartForm function to start the HTML form and insert the CSRF token for later validation.

The papplClientIsAuthorized function determines whether a client is authorized to submit an administrative request.

The papplClientIsEncrypted function returns a boolean value indicating whether a Client connection is encrypted with TLS.

Use papplClientRespond to send a regular HTTP response. This function sends all of the required HTTP fields and includes standard messages for errors. The following values for "code" are explicitly supported:

  • HTTP_STATUS_OK: The request is successful.
  • HTTP_STATUS_BAD_REQUEST: The client submitted a bad request.
  • HTTP_STATUS_CONTINUE: An authentication challenge is not needed.
  • HTTP_STATUS_FORBIDDEN: Authenticated but not allowed.
  • HTTP_STATUS_METHOD_NOT_ALLOWED: The HTTP method is not supported for the
    given URI.
  • HTTP_STATUS_UNAUTHORIZED: Not authenticated.
  • HTTP_STATUS_UPGRADE_REQUIRED: Redirects the client to a secure page.

Use the papplClientRespondRedirect when you need to redirect the client to another page.

The papplClientRespondIPP function sets the return status for an IPP request and returns the current IPP response message. The "status" and "message" arguments replace any existing status-code and "status-message" attribute value that may be already present in the response.

Use papplClientRespondIPPUnsupported to respond with a 'client-error-attributes-or-values-not-supported' status code and add the specified attribute to the unsupported attributes group in the response.

The papplClientSetCookie function sets the value of a cookie for the client by updating the Set-Cookie header in the HTTP response that will be sent. The "name" and "value" strings must contain only valid characters for a cookie and its value as documented in RFC 6265, which basically means letters, numbers, "@", "-", ".", and "_".

The "expires" argument specifies how long the cookie will remain active in seconds, for example 3600 seconds is one hour and 86400 seconds is one day. If the value is zero or less, a "session" cookie is created instead which will expire as soon as the web browser is closed.

Use papplClientSetUsername to set the current authenticated username, if any.

The papplSystemAddLink function adds system-wide navigation links to the header. Similarly, use papplPrinterAddLink to add printer-specific links, which will appear in the web interface printer if the system is not configured to support multiple printers (the PAPPL_SOPTIONS_MULTI_QUEUE option to papplSystemCreate).

This function sends the standard web interface header and title for a printer. If the "refresh" argument is greater than zero, the page will automatically reload after that many seconds.

If "label" and "path_or_url" are non-NULL strings, an additional navigation link is included with the title header - this is typically used for an action button ("Change").

pappl-client - Bibliotecas de clientes de PAPPL

DESCRIPCIÓN

La biblioteca pappl-client proporciona funciones para interactuar con un servidor PAPPL. PAPPL (Printing Application Plumbing) es un sistema para crear aplicaciones de impresión multiplataforma.

USO

Las aplicaciones pueden usar las funciones proporcionadas por pappl-client para descubrir impresoras PAPPL en la red, enviar trabajos de impresión y administrar impresoras.

FUNCIONES

A continuación se muestra una lista de algunas de las funciones clave proporcionadas por pappl-client:

Descubrimiento de impresoras

  • pappl_client_discover_printers(): Busca impresoras PAPPL en la red.
  • pappl_client_get_printer_info(): Obtiene información detallada sobre una impresora específica.

Envío de trabajos de impresión

  • pappl_client_print_file(): Envía un archivo para imprimir a una impresora PAPPL.
  • pappl_client_print_data(): Envía datos de impresión (por ejemplo, un buffer de memoria) a una impresora PAPPL.

Administración de impresoras

  • pappl_client_cancel_job(): Cancela un trabajo de impresión pendiente.
  • pappl_client_get_job_status(): Obtiene el estado de un trabajo de impresión.
  • pappl_client_get_printers(): Obtiene una lista de todas las impresoras gestionadas por el servidor PAPPL.

RESPUESTA A SOLICITUDES DEL CLIENTE

pappl-client maneja las solicitudes del lado del cliente para interactuar con el servidor PAPPL. Esto incluye el envío de solicitudes para obtener información de la impresora, enviar trabajos de impresión y administrar colas de impresión.

FORMULARIOS HTML

PAPPL utiliza formularios HTML para la administración web de impresoras. La biblioteca pappl-client puede ser utilizada indirectamente por aplicaciones que interactúan con estas interfaces web para enviar configuraciones o iniciar acciones.

AUTENTICACIÓN Y AUTORIZACIÓN

pappl-client admite la autenticación y autorización para acceder a las funciones del servidor PAPPL. Los mecanismos de seguridad pueden incluir nombres de usuario, contraseñas u otros métodos de autenticación compatibles con el servidor.

FUNCIONES

Las funciones proporcionadas por esta biblioteca están diseñadas para ser fáciles de usar y eficientes, permitiendo una integración fluida con aplicaciones de impresión existentes y nuevas.
