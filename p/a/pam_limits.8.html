NOMBRE

pam_limits - Módulo PAM para limitar recursos

SINOPSIS

pam_limits.so [conf=/ruta/a/limits.conf] [debug] [set_all] [utmp_early] [noaudit]

DESCRIPCIÓN

El módulo PAM pam_limits establece límites en los recursos del sistema que se pueden obtener en una sesión de usuario. Los usuarios con uid=0 también se ven afectados por estos límites.

Por defecto, los límites se toman del archivo de configuración /etc/security/limits.conf. Luego se leen archivos *.conf individuales del directorio /etc/security/limits.d/. Los archivos se analizan uno tras otro según el orden del local "C". El efecto de los archivos individuales es el mismo que si todos los archivos se hubieran concatenado en el orden de análisis. Si se especifica explícitamente un archivo de configuración con una opción del módulo, no se analizan los archivos del directorio anterior.

El módulo no debe ser llamado por una aplicación multihilo.

Si Linux PAM se compila con soporte de auditoría, el módulo informará cuando niegue el acceso basándose en el límite del número máximo de sesiones de inicio de sesión concurrentes.

OPCIONES

conf=/ruta/a/limits.conf

Indica un archivo de configuración alternativo estilo limits.conf para anular el predeterminado.

debug

Imprime información de depuración.

set_all

Establece los límites para los que no se especifica ningún valor en el archivo de configuración al del proceso con PID 1. Tenga en cuenta que si el proceso init es systemd, estos límites no serán los límites predeterminados del kernel y esta opción no debe usarse.

utmp_early

Algunas aplicaciones defectuosas en realidad asignan una entrada utmp para el usuario antes de que sea admitido en el sistema. Si algunos de los servicios para los que está configurando PAM hacen esto, puede utilizar selectivamente este argumento del módulo para compensar este comportamiento y al mismo tiempo mantener la coherencia a nivel de sistema con un único archivo limits.conf.

noaudit

No informar al subsistema de auditoría sobre el recuento excedido de inicios de sesión máximos.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo session.

VALORES DE RETORNO

PAM_ABORT

No se pueden obtener los límites actuales.

PAM_IGNORE

No se encontraron límites para este usuario.

PAM_PERM_DENIED

No se pudieron establecer los nuevos límites.

PAM_SERVICE_ERR

No se pudo leer el archivo de configuración.

PAM_SESSION_ERR

Error al recuperar el nombre de la cuenta.

PAM_SUCCESS

Se cambiaron los límites.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

ARCHIVOS

/etc/security/limits.conf

Archivo de configuración predeterminado

EJEMPLOS

Para los servicios que necesiten límites de recursos (login, por ejemplo) coloque la siguiente línea en /etc/pam.d/login como última línea para ese servicio (generalmente después de la línea de sesión pam_unix):

#%PAM-1.0
#
# Límites de recursos impuestos a las sesiones de inicio de sesión a través de pam_limits
#
session  required  pam_limits.so

Reemplace "login" por cada servicio en el que esté utilizando este módulo.

VER TAMBIÉN

limits.conf(5), pam.d(5), pam(8).
