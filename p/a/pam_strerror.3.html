NOMBRE

pam_strerror - devuelve una cadena que describe el código de error de PAM

SINOPSIS

#include <security/pam_appl.h>

const char *pam_strerror(pam_handle_t *pamh, int errnum);

DESCRIPCIÓN

La función pam_strerror devuelve un puntero a una cadena que describe el código de error pasado en el argumento errnum, posiblemente usando la parte LC_MESSAGES de la configuración regional actual para seleccionar el idioma apropiado. Esta cadena no debe ser modificada por la aplicación. Ninguna función de la biblioteca modificará esta cadena.

VALORES DE RETORNO

Esta función siempre devuelve un puntero a una cadena.
