PACREPAIRDB(1) pacrepairdb PACREPAIRDB(1)

NOMBRE

pacrepairdb - arreglar entradas corruptas de la base de datos

SINOPSIS

pacrepairdb [opciones] <paquete>...
pacrepairdb (--help|--version)

DESCRIPCIÓN

Intenta reparar entradas de paquetes rotas en la base de datos de libalpm. Se crearán los archivos esenciales faltantes y se reinstalarán los paquetes desde la caché.

Si stdin no está conectado a una terminal, los nombres de los paquetes se leerán de stdin.

OPCIONES

--cachedir=ruta
Establece una ruta alternativa para el directorio de caché.
--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbonly
Realiza los cambios en la base de datos sin extraer ni eliminar ningún paquete.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--debug
Muestra información de depuración adicional.
--hookdir
Agrega directorios de hooks de usuario adicionales.
--logfile=ruta
Establece una ruta alternativa para el archivo de registro.
--no-confirm
Asume respuestas predeterminadas a todas las preguntas.
--no-scriptlet
No ejecuta scripts de instalación de paquetes.
--no-hooks
No ejecuta hooks de transacción.
--no-timeout
Deshabilita los tiempos de espera de baja velocidad para las descargas.
--print-only
Muestra los paquetes que se van a reparar y los paquetes de caché que se utilizarán y sale.
--root=ruta
Establece una ruta raíz de instalación alternativa.
--sysroot=ruta
Establece una ruta raíz del sistema alternativa. Ver pacutils-sysroot(7).
--verbose
Muestra información de progreso adicional.
--help
Muestra información de uso y sale.
--version
Muestra información de la versión y sale.

EJEMPLOS

Encuentra y reinstala paquetes rotos:

paccheck --list-broken --files --file-properties --db-files --require-mtree | pacrepairdb

ADVERTENCIAS

pacrepairdb espera que todos los paquetes que se reparan estén en la caché. Los paquetes en caché que coinciden con el nombre y la versión de un paquete instalado se asumen que son el mismo paquete. No se intenta validar los paquetes en caché. Si una caché contiene un paquete que no coincide con el paquete instalado, pero tiene el mismo nombre y versión, pacrepairdb lo instalará ciegamente, empeorando cualquier problema de la base de datos.

pacrepairdb no verifica los archivos huérfanos restantes. Es responsabilidad del usuario localizar y manejar los archivos huérfanos.

pacrepairdb determina si leer nombres de paquetes de stdin basándose en una comprobación ingenua usando isatty(3). Si pacrepairdb se llama en un entorno, como una función de shell o un script que se utiliza en una tubería, donde stdin no está conectado a una terminal pero no contiene nombres de paquetes para reparar, pacrepairdb debería llamarse con stdin cerrado. Para shells compatibles con POSIX, esto se puede hacer con "<&-".
