NOMBRE

pam_timestamp - Autenticar usando intentos de autenticación exitosos en caché

SINOPSIS

pam_timestamp.so [timestampdir=directorio] [timestamp_timeout=número] [verbose] [debug]

DESCRIPCIÓN

En pocas palabras, pam_timestamp almacena en caché los intentos de autenticación exitosos y te permite usar un intento exitoso reciente como base para la autenticación. Este es un mecanismo similar al que se usa en sudo.

Cuando una aplicación abre una sesión usando pam_timestamp, se crea un archivo de marca de tiempo en el directorio timestampdir para el usuario. Cuando una aplicación intenta autenticar al usuario, un pam_timestamp tratará un archivo de marca de tiempo suficientemente reciente como motivo para tener éxito.

OPCIONES

timestampdir=directorio

Especificar un directorio alternativo donde pam_timestamp crea archivos de marca de tiempo.

timestamp_timeout=número

Cuánto tiempo debe pam_timestamp considerar válida la marca de tiempo después de su última fecha de modificación (en segundos). El valor predeterminado es 300 segundos.

verbose

Intentar informar al usuario cuando se concede el acceso.

debug

Activa los mensajes de depuración enviados a syslog(3).

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo auth y session.

VALORES DE RETORNO

PAM_AUTH_ERR

El módulo no pudo recuperar el nombre de usuario o no se encontró ningún archivo de marca de tiempo válido.

PAM_SUCCESS

Todo fue exitoso.

PAM_SESSION_ERR

No se pudo crear o actualizar el archivo de marca de tiempo.

NOTAS

Los usuarios pueden confundirse cuando no se les piden contraseñas siempre al ejecutar un programa determinado. Algunos usuarios comienzan instintivamente a escribir información antes de notar que no se les está pidiendo.

EJEMPLOS

auth sufficient pam_timestamp.so verbose
auth required   pam_unix.so
session required pam_unix.so
session optional pam_timestamp.so

ARCHIVOS

/var/run/pam_timestamp/...

archivos y directorios de marca de tiempo
