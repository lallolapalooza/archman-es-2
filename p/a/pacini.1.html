NOMBRE

pacini - consultar archivos de configuración estilo pacman

SINOPSIS

pacini [opciones] [<archivo> [<directiva>...]]
pacini (--section-list|--help|--version)

DESCRIPCIÓN

Consulta opciones de configuración de archivos INI estilo pacman. Si no se proporcionan directivas, se imprimirá el archivo en un formato normalizado. Por defecto, si solo se proporciona una directiva, solo se imprimirá su valor sin el nombre de la opción. Para directivas sin valor, el nombre de la directiva se usará como valor. Si se omite el archivo o se usa "-", la configuración se leerá desde stdin.

OPCIONES

--section=nombre
Solo muestra las directivas listadas en la sección nombre.
--section-list
Lista las secciones configuradas.
--verbose
Siempre muestra los nombres de las directivas, incluso si solo se proporciona una directiva.
--help
Muestra información de uso y sale.
--version
Muestra información de versión y sale.
