NOMBRE

pam_tty_audit - Habilita o deshabilita la auditoría de TTY para usuarios especificados

SINOPSIS

pam_tty_audit.so [disable=patrones] [enable=patrones]

DESCRIPCIÓN

El módulo PAM pam_tty_audit se utiliza para habilitar o deshabilitar la auditoría de TTY. Por defecto, el kernel no audita la entrada en ninguna TTY.

OPCIONES

disable=patrones

Para cada usuario que coincida con los patrones, deshabilita la auditoría de TTY. Esto anula cualquier opción enable previa que coincida con el mismo nombre de usuario en la línea de comandos. Consulte NOTAS para una descripción más detallada de los patrones.

enable=patrones

Para cada usuario que coincida con los patrones, habilita la auditoría de TTY. Esto anula cualquier opción disable previa que coincida con el mismo nombre de usuario en la línea de comandos. Consulte NOTAS para una descripción más detallada de los patrones.

open_only

Establece la bandera de auditoría de TTY al abrir la sesión, pero no la restaura al cerrar la sesión. Usar esta opción es necesario para algunos servicios que no fork() para ejecutar la sesión autenticada, como sudo.

log_passwd

Registra las pulsaciones de teclas cuando el modo ECHO está desactivado pero el modo ICANON está activo. Este es el modo en el que se coloca la TTY durante la entrada de la contraseña. Por defecto, las contraseñas no se registran. Es posible que esta opción no esté disponible en kernels más antiguos (¿3.9?).

TIPOS DE MÓDULO PROPORCIONADOS

Solo se admite el tipo session.

VALORES DE RETORNO

PAM_SESSION_ERR

Error al leer o modificar la bandera de auditoría de TTY. Consulte el registro del sistema para obtener más detalles.

PAM_SUCCESS

Éxito.

NOTAS

Cuando la auditoría de TTY está habilitada, es heredada por todos los procesos iniciados por ese usuario. En particular, los demonios reiniciados por un usuario seguirán teniendo la auditoría de TTY habilitada, y auditarán la entrada de TTY incluso de otros usuarios, a menos que la auditoría para estos usuarios esté explícitamente deshabilitada. Por lo tanto, se recomienda usar disable=* como la primera opción para la mayoría de los demonios que usan PAM.

Para ver los datos que el kernel registró para auditar, use el comando aureport --tty.

Los patrones son listas separadas por comas de patrones glob o rangos de uid. Un rango se especifica como min_uid:max_uid donde uno de estos valores puede estar vacío. Si min_uid está vacío, solo se comparará al usuario con el uid max_uid. Si max_uid está vacío, se compararán usuarios con el uid mayor o igual a min_uid.

Tenga en cuenta que las contraseñas, en algunas circunstancias, pueden ser registradas por la auditoría de TTY incluso si no se utiliza log_passwd. Por ejemplo, toda la entrada a una sesión ssh se registrará, incluso si se está escribiendo una contraseña en algún software que se ejecuta en el host remoto, porque solo el estado de la TTY local afecta a la auditoría de la TTY local.

EJEMPLOS

Auditar todas las acciones administrativas.

session	required pam_tty_audit.so disable=* enable=root
