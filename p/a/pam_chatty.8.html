NOMBRE

pam_chatty - Un módulo de prueba PAM que genera mensajes de información y error de PAM.

SINOPSIS

pam_chatty.so [...]

DESCRIPCIÓN

El módulo pam_chatty facilita la replicación del comportamiento de los módulos PAM que generan mucha salida, para asegurar que los clientes PAM reaccionan como se espera.

IMPORTANTE

pam_chatty es una herramienta de prueba. Debe considerarse completamente inseguro y nunca debe usarse fuera de entornos de prueba. Como verá al leer la descripción de las opciones, muchas de ellas no tienen sentido en el mundo real y se agregaron solo para hacer posibles las pruebas.

El módulo pam_chatty genera mucha salida de información y error de PAM, cuando se llama a su método de autenticación, y luego devuelve éxito.

OPCIONES

•num_lines=NÚMERO - el número de líneas de mensajes a mostrar, para cada uno de los tipos de mensajes habilitados seleccionados.
•error - si se muestran mensajes de nivel de error.
•info - si se muestran mensajes de nivel de información.

TIPOS DE MÓDULOS PROPORCIONADOS

Solo se admite el tipo de módulo auth.

EJEMPLO

auth            required        pam_chatty.so num_lines=16 info error
