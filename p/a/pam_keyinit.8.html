NOMBRE

pam_keyinit - Módulo inicializador de keyring de sesión del Kernel

SINOPSIS

pam_keyinit.so [debug] [force] [revoke]

DESCRIPCIÓN

El módulo PAM pam_keyinit asegura que el proceso invocador tenga un keyring de sesión distinto del keyring de sesión predeterminado del usuario.

El módulo comprueba si el keyring de sesión del proceso es el user-session-keyring(7) y, si lo es, crea un nuevo session-keyring(7) para reemplazarlo. Si se crea un nuevo keyring de sesión, instalará un enlace al user-keyring(7) en el keyring de sesión para que las claves comunes al usuario sean automáticamente accesibles a través de él. El keyring de sesión del proceso invocador será en adelante heredado por todos sus hijos a menos que lo invaliden.

Para permitir que otros módulos PAM adjunten tokens al keyring, este módulo proporciona un componente de auth (limitado a pam_setcred(3)) y un componente de session. El keyring de sesión se crea en el módulo llamado. Además, este módulo debe incluirse lo antes posible en la configuración de PAM.

Este módulo está destinado principalmente a ser utilizado por procesos de inicio de sesión. Tenga en cuenta que después de que el keyring de sesión se reemplace, el antiguo keyring de sesión y las claves que contiene ya no serán accesibles.

En general, este módulo no debe ser invocado por programas como su, ya que normalmente es deseable que el conjunto de claves se filtre al contexto alternativo. Las claves tienen su propio sistema de permisos para gestionarlo.

El paquete keyutils se utiliza para manipular claves de forma más directa. Esto se puede obtener en:

Keyutils[1]

OPCIONES

debug

Registra información de depuración con syslog(3).

force

Causa que el keyring de sesión del proceso invocador sea reemplazado incondicionalmente.

revoke

Causa que el keyring de sesión del proceso invocador sea revocado cuando el proceso invocador sale, si el keyring de sesión fue creado para este proceso en primer lugar.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo session.

VALORES DE RETORNO

PAM_SUCCESS

Este módulo normalmente devolverá este valor

PAM_AUTH_ERR

Error de autenticación.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_IGNORE

PAM dispatch debe ignorar el valor de retorno.

PAM_SERVICE_ERR

No se puede determinar el nombre de usuario.

PAM_SESSION_ERR

Este módulo devolverá este valor si sus argumentos son inválidos o si ocurre un error del sistema como ENOMEM.

PAM_USER_UNKNOWN

Usuario desconocido.

EJEMPLOS

Agregue esta línea a sus entradas de inicio de sesión para iniciar cada sesión de inicio de sesión con su propio keyring de sesión:

session  required  pam_keyinit.so

Esto evitará que las claves de una sesión se filtren a otra sesión para el mismo usuario.
