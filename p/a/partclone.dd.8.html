PARTCLONE.DD(8) Manual de Usuario de Partclone PARTCLONE.DD(8)

NOMBRE

partclone.dd - utilidad de copia de seguridad de sistemas de archivos no soportados (similar a `dd`)

SINOPSIS

partclone.dd {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.dd es parte del proyecto Partclone para clonar sistemas de archivos no soportados con el método dd. Copiará todos los bloques de la partición. Partclone proporciona utilidades para hacer copias de seguridad de los bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer los bloques utilizados de una partición ext2.

Los sistemas de archivos soportados por Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS y FAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Todas las utilidades de partclone se pueden ejecutar como partclone.xxx, muy similar a fsck o mkfs. Por ejemplo, para hacer copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp.

OPCIONES

El programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s FICHERO, --source FICHERO

Archivo fuente. El FICHERO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de su acción. Normalmente, la fuente de copia de seguridad es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos de una tubería está soportada SOLO para la restauración, simplemente ignore la opción -s o use '-' que significa recibir datos de stdin.

-o FICHERO, --output FICHERO

Archivo de salida. El FICHERO puede ser un archivo de imagen (generado por partclone) o un dispositivo dependiendo de su acción. Normalmente, la salida de copia de seguridad es un archivo de imagen y la salida de restauración es un dispositivo.

El envío de datos a una tubería también está soportado SOLO para la copia de seguridad, simplemente ignore la opción -o o use '-' que significa enviar datos a stdout.

-O FICHERO, --overwrite FICHERO

Sobrescribir FICHERO, sobrescribiendo si existe.

-W FICHERO, --restore_raw_file FICHERO

Crear un archivo especial crudo para el dispositivo loop.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue a partir del dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloques utilizadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Creando un archivo especial crudo para el dispositivo loop.

-L FICHERO, --logfile FICHERO

Indica una ruta especial para registrar la información del registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No comprobar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar la interfaz de usuario de texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de la comprobación crc.

-F, --force

Forzar progreso.

-f seg, --UI-fresh seg

Indica un intervalo de segundos para actualizar.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar mensajes de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

-kX, --blocks-per-checksum=X

Escribir una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continuar la restauración mientras haya errores de escritura.

--write-direct-io

Escribir datos en la partición de DESTINO sin caché.

--read-direct-io

Leer datos desde la partición de FUENTE sin caché.

-B, --no_block_detail

Mostrar mensaje de progreso sin detalle de bloques.

--binary-prefix

Mostrar progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Mostrar progreso en segundos (por defecto es minuto).

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar la versión del programa.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone.dd

EJEMPLOS

 Clonar /dev/hda1 a hda1.dd.img y mostrar información de depuración.
   partclone.dd -d -s /dev/hda1 -o hda1.dd.img
 Restaurar /dev/hda1 desde hda1.dd.img y mostrar información de depuración.
   partclone.dd -d -s hda1.dd.img -o /dev/hda1

DIAGNÓSTICO

Los siguientes diagnósticos pueden emitirse en stderr:

partclone.dd proporciona algunos códigos de retorno, que pueden utilizarse en scripts:

Código Diagnóstico
0 El programa terminó con éxito.
1 La clonación o restauración parecen haber fallado.
