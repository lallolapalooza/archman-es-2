NOMBRE

pam_prompt, pam_vprompt - interfaz a la función de conversación

SINOPSIS

#include <security/pam_ext.h>

int pam_prompt(pam_handle_t *pamh, int style, char **response, const char *fmt, ...);

int pam_vprompt(pam_handle_t *pamh, int style, char **response, const char *fmt, va_list args);

DESCRIPCIÓN

La función pam_prompt construye un mensaje a partir de la cadena de formato y los argumentos especificados y lo pasa a la función de conversación configurada por el servicio. Tras un retorno exitoso, response se establece para apuntar a una cadena devuelta por la función de conversación. Esta cadena se asigna en el heap y debe liberarse.

VALORES DE RETORNO

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CONV_ERR

Fallo de conversación.

PAM_SUCCESS

Conversación exitosa, se establece la respuesta.

PAM_SYSTEM_ERR

Error del sistema.

VER TAMBIÉN

pam(8), pam_conv(3)

ESTNDARES

Las funciones pam_prompt y pam_vprompt son extensiones de Linux-PAM.
