NOMBRE

pacinfo - muestra información de paquetes

SINOPSIS

pacinfo [opciones] (<especificación_paquete>|<nombre_paquete>)...
pacinfo (--ayuda|--versión)

DESCRIPCIÓN

Si se proporciona un nombre_paquete, se mostrará información para todos los paquetes que coincidan con ese nombre en todas las bases de datos.

Si stdin no está conectado a una terminal, los paquetes se leerán desde stdin.

OPCIONES

--config=ruta
Establece una ruta de archivo de configuración alternativa.
--dbext=extensión
Establece una extensión de base de datos de sincronización alternativa.
--dbpath=ruta
Establece una ruta de base de datos alternativa.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--null[=sep]
Establece un separador alternativo para los valores analizados desde stdin. Por defecto, se utiliza una nueva línea "\n" como separador. Si se usa --null sin especificar sep, se utilizará "NUL".
--no-timeout
Desactiva los tiempos de espera de baja velocidad para las descargas.
--short
Muestra información breve. Adecuado para imprimir un número potencialmente grande de paquetes: 
pacsift --nombre libreoffice | pacinfo --short
--verbose
Muestra información adicional del paquete: "requerido por", "opcional para" y "firma base64".
--raw
Muestra valores numéricos brutos de tamaño y fecha.
--removable-size
Incluye el tamaño de las dependencias extraíbles en el tamaño instalado.
--help
Muestra información de uso y sale.
--version
Muestra información de versión y sale.

ADVERTENCIAS

pacinfo determina si debe leer paquetes desde stdin basándose en una comprobación simple usando isatty(3). Si pacinfo se llama en un entorno, como una función de shell o un script que se utiliza en una tubería, donde stdin no está conectado a una terminal pero no contiene paquetes para imprimir, pacinfo debería llamarse con stdin cerrado. Para shells compatibles con POSIX, esto se puede hacer con "<&-".
