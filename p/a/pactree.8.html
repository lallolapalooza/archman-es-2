PACTREE(8) Manual de Pacman-contrib PACTREE(8)

NOMBRE

pactree - visor de árboles de dependencias de paquetes

SINOPSIS

pactree [opciones] <paquete>

DESCRIPCIÓN

pactree produce un árbol de dependencias para un paquete.

Por defecto, se genera una salida similar a un árbol, pero con la opción --graph, se genera una descripción de Graphviz.

OPCIONES

-a, --ascii

Usa caracteres ASCII para el formato del árbol. Por defecto, pactree usará caracteres de dibujo de líneas Unicode si es capaz de detectar que la configuración regional los soporta.

-c, --color

Colorea la salida.

--config <archivo>

Especifica un archivo de configuración de pacman alternativo.

-b, --dbpath

Especifica una ubicación alternativa para la base de datos.

--debug

Imprime mensajes de registro producidos por libalpm.

-d, --depth <num>

Limita el número de niveles de dependencia a mostrar. Un cero significa mostrar solo el paquete nombrado, uno muestra los paquetes que son directamente requeridos.

--gpgdir <dir>

Especifica un directorio GnuPG alternativo para verificar las firmas de la base de datos (el valor predeterminado es /etc/pacman.d/gnupg).

-g, --graph

Genera una descripción de Graphviz. Si se proporciona esta opción, las opciones --color y --linear se ignoran.

-h, --help

Muestra la sintaxis y las opciones de línea de comandos.

-l, --linear

Imprime los nombres de los paquetes al principio de cada línea, uno por línea.

-o, --optional[=depth]

Imprime además las dependencias opcionales hasta una cierta profundidad, predeterminadamente 1 para dependencias opcionales inmediatas. Cuando se usa junto con -r, muestra para qué paquetes es opcional. En modo Graphviz, produce líneas punteadas. Los valores negativos significan profundidad infinita.

-r, --reverse

Muestra los paquetes que dependen del paquete nombrado.

-s, --sync

Lee los datos del paquete de las bases de datos de sincronización en lugar de la base de datos local.

-u, --unique

Lista los paquetes dependientes una sola vez. Implica --linear.

-V, --version

Muestra la versión.

VER TAMBIÉN

pacman(8), pacman.conf(5), makepkg(8)
