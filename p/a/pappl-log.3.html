NOMBRE

pappl-log - Funciones de registro de pappl

BIBLIOTECA

Printer Application Framework (libpappl, "pkg-config --cflags --libs pappl")

SINOPSIS

#include <pappl/pappl.h>

void
papplLog(pappl_system_t *system, pappl_loglevel_t level, const char *message, ...);

void
papplLogClient(pappl_client_t *client, pappl_loglevel_t level, const char *message, ...);

void
papplLogJob(pappl_job_t *job, pappl_loglevel_t level, const char *message, ...);

void
papplLogPrinter(pappl_printer_t *printer, pappl_loglevel_t level, const char *message, ...);

DESCRIPCIÓN

Las funciones de registro de PAPPL registran mensajes en el archivo de registro configurado.

papplLog registra mensajes que se aplican al sistema en su conjunto.

papplLogClient, papplLogJob y papplLogPrinter registran mensajes específicos para una conexión de cliente, un trabajo de impresión o una impresora, respectivamente.

El argumento level especifica un nivel de registro, desde depuración (PAPPL_LOGLEVEL_DEBUG) hasta fatal (PAPPL_LOGLEVEL_FATAL) y se utiliza para determinar si el mensaje se registra en el registro.

El argumento message especifica el mensaje utilizando una cadena de formato printf(3).

FUNCIONES

papplLog

Registra un mensaje para el sistema.

void papplLog (
    pappl_system_t *system,
    pappl_loglevel_t level,
    const char *message,
    ...
);

Esta función envía un mensaje al archivo de registro del sistema. El argumento "level" especifica la urgencia del mensaje:

  • PAPPL_LOGLEVEL_DEBUG: Un mensaje de depuración.
  • PAPPL_LOGLEVEL_ERROR: Un mensaje de error.
  • PAPPL_LOGLEVEL_FATAL: Un mensaje de error fatal.
  • PAPPL_LOGLEVEL_INFO: Un mensaje informativo.
  • PAPPL_LOGLEVEL_WARN: Un mensaje de advertencia.

El argumento "message" especifica una cadena de formato estilo printf. Los valores registrados usando los especificadores de formato "%c" y "%s" se sanitizan para no contener caracteres de control.
