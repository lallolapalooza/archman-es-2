NOMBRE

pam_get_user - obtener nombre de usuario

SINOPSIS

#include <security/pam_modules.h>

int pam_get_user(const pam_handle_t *pamh, const char **user, const char *prompt);

DESCRIPCIÓN

La función pam_get_user devuelve el nombre del usuario especificado por pam_start(3). Si no se especificó ningún usuario, devuelve lo que devolvería pam_get_item (pamh, PAM_USER, ... );. Si este es NULL, obtiene el nombre de usuario a través del mecanismo de pam_conv(3), y solicita al usuario con la primera cadena no-NULL de la siguiente lista:

•El argumento prompt pasado a la función.
•Lo que devuelve pam_get_item (pamh, PAM_USER_PROMPT, ... );
•El mensaje de solicitud por defecto: "login: "

Por cualquier medio que se obtenga el nombre de usuario, se devuelve un puntero a él como contenido de *user. Tenga en cuenta que esta memoria **no** debe ser liberada con free() ni modificada por el módulo.

Esta función establece el elemento PAM_USER asociado con las funciones de pam_set_item(3) y pam_get_item(3).

VALORES DE RETORNO

PAM_SUCCESS

Nombre de usuario recuperado con éxito.

PAM_SYSTEM_ERR

Se envió un puntero NULL.

PAM_CONV_ERR

El método de conversación proporcionado por la aplicación falló al obtener el nombre de usuario.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_ABORT

Error al reanudar una conversación antigua.

PAM_CONV_AGAIN

El método de conversación proporcionado por la aplicación está esperando un evento.

VER TAMBIÉN
