PARTCLONE.NTFSFIXB(8) Manual de usuario de Partclone PARTCLONE.NTFSFIXB(8)

NOMBRE

partclone.ntfsfixboot - gestiona la estupidez con sistemas de archivos NTFS en movimiento.

SINOPSIS

partclone.ntfsfixboot [-w] [-h n] [-t n] [-s n] [-b] [-f] [-p] {DISPOSITIVO}

DESCRIPCIÓN

partclone.ntfsfixboot NO es parte del proyecto Partclone, pero se incluye para corregir problemas de arranque de NTFS. Partclone proporciona utilidades para respaldar bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque usado de la partición ext2.

Partclone.ntfsfixboot gestiona la estupidez con sistemas de archivos NTFS en movimiento. Escrito por Orgad Shaneh (2009) y Daniel J. Grace (2006).

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, a continuación se incluye un resumen de las opciones.

-w

Escribe el nuevo sector de inicio en la partición.

-h num

Especifica el número de cabezales por pista. Si se omite, se determina a través de ioctl.

-t num

Especifica el número de sectores por pista. Si se omite, se determina a través de ioctl.

-s num

Nuevo sector de inicio a escribir. Si se omite, se determina a través de ioctl.

-b

Continúa incluso si el dispositivo especificado no es una partición.

-f

Fuerza la operación incluso si el dispositivo no parece ser una partición NTFS válida o si los valores son iguales.

-p

Imprime información de depuración (valores leídos, valores solicitados, etc.).

dispositivo

donde dispositivo apunta a una partición NTFS

DIAGNÓSTICOS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone.ntfsfixboot proporciona algunos códigos de retorno, que pueden usarse en scripts:

Código Diagnóstico
0 éxito (los valores son correctos o se cambiaron con éxito)
1 se necesita un cambio, pero no se especificó -w
2 ocurrió un error
