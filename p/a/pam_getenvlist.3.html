NOMBRE

pam_getenvlist - obtener el entorno PAM

SINOPSIS

#include <security/pam_appl.h>

char **pam_getenvlist(pam_handle_t *pamh);

DESCRIPCIÓN

La función pam_getenvlist devuelve una copia completa del entorno PAM asociado al manejador pamh. Las variables de entorno PAM representan el contenido de las variables de entorno regulares del usuario autenticado cuando se concede el servicio.

El formato de la memoria es un array de punteros char asignado con malloc(), cuyo último elemento se establece a NULL. Cada una de las entradas no NULL en este array apunta a una cadena de caracteres NUL terminada y asignada con malloc() del tipo: "nombre=valor".

Cabe señalar que esta memoria nunca será liberada por libpam. Una vez obtenida mediante una llamada a pam_getenvlist, es responsabilidad de la aplicación que llama liberar() esta memoria.

No es una coincidencia que el formato y el contenido del array devuelto coincida con lo requerido para el tercer argumento de la llamada a la función execle(3).

VALORES DE RETORNO

La función pam_getenvlist devuelve NULL en caso de fallo.
