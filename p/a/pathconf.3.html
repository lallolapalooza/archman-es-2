fpathconf(3) Manual de Funciones de Biblioteca fpathconf(3)

NOMBRE

fpathconf, pathconf - obtener valores de configuración para archivos

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
long fpathconf(int fd, int name);
long pathconf(const char *path, int name);

DESCRIPCIÓN

fpathconf() obtiene un valor para la opción de configuración name para el descriptor de archivo abierto fd.

pathconf() obtiene un valor para la opción de configuración name para el nombre de archivo path.

Las macros correspondientes definidas en <unistd.h> son valores mínimos; si una aplicación desea aprovechar valores que pueden cambiar, se puede realizar una llamada a fpathconf() o pathconf(), que puede producir resultados más liberales.

Establecer name igual a una de las siguientes constantes devuelve las siguientes opciones de configuración:

_PC_LINK_MAX
El número máximo de enlaces al archivo. Si fd o path se refieren a un directorio, entonces el valor se aplica a todo el directorio. La macro correspondiente es _POSIX_LINK_MAX.
_PC_MAX_CANON
La longitud máxima de una línea de entrada formateada, donde fd o path debe referirse a una terminal. La macro correspondiente es _POSIX_MAX_CANON.
_PC_MAX_INPUT
La longitud máxima de una línea de entrada, donde fd o path debe referirse a una terminal. La macro correspondiente es _POSIX_MAX_INPUT.
_PC_NAME_MAX
La longitud máxima de un nombre de archivo en el directorio path o fd que el proceso tiene permitido crear. La macro correspondiente es _POSIX_NAME_MAX.
_PC_PATH_MAX
La longitud máxima de un nombre de ruta relativo cuando path o fd es el directorio de trabajo actual. La macro correspondiente es _POSIX_PATH_MAX.
_PC_PIPE_BUF
El número máximo de bytes que se pueden escribir atómicamente en una tubería o FIFO. Para fpathconf(), fd debe referirse a una tubería o FIFO. Para fpathconf(), path debe referirse a un FIFO o a un directorio; en este último caso, el valor devuelto corresponde a los FIFOs creados en ese directorio. La macro correspondiente es _POSIX_PIPE_BUF.
_PC_CHOWN_RESTRICTED
Esto devuelve un valor positivo si el uso de chown(2) y fchown(2) para cambiar el ID de usuario de un archivo está restringido a un proceso con privilegios apropiados, y cambiar el ID de grupo de un archivo a un valor distinto del ID de grupo efectivo del proceso o uno de sus IDs de grupo suplementarios está restringido a un proceso con privilegios apropiados. Según POSIX.1, esta variable siempre se definirá con un valor distinto de -1. La macro correspondiente es _POSIX_CHOWN_RESTRICTED.
Si fd o path se refieren a un directorio, entonces el valor de retorno se aplica a todos los archivos en ese directorio.
_PC_NO_TRUNC
Esto devuelve un valor distinto de cero si el acceso a nombres de archivo más largos que _POSIX_NAME_MAX genera un error. La macro correspondiente es _POSIX_NO_TRUNC.
_PC_VDISABLE
Esto devuelve un valor distinto de cero si el procesamiento de caracteres especiales se puede deshabilitar, donde fd o path debe referirse a una terminal.

VALOR DE RETORNO

El valor de retorno de estas funciones es uno de los siguientes:

•
En caso de error, se devuelve -1 y errno se establece para indicar el error (por ejemplo, EINVAL, que indica que name no es válido).
•
Si name corresponde a un límite máximo o mínimo, y ese límite es indeterminado, se devuelve -1 y errno no se modifica. (Para distinguir un límite indeterminado de un error, establezca errno a cero antes de la llamada, y luego verifique si errno es distinto de cero cuando se devuelve -1.)
•
Si name corresponde a una opción, se devuelve un valor positivo si la opción es compatible y -1 si la opción no es compatible.
•
De lo contrario, se devuelve el valor actual de la opción o límite. Este valor no será más restrictivo que el valor correspondiente que se describió a la aplicación en <unistd.h> o <limits.h> cuando la aplicación fue compilada.

ERRORES

EACCES
(pathconf()) Se deniega el permiso de búsqueda en uno de los directorios en el prefijo de ruta de path.
EBADF
(fpathconf()) fd no es un descriptor de archivo válido.
EINVAL
name no es válido.
EINVAL
La implementación no admite una asociación de name con el archivo especificado.
ELOOP
(pathconf()) Se encontraron demasiados enlaces simbólicos al resolver path.
ENAMETOOLONG
(pathconf()) path es demasiado largo.
ENOENT
(pathconf()) Un componente de path no existe, o path es una cadena vacía.
ENOTDIR
(pathconf()) Un componente utilizado como directorio en path no es en realidad un directorio.

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

NOTAS

Los archivos con nombres de longitud mayor que el valor devuelto para name igual a _PC_NAME_MAX pueden existir en el directorio dado.

Algunos valores devueltos pueden ser enormes; no son adecuados para asignar memoria.
