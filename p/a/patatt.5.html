NOMBRE

PATATT - Atestación criptográfica de parches similar a DKIM

SINOPSIS

patatt {sign,validate,genkey,install-hook} [opciones]

DESCRIPCIÓN

Esta herramienta permite firmar criptográficamente los parches enviados por correo electrónico utilizando cabeceras de mensajes similares a DKIM. Este enfoque es efectivo y no interfiere con otras herramientas de revisión de código de la misma manera que lo hacen las firmas PGP en línea o separadas. Para una visión general completa de los conceptos y consideraciones principales, consulte README.

Si ya tiene una clave PGP configurada para firmar etiquetas o commits de git, entonces debería poder usar patatt sin ninguna configuración adicional. Intente ejecutar lo siguiente en cualquier repositorio de git:

git format-patch -1 --stdout | patatt sign

Si patatt no encuentra su clave PGP, intente agregar lo siguiente a su ~/.gitconfig:

[user]
    signingkey = [suidclave]

Para averiguar su id de clave, ejecute gpg --list-secret-keys. Si desea utilizar una subclave específica, puede especificar el id de la subclave con un ! al final.

USO COMO HOOK DE GIT

Si utiliza git-send-email para enviar parches, puede hacer que se firmen automáticamente a través del hook sendemail-validate. Para instalarlo, ejecute el siguiente comando en el repositorio que desee habilitar para la firma:

$ patatt install-hook

O puede instalarlo manualmente:

$ echo 'patatt sign --hook "${1}"' >> .git/hooks/sendemail-validate
$ chmod a+x .git/hooks/sendemail-validate

SUBCOMANDOS

  • sign: firma la entrada estándar o archivos RFC2822 pasados como argumentos
  • validate: validación básica para mensajes firmados
  • genkey: genera un nuevo par de claves ed25519
  • install-hook: instala el hook sendemail-validate en el repositorio actual

Puede ejecutar patatt [subcomando] --help para ver un resumen de las banderas para cada subcomando.
