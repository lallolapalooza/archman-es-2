NOMBRE

pacmd - Reconfigura un servidor de sonido PulseAudio durante la ejecución

SINOPSIS

pacmd

pacmd --help

pacmd --version

DESCRIPCIÓN

Esta herramienta se puede usar para inspeccionar o reconfigurar un servidor de sonido PulseAudio en ejecución durante el tiempo de ejecución. Se conecta al servidor de sonido y ofrece un shell interactivo simple que se puede usar para introducir los comandos que también se entienden en los scripts de configuración de default.pa.

Para salir del shell interactivo, usa ctrl+d. ¡Ten en cuenta que el comando 'exit' dentro del shell hará que el propio demonio PulseAudio se cierre!

Si se pasan argumentos en la línea de comandos, se pasarán al shell interactivo, que procesará el comando y saldrá.

OPCIONES

-h | --help
Mostrar ayuda.
--version
Mostrar información de la versión.

AUTORES

Los desarrolladores de PulseAudio <pulseaudio-discuss (at) lists (dot) freedesktop (dot) org>; PulseAudio está disponible en http://pulseaudio.org/

VER TAMBIÉN

pulse-cli-syntax(5), pulseaudio(1), pactl(1), default.pa(5)
