NOMBRE

pam_get_item - obtener información de PAM

SINOPSIS

#include <security/pam_modules.h>

int pam_get_item(const pam_handle_t *pamh, int item_type, const void **item);

DESCRIPCIÓN

La función pam_get_item permite a las aplicaciones y a los módulos de servicio PAM acceder y recuperar información de PAM de item_type. Al regresar exitosamente, item contiene un puntero al valor del elemento correspondiente. ¡Nota, este es un puntero a los datos *reales* y no debe ser liberado con free() ni sobrescrito! Los siguientes valores son compatibles para item_type:

PAM_SERVICE

El nombre del servicio (que identifica la pila PAM que las funciones PAM usarán para autenticar el programa).

PAM_USER

El nombre de usuario de la entidad bajo cuya identidad se dará servicio. Es decir, tras la autenticación, PAM_USER identifica la entidad local que obtiene acceso al servicio. Nota, este valor puede ser mapeado de algo (ej., "anonymous") a algo más (ej. "guest119") por cualquier módulo en la pila PAM. Como tal, una aplicación debe consultar el valor de PAM_USER después de cada llamada a una función PAM.

PAM_USER_PROMPT

La cadena utilizada al solicitar el nombre de usuario. El valor predeterminado para esta cadena es una versión localizada de "login: ".

PAM_TTY

El nombre de la terminal prefijado por /dev/ para los archivos de dispositivo. En el pasado, las aplicaciones gráficas basadas en X solían almacenar la variable $DISPLAY aquí, pero con la introducción de PAM_XDISPLAY este uso está obsoleto.

PAM_RUSER

El nombre de usuario solicitante: nombre local para un usuario solicitante local o un nombre de usuario remoto para un usuario remoto solicitante.

Generalmente, una aplicación o módulo intentará proporcionar el valor que esté más fuertemente autenticado (una cuenta local antes que una remota). El nivel de confianza en este valor está implícito en la pila de autenticación asociada con la aplicación, por lo que está en última instancia a discreción del administrador del sistema.

PAM_RUSER@PAM_RHOST siempre debe identificar al usuario solicitante. En algunos casos, PAM_RUSER puede ser NULL. En tales situaciones, no está claro quién es la entidad solicitante.

PAM_RHOST

El nombre de host solicitante (el nombre del host de la máquina desde la cual la entidad PAM_RUSER está solicitando servicio). Es decir, PAM_RUSER@PAM_RHOST identifica al usuario solicitante. En algunas aplicaciones, PAM_RHOST puede ser NULL. En tales situaciones, no está claro de dónde proviene la solicitud de autenticación.

PAM_AUTHTOK

El token de autenticación (a menudo una contraseña). Este token debe ser ignorado por todas las funciones del módulo, excepto pam_sm_authenticate(3) y pam_sm_chauthtok(3). En la primera función se utiliza para pasar el token de autenticación más reciente de un módulo apilado a otro. En la segunda función, el token se utiliza para otro propósito. Contiene el token de autenticación actualmente activo.

PAM_OLDAUTHTOK

El token de autenticación antiguo. Este token debe ser ignorado por todas las funciones del módulo excepto pam_sm_chauthtok(3).

PAM_CONV

La estructura pam_conv. Ver pam_conv(3).

Los siguientes elementos adicionales son específicos de Linux-PAM y no deben usarse en aplicaciones portátiles:

PAM_FAIL_DELAY

Un puntero de función para redirigir retrasos de fallo gestionados centralmente. Ver pam_fail_delay(3).

PAM_XDISPLAY

El nombre de la pantalla X. Para aplicaciones gráficas basadas en X, el valor de este elemento debe ser la variable $DISPLAY. Este valor puede utilizarse de forma independiente de PAM_TTY para pasar el nombre de la pantalla.

PAM_XAUTHDATA

Un puntero a una estructura que contiene los datos de autenticación X necesarios para establecer una conexión con la pantalla especificada por PAM_XDISPLAY, si dicha información es necesaria. Ver pam_xauth_data(3).

PAM_AUTHTOK_TYPE

La acción predeterminada es que el módulo utilice las siguientes indicaciones al solicitar contraseñas: "Nueva contraseña UNIX: " y "Vuelva a escribir la contraseña UNIX: ". La palabra de ejemplo UNIX puede ser reemplazada por este elemento; por defecto, está vacía. Este elemento es utilizado por pam_get_authtok(3).

Si un módulo de servicio desea obtener el nombre del usuario, no debe usar esta función, sino realizar una llamada a pam_get_user(3).

Solo un módulo de servicio tiene el privilegio de leer los tokens de autenticación, PAM_AUTHTOK y PAM_OLDAUTHTOK.

VALORES DE RETORNO

PAM_BAD_ITEM

La aplicación intentó establecer un elemento indefinido o inaccesible.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_PERM_DENIED

El valor de item era NULL.

PAM_SUCCESS

Los datos se actualizaron correctamente.

PAM_SYSTEM_ERR

El pam_handle_t pasado como primer argumento era inválido.

VER TAMBIÉN

pam_set_item(3), pam_strerror(3)
