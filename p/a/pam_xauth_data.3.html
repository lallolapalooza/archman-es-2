Paquete: pam

PAM_XAUTH_DATA(3) Manual de Linux-PAM PAM_XAUTH_DATA(3)

NOMBRE

pam_xauth_data - estructura que contiene datos de autenticación X

SINOPSIS

#include <security/pam_appl.h>
struct pam_xauth_data {
    int namelen;
    char *name;
    int datalen;
    char *data;
};

DESCRIPCIÓN

La estructura pam_xauth_data contiene datos de autenticación X utilizados para establecer una conexión a una pantalla X. Usando este mecanismo, una aplicación puede comunicar datos de autenticación X a los módulos de servicio PAM. Esto permite a los módulos establecer una conexión a la pantalla X del usuario para etiquetar la sesión del usuario al iniciar sesión, mostrar retroalimentación visual u otros propósitos.

El campo name contiene el nombre del método de autenticación, como "MIT-MAGIC-COOKIE-1". El campo namelen contiene la longitud de esta cadena, sin incluir el carácter NUL final.

El campo data contiene los datos específicos del método de autenticación correspondientes al nombre especificado. El campo datalen contiene su longitud en bytes.

Los datos de autenticación X se pueden cambiar con el elemento PAM_XAUTH_DATA. Se puede consultar y establecer con pam_get_item(3) y pam_set_item (3) respectivamente. El valor utilizado para establecerlo debe ser un puntero a una estructura pam_xauth_data. PAM realiza una copia interna tanto de la estructura en sí como de sus campos al establecer el elemento.

VER TAMBIÉN

pam_start(3), pam_get_item(3),

ESTÁNDARES

La estructura pam_xauth_data y el elemento PAM_XAUTH_DATA son extensiones de Linux-PAM.
