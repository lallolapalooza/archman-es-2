NOMBRE

pam_cifscreds - Módulo PAM para gestionar credenciales NTLM en el keyring del kernel

SINOPSIS

Edite los archivos de configuración de PAM para los sistemas para los que desea registrar automáticamente las credenciales NTLM, por ejemplo, /etc/pam.d/login, y modifique como sigue:

    ...
    auth       substack     system-auth
+++ auth       optional     pam_cifscreds.so
    auth       include      postlogin
    ...
    ...
    session    include      system-auth
+++ session    optional     pam_cifscreds.so domain=DOMINIO
    session    include      postlogin
    ...

Cambie DOMINIO por el nombre de su dominio de Windows, o use host= como se describe a continuación.

DESCRIPCIÓN

El módulo PAM pam_cifscreds es una herramienta para agregar automáticamente credenciales (nombre de usuario y contraseña) con el fin de establecer sesiones en montajes multiusuario.

Cuando un sistema de archivos cifs se monta con la opción "multiuser" y no utiliza autenticación krb5, necesita poder obtener las credenciales de cada usuario de alguna parte. El módulo pam_cifscreds puede usarse para proporcionar estas credenciales al kernel automáticamente al iniciar sesión.

En la sección de sesión del archivo de configuración de PAM, el módulo puede usar un nombre de dominio NT o una lista de nombres de host o direcciones.

OPCIONES

pam_cifscreds admite un par de opciones que se pueden establecer en los archivos de configuración de PAM. Debe tener una (y solo una) de las opciones domain= o host=.

debug
Activa un registro de depuración adicional.
domain=<nombre de dominio NT>
Las credenciales se agregarán para el nombre de dominio NT especificado.
host=<nombre de host o dirección IP>[,]
Las credenciales se agregarán para los nombres de host o direcciones IP especificados.

NOTAS

El módulo PAM pam_cifscreds requiere un kernel compilado con soporte para el tipo de clave login. Ese tipo de clave se agregó en la versión 3.3 en los kernels Linux principales.

Dado que pam_cifscreds agrega claves al keyring de sesión, se recomienda encarecidamente utilizar pam_keyinit para garantizar que se establezca un keyring de sesión al iniciar sesión.

VER TAMBIÉN

cifscreds(1), pam_keyinit(8)
