NOMBRE

passwd.nntp - Contraseñas para conectarse a servidores NNTP remotos

DESCRIPCIÓN

El archivo pathetc/passwd.nntp contiene tríos de host / nombre / contraseña para usarlos al autenticar programas cliente en servidores NNTP. Este archivo es interpretado normalmente por "NNTPsendpassword()" en libinn(3). Las líneas en blanco y las líneas que comienzan con un signo de numeral ("#") son ignoradas. Todas las demás líneas deberían consistir en tres o cuatro campos separados por dos puntos:

host:nombre:contraseña
host:nombre:contraseña:estilo

El primer campo es el nombre de un host y se compara sin distinguir entre mayúsculas y minúsculas. (No se realiza una comparación detallada, como comparar direcciones IP).

El segundo campo es un nombre de usuario y el tercero es una contraseña. Si el nombre de usuario o la contraseña están vacíos, esa parte de la autenticación no se llevará a cabo. (Por ejemplo, un servidor puede requerir solo un nombre de usuario, en cuyo caso la contraseña no es necesaria. Tenga en cuenta que un nombre de usuario es obligatorio con AUTHINFO USER/PASS).

El cuarto campo opcional especifica el tipo de autenticación a utilizar. Actualmente, el único "estilo de autenticación" reconocido es "authinfo"; este es también el valor predeterminado. Significa que se utilizan los comandos AUTHINFO USER/PASS para autenticarse en el host remoto. (Estos comandos NNTP se describen en RFC 4643).

Por ejemplo:

mit.edu:bbn:mypassword
uunet.uu.net:bbn:yoyoma:authinfo

Este archivo no debería ser legible por todos.

actsync, getlist, inews, innxbatch, innxmit, nnrpd, nntpget y rnews hacen uso de passd.nntp cuando necesitan conectarse a un servidor remoto.
