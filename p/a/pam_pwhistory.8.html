NOMBRE

pam_pwhistory - Módulo PAM para recordar contraseñas anteriores

SINOPSIS

pam_pwhistory.so [debug] [use_authtok] [enforce_for_root] [remember=N] [retry=N] [authtok_type=STRING] [file=/ruta/nombre_archivo] [conf=/ruta/a/archivo_configuracion]

DESCRIPCIÓN

Este módulo guarda las últimas contraseñas de cada usuario para forzar el historial de cambios de contraseña y evitar que el usuario alterne entre la misma contraseña con demasiada frecuencia.

Este módulo no funciona junto con Kerberos. En general, no tiene mucho sentido usar este módulo junto con NIS o LDAP, ya que las contraseñas antiguas se almacenan en la máquina local y no están disponibles en otra máquina para la verificación del historial de contraseñas.

OPCIONES

debug

Activa la depuración a través de syslog(3).

use_authtok

Cuando se cambia la contraseña, obliga al módulo a usar la nueva contraseña proporcionada por un módulo de password apilado previamente (esto se usa en el ejemplo de apilamiento del módulo pam_passwdqc documentado a continuación).

enforce_for_root

Si esta opción está activada, la comprobación también se aplica a root.

remember=N

Se guardan las últimas N contraseñas de cada usuario. El valor por defecto es 10. Un valor de 0 hace que el módulo mantenga el contenido existente del archivo opasswd sin cambios.

retry=N

Pide al usuario como máximo N veces antes de devolver un error. El valor por defecto es 1.

authtok_type=STRING

Ver pam_get_authtok(3) para más detalles.

file=/ruta/nombre_archivo

Almacena el historial de contraseñas en el archivo /ruta/nombre_archivo en lugar de la ubicación por defecto. La ubicación por defecto es /etc/security/opasswd.

conf=/ruta/a/archivo_configuracion

Usa otro archivo de configuración en lugar del archivo por defecto /etc/security/pwhistory.conf.

Las opciones para configurar el comportamiento del módulo se describen en la página del manual pwhistory.conf(5). Las opciones especificadas en la línea de comandos del módulo anulan los valores del archivo de configuración.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo password.

VALORES DE RETORNO

PAM_AUTHTOK_ERR

No se introdujo una nueva contraseña, el usuario abortó el cambio de contraseña o no se pudo establecer la nueva contraseña.

PAM_IGNORE

El historial de contraseñas estaba deshabilitado.

PAM_MAXTRIES

La contraseña fue rechazada demasiadas veces.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

EJEMPLOS

Una sección de contraseña de ejemplo sería:

#%PAM-1.0
password     required       pam_pwhistory.so
password     required       pam_unix.so        use_authtok

En combinación con pam_passwdqc:

#%PAM-1.0
password     required       pam_passwdqc.so    config=/etc/passwdqc.conf
password     required       pam_pwhistory.so   use_authtok
password     required       pam_unix.so        use_authtok

ARCHIVOS

/etc/security/opasswd

Archivo por defecto con el historial de contraseñas

/etc/security/pwhistory.conf

Archivo de configuración para las opciones de pam_pwhistory

VER TAMBIÉN
