PARTCLONE(8) Manual de usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se usan e2fslibs para leer el bloque utilizado de una partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS DE APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], similar a fsck o mkfs. Por ejemplo, para respaldar/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de Archivos                 partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de tu acción. Normalmente, la fuente de respaldo es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos desde una tubería está soportada ÚNICAMENTE para restaurar, simplemente ignora la opción -s o usa '-' significa recibir datos desde stdin.

-o ARCHIVO, --output ARCHIVO

Archivo de salida. El ARCHIVO puede ser un archivo de imagen (partclone generará) o un dispositivo dependiendo de tu acción. Normalmente, la salida de respaldo va a un archivo de imagen y la salida de restauración va a un dispositivo.

Enviar datos a una tubería también está soportado ÚNICAMENTE para respaldar, simplemente ignora la opción -o o usa '-' significa enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo loop.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, origen y salida son ambos dispositivos.

-D, --domain

Crea un archivo de log de dominio de GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de log de dominio

--restore_raw_file

Creando archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Coloca una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de comprobación crc.

-F, --force

Fuerza el progreso.

-f seg, --UI-fresh seg

Coloca un intervalo especial en segundos para la actualización.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactiva el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de verificación a usar para agregar detección de errores.

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

2: xxHash, algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de verificación por cada X bloques.

-w, --skip_write_error

Continúa la restauración durante errores de escritura.

--write-direct-io

Escribe datos en la partición DESTINO sin caché.

--read-direct-io

Lee datos desde la partición FUENTE sin caché.

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques.

--binary-prefix

Muestra el progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Muestra el progreso en segundos (por defecto es minutos).

-E, --offset=X

Añade el desplazamiento X (bytes) a SALIDA.

-T, --btfiles

Restaura bloques como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura bloques como archivo para ClonezillaBT pero solo genera torrent.

-n, --note NOTA

Muestra Mensaje de Nota (128 palabras).

-h, --help

Muestra el resumen de opciones.

-v, --version

Muestra la versión.

partclone.ntfs(8) - Arch Linux

NAME

partclone.ntfs - partclone filesystem utility for NTFS

SYNOPSIS

partclone.ntfs [ -cqr> ] [ -s source ] [ -o output ] [ -d ] [ -N ] [ -X ] [ -i ] [ -b ] [ -v ] [ -p ] [ -z ] [ -t ] [ -a ] [ -z ] [ -M ] [ -C ] [ -g ] [ -L ] [ -Z ] [ -S ] [ -P ] [ -F ] [ -R ] [ -n ] [ -w ] [ -l ] [ -m ] [ -f ] [ -k ] [ -q ] [ -h ]

DESCRIPTION

Partclone is a tool to copy / save / restore a partition to / from a file.

Partclone aims to be an useful tool for the administrator. Partclone supports many filesystems like:

NTFS, FAT, LVM, UFS, XFS, JFS, VMFS, ReiserFS, HFS+, Ext2, Ext3, Ext4, Btrfs, etc.

Partclone can copy only used blocks in the partition, to save disk space.

Partclone can save image file to many locations:

Local disk, Network share (NFS, Samba), SSH, etc.

Partclone supports split image file into many pieces, and copy image file to compress image file.

Partclone can restore image file to partition. It can restore split image file and compress image file.

Partclone also provides checking image file function.

OPTIONS

-c, --clone
Clone a partition to a file.
-q, --quiet
Quiet mode, less output.
-r, --restore
Restore a partition from a file.
-s, --source source
Source partition or file.
-o, --output output
Output file or partition.
-d, --debug
Enable debug messages.
-N, --no-check
No check partition
-X, --no-partclone
No partclone, use dd to copy partition.
-i, --ignore-fsck
Ignore filesystem check.
-b, --force
Force clone or restore.
-v, --verbose
Verbose mode.
-p, --progress
Show progress bar.
-z, --size size
Set split size (e.g., 2048 MB).
-t, --threads threads
Number of threads.
-a, --allow-other
Allow other users to access the mounted filesystem.
-M, --mount
Mount filesystem.
-C, --unmount
Unmount filesystem.
-g, --checksum
Calculate checksum.
-L, --list
List available filesystems.
-Z, --reopen
Reopen image file.
-S, --save-part
Save partition.
-P, --save-part-to-file
Save partition to file.
-F, --restore-file
Restore file.
-R, --restore-part
Restore partition.
-n, --ncurses
Use ncurses interface.
-w, --force-overwrite
Force overwrite.
-l, --log
Enable logging.
-m, --memory
Use memory for buffering.
-f, --force-fsck
Force filesystem check.
-k, --keep-log
Keep log file.
-h, --help
Display help message.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
