NOMBRE

pam_ftp - módulo de acceso anónimo

SINOPSIS

pam_ftp.so [debug] [ignore] [users=XXX,YYY,...]

DESCRIPCIÓN

pam_ftp es un módulo PAM que proporciona un modo de acceso anónimo ftp configurable.

Este módulo intercepta el nombre y la contraseña del usuario. Si el nombre es ftp o anonymous, la contraseña del usuario se divide en el delimitador @ en una parte PAM_RUSER y otra PAM_RHOST; estos elementos pam se configuran en consecuencia. El nombre de usuario (PAM_USER) se establece en ftp. En este caso, el módulo tiene éxito. Alternativamente, el módulo establece el elemento PAM_AUTHTOK con la contraseña introducida y falla.

Este módulo no es seguro y se puede falsificar fácilmente.

OPCIONES

debug

Imprime información de depuración.

ignore

No presta atención a la dirección de correo electrónico del usuario (si se proporciona).

ftp=XXX,YYY,...

En lugar de ftp o anonymous, proporciona acceso anónimo a la lista de usuarios separada por comas: XXX,YYY,.... Si el solicitante introduce uno de estos nombres de usuario, el nombre de usuario devuelto se establece en el primero de la lista: XXX.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_SUCCESS

La autenticación fue exitosa.

PAM_USER_UNKNOWN

Usuario desconocido.

EJEMPLOS

Añada la siguiente línea a /etc/pam.d/ftpd para manejar el inicio de sesión anónimo estilo ftp:

#
# ftpd; añadir elementos específicos de ftp. Estas líneas permiten el ftp anónimo a través
#       del acceso estándar UN*X (la entrada listfile bloquea el acceso a
#       usuarios listados en /etc/ftpusers)
#
auth    sufficient  pam_ftp.so
auth    required    pam_unix.so use_first_pass
auth    required    pam_listfile.so \
           onerr=succeed item=user sense=deny file=/etc/ftpusers

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)
