NOMBRE

pamphletangler - Extrae fragmentos de código de archivos de folletos LaTeX.

SINOPSIS

pamphletangler [OPCIÓN...] ARCHIVO NOMBREDEFRAGMENTO

DESCRIPCIÓN

El sistema de folletos de clojure es un sistema basado en el sistema literario de clojure. En el sistema de folletos de clojure, tienes tu archivo LaTeX principal, que se puede compilar regularmente. Este archivo contiene documentación y código fuente (al igual que en otras formas de programación literaria). Estos fragmentos de código están envueltos en el entorno 'chunk', por lo que pueden ser reconocidos por el tangler con el fin de extraerlos. Los fragmentos se pueden incluir unos dentro de otros mediante el comando 'getchunk' (que se compondrá tipográficamente de forma adecuada). Finalmente, ejecutas tu archivo LaTeX a través del tangler y obtienes el fragmento de código deseado.

OPCIONES

-L, --line=textolinea
Si se establece, este texto se insertará después de saltos de línea, cambiando la cadena dentro de "changetext" por el número de línea. Esto se usa para que el informe de errores se refiera al número de línea del folleto en lugar del número de línea de salida.
-C, --change=textocambio
Por defecto es ""{}"", este es el texto que se reemplazará con el número de línea si se especifica la opción textolinea.
-?, --help
Muestra esta lista de ayuda.
--usage
Muestra un mensaje de uso corto.
--man
Imprime la página del manual.
-V, --version
Imprime la versión del programa.
