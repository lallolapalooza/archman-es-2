NOMBRE

pam_rhosts - El módulo PAM de rhosts

SINOPSIS

pam_rhosts.so

DESCRIPCIÓN

Este módulo realiza la autenticación de red estándar para servicios, tal como se usa en las implementaciones tradicionales de rlogin y rsh, etc.

El mecanismo de autenticación de este módulo se basa en el contenido de dos archivos; /etc/hosts.equiv (o) y ~/.rhosts. En primer lugar, los hosts listados en el archivo anterior se tratan como equivalentes al localhost. En segundo lugar, las entradas en la copia del usuario del último archivo se utilizan para mapear pares de "host-remoto usuario-remoto" a la cuenta de ese usuario en el host actual. Se concede acceso al usuario si su host está presente en /etc/hosts.equiv y su cuenta remota es idéntica a la local, o si su cuenta remota tiene una entrada en su archivo de configuración personal.

El módulo autentica a un usuario remoto (especificado internamente por el ítem PAM_RUSER que se conecta desde el host remoto (especificado internamente por el ítem PAM_RHOST). En consecuencia, para que las aplicaciones sean compatibles con este módulo de autenticación, deben establecer estos ítems antes de llamar a pam_authenticate(). El módulo no es capaz de sonder independientemente la conexión de red en busca de dicha información.

OPCIONES

debug

Imprime información de depuración.

silent

No imprime mensajes informativos.

superuser=account

Maneja la cuenta como root.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_AUTH_ERR

No se pudo determinar el host remoto, el nombre de usuario remoto o el nombre de usuario local, o se denegó el acceso por el archivo .rhosts.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

EJEMPLOS

Para conceder acceso a un usuario remoto a través de /etc/hosts.equiv o .rhosts para rsh, agregue las siguientes líneas a /etc/pam.d/rsh:

#%PAM-1.0
#
auth     required       pam_rhosts.so
auth     required       pam_nologin.so
auth     required       pam_env.so
auth     required       pam_unix.so
