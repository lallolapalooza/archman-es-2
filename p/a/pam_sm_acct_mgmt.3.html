NOMBRE

pam_sm_acct_mgmt - función de servicio de PAM para la gestión de cuentas

SINOPSIS

#include <security/pam_modules.h>

int pam_sm_acct_mgmt(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPCIÓN

La función pam_sm_acct_mgmt es la implementación del módulo de servicio de la interfaz pam_acct_mgmt(3).

Esta función realiza la tarea de establecer si al usuario se le permite obtener acceso en este momento. Debe entenderse que el usuario ha sido previamente validado por un módulo de autenticación. Esta función comprueba otras cosas. Tales cosas pueden ser: la hora del día o la fecha, la línea del terminal, el nombre de host remoto, etc. Esta función también puede determinar cosas como la expiración de las contraseñas y responder que el usuario debe cambiarla antes de continuar.

Las banderas válidas, que pueden ser OR'd lógicamente con PAM_SILENT, son:

PAM_SILENT

No emita ningún mensaje.

PAM_DISALLOW_NULL_AUTHTOK

Devuelve PAM_AUTH_ERR si la base de datos de tokens de autenticación para este mecanismo de autenticación tiene una entrada NULL para el usuario.

VALORES DE RETORNO

PAM_ACCT_EXPIRED

La cuenta del usuario ha expirado.

PAM_AUTH_ERR

Error de autenticación.

PAM_NEW_AUTHTOK_REQD

El token de autenticación del usuario ha expirado. Antes de llamar a esta función de nuevo, la aplicación organizará que se proporcione uno nuevo. Esto probablemente resultará en una llamada a pam_sm_chauthtok().

PAM_PERM_DENIED

Permiso denegado.

PAM_SUCCESS

El token de autenticación se actualizó correctamente.

PAM_USER_UNKNOWN

Usuario desconocido para el servicio de contraseñas.
