PARTCLONE.NTFSFIXB(8) Manual de usuario de Partclone PARTCLONE.NTFSFIXB(8)

NOMBRE

partclone.ntfsfixboot - se ocupa de la estupidez al mover sistemas de archivos NTFS.

SINOPSIS

partclone.ntfsfixboot [-w] [-h n] [-t n] [-s n] [-b] [-f] [-p] {DISPOSITIVO}

DESCRIPCIÓN

partclone.ntfsfixboot NO es parte del proyecto Partclone, pero se incluye para corregir problemas de arranque de NTFS. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se utilizan e2fslibs para leer el bloque usado de la partición ext2.

Partclone.ntfsfixboot se ocupa de la estupidez al mover sistemas de archivos NTFS. Escrito por Orgad Shaneh (2009) y Daniel J. Grace (2006).

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, se incluye un resumen de las opciones a continuación.

-w

Escribe un nuevo sector de inicio en la partición.

-h num

Especifica el número de cabezales por pista. Si se omite, se determina mediante ioctl.

-t num

Especifica el número de sectores por pista. Si se omite, se determina mediante ioctl.

-s num

Nuevo sector de inicio para escribir. Si se omite, se determina mediante ioctl.

-b

Procede incluso si el dispositivo especificado no es una partición.

-f

Fuerza la operación incluso si el dispositivo no parece ser una partición NTFS válida o los valores son iguales.

-p

Imprime información de depuración (valores leídos, valores solicitados, etc.

dispositivo

donde dispositivo apunta a una partición NTFS

DIAGNÓSTICOS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone.ntfsfixboot proporciona algunos códigos de retorno, que pueden usarse en scripts:

Código Diagnóstico
0 éxito (los valores son correctos o se cambiaron correctamente)
1 se necesita un cambio, pero no se especificó -w
2 ocurrió un error
