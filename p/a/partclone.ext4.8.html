PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se usan e2fslibs para leer el bloque utilizado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de Archivos            partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS No Soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo de origen ARCHIVO. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de tu acción. Normalmente, la fuente de copia de seguridad es el dispositivo, la fuente de restauración es el archivo de imagen.

La recepción de datos de una tubería está soportada SÓLO para la restauración, simplemente ignora la opción -s o usa '-' para recibir datos desde stdin.

-o ARCHIVO, --output ARCHIVO

Archivo de salida ARCHIVO. El ARCHIVO puede ser un archivo de imagen (partclone generará) o un dispositivo dependiendo de tu acción. Normalmente, la salida de copia de seguridad va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a una tubería también está soportado SÓLO para copias de seguridad, simplemente ignora la opción -o o usa '-' para enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, origen y salida son ambos dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque usadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Creando un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Colocar una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No comprobar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utilizar la Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de comprobación crc.

-F, --force

Forzar el progreso.

-f seg, --UI-fresh seg

Establecer un intervalo de segundos específico.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar el mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de verificación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Cálculo rápido, detección básica)

2: xxHash, un algoritmo hash no criptográfico extremadamente rápido.

-kX, --blocks-per-checksum=X

Escribir una suma de verificación por cada X bloques.

-w, --skip_write_error

Continuar la restauración mientras ocurren errores de escritura.

--write-direct-io

Escribir datos en la partición de destino sin caché.

--read-direct-io

Leer datos de la partición de origen sin caché.

-B, --no_block_detail

Mostrar el mensaje de progreso sin detalles de bloque.

--binary-prefix

Mostrar el progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Mostrar el progreso en segundos (por defecto es minutos).

-E, --offset=X

Añadir un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT, pero solo generar torrent.

-n, --note NOTA

Mostrar Mensaje NOTA (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar la versi

EJEMPLOS

 clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restaurar imagen desde clonezilla (dividida, gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden ser emitidos en stderr:

partclone proporciona algunos códigos de retorno, que pueden ser usados en scripts:

Código Diagnóstico
0 El programa terminó exitosamente.
1 La clonación o restauración parecen haber fallado.
