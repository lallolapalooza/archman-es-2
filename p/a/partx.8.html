PARTX(8) Administración del Sistema PARTX(8)

NOMBRE

partx - informa al kernel sobre la presencia y numeración de particiones en disco

SINOPSIS

partx [-a|-d|-P|-r|-s|-u] [-t tipo] [-n M:_N_] [-] disco

partx [-a|-d|-P|-r|-s|-u] [-t tipo] partición [disco]

DESCRIPCIÓN

Dado un dispositivo o una imagen de disco, partx intenta analizar la tabla de particiones y listar su contenido. También puede indicar al kernel que agregue o elimine particiones de su contabilidad.

El argumento disco es opcional cuando se proporciona un argumento partición. Para forzar el escaneo de una partición como si fuera un disco completo (por ejemplo, para listar subparticiones anidadas), use el argumento "-" (guion). Por ejemplo:

partx --show - /dev/sda3

Esto verá sda3 como un disco completo en lugar de una partición.

partx NO es un programa fdisk - agregar y eliminar particiones no cambia el disco, solo informa al kernel sobre la presencia y numeración de las particiones en disco.

OPCIONES

-a, --add

Agrega las particiones especificadas, o lee el disco y agrega todas las particiones.

-b, --bytes

Muestra los tamaños en bytes en lugar de en formato legible por humanos.

Por defecto, la unidad en la que se expresan los tamaños es el byte, y los prefijos de unidad están en potencias de 2^10 (1024). Las abreviaturas de los símbolos se muestran truncadas para mejorar la legibilidad, mostrando solo la primera letra de ellas; ejemplos: "1 KiB" y "1 MiB" se muestran respectivamente como "1 K" y "1 M", omitiendo a propósito la mención "iB", que es parte de estas abreviaturas.

-d, --delete

Elimina las particiones especificadas o todas las particiones. No es un error eliminar particiones inexistentes, por lo que esta opción se puede usar junto con rangos amplios de --nr sin preocuparse por el conjunto actual de particiones en el dispositivo.

-g, --noheadings

No imprime una línea de encabezado con --show o --raw.

-l, --list

Lista las particiones. Tenga en cuenta que todos los números están en sectores de 512 bytes. Este formato de salida está OBSOLETO en favor de --show. No lo use en scripts recién escritos.

-n, --nr M:N

Especifica el rango de particiones. Para compatibilidad con versiones anteriores, también se admite el formato M-N. El rango puede contener números negativos, por ejemplo, --nr -1:-1 significa la última partición, y --nr -2:-1 significa las últimas dos particiones. Las especificaciones de rango admitidas son:

M

Especifica solo una partición (por ejemplo, --nr 3).

M:

Especifica solo el límite inferior (por ejemplo, --nr 2:).

:N

Especifica solo el límite superior (por ejemplo, --nr :4).

M:N

Especifica los límites inferior y superior (por ejemplo, --nr 2:4).

-o, --output lista

Define las columnas de salida a utilizar para la salida --show, --pairs y --raw. Si no se especifica ninguna disposición de salida, se utiliza un conjunto predeterminado. Utilice --help para obtener una lista de todas las columnas admitidas. Esta opción no se puede combinar con las opciones --add, --delete, --update o --list.

--output-all

Muestra todas las columnas disponibles.

-P, --pairs

Lista las particiones usando el formato CLAVE="valor".

-r, --raw

Lista las particiones usando el formato de salida sin procesar.

-s, --show

Lista las particiones. Las columnas de salida se pueden seleccionar y reorganizar con la opción --output. Todos los números (excepto SIZE) están en sectores de 512 bytes.

-t, --type tipo

Especifica el tipo de tabla de particiones.

--list-types

Lista los tipos de partición admitidos y sale.

-u, --update

Actualiza las particiones especificadas.

-S, --sector-size tamaño

Sobrescribe el tamaño de sector predeterminado.

-v, --verbose

Modo detallado.

-h, --help

Muestra el texto de ayuda y sale.

-V, --version

Muestra la versión y sale.

AMBIENTE

LIBBLKID_DEBUG=all

habilita la salida de depuración de libblkid.

EJEMPLO

partx --show /dev/sdb3, partx --show --nr 3 /dev/sdb, partx --show /dev/sdb3 /dev/sdb

Todos los tres comandos listan la partición 3 de /dev/sdb.

partx --show - /dev/sdb3

Lista todas las subparticiones en /dev/sdb3 (el dispositivo se usa como disco completo).

partx -o START -g --nr 5 /dev/sdb

Muestra el sector de inicio de la partición 5 en /dev/sdb sin encabezado.

partx -o SECTORS,SIZE /dev/sda5 /dev/sda

Lista la longitud en sectores y el tamaño legible por humanos de la partición 5 en /dev/sda.

partx --add --nr 3:5 /dev/sdd

Agrega todas las particiones disponibles del 3 al 5 (inclusive) en /dev/sdd.

partx -d --nr -1: /dev/sdd

Elimina la última partición en /dev/sdd.

partx(8)

Manual page for partx(8)

NAME

partx — report or manipulate the block device partition table

SYNOPSIS

partx [-a|--show-all] [-b|--bytes] [-r|--raw] [-s|--sizes] [-u|--update] [-v|--verbose] [-n partition-range] [-g|--first-partition] [-l|--last-partition] device [partition ...]

partx [-d|--delete] [-a|--show-all] [-v|--verbose] [-n partition-range] device

partx [-a|--show-all] [-v|--verbose] [-w|--write] [-n partition-range] device

DESCRIPTION

partx reports partition information for a specified block device. It can also be used to add or delete partitions from the partition table. The tool reads the partition table from the given device and prints the partition information to standard output.

The tool supports MBR, Sun, GPT and other partition table formats. It is mostly a frontend for the libparted functions.

The optional partition arguments specify which partitions to report. If no partitions are specified, all partitions are reported.

The options -a, -b, -r, -s, -u, -v, -g, -l, -d, -w and -n are described in detail below.

OPTIONS

-a, --show-all

Show all partitions, including the existing ones. This option is useful when used with -d or -w to see the partition table state before and after the operation.

-b, --bytes

Print sizes in bytes instead of sectors.

-r, --raw

Print partition information in a raw, machine-readable format. This format is intended for use by scripts and may change between versions.

-s, --sizes

Print partition sizes in sectors and the total capacity of the disk in sectors. This option is useful for scripting and for obtaining low-level disk information.

-u, --update

Update the partition table on the device. This option should be used with caution as it modifies the partition table. It is often used in conjunction with other options to add or delete partitions.

-v, --verbose

Be verbose. This option provides more detailed output, including the partition type, bootable flag, and other relevant information. It is helpful for debugging and for understanding the partition table structure.

-n partition-range, --partitions partition-range

Specify a range of partitions to operate on. The partition-range should be in the format start:end, where start and end are partition numbers. For example, -n 1:5 would operate on partitions 1 through 5.

-g, --first-partition

Select only the first partition on the device.

-l, --last-partition

Select only the last partition on the device.

-d, --delete

Delete the specified partitions from the partition table. This option should be used with extreme caution as it can lead to data loss if used incorrectly.

-w, --write

Write the partition table to the device. This option is used in conjunction with other options to add or modify partitions. It is typically used after specifying the new partition layout.

ENVIRONMENT

No specific environment variables affect the behavior of partx.

EXAMPLE

To display all partitions on a device /dev/sda in bytes:

partx -b -a /dev/sda

To delete partition 3 from the device /dev/sdb:

partx -d /dev/sdb 3

To add a new partition (typically done with other tools like fdisk or parted) and then write the changes to the device:

partx -w /dev/sdc
