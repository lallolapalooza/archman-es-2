PARTCLONE(8) Partclone User Manual PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También es compatible con algunos sistemas operativos no linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS DE APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], lo cual es muy similar a fsck o mkfs. Por ejemplo, para respaldar/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos                 partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo de fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de su acción. Normalmente, la fuente de respaldo es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos de una tubería solo es compatible con la restauración, simplemente ignore la opción -s o use '-' para indicar recibir datos desde la entrada estándar.

-o ARCHIVO, --output ARCHIVO

Archivo de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo dependiendo de su acción. Normalmente, la salida de respaldo va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a una tubería también es compatible SOLO para respaldo, simplemente ignore la opción -o o use '-' para indicar enviar datos a la salida estándar.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloque usadas y ? marca las áreas libres.

--offset_domain=X

Agrega X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restore_raw_file

Crear un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Poner una ruta especial para registrar la información del registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de los errores de lectura del disco.

-C, --no_check

No verificar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de comprobación crc.

-F, --force

Forzar el progreso.

-f seg, --UI-fresh seg

Establecer un intervalo de segundos diferente para la actualización.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar el mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada

-aX, --checksum-mode=X

Fórmula de suma de verificación a utilizar para agregar detección de errores

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

2: xxHash, algoritmo hash extremadamente rápido no criptográfico

-kX, --blocks-per-checksum=X

Escribir una suma de verificación por cada X bloques

-w, --skip_write_error

Continuar la restauración durante errores de escritura

--write-direct-io

Escribir datos en la partición de DESTINO sin caché

--read-direct-io

Leer datos desde la partición de FUENTE sin caché

-B, --no_block_detail

Mostrar el mensaje de progreso sin detalles de bloque

--binary-prefix

Mostrar el progreso con tamaño de bits (por defecto es MB, GB...)

--prog-second

Mostrar el progreso en segundos (por defecto es minuto)

-E, --offset=X

Agregar un desplazamiento X (bytes) a la SALIDA

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-n, --note NOTE

Mostrar Mensaje de Nota (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar vers

NOMBRE

partclone.ext3 - partclone para sistema de archivos ext3.

SINOPSIS

partclone.ext3 [-a] [-b] [-c] [-d] [-f] [-g] [-i] [-k] [-l] [-m] [-n] [-N] [-o OF] [-p P] [-q] [-r] [-s SF] [-T] [-v] [-x] [-z Z]

DESCRIPCIÓN

partclone es una utilidad de clonación de particiones inspirada en Clonezilla. Está diseñada para clonar y restaurar una partición de un sistema de archivos a nivel de bloque. partclone está diseñada para ser más eficiente que dd, ya que solo copia los bloques utilizados en el sistema de archivos. Esto puede ahorrar una cantidad significativa de tiempo y espacio en disco, especialmente en particiones grandes que están en su mayoría vacías.

partclone.ext3 es un programa específico para el sistema de archivos ext3. Admite los sistemas de archivos ext2, ext3 y ext4.

OPCIONES

Las opciones son las mismas que las de partclone. Consulte la página del manual de partclone para obtener una lista completa de opciones.

Opciones comunes:

-c
Clonar partición.
-r
Restaurar partición.
-s SF
Especificar archivo o dispositivo de origen.
-o OF
Especificar archivo o dispositivo de destino.
-d
Mostrar información de depuración.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone

EJEMPLOS

 clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restaurar imagen de clonezilla (dividida, gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone proporciona algunos códigos de retorno, que pueden usarse en scripts:

Código Diagnóstico
0 El programa salió con éxito.
1 La clonación o restauración parecen haber fallado.
