pathname(7) Manual de Información Miscelánea pathname(7)

NOMBRE

pathname, filename - cómo se codifican e interpretan las rutas de nombres

DESCRIPCIÓN

Algunas llamadas al sistema te permiten pasar una ruta de nombre como parámetro. Al escribir código que maneja rutas de nombres, hay requisitos del espacio del kernel que debes cumplir y requisitos del espacio del usuario que debes cumplir.

El kernel almacena las rutas de nombres como cadenas C, es decir, secuencias de bytes no nulos terminadas por un byte nulo. Hay algunas reglas generales que se aplican a todas las rutas de nombres:

•
El último byte de la secuencia debe ser un byte nulo.
•
Cualquier otro byte en la secuencia debe ser un byte no nulo.
•
Un byte 0x2F ('/') siempre se interpreta como un separador de directorios y no puede formar parte de un nombre de archivo.
•
Una ruta de nombre puede tener como máximo PATH_MAX bytes de longitud (ver limits.h(0p)). Una ruta de nombre que sea más larga que PATH_MAX bytes puede dividirse en varias rutas de nombres más pequeñas y abrirse pieza por pieza utilizando openat(2).
•
Un nombre de archivo puede tener como máximo un cierto número de bytes de longitud. El número depende del sistema de archivos (ver _PC_NAME_MAX en fpathconf(3)). Para máxima portabilidad, los programas deben ser capaces de manejar nombres de archivo tan largos como los sistemas de archivos relevantes lo permitan. Para máxima portabilidad, los programas y los usuarios deben limitar la longitud de sus propias rutas de nombres a NAME_MAX bytes (ver limits.h(0p)).

Algunos sistemas de archivos o APIs pueden aplicar restricciones adicionales, como requerir nombres de archivo más cortos, o restringir los bytes permitidos en un nombre de archivo.

Para una máxima interoperabilidad, los programas y los usuarios también deben limitar los caracteres que utilizan para sus propias rutas de nombres a los caracteres del Conjunto de Caracteres de Nombres de Archivo Portátiles de POSIX.

VERSIÓN

POSIX.1-2024 alienta a las implementaciones a no permitir la creación de nombres de archivo que contengan caracteres de nueva línea. Linux no sigue esto y permite el uso de caracteres de nueva línea.

VER TAMBIÉN

limits.h(0p), open(2), fpathconf(3), path_resolution(7), mount(8)
