PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - Utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] origen} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque usado de una partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar de forma similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de Archivos                 partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (Sistemas de Archivos No Soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo según tu acción. Normalmente, el origen de la copia de seguridad es un dispositivo, el origen de la restauración es un archivo de imagen.

La recepción de datos desde una tubería (pipe) sólo se admite para la restauración, ignora la opción -s o usa '-' para indicar que se reciben datos desde la entrada estándar (stdin).

-o ARCHIVO, --output ARCHIVO

Archivo de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo según tu acción. Normalmente, la copia de seguridad se envía a un archivo de imagen y la restauración se envía a un dispositivo.

El envío de datos a una tubería también está admitido SÓLO para copias de seguridad, ignora la opción -o o usa '-' para indicar que se envían datos a la salida estándar (stdout).

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe el ARCHIVO, si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo de bucle (loop device).

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, origen y salida son ambos dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca áreas de bloques usados y ? marca áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Crea un archivo raw especial para el dispositivo de bucle.

-L ARCHIVO, --logfile ARCHIVO

Especifica una ruta para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de los errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza una Interfaz Gráfica de Texto (TUI) basada en Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora los errores de comprobación CRC.

-F, --force

Forzar el progreso.

-f segundos, --UI-fresh segundos

Especifica un intervalo de tiempo en segundos para actualizar la interfaz.

-z tamaño, --buffer_size tamaño

Tamaño del buffer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Deshabilita el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Cálculo rápido, detección básica)

2: xxHash, un algoritmo de hash extremadamente rápido no criptográfico.

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continúa la restauración durante errores de escritura.

--write-direct-io

Escribe datos en la partición DESTINO sin caché.

--read-direct-io

Lee datos desde la partición ORIGEN sin caché.

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques.

--binary-prefix

Muestra el progreso con tamaño en bits (por defecto es MB, GB...).

--prog-second

Muestra el progreso en segundos (por defecto es minutos).

-E, --offset=X

Añade un desplazamiento X (en bytes) a la SALIDA.

-T, --btfiles

Restaura el bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura el bloque como archivo para ClonezillaBT pero sólo genera el torrent.

-n, --note NOTA

Muestra un mensaje de NOTA (128 palabras).

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión

partclone.ext3(8) — Partclone manual

NAME

partclone.ext3 - clone, restore and check ext2/ext3/ext4 filesystem.

SYNOPSIS

partclone.ext3 [OPTIONS] [-s SOURCE] [-o OUTPUT]

DESCRIPTION

partclone.ext3 is a tool to clone, restore and check ext2/ext3/ext4 filesystem. It is part of the partclone utilities.

partclone.ext3 can clone a filesystem to an image file or another partition. It can also restore an image file to a partition.

The main feature of partclone is that it only copies the used blocks of the filesystem. This makes the cloning process much faster and the resulting image files smaller.

OPTIONS

The following options are available:

-c, --clone
Clone the source filesystem to the output.
-r, --restore
Restore the source image file to the output partition.
-s, --source SOURCE
Specify the source device or image file.
-o, --output OUTPUT
Specify the output device or image file.
-d, --debug
Enable debug messages.
-v, --verbose
Enable verbose output.
-i, --info
Display filesystem information.
-n, --ncurses
Use ncurses interface for progress display.
-h, --help
Display help message and exit.
-V, --version
Display version information and exit.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
