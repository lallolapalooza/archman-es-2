NOMBRE

pamtohtmltbl - convierte una imagen visual pnm/pam a una tabla HTML

SINOPSIS

pamtohtmltbl [-transparente=color] [-verbose] [archivo]

La abreviatura mínima única de la opción es aceptable. Puede usar guiones dobles en lugar de guiones simples para indicar opciones. Puede usar espacios en blanco en lugar del signo igual para separar un nombre de opción de su valor.

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pamtohtmltbl convierte una imagen visual a una tabla HTML con una celda por píxel. La celda está vacía, pero su color de fondo es el del píxel.

archivo es un archivo PBM, PGM, PPM o PAM. Si es PAM, debe ser una imagen visual estándar de tipo de tupla RGB, ESCALA DE GRISES o BLANCO Y NEGRO, o algo equivalente con canales adicionales de número superior, pero pamtohtmltbl no verifica el tipo de tupla; simplemente lo asume.

Tenga en cuenta que la forma más normal de incluir una imagen visual en un documento HTML es con una etiqueta <IMG>.

No todos los navegadores web renderizan las tablas como pamtohtmltbl espera, y por lo tanto muestran una imagen muy distorsionada. Se ha observado que Internet Explorer 7 en Windows y Opera 9.02 en Windows funcionan; Firefox 2.0.0.16 en el mismo sistema Windows se ha observado que no.

OPCIONES

-transparente=color
Esta opción indica que los píxeles del color especificado deben ser transparentes en la tabla HTML. La celda de la tabla para un píxel de este color no tendrá especificado ningún color de fondo.

Especifique el color (color) como se describe para la rutina de la biblioteca de argumentos de ppm_parsecolor().

-verbose
Esta opción hace que pamtohtmltbl muestre mensajes sobre el proceso de conversión.

AUTORES
