XCRYPT(3) Manual de funciones de biblioteca XCRYPT(3)

NOMBRE

xencrypt, xdecrypt, passwd2des - Cifrado de contraseña RFS

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <rpc/des_crypt.h>
void passwd2des(char *passwd, char *key);
int xencrypt(char *secret, char *passwd);
int xdecrypt(char *secret, char *passwd);

DESCRIPCIÓN

ADVERTENCIA: No utilice estas funciones en código nuevo. No ofrecen ninguna garantía de seguridad criptográfica aceptable.

La función passwd2des() toma una cadena de caracteres passwd de longitud arbitraria y rellena un array de caracteres key de longitud 8. El array key es adecuado para su uso como clave DES. Tiene paridad impar establecida en el bit 0 de cada byte. Las otras dos funciones descritas aquí utilizan esta función para convertir su argumento passwd en una clave DES.

La función xencrypt() toma la cadena de caracteres ASCII secret dada en hexadecimal, que debe tener una longitud múltiplo de 16, la cifra utilizando la clave DES derivada de passwd por passwd2des(), y devuelve el resultado de nuevo en secret como una cadena hexadecimal de la misma longitud.

La función xdecrypt() realiza la operación inversa.

VALOR DE RETORNO

Las funciones xencrypt() y xdecrypt() devuelven 1 en caso de éxito y 0 en caso de error.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, véase atributos(7).

Interfaz Atributo Valor
passwd2des (), xencrypt (), xdecrypt () Seguridad en hilos MT-Safe

VERSIÓNES

Estas funciones están disponibles desde glibc 2.1.

ERRORES

Los prototipos faltan en el archivo de inclusión mencionado anteriormente.
