PASS(1) Store de contraseñas PASS(1)

NOMBRE

pass - almacena, recupera, genera y sincroniza contraseñas de forma segura

SINOPSIS

pass [ COMANDO ] [ OPCIONES ]... [ ARGUMENTOS ]...

DESCRIPCIÓN

pass es un gestor de contraseñas muy simple que guarda las contraseñas dentro de archivos cifrados con gpg2(1) en un árbol de directorios simple que reside en ~/.password-store. La utilidad pass proporciona una serie de comandos para manipular el almacén de contraseñas, permitiendo al usuario añadir, eliminar, editar, sincronizar, generar y manipular contraseñas.

Si no se especifica ningún COMANDO, el COMANDO por defecto es show o ls, dependiendo del tipo de especificador en ARGUMENTOS. Alternativamente, si PASSWORD_STORE_ENABLE_EXTENSIONS está establecido a "true", y el archivo .extensions/COMANDO.bash existe dentro del almacén de contraseñas y es ejecutable, entonces se carga en el entorno, pasando cualquier argumento y variable de entorno. Las extensiones que existen en un directorio de todo el sistema, solo instalables por el administrador, están siempre habilitadas.

De lo contrario, COMANDO debe ser uno de los comandos válidos listados a continuación.

Varios de los comandos listados a continuación dependen o proporcionan funcionalidad adicional si el directorio del almacén de contraseñas es también un repositorio git. Si el directorio del almacén de contraseñas es un repositorio git, todos los comandos de modificación del almacén de contraseñas causarán un commit git correspondiente. Los subdirectorios pueden ser repositorios git anidados separados, y pass usará el directorio más interno en relación con la contraseña actual. Véase la sección EJEMPLO GIT EXTENDIDO para una descripción detallada usando init y git(1).

El comando init debe ejecutarse antes que otros comandos para inicializar el almacén de contraseñas con el ID de clave gpg correcto. Las contraseñas se cifran utilizando la clave gpg establecida con init.

Existe un script de completado bash correspondiente para su uso con la tabulación de nombres de contraseñas en bash(1).

COMANDOS

init [ --path=sub-carpeta, -p sub-carpeta ] gpg-id...
Inicializa un nuevo almacenamiento de contraseñas y utiliza gpg-id para el cifrado. Se pueden especificar múltiples gpg-ids, para cifrar cada contraseña con varios ids. Este comando debe ejecutarse primero antes de que se pueda usar un almacén de contraseñas. Si el gpg-id especificado es diferente de la clave utilizada en cualquier archivo existente, estos archivos se volverán a cifrar para usar el nuevo id. Tenga en cuenta que se recomienda el uso de gpg-agent(1) para que el descifrado por lotes no requiera tanta intervención del usuario. Si se especifica --path o -p, junto con un argumento, se asigna un gpg-id específico o un conjunto de gpg-ids para esa subcarpeta específica del almacén de contraseñas. Si solo se proporciona un gpg-id, y es una cadena vacía, entonces se elimina el archivo .gpg-id actual para la subcarpeta especificada (o la raíz si no se especifica).
ls subcarpeta
Lista los nombres de las contraseñas dentro del árbol en subcarpeta utilizando el programa tree(1). Este comando se llama alternativamente list.
grep [OPCIONES_GREP] cadena-buscada
Busca dentro de cada archivo de contraseña descifrado la cadena-buscada, y muestra la línea que contiene la cadena coincidente junto con el nombre del archivo. Utiliza grep(1) para la coincidencia. OPCIONES_GREP se pasan a grep(1) tal cual. (Nota: la variable de entorno GREP_OPTIONS también funciona).
find nombres-contraseña...
Lista los nombres de las contraseñas dentro del árbol que coinciden con nombres-contraseña utilizando el programa tree(1). Este comando se llama alternativamente search.
show [ --clip[=número-de-línea], -c[número-de-línea] ] [ --qrcode[=número-de-línea], -q[número-de-línea] ] nombre-contraseña
Descifra e imprime una contraseña llamada nombre-contraseña. Si se especifica --clip o -c, no imprime la contraseña sino que copia la primera línea (o la especificada) al portapapeles utilizando xclip(1) o wl-clipboard(1) y luego restaura el portapapeles después de 45 segundos (o PASSWORD_STORE_CLIP_TIME). Si se especifica --qrcode o -q, no imprime la contraseña sino que muestra un código QR utilizando qrencode(1) ya sea en la terminal o gráficamente si es compatible.
insert [ --echo, -e | --multiline, -m ] [ --force, -f ] nombre-contraseña
Inserta una nueva contraseña en el almacén de contraseñas llamada nombre-contraseña. Esto leerá la nueva contraseña desde la entrada estándar. Si --echo o -e *no* se especifica, deshabilita el eco del teclado cuando se ingresa la contraseña y confirma la contraseña pidiéndola dos veces. Si se especifica --multiline o -m, se leerán líneas hasta EOF o se presione Ctrl+D. De lo contrario, solo se lee una sola línea de la entrada estándar. Pregunta antes de sobrescribir una contraseña existente, a menos que se especifique --force o -f. Este comando se llama alternativamente add.
edit nombre-contraseña
Inserta una nueva contraseña o edita una contraseña existente utilizando el editor de texto predeterminado especificado por la variable de entorno EDITOR o utilizando vi(1) como respaldo. Este modo hace uso de archivos temporales para editar, pero se tiene cuidado para asegurar que los archivos temporales se creen en /dev/shm para evitar escribir en sectores de disco difíciles de borrar. Si /dev/shm no es accesible, se recurre a la ubicación ordinaria de TMPDIR y se muestra una advertencia.
generate [ --no-symbols, -n ] [ --clip, -c ] [ --in-place, -i | --force, -f ] nombre-contraseña [longitud-contraseña]
Genera una nueva contraseña utilizando /dev/urandom de longitud longitud-contraseña (o PASSWORD_STORE_GENERATED_LENGTH si no se especifica) e inserta en nombre-contraseña. Si se especifica --no-symbols o -n, no se utilizan caracteres no alfanuméricos en la contraseña generada. Los conjuntos de caracteres utilizados en la generación de contraseñas se pueden cambiar con las variables de entorno PASSWORD_STORE_CHARACTER_SET y PASSWORD_STORE_CHARACTER_SET_NO_SYMBOLS, descritas a continuación. Si se especifica --clip o -c, no imprime la contraseña sino que la copia al portapapeles utilizando xclip(1) o wl-clipboard(1) y luego restaura el portapapeles después de 45 segundos (o PASSWORD_STORE_CLIP_TIME). Si se especifica --qrcode o -q, no imprime la contraseña sino que muestra un código QR utilizando qrencode(1) ya sea en la terminal o gráficamente si es compatible. Pregunta antes de sobrescribir una contraseña existente, a menos que se especifique --force o -f. Si se especifica --in-place o -i, no pregunta interactivamente, y solo reemplaza la primera línea del archivo de contraseña con la nueva contraseña generada, manteniendo el resto del archivo intacto.
rm [ --recursive, -r ] [ --force, -f ] nombre-contraseña
Elimina la contraseña llamada nombre-contraseña del almacén de contraseñas. Este comando se llama alternativamente remove o delete. Si se especifica --recursive o -r, elimina recursivamente nombre-contraseña si es un directorio. Si se especifica --force o -f, no pregunta interactivamente antes de la eliminación.
mv [ --force, -f ] ruta-antigua ruta-nueva
Renombra la contraseña o directorio llamado ruta-antigua a ruta-nueva. Este comando se llama alternativamente rename. Si se especifica --force, sobrescribe silenciosamente ruta-nueva si existe. Si ruta-nueva termina con una barra diagonal (/), siempre se trata como un directorio. Las contraseñas se vuelven a cifrar selectivamente a las claves correspondientes de su nuevo destino.
cp [ --force, -f

COMMANDS

copy old-path new-path
Copia la contraseña o el directorio llamado old-path a new-path. Este comando tiene el nombre alternativo copy. Si se especifica --force, sobrescribe silenciosamente new-path si existe. Si new-path termina en /, siempre se trata como un directorio. Las contraseñas se re-cifran selectivamente a las claves correspondientes de su nuevo destino.
git git-command-args...
Si el almacén de contraseñas es un repositorio git, pasa git-command-args como argumentos a git(1) utilizando el almacén de contraseñas como repositorio git. Si git-command-args es init, además de inicializar el repositorio git, añade el contenido actual del almacén de contraseñas al repositorio en un commit inicial. Si la clave de configuración git pass.signcommits está establecida a true, entonces todos los commits se firmarán utilizando user.signingkey o la clave de firma git por defecto. Esta clave de configuración puede activarse usando: `pass git config --bool --add pass.signcommits true`
help
Muestra el mensaje de uso.
version
Muestra información de la versión.

EJEMPLOS SIMPLES

Inicializar el almacén de contraseñas
zx2c4@laptop ~ $ pass init Jason@zx2c4.com
mkdir: created directory ‘/home/zx2c4/.password-store’
Password store initialized for Jason@zx2c4.com.
Listar las contraseñas existentes en el almacén
zx2c4@laptop ~ $ pass
Password Store
├── Business
│ ├── some-silly-business-site.com
│ └── another-business-site.net
├── Email
│ ├── donenfeld.com
│ └── zx2c4.com
└── France
├── bank
├── freebox
└── mobilephone

Alternativamente, "pass ls".

Buscar contraseñas existentes en el almacén que coincidan con .com
zx2c4@laptop ~ $ pass find .com
Search Terms: .com
├── Business
│ ├── some-silly-business-site.com
└── Email
├── donenfeld.com
└── zx2c4.com

Alternativamente, "pass search .com".

Mostrar la contraseña existente
zx2c4@laptop ~ $ pass Email/zx2c4.com
sup3rh4x3rizmynam3
Copiar la contraseña existente al portapapeles
zx2c4@laptop ~ $ pass -c Email/zx2c4.com
Copied Email/jason@zx2c4.com to clipboard. Will clear in 45 seconds.
Añadir contraseña al almacén
zx2c4@laptop ~ $ pass insert Business/cheese-whiz-factory
Enter password for Business/cheese-whiz-factory: omg so much cheese what am i gonna do
Añadir contraseña multilínea al almacén
zx2c4@laptop ~ $ pass insert -m Business/cheese-whiz-factory
Enter contents of Business/cheese-whiz-factory and press Ctrl+D when finished:

Hey this is my
awesome
multi
line
passworrrrrrrrd.
^D

Generar nueva contraseña
zx2c4@laptop ~ $ pass generate Email/jasondonenfeld.com 15
The generated password to Email/jasondonenfeld.com is:
$(-QF&Q=IN2nFBx
Generar nueva contraseña alfanumérica
zx2c4@laptop ~ $ pass generate -n Email/jasondonenfeld.com 12
The generated password to Email/jasondonenfeld.com is:
YqFsMkBeO6di
Generar nueva contraseña y copiarla al portapapeles
zx2c4@laptop ~ $ pass generate -c Email/jasondonenfeld.com 19
Copied Email/jasondonenfeld.com to clipboard. Will clear in 45 seconds.
Eliminar contraseña del almacén
zx2c4@laptop ~ $ pass remove Business/cheese-whiz-factory
rm: remove regular file ‘/home/zx2c4/.password-store/Business/cheese-whiz-factory.gpg’? y
removed ‘/home/zx2c4/.password-store/Business/cheese-whiz-factory.gpg’

ARCHIVOS

~/.password-store
El directorio de almacenamiento de contraseñas por defecto.
~/.password-store/.gpg-id
Contiene la identificación de clave gpg por defecto utilizada para el cifrado y descifrado. Se pueden especificar múltiples claves gpg en este archivo, una por línea. Si este archivo existe en algún subdirectorio, las contraseñas dentro de esos subdirectorios se cifrarán utilizando esas claves. Esto debe configurarse usando el comando init.
~/.password-store/.extensions
El directorio que contiene los archivos de extensión.

VARIABLES DE ENTORNO

PASSWORD_STORE_DIR
Anula el directorio de almacenamiento de contraseñas por defecto.
PASSWORD_STORE_KEY
Anula la identificación de clave gpg por defecto establecida por init. Las claves no deben contener espacios y, por lo tanto, se recomienda el uso de la firma hexadecimal de la clave. Se pueden especificar múltiples claves separadas por espacios.
PASSWORD_STORE_GPG_OPTS
Opciones adicionales que se pasarán a todas las invocaciones de GPG.
PASSWORD_STORE_X_SELECTION
Anula la selección que se pasa a xclip, por defecto clipboard. Consulte xclip(1) para más información.
PASSWORD_STORE_CLIP_TIME
Especifica el número de segundos a esperar antes de restaurar el portapapeles, por defecto 45 segundos.
PASSWORD_STORE_UMASK
Establece la máscara de creación de archivos (umask) de todos los archivos modificados por pass, por defecto 077.
PASSWORD_STORE_GENERATED_LENGTH
La longitud de contraseña por defecto si el parámetro pass-length para generate no se especifica.
PASSWORD_STORE_CHARACTER_SET
El conjunto de caracteres que se utilizará en la generación de contraseñas para generate. Este valor será interpretado por tr. Consulte tr(1) para más información.
PASSWORD_STOR

VARIABLES DE ENTORNO

PASSWORD_STORE_ACCEPT_DECRYPTION_KEYS
Si esta variable está establecida en "true", entonces pass insert preguntará por la clave de descifrado de cada archivo .gpg-id y almacenará las respuestas en el archivo de configuración de GPG. Esto es útil si usted tiene múltiples claves de descifrado para una misma contraseña.
PASSWORD_STORE_CLIP_TIME
El número de segundos que la contraseña permanecerá en el portapapeles. El valor por defecto es 45 segundos. Si se establece en 0, la contraseña nunca se borrará del portapapeles. Si se establece en un valor negativo, la contraseña no se copiará al portapapeles en absoluto.
PASSWORD_STORE_DIR
El directorio donde se almacenan las contraseñas. El valor por defecto es $HOME/.password-store.
PASSWORD_STORE_ENABLE_EXTENSIONS
Esta variable de entorno debe establecerse en "true" para que las extensiones estén habilitadas.
PASSWORD_STORE_EXTENSIONS_DIR
La ubicación donde buscar archivos ejecutables de extensión, por defecto PASSWORD_STORE_DIR/.extensions.
PASSWORD_STORE_GENERATION_LENGTH
La longitud de la contraseña a generar por defecto para generate.
PASSWORD_STORE_NO_SYMBOLS
Si esta variable está establecida, generate no usará símbolos en la contraseña generada. Equivale a la opción --no-symbols.
PASSWORD_STORE_PASSFILE_DIR
El directorio donde se almacenan los archivos de contraseña. Por defecto, es PASSWORD_STORE_DIR.
PASSWORD_STORE_SIGNING_KEY
Si esta variable de entorno está establecida, entonces todos los archivos .gpg-id y los archivos de extensión no del sistema deben ser firmados usando una firma separada con la clave GPG especificada por el fingerprint completo de 40 caracteres en mayúsculas en esta variable. Si se especifican múltiples fingerprints, cada uno separado por un espacio en blanco, entonces las firmas deben coincidir al menos con una. El comando init mantendrá actualizadas las firmas de los archivos .gpg-id.
PASSWORD_STORE_USE_SUDO
Si esta variable está establecida en "true", entonces pass git se ejecutará usando sudo para evitar problemas de permisos con el repositorio git. Es necesario que el usuario actual tenga permisos para ejecutar comandos git como root vía sudo, lo cual se configura normalmente en el archivo /etc/sudoers.
EDITOR
La ubicación del editor de texto utilizado por edit.

VER TAMBIEN
