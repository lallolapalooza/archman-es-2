NOMBRE

pam_sm_open_session - función del módulo de servicio para iniciar la gestión de sesiones

SINOPSIS

#include <security/pam_modules.h>

int pam_sm_open_session(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPCIÓN

La función pam_sm_open_session es la implementación del módulo de servicio de la interfaz pam_open_session(3).

Esta función se llama para iniciar una sesión. El único valor válido para flags es cero o:

PAM_SILENT

No emitir ningún mensaje.

VALORES DE RETORNO

PAM_SESSION_ERR

No se puede crear/eliminar una entrada para la sesión especificada.

PAM_SUCCESS

La sesión se inició correctamente.
