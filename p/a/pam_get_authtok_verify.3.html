NOMBRE

pam_get_authtok, pam_get_authtok_verify, pam_get_authtok_noverify - obtener token de autenticación

SINOPSIS

#include <security/pam_ext.h>

int pam_get_authtok(pam_handle_t *pamh, int item, const char **authtok, const char *prompt);

int pam_get_authtok_noverify(pam_handle_t *pamh, const char **authtok, const char *prompt);

int pam_get_authtok_verify(pam_handle_t *pamh, const char **authtok, const char *prompt);

DESCRIPCIÓN

La función pam_get_authtok devuelve el token de autenticación en caché, o solicita al usuario si no hay ningún token en caché actualmente. Está destinada al uso interno de Linux-PAM y módulos de servicio PAM. Tras una ejecución exitosa, authtok contiene un puntero al valor del token de autenticación. ¡Tenga en cuenta que este es un puntero a los datos *reales* y **no** debe ser liberado con free() ni sobrescrito!

El argumento prompt especifica una solicitud a usar si no hay ningún token en caché. Si se proporciona un puntero NULL, pam_get_authtok utiliza solicitudes predefinidas.

Los siguientes valores son compatibles para item:

PAM_AUTHTOK

Devuelve el token de autenticación actual. Llamado desde pam_sm_chauthtok(3), pam_get_authtok pedirá al usuario que confirme el nuevo token al reingresarlo. Si se especificó una solicitud, se usará "Retype" como prefijo.

PAM_OLDAUTHTOK

Devuelve el token de autenticación anterior al cambiar los tokens de autenticación.

La función pam_get_authtok_noverify solo puede usarse para cambiar la contraseña (desde pam_sm_chauthtok(3)). Devuelve el token de autenticación en caché, o solicita al usuario si no hay ningún token en caché actualmente. La diferencia con pam_get_authtok es que esta función no pide la contraseña una segunda vez para verificarla. Tras una ejecución exitosa, authtok contiene un puntero al valor del token de autenticación. ¡Tenga en cuenta que este es un puntero a los datos *reales* y **no** debe ser liberado con free() ni sobrescrito!

La función pam_get_authtok_verify solo puede usarse para verificar una contraseña contra errores tipográficos obtenidos por pam_get_authtok_noverify(3). Esta función solicita la contraseña una segunda vez y la verifica con la contraseña proporcionada por el argumento authtok. En caso de error, el valor de authtok no está definido. De lo contrario, este argumento apuntará a los datos *reales* y **no** debe ser liberado con free() ni sobrescrito.

OPCIONES

pam_get_authtok respeta las siguientes opciones del módulo:

try_first_pass

Antes de solicitar la contraseña al usuario, el módulo intenta primero la contraseña del módulo apilado anterior en caso de que también satisfaga a este módulo.

use_first_pass

El argumento use_first_pass fuerza al módulo a usar la contraseña de los módulos apilados anteriores y nunca solicitará al usuario; si no hay contraseña disponible o la contraseña no es apropiada, se denegará el acceso al usuario.

use_authtok

Al cambiar la contraseña, obliga al módulo a establecer el nuevo token al proporcionado por un módulo password apilado anteriormente. Si no hay ningún token disponible, el cambio de token fallará.

authtok_type=XXX

La acción predeterminada es que el módulo use las siguientes solicitudes al pedir contraseñas: "New UNIX password: " y "Retype UNIX password: ". La palabra de ejemplo UNIX puede ser reemplazada con esta opción, por defecto está vacía.

VALORES DE RETORNO

PAM_AUTH_ERR

No se pudo recuperar el token de autenticación.

PAM_AUTHTOK_ERR

No se pudo recuperar la nueva autenticación.

PAM_SUCCESS

El token de autenticación se recuperó con éxito.

PAM_SYSTEM_ERR

Se especificó un puntero NULL como manejador PAM, o no se proporcionó espacio para un token de autenticación.

PAM_TRY_AGAIN

Los nuevos tokens de autenticación no coinciden.
