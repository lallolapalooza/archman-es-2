FBB::Pattern(3bobcat) Coincidencia de patrones FBB::Pattern(3bobcat)

NOMBRE

FBB::Pattern - Realiza coincidencias de patrones RE

SINOPSIS

#include <bobcat/pattern>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos Pattern se pueden utilizar para la coincidencia de patrones de Expresiones Regulares (RE). La clase es un envoltorio para la familia de funciones regcomp(3). Por defecto utiliza 'expresiones regulares extendidas', lo que requiere que escapemos multiplicadores y caracteres delimitadores cuando deban interpretarse como caracteres ordinarios (es decir, *, +, ?, ^, $, |, (, ), [, ], {, } deben escaparse cuando se usan como caracteres literales).

La clase Pattern admite el uso de las siguientes secuencias de escape especiales (similares a Perl):
\b - indica un límite de palabra
\d - indica un dígito ([[:digit:]])
\s - indica un espacio en blanco ([:space:])
\w - indica una palabra ([:alnum:])

Las mayúsculas correspondientes (por ejemplo, \W) definen los conjuntos de caracteres complementarios. Los atajos de conjuntos de caracteres en mayúsculas no se expanden dentro de clases de caracteres explícitas (es decir, construcciones [ ... ]). Por lo tanto, [\W] representa un conjunto de dos caracteres: \ y W.

Dado que la barra invertida (\) se trata como un carácter especial, debe manejarse con cuidado. Pattern convierte las secuencias de escape \d \s \w (y fuera de las clases de caracteres explícitas las secuencias \D \S \W) a sus respectivas clases de caracteres. Todas las demás secuencias de escape se mantienen tal cual, y la expresión regular resultante se ofrece a la función de compilación de coincidencia de patrones regcomp(3). Esta función interpreta las secuencias de escape. En consecuencia, se debe tener cuidado al definir patrones que contengan secuencias de escape. Estas son las reglas:

o
Las secuencias de escape especiales (como \d) se convierten en clases de caracteres. Por ejemplo, 
    ---------------------------------------------------------
    Especificar: Convierte a: regcomp usa: Coincide con:
    ---------------------------------------------------------
    \d          [[:digit:]]     [[:digit:]]        3
    ---------------------------------------------------------
o
Las secuencias de escape ordinarias (como \x) se mantienen tal cual. Por ejemplo, 
    ---------------------------------------------------------
    Especificar: Convierte a: regcomp usa: Coincide con:
    ---------------------------------------------------------
    \x          \x              x                  x
    ---------------------------------------------------------
o
Para especificar secuencias de escape literales, se recomiendan las cadenas de caracteres literales (Raw String Literals), ya que no requieren duplicar las secuencias de escape. Por ejemplo, la siguiente expresión regular coincide con una palabra (alfanumérica), seguida de espacios opcionales, dos puntos, más espacios opcionales y un número (decimal): 
    R"((\w+)\s*:\s*\d+)"

DEFINICIÓN DE TIPO

o
Pattern::Position:
Un tipo anidado que representa los desplazamientos del primer carácter y del desplazamiento más allá del último carácter del texto coincidente o de la subexpresión indexada, definido como std::pair<std::string::size_type, std::string::size_type>.

CONSTRUCTORES

o
Pattern():
El constructor por defecto no define ningún patrón, pero está disponible como un marcador de posición para, por ejemplo, contenedores que requieren constructores por defecto. Por lo tanto, un objeto Pattern construido de esta manera no se puede utilizar para hacer coincidir patrones, pero puede ser el lvalue en asignaciones donde otro objeto Pattern es el rvalue. Sin embargo, puede recibir un patrón utilizando el miembro setPattern() (ver más abajo). Se lanza una excepción FBB::Exception si el objeto no pudo ser construido.
o
Pattern(std::string const &pattern, bool caseSensitive = true, size_t nSub = 10, int options = REG_EXTENDED | REG_NEWLINE):
Este constructor compila pattern, preparando el objeto Pattern para las coincidencias de patrones. El segundo parámetro determina si se utilizará la coincidencia sensible a mayúsculas (por defecto) o no. Las subexpresiones se definen mediante pares de paréntesis. Cada par coincidente define una subexpresión, donde el número de orden de sus paréntesis de apertura determina el índice de la subexpresión. Por defecto, se reconocen como máximo 10 subexpresiones. Las banderas options pueden ser:
REG_EXTENDED:
Utiliza la sintaxis de Expresión Regular Extendida POSIX al interpretar regex. Si no se establece, se utiliza la sintaxis de Expresión Regular Básica POSIX.
REG_NOSUB:
No se requiere soporte para la dirección de subcadenas de las coincidencias. Los parámetros nmatch y pmatch de regexec se ignoran si el búfer de patrón suministrado se compiló con esta bandera establecida.
REG_NEWLINE:
Los operadores de coincidencia de cualquier carácter no coinciden con una nueva línea.
Una lista de no coincidencia ([^...]) que no contiene una nueva línea no coincide con una nueva línea.
El operador de principio de línea (^) coincide con la cadena vacía inmediatamente después de una nueva línea, independientemente de si eflags, las banderas de ejecución de regexec, contienen REG_NOTBOL.
El operador de fin de línea ($) coincide con la cadena vacía inmediatamente antes de una nueva línea, independientemente de si eflags contiene REG_NOTEOL.

Están disponibles constructores de copia y movimiento (y operadores de asignación).

FUNCIONES MIEMBRO

Todos los miembros de std::ostringstream y std::exception están disponibles, ya que Pattern hereda de estas clases.

o
std::string before() const:
Después de una coincidencia exitosa, before() devuelve el texto antes del texto coincidente.
o
std::string beyond() const:
Después de una coincidencia exitosa, beyond() devuelve el texto después del texto coincidente.
o
size_t end() const:
Devuelve el número de elementos coincidentes (texto y subexpresiones). end() es el valor de índice más bajo para el cual position() devuelve dos valores std::string::npos (ver la función miembro position(), a continuación).
o
void match(std::string const &text, int options = 0):
Coincide una cadena con un patrón. Si la cadena no pudo ser coincidente, se lanza una excepción Exception, utilizando Pattern::match() como su texto de prefijo.
Las opciones pueden ser:
REG_NOTBOL:
El operador de principio de línea siempre falla al coincidir (pero ver la bandera de compilación REG_NEWLINE anterior). Esta bandera se puede usar cuando se pasan diferentes porciones de una cadena a regexec y el principio de la cadena no debe interpretarse como el principio de la línea.
REG_NOTEOL:
El operador de fin de línea siempre falla al coincidir (pero ver la bandera de compilación REG_NEWLINE)
o
std::string matched() const:
Después de una coincidencia exitosa, esta función devuelve el texto coincidente.
o
std::string const &pattern() const:
Esta función miembro devuelve el patrón que se ofrece a regcomp(3). Devuelve el contenido de una cadena estática que se sobrescribe en cada construcción de un objeto Pattern y en cada llamada a la i

MIEMBROS DE CLASE

o
Pattern(std::string const &pattern, bool caseSensitive = true, size_t nSub = 10, int options = REG_EXTENDED | REG_NEWLINE):
El constructor que crea el objeto Pattern dado un patrón de expresión regular. Si las banderas caseSensitive o options son definidas, el patrón se compilará de acuerdo con ellas. De lo contrario, el patrón será sensible a mayúsculas y minúsculas y las expresiones regulares extendidas con saltos de línea permitidos se aplicarán.

Si nSub se define, entonces se pueden almacenar hasta nSub subexpresiones por cada coincidencia. Si no, se almacenará solo la coincidencia completa.

Una excepción FBB::Exception se lanza si el patrón no se puede compilar.

o
Pattern(Pattern const &other):
El constructor de copia. Crea un nuevo objeto Pattern con el mismo patrón que other.
o
Pattern(Pattern &&other):
El constructor de movimiento.
o
size_t end() const:
Devuelve el número de subexpresiones encontradas en la última coincidencia (si las hay). Si no se encontró ninguna coincidencia, o si no se encontraron subexpresiones, entonces el valor devuelto es 0. Tenga en cuenta que el índice de la coincidencia completa se indica mediante el índice 0. Por lo tanto, si no se encontraron subexpresiones, el valor de end() será 0, lo que significa que solo el índice 0 es válido.
o
std::string matched() const:
Devuelve la subcadena de la última coincidencia que fue coincidente con el patrón. Si no se encontró ninguna coincidencia, se devuelve una cadena vacía.
o
void match(std::string const &text, int matchOptions = 0):
Intenta hacer coincidir el patrón compilado con el text proporcionado. Las opciones de coincidencia pasadas por matchOptions definen cómo se realizará la coincidencia. Si no se especifica ninguna opción, se utilizarán las opciones definidas en la setPattern() miembro función.
o
Pattern::Position position(size_t index) const:
Con index == 0 se devuelve el texto completamente coincidente (idéntico a matched()). Otros valores de índice devuelven las subexpresiones correspondientes. Se devuelve std::string::npos, std::string::npos si el índice es al menos end() (lo que puede ocurrir con el valor de índice 0).
o
void setPattern(std::string const &pattern, bool caseSensitive = true, size_t nSub = 10, int options = REG_EXTENDED | REG_NEWLINE):
Esta función miembro instala un nuevo patrón compilado en su objeto Pattern. Los parámetros de esta función miembro son idénticos a los parámetros del segundo constructor. Consulte ese constructor para obtener detalles sobre los parámetros. Al igual que el constructor, se lanza una excepción FBB::Exception si el nuevo patrón no se pudo compilar.
o
void swap(Pattern &other):
El contenido del objeto actual y el objeto other se intercambian.

OPERADORES SOBRECARGADOS

o
std::string operator[](size_t index) const:
Devuelve el texto coincidente (para el índice 0) o el texto de una subexpresión. Se devuelve una cadena vacía para los valores de índice que son al menos end().
o
Pattern &operator<<(int matchOptions):
Define las opciones de coincidencia que se utilizarán con el siguiente operador sobrecargado.
o
bool operator<<(std::string const &text):
Realiza una llamada a match(text, matchOptions), capturando cualquier excepción que pueda lanzarse. Si no se establecieron matchOptions usando el operador sobrecargado anterior, no se usan. Las opciones establecidas de esta manera no son "pegajosas": cuando sea necesario, deben reinscribirse antes de cada nueva coincidencia de patrón. La función devuelve true si la coincidencia fue exitosa, false en caso contrario.

EJEMPLO

#include "driver.h"
#include <bobcat/pattern>
using namespace std;
using namespace FBB;
#include <algorithm>
#include <cstring>
void showSubstr(string const &str)
{
    static int count = 0;
    cout << "String " << ++count << " is ’" << str << "’\n";
}
void match(Pattern const &patt, string const &text)
try
{
     Pattern pattern{ patt };
    pattern.match(text);
    Pattern p3(pattern);
    cout << "before:  " << p3.before() << "\n"
            "matched: " << p3.matched() << "\n"
            "beyond:  " << pattern.beyond() << "\n"
            "end() = " << pattern.end() << ’\n’;
    for (size_t idx = 0; idx != pattern.end(); ++idx)
    {
        string str = pattern[idx];
        if (str.empty())
            cout << "part " << idx << " not present\n";
        else
        {
            Pattern::Position pos = pattern.position(idx);
            cout << "part " << idx << ": ’" << str << "’ (" <<
                        pos.first << "-" << pos.second << ")\n";
        }
    }
}
catch (exception const &exc)
{
    cout << exc.what() << ’\n’;
}
int main(int argc, char **argv)
{
    string patStr = R"(\d+)";
    do
    {
        cout << "Pattern: ’" << patStr << "’\n";
        try
        {
                // by default: case sensitive
                // use any args. for case insensitive
            Pattern patt(patStr, argc == 1);
            cout << "Compiled pattern: " << patt.pattern() << ’\n’;
            while (true)
            {
                cout << "string to match : ";
                string text;
                getline(cin, text);
                if (text.empty())
                    break;
                cout << "String: ’" << text << "’\n";
                match(patt, text);
            }
        }
        catch (exception const &exc)
        {
            cout << exc.what() << ": compilation failed\n";
        }
        cout << "New pattern: ";
    }
    while (getline(cin, patStr) and not patStr.empty());
}

ERRORES

Usar objetos Pattern como miembros de datos estáticos de clases (o como objetos globales) es potencialmente peligroso. Si los archivos objeto que definen estos miembros de datos estáticos se almacenan en una biblioteca dinámica, es posible que no se inicialicen correctamente o a tiempo, y su eventual destrucción puede resultar en un fallo de segmentación. Este es un problema bien conocido con los datos estáticos, véase, por ejemplo, http://www.parashift.com/c++-faq-lite/ctors.html#faq-10.15. En situaciones como esta, prefiera el uso de un puntero (compartido, único) a un Pattern, inicializando el puntero cuando, por ejemplo, se usa por primera vez.
