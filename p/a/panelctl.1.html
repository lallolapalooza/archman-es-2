PANELCTL(1) Comandos de usuario PANELCTL(1)

NOMBRE

panelctl - página del manual para panelctl 0.2

SINOPSIS

panelctl [OPCIÓN...] <canal|comando>

DESCRIPCIÓN

panelctl AV/C - cambia canales en, o emite comandos a, un dispositivo AV de firewire

-c, --comandos
Imprime la lista de comandos (requiere un argumento ficticio)
-d, --debug
Modo de depuración
-g, --guid=GUID
Especifica el GUID del STB a controlar

-n, --swversion=VERSIÓN_SW Especifica la versión de software del STB

-s, --specid=ID_ESPEC
Especifica el id_espec del STB a controlar
-v, --verbose
Produce salida detallada
-?, --help
Muestra esta lista de ayuda
--usage
Muestra un breve mensaje de uso
-V, --version
Imprime la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas son también obligatorios u opcionales para cualquier opción corta correspondiente.

Este programa es mayormente útil para un sintonizador firewire o un decodificador con interfaz AV. Úsalo para emitir un comando (panelctl <comando>) o para cambiar canales en el sintonizador (panelctl <canal>). Para obtener una lista de comandos válidos, usa el modificador --comandos.

Por defecto, panelctl controlará el primer STB de Motorola en la cadena firewire. Esto solo funcionará con algunos STB de Motorola. Para controlar cualquier otro STB, o para controlar múltiples STB, especifica el GUID o tanto el id_espec como la versión de software para el STB deseado. Esto se puede averiguar ejecutando "panelctl -v -g 1 1". Como no habrá un STV con GUID 1, recorrerá todos los dispositivos posibles e imprimirá la información de cada uno. Una vez que se conozca el GUID, o el id_espec y la version_sw del dispositivo deseado, se pueden usar en comandos posteriores, por ejemplo, "panelctl -g 0x123456 666". Generalmente, será un mejor enfoque usar el guid, ya que será único para cada STB.

VER TAMBIÉN

La documentación completa de panelctl se mantiene como un manual de Texinfo. Si los programas info y panelctl están instalados correctamente en su sitio, el comando

info panelctl

debería darle acceso al manual completo.
