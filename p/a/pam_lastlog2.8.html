PAM_LASTLOG2(8) Administración del Sistema PAM_LASTLOG2(8)

NOMBRE

pam_lastlog2 - módulo PAM para mostrar la fecha del último inicio de sesión

SINOPSIS

pam_lastlog2.so [debug] [silent] [silent_if=<servicios>] [database=<archivo>]

DESCRIPCIÓN

pam_lastlog2 es un módulo PAM para mostrar una línea de información sobre el último inicio de sesión del usuario. El módulo utiliza el archivo de base de datos /var/lib/lastlog/lastlog2.db para almacenar toda la información.

En comparación con pam_lastlog, este módulo PAM es seguro para Y2038 y utiliza sqlite3 para almacenar la información.

OPCIONES

debug

Imprime información de depuración.

silent

Evita todos los mensajes excepto los errores y no informa al usuario sobre ningún inicio de sesión anterior, solo actualiza la base de datos /var/lib/lastlog/lastlog2.db.

silent_if=<servicios>

El argumento servicios es una lista de servicios PAM separados por comas. Si un servicio está listado aquí, el mensaje del último inicio de sesión no se mostrará.

database=<archivo>

Utiliza archivo en lugar de /var/lib/lastlog/lastlog2.db.

TIPOS DE MÓDULO PROPORCIONADOS

El tipo de módulo session se proporciona para mostrar la información sobre el último inicio de sesión y actualizar el archivo lastlog.

VALORES DE RETORNO

PAM_SUCCESS

Todo fue exitoso.

PAM_SERVICE_ERR

Error interno del módulo de servicio. Esto incluye errores al leer o escribir en la base de datos.

PAM_USER_UNKNOWN

Usuario desconocido.

PAM_IGNORE

Devuelto por tipos de servicio que no hacen nada.

EJEMPLOS

Añade la siguiente línea a, por ejemplo, /etc/pam.d/login para mostrar la hora del último inicio de sesión de un usuario:

session optional pam_lastlog2.so silent_if=gdm,gdm-password

Depende del administrador decidir si el usuario puede iniciar sesión (opcional/requerido) cuando pam_lastlog2 ha devuelto un error.
