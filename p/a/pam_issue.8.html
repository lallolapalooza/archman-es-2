NOMBRE

pam_issue - Módulo PAM para añadir un archivo de aviso al prompt del usuario

SINOPSIS

pam_issue.so [noesc] [issue=nombre-archivo-aviso]

DESCRIPCIÓN

pam_issue es un módulo PAM para anteponer un archivo de aviso al prompt del nombre de usuario. También analiza por defecto códigos de escape en el archivo de aviso, similar a algunos getty comunes (usando formato \\x).

Escapes reconocidos:

\d

día actual

\l

nombre de este tty

\m

arquitectura de la máquina (uname -m)

\n

nombre de host del nodo de red de la máquina (uname -n)

\o

nombre de dominio de este sistema

\r

número de versión del sistema operativo (uname -r)

\t

hora actual

\s

nombre del sistema operativo (uname -s)

\u

número de usuarios actualmente conectados

\U

igual que \\u excepto que se sufija con "user" o "users" (p. ej., "1 user" o "10 users")

\v

versión del sistema operativo y fecha de compilación (uname -v)

OPCIONES

noesc

Desactiva el análisis de códigos de escape.

issue=nombre-archivo-aviso

El archivo a generar si no se utiliza el predeterminado.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_IGNORE

El prompt ya fue modificado.

PAM_SERVICE_ERR

Ocurrió un error en un módulo de servicio.

PAM_SUCCESS

El nuevo prompt se estableció correctamente.

EJEMPLOS

Añada la siguiente línea a /etc/pam.d/login para establecer el aviso específico del usuario al iniciar sesión:

        auth optional pam_issue.so issue=/etc/issue

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)
