NOMBRE

pam_set_items - Un módulo de prueba PAM para establecer elementos específicos del módulo PAM

SINOPSIS

pam_set_items.so

DESCRIPCIÓN

Los módulos PAM almacenan datos en elementos PAM. Estos elementos solo son accesibles desde el contexto del módulo, no desde el contexto de la aplicación, ya que pueden incluir datos privados (PAM_AUTHTOK normalmente contiene la contraseña). Pero al probar módulos PAM, a menudo es útil asegurarse de que un módulo PAM bajo prueba pueda recuperar datos de la pila. El módulo pam_set_items hace esto posible leyendo variables de entorno y estableciéndolas como elementos PAM.

OPCIONES

Ninguna

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulo (account, auth, password y session).

EJEMPLO

Considere un ejemplo que prueba que pam_unix puede leer una contraseña proporcionada y no la consulta por sí mismo. El archivo de servicio de prueba contendría:

auth required        pam_set_items.so
auth required        pam_unix.so

Luego, la prueba pondría el elemento en el entorno de prueba con:

setenv("PAM_AUTHTOK", "secret");

Luego ejecutaría la conversación PAM.
