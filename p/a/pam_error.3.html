PAM_ERROR(3) Manual de Linux-PAM PAM_ERROR(3)

NOMBRE

pam_error, pam_verror - mostrar mensajes de error al usuario

SINOPSIS

#include <security/pam_ext.h>

int pam_error(pam_handle_t *pamh, const char *fmt, ...);

int pam_verror(pam_handle_t *pamh, const char *fmt, va_list args);

DESCRIPCIÓN

La función pam_error imprime mensajes de error a través de la función de conversación al usuario.

La función pam_verror realiza la misma tarea que pam_error() con la diferencia de que toma un conjunto de argumentos que se han obtenido utilizando las macros de lista de argumentos variables de stdarg(3).

VALORES DE RETORNO

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CONV_ERR

Fallo de conversación.

PAM_SUCCESS

El mensaje de error se mostró.

PAM_SYSTEM_ERR

Error del sistema.

VER TAMBIÉN

pam_info(3), pam_vinfo(3), pam_prompt(3), pam_vprompt(3), pam(8)

ESTÁNDARES

Las funciones pam_error y pam_verror son extensiones de Linux-PAM.
