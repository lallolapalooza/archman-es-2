NOMBRE

pam_permit - El módulo promiscuo

SINOPSIS

pam_permit.so

DESCRIPCIÓN

pam_permit es un módulo PAM que siempre permite el acceso. No hace nada más.

En el caso de la autenticación, el nombre de usuario se establecerá en nobody si la aplicación no estableció uno. Muchas aplicaciones y módulos PAM se confunden si este nombre es desconocido.

Este módulo es muy peligroso. Debe usarse con extrema precaución.

OPCIONES

Este módulo no reconoce ninguna opción.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo auth, account, password y session.

VALORES DE RETORNO

PAM_SUCCESS

Este módulo siempre devuelve este valor.

EJEMPLOS

Añada esta línea a sus otras entradas de inicio de sesión para deshabilitar la gestión de cuentas, pero seguir permitiendo a los usuarios iniciar sesión.

account  required  pam_permit.so

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8)

AUTOR

pam_permit fue escrito por Andrew G. Morgan, <morgan@kernel.org>.
