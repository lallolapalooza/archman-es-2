Paquete: graphviz

LIBPATH(3) Manual de Funciones de Biblioteca LIBPATH(3)

NOMBRE

libpathplan - encuentra y suaviza trayectorias más cortas

SINOPSIS

#include <graphviz/pathplan.h>
typedef struct Pxy_t {
    double x, y;
} Pxy_t;
typedef struct Pxy_t Ppoint_t;
typedef struct Pxy_t Pvector_t;
typedef struct Ppoly_t {
    Ppoint_t *ps;
    int pn;
} Ppoly_t;
typedef Ppoly_t Ppolyline_t;
typedef struct Pedge_t {
    Ppoint_t a, b;
} Pedge_t;
typedef struct vconfig_s vconfig_t;
#define POLYID_NONE	
#define POLYID_UNKNOWN
int Pshortestpath(Ppoly_t *boundary, Ppoint_t endpoints[2], Ppolyline_t *output_route);
vconfig_t *Pobsopen(Ppoly_t **obstacles, int n_obstacles);
int Pobspath(vconfig_t *config, Ppoint_t p0, int poly0, Ppoint_t p1, int poly1, Ppolyline_t *output_route);
void Pobsclose(vconfig_t *config);
int Proutespline (Pedge_t *barriers, int n_barriers, Ppolyline_t input_route, Pvector_t endpoint_slopes[2],
	Ppolyline_t *output_route);
int Ppolybarriers(Ppoly_t **polys, int n_polys, Pedge_t **barriers, int *n_barriers);

DESCRIPCIÓN

libpathplan proporciona funciones para crear trayectorias spline en el plano que están restringidas por un límite poligonal u obstáculos a evitar. Todos los polígonos deben ser simples, pero no necesariamente convexos.

int Pshortestpath(Ppoly_t *boundary, Ppoint_t endpoints[2], Ppolyline_t *output_route);

La función Pshortestpath encuentra una trayectoria más corta entre dos puntos en un polígono simple. El polígono se especifica mediante una lista de sus vértices, en orden horario o antihorario. Se pasan los puntos finales en el interior del polígono límite. Se devuelve una trayectoria más corta que conecta los puntos y permanece dentro del polígono en output_route. Si alguno de los puntos finales no se encuentra dentro del polígono, se devuelve -1; de lo contrario, se devuelve 0 en caso de éxito. El array de puntos en output_route es estático para la biblioteca. No debe liberarse y debe usarse antes de otra llamada a Pshortestpath.

vconfig_t *Pobsopen(Ppoly_t **obstacles, int n_obstacles);

Pobspath(vconfig_t *config, Ppoint_t p0, int poly0, Ppoint_t p1, int poly1, Ppolyline_t *output_route);

void Pobsclose(vconfig_t *config);

Estas funciones encuentran una trayectoria más corta entre dos puntos en el plano que contiene obstáculos (agujeros) poligonales. Pobsopen crea una configuración (una estructura opaca de tipo vconfig_t) sobre un conjunto de obstáculos. Los n_obstacles obstáculos se dan en el array obstacles; los puntos de cada polígono deben estar en orden horario. La función Pobsclose libera los datos asignados en Pobsopen.

Pobspath encuentra una trayectoria más corta entre los puntos finales que permanece fuera de los obstáculos. Si se sabe que los puntos finales se encuentran dentro de obstáculos, poly0 o poly1 deben establecerse en el índice en el array de obstáculos. Si un punto final definitivamente no está dentro de un obstáculo, entonces se debe pasar POLYID_NONE. Si el llamador no ha verificado, entonces se debe pasar POLYID_UNKNOWN, y la biblioteca de trayectorias realizará la prueba. La trayectoria más corta resultante se devuelve en output_route. Tenga en cuenta que esta función no proporciona un polígono límite. El array de puntos almacenado en output_route es asignado por la biblioteca, pero debe ser liberado por el usuario.

int Proutespline (Pedge_t *barriers, int n_barriers, Ppolyline_t input_route, Pvector_t endpoint_slopes[2], Ppolyline_t *output_route);

Esta función ajusta una curva spline B cúbica a una trayectoria polilínea. La curva se construye para evitar un conjunto de segmentos de línea de barrera de n_barriers especificados en el array barriers. Si comienza con obstáculos poligonales, puede proporcionar los bordes de cada polígono como parte de la lista de barreras. La polilínea input_route proporciona una plantilla para la trayectoria final; es normalmente el output_route de uno de los localizadores de trayectorias más cortas, pero puede ser cualquier trayectoria simple que no cruce ningún segmento de barrera. La entrada también permite la especificación de las pendientes deseadas en los puntos finales a través de endpoint_slopes. Estos se especifican como vectores. Por ejemplo, para tener un ángulo de T en un punto final, se podría usar (cos(T),sin(T)). Un vector (0,0) significa pendiente no restringida. La salida se devuelve en output_route y consta de los puntos de control de la spline B. La función devuelve 0 en caso de éxito; un valor de retorno de -1 indica un fallo. El array de puntos en output_route es estático para la biblioteca. No debe liberarse y debe usarse antes de otra llamada a Proutespline.

int Ppolybarriers(Ppoly_t **polys, int n_polys, Pedge_t **barriers, int *n_barriers);

Esta es una función de utilidad que convierte una lista de entrada de polígonos en una lista de salida de segmentos de barrera. El array de puntos en barriers es estático para la biblioteca. No debe liberarse y debe usarse antes de otra llamada a Ppolybarriers. La función devuelve 1 en caso de éxito.

ERRORES

La función Proutespline no garantiza que preservará la topología de la trayectoria de entrada con respecto a los límites. Por ejemplo, si algunos de los segmentos corresponden a un polígono pequeño, puede ser posible que la trayectoria final haya dado la vuelta al obstáculo.
