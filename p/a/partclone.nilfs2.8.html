PARTCLONE(8) Manual de usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de una partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de archivos                 partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo dependiendo de su acción. Normalmente, la fuente de copia de seguridad es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos desde una tubería solo se admite para la restauración, simplemente ignore la opción -s o use '-' para recibir datos desde la entrada estándar.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (partclone generará) o un dispositivo dependiendo de su acción. Normalmente, la salida de copia de seguridad a un archivo de imagen y la restauración a un dispositivo.

El envío de datos a una tubería también se admite SOLO para copias de seguridad, simplemente ignore la opción -o o use '-' para enviar datos a la salida estándar.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, origen y salida ambos son dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añadir X (en bytes) a todas las posiciones informadas en el archivo de registro de dominio.

--restore_raw_file

Crear un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Colocar una ruta especial para registrar la información de registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No verificar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar error de verificación crc.

-F, --force

Forzar el progreso.

-f seg, --UI-fresh seg

Establecer un intervalo de segundos diferente.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar el mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápida de calcular, detección básica)

2: xxHash, algoritmo de hash no criptográfico extremadamente rápido.

-kX, --blocks-per-checksum=X

Escribir una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continuar la restauración durante errores de escritura.

--write-direct-io

Escribir datos en la partición de DESTINO sin caché.

--read-direct-io

Leer datos de la partición de ORIGEN sin caché.

-B, --no_block_detail

Mostrar el mensaje de progreso sin detalle de bloques.

--binary-prefix

Mostrar progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Mostrar progreso en segundos (por defecto es minuto).

-E, --offset=X

Añadir un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar el torrent.

-n, --note NOTA

Mostrar Mensaje de Nota (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar versión
partclone.ext3(8) — partclone documentation

NAME

partclone.ext3

clone, save, restore, or repair an ext3 filesystem

SYNOPSIS

partclone.ext3 [OPTION...]

DESCRIPTION

partclone.ext3 is a command-line tool that saves or restores an ext3 filesystem partition.

It works by reading the filesystem block by block, and writing only used blocks to the destination. This allows it to be faster than disk-to-disk cloning tools like dd, especially on drives that are not full.

It can save an image of a filesystem to a file or to another device. It can also restore an image from a file or device back to a filesystem partition.

partclone.ext3 is part of the partclone suite of tools, which provide filesystem-level cloning capabilities for various filesystems.

OPTIONS

The following options are available:

-c, --clone
Clone the source filesystem to the destination. This is the default action.
-r, --restore
Restore the source image to the destination filesystem.
-s, --source SOURCE
Specify the source filesystem or image file. This can be a device (e.g., /dev/sda1) or a file path.
-o, --output OUTPUT
Specify the destination device or image file. This can be a device (e.g., /dev/sdb1) or a file path.
-d, --debug
Enable debug output. This will print more verbose information during the cloning or restoring process.
-a, --allow-clean-fs
Allow cloning of a clean filesystem. By default, partclone will refuse to clone a filesystem that is marked as clean (e.g., due to being unmounted properly). Use with caution.
-R, --rescue
Rescue mode. This option attempts to copy all files from the source to the destination, even if there are errors. This is useful for recovering data from damaged filesystems.
-z, --compress-level LEVEL
Set the compression level for the image file. LEVEL can be an integer from 0 (no compression) to 9 (maximum compression). This option is only effective when saving to a file.
-A, --no-create-device
Do not create a new device node for the image file. This is useful when restoring an image to an existing device.
-i, --ignore-zero-blocks
Ignore zero-filled blocks when cloning. This can speed up the process by not writing unnecessary blocks to the image file.
-v, --verbose
Enable verbose output. This will show more detailed progress information.
-h, --help
Display a help message and exit.
-V, --version
Display version information and exit.

Note that not all options may be supported for all filesystem types.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
