NOMBRE

paccat - Imprimir archivos de paquetes de pacman

SINOPSIS

paccat [opciones] <objetivo> <archivos>
paccat [opciones] [objetivos] -- <archivos>
paccat [opciones] -<Q|F> <archivos>
paccat [opciones] <-Q|-F> [objetivos] -- <archivos>

un objetivo se puede especificar como:
<nombre_paquete>, <repo>/<nombre_paquete>, <url> o <archivo>.

los archivos se pueden especificar solo como el nombre del archivo o la ruta completa.

DESCRIPCIÓN

Imprimir archivos de paquetes de pacman.

paccat imprime archivos de paquetes independientemente de tu sistema, descargando los paquetes necesarios y extrayendo los archivos necesarios.

RESALTADO DE SINTAXIS

paccat usará bat para el resaltado de sintaxis si está instalado.

OPCIONES

-F, --files
Usar la base de datos de archivos para buscar archivos antes de descargar.
-Q, --query
Usar la base de datos local para buscar archivos antes de descargar.
-r, --root <ruta>
Establecer un directorio raíz alternativo.
-b, --dbpath <ruta>
Establecer una ubicación de base de datos alternativa.
--config <archivo>
Usar un pacman.conf alternativo.
--color <cuándo>
Especificar cuándo habilitar la coloración. Las opciones válidas son siempre, nunca o auto.
-y, --refresh
Descargar bases de datos de paquetes actualizadas del servidor. Pasar dos veces para forzar la descarga incluso si las bases de datos están actualizadas.
--cachedir <ruta>
Establecer el directorio principal de caché.

Este directorio será el directorio preferido para descargar paquetes si es escribible. Los otros directorios configurados seguirán utilizándose para la lectura.

-a, --all
Imprimir todos los archivos coincidentes en lugar de solo el primero.
-x, --regex
Habilitar la búsqueda utilizando expresiones regulares.
--binary
Imprimir archivos binarios
-X, --executable
Filtrar resultados a archivos ejecutables.
-e, --extract
Extraer los archivos coincidentes al directorio actual.
-l, --list
Imprimir nombres de archivo en lugar de contenido de archivo.
-i, --install
Instalar los archivos coincidentes en el sistema.
--debug
Mostrar mensajes de depuración.
-h, --help
Imprimir información de ayuda.
-V, --version
Imprimir información de versión.

EJEMPLOS

paccat grub etc/default/grub
Imprimir el contenido de 'etc/default/grub' del paquete grub.
paccat pacman pacman.conf
Imprimir el contenido del primer archivo llamado 'pacman.conf' del paquete pacman.
paccat -F pacman.conf
Imprimir el contenido del primer archivo llamado 'pacman.conf' en los repos
paccat -x pacman mkinitcpio -- '.conf$'
Imprimir el contenido de todos los archivos que terminan en '.conf' de los paquetes pacman y mkinitcpio.
paccat ~/pkgs/my-pkg-1.0.0-1.pkg.tar.zst myfile
Imprimir el contenido de 'myfile' de un archivo tarball de paquete.
paccat https://archlinux.org/packages/extra/x86_64/git/download git-blame.1.gz
Descargar e imprimir el contenido de 'git-blame.1.gz' del paquete git.";
