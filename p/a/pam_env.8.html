NOMBRE

pam_env - Módulo PAM para establecer/desestablecer variables de entorno

SINOPSIS

pam_env.so [debug] [conffile=archivo-conf] [envfile=archivo-env] [readenv=0|1] [user_envfile=archivo-env] [user_readenv=0|1]

DESCRIPCIÓN

El módulo PAM pam_env permite el (des)establecimiento de variables de entorno. Se soporta el uso de variables de entorno previamente establecidas, así como PAM_ITEMs como PAM_RHOST.

Por defecto, las reglas para (des)establecer variables se toman del archivo de configuración /etc/security/pam_env.conf. Se puede especificar un archivo alternativo con la opción conffile.

En segundo lugar, se leerá un archivo (/etc/environment por defecto) con pares simples de CLAVE=VALOR en líneas separadas. Con la opción envfile se puede especificar un archivo alternativo. Y con la opción readenv esto se puede deshabilitar completamente.

En tercer lugar, leerá un archivo de configuración de usuario ($HOME/.pam_environment por defecto). El archivo por defecto se puede cambiar con la opción user_envfile y se puede activar o desactivar con la opción user_readenv.

Dado que el establecimiento de variables de entorno de PAM puede tener efectos secundarios en otros módulos, este módulo debería ser el último en la pila.

Este módulo solo se ejecuta si la aplicación principal llama a pam_setcred(3) o pam_open_session(3). El módulo no hace nada y devuelve PAM_IGNORE si es llamado por pam_authenticate(3).

OPCIONES

conffile=/ruta/a/pam_env.conf

Indica un archivo de configuración alternativo estilo pam_env.conf para anular el predeterminado. Esto puede ser útil cuando diferentes servicios necesitan entornos diferentes.

debug

Se imprime mucha información de depuración con syslog(3).

envfile=/ruta/a/environment

Indica un archivo de entorno alternativo para anular el predeterminado. La sintaxis son pares simples de CLAVE=VALOR en líneas separadas. Se puede especificar la instrucción export para compatibilidad con bash, pero será ignorada. Esto puede ser útil cuando diferentes servicios necesitan entornos diferentes.

readenv=0|1

Activa o desactiva la lectura del archivo especificado por envfile (0 es desactivado, 1 es activado). Por defecto, esta opción está activada.

user_envfile=nombre-archivo

Indica un archivo .pam_environment alternativo para anular el predeterminado. El nombre del archivo es relativo al directorio personal del usuario. Esto puede ser útil cuando diferentes servicios necesitan entornos diferentes.

user_readenv=0|1

Activa o desactiva la lectura del archivo de entorno específico del usuario. 0 es desactivado, 1 es activado. Por defecto, esta opción está desactivada, ya que las variables de entorno proporcionadas por el usuario en el entorno PAM podrían afectar el comportamiento de los módulos subsiguientes en la pila sin el consentimiento del administrador del sistema.

Debido a problemas de seguridad, esta funcionalidad está obsoleta desde la versión 1.5.0 y se eliminará por completo en algún momento en el futuro.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo auth y session.

VALORES DE RETORNO

PAM_ABORT

No se pudieron obtener todos los datos o opciones relevantes.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_IGNORE

No se encontró ningún archivo pam_env.conf ni archivo de entorno, o el módulo fue llamado por pam_authenticate(3).

PAM_SUCCESS

Se establecieron las variables de entorno.

ARCHIVOS

/etc/security/pam_env.conf

Archivo de configuración por defecto

/etc/environment

Archivo de entorno por defecto

$HOME/.pam_environment

Archivo de entorno específico del usuario
