NOMBRE

pam_group - Módulo PAM para acceso a grupos

SINOPSIS

pam_group.so

DESCRIPCIÓN

El módulo PAM pam_group no autentica al usuario, sino que otorga membresías de grupo (en la fase de configuración de credenciales del módulo de autenticación) al usuario. Dichas membresías se basan en el servicio para el que se está aplicando.

Por defecto, las reglas para las membresías de grupo se toman del archivo de configuración /etc/security/group.conf.

La utilidad de este módulo depende de los sistemas de archivos accesibles para el usuario. El punto es que, una vez otorgada la membresía a un grupo, el usuario puede intentar crear un binario setgid con una propiedad de grupo restringida. Más tarde, cuando al usuario no se le otorga la membresía a este grupo, puede recuperar la membresía de grupo con el binario precompilado. La razón por la que los sistemas de archivos a los que tiene acceso el usuario son tan significativos es el hecho de que cuando un sistema se monta con la opción nosuid, el usuario no puede crear ni ejecutar dicho archivo binario. Para que este módulo proporcione algún nivel de seguridad, todos los sistemas de archivos a los que el usuario tiene acceso de escritura deben montarse con la opción nosuid.

El módulo pam_group funciona en paralelo con el archivo /etc/group. Si al usuario se le otorgan algunos grupos basándose en el comportamiento de este módulo, se le otorgan *además* de las entradas de /etc/group (o equivalente).

OPCIONES

Este módulo no reconoce ninguna opción.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_SUCCESS

se otorgó la membresía de grupo.

PAM_ABORT

No se pudieron obtener todos los datos relevantes.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_CRED_ERR

No se otorgó la membresía de grupo.

PAM_IGNORE

Se llamó a pam_sm_authenticate, lo cual no hace nada.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

ARCHIVOS

/etc/security/group.conf

Archivo de configuración predeterminado

VER TAMBIÉN

group.conf(5), pam.d(5), pam(8).
