NOMBRE

pamseq - genera una imagen PAM de todos los valores de tupla posibles, en secuencia

SINOPSIS

pamseq [-tipotupla=tipotupla] profundidad valormax

Todas las opciones se pueden abreviar a su prefijo único más corto. Puede usar dos guiones en lugar de uno para designar una opción. Puede usar espacio en blanco o un signo igual entre un nombre de opción y su valor.

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pamseq genera una imagen PAM de una profundidad especificada y un valormax especificado que consiste en una sola fila. La fila consta de una tupla de cada valor posible, en orden. Para una profundidad de uno, el orden es simple: de 0 a valormax, yendo de izquierda a derecha. Para profundidades mayores, el plano con el número más alto va de 0 a valormax (yendo de izquierda a derecha) mientras que todos los demás planos tienen valor 0. Luego la secuencia se repite excepto con el siguiente plano más alto establecido en un valor de 1, luego 2, etc.

OPCIONES

-tipotupla
Este es el valor del atributo "tuple_type" de la imagen PAM creada. Puede ser cualquier cadena de hasta 255 caracteres.

USO

Para crear una rampa simple de los valores 0..255, para entrada a varios cálculos matriciales, intente


  pamseq 1 255

(Antes de que existiera pamseq, a menudo se recurría a pgmramp para esto).

Para crear un mapa de colores PPM de todos los colores posibles representables con un valormax de 5, haga:


  pamseq 3 5 -tipotupla=RGB | pamtopnm

Nuevamente, con un programa moderno basado en la biblioteca Netpbm, no necesita pamtopnm porque una imagen PAM RGB es equivalente a una imagen PPM.

Puede usar dicho mapa de colores con pnmremap(1)
para cuantizar los colores en una imagen. Con el valormax de 5 dado en el ejemplo, obtiene un mapa de colores del conjunto de colores "seguros para la web" tal como los define Netscape. La mayoría de los navegadores web garantizan que pueden producir al menos estos 216 colores (215 más el negro).

VER TAMBIÉN

pnmremap(1) , pamtopnm(1) , pam(5)
