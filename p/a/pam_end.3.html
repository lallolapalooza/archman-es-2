NOMBRE

pam_end - terminación de transacción PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_end(pam_handle_t *pamh, int pam_status);

DESCRIPCIÓN

La función pam_end termina la transacción PAM y es la última función que una aplicación debe llamar en el contexto PAM. Al regresar, el manejador pamh ya no es válido y toda la memoria asociada a él será inválida.

El argumento pam_status debe establecerse al valor devuelto a la aplicación por la última llamada a la biblioteca PAM.

El valor tomado por pam_status se utiliza como argumento para la función de devolución de llamada específica del módulo, cleanup() (ver pam_set_data(3) y pam_get_data(3)). De esta manera, se puede notificar al módulo sobre la naturaleza de éxito/fallo del proceso de limpieza, y realizar cualquier tarea de última hora que sea apropiada para el módulo antes de que se desvincule. Este argumento puede combinarse lógicamente con PAM_DATA_SILENT para indicar que el módulo no debe tomar la llamada demasiado en serio. Generalmente se utiliza para indicar que el cierre actual de la biblioteca se realiza en un proceso fork(2)ed, y que el proceso padre se encargará de limpiar las cosas que existen fuera del espacio del proceso actual (archivos, etc.).

Esta función *libera* toda la memoria de los elementos asociados con las funciones pam_set_item(3) y pam_get_item(3). Los punteros asociados con dichos objetos ya no son válidos después de que se llamó a pam_end.

VALORES DE RETORNO

PAM_SUCCESS

La transacción se terminó con éxito.

PAM_SYSTEM_ERR

Error del sistema, por ejemplo, se envió un puntero NULL como manejador PAM o un módulo llamó a la función.

VER TAMBIÉN

pam_get_data(3), pam_set_data(3), pam_start(3), pam_strerror(3)
