NOMBRE

pam_matrix - Un módulo de prueba de PAM para recuperar elementos específicos del módulo de PAM.

SINOPSIS

pam_matrix.so [...]

DESCRIPCIÓN

Las aplicaciones de prueba de PAM a menudo requieren configurar un backend de autenticación con el menor esfuerzo posible. El módulo pam_matrix permite autenticarse contra un archivo de texto clave-valor, proporcionado por una opción o mediante una variable de entorno.

IMPORTANTE

pam_matrix es una **herramienta de prueba**. Debe considerarse completamente inseguro y ¡nunca debe usarse fuera de entornos de prueba! Como verá al leer la descripción de las opciones y acciones, muchas de ellas no tienen sentido en el mundo real y se agregaron solo para hacer posibles las pruebas.

BASE DE DATOS DE CONTRASEÑAS

El módulo pam_matrix autentica al usuario contra un archivo CSV de texto plano. El formato del archivo es el siguiente:

nombre_usuario:contraseña:servicio_permitido

Ejemplo: Usuario bob permitido para autenticarse con el servicio sshd

bob:secreto:sshd

OPCIONES

•passdb=/ruta/al/archivo - la ruta a la base de datos de contraseñas. Si la base de datos no se proporciona con esta opción del módulo, pam_matrix.so lee la variable de entorno PAM_MATRIX_PASSWD e intenta cargar el archivo desde allí. Si eso también falla, se devuelve PAM_AUTHINFO_UNAVAIL.
•echo - si se proporciona esta opción, pam_matrix.so solicitará la contraseña utilizando PAM_PROMPT_ECHO_ON, es decir, la contraseña se mostrará al usuario. Esta opción se agregó para facilitar la prueba de las funciones de conversación.
•verbose - si se proporciona esta opción, pam_matrix.so mostrará un mensaje PAM_TEXT_INFO cuando la autenticación sea exitosa y un mensaje PAM_ERROR_MSG cuando la autenticación falle. Esta opción se agregó para facilitar la prueba de las funciones de conversación.

TIPOS DE MÓDULOS PROPORCIONADOS

Se admiten todos los tipos de módulos (account, auth, password y session).

El módulo auth busca al usuario en el archivo passdb y compara la contraseña proporcionada con la del archivo passdb.

El módulo password es capaz de actualizar la contraseña en el archivo passdb.

El módulo access compara el nombre del servicio con el que se invocó la conversación de PAM con el servicio permitido para el usuario, según lo configurado en el archivo passdb.

El módulo session establece la variable de entorno PAM HOMEDIR a ""/home/%u"" donde %u representa al usuario que abre la sesión. La variable se elimina al cerrar la sesión.

EJEMPLO

auth        required    pam_matrix.so passdb=/tmp/passdb verbose
account     required    pam_matrix.so passdb=/tmp/passdb verbose
password    required    pam_matrix.so passdb=/tmp/passdb verbose
session     required    pam_matrix.so passdb=/tmp/passdb verbose
