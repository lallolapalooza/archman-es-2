NOMBRE

pam_timestamp_check - Comprueba si la marca de tiempo predeterminada es válida

SINOPSIS

pam_timestamp_check [-k] [-d] [usuario_objetivo]

DESCRIPCIÓN

Sin argumentos, pam_timestamp_check comprobará si la marca de tiempo predeterminada es válida, o la eliminará opcionalmente.

OPCIONES

-k

En lugar de comprobar la validez de una marca de tiempo, elimínela. Esto es análogo a la opción -k de sudo.

-d

En lugar de devolver la validez mediante un estado de salida, bucle indefinidamente, sondeos periódicamente e imprimiendo el estado en la salida estándar.

usuario_objetivo

Por defecto, pam_timestamp_check comprueba o elimina las marcas de tiempo generadas por pam_timestamp cuando los usuarios se autentican como ellos mismos. Cuando el usuario se autentica como otro usuario, el nombre del archivo de marca de tiempo cambia para acomodar esto. usuario_objetivo permite especificar este nombre de usuario.

VALORES DE RETORNO

0

La marca de tiempo es válida.

2

El binario no tiene el bit setuid root.

3

Invocación inválida.

4

Usuario desconocido.

5

Error de permisos.

6

TTY de control inválido.

7

La marca de tiempo no es válida.

NOTAS

Los usuarios pueden confundirse cuando no siempre se les piden contraseñas al ejecutar un programa determinado. Algunos usuarios comienzan a escribir información reflexivamente antes de notar que no se les está pidiendo.

EJEMPLOS

auth sufficient pam_timestamp.so verbose
auth required   pam_unix.so
session required pam_unix.so
session optional pam_timestamp.so

ARCHIVOS

/var/run/sudo/...

archivos y directorios de marcas de tiempo
