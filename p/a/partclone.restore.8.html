PARTCLONE.RESTORE(8) Manual de usuario de Partclone PARTCLONE.RESTORE(8)

NOMBRE

partclone.restore - restaura una imagen de partclone a un dispositivo.

SINOPSIS

partclone.restore {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [--ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-w | --skip_write_error] [--write-direct-io] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-B | --no_block_detail]]

DESCRIPCIÓN

partclone.restore es parte del proyecto Partclone para restaurar todas las imágenes creadas por partclone.[fstype] o partclone.dd. Partclone proporciona utilidades para hacer copias de seguridad de bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se utilizan e2fslibs para leer el bloque utilizado de la partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT, EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Todas las utilidades de partclone pueden ejecutarse como partclone.xxx, muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp.

OPCIONES

El programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (hecho por partclone) o un dispositivo, dependiendo de su acción. Normalmente, el origen de la copia de seguridad es un dispositivo, el origen de la restauración es un archivo de imagen.

La recepción de datos de una tubería está soportada ÚNICAMENTE para la restauración, simplemente ignore la opción -s o use '-' para recibir datos de stdin.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (partclone lo generará) o un dispositivo, dependiendo de su acción. Normalmente, la salida de la copia de seguridad es un archivo de imagen y la salida de la restauración es un dispositivo.

El envío de datos a una tubería también está soportado ÚNICAMENTE para la copia de seguridad, simplemente ignore la opción -o o use '-' para enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe el ARCHIVO, si ya existe.

--restore_raw_file

Crea un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Especifica una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-X, --dialog

Muestra los mensajes en formato Diálogo.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

--ignore_crc

Ignora los errores de comprobación CRC.

-F, --force

Forzar el progreso.

-f segundos, --UI-fresh segundos

Establece un intervalo de actualización de la interfaz de usuario en segundos.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Deshabilita los mensajes de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión del programa.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone.restore

EJEMPLOS

 Restaura /dev/hda1 desde hda1.img y muestra información de depuración.
  partclone.restore -d -s hda1.img -o /dev/hda1
 Restaura una imagen de clonezilla (dividida, gzip,) con fuente stdin 
  cat  sda1.ext3-ptcl-img.gz.a*  | gunzip -c | partclone.restore -d -s - -o /dev/sda1
 Restaura una imagen raw de partclone.dd  
  partclone.dd  -d  -c  -s  /dev/sda1  -o  - | partclone.restore -d -s - -o /dev/sdb1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden aparecer en stderr:

partclone.restore proporciona algunos códigos de retorno, que pueden usarse en scripts:

Código Diagnóstico
0 El programa terminó con éxito.
1 La clonación o restauración parecen haber fallado.

NAME

partclone.restore - restore a partition image to a device

SYNOPSIS

partclone.restore -c clone.img -s device [-W] [-C] [-d] [-f] [-h] [-H] [-L] [-N] [-P] [-q] [-S] [-t] [-v] [-Z] [-b blocksize] [-e error_file] [-i io_buffer_size] [-p partition_type] [-r restore_size] [-u uuid] [-x partclone_opt]

DESCRIPTION

partclone.restore restores a partition image previously created with partclone.clone. It writes the partition image to the specified device.

OPTIONS

  • -c clone.img: Specifies the partition image file to restore.
  • -s device: Specifies the destination device to restore the partition to.
  • -W: Overwrite the destination device without confirmation.
  • -C: Continue restoring even if errors occur.
  • -d: Dump the partition image.
  • -f: Force overwrite of the destination device.
  • -h: Display help message.
  • -H: Show partition size.
  • -L: Create a log file.
  • -N: No progress indicator.
  • -P: Print partition information.
  • -q: Quiet mode.
  • -S: Skip zero blocks.
  • -t: Show progress in percentage.
  • -v: Verbose mode.
  • -Z: Zero the destination device.
  • -b blocksize: Set block size (default: 1MB).
  • -e error_file: Specify a file to log errors.
  • -i io_buffer_size: Set I/O buffer size.
  • -p partition_type: Set partition type.
  • -r restore_size: Set the size of the partition to restore.
  • -u uuid: Set the UUID of the partition.
  • -x partclone_opt: Pass additional options to partclone.

FILES

  • /var/log/partclone.log: Default log file.

EXAMPLES

Restore a partition image to a device: 

    partclone.restore -c /path/to/clone.img -s /dev/sda1

DIAGNOSTICS

Partclone will print error messages to the console or to a log file if specified.
