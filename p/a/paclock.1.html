NOMBRE

paclock - bloquear/desbloquear la base de datos alpm

SINOPSIS

paclock [opciones]
paclock (--help|--version)

DESCRIPCIÓN

Bloqueo y desbloqueo seguro de la base de datos ALPM utilizando claves de identidad para scripts.

OPCIONES

--config=ruta
Establecer una ruta de archivo de configuración alternativa.
--lockfile=ruta
Establecer una ruta de archivo de bloqueo alternativo.
--root=ruta
Establecer una raíz de instalación alternativa.
--sysroot=ruta
Establecer una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--lock
Bloquear la base de datos (predeterminado).
--unlock
Desbloquear la base de datos.
--run
Tratar "argv" como un comando a ejecutar con la base de datos bloqueada. Si el comando devuelve un valor distinto de cero, el archivo de bloqueo se dejará en su lugar para indicar un error a menos que se use --fail-ok.
--fail-ok
Desbloquear la base de datos después de ejecutar un comando con --run incluso si el comando devuelve un valor distinto de cero. Generalmente, la base de datos debe dejarse bloqueada si puede estar en un estado inconsistente para indicar que puede necesitar ser reparada. Esta bandera está destinada principalmente a operaciones de solo lectura.
--print
Escribir la ruta del archivo de bloqueo en stdout y salir sin modificar el archivo de bloqueo.
--no-check-keys
Omitir la verificación de coincidencia de clave de identidad antes de desbloquear.
--enoent-ok
No tratar un archivo de bloqueo inexistente como un error al desbloquear.
--key=identidad
Un identificador a escribir en el archivo de bloqueo. Por defecto, --unlock solo operará si el archivo de bloqueo fue bloqueado previamente con la misma clave. Por defecto, el nombre del host seguido de dos puntos y el ID del proceso del llamante (por ejemplo: "localhost:123").
--help
Mostrar información de uso y salir.
--version
Mostrar información de versión y salir.

EJEMPLO

La configuración del sistema en la que se basa paclock para construir la ruta predeterminada del archivo de bloqueo y la clave de identidad puede cambiar entre invocaciones. Para garantizar la consistencia, los scripts deben proporcionar explícitamente la ruta y la clave a utilizar cada vez que se llame a paclock.

#!/bin/bash
lock_file="$(paclock --print)"
lock_key="myapp:$(hostname):$$"
paclock --lockfile="$lock_file" --key="$lock_key" || exit 1
echo "hacer cosas aquí"
paclock --lockfile="$lock_file" --key="$lock_key" --unlock || exit 1

Ejecutar un comando que carece de soporte de bloqueo nativo:

paclock --run -- paccache --dryrun --verbose
