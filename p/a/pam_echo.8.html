NOMBRE

pam_echo - Módulo PAM para imprimir mensajes de texto

SINOPSIS

pam_echo.so [archivo=/ruta/mensaje]

DESCRIPCIÓN

El módulo PAM pam_echo se utiliza para imprimir mensajes de texto para informar al usuario sobre cosas especiales. Las secuencias que comienzan con el carácter % se interpretan de la siguiente manera:

%H

El nombre del host remoto (PAM_RHOST).

%h

El nombre del host local.

%s

El nombre del servicio (PAM_SERVICE).

%t

El nombre de la terminal de control (PAM_TTY).

%U

El nombre de usuario remoto (PAM_RUSER).

%u

El nombre de usuario local (PAM_USER).

Todas las demás secuencias que comienzan con % se expanden a los caracteres que siguen al carácter %.

OPCIONES

archivo=/ruta/mensaje

El contenido del archivo /ruta/mensaje se imprimirá con la función de conversión de PAM como PAM_TEXT_INFO.

TIPOS DE MÓDULO PROPORCIONADOS

Todos los tipos de módulo (auth, account, password y session) se proporcionan.

VALORES DE RETORNO

PAM_BUF_ERR

Error de búfer de memoria.

PAM_SUCCESS

El mensaje se imprimió correctamente.

PAM_IGNORE

Se dio la bandera PAM_SILENT o el archivo de mensaje no existe, no se imprimió ningún mensaje.

EJEMPLOS

Para un ejemplo del uso de este módulo, mostramos cómo se puede utilizar para imprimir información sobre contraseñas seguras:

contraseña opcional pam_echo.so archivo=/usr/share/doc/good-password.txt
contraseña requerida pam_unix.so
