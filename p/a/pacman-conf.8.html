PACMAN-CONF(8) Manual de Pacman PACMAN-CONF(8)

NOMBRE

pacman-conf - consultar el archivo de configuración de pacman

SINOPSIS

pacman-conf [opciones] [<directiva> ...]

pacman-conf (--repo-list|--help|--version)

DESCRIPCIÓN

pacman-conf es una utilidad para analizar el archivo de configuración de pacman y devolver una salida amigable para scripts. Está diseñado para manejar correctamente características de configuración no triviales como la interpolación de variables y el uso de la directiva Include, y garantiza que devolverá los mismos valores de configuración que el propio pacman usaría.

pacman-conf mostrará el contenido completamente resuelto del archivo de configuración por defecto, o, si se le proporciona el nombre de una directiva de configuración, mostrará el contenido de la directiva dada sola.

OPCIONES

-c, --config <ruta>

Especifica un archivo de configuración alternativo.

-R, --rootdir <ruta>

Especifica una raíz de instalación alternativa (el valor predeterminado es /).

-r, --repo <repositorio>

Consulta opciones para un repositorio específico.

-v, --verbose

Muestra siempre los nombres de las directivas.

-l, --repo-list

Lista los repositorios configurados.

-h, --help

Muestra la sintaxis y las opciones de la línea de comandos.

-V, --version

Muestra la versión y sale.

EJEMPLOS

pacman-conf -r core Usage

Muestra el valor de la opción de configuración Usage para el repositorio core.

pacman-conf HoldPkg

Muestra el valor de la opción de configuración HoldPkg.
