PACMAN.CONF(5) Manual de Pacman PACMAN.CONF(5)

NOMBRE

pacman.conf - archivo de configuración del gestor de paquetes pacman

SINOPSIS

/etc/pacman.conf

DESCRIPCIÓN

Pacman, utilizando libalpm(3), intentará leer pacman.conf cada vez que se invoque. Este archivo de configuración se divide en secciones o repositorios. Cada sección define un repositorio de paquetes que pacman puede usar al buscar paquetes en modo --sync. La excepción a esto es la sección de opciones, que define opciones globales.

Los comentarios solo se admiten comenzando una línea con el símbolo de almohadilla (#). Los comentarios no pueden comenzar en medio de una línea.

EJEMPLO

#
# pacman.conf
#
[options]
NoUpgrade = etc/passwd etc/group etc/shadow
NoUpgrade = etc/fstab
[core]
Include = /etc/pacman.d/core
[custom]
Server = file:///home/pkgs

Nota

Cada directiva debe estar en CamelCase. Si no se respeta la mayúscula/minúscula, la directiva no será reconocida. Por ejemplo, noupgrade o NOUPGRADE no funcionarán.

OPCIONES

RootDir = /ruta/al/directorio/raiz

Establece el directorio raíz predeterminado para que pacman instale. Esta opción se utiliza si desea instalar un paquete en una partición montada temporalmente que es "propiedad" de otro sistema, o para una instalación chroot. NOTA: Si la ruta de la base de datos o el archivo de registro no se especifican en la línea de comandos o en pacman.conf(5), su ubicación predeterminada estará dentro de esta ruta raíz.

DBPath = /ruta/al/directorio/db

Anula la ubicación predeterminada del directorio raíz de la base de datos. El valor predeterminado es /var/lib/pacman/. La mayoría de los usuarios no necesitarán establecer esta opción. NOTA: si se especifica, esta es una ruta absoluta y la ruta raíz no se antepone automáticamente.

CacheDir = /ruta/al/directorio/cache

Anula la ubicación predeterminada del directorio de caché de paquetes. El valor predeterminado es /var/cache/pacman/pkg/. Se pueden especificar múltiples directorios de caché, y se prueban en el orden en que se enumeran en el archivo de configuración. Si un archivo no se encuentra en ningún directorio de caché, se descargará en el primer directorio de caché con acceso de escritura. NOTA: esta es una ruta absoluta, la ruta raíz no se antepone automáticamente.

HookDir = /ruta/al/directorio/hooks

Agrega directorios para buscar ganchos alpm además del directorio de ganchos del sistema (/usr/share/libalpm/hooks/). El valor predeterminado es /etc/pacman.d/hooks. Se pueden especificar múltiples directorios con ganchos en directorios posteriores que tienen prioridad sobre los ganchos en directorios anteriores. NOTA: esta es una ruta absoluta, la ruta raíz no se antepone automáticamente. Para más información sobre los ganchos alpm, consulte alpm-hooks(5).

GPGDir = /ruta/al/directorio/gpg

Anula la ubicación predeterminada del directorio que contiene los archivos de configuración para GnuPG. El valor predeterminado es /etc/pacman.d/gnupg/. Este directorio debe contener dos archivos: pubring.gpg y trustdb.gpg. pubring.gpg contiene las claves públicas de todos los empaquetadores. trustdb.gpg contiene una llamada base de datos de confianza, que especifica que las claves son auténticas y confiables. NOTA: esta es una ruta absoluta, la ruta raíz no se antepone automáticamente.

LogFile = /ruta/al/archivo/log

Anula la ubicación predeterminada del archivo de registro de pacman. El valor predeterminado es /var/log/pacman.log. Esta es una ruta absoluta y el directorio raíz no se antepone.

HoldPkg = paquete ...

Si un usuario intenta --remove un paquete que está listado en HoldPkg, pacman pedirá confirmación antes de continuar. Se permiten patrones de estilo shell (glob).

IgnorePkg = paquete ...

Instruye a pacman para que ignore cualquier actualización para este paquete al realizar una --sysupgrade. Se permiten patrones de estilo shell (glob).

IgnoreGroup = grupo ...

Instruye a pacman para que ignore cualquier actualización para todos los paquetes de este grupo al realizar una --sysupgrade. Se permiten patrones de estilo shell (glob).

Include = /ruta/al/archivo/de/configuracion

Incluye otro archivo de configuración. Este archivo puede incluir repositorios u opciones de configuración generales. Los comodines en las rutas especificadas se expandirán según las reglas de glob(7).

Architecture = auto &| i686 &| x86_64 | ...

Si se establece, pacman solo permitirá la instalación de paquetes con las arquitecturas dadas (por ejemplo, i686, x86_64, etc.). El valor especial auto utilizará la arquitectura del sistema, proporcionada por "uname -m". Si no se establece, no se realizan verificaciones de arquitectura. NOTA: Los paquetes con la arquitectura especial any siempre se pueden instalar, ya que están destinados a ser independientes de la arquitectura.

XferCommand = /ruta/al/comando %u [%o]

Si se establece, se utilizará un programa externo para descargar todos los archivos remotos. Todas las instancias de %u se reemplazarán con la URL de descarga. Si está presente, las instancias de %o se reemplazarán con el nombre del archivo local, más una extensión ".part", lo que permite que programas como wget realicen reanudaciones de archivos correctamente.

Esta opción es útil para usuarios que experimentan problemas con el soporte HTTP/FTP integrado, o que necesitan un soporte de proxy más avanzado que viene con utilidades como wget.

NoUpgrade = archivo ...

Todos los archivos listados con una directiva NoUpgrade nunca serán tocados durante la instalación/actualización de un paquete, y los nuevos archivos se instalarán con la extensión .pacnew. Estos archivos se refieren a archivos en el archivo del paquete, por lo que no incluya la barra inicial (el RootDir) al especificarlos. Se permiten patrones de estilo shell (glob). Es posible invertir coincidencias anteponiendo un archivo con un signo de exclamación. Los archivos invertidos resultarán en que los archivos previamente bloqueados vuelvan a ser permitidos. Las coincidencias posteriores anularán las anteriores. Se debe escapar un signo de exclamación literal inicial o una barra invertida.

NoExtract = archivo ...

Todos los archivos listados con una directiva NoExtract nunca serán extraídos de un paquete al sistema de archivos. Esto puede ser útil cuando no desea que parte de un paquete se instale. Por ejemplo, si la raíz httpd de su servidor utiliza un index.php, entonces no querría que el archivo index.html se extrajera del paquete apache. Estos archivos se refieren a archivos en el archivo del paquete, por lo que no incluya la barra inicial (el RootDir) al especificarlos. Se permiten patrones de estilo shell (glob). Es posible invertir coincidencias anteponiendo un archivo con un signo de exclamación. Los archivos invertidos resultarán en que los archivos previamente bloqueados vuelvan a ser permitidos. Las coincidencias posteriores anularán las anteriores. Se debe escapar un signo de exclamación literal inicial o una barra invertida.

CleanMethod = KeepInstalled &| KeepCurrent

Si se establece en KeepInstalled (el valor predeterminado), la operación -Sc limpiará los paquetes que ya no están instalados (no presentes en la base de datos local). Si se establece en KeepCurrent, -Sc limpiará los paquetes obsoletos (no presentes en ninguna base de datos de sincronización). El segundo comportamiento es útil cuando la caché de paquetes se comparte entre múltiples máquinas, donde las bases de datos locales suelen ser diferentes, pero las bases de datos de sincronización en uso podrían ser las mismas. Si se especifican ambos valores, los paquetes solo se limpiarán si no están instalados localmente y no están presentes en ninguna base de datos de sincronización conocida.

SigLevel = ...

Establece el nivel de verificación de firma predeterminado. Para más información, consulte Verificación de Firma de Paquetes y Bases de Datos a continuación.

LocalFileSigLevel = ...

Establece el nivel de verificación de firma para instalar paquetes utilizando la operación "-U" en un archivo local. Utiliza el valor de SigLevel como predeterminado.

RemoteFileSigLevel = ...

Establece el nivel de verificación de firma para instalar paquetes utilizando la operación "-U" en una URL de archivo remoto. Utiliza el valor de SigLevel como predeterminado.

UseSyslog

Registra mensajes de acción a través de syslog(). Esto insertará entradas de registro en /var/log/messages o equivalente.
