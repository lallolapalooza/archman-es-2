NOMBRE

pamaddnoise - añade ruido a una imagen Netpbm

SINOPSIS

pamaddnoise

[-tipo tipo_de_ruido]

[-semilla entero] pamaddnoise -tipo gaussian

[-sigma1 valor]

[-sigma2 valor] [-semilla entero]

[archivo_netpbm] pamaddnoise -tipo multiplicative_gaussian

[-mgsigma valor] [-semilla entero]

[archivo_netpbm] pamaddnoise -tipo impulse

[-tolerancia ratio]

[-semilla entero] [archivo_netpbm] pamaddnoise -tipo laplacian

[-lsigma valor]

[-semilla entero] [archivo_netpbm] pamaddnoise -tipo poisson

[-lambda valor]

[-semilla entero] [archivo_netpbm]

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pamaddnoise añade el tipo de ruido especificado a una imagen Netpbm. pamaddnoise trata una imagen PPM como 3 planos independientes, no como un plano de colores en un espacio de color.

OPCIONES

-lambda valor
Usado solo para ruido poisson. El valor predeterminado es 0.05.
-lsigma valor
Usado solo para ruido laplaciano. El valor predeterminado es 10.0.
-mgsigma valor
Usado solo para ruido gaussiano multiplicativo. El valor predeterminado es 0.5.
-semilla entero
Usado para todos los tipos de ruido. Establece el valor inicial de la semilla del generador de números aleatorios.
-sigma1 valor
Usado solo para ruido gaussiano. El valor predeterminado es 4.0.
-sigma2 valor
Usado solo para ruido gaussiano. El valor predeterminado es 20.0.
-tolerancia ratio
Usado solo para ruido de impulso. El valor predeterminado es 0.10. Esto significa que el 5% de todos los valores de píxel se establecerán en 0 y el 5% se establecerán en el valor máximo.
-tipo tipo_de_ruido
Selecciona el tipo de ruido por nombre. Los siguientes tipos de ruido están disponibles: gaussian, multiplicative_gaussian, impulse, laplacian, poisson. Solo se requieren suficientes letras para ser únicas para la opción de tipo de ruido. El tipo de ruido predeterminado es gaussian.

HISTORIA

pamaddnoise se añadió a Netpbm en la versión 10.29 (agosto de 2005). Antes de eso, había sido distribuido por Mike Burns a través de su propio sitio web (y continuó siéndolo).

La versión de Burns, y la incluida en Netpbm 10.29, se llamaba pnmaddnoise y solo funcionaba con imágenes PNM. En Netpbm 10.30, se convirtió para manejar imágenes PAM y se renombró a pamaddnoise.
