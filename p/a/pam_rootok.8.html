NOMBRE

pam_rootok - Obtener acceso solo como root

SINOPSIS

pam_rootok.so [debug]

DESCRIPCIÓN

pam_rootok es un módulo PAM que autentica al usuario si su UID es 0. Las aplicaciones creadas con setuid-root generalmente conservan el UID del usuario pero se ejecutan con la autoridad de un efectivo-UID mejorado. Se verifica el UID real.

OPCIONES

debug

Imprime información de depuración.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan los tipos de módulo auth, account y password.

VALORES DE RETORNO

PAM_SUCCESS

El UID es 0.

PAM_AUTH_ERR

El UID no es 0.

EJEMPLOS

En el caso de la aplicación su(1), el uso histórico es permitir al superusuario adoptar la identidad de un usuario menor sin el uso de una contraseña. Para obtener este comportamiento con PAM, se necesitan las siguientes líneas para la entrada correspondiente en el archivo de configuración /etc/pam.d/su:

# Autenticación de su. Se concede acceso a root por defecto.
auth  sufficient   pam_rootok.so
auth  required     pam_unix.so

VER TAMBIÉN

su(1), pam.conf(5), pam.d(5), pam(8)
