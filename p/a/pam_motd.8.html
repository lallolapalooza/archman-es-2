NOMBRE

pam_motd - Muestra el archivo motd

SINOPSIS

pam_motd.so [motd=/ruta/nombre_archivo] [motd_dir=/ruta/directorio.d]

DESCRIPCIÓN

pam_motd es un módulo PAM que se puede usar para mostrar archivos arbitrarios de motd (mensaje del día) después de un inicio de sesión exitoso. Por defecto, pam_motd muestra los archivos en las siguientes ubicaciones:

/etc/motd
/run/motd
/usr/lib/motd
/etc/motd.d/
/run/motd.d/
/usr/lib/motd.d/

El tamaño de cada mensaje está limitado a 64 KB.

Si /etc/motd no existe, entonces se muestra /run/motd. Si /run/motd no existe, entonces se muestra /usr/lib/motd.

Un comportamiento similar de anulación se aplica a los directorios. Los archivos en /etc/motd.d/ anulan a los archivos con el mismo nombre en /run/motd.d/ y /usr/lib/motd.d/. Los archivos en /run/motd.d/ anulan a los archivos con el mismo nombre en /usr/lib/motd.d/.

Los archivos en los directorios listados arriba se muestran en orden lexicográfico por nombre. Además, los archivos se filtran leyéndolos con las credenciales del usuario de destino que se autentica en el sistema.

Para silenciar un mensaje, se puede colocar un enlace simbólico con destino /dev/null en /etc/motd.d/ con el mismo nombre de archivo que el mensaje que se desea silenciar. Por ejemplo: Crear un enlace simbólico como el siguiente silencia /usr/lib/motd.d/my_motd.

ln -s /dev/null /etc/motd.d/my_motd

La variable de entorno MOTD_SHOWN=pam se establece después de mostrar los archivos motd, incluso cuando todos ellos fueron silenciados usando enlaces simbólicos.

OPCIONES

motd=/ruta/nombre_archivo

Se muestra el archivo /ruta/nombre_archivo como mensaje del día. Se pueden especificar múltiples rutas a probar como una lista separada por dos puntos. Por defecto, esta opción se establece en /etc/motd:/run/motd:/usr/lib/motd.

motd_dir=/ruta/directorio.d

Se escanea el directorio /ruta/directorio.d y se muestra cada archivo contenido en él. Se pueden especificar múltiples directorios a escanear como una lista separada por dos puntos. Por defecto, esta opción se establece en /etc/motd.d:/run/motd.d:/usr/lib/motd.d.

Cuando no se proporcionan opciones, se aplica el comportamiento por defecto para ambas opciones. Especificar cualquiera de las opciones (o ambas) desactivará el comportamiento por defecto para ambas opciones.

TIPOS DE MÓDULOS PROPORCIONADOS

Solo se proporciona el tipo de módulo session.

VALORES DE RETORNO

PAM_ABORT

No se pudieron obtener todos los datos o opciones relevantes.

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_IGNORE

Este es el valor de retorno por defecto de este módulo.

EJEMPLOS

El uso sugerido para /etc/pam.d/login es:

session  optional  pam_motd.so

Para usar un archivo motd de una ubicación diferente:

session  optional  pam_motd.so motd=/otro_lugar/motd

Para usar un archivo motd de otro lugar, junto con un directorio .d correspondiente:

session  optional  pam_motd.so motd=/otro_lugar/motd motd_dir=/otro_lugar/motd.d
