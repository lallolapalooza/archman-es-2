NOMBRE

pam_misc_setenv - Establecimiento de variables de entorno al estilo BSD en PAM

SINOPSIS

#include <security/pam_misc.h>

int pam_misc_setenv(pam_handle_t *pamh, const char *name, const char *value, int readonly);

DESCRIPCIÓN

Esta función realiza una tarea equivalente a pam_putenv(3), sin embargo, su sintaxis se parece más a la función de estilo BSD; setenv(). Los argumentos name y value se concatenan con un '=' para formar un nombre=valor y se pasan a pam_putenv(). Sin embargo, si la variable PAM ya está establecida, el reemplazo solo se aplicará si el último argumento, readonly, es cero.

VER TAMBIÉN

pam_putenv(3), pam(8)

ESTÁNDARES

La función pam_misc_setenv es parte de la biblioteca libpam_misc y no está definida en ningún estándar.
