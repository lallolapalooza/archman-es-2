PACLOG(1) paclog PACLOG(1)

NOMBRE

paclog - filtrar entradas del registro de pacman

SINOPSIS

paclog [opciones] [filtros]...
paclog [opciones] --pkglist
paclog (--help|--version)

DESCRIPCIÓN

Si se proporciona entrada en stdin, se analizará en lugar de usar --logfile. Las entradas del registro se mostrarán si coinciden con *cualquiera* de los filtros proporcionados. Para mostrar la intersección de múltiples filtros, se pueden conectar con una tubería:

paclog --after=2015-01-01 | paclog --warnings

OPCIONES

--config=ruta
Establecer una ruta de archivo de configuración alternativa.
--logfile=ruta
Establecer una ruta de archivo de registro alternativa.
--root=ruta
Establecer una raíz de instalación alternativa.
--sysroot=ruta
Establecer una raíz de sistema alternativa. Consulte pacutils-sysroot(7).
--[no-]color
Colorea la salida. Por defecto, la salida se coloreará si stdout es una terminal.
--pkglist
Imprime la lista de paquetes instalados según el registro.
--help
Muestra la información de uso y sale.
--version
Muestra la información de la versión y sale.

Filtros

--action=acción
Muestra operaciones de paquetes. acción debe ser una de "install", "reinstall", "upgrade", "downgrade", "remove", o "all".
--after=fecha, --before=fecha
Muestra entradas después/antes de fecha. Si se incluyen segundos o información de zona horaria, se ignorarán silenciosamente, lo que permite usar la salida de "date -I": 
paclog --after "$(date -Iminutes --date '3 days ago')"
--caller=nombre
Muestra entradas del registro de nombre. Puede especificarse varias veces. Distingue entre mayúsculas y minúsculas.
--commandline
Muestra entradas de línea de comandos registradas al estilo pacman.
--grep=expresión regular
Muestra entradas del registro cuyo mensaje coincide con expresión regular.
--package=nombrepaquete
Muestra acciones registradas que afectan a nombrepaquete. Puede especificarse varias veces.
--warnings
Muestra errores, advertencias y notas.

ADVERTENCIAS

paclog determina si debe leer el archivo de registro de stdin basándose en una comprobación ingenua usando isatty(3). Si paclog se llama en un entorno, como una función de shell o un script que se usa en una tubería, donde stdin no está conectado a una terminal pero no hay un archivo de registro para analizar, paclog debe llamarse con stdin cerrado. Para shells compatibles con POSIX, esto se puede hacer con "<&-".
