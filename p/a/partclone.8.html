PARTCLONE(8) Manual de usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - Utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de una partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También admite algunos sistemas operativos no linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], muy similar a fsck o mkfs. Por ejemplo, para respaldar/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos             partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no admitidos)     partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de su acción. Normalmente, el origen de la copia de seguridad es un dispositivo, el origen de la restauración es un archivo de imagen.

La recepción de datos desde una tubería solo se admite para la restauración, simplemente ignore la opción -s o use '-' para recibir datos de stdin.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de su acción. Normalmente, la copia de seguridad se guarda en un archivo de imagen y la restauración se envía a un dispositivo.

El envío de datos a una tubería también se admite solo para copia de seguridad, simplemente ignore la opción -o o use '-' para enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, el origen y la salida son ambos dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añadir X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Crear un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Poner una ruta especial para registrar información del registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No verificar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de comprobación crc.

-F, --force

Forzar progreso.

-f seg, --UI-fresh seg

Establecer un intervalo de segundos para la actualización de la interfaz.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de verificación a utilizar para agregar detección de errores.

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

2: xxHash, algoritmo hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribir una suma de verificación por cada X bloques.

-w, --skip_write_error

Continuar la restauración durante errores de escritura.

--write-direct-io

Escribir datos en la partición DE DESTINO sin caché.

--read-direct-io

Leer datos de la partición DE ORIGEN sin caché.

-B, --no_block_detail

Mostrar mensaje de progreso sin detalle de bloques.

--binary-prefix

Mostrar progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Mostrar progreso en segundos (por defecto es minuto).

-E, --offset=X

Añadir un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-n, --note NOTA

Mostrar mensaje NOTA (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar la versión de
partclone.ext3(8) - Manual de partclone

NAME

partclone.ext3

- Clonar y restaurar el sistema de archivos ext3.

SYNOPSIS

partclone.ext3 [opciones] [-s fuente] [-o destino]

DESCRIPTION

partclone.ext3 es una utilidad para clonar y restaurar sistemas de archivos ext3. Puede ser utilizado para clonar un sistema de archivos ext3 a un archivo de imagen o a otro dispositivo, o para restaurar un sistema de archivos ext3 desde un archivo de imagen o dispositivo. Partclone está diseñado para ser más eficiente que dd, ya que sólo copia los bloques utilizados en el sistema de archivos.

OPTIONS

Las siguientes opciones están disponibles:

-c, --clone
Clonar el sistema de archivos.
-r, --restore
Restaurar el sistema de archivos.
-s, --source fuente
Especificar el dispositivo o archivo de origen.
-o, --output destino
Especificar el dispositivo o archivo de destino.
-d, --debug
Habilitar información de depuración.
-R, --readme
Mostrar la información de README.
-h, --help
Mostrar el mensaje de ayuda.
-v, --version
Mostrar la versión del programa.

Para clonar un sistema de archivos, debe especificar la opción -c y el origen y destino. Para restaurar un sistema de archivos, debe especificar la opción -r y el origen y destino.

El origen puede ser un dispositivo de bloque (por ejemplo, /dev/hda1) o un archivo de imagen. El destino puede ser un dispositivo de bloque o un archivo.

Si especifica la opción -d, se mostrará información de depuración en la salida estándar.

FILES

/var/log/partclone.log

El archivo de registro de partclone

EXAMPLES

 Clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 Restaurar imagen desde clonezilla (dividida, gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone proporciona algunos códigos de retorno, que pueden usarse en scripts:

Código Diagnóstico
0 El programa salió exitosamente.
1 La clonación o restauración parecen haber fallado.
