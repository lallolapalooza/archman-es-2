NOMBRE

pam_mkhomedir - Módulo PAM para crear el directorio de inicio del usuario

SINOPSIS

pam_mkhomedir.so [silent] [debug] [umask=modo] [skel=directorio_esqueleto]

DESCRIPCIÓN

El módulo PAM pam_mkhomedir creará el directorio de inicio de un usuario si no existe al comenzar la sesión. Esto permite que los usuarios estén presentes en una base de datos central (como NIS, kerberos o LDAP) sin usar un sistema de archivos distribuido o precrear un gran número de directorios. El directorio esqueleto (generalmente /etc/skel/) se usa para copiar archivos predeterminados y también establece una umask para la creación.

El nuevo directorio de inicio del usuario no se eliminará después de que el usuario cierre la sesión.

OPCIONES

silent

No imprime mensajes informativos.

debug

Activa la depuración a través de syslog(3).

umask=mask

La máscara de creación de archivos se establece en mask. El valor predeterminado de mask es 0022. Si esta opción no se especifica, los permisos del directorio de inicio del usuario creado se establecen en el valor del elemento de configuración HOME_MODE de /etc/login.defs. Si no existe tal elemento de configuración, el valor se calcula a partir del valor de UMASK en el mismo archivo. Si tampoco existe tal opción de configuración, se utiliza el valor predeterminado de 0755 para el modo.

skel=/ruta/al/directorio/esqueleto

Indica un directorio esqueleto alternativo para anular el predeterminado /etc/skel.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo session.

VALORES DE RETORNO

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_PERM_DENIED

Permisos insuficientes para crear el nuevo directorio o leer el directorio esqueleto.

PAM_USER_UNKNOWN

Usuario no conocido por el módulo de autenticación subyacente.

PAM_SUCCESS

Las variables de entorno se establecieron.

ARCHIVOS

/etc/skel

Directorio esqueleto predeterminado

EJEMPLOS

Un archivo /etc/pam.d/login de ejemplo:

  auth       requisite   pam_securetty.so
  auth       sufficient  pam_ldap.so
  auth       required    pam_unix.so
  auth       required    pam_nologin.so
  account    sufficient  pam_ldap.so
  account    required    pam_unix.so
  password   required    pam_unix.so
  session    required    pam_mkhomedir.so skel=/etc/skel/ umask=0022
  session    required    pam_unix.so
  session    optional    pam_lastlog.so
  session    optional    pam_mail.so standard

VER TAMBIÉN

pam.d(5), pam(8).
