PAM_SM_SETCRED(3) Manual de Linux-PAM PAM_SM_SETCRED(3)

NOMBRE

pam_sm_setcred - función de servicio de PAM para alterar credenciales

SINOPSIS

#include <security/pam_modules.h>

int pam_sm_setcred(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPCIÓN

La función pam_sm_setcred es la implementación del módulo de servicio de la interfaz pam_setcred(3).

Esta función realiza la tarea de alterar las credenciales del usuario con respecto al esquema de autorización correspondiente. Generalmente, un módulo de autenticación puede tener más información sobre un usuario que su token de autenticación. Esta función se utiliza para hacer que dicha información esté disponible para la aplicación. Solo debe ser llamada *después* de que el usuario haya sido autenticado pero antes de que se haya establecido una sesión.

Las banderas válidas, que pueden ser OR'adas lógicamente con *PAM_SILENT*, son:

PAM_SILENT

No emitir ningún mensaje.

PAM_ESTABLISH_CRED

Inicializar las credenciales para el usuario.

PAM_DELETE_CRED

Eliminar las credenciales asociadas con el servicio de autenticación.

PAM_REINITIALIZE_CRED

Reinicializar las credenciales del usuario.

PAM_REFRESH_CRED

Extender la vida útil de las credenciales del usuario.

La forma en que se navega la pila de *auth* para evaluar la llamada a la función pam_setcred(), independientemente de los códigos de retorno de pam_sm_setcred(), es exactamente la misma forma en que se navegó al evaluar la llamada a la biblioteca pam_authenticate(). Típicamente, si una entrada de la pila fue ignorada al evaluar pam_authenticate(), será ignorada cuando libpam evalúe la llamada a la función pam_setcred(). De lo contrario, los códigos de retorno de cada llamada a pam_sm_setcred() específica del módulo se tratan como *requeridos*.

VALORES DE RETORNO

PAM_CRED_UNAVAIL

Este módulo no puede recuperar las credenciales del usuario.

PAM_CRED_EXPIRED

Las credenciales del usuario han expirado.

PAM_CRED_ERR

Este módulo no pudo establecer las credenciales del usuario.

PAM_SUCCESS

Las credenciales del usuario se establecieron correctamente.

PAM_USER_UNKNOWN

El usuario no es conocido por este módulo de autenticación.

Estos valores de retorno, que no son *PAM_SUCCESS*, típicamente llevarán a que la pila de credenciales *falle*. El primer error de este tipo dominará el valor de retorno de pam_setcred().
