NOMBRE

pano_modify - Cambiar los parámetros de salida del archivo de proyecto

SINOPSIS

pano_modify [opciones] archivo_entrada.pto

DESCRIPCIÓN

pano_modify modifica un único proyecto .pto de Hugin.

OPCIONES

-o, --output=archivo.pto
Archivo de salida PTO de Hugin. Por defecto: <nombre_archivo>_mod.pto
-p, --projection=NÚMERO
Establece la proyección de salida a NÚMERO
RECTILINEAR = 0,
PANORAMA (Circular) = 1,
ECUIRRECTANGULAR = 2,
FISHEYE_FF = 3,
ESTEREOOGRÁFICA = 4,
MERCATOR = 5,
TRANS_MERCATOR = 6,
SINUSOIDAL = 7,
LAMBERT_IGUAL_AREA_CÓNICA = 8,
LAMBERT_AZIMUTAL = 9,
ALBERS_IGUAL_AREA_CÓNICA = 10,
MILLER_CILÍNDRICA = 11,
PANINI = 12,
ARQUITECTÓNICA = 13,
ORTOGRÁFICA = 14,
EQUISÓLIDO = 15,
EQUI_PANINI = 16,
BIPLANO = 17,
TRIPLANO = 18,
PANINI_GENERAL = 19,
THOBY = 20,
HAMMER = 21
--fov=AUTO|HFOV|HFOVxVFOV
Establece el campo de visión.

AUTO: calcula el FOV óptimo

HFOV|HFOVxVFOV: establece al FOV dado

-s, --straighten
Endereza el panorama
-c, --center
Centra el panorama
--canvas=AUTO|num%|ANCHOxALTO
Establece el tamaño del lienzo de salida

AUTO: calcula el tamaño óptimo del lienzo

num%: escala el tamaño óptimo por el porcentaje dado

ANCHOxALTO: establece al tamaño dado

--crop=AUTO|AUTOHDR|izq,der,sup,inf
Establece el rectángulo de recorte

AUTO: recorte automático del panorama

AUTOHDR: recorte automático del panorama HDR

izq,der,sup,inf: al tamaño dado

--output-exposure=AUTO|num
Establece el valor de exposición de salida a la exposición media (AUTO) o a un valor dado
--output-type=str
Establece el tipo de salida

Los elementos válidos son (se pueden separar varios elementos por una coma)

NORMAL|N: panorama normal

STACKSFUSEDBLENDED|BF: panorama LDR con pilas mezcladas

EXPOSURELAYERSFUSED|FB: panorama LDR con capas de exposición mezcladas (cualquier disposición)

HDR: panorama HDR

REMAP: imágenes remapeadas con exposición corregida

REMAPORIG: imágenes remapeadas con exposición sin corregir

HDRREMAP: imágenes remapeadas en espacio de color lineal

FUSEDSTACKS: pilas de exposición mezcladas

HDRSTACKS: pilas HDR

EXPOSURELAYERS: capas de exposición mezcladas

--ldr-file=JPG|TIF|PNG
Establece el tipo de archivo para la salida del panorama LDR
--ldr-compression=str
Establece la compresión para la salida del panorama LDR

Para TIF: NONE|PACKBITS|LZW|DEFLATE

Para JPG: calidad como número

--hdr-file=EXR|TIF
Establece el tipo de archivo para la salida del panorama HDR
--hdr-compression=str
Establece la compresión para la salida del panorama HDR

Para TIF: NONE|PACKBITS|LZW|DEFLATE

--blender=ENBLEND|INTERNAL
Establece el mezclador a utilizar en la etapa de unión
--rotate=guiñada,cabeceo,balanceo
Rota todo el panorama con los ángulos dados
--translate=x,y,z
Translada todo el panorama con los valores dados
-h, --help
Muestra la ayuda
