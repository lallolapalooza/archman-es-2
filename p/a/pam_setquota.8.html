NOMBRE

pam_setquota - módulo PAM para establecer o modificar cuotas de disco al inicio de sesión

SINOPSIS

pam_setquota.so [fs=/home] [overwrite=0] [debug=0] [startuid=1000] [enduid=0] [bsoftlimit=19000] [bhardlimit=20000] [isoftlimit=3000] [ihardlimit=4000]

DESCRIPCIÓN

pam_setquota es un módulo PAM para establecer o modificar una cuota de disco al inicio de sesión.

Esto hace que las cuotas sean utilizables con bases de datos de usuarios centrales, como MySQL o LDAP.

OPCIONES

fs=/home

El archivo del dispositivo o punto de montaje al que se aplica la política. Por defecto, el sistema de archivos que contiene el directorio personal del usuario.

overwrite=0

Sobrescribir una cuota existente. Nota: Habilitar esto eliminará la capacidad del administrador para configurar manualmente cuotas diferentes para los usuarios en un sistema de archivos con edquota(8). (Por defecto 0)

debug=0

Habilitar depuración. Un valor de 1 muestra la cuota antigua y la nueva en un dispositivo. Un valor de 2 también imprime los sistemas de archivos coincidentes y encontrados si **fs** no está definido. (Por defecto 0)

startuid=1000

Describe el inicio del rango de UID al que se aplica la política. (Por defecto UID_MIN de login.defs o el valor uidmin definido en tiempo de compilación si UID_MIN no está definido).

enduid=0

Describe el final del rango de UID al que se aplica la política. Establecer enduid=0 resulta en un rango de UID abierto (es decir, se incluyen todos los uids mayores que **startuid**). (Por defecto 0)

bsoftlimit=19000

Límite blando para bloques de cuota de disco, como se define en quotactl(2). Nota: **bsoftlimit** y **bhardlimit** deben establecerse al mismo tiempo.

bhardlimit=20000

Límite duro para bloques de cuota de disco, como se define en quotactl(2). Nota: **bsoftlimit** y **bhardlimit** deben establecerse al mismo tiempo.

isoftlimit=3000

Límite blando para inodos, como se define en ** quotactl**(2). Nota: **isoftlimit** y **ihardlimit** deben establecerse al mismo tiempo.

ihardlimit=4000

Límite duro para inodos, como se define en ** quotactl**(2). Nota: **isoftlimit** y **ihardlimit** deben establecerse al mismo tiempo.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo **session**.

VALORES DE RETORNO

PAM_SUCCESS

La cuota se estableció correctamente.

PAM_IGNORE

No se realizó ninguna acción porque el UID del usuario estaba fuera del rango especificado, ya existía una cuota y no se configuró **overwrite=1**, o no se configuraron límites.

PAM_USER_UNKNOWN

El usuario no fue encontrado.

PAM_PERM_DENIED

No se pudo abrir /proc/mounts.

No se encontró el sistema de archivos o dispositivo especificado.

No se pudieron recuperar los límites del usuario. Consulte syslog para obtener más información.

No se pudieron establecer los límites del usuario. Consulte syslog para obtener más información.

No se establecieron **isoftlimit**/**ihardlimit** o **bsoftlimit**/**bhardlimit** al mismo tiempo.

EJEMPLOS

Una única invocación de `pam_setquota` aplica una política específica a un rango de UID. La aplicación de diferentes políticas a rangos de UID específicos se realiza invocando pam_setquota varias veces. La última entrada que coincide define la cuota resultante.

      session  required   pam_setquota.so bsoftlimit=1000 bhardlimit=2000 isoftlimit=1000 ihardlimit=2000 startuid=1000 enduid=0 fs=/home
      session  required   pam_setquota.so bsoftlimit=19000 bhardlimit=20000 isoftlimit=3000 ihardlimit=4000 startuid=2001 enduid=3000 fs=/dev/sda1
      session  required   pam_setquota.so bsoftlimit=19000 bhardlimit=20000 isoftlimit=3000 ihardlimit=4000 startuid=3001 enduid=4000 fs=/dev/sda1 overwrite=1
