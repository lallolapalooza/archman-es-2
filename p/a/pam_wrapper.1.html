NOMBRE

pam_wrapper - Un envoltorio pre-cargable para probar aplicaciones y módulos PAM

SINOPSIS

LD_PRELOAD=libpam_wrapper.so PAM_WRAPPER=1 PAM_WRAPPER_SERVICE_DIR=/ruta/a/configuración ./miaplicacion

DESCRIPCIÓN

Esta herramienta te permite probar tu aplicación o módulo PAM. Para probar aplicaciones PAM, hemos escrito un módulo PAM simple llamado pam_matrix (ver más abajo). Si planeas probar un módulo PAM, puedes usar la biblioteca pamtest que hemos implementado. Simplifica las pruebas de módulos. Puedes combinarla con el framework de pruebas unitarias cmocka o puedes usar los enlaces de Python proporcionados para escribir pruebas para tu módulo en Python.

VARIABLES DE ENTORNO

pam_wrapper se activa y se controla mediante variables de entorno. Puedes establecer las siguientes variables:

PAM_WRAPPER

Si cargas pam_wrapper y lo activas estableciendo PAM_WRAPPER=1, todas las llamadas PAM serán envueltas para que puedas especificar un directorio con los archivos de servicio que debe usar pam_wrapper.

PAM_WRAPPER_SERVICE_DIR

El directorio desde donde leer los archivos de servicio de PAM.

Si deseas usar pam_matrix (ver más abajo) o quieres probar tu propio módulo PAM, necesitas especificar la ruta absoluta a tu módulo en los archivos de servicio.

PAM_WRAPPER_DEBUGLEVEL

Si necesitas ver lo que está sucediendo en pam_wrapper o intentar encontrar un error, puedes habilitar el soporte de registro en pam_wrapper si lo compilaste con símbolos de depuración.
•0 = ERROR
•1 = ADVERTENCIA
•2 = DEBUG
•3 = TRAZA

PAM_WRAPPER_USE_SYSLOG

Por defecto, los registros de PAM irán al nivel de registro DEBUG de pam_wrapper y no se enviarán a syslog. Si también quieres registrar en syslog, puedes establecer esta variable a 1.

PAM_WRAPPER_KEEP_DIR

Si esta opción se establece a 1, pam_wrapper no eliminará sus directorios temporales. Principalmente útil para el desarrollo de pam_wrapper.

PAM_WRAPPER_DISABLE_DEEPBIND

Esto te permite deshabilitar el enlace profundo en pam_wrapper. Esto es útil para ejecutar herramientas como valgrind o sanitizadores como (address, undefined, thread).

EJEMPLO

Un archivo de servicio para pam_wrapper debería verse así:

auth            required        /usr/lib/pam_wrapper/pam_matrix.so passdb=/ruta/a/pdb
account         required        /usr/lib/pam_wrapper/pam_matrix.so passdb=/ruta/a/pdb
password        required        /usr/lib/pam_wrapper/pam_matrix.so passdb=/ruta/a/pdb
session         required        /usr/lib/pam_wrapper/pam_matrix.so passdb=/ruta/a/pdb

El nombre del archivo debe representar el nombre del servicio utilizado por tu aplicación PAM.

LD_PRELOAD=./libpam_wrapper.so PAM_WRAPPER=1 PAM_WRAPPER_SERVICE_DIR=./servicios_pam ./mi_app_pam

PAM_MATRIX

Ofrecemos un módulo para facilitar las pruebas de aplicaciones PAM. Encontrarás más información en la página del manual pam_matrix(8).
