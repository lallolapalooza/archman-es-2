PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone.extfs - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de los bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos mediante el uso de bibliotecas existentes, por ejemplo, se utilizan e2fslibs para leer el bloque utilizado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También es compatible con algunos sistemas operativos no linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], de forma muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos             partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS no soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s FICHERO, --source FICHERO

FICHERO de origen. El FICHERO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de su acción. Normalmente, la fuente de copia de seguridad es un dispositivo, la fuente de restauración es un archivo de imagen.

La recepción de datos desde una tubería solo se admite para la restauración; ignore la opción -s o use '-' para indicar la recepción de datos desde stdin.

-o FICHERO, --output FICHERO

FICHERO de salida. El FICHERO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de su acción. Normalmente, la salida de copia de seguridad va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a una tubería también se admite SOLO para copias de seguridad; ignore la opción -o o use '-' para indicar el envío de datos a stdout.

-O FICHERO, --overwrite FICHERO

Sobrescribir FICHERO, sobrescribiendo si existe.

-W FICHERO, --restore_raw_file FICHERO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añadir X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Crear un archivo raw especial para el dispositivo loop.

-L FICHERO, --logfile FICHERO

Especificar una ruta especial para registrar la información de registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No verificar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar la interfaz de usuario de texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de la comprobación crc.

-F, --force

Forzar el progreso.

-f seg, --UI-fresh seg

Establecer un intervalo de segundos diferente para la actualización.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar el mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápida de calcular, detección básica)

2: xxHash, algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribir una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continuar la restauración mientras hay errores de escritura.

--write-direct-io

Escribir datos en la partición DESTINO sin caché.

--read-direct-io

Leer datos de la partición FUENTE sin caché.

-B, --no_block_detail

Mostrar mensaje de progreso sin detalle de bloques.

--binary-prefix

Mostrar progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Mostrar progreso en segundos (por defecto es minuto).

-E, --offset=X

Añadir un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-n, --note NOTE

Mostrar Nota de Mensaje (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar versión.

EJEMPLOS

partclone.ext4 --clone --source /dev/sda1 --output /dev/sda1.img

Clonar la partición /dev/sda1 a un archivo de imagen /dev/sda1.img.

partclone.ext4 --restore --source /dev/sda1.img --output /dev/sda2

Restaurar la imagen /dev/sda1.img a la partición /dev/sda2.

partclone.ntfs -c -s /dev/sda1 | partclone.ntfs -r -o /dev/sda2

Clonar la partición /dev/sda1 a /dev/sda2 usando tubería. (Solo para archivos compatibles con tubería).

partclone.ext4 --clone --source /dev/sda1 --output /dev/sda1.img --compresscmd "gzip -c"

Clonar la partición /dev/sda1 a /dev/sda1.img y comprimir la imagen con gzip.

partclone.ext4 --restore --source /dev/sda1.img --output /dev/sda2 --ncurses

Restaurar la imagen /dev/sda1.img a /dev/sda2 usando la interfaz de usuario de texto Ncurses.

NAME

partclone.extfs - clone file system

SYNOPSIS

partclone.extfs [ -c | -r ] [ -s device | -s file ] [ -o device | -o file ] [ -d ]

DESCRIPTION

partclone is a tool that helps you clone, save and restore any block device. The partclone tools support many file systems, such as btrfs, ext2, ext3, ext4, f2fs, fat, hfs+, hfsx, ntfs, reiserfs, udf, xfs, and nilfs2.

partclone.extfs can be used to clone or restore ext2, ext3, and ext4 file systems.

OPTIONS

The following options are supported:

-c
Clone the file system. When this option is used, partclone.extfs will save the file system to an image file. If the image file is split into multiple parts, you will need to use the same name for the first part and the rest will be named with a trailing number.
-r
Restore the file system. When this option is used, partclone.extfs will restore the file system from an image file.
-s device | file
Specify the source device or file. This can be a device such as /dev/hda1 or an image file. If this is set to '-', the image will be read from stdin.
-o device | file
Specify the output device or file. This can be a device such as /dev/hda1 or an image file. If this is set to '-', the image will be written to stdout.
-d
Display debug information. This option is useful for troubleshooting.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
