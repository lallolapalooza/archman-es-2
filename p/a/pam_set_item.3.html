PAM_SET_ITEM(3) Manual de Linux-PAM PAM_SET_ITEM(3)

NOMBRE

pam_set_item - establecer y actualizar información PAM

SINOPSIS

#include <security/pam_modules.h>

int pam_set_item(pam_handle_t *pamh, int item_type, const void *item);

DESCRIPCIÓN

La función pam_set_item permite a las aplicaciones y a los módulos de servicio PAM acceder y actualizar la información PAM del item_type. Para ello, se crea una copia del objeto al que apunta el argumento item. Los siguientes item_types son compatibles:

PAM_SERVICE

El nombre del servicio (que identifica la pila PAM que las funciones PAM utilizarán para autenticar el programa).

PAM_USER

El nombre de usuario de la entidad bajo cuya identidad se otorgará el servicio. Es decir, tras la autenticación, PAM_USER identifica la entidad local que puede usar el servicio. Tenga en cuenta que este valor puede ser mapeado de algo (por ejemplo, "anonymous") a algo más (por ejemplo, "guest119") por cualquier módulo en la pila PAM. Como tal, una aplicación debe consultar el valor de PAM_USER después de cada llamada a una función PAM.

PAM_USER_PROMPT

La cadena utilizada al solicitar el nombre de usuario. El valor predeterminado para esta cadena es una versión localizada de "login: ".

PAM_TTY

El nombre de la terminal precedido por /dev/ para los archivos de dispositivo. En el pasado, las aplicaciones gráficas basadas en X solían almacenar la variable $DISPLAY aquí, pero con la introducción de PAM_XDISPLAY este uso está obsoleto.

PAM_RUSER

El nombre de usuario solicitante: el nombre local para un usuario solicitante local o el nombre de usuario remoto para un usuario solicitante remoto.

En general, una aplicación o módulo intentará proporcionar el valor que está más fuertemente autenticado (una cuenta local antes que una remota). El nivel de confianza en este valor está incorporado en la pila de autenticación real asociada con la aplicación, por lo que está en última instancia a discreción del administrador del sistema.

PAM_RUSER@PAM_RHOST siempre debe identificar al usuario solicitante. En algunos casos, PAM_RUSER puede ser NULL. En tales situaciones, no está claro quién es la entidad solicitante.

PAM_RHOST

El nombre de host solicitante (el nombre de host de la máquina desde la que la entidad PAM_RUSER solicita el servicio). Es decir, PAM_RUSER@PAM_RHOST identifica al usuario solicitante. En algunas aplicaciones, PAM_RHOST puede ser NULL. En tales situaciones, no está claro de dónde se origina la solicitud de autenticación.

PAM_AUTHTOK

El token de autenticación (a menudo una contraseña). Este token debe ser ignorado por todas las funciones de módulo, excepto pam_sm_authenticate(3) y pam_sm_chauthtok(3). En la primera función, se utiliza para pasar el token de autenticación más reciente de un módulo apilado a otro. En la segunda función, el token se utiliza para otro propósito. Contiene el token de autenticación activo actualmente.

PAM_OLDAUTHTOK

El token de autenticación antiguo. Este token debe ser ignorado por todas las funciones de módulo, excepto pam_sm_chauthtok(3).

PAM_CONV

La estructura pam_conv. Consulte pam_conv(3).

Los siguientes elementos adicionales son específicos de Linux-PAM y no deben utilizarse en aplicaciones portátiles:

PAM_FAIL_DELAY

Un puntero de función para redirigir los retrasos de fallo gestionados centralmente. Consulte pam_fail_delay(3).

PAM_XDISPLAY

El nombre de la pantalla X. Para aplicaciones gráficas basadas en X, el valor de este elemento debe ser la variable $DISPLAY. Este valor puede usarse independientemente de PAM_TTY para pasar el nombre de la pantalla.

PAM_XAUTHDATA

Un puntero a una estructura que contiene los datos de autenticación X necesarios para establecer una conexión con la pantalla especificada por PAM_XDISPLAY, si dicha información es necesaria. Consulte pam_xauth_data(3).

PAM_AUTHTOK_TYPE

La acción predeterminada es que el módulo utilice las siguientes indicaciones al solicitar contraseñas: "Nueva contraseña UNIX: " y "Vuelva a escribir la contraseña UNIX: ". La palabra de ejemplo UNIX puede ser reemplazada por este elemento, por defecto está vacía. Este elemento es utilizado por pam_get_authtok(3).

Para todos los item_types, aparte de PAM_CONV y PAM_FAIL_DELAY, item es un puntero a una cadena de caracteres terminada en <NUL>. En el caso de PAM_CONV, item apunta a una estructura pam_conv inicializada. En el caso de PAM_FAIL_DELAY, item es un puntero de función: void (*delay_fn)(int retval, unsigned usec_delay, void *appdata_ptr)

Tanto PAM_AUTHTOK como PAM_OLDAUTHTOK se restablecerán antes de devolverlos a la aplicación. Lo que significa que una aplicación no puede acceder a los tokens de autenticación.

VALORES DE RETORNO

PAM_BAD_ITEM

La aplicación intentó establecer un elemento indefinido o inaccesible.

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_SUCCESS

Los datos se actualizaron correctamente.

PAM_SYSTEM_ERR

El pam_handle_t pasado como primer argumento era inválido.
