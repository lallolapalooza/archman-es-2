NOMBRE

pactrans, pacinstall, pacremove - instala/elimina paquetes alpm

SINOPSIS

pactrans   [opciones] <objetivo>...
pacinstall [opciones] <objetivo>...
pacremove  [opciones] <objetivo>...
pactrans   (--help|--version)

DESCRIPCIÓN

Instala/elimina paquetes alpm. Los alias pacinstall y pacremove se proporcionan como conveniencia, difiriendo solo en su interpretación predeterminada de objetivos. Por lo demás, son idénticos.

Si stdin no está conectado a una terminal, se leerán los pkgspec para instalar/eliminar desde stdin.

OPCIONES

Operaciones

Las opciones de operación afectan la interpretación de todos los objetivos que les siguen hasta que se encuentra otra opción de operación.

--spec (predeterminado de pactrans)
Interpreta los objetivos siguientes como pkgspec. Si un pkgspec indica un archivo de paquete o un paquete de repositorio, se instalará. Si indica un paquete en la base de datos local, se eliminará. Ver PKGSPEC para detalles del formato.
--install (predeterminado de pacinstall)
Interpreta los objetivos siguientes como paquetes a instalar desde un repositorio. Si solo se proporciona el nombre del paquete, se buscarán repositorios en el orden en que se declaran.
--remove (predeterminado de pacremove)
Interpreta los objetivos siguientes como nombres de paquetes a desinstalar.
--file
Interpreta los objetivos siguientes como rutas a archivos de paquetes a instalar.
--sysupgrade
Actualiza los paquetes instalados.

Opciones de Configuración

--cachedir=ruta
Establece una ruta de directorio de caché alternativa.
--config=ruta
Establece una ruta de archivo de configuración alternativa.
--dbext=extensión
Establece una extensión de base de datos de sincronización alternativa.
--dbpath=ruta
Establece una ruta de base de datos alternativa.
--logfile=ruta
Establece una ruta de archivo de registro alternativa.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--null[=sep]
Establece un separador alternativo para los valores analizados desde stdin. Por defecto, se usa una nueva línea "\n" como separador. Si se usa --null sin especificar sep, se usará "NUL".
--debug
Muestra información de depuración adicional.
--print-only
Muestra lo que haría la transacción y sale.
--no-confirm
Asume respuestas predeterminadas a todas las preguntas.
--no-timeout
Desactiva los tiempos de espera de baja velocidad para las descargas.
--help
Muestra la información de uso y sale.
--version
Muestra la información de versión y sale.

Opciones de Transacción

--dbsync
Actualiza las bases de datos de sincronización antes de realizar la transacción.
--dbonly
Realiza los cambios en la base de datos sin extraer ni eliminar ningún paquete.
--nodeps
Ignora las versiones de dependencias. Pasa dos veces para ignorar las comprobaciones de dependencias por completo.
--no-scriptlet
No ejecuta los scripts de instalación de paquetes.
--no-hooks
No ejecuta los hooks de transacción.
--assume-installed=paquete[=versión]
Actúa como si paquete estuviera instalado.

Opciones de Sysupgrade

--ignore-pkg=paquete
Ignora las actualizaciones para el paquete paquete. paquete puede ser un patrón comodín de estilo shell.
--ignore-group=grupo
Ignora las actualizaciones para cualquier paquete del grupo grupo. grupo puede ser un patrón comodín de estilo shell.

Opciones de --install/--file

--as-deps
Marca todos los paquetes instalados como dependencias.
--as-explicit
Marca todos los paquetes instalados como instalados explícitamente.
--download-only
Descarga paquetes sin instalarlos realmente.

Opciones de --remove

--cascade
Desinstala todos los paquetes instalados que dependen de un paquete que se está desinstalando.
--no-backup
No guarda copias de seguridad .pacsave.
--recursive
Desinstala las dependencias de los paquetes que se están eliminando que no son requeridas por ningún otro paquete.
--unneeded
No desinstala ningún paquete requerido por un paquete instalado.

Opciones de Disposición de Preguntas

--resolve-conflicts=método
Selecciona un método para resolver conflictos. Los valores posibles para método son:
"prompt"
Pregunta al usuario si desea eliminar el paquete conflictivo instalado.
"none"
No elimina ningún paquete conflictivo.
"all"
Elimina cualquier paquete conflictivo.
"provided"
Elimina un paquete conflictivo si el nuevo paquete lo proporciona.
"depends"
Elimina un paquete conflictivo si fue instalado como una dependencia.
"provided-depends"
Elimina un paquete conflictivo si fue instalado como una dependencia y el nuevo paquete lo proporciona.
--resolve-replacements=método
Selecciona un método para resolver reemplazos. Los valores posibles para método son:
"prompt"
Pregunta al usuario si desea reemplazar el paquete.
"none"
No reemplaza ningún paquete.
"all"
Realiza todos los reemplazos de paquetes disponibles.
"provided"
Realiza reemplazos donde el nuevo paquete proporciona el antiguo.
"depends"
Realiza reemplazos donde el paquete antiguo fue instalado como una dependencia.
"provided-depends"
Realiza reemplazos donde el paquete antiguo fue instalado como una dependencia y el nuevo paquete

NAME

pactrans - synchronize package repositories

SYNOPSIS

pactrans [ options ] [ pkgspec ... ]

DESCRIPTION

pactrans is a tool that can synchronize package repositories. It can be used to install, remove, or replace packages in a repository with versions from another repository. It attempts to preserve dependencies by installing any required dependencies and removing any packages that depend on removed packages.

If no pkgspec is provided on the command line, pactrans will attempt to read them from standard input.

OPTIONS

--no-confirm
Do not prompt for confirmation. This option overrides any disposition options that would otherwise prompt the user.
--nodeps
Do not check dependencies. This option should be used with extreme caution, as it can lead to a broken system.
--install
Install the given pkgspecs. This is the default behavior if no operation is specified.
--remove
Remove the given pkgspecs. Any packages that depend on the removed packages will also be removed.
--change-repo=new_repo
Change the repository of the specified pkgspecs to new_repo. This is useful for migrating packages between repositories.
--search
Search for packages that match the given pkgspecs. This option can be used to find packages in other repositories.
--add
Add the given pkgspecs to the transaction. This is the default behavior when a pkgspec is provided.
--replace
Replace the given pkgspecs with newer versions from other repositories. This option is useful for upgrading packages.
--copy
Copy the given pkgspecs to the target repository. This option is useful for moving packages between repositories.
--prompt=prompt|yes|no
Set the disposition for prompts. Valid options are "prompt", "yes", and "no". If set to "yes", all prompts will be answered with yes. If set to "no", all prompts will be answered with no. If set to "prompt", the user will be prompted for each decision. This option is a shortcut for setting all other disposition options to their default value. If a disposition option is explicitly set, it will override this option.
--install-ignored-packages=prompt|yes|no
Set the disposition for prompts to install ignored packages.
--delete-corrupt-files=prompt|yes|no
Set the disposition for prompts to delete corrupt packages.
--use-first-provider=prompt|yes|no
Set the disposition for prompts to select a provider. If set to "yes", the first available provider will be selected.
--skip-unresolvable=prompt|yes|no
Set the disposition for prompts to skip packages with unresolvable dependencies.
--import-pgp-keys=prompt|yes|no
Set the disposition for prompts to import missing PGP keys.
--yolo
Set all prompt disposition options to their "all" or "yes" value and set --no-confirm.

NOTE: regardless of the disposition options chosen, all dependencies must still be satisfied in order for the transaction to succeed unless --nodeps is used as well.

PKGSPEC

A pkgspec is a string that can identify an individual package. Accepted formats are:

<repository>/<package>
core/pacman
local/pacman
<proto>://<path/to/package/file>
file:///var/cache/pacman/pkg/pacman-4.1.0-1-x86_64.pkg.tar.xz

EXAMPLES

Replace foo with bar
pactrans local/foo baz/bar

Or, if bar's repository is unknown:

pacinstall bar --remove foo
Install foo and bar:
pactrans --install foo bar

CAVEATS

pactrans determines whether or not to read pkgspecs from stdin based on a naive check using isatty(3). If pactrans is called in an environment, such as a shell function or script being used in a pipe, where stdin is not connected to a terminal but does not contain pkgspecs to install/remove, pactrans should be called with stdin closed. For POSIX-compatible shells, this can be done with "<&-".
