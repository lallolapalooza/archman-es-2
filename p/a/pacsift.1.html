pacsift(1)

Paquete: pacutils

Licencias: MIT

PACSIFT(1) pacsift PACSIFT(1)

NOMBRE

pacsift - consultar y filtrar paquetes

SINOPSIS

pacsift [opciones] (<campo> <término>)...
pacsift (--help|--version)

DESCRIPCIÓN

Por defecto, se devuelve la intersección de los paquetes coincidentes. Si un campo se proporciona varias veces, se utilizará la unión de las coincidencias para ese campo.

Si stdin no está conectado a una terminal, los paquetes a filtrar se leerán de stdin.

Combina con pacinfo para mostrar información breve del paquete similar a "pacman -Qs" y "pacman -Ss":

pacsift --name pacman | pacinfo --short

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbext=extensión
Establece una extensión alternativa para la base de datos de sincronización.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz del sistema alternativa. Ver pacutils-sysroot(7).
--null[=sep]
Establece un separador alternativo para los valores analizados desde stdin. Por defecto se utiliza un salto de línea "\n" como separador. Si se usa --null sin especificar sep se utilizará "NUL".
--exists
Sale con un valor distinto de cero si no se encuentran coincidencias.
--not-exists
Sale con un valor distinto de cero si se encuentran coincidencias.
--invert
Devuelve los paquetes que NO coinciden con los términos de búsqueda proporcionados.
--any
Devuelve la unión de los paquetes coincidentes en lugar de la intersección.
--exact
Coincide los valores de forma exacta.
--regex
Trata los valores de cadena como expresiones regulares extendidas insensibles a mayúsculas y minúsculas.
--help
Muestra información de uso y sale.
--version
Muestra información de la versión y sale.

Filtros

Los filtros limitan el conjunto inicial de paquetes a buscar. No se pueden utilizar si se proporcionan paquetes en stdin y no se ven afectados por --invert o --any.

--local
Busca paquetes instalados localmente. Similar a:
pacsift --repo=local | pacsift ...
--sync
Busca paquetes en las bases de datos de sincronización. Similar a:
pacsift --invert --repo=local | pacsift ...
--cache (EXPERIMENTAL)
Busca paquetes en los directorios de caché.

Campos de Cadena

Por defecto, los campos de cadena utilizarán una búsqueda de subcadena insensible a mayúsculas y minúsculas. Si se usa --exact, los campos de cadena deben coincidir exactamente con val. Si se usa "--regex", val se utilizará como una expresión regular extendida insensible a mayúsculas y minúsculas.

--repo=val
--name=val
--base=val
--description=val
--packager=val
--group=val
--owns-file=ruta
Las rutas de archivo deben coincidir con la base de datos del paquete; no se intenta resolver la ruta proporcionada. Nota: cuando se usa con --exact, se eliminará la raíz de instalación de ruta si está presente, de lo contrario se usará ruta exactamente como se proporcionó. Puede usarse con realpath o which para buscar más fácilmente el propietario de los archivos instalados: 
pacsift --local --exact --owns-file="$(which pacsift)"
--license=val
--url=val

Campos de Dependencias

Las dependencias pueden especificarse en el formato "<nombre_paquete>[<cmp><versión]". "cmp" puede ser cualquiera de los siguientes: "=", "<", "<=", ">", ">=". Si se proporciona "versión", la dependencia del paquete debe coincidir exactamente con el término de búsqueda. Si se omite "versión", solo se comparará "nombre_paquete" a menos que se use --exact. Si se usa "--exact" y no se proporciona "versión", solo se corresponderán las dependencias sin versión especificada.

Los campos de dependencias no se ven afectados por --regex.

--provides
--conflicts
--replaces
--depends
--optdepends

Campos de Tamaño

Los campos de tamaño pueden ir precedidos por cualquiera de las siguientes comparaciones: "=", "!=", "<", "<=", ">", ">=". Si no se proporciona comparación, se usará "=". El tamaño puede ir seguido de una unidad abreviada. Las unidades distinguen entre mayúsculas y minúsculas.

--size
--installed-size
--download-size

Campos de Fecha

Los campos de fecha pueden ir precedidos por cualquiera de las siguientes comparaciones: "=", "!=", "<", "<=", ">", ">=". Si no se proporciona comparación, se usará "=". Las fechas pueden proporcionarse como segundos desde la época o cualquiera de los siguientes formatos "strptime": "%Y-%m-%d", "%Y-%m-%d %H:%M", "%Y-%m-%d %H:%M:%S".

--install-date
--build-date

Find packages with either "pacman" or "alpm" in their description:
pacsift --description pacman --description alpm
Find packages with both "pacman" and "alpm" in their description:
pacsift --description pacman | pacsift --description alpm
Check if a package is installed:
pacsift --local --exists --satisfies pacman && echo "pacman is installed"

CAVEATS

pacsift determines whether or not to read packages from stdin based on a naive check using isatty(3). If pacsift is called in an environment, such as a shell function or script being used in a pipe, where stdin is not connected to a terminal but does not contain packages to filter, pacsift should be called with stdin closed. For POSIX-compatible shells, this can be done with "<&-".
