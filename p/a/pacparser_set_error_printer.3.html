Documentación de Funciones

int pacparser_init (void)

Inicializa el analizador PAC.

Devoluciones:

0 en caso de fallo y 1 en caso de éxito.

Inicializa el motor de JavaScript y realiza algunas inicializaciones básicas específicas de pacparser.

int pacparser_parse_pac_file (const char *pacfile)

Analiza el archivo PAC dado.

Parámetros:

pacfile Archivo PAC a analizar.

Devoluciones:

0 en caso de fallo y 1 en caso de éxito.

Lee el archivo PAC dado y lo evalúa en el contexto de JavaScript creado por pacparser_init.

int pacparser_parse_pac_string (const char *pacstring)

Analiza la cadena de script PAC dada.

Parámetros:

pacstring Cadena PAC a analizar.

Devoluciones:

0 en caso de fallo y 1 en caso de éxito.

Evalúa la cadena de script PAC dada en el contexto de JavaScript creado por pacparser_init.

int pacparser_parse_pac (const char *pacfile)

Analiza el archivo PAC dado.

Obsoleto

Use pacparser_parse_pac_file en su lugar.

Parámetros:

pacfile Archivo PAC a analizar.

Devoluciones:

0 en caso de fallo y 1 en caso de éxito.

Igual que pacparser_parse_pac_file. Incluido solo por compatibilidad con versiones anteriores.

char* pacparser_find_proxy (const char *url, const char *host)

Encuentra el proxy para la URL y Host dados.

Parámetros:

url URL para la que encontrar el proxy.
host Parte del host de la URL.

Devoluciones:

cadena de proxy en caso de éxito y NULL en caso de error.

Encuentra el proxy para la URL y Host dados. Esta función solo debe llamarse después de que el motor pacparser haya sido inicializado (usando pacparser_init) y el script pac haya sido analizado (usando pacparser_parse_pac_file o pacparser_parse_pac_string).

char* pacparser_just_find_proxy (const char *pacfile, const char *url, const char *host)

Encuentra el proxy para el archivo PAC, URL y Host dados.

Parámetros:

pacfile Archivo PAC a analizar.
url URL para la que encontrar el proxy.
host Parte del host de la URL.

Devoluciones:

cadena de proxy en caso de éxito y NULL en caso de error.

Esta función es un envoltorio de las funciones pacparser_init, pacparser_parse_pac_file, pacparser_find_proxy y pacparser_cleanup. Si solo desea averiguar el proxy para un conjunto dado de archivo PAC, URL y host, esta es la función a llamar. Esta función se encarga de toda la inicialización y limpieza.

void pacparser_cleanup (void)

Destruye el contexto de JavaScript. Esta función debe llamarse una vez que haya terminado de usar el motor pacparser.

void pacparser_setmyip (const char *ip)

Establece mi dirección IP.

Parámetros:

ip Dirección IP personalizada.

Establece mi dirección IP a un valor personalizado. Esta es la dirección IP devuelta por la función JavaScript myIpAddress().

void pacparser_set_error_printer (pacparser_error_printerfunc)

Establece la función de impresión de errores.

Parámetros:

func Función de impresión.

Establece la función de impresión de argumentos variables de error. Si no se establece, los mensajes se imprimen en stderr. Si los mensajes comienzan con DEBUG: o WARNING:, no son mensajes de error fatales, de lo contrario sí lo son. Puede ser llamado antes de pacparser_init().

void pacparser_enable_microsoft_extensions (void)

(Obsoleto) Habilita las extensiones IPv6 de Microsoft PAC. Obsoleto. Las extensiones IPv6 (funciones *Ex) están habilitadas por defecto ahora.

char* pacparser_version (void)

Devuelve la versión de pacparser.

Devoluciones:

cadena de versión si la versión está definida, '' en caso contrario.

La cadena de versión se determina en el momento de la compilación. Si se compila desde un paquete liberado, la versión corresponde a la última etiqueta de lanzamiento (git). Si se compila desde el repositorio, corresponde a la revisión principal del repositorio.
