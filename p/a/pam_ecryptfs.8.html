NOMBRE

pam_ecryptfs - Módulo PAM para eCryptfs

SINOPSIS

pam_ecryptfs.so [unwrap]

DESCRIPCIÓN

pam_ecryptfs es un módulo PAM que puede usar la contraseña de inicio de sesión para descifrar una contraseña de montaje ecryptfs almacenada en ~/.ecryptfs/wrapped-passphrase, y montar automáticamente un directorio criptográfico privado.

OPCIONES

unwrap
Usa la contraseña de inicio de sesión para descifrar una contraseña de montaje eCryptfs.

SERVICIOS PROPORCIONADOS POR EL MÓDULO

Se soportan los servicios auth y session.

EJEMPLOS

Para descifrar una contraseña de montaje y montar automáticamente un directorio privado al iniciar sesión, añade las siguientes líneas a

/etc/pam.d/common-auth:

        auth    required        pam_ecryptfs.so unwrap

/etc/pam.d/common-session:

        session optional        pam_ecryptfs.so unwrap
