NOMBRE

pam_getenv - obtener una variable de entorno de PAM

SINOPSIS

#include <security/pam_appl.h>

const char *pam_getenv(pam_handle_t *pamh, const char *name);

DESCRIPCIÓN

La función pam_getenv busca en la lista de entorno de PAM asociada con el manejador pamh un elemento que coincida con la cadena apuntada por name y devuelve un puntero al valor de la variable de entorno. La aplicación no tiene permitido liberar los datos.

VALORES DEVUELTOS

La función pam_getenv devuelve NULL en caso de fallo.

VER TAMBIÉN
