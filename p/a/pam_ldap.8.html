pam_ldap(8) Manual del Administrador del Sistema pam_ldap(8)

NOMBRE

pam_ldap - Módulo PAM para autenticación basada en LDAP

SINOPSIS


pam_ldap.so
[...]

DESCRIPCIÓN

Este es un módulo PAM que utiliza un servidor LDAP para verificar los derechos de acceso y credenciales del usuario.

OPCIONES

use_first_pass
Especifica que el módulo PAM debe usar la primera contraseña proporcionada en la pila de autenticación y no solicitarle al usuario una contraseña.
try_first_pass
Especifica que el módulo PAM debe usar la primera contraseña proporcionada en la pila de autenticación y si falla, solicitarle al usuario una contraseña.
nullok
Especificar esta opción permite a los usuarios iniciar sesión con una contraseña en blanco. Normalmente, los inicios de sesión sin contraseña se deniegan.
ignore_unknown_user
Especifica que el módulo PAM debe devolver PAM_IGNORE para los usuarios que no estén presentes en el directorio LDAP. Esto hace que el framework PAM ignore este módulo.
ignore_authinfo_unavail
Especifica que el módulo PAM debe devolver PAM_IGNORE si no puede contactar con el servidor LDAP. Esto hace que el framework PAM ignore este módulo.
no_warn
Especifica que los mensajes de advertencia no deben propagarse a la aplicación PAM.
use_authtok
Esto hace que el módulo PAM utilice la contraseña proporcionada anteriormente al cambiar la contraseña. El módulo no solicitará al usuario una nueva contraseña (es análogo a use_first_pass).
debug
Esta opción hace que el módulo PAM registre información de depuración en syslog(3).
minimum_uid=UID
Esta opción hace que el módulo PAM ignore al usuario si el ID de usuario es inferior al valor especificado. Esto se puede utilizar para omitir las comprobaciones de LDAP para usuarios del sistema (por ejemplo, estableciéndolo en 1000).

SERVICIOS PROPORCIONADOS POR EL MÓDULO

Todos los servicios son proporcionados por este módulo, pero actualmente los cambios de sesión no están implementados en el demonio nslcd.

ARCHIVOS

/etc/pam.conf
el archivo de configuración principal de PAM
/etc/nslcd.conf
El archivo de configuración para el demonio nslcd (ver nslcd.conf(5))

VER TAMBIÉN

pam.conf(5), nslcd(8), nslcd.conf(5)
