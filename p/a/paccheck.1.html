NOMBRE

paccheck - comprobar paquetes instalados

SINOPSIS

paccheck [opciones] [<paquete>]...
paccheck (--help|--version)

DESCRIPCIÓN

Comprueba los paquetes instalados. Se pueden especificar paquetes adicionales desde stdin. Si no se proporcionan paquetes, se comprobarán todos los paquetes instalados. Por defecto, solo se comprobarán las dependencias de los paquetes y la información básica de los archivos.

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Consulte pacutils-sysroot(7).
--null[=sep]
Establece un separador alternativo para los valores analizados desde stdin. Por defecto, se utiliza una nueva línea "\n" como separador. Si se utiliza --null sin especificar sep, se utilizará "NUL".
--list-broken
Solo imprime los nombres de los paquetes que fallan las comprobaciones seleccionadas.
--quiet
Solo muestra mensajes si se encuentra un problema.
--recursive
Realiza comprobaciones de forma recursiva también en las dependencias de los paquetes.
--depends
Comprueba que todas las dependencias de los paquetes estén satisfechas.
--opt-depends
Comprueba que todas las dependencias opcionales de los paquetes estén satisfechas.
--files
Comprueba los archivos de los paquetes contra la base de datos local.
--file-properties
Comprueba los archivos de los paquetes contra los datos MTREE.
--md5sum
Comprueba las sumas MD5 de los archivos contra los datos MTREE.
--sha256sum
Comprueba las sumas SHA256 de los archivos contra los datos MTREE.
--require-mtree
Trata los datos MTREE faltantes como un error para --db-files y/o --file-properties.
--db-files
Incluye archivos de base de datos en las comprobaciones --files y --file-properties. --files probará la existencia de los archivos desc, files y mtree (con --require-mtree) en la entrada de la base de datos del paquete. --file-properties comprobará los archivos install y changelog en la base de datos del paquete cuando sea aplicable.
--backup
Incluye archivos de copia de seguridad en las comprobaciones de modificación de archivos.
--noextract
Incluye archivos NoExtract en las comprobaciones de modificación de archivos.
--noupgrade
Incluye archivos NoUpgrade en las comprobaciones de modificación de archivos.
--help
Muestra la información de uso y sale.
--version
Muestra la información de la versión y sale.

ADVERTENCIAS

paccheck determina si debe leer paquetes de stdin basándose en una comprobación ingenua utilizando isatty(3). Si paccheck se llama en un entorno, como una función de shell o un script que se utiliza en una tubería, donde stdin no está conectado a una terminal pero no contiene paquetes para comprobar, paccheck debe ser llamado con stdin cerrado. Para shells compatibles con POSIX, esto se puede hacer con "<&-".
