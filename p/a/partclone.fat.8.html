PARTCLONE(8) Manual de usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_sistema_archivos] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_sistema_archivos] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque utilizado de la partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_sistema_archivos], muy similar a fsck o mkfs. Por ejemplo, para hacer copia de seguridad/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de Archivos        partclone.[tipo_sistema_archivos]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (Sistemas de Archivos No Soportados)  partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de tu acción. Normalmente, el origen de la copia de seguridad es un dispositivo y el origen de la restauración es un archivo de imagen.

La recepción de datos desde una tubería está soportada ÚNICAMENTE para la restauración, simplemente ignora la opción -s o usa '-' para indicar la recepción de datos desde la entrada estándar.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de tu acción. Normalmente, la salida de copia de seguridad es un archivo de imagen y la salida de restauración es un dispositivo.

El envío de datos a una tubería también está soportado ÚNICAMENTE para la copia de seguridad, simplemente ignora la opción -o o usa '-' para indicar el envío de datos a la salida estándar.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe el ARCHIVO, si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo de bucle.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, el origen y la salida son ambos dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restore_raw_file

Crea un archivo raw especial para el dispositivo de bucle.

-L ARCHIVO, --logfile ARCHIVO

Coloca una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de los errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de comprobación crc.

-F, --force

Fuerza el progreso.

-f seg, --UI-fresh seg

Establece un intervalo de segundos específico para la actualización de la interfaz.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactiva el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápida de calcular, detección básica)

2: xxHash, un algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques

-w, --skip_write_error

Continúa la restauración durante errores de escritura

--write-direct-io

Escribe datos en la partición de DESTINO sin caché

--read-direct-io

Lee datos de la partición de ORIGEN sin caché

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques

--binary-prefix

Muestra el progreso con tamaño en bits (por defecto es MB, GB...)

--prog-second

Muestra el progreso en segundos (por defecto es minuto)

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA

-T, --btfiles

Restaura el bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura el bloque como archivo para ClonezillaBT, pero solo genera el torrent.

-n, --note NOTA

Muestra un Mensaje de Nota (128 palabras).

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión

partclone.fat(8) - partclone

NAME

partclone.fat - clone, save, restore, and image partitions

SYNOPSIS

partclone.fat [ -c | -r ] [ -s source ] [ -o output ] [ -d ] [ -h ] [ -v ]

DESCRIPTION

partclone.fat is a tool that saves and restores partitions. It only saves the used blocks and it is therefore faster than dd. It can save, restore and clone.

The program partclone saves the used blocks on the partition, so it can save, restore and clone.

It can work with many filesystem, like ext2, ext3, ext4, reiserfs, xfs, nfs, FAT(32), ntfs.

OPTIONS

A summary of options is included below.

-c
Clone a partition. This is the default mode.
-r
Restore a partition.
-s source
Specify the source. Can be a partition device or an image file.
-o output
Specify the output. Can be a partition device or an image file.
-d
Display debug information.
-h
Display help message.
-v
Display version information.

If the source or output is specified as '-', partclone will use stdin or stdout.

The program partclone saves the used blocks on the partition, so it can save, restore and clone.

It can work with many filesystem, like ext2, ext3, ext4, reiserfs, xfs, nfs, FAT(32), ntfs.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
