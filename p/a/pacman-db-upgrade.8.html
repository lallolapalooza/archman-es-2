PACMAN-DB-UPGRADE(8) Manual de Pacman PACMAN-DB-UPGRADE(8)

NOMBRE

pacman-db-upgrade - actualizar la base de datos local de pacman a un formato más reciente

SINOPSIS

pacman-db-upgrade [opciones]

DESCRIPCIÓN

pacman-db-upgrade es un script que actualiza la base de datos local utilizada por pacman(8) a un formato más reciente.

Opciones

*-h, \--help*::
Mostrar el mensaje de ayuda integrado y salir.
*-V, \--version*::
Mostrar información de la versión y salir.
*-d, \--dbpath* <ruta>::
Establecer una ubicación de base de datos alternativa.
*-r, \--root* <ruta>::
Establecer una raíz de instalación alternativa.
*\--config* <ruta>::
Establecer un archivo de configuración alternativo.
*\--nocolor*::
Eliminar el color de la salida.

pacman(8)
