NOMBRE

pam_sm_chauthtok - función de servicio PAM para la gestión del token de autenticación

SINOPSIS

#include <security/pam_modules.h>

int pam_sm_chauthtok(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPCIÓN

La función pam_sm_chauthtok es la implementación del módulo de servicio de la interfaz pam_chauthtok(3).

Esta función se utiliza para (re)establecer el token de autenticación del usuario.

Las banderas válidas, que pueden combinarse lógicamente con OR con PAM_SILENT, son:

PAM_SILENT

No emita ningún mensaje.

PAM_CHANGE_EXPIRED_AUTHTOK

Este argumento indica al módulo que el token de autenticación del usuario (contraseña) solo debe cambiarse si ha expirado. Esta bandera es opcional y *debe* combinarse con una de las siguientes dos banderas. Tenga en cuenta, sin embargo, que las dos opciones siguientes son *mutuamente excluyentes*.

PAM_PRELIM_CHECK

Esto indica que los módulos están siendo sondeados sobre su estado de preparación para alterar el token de autenticación del usuario. Si el módulo requiere acceso a otro sistema a través de alguna red, debe intentar verificar que puede conectarse a este sistema al recibir esta bandera. Si un módulo no puede establecer que está listo para actualizar el token de autenticación del usuario, debe devolver PAM_TRY_AGAIN, esta información se pasará a la aplicación.

Si el valor de control sufficient se usa en la pila de contraseñas, la sección PAM_PRELIM_CHECK de los módulos que siguen ese valor de control no siempre se ejecuta.

PAM_UPDATE_AUTHTOK

Esto informa al módulo que esta es la llamada en la que debe cambiar los tokens de autorización. Si la bandera se combina lógicamente con PAM_CHANGE_EXPIRED_AUTHTOK, el token solo se cambia si realmente ha expirado.

La biblioteca PAM llama a esta función dos veces seguidas. La primera vez con PAM_PRELIM_CHECK y luego, si el módulo no devuelve PAM_TRY_AGAIN, posteriormente con PAM_UPDATE_AUTHTOK. Solo en la segunda llamada se cambia (posiblemente) el token de autorización.

VALORES DE RETORNO

PAM_AUTHTOK_ERR

El módulo no pudo obtener el nuevo token de autenticación.

PAM_AUTHTOK_RECOVERY_ERR

El módulo no pudo obtener el token de autenticación anterior.

PAM_AUTHTOK_LOCK_BUSY

No se puede cambiar el token de autenticación ya que está bloqueado actualmente.

PAM_AUTHTOK_DISABLE_AGING

El envejecimiento del token de autenticación ha sido deshabilitado.

PAM_PERM_DENIED

Permiso denegado.

PAM_TRY_AGAIN

La comprobación preliminar no tuvo éxito. Señala una salida inmediata a la aplicación deseada.

PAM_SUCCESS

El token de autenticación se actualizó correctamente.

PAM_USER_UNKNOWN

Usuario desconocido para el servicio de contraseñas.
