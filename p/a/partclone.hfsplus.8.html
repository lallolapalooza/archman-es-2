PARTCLONE(8) Manual de usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_sistema_archivos] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_sistema_archivos] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se utilizan las bibliotecas e2fslibs para leer el bloque utilizado de la partición ext2.

Los sistemas de archivos compatibles con Partclone incluyen btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS DE APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_sistema_archivos], de forma muy similar a fsck o mkfs. Por ejemplo, para respaldar/restaurar hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos                 partclone.[tipo_sistema_archivos]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (Sistema de Archivos No Soportado)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO fuente. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de su acción. Normalmente, la fuente de respaldo es un dispositivo y la fuente de restauración es un archivo de imagen.

La recepción de datos desde tuberías (pipe lines) solo se admite para la restauración; simplemente ignore la opción -s o use '-' para recibir datos de stdin.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de su acción. Normalmente, la salida de respaldo va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a tuberías también solo se admite para copias de seguridad; simplemente ignore la opción -o o use '-' para enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crear un archivo raw especial para el dispositivo loop.

-c, --clone

Guardar la partición en el formato de imagen especial.

-r, --restore

Restaurar la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia de dispositivo local a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crear un archivo de registro de dominio GNU Ddrescue desde el dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añadir X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restore_raw_file

Creando archivo raw especial para dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

poner una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continuar después de errores de lectura del disco.

-C, --no_check

No comprobar el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Usar Interfaz de Usuario de Texto Ncurses.

-I, --ignore_fschk

Ignorar la comprobación del sistema de archivos.

-i, --ignore_crc

Ignorar el error de verificación de CRC.

-F, --force

Forzar el progreso.

-f seg, --UI-fresh seg

establecer un intervalo de segundos diferente.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactivar el mensaje de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada

-aX, --checksum-mode=X

Fórmula de suma de verificación a usar para añadir detección de errores

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápida de calcular, detección básica)

2: xxHash algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribir una suma de verificación por cada X bloques

-w, --skip_write_error

Continuar la restauración en caso de errores de escritura

--write-direct-io

Escribir datos en la partición DESTINO sin caché

--read-direct-io

Leer datos desde la partición FUENTE sin caché

-B, --no_block_detail

Mostrar mensaje de progreso sin detalle de bloques

--binary-prefix

Mostrar progreso con tamaño de bits (por defecto es MB, GB...)

--prog-second

Mostrar progreso en segundos (por defecto es minuto)

-E, --offset=X

Añadir desplazamiento X (bytes) a la SALIDA

-T, --btfiles

Restaurar bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-n, --note NOTE

Mostrar Nota de Mensaje (128 palabras).

-h, --help

Mostrar resumen de opciones.

-v, --version

Mostrar ve

NOMBRE

partclone - clonar o restaurar una partición con el sistema de archivos

SINOPSIS

partclone.extfs [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.gpt [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.hfs+ [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.ntfs [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.exfat [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.mbr [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.vmfs [-c] [-r] [-s fuente] [-o destino] [-C] [-d] [-F] [-P] [-X]

partclone.wipe [-s fuente] [-d]

DESCRIPCIÓN

partclone es una utilidad de copia de seguridad y restauración de la imagen del sistema de archivos. Se basa en el código de Clonezilla. partclone se especializa en el sistema de archivos. Si sabe qué sistema de archivos está utilizando, puede obtener un mejor rendimiento y, además, puede utilizar esta herramienta para clonar el sistema de archivos de forma eficaz.

Es compatible con varios sistemas de archivos, incluyendo:

  • Ext2, Ext3, Ext4
  • NTFS
  • HFS+
  • ReiserFS
  • XFS
  • UFS
  • VMFS
  • FAT (FAT12, FAT16, FAT32, exFAT)
  • Btrfs

partclone también puede clonar la tabla de particiones MBR y GPT sin el sistema de archivos.

Utilice la opción de ayuda [-h] para ver el último número de versión del programa.

OPCIONES

Las siguientes opciones están disponibles:

-c, --clone
Clonar el sistema de archivos o la tabla de particiones.
-r, --restore
Restaurar el sistema de archivos o la tabla de particiones.
-s, --source fuente
Especificar la fuente para clonar o restaurar. Puede ser un dispositivo de bloque (por ejemplo, /dev/sda1) o un archivo de imagen.
-o, --output destino
Especificar el destino para clonar o restaurar. Puede ser un dispositivo de bloque (por ejemplo, /dev/sda1) o un archivo de imagen.
-C, --comment
Mostrar información del comentario en el archivo de imagen.
-d, --debug
Habilitar la salida de depuración.
-F, --force
Forzar la operación. Por ejemplo, para sobrescribir un archivo existente.
-P, --no_part_update
No actualizar la tabla de particiones.
-X, --no_resize
No redimensionar el sistema de archivos. Por defecto, partclone intentará redimensionar el sistema de archivos clonado al tamaño del dispositivo de destino si el sistema de archivos de origen es más pequeño.
-h, --help
Mostrar mensaje de ayuda y salir.
-V, --version
Mostrar información de la versión del programa y salir.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone

EJEMPLOS

 clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restaurar imagen desde clonezilla (dividida, comprimida con gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden emitirse en stderr:

partclone proporciona algunos códigos de retorno, que pueden utilizarse en scripts:

Código Diagnóstico
0 El programa terminó con éxito.
1 La clonación o restauración parecen haber fallado.
