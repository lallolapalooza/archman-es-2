NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[fstype] {[-c o --clone] [-r o --restore] [-b o --dev-to-dev]} {[-s o --source] fuente} {[[-o o --output] [-O o --overwrite]] destino} [[-dX o --debug=X] [--restore_raw_file] [-z o --buffer_size] [-N o --ncurses] [-q o --quiet] [-f o --UI-fresh] [-F o --force] [-I o --ignore_fschk] [-i o --ignore_crc] [-C o --nocheck] [-R o --rescue] [-L o --logfile] logfile [-R o --rescue] [-L o --logfile] logfile [-X o --compresscmd] [-D o --domain] [--offset_domain] [-aX o --checksum-mode=X] [-kX o --blocks-per-checksum=X] [-K o --no-reseed] [-w o --skip_write_error] [-E o --offset=X] [-T o --btfiles] [-t o --btfiles_torrent] [-n o --note] [-B o --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[fstype] es parte del proyecto Partclone. Partclone proporciona utilidades para respaldar bloques utilizados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, se usan e2fslibs para leer el bloque utilizado de la partición ext2.

El sistema de archivos soportado por Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (APPLE MAC OS), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[fstype], lo cual es muy similar a fsck o mkfs. Por ejemplo, para respaldar/restaurar hfsplus, simplemente ejecuta partclone.hfsp

       Sistema de Archivos                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS No Soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de la línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de tu acción. Normalmente, la fuente de respaldo es un dispositivo, y la fuente de restauración es un archivo de imagen.

La recepción de datos de una tubería solo se admite para la restauración, simplemente ignora la opción -s o usa '-' para indicar recibir datos de stdin.

-o ARCHIVO, --output ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de tu acción. Normalmente, la salida de respaldo va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a una tubería también se admite solo para copias de seguridad, simplemente ignora la opción -o o usa '-' para indicar enviar datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe ARCHIVO, si ya existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo loop.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque utilizadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Creando archivo raw especial para dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Pone una ruta especial para registrar información del registro de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de errores de lectura de disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la interfaz de usuario de texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de comprobación crc.

-F, --force

Fuerza el progreso.

-f sec, --UI-fresh sec

Establece un intervalo de segundos específico.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Deshabilita el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada.

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para agregar detección de errores.

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Cálculo rápido, detección básica)

2: xxHash algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques.

-w, --skip_write_error

Continúa la restauración durante errores de escritura.

--write-direct-io

Escribe datos en la partición de DESTINO sin caché.

--read-direct-io

Lee datos de la partición de ORIGEN sin caché.

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques.

--binary-prefix

Muestra el progreso con tamaño de bits (por defecto es MB, GB...).

--prog-second

Muestra el progreso en segundos (por defecto es minuto).

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA.

-T, --btfiles

Restaura bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura bloque como archivo para ClonezillaBT pero solo genera torrent.

-n, --note NOTE

Muestra Mensaje Nota (128 palabras).

-h, --help

Muestra el resumen de opciones.

-v, --version

Muestra la vers

NOMBRE

partclone - herramienta para clonar y restaurar un sistema de archivos.

SINOPSIS

partclone.ext2, partclone.ext3, partclone.ext4, partclone.hfs, partclone.ntfs, partclone.fat, partclone.xfs, partclone.btrfs, partclone.vmfs, partclone.udf, partclone.ufs, partclone.ffs, partclone.jfs, partclone.xfs, partclone.dfs, partclone.hfsplus, partclone.exfat, partclone.nilfs2, partclone.minix, partclone.f2fs, partclone.ubifs, partclone.logfs, partclone.cramfs, partclone.bfs, partclone.vxfs, partclone.zap, partclone.dd, partclone.restore, partclone.info

DESCRIPCIÓN

partclone es una herramienta para clonar y restaurar un sistema de archivos. Se basa en la biblioteca de clonación de particiones (partclone-lib) y soporta un gran número de sistemas de archivos.

Se enfoca en un solo sistema de archivos por ejecutable. Por ejemplo, para clonar un sistema de archivos ext3, se usa partclone.ext3. Para restaurar, se puede usar partclone.ext3 o partclone.restore.

Las características clave incluyen:

  • Clonación de bloques (similar a dd) o de archivos, que solo copia los bloques usados.
  • Soporte para compresión (gzip, bzip2, lzma, lzo, lzop, etc.).
  • Soporte para división de archivos de imagen en partes de tamaño específico.
  • Restauración de imágenes.
  • Obtención de información sobre la imagen.

OPCIONES

Las opciones comunes a la mayoría de los comandos de partclone incluyen:

-c, --clone
Modo de clonación (crear imagen). Este es el modo predeterminado si no se especifica -r.
-r, --restore
Modo de restauración (restaurar imagen a un dispositivo). Requiere especificar el archivo de imagen de origen con -s.
-s, --source <fuente>
Origen. Puede ser un dispositivo de bloque (ej. /dev/sda1) o un archivo de imagen. Use '-' para leer desde la entrada estándar (stdin).
-o, --output <destino>
Destino. Puede ser un dispositivo de bloque (ej. /dev/sda1) o un archivo de imagen. Use '-' para escribir a la salida estándar (stdout).
-d, --debug
Activa la salida de depuración detallada.
-v, --verbose
Muestra información detallada sobre el progreso y las operaciones.
-z, --compression <compresión>
Especifica el tipo de compresión a usar (ej. gzip, bzip2, lzma, lzo, lzop). Si se usa la restauración, debe coincidir con la compresión usada al crear la imagen.
-b, --blocksize <tamaño_bloque>
Establece el tamaño del bloque para la operación (en bytes).
-F, --force
Fuerza la operación, incluso si se detectan advertencias.
-N, --no_finish_in_time
No espera a que todas las operaciones se completen antes de salir.
-Q, --quiet
Suprime la salida de progreso y solo muestra errores.
-X, --no_squeeze
Desactiva la optimización para reducir el tamaño de la imagen (clonación de bloques no utilizada).
-A, --no_alloc
Desactiva la asignación de bloques no utilizados (clonación de archivos solo).
-p, --percentage <porcentaje>
Porcentaje de datos a clonar/restaurar.
-R, --nthreads <nthreads>
Número de hilos a usar para la clonación/restauración.
-G, --giga_byte <giga_byte>
Tamaño máximo de archivo en Gigabytes.
-Z, --zfile <zfile>
Nombre del archivo comprimido (si se usa compresión).
-T, --nthreads <nthreads>
Número de hilos a usar para la descompresión.
-i, --split_size <tamaño_división>
Tamaño en el que dividir el archivo de imagen (en Gigabytes).
-u, --unique_id <id_único>
ID único para la imagen (útil para el encadenamiento de imágenes).
-h, --help
Muestra el mensaje de ayuda.
-?
Muestra el mensaje de ayuda.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone

EJEMPLOS

 Clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 Restaurar imagen desde clonezilla (dividida, comprimida con gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden ser emitidos en stderr:

partclone proporciona algunos códigos de retorno, que pueden ser utilizados en scripts:

Código Diagnóstico
0 El programa salió exitosamente.
1 La clonación o restauración parecen haber fallado.
