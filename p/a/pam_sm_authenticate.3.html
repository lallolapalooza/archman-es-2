PAM_SM_AUTHENTICATE(3) Manual de Linux-PAM PAM_SM_AUTHENTICATE(3)

NOMBRE

pam_sm_authenticate - función de servicio PAM para la autenticación de usuarios

SINOPSIS

#include <security/pam_modules.h>

int pam_sm_authenticate(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPCIÓN

La función pam_sm_authenticate es la implementación del módulo de servicio de la interfaz pam_authenticate(3).

Esta función realiza la tarea de autenticar al usuario.

Las banderas válidas, que pueden combinarse lógicamente con PAM_SILENT, son:

PAM_SILENT

No emitir ningún mensaje.

PAM_DISALLOW_NULL_AUTHTOK

Devolver PAM_AUTH_ERR si la base de datos de tokens de autenticación para este mecanismo de autenticación tiene una entrada NULL para el usuario. Sin esta bandera, un token NULL de este tipo conducirá a un éxito sin que se le solicite al usuario.

VALORES DE RETORNO

PAM_AUTH_ERR

Fallo de autenticación.

PAM_CRED_INSUFFICIENT

Por alguna razón, la aplicación no tiene credenciales suficientes para autenticar al usuario.

PAM_AUTHINFO_UNAVAIL

Los módulos no pudieron acceder a la información de autenticación. Esto podría deberse a un fallo de red o de hardware, etc.

PAM_SUCCESS

El token de autenticación se actualizó con éxito.

PAM_USER_UNKNOWN

El nombre de usuario proporcionado no es conocido por el servicio de autenticación.

PAM_MAXTRIES

Uno o más de los módulos de autenticación han alcanzado su límite de intentos para autenticar al usuario. No vuelva a intentarlo.
