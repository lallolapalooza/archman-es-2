pappl-mainloop(3) Funciones del bucle principal de pappl pappl-mainloop(3)

NOMBRE

pappl-mainloop - funciones del bucle principal de pappl

BIBLIOTECA

Marco de Aplicaciones de Impresoras (libpappl, "pkg-config --cflags --libs pappl")

SINOPSIS

#include <pappl/pappl.h>

int
papplMainloop(int argc, char *argv[], const char *version, const char *footer_html, int num_drivers, pappl_driver_t *drivers, pappl_driver_cb_t driver_cb, pappl_ml_autoadd_cb_t autoadd_cb, const char *subcmd_name, pappl_ml_subcmd_cb_t subcmd_cb, pappl_ml_system_cb_t system_cb, pappl_ml_usage_cb_t usage_cb, void *data);

DESCRIPCIÓN

La función

mainloop inicia la aplicación de impresora y soporta argumentos de línea de comandos y comportamientos estándar.

FUNCIONES

papplMainloop

Ejecuta un bucle principal estándar para aplicaciones de impresoras.

int  papplMainloop (
    int argc,
    char *argv[],
    const char *version,
    const char *footer_html,
    int num_drivers,
    pappl_pr_driver_t *drivers,
    pappl_pr_autoadd_cb_t autoadd_cb,
    pappl_pr_driver_cb_t driver_cb,
    const char *subcmd_name,
    pappl_ml_subcmd_cb_t subcmd_cb,
    pappl_ml_system_cb_t system_cb,
    pappl_ml_usage_cb_t usage_cb,
    void *data
);

Esta función ejecuta un bucle principal estándar para una aplicación de impresora. Los argumentos "argc" y "argv" son los proporcionados a la función main.

El argumento "version" especifica un número de versión numérico para la aplicación de impresora que se ajusta a las directrices de versión semántica con hasta cuatro números, por ejemplo "1.2.3.4".

El argumento "footer_html" especifica texto HTML para usar en el pie de página de la interfaz web. Si es NULL, el pie de página se omite.

Los argumentos "num_drivers", "drivers" y "driver_cb" especifican una lista de controladores y la devolución de llamada del controlador para impresoras. Especifique 0 y NULL si los controladores están configurados en la devolución de llamada del sistema. El argumento "autoadd_cb" especifica una devolución de llamada para agregar automáticamente nuevas impresoras con el subcomando "autoadd" y para detectar automáticamente el controlador al agregar manualmente.

El argumento "usage_cb" especifica una devolución de llamada que muestra un resumen de uso/ayuda. Si es NULL, se muestra un resumen genérico según sea necesario.

Los argumentos "subcmd_name" y "subcmd_cb" especifican el nombre y una devolución de llamada para un subcomando personalizado. Si es NULL, no se admitirán subcomandos personalizados.

El argumento "system_cb" especifica una función que creará un nuevo objeto pappl_system_t. Si es NULL, se crea un objeto de sistema predeterminado.

El argumento "data" proporciona datos específicos de la aplicación para cada una de las devoluciones de llamada.

papplMainloopShutdown

Solicita el cierre de un sistema en ejecución.

void papplMainloopShutdown (void);

Esta función solicita que se cierre el sistema iniciado por papplMainloop.
