DESCRIPCIÓN

Las funciones de trabajo de PAPPL proporcionan acceso al objeto de trabajo. Los trabajos y el ciclo de vida de los objetos pappl_job_t son gestionados automáticamente por el objeto del sistema para la aplicación de la impresora.

Las funciones papplJobGet obtienen los valores actuales asociados con un trabajo, mientras que las funciones papplJobSet establecen los valores actuales asociados con un trabajo.

La función papplJobCancel cancela el procesamiento de un trabajo, mientras que la función papplJobIsCanceled devuelve si un trabajo está en el estado de cancelado (IPP_JSTATE_CANCELED) o está en proceso de ser cancelado (IPP_JSTATE_PROCESSING y PAPPL_JREASON_PROCESSING_TO_STOP_POINT).

La función papplJobOpenFile abre un archivo asociado con el trabajo. El descriptor de archivo debe ser cerrado por el llamador usando la llamada al sistema close(2).

La función papplJobFilterImage convierte datos de imagen en crudo a datos ráster adecuados para la impresora.

FUNCIONES

papplJobCancel

Cancelar un trabajo.

void papplJobCancel (
    pappl_job_t *job
);

Esta función cancela el trabajo especificado. Si el trabajo se está imprimiendo actualmente, se detendrá en un momento conveniente (generalmente al final de una página) para que la impresora quede en un estado conocido.

papplJobCreatePrintOptions

Crear las opciones de impresión para un trabajo.

pappl_pr_options_t * papplJobCreatePrintOptions (
    pappl_job_t *job,
    unsigned num_pages,
    bool color
);

Esta función asigna una estructura de opciones de impresora y calcula las opciones de impresión para un trabajo basándose en los atributos de la plantilla del trabajo enviados en la solicitud de impresión y los valores predeterminados establecidos en los datos del controlador de la impresora.

Los argumentos "num_pages" y "color" especifican el número de páginas y si el documento contiene colores que no sean de escala de grises; esta información normalmente proviene del análisis del archivo del trabajo.

papplJobCreateWithFile

Crear un trabajo con un archivo local.

pappl_job_t * papplJobCreateWithFile (
    pappl_printer_t *printer,
    const char *username,
    const char *format,
    const char *job_name,
    int num_options,
    cups_option_t *options,
    const char *filename
);

Esta función crea un nuevo trabajo de impresión con un archivo local. Los parámetros "num_options" y "options" especifican opciones de impresión adicionales, según sea necesario. El archivo especificado por "filename" se elimina automáticamente si reside en el directorio de spool.

papplJobDeletePrintOptions

Eliminar una estructura de opciones de trabajo.

void papplJobDeletePrintOptions (
    pappl_pr_options_t *options
);

Esta función libera la memoria utilizada por una estructura de opciones de trabajo.

papplJobFilterImage

Filtrar una imagen en memoria.

bool  papplJobFilterImage (
    pappl_job_t *job,
    pappl_device_t *device,
    pappl_pr_options_t *options,
    const unsigned char *pixels,
    int width,
    int height,
    int depth,
    int ppi,
    bool smoothing
);

Esta función imprimirá una imagen en escala de grises o sRGB utilizando la interfaz del controlador ráster de la impresora, escalando y posicionando la imagen según sea necesario basándose en las opciones del trabajo, e imprimiendo tantas copias como se soliciten.

Los datos de la imagen son una matriz de píxeles en escala de grises ("depth" = 1) o sRGB ("depth" = 3) que comienzan en la esquina superior izquierda de la imagen.

La resolución de la imagen ("ppi") se expresa en píxeles por pulgada y se utiliza para algunos modos de "print-scaling". Pase 0 si la imagen no tiene información de resolución explícita.

papplJobGetState

Obtener el estado actual del trabajo.

ipp_jstate_t  papplJobGetState (
    pappl_job_t *job
);

Esta función devuelve el estado de procesamiento actual del trabajo, que se representa como una enumeración:

  • IPP_JSTATE_ABORTED: El trabajo ha sido abortado por el sistema debido a un error.
  • IPP_JSTATE_CANCELED: El trabajo ha sido cancelado por un usuario.
  • IPP_JSTATE_COMPLETED: El trabajo ha terminado de imprimirse.
  • IPP_JSTATE_HELD: El trabajo se está reteniendo por alguna razón, típicamente porque
    se están recibiendo los datos del documento.
  • IPP_JSTATE_PENDING: El trabajo está en cola y esperando ser impreso.
  • IPP_JSTATE_PROCESSING: El trabajo se está imprimiendo.
  • IPP_JSTATE_STOPPED: El trabajo está en pausa, típicamente cuando la impresora no está
    lista.</li> </ul>

NAME

pappl-job - PAPPL job functions

LIBRARY

libkrun (libkrun.so)

SYNOPSIS

#include <pappl/pappl-job.h>

DESCRIPTION

These functions are part of the PAPPL library and provide access to job management operations.

ENUMERATIONS

The following enumerations are defined:

pappl_jreason_t
Bitfield for IPP "job-state-reasons" values. See ipp-bindings-20231009.pdf for a list of supported values.

These are typically ORed together to represent the current state of the job.

Commonly used values include:

papplJobOpenFile

Create or open a file for the document in a job.

int  papplJobOpenFile (
    pappl_job_t *job,
    char *fname,
    size_t fnamesize,
    const char *directory,
    const char *ext,
    const char *mode
);

This function creates or opens a file for a job. The "fname" and "fnamesize" arguments specify the location and size of a buffer to store the job filename, which incorporates the "directory", printer ID, job ID, job name (title), and "ext" values. The job name is "sanitized" to only contain alphanumeric characters.

The "mode" argument is "r" to read an existing job file or "w" to write a new job file. New files are created with restricted permissions for security purposes.
