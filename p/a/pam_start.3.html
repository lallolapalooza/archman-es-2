PAM_START(3) Manual de Linux-PAM PAM_START(3)

NOMBRE

pam_start, pam_start_confdir - inicialización de la transacción PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_start(const char *nombre_servicio, const char *usuario, const struct pam_conv *conversacion_pam, pam_handle_t **pamh);

int pam_start_confdir(const char *nombre_servicio, const char *usuario, const struct pam_conv *conversacion_pam, const char *dir_config, pam_handle_t **pamh);

DESCRIPCIÓN

La función pam_start crea el contexto PAM e inicia la transacción PAM. Es la primera de las funciones PAM que debe ser llamada por una aplicación. El estado de la transacción está contenido enteramente dentro de la estructura identificada por este manejador, por lo que es posible tener múltiples transacciones en paralelo. Pero no es posible usar el mismo manejador para diferentes transacciones, se necesita uno nuevo para cada contexto nuevo.

El argumento nombre_servicio especifica el nombre del servicio a aplicar y se almacenará como elemento PAM_SERVICE en el nuevo contexto. La política para el servicio se leerá del archivo /etc/pam.d/nombre_servicio o, si ese archivo no existe, de /etc/pam.conf.

El argumento usuario puede especificar el nombre del usuario de destino y se almacenará como elemento PAM_USER. Si el argumento es NULL, el módulo tiene que solicitar este elemento si es necesario.

El argumento conversacion_pam apunta a una struct pam_conv que describe la función de conversación a usar. Una aplicación debe proporcionar esto para la comunicación directa entre un módulo cargado y la aplicación.

Tras un retorno exitoso (PAM_SUCCESS), el contenido de pamh es un manejador que contiene el contexto PAM para las llamadas sucesivas a las funciones PAM. En caso de error, el contenido de pamh no está definido.

El pam_handle_t es una estructura ciega y la aplicación no debe intentar sondearla directamente en busca de información. En su lugar, la biblioteca PAM proporciona las funciones pam_set_item(3) y pam_get_item(3). El manejador PAM no puede usarse para múltiples autenticaciones al mismo tiempo mientras no se haya llamado a pam_end sobre él.

La función pam_start_confdir se comporta como la función pam_start pero también permite establecer el argumento dir_config con una ruta a un directorio para anular la ruta predeterminada (/etc/pam.d) para los archivos de política de servicio. Si dir_config es NULL, la función funciona exactamente igual que pam_start.

VALORES DE RETORNO

PAM_ABORT

Fallo general.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_SUCCESS

La transacción se inició correctamente.

PAM_SYSTEM_ERR

Error del sistema, por ejemplo, se envió un puntero NULL en lugar de un puntero a datos.

VER TAMBIÉN

pam_get_data(3), pam_set_data(3), pam_end(3), pam_strerror(3)
