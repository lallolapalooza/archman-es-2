DESCRIPCIÓN

Las funciones de recursos de PAPPL gestionan archivos de recursos, devoluciones de llamada y enlaces en la aplicación de la impresora.

FUNCIONES

papplPrinterAddLink

Añade un enlace de impresora a la cabecera de navegación.

void papplPrinterAddLink (
    pappl_printer_t *printer,
    const char *label,
    const char *path_or_url,
    pappl_loptions_t options
);

Esta función añade un enlace de navegación para una impresora. El argumento "path_or_url" especifica una ruta absoluta como "/ipp/print/example/page" o una URL absoluta como "https://www.example.com/". El argumento "options" especifica dónde se muestra el enlace y si el enlace debe redirigir una ruta absoluta a la interfaz web segura ("https://.../path").

papplPrinterRemoveLink

Elimina un enlace de impresora de la cabecera de navegación.

void papplPrinterRemoveLink (
    pappl_printer_t *printer,
    const char *label
);

Esta función elimina el enlace nombrado para la impresora.

papplSystemAddLink

Añade un enlace a la cabecera de navegación.

void papplSystemAddLink (
    pappl_system_t *system,
    const char *label,
    const char *path_or_url,
    pappl_loptions_t options
);

Esta función añade un enlace de navegación para el sistema. El argumento "path_or_url" especifica una ruta absoluta como "/page" o una URL absoluta como "https://www.example.com/". El argumento "options" especifica dónde se muestra el enlace y si el enlace debe redirigir una ruta absoluta a la interfaz web segura ("https://.../path").

papplSystemAddResourceCallback

Añade un recurso dinámico que utiliza una función de devolución de
llamada.

void papplSystemAddResourceCallback (
    pappl_system_t *system,
    const char *path,
    const char *format,
    pappl_resource_cb_t cb,
    void *data
);

Esta función añade un recurso dinámico en la ruta especificada. Cuando se recibe una solicitud GET o POST del cliente en la ruta especificada, la función "cb" será llamada con el puntero del cliente y el puntero "data" para responder a ella.

Las devoluciones de llamada de recursos se utilizan con mayor frecuencia para implementar páginas web personalizadas.

Añade un recurso de datos estático.

void papplSystemAddResourceData (
    pappl_system_t *system,
    const char *path,
    const char *format,
    const void *data,
    size_t datalen
);

Esta función añade un recurso estático en la ruta especificada. Los datos proporcionados no se copian al recurso y deben permanecer estables mientras el recurso esté añadido al sistema.

5

5

papplSystemAddResourceDirectory

Añade archivos externos en un directorio como
recursos.

void papplSystemAddResourceDirectory (
    pappl_system_t *system,
    const char *basepath,
    const char *directory
);

Esta función añade recursos estáticos del directorio especificado bajo la ruta especificada. El directorio se escanea y solo los archivos presentes en el momento de la llamada estarán disponibles, y esos archivos deben permanecer estables mientras los recursos estén añadidos al sistema.
