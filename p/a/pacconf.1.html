NOMBRE

pacconf - consultar el archivo de configuración de pacman

SINOPSIS

pacconf [opciones] [<directiva>...]
pacconf (--repo-list|--help|--version)

DESCRIPCIÓN

Consulta las opciones de configuración del archivo de configuración de pacman. Si no se proporcionan directivas, se imprimirá toda la configuración en un formato normalizado. Por defecto, si solo se proporciona una única directiva, solo se imprimirá su valor sin el nombre de la opción. Para directivas sin valor, se utilizará el nombre de la directiva como valor.

Los valores mostrados son los valores finales tal como los analizaría el propio pacman. Se establecen todos los valores predeterminados, se procesan las directivas "Include", se reemplazan las variables $arch y $repo en los servidores de repositorios, y se reemplazará "Architecture" si se establece en "auto".

OPCIONES

--config=ruta
Establece una ruta alternativa al archivo de configuración.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--arch=arch
Establece una arquitectura alternativa.
--null[=sep]
Establece un separador alternativo para los valores analizados desde stdin. Por defecto, se utiliza una nueva línea "\n" como separador. Si se usa --null sin especificar sep, se usará "NUL".
--options
Muestra solo la configuración global de la sección "[options]". El encabezado "[options]" en sí no se imprime.
--raw
Muestra valores sin modificar. Las directivas "Include" se procesarán, pero no se establecerán los valores predeterminados, las variables $arch y $repo en los servidores de repositorios no se reemplazarán, y "Architecture" no se reemplazará si se establece en "auto".
--repo=nombre
Muestra solo las directivas para el repositorio nombre. El encabezado del repositorio no se imprime.
--repo-list
Lista los repositorios configurados.
--single
Muestra solo el primer valor de las opciones multivalor.
--verbose
Muestra siempre los nombres de las directivas, incluso si solo se proporciona una directiva.
--help
Muestra la información de uso y sale.
--version
Muestra la información de la versión y sale.

EJEMPLOS

Comprobar si el color está activado:
color=$(pacconf color)
[[ -n $color ]] && ... # imprime algo en color
