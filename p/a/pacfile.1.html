NOMBRE

pacfile - muestra información sobre archivos de paquetes

SINOPSIS

pacfile [opciones] <ruta>...
pacfile (--ayuda|--versión)

DESCRIPCIÓN

Muestra información de archivos de la base de datos de paquetes local.

OPCIONES

--config=ruta
Establece una ruta alternativa para el archivo de configuración.
--dbpath=ruta
Establece una ruta alternativa para la base de datos.
--root=ruta
Establece una raíz de instalación alternativa.
--sysroot=ruta
Establece una raíz de sistema alternativa. Ver pacutils-sysroot(7).
--package=nombre_paquete
Limita la información al paquete especificado. Se puede especificar varias veces.
--check
Compara los valores de la base de datos con el sistema de archivos.
--help
Muestra la información de uso y sale.
--version
Muestra la información de la versión y sale.
