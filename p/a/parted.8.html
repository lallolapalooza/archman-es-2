PARTED(8) Manual de GNU Parted PARTED(8)

NOMBRE

parted - un programa de manipulación de particiones

SINOPSIS

parted [opciones] [dispositivo [comando [opciones...]...]]

DESCRIPCIÓN

parted es un programa para manipular particiones de disco. Soporta múltiples formatos de tabla de particiones, incluyendo MS-DOS y GPT. Es útil para crear espacio para nuevos sistemas operativos, reorganizar el uso del disco y copiar datos a discos duros nuevos.

Esta página del manual documenta parted brevemente. La documentación completa se distribuye con el paquete en formato GNU Info.

OPCIONES

-h, --help
muestra un mensaje de ayuda
-l, --list
lista el diseño de particiones en todos los dispositivos de bloque
-m, --machine
muestra salida interpretable por máquina
-j, --json
muestra salida JSON
-s, --script
nunca pide intervención del usuario
-f, --fix
responde automáticamente "fix" a las excepciones en modo script
-v, --version
muestra la versión
-a tipo-alineacion, --align tipo-alineacion
Establece la alineación para las particiones recién creadas, los tipos de alineación válidos son:
none
Usa la alineación mínima permitida por el tipo de disco.
cylinder
Alinea las particiones a cilindros.
minimal
Usa la alineación mínima dada por la información de topología del disco. Este y el valor opt usarán la información de diseño proporcionada por el disco para alinear las direcciones de la tabla de particiones lógicas a bloques físicos reales en los discos. El valor min es la alineación mínima necesaria para alinear correctamente la partición a bloques físicos, lo que evita la degradación del rendimiento.
optimal
Usa la alineación óptima dada por la información de topología del disco. Esto alinea a un múltiplo del tamaño del bloque físico de una manera que garantiza un rendimiento óptimo.

COMANDOS

[dispositivo]
El dispositivo de bloque a utilizar. Cuando no se proporciona ninguno, parted usará el primer dispositivo de bloque que encuentre.
[comando [opciones]]
Especifica el comando a ejecutar. Si no se proporciona ningún comando, parted presentará un prompt de comandos. Los comandos posibles son:
help [comando]
Imprime ayuda general, o ayuda sobre comando si se especifica.
align-check tipo partición
Comprueba si partición satisface la restricción de alineación de tipo. tipo debe ser "minimal" o "optimal".
mklabel tipo-etiqueta
Crea una nueva etiqueta de disco (tabla de particiones) de tipo-etiqueta. tipo-etiqueta debe ser uno de "aix", "amiga", "bsd", "dvh", "gpt", "loop", "mac", "msdos", "pc98", o "sun".
mkpart [tipo-part nombre tipo-fs] inicio fin
Crea una nueva partición. tipo-part solo puede especificarse con tablas de particiones msdos y dvh, debe ser uno de "primary", "logical", o "extended". nombre es requerido para las tablas de particiones GPT y tipo-fs es opcional. tipo-fs puede ser uno de "btrfs", "ext2", "ext3", "ext4", "fat16", "fat32", "hfs", "hfs+", "linux-swap", "ntfs", "reiserfs", "udf", o "xfs".
name partición nombre
Establece el nombre de partición a nombre. Esta opción solo funciona en etiquetas de disco Mac, PC98 y GPT. El nombre puede colocarse entre comillas dobles, si es necesario. Y dependiendo de la shell puede que necesite también ser envuelto en comillas simples para que la shell no elimine las comillas dobles.
print tipo-impresion
Muestra la tabla de particiones. tipo-impresion es opcional, y puede ser uno de devices, free, list, o all.
quit
Sale de parted.
rescue inicio fin
Recupera una partición perdida que estaba ubicada entre inicio y fin. Si se encuentra una partición, parted preguntará si desea crear una entrada para ella en la tabla de particiones.
resizepart partición fin
Cambia la posición de fin de partición. Ten en cuenta que esto no modifica ningún sistema de archivos presente en la partición.
rm partición
Elimina partición.
select dispositivo
Elige dispositivo como el dispositivo actual a editar. dispositivo usualmente debería ser un dispositivo de disco duro de Linux, pero puede ser una partición, un dispositivo de RAID por software, o un volumen lógico LVM si es necesario.
set partición bandera estado
Cambia el estado de la bandera en partición a estado. Las banderas soportadas son: "boot", "root", "swap", "hidden", "raid", "lvm", "lba", "legacy_boot", "irst", "msftres", "esp", "chromeos_kernel", "bls_boot", "linux-home", "no_automount", "bios_grub", y "palo". estado debe ser "on" u "off".
unit unidad
Establece unidad como la unidad a usar al mostrar ubicaciones y tamaños, y para interpretar los proporcionados por el usuario cuando no están seguidos de una unidad explícita. unidad puede ser uno de "s" (sectores), "B" (bytes), "kB", "MB", "KiB", "MiB", "GB", "GiB", "TB", "TiB", "%" (porcentaje del tamaño del dispositivo), "cyl" (cilindros), "chs" (cilindros, cabezales, sectores), o "compact" (megabytes para entrada, y una forma amigable para humanos para salida).
toggle partición bandera
Cambia el estado de bandera en partición.
type partición id o uuid
En MS-DOS, establece el tipo o ID de partición de partición a id. El id es un valor entre "0x01" y "0xff". En GPT, el tipo-uuid de partición a uuid.
disk_set bandera estado
Cambia una bandera en el disco a estado. Una bandera puede ser "on" u "off". Algunas o todas estas banderas estarán disponibles, dependiendo de qué etiqueta de disco estés usando. Las banderas soportadas son: "pmbr_boot" en GPT para habilitar la bandera de arranque en la partición MBR protectora de GPT.

OPTIONS

-flag
Insertir o eliminar la bandera flag en el disco.
--version
Mostrar información de la versión y un mensaje de copyright.
