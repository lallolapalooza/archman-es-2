NOMBRE

pam_stress - El módulo PAM para pruebas de estrés

SINOPSIS

pam_stress.so [debug] [no_warn] [use_first_pass] [try_first_pass] [rootok] [expired] [fail_1] [fail_2] [prelim] [required]

DESCRIPCIÓN

El módulo PAM pam_stress está destinado principalmente a dar la impresión de fallar como lo haría un módulo completamente funcional.

OPCIONES

debug

Escribe mucha información en syslog. *NOTA* esta opción escribe contraseñas en syslog, así que no uses nada sensible al hacer pruebas.

no_warn

No emite advertencias sobre cosas (de lo contrario, las advertencias se emiten a través de la función de conversación).

use_first_pass

No solicitar contraseña, para la función pam_sm_authentication simplemente usa el elemento PAM_AUTHTOK.

try_first_pass

No solicitar contraseña a menos que no haya un token de autenticación previo (el elemento PAM_AUTHTOK es NULL).

rootok

Esto está destinado a la función pam_sm_chauthtok e instruye a esta función para permitir que root cambie la contraseña del usuario sin ingresar la contraseña anterior.

expired

Un argumento destinado a las partes del módulo account y chauthtok. Instruye al módulo para que actúe como si la contraseña del usuario hubiera expirado.

fail_1

Esto instruye al módulo para que falle en su primera función.

fail_2

Esto instruye al módulo para que falle en su segunda función (si la hay).

prelim

Para pam_sm_chauthtok, significa fallar en PAM_PRELIM_CHECK.

required

Para pam_sm_chauthtok, significa fallar si el usuario no ha sido autenticado previamente por este módulo. (Ver cadena de datos stress_new_pwd en NOTAS).

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulo (auth, account, password y session).

VALORES DE RETORNO

PAM_BUF_ERR

Error de búfer de memoria.

PAM_PERM_DENIED

Permiso denegado.

PAM_AUTH_ERR

Se denegó el acceso al sistema.

PAM_CONV_ERR

Fallo de conversación.

PAM_SUCCESS

La función supera todas las comprobaciones.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

PAM_CRED_ERR

Fallo relacionado con las credenciales del usuario.

PAM_NEW_AUTHTOK_REQD

El token de autenticación ya no es válido; se requiere uno nuevo.

PAM_SESSION_ERR

Fallo de sesión.

PAM_TRY_AGAIN

Fallo en la comprobación preliminar por parte del servicio.

PAM_AUTHTOK_LOCK_BUSY

Bloqueo del token de autenticación ocupado.

PAM_AUTHTOK_ERR

Error de manipulación del token de autenticación.

PAM_SYSTEM_ERR

Error del sistema.

NOTAS

Este módulo utiliza la cadena de datos stress_new_pwd que le indica a pam_sm_chauthtok que pam_sm_acct_mgmt indica que necesitamos una nueva contraseña. El único valor posible para esta cadena de datos es 'yes'.

EJEMPLOS

#%PAM-1.0
#
# Cualquiera de los siguientes será suficiente
account  required pam_stress.so
auth     required pam_stress.so
password required pam_stress.so
session  required pam_stress.so

VER TAMBIÉN

pam.conf(5), pam.d(5), pam(8).
