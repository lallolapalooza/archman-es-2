pas2jni(1) Herramienta de generación de interfaz nativa Java de Free Pascal pas2jni(1)

NOMBRE

pas2jni - Herramienta de generación de interfaz nativa Java de Free Pascal

SINOPSIS

pas2jni [opciones] <unidad> [<unidad2> <unidad3> ...]

Genera una descripción de interfaz nativa Java y una biblioteca a partir de unidades compiladas de Free Pascal. pas2jni genera 2 archivos por unidad: una biblioteca que proporciona acceso a las funciones y procedimientos de la unidad pascal de una manera que Java entienda, y un archivo .java que describe la biblioteca y puede ser utilizado para acceder a ella desde Java.

OPCIONES

-U<ruta>
Ruta de búsqueda de unidades, separada por punto y coma. Se permiten comodines.
-L<nombre>
Establece el nombre de la biblioteca de salida. Por defecto, es el nombre de la unidad seguido de 'jni'.
-P<nombre>
Establece el nombre del paquete Java. Por defecto, es 'pas'.
-O<ruta>
Establece la ruta de salida para los archivos Pascal. Por defecto, es el directorio actual.
-J<ruta>
Establece la ruta de salida para los archivos Java. Por defecto, es 'pas'.
-D<prog>
Establece la ruta completa del programa "ppudump". El programa ppudump es necesario para analizar el contenido de los archivos de unidad.
-I<lista>
Incluye la lista de objetos especificados en la salida. La lista está separada por punto y coma. Para leer esta lista desde un archivo, usa -I@<archivo>
-E <lista>
Excluye la lista de objetos especificados de la salida. La lista está separada por punto y coma. Para leer esta lista desde un archivo, usa -E@<archivo>
-?
Muestra un mensaje de ayuda.

EJEMPLOS

Lo siguiente creará un archivo pas/getopts.java y una unidad de archivo de biblioteca getoptsjni.pas a partir de la unidad estándar getopts:

pas2jni units/x86_64-linux/getopts.ppu

Lo siguiente creará un archivo getopts.java y una unidad de archivo de biblioteca pasgetopts.pas a partir de la unidad estándar getopts:

pas2jni -J. -O. -Lpasgetopts -units/x86_64-linux/getopts.ppu
