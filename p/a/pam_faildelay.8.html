NOMBRE

pam_faildelay - Cambia el retraso en caso de fallo por aplicación

SINOPSIS

pam_faildelay.so [debug] [delay=microsegundos]

DESCRIPCIÓN

pam_faildelay es un módulo PAM que se puede utilizar para establecer el retraso en caso de fallo por aplicación.

Si no se proporciona ningún delay, pam_faildelay usará el valor de FAIL_DELAY de /etc/login.defs.

OPCIONES

debug

Activa los mensajes de depuración enviados a syslog.

delay=N

Establece el retraso en caso de fallo a N microsegundos.

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo auth.

VALORES DE RETORNO

PAM_IGNORE

El retraso se ajustó correctamente.

PAM_SYSTEM_ERR

El retraso especificado no era válido.

EJEMPLOS

El siguiente ejemplo establecerá el retraso en caso de fallo a 10 segundos:

auth  optional  pam_faildelay.so  delay=10000000

VER TAMBIÉN

pam_fail_delay(3), pam.conf(5), pam.d(5), pam(8)
