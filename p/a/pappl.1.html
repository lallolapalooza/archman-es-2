NOMBRE

pappl - framework de aplicaciones de impresión

BIBLIOTECA

Framework de Aplicaciones de Impresión (libpappl, "pkg-config --cflags --libs pappl")

SINAPSIS

#include <pappl/pappl.h>

DESCRIPCIÓN

PAPPL es un framework/biblioteca simple basado en C para desarrollar Aplicaciones de Impresión CUPS, que son el reemplazo recomendado para los controladores de impresión. Es lo suficientemente general como para soportar cualquier tipo de impresora o controlador que pueda usarse en escritorios, servidores y entornos integrados.

PAPPL integra un servidor HTTP / IPP Everywhere™ multihilo y proporciona devoluciones de llamada para una variedad de eventos que permiten a una aplicación gráfica o de línea de comandos interactuar tanto con el usuario local que ejecuta la Aplicación de Impresión como con cualquier cliente de red que envíe trabajos de impresión, consulte el estado y las capacidades de la impresora, etc.

PAPPL proporciona una interfaz de controlador simple para la impresión de gráficos rasterizados, y los desarrolladores de controladores CUPS Raster se adaptarán fácilmente a ella. PAPPL también se puede usar con impresoras que admiten la impresión de gráficos vectoriales, aunque tendrá que desarrollar más código para admitirlos. Los controladores proporcionan información de configuración y capacidad a PAPPL, y PAPPL luego llama al controlador para imprimir según sea necesario. PAPPL admite automáticamente la impresión de archivos JPEG, PNG, PWG Raster, Apple Raster y "raw" a impresoras conectadas a través de conexiones USB y de red (AppSocket/JetDirect). Otros formatos se pueden admitir a través de devoluciones de llamada de "filtro" que usted registre.
