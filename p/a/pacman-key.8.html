PACMAN-KEY(8) Manual de Pacman PACMAN-KEY(8)

NOMBRE

pacman-key - gestiona la lista de claves de confianza de pacman

SINOPSIS

pacman-key [opciones] operación [objetivos]

DESCRIPCIÓN

pacman-key es un script de envoltorio para GnuPG utilizado para gestionar el llavero de pacman, que es la colección de claves PGP utilizadas para verificar paquetes y bases de datos firmados. Proporciona la capacidad de importar y exportar claves, obtener claves de servidores de claves y actualizar la base de datos de confianza de claves.

Una gestión más compleja del llavero se puede lograr utilizando GnuPG directamente combinado con la opción --homedir apuntando al llavero de pacman (ubicado en /etc/pacman.d/gnupg por defecto).

Invocar pacman-key consiste en proporcionar una operación con cualquier opción y objetivo potencial para operar. Dependiendo de la operación, un objetivo puede ser un identificador de clave válido, un nombre de archivo o un directorio.

OPERACIONES

-a, --add

Añade la(s) clave(s) contenida(s) en el archivo o archivos especificados al llavero de pacman. Si una clave ya existe, la actualiza.

-d, --delete

Elimina la(s) clave(s) identificada(s) por el(los) identificador(es) de clave especificado(s) del llavero de pacman.

-e, --export

Exporta la(s) clave(s) identificada(s) por el(los) identificador(es) de clave especificado(s) a stdout. Si no se especifica ningún identificador de clave, se exportarán todas las claves.

--edit-key

Presenta un menú para tareas de gestión de claves en el(los) identificador(es) de clave especificado(s). Útil para ajustar el nivel de confianza de una clave.

-f, --finger

Lista una huella digital para cada identificador de clave especificado, o para todas las claves conocidas si no se especifican identificadores de clave.

-h, --help

Muestra la sintaxis y las opciones de la línea de comandos.

--import

Importa claves de pubring.gpg al llavero público desde los directorios especificados.

--import-trustdb

Importa valores de confianza del propietario desde trustdb.gpg a la base de datos de confianza compartida desde los directorios especificados.

--init

Asegura que el llavero esté inicializado correctamente y tenga los permisos de acceso requeridos.

-l, --list-keys

Lista todas las claves o claves especificadas del llavero público.

--list-sigs

Igual que --list-keys, pero también se listan las firmas.

--lsign-key

Firma localmente la clave dada. Esto se usa principalmente para enraizar la red de confianza en la clave privada local generada por --init.

--nocolor

Deshabilita la salida a color de pacman-key.

-r, --recv-keys

Equivalente a --recv-keys en GnuPG.

--refresh-keys

Equivalente a --refresh-keys en GnuPG.

--populate

Recarga las claves predeterminadas de los llaveros (opcionalmente proporcionados) en /usr/share/pacman/keyrings. Para más información, ver Proporcionar un Llavero para Importar más abajo.

-u, --updatedb

Equivalente a --check-trustdb en GnuPG. Esta operación puede especificarse con otras operaciones.

-V, --version

Muestra la versión del programa.

-v, --verify

Supone que el primer argumento es una firma y la verifica. Si se proporciona un segundo argumento, es el archivo que se va a verificar.

Con solo un argumento, se asume que la firma es una firma separada, y se busca un archivo de datos coincidente para verificar eliminando la extensión del archivo. Si no se encuentra ningún archivo de datos coincidente, se recurre a la semántica de GnuPG y se intenta verificar un archivo con una firma incrustada.

OPCIONES

--config <archivo>

Utiliza un archivo de configuración alternativo en lugar del predeterminado /etc/pacman.conf.

--gpgdir <directorio>

Establece un directorio de inicio alternativo para GnuPG. Si no se especifica, el valor se lee de /etc/pacman.conf.

--keyserver <servidor-de-claves>

Utiliza el servidor de claves especificado si la operación requiere uno. Esto tendrá prioridad sobre cualquier opción de servidor de claves especificada en un archivo de configuración gpg.conf. Ejecutar --init con esta opción establecerá el servidor de claves predeterminado si aún no estaba configurado.

PROPORCIONAR UN LLAVERO PARA IMPORTAR

Una distribución u otro repositorio proporcionado puede querer proporcionar un conjunto de claves PGP utilizadas en la firma de sus paquetes y bases de datos de repositorio que puedan importarse fácilmente en el llavero de pacman. Esto se logra proporcionando un archivo de llavero PGP foo.gpg que contenga las claves para el llavero foo en el directorio /usr/share/pacman/keyrings.

Opcionalmente, se puede proporcionar el archivo foo-trusted que contiene una lista de identificadores de clave de confianza para ese llavero. Este es un archivo en un formato compatible con la salida de gpg --export-ownertrust. Este archivo informará al usuario qué claves necesita un usuario verificar y firmar para construir una red de confianza local, además de asignar valores de confianza del propietario proporcionados.

También opcionalmente, se puede proporcionar el archivo foo-revoked que contiene una lista de identificadores de clave revocados para ese llavero. Revocado se define como "ya no válido para ninguna firma", por lo que debe usarse con prudencia. Una clave marcada como revocada se deshabilitará en el llavero y ya no se tratará como válida, por lo que esto siempre tiene prioridad sobre su estado de confianza en cualquier otro llavero.

VER TAMBIÉN

pacman-key(8)

NOMBRE

pacman-key - utilidad de gestión de claves para pacman

SINOPSIS

pacman-key --init

pacman-key --populate [arch|... ]

pacman-key --add [clave ...]

pacman-key --list-keys [clave ...]

pacman-key --list-sigs [clave ...]

pacman-key --lsign-key [clave ...]

pacman-key --recv-keys [clave ...]

pacman-key --refresh-keys [clave ...]

pacman-key --edit-key [clave ...]

pacman-key --verify [archivo ...]

pacman-key --delete-key [clave ...]

pacman-key --delete-secret-key [clave ...]

pacman-key --export [clave ...]

pacman-key --export-secret-keys [clave ...]

pacman-key --import [archivo]

pacman-key --import-cert [archivo]

pacman-key --fingerprint [clave ...]

pacman-key --generate-key [opciones] [nombre_de_usuario]

pacman-key --edit-key --expert [clave ...]

pacman-key --sign-key [clave ...]

pacman-key --gen-key

pacman-key --sign-key --local-user [ID] [clave]

pacman-key --default-key [clave]

pacman-key --edit-key --gpg-options [opciones] [clave]

pacman-key --delete-key --keyring [ruta] [clave]

pacman-key --import --keyring [ruta] [archivo]

pacman-key --verify --keyring [ruta] [archivo]

pacman-key --recv-keys --keyserver [servidor] [clave ...]

pacman-key --refresh-keys --keyserver [servidor] [clave ...]

DESCRIPCIÓN

pacman-key es una utilidad para gestionar claves GnuPG usadas por pacman para verificar la integridad de los paquetes. Soporta la creación de un nuevo anillo de claves, la importación y exportación de claves, la firma de claves, la obtención de claves de servidores de claves y la verificación de archivos firmados.

OPERACIONES

--init
Inicializa un nuevo y vacío anillo de claves de usuario. Esto creará el archivo /etc/pacman.d/gnupg/pubring.kbx. Si ya existe un anillo de claves, esta operación fallará a menos que se use la opción --force.
--populate [arch|... ]
Rellena el anillo de claves con claves predeterminadas de los repositorios de Arch Linux. Si se especifica un argumento, solo se rellenarán las claves de ese repositorio (por ejemplo, --populate arch).
--add [clave ...]
Añade claves GPG públicas o secretas a tu anillo de claves. Las claves pueden especificarse como rutas a archivos o como IDs de clave hexadecimales.
--list-keys [clave ...]
Lista las claves públicas en tu anillo de claves. Si se proporcionan IDs de clave, solo se mostrarán las claves que coincidan.
--list-sigs [clave ...]
Lista las firmas de las claves públicas en tu anillo de claves. Si se proporcionan IDs de clave, solo se mostrarán las firmas de las claves que coincidan.
--lsign-key [clave ...]
Firma localmente la clave especificada. Esto es útil para firmar claves de otros usuarios en tu anillo de claves, indicando que confías en ellas.
--recv-keys [clave ...]
Recibe claves GPG públicas desde un servidor de claves. Si no se especifican IDs de clave, se intentarán descargar todas las claves que faltan en el anillo de claves local.
--refresh-keys [clave ...]
Actualiza las claves GPG públicas en tu anillo de claves desde un servidor de claves. Si no se especifican IDs de clave, se intentarán actualizar todas las claves del anillo de claves local.
--edit-key [clave ...]
Abre el menú de edición para la clave especificada. Permite modificar los atributos de la clave, añadir o eliminar firmas, etc.
--verify [archivo ...]
Verifica la firma de un archivo usando las claves públicas disponibles en tu anillo de claves.
--delete-key [clave ...]
Elimina una clave pública de tu anillo de claves.
--delete-secret-key [clave ...]
Elimina una clave secreta de tu anillo de claves.
--export [clave ...]
Exporta claves públicas de tu anillo de claves a la salida estándar. Si no se especifican IDs de clave, se exportarán todas las claves públicas.
--export-secret-keys [clave ...]
Exporta claves secretas de tu anillo de claves a la salida estándar. Si no se especifican IDs de clave, se exportarán todas las claves secretas.
--import [archivo]
Importa claves GPG públicas o secretas desde un archivo. Si no se especifica un archivo, se leerá de la entrada estándar.
--import-cert [archivo]
Importa un certificado de clave pública GPG desde un archivo.
--fingerprint [clave ...]
Muestra la huella digital de las claves especificadas. Si no se proporcionan IDs de clave, se mostrarán las huellas digitales de todas las claves del anillo de claves.
--generate-key [opciones] [nombre_de_usuario]
Genera una nueva clave GPG pública y secreta para el usuario especificado. Las opciones pueden incluir el tipo de clave, el tamaño de bits, la fecha de caducidad, etc.
--sign-key [clave ...]
Firma la clave especificada con tu clave secreta. Esto se usa típicamente para firmar las claves de otros usuarios en un entorno de confianza distribuida.
--default-key [clave]
Establece la clave predeterminada que se utilizará para firmar claves. Si no se especifica una clave, se intentará usar la clave predeterminada de GPG.

OPCIONES

--force
Fuerza la operación, incluso si ya existe un anillo de claves o si hay otros conflictos.
--keyring [ruta]
Especifica una ruta alternativa para el anillo de claves. Por defecto, se utiliza /etc/pacman.d/gnupg/pubring.kbx.
--keyserver [servidor]
Especifica el servidor de claves a utilizar para recibir o actualizar claves. Por defecto, se utiliza keys.openpgp.org.
--gpg-options [opciones]
Pasa opciones adicionales directamente a la utilidad gpg.
--expert
Habilita el modo experto para operaciones como la edición de claves, proporcionando más control.
--local-user [ID]
Especifica el ID de usuario local a utilizar para firmar claves. Útil cuando se tienen varias claves secretas.

PROPORCIONAR UN ANILLO DE CLAVES PARA IMPORTACIÓN

Si necesitas importar un anillo de claves completo (que contenga claves públicas y secretas), puedes usar la opción --import seguida de la ruta al archivo del anillo de claves. Asegúrate de que el archivo esté en el formato correcto de GPG.
