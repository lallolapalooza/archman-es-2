parent(3perl) Guía de referencia para programadores de Perl parent(3perl)

NOMBRE

parent - Establecer una relación ISA con clases base en tiempo de compilación

SINOPSIS

package Baz;
use parent qw(Foo Bar);

DESCRIPCIÓN

Permite cargar uno o más módulos, al mismo tiempo que se configura la herencia de esos módulos. Mayormente similar en efecto a

package Baz;
BEGIN {
    require Foo;
    require Bar;
    push @ISA, qw(Foo Bar);
}

Por defecto, cada clase base necesita vivir en su propio archivo. Si desea tener una subclase y su clase padre en el mismo archivo, puede indicarle a "parent" que no cargue ningún módulo usando el modificador "-norequire":

package Foo;
sub exclaim { "I CAN HAS PERL" }
package DoesNotLoadFooBar;
use parent -norequire, 'Foo', 'Bar';
# no buscará Foo.pm o Bar.pm

Esto es equivalente al siguiente código:

package Foo;
sub exclaim { "I CAN HAS PERL" }
package DoesNotLoadFooBar;
push @DoesNotLoadFooBar::ISA, 'Foo', 'Bar';

Esto también es útil para el caso en que un paquete vive en un archivo con un nombre diferente:

package MyHash;
use Tie::Hash;
use parent -norequire, 'Tie::StdHash';

Esto es equivalente al siguiente código:

package MyHash;
require Tie::Hash;
push @ISA, 'Tie::StdHash';

Si desea cargar una subclase de un archivo que "require" no consideraría un nombre de archivo elegible (es decir, no termina en ".pm" o ".pmc"), use el siguiente código:

package MySecondPlugin;
require './plugins/custom.plugin'; # contiene Plugin::Custom
use parent -norequire, 'Plugin::Custom';

Este módulo se bifurcó de "base" para eliminar el código superfluo que se había acumulado en él.
