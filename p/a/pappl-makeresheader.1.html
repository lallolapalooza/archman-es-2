NOMBRE

pappl-makeresheader - utilidad de encabezado de recursos

SINOPSIS

pappl-makeresheader ARCHIVOS > NOMBRE_ARCHIVO.h

DESCRIPCIÓN

pappl-makeresheader crea un archivo de encabezado C adecuado para incluirlo en una aplicación de impresora. El archivo de encabezado crea una matriz de caracteres sin signo C o una constante de cadena que puede usarse con las funciones papplSystemAddResourceData o papplSystemAddResourceString, o como datos para un ícono de impresora en la estructura pappl_icon_t. Los nombres de variables C utilizados para cada archivo se generan reemplazando todos los espacios, puntos y guiones con el guion bajo. Por ejemplo, un archivo llamado "mi ícono de impresora.png" tendría el nombre de variable C "mi_icono_de_impresora_png".
