NOMBRE

pam_get_items - Un módulo de prueba PAM para recuperar elementos específicos del módulo PAM

SINOPSIS

pam_get_items.so

DESCRIPCIÓN

Los módulos PAM almacenan datos en elementos PAM. Estos elementos solo son accesibles desde el contexto del módulo, no desde el contexto de la aplicación, ya que podrían incluir datos privados (PAM_AUTHTOK normalmente contiene la contraseña). Pero al probar módulos PAM, a menudo es útil asegurarse de que un módulo PAM bajo prueba establece los elementos para el siguiente módulo de la manera correcta. El módulo pam_get_items hace esto posible exportando todos los elementos PAM como variables de entorno usando pam_putenv. El nombre de la variable de entorno es el mismo que el nombre constante del elemento PAM.

OPCIONES

Ninguna

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulos (account, auth, password y session).

EJEMPLO

Considere un ejemplo que prueba que pam_unix coloca la contraseña que lee en la pila PAM. El archivo de servicio de prueba contendría:

auth required        pam_unix.so
auth required        pam_get_items.so

Luego, la prueba ejecutaría la conversación PAM y después llamaría:

pam_getenv(pamh, "PAM_AUTHTOK");

Para recuperar la contraseña.
