PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_sistema_archivos] {[-c | --clonar] [-r | --restaurar] [-b | --dev-a-dev]} {[-s | --fuente] fuente} {[[-o | --salida] [-O | --sobrescribir]] destino} [[-dX | --debug=X] [--restaurar_archivo_crudo] [-z | --tamaño_buffer] [-N | --ncurses] [-q | --silencioso] [-f | --UI-actualizar] [-F | --forzar] [-I | --ignorar_fsck] [-i | --ignorar_crc] [-C | --sin_comprobacion] [-R | --rescatar] [-L | --archivo_log] archivo_log [-R | --rescatar] [-L | --archivo_log] archivo_log [-X | --comando_compresion] [-D | --dominio] [--dominio_desplazamiento] [-aX | --modo_suma_verificacion=X] [-kX | --bloques_por_suma_verificacion=X] [-K | --sin_resembrar] [-w | --ignorar_errores_escritura] [-E | --desplazamiento=X] [-T | --archivos_bt] [-t | --torrent_archivos_bt] [-n | --nota] [-B | --sin_detalle_bloques] [--prefijo_binario] [--segundo_progreso] [--escritura_directa_io] [--lectura_directa_io]]

DESCRIPCIÓN

partclone.[tipo_sistema_archivos] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque usado de la partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También es compatible con algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_sistema_archivos], lo que es muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restauración de hfsplus, simplemente ejecute partclone.hfsp

       Sistema de Archivos           partclone.[tipo_sistema_archivos]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (Sistemas de Archivos No Soportados)   partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --fuente ARCHIVO

ARCHIVO de origen. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo según tu acción. Normalmente, el origen de la copia de seguridad es un dispositivo, el origen de la restauración es un archivo de imagen.

La recepción de datos de una tubería solo se admite para la restauración, ignora la opción -s o usa '-' para recibir datos de stdin.

-o ARCHIVO, --salida ARCHIVO

ARCHIVO de salida. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo según tu acción. Normalmente, la salida de la copia de seguridad es a un archivo de imagen y la salida de la restauración es a un dispositivo.

El envío de datos a una tubería también es compatible SOLO para la copia de seguridad, ignora la opción -o o usa '-' para enviar datos a stdout.

-O ARCHIVO, --sobrescribir ARCHIVO

Sobrescribir ARCHIVO, sobrescribiendo si existe.

-W ARCHIVO, --restaurar_archivo_crudo ARCHIVO

Crear un archivo crudo especial para el dispositivo loop.

-c, --clonar

Guardar la partición en el formato de imagen especial.

-r, --restaurar

Restaurar la partición desde el formato de imagen especial.

-b, --dev-a-dev

Copia de dispositivo local a dispositivo sobre la marcha, el origen y la salida son ambos dispositivos.

-D, --dominio

Crear un archivo de registro de dominio de GNU Ddrescue a partir del dispositivo de origen. Este es un archivo legible por humanos en el que + marca las áreas de bloque usadas y ? marca las áreas libres.

--dominio_desplazamiento=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio

--restaurar_archivo_crudo

Crear un archivo crudo especial para el dispositivo loop.

-L ARCHIVO, --archivo_log ARCHIVO

Especificar una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescatar

Continuar después de errores de lectura en el disco.

-C, --sin_comprobacion

No comprobar el tamaño del dispositivo y el espacio libre.

-N, --ncurses

Usar la Interfaz de Usuario de Texto Ncurses.

-I, --ignorar_fsck

Ignorar la comprobación del sistema de archivos.

-i, --ignorar_crc

Ignorar el error de comprobación crc.

-F, --forzar

Forzar el progreso.

-f seg, --UI-actualizar seg

Especificar segundos para diferentes intervalos.

-z tamaño, --tamaño_buffer tamaño

Tamaño del buffer de lectura/escritura (por defecto: 1048576)

-q, --silencioso

Desactivar mensajes de progreso.

-dnivel, --debug nivel

Establecer el nivel de depuración [1|2|3]

-x, --comando_compresion CMD

Iniciar CMD como una tubería de salida para comprimir la imagen clonada

-aX, --modo_suma_verificacion=X

Fórmula de suma de verificación a utilizar para añadir detección de errores

donde X:

0: Sin suma de verificación (sin ralentización, imagen más pequeña)

1: CRC32 (Rápido de calcular, detección básica)

2: xxHash algoritmo de hash no criptográfico extremadamente rápido

-kX, --bloques_por_suma_verificacion=X

Escribir una suma de verificación por cada X bloques

-w, --ignorar_errores_escritura

Continuar la restauración durante errores de escritura

--escritura_directa_io

Escribir datos en la partición DESTINO sin caché

--lectura_directa_io

Leer datos de la partición ORIGEN sin caché

-B, --sin_detalle_bloques

Mostrar mensaje de progreso sin detalle de bloques

--prefijo_binario

Mostrar progreso con tamaño de bits (por defecto es MB, GB...)

--segundo_progreso

Mostrar progreso en segundos (por defecto es minuto)

-E, --desplazamiento=X

Añadir desplazamiento X (bytes) a la SALIDA

-T, --archivos_bt

Restaurar bloque como archivo para ClonezillaBT.

-t, --torrent_archivos_bt

Restaurar bloque como archivo para ClonezillaBT pero solo generar torrent.

-n, --nota NOTA

Mostrar Mensaje Nota (128 palabras).

-h, --ayuda

Mostrar resumen de opciones.

-v, --version

Mostrar versión

partclone.ext3(8) — Arch Linux manual pages

NAME

partclone.ext3

backup and restore ext3 file system

SYNOPSIS

partclone.ext3 [-d] [-c] [-i] [-l] [-q] [-s source] [-o output]

partclone.ext3 [-d] [-r] [-i] [-l] [-q] [-s source] [-o output]

DESCRIPTION

partclone is a tool that allows you to backup and restore a used block device. It was inspired by partimage and clonezilla. This program is an ext3 file system specific program. The generic program is called partclone.

partclone saves the used blocks of a partition to an image file. It can also restore an image file to a partition. It supports many file systems, such as ext2, ext3, reiserfs, reiser4, btrfs, xfs, ntfs, fat32, etc.

partclone saves the file system to the image file, not the entire partition. If the partition is not full, the image file will be smaller than the partition. It will save the file system's metadata, like inode, superblock, etc.

partclone supports cloning to a partition directly, and supports resuming an interrupted clone or restore.

The specific file system program, such as partclone.ext3, will only perform operations on the ext3 file system.

OPTIONS

The following options are supported by partclone.ext3.

-c, --clone

Clone a partition to an image file. This is the default mode if neither -c nor -r is specified.

-r, --restore

Restore an image file to a partition.

-s, --source source

The source of the clone or restore. It can be a device file (e.g. /dev/hda1) or an image file.

Use '-' to specify stdin for restoring an image. Use '-' for cloning to stdout.

-o, --output output

The destination of the clone or restore. It can be a device file (e.g. /dev/hda1) or an image file.

Use '-' to specify stdout for cloning. Use '-' for restoring to stdin.

-d, --debug

Turn on debug messages. This will print more information about the program execution.

-i, --ignore

Ignore errors during clone/restore.

-l, --list_files

List files in the image file.

-q, --quiet

Quiet mode. Suppress progress information.

--force-small

Force program to write a small image file. This will make the image file smaller, but it may cause errors if the image file is smaller than the original file system.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
