PANGO-VIEW(1) Comandos Pango PANGO-VIEW(1)

NOMBRE

pango-view - visor de texto Pango

SINOPSIS

pango-view [OPCIONES...] ARCHIVO

DESCRIPCIÓN

pango-view formatea texto usando Pango, con opciones para ejercitar la mayoría de las características de diseño de Pango.

OPCIONES DE AYUDA

-h, --help

Muestra las opciones de ayuda.

--help-all

Muestra todas las opciones de ayuda.

--help-cairo

Muestra la ayuda para las opciones entendidas por el backend de cairo.

--version

Imprime la versión del comando y sale.

OPCIONES DEL BACKEND CAIRO

--annotate=FLAGS

Anota la salida. Lista separada por comas de gravedad, progresión, líneas base, diseño, línea, ejecución, clúster, carácter, glifo, cursor, pendiente.

OPCIONES DE APLICACIÓN

--no-auto-dir

Sin dirección de diseño según el contenido.

--backend=cairo/xft/ft2

Backend de Pango a usar para renderizar (por defecto: cairo).

--background=red/#rrggbb/#rrggbbaa/transparent

Establece el color de fondo.

-q, --no-display

No mostrar (solo escribir en archivo o lo que sea).

--dpi=número

Establece la resolución.

--align=left/center/right

Establece la alineación del texto.

--ellipsize=start/middle/end

Establece el modo de elipsis.

--font=description

Establece la descripción de la fuente.

--foreground=red/#rrggbb/#rrggbbaa

Establece el color del texto.

--gravity=south/east/north/west/auto

Establece la gravedad base: rotación de glifos.

--gravity-hint=natural/strong/line

Establece la pista de gravedad.

--header

Muestra las opciones en la salida.

--height=+points/-numlines

Establece la altura en puntos (positivo) o número de líneas (negativo) para elipsis.

--hinting=none/auto/slight/medium/full

Establece el estilo de hinting.

--antialias=none/gray/subpixel

Establece el antialiasing.

--hint-metrics=on/off

Establece las métricas de hinting.

--subpixel-positions

Establece el posicionamiento subpíxel.

--subpixel-order=rgb/bgr/vrgb/vbgr

Establece el orden subpíxel.

--indent=points

Establece la sangría del párrafo (en puntos).

--spacing=points

Establece el espaciado entre líneas (en puntos).

--line-spacing=factor

Establece el factor de expansión para la altura de línea.

--justify

Estira las líneas del párrafo para que estén justificadas.

--justify-last-line

Justifica la última línea del párrafo.

--language=en_US/etc

Establece el idioma a usar para la selección de fuentes.

--margin= números estilo CSS en píxeles

Establece el margen en la salida en píxeles.

--markup

Interpreta el texto como marcado de Pango.

-o, --output=archivo

Guarda la imagen renderizada en un archivo de salida.

--pixels

Usa unidades de píxeles en lugar de puntos (establece dpi a 72).

--pango-units

Usa unidades Pango en lugar de puntos.

--rtl

Establece la dirección base de derecha a izquierda.

--rotate=grados

Establece el ángulo en el que se rotarán los resultados,

-n, --runs=entero

Ejecuta el motor de diseño Pango este número de veces.

--single-par

Habilita el modo de un solo párrafo.

-t, --text=cadena

Texto a mostrar (en lugar de un archivo).

--waterfall

Crea una visualización en cascada.

-w, --width=puntos

Ancho en puntos al que se ajustarán las líneas o se hará elipsis.

--wrap=word/char/word-char

Modo de ajuste de texto (necesita un ancho establecido).

--serialized=ARCHIVO

Crea el diseño a partir de un archivo serializado,

--serialize-to=ARCHIVO

Serializa el resultado a un archivo.
