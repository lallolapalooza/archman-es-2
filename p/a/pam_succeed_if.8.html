NOMBRE

pam_succeed_if - prueba las características de la cuenta

SINOPSIS

pam_succeed_if.so [flag...] [condición...]

DESCRIPCIÓN

pam_succeed_if.so está diseñado para tener éxito o fallar la autenticación basándose en las características de la cuenta perteneciente al usuario que se está autenticando o en los valores de otros elementos PAM. Un uso es seleccionar si se cargan otros módulos basándose en esta prueba.

Al módulo se le deben dar una o más condiciones como argumentos del módulo, y la autenticación solo tendrá éxito si se cumplen todas las condiciones.

OPCIONES

Las siguientes flags son compatibles:

debug

Activa los mensajes de depuración enviados a syslog.

use_uid

Evalúa las condiciones utilizando la cuenta del usuario cuyo UID bajo el que se está ejecutando la aplicación en lugar del usuario que se está autenticando.

quiet

No registra el fallo o el éxito en el registro del sistema.

quiet_fail

No registra el fallo en el registro del sistema.

quiet_success

No registra el éxito en el registro del sistema.

audit

Registra los usuarios desconocidos en el registro del sistema.

Las condiciónes son tres palabras: un campo, una prueba y un valor para probar.

Los campos disponibles son user, uid, gid, shell, home, ruser, rhost, tty y service:

field < number

El campo tiene un valor numéricamente menor que number.

field <= number

El campo tiene un valor numéricamente menor o igual que number.

field eq number

El campo tiene un valor numéricamente igual a number.

field >= number

El campo tiene un valor numéricamente mayor o igual que number.

field > number

El campo tiene un valor numéricamente mayor que number.

field ne number

El campo tiene un valor numéricamente diferente de number.

field = string

El campo coincide exactamente con la cadena dada.

field != string

El campo no coincide con la cadena dada.

field =~ glob

El campo coincide con el glob dado.

field !~ glob

El campo no coincide con el glob dado.

field in item:item:...

El campo está contenido en la lista de elementos separados por dos puntos.

field notin item:item:...

El campo no está contenido en la lista de elementos separados por dos puntos.

user ingroup group[:group:....]

El usuario está en el(los) grupo(s) dado(s).

user notingroup group[:group:....]

El usuario no está en el(los) grupo(s) dado(s).

user innetgr netgroup

(usuario,host) está en el netgroup dado.

user notinnetgr group

(usuario,host) no está en el netgroup dado.

TIPOS DE MÓDULO PROPORCIONADOS

Todos los tipos de módulo (account, auth, password y session) son proporcionados.

VALORES DE RETORNO

PAM_SUCCESS

La condición fue verdadera.

PAM_AUTH_ERR

La condición fue falsa.

PAM_SERVICE_ERR

Ocurrió un error de servicio o los argumentos no se pudieron analizar correctamente.

EJEMPLOS

Para emular el comportamiento de pam_wheel, excepto que no hay recurso de reserva para que el grupo 0 solo se aproxime comprobando también la pertenencia al grupo root:

auth required pam_succeed_if.so quiet user ingroup wheel:root

Dado que el tipo coincide, solo carga la regla othermodule si el UID es superior a 500. Ajusta el número después de default para omitir varias reglas.

type [default=1 success=ignore] pam_succeed_if.so quiet uid > 500
type required othermodule.so arguments...
