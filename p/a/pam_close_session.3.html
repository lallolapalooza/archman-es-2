NOMBRE

pam_close_session - terminar la gestión de sesiones de PAM

SINOPSIS

#include <security/pam_appl.h>

int pam_close_session(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_close_session se utiliza para indicar que ha finalizado una sesión autenticada. La sesión debería haber sido creada con una llamada a pam_open_session(3).

Cabe señalar que el uid efectivo, geteuid(2), de la aplicación debe tener privilegios suficientes para realizar tareas como desmontar el directorio de inicio del usuario, por ejemplo.

El argumento flags es la combinación binaria de cero o más de los siguientes valores:

PAM_SILENT

No emitir ningún mensaje.

VALORES DE RETORNO

PAM_ABORT

Fallo general.

PAM_BUF_ERR

Error en el búfer de memoria.

PAM_SESSION_ERR

Fallo de sesión.

PAM_SUCCESS

La sesión se ha terminado correctamente.

VER TAMBIÉN

pam_open_session(3), pam_strerror(3)
