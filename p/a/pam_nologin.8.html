NOMBRE

pam_nologin - Evita que usuarios no-root inicien sesión

SINOPSIS

pam_nologin.so [file=/ruta/nologin] [successok]

DESCRIPCIÓN

pam_nologin es un módulo PAM que evita que los usuarios inicien sesión en el sistema cuando existe /var/run/nologin o /etc/nologin. El contenido del archivo se muestra al usuario. El módulo pam_nologin no tiene efecto sobre la capacidad del usuario root de iniciar sesión.

OPCIONES

file=/ruta/nologin

Utiliza este archivo en lugar de los predeterminados /var/run/nologin o /etc/nologin.

successok

Devuelve PAM_SUCCESS si no existe el archivo, el predeterminado es PAM_IGNORE.

TIPOS DE MÓDULOS PROPORCIONADOS

Se proporcionan los tipos de módulos auth y account.

VALORES DE RETORNO

PAM_AUTH_ERR

El usuario no es root y existe el archivo /etc/nologin, por lo que no se permite al usuario iniciar sesión.

PAM_BUF_ERR

Error de búfer de memoria.

PAM_IGNORE

Este es el valor de retorno predeterminado.

PAM_SUCCESS

Éxito: ya sea que el usuario sea root o que el archivo nologin no exista.

PAM_USER_UNKNOWN

Usuario no conocido por el módulo de autenticación subyacente.

EJEMPLOS

El uso sugerido para /etc/pam.d/login es:

auth  required  pam_nologin.so

NOTAS

Para que este módulo sea efectivo, todos los métodos de inicio de sesión deben estar asegurados por él. Debería usarse como un método required (requerido) listado antes que cualquier método sufficient (suficiente) para obtener la semántica estándar de nologin de Unix. Tenga en cuenta que el uso del argumento del módulo successok hace que el módulo devuelva PAM_SUCCESS y, como tal, rompería una configuración así: los módulos sufficient fallidos conducirían a un inicio de sesión exitoso porque el módulo nologin tuvo éxito.

VER TAMBIÉN

nologin(5), pam.conf(5), pam.d(5), pam(8)
