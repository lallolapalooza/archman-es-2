Documentación de Tipo Enumerado

enum pamtest_err

El código de retorno de la función pamtest.

Enumerator

PAMTEST_ERR_OK
Los casos de prueba devueltos corresponden con la entrada.
PAMTEST_ERR_START
pam_start() falló
PAMTEST_ERR_CASE
Un caso de prueba falló. Usa pamtest_failed_case
PAMTEST_ERR_OP
No se pudo ejecutar un caso de prueba.
PAMTEST_ERR_END
pam_end falló
PAMTEST_ERR_KEEPHANDLE
Manejado internamente.
PAMTEST_ERR_INTERNAL
Error interno - entrada incorrecta o similar.

enum pamtest_ops

La enumeración que describe las operaciones realizadas por pamtest().

Enumerator

PAMTEST_AUTHENTICATE
ejecuta pam_authenticate para autenticar la cuenta
PAMTEST_SETCRED
ejecuta pam_setcred() para establecer/eliminar credenciales de usuario
PAMTEST_ACCOUNT
ejecuta pam_acct_mgmt() para validar la cuenta PAM
PAMTEST_OPEN_SESSION
ejecuta pam_open_session() para iniciar una sesión PAM
PAMTEST_CLOSE_SESSION
ejecuta pam_close_session() para finalizar una sesión PAM
PAMTEST_CHAUTHTOK
ejecuta pam_chauthtok() para actualizar el token de autenticación
PAMTEST_GETENVLIST
Si esta opción está configurada, la prueba llamará a pam_getenvlist() y copiará el entorno en case_out.envlist.
PAMTEST_KEEPHANDLE
Esto evitará llamar a pam_end() y solo devolverá el manejador PAM en case_out.ph.

Documentación de Función

const struct pam_testcase * pamtest_failed_case (struct pam_testcase * test_cases)

Ayuda que puedes llamar si run_pamtest() falla. Si PAMTEST_ERR_CASE es devuelto por run_pamtest() deberías llamar a esta función para obtener un puntero al caso de prueba fallido.

Parámetros

test_cases El array de pruebas.

Retorna

un puntero al array de test_cases[] que corresponde al primer caso de prueba donde el código de error esperado no coincide con el código de error real.

void pamtest_free_env (char ** envlist)

Esto libera el array de cadenas devuelto por la prueba PAMTEST_GETENVLIST.

Parámetros

envlist El array a liberar.

const char * pamtest_strerror (enum pamtest_err perr)

devuelve una representación en cadena del código de error de libpamtest.

Parámetros

perr código de error de libpamtest

Retorna

Representación en cadena del argumento perr. Nunca devuelve NULL.

Referencias PAMTEST_ERR_CASE, PAMTEST_ERR_END, PAMTEST_ERR_INTERNAL, PAMTEST_ERR_KEEPHANDLE, PAMTEST_ERR_OK, PAMTEST_ERR_OP, y PAMTEST_ERR_START.

enum pamtest_err run

Ejecuta casos de prueba de libpamtest.
run_pamtest() puede utilizar la función de conversación interna de libpamtest o puede pasar su propia función de conversación. Si pasa su propia función de conversación, esta debe ser compatible con la interfaz de una función de conversación PAM estándar.

Parámetros

service
El nombre del servicio PAM que se está probando. user
El nombre del usuario que se está probando. conv_data
Puntero a la estructura pamtest_conv_data. Debe inicializarse antes de llamar a la función. test_cases
Un array de estructuras pam_testcase que describe las pruebas a realizar. El array debe terminar con un elemento donde el campo 'op' sea 0. pam_handle
Puntero a un manejador PAM. Si se pasa NULL, run_pamtest() intentará crear uno nuevo. Si se pasa un manejador existente, run_pamtest() no llamará a pam_end().

Retorna

un código de error de la enumeración pamtest_err.

Véase también: pam_authenticate(3), pam_acct_mgmt(3), pam_open_session(3), pam_close_session(3), pam_setcred(3), pam_chauthtok(3), pam_getenvlist(3), pam_start(3), pam_end(3), pam_strerror(3), pam_conv(3).

NAME

pamtest, run_pamtest, run_pamtest_conv — libpamtest test runner

SYNOPSIS

_pamtest(const char * service, const char * user, struct pamtest_conv_data * conv_data, struct pam_testcase test_cases[], pam_handle_t * pam_handle)

Run libpamtest test cases. This is using the default libpamtest conversation function.

Parameters

service The PAM service to use in the conversation
user The user to run conversation as
conv_data Test-specific conversation data
test_cases List of libpamtest test cases. Must end with PAMTEST_CASE_SENTINEL
pam_handle The PAM handle to use to run the tests
int main(void) {
    int rc;
    const struct pam_testcase tests[] = {
        pam_test(PAM_AUTHENTICATE, PAM_SUCCESS),
    };
    rc = run_pamtest(tests, NULL, NULL);
    return rc;
}

Returns

PAMTEST_ERR_OK on success, else the error code matching the failure.
