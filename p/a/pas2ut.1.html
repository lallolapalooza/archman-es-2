pas2ut(1) Herramienta de creación de casos de prueba de unidades Free Pascal pas2ut(1)

NOMBRE

pas2ut - La herramienta de conversión de unidades de Free Pascal a casos de prueba.

SINOPSIS

pas2ut [opciones] archivo_entrada [archivo_salida]

DESCRIPCIÓN

pas2ut escanea el archivo de entrada en busca de clases y rutinas, y crea un caso de prueba para todas las clases y rutinas encontradas en la sección de interfaz del archivo. Puede generar una unidad o un archivo de inclusión. Todas las pruebas se crean con un mensaje de fallo estándar. Por defecto, solo se generan pruebas para miembros de clases con visibilidad pública, publicada y por defecto.

USO

pas2ut acepta las siguientes opciones en este momento:

--defaultclasstest=lista
Especifica una lista separada por comas de pruebas predeterminadas para cada clase. Los elementos de la lista deben ser identificadores Pascal válidos.
--failmessage=Msg
Establece el mensaje para la sentencia Fail() dentro de cada método de prueba.
--limit=lista
Especifica una lista separada por comas de identificadores globales para los que generar pruebas. Por defecto, se generan pruebas para todos los identificadores globales en la sección de interfaz de una unidad.
--prefix=nombre
Establece el prefijo para los nombres de las pruebas (el valor predeterminado es Test). Una prueba se nombra según el identificador que prueba, con este prefijo.
--singletestclass
Utiliza una única clase de prueba por cada clase encontrada. El valor predeterminado es crear una clase de caso de prueba por cada clase en la unidad de entrada.
--skip-classes
No genera código de prueba para clases, solo para funciones y procedimientos.
--skip-declaration
No genera declaraciones para las pruebas, solo implementaciones.
--skip-default
Omite pruebas para miembros con visibilidad por defecto. Por defecto, se generan junto con miembros públicos o publicados.
--skip-fail
No crea sentencias fail() en las implementaciones de rutinas de prueba.
--skip-fields
No genera casos de prueba para campos de clases (solo para métodos y propiedades).
--skip-functions
No genera pruebas para funciones/procedimientos, solo para clases.
--skip-implementation
No genera una implementación (vacía) para las pruebas, solo se genera una declaración de clase. (puede completarse en un IDE como Lazarus o MSIDE)
--skip-methods
No genera pruebas para métodos de clases, solo para campos y propiedades.
--skip-properties
No genera pruebas para propiedades de clases, solo para campos y métodos.
--skip-property-default
No genera una prueba predeterminada para cada propiedad.
--skip-public
Omite pruebas para miembros públicos, solo se probarán miembros protegidos si --test-protected está activo.
--skip-published
No genera pruebas para miembros publicados, solo se probarán miembros públicos y por defecto.
--skip-register
No genera la sentencia RegisterTests.
--skip-setup
No sobrescribe el método TTestCase.Setup() en la clase generada.
--skip-teardown
No sobrescribe el método TTestCase.TearDown() en la clase generada.
--skip-unit
No genera una unidad, solo un archivo de inclusión.
--testparentname=nombre
Establece el nombre de la clase padre para las clases de prueba generadas. El valor predeterminado es TTestCase, se puede usar para establecer otro nombre de clase.
--test-property-bounds
Genera una prueba GetBounds para cada propiedad.
--test-property-maxlen
Genera una prueba MaxLen para cada propiedad.
--test-property-notify
Genera una prueba Notify para cada propiedad.
--test-property-required
Genera una prueba Required para cada propiedad.
--test-protected
También genera pruebas para miembros protegidos de clases. Por defecto, las pruebas solo se generan para miembros con visibilidad pública, publicada y por defecto.
--testunitname=nombre
Establece el nombre de la unidad generada (el valor predeterminado se toma del nombre del archivo de salida)
--tiopf
Crea pruebas tiopf (esto es lo mismo que especificar las pruebas --default,--bounds,--required,--notify y --maxlen).
--unittestclassname=nombre
Establece el nombre global de la clase de prueba unitaria. Para ser utilizado con --singletestclass. --limit y --defaultclasstest pueden especificarse varias veces.
