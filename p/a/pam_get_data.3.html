NOMBRE

pam_get_data - obtener datos internos del módulo

SINOPSIS

#include <security/pam_modules.h>

int pam_get_data(const pam_handle_t *pamh, const char *module_data_name, const void **data);

DESCRIPCIÓN

Esta función, junto con la función pam_set_data(3), es útil para gestionar datos específicos del módulo que solo son significativos para el módulo PAM que llama.

La función pam_get_data busca el objeto asociado con la cadena (con suerte) única module_data_name en el contexto PAM especificado por el argumento pamh. Una llamada exitosa a pam_get_data resultará en que data apunte al objeto. Tenga en cuenta que estos datos no son una copia y deben tratarse como constantes por el módulo.

VALORES DE RETORNO

PAM_SUCCESS

Se recuperaron los datos correctamente.

PAM_SYSTEM_ERR

Se envió un puntero NULL como manejador PAM o la función fue llamada por una aplicación.

PAM_NO_MODULE_DATA

No hay datos específicos del módulo presentes.

VER TAMBIÉN

pam_end(3), pam_set_data(3), pam_strerror(3)
