NOMBRE

pam_chauthtok - actualizando tokens de autenticación

SINOPSIS

#include <security/pam_appl.h>

int pam_chauthtok(pam_handle_t *pamh, int flags);

DESCRIPCIÓN

La función pam_chauthtok se utiliza para cambiar el token de autenticación de un usuario dado (como se indica en el estado asociado con el manejador pamh).

El argumento pamh es un manejador de autenticación obtenido por una llamada previa a pam_start(). El argumento flags es el or binario de cero o más de los siguientes valores:

PAM_SILENT

No emitir ningún mensaje.

PAM_CHANGE_EXPIRED_AUTHTOK

Este argumento indica a los módulos que el token de autenticación del usuario (contraseña) solo debe cambiarse si ha expirado. Si este argumento no se pasa, la aplicación requiere que todos los tokens de autenticación sean cambiados.

VALORES DE RETORNO

PAM_AUTHTOK_ERR

Un módulo no pudo obtener el nuevo token de autenticación.

PAM_AUTHTOK_RECOVERY_ERR

Un módulo no pudo obtener el token de autenticación anterior.

PAM_AUTHTOK_LOCK_BUSY

Uno o más módulos no pudieron cambiar el token de autenticación ya que está bloqueado actualmente.

PAM_AUTHTOK_DISABLE_AGING

El envejecimiento del token de autenticación ha sido deshabilitado para al menos uno de los módulos.

PAM_PERM_DENIED

Permiso denegado.

PAM_SUCCESS

El token de autenticación se actualizó correctamente.

PAM_TRY_AGAIN

No todos los módulos estaban en posición de actualizar los tokens de autenticación. En tal caso, ninguno de los tokens de autenticación del usuario se actualiza.

PAM_USER_UNKNOWN

Usuario desconocido para el servicio de contraseñas.
