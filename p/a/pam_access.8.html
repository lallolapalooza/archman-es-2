NOMBRE

pam_access - Módulo PAM para control de acceso de inicio de sesión estilo logdaemon

SINOPSIS

pam_access.so [debug] [noaudit] [nodefgroup] [nodns] [quiet_log] [accessfile=archivo] [fieldsep=sep] [listsep=sep]

DESCRIPCIÓN

El módulo PAM pam_access se utiliza principalmente para la gestión de acceso. Proporciona control de acceso de inicio de sesión estilo logdaemon basado en nombres de inicio de sesión, nombres de host o dominio, direcciones IP o números de red, o en nombres de líneas de terminal, valores de $DISPLAY de X, o nombres de servicio PAM en caso de inicios de sesión no en red.

Por defecto, las reglas para la gestión de acceso se toman del archivo de configuración /etc/security/access.conf si no se especifica otro archivo. Luego se leen archivos individuales de *.conf del directorio /etc/security/access.d/. Los archivos se analizan uno tras otro en el orden de la configuración regional del sistema. El efecto de los archivos individuales es el mismo que si todos los archivos se concatenaran juntos en el orden de análisis. Esto significa que una vez que se coincide un patrón en algún archivo, no se analizan más archivos. Si se especifica explícitamente un archivo de configuración con la opción accessfile, no se analizan los archivos del directorio anterior.

Si Linux PAM está compilado con soporte de auditoría, el módulo informará cuándo deniega el acceso basándose en el origen (host, tty, etc.).

OPCIONES

accessfile=/ruta/a/access.conf

Indica un archivo de configuración alternativo estilo access.conf para anular el predeterminado. Esto puede ser útil cuando diferentes servicios necesitan listas de acceso diferentes.

debug

Se imprime mucha información de depuración con syslog(3).

noaudit

No informar inicios de sesión desde hosts y ttys denegados al subsistema de auditoría.

nodefgroup

Los tokens de usuario que no están entre paréntesis no coincidirán con la base de datos de grupos. El valor predeterminado compatible con versiones anteriores es intentar la coincidencia de la base de datos de grupos incluso para tokens que no están entre paréntesis.

nodns

No intente resolver tokens como nombres de host, solo se resolverán direcciones IPv4 e IPv6. Esto significa que para permitir el inicio de sesión desde un host remoto, las direcciones IP deben especificarse en access.conf.

quiet_log

No registrar denegaciones con syslog(3).

fieldsep=separadores

Esta opción modifica el carácter separador de campo que pam_access reconocerá al analizar el archivo de configuración de acceso. Por ejemplo: fieldsep=| hará que el carácter predeterminado `:` se trate como parte de un valor de campo y `|` se convierta en el separador de campo. Hacer esto puede ser útil en conjunción con un sistema que desea usar pam_access con aplicaciones basadas en X, ya que el elemento PAM_TTY probablemente será del tipo "nombrehost:0" que incluye un carácter `:` en su valor. Pero no debería necesitar esto.

listsep=separadores

Esta opción modifica el carácter separador de lista que pam_access reconocerá al analizar el archivo de configuración de acceso. Por ejemplo: listsep=, hará que los caracteres predeterminados ` ` (espacio) y `\t` (tabulación) se traten como parte de un valor de elemento de lista y `,` se convierta en el único separador de elementos de lista. Hacer esto puede ser útil en un sistema con información de grupos obtenida de un dominio de Windows, donde los grupos integrados predeterminados "Usuarios del dominio", "Administradores del dominio" contienen un espacio.

TIPOS DE MÓDULO PROPORCIONADOS

Se proporcionan todos los tipos de módulos (auth, account, password y session).

VALORES DE RETORNO

PAM_SUCCESS

Se concedió el acceso.

PAM_PERM_DENIED

No se concedió el acceso.

PAM_IGNORE

Se llamó a pam_setcred lo cual no hace nada.

PAM_ABORT

No se pudieron obtener todos los datos u opciones relevantes.

PAM_USER_UNKNOWN

El usuario no es conocido por el sistema.

ARCHIVOS

/etc/security/access.conf

Archivo de configuración predeterminado
