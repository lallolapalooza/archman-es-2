PARTCLONE(8) Manual de Usuario de Partclone PARTCLONE(8)

NOMBRE

partclone - La utilidad para clonar y restaurar una partición.

SINOPSIS

partclone.[tipo_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] fuente} {[[-o | --output] [-O | --overwrite]] destino} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] archivo_log [-R | --rescue] [-L | --logfile] archivo_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPCIÓN

partclone.[tipo_fs] es parte del proyecto Partclone. Partclone proporciona utilidades para hacer copias de seguridad de bloques usados y está diseñado para una mayor compatibilidad del sistema de archivos utilizando bibliotecas existentes, por ejemplo, e2fslibs se utiliza para leer el bloque usado de una partición ext2.

El sistema de archivos compatible con Partclone incluye btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs y jfs para LINUX. También soporta algunos sistemas operativos no Linux, por ejemplo: NTFS, FAT y EXFAT (para Windows), HFS plus (MAC OS de APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) y MINIX (MINIX3).

Todas las utilidades de partclone se pueden ejecutar como partclone.[tipo_fs], muy similar a fsck o mkfs. Por ejemplo, para hacer una copia de seguridad/restaurar hfsplus, simplemente ejecute partclone.hfs

       Sistema de Archivos           partclone.[tipo_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       otros (FS No Soportados)    partclone.imager

OPCIONES

El programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-s ARCHIVO, --source ARCHIVO

Archivo FUENTE. El ARCHIVO puede ser un archivo de imagen (creado por partclone) o un dispositivo, dependiendo de su acción. Normalmente, la fuente de la copia de seguridad es el dispositivo, y la fuente de restauración es el archivo de imagen.

La recepción de datos de una tubería (pipe) sólo se admite para la restauración; omita la opción -s o utilice '-' para indicar la recepción de datos desde stdin.

-o ARCHIVO, --output ARCHIVO

Archivo de SALIDA. El ARCHIVO puede ser un archivo de imagen (que partclone generará) o un dispositivo, dependiendo de su acción. Normalmente, la salida de la copia de seguridad va a un archivo de imagen y la salida de restauración va a un dispositivo.

El envío de datos a una tubería también se admite para copias de seguridad; omita la opción -o o utilice '-' para indicar el envío de datos a stdout.

-O ARCHIVO, --overwrite ARCHIVO

Sobrescribe ARCHIVO, si ya existe.

-W ARCHIVO, --restore_raw_file ARCHIVO

Crea un archivo raw especial para el dispositivo loop.

-c, --clone

Guarda la partición en el formato de imagen especial.

-r, --restore

Restaura la partición desde el formato de imagen especial.

-b, --dev-to-dev

Copia local de dispositivo a dispositivo sobre la marcha, la fuente y la salida son ambos dispositivos.

-D, --domain

Crea un archivo de registro de dominio GNU Ddrescue desde el dispositivo fuente. Este es un archivo legible por humanos en el que + marca las áreas de bloque usadas y ? marca las áreas libres.

--offset_domain=X

Añade X (en bytes) a todas las posiciones reportadas en el archivo de registro de dominio.

--restore_raw_file

Crea un archivo raw especial para el dispositivo loop.

-L ARCHIVO, --logfile ARCHIVO

Especifica una ruta especial para registrar la información del log de partclone. (por defecto /var/log/partclone.log)

-R, --rescue

Continúa después de errores de lectura del disco.

-C, --no_check

No comprueba el tamaño del dispositivo ni el espacio libre.

-N, --ncurses

Utiliza la interfaz de usuario de texto Ncurses.

-I, --ignore_fschk

Ignora la comprobación del sistema de archivos.

-i, --ignore_crc

Ignora el error de la comprobación crc.

-F, --force

Fuerza el progreso.

-f sec, --UI-fresh sec

Establece un intervalo en segundos para la actualización de la interfaz de usuario.

-z tamaño, --buffer_size tamaño

Tamaño del búfer de lectura/escritura (por defecto: 1048576)

-q, --quiet

Desactiva el mensaje de progreso.

-dnivel, --debug nivel

Establece el nivel de depuración [1|2|3]

-x, --compresscmd CMD

Inicia CMD como una tubería de salida para comprimir la imagen clonada

-aX, --checksum-mode=X

Fórmula de suma de comprobación a utilizar para añadir detección de errores

donde X:

0: Sin suma de comprobación (sin ralentización, imagen más pequeña)

1: CRC32 (Cálculo rápido, detección básica)

2: xxHash algoritmo de hash no criptográfico extremadamente rápido

-kX, --blocks-per-checksum=X

Escribe una suma de comprobación por cada X bloques

-w, --skip_write_error

Continúa la restauración a pesar de errores de escritura

--write-direct-io

Escribe datos en la partición de DESTINO sin caché

--read-direct-io

Lee datos de la partición de FUENTE sin caché

-B, --no_block_detail

Muestra el mensaje de progreso sin detalle de bloques

--binary-prefix

Muestra el progreso con tamaño en bits (por defecto es MB, GB...)

--prog-second

Muestra el progreso en segundos (por defecto es minuto)

-E, --offset=X

Añade un desplazamiento X (bytes) a la SALIDA

-T, --btfiles

Restaura el bloque como archivo para ClonezillaBT.

-t, --btfiles_torrent

Restaura el bloque como archivo para ClonezillaBT pero solo genera el torrent.

-n, --note NOTA

Muestra un Mensaje NOTA (128 palabras).

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión

NOMBRE

partclone.ext3 - clonar y restaurar el sistema de archivos ext3

SINOPSIS

partclone.ext3 [Opciones]

DESCRIPCIÓN

partclone.ext3 es una utilidad para clonar y restaurar sistemas de archivos ext3. Usa la biblioteca partclone para realizar operaciones de copia de seguridad y restauración. Esta herramienta está diseñada para ser eficiente en el uso del espacio en disco, ya que solo copia los bloques utilizados del sistema de archivos.

Se puede utilizar para clonar una partición a un archivo de imagen o restaurar una partición desde un archivo de imagen. También soporta operaciones con flujos (stdin/stdout) para integrar con otras herramientas como gzip, dd, etc.

OPCIONES

-c, --clone
Clonar el sistema de archivos. Por defecto, la acción es restaurar.
-r, --restore
Restaurar el sistema de archivos. Este es el comportamiento por defecto.
-s, --source FUENTE
Especificar la fuente de la operación. Puede ser un dispositivo de bloque (ej. /dev/hda1) o un archivo de imagen.
-o, --output SALIDA
Especificar la salida de la operación. Puede ser un dispositivo de bloque o un archivo de imagen.
-d, --debug
Habilitar información de depuración durante la ejecución del programa.
-h, --help
Mostrar mensaje de ayuda y salir.
-v, --version
Mostrar información de la versión y salir.

ARCHIVOS

/var/log/partclone.log

El archivo de registro de partclone

EJEMPLOS

 Clonar /dev/hda1 a hda1.img y mostrar información de depuración.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurar /dev/hda1 desde hda1.img y mostrar información de depuración.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 Restaurar imagen de clonezilla (dividida, comprimida con gzip,) con fuente stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNÓSTICOS

Los siguientes diagnósticos pueden ser emitidos en stderr:

partclone proporciona algunos códigos de retorno, que pueden ser usados en scripts:

Código Diagnóstico
0 El programa finalizó con éxito.
1 La clonación o restauración parecen haber fallado.
