NOMBRE

pamu2fcfg - Herramienta de configuración para el módulo U2F de PAM.

SINOPSIS

pamu2fcfg [OPCIÓN]...

DESCRIPCIÓN

Realiza un procedimiento de registro FIDO2/U2F utilizando un autenticador conectado y genera una línea de configuración que se puede usar con el módulo U2F de PAM.

OPCIONES

-d, --debug

Imprime información de depuración (muy detallada)

-h, --help

Imprime la ayuda y sale

-o, --origin=CADENA

Establece el ID de la parte confiable de FIDO2 a usar durante el registro. Por defecto es pam://hostname. Antes de pamu2fcfg v1.1.0, esto establecía la URL de origen de U2F.

-i, --appid=CADENA

Establece el nombre de la parte confiable de FIDO2 a usar durante el registro. Por defecto es origin. Antes de pamu2fcfg v1.1.0, esto establecía el ID de la aplicación U2F.

-r, --resident

Genera una credencial residente. Por defecto está desactivada.

-t, --type=CADENA

Tipo COSE a usar durante el registro (ES256, EDDSA o RS256). Por defecto es ES256.

-P, --no-user-presence

Permite usar la credencial sin asegurar la presencia del usuario. Por defecto está desactivada.

-N, --pin-verification

Requiere verificación de PIN durante la autenticación. Por defecto está desactivada.

-V, --user-verification

Requiere verificación del usuario durante la autenticación. Por defecto está desactivada.

--version: Imprime la versión y sale

-u, --username=CADENA

El nombre del usuario que registra el dispositivo. Por defecto es el nombre del usuario actual.

-n, --nouser

Imprime solo información de registro (manejador de clave, clave pública y opciones). Útil para añadir.

ERRORES

Reportar errores de pamu2fcfg en el rastreador de incidencias: https://github.com/Yubico/pam-u2f/issues
