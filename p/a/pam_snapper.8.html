PAM_SNAPPER(8) Gestión de instantáneas del sistema de archivos PAM_SNAPPER(8)

NOMBRE

pam_snapper - Módulo PAM que crea instantáneas del sistema de archivos a través de "snapper"

SINOPSIS

pam_snapper.so [debug] [homeprefix=prefijo] [ignoreservices=servicios] [ignoreusers=usuarios] [rootasroot] [ignoreroot] [openonly] [closeonly] [cleanup=algoritmo]

DESCRIPCIÓN

Crea una instantánea en cada inicio de sesión de un usuario, de modo que siempre tengan un punto de partida guardado.

Dado que muchos usuarios no cierran la sesión durante algún tiempo, es una buena idea habilitar también las instantáneas basadas en tiempo de snapper.

OPCIONES

debug

Activa la depuración en el módulo.

homeprefix=prefijo

Prefijo para el nombre de la configuración de snapper. El nombre de usuario se añadirá a este prefijo.

Por defecto: "home_"

ignoreservices=lista de servicios separada por comas

Por defecto: "crond"

ignoreusers=lista de usuarios separada por comas

Por defecto: (ninguno)

rootasroot

Realiza una instantánea utilizando la configuración de snapper "root" si el usuario "root" inicia sesión. En otras palabras: el prefijo del directorio personal no se usa en este caso. Dado que la configuración de snapper "root" se utiliza para el sistema (el sistema de archivos raíz), esto significa que con cada inicio de sesión del usuario "root" se creará una instantánea completa del sistema de archivos "/". Esto puede ser útil para ayudar a los administradores a revertir en caso de que sus cambios de actividad/configuración hayan sido erróneos accidentalmente.

"rootasroot" y "ignoreroot" son mutuamente excluyentes.

ignoreroot

No se toma ninguna instantánea si el usuario "root" abre/cierra una sesión.

"rootasroot" y "ignoreroot" son mutuamente excluyentes.

openonly

Solo crea una única instantánea al abrir la sesión PAM.

Por defecto: crea instantáneas pre y post

closeonly

Solo crea una única instantánea al cerrar la sesión PAM.

Por defecto: crea instantáneas pre y post

cleanup=algoritmo-de-limpieza

Establece el algoritmo de limpieza de snapper.

Por defecto: (ninguno)

TIPOS DE MÓDULO PROPORCIONADOS

Solo se proporciona el tipo de módulo "session".

VALORES DE RETORNO

PAM_SUCCESS

pam_snapper siempre devolverá PAM_SUCCESS, para no impedir que los usuarios inicien sesión, en caso de que una instantánea falle. Esto puede cambiar en el futuro.

EJEMPLOS

Uso básico

1. Cree un subvolumen de btrfs para el nuevo usuario y una configuración de snapper, por ejemplo, usando la herramienta /usr/lib/pam_snapper/pam_snapper_useradd.sh.
2. Añada la siguiente línea a /etc/pam.d/common-session: 
session    optional    pam_snapper.so
