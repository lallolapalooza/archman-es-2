PWD(1P) Manual del Programador POSIX PWD(1P)

PROLOGO

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

pwd — devuelve el nombre del directorio de trabajo

SINOPSIS

pwd [-L|-P]

DESCRIPCIÓN

La utilidad pwd escribirá en la salida estándar una ruta absoluta del directorio de trabajo actual, que no contenga los nombres de archivo punto o doble punto.

OPCIONES

La utilidad pwd cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de Sintaxis de Utilidades.

Las siguientes opciones serán compatibles con la implementación:

-L
Si la variable de entorno PWD contiene una ruta absoluta del directorio actual y la ruta no contiene ningún componente que sea punto o doble punto, pwd escribirá esta ruta en la salida estándar, excepto que si la variable de entorno PWD es más larga que {PATH_MAX} bytes, incluido el nulo de terminación, no se especifica si pwd escribirá esta ruta en la salida estándar o se comportará como si se hubiera especificado la opción -P. De lo contrario, la opción -L se comportará como la opción -P.
-P
La ruta escrita en la salida estándar no contendrá ningún componente que haga referencia a archivos de tipo enlace simbólico. Si hay múltiples rutas que la utilidad pwd podría escribir en la salida estándar, una que comience con un solo carácter de barra diagonal (<slash>) y una o más que comiencen con dos caracteres de barra diagonal (<slash>), entonces escribirá la ruta que comienza con un solo carácter de barra diagonal (<slash>). La ruta no contendrá caracteres de barra diagonal (<slash>) innecesarios después de los caracteres de barra diagonal (<slash>) iniciales o dobles.

Si se especifican tanto -L como -P, la última se aplicará. Si no se especifica ni -L ni -P, la utilidad pwd se comportará como si se hubiera especificado -L.

Ninguno.

ENTRADA ESTÁNDAR

No se usa.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de pwd:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización, la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.
PWD
Una ruta absoluta del directorio de trabajo actual. Si una aplicación establece o anula el valor de PWD, el comportamiento de pwd no está especificado.

EVENTOS ASINCRONOS

Predeterminado.

SALIDA ESTÁNDAR

La salida de la utilidad pwd es una ruta absoluta del directorio de trabajo actual:

"%s\n", <ruta del directorio>

SALIDA DE ERROR ESTÁNDAR

La salida de error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización exitosa.
>0
Ocurrió un error.

CONSECUENCIAS DE ERRORES

Si se detecta un error, no se escribirá ninguna salida en la salida estándar, se escribirá un mensaje de diagnóstico en la salida de error estándar y el estado de salida no será cero.

Las siguientes secciones son informativas.

USO DE APLICACIONES

Si la ruta obtenida de pwd es más larga que {PATH_MAX} bytes, podría producir un error si se pasa a cd. Por lo tanto, para volver a ese directorio puede ser necesario dividir la ruta en secciones más cortas que {PATH_MAX} y llamar a cd en cada sección por turnos (la primera sección siendo una ruta absoluta y las secciones posteriores siendo rutas relativas).

EJEMPLOS

Ninguno.

RACIONAMIENTO

Algunas implementaciones han proporcionado históricamente pwd como un comando especial interno del shell.

En la mayoría de las utilidades, si ocurre un error, la salida parcial puede escribirse en la salida estándar. Esto no ocurre en las implementaciones históricas de pwd. Dado que pwd se utiliza con frecuencia en scripts de shell históricos sin verificar el estado de salida, es importante que aquí se requiera el comportamiento histórico; por lo tanto, la sección CONSECUENCIAS DE ERRORES prohíbe específicamente la escritura de cualquier salida parcial en la salida estándar.

Una versión anterior de este estándar indicaba que la variable de entorno PWD se veía afectada cuando la opción -P estaba en efecto. Esto era incorrecto; las implementaciones conformes no hacen esto.
