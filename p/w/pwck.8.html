PWCK(8) Comandos de administración del sistema PWCK(8)

NOMBRE

pwck - verifica la integridad de los archivos de contraseñas

SINOPSIS

pwck [opciones] [ARCHIVO_CONTRASENAS [ ARCHIVO_SOMBRA ]]

DESCRIPCIÓN

El comando pwck verifica la integridad de la información de usuarios y autenticación. Comprueba que todas las entradas en /etc/passwd y /etc/shadow tengan el formato correcto y contengan datos válidos. Se le pedirá al usuario que elimine las entradas que tengan un formato incorrecto o que tengan otros errores incorregibles.

Se realizan comprobaciones para verificar que cada entrada tenga:

•el número correcto de campos
•un nombre de usuario único y válido
•un identificador de usuario y grupo válido
•un grupo primario válido
•un directorio de inicio válido
•un shell de inicio de sesión válido

Las comprobaciones de la información de contraseñas en sombra se habilitan cuando se especifica el segundo parámetro de archivo ARCHIVO_SOMBRA o cuando /etc/shadow existe en el sistema.

Estas comprobaciones son las siguientes:

•cada entrada de passwd tiene una entrada de sombra correspondiente, y cada entrada de sombra tiene una entrada de passwd correspondiente
•las contraseñas se especifican en el archivo en sombra
•las entradas de sombra tienen el número correcto de campos
•las entradas de sombra son únicas en el archivo de sombra
•los últimos cambios de contraseña no están en el futuro

Las comprobaciones del número correcto de campos y del nombre de usuario único son fatales. Si la entrada tiene el número incorrecto de campos, se le pedirá al usuario que elimine toda la línea. Si el usuario no responde afirmativamente, se omitirán todas las comprobaciones posteriores. Se le pedirá que elimine una entrada con un nombre de usuario duplicado, pero aún se realizarán las comprobaciones restantes. Todos los demás errores son advertencias y se anima al usuario a ejecutar el comando usermod para corregir el error.

Los comandos que operan en el archivo /etc/passwd no pueden modificar entradas corruptas o duplicadas. pwck debe usarse en esas circunstancias para eliminar la entrada infractora.

OPCIONES

Las opciones -r y -s no se pueden combinar.

Las opciones que se aplican al comando pwck son:

--badname 

Permite nombres que no se ajustan a los estándares.

-h, --help

Muestra el mensaje de ayuda y sale.

-q, --quiet

Solo informa de errores. Las advertencias que no requieren ninguna acción por parte del usuario no se mostrarán.

-r, --read-only

Ejecuta el comando pwck en modo de solo lectura.

-R, --root CHROOT_DIR

Aplica cambios en el directorio CHROOT_DIR y utiliza los archivos de configuración del directorio CHROOT_DIR. Solo se admiten rutas absolutas.

-s, --sort

Ordena las entradas en /etc/passwd y /etc/shadow por UID.

Por defecto, pwck opera en los archivos /etc/passwd y /etc/shadow. El usuario puede seleccionar archivos alternativos con los parámetros passwd y shadow.

CONFIGURACIÓN

Las siguientes variables de configuración en /etc/login.defs cambian el comportamiento de esta herramienta:

NONEXISTENT (cadena)

Si una cuenta de sistema no tiene intencionadamente un directorio de inicio que exista, esta cadena se puede proporcionar en la entrada de /etc/passwd para la cuenta para indicarlo. El resultado es que pwck no emitirá una advertencia espuria para esta cuenta.

PASS_MAX_DAYS (número)

El número máximo de días que se puede utilizar una contraseña. Si la contraseña es anterior a esto, se forzará un cambio de contraseña. Si no se especifica, se asumirá -1 (lo que deshabilita la restricción).

PASS_MIN_DAYS (número)

El número mínimo de días permitidos entre cambios de contraseña. Cualquier intento de cambio de contraseña antes de este tiempo será rechazado. Si no se especifica, se asumirá 0 (lo que deshabilita la restricción).

PASS_WARN_AGE (número)

El número de días de advertencia que se dan antes de que una contraseña expire. Un cero significa que la advertencia se da solo el día de la expiración, un valor de -1 significa que no se da ninguna advertencia. Si no se especifica, no se proporcionará ninguna advertencia.

ARCHIVOS

/etc/group

Información de la cuenta de grupo.

/etc/passwd

Información de la cuenta de usuario.

/etc/shadow

Información segura de la cuenta de usuario.

VALORES DE SALIDA

El comando pwck sale con los siguientes valores:

0

éxito

1

sintaxis de comando inválida

2

una o más entradas de contraseña incorrectas

3

no se pueden abrir los archivos de contraseña

4

no se pueden bloquear los archivos de contraseña

5

no se pueden actualizar los archivos de contraseña

6

no se pueden ordenar los archivos de contraseña
