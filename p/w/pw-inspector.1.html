PW-INSPECTOR(1) Manual de Comandos Generales PW-INSPECTOR(1)

NOMBRE

pw-inspector - Una herramienta para reducir la lista de contraseñas

SINOPSIS

pw-inspector [-i ARCHIVO] [-o ARCHIVO] [-m MINLEN] [-M MAXLEN] [-c MINSETS] -l -u -n -p -s

DESCRIPCIÓN

PW-Inspector lee contraseñas y muestra aquellas que cumplen con los requisitos. El código de retorno es el número de contraseñas válidas encontradas, 0 si no se encontró ninguna. Úsese para seguridad: comprueba contraseñas, si se devuelve 0, rechaza la elección de contraseña. Úsese para hacking: recorta tu archivo de diccionario según los requisitos de pw del objetivo. El uso solo está permitido para fines legales.

OPCIONES

-i ARCHIVO
archivo del que leer contraseñas (por defecto: stdin)
-o ARCHIVO
archivo al que escribir contraseñas válidas (por defecto: stdout)
-m MINLEN
longitud mínima de una contraseña válida
-M MAXLEN
longitud máxima de una contraseña válida
-c MINSETS
el número mínimo de conjuntos requeridos (por defecto: todos los dados)
-h, --help
Muestra un resumen de las opciones.

CONJUNTOS

-l
caracteres en minúsculas (a,b,c,d, etc.)
-u
caracteres en mayúsculas (A,B,C,D, etc.)
-n
números (1,2,3,4, etc.)
-p
caracteres imprimibles (que no son -l/-n/-n, p. ej., $,!,/,(,*, etc.)
 -s
caracteres especiales - todos los demás que no están dentro de los conjuntos anteriores

VER TAMBIÉN

hydra(1), xhydra(1).
