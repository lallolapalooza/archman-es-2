pw-cli(1) Manual de Comandos Generales pw-cli(1)

NOMBRE

pw-cli - La Interfaz de Línea de Comandos de PipeWire

SINOPSIS

pw-cli [comando]

DESCRIPCIÓN

Interactúa con una instancia de PipeWire.

Cuando se proporciona un comando, pw-cli ejecutará el comando y saldrá.

Cuando no se proporciona ningún comando, pw-cli inicia una sesión interactiva con la instancia predeterminada de PipeWire pipewire-0.

Se pueden establecer conexiones con otras instancias remotas. El nombre de la instancia actual se muestra en el prompt.

Tenga en cuenta que pw-cli también crea una instancia local de PipeWire. Algunos comandos operan en la instancia actual (remota) y otros en la instancia local, como la carga de módulos.

Utilice el comando 'help' para listar los comandos disponibles.

COMANDOS GENERALES

help | h

Muestra una ayuda rápida sobre los comandos disponibles. También lista los alias para muchos comandos.

quit | q

Sale de pw-cli.

GESTIÓN DE MÓDULOS

Los módulos se cargan y descargan en la instancia local, por lo tanto, el binario pw-cli en sí mismo puede agregar funcionalidad u objetos a la instancia local. No es posible en PipeWire cargar módulos en otra instancia.

load-module nombre [argumentos...]

Carga un módulo especificado por su nombre y argumentos en la instancia local. Para la mayoría de los módulos está bien cargarlos más de una vez.

Este comando devuelve una variable de módulo que puede usarse para descargar el módulo.

El módulo local *no* es visible en la instancia remota. No es posible en PipeWire cargar módulos en una instancia remota.

unload-module variable-modulo

Descarga un módulo, especificado por su variable.

INTROSPECCIÓN DE OBJETOS

list-objects

Lista los objetos de la instancia actual.

Los objetos se listan con su id, tipo y versión.

info id | all

Obtiene información sobre un objeto específico o *todos* los objetos.

Solicitar información sobre un objeto también le notificará de cambios.

TRABAJAR CON REMOTAS

connect [nombre-remoto]

Se conecta a una instancia remota y la convierte en la nueva instancia actual.

Si no se especifica ningún nombre remoto, se establece una conexión con la instancia remota predeterminada, generalmente pipewire-0.

El nombre remoto especial llamado internal puede usarse para conectarse a la instancia de PipeWire local de pw-cli.

Este comando devuelve una variable remota que puede usarse para desconectar o cambiar remotas.

disconnect [variable-remota]

Desconecta de una instancia remota.

Si no se especifica ningún nombre remoto, se desconecta la instancia actual.

list-remotes

Lista todas las instancias remotas.

switch-remote [variable-remota]

Convierte la remota especificada en la instancia actual.

Si no se especifica ningún nombre remoto, se establece la primera instancia como actual.

GESTIÓN DE NODOS

create-node nombre-fábrica [propiedades...]

Crea un nodo desde una fábrica en la instancia actual.

Las propiedades son pares clave=valor separados por espacios en blanco.

Este comando devuelve una variable de nodo.

export-node id-nodo [variable-remota]

Exporta un nodo de la instancia local a la instancia especificada. Cuando no se especifica ninguna instancia, el nodo se exportará a la instancia actual.

GESTIÓN DE DISPOSITIVOS

create-device nombre-fábrica [propiedades...]

Crea un dispositivo desde una fábrica en la instancia actual.

Las propiedades son pares clave=valor separados por espacios en blanco.

Este comando devuelve una variable de dispositivo.

GESTIÓN DE ENLACES

create-link id-nodo id-puerto id-nodo id-puerto [propiedades...]

Crea un enlace entre 2 nodos y puertos.

Los ids de puerto y los ids de nodo pueden establecerse en - para seleccionar automáticamente un nodo o un puerto.

Los ids de puerto pueden ser * para enlazar automáticamente puertos coincidentes en los nodos.

Las propiedades son pares clave=valor separados por espacios en blanco.

Este comando devuelve una o más variables de enlace.

GESTIÓN DE GLOBALS

destroy id-objeto

Destruye un objeto global.

GESTIÓN DE PARÁMETROS

enum-params id-objeto id-parámetro

Enumera los parámetros de un objeto.

El id-parámetro también puede darse como el nombre corto del parámetro.

set-param id-objeto id-parámetro json-parámetro

Establece el parámetro de un objeto.

El id-parámetro también puede darse como el nombre corto del parámetro.

GESTIÓN DE PERMISOS

permissions id-cliente id-objeto permiso

Establece permisos para un cliente.

El id-objeto puede ser -1 para establecer los permisos predeterminados.

get-permissions id-cliente

Obtiene los permisos de un cliente.

GESTIÓN DE COMANDOS

send-command id-objeto

Envía un comando a un objeto.
