PWMAKE(1) Manual de Comandos Generales PWMAKE(1)

NOMBRE

pwmake - herramienta simple para generar contraseñas aleatorias relativamente fáciles de pronunciar

SINOPSIS

pwmake <bits-de-entropia>

DESCRIPCIÓN

pwmake es una herramienta simple y configurable para generar contraseñas aleatorias y relativamente fáciles de pronunciar. La herramienta le permite especificar el número de bits de entropía que se utilizan para generar la contraseña.

La entropía se extrae de /dev/urandom.

El número mínimo de bits es 56, que es utilizable para contraseñas en sistemas/servicios donde los ataques de fuerza bruta tienen una tasa de intentos muy limitada. Los 64 bits deberían ser adecuados para aplicaciones donde el atacante no tiene acceso directo al archivo hash de la contraseña. Para situaciones en las que el atacante pueda obtener acceso directo al hash de la contraseña o la contraseña se utilice como clave de cifrado, se deben usar entre 80 y 128 bits, dependiendo de su nivel de paranoia.

Cualquier valor de bits-de-entropia fuera del rango de 56 a 256 bits se ajustará para que encaje dentro del rango permitido.

OPCIONES

El primer y único argumento es el número de bits de entropía utilizados para generar la contraseña.

FICHEROS

/etc/security/pwquality.conf - El archivo de configuración para la biblioteca libpwquality.

CÓDIGOS DE RETORNO

pwmake devuelve 0 en caso de éxito, un valor distinto de cero en caso de error.

VER TAMBIÉN

pwscore(1), pam_pwquality(8)
