NOMBRE

pw-profiler - El generador de perfiles de PipeWire

SINOPSIS

pw-profiler [opciones]

DESCRIPCIÓN

Inicia la generación de perfiles de una instancia de PipeWire.

Si el servidor tiene cargado el módulo de generación de perfiles, este programa se conectará a él y registrará los datos del generador de perfiles. Los datos del generador de perfiles contienen tiempos y duraciones de cuándo comenzó y completó el procesamiento de nodos y dispositivos.

Cuando este programa se detiene, se genera un conjunto de archivos gnuplot y un script para generar archivos SVG a partir de los archivos .plot, junto con un archivo .html para visualizar los resultados de la generación de perfiles en un navegador.

Esta función utiliza los mismos datos que utiliza pw-top.

OPCIONES

-r | --remote=NOMBRE

El nombre de la instancia remota a supervisar. Si se deja sin especificar, se establece una conexión con la instancia predeterminada de PipeWire.

-h | --help

Muestra la ayuda.

--version

Muestra la información de la versión.

-o | --output=ARCHIVO

Nombre del archivo de salida del generador de perfiles (predeterminado "profiler.log").

AUTORES

Los desarrolladores de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire está disponible en https://pipewire.org
