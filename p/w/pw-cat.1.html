pw-cat(1) Manual de comandos generales pw-cat(1)

NOMBRE

pw-cat - Reproduce y graba medios con PipeWire

SINOPSIS

pw-cat [opciones] [ARCHIVO | -]

pw-play [opciones] [ARCHIVO | -]

pw-record [opciones] [ARCHIVO | -]

pw-midiplay [opciones] [ARCHIVO | -]

pw-midirecord [opciones] [ARCHIVO | -]

pw-dsdplay [opciones] [ARCHIVO | -]

DESCRIPCIÓN

pw-cat es una herramienta simple para reproducir o capturar archivos de medios codificados o sin codificar en un servidor PipeWire. Entiende todos los formatos de archivo de audio compatibles con libsndfile para captura y reproducción PCM. Al capturar PCM, la extensión del nombre del archivo se utiliza para adivinar el formato del archivo, siendo el formato de archivo WAV el predeterminado.

Entiende archivos MIDI estándar para reproducción y grabación. Esta herramienta no renderizará archivos MIDI, simplemente hará que los eventos MIDI estén disponibles para el grafo. Necesitas un renderizador MIDI como qsynth, timidity o un renderizador MIDI de hardware para escuchar el MIDI.

La reproducción DSD es compatible con el formato de archivo DSF. Esta herramienta solo funcionará con hardware capaz de DSD nativo y producirá un error cuando no se encuentre dicho hardware.

Cuando ARCHIVO es -, la entrada y la salida serán datos sin procesar de STDIN y STDOUT respectivamente.

OPCIONES

-h | --help

Muestra la ayuda.

--version

Muestra información de la versión.

-v | --verbose

Operación detallada.

-R | --remote=NOMBRE

El nombre de la instancia remota a la que conectarse. Si no se especifica, se establece una conexión con la instancia predeterminada de PipeWire.

-p | --playback

Modo de reproducción. Lee datos del archivo especificado y los reproduce. Si la herramienta se llama con el nombre pw-play o pw-midiplay, este es el modo predeterminado.

-r | --record

Modo de grabación. Captura datos y los escribe en el archivo especificado. Si la herramienta se llama con el nombre pw-record o pw-midirecord, este es el modo predeterminado.

-m | --midi

Modo MIDI. ARCHIVO es un archivo MIDI. Si la herramienta se llama con el nombre pw-midiplay o pw-midirecord, este es el modo predeterminado. Tenga en cuenta que este programa no renderizará los eventos MIDI en muestras audibles, simplemente proporcionará los eventos MIDI en el grafo. Necesitas un renderizador MIDI separado como qsynth, timidity o un renderizador de hardware para escuchar el MIDI.

-d | --dsd

Modo DSD. ARCHIVO es un archivo DSF. Si la herramienta se llama con el nombre pw-dsdplay, este es el modo predeterminado. Tenga en cuenta que este programa no renderizará el audio DSD. Necesitas un dispositivo capaz de DSD para reproducir contenido DSD o este programa saldrá con un error.

--media-type=VALOR

Establece la propiedad de tipo de medio (predeterminado Audio/Midi según el modo). El gestor de sesiones utiliza el tipo de medio para seleccionar un destino adecuado al que vincularse.

--media-category=VALOR

Establece la propiedad de categoría de medio (predeterminado Reproducción/Captura según el modo). El gestor de sesiones utiliza el tipo de medio para seleccionar un destino adecuado al que vincularse.

--media-role=VALOR

Establece la propiedad de rol de medio (predeterminado Música). El gestor de sesiones utiliza el tipo de medio para seleccionar un destino adecuado al que vincularse.

--target=VALOR

Establece un nodo de destino (predeterminado auto). El valor puede ser:
  • auto: Selección automática (Predeterminado)
  • 0: No intentar vincular este nodo
  • <id>: El serial del objeto o el nombre del nodo de un nodo de destino

--latency=VALOR[unidades]

Establece la latencia del nodo (predeterminado 100ms)

La latencia determina la cantidad mínima de tiempo que tarda una muestra en viajar desde la aplicación hasta el dispositivo (reproducción) y desde el dispositivo hasta la aplicación (captura).

La latencia determina el tamaño de los búferes que la aplicación podrá llenar. Una latencia menor significa búferes más pequeños pero mayor sobrecarga. Una latencia mayor significa búferes más grandes y menor sobrecarga.

Las unidades pueden ser s para segundos, ms para milisegundos, us para microsegundos, ns para nanosegundos. Si no se proporcionan unidades, el valor de latencia son muestras con la frecuencia de muestreo del archivo.

-P | --properties=VALOR

Establece propiedades de transmisión adicionales como un objeto JSON.

-q | --quality=VALOR

Calidad del remuestreador. Cuando la frecuencia de muestreo del archivo de origen o destino no coincide con la frecuencia de muestreo del servidor, los datos se remuestrean. Una mayor calidad utiliza más CPU. Se permiten valores entre 0 y 15, la calidad predeterminada es 4.

--rate=VALOR

La frecuencia de muestreo, predeterminada 48000.

--channels=VALOR

El número de canales, predeterminado 2.

--channel-map=VALOR

El mapa de canales. Los valores posibles incluyen: mono, stereo, surround-21, quad, surround-22, surround-40, surround-31, surround-41, surround-50, surround-51, surround-51r, surround-70, surround-71 o una lista separada por comas de nombres de canales: FL, FR, FC, LFE, SL, SR, FLC, FRC, RC, RL, RR, TC, TFL, TFC, TFR, TRL, TRC, TRR, RLC, RRC, FLW, FRW, LFE2, FLH, FCH, FRH, TFLC, TFRC, TSL, TSR, LLFR, RLFE, BC, BLC, BRC

--format=VALOR

El formato de muestra a utilizar. Uno de: u8, s8, s16 (predeterminado), s24, s32, f32, f64.

--volume=VALOR

El volumen de la transmisión, predeterminado 1.000. Dependiendo de la configuración regional que tenga configurada, se puede utilizar "," o "." como separador decimal. Verifique con el comando locale.
