pw-reserve(1) Manual de comandos generales pw-reserve(1)

NOMBRE

pw-reserve - La utilidad de reserva de dispositivos de PipeWire

SINOPSIS

pw-reserve [opciones]

DESCRIPCIÓN

Reserva un dispositivo utilizando el esquema de reserva de dispositivos DBus org.freedesktop.ReserveDevice1 [1], esperando hasta ser terminado por SIGINT u otra señal.

También puede solicitar a otras aplicaciones que liberen un dispositivo. Esto se puede utilizar para hacer que los servidores de audio como PipeWire, Pulseaudio, JACK u otras aplicaciones que respeten el protocolo de reserva de dispositivos, ignoren un dispositivo o liberen un dispositivo de sonido que ya están utilizando para que pueda ser utilizado por otras aplicaciones.

OPCIONES

-r | --release

Solicita a cualquier cliente que actualmente tenga el dispositivo que lo libere, e intenta reservarlo después. Si no se proporciona esta opción y el dispositivo ya está en uso, pw-reserve saldrá con estado de error.

-n NOMBRE | --name=NOMBRE

Nombre del dispositivo a reservar. Por convención, este es
•
AudioN: para la tarjeta ALSA número N

pw-reserve puede reservar cualquier nombre de dispositivo, sin embargo PipeWire no admite actualmente otros valores que los enumerados anteriormente.

-a NOMBRE | --appname= NOMBRE

Nombre de la aplicación a utilizar al reservar el dispositivo.

-p PRIORIDAD | --priority= PRIORIDAD

Prioridad a utilizar al reservar el dispositivo.

-m | --monitor

Monitorea las reservas de un dispositivo dado, en lugar de reservarlo.

-h | --help

Mostrar ayuda.

--version

Mostrar información de la versión.

ESTADO DE SALIDA

Si la reserva del dispositivo tiene éxito, pw-reserve no sale hasta que se termina con una señal. Sale con estado 0 si se termina con SIGINT o SIGTERM en este caso.

De lo contrario, sale con un estado de salida distinto de cero.

EJEMPLOS

pw-reserve -n Audio0

Reserva la tarjeta ALSA 0 y sale con error si ya está reservada.

pw-reserve -n Audio0 -r

Reserva la tarjeta ALSA 0, solicitando a cualquier aplicación que haya reservado el dispositivo que la libere para nosotros.

AUTORES

Los desarrolladores de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire está disponible en https://pipewire.org

VER TAMBIÉN
