NOMBRE

pw-container - La utilidad de contenedor de PipeWire

SINOPSIS

pw-container [opciones] [PROGRAMA]

DESCRIPCIÓN

Ejecuta un programa en un nuevo contexto de seguridad [1].

pw-container creará un nuevo socket unix temporal y usará la API de extensión SecurityContext para crear un servidor en este socket con las propiedades dadas. Los clientes creados desde este socket del servidor tendrán las propiedades de seguridad asociadas a ellos.

Esto se puede usar para simular el comportamiento de Flatpak u otros contenedores.

Sin argumentos, pw-container simplemente crea el nuevo socket e imprime la dirección en la salida estándar. Otros programas de PipeWire pueden luego ejecutarse con PIPEWIRE_REMOTE=<dirección-del-socket> para conectarse a través de este contexto de seguridad.

Cuando se proporciona PROGRAMA, se establecerá la variable entorno PIPEWIRE_REMOTE y PROGRAMA se pasará a system(). Los argumentos para PROGRAMA deben ser citados correctamente.

OPCIONES

-P | --properties=VALOR

Establece propiedades de contexto adicionales como un objeto JSON.

-r | --remote=NOMBRE

El nombre de la instancia remota a la que conectarse. Si no se especifica, se establece una conexión con la instancia predeterminada de PipeWire.

-h | --help

Muestra la ayuda.

--version

Muestra información de la versión.

ESTADO DE SALIDA

Si el contexto de seguridad se creó con éxito, pw-container no sale hasta que se termina con una señal. Sale con estado 0 si se termina por SIGINT o SIGTERM en este caso.

De lo contrario, sale con un estado de salida distinto de cero.

EJEMPLOS

pw-container 'pw-dump i 0'

Ejecuta pw-dump del objeto Core. Tenga en cuenta la diferencia en los permisos del objeto al ejecutar pw-dump con y sin pw-container.

pw-container 'pw-dump pw-dump'

Ejecuta pw-dump de sí mismo. Tenga en cuenta la diferencia en los tokens de seguridad del Cliente al ejecutar pw-dump con y sin pw-container.
