pw-config(1) Manual de comandos generales pw-config(1)

NOMBRE

pw-config - Analiza la configuración de PipeWire para depuración

SINOPSIS

pw-config [opciones] rutas

pw-config [opciones] listar [SECCIÓN]

pw-config [opciones] fusionar SECCIÓN

DESCRIPCIÓN

Lista las rutas de configuración y las secciones de configuración y muestra la salida analizada.

Esta herramienta se puede utilizar para obtener una visión general del archivo de configuración que será analizado por el servidor y los clientes de PipeWire.

OPCIONES COMUNES

-h | --help

Muestra la ayuda.

--version

Muestra información de la versión.

-n | --name=NOMBRE

Nombre de la configuración (por defecto 'pipewire.conf')

-p | --prefix=PREFIJO

Prefijo de configuración (por defecto '')

-L | --no-newline

Omite saltos de línea después de los valores

-r | --recurse

Reforma las secciones de configuración recursivamente

-N | --no-colors

Deshabilita la salida de color

-C | -color[=CUÁNDO]

si habilita el soporte de color. CUÁNDO es nunca, siempre o automático

LISTADO DE RUTAS

Especifique el comando rutas. Mostrará todos los archivos de configuración que se analizarán y en qué orden.

LISTADO DE SECCIONES DE CONFIGURACIÓN

Especifique el comando listar con una SECCIÓN opcional para listar los fragmentos de configuración utilizados para la SECCIÓN. Sin una SECCIÓN, se listarán todas las secciones.

Use las opciones -r para reformar las secciones.

FUSIÓN DE UNA SECCIÓN DE CONFIGURACIÓN

Con la opción fusionar y una SECCIÓN, pw-config fusionará todos los archivos de configuración en una sección de configuración fusionada y volcará los resultados. Esta será la sección utilizada por el cliente o servidor.

Use las opciones -r para reformar las secciones.

EJEMPLOS

pw-config

Lista todos los archivos de configuración que se utilizarán

pw-config -n pipewire-pulse.conf

Lista todos los archivos de configuración que serán utilizados por el servidor pulseaudio de PipeWire.

pw-config -n pipewire-pulse.conf list

Lista todas las secciones de configuración utilizadas por el servidor pulseaudio de PipeWire.

pw-config -n jack.conf list context.properties

Lista los fragmentos de context.properties utilizados por los clientes JACK.

pw-config -n jack.conf merge context.properties

Lista el context.properties fusionado utilizado por los clientes JACK.

pw-config -n pipewire.conf -r merge context.modules

Lista el context.modules fusionado utilizado por el servidor PipeWire y reforma.
