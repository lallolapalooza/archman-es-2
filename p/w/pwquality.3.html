PWQUALITY(3) Manual de la API de Libpwquality PWQUALITY(3)

NOMBRE

pwquality - Documentación de la API de libpwquality

SINOPSIS

#include <pwquality.h>
pwquality_settings_t *pwquality_default_settings(void);
void pwquality_free_settings(pwquality_settings_t *pwq);
int pwquality_read_config(pwquality_settings_t *pwq, const char *cfgfile,
       void **auxerror);
int pwquality_set_option(pwquality_settings_t *pwq, const char *option);
int pwquality_set_int_value(pwquality_settings_t *pwq, int setting, int value);
int pwquality_set_str_value(pwquality_settings_t *pwq, int setting,
       const char *value);
int pwquality_get_int_value(pwquality_settings_t *pwq, int setting, int *value);
int pwquality_get_str_value(pwquality_settings_t *pwq, int setting, const char **value);
int pwquality_generate(pwquality_settings_t *pwq, int entropy_bits,
       char **password);
int pwquality_check(pwquality_settings_t *pwq, const char *password,
       const char *oldpassword, const char *user, void **auxerror);
const char *pwquality_strerror(char *buf, size_t len, int errcode, void *auxerror);

DESCRIPCIÓN

La función pwquality_default_settings() asigna y devuelve la configuración predeterminada de pwquality para ser utilizada en otras llamadas a la biblioteca. La estructura opaca asignada debe liberarse con la llamada pwquality_free_settings().

pwquality_read_config() analiza el archivo de configuración (si cfgfile es NULL, entonces el predeterminado). Si auxerror no es NULL, también puede devolver información auxiliar de errores que debe pasarse a la función pwquality_strerror().

Nuevo en 1.3.0:
La biblioteca primero intenta analizar todos los archivos de configuración *.conf del directorio <cfgfile>.d si existe. El orden del análisis determina qué valores estarán en vigor; el último gana.

La función pwquality_set_option() es útil para establecer las opciones configuradas en la línea de comandos del módulo pam en forma de opt=val.

Las funciones de obtención y establecimiento de valores enteros y de cadena individuales son: pwquality_set_int_value(), pwquality_set_str_value(), pwquality_get_int_value() y pwquality_get_str_value(). En el caso del método de obtención de cadenas, el llamador debe copiar la cadena antes de que otras llamadas puedan manipular el objeto de configuración pwq.

La función pwquality_generate() genera una contraseña aleatoria de entropy_bits de entropía y la verifica según la configuración. El *password es asignado en el heap por la biblioteca. El valor entropy_bits se ajusta para que encaje dentro del rango de PWQ_MIN_ENTROPY_BITS y PWQ_MAX_ENTROPY_BITS antes de generar una contraseña.

La función pwquality_check() verifica la password según la configuración. Devuelve una puntuación (valor entre 0 y 100), un número de error negativo y, posiblemente, información auxiliar de errores que debe pasarse a la función pwquality_strerror(). La oldpassword es opcional y puede ser NULL. El user se utiliza para verificar la password contra el nombre de usuario y, potencialmente, otra información de passwd(5) y puede ser NULL. El auxerror puede ser NULL; en ese caso, no se devuelve información auxiliar de errores. Sin embargo, si no es NULL, no pasar el *auxerror devuelto a pwquality_strerror() puede provocar fugas de memoria.

La puntuación de una contraseña depende del valor de la configuración PWQ_SETTING_MIN_LENGTH. Si se establece más alto, la puntuación para las mismas contraseñas será menor.

La función pwquality_strerror() traduce el errcode y los datos auxiliares auxerror en un mensaje de texto localizado. Si buf es NULL, la función utiliza un búfer estático interno, lo que hace que la función no sea reentrante en ese caso. El puntero devuelto no está garantizado que apunte a buf. La función libera los datos eventuales de auxerror que se le pasan, por lo tanto, no debe llamarse dos veces con los mismos datos de auxerror.

VALORES DE RETORNO

En general, las funciones que devuelven int devuelven 0 como valor de éxito y valores negativos como código de error concreto de PWQ_ERROR. pwquality_strerror() no asigna datos y por lo tanto no puede fallar.

La puntuación positiva o cero devuelta por pwquality_check() no debe utilizarse para rechazar contraseñas; solo debe utilizarse como indicador aproximado de la entropía presente en la contraseña, con valores como 0-30 siendo bajos, 30-60 medios y 60-100 altos.

EJEMPLO

Uso típico de la API de libpwquality:

#include <pwquality.h>
...
       pwquality_settings_t *pwq;
       int rv;
       void *auxerror;
       char buf[PWQ_MAX_ERROR_MESSAGE_LEN];
       pwq = pwquality_default_settings();
       if (pwq == NULL) {
               fprintf(stderr, "Error: %s\n", pwquality_strerror(buf, sizeof(buf), PWQ_ERROR_MEM_ALLOC, NULL));
               return -1;
       }

       if ((rv=pwquality_read_config(pwq, NULL, &auxerror)) != 0) {
               pwquality_free_settings(pwq);
               fprintf(stderr, "Error: %s\n", pwquality_strerror(buf, sizeof(buf), rv, auxerror));
               return -1;
       }

       rv = pwquality_check(pwq, buf, NULL, user, &auxerror);
       pwquality_free_settings(pwq);
       if (rv >= 0) {
               fprintf(stderr, "La puntuación de entropía de la contraseña es: %d\n", rv);
       } else {
               fprintf(stderr, "La contraseña es rechazada con el error: %s\n", pwquality_strerror(buf, sizeof(buf), rv, auxerror));
       }
