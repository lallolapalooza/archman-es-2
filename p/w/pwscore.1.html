PWSCORE(1) Manual de Comandos Generales PWSCORE(1)

NOMBRE

pwscore - herramienta simple configurable para verificar la calidad de una contraseña

SINOPSIS

pwscore [usuario]

DESCRIPCIÓN

pwscore es una herramienta simple para verificar la calidad de una contraseña. La contraseña se lee desde la entrada estándar.

La herramienta utiliza la biblioteca libpwquality para realizar comprobaciones configurables de longitud mínima, comprobación de diccionario contra diccionarios cracklib y otras comprobaciones.

Informa un error si la contraseña falla alguna de las comprobaciones, o imprime la puntuación de calidad de la contraseña como un valor entero entre 0 y 100.

La puntuación de calidad de la contraseña es relativa a la configuración minlen en el archivo de configuración. Pero en general, los valores por debajo de 50 pueden considerarse de calidad moderada y por encima de calidad bastante fuerte. Cualquier contraseña que pase las comprobaciones de calidad (especialmente la comprobación obligatoria de cracklib) debería resistir ataques de diccionario y las puntuaciones superiores a 50 con la configuración predeterminada de minlen incluso ataques de fuerza bruta rápidos.

OPCIONES

El primer y único argumento opcional es el nombre de usuario que se utiliza para comprobar la similitud de la contraseña con el nombre de usuario.

ARCHIVOS

/etc/security/pwquality.conf - El archivo de configuración para la biblioteca libpwquality.

CÓDIGOS DE RETORNO

pwscore devuelve 0 en caso de éxito, distinto de cero en caso de error.

VEA TAMBIÉN

pwscore(1), pwquality.conf(5), pam_pwquality(8)
