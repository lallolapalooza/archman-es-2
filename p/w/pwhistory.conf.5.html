NOMBRE

pwhistory.conf - archivo de configuración de pam_pwhistory

DESCRIPCIÓN

pwhistory.conf proporciona una forma de configurar los ajustes predeterminados para guardar las últimas contraseñas de cada usuario. Este archivo es leído por el módulo pam_pwhistory y es el método preferido sobre la configuración directa de pam_pwhistory.

El archivo tiene un formato muy simple de nombre = valor con posibles comentarios que comienzan con el carácter #. Se ignora el espacio en blanco al principio de la línea, al final de la línea y alrededor del signo =.

OPCIONES

debug

Activa la depuración a través de syslog(3).

enforce_for_root

Si esta opción está establecida, la comprobación se aplica también a root.

remember=N

Se guardan las últimas N contraseñas de cada usuario. El valor predeterminado es 10. Un valor de 0 hace que el módulo mantenga sin cambios el contenido existente del archivo opasswd.

retry=N

Solicita al usuario como máximo N veces antes de devolver un error. El valor predeterminado es 1.

file=/ruta/nombre_archivo

Almacena el historial de contraseñas en el archivo /ruta/nombre_archivo en lugar de la ubicación predeterminada. La ubicación predeterminada es /etc/security/opasswd.

EJEMPLOS

Ejemplo de archivo /etc/security/pwhistory.conf:

debug
remember=5
file=/tmp/opasswd

ARCHIVOS

/etc/security/pwhistory.conf

el archivo de configuración para opciones personalizadas
