NOMBRE

ppmdither - difuminado ordenado para imágenes en color

SINOPSIS

ppmdither

[-dim=potencia]

[-red=n]

[-green=n]

[-blue=n]

[archivo netpbm]

Todas las opciones se pueden abreviar a su prefijo único más corto. Puede usar dos guiones en lugar de uno para designar una opción. Puede usar espacio en blanco o un signo igual entre el nombre de la opción y su valor.

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ppmdither lee una imagen Netpbm como entrada, y le aplica un difuminado para reducir el número de colores utilizados al número especificado de tonos para cada primario. Produce una imagen PPM como salida.

El número predeterminado de tonos es 5 rojo, 9 verde y 5 azul, para un total de 225 colores. Para convertir la imagen a un formato rgb binario adecuado para impresoras de color primitivas, use -red=2 -green=2 -blue=2.

Puede hacer otro tipo de difuminado — Floyd-Steinberg — con pnmquant o pnmremap.

OPCIONES

-dim potencia

El tamaño de la matriz de difuminado. La matriz de difuminado es un cuadrado cuya dimensión es una potencia de 2. potencia es esa potencia de 2. El valor predeterminado es 4, para una matriz de 16 por 16.
-red=n
El número de tonos rojos a utilizar, incluido el negro; mínimo de 2.

El valor predeterminado es 5.

-green n
El número de tonos verdes a utilizar, incluido el negro; mínimo de 2.

El valor predeterminado es 9.

-blue n
El número de tonos azules a utilizar, incluido el negro; mínimo de 2.

El valor predeterminado es 5.
