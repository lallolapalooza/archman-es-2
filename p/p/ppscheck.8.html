NOMBRE

ppscheck - herramienta para verificar un puerto serie en busca de PPS

SINOPSIS

ppscheck [-?] [--help] [-p] [--pps] [--version] [-h] [-V]

ppscheck [-m] dispositivo

DESCRIPCIÓN

ppscheck monitoriza un puerto serie especificado en busca de transiciones que puedan ser PPS. Busca cambios en las líneas de handshake CD, CTS, DSR e RI ejecutando ioctl(...., TIOCMIWAIT, ...) en un bucle. Cuando detecta un cambio de estado, emite una línea de salida con marca de tiempo que vuelca el estado de las señales de handshake. Es útil para verificar si un dispositivo está emitiendo PPS.

ppscheck puede ejecutarse como un usuario normal, pero dicho usuario debe tener permisos para leer el dispositivo de destino. La ejecución bajo sudo puede o no funcionar. La ejecución como root siempre funcionará.

Para verificar el primer puerto serie, haga esto:

# ppscheck /dev/ttyS0

Como efecto secundario, ppscheck intentará crear el dispositivo /dev/ppsX correspondiente estableciendo la disciplina de línea (ldisc) a N_PPS (18). Debería tener entonces un dispositivo /dev/pps0. Tenga en cuenta que no todos los dispositivos serie soportan ldisc N_PPS.

Ahora puede usar ppscheck para ver si la interfaz KPPS (RFC 2783) está funcionando:

# ppscheck /dev/pps0

ppscheck no está diseñado para un uso rutinario, sino para fines de diagnóstico. Una vez que haya verificado que un dispositivo particular puede emitir señales PPS, nunca más necesitará usarlo en ese dispositivo.

OPCIONES

El programa acepta las siguientes opciones:

-?, `-h, `--help

Imprime el mensaje de ayuda y luego sale.

-m, `--match

Encuentra el dispositivo PPS que coincide con dispositivo.

-p, `--pps

Imprime los dispositivos PPS activos y luego sale.

-V, `--version

Muestra la versión y luego sale.

-x SEC, --seconds SEC

Sale después de un retraso de SEC segundos.

ARGUMENTOS

El argumento dispositivo debe ser la ruta a un dispositivo. Como /dev/ttyS0 o /dev/pps0. Será el dispositivo monitorizado.

Para un dispositivo tty, cada línea de salida son las partes de segundo y nanosegundo de una marca de tiempo seguida de los nombres de las señales de handshake que se activaron. Las transiciones de apagado pueden generar líneas sin señales activadas.

Para un dispositivo pps, cada línea de salida contendrá los tiempos de activación y desactivación detectados por última vez por KPPS.

Si no ve salida en un segundo, use cgps, xgps o alguna otra herramienta equivalente para verificar que su dispositivo tiene un bloqueo de satélite y está obteniendo correcciones 3D antes de renunciar a la posibilidad de PPS.

Revise su cable. Los cables baratos DB9 a DB9, como los que se suministran con los UPS, a menudo solo llevan TXD/RXD/GND, omitiendo las líneas de handshake como CD. ¡Sospeche esto especialmente si la cubierta del cable parece demasiado delgada para contener más de tres cables!

La mayoría de los GPS que tienen USB integrado no soportan PPS. En caso de duda, póngase en contacto con el proveedor para confirmar que su dispositivo proporciona PPS.

VALORES DE RETORNO

0

OK

1

si el dispositivo no pudo ser abierto, o algún otro fallo
