NOMBRE

pprof - página del manual para pprof (parte de gperftools)

SINOPSIS

pprof [opciones] <programa> <perfil>

DESCRIPCIÓN

Imprime el perfil de CPU o heap especificado

OPCIONES

--cum
Ordenar por datos acumulados
--base=<base>
Restar <base> de <perfil> antes de mostrar

Nivel de granularidad del informe:

--addresses
Informar a nivel de dirección
--lines
Informar a nivel de línea de código fuente
--functions
Informar a nivel de función [predeterminado]
--files
Informar a nivel de archivo de código fuente

Tipo de salida:

--text
Generar informe de texto [predeterminado]
--gv
Generar Postscript y mostrar
--list=<regexp>
Generar listado de código fuente de rutinas coincidentes
--disasm=<regexp>
Generar desensamblado de rutinas coincidentes
--dot
Generar archivo DOT a stdout
--ps
Generar Postscript a stdout
--pdf
Generar PDF a stdout
--gif
Generar GIF a stdout

Opciones del perfil de heap:

--inuse_space
Mostrar bytes (mega) en uso [predeterminado]
--inuse_objects
Mostrar objetos en uso
--alloc_space
Mostrar bytes (mega) asignados
--alloc_objects
Mostrar objetos asignados
--show_bytes
Mostrar espacio en bytes
--drop_negative
Ignorar diferencias negativas

Opciones del grafo de llamadas:

--nodecount=<n>
Mostrar como máximo tantos nodos [predeterminado=80]
--nodefraction=<f>
Ocultar nodos por debajo de <f>*total [predeterminado=.005]
--edgefraction=<f>
Ocultar aristas por debajo de <f>*total [predeterminado=.001]
--focus=<regexp>
Enfocar en nodos que coinciden con <regexp>
--ignore=<regexp>
Ignorar nodos que coinciden con <regexp>
--scale=<n>
Establecer escala GV [predeterminado=0]

EJEMPLOS

pprof /bin/ls ls.prof

Genera una línea por procedimiento

pprof --gv /bin/ls ls.prof

Muestra el grafo de llamadas anotado a través de 'gv'

pprof --gv --focus=Mutex /bin/ls ls.prof

Restringe a rutas de código que incluyen una entrada .*Mutex.*

pprof --gv --focus=Mutex --ignore=string /bin/ls ls.prof

Rutas de código que incluyen Mutex pero no string

pprof --list=getdir /bin/ls ls.prof

Desensamblado (con anotaciones por línea) para getdir()

pprof --disasm=getdir /bin/ls ls.prof

Desensamblado (con anotaciones por PC) para getdir()
