CPPTRS

Propósito:

!>
!> CPPTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> Hermítica positiva definida A en almacenamiento empaquetado usando la
!> factorización de Cholesky A = U**H*U o A = L*L**H calculada por CPPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array de COMPLEX, dimensión (N*(N+1)/2)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, empaquetado por columnas en un array
!>          lineal. La j-ésima columna de U o L está almacenada en el array AP
!>          de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.
!>

B

!>          B es un array de COMPLEX, dimensión (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

NAME

ZPPTRS - ZPPTRS resuelve un sistema de ecuaciones lineales A*X = B...

SYNOPSIS

SUBROUTINE ZPPTRS(UPLO, N, NRHS, AP, B, LDB, INFO)
    CHARACTER UPLO
    INTEGER N, NRHS, LDB, INFO
    COMPLEX*16 AP(*), B(LDB,*)

Detailed Description

ZPPTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz hermitiana positiva definida A en almacenamiento empaquetado usando la factorización de Cholesky A = U**H * U o A = L * L**H calculada por ZPPTRF.

Parmeters

UPLO: CHARACTER*1

          = 'U': El triángulo superior de A está almacenado;
          = 'L': El triángulo inferior de A está almacenado.

N: INTEGER

          El orden de la matriz A.  N >= 0.

NRHS: INTEGER

          El número de lados derechos, es decir, el número de columnas
          de la matriz B.  NRHS >= 0.

AP: COMPLEX*16 array, dimension (N*(N+1)/2)

          El factor triangular U o L de la factorización de Cholesky
          A = U**H * U o A = L * L**H, empaquetado columna a columna en una
          matriz lineal. La j-ésima columna de U o L se almacena en la
          matriz AP como sigue:
          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.

B: COMPLEX*16 array, dimension (LDB,NRHS)

          En la entrada, la matriz de lados derechos B.
          En la salida, la matriz solución X.

LDB: INTEGER

          La dimensión principal de la matriz B.  LDB >= max(1,N).

INFO: INTEGER

          = 0:  salida exitosa
          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
