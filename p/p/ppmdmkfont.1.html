NOMBRE

ppmdmkfont - Crear fuente Ppmdfont 'standard'.

SINOPSIS

ppmdmkfont

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

ppmdmkfont crea la fuente Ppmdfont 'standard' como un archivo Ppmdfont. No tiene entrada; siempre genera archivos idénticos.

(No hay argumentos ni opciones)

Este programa es útil principalmente como ejemplo para crear otras fuentes. libnetpbm tiene la fuente 'standard' integrada.

Ver LibnetpbmPPMDrawingFunction Manual (1)
para detalles sobre los archivos Ppmdfont.
