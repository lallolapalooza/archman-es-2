subrutina cpptri (uplo caracter, n entero, complejo, dimensión( * ) ap, info entero)

CPPTRI

Propósito:

!>
!> CPPTRI calcula la inversa de una matriz compleja hermitiana definida positiva
!> A utilizando la factorización de Cholesky A = U**H*U o A = L*L**H
!> calculada por CPPTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': el factor triangular superior se almacena en AP;
!>          = 'L': el factor triangular inferior se almacena en AP.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX, dimensión (N*(N+1)/2)
!>          En la entrada, el factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H, empaquetado por columnas como
!>          un array lineal. La j-ésima columna de U o L se almacena en el
!>          array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) para j<=i<=n.
!>
!>          En la salida, el triángulo superior o inferior de la inversa (hermitiana)
!>          de A, sobrescribiendo el factor de entrada U o L.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el elemento (i,i) del factor U o L es
!>                cero, y la inversa no pudo ser calculada.
!>

zpptri.f - LAPACK

NAME

zpptri.f

SYNOPSIS

 subroutine zpptri(UPLO, N, AP, INFO)
 
 !> @brief **ZPPTRI** computes the inverse of a complex-valued general
 !> matrix.
 !>
 !> @details This routine is intended for general use. It is used to compute
 !> the inverse of a complex-valued general matrix A.
 !>
 !> @param[in] UPLO
 !> Character*1. Specifies whether the matrix A is upper or lower
 !> triangular, as follows:
 !> 'U' <-> A is upper triangular
 !> 'L' <-> A is lower triangular
 !>
 !> @param[in] N
 !> Integer. The order of the matrix A. N >= 0.
 !>
 !> @param[in,out] AP
 !> Complex*16 array, dimension (N*(N+1)/2).
 !> On entry, the upper or lower triangular part of the matrix A,
 !> packed column-wise in a one-dimensional array. The elements of the
 !> triangular part are those in the upper triangle if UPLO = 'U', or
 !> those in the lower triangle if UPLO = 'L'.
 !> On exit, the upper or lower triangular part of the inverse of A.
 !>
 !> @param[out] INFO
 !> Integer.
 !> = 0:  successful exit
 !> < 0:  if INFO = -k, the k-th argument had an internal error
 !> > 0:  if INFO = k, the k-th diagonal element of the factor U or L
 !> is zero, and the inverse could not be computed.
 !>
 !> @warning This routine is part of the LAPACK routines for computing
 !> the inverse of a complex-valued general matrix. It is intended for
 !> general use.
 !>
 !> @note The elements of AP are stored in column-major order.
 !> The diagonal elements are stored first, followed by the elements
 !> above or below the diagonal.
 !>
 !> @see zppsv.f
 !> @see zppsvd.f
 !> @see zppsvx.f
 !>
 !> @bug If INFO > 0, the k-th diagonal element of the factor U or L
 !> is zero, and the inverse could not be computed.

Detailed Description

This routine is intended for general use. It is used to compute the inverse of a complex-valued general matrix A.

The elements of the matrix A are stored in a packed format. This means that the elements of the upper or lower triangular part of A are stored in a one-dimensional array AP.

The elements of AP are stored in column-major order. The diagonal elements are stored first, followed by the elements above or below the diagonal.

For example, if UPLO = 'U', the elements of AP are stored as follows:

 AP(1) = A(1,1)
 AP(2) = A(1,2)
 AP(3) = A(2,2)
 AP(4) = A(1,3)
 AP(5) = A(2,3)
 AP(6) = A(3,3)
 ...

If UPLO = 'L', the elements of AP are stored as follows:

 AP(1) = A(1,1)
 AP(2) = A(2,1)
 AP(3) = A(2,2)
 AP(4) = A(3,1)
 AP(5) = A(3,2)
 AP(6) = A(3,3)
 ...
