NOMBRE

ppmtoyuv - convertir una imagen PPM a un archivo YUV de Abekas

SINOPSIS

ppmtoyuv [archivo.ppm]

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ppmtoyuv lee una imagen PPM como entrada y produce un archivo YUV de Abekas como salida.

El archivo de salida contiene una cuadrícula de códigos YUV de cuatro bytes, cada uno asociado de forma única a dos píxeles adyacentes en la imagen. La cuadrícula contiene filas en orden de arriba a abajo y, dentro de cada fila, columnas de izquierda a derecha. Por lo tanto, el tamaño del archivo de salida en bytes es el doble del número de píxeles de la imagen.

Cada código YUV se asocia con dos píxeles de la imagen de entrada que llamaremos el píxel izquierdo y el píxel derecho. El segundo byte del código es el valor Y del píxel izquierdo. El cuarto byte del código es el valor Y del píxel derecho. El primer byte del código es un promedio de los valores U del píxel *a la izquierda del píxel izquierdo*, el píxel izquierdo y el píxel derecho. El tercer byte del código es análogo para los valores V. Estos promedios son medias aritméticas ponderadas donde el píxel izquierdo tiene el doble de peso que los otros dos píxeles.

Este formato recuerda al formato común YUV 4:2:0 (también conocido como YUV 420) y a los similares YUV 4:4:4, YUV 4:2:2, YUV 4:1:1, YUV 4:1:1s y YUV 4:1:0, pero es bastante diferente. En YUV 4:2:0, la cuadrícula es diferente para las líneas de número par e impar. En las líneas de número par, hay el doble de bits para Y de cada píxel que para U o V. En las líneas de número impar, hay la misma cantidad de bits para Y que en las líneas de número par, pero ningún bit para U y V.

Otro formato basado en YUV es YUV4MPEG2, que es un formato de película que se usa normalmente con MJPEGTools. Netpbm no tiene conversores para este formato, pero MJPEGTools sí los tiene.
