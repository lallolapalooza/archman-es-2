NAME

DPPRFS, SPPRFS, CPPRFS, ZPPRFS - compute error bounds for the solution of a packed symmetric positive-definite system of equations

DESCRIPTION

The subroutines compute an estimation of the error bounds and backward errors in the solution to a system of linear equations A*X = B, where A is a symmetric positive-definite packed matrix. Iterative refinement is used to improve the computed solution X, and error bounds are returned for the refined solution.

The packed storage scheme is described in the manual for the `*PPFA' routines.

The routines first compute the forward error bound FERR(j) for each solution vector X(:,j), and then compute the componentwise backward error BERR(j) for each solution vector X(:,j).

The iterative refinement is performed by the following algorithm:

  1. Compute the residual R = B - A*X.
  2. If the residual is acceptable, go to step 5.
  3. Update the solution, X = X + deltaX, where deltaX is the solution to A*deltaX = R.
  4. Go to step 1.
  5. Compute error bounds FERR and BERR.

If the matrix A is not positive definite, the procedure may fail. The iterative refinement algorithm requires that the matrix A is positive definite.

Note that the complex subroutines CPPRFS and ZPPRFS differ in that they return the error bounds as DOUBLE PRECISION arrays, and use a REAL array WORK and a DOUBLE PRECISION array RWORK.

INTRODUCTION

This section describes the subroutines DPPRFS, SPPRFS, CPPRFS, and ZPPRFS. These subroutines are used to compute error bounds for the solution of a system of linear equations where the coefficient matrix is packed and symmetric positive-definite.

ARGUMENTS

UPLO

UPLO is CHARACTER*1
Specifies whether the upper or lower triangular part of the packed
matrix A is stored in the array AP.
= 'U': Upper triangle stored.
= 'L': Lower triangle stored.

N

N is INTEGER
The order of the matrix A. N >= 0.

NRHS

NRHS is INTEGER
The number of right hand sides, i.e., the number of columns of the
matrices B and X. NRHS >= 0.

AP

AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
(For SPPRFS: REAL array, dimension (N*(N+1)/2))
(For CPPRFS: COMPLEX array, dimension (N*(N+1)/2))
(For ZPPRFS: COMPLEX*16 array, dimension (N*(N+1)/2))
The upper or lower triangle of the symmetric (or Hermitian) matrix A,
packed columnwise in a linear array. The j-th column of A is stored
in the array AP as follows:
if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.

AFP

AFP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
(For SPPRFS: REAL array, dimension (N*(N+1)/2))
(For CPPRFS: COMPLEX array, dimension (N*(N+1)/2))
(For ZPPRFS: COMPLEX*16 array, dimension (N*(N+1)/2))
The triangular factor U or L from the Cholesky factorization
A = U**T*U (or A = U**H*U) or A = L*L**T (or A = L*L**H),
as computed by DPPTFA/SPPTFA (or CPPTFA/ZPPTFA) or DPPTRF/SPPTRF
(or CPPTRF/ZPPTRF), packed columnwise in a linear array in the
same format as A (see AP).

B

B is DOUBLE PRECISION array, dimension (LDB,NRHS)
(For SPPRFS: REAL array, dimension (LDB,NRHS))
(For CPPRFS: COMPLEX array, dimension (LDB,NRHS))
(For ZPPRFS: COMPLEX*16 array, dimension (LDB,NRHS))
The right hand side matrix B.

LDB

LDB is INTEGER
The leading dimension of the array B. LDB >= max(1,N).

X

X is DOUBLE PRECISION array, dimension (LDX,NRHS)
(For SPPRFS: REAL array, dimension (LDX,NRHS))
(For CPPRFS: COMPLEX array, dimension (LDX,NRHS))
(For ZPPRFS: COMPLEX*16 array, dimension (LDX,NRHS))
On entry, the solution matrix X, as computed by DPPTSS/SPPTSS
(or CPPTSS/ZPPTSS) or DPPTRS/SPPTRS (or CPPTRS/ZPPTRS).
On exit, the improved solution matrix X.

LDX

LDX is INTEGER
The leading dimension of the array X. LDX >= max(1,N).

FERR

FERR is DOUBLE PRECISION array, dimension (NRHS)
(For CPPRFS and ZPPRFS: DOUBLE PRECISION array, dimension (NRHS))
The estimated forward error bound for each solution vector
X(j) (the j-th column of the solution matrix X).
If XTRUE is the true solution corresponding to X(j), FERR(j)
is an estimated upper bound for the magnitude of the largest
element in (X(j) - XTRUE) divided by the magnitude of the
largest element in X(j). The estimate is as reliable as
the estimate for RCOND, and is almost always a slight
overestimate of the true error.

BERR

BERR is DOUBLE PRECISION array, dimension (NRHS)
(For CPPRFS and ZPPRFS: DOUBLE PRECISION array, dimension (NRHS))
The componentwise relative backward error of each solution
vector X(j) (i.e., the smallest relative change in
any element of A or B that makes X(j) an exact solution).

WORK

WORK is DOUBLE PRECISION array, dimension (3*N)
(For SPPRFS: REAL array, dimension (3*N))
(For CPPRFS: COMPLEX array, dimension (3*N))
(For ZPPRFS: COMPLEX*16 array, dimension (3*N))

IWORK

IWORK is INTEGER array, dimension (N)
(Only for DPPRFS and SPPRFS)

RWORK

RWORK is DOUBLE PRECISION array, dimension (N)
(Only for CPPRFS and ZPPRFS)

INFO

INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value

Internal Parameters:

ITMAX is the maximum number of steps of iterative refinement.

SUBROUTINE PPRFS( UPLO, N, NRHS, AB, LDAB, B, LDB, X, LDX, FERR, BERR, EERR, WORK, RWORK, INFO )

Purpose

PPRFS applies a 1-norm approximation to the error bounds on the solution of a symmetric positive definite tridiagonal system of equations.

Arguments

UPLO
CHARACTER*1

Specifies whether the matrix AB is upper or lower tridiagonal. UPLO = ‘U’ or ‘u’ indicates upper tridiagonal. UPLO = ‘L’ or ‘l’ indicates lower tridiagonal.

N
INTEGER

The order of the matrix AB. N >= 0.

NRHS
INTEGER

The number of right hand sides, i.e., the number of systems to solve.

AB
COMPLEX*16 array, dimension (LDAB,N)

The 2D-array representation of the tridiagonal matrix AB. This matrix is represented as:

    if UPLO = 'U' or 'u' then
        AB(1,j) = A(j,j)
        AB(2,j) = A(j,j+1)
    else if UPLO = 'L' or 'l' then
        AB(1,j) = A(j,j)
        AB(2,j) = A(j+1,j)
    endif

Here A(i,j) denotes the element of the original matrix in row i and column j.

LDAB
INTEGER

The leading dimension of the array AB. LDAB >= 2.

B
COMPLEX*16 array, dimension (LDB,NRHS)

The right hand side matrix B.

LDB
INTEGER

The leading dimension of the array B. LDB >= max(1,N).

X
COMPLEX*16 array, dimension (LDX,NRHS)

The matrix of computed solutions X.

LDX
INTEGER

The leading dimension of the array X. LDX >= max(1,N).

FERR
DOUBLE PRECISION array, dimension (NRHS)

On exit, FERR(j) contains an estimate of the relative forward error in the j-th solution vector, and is computed at the i-th iteration as norm(B - A*X) / (norm(A) * norm(X)).

BERR
DOUBLE PRECISION array, dimension (NRHS)

On exit, BERR(j) contains an estimate of the relative backward error, and is computed at the i-th iteration as norm(B - A*X) / (norm(B) * norm(A) * norm(X)).

EERR
DOUBLE PRECISION array, dimension (NRHS)

On exit, EERR(j) contains an estimate of the smallest relative perturbation in either the array A or the array B, that must be made in order for the approximate solution X to be exact.

WORK
COMPLEX*16 array, dimension (2*N)

Workspace array. The diagonal elements of AB are saved in WORK and the subdiagonal elements are saved in WORK(N+1)...WORK(2*N-1).

RWORK
DOUBLE PRECISION array, dimension (N)

Workspace array.

INFO
INTEGER

INFO = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value
