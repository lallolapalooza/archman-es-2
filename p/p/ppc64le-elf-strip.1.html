NOMBRE

strip - descarta símbolos y otros datos de los archivos objeto

SINOPSIS

strip [-F nombre_bfd |--target=nombre_bfd]
[-I nombre_bfd |--input-target=nombre_bfd]
[-O nombre_bfd |--output-target=nombre_bfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nombre_simbolo|--keep-symbol=nombre_simbolo]
[-M|--merge-notes][--no-merge-notes]
[-N nombre_simbolo |--strip-symbol=nombre_simbolo]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nombre_seccion |--remove-section=nombre_seccion]
[--keep-section=patron_seccion]
[--remove-relocations=patron_seccion]
[--strip-section-headers]
[-o archivo] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
archivo_objeto...

DESCRIPCION

GNU strip descarta todos los símbolos de los archivos objeto archivo_objeto. La lista de archivos objeto puede incluir archivos mancomunados (archives). Debe proporcionarse al menos un archivo objeto.

strip modifica los archivos especificados en sus argumentos, en lugar de escribir copias modificadas con nombres diferentes.

OPCIONES

-F nombre_bfd
--target=nombre_bfd
Trata el archivo_objeto original como un archivo con el formato de código objeto nombre_bfd, y lo reescribe en el mismo formato.
--help
Muestra un resumen de las opciones de strip y sale.
--info
Muestra una lista con todas las arquitecturas y formatos de objeto disponibles.
-I nombre_bfd
--input-target=nombre_bfd
Trata el archivo_objeto original como un archivo con el formato de código objeto nombre_bfd.
-O nombre_bfd
--output-target=nombre_bfd
Reemplaza archivo_objeto con un archivo en el formato de salida nombre_bfd.
-R nombre_seccion
--remove-section=nombre_seccion
Elimina cualquier sección llamada nombre_seccion del archivo de salida, además de las secciones que de otra manera serían eliminadas. Esta opción puede darse varias veces. Tenga en cuenta que el uso inadecuado de esta opción puede hacer que el archivo de salida sea inutilizable. El carácter comodín * puede darse al final de nombre_seccion. Si es así, se eliminará cualquier sección que comience con nombre_seccion.

Si el primer carácter de patron_seccion es el signo de exclamación (!) entonces las secciones que coincidan no serán eliminadas incluso si un uso anterior de --remove-section en la misma línea de comandos lo haría de otra manera. Por ejemplo:

--remove-section=.text.* --remove-section=!.text.foo

eliminará todas las secciones que coincidan con el patrón '.text.*', pero no eliminará la sección '.text.foo'.

--keep-section=patron_seccion
Al eliminar secciones del archivo de salida, mantenga las secciones que coincidan con patron_seccion.
--remove-relocations=patron_seccion
Elimina las reubicaciones del archivo de salida para cualquier sección que coincida con patron_seccion. Esta opción puede darse varias veces. Tenga en cuenta que el uso inadecuado de esta opción puede hacer que el archivo de salida sea inutilizable. Se aceptan caracteres comodín en patron_seccion. Por ejemplo: 
--remove-relocations=.text.*

eliminará las reubicaciones de todas las secciones que coincidan con el patrón '.text.*'.

Si el primer carácter de patron_seccion es el signo de exclamación (!) entonces a las secciones que coincidan no se les eliminarán las reubicaciones, incluso si un uso anterior de --remove-relocations en la misma línea de comandos causara de otra manera que se eliminaran las reubicaciones. Por ejemplo:

--remove-relocations=.text.* --remove-relocations=!.text.foo

eliminará todas las reubicaciones para las secciones que coincidan con el patrón '.text.*', pero no eliminará las reubicaciones para la sección '.text.foo'.

--strip-section-headers
Elimina las cabeceras de sección. Esta opción es específica para archivos ELF. Implica --strip-all y --merge-notes.
-s
--strip-all
Elimina todos los símbolos.
-g
-S
-d
--strip-debug
Elimina solo los símbolos de depuración.
--strip-dwo
Elimina el contenido de todas las secciones DWARF .dwo, dejando intactas las secciones de depuración restantes y todos los símbolos. Consulte la descripción de esta opción en la sección objcopy para obtener más información.
--strip-unneeded
Elimina todos los símbolos que no son necesarios para el procesamiento de reubicaciones, además de los símbolos y secciones de depuración que se eliminan con --strip-debug.
-K nombre_simbolo
--keep-symbol=nombre_simbolo
Al eliminar símbolos, mantenga el símbolo nombre_simbolo incluso si normalmente sería eliminado. Esta opción puede darse varias veces.
-M
--merge-notes
--no-merge-notes
Para archivos ELF, intente (o no intente) reducir el tamaño de cualquier sección de tipo SHT_NOTE eliminando notas duplicadas. Por defecto, se intenta esta reducción a menos que se esté eliminando información de depuración o DWO.
-N nombre_simbolo
--strip-symbol=nombre_simbolo
Elimina el símbolo nombre_simbolo del archivo fuente. Esta opción puede darse varias veces y puede combinarse con otras opciones de strip que no sean -K.
-o archivo
Coloca la salida procesada en archivo, en lugar de reemplazar el archivo existente. Cuando se usa este argumento, solo puede especificarse un argumento archivo_objeto.
-p
--preserve-dates
Conserva las fechas de acceso y modificación del archivo.
-D
--enable-deterministic-archives
Opera en modo determinista. Al copiar miembros de archivo y escribir el índice del archivo, usa cero para UID, GID, marcas de tiempo y usa modos de archivo consistentes para todos los archivos.

Si binutils fue configurado con --enable-deterministic-archives, entonces este modo está activado por defecto. Puede ser desactivado con la opción -U, abajo.

-U
--disable-deterministic-archives
No opera en modo determinista. Esto
es la inversa de la opción -D, anterior: al copiar miembros de archivo y escribir el índice del archivo, utiliza sus valores reales de UID, GID, marca de tiempo y modo de archivo.

Este es el valor predeterminado a menos que binutils se haya configurado con --enable-deterministic-archives.

-w
--wildcard
Permite expresiones regulares en los symbolnames utilizados en otras opciones de línea de comandos. Los operadores signo de interrogación (?), asterisco (*), barra invertida (\) y corchetes ([]) se pueden usar en cualquier lugar del nombre del símbolo. Si el primer carácter del nombre del símbolo es el signo de exclamación (!) entonces el sentido del interruptor se invierte para ese símbolo. Por ejemplo: 
-w -K !foo -K fo*

haría que strip solo mantuviera los símbolos que comienzan con las letras "fo", pero descartara el símbolo "foo".

-x
--discard-all
Elimina los símbolos no globales.
-X
--discard-locals
Elimina los símbolos locales generados por el compilador. (Estos suelen comenzar con L o ..)
--keep-section-symbols
Al realizar strip en un archivo, quizás con --strip-debug o --strip-unneeded, conserva cualquier símbolo que especifique nombres de sección, que de otro modo se eliminarían.
--keep-file-symbols
Al realizar strip en un archivo, quizás con --strip-debug o --strip-unneeded, conserva cualquier símbolo que especifique nombres de archivos de origen, que de otro modo se eliminarían.
--only-keep-debug
Realiza strip en un archivo, vaciando el contenido de cualquier sección que no se eliminaría con --strip-debug y dejando intactas las secciones de depuración. En archivos ELF, esto también conserva todas las secciones de notas en la salida.

Nota: las cabeceras de sección de las secciones eliminadas se conservan, incluidos sus tamaños, pero se descarta el contenido de la sección. Las cabeceras de sección se conservan para que otras herramientas puedan relacionar el archivo de información de depuración con el ejecutable real, incluso si ese ejecutable se ha trasladado a un espacio de direcciones diferente.

La intención es que esta opción se utilice junto con --add-gnu-debuglink para crear un ejecutable de dos partes. Una un binario con strip que ocupará menos espacio en RAM y en una distribución, y la segunda un archivo de información de depuración que solo se necesitará si se requieren capacidades de depuración. El procedimiento sugerido para crear estos archivos es el siguiente:

1.<Enlaza el ejecutable normalmente. Suponiendo que se llama>
"foo" entonces...
1.<Ejecuta "objcopy --only-keep-debug foo foo.dbg" para>
crear un archivo que contenga la información de depuración.
1.<Ejecuta "objcopy --strip-debug foo" para crear un>
ejecutable con strip.
1.<Ejecuta "objcopy --add-gnu-debuglink=foo.dbg foo">
para agregar un enlace a la información de depuración en el ejecutable con strip.

Nota: la elección de ".dbg" como extensión para el archivo de información de depuración es arbitraria. Tampoco es obligatorio el paso de "--only-keep-debug". Puedes hacer esto en su lugar:

1.<Enlaza el ejecutable normalmente.>
1.<Copia "foo" a "foo.full">
1.<Ejecuta "strip --strip-debug foo">
1.<Ejecuta "objcopy --add-gnu-debuglink=foo.full foo">

es decir, el archivo al que apunta --add-gnu-debuglink puede ser el ejecutable completo. No tiene que ser un archivo creado con el modificador --only-keep-debug.

Nota: este modificador solo está diseñado para usarse en archivos completamente enlazados. No tiene sentido usarlo en archivos objeto donde la información de depuración puede ser incompleta. Además, la característica gnu_debuglink actualmente solo admite la presencia de un nombre de archivo que contenga información de depuración, no múltiples nombres de archivo de forma individual por archivo objeto.

-V
--version
Muestra el número de versión de strip.
-v
--verbose
Salida detallada: lista todos los archivos objeto modificados. En el caso de los archivos, strip -v lista todos los miembros del archivo.
@file
Lee las opciones de la línea de comandos desde file. Las opciones leídas se insertan en lugar de la opción @file original. Si file no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en file están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción rodeando toda la opción con comillas simples o dobles. Se puede incluir cualquier carácter (incluida una barra invertida) anteponiendo a ese carácter el carácter que se desea incluir. El file puede contener a su vez opciones adicionales @file; dichas opciones se procesarán recursivamente.
