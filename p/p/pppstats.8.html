PPPSTATS(8) Manual del Administrador del Sistema PPPSTATS(8)

NOMBRE

pppstats - mostrar estadísticas de PPP

SINOPSIS

pppstats [ -a ] [ -d ] [ -v ] [ -r ] [ -z ] [ -c <contador> ] [ -w <segundos> ] [ interfaz ]

DESCRIPCIÓN

La utilidad pppstats informa estadísticas relacionadas con PPP a intervalos regulares para la interfaz PPP especificada. Si la interfaz no se especifica, se utilizará ppp0 por defecto. La pantalla se divide horizontalmente en secciones de entrada y salida que contienen columnas de estadísticas que describen las propiedades y el volumen de paquetes recibidos y transmitidos por la interfaz.

Las opciones son las siguientes:

-a
Mostrar valores absolutos en lugar de incrementos. Con esta opción, todos los informes muestran estadísticas desde que se inició el enlace. Sin esta opción, el segundo y posteriores informes muestran estadísticas desde el último informe.
-d
Mostrar la tasa de datos (kB/s) en lugar de bytes.
-c contador
Repetir la visualización contador veces. Si no se especifica esta opción, el contador de repeticiones por defecto es 1 si no se especifica la opción -w, de lo contrario es infinito.
-r
Mostrar estadísticas adicionales que resumen la relación de compresión lograda por el algoritmo de compresión de paquetes en uso.
-v
Mostrar estadísticas adicionales relacionadas con el rendimiento del algoritmo de compresión de cabeceras TCP Van Jacobson.
-w espera
Pausar espera segundos entre cada visualización. Si no se especifica esta opción, el intervalo por defecto es 5 segundos.
-z
En lugar de la visualización estándar, mostrar estadísticas que indican el rendimiento del algoritmo de compresión de paquetes en uso.

Los siguientes campos se imprimen en el lado de entrada cuando no se utiliza la opción -z:

IN
El número total de bytes recibidos por esta interfaz.
PACK
El número total de paquetes recibidos por esta interfaz.
VJCOMP
El número de paquetes TCP con cabeceras comprimidas recibidos por esta interfaz.
VJUNC
El número de paquetes TCP con cabeceras no comprimidas recibidos por esta interfaz. No se informa cuando se especifica la opción -r.
VJERR
El número de paquetes TCP con cabeceras comprimidas corruptos o erróneos recibidos por esta interfaz. No se informa cuando se especifica la opción -r.
VJTOSS
El número de paquetes TCP con cabeceras VJ comprimidas descartados en la recepción por esta interfaz debido a errores previos. Solo se informa cuando se especifica la opción -v.
NON-VJ
El número total de paquetes no TCP recibidos por esta interfaz. Solo se informa cuando se especifica la opción -v.
RATIO
La relación de compresión lograda para los paquetes recibidos por el esquema de compresión de paquetes en uso, definida como el tamaño sin comprimir dividido por el tamaño comprimido. Solo se informa cuando se especifica la opción -r.
UBYTE
El número total de bytes recibidos, después de la descompresión de los paquetes comprimidos. Solo se informa cuando se especifica la opción -r.

Los siguientes campos se imprimen en el lado de salida:

OUT
El número total de bytes transmitidos desde esta interfaz.
PACK
El número total de paquetes transmitidos desde esta interfaz.
VJCOMP
El número de paquetes TCP transmitidos desde esta interfaz con cabeceras TCP comprimidas VJ.
VJUNC
El número de paquetes TCP transmitidos desde esta interfaz con cabeceras TCP no comprimidas VJ. No se informa cuando se especifica la opción -r.
NON-VJ
El número total de paquetes no TCP transmitidos desde esta interfaz. No se informa cuando se especifica la opción -r.
VJSRCH
El número de búsquedas de la entrada de cabecera en caché para un paquete TCP con cabecera VJ comprimida. Solo se informa cuando se especifica la opción -v.
VJMISS
El número de búsquedas fallidas de la entrada de cabecera en caché para un paquete TCP con cabecera VJ comprimida. Solo se informa cuando se especifica la opción -v.
RATIO
La relación de compresión lograda para los paquetes transmitidos por el esquema de compresión de paquetes en uso, definida como el tamaño antes de la compresión dividido por el tamaño comprimido. Solo se informa cuando se especifica la opción -r.
UBYTE
El número total de bytes a transmitir, antes de aplicar la compresión de paquetes. Solo se informa cuando se especifica la opción -r.

Cuando se especifica la opción -z, pppstats muestra en su lugar los siguientes campos, relacionados con el algoritmo de compresión de paquetes actualmente en uso. Si la compresión de paquetes no está en uso, todos estos campos mostrarán ceros. Los campos mostrados en el lado de entrada son:

COMPRESSED BYTE
El número de bytes de paquetes comprimidos recibidos.
COMPRESSED PACK
El número de paquetes comprimidos recibidos.
INCOMPRESSIBLE BYTE
El número de bytes de paquetes incompresibles (es decir, aquellos que se transmitieron sin comprimir) recibidos.
INCOMPRESSIBLE PACK
El número de paquetes incompresibles recibidos.
COMP RATIO
La relación de compresión reciente para los paquetes entrantes, definida como el tamaño sin comprimir dividido por el tamaño comprimido (incluyendo paquetes tanto compresibles como incompresibles).

Los campos mostrados en el lado de salida son:

COMPRESSED BYTE
El número de bytes de paquetes comprimidos transmitidos.
COMPRESSED PACK
El número de paquetes comprimidos transmitidos.
INCOMPRESSIBLE BYTE
El número de bytes de paquetes incompresibles transmitidos (es decir, aquellos que se transmitieron sin comprimir).
INCOMPRESSIBLE PACK
El número de paquetes incompresibles transmitidos.
COMP RATIO
La relación de compresión reciente para los paquetes salientes.

pppstats(8)

NOMBRE

pppstats - Muestra estadísticas para las conexiones PPP

SINOPSIS

pppstats [-a]

DESCRIPCIÓN

El comando pppstats muestra estadísticas para las conexiones PPP. Las estadísticas incluyen el número de paquetes recibidos y transmitidos, y el número de bytes recibidos y transmitidos.

La opción -a muestra estadísticas para todas las interfaces PPP activas.
