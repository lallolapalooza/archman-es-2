PPTPD(8) Manual del Administrador del Sistema PPTPD(8)

NOMBRE

pptpd - Demonio VPN PPTP

SINOPSIS

pptpd [ opciones ]

DESCRIPCIÓN

pptpd es el demonio PPTP de Poptop, que gestiona conexiones PPP en túnel encapsuladas en GRE usando el protocolo VPN PPTP. Puede contener características como gestión de direcciones IP y envolturas TCP si se compila.

OPCIONES

Aquí se documentan las opciones de línea de comandos. Consulte pptpd.conf(5) para directivas de configuración, asignación de direcciones IP, enrutamiento y reglas de firewall.

-b|--bcrelay interfaz-interna
especifica que las difusiones recibidas en la interfaz de red interna del servidor deben ser retransmitidas a los clientes.
-c|--conf archivo-conf
especifica el archivo de configuración para pptpd (por defecto /etc/pptpd.conf)
-d|--debug
activa el modo de depuración, lo que provoca que se envíen más mensajes de depuración a syslog.
-e|--ppp programa-ppp
usa programa-ppp en lugar del predeterminado pppd(8).
-f|--fg
ejecuta en primer plano en lugar de separarse de la terminal.
-h|--help
muestra el uso del programa.
-i|--noipparam
no envía la dirección IP del cliente a los scripts ip-up (requerido si está usando la opción ipparam de pppd(8) para algún otro propósito).
-l|--listen x.x.x.x
especifica la dirección IP de la interfaz local en la que escuchar.
-o|--option archivo-conf-ppp
especifica que pptpd debe especificar un archivo de configuración alternativo para el demonio ppp (el predeterminado suele ser /etc/ppp/options, pero puede variar según su demonio ppp).
-p|--pidfile archivo-pid
especifica una ubicación alternativa para almacenar el archivo de ID de proceso (por defecto /var/run/pptpd.pid).
-s|--speed velocidad
especifica que la velocidad velocidad debe pasarse al demonio ppp como la velocidad de tty a usar (en algunos casos, esto es ignorado por el demonio ppp).
-t|--stimeout segundos
especifica el número de segundos a esperar por el primer paquete antes de desconectar. Esta es una característica de protección contra ataques de denegación de servicio.
-w|--logwtmp
actualiza wtmp(5) cuando los usuarios se conectan y desconectan. Ver wtmp(1).
-C|--connections n
limita el número de conexiones de clientes que pueden ser aceptadas. Corresponde a la opción connections en pptpd.conf. Si pptpd está asignando direcciones IP (por ejemplo, no se usa --delegate), el número de conexiones también está limitado por la opción remoteip en pptpd.conf.
-D|--delegate
delegan la asignación de direcciones IP de cliente a pppd(8). Sin esta opción, que es la predeterminada, pptpd gestiona la lista de direcciones IP para los clientes y pasa la siguiente dirección libre a pppd. Con esta opción, pptpd no pasa una dirección, por lo que pppd puede usar radius o chap-secrets para asignar una dirección.
-V|--vrf nombre-vrf
especifica la VRF a utilizar para escuchar.
-v|--version
muestra la versión actual del demonio pptp.

ARCHIVOS

/etc/pptpd.conf
/var/run/pptpd.pid

DEPURACIÓN

Para activar la depuración, agregue 'debug' a /etc/pptpd.conf y a su archivo de opciones PPP, y reinicie pptpd.

Normalmente, el archivo de opciones PPP es options.pptpd en /etc/ppp, aunque en algunas distribuciones puede ser pptpd-options. Use su gestor de paquetes para encontrarlo, por ejemplo, 'rpm -ql pptpd | grep options' o 'dpkg --listfiles pptpd | grep options'.

Es posible que necesite configurar syslogd para capturar los mensajes de depuración. Por ejemplo, edite /etc/syslog.conf y agregue algo similar al siguiente ejemplo, luego reinicie syslogd.

# registro de depuración
*.debug;mail.none /var/log/debug

Esto registrará toda la información de depuración, excepto correo, en el archivo /var/log/debug. Tenga en cuenta que esta es una gran cantidad de información y podría saturar sus discos. Si el rendimiento es un problema, puede intentar desactivar la sincronización durante la depuración, prefijando el destino con '-'.

# registro de depuración
*.debug;mail.none -/var/log/debug

Deshabilite esta línea y reinicie syslog después de terminar la depuración. Consulte las páginas del manual de syslog para obtener más detalles.

pptpd(8)

PPTPD - Servidor PPTP

SYNOPSIS

pptpd [-b] [-e] [-f config_file] [-g pid_file] [-i] [-l log_file] [-p port] [-s script] [-t tunnel_fd]

DESCRIPTION

pptpd es un servidor para el Protocolo de Túnel de Paquetes Punto a Punto (PPTP). Permite que clientes PPTP establezcan conexiones VPN a través de Internet. Los clientes pueden ser de casi cualquier sistema operativo.

El servidor PPTP se puede configurar para usar autenticación PAP (Protocolo de Autenticación por Contraseña) y CHAP (Protocolo de Autenticación Desafío-Respuesta). La autenticación se realiza generalmente contra un archivo de contraseñas o contra un servicio de autenticación remoto como RADIUS.

Una vez que un cliente se ha autenticado y se ha establecido un túnel, pptpd puede iniciar un shell para el cliente, ejecutar un script o configurar un túnel IP estándar. Para cada conexión entrante, pptpd se bifurca y se comunica con el cliente a través de los descriptores de archivo del túnel.

OPTIONS

  • -b: No bindea a ninguna interfaz. Es decir, escucha en todas las interfaces disponibles.
  • -e: Ejecuta el script especificado por -s en lugar de iniciar un shell para el cliente.
  • -f config_file: Especifica un archivo de configuración alternativo. Por defecto, se usa /etc/pptpd.conf.
  • -g pid_file: Especifica un archivo PID alternativo. Por defecto, se usa /var/run/pptpd.pid.
  • -i: Ignora la interfaz por defecto y escucha en todas las interfaces.
  • -l log_file: Especifica un archivo de registro alternativo. Por defecto, se usa /var/log/pptpd.log.
  • -p port: Especifica el puerto de escucha. Por defecto, es el puerto 1723.
  • -s script: Especifica el script a ejecutar para cada conexión. Este script recibirá la dirección IP del cliente y el nombre de usuario como argumentos.
  • -t tunnel_fd: Usado internamente por el proceso bifurcado para comunicarse con el padre.

FILES

  • /etc/pptpd.conf: Archivo de configuración principal.
  • /etc/ppp/chap-secrets: Contiene nombres de usuario y contraseñas para la autenticación CHAP y PAP.
  • /var/log/pptpd.log: Archivo de registro para los eventos del servidor PPTP.
  • /var/run/pptpd.pid: Archivo PID del proceso principal de pptpd.

DEBUGGING

pptpd puede ser ejecutado con un nivel de depuración más alto para obtener información detallada sobre su funcionamiento. Esto se puede configurar en el archivo pptpd.conf o pasándolo como argumento a pppd si se usa un script para iniciar la conexión PPP.
