NOMBRE

pptpsetup - configuración del protocolo de túnel punto a punto

SINOPSIS

pptpsetup --create <TUNEL> --server <SERVIDOR> [--domain <DOMINIO>]
          --username <NOMBRE_USUARIO> [--password <CONTRASEÑA>]
          [--encrypt] [--start]
pptpsetup --delete <TUNEL>

DESCRIPCIÓN

PPTP Client es un cliente para Linux, FreeBSD, NetBSD y OpenBSD del protocolo propietario de Microsoft Point-to-Point Tunneling Protocol, PPTP.

Este script configura PPTP Client en Linux.

OPCIONES

--create TUNEL
crea un túnel llamado TUNEL
--delete TUNEL
elimina el archivo /etc/ppp/peers/TUNEL y cualquier línea de /etc/ppp/chap-secrets que contenga "TUNEL" como una sola palabra
--server SERVIDOR
la dirección IP o el nombre del host del servidor
--domain DOMINIO
el nombre del dominio de autenticación (opcional)
--username NOMBRE_USUARIO
el nombre de usuario que se debe utilizar
--password CONTRASEÑA
la contraseña que se debe utilizar. Si no se especifica una contraseña, pptpsetup la pedirá.
--encrypt
si se requiere cifrado
--start
si la conexión debe iniciarse después de la configuración.
