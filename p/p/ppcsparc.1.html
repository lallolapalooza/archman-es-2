NOMBRE

ppcsparc - binario del Compilador Free Pascal (FPC), nombre derivado de Portable Pascal Compiler

SINOPSIS

ppcsparc [opciones] [archivo_fuente]

DESCRIPCION

Este binario es el binario del backend del Compilador Free Pascal (FPC), que es un compilador Pascal independiente (frontend no GCC) compatible con Turbo Pascal y Delphi (7.0), multi-target.

Este binario no debe llamarse directamente, en su lugar se debe utilizar el programa fpc. Éste elegirá el backend adecuado para compilar unidades para las plataformas solicitadas.

OPCIONES

Para una lista completa de todas las opciones de línea de comandos soportadas, consulte la página del manual de fpc(1).
