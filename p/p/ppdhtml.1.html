NOMBRE

ppdhtml - generador de resumen html de cups (obsoleto)

SINOPSIS

ppdhtml [ -D nombre[=valor] ] [ -I directorio-de-inclusión ] archivo-fuente

DESCRIPCIÓN

ppdhtml lee un archivo de información del controlador y produce una página de resumen HTML que lista todos los controladores en un archivo y las opciones admitidas. Este programa está obsoleto y se eliminará en una futura versión de CUPS.

OPCIONES

ppdhtml admite las siguientes opciones:

-D nombre[=valor]
Establece la variable nombrada para su uso en el archivo fuente. Es equivalente a usar la directiva #define en el archivo fuente.
-I directorio-de-inclusión
Especifica un directorio de inclusión alternativo. Se pueden proporcionar múltiples opciones -I para añadir directorios adicionales.

NOTAS

Los archivos PPD están obsoletos y ya no serán compatibles en una futura versión de características de CUPS. Las impresoras que no admiten IPP pueden ser compatibles utilizando aplicaciones como ippeveprinter(1).
