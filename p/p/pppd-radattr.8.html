PPPD-RADATTR(8) Manual del Administrador del Sistema PPPD-RADATTR(8)

NOMBRE

radattr.so - Plugin de utilidad RADIUS para pppd(8)

SINTAXIS

pppd [ opciones ] plugin radius.so plugin radattr.so

DESCRIPCIÓN

El plugin radattr para pppd hace que todos los atributos radius devueltos por el servidor RADIUS en el momento de la autenticación se almacenen en el archivo /var/run/radattr.pppN donde pppN es el nombre de la interfaz PPP. Los atributos RADIUS se almacenan uno por línea en el formato "Nombre-Atributo Valor-Atributo". Este formato es conveniente para su uso en los scripts /etc/ppp/ip-up y /etc/ppp/ip-down.

Tenga en cuenta que debe cargar el plugin radius.so antes de cargar el plugin radattr.so; radattr.so depende de símbolos definidos en radius.so.

USO

Para usar el plugin, simplemente proporcione las opciones plugin radius.so plugin radattr.so a pppd.

VER TAMBIÉN

pppd(8) pppd-radius(8)
