NOMBRE

ppmtopjxl - convertir una imagen PPM a un archivo PCL para HP PaintJet XL

SINOPSIS

ppmtopjxl [-nopack] [-gamma n] [-presentation] [-dark] [-diffuse] [-cluster] [-dither] [-xshift s] [-yshift s] [-xshift s] [-yshift s] [{-xsize|-width|-xscale} s] [{-ysize|-height|-yscale} s] [archivoppm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

ppmtopjxl lee una imagen PPM como entrada y produce un archivo PCL adecuado para imprimir en una impresora HP PaintJet XL.

El archivo generado no es adecuado para imprimir en una impresora PrintJet normal. La opción -nopack genera un archivo que no utiliza el método de compresión TIFF 4.0 normal. Este archivo podría ser imprimible en una impresora PaintJet normal (no XL).

La opción -gamma establece la corrección gamma para la imagen. El rango útil para la PaintJet XL es aproximadamente de 0.6 a 1.5.

Puedes alterar el algoritmo de renderizado utilizado para las imágenes con las opciones -dither, -cluster, y -diffuse. Estas opciones seleccionan el tramado ordenado, el tramado ordenado agrupado o la difusión de errores, respectivamente. Puedes usar la opción -dark para mejorar imágenes con un fondo oscuro cuando se reducen de tamaño. La opción -presentation activa el modo de presentación, en el que se realizan dos pasadas sobre el papel para aumentar la densidad de tinta. Solo debes usar esto para imágenes donde la calidad sea crítica.

Puedes redimensionar la imagen estableciendo las opciones -xsize y -ysize. El parámetro para cualquiera de estas opciones se interpreta como el número de puntos para establecer el ancho o la altura, pero puedes añadir una dimensión opcional de `pt' (puntos), `dp' (decipuntos), `in' (pulgadas), o `cm' (centímetros). Si solo especificas una dimensión, ppmtopjxl escalará la otra apropiadamente.

Las opciones -width y -height son sinónimos de -xsize y -ysize.

Alternativamente, puedes usar las opciones -xscale y -yscale para escalar la imagen mediante un factor simple.

Puedes desplazar la imagen en la página con las opciones -xshift y -yshift. Estas mueven la imagen las dimensiones especificadas a la derecha y hacia abajo.
