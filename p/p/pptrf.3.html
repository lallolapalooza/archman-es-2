subrutina cpptrf (carácter uplo, entero n, complejo, dimensión( * ) ap, entero info)

CPPTRF

Propósito:

!>
!> CPPTRF calcula la factorización de Cholesky de una matriz Hermitiana
!> compleja A definida positiva almacenada en formato empaquetado.
!>
!> La factorización tiene la forma
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L  * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es triangular inferior.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es una matriz COMPLEX de dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz Hermitiana
!>          A, empaquetado por columnas en un array lineal. La j-ésima columna de A
!>          se almacena en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si INFO = 0, el factor triangular U o L de la
!>          factorización de Cholesky A = U**H*U o A = L*L**H, en el mismo
!>          formato de almacenamiento que A.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el menor principal principal de orden i
!>                no es positivo definido, y la factorización no pudo ser
!>                completada.
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Más detalles:

!>
!>  El esquema de almacenamiento empaquetado se ilustra con el siguiente ejemplo
!>  cuando N = 4, UPLO = 'U':
!>
!>  Almacenamiento bidimensional de la matriz Hermitiana A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Almacenamiento empaquetado del triángulo superior de A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>

!>
!> The factorization has the form
!>    A = U**H * U,  if UPLO = 'U', or
!>    A = L  * L**H,  if UPLO = 'L',

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the Hermitian matrix
!>          A, packed columnwise in a linear array.  The j-th column of A

!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>
!>          On exit, if INFO = 0, the triangular factor U or L from the
!>          Cholesky factorization A = U**H*U or A = L*L**H, in the same
!>          storage format as A.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit

!>          > 0:  if INFO = i, the leading principal minor of order i

pptrf(3) - LAPACK

NAME

pptrf - computes the Cholesky factorization of a general band matrix

SYNOPSIS

      SUBROUTINE PPTRF( UPLO, N, AP, INFO )
          CHARACTER * 1        UPLO
          INTEGER              N
          REAL                 AP( * )
          INTEGER              INFO
      END

      SUBROUTINE ZPPTRF( UPLO, N, AP, INFO )
          CHARACTER * 1        UPLO
          INTEGER              N
          DOUBLE PRECISION      AP( * )
          INTEGER              INFO
      END

This subroutine computes the Cholesky factorization of a complex Hermitian positive definite matrix. There are two versions of the routine: a real version for single precision matrices and a complex version for double precision matrices. The real version is denoted by PPTRF and the complex version by ZPPTRF.

Detailed Description

PPTRF computes the Cholesky factorization of a real symmetric positive definite matrix A stored in packed format.

The factorization has the form

    A = U**T * U,  if UPLO = 'U', or
    A = L  * L**T,  if UPLO = 'L',

where U is an upper triangular matrix and L is lower triangular. The factored matrix (U or L) is stored in the same packed format as the input matrix A.

ZPPTRF computes the Cholesky factorization of a complex Hermitian positive definite matrix.

The factorization has the form

    A = U**H * U,  if UPLO = 'U', or
    A = L  * L**H,  if UPLO = 'L',

where U is an upper triangular matrix and L is lower triangular. The factored matrix (U or L) is stored in the same packed format as the input matrix A.

Purpose:

!>
!> SPPTRF computes the Cholesky factorization of a real symmetric
!> positive definite matrix A stored in packed format.
!>
!> The factorization has the form
!>    A = U**T * U,  if UPLO = 'U', or
!>    A = L  * L**T,  if UPLO = 'L',

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          A, packed columnwise in a linear array.  The j-th column of A
!>          is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>
!>          On exit, if INFO = 0, the triangular factor U or L from the
!>          Cholesky factorization A = U**T*U or A = L*L**T, in the same
!>          storage format as A.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the leading principal minor of order i
!>                is not positive, and the factorization could not be
!>                completed.
!>
