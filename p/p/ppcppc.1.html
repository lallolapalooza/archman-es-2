NOMBRE

ppcppc - binario del Compilador Free Pascal (FPC), nombre derivado de Portable Pascal Compiler

SINOPSIS

ppcppc [opciones] [archivo_fuente]

DESCRIPCIÓN

Este binario es el binario de backend del Compilador Free Pascal (FPC), que es un compilador Pascal multitarget independiente (sin frontend GCC) compatible con Turbo Pascal y Delphi (7.0).

Este binario no debe llamarse directamente, en su lugar se debe usar el programa fpc. Este elegirá el backend adecuado para compilar unidades para las plataformas solicitadas.

OPCIONES

Para una lista completa de todas las opciones de línea de comandos admitidas, consulte la página del manual fpc(1).
