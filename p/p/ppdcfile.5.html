NOMBRE

ppdcfile - formato de archivo fuente del compilador PPD de cups (obsoleto)

DESCRIPCIÓN

El compilador PPD de CUPS lee meta-archivos que contienen descripciones de uno o más archivos PPD que serán generados por ppdc(1). Esta página del manual proporciona una referencia rápida a las palabras clave compatibles y debe usarse junto con la ayuda en línea para CUPS.

El formato del archivo fuente es texto ASCII plano que se puede editar con su editor de texto favorito. Se admiten comentarios usando los mecanismos de comentarios C (/* ... */) y C++ (// ...).

La información del controlador de impresora se puede agrupar y compartir usando llaves ({ ... }); los archivos PPD se escriben cuando se ve una llave de cierre o el final del archivo y se ha definido una directiva PCFileName.

Las directivas pueden colocarse en cualquier lugar de una línea y van seguidas de uno o más valores. La siguiente es una lista de las directivas disponibles y los valores que aceptan:

ppdcfile.5.en — CUPS

NAME

ppdcfile — CUPS PPD file format

SYNOPSIS

ppdcfile

DESCRIPTION

The ppdcfile utility is used by the CUPS printing system to store printer driver information in PPD (PostScript Printer Description) files.

PPD files are text files that contain information about the capabilities and features of a printer. This information is used by CUPS to generate PostScript code that is compatible with the printer.

Version

NOTES

Los archivos PPD están obsoletos y dejarán de ser compatibles en una futura versión de características de CUPS. Las impresoras que no admiten IPP pueden ser compatibles utilizando aplicaciones como ippeveprinter(1).
