NOMBRE

nm - lista símbolos de archivos objeto

SINOPSIS

nm [-A|-o|--print-file-name]
[-a|--debug-syms]
[-B|--format=bsd]
[-C|--demangle[=estilo]]
[-D|--dynamic]
[-fformato|--format=formato]
[-g|--extern-only]
[-h|--help]
[--ifunc-chars=CARACTERES]
[-j|--format=just-symbols]
[-l|--line-numbers] [--inlines]
[-n|-v|--numeric-sort]
[-P|--portability]
[-p|--no-sort]
[-r|--reverse-sort]
[-S|--print-size]
[-s|--print-armap]
[-t base|--radix=base]
[-u|--undefined-only]
[-U|--defined-only]
[-V|--version]
[-W|--no-weak]
[-X 32_64]
[--no-demangle]
[--no-recurse-limit|--recurse-limit]]
[--plugin nombre]
[--size-sort]
[--special-syms]
[--synthetic]
[--target=nombre-bfd]
[--unicode=método]
[--with-symbol-versions]
[--without-symbol-versions]
[archivo-objeto...]

DESCRIPCIÓN

GNU nm lista los símbolos de los archivos objeto archivo-objeto.... Si no se listan archivos objeto como argumentos, nm asume que el archivo es a.out.

Para cada símbolo, nm muestra:

  • El valor del símbolo, en la base seleccionada por las opciones (ver más abajo), o hexadecimal por defecto.
  • El tipo de símbolo. Se utilizan al menos los siguientes tipos; otros también, dependiendo del formato del archivo objeto. Si es minúscula, el símbolo es generalmente local; si es mayúscula, el símbolo es global (externo). Sin embargo, hay algunos símbolos en minúsculas que se muestran para símbolos globales especiales ("u", "v" y "w").
"A"
El valor del símbolo es absoluto y no cambiará con enlaces posteriores.
"B"
"b"
El símbolo está en la sección de datos BSS. Esta sección típicamente contiene datos inicializados a cero o no inicializados, aunque el comportamiento exacto depende del sistema.
"C"
"c"
El símbolo es común. Los símbolos comunes son datos no inicializados. Al enlazar, múltiples símbolos comunes pueden aparecer con el mismo nombre. Si el símbolo está definido en algún lugar, los símbolos comunes se tratan como referencias indefinidas. El carácter minúscula c se utiliza cuando el símbolo está en una sección especial para comunes pequeños.
"D"
"d"
El símbolo está en la sección de datos inicializados.
"G"
"g"
El símbolo está en una sección de datos inicializados para objetos pequeños. Algunos formatos de archivo objeto permiten un acceso más eficiente a objetos de datos pequeños, como una variable entera global en lugar de un array global grande.
"i"
Para archivos con formato PE, esto indica que el símbolo está en una sección específica de la implementación de DLLs.

Para archivos con formato ELF, esto indica que el símbolo es una función indirecta. Esta es una extensión de GNU al conjunto estándar de tipos de símbolos ELF. Indica un símbolo que si se referencia mediante una relocalización no se evalúa a su dirección, sino que debe ser invocado en tiempo de ejecución. La ejecución en tiempo de ejecución devolverá el valor a utilizar en la relocalización.

Nota: la visualización real de símbolos para símbolos indirectos de GNU se controla mediante la opción de línea de comandos --ifunc-chars. Si esta opción ha sido proporcionada, el primer carácter de la cadena se utilizará para los símbolos de función indirecta globales. Si la cadena contiene un segundo carácter, este se utilizará para los símbolos de función indirecta locales.

"I"
El símbolo es una referencia indirecta a otro símbolo.
"N"
El símbolo es un símbolo de depuración.
"n"
El símbolo está en una sección de solo lectura no de datos, no de código, no de depuración.
"p"
El símbolo está en una sección de desenrollado de pila.
"R"
"r"
El símbolo está en una sección de datos de solo lectura.
"S"
"s"
El símbolo está en una sección de datos no inicializados o inicializados a cero para objetos pequeños.
"T"
"t"
El símbolo está en la sección de texto (código).
"U"
El símbolo es indefinido.
"u"
El símbolo es un símbolo global único. Esta es una extensión de GNU al conjunto estándar de enlaces de símbolos ELF. Para un símbolo de este tipo, el enlazador dinámico se asegurará de que en todo el proceso solo se utilice un símbolo con este nombre y tipo.
"V"
"v"
El símbolo es un objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo débil se convierte en cero sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor por defecto.
"W"
"w"
El símbolo es un símbolo débil que no ha sido etiquetado específicamente como símbolo de objeto débil. Cuando un símbolo definido débil se enlaza con un símbolo definido normal, se utiliza el símbolo definido normal sin errores. Cuando se enlaza un símbolo indefinido débil y el símbolo no está definido, el valor del símbolo se determina de manera específica del sistema sin errores. En algunos sistemas, las mayúsculas indican que se ha especificado un valor por defecto.
"-"
El símbolo es un símbolo stabs en un archivo objeto a.out. En este caso, los siguientes valores impresos son el campo 'other' de stabs, el campo 'desc' de stabs y el tipo de stab. Los símbolos stabs se utilizan para contener información de depuración.
"?"
El tipo de símbolo es desconocido, o específico del formato del archivo objeto.
•
El nombre del símbolo. Si un símbolo tiene información de versión asociada, entonces se muestra también la información de versión. Si el símbolo versionado es indefinido o está oculto para el enlazador, la cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo foo@VER_1. Si la versión es la versión por defecto a utilizar al resolver referencias no versionadas al símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo foo@@VER_2.

OPCIONES

Las formas largas y cortas de las opciones, mostradas aquí como alternativas, son equivalentes.

-A
-o
--print-file-name
Precede cada símbolo con el nombre del archivo de entrada (o miembro del archivo) en el que se encontró, en lugar de identificar el archivo de entrada solo una vez, antes de todos sus símbolos.
-a
--debug-syms
Muestra todos los símbolos, incluso los símbolos solo para depuradores; normalmente estos no se listan.
-B
Lo mismo que --format=bsd (para compatibilidad con el nm de MIPS).
-C
--demangle[=estilo]
Decodifica (demangle) nombres de símbolos de bajo nivel a nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de mangling. El argumento opcional de estilo de demangling puede usarse para elegir un estilo de demangling apropiado para su compilador.
--no-demangle
No decodificar nombres de símbolos de bajo nivel. Esta es la opción por defecto.
--recurse-limit
--no-recurse-limit
Estas opciones son para la recursión de `nm --print-file-name --no-sort`.
-D
--dynamic
Lista los símbolos dinámicos en lugar de los símbolos normales.
-f formato
--format=formato
Usa el formato especificado para la salida. El formato puede ser uno de los siguientes:
traditional
Este es el formato por defecto si el nombre de la máquina es desconocido. La salida es similar a la de AT&T Unix nm (ver más abajo). Si no se especifica ninguna opción, entonces la salida es una línea para cada archivo objeto que lista los símbolos no definidos del archivo, y una línea para cada archivo objeto que lista los símbolos definidos del archivo. Los símbolos se listan en orden alfabético.
bsd
Este es el formato por defecto si el nombre de la máquina es conocido. La salida es similar a la del nm de BSD Unix (ver más abajo). Los símbolos se listan en orden alfabético. Cuando se le da esta opción a nm, el símbolo aparece en una línea, junto con su valor, tipo, nombre de archivo (si es aplicable), y nombre de símbolo.
sysv
Este es el formato por defecto para algunos sistemas. La salida es similar a la del nm de System V Unix (ver más abajo). La salida es en un formato consistente, con el valor del símbolo, el tipo y el nombre del símbolo en cada línea.
posix
Este es el formato por defecto si el nombre de la máquina es conocido. La salida es similar a la del nm de BSD Unix (ver más abajo). Los símbolos se listan en orden alfabético. Cuando se le da esta opción a nm, el símbolo aparece en una línea, junto con su valor, tipo, nombre de archivo (si es aplicable), y nombre de símbolo. El formato POSIX sólo requiere que se imprima el valor del símbolo, el tipo y el nombre.
just-symbols
Imprime solo los nombres de los símbolos, uno por línea. Esto es útil para el procesamiento posterior por otros programas.
null
Este formato imprime los nombres de los símbolos separados por un carácter nulo. Esto es útil para el procesamiento posterior por otros programas que pueden manejar nombres de archivo con espacios u otros caracteres especiales.
-g
--extern-only
Solo imprime los símbolos externos (globales).
-h
--help
Muestra un resumen de las opciones y sale.
--ifunc-chars=CARACTERES
Especifica los caracteres a usar para mostrar símbolos de función indirecta. El primer carácter se usa para símbolos globales y el segundo (si existe) para símbolos locales. Por defecto, usa '&' y '^'.
-j
--format=just-symbols
Imprime solo los nombres de los símbolos, uno por línea.
-l
--line-numbers
Para cada símbolo, imprime el nombre del archivo fuente y el número de línea en el archivo fuente donde se definió el símbolo. Esto solo funciona si el archivo objeto contiene información de depuración que relaciona los símbolos con los números de línea.
--inlines
Muestra información sobre símbolos en línea. Esto es una extensión de GNU y puede no estar disponible en todas las plataformas. Funciona con archivos ELF y DWARF.
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por su valor.
-P
--portability
Utiliza el formato POSIX para la salida. Esto asegura que la salida sea compatible con la especificación POSIX para el comando nm.
-p
--no-sort
No ordenar los símbolos. La salida se mostrará en el orden en que los símbolos aparecen en el archivo objeto.
-r
--reverse-sort
Invierte el orden de clasificación. Esto se aplica a cualquier opción de ordenación que se haya especificado (por ejemplo, alfabético o numérico).
-S
--print-size
Para cada símbolo, imprime el tamaño del símbolo. Esto solo funciona si el archivo objeto contiene información sobre el tamaño de los símbolos.
-s
--print-armap
Imprime el mapa de archivo (archive map) de los archivos de biblioteca estática. Esto muestra los archivos que componen la biblioteca y los símbolos que exporta cada uno.
-t base
--radix=base
Utiliza la base especificada para mostrar los valores de los símbolos. La base puede ser:
d
Decimal
o
Octal
x
Hexadecimal (por defecto)
-u
--undefined-only
Solo imprime los símbolos indefinidos.
-U
--defined-only
Solo imprime los símbolos definidos.
-V
--version
Muestra la información de la versión de nm y sale.
-W
--no-weak
No mostrar símbolos débiles.
-X 32_64
Especifica la arquitectura para los archivos de objeto de IA64. Puede ser 32 o 64.
--plugin nombre
Carga un plugin de BFD con el nombre especificado. Esto permite extender la funcionalidad de nm con soporte para nuevos formatos de archivo objeto.
--size-sort
Ordena los símbolos por su tamaño.
--special-syms
Muestra símbolos especiales además de los normales. Los símbolos especiales son aquellos que no se utilizan para el código o los datos, como los símbolos de depuración o los símbolos utilizados por el enlazador dinámico.
--synthetic
Muestra símbolos sintéticos. Los símbolos sintéticos son aquellos que no están presentes en el archivo objeto original, sino que son generados por el compilador o el enlazador. Esto es útil para depurar problemas relacionados con la generación de código.
--target=nombre-bfd
Especifica el formato de archivo objeto que se debe utilizar. Por defecto, nm intenta detectar automáticamente el formato del archivo objeto. Esta opción permite especificar explícitamente el formato.
--unicode=método
Especifica el método para mostrar nombres de símbolos Unicode. El método puede ser:
none
No mostrar nombres Unicode.
locale
Mostrar nombres Unicode utilizando la configuración regional del sistema.
hex
Mostrar nombres Unicode utilizando códigos hexadecimales.
--with-symbol-versions
Muestra la información de versión de los símbolos. Esto es útil cuando se trabaja con bibliotecas que utilizan versiones de símbolos.
--without-symbol-versions
No muestra la información de versión de los símbolos.
="permalink" href="#recurse">--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al desdemantelar cadenas. Dado que los formatos de mangling de nombres permiten un nivel de recursión infinito, es posible crear cadenas cuya decodificación agote el espacio de pila disponible en la máquina anfitriona, desencadenando un fallo de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

Por defecto, este límite está habilitado, pero puede ser necesario deshabilitarlo para desmantelar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

-D
--dynamic
Muestra los símbolos dinámicos en lugar de los símbolos normales. Esto solo es significativo para objetos dinámicos, como ciertos tipos de bibliotecas compartidas.
-f formato
--format=formato
Utiliza el formato de salida formato, que puede ser "bsd", "sysv", "posix" o "just-symbols". Por defecto es "bsd". Solo el primer carácter de formato es significativo; puede ser mayúscula o minúscula.
-g
--extern-only
Muestra solo símbolos externos.
-h
--help
Muestra un resumen de las opciones de nm y sale.
--ifunc-chars=CHARS
Al mostrar símbolos de funciones indirectas de GNU, nm usará por defecto el carácter "i" tanto para funciones indirectas locales como globales. La opción --ifunc-chars permite al usuario especificar una cadena que contiene uno o dos caracteres. El primer carácter se usará para símbolos de funciones indirectas globales y el segundo carácter, si está presente, se usará para símbolos de funciones indirectas locales.
j
Lo mismo que --format=just-symbols.
-l
--line-numbers
Para cada símbolo, utiliza la información de depuración para intentar encontrar un nombre de archivo y un número de línea. Para un símbolo definido, busca el número de línea de la dirección del símbolo. Para un símbolo indefinido, busca el número de línea de una entrada de reubicación que se refiera al símbolo. Si se puede encontrar información sobre el número de línea, se imprime después de la otra información del símbolo.
--inlines
Cuando la opción -l está activa, si la dirección pertenece a una función que fue inlinada, esta opción hace que se imprima también la información de origen de todos los ámbitos contenedores hasta la primera función no inlinada. Por ejemplo, si "main" inlina "callee1", que a su vez inlina "callee2", y la dirección es de "callee2", también se imprimirá la información de origen de "callee1" y "main".
-n
-v
--numeric-sort
Ordena los símbolos numéricamente por sus direcciones, en lugar de alfabéticamente por sus nombres.
-p
--no-sort
No se molesta en ordenar los símbolos en ningún orden; los imprime en el orden en que se encuentran.
-P
--portability
Utiliza el formato de salida estándar POSIX.2 en lugar del formato predeterminado. Equivalente a -f posix.
-r
--reverse-sort
Invierte el orden de clasificación (ya sea numérico o alfabético); que el último venga primero.
-S
--print-size
Imprime tanto el valor como el tamaño de los símbolos definidos para el estilo de salida "bsd". Esta opción no tiene efecto para formatos de objeto que no registran tamaños de símbolos, a menos que también se use --size-sort, en cuyo caso se mostrará un tamaño calculado.
-s
--print-armap
Al listar símbolos de miembros de archivo, incluye el índice: un mapa (almacenado en el archivo por ar o ranlib) de qué módulos contienen definiciones para qué nombres.
-t base
--radix=base
Utiliza base como la base para imprimir los valores de los símbolos. Debe ser d para decimal, o para octal, o x para hexadecimal.
-u
--undefined-only
Muestra solo símbolos indefinidos (aquellos externos a cada archivo objeto). Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-U
--defined-only
Muestra solo los símbolos definidos para cada archivo objeto. Por defecto, se muestran tanto los símbolos definidos como los indefinidos.
-V
--version
Muestra el número de versión de nm y sale.
-X
Esta opción se ignora por compatibilidad con la versión AIX de nm. Toma un parámetro que debe ser la cadena 32_64. El modo predeterminado de nm de AIX corresponde a -X 32, que no está soportado por GNU nm.
--plugin nombre
Carga el plugin llamado nombre para añadir soporte a tipos de destino adicionales. Esta opción solo está disponible si la cadena de herramientas se compiló con soporte de plugins habilitado.

Si no se proporciona --plugin, pero el soporte de plugins ha sido habilitado, entonces nm itera sobre los archivos en ${libdir}/bfd-plugins en orden alfabético y se utiliza el primer plugin que reclama el objeto en cuestión.

Por favor, tenga en cuenta que este directorio de búsqueda de plugins no es el que utiliza la opción -plugin de ld. Para hacer que nm utilice el plugin del enlazador, debe copiarse al directorio ${libdir}/bfd-plugins. Para compilaciones basadas en GCC, el plugin del enlazador se llama liblto_plugin.so.0.0.0. Para compilaciones basadas en Clang, se llama LLVMgold.so. El plugin de GCC es siempre compatible con versiones anteriores, por lo que es suficiente copiar el más reciente.

--size-sort
Ordena los símbolos por tamaño. Para objetos ELF, los tamaños de los símbolos se leen de ELF; para otros tipos de objeto, los tamaños de los símbolos se calculan como la diferencia entre el valor del símbolo y el valor del símbolo con el siguiente valor superior. Si se utiliza el formato de salida "bsd", se imprime el tamaño del símbolo, en lugar del valor, y se debe usar -S para imprimir tanto el tamaño como el valor.

Nota: esta opción no funciona si se ha habilitado --undefined-only, ya que los símbolos indefinidos no tienen tamaño.

--special-syms
Muestra símbolos que tienen un significado especial específico del destino. Estos símbolos suelen ser utilizados por el destino para algún procesamiento especial y no son normalmente útiles cuando se incluyen en las listas de símbolos normales. Por ejemplo, para destinos ARM, esta opción omitiría los símbolos de mapeo utilizados para marcar transiciones entre código ARM, código THUMB y datos.
--synthetic
Incluye símbolos sintéticos en la salida. Estos son símbolos especiales creados por el enlazador para diversos propósitos. No se muestran por defecto ya que no forman parte del código fuente original del binario.
--unicode=[default|invalid|locale|escape|hex|highlight]
Controla la visualización de caracteres multibyte codificados en UTF-8 en cadenas. El valor predeterminado (--unicode=default) es no darles ningún tratamiento especial. La opción --unicode=locale muestra la secuencia en la configuración regional actual, que puede o no admitirla. Las opciones --unicode=hex y --unicode=invalid las muestran como secuencias de bytes hexadecimales encerradas entre corchetes angulares o llaves.

La opción --unicode=escape las muestra como secuencias de escape (\uxxxx) y la opción --unicode=highlight las muestra como secuencias de escape resaltadas en rojo (si el dispositivo de salida lo soporta). El coloreado está destinado a llamar la atención sobre la presencia de secuencias unicode donde no se esperaban.

-W
--no-weak
No muestra símbolos débiles.
--with-symbol-versions
--without-symbol-versions
Habilita o deshabilita la visualización de información de versiones de símbolos. La cadena de versión se muestra como un sufijo al nombre del símbolo, precedido por un carácter @. Por ejemplo nm(1) — nm, versión 2.42

NAME

nm(1) — listar símbolos de archivos objeto

SYNOPSIS

nm [-{dpfFLarvV] [--{dynamic-syms|extern-only|print-file-names|format|all-errors|no-sort|radix|verbose|version}] [-{AaeGgInm] [--{print-file-name|no-demangle|extern-only|global|print-file-names|no-sort|undefined-only|demangle|format}] [-{S] [--{size-sort}] [-{t}{o|u}] [--{target=}bfdname] [--{help|version}] [objfile... ]

DESCRIPTION

El programa nm imprime una lista de los símbolos de los archivos objeto especificados. Si no se especifica ningún archivo objeto, se utiliza el archivo nombrado a.out como archivo predeterminado. Si se especifican varios archivos objeto, los símbolos de cada uno se preceden del nombre del archivo. El orden de salida es, por defecto, alfabético.

Los símbolos pueden ser precedidos por una de las siguientes letras para indicar su tipo:

?
El tipo de símbolo es desconocido.
A
El símbolo está en la sección absolute.
B
El símbolo está en la sección BSS (bloques sin inicializar).
C
El símbolo es una referencia común (COMMON), es decir, un símbolo no inicializado que no ha sido definido todavía.
D
El símbolo está en la sección de datos inicializados.
d
El símbolo está en la sección de datos inicializados (con el mismo significado que D).
G
El símbolo está en la sección de datos de inicialización global.
g
El símbolo está en la sección de datos de inicialización global (con el mismo significado que G).
I
El símbolo es una referencia de importación.
R
El símbolo está en la sección de solo lectura.
r
El símbolo está en la sección de solo lectura (con el mismo significado que R).
T
El símbolo está en la sección de texto (código).
t
El símbolo está en la sección de texto (código) (con el mismo significado que T).
U
El símbolo no está definido.
u
El símbolo no está definido (con el mismo significado que U).
V
El símbolo es una referencia a un objeto dinámico.
v
El símbolo es una referencia a un objeto dinámico (con el mismo significado que V).
W
El símbolo es una referencia débil.
w
El símbolo es una referencia débil (con el mismo significado que W).
0
El símbolo es una sección.
a
El símbolo está en la sección de datos absolute.
i
El símbolo es una referencia de importación.
s
El símbolo está en la sección de datos de solo lectura.
x
El símbolo está en la sección de datos de solo lectura.

Los símbolos globales pueden ser precedidos por una de las siguientes letras para indicar su visibilidad:

l
El símbolo tiene enlace local.
i
El símbolo tiene enlace interno.
g
El símbolo tiene enlace global.
w
El símbolo tiene enlace débil.
v
El símbolo tiene enlace de objeto virtual.

El tipo de símbolo está seguido de una letra que indica el estado del símbolo:

a
El símbolo está en la sección de datos absolute.
c
El símbolo está en la sección BSS.
d
El símbolo está en la sección de datos inicializados.
i
El símbolo es una referencia de importación.
n
El símbolo es un valor numérico.
r
El símbolo está en la sección de solo lectura.
t
El símbolo está en la sección de texto.
u
El símbolo no está definido.
v
El símbolo es una referencia a un objeto dinámico.
w

El símbolo es una sección.

Si un símbolo tiene versiones, se muestra el nombre de la versión sufijado con un guion y el nombre de la versión. Por ejemplo, foo-VER_1. Si la versión es la versión predeterminada que se utiliza al resolver referencias no versionadas del símbolo, entonces se muestra como un sufijo precedido por dos caracteres @. Por ejemplo, foo@@VER_2. Por defecto, la información de versión del símbolo se muestra.

OPTIONS

Las siguientes opciones se pueden utilizar con nm:

--target=bfdname
Especifica un formato de código de objeto distinto del formato predeterminado de su sistema.
@archivo
Lee las opciones de la línea de comandos del archivo especificado. Las opciones leídas se insertan en el lugar de la opción original @archivo. Si el archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

Las opciones en el archivo están separadas por espacios en blanco. Un carácter de espacio en blanco puede incluirse en una opción encerrando la opción completa entre comillas simples o dobles. Cualquier carácter (incluido un carácter de barra invertida) puede incluirse prefijando el carácter a incluir con una barra invertida. El archivo puede contener él mismo opciones adicionales @archivo; dichas opciones se procesarán recursivamente.
