ppdep(1) Seguimiento de dependencias de unidades Pascal ppdep(1)

NOMBRE

ppdep - El programa de seguimiento de dependencias de unidades Pascal de FPC.

SINOPSIS

ppdep [-DDefine] [-oArchivo] [-eext] [-V] [-h] [A[llamada]] archivo

Descripción

ppdep vuelca las dependencias de una unidad en un formato que GNU make pueda entender. Escribe estas dependencias en la salida estándar. Se encarga de las dependencias tanto en la sección de interfaz como en la de implementación de la unidad, y puede manejar defines condicionales.

Uso

Puede invocar ppdep con el nombre del archivo (programa o unidad) cuyas dependencias desea listar como el único argumento requerido. No necesita especificar una extensión, por defecto se asume .pp.

Opciones

ppdep tiene varias opciones, que no distinguen entre mayúsculas y minúsculas:

-allamada
Esta opción indica a ppdep que genere una llamada al compilador para el makefile. La llamada al compilador se generará para cada archivo que se encuentre en el directorio actual. Si no especifica una llamada de compilador explícita, se usa ppc386.
-dpalabra_clave
Esta opción define palabra_clave que puede usarse para verificar defines condicionales. ppdep entiende defines condicionales, debería usar esta opción si la cláusula uses de los programas o unidades puede contener defines condicionales.
-eext
Esto le permite especificar una extensión diferente para los archivos de unidad. Por defecto, se asume .ppu. Esta extensión se escribe en el makefile.
-f[llamada]
Esta opción indica a ppdep que genere una llamada al compilador para el makefile. La llamada al compilador se generará solo para el archivo que se especificó en la línea de comandos de ppdep. Si desea generar una llamada al compilador para cada archivo encontrado, use la opción -a. Si no especifica una llamada de compilador explícita, se usa ppc386.
-h
Muestra una pantalla de ayuda breve.
-oarchivo
Esta opción le permite especificar un archivo al que se deben escribir las dependencias. Por defecto, las dependencias se escriben en la salida estándar. Si especifica esta opción, las dependencias se escriben en archivo en su lugar.

-v
Escribe algunos mensajes de diagnóstico. Si usa esta opción, asegúrese de usar también -o, ya que los mensajes de diagnóstico también se escribirán en la salida estándar.
