NOMBRE

ppc386 - binario del Compilador Free Pascal (FPC), nombre derivado de Portable Pascal Compiler

SINOPSIS

ppc386 [opciones] [archivo_fuente]

DESCRIPCIÓN

Este binario es el binario del lado del backend del *Compilador Free Pascal (FPC)*, que es un compilador Pascal multitarget independiente (frontend no basado en GCC) compatible con *Turbo Pascal* y *Delphi (7.0)*.

Este binario no debe ser llamado directamente, en su lugar se debe utilizar el programa fpc. Este elegirá el backend correcto para compilar unidades para las plataformas solicitadas.

OPCIONES

Para obtener una lista completa de todas las opciones de línea de comandos compatibles, consulte la página del manual fpc(1).
