PPPOE-SNIFF(8) Manual del Administrador del Sistema PPPOE-SNIFF(8)

NOMBRE

pppoe-sniff - examina la red en busca de tramas PPPoE no estándar

SINOPSIS

pppoe-sniff [opciones]

DESCRIPCIÓN

pppoe-sniff escucha tramas PPPoE PADR y de sesión que parecen prometedoras y deduce las opciones adicionales necesarias para que pppoe(8) funcione.

Algunos proveedores de DSL parecen usar tipos de trama no estándar para las tramas PPPoE y/o requieren un valor determinado en el campo Service-Name. A menudo es más fácil analizar esos valores desde una máquina que puede conectarse con éxito que intentar obtenerlos del proveedor de DSL.

Para usar pppoe-sniff, necesitas dos computadoras, un módem DSL y un hub Ethernet (no un switch Ethernet).

Si el módem DSL normalmente se conecta directamente a la tarjeta Ethernet de tu computadora, conéctalo al puerto "uplink" del hub Ethernet. Conecta dos computadoras a puertos normales del hub. En una de las computadoras, ejecuta el software que te proporcionó el proveedor de DSL en el sistema operativo que admita el proveedor de DSL. En la otra computadora, ejecuta Linux e inicia sesión como root.

En la máquina Linux, pon la interfaz Ethernet en modo promiscuo y ejecuta pppoe-sniff. Si la interfaz Ethernet es eth0, por ejemplo, escribe estos comandos:

ip link set eth0 promisc on
pppoe-sniff -I eth0

En la otra máquina, inicia tu conexión DSL como de costumbre. Después de un corto tiempo, pppoe-sniff debería imprimir recomendaciones para el valor de una opción '-f' para pppoe.

Después de que pppoe-sniff termine (o lo detengas si parece colgado), recuerda desactivar el modo promiscuo:

ip link set eth0 promisc on

OPCIONES

-I interfaz
La opción -I especifica la interfaz Ethernet a usar. En Linux, típicamente es eth0 o eth1. La interfaz debe estar "arriba" y en modo promiscuo antes de iniciar pppoe-sniff.
-V
La opción -V hace que pppoe-sniff imprima su número de versión y salga.

ERRORES

pppoe-sniff solo funciona en Linux.
