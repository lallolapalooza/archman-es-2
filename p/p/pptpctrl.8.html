PPTPCTRL(8) Manual del Administrador del Sistema PPTPCTRL(8)

NOMBRE

pptpctrl - gestor de conexión de control PPTP

SINOPSIS

pptpctrl flag-depuracion-pptp flag-no-ipparam valor-opciones-ppp valor-velocidad-ppp valor-ip-local-ppp valor-ip-remoto-ppp [ id-llamada-pptp ] [ binario-ppp ] [ pptp-logwtmp ]

DESCRIPCIÓN

pptpctrl suele ser ejecutado por pptpd(8), pero también puede ser ejecutado desde inetd(8) si algunas de las características de pptpd(8), como la gestión del grupo de IP y los envoltorios TCP integrados, no son necesarias.

OPCIONES

Las opciones de pptpctrl son poco convencionales, ya que están diseñadas para ser utilizadas por pptpd(8) en lugar de por los usuarios. El orden de las opciones es crítico. Las opciones de bandera consisten en un 0 o 1, y deben estar presentes. Las opciones de valor consisten en un 0, o un 1 seguido del valor. Deben estar presentes o bien el 0 o bien tanto el 1 como el valor. Las opciones restantes son opcionales, pero deben estar presentes en el orden definido. Las opciones son las siguientes:

flag-depuracion-pptp
si se establece (1), habilita mensajes de depuración a syslog desde pptpctrl. Esto no tiene efecto en la configuración de la opción de depuración de PPP.
flag-no-ipparam
si se establece, pptpctrl no pasará la dirección IP del cliente a pppd(8) utilizando la opción ipparam. Consulte la opción noipparam en pptpd.conf(5).
valor-opciones-ppp
archivo a utilizar para las opciones de PPP. Consulte la opción file en pppd(8).
valor-velocidad-ppp
valor para la opción speed dada a pppd(8). Tenga en cuenta que en Linux, este parámetro es ineficaz.
valor-ip-local-ppp
si se establece, especifica la dirección IP que pppd(8) debe usar para la interfaz de red en el servidor. Si no se establece, pppd(8) la determinará basándose en las opciones; normalmente será la dirección ethernet del servidor.
valor-ip-remoto-ppp
si se establece, especifica la dirección IP que pppd(8) debe usar para la interfaz de red en el cliente. Si no se establece, pppd(8) la determinará basándose en las opciones; normalmente será la dirección ethernet del cliente, o una dirección dada en chap-secrets. Debe establecerse si se establece valor-ip-local-ppp.
id-llamada-pptp
si está presente, especifica la identificación de la llamada para la sesión PPTP. Si se omite, la identificación de la llamada es cero. Normalmente el ID es asignado por pptpd(8) y pasado a pptpctrl.
binario-ppp
si está presente, ruta al binario PPP a utilizar. Si se omite, se utiliza el valor predeterminado.
pptp-logwtmp
si está presente, especifica si wtmp(5) debe actualizarse cuando los usuarios se conectan y desconectan.
