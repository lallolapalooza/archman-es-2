subrutina cppsv (carácter uplo, entero n, entero nrhs, complejo, dimensión( * ) ap, complejo, dimensión( ldb, * ) b, entero ldb, entero info)

CPPSV calcula la solución del sistema de ecuaciones lineales complejas A * X = B para matrices OTRAS

Propósito:

!>
!> CPPSV calcula la solución de un sistema de ecuaciones lineales complejas
!>    A * X = B,
!> donde A es una matriz Hermítica definida positiva de N x N almacenada
!> en formato empaquetado y X y B son matrices de N x NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L * L**H,  si UPLO = 'L',
!> donde U es una matriz triangular superior y L es una matriz triangular
!> inferior.  La forma factorizada de A se utiliza luego para resolver el
!> sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El número de ecuaciones lineales, es decir, el orden de
!>          la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AP

!>          AP es un array COMPLEJO, dimensión (N*(N+1)/2)
!>          En la entrada, el triángulo superior o inferior de la matriz
!>          Hermítica A, empaquetado columna por columna en un array lineal.
!>          La j-ésima columna de A se almacena en el array AP como sigue:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si INFO = 0, el factor U o L de la
!>          factorización de Cholesky A = U**H*U o A = L*L**H, en el mismo
!>          formato de almacenamiento que A.
!>

B

!>          B es un array COMPLEJO, dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N x NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N x NRHS.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>

Más detalles:

!>
!>  El esquema de almacenamiento empaquetado se ilustra con el siguiente ejemplo
!>  cuando N = 4, UPLO = 'U':
!>
!>  Almacenamiento bidimensional de la matriz Hermítica A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44

!>  Almacenamiento empaquetado del triángulo superior de A:
!>

!>

NAME

sppsv, zppsv - SPPSV computes the solution to system of linear equations A * X = B for OTHER matrices

SYNOPSIS

subroutine sppsv(uplo, n, nrhs, ap, b, ldb, info)

character uplo
integer n
integer nrhs
real, dimension(*) ap
real, dimension(ldb,*) b
integer ldb
integer info

subroutine zppsv(uplo, n, nrhs, ap, b, ldb, info)

character uplo
integer n
integer nrhs
complex*16, dimension(*) ap
complex*16, dimension(ldb,*) b
integer ldb
integer info

Detailed Description

SPPSV computes the solution to a real system of linear equations A * X = B, where A is an N-by-N symmetric positive definite matrix stored in packed format and X and B are N-by-NRHS matrices.

The Cholesky decomposition is used to factor A as

   A = U**T* U,  if UPLO = 'U', or
   A = L * L**T,  if UPLO = 'L',

where U is an upper triangular matrix and L is a lower triangular matrix. The factored form of A is then used to solve the system of equations A * X = B.

ZZPSV computes the solution to a complex system of linear equations A * X = B, where A is an N-by-N Hermitian positive definite matrix stored in packed format and X and B are N-by-NRHS matrices.

The Cholesky decomposition is used to factor A as

   A = U**H * U,  if UPLO = 'U', or
   A = L * L**H,  if UPLO = 'L',

where U is an upper triangular matrix and L is a lower triangular matrix. The factored form of A is then used to solve the system of equations A * X = B.

subroutine sppsv (character uplo, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( ldb, * ) b, integer ldb, integer info)

SPPSV computes the solution to system of linear equations A * X = B for OTHER matrices

Purpose:

!>
!> SPPSV computes the solution to a real system of linear equations
!>    A * X = B,
!> where A is an N-by-N symmetric positive definite matrix stored in
!> packed format and X and B are N-by-NRHS matrices.
!>
!> The Cholesky decomposition is used to factor A as
!>    A = U**T* U,  if UPLO = 'U', or
!>    A = L * L**T,  if UPLO = 'L',
!> where U is an upper triangular matrix and L is a lower triangular
!> matrix.  The factored form of A is then used to solve the system of
!> equations A * X = B.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The number of linear equations, i.e., the order of the
!>          matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          A, packed columnwise in a linear array.  The j-th column of A
!>          is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>
!>          On exit, if INFO = 0, the factor U or L from the Cholesky
!>          factorization A = U**T*U or A = L*L**T, in the same storage
!>          format as A.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS right hand side matrix B.
!>          On exit, if INFO = 0, the N-by-NRHS solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the leading principal minor of order i
!>                of A is not positive, so the factorization could not
!>                be completed, and the solution has not been computed.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  The packed storage scheme is illustrated by the following example
!>  when N = 4, UPLO = 'U':
!>
!>  Two-dimensional storage of the symmetric matrix A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Packed storage of the upper triangle of A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
