Paquete: ppc64le-elf-binutils

Licencias: GPL

ADDR2LINE(1) Herramientas de desarrollo GNU ADDR2LINE(1)

NOMBRE

addr2line - convertir direcciones o símbolo+desplazamiento en nombres de archivo y números de línea

SINOPSIS

addr2line [-a|--addresses]
[-b nombrebfd|--target=nombrebfd]
[-C|--demangle[=estilo]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nombrearchivo|--exe=nombrearchivo]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nombre]
[-H|--help] [-V|--version]
[dir dir ...]

DESCRIPCIÓN

addr2line traduce direcciones o símbolo+desplazamiento en nombres de archivo y números de línea. Dada una dirección o un símbolo+desplazamiento en un ejecutable o un desplazamiento en una sección de un objeto relocable, utiliza la información de depuración para determinar qué nombre de archivo y número de línea están asociados con él.

El ejecutable o el objeto relocable a usar se especifica con la opción -e. El valor predeterminado es el archivo a.out. La sección en el objeto relocable a usar se especifica con la opción -j.

addr2line tiene dos modos de operación.

En el primero, se especifican direcciones hexadecimales o símbolo+desplazamiento en la línea de comandos, y addr2line muestra el nombre del archivo y el número de línea para cada dirección.

En el segundo, addr2line lee direcciones hexadecimales o símbolo+desplazamiento de la entrada estándar y, para cada dirección, imprime el nombre del archivo y el número de línea en la salida estándar. En este modo, addr2line puede usarse en una tubería para convertir direcciones seleccionadas dinámicamente.

El formato de la salida es NOMBREARCHIVO:NUMEROLINEA. Por defecto, cada dirección de entrada genera una línea de salida.

Dos opciones pueden generar líneas adicionales antes de cada línea de NOMBREARCHIVO:NUMEROLINEA (en ese orden).

Si se usa la opción -a, entonces se muestra una línea con la dirección de entrada.

Si se usa la opción -f, entonces se muestra una línea con el NOMBREFUNCIÓN. Este es el nombre de la función que contiene la dirección.

Una opción puede generar líneas adicionales después de la línea de NOMBREARCHIVO:NUMEROLINEA.

Si se usa la opción -i y el código en la dirección dada está presente debido a la incrustación (inlining) por parte del compilador, se mostrarán líneas adicionales después. Se mostrarán una o dos líneas extra (si se usa la opción -f) por cada función incrustada.

Alternativamente, si se usa la opción -p, entonces cada dirección de entrada genera una única línea de salida larga que contiene la dirección, el nombre de la función, el nombre del archivo y el número de línea. Si también se ha utilizado la opción -i, las funciones incrustadas se mostrarán de la misma manera, pero en líneas separadas y precedidas por el texto (incrustado por).

Si el nombre del archivo o el nombre de la función no se pueden determinar, addr2line imprimirá dos signos de interrogación en su lugar. Si el número de línea no se puede determinar, addr2line imprimirá 0.

Cuando se usa símbolo+desplazamiento, +desplazamiento es opcional, excepto cuando el símbolo es ambiguo con un número hexadecimal. Los símbolos resueltos pueden estar codificados o no, excepto que los símbolos no codificados con + no están permitidos.

OPCIONES

Las formas largas y cortas de las opciones, que se muestran aquí como alternativas, son equivalentes.

-a
--addresses
Muestra la dirección antes de la información del nombre de la función, archivo y número de línea. La dirección se imprime con un prefijo 0x para identificarla fácilmente.
-b nombrebfd
--target=nombrebfd
Especifica que el formato del código objeto para los archivos objeto es nombrebfd.
-C
--demangle[=estilo]
Decodifica (demangle) los nombres de símbolos de bajo nivel en nombres de nivel de usuario. Además de eliminar cualquier guion bajo inicial agregado por el sistema, esto hace que los nombres de funciones C++ sean legibles. Diferentes compiladores tienen diferentes estilos de codificación. El argumento opcional de estilo de decodificación puede utilizarse para elegir un estilo de decodificación apropiado para su compilador.
-e nombrearchivo
--exe=nombrearchivo
Especifica el nombre del ejecutable para el cual se traducirán las direcciones. El archivo predeterminado es a.out.
-f
--functions
Muestra los nombres de las funciones, así como la información del archivo y el número de línea.
-s
--basenames
Muestra solo la parte base de cada nombre de archivo.
-i
--inlines
Si la dirección pertenece a una función que fue incrustada (inlined), también se imprimirá la información fuente de todos los ámbitos contenedores hasta la primera función no incrustada. Por ejemplo, si "main" incrusta "callee1", que incrusta "callee2", y la dirección es de "callee2", también se imprimirá la información fuente de "callee1" y "main".
-j
--section
Lee los desplazamientos relativos a la sección especificada en lugar de direcciones absolutas.
-p
--pretty-print
Hace que la salida sea más amigable para el ser humano: cada ubicación se imprime en una línea. Si se especifica la opción -i, las líneas de todos los ámbitos contenedores se prefijan con (incrustado por).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Habilita o deshabilita un límite en la cantidad de recursión realizada al decodificar cadenas. Dado que los formatos de codificación de nombres permiten un nivel infinito de recursión, es posible crear cadenas cuya decodificación agote la cantidad de espacio de pila disponible en la máquina anfitriona, provocando una falla de memoria. El límite intenta evitar que esto suceda restringiendo la recursión a 2048 niveles de anidamiento.

El valor predeterminado es que este límite esté habilitado, pero deshabilitarlo puede ser necesario para decodificar nombres verdaderamente complicados. Tenga en cuenta, sin embargo, que si el límite de recursión está deshabilitado, es posible agotar la pila y cualquier informe de error sobre tal evento será rechazado.

La opción -r es un sinónimo de la opción --no-recurse-limit. La opción -R es un sinónimo de la opción --recurse-limit.

Tenga en cuenta que esta opción solo es efectiva si se ha habilitado la opción -C o --demangle.

@archivo
Lee las opciones de la línea de comandos de archivo. Las opciones leídas se insertan en lugar de la opción original @archivo. Si archivo no existe o no se puede leer, la opción se tratará literalmente y no se eliminará.

NAME

ppc64le-elf-addr2line - convert segment addresses to file names and line numbers

SYNOPSIS

ppc64le-elf-addr2line [-a | --all] [-e executable] [-f | --functions] [-i | --inlines] [-j | --imported] [-p | --demangle[=style]] [-R | --real-code] [-s | --basename] [-- addr...]

DESCRIPTION

The ppc64le-elf-addr2line utility uses the debugging information present in an executable file to translate addresses into symbol names, file names, and line numbers. It can also do the reverse, translating symbol names, file names, and line numbers into addresses.

This version of addr2line is built for the ppc64le-elf target.

The addresses are read from the input file specified by the environment variable ADR2LNE_DEFAULT_EXECUTE, or if that is not set, from standard input. If the -e option is specified, then the addresses from the executable file specified by that option are translated. If no executable file is specified, then addr2line uses the file named a.out by default.

The addresses are specified in hexadecimal format. Multiple addresses can be specified on the command line.

The output consists of pairs of lines. The first line of each pair indicates the name of the function containing the address. The second line indicates the file name and the line number within that file. The format is:

function name
  file:line number

If an address cannot be translated, then the corresponding function name and file name are replaced by “??”.

OPTIONS

-a, --all
Print all programming language information for the specified address. This includes all information that the -f and -e options print, plus inline function information.
-e executable
This option specifies the executable file which contains the debugging information.
-f, --functions
Print the name of the function associated with the address. This information is printed before the file name and line number.
-i, --inlines
Print information about inline function calls. When used with -a, it prints all programming language information for the specified address. If used alone, it prints only the inline function information.
-j, --imported
Print information from any imported symbol tables. This is useful for executables that have been linked with static archives.
-p, --demangle[=style]
Print the programming language symbol names rather than the raw compiler-generated symbol names. If style is given, it specifies which language to demangle. The default is auto-detection. Supported styles are listed by ppc64le-elf-c++filt --help.
-R, --real-code
Print the real function name. This option causes the function name to be printed even if it is inlined. This is only effective when used with -a or -i.
-s, --basename
Strip the directory name and only print the base name of the file name. This option can be used multiple times.
--
Marks the end of the options. Any subsequent arguments are treated as addresses, even if they start with a hyphen.

The addresses are read from standard input unless the -- option is used. If the -e option is not specified, then the executable file is read from standard input as well.

The output is in the following format:

function_name
  file_name:line_number

If the information is not available, then it is printed as “??”.

If the -f option is used, then the function name is printed before the file name and line number. If the -a option is used, then all available information is printed, including information about inlined functions.

If the -i option is used, then information about inline function calls is printed. If this option is used alone, only inline function information is printed. If used with -a, all information is printed.

If the -R option is used, then the real function name is printed, even if it is inlined. This option is only effective when used with -a or -i.

If the -s option is used, then only the basename of the file name is printed.

If the -p option is used, then the function names are demangled. The default behavior is to not demangle.
