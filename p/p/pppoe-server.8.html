PPPOE-SERVER(8) Manual del Administrador del Sistema PPPOE-SERVER(8)

NOMBRE

pppoe-server - servidor PPPoE en espacio de usuario

SINOPSIS

pppoe-server [opciones]

DESCRIPCIÓN

pppoe-server es un servidor en espacio de usuario para PPPoE (Protocolo de Túnel Punto a Punto sobre Ethernet) para Linux y otros sistemas UNIX. pppoe-server funciona en conjunto con el cliente pppoe para responder a los paquetes de descubrimiento PPPoE y establecer sesiones PPPoE.

OPCIONES

-F
La opción -F hace que pppoe-server no se bifurque y se convierta en un demonio. El valor predeterminado es bifurcarse y convertirse en un demonio.
-I interfaz
La opción -I especifica la interfaz Ethernet a utilizar. En Linux, típicamente es eth0 o eth1. La interfaz debe estar "arriba" antes de iniciar pppoe-server, pero no necesita tener una dirección IP. Puede proporcionar múltiples opciones -I si desea que el servidor responda en más de una interfaz.
-X archivo_pid
Esta opción hace que pppoe-server escriba su ID de proceso en archivo_pid. Además, mantiene el archivo bloqueado para que solo un proceso pueda iniciarse para un archivo_pid dado.
-q /ruta/a/pppd
Especifica la ruta completa al programa pppd. El valor predeterminado se determina en tiempo de compilación. Un uso de esta opción es proporcionar un script de envoltura que modifique los argumentos pasados a pppd. Esto le permite hacer cosas que no son compatibles directamente con el servidor (por ejemplo, especificar direcciones IPv6).
-Q /ruta/a/pppoe
Especifica la ruta completa al programa pppoe. El valor predeterminado se determina en tiempo de compilación. Esta opción solo es relevante si *no* está utilizando PPPoE en modo kernel.
-T tiempo_espera
Esta opción se pasa directamente a pppoe; consulte pppoe(8) para obtener detalles. Si está utilizando PPPoE en modo kernel, esta opción no tiene *ningún efecto*.
-C nombre_ac
Especifica qué nombre reportar como nombre del concentrador de acceso. Si no se proporciona, se utiliza el nombre del host.
-S nombre
Ofrece un servicio llamado nombre. Se pueden especificar múltiples opciones -S; cada una hace que el servicio nombrado se anuncie en una etiqueta Service-Name en el paquete PADO. La primera opción -S especifica el servicio predeterminado y se utiliza si el cliente PPPoE solicita un Service-Name de longitud cero.
-m MSS
Esta opción se pasa directamente a pppoe; consulte pppoe(8) para obtener detalles. Si está utilizando PPPoE en modo kernel, esta opción no tiene *ningún efecto*.
-x n
Limita el número de sesiones por dirección MAC del par a n. Si una dirección MAC dada intenta crear más de n sesiones, entonces sus paquetes PADI y PADR se ignoran. Si establece n en 0 (el valor predeterminado), no se impone ningún límite al número de sesiones por dirección MAC del par.
-s
Esta opción se pasa directamente a pppoe; consulte pppoe(8) para obtener detalles. Además, hace que pppd se invoque con la opción sync.
-L ip
Establece la dirección IP local. Esto se pasa a los procesos pppd generados. Si no se especifica, el valor predeterminado es 10.0.0.1. Si se especifica como 0.0.0.0, la selección de la dirección IP local se delega a pppd.
-R ip
Establece la dirección IP remota de inicio. A medida que se establecen las sesiones, las direcciones IP se asignan a partir de ip. pppoe-server realiza automáticamente un seguimiento del grupo de direcciones y pasa una dirección IP remota válida a pppd. Si no se especifica, se utiliza una dirección de inicio de 10.67.15.1. Si se especifica como 0.0.0.0, la asignación de IP remota se delegará a pppd.
-N num
Permite como máximo num sesiones PPPoE concurrentes. Si no se especifica, el valor predeterminado es 64.
-M cadena
Envía cadena en una etiqueta MOTM en un paquete PADM justo después de enviar el PADS a un cliente.
-H url
Envía url en una etiqueta HURL en un paquete PADM justo después de enviar el PADS a un cliente. Tenga en cuenta que url debe comenzar con http:// o https://.
-O fname
Esta opción hace que pppoe-server indique a pppd que utilice el archivo de opciones fname en lugar del archivo predeterminado /etc/ppp/pppoe-server-options.
-p fname
Lee el archivo especificado fname, que es un archivo de texto que consiste en una dirección IP por línea. Estas direcciones IP se asignarán a los clientes. El número de sesiones permitidas será igual al número de direcciones encontradas en el archivo. La opción -p anula tanto -R como -N.

Además de contener direcciones IP, el archivo de grupo puede contener líneas de la forma:

a.b.c.d-e

que incluye todas las direcciones IP desde a.b.c.d hasta a.b.c.e. Por ejemplo, la línea:

1.2.3.4-7

es equivalente a:

1.2.3.4
1.2.3.5
1.2.3.6
1.2.3.7
-r
Indica al servidor PPPoE que permute aleatoriamente los números de sesión. En lugar de entregar las sesiones en orden, los números de sesión se asignarán en un orden impredecible.
-u
Indica al servidor que invoque pppd con la opción unit. Tenga en cuenta que esta opción solo funciona para la versión 2.4.0 o posterior de pppd.
-o offset
En lugar de numerar las sesiones PPPoE a partir de 1, se numerarán a partir de offset+1. Esto le permite ejecutar varios servidores en una máquina determinada; solo asegúrese de que sus números de sesión no se solapen.
-f disc:sess
La opción -f establece los tipos de trama Ethernet para el descubrimiento PPPoE y las tramas de sesión. Los tipos se especifican como números hexadecimales separados por dos puntos. PPPoE estándar utiliza los tipos de trama 8863:8864. No debe usar esta opción a menos que esté absolutamente seguro de que el par con el que está tratando utiliza tipos de trama no estándar.
-k
La opción -k indica al servidor que utilice PPPoE en modo kernel en Linux. Esta opción solo está disponible en los kernels de Linux 2.4.0 y posteriores, y solo si el servidor se compiló con soporte para modo kernel.
-g ruta
La opción -g indica al servidor la ruta completa al plugin pppoe.so o rp-pppoe.so que se utilizará con PPPoE en modo kernel. Si se omite, se utiliza un valor predeterminado compilado; este valor predeterminado se puede mostrar utilizando la opción -h.
-i
La opción -i indica al servidor que ignore por completo los paquetes PADI si no hay ranuras de sesión libres.
-h
La opción -h imprime un breve mensaje de uso y sale.
-U ruta
La opción -U crea un socket UNIX al que se puede conectar para gestionar pppoe-server en tiempo de ejecución. Consulte la sección SOCKET DE CONTROL a continuación para obtener instrucciones más detalladas.

OPERACIÓN

pppoe-server escucha los paquetes de descubrimiento PPPoE entrantes. Cuando se establece una sesión, genera un proceso pppd. Las siguientes opciones se pasan a pppd:

nodetach noaccomp nobsdcom nodeflate nopcomp novj novjccomp
default-asyncmap

pppoe-server(8)

NAME

pppoe-server ― pppoe servidor

SYNOPSIS

pppoe-server [-h | -v] [-d] [-U socket] [-L local_ip] [-R remote_ip] [pppd_options]

DESCRIPTION

pppoe-server se utiliza para iniciar múltiples sesiones PPPoE a partir de un único servidor PPPoE. Normalmente, un servidor PPPoE se utiliza para proporcionar el acceso a Internet a múltiples clientes PPPoE.

El servidor se inicia con un comando pppoe en ejecución. El servidor pppoe-server se comunica con el programa pppoe y éste se comunica con el programa pppd.

pppoe-server requiere que el programa pppoe esté instalado y se ejecute en el sistema.

OPTIONS

-d
Activa el modo de depuración. En este modo, pppoe-server imprimirá información detallada sobre el funcionamiento de la red PPPoE.
-h
Muestra un mensaje de ayuda y sale.
-L local_ip
Establece la dirección IP local que se asignará a los clientes PPPoE. Si no se especifica, se utilizará la dirección IP de la interfaz de red por defecto.
-R remote_ip
Establece la dirección IP remota que se asignará a los clientes PPPoE. Si no se especifica, se utilizará la dirección IP de la interfaz de red por defecto.
-U socket
Crea un socket de control en la ruta especificada. Este socket puede utilizarse para controlar el servidor pppoe-server en tiempo de ejecución. Consulte la sección CONTROL-SOCKET para más información.
-v
Muestra la versión del programa y sale.

OPERATION

La dirección IP local y remota se establecen basándose en las opciones -L y -R. La opción pty se suministra junto con un comando pppoe para iniciar la sesión PPPoE. Finalmente, las opciones adicionales de pppd se pueden colocar en el archivo /etc/ppp/pppoe-server-options (¡que debe existir, aunque solo esté vacío!).

Tenga en cuenta que pppoe-server está diseñado principalmente para probar clientes PPPoE. No es un servidor de alto rendimiento destinado a uso en producción.

CONTROL-SOCKET

El control-socket se implementó como un mecanismo secundario para mejorar el control en tiempo de ejecución del servidor pppoe-server. Para utilizarlo, necesita iniciar pppoe-server con la opción -U descrita anteriormente. A continuación, puede (en ausencia de un cliente de control actualmente) utilizar netcat para conectarse al socket de control, por ejemplo:

nc -U /run/pppoe-server.control

Suponiendo que se pasó -U /run/pppoe-server.control a pppoe-server.

Los siguientes comandos están implementados:

set drain {off|on|quit}
Esto establecerá si pppoe-server responde o no a los paquetes PADI. Cuando se establece en off, pppoe-server responderá; de lo contrario, los paquetes PADI se ignorarán. Esto permite que pppoe-server se vacíe de clientes. Además, cuando se establece en quit, se terminará pppoe-server cuando todos los pppoe-clients hayan terminado.

Esto permite actualizaciones (en su mayoría) sin problemas, en el sentido de que a la instancia en ejecución se le puede emitir "set drain quit" antes de iniciar una nueva interfaz en las mismas interfaces, permitiendo así que se realicen nuevas conexiones mientras se mantiene el estado correcto en los clientes existentes.

show status
Esto mostrará información básica del estado del servidor pppoe-server al que se ha conectado.
