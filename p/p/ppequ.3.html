CPPEQU

Propósito:

!>
!> CPPEQU calcula escalados de filas y columnas destinados a equilibrar una
!> matriz hermitiana definida positiva A en almacenamiento empaquetado y reducir
!> su número de condición (con respecto a la norma dos). S contiene los
!> factores de escala, S(i)=1/sqrt(A(i,i)), elegidos de tal manera que la matriz escalada
!> B con elementos B(i,j)=S(i)*A(i,j)*S(j) tenga unos en la diagonal.
!> Esta elección de S pone el número de condición de B dentro de un factor N del
!> número de condición mínimo posible sobre todos los escalados diagonales posibles.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array COMPLEX, de dimensión (N*(N+1)/2)
!>          El triángulo superior o inferior de la matriz hermitiana A, empaquetado
!>          por columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

S

!>          S es un array REAL, de dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación entre el S(i) más pequeño y
!>          el S(i) más grande. Si SCOND >= 0.1 y AMAX no es ni demasiado
!>          grande ni demasiado pequeño, no merece la pena escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento más grande de la matriz. Si AMAX está muy
!>          cerca del desbordamiento o del subdesbordamiento, la matriz
!>          debería ser escalada.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal es no positivo.
!>

NAME

ppequ - pre-conditioner calculation for general matrices

SYNOPSIS

   subroutine sppequ(uplo, n, a, lda, s, scond, amax, info)
       character uplo
       integer n
       real a(lda,*)
       integer lda
       real s(*)
       real scond
       real amax
       integer info

   subroutine dppequ(uplo, n, a, lda, s, scond, amax, info)
       character uplo
       integer n
       double precision a(lda,*)
       integer lda
       double precision s(*)
       double precision scond
       double precision amax
       integer info

   subroutine cppequ(uplo, n, a, lda, s, scond, amax, info)
       character uplo
       integer n
       complex a(lda,*)
       integer lda
       real s(*)
       real scond
       real amax
       integer info

   subroutine zppequ(uplo, n, a, lda, s, scond, amax, info)
       character uplo
       integer n
       double complex a(lda,*)
       integer lda
       double precision s(*)
       double precision scond
       double precision amax
       integer info

Description

The routines compute row and column scalings intended to equilibrate a general n-by-n matrix A in partitioned storage and reduce its condition number (with respect to the two-norm). S contains the scale factors S(i)=1/sqrt(A(i,i)) chosen so that the scaled matrix B with elements B(i,j)=S(i)*A(i,j)*S(j) has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.

The routines require the matrix A to be Hermitian positive definite.

The argument UPLO specifies whether the upper or lower triangular part of the matrix A is supplied.

All routines are interface routines to the lower level routines sppequ, dppequ, cppequ, and zppequ.

The routines compute row and column scalings intended to equilibrate a general N-by-N matrix A in partitioned storage and reduce its condition number (with respect to the two-norm). S contains the scale factors S(i)=1/sqrt(A(i,i)) chosen so that the scaled matrix B with elements B(i,j)=S(i)*A(i,j)*S(j) has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.

The routines require the matrix A to be Hermitian positive definite.

The argument UPLO specifies whether the upper or lower triangular part of the matrix A is supplied.

Arguments

UPLO
CHARACTER*1. = 'U': Upper triangle of A is stored; = 'L': Lower triangle of A is stored.
N
INTEGER. The order of the matrix A. N >= 0.
A
REAL, DOUBLE PRECISION, COMPLEX, DOUBLE COMPLEX array, dimension (LDA, N). The N-by-N matrix A. The elements of A must be stored in packed format according to the value of UPLO.
LDA
INTEGER. The leading dimension of the array A. LDA >= max(1,N).
S
REAL, DOUBLE PRECISION array, dimension (N).
SCOND
REAL, DOUBLE PRECISION. If INFO = 0, S contains the ratio of the smallest S(i) to the largest S(i). If SCOND >= 0.1 and AMAX is neither too large nor too small, it is not worth scaling by S.
AMAX
REAL, DOUBLE PRECISION. If INFO = 0, AMAX contains the absolute value of the largest matrix element. If AMAX is very close to overflow or very close to underflow, the matrix should be scaled.
INFO
INTEGER.
= 0: successful exit.
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: if INFO = i, the i-th diagonal element is nonpositive. This means that the matrix is not positive definite.
