PPL_LPSOL(1) Comandos de Usuario PPL_LPSOL(1)

NOMBRE

ppl_lpsol - un solucionador de problemas de programación lineal mixta basado en PPL

SINOPSIS

ppl_lpsol [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

Lee un archivo en formato MPS e intenta resolverlo utilizando los algoritmos de optimización proporcionados por PPL.

Consulte el Manual de Referencia de GNU Linear Programming Kit (Versión 4.31) para obtener información sobre el formato MPS.

OPCIONES

-c, --check[=UMBRAL] comprueba los resultados obtenidos usando GLPK;
los óptimos se comprueban con una tolerancia de UMBRAL (por defecto 1e-09); los datos de entrada también se perturban de la misma manera que lo hace GLPK.
-i, --incremental
resuelve el problema de forma incremental.
-m, --min
minimiza la función objetivo.
-M, --max
maximiza la función objetivo (por defecto).
-n, --no-optimization
solo comprueba la satisfacibilidad.
-r, --no-mip
considera las variables enteras como variables reales.
-CSECS, --max-cpu=SECS
limita el uso de CPU a SECS segundos.
-RMB, --max-memory=MB
limita el uso de memoria a MB megabytes.
-h, --help
imprime esta ayuda en la salida estándar.
-oPATH, --output=PATH
añade la salida a PATH.
-e, --enumerate
utiliza el método de enumeración (¡costoso!).
-pM, --pricing=M
utiliza el método de precios M para el simplex (asume -s); M es un entero de 0 a 2, por defecto 0: 0 --> borde más pronunciado usando aritmética de punto flotante 1 --> borde más pronunciado usando aritmética exacta 2 --> de libro de texto.
-s, --simplex
utiliza el método simplex.
-t, --timings
imprime tiempos en la salida de error.
-v, --verbosity=NIVEL
establece el nivel de verbosidad (de 0 a 4, por defecto 3): 0 --> silencioso: sin salida excepto errores y
notificaciones explícitamente requeridas
1 --> solo estado del solucionador 2 --> estado + valor óptimo 3 --> estado + valor óptimo + ubicación del óptimo 4 --> mucha salida
-V, --version
imprime información de la versión en la salida estándar.

DISPONIBILIDAD

NOTAS

Las opciones -CSECS (--max-cpu=SECS) y -t (--timings) no están disponibles en algunas plataformas.
