Paquete: pppusage

Licencias: GPL

PPPUSAGE(1p) Documentación de Perl aportada por el usuario PPPUSAGE(1p)

NOMBRE

pppusage - genera resúmenes de conexión PPP

SINOPSIS

pppusage [-bcq] [-f archivo de datos] [-t aaaa[mm[dd]][-aaaa[mm[dd]]]] [archivo de registro...]

pppusage [-hv]

DESCRIPCIÓN

pppusage resume los volúmenes de transferencia promedio y total, el número de conexiones y el tiempo promedio y total en línea para todas las conexiones PPP registradas. Los datos se recopilan leyendo los archivos de registro de logfiles que contienen los mensajes de ppp[d]. Se pueden leer varios archivos de registro (es decir, los archivos de registro de ppp[d] activos y rotados) para asegurar que no se pierdan nuevas entradas de ppp[d] cuando el archivo de registro relevante se rote antes de que pppusage haya visto las entradas. Sin embargo, ¡consulte "ADVERTENCIAS" abajo! pppusage guarda los datos relevantes en archivo de datos (una base de datos Berkeley DB) que se puede actualizar automáticamente de forma regular utilizando cron(5) o algo similar.

OPCIONES

Por defecto, pppusage realiza los cuatro pasos: Analiza los archivos de registro de PPP, guarda los datos, lee los datos guardados y muestra los resúmenes de todos los datos disponibles. Puede dividir la creación de la base de datos por un lado y su consulta por el otro utilizando algunas de las siguientes opciones.

-b
No utilice colores ni atributos ANSI para la salida de pppusage.
-c
Analiza los archivos de registro de PPP, actualiza el archivo de base de datos Berkeley DB (o lo crea si no existe) y sale. Esta opción es especialmente útil si desea que la base de datos se actualice automáticamente en segundo plano de forma regular. Por ejemplo: 
05 14 * * * nice /usr/bin/core_perl/pppusage -c > /dev/null

Esta entrada de crontab(5) actualizaría la base de datos una vez al día (a las 14:05).

-f archivo de datos
Especifique el archivo de base de datos que debe ser utilizado por pppusage.
-q
Consulta la base de datos: Lee el archivo de base de datos y muestra los resúmenes. Si el rango de tiempo no se especifica con -t, se procesarán todos los datos disponibles.
-h
Muestra un resumen rápido de todas las opciones disponibles y sale.
-t aaaa[mm[dd]][-<aaaa>[mm[dd]]]
Especifique el período de tiempo para una consulta. Esto se puede hacer especificando un solo año, mes o día, o especificando un rango de tiempo. Un rango de tiempo se utiliza especificando dos fechas separadas por un `-'. El orden en que se dan las dos fechas es irrelevante. Se puede especificar cualquier combinación de días, meses o años. Implica -q.
-v
Muestra la información de la versión y sale.

CONFIGURACIÓN

El archivo de configuración utilizado por pppusage es simplemente un archivo de perl que se lee al inicio. Tanto los archivos de registro a analizar como el archivo de base de datos a utilizar se pueden ajustar estableciendo las siguientes variables. Sin embargo, especificarlos en la línea de comandos anulará estas configuraciones. Los valores por defecto se muestran entre corchetes.

$logfiles = 'archivo de registro...'; [`ls /var/log/messages*`]
Los archivo(s) de registro de ppp[d] a analizar. Se debe utilizar una lista separada por espacios para especificar varios archivos. Tenga en cuenta que si especifica los archivos a analizar directamente (en lugar de usar la salida de un comando como ls), debe usar comillas normales, ¡no comillas invertidas!
$datafile = 'archivo de datos'; ['/tmp/pppusage.db']
El archivo que utiliza pppusage para almacenar sus datos. Normalmente, tiene sentido establecer esto en una ruta diferente, especialmente si el directorio /tmp se borra de vez en cuando (por ejemplo, mediante un trabajo de cron(5) o al arrancar).
$configured = 0|1; [0]
Olvide esta variable. La necesitábamos para asegurarnos de que aquellos de ustedes que actualizaron desde versiones anteriores de pppusage hayan configurado $logfiles correctamente obligándoles a abrir el archivo de configuración y estableciendo $configured a 1 ;-) De hecho, puede eliminar esta variable por completo. Se eliminará de futuras versiones de pppusage.

EJEMPLOS

pppusage

Analiza los archivos de registro donde ppp[d] registra sus mensajes, guarda los datos relevantes en un archivo Berkeley DB y escribe resúmenes sobre todos los datos disponibles en STDOUT.

pppusage -t 2003

Busca en el archivo de base de datos todas las conexiones PPP registradas en 2003 y escribe los resultados en STDOUT.

pppusage -t 200305

Busca en el archivo de base de datos todas las conexiones PPP registradas en mayo de 2003 y escribe los resultados en STDOUT.

pppusage -t 2003-200303

Busca en el archivo de base de datos todas las conexiones PPP registradas en el primer trimestre de 2003 y escribe los resultados en STDOUT.

pppusage -t 20030915-20030931

Busca en el archivo de base de datos todas las conexiones PPP registradas en la segunda mitad de septiembre de 2003 y escribe los resultados en STDOUT.

pppusage -b -f /tmp/pppusage.2002.db -t 20020501

Busca en el archivo de base de datos /tmp/pppusage.2002.db todas las conexiones PPP registradas el 1 de mayo de 2002 y muestra los resultados sin usar colores ni atributos ANSI.

ARCHIVOS

~/.pppusagerc
Archivo de configuración del usuario.

/etc/pppusagerc
Archivo de configuración a nivel de sistema.

ADVERTENCIAS

Dado que pppusage intenta obtener varios archivos de registro en el orden correcto simplemente ordenándolos por su hora de última modificación, alimentar varios archivos de registro a pppusage probablemente producirá una base de datos corrupta si fueron modificados después de haber sido rotados.

Peor aún: actualizar una base de datos *existente* con archivos de registro que contienen datos *más antiguos* que los datos ya analizados tampoco funcionará. Esto resultaría nuevamente en una base de datos corrupta.

En ambos casos, el archivo de base de datos debe ser eliminado y recreado.

ERRORES

Lo más probable es que haya algunos. ¡Por favor, hágame saber si los encuentra!
