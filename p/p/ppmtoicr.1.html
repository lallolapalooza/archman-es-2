NOMBRE

ppmtoicr - convertir una imagen PPM a formato NCSA ICR

SINOPSIS

ppmtoicr

[-windowname nombre]

[-expand expandir]

[-display display]

[-rle]

[archivo_ppm]

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ppmtoicr lee un archivo PPM como entrada. Produce un archivo NCSA Telnet Interactive Color Raster como salida.

Si no se proporciona archivo_ppm, ppmtoicr lee de la entrada estándar.

Interactive Color Raster (ICR) es un protocolo para mostrar gráficos rasterizados en pantallas de estaciones de trabajo. El protocolo está implementado en NCSA Telnet para Macintosh versión 2.3. El protocolo ICR comparte características del protocolo de emulación de terminal gráfico Tektronix. Por ejemplo, se usan secuencias de escape para controlar la pantalla.

ppmtoicr generará las secuencias apropiadas para crear una ventana con las dimensiones de la imagen de entrada, crear un mapa de colores de hasta 256 colores en la pantalla, y luego cargar los datos de la imagen en la ventana.

Tenga en cuenta que no existe una herramienta icrtoppm; esta transformación es unidireccional.

OPCIONES

-windowname nombre
La salida se mostrará en nombre (Por defecto, se usa archivo_ppm o 'untitled' si la entrada es de la entrada estándar).
-expand expandir
La salida se expandirá en pantalla por el factor expandir (Por ejemplo, un valor de 2 hará que se muestren cuatro píxeles por cada píxel de entrada.)
-display display
La salida se mostrará en la pantalla número display
-rle
Usar formato de codificación run-length para la visualización. (Esto casi siempre resultará en una visualización más rápida, pero puede distorsionar el mapa de colores).

EJEMPLOS

Para mostrar un archivo PPM llamado archivo_ppm usando el protocolo:

    ppmtoicr archivo_ppm

Esto creará una ventana llamada archivo_ppm en la pantalla con las dimensiones correctas para archivo_ppm, creará y descargará un mapa de colores de hasta 256 colores, y descargará la imagen en la ventana. Puede lograr el mismo efecto con la siguiente secuencia:

    ppmtoicr archivo_ppm > nombre_archivo
    cat nombre_archivo

Para mostrar un archivo GIF usando el protocolo en una ventana titulada según el archivo de entrada, ampliar la imagen mostrada por un factor de 2 y codificar en run-length los datos:

    giftopnm archivo_gif | ppmtoicr -w archivo_gif -r -e 2

LIMITACIONES

El protocolo utiliza llamadas frecuentes a fflush() para acelerar la visualización. Si guarda la salida en un archivo para su posterior visualización mediante cat, ppmtoicr dibujará mucho más lentamente. En cualquier caso, aumentar el tamaño del bloque límite en la pantalla acelerará sustancialmente la transmisión.
