NOMBRE

ppmlabel - añadir texto a una imagen PPM

SINOPSIS

ppmlabel

[-angulo angulo]

[-fondo { transparente | color } ]

[-color color]

[-archivo nombre_archivo]

[-tamaño

tamaño_texto]

[-texto cadena_texto]

[-x columna]

[-y fila]

...

[archivo_ppm]

EJEMPLO


    ppmlabel -x 50 -y 50 -texto hola \
             -angulo -30 -texto mundo \
             testimg.ppm

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

ppmlabel utiliza las facilidades de dibujo de texto del componente 'ppmd' de libnetpbm para añadir texto a una imagen PBM. Controlas la ubicación, el tamaño, el ángulo de la línea base, el color del texto y el color de fondo (si lo hay) con argumentos de línea de comandos. Puedes especificar el texto en la línea de comandos o proporcionarlo en archivos.

Puedes añadir cualquier número de etiquetas separadas en una sola invocación de ppmlabel, limitado solo por cualquier restricción que tenga tu entorno sobre el número y tamaño de los argumentos del programa (por ejemplo, el límite de tamaño de comando de un shell).

Si no especificas archivo_ppm, ppmlabel lee su imagen PPM de entrada de la Entrada Estándar.

La imagen de salida va a la Salida Estándar.

Una forma más sofisticada de añadir una etiqueta a una imagen es usar pbmtext o pbmtextps para crear una imagen del texto, y luego pamcomp para superponerla sobre la imagen base.

Otro programa más general es ppmdraw. Es un poco más difícil de usar para etiquetado simple.

OPCIONES

Los argumentos en la línea de comandos de ppmlabel no son opciones en el sentido estricto; son comandos que controlan la colocación y la apariencia del texto que se añade a la imagen de entrada. Se ejecutan de izquierda a derecha, y puede aparecer cualquier número de argumentos.

Puedes abreviar cualquier opción a su prefijo único más corto.

-angulo angulo
Esta opción establece el ángulo de la línea base del texto subsiguiente. angulo es un número entero de grados, medido en sentido contrario a las agujas del reloj desde el eje de fila de la imagen.
-fondo { transparente | color }
Si el argumento es transparente, ppmlabel dibuja el texto sobre los píxeles existentes en la imagen. Si especificas un color (ver la opción -color abajo para información sobre cómo especificar colores), ppmlabel genera rectángulos de fondo que encierran el texto subsiguiente, y esos rectángulos se rellenan con ese color.
-color color
Esta opción establece el color para el texto subsiguiente.

Especifica el color (color) como se describe para el argumento de la rutina de la biblioteca ppm_parsecolor().

-color es una ortografía alternativa aceptable.

-archivo nombre_archivo
Esta opción hace que ppmlabel lea líneas de texto del archivo llamado nombre_archivo y lo dibuje en líneas sucesivas.
-tamaño tamaño_texto
Esta opción establece la altura de los caracteres más altos por encima de la línea base en tamaño_texto píxeles.
-texto cadena_texto
Esta opción hace que ppmlabel dibuje la cadena de texto especificada. Avanza la ubicación para el texto subsiguiente 1.75 veces el tamaño_texto actual. Eso te permite dibujar múltiples líneas de texto de manera razonable sin especificar la posición de cada línea.

Ten en cuenta que si invocas ppmlabel a través de un comando de shell y tu cadena de texto contiene espacios, tendrás que ponerla entre comillas para que el shell trate toda la cadena como un único token. Por ejemplo:

  $ ppmlabel -texto "este es mi texto" imagenbase.ppm >imagenganotada.ppm
-x columna
Esta opción establece la columna de píxel en la que el texto subsiguiente será justificado a la izquierda. Dependiendo de la forma del primer carácter, el texto real puede comenzar unos pocos píxeles a la derecha de este punto.
-y fila
Esta opción establece la fila de píxel que formará la línea base del texto subsiguiente. Los caracteres con descendentes, como "y", se extenderán por debajo de esta línea.

LIMITACIONES

Las cadenas de texto están restringidas a 7 bits ASCII. La fuente de texto utilizada por ppmlabel no incluye definiciones para caracteres de 8 bits ISO 8859/1.

Al dibujar múltiples líneas de texto con un fondo no transparente, probablemente debería rellenar el espacio entre las líneas con el color de fondo. Esto es difícil de hacer correctamente cuando el texto está rotado a un ángulo no ortogonal.
