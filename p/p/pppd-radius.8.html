PPPD-RADIUS(8) Manual del Administrador del Sistema PPPD-RADIUS(8)

NOMBRE

radius.so - plugin de autenticación RADIUS para pppd(8)

SINOPSIS

pppd [ opciones ] plugin radius.so

DESCRIPCIÓN

El plugin RADIUS para pppd permite a pppd realizar autenticación PAP, CHAP, MS-CHAP y MS-CHAPv2 contra un servidor RADIUS en lugar de los archivos habituales /etc/ppp/pap-secrets y /etc/ppp/chap-secrets.

El plugin RADIUS está construido sobre una biblioteca llamada radiusclient que tiene sus propios archivos de configuración (generalmente en /etc/radiusclient), consulte esos archivos para obtener más información sobre la configuración del plugin RADIUS.

OPCIONES

El plugin RADIUS introduce una opción adicional de pppd:

archivo-config-radius nombre_archivo
El archivo nombre_archivo se toma como el archivo de configuración de radiusclient. Si no se utiliza esta opción, el plugin utiliza /etc/radiusclient/radiusclient.conf como archivo de configuración.
paravpar atributo=valor
Agrega un par Atributo-Valor para ser pasado al servidor RADIUS en cada solicitud.
mapear-a-nombre-interfaz
Establece el atributo Radius NAS-Port a un número igual al nombre de la interfaz (Predeterminado)
mapear-a-nombre-tty
Establece el valor del atributo Radius NAS-Port a través de la biblioteca libradiusclient.

USO

Para usar el plugin, simplemente proporcione la opción plugin radius.so a pppd y edite apropiadamente /etc/radiusclient/radiusclient.conf. Si utiliza el plugin RADIUS, los esquemas de autenticación normales de pppd (login, comprobación de los archivos /etc/ppp/*-secrets) se omiten. El servidor RADIUS debe asignar una dirección IP al par utilizando el atributo RADIUS Framed-IP-Address.
