NOMBRE

ppmdraw - dibuja líneas, texto, etc. en una imagen PPM

SINOPSIS

ppmdraw

{ -script=script | -scriptfile=archivo } [-verbose]

[archivoppm]

Todas las opciones se pueden abreviar a su prefijo único más corto. Puede usar dos guiones en lugar de uno para designar una opción. Puede usar espacio en blanco o un signo de igual entre el nombre de una opción y su valor.

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ppmdraw dibuja líneas, formas, texto, etc. en una imagen PPM. Es esencialmente una interfaz fácil de programar para las subrutinas 'ppmd' de libnetpbm. Le permite crear un script fácil de entender para describir el dibujo en lugar de escribir un programa en C.

Usted proporciona instrucciones de dibujo con un script, que proporciona ya sea en un archivo nombrado por una opción -scriptfile o como el valor de una opción -script. Aquí hay un ejemplo de script:


setpos 50 50;
text_here 10 30 'hello';
setcolor black;
text_here 10 0 'there';
line_here 5 20;

Este ejemplo comienza en la Columna 50, Fila 50 de la imagen de entrada y escribe la palabra 'hello' allí con letras de 10 píxeles de altura en un ángulo de 30 grados hacia arriba desde la horizontal. Luego, desde donde termina eso, el script escribe 'there' en letras negras de 10 píxeles de altura horizontalmente. Finalmente, dibuja una línea negra hacia un punto a 5 píxeles de distancia hacia la derecha y 20 píxeles hacia abajo desde el final de 'there'.

Si no especifica archivoppm, ppmdraw lee su imagen PPM de entrada desde la Entrada Estándar.

La imagen de salida va a la Salida Estándar.

ppmdraw funciona en flujos de múltiples imágenes. Ejecuta el mismo script en cada imagen de entrada y produce un flujo de salida con una imagen por cada imagen de entrada. Pero antes de Netpbm 10.32 (febrero de 2006), ppmdraw ignoraba todas las imágenes después de la primera.

Si solo desea agregar una sola línea de texto a una imagen, ppmlabel puede ser más lo que desea.

OPCIONES

-script=script
Esta opción proporciona el script. Ver Script.

No puede especificar tanto -script como -scriptfile.

-scriptfile=archivo
Esta opción nombra un archivo que contiene el script. - significa Entrada Estándar.

No puede especificar tanto -script como -scriptfile.

No puede especificar - (Entrada Estándar) tanto para -scriptfile como para el archivo de imagen de entrada.

SCRIPT

El corazón de la función de ppmdraw es su script. El script es un flujo de caracteres. El flujo consiste en comandos. Los comandos están separados por puntos y comas. Los espacios en blanco se consideran igual que en C: cualquier tramo contiguo de espacio en blanco sin comillas equivale a un solo carácter de espacio. Tenga en cuenta que esto significa que las líneas nuevas no tienen una importancia particular.

Un comando se compone de tokens, separados entre sí por espacios en blanco. Para escribir un token que contenga espacios en blanco, enciérrelo entre comillas dobles. Todo lo que está entre dos comillas coincidentes es un token.

El primer token de un comando es el verbo, que determina la función básica del comando. El resto de los tokens del comando son argumentos, cuyo significado depende del verbo. La siguiente lista da todos los verbos válidos, y para cada uno su significado y sus argumentos.

Muchos comandos tienen argumentos que especifican una posición en el lienzo, que usted especifica por fila y columna. La fila 0 es la fila superior. La columna 0 es la columna más a la izquierda. Puede especificar números negativos (pero tal posición estaría necesariamente fuera del lienzo).

Sus instrucciones de dibujo pueden involucrar posiciones que no estén en el lienzo. Pero cualquier píxel que dibuje allí simplemente se descarta.

setpos
Establece la 'posición actual' en la imagen. Esto afecta dónde los comandos posteriores dibujan cosas. Los 2 argumentos son el número de columna y fila.

Al inicio del script, la posición actual es (0,0).

setlinetype
El argumento 1 es 'normal' o 'nodiag.'. Esto afecta una llamada a ppmd_setlinetype(). Aún no se documentan más detalles.
setlineclip
Esto afecta una llamada a ppmd_setlineclip(). Aún no se documenta.
setcolor
Esto establece el 'color actual', que determina el color en el que los comandos de dibujo posteriores dibujan. Antes del primer setcolor, el color actual es blanco.
setfont
Esto establece la 'fuente actual', que determina la fuente en la que los comandos de dibujo de texto posteriores dibujan. Antes de la primera setfont, la fuente actual es una fuente integrada llamada 'standard'.

El argumento de este comando es un nombre de archivo. Es el nombre de un archivo de fuente PPMD de Netpbm.

Un archivo de fuente PPMD de Netpbm típicamente tiene un nombre que termina en '.ppmdfont' y sus primeros 8 bytes son la codificación ASCII de 'ppmdfont'.

Solo hay una de estas fuentes hasta donde sabemos. Se distribuye con Netpbm como el archivo standard.ppmdfont, pero no necesita usar ese archivo porque la misma fuente está integrada en la biblioteca Netpbm y es la predeterminada. Si desea crear una nueva fuente, puede encontrar el formato de un archivo ppmdfont en el archivo de encabezado de la interfaz de Netpbm ppmdfont.h, pero tendrá que crear sus propias herramientas para construirlo. El programa ppmdmkfont genera standard.ppmdfont, por lo que puede usarlo como ejemplo.

line
Esto dibuja una línea de un píxel de ancho en el color actual. Los 4 argumentos son: columna de inicio, fila de inicio, columna de fin, fila de fin.

Este comando no afecta la posición actual.

line_here
Esto es como line, excepto que funciona de una manera más relativa.

La línea comienza en el punto actual. Los dos argumentos son el desplazamiento hacia la derecha y hacia abajo desde allí hasta el punto terminal. El comando mueve la posición actual al punto terminal después de dibujar.

spline3
Esto dibuja una spline en el color actual entre 2 puntos, usando un tercero como punto de control. Aproxima un segmento de spline cúbico.

La forma de la curva es tal que pasa por los puntos finales especificados, y las líneas tangentes a la curva en esos puntos finales se cruzan en el punto de control. Controlar las tangentes le permite conectar esta curva con otras curvas generadas de la misma manera sin tener esquinas en los puntos de conexión.

Los 6 argumentos son la columna del punto de inicio, la fila del punto de inicio, la columna del punto de control, la fila del punto de control, la columna del punto final y la fila del punto final.

Este comando no afecta la posición actual.

circle
Este comando dibuja un círculo en el color actual. Los tres argumentos son el número de columna y el número de fila del centro del círculo y el radio del círculo en píxeles.
filledrectangle
Este comando dibuja un rectángulo relleno con el color actual.

Los 4 argumentos son los números de columna y fila de la esquina superior izquierda del rectángulo, el ancho del rectángulo y la altura del rectángulo.

text
Este comando dibuja texto en el color actual en la fuente integrada. Los 5 argumentos son:
  • número de columna del punto de inicio de la línea base
  • número de fila del punto de inicio de la línea base
  • altura de los caracteres, en píxeles
  • ángulo de la línea base en grados elevados desde la horizontal
  • texto

NAME

ppmdraw - draw graphical primitives on a PPM image

SYNOPSIS

ppmdraw 
    [-flag ...] [ppmfile]

DESCRIPTION

ppmdraw accepts a PPM image as input and draws various graphical primitives on it, based on a script file. The script file is read from standard input if no input file is specified.

The script is a sequence of commands, each on a separate line. Each command consists of a command name and zero or more arguments.

The commands can be grouped into categories:

line
Draws a line from (x1, y1) to (x2, y2) with the specified color.
rect
Draws a rectangle with the specified color.
circle
Draws a circle with the specified color.
text
Draws text with the specified color.
color
Sets the current drawing color.
point
Sets the current drawing position.

OPTIONS

ppmdraw does not support any command line options.

SCRIPT

The script file contains a sequence of commands. Each command is on a separate line. Commands are case-sensitive.

The following commands are supported:

  • color r g b:

    Sets the current drawing color to the given RGB values. Values must be between 0 and the maximum color value of the input image.

  • point x y:

    Sets the current drawing position to (x, y). Coordinates are 0-based.

  • line x1 y1 x2 y2:

    Draws a line from (x1, y1) to (x2, y2) using the current drawing color.

  • rect x y width height:

    Draws a rectangle with its top-left corner at (x, y), and the specified width and height, using the current drawing color.

  • circle x y radius:

    Draws a circle centered at (x, y) with the specified radius, using the current drawing color.

  • text string:

    Draws the given string at the current drawing position, using the current drawing color. The current drawing position is updated to the end of the string.

    If the string contains white space, you'll have to use double quotes to cause it to be a single token.

text_here

This is like text, except that the baseline starts at the current position and the command updates the current position to the other end of the baseline after it draws.

Bear in mind that a script starts with the current position in the top line, so if you leave it there, only the bottom line of your text will be within the image!

HISTORY

ppmdraw was new in Netpbm 10.29 (August 2005).
