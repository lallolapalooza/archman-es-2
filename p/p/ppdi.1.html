NOMBRE

ppdi - importar archivos ppd (obsoleto)

SINOPSIS

ppdi [ -I directorio-de-inclusión ] [ -o archivo-fuente ] archivo-ppd [ ... archivo-ppd ]

DESCRIPCIÓN

ppdi importa uno o más archivos PPD a un archivo fuente del compilador PPD. Múltiples idiomas del mismo archivo PPD se fusionan en una única definición de impresora para facilitar cambios precisos en todas las localizaciones. Este programa está obsoleto y será eliminado en una futura versión de CUPS.

OPCIONES

ppdi soporta las siguientes opciones:

-I directorio-de-inclusión
Especifica un directorio de inclusión alternativo. Se pueden proporcionar múltiples opciones -I para añadir directorios adicionales.
-o archivo-fuente
Especifica el archivo fuente PPD a actualizar. Si el archivo fuente no existe, se crea un nuevo archivo fuente. De lo contrario, el archivo existente se fusiona con los nuevos archivos PPD de la línea de comandos. Si no se especifica ningún archivo fuente, se utiliza el nombre de archivo ppdi.drv.

NOTAS

Los archivos PPD están obsoletos y ya no serán compatibles en una futura versión de CUPS. Las impresoras que no soportan IPP pueden ser soportadas utilizando aplicaciones como ippeveprinter(1).
