PPL_PIPS(1) Comandos de usuario PPL_PIPS(1)

NOMBRE

ppl_pips - un solucionador de problemas de programación entera paramétrica basado en PPL

SINOPSIS

ppl_pips [OPCIÓN]... [ARCHIVO]

DESCRIPCIÓN

Lee la definición de un problema de programación entera paramétrica y muestra el mínimo lexicográfico en términos de los valores de los parámetros.

OPCIONES

-RMB, --max-memory=MB
limita el uso de memoria a MB megabytes
-h, --help
imprime este texto de ayuda en stdout
-oPATH, --output=RUTA
añade la salida al final de PATH
-P, --polylib
lee el problema en formato PolyLib (predeterminado)
-p, --piplib
lee el problema en formato PipLib
-t, --timings
imprime tiempos en stderr
-v, --verbose
produce mucha salida
-i, --iterations=N
ejecuta la resolución N veces (predeterminado=1)
-V, --version
imprime información de la versión en stdout
-cPATH, --check=RUTA
comprueba si el resultado es igual a lo que hay en PATH

Opciones de generación de cortes:

-f, --cut-first
usa la primera fila no entera (predeterminado)
-d, --cut-deepest
intenta generar el corte más profundo
-a, --cut-all
genera siempre todos los cortes posibles

Opciones de estrategia de fila pivote:

-F, --row-first
usa la primera fila con parámetro negativo (predeterminado)
-M, --row-max
elige la fila que genera la columna pivote lexico-maximal

DISPONIBILIDAD

La última versión de la Parma Polyhedra Library y toda la documentación está disponible en http://bugseng.com/products/ppl/ .

NOTAS

Las opciones -CSECS (--max-cpu=SECS) y -t (--timings) no están disponibles en algunas plataformas.

El formato PolyLib es el siguiente:

-
La primera fila describe la matriz de contexto (es decir, las restricciones sobre los parámetros). El primer valor es el número de filas (que puede ser cero) y el segundo valor es el número de columnas. El número de parámetros es el número de columnas menos 2.
-
A partir de la segunda fila, se encuentran las filas de la matriz de contexto, si las hay. Cada fila, que representa una restricción del tipo c1*p1 + ... + cn*pn + c0 =/>= 0 , contiene: el valor 0 si la restricción es una igualdad, 1 si es una desigualdad; los coeficientes de los parámetros c1, ..., cn ; el término constante c0 . Por ejemplo, la restricción de desigualdad sobre dos parámetros p1 + 2*p2 - 1 >= 0 se codifica con la fila 1 1 2 -1 .
-
La siguiente fila contiene el número de parámetro para el llamado *parámetro grande*. Si no se utiliza ningún parámetro grande, el valor es -1.
-
Las siguientes filas codifican la matriz de desigualdad del problema. Al igual que con la matriz de contexto, los dos primeros valores son las dimensiones de la matriz. El número de variables es el número de columnas de la matriz menos el número de parámetros menos 2. Cada fila, que representa una restricción del tipo d1*v1 + ... + dm*vm + c1*p1 + ... + cn*pn + c0 =/>= 0 , contiene: el valor 0 si la restricción es una igualdad, 1 si es una desigualdad; los coeficientes de las variables d1, ..., dm ; los coeficientes de los parámetros c1, ..., cn ; el término constante c0 .

El formato PipLib se describe en la Sección 2.2 de PIP/PipLib: A Solver for Parametric Integer Programming Problems (ver más abajo).
