pppoe-discovery(8)

Paquete: ppp

Licencias: GPL, BSD

PPPOE-DISCOVERY(8) Manual del Administrador del Sistema PPPOE-DISCOVERY(8)

NOMBRE

pppoe-discovery - realiza el descubrimiento PPPoE

SINOPSIS

pppoe-discovery [ opciones ]
pppoe-discovery { -V | -h }

DESCRIPCIÓN

pppoe-discovery realiza el mismo proceso de descubrimiento que pppoe, pero no inicia una sesión. Envía un paquete PADI y luego imprime los nombres de los concentradores de acceso en cada paquete PADO que recibe.

OPCIONES

-I interfaz
La opción -I especifica la interfaz Ethernet a utilizar. En Linux, suele ser eth0 o eth1. La interfaz debe estar “arriba” antes de iniciar pppoe-discovery, pero no debe tener configurada una dirección IP. Esta opción es obligatoria.
-D nombre_archivo
La opción -D hace que cada paquete se vuelque en el nombre_archivo especificado. Esto es solo para depuración.
-U
Hace que pppoe-discovery use la etiqueta Host-Uniq en sus paquetes de descubrimiento. Esto le permite ejecutar múltiples instancias de pppoe-discovery y/o pppoe sin que sus paquetes de descubrimiento interfieran entre sí. Debe proporcionar esta opción a *todas* las instancias que pretenda ejecutar simultáneamente.
-S nombre_servicio
Especifica el nombre del servicio deseado. pppoe-discovery solo aceptará concentradores de acceso que puedan proporcionar el servicio especificado. En la mayoría de los casos, no debe especificar esta opción. Úsela solo si sabe que hay múltiples concentradores de acceso o si sabe que necesita un nombre de servicio específico.
-C nombre_ac
Especifica el nombre del concentrador de acceso deseado. pppoe-discovery solo aceptará el concentrador de acceso especificado. En la mayoría de los casos, no debe especificar esta opción. Úsela solo si sabe que hay múltiples concentradores de acceso. Si se especifican ambas opciones, -S y -C, deben coincidir *ambas*.
-A
Esta opción se acepta por compatibilidad con pppoe, pero no tiene efecto.
-V | -h
Cualquiera de estas opciones hace que pppoe-discovery imprima su número de versión e información de uso, y luego salga.

AUTORES
