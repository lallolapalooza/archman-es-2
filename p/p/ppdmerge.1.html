NOMBRE

ppdmerge - fusionar archivos ppd (obsoleto)

SINOPSIS

ppdmerge [ -o archivo-ppd-salida ] archivo-ppd archivo-ppd [ ... archivo-ppd ]

DESCRIPCIÓN

ppdmerge fusiona dos o más archivos PPD en un único archivo PPD multilingüe. Este programa está obsoleto y se eliminará en una futura versión de CUPS.

OPCIONES

ppdmerge soporta las siguientes opciones:

-o archivo-ppd-salida
Especifica el archivo PPD a crear. Si no se especifica, el archivo PPD fusionado se escribe en la salida estándar. Si el archivo de salida ya existe, se sobrescribe silenciosamente.

NOTAS

Los archivos PPD están obsoletos y dejarán de ser compatibles en una futura versión de características de CUPS. Las impresoras que no soportan IPP pueden ser soportadas utilizando aplicaciones como ippeveprinter(1).

ppdmerge no comprueba si los archivos PPD fusionados son para el mismo dispositivo. La fusión de PPDs de diferentes dispositivos producirá resultados impredecibles.
