NOMBRE

ppmmake - crea una imagen PPM de un color y dimensiones especificados

SINOPSIS

ppmmake [-maxval=valormáximo] color ancho alto

Todas las opciones pueden abreviarse a su prefijo único más corto. Puede usar dos guiones en lugar de uno para designar una opción. Puede usar espacio en blanco o un signo igual entre el nombre de una opción y su valor.

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

ppmmake produce una imagen PPM del color, ancho, alto y valormáximo especificados.

Especifique el color (color) como se describe para la rutina de la biblioteca ppm_parsecolor().

EJEMPLOS

    ppmmake red 50 50
    ppmmake rgb:ff/80/80 50 100 -maxval=5

OPCIONES

-maxval=valormáximo

El valormáximo para la imagen generada. Por defecto es 255.


Esta opción no existía antes de junio de 2002. Antes, el valormáximo
era siempre 255.
