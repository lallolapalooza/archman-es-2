NOMBRE

pg_controldata - muestra información de control de un clúster de base de datos PostgreSQL

SINOPSIS

pg_controldata [opción] [[-D | --pgdata]datadir]

DESCRIPCIÓN

pg_controldata imprime información inicializada durante initdb, como la versión del catálogo. También muestra información sobre el registro de escritura anticipada (write-ahead logging) y el procesamiento de puntos de control (checkpoint). Esta información es específica del clúster completo, y no de una base de datos individual.

Esta utilidad solo puede ser ejecutada por el usuario que inicializó el clúster, ya que requiere acceso de lectura al directorio de datos. Puede especificar el directorio de datos en la línea de comandos o usar la variable de entorno PGDATA. Esta utilidad soporta las opciones -V y --version, que imprimen la versión de pg_controldata y salen. También soporta las opciones -? y --help, que muestran los argumentos soportados.

ENTORNO

PGDATA

Ubicación predeterminada del directorio de datos

PG_COLOR

Especifica si se debe usar color en los mensajes de diagnóstico. Los valores posibles son siempre, auto y nunca.
