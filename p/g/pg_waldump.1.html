NAME

pg_waldump - muestra una representación legible por humanos del log de escritura anticipada (WAL) de un clúster de bases de datos PostgreSQL

SYNOPSIS

pg_waldump [opción...] [segmento_inicial [segmento_final]]

DESCRIPTION

pg_waldump muestra el log de escritura anticipada (WAL) y es principalmente útil para fines de depuración o educativos.

Esta utilidad solo puede ser ejecutada por el usuario que instaló el servidor, ya que requiere acceso de solo lectura al directorio de datos.

OPTIONS

Las siguientes opciones de línea de comandos controlan la ubicación y el formato de la salida:

segmento_inicial

Comienza a leer en el archivo de segmento WAL especificado. Esto determina implícitamente la ruta en la que se buscarán los archivos y la línea de tiempo a utilizar.

segmento_final

Detente después de leer el archivo de segmento WAL especificado.

-b
--bkp-details

Muestra información detallada sobre los bloques de copia de seguridad.

-B bloque
--block=bloque

Solo muestra registros que modifican el bloque dado. La relación también debe proporcionarse con --relation o -R.

-e final
--end=final

Deja de leer en la ubicación WAL especificada, en lugar de leer hasta el final del flujo de logs.

-f
--follow

Después de alcanzar el final del WAL válido, continúa consultando una vez por segundo para detectar la aparición de nuevo WAL.

-F fork
--fork=fork

Solo muestra registros que modifican bloques en el fork dado. Los valores válidos son main para el fork principal, fsm para el mapa de espacio libre, vm para el mapa de visibilidad e init para el fork init.

-n límite
--limit=límite

Muestra el número especificado de registros y luego se detiene.

-p ruta
--path=ruta

Especifica un directorio para buscar archivos de segmento WAL o un directorio con un subdirectorio pg_wal que contenga dichos archivos. Por defecto, se busca en el directorio actual, el subdirectorio pg_wal del directorio actual y el subdirectorio pg_wal de PGDATA.

-q
--quiet

No imprime ninguna salida, excepto por errores. Esta opción puede ser útil cuando deseas saber si un rango de registros WAL se puede analizar correctamente pero no te importan los contenidos de los registros.

-r rmgr
--rmgr=rmgr

Solo muestra registros generados por el gestor de recursos especificado. Puedes especificar la opción varias veces para seleccionar múltiples gestores de recursos. Si se pasa "list" como nombre, imprime una lista de nombres de gestores de recursos válidos y sale.

Las extensiones pueden definir gestores de recursos personalizados, pero pg_waldump no carga el módulo de extensión y, por lo tanto, no reconoce los gestores de recursos personalizados por nombre. En su lugar, puedes especificar los gestores de recursos personalizados como custom### donde ### es el ID de tres dígitos del gestor de recursos. Los nombres de este formato siempre se considerarán válidos.

-R tblspc/db/rel
--relation=tblspc/db/rel

Solo muestra registros que modifican bloques en la relación dada. La relación se especifica con el OID del tablespace, el OID de la base de datos y el relfilenode separados por barras, por ejemplo 1234/12345/12345. Este es el mismo formato utilizado para las relaciones en la salida del programa.

-s inicio
--start=inicio

Ubicación WAL desde la que comenzar a leer. Por defecto, se comienza a leer el primer registro WAL válido encontrado en el archivo más antiguo encontrado.

-t línea_de_tiempo
--timeline=línea_de_tiempo

Línea de tiempo desde la que leer los registros WAL. Por defecto, se utiliza el valor de segmento_inicial, si se especifica; de lo contrario, el valor predeterminado es 1. El valor se puede especificar en decimal o hexadecimal, por ejemplo, 17 o 0x11.

-V
--version

Imprime la versión de pg_waldump y sale.

-w
--fullpage

Solo muestra registros que incluyen imágenes completas de página.

-x xid
--xid=xid

Solo muestra registros marcados con el ID de transacción dado.

-z
--stats[=record]

Muestra estadísticas resumidas (número y tamaño de registros e imágenes completas de página) en lugar de registros individuales. Opcionalmente, genera estadísticas por registro en lugar de por rmgr.

Si pg_waldump se interrumpe con la señal SIGINT (Control+C), se muestra el resumen de las estadísticas calculadas hasta el punto de interrupción. Esta operación no es compatible con Windows.

--save-fullpage=ruta_guardado

Guarda las imágenes completas de página encontradas en los registros WAL en el directorio ruta_guardado. Las imágenes guardadas están sujetas a los mismos criterios de filtrado y limitación que los registros mostrados.

Las imágenes completas de página se guardan con el siguiente formato de nombre de archivo: TIMELINE-LSN.RELTABLESPACE.DATOID.RELNODE.BLKNO_FORK Los nombres de archivo se componen de las siguientes partes:

Componente Descripción
TIMELINE La línea de tiempo del archivo de segmento WAL donde se encuentra el registro, formateado como un número hexadecimal de 8 caracteres %08X
LSN El LSN del registro con esta imagen, formateado como dos números hexadecimales de 8 caracteres %08X-%08X
RELTABLESPACE OID del tablespace del bloque
DATOID OID de la base de datos del bloque
RELNODE filenode del bloque
BLKNO número de bloque del bloque
FORK El nombre del fork del que proviene la imagen completa de página, como main, fsm, vm o init.

-?
--help

Muestra la ayuda sobre los argumentos de la línea de comandos de pg_waldump y sale.

ENVIRONMENT

PGDATA

Directorio de datos; ver también la opción -p.

PG_COLOR

Especifica si se debe usar color en los mensajes de diagnóstico. Los valores posibles son always, auto y never.

NOTES

Puede dar resultados incorrectos cuando el servidor se está ejecutando.

Solo se muestra la línea de tiempo especificada (o la predeterminada, si no se especifica ninguna). Los registros en otras líneas de tiempo se ignoran.

pg_waldump no puede leer archivos WAL con sufijo .partial. Si esos archivos necesitan ser leídos, el sufijo .partial debe eliminarse del nombre del archivo.

pg_waldump(1)

pg_waldump — exportar el contenido de los registros WAL de PostgreSQL.

NOMBRE

pg_waldump - volcar el contenido de los registros WAL de PostgreSQL

SINOPSIS

pg_waldump [opciones] [archivo_WAL_inicial] [archivo_WAL_final]

DESCRIPCIÓN

pg_waldump es una utilidad para exportar el contenido de los archivos WAL (Write-Ahead Logging) de PostgreSQL en un formato legible por humanos. Esto es útil para depurar problemas, comprender el flujo de datos o realizar análisis forenses.

El programa lee uno o más archivos WAL y muestra la información contenida en ellos, incluyendo los cambios realizados en las bases de datos. Se pueden especificar rangos de archivos WAL para volcar, ya sea nombrando archivos individuales o especificando un archivo inicial y final.

OPCIONES

A continuación se detallan algunas opciones comunes de pg_waldump:

  • -V, --version: Muestra la versión de pg_waldump e inmediatamente sale.
  • -?, --help: Muestra ayuda sobre cómo usar pg_waldump y sale.
  • -p, --path=directorio: Especifica el directorio donde se encuentran los archivos WAL. Si no se especifica, se usa la configuración predeterminada de PostgreSQL.
  • -f, --format=formato: Especifica el formato de salida. Los formatos comunes incluyen text (predeterminado) y tlog.
  • -o, --output=archivo: Escribe la salida en el archivo especificado en lugar de la salida estándar.
  • -s, --start-lsn=LSN: Especifica el LSN (Log Sequence Number) inicial para el volcado.
  • -e, --end-lsn=LSN: Especifica el LSN final para el volcado.
  • -t, --timeline=línea_de_tiempo: Especifica la línea de tiempo de los archivos WAL a procesar.
  • -d, --debug=nivel: Establece el nivel de depuración.

ENTORNO

pg_waldump utiliza las variables de entorno estándar de PostgreSQL para conectarse a una instancia, como PGHOST, PGPORT, PGDATABASE, PGUSER y PGPASSWORD.

NOTAS

El acceso a los archivos WAL requiere permisos adecuados. Generalmente, solo el usuario del sistema operativo que ejecuta PostgreSQL o el usuario con privilegios de superusuario puede leer estos archivos. Es recomendable realizar volcados WAL en un entorno controlado para evitar la corrupción de datos o la exposición de información sensible.
