NOMBRE

pg_isready - comprueba el estado de conexión de un servidor PostgreSQL

SINOPSIS

pg_isready [opción-de-conexión...] [opción...]

DESCRIPCIÓN

pg_isready es una utilidad para comprobar el estado de conexión de un servidor de base de datos PostgreSQL. El estado de salida especifica el resultado de la comprobación de la conexión.

OPCIONES

-d nombre-bd
--dbname=nombre-bd

Especifica el nombre de la base de datos a la que conectarse. El nombre-bd puede ser una cadena de conexión. Si es así, los parámetros de la cadena de conexión anularán cualquier opción de línea de comandos en conflicto.

-h nombre-host
--host=nombre-host

Especifica el nombre del host de la máquina en la que se ejecuta el servidor. Si el valor comienza con una barra inclinada, se utilizará como directorio para el socket de dominio Unix.

-p puerto
--port=puerto

Especifica el puerto TCP o la extensión del archivo de socket de dominio Unix local en el que el servidor está escuchando conexiones. Por defecto, es el valor de la variable de entorno PGPORT o, si no está configurada, el puerto especificado en la compilación, normalmente 5432.

-q
--quiet

No muestre el mensaje de estado. Esto es útil al escribir scripts.

-t segundos
--timeout=segundos

El número máximo de segundos a esperar al intentar la conexión antes de devolver que el servidor no está respondiendo. Establecerlo en 0 lo deshabilita. El valor por defecto es 3 segundos.

-U nombre-usuario
--username=nombre-usuario

Conéctese a la base de datos como el usuario nombre-usuario en lugar del predeterminado.

-V
--version

Imprime la versión de pg_isready y sale.

-?
--help

Muestra ayuda sobre los argumentos de la línea de comandos de pg_isready y sale.

ESTADO DE SALIDA

pg_isready devuelve 0 a la shell si el servidor está aceptando conexiones normalmente, 1 si el servidor está rechazando conexiones (por ejemplo, durante el inicio), 2 si no hubo respuesta al intento de conexión, y 3 si no se realizó ningún intento (por ejemplo, debido a parámetros inválidos).

ENTORNO

pg_isready, al igual que la mayoría de las otras utilidades de PostgreSQL, también utiliza las variables de entorno admitidas por libpq (véase la Sección 32.15).

La variable de entorno PG_COLOR especifica si se debe usar color en los mensajes de diagnóstico. Los valores posibles son always, auto y never.

NOTAS

No es necesario proporcionar valores correctos para el nombre de usuario, la contraseña o el nombre de la base de datos para obtener el estado del servidor; sin embargo, si se proporcionan valores incorrectos, el servidor registrará un intento de conexión fallido.

EJEMPLOS

Uso estándar:

$ pg_isready
/tmp:5432 - aceptando conexiones
$ echo $?
0

Ejecución con parámetros de conexión a un clúster de PostgreSQL en inicio:

$ pg_isready -h localhost -p 5433
localhost:5433 - rechazando conexiones
$ echo $?
1

Ejecución con parámetros de conexión a un clúster de PostgreSQL que no responde:

$ pg_isready -h someremotehost
someremotehost:5432 - sin respuesta
$ echo $?
2
