NOMBRE

pgtopo_import - importador de topología postgis

SINTAXIS

pgtopo_import [opciones] topología

DESCRIPCIÓN

El cargador de datos pgtopo_import lee un archivo de exportación escrito por pgtopo_export y genera un script SQL que reconstruye la topología contenida en él.

USO

La <topología> es el nombre que se le dará a la topología recreada, que puede ser diferente del nombre de la topología de la que se hizo la exportación.

Por defecto, el script SQL se escribe en la salida estándar.

OPCIONES

Estas son las opciones soportadas

(Tenga en cuenta que --skip-layers y --only-layers son mutuamente excluyentes.)

--skip-layers
No incluir capas en el script SQL de salida. Solo el esquema de topología.
--only-layers
No incluir el esquema de topología en el script SQL de salida. Solo las capas.
-f <nombre_archivo>
Leer el archivo de exportación desde el nombre de archivo especificado, en lugar de desde la entrada estándar. -h Mostrar información de uso.

EJEMPLOS

Una sesión de ejemplo utilizando el cargador para crear un archivo SQL y subirlo podría verse así:

# pgtopo_import ciudad_datos < ciudad_datos.pgtopo_export | psql nuevabd
