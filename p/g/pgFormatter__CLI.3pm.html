pgFormatter::CLI(3) Documentación de Contribución de Usuarios de Perl pgFormatter::CLI(3)

NOMBRE

pgFormatter::CLI - Implementación del programa de línea de comandos para formatear consultas SQL.

VERSIÓN

Versión 5.8

SINOPSIS

Este módulo es llamado por el programa pg_format, cuando detecta que no se está ejecutando en un entorno CGI. En tal caso, todo el control del flujo se pasa a este módulo llamando a:

my $program = pgFormatter::CLI->new();
$program->run()

FUNCIONES

new

Constructor de objetos, nada especial aquí.

run

Envuelve todo el trabajo relacionado con el programa CLI de pg_format. Esto incluye llamar a métodos para leer los parámetros de la línea de comandos, validarlos, leer la consulta, embellecerla y sacarla.

beautify

Formatea realmente la consulta cargada utilizando la biblioteca pgFormatter::Beautify. Si es necesario, realiza la anonimización.

save_output

Guarda la consulta embellecida en el manejador de salida que sea.

logmsg

Muestra el mensaje siguiendo el nivel de registro.

show_help_and_die

Como sugiere el nombre: muestra la página de ayuda, con un mensaje de error opcional, y termina el programa.

load_sql

Carga SQL desde un archivo de entrada o desde la entrada estándar.

get_command_line_args

Analiza las opciones de la línea de comandos en $self->{'cfg'}.

validate_args

Valida que las opciones analizadas de la línea de comandos tengan valores sensatos, abre los archivos de entrada y salida.
