NOMBRE

pgsql2shp - volcado de PostGIS a shapefile

SINTAXIS

pgsql2shp [opciones] base_de_datos [esquema.]tabla
pgsql2shp [opciones] base_de_datos consulta

DESCRIPCIÓN

El volcador de tablas pgsql2shp se conecta directamente a la base de datos y convierte una tabla (posiblemente creada por una consulta del usuario) en un archivo de forma (shape file). Es compatible con todas las versiones de PostGIS.

Versión: 1.1.5 (06/10/2006)

USO

La <base_de_datos> es el nombre de la base de datos a la que conectarse.

La <tabla> es la tabla (opcionalmente calificada por esquema) de la que leer datos espaciales. Alternativamente, puede especificar una CONSULTA cuyo resultado se escribirá en el archivo de forma.

OPCIONES

Las opciones de línea de comandos son:

-f <nombre_archivo>
Escribe la salida a un nombre de archivo en particular.
-h <host>
El host de la base de datos al que conectarse.
-p <puerto>
El puerto al que conectarse en el host de la base de datos.
-P <contraseña>
La contraseña a usar al conectarse a la base de datos.
-u <usuario>
El nombre de usuario a usar al conectarse a la base de datos.
-g <columna_geometria>
En el caso de tablas con múltiples columnas de geometría, la columna de geometría a usar al escribir el archivo de forma.
-b
Utiliza un cursor binario. Cuando se usa en versiones de PostGIS anteriores a la 1.0.0, esto reducirá la probabilidad de deriva de coordenadas debido a la conversión desde y hacia el formato WKT. Las derivas de coordenadas no ocurrirán con las versiones 1.0.0 y posteriores de PostGIS. Será un poco más rápido, pero podría fallar si alguna columna que NO sea de geometría carece de una conversión a texto.
-r
Modo RAW. No elimine el campo gid ni escape los nombres de columna.
-d
Para compatibilidad hacia atrás: escribe un archivo de forma tridimensional al volcar desde bases de datos postgis antiguas (anteriores a la 1.0.0) (el valor por defecto es escribir un archivo de forma bidimensional en ese caso). A partir de postgis-1.0.0+, las dimensiones se codifican completamente.
-k
Conservar mayúsculas/minúsculas en los identificadores (no convertir a mayúsculas los nombres de campo).
-m <nombre_archivo>
Especifica un archivo que contiene un conjunto de mapeos de nombres de columna (largos) a nombres de columna de DBF de 10 caracteres. El contenido del archivo son una o más líneas de dos nombres separados por espacios en blanco y sin espacios al final o al principio:

NOMBRECOLUMNA CAMPO_DBF1\n
UNNOMBRELARGODELACULUMNA CAMPO_DBF2\n

etc.

-?
Mostrar información de versión y uso.

INSTALACIÓN

Para compilar el programa desde el código fuente, simplemente ejecute "make" en el directorio fuente. Luego, copie el binario en su ruta de búsqueda de shell (o donde prefiera). Este texto también está disponible como página de manual en el directorio ../doc/man/, listo para ser copiado en la ruta de búsqueda de manuales en sistemas unixoides.

EJEMPLOS

Una sesión de ejemplo usando el volcado para crear un archivo de forma a partir de una base de datos podría verse así:

# pgsql2shp -f mi_archivo -p 5555 mi_db tabla_carreteras

AUTORES

Originalmente escrito por Jeff Lounsbury <jeffloun@refractions.net>. Mejorado y mantenido por Sandro Santilli <strk@kbt.io>. Incluye pequeñas contribuciones y mejoras de otros.

Esta aplicación utiliza funcionalidades de shapelib 1.2.9 de Frank Warmerdam <warmerda@gdal.velocet.ca> para escribir en archivos ESRI Shape files.
