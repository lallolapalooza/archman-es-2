NOMBRE

pg_config - obtener información sobre la versión instalada de PostgreSQL

SINOPSIS

pg_config [opción...]

DESCRIPCIÓN

La utilidad pg_config imprime los parámetros de configuración de la versión actualmente instalada de PostgreSQL. Está pensada, por ejemplo, para ser utilizada por paquetes de software que quieran interactuar con PostgreSQL para facilitar la búsqueda de los archivos de cabecera y bibliotecas necesarias.

OPCIONES

Para usar pg_config, proporcione una o más de las siguientes opciones:

--bindir

Imprime la ubicación de los ejecutables de usuario. Úselo, por ejemplo, para encontrar el programa psql. Normalmente, esta es también la ubicación donde reside el programa pg_config.

--docdir

Imprime la ubicación de los archivos de documentación.

--htmldir

Imprime la ubicación de los archivos de documentación HTML.

--includedir

Imprime la ubicación de los archivos de cabecera C de las interfaces de cliente.

--pkgincludedir

Imprime la ubicación de otros archivos de cabecera C.

--includedir-server

Imprime la ubicación de los archivos de cabecera C para programación del servidor.

--libdir

Imprime la ubicación de las bibliotecas de código objeto.

--pkglibdir

Imprime la ubicación de los módulos cargables dinámicamente, o dónde los buscaría el servidor. (Otros archivos de datos dependientes de la arquitectura también podrían instalarse en este directorio).

--localedir

Imprime la ubicación de los archivos de soporte de localización. (Esta será una cadena vacía si el soporte de localización no se configuró cuando se compiló PostgreSQL).

--mandir

Imprime la ubicación de las páginas del manual.

--sharedir

Imprime la ubicación de los archivos de soporte independientes de la arquitectura.

--sysconfdir

Imprime la ubicación de los archivos de configuración de todo el sistema.

--pgxs

Imprime la ubicación de los Makefiles de extensión.

--configure

Imprime las opciones que se pasaron al script configure cuando PostgreSQL se configuró para su compilación. Esto se puede usar para reproducir la configuración idéntica, o para averiguar con qué opciones se compiló un paquete binario. (Sin embargo, tenga en cuenta que los paquetes binarios a menudo contienen parches personalizados específicos del proveedor). Consulte también los ejemplos a continuación.

--cc

Imprime el valor de la variable CC que se usó para compilar PostgreSQL. Esto muestra el compilador C utilizado.

--cppflags

Imprime el valor de la variable CPPFLAGS que se usó para compilar PostgreSQL. Esto muestra las opciones del compilador C necesarias en tiempo de preprocesamiento (típicamente, conmutadores -I).

--cflags

Imprime el valor de la variable CFLAGS que se utilizó para compilar PostgreSQL. Esto muestra las opciones del compilador C.

--cflags_sl

Imprime el valor de la variable CFLAGS_SL que se utilizó para compilar PostgreSQL. Esto muestra las opciones adicionales del compilador C utilizadas para compilar bibliotecas compartidas.

--ldflags

Imprime el valor de la variable LDFLAGS que se utilizó para compilar PostgreSQL. Esto muestra las opciones del enlazador.

--ldflags_ex

Imprime el valor de la variable LDFLAGS_EX que se utilizó para compilar PostgreSQL. Esto muestra las opciones del enlazador utilizadas solo para compilar ejecutables.

--ldflags_sl

Imprime el valor de la variable LDFLAGS_SL que se utilizó para compilar PostgreSQL. Esto muestra las opciones del enlazador utilizadas solo para compilar bibliotecas compartidas.

--libs

Imprime el valor de la variable LIBS que se usó para compilar PostgreSQL. Normalmente contiene conmutadores -l para bibliotecas externas enlazadas a PostgreSQL.

--version

Imprime la versión de PostgreSQL.

-?
--help

Muestra ayuda sobre los argumentos de línea de comandos de pg_config y sale.
Si se proporcionan varias opciones, la información se imprime en ese orden, un elemento por línea. Si no se proporcionan opciones, se imprime toda la información disponible, con etiquetas.

NOTAS

Las opciones --docdir, --pkgincludedir, --localedir, --mandir, --sharedir, --sysconfdir, --cc, --cppflags, --cflags, --cflags_sl, --ldflags, --ldflags_sl y --libs se agregaron en PostgreSQL 8.1. La opción --htmldir se agregó en PostgreSQL 8.4. La opción --ldflags_ex se agregó en PostgreSQL 9.0.

EJEMPLO

Para reproducir la configuración de compilación de la instalación actual de PostgreSQL, ejecute el siguiente comando:

eval ./configure `pg_config --configure`

La salida de pg_config --configure contiene comillas de shell para que los argumentos con espacios se representen correctamente. Por lo tanto, se requiere eval para obtener resultados adecuados.
