pgFormatter::CGI(3) Documentación de Perl aportada por el usuario pgFormatter::CGI(3)

NOMBRE

pgFormatter::CGI - Implementación de un script CGI-BIN para formatear consultas SQL.

VERSIÓN

Versión 5.8

SINOPSIS

Este módulo es llamado por el programa pg_format, cuando detecta que se está ejecutando en un entorno CGI. En tal caso, todo el control del flujo se pasa a este módulo llamando a:

my $program = pgFormatter::CGI->new();
$program->run()

FUNCIONES

new

Constructor de objetos, llama al método set_config para establecer valores predeterminados para varios parámetros.

run

Ruta al manejador correcto según el tipo de datos que recibimos

run_webpage

Envuelve todo el trabajo relacionado con la generación de la página html.

Llama a un conjunto de funciones para obtener el objeto CGI, recibir parámetros de la solicitud, sanitizarlos, embellecer la consulta (si se proporciona) e imprimir el html.

run_api

Envuelve todo el trabajo relacionado con la generación de la respuesta JSON cuando se usa como API.

get_cgi

Crea el objeto CGI y establece el límite de tamaño de POST

Establece la configuración para la página y el embellecedor. URLs, nombres de archivos auxiliares, configuración para el módulo pgFormatter::Beautify.

Carga y devuelve el CSS predeterminado desde __DATA__.

Obtiene los valores de los parámetros, y posiblemente el archivo cargado, del objeto CGI a estructuras en $self.

Obtiene los parámetros para la versión API de este servicio

sanitize_params

Anula los valores de los parámetros si los valores proporcionados no estaban dentro de los rangos aceptables.

beautify_query

Ejecuta el embellecimiento en la consulta proporcionada y almacena la nueva versión en $self->{'content'}

print_json

Muestra el SQL embellecido como JSON

Muestra el cuerpo de la página.

print_footer

Muestra el pie de página.

_load_optional_file

Función auxiliar para intentar cargar un archivo. Si tiene éxito, devuelve el contenido del archivo, si no, devuelve una cadena vacía (en lugar de fallar).

print_error

Muestra un mensaje de error cuando no se encuentra ninguna respuesta aceptable.

print_headers

Muestra las cabeceras de la página, tanto a nivel HTTP como HTML.

DATOS

La sección __DATA__ (al final de este archivo) se utiliza para almacenar el estilo CSS predeterminado, de modo que no "contamine" el código Perl y no necesite ser indentado.
