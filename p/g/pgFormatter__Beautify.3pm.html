NOMBRE

pgFormatter::Beautify - Biblioteca para dar formato legible a consultas SQL

VERSIÓN

Versión 5.8

SINOPSIS

Este módulo se puede utilizar para reformatear consultas SQL dadas, opcionalmente anonimizando parámetros.

La salida puede ser texto plano, o puede ser HTML con estilos apropiados para que se pueda mostrar en una página web.

Ejemplo de uso:

my $beautifier = pgFormatter::Beautify->new();
$beautifier->query( 'select a,b,c from d where e = f' );
$beautifier->beautify();
my $nice_txt = $beautifier->content();
$beautifier->format('html');
$beautifier->beautify();
my $nice_html = $beautifier->content();
$beautifier->format('html');
$beautifier->anonymize();
$beautifier->beautify();
my $nice_anonymized_html = $beautifier->content();
$beautifier->format();
$beautifier->beautify();
$beautifier->wrap_lines()
my $wrapped_txt = $beautifier->content();

FUNCIONES

new

Constructor genérico: crea un objeto, establece valores predeterminados y lee la configuración de un hash dado con opciones.

Acepta opciones como un hash. Se reconocen las siguientes opciones:

  • break - Cadena que se usa para los saltos de línea. El valor predeterminado es "\n".
  • colorize - si se establece en falso, el estilo CSS no se aplicará a la salida html. Se usa internamente para mostrar errores en modo CGI sin estilo.
  • comma - establece la coma al principio o al final de una línea en una lista de parámetros
end - poner la coma al final de la lista (predeterminado)
start - poner la coma al principio de la lista
  • comma_break - agregar un salto de línea después de cada coma en las declaraciones INSERT
  • format - establece el formato de embellecimiento a aplicar al contenido (predeterminado: text)
text - salida de contenido como texto plano (predeterminado en modo línea de comandos)
html - salida text/html con estilo CSS aplicado al contenido (predeterminado en modo CGI)
  • functions - lista (arrayref) de cadenas que son nombres de funciones
  • keywords - lista (arrayref) de cadenas que son palabras clave
  • multiline - usar búsqueda multilínea para la expresión regular de marcadores, ver placeholder.
  • no_comments - si se establece en true, los comentarios se eliminarán de la consulta
  • no_grouping - si se establece en true, las declaraciones no se agruparán en una transacción, se agregará un carácter de nueva línea adicional entre las declaraciones como si estuvieran fuera de una transacción.
  • placeholder - usar la expresión regular especificada para encontrar código que no debe modificarse en la consulta.
  • query - consulta a embellecer
  • rules - hash de reglas - utiliza la semántica de reglas de SQL::Beautify
  • space - carácter(es) a usar como espacio para la indentación
  • spaces - cuántos espacios usar para la indentación
  • uc_functions - qué hacer con los nombres de funciones:
0 - no cambiar
1 - cambiar a minúsculas
2 - cambiar a mayúsculas
3 - cambiar a Mayúsculas iniciales
  • separator - cadena utilizada como separador de código dinámico, el predeterminado es una comilla simple
  • uc_keywords - qué hacer con las palabras clave - significado del valor igual que con uc_functions
  • uc_types - qué hacer con los tipos de datos - significado del valor igual que con uc_functions
  • wrap - envuelve las palabras clave dadas en marcas pre y post. Documentación específica en SQL::Beautify
  • format_type - probar un formato diferente
  • wrap_limit - envuelve consultas en una cierta longitud
  • wrap_after - número de columna después del cual las listas deben ser envueltas
  • wrap_comment - aplicar envoltorio a comentarios que comienzan con --
  • numbering - numeración de declaraciones como comentario antes de cada consulta
  • redshift - agregar palabras clave de Redshift (obsoleto, usar --extra-keyword)
  • no_extra_line - no agregar una línea vacía adicional al final de la salida
  • keep_newline - preservar la línea vacía en el código plpgsql
  • no_space_function - eliminar espacio antes de la llamada a la función y el paréntesis de apertura
  • redundant_parenthesis - no eliminar paréntesis redundantes en consultas DML

Para los valores predeterminados, consulta la función set_defaults.

query

Accesor a la cadena de consulta. Lee:

$object->query()

y escribe:

$object->query( $something )

content

Accesor al contenido de los resultados. Debe llamarse después de $object->beautify().

Esto puede ser texto plano o HTML siguiendo el formato solicitado por el cliente con el método $object->format().

highlight_code

Hace que el resultado sea HTML con estilos establecidos para el resaltado.

tokenize_sql

Divide el SQL de entrada en tokens

format

Establece el formato de salida: los valores posibles son 'text' y 'html'.

El valor predeterminado es la salida de texto. Devuelve 0 en caso de formato incorrecto y utiliza el predeterminado.

set_dicts

Establece varios diccionarios (listas de palabras clave, funciones, símbolos y similares).

Esto se movió a una función separada para que se pueda colocar al final del módulo y facilitar la lectura del resto del código.

_remove_dynamic_code

Función interna utilizada para ocultar el código dinámico en plpgsql al analizador. Los valores originales se restauran con la función _restore_dynamic_code().

_restore_dynamic_code

Función interna utilizada para restaurar el código dinámico de plpgsql en plpgsql que fue eliminado por el método _remove_dynamic_code().

_quote_operator

Función interna utilizada para entrecomillar operadores con múltiples caracteres para que se analicen como una sola palabra. Los valores originales se restauran con la función _restore_operator().

_restore_operator

Función interna utilizada para restaurar operadores que fueron eliminados por el método _quote_operator().

_quote_comment_stmt

Función interna utilizada para reemplazar constantes en una sentencia COMMENT para que se analicen como una sola palabra. Los valores originales se restauran con la función _restore_comment_stmt().

_restore_comment_stmt

Función interna utilizada para restaurar cadenas de comentarios que fueron eliminadas por el método _quote_comment_stmt().

_remove_comments

Función interna utilizada para eliminar comentarios en el código SQL para simplificar el trabajo de `wrap_lines`. Los comentarios deben restaurarse con el método _restore_comments().

_restore_comments

Función interna utilizada para restaurar comentarios en el código SQL que fueron eliminados por el método _remove_comments().

wrap_lines

Función interna utilizada para dividir líneas en una longitud determinada.
