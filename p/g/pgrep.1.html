PGREP(1) Manual de Comandos Generales PGREP(1)

NOMBRE

pgrep, pkill, pidwait - buscar, señalar o esperar por procesos basados en nombre y otros atributos

SINOPSIS

pgrep [opción ...] patrón

pkill [opción ...] patrón

pidwait [opción ...] patrón

DESCRIPCIÓN

pgrep busca entre los procesos en ejecución actualmente y lista los IDs de proceso que coinciden con los criterios de selección en la salida estándar. Todos los criterios deben coincidir. Por ejemplo,

$ pgrep -u root sshd

solo listará los procesos cuyo nombre incluya sshd Y sean propiedad de root. Por otro lado,

$ pgrep -u root,daemon

listará los procesos propiedad de root O daemon.

pkill enviará la señal especificada (por defecto SIGTERM) a cada proceso en lugar de listarlos en la salida estándar.

pidwait esperará por cada proceso en lugar de listarlos en la salida estándar.

OPCIONES

-señal
--signal señal
Define la señal a enviar a cada proceso coincidente. Se puede usar el valor numérico o el nombre simbólico de la señal. En modo pgrep o pidwait solo se puede usar la opción larga y no tiene efecto a menos que se use junto con --require-handler para filtrar por procesos que tengan un manejador de señales en el espacio de usuario para una señal particular.
-c, --count
Suprime la salida normal; en su lugar imprime una cuenta de los procesos coincidentes. Cuando el recuento no coincide con nada, por ejemplo, devuelve cero, el comando devolverá un valor distinto de cero. Tenga en cuenta que para pkill y pidwait, el recuento es el número de procesos coincidentes, no los procesos a los que se les envió una señal o se esperaron exitosamente.
-d, --delimiter delimitador
Establece la cadena utilizada para delimitar cada ID de proceso en la salida (por defecto, una nueva línea). (Solo pgrep.)
-e, --echo
Muestra el nombre y el PID del proceso que se está eliminando. (Solo pkill.)
-f, --full
El patrón normalmente solo se compara con el nombre del proceso. Cuando se establece -f, se utiliza la línea de comandos completa.
-g, --pgroup pgrp,...
Solo coincide con procesos en los IDs de grupo de procesos listados. El grupo de procesos 0 se traduce al propio grupo de procesos de pgrep, pkill o pidwait.
-G, --group gid,...
Solo coincide con procesos cuyo ID de grupo real está listado. Se puede usar el valor numérico o simbólico.
-i, --ignore-case
Compara procesos sin distinguir entre mayúsculas y minúsculas.
-l, --list-name
Lista el nombre del proceso además del ID del proceso. (Solo pgrep.)
-a, --list-full
Lista la línea de comandos completa además del ID del proceso. (Solo pgrep.)
-n, --newest
Selecciona solo los procesos coincidentes más nuevos (iniciados más recientemente).
-o, --oldest
Selecciona solo los procesos coincidentes más antiguos (iniciados menos recientemente).
-O, --older secs
Selecciona procesos más antiguos que secs.
-P, --parent ppid,...
Solo coincide con procesos cuyo ID de proceso padre está listado.
-s, --session sid,...
Solo coincide con procesos cuyo ID de sesión de proceso está listado. El ID de sesión 0 se traduce al propio ID de sesión de pgrep, pkill o pidwait.
-t, --terminal term,...
Solo coincide con procesos cuyo terminal de control está listado. El nombre del terminal debe especificarse sin el prefijo "/dev/".
-u, --euid euid,...
Solo coincide con procesos cuyo ID de usuario efectivo está listado. Se puede usar el valor numérico o simbólico.
-U, --uid uid,...
Solo coincide con procesos cuyo ID de usuario real está listado. Se puede usar el valor numérico o simbólico.
-v, --inverse
Niega la coincidencia. Esta opción se usa generalmente en el contexto de pgrep o pidwait. En el contexto de pkill, la opción corta está deshabilitada para evitar el uso accidental de la opción.
-w, --lightweight
Muestra todos los IDs de hilo en lugar de PIDs en el contexto de pgrep o pidwait. En el contexto de pkill esta opción está deshabilitada.
-x, --exact
Solo coincide con procesos cuyos nombres (o líneas de comandos si se especifica -f) coinciden exactamente con el patrón.
-F, --pidfile archivo
Lee los PIDs del archivo. Esta opción es más útil para pkill o pidwait que para pgrep. El nombre de archivo "-" se puede usar para leer desde STDIN.
-L, --logpidfile
Falla si el archivo PID (ver -F) no está bloqueado.
-r, --runstates D,R,S,Z,...
Coincide solo con procesos que coinciden con el estado del proceso.
-A, --ignore-ancestors
Ignora todos los ancestros de pgrep, pkill o pidwait. Por ejemplo, esto puede ser útil al elevar privilegios con sudo o herramientas similares.
-H, --require-handler
Coincide solo con procesos que tienen un manejador de señales en el espacio de usuario presente para la señal que se enviará.
--cgroup nombre,...
Coincide con el nombre del grupo de control (cgroup) v2 proporcionado. Ver cgroups(8)
--env nombre[=valor],...
Coincide con procesos que tienen estas variables de entorno. Si el parámetro =valor no está definido, solo se compara el nombre de la variable.
--ns pid
Coincide con procesos que pertenecen a los mismos espacios de nombres. Se requiere ejecutarse como root para coincidir con procesos de otros usuarios. Ver --nslist para saber cómo limitar a qué espacios de nombres coincidir.
--nslist nombre,...
Coincide solo con los espacios de nombres proporcionados. Espacios de nombres disponibles: ipc, mnt, net, pid, user, uts.
-q, --queue valor
Usa sigqueue(3) en lugar de kill(2) y el argumento valor se usa para especificar un entero que se enviará con la señal. Si el proceso receptor ha instalado un manejador para esta señal usando el flag SA_SIGINFO a sigaction(2), entonces puede obtener estos datos a través del campo si_value de la estructura siginfo_t.
-V, --version
Muestra información de la versión y sale.
-h, --help
Muestra la ayuda y sale.

OPERANDOS

patrón
Especifica una Expresión Regular Extendida para hacer coincidir los nombres de procesos o las líneas de comandos.

EJEMPLOS

Ejemplo 1: Buscar el ID del proceso del demonio named:

$ pgrep -u root named

Ejemplo 2: Hacer que syslog vuelva a leer su archivo de configuración:

$ pkill -HUP syslogd

Ejemplo 3: Proporcionar información detallada sobre todos los procesos xterm:

$ ps -fp $(pgrep -d, -x xterm)

Ejemplo 4: Hacer que todos los procesos chrome se ejecuten mejor:

$ renice +4 $(pgrep chrome)

Ejemplo 5: Esperar a que termine un proceso con un PID conocido:

$ echo ${PID} | pidwait -F -

ESTADO DE SALIDA

0
Uno o más procesos coincidieron con los criterios. Para pkill y pidwait, uno o más procesos también deben haber sido señalados o esperados con éxito.
1
Ningún proceso coincidió o ninguno de ellos pudo ser señalado.
2
Error de sintaxis en la línea de comandos.
3
Error fatal: falta de memoria, etc.

NOTAS

El nombre del proceso utilizado para la coincidencia se limita a los 15 caracteres presentes en la salida de /proc/pid/stat. Utilice la opción -f para hacer coincidir la línea de comandos completa, /proc/pid/cmdline. Los hilos pueden no tener el mismo nombre de proceso que el proceso padre, pero tendrán la misma línea de comandos.

El proceso pgrep, pkill o pidwait en ejecución nunca se informará a sí mismo como una coincidencia.

La opción -O --older fallará silenciosamente si /proc está montado con la opción subset=pid.

ERRORES

Las opciones -n, -o y -v no se pueden combinar. Avísame si necesitas hacerlo.

Se informan los procesos difuntos.

pidwait requiere la llamada al sistema pidfd_open(2) que apareció por primera vez en Linux 5.3.
