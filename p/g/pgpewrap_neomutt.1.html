NOMBRE

pgpewrap - Herramienta de manipulación de línea de comandos de NeoMutt

SINTAXIS

pgpewrap [ banderas ] -- prefijo [ destinatarios ]

DESCRIPCIÓN

Este es un pequeño programa C que realiza algunas manipulaciones de línea de comandos: El primer argumento es un comando a ejecutar. Cuando pgpewrap encuentra un argumento "--" (guión-guión), interpretará el siguiente argumento como un prefijo que se coloca delante de todos los argumentos posteriores.

EJEMPLO


pgpewrap pgpe file -- -r a b c

ejecutará:


pgpe file -r a -r b -r c

Este script es necesario con PGP 5 y con GPG, ya que las interfaces de línea de comandos no pueden ser atendidas correctamente por el mecanismo de formato de neomutt.
