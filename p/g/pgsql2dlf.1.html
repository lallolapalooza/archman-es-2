NOMBRE

pgsql2dlf - convertir archivos de registro de pgsql a formato dlf

SINOPSIS

pgsql2dlf

DESCRIPCIÓN

pgsql2dlf convierte un archivo de registro de consultas de PostgreSQL a formato DLF. La información sobre PostgreSQL se puede encontrar en http://www.postgresql.org/. El registro se puede habilitar en el archivo postgresql.conf.

Las siguientes opciones deben estar presentes al menos para que este conversor funcione bien:

debug_level = 1

debug_print_parse = on

debug_print_query = on

El formato genérico de base de datos dlf se describe en database.xml.

EJEMPLOS

Para procesar un registro tal como lo produce PostgreSQL:

$ pgsql2dlf < /var/log/postgresql.log

pgsql2dlf rara vez se usará por sí solo, sino que es más probable que sea llamado por lr_log2report:

$ lr_log2report pgsql < /var/log/postgresql.log

NOTAS

El analizador ha sido probado para archivos de registro de PostgreSQL 7.2.1.

VER TAMBIÉN

psql(1), postmaster(1), postgresql.conf(5)
