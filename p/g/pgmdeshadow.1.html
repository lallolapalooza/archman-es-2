NOMBRE

pgmdeshadow - Elimina sombras de una imagen PGM

SINOPSIS

pgmdeshadow

[archivo pnm]

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pgmdeshadow elimina sombras grises de una imagen. Esto es útil para una imagen que contiene texto, como las páginas de un libro escaneado, donde una sombra suele aparecer cerca del lomo del libro o cerca de un lado de la imagen. pgmdeshadow reconoce una sombra gris como un área de color que cambia suavemente, comenzando desde los bordes exteriores de la imagen. El programa utiliza un algoritmo simple de reconstrucción de imágenes para determinar el nivel de gris de la sombra local, luego divide el nivel de gris de cada píxel por el nivel de gris de la sombra local.

El algoritmo es el algoritmo 'reducción rápida de grises híbrida' de Luc Vincent, "Morphological Grayscale Reruction in Image Analysis: Applications and Efficient Algorithms.

Ninguna.

REFERENCIAS

Luc Vincent, 'Morphological Grayscale Reruction in Image Analysis: Applications and Efficient Algorithms,' IEEE Transactions on Image Processing, vol. 2, no. 2, abril de 1993, págs. 176-201.
