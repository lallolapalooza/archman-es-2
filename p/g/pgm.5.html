PGM(5) Manual de Formatos de Archivo PGM(5)

NOMBRE

pgm - Formato de imagen en escala de grises de Netpbm

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

El formato PGM es un formato de archivo de imagen en escala de grises de mínimo común denominador. Está diseñado para ser extremadamente fácil de aprender y de escribir programas para él. (Es tan simple que la mayoría de la gente simplemente lo ingeniería inversa porque es más fácil que leer esta especificación).

Una imagen PGM representa una imagen gráfica en escala de grises. Existen muchos formatos pseudo-PGM en uso donde todo es como se especifica aquí, excepto por el significado de los valores de píxel individuales. Para la mayoría de los propósitos, una imagen PGM puede pensarse simplemente como una matriz de enteros arbitrarios, y todos los programas del mundo que creen estar procesando una imagen en escala de grises pueden ser fácilmente engañados para procesar algo más.

El nombre "PGM" es un acrónimo derivado de "Portable Gray Map".

Una variante oficial de PGM es la máscara de transparencia. Una máscara de transparencia en Netpbm se representa mediante una imagen PGM, excepto que en lugar de intensidades de píxeles, hay valores de opacidad. Ver más abajo.

EL FORMATO

La definición del formato es la siguiente. Puede usar la biblioteca de subrutinas C libnetpbm(3)
para leer e interpretar el formato de manera conveniente y precisa.

Un archivo PGM consta de una secuencia de una o más imágenes PGM. No hay datos, delimitadores ni relleno antes, después o entre las imágenes.

Cada imagen PGM consta de lo siguiente:

  • Un 'número mágico' para identificar el tipo de archivo. El número mágico de una imagen pgm son los dos caracteres 'P5'.
  • Espacio en blanco (espacios, TABs, CRs, LFs).
  • Un ancho, formateado como caracteres ASCII en decimal.
  • Espacio en blanco.
  • Una altura, nuevamente en decimal ASCII.
  • Espacio en blanco.
  • El valor máximo de gris (Maxval), nuevamente en decimal ASCII. Debe ser menor que 65536 y mayor que cero.
  • Un solo carácter de espacio en blanco (generalmente un salto de línea).
  • Una matriz de Altura filas, en orden de arriba a abajo. Cada fila consta de Ancho valores de gris, en orden de izquierda a derecha. Cada valor de gris es un número de 0 a Maxval, siendo 0 negro y Maxval blanco. Cada valor de gris se representa en binario puro mediante 1 o 2 bytes. Si Maxval es menor que 256, es 1 byte. De lo contrario, son 2 bytes. El byte más significativo va primero.

    Una fila de una imagen es horizontal. Una columna es vertical. Los píxeles de la imagen son cuadrados y contiguos.

    Cada valor de gris es un número proporcional a la intensidad del píxel, ajustado por la función de transferencia gamma de la Recomendación BT.709 de la UIT-R. (Esa función de transferencia especifica un número gamma de 2.2 y tiene una sección lineal para intensidades pequeñas). Un valor de cero es, por lo tanto, negro. Un valor de Maxval representa el blanco CIE D65 y el valor más intenso en la imagen y cualquier otra imagen con la que la imagen pueda compararse.

    Tenga en cuenta que una variación común en el formato PGM es tener el valor de gris 'lineal', es decir, como se especifica arriba, pero sin el ajuste de gamma. pnmgamma toma tal variante PGM como entrada y produce una verdadera PGM como salida.

    En la variación de máscara de transparencia de PGM, el valor representa la opacidad. Es proporcional a la fracción de intensidad de un píxel que se mostraría en lugar de un píxel subyacente. Por lo tanto, lo que normalmente significa blanco representa opacidad total y lo que normalmente significa negro representa transparencia total. En medio, calcularía la intensidad de un píxel compuesto de un píxel 'inferior' y 'superior' como inferior * (1-(alfa/alpha_maxval)) + superior * (alfa/alpha_maxval). Tenga en cuenta que no hay función de transferencia gamma en la máscara de transparencia.

Las cadenas que comienzan con '#' pueden ser comentarios, lo mismo que con PBM(5)

Tenga en cuenta que puede usar pamdepth para convertir entre el formato con 1 byte por valor de gris y el que tiene 2 bytes por valor de gris.

Todos los caracteres mencionados aquí están codificados en ASCII. 'newline' se refiere al carácter conocido en ASCII como Line Feed o LF. Un carácter de 'espacio en blanco' es espacio, CR, LF, TAB, VT o FF (es decir, lo que la función isspace() de C estándar de ANSI llama espacio en blanco).

PGM Plano

En realidad, existe otra versión del formato PGM que es bastante rara: el formato PGM 'plano'. El formato anterior, que generalmente se considera el normal, se conoce como formato PGM 'crudo'. Consulte pbm(5)
para obtener algunos comentarios sobre cómo se relacionan los formatos plano y crudo entre sí y cómo usarlos.

La diferencia en el formato plano es:

  • Hay exactamente una imagen en un archivo.

  • El número mágico es P2 en lugar de P5.

  • Cada píxel en la matriz se representa como un número decimal ASCII (de tamaño arbitrario).

  • Cada píxel en la matriz tiene espacio en blanco antes y después. Debe haber al menos un carácter de espacio en blanco entre dos píxeles cualesquiera, pero no hay máximo.

  • Ninguna línea debe tener más de 70 caracteres.

Los programas que leen este formato deben ser lo más permisivos posible, aceptando cualquier cosa que parezca remotamente un PGM.

TIPO DE MEDIO DE INTERNET

No se ha registrado ningún Tipo de Medio de Internet (también conocido como tipo MIME, tipo de contenido) para PGM en IANA, pero el valor image/x-portable-graymap es convencional.

Tenga en cuenta que el Tipo de Medio de Internet PNM image/x-portable-anymap también se aplica.

NOMBRE DE ARCHIVO

No hay requisitos sobre el nombre de un archivo PGM, pero la convención es usar el sufijo '.pgm'. 'pnm' también es convencional, para casos en los que no es conveniente distinguir entre los subformatos particulares de PNM.

COMPATIBILIDAD

Antes de abril de 2000, un archivo PGM en formato crudo no podía tener un maxval mayor que 255. Por lo tanto, no podía tener más de un byte por muestra. Los programas antiguos pueden depender de esto.

Antes de julio de 2000, solo podía haber una imagen en un archivo PGM. Como resultado, la mayoría de las herramientas para procesar archivos PGM ignoran (y no leen) cualquier dato después de la primera imagen.

pgm(5)

NAME

pgm - portable graymap format

DESCRIPTION

The PGM (Portable Graymap) format is a simple, uncompressed, 8-bit-per-pixel grayscale image format.

A PGM file consists of a header followed by the image data.

The header contains the following information:

  • A magic number ("P2" for ASCII or "P5" for binary)
  • The width and height of the image in pixels
  • The maximum gray value (typically 255)

The image data follows the header, with pixel values ranging from 0 (black) to the maximum gray value (white).

THE FORMAT

There are two versions of the PGM format:

P2 (ASCII):
The header is in ASCII text, followed by pixel values separated by whitespace. This format is human-readable but larger in size.
P5 (Binary):
The header is in ASCII text, followed by the pixel data as raw bytes. This format is more compact but not human-readable.

INTERNET MEDIA TYPE

image/x-portable-graymap

FILE NAME

Typically, PGM files have the extension ".pgm".

COMPATIBILITY

The PGM format is widely supported by image manipulation software.
