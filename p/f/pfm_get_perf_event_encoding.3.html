pfm_get_perf_event_encoding(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual de Programador de Linux LIBPFM(3)

NOMBRE

pfm_get_perf_event_encoding - codifica el evento para la API perf_event

SINOPSIS

#include <perfmon/pfmlib_perf_event.h>

int pfm_get_perf_event_encoding(const char *str, int dfl_plm, struct perf_event_attr *attr, char **fstr, int *idx);

DESCRIPCIÓN

Esta función se puede usar junto con la API del kernel de Linux perf_events, que proporciona acceso a los contadores de rendimiento de hardware, contadores de software del kernel y puntos de traza. La función toma una cadena de evento en str y una máscara de nivel de privilegio por defecto en dfl_plm y rellena las partes relevantes de la estructura de datos específica de perf_events en attr.

Esta función está obsoleta. Ha sido reemplazada por pfm_get_os_event_encoding() con el argumento OS establecido en PFM_OS_PERF_EVENT o PFM_OS_PERF_EVENT_EXT. El uso de esta función proporciona soporte extendido para perf_events. Ciertas opciones de configuración de perf_event solo están disponibles a través de esta nueva interfaz.

Los siguientes ejemplos ilustran la transición:

   struct perf_event_attr attr;
   int i, count = 0;
   uint64_t *codes;
   memset(&attr, 0, sizeof(attr));
   ret = pfm_get_perf_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, &attrs, NULL, NULL);
   if (ret != PFM_SUCCESS)
      err(1, "no se puede obtener la codificación %s", pfm_strerror(ret));

es equivalente a:

   #include <perfmon/pfmlib_perf_event.h>
   struct perf_event_attr attr;
   pfm_perf_encode_arg_t arg;
   memset(&arg, 0, sizeof(arg));
   arg.size = sizeof(arg);
   arg.attr = &attr;
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_PERF, &arg);
   if (ret != PFM_SUCCESS)
      err(1, "no se puede obtener la codificación %s", pfm_strerror(ret));
El dfl_plm no puede ser cero, aunque no necesariamente lo utilice el evento.
Dependiendo del evento, se pueden utilizar combinaciones de los siguientes niveles
de privilegio:
PFM_PLM3
Medir a nivel de privilegio 3. Esto suele corresponder al nivel de usuario. En X86,
corresponde a los niveles de privilegio 3, 2, 1. Consulte la página del manual
específica de PMU para verificar si su modelo de PMU admite este nivel.
PFM_PLM2
Medir a nivel de privilegio 2. Consulte la página del manual específica de PMU para
verificar si su modelo de PMU admite este nivel.
PFM_PLM1
Medir a nivel de privilegio 1. Consulte la página del manual específica de PMU para
verificar si su modelo de PMU admite este nivel.
PFM_PLM0
Medir a nivel de privilegio 0. Esto suele corresponder al nivel del kernel. Consulte la
página del manual específica de PMU para verificar si su modelo de PMU admite
este nivel.
PFM_PLMH
Medir a nivel de privilegio de hipervisor. Esto se utiliza en conjunción con la
virtualización de hardware. Consulte la página del manual específica de PMU para
verificar si su modelo de PMU admite este nivel.
Si fstr no es NULL, la función hará que apunte a la cadena de evento
completamente calificada, es decir, una cadena con el nombre del evento, todas
las máscaras de unidad establecidas y el valor de todos los modificadores.
La biblioteca asignará memoria para almacenar la cadena de evento, pero es
responsabilidad del llamador liberar esa cadena eventualmente usando free().
Si idx no es NULL, devuelve el identificador único del evento
correspondiente.
Solo se modifican campos selectos por la función, los demás no se ven afectados.
Los siguientes campos en attr se modifican:
type
El tipo del evento
config
La codificación del evento
exclude_user
Si la ejecución a nivel de usuario debe o no excluirse del monitoreo. La definición
de usuario es específica del modelo de PMU.
exclude_kernel
Si la ejecución a nivel de kernel debe o no excluirse del monitoreo. La definición
de kernel es específica del modelo de PMU.
exclude_hv
Si la ejecución a nivel de hipervisor debe o no excluirse del monitoreo. La definición
de hipervisor es específica del modelo de PMU.
Por defecto, si no se especifica ningún modificador de nivel de privilegio en la
cadena del evento, la biblioteca borra
exclude_user, exclude_kernel y exclude_hv, lo que
resulta en que el evento se mida en todos los niveles sujetos al soporte de
hardware.
La función solo puede operar en un evento a la vez. Para mayor comodidad, acepta
cadenas de eventos con comas. En ese caso, traducirá el primer evento hasta la
primera coma. Esto es útil en caso de que las herramientas reciban eventos como
una lista separada por comas.

RETORNO

La función devuelve en attr la codificación perf_event que corresponde a la cadena del evento. Si idx no es NULL, contendrá el identificador único del evento al regresar exitosamente. El valor PFM_SUCCESS se devuelve si tiene éxito, de lo contrario, se devuelve un código de error negativo.

ERRORES

PFM_ERR_TOOSMALL
El argumento code es demasiado pequeño para la codificación.
PFM_ERR_INVAL
El argumento attr es NULL.
PFM_ERR_NOMEM
No hay suficiente memoria.
PFM_ERR_NOTFOUND
Evento no encontrado.
PFM_ERR_ATTR
Atributo de evento inválido (máscara de unidad o modificador)
PFM_ERR_ATTR_VAL
Valor del modificador inválido.
PFM_ERR_ATTR_SET
El atributo ya está establecido, no se puede cambiar.
PFM_ERR_ATTR_UMASK
Máscara de unidad faltante.
PFM_ERR_ATTR_FEATCOMB
Las máscaras de unidad o las características no se pueden combinar en un solo evento.
