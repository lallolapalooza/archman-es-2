pfm_get_event_next(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual de Programador de Linux LIBPFM(3)

NOMBRE

pfm_get_event_next - itera sobre eventos

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_event_next(int idx);

DESCRIPCIÓN

Los eventos se identifican de forma única con identificadores enteros opacos. No hay un orden garantizado dentro de los identificadores. Por lo tanto, para listar todos los eventos, es necesario utilizar iteradores.

Los eventos se agrupan en tablas dentro de la biblioteca. Una tabla suele corresponder a un modelo o familia de PMU. La biblioteca contiene soporte para múltiples modelos de PMU, por lo que tiene múltiples tablas. Basado en el hardware anfitrión y entornos de software, las tablas se activan cuando la biblioteca se inicializa a través de pfm_initialize(). Los eventos de las tablas activadas se denominan eventos activos. Los eventos de tablas no activadas se denominan eventos soportados.

Los identificadores de eventos suelen recuperarse a través de pfm_find_event() o al codificar eventos.

Para iterar sobre una lista de eventos para un modelo de PMU dado, todo lo que se necesita es un identificador inicial para el PMU. El primer identificador de evento se obtiene generalmente a través de pfm_get_pmu_info().

La función pfm_get_event_next() devuelve el identificador del siguiente evento soportado después del pasado en idx. Este iterador se detiene cuando el último evento para el PMU se pasa como argumento, en cuyo caso la función devuelve -1.

void list_pmu_events(pfm_pmu_t pmu)
{
   struct pfm_event_info info;
   struct pfm_pmu_info pinfo;
   int i, ret;
   memset(&info, 0, sizeof(info));
   memset(&pinfo, 0, sizeof(pinfo));
   info.size = sizeof(info);
   pinfo.size = sizeof(pinfo);
   ret = pfm_get_pmu_info(pmu, &pinfo);
   if (ret != PFM_SUCCESS)
      errx(1, "no se puede obtener información del pmu");
   for (i = pinfo.first_event; i != -1; i = pfm_get_event_next(i)) {
      ret = pfm_get_event_info(i, &info);
      if (ret != PFM_SUCCESS)
        errx(1, "no se puede obtener información del evento");
        printf("%s Evento: %s::%s\n",
               pinfo.present ? "Activo" : "Soportado",
               pinfo.name, info.name);
  }
}

RETORNO

La función devuelve el identificador del siguiente evento soportado. Devuelve -1 cuando el argumento ya es el último evento para el PMU.

ERRORES

Esta función no devuelve ningún código de error, aparte de -1.
