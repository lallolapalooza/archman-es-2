NOMBRE

pf2afm - Crea un archivo AFM a partir de archivos de fuentes Postscript (PFB/PFA/PFM) usando ghostscript

SINOPSIS

pf2afm nombre_archivo_fuente

DESCRIPCIÓN

Este script invoca gs(1) para crear un archivo AFM a partir de archivos PFB / PFA y (opcionalmente) PFM. La salida va a nombre_archivo_fuente.afm, que no debe existir previamente.

VER TAMBIÉN

gs(1)
pf2afm.ps en el directorio lib de Ghostscript.

VERSIÓN

Este documento fue revisado por última vez para la versión de Ghostscript 10.04.0.
