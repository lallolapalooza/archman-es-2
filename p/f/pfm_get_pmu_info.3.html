pfm_get_pmu_info(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual de Programador de Linux LIBPFM(3)

NOMBRE

pfm_get_pmu_info - obtener información de la PMU

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_pmu_info(pfm_pmu_t pmu, pfm_pmu_info_t *info);

DESCRIPCIÓN

Esta función devuelve en info información sobre un modelo de PMU designado por su identificador en pmu.

La estructura pfm_pmu_info se define de la siguiente manera:

typedef struct {
        const char              *name;
        const char              *desc;
        pfm_pmu_t               pmu;
        pfm_pmu_type_t          type;
        int                     size;
        int                     nevents;
        int                     first_event;
        int                     max_encoding;
        int                     num_cntrs;
        int                     num_fixed_cntrs;
        struct {
                int             is_present:1;
                int             is_arch_default:1;
                int             is_core:1;
                int             is_uncore:1;
                int             reserved:28;
        };
} pfm_pmu_info_t;

Los campos de esta estructura se definen de la siguiente manera:

name
Este es el nombre simbólico de la PMU. Este nombre puede usarse como prefijo en una cadena de eventos. Esta es una cadena de solo lectura.
desc
Esta es la descripción de la PMU. Esta es una cadena de solo lectura.
pmu
Este es el código de identificación único de la PMU. Es idéntico al valor pasado en pmu y se proporciona solo para completitud.
type
Este campo contiene el tipo de la PMU. Los siguientes tipos están definidos:
PFM_PMU_TYPE_UNKNOWN
No se pudo determinar el tipo de la PMU.
PFM_PMU_TYPE_CORE
Este campo se establece a uno cuando la PMU es implementada por el núcleo del procesador.
PFM_PMU_TYPE_UNCORE
Este campo se establece a uno cuando la PMU está implementada en el chip del procesador pero a nivel de socket, es decir, capturando eventos para todos los núcleos.
nevents
Este es el número de eventos disponibles para este modelo de PMU basado en el procesador anfitrión. Es solo válido si el campo is_present está establecido a 1. Los identificadores de eventos no están garantizados como contiguos. En otras palabras, no es porque nevents sea igual a 100, que los identificadores de eventos van de 0 a 99. La función iteradora pfm_get_event_next() debe usarse para pasar de un identificador al siguiente.
first_event
Este campo devuelve el índice opaco del primer evento para este modelo de PMU. El índice puede usarse con las funciones pfm_get_event_info() o pfm_get_event_next(). En caso de que no haya ningún evento disponible, este campo contiene -1.
num_cntrs
Este campo contiene el número de contadores genéricos soportados por la PMU. Un contador es genérico si puede contar más de un evento. Cuando no es posible determinar el número de contadores genéricos, este campo contiene -1.
num_fixed_cntrs
Este campo contiene el número de contadores fijos soportados por la PMU. Un contador es fijo si está cableado para contar solo un evento. Cuando no es posible determinar el número de contadores genéricos, este campo contiene -1.
size
Este campo contiene el tamaño de la estructura pasada. Este campo se usa para proporcionar extensibilidad a la estructura sin comprometer la compatibilidad con versiones anteriores. El valor debe establecerse en sizeof(pfm_pmu_info_t). Si en cambio, se especifica un valor de 0, la biblioteca asume que la estructura pasada es idéntica a la primera versión de ABI, cuyo tamaño es PFM_PMU_INFO_ABI0. Por lo tanto, si se agregaron campos después de la primera ABI, no serán establecidos por la biblioteca. La biblioteca verifica que los bytes más allá de lo implementado sean ceros.
max_encoding
Este campo devuelve el número de códigos de evento devueltos por pfm_get_event_encoding().
is_present
Este campo se establece a uno si el modelo de PMU ha sido detectado en el sistema anfitrión.
is_dfl
Este campo se establece a uno si la PMU es la PMU predeterminada para esta arquitectura. De lo contrario, este campo es cero.

RETORNO

Si la operación es exitosa, la función devuelve PFM_SUCCESS y la información de la PMU en info; de lo contrario, devuelve un código de error.

ERRORES

PFMLIB_ERR_NOINIT
La biblioteca no ha sido inicializada correctamente.
PFMLIB_ERR_NOTSUPP
El modelo de PMU no es soportado por la biblioteca.
PFMLIB_ERR_INVAL
El argumento pmu es inválido o info es NULL o size no es cero.
