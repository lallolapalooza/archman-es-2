pfm_get_os_event_encoding(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual del programador de Linux LIBPFM(3)

NOMBRE

pfm_get_os_event_encoding - obtener la codificación de eventos para un sistema operativo específico

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_os_event_encoding(const char *str, int dfl_plm, pfm_os_t os,  void *arg);

DESCRIPCIÓN

Esta es la función clave para recuperar la codificación de un evento para una interfaz de sistema operativo específica. La cadena de evento pasada en str se analiza y se codifica para el sistema operativo especificado por os. Solo se puede codificar un evento por llamada. Como tal, str solo puede contener un nombre de evento simbólico. El evento se codifica para monitorear en los niveles de privilegio especificados por la máscara dfl_plm, si es compatible, de lo contrario, este parámetro se ignora. Los argumentos de entrada y salida específicos del sistema operativo se pasan en arg.

La cadena de evento, str, puede contener máscaras de sub-eventos (umask) y cualquier otro modificador compatible. Solo se analiza un evento de la cadena. Para mayor comodidad, es posible pasar una lista separada por comas de eventos en str, pero solo se codifica el primer evento.

Los siguientes valores son compatibles con os:

PFM_OS_NONE
Este valor hace que el evento se codifique puramente según lo especificado por el hardware PMU. El argumento arg debe ser un puntero a una estructura pfm_pmu_encode_arg_t que se define de la siguiente manera: 
typedef struct {
    uint64_t    *codes;
    char        **fstr;
    size_t      size;
    int         count;
    int         idx;
} pfm_pmu_encode_arg_t;

Los campos se definen de la siguiente manera:

codes
Un puntero a una matriz de valores de 64 bits. En la entrada, si codes es NULL, la biblioteca asigna lo necesario para almacenar la codificación del evento. Si codes no es NULL en la entrada, entonces count debe reflejar su número real de elementos. Si count es lo suficientemente grande, la biblioteca almacena la codificación en la dirección proporcionada. De lo contrario, se devuelve un error.
count
En la entrada, el campo contiene el número máximo de elementos en la matriz codes. Al regresar, contiene el número de entradas reales en codes. Si codes es NULL, entonces count debe ser cero.
fstr
Si el llamador está interesado en recuperar la cadena de evento completamente calificada donde se deletrean todas las máscaras de unidad utilizadas y todos los modificadores, este campo debe establecerse en una dirección no nula de un puntero a una cadena (char **). Al regresar, si fstr no era NULL, entonces el puntero de cadena pasado en la entrada apunta a la cadena de evento. La cadena se asigna dinámicamente y debe ser liberada eventualmente por el llamador. Si fstr era NULL en la entrada, entonces no se devuelve nada en este campo. La secuencia de llamada típica se ve así: 
   char *fstr = NULL
   pfm_pmu_encode_arg_t arg;
   arg.fstr = &fstr;
   ret = pfm_get_os_event_encoding("event",
                                   PFM_PLM0|PFM_PLM3,
                                   PFM_OS_NONE,
                                   &e);
   if (ret == PFM_SUCCESS) {
      printf("fstr=%s\n", fstr);
      free(fstr);
   }
size
Este campo contiene el tamaño de la estructura pasada. Este campo se utiliza para proporcionar extensibilidad de la estructura sin comprometer la compatibilidad con versiones anteriores. El valor debe establecerse en sizeof(pfm_pmu_encode_arg_t). Si en su lugar se especifica un valor de 0, la biblioteca asume que la estructura pasada es idéntica a la primera versión ABI, cuyo tamaño es PFM_RAW_ENCODE_ABI0. Por lo tanto, si se agregaron campos después de la primera ABI, la biblioteca no los establecerá. La biblioteca verifica que los bytes más allá de lo implementado estén en cero.
idx
Al regresar, este campo contiene el identificador único opaco para el evento descrito en str. Este índice se puede utilizar para recuperar información sobre el evento utilizando pfm_get_event_info(), por ejemplo.
PFM_OS_PERF_EVENT, PFM_OS_PERF_EVENT_EXT
Este valor hace que el evento se codifique para la interfaz del kernel de Linux perf_event (disponible desde 2.6.31). El arg debe ser un puntero a una estructura pfm_perf_encode_arg_t. La capa PFM_OS_PERF_EVENT proporciona los modificadores exportados por el hardware PMU subyacente, algunos de los cuales pueden ser anulados por la interfaz perf_event, como los niveles de privilegio de monitoreo. El PFM_OS_PERF_EVENT_EXT extiende PFM_OS_PERF_EVENT para agregar modificadores controlados solo por la interfaz perf_event, como el período de muestreo (period), la frecuencia (freq) y el acceso exclusivo a recursos (excl). 
typedef struct {
    struct perf_event_attr *attr;
    char **fstr;
    size_t size;
    int idx;
    int cpu;
    int flags;
} pfm_perf_encode_arg_t;
Los campos se definen de la siguiente manera:
attr
Un puntero a una struct perf_event_attr según se define en perf_event.h. Este campo no puede ser NULL en la entrada. La estructura no se sobrescribe por completo con la llamada. La biblioteca solo modifica los campos que conoce, lo que permite la falta de coincidencia de la ABI de perf_event entre el llamador y la biblioteca.
fstr
Mismo comportamiento que se describe para PFM_OS_NONE arriba.
size
Este campo contiene el tamaño de la estructura pasada. Este campo se utiliza para proporcionar extensibilidad de la estructura sin comprometer la compatibilidad con versiones anteriores. El valor debe establecerse en sizeof(pfm_perf_encode_arg_t). Si en su lugar se especifica un valor de 0, la biblioteca asume que la estructura pasada es idéntica a la primera versión ABI, cuyo tamaño es PFM_PERF_ENCODE_ABI0. Por lo tanto, si se agregaron campos después de la primera ABI, la biblioteca no los establecerá. La biblioteca verifica que los bytes más allá de lo implementado estén en cero.
idx
Al regresar, este campo contiene el identificador único opaco para el evento descrito en str. Este índice se puede utilizar para recuperar información sobre el evento utilizando pfm_get_event_info(), por ejemplo.
cpu
Aún no se utiliza.
flags
Aún no se utiliza.

Aquí hay un ejemplo de cómo se podría usar esta función con PFM_OS_NONE:

#include <inttypes.h>
#include <err.h>
#include <perfmon/pfmlib.h>
int main(int argc, char **argv)
{
   pfm_pmu_encode_arg_t arg;
   int i, ret;
   ret = pfm_initialize();
   if (ret != PFM_SUCCESS)
      errx(1, "cannot initialize library %s", pfm_strerror(ret));
   memset(&arg, 0, sizeof(arg));
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_NONE, &arg);
   if (ret != PFM_SUCCESS)
      err(1, "cannot get encoding %s", pfm_strerror(ret));
   for(i = 0; i < arg.count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, arg.codes[i]);
   free(arg.codes);
   return 0;
}

RETORNO

La función devuelve en arg la codificación del evento para el os pasado en os. El contenido de arg depende del argumento os. En caso de éxito, se devuelve PFM_SUCCESS; de lo contrario, se devuelve un código de error específico.

ERRORES

PFM_ERR_TOOSMALL
El argumento code es demasiado pequeño para la codificación.
PFM_ERR_INVAL
El argumento code o count es NULL o str contiene más de un evento simbólico.
PFM_ERR_NOMEM
No hay suficiente memoria.
PFM_ERR_NOTFOUND
Evento no encontrado.
permalink' href='#PFM_ERR_ATTR'>MAL
El campo attr es NULL en la entrada para PFM_OS_PERF_EVENT, PFM_OS_PERF_EVENT_EXT.
PFM_ERR_ABI
La estructura de argumentos pasada es demasiado antigua y no soporta las características solicitadas por la llamada.

pfm_get_os_event_encoding.3

NAME

pfm_get_os_event_encoding — retrieve OS-specific event encoding

SYNOPSIS

#include <perfmon/pfm.h>

int pfm_get_os_event_encoding(unsigned int event_code, pfm_event_encoding_t *encoding, void *buffer, size_t buffer_size);

DESCRIPTION

The pfm_get_os_event_encoding function retrieves the OS-specific encoding for a given hardware performance monitoring event. The encoding is typically used by the OS kernel to configure the performance monitoring unit (PMU).

The event_code parameter is the unique identifier for the event, as returned by functions like pfm_get_event_code.

The encoding parameter is a pointer to a pfm_event_encoding_t structure. This structure will be filled with the OS-specific encoding information. The structure contains fields for the event identifier, the unit mask, and any modifier values.

The buffer and buffer_size parameters are used for the OS-specific data associated with the encoding. This data might include things like CPU-specific flags or other configuration details. The library will copy the OS-specific data into the provided buffer. The size of the buffer must be at least PFM_OS_BUF_SIZE.

RETURN

On success, the function returns PFM_SUCCESS. On failure, it returns an error code.

ERRORS

PFM_ERR_ATTR
Invalid event attribute (unit mask or modifier)
PFM_ERR_ATTR_VAL
Invalid modifier value.
PFM_ERR_ATTR_SET
attribute already set, cannot be changed.
PFM_ERR_ATTR_UMASK
Missing unit mask.
PFM_ERR_ATTR_FEATCOMB
Unit masks or features cannot be combined into a single event.
