pfm_get_event_info(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual de Programación de Linux LIBPFM(3)

NOMBRE

pfm_get_event_info - obtener información del evento

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_event_info(int idx, pfm_os_t os, pfm_event_info_t *info);

DESCRIPCIÓN

Esta función devuelve en info información sobre un evento específico designado por su identificador único opaco en idx para el sistema operativo especificado en os.

La estructura pfm_event_info_t se define de la siguiente manera:

typedef struct {
        const char              *name;
        const char              *desc;
        const char              *equiv;
        size_t			size;
        uint64_t                code;
        pfm_pmu_t               pmu;
        pfm_dtype_t             dtype
        int                     idx;
        int                     nattrs;
        struct {
          unsigned int is_precise:1;
          unsigned int reserved_bits:31;
        };
} pfm_event_info_t;

Los campos de esta estructura se definen de la siguiente manera:

name
Este es el nombre del evento. Es una cadena de solo lectura.
desc
Esta es la descripción del evento. Es una cadena de solo lectura. Puede contener varias oraciones.
equiv
Ciertos eventos pueden ser solo variaciones de eventos reales. Pueden proporcionarse como atajos útiles para evitar proporcionar una larga lista de atributos. Para esos eventos, este campo no es NULL y contiene la cadena de evento equivalente completa.
code
Este es el código de evento sin procesar. No debe confundirse con la codificación del evento. Este campo representa solo el código de selección del evento, no incluye ninguna máscara de unidad ni configuración de atributos.
pmu
Esta es la identificación del modelo PMU al que pertenece este evento. Es de tipo pfm_pmu_t. Usando este valor y la función pfm_get_pmu_info, es posible obtener información del PMU.
dtype
Este campo devuelve la representación de los datos del evento. Por defecto, es PFM_DATA_UINT64.

idx Este es el identificador opaco único del evento. Es idéntico al índice pasado a la llamada y se proporciona para completar.

nattrs
Este es el número de atributos compatibles con este evento. Los atributos pueden ser máscaras de unidad o modificadores. Si el evento no tiene atributos, el valor de este campo es simplemente 0.
size
Este campo contiene el tamaño de la estructura pasada. Este campo se utiliza para proporcionar extensibilidad de la estructura sin comprometer la compatibilidad con versiones anteriores. El valor debe establecerse en sizeof(pfm_event_info_t). Si en su lugar se especifica un valor de 0, la biblioteca asume que la estructura pasada es idéntica a la primera versión de la ABI, cuyo tamaño es PFM_EVENT_INFO_ABI0. Por lo tanto, si se agregaron campos después de la primera ABI, la biblioteca no los establecerá. La biblioteca verifica que los bytes más allá de lo implementado estén en ceros.
is_precise
Este campo de bits indica si el evento admite muestreo preciso. El muestreo preciso es un mecanismo de hardware que evita el deslizamiento de la dirección de la instrucción al usar muestreo basado en interrupciones. Cuando el evento tiene máscaras de unidad, este campo significa que al menos una máscara de unidad admite muestreo preciso. En los procesadores Intel X86, esto indica si el evento admite Muestreo Preciso Basado en Eventos (PEBS).
is_speculative
Este campo de bits indica si el evento incluye ocurrencias que suceden durante la ejecución especulativa tanto para el camino incorrecto como para el correcto. Dado que este tipo de información del evento no siempre está disponible por parte de los proveedores, este campo utiliza varios bits. Un valor de PFM_EVENT_INFO_SPEC_NA indica que la información de especulación no está disponible. Un valor de PFM_EVENT_INFO_SPEC_TRUE indica que el evento cuenta durante la ejecución especulativa. Un valor de PFM_EVENT_INFO_SPEC_FALS indica que el evento no cuenta durante la ejecución especulativa.

La enumeración pfm_os_t proporciona las siguientes opciones:

PFM_OS_NONE
La información devuelta se refiere únicamente a lo que exporta el hardware PMU. No se tienen en cuenta los atributos del sistema operativo.
PFM_OS_PERF_EVENT
La información devuelta incluye el hardware PMU real y los atributos adicionales exportados por la interfaz del kernel perf_events. Los atributos perf_event se refieren únicamente al hardware PMU. En caso de que no se detecte perf_events, se devuelve un error.
PFM_OS_PERF_EVENT_EXT
La información devuelta incluye todo lo que ya proporciona PFM_OS_PERF_EVENT más todos los atributos de software controlados por perf_events, como el período de muestreo y el muestreo preciso.

RETORNO

Si la operación es exitosa, la función devuelve PFM_SUCCESS y la información del evento en info, de lo contrario, devuelve un código de error.

ERRORES

PFMLIB_ERR_NOINIT
La biblioteca no se inicializó correctamente.
PFMLIB_ERR_INVAL
El argumento idx no es válido o info es NULL o size no es cero.
PFMLIB_ERR_NOTSUPP
El os solicitado no se detecta o no es compatible.
