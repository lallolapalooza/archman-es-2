pfm_get_event_attr_info(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual del programador de Linux LIBPFM(3)

NOMBRE

pfm_get_event_attr_info - obtener información de atributos de eventos

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_event_attr_info(int idx, int attr, pfm_os_t os, pfm_event_attr_info_t *info);

DESCRIPCIÓN

Esta función devuelve en info información sobre el atributo designado por attr para el evento especificado en idx y la capa del SO en os.

La enumeración pfm_os_t proporciona las siguientes opciones:

PFM_OS_NONE
La información devuelta se refiere únicamente a lo que exporta el hardware de la PMU. No se tienen en cuenta los atributos del sistema operativo.
PFM_OS_PERF_EVENT
La información devuelta incluye el hardware de la PMU real y los atributos adicionales exportados por la interfaz del kernel perf_events. Los atributos de perf_event se refieren únicamente al hardware de la PMU. En caso de que no se detecte perf_events, se devuelve un error.
PFM_OS_PERF_EVENT_EXT
La información devuelta incluye todo lo que ya proporciona PFM_OS_PERF_EVENT más todos los atributos de software controlados por perf_events, como el período de muestreo, muestreo preciso.

La estructura pfm_event_attr_info_t se define de la siguiente manera:

typedef struct {
        const char              *name;
        const char              *desc;
        const char              *equiv;
        size_t			size;
        uint64_t                code;
        pfm_attr_t              type;
        int                     idx;
        pfm_attr_ctrl_t         ctrl;
        int                     reserved1;
        struct {
                int             is_dfl:1;
                int             is_precise:1;
                int             is_speculative:2;
		int		support_hw_smpl:1;
		int		support_no_mods:1;
                int             reserved:26;
        };
        union {
                uint64_t        dfl_val64;
                const char      *dfl_str;
                int             dfl_bool;
                int             dfl_int;
        };
} pfm_event_attr_info_t;

Los campos de esta estructura se definen de la siguiente manera:

name
Este es el nombre del atributo. Es una cadena de solo lectura.
desc
Esta es la descripción del atributo. Es una cadena de solo lectura. Puede contener varias frases.
equiv
Ciertos atributos pueden ser simplemente variaciones de otros atributos para el mismo evento. Pueden proporcionarse como atajos útiles para evitar suministrar una larga lista de atributos. Para esos atributos, este campo no es NULL y contiene la cadena de atributo equivalente completa. Esta cadena, una vez añadida al nombre del evento, puede usarse en llamadas a la biblioteca que requieran una cadena de evento.
code
Este es el código de atributo real. Para PFM_ATTR_UMASK, es el código de la máscara de unidad. Para todos los demás atributos, es un índice opaco.
type
Este es el tipo del atributo. Los atributos representan sub-eventos o filtros adicionales que se pueden aplicar al evento. Los filtros (también llamados modificadores) pueden estar vinculados al evento o al registro PMU en el que se programa el evento. El tipo de un atributo determina cómo debe especificarse. Los siguientes tipos están definidos:
PFM_ATTR_UMASK
Esta es una máscara de unidad, es decir, un sub-evento. Se especifica usando su nombre. Dependiendo del evento, puede ser posible especificar múltiples máscaras de unidad.
PFM_ATTR_MOD_BOOL
Este es un atributo booleano. Tiene un valor de 0, 1, y o n. El valor se especifica después del signo igual, por ejemplo, foo=1. Como conveniencia, se pueden omitir el signo igual y el valor, en cuyo caso esto es equivalente a =1.
PFM_ATTR_MOD_INTEGER
Este es un atributo entero. Tiene un valor que debe pasarse después del signo igual. El rango de valores válidos depende del atributo y generalmente se especifica en su descripción.
idx
Este es el índice del atributo. Es idéntico al valor de attr pasado a la llamada y se proporciona por completitud.
size
Este campo contiene el tamaño de la estructura pasada. Este campo se utiliza para proporcionar extensibilidad a la estructura sin comprometer la compatibilidad con versiones anteriores. El valor debe establecerse en sizeof(pfm_event_attr_info_t). Si, en cambio, se especifica un valor de 0, la biblioteca asume que la estructura pasada es idéntica a la primera versión de la ABI, cuyo tamaño es PFM_ATTR_INFO_ABI0. Por lo tanto, si se agregaron campos después de la primera ABI, la biblioteca no los establecerá. La biblioteca comprueba que los bytes más allá de lo implementado sean ceros.
is_dfl
Este campo indica si este atributo se establece por defecto o no. Esto se aplica principalmente a PFM_ATTR_UMASK. Si una máscara de unidad está marcada como por defecto y no se especifica ninguna máscara de unidad en la cadena del evento, la biblioteca la usa por defecto. Tenga en cuenta que puede haber varios valores por defecto por evento, dependiendo de cómo se agrupen las máscaras de unidad.
is_precise
Este campo indica si esta máscara de unidad admite el muestreo preciso. El muestreo preciso es un mecanismo de hardware que evita el deslizamiento de la dirección de la instrucción cuando se utiliza el muestreo basado en interrupciones. En los procesadores Intel X86, este campo indica que la máscara de unidad admite el muestreo basado en eventos precisos (PEBS).
is_speculative
Este campo de bits indica si el atributo incluye ocurrencias que suceden durante la ejecución especulativa, tanto en caminos correctos como incorrectos. Dado que esta información de eventos no siempre está disponible de los proveedores, este campo utiliza varios bits. Un valor de PFM_EVENT_INFO_SPEC_NA indica que la información de especulación no está disponible. Un valor de PFM_EVENT_INFO_SPEC_TRUE indica que el atributo cuenta durante la ejecución especulativa. Un valor de PFM_EVENT_INFO_SPEC_FALSE indica que el atributo no cuenta durante la ejecución especulativa.
support_hw_smpl
Este campo booleano indica que el atributo (en este caso una máscara de unidad) admite el muestreo de hardware. Esto significa que el hardware puede muestrear este evento + máscaras de unidad sin involucrar al kernel en cada muestra.
support_no_mods
Este campo booleano indica que el atributo (en este caso una máscara de unidad) no admite modificadores de hardware o software, como filtros de nivel de privilegio, muestreo, muestreo preciso, etc. Esto es necesario cuando algunas máscaras de unidad de un evento tienen más restricciones que otras, por ejemplo, el evento y la mayoría de las máscaras de unidad admiten modificadores, excepto algunas máscaras de unidad.
dfl_val64, dfl_str, dfl_bool, dfl_int
Esta unión contiene el valor de un atributo. Para PFM_ATTR_UMASK, es el código de la máscara de unidad, para todos los demás tipos es el valor real del atributo.
ctrl
Este campo indica qué capa o fuente controla el atributo. Las siguientes fuentes están definidas:
PFM_ATTR_CTRL_UNKNOWN
La fuente que controla el atributo es desconocida.
PFM_ATTR_CTRL_PMU
El atributo está controlado por el hardware de la PMU.
PFM_ATTR_CTRL_PERF_EVENT
El atributo está controlado por la interfaz del kernel perf_events.

RESERVADO

RESERVADO
Estos campos deben establecerse en cero.

DEVOLUCIÓN

Si la operación tiene éxito, la función devuelve PFM_SUCCESS e información de atributos en info; de lo contrario, devuelve un código de error.

ERRORES

PFMLIB_ERR_NOINIT
La biblioteca no se ha inicializado correctamente.
PFMLIB_ERR_INVAL
Los argumentos idx o attr son inválidos, o info es NULL, o size no es cero.
PFM_ERR_NOTSUPP
La capa del sistema operativo solicitada no se ha detectado en el sistema host.
