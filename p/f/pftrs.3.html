CPFTRS

Propósito:

!>
!> CPFTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> Hermítica positiva definida A utilizando la factorización de Cholesky
!> A = U**H*U o A = L*L**H calculada por CPFTRF.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la TRANSficción Normal de A en formato empaquetado (RFP);
!>          = 'C':  Se almacena la TRANSficción Conjugada-transpuesta de A en formato empaquetado (RFP).
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A en formato empaquetado (RFP);
!>          = 'L':  Se almacena el triángulo inferior de A en formato empaquetado (RFP).
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión ( N*(N+1)/2 );
!>          El factor triangular U o L de la factorización de Cholesky
!>          de A en formato empaquetado (RFP) A = U**H*U o RFP A = L*L**H,
!>          tal como se calculó en CPFTRF.
!>          Ver la nota a continuación para más detalles sobre el formato RFP A.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>          En la entrada: la matriz del lado derecho B.
!>          En la salida: la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

subroutine cpftrs (character transr, character uplo, integer n, integer nrhs, complex, dimension( 0: * ) a, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPFTRS

Purpose:

!>
!> CPFTRS solves a system of linear equations A*X = B with a Hermitian
!> positive definite matrix A using the Cholesky factorization
!> A = U**H*U or A = L*L**H computed by CPFTRF.
!>

Parameters

TRANSR 
!>          TRANSR is CHARACTER*1
!>          = 'N':  The Normal TRANSR of RFP A is stored;
!>          = 'C':  The Conjugate-transpose TRANSR of RFP A is stored.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of RFP A is stored;
!>          = 'L':  Lower triangle of RFP A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

A

!>          A is COMPLEX array, dimension ( N*(N+1)/2 )
!>          The triangular factor U or L from the Cholesky factorization
!>          of RFP A = U**H*U or RFP A = L*L**H, as computed by CPFTRF.
!>          See note below for more details about RFP A.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

!>
!>  We first consider Rectangular Full Packed (RFP) Format when N is
!>  even. We give an example where N = 6.
!>

!>      11 12 13 14 15       10 11

!>            33 34 35       30 31 32 33
!>               44 45       40 41 42 43 44
!>                  55       50 51 52 53 54 55
!>

!>  For UPLO = 'U' the upper trapezoid A(0:5,0:2) consists of the last
!>  three columns of AP upper. The lower triangle A(4:6,0:2) consists of
!>  the transpose of the first three columns of AP upper.
!>  For UPLO = 'L' the lower trapezoid A(1:6,0:2) consists of the first
!>  three columns of AP lower. The upper triangle A(0:2,0:2) consists of
!>  the transpose of the last three columns of AP lower.
!>  This covers the case N even and TRANSR = 'N'.
!>

!>        33 34 35                20 21 22
!>        00 44 45                30 31 32
!>        01 11 55                40 41 42
!>        02 12 22                50 51 52

!>  transpose of RFP A above. One therefore gets:

!>           RFP A                   RFP A

!>      11 12 13 14              10 11
!>         22 23 24              20 21 22
!>            33 34              30 31 32 33
!>               44              40 41 42 43 44
!>

SGFTRI

Purpose:

!>
!> SGFTRI computes the inverse of a general tridiagonal matrix A = GFT = L*U
!> using the L*U factorization computed by SGFTRF.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U': Upper trapezoid of A is supplied on the diagonal and
!>                 first super-diagonal.
!>          = 'L': Lower trapezoid of A is supplied on the diagonal and
!>                 first sub-diagonal.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA, N)
!>          On entry, the elements of U or L from the factorization of A.
!>          On exit, the inverse of the original matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

B

!>          B is REAL array, dimension (LDB, N).
!>          On entry, the first N entries of B must contain the vectors
!>          e_1, ..., e_N, the standard basis vectors in the representation
!>          of the inverse.
!>          On exit, B contains the inverse of A.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          > 0:  if INFO = i, then U(i,i) is zero. The inverse could not
!>                be computed, and the matrix is singular.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

subroutine sgftrf (character uplo, integer n, integer lda, real, dimension( lda, * ) a, real, dimension( n, * ) d, real, dimension( n, * ) e, integer info)

SGFTRF

Purpose:

!>
!> SGFTRF computes the L*U factorization of a general tridiagonal matrix A
!> with partial pivoting.
!>
!> A = P * GFT = P * (D * U) = (L * U) * U
!>
!> where U is a unit upper triangular matrix, P is a unit lower
!> triangular matrix, D is a diagonal matrix, and GFT is the general
!> tridiagonal factorization.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower tridiagonal.
!>          = 'U': Upper tridiagonal matrix:
!>                 A = ( D   U )
!>                     ( L   0 )
!>          = 'L': Lower tridiagonal matrix:
!>                 A = ( 0   U )
!>                     ( L   D )
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

A

!>          A is REAL array, dimension (LDA, N)
!>          On entry, the matrix A to be factorized.
!>          On exit, the factors L and U are stored on the diagonal
!>          and first sub- and super-diagonals of A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

D

!>          D is REAL array, dimension (N)
!>          On exit, the diagonal matrix D.
!>

E

!>          E is REAL array, dimension (N)
!>          On exit, the first sub-diagonal of E and the first
!>          super-diagonal of E.
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          > 0: if INFO = i, then D(i) is zero. The factorization has been
!>               completed, but the matrix is not needed since the
!>               diagonal entry and/or sub-diagonal entry is zero.
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

ZGFTRF

Purpose:

!>
!> ZGFTRF computes the L*U factorization of a general tridiagonal matrix A
!> with partial pivoting.
!>
!> A = P * GFT = P * (D * U) = (L * U) * U
!>
!> where U is a unit upper triangular matrix, P is a unit lower
!> triangular matrix, D is a diagonal matrix, and GFT is the general
!> tridiagonal factorization.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower tridiagonal.
!>          = 'U': Upper tridiagonal matrix:
!>                 A = ( D   U )
!>                     ( L   0 )
!>          = 'L': Lower tridiagonal matrix:
!>                 A = ( 0   U )
!>                     ( L   D )
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, N)
!>          On entry, the matrix A to be factorized.
!>          On exit, the factors L and U are stored on the diagonal
!>          and first sub- and super-diagonals of A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

D

!>          D is COMPLEX*16 array, dimension (N)
!>          On exit, the diagonal matrix D.
!>

E

!>          E is COMPLEX*16 array, dimension (N)
!>          On exit, the first sub-diagonal of E and the first
!>          super-diagonal of E.
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          > 0: if INFO = i, then D(i) is zero. The factorization has been
!>               completed, but the matrix is not needed since the
!>               diagonal entry and/or sub-diagonal entry is zero.
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>

LDA

  character uplo
  integer n, nrhs, ldb, info

      Description
     

     
zpftrs solves a system of linear equations A*X = B for a
       complex hermitian positive-definite matrix A in RFP format.

     
The matrix A is represented in RFP (Rectangular Full Packed)
       format. RFP format is a packed format that allows for the efficient storage
       of a triangular matrix, along with its conjugate-transpose, in a single
       one-dimensional array. This is particularly useful for certain LAPACK
       routines that operate on triangular matrices.

     
The function assumes that the Cholesky decomposition of A has
       already been computed and is stored in the array A. The Cholesky decomposition
       of a Hermitian positive-definite matrix A results in A = UHU or
       A = LLH, where U is upper triangular and L is lower triangular.

     
zpftrs then uses this decomposition to solve the system A*X =
       B by performing forward and backward substitutions.

     
The arguments to the routine specify:

     
    
      
  • 
       
    UPLO: A character string indicating whether the
         upper ('U') or lower ('L') triangle of the matrix A is stored in RFP
         format.
    
      
    • 
      
  • 
       
    N: The order of the matrix A (N x N).
    
      
    • 
      
  • 
       
    NRHS: The number of right-hand sides, i.e., the number
         of columns in matrix B.
    
      
    • 
      
  • 
       
    A: The array containing the Cholesky factor of A in
         RFP format.
    
      
    • 
      
  • 
       
    LDB: The leading dimension of the array B.
    
      
    • 
      
  • 
       
    B: On entry, the right-hand side matrix. On exit, the
         solution matrix X.
    
      
    • 
      
  • 
       
    INFO: An integer status code indicating success or
         an error.
    
      
    • 
     

     
The 'Further Details' section provides a detailed explanation
       of the RFP format, including examples for both even and odd matrix dimensions
       (N) and for both 'U' and 'L' storage options. This format is crucial for
       understanding how the triangular matrices are packed and how the conjugate
       transpose is handled.
