NOMBRE

pfbtopfa - Convierte fuentes .pfb de Postscript a formato .pfa usando ghostscript

SINOPSIS

pfbtopfa entrada.pfb [salida.pfa]

DESCRIPCIÓN

Este script invoca gs(1) para convertir un archivo .pfb a un archivo .pfa.

VER TAMBIÉN

gs(1)

VERSIÓN

Este documento fue revisado por última vez para la versión de Ghostscript 10.04.0.
