pfm_get_event_encoding(3)

Paquete: libpfm

Licencias: MIT

LIBPFM(3) Manual del programador de Linux LIBPFM(3)

NOMBRE

pfm_get_event_encoding - obtener la codificación de eventos sin procesar

SINOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_event_encoding(const char *str,int dfl_plm, char **fstr, int *idx, uint64_t *code, int *count);

DESCRIPCIÓN

Esta función se utiliza para recuperar la codificación de eventos sin procesar correspondiente a la cadena de eventos en str. Solo se puede codificar un evento por llamada. Como tal, str solo puede contener un nombre de evento simbólico. La cadena puede contener máscaras de unidad y modificadores. La máscara de nivel de privilegio predeterminada se pasa en dfl_plm. Puede utilizarse según el evento.

Esta función está obsoleta. Está superada por pfm_get_os_event_encoding(), donde el sistema operativo se establece en PFM_OS_NONE. La codificación se recupera a través de la estructura pfm_pmu_encode_arg_t.

Los siguientes ejemplos ilustran la transición:

   int i, count = 0;
   uint64_t *codes;
   ret = pfm_get_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, NULL, &codes, &count);
   if (ret != PFM_SUCCESS)
      err(1", no se puede obtener la codificación %s", pfm_strerror(ret));
   for(i=0; i < count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, codes[i]);

es equivalente a:

   pfm_pmu_encode_arg_t arg;
   int i;
   memset(&arg, 0, sizeof(arg));
   arg.size = sizeof(arg);
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_NONE, &arg);
   if (ret != PFM_SUCCESS)
      err(1", no se puede obtener la codificación %s", pfm_strerror(ret));
   for(i=0; i < arg.count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, arg.codes[i]);
   free(arg.codes);
La codificación puede ocupar varios enteros de 64 bits. La función puede utilizar la matriz pasada en code si el número
de entradas pasadas en count es lo suficientemente grande. Sin embargo, si tanto *codes es NULL como count
es 0, la función asigna la memoria necesaria para almacenar la codificación. Es responsabilidad del que llama
liberar la memoria eventualmente. El número de entradas de 64 bits en codes se refleja en *count al regresar,
independientemente de si codes fue asignado o utilizado tal cual. Si el número de enteros de 64 bits es
mayor que uno, entonces el orden en que se devuelve cada componente es específico del modelo de PMU. Consulte la
página del manual específica del PMU.
La codificación sin procesar significa la codificación según lo dictado por el modelo de PMU subyacente. Puede que no sea directamente adecuada
para pasar a una API del kernel. Es posible que desee utilizar llamadas a bibliotecas específicas de la API para garantizar que se pase la codificación correcta.
Si fstr no es NULL, apuntará a la cadena de eventos completamente calificada al regresar con éxito. La cadena
contiene el nombre del evento, cualquier máscara de unidad establecida y el valor de todos los modificadores. Refleja lo que la codificación realmente medirá.
La función asigna memoria para almacenar la cadena. El que llama debe liberar la cadena eventualmente.
Aquí hay un ejemplo de cómo se podría usar esta función:
#include <inttypes.h>
#include <err.h>
#include <perfmon/pfmlib.h>
int main(int argc, char **argv)
{
   uint64_t *codes 0;
   int count = 0;
   int ret;
   ret = pfm_initialize();
   if (ret != PFMLIB_SUCCESS)
      err(1", no se puede inicializar la biblioteca %s", pfm_strerror(ret));
   ret = pfm_get_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, NULL, &codes, &count);
   if (ret != PFM_SUCCESS)
      err(1", no se puede obtener la codificación %s", pfm_strerror(ret));
   for(i=0; i < count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, codes[i]);
   free(codes);
   return 0;
}

DEVOLVER

La función devuelve en *codes la codificación del evento y en *count el número de enteros de 64 bits para soportar esa codificación. Al regresar con éxito, se devuelve PFM_SUCCESS; de lo contrario, se devuelve un código de error específico.

ERRORES

PFM_ERR_TOOSMALL
El argumento code es demasiado pequeño para la codificación.
PFM_ERR_INVAL
El argumento code o count es NULL o str contiene más de un evento simbólico.
PFM_ERR_NOMEM
Memoria insuficiente.
PFM_ERR_NOTFOUND
Evento no encontrado.
PFM_ERR_ATTR
Atributo de evento no válido (máscara de unidad o modificador)
PFM_ERR_ATTR_VAL
Valor de modificador no válido.
PFM_ERR_ATTR_SET
El atributo ya está establecido, no se puede cambiar.
PFM_ERR_ATTR_UMASK
Falta máscara de unidad.
PFM_ERR_ATTR_FEATCOMB
Las máscaras de unidad o las características no se pueden combinar en un solo evento.
