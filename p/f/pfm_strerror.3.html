NOMBRE

pfm_strerror - devuelve una cadena constante que describe un código de error

SINOPSIS

#include <perfmon/pfmlib.h>

const char *pfm_strerror(int code);

DESCRIPCIÓN

Esta función devuelve una cadena que describe el valor de error code de libpfm. La cadena devuelta por la llamada es de solo lectura.

La función solo debe usarse con llamadas a libpfm documentadas para devolver códigos de error específicos. El valor -1 no se considera un código de error específico. Las cadenas y los valores de retorno de pfm_pmu_t no se pueden usar con esta función. Típicamente se devuelve NULL en caso de error para valores de cadena y PFM_PMU_NONE para valores pfm_pmu_t.

La función tampoco está diseñada para manejar errores de llamadas al sistema operativo, es decir, valores de `errno`.

RETORNAR

La función devuelve un puntero a la cadena constante que describe el código de error. La cadena está en inglés. Si el código no es válido, se devuelve un mensaje de error predeterminado.

ERRORES

Si el código de error no es válido, la función devuelve un puntero a una cadena que dice "unknown error code" (código de error desconocido).
