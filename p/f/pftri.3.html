CPFTRI

Propósito:

!>
!> CPFTRI calcula la inversa de una matriz compleja Hermítica definida positiva
!> A utilizando la factorización de Cholesky A = U**H*U o A = L*L**H
!> calculada por CPFTRF.
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se almacena la representación normal (TRANSR) de RFP A;
!>          = 'C':  Se almacena la representación conjugada transpuesta (TRANSR) de RFP A.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena el triángulo superior de A;
!>          = 'L':  Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, dimension ( N*(N+1)/2 );
!>          En la entrada, la matriz Hermítica A en formato RFP. El formato RFP
!>          se describe por TRANSR, UPLO y N como sigue: Si TRANSR = 'N'
!>          entonces RFP A es (0:N,0:k-1) cuando N es par; k=N/2. RFP A es
!>          (0:N-1,0:k) cuando N es impar; k=N/2. SI TRANSR = 'C' entonces RFP es
!>          la transpuesta conjugada de RFP A tal como se define cuando
!>          TRANSR = 'N'. Los contenidos de RFP A están definidos por UPLO como
!>          sigue: Si UPLO = 'U' la RFP A contiene los nt elementos de
!>          A empaquetada superior. Si UPLO = 'L' la RFP A contiene los elementos
!>          de A empaquetada inferior. El LDA de RFP A es (N+1)/2 cuando TRANSR =
!>          'C'. Cuando TRANSR es 'N' el LDA es N+1 cuando N es par y N
!>          es impar. Ver la Nota abajo para más detalles.
!>
!>          En la salida, la inversa Hermítica de la matriz original, en el
!>          mismo formato de almacenamiento.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0:  si INFO = i, el elemento (i,i) del factor U o L es
!>                cero, y la inversa no pudo ser calculada.
!>

NAME

dpftri, spftri, cpftri, zpftri - dpftri computes the inverse of a real or complex (Hermitian) positive definite matrix, using the previously computed Cholesky factorization.

SYNOPSIS

All subroutines have the same interface:

SUBROUTINE CPFTRI (TRANSR, UPLO, N, A, INFO)
    CHARACTER(LEN=1)          TRANSR, UPLO
    INTEGER                   N
    COMPLEX(KIND=8)           A( 0: * )
    INTEGER                   INFO
END SUBROUTINE CPFTRI

where:

TRANSR

   is CHARACTER*1
   On entry, TRANSR specifies the nature of the matrix A.
   = 'N':  The Normal TRANSR of RFP A is stored.
   = 'C':  The Conjugate-transpose TRANSR of RFP A is stored.
   = 'T':  The Transpose TRANSR of RFP A is stored.

UPLO

   is CHARACTER*1
   On entry, UPLO specifies whether the triangle stored is upper or lower:
   = 'U':  Upper triangle of A is stored.
   = 'L':  Lower triangle of A is stored.

N

   is INTEGER
   The order of the matrix A.  N >= 0.

A

   is DOUBLE PRECISION, REAL, COMPLEX*16, or COMPLEX array,
   dimension ( N*(N+1)/2 )
   On entry, the upper or lower triangle of the Hermitian or symmetric
   positive definite matrix A in RFP format.
   On exit, the upper or lower triangle of the inverse of A, in the same
   storage format.

INFO

   is INTEGER
   = 0:  successful exit
   < 0:  if INFO = -i, the i-th argument had an illegal value.  For
         example, if TRANSR = 'C' and UPLO = 'L', then the routine
         expects the matrix to be complex Hermitian, not symmetric.
   > 0:  if INFO = i, the (i,i) element of the factor U or L is zero, and
         the inverse could not be computed.

DESCRIPTION

The subroutines compute the inverse of a complex Hermitian or real symmetric positive definite matrix A.

The Cholesky factorization of A is computed by calling the appropriate routine from the routines described in dpctr f.

The inverse is then computed by solving one of the systems:

   inv(A) * U**T = I, if UPLO = 'U'
   inv(A) * L = I, if UPLO = 'L'

and then taking the transpose (conjugate transpose if complex Hermitian).

The matrix A is stored in Rectangular Full Packed (RFP) format.

The details of RFP format are given in Further Details.

We assume that A contains the Cholesky factorization computed by DPTRF, SPTRF, CPTRF, or ZPTRF.

The routines differ as follows:

DPFTRI
double precision matrix A
SPFTRI
single precision matrix A
CPFTRI
single precision complex matrix A
ZPFTRI
double precision complex matrix A

NAME

zpftri - ZPFTRI computes the inverse of a complex Hermitian positive definite matrix.

SYNOPSIS

subroutine zpftri(TRANSR, UPLO, N, A, INFO)

Parameters

TRANSR

TRANSR is CHARACTER*1

On entry, TRANSR specifies whether the matrix A is stored in transpose format or not. See below for details.

  TRANSR = 'N':  RFP A is in row-major format;
  TRANSR = 'C':  RFP A is in column-major format.
UPLO

UPLO is CHARACTER*1

On entry, UPLO specifies whether the matrix A is upper triangular or lower triangular:

  UPLO = 'U':  Upper triangle of A is stored and will be used.
  UPLO = 'L':  Lower triangle of A is stored and will be used.
N

N is INTEGER

The order of the matrix A. N >= 0.

A

A is COMPLEX*16 array, dimension ( N*(N+1)/2 );

On entry, the Hermitian matrix A in RFP format. RFP format is described by TRANSR, UPLO, and N as follows: If TRANSR = 'N' then RFP A is (0:N,0:k-1) when N is even; k=N/2. RFP A is (0:N-1,0:k) when N is odd; k=N/2. IF TRANSR = 'C' then RFP is the Conjugate-transpose of RFP A as defined when TRANSR = 'N'. The contents of RFP A are defined by UPLO as follows: If UPLO = 'U' the RFP A contains the nt elements of upper packed A. If UPLO = 'L' the RFP A contains the elements of lower packed A. The LDA of RFP A is (N+1)/2 when TRANSR = 'C'. When TRANSR is 'N' the LDA is N+1 when N is even and N is odd. See the Note below for more details.

On exit, the Hermitian inverse of the original matrix, in the same storage format.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, the (i,i) element of the factor U or L is zero, and the inverse could not be computed.

Detailed Description

This routine is part of the LAPACK routines that compute the inverse of a matrix. It is an auxiliary routine and is not intended for direct use by the user.

This routine computes the inverse of a Hermitian positive definite matrix A in Real Function Packet (RFP) format.

The matrix A is factored as:

  A = U * T, if UPLO = 'U'
  A = L * T, if UPLO = 'L'

where T is a tridiagonal matrix and U and L are upper and lower triangular matrices, respectively.

The inverse is then computed as:

  A**(-1) = T**(-1) * U**(-1), if UPLO = 'U'
  A**(-1) = T**(-1) * L**(-1), if UPLO = 'L'

The routine uses the fact that the inverse of a triangular matrix is also a triangular matrix, and the inverse of a tridiagonal matrix can be computed efficiently.

The RFP format is a storage format for Hermitian matrices that allows for efficient storage and computation. It is described in more detail in the LAPACK documentation.

The routine handles both 'N' (row-major) and 'C' (column-major) formats for the RFP storage.

The routine returns the inverse of the original matrix A in the same RFP format.

If the matrix is not positive definite, the routine may fail to compute the inverse and will return an error code.

Notes

!>  This is a preliminary version of ZPFTRI. It is based on the algorithms
!>  described in the following papers:
!>
!>  * O. Bershadsky, W. J. Li, and H. Zha, "A storage format for
!>    matrix computations,"
!>    *SIAM Journal on Matrix Analysis and Applications*, 18 (1997),
!>    pp. 820-835.
!>
!>  * W. J. Li, "The Real Function Packet (RFP) Format for Matrix
!>    Computations," LAPACK Working Note 120, UTK-CSI-97-05 (1997).
!>
!>  The Real Function Packet (RFP) format is described as follows:
!>
!>  Let A be an n x n Hermitian matrix. We store the upper or lower
!>  triangle of A in packed format. Let AP be the packed array.
!>  If UPLO = 'U', AP contains the elements of the upper triangle of A.
!>  If UPLO = 'L', AP contains the elements of the lower triangle of A.
!>
!>  The RFP format rearranges the elements of AP into a different
!>  two-dimensional array, denoted RFP A. The dimensions of RFP A
!>  depend on whether n is even or odd, and on the value of TRANSR.
!>
!>  Case 1: n is even. Let n = 2k.
!>    If TRANSR = 'N', RFP A has dimensions (n+1) x k.
!>      The elements of the upper triangle of A are stored in the
!>      first k columns of RFP A. Specifically, the j-th column
!>      (0-indexed) contains the elements A(i, j) for i = j, ..., n-1.
!>      The elements of the lower triangle of A are stored in the
!>      last k columns of RFP A, in conjugate-transposed form.
!>      Specifically, the (k+j)-th column contains the elements
!>      A(i, j) for i = 0, ..., j.
!>
!>    If TRANSR = 'C', RFP A is the conjugate transpose of the RFP A
!>      computed when TRANSR = 'N'.
!>
!>  Case 2: n is odd. Let n = 2k+1.
!>    If TRANSR = 'N', RFP A has dimensions n x (k+1).
!>      The elements of the upper triangle of A are stored in the
!>      first k+1 columns of RFP A. Specifically, the j-th column
!>      (0-indexed) contains the elements A(i, j) for i = j, ..., n-1.
!>      The elements of the lower triangle of A are stored in the
!>      last k columns of RFP A, in conjugate-transposed form.
!>      Specifically, the (k+1+j)-th column contains the elements
!>      A(i, j) for i = 0, ..., j.
!>
!>    If TRANSR = 'C', RFP A is the conjugate transpose of the RFP A
!>      computed when TRANSR = 'N'.
!>
!>  The function ZPFTRI assumes that the input matrix A is in RFP format
!>  and computes its inverse, also in RFP format.
!>
!>  For example, if N = 6 and UPLO = 'U', then k = 3.
