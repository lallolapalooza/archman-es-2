P11-KIT(8) Comandos del Sistema P11-KIT(8)

NOMBRE

p11-kit - Herramienta para operar sobre módulos PKCS#11 configurados

SINOPSIS

p11-kit list-modules

p11-kit list-tokens ...

p11-kit list-objects ...

p11-kit import-object ...

p11-kit export-object ...

p11-kit delete-object ...

p11-kit generate-keypair ...

p11-kit list-profiles ...

p11-kit add-profile ...

p11-kit delete-profile ...

p11-kit list-mechanisms ...

p11-kit print-config

p11-kit extract ...

p11-kit server ...

DESCRIPCIÓN

p11-kit es una herramienta de línea de comandos que se puede utilizar para realizar operaciones en módulos PKCS#11 configurados en el sistema.

Consulte los diversos subcomandos a continuación. Se pueden utilizar las siguientes opciones globales:

-v, --verbose

Ejecutar en modo detallado con salida de depuración.

-q, --quiet

Ejecutar en modo silencioso sin mensajes de advertencia o error.

LISTAR MÓDULOS

Lista los módulos PKCS#11 configurados en el sistema.

$ p11-kit list-modules

Se mostrarán los módulos, información sobre ellos y los tokens presentes en los módulos PKCS#11.

LISTAR TOKENS

Lista todos los tokens disponibles en los módulos PKCS#11 configurados en el sistema.

$ p11-kit list-tokens pkcs11:token

Esto recupera todos los tokens y muestra algunos de sus atributos comunes.

Este subcomando toma las siguientes opciones:

--only-uris

Imprimir solo las URIs de tokens coincidentes.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

LISTAR OBJETOS

Lista objetos que coinciden con la URI PKCS#11 dada.

$ p11-kit list-objects pkcs11:object_on_token

Esto recupera todos los objetos que coinciden con la URI PKCS#11 dada y muestra algunos de sus atributos comunes. Los objetos de almacenamiento también tienen su URI PKCS#11 mostrada.

Este subcomando toma las siguientes opciones:

--login

Autenticarse en el token antes de enumerar objetos. El valor del PIN se lee del atributo pin-value en la URI o desde la terminal.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

IMPORTAR OBJETO

Importar objeto a un token PKCS#11.

$ p11-kit import-object --file=archivo.pem [--label=etiqueta] [--id=id_objeto] pkcs11:token

Toma un certificado X.509 o una clave pública en formato de archivo PEM y lo importa al primer token que coincida con la URI PKCS#11 dada.

Las siguientes opciones son requeridas:

--file=<archivo.pem>

Archivo que contiene un certificado X.509 o una clave pública en formato PEM.

Este subcomando también acepta las siguientes opciones:

--label=<etiqueta>

Asigna una etiqueta al objeto importado.

--id=<id_objeto>

Asigna un ID al objeto importado. El ID debe especificarse en formato hexadecimal sin el prefijo '0x'.

--login

Autenticarse en el token antes de enumerar objetos. El valor del PIN se lee del atributo pin-value en la URI o desde la terminal.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

EXPORTAR OBJETO

Exportar objeto que coincide con la URI PKCS#11.

$ p11-kit export-object pkcs11:object_on_token

Muestra el contenido en formato PEM del primer objeto que coincide con la URI PKCS#11 dada. El objeto coincidente debe ser un certificado X.509 o una clave pública.

Este subcomando toma las siguientes opciones:

--login

Autenticarse en el token antes de enumerar objetos. El valor del PIN se lee del atributo pin-value en la URI o desde la terminal.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

ELIMINAR OBJETO

Elimina el objeto que coincide con la URI PKCS#11.

$ p11-kit delete-object pkcs11:object_on_token

Destruye el primer objeto que coincide con la URI PKCS#11 dada.

Este subcomando toma las siguientes opciones:

--login

Autenticarse en el token antes de enumerar objetos. El valor del PIN se lee del atributo pin-value en la URI o desde la terminal.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

GENERAR PAR DE CLAVES

Genera un par de claves en un token PKCS#11.

$ p11-kit generate-keypair --type=algoritmo {--bits=n|--curve=nombre} [--label=etiqueta] [--id=id_objeto] pkcs11:token

Genera un par de claves privada-pública del tipo especificado en el primer token que coincida con la URI PKCS#11 dada. Este comando debe usarse junto con la opción --type y una de las opciones --bits o --curve.

Las siguientes opciones son requeridas:

--type=<algoritmo>

Especifica el tipo de claves a generar. Los valores admitidos son rsa, ecdsa y eddsa.

--bits=<n>

Especifica el número de bits para la generación del par de claves. No se puede usar junto con la opción --curve.

--curve=<nombre>

Especifica una curva elíptica para la generación del par de claves. Los valores admitidos son secp256r1, secp384r1, secp521r1, ed25519 y eddsa. No se puede usar junto con la opción --bits.

Este subcomando también acepta las siguientes opciones:

--label=<etiqueta>

Asigna una etiqueta a los objetos del par de claves generado.

--id=<id_objeto>

Asigna un ID a los objetos del par de claves generado. El ID debe especificarse en formato hexadecimal sin el prefijo '0x'.

--login

Autenticarse en el token antes de enumerar objetos. El valor del PIN se lee del atributo pin-value en la URI o desde la terminal.

--provider=<ruta_módulo>

Cargar solo el módulo PKCS#11 dado en lugar de enumerar los módulos instalados en el sistema. Si ruta_módulo es una ruta relativa, el módulo se carga desde la ruta de módulo predeterminada. Esta ruta se puede determinar ejecutando: 
$ pkg-config p11-kit-1 --variable p11_module_path
/usr/lib64/pkcs11

LISTAR PERFILES

Lista los perfiles PKCS#11 configurados en el sistema.

$ p11-kit list-profiles

Se mostrará una lista de los perfiles PKCS#11 actualmente configurados en el sistema.

AGREGAR PERFIL

Agrega un nuevo perfil PKCS#11 al sistema.

$ p11-kit add-profile <ruta_archivo_perfil>

Toma un archivo de perfil PKCS#11 y lo agrega a la configuración del sistema. Esto permite que p11-kit reconozca y utilice el módulo definido en el perfil.

<ruta_archivo_perfil>

La ruta al archivo que contiene la definición del perfil PKCS#11.

ELIMINAR PERFIL

Elimina un perfil PKCS#11 existente del sistema.

$ p11-kit delete-profile <nombre_perfil>

Elimina el perfil PKCS#11 especificado de la configuración del sistema.

<nombre_perfil>

El nombre del perfil PKCS#11 a eliminar.

LISTAR MECANISMOS

Lista los mecanismos criptográficos admitidos por un token.

$ p11-kit list-mechanisms pkcs11:token

Este comando muestra los mecanismos criptográficos que están disponibles en el token especificado.

IMPRIMIR CONFIGURACIÓN

Imprime la configuración actual de PKCS#11.

$ p11-kit print-config

Muestra la configuración detallada de los módulos PKCS#11 que p11-kit está utilizando, incluyendo las rutas de los módulos y sus asociaciones.

EXTRAER

Extrae información de un módulo PKCS#11.

$ p11-kit extract --module=<ruta_módulo>

Extrae información sobre un módulo PKCS#11 específico. Esto puede ser útil para depurar o para obtener detalles sobre un módulo en particular.

--module=<ruta_módulo>

La ruta al archivo del módulo PKCS#11 del que se desea extraer información.

SERVIDOR

Inicia un servidor PKCS#11.

$ p11-kit server --socket=<ruta_socket>

Inicia un servidor que expone los módulos PKCS#11 configurados a través de un socket Unix. Esto permite que otras aplicaciones se conecten al servidor y utilicen las funcionalidades PKCS#11 de forma remota.

--socket=<ruta_socket>

La ruta al archivo de socket Unix donde se ejecutará el servidor.

EJEMPLOS

Listar todos los módulos PKCS#11 y sus tokens disponibles:

$ p11-kit list-modules

Listar todos los tokens y sus URIs:

$ p11-kit list-tokens --only-uris

Importar un certificado a un token:

$ p11-kit import-object --file=~/mycert.pem --label=mycert pkcs11:token&pin-value=1234

Exportar un certificado desde un token:

$ p11-kit export-object pkcs11:token;object=mycert;type=cert

Generar un par de claves RSA en un token:

$ p11-kit generate-keypair --type=rsa --bits=2048 --label=mykey pkcs11:token

Imprimir la configuración actual de PKCS#11:

$ p11-kit print-config

IMPRIMIR CONFIGURACIÓN

Imprime la configuración fusionada.

$ p11-kit print-config

P11-kit proporciona 3 niveles de configuración: del sistema, por módulo y por usuario. En tiempo de ejecución, los 3 niveles se fusionan en una sola configuración. Este comando muestra la configuración fusionada.

EXTRAER

Extrae certificados de módulos PKCS#11 configurados.

Esta operación se ha trasladado a un comando separado trust extract. Consulte

trust(1)
para más información.

SERVIDOR

Ejecuta un proceso servidor que expone el módulo PKCS#11 de forma remota.

$ p11-kit server pkcs11:token1 pkcs11:token2 ...
$ p11-kit server --provider /path/to/pkcs11-module.so pkcs11:token1 pkcs11:token2 ...

Esto inicia un servidor que expone los tokens PKCS#11 dados en un socket local. Los tokens deben pertenecer al mismo módulo. Para acceder al socket, utilice el módulo p11-kit-client.so. La dirección del servidor y el PID se imprimen como un fragmento de script de shell que establece la variable de entorno apropiada: P11_KIT_SERVER_ADDRESS y P11_KIT_SERVER_PID.

EXTRAER CONFIANZA

Extrae archivos de información de confianza estándar.

Esta operación se ha trasladado a un comando separado trust extract-compat. Consulte trust(1) para más información.

REMOTO

Ejecuta un módulo PKCS#11 de forma remota.

$ p11-kit remote /path/to/pkcs11-module.so
$ p11-kit remote pkcs11:token1 pkcs11:token2 ...

Esto no está diseñado para ejecutarse directamente desde una terminal, sino en una opción remote en un archivo de pkcs11.conf(5).

Esto expone el módulo PKCS#11 o los tokens dados a través de la entrada y salida estándar. Estas dos formas, si exponen un módulo o tokens, son mutuamente excluyentes y, si se utiliza la segunda forma, los tokens deben pertenecer al mismo módulo.
