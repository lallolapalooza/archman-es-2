p11tool(1)

p11tool(1) Comandos de usuario p11tool(1)

NOMBRE

p11tool - Herramienta PKCS #11 de GnuTLS

SINOPSIS

p11tool [-flags] [-flag [valor]] [--nombre-opcion[[=| ]valor]] [url]

Los operandos y las opciones pueden mezclarse. Serán reordenados.

DESCRIPCIÓN

Programa que permite operaciones en tarjetas inteligentes y módulos de seguridad PKCS #11.

Para usar tokens PKCS #11 con GnuTLS, los archivos de configuración de p11-kit deben estar configurados. Es decir, crear un archivo .module en /etc/pkcs11/modules con el contenido 'module: /ruta/a/pkcs11.so'. Alternativamente, el archivo de configuración /etc/gnutls/pkcs11.conf debe existir y contener un número de líneas del tipo 'load=/usr/lib/opensc-pkcs11.so'.

Puedes proporcionar el PIN que se utilizará para las operaciones PKCS #11 con las variables de entorno GNUTLS_PIN y GNUTLS_SO_PIN.

OPCIONES

Tokens

--list-tokens

Lista todos los tokens disponibles.
--list-token-urls

Lista las URLs de los tokens disponibles.

Esta es una versión más compacta de --list-tokens.

--list-mechanisms

Lista todos los mecanismos disponibles en un token.
--initialize

Inicializa un token PKCS #11.
--initialize-pin

Inicializa/restablece el PIN de usuario de un token PKCS #11.
--initialize-so-pin

Inicializa/restablece el PIN del oficial de seguridad de un token PKCS #11.

Esto inicializa el PIN del oficial de seguridad. Cuando se usa de forma no interactiva, utiliza las variables de entorno GNUTLS_NEW_SO_PIN para inicializar el PIN del SO.

--set-pin=cadena

Especifica el PIN a usar en las operaciones del token.

Alternativamente, se puede usar la variable de entorno GNUTLS_PIN.

--set-so-pin=cadena

Especifica el PIN del Oficial de Seguridad a usar en la inicialización del token.

Alternativamente, se puede usar la variable de entorno GNUTLS_SO_PIN.

Listado de objetos

--list-all

Lista todos los objetos disponibles en un token.

Se listarán todos los objetos disponibles en el token. Esto incluye objetos que pueden no ser accesibles con esta herramienta.

--list-all-certs

Lista todos los certificados disponibles en un token.

Esta opción también proporcionará más información sobre los certificados, por ejemplo, expandirá las extensiones adjuntas en un token de confianza (como p11-kit-trust).

--list-certs

Lista todos los certificados que tienen una clave privada asociada.

Esta opción solo mostrará certificados que tienen una clave privada asociada a ellos (comparten el mismo ID).

--list-all-privkeys

Lista todas las claves privadas disponibles en un token.

Lista todas las claves privadas en un token que coinciden con la URL especificada.

--list-privkeys

Este es un alias para la opción --list-all-privkeys.
--list-keys

Este es un alias para la opción --list-all-privkeys.
--list-all-trusted

Lista todos los certificados disponibles marcados como de confianza.
--export

Exporta el objeto especificado por la URL. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: export-stapled, export-chain, export-pubkey.
--export-stapled

Exporta el objeto certificado especificado por la URL. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: export, export-chain, export-pubkey.

Exporta el certificado especificado por la URL, incluyendo cualquier extensión adjunta al mismo. Dado que las extensiones adjuntas son una extensión de p11-kit, esta opción solo está disponible en módulos de confianza registrados en p11-kit.

--export-chain

Exporta el certificado especificado por la URL y su cadena de confianza. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: export-stapled, export, export-pubkey.

Exporta el certificado especificado por la URL y genera su cadena de confianza basándose en los certificados almacenados en el módulo.

--export-pubkey

Exporta la clave pública de una clave privada. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: export-stapled, export, export-chain.

Exporta la clave pública para la clave privada especificada.

--info

Lista información sobre un objeto disponible en un token.
--trusted

Este es un alias para la opción --mark-trusted.
--distrusted

Este es un alias para la opción --mark-distrusted.

Generación de claves

--generate-privkey=cadena

Genera un par de claves privada-pública del tipo especificado.

Genera un par de claves privada-pública en el token especificado. Los tipos aceptables son RSA, ECDSA, Ed25519 y DSA. Debe combinarse con --sec-param o --bits.

--generate-rsa

Genera un par de claves privada-pública RSA.

Genera un par de claves privada-pública RSA en el token especificado. Debe combinarse con --sec-param o --bits.

NOTA: ESTA OPCIÓN ESTÁ OBSOLETA

--generate-dsa

Genera un par de claves privada-pública DSA.

Genera un par de claves privada-pública DSA en el token especificado. Debe combinarse con --sec-param o --bits.

NOTA: ESTA OPCIÓN ESTÁ OBSOLETA

--generate-ecc

Genera un par de claves privada-pública ECDSA.

Genera un par de claves privada-pública ECDSA en el token especificado. Debe combinarse con --curve, --sec-param o --bits.

NOTA: ESTA OPCIÓN ESTÁ OBSOLETA

--bits=num

Especifica el número de bits para la clave generada. Esta opción toma un número entero como argumento.

Para aplicaciones que no tienen restricciones de tamaño de clave, se recomienda la opción --sec-param, ya que los niveles de seguridad se adaptarán a los niveles de seguridad aceptables con las nuevas versiones de gnutls.

--curve=cadena

Especifica la curva utilizada para la generación de claves EC.

Los valores soportados son secp192r1, secp224r1, secp256r1, secp384r1 y secp521r1.

--sec-param=parámetro de seguridad

Especifica el nivel de seguridad.

NOMBRE

p11tool - Herramienta de línea de comandos para PKCS#11

SINOPSIS

p11tool [OPCIÓN]...

DESCRIPCIÓN

p11tool es una herramienta de línea de comandos para interactuar con módulos PKCS#11. Permite realizar diversas operaciones en dispositivos criptográficos compatibles con PKCS#11, como listar tokens, ver objetos, almacenar y recuperar claves y certificados, y generar pares de claves.

OPCIONES

-d, --list-tokens

Lista todos los tokens disponibles en el sistema.
-L, --list-all TOKEN

Lista todos los objetos (claves, certificados, etc.) en el token especificado. TOKEN debe ser una URL de tipo PKCS#11.
-l, --login

Inicia sesión en el token. Normalmente se usa junto con otras opciones.
-w, --write TOKEN

Escribe objetos en el token especificado. Requiere opciones adicionales para especificar los objetos a escribir (por ejemplo, --load-privkey, --load-certificate).
--load-privkey ARCHIVO

Carga una clave privada desde ARCHIVO para escribirla en un token.
--load-certificate ARCHIVO

Carga un certificado desde ARCHIVO para escribirlo en un token.
--label ETIQUETA

Asigna una etiqueta a un objeto que se está escribiendo o generando en un token.
--generate-privkey TIPO

Genera una clave privada de tipo TIPO (por ejemplo, rsa, ec) en el token.
--bits NÚMERO

Especifica el número de bits para la generación de claves RSA.
--outfile ARCHIVO

Guarda la clave pública correspondiente a una clave privada generada en el token en ARCHIVO.
-v, --verbose

Aumenta el nivel de verbosidad. Útil para depuración. Una
v simple. El modo
c imprimirá información de derechos de autor y
n imprimirá el aviso de derechos de autor completo.
-h, --help

Muestra información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a un paginador.

EJEMPLOS

Para ver todos los tokens en su sistema, use:


$ p11tool --list-tokens

Para ver todos los objetos en un token, use:


$ p11tool --login --list-all "pkcs11:TOKEN-URL"

Para almacenar una clave privada y un certificado en un token, ejecute:


$ p11tool --login --write "pkcs11:URL" --load-privkey key.pem --label "Mykey"
        $ p11tool --login --write "pkcs11:URL" --load-certificate cert.pem --label "Mykey"

Tenga en cuenta que algunos tokens requieren que se utilice la misma etiqueta para el certificado y su clave privada correspondiente.

Para generar una clave privada RSA dentro del token, use:


$ p11tool --login --generate-privkey rsa --bits 1024 --label "MyNewKey" --outfile MyNewKey.pub "pkcs11:TOKEN-URL"
El parámetro
bits en el ejemplo anterior se establece explícitamente porque algunos tokens solo admiten opciones limitadas en la longitud de bits. El archivo de salida es la clave pública correspondiente. Esta clave se puede usar para generar una solicitud de certificado con
certtool. 

certtool --generate-request --load-privkey "pkcs11:KEY-URL" --load-pubkey MyNewKey.pub --outfile request.pem

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

La operación falló o la sintaxis del comando no fue válida.
