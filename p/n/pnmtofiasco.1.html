NOMBRE

pnmtofiasco - Convertir archivo PNM a archivo comprimido FIASCO

SINOPSIS

pnmtofiasco [opción]... [nombre_archivo]...

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pnmtofiasco comprime los archivos de imagen pbm, pgm o ppm nombrados, o la entrada estándar si no se nombra ningún archivo, y produce un archivo FIASCO en la salida estándar.

OPCIONES

Todos los nombres de opción pueden abreviarse; por ejemplo, --optimize puede escribirse como --optim o --opt. Para la mayoría de las opciones, se proporciona una opción corta de una sola letra. Los argumentos obligatorios u opcionales para las opciones largas son obligatorios u opcionales también para las opciones cortas. Tanto las opciones cortas como las largas distinguen entre mayúsculas y minúsculas.

Las opciones básicas son:

-i nombre, --input-name=nombre
Comprimir las imágenes nombradas, no la entrada estándar. Si nombre es -, leer la entrada estándar. nombre debe ser un nombre de archivo de imagen o una plantilla de la forma: 
prefijo[inicio-fin{+,-}paso]sufijo

Las plantillas son útiles al comprimir flujos de vídeo: por ejemplo, si especifica la plantilla img0[12-01-2].pgm, entonces pnmtofiasco comprime las imágenes img012.pgm, img010.pgm, ..., img002.pgm.

Si nombre es una ruta relativa, pnmtofiasco busca los archivos de imagen en el directorio actual y en la lista (separada por dos puntos) de directorios dada por la variable de entorno FIASCO_IMAGES.

-o archivo-salida, --output-name=nombre
Escribir la salida FIASCO en el archivo nombrado, no en la salida estándar.

Si nombre es una ruta relativa y la variable de entorno FIASCO_DATA es una lista (separada por dos puntos) de directorios, entonces pnmtofiasco escribe el archivo de salida en el primer directorio (escribible) de esta lista. De lo contrario, pnmtofiasco lo escribe en el directorio actual.

-q N, --quality=N
Establecer la calidad de la compresión a N. La calidad es de 1 (peor) a 100 (mejor); el valor predeterminado es 20.
-v, --version
Imprimir la versión de pnmtofiasco, luego salir.
-V N, --verbose N
Establecer el nivel de verbosidad a N. El nivel es 0 (sin salida en absoluto), 1 (mostrar medidor de progreso) o 2 (mostrar estadísticas detalladas de compresión); el valor predeterminado es 1.
-B N, --progress-meter N
Establecer el tipo de medidor de progreso a N. Los siguientes tipos están disponibles; el valor predeterminado es 1:
0
sin medidor de progreso
1
barra de progreso estilo RPM con 50 marcas de hash
2
medidor de porcentaje
-f nombre, --config=nombre
Cargar el archivo de parámetros nombre para inicializar las opciones de pnmtofiasco. Consulte el archivo system.fiascorc para ver un ejemplo de la sintaxis. Las opciones de pnmtofiasco se establecen mediante cualquiera de los siguientes métodos (en el orden especificado):
  • Archivo de recursos global /etc/system.fiascorc
  • $HOME/.fiascorc
  • línea de comandos
  • --config=nombre
-h, --info
Imprimir ayuda breve, luego salir.
-H, --help
Imprimir ayuda detallada, luego salir.

Las opciones para usuarios avanzados son:

-b nombre, --basis-name=nombre
Pre-cargar la base de compresión nombre en FIASCO. La base nombre proporciona el diccionario de compresión inicial. Utilice uno de los archivos 'small.fco', 'medium.fco' o 'large.fco' que vienen con pnmtofiasco o cree un nuevo archivo de base ASCII.
-z N, --optimize=N
Establecer el nivel de optimización a N. El nivel es de 0 (más rápido) a 3 (más lento); el valor predeterminado es 1. Tenga en cuenta que el tiempo de codificación aumenta drásticamente cuando N=2 o N=3, mientras que el rendimiento de la compresión solo mejora ligeramente.
-P, --prediction
Utilizar codificación predictiva adicional. Si esta optimización está activada, la imagen se comprime en dos pasos. En el primer paso, se calcula una aproximación aproximada de la imagen utilizando grandes bloques unícromos. Finalmente, se calcula la imagen delta y el error de predicción se aproxima utilizando el algoritmo FIASCO estándar.
-D N, --dictionary-size=N
Establecer el tamaño del diccionario que se utiliza al codificar la banda de luminancia a N; el valor predeterminado es 10000, es decir, el diccionario no está restringido.
-C N, --chroma-dictionary=N
Establecer el tamaño del diccionario que se utiliza al codificar las bandas de croma a N; el valor predeterminado es 40.
-Q N, --chroma-qfactor=N
Reducir la calidad de la compresión de la banda de croma N veces con respecto a la calidad definida por el usuario q de la compresión de la banda de luminancia (--quality=q); el valor predeterminado es 2.
-t N, --tiling-exponent=N
Subdividir la imagen en 2^N mosaicos antes de codificar; el valor predeterminado es 4, es decir, la imagen se subdivide en 16 mosaicos. El orden de procesamiento de los mosaicos individuales se define mediante la opción --tiling-method=nombre.
-T nombre, --tiling-method=nombre
Ordenar los mosaicos individuales de la imagen (en los que se subdivide la imagen; consulte la opción --tiling-exponent=N) por el método nombre; el valor predeterminado es desc-variance.
desc-variance
Los mosaicos con varianzas pequeñas se procesan primero.
asc-variance
Los mosaicos con varianzas grandes se procesan primero.
desc-spiral
Los mosaicos se procesan en orden espiral comenzando en el centro.
asc-spiral
Los mosaicos se procesan en orden espiral comenzando en el borde.
--rpf-mantissa=N
Utilizar N bits de mantisa para los coeficientes cuantificados.
--dc-rpf-mantissa=N
Utilizar N bits de mantisa para los coeficientes DC cuantificados.
--rpf-range=N
Los coeficientes fuera del intervalo de cuantificación [-N,+N] se establecen en cero.
--dc-rpf-range=N
Los coeficientes DC fuera del intervalo de cuantificación [-N,+N] se establecen en cero.

Opciones adicionales para la compresión de vídeo son

-s N, --smooth=N
Suavizar los fotogramas de referencia descomprimidos a lo largo de los bordes de partición en la cantidad dada N. N va de 0 (sin suavizado) a 100; el valor predeterminado es 70. Este factor se almacena en el archivo FIASCO.
-m N, --min-level=N
Iniciar la predicción (predicción compensada por movimiento o predicción adicional) en el nivel de bloque N; el valor predeterminado es el nivel 6. Es decir, la compensación de movimiento se aplica a todos los bloques de imagen de al menos 8x8 píxeles (nivel del árbol binario N=6), 16x8 (N=7), 16x16 (N=8), etc.
-M N, --max-level=N
Detener la predicción

OPTIONS

motion-compensated prediction or additional prediction
on block level N; default is level 10. I.e., motion compensation is applied to all image blocks of at most 16x16 pixels (N=8), 32x16 (N=9), 32x32 (N=10), etc.
-2, --half-pixel
Use half pixel precise motion compensation.
-F N, --fps=N
Set number of frames per second to N. This value is stored in the FIASCO output file and is used in the decoder fiascotopnm(1)
to control the framerate.
-p type, --pattern=type
Defines the type of inter frame compression which should be applied to individual frames of a video stream. type is a sequence of characters; default is 'IPPPPPPPPP'. Element N defines the type of predicting which should be used for frame N; the frame type pattern is periodically extended. Valid characters are:
I
intra frame, i.e., no motion compensated prediction is used at all.
P
predicted frame, i.e., a previously encoded frame is used for prediction (forward prediction).
B
bidirectional predicted frame, i.e., not only a previously shown frame but also a frame of the future is used for prediction (forward, backward or interpolated prediction).
--cross-B-search
Instead of using exhaustive search the 'Cross-B-Search' algorithm is used to find the best interpolated prediction of B-frames.
--B-as-past-ref
Also use previously encoded B-frames when prediction the current frame. If this option is not set, only I- and P-frames are used to predict the current frame.

EXAMPLES

Compress the still image 'foo.ppm' to the FIASCO file 'foo.wfa' using the default options:

        pnmtofiasco < foo.ppm >foo.wfa

Compress the video frames 'foo0*.ppm' to the FIASCO file 'video.wfa' using half pixel precise motion compensation at a frame rate of 15 frames per second. Intra frame 1 is used to predict P-frame 4, frames 1 and 4 are used to predict B-frames 2 and 3, and so on. Frame 10 is again an intra-frame.

        pnmtofiasco -2 -p 'IBBPBBPBB' -fps 15 -o video.wfa foo0*.ppm

FILES

/etc/system.fiascorc
The systemwide initialization file.
$HOME/.fiascorc
The personal initialization file.

ENVIRONMENT

FIASCO_IMAGES
Search path for image files. Default is './'.
FIASCO_DATA
Search and save path for FIASCO files. Default is './'.
