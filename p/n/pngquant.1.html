NOMBRE

pngquant — Convertidor y compresor de imágenes con pérdida para PNG

SINOPSIS

pngquant ⟨opciones⟩ [colores] archivo [archivo ...]

pngquant ⟨opciones⟩ [colores] - <archivo >archivo

DESCRIPCIÓN

pngquant convierte PNGs RGBA de 32 bits a PNGs RGBA de 8 bits (o menos) con paleta, utilizando opcionalmente el tramado de Floyd-Steinberg. El nombre del archivo de salida es el mismo que el de entrada, excepto que termina en ‘-fs8.png’ o ‘-or8.png’ (a menos que la entrada sea stdin, en cuyo caso la imagen cuantificada irá a stdout). El comportamiento por defecto si el archivo de salida existe es omitir la conversión; use --force para sobrescribir.

OPCIONES

-o salida.png, --output salida.png
Escribe el archivo convertido en la ruta dada. Cuando se usa esta opción, solo se permite un archivo de entrada.
--ext nuevo.png
Extensión de archivo (sufijo) a usar para los archivos de salida en lugar del predeterminado ‘-fs8.png’ o ‘-or8.png’.
-f, --force
Sobrescribe los archivos de salida existentes. “--ext .png --force” puede usarse para convertir archivos en el lugar (lo cual es inseguro).
--nofs, --ordered
Deshabilita el tramado de Floyd-Steinberg.
--floyd [=N]
Establece el nivel de tramado usando un número fraccional entre 0 (ninguno) y 1 (completo, el predeterminado).
-s N, --speed N
1 (fuerza bruta) hasta 11 (el más rápido). El predeterminado es 3. La velocidad 10 tiene un 5% menos de calidad, pero es aproximadamente 8 veces más rápida que la predeterminada. La velocidad 11 deshabilita el tramado y reduce el nivel de compresión.
-Q min-max, --quality min-max
min y max son números en el rango 0 (peor) a 100 (perfecto), similar a JPEG. pngquant usará la menor cantidad de colores requerida para cumplir o exceder la calidad max. Si la conversión resulta en una calidad por debajo de la calidad min, la imagen no se guardará (o si se genera en stdin, se generará el original de 24 bits) y pngquant saldrá con el código de estado 99.
--skip-if-larger
Si la conversión resulta en un archivo más grande que el original, la imagen no se guardará y pngquant saldrá con el código de estado 98. Adicionalmente, la ganancia en tamaño de archivo debe ser mayor que la cantidad de calidad perdida. Si la calidad cae un 50%, esperará una reducción del tamaño de archivo del 50% para considerarlo rentable.
--posterize bits
Trunca el número de bits menos significativos de color (por canal). Úselo cuando la imagen se genere en pantallas de baja profundidad (por ejemplo, RGB de 16 bits). pngquant hará que los píxeles casi opacos sean completamente opacos y reducirá la cantidad de colores semitransparentes. Cuando se habilita esta opción, el sufijo de nombre de archivo predeterminado es ‘-ie-fs8.png’ / ‘-ie-or8.png’.
--strip
Elimina fragmentos opcionales (metadatos) de los archivos PNG.
--transbug
Solución alternativa para lectores que esperan que el color completamente transparente sea la última entrada en la paleta.
-v, --verbose
Habilita mensajes detallados que muestran el progreso e información sobre la entrada/salida. Lo opuesto es --quiet. Los errores se generan en stderr independientemente de esta opción.
-V, --version
Muestra la versión en stdout y sale.
-h, --help
Muestra la ayuda y sale.

EJEMPLO

Creando una nueva imagen con el número de colores reducido a 64:

pngquant 64 imagen.png

La imagen resultante tendrá 64 colores y se guardará como imagen-fs8.png.

Sobrescribiendo la imagen en el lugar si se puede reducir sin demasiada pérdida de calidad:

pngquant -f --ext .png --quality 70-95 imagen.png

AUTOR
