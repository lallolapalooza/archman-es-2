NOMBRE

pnetcdf_version - imprime la información de la versión de la biblioteca PnetCDF

SINOPSIS

pnetcdf_version [-v] [-d] [-c] [-b] [-h]

DESCRIPCIÓN

pnetcdf_version imprime la información de la versión de la biblioteca PnetCDF y la línea de comandos de configuración utilizada para construir la biblioteca.

Si no se proporciona ningún argumento, se imprime toda la información.

OPCIONES

-v
Número de versión de esta versión de PnetCDF.
-d
Fecha de lanzamiento.
-c
Argumentos de la línea de comandos de configuración utilizados para construir esta PnetCDF.
-b
Compiladores MPI utilizados para construir esta biblioteca PnetCDF.
-h
Imprime las opciones de línea de comandos disponibles de pnetcdf_version.

EJEMPLOS

Imprime toda la información sobre la biblioteca PnetCDF ejecutando el comando sin opciones.

% pnetcdf_version

PnetCDF Version:    	1.14.1
PnetCDF Release date:	July 31, 2025
PnetCDF configure: 	--with-mpi=/usr/local/bin
MPICC:  /usr/local/bin/mpicc -g -O2
MPICXX: /usr/local/bin/mpicxx -g -O2
MPIF77: /usr/local/bin/mpif77 -g -O2
MPIF90: /usr/local/bin/mpif90 -g -O2
