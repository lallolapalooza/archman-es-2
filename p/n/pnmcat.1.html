NOMBRE

pnmcat - concatenar imágenes Netpbm

SINOPSIS

pnmcat

{-leftright | -lr | -topbottom | -tb}

[-white|-black]

[-jtop|-jbottom|-jcenter] [-jleft|-jright|-jcenter]

pnmfile ...

Se puede usar la abreviatura única mínima de la opción. Puede usar guiones dobles en lugar de guiones simples para indicar las opciones. Puede usar espacios en blanco en lugar del signo igual para separar el nombre de una opción de su valor.

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pnmcat lee una o más imágenes PNM como entrada, las concatena de izquierda a derecha o de arriba a abajo, y produce una única imagen PNM como salida.

Los argumentos son los nombres de los archivos de entrada. Cualquiera de ellos, pero no más de uno, puede ser '-' para indicar la Entrada Estándar. Si no tiene argumentos, significa una sola imagen de entrada desde la Entrada Estándar (y eso es inútil, la salida es la misma que la entrada).

Para ensamblar una cuadrícula regular de imágenes, puede usar pamundice.

Para hacer lo contrario, podría usar pamdice para dividir una imagen en otras más pequeñas de tamaño igual o pamcut para recortar parte de una imagen o extraer parte de una imagen.

pnmtile concatena una sola imagen de entrada a sí misma repetidamente.

OPCIONES

Si las imágenes PNM no tienen todas la misma altura (izquierda-derecha) o ancho (arriba-abajo), las más pequeñas deben justificarse con la más grande. Por defecto, pnmcat las centra, pero puede especificar la justificación a un lado u otro con una de las opciones -jxxx. Por lo tanto, -topbottom -jleft apilaría las PNM una encima de la otra, alineadas al borde izquierdo. -leftright -jbottom alinearía las imágenes de izquierda a derecha con sus bordes inferiores alineados como si estuvieran sentadas en una mesa.

Las opciones -white y -black especifican qué color usar para rellenar el espacio adicional al hacer esta justificación. Si no se especifica ninguna, pnmcat elige la que parezca adecuada para las imágenes.
