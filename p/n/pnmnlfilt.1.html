NOMBRE

pnmnlfilt - filtros no lineales: suavizado, media recortada alfa, suavizado por estimación óptima, realce de bordes.

SINOPSIS

pnmnlfilt alfa radio [archivo pnm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pnmnlfilt produce una imagen de salida donde los píxeles son un resumen de múltiples píxeles cercanos a la ubicación correspondiente en una imagen de entrada.

Este programa funciona con flujos de imágenes múltiples.

Es algo así como un filtro de navaja suiza. Tiene 3 modos de operación distintos. En todos los modos, pnmnlfilt examina cada píxel de la imagen y lo procesa de acuerdo con los valores de este y los píxeles circundantes. En lugar de usar un bloque cuadrado de píxeles circundantes (por ejemplo, el píxel sujeto y sus 8 vecinos inmediatos, en un cuadrado de 3x3), pnmnlfilt utiliza 7 áreas hexagonales. Usted elige el tamaño de los hexágonos con el parámetro de radio. Un valor de radio de 1/3 significa que los 7 hexágonos básicamente caben en el píxel sujeto (es decir, no habrá efecto de filtrado). Un valor de radio de 1.0 significa que los 7 hexágonos cubren básicamente el cuadrado de vecinos inmediatos de 3x3.

Su elección del parámetro 'alfa' selecciona entre los tres modos.

Filtro de media recortada alfa (0.0 <= alfa <= 0.5)

El valor del píxel central se reemplazará por la media de los 7 valores hexagonales, pero los 7 valores se ordenan por tamaño y la porción superior e inferior alfa de los 7 se excluye de la media. Esto implica que un valor alfa de 0.0 da el mismo tipo de salida que una convolución normal (es decir, un filtro de promediado o suavizado), donde el radio determinará la 'fuerza' del filtro. Un buen valor para empezar para un filtrado sutil es alfa = 0.0, radio = 0.55. Para un efecto más notorio, pruebe alfa 0.0 y radio 1.0.

Un valor alfa de 0.5 provocará que el valor mediano de los 7 hexágonos se utilice para reemplazar el valor del píxel central. Este tipo de filtro es bueno para eliminar el ruido 'pop' o de un solo píxel de una imagen sin extender el ruido o difuminar las características de la imagen. El uso juicioso del parámetro de radio ajustará el filtrado. Los valores intermedios de alfa dan efectos entre el suavizado y la reducción de ruido 'pop'. Para un filtrado sutil, intente empezar con valores de alfa = 0.4, radio = 0.6. Para un efecto más notorio, intente alfa = 0.5, radio = 1.0.

Suavizado por estimación óptima. (1.0 <= alfa <= 2.0)

Este tipo de filtro aplica un filtro de suavizado de forma adaptativa sobre la imagen. Para cada píxel, se calcula la varianza de los valores hexagonales circundantes y la cantidad de suavizado se hace inversamente proporcional a ella. La idea es que si la varianza es pequeña, es debido al ruido en la imagen, mientras que si la varianza es grande, se debe a características 'deseadas' de la imagen. Como de costumbre, el parámetro de radio controla el radio efectivo, pero probablemente sea aconsejable dejar el radio entre 0.8 y 1.0 para que el cálculo de la varianza sea significativo. El parámetro alfa establece el umbral de ruido, por encima del cual se hará menos suavizado. Esto significa que los valores pequeños de alfa darán el efecto de filtrado más sutil, mientras que los valores grandes tenderán a suavizar todas las partes de la imagen. Podría empezar con valores como alfa = 1.2, radio = 1.0 y probar a aumentar o disminuir el parámetro alfa para obtener el efecto deseado. Este tipo de filtro es el mejor para filtrar el ruido de tramado en imágenes tanto de mapa de bits como en color.

Realce de bordes. (-0.1 >= alfa >= -0.9)

Este es el tipo de filtro opuesto al filtro de suavizado. Realza los bordes. El parámetro alfa controla la cantidad de realce de bordes, desde sutil (-0.1) hasta notorio (-0.9). El parámetro de radio controla el radio efectivo como de costumbre, pero los valores útiles están entre 0.5 y 0.9. Intente empezar con valores de alfa = 0.3, radio = 0.8.

Uso combinado.

Los diversos modos de pnmnlfilt se pueden usar uno tras otro para obtener el resultado deseado. Por ejemplo, para convertir una imagen tramada monocromática en una imagen en escala de grises, podría probar una o dos pasadas del filtro de suavizado, seguidas de una pasada del filtro de estimación óptima, y luego algún realce sutil de bordes. Tenga en cuenta que el uso del realce de bordes solo es probable que sea útil después de uno de los filtros no lineales (media recortada alfa o filtro de estimación óptima), ya que el realce de bordes es lo opuesto directo al suavizado.

Para reducir el ruido de cuantificación de color en las imágenes (es decir, convertir archivos .gif de nuevo en archivos de 24 bits), podría probar una pasada del filtro de estimación óptima (alfa 1.2, radio 1.0), una pasada del filtro de mediana (alfa 0.5, radio 0.55) y posiblemente una pasada del filtro de realce de bordes. Varias pasadas del filtro de estimación óptima con valores de alfa decrecientes son más efectivas que una sola pasada con un valor alfa grande. Como de costumbre, existe una compensación entre la efectividad del filtrado y la pérdida de detalle. Se fomenta la experimentación.

Referencias:

El filtro de media recortada alfa se basa en la descripción en IEEE CG&A Mayo de 1990 Página 23 de Mark E. Lee y Richard A. Redner, y ha sido mejorado para permitir el ajuste continuo de alfa.

El filtro de estimación óptima se toma de un artículo 'Converting Dithered Images Back to Gray Scale' de Allen Stenger, Dr Dobb's Journal, Noviembre de 1992, y este artículo hace referencia a 'Digital Image Enhancement and Noise Filtering by Use of Local Statistics', Jong-Sen Lee, IEEE Transactions on Pattern Analysis and Machine Intelligence, Marzo de 1980.

Los detalles del realce de bordes provienen de pgmenhance(1) , que se toma del programa 'xim' de Philip R. Thompson, que a su vez lo tomó de la sección 6 de 'Digital Halftones by Dot Diffusion', D. E. Knuth, ACM Transaction on Graphics Vol. 6, No. 4, Octubre de 1987, que a su vez lo obtuvo de dos artículos de 1976 de J. F. Jarvis et. al.

Los parámetros son:

alfa
El valor alfa (descrito anteriormente), en decimal. Puede ser fraccionario.
radio
El radio (descrito anteriormente), en decimal. Puede ser fraccionario.

NAME

pnmnlfilt — Filters a Pnm to remove noise.

SYNOPSIS

pnmnlfilt [ -b black ] [ -w white ] [ -m max ] [ pnmfile

DESCRIPTION

This program is part of the Netpbm documentation.

Removes noise from a Pnm image. This is done by iterating through the pixels and removing those that are obviously noise. The algorithm is as follows: For each pixel, compare it to its neighbors. If it is darker than both neighbors and the difference between it and its neighbors is greater than black, then it is noise. If it is brighter than both neighbors and the difference between it and its neighbors is greater than white, then it is noise. If it is noise, then the pixel is changed to the average of its neighbors.

The maximum value for a pixel is determined by the image’s maxval.

OPTIONS

-b black
This option specifies the black threshold. If a pixel is darker than both its neighbors and the difference is greater than this threshold, then it is noise. Default: 0.

-w white
This option specifies the white threshold. If a pixel is brighter than both its neighbors and the difference is greater than this threshold, then it is noise. Default: 0.

-m max
This option specifies the maximum value for a pixel. If this is not specified, the program will determine it from the image’s maxval.

EXAMPLES

Remove noise from the image “image.pnm” using the default thresholds: 

pnmnlfilt image.pnm

Remove noise using a black threshold of 10 and a white threshold of 10: 

pnmnlfilt -b 10 -w 10 image.pnm
