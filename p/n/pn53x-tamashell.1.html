NOMBRE

pn53x-tamashell - Shell de demostración de comunicación TAMA de PN53x

SINOPSIS

pn53x-tamashell [script]

DESCRIPCIÓN

pn53x-tamashell es una herramienta interactiva simple para enviar los llamados comandos TAMA y recibir las respuestas. TAMA se refiere al conjunto de comandos compatible con la familia PN53x. Los mensajes son binarios y la shell espera notación hexadecimal. Los prefijos de comandos y respuestas TAMA (0xD4/0xD5), CRC y cualquier encapsulación superior se manejan de forma transparente.

Puedes usar la shell interactivamente (con soporte readline) o puedes escribir tu propio archivo de script que consista en comandos y comentarios (todo lo que empiece con ";", "#" o "//"). Los espacios se ignoran y se pueden usar para mejorar la legibilidad.

El Shebang es compatible, simplemente empieza tu script con:
#!/usr/bin/env pn53x-tamashell

COMANDOS

p N para introducir una pausa de N milisegundos.

q o Ctrl-d para salir.

EJEMPLOS

El comando GetFirmware es D4 02, así que solo tienes que enviar el comando "02":


$ pn53x-tamashell
Conectado al lector NFC: SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> 02
Tx: 02
Rx: 33 02 07 07
> 40
Tx: 40
Rx: Comando No Aceptable
> q
¡Adiós!

Lo mismo, con un script:


$ pn53x-tamashell << EOF
// Esto es un comentario
02 // GetFirmware
40 // Comando con argumentos faltantes
EOF


Conectado al lector NFC: SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> // Esto es un comentario
> 02 // GetFirmware
Tx: 02
Rx: 33 02 07 07
> 40 // Comando con argumentos faltantes
Tx: 40
Rx: Comando No Aceptable
> ¡Adiós!
