NOMBRE

pnmtile - replica una imagen para llenar una región especificada

SINOPSIS

pnmtile ancho alto [archivo pnm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pnmtile lee una imagen PNM como entrada. La replica para llenar un área de las dimensiones especificadas y produce una imagen en el mismo formato como salida.

Puedes hacer prácticamente lo inverso con pamdice.

Puedes concatenar explícitamente una imagen consigo misma (o con cualquier otra cosa) con pnmcat.

Si estás intentando mosaquear múltiples imágenes en una súper-imagen, consulta pamundice o (para una hoja de miniaturas) pnmindex.
