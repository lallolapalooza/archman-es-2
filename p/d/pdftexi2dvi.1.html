TEXI2DVI(1) Comandos de usuario TEXI2DVI(1)

NOMBRE

texi2dvi - convierte documentos Texinfo a DVI o PDF

SINOPSIS

texi2dvi [OPCIÓN]... FICHERO...
texi2pdf [OPCIÓN]... FICHERO...
pdftexi2dvi [OPCIÓN]... FICHERO...

DESCRIPCIÓN

Ejecuta cada FICHERO de Texinfo o (La)TeX en secuencia hasta que todas las referencias cruzadas se resuelvan, construyendo todos los índices. El directorio que contiene cada FICHERO se busca para incluir archivos. El sufijo de FICHERO se usa para determinar su idioma ((La)TeX o Texinfo). Para procesar archivos (e)plain TeX, establezca la variable de entorno LATEX=tex.

Cuando se invoca como `texi2pdf' o se le da la opción --pdf, genera salida PDF. De lo contrario, genera DVI.

Opciones generales:

-D, --debug
activa la depuración del shell (establece -x)
-h, --help
muestra esta ayuda y sale con éxito
-o, --output=FICHERO SALIDA
deja la salida en FICHERO SALIDA; solo se permite un FICHERO de entrada
-q, --quiet
sin salida a menos que haya errores
-v, --version
muestra la información de la versión y sale con éxito
-V, --verbose
informa sobre lo que se está haciendo
--max-iterations=N
no procesar archivos más de N veces [7]
--mostly-clean
elimina archivos o directorios auxiliares de ejecuciones anteriores (pero no la salida)

Formato de salida:

--dvi
genera un archivo DVI [predeterminado]
--dvipdf
genera un archivo PDF a través de DVI (usando un programa de dvi a pdf)
-p, --pdf
usa pdftex o pdflatex para el procesamiento
--ps
genera un archivo PostScript a través de DVI (usando dvips)

Ajuste de TeX:

-E, --expand
expansión de macros usando makeinfo
-I DIR
busca en DIR archivos Texinfo
-l, --language=LANG
especifica el idioma LANG para FICHERO, ya sea latex o texinfo
--no-line-error
no pasar --file-line-error a TeX
--shell-escape
pasar --shell-escape a TeX
--src-specials
pasar --src-specials a TeX
--translate-file=FICHERO
usa el archivo de traducción de codificación de caracteres dado para TeX
-t, --command=CMD
inserta CMD en una copia del archivo de entrada

Modos de compilación:

--build=MODO
especifica el tratamiento de los archivos auxiliares [local]
--tidy
igual que --build=tidy
-c, --clean
igual que --build=clean
--build-dir=DIR
especifica dónde se realiza la compilación tidy; implica --tidy

El MODO especifica dónde tiene lugar la compilación de TeX y, en consecuencia, cómo se tratan los archivos auxiliares.

Los valores válidos de MODO son:

`local'
compila en el directorio actual, dejando todos los archivos auxiliares. Este es el uso tradicional de TeX.
`tidy'
compila en un directorio local *.t2d, donde se dejan los archivos auxiliares. Los archivos de salida se copian de nuevo al archivo original.
`clean'
igual que `tidy', pero elimina el directorio auxiliar después. Cada compilación requiere, por lo tanto, el ciclo completo.

El modo de compilación también se puede establecer usando la variable de entorno TEXI2DVI_BUILD_MODE. El directorio de compilación tidy también se puede establecer usando la variable de entorno TEXI2DVI_BUILD_DIRECTORY.

Los valores de estas variables de entorno se utilizan para ejecutar los comandos correspondientes, si están establecidos:

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

En cuanto a --dvipdf, si DVIPDF no está establecido en el entorno, se buscan los siguientes programas (en este orden): dvipdfmx dvipdfm dvipdf dvi2pdf dvitopdf.

Si Texinfo está instalado en su sitio, entonces el comando

info texi2dvi

debería darle acceso a más documentación.
