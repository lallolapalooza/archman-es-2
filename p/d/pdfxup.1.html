NOMBRE

pdfxup - herramienta n-up con márgenes reducidos

SINOPSIS

pdfxup [OPCIONES] [ARCHIVO]

DESCRIPCIÓN

pdfxup crea un documento PDF donde cada página se obtiene combinando varias páginas de un archivo PDF proporcionado como salida. La característica importante de pdfxup, en comparación con programas similares, es que intenta calcular el cuadro delimitador (global) del archivo PDF de entrada, para eliminar los márgenes y conservar solo el texto. En lugar de tener el tamaño de fuente dividido por 2 (para el caso de salida 2-up), en algunos casos puede terminar con un tamaño de fuente casi igual al del documento original (como es el caso de un documento 'article' predeterminado producido por LaTeX).

pdfxup utiliza ghostscript para calcular el cuadro delimitador máximo de (algunas) páginas del documento, y luego usa pdflatex (con el paquete graphicx) para producir el nuevo documento.

OPCIONES

pdfxup acepta numerosas opciones. Las más importantes son:

-x m, --columns m
establece el número de columnas del archivo de salida (predeterminado 2);
-y n, --rows n
establece el número de filas del archivo de salida (predeterminado 1);
-nup mxn, --nup mxn
establece el número de filas y columnas del archivo de salida (predeterminado 2x1);
-l (0|1), --landscape, --portrait
establece la orientación del papel (del documento final);
-cf archivo, --config archivo, --mode archivo
lee el archivo (con extensión .xup) y usa las opciones definidas en ese archivo (ver más abajo para detalles sobre los archivos .xup). Todas las opciones se procesan en el orden en que aparecen en la línea de comandos, por lo que es posible modificar las opciones establecidas en el archivo de configuración (e incluso es posible incluir varios archivos de configuración, el último sobrescribe las opciones establecidas por los anteriores). Los archivos se buscan utilizando kpsewhich (si está disponible).
-b (le|se), --booklet (le|se)
configura para imprimir como un folleto. El valor 'le' (que es el valor predeterminado cuando se usa -b sin argumento) significa que la impresión a doble cara está en modo 'borde largo' (pasas de una página a la siguiente a lo largo del borde largo del papel). 'se' es la opción 'borde corto'.
-c, --clip, -nc, --no-clip
recorta (o no recorta) las páginas al cuadro delimitador calculado. Por defecto, el contenido se recorta para evitar la superposición entre páginas vecinas. Con --no-clip, se mostrará todo lo que esté fuera del cuadro delimitador.
-o archivo, --output archivo
nombre del archivo de salida.
-i
preguntar antes de sobrescribir el archivo de salida.
-ow
sobrescribir el archivo de salida sin preguntar.
-ps s, --paper s
establece el tamaño del papel (predeterminado a4). El nombre debe ser conocido por el paquete geometry (más precisamente, "<s>paper" debería estar definido en ese paquete).
-fw d, --framewidth d
ancho del marco alrededor de cada página (predeterminado 0.4pt). Establézcalo en 0pt para no tener ningún marco.
-tf [0|1], --tight-frame [0|1]
si el marco debe ser ajustado alrededor de la página, dejando espacio blanco horizontal fuera del marco, o debe ser ancho y ocupar todo el ancho disponible.
-im d, --innermargins d
margen interior entre el marco y la página (predeterminado 5pt).
-m d, --margins d
margen de las páginas del nuevo documento (predeterminado 5pt).
-is d, --intspaces d
espacio entre diferentes páginas (predeterminado 1pt).
-p lista, --pages lista
solo considera una sublista de páginas del documento de entrada. La lista es una lista separada por comas de páginas o rangos de páginas de la forma a-b; se puede omitir a para empezar desde la primera página, y se puede omitir b para terminar en la última página. Por lo tanto, ""-p -"" (que es el predeterminado) incluye todas las páginas. También permite el módulo, de modo que ""-p 0%2"" solo incluiría las páginas pares.
-bb lista, --bb lista
solo considera una sublista de páginas del documento de entrada para calcular el cuadro delimitador.
-nobb lista, --no-bb lista
omite la lista de páginas del documento de entrada del cálculo del cuadro delimitador.
-g, --get-bb
solo calcula (y muestra) el cuadro delimitador. No producirá ningún archivo de salida.
-kbb, --keep-bb
no calcular el cuadro delimitador, conservar los márgenes actuales.
-s x y An Al, --set-bb x y An Al
establece el cuadro delimitador a los valores dados. Los valores están en pt; los dos primeros elementos corresponden a la esquina inferior izquierda, mientras que los dos últimos representan el ancho y la altura de la parte que se mostrará.
-w archivo, --watermark archivo
usa el archivo como marca de agua de fondo. El archivo puede ser de cualquier formato aceptado por pdflatex (por ejemplo, png o pdf). Si el archivo es un archivo PDF multipágina, la página n del archivo de marca de agua se usa con la página n del archivo de entrada, y la última página del archivo de marca de agua se repite si el archivo de entrada tiene más páginas.
-wp p, --watermark-period p
repite las últimas p páginas del archivo de marca de agua en lugar de solo la última.
-d, --debug
modo de depuración: conserva los archivos intermedios.
-col, --column-mode, --vertical
llena las páginas de arriba hacia abajo primero (en lugar del modo predeterminado de izquierda a derecha); por defecto, las páginas se insertan de izquierda a derecha, hasta que la línea está llena; con esta opción, las páginas se insertan de arriba a abajo, hasta que la columna está llena. Por ejemplo: 
           ---------                     ---------
modo-fila | 1  2  3 |      modo-columna  | 1  4  7 |
          | 4  5  6 |                   | 2  5  8 |
          | 7  8  9 |                   | 3  6  9 |
           ---------                     ---------
-row, --row-mode, --horizontal
llena las páginas de izquierda a derecha.
-bal, --balance-last
equilibrar última página: al usar el modo columna, las páginas se llenan de arriba a abajo, y la última página no es una excepción. Aún así, puede ser preferible que las columnas de la última página permanezcan "equilibradas", que es lo que logra esta opción. De manera simétrica, en modo fila, esta opción equilibraría las filas. 
                 ---------                        ---------
fila, sin-balance | 1  2  3 |  columna, sin-balance  | 1  4    |
                  | 4  5    |                      | 2  5    |
                  |         |                      | 3       |
                   ---------                        ---------
                   ---------                        ---------
     fila, balance | 1  2    |     columna, balance  | 1  3  5 |
                  | 3  4    |                      | 2  4    |
                  | 5       |                      |         |
                   ---------                        ---------
-V [0-3], --verbose [0-3]
selecciona la verbosidad (predeterminado: 1).
-q, --quiet
ejecutar silenciosamente (equivale a '-V 0').
-v, --version
imprime el número de versión y sale.
-h, --help
imprime el mensaje de ayuda y sale.

ARCHIVOS DE CONFIGURACIÓN

Los archivos .xup (extensión .xup) son scripts bash utilizados para configurar algunas variables. Si se utiliza la opción "--config-file <archivo>" (o equivalente), se busca <archivo> primero con kpsewhich, si no contiene '/'. Si kpsewhich no lo encuentra, entonces pdfxup comprueba si el archivo existe (usando 'test -e') antes de incluirlo (la variable PATH no se usará para encontrarlo).

El script solo debe configurar algunas variables internas de pdfxup, como NB_ROWS, NB_COLUMNS, LANDSCAPE (para configurar un diseño predefinido). Se puede usar para configurar el cuadro delimitador (bounding box), pero a menudo es mejor calcularlo en las primeras páginas del documento. Aquí hay algunos ejemplos de líneas que se pueden poner en un archivo .xup:

NB_COLUMNS=1
establece el número de columnas a 1
NB_ROWS=2
establece el número de filas a 2
LANDSCAPE=0
establece el modo retrato
KEEP_ORIG_BBOX=1
no recortar márgenes
SET_BBOX="75 47 540 755"
establece el cuadro delimitador: inferior izquierda=(75,47); superior derecha=(540,755)
TIGHT_FRAME=1
establece marcos ajustados alrededor de las páginas
INNER_MARGINS=10pt
establece el margen alrededor de cada página (dentro del marco) a 10pt
INTERM_SPACES=10pt
establece el espacio entre páginas a 10pt
FRAME_WIDTH=2mm
establece el ancho del marco a 2mm

Otras variables disponibles se pueden encontrar en la función setdefaultvalues.

EJEMPLOS

# pdfxup archivo.pdf
produce un archivo pdf de 2 páginas (2-up) a partir de archivo.pdf.
# pdfxup -bb 1-4 archivo.pdf
mismo comportamiento, pero calcula el cuadro delimitador usando solo las primeras 4 páginas (esto ahorra tiempo al procesar documentos largos).
# pdfxup -b -o folleto.pdf archivo.pdf
mismo comportamiento, pero crea un folleto (como folleto.pdf).
# pdfxup -kbb -x1 -y2 -l0 beamer-frames.pdf
organiza 2 fotogramas de beamer por página (sin reducir márgenes).
# pdfxup --mode beamer2 beamer-frames.pdf
organiza las páginas PDF según el archivo de configuración beamer2.xup.
# pdfxup -kbb -x2 -y2 -l beamer-frames.pdf:1-12,15-19
organiza 4 fotogramas de beamer por página (sin reducir márgenes), incluyendo solo los fotogramas 1 a 12 y 15 a 19.
