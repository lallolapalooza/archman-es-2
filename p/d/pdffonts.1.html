pdffonts(1) Manual de Comandos Generales pdffonts(1)

NOMBRE

pdffonts - Analizador de fuentes de Formato de Documento Portátil (PDF) (versión 3.03)

SINOPSIS

pdffonts [opciones] [archivo-PDF]

DESCRIPCIÓN

Pdffonts lista las fuentes utilizadas en un archivo de Formato de Documento Portátil (PDF) junto con diversa información para cada fuente.

Si archivo-PDF es ´-', lee el archivo PDF desde la entrada estándar.

La siguiente información se lista para cada fuente:

nombre
el nombre de la fuente, tal como se proporciona en el archivo PDF (potencialmente incluyendo un prefijo de subconjunto)
tipo
el tipo de fuente – ver abajo para más detalles
codificación
la codificación de la fuente
inc
"sí" si la fuente está incrustada en el archivo PDF
sub
"sí" si la fuente es un subconjunto
uni
"sí" si hay un mapa explícito "ToUnicode" en el archivo PDF (la ausencia de un mapa ToUnicode no significa necesariamente que el texto no se pueda convertir a Unicode)
ID de objeto
el ID del objeto del diccionario de fuentes (número y generación)

Los archivos PDF pueden contener los siguientes tipos de fuentes:

Tipo 1
Tipo 1C – también conocido como formato de fuente compacto (CFF)
Tipo 3
TrueType
CID Tipo 0 – fuente de 16 bits sin tipo especificado
CID Tipo 0C – fuente PostScript CFF de 16 bits
CID TrueType – fuente TrueType de 16 bits

OPCIONES

-f número
Especifica la primera página a analizar.
-l número
Especifica la última página a analizar.
-subst
Lista las fuentes sustitutas que poppler utilizará para las fuentes no incrustadas.
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionarla omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña del usuario para el archivo PDF.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes).

CÓDIGOS DE SALIDA

Las herramientas de Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
99
Otro error.
