PDFJAM(1) User Commands PDFJAM(1)

NOMBRE

pdfjam - Un script de shell para manipular archivos PDF

SINOPSIS

pdfjam [opciones] [--] [archivo[páginas]]...

DESCRIPCIÓN

pdfjam ensambla una lista de documentos (pdf, ps, eps, jpg o png) en un solo pdf. Permite rotar, escalar, reordenar y combinar páginas libremente usando el poder de los paquetes LaTeX 'pdfpages' y 'graphicx'.

La salida se escribe en un nombre generado (a menos que se especifique a través de --outfile). Los archivos de entrada se incrustan como gráficos en la salida. Especialmente los archivos jpg se conservan tal cual, sin transcodificación. Se soporta la entrada desde stdin especificando /dev/stdin como archivo y es el valor predeterminado si no se proporciona ningún archivo.

Especificando páginas es posible especificar qué páginas incluir y en qué orden. El valor predeterminado '-' selecciona todas las páginas. Un ejemplo:

pdfjam archivo1 '{},2,4-6,9-' ...

crea una página vacía, seguida de las páginas 2,4,5,6 del archivo1, seguida de las páginas 9 en adelante (hasta el final del archivo1).

Una selección de páginas se puede aplicar a más de un archivo, por ejemplo:

pdfjam archivo1 archivo2 archivo3 ultimo-1 ...

aplica la selección de páginas 'ultimo-1' (invirtiendo el orden de las páginas) a los tres archivos; pero por ejemplo

pdfjam archivo1 archivo2 2- archivo3 1-7 ...

aplicaría la selección de páginas '2-' a archivo1 y archivo2, y '1-7' a archivo3. Una selección de páginas se aplica a todos los archivos *inmediatamente* anteriores a ella en la lista de argumentos.

Ver el manual de pdfpages para más detalles sobre la sintaxis de selección de páginas.

OPCIONES PARA PDFPAGES Y GRAPHICX

Las opciones clave-valor para 'pdfpages' y 'graphicx' se pueden especificar como --clave valor.

OPCIONES META

-h, --help
Muestra solo este texto; no se procesan archivos PDF.
--configpath
Muestra la variable 'configpath' y sale inmediatamente; no se procesan archivos PDF.
-V, --version
Muestra el número de versión de pdfjam y sale inmediatamente; no se procesan archivos PDF.
-q, --quiet
Suprime comentarios detallados sobre el progreso.

OPCIONES DE PROCESAMIENTO

--batch
Ejecuta pdfjam secuencialmente en cada archivo de entrada por turno, y produce un archivo de salida separado para cada entrada, en lugar del comportamiento predeterminado de coalescencia. Para la ubicación de los archivos de salida, ver --outfile. La opción --batch no se puede usar en el caso de entrada desde stdin.
-o, --outfile nombre
Especifica dónde irán los archivos de salida. Si 'nombre' es un directorio existente, pdfjam intentará escribir sus archivos PDF de salida allí, con nombres derivados del nombre del archivo de entrada y la opción --suffix (ver más abajo). De lo contrario, el pdf de salida se escribirá en 'nombre'.
--suffix cadena
Especifica un sufijo para los nombres de los archivos de salida, a usar cuando --outfile no se especifica o es un directorio. La CADENA no debe tener longitud cero.
--checkfiles, --no-checkfiles
Si la utilidad Unix 'file' está disponible, la salida de 'file -Lb ARCHIVO1' debe ser 'documento PDF...' donde '...' da información de versión. Si este es el caso en su sistema, debe usar --checkfiles; de lo contrario, use --no-checkfiles, en cuyo caso todos los archivos de entrada deben tener las extensiones correctas (.pdf, .ps, .eps .jpg, .jpeg, .png, o sus variantes en mayúsculas).
--latex rutalatex
Especifica el motor LaTeX a utilizar (uno de pdflatex, xelatex, lualatex). La cadena rutalatex debe ser la ruta completa a un ejecutable LaTeX adecuado (por ejemplo /usr/bin/xelatex en muchos sistemas unix).
--tidy, --no-tidy
Especifica si el directorio temporal creado por pdfjam debe ser eliminado. Use '--no-tidy' o '--builddir' (ver más abajo) para ayudar a depurar la mayoría de los errores.
--builddir ruta
Especifica un directorio de compilación a usar en lugar de uno temporal. Los archivos existentes dentro serán sobrescritos. Anula --tidy.
--runs N
Ejecuta latex N veces, por cada documento de salida creado.
--vanilla
Suprime la lectura de cualquier archivo de configuración de pdfjam.
--enc
Especifica una codificación de línea de comandos

OPCIONES DE PAPEL

--paper nombrepapel, --nombrepapel
Especifica un tamaño de papel LaTeX, por ejemplo '--paper a4' o simplemente '--a4paper' para papel ISO A4. Hay una amplia gama de tamaños de papel disponibles gracias al paquete LaTeX 'geometry'. Para detalles ver la documentación de LaTeX y/o el paquete 'geometry'. Si no hay un valor predeterminado establecido, se obtiene el papel predeterminado del sistema a través de libpaper, cayendo de nuevo a A4.
--papersize anchura,altura
Especifica un tamaño de papel personalizado en puntos = 1/72 de pulgada (conocido como bp en LaTeX y como pt en otro software), por ejemplo --papersize 612,792. Las unidades también se pueden especificar explícitamente, por ejemplo --papersize 10in,18cm.
--landscape, --no-landscape
Especifica la orientación de página horizontal (o no) en el archivo PDF de salida.
--twoside, --no-twoside
Especifica (o no) la opción de clase de documento 'twoside'.
--other-edge, --no-other-edge
Rota cada página impar 180 grados (o no). Esto cambia a lo largo de qué borde se voltean las páginas en la impresión a doble cara.
--pagecolor esprgb
Especifica un color de fondo para las páginas de salida. El ESPrgb debe ser un triple separado por comas de enteros entre 0 y 255. Un ejemplo: --pagecolor 150,200,150. El valor predeterminado es sin color de fondo.

OPCIONES DE PDFINFO

--keepinfo, --no-keepinfo
Conserva (o no) Título, Autor, Asunto y Palabras clave (del último archivo PDF, si hay más de uno) en el archivo PDF de salida. Esto requiere la utilidad pdfinfo, del paquete poppler-utils, y el paquete LaTeX 'hyperref'; si alguno de ellos no está disponible, '--keepinfo' se ignora.
--pdftitle cadena, --pdfauthor cadena,
--pdfsubject cadena, --pdfkeywords cadena Proporciona texto para el Título, Autor, Asunto y Palabras clave en el archivo PDF de salida. Requiere el paquete LaTeX 'hyperref'. Estas opciones, individualmente, anulan --keepinfo.

OPCIONES AVANZADAS

--preamble cadena
Añade la CADENA suministrada al preámbulo de los archivos fuente LaTeX, inmediatamente antes de la línea '\begin{document}' para cargar paquetes LaTeX o establecer opciones globales. Un ejemplo:
pdfjam --nup 2x2 miarchivo.pdf -o miarchivo-4up.pdf --preamble '\usepackage{fancyhdr} \pagestyle{fancy}'

Si '--preamble' se usa más de una vez en la llamada, las cadenas suministradas

se concatenan. Para una nota sobre cómo evitar conflictos, consulte el archivo README, también disponible en https://github.com/pdfjam/pdfjam.

--
Indica el fin del procesamiento de opciones.

OPCIONES DE PDFPAGES Y GRAPHICX

--CLAVE VALOR
Especifica opciones para '\includepdfmerge', en el paquete LaTeX 'pdfpages'. Consulte la documentación de pdfpages (normalmente 'texdoc pdfpages') para más información. Aquí CLAVE es el nombre de cualquiera de las muchas opciones para '\includepdfmerge', y VALOR es un valor correspondiente. Ejemplos:
--nup 2x1 (para imposición 2 por página lado a lado)
--scale 0.7 (para escalar todas las páginas de entrada al 70% de su tamaño)
--offset '1cm 0.5cm' (para desplazar todas las páginas -- ¡note las comillas!)
--frame true (para poner un marco alrededor de cada página de entrada)
--booklet true (para reordenar las páginas en signaturas, generalmente útil con --nup)
--signature N (especifica el tamaño de la signatura, como el número de páginas originales en una signatura en el documento final. Advertencia: booklet es una forma abreviada de signature, por lo que si usa --booklet true, signature se ignorará)
--trim '1cm 2cm 1cm 2cm' --clip true (para recortar esas cantidades de la izquierda, abajo, derecha y arriba, respectivamente, de las páginas de entrada)
--angle NNN (El ángulo de rotación en grados. Los ángulos que no sean 0, 90, 180 o 270 seguirán creando páginas rectangulares rectas, solo el contenido se rotará.)

ARCHIVOS DE CONFIGURACIÓN

Los valores predeterminados para las opciones --suffix, --keepinfo, --paper, --outfile, --landscape, --twoside, --tidy, --latex, --runs, --checkfiles y --preamble se pueden establecer en archivos de configuración a nivel de sitio o específicos del usuario. Los archivos que se buscan son

/etc/pdfjam.conf /usr/share/etc/pdfjam.conf /usr/local/share/pdfjam.conf /usr/local/etc/pdfjam.conf $XDG_CONFIG_HOME/pdfjam.conf $HOME/.pdfjam.conf

Esta lista se puede modificar editando 'configpath' en el script pdfjam. Todos estos archivos se ignoran si se utiliza el argumento --vanilla.
