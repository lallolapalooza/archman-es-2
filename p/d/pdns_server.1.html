PDNS_SERVER(1) Servidor Autoritativo PowerDNS PDNS_SERVER(1)

NOMBRE

pdns_server - El Servidor Autoritativo PowerDNS

SINOPSIS

pdns_server [OPCIÓN]

DESCRIPCIÓN

El Servidor Autoritativo PowerDNS es un servidor de nombres versátil que soporta un gran número de backends. Estos backends pueden ser archivos de zona simples o tener una naturaleza más dinámica. Por favor, consulte la documentación en línea para más información.

OPCIONES

Consulte la documentación en línea para ver todas las opciones. Las más importantes son:

--daemon
Indica si el servidor debe ejecutarse en segundo plano como un demonio real, o en primer plano.
--guardian
Ejecuta pdns_server dentro de un guardián. Este guardián supervisa el rendimiento de la instancia interna de pdns_server. También es con este guardián con el que se comunica pdns_control.
--control-console
Ejecuta el servidor en un modo de monitor especial. Esto habilita el registro detallado y expone el socket de control en bruto.
--loglevel=<NIVEL>
Establece el nivel de registro.
--config
Muestra la configuración actual. Hay tres valores opcionales:
--config=default
muestra la configuración predeterminada.
--config=diff
muestra las opciones modificadas en la configuración actual.
--config=check
analiza la configuración actual, con verificación de errores.
--help
Muestra la lista de todas las opciones disponibles.

VER TAMBIÉN

pdns_control(1), pdnsutil(1), https://doc.powerdns.com/
