PDFTEX(1) Manual de Comandos Generales PDFTEX(1)

NOMBRE

pdftex - Salida PDF de TeX

SINOPSIS

pdftex [opciones] [&formato] [archivo|\comandos]

DESCRIPCIÓN

Ejecuta el componedor pdfTeX sobre archivo, usualmente creando archivo.pdf. Si el argumento del archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede dar un conjunto de comandos de pdfTeX, el primero de los cuales debe empezar con una barra invertida. Con el argumento &formato, pdfTeX usa un conjunto diferente de comandos precompilados, contenidos en formato.fmt; usualmente es mejor usar la opción -fmt formato en su lugar.

pdfTeX es una versión de TeX, con las extensiones e-TeX, que puede crear archivos PDF además de archivos DVI.

En modo DVI, pdfTeX puede usarse como un reemplazo completo para el motor TeX.

El uso típico de pdfTeX es con formatos pregenerados para los cuales la salida PDF ha sido habilitada. El comando pdftex usa el equivalente del formato plain TeX, y el comando pdflatex usa el equivalente del formato LaTeX. Para generar formatos, use el interruptor -ini.

Los comandos pdfinitex y pdfvirtex son los análogos de pdfTeX a los comandos initex y virtex. En esta instalación, si los enlaces existen, son enlaces simbólicos al ejecutable pdftex.

En modo PDF, pdfTeX puede manejar nativamente los formatos gráficos PDF, JPG, JBIG2 y PNG. pdfTeX no puede incluir archivos gráficos PostScript o Encapsulated PostScript (EPS); primero conviértelos a PDF usando epstopdf(1). El manejo de pdfTeX de sus argumentos de línea de comandos es similar al de los otros programas TeX en la implementación de web2c.

A partir de la versión 1.40, pdfTeX incorpora las extensiones e-TeX, y pdfeTeX es solo una copia de pdfTeX. Véase etex(1).

OPCIONES

Esta versión de pdfTeX entiende las siguientes opciones de línea de comandos.

-cnf-line cadena
Interpreta cadena como una línea de configuración de texmf.cnf. Véase el manual de Kpathsea.
-draftmode
Establece \pdfdraftmode para que pdfTeX no escriba un PDF y no lea ninguna imagen incluida, acelerando así la ejecución.
-enc
Habilita las extensiones encTeX. Esta opción solo es efectiva en combinación con -ini. Para documentación de las extensiones encTeX véase http://www.olsak.net/enctex.html.
-etex
Habilita las extensiones e-TeX. Esta opción solo es efectiva en combinación con -ini. Véase etex(1).
-file-line-error
Imprime mensajes de error en el formato archivo:línea:error, similar a como muchos compiladores los formatean.
-no-file-line-error
Deshabilita la impresión de mensajes de error en el estilo archivo:línea:error.
-file-line-error-style
Este es el nombre antiguo de la opción -file-line-error.
-fmt formato
Usa formato como el nombre del formato a usar, en lugar del nombre por el cual se llamó a pdfTeX o una línea %&.
-halt-on-error
Sale con un código de error cuando se encuentra un error durante el procesamiento.
-help
Imprime el mensaje de ayuda y sale.
-ini
Inicia en modo INI, que se usa para volcar formatos. El modo INI puede usarse para componer, pero no se precarga ningún formato y pueden requerirse inicializaciones básicas como establecer códigos de categoría.
-interaction modo
Establece el modo de interacción. El modo puede ser batchmode, nonstopmode, scrollmode y errorstopmode. El significado de estos modos es el mismo que el de los comandos \correspondientes.
-ipc
Envía la salida DVI o PDF a un socket además del archivo de salida usual. Si esta opción está disponible es a elección del instalador.
-ipc-start
Como -ipc, e inicia también el servidor en el otro extremo. Si esta opción está disponible es a elección del instalador.
-jobname nombre
Usa nombre para el nombre del trabajo (job name), en lugar de derivarla del nombre del archivo de entrada.
-kpathsea-debug máscara_de_bits
Establece las banderas de depuración de búsqueda de rutas según la máscara de bits. Véase el manual de Kpathsea para detalles.
-mktex fmt
Habilita mktexfmt, donde fmt debe ser tex o tfm.
-mltex
Habilita las extensiones MLTeX. Solo efectivo en combinación con -ini.
-no-mktex fmt
Deshabilita mktexfmt, donde fmt debe ser tex o tfm.
-output-comment cadena
En modo DVI, usa cadena para el comentario del archivo DVI en lugar de la fecha. Esta opción se ignora en modo PDF.
-output-directory directorio
Escribe los archivos de salida en directorio en lugar del directorio actual. Busca archivos de entrada en directorio primero, luego a lo largo de la ruta de búsqueda normal.
-output-format formato
Establece el modo de formato de salida, donde formato debe ser pdf o dvi. Esto también influye en el conjunto de formatos gráficos entendidos por pdfTeX.
-parse-first-line
Si la primera línea del archivo de entrada principal comienza con %&, la interpreta para buscar un nombre de volcado o una opción -translate-file.
-no-parse-first-line
Deshabilita la interpretación de la primera línea del archivo de entrada principal.
-progname nombre
Finge ser el programa nombre. Esto afecta tanto al formato usado como a las rutas de búsqueda.
-recorder
Habilita el registrador de nombres de archivo. Deja un rastro de los archivos abiertos para entrada y salida en un archivo con extensión .fls.
-shell-escape
Habilita la construcción \write18{comando}. El comando puede ser cualquier comando de shell. Esta construcción normalmente está prohibida por razones de seguridad.
-no-shell-escape
Deshabilita la construcción \write18{comando}, incluso si está habilitada en el archivo texmf.cnf.
-shell-restricted
Habilita \write18{} restringido, como se explica en la sección de "Escapes de shell" del manual Texinfo de Web2c.
-src-specials
En modo DVI, inserta especiales de origen en el archivo DVI. Esta opción se ignora en modo PDF.
-src-specials dónde
En modo DVI, inserta especiales de origen en ciertos lugares del archivo DVI. El argumento dónde es una lista de valores separados por comas: cr, display, hbox, math, par, parent, o vbox.
-tex-input-directory directorio
Establece la ruta de búsqueda de entrada TeX al directorio dado, en lugar de usar la ruta de búsqueda de entrada TeX definida por defecto. Véase el manual de Kpathsea.
-translate-file filename
En modo DVI, usa filename como el archivo de traducción de caracteres en lugar del archivo de traducción por defecto. Esta opción se ignora en modo PDF. Véase también la opción -parse-first-line.
-true name
Anula la entrada name en el archivo texmf.cnf con el valor true. Esto se usa para habilitar las extensiones que se pueden controlar con valores booleanos en el archivo de configuración. Véase el manual de Kpathsea.
-unregistered
Permite el uso de extensiones no registradas en pdfTeX.
-version
Imprime la versión de pdfTeX y sale.
-vpath ruta
Establece la ruta de búsqueda de paquetes en ruta en lugar de la ruta de búsqueda de paquetes por defecto. Véase el manual de Kpathsea.
-write18
Equivalente a -shell-escape.
-no-write18
Equivalente a -no-shell-escape.
-x pedantic
Establece la opción pedantic de Kpathsea. Véase el manual de Kpathsea.

OPTIONS

-8bit
make all characters printable by default.
-credits
Print a list of all people who have contributed to pdfTeX and exit.
-debug-output
Turn on all the debugging output. This option is ignored in PDF mode.
-disable-installer
Disable the installer. This option is ignored in PDF mode.
-draftmode
Set the PDF output intent to Draft. This option is ignored in PDF mode.
-enable-installer
Enable the installer. This option is ignored in PDF mode.
-etex
Enable extensions of pdfTeX, which are described in the e-TeX manual.
-file-line-error
Make all error messages include file name and line number. This option is ignored in PDF mode.
-fmt name
Use name as the format file. The default is to use the format file named after the program being run (e.g. pdftex).
-fuzz =NUMBER
Set the fuzz factor for comparisons of box widths. Default value is 1.
-halt-on-error
Exit when the first error has been encountered.
-help
Print a usage message and exit.
-ini
Initialize pdfTeX in the dumping mode. This is the default mode.
-interaction mode
Set the mode of interaction between TeX and the user. The modes are: batchmode, nonstopmode, nonstopmode, scrollmode, and errorstopmode. The default mode is errorstopmode. This option is ignored in PDF mode.
-kpathsea-debug =NUMBER
Set Kpathsea debugging flags according to bits of NUMBER. See the Kpathsea library documentation for details.
-maketex tfm
If the TFM file for a font is missing, generate it. Supported values for tfm are: 0 (off), 1 (on), 2 (force).
-memdir DIR
Use DIR as the directory for memory dumps. This option is ignored in PDF mode.
-mlbibtex
Use MLbibtex instead of Bibtex.
-no-maketex
Disable generation of TFM files.
-output-comment string
Use string to comment the output file. Default is the pdfTeX version string.
-parse-first-line
Scan the first line of the input file for any of the options described above. This option is ignored in PDF mode.
-progname name
Set the program name. This is usually done automatically.
-shell-escape
Enable shell escape, that is, the execution of arbitrary programs via the \write18{...} primitive. This option is ignored in PDF mode.
-shell-restricted
Enable restricted shell escape. This option is ignored in PDF mode.
-src-specials
Generate source specials in the output. This option is ignored in PDF mode.
-synctex NUMBER
generate SyncTeX data for previewers according to bits of NUMBER. See the synctex manual page for details.
-translate-file tcxname
Use the tcxname translation table to set the mapping of input characters and re-mapping of output characters.
-default-translate-file tcxname
Like -translate-file except that a %& line can overrule this setting.
-version
Print version information and exit.
-8bit
make all characters printable by default.

ENVIRONMENT

See the Kpathsea library documentation (e.g., the `Path specifications' node) for precise details of how the environment variables are used. The kpsewhich utility can be used to query the values of the variables.

One caveat: In most pdfTeX formats, you cannot use ~ in a filename you give directly to pdfTeX, because ~ is an active character in TeX, and hence is expanded, not taken as part of the filename. Other programs, such as Metafont, do not have this problem.

TEXMFOUTPUT
Normally, pdfTeX puts its output files in the current directory. If any output file cannot be opened there, it tries to open it in the directory specified in the environment variable TEXMFOUTPUT. There is no default value for that variable. For example, if you say pdftex paper and the current directory is not writable and TEXMFOUTPUT has the value /tmp, pdfTeX attempts to create /tmp/paper.log (and /tmp/paper.pdf, if any output is produced.) TEXMFOUTPUT is also checked for input files, as TeX often generates files that need to be subsequently read; for input, no suffixes (such as ``.tex'') are added by default, the input name is simply checked as given.
TEXINPUTS
Search path for \input and \openin files. This normally starts with ``.'', so that user files are found before system files. An empty path component will be replaced with the paths defined in the texmf.cnf file. For example, set TEXINPUTS to ".:/home/user/tex:" to prepend the current directory and ``/home/user/tex'' to the standard search path.
TEXFORMATS
Search path for format files.
TEXEDIT
Command template for switching to editor. The default, usually vi, is set when pdfTeX is compiled.
TFMFONTS
Search path for font metric (.tfm) files.
SOURCE_DATE_EPOCH
If set, its value, taken to be in epoch-seconds, will be used for the timestamps in the PDF output, such as the CreationDate and ModDate keys. This is useful for making reproducible builds.
FORCE_SOURCE_DATE
If set to the value "1", the time-related TeX primitives (\year, \month, \day, \time) are also initialized from the value of SOURCE_DATE_EPOCH. This is not recommended if there is any viable alternative.
pdfTeX also has several primitives to support reproducible builds, which are preferable to setting these environment variables; see the main manual.

Many, many more environment variables may be consulted related to path searching. See the Kpathsea manual.

NOTES

BUGS

This version of pdfTeX fails to trap arithmetic overflow when dimensions are added or subtracted. Cases where this occurs are rare, but when it does the generated DVI or PDF file will be invalid.

AVAILABILITY

pdfTeX is available for a large variety of machine architectures and operating systems. pdfTeX is part of all major TeX distributions.
