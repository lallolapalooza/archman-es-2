pdftocairo(1) Manual de comandos generales pdftocairo(1)

NOMBRE

pdftocairo - Formato de documento portátil (PDF) a PNG/JPEG/TIFF/PDF/PS/EPS/SVG usando cairo

SINOPSIS

pdftocairo [opciones] archivo-PDF [archivo-salida]

DESCRIPCIÓN

pdftocairo convierte archivos en formato de documento portátil (PDF), utilizando el dispositivo de salida cairo de la biblioteca PDF poppler, a cualquiera de los siguientes formatos de salida:

  • Formato de gráfico de red portátil (PNG)
  • Formato de intercambio JPEG (JPEG)
  • Formato de archivo de imagen etiquetada (TIFF)
  • Formato de documento portátil (PDF)
  • PostScript (PS)
  • PostScript encapsulado (EPS)
  • Gráficos vectoriales escalables (SVG)
  • Impresora de Windows

pdftocairo lee el archivo PDF, archivo-PDF, y escribe en archivo-salida. Los formatos de imagen (PNG, JPEG y TIFF) generan un archivo por página con el número de página y el tipo de archivo añadidos a archivo-salida. Cuando se usa -singlefile con los formatos de imagen, el tipo de archivo se añade a archivo-salida. Cuando el formato de salida es un formato vectorial (PDF, PS, EPS y SVG), archivo-salida es el nombre de archivo completo.

Si el archivo-PDF es “-”, el PDF se lee desde stdin. Si el archivo-salida es “-”, el archivo de salida se escribirá en stdout. Usar stdout no es válido con formatos de imagen a menos que se use -singlefile. Si no se usa archivo-salida, el nombre del archivo de salida se derivará del nombre del archivo archivo-PDF.

No todas las opciones son válidas con todos los formatos de salida. Se debe utilizar una (y solo una) de las opciones de formato de salida (-png, -jpeg, -tiff, -pdf, -print, -ps, -eps o -svg).

Las opciones de resolución (-r, -rx, -ry) establecen la resolución de los formatos de salida de imagen. Las dimensiones de la imagen dependerán del tamaño de la página PDF y la resolución. Para las salidas vectoriales, las regiones de la página que no pueden representarse de forma nativa en el formato de salida (por ejemplo, la transparencia en PS) se rasterizarán a la resolución especificada por las opciones de resolución.

Las opciones -scale-to pueden usarse para establecer un tamaño de imagen fijo. La resolución de la imagen variará con el tamaño de la página.

Las opciones de recorte (-x, -y, -W, y -H) usan unidades de píxeles con los formatos de imagen y puntos PostScript (1/72 pulgada) con los formatos vectoriales. Cuando se usa el recorte con salida vectorial, la región recortada se centra a menos que se use -nocenter, en cuyo caso la región recortada está en la esquina superior izquierda (SVG) o inferior izquierda (PDF, PS, EPS).

OPCIONES

-png
Genera un archivo PNG.
-jpeg
Genera un archivo JPEG. Ver también -jpegopt.
-tiff
Genera un archivo TIFF.
-pdf
Genera un archivo PDF.
-ps
Genera un archivo PS.
-eps
Genera un archivo EPS. Un archivo EPS contiene una sola imagen, por lo que si usa esta opción con un archivo PDF de varias páginas, debe usar -f y -l para especificar una sola página. Las opciones de tamaño de página (-origpagesizes, -paper, -paperw, -paperh) no se pueden usar con esta opción.
-svg
Genera un archivo SVG (Gráficos vectoriales escalables).
-print
(Solo Windows) Imprime en una impresora del sistema. Ver también -printer y -printeropt.
Si no se especifica un archivo de salida, la salida se enviará a la impresora.
El archivo de salida '-' no se puede usar con esta opción.
-printdlg
(Solo Windows) Imprime en una impresora del sistema. Muestra el cuadro de diálogo de impresión para permitir modificar las opciones de impresión antes de imprimir.
-f número
Especifica la primera página a convertir.
-l número
Especifica la última página a convertir.
-o
Genera solo las páginas impares.
-e
Genera solo las páginas pares.
-singlefile
Escribe solo la primera página y no añade dígitos.
-r número
Especifica la resolución X e Y, en píxeles por pulgada de los archivos de imagen (o regiones rasterizadas en salida vectorial). El valor predeterminado es 150 PPI.
-rx número
Especifica la resolución X, en píxeles por pulgada de los archivos de imagen (o regiones rasterizadas en salida vectorial). El valor predeterminado es 150 PPI.
-ry número
Especifica la resolución Y, en píxeles por pulgada de los archivos de imagen (o regiones rasterizadas en salida vectorial). El valor predeterminado es 150 PPI.
-scale-to número
Escala el lado más largo de cada página (ancho para páginas apaisadas, alto para páginas verticales) para que quepa en `número` píxeles. El tamaño del lado más corto se determinará por la relación de aspecto de la página (solo PNG/JPEG/TIFF).
-scale-to-x número
Escala cada página horizontalmente para que quepa en `número` píxeles. Si scale-to-y se establece en -1, el tamaño vertical se determinará por la relación de aspecto de la página (solo PNG/JPEG/TIFF).
-scale-to-y número
Escala cada página verticalmente para que quepa en `número` píxeles. Si scale-to-x se establece en -1, el tamaño horizontal se determinará por la relación de aspecto de la página (solo PNG/JPEG/TIFF).
-x número
Especifica la coordenada x de la esquina superior izquierda del área de recorte en píxeles (salida de imagen) o puntos (salida vectorial)
-y número
Especifica la coordenada y de la esquina superior izquierda del área de recorte en píxeles (salida de imagen) o puntos (salida vectorial)
-W número
Especifica el ancho del área de recorte en píxeles (salida de imagen) o puntos (salida vectorial) (predeterminado es 0)
-H número
Especifica la altura del área de recorte en píxeles (salida de imagen) o puntos (salida vectorial) (predeterminado es 0)
-sz número
Especifica el tamaño del cuadrado de recorte en píxeles (salida de imagen) o puntos (salida vectorial) (establece -W y -H)
-cropbox
Usa el cuadro de recorte en lugar del cuadro de medios al generar los archivos (solo PNG/JPEG/TIFF)
-mono
Genera un archivo monocromático (solo PNG y TIFF).
-gray
Genera un archivo en escala de grises (solo PNG, JPEG y TIFF).
-antialias
Establece la opción de antialiasing de cairo utilizada para texto y dibujo en archivos de imagen (o regiones rasterizadas en salida vectorial). Las opciones son:
default
Usa el antialiasing predeterminado para el dispositivo de destino. Esta es la configuración predeterminada si no se usa -antialias.
none
El antialiasing está deshabilitado.
gray
Realiza antialiasing de un solo color utilizando tonos de gris.
subpixel
Realiza antialiasing aprovechando el orden de los subpíxeles en dispositivos como LCD.
fast
Indica que el backend debe realizar cierto antialiasing pero priorizar la velocidad sobre la calidad.
good
El backend debe equilibrar calidad y rendimiento.
best
Indica que el backend debe renderizar con la máxima calidad, sacrificando velocidad si es necesario.

OPTIONS

-transp
Use a transparent page color instead of white (PNG and TIFF only).
-icc icc-file
Use the specified ICC file as the output profile (PNG only). The profile will be embedded in the PNG file.
-jpegopt jpeg-options
When used with -jpeg, takes a list of options to control the jpeg compression. See JPEG OPTIONS for the available options.
-level2
Generate Level 2 PostScript (PS only).
-level3
Generate Level 3 PostScript (PS only). This enables all Level 2 features plus shading patterns and masked images. This is the default setting.
-struct
If the input file contains structural information about the document's content, write this information to the output file (PDF only).
-origpagesizes
This option is the same as "-paper match".
-paper size
Set the paper size to one of "letter", "legal", "A4", or "A3" (PS,PDF,SVG only). This can also be set to "match", which will set the paper size of each page to match the size specified in the PDF file. If none the -paper, -paperw, or -paperh options are specified the default is to match the paper size.
-paperw size
Set the paper width, in points (PS,PDF,SVG only).
-paperh size
Set the paper height, in points (PS,PDF,SVG only).
-nocrop
By default, printing output is cropped to the CropBox specified in the PDF file. This option disables cropping (PS,PDF,SVG only).
-expand
Expand PDF pages smaller than the paper to fill the paper (PS,PDF,SVG only). By default, these pages are not scaled.
-noshrink
Don't scale PDF pages which are larger than the paper (PS,PDF,SVG only). By default, pages larger than the paper are shrunk to fit.
-nocenter
By default, PDF pages smaller than the paper (after any scaling) are centered on the paper. This option causes them to be aligned to the lower-left corner of the paper instead (PS,PDF,SVG only).
-duplex
Adds the %%IncludeFeature: *Duplex DuplexNoTumble DSC comment to the PostScript file (PS only). This tells the print manager to enable duplexing.
-printer printer-name
(Windows only). When used with -print, specifies the name of the printer to be used, instead of the system default.
-printopt printer-options
(Windows only). When used with -print, takes a list of options to be used to configure the printer. See WINDOWS PRINTER OPTIONS for the available options.
-setupdlg
(Windows only). When used with -print, the printer properties dialog is displayed allowing the print settings to be modified before printing. The paper size selected in the print properties dialog will be used except when -origpagesizes is specified.
-opw password
Specify the owner password for the PDF file. Providing this will bypass all security restrictions.
-upw password
Specify the user password for the PDF file.
-q
Don't print any messages or errors.
-v
Print copyright and version information.
-h
Print usage information. (-help and --help are equivalent.)

EXIT CODES

The poppler tools use the following exit codes:

0
No error.
1
Error opening a PDF file.
2
Error opening an output file.
3
Error related to PDF permissions.
4
Error related to ICC profile.
99
Other error.

JPEG OPTIONS

When JPEG output is specified, the -jpegopt option can be used to control the JPEG compression parameters. It takes a string of the form "<opt>=<val>[,<opt>=<val>]". Currently the available options are:

quality
Selects the JPEG quality value. The value must be an integer between 0 and 100.
progressive
Select progressive JPEG output. The possible values are "y", "n", indicating progressive (yes) or non-progressive (no), respectively.
optimize
Sets whether to compute optimal Huffman coding tables for the JPEG output, which will create smaller files but make an extra pass over the data. The value must be "y" or "n", with "y" performing optimization, otherwise the default Huffman tables are used.

WINDOWS PRINTER OPTIONS

In Windows, you can use the -print option to print directly to a system printer. Additionally, you can use the -printopt option to configure the printer. It takes a string of the form "<opt>=<val>[,<opt>=<val>]". Currently the available options are:

source
Selects the source paper tray to be used (bin). The possible values are "upper", "onlyone", "lower", "middle", "manual", "envelope", "envmanual", "auto", "tractor", "smallfmt", "largefmt", "largecapacity", "formsource", or a numeric value to choose a driver specific source.
duplex
Sets the duplex mode of the printer. The possible values are "off", "short" or "long", indicating no duplexing, short-edge binding, or long-edge binding, respectively. General option -duplex is a synonym of "duplex=long". If both options are specified, -printopt has priority.
