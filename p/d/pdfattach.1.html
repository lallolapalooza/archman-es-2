pdfattach(1) Manual de Comandos Generales pdfattach(1)

NOMBRE

pdfattach - Creador de archivos incrustados de documentos Portable Document Format (PDF) (versión 3.03)

SINOPSIS

pdfattach [opciones] archivo-PDF-entrada archivo-a-adjuntar archivo-PDF-salida

DESCRIPCIÓN

Pdfattach añade un nuevo archivo incrustado (adjunto) a un archivo Portable Document Format (PDF) existente.

OPCIONES

-reemplazar
Reemplazar el archivo incrustado con el mismo nombre (si existe)
-v
Imprimir información de copyright y versión.
-h
Imprimir información de uso. (-help y --help son equivalentes.)

CÓDIGOS DE SALIDA

0
Sin error.
1
Error al abrir el archivo PDF de entrada.
2
Error al abrir el archivo a adjuntar.
3
El archivo de salida ya existe.
3
Ya existe un archivo adjunto con ese nombre.
5
Error al guardar el archivo de salida.
