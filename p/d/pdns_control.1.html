PDNS_CONTROL(1) Servidor Autoritativo de PowerDNS PDNS_CONTROL(1)

NOMBRE

pdns_control - Controlar el servidor de nombres de PowerDNS

SINOPSIS

pdns_control [OPCIÓN]... COMANDO

DESCRIPCIÓN

pdns_control se utiliza para enviar comandos a un servidor de nombres de PowerDNS en ejecución.

OPCIONES

--help
Mostrar resumen de opciones.
--chroot=<DIR>
Directorio donde PowerDNS está chroot-eado.
--config-dir=<DIR>
Ubicación del directorio de configuración (pdns.conf).
--config-name=<NOMBRE>
Nombre de esta configuración virtual - renombrará la imagen binaria.
--remote-address=<DIRECCIÓN>
Dirección remota a consultar.
--remote-port=<PUERTO>
Puerto remoto a consultar.
--secret=<SECRETO>
Secreto necesario para conectarse a un PowerDNS remoto.
--socket-dir=<DIR>
Donde reside el socket de control.

COMANDOS

bind-add-zone ZONA NOMBRE_ARCHIVO

Cuando se usa el backend BIND, añade una zona. Esta zona se añade en memoria y se sirve inmediatamente. Tenga en cuenta que esto no añade la zona al archivo bind-config. NOMBRE_ARCHIVO debe ser una ruta absoluta.

bind-domain-extended-status [ZONA...]

Muestra un estado extendido de todas las zonas, que contiene mucha más información que el simple estado de zona, como el número de registros cargados actualmente, si pdns es primario o secundario para la zona, la lista de primarios, varios temporizadores, etc. Opcionalmente, añada ZONAS para obtener el estado de zonas específicas.

bind-domain-status [ZONA...]

Cuando se usa el backend BIND, lista el estado de todas las zonas. Opcionalmente, añada ZONAS para obtener el estado de zonas específicas.

bind-list-rejects

Cuando se usa el backend BIND, obtiene una lista de todas las zonas rechazadas.

bind-reload-now ZONA [ZONA...]

Cuando se usa el backend BIND, recarga inmediatamente ZONA desde el disco.

ccounts

Muestra el contenido de la caché.

current-config [diff]

Muestra la configuración que se está ejecutando actualmente. La salida tiene el mismo formato que pdns_server --config. Con la opción diff, solo se incluyen en la salida las opciones modificadas.

cycle

Reinicia el servidor de nombres para que recargue su configuración. Solo funciona cuando el servidor se ejecuta en modo guardián.

list

Vuelca todas las estadísticas y sus valores en una lista separada por comas, equivalente a show *.

list-zones [primary,secondary,native]

Muestra una lista de zonas, opcionalmente filtra por el tipo de zonas a mostrar.

notify ZONA

Añade ZONA a la lista de notificaciones, haciendo que PowerDNS envíe notificaciones a los servidores de nombres de una zona. Se puede usar si una secundaria perdió notificaciones anteriores o es generalmente sorda. Use * para notificar a todas las zonas. (Tenga en cuenta que es posible que necesite escapar el signo * en su shell.)

notify-host ZONA DIRECCIÓN

Igual que el anterior pero con la IP DIRECCIÓN especificada por el operador como destino, para usar si usted sabe más que PowerDNS.

ping, rping

Comprueba si el servidor sigue activo. Devolverá 'PONG' cuando lo esté. ping funciona cuando se ejecuta dentro de un guardián, mientras que rping funciona cuando se ejecuta sin un guardián.

purge [REGISTRO]

Vacía entradas de la caché. Si REGISTRO termina con un dólar ($) se eliminan todas las entradas que terminan con ese nombre. Si no se especifica ningún registro, se vacía toda la caché.

qtypes

Obtiene un recuento de consultas por qtype en la salida estándar.

quit o stop

Indica a un pdns_server en ejecución que salga.

rediscover

Instruye a los backends que pueden haber aparecido nuevas zonas en la base de datos, o, en el caso del backend BIND, en named.conf.

reload

Instruye al servidor que recargue todas sus zonas, esto no añadirá nuevas zonas.

remotes

Obtiene el número superior de direcciones remotas (clientes).

respsizes

Obtiene un histograma de los tamaños de respuesta.

retrieve ZONA [IP]

Recupera la ZONA secundaria de su primario. Se hace casi inmediatamente. Si se especifica IP, la recuperación se fuerza desde la IP especificada. El puerto se puede especificar de forma específica de AFI.

set VARIABLE VALOR

Establece el parámetro de configuración VARIABLE a VALOR. Actualmente solo se puede establecer el registro de consultas.

show ESTADÍSTICA

Muestra una única estadística, tal como aparece en la salida del comando list.

show PREFIJO_ESTADÍSTICA*

Muestra todas las estadísticas cuyos nombres comienzan con el PREFIJO_ESTADÍSTICA proporcionado, como una lista separada por comas. Solo se permite un comodín (final).

status

Muestra estadísticas de uso. Esto solo funciona si el servidor se ejecuta en modo guardián.

token-login MÓDULO RANURA PIN

Inicia sesión en una ranura PKCS#11. Solo necesitas iniciar sesión una vez por ranura, incluso si tienes varias claves en una sola ranura. Solo disponible si PowerDNS fue compilado con soporte PKCS#11.

uptime

Muestra el tiempo de actividad del servidor en ejecución.

version

Imprime la versión del demonio pdns en ejecución.
