NOMBRE

pdfatfi - Programa de ayuda para el paquete LaTeX attachfile2.

SINOPSIS

pdfatfi <comando> [<opciones>] <archivo[.atfi]>

DESCRIPCIÓN

Programa auxiliar para el paquete LaTeX attachfile2.

Este paquete también intenta obtener y añadir datos de metainformación, como tamaño de archivo, fecha de archivo, suma de comprobación, ....

El script pdfatfi.pl se proporciona para su uso con versiones antiguas de pdfTeX y XeTeX que no proporcionan acceso a metadatos de archivo.

El uso del script Perl no es obligatorio. Estos datos pueden ser mostrados por los visores de PDF, pero no son un requisito de la especificación de PDF.

El paquete attachfile2 y el script Perl se comunican a través de un archivo auxiliar con extensión .atfi. El script se utiliza entre dos ejecuciones de LaTeX y actualiza el archivo auxiliar.

latex test
pdfatfi test
latex test
dvips test
ps2pdf test.ps test.pdf

OPCIONES

Se admiten varias opciones

--help
Mostrar texto de ayuda.
--version
Imprimir número de versión
--(no)quiet
Suprimir/no suprimir mensajes
--(no)verbose
Impresión detallada (no detallada).
--(no)debug
Información de depuración impresa (no impresa)
