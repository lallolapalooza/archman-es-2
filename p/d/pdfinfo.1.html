pdfinfo(1) Manual de Comandos Generales pdfinfo(1)

NOMBRE

pdfinfo - Extractor de información de documentos en formato Portable Document Format (PDF) (versión 3.03)

SINOPSIS

pdfinfo [opciones] [archivo-PDF]

DESCRIPCIÓN

Pdfinfo imprime el contenido del diccionario ´Info' (más alguna otra información útil) de un archivo en formato Portable Document Format (PDF).

Si archivo-PDF es ´-', lee el archivo PDF desde la entrada estándar (stdin).

El diccionario ´Info' contiene los siguientes valores:

título
tema
palabras clave
autor
creador
productor
fecha de creación
fecha de modificación

Además, se imprime la siguiente información:

metadatos personalizados (sí/no)
flujo de metadatos (sí/no)
etiquetado (sí/no)
propiedades de usuario (sí/no)
sospechosos (sí/no)
formulario (AcroForm / XFA / ninguno)
javascript (sí/no)
número de páginas
indicador cifrado (sí/no)
permisos de impresión y copia (si está cifrado)
tamaño de página
tamaño de archivo
linealizado (sí/no)
versión de PDF
metadatos (solo si se solicita)

Las opciones -listenc, -meta, -js, -struct y -struct-text solo imprimen la información solicitada. El diccionario 'Info' y los datos relacionados enumerados anteriormente no se imprimen. Como máximo, se puede utilizar una de estas cinco opciones.

OPCIONES

-f número
Especifica la primera página a examinar. Si se solicitan varias páginas usando las opciones "-f" y "-l", se imprime el tamaño de cada página solicitada (y, opcionalmente, los recuadros de delimitación para cada página solicitada). De lo contrario, solo se examina la página uno.
-l número
Especifica la última página a examinar.
-box
Imprime los recuadros de delimitación de la página: MediaBox, CropBox, BleedBox, TrimBox y ArtBox.
-meta
Imprime los metadatos a nivel de documento. (Este es el flujo "Metadata" del objeto Catálogo del archivo PDF).
-custom
Imprime metadatos personalizados y estándar.
-js
Imprime todo el JavaScript en el PDF.
-struct
Imprime la estructura lógica del documento de un archivo PDF etiquetado.
-struct-text
Imprime el contenido textual junto con la estructura del documento de un archivo PDF etiquetado. Tenga en cuenta que la extracción de texto de esta manera puede ser lenta para archivos PDF grandes. (Implica -struct).
-url
Imprime todas las URL en el PDF. Solo se enumeran los tipos de URL soportados por Poppler. Actualmente, esto se limita a las Anotaciones. Nota: solo se enumeran las URL referenciadas por los objetos PDF, como las Anotaciones de Enlace. pdfinfo no intenta extraer cadenas que coincidan con http://... del contenido de texto.
-isodates
Imprime las fechas en formato ISO-8601 (incluyendo la zona horaria).
-rawdates
Imprime las cadenas de fecha sin procesar (sin decodificar), directamente del archivo PDF.
-dests
Imprime una lista de todas las destinaciones nombradas. Si se especifica un rango de páginas usando "-f" y "-l", solo se enumeran las destinaciones dentro de ese rango.
-enc nombre-codificación
Establece la codificación a utilizar para la salida de texto. Por defecto es "UTF-8".
-listenc
Enumera las codificaciones disponibles.
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionar esta contraseña omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña del usuario para el archivo PDF.
-v
Imprime la información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes).

CÓDIGOS DE SALIDA

Las herramientas Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
99
Otro error.
