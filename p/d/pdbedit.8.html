PDBEDIT(8) Herramientas de Administración de Sistemas PDBEDIT(8)

NOMBRE

pdbedit - administrar la base de datos SAM (Base de datos de Usuarios de Samba)

SINOPSIS

pdbedit [-L|--list] [-v|--verbose] [-w|--smbpasswd-style] [-u|--user=USUARIO] [-N|--account-desc=CADENA] [-f|--fullname=CADENA] [-h|--homedir=CADENA] [-D|--drive=CADENA] [-S|--script=CADENA] [-p|--profile=CADENA] [-I|--domain=CADENA] [-U|--user SID=CADENA] [-M|--machine SID=CADENA] [-a|--create] [-r|--modify] [-m|--machine] [-x|--delete] [-b|--backend=CADENA] [-i|--import=CADENA] [-e|--export=CADENA] [-g|--group] [-y|--policies] [--policies-reset] [-P|--account-policy=CADENA] [-C|--value=LARGO] [-c|--account-control=CADENA] [--force-initialized-passwords] [-z|--bad-password-count-reset] [-Z|--logon-hours-reset] [--time-format=CADENA] [-t|--password-from-stdin] [-K|--kickoff-time=CADENA] [--set-nt-hash=CADENA] [-?|--help] [--usage] [-d|--debuglevel=NIVELDEBUG] [--debug-stdout] [--configfile=ARCHIVO] [--option=nombre=valor] [-l|--log-basename=ARCHIVOLOG] [--leak-report] [--leak-report-full]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de herramientas de samba(7).

El programa pdbedit se utiliza para administrar las cuentas de usuario almacenadas en la base de datos SAM y solo puede ser ejecutado por root.

La herramienta pdbedit utiliza la interfaz modular passdb y es independiente del tipo de base de datos de usuarios utilizada (actualmente existen bases de datos basadas en smbpasswd, ldap, nis+ y tdb, y se pueden añadir más sin modificar la herramienta).

Hay cinco formas principales de usar pdbedit: añadir una cuenta de usuario, eliminar una cuenta de usuario, modificar una cuenta de usuario, listar cuentas de usuario, importar cuentas de usuario.

OPCIONES

-L|--list

Esta opción lista todas las cuentas de usuario presentes en la base de datos de usuarios. Esta opción imprime una lista de pares usuario/uid separados por el carácter ':'.

Ejemplo: pdbedit -L

sorce:500:Simo Sorce
samba:45:Test User

-v|--verbose

Esta opción habilita el formato de listado detallado. Hace que pdbedit liste los usuarios en la base de datos, imprimiendo los campos de la cuenta en un formato descriptivo. Usado junto con -w también muestra los hashes de las contraseñas.

Ejemplo: pdbedit -L -v

---------------
username:       sorce
user ID/Group:  500/500
user RID/GRID:  2000/2001
Full Name:      Simo Sorce
Home Directory: \\BERSERKER\sorce
HomeDir Drive:  H:
Logon Script:   \\BERSERKER\netlogon\sorce.bat
Profile Path:   \\BERSERKER\profile
---------------
username:       samba
user ID/Group:  45/45
user RID/GRID:  1090/1091
Full Name:      Test User
Home Directory: \\BERSERKER\samba
HomeDir Drive:  
Logon Script:   
Profile Path:   \\BERSERKER\profile

-w|--smbpasswd-style

Esta opción establece el formato de listado "smbpasswd". Hará que pdbedit liste los usuarios en la base de datos, imprimiendo los campos de la cuenta en un formato compatible con el formato del archivo smbpasswd (ver smbpasswd(5) para detalles). En su lugar, cuando se usa junto con (-v) muestra los hashes de las contraseñas en la salida detallada.

Ejemplo: pdbedit -L -w

sorce:500:508818B733CE64BEAAD3B435B51404EE:
          D2A2418EFC466A8A0F6B1DBB5C3DB80C:
          [UX         ]:LCT-00000000:
samba:45:0F2B255F7B67A7A9AAD3B435B51404EE:
          BC281CE3F53B6A5146629CD4751D3490:
          [UX         ]:LCT-3BFA1E8D:

-u|--user nombre_usuario

Esta opción especifica el nombre de usuario que se utilizará para la operación solicitada (listado, adición, eliminación). Es *requerido* en las operaciones de adición, eliminación y modificación, y *opcional* en las operaciones de listado.

-f|--fullname nombre_completo

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará el nombre completo del usuario.

Ejemplo: -f "Simo Sorce"

-h|--homedir directorio_personal

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará la ruta de red del directorio personal del usuario.

Ejemplo: -h "\\BERSERKER\sorce"

-D|--drive unidad

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará la letra de unidad de Windows que se utilizará para mapear el directorio personal.

Ejemplo: -D "H:"

-S|--script script

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará la ruta del script de inicio de sesión del usuario.

Ejemplo: -S "\\BERSERKER\netlogon\sorce.bat"

--set-nt-hash

Esta opción se puede utilizar al modificar una cuenta de usuario. Establecerá la contraseña del usuario utilizando el valor nt-hash proporcionado como cadena hexadecimal. Útil para sincronizar contraseñas.

Ejemplo: --set-nt-hash 8846F7EAEE8FB117AD06BDD830B7586C

-p|--profile perfil

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará el directorio de perfil del usuario.

Ejemplo: -p "\\BERSERKER\netlogon"

-M|'--machine SID' SID|rid

Esta opción se puede utilizar al añadir o modificar una cuenta de máquina. Especificará el nuevo SID (Identificador de Seguridad) o rid del grupo primario de la máquina.

Ejemplo: -M S-1-5-21-2447931902-1787058256-3961074038-1201

-U|'--user SID' SID|rid

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará el nuevo SID (Identificador de Seguridad) o rid del usuario.

Ejemplo: -U S-1-5-21-2447931902-1787058256-3961074038-5004

Ejemplo: '--user SID' S-1-5-21-2447931902-1787058256-3961074038-5004

Ejemplo: -U 5004

Ejemplo: '--user SID' 5004

-c|--account-control control_cuenta

Esta opción se puede utilizar al añadir o modificar una cuenta de usuario. Especificará la propiedad de control de cuenta del usuario. Las banderas posibles se enumeran a continuación.
•N: No se requiere contraseña
•D: Cuenta deshabilitada
•H: Se requiere directorio personal
•T: Duplicado temporal de otra cuenta
•U: Cuenta de usuario normal
•M: Cuenta de usuario MNS
•W: Cuenta de confianza de estación de trabajo
•S: Cuenta de confianza de servidor
•L: Bloqueo automático
•X: La contraseña no expira
•I: Cuenta de confianza de dominio

Ejemplo: -c "[X ]"

-K|--kickoff-time

Esta opción se utiliza para modificar la hora de finalización de sesión de un usuario determinado. Utilice "never" como argumento para establecer la hora de finalización de sesión en ilimitada.

Ejemplo: pdbedit -K never usuario

-a|--create

Esta opción se utiliza para añadir un usuario a la base de datos. Este comando necesita un nombre de usuario especificado con la opción -u. Al añadir un nuevo usuario, pdbedit también pedirá la contraseña a utilizar.

Ejemplo: pdbedit -a -u sorce

new password:
retype new password

Nota
pdbedit no llama al script de sincronización de contraseñas de Unix si unix password sync ha sido configurado. Solo actualiza los datos en la base de datos de usuarios de Samba.

Si desea añadir un usuario y sincronizar la contraseña inmediatamente, utilice la opción -a de smbpasswd.

-t|--password-from-stdin

Esta opción hace que pdbedit lea la contraseña de la entrada estándar, en lugar de /dev/tty (como hace el programa passwd(1)). La contraseña debe ser enviada dos veces y terminada por un salto de línea cada vez.

-r|--modify

Esta opción se utiliza para modificar un usuario existente en la base de datos. Este comando necesita un nombre de usuario especificado con la opción -u. Se pueden especificar otras opciones para modificar las propiedades del usuario especificado. Esta bandera se mantiene por compatibilidad hacia atrás, pero ya no es necesario especificarla.

-m|--machine

Esta opción solo puede usarse junto con la opción -a. Hará que pdbedit añada una cuenta de confianza de máquina en lugar de una cuenta de usuario (-u nombre_usuario proporcionará el nombre de la máquina).

Ejemplo: pdbedit -a -m -u w2k-wks

-x|--delete

Esta opción hace que pdbedit elimine una cuenta de la base de datos. Necesita un nombre de usuario especificado con la opción -u.

Ejemplo: pdbedit -x -u bob

-b|--backend backend

Esta opción especifica la base de datos de contraseñas a utilizar. Las bases de datos disponibles son: smbpasswd, ldap, nisplus, tdb.

Ejemplo: -b ldap

-i|--import archivo

Esta opción se utiliza para importar usuarios desde un archivo. El archivo debe estar en formato smbpasswd.

Ejemplo: -i /root/smbpasswd.txt

-e|--export archivo

Esta opción se utiliza para exportar usuarios a un archivo. El archivo estará en formato smbpasswd.

Ejemplo: -e /root/smbpasswd.txt

-g|--group

Esta opción se utiliza para administrar grupos en lugar de usuarios.

Ejemplo: pdbedit -L -g

-y|--policies

Esta opción se utiliza para listar las políticas de cuenta de usuario.

Ejemplo: pdbedit -y

--policies-reset

Esta opción se utiliza para restablecer las políticas de cuenta de usuario a los valores predeterminados.

Ejemplo: pdbedit --policies-reset -u user

-P|--account-policy politica_cuenta

Esta opción se utiliza para establecer una política de cuenta de usuario. Las políticas disponibles son: `minpwdlen`, `maxpwdage`, `minpwdage`, `pwdComplexity`, `pwdhistory`, `lockout`, `lockoutduration`, `fDenyAcc` (denegar acceso).

Ejemplo: -P minpwdlen=8

Ejemplo: -P maxpwdage=42

-C|--value valor

Esta opción se utiliza para especificar el valor de una política de cuenta.

Ejemplo: -C 8

--force-initialized-passwords

Esta opción se utiliza para forzar la inicialización de contraseñas.

-z|--bad-password-count-reset

Esta opción se utiliza para restablecer el contador de contraseñas erróneas de un usuario.

Ejemplo: pdbedit -z -u user

-Z|--logon-hours-reset

Esta opción se utiliza para restablecer las horas de inicio de sesión de un usuario.

Ejemplo: pdbedit -Z -u user

--time-format formato

Esta opción se utiliza para especificar el formato de la hora.

Ejemplo: --time-format "%Y-%m-%d %H:%M:%S"

-d|--debuglevel nivel_debug

Establece el nivel de depuración. Un valor mayor produce más salida.

--debug-stdout

Imprime la salida de depuración en la salida estándar.

--configfile archivo

Establece el archivo de configuración a utilizar.

--option nombre=valor

Establece una opción de Samba.

-l|--log-basename archivo_log

Establece el nombre base para los archivos de registro.

--leak-report

Genera un informe de fugas de memoria.

--leak-report-full

Genera un informe completo de fugas de memoria.

EJEMPLOS

Listar todos los usuarios:

pdbedit -L

Listar todos los usuarios con detalles:

pdbedit -L -v

Crear un nuevo usuario llamado 'bob':

pdbedit -a -u bob

Eliminar al usuario 'bob':

pdbedit -x -u bob

Modificar el directorio personal y la unidad de disco del usuario 'bob':

pdbedit -r -u bob -h "\\server\share\bob" -D H:

Establecer la cuenta de usuario 'bob' como deshabilitada:

pdbedit -c "[D ]" -u bob

Establecer la cuenta de usuario 'bob' para que la contraseña no expire nunca:

pdbedit -c "[X ]" -u bob

Importar usuarios desde un archivo:

pdbedit -i /root/smbpasswd.txt

Exportar usuarios a un archivo:

pdbedit -e /root/smbpasswd.txt

Restablecer el contador de contraseñas erróneas para el usuario 'bob':

pdbedit -z -u bob

Restablecer las horas de inicio de sesión para el usuario 'bob':

pdbedit -Z -u bob

VER TAMBIÉN

smbpasswd(8), samba(7), smb.conf(5)

NAME

pdbedit - edit Samba user accounts database

SYNOPSIS

pdbedit [global options] {command} [command options]

DESCRIPTION

pdbedit is a utility that allows a system administrator to manage the Samba user accounts database. This database can be stored in a number of different backends, and this utility allows for manipulation of these accounts regardless of the backend.

When Samba is configured to use the standard smbpasswd file backend, this utility essentially provides a front-end to the smbpasswd command.

When Samba is configured to use an LDAP backend, this utility provides a way to manipulate the user accounts stored in the LDAP directory.

When Samba is configured to use a TDB database backend, this utility provides a way to manipulate the user accounts stored in the TDB database.

Please note that for security reasons, pdbedit must be run as root.

OPTIONS

-i|--import passdb-backend

Use a different passdb backend to retrieve users than the one specified in smb.conf. Can be used to import data into your local user database.

This option will ease migration from one passdb backend to another.

Example: pdbedit -i smbpasswd:/etc/smb.conf.old

-e|--export passdb-backend

Exports all currently available users to the specified password database backend.

This option will ease migration from one passdb backend to another and will ease backing up.

Example: pdbedit -e smbpasswd:/root/samba-users.backup

-g|--group

If you specify -g, then -i in-backend -e out-backend applies to the group mapping instead of the user database.

This option will ease migration from one passdb backend to another and will ease backing up.

-b|--backend passdb-backend

Use a different default passdb backend.

Example: pdbedit -b xml:/root/pdb-backup.xml -l

-P|--account-policy account-policy

Display an account policy

Valid policies are: minimum password age, reset count minutes, disconnect time, user must logon to change password, password history, lockout duration, min password length, maximum password age and bad lockout attempt.

Example: pdbedit -P "bad lockout attempt"

account policy value for bad lockout attempt is 0

-C|--value account-policy-value

Sets an account policy to a specified value. This option may only be used in conjunction with the -P option.

Example: pdbedit -P "bad lockout attempt" -C 3

account policy value for bad lockout attempt was 0
account policy value for bad lockout attempt is now 3

-y|--policies

If you specify -y, then -i in-backend -e out-backend applies to the account policies instead of the user database.

This option will allow one to migrate account policies from their default tdb-store into a passdb backend, e.g. an LDAP directory server.

Example: pdbedit -y -i tdbsam: -e ldapsam:ldap://my.ldap.host

--force-initialized-passwords

This option forces all users to change their password upon next login.

-N|--account-desc description

This option can be used while adding or modifying a user account. It will specify the user's description field.

Example: -N "test description"

-Z|--logon-hours-reset

This option can be used while adding or modifying a user account. It will reset the user's allowed logon hours. A user may login at any time afterwards.

Example: -Z

-z|--bad-password-count-reset

This option can be used while adding or modifying a user account. It will reset the stored bad login counter from a specified user.

Example: -z

--policies-reset

This option can be used to reset the general password policies stored for a domain to their default values.

Example: --policies-reset

-I|--domain

This option can be used while adding or modifying a user account. It will specify the user's domain field.

Example: -I "MYDOMAIN"

--time-format

This option is currently not being used.

-?|--help

Print a summary of command line options.

--usage

Display brief usage message.

-d|--debuglevel=level

level is an integer from 0 to 10. The default value if this parameter is not specified is 1 for client applications.

The higher this value, the more detail will be logged to the log files about the activities of the server. At level 0, only critical errors and serious warnings will be logged. Level 1 is a reasonable level for day-to-day running - it generates a small amount of information about operations carried out.

Levels above 1 will generate considerable amounts of log data, and should only be used when investigating a problem. Levels above 3 are designed for use only by developers and generate HUGE amounts of log data, most of which is extremely cryptic.

Note that specifying this parameter here will override the log level parameter in the /etc/samba/smb.conf file.

--debug-stdout

This will redirect debug output to STDOUT. By default all clients are logging to STDERR.

--configfile=<configuration file>

The file specified contains the configuration details required by the client. The information in this file can be general for client and server or only provide client specific like options such as client smb encrypt. See /etc/samba/smb.conf for more information. The default configuration file name is determined at compile time.

--option=<name>=<value>

Set the smb.conf(5) option "<name>" to value "<value>" from the command line. This overrides compiled-in defaults and options read from the configuration file. If a name or a value includes a space, wrap whole --option=name=value into quotes.

-l|--log-basename=logdirectory

Base directory name for log/debug files. The extension ".progname" will be appended (e.g. log.smbclient, log.smbd, etc...). The log file is never removed by the client.

--leak-report

Enable talloc leak reporting on exit.

--leak-report-full

Enable full talloc leak reporting on exit.

-V|--version

Prints the program version number.

NOTES

This command may be used only by root.
