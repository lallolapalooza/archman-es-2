NOMBRE

pdfbook2 - transforma archivos PDF en folletos para impresión a doble cara

SINOPSIS

pdfbook2 [ opciones ] ENTRADA [ ENTRADA, ...]

DESCRIPCIÓN

Crea archivos PDF listos para imprimir a partir de algunos archivos PDF de ENTRADA para la impresión de folletos. Los archivos resultantes deben imprimirse en formato horizontal/doble cara por el borde largo. El formato de papel predeterminado depende de la configuración regional y es elegido por pdfjam. Se puede establecer con la opción --paper.

Antes de componer el PDF, el archivo de ENTRADA se recorta al área relevante para descartar espacios en blanco innecesarios. En este proceso, todas las páginas se recortan a las mismas dimensiones. Se pueden definir márgenes adicionales en los bordes del folleto y en el medio donde ocurre el encuadernado.

La SALIDA se escribe en ENTRADA-book.pdf. Los archivos existentes se sobrescribirán. Todos los archivos de entrada se procesan por separado.

EJEMPLO

Para simplemente crear un folleto desde input.pdf, puedes usar

pdfbook2 input.pdf

para crear input-book.pdf. Para seleccionar un tipo de papel especial, puedes hacer

pdfbook2 --paper=letter input.pdf

para carta (letter) o

pdfbook2 --paper=a4paper input.pdf

para A4 estándar. Para aumentar el margen interior para el encuadernado, usa

pdfbook2 --inner-margin=200 input.pdf

para aumentar el valor predeterminado de 150. Puedes enviar múltiples archivos al script para su procesamiento como

pdfbook2 input1.pdf input2.pdf

lo que resultará en input1-book.pdf y input2-book.pdf.

OPCIONES

--version
muestra el número de versión del programa y sale
-h, --help
muestra el mensaje de ayuda y sale

GENERALES

-p, --paper=STR
Formato de las dimensiones del papel de salida como palabra clave de latex (por ejemplo, a4paper, letterpaper, legalpaper, ...)
-s, --short-edge
Formatea el folleto para impresión a doble cara por el borde corto
-n, --no-crop
Evita el recorte al área de contenido

MÁRGENES

-o, --outer-margin=INT
Define el margen exterior en el folleto (predeterminado: 40)
-i, --inner-margin=INT
Define el margen interior entre las páginas del folleto (predeterminado: 150)
-t, --top-margin=INT
Define el margen superior en el folleto (predeterminado: 30)
-b, --bottom-margin=INT
Define el margen inferior en el folleto (predeterminado: 30)

AVANZADO

--signature=INT
Define la signatura para el folleto que se pasa a pdfjam, debe ser múltiplo de 4 (predeterminado: 4)
--signature*=INT
Igual que --signature
--resolution=INT
Resolución utilizada por ghostscript en bp (predeterminado: 72)
