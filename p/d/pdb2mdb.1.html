NOMBRE

pdb2mdb - Convertidor de base de datos de programas a símbolos de depuración Mono.

SINOPSIS

pdb2mdb archivo_pdb

DESCRIPCIÓN

Esta herramienta se utiliza para convertir los símbolos de depuración generados por los compiladores de Microsoft en símbolos de depuración que pueden ser consumidos por el runtime de Mono.

Los archivos de base de datos de programas son archivos que terminan con la extensión .pdb y están asociados con una biblioteca o ejecutable (un archivo .dll o .exe). Este formato no fue documentado hasta hace poco, por lo que Mono utilizó su propio formato de archivo para almacenar información de depuración, el formato de depuración de Mono.

Al igual que los archivos PDB, la información de depuración de Mono se almacena en archivos que residen junto a un ejecutable de programa o una biblioteca.

Puede utilizar la herramienta pdb2mdb para transformar estos archivos PDB en archivos MDB que Mono puede consumir para depurar programas o proporcionar información de número de línea para rastreos de pila o excepciones.

LICENCIA

La herramienta pdb2mdb se distribuye bajo los términos de la Microsoft Public License (MS-PL). JB Evain escribió la herramienta. El soporte de lectura de PDB provino de Microsoft Common Compiler Infrastructure.
