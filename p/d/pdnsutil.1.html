PDNSUTIL(1) Servidor de Autoridad PowerDNS PDNSUTIL(1)

NOMBRE

pdnsutil - Control y comandos de PowerDNS para registros y DNSSEC

SINOPSIS

pdnsutil [OPCIÓN]... COMANDO

DESCRIPCIÓN

pdnsutil (anteriormente pdnssec) es un potente comando que actúa como una puerta de acceso amigable para el operador a DNSSEC y la gestión de zonas para PowerDNS. Detrás de escena, pdnsutil manipula una base de datos de backend de PowerDNS, lo que también significa que para muchas bases de datos, pdnsutil se puede ejecutar de forma remota y puede configurar material clave en diferentes servidores.

OPCIONES

-h, --help
Muestra un resumen de las opciones
-v, --verbose
Ser más detallado
-f, --force
Forzar una acción
-q, --quiet
Ser silencioso
--config-name <NOMBRE>
Nombre de configuración virtual
--config-dir <DIR>
Ubicación de pdns.conf. El valor predeterminado es /etc/powerdns.

COMANDOS

Hay muchos comandos disponibles. La mayoría de los comandos siguen el patrón pdnsutil <objeto> <acción> [argumentos...], donde <objeto> es un sustantivo y <acción> es un verbo; algunos comandos que no se aplican a ningún tipo de objeto en particular usan solo el verbo.

COMANDOS AUTOPRIMARY

autoprimary add IP SERVIDORDNS [CUENTA]

Agrega una entrada de autoprimary a la base de datos. Esto permite recibir actualizaciones de zonas de otros servidores.

autoprimary list

Lista todas las autoprimarias.

autoprimary remove IP SERVIDORDNS

Elimina una autoprimaria de la base de datos. No soportado por el backend BIND.

ZONA CATÁLOGO COMANDOS

catalog list-members CATÁLOGO

Lista todos los miembros de la zona de catálogo CATÁLOGO"

catalog set ZONA [CATÁLOGO]

Cambia el catálogo de ZONA a CATÁLOGO. Si CATÁLOGO se omite, elimina ZONA del catálogo en el que se encuentra.

METADATOS ZONA COMANDOS

metadata add ZONA TIPO VALOR [VALOR]...

Agrega VALOR al metadato TIPO existente para ZONA. Devolverá un error si TIPO no admite valores múltiples, usa metadata set para estos valores.

metadata get ZONA [TIPO]...

Obtiene los metadatos de la zona. Si no se proporciona TIPO, lista todos los conocidos.

metadata set ZONA TIPO [VALOR]...

Establece el metadato TIPO de la zona para ZONA a VALOR, reemplazando todos los valores existentes de TIPO. Un valor omitido lo borra.

RED COMANDOS

network list

Lista todas las redes definidas con sus vistas seleccionadas.

network set RED [VISTA]

Establece la VISTA para la red RED, o la elimina si no se proporciona el argumento VISTA.

REGISTRO ZONA COMANDOS

En estos comandos, el nombre de objeto rrset también puede escribirse como record.

rrset add ZONA NOMBRE TIPO [TTL] CONTENIDO

Agrega uno o más registros de NOMBRE y TIPO a ZONA con CONTENIDO y TTL opcional. Si no se establece TTL, se utilizará el default-ttl configurado. NOMBRE debe ser absoluto.

rrset delete ZONA NOMBRE TIPO

Elimina un RRSET con nombre de la zona. NOMBRE debe ser absoluto.

rrset hash ZONA NOMBRE_REGISTRO

Este comando de conveniencia hashea el nombre NOMBRE_REGISTRO según la configuración NSEC3 de ZONA. Se niega a hashear para zonas sin configuración NSEC3.

rrset replace ZONA NOMBRE TIPO [TTL] CONTENIDO [CONTENIDO...]

Reemplaza un NOMBRE existente en la zona ZONA con un nuevo conjunto.

RELACIONADOS TSIG COMANDOS

Estos comandos manipulan la información de claves TSIG en la base de datos. Algunos comandos requieren un ALGORITMO, que puede ser cualquiera de los siguientes:

  • hmac-md5
  • hmac-sha1
  • hmac-sha224
  • hmac-sha256
  • hmac-sha384
  • hmac-sha512

tsigkey activate ZONA NOMBRE {primary,secondary,producer,consumer}

Habilita AXFR autenticado por TSIG utilizando la clave NOMBRE para la zona ZONA. Esto establece los metadatos de zona TSIG-ALLOW-AXFR (primary/producer) o AXFR-MASTER-TSIG (secondary/consumer).

tsigkey deactivate ZONA NOMBRE {primary,secondary,producer,consumer}

Deshabilita AXFR autenticado por TSIG utilizando la clave NOMBRE para la zona ZONA.

tsigkey delete NOMBRE

Elimina la clave TSIG NOMBRE. Advertencia: esto no desactiva dicha clave.

tsigkey generate NOMBRE ALGORITMO

Genera una nueva clave TSIG con el nombre NOMBRE y el algoritmo especificado.

tsigkey import NOMBRE ALGORITMO CLAVE

Importa la CLAVE del algoritmo especificado como NOMBRE.

tsigkey list

Muestra una lista de todas las claves TSIG configuradas.

VISTAS COMANDOS

views add-zone VISTA ZONA..VARIANTE

Agrega la ZONA VARIANTE dada a una VISTA.

views del-zone VISTA ZONA..VARIANTE

Elimina una ZONA VARIANTE de una VISTA.

views list VISTA

Lista todas las zonas dentro de VISTA.

views list-all

Lista todos los nombres de vista.

MANIPULACIÓN ZONA COMANDOS

zone check ZONA

Comprueba la corrección de la zona ZONA.

zone check-all [exit-on-error]

Comprueba la corrección de todas las zonas, abortando al encontrar el primer error en cualquier zona si se especifica "exit-on-error".

zone clear ZONA

Borra los registros de la zona ZONA, pero deja la zona real y la configuración sin cambios.

zone create ZONA

zone import-key ZONE FILE [KSK,ZSK] [active,inactive] [published,unpublished]

Importa desde FILE una clave completa (privada) para la zona ZONE. El formato utilizado es compatible con BIND y NSD/LDNS. KSK o ZSK especifica las marcas que debe tener esta clave al importarla. Por defecto es KSK, activa y publicada. Imprime el id de la clave añadida.

zone import-key-pem ZONE FILE ALGORITHM {KSK,ZSK}

Importa desde FILE en formato PEM una clave completa (privada) para la zona ZONE con un ALGORITHM especificado. El formato utilizado es compatible con muchos productos de software no DNS. KSK o ZSK especifica las marcas que debe tener esta clave al importarla. Imprime el id de la clave añadida.

zone publish-key ZONE KEY_ID

Publica la clave con id KEY_ID dentro de la zona ZONE.

zone remove-key ZONE KEY_ID

Elimina una clave con id KEY_ID de la zona ZONE.

zone unpublish-key ZONE KEY_ID

Despublica la clave con id KEY_ID dentro de la zona ZONE.

OTROS/COMANDOS VARIOS

b2b-migrate OLD NEW

Migra datos de un backend a otro. Requiere launch=OLD,NEW en la configuración.

backend-cmd BACKEND CMD [CMD...]

Envía un comando de texto a un backend para su ejecución. Los backends GSQL aceptarán comandos SQL, otros backends pueden aceptar otras cosas. ¡Ten cuidado!

backend-lookup BACKEND NAME [TYPE [CLIENT_IP_SUBNET]]

Realiza una búsqueda de registro en el backend.

bench-db [FILE]

Realiza una prueba de rendimiento de la base de datos backend. FILE puede ser un archivo con una lista, una por línea, de nombres de zona para usar en esto. Si FILE no se especifica, se usa powerdns.com.

create-bind-db FILENAME

Crea una base de datos DNSSEC (sqlite3) en FILENAME para el backend BIND. Recuerda establecer bind-dnssec-db=*FILE* en tu pdns.conf.

hash-password [WORK_FACTOR]

Este comando de conveniencia lee una contraseña (no se muestra) de la entrada estándar y devuelve una versión cifrada y con sal, para usarla como contraseña del servidor web o clave de API. Se puede especificar un factor de trabajo scrypt opcional, en potencias de dos, de lo contrario, por defecto es 1024.

ipdecrypt IP_ADDRESS PASSPHRASE_OR_KEY [key]

Descifra una dirección IP según el estándar 'ipcipher'. Si la frase secreta es una clave base64, añade la palabra "key" después de ella.

ipencrypt IP_ADDRESS PASSPHRASE_OR_KEY [key]

Cifra una dirección IP según el estándar 'ipcipher'. Si la frase secreta es una clave base64, añade la palabra "key" después de ella.

list-algorithms [with-backend]

Lista todos los algoritmos DNSSEC soportados, opcionalmente listando también la biblioteca criptográfica utilizada si se especifica "with-backend".

test-schema ZONE

Prueba el esquema de la base de datos, esto crea la zona ZONE.

raw-lua-from-content TYPE CONTENT

Muestra el contenido de los registros en un formato adecuado para SpoofRawAction de dnsdist.
