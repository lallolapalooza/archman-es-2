pdftotext(1) Manual de comandos generales pdftotext(1)

NOMBRE

pdftotext - conversor de formato de documento portátil (PDF) a texto (versión 3.03)

SINOPSIS

pdftotext [opciones] archivo-PDF [archivo-texto]

DESCRIPCIÓN

Pdftotext convierte archivos en formato de documento portátil (PDF) a texto plano.

Pdftotext lee el archivo PDF, archivo-PDF, y escribe un archivo de texto, archivo-texto. Si no se especifica archivo-texto, pdftotext convierte archivo.pdf a archivo.txt. Si archivo-texto es ´-', el texto se envía a stdout. Si archivo-PDF es ´-', lee el archivo PDF desde stdin.

OPCIONES

-f número
Especifica la primera página a convertir.
-l número
Especifica la última página a convertir.
-r número
Especifica la resolución, en DPI. El valor predeterminado es 72 DPI.
-x número
Especifica la coordenada x de la esquina superior izquierda del área de recorte.
-y número
Especifica la coordenada y de la esquina superior izquierda del área de recorte.
-W número
Especifica el ancho del área de recorte en píxeles (el valor predeterminado es 0).
-H número
Especifica la altura del área de recorte en píxeles (el valor predeterminado es 0).
-layout
Mantiene (en la medida de lo posible) la disposición física original del texto. El valor predeterminado es "deshacer" la disposición física (columnas, guiones, etc.) y generar el texto en orden de lectura.
-fixed número
Asume texto de ancho fijo (o tabular), con el ancho de carácter especificado (en puntos). Esto fuerza el modo de disposición física.
-raw
Mantiene el texto en el orden del flujo de contenido. Este es un truco que a menudo "deshace" el formato de columnas, etc. Ya no se recomienda el uso del modo raw.
-nodiag
Descarta el texto diagonal (es decir, el texto que no está cerca de ninguno de los ejes de 0, 90, 180 o 270 grados). Esto es útil para omitir marcas de agua dibujadas sobre el texto principal.
-htmlmeta
Genera un archivo HTML simple, incluyendo la información meta. Esto simplemente envuelve el texto en <pre> y </pre> y antepone las cabeceras meta.
-bbox
Genera un archivo XHTML que contiene información de cuadros delimitadores para cada palabra del archivo.
-bbox-layout
Genera un archivo XHTML que contiene información de cuadros delimitadores para cada bloque, línea y palabra del archivo.
-tsv
Genera un archivo TSV que contiene la información de cuadros delimitadores para cada bloque, línea y palabra del archivo.
-cropbox
Utiliza el cuadro de recorte en lugar del cuadro de página con -bbox y -bbox-layout.
-colspacing número
Especifica cuánto espacio se permite después de una palabra antes de considerar que el texto adyacente es una nueva columna, medido como una fracción del tamaño de fuente. El valor predeterminado actual es 0.7, las versiones anteriores tenían un valor predeterminado de 0.3.
-enc nombre-codificación
Establece la codificación a utilizar para la salida de texto. El valor predeterminado es "UTF-8".
-listenc
Lista las codificaciones disponibles.
-eol unix | dos | mac
Establece la convención de fin de línea a utilizar para la salida de texto.
-nopgbrk
No inserta saltos de página (caracteres de avance de página) entre páginas.
-opw contraseña
Especifica la contraseña de propietario para el archivo PDF. Proporcionar esto omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña de usuario para el archivo PDF.
-q
No imprime ningún mensaje ni error.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes).

ERRORES GRAVES

Algunos archivos PDF contienen fuentes cuyas codificaciones se han estropeado hasta el punto de ser irreconocibles. No hay forma (salvo OCR) de extraer texto de estos archivos.

CÓDIGOS DE SALIDA

Las herramientas de Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
99
Otro error.
