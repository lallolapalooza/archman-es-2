PDFPC(1) Manual de comandos generales PDFPC(1)

NOMBRE

pdfpc - consola de presentación PDF con soporte para múltiples monitores

SINOPSIS

pdfpc [opciones] archivo.pdf

DESCRIPCIÓN

pdfpc es un visor de presentaciones basado en GTK que utiliza una salida multimonitor similar a Keynote para proporcionar metainformación al presentador durante la presentación. Es capaz de mostrar una ventana de presentación normal en una pantalla mientras muestra una vista de organizador más sofisticada en la otra, proporcionando información como una imagen de la siguiente diapositiva, así como el tiempo restante en la presentación. pdfpc procesa documentos PDF, que pueden ser creados usando casi todo el software de presentación moderno.

Por defecto, la vista del presentador aparece en el monitor primario y la vista de presentación en el segundo monitor (si tienes dos monitores).

-L, --list-actions
Lista las acciones compatibles
-M, --list-monitors
Lista los monitores conocidos por el sistema operativo
-n, --notes=P
Posición de las notas del presentador de segunda pantalla en la página PDF (izquierda, derecha, arriba, abajo o ninguna. Predeterminado: ninguna). Ten en cuenta que esto deshabilita la agrupación automática de diapositivas.
-N, --no-install
Permite probar pdfpc sin una instalación adecuada. Los iconos, los archivos de configuración, etc., se cargarán desde las ubicaciones de la ruta fuente. Principalmente destinado a desarrolladores.
-p, --rest-port
Puerto en el que se vincula el servidor REST. (Predeterminado: 8088)
-P, --page
Ir a una página específica directamente después del inicio. En caso de superposiciones, se mostrará la primera diapositiva.
-r, --page-transition=TRANSICIÓN
Establece la transición de página predeterminada. La especificación de TRANSICIÓN tiene el formato tipo[:duración[:ángulo[:alineación[:dirección]]]]. Ver la sección Transiciones de página para la lista de tipos soportados. duración está en segundos y se establece en 1 por defecto. Los valores aceptados para ángulo son 0/90/180/270; la alineación puede ser h[orizontal] o v[ertical] y la dirección i[nward] o o[utward]. Las últimas tres configuraciones opcionales no tienen sentido para algunos tipos de transición y pueden dejarse vacías. Ejemplos: "push", "dissolve:1.5", "wipe:1:90", "split:1::vertical:outward".
-R, --pdfpc-location=UBICACIÓN
Usar un archivo pdfpc personalizado.
-s, --switch-screens
Intercambiar la presentación y la pantalla del presentador.
-S, --single-screen
Forzar el uso de una sola pantalla
-t, --start-time=T
Hora de inicio de la presentación que se utilizará como cuenta atrás. (Formato: HH:MM (24h))
-T, --enable-auto-srt-load
Intentar cargar archivos de subtítulos de video automáticamente. Para cada medio de video, pdfpc agregará ".srt" a la URI del medio e intentará cargar un archivo de subtítulos (en formato SRT) desde esa ubicación.
-V, --enable-rest-server
Habilitar el servidor REST para el control remoto de pdfpc.
-W, --wayland-workaround
Habilitar una solución alternativa específica para Wayland. Esto podría solucionar problemas de escalado HiDPI.
-w, --windowed=MODO
Ejecutar en el modo de ventana dado (presentador|presentación|ambos|ninguno). El modo predeterminado es "presenter" (solo la ventana de presentación está en pantalla completa).
-X, --external-script=NOMBRE_ARCHIVO
Especificar un script que se ejecutará con la tecla 'X' (Shift+x) durante la presentación. El script debe ser ejecutable pero, por lo demás, puede estar escrito en cualquier idioma. El script se llama con los siguientes argumentos de línea de comandos:

• Nombre del archivo PDF
• Número total de diapositivas
• Número de diapositiva actual
• Número de diapositiva de usuario actual

Si el script sale con un valor de retorno distinto de cero, lo que el script escribió en la salida estándar se imprime en la consola. De lo contrario, no se imprime nada.

-Z, --size
Tamaño de la ventana de presentación en formato ancho:alto (fuerza el modo de ventana)
-1, --presenter-screen=MONITOR
Monitor a utilizar para la pantalla del presentador (ver la opción -M).
-2, --presentation-screen=MONITOR
Monitor a utilizar para la pantalla de presentación (ver la opción -M).

FEATURES

Caching / Pre-rendering

To allow fast changes between the presentation slides, a few consecutive PDF pages (the number is configurable) are pre-rendered and kept in memory. To avoid excessive memory consumption, cached are only slides that took a significant time to render; this threshold is configurable. In order to further reduce memory consumption, the pre-rendered and cached slides are selectively compressed. The compression factor is typically 10-30, however, it takes some CPU time to compress and uncompress, so there is a trade-off. Small images below a certain (configurable) threshold will not be compressed.

Please refer to the pdfpcrc(5) man page for options to fine-tune the caching algorithm.

Timer

If a duration is given (-d option), the timer will show a countdown with the given parameters. If no duration is specified (or if a value of 0 is given to the -d option), the timer will show how much time has been spent. The duration is stored automatically, so you do not need to repeat it for every invocation.

The timer is started if you are navigating away from the first page for the first time. This feature is quite useful as you may want to show the title page of your presentation while people are still entering the room and the presentation has not really begun yet. If you want to start over you can use the 'Ctrl + t' key which will make the presenter reset the timer.

If a duration is given, the timer also provides hints aiding the presenter to judge whether the talk would end on time. There are two modes in which pdfpc can operate. In the old (and the only one available up to, and including pdfpc-4.0.8) mode, at the moment the timer reaches the defined last-minutes value it will change color to indicate your talk is nearing its end, thus mimicking a chairman frantically pantomiming in front of you with five (four, three, ...) fingers up. A drawback of this approach is it is often too late at that moment to alter the presentation pace without ruining to some extent the rest of the talk. On the other hand, the warning indication provides an unnecessary distraction if you have been perfectly conveying the talk and the remaining time is adequate.

Contrary to that, in the new (default) mode, pdfpc tracks your progress continuously, calculating the expected time as (talk_duration)*(current_user_slide_number - 0.5)/(total_number_of_user_slides) and comparing it to the actual wall time since beginning of the talk. If these two numbers differ by more than 60 seconds, the timer changes its color to either orange (indicating you need to speed up) or a blueish one (need to slow down). Once the optimal progress is recovered, the timer becomes white again. In this mode, the last-minutes option (-l) has no effect. The previous behavior can be restored by setting the 'timer-pace-color' option to 'false' in the configuration file, see pdfpcrc(5).

In any case as soon as the timer reaches the zero mark (00:00:00), it will turn red and count further down showing a negative time, to provide information on how many minutes you are overtime.

Notes

Textual notes can be displayed for each slide. pdfpc understands the Markdown syntax, which allows for rendering anything from plain text to a very rich formatting, if so desired. A few types of PDF annotations are understood by pdfpc and will be automatically imported and displayed. The PDF annotations can be made using many PDF editors and even viewers; when using LaTeX, the pdfpc package (see below) provides a convenient macro. These "native" PDF notes cannot be edited in pdfpc.

In addition, while in the presentation mode, pressing 'Ctrl + n' will allow you to take or edit notes for the current slide. These notes are stored in the .pdfpc file. The native PDF annotations take precedence over these notes, i.e., if a note exists for a given slide in the .pdfpc file, any PDF annotation on that page will silently override it. While editing a note, the normal keybindings are disabled, e.g., you are not able to change slides. To exit the note editing mode, press the Escape key.

Although mixing the two types of notes is possible, for a given presentation one will likely want to have either only the "native" notes (produced by the same PDF authoring software used for making the slides), or only the "pdfpc" ones. Note that if the PDF presentation changes, the notes stored in the respective .pdfpc file may get out of sync.

pdfpc also supports old-style beamer notes (see the -n option), which are typeset on a half of the "virtual" slide twice as large as the real one. Note that due to a bug in beamer, the auto-grouping feature does not work with such presentations.

Overview mode

Pressing the Tab key enters the overview mode, where thumbnails of the slides are shown in a grid. You can select a slide to jump to with the mouse or with the arrow keys. You can also define overlays and the end slide (see next sections) in this mode. Press Escape to exit the mode without making an change.

Overlays

Many slide preparation systems allow for overlays, i.e. sets of slides that are logically grouped together as a single, changing slide. Examples include enumerations where bullet items are displayed one after another, or rough "animations", where parts of a picture change from slide to slide. Pdfpc includes facilities for dealing with such overlays.

In this description, we will differentiate between slides (i.e. pages in the PDF document) and "user slides", that are the logical slides. The standard forward movement command (page down, enter, etc.) moves through one slide at a time, as ex

ped. Esto significa que se recorre cada paso del superpuesto. El comando de movimiento hacia atrás funciona de manera diferente según si las diapositivas actuales y anteriores forman parte de un superpuesto:

•
Si la diapositiva actual forma parte de un superpuesto, simplemente saltamos a la diapositiva anterior. Esto significa que estamos en medio de un superpuesto y podemos saltar hacia adelante y hacia atrás a través de los pasos individuales del mismo.
•
Si la diapositiva actual no forma parte de un superpuesto (o si es la primera), pero las diapositivas anteriores sí lo hacen, saltamos a la diapositiva de usuario anterior. Esto significa que al retroceder en la presentación no tienes que pasar por cada paso del superpuesto; pdfpc solo muestra la primera diapositiva de cada superpuesto. Como normalmente se retrocede en una presentación solo cuando se busca una diapositiva concreta, esto es más conveniente.

Las combinaciones de teclas Shift + Av Pág arriba/abajo funcionan en base a las "diapositivas de usuario". Puedes usarlas para omitir el resto de un superpuesto o para saltar a la diapositiva de usuario anterior, ignorando el estado de la diapositiva actual.

Al pasar por un superpuesto, se pueden activar dos previsualizaciones adicionales en la vista del presentador, justo debajo de la vista principal, que muestran la diapositiva siguiente y la anterior en un superpuesto.

Pdfpc intenta encontrar estos superpuestos automáticamente buscando en las etiquetas de página del archivo PDF. Para LaTeX, esto funciona correctamente al menos con la clase beamer y también modificando manualmente los números de página (compilando con pdflatex). Si tu método preferido de producción de diapositivas no funciona correctamente con esta detección, puedes proporcionar esta información usando la tecla 'Ctrl + o' para cada diapositiva que forma parte de un superpuesto (¡excepto la primera!). La numeración de página también se adapta. Esta información se almacena automáticamente.

Diapositivas ocultas

Al preparar una presentación a partir de un conjunto de diapositivas existentes, a veces es útil marcar ciertas diapositivas para omitirlas durante la charla. La combinación 'Ctrl + h' alterna el atributo "oculto" de la diapositiva actual, haciéndola esencialmente invisible. Todavía es posible navegar a una diapositiva oculta ya sea en el modo Vista general, usando la acción Ir a ('g'), o presionando 'Shift + n' o 'Shift + p' para pasar a la diapositiva siguiente/anterior, respectivamente, ignorando el atributo "oculto".

Diapositiva final

A algunas personas les gusta tener diapositivas adicionales de respaldo después de la última diapositiva de la presentación real. Cosas como referencias bibliográficas o diapositivas que abordan preguntas especializadas son ejemplos típicos. Pdfpc te permite definir cuál es la última diapositiva de la presentación real a través de la tecla 'Ctrl + e'. Esto simplemente cambia la visualización del progreso en la pantalla del presentador, para tener una mejor visión general de cuántas diapositivas quedan.

Transiciones de página

Pdfpc soporta casi todas las transiciones de página animadas estándar de PDF: persianas, caja, cubierta, disolver, fundir, brillo (excepto la diagonal), empuje, dividir, descubrir y barrido, incluyendo varias alineaciones, ángulos y direcciones (cuando sea aplicable). Las transiciones están habilitadas solo para movimientos secuenciales (hacia adelante o hacia atrás); en este último caso, la transición se "invierte".

También se admite el avance automático de diapositivas.

Películas

Pdfpc puede reproducir películas incluidas en el archivo PDF. Las películas pueden iniciarse y detenerse haciendo clic dentro de su área. Para el presentador, se dibuja una barra de progreso en la parte inferior de la película. Esta se expande cuando el ratón pasa por encima, permitiendo desplazarse haciendo clic o arrastrando dentro de la barra de progreso. El cambio de diapositivas detiene automáticamente la reproducción, y las películas se reiniciarán al salir y volver a una diapositiva.

Las películas pueden incluirse en archivos PDF como "anotaciones de pantalla". En LaTeX, tales películas pueden añadirse a una presentación con el paquete "multimedia". Tenga en cuenta que la opción de reproducción automática aún no es compatible.

pdfpc también reproducirá películas enlazadas desde un hipervínculo de tipo "launch".

Vea nuestro sitio web ⟨URL: http://pdfpc.github.io/demo/pdfpc-video-example.zip ⟩ para una explicación detallada con ejemplos.

Modo puntero

Si es necesario, es posible activar un puntero que dibuja un punto rojo (por defecto) en el lugar señalado por el cursor del ratón en las pantallas tanto del presentador como de la presentación. También es posible aumentar y disminuir el tamaño del puntero. Además, cuando el puntero está activado, es posible resaltar un área de la diapositiva actual usando el movimiento de arrastre del ratón. El área fuera de la región seleccionada se atenuará. Puedes ampliar el área seleccionada presionando 'z'; presiona 'Escape' para salir del modo de zoom. Puedes resaltar otra región mientras estás ampliado, pero no habrá ninguna acción adicional al presionar 'z'. El dibujo también se deshabilita en este modo.

Modo foco

El modo foco es similar al modo puntero: un área circular que se mueve con el ratón y se puede ajustar en tamaño, pero en lugar de resaltar el punto con un color diferente, sombrea el fondo.

Modo dibujo

Es posible activar un modo que permite dibujar sobre las diapositivas con el cursor del ratón o una tableta conectada. Cuando el modo de dibujo está activado, se pueden realizar dibujos en la pantalla del presentador. Se mantendrá un dibujo separado en memoria para cada diapositiva (basado en los números de diapositiva del usuario, consolidando así las diapositivas del superpuesto). Actualmente, los dibujos no se guardan entre sesiones.

En el modo de dibujo, hay dos herramientas de dibujo, un bolígrafo y un borrador. Un indicador en la esquina inferior izquierda de la pantalla del presentador indicará cuál está activo. Cuando está en modo bolígrafo, el tamaño y color del bolígrafo se indicarán mediante el cursor. El tamaño del bolígrafo se puede aumentar o disminuir usando las teclas de acceso rápido especificadas en la configuración de teclas. Cuando la herramienta borrador está activa, el tamaño del cursor indica la cantidad a borrar.

El color del bolígrafo se puede cambiar a través de las teclas de acceso rápido o usando la caja de herramientas.

Si estás usando una tableta, la herramienta bolígrafo o borrador se seleccionarará en función de si la tableta informa de un dispositivo de entrada de bolígrafo o borrador que se está utilizando, anulando la selección normal de la herramienta de dibujo. También para los dispositivos de entrada sensibles a la presión, la presión afectará al grosor de la línea y al tamaño del borrador. Ambas características se pueden deshabilitar en el archivo de configuración, si se desea.

Plug and Play de monitores

Pdfpc puede gestionar el Plug and Play de monitores. Por ejemplo, si pdfpc se inició antes de que se conectara la pantalla de presentación al ordenador, pdfpc puede crear y mostrar la pantalla de presentación después de conectar la segunda pantalla. Esto permite al usuario ensayar las diapositivas y cambiar a una presentación normal sin tener la configuración completa en el ordenador de antemano.

Archivos pdfpc

Las notas, los superpuestos definidos por el usuario y alguna información adicional se almacenan en un archivo con la extensión "pdfpc". Cuando pdfpc se invoca con un archivo PDF, busca y carga automáticamente el archivo .pdfpc asociado, si existe. Esto significa que normalmente no tienes que tratar explícitamente con este tipo de archivos.

Además de la configuración interna, las siguientes opciones de línea de comandos se guardan en el archivo pdfpc para su uso posterior:

•
duration
•
end_time
•
last_minutes
•
notes (posición)
•
page_transition
•
start_time

Apariencia

Con GTK3 es posible modificar la apariencia de pdfpc. Hay dos ubicaciones donde pdfpc busca archivos. La ubicación predeterminada es /usr/share/pixmaps/pdfpc/pdfpc.css. Puede copiarse a $XDG_CONFIG_HOME/pdfpc/pdfpc.css y modificarse al gusto del usuario.

La geometría de varias vistas (la diapositiva actual/siguiente, etc.) en la ventana del presentador se puede ajustar en tiempo de ejecución en el modo "Personalización", que se activa presionando Shift+c. En este modo, aparecerán manejadores que se pueden arrastrar con el ratón. Sal del modo de personalización con Escape.

Integración de escritorio

Pdfpc proporciona una interfaz DBus que aparece en el bus de sesión como io.github.pdfpc. Otras aplicaciones pueden, en particular, ejecutar cualquier acción listada por --list-actions. También es posible controlar pdfpc desde la línea de comandos (y escribir scripts de shell) usando la utilidad dbus-send(1). Por ejemplo, para avanzar a la siguiente diapositiva, ejecuta

dbus-send --type=method_call --session --dest=io.github.pdfpc
/io/github/pdfpc io.github.pdfpc.TriggerAction string:next

Para acciones que requieren un argumento, usa TriggerActionArg, por ejemplo:

dbus-send --type=method_call --session --dest=io.github.pdfpc
/io/github/pdfpc io.github.pdfpc.TriggerActionArg string:switchMode
string:pointer

Además de TriggerAction*, la interfaz DBus de pdfpc expone el método GetNotes, tres propiedades (NumberOfOverlays, NumberOfSlides, Url) y dos señales (OverlayChange y SlideChange).

Control remoto

Pdfpc tiene un servidor REST incorporado. Cuando está habilitado (desactivado por defecto), permite controlar presentaciones a través de la red, por ejemplo, utilizando un dispositivo móvil como controlador inteligente. (Esta sección se ampliará con más detalles cuando la interfaz REST se estabilice lo suficiente).

Paquete LaTeX

Un pequeño paquete LaTeX está disponible para pdfpc en CTAN. Proporciona una forma conveniente de especificar notas y definir ciertas propiedades meta de la presentación. Para una documentación completa, consulte la documentación del paquete pdfpc. Puede abrirla con:

$ texdoc pdfpc

Existen varios programas con funcionalidad similar.

impressive(1) tiene agradables efectos de transición.

Muchos visores de PDF tienen modos de presentación a pantalla completa, pero sin vista previa de doble monitor, notas o temporizador. Estos incluyen zathura(1), evince(1) y okular(1).
