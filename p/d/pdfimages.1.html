pdfimages(1) Manual de Comandos Generales pdfimages(1)

NOMBRE

pdfimages - extractor de imágenes en formato de documento portátil (PDF) (versión 3.03)

SINOPSIS

pdfimages [opciones] archivo-PDF raíz-imagen

DESCRIPCIÓN

Pdfimages guarda imágenes de un archivo en formato de documento portátil (PDF) como archivos Portable Pixmap (PPM), Portable Bitmap (PBM), Portable Network Graphics (PNG), Tagged Image File Format (TIFF), JPEG, JPEG2000 o JBIG2.

Pdfimages lee el archivo PDF archivo-PDF, escanea una o más páginas y escribe un archivo por cada imagen, raíz-imagen-nnn.xxx, donde nnn es el número de imagen y xxx es el tipo de imagen (.ppm, .pbm, .png, .tif, .jpg, jp2, jb2e o jb2g). Si archivo-PDF es ´-', lee el archivo PDF desde la entrada estándar.

El formato de salida predeterminado es PBM (para imágenes monocromáticas) o PPM para imágenes no monocromáticas. Las opciones -png o -tiff cambian el formato de salida predeterminado a PNG o TIFF respectivamente. Si se especifican tanto -png como -tiff, las imágenes CMYK se escribirán como TIFF y todas las demás imágenes se escribirán como PNG. Además, las opciones -j, -jp2 y -jbig2 harán que las imágenes JPEG, JPEG2000 y JBIG2, respectivamente, en el archivo PDF se escriban en su formato nativo.

OPCIONES

-f número
Especifica la primera página a escanear.
-l número
Especifica la última página a escanear.
-png
Cambia el formato de salida predeterminado a PNG.
-tiff
Cambia el formato de salida predeterminado a TIFF.
-j
Escribe las imágenes en formato JPEG como archivos JPEG en lugar del formato predeterminado. El archivo JPEG es idéntico a los datos JPEG almacenados en el PDF.
-jp2
Escribe las imágenes en formato JPEG2000 como archivos JP2 en lugar del formato predeterminado. El archivo JP2 es idéntico a los datos JPEG2000 almacenados en el PDF.
-jbig2
Escribe las imágenes en formato JBIG2 como archivos JBIG2 en lugar del formato predeterminado. Los datos JBIG2 en PDF son del tipo incrustado. El tipo incrustado de JBIG2 tiene un archivo separado opcional que contiene datos globales. Los datos incrustados se escriben con la extensión .jb2e y los datos globales (si están disponibles) se escribirán con el mismo número de imagen con la extensión .jb2g. El contenido de ambos archivos es idéntico a los datos JBIG2 en el PDF.
-ccitt
Escribe las imágenes en formato CCITT como archivos CCITT en lugar del formato predeterminado. El archivo CCITT es idéntico a los datos CCITT almacenados en el PDF. Los archivos PDF contienen parámetros adicionales que especifican cómo decodificar los datos CCITT. Estos parámetros se traducen a opciones de entrada de fax2tiff y se escriben en un archivo .params con el mismo número de imagen. Los parámetros son:
-1
Codificación Group 3 1D
-2
Codificación Group 3 2D
-4
Codificación Group 4
-A
El principio de línea está alineado en un límite de byte
-P
El principio de línea no está alineado en un límite de byte
-X n
El ancho de la imagen en píxeles
-W
La codificación usa 1 para negro y 0 para blanco
-B
La codificación usa 0 para negro y 1 para blanco
-M
Los datos de entrada se rellenan del bit más significativo al menos significativo.
-all
Escribe las imágenes JPEG, JPEG2000, JBIG2 y CCITT en su formato nativo. Las imágenes CMYK se escriben como archivos TIFF. Todas las demás imágenes se escriben como archivos PNG. Esto es equivalente a especificar las opciones -png -tiff -j -jp2 -jbig2 -ccitt.
-list
En lugar de escribir las imágenes, lista las imágenes junto con diversa información para cada imagen. No especifique una raíz-imagen con esta opción.
La siguiente información se lista para cada imagen:
página
el número de página que contiene la imagen
num
el número de imagen
tipo
el tipo de imagen:
imagen - una imagen opaca
máscara - una imagen de máscara monocromática
smask - una imagen de máscara suave
plantilla - una imagen de máscara monocromática utilizada para pintar un color o patrón

Nota: La transparencia en las imágenes se representa en PDF utilizando una imagen separada para la imagen y la máscara/smask. La máscara/smask utilizada como parte de una imagen transparente siempre sigue inmediatamente a la imagen en la lista de imágenes.

ancho
ancho de la imagen (en píxeles)
alto
alto de la imagen (en píxeles)

Nota: el ancho/alto de la imagen es el tamaño de la imagen incrustada, no el tamaño al que se renderizará la imagen.

color
espacio de color de la imagen:
gris - Gris
rgb - RGB
cmyk - CMYK
lab - L*a*b
icc - Basado en ICC
índice - Color Indexado
sep - Separación
devn - DeviceN
comp
número de componentes de color
bpc
bits por componente
enc
codificación:
imagen - imagen ráster (puede estar comprimida con Flate o LZW pero no usa una codificación de imagen)
jpeg - Joint Photographic Experts Group
jp2 - JPEG2000
jbig2 - Joint Bi-Level Image Experts Group
ccitt - Fax CCITT Group 3 o Group 4
interp
"sí" si se va a realizar interpolación al escalar la imagen
ID de objeto
el ID del objeto del diccionario de imagen (número y generación)
x-ppp
La resolución horizontal de la imagen (en píxeles por pulgada) al renderizarla en la página PDF.
y-ppp
La resolución vertical de la imagen (en píxeles por pulgada) al renderizarla en la página PDF.
tamaño
El tamaño de la imagen incrustada en el archivo PDF. Se utilizan los siguientes sufijos: 'B' bytes, 'K' kilobytes, 'M' megabytes y 'G' gigabytes.
ratio
La relación de compresión de la imagen incrustada.
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionarla omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña del usuario para el archivo PDF.
-p
Incluye los números de página en los nombres de archivo de salida.
-print-filenames
Imprime los nombres de archivo de imagen en la salida estándar.
-q
No imprime ningún mensaje ni error.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes.)

CÓDIGOS DE SALIDA

Las herramientas Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
99
Otro error.
