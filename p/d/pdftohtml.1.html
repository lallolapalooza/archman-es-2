PDFTOHTML(1) Manual de Comandos Generales PDFTOHTML(1)

NOMBRE

pdftohtml - programa para convertir archivos PDF en HTML, XML e imágenes PNG

SINOPSIS

pdftohtml [opciones] <archivo.PDF> [<archivo.HTML> <archivo.XML>]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando pdftohtml. Esta página del manual fue escrita para la distribución Debian GNU/Linux porque el programa original no tiene una página del manual.

pdftohtml es un programa que convierte documentos PDF en HTML. Genera su salida en el directorio de trabajo actual. Si archivo.PDF es ´-', lee el archivo PDF desde la entrada estándar.

OPCIONES

A continuación se incluye un resumen de las opciones.

-h, -help
Muestra un resumen de las opciones.
-f <entero>
Primera página a imprimir.
-l <entero>
Última página a imprimir.
-q
No imprimir ningún mensaje ni error.
-v
Imprimir información de copyright y versión.
-p
Intercambiar enlaces .pdf con .html.
-c
Generar salida compleja.
-s
Generar un único HTML que incluya todas las páginas.
-dataurls
Usar URLs de datos en lugar de imágenes externas en HTML. No disponible en todas las plataformas.
-i
Ignorar imágenes.
-noframes
No generar marcos. No soportado en modo de salida compleja.
-stdout
Usar salida estándar.
-zoom <fp>
Ampliar el documento PDF (por defecto 1.5) (1 significa 72 DPI).
-xml
Salida para postprocesamiento XML.
-noroundcoord
No redondear coordenadas (solo con salida XML).
-enc <cadena>
Nombre de la codificación de texto de salida.
-opw <cadena>
Contraseña del propietario (para archivos cifrados).
-upw <cadena>
Contraseña del usuario (para archivos cifrados).
-hidden
Forzar la extracción de texto oculto.
-fmt
Formato de archivo de imagen para salida Splash (png o jpg). Si se selecciona complejo pero no se especifica -fmt, se asumirá -fmt png.
-nomerge
No fusionar párrafos.
-nodrm
Anular la configuración DRM del documento.
-wbt <fp>
Ajustar el umbral de separación de palabras en porcentaje. Por defecto es 10. La separación de palabras ocurre cuando la distancia entre dos caracteres adyacentes es mayor que este porcentaje de la altura del carácter.
-fontfullname
Muestra el nombre de la fuente sin sustituciones.
