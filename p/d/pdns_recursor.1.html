PDNS_RECURSOR(1) PowerDNS Recursor PDNS_RECURSOR(1)

NOMBRE

pdns_recursor - El binario del servidor recursivo PowerDNS

SINOPSIS

pdns_recursor [OPCIÓN]...

DESCRIPCIÓN

pdns_recursor es un servidor de nombres recursivo de alto rendimiento, simple y seguro. Actualmente da servicio a cientos de millones de conexiones a Internet.

El recursor se configura a través de un archivo de configuración, pero cada elemento de ese archivo puede ser anulado en la línea de comandos.

Esta página del manual enumera el conjunto central de características necesarias para que el PowerDNS Recursor funcione. Para obtener información completa y actualizada, diríjase a https://doc.powerdns.com/.

EJEMPLOS

Para escuchar en 192.0.2.53 y permitir que la subred 192.0.2.0/24 recursione, y ejecutarlo en segundo plano, ejecute:

# pdns_recursor --local-address=192.0.2.53 --allow-from=192.0.2.0/24 --daemon

Para detener el recursor manualmente, ejecute:

# rec_control quit-nicely

Sin embargo, la forma recomendada de iniciar y detener el recursor es utilizar systemctl(1) o el script init.d.

OPCIONES

Para una lista autorizada de opciones, consulte la documentación en línea en https://doc.powerdns.com/

--allow-from=<redes>
Si se establece, solo permita que estas redes separadas por comas, con máscara de red, recursione. Por ejemplo: 192.0.2.0/24,203.0.113.128/25.
--auth-zones=<zonas-aut>
Donde zona-aut es <nombre-zona>=<nombre-archivo>. Sirva nombre-zona desde nombre-archivo autoritativamente. Por ejemplo: ds9a.nl=/var/zones/ds9a.nl,powerdns.com=/var/zones/powerdns.com.
--chroot=<directorio>
chroot el proceso al directorio.
--client-tcp-timeout=<num>
Tiempo de espera en segundos al hablar con clientes TCP.
--config
Mostrar la configuración actual. Desde la versión 4.8.0 hay tres valores opcionales: --config=default para mostrar la configuración predeterminada. --config=diff para mostrar las opciones modificadas en la configuración actual. --config=check para verificar si la configuración actual tiene errores.
--config-dir=<directorio>
Ubicación del directorio de configuración (recursor.conf), el valor predeterminado depende de la opción SYSCONFDIR en el momento de la compilación, que suele ser /etc/powerdns. El valor predeterminado se puede encontrar con pdns_recursor --config | grep ' config-dir='.
--daemon
Operar como un demonio.
--entropy-source=<archivo>
Leer nueva entropía desde archivo, el valor predeterminado es /dev/urandom.
--export-etc-hosts
Si se establece, esta bandera exportará los nombres de host y direcciones IP mencionados en /etc/hosts.
--forward-zones=<zonas-reenv>
Donde zona-reenv es <nombre-zona>=<dirección>. Las consultas para nombre-zona se reenviarán a dirección. dirección debe ser una dirección IP, no un nombre de host (para evitar problemas de huevo y gallina). Ejemplo: forward-zones= ds9a.nl=213.244.168.210, powerdns.com=127.0.0.1.
--forward-zones-file=<nombre-archivo>
Similar a --forward-zones, pero lee las opciones desde nombre-archivo. nombre-archivo debe contener una zona por línea, como: ds9a.nl=213.244.168.210.
--help
Mostrar un resumen de opciones.
--hint-file=<nombre-archivo>
Cargar las pistas raíz desde este nombre-archivo
--local-address=<dirección>
Escuchar en dirección, separadas por espacios o comas. Las direcciones especificadas pueden incluir números de puerto; las que no incluyan números de puerto escucharán en --local-port.
--local-port=<puerto>
Escuchar en puerto.
--log-common-errors
Si debemos registrar errores bastante comunes.
--max-cache-entries=<num>
Número máximo de entradas en la caché principal.
--max-negative-ttl=<num>
número máximo de segundos para mantener una entrada de caché negativa en memoria.
--max-tcp-clients=<num>
Número máximo de clientes TCP simultáneos.
--max-tcp-per-client=<num>
Si se establece, número máximo de sesiones TCP por cliente (dirección IP).
--query-local-address=<dirección[,dirección...]>
Usar dirección como dirección IP de origen al enviar consultas.
--quiet
Suprimir el registro de preguntas y respuestas.
--server-id=<texto>
Devolver texto cuando se consulte por TXT 'id.server', el valor predeterminado es el nombre de host.
--serve-rfc1918
Activado por defecto, esto hace que el servidor sea autoritativamente consciente de: 10.in-addr.arpa, 168.192.in-addr.arpa y 16-31.172.in-addr.arpa, lo que ahorra carga en los servidores AS112. Partes individuales de estas zonas aún pueden cargarse o reenviarse.
--setgid=<gid>
Si se establece, cambiar el id de grupo a gid para mayor seguridad.
--setuid=<uid>
Si se establece, cambiar el id de usuario a uid para mayor seguridad.
--single-socket
Si se establece, usar solo un socket para consultas salientes.
--socket-dir=<directorio>
El socket de control vivirá en directorio.
--spoof-nearmiss-max=<num>
Si es distinto de cero, asumir suplantación después de este número de casi aciertos.
--trace
si debemos generar una gran cantidad de registros.
--version-string=<texto>
texto SE INFORMARÁ en las consultas version.pdns o version.bind.

pdns_recursor(1)

NOMBRE

pdns_recursor - PowerDNS Recursor

SINOPSIS

pdns_recursor [opciones]

DESCRIPCIÓN

El PowerDNS Recursor es un resolvedor DNS recursivo independiente. Está diseñado para ser muy rápido y eficiente, y proporciona varias características avanzadas, como el caché de consultas, la validación de DNSSEC y el filtrado de consultas.

EJEMPLOS

Iniciar el recursor con la configuración por defecto:

pdns_recursor

Iniciar el recursor con un archivo de configuración específico:

pdns_recursor --config-dir=/etc/powerdns

OPCIONES

--config-dir=directorio
Establece el directorio de configuración. Por defecto: /etc/powerdns.
--daemon
Ejecutar como un demonio en segundo plano.
--disable-syslog
Desactivar el registro en syslog.
--help
Mostrar mensaje de ayuda y salir.
--log-file=archivo
Registrar en el archivo especificado en lugar de syslog.
--pid-file=archivo
Escribir el PID en el archivo especificado.
--quiet
Ser menos verboso.
--version
Mostrar información de la versión y salir.

VER TAMBIÉN

pdnsutil(1)
