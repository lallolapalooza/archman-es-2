pdftopng(1) Manual de Comandos Generales pdftopng(1)

NOMBRE

pdftopng - Convertidor de formato de documento portátil (PDF) a formato de gráficos de red portátiles (PNG) (versión 4.05)

SINOPSIS

pdftopng [opciones] archivo-PDF raíz-PNG

DESCRIPCIÓN

Pdftopng convierte archivos de formato de documento portátil (PDF) a archivos de imagen en color, escala de grises o monocromáticos en formato de gráficos de red portátiles (PNG).

Pdftopng lee el archivo PDF, archivo-PDF, y escribe un archivo PNG por cada página, raíz-PNG-nnnnnn.png, donde nnnnnn es el número de página. Si raíz-PNG es ´-', la imagen se envía a la salida estándar (esto es probablemente útil solo cuando se convierte una sola página).

ARCHIVO DE CONFIGURACIÓN

Pdftopng lee un archivo de configuración al inicio. Primero intenta encontrar el archivo de configuración privado del usuario, ~/.xpdfrc. Si este no existe, busca un archivo de configuración a nivel del sistema, típicamente /etc/xpdfrc (pero esta ubicación puede cambiarse cuando se compila pdftopng). Consulte la página del manual xpdfrc(5) para obtener detalles.

OPCIONES

Muchas de las siguientes opciones se pueden establecer con comandos del archivo de configuración. Estas se enumeran entre corchetes con la descripción de la opción correspondiente de la línea de comandos.

-f número
Especifica la primera página a convertir.
-l número
Especifica la última página a convertir.
-r número
Especifica la resolución, en DPI. El valor predeterminado es 150 DPI.
-mono
Genera una imagen monocromática (en lugar de una imagen en color).
-gray
Genera una imagen en escala de grises (en lugar de una imagen en color).
-alpha
Genera un canal alfa en el archivo PNG. Esto solo es útil con archivos PDF que se han construido con un fondo transparente. La bandera -alpha no se puede usar con -mono.
-rot ángulo
Gira las páginas 0 (predeterminado), 90, 180 o 270 grados.
-freetype sí | no
Habilita o deshabilita FreeType (un rasterizador de fuentes TrueType / Type 1). Esto está configurado en "sí" por defecto. [archivo de configuración: enableFreeType]
-aa sí | no
Habilita o deshabilita el suavizado de fuentes. Esto está configurado en "sí" por defecto. [archivo de configuración: antialias]
-aaVector sí | no
Habilita o deshabilita el suavizado de vectores. Esto está configurado en "sí" por defecto. [archivo de configuración: vectorAntialias]
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionar esto anulará todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña del usuario para el archivo PDF.
-verbose
Imprime un mensaje de estado (a la salida estándar) antes de procesar cada página. [archivo de configuración: printStatusInfo]
-q
No imprima ningún mensaje ni error. [archivo de configuración: errQuiet]
-cfg archivo-configuración
Lee archivo-configuración en lugar de ~/.xpdfrc o el archivo de configuración del sistema.
-v
Imprime información de derechos de autor y versión.
-h
Imprime información de uso. (-help y --help son equivalentes.)

CÓDIGOS DE SALIDA

Las herramientas Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
98
Sin memoria.
99
Otro error.
