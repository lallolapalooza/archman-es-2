pdftops(1) Manual de comandos generales pdftops(1)

NOMBRE

pdftops - Convertidor de formato de documento portátil (PDF) a PostScript (versión 3.03)

SINOPSIS

pdftops [opciones] <archivo-PDF> [<archivo-PS>]

DESCRIPCION

Pdftops convierte archivos de formato de documento portátil (PDF) a PostScript para que puedan ser impresos.

Pdftops lee el archivo PDF, archivo-PDF, y escribe un archivo PostScript, archivo-PS. Si no se especifica archivo-PS, pdftops convierte archivo.pdf a archivo.ps (o archivo.eps con la opción -eps). Si archivo-PS es ´-', el PostScript se envía a stdout. Si archivo-PDF es ´-', Pdftops lee el archivo PDF de stdin.

OPCIONES

-f número
Especifica la primera página a imprimir.
-l número
Especifica la última página a imprimir.
-level1
Genera PostScript de Nivel 1. Los archivos PostScript resultantes serán significativamente más grandes (si contienen imágenes), pero se imprimirán en impresoras de Nivel 1. Esto también convierte todas las imágenes a blanco y negro. No se pueden dar más de una de las opciones de nivel de PostScript (-level1, -level1sep, -level2, -level2sep, -level3, -level3sep).
-level1sep
Genera PostScript separable de Nivel 1. Todos los colores se convierten a CMYK. Las imágenes se escriben con datos de flujo separados para los cuatro componentes.
-level2
Genera PostScript de Nivel 2. El Nivel 2 admite imágenes a color y compresión de imágenes. Esta es la configuración predeterminada.
-level2sep
Genera PostScript separable de Nivel 2. Todos los colores se convierten a CMYK. Se utilizan los operadores de convención de separación de PostScript para manejar colores personalizados (directos).
-level3
Genera PostScript de Nivel 3. Esto habilita todas las características de Nivel 2 más la incrustación de fuentes CID.
-level3sep
Genera PostScript separable de Nivel 3. El manejo de separaciones es el mismo que para -level2sep.
-eps
Genera un archivo PostScript Encapsulado (EPS). Un archivo EPS contiene una sola imagen, por lo que si utiliza esta opción con un archivo PDF de varias páginas, debe usar -f y -l para especificar una sola página. No se pueden dar más de una de las opciones de modo (-eps, -form).
-form
Genera un formulario PostScript que puede ser importado por software que entienda formularios. Un formulario contiene una sola página, por lo que si utiliza esta opción con un archivo PDF de varias páginas, debe usar -f y -l para especificar una sola página. La opción -level1 no se puede usar con -form. No se pueden dar más de una de las opciones de modo (-eps, -form).
-opi
Genera comentarios OPI para todas las imágenes y formularios que tienen información OPI. (Esta opción solo está disponible si pdftops fue compilado con soporte OPI).
-binary
Escribe datos binarios en PostScript de Nivel 1. Por defecto, pdftops escribe datos codificados en hexadecimal en PostScript de Nivel 1. Los datos binarios no son estándar en PostScript de Nivel 1 pero reducen el tamaño del archivo y pueden ser útiles cuando PostScript de Nivel 1 solo se requiere por su uso restringido de operadores PostScript.
-r número
Establece la resolución en DPI cuando pdftops rasteriza imágenes con transparencias o, para PostScript de Nivel 1, cuando pdftops rasteriza imágenes con máscaras de color. Por defecto, pdftops rasteriza imágenes a 300 DPI.
-noembt1
Por defecto, cualquier fuente Type 1 que esté incrustada en el archivo PDF se copia al archivo PostScript. Esta opción hace que pdftops las sustituya por fuentes base. Las fuentes incrustadas hacen los archivos PostScript más grandes, pero pueden ser necesarias para una salida legible.
-noembtt
Por defecto, cualquier fuente TrueType que esté incrustada en el archivo PDF se copia al archivo PostScript. Esta opción hace que pdftops las sustituya por fuentes base. Las fuentes incrustadas hacen los archivos PostScript más grandes, pero pueden ser necesarias para una salida legible. Además, algunos intérpretes PostScript no tienen rasterizadores TrueType.
-noembcidps
Por defecto, cualquier fuente CID PostScript que esté incrustada en el archivo PDF se copia al archivo PostScript. Esta opción deshabilita esa incrustación. No se intenta sustituir las fuentes CID PostScript no incrustadas.
-noembcidtt
Por defecto, cualquier fuente CID TrueType que esté incrustada en el archivo PDF se copia al archivo PostScript. Esta opción deshabilita esa incrustación. No se intenta sustituir las fuentes CID TrueType no incrustadas.
-passfonts
Por defecto, las referencias a fuentes de 8 bits no incrustadas en el archivo PDF se sustituyen por la fuente "Helvetica", "Times-Roman" o "Courier" más cercana. Esta opción pasa las referencias a fuentes no incrustadas al archivo PostScript.
-aaRaster sí | no
Habilita o deshabilita el anti-aliasing rasterizado. Por defecto es "no". pdftops puede necesitar rasterizar transparencias y máscaras de imagen de patrones en el PDF. Si el PostScript se va a imprimir, deje -aaRaster deshabilitado y establezca -r a la resolución de la impresora. Si el PostScript se va a ver, habilitar -aaRaster puede hacer que el texto rasterizado sea más fácil de leer.
-rasterize siempre | nunca | cuandosea_necesario
Por defecto, pdftops rasteriza páginas según sea necesario, por ejemplo, si contienen transparencias. Para forzar la rasterización, establezca -rasterize a "siempre". Use esto para eliminar fuentes. Para prevenir la rasterización, establezca -rasterize a "nunca". Esto puede producir archivos que se muestren incorrectamente.
-processcolorformat MONO8 | CMYK8 | RGB8
Establece el formato de color de proceso tal como se utiliza durante la rasterización y la reducción de transparencia. El valor predeterminado depende de otras configuraciones: Para -level1 el valor predeterminado es MONO8, para -level{1,2,3}sep o -overprint el valor predeterminado es CMYK8, y en todos los demás casos RGB8 es el valor predeterminado. Si se da -processcolorprofile, entonces -processcolorformat se infiere del perfil ICC especificado.
-processcolorprofile nombre-archivo
Establece el perfil ICC que se asume durante la rasterización y la reducción de transparencia.
-defaultgrayprofile perfil-gris-predeterminado-archivo
Si poppler está compilado con soporte de gestión de color, esta opción establece el espacio de color DefaultGray al perfil ICC almacenado en perfil-gris-predeterminado-archivo.
-defaultrgbprofile perfil-rgb-predeterminado-archivo
Si poppler está compilado con soporte de gestión de color, esta opción establece el espacio de color DefaultRGB al perfil ICC almacenado en perfil-rgb-predeterminado-archivo.
-defaultcmykprofile perfil-cmyk-predeterminado-archivo
Si poppler está compilado con soporte de gestión de color, esta opción establece el espacio de color DefaultCMYK al perfil ICC almacenado en perfil-cmyk-predeterminado-archivo.
-optimizecolorspace
Por defecto, las imágenes de mapa de bits en el PDF pasan a la salida PostScript en su espacio de color original, lo que produce resultados predecibles. Esta opción convierte imágenes RGB y CMYK en imágenes Gris si cada píxel de la imagen tiene componentes iguales. Esto puede solucionar problemas al realizar separaciones de color de PDFs que contienen imágenes incrustadas en blanco y negro codificadas como RGB.
-preload
precargar imágenes y formularios
pdftops(1)

NAME

pdftops - PDF-to-PostScript converter

SYNOPSIS

pdftops [-options] [-i] [PDF-file [PS-file]]

DESCRIPTION

The pdftops utility converts PDF files to PostScript. It can produce either level 1 or level 2 PostScript. By default, it produces level 2 PostScript.

OPTIONS

-paper size
Establece el tamaño del papel a uno de "letter", "legal", "A4" o "A3". Esto también puede establecerse a "match", que establecerá el tamaño del papel de cada página para que coincida con el tamaño especificado en el archivo PDF. Si no se especifican las opciones -paper, -paperw o -paperh, el valor predeterminado es hacer coincidir el tamaño del papel.
-paperw size
Establece el ancho del papel, en puntos.
-paperh size
Establece la altura del papel, en puntos.
-origpagesizes
Esta opción es la misma que "-paper match".
-nocrop
Por defecto, la salida se recorta a la CropBox especificada en el archivo PDF. Esta opción deshabilita el recorte.
-expand
Expande las páginas PDF más pequeñas que el papel para llenar el papel. Por defecto, estas páginas no se escalan.
-noshrink
No escala las páginas PDF más grandes que el papel. Por defecto, las páginas más grandes que el papel se reducen para que encajen.
-nocenter
Por defecto, las páginas PDF más pequeñas que el papel (después de cualquier escalado) se centran en el papel. Esta opción hace que se alineen en la esquina inferior izquierda del papel en su lugar.
-duplex
Establece la entrada pagedevice Duplex en el archivo PostScript. Esto indica a las impresoras con capacidad dúplex que activen el dúplex.
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionarla omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña del usuario para el archivo PDF.
-overprint
Habilita la emulación de sobreimpresión durante la rasterización. Para -processcolorformat siendo CMYK8 y el nivel de idioma siendo superior a 2, esta opción se establece en verdadero por defecto. Nota: Esta opción requiere que -processcolorformat sea CMYK8.
-q
No imprime ningún mensaje ni error.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes).

EXIT CODES

Las herramientas de Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos de PDF.
99
Otro error.
