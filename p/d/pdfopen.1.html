NOMBRE

pdfopen, pdfclose - abrir o cerrar un visor de PDF

SINOPSIS

pdfopen [ opciones ]  [ --archivo ]  archivo.pdf
pdfclose [ --archivo ]  archivo.pdf

OPCIONES

-h, --ayuda, -?
mostrar ayuda y salir.
-v, --version, -V
mostrar el número de versión y salir.
-p <n>, --página <n>
al iniciar el visor, mostrar la página <n> del documento (notas: no todos los visores soportan esta característica, e incluso en esos casos esta opción solo tiene efecto cuando el documento se carga inicialmente). Esta opción es anulada por -g.
-g <destino nombrado>, --ir-a <destino nombrado>
al iniciar el visor, mostrar la página del documento que contiene el destino nombrado (notas: no todos los visores soportan esta característica, e incluso en esos casos esta opción solo tiene efecto cuando el documento se carga inicialmente).
-r, --restaurar_foco
después de enviar comandos al visor de PDF, intentar restaurar el foco de entrada a la ventana que tenía el foco antes de que se enviaran los comandos.
-visor, --visor <ar9|ar9-tab|ar8|ar7|ar5|xpdf|evince>
usar (respectivamente) Adobe Reader 9 (en una ventana nueva), Adobe Reader 9 (en una pestaña nueva de un AR9 en ejecución, si existe), Adobe Reader 8, Adobe Reader 7, Adobe Reader 5, xpdf o evince como programa visor de PDF. Adobe Reader 9 (en una ventana nueva) es el predeterminado.

FUNDAMENTO

En ciertos puntos de la preparación de documentos TeX, muchas personas repiten un ciclo de "editar-compilar-ver". Dado que los visores de PDF como Adobe Acrobat Reader ("acroread") no actualizan automáticamente la pantalla cuando el archivo PDF cambia, este ciclo puede ser más engorroso de lo deseado. El programa pdfopen proporciona la capacidad de automatizar la recarga del documento PDF cuando este cambia.

Nota: parece haber poca necesidad para pdfclose en GNU/Linux, ya que (a diferencia de la situación en Windows) acroread no bloquea el archivo PDF, lo que impediría a pdftex (o a un convertidor de DVI a PDF) crear una nueva versión del archivo de salida PDF. Sin embargo, se proporciona pdfclose en caso de que alguien lo encuentre útil.

DESCRIPCIÓN

pdfopen busca una instancia del visor de PDF especificado (o predeterminado) que muestre el archivo PDF especificado. Si ya existe una instancia del visor dado mostrando el archivo dado, el visor recibe la instrucción de recargar el archivo. Si no se encuentra ninguna instancia de este tipo, pdfopen intenta ejecutar el visor especificado en el documento especificado.

El visor predeterminado es "acroread", que podría iniciar cualquiera de las varias versiones de Acrobat Reader, dependiendo de lo que esté instalado en su sistema. Sin embargo, los comandos para recargar el documento actual varían de una versión de acroread a otra; en consecuencia, si está utilizando una versión de acroread distinta de AR9, debería especificar explícitamente el programa visor.

Esta versión de pdfopen acepta las siguientes opciones de visor:
ar9, ar9-tab, ar8, ar7, ar5, xpdf, y evince.
La diferencia entre ar9 y ar9-tab es significativa cuando no hay ninguna instancia de AR9 mostrando el documento solicitado. En esta situación, mientras que ar9 solicitará a acroread que cree una nueva instancia de acroread (y por lo tanto abra una nueva ventana) usando el argumento -openInNewInstance, ar9-tab inicia acroread sin este argumento; si ya hay una instancia de acroread en ejecución, se abrirá una nueva pestaña en una ventana existente.

pdfclose busca uno de los visores de PDF anteriores mostrando el archivo dado e instruye al visor para "cerrar" la ventana. En la mayoría de los casos, el visor de PDF continúa ejecutándose, posiblemente mostrando ahora solo una ventana en blanco. (Este comportamiento varía algo de un visor de PDF a otro).

PORTABILIDAD Y DISPONIBILIDAD

Estos programas han sido probados en Slackware64 Versión 14.1 y algunas otras versiones / distribuciones de GNU/Linux. El código es razonablemente genérico y debería funcionar directamente con la mayoría de las implementaciones X11 recientes. (Los informes en contrario son bienvenidos, especialmente si vienen con correcciones robustas.)

Estos programas están diseñados para sistemas basados en X11. Si de alguna manera encuentra versiones compiladas de estos programas en un sistema que utiliza otro sistema de ventanas, es muy poco probable que le sean de utilidad.

Los programas fuente y binarios se pueden descargar desde CTAN://support/xpdfopen/ (por ejemplo, http://mirror.ctan.org/support/xpdfopen).

ADVERTENCIAS

Si usa ar9-tab para recargar el documento PDF y la instancia de acroread con el documento dado está mostrando actualmente algún otro documento, el comando hace que su documento se muestre, pero no se recargue.

pdfopen funciona buscando una ventana con un nombre (título de ventana) que coincida con el esperado para el visor y documento dados. Si por alguna razón el nombre de la ventana de su visor no es el esperado, pdfopen puede no funcionar para usted.

Con al menos AR9 y algunos gestores de ventanas, usar pdfopen para recargar el documento da el foco a la ventana de acroread, incluso si el cursor del ratón no está necesariamente en esa ventana. Esto puede ser molesto. La opción -reset_focus se puede usar para lidiar con este problema.

    pdfopen - opens a PDF document.

    SYNOPSIS

    pdfopen [options] pdf-file

    DESCRIPTION

    pdfopen opens a PDF document in the default PDF viewer.

    OPTIONS

    -p, --page page-number
    Open the PDF document to a specific page.
    -z, --zoom zoom-level
    Open the PDF document with a specific zoom level. The zoom level can be a percentage (e.g., 150) or one of the following keywords:
    • page-actual: Actual size.
    • page-width: Fit page width.
    • page-height: Fit page height.
    • page-fit: Fit entire page.
    -f, --find text
    Open the PDF document and search for the specified text.
    -a, --all
    Open all PDF files in the current directory.
    -h, --help
    Show help message and exit.
    -v, --version
    Show version information and exit.

    EXAMPLES

    Open a PDF document: 

    pdfopen document.pdf

    Open a PDF document to page 5: 

    pdfopen -p 5 document.pdf

    Open a PDF document with 150% zoom: 

    pdfopen -z 150 document.pdf

    Open a PDF document and search for "example": 

    pdfopen -f "example" document.pdf

    Open all PDF files in the current directory: 

    pdfopen -a
