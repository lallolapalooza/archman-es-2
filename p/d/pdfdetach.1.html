NOMBRE

pdfdetach - Extractor de archivos incrustados de documentos de formato portátil (PDF) (versión 3.03)

SINOPSIS

pdfdetach [opciones] [archivo-PDF]

DESCRIPCIÓN

Pdfdetach lista o extrae archivos incrustados (adjuntos) de un archivo PDF (Portable Document Format).

OPCIONES

Algunas de las siguientes opciones se pueden configurar mediante comandos en el archivo de configuración. Estos se enumeran entre corchetes con la descripción de la opción de línea de comandos correspondiente.

-list
Lista todos los archivos incrustados en el archivo PDF. Los nombres de archivo se convierten a la codificación de texto especificada por el interruptor "-enc".
-save número
Guarda el archivo incrustado especificado. Por defecto, esto usa el nombre de archivo asociado con el archivo incrustado (tal como lo imprime el interruptor "-list"); el nombre de archivo se puede cambiar con el interruptor "-o".
-savefile nombrearchivo
Guarda el archivo incrustado especificado. Por defecto, esto usa el nombre de archivo asociado con el archivo incrustado (tal como lo imprime el interruptor "-list"); el nombre de archivo se puede cambiar con el interruptor "-o".
-saveall
Guarda todos los archivos incrustados. Esto utiliza los nombres de archivo asociados con los archivos incrustados (tal como los imprime el interruptor "-list"). Por defecto, los archivos se guardan en el directorio actual; esto se puede cambiar con el interruptor "-o".
-o ruta
Establece el nombre de archivo utilizado al guardar un archivo incrustado con el interruptor "-save", o el directorio utilizado por "-saveall".
-enc nombre-codificación
Establece la codificación a utilizar para la salida de texto (nombres de archivos incrustados). Esto tiene por defecto "UTF-8".
-opw contraseña
Especifica la contraseña del propietario para el archivo PDF. Proporcionarla omitirá todas las restricciones de seguridad.
-upw contraseña
Especifica la contraseña de usuario para el archivo PDF.
-v
Imprime información de copyright y versión.
-h
Imprime información de uso. (-help y --help son equivalentes.)

CÓDIGOS DE SALIDA

Las herramientas Xpdf utilizan los siguientes códigos de salida:

0
Sin error.
1
Error al abrir un archivo PDF.
2
Error al abrir un archivo de salida.
3
Error relacionado con los permisos del PDF.
99
Otro error.
