PDFJADETEX(1) Manual de comandos generales PDFJADETEX(1)

NOMBRE

pdfjadetex - Salida PDF desde JadeTeX

SINOPSIS

pdfjadetex [opciones] [comandos]

DESCRIPCIÓN

Esta página del manual se derivó de la página del manual de pdfTeX y no pretende ser exhaustiva. La documentación completa de esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

pdfjadeTeX es una versión de TeX que puede crear archivos PDF así como archivos DVI.

El uso típico de pdfjadeTeX es con formatos pregenerados para los cuales se ha habilitado la salida PDF. El comando pdfjadetex utiliza el equivalente del formato plano JadeTeX.

El manejo de sus argumentos de línea de comandos por parte de pdfjadeTeX es similar al de LaTeX.

OPCIONES

Esta versión de pdfjadeTeX entiende las siguientes opciones de línea de comandos.

--fmt formato
Utiliza formato como el nombre del formato a utilizar, en lugar del nombre por el cual se llamó a pdfjadeTeX o una línea %&.
--help
Imprime el mensaje de ayuda y sale.
--ini
Ser pdfinitex, para volcar formatos; esto es implícitamente cierto si el programa se llama como pdfinitex.
--interaction modo
Establece el modo de interacción. El modo puede ser uno de batchmode, nonstopmode, scrollmode y errorstopmode. El significado de estos modos es el mismo que el de los \commands correspondientes.
--ipc
Envía la salida DVI o PDF a un socket además del archivo de salida habitual. Si esta opción está disponible es elección del instalador.
--ipc-start
Como --ipc, e inicia el servidor en el otro extremo también. Si esta opción está disponible es elección del instalador.
--kpathsea-debug mascara-de-bits
Establece las banderas de depuración de búsqueda de rutas según la máscara de bits. Consulte el manual de Kpathsea para obtener detalles.
--maketex fmt
Habilita mktexfmt, donde fmt debe ser uno de tex o tfm.
--no-maketex fmt
Inhabilita mktexfmt, donde fmt debe ser uno de tex o tfm.
--output-comment cadena
Utiliza cadena para el comentario del archivo DVI en lugar de la fecha.
--progname nombre
Finge ser el programa nombre. Esto afecta tanto al formato utilizado como a las rutas de búsqueda.
--shell-escape
Habilita la construcción \write18{comando}. El comando puede ser cualquier comando de shell Bourne. Esta construcción normalmente está deshabilitada por razones de seguridad.
--version
Imprime la información de la versión y sale.

AMBIENTE

Consulte la documentación de la biblioteca Kpathsearch (el nodo de especificaciones de rutas) para obtener detalles precisos sobre cómo se utilizan las variables de entorno. La utilidad kpsewhich se puede usar para consultar los valores de las variables.

Una advertencia: en la mayoría de los formatos de pdfjadeTeX, no se puede usar ~ en un nombre de archivo que se proporcione directamente a pdfjadeTeX, porque ~ es un carácter activo y, por lo tanto, se expande, no se toma como parte del nombre del archivo. Otros programas, como Metafont, no tienen este problema.

TEXMFOUTPUT
Normalmente, pdfjadeTeX coloca sus archivos de salida en el directorio actual. Si algún archivo de salida no se puede abrir allí, intenta abrirlo en el directorio especificado en la variable de entorno TEXMFOUTPUT. No hay un valor predeterminado para esa variable. Por ejemplo, si dices tex paper y el directorio actual no se puede escribir, si TEXMFOUTPUT tiene el valor /tmp, pdfjadeTeX intenta crear /tmp/paper.log (y /tmp/paper.pdf, si se produce alguna salida).
TEXINPUTS
Ruta de búsqueda para archivos \input y \openin. Probablemente debería comenzar con "." para que los archivos del usuario se encuentren antes que los archivos del sistema.
TEXFONTS
Ruta de búsqueda para archivos de métricas de fuentes (.tfm).
TEXFORMATS
Ruta de búsqueda para archivos de formato.
TEXPOOL
Ruta de búsqueda de cadenas internas de pdfinitex.
TEXEDIT
Plantilla de comando para cambiar al editor. El valor predeterminado, generalmente vi, se establece cuando se compila pdfjadeTeX.

ARCHIVOS

La ubicación de los archivos mencionados a continuación varía de un sistema a otro. Utilice la utilidad kpsewhich para encontrar sus ubicaciones.

pdfjadetex.pool
Texto codificado de los mensajes de pdfjadeTeX.
texfonts.map
Definiciones de mapeo de nombres de archivo.
*.tfm
Archivos de métricas para las fuentes de pdfjadeTeX.
*.fmt
Archivos de formato predigeridos de pdfjadeTeX (.fmt).

ERRORES

Esta versión de pdfjadeTeX no logra detectar el desbordamiento aritmético cuando se suman o restan dimensiones. Los casos en los que esto ocurre son raros, pero cuando sucede, el archivo DVI generado será inválido.
