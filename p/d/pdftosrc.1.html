pdftosrc(1) Manual general de comandos pdftosrc(1)

NOMBRE

pdftosrc - extraer archivo o flujo fuente de un archivo PDF

SINOPSIS

pdftosrc archivo-PDF [número-objeto-flujo]

DESCRIPCIÓN

Si solo se proporciona archivo-PDF como argumento, pdftosrc extrae el archivo fuente incrustado del primer objeto de flujo con /Type /SourceFile encontrado dentro de archivo-PDF y lo escribe en un archivo con el nombre /SourceName definido en dicho objeto de flujo PDF (ver ejemplo de aplicación a continuación).

Si se proporcionan ambos argumentos, archivo-PDF y número-objeto-flujo, y número-objeto-flujo es positivo, pdftosrc extrae y descomprime el flujo PDF del objeto dado por su número-objeto-flujo del archivo-PDF y lo escribe en un archivo llamado archivo-PDF.número-objeto-flujo, eliminando la terminación .pdf o .PDF del nombre original del archivo-PDF.

Un caso especial se relaciona con los flujos de objetos XRef que forman parte del estándar PDF a partir de PDF-1.5: si número-objeto-flujo es igual a -1, entonces pdftosrc descomprime el flujo XRef del archivo PDF y lo escribe en formato de tabla de referencia cruzada PDF legible por humanos en un archivo llamado archivo-PDF.xref (estos flujos XRef no se pueden extraer simplemente proporcionando su número de objeto).

En cualquier caso, se sobrescribirá un archivo existente con el nombre del archivo de salida.

OPCIONES

Ninguna.

ARCHIVOS

Solo el ejecutable pdftosrc.

ENTORNO

Ninguno.

DIAGNÓSTICOS

En caso de éxito, el código de salida de pdftosrc es 0, de lo contrario es 1.

Todos los mensajes van a stderr. Al invocar el programa, pdftosrc emite el número de versión actual del programa xpdf, en el que se basa pdftosrc:

pdftosrc version 3.01
Cuando pdftosrc ha tenido éxito con la escritura del archivo de salida, se emitirá uno de los siguientes mensajes:
Source file extracted to nombre-archivo-fuente
o
Stream object extracted to archivo-PDF.número-objeto-flujo
o
Cross-reference table extracted to archivo-PDF.xref

Cuando el objeto dado por el número-objeto-flujo no contiene un flujo, pdftosrc emite el siguiente mensaje de error:

Not a Stream object
Cuando no se puede abrir el archivo-PDF, el mensaje de error es:
Error: Couldn't open file 'archivo-PDF'.
Cuando pdftosrc encuentra un archivo PDF inválido, el mensaje de error (varias líneas) es:
Error: May not be a PDF file (continuing anyway)
(más líneas)
Invalid PDF file
También hay más mensajes de error de pdftosrc para varios tipos de archivos PDF dañados.

NOTAS

Un archivo fuente incrustado se escribirá sin cambios, es decir, no se descomprimirá en este proceso.

Solo se escribirá el flujo del objeto, es decir, no el diccionario de ese objeto.

Saber qué número-objeto-flujo consultar requiere información sobre el archivo PDF que debe obtenerse en otro lugar, por ejemplo, examinando el archivo PDF con un editor.

Las capacidades de extracción de flujos de pdftosrc (por ejemplo, con respecto a las versiones de PDF y tipos de filtro comprendidos) siguen las capacidades de la versión subyacente del programa xpdf.

Actualmente no se admite el número de generación del objeto de flujo. Se toma el valor predeterminado 0 (cero).

La redacción número-objeto-flujo no tiene nada que ver con los `object streams' introducidos por la Adobe PDF Reference, 5ª edición, versión 1.6.

EJEMPLOS

Al usar pdftex, se puede incrustar un archivo fuente en algún archivo-PDF utilizando primitivas de pdftex, como se ilustra en el siguiente ejemplo:

\immediate\pdfobj
stream attr {/Type /SourceFile /SourceName (myfile.zip)}


file{myfile.zip} \pdfcatalog{/SourceObject \the\pdflastobj\space 0 R}

Luego, este archivo zip se puede extraer del archivo-PDF llamando a pdftosrc archivo-PDF.

ERRORES

No se extraerán todos los archivos fuente incrustados, solo el primero que se encuentre.

Envíe informes de errores por correo electrónico a pdftex@tug.org.
