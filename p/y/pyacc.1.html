pyacc(1) Generador de analizadores sintácticos Pascal pyacc(1)

NOMBRE

pyacc - Compilador de compiladores Pascal Yacc.

USO

yacc [opciones] archivo-yacc[.y] [archivo-salida[.pas]]

OPCIONES SH

-v
Detallado: Pascal Yacc genera una descripción legible del analizador sintáctico generado, escrita en el archivo-yacc con la extensión nueva .lst.
-d
Depuración: TP Yacc genera un analizador sintáctico con salida de depuración.

DESCRIPCIÓN

TP Yacc es un programa que te permite preparar analizadores sintácticos a partir de la descripción de lenguajes de entrada mediante gramáticas similares a BNF. Simplemente especifica la gramática para tu lenguaje objetivo, aumentada con el código Turbo Pascal necesario para procesar las construcciones sintácticas, y TP Yacc traducirá tu gramática al código Turbo Pascal para una subrutina de análisis sintáctico correspondiente llamada yyparse.

TP Yacc analiza la gramática fuente contenida en archivo-yacc (con sufijo predeterminado .y) y escribe la subrutina de análisis sintáctico construida en el archivo de salida especificado (con sufijo predeterminado .pas); si no se especifica ningún archivo de salida, la salida va al archivo-yacc con el nuevo sufijo .pas. Si se encuentran errores durante la compilación, los mensajes de error se escriben en el archivo de lista (archivo-yacc con el nuevo sufijo .lst).

La rutina de análisis sintáctico generada, yyparse, se declara como:


function yyparse : Integer;

Esta rutina puede ser llamada por tu programa principal para ejecutar el analizador sintáctico. El valor de retorno de la rutina yyparse denota el éxito o el fracaso del analizador sintáctico (valores de retorno posibles: 0 = éxito, 1 = error de sintaxis irrecuperable o desbordamiento de la pila de análisis).

Similar a TP Lex, la plantilla de código para la rutina yyparse se puede encontrar en el archivo yyparse.cod. Las reglas para localizar este archivo son análogas a las de TP Lex (ver Sección `TP Lex').

La unidad de la biblioteca TP Yacc (YaccLib) es requerida por programas que usan analizadores sintácticos generados por Yacc; por lo tanto, tendrás que incluir una cláusula `uses` apropiada en tu programa o unidad que contenga la rutina del analizador sintáctico. La unidad YaccLib también proporciona algunas rutinas que se pueden utilizar para controlar las acciones del analizador sintáctico. Ver el archivo yacclib.pas para más información.
