NOMBRE

pyro - simula fuegos artificiales

SINOPSIS

pyro [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--count entero] [--frequency entero] [--scatter entero] [--fps]

DESCRIPCIÓN

El programa pyro simula fuegos artificiales, de forma similar a un programa de Macintosh con el mismo nombre.

OPCIONES

pyro acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si se está en una pantalla en color, simula estar en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--count entero
Cuántas partículas se permitirán en la pantalla a la vez. Por defecto 600.
--frequency entero
Con qué frecuencia se lanzarán nuevos proyectiles. Por defecto 30.
--scatter entero
Cuántas partículas aparecerán cuando un proyectil explote. Por defecto 100. El número real utilizado está entre N y N+(N/2).
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anule los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
