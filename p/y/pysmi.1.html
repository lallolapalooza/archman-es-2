DOCUMENTACIÓN

Documentación de PySMI

La biblioteca PySMI es altamente modular. El componente de nivel superior se llama compiler (compilador) y actúa como el objeto principal que utiliza el usuario. La mayoría de los otros componentes se conectan al objeto compiler antes de su uso.

Normalmente, el usuario solicita al compiler que realice cierta transformación de un módulo MIB nombrado. El compilador:

  • Busca en sus fuentes de datos el módulo MIB dado (identificado por nombre) anotando sus últimas fechas de modificación.
  • Busca en los repositorios gestionados por el compilador de módulos MIB ya convertidos, módulos que sean más recientes que el módulo MIB fuente correspondiente.
  • Si se encuentra un módulo MIB transformado recientemente, el procesamiento se detiene aquí.
  • De lo contrario, el compilador pasa el contenido del módulo MIB ASN.1 al componente lexer (analizador léxico).
  • El lexer devuelve una secuencia de contenidos MIB ASN.1 tokenizados. El compilador luego pasa esa secuencia de tokens al componente parser (analizador sintáctico).
  • El parser ejecuta el algoritmo LR sobre el MIB tokenizado, transformando así el contenido del MIB en un Árbol de Sintaxis Abstracta (AST) y también anotando qué otros módulos MIB se hacen referencia desde el MIB que se está analizando.
  • En caso de fallo del parser, lo que usualmente es una indicación de sintaxis MIB ASN.1 rota, el compilador puede intentar obtener el contenido MIB pre-transformado de la fuente configurada. Este proceso se llama borrowing (préstamo) en PySMI.
  • En caso de finalización exitosa del parser, el compilador pasará el AST producido al componente code generator (generador de código).
  • El generador de código recorre su AST de entrada y realiza la transformación de datos real.
  • Los pasos anteriores pueden repetirse para cada uno de los módulos MIB a los que se hace referencia a medida que el parser los identifica. Una vez que no quedan dependencias no resueltas, el compilador llamará a su componente writer (escritor) para almacenar todos los módulos MIB transformados.

La ubicación de los módulos MIB ASN.1 y el sabor de su sintaxis, así como el formato de transformación deseado, se determinan por los componentes respectivos elegidos y configurados para el compilador.

La herramienta mibdump

La herramienta mibdump.py es una interfaz de línea de comandos para la biblioteca PySMI. Esta herramienta se puede utilizar para descargar y transformar automáticamente módulos MIB SNMP a varios formatos.

Especificación de la fuente MIB

La opción --mib-source se puede proporcionar varias veces. Cada instancia de --mib-source debe especificar una URL donde se buscarán y descargarán los módulos MIB ASN.1. En este momento se admiten tres métodos de fuente MIB:

  • Archivos locales. Puede ser un directorio de nivel superior donde se encuentran los archivos MIB. Los subdirectorios también se recorrerán automáticamente. Ejemplo: file:///usr/share/snmp
  • Archivos ZIP que contienen archivos MIB. Los subdirectorios y los archivos ZIP incrustados se recorrerán automáticamente. Ejemplo: zip://mymibs.zip
  • HTTP/HTTPS. Una URL completamente especificada donde el nombre del módulo MIB está especificado por un marcador @mib@. Cuando se busca un MIB específico, PySMI reemplazará ese marcador con el nombre del módulo MIB que está buscando. Ejemplo: http://mibs.snmplabs.com/asn1/@mib@
  • SFTP/FTP. Una URL completamente especificada que incluye el nombre de usuario y la contraseña de FTP. El nombre del módulo MIB está especificado por un marcador @mib@. Cuando se busca un MIB específico, PySMI reemplazará ese marcador con el nombre del módulo MIB que está buscando. Ejemplo: http://mibs.snmplabs.com/asn1/@mib@

Al intentar obtener un módulo MIB, la herramienta mibdump.py intentará cada uno de los transportes --mib-source configurados en el orden de especificación hasta el primer éxito.

Por defecto, mibdump.py buscará:

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

Una vez que se proporciona otra opción --mib-source, los valores por defecto no se usarán y deben ser proporcionados manualmente a mibdump.py si es necesario.

Arbitraje de nombres de módulos MIB

No existe una convención única sobre cómo deben nombrarse los archivos de módulos MIB. Por defecto, mibdump.py intentará varias suposiciones al intentar encontrar un archivo que contenga un módulo MIB específico. Intentará mayúsculas y minúsculas, un archivo con el nombre del módulo MIB, intentará agregar diferentes extensiones al archivo (.mib, .my, etc.), intentará agregar/cortar la parte '-MIB' del nombre del archivo. Si nada coincide, mibdump.py considerará que la fuente --mib-source probada no contiene el módulo MIB que está buscando.

Existe una pequeña posibilidad, sin embargo, de que la coincidencia difusa pueda resultar en la obtención de un MIB incorrecto. Si eso sucede, puede deshabilitar la arbitrariedad anterior proporcionando a mibdump.py la opción --disable-fuzzy-source.

Especificación de la fuente de MIB

La opción --mib-source puede especificarse varias veces. Cada instancia de --mib-source debe especificar una URL donde se deben buscar y descargar los módulos MIB de ASN.1. En este momento se admiten tres métodos de obtención de MIB:

  • Archivos locales. Este podría ser un directorio de nivel superior donde se ubican los archivos MIB. Los subdirectorios también se recorrerán automáticamente. Ejemplo: file:///usr/share/snmp
  • Archivos ZIP que contienen archivos MIB. Los subdirectorios y los archivos ZIP incrustados se recorrerán automáticamente. Ejemplo: zip://mymibs.zip
  • HTTP/HTTPS. Una URL completamente especificada donde el nombre del módulo MIB se especifica mediante un marcador @mib@. Cuando se busca un MIB específico, PySMI reemplazará ese marcador con el nombre del módulo MIB que está buscando. Ejemplo: http://mibs.snmplabs.com/asn1/@mib@
  • SFTP/FTP. Una URL completamente especificada que incluye el nombre de usuario y la contraseña de FTP. El nombre del módulo MIB se especifica mediante un marcador @mib@. Cuando se busca un MIB específico, PySMI reemplazará ese marcador con el nombre del módulo MIB que está buscando. Ejemplo: http://mibs.snmplabs.com/asn1/@mib@

Al intentar obtener un módulo MIB, la herramienta mibcopy.py intentará cada uno de los transportes --mib-source configurados en el orden de especificación hasta el primer acierto exitoso.

Por defecto, mibcopy.py buscará:

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

Una vez que se proporciona otra opción --mib-source, esos valores predeterminados no se utilizarán y deberán proporcionarse manualmente a mibcopy.py si es necesario.

Establecer el directorio de destino

mibcopy.py escribe los MIB en el directorio <DESTINATION>.

Ignorar errores de transformación

Por defecto, PySMI se detendrá ante el primer error fatal ocurrido durante la transformación de una serie de MIB. Si desea que PySMI ignore los errores fatales y, por lo tanto, omita los MIB fallidos, utilice la opción --ignore-errors.

Tenga en cuenta que omitir la transformación de MIB que son importados por otros MIB puede hacer que los MIB dependientes sean inconsistentes para su uso.

Pequeñas mejoras de velocidad

La opción --cache-directory puede utilizarse para apuntar a un directorio temporal escribible donde el analizador de PySMI (por ejemplo, Ply) almacenaría sus tablas de búsqueda. Esto debería mejorar ligeramente el rendimiento de PySMI.

Biblioteca PySMI

El objeto MibCompiler es la interfaz principal de las características de la biblioteca PySMI. Reúne las partes aisladas de la infraestructura del compilador y gestiona el flujo de trabajo de la transformación de MIB de ASN.1.

Este ejemplo muestra algunas de sus características:

from pysmi.reader import HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [('mibs.snmplabs.com', 80, '/asn1/@mib@')]
# almacenar los MIB compilados llamando a esta función
def store_mibs(mibName, jsonDoc, cbCtx):
    print('# MIB module %s' % mibName)
    print(jsonDoc)
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(store_mibs)
)
# descargar MIB de ASN.1 a través de HTTP
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# nunca recompilar MIB con MACROs de ASN.1
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
status = mibCompiler.compile(*inputMibs)
print(status)

Compilador MIB

Estado de la compilación

La instancia de la clase MibStatus es utilizada por MibCompiler.compiler() para indicar el resultado de la operación de transformación de MIB.

Fuentes MIB

PySMI ofrece un puñado de mecanismos de transporte distintos para obtener MIB por nombre de ubicaciones específicas. En todos los casos, la correspondencia entre el nombre del módulo MIB y el nombre del archivo puede no ser exacta: se puede realizar una búsqueda difusa de nombres para mitigar posibles cambios en el nombre del archivo MIB.

Lector de archivos locales

La instancia de la clase FileReader busca archivos MIB en los directorios dados en el host que ejecuta PySMI.

Lector de archivos ZIP

La instancia de la clase ZipReader busca archivos MIB en un archivo ZIP local. Los subdirectorios ZIP y los archivos ZIP incrustados se recorrerán.

Lector HTTP

La instancia de la clase HttpReader intenta descargar archivos MIB utilizando la URL configurada.

Lector FTP

La instancia de la clase FtpReader intenta descargar archivos MIB desde el servidor FTP configurado.

Lector de devolución de llamada

La instancia de la clase CallbackReader intenta obtener archivos MIB llamando a un objeto de usuario.

Compilación condicional

Hay casos en los que la transformación de MIB puede o no debe realizarse. Tales casos incluyen:

  • MIBs fundamentales que contienen piezas implementadas manualmente o MACROs de ASN.1
  • MIBs obsoletos completamente reimplementados dentro de MIBs modernos
  • MIBs ya transformados

MibCompiler espera que el usuario proporcione un objeto searcher que permita o omita la transformación de MIB para un nombre particular basándose en cualquier razón de la que sea consciente.

Buscador de archivos Python

Los MIB transformados que se guardaron en forma de archivos Python se pueden verificar con instancias de la clase PyFileSearcher.

Buscar paquetes Python

Algunos MIB, los más frecuentemente los básicos, pueden almacenarse en un paquete de Python. Su existencia puede ser verificada con instancias de la clase PyPackageSearcher.

Ignorar MIB incondicionalmente

Los MIB fundamentales u obsoletos que nunca deben transformarse pueden excluirse ciegamente listando sus nombres en la instancia de la clase StubSearcher.

Configuración del analizador

Los MIB pueden estar escritos en una de las dos versiones principales del lenguaje SMI (v1 y v2). Algunos MIB pueden contener errores típicos.

PySMI ofrece una forma de personalizar el analizador para consumir cualquiera de las gramáticas SMI principales, así como para recuperarse de errores conocidos en archivos MIB.

Analizador SMI

Los MIB de SNMP están escritos en dos tipos de lenguajes especiales: SMIv1 y SMIv2. La primera versión de SMI está obsoleta; la mayoría de los MIB en la actualidad están escritos en la gramática SMIv2. También hay esfuerzos dirigidos a mejorar SMIv2, pero esos MIB son una gran minoría en el momento de escribir esto.

PySMI está diseñado para manejar tanto SMIv1 como SMIv2. La forma en que se hace es que SMIv2 se considera el más básico y completo, mientras que SMIv1 es una especialización de la sintaxis SMIv2.

Para que un usuario obtenga un analizador SMIv2, se debe llamar a la función parserFactory con el objeto de dialecto SMI.

El objeto analizador debe pasarse al objeto MibCompiler.

NOTA:

Por favor, tenga en cuenta que la función parserFactory devuelve una clase, no una instancia de clase. Asegúrese de instanciarla al pasarla al constructor de la clase MibCompiler.

Dialectos del lenguaje SMI

PySMI ofrece una colección preconstruida de opciones de relajación de gramática del analizador para simplificar su uso:

  • pysmi.parser.dialect.smiV2 - gramática canónica SMIv2
  • pysmi.parser.dialect.smiV1 - gramática canónica SMIv1
  • pysmi.parser.dialect.smiV1Relaxed - gramática SMIv1 relajada que permite algunas desviaciones

El objeto de gramática debe pasarse a la función parserFactory.

from pysmi.parser.dialect import smiV1
from pysmi.parser.smi import parserFactory
SmiV1Parser = parserFactory(**smiV1)

Aparentemente, muchos MIB de producción se distribuyeron en condiciones sintácticamente defectuosas. PySMI intenta solucionar estos problemas permitiendo algunas relajaciones adicionales de la gramática SMI. Puede habilitar todas estas relajaciones a la vez para maximizar el número de MIB, encontrados en la naturaleza, compilados con éxito.

from pysmi.parser.dialect import smiV1Relaxed
from pysmi.parser.smi import parserFactory
RelaxedSmiV1Parser = parserFactory(**smiV1Relaxed)

Generadores de código

Una vez que el MIB de ASN.1 es analizado, el AST se pasa a un generador de código que convierte el AST en la representación deseada del MIB.

Generador de documentos JSON

Generador de MIB PySNMP

PySNMP MIB generator

This module could be used to implement custom MIB compiler.

PySMI offers a MIB compiler that can run on your machine and process any ASN.1 MIB modules.

In order to run MIB compiler, you would need to create an instance of MibCompiler class.

The MibCompiler takes the following arguments:

  • MIB parser

    An object that understands ASN.1 MIB syntax.

  • MIB code generator

    An object that knows how to convert MIBs into target format.

  • MIB reader

    An object that knows how to fetch MIBs from various sources.

  • MIB searcher

    An object that knows where to look for pre-compiled MIBs.

  • MIB borrower

    An object that knows how to fetch pre-compiled MIBs from various sources.

  • MIB writer

    An object that knows how to save compiled MIBs.

The MibCompiler can be extended with multiple readers, searchers, borrowers and writers.

The following configuration methods are available:

addSources(*mibReaders)
Add MIB reader instance to the list of sources.
addSearchers(*mibSearchers)
Add MIB searcher instance to the list of searchers.
addBorrowers(*mibBorrowers)
Add MIB borrower instance to the list of borrowers.
addWriters(*mibWriters)
Add MIB writer instance to the list of writers.
compile(*mibNames, **kwargs)
The main method that runs the MIB compilation process. It takes MIB module names as arguments and returns a dictionary of results.

Optional arguments to compile method:

rebuild
If set to True, forces MIB compilation even if pre-compiled MIBs are already available.
genTexts
If set to True, includes textual conventions and descriptions into compiled MIBs.
noDeps
If set to True, skips dependency resolution and compiles only the requested MIB modules.

Code generation stub

Code generators are responsible for converting MIBs into the desired format. PySMI provides several code generators:

  • PySnmpCodeGen

    Generates PySNMP-compatible Python modules.

  • JsonCodeGen

    Generates JSON documents representing MIB modules.

You can also implement your own code generator by subclassing the AbstractCodeGen class and implementing the generateMibModule method.

Borrow pre-compiled MIBs

Some MIBs in circulation appear broken beyond automatic repair. To handle such cases PySMI introduces the MIB borrowing functionality. When MibCompiler gives up compiling a MIB, it can try to go out and take a copy of already transformed MIB to complete the request successfully.

Any file borrower

The AnyFileBorrower allows borrowing MIBs from any location accessible by the system's file paths.

Python file borrower

The PyFileBorrower allows borrowing pre-compiled PySNMP MIB modules from local directories.

Write compiled MIBs

Successfully transformed MIB modules' contents will be passed to writer object given to MibCompiler on instantiation.

File writer

The FileWriter can be used to write compiled MIBs to files in a specified directory.

Python file writer

The PyFileWriter is a specialized writer that saves compiled MIBs as Python modules in a specified directory.

Callback writer

CallbackWriter class instance passes the contents of the compiled MIB files to a user object.

Examples

The following examples focus on various feature of the PySMI library.

Compile MIBs into JSON

Look up specific ASN.1 MIBs at configured Web and FTP sites, compile them into JSON documents and print them out to stdout.

Try to support both SMIv1 and SMIv2 flavors of SMI as well as popular deviations from official syntax found in the wild.

from pysmi.reader import FileReader, HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('reader', 'compiler'))
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
def printOut(mibName, jsonDoc, cbCtx):
    print('\n\n# MIB module %s' % mibName)
    print(jsonDoc)
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(printOut)
)
# search for source MIBs here
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# search for source MIBs at Web sites
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
# run recursive MIB compilation
results = mibCompiler.compile(*inputMibs)
print('\n# Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compile MIBs from web

Look up specific ASN.1 MIBs at configured Web and FTP sites, compile them into pysnmp form and save Python modules as plain-text files in a local directory.

Try to support both SMIv1 and SMIv2 flavors of SMI as well as popular deviations from official syntax found in the wild.

In this example we disable automatic dependency checking on MIB compilation using noDeps flag.

Also, we do not check if target file already exists thus MIB compilation occurs on every invocation.

from pysmi.reader import HttpReader
from pysmi.reader import FtpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
ftpSources = [
    ('ftp.cisco.com', '/pub/mibs/v2/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# search for source MIBs at Web and FTP sites
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
mibCompiler.addSources(*[FtpReader(*x) for x in ftpSources])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# run non-recursive MIB compilation
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compile SMIv1/v2 MIBs

Look up specific ASN.1 MIBs at configured local directories, compile them into pysnmp form if not done yet and save Python modules as plain-text files in a local directory.

Try to support both SMIv1 and SMIv2 flavors of SMI as well as popular deviations from official syntax found in the wild.

When figuring out if compilation is needed, check all known places where pysnmp MIBs could possibly be found.

You can force MIB re-compilation by passing rebuild flag to MIB compiler (see below).

Default invocation of MIB compiler does not generate [potentially large] comments and texts found in MIBs. If you need them in pysnmp MIB modules, just pass genTexts flag to MIB compiler.

from pysmi.reader import FileReader
from pysmi.searcher import PyFileSearcher, PyPackageSearcher, StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(SmiStarParser(),
                          PySnmpCodeGen(),
                          PyFileWriter(dstDirectory))
# search for source MIBs here
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# check compiled MIBs in our own productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# ...and at default PySNMP MIBs packages
mibCompiler.addSearchers(*[PyPackageSearcher(x) for x in PySnmpCodeGen.defaultMibPackages])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# run [possibly recursive] MIB compilation
results = mibCompiler.compile(*inputMibs)  #, rebuild=True, genTexts=True)
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compile SMIv2 MIBs

Invoke user callback function to provide MIB text, compile given text string into pysnmp MIB form and pass results to another user callback function for storing.

Here we expect to deal only with SMIv2-valid MIBs.

We use noDeps flag to prevent MIB compiler from attemping to compile IMPORT'ed MIBs as well.

import sys
from pysmi.reader import CallbackReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiV2Parser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDir = '/usr/share/snmp/mibs/'  # we will read MIBs from here
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiV2Parser(),
    PySnmpCodeGen(),
    # out own callback function stores results in its own way
    CallbackWriter(lambda m, d, c: sys.stdout.write(d))
)
# our own callback function serves as a MIB source here
mibCompiler.addSources(
  CallbackReader(lambda m, c: open(srcDir+m+'.txt').read())
)
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# run non-recursive MIB compilation
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Borrow pysnmp MIBs on failure

Look up specific ASN.1 MIBs at configured Web/FTP sites. If no required MIB is found or its compilation fails for some reason, attempt to download precompiled version of failed MIB and store it locally as if we had compiled it.

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.searcher import StubSearcher
from pysmi.borrower import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('borrower', 'reader', 'searcher'))
inputMibs = ['BORROWED-MIB']
httpSources = [ 
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# search for source MIBs at Web sites
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# check compiled/borrowed MIBs in our own productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# search for compiled MIBs at Web sites if source is not available or broken
mibCompiler.addBorrowers(*[PyFileBorrower(HttpReader(*x)).setOptions(genTexts=False) for x in httpBorrowers])
# run non-recursive MIB compilation
results = mibCompiler.compile(*inputMibs)
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))
