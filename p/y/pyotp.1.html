NOMBRE

pyotp - PyOTP

PyOTP es una biblioteca de Python para generar y verificar contraseñas de un solo uso. Se puede utilizar para implementar métodos de autenticación de dos factores (2FA) o multi-factor (MFA) en aplicaciones web y en otros sistemas que requieren que los usuarios inicien sesión.

  • Asegurar la confidencialidad del transporte utilizando HTTPS
  • Asegurar la confidencialidad de los secretos HOTP/TOTP almacenando los secretos en una base de datos de acceso controlado
  • Denegar ataques de repetición rechazando contraseñas de un solo uso que hayan sido utilizadas por el cliente (esto requiere almacenar la marca de tiempo, OTP o hash de la OTP más recientemente autenticada en su base de datos, y rechazar la OTP cuando se vea una coincidencia)
  • Limitar (limitar la velocidad) los ataques de fuerza bruta contra la funcionalidad de inicio de sesión de su aplicación (ver RFC 4226, sección 7.3)
  • Al implementar una aplicación "desde cero", considere admitir FIDO U2F/WebAuthn además de HOTP/TOTP. U2F utiliza criptografía asimétrica para evitar el uso de un diseño de secreto compartido, lo que fortalece su solución MFA contra ataques del lado del servidor. El U2F de hardware también oculta el secreto del cliente en un dispositivo dedicado de un solo propósito, lo que fortalece a sus clientes contra ataques del lado del cliente. Y al automatizar el alcance de las credenciales a los IDs de las partes confiables (orígenes de la aplicación/nombres de dominio), U2F agrega protección contra ataques de phishing. Una implementación de FIDO U2F/WebAuthn es el proyecto hermano de PyOTP, PyWARP.

BREVE RESUMEN SOBRE EL USO DE CONTRASEÑAS DE UN SOLO USO EN EL TELÉFONO

  • Las OTP implican un secreto compartido, almacenado tanto en el teléfono como en el servidor
  • Las OTP se pueden generar en un teléfono sin conexión a Internet
  • Las OTP siempre deben usarse como un segundo factor de autenticación (si se pierde el teléfono, la cuenta aún está protegida con una contraseña)
  • Google Authenticator y otras aplicaciones de clientes OTP le permiten almacenar múltiples secretos OTP y aprovisionarlos mediante un código QR

USO

OTP basadas en tiempo

import pyotp
import time
totp = pyotp.TOTP('base32secret3232')
totp.now() # => '492039'
# OTP verificada para el tiempo actual
totp.verify('492039') # => True
time.sleep(30)
totp.verify('492039') # => False

OTP basadas en contador

import pyotp
hotp = pyotp.HOTP('base32secret3232')
hotp.at(0) # => '260182'
hotp.at(1) # => '055283'
hotp.at(1401) # => '316439'
# OTP verificada con un contador
hotp.verify('316439', 1401) # => True
hotp.verify('316439', 1402) # => False

Generación de una clave secreta

Se proporciona una función de ayuda para generar un secreto base32 de 32 caracteres, compatible con Google Authenticator y otras aplicaciones OTP:

pyotp.random_base32()

Algunas aplicaciones desean que la clave secreta tenga el formato de una cadena codificada en hexadecimal:

pyotp.random_hex()  # devuelve un secreto codificado en hexadecimal de 40 caracteres

Compatible con Google Authenticator

PyOTP funciona con la aplicación Google Authenticator para iPhone y Android, así como con otras aplicaciones OTP como Authy. PyOTP incluye la capacidad de generar URIs de aprovisionamiento para su uso con el escáner de código QR integrado en estas aplicaciones de clientes MFA:

El análisis de estas URL también es compatible:

pyotp.parse_uri('otpauth://totp/Secure%20App:alice%40google.com?secret=JBSWY3DPEHPK3PXP&issuer=Secure%20App')
>>> <pyotp.totp.TOTP object at 0xFFFFFFFF>
pyotp.parse_uri('otpauth://hotp/Secure%20App:alice%40google.com?secret=JBSWY3DPEHPK3PXP&issuer=Secure%20App&counter=0'
>>> <pyotp.totp.HOTP object at 0xFFFFFFFF>

    pyotp - Python One Time Password library

    SINOPSIS

    import pyotp
import datetime

# TOTP
totp = pyotp.TOTP("JBSWY3DPEHPK3PXP") # Base32 encoded secret
print(totp.now())                    # Get current OTP
print(totp.at(datetime.datetime.now())) # Get OTP for current time
print(totp.verify('123456'))         # Verify an OTP

# HOTP
hotp = pyotp.HOTP("JBSWY3DPEHPK3PXP") # Base32 encoded secret
print(hotp.at(0))                    # Get OTP for counter 0
print(hotp.verify('123456', 0))      # Verify an OTP for counter 0

# Provisioning URI
uri = totp.provisioning_uri('user@example.com', issuer_name='MyApp')
print(uri) # otpauth://totp/MyApp:user@example.com?secret=JBSWY3DPEHPK3PXP&issuer=MyApp

# Parse URI
otp = pyotp.parse_uri(uri)
print(otp.name) # user@example.com
print(otp.issuer_name) # MyApp
print(otp.secret) # JBSWY3DPEHPK3PXP
print(otp.provisioning_uri()) # otpauth://totp/MyApp:user@example.com?secret=JBSWY3DPEHPK3PXP&issuer=MyApp

    DESCRIPCIÓN

    PyOTP es una biblioteca para generar y verificar contraseñas de un solo uso (OTP) basadas en HMAC (HOTP) y basadas en tiempo (TOTP). Admite URIs de aprovisionamiento compatibles con Google Authenticator para facilitar la configuración.

    Algoritmos de Contraseña de Un Solo Uso

    Este paquete implementa los siguientes algoritmos de OTP:

    • RFC 4226: HOTP: An HMAC-Based One-Time Password
    • RFC 6238: TOTP: Time-Based One-Time Password Algorithm

    También se incluyen enlaces a implementaciones y recursos útiles:

    • ROTP - Biblioteca original de Ruby OTP por Mark Percival
    • OTPHP - Puerto PHP de ROTP por Le Lag
    • OWASP Authentication Cheat Sheet
    • NIST SP 800-63-3: Digital Authentication Guideline

    Para nuevas aplicaciones:

    • WebAuthn
    • PyWARP

    Control de Versiones

    pyotp.parse_uri(uri: str) -> OTP
    Analiza la URI de aprovisionamiento para el OTP; funciona tanto para TOTP como para HOTP.
    Ver también:
    https://github.com/google/google-authenticator/wiki/Key-Uri-Format
    Parámetros
    uri -- la URI hotp/totp a analizar
