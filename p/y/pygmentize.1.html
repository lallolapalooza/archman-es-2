PYGMENTIZE(1) Manual de Comandos Generales PYGMENTIZE(1)

NOMBRE

pygmentize - resalta el archivo de entrada

SINOPSIS

pygmentize [-l <lexer> | -g] [-F <filtro>[:<opciones>]] [-f <formateador>] [-O <opciones> ] [-P <opción=valor> ] [-o <archivo_salida> ] [<archivo_entrada>]
pygmentize -S <estilo> -f <formateador> [-a <argumento>] [-O <opciones>] [-P <opción=valor>]
pygmentize -L [<qué> ...]
pygmentize -N <nombre_archivo>
pygmentize -C
pygmentize -H <tipo> <nombre>
pygmentize -h | -V

DESCRIPCIÓN

Pygments es un resaltador de sintaxis genérico para uso general en todo tipo de software, como sistemas de foros, wikis u otras aplicaciones que necesitan embellecer código fuente.

Sus características son:
* se soporta una amplia gama de lenguajes comunes y formatos de marcado
* se presta especial atención a los detalles, aumentando la calidad en una cantidad considerable
* se agregan fácilmente nuevos lenguajes y formatos
* una serie de formatos de salida, actualmente HTML, LaTeX y secuencias ANSI
* es utilizable como una herramienta de línea de comandos y como una biblioteca
* ... ¡y resalta incluso Brainfuck!

pygmentize es un comando que utiliza Pygments para resaltar el archivo de entrada y escribir el resultado en <archivo_salida>. Si no se proporciona <archivo_entrada>, se utiliza la entrada estándar.

OPCIONES

A continuación se incluye un resumen de las opciones.

-l <lexer>
Establece el nombre del lexer. Si no se proporciona, el lexer se adivina a partir de la extensión del nombre del archivo de entrada (esto, obviamente, no funciona si la entrada es la entrada estándar).
-g
Intenta adivinar el lexer a partir del contenido del archivo, o lo pasa como texto plano si falla (esta opción funciona para resaltar la entrada estándar).
-F <filtro>[:<opciones>]
Agrega un filtro al flujo de tokens. Puedes proporcionar opciones de la misma manera que para -O después de dos puntos (nota: no debe haber espacios alrededor de los dos puntos). Esta opción se puede dar varias veces.
-f <formateador>
Establece el nombre del formateador. Si no se proporciona, se adivinará a partir de la extensión del nombre del archivo de salida. Si no se proporciona un archivo de salida, se utilizará el formateador de terminal por defecto.
-o <archivo_salida>
Establece el archivo de salida. Si no se proporciona, se utiliza la salida estándar.
-O <opciones>
Con esta opción, puedes dar al lexer y al formateador una lista de opciones separada por comas, por ejemplo: "-O bg=light,python=cool". Qué opciones son válidas para qué lexers y formateadores se puede encontrar en la documentación. Esta opción se puede dar varias veces.
-P <opción=valor>
Esta opción agrega opciones de lexer y formateador como la opción -O, pero solo puedes dar una opción por -P. De esta manera, el valor de la opción puede contener comas y signos de igual, lo que no puede hacer con -O.
-S <estilo>
Imprime las definiciones de estilo para el estilo <estilo> y para el formateador <formateador>. El significado del argumento proporcionado por -a <argumento> depende del formateador y se puede encontrar en la documentación.
-L [<qué> ...]
Lista lexers, formateadores, estilos o filtros. Establece <qué> en el elemento que deseas listar (por ejemplo, "styles"), u omítelo para listar todo.
-N <nombre_archivo>
Adivina e imprime un nombre de lexer basándose únicamente en el nombre de archivo proporcionado. No toma entrada ni resalta nada. Si no se puede encontrar un lexer específico, se imprime "text".
-C
Similar a -N, pero adivina un lexer basándose en el contenido leído de la entrada estándar.
-H <tipo> <nombre>
Imprime ayuda detallada para el objeto <nombre> del tipo <tipo>, donde <tipo> es uno de "lexer", "formatter" o "filter".
-h
Muestra la pantalla de ayuda.
-V
Muestra la versión del paquete Pygments.
