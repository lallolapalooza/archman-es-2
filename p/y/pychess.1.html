NOMBRE

pychess - interfaz gráfica de usuario de ajedrez para varios motores de ajedrez

DESCRIPCIÓN

pychess proporciona un cliente de ajedrez completo, de aspecto agradable y fácil de usar para el escritorio gnome.

El cliente debería ser utilizable tanto para aquellos que son completamente nuevos en el ajedrez, como para aquellos que quieren usar una computadora para mejorar su juego.

CARACTERÍSTICAS

* Interfaz con pestañas

* Soporte de lectura/escritura pgn+epd

* Pistas y modo espía

* Soporte de motor xboard/cecp

* Motor incorporado basado en python

* Libro de aperturas usando sqlite

* Interfaz y diálogos limpios

* Validador de movimientos incorporado

* Resaltado de movimientos legales

* Soporta arrastrar y soltar.
