PYDF(1) Manual de Comandos Generales PYDF(1)

NOMBRE

pydf - informa sobre el uso del espacio en disco de los sistemas de archivos con colores

SINOPSIS

pydf [opciones] [archivo]

DESCRIPCIÓN

pydf es un script de python que muestra la cantidad de espacio en disco disponible en los sistemas de archivos montados, utilizando diferentes colores para diferentes tipos de sistemas de archivos. El formato de salida es completamente personalizable.

Si se proporciona un argumento opcional de
archivo, pydf muestra solo información sobre el sistema de archivos que contiene el(los) archivo(s), de lo contrario, muestra información sobre todos los sistemas de archivos montados.

OPCIONES

--ayuda
Muestra un resumen de las opciones.
-v, --version
Muestra la versión del programa.
-a, --todo
Incluye sistemas de archivos que tienen 0 bloques.
-h, --legible
Imprime los tamaños en formato legible para humanos (por ejemplo, 133K 2341M 2448G).
-H, --si
Ídem, pero usa potencias de 1000 no 1024.
--tamaño-bloque=TAMAÑO
usa bloques de tamaño TAMAÑO-byte.
-k, --kilobytes
igual que --tamaño-bloque=1024.
-i, --inodes
muestra información sobre inodos en lugar de bloques.
-l, --local
limita la lista a sistemas de archivos locales.
-m, --megabytes
igual que --tamaño-bloque=1048576.
-g, --gigabytes
igual que --tamaño-bloque=1073741824.
--bloques
usa el tamaño de bloque nativo del sistema de archivos.
--bn
no usa colores.
--montajes=ARCHIVO
archivo para obtener información de montaje. En un sistema linux normal, solo /etc/mtab o /proc/mounts tienen sentido. Usa /proc/mounts cuando /etc/mtab está corrupto o inaccesible (la salida se ve un poco extraña en este caso).
-B, --mostrar-vinculos
Muestra también los sistemas de archivos montados con --mount --bind.

ERRORES

Al ejecutar con python3, los puntos de montaje con nombres no ASCII fuera de la configuración regional no se mostrarán (debido a la incapacidad de os.statvfs para usar bytes en lugar de cadenas).

ARCHIVOS

/etc/pydfrc
archivo de configuración principal.
~/.pydfrc
archivo de configuración por usuario.
