Uno de los escenarios típicos donde sshtunnel es útil se representa en la siguiente figura. El usuario puede necesitar conectar un puerto de un servidor remoto (es decir, 8080) donde solo el puerto SSH (normalmente el puerto 22) es alcanzable.

----------------------------------------------------------------------
                            |
-------------+              |    +----------+
    CLIENTE  |              |    |  SERVIDOR | :22 SSH
    LOCAL    | <== SSH ========> | REMOTO   | :8080 servicio web
-------------+              |    +----------+
                            |
                         FIREWALL (solo el puerto 22 está abierto)
----------------------------------------------------------------------

Fig1: Cómo conectar a un servicio bloqueado por un cortafuegos a través de un túnel SSH.

Si el servidor SSH lo permite, también es posible acceder a un servidor privado (desde la perspectiva del SERVIDOR REMOTO) que no es directamente visible desde el exterior (perspectiva del CLIENTE LOCAL).

----------------------------------------------------------------------
                            |
-------------+              |    +----------+               +---------
    CLIENTE  |              |    |  SERVIDOR |               | SERVIDOR
    LOCAL    | <== SSH ========> | REMOTO   | <== local ==> | PRIVADO
-------------+              |    +----------+               +---------
                            |
                         FIREWALL (solo el puerto 443 está abierto)
----------------------------------------------------------------------

Fig2: Cómo conectar al SERVIDOR PRIVADO a través de un túnel SSH.

La API permite inicializar el túnel y ponerlo en marcha, o usar un contexto with, que se encargará de iniciar y detener el túnel:

EJEMPLO 1

El código correspondiente a la Fig1 anterior sigue, dado que la dirección del servidor remoto es pahaz.urfuclub.ru, autenticación por contraseña y un puerto de enlace local asignado aleatoriamente.

from sshtunnel import SSHTunnelForwarder
server = SSHTunnelForwarder(
    'alfa.8iq.dev',
    ssh_username="pahaz",
    ssh_password="secret",
    remote_bind_address=('127.0.0.1', 8080)
)
server.start()
print(server.local_bind_port)  # muestra el puerto local asignado
# trabaja con `SERVICIO SECRETO` a través de `server.local_bind_port`.
server.stop()

EJEMPLO 2

Ejemplo de reenvío de puerto a un servidor privado no accesible directamente, asumiendo autenticación por clave pkey protegida por contraseña, el servicio SSH del servidor remoto está escuchando en el puerto 443 y ese puerto está abierto en el cortafuegos (Fig2):

import paramiko
import sshtunnel
with sshtunnel.open_tunnel(
    (REMOTE_SERVER_IP, 443),
    ssh_username="",
    ssh_pkey="/var/ssh/rsa_key",
    ssh_private_key_password="secret",
    remote_bind_address=(PRIVATE_SERVER_IP, 22),
    local_bind_address=('0.0.0.0', 10022)
) as tunnel:
    client = paramiko.SSHClient()
    client.load_system_host_keys()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    client.connect('127.0.0.1', 10022)
    # realiza algunas operaciones con la sesión del cliente
    client.close()
print('¡FIN!')

EJEMPLO 3

Ejemplo de reenvío de puerto para el puerto local de MySQL de Vagrant:

from sshtunnel import open_tunnel
from time import sleep
with open_tunnel(
    ('localhost', 2222),
    ssh_username="vagrant",
    ssh_password="vagrant",
    remote_bind_address=('127.0.0.1', 3306)
) as server:
    print(server.local_bind_port)
    while True:
        # presiona Ctrl-C para detener
        sleep(1)
print('¡FIN!')

O simplemente usando la CLI:

(bash)$ python -m sshtunnel -U vagrant -P vagrant -L :3306 -R 127.0.0.1:3306 -p 2222 localhost

        with SSHClient() as ssh:
            ssh.connect('localhost',

                username='target_user',
                password='target_pwd',
            )

sshtunnel - Iniciar túneles SSH a través de una puerta de enlace remota.

sshtunnel funciona abriendo una conexión SSH de reenvío de puertos en segundo plano, utilizando hilos.

La(s) conexión(es) se cierran al llamar explícitamente al método SSHTunnelForwarder.stop() o al usarlo como contexto.

sshtunnel.SSH_TIMEOUT = 0.1
Tiempo de espera (segundos) para el socket de transporte (socket.settimeout)
sshtunnel.TUNNEL_TIMEOUT = 10.0
Tiempo de espera (segundos) para la conexión del túnel (tiempo de espera de `open_channel`)
sshtunnel.DEFAULT_LOGLEVEL = 40
Nivel por defecto si no se pasa ningún logger (ERROR)
sshtunnel.DEFAULT_SSH_DIRECTORY = '~/.ssh'
Ruta del archivo de configuración SSH opcional
