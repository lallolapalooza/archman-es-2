INSTALACIÓN

Paquetes precompilados

Si tu distribución incluye este proyecto como un paquete, como lo hace Fedora Linux, puedes simplemente usar tu gestor de paquetes para instalar el paquete. Por ejemplo:

$ dnf install python3-feedgen

Usando pip

También puedes usar pip para instalar el módulo feedgen. Simplemente ejecuta:

$ pip install feedgen

CREAR UN FEED

Para crear un feed, simplemente instancia la clase FeedGenerator e inserta algunos datos:

from feedgen.feed import FeedGenerator
fg = FeedGenerator()
fg.id('http://lernfunk.de/media/654321')
fg.title('Some Testfeed')
fg.author( {'name':'John Doe','email':'john@example.de'} )
fg.link( href='http://example.com', rel='alternate' )
fg.logo('http://ex.com/logo.jpg')
fg.subtitle('This is a cool feed!')
fg.link( href='http://larskiesow.de/test.atom', rel='self' )
fg.language('en')

Ten en cuenta que para los métodos que establecen campos que pueden aparecer más de una vez en un feed, puedes usar todas las siguientes formas de proporcionar datos:

  • Proporciona los datos para ese elemento como argumentos de palabra clave
  • Proporciona los datos para ese elemento como un diccionario
  • Proporciona una lista de diccionarios con los datos para varios elementos

Ejemplo:

fg.contributor( name='John Doe', email='jdoe@example.com' )
fg.contributor({'name':'John Doe', 'email':'jdoe@example.com'})
fg.contributor([{'name':'John Doe', 'email':'jdoe@example.com'}, ...])

GENERAR EL FEED

Después de eso, puedes generar tanto RSS como ATOM llamando al método respectivo:

atomfeed = fg.atom_str(pretty=True) # Obtener el feed ATOM como cadena
rssfeed  = fg.rss_str(pretty=True) # Obtener el feed RSS como cadena
fg.atom_file('atom.xml') # Escribir el feed ATOM a un archivo
fg.rss_file('rss.xml') # Escribir el feed RSS a un archivo

AÑADIR ENTRADAS AL FEED

Para añadir entradas (elementos) a un feed, necesitas crear nuevos objetos FeedEntry y añadirlos a la lista de entradas en el FeedGenerator. La forma más conveniente es usar el propio FeedGenerator para la instanciación del objeto FeedEntry:

fe = fg.add_entry()
fe.id('http://lernfunk.de/media/654321/1')
fe.title('The First Episode')
fe.link(href="http://lernfunk.de/feed")

El método add_entry(...) del FeedGenerator generará un nuevo objeto FeedEntry, lo añadirá automáticamente a la lista interna de entradas del feed y lo devolverá, para que se puedan añadir datos adicionales.

EXTENSIONES

El FeedGenerator soporta extensiones para incluir datos adicionales en la estructura XML de los feeds. Las extensiones se pueden cargar así:

fg.load_extension('someext', atom=True, rss=True)

Este ejemplo intentaría cargar la extensión “someext” del archivo ext/someext.py. Es necesario que someext.py contenga una clase llamada “SomextExtension” que se requiere que tenga al menos los dos métodos extend_rss(...) y extend_atom(...). Aunque no es obligatorio, se recomienda encarecidamente usar BaseExtension de ext/base.py como superclase.

“load_extension('someext', ...)” también intentará cargar una clase llamada “SomextEntryExtension” para cada entrada del feed. Esta clase puede estar ubicada en el mismo archivo que SomextExtension o en ext/someext_entry.py, lo cual se sugiere especialmente para extensiones grandes.

Los parámetros atom y rss controlan si la extensión se utiliza para feeds ATOM y RSS respectivamente. El valor predeterminado para ambos parámetros es True, lo que significa que la extensión se utiliza para ambos tipos de feeds.

Ejemplo: Producción de un Podcast

Una extensión ya proporcionada es la extensión de podcast. Un podcast es un feed RSS con algunos elementos adicionales para ITunes.

Para producir un podcast, simplemente carga la extensión podcast:

from feedgen.feed import FeedGenerator
fg = FeedGenerator()
fg.load_extension('podcast')
...
fg.podcast.itunes_category('Technology', 'Podcasting')
...
fe = fg.add_entry()
fe.id('http://lernfunk.de/media/654321/1/file.mp3')
fe.title('The First Episode')
fe.description('Enjoy our first episode.')
fe.enclosure('http://lernfunk.de/media/654321/1/file.mp3', 0, 'audio/mpeg')
...
fg.rss_str(pretty=True)
fg.rss_file('podcast.xml')

Si la clase FeedGenerator se utiliza para cargar una extensión, ésta se carga automáticamente también para cada entrada del feed. Sin embargo, puedes cargar una extensión para una FeedEntry específica llamando a load_extension(...) en esa entrada.

Incluso si se cargan extensiones, se pueden deshabilitar temporalmente durante la generación del feed llamando al método de generación con el argumento de palabra clave extensions establecido en False.

Extensiones Personalizadas

Si deseas cargar extensiones personalizadas que no formen parte del paquete feedgen, puedes usar el método register_extension en su lugar. Puedes pasar directamente las clases para el feed y la extensión de entrada a este método, lo que significa que puedes definirlas en cualquier lugar.

Añadir Entradas del Feed

Para añadir entradas (elementos) a un feed, necesita crear nuevos objetos FeedEntry y añadirlos a la lista de entradas en el FeedGenerator. La forma más conveniente de hacerlo es llamar al método add_entry(...) de la siguiente manera:

>>> fe = fg.add_entry()
>>> fe.id('http://lernfunk.de/media/654321/1')
>>> fe.title('The First Episode')

El método add_entry(...) del FeedGenerator creará automáticamente un nuevo objeto FeedEntry, lo añadirá a la lista interna de entradas del feed y lo devolverá, para que se puedan añadir datos adicionales.

Extensiones

FeedGenerator soporta extensiones para incluir datos adicionales en la estructura XML de los feeds. Las extensiones se pueden cargar de la siguiente manera:

>>> fg.load_extension('someext', atom=True, rss=True)

Esto intentará cargar la extensión 'someext' desde el archivo ext/someext.py. Es necesario que someext.py contenga una clase llamada 'SomextExtension', que debe tener al menos los dos métodos extend_rss(...) y extend_atom(...). Aunque no es obligatorio, se recomienda encarecidamente utilizar BaseExtension de ext/base.py como superclase.

load_extension('someext', ...) también intentará cargar una clase llamada 'SomextEntryExtension' para cada entrada del feed. Esta clase puede estar ubicada en el mismo archivo que SomextExtension o en ext/someext_entry.py, lo que se sugiere especialmente para extensiones grandes.

Los parámetros atom y rss indican al FeedGenerator si las extensiones solo deben usarse para feeds ATOM o RSS. El valor predeterminado para ambos parámetros es verdadero, lo que significa que la extensión se usaría para ambos tipos de feeds.

Ejemplo: Producción de un Podcast

Una extensión que ya se proporciona es la extensión de podcast. Un podcast es un feed RSS con algunos elementos adicionales para ITunes.

Para producir un podcast, simplemente cargue la extensión de podcast:

>>> from feedgen.feed import FeedGenerator
>>> fg = FeedGenerator()
>>> fg.load_extension('podcast')
...
>>> fg.podcast.itunes_category('Technology', 'Podcasting')
...
>>> fg.rss_str(pretty=True)
>>> fg.rss_file('podcast.xml')

Por supuesto, la extensión debe cargarse también para los objetos FeedEntry, pero esto lo hace automáticamente el FeedGenerator para cada entrada del feed si la extensión se carga para todo el feed. Sin embargo, puede cargar una extensión para un FeedEntry específico llamando a load_extension(...) en esa entrada. Pero este es un uso bastante poco común.

Por supuesto, aún puede generar un feed ATOM o RSS normal, incluso si ha cargado algunos complementos, deshabilitándolos temporalmente durante la generación del feed. Esto se puede hacer llamando al método de generación con el argumento de palabra clave extensions establecido en False.

link(link=None, replace=False, **kwargs)
Obtiene o establece los datos de enlace. Un elemento de enlace es un diccionario con los campos href, rel, type, hreflang, title y length. href es obligatorio para ATOM.

Este método se puede llamar con:

  • los campos de un enlace como argumentos de palabra clave
  • los campos de un enlace como un diccionario
  • una lista de diccionarios que contienen los campos del enlace

Un enlace tiene los siguientes campos:

  • href es la URI del recurso referenciado (típicamente una página web)
  • rel contiene un solo tipo de relación de enlace. Puede ser una URI completa, o uno de los siguientes valores predefinidos (predeterminado=alternate):
  • alternate una representación alternativa de la entrada o feed, por ejemplo, un permalink a la versión html de la entrada, o la página principal del weblog.
  • enclosure un recurso relacionado que es potencialmente de gran tamaño y podría requerir un manejo especial, por ejemplo, una grabación de audio o video.
  • related un documento relacionado con la entrada o el feed.
  • self el feed en sí.
  • via la fuente de la información proporcionada en la entrada.
  • type indica el tipo de medio del recurso.
  • hreflang indica el idioma del recurso referenciado.
  • title información legible por humanos sobre el enlace, típicamente para fines de visualización.
  • length la longitud del recurso, en bytes.

RSS solo admite un enlace con URL solamente.

Parámetros
  • link -- Diccionario o lista de diccionarios con datos.
  • replace -- Si los enlaces antiguos deben ser reemplazados (predeterminado: False)
Devuelve
Conjunto actual de datos de enlace

Ejemplo:

>>> feedgen.link( href='http://example.com/', rel='self')
[{'href':'http://example.com/', 'rel':'self'}]

Obtiene o establece los datos del enlace. Un elemento de enlace es un diccionario con los campos `href`, `rel`, `type`, `hreflang`, `title` y `longitud`. `href` es obligatorio para ATOM.

Este método se puede llamar con: - los campos de un enlace como argumentos de palabra clave - los campos de un enlace como un diccionario - una lista de diccionarios que contienen los campos del enlace

Un enlace tiene los siguientes campos:

  • href es la URI del recurso referenciado (típicamente una página web)
  • rel contiene un único tipo de relación de enlace. Puede ser una URI completa, o uno de los siguientes valores predefinidos (predeterminado=alternativo):
  • alternativo una representación alternativa de la entrada o feed, por ejemplo, un enlace permanente a la versión HTML de la entrada, o la página principal del blog.
  • cerramiento un recurso relacionado que potencialmente es de gran tamaño y podría requerir un manejo especial, por ejemplo, una grabación de audio o video.

  • self el feed en sí.
  • via la fuente de la información proporcionada en la entrada.
  • type indica el tipo de medio del recurso.
  • hreflang indica el idioma del recurso referenciado.
  • title información legible por humanos sobre el enlace, típicamente para fines de visualización.
  • longitud la longitud del recurso, en bytes.

RSS solo admite un enlace sin nada más que una URL. Por lo tanto, para el elemento de enlace RSS, se utiliza el último enlace con `rel=alternate`.

RSS también admite un elemento de cerramiento por entrada, que está cubierto por el elemento de enlace en las entradas del feed ATOM. Por lo tanto, para el elemento de cerramiento RSS, se utiliza el último enlace con `rel=enclosure`.
