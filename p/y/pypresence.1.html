INFORMACIÓN

Sobre

Pypresence es un envoltorio para Discord RPC. Puedes usarlo para Rich Presence para tus juegos, así como para otras integraciones de Discord.

Inicio rápido

Esta página existe por si no tienes ni la menor idea de lo que estás haciendo, o si simplemente necesitas un inicio rápido. (Para rich presence)

Lo primero que querrás hacer es crear una aplicación RPC de Discord. Estos son los pasos:

  • Navega a https://discord.com/developers/
  • Haz clic en "Crear una aplicación".
  • Configura la aplicación como quieras, dale el nombre que desees y una buena imagen.
  • Justo debajo del nombre de tu aplicación, localiza tu ID de Cliente. Lo necesitarás más adelante.
  • Por último, guarda tu aplicación.

A continuación, necesitas instalar pypresence. Necesitarás tener python 3.9+ instalado. Estos son los pasos:

  • Abre la línea de comandos
  • Escribe pip install pypresence y presiona enter
  • Debería aparecer algo cerca del final que diga algo como "Successfully installed pypresence".

Ahora necesitarás crear el programa para establecer tu rich presence. Primero necesitamos importar lo que necesitamos, así:

from pypresence import Presence # El cliente de rich presence simple en pypresence
import time

A continuación, necesitamos inicializar nuestro cliente de Rich Presence. Necesitarás ese ID de Cliente de antes:

client_id = "ID AQUÍ"  # Pon tu ID de Cliente aquí
RPC = Presence(client_id)  # Inicializa el cliente Presence

Ahora necesitamos conectar nuestro Cliente a Discord, para que pueda enviar actualizaciones de presencia:

RPC.connect() # Inicia el bucle de handshake

Ahora necesitamos establecer nuestra rich presence. Podemos usar la función update() para esto. Hay muchas opciones que podemos usar, pero para esto usaremos estas:

 RPC.update(
    state="¡Aquí está!",
    details="Una presencia funcionando, ¡desde python!",
    name="Ejemplo de Rich Presence",
) # Actualiza nuestra presencia

Ahora necesitamos que nuestro programa se ejecute para siempre, así que usamos un bucle while.

while True:  # La presencia se mantendrá activa mientras el programa se esté ejecutando
    time.sleep(15) # Solo se puede actualizar la rich presence cada 15 segundos

¡Ahora, cuando ejecutes tu programa, debería verse algo como esto!

Uso de tipos de actividad y tipos de visualización de estado

Puedes personalizar cómo aparece tu presencia utilizando los enums ActivityType y StatusDisplayType. Aquí tienes un ejemplo:

from pypresence import Presence
from pypresence.types import ActivityType, StatusDisplayType
import time
client_id = "ID AQUÍ"
RPC = Presence(client_id)
RPC.connect()
# Mostrar como "Escuchando" en lugar de "Jugando"
RPC.update(
    activity_type=ActivityType.LISTENING,
    details="Mi Canción Favorita",
    state="De Mi Artista Favorito"
)
# O usar StatusDisplayType para controlar qué aparece en el estado del usuario
RPC.update(
    status_display_type=StatusDisplayType.STATE,
    state="Construyendo algo increíble",
    details="Usando pypresence"
)
while True:
    time.sleep(15)

Tipos de actividad disponibles: PLAYING (por defecto), LISTENING, WATCHING, COMPETING

Tipos de visualización de estado disponibles: NAME (por defecto - muestra el nombre de la aplicación), STATE, DETAILS

Enum ActivityType

El Enum ActivityType especifica qué tipo de actividad se está mostrando. Se importa de pypresence.types.

Valores disponibles:

  • ActivityType.PLAYING (0) - Muestra "Jugando {nombre del juego}" (predeterminado)
  • ActivityType.LISTENING (2) - Muestra "Escuchando {nombre}"
  • ActivityType.WATCHING (3) - Muestra "Viendo {nombre}"
  • ActivityType.COMPETING (5) - Muestra "Compitiendo en {nombre}"

Ejemplo de uso:

from pypresence import Presence
from pypresence.types import ActivityType
RPC = Presence(client_id)
RPC.connect()
RPC.update(
    activity_type=ActivityType.LISTENING,
    details="Mi canción favorita",
    state="De mi artista favorito"
)

Nota: Discord solo admite los tipos de actividad 0, 2, 3 y 5. Los tipos 1 (STREAMING) y 4 (CUSTOM) no están disponibles a través de Presencia Rica.

Enum StatusDisplayType

El Enum StatusDisplayType controla qué campo de tu presencia se muestra en el estado del usuario. Se importa de pypresence.types.

Valores disponibles:

  • StatusDisplayType.NAME (0) - Muestra el nombre de la aplicación (predeterminado)
  • StatusDisplayType.STATE (1) - Muestra el campo state
  • StatusDisplayType.DETAILS (2) - Muestra el campo details

Ejemplo de uso:

from pypresence import Presence
from pypresence.types import StatusDisplayType
RPC = Presence(client_id)
RPC.connect()
RPC.update(
    status_display_type=StatusDisplayType.STATE,
    state="Mensaje de estado personalizado",
    details="Lo que estoy haciendo"
)

Esto te permite controlar lo que aparece en la barra de estado de Discord del usuario mientras mantienes toda la información en la visualización completa de Presencia Rica.

  • args (dict) -- optional args used in subscription
