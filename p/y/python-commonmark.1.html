commonmark-py - Documentación de commonmark.py

commonmark.py se prueba contra la especificación CommonMark con versiones de Python 2.7, 3.4, 3.5, 3.6 y 3.7.

Versión actual: 0.9.1

INSTALACIÓN

$ pip install commonmark

USO

>>> import commonmark
>>> commonmark.commonmark('*hola!*')
'<p><em>hola!</em></p>\n'

O, sin el azúcar sintáctico:

import commonmark
parser = commonmark.Parser()
ast = parser.parse("Hola *Mundo*")
renderer = commonmark.HtmlRenderer()
html = renderer.render(ast)
print(html) # <p>Hola <em>Mundo</em><p/>
# inspeccionando el árbol de sintaxis abstracta
json = commonmark.dumpJSON(ast)
commonmark.dumpAST(ast) # impresión formateada de la estructura AST generada

PRUEBAS

Para trabajar en commonmark.py, necesitará poder ejecutar la suite de pruebas para asegurarse de que sus cambios no rompan nada. Para ejecutar las pruebas, puede hacer algo como esto:

$ pyvenv venv
$ ./venv/bin/python setup.py develop test

El script de pruebas, commonmark/tests/run_spec_tests.py, es básicamente una herramienta de desarrollo. Además de ejecutar todas las pruebas incrustadas en spec.txt, también le permite ejecutar pruebas específicas usando el argumento -t, proporcionar información sobre las pruebas pasadas con -p, el porcentaje de pruebas pasadas por categoría con -s, y entrar en modo Markdown interactivo con -i (En modo interactivo, finalice un bloque introduciendo una línea con solo end, para salir haga lo mismo pero con quit). -d se puede usar para imprimir el rastreo de llamadas.

agregar_hijo(etiqueta, offset)
Agrega un bloque del tipo etiqueta como hijo del elemento superior. Si el elemento superior no puede aceptar hijos, se cierra y finaliza, y se intenta con su padre, y así sucesivamente hasta encontrar un bloque que pueda aceptar hijos.
agregar_linea()
Agrega una línea al bloque en el elemento superior. Asumimos que el elemento superior puede aceptar líneas; esa comprobación debe hacerse antes de llamar a esto.

Finaliza y cierra cualquier bloque no emparejado.
finalizar(bloque, numero_linea)
Finaliza un bloque. Lo cierra y realiza cualquier postprocesamiento necesario, por ejemplo, creando `string_content` a partir de cadenas, estableciendo el estado 'tight' o 'loose' de una lista, y analizando los inicios de párrafos para definiciones de referencia. Restablece el elemento superior al padre del bloque cerrado.

NAME

commonmark — Python library for parsing and rendering CommonMark

INSTALLATION

Install the latest stable release from PyPI:

pip install --upgrade commonmark

USAGE

The `commonmark` package can be used in Python code to parse and render Markdown text.

Here is a basic example:

import commonmark

markdown_text = "# Hello, World!\n\nThis is some **bold** text."
ast = commonmark.parse(markdown_text)

# You can then walk the AST or render it.
# For example, to render to HTML:
html = commonmark.dump_html(ast)
print(html)
# Output:
# 
Hello, World!

# 
This is some bold text.
