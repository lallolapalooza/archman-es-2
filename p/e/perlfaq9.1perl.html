perlfaq9 - Web, Email y Redes

VERSIÓN

version 5.20250619

DESCRIPCIÓN

Esta sección trata sobre preguntas relacionadas con la ejecución de sitios web, el envío y la recepción de correos electrónicos, así como la gestión de redes en general.

¿Debería usar un framework web?

Sí. Si está creando un sitio web con algún nivel de interactividad (formularios / usuarios / bases de datos), querrá usar un framework para facilitar el manejo de solicitudes y respuestas.

Si no hay interactividad, aún puede considerar usar algo como Template Toolkit https://metacpan.org/module/Template o Plack::Middleware::TemplateToolkit para que el mantenimiento de sus archivos HTML (y otros recursos) sea más fácil.

¿Qué framework web debería usar?

No hay una respuesta simple a esta pregunta. Los frameworks de Perl pueden manejar desde servidores de archivos básicos e intranets a pequeña escala hasta sitios web masivos multinacionales y multilingües que son el núcleo de negocios internacionales.

A continuación, se presenta una lista de algunos frameworks con comentarios que podrían ayudarlo a tomar una decisión, dependiendo de sus requisitos específicos. Comience leyendo la documentación, luego haga preguntas en la lista de correo o canal de IRC correspondiente.

Catalyst
Fuertemente orientado a objetos y con todas las funcionalidades, con un largo historial de desarrollo y una gran comunidad y ecosistema de complementos. Es excelente para aplicaciones grandes y complejas, donde usted tiene control total sobre el servidor.
Dancer2
Libre de peso heredado, proporciona una API ligera y fácil de aprender. Tiene un ecosistema de complementos en crecimiento. Se utiliza mejor para proyectos más pequeños y es muy fácil de aprender para principiantes.
Mojolicious
Autocontenido y potente tanto para proyectos pequeños como grandes, con un enfoque en HTML5 y tecnologías web en tiempo real como WebSockets.
Web::Simple
Fuertemente orientado a objetos y minimalista, construido para la velocidad y destinado como un conjunto de herramientas para construir micro aplicaciones web, frameworks personalizados o para conectar aplicaciones web compatibles con Plack existentes con un despachador central.

Todos estos interactúan o utilizan Plack, lo que vale la pena entender sus conceptos básicos al construir un sitio web en Perl (hay muchos Plack::Middleware útiles https://metacpan.org/search?q=plack%3A%3Amiddleware).

¿Qué es Plack y PSGI?

PSGI es la Especificación de la Interfaz de la Puerta de Enlace del Servidor Web de Perl, es un estándar que utilizan muchos frameworks web de Perl, no debería necesitar entenderlo para construir un sitio web, la parte que podría querer usar es Plack.

Plack es un conjunto de herramientas para usar la pila PSGI. Contiene componentes de middleware https://metacpan.org/search?q=plack%3A%3Amiddleware, un servidor de referencia y utilidades para frameworks de aplicaciones web. Plack es como Rack de Ruby o Paste de Python para WSGI.

Podría construir un sitio web usando Plack y su propio código, pero para cualquier cosa que no sea un sitio web muy básico, usar un framework web (que utiliza https://plackperl.org) es una mejor opción.

¿Cómo elimino HTML de una cadena?

Use HTML::Strip, o HTML::FormatText que no solo elimina HTML sino que también intenta hacer un formato simple del texto plano resultante.

¿Cómo extraigo URLs?

HTML::SimpleLinkExtor extraerá URLs de HTML, maneja anclas, imágenes, objetos, frames y muchas otras etiquetas que pueden contener una URL. Si necesita algo más complejo, puede crear su propia subclase de HTML::LinkExtor o HTML::Parser. Incluso podría usar HTML::SimpleLinkExtor como ejemplo para algo específicamente adecuado a sus necesidades.

Puede usar URI::Find o URL::Search para extraer URLs de un documento de texto arbitrario.

¿Cómo obtengo un archivo HTML?

(contribuido por brian d foy)

El módulo central HTTP::Tiny puede obtener recursos web y devolver su contenido como una cadena:

use HTTP::Tiny;
my $ua = HTTP::Tiny->new;
my $html = $ua->get( "http://www.example.com/index.html" )->{content};

También puede almacenar el recurso directamente en un archivo:

$ua->mirror( "http://www.example.com/index.html", "foo.html" );

Si necesita hacer algo más complicado, el objeto HTTP::Tiny puede ser personalizado estableciendo atributos, o puede usar LWP::UserAgent de la distribución libwww-perl o Mojo::UserAgent de la distribución Mojolicious para facilitar tareas comunes. Si desea simular un navegador web interactivo, puede usar el módulo WWW::Mechanize.

¿Cómo automatizo el envío de un formulario HTML?

Si está haciendo algo complejo, como navegar por muchas páginas y formularios o un sitio web, puede usar WWW::Mechanize. Consulte su documentación para obtener todos los detalles.

Si está enviando valores usando el método GET, cree una URL y codifique el formulario usando el método "www_form_urlencode" de HTTP::Tiny:

use HTTP::Tiny;
my $ua = HTTP::Tiny->new;
my $query = $ua->www_form_urlencode([ q => 'DB_File', lucky => 1 ]);
my $url = "https://metacpan.org/search?$query";
my $content = $ua->get($url)->{content};

Si está utilizando el método POST, el método "post_form" codificará el contenido apropiadamente.

use HTTP::Tiny;
my $ua = HTTP::Tiny->new;
my $url = 'https://metacpan.org/search';
my $form = [ q => 'DB_File', lucky => 1 ];
my $content = $ua->post_form($url, $form)->{content};

¿Cómo decodifico o creo esas codificaciones % en la web?

La mayoría de las veces no necesitará hacer esto, ya que su framework web, o si está haciendo una solicitud, LWP u otro módulo lo manejarán por usted.

Para codificar una cadena usted mismo, use el módulo URI::Escape. La función "uri_escape" devuelve la cadena codificada:

my $original = "Colon : Hash # Percent %";
my $escaped = uri_escape( $original );
print "$escaped\n"; # 'Colon%20%3A%20Hash%20%23%20Percent%20%25'

Para decodificar la cadena, use la función "uri_unescape":

my $unescaped = uri_unescape( $escaped );
print $unescaped; # de vuelta al original

Recuerde no codificar una URI completa, necesita escapar cada componente por separado y luego unirlos.

¿Cómo redirijo a otra página?

La mayoría de los Frameworks Web de Perl tendrán un mecanismo para hacer esto, usando el framework Catalyst sería:

$c->res->redirect($url);
$c->detach();

Si está usando Plack (que la mayoría de los frameworks hacen), entonces Plack::Middleware::Rewrite vale la pena considerarlo si está migrando desde Apache o tiene URLs que desea redirigir siempre.

¿Cómo pongo una contraseña en mis páginas web?

Verifique si el framework web que está utilizando tiene un sistema de autenticación y si este se ajusta a sus necesidades.

Alternativamente, considere Plack::Middleware::Auth::Basic, o uno de

otras opciones de autenticación de Plack https://metacpan.org/search?q=plack+auth.

¿Cómo me aseguro de que los usuarios no puedan introducir valores en un formulario que hagan que mi script CGI haga cosas malas?

(contribuido por brian d foy)

No puedes evitar que la gente envíe datos incorrectos a tu script. Incluso si agregas algunas comprobaciones del lado del cliente, la gente puede deshabilitarlas o evitarlas por completo. Por ejemplo, alguien podría usar un módulo como LWP para enviar a tu sitio web. Si quieres evitar datos que intenten usar inyección SQL u otros tipos de ataques (y deberías quererlo), tienes que no confiar en ningún dato que entre en tu programa.

La documentación de perlsec tiene consejos generales sobre seguridad de datos. Si estás usando el módulo DBI, usa marcadores de posición para rellenar los datos. Si estás ejecutando programas externos con "system" o "exec", usa las formas de lista. Hay muchas otras precauciones que deberías tomar, demasiadas para enumerarlas aquí, y la mayoría de ellas caen en la categoría de no usar ningún dato que no pretendas usar. No confíes en nadie.

¿Cómo analizo una cabecera de correo?

Usa el módulo Email::MIME. Está bien probado y soporta toda la locura que verás en el mundo real (espacio en blanco para plegar comentarios, codificaciones, comentarios, etc.).

use Email::MIME;
my $message = Email::MIME->new($rfc2822);
my $subject = $message->header('Subject');
my $from    = $message->header('From');

Si ya tienes algún otro tipo de objeto de correo electrónico, considera pasarlo a Email::Abstract y luego usar su método cast para obtener un objeto Email::MIME:

my $abstract = Email::Abstract->new($mail_message_object);
my $email_mime_object = $abstract->cast('Email::MIME');

¿Cómo verifico una dirección de correo válida?

(parcialmente contribuido por Aaron Sherman)

Esta pregunta no es tan simple como parece. Hay dos partes:

a) ¿Cómo verifico que una dirección de correo electrónico tiene el formato correcto?

b) ¿Cómo verifico que una dirección de correo electrónico se dirige a un destinatario válido?

Sin enviar un correo a la dirección y ver si hay un humano al otro lado para responderte, no puedes responder completamente la parte b, pero el módulo Email::Valid hará ambas partes a y b tanto como sea posible en tiempo real.

Nuestro mejor consejo para verificar la dirección de correo de una persona es pedirles que introduzcan su dirección dos veces, como normalmente haces para cambiar una contraseña. Esto generalmente elimina errores tipográficos. Si ambas versiones coinciden, envía un correo a esa dirección con un mensaje personal. Si recibes el mensaje y han seguido tus instrucciones, puedes estar razonablemente seguro de que es real.

Una estrategia relacionada que es menos susceptible a la falsificación es darles un PIN (número de identificación personal). Registra la dirección y el PIN (es mejor que sea aleatorio) para su posterior procesamiento. En el correo que envíes, incluye un enlace a tu sitio web con el PIN incluido. Si el correo rebota, sabes que no es válido. Si no hacen clic en el enlace, o falsificaron la dirección o (asumiendo que recibieron el mensaje) seguir adelante no fue importante, así que no tienes que preocuparte por ello.

¿Cómo decodifico una cadena MIME/BASE64?

El paquete MIME::Base64 se encarga de esto, así como de la codificación MIME/QP. Decodificar base 64 se vuelve tan simple como:

use MIME::Base64;
my $decoded = decode_base64($encoded);

El módulo Email::MIME puede decodificar partes de mensajes de correo codificados en base 64 de forma transparente, para que el desarrollador no tenga que preocuparse por ello.

¿Cómo encuentro la dirección de correo del usuario?

Pídesela. Hay tantos proveedores de correo electrónico disponibles que es poco probable que el sistema local tenga idea de cómo determinar la dirección de correo electrónico de un usuario.

La excepción es para el correo electrónico específico de la organización (por ejemplo, foo@tuempresa.com) donde la política se puede codificar en tu programa. En ese caso, podrías mirar $ENV{USER}, $ENV{LOGNAME}, y getpwuid($<) en contexto escalar, así:

my $user_name = getpwuid($<)

Pero aún así no puedes hacer suposiciones sobre si esto es correcto, a menos que tu política diga que lo es. Realmente es mejor preguntar al usuario.

¿Cómo envío un correo electrónico?

Usa el módulo Email::Stuffer, así:

# primero, crea tu mensaje
my $message = Email::Stuffer->from('tú@ejemplo.com')
                            ->to('amigo@ejemplo.com')
                            ->subject('¡Feliz cumpleaños!')
                            ->text_body("¡Feliz cumpleaños a ti!\n");
$message->send_or_die;

Por defecto, Email::Sender::Simple (los métodos "send" y "send_or_die" usan esto internamente) intentará usar "sendmail" primero, si existe en tu $PATH. Esto generalmente no es el caso. Si hay un servidor de correo remoto que usas para enviar correo, considera investigar una de las clases Transport. En el momento de escribir esto, los transportes disponibles incluyen:

Email::Sender::Transport::Sendmail
Este es el valor predeterminado. Si puedes usar el programa mail(1) o mailx(1) para enviar correo desde la máquina donde se ejecuta tu código, deberías poder usarlo.
Email::Sender::Transport::SMTP
Este transporte contacta a un servidor SMTP remoto a través de TCP. Opcionalmente usa TLS o SSL y puede autenticarse al servidor a través de SASL.

Indicarle a Email::Stuffer que use tu transporte es sencillo.

$message->transport($email_sender_transport_object)->send_or_die;

¿Cómo uso MIME para hacer un adjunto a un mensaje de correo?

Email::MIME soporta directamente mensajes multipartes. Los propios objetos Email::MIME son partes y pueden adjuntarse a otros objetos Email::MIME. Consulta la documentación de Email::MIME para obtener más información, incluyendo todos los métodos soportados y ejemplos de su uso.

Email::Stuffer usa Email::MIME internamente para construir mensajes y envuelve las tareas de adjunto más comunes con los sencillos métodos "attach" y "attach_file".

Email::Stuffer->to('amigo@ejemplo.com')
              ->subject('El archivo')
              ->attach_file('stuff.csv')
              ->send_or_die;

¿Cómo leo correo electrónico?

Usa el módulo Email::Folder, así:

use Email::Folder;
my $folder = Email::Folder->new('/ruta/a/la/carpeta/de/correo');
while(my $message = $folder->next_message) {
  # next_message devuelve objetos Email::Simple, pero queremos
  # objetos Email::MIME ya que son más robustos
  my $mime = Email::MIME->new($message->as_string);
}

Hay diferentes clases en el espacio de nombres Email::Folder para soportar varios tipos de buzones. Ten en cuenta que estos módulos son generalmente bastante limitados y solo soportan la **lectura**, no la escritura.

¿Cómo averiguo mi nombre de host, nombre de dominio o dirección IP?

(contribuido por brian d foy)

El módulo Net::Domain, que forma parte de la Biblioteca Estándar a partir de Perl 5.7.3, puede proporcionarte el nombre de dominio completo (FQDN), el nombre del host o el nombre del dominio.

use Net::Domain qw(hostname hostfqdn hostdomain);
my $host = hostfqdn();

El módulo Sys::Hostname, parte de la Biblioteca Estándar, también puede obtener el nombre del host:

use Sys::Hostname;
$host = hostname();

El módulo Sys::Hostname::Long adopta un enfoque diferente y se esfuerza más por devolver el nombre de host completo:

use Sys::Hostname::Long 'hostname_long';
my $hostname = hostname_long();

Para obtener la dirección IP, puedes usar la función integrada "gethostbyname" para convertir el nombre en un número. Para convertir ese número en la forma de octeto punto (a.b.c.d) que la mayoría de la gente espera, usa la función "inet_ntoa" del módulo Socket, que también viene con perl.

use Socket;
my $address = inet_ntoa(
    scalar gethostbyname( $host || 'localhost' )
);

¿Cómo descargo/subo un archivo (S)FTP?

Net::FTP y Net::SFTP te permiten interactuar con servidores FTP y SFTP (FTP seguro).

¿Cómo puedo hacer RPC en Perl?

Usa uno de los módulos RPC ( https://metacpan.org/search?q=RPC ).
