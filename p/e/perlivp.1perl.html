PERLIVP(1perl) Guía de Referencia del Programador de Perl PERLIVP(1perl)

NOMBRE

perlivp - Procedimiento de Verificación de Instalación de Perl

SINOPSIS

perlivp [-p] [-v] [-h]

DESCRIPCIÓN

El programa perlivp se configura en el momento de compilación del código fuente de Perl para probar la versión de Perl bajo la que fue compilado. Puede usarse después de ejecutar:

make install

(o el procedimiento equivalente de tu plataforma) para verificar que perl y sus bibliotecas se han instalado correctamente. Una instalación correcta se verifica mediante una salida que se parece a:

ok 1
ok 2

etc.

OPCIONES

-h ayuda
Imprime un breve mensaje de ayuda.
-p imprimir prefacio
Proporciona una descripción de cada prueba antes de realizarla.
-v detallado
Proporciona información más detallada sobre cada prueba, después de haberla realizado. Ten en cuenta que cualquier prueba fallida debería imprimir información adicional independientemente de si se usa o no -v.

DIAGNÓSTICOS

  • print "# El binario de Perl '$perlpath' no parece ser ejecutable.\n";

    Es probable que ocurra con un binario de perl que no se instaló correctamente. Corrige realizando una instalación adecuada.

  • print "# Versión de Perl '$]' instalada, se esperaba $ivp_VERSION.\n";

    Es probable que ocurra con un perl que no se instaló correctamente. Corrige realizando una instalación adecuada.

  • print "# El directorio \@INC de Perl '$_' no parece existir.\n";

    Es probable que ocurra con un árbol de bibliotecas de perl que no se instaló correctamente. Corrige realizando una instalación adecuada.

  • print "# El módulo necesario '$_' no parece estar instalado correctamente.\n";

    Uno de los dos módulos que utiliza perlivp no estaba presente en la instalación. Este es un error grave ya que afecta negativamente la capacidad de perlivp para funcionar. Puedes intentar corregir esto realizando una instalación adecuada de perl.

  • print "# El módulo requerido '$_' no parece estar instalado correctamente.\n";

    Un intento de "eval " require $module"" falló, a pesar de que la lista de extensiones indicaba que debería tener éxito. Corrige realizando una instalación adecuada.

  • print "# El módulo innecesario 'bLuRfle' parece estar instalado.\n";

    Que esta prueba no resulte ok podría indicar que de hecho has instalado un módulo bLuRfle.pm o que la prueba "eval " require \"$module_name.pm\"; "" puede dar resultados engañosos con tu instalación de perl. Si este es tu caso, por favor informa al autor.

  • print "# Archivo",+($#missing == 0) ? '' : 's'," faltantes de la instalación:\n";

    Uno o más archivos resultaron faltantes según una ejecución de "ExtUtils::Installed -> validate()" sobre tu instalación. Corrige realizando una instalación adecuada.

Para obtener más información sobre cómo realizar una instalación adecuada, consulta el archivo INSTALL que viene con el código fuente de perl y el archivo README para tu plataforma.
