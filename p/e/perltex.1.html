NOMBRE

perltex - permite definir macros de LaTeX en términos de código Perl

SINOPSIS

perltex [--help] [--latex=programa] [--[no]safe] [--permit=característica] [--makesty] [opciones de latex]

DESCRIPCIÓN

LaTeX, a través del sistema de composición de textos TeX subyacente, produce documentos bellamente compuestos, pero tiene un lenguaje de macros difícil de programar. En particular, la compatibilidad con la manipulación compleja de cadenas de texto es en gran medida inexistente. Perl es un lenguaje de programación de propósito general popular cuyo fuerte es la manipulación de cadenas de texto. Sin embargo, no tiene capacidades de composición de textos en absoluto.

Claramente, la programabilidad de Perl podría complementar las fortalezas de composición de textos de LaTeX. perltex es la herramienta que permite una simbiosis entre los dos sistemas. Todo lo que el usuario necesita hacer es compilar un documento LaTeX usando perltex en lugar de latex. (perltex es en realidad un envoltorio para latex, por lo que no se pierde ninguna funcionalidad de latex). Si el documento incluye un "\usepackage{perltex}" en su preámbulo, se pondrán a disposición las macros "\perlnewcommand" y "\perlrenewcommand". Estas se comportan igual que las macros de LaTeX "\newcommand" y "\renewcommand", excepto que el cuerpo de la macro contiene código Perl en lugar de código LaTeX.

OPCIONES

perltex acepta las siguientes opciones de línea de comandos:

--help
Muestra información básica de uso.
--latex=programa
Especifica un programa a usar en lugar de latex. Por ejemplo, "--latex=pdflatex" compondrá el documento dado usando pdflatex en lugar del latex normal.
--[no]safe
Habilita o deshabilita el aislamiento. Con la opción predeterminada --safe, perltex ejecuta el código de una macro "\perlnewcommand" o "\perlrenewcommand" dentro de un entorno protegido que prohíbe operaciones ``inseguras'' como acceder a archivos o ejecutar programas externos. Especificar --nosafe otorga al documento LaTeX carta blanca para ejecutar cualquier código Perl arbitrario, incluido aquel que pueda dañar los archivos del usuario. Ver Safe para más información.
--permit=característica
Permite realizar operaciones Perl particulares. La opción --permit, que se puede especificar más de una vez en la línea de comandos, permite un control más granular sobre el sandbox de perltex. Ver Opcode para más información.
--makesty
Genera un archivo de estilo LaTeX llamado noperltex.sty. Reemplazar la línea "\usepackage{perltex}" del documento por "\usepackage{noperltex}" produce el mismo resultado pero no requiere PerlTeX, lo que hace que el documento sea adecuado para su distribución a personas que no tengan PerlTeX instalado. La desventaja es que noperltex.sty es específico del documento que lo produjo. Cualquier cambio en las definiciones de macros o invocaciones de macros de PerlTeX del documento requiere volver a ejecutar perltex con la opción --makesty.

Estas opciones van seguidas de las opciones que normalmente se pasan a latex (o al programa que se especificó con "--latex"), incluido, por ejemplo, el nombre del archivo .tex a compilar.

EJEMPLOS

En su forma más simple, perltex se ejecuta igual que latex:

perltex myfile.tex

Para usar pdflatex en lugar de latex normal, usa la opción --latex:

perltex --latex=pdflatex myfile.tex

Si LaTeX da un error de tipo "``"atrapado por máscara de operación"''" y confías en que el archivo .tex que estás intentando compilar no ejecutará código Perl malicioso (por ejemplo, porque lo escribiste tú mismo), puedes deshabilitar los mecanismos de seguridad de perltex con --nosafe:

perltex --nosafe myfile.tex

El siguiente comando otorga a los documentos solo los permisos predeterminados de perltex (":browse") más la capacidad de abrir archivos e invocar el comando "time":

perltex --permit=:browse --permit=:filesys_open
  --permit=time myfile.tex

ENTORNO

perltex respeta las siguientes variables de entorno:

PERLTEX
Especifica el nombre del archivo del compilador LaTeX. El compilador LaTeX predeterminado es ``"latex"''. La variable de entorno "PERLTEX" anula este valor predeterminado, y la opción de línea de comandos --latex (ver "OPCIONES") la anula.

ARCHIVOS

Mientras compila jobname.tex, perltex utiliza los siguientes archivos:

jobname.lgpl
archivo de registro escrito por Perl; útil para depurar macros de Perl
jobname.topl
información enviada de LaTeX a Perl
jobname.frpl
información enviada de Perl a LaTeX
jobname.tfpl
archivo de "bandera" cuya existencia indica que jobname.topl contiene datos válidos
jobname.ffpl
archivo de "bandera" cuya existencia indica que jobname.frpl contiene datos válidos
jobname.dfpl
archivo de "bandera" cuya existencia indica que jobname.ffpl ha sido eliminado
noperltex-#.tex
archivo generado por noperltex.sty para cada invocación de macro de PerlTeX

NOTAS

El sandbox de perltex tiene como valor predeterminado lo que Opcode llama ``":browse"''.

    perltex - Un procesador de TeX con Perl integrado

    SYNOPSIS

    perltex [OPCIONES] [ARCHIVOS]

    DESCRIPTION

    perltex es un procesador de TeX que integra Perl. Permite incrustar código Perl en documentos TeX y ejecutarlo durante la compilación de TeX.

    Esto abre una gran cantidad de posibilidades para la generación dinámica de contenido, la automatización de tareas complejas y la creación de macros personalizadas.

    OPTIONS

    -v, --version
    Muestra la versión de perltex y sale.
    -h, --help
    Muestra un mensaje de ayuda y sale.
    -I directorio
    Añade un directorio a la ruta de búsqueda de módulos de Perl.
    -P opciones
    Pasa opciones al intérprete de Perl.
    -W
    Habilita todas las advertencias de Perl.
    -k
    Permite el uso de caracteres no ASCII en el código fuente de Perl.

    EXAMPLES

    perltex mi_documento.tex

    Compila el documento TeX mi_documento.tex usando perltex.

    perltex -P -MUTF8 -e 'print "¡Hola, mundo!\n"' mi_documento.tex

    Compila un documento TeX pasando opciones a Perl, incluyendo la carga del módulo UTF8 y la ejecución de un fragmento de código.

    ENVIRONMENT

    TEXINPUTS: Variable de entorno que especifica directorios de búsqueda adicionales para archivos de entrada de TeX.

    PERL5LIB: Variable de entorno que especifica directorios de búsqueda adicionales para módulos de Perl.

    FILES

    <nombre_archivo>.tex: Archivo de entrada principal de TeX.

    <nombre_archivo>.log: Archivo de registro de la compilación.

    <nombre_archivo>.dvi: Archivo de salida en formato Device Independent.

    NOTES

    El código Perl incrustado se ejecutará durante la fase de compilación de TeX. Asegúrate de que tu código Perl sea seguro para ejecutarlo en este contexto.

    La salida del código Perl se insertará en el flujo de procesamiento de TeX. Esto puede incluir texto, comandos de TeX o macros.

    tex(1), latex(1), perl(1)
