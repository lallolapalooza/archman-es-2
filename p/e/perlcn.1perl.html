PERLCN(1perl) Guía de referencia para programadores de Perl PERLCN(1perl)

NOMBRE

perlcn - Guía de Perl en chino simplificado

DESCRIPCIÓN

¡Bienvenido al paraíso de Perl!

Desde la versión 5.8.0, Perl ha incorporado soporte completo para Unicode (codificación unificada), y también soporta muchos esquemas de codificación además de los de latín; CJK (chino, japonés, coreano) es solo una parte de ellos. Unicode es un estándar internacional que intenta cubrir todos los caracteres del mundo: el mundo occidental, el mundo oriental y todo lo que hay entre medias (latín, griego, árabe, hebreo, hindi, tailandés, etc.). También abarca muchos sistemas operativos y plataformas (como PC y Mac).

El propio Perl opera en Unicode. Esto significa que los datos de cadenas dentro de Perl se pueden representar en Unicode; las funciones y operadores de Perl (como la coincidencia de expresiones regulares) también pueden operar en Unicode. Al leer y escribir, para manejar datos almacenados en esquemas de codificación anteriores a Unicode, Perl proporciona el módulo Encode, que le permite leer y escribir fácilmente datos en esquemas de codificación antiguos.

El módulo de extensión Encode soporta los siguientes esquemas de codificación de chino simplificado ('gb2312' representa 'euc-cn'):

euc-cn      Extensión de conjunto de caracteres Unix, también conocida como código nacional
gb2312-raw  Tabla de caracteres GB2312 sin procesar (lower-bit)
gb12345     Codificación de caracteres chinos tradicionales de China sin procesar
iso-ir-165  GB2312 + GB6345 + GB8565 + caracteres recién añadidos
cp936       Página de códigos 936, también se puede especificar como 'GBK' (extensión del código nacional)
hz          GB2312 en modo de escape de 7 bits

Por ejemplo, para convertir un archivo codificado en EUC-CN a Unicode, solo necesita introducir el siguiente comando:

perl -Mencoding=euc-cn,STDOUT,utf8 -pe1 < file.euc-cn > file.utf8

Perl también incluye "piconv", una utilidad completa de conversión de caracteres escrita en Perl, que se usa de la siguiente manera:

piconv -f euc-cn -t utf8 < file.euc-cn > file.utf8
piconv -f utf8 -t euc-cn < file.utf8 > file.euc-cn

Además, utilizando el módulo encoding, puede escribir fácilmente código que opere por caracteres, como se muestra a continuación:

#!/usr/bin/env perl
# Inicializar el análisis de cadenas euc-cn; la salida estándar y el error estándar se establecen en codificación euc-cn
use encoding 'euc-cn', STDIN => 'euc-cn', STDOUT => 'euc-cn';
print length("骆驼");      #  2 (comillas dobles indican caracteres)
print length('骆驼');      #  4 (comillas simples indican bytes)
print index("谆谆教诲", "蛔唤"); # -1 (no contiene esta subcadena)
print index('谆谆教诲', '蛔唤'); #  1 (comienza desde el segundo byte)

En el último ejemplo, el segundo byte de "谆" se combina con el primer byte de "谆" para formar el código EUC-CN para "蛔"; el segundo byte de "谆" se combina luego con el primer byte de "教" para formar "唤". Esto resuelve el problema común de coincidencia de códigos EUC-CN.

网额外的中文编码

Si necesita más codificaciones de caracteres chinos, puede descargar el módulo Encode::HanExtra de CPAN (https://www.cpan.org/). Actualmente proporciona la siguiente codificación:

gb18030     Código nacional extendido, incluye chino tradicional

El módulo Encode::HanConvert proporciona conversiones bidireccionales de dos codificaciones:

big5-simp   Conversión bidireccional de chino tradicional Big5 a chino simplificado Unicode
gbk-trad    Conversión bidireccional de chino simplificado GBK a chino tradicional Unicode

Si desea convertir entre GBK y Big5, consulte los programas b2g.pl y g2b.pl incluidos en este módulo, o utilice la siguiente escritura dentro de su programa:

use Encode::HanConvert;
$euc_cn = big5_to_gb($big5); # Convertir de Big5 a GBK
$big5 = gb_to_big5($euc_cn); # Convertir de GBK a Big5
