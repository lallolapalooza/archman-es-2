perltodo - Enlace a la lista de tareas pendientes de Perl

DESCRIPCIÓN

La lista de tareas pendientes de Perl 5 se mantiene en el repositorio git y se puede ver en https://github.com/Perl/perl5/blob/blead/Porting/todo.pod.

(La lista de tareas pendientes solía estar aquí en perltodo. Eso ha cesado, ya que instalar una instantánea que se vuelve cada vez más desactualizada no es muy útil para nadie).
