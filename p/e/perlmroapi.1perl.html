PERLMROAPI(1perl) Guía de Referencia del Programador de Perl PERLMROAPI(1perl)

NOMBRE

perlmroapi - Interfaz de plugin para el orden de resolución de métodos de Perl

DESCRIPCIÓN

A partir de Perl 5.10.1, existe una nueva interfaz para conectar y utilizar órdenes de resolución de métodos distintas de la predeterminada (búsqueda lineal en profundidad). El orden de resolución de métodos C3 añadido en 5.10.0 se ha reimplementado como un plugin, sin cambiar su interfaz en espacio de Perl.

Cada plugin debe registrarse proporcionando la siguiente estructura

struct mro_alg {
    AV *(*resolve)(pTHX_ HV *stash, U32 level);
    const char *name;
    U16 length;
    U16 kflags;
    U32 hash;
};

y llamando a "Perl_mro_register":

Perl_mro_register(aTHX_ &my_mro_alg);
resolve
Puntero a la función de linealización, descrita a continuación.
name
Nombre del MRO, en ISO-8859-1 o UTF-8.
length
Longitud del nombre.
kflags
Si el nombre se proporciona en UTF-8, establezca esto en "HVhek_UTF8". El valor se pasa directamente como parámetro kflags a hv_common().
hash
Un valor de hash precalculado para el nombre del MRO, o 0.

Callbacks

La función "resolve" se llama para generar un ISA linealizado para el stash dado, utilizando este MRO. Se llama con un puntero al stash y un level de 0. El núcleo siempre establece level en 0 cuando llama a su función; el parámetro se proporciona para permitir que su implementación rastree la profundidad si necesita recursión.

La función debe devolver una referencia a un array que contiene SV de tipo string que dan los nombres de las clases padre en orden. Los nombres de las clases deben ser el resultado de llamar a HvENAME() en el stash. En los casos en que HvENAME() devuelva nulo, se debe usar HvNAME() en su lugar.

El llamador es responsable de incrementar el contador de referencias del array devuelto si desea conservar la estructura. Por lo tanto, si ha creado un valor temporal del que no guarda un puntero, use sv_2mortal() para asegurar que se deseche correctamente. Si ha almacenado en caché su valor de retorno, devuelva un puntero a él sin cambiar el contador de referencias.

Almacenamiento en caché

Calcular MROs puede ser costoso. La implementación proporciona una caché, en la que puede almacenar un único "SV *", o cualquier cosa que pueda convertirse a "SV *", como "AV *". Para leer sus datos privados, use la macro MRO_GET_PRIVATE_DATA(), pasándole la estructura "mro_meta" del stash y un puntero a su estructura "mro_alg":

meta = HvMROMETA(stash);
private_sv = MRO_GET_PRIVATE_DATA(meta, &my_mro_alg);

Para establecer su valor privado, llame a Perl_mro_set_private_data():

Perl_mro_set_private_data(aTHX_ meta, &c3_alg, private_sv);

La caché de datos privados se apropiará de una referencia a private_sv, de forma muy similar a como hv_store() se apropia de una referencia al valor que le pasa.

Ejemplos

Para ver ejemplos de implementaciones de MRO, consulte S_mro_get_linear_isa_c3() y la sección "BOOT:" de ext/mro/mro.xs, y S_mro_get_linear_isa_dfs() en mro_core.c
