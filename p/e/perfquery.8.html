perfquery(8) Diagnósticos Open IB perfquery(8)

Nombre

perfquery - consulta los contadores de puertos InfiniBand en un solo puerto

SINOPSIS

perfquery [opciones] [<lid|guid> [[puerto(s)] [máscara_reset]]]

DESCRIPCIÓN

perfquery utiliza GMPs de PerfMgt para obtener los PortCounters (contadores básicos de rendimiento y errores), PortExtendedCounters, PortXmitDataSL, PortRcvDataSL, PortRcvErrorDetails, PortXmitDiscardDetails, PortExtendedSpeedsCounters o PortSamplesControl del PMA en el nodo/puerto especificado. Opcionalmente, muestra los contadores agregados para todos los puertos del nodo. Finalmente, puede restablecer después de la lectura o simplemente restablecer los contadores.

Nota: En PortCounters, PortCountersExtended, PortXmitDataSL y PortRcvDataSL, los componentes que representan datos (por ejemplo, PortXmitData y PortRcvData) indican octetos divididos por 4 en lugar de solo octetos.

Nota: Ingresar un puerto de 255 indica que se realizará una operación en todos los puertos.

Nota: Para PortCounters, ExtendedCounters y restablecimientos, se pueden especificar varios puertos mediante una lista separada por comas o un rango de puertos. Ver ejemplos a continuación.

OPCIONES

-x, --extended
muestra contadores de puerto extendidos en lugar de contadores de puerto (básicos). Tenga en cuenta que el atributo de contadores de puerto extendidos es opcional.
-X, --xmtsl
muestra el contador de datos de transmisión SL. Este es un contador opcional para QoS.
-S, --rcvsl
muestra el contador de datos de recepción SL. Este es un contador opcional para QoS.
-D, --xmtdisc
muestra detalles de descarte de transmisión. Este es un contador opcional.
-E, --rcverr
muestra detalles de error de recepción. Este es un contador opcional.
-D, --xmtdisc
muestra detalles de descarte de transmisión. Este es un contador opcional.
-T, --extended_speeds
muestra contadores de puertos de velocidades extendidas. Este es un contador opcional.
--oprcvcounters
muestra Contadores de Recepción por código de operación. Este es un contador opcional.
--flowctlcounters
muestra contadores de control de flujo. Este es un contador opcional.
--vloppackets
muestra paquetes recibidos por código de operación por VL. Este es un contador opcional.
--vlopdata
muestra datos recibidos por código de operación por VL. Este es un contador opcional.
--vlxmitflowctlerrors
muestra errores de actualización de control de flujo por VL. Este es un contador opcional.
--vlxmitcounters
muestra ticks esperando para transmitir contadores por VL. Este es un contador opcional.
--swportvlcong
muestra la congestión del puerto VL del software. Este es un contador opcional.
--rcvcc
muestra contadores de control de congestión de recepción. Este es un contador opcional.
--slrcvfecn
muestra contadores SL Rcv FECN. Este es un contador opcional.
--slrcvbecn
muestra contadores SL Rcv BECN. Este es un contador opcional.
--xmitcc
muestra contadores de control de congestión de transmisión. Este es un contador opcional.
--vlxmittimecc
muestra contadores de control de congestión de tiempo de transmisión VL. Este es un contador opcional.
-c, --smplctl
muestra el control de muestras del puerto.
-a, --all_ports
muestra contadores agregados para todos los puertos del lid de destino, restablece todos los contadores para todos los puertos, o si se especifican varios puertos, agrega los contadores de los puertos especificados. Si el lid de destino no admite el indicador AllPortSelect, se iterará a través de todos los puertos para emular el comportamiento de AllPortSelect.
-l, --loop_ports
Si se seleccionan todos los puertos por el usuario (a través de la opción -a o el puerto 255) o se especifican varios puertos, itera a través de cada puerto en lugar de realizar una operación de agregación.
-r, --reset_after_read
restablece los contadores después de la lectura
-R, --Reset_only
solo restablece los contadores

Indicadores de Direccionamiento

-G, --Guid La dirección especificada es una GUID de puerto

-L, --Lid La dirección especificada es una LID

-s, --sm_port <smlid> usa 'smlid' como lid de destino para consultas SA.

Indicadores de Selección de Puerto

-C, --Ca <ca_name> usa el ca_name especificado.

-P, --Port <ca_port> usa el ca_port especificado.

Selección de Puerto Local

Soporte para múltiples puertos/múltiples CA: cuando no se especifica dispositivo o puerto IB (ver los "parámetros umad locales" a continuación), la biblioteca libibumad selecciona el puerto a usar según los siguientes criterios:

1.
el primer puerto que está ACTIVO.
2.
si no se encuentra, el primer puerto que está ARRIBA (enlace físico activo).

Si se especifica un puerto y/o nombre de CA, la biblioteca libibumad intenta cumplir la solicitud del usuario y fallará si no es posible.

Por ejemplo:

ibaddr                 # usa el primer puerto (criterio #1 arriba)
ibaddr -C mthca1       # elige el mejor puerto de solo "mthca1".
ibaddr -P 2            # usa el segundo puerto (activo/arriba) del primer dispositivo IB disponible.
ibaddr -C mthca0 -P 2  # usa solo el puerto especificado.

Indicadores de Depuración

-d
aumenta el nivel de depuración de IB. Puede usarse varias veces (-ddd o -d -d -d).
-e
muestra errores de envío y recepción (tiempos de espera y otros)

-h, --help muestra el mensaje de uso

-v, --verbose
aumenta el nivel de verbosidad de la aplicación. Puede usarse varias veces (-vv o -v -v -v)

-V, --version muestra la información de la versión.

Indicadores de Configuración

-t, --timeout <timeout_ms> anula el tiempo de espera predeterminado para los mads solicitados.

-y, --m_key <key>
usa la M_key especificada para las solicitudes. Si se especifica un valor no numérico (como 'x'), se solicitará un valor.

--config, -z <config_file> Especifica un archivo de configuración alternativo.

Predeterminado: /etc/infiniband-diags/ibdiag.conf

perfquery(8)

NAME

perfquery - Query RDMA performance counters

SYNOPSIS

perfquery [ options ] [ lid [ port ] ]

DESCRIPTION

perfquery is a tool used to query RDMA performance counters from the specified lid and port.

If lid and port are not specified, the tool queries the local machine's performance counters.

The tool supports querying all performance counters, or a subset, and can reset counters as part of the query.

OPTIONS

-x, --extended
Query extended performance counters. This includes L2/L3 specific counters if supported by the hardware.
-r, --reset
Reset performance counters after reading them. This option affects all counters queried.
-R, --reset-only
Reset performance counters without reading them. This option affects all counters queried.
-a, --aggregate
Aggregate the performance counters for the specified ports. This is the default behavior when multiple ports are specified.
-l, --list
List performance counters for each port individually. This is the default behavior when a single port is specified.
-h, --help
Display help information.

The lid and port arguments can be specified as integers or hexadecimal values (prefixed with 0x).

Port ranges can be specified using a hyphen, e.g., 1-10. Individual ports can be specified using a comma, e.g., 1,4,8.

When using the --reset-only option, an optional mask can be provided to reset specific counters. The mask is a hexadecimal value. For example, 0x0fff resets only error counters, and 0xf000 resets only non-error counters.

FILES

A global configuration file can be provided to set common options for all tools. The file is located at /etc/rdma/ibdiag.conf. See the supplied configuration file for details.

EXAMPLES

perfquery                # read local port performance counters
perfquery 32 1           # read performance counters from lid 32, port 1
perfquery -x 32 1        # read extended performance counters from lid 32, port 1
perfquery -a 32          # read perf counters from lid 32, all ports
perfquery -r 32 1        # read performance counters and reset
perfquery -x -r 32 1     # read extended performance counters and reset
perfquery -R 0x20 1      # reset performance counters of port 1 only
perfquery -x -R 0x20 1   # reset extended performance counters of port 1 only
perfquery -R -a 32       # reset performance counters of all ports
perfquery -R 32 2 0x0fff # reset only error counters of port 2
perfquery -R 32 2 0xf000 # reset only non-error counters of port 2
perfquery -a 32 1-10     # read performance counters from lid 32, port 1-10, aggregate output
perfquery -l 32 1-10     # read performance counters from lid 32, port 1-10, output each port
perfquery -a 32 1,4,8    # read performance counters from lid 32, port 1, 4, and 8, aggregate output
perfquery -l 32 1,4,8    # read performance counters from lid 32, port 1, 4, and 8, output each port
