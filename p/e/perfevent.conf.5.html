PERFEVENT.CONF(5) Manual de formatos de archivo PERFEVENT.CONF(5)

NOMBRE

perfevent.conf - archivo de configuración del PMDA perfevent de Performance Co-Pilot

SINOPSIS

$PCP_PMDAS_DIR/perfevent/perfevent.conf

DESCRIPCIÓN

El archivo de configuración perfevent.conf define qué contadores de rendimiento de hardware están habilitados por el PMDA perfevent.

El archivo de configuración contiene una lista de eventos que deben estar habilitados para cada PMU. El PMDA perfevent detecta qué PMU están presentes y programa los eventos configurados. Si hay varias PMU disponibles, el PMDA perfevent utiliza el orden de las entradas en el archivo de configuración para determinar qué configuración de PMU usar. Las entradas en la parte superior del archivo de configuración tienen mayor precedencia. Solo se utiliza una configuración de PMU. El archivo de configuración también puede contener eventos derivados de perf. Un evento derivado tiene una lista de eventos que deben figurar como eventos base. Los valores de los contadores en los eventos derivados se agregan y se muestran.

FORMATO DEL ARCHIVO

El archivo consta de uno o más grupos de PMU y los eventos correspondientes.

La cadena de identificación de la PMU se encierra entre corchetes y se listan uno o más eventos debajo, uno por línea.

["cadena de identificación de la PMU"]
NOMBRE_EVENTO [OPCIÓN_CPU]
...

Para eventos derivados, se pueden especificar uno o más grupos de eventos donde los contadores de un grupo pueden ser específicos para una arquitectura y los contadores de otro grupo pueden ser específicos para otra arquitectura. De lo contrario, solo se puede especificar un grupo. NOMBRE_EVENTO_1, NOMBRE_EVENTO_2, etc., pertenecen al grupo 1 y NOMBRE_EVENTO_3, NOMBRE_EVENTO_4 pertenecen al grupo 2 y así sucesivamente. Si alguno de los eventos del primer grupo no está disponible, se descartará todo el grupo. Y se comprobará el siguiente grupo. Se activará y monitorizará el primer grupo con todos los eventos disponibles. El evento perf derivado se encierra entre corchetes junto con :derived como sufijo. Tenga en cuenta que el NOMBRE_EVENTO listado bajo el evento derivado debe estar presente como un evento base en el archivo de configuración. Y todos los eventos bajo un grupo de eventos perf derivados particular deben tener la misma OPCIÓN_CPU. || actúa como separador para diferentes grupos dentro de un mismo evento derivado. La sintaxis es:

[evento:derivado]
NOMBRE_EVENTO_1 [OPCIÓN_CPU] [escala]
NOMBRE_EVENTO_2 [OPCIÓN_CPU] [escala]
...
||
NOMBRE_EVENTO_3 [OPCIÓN_CPU] [escala]
NOMBRE_EVENTO_4 [OPCIÓN_CPU] [escala]
...

Las opciones de CPU de evento disponibles son las siguientes:

cpu
para añadir el contador a todas las cpus del sistema
cpu_rr
para añadir a una de las cpus en una estrategia de asignación por rondas (round-robin)
node
para añadir el contador a la primera cpu de cada nodo numa
node_rr
para añadir el contador a las cpus de cada nodo numa en una estrategia de asignación por rondas (round-robin)
[N]
donde N es el dígito numérico del índice de la CPU

si la opción de CPU está ausente, el evento se programará en todas las cpus.

escala es aplicable a los contadores en eventos derivados. Si se proporciona la escala, los contadores se escalarán a sus valores respectivos. Las opciones son las siguientes:

un valor flotante
Puede ser un valor flotante simple o un valor en notación científica.
perf_scale
La escala se tomará del archivo de escala de entrada del archivo sysfs del kernel para ese evento. Generalmente se especifica en /sys/bus/event_source/device/events/<nombre_evento>.scale

Si no se proporciona ninguna escala, la escala predeterminada será 1.0.

Las líneas en blanco se ignoran. Las líneas que comienzan con el signo # se ignoran.

Se pueden especificar varias PMU, separadas por comas, en la definición de la PMU.
