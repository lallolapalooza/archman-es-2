DESCRIPCIÓN

Un glosario de términos (técnicos y de otro tipo) utilizados en la documentación de Perl, derivado del Glosario de Programming Perl, Cuarta Edición. Las palabras o frases en negrita se definen en otra parte de este glosario.

Otras fuentes útiles incluyen el Glosario Unicode http://unicode.org/glossary/, el Free On-Line Dictionary of Computing http://foldoc.org/, el Jargon File http://catb.org/~esr/jargon/, y Wikipedia http://www.wikipedia.org/.

A

métodos accesor(es)
Un método utilizado para inspeccionar o actualizar indirectamente el estado de un objeto (sus variables de instancia).
argumentos reales
Los valores escalares que usted suministra a una función o subrutina cuando la llama. Por ejemplo, cuando llama a power("puff"), la cadena "puff" es el argumento real. Vea también argumento y argumentos formales.
operador de dirección
Algunos lenguajes trabajan directamente con las direcciones de memoria de los valores, pero esto puede ser como jugar con fuego. Perl proporciona un conjunto de guantes de amianto para manejar toda la gestión de memoria. Lo más parecido a un operador de dirección en Perl es el operador de barra invertida, pero este le da una referencia fuerte, que es mucho más segura que una dirección de memoria.
algoritmo
Una secuencia de pasos bien definida, explicada con suficiente claridad como para que incluso un ordenador pueda realizarlos.
alias
Un apodo para algo, que se comporta en todos los aspectos como si hubiera utilizado el nombre original en lugar del apodo. Los alias temporales se crean implícitamente en la variable del bucle para los bucles "foreach", en la variable $_ para los operadores "map" o "grep", en $a y $b durante la función de comparación de "sort", y en cada elemento de @_ para los argumentos reales de una llamada a subrutina. Los alias permanentes se crean explícitamente en los paquetes importando símbolos o asignando a typeglobs. Los alias con ámbito léxico para variables de paquete se crean explícitamente mediante la declaración "our".
alfabético
El tipo de caracteres que ponemos en las palabras. En Unicode, todas las letras incluyendo todos los ideogramas y ciertos diacríticos, números de letra como los números romanos y varias marcas de combinación.
alternativas
Una lista de posibles opciones de la cual usted puede seleccionar solo una, como en, "¿Desea la puerta A, B o C?". Las alternativas en expresiones regulares están separadas por una barra vertical simple: "|". Las alternativas en expresiones Perl normales están separadas por una doble barra vertical: "||". Las alternativas lógicas en expresiones Booleanas están separadas por "||" o "or".
anónimo
Se utiliza para describir un referente que no es directamente accesible a través de una variable con nombre. Dicho referente debe ser accesible indirectamente a través de al menos una referencia fuerte. Cuando la última referencia fuerte desaparece, el referente anónimo es destruido sin piedad.
aplicación
Un programa más grande y sofisticado con un nombre más elegante para que la gente no se dé cuenta de que está usando un programa.
arquitectura
El tipo de ordenador en el que está trabajando, donde un "tipo de ordenador" significa todos aquellos ordenadores que comparten un lenguaje máquina compatible. Dado que los programas Perl son (típicamente) archivos de texto simples, no imágenes ejecutables, un programa Perl es mucho menos sensible a la arquitectura en la que se está ejecutando que los programas en otros lenguajes, como C, que se compilan a código máquina. Vea también plataforma y sistema operativo.
argumento
Una pieza de datos suministrada a un programa, subrutina, función o método para indicarle qué se supone que debe hacer. También llamado "parámetro".
ARGV
El nombre del array que contiene el vector de argumentos de la línea de comandos. Si utiliza el operador vacío "<>", "ARGV" es el nombre tanto del filehandle utilizado para recorrer los argumentos como del escalar que contiene el nombre del archivo de entrada actual.
operador aritmético
Un símbolo como "+" o "/" que le dice a Perl que realice la aritmética que se suponía que debía aprender en la escuela primaria.
array
Una secuencia ordenada de valores, almacenada de tal manera que pueda acceder fácilmente a cualquiera de los valores utilizando un subíndice entero que especifica el desplazamiento del valor en la secuencia.
contexto de array
Una expresión arcaica para lo que se denomina más correctamente contexto de lista.
Licencia Artística
La licencia de código abierto que Larry Wall creó para Perl, maximizando la utilidad, disponibilidad y modificabilidad de Perl. La versión actual es la 2. (http://www.opensource.org/licenses/artistic-license.php).
ASCII
El American Standard Code for Information Interchange (un conjunto de caracteres de 7 bits adecuado solo para representar mal texto en inglés). A menudo se utiliza de forma laxa para describir los 128 valores más bajos de los diversos conjuntos de caracteres ISO-8859-X, un montón de códigos de 8 bits mutuamente incompatibles que se describen mejor como medio ASCII. Vea también Unicode.
aserción
Un componente de una expresión regular que debe ser verdadero para que el patrón coincida, pero que no necesariamente coincide con ningún carácter en sí mismo. A menudo se utiliza específicamente para referirse a una aserción de ancho cero.
asignación
Un operador cuya misión asignada en la vida es cambiar el valor de una variable.
operador de asignación
Ya sea una asignación regular o un operador compuesto por una asignación ordinaria y algún otro operador, que cambia el valor de una variable en su lugar; es decir, en relación con su valor anterior. Por ejemplo, "$a += 2" suma 2 a $a.
array asociativo
Vea hash. Por favor. El término array asociativo es el término antiguo de Perl 4 para un hash. Algunos lenguajes lo llaman diccionario.
asociatividad
Determina si usted realiza el operador izquierdo primero o el operador derecho primero cuando tiene "A operador B operador C", y los dos operadores son de la misma precedencia. Los operadores como "+" son asociativos a la izquierda, mientras que los operadores como "**" son asociativos a la derecha. Vea el capítulo 3 del "Camello", "Operadores Unarios y Binarios", para una lista de operadores y su asociatividad.
asíncrono
Se dice de eventos o actividades cuya temporalidad relativa

asynchronous event
An event whose ordering is indeterminate because too many things are going on at once. Hence, an asynchronous event is one you didn’t know when to expect.
atom
A regular expression component potentially matching a substring containing one or more characters and treated as an indivisible syntactic unit by any following quantifier. (Contrast with an assertion that matches something of zero width and may not be quantified.)
atomic operation
When Democritus gave the word “atom” to the indivisible bits of matter, he meant literally something that could not be cut: a- (not) + tomos (cuttable). An atomic operation is an action that can’t be interrupted, not one forbidden in a nuclear-free zone.
attribute
A new feature that allows the declaration of variables and subroutines with modifiers, as in "sub foo : locked method". Also another name for an instance variable of an object.
autogeneration
A feature of operator overloading of objects, whereby the behavior of certain operators can be reasonably deduced using more fundamental operators. This assumes that the overloaded operators will often have the same relationships as the regular operators. See Camel chapter 13, “Overloading”.
autoincrement
To add one to something automatically, hence the name of the "++" operator. To instead subtract one from something automatically is known as an “autodecrement”.
autoload
To load on demand. (Also called “lazy” loading.) Specifically, to call an "AUTOLOAD" subroutine on behalf of an undefined subroutine.
autosplit
To split a string automatically, as the –a switch does when running under –p or –n in order to emulate awk. (See also the "AutoSplit" module, which has nothing to do with the "–a" switch but a lot to do with autoloading.)
autovivification
A Graeco-Roman word meaning “to bring oneself to life”. In Perl, storage locations (lvalues) spontaneously generate themselves as needed, including the creation of any hard reference values to point to the next level of storage. The assignment "$a[5][5][5][5][5] = "quintet"" potentially creates five scalar storage locations, plus four references (in the first four scalar locations) pointing to four new anonymous arrays (to hold the last four scalar locations). But the point of autovivification is that you don’t have to worry about it.
AV
Short for “array value”, which refers to one of Perl’s internal data types that holds an array. The "AV" type is a subclass of SV.
awk
Descriptive editing term—short for “awkward”. Also coincidentally refers to a venerable text-processing language from which Perl derived some of its high-level ideas.

B

backreference
A substring captured by a subpattern within unadorned parentheses in a regex. Backslashed decimal numbers ("\1", "\2", etc.) later in the same pattern refer back to the corresponding subpattern in the current match. Outside the pattern, the numbered variables ($1, $2, etc.) continue to refer to these same values, as long as the pattern was the last successful match of the current dynamic scope.
backtracking
The practice of saying, “If I had to do it all over, I’d do it differently,” and then actually going back and doing it all over differently. Mathematically speaking, it’s returning from an unsuccessful recursion on a tree of possibilities. Perl backtracks when it attempts to match patterns with a regular expression, and its earlier attempts don’t pan out. See the section “The Little Engine That /Couldn(n’t)” in Camel chapter 5, “Pattern Matching”.
backward compatibility
Means you can still run your old program because we didn’t break any of the features or bugs it was relying on.
bareword
A word sufficiently ambiguous to be deemed illegal under "use strict 'subs'". In the absence of that stricture, a bareword is treated as if quotes were around it.
base class
A generic object type; that is, a class from which other, more specific classes are derived genetically by inheritance. Also called a “superclass” by people who respect their ancestors.
big-endian
From Swift: someone who eats eggs big end first. Also used of computers that store the most significant byte of a word at a lower byte address than the least significant byte. Often considered superior to little-endian machines. See also little-endian.
binary
Having to do with numbers represented in base 2. That means there’s basically two numbers: 0 and 1. Also used to describe a file of “nontext”, presumably because such a file makes full use of all the binary bits in its bytes. With the advent of Unicode, this distinction, already suspect, loses even more of its meaning.
binary operator
An operator that takes two operands.
bind
To assign a specific network address to a socket.
bit
An integer in the range from 0 to 1, inclusive. The smallest possible unit of information storage. An eighth of a byte or of a dollar. (The term “Pieces of Eight” comes from being able to split the old Spanish dollar into 8 bits, each of which still counted for money. That’s why a 25- cent piece today is still “two bits”.)
bit shift
The movement of bits left or right in a computer word, which has the effect of multiplying or dividing by a power of 2.
bit string
A sequence of bits that is actually being thought of as a sequence of bits, for once.
bless
In corporate life, to grant official approval to a thing, as in, “The VP of Engineering has blessed our WebCruncher project.” Similarly, in Perl, to grant official approval to a referent so that it can function as an object, such as a WebCruncher object. See the "bless" function in Camel chapter 27, “Functions”.
block
What a process does when it has to wait for something: “My process blocked waiting for the disk.” As an unrelated noun, it refers to a large chunk of data, of a size that the operating system likes to deal with (normally a power of 2 such as 512 or 8192). Typically refers to a chunk of data that’s coming from or going to a disk file.
BLOCK
A syntactic construct consisting of a sequence of Perl statements that is delimited by braces. The "if" and "while" statements are defined in terms of BLOCKs, for instance. Sometimes we also say “block” to mean a lexical scope; that is, a sequence of statements that acts like a BLOCK, such as within an "eval" or a file, even though the statements aren’t delimited by braces.
block buffering
A method of making input and output efficient by passing one block at a time. By default, Perl does block buffering to disk files. See buffer and command buffering.
Boolean
A value that is either true or false.
Boolean context
A special kind of scalar context used in conditionals to decide whether the scalar value returned by an expression is true or false. Does not evaluate as either a string or a number. See context.
breakpoint
A spot in your program where you’ve told the debugger to stop execution so you can poke around and see whether anything is wrong yet.
broadcast
To send a datagram to multiple destinations simultaneously.
BSD
A psychoactive drug, popular in the ’80s, probably developed at UC Berkeley or thereabouts. Similar in many ways to the prescription-only medication called “System V”, but infinitely more useful. (Or, at least, more fun.) The full chemical name is “Berkeley Standard Distribution”.
bucket
A location in a hash table containing (potentially) multiple entries whose keys “hash” to the same hash value according to its hash function. (As internal policy, you don’t have to worry about it unless you’re into internals, or policy.)
buffer
A temporary holding location for data. Data that are Block

B

buffering
means that the data is passed on to its destination whenever the buffer is full. Line buffering means that it’s passed on whenever a complete line is received. Command buffering means that it’s passed every time you do a "print" command (or equivalent). If your output is unbuffered, the system processes it one byte at a time without the use of a holding area. This can be rather inefficient.
built-in
A function that is predefined in the language. Even when hidden by overriding, you can always get at a built- in function by qualifying its name with the "CORE::" pseudopackage.
bundle
A group of related modules on CPAN. (Also sometimes refers to a group of command-line switches grouped into one switch cluster.)
byte
A piece of data worth eight bits in most places.
bytecode
A pidgin-like lingo spoken among ’droids when they don’t wish to reveal their orientation (see endian). Named after some similar languages spoken (for similar reasons) between compilers and interpreters in the late 20th century. These languages are characterized by representing everything as a nonarchitecture-dependent sequence of bytes.

C

C
A language beloved by many for its inside-out type definitions, inscrutable precedence rules, and heavy overloading of the function-call mechanism. (Well, actually, people first switched to C because they found lowercase identifiers easier to read than upper.) Perl is written in C, so it’s not surprising that Perl borrowed a few ideas from it.
cache
A data repository. Instead of computing expensive answers several times, compute it once and save the result.
callback
A handler that you register with some other part of your program in the hope that the other part of your program will trigger your handler when some event of interest transpires.
call by reference
An argument-passing mechanism in which the formal arguments refer directly to the actual arguments, and the subroutine can change the actual arguments by changing the formal arguments. That is, the formal argument is an alias for the actual argument. See also call by value.
call by value
An argument-passing mechanism in which the formal arguments refer to a copy of the actual arguments, and the subroutine cannot change the actual arguments by changing the formal arguments. See also call by reference.
canonical
Reduced to a standard form to facilitate comparison.
capture variables
The variables—such as $1 and $2, and "%+" and "%– "—that hold the text remembered in a pattern match. See Camel chapter 5, “Pattern Matching”.
capturing
The use of parentheses around a subpattern in a regular expression to store the matched substring as a backreference. (Captured strings are also returned as a list in list context.) See Camel chapter 5, “Pattern Matching”.
cargo cult
Copying and pasting code without understanding it, while superstitiously believing in its value. This term originated from preindustrial cultures dealing with the detritus of explorers and colonizers of technologically advanced cultures. See The Gods Must Be Crazy.
case
A property of certain characters. Originally, typesetter stored capital letters in the upper of two cases and small letters in the lower one. Unicode recognizes three cases: lowercase (character property "\p{lower}"), titlecase ("\p{title}"), and uppercase ("\p{upper}"). A fourth casemapping called foldcase is not itself a distinct case, but it is used internally to implement casefolding. Not all letters have case, and some nonletters have case.
casefolding
Comparing or matching a string case-insensitively. In Perl, it is implemented with the "/i" pattern modifier, the "fc" function, and the "\F" double-quote translation escape.
casemapping
The process of converting a string to one of the four Unicode casemaps; in Perl, it is implemented with the "fc", "lc", "ucfirst", and "uc" functions.
character
The smallest individual element of a string. Computers store characters as integers, but Perl lets you operate on them as text. The integer used to represent a particular character is called that character’s codepoint.
character class
A square-bracketed list of characters used in a regular expression to indicate that any character of the set may occur at a given point. Loosely, any predefined set of characters so used.
character property
A predefined character class matchable by the "\p" or "\P" metasymbol. Unicode defines hundreds of standard properties for every possible codepoint, and Perl defines a few of its own, too.
circumfix operator
An operator that surrounds its operand, like the angle operator, or parentheses, or a hug.
class
A user-defined type, implemented in Perl via a package that provides (either directly or by inheritance) methods (that is, subroutines) to handle instances of the class (its objects). See also inheritance.
class method
A method whose invocant is a package name, not an object reference. A method associated with the class as a whole. Also see instance method.
client
In networking, a process that initiates contact with a server process in order to exchange data and perhaps receive a service.
closure
An anonymous subroutine that, when a reference to it is generated at runtime, keeps track of the identities of externally visible lexical variables, even after those lexical variables have supposedly gone out of scope. They’re called “closures” because this sort of behavior gives mathematicians a sense of closure.
cluster
A parenthesized subpattern used to group parts of a regular expression into a single atom.
CODE
The word returned by the "ref" function when you apply it to a reference to a subroutine. See also CV.
code generator
A system that writes code for you in a low-level language, such as code to implement the backend of a compiler. See program generator.
codepoint
The integer a computer uses to represent a given character. ASCII codepoints are in the range 0 to 127; Unicode codepoints are in the range 0 to 0x10_FFFF; and Perl codepoints are in the range 0 to 232−1 or 0 to 264−1, depending on your native integer size. In Perl Culture, sometimes called ordinals.
code subpattern
A regular expression subpattern whose real purpose is to execute some Perl code—for example, the "(?{...})" and "(??{...})" subpatterns.
collating sequence
The order into which characters sort. This is used by string comparison routines to decide, for example, where in this glossary to put “collating sequence”.
co-maintainer
A person with permissions to index a namespace in PAUSE. Anyone can upload any namespace, but only primary and co-maintainers get their contributions indexed.
combining character
Any character with the General Category of Combining Mark ("\p{GC=M}"), which may be spacing or nonspacing. Some are even invisible. A sequence of combining characters following a grapheme base character together make up a single user-visible character called a grapheme. Most but not all diacritics are combining characters, and vice versa.
command
In shell programming, the syntactic combination of a program name and its arguments. More loosely, anything you type to a shell (a command interpreter) that starts it doing something. Even more loosely, a Perl statement, which might start with a label and typically ends with a semicolon.
command buffering
A mechanism in Perl that lets you store up the output of each Perl command and then flush it out as a single request to the operating system. It’s enabled by setting the $|
n> ($AUTOFLUSH) variable a un valor verdadero. Se usa cuando no quieres que los datos queden pendientes, sin ir a donde se supone que deben ir, lo que puede suceder porque el valor predeterminado en un archivo o tubería es usar buffer de bloque.
argumentos de línea de comandos
Los valores que suministras junto con el nombre de un programa cuando le dices a un shell que ejecute un comando. Estos valores se pasan a un programa Perl a través de @ARGV.
nombre del comando
El nombre del programa que se está ejecutando actualmente, tal como se escribió en la línea de comandos. En C, el nombre del comando se pasa al programa como el primer argumento de la línea de comandos. En Perl, llega por separado como $0.
comentario
Una observación que no afecta el significado del programa. En Perl, un comentario se introduce con un carácter "#" y continúa hasta el final de la línea.
unidad de compilación
El archivo (o cadena, en el caso de "eval") que se está compilando actualmente.
compilar
El proceso de convertir el código fuente en una forma utilizable por la máquina. Ver fase de compilación.
fase de compilación
Cualquier momento antes de que Perl comience a ejecutar tu programa principal. Ver también fase de ejecución. La fase de compilación se dedica principalmente al tiempo de compilación, pero también puede dedicarse al tiempo de ejecución cuando se evalúan bloques "BEGIN", declaraciones "use" o "no", o subexpresiones constantes. El código de inicio e importación de cualquier declaración "use" también se ejecuta durante la fase de compilación.
compilador
Estrictamente hablando, un programa que procesa otro programa y genera otro archivo que contiene el programa en una forma "más ejecutable", típicamente conteniendo instrucciones de máquina nativas. El programa perl no es un compilador según esta definición, pero sí contiene una especie de compilador que toma un programa y lo convierte en una forma más ejecutable (árboles sintácticos) dentro del propio proceso perl, que luego el intérprete interpreta. Sin embargo, existen módulos de extensión para que Perl actúe más como un compilador "real". Ver el Capítulo 16 del Libro de Cocodrilo, "Compilación".
tiempo de compilación
El momento en que Perl está intentando dar sentido a tu código, en oposición a cuando cree que sabe lo que significa tu código y simplemente está tratando de hacer lo que cree que tu código dice que haga, que es el tiempo de ejecución.
compositor
Un "constructor" para un referente que en realidad no es un objeto, como un array anónimo o un hash (o una sonata, ya que estamos en ello). Por ejemplo, un par de llaves actúa como compositor para un hash, y un par de corchetes actúa como compositor para un array. Ver la sección "Creación de Referencias" en el Capítulo 8 del Libro de Cocodrilo, "Referencias".
concatenación
El proceso de pegar la nariz de un gato a la cola de otro gato. También una operación similar en dos cadenas.
condicional
Algo "condicional" o "si acaso". Ver contexto booleano.
conexión
En telefonía, el circuito eléctrico temporal entre el teléfono del llamante y el del llamado. En redes, el mismo tipo de circuito temporal entre un cliente y un servidor.
construir
Como sustantivo, una pieza de sintaxis compuesta por piezas más pequeñas. Como verbo transitivo, crear un objeto usando un constructor.
constructor
Cualquier método de clase, instancia o subrutina que compone, inicializa, bendice y devuelve un objeto. A veces usamos el término de manera informal para referirnos a un compositor.
contexto
El entorno o las circunstancias. El contexto proporcionado por el código circundante determina qué tipo de datos se espera que devuelva una determinada expresión. Los tres contextos principales son el contexto de lista, el escalar y el contexto nulo. El contexto escalar a veces se subdivide en contexto booleano, contexto numérico, contexto de cadena y contexto nulo. También existe un contexto de "no importa" (que se trata en el Capítulo 2 del Libro de Cocodrilo, "Piezas y Trozos", si te importa).
continuación
El tratamiento de más de una línea física como una sola línea lógica. Las líneas de Makefile se continúan colocando una barra inversa antes del salto de línea. Las cabeceras de correo, según definidas por RFC 822, se continúan colocando un espacio o una tabulación *después* del salto de línea. En general, las líneas en Perl no necesitan ninguna forma de marca de continuación, porque el espacio en blanco (incluidos los saltos de línea) se ignora con gusto. Por lo general.
volcado del núcleo
El cadáver de un proceso, en forma de archivo dejado en el directorio de trabajo del proceso, generalmente como resultado de ciertos tipos de errores fatales.
CPAN
La Comprehensive Perl Archive Network. (Ver el Prefacio del Libro de Cocodrilo y el Capítulo 19 del Libro de Cocodrilo, "CPAN" para detalles.)
preprocesador C
La primera pasada del compilador C típico, que procesa las líneas que comienzan con "#" para compilación condicional y definición de macros, y realiza varias manipulaciones del texto del programa basándose en las definiciones actuales. También conocido como cpp(1).
cracker
Alguien que rompe la seguridad en sistemas informáticos. Un cracker puede ser un hacker de verdad o solo un script kiddie.
canal de salida seleccionado actualmente
El último manejador de archivo que fue designado con select(FILEHANDLE); "STDOUT", si no se ha seleccionado ningún manejador de archivo.
paquete actual
El paquete en el que se está compilando la declaración actual. Escanee hacia atrás en el texto de su programa a través del ámbito léxico actual o cualquier ámbito léxico circundante hasta que encuentre una declaración de paquete. Ese es el nombre de su paquete actual.
directorio de trabajo actual
Ver directorio de trabajo.
CV
En el ámbito académico, un currículum vitae, un tipo elegante de currículum. En Perl, un tipo interno de "valor de código" (typedef) que contiene una subrutina. El tipo "CV" es una subclase de SV.

D

declaración colgante
Una declaración desnuda, única, sin llaves, que cuelga de un condicional "if" o "while". C las permite. Perl no.
datagrama
Un paquete de datos, como un mensaje UDP, que (desde el punto de vista de los programas involucrados) se puede enviar de forma independiente a través de la red. (De hecho, todos los paquetes se envían de forma independiente a nivel IP, pero los protocolos de flujo como TCP ocultan esto a tu programa).
estructura de datos
Cómo se relacionan tus diversos datos entre sí y qué forma toman cuando los juntas, como en una tabla rectangular o un árbol triangular.
tipo de datos
Un conjunto de valores posibles, junto con todas las operaciones que saben cómo tratar con esos valores. Por ejemplo, un tipo de datos numérico tiene un cierto conjunto de números con los que puedes trabajar, así como varias operaciones matemáticas que puedes hacer con los números, pero que tendrían poco sentido en, digamos, una cadena como "Kilroy". Las cadenas tienen sus propias operaciones, como la concatenación. Los tipos compuestos hechos de un número de piezas más pequeñas generalmente tienen operaciones para componerlas y descomponerlas, y quizás para reorganizarlas. Los objetos que modelan cosas del mundo real a menudo tienen operaciones que corresponden a actividades reales. Por ejemplo, si modelas un ascensor, tu objeto ascensor podría tener un método "abrir_puerta".
DBM
Abreviatura de las rutinas "Database Management" (Gestión de Bases de Datos), un conjunto de rutinas que emulan un array asociativo utilizando archivos en disco. Las rutinas utilizan un esquema de hashing dinámico para localizar cualquier entrada con solo dos accesos a disco. Perl mongers
Un grupo de usuarios de Perl, que toma la forma de su nombre de los Perl mongers de Nueva York, el primer grupo de usuarios de Perl. Encuentra uno cerca de ti en http://www.pm.org.
bits de permiso
Bits que el propietario de un archivo establece o elimina para permitir o denegar el acceso a otras personas. Estos bits de bandera son parte de la palabra de modo devuelta por la función integrada "stat" cuando preguntas sobre un archivo. En sistemas Unix, puedes consultar la página del manual de ls(1) para obtener más información.
Pern
Lo que obtienes cuando haces "Perl++" dos veces. Hacerlo una sola vez te riza el pelo. Tienes que incrementarlo ocho veces para lavarte el pelo. Enjabona, enjuaga, itera.
phaser
La vida útil (cronograma de ejecución) de un programa se divide en fases. Un phaser es un bloque de código llamado durante una fase de ejecución específica.
tubería
Una conexión directa que transporta la salida de un proceso a la entrada de otro sin un archivo temporal intermedio. Una vez establecida la tubería, los dos procesos en cuestión pueden leer y escribir como si estuvieran hablando con un archivo normal, con algunas advertencias.
canalización
Una serie de procesos en fila, conectados por tuberías, donde cada uno pasa su flujo de salida al siguiente.
plataforma
El contexto completo de hardware y software en el que se ejecuta un programa. Un programa escrito en un lenguaje dependiente de la plataforma podría fallar si cambias alguno de los siguientes: máquina, sistema operativo, bibliotecas, compilador o configuración del sistema. El intérprete perl tiene que ser compilado de manera diferente para cada plataforma porque está implementado en C, pero los programas escritos en el lenguaje Perl son en gran medida independientes de la plataforma.
pod
El marcado utilizado para incrustar documentación en tu código Perl. Pod significa "Plain old documentation" (Documentación simple). Véase el capítulo 23 del Libro del Camello, "Plain Old Documentation".
comando pod
Una secuencia, como "=head1", que indica el inicio de una sección pod.
puntero
Una variable en un lenguaje como C que contiene la ubicación exacta en memoria de algún otro elemento. Perl maneja los punteros internamente para que no tengas que preocuparte por ellos. En su lugar, simplemente usas punteros simbólicos en forma de claves y nombres de variables, o referencias fuertes, que no son punteros (pero actúan como punteros y de hecho contienen punteros).
polimorfismo
La idea de que puedes decirle a un objeto que haga algo genérico, y el objeto interpretará el comando de diferentes maneras dependiendo de su tipo. [< Griego πολύ- + μοΡϕή, muchas formas.]
puerto
La parte de la dirección de un socket TCP o UDP que dirige los paquetes al proceso correcto después de encontrar la máquina correcta, algo así como la extensión telefónica que das cuando llegas al operador de la empresa. También es el resultado de convertir código para que se ejecute en una plataforma diferente a la prevista originalmente, o el verbo que denota esta conversión.
portable
Érase una vez, código C compilable tanto en BSD como en SysV. En general, código que se puede convertir fácilmente para que se ejecute en otra plataforma, donde "fácilmente" se puede definir como quieras, y generalmente así es. Cualquier cosa puede considerarse portable si te esfuerzas lo suficiente, como una casa móvil o el Puente de Londres.
portador
Alguien que "transporta" software de una plataforma a otra. Portar programas escritos en lenguajes dependientes de la plataforma, como C, puede ser un trabajo difícil, pero portar programas como Perl vale mucho la pena la agonía.
posesivo
Se dice de los cuantificadores y grupos en patrones que se niegan a ceder nada una vez que lo han conseguido. Más pegadizo y fácil de decir que el aún más formal *no backtracking*.
POSIX
La especificación Portable Operating System Interface (Interfaz Portable para Sistemas Operativos).
sufijo
Un operador que sigue a su operando, como en "$x++".
pp
Una abreviatura interna para un código de "push-pop"; es decir, código C que implementa la máquina de pila de Perl.
pragma
Un módulo estándar cuyas sugerencias e indicaciones prácticas son recibidas (y posiblemente ignoradas) en tiempo de compilación. Los pragmas se nombran en minúsculas.
precedencia
Las reglas de conducta que, en ausencia de otras indicaciones, determinan qué debe suceder primero. Por ejemplo, en ausencia de paréntesis, siempre haces la multiplicación antes que la suma.
prefijo
Un operador que precede a su operando, como en "++$x".
preprocesamiento
Lo que hizo algún proceso auxiliar para transformar los datos entrantes en una forma más adecuada para el proceso actual. A menudo se hace con una tubería entrante. Véase también preprocesador de C.
mantenedor principal
El autor al que PAUSE permite asignar permisos de co-mantenedor a un espacio de nombres. Un mantenedor principal puede renunciar a esta distinción asignándola a otro autor de PAUSE. Véase el capítulo 19 del Libro del Camello, "CPAN".
procedimiento
Una subrutina.
proceso
Una instancia de un programa en ejecución. En sistemas multitarea como Unix, dos o más procesos separados podrían estar ejecutando el mismo programa de forma independiente al mismo tiempo; de hecho, la función "fork" está diseñada para propiciar este feliz estado de cosas. En otros sistemas operativos, los procesos a veces se denominan "hilos", "tareas" o "jobs", a menudo con matices sutiles en el significado.
programa
Ver script.
generador de programas
Un sistema que escribe código algorítmicamente para ti en un lenguaje de alto nivel. Véase también generador de código.
coincidencia progresiva
Coincidencia de patrones que retoma donde lo dejó antes.
propiedad
Ver variable de instancia o propiedad de carácter.
protocolo
En redes, una forma acordada de enviar mensajes de ida y vuelta para que ninguno de los dos corresponsales se confunda demasiado.
prototipo
Una parte opcional de una declaración de subrutina que indica al compilador de Perl cuántos y qué tipo de argumentos pueden pasarse como argumentos reales, para que puedas escribir llamadas a subrutinas que analicen de forma similar a las funciones integradas. (O que no analicen, según el caso).
pseudofunción
Una construcción que a veces parece una función pero en realidad no lo es. Generalmente reservada para modificadores de lvalue como "my", para modificadores de contexto como "scalar", y para los constructos de elección de comillas, "q//", "qq//", "qx//", "qw//", "qr//", "m//", "s///", "y///" y "tr///".
pseudohash
Anteriormente, una referencia a un array cuyo elemento inicial contenía una referencia a un hash. Solías poder tratar una referencia de pseudohash como una referencia de array o una referencia de hash. Los pseudohashes ya no son compatibles.
pseudoliteral
Un operador X"que se parece algo a un literal, como el operador de captura de salida, <literal moreinfo="none""`>"comando""`".
dominio público
Algo que no pertenece a nadie. Perl tiene derechos de autor y, por lo tanto, *no* está en el dominio público; es simplemente **gratuito** y **redistribuible libremente**.
calabaza (pumpkin)
Un "bastón" notacional que se pasa por la comunidad Perl indicando quién es el integrador principal en alguna área de desarrollo.
encargado de la calabaza (pumpking)
Un poseedor de pumpkin, la persona a cargo de bombear la bomba, o al menos cebarla. Debe estar dispuesto a desempeñar el papel de la Gran Calabaza de vez en cuando.
PV
Un "valor de puntero", que en la jerga interna de Perl significa un "char*".

Q

calificado
Que posee un nombre completo. El símbolo $Ent::moot está calificado; $moot no está calificado. Un nombre de archivo completamente calificado se especifica desde el directorio de nivel superior.
cuantificador
Un componente de una expresión regular que especifica cuántas veces el átomo precedente puede ocurrir.

R

condición de carrera
Existe una condición de carrera cuando el resultado de varios eventos interrelacionados depende del orden de esos eventos, pero ese orden no puede garantizarse debido a efectos de temporización no deterministas. Si dos o más programas, o partes del mismo programa, intentan pasar por la misma serie de eventos, uno podría interrumpir el trabajo del otro. Esta es una buena manera de encontrar un exploit.
legible
Con respecto a los archivos, uno que tiene el bit de permiso adecuado configurado para permitirle acceder al archivo. Con respecto a los programas informáticos, uno que está escrito lo suficientemente bien como para que alguien tenga una posibilidad de averiguar qué está tratando de hacer.
recolección (reaping)
Los últimos ritos realizados por un proceso padre en nombre de un proceso hijo fallecido para que no permanezca como un zombie. Consulte las llamadas a función "wait" y "waitpid".
registro
Un conjunto de valores de datos relacionados en un archivo o flujo, a menudo asociado con un campo de clave único. En Unix, a menudo es equivalente a una línea, o un conjunto de líneas terminadas por una línea en blanco (un "párrafo"). Cada línea del archivo /etc/passwd es un registro, indexado por el nombre de inicio de sesión, que contiene información sobre ese usuario.
recursión
El arte de definir algo (al menos parcialmente) en términos de sí mismo, lo cual es un error grave en los diccionarios, pero a menudo funciona bien en los programas informáticos si se tiene cuidado de no recursar para siempre (lo que es como un bucle infinito con modos de fallo más espectaculares).
referencia
Donde miras para encontrar un puntero a información en otro lugar. (Ver indirección). Las referencias vienen en dos sabores: referencias simbólicas y referencias duras.
referente
Aquello a lo que se refiere una referencia, que puede o no tener un nombre. Los tipos comunes de referentes incluyen escalares, arrays, hashes y subrutinas.
regex
Ver expresión regular.
expresión regular
Una entidad única con varias interpretaciones, como un elefante. Para un científico informático, es una gramática para un pequeño lenguaje en el que algunas cadenas son legales y otras no. Para la gente normal, es un patrón que puedes usar para encontrar lo que buscas cuando varía de un caso a otro. Las expresiones regulares de Perl están lejos de ser regulares en el sentido teórico, pero en el uso regular funcionan bastante bien. Aquí hay una expresión regular: "/Oh s.*t./". Esto coincidirá con cadenas como ""Oh, sí, ¿puedes ver a la luz del amanecer?"" y ""¡Oh, siéntate!"". Ver Capítulo 5 del Libro del Camello, "Coincidencia de Patrones".
modificador de expresión regular
Una opción en un patrón o sustitución, como "/i" para hacer que el patrón no distinga entre mayúsculas y minúsculas.
archivo regular
Un archivo que no es un directorio, un dispositivo, una tubería o socket con nombre, o un enlace simbólico. Perl utiliza el operador de prueba de archivos "–f" para identificar archivos regulares. A veces se denomina archivo "normal" (plain file).
operador relacional
Un operador que indica si una relación de orden particular es verdadera para un par de operandos. Perl tiene operadores relacionales numéricos y de cadena. Ver secuencia de intercalación.
palabras reservadas
Una palabra con un significado específico y predefinido para un compilador, como "if" o "delete". En muchos lenguajes (no en Perl), es ilegal usar palabras reservadas para nombrar cualquier otra cosa. (Es por eso que están reservadas, después de todo). En Perl, simplemente no puedes usarlas para nombrar etiquetas o manejadores de archivos. También se llaman "palabras clave".
valor de retorno
El valor producido por una subrutina o expresión cuando se evalúa. En Perl, un valor de retorno puede ser una lista o un escalar.
RFC
Request For Comment (Solicitud de Comentario), que a pesar de las connotaciones tímidas, es el nombre de una serie de importantes documentos estándar.
desplazamiento a la derecha
Un desplazamiento de bits que divide un número por alguna potencia de 2.
rol
Un nombre para un conjunto concreto de comportamientos. Un rol es una forma de agregar comportamiento a una clase sin herencia.
root
El superusuario ("UID" == 0). También el directorio de nivel superior del sistema de archivos.
RTFM
Lo que te dicen cuando alguien piensa que deberías Leer El Maldito Manual (Read The Fine Manual).
fase de ejecución
Cualquier momento después de que Perl comience a ejecutar tu programa principal. Ver también fase de compilación. La fase de ejecución se pasa en su mayor parte en tiempo de ejecución, pero también puede pasarse en tiempo de compilación cuando se ejecutan los operadores "require", "do" "FILE", o "eval" "STRING", o cuando una sustitución utiliza el modificador "/ee".
tiempo de ejecución
El momento en que Perl está realmente haciendo lo que tu código dice que haga, en contraposición al período de tiempo anterior en el que estaba tratando de averiguar si lo que dijiste tenía algún sentido, que es el tiempo de compilación.
patrón en tiempo de ejecución
Un patrón que contiene una o más variables para interpolar antes de analizar el patrón como una expresión regular, y que por lo tanto no puede ser analizado en tiempo de compilación, sino que debe ser reanalizado cada vez que se evalúa el operador de coincidencia de patrones. Los patrones en tiempo de ejecución son útiles pero costosos.
RV
Un vehículo recreativo, no confundir con recreación vehicular. RV también significa un Valor de Referencia interno del tipo que puede contener un escalar. Ver también IV y NV si aún no estás confundido.
rvalue (valor derecho)
Un valor que podrías encontrar en el lado derecho de una asignación. Ver también lvalue (valor izquierdo).

S

sandbox (entorno aislado)
Un área amurallada que no se supone que afecte más allá de sus muros. Dejas que los niños jueguen en el sandbox en lugar de correr por la carretera. Ver Capítulo 20 del Libro del Camello, "Seguridad".
escalar
Un valor simple y singular; un número, cadena o referencia.
contexto escalar
La situación en la que una expresión se espera por su entorno (el código que la llama) que devuelva un único valor en lugar de una lista de valores. Ver también contexto y contexto de lista. Un contexto escalar a veces impone restricciones adicionales al valor de retorno; ver contexto de cadena y contexto numérico. A veces hablamos de un contexto booleano dentro de los condicionales, pero esto no impone restricciones adicionales, ya que cualquier valor escalar, ya sea numérico o de cadena, ya es verdadero o falso.
literal escalar
Un número o una cadena entre comillas, es decir, un valor real en el texto de tu programa, en contraposición a una variable.
valor escalar
Un valor que resulta ser un escalar en contraposición a una lista.
variable escalar
Una variable prefijada con "$" que contiene un solo valor.
ámbito (scope)
Desde qué distancia se puede ver una variable, a través de una. Perl tiene dos mecanismos de visibilidad. Realiza anidamiento dinámico de variables "local", lo que significa que el resto del bloque, y cualquier subrutina que se llame desde el resto del bloque, pueden ver las variables que son
local al bloque. Perl tiene alcance léxico de variables de "my", lo que significa que el resto del bloque puede ver la variable, pero otras subrutinas llamadas por el bloque *no* pueden ver la variable.
espacio de trabajo
El área en la que una invocación particular de un archivo o subrutina particular mantiene algunos de sus valores temporales, incluidas las variables de alcance léxico.
script
Un archivo de texto que es un programa destinado a ser ejecutado directamente en lugar de ser compilado a otra forma de archivo antes de la ejecución.

Asimismo, en el contexto de Unicode, un sistema de escritura para un idioma o grupo de idiomas en particular, como griego, bengalí o tengwar.

script kiddie
Un cracker que no es un hacker pero sabe lo suficiente para ejecutar scripts predefinidos. Un programador de cultura de carga.
sed
Un venerable editor de flujo (Stream EDitor) del que Perl deriva algunas de sus ideas.
semáforo
Un tipo sofisticado de enclavamiento que evita que múltiples hilos o procesos utilicen los mismos recursos simultáneamente.
separador
Un carácter o cadena que evita que dos cadenas circundantes se confundan entre sí. La función "split" opera sobre separadores. No confundir con delimitadores o terminadores. El "o" de la oración anterior separó las dos alternativas.
serialización
Colocar una estructura de datos compleja en orden lineal para que pueda almacenarse como una cadena en un archivo de disco o base de datos, o enviarse a través de una tubería. También se llama marshalling.
servidor
En redes, un proceso que anuncia un servicio o simplemente permanece en un lugar conocido y espera a que los clientes que necesitan servicio se pongan en contacto con él.
servicio
Algo que haces por otra persona para hacerla feliz, como darle la hora del día (o de su vida). En algunas máquinas, los servicios conocidos se enumeran mediante la función "getservent".
setgid
Igual que setuid, pero solo tiene que ver con la cesión de privilegios de grupo.
setuid
Se dice de un programa que se ejecuta con los privilegios de su propietario en lugar de (como suele ser el caso) los privilegios de quien lo está ejecutando. También describe el bit en la palabra de modo (bits de permiso) que controla la función. Este bit debe ser establecido explícitamente por el propietario para habilitar esta función, y el programa debe estar escrito con cuidado para no ceder más privilegios de los que debería.
memoria compartida
Una porción de memoria accesible por dos procesos diferentes que de otro modo no verían la memoria del otro.
shebang
Irlandés para todo el McGillicuddy. En la cultura Perl, un acrónimo de "sharp" (almohadilla) y "bang" (signo de exclamación), que significa la secuencia "#! " que le dice al sistema dónde encontrar el intérprete.
shell
Un intérprete de línea de comandos. El programa que interactivamente le da un prompt, acepta una o más líneas de entrada y ejecuta los programas que usted mencionó, alimentando a cada uno de ellos sus correctos argumentos y datos de entrada. Los shells también pueden ejecutar scripts que contengan dichos comandos. En Unix, los shells típicos incluyen el Bourne shell (/bin/sh), el C shell (/bin/csh) y el Korn shell (/bin/ksh). Perl no es estrictamente un shell porque no es interactivo (aunque los programas Perl pueden ser interactivos).
efectos secundarios
Algo adicional que ocurre cuando evalúas una expresión. Hoy en día puede referirse a casi cualquier cosa. Por ejemplo, evaluar una simple declaración de asignación típicamente tiene el "efecto secundario" de asignar un valor a una variable. (¡Y usted pensó que asignar el valor era su intención principal en primer lugar!) Asimismo, asignar un valor a la variable especial $| ($AUTOFLUSH) tiene el efecto secundario de forzar un vaciado después de cada "write" o "print" en el manejador de archivo seleccionado actualmente.
sigilo
Un glifo usado en magia. O, para Perl, el símbolo delante del nombre de una variable, como "$", "@", y "%".
señal
Un rayo inesperado; es decir, un evento desencadenado por el sistema operativo, probablemente cuando menos lo esperas.
manejador de señales
Una subrutina que, en lugar de estar contenta de ser llamada de la forma normal, se queda esperando un rayo inesperado antes de dignarse a ejecutarse. En Perl, los rayos inesperados se llaman señales, y se envían con la función incorporada "kill". Consulte el hash %SIG en el capítulo 25 del Libro del Camello, "Nombres Especiales", y la sección "Señales" en el capítulo 15 del Libro del Camello, "Comunicación entre procesos".
herencia simple
Las características que obtuviste de tu madre, si te dijo que no tenías padre. (Ver también herencia y herencia múltiple). En los lenguajes de computadora, la idea de que las clases se reproducen asexualmente de modo que una clase dada solo puede tener un ancestro o clase base directa. Perl no proporciona tal restricción, aunque ciertamente puedes programar Perl de esa manera si lo deseas.
rebanada
Una selección de cualquier número de elementos de una lista, arreglo o hash.
absorber
Leer un archivo completo en una cadena en una sola operación.
socket
Un punto final para la comunicación de red entre múltiples procesos que funciona de manera muy similar a un teléfono o un buzón de correos. Lo más importante de un socket es su dirección de red (como un número de teléfono). Diferentes tipos de sockets tienen diferentes tipos de direcciones; algunas se parecen a nombres de archivo y otras no.
referencia débil
Ver referencia simbólica.
filtro de fuente
Un tipo especial de módulo que realiza preprocesamiento en tu script justo antes de que llegue al tokenizador.
pila
Un dispositivo en el que puedes colocar cosas en la parte superior y luego retirarlas en el orden opuesto al que las pusiste. Ver LIFO.
estándar
Incluido en la distribución oficial de Perl, como en un módulo estándar, una herramienta estándar o una página de manual estándar de Perl.
error estándar
El flujo de salida predeterminado para comentarios desagradables que no pertenecen a la salida estándar. Representado dentro de un programa Perl por el manejador de salida filehandle "STDERR". Puedes usar este flujo explícitamente, pero las funciones incorporadas "die" y "warn" escriben automáticamente en tu flujo de error estándar (a menos que sean interceptadas o desviadas de otra manera).
entrada estándar
El flujo de entrada predeterminado para tu programa, que si es posible no debería importar de dónde provienen sus datos. Representado dentro de un programa Perl por el manejador de archivo "STDIN".
E/S estándar
Una biblioteca estándar de C para realizar entrada y salida en búfer al sistema operativo. (El "estándar" de la E/S estándar está como mucho marginalmente relacionado con el "estándar" de la entrada y salida estándar.) En general, Perl se basa en la implementación de E/S estándar que proporciona un sistema operativo determinado, por lo que las características de almacenamiento en búfer de un programa Perl en una máquina pueden no coincidir exactamente con las de otra máquina. Normalmente, esto solo influye en la eficiencia, no en la semántica. Si tu paquete de E/S estándar está haciendo almacenamiento en búfer de bloques y quieres que vacíe el búfer con más frecuencia, simplemente establece la variable $| a un valor verdadero.
Biblioteca Estándar
Todo lo que viene con la distribución oficial de perl. Algunas versiones de proveedor de perl cambian sus distribuciones, omitiendo algunas partes o incluyendo extras. Ver también doble vida.
salida estándar
El flujo de salida predeterminado para tu programa, que si es posible no debería importar a dónde van sus datos. Representado dentro de un programa Perl por el manejador de archivo "STDOUT".
declaración
Un comando para la computadora sobre qué hacer a continuación, como un paso en una receta: "Agregar mermelada a la masa y mezclar hasta que esté mezclado". Una declaración se distingue de una definición, que no le dice a la computadora que haga nada, sino solo que aprenda algo.
modificador de declaración
Un condicional o bucle que pones después de la declaración en lugar de antes, si sabes a qué nos referimos.
estático
Variando lentamente en comparación con algo más. (Desafortunadamente, todo es relativamente estable en comparación con algo más, excepto por ciertas partículas elementales, y no estamos tan seguros de ellas.) En las computadoras, donde se supone que las cosas varían rápidamente, "estático" tiene una connotación despectiva, indicando una variable, subrutina o método ligeramente disfuncional. En la cultura Perl, la palabra se evita educadamente.

En sistemas Unix, este estado es el mismo que el estado devuelto por wait(2). Ver "system" en el capítulo 27 del libro Camel, “Funciones”.

subrutina
Una parte de programa con nombre o accesible de otra manera que puede ser invocada desde otras partes del programa para lograr un subobjetivo del programa. Una subrutina a menudo se parametriza para realizar cosas diferentes pero relacionadas dependiendo de sus argumentos de entrada. Si la subrutina devuelve un valor significativo, también se llama función.
subíndice
Un valor que indica la posición de un elemento particular de un array en un array.
sustitución
Cambiar partes de una cadena mediante el operador "s///". (Evitamos usar este término para referirnos a la interpolación de variables).
subcadena
Una porción de una cadena, que comienza en una posición de carácter determinada (desplazamiento) y que abarca un número determinado de caracteres.
superclase
Ver clase base.
superusuario
La persona a la que el sistema operativo le permite hacer casi cualquier cosa. Típicamente tu administrador del sistema o alguien que pretende ser tu administrador del sistema. En sistemas Unix, el usuario root. En sistemas Windows, generalmente el usuario Administrador.
SV
Abreviatura de "scalar value" (valor escalar). Pero dentro del intérprete de Perl, cada referente se trata como miembro de una clase derivada de SV, de una manera orientada a objetos. Cada valor dentro de Perl se pasa como un puntero C "SV*". La struct SV conoce su propio "tipo de referente", y el código es lo suficientemente inteligente (esperamos) como para no intentar llamar a una función de hash en una subrutina.
conmutador
Una opción que se da en la línea de comandos para influir en cómo funciona tu programa, generalmente introducida con un guion. La palabra también se usa como apodo para una sentencia switch.
agrupación de conmutadores
La combinación de múltiples conmutadores de línea de comandos (por ejemplo, "-a -b -c") en un solo conmutador (por ejemplo, "-abc"). Cualquier conmutador con un argumento adicional debe ser el último conmutador en un grupo.
sentencia switch
Una técnica de programación que te permite evaluar una expresión y luego, basándose en el valor de la expresión, realizar una bifurcación múltiple al fragmento de código apropiado para ese valor. También se le llama "estructura case", en honor a la construcción similar de Pascal. La mayoría de las sentencias switch en Perl se escriben "given". Ver "La sentencia \"given\"" en el capítulo 4 del libro Camel, “Sentencias y Declaraciones”.

Las palabras clave "given", "when" y el operador smartmatch ("~~") se eliminarán en Perl 5.42.

símbolo
En general, cualquier token o metasímbolo. A menudo se usa más específicamente para referirse al tipo de nombre que se puede encontrar en una tabla de símbolos.
depurador simbólico
Un programa que te permite recorrer la ejecución de tu programa, deteniéndote o imprimiendo cosas aquí y allá para ver si algo salió mal y, si es así, qué. La parte "simbólica" solo significa que puedes hablar con el depurador usando los mismos símbolos con los que está escrito tu programa.
enlace simbólico
Un nombre de archivo alternativo que apunta al nombre de archivo real, que a su vez apunta al archivo real. Cada vez que el sistema operativo intenta analizar una ruta que contiene un enlace simbólico, simplemente sustituye el nuevo nombre y continúa analizando.
referencia simbólica
Una variable cuyo valor es el nombre de otra variable o subrutina. Al desreferenciar la primera variable, puedes acceder a la segunda. Las referencias simbólicas son ilegales bajo "use strict \"refs\"".
tabla de símbolos
Donde un compilador recuerda los símbolos. Un programa como Perl debe recordar de alguna manera todos los nombres de todas las variables, manejadores de archivo y subrutinas que has usado. Lo hace colocando los nombres en una tabla de símbolos, que en Perl se implementa utilizando una tabla hash. Hay una tabla de símbolos separada para cada paquete para darle a cada paquete su propio espacio de nombres.
síncrono
Programación en la que se puede determinar la secuencia ordenada de eventos; es decir, cuando las cosas suceden una tras otra, no al mismo tiempo.
azúcar sintáctico
Una forma alternativa de escribir algo más fácilmente; un atajo.
sintaxis
Del griego σύνταξις, "con arreglo". Cómo se combinan las cosas (particularmente los símbolos) entre sí.
árbol de sintaxis
Una representación interna de tu programa donde las construcciones de nivel inferior cuelgan de las construcciones de nivel superior que las engloban.
llamada al sistema
Una llamada a una función directamente al sistema operativo. Muchas de las subrutinas y funciones importantes que usas no son llamadas directas al sistema, sino que se construyen en una o más capas por encima del nivel de llamada al sistema. En general, los programadores de Perl no necesitan preocuparse por la distinción. Sin embargo, si da la casualidad de que sabes qué funciones de Perl son realmente llamadas al sistema, puedes predecir cuáles de ellas establecerán la variable $! ($ERRNO) en caso de fallo. Desafortunadamente, los programadores principiantes a menudo confunden el término "llamada al sistema" con lo que sucede cuando llamas a la función "system" de Perl, que en realidad implica muchas llamadas al sistema. Para evitar cualquier confusión, casi siempre decimos "llamada al sistema" para algo que podrías llamar indirectamente a través de la función "syscall" de Perl, y nunca para algo que llamarías con la función "system" de Perl.

T

comprobaciones de contaminació
La contabilidad especial que realiza Perl para rastrear el flujo de datos externos a través de tu programa y prohibir su uso en comandos del sistema.
contaminado
Se dice de los datos derivados de las manos sucias de un usuario, y por lo tanto inseguros para que un programa seguro dependa de ellos. Perl realiza comprobaciones de contaminación si ejecutas un programa setuid (o setgid), o si usas el conmutador "-T".
modo de contaminación
Ejecutar bajo el conmutador "-T", marcando todos los datos externos como sospechosos y negándose a usarlos con comandos del sistema. Ver el capítulo 20 del libro Camel, “Seguridad”.
TCP
Abreviatura de Transmission Control Protocol. Un protocolo envuelto alrededor

NAME

perlglossary — Glossary of Perl terms

VERSION

This document describes the terms used in the Perl language.

DESCRIPTION

This glossary contains terms commonly used in Perl programming. The terms are listed alphabetically.

T

taint mode
A mode of operation in which Perl considers any data coming from the outside world (environment variables, command-line arguments, filehandles) to be potentially unsafe. Operations involving tainted data are restricted. Taint mode is enabled by the -T command-line switch. See also security.
tainted scalar
A scalar value that is marked as tainted. See taint mode.
temporary
A file or other resource that is created for a specific purpose and is expected to be deleted or discarded after use. Perl often creates temporary files for various operations.
term
An individual component of an expression, such as a variable, a literal, or a function call.
ternary operator
An operator that takes three operands. In Perl, the conditional operator (?:) is the only ternary operator. It is used for conditional assignment or expression evaluation.
text
A sequence of characters, typically forming human-readable content. In Perl, strings are used to represent text.
thread
A unit of execution within a process. Perl supports multithreading, allowing concurrent execution of code. Threads share memory within a process.
tie
A mechanism that allows you to associate a variable with a Perl object. This object then overrides the default behavior of the variable for accessing or modifying its value. It's used to implement custom data types.
time
The current system time, usually represented as the number of seconds since the Unix epoch (January 1, 1970, 00:00:00 UTC). The time function returns this value.
timestamp
A record of the date and time at which an event occurred. In Perl, timestamps are often handled using the time function or related modules.
token
The smallest meaningful unit in a programming language, often representing keywords, identifiers, operators, or literals. Lexical analysis breaks code into tokens.
transparent
See virtual.
tree
A hierarchical data structure consisting of nodes connected by edges. Abstract Syntax Trees (ASTs) are examples of trees used in programming language compilation and analysis.
trigraph
A sequence of three characters that represents a single special character. Trigraphs are rarely used in modern programming and are generally discouraged.
true
A boolean value representing a condition that is met or valid. In Perl, any non-zero number, non-empty string, or the special value undef (when evaluated in a boolean context) can be considered true.
truth
The property of an expression evaluating to a true value in a boolean context.
try
A block of code that may potentially raise an exception. Often used in conjunction with catch or finally blocks for exception handling. Perl's exception handling is typically done using modules like Try::Tiny.
TSRM
Thread Safe Reentrant Management. A system used in Perl to manage global state in a way that is safe for multithreaded applications.
type
The kind of data that a variable can hold, such as integer, floating-point number, string, or reference. Perl is dynamically typed, meaning variable types are determined at runtime.
typeglob
A mechanism in Perl that allows you to refer to a symbol table entry by its name, regardless of whether it represents a scalar, array, hash, subroutine, or filehandle. It's denoted by an asterisk (*) followed by a name.

U

UALIAS
Underlying Alias. Refers to how Perl handles aliases internally, particularly in relation to symbol table entries.
undef
A special value in Perl indicating the absence of a defined value. It evaluates to false in a boolean context.
Unicode
An international standard for encoding characters. Perl has robust support for Unicode, allowing programs to handle text from various languages.
uninitialized
A variable that has been declared but has not yet been assigned a value. Accessing an uninitialized variable may result in warnings or unpredictable behavior.
unique
An element or value that occurs only once within a collection or dataset. In Perl, uniqueness can often be enforced using hash keys.
unlink
A built-in Perl function used to delete files. It returns the number of files successfully deleted.
unpack
A built-in Perl function used to extract data from a packed binary string according to a specified template. It is the inverse of the pack function.
untaint
The process of removing the taint mark from a scalar value. This is typically done using the untaint method of a regular expression match within the taint mode.
unshift
A built-in Perl function used to add elements to the beginning of an array.
until loop
A looping construct that repeatedly executes a block of code as long as a given condition is false. It checks the condition *after* executing the block at least once.
upgrade
To enhance or improve the capabilities or performance of a system or software component.
URI
Uniform Resource Identifier. A string of characters used to identify a resource. Perl has modules for working with URIs.
use
A statement in Perl used to load modules and enable pragmas. It typically imports functions, variables, or other definitions into the current scope.
user
An entity that interacts with a computer system. In the context of Perl scripts, users might provide input or run the script itself.
UTF-8
A character encoding standard that represents Unicode characters. Perl supports UTF-8 encoding for strings.

V

value
A piece of data stored in a variable or returned by an expression. Values can be of various types, such as numbers, strings, or references.
variable
A named storage location that holds a value. In Perl, variables are distinguished by leading sigils: $ for scalars, @ for arrays, and % for hashes.
vector
See v-string.
verbose
Describes a mode of operation where a program produces a large amount of output, often for debugging or informational purposes. The -v switch can enable verbose output in some Perl contexts.
version
See v-string.
virtual
An abstraction or representation that hides the underlying complexity of a system. In Perl, certain operations or data structures might be handled virtually, meaning the programmer doesn't need to manage the low-level details. The opposite of transparent.
virtual machine
An abstract computing machine that is implemented in software. The Perl interpreter itself can be thought of as a virtual machine executing Perl bytecode.
void context
A form of scalar context in which an expression is not expected to return any value at all and is evaluated for its side effects alone.
v-string
A “version” or “vector” string specified with a "v" followed by a series of decimal integers in dot notation, for instance, "v1.20.300.4000". Each number turns into a character with the specified ordinal value. (The "v" is optional when there are at least three integers.)

W

warning
A message printed to the "STDERR" stream to the effect that something might be wrong but isn’t worth blowing up over. See "warn" in Camel chapter 27, “Functions” and the "warnings" pragma in Camel chapter 28, “Pragmatic Modules”.
watch expression
An expression which, when its value changes, causes a breakpoint in the Perl debugger.
weak reference
A reference that doesn’t get counted normally. When all the normal references to data disappear, the data disappears. These are useful for circular references that would never disappear otherwise.
whitespace
A character that moves your cursor but doesn’t otherwise put anything on your screen. Typically refers to any of: space, tab, line feed, carriage return, or form feed. In Unicode, matches many other characters that Unicode considers whitespace, including the ɴ-ʙʀ .
word
In normal “computerese”, the piece of data of the size most efficiently handled by your computer, typically 32 bits or so, give or take a few powers of 2. In Perl culture, it more often refers to an alphanumeric identifier (including underscores), or to a string of nonwhitespace characters bounded by whitespace or string boundaries.
working directory
Your current directory, from which relative pathnames are interpreted by the operating system. The operating system knows your current directory because you told it with a "chdir", or because you started out in the place where your parent process was when you were born.
wrapper
A program or subroutine that runs some other program or subroutine for you, modifying some of its input or output to better suit your purposes.
WYSIWYG
What You See Is What You Get. Usually used when something that appears on the screen matches how it will eventually look, like Perl’s "format" declarations. Also used to mean the opposite of magic because everything works exactly as it appears, as in the three- argument form of "open".

X

XS
An extraordinarily exported, expeditiously excellent, expressly eXternal Subroutine, executed in existing C or C++ or in an exciting extension language called (exasperatingly) XS.
XSUB
An external subroutine defined in XS.

Y

yacc
Yet Another Compiler Compiler. A parser generator without which Perl probably would not have existed. See the file perly.y in the Perl source distribution.

Z

zero width
A subpattern assertion matching the null string between characters.
zombie
A process that has died (exited) but whose parent has not yet received proper notification of its demise by virtue of having called "wait" or "waitpid". If you "fork", you must clean up after your child processes when they exit; otherwise, the process table will fill up and your system administrator will Not Be Happy with you.
