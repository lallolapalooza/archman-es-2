NOMBRE

perf-kmem - Herramienta para rastrear/medir propiedades de la memoria del kernel

SINOPSIS

perf kmem [<opciones>] {record|stat}

DESCRIPCIÓN

Hay dos variantes de perf kmem:

'perf kmem [<opciones>] record [<opciones-de-perf-record>] <comando>' para
grabar los eventos kmem de una carga de trabajo arbitraria. Se pueden especificar
opciones adicionales de 'perf record' después de record, como '-o' para cambiar
el nombre del archivo de salida.
'perf kmem [<opciones>] stat' para reportar estadísticas de la memoria del
kernel.

OPCIONES

-i <archivo>, --input=<archivo>

Para stat, seleccionar el archivo de entrada (por defecto: perf.data a menos que stdin sea un fifo)

-f, --force

No realizar validación de propiedad

-v, --verbose

Ser más verboso. (mostrar dirección del símbolo, etc.)

--caller

Mostrar estadísticas por sitio de llamada

--alloc

Mostrar estadísticas por asignación

-s <clave[,clave2...]>, --sort=<clave[,clave2...]>

Ordenar la salida (por defecto: frag,hit,bytes para slab y bytes,hit para page). Las claves de ordenación disponibles son ptr, callsite, bytes, hit, pingpong, frag para slab y page, callsite, bytes, hit, order, migtype, gfp para page. Esta opción debe ir precedida por una de las opciones de selección de modo, es decir, --slab, --page, --alloc y/o --caller.

-l <num>, --line=<num>

Mostrar solo n líneas

--raw-ip

Mostrar ip sin procesar en lugar de símbolo

--slab

Analizar eventos del asignador SLAB.

--page

Analizar eventos del asignador de páginas

--live

Mostrar estadísticas de páginas en vivo. perf kmem muestra estadísticas totales de asignación por defecto, pero esta opción muestra páginas en vivo (actualmente asignadas) en su lugar. (Esta opción solo funciona con la opción --page)

--time=<inicio>,<fin>

Analizar solo muestras dentro de la ventana de tiempo dada: <inicio>,<fin>. Los tiempos tienen el formato segundos.microsegundos. Si no se proporciona inicio (es decir, la cadena de tiempo es ,x.y) el análisis comienza al principio del archivo. Si no se proporciona tiempo de fin (es decir, la cadena de tiempo es x.y,) el análisis llega hasta el final del archivo.
