PESIGCHECK(1) Manual de Comandos Generales PESIGCHECK(1)

NOMBRE

pesigcheck — herramienta para verificar aplicaciones UEFI

SINOPSIS

pesigcheck -i archivo [-n] [-D archivo] [-X archivo] [-c archivo] [-q] [-v]

DESCRIPCIÓN

pesigcheck es una herramienta de línea de comandos para verificar la firma de aplicaciones UEFI.

OPCIONES

-i archivo | --in archivo
Archivo binario PE archivo a ser verificado
-n | --no-system-db
inhibir el uso de DB y DBX del sistema en ejecución
-D archivo | --dbfile archivo
Lista de Firma EFI o archivo de variable EFI archivo a ser usado como base de datos de seguridad permitida

puede ser usado más de una vez

-X archivo | --dbxfile archivo
Lista de Firma EFI o archivo de variable EFI archivo a ser usado como base de datos de seguridad en lista negra

puede ser usado más de una vez

-c archivo | --certfile archivo
Archivo de certificado codificado en DER archivo a ser añadido a la base de datos de seguridad permitida

puede ser usado más de una vez

-q | --quiet
ser más silencioso
-v | --verbose
ser más verboso

ESTÁNDARES

UEFI Specification Working Group, Unified Extensible Firmware Interface (UEFI) Specification Version 2.8, Unified Extensible Firmware Interface Forum, https://uefi.org/specifications , Marzo 2019.

VER TAMBIÉN

authvar(1), pesign(1), efisigdb(1)
