PERLDBMFILTER(1perl) Guía de Referencia del Programador de Perl PERLDBMFILTER(1perl)

NOMBRE

perldbmfilter - Filtros DBM de Perl

SINOPSIS

$db = tie %hash, 'DBM', ...
$old_filter = $db->filter_store_key  ( sub { ... } );
$old_filter = $db->filter_store_value( sub { ... } );
$old_filter = $db->filter_fetch_key  ( sub { ... } );
$old_filter = $db->filter_fetch_value( sub { ... } );

DESCRIPCIÓN

Los cuatro métodos "filter_*" mostrados arriba están disponibles en todos los módulos DBM que se distribuyen con Perl, a saber DB_File, GDBM_File, NDBM_File, ODBM_File y SDBM_File.

Cada uno de los métodos funciona de manera idéntica y se utiliza para instalar (o desinstalar) un único Filtro DBM. La única diferencia entre ellos es el lugar donde se instala el filtro.

En resumen:

filter_store_key
Si se ha instalado un filtro con este método, se invocará cada vez que escriba una clave en una base de datos DBM.
filter_store_value
Si se ha instalado un filtro con este método, se invocará cada vez que escriba un valor en una base de datos DBM.
filter_fetch_key
Si se ha instalado un filtro con este método, se invocará cada vez que lea una clave de una base de datos DBM.
filter_fetch_value
Si se ha instalado un filtro con este método, se invocará cada vez que lea un valor de una base de datos DBM.

Puede utilizar cualquier combinación de los métodos, desde ninguno hasta los cuatro.

Todos los métodos de filtro devuelven el filtro existente, si lo hay, o "undef" si no.

Para eliminar un filtro, pase "undef" a él.

El Filtro

Cuando cada filtro es llamado por Perl, una copia local de $_ contendrá la clave o el valor a filtrar. El filtrado se logra modificando el contenido de $_. El código de retorno del filtro se ignora.

Un Ejemplo: el problema de la terminación NULL

Los Filtros DBM son útiles para una clase de problemas donde siempre se desea realizar la misma transformación a todas las claves, todos los valores o ambos.

Por ejemplo, considere el siguiente escenario. Tiene una base de datos DBM que necesita compartir con una aplicación C de terceros. La aplicación C asume que *todas* las claves y valores están terminados en NULL. Desafortunadamente, cuando Perl escribe en bases de datos DBM, no utiliza terminación NULL, por lo que su aplicación Perl tendrá que gestionar la terminación NULL por sí misma. Al escribir en la base de datos, tendrá que usar algo como esto:

$hash{"$key\0"} = "$value\0";

De manera similar, el NULL debe tenerse en cuenta al considerar la longitud de las claves/valores existentes.

Sería mucho mejor si pudiera ignorar el problema de la terminación NULL en el código de la aplicación principal y tener un mecanismo que añadiera automáticamente el NULL terminador a todas las claves y valores cada vez que escriba en la base de datos y los eliminara al leer de la base de datos. Como seguramente ya ha adivinado, este es un problema que los Filtros DBM pueden solucionar muy fácilmente.

use v5.36;
use SDBM_File;
use Fcntl;
my %hash;
my $filename = "filt";
unlink $filename;
my $db = tie(%hash, 'SDBM_File', $filename, O_RDWR|O_CREAT, 0640)
  or die "No se puede abrir $filename: $!\n";
# Instalar Filtros DBM
$db->filter_fetch_key  ( sub { s/\0$//    } );
$db->filter_store_key  ( sub { $_ .= "\0" } );
$db->filter_fetch_value(
    sub { no warnings 'uninitialized'; s/\0$// } );
$db->filter_store_value( sub { $_ .= "\0" } );
$hash{"abc"} = "def";
my $x = $hash{"ABC"};
# ...
undef $db;
untie %hash;

El código anterior utiliza SDBM_File, pero funcionará con cualquiera de los módulos DBM.

Esperamos que el contenido de cada uno de los filtros sea autodescriptivo. Ambos filtros de "fetch" eliminan el NULL terminador, y ambos filtros de "store" añaden un NULL terminador.

Otro Ejemplo: La clave es un int de C

Aquí hay otro ejemplo real. Por defecto, cada vez que Perl escribe en una base de datos DBM, siempre escribe la clave y el valor como cadenas. Así que cuando usas esto:

$hash{12345} = "algo";

la clave 12345 se almacenará en la base de datos DBM como la cadena de 5 bytes "12345". Si realmente desea que la clave se almacene en la base de datos DBM como un int de C, tendrá que usar "pack" al escribir, y "unpack" al leer.

Aquí hay un Filtro DBM que lo hace:

use v5.36;
use DB_File;
my %hash;
my $filename = "filt";
unlink $filename;
my $db = tie %hash, 'DB_File', $filename, O_CREAT|O_RDWR, 0666,
    $DB_HASH or die "No se puede abrir $filename: $!\n";
$db->filter_fetch_key  ( sub { $_ = unpack("i", $_) } );
$db->filter_store_key  ( sub { $_ = pack ("i", $_) } );
$hash{123} = "def";
# ...
undef $db;
untie %hash;

El código anterior utiliza DB_File, pero de nuevo funcionará con cualquiera de los módulos DBM.

Esta vez solo se han utilizado dos filtros; solo necesitamos manipular el contenido de la clave, por lo que no fue necesario instalar ningún filtro de valor.

VER TAMBIÉN

DB_File, GDBM_File, NDBM_File, ODBM_File y SDBM_File.
