NOMBRE

perf-diff - Lee archivos perf.data y muestra el perfil diferencial

SINOPSIS

perf diff [archivo base] [archivo de datos1] [[archivo de datos2] ... ]

DESCRIPCIÓN

Este comando muestra la diferencia de rendimiento entre dos o más archivos perf.data capturados mediante perf record.

Si no se pasan parámetros, asumirá perf.data.old y perf.data.

El perfil diferencial se muestra solo para eventos que coinciden en ambos archivos perf.data especificados.

Si no se pasan parámetros, las muestras se ordenarán por dso y símbolo. Dado que los archivos perf.data pueden provenir de binarios diferentes, las direcciones de los símbolos pueden variar. Por lo tanto, perf diff se basa en la comparación de los nombres de archivos y símbolos.

OPCIONES

-D, --dump-raw-trace

Vuelca el rastreo sin procesar en formato ASCII.

--kallsyms=<archivo>

Ruta del archivo kallsyms.

-m, --modules

Carga símbolos de módulos. ADVERTENCIA: usar solo con -k y el kernel ACTIVO.

-d, --dsos=

Solo considera símbolos en estos dsos. CSV que entiende entradas file://nombre_archivo. Esta opción afectará al porcentaje de la columna Baseline/Delta. Consulte --percentage para más información.

-C, --comms=

Solo considera símbolos en estos comms. CSV que entiende entradas file://nombre_archivo. Esta opción afectará al porcentaje de la columna Baseline/Delta. Consulte --percentage para más información.

-S, --symbols=

Solo considera estos símbolos. CSV que entiende entradas file://nombre_archivo. Esta opción afectará al porcentaje de la columna Baseline/Delta. Consulte --percentage para más información.

-s, --sort=

Ordena por clave(s): pid, comm, dso, symbol, cpu, parent, srcline. Por favor, consulte la descripción de --sort en la página del manual de perf-report.

-t, --field-separator=

Usa un carácter separador especial y no rellenes con espacios, reemplazando todas las ocurrencias de este separador en los nombres de símbolos (y otra salida) con un carácter de ., que por lo tanto es el único separador no válido.

-v, --verbose

Sé verboso, por ejemplo, muestra los recuentos sin procesar además de la diferencia.

-q, --quiet

No muestres advertencias ni mensajes. (Suprime -v)

-f, --force

No realices validación de propiedad.

--symfs=<directorio>

Busca archivos con símbolos relativos a este directorio.

-b, --baseline-only

Muestra solo elementos con coincidencia en la línea base.

-c, --compute

Selección de cálculo diferencial - delta, ratio, wdiff, cycles, delta-abs (por defecto es delta-abs). El valor predeterminado se puede cambiar usando la opción de configuración diff.compute. Consulte la sección MÉTODOS DE COMPARACIÓN para más información.

--cycles-hist

Informa un histograma y la desviación estándar para los datos de ciclos. Puede ayudarnos a juzgar si los datos de ciclos reportados son ruidosos o no. Esta opción debe usarse con -c cycles.

-p, --period

Muestra los valores de período para ambas entradas de historial comparadas.

-F, --formula

Muestra la fórmula para el cálculo dado.

-o, --order

Especifica el número de columna de ordenación del cálculo. 0 significa ordenar por la sobrecarga de la línea base y 1 (por defecto) significa ordenar por el valor calculado de la columna 1 (datos del primer archivo distinto de la línea base). Los valores mayores que 1 solo se pueden usar si se proporcionan suficientes archivos de datos. El valor predeterminado se puede establecer utilizando la opción de configuración diff.order.

--percentage

Determina cómo mostrar el porcentaje de sobrecarga de las entradas filtradas. Se pueden aplicar filtros mediante las opciones --comms, --dsos y/o --symbols. 
"relative" significa que es relativo solo a las entradas filtradas,
de modo que la suma de las entradas mostradas siempre será del 100%.
"absolute" significa que conserva el valor original antes y después
de aplicar el filtro.

--time

Analiza muestras dentro de la ventana de tiempo dada. Admite porcentajes de tiempo con rangos de tiempo múltiples. La cadena de tiempo es a%/n,b%/m,... o a%-b%,c%-%d,.... 
Por ejemplo:
Selecciona la segunda porción de tiempo del 10% para comparar:
perf diff --time 10%/2
Selecciona la porción de tiempo del 0% al 10% para comparar:
perf diff --time 0%-10%
Selecciona la primera y la segunda porción de tiempo del 10% para
comparar:
perf diff --time 10%/1,10%/2
Selecciona las porciones de tiempo del 0% al 10% y del 30% al 40%
para comparar:
perf diff --time 0%-10%,30%-40%
También admite el análisis de muestras dentro de una ventana de
tiempo dada <inicio>,<fin>. Los tiempos tienen el formato
segundos.nanosegundos. Si no se proporciona 'inicio' (es decir, la
cadena de tiempo es ',x.y'), el análisis comienza al principio del
archivo. Si no se proporciona el tiempo de fin (es decir, la cadena
de tiempo es 'x.y,'), el análisis llega hasta el final del archivo.
Se pueden separar varios rangos con espacios, lo que requiere que el
argumento esté entre comillas, por ejemplo, --time "1234.567,1234.789
1235," La cadena de tiempo es 'a1.b1,c1.d1:a2.b2,c2.d2'. Use ':' para
separar marcas de tiempo para diferentes archivos perf.data.
Por ejemplo, obtenemos la información de marca de tiempo de 'perf
script'.
perf script -i perf.data.old
  mgen 13940 [000]  3946.361400: ...
perf script -i perf.data
  mgen 13940 [000]  3971.150589 ...
perf diff --time 3946.361400,:3971.150589,
Analiza perf.data.old desde la marca de tiempo 3946.361400 hasta
el final de perf.data.old y analiza perf.data desde la marca de
tiempo 3971.150589 hasta el final de perf.data.

--cpu

Solo compara muestras para la lista de CPUs proporcionadas. Se pueden proporcionar varias CPUs como una lista separada por comas sin espacios: 0,1. Los rangos de CPUs se especifican con -: 0-2. El valor predeterminado es informar muestras en todas las CPUs.

--pid=

Solo compara muestras para el ID de proceso dado (lista separada por comas).

--tid=

Solo compara muestras para el ID de hilo dado (lista separada por comas).

--stream

Habilita la comparación de flujos calientes. Un flujo puede ser una cadena de llamadas que se agrega mediante los registros de rama de las muestras.

COMPARACIÓN

La comparación está regida por el archivo base. El archivo perf.data base se itera en busca de muestras. Todos los demás archivos perf.data especificados en la línea de comandos se buscan para encontrar el par de muestras de la línea base. Si se encuentra el par, se realiza el cálculo especificado y se muestra el resultado.

Todas las muestras de los archivos perf.data no base, que no coinciden con ninguna entrada de la línea base, se muestran con un espacio vacío en la columna de la línea base y posibles resultados de cálculo (delta) en su columna relacionada.

Ejemplo de archivos de muestras: - archivo A con muestras f1, f2, f3, f4, f6 - archivo B con muestras f2, f4, f5 - archivo C con muestras f1, f2, f5

Ejemplo de salida: x - se realiza el cálculo para el par b - porcentaje de muestra base

•perf diff A B C 
línea base/A cálculo/B cálculo/C  muestras
---------------------------------------
b                    x          f1
b          x         x          f2
b                               f3
b          x                    f4
b                               f6
           x         x          f5
•perf diff B A C 
línea base/B cálculo/A cálculo/C  muestras
---------------------------------------
b          x         x          f2
b          x                    f4
b                    x          f5
           x         x          f1
           x                    f3
           x                    f6
•perf diff C B A 
línea base/C cálculo/B cálculo/A  muestras
---------------------------------------
b                    x          f1
b          x         x          f2
b          x                    f5
                     x          f3
           x         x          f4
                     x          f6

MÉTODOS DE COMPARACIÓN

delta

Si se especifica, la columna Delta se muestra con el valor d calculado como:

d = A->period_percent - B->period_percent

con: - A/B siendo entradas de hist coincidentes de los archivos de datos/base especificados (o perf.data/perf.data.old) respectivamente.

•period_percent siendo el % del valor del período de la entrada de hist dentro de un único archivo de datos.
•con filtrado por -C, -d y/o -S, period_percent puede cambiar en relación a cómo se filtran las entradas. Use --percentage=absolute para prevenir tales fluctuaciones.

delta-abs

Igual que el método 'delta', pero ordena el resultado por los valores absolutos.

ratio

Si se especifica, la columna Ratio se muestra con el valor r calculado como:

r = A->period / B->period

con: - A/B siendo entradas de hist coincidentes de los archivos de datos/base especificados (o perf.data/perf.data.old) respectivamente.

•period siendo el valor del período de la entrada de hist.

wdiff:WEIGHT-B,WEIGHT-A

Si se especifica, la columna Diferencia ponderada se muestra con el valor d calculado como:

d = B->period * WEIGHT-A - A->period * WEIGHT-B
•A/B siendo entradas de hist coincidentes de los archivos de datos/base especificados (o perf.data/perf.data.old) respectivamente.
•period siendo el valor del período de la entrada de hist.
•WEIGHT-A/WEIGHT-B siendo pesos proporcionados por el usuario en la opción -c detrás del separador : como -c wdiff:1,2.
•WEIGHT-A siendo el peso del archivo de datos.
•WEIGHT-B siendo el peso del archivo de datos base.

cycles

Si se especifica, se muestra la columna Diferencia de Ciclos [Rango de Bloque de Programa]. Muestra la diferencia de ciclos del mismo bloque básico de programa entre dos perf.data. El bloque básico de programa es el código entre dos bifurcaciones.

[Rango de Bloque de Programa] indica el rango de un bloque básico de programa. Se informa la línea fuente si se puede encontrar, de lo contrario se utiliza símbolo+desplazamiento.

VER TAMBIÉN

perf-record(1), perf-report(1)
