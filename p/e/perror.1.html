PERROR(1) Sistema de bases de datos MariaDB PERROR(1)

NOMBRE

perror - explica códigos de error

SINOPSIS

perror [opciones] codigodeerror ...

DESCRIPCIÓN

Para la mayoría de los errores del sistema, MariaDB muestra, además de un mensaje de texto interno, el código de error del sistema en uno de los siguientes estilos:

mensaje ... (errno: #)
mensaje ... (Errcode: #)

Puede averiguar qué significa el código de error examinando la documentación de su sistema o utilizando la utilidad perror.

perror imprime una descripción de un código de error del sistema o de un código de error del motor de almacenamiento (manejador de tablas).

Invoque perror de la siguiente manera:

shell> perror [opciones] codigodeerror ...

Ejemplo:

shell> perror 13 64
OS error code  13:  Permission denied
OS error code  64:  Machine is not on the network

Tenga en cuenta que el significado de los mensajes de error del sistema puede depender de su sistema operativo. Un código de error dado puede significar cosas diferentes en diferentes sistemas operativos.

perror admite las siguientes opciones.

•--help, --info, -I, -?

Muestra un mensaje de ayuda y sale.

•--silent, -s

Modo silencioso. Imprime solo el mensaje de error.

•--verbose, -v

Modo detallado. Imprime el código de error y el mensaje. Este es el comportamiento predeterminado.

•--version, -V

Muestra información de la versión y sale.
