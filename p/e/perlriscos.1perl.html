PERLRISCOS(1perl) Guía de referencia del programador de Perl PERLRISCOS(1perl)

NOMBRE

perlriscos - Versión 5 de Perl para RISC OS

DESCRIPCIÓN

Este documento proporciona instrucciones para compilar Perl para RISC OS. Es complicado por la necesidad de compilar cruzadamente. Hay una versión binaria de perl disponible en https://www.cp15.org/perl/ que quizás desee utilizar en lugar de intentar compilarlo usted mismo.

COMPILACIÓN

Necesita un compilador cruzado GCCSDK https://www.riscos.info/downloads/gccsdk/latest/ instalado y funcionando y REXEN https://www.cp15.org/programming/.

Primero, copie el código fuente y compile una copia nativa de perl para su sistema anfitrión. Luego, en el código fuente a compilar cruzadamente:

1.
$ ./Configure
2.
Seleccione el archivo de ayuda de RISC OS (hints/riscos.sh). Las respuestas predeterminadas para el resto de las preguntas suelen ser suficientes.

Tenga en cuenta que, si desea ejecutar "Configure" de forma no interactiva (consulte el documento INSTALL para obtener detalles), para que seleccione el archivo de ayuda correcto, deberá proporcionar el argumento "-Dhintfile=riscos" en la línea de comandos de "Configure".

3.
$ make miniperl
4.
Esto debería compilar "miniperl" y luego fallar cuando intente ejecutarlo.
5.
Copie el ejecutable miniperl de la compilación nativa realizada anteriormente para reemplazar el miniperl compilado cruzadamente.
6.
$ make
7.
Esto utilizará "miniperl" para completar el resto de la compilación.
