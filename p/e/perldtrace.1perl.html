PERLDTRACE(1perl) Guía de referencia del programador de Perl PERLDTRACE(1perl)

NOMBRE

perldtrace — Soporte de Perl para DTrace

SINOPSIS

# dtrace -Zn 'perl::sub-entry, perl::sub-return { trace(copyinstr(arg0)) }'
dtrace: description 'perl::sub-entry, perl::sub-return ' matched 10 probes
# perl -E 'sub outer { inner(@_) } sub inner { say shift } outer("hola")'
hola
(salida de dtrace)
CPU     ID                    FUNCTION:NAME
  0  75915       Perl_pp_entersub:sub-entry   BEGIN
  0  75915       Perl_pp_entersub:sub-entry   import
  0  75922      Perl_pp_leavesub:sub-return   import
  0  75922      Perl_pp_leavesub:sub-return   BEGIN
  0  75915       Perl_pp_entersub:sub-entry   outer
  0  75915       Perl_pp_entersub:sub-entry   inner
  0  75922      Perl_pp_leavesub:sub-return   inner
  0  75922      Perl_pp_leavesub:sub-return   outer

DESCRIPCIÓN

DTrace es un framework para el rastreo integral a nivel de sistema y aplicación. Perl es un proveedor de DTrace, lo que significa que expone varios puntos de sondeo para instrumentación. Puede utilizarlos en conjunción con puntos de sondeo a nivel de kernel, así como puntos de sondeo de otros proveedores como MySQL, para diagnosticar defectos de software, o incluso cuellos de botella de su aplicación.

Perl debe compilarse con la opción "-Dusedtrace" para poder utilizar los puntos de sondeo proporcionados. Si bien DTrace intenta no tener sobrecarga cuando su instrumentación no está activa, el propio soporte de Perl no puede garantizarlo, por lo que se compila sin puntos de sondeo de DTrace en la mayoría de los sistemas. Una excepción notable es que Mac OS X incluye un /usr/bin/perl con el soporte de DTrace habilitado.

HISTORIA

5.10.1
Se agregó el soporte inicial de DTrace de Perl, proporcionando puntos de sondeo "sub-entry" y "sub-return".
5.14.0
Los puntos de sondeo "sub-entry" y "sub-return" obtienen un cuarto argumento: el nombre del paquete de la función.
5.16.0
Se agregó el punto de sondeo "phase-change".
5.18.0
Se agregaron los puntos de sondeo "op-entry", "loading-file" y "loaded-file".

PUNTOS DE SONDEO

sub-entry(NOMBRE_SUBRUTINA, ARCHIVO, LÍNEA, PAQUETE)
Rastrea la entrada de cualquier subrutina. Tenga en cuenta que todas las variables se refieren a la subrutina que se está invocando; actualmente no hay forma de obtener información sobre el llamador de la subrutina desde una acción de DTrace. 
:*perl*::sub-entry {
    printf("%s::%s entrado en %s línea %d\n",
          copyinstr(arg3), copyinstr(arg0), copyinstr(arg1), arg2);
}
sub-return(NOMBRE_SUBRUTINA, ARCHIVO, LÍNEA, PAQUETE)
Rastrea la salida de cualquier subrutina. Tenga en cuenta que todas las variables se refieren a la subrutina que está regresando; actualmente no hay forma de obtener información sobre el llamador de la subrutina desde una acción de DTrace. 
:*perl*::sub-return {
    printf("%s::%s regresó en %s línea %d\n",
          copyinstr(arg3), copyinstr(arg0), copyinstr(arg1), arg2);
}
phase-change(NUEVA_FASE, ANTIGUA_FASE)
Rastrea los cambios en el estado del intérprete de Perl. Puede internalizar esto como el rastreo de cambios en la variable de Perl "${^GLOBAL_PHASE}", especialmente dado que los valores para "NUEVA_FASE" y "ANTIGUA_FASE" son las cadenas que informa "${^GLOBAL_PHASE}". 
:*perl*::phase-change {
    printf("Fase cambiada de %s a %s\n",
        copyinstr(arg1), copyinstr(arg0));
}
op-entry(NOMBRE_OPCODE)
Rastrea la ejecución de cada opcode en el bucle de ejecución de Perl. Este punto de sondeo se dispara antes de que se ejecute el opcode. Cuando el depurador de Perl está habilitado, el punto de sondeo de DTrace se dispara después de los ganchos del depurador (pero aún antes de que el opcode en sí se ejecute). 
:*perl*::op-entry {
    printf("A punto de ejecutar el opcode %s\n", copyinstr(arg0));
}
loading-file(NOMBRE_ARCHIVO)
Se dispara cuando Perl está a punto de cargar un archivo individual, ya sea desde "use", "require" o "do". Este punto de sondeo se dispara antes de que el archivo se lea del disco. El argumento del nombre de archivo se convierte a rutas de sistema de archivos locales en lugar de proporcionar nombres al estilo "Nombre::Módulo". 
:*perl*:loading-file {
    printf("A punto de cargar %s\n", copyinstr(arg0));
}
loaded-file(NOMBRE_ARCHIVO)
Se dispara cuando Perl ha cargado exitosamente un archivo individual, ya sea desde "use", "require" o "do". Este punto de sondeo se dispara después de que el archivo se lee del disco y su contenido se evalúa. El argumento del nombre de archivo se convierte a rutas de sistema de archivos locales en lugar de proporcionar nombres al estilo "Nombre::Módulo". 
:*perl*:loaded-file {
    printf("Cargado exitosamente %s\n", copyinstr(arg0));
}

perldtrace(1perl) — Arch Linux man pages

NAME

perldtrace - DTrace probes for Perl

SYNOPSIS

 DTRACE_PROBES=/usr/share/perl/core/DTrace/probes.d

DESCRIPTION

This distribution includes DTrace probes for the Perl interpreter. DTrace is a dynamic tracing framework built into the kernel of Oracle Solaris, Mac OS X and FreeBSD. It allows you to dynamically trace applications, the kernel, and even hardware events in real-time. This distribution provides a set of DTrace probes for the Perl interpreter, so that you can trace Perl programs and the Perl interpreter itself.

The probes are defined in /usr/share/perl/core/DTrace/probes.d. You can use these probes with the DTrace command-line utility to gather information about your Perl programs.

HISTORY

This module was first introduced in Perl 5.14.0.

PROBES

The following probes are available:

perl::sub-entry
Fired when a Perl subroutine is entered.
perl::sub-return
Fired when a Perl subroutine returns.
perl::gv-lookup
Fired when a Perl glob symbol is looked up.
perl::eval-entry
Fired when an eval block is entered.
perl::eval-return
Fired when an eval block returns.
perl::op-entry
Fired when a Perl opcode is executed.
perl::op-return
Fired when a Perl opcode returns.

EXAMPLES

The following DTrace script counts the number of times each Perl subroutine is called:

 #pragma D option quiet

 perl*:::sub-entry
 /arg0/
 {
  self->fqn = copyinstr(arg0);
  @[self->fqn] = count();
 }

The following DTrace script counts the number of times each Perl opcode is executed, but only for subroutines that have a fully qualified name (i.e., they are not in the main package):

 #pragma D option quiet

 perl*:::sub-entry
 {
  self->fqn = strjoin(copyinstr(arg3), strjoin("::", copyinstr(arg0)))
 }

 perl*::op-entry
 /self->fqn != ""/
 {
  @[self->fqn] = count()
 }

 END
 {
  trunc(@, 3)
 }

The output of this script might look like this:

            warnings::unimport                                             4589
            Exporter::Heavy::_rebuild_cache                                5039
            Exporter::import                                              14578
