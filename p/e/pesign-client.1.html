PESIGN-CLIENT(1) Manual de Comandos Generales PESIGN-CLIENT(1)

NOMBRE

pesign-client — herramienta para firmar aplicaciones UEFI con un servidor pesign

SINOPSIS

pesign-client [-i archivo] [-o archivo] [-e archivo] [-t token] [-c apodo] ⟨[-k |] [-q |] [-s |] [-u]⟩ [-f fd] [-F archivo]

DESCRIPCIÓN

pesign-client es una herramienta de línea de comandos para manipular firmas y resúmenes criptográficos de aplicaciones UEFI.

OPCIONES

-i archivo | --infile archivo
El archivo binario de entrada para ser firmado con --sign
-o archivo | --outfile archivo
El archivo binario de salida para ser firmado con --sign
-e archivo | --export archivo
Exportar firma desde --sign a archivo
-t token | --token token
Firmar usando el token NSS token
-c apodo | --certificate apodo
Firmar usando el certificado NSS apodo
-k | --kill
Eliminar el servidor pesign
-q | --is-unlocked
Consultar el estado de bloqueo del token especificado por --token
-s | --sign
Firmar el archivo especificado por --infile
-u | --unlock
Desbloquear el token especificado con --token usando el PIN leído de --pinfd o --pinfile, o especificado por PESIGN_TOKEN_PIN
-f fd | --pinfd fd
Descriptor de archivo del cual leer el PIN para --unlock
-F archivo | --pinfile archivo
Archivo del cual leer el PIN para desbloquear

ENTORNO

PESIGN_TOKEN_PIN
PIN a usar con --unlock para el token especificado por -fl -token

VER TAMBIÉN

pesign(1), certutil(1)
