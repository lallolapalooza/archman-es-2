PERLIRIX(1perl) Guía de referencia del programador de Perl PERLIRIX(1perl)

NOMBRE

perlirix - Versión de Perl 5 en sistemas Irix

DESCRIPCIÓN

Este documento describe varias características de Irix que afectarán a cómo se compila y/o ejecuta Perl versión 5 (en adelante, Perl).

Compilar Perl de 32 bits en Irix

Usa

sh Configure -Dcc='cc -n32'

para compilar Perl de 32 bits. No te molestes con -n32 a menos que tengas compiladores 7.1 o posteriores (usa cc -version para comprobarlo).

(La compilación 'cc -n32' es la predeterminada).

Compilar Perl de 64 bits en Irix

Usa

sh Configure -Dcc='cc -64' -Duse64bitint

Esto requiere una CPU MIPS de 64 bits (R8000, R10000, ...)

También puedes usar

sh Configure -Dcc='cc -64' -Duse64bitall

pero eso no marca ninguna diferencia comparado con -Duse64bitint debido al "cc -64".

También puedes hacer

sh Configure -Dcc='cc -n32' -Duse64bitint

para usar 'long long' para el tipo entero de 64 bits, en caso de que no tengas una CPU de 64 bits.

Si estás usando gcc, simplemente

sh Configure -Dcc=gcc -Duse64bitint

debería ser suficiente, el Configure debería sondear automáticamente para la configuración correcta de 64 bits.

Sobre versiones de compilador de Irix

Se sabe que algunas versiones de cc de Irix, por ejemplo 7.3.1.1m (prueba cc -version), han tenido problemas (core dumps) al compilar perl.c. Si has usado -OPT:fast_io=ON y esto sucede, intenta eliminarlo. Si eso falla, o si no lo usaste, intenta ajustar otras opciones de optimización (-LNO, -INLINE, -O3 a -O2, etc.). El error del compilador ha sido reportado a SGI. (Allen Smith <easmith@beatrice.rutgers.edu>)

Problemas del enlazador en Irix

Si obtienes quejas sobre so_locations, busca en el archivo hints/irix_6.sh las "lddflags" y haz los ajustes sugeridos. (David Billinghurst <David.Billinghurst@riotinto.com.au>)

Malloc en Irix

No intentes usar el malloc de Perl, esto conducirá a errores muy misteriosos (especialmente con -Duse64bitall).

Compilar con hilos en Irix

Ejecuta Configure con -Duseithreads, lo que configurará Perl con los "hilos del intérprete" de Perl 5.8.0, ver threads.

Para Irix 6.2 con hilos de Perl, debes tener instalados los siguientes parches:

1404 Irix 6.2 Posix 1003.1b man pages
1645 Actualizaciones de archivos de cabecera POSIX de Irix 6.2 y 6.3
2000 Módulos de soporte POSIX 1003.1b de Irix 6.2
2254 Correcciones de la biblioteca Pthread
2401 Rollup de kernel para todas las plataformas 6.2

IMPORTANTE: Sin el parche 2401, un error del kernel en Irix 6.2 hará que tu máquina entre en pánico y se bloquee al ejecutar Perl con hilos. Irix 6.3 y posteriores están bien.

Gracias a Hannu Napari <Hannu.Napari@hut.fi> por la información de los parches pthreads de IRIX.

Irix 5.3

Mientras ejecutas Configure y al compilar, es probable que obtengas bastantes de estas advertencias:

ld:
El objeto compartido /usr/lib/libm.so no resolvió ningún símbolo.
      Puede que quieras eliminarlo de tu línea de enlace.

Ignóralas: en IRIX 5.3 no hay forma de silenciar a ld sobre esto.

Durante la compilación verás esta advertencia de toke.c:

uopt: Warning: Perl_yylex: este procedimiento no está optimizado porque
      excede el umbral de tamaño; para optimizar este procedimiento, usa la
      opción -Olimit con un valor >= 4252.

Ignora la advertencia.

En IRIX 5.3 y con Perl 5.8.1 (Perl 5.8.0 no compiló en IRIX 5.3), los siguientes fallos son conocidos.

Failed Test                  Stat Wstat Total Fail  Failed|Failing List
-----------------------------------------------------------------------
../ext/List/Util/t/shuffle.t    0   139    ??   ??       %  ??
../lib/Math/Trig.t            255 65280    29   12  41.38%  24-29
../lib/sort.t                   0   138   119   72  60.50%  48-119
56 tests and 474 subtests skipped.
Failed 3/811 test scripts, 99.63% okay. 78/75813 subtests failed,
   99.90% okay.

Se sospecha que son errores del compilador (al menos el fallo de shuffle.t se conoce en algunas configuraciones de IRIX 6) y errores de la biblioteca matemática (el fallo de Trig.t), pero dado que IRIX 5 ha finalizado su ciclo de vida, es poco probable que haya más correcciones para IRIX. Si puedes conseguir gcc para 5.3, también podrías probar eso, ya que gcc en IRIX 6 es una solución conocida para al menos los fallos de shuffle.t y sort.t.
