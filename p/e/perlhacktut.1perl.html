perlhacktut - Recorrido por la creación de un parche simple en código C

DESCRIPCIÓN

Este documento te guía a través de un ejemplo de parche simple.

Si aún no has leído perlhack, ¡hazlo primero! Es posible que también desees leer perlsource.

Una vez que hayas terminado aquí, consulta perlhacktips a continuación.

EJEMPLO DE UN PARCHE SIMPLE

Vamos a tomar un parche simple de principio a fin.

Aquí hay algo que sugirió Larry: si una "U" es el primer formato activo durante un "pack", (por ejemplo, "pack "U3C8", @stuff") entonces la cadena resultante debe tratarse como codificada en UTF-8.

Si estás trabajando con una copia de git del repositorio de Perl, querrás crear una rama para tus cambios. Esto hará que la creación de un parche adecuado sea mucho más sencilla. Consulta perlgit para obtener detalles sobre cómo hacer esto.

Escribiendo el parche

¿Cómo nos preparamos para arreglar esto? Primero localizamos el código en cuestión: el "pack" ocurre en tiempo de ejecución, por lo que estará en uno de los archivos pp. Efectivamente, "pp_pack" está en pp.c. Como vamos a modificar este archivo, hagamos una copia a pp.c~.

[Bueno, estaba en pp.c cuando se escribió este tutorial. Ahora se ha separado con "pp_unpack" a su propio archivo, pp_pack.c]

Ahora echemos un vistazo a "pp_pack": tomamos un patrón en "pat", y luego recorremos el patrón, tomando cada carácter de formato en su turno en "datum_type". Luego, para cada carácter de formato posible, consumimos los otros argumentos en el patrón (un ancho de campo, un asterisco, etc.) y convertimos el siguiente fragmento de entrada al formato especificado, agregándolo al SV de salida "cat".

¿Cómo sabemos si la "U" es el primer formato en el "pat"? Bueno, si tenemos un puntero al inicio de "pat", entonces, si vemos una "U" podemos probar si todavía estamos al principio de la cadena. Entonces, aquí es donde se configura "pat":

STRLEN fromlen;
char *pat = SvPVx(*++MARK, fromlen);
char *patend = pat + fromlen;
I32 len;
I32 datumtype;
SV *fromstr;

Tendremos otro puntero de cadena allí:

   STRLEN fromlen;
   char *pat = SvPVx(*++MARK, fromlen);
   char *patend = pat + fromlen;
+  char *patcopy;
   I32 len;
   I32 datumtype;
   SV *fromstr;

Y justo antes de comenzar el bucle, configuraremos "patcopy" para que sea el inicio de "pat":

   items = SP - MARK;
   MARK++;
   SvPVCLEAR(cat);
+  patcopy = pat;
   while (pat < patend) {

Ahora, si vemos una "U" que estaba al principio de la cadena, activamos el indicador "UTF8" para el SV de salida, "cat":

+  if (datumtype == 'U' && pat==patcopy+1)
+      SvUTF8_on(cat);
   if (datumtype == '#') {
       while (pat < patend && *pat != '\n')
           pat++;

Recuerda que tiene que ser "patcopy+1" porque el primer carácter de la cadena es la "U" que se ha consumido en "datumtype!"

Oops, olvidamos una cosa: ¿qué pasa si hay espacios al principio del patrón? "pack(" U*", @stuff)" tendrá "U" como el primer carácter activo, aunque no sea lo primero en el patrón. En este caso, tenemos que avanzar "patcopy" junto con "pat" cuando vemos espacios:

if (isSPACE(datumtype))
    continue;

debe convertirse en

if (isSPACE(datumtype)) {
    patcopy++;
    continue;
}

OK. Eso es todo por la parte de C. Ahora debemos hacer dos cosas adicionales antes de que este parche esté listo: hemos cambiado el comportamiento de Perl, y por lo tanto debemos documentar ese cambio. También debemos proporcionar más pruebas de regresión para asegurarnos de que nuestro parche funcione y no cree un error en otro lugar.

Probando el parche

Las pruebas de regresión para cada operador viven en t/op/, así que hacemos una copia de t/op/pack.t a t/op/pack.t~. Ahora podemos agregar nuestras pruebas al final. Primero, probaremos que la "U" realmente crea cadenas Unicode.

t/op/pack.t tiene una función "ok()" sensata, pero si no la tuviera, podríamos usar la de t/test.pl.

require './test.pl';
plan( tests => 159 );

así que en lugar de esto:

print 'not ' unless "1.20.300.4000" eq sprintf "%vd",
                                              pack("U*",1,20,300,4000);
print "ok $test\n"; $test++;

podemos escribir el más sensato (ver Test::More para una explicación completa de "is()" y otras funciones de prueba).

is( "1.20.300.4000", sprintf "%vd", pack("U*",1,20,300,4000),
                                      "U* produce Unicode" );

Ahora probaremos que hicimos bien eso de los espacios al principio:

is( "1.20.300.4000", sprintf "%vd", pack("  U*",1,20,300,4000),
                                    "  con espacios al principio" );

Y finalmente probaremos que no creamos cadenas Unicode si la "U" **no** es el primer formato activo:

isnt( v1.20.300.4000, sprintf "%vd", pack("C0U*",1,20,300,4000),
                                      "U* no es el primero no es Unicode" );

No debemos olvidar cambiar el número de pruebas que aparece en la parte superior, o el probador automático se confundirá. Esto se verá así:

print "1..156\n";

o así:

plan( tests => 156 );

Ahora compilamos Perl y lo ejecutamos a través de la suite de pruebas. ¡Nuestras nuevas pruebas pasan, hurra!

Documentando el parche

Finalmente, la documentación. El trabajo nunca está terminado hasta que se completa el papeleo, así que describamos el cambio que acabamos de hacer. El lugar relevante es pod/perlfunc.pod; nuevamente, hacemos una copia, y luego insertaremos este texto en la descripción de "pack":

=item *
Si el patrón comienza con una C<U>, la cadena resultante se tratará como Unicode codificado en UTF-8. Puedes forzar la codificación UTF-8 en una cadena con una C<U0> inicial, y los bytes que sigan se interpretarán como caracteres Unicode. Si no quieres que esto suceda, puedes comenzar tu patrón con C<C0> (o cualquier otra cosa) para forzar a Perl a no codificar tu cadena en UTF-8, y luego seguir esto con un C<U*> en algún lugar de tu patrón.
