NOMBRE

perl5342delta - qué hay de nuevo en perl v5.34.2

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.34.1 y la versión 5.34.2.

Si estás actualizando desde una versión anterior como la 5.34.0, primero lee perl5341delta, que describe las diferencias entre 5.34.0 y 5.34.1.

Seguridad

Esta versión corrige los siguientes problemas de seguridad.

CVE-2023-47038 - Escritura más allá del final del búfer a través de propiedades Unicode definidas por el usuario no válidas

Esta vulnerabilidad fue informada directamente al equipo de seguridad de Perl por Nathan Mills "the.true.nathan.mills@gmail.com".

Una expresión regular manipulada al ser compilada por perl 5.30.0 hasta 5.38.0 puede causar un desbordamiento de búfer de un byte controlado por el atacante en un búfer asignado en el heap.

CVE-2023-47039 - Vulnerabilidad de secuestro de binarios de Perl para Windows

Esta vulnerabilidad fue informada al Equipo de Respuesta a Incidentes de Seguridad de Productos de Intel (PSIRT) por el usuario de GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT luego la informó al equipo de seguridad de Perl.

Perl para Windows depende de la variable de entorno PATH del sistema para encontrar el shell ("cmd.exe"). Al ejecutar un ejecutable que utiliza el intérprete de Perl de Windows, Perl intenta encontrar y ejecutar "cmd.exe" dentro del sistema operativo. Sin embargo, debido a problemas en el orden de búsqueda de rutas, Perl busca inicialmente cmd.exe en el directorio de trabajo actual.

Un atacante con privilegios limitados puede explotar este comportamiento colocando "cmd.exe" en ubicaciones con permisos débiles, como "C:\ProgramData". Al hacerlo, cuando un administrador intenta usar este ejecutable desde estas ubicaciones comprometidas, se puede ejecutar código arbitrario.

Agradecimientos

Perl 5.34.2 representa aproximadamente 1 mes de desarrollo desde Perl 5.34.1 y contiene aproximadamente 3.700 líneas de cambios en 40 archivos de 4 autores.

Excluyendo archivos generados automáticamente, documentación y herramientas de lanzamiento, hubo aproximadamente 2.800 líneas de cambios en 9 archivos .pm, .t, .c y .h.

Perl continúa floreciendo en su cuarta década gracias a una vibrante comunidad de usuarios y desarrolladores. Las siguientes personas han contribuido con las mejoras que se convirtieron en Perl 5.34.2:

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

Reportar Errores

Si encuentras lo que crees que es un error, puedes consultar la base de datos de errores de perl en https://github.com/Perl/perl5/issues. También puede haber información en http://www.perl.org/, la Página Principal de Perl.

Si crees que tienes un error no reportado, por favor abre un ticket en https://github.com/Perl/perl5/issues. Asegúrate de reducir tu error a un caso de prueba pequeño pero suficiente.

Si el error que reportas tiene implicaciones de seguridad que hacen inapropiado enviarlo a un rastreador de incidencias público, consulta "INFORMACIÓN DE CONTACTO PARA VULNERABILIDADES DE SEGURIDAD" en perlsec para obtener detalles sobre cómo reportar el problema.
