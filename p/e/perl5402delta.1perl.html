NOMBRE

perl5402delta - qué hay de nuevo para perl v5.40.2

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.40.1 y la versión 5.40.2.

Si está actualizando desde una versión anterior como la 5.40.0, primero lea perl5401delta, que describe las diferencias entre 5.40.0 y 5.40.1.

Seguridad

[CVE-2024-56406] Desbordamiento de búfer en montículo con tr//

Se descubrió una vulnerabilidad de desbordamiento de búfer en montículo en Perl.

Cuando hay bytes no ASCII en el lado izquierdo del operador "tr", S_do_trans_invmap() puede desbordar el puntero de destino "d".

$ perl -e '$_ = "\x{FF}" x 1000000; tr/\xFF/\x{100}/;'
Segmentation fault (core dumped)

Se cree que esta vulnerabilidad puede permitir ataques de Denegación de Servicio o Ejecución Arbitraria de Código en plataformas que carecen de defensas suficientes.

Descubierto por: Nathan Mills.

Agradecimientos

Reportar errores

Si encuentra lo que cree que es un error, puede consultar la base de datos de errores de perl en https://github.com/Perl/perl5/issues. También puede haber información en https://www.perl.org/, la página principal de Perl.

Si cree que tiene un error no reportado, por favor abra un problema en https://github.com/Perl/perl5/issues. Asegúrese de reducir su error a un caso de prueba pequeño pero suficiente.

Si el error que está informando tiene implicaciones de seguridad que hacen que no sea apropiado enviarlo a un rastreador de problemas público, consulte "INFORMACIÓN DE CONTACTO DE VULNERABILIDADES DE SEGURIDAD" en perlsec para obtener detalles sobre cómo informar el problema.

Dar gracias

Si desea agradecer a los Perl 5 Porters por el trabajo realizado en Perl 5, puede hacerlo ejecutando el programa "perlthanks":

perlthanks

Esto enviará un correo electrónico a la lista de Perl 5 Porters con su muestra de agradecimiento.
