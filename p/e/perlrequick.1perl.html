NOMBRE

perlrequick - Inicio rápido de expresiones regulares de Perl

DESCRIPCIÓN

Esta página cubre lo más básico para entender, crear y usar expresiones regulares ('regexes') en Perl.

La Guía

Esta página asume que ya sabes cosas, como qué es un "patrón", y la sintaxis básica para usarlos. Si no es así, consulta perlretut.

Coincidencia simple de palabras

La regex más simple es simplemente una palabra, o más generalmente, una cadena de caracteres. Una regex que consiste en una palabra coincide con cualquier cadena que contenga esa palabra:

"Hello World" =~ /World/;  # coincide

En esta declaración, "World" es una regex y las "//" que encierran "/World/" le dicen a Perl que busque una coincidencia en una cadena. El operador "=~" asocia la cadena con la coincidencia de la regex y produce un valor verdadero si la regex coincidió, o falso si no coincidió. En nuestro caso, "World" coincide con la segunda palabra en "Hello World", por lo que la expresión es verdadera. Esta idea tiene varias variaciones.

Expresiones como esta son útiles en condicionales:

print "Coincide\n" if "Hello World" =~ /World/;

El sentido de la coincidencia se puede invertir usando el operador "!~":

print "No coincide\n" if "Hello World" !~ /World/;

La cadena literal en la regex se puede reemplazar por una variable:

$greeting = "World";
print "Coincide\n" if "Hello World" =~ /$greeting/;

Si estás coincidiendo contra $_, la parte "$_ =~" se puede omitir:

$_ = "Hello World";
print "Coincide\n" if /World/;

Finalmente, los delimitadores por defecto "//" para una coincidencia se pueden cambiar a delimitadores arbitrarios anteponiendo una 'm':

"Hello World" =~ m!World!;   # coincide, delimitado por '!'
"Hello World" =~ m{World};   # coincide, nota el emparejamiento '{}'
"/usr/bin/perl" =~ m"/perl"; # coincide después de '/usr/bin',
                             # '/' se convierte en un carácter ordinario

Las regex deben coincidir con una parte de la cadena *exactamente* para que la declaración sea verdadera:

"Hello World" =~ /world/;  # no coincide, sensible a mayúsculas
"Hello World" =~ /o W/;    # coincide, ' ' es un carácter ordinario
"Hello World" =~ /World /; # no coincide, no hay ' ' al final

Perl siempre coincidirá en el punto más temprano posible de la cadena:

"Hello World" =~ /o/;       # coincide con la 'o' en 'Hello'
"That hat is red" =~ /hat/; # coincide con 'hat' en 'That'

No todos los caracteres se pueden usar 'tal cual' en una coincidencia. Algunos caracteres, llamados **metacaracteres**, se consideran especiales y se reservan para su uso en la notación de regex. Los metacaracteres son

{}[]()^$.|*+?\

Un metacaracter se puede coincidir literalmente anteponiendo una barra invertida:

"2+2=4" =~ /2+2/;    # no coincide, + es un metacaracter
"2+2=4" =~ /2\+2/;   # coincide, \+ se trata como un + ordinario
'C:\WIN32' =~ /C:\\WIN/;                       # coincide
"/usr/bin/perl" =~ /\/usr\/bin\/perl/;  # coincide

En la última regex, la barra inclinada '/' también está con barra invertida, porque se usa para delimitar la regex.

La mayoría de los metacaracteres no son siempre especiales, y otros caracteres (como los que delimitan el patrón) se vuelven especiales en diversas circunstancias. Esto puede ser confuso y llevar a resultados inesperados. "use re 'strict'" puede notificarte de posibles dificultades.

Los caracteres ASCII no imprimibles se representan mediante **secuencias de escape**. Ejemplos comunes son "\t" para tabulación, "\n" para nueva línea y "\r" para retorno de carro. Los bytes arbitrarios se representan mediante secuencias de escape octales, por ejemplo, "\033", o secuencias de escape hexagonales, por ejemplo, "\x1B":

"1000\t2000" =~ m(0\t2)  # coincide
"cat" =~ /\143\x61\x74/  # coincide en ASCII, pero
                         # es una forma extraña de escribir cat

Las regex se tratan en su mayor parte como cadenas entrecomilladas, por lo que la sustitución de variables funciona:

$foo = 'house';
'cathouse' =~ /cat$foo/;   # coincide
'housecat' =~ /${foo}cat/; # coincide

Con todas las regex anteriores, si la regex coincidía en algún lugar de la cadena, se consideraba una coincidencia. Para especificar *dónde* debe coincidir, usaríamos los metacaracteres de **anclaje** "^" y "$". El anclaje "^" significa coincidir al principio de la cadena y el anclaje "$" significa coincidir al final de la cadena, o antes de una nueva línea al final de la cadena. Algunos ejemplos:

"housekeeper" =~ /keeper/;         # coincide
"housekeeper" =~ /^keeper/;        # no coincide
"housekeeper" =~ /keeper$/;        # coincide
"housekeeper\n" =~ /keeper$/;      # coincide
"housekeeper" =~ /^housekeeper$/;  # coincide

Usando clases de caracteres

Una **clase de caracteres** permite un conjunto de caracteres posibles, en lugar de solo un carácter, para coincidir en un punto particular de una regex. Hay varios tipos de clases de caracteres, pero generalmente cuando la gente usa este término, se refieren al tipo descrito en esta sección, que son técnicamente llamadas "Clases de caracteres entre corchetes", porque están denotadas por corchetes "[...]", con el conjunto de caracteres a coincidir posiblemente dentro. Pero dejaremos de lado "entre corchetes" a continuación para corresponder con el uso común. Aquí hay algunos ejemplos de clases de caracteres (entre corchetes):

/cat/;            # coincide con 'cat'
/[bcr]at/;        # coincide con 'bat', 'cat' o 'rat'
"abc" =~ /[cab]/; # coincide con 'a'

En la última declaración, aunque 'c' es el primer carácter de la clase, el punto más temprano en el que la regex puede coincidir es 'a'.

/[yY][eE][sS]/; # coincide con 'yes' de forma insensible a mayúsculas
                # 'yes', 'Yes', 'YES', etc.
/yes/i;         # también coincide con 'yes' de forma insensible a mayúsculas

El último ejemplo muestra una coincidencia con un **modificador** 'i', que hace que la coincidencia sea insensible a mayúsculas.

Las clases de caracteres también tienen caracteres ordinarios y especiales, pero los conjuntos de caracteres ordinarios y especiales dentro de una clase de caracteres son diferentes a los de fuera de una clase de caracteres. Los caracteres especiales para una clase de caracteres son "-]\^$" y se coinciden usando un escape:

/[\]c]def/; # coincide con ']def' o 'cdef'
$x = 'bcr';
/[$x]at/;   # coincide con 'bat', 'cat' o 'rat'
/[\$x]at/;  # coincide con '$at' o 'xat'
/[\\$x]at/; # coincide con '\at', 'bat', 'cat' o 'rat'

El carácter especial '-' actúa como un operador de rango dentro de las clases de caracteres, de modo que el poco elegante "[0123456789]" y "[abc...xyz]" se convierten en el esbelto "[0-9]" y "[a-z]":

/item[0-9]/;  # coincide con 'item0' o ... o 'item9'
/[0-9a-fA-F]/;  # coincide con un dígito hexadecimal

Si '-' es el primer o último carácter de una clase de caracteres, se trata como un carácter ordinario.

El carácter especial "^" en la primera posición de una clase de caracteres denota una **clase de caracteres negada**, que coincide con cualquier carácter excepto los de los corchetes. Tanto "[...]" como "[^...]" deben coincidir con un carácter, o la coincidencia falla. Entonces

/[^a]at/;  # no coincide con 'aat' o 'at', pero coincide
           # con todos los demás 'bat', 'cat', '0at', '%at', etc.
/[^0-9]/;  # coincide con un carácter no numérico
/[a^]at/;  # coincide con 'aat' o '^at'; aquí '^' es ordinario

CLASES DE CARACTERES

En la sección anterior, introdujimos la idea de las clases de caracteres "[]", que nos permiten hacer coincidir uno de varios caracteres. Aquí veremos algunas de las clases de caracteres predefinidas en Perl, que están disponibles dentro o fuera de las clases de caracteres. Si no se especifica lo contrario, todos estos son sensibles a las mayúsculas y minúsculas. Por ejemplo, "\d" coincidirá con "1" pero no con "2", mientras que "2" coincidirá con "2" pero no con "1". Sin embargo, si se utiliza el modificador "/u", entonces "\d" también coincidirá con todos los dígitos Unicode de otras escrituras. Por ejemplo, "\d" sin el modificador "/u" coincidirá con los diez dígitos de 0 a 9, y con todos los diez dígitos de cada una de las escrituras árabiga, Devanagari y otros. El modificador "/u" puede usarse solo o en combinación con otros modificadores, por ejemplo, "/gu". Para obtener una lista completa de caracteres que coinciden con las secuencias de escape Unicode, consulta la página de manual de perluni. Si se utiliza el modificador "/a", entonces "\d" coincidirá solo con los diez dígitos ASCII de 0 a 9. Si el modificador "/a" se usa sin el modificador "/u", las secuencias de escape de los caracteres que no son de la tabla ASCII que representan rangos de caracteres se tratarán como si los rangos fueran de caracteres ASCII. Por ejemplo, "\w" sin el modificador "/u" coincide con "[0-9a-zA-Z_]". Con el modificador "/u" se expande para incluir todos los caracteres de "palabra" Unicode. Con el modificador "/a" solo se expande para incluir solo los caracteres de "palabra" ASCII. Si se usan ambos modificadores "/au", entonces "\w" coincide con los caracteres ASCII "[0-9a-zA-Z_]" y el modificador "/u" no tiene ningún efecto.

  • \d es un dígito y representa 
    [0-9]
  • \s es un carácter de espacio en blanco y representa 
    [\ \t\r\n\f]
  • \w es un carácter de palabra (alfanumérico o _) y representa 
    [0-9a-zA-Z_]
  • \D es un \d negado; representa cualquier carácter excepto un dígito 
    [^0-9]
  • \S es un \s negado; representa cualquier carácter que no sea de espacio en blanco 
    [^\s]
  • \W es un \w negado; representa cualquier carácter que no sea de palabra 
    [^\w]
  • El punto '.' coincide con cualquier carácter excepto "\n"

Las abreviaturas "\d\s\w\D\S\W" se pueden usar tanto dentro como fuera de las clases de caracteres. Aquí hay algunas en uso:

/\d\d:\d\d:\d\d/; # coincide con un formato de hora hh:mm:ss
/[\d\s]/;         # coincide con cualquier dígito o carácter de espacio en blanco
/\w\W\w/;         # coincide con un carácter de palabra, seguido de un
                  # carácter que no es de palabra, seguido de un carácter de palabra
/..rt/;           # coincide con cualquier par de caracteres, seguido de 'rt'
/end\./;          # coincide con 'end.'
/end[.]/;         # lo mismo, coincide con 'end.'

El ancla de palabra "\b" coincide con un límite entre un carácter de palabra y un carácter que no es de palabra "\w\W" o "\W\w":

$x = "Housecat catenates house and cat";
$x =~ /\bcat/;  # coincide con 'cat' en 'catenates'
$x =~ /cat\b/;  # coincide con 'cat' en 'housecat'
$x =~ /\bcat\b/;  # coincide con 'cat' al final de la cadena

En el último ejemplo, el final de la cadena se considera un límite de palabra.

Para el procesamiento del lenguaje natural (para que, por ejemplo, los apóstrofes se incluyan en las palabras), usa en su lugar "\b{wb}"

"don't" =~ / .+? \b{wb} /x;  # coincide con toda la cadena

Coincidiendo esto o aquello

Podemos hacer coincidir diferentes cadenas de caracteres con el metacaracter de alternancia '|'. Para hacer coincidir "dog" o "cat", formamos la expresión regular "dog|cat". Como antes, Perl intentará hacer coincidir la expresión regular en el punto más temprano posible de la cadena. En cada posición de carácter, Perl primero intentará hacer coincidir la primera alternativa, "dog". Si "dog" no coincide, Perl intentará la siguiente alternativa, "cat". Si "cat" tampoco coincide, entonces la coincidencia falla y Perl pasa a la siguiente posición en la cadena. Algunos ejemplos:

"cats and dogs" =~ /cat|dog|bird/;  # coincide con "cat"
"cats and dogs" =~ /dog|cat|bird/;  # coincide con "cat"

Incluso aunque "dog" sea la primera alternativa en la segunda expresión regular, "cat" puede coincidir antes en la cadena.

"cats"          =~ /c|ca|cat|cats/; # coincide con "c"
"cats"          =~ /cats|cat|ca|c/; # coincide con "cats"

En una posición de carácter dada, la primera alternativa que permita que la expresión regular coincida será la que coincida. Aquí, todas las alternativas coinciden en la primera posición de la cadena, por lo que la primera coincide.

Agrupando cosas y coincidencia jerárquica

Los metacaracteres de agrupación "()" permiten que una parte de una expresión regular se trate como una unidad única. Las partes de una expresión regular se agrupan encerrándolas entre paréntesis. La expresión regular house(cat|keeper) significa que coincida con "house" seguido de "cat" o "keeper". Algunos ejemplos más son

/(a|b)b/;    # coincide con 'ab' o 'bb'
/(^a|b)c/;   # coincide con 'ac' al inicio de la cadena o 'bc' en cualquier lugar
/house(cat|)/;  # coincide con 'housecat' o 'house'
/house(cat(s|)|)/;  # coincide con 'housecats' o 'housecat' o
                    # 'house'.  Nota que los grupos pueden anidarse.
"20" =~ /(19|20|)\d\d/;  # coincide con la alternativa nula '()\d\d',
                         # porque '20\d\d' no puede coincidir

Extrayendo coincidencias

Los metacaracteres de agrupación "()" también permiten la extracción de las partes de una cadena que coincidieron. Para cada agrupación, la parte que coincidió dentro va a las variables especiales $1, $2, etc. Se pueden usar como variables ordinarias:

# extraer horas, minutos, segundos
$time =~ /(\d\d):(\d\d):(\d\d)/;  # coincide con el formato hh:mm:ss
$hours = $1;
$minutes = $2;
$seconds = $3;

En contexto de lista, una coincidencia "/regex/" con agrupaciones devolverá la lista de valores coincidentes "($1,$2,...)". Así que podríamos reescribirlo como

($hours, $minutes, $second) = ($time =~ /(\d\d):(\d\d):(\d\d)/);

Si las agrupaciones en una expresión regular están anidadas, $1 obtendrá el grupo con el paréntesis de apertura más a la izquierda, $2 el siguiente paréntesis de apertura, etc. Por ejemplo, aquí hay una expresión regular compleja y las variables de coincidencia indicadas debajo de ella:

/(ab(cd|ef)((gi)|j))/;
 1  2      34

Asociadas con las variables de coincidencia $1, $2, ... están las referencias posteriores "\g1", "\g2", ... Las referencias posteriores son variables de coincidencia que se pueden usar *dentro* de una expresión regular:

/(\w\w\w)\s\g1/; # encuentra secuencias como 'the the' en la cadena

$1, $2, ... solo deben usarse fuera de una expresión regular, y "\g1", "\g2", ... solo dentro de una expresión regular.

Coincidiendo repeticiones

Los metacaracteres cuantificadores "?", "*", "+", y "{}" nos permiten determinar el número de repeticiones de una porción de una expresión regular que consideramos una coincidencia. Los cuantificadores se colocan inmediatamente después del carácter, clase de caracteres o agrupación sobre la que queremos especificar. Tienen los siguientes significados:

  • "a?" = coincide con 'a' 1 o 0 veces
  • "a*" = coincide con 'a' 0 o más veces, es decir, cualquier número de veces
  • "a+" = coincide con 'a' 1 o más veces, es decir, al menos una vez
  • "a{n,m}" = coincide al menos "n" veces, pero no más de "m" veces.
  • "a{n,}" = coincide al menos "n" o más veces
  • "a{,n}" = coincide "n" veces o menos (Añadido en la v5.34)
  • "a{n}" = coincide exactamente "n" veces

Aquí hay algunos ejemplos:

/[a-z]+\s+\d*/;  # coincide con una palabra en minúsculas, al menos un espacio, y
                 # cualquier número de dígitos
/(\w+)\s+\g1/;    # coincide con palabras duplicadas de longitud arbitraria
$year =~ /^\d{2,4}$/;  # asegúrate de que el año tenga al menos 2 pero no más
                      # de 4 dígitos
$year =~ /^\d{ 4 }$|^\d{2}$/; # mejor coincidencia; descarta fechas de 3 dígitos

Estos cuantificadores intentarán hacer coincidir la mayor parte posible de la cadena, al tiempo que permiten que la expresión regular coincida. Así que tenemos

$x = 'the cat in the hat';
$x =~ /^(.*)(at)(.*)$/; # coincide,
                        # $1 = 'the cat in the h'
                        # $2 = 'at'
                        # $3 = ''   (0 coincidencias)

El primer cuantificador ".*" toma la mayor parte posible de la cadena mientras permite que la expresión regular coincida. El segundo cuantificador ".*" no tiene cadena restante, por lo que coincide 0 veces.

Más coincidencias

Hay algunas cosas más que quizás quieras saber sobre los operadores de coincidencia. El modificador global "/g" permite que el operador de coincidencia coincida dentro de una cadena tantas veces como sea posible. En contexto escalar, las coincidencias sucesivas contra una cadena harán que "/g" salte de una coincidencia a otra, manteniendo un registro de la posición en la cadena a medida que avanza. Puedes obtener o establecer la posición con la función pos(). Por ejemplo,

$x = "cat dog house"; # 3 palabras
while ($x =~ /(\w+)/g) {
    print "Word is $1, ends at position ", pos $x, "\n";
}

imprime

Word is cat, ends at position 3
Word is dog, ends at position 7
Word is house, ends at position 13

Una coincidencia fallida o un cambio en la cadena objetivo restablecen la posición. Si no quieres que la posición se restablezca después de un fallo de coincidencia, añade "/c", como en "/regex/gc".

En contexto de lista, "/g" devuelve una lista de agrupaciones coincidentes, o si no hay agrupaciones, una lista de coincidencias con la expresión regular completa. Así que

@words = ($x =~ /(\w+)/g);  # coincide,
                            # $word[0] = 'cat'
                            # $word[1] = 'dog'
                            # $word[2] = 'house'
