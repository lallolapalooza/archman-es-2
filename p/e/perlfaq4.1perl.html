Datos: Números

¿Por qué obtengo decimales largos (ej., 19.9499999999999) en lugar de los números que debería obtener (ej., 19.95)?

Para la explicación detallada, consulta el artículo de David Goldberg "What Every Computer Scientist Should Know About Floating-Point Arithmetic" (http://web.cse.msu.edu/~cse320/Documents/FloatingPoint.pdf).

Internamente, tu computadora representa los números de punto flotante en binario. Las computadoras digitales (basadas en potencias de dos) no pueden almacenar todos los números de forma exacta. Algunos números reales pierden precisión en el proceso. Este es un problema de cómo las computadoras almacenan los números y afecta a todos los lenguajes de programación, no solo a Perl.

perlnumber muestra los detalles del formato de las representaciones y conversiones de números.

Para limitar el número de decimales en tus números, puedes usar la función "printf" o "sprintf". Consulta "Floating-point Arithmetic" en perlop para más detalles.

printf "%.2f", 10/3;
my $number = sprintf "%.2f", 10/3;

¿Por qué está roto int()?

Lo más probable es que tu int() funcione correctamente. Son los números los que no son exactamente lo que crees.

Primero, consulta la respuesta a "¿Por qué obtengo decimales largos (ej., 19.9499999999999) en lugar de los números que debería obtener (ej., 19.95)?".

Por ejemplo, esto

print int(0.6/0.2-2), "\n";

en la mayoría de las computadoras imprimirá 0, no 1, porque incluso números tan simples como 0.6 y 0.2 no pueden ser representados exactamente por números de punto flotante. Lo que crees que es 'tres' en el ejemplo anterior es en realidad más parecido a 2.9999999999999995559.

¿Por qué mis datos octales no se interpretan correctamente?

(contribuido por brian d foy)

Probablemente estés intentando convertir una cadena a un número, que Perl solo convierte como un número decimal. Cuando Perl convierte una cadena a un número, ignora los espacios y ceros iniciales, y luego asume que el resto de los dígitos están en base 10:

my $string = '0644';
print $string + 0;  # imprime 644
print $string + 44; # imprime 688, ¡ciertamente no octal!

Este problema generalmente involucra uno de los comandos integrados de Perl que tiene el mismo nombre que un comando de Unix que utiliza números octales como argumentos en la línea de comandos. En este ejemplo, "chmod" en la línea de comandos sabe que su primer argumento es octal porque eso es lo que hace:

%prompt> chmod 644 file

Si quieres usar los mismos dígitos literales (644) en Perl, tienes que decirle a Perl que los trate como números octales, ya sea prefijando los dígitos con un 0 o usando "oct":

chmod(     0644, $filename );  # correcto, tiene cero inicial
chmod( oct(644), $filename );  # también correcto

El problema surge cuando tomas tus números de algo que Perl piensa que es una cadena, como un argumento de línea de comandos en @ARGV:

chmod( $ARGV[0],      $filename );  # incorrecto, incluso si es "0644"
chmod( oct($ARGV[0]), $filename );  # correcto, trata la cadena como octal

Siempre puedes verificar el valor que estás usando imprimiéndolo en notación octal para asegurarte de que coincide con lo que crees que debería ser. Imprímelo en formato octal y decimal:

printf "0%o %d", $number, $number;

¿Tiene Perl una función round()? ¿Qué pasa con ceil() y floor()? ¿Funciones trigonométricas?

Recuerda que int() simplemente trunca hacia 0. Para redondear a un cierto número de decimales, sprintf() o printf() son generalmente la ruta más fácil.

printf("%.3f", 3.1415926535);   # imprime 3.142

El módulo POSIX (parte de la distribución estándar de Perl) implementa ceil(), floor(), y una serie de otras funciones matemáticas y trigonométricas.

use POSIX;
my $ceil   = ceil(3.5);   # 4
my $floor  = floor(3.5);  # 3

En las versiones 5.000 a 5.003 de Perl, la trigonometría se realizaba en el módulo Math::Complex. Con la versión 5.004, el módulo Math::Trig (parte de la distribución estándar de Perl) implementa las funciones trigonométricas. Internamente utiliza el módulo Math::Complex y algunas funciones pueden salirse del eje real hacia el plano complejo, por ejemplo, el seno inverso de 2.

El redondeo en aplicaciones financieras puede tener implicaciones serias, y el método de redondeo utilizado debe especificarse con precisión. En estos casos, probablemente sea mejor no confiar en el sistema de redondeo que esté utilizando Perl, sino implementar tú mismo la función de redondeo que necesitas.

Para ver por qué, nota cómo todavía tendrás un problema con la alternancia en el punto medio:

for (my $i = -5; $i <= 5; $i += 0.5) { printf "%.0f ",$i }

No culpes a Perl. Es lo mismo que en C. IEEE dice que tenemos que hacer esto. Los números de Perl cuyos valores absolutos son enteros menores que 2**31 (en máquinas de 32 bits) funcionarán de manera muy similar a los enteros matemáticos. No se garantizan otros números.

¿Cómo convierto entre representaciones/bases/raíces numéricas?

Como siempre con Perl, hay más de una forma de hacerlo. A continuación se presentan algunos ejemplos de enfoques para realizar conversiones comunes entre representaciones numéricas. Esto pretende ser representativo en lugar de exhaustivo.

Algunos de los ejemplos posteriores en perlfaq4 utilizan el módulo Bit::Vector de CPAN. La razón por la que podrías elegir Bit::Vector sobre las funciones integradas de Perl es que funciona con números de CUALQUIER tamaño, que está optimizado para la velocidad en algunas operaciones y que, para al menos algunos programadores, la notación podría ser familiar.

my $number = 0b10110110;

my $decimal = ord(pack('B8', '10110110'));

my $int = unpack("N", pack("B32",

¿Por qué & no funciona como quiero?

El operador bit a bit "&" de Perl funciona tanto con números como con cadenas, produciendo a veces resultados sorprendentes cuando esperabas un número pero recibiste una cadena. Probablemente esperabas que Perl convirtiera automáticamente los operandos a números como lo harían los operadores matemáticos. En su lugar, Perl trata los operandos de cadena como vectores de bits.

Considera la diferencia bit a bit entre el número 3 y el vector de bits representado por "3". Un número tiene el patrón de bits para su magnitud. El número 3 es 0b11 (un 2 y un 1). El vector de bits tiene el patrón de bits que es el valor ordinal de cada octeto, y ese valor no está relacionado con ningún valor numérico que represente el dígito. El carácter "3" es el vector de bits 0b0011_0011.

Estas operaciones tienen resultados diferentes aunque podrías pensar que parecen el mismo "número":

 11  &  3;   # 0b0000_1011 & 0b0000_0011
             #     -> 0b0000_0011   (número 3)
"11" & "3";  # 0b0011_0001_0011_0001 & 0b0011_0011
             #     -> 0b0011_0001   (carácter ASCII "1")

Ten en cuenta que si algún operando tiene un valor numérico, Perl usa semántica numérica (aunque no deberías contar con esto):

my($i, $j) = ( 11,   3 );   # $i & $j  # 11  &  3 -> 3
my($i, $j) = ("11",  3 );   # $i & $j  # 11  &  3 -> 3
my($i, $j) = ("11", "3");   # $i & $j  # "11"  &  "3" -> 1

Recuerda que un escalar de Perl puede tener valores de cadena y numéricos al mismo tiempo. Un valor que comienza como una cadena y que nunca ha encontrado una operación numérica no tiene valor numérico todavía. Perl hace esto para ahorrar tiempo y trabajo, para no tener que decidir un valor numérico para un escalar que quizás nunca use como número. En ese caso, la semántica de cadena gana. Pero, si ya existe un valor numérico, gana la semántica numérica. Fuerza a Perl a calcular el valor numérico sumando 0:

my($i, $j) = ("11", "3"); $j += 0;  # $i & $j  # "11"  &  3 -> 3

Sin embargo, esto no es una característica documentada, o como dice perlop, "no está bien definido". Una forma de garantizar la semántica numérica es convertir explícitamente ambos valores a números:

(0+$i) & (0+$j)

Para solucionar esta molestia, Perl v5.22 separó el comportamiento de cadenas y números. La característica "bitwise" introdujo cuatro nuevos operadores que funcionarían solo con semántica de cadenas: "&.", "|.", "^." y "~.". Los operadores originales, "&", "|", "^" y "~", aplicarían entonces solo semántica numérica.

Habilita esta característica explícitamente con feature:

use feature qw(bitwise);

O, a partir de la v5.28, requiere la versión mínima de perl con "use":

use v5.28;  # característica bitwise gratis

¿Cómo realizo una operación en una serie de enteros?

Para llamar a una función en cada elemento de un array y recopilar los resultados, usa:

my @results = map { my_func($_) } @array;

Por ejemplo:

my @triple = map { 3 * $_ } @single;

Para llamar a una función en cada elemento de un array, pero ignorar los resultados:

foreach my $iterator (@array) {
    some_func($iterator);
}

Para llamar a una función en cada entero en un rango (pequeño), **puedes** usar:

my @results = map { some_func($_) } (5 .. 25);

pero debes tener en cuenta que en esta forma, el operador ".." crea una lista de todos los enteros en el rango, lo que puede consumir mucha memoria para rangos grandes. Sin embargo, el problema no ocurre cuando se usa ".." dentro de un bucle "for", porque en ese caso el operador de rango se optimiza para *iterar* sobre el rango, sin crear toda la lista. Así que

my @results = ();
for my $i (5 .. 500_005) {
    push(@results, some_func($i));
}

o incluso

push(@results, some_func($_)) for 5 .. 500_005;

no crearán una lista intermedia de 500,000 enteros.

¿Por qué mis números aleatorios no son aleatorios?

Si estás usando una versión de Perl anterior a la 5.004, debes llamar a "srand" una vez al inicio de tu programa para inicializar el generador de números aleatorios.

BEGIN { srand() if $] < 5.004 }

A partir de la 5.004, se llama automáticamente a "srand" al principio. No llames a "srand" más de una vez; harás que tus números sean menos aleatorios, en lugar de más.

Los ordenadores son buenos para ser predecibles y malos para ser aleatorios (a pesar de las apariencias causadas por errores en tus programas :-)). El artículo *random* en la colección "Far More Than You Ever Wanted To Know" en http://www.cpan.org/misc/olddoc/FMTEYEWTK.tgz, cortesía de Tom Phoenix, habla más sobre esto. John von Neumann dijo: "Cualquiera que intente generar números aleatorios por medios deterministas está, por supuesto, viviendo en estado de pecado".

Perl depende del sistema subyacente para la implementación de "rand" y "srand"; en algunos sistemas, los números generados no son lo suficientemente aleatorios (especialmente en Windows: ver http://www.perlmonks.org/?node_id=803632). Varios módulos de CPAN en el espacio de nombres "Math" implementan mejores generadores pseudoaleatorios; ver por ejemplo Math::Random::MT ("Mersenne Twister", rápido). Se describen más algoritmos para números aleatorios en "Numerical Recipes in C" en http://www.nr.com/

Existen varios módulos para muestrear fuentes del sistema de números aleatorios, que son útiles para tokens de seguridad y criptografía. Por ejemplo, Crypt::URandom. Ver la "CPAN Author's Guide to Random Data for Security" en https://security.metacpan.org/docs/guides/random-data-for-security.html

¿Cómo obtengo un número aleatorio entre X e Y?

Para obtener un número aleatorio entre dos valores, puedes usar la función incorporada rand() para obtener un número aleatorio entre 0 y 1. A partir de ahí, lo desplazas al rango que deseas.

rand($x) devuelve un número tal que "0 <= rand($x) < $x". Por lo tanto, lo que necesitas que Perl calcule es un número aleatorio en el rango de 0 a la diferencia entre tu X e Y.

Por ejemplo, para obtener un número aleatorio entre 5 y 10 (inclusive), necesitas un número aleatorio en el rango de 0 a 5, y luego sumarle 5.

my $random_number = int(rand(6)) + 5;

Aquí, rand(6) te da un número entre 0 (inclusive) y 6 (exclusive). int() lo trunca a un entero (0, 1, 2, 3, 4 o 5). Finalmente, sumarle 5 lo desplaza al rango deseado (5, 6, 7, 8, 9 o 10).

Si quieres incluir el límite superior, debes asegurarte de que el rango sea del tamaño correcto, es decir, Y - X + 1.

Entonces, para obtener un número aleatorio entre X e Y (inclusive):

my $random_number = int(rand(Y - X + 1)) + X;

Ten en cuenta que el valor devuelto por rand() es un número de punto flotante. Si necesitas números enteros, debes usar int().

Si necesitas números aleatorios de alta calidad para criptografía o simulaciones, considera usar módulos de CPAN como Math::Random, Math::Random::Secure o Crypt::URandom.

sub random_int_between {

    return $min if $min == $max;

    return $min + int rand(1 + $max - $min);
}

Datos: Fechas

¿Cómo encuentro el día o la semana del año?

El día del año está en la lista devuelta por la función "localtime". Sin argumentos, "localtime" usa la hora actual.

my $day_of_year = (localtime)[7];

El módulo POSIX también puede formatear una fecha como el día del año o la semana del año.

use POSIX qw/strftime/;
my $day_of_year  = strftime "%j", localtime;
my $week_of_year = strftime "%W", localtime;

Para obtener el día del año para cualquier fecha, usa "mktime" de POSIX para obtener una hora en segundos de época para el argumento de "localtime".

use POSIX qw/mktime strftime/;
my $day_of_year = strftime "%j",
    localtime( mktime( 0, 0, 0, 18, 11, 87 ) );

También puedes usar Time::Piece, que viene con Perl y proporciona un "localtime" que devuelve un objeto:

use Time::Piece;
my $day_of_year  = localtime->yday;
my $week_of_year = localtime->week;

El módulo Date::Calc proporciona dos funciones para calcular esto también:

use Date::Calc;
my $day_of_year  = Day_of_Year(  1987, 12, 18 );
my $week_of_year = Week_of_Year( 1987, 12, 18 );

¿Cómo encuentro el siglo o milenio actual?

Usa las siguientes funciones simples:

sub get_century    {
    return int((((localtime(shift || time))[5] + 1999))/100);
}
sub get_millennium {
    return 1+int((((localtime(shift || time))[5] + 1899))/1000);
}

En algunos sistemas, la función strftime() del módulo POSIX se ha extendido de forma no estándar para usar un formato %C, que a veces reclaman que es el "siglo". No lo es, porque en la mayoría de estos sistemas, son solo los dos primeros dígitos del año de cuatro dígitos, y por lo tanto no se puede usar para determinar de forma fiable el siglo o milenio actual.

¿Cómo puedo comparar dos fechas y encontrar la diferencia?

(contribuido por brian d foy)

Podrías simplemente almacenar todas tus fechas como un número y luego restar. Sin embargo, la vida no siempre es tan simple.

El módulo Time::Piece, que viene con Perl, reemplaza "localtime" con una versión que devuelve un objeto. También sobrecarga los operadores de comparación para que puedas compararlos directamente:

use Time::Piece;
my $date1 = localtime( $some_time );
my $date2 = localtime( $some_other_time );
if( $date1 < $date2 ) {
    print "La fecha fue en el pasado\n";
}

También puedes obtener diferencias con una resta, que devuelve un objeto Time::Seconds:

my $date_diff = $date1 - $date2;
print "La diferencia es ", $date_diff->days, " días\n";

Si quieres trabajar con fechas formateadas, los módulos Date::Manip, Date::Calc o DateTime pueden ayudarte.

¿Cómo puedo tomar una cadena y convertirla en segundos de época?

Si es una cadena lo suficientemente regular como para que siempre tenga el mismo formato, puedes dividirla y pasar las partes a "timelocal" en el módulo estándar Time::Local. De lo contrario, deberías buscar los módulos Date::Calc, Date::Parse y Date::Manip de CPAN.

(contribuido por brian d foy y Dave Cross)

$ perl -MTime::Piece -le 'print localtime->yday'

¿Cómo encuentro la fecha de ayer?

(contribuido por brian d foy)

Para hacerlo correctamente, puedes usar uno de los módulos de "Date" ya que trabajan con calendarios en lugar de horas. El módulo DateTime lo hace simple, y te da la misma hora del día, solo que el día anterior, a pesar de los cambios de horario de verano:

use DateTime;
my $yesterday = DateTime->now->subtract( days => 1 );
print "Ayer fue $yesterday\n";

También puedes usar el módulo Date::Calc usando su función "Today_and_Now".

use Date::Calc qw( Today_and_Now Add_Delta_DHMS );
my @date_time = Add_Delta_DHMS( Today_and_Now(), -1, 0, 0, 0 );
print "@date_time\n";

La mayoría de la gente intenta usar la hora en lugar del calendario para calcular fechas, pero eso asume que los días son de veinticuatro horas. Para la mayoría de la gente, hay dos días al año en los que no lo son: el cambio de y hacia el horario de verano lo desajusta. Por ejemplo, el resto de las sugerencias serán incorrectas a veces:

A partir de Perl 5.10, Time::Piece y Time::Seconds forman parte de la distribución estándar, así que podrías pensar que podrías hacer algo como esto:

use Time::Piece;
use Time::Seconds;
my $yesterday = localtime() - ONE_DAY; # INCORRECTO
print "Ayer fue $yesterday\n";

El módulo Time::Piece exporta un nuevo "localtime" que devuelve un objeto, y Time::Seconds exporta la constante "ONE_DAY" que es un número fijo de segundos. Esto significa que siempre da la hora de hace 24 horas, lo que no siempre es ayer. Esto puede causar problemas alrededor del fin del horario de verano, cuando hay un día que dura 25 horas.

Tienes el mismo problema con Time::Local, que dará la respuesta incorrecta para esos mismos casos especiales:

# contribuido por Gunnar Hjalmarsson
 use Time::Local;
 my $today = timelocal 0, 0, 12, ( localtime )[3..5];
 my ($d, $m, $y) = ( localtime $today-86400 )[3..5]; # INCORRECTO
 printf "Ayer: %d-%02d-%02d\n", $y+1900, $m+1, $d;

¿Tiene Perl un problema del Año 2000 o 2038? ¿Es Perl compatible con Y2K?

(contribuido por brian d foy)

Perl en sí nunca tuvo un problema Y2K, aunque eso nunca impidió que la gente creara problemas Y2K por sí mismos. Consulta la documentación de "localtime" para su uso correcto.

A partir de Perl 5.12, "localtime" y "gmtime" pueden manejar fechas posteriores a las 03:14:08 del 19 de enero de 2038, cuando un tiempo basado en 32 bits se desbordaría. Aún podrías obtener una advertencia en un "perl" de 32 bits:

% perl5.12 -E 'say scalar localtime( 0x9FFF_FFFFFFFF )'
Integer overflow in hexadecimal number at -e line 1.
Wed Nov  1 19:42:39 5576711

En un "perl" de 64 bits, puedes obtener fechas aún mayores para esos proyectos de larga duración:

% perl5.12 -E 'say scalar gmtime( 0x9FFF_FFFFFFFF )'
Thu Nov  2 00:42:39 5576711

Aún así, no tienes suerte si necesitas seguir la pista de los protones en descomposición.

¿Cómo elimino caracteres duplicados?

contribuido por brian d foy)

Puede utilizar el operador de sustitución para encontrar pares de caracteres (o secuencias de caracteres) y reemplazarlos con una sola instancia. En esta sustitución, encontramos un carácter en "(.)". Los paréntesis de memoria almacenan el carácter coincidente en la referencia posterior y lo usamos para exigir que la misma cosa lo siga inmediatamente. Reemplazamos esa parte de la cadena con el carácter en $1.

s/(.)\g1/$1/g;

También podemos usar el operador de transliteración, "tr///". En este ejemplo, la lista de búsqueda de nuestro "tr///" no contiene nada, pero la opción "c" la complementa para que contenga todo. La lista de reemplazo tampoco contiene nada, por lo que la transliteración es casi una operación nula, ya que no realizará ningún reemplazo (o, más exactamente, reemplazará el carácter por sí mismo). Sin embargo, la opción "s" aplasta los caracteres duplicados y consecutivos en la cadena, de modo que un carácter no aparece junto a sí mismo.

my $str = 'Haarlem';   # en los Países Bajos
$str =~ tr///cs;       # Ahora Harlem, como en Nueva York

¿Cómo expando llamadas a funciones en una cadena?

(contribuido por brian d foy)

Esto está documentado en perlref, y aunque no es lo más fácil de leer, funciona. En cada uno de estos ejemplos, llamamos a la función dentro de las llaves que se utilizan para desreferenciar una referencia. Si tenemos más de un valor de retorno, podemos construir y desreferenciar una matriz anónima. En este caso, llamamos a la función en contexto de lista.

print ""Los valores de tiempo son @{ [localtime] }.\n";

Si queremos llamar a la función en contexto escalar, tenemos que hacer un poco más de trabajo. Realmente podemos tener cualquier código que queramos dentro de las llaves, así que simplemente tenemos que terminar con la referencia escalar, aunque cómo lo haga depende de usted, y puede usar código dentro de las llaves. Tenga en cuenta que el uso de paréntesis crea un contexto de lista, por lo que necesitamos "scalar" para forzar el contexto escalar en la función:

print ""La hora es ${\(scalar localtime)}.\n"
print "La hora es ${ my $x = localtime; \$x }.\n";

Si su función ya devuelve una referencia, no necesita crear la referencia usted mismo.

sub timestamp { my $t = localtime; \$t }
print "La hora es ${ timestamp() }.\n";

El módulo "Interpolation" también puede hacer mucha magia por usted. Puede especificar un nombre de variable, en este caso "E", para configurar un hash enlazado que realice la interpolación por usted. Tiene varios otros métodos para hacer esto también.

use Interpolation E => 'eval';
print "Los valores de tiempo son $E{localtime()}.\n";

En la mayoría de los casos, probablemente sea más fácil simplemente usar la concatenación de cadenas, que también fuerza el contexto escalar.

print ""La hora es " . localtime() . ".\n";

¿Cómo encuentro cualquier cosa coincidente/anidada?

Para encontrar algo entre dos caracteres individuales, un patrón como "/x([^x]*)x/" obtendrá las partes intermedias en $1. Para múltiples, entonces se necesitaría algo más como "/alpha(.*?)omega/". Para patrones anidados y/o expresiones equilibradas, consulte la llamada construcción (?PARNO) (disponible desde perl 5.10). El módulo CPAN Regexp::Common puede ayudar a construir tales expresiones regulares (consulte en particular Regexp::Common::balanced y Regexp::Common::delimited).

Casos más complejos requerirán escribir un analizador, probablemente usando un módulo de análisis de CPAN, como Regexp::Grammars, Parse::RecDescent, Parse::Yapp, Text::Balanced o Marpa::R2.

¿Cómo accedo o cambio N caracteres de una cadena?

Puede acceder a los primeros caracteres de una cadena con substr(). Para obtener el primer carácter, por ejemplo, comience en la posición 0 y tome la cadena de longitud 1.

my $string = "Just another Perl Hacker";
my $first_char = substr( $string, 0, 1 );  #  'J'

Para cambiar parte de una cadena, puede usar el cuarto argumento opcional, que es la cadena de reemplazo.

substr( $string, 13, 4, "Perl 5.8.0" );

También puede usar substr() como Lvalue.

substr( $string, 13, 4 ) =  "Perl 5.8.0";

¿Cómo cambio la N-ésima ocurrencia de algo?

Tiene que hacer un seguimiento de N usted mismo. Por ejemplo, digamos que quiere cambiar la quinta ocurrencia de "whoever" o "whomever" a "whosoever" o "whomsoever", sin distinción de mayúsculas y minúsculas. Todas estas asumen que $_ contiene la cadena a modificar.

$count = 0;
s{((whom?)ever)}{
++$count == 5       # ¿es la 5ª?
    ? "${2}soever"  # sí, intercambiar
    : $1            # retractarse y dejarlo ahí
    }ige;

En el caso más general, puede usar el modificador "/g" en un bucle "while", llevando la cuenta de las coincidencias.

$WANT = 3;
$count = 0;
$_ = "One fish two fish red fish blue fish";
while (/(\w+)\s+fish\b/gi) {
    if (++$count == $WANT) {
        print "The third fish is a $1 one.\n";
    }
}

Esto imprime: "The third fish is a red one.". También puede usar un recuento de repetición y un patrón repetido como este:

/(?:\w+\s+fish\s+){2}(\w+)\s+fish/i;

¿Cómo puedo contar el número de ocurrencias de una subcadena dentro de una cadena?

Hay varias formas, con diferente eficiencia. Si desea contar un solo carácter (X) dentro de una cadena, puede usar la función "tr///" de la siguiente manera:

my $string = "ThisXlineXhasXsomeXx'sXinXit";
my $count = ($string =~ tr/X//);
print "There are $count X characters in the string";

Esto está bien si solo está buscando un solo carácter. Sin embargo, si está intentando contar subcadenas de varios caracteres dentro de una cadena más grande, "tr///" no funcionará. Lo que puede hacer es envolver un bucle while() alrededor de una coincidencia de patrón global. Por ejemplo, contemos enteros negativos:

my $string = "-9 55 48 -2 23 -76 4 14 -44";
my $count = 0;
while ($string =~ /-\d+/g) { $count++ }
print "There are $count negative numbers in the string";

Otra versión usa una coincidencia global en contexto de lista, luego asigna el resultado a un escalar, produciendo un recuento del número de coincidencias.

my $count = () = $string =~ /-\d+/g;

¿Cómo capitalizo todas las palabras de una línea?

(contribuido por brian d foy)

Text::Autoformat de Damian Conway maneja todo el pensamiento por usted:

use Text::Autoformat;
my $s = "Going to the desert with a camel";
printf "%-10s %s\n", "original:", $s;
for my $style (qw( sentence title highlight )) {
    printf "%-10s %s\n",
        "$style:",
        autoformat($s, { case => $style }) =~ s/\R+\z//r;
}

Cada estilo tiene una idea diferente de lo que debería hacer con las palabras pequeñas:

original:  Going to the desert with a camel
sentence:  Going to the desert with a camel
title:     Going To The Desert With A Camel
highlight: Going to the Desert with a Camel

Intentar esto usted mismo en una expresión regular simple tiene más de un par de trampas. Las "palabras" de Perl son grupos de "\w+", pero eso no es lo que quieres capitalizar. Algunos de esos caracteres ni siquiera son letras. ¿Qué pasa si usaste un límite de palabra, "\b"?

my $string = "A camel's journey";
$string =~ s/\b(\w)/\U$1/g;  # A Camel'S Journey

¿Cómo se supone que Perl sepa no capitalizar esa "s"? Podrías esforzarte más para buscar un espacio en blanco precedente o el inicio de la cadena:

$string =~ s/( (?:^|\s) \w ) /\U$1/xg; # A Camel's Journey

O tal vez coincidas con todo el grupo, lo pongas todo en minúsculas ("L"), y luego pongas en mayúscula la primera letra ("\u"):

$string =~ s/([\w']+)/\u\L$1/g;

Cada uno de estos tiene sus casos extremos molestos. Perl v5.22 agregó palabras Unicode más sofisticadas y sen

límites de palabras para solucionar este tipo de problemas. El límite de palabra "\b{wb}" ignora algunas cosas que no considera palabras "humanas" que comiencen o terminen:

use v5.22;
my $string = "A camel's journey";
$string =~ s/\b{wb}(\w)/\U$1/g;  # A Camel's Journey

Los detalles se encuentran en el Informe Técnico Unicode #29 (https://unicode.org/reports/tr29/), y deberías asegurarte de que su idea de un límite de palabra se corresponda con la tuya.

¿Cómo puedo dividir una cadena delimitada por [caracter] excepto cuando estoy dentro de [caracter]?

Varios módulos pueden manejar este tipo de análisis: Text::Balanced, Text::CSV, Text::CSV_XS y Text::ParseWords, entre otros.

Tomemos el caso de ejemplo de intentar dividir una cadena separada por comas en sus diferentes campos. No puedes usar "split(/,/)" porque no debes dividir si la coma está dentro de comillas. Por ejemplo, toma una línea de datos como esta:

SAR001,"","Cimetrix, Inc","Bob Smith","CAM",N,8,1,0,7,"Error, Core Dumped"

Debido a la restricción de las comillas, este es un problema bastante complejo. Afortunadamente, tenemos a Jeffrey Friedl, autor de Mastering Regular Expressions, para que se encargue de esto por nosotros. Él sugiere (asumiendo que tu cadena está contenida en $text):

my @new = ();
push(@new, $+) while $text =~ m{
    "([^\"\\]*(?:\\.[^\"\\]*)*)",? # agrupa la frase dentro de las comillas
   | ([^,]+),?
   | ,
}gx;
push(@new, undef) if substr($text,-1,1) eq ',';

Si quieres representar comillas dentro de un campo delimitado por comillas, escápalas con barras invertidas (por ejemplo, "like \"this\"".

Alternativamente, el módulo Text::ParseWords (parte de la distribución estándar de Perl) te permite decir:

use Text::ParseWords;
@new = quotewords(",", 0, $text);

Sin embargo, para analizar o generar CSV, se recomienda encarecidamente usar Text::CSV en lugar de implementarlo tú mismo; te ahorrarás errores extraños que surjan más adelante al simplemente usar código que ya ha sido probado y verificado en producción durante años.

¿Cómo elimino espacios en blanco del principio/final de una cadena?

(aportado por brian d foy)

Una sustitución puede hacer esto por ti. Para una sola línea, quieres reemplazar todos los espacios en blanco iniciales o finales con nada. Puedes hacerlo con un par de sustituciones:

s/^\s+//;
s/\s+$//;

También puedes escribirlo como una sola sustitución, aunque resulta que la instrucción combinada es más lenta que las separadas. Eso podría no importarte, sin embargo:

s/^\s+|\s+$//g;

En esta expresión regular, la alternancia coincide al principio o al final de la cadena, ya que las anclas tienen una precedencia menor que la alternancia. Con el indicador "/g", la sustitución realiza todas las coincidencias posibles, por lo que obtiene ambas. Recuerda, el salto de línea final coincide con "\s+", y la ancla "$" puede coincidir con el final absoluto de la cadena, por lo que el salto de línea también desaparece. Simplemente agrega el salto de línea a la salida, lo que tiene el beneficio adicional de preservar las líneas "en blanco" (que consisten enteramente en espacios en blanco) que el "^\s+" eliminaría por sí solo:

while( <> ) {
    s/^\s+|\s+$//g;
    print "$_\n";
}

Para una cadena multilínea, puedes aplicar la expresión regular a cada línea lógica de la cadena agregando el indicador "/m" (de "multilínea"). Con el indicador "/m", "$" coincide *antes* de un salto de línea incrustado, por lo que no lo elimina. Este patrón aún elimina el salto de línea al final de la cadena:

$string =~ s/^\s+|\s+$//gm;

Recuerda que las líneas que consisten enteramente en espacios en blanco desaparecerán, ya que la primera parte de la alternancia puede coincidir con toda la cadena y reemplazarla con nada. Si necesitas mantener las líneas en blanco incrustadas, tienes que hacer un poco más de trabajo. En lugar de coincidir con cualquier espacio en blanco (ya que eso incluye un salto de línea), simplemente coincide con el otro espacio en blanco:

$string =~ s/^[\t\f ]+|[\t\f ]+$//mg;

¿Cómo relleno una cadena con espacios o un número con ceros?

En los siguientes ejemplos, $pad_len es la longitud a la que deseas rellenar la cadena, $text o $num contiene la cadena a rellenar y $pad_char contiene el carácter de relleno. Puedes usar una constante de cadena de un solo carácter en lugar de la variable $pad_char si sabes cuál es de antemano. Y de la misma manera, puedes usar un entero en lugar de $pad_len si conoces la longitud de relleno de antemano.

El método más simple utiliza la función "sprintf". Puede rellenar a la izquierda o a la derecha con espacios y a la izquierda con ceros, y no truncará el resultado. La función "pack" solo puede rellenar cadenas a la derecha con espacios y truncará el resultado a una longitud máxima de $pad_len.

# Relleno a la izquierda de una cadena con espacios (sin truncamiento):
my $padded = sprintf("%${pad_len}s", $text);
my $padded = sprintf("%*s", $pad_len, $text);  # lo mismo
# Relleno a la derecha de una cadena con espacios (sin truncamiento):
my $padded = sprintf("%-${pad_len}s", $text);
my $padded = sprintf("%-*s", $pad_len, $text); # lo mismo
# Relleno a la izquierda de un número con 0 (sin truncamiento):
my $padded = sprintf("%0${pad_len}d", $num);
my $padded = sprintf("%0*d", $pad_len, $num); # lo mismo
# Relleno a la derecha de una cadena con espacios usando pack (truncará):
my $padded = pack("A$pad_len",$text);

Si necesitas rellenar con un carácter que no sea un espacio en blanco o cero, puedes usar uno de los siguientes métodos. Todos generan una cadena de relleno con el operador "x" y la combinan con $text. Estos métodos no truncan $text.

Relleno a la izquierda y derecha con cualquier carácter, creando una nueva cadena:

my $padded = $pad_char x ( $pad_len - length( $text ) ) . $text;
my $padded = $text . $pad_char x ( $pad_len - length( $text ) );

Relleno a la izquierda y derecha con cualquier carácter, modificando $text directamente:

substr( $text, 0, 0 ) = $pad_char x ( $pad_len - length( $text ) );
$text .= $pad_char x ( $pad_len - length( $text ) );

¿Cómo extraigo columnas seleccionadas de una cadena?

(aportado por brian d foy)

Si conoces las columnas que contienen los datos, puedes usar "substr" para extraer una sola columna.

my $column = substr( $line, $start_column, $length );

Puedes usar "split" si las columnas están separadas por espacios en blanco o algún otro delimitador, siempre y cuando los espacios en blanco o el delimitador no puedan aparecer como parte de los datos.

my $line    = ' fred barney   betty   ';
my @columns = split /\s+/, $line;
    # ( '', 'fred', 'barney', 'betty' );
my $line    = 'fred||barney||betty';
my @columns = split /\|/, $line;
    # ( 'fred', '', 'barney', '', 'betty' );

Si quieres trabajar con valores separados por comas, no hagas esto, ya que ese formato es un poco más complicado. Usa uno de los módulos que manejan ese formato, como Text::CSV, Text::CSV_XS o Text::CSV_PP.

Si quieres desglosar una línea completa de columnas fijas, puedes usar "unpack" con el formato A (ASCII). Al usar un número después del especificador de formato, puedes indicar el ancho de la columna. Consulta las entradas de "pack" y "unpack" en perlfunc para más detalles.

my @fields = unpack( "A8 A8 A8 A16 A4", $line );

Ten en cuenta que los espacios en el argumento del formato para "unpack" no denotan espacios literales. Si tienes datos separados por espacios, es posible que prefieras "split".

¿Cómo puedo expandir variables en cadenas de texto?

(aportado por brian d foy)

Si puedes evitarlo, no lo hagas, o si puedes usar un sistema de plantillas, como Text::Template o Template Toolkit, haz eso en su lugar. Incluso podrías lograr el trabajo con "sprintf" o "printf":

my $string = sprintf 'Say hello to %s and %s', $foo, $bar;

Sin embargo, para el caso simple y único en el que no quiero usar un sistema de plantillas completo, usaré una cadena que tiene dos variables escalares de Perl. En este ejemplo, quiero expandir $foo y $bar a sus valores de variable:

my $foo = 'Fred';
my $bar = 'Barney';
$string = 'Say hello to $foo and $bar';

Una forma en que puedo hacer esto implica el operador de sustitución y un doble indicador "/e". El primer "/e" evalúa $1 en el lado de reemplazo y lo convierte en $foo. El segundo /e comienza con $foo y lo reemplaza con su valor. $foo, entonces, se convierte en 'Fred', y eso es finalmente lo que queda en la cadena:

$string =~ s/(\$\w+)/$1/eeg; # 'Say hello to Fred and Barney'

El "/e" también ignorará silenciosamente las violaciones de strict, reemplazando los nombres de variables indefinidos por la cadena vacía. Dado que estoy usando el flag "/e" (¡incluso dos veces!), tengo todos los mismos problemas de seguridad que tengo con "eval" en su forma de cadena. Si hay algo extraño en $foo, quizás algo como "@{[ system "rm -rf /" ]}", entonces podría meterme en problemas.

Para solucionar el problema de seguridad, también podría extraer los valores de un hash en lugar de evaluar nombres de variables. Usando un solo "/e", puedo verificar el hash para asegurarme de que el valor exista, y si no es así, puedo reemplazar el valor faltante con un marcador, en este caso "???" para indicar que me perdí algo:

my $string = 'This has $foo and $bar';
my %Replacements = (
    foo  => 'Fred',
    );
# $string =~ s/\$(\w+)/$Replacements{$1}/g;
$string =~ s/\$(\w+)/
    exists $Replacements{$1} ? $Replacements{$1} : '???'
    /eg;
print $string;

¿Perl tiene algo como el #{ de Ruby o la cadena f de Python?

A diferencia de los demás, Perl te permite incrustar una variable desnuda en una cadena con comillas dobles, por ejemplo, "variable $variable". Cuando no hay espacios en blanco u otros caracteres no alfanuméricos después del nombre de la variable, puedes agregar llaves (por ejemplo, "foo ${foo}bar") para asegurar un análisis correcto.

También se puede incrustar un array directamente en una cadena, y se expandirá por defecto con espacios entre los elementos. El LIST_SEPARATOR predeterminado se puede cambiar asignando una cadena diferente a la variable especial $", como "local $" = ', ';".

Perl también admite referencias dentro de una cadena, proporcionando el equivalente a las características de los otros dos lenguajes.

"${\ ... }" incrustado dentro de una cadena funcionará para la mayoría de las sentencias simples, como una llamada a objeto->método. Se pueden envolver códigos más complejos en un bloque `do` "${\ do{...} }".

Cuando quieres que una lista se expanda por $", usa "@{[ ... ]}".

use Time::Piece;
use Time::Seconds;
my $scalar = 'STRING';
my @array = ( 'zorro', 'a', 1, 'B', 3 );
# Imprime la fecha y hora actual y luego el mañana
my $t = Time::Piece->new;
say "Now is: ${\ $t->cdate() }";
say "Tomorrow: ${\ do{ my $T=Time::Piece->new + ONE_DAY ; $T->fullday }}";
# algunas variables en cadenas
say "This is some scalar I have $scalar, this is an array @array.";
say "You can also write it like this ${scalar} @{array}.";
# Cambia el $LIST_SEPARATOR
local $" = ':';
say "Set \$\" to delimit with ':' and sort the Array @{[ sort @array ]}";

También puede que quieras mirar el módulo Quote::Code, y herramientas de plantillas como Template::Toolkit y Mojo::Template.

Ver también: "¿Cómo puedo expandir variables en cadenas de texto?" y "¿Cómo expando llamadas a funciones en una cadena?" en esta FAQ.

¿Qué está mal con citar siempre "$vars"?

El problema es que esas comillas dobles fuerzan la conversión a cadena (stringification), coaccionando números y referencias a cadenas, incluso cuando no quieres que sean cadenas. Piénsalo de esta manera: la expansión de comillas dobles se usa para producir nuevas cadenas. Si ya tienes una cadena, ¿por qué necesitas más?

Si te acostumbras a escribir cosas extrañas como estas:

print "$var";       # MAL
my $new = "$old";       # MAL
somefunc("$var");    # MAL

Estarás en problemas. Esos deberían ser (en el 99.8% de los casos) los más simples y directos:

print $var;
my $new = $old;
somefunc($var);

De lo contrario, además de ralentizarte, romperás código cuando lo que está en el escalar no es ni una cadena ni un número, sino una referencia:

func(\@array);
sub func {
    my $aref = shift;
    my $oref = "$aref";  # MAL
}

También puedes tener problemas sutiles en esas pocas operaciones en Perl que realmente se preocupan por la diferencia entre una cadena y un número, como el operador mágico de autoincremento "++" o la función syscall().

La conversión a cadena también destruye arrays.

my @lines = `command`;
print "@lines";     # MAL - espacios extra
print @lines;       # bien

¿Por qué no funcionan mis documentos <

Los documentos here se encuentran en perlop. Comprueba estas tres cosas:

No debe haber espacio después de la parte <<.
Probablemente debería haber un punto y coma al final del token de apertura
No puedes (fácilmente) tener espacio delante de la etiqueta.
Debe haber al menos un separador de línea después del token final.

Si quieres indentar el texto en el documento here, puedes hacer esto:

# todo en uno
(my $VAR = <<HERE_TARGET) =~ s/^\s+//gm;
    your text
    goes here
HERE_TARGET

Pero el HERE_TARGET aún debe estar pegado al margen. Si también quieres indentar eso, tendrás que citar la indentación.

(my $quote = <<'    FINIS') =~ s/^\s+//gm;
        ...we will have peace, when you and all your works have
        perished--and the works of your dark master to whom you
        would deliver us. You are a liar, Saruman, and a corrupter
        of men's hearts. --Theoden in /usr/src/perl/taint.c
    FINIS
$quote =~ s/\s+--/\n--/;

Una función general y útil para documentos here indentados es la siguiente. Espera ser llamada con un documento here como argumento. Observa si cada línea comienza con una subcadena común y, si es así, elimina esa subcadena. De lo contrario, toma la cantidad de espacio en blanco inicial encontrado en la primera línea y elimina esa cantidad de cada línea subsiguiente.

sub fix {
    local $_ = shift;
    my ($white, $leader);  # espacio en blanco común y cadena inicial común
    if (/^\s*(?:([^\w\s]+)(\s*).*\n)(?:\s*\g1\g2?.*\n)+$/) {
        ($white, $leader) = ($2, quotemeta($1));
    } else {
        ($white, $leader) = (/^(\s+)/, '');
    }
    s/^\s*?$leader(?:$white)?//gm;
    return $_;
}

Esto funciona con cadenas especiales iniciales, determinadas dinámicamente:

my $remember_the_main = fix<<'    MAIN_INTERPRETER_LOOP';
@@@ int
@@@ runops() {
@@@     SAVEI32(runlevel);
@@@     runlevel++;

@@@     TAINT_NOT;
@@@     return 0;
@@@ }
MAIN_INTERPRETER_LOOP

O con una cantidad fija de espacio en blanco inicial, con la indentación restante correctamente preservada:

my $poem = fix<<EVER_ON_AND_ON;
   Now far ahead the Road has gone,
  And I must follow, if I can,
   Pursuing it with eager feet,
  Until it joins some larger way
   Where many paths and errands meet.
  And whither then? I cannot say.

¿Cuál es la diferencia entre una lista y un array?

(contribuido por brian d foy)

Una lista es una colección fija de escalares. Un array es una variable que contiene una colección variable de escalares. Un array puede suministrar su colección para operaciones de lista, por lo que las operaciones de lista también funcionan en arrays:

# slices
( 'dog', 'cat', 'bird' )[2,3];
@animals[2,3];
# iteración
foreach ( qw( dog cat bird ) ) { ... }
foreach ( @animals ) { ... }
my @three = grep { length == 3 } qw( dog cat bird );
my @three = grep { length == 3 } @animals;
# suministrar una lista de argumentos
wash_animals( qw( dog cat bird ) );
wash_animals( @animals );

Las operaciones de array, que cambian los escalares, los reorganizan, o añaden o restan algunos escalares, solo funcionan en arrays. Estas no pueden funcionar en una lista, que es fija. Las operaciones de array incluyen "shift", "unshift", "push", "pop" y "splice".

Un array también puede cambiar su longitud:

$#animals = 1;  # truncar a dos elementos
$#animals = 10000; # pre-extender a 10,001 elementos

Puedes cambiar un elemento de array, pero no puedes cambiar un elemento de lista:

$animals[0] = 'Rottweiler';
qw( dog cat bird )[0] = 'Rottweiler'; # ¡error de sintaxis!
foreach ( @animals ) {
    s/^d/fr/;  # funciona bien
}
foreach ( qw( dog cat bird ) ) {
    s/^d/fr/;  # ¡Error! Modificación de valor de solo lectura!
}

Sin embargo, si el elemento de lista es en sí mismo una variable, parece que puedes cambiar un elemento de lista. Sin embargo, el elemento de lista es la variable, no los datos. No estás cambiando el elemento de lista, sino algo a lo que el elemento de lista se refiere. El elemento de lista en sí mismo no cambia: sigue siendo la misma variable.

También tienes que tener cuidado con el contexto. Puedes asignar un array a un escalar para obtener el número de elementos en el array. Esto solo funciona para arrays, sin embargo:

my $count = @animals;  # solo funciona con arrays

Si intentas hacer lo mismo con lo que crees que es una lista, obtienes un resultado bastante diferente. Aunque parezca que tienes una lista en el lado derecho, Perl en realidad ve un montón de escalares separados por una coma:

my $scalar = ( 'dog', 'cat', 'bird' );  # $scalar obtiene 'bird'

Dado que estás asignando a un escalar, el lado derecho está en contexto escalar. El operador coma (sí, ¡es un operador!) en contexto escalar evalúa su lado izquierdo, descarta el resultado, y evalúa su lado derecho y devuelve el resultado. En efecto, esa apariencia de lista asigna a $scalar su valor más a la derecha. Mucha gente se equivoca en esto porque eligen una apariencia de lista cuyo último elemento es también el conteo que esperan:

my $scalar = ( 1, 2, 3 );  # $scalar obtiene 3, por accidente

¿Cómo manejo las listas enlazadas?

(contribuido por brian d foy)

Los arrays de Perl no tienen un tamaño fijo, así que no necesitas listas enlazadas si solo quieres añadir o eliminar elementos. Puedes usar operaciones de array como "push", "pop", "shift", "unshift" o "splice" para hacerlo.

Sin embargo, a veces las listas enlazadas pueden ser útiles en situaciones donde quieres "dividir" un array para tener muchos arrays pequeños en lugar de un solo array grande. Puedes mantener arrays más largos que el índice más grande de Perl, bloquear arrays más pequeños por separado en programas con hilos, reasignar menos memoria o insertar elementos rápidamente en medio de la cadena.

Steve Lembark detalla esto en su charla YAPC::NA 2009 "Perly Linked Lists" (http://www.slideshare.net/lembark/perly-linked-lists), aunque también puedes usar su módulo LinkedList::Single.

¿Cómo manejo listas circulares?

(contribuido por brian d foy)

Si quieres recorrer un array sin fin, puedes incrementar el índice módulo el número de elementos del array:

my @array = qw( a b c );
my $i = 0;
while( 1 ) {
    print $array[ $i++ % @array ], "\n";
    last if $i > 20;
}

También puedes usar Tie::Cycle para usar un escalar que siempre tiene el siguiente elemento del array circular:

use Tie::Cycle;
tie my $cycle, 'Tie::Cycle', [ qw( FFFFFF 000000 FFFF00 ) ];
print $cycle; # FFFFFF
print $cycle; # 000000
print $cycle; # FFFF00

Array::Iterator::Circular crea un objeto iterador para arrays circulares:

use Array::Iterator::Circular;
my $color_iterator = Array::Iterator::Circular->new(
    qw(red green blue orange)
    );
foreach ( 1 .. 20 ) {
    print $color_iterator->next, "\n";
}

¿Cómo mezclo un array aleatoriamente?

Si tienes Perl 5.8.0 o posterior instalado, o si tienes Scalar-List-Utils 1.03 o posterior instalado, puedes decir:

use List::Util 'shuffle';
@shuffled = shuffle(@list);

Si no, puedes usar un barajado Fisher-Yates.

sub fisher_yates_shuffle {
    my $deck = shift;  # $deck es una referencia a un array
    return unless @$deck; # ¡no debe estar vacío!
    my $i = @$deck;
    while (--$i) {
        my $j = int rand ($i+1);
        @$deck[$i,$j] = @$deck[$j,$i];
    }
}
# baraja mi colección mpeg
#
my @mpeg = <audio/*/*.mp3>;
fisher_yates_shuffle( \@mpeg );    # aleatoriza @mpeg en su lugar
print @mpeg;

Nota que la implementación anterior baraja un array en su lugar, a diferencia de List::Util::shuffle() que toma una lista y devuelve una nueva lista barajada.

Probablemente hayas visto algoritmos de barajado que funcionan usando splice, eligiendo aleatoriamente otro elemento para intercambiar con el elemento actual

srand;
@new = ();
@old = 1 .. 10;  # solo una demostración
while (@old) {
    push(@new, splice(@old, rand @old, 1));
}

Esto es malo porque splice ya es O(N), y como lo haces N veces, acabas de inventar un algoritmo cuadrático; es decir, O(N**2). Esto no escala, aunque Perl es tan eficiente que probablemente no lo notarás hasta que tengas arrays bastante grandes.

¿Cómo proceso/modifico cada elemento de un array?

Usa "for"/"foreach":

for (@lines) {
    s/foo/bar/;    # cambia esa palabra
    tr/XZ/ZX/;    # intercambia esas letras
}

Aquí tienes otro; calculemos volúmenes esféricos:

my @volumes = @radii;
for (@volumes) {   # @volumes ha cambiado partes
    $_ **= 3;
    $_ *= (4/3) * 3.14159;  # esto será doblado por constantes
}

lo cual también se puede hacer con map() que está hecho para transformar una lista en otra:

my @volumes = map {$_ ** 3 * (4/3) * 3.14159} @radii;

Si quieres hacer lo mismo para modificar los valores del hash, puedes usar la función "values". A partir de Perl 5.6, los valores no se copian, por lo que si modificas $orbit (en este caso), modificas el valor.

for my $orbit ( values %orbits ) {
    ($orbit **= 3) *= (4/3) * 3.14159;
}

Antes de perl 5.6, "values" devolvía copias de los valores, por lo que el código antiguo de Perl a menudo contiene construcciones como @orbits{keys %orbits} en lugar de "values %orbits" cuando se van a modificar los valores del hash.

¿Cómo selecciono un elemento aleatorio de un array?

Usa la función rand() (ver "rand" en perlfunc):

my $index   = rand @array;
my $element = $array[$index];

O, simplemente:

my $element = $array[ rand @array ];

¿Cómo permuto N elementos de una lista?

Usa el módulo List::Permutor en CPAN. Si la lista es en realidad un array, prueba el módulo Algorithm::Permute (también en CPAN). Está escrito en código XS y es muy eficiente:

use Algorithm::Permute;
my @array = 'a'..'d';
my $p_iterator = Algorithm::Permute->new ( \@array );
while (my @perm = $p_iterator->next) {
   print "siguiente permutación: (@perm)\n";
}

Para una ejecución aún más rápida, podrías hacer:

use Algorithm::Permute;
my @array = 'a'..'d';
Algorithm::Permute::permute {
    print "siguiente permutación: (@array)\n";
} @array;

Aquí tienes un pequeño programa que genera todas las permutaciones de todas las palabras en cada línea de entrada. El algoritmo que se muestra en la función permute() se discute en el Volumen 4 (aún no publicado) de The Art of Computer Programming de Knuth y funcionará en cualquier lista:

#!/usr/bin/perl -n
# Generador de permutaciones ordenadas Fischer-Krause
sub permute (&@) {
    my $code = shift;
    my @idx = 0..$#_;
    while ( $code->(@_[@idx]) ) {
        my $p = $#idx;
        --$p while $idx[$p-1] > $idx[$p];
        my $q = $p or return;
        push @idx, reverse splice @idx, $p;
        ++$q while $idx[$p-1] > $idx[$q];
        @idx[$p-1,$q]=@idx[$q,$p-1];
    }
}
permute { print "@_\n" } split;

El módulo Algorithm::Loops también proporciona las funciones "NextPermute" y "NextPermuteNum" que encuentran eficientemente todas las permutaciones únicas de un array, incluso si contiene valores duplicados, modificándolo en su lugar: si sus elementos están en orden inverso ordenado, el array se invierte, haciéndolo ordenado, y devuelve falso; de lo contrario, se devuelve la siguiente permutación.

"NextPermute" usa orden de cadenas y "NextPermuteNum" orden numérico, por lo que puedes enumerar todas las permutaciones de 0..9 así:

use Algorithm::Loops qw(NextPermuteNum);
my @list= 0..9;
do { print "@list\n" } while NextPermuteNum @list;

¿Cómo ordeno un array por (cualquier cosa)?

Proporciona una función de comparación a sort() (descrita en "sort" en perlfunc):

@list = sort { $a <=> $b } @list;

La función de ordenación predeterminada es cmp, comparación de cadenas, que ordenaría "(1, 2, 10)" como "(1, 10, 2)". "<=>", usado arriba, es el operador de comparación numérica.

Si tienes una función complicada necesaria para extraer la parte por la que quieres ordenar, entonces no la hagas dentro de la función de ordenación. Extráela primero, porque el BLOQUE de ordenación puede ser llamado muchas veces para el mismo elemento. Aquí hay un ejemplo de cómo extraer la primera palabra después del primer número en cada elemento, y luego ordenar esas palabras sin distinción de mayúsculas y minúsculas.

my @idx;
for (@data) {
    my $item;
    ($item) = /\d+\s*(\S+)/;
    push @idx, uc($item);
}
my @sorted = @data[ sort { $idx[$a] cmp $idx[$b] } 0 .. $#idx ];

lo cual también podría escribirse de esta manera, usando un truco que se ha conocido como la Transformada Schwartziana:

my @sorted = map  { $_->[0] }
    sort { $a->[1] cmp $b->[1] }
    map  { [ $_, uc( (/\d+\s*(\S+)/)[0]) ] } @data;

Si necesitas ordenar por varios campos, el siguiente paradigma es útil.

my @sorted = sort {
    field1($a) <=> field1($b) ||
    field2($a) cmp field2($b) ||
    field3($a) cmp field3($b)
} @data;

Esto se puede combinar convenientemente con el pre-cálculo de claves como se indica arriba.

Ver el artículo de sort en la colección "Far More Than You Ever Wanted To Know" en http://www.cpan.org/misc/olddoc/FMTEYEWTK.tgz para más información sobre este enfoque.

Ver también la pregunta más adelante en perlfaq4 sobre la ordenación de hashes.

¿Cómo manipulo arrays de bits?

Usa pack() y unpack(), o si no vec() y las operaciones a nivel de bit.

Por ejemplo, no tienes que almacenar bits individuales en un array (lo que significaría que estás desperdiciando mucho espacio). Para convertir un array de bits a una cadena, usa vec() para establecer los bits correctos. Esto establece $vec para tener el bit N activado solo si $ints[N] estaba activado:

my @ints = (...); # array de bits, por ejemplo ( 1, 0, 0, 1, 1, 0 ... )
my $vec = '';
foreach( 0 .. $#ints ) {
    vec($vec,$_,1) = 1 if $ints[$_];
}

La cadena $vec solo ocupa tantos bits como necesita. Por ejemplo, si tenías 16 entradas en @ints, $vec solo necesita dos bytes para almacenarlas (sin contar la sobrecarga de la variable escalar).

    my @ints;
    # Encuentra la densidad de bytes nulos y luego selecciona el mejor algoritmo

        use integer;
        my $i;
        # Este método es más rápido con la mayoría de bytes nulos
        while($vec =~ /[^\0]/g ) {

            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
        }

¿Cómo proceso un hash completo?

(aportado por brian d foy)

Hay un par de formas de procesar un hash completo. Puedes obtener una lista de claves, luego recorrer cada clave, o tomar un par clave-valor a la vez.

Para recorrer todas las claves, usa la función "keys". Esto extrae todas las claves del hash y te las devuelve como una lista. Luego puedes obtener el valor a través de la clave particular que estás procesando:

foreach my $key ( keys %hash ) {
    my $value = $hash{$key};
    ...
}

Una vez que tienes la lista de claves, puedes procesar esa lista antes de procesar los elementos del hash. Por ejemplo, puedes ordenar las claves para procesarlas en orden léxico:

foreach my $key ( sort keys %hash ) {
    my $value = $hash{$key};
    ...
}

O, podrías querer procesar solo algunos de los elementos. Si solo quieres tratar con las claves que comienzan con "text:", puedes seleccionar solo esas usando "grep":

foreach my $key ( grep /^text:/, keys %hash ) {
    my $value = $hash{$key};
    ...
}

Si el hash es muy grande, quizás no quieras crear una lista larga de claves. Para ahorrar algo de memoria, puedes tomar un par clave-valor a la vez usando each(), que devuelve un par que aún no has visto:

while( my( $key, $value ) = each( %hash ) ) {
    ...
}

El operador "each" devuelve los pares en un orden aparentemente aleatorio, así que si el orden te importa, tendrás que quedarte con el método "keys".

Sin embargo, el operador each() puede ser un poco complicado. No puedes añadir o eliminar claves del hash mientras lo estás usando sin posiblemente saltarte o reprocesar algunos pares después de que perl reorganice internamente todos los elementos. Adicionalmente, un hash solo tiene un iterador, así que si mezclas "keys", "values", o "each" en el mismo hash, corres el riesgo de restablecer el iterador y arruinar tu procesamiento. Consulta la entrada para "each" en perlfunc para más detalles.

¿Cómo fusiono dos hashes?

(aportado por brian d foy)

Antes de decidir fusionar dos hashes, tienes que decidir qué hacer si ambos hashes contienen claves iguales y si quieres dejar los hashes originales como estaban.

Si quieres preservar los hashes originales, copia un hash (%hash1) a un nuevo hash (%new_hash), luego añade las claves del otro hash (%hash2) al nuevo hash. Comprobar si la clave ya existe en %new_hash te da la oportunidad de decidir qué hacer con los duplicados:

my %new_hash = %hash1; # haz una copia; deja %hash1 intacto
foreach my $key2 ( keys %hash2 ) {
    if( exists $new_hash{$key2} ) {
        warn "¡La clave [$key2] está en ambos hashes!";
        # maneja el duplicado (quizás solo una advertencia)
        ...
        next;
    }
    else {
        $new_hash{$key2} = $hash2{$key2};
    }
}

Si no quieres crear un nuevo hash, aún puedes usar esta técnica de bucle; solo cambia %new_hash por %hash1.

foreach my $key2 ( keys %hash2 ) {
    if( exists $hash1{$key2} ) {
        warn "¡La clave [$key2] está en ambos hashes!";
        # maneja el duplicado (quizás solo una advertencia)
        ...
        next;
    }
    else {
        $hash1{$key2} = $hash2{$key2};
    }
  }

Si no te importa que un hash sobrescriba claves y valores del otro, podrías simplemente usar un slice de hash para añadir un hash a otro. En este caso, los valores de %hash2 reemplazan a los valores de %hash1 cuando tienen claves comunes:

@hash1{ keys %hash2 } = values %hash2;

¿Qué sucede si añado o elimino claves de un hash mientras lo estoy iterando?

(aportado por brian d foy)

La respuesta fácil es "¡No lo hagas!"

Si iteras a través del hash con each(), puedes eliminar la clave devuelta más recientemente sin preocuparte por ello. Si eliminas o añades otras claves, el iterador puede saltárselas o duplicarlas ya que perl puede reorganizar la tabla hash. Consulta la entrada para each() en perlfunc.

¿Cómo busco un elemento de hash por valor?

Crea un hash inverso:

my %by_value = reverse %by_key;
my $key = $by_value{$value};

Eso no es particularmente eficiente. Sería más eficiente en espacio usar:

while (my ($key, $value) = each %by_key) {
    $by_value{$value} = $key;
}

Si tu hash puede tener valores repetidos, los métodos anteriores solo encontrarán una de las claves asociadas. Esto puede o no preocuparte. Si te preocupa, siempre puedes invertir el hash en un hash de arrays en su lugar:

while (my ($key, $value) = each %by_key) {

}

¿Cómo sé cuántas entradas hay en un hash?

(aportado por brian d foy)

Esto es muy similar a "¿Cómo proceso un hash completo?", también en perlfaq4, pero un poco más simple en los casos comunes.

Puedes usar la función incorporada keys() en contexto de escalar para saber cuántas entradas tienes en un hash:

my $key_count = keys %hash; # ¡debe ser contexto de escalar!

Si quieres saber cuántas entradas tienen un valor definido, eso es un poco diferente. Tienes que comprobar cada valor. Un "grep" es útil:

my $defined_value_count = grep { defined } values %hash;

Puedes usar esa misma estructura para contar las entradas de la forma que quieras. Si quieres contar las claves que tienen vocales, solo comprueba eso en su lugar:

my $vowel_count = grep { /[aeiou]/ } keys %hash;

La función "grep" en contexto de escalar devuelve el recuento. Si quieres la lista de elementos coincidentes, simplemente úsala en contexto de lista en su lugar:

my @defined_values = grep { defined } values %hash;

La función keys() también restablece el iterador, lo que significa que podrías ver resultados extraños si usas esto entre usos de otros operadores de hash como each().

¿Cómo puedo ordenar mi hash por clave o valor?

Los hashes en Perl no están ordenados. Cuando iteras sobre ellos, los elementos se presentan en un orden arbitrario que puede cambiar de una iteración a otra. Si necesitas que los elementos de tu hash se presenten en un orden específico, debes obtener sus claves y ordenarlas tú mismo.

Para crear un informe que enumere las claves en orden alfabético:

my @keys = sort { $a cmp $b } keys %hash;
foreach my $key ( @keys ) {
    printf "%-20s %6d\n", $key, $hash{$key};
}

Podríamos ser más sofisticados en el bloque sort(). En lugar de comparar las claves, podemos calcular un valor con ellas y usar ese valor como comparación.

Por ejemplo, para que nuestro informe se ordene sin distinción entre mayúsculas y minúsculas, usamos "fc" para convertir las claves a minúsculas de forma segura antes de compararlas:

use v5.16;
my @keys = sort { fc($a) cmp fc($b) } keys %hash;

Versiones anteriores de esta respuesta usaban "lc", pero esto podía dar resultados inesperados con algunas cadenas Unicode. Vea "fc" en perlfunc para más detalles. El módulo Unicode::UCD hace lo mismo para versiones anteriores de Perl.

Nota: si el cálculo es costoso o el hash tiene muchos elementos, puede que desee consultar la Transformada de Schwartz para almacenar en caché los resultados del cálculo.

Si queremos ordenar por el valor del hash en su lugar, usamos la clave del hash para buscarlo. Aún obtenemos una lista de claves, pero esta vez están ordenadas por su valor:

my @keys = sort { $hash{$a} <=> $hash{$b} } keys %hash;

A partir de ahí podemos volvernos más complejos. Si los valores del hash son los mismos, podemos proporcionar un ordenamiento secundario por la clave del hash:

use v5.16;
my @keys = sort {
    $hash{$a} <=> $hash{$b}
        or
    fc($a) cmp fc($b)
} keys %hash;

¿Cuál es la diferencia entre "delete" y "undef" con hashes?

Los hashes contienen pares de escalares: el primero es la clave, el segundo es el valor. La clave se convertirá a una cadena, aunque el valor puede ser de cualquier tipo escalar: cadena, número o referencia. Si una clave $key está presente en %hash, exists($hash{$key}) devolverá verdadero. El valor para una clave dada puede ser "undef", en cuyo caso $hash{$key} será "undef" mientras que "exists $hash{$key}" devolverá verdadero. Esto corresponde a que ($key, "undef") esté en el hash.

How can I make a hash entry hold a reference to a scalar?

The easiest way is to just use a reference:

    $hash{key} = \$scalar;

However, this doesn't help you when you want to access the value of the scalar. You would have to dereference it manually:

    my $scalar_ref = $hash{key};
    print "The value is: $$scalar_ref\n";
    $$scalar_ref = 42;

If you want automatic dereferencing (that is, you want $hash{key} to give you the value of the scalar, not its reference), then you may want to consider using a tied hash. The Tie::RefHash module (available on CPAN) allows you to use scalars as hash keys and values, automatically handling the dereferencing for you. It also handles garbage collection of scalars that are no longer referenced by the hash.

Here's an example:

    use Tie::RefHash;
    tie my %map, 'Tie::RefHash';
    my $x = 10;
    my $y = 20;
    $map{a} = \$x;
    $map{b} = \$y;
    print $map{a}; # prints 10
    $map{a} = 15;  # assigns to the scalar $x
    print $x;      # prints 15

Note that Tie::RefHash uses autovivification and might create references to undefined values for keys that don't exist. If you wish to avoid this, you can use the "use Tie::RefHash autovivification => 0;" pragma. You can also prevent unwanted autovivification using the lexical "no autovivification;" pragma, or by checking existence first with "exists".

If you actually need to be able to get a real reference back from each hash entry, you can use the Tie::RefHash module, which does the required work for you.

How can I check if a key exists in a multilevel hash?

(contributed by brian d foy)

The trick to this problem is avoiding accidental autovivification. If you want to check three keys deep, you might naïvely try this:

my %hash;
if( exists $hash{key1}{key2}{key3} ) {
    ...;
}

Even though you started with a completely empty hash, after that call to "exists" you've created the structure you needed to check for "key3":

%hash = (
          'key1' => {
                      'key2' => {}
                    }
        );

That's autovivification. You can get around this in a few ways. The easiest way is to just turn it off. The lexical "autovivification" pragma is available on CPAN. Now you don't add to the hash:

{
    no autovivification;
    my %hash;
    if( exists $hash{key1}{key2}{key3} ) {
        ...;
    }
}

The Data::Diver module on CPAN can do it for you too. Its "Dive" subroutine can tell you not only if the keys exist but also get the value:

use Data::Diver qw(Dive);
my @exists = Dive( \%hash, qw(key1 key2 key3) );
if(  ! @exists  ) {
    ...; # keys do not exist
}
elsif(  ! defined $exists[0]  ) {
    ...; # keys exist but value is undef
}

You can easily do this yourself too by checking each level of the hash before you move onto the next level. This is essentially what Data::Diver does for you:

if( check_hash( \%hash, qw(key1 key2 key3) ) ) {
    ...;
}
sub check_hash {
   my( $hash, @keys ) = @_;
   return unless @keys;
   foreach my $key ( @keys ) {
       return unless eval { exists $hash->{$key} };
       $hash = $hash->{$key};
    }
   return 1;
}

How do I handle binary data correctly?

Perl is binary-clean, so it can handle binary data just fine. On Windows or DOS, however, you have to use "binmode" for binary files to avoid conversions for line endings. In general, you should use "binmode" any time you want to work with binary data.

Also see "binmode" in perlfunc or perlopentut.

If you're concerned about 8-bit textual data then see perllocale. If you want to deal with multibyte characters, however, there are some gotchas. See the section on Regular Expressions.

How do I determine whether a scalar is a number/whole/integer/float?

Assuming that you don't care about IEEE notations like "NaN" or "Infinity", you probably just want to use a regular expression (see also perlretut and perlre):

use 5.010;
if ( /\D/ )
    { say "\thas nondigits"; }
if ( /^\d+\z/ )
    { say "\tis a whole number"; }
if ( /^-?\d+\z/ )
    { say "\tis an integer"; }
if ( /^[+-]?\d+\z/ )
    { say "\tis a +/- integer"; }
if ( /^-?(?:\d+\.?|\.\d)\d*\z/ )
    { say "\tis a real number"; }
if ( /^[+-]?(?=\.?\d)\d*\.?\d*(?:e[+-]?\d+)?\z/i )
    { say "\tis a C float" }

There are also some commonly used modules for the task. Scalar::Util (distributed with 5.8) provides access to perl's internal function "looks_like_number" for determining whether a variable looks like a number. Data::Types exports functions that validate data types using both the above and other regular expressions. Thirdly, there is Regexp::Common which has regular expressions to match various types of numbers. Those three modules are available from the CPAN.

If you're on a POSIX system, Perl supports the "POSIX::strtod" function for converting strings to doubles (and also "POSIX::strtol" for longs). Its semantics are somewhat cumbersome, so here's a "getnum" wrapper function for more convenient access. This function takes a string and returns the number it found, or "undef" for input that isn't a C float. The "is_numeric" function is a front end to "getnum" if you just want to say, "Is this a float?"

sub getnum {
    use POSIX qw(strtod);
    my $str = shift;
    $str =~ s/^\s+//;
    $str =~ s/\s+$//;
    $! = 0;
    my($num, $unparsed) = strtod($str);
    if (($str eq '') || ($unparsed != 0) || $!) {
            return undef;
    }
    else {
        return $num;
    }
}

How do I keep persistent data across program calls?

For some specific applications, you can use one of the DBM modules. See AnyDBM_File. More generically, you should consult the FreezeThaw or Storable modules from CPAN. Starting from Perl 5.8, Storable is part of the standard distribution. Here's one example using Storable's "store" and "retrieve" functions:

use Storable;
store(\%hash, "filename");
# later on...
$href = retrieve("filename");        # by ref
%hash = %{ retrieve("filename") };   # direct to hash

How do I print out or copy a recursive data structure?

The Data::Dumper module on CPAN (or the 5.005 release of Perl) is great for printing out data structures. The Storable module on CPAN (or the 5.8 release of Perl), provides a function called "dclone" that recursively copies its argument.

use Storable qw(dclone);
$r2 = dclone($r1);

Where $r1 can be a reference to any kind of data structure you'd like. It will be deeply copied. Because "dclone" takes and returns references, you'd have to add extra punctuation if you had a hash of arrays that you wanted to copy.

%newhash = %{ dclone(\%oldhash) };

How do I define methods for every class/object?

(contributed by Ben Morrow)

You can use the "UNIVERSAL" class (see UNIVERSAL). However, please be very careful to consider the consequences of doing this: adding methods to every object is very likely to have unintended consequences. If possible, it would be better to have all your objects inherit from some common base class, or to use an object system like Moose that supports roles.
