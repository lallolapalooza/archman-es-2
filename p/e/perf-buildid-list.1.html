NOMBRE

perf-buildid-list - Listar los buildids en un archivo perf.data

SINOPSIS

perf buildid-list <opciones>

DESCRIPCIÓN

Este comando muestra los buildids encontrados en un archivo perf.data, para que otras herramientas puedan ser utilizadas para obtener paquetes con tablas de símbolos coincidentes para su uso por perf report.

También se puede usar para mostrar el build id del kernel en ejecución o en un archivo ELF usando -i/--input.

OPCIONES

-H, --with-hits

Mostrar solo DSOs con hits.

-i, --input=

Nombre del archivo de entrada. (por defecto: perf.data a menos que stdin sea una fifo)

-f, --force

No hacer validación de propiedad.

-k, --kernel

Mostrar el build id del kernel en ejecución.

-m, --kernel-maps

Mostrar el buildid, la dirección de inicio/fin del texto y la ruta del kernel en ejecución y sus módulos.

-v, --verbose

Ser más verboso.

VER TAMBIÉN

perf-record(1), perf-top(1), perf-report(1)
