PERLINTRO(1perl) Guía de Referencia del Programador de Perl PERLINTRO(1perl)

NOMBRE

perlintro - una breve introducción y resumen de Perl

DESCRIPCIÓN

Este documento está destinado a proporcionar una visión general rápida del lenguaje de programación Perl, junto con enlaces a documentación adicional. Está pensado como una guía de "arranque" para aquellos que son nuevos en el lenguaje, y proporciona la información suficiente para que puedas leer Perl de otras personas y entender aproximadamente lo que está haciendo, o escribir tus propios scripts sencillos.

Este documento introductorio no pretende ser completo. Ni siquiera pretende ser completamente preciso. En algunos casos, se ha sacrificado la perfección en el objetivo de transmitir la idea general. Se le aconseja encarecidamente que complemente esta introducción con más información del manual completo de Perl, cuyo índice se encuentra en perltoc.

A lo largo de este documento verá referencias a otras partes de la documentación de Perl. Puede leer esa documentación utilizando el comando "perldoc" o cualquier método que esté utilizando para leer este documento.

A lo largo de la documentación de Perl, encontrará numerosos ejemplos destinados a ayudar a explicar las características discutidas. Tenga en cuenta que muchos de ellos son fragmentos de código en lugar de programas completos.

Estos ejemplos a menudo reflejan el estilo y la preferencia del autor de esa pieza de la documentación, y pueden ser más breves que una línea de código correspondiente en un programa real. Excepto donde se indique lo contrario, debe asumir que las declaraciones "use strict" y "use warnings" aparecen antes en el "programa", y que cualquier variable utilizada ya ha sido declarada, incluso si esas declaraciones se han omitido para facilitar la lectura del ejemplo.

Tenga en cuenta que los ejemplos han sido escritos por muchos autores diferentes a lo largo de varias décadas. Por lo tanto, los estilos y las técnicas variarán, aunque se ha hecho un esfuerzo para no variar los estilos demasiado dentro de las mismas secciones. No considere un estilo mejor que otros: "Hay más de una forma de hacerlo" es uno de los lemas de Perl. Después de todo, en su viaje como programador, es probable que encuentre diferentes estilos.

¿Qué es Perl?

Perl es un lenguaje de programación de propósito general desarrollado originalmente para la manipulación de texto y que ahora se utiliza para una amplia gama de tareas, incluida la administración de sistemas, el desarrollo web, la programación de redes, el desarrollo de GUI y más.

El lenguaje está destinado a ser práctico (fácil de usar, eficiente, completo) en lugar de hermoso (pequeño, elegante, minimalista). Sus principales características son que es fácil de usar, admite programación procedural y orientada a objetos (OO), tiene un potente soporte incorporado para el procesamiento de texto y posee una de las colecciones de módulos de terceros más impresionantes del mundo.

Diferentes definiciones de Perl se dan en perl, perlfaq1 y sin duda en otros lugares. A partir de esto, podemos determinar que Perl es diferente para diferentes personas, pero que a mucha gente le parece que al menos vale la pena escribir sobre él.

Ejecución de programas Perl

Para ejecutar un programa Perl desde la línea de comandos de Unix:

perl progname.pl

Alternativamente, coloque esto como la primera línea de su script:

#!/usr/bin/env perl

... y ejecute el script como /ruta/a/script.pl. Por supuesto, primero deberá ser ejecutable, así que "chmod 755 script.pl" (en Unix).

(Esta línea de inicio asume que tiene el programa env. También puede colocar directamente la ruta a su ejecutable de perl, como en "#!/usr/bin/perl").

Para obtener más información, incluidas las instrucciones para otras plataformas como Windows, lea perlrun.

Red de seguridad

Perl, por defecto, es muy indulgente. Para hacerlo más robusto, se recomienda comenzar todos los programas con las siguientes líneas:

#!/usr/bin/perl
use strict;
use warnings;

Las dos líneas adicionales solicitan a perl que detecte varios problemas comunes en su código. Verifican diferentes cosas, por lo que necesita ambas. Un problema potencial detectado por "use strict;" hará que su código se detenga inmediatamente cuando se encuentre, mientras que "use warnings;" simplemente dará una advertencia (como la opción de línea de comandos -w) y dejará que su código se ejecute. Para leer más sobre ellas, consulte sus páginas de manual correspondientes en strict y warnings.

Una declaración "use v5.35" (o superior) habilitará tanto "strict" como "warnings":

#!/usr/bin/perl
use v5.35;

Además de habilitar los pragmas "strict" y "warnings", esta declaración también activará un "paquete de características"; una colección de características nombradas que habilitan muchas de las adiciones y cambios más recientes al lenguaje, y ocasionalmente eliminan características antiguas que se consideraron errores de diseño y se desaconsejaron.

Descripción general de la sintaxis básica

Un script o programa Perl consta de una o más sentencias. Estas sentencias se escriben simplemente en el script de forma directa. No es necesario tener una función main() ni nada parecido.

Las sentencias de Perl terminan con un punto y coma:

print "Hello, world";

Los comentarios comienzan con un símbolo de almohadilla (#) y continúan hasta el final de la línea.

# Este es un comentario

El espacio en blanco es irrelevante:

print
    "Hello, world"
    ;

... excepto dentro de cadenas entre comillas:

# esto imprimiría con un salto de línea en el medio
print "Hello
world";

Se pueden usar comillas dobles o simples alrededor de cadenas literales:

print "Hello, world";
print 'Hello, world';

Sin embargo, solo las comillas dobles "interpolan" variables y caracteres especiales como saltos de línea ("\n"):

print "Hello, $name\n";     # funciona bien
print 'Hello, $name\n';     # imprime $name\n literalmente

Los números no necesitan comillas:

print 42;

Puede usar paréntesis para los argumentos de las funciones u omitirlos según su gusto personal. Solo se requieren ocasionalmente para aclarar cuestiones de precedencia.

print("Hello, world\n");
print "Hello, world\n";

Puede encontrar información más detallada sobre la sintaxis de Perl en perlsyn.

Tipos de variables de Perl

Es posible que haya notado la extraña cadena de caracteres <$name> arriba. Eso denota una variable, que generalmente se pronuncia como "name". El signo de dólar se llama "sigilo" e indica que "name" es una variable. A diferencia de muchos otros lenguajes de programación donde las variables son solo cadenas de caracteres típicamente solo alfabéticos y numéricos, todas las variables de Perl van precedidas de un sigilo.

Perl tiene tres tipos principales de variables: escalares, arrays (arreglos) y hashes (tablas hash). El sigilo particular utilizado para un nombre de variable indica el tipo de esa variable. Ya hemos visto el signo de dólar como sigilo, $name. El signo de dólar indica que esta variable es un escalar.

Escalares
Un escalar representa un único valor: 
my $animal = "camel";
my $answer = 42;

Los valores escalares pueden ser cadenas, enteros o números de punto flotante, y Perl los convertirá automáticamente según sea necesario. Debe declararlos usando la palabra clave "my" la primera vez que los utilice. (Este es uno de los requisitos de "use strict;".)

Los valores escalares se pueden usar de varias maneras:

print $animal;
print "The animal is $animal\n";
print "The square of $answer is ", $answer * $answer, "\n";

Arrays
Un array representa una lista de valores. Un "@" sigilo indica que una variable es un array: 
my @animals = ("camel", "llama", "owl");
my @numbers = (23, 42, 69);
my @mixed   = ("camel", 42, 1.23);

Cada uno de estos arrays es una agregación de valores individuales. Y cada valor es en realidad un escalar.

Los arrays están indexados desde cero. Aquí se explica cómo acceder a los elementos escalares individuales en un array:

print $animals[0];              # imprime "camel"
print $animals[1];              # imprime "llama"

En Perl, los escalares siempre se referencian con el "$" sigilo. Por lo tanto, escribimos $animals[0] arriba para obtener la variable escalar 0 dentro del array @animals. Los corchetes indican que estamos obteniendo el valor de un array. Este es un punto importante de confusión para los recién llegados a Perl. Cuando buscas un solo valor, necesitas usar , aunque ese valor sea parte de una agregación mayor.

La variable especial $#array te indica el índice del último elemento de un array:

print $mixed[$#mixed];       # último elemento, imprime 1.23

Podrías verte tentado a usar para saber cuántos elementos hay en un array. No te molestes. Resulta que, usar @array donde Perl espera encontrar un valor escalar ("en contexto escalar") te dará el número de elementos en el array:

if (@animals < 5) { ... }

Los elementos que obtenemos del array comienzan con un porque solo obtenemos un solo valor del array; solicitas un escalar, obtienes un escalar.

Para obtener múltiples valores de un array:

@animals[0,1];                 # da ("camel", "llama");
@animals[0..2];                # da ("camel", "llama", "owl");
@animals[1..$#animals];        # da todos excepto el primer elemento

Esto se llama un "slice de array". Usamos el sigilo aquí porque queremos múltiples valores; está reservado para referenciar valores únicos.

Puedes hacer varias cosas útiles con las listas:

my @sorted    = sort @animals;
my @backwards = reverse @numbers;

También hay un par de arrays especiales, como @ARGV (los argumentos de línea de comandos de tu script) y @_ (los argumentos pasados a una subrutina). Estos se documentan en perlvar.

Hashes
Un hash representa un conjunto de pares clave/valor. Un sigilo indica que una variable es un hash: 
my %fruit_color = ("apple", "red", "banana", "yellow");

Puedes usar espacios en blanco y el operador "=>" para presentarlos de una manera más ordenada:

my %fruit_color = (
    apple  => "red",
    banana => "yellow",
    lime   => "green",
);

Para acceder a los elementos del hash:

$fruit_color{"apple"};           # da "red"

Nota de nuevo el uso del sigilo para acceder a un solo elemento del hash. Las llaves indican que estamos obteniendo el valor de un hash.

Y podemos obtener múltiples valores usando un slice

my @non_red = @fruit_color{"banana", "lime"};
print $non_red[0], "\n";    # yellow
print $non_red[1], "\n";    # green

Nota de nuevo que múltiples valores usan el sigilo , y los individuales usan .

Puedes obtener listas de claves y valores con keys() y values().

my @fruits = keys %fruit_color;
my @colors = values %fruit_color;

Los hashes no tienen un orden interno particular, aunque puedes ordenar las claves y recorrerlas.

Al igual que los escalares y arrays especiales, también hay hashes especiales. El más conocido de ellos es %ENV, que contiene variables de entorno. Lee todo sobre él (y otras variables especiales) en perlvar.

Escalares, arrays y hashes se documentan más ampliamente en perldata.

Ten en cuenta que $name, @name, y %name son tres variables diferentes. Puede ser confuso usar los mismos alfanuméricos para representar diferentes variables, pero en algunas situaciones podría ser aclaratorio; una de ellas podría ser usar $name para representar el elemento particular de interés en el array @name. La elección del nombre es tuya; el intérprete de Perl no se preocupa. Cuando múltiples variables tienen el mismo nombre, usar corchetes versus llaves le dice al intérprete cuál se pretende.

Se pueden construir tipos de datos más complejos utilizando referencias, que permiten construir listas y hashes dentro de listas y hashes. El siguiente ejemplo muestra una estructura de hash de hash de 2 niveles usando referencias de hash anónimas.

my $variables = {
    scalar  =>  {
                 description => "single item",
                 sigil => '$',
                },
    array   =>  {
                 description => "ordered list of items",
                 sigil => '@',
                },
    hash    =>  {
                 description => "key/value pairs",
                 sigil => '%',
                },
};
print "Scalars begin with a $variables->{'scalar'}->{'sigil'}\n";

Encontrarás información exhaustiva sobre el tema de las referencias en perlreftut, perllol, perlref y perldsc.

Ámbito de las variables

A lo largo de la sección anterior, todos los ejemplos han utilizado la sintaxis:

my $var = "value";

El "my" en realidad no es obligatorio; podrías simplemente usar:

$var = "value";

Sin embargo, el uso anterior creará variables globales en todo tu programa, lo cual es una mala práctica de programación. "my" crea variables con ámbito léxico en su lugar. Las variables tienen el ámbito del bloque (es decir, un conjunto de sentencias rodeadas por llaves) en el que se definen.

my $x = "foo";
my $some_condition = 1;
if ($some_condition) {
    my $y = "bar";
    print $x;           # imprime "foo"
    print $y;           # imprime "bar"
}
print $x;               # imprime "foo"
print $y;               # imprime nada; $y ha salido de ámbito

Usar "my" en combinación con "use strict;" al principio de tus scripts de Perl significa que el intérprete detectará ciertos errores comunes de programación. Por ejemplo, en el ejemplo anterior, el último "print $y" causaría un error en tiempo de compilación y evitaría que ejecutaras el programa. Se recomienda encarecidamente usar "strict".

Construcciones condicionales y de bucle

Perl tiene la mayoría de las construcciones condicionales y de bucle habituales.

Las condiciones pueden ser cualquier expresión de Perl. Consulta la lista de operadores en la siguiente sección para obtener información sobre los operadores de comparación y lógica booleana, que se utilizan comúnmente en declaraciones condicionales.

if
if ( condition ) {
    ...
} elsif ( other condition ) {
    ...
} else {
    ...
}

También hay una versión negada:

unless ( condition ) {
    ...
}

Esto se proporciona como una versión más legible de "if (!condition)".

Ten en cuenta que las llaves son obligatorias en Perl, incluso si solo tienes una línea en el bloque. Sin embargo, hay una forma inteligente de hacer que tus bloques condicionales de una sola línea sean más parecidos al inglés:

# la forma tradicional
if ($zippy) {
    print "Yow!";
}
# la forma perl de post-condición
print "Yow!" if $zippy;
print "We have no bananas" unless $bananas;
while
while ( condition ) {
    ...
}

También hay una versión negada, por la misma razón que tenemos "unless":

until ( condition ) {
    ...
}

También puedes usar "while" en una post-condición:

print "LA LA LA\n" while 1;          # bucle infinito
for
Exactamente como en C: 
for ($i = 0; $i <= $max; $i++) {
    ...
}

El bucle for estilo C rara vez es necesario en Perl, ya que Perl proporciona el bucle "foreach" más amigable para escanear listas.

foreach
foreach (@array) {
    print "This element is $_\n";
}
print $list[$_] foreach 0 .. $max;
# tampoco tienes que usar el $_ por defecto...
foreach my $key (keys %hash) {
    print "The value of $key is $hash{$key}\n";
}

La palabra clave "foreach" es en realidad un sinónimo de "for" palabra clave. Véase "Bucles Foreach" en perlsyn.

Para más detalles sobre las construcciones de bucle (y algunas que no se mencionaron en este resumen) véase perlsyn.

Archivos y E/S

Puedes abrir un archivo para entrada o salida usando la función open(). Se documenta con detalle extravagante en perlfunc y perlopentut, pero en resumen:

open(my $in,  "<",  "input.txt")  o die "No se puede abrir input.txt: $!";
open(my $out, ">",  "output.txt") o die "No se puede abrir output.txt: $!";
open(my $log, ">>", "my.log")     o die "No se puede abrir my.log: $!";

Puedes leer de un manejador de archivo abierto usando el operador "<>". En contexto escalar lee una sola línea del manejador de archivo, y en contexto de lista lee el archivo completo, asignando cada línea a un elemento de la lista:

my $line  = <$in>;
my @lines = <$in>;

Leer el archivo completo a la vez se llama "slurping". Puede ser útil pero puede consumir mucha memoria. La mayor parte del procesamiento de archivos de texto se puede hacer línea por línea con las construcciones de bucle de Perl.

El operador "<>" se ve más a menudo en un bucle "while":

while (<$in>) {     # asigna cada línea en turno a $_
    print "Acabo de leer esta línea: $_";
}

Ya hemos visto cómo imprimir en la salida estándar usando print(). Sin embargo, print() también puede tomar un argumento opcional especificando a qué manejador de archivo imprimir:

print STDERR "Esta es tu advertencia final.\n";
print $out $record;
print $log $logmessage;

Cuando hayas terminado con tus manejadores de archivo, deberías close() (aunque, para ser honesto, Perl limpiará después de ti si lo olvidas):

close $in or die "$in: $!";

Expresiones regulares

El soporte de expresiones regulares de Perl es amplio y profundo, y es el tema de una extensa documentación en perlrequick, perlretut y otros. Sin embargo, en resumen:

Emparejamiento sencillo
if (/foo/)       { ... }  # verdadero si $_ contiene "foo"
if ($x =~ /foo/) { ... }  # verdadero si $x contiene "foo"

El operador de emparejamiento "//" se documenta en perlop. Opera sobre $_ por defecto, o puede enlazarse a otra variable usando el operador de enlace "=~" (también documentado en perlop).

Sustitución sencilla
s/foo/bar/;               # reemplaza foo por bar en $_
$x =~ s/foo/bar/;         # reemplaza foo por bar en $x
$x =~ s/foo/bar/g;        # reemplaza TODAS LAS INSTANCIAS de foo por bar
                          # en $x

El operador de sustitución "s///" se documenta en perlop.

Expresiones regulares más complejas
No solo tienes que emparejar cadenas fijas. De hecho, puedes emparejar casi cualquier cosa que puedas imaginar usando expresiones regulares más complejas. Estas se documentan extensamente en perlre, pero por ahora, aquí hay una hoja de referencia rápida: 
.                   un solo carácter
\s                  un carácter de espacio en blanco (espacio, tabulador, nueva línea, ...)
\S                  carácter no de espacio en blanco
\d                  un dígito (0-9)
\D                  un no dígito
\w                  un carácter de palabra (a-z, A-Z, 0-9, _)
\W                  un carácter no de palabra
[aeiou]             empareja un solo carácter del conjunto dado
[^aeiou]            empareja un solo carácter fuera del conjunto
                    dado
(foo|bar|baz)       empareja cualquiera de las alternativas especificadas
^                   inicio de la cadena
$                   fin de la cadena

Nota que en lo anterior, "$" no coincide con un signo de dólar. De manera similar ".", "\", "[", "]", "(", ")", y "^" no coinciden con los caracteres que podrías esperar. Estos se llaman "metacaracteres". En contraste, los caracteres "a", "e", "i", "o", y "u", por ejemplo, no son metacaracteres. Coinciden consigo mismos literalmente. Los metacaracteres normalmente coinciden con algo que no es su valor literal. Hay algunos metacaracteres más que los anteriores. Algunos cuantificadores se dan a continuación, y la lista completa está en "Metacaracteres" en perlre.

Para que un metacaracter coincida con su valor literal, lo "escapas" (o "citas") precediéndolo con una barra invertida. Por lo tanto, "\$" sí coincide con un signo de dólar, y "\\" coincide con una barra invertida literal.

Nota también que en lo anterior, la cadena "\s", por ejemplo, no coincide con una barra invertida seguida de la letra "s". En este caso, preceder el no metacaracter "s" con una barra invertida lo convierte en algo que no coincide con su valor literal. Dicha secuencia se llama "secuencia de escape". perlrebackslash documenta todas las actuales.

Se genera una advertencia si escapas un carácter que no es un metacaracter y no forma parte de una secuencia de escape definida actualmente.

Puedes especificar cuántas veces quieres que coincida lo anterior usando cuantificadores (donde "lo anterior" significa uno de: un carácter literal, uno de los constructos listados arriba, o un grupo de cualquiera de ellos entre paréntesis).

*                   cero o más de lo anterior
+                   uno o más de lo anterior
?                   cero o uno de lo anterior
{3}                 coincide exactamente 3 de lo anterior
{3,6}               coincide entre 3 y 6 de lo anterior
{3,}                coincide 3 o más de lo anterior

Algunos ejemplos breves:

/^\d+/              la cadena comienza con uno o más dígitos
/^$/                nada en la cadena (inicio y fin son
                    adyacentes)
/(\d\s){3}/         tres dígitos, cada uno seguido de un carácter de
                    espacio en blanco (ej. "3 4 5 ")
/(a.)+/             coincide con una cadena en la que cada letra
                    impar es una (ej. "abacadaf")
# Este bucle lee desde STDIN y imprime líneas no vacías:
while (<>) {
    next if /^$/;
    print;
}
Paréntesis para capturar
Además de agrupar, los paréntesis cumplen un segundo propósito. Se pueden usar para capturar los resultados de partes de la coincidencia de la expresión regular para su uso posterior. Los resultados terminan en $1, $2 y así sucesivamente. 
# una forma barata y cutre de dividir una dirección de correo electrónico en partes
if ($email =~ /([^@]+)@(.+)/) {
    print "El nombre de usuario es $1\n";
    print "El nombre del host es $2\n";
}

NAME

perlintro - Introduction to Perl

DESCRIPTION

This document is intended to give new Perl programmers a gentle introduction to the Perl language.

The Perl language is a high-level, general-purpose, interpreted, dynamic programming language. It was created by Larry Wall in 1987 and is now considered to be one of the most powerful and flexible scripting languages available.

Perl is well-suited to tasks such as system administration, web development, network programming, database interaction, and more.

The basics

Perl code is written in plain text files and executed by the Perl interpreter.

A typical Perl program consists of a sequence of statements, each ending with a semicolon.

print "Hello, world!\n";

Comments are denoted by a hash symbol (#).

# This is a comment

Variables are prefixed with a special character:

  • $ denotes a scalar variable (a single value like a number or string).
  • @ denotes an array (an ordered list of scalar values).
  • % denotes a hash (an associative array, mapping keys to values).

Perl uses context to determine how to interpret operations. For example, the print function outputs its arguments to standard output.

Control Structures

Perl provides standard control structures like if, unless, while, and for.

if ($condition) {
    # do something
} elsif ($another_condition) {
    # do something else
} else {
    # do default action
}

Loops:

while (<STDIN>) {
    print; # Prints the input line
}

A for loop:

for my $i (1..5) {
    print "$i squared is ", $i * $i, "\n";
}

Subroutines

Subroutines (also known as functions) allow you to group code into reusable blocks.

Here's a simple subroutine:

sub hello {
    print "Hello there!\n";
}

You call a subroutine using its name, optionally followed by parentheses containing arguments:

hello();

Arguments are passed into a subroutine via the special array @_. You can access arguments by shifting them off the array or by accessing elements by index.

sub logger {
   my $logmessage = shift;
   open my $logfile, ">>", "my.log" or die "Could not open my.log: $!";
   print $logfile $logmessage;
}

Now we can use the subroutine just as any other built-in function:

logger("We have a logger subroutine!");

What's that "shift"? Well, the arguments to a subroutine are available to us as a special array called @_ (see perlvar for more on that). The default argument to the "shift" function just happens to be @_. So "my $logmessage = shift;" shifts the first item off the list of arguments and assigns it to $logmessage.

We can manipulate @_ in other ways too:

my ($logmessage, $priority) = @_;       # common
my $logmessage = $_[0];                 # uncommon, and ugly

Subroutines can also return values:

sub square {
    my $num = shift;
    my $result = $num * $num;
    return $result;
}

Then use it like:

$sq = square(8);

For more information on writing subroutines, see perlsub.

OO Perl

OO Perl is relatively simple and is implemented using references which know what sort of object they are based on Perl's concept of packages. However, OO Perl is largely beyond the scope of this document. Read perlootut and perlobj.

As a beginning Perl programmer, your most common use of OO Perl will be in using third-party modules, which are documented below.

Using Perl modules

Perl modules provide a range of features to help you avoid reinventing the wheel, and can be downloaded from CPAN https://www.cpan.org/. A number of popular modules are included with the Perl distribution itself.

Categories of modules range from text manipulation to network protocols to database integration to graphics. A categorized list of modules is also available from CPAN.

To learn how to install modules you download from CPAN, read perlmodinstall.

To learn how to use a particular module, use "perldoc Module::Name". Typically you will want to "use Module::Name", which will then give you access to exported functions or an OO interface to the module.

perlfaq contains questions and answers related to many common tasks, and often provides suggestions for good CPAN modules to use.

perlmod describes Perl modules in general. perlmodlib lists the modules which came with your Perl installation.

If you feel the urge to write Perl modules, perlnewmod will give you good advice.
