NOMBRE

perl5363delta - qué hay de nuevo para la versión 5.36.3 de perl

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.36.1 y la versión 5.36.3. **Por favor, tenga en cuenta:** Este documento ignora la versión 5.36.2 de Perl, una versión defectuosa que solo existió durante un par de días.

Si está actualizando desde una versión anterior como la 5.36.0, primero lea perl5361delta, que describe las diferencias entre 5.36.0 y 5.36.1.

Seguridad

Esta versión corrige los siguientes problemas de seguridad.

CVE-2023-47038 - Escritura posterior al final del búfer a través de una propiedad Unicode definida por el usuario ilegal

Esta vulnerabilidad fue informada directamente al equipo de seguridad de Perl por Nathan Mills "the.true.nathan.mills@gmail.com".

Una expresión regular manipulada al ser compilada por perl 5.30.0 a 5.38.0 puede causar un desbordamiento de búfer de un byte controlado por el atacante en un búfer asignado en el montón (heap).

CVE-2023-47039 - Vulnerabilidad de secuestro de binarios de Perl para Windows

Esta vulnerabilidad fue informada al Equipo de Respuesta a Incidentes de Seguridad de Productos de Intel (PSIRT) por el usuario de GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT luego la informó al equipo de seguridad de Perl.

Perl para Windows depende de la variable de entorno PATH del sistema para encontrar el intérprete de comandos ("cmd.exe"). Al ejecutar un ejecutable que utiliza el intérprete de Perl de Windows, Perl intenta encontrar y ejecutar "cmd.exe" dentro del sistema operativo. Sin embargo, debido a problemas de orden de búsqueda en el PATH, Perl busca inicialmente cmd.exe en el directorio de trabajo actual.

Un atacante con privilegios limitados puede explotar este comportamiento colocando "cmd.exe" en ubicaciones con permisos débiles, como "C:\ProgramData". Al hacerlo, cuando un administrador intenta usar este ejecutable desde estas ubicaciones comprometidas, se puede ejecutar código arbitrario.

Agradecimientos

Perl 5.36.3 representa aproximadamente 1 mes de desarrollo desde Perl 5.36.1 y contiene aproximadamente 2.300 líneas de cambios en 38 archivos de 4 autores.

Excluyendo archivos autogenerados, documentación y herramientas de lanzamiento, hubo aproximadamente 1.400 líneas de cambios en 8 archivos .pm, .t, .c y .h.

Perl continúa floreciendo en su cuarta década gracias a una comunidad vibrante de usuarios y desarrolladores. Las siguientes personas han contribuido a las mejoras que se convirtieron en Perl 5.36.3:

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La lista anterior es casi con seguridad incompleta ya que se genera automáticamente a partir del historial del control de versiones. En particular, no incluye los nombres de los (muy apreciados) contribuyentes que informaron problemas en el rastreador de errores de Perl.

Reporte de Errores

Si encuentra lo que cree que es un error, puede consultar la base de datos de errores de perl en https://github.com/Perl/perl5/issues. También puede haber información en http://www.perl.org/, la página principal de Perl.

Si cree que tiene un error no reportado, por favor abra un ticket en https://github.com/Perl/perl5/issues. Asegúrese de reducir su error a un caso de prueba pequeño pero suficiente.

Si el error que está reportando tiene implicaciones de seguridad que hacen que no sea apropiado enviarlo a un rastreador de problemas público, consulte la sección "INFORMACIÓN DE CONTACTO DE VULNERABILIDADES DE SEGURIDAD" en perlsec para obtener detalles sobre cómo informar el problema.

Dar Gracias

Si desea agradecer a los Perl 5 Porters por el trabajo realizado en Perl 5, puede hacerlo ejecutando el programa "perlthanks":

perlthanks

Esto enviará un correo electrónico a la lista de Perl 5 Porters con su muestra de agradecimiento.
