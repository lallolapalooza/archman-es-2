PERF-ANNOTATE(1) Manual de perf PERF-ANNOTATE(1)

NOMBRE

perf-annotate - Leer perf.data (creado por perf record) y mostrar código anotado

SINOPSIS

perf annotate [-i <archivo> | --input=archivo] [nombre_símbolo]

DESCRIPCIÓN

Este comando lee el archivo de entrada y muestra una versión anotada del código. Si el archivo objeto tiene símbolos de depuración, se mostrará el código fuente junto al código ensamblador.

Si no hay información de depuración en el objeto, se muestra código ensamblador anotado.

OPCIONES

-i, --input=<archivo>

Nombre del archivo de entrada. (por defecto: perf.data a menos que stdin sea una tubería)

-d, --dsos=<dso[,dso...]>

Considerar solo símbolos en estos dsos.

-s, --symbol=<símbolo>

Símbolo a anotar.

-f, --force

No realizar validación de propiedad.

-v, --verbose

Ser más verboso. (Mostrar dirección del símbolo, etc.)

-q, --quiet

No mostrar advertencias ni mensajes. (Suprime -v)

-n, --show-nr-samples

Mostrar el número de muestras para cada símbolo.

-D, --dump-raw-trace

Volcar rastreo sin procesar en ASCII.

-k, --vmlinux=<archivo>

Ruta del archivo vmlinux.

--ignore-vmlinux

Ignorar archivos vmlinux.

--itrace

Opciones para decodificar datos de rastreo de instrucciones. Las opciones son: 
i       sintetizar eventos de instrucciones
y       sintetizar eventos de ciclos
b       sintetizar eventos de ramas
c       sintetizar eventos de ramas (solo llamadas)
r       sintetizar eventos de ramas (solo retornos)
x       sintetizar eventos de transacciones
w       sintetizar eventos ptwrite
p       sintetizar eventos de energía (incl. eventos PSB para Intel PT)
o       sintetizar otros eventos registrados debido al uso
        de salida aux (consultar perf record)
I       sintetizar interrupciones o eventos similares (asíncronos)
        (por ejemplo, Intel PT Event Trace)
e       sintetizar eventos de error
d       crear un registro de depuración
f       sintetizar eventos de caché de primer nivel
m       sintetizar eventos de caché de último nivel
M       sintetizar eventos de memoria
t       sintetizar eventos TLB
a       sintetizar eventos de acceso remoto
g       sintetizar una cadena de llamadas (usar con i o x)
G       sintetizar una cadena de llamadas en registros de eventos existentes
l       sintetizar entradas de rama de último nivel (usar con i o x)
L       sintetizar entradas de rama de último nivel en registros de eventos existentes
s       omitir el número inicial de eventos
q       decodificación más rápida (menos detallada)
A       IPC aproximado
Z       preferir ignorar las marcas de tiempo (decodificación llamada "sin tiempo")
T       usar el rastreo de marcas de tiempo como tiempo del kernel
El valor por defecto es todos los eventos, es decir, lo mismo que --itrace=iybxwpe,
excepto para perf script donde es --itrace=ce
Además, el período (por defecto 100000, excepto para perf script donde es 1)
para eventos de instrucciones se puede especificar en unidades de:
i       instrucciones
t       ticks
ms      milisegundos
us      microsegundos
ns      nanosegundos (por defecto)
También se puede especificar el tamaño de la cadena de llamadas (por defecto 16, máximo 1024) para eventos de instrucciones o transacciones.
También se puede especificar el número de entradas de rama de último nivel (por defecto 64, máximo 1024) para eventos de instrucciones o transacciones.
Similar a las opciones g y l, el tamaño también se puede especificar para las opciones G y L.
En x86, tenga en cuenta que G y L funcionan mal cuando los datos se han registrado con
PEBS grandes. Consulte la página del manual linkperf:perf-intel-pt[1] para obtener
detalles.
También es posible omitir los eventos generados (instrucciones, ramas, transacciones,
ptwrite, energía) al principio. Esto es útil para ignorar el código de inicialización.
--itrace=i0nss1000000
omite los primeros un millón de instrucciones.
La opción 'e' puede ir seguida de indicadores que afectan qué errores se informarán o no. Cada indicador debe ir precedido de '+' o '-'.
Los indicadores son:
        o       desbordamiento
        l       datos de rastreo perdidos
Si es compatible, la opción 'd' puede ir seguida de indicadores que afectan qué
mensajes de depuración se registrarán o no. Cada indicador debe ir precedido
por '+' o '-'. Los indicadores son:
        a       todos los eventos de perf
        e       salida solo en errores (tamaño configurable - ver linkperf:perf-config[1])
        o       salida a stdout
Si es compatible, la opción 'q' se puede repetir para aumentar el efecto.
Para deshabilitar completamente la decodificación, use --no-itrace.

-m, --modules

Cargar símbolos de módulos. ADVERTENCIA: usar solo con -k y el kernel EN VIVO.

-l, --print-line

Imprimir líneas de origen coincidentes (puede ser lento).

-P, --full-paths

No acortar las rutas mostradas.

--stdio

Usar la interfaz stdio.

--stdio2

Usar la interfaz stdio2, no interactiva, utiliza el formato TUI.

--stdio-color=<modo>

siempre, nunca o auto, permitiendo configurar la salida en color a través de la línea de comandos, además de a través de "color.ui" en perfconfig. Use --stdio-color siempre para generar color incluso al redirigir a una tubería o archivo. Usar solo --stdio-color es equivalente a usar siempre.

--tui

Usar la interfaz TUI. El uso de --tui requiere una tty; si no hay una, como al canalizar a otros comandos, se utiliza la interfaz stdio. Esta interfaz comienza centrándose en la línea con más muestras, TAB/UNTAB ciclaba a través de las líneas con más muestras.

--gtk

Usar la interfaz GTK.

-C, --cpu=<cpu>

Informar solo muestras para la lista de CPU proporcionadas. Se pueden proporcionar múltiples CPU como una lista separada por comas sin espacio: 0,1. Los rangos de CPU se especifican con -: 0-2. El valor por defecto es informar muestras en todas las CPU.

--asm-raw

Mostrar la codificación de instrucciones sin procesar de las instrucciones de ensamblaje.

--show-total-period

Mostrar una columna con la suma de los períodos.

--source

Intercalar el código fuente con el código ensamblador. Habilitado por defecto, deshabilitar con --no-source.

--symfs=<directorio>

Buscar archivos con símbolos relativos a este directorio.

-M, --disassembler-style=

Establecer el estilo del desensamblador para objdump.

--addr2line=<ruta>

Ruta al binario addr2line.

--objdump=<ruta>

Ruta al binario objdump.

--prefix=PREFIJO, --prefix-strip=N

Eliminar las primeras N entradas de las rutas de archivos fuente en los ejecutables y agregar PREFIJO. Esto permite mostrar código fuente compilado en sistemas con una disposición de archivos diferente.

--skip-missing

Omitir símbolos que no se pueden anotar.

--group

Mostrar información de grupos de eventos juntos.

--demangle

Deshacer el demangling de nombres de símbolos a una forma legible por humanos. Está habilitado por defecto, deshabilitar con --no-demangle.

--demangle-kernel

Deshacer el demangling de nombres de símbolos del kernel a una forma legible por humanos (para kernels C++).

--percent-type

Establecer el tipo de porcentaje de anotación a partir de las siguientes opciones: global-period, local-period, global-hits, local-hits 
Las palabras clave local/global establecen si el porcentaje se calcula
en el ámbito de la función (local) o en todos los datos (global).
Las palabras clave period/hits establecen la base sobre la que se calcula el porcentaje:
el período de las muestras o el número de muestras (hits).

--percent-limit

No mostrar funciones que tengan una sobrecarga inferior a este porcentaje en stdio o stdio2 (Por defecto: 0). Tenga en cuenta que esto se refiere a la selección de funciones a mostrar, no a las líneas dentro de la función.

--data-type[=NOMBRE_TIPO]

Mostrar anotación de tipo de datos en lugar de código. Infiere el tipo de datos de las muestras (si son instrucciones que acceden a memoria) utilizando información de depuración DWARF. Puede tomar un argumento opcional del nombre del tipo de datos. En ese caso, mostraría la anotación para el tipo.

perf-annotate(1) — perf — Arch Linux

NAME

perf-annotate

analizar datos de rendimiento

SYNOPSIS

perf-annotate [OPCIONES]

DESCRIPTION

perf-annotate es una herramienta para visualizar las anotaciones de rendimiento creadas por la herramienta perf-record(1). Permite analizar el código fuente y las instrucciones de ensamblaje para identificar cuellos de botella en el rendimiento.

OPTIONS

--objdump=cmd

Utiliza el comando especificado para obtener información de desensamblado. El valor predeterminado es “objdump”.

--dsos=dso_list

Lista de objetos compartidos separados por comas para mostrar. Si no se especifica, se mostrarán todos los objetos compartidos encontrados.

--syms=sym_list

Lista de símbolos separados por comas para mostrar. Si no se especifica, se mostrarán todos los símbolos encontrados.

--source

Mostrar el código fuente junto con la anotación.

--full-source

Mostrar la línea completa del código fuente.

--show-children

Mostrar las llamadas a funciones anidadas.

--demangle

Intentar desmanglear los nombres de los símbolos C++.

--show-line-in-symbol

Mostrar la línea de código fuente dentro de la anotación del símbolo.

--annotate-buildid

Anotar utilizando la información de buildid en lugar de rutas de archivos.

--header

Mostrar el encabezado de la información de rendimiento.

--stdio

Imprimir la salida en el formato especificado por el usuario.

--type=type

Filtrar por tipo de evento específico. Si no se especifica, se mostrarán todos los tipos de datos que encuentre.

--type-stat

Mostrar estadísticas para la anotación de tipo de dato.

--skip-empty

No mostrar eventos vacíos (o dummy).

--code-with-type

Mostrar información de tipo de dato en la anotación de código (solo para instrucciones de memoria). Actualmente, solo funciona con la opción --stdio.
