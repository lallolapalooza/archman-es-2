PERLREREF(1perl) Guía de Referencia para Programadores de Perl PERLREREF(1perl)

NOMBRE

perlreref - Referencia de expresiones regulares de Perl

DESCRIPCIÓN

Esta es una referencia rápida a las expresiones regulares de Perl. Para obtener información completa, consulte perlre y perlop, así como la sección "VER TAMBIÉN" de este documento.

OPERADORES

"=~" determina a qué variable se aplica la expresión regular. En su ausencia, se utiliza $_.

$var =~ /foo/;

"!~" determina a qué variable se aplica la expresión regular y niega el resultado de la coincidencia; devuelve falso si la coincidencia tiene éxito y verdadero si falla.

$var !~ /foo/;

"m/patrón/msixpogcduln" busca una coincidencia de patrón en una cadena, aplicando las opciones dadas.

m  Modo multilínea - ^ y $ coinciden con líneas internas
s  Coincidir como una sola línea - . coincide con \n
i  Ignorar mayúsculas/minúsculas
x  Legibilidad eXtensa - espacios en blanco y comentarios libres
p  Preservar una copia de la cadena coincidente -
   ${^PREMATCH}, ${^MATCH}, ${^POSTMATCH} se definirán.
o  Compilar patrón una vez
g  Global - todas las ocurrencias
c  no restablecer pos en coincidencias fallidas al usar /g
a  restringir \d, \s, \w y [:posix:] solo a coincidencias ASCII
aa (dos a) también las coincidencias /i excluyen ASCII/no ASCII
l  coincidir según la configuración regional actual
u  coincidir según las reglas de Unicode
d  coincidir según las reglas nativas a menos que algo indique
   Unicode
n  Modo de no captura. No dejes que () rellene $1, $2, etc...

Si 'patrón' es una cadena vacía, se utiliza la última expresión regular coincidente *exitosamente*. Se pueden usar delimitadores distintos de '/' tanto para este operador como para los siguientes. El "m" inicial se puede omitir si el delimitador es '/'.

"qr/patrón/msixpoduln" te permite almacenar una expresión regular en una variable o pasar una. Modificadores como para "m//", y se almacenan dentro de la expresión regular.

"s/patrón/reemplazo/msixpogcedul" sustituye las coincidencias de 'patrón' con 'reemplazo'. Modificadores como para "m//", con dos adiciones:

e  Evaluar 'reemplazo' como una expresión
r  Devolver la sustitución y dejar la cadena original intacta.

'e' se puede especificar varias veces. 'reemplazo' se interpreta como una cadena entre comillas dobles a menos que unas comillas simples ("'") sean el delimitador.

"m?patrón?" es como "m/patrón/" pero solo coincide una vez. No se pueden usar delimitadores alternativos. Debe restablecerse con reset().

SINTAXIS

\       Escapa el carácter inmediatamente siguiente
.       Coincide con cualquier carácter individual excepto una nueva línea (a menos que se use /s)
^       Coincide al principio de la cadena (o línea, si se usa /m)
$       Coincide al final de la cadena (o línea, si se usa /m)
*       Coincide con el elemento anterior 0 o más veces
+       Coincide con el elemento anterior 1 o más veces
?       Coincide con el elemento anterior 0 o 1 vez
{...}   Especifica un rango de ocurrencias para el elemento anterior
[...]   Coincide con cualquiera de los caracteres contenidos entre corchetes
(...)   Agrupa subexpresiones para capturar en $1, $2...
(?:...) Agrupa subexpresiones sin capturar (clúster)
|       Coincide con la subexpresión anterior o siguiente
\g1 o \g{1}, \g2 ...    Coincide con el texto del N-ésimo grupo
\1, \2, \3 ...           Coincide con el texto del N-ésimo grupo
\g-1 o \g{-1}, \g-2 ... Coincide con el texto del N-ésimo grupo anterior
\g{nombre}     Referencia posterior con nombre
\k<nombre>     Referencia posterior con nombre
\k'nombre'     Referencia posterior con nombre
(?P=nombre)    Referencia posterior con nombre (sintaxis python)

SECUENCIAS DE ESCAPADO

Funcionan como en las cadenas normales.

\a       Alarma (pitido)
\e       Escape
\f       Avance de página
\n       Nueva línea
\r       Retorno de carro
\t       Tabulación
\037     Carácter cuya ordinal es los 3 dígitos octales, máximo \777
\o{2307} Carácter cuya ordinal es el número octal, sin restricciones
\x7f     Carácter cuya ordinal es los 2 dígitos hexadecimales, máximo \xFF
\x{263a} Carácter cuya ordinal es el número hexadecimal, sin restricciones
\cx      Control-x
\N{nombre} Un carácter o secuencia de caracteres Unicode con nombre
\N{U+263D} Un carácter Unicode por ordinal hexadecimal
\l  Minúscula del siguiente carácter
\u  Mayúscula inicial del siguiente carácter
\L  Minúsculas hasta \E
\U  Mayúsculas hasta \E
\F  Foldcase hasta \E
\Q  Desactivar metacaracteres de patrón hasta \E
\E  Fin de modificación

Para mayúsculas iniciales, consulte "Titlecase".

Este funciona de manera diferente a las cadenas normales:

\b  Una afirmación, no retroceso, excepto en una clase de caracteres

CLASES DE CARACTERES

[amy]    Coincide con 'a', 'm' o 'y'
[f-j]    El guión especifica un "rango"
[f-j-]   El guión escapado o al principio o al final significa 'guión'
[^f-j]   El acento circunflejo indica "coincidir con cualquier carácter *excepto* estos"

Las siguientes secuencias (excepto "\N") funcionan dentro o fuera de una clase de caracteres. Las seis primeras dependen de la configuración regional, todas dependen de Unicode. Consulte perllocale y perlunicode para obtener detalles.

\d      Un dígito
\D      No un dígito
\w      Un carácter de palabra
\W      No un carácter de palabra
\s      Un carácter de espacio en blanco
\S      No un carácter de espacio en blanco
\h      Un espacio en blanco horizontal
\H      No un espacio en blanco horizontal
\N      No una nueva línea (cuando no seguido de '{NOMBRE}';
        no válido en una clase de caracteres; equivalente a [^\n]; es
        como '.' sin modificador /s)
\v      Un espacio en blanco vertical
\V      No un espacio en blanco vertical
\R      Una nueva línea genérica           (?>\x0D\x0A|\v)
\pP     Coincide con la propiedad Unicode con nombre P
\p{...} Coincide con la propiedad Unicode con nombre de más de 1 carácter
\PP     Coincide con no P
\P{...} Coincide con la falta de propiedad Unicode con nombre de más de 1 carácter
\X      Coincide con un clúster de grafemas extendido de Unicode

                                                  punct fuera de él

Además, varios sinónimos como "\p{Alpha}" para "\p{XPosixAlpha}"; todos listados en "Propiedades accesibles a través de \p{} y \P{}" en perluniprops

Dentro de una clase de caracteres:

  POSIX      tradicional   Unicode
[:digit:]       \d        \p{Digit}
[:^digit:]      \D        \P{Digit}

ANCLAS

Todas son afirmaciones de ancho cero.

^  Coincide con el inicio de la cadena (o línea, si se usa /m)
$  Coincide con el final de la cadena (o línea, si se usa /m) o antes de una nueva línea
\b{} Coincide con el límite del tipo especificado entre llaves
\B{} Coincide donde \b{} no coincide
\b Coincide con el límite de palabra (entre \w y \W)
\B Coincide excepto en el límite de palabra (entre \w y \w o \W y \W)
\A Coincide con el inicio de la cadena (independientemente de /m)
\Z Coincide con el final de la cadena (antes de una nueva línea opcional)
\z Coincide con el final absoluto de la cadena
\G Coincide donde el m//g anterior se detuvo
\K Conserva lo que está a la izquierda de \K, no lo incluye en $&

NAME

perlreref - Perl regular expression reference

DESCRIPTION

This document provides a quick reference to Perl's regular expression syntax.

CUANTIFICADORES

Los cuantificadores son codiciosos por defecto y coinciden con la forma más larga de la izquierda.

Máximo Mínimo Posesivo Rango permitido
------- ------- ---------- -------------
{n,m}   {n,m}?  {n,m}+     Debe ocurrir al menos n veces
                           pero no más de m veces
{n,}    {n,}?   {n,}+      Debe ocurrir al menos n veces
{,n}    {,n}?   {,n}+      Debe ocurrir como máximo n veces
{n}     {n}?    {n}+       Debe ocurrir exactamente n veces
*       *?      *+         0 o más veces (igual que {0,})
+       +?      ++         1 o más veces (igual que {1,})
?       ??      ?+         0 o 1 vez (igual que {0,1})

Las formas posesivas (nuevas en Perl 5.10) evitan el retroceso: lo que coincide con un patrón con un cuantificador posesivo no retrocederá, incluso si eso causa que la coincidencia completa falle.

CONSTRUCTOS EXTENDIDOS

(?#texto)          Un comentario
(?:...)           Agrupa subexpresiones sin capturar (clúster)
(?pimsx-imsx:...) Habilita/deshabilita opción (como en los modificadores m//)
(?=...)           Aserción de lookahead positivo de ancho cero
(*pla:...)        Igual, a partir de 5.32; experimentalmente en 5.28
(*positive_lookahead:...) Igual, mismas versiones que *pla
(?!...)           Aserción de lookahead negativo de ancho cero
(*nla:...)        Igual, a partir de 5.32; experimentalmente en 5.28
(*negative_lookahead:...) Igual, mismas versiones que *nla
(?<=...)          Aserción de lookbehind positivo de ancho cero
(*plb:...)        Igual, a partir de 5.32; experimentalmente en 5.28
(*positive_lookbehind:...) Igual, mismas versiones que *plb
(?<!...)          Aserción de lookbehind negativo de ancho cero
(*nlb:...)        Igual, a partir de 5.32; experimentalmente en 5.28
(*negative_lookbehind:...) Igual, mismas versiones que *nlb
(?>...)           Captura lo que pueda, prohíbe el retroceso
(*atomic:...)     Igual, a partir de 5.32; experimentalmente en 5.28
(?|...)           Reinicio de rama
(?<name>...)      Captura nombrada
(?'name'...)      Captura nombrada
(?P<name>...)     Captura nombrada (sintaxis de python)
(?[...])          Clase de caracteres entre corchetes extendida
(?{ código })       Código incrustado, el valor de retorno se convierte en $^R
(??{ código })      Expresión regular dinámica, el valor de retorno se usa como expresión regular
(?N)              Recursiona en el subpatrón número N
(?-N), (?+N)      Recursiona en el N-ésimo subpatrón anterior/siguiente
(?R), (?0)        Recursiona al principio del patrón completo
(?&name)          Recursiona en un subpatrón nombrado
(?P>name)         Recursiona en un subpatrón nombrado (sintaxis de python)
(?(cond)yes|no)
(?(cond)yes)      Expresión condicional, donde "(cond)" puede ser:
                  (?=pat)   lookahead; también (*pla:pat)
                            (*positive_lookahead:pat)
                  (?!pat)   lookahead negativo; también (*nla:pat)
                            (*negative_lookahead:pat)
                  (?<=pat)  lookbehind; también (*plb:pat)
                            (*lookbehind:pat)
                  (?<!pat)  lookbehind negativo; también (*nlb:pat)
                            (*negative_lookbehind:pat)
                  (N)       el subpatrón N ha coincidido con algo
                  (<name>)  el subpatrón nombrado ha coincidido con algo
                  ('name')  el subpatrón nombrado ha coincidido con algo
                  (?{code}) condición de código
                  (R)       verdadero si se está recursando
                  (RN)      verdadero si se está recursando en el subpatrón N
                  (R&name)  verdadero si se está recursando en el subpatrón nombrado
                  (DEFINE)  siempre falso, no se permite patrón no

VARIABLES

$_    Variable por defecto para que la usen los operadores
$`    Todo lo anterior a la cadena coincidente
$&    Cadena coincidente completa
$'    Todo lo posterior a la cadena coincidente
${^PREMATCH}   Todo lo anterior a la cadena coincidente
${^MATCH}      Cadena coincidente completa
${^POSTMATCH}  Todo lo posterior a la cadena coincidente

Nota para quienes todavía usan Perl 5.18 o anterior: El uso de "$`", $& o "$'" ralentizará todos los usos de expresiones regulares en su programa. Consulte perlvar para "@-" para ver expresiones equivalentes que no causen una ralentización. Vea también Devel::SawAmpersand. A partir de Perl 5.10, también puede usar las variables equivalentes "${^PREMATCH}", "${^MATCH}" y "${^POSTMATCH}", pero para que estén definidas, debe especificar el modificador "/p" (preserve) en su expresión regular. En Perl 5.20, el uso de "$`", $& y "$'" no produce ninguna diferencia de velocidad.

$1, $2 ...  contienen la X-ésima expresión capturada
$+    Última coincidencia de patrón entre paréntesis
$^N   Contiene la captura cerrada más reciente
$^R   Contiene el resultado de la última expresión (?{...})
@-    Desplazamientos de los inicios de los grupos. $-[0] contiene el inicio de la coincidencia completa
@+    Desplazamientos de los finales de los grupos. $+[0] contiene el final de la coincidencia completa
%+    Grupos de captura nombrados
%-    Grupos de captura nombrados, como referencias a arreglos

Los grupos capturados se numeran según su paréntesis de apertura.

FUNCIONES

lc          Convierte una cadena a minúsculas
lcfirst     Convierte el primer carácter de una cadena a minúsculas
uc          Convierte una cadena a mayúsculas
ucfirst     Convierte el primer carácter de una cadena a mayúsculas (iniciales)
fc          Convierte una cadena a mayúsculas/minúsculas de plegado
pos         Devuelve o establece la posición de coincidencia actual
quotemeta   Escapa metacaracteres (anula su significado normal)
reset       Reinicia el estado del patrón m?pattern?
study       Analiza la cadena para optimizar la coincidencia
split       Usa una expresión regular para dividir una cadena en partes

Las cinco primeras de estas son como las secuencias de escape "\L", "\l", "\U", "\u" y "\F". Para las mayúsculas iniciales, consulte "Titlecase"; Para las mayúsculas/minúsculas de plegado, consulte "Foldcase".

TERMINOLOGÍA

Titlecase (Mayúsculas iniciales)

Concepto de Unicode que la mayoría de las veces es igual a mayúsculas, pero para ciertos caracteres como la "s sharp" alemana existe una diferencia.

Foldcase (Mayúsculas/minúsculas de plegado)

Forma de Unicode que es útil al comparar cadenas independientemente de mayúsculas/minúsculas, ya que ciertos caracteres tienen complejas correspondencias de mayúsculas/minúsculas uno a muchos. Principalmente una variante de minúsculas.
