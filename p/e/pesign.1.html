PESIGN(1) Manual de Comandos Generales PESIGN(1)

NOMBRE

pesign — herramienta para firmar aplicaciones UEFI

SINOPSIS

pesign -i archivo [-o archivo] [-f] [-n directorio] [-t token] [-c apodo] [-u número] [-m archivo] [-e archivo] [-I archivo] [-E archivo] [-R archivo] [-K archivo] [-C archivo] [-a] [-l] [-S] [-v] ⟨-s | -D [-N] | -r | -h [-d digest] [-P | -p]⟩

DESCRIPCIÓN

pesign es una herramienta de línea de comandos para manipular firmas y resúmenes criptográficos de aplicaciones UEFI.

OPCIONES

-i archivo | --in archivo
Archivo PE de entrada archivo para firmar
-o archivo | --out archivo
Archivo PE de salida archivo para firmar
-f | --force
Sobrescribir el archivo existente especificado con --out
-n directorio | --certdir directorio
Usar la Base de Datos NSS en el directorio (por defecto: /etc/pki/pesign)
-t token | --token token
Usar el token NSS llamado token
-c apodo | --certificate apodo
Usar el certificado llamado apodo en la Base de Datos NSS
-u número | --signature-number número
Número de firma, indexado desde 0, para usar con --remove-signature, --export-signature, o --show-signature (por defecto: 0)
-m archivo | --import-signature archivo
Importar firma Authenticode desde el archivo
-e archivo | --export-signature archivo
Exportar firma Authenticode al archivo
-I archivo | --import-signed-attributes archivo
Importar SignedAttributes PKCS-7 (sin firma) desde el archivo
-E archivo | --export-signed-attributes archivo
Exportar SignedAttributes PKCS-7 (sin firma) al archivo
-R archivo | --import-raw-signature archivo
Importar el resumen de firma desde el archivo
-K archivo | --export-pubkey archivo
Exportar la clave pública desde la Base de Datos NSS especificada por --token y --certificate al archivo
-C archivo | --export-cert archivo
Exportar el certificado desde la Base de Datos NSS especificada por --token y --certificate al archivo
-a | --ascii-armor
Al exportar certificados, codificarlos en ascii-armor
-l | --list-signatures
Listar firmas
-S | --show-signature
Mostrar información sobre las firmas
-v | --verbose
Ser más verboso
-s | --sign
Crear una nueva firma
-D | --daemonize
Ejecutar como un demonio
-N | --nofork
No bifurcar al ejecutar como demonio (el demonio se ejecuta en primer plano)
-r | --remove-signature
Eliminar firma
-h | --hash
Mostrar el resumen (hash) Authenticode del binario
-d digest | --digest-type digest
Usar el digest criptográfico con --hash (usar help para listar opciones) (por defecto: sha256)
-P | --padding |

NOMBRE

pesign - Firmar un archivo PE con un certificado de clave pública

SINOPSIS

pesign [ -h | --help ] [ -v | --version ] [ -c NAME | --cert NAME ] [ -t TOKEN | --token TOKEN ] [ -k KEYFILE | --key KEYFILE ] [ -C CERTFILE | --certfile CERTFILE ] [ -W PIN | --pin PIN ] [ -E OUTFILE | --export-attrs OUTFILE ] [ -R SIGFILE | --sigfile SIGFILE ] [ -I ATTRFILE | --attrsfile ATTRFILE ] [ -s | --sign ] [ -a | --add-signature ] [ -p | --padding ] [ --nopadding ] -i INFILE -o OUTFILE

DESCRIPCIÓN

La utilidad pesign firma archivos PE (Portable Executable) de Windows, que incluyen archivos .exe, .dll, .sys y .efi.

Para firmar un archivo PE, pesign utiliza el protocolo de firma de Authenticode de Microsoft. El proceso de firma se basa en el estándar PKCS #7 y se documenta en la referencia de Microsoft.

La firma es opcional, pero se recomienda encarecidamente para evitar advertencias de seguridad al ejecutar o instalar software en sistemas Windows. La firma también es necesaria para ciertos tipos de controladores y firmware.

La clave privada utilizada para la firma puede ser de un archivo PKCS #12, un módulo PKCS #11 (como un dispositivo HSM o una tarjeta inteligente) o un archivo PEM.

La base de datos de claves NSS se utiliza para almacenar certificados y claves privadas, y para acceder a los módulos PKCS #11.

Las siguientes opciones están disponibles:

-c NAME | --cert NAME
Especifica el nombre del certificado que se utilizará para firmar el archivo. Si el certificado se encuentra en la base de datos NSS, se puede referenciar por su nombre o alias. Si se utiliza un módulo PKCS #11, este nombre se utilizará para identificar el token y el certificado dentro de él.
-t TOKEN | --token TOKEN
Especifica el nombre del token PKCS #11 que contiene la clave privada y el certificado. Esto se utiliza para acceder a módulos como HSMs o tarjetas inteligentes. El nombre del token se puede obtener de la salida de modutil -list.
-k KEYFILE | --key KEYFILE
Especifica el archivo PEM que contiene la clave privada. Se recomienda proteger este archivo con una contraseña.
-C CERTFILE | --certfile CERTFILE
Especifica el archivo PEM que contiene el certificado público. Esto es necesario si la clave privada no está en un formato que incluya el certificado (como PKCS #12).
-W PIN | --pin PIN
Especifica la contraseña o PIN para acceder a la clave privada o al token PKCS #11. Si no se proporciona, pesign solicitará la contraseña.
-E OUTFILE | --export-attrs OUTFILE
Exporta los atributos de firma (por ejemplo, la información de PKCS #7) a un archivo especificado. Esto es útil para firmar fuera de línea o para depuración.
-R SIGFILE | --sigfile SIGFILE
Importa un archivo de firma previamente generado. Esto se usa en combinación con -I para añadir una firma existente a un archivo PE.
-I ATTRFILE | --attrsfile ATTRFILE
Importa un archivo de atributos de firma previamente generado. Esto se usa en combinación con -R para añadir una firma existente a un archivo PE.
-s | --sign
Realiza la firma del archivo PE de entrada utilizando el certificado y la clave especificados. Si se usa con -E, solo se exportan los atributos de firma sin firmar el archivo PE.
-a | --add-signature
Añade una firma preexistente a un archivo PE. Esto requiere que los atributos de firma y la firma en sí se hayan generado previamente y se especifiquen con las opciones -I y -R respectivamente.
-i INFILE
Archivo PE de entrada que se va a firmar o modificar.
-o OUTFILE
Archivo PE de salida. Si se omite, se modificará el archivo de entrada in situ.
-p | --padding
Rellena el archivo binario según las reglas de PE 9.3 antes de firmarlo o hashearlo (por defecto: --padding).
--nopadding
No rellena el archivo binario según las reglas de PE 9.3 antes de firmarlo o hashearlo (por defecto: --padding).

Se recomienda el relleno (y en muchas circunstancias es necesario) incluso para binarios que son anteriores a la especificación PE actual, y está habilitado por defecto a partir de pesign 113.

EJEMPLOS

Firmar con el certificado y la clave privada en archivos individuales

Si tiene un archivo de certificado y un archivo de clave privada, los siguientes pasos se pueden utilizar para firmar una imagen PE:

# Crear un archivo pkcs12 a partir de la clave privada y el archivo de certificado.
host:~$ openssl pkcs12 -export -out foo_key.p12 \
        -inkey signing_key.pem -in xyz_cert.x509.pem

# Importar el archivo pkcs12 en la base de datos de pesign
host:~$ pk12util -i foo_key.p12 -d /etc/pki/pesign

# Realizar la firma
host:~$ pesign -c my-signing-cert -s \
        -i foo.unsigned.efi -o foo.signed.efi

Tenga en cuenta que este es solo un ejemplo y que la mejor práctica recomendada es almacenar siempre las claves privadas en un *Módulo de seguridad de hardware* (HSM) FIPS 140-2, nivel 2 o superior.

Firmar usando un HSM

Si tiene un par de claves en su HSM y su proveedor de HSM proporciona una biblioteca PKCS-11, puede usarla directamente con NSS:

# Añadir la biblioteca PKCS#11 del HSM a la base de datos NSS
host:~$ modutil -dbdir /etc/pki/pesign -add vendor-engine \
        -libfile /usr/lib64/pkcs11/vendor-engine.so

Firmar usando un HSM con un motor OpenSSL

Si tiene un par de claves en su HSM pero no puede acceder a él directamente, pero sí tiene acceso a la utilidad de línea de comandos openssl configurada con las bibliotecas de su proveedor, aún puede usar pesign para firmar sus binarios PE:

# Importar el certificado público en la base de datos NSS
host:~$ certutil -d /etc/pki/pesign -A -n myorg-sb-signer \
        -t ,,u -i myorg-sb-signer.cer

# Exportar la sección SignedAttributes de PKCS#7 que genera pesign
host:~$ pesign -i foo.unsigned.efi -E foo.sattrs.bin

# Generar una firma usando OpenSSL
host:~$ openssl dgst -sha256 -sign $KEY \
        --keyform ENGINE --engine $ENGINEID \
        -out foo.sattrs.sig foo.sattrs.bin

# Importar la firma con los SignedAttributes originales en
# el binario PE
host:~$ pesign -c myorg-sb-signer \
        -R foo.sattrs.sig -I foo.sattrs.bin \
        -i foo.unsigned.efi -o foo.efi
