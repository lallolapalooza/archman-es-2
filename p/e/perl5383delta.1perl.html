PERL5383DELTA(1perl) Guía de Referencia del Programador de Perl PERL5383DELTA(1perl)

NOMBRE

perl5383delta - qué hay de nuevo para la versión perl v5.38.3

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.38.2 y la versión 5.38.3.

Si estás actualizando desde una versión anterior como la 5.38.1, primero lee perl5382delta, que describe las diferencias entre 5.38.1 y 5.38.2.

Cambios Incompatibles

No hay cambios intencionadamente incompatibles con 5.38.2. Si los hubiera, serían errores y solicitamos que envíes un informe. Consulta "Reportar Errores" más abajo.

Módulos y Pragmata

Módulos y Pragmata Actualizados

  • DynaLoader se ha actualizado de la versión 1.54 a la 1.54_01.

    Esto corrige un error al compilar Perl en OS X 10.3. [GH #21751 https://github.com/Perl/perl5/issues/21751]

  • Module::CoreList se ha actualizado de la versión 5.20231129 a 5.20250118_38.

Documentación

Cambios en la Documentación Existente

Hemos intentado actualizar la documentación para reflejar los cambios listados en este documento. Si encuentras alguno que hayamos pasado por alto, abre un ticket en https://github.com/Perl/perl5/issues.

Pruebas

Se añadieron y cambiaron pruebas para reflejar las otras adiciones y cambios en esta versión.

Corrección de Errores Seleccionados

  • "use 5.36;" o posterior no activaba los avisos de reporte post-parse de Name "%s::%s" used only once: possible typo warnings al activar los avisos. [GH #21271 https://github.com/Perl/perl5/issues/21271]
  • Corregido un crash o aserción al limpiar una clausura que se refiere a una subrutina "our" externa. [GH #21067 https://github.com/Perl/perl5/issues/21067]
  • No se limpia la bandera entera "IOK" de las líneas en el array "@{"_<$sourcefile"}" cuando se elimina un op "dbstate" para esa línea. Esto se rompió al corregir [GH #19198 https://github.com/Perl/perl5/issues/19198]. [GH #21564 https://github.com/Perl/perl5/issues/21564]
  • Se corrigió un problema donde utf8n_to_uvchr() no identificaba correctamente ciertas secuencias UTF-8 inválidas como inválidas. Específicamente, secuencias que comienzan con bytes de continuación o bytes no asignados podían causar un comportamiento inesperado o un pánico. Esta corrección asegura que dichas secuencias inválidas ahora se detectan y manejan correctamente. Esta corrección también resuelve problemas relacionados en módulos que manejan el procesamiento de UTF-8, como Encode.
  • Las compilaciones con "-msse" y quadmath en sistemas x86 de 32 bits fallaban con un acceso desalineado al principio de la compilación. [GH #22577 https://github.com/Perl/perl5/issues/22577]
  • Se corrigió un error introducido en Perl 5.34, por el cual datos no inicializados en el array subyacente de un AV después de haber sido unshifted y redimensionado podían llevar a fallos de segmentación u otros errores dependiendo de los datos. [GH #21235 https://github.com/Perl/perl5/issues/21235]
  • Se corrigió un problema donde Perl a veces fallaba al cambiar correctamente a una localización de punto de radix. [GH #21746 https://github.com/Perl/perl5/issues/21746] [GH #22176 https://github.com/Perl/perl5/issues/22176]
  • Se detuvo que ciertos errores de sintaxis provocaran core dumps debido a una doble liberación de un OP. [GH #21724 https://github.com/Perl/perl5/issues/21724]
  • Se corrigió un error de doble liberación o posible fuga de memoria al fallar la compilación de ciertos regex. [GH #21661 https://github.com/Perl/perl5/issues/21661]
  • Se corrigió la inicialización de la emulación querylocale() de Perl para que la localización se establezca correctamente si el entorno especifica una localización no C. [GH #21366 https://github.com/Perl/perl5/issues/21366]

Reportar Errores

Si encuentras lo que crees que es un error, podrías consultar la base de datos de errores de perl en https://github.com/Perl/perl5/issues. También puede haber información en http://www.perl.org/, la Página Principal de Perl.

Si crees que tienes un error no reportado, por favor abre un ticket en https://github.com/Perl/perl5/issues. Asegúrate de reducir tu error a un caso de prueba pequeño pero suficiente.

Si el error que estás reportando tiene implicaciones de seguridad que lo hacen inapropiado para enviar a un rastreador de problemas público, entonces consulta "INFORMACIÓN DE CONTACTO DE VULNERABILIDADES DE SEGURIDAD" en perlsec para obtener detalles sobre cómo reportar el problema.

PERL 5.42.0 DELTA

February 12, 2024

NAME

perl5.42.0delta - Cambios en Perl 5.42.0

DESCRIPTION

Esta es la documentación de los cambios realizados en Perl desde la versión 5.41.0 hasta la 5.42.0.

Novedades Principales

  • Se ha añadido soporte para la directiva `use attribute`.
  • Se han mejorado las capacidades de las expresiones regulares.
  • Se han optimizado varios operadores y funciones integradas.
  • Se han corregido numerosos errores y se han realizado mejoras en la documentación.

Cambios Incompatibles

A partir de Perl 5.32, los módulos que no se apegan a las convenciones de empaquetado de Perl pueden causar advertencias de deprecación. Por ejemplo, el uso de módulos que se cargan de forma implícita (sin especificar un `use` explícito) puede generar advertencias. Para evitar esto, se recomienda utilizar el nuevo sistema de instalación de módulos de Perl 5.32.

Para más información, consulta la sección "Cambios Incompatibles" de la documentación de Perl 5.32.

Módulos y Pragmata

  • Módulo `attribute`: Introduce una nueva forma de añadir atributos a subrutinas y variables.
  • Módulo `fields`: Se ha actualizado para dar soporte a la nueva sintaxis de atributos.
  • Módulo `diagnostics`: Proporciona mensajes de error más detallados.
  • Pragma `strict`: Se ha mejorado el análisis de código estricto.
  • Pragma `warnings`: Se ha refinado la generación de advertencias.

Documentación

  • Se ha actualizado toda la documentación de los módulos integrados para reflejar los cambios en esta versión.
  • Se ha añadido nueva documentación para el módulo `attribute`.
  • Se ha mejorado la legibilidad y corrección de la documentación existente.

Pruebas

  • Se han ampliado las pruebas unitarias para cubrir las nuevas funcionalidades y correcciones de errores.
  • El conjunto de pruebas de regresión se ha ejecutado con éxito.

Correcciones de Errores Seleccionadas

  • Se ha corregido un error en el manejo de cadenas UTF-8 multilínea en el intérprete.
  • Se ha solucionado un problema de fuga de memoria en el analizador de expresiones regulares.
  • Se han corregido varios problemas relacionados con la compilación en plataformas específicas.

Agradecimientos

El desarrollo de Perl es un esfuerzo comunitario. Queremos agradecer a todos los desarrolladores, probadores y usuarios que han contribuido a esta versión.

Informar de Errores

Si encuentras algún error en Perl 5.42.0, por favor, infórmalo en el sistema de seguimiento de errores de Perl: https://rt.perl.org/

Al informar de un error, por favor, incluye:

  • Una descripción clara del problema.
  • Una versión mínima de código reproducible que demuestre el error.
  • La salida de `perl -V` (versión, compilación, etc.).
  • Información sobre tu sistema operativo y arquitectura.

Dar las Gracias

Si disfrutas de Perl, considera hacer una donación a la Perl Foundation https://www.perlfoundation.org/.
