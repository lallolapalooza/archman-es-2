NOMBRE

perlos400 - Versión 5 de Perl en OS/400

Este documento necesita ser actualizado, pero no sabemos qué debería decir. Por favor, envíe sus comentarios a https://github.com/Perl/perl5/issues.

DESCRIPCIÓN

Este documento describe varias características del sistema operativo OS/400 de IBM que afectarán a cómo se compila y/o ejecuta la versión 5 de Perl (en adelante, Perl).

La forma más fácil de compilar Perl para OS/400 es usar PASE (Portable Application Solutions Environment). Para más información, consulte http://www.iseries.ibm.com/developer/factory/pase/index.html. Este entorno permite usar APIs de AIX mientras se programa y proporciona un entorno de ejecución que permite ejecutar binarios de AIX directamente en el iSeries PowerPC.

Compilación de Perl para OS/400 PASE

La forma recomendada de compilar Perl para el PASE de OS/400 es compilar el código fuente de Perl 5 (versión 5.8.1 o posterior) bajo AIX.

El truco consiste en pasar un parámetro especial al script Configure al ejecutarlo en AIX:

sh Configure -DPASE ...

El directorio de instalación predeterminado de Perl bajo PASE es /QOpenSys/perl. Esto se puede modificar si es necesario con el parámetro de Configure -Dprefix=/algún/directorio.

A partir de OS/400 V5R2, el compilador IBM Visual Age es compatible con OS/400 PASE, por lo que es posible compilar Perl de forma nativa en OS/400. Sin embargo, la forma más fácil es compilar en AIX, como se ha descrito anteriormente.

Si no desea instalar el Perl compilado en AIX en /QOpenSys (para empaquetarlo antes de copiarlo a PASE), puede usar un parámetro de Configure: -Dinstallprefix=/tmp/QOpenSys/perl. Esto hará que "make install" instale todo en ese directorio, mientras que los archivos instalados seguirán pensando que están (estarán) en /QOpenSys/perl.

Si compila de forma nativa en PASE, por favor, realice la compilación dentro del directorio /QOpenSys, ya que Perl funciona mejor cuando se compila en un sistema de archivos sensible a mayúsculas y minúsculas.

Instalación de Perl en OS/400 PASE

Si está compilando en AIX, simplemente ejecute "make install" en la máquina AIX. Una vez que la instalación finalice, empaquete el directorio /QOpenSys/perl con tar. Transfiera el archivo tar a OS/400 usando FTP con los siguientes comandos:

> binary
> site namefmt 1
> put perl.tar /QOpenSys

Una vez que lo tenga, simplemente inicie un shell PASE y extraiga el archivo tar.

Si está compilando en PASE, entonces "make install" es lo único que necesitará hacer.

La ruta predeterminada para el binario de perl es /QOpenSys/perl/bin/perl. Querrá crear un enlace simbólico de /QOpenSys/usr/bin/perl a este archivo para no tener que modificar su ruta.

Uso de Perl en OS/400 PASE

Perl en PASE se puede usar de la misma manera que usaría Perl en AIX.

Los scripts que comienzan con #!/usr/bin/perl deberían funcionar si ha creado un enlace simbólico de /QOpenSys/usr/bin/perl a su binario de perl. Esto no funcionará si ha realizado un setuid/setgid o tiene la variable de entorno PASE_EXEC_QOPENSYS="N". Si tiene V5R1, necesitará obtener los últimos PTF para tener esta funcionalidad. Los scripts que comienzan con #!/QOpenSys/perl/bin/perl siempre deberían funcionar.

Problemas conocidos

Al compilar en PASE, no existe el comando "oslevel". Por lo tanto, es posible que desee crear un script llamado "oslevel" que muestre el nivel de AIX que soporta su versión del entorno de ejecución PASE. Si no está seguro, consulte su documentación o use "4.3.3.0".

Si tiene casos de prueba que fallan, compruebe la existencia de archivos de spool. El caso de prueba puede estar intentando usar una llamada al sistema (syscall) que no está implementada en PASE. Para evitar SIGILL, intente establecer la variable de entorno PASE_SYSCALL_NOSIGILL o tenga un manejador para SIGILL. Si puede compilar programas para PASE, ejecute el script de configuración y edite config.sh cuando le ofrezca la opción. Si desea eliminar fchdir(), que no está implementado en V5R1, simplemente cambie la línea que dice:

d_fchdir='define'

a

d_fchdir='undef'

y luego compile Perl. Los lugares donde se usa fchdir() tienen alternativas para sistemas que no tienen fchdir() disponible.

Perl en ILE

Existe un puerto de Perl al entorno ILE. Sin embargo, este puerto se basa en una versión bastante antigua de Perl, Perl 5.00502 (agosto de 1998). (A fecha de julio de 2002, la última versión de Perl es la 5.8.0, e incluso la 5.6.1 está disponible desde abril de 2001). Si necesita ejecutar Perl en ILE, es posible que necesite este puerto más antiguo: http://www.cpan.org/ports/#os400. Tenga en cuenta que cualquier versión de Perl posterior a la 5.00502 no ha sido portada a ILE.

Si necesita usar Perl en el entorno ILE, podría considerar usar Qp2RunPase() para llamar a la versión PASE de Perl.
