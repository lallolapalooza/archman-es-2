NOMBRE

perltw - Guía de Perl en chino tradicional

DESCRIPCIÓN

¡Bienvenido al mundo de Perl!

Desde la versión 5.8.0, Perl cuenta con un soporte completo de Unicode, y también incluye soporte para muchas codificaciones distintas de las lenguas latinas; CJK (chino, japonés y coreano) es una de ellas. Unicode es un estándar internacional que intenta abarcar todos los caracteres del mundo: el mundo occidental, el mundo oriental y todo lo que hay entre ambos (hebreo, cirílico, árabe, griego, hindi, devanagari, etc.). También admite diversos sistemas operativos y plataformas (como PC y Macintosh).

Perl opera internamente con Unicode. Esto significa que los datos de cadena dentro de Perl pueden representarse en Unicode; las funciones y operadores de Perl (por ejemplo, la coincidencia de expresiones regulares) también pueden operar sobre Unicode. Al leer y escribir, para manejar datos almacenados en codificaciones anteriores a Unicode, Perl proporciona el módulo Encode, que te permite leer y escribir fácilmente datos en codificaciones antiguas.

La extensión del módulo Encode admite las siguientes codificaciones de chino tradicional ('big5' significa 'big5-eten'):

big5-eten   Codificación Big5 (incluye glifos de extensión de Eten)
big5-hkscs  Big5 + conjunto de caracteres externos de Hong Kong, versión de 2001
cp950       Página de códigos 950 (Big5 + caracteres añadidos por Microsoft)

Por ejemplo, para convertir un archivo codificado en Big5 a Unicode, basta con introducir la siguiente orden:

perl -MEncode -pe '$_= encode( utf8 => decode( big5 => $_ ) )' \
  < file.big5 > file.utf8

Perl también incluye "piconv", una herramienta de conversión de caracteres escrita completamente en Perl, cuyo uso es el siguiente:

piconv -f big5 -t utf8 < file.big5 > file.utf8
piconv -f utf8 -t big5 < file.utf8 > file.big5

Además, si el propio código del programa se almacena en codificación utf8, junto con el uso del módulo utf8, se puede hacer que las cadenas del código del programa y sus operaciones se basen en caracteres en lugar de en unidades de byte, como se muestra a continuación:

#!/usr/bin/env perl
use utf8;
print length("駱駝");      #  2 (no 6)
print index("諄諄教誨", "教誨"); #  2 (el segundo carácter contando desde 0)

Codificaciones chinas adicionales

Si necesitas más codificaciones chinas, puedes descargar el módulo Encode::HanExtra desde CPAN (https://www.cpan.org/). Actualmente proporciona las siguientes codificaciones:

cccii       Código de intercambio de información china de la Conferencia de 1980
euc-tw      Conjunto de caracteres de extensión Unix, incluye los planos 1-7 de CNS11643
big5plus    Big5+ de la Fundación para la Promoción de la Tecnología Digital China
big5ext     Big5e de la Fundación para la Promoción de la Tecnología Digital China

Además, el módulo Encode::HanConvert proporciona dos codificaciones para la conversión entre chino simplificado y tradicional:

big5-simp   Conversión mutua entre chino tradicional Big5 y chino simplificado Unicode
gbk-trad    Conversión mutua entre chino simplificado GBK y chino tradicional Unicode

Si deseas convertir entre GBK y Big5, consulta los dos programas b2g.pl y g2b.pl incluidos en dicho módulo, o utiliza la siguiente forma dentro del programa:

use Encode::HanConvert;
$euc_cn = big5_to_gb($big5); # Convertir de Big5 a GBK
$big5 = gb_to_big5($euc_cn); # Convertir de GBK a Big5
