NOMBRE

perf - Herramientas de análisis de rendimiento para Linux

SINOPSIS

perf [--version] [--help] [OPCIONES] COMANDO [ARGUMENTOS]

OPCIONES

-h, --help

Ejecuta el comando de ayuda de perf.

-v, --version

Muestra la versión de perf.

-vv

Imprime el estado compilado de las bibliotecas.

--exec-path

Muestra o establece la ruta de ejecución.

--html-path

Muestra la ruta de la documentación HTML.

-p, --paginate

Configura el paginador.

--no-pager

No configures el paginador.

--buildid-dir

Configura el directorio de caché de buildid. Tiene mayor prioridad que la opción del archivo de configuración buildid.dir.

--list-cmds

Enumera los comandos de perf de uso más común.

--list-opts

Enumera las opciones disponibles de perf.

--debugfs-dir

Establece el directorio debugfs o la variable de entorno PERF_DEBUGFS_DIR.

--debug

Configura la variable de depuración (ver más abajo) en el rango de valores (0, 10). Úselo así: --debug verbose # establece verbose = 1 --debug verbose=2 # establece verbose = 2 
Lista de variables de depuración permitidas para configurar:
  verbose          - mensajes generales de depuración
  ordered-events   - mensajes de depuración del objeto de eventos ordenados
  data-convert     - mensajes de depuración del comando de conversión de datos
  stderr           - escribe la salida de depuración (opción -v)
                     en stderr en modo navegador
  perf-event-open  - imprime los argumentos y el valor de retorno
                     de perf_event_open()
  kmaps            - imprime los mapas del kernel y los módulos
                     (script de perf y reporte de perf sin navegador)

--debug-file

Escribe la salida de depuración en un archivo especificado.

DESCRIPCIÓN

Los contadores de rendimiento para Linux son un nuevo subsistema basado en el kernel que proporciona un marco para todo lo relacionado con el análisis de rendimiento. Cubre características de nivel de hardware (CPU/PMU, Unidad de Monitorización de Rendimiento) y también características de software (contadores de software, puntos de traza).
