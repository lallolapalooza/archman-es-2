NOMBRE

perl5223delta - qué hay de nuevo para la versión perl v5.22.3

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.22.2 y la versión 5.22.3.

Si está actualizando desde una versión anterior como la 5.22.1, primero lea perl5222delta, que describe las diferencias entre 5.22.1 y 5.22.2.

Seguridad

El interruptor -Di ahora es obligatorio para la salida de depuración de PerlIO

Anteriormente, la salida de depuración de PerlIO se enviaba al archivo especificado por la variable de entorno "PERLIO_DEBUG" si perl no se estaba ejecutando como setuid y los interruptores -T o -t aún no se habían analizado.

Si perl realizaba una salida en un punto en el que aún no había analizado sus interruptores, esto podría resultar en que perl creara o sobrescribiera el archivo nombrado por "PERLIO_DEBUG" incluso cuando se había proporcionado el interruptor -T.

Perl ahora requiere el interruptor -Di para producir salida de depuración de PerlIO. Por defecto, esto se escribe en "stderr", pero opcionalmente se puede redirigir a un archivo estableciendo la variable de entorno "PERLIO_DEBUG".

Si perl se está ejecutando como setuid o se proporcionó el interruptor -T, se ignora "PERLIO_DEBUG" y la salida de depuración se envía a "stderr" como con cualquier otro interruptor -D.

Los módulos y herramientas principales ya no buscan "." para módulos opcionales

Las herramientas y muchos módulos suministrados en el núcleo ya no buscan la entrada del directorio actual por defecto en @INC para módulos opcionales. Por ejemplo, Storable eliminará el "." final de @INC antes de intentar cargar Log::Agent.

Esto evita que un atacante inyecte un módulo opcional en un proceso ejecutado por otro usuario donde el directorio actual sea escribible por el atacante, por ejemplo, el directorio /tmp.

En la mayoría de los casos, esta eliminación no debería causar problemas, pero se encontraron dificultades con `base`, que trata cada nombre de módulo proporcionado como opcional. Estas dificultades aún no se han resuelto, por lo que para esta versión no hay cambios en `base`. Esperamos tener una solución para `base` en Perl 5.22.4.

Para proteger su propio código de este ataque, elimine la entrada predeterminada "." de @INC al inicio de su script, de modo que:

#!/usr/bin/perl
use strict;
...

se convierta en:

#!/usr/bin/perl
BEGIN { pop @INC if $INC[-1] eq '.' }
use strict;
...

o para módulos, elimine "." de un @INC localizado, de modo que:

my $can_foo = eval { require Foo; }

se convierta en:

my $can_foo = eval {
    local @INC = @INC;
    pop @INC if $INC[-1] eq '.';
    require Foo;
};

Cambios incompatibles

Aparte de los cambios de seguridad anteriores, no hay cambios intencionalmente incompatibles con Perl 5.22.2. Si existen, son errores y solicitamos que envíe un informe. Consulte "Reporte de errores" a continuación.

Informar de errores

Si encuentra lo que cree que es un error, puede consultar los artículos publicados recientemente en el grupo de noticias comp.lang.perl.misc y en la base de datos de errores de Perl en https://rt.perl.org/ . También puede haber información en http://www.perl.org/ , la página principal de Perl.

Si cree que tiene un error no reportado, ejecute el programa perlbug incluido con su versión. Asegúrese de reducir su error a un caso de prueba pequeño pero suficiente. Su informe de error, junto con la salida de "perl -V", se enviará a perlbug@perl.org para ser analizado por el equipo de adaptación de Perl.

Si el error que está informando tiene implicaciones de seguridad, lo que hace que no sea apropiado enviarlo a una lista de correo archivada públicamente, envíelo a perl5-security-report@perl.org. Esto apunta a una lista de correo cerrada, sin archivo y con suscripción cerrada, que incluye a todos los confirmadores principales, quienes podrán ayudar a evaluar el impacto de los problemas, encontrar una solución y ayudar a coordinar la publicación de parches para mitigar o solucionar el problema en todas las plataformas en las que se admite Perl. Utilice esta dirección solo para problemas de seguridad en el núcleo de Perl, no para módulos distribuidos de forma independiente en CPAN.
