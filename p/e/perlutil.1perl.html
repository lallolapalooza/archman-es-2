PERLUTIL(1perl) Guía de referencia para programadores de Perl PERLUTIL(1perl)

NOMBRE

perlutil - utilidades empaquetadas con la distribución de Perl

DESCRIPCIÓN

Además del intérprete de Perl en sí, la distribución de Perl instala una serie de utilidades en su sistema. También hay varias utilidades que son utilizadas por la propia distribución de Perl como parte del proceso de instalación. Este documento existe para listar todas estas utilidades, explicar para qué sirven y proporcionar enlaces a la documentación de cada módulo, si corresponde.

LISTA DE UTILIDADES

Documentación

perldoc
La interfaz principal para la documentación de Perl es perldoc, aunque si está leyendo esto, lo más probable es que ya lo haya encontrado. perldoc extraerá y formateará la documentación de cualquier archivo en el directorio actual, cualquier módulo de Perl instalado en el sistema, o cualquiera de las páginas de documentación estándar, como esta. Utilice "perldoc <nombre>" para obtener información sobre cualquiera de las utilidades descritas en este documento.
pod2man
pod2text
Si se ejecuta desde una terminal, perldoc normalmente llamará a pod2man para traducir POD (Plain Old Documentation - vea perlpod para una explicación) a una página de manual, y luego ejecutará man para mostrarla; si man no está disponible, se utilizará pod2text en su lugar y la salida se canalizará a su visor de páginas preferido.
pod2html
Además de estos dos, hay otro conversor: pod2html producirá páginas HTML a partir de POD.
pod2usage
Si solo desea saber cómo usar las utilidades descritas aquí, pod2usage solo extraerá la sección "USAGE"; algunas de las utilidades llamarán automáticamente a pod2usage cuando las ejecute con "-help".
podchecker
Si está escribiendo su propia documentación en POD, la utilidad podchecker buscará errores en su marcado.
splain
splain es una interfaz para perldiag: introdúzcale su mensaje de error y él se lo explicará.
roffitall
La utilidad roffitall no se instala en su sistema, sino que reside en el directorio pod/ de su kit de código fuente de Perl; convierte toda la documentación de la distribución al formato *roff y produce un archivo de texto o PostScript formateado de todo el conjunto.

Conversores

pl2pm
Para ayudarle a convertir programas heredados a Perl más moderno, la utilidad pl2pm le ayudará a convertir bibliotecas antiguas de Perl 4 a módulos de Perl 5 modernos.

Administración

libnetcfg
Para mostrar y cambiar la configuración de libnet, ejecute el comando libnetcfg.
perlivp
El programa perlivp se configura en el momento de compilar el código fuente de Perl para probar la versión de Perl bajo la que se compiló. Puede usarse después de ejecutar "make install" (o el procedimiento equivalente de su plataforma) para verificar que perl y sus bibliotecas se han instalado correctamente.

Desarrollo

Hay un conjunto de utilidades que le ayudan en el desarrollo de programas Perl, y en particular, en la extensión de Perl con C.

perlbug
perlbug solía ser la forma recomendada de informar de errores en el intérprete de perl o en cualquiera de los módulos de la biblioteca estándar a los desarrolladores; ahora los informes de errores y parches deben enviarse a https://github.com/Perl/perl5/issues.
perlthanks
Este programa proporciona una forma fácil de enviar un mensaje de agradecimiento a los autores y mantenedores de perl. Es simplemente perlbug instalado con otro nombre.
h2ph
Antes de que Perl tuviera el sistema XS para conectarse con bibliotecas C, los programadores solían obtener constantes de bibliotecas leyendo los archivos de cabecera C. Es posible que todavía vea "require 'syscall.ph'" o similar alrededor; el archivo .ph debería crearse ejecutando h2ph en el archivo .h correspondiente. Consulte la documentación de h2ph para saber cómo convertir un montón de archivos de cabecera a la vez.
h2xs
h2xs convierte archivos de cabecera C en módulos XS, e intentará escribir la mayor cantidad de código de pegamento entre bibliotecas C y módulos Perl que pueda. También es muy útil para crear esqueletos de módulos puramente en Perl.
enc2xs
enc2xs crea una extensión de Perl para ser utilizada por Encode a partir de archivos de mapeo de caracteres Unicode (.ucm) o archivos de codificación Tcl (.enc). Además de ser utilizado internamente durante el proceso de compilación del módulo Encode, puede usar enc2xs para agregar su propia codificación a perl. No se necesita conocimiento de XS.
xsubpp
xsubpp es un compilador para convertir código XS de Perl a código C. Normalmente es ejecutado por los makefiles creados por ExtUtils::MakeMaker.

xsubpp compilará código XS a código C incrustando las construcciones necesarias para que las funciones C manipulen valores de Perl y crea el pegamento necesario para que Perl acceda a esas funciones.

prove
prove es una interfaz de línea de comandos para la funcionalidad de ejecución de pruebas de Test::Harness. Es una alternativa a "make test".
corelist
Un frontend de línea de comandos para Module::CoreList, para consultar qué módulos se enviaron con versiones dadas de perl.

Herramientas generales

Varias herramientas de propósito general se distribuyen con perl, principalmente porque vienen con módulos incluidos en la distribución de perl.

encguess
encguess intentará adivinar la codificación de caracteres de los archivos.
json_pp
json_pp es un conversor y formateador JSON puramente en Perl.
piconv
piconv es una versión en Perl de iconv(1), un conversor de codificación de caracteres ampliamente disponible para varios Unix hoy en día. Este script fue principalmente una demostración tecnológica para Perl v5.8.0, pero puedes usar piconv en lugar de iconv para prácticamente cualquier caso.
ptar
ptar es un programa similar a tar, escrito puramente en Perl.
ptardiff
ptardiff es una pequeña utilidad que produce una diferencia entre un archivo extraído y uno no extraído. (Tenga en cuenta que esta utilidad requiere el módulo Text::Diff para funcionar correctamente; este módulo no se distribuye con perl, pero está disponible en CPAN.)
ptargrep
ptargrep es una utilidad para aplicar coincidencia de patrones al contenido de archivos en un archivo tar.
shasum
Esta utilidad, que viene con el módulo Digest::SHA, se utiliza para imprimir o verificar sumas de verificación SHA.
streamzip
streamzip comprime datos transmitidos a STDIN en un contenedor zip transmitido.

NAME

perlutil - utilities accompanying the Perl distribution

DESCRIPTION

This document describes the utilities that come with the Perl distribution.

Core Perl Utilities

These are utilities that are shipped with the core Perl distribution. You don't need to install them separately. They are usually installed in Perl's own private bin directory, which is often added to your PATH environment variable when you install Perl.

enc2xs
Converts older Perl character-set-related modules to the new Encode/encoding.pm system.
h2ph
Reads C header files and produces Perl modules that contain constants found in the header files.
h2xs
Reads C header files and produces Perl modules that can be used to interface Perl with C code.
json_pp
A pretty-printer for JSON data.
piconv
Perl iconv(1) program.
pod2html
Converts POD (Plain Old Documentation) to HTML.
pod2man
Converts POD to man pages.
pod2text
Converts POD to plain text.
pod2usage
Prints POD documentation as plain text, usually to standard output.
podchecker
Checks POD documents for syntax errors.
prove
A command-line interface to the Test::Harness module, for running Perl tests.
splain
Formats Perl error messages.
xsubpp
A pre-processor for Perl module XS code.

Additional Utilities

These utilities are usually installed from CPAN modules.

corelist
A tool to query which Perl core modules are included in a given Perl version.
cpan
A command-line interface to CPAN.pm. It allows you to install modules or distributions from CPAN, or just get information about them.
instmodsh
A shell interface to ExtUtils::Installed, allowing examination of installed modules.
pl2pm
A script to convert Perl 4 style `.pl` files to Perl 5 `.pm` files.
perlbug
A script to help users report bugs in Perl.
ptar
A module to extract tar archives.
ptardiff
Compares tar archives.
shasum
Calculates cryptographic hashes (like SHA-1, SHA-256, MD5, etc.) of files.
streamzip
A Perl module for streaming zip archive creation and manipulation.
zipdetails
zipdetails displays information about the internal record structure of the zip file. It is not concerned with displaying any details of the compressed data stored in the zip file.

Installation

These utilities help manage extra Perl modules that don't come with the perl distribution.

cpan
cpan is a command-line interface to CPAN.pm. It allows you to install modules or distributions from CPAN, or just get information about them, and a lot more. It is similar to the command line mode of the CPAN module, 
perl -MCPAN -e shell
instmodsh
A little interface to ExtUtils::Installed to examine installed modules, validate your packlists and even create a tarball from an installed module.
