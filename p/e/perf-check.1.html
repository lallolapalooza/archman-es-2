PERF-CHECK(1) Manual de perf PERF-CHECK(1)

NOMBRE

perf-check - comprueba si las características están presentes en perf

SINOPSIS

perf check [<opciones>]
perf check {feature <lista_de_caracteristicas>} [<opciones>]

DESCRIPCIÓN

Sin subcomandos dados, el comando perf check simplemente muestra el uso del comando en la salida estándar.

Si se utiliza el subcomando feature, se imprime el estado de la característica en la salida estándar (a menos que también se pase -q), es decir, si está compilada/integrada o no. Además, perf check feature devuelve el estado de salida 0 si la característica está integrada, de lo contrario, devuelve el estado de salida 1.

SUBCOMANDOS

feature

Imprime si la(s) característica(s) está(n) compilada(s) o no, y además devuelve un estado de salida de 0 si la(s) característica(s) pasada(s) está(n) compilada(s), de lo contrario 1. 
Espera una lista de características como argumento. Puede ser un único
nombre/macro de característica, o se pueden pasar múltiples características
como una lista separada por comas, en cuyo caso el estado de salida será 0
solo si todas las características pasadas están compiladas.
Los nombres/macros de las características no distinguen entre mayúsculas y
minúsculas.
Ejemplo de uso:
        perf check feature libtraceevent
        perf check feature HAVE_LIBTRACEEVENT
        perf check feature libtraceevent,bpf
Nombres/macros de características admitidos:
        aio                     /  HAVE_AIO_SUPPORT
        bpf                     /  HAVE_LIBBPF_SUPPORT
        bpf_skeletons           /  HAVE_BPF_SKEL
        debuginfod              /  HAVE_DEBUGINFOD_SUPPORT
        dwarf                   /  HAVE_LIBDW_SUPPORT
        dwarf_getlocations      /  HAVE_LIBDW_SUPPORT
        dwarf-unwind            /  HAVE_DWARF_UNWIND_SUPPORT
        auxtrace                /  HAVE_AUXTRACE_SUPPORT
        libbfd                  /  HAVE_LIBBFD_SUPPORT
        libbpf-strings          /  HAVE_LIBBPF_STRINGS_SUPPORT
        libcapstone             /  HAVE_LIBCAPSTONE_SUPPORT
        libdw-dwarf-unwind      /  HAVE_LIBDW_SUPPORT
        libelf                  /  HAVE_LIBELF_SUPPORT
        libnuma                 /  HAVE_LIBNUMA_SUPPORT
        libopencsd              /  HAVE_CSTRACE_SUPPORT
        libperl                 /  HAVE_LIBPERL_SUPPORT
        libpfm4                 /  HAVE_LIBPFM
        libpython               /  HAVE_LIBPYTHON_SUPPORT
        libslang                /  HAVE_SLANG_SUPPORT
        libtraceevent           /  HAVE_LIBTRACEEVENT
        libunwind               /  HAVE_LIBUNWIND_SUPPORT
        lzma                    /  HAVE_LZMA_SUPPORT
        numa_num_possible_cpus  /  HAVE_LIBNUMA_SUPPORT
        zlib                    /  HAVE_ZLIB_SUPPORT
        zstd                    /  HAVE_ZSTD_SUPPORT

OPCIONES

-q, --quiet

No imprimir ningún mensaje ni advertencia 
Esto puede usarse junto con subcomandos como 'perf check feature'
para ocultar la salida innecesaria en scripts de prueba, por ejemplo,
'perf check feature --quiet libtraceevent'
