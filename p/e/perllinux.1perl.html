PERLLINUX(1perl) Guía de Referencia del Programador de Perl PERLLINUX(1perl)

NOMBRE

perllinux - Versión 5 de Perl en sistemas Linux

DESCRIPCIÓN

Este documento describe varias características de Linux que afectarán a cómo la versión 5 de Perl (en adelante, Perl) se compila y/o se ejecuta.

Despliegue de Perl en Linux

Normalmente se puede instalar /usr/bin/perl en Linux usando el gestor de paquetes de su distribución (ejemplo: "sudo apt-get install perl", o "sudo dnf install perl"). Tenga en cuenta que a veces es necesario instalar algunos paquetes de sistema adicionales para poder usar front-ends de CPAN, y que manipular el perl del sistema no siempre es recomendable. Se puede usar perlbrew https://perlbrew.pl/ para evitar tales problemas.

De lo contrario, perl debería compilarse bien en Linux usando los compiladores convencionales GCC y clang, siguiendo las instrucciones habituales.

Soporte experimental para los compiladores Sun Studio para el sistema operativo Linux

Sun Microsystems ha lanzado un port de sus compiladores Sun Studio para Linux. A mayo de 2019, la última versión estable tuvo lugar en 2017, y se pueden adquirir contratos de soporte para ellos.

Existen algunas instrucciones especiales para compilar Perl con Sun Studio en Linux. Siguiendo la configuración normal de "Configure", debe ejecutar make de la siguiente manera:

LDLOADLIBS=-lc make

"LDLOADLIBS" es una variable de entorno utilizada por el enlazador para enlazar los módulos de "/ext" a glibc. Actualmente, esa variable de entorno no se está llenando mediante una combinación de entradas de "Config" y "ExtUtil::MakeMaker". Aunque puede haber un error en algún lugar de la configuración de Perl o en "ExtUtil::MakeMaker" que cause el problema, la causa más probable es una comprensión incompleta de Sun Studio por parte de este autor. Se necesita una mayor investigación para que esto funcione mejor.
