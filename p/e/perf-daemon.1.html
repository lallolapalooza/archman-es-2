NOMBRE

perf-daemon - Ejecuta sesiones de grabación en segundo plano

SINOPSIS

perf daemon
perf daemon [<opciones>]
perf daemon start  [<opciones>]
perf daemon stop   [<opciones>]
perf daemon signal [<opciones>]
perf daemon ping   [<opciones>]

DESCRIPCIÓN

Este comando permite ejecutar un proceso demonio simple que inicia y monitoriza sesiones de grabación configuradas.

Puedes imaginar perf daemon como un proceso en segundo plano con varias tareas perf record hijas, como:

# ps axjf
...
     1  916507 ... perf daemon start
916507  916508 ...  \_ perf record --control=fifo:control,ack -m 10M -e cycles --overwrite --switch-output -a
916507  916509 ...  \_ perf record --control=fifo:control,ack -m 20M -e sched:* --overwrite --switch-output -a

No todas las sesiones de perf record son adecuadas para ejecutarse bajo el demonio. El usuario necesita sesiones perf que produzcan datos al consultarlos, como las sesiones del registrador de vuelo en el ejemplo anterior, o sesiones configuradas para producir datos periódicamente, como con la configuración --switch-output por tiempo y tamaño.

Cada sesión se inicia con una configuración de control (con las opciones de perf record --control).

Las sesiones se configuran a través del archivo de configuración, consulta la sección ARCHIVO DE CONFIGURACIÓN con EJEMPLOS.

OPCIONES

-v, --verbose

Sé más verboso.

--config=<RUTA>

Ruta del archivo de configuración. Si no se proporciona, perf buscará en las ubicaciones del sistema y predeterminadas (/etc/perfconfig, $HOME/.perfconfig).

--base=<RUTA>

Ruta del directorio base. Cada instancia del demonio se ejecuta sobre el directorio base. Solo una instancia de servidor puede ejecutarse sobre un directorio a la vez.

Todas las opciones genéricas están disponibles también bajo los comandos.

COMANDO START

El comando start crea el proceso demonio.

-f, --foreground

No pongas el proceso en segundo plano.

COMANDO STOP

El comando stop detiene todas las sesiones y el proceso demonio.

COMANDO SIGNAL

El comando signal envía una señal a las sesiones configuradas.

--session

Envía una señal a una sesión específica.

COMANDO PING

El comando ping envía un ping de control a las sesiones configuradas.

--session

Envía un ping a una sesión específica.

ARCHIVO DE CONFIGURACIÓN

El demonio se configura dentro del archivo de configuración estándar de perf utilizando las siguientes nuevas variables:

daemon.base: Ruta base para los datos del demonio. Todos los datos de las sesiones se almacenan bajo esta ruta.

session-<NOMBRE>.run: Define una nueva sesión de grabación. El valor es la línea de comandos de record sin la palabra clave record.

Cada sesión de perf record se ejecuta en el directorio daemon.base/<NOMBRE>.

EJEMPLOS

Ejemplo con 2 sesiones de grabación:

# cat ~/.perfconfig
[daemon]
base=/opt/perfdata
[session-cycles]
run = -m 10M -e cycles --overwrite --switch-output -a
[session-sched]
run = -m 20M -e sched:* --overwrite --switch-output -a

Iniciando el demonio:

# perf daemon start

Verificar sesiones:

# perf daemon
[603349:daemon] base: /opt/perfdata
[603350:cycles] perf record -m 10M -e cycles --overwrite --switch-output -a
[603351:sched] perf record -m 20M -e sched:* --overwrite --switch-output -a

La primera línea es información del proceso demonio con la base del demonio configurada.

Verificar sesiones con más información:

# perf daemon -v
[603349:daemon] base: /opt/perfdata
  output:  /opt/perfdata/output
  lock:    /opt/perfdata/lock
  up:      1 minutes
[603350:cycles] perf record -m 10M -e cycles --overwrite --switch-output -a
  base:    /opt/perfdata/session-cycles
  output:  /opt/perfdata/session-cycles/output
  control: /opt/perfdata/session-cycles/control
  ack:     /opt/perfdata/session-cycles/ack
  up:      1 minutes
[603351:sched] perf record -m 20M -e sched:* --overwrite --switch-output -a
  base:    /opt/perfdata/session-sched
  output:  /opt/perfdata/session-sched/output
  control: /opt/perfdata/session-sched/control
  ack:     /opt/perfdata/session-sched/ack
  up:      1 minutes

La ruta base es la base del demonio/sesión. El archivo lock es el archivo de bloqueo del demonio que garantiza que ningún otro demonio se esté ejecutando sobre la base. El archivo output es la salida de perf record para una sesión específica. Los archivos control y ack son los archivos de control de perf. El número up muestra los minutos que el demonio/sesión ha estado funcionando.

Asegúrate de que la sesión de control esté en línea:

# perf daemon ping
OK   cycles
OK   sched

Envía la señal USR2 a la sesión cycles para generar el archivo perf.data:

# perf daemon signal --session cycles
signal 12 sent to session 'cycles [603452]'
# tail -2  /opt/perfdata/session-cycles/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017013149 ]

Envía la señal USR2 a todas las sesiones:

# perf daemon signal
signal 12 sent to session 'cycles [603452]'
signal 12 sent to session 'sched [603453]'
# tail -2  /opt/perfdata/session-cycles/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017024689 ]
# tail -2  /opt/perfdata/session-sched/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017024713 ]

Detener el demonio:

# perf daemon stop
