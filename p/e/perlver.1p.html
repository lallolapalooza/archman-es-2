NOMBRE

perlver - El Analizador de Versión Mínima de Perl

SINOPSIS

adam@red:~$ perlver Perl-MinimumVersion
Found directory '.'
Searching for Perl files... found 3 file(s)
Scanning lib/Perl/MinimumVersion.pm... done
Scanning t/01_compile.t... done
Scanning t/02_main.t... done
    ---------------------------------------------------------
  | file                       | explicit | syntax | external |
  | --------------------------------------------------------- |
  | lib/Perl/MinimumVersion.pm | 5.005    | ~      | n/a      |
  | t/01_compile.t             | ~        | ~      | n/a      |
  | t/02_main.t                | ~        | ~      | n/a      |
    ---------------------------------------------------------
Minimum version of Perl required: ...
adam@red:~$

DESCRIPCIÓN

"perlver" es un script de consola creado para proporcionar acceso conveniente a la funcionalidad proporcionada por Perl::MinimumVersion.

La opción --blame muestra el código que requiere esta versión de perl

La sinopsis anterior cubre prácticamente todo lo que necesitas saber en este momento.

POR HACER

- Integrar PPI::Cache

- Integrar PPI::Metrics (cuando exista)

- Añadir algún tipo de salida analizable
