PERF-DLFILTER(1) Manual de perf PERF-DLFILTER(1)

NOMBRE

perf-dlfilter - Filtra eventos de muestra usando un archivo de objeto compartido cargado dinámicamente

SINOPSIS

perf script [--dlfilter archivo.so ] [ --dlarg argumento ]...

DESCRIPCIÓN

Esta opción se utiliza para procesar datos a través de un filtro personalizado proporcionado por un archivo de objeto compartido cargado dinámicamente. Los argumentos se pueden pasar usando --dlarg y recuperar usando perf_dlfilter_fns.args().

Si archivo.so no contiene "/", se encontrará ya sea en el directorio actual, o en la ruta de ejecución de las herramientas de perf, que es ~/libexec/perf-core/dlfilters para una compilación e instalación local (consulte perf --exec-path), o en las rutas del enlazador dinámico.

API

La API para filtrar consta de lo siguiente:

#include <perf/perf_dlfilter.h>
struct perf_dlfilter_fns perf_dlfilter_fns;
int start(void **data, void *ctx);
int stop(void *data, void *ctx);
int filter_event(void *data, const struct perf_dlfilter_sample *sample, void *ctx);
int filter_event_early(void *data, const struct perf_dlfilter_sample *sample, void *ctx);
const char *filter_description(const char **long_description);

Si se implementa, se llamará a start al principio, antes de cualquier llamada a filter_event o filter_event_early. Devuelva 0 para indicar éxito, o devuelva un código de error negativo. *data se puede asignar para su uso en otras funciones. ctx es necesario para las llamadas a perf_dlfilter_fns, pero la mayoría de las perf_dlfilter_fns no son válidas cuando se llaman desde start.

Si se implementa, se llamará a stop al final, después de cualquier llamada a filter_event o filter_event_early. Devuelva 0 para indicar éxito, o devuelva un código de error negativo. data es establecido por start. ctx es necesario para las llamadas a perf_dlfilter_fns, pero la mayoría de las perf_dlfilter_fns no son válidas cuando se llaman desde stop.

Si se implementa, se llamará a filter_event para cada evento de muestra. Devuelva 0 para mantener el evento de muestra, 1 para filtrarlo, o devuelva un código de error negativo. data es establecido por start. ctx es necesario para las llamadas a perf_dlfilter_fns.

filter_event_early es lo mismo que filter_event excepto que se llama antes del filtrado interno.

Si se implementa, filter_description debe devolver una descripción de una línea del filtro, y opcionalmente una descripción más larga.

No asuma que el argumento sample es válido (que se puede referenciar) después de que filter_event y filter_event_early devuelvan.

No asuma que los datos a los que apuntan los punteros en la estructura perf_dlfilter_sample son válidos (que se pueden referenciar) después de que filter_event y filter_event_early devuelvan.

La estructura perf_dlfilter_sample

A filter_event y filter_event_early se les pasa una estructura perf_dlfilter_sample, que contiene los siguientes campos:

/*
 * Información del evento de muestra de perf (según perf script y <linux/perf_event.h>)
 */
struct perf_dlfilter_sample {
        __u32 size; /* Tamaño de esta estructura (para comprobación de compatibilidad) */
        __u16 ins_lat;          /* Consulte PERF_SAMPLE_WEIGHT_TYPE en <linux/perf_event.h> */
        __u16 p_stage_cyc;      /* Consulte PERF_SAMPLE_WEIGHT_TYPE en <linux/perf_event.h> */
        __u64 ip;
        __s32 pid;
        __s32 tid;
        __u64 time;
        __u64 addr;
        __u64 id;
        __u64 stream_id;
        __u64 period;
        __u64 weight;           /* Consulte PERF_SAMPLE_WEIGHT_TYPE en <linux/perf_event.h> */
        __u64 transaction;      /* Consulte PERF_SAMPLE_TRANSACTION en <linux/perf_event.h> */
        __u64 insn_cnt; /* Para instrucciones por ciclo (IPC) */
        __u64 cyc_cnt;          /* Para instrucciones por ciclo (IPC) */
        __s32 cpu;
        __u32 flags;            /* Consulte PERF_DLFILTER_FLAG_* arriba */
        __u64 data_src;         /* Consulte PERF_SAMPLE_DATA_SRC en <linux/perf_event.h> */
        __u64 phys_addr;        /* Consulte PERF_SAMPLE_PHYS_ADDR en <linux/perf_event.h> */
        __u64 data_page_size;   /* Consulte PERF_SAMPLE_DATA_PAGE_SIZE en <linux/perf_event.h> */
        __u64 code_page_size;   /* Consulte PERF_SAMPLE_CODE_PAGE_SIZE en <linux/perf_event.h> */
        __u64 cgroup;           /* Consulte PERF_SAMPLE_CGROUP en <linux/perf_event.h> */
        __u8  cpumode;          /* Consulte CPUMODE_MASK etc en <linux/perf_event.h> */
        __u8  addr_correlates_sym; /* Verdadero => se puede llamar a resolve_addr() */
        __u16 misc;             /* Consulte perf_event_header en <linux/perf_event.h> */
        __u32 raw_size;         /* Consulte PERF_SAMPLE_RAW en <linux/perf_event.h> */
        const void *raw_data;   /* Consulte PERF_SAMPLE_RAW en <linux/perf_event.h> */
        __u64 brstack_nr;       /* Número de entradas de brstack */
        const struct perf_branch_entry *brstack; /* Consulte <linux/perf_event.h> */
        __u64 raw_callchain_nr; /* Número de entradas de raw_callchain */
        const __u64 *raw_callchain; /* Consulte <linux/perf_event.h> */
        const char *event;
        __s32 machine_pid;
        __s32 vcpu;
};

Nota: machine_pid y vcpu no son miembros originales, sino que se añadieron juntos más tarde. size se puede usar para determinar su presencia en tiempo de ejecución. PERF_DLFILTER_HAS_MACHINE_PID se definirá si están presentes en tiempo de compilación. Por ejemplo:

#include <perf/perf_dlfilter.h>
#include <stddef.h>
#include <stdbool.h>
static inline bool have_machine_pid(const struct perf_dlfilter_sample *sample)
{
#ifdef PERF_DLFILTER_HAS_MACHINE_PID
        return sample->size >= offsetof(struct perf_dlfilter_sample, vcpu) + sizeof(sample->vcpu);
#else
        return false;
#endif
}

La estructura perf_dlfilter_fns

La estructura perf_dlfilter_fns se rellena con punteros a funciones cuando se carga el archivo. Las funciones pueden ser llamadas por filter_event o filter_event_early.

struct perf_dlfilter_fns {
        const struct perf_dlfilter_al *(*resolve_ip)(void *ctx);
        const struct perf_dlfilter_al *(*resolve_addr)(void *ctx);
        char **(*args)(void *ctx, int *dlargc);
        __s32 (*resolve_address)(void *ctx, __u64 address, struct perf_dlfilter_al *al);
        const __u8 *(*insn)(void *ctx, __u32 *length);
        const char *(*srcline)(void *ctx, __u32 *line_number);
        struct perf_event_attr *(*attr)(void *ctx);
        __s32 (*object_code)(void *ctx, __u64 ip, void *buf, __u32 len);
        void (*al_cleanup)(void *ctx, struct perf_dlfilter_al *al);
        void *(*reserved[119])(void *);
};

resolve_ip devuelve información sobre ip.

resolve_addr devuelve información sobre addr (si addr_correlates_sym).

args devuelve argumentos de las opciones --dlarg.

resolve_address proporciona información sobre address. Se debe establecer al->size antes de llamar. Devuelve 0 en caso de éxito, -1 en caso contrario. Llame a al_cleanup() (si está presente, vea más abajo) cuando los datos de al ya no sean necesarios.

insn devuelve los bytes de la instrucción y la longitud.

srcline devuelve el nombre del archivo fuente y el número de línea.

attr devuelve perf_event_attr, consulte <linux/perf_event.h>.

object_code lee el código objeto y devuelve el número de bytes leídos.

al_cleanup debe llamarse (si está presente, así que verifique perf_dlfilter_fns.al_cleanup != NULL) después de resolve_address() para liberar cualquier recurso asociado.

No asuma que los punteros obtenidos a través de perf_dlfilter_fns son válidos (que se pueden referenciar) después de que filter_event y filter_event_early devuelvan.

La estructura perf_dlfilter_al

La estructura perf_dlfilter_al contiene información sobre una dirección.

/*
 * Ubicación de la dirección (según perf script)
 */
struct perf_dlfilter_al {
        __u32 size; /* Tamaño de esta estructura (para comprobación de compatibilidad) */
        __u32 symoff;
        const char *sym;
        __u64 addr; /* Dirección mapeada (desde dso) */
        __u64 sym_start;
        __u64 sym_end;
        const char *dso;
        __u8  sym_binding; /* STB_LOCAL, STB_GLOBAL o STB_WEAK, consulte <elf.h> */
        __u8  is_64_bit; /* Solo válido si dso no es NULL */
        __u8  is_kernel_ip; /* Verdadero si está en espacio del kernel */
        __u32 buildid_size;
        __u8 *buildid;
        /* Los siguientes miembros solo son poblados por */
};

perf-dlfilter(1) — Arch manual pages

NAME

perf-dlfilter - dynamic shared object filters for perf script

SYNOPSIS

perf script --dlfilter <filter.so>

DESCRIPTION

The perf script utility allows for filtering events using a dynamic shared object (.so) file. This feature is useful for advanced event filtering based on complex logic that cannot be expressed with simple command-line options. The shared object must export a function named filter_event, which will be called by perf script for each event.

The shared object can be built using the libperf library, which provides the necessary structures and functions for interacting with perf events.

API

The filter shared object must implement the following structures and functions.

perf_dlfilter_fns

This structure holds pointers to functions provided by libperf. It must be exported by the shared object under the name perf_dlfilter_fns.

struct perf_dlfilter_fns {
        /*
         * Resolve the current IP (instruction pointer) to a symbol/address.
         * The context (ctx) is opaque and should be passed as-is to this function.
         */
        const struct perf_dlfilter_al *(*resolve_ip)(void *ctx);

        /*
         * Resolve the address (e.g. from a branch event) to a symbol/address.
         * The context (ctx) is opaque and should be passed as-is to this function.
         */
        const struct perf_dlfilter_al *(*resolve_addr)(void *ctx);
};

perf_dlfilter_al

This structure represents an address and its associated symbol information.

struct perf_dlfilter_al {
        struct perf_dlfilter_al *next; /* Next entry in a list */
        const char *sym;              /* Symbol name, if any */
        const char *file;             /* Source file name, if any */
        unsigned long offset;         /* Offset within the symbol, if any */
        unsigned long ip;             /* Instruction pointer */
        unsigned long size;           /* Size of the symbol, if any */
        unsigned long cpu;            /* CPU the sample is from */
        unsigned long nr_samples;     /* Number of samples hitting this entry */
        unsigned long nr_misses;      /* Number of samples missing this entry */
        unsigned long long tstamp;    /* Timestamp of the sample */
        int comm_len;                 /* Length of command name */
        const char *comm;             /* Process command name */
        void *priv;                   /* Private data. Do not change */
};

Do not assume data referenced by pointers in struct perf_dlfilter_al is valid (dereferenceable) after filter_event and filter_event_early return.

perf_dlfilter_sample flags

The flags member of perf_dlfilter_sample corresponds with the flags field of perf script. The bits of the flags are as follows:

/* Definitions for perf_dlfilter_sample flags */
enum {
        PERF_DLFILTER_FLAG_BRANCH       = 1ULL << 0,
        PERF_DLFILTER_FLAG_CALL         = 1ULL << 1,
        PERF_DLFILTER_FLAG_RETURN       = 1ULL << 2,
        PERF_DLFILTER_FLAG_CONDITIONAL  = 1ULL << 3,
        PERF_DLFILTER_FLAG_SYSCALLRET   = 1ULL << 4,
        PERF_DLFILTER_FLAG_ASYNC        = 1ULL << 5,
        PERF_DLFILTER_FLAG_INTERRUPT    = 1ULL << 6,
        PERF_DLFILTER_FLAG_TX_ABORT     = 1ULL << 7,
        PERF_DLFILTER_FLAG_TRACE_BEGIN  = 1ULL << 8,
        PERF_DLFILTER_FLAG_TRACE_END    = 1ULL << 9,
        PERF_DLFILTER_FLAG_IN_TX        = 1ULL << 10,
        PERF_DLFILTER_FLAG_VMENTRY      = 1ULL << 11,
        PERF_DLFILTER_FLAG_VMEXIT       = 1ULL << 12,
};

EXAMPLE

Filter out everything except branches from "foo" to "bar":

#include <perf/perf_dlfilter.h>
#include <string.h>
struct perf_dlfilter_fns perf_dlfilter_fns;
int filter_event(void *data, const struct perf_dlfilter_sample *sample, void *ctx)
{
        const struct perf_dlfilter_al *al;
        const struct perf_dlfilter_al *addr_al;
        if (!sample->ip || !sample->addr_correlates_sym)
                return 1;
        al = perf_dlfilter_fns.resolve_ip(ctx);
        if (!al || !al->sym || strcmp(al->sym, "foo"))
                return 1;
        addr_al = perf_dlfilter_fns.resolve_addr(ctx);
        if (!addr_al || !addr_al->sym || strcmp(addr_al->sym, "bar"))
                return 1;
        return 0;
}

To build the shared object, assuming perf has been installed for the local user i.e. perf_dlfilter.h is in ~/include/perf :

gcc -c -I ~/include -fpic dlfilter-example.c
gcc -shared -o dlfilter-example.so dlfilter-example.o

To use the filter with perf script:

perf script --dlfilter dlfilter-example.so

NOTES

The dlfilter .so file will be dependent on shared libraries. If those change, it may be necessary to rebuild the .so. Also there may be unexpected results if the .so uses different versions of the shared libraries that perf uses. Versions can be checked using the ldd command.
