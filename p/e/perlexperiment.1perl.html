PERLEXPERIMENT(1perl) Guía de referencia para programadores de Perl PERLEXPERIMENT(1perl)

NOMBRE

perlexperiment - Un listado de características experimentales en Perl

DESCRIPCIÓN

Este documento enumera las características experimentales actuales y pasadas en el núcleo de Perl. Aunque todas están documentadas con sus temas apropiados, este listado conciso te da una visión general y hechos básicos sobre su estado.

Hasta ahora solo hemos intentado encontrar y listar las características experimentales e inferir su inicio, versiones, etc. Hay mucha especulación aquí.

Experimentos actuales

Palabras clave enchufables
Introducido en Perl 5.11.2

Ver "PL_keyword_plugin" en perlapi para el mecanismo.

El ticket para este experimento es [perl #13199] https://github.com/Perl/perl5/issues/13199.

Alias mediante referencia
Introducido en Perl 5.22.0

El uso de esta característica activa advertencias en la categoría "experimental::refaliasing".

El ticket para este experimento es [perl #14150] https://github.com/Perl/perl5/issues/14150.

Ver también: "Asignación a referencias" en perlref

use re 'strict';
Introducido en Perl 5.22.0

El uso de esta característica activa advertencias en la categoría "experimental::re_strict".

El ticket para este experimento es [perl #18755] https://github.com/Perl/perl5/issues/18755

Ver "Modo 'strict'" en re

Declaración de una referencia a una variable
Introducido en Perl 5.26.0

El uso de esta característica activa advertencias en la categoría "experimental::declared_refs".

El ticket para este experimento es [perl #15458] https://github.com/Perl/perl5/issues/15458.

Ver también: "Declaración de una Referencia a una Variable" en perlref

Hay un objetivo "installhtml" en el Makefile.
El ticket para este experimento es [perl #12726] https://github.com/Perl/perl5/issues/12726.
(Limitado) Look-behind de longitud variable
Introducido en Perl 5.30.0.

Se maneja una variabilidad de hasta 255 caracteres.

El uso de esta característica activa advertencias en la categoría "experimental::vlb".

El ticket para este experimento es [perl #18756] https://github.com/Perl/perl5/issues/18756.

Ver también: "(*positive_lookbehind:patrón)" en perlre y "(*negative_lookbehind:patrón)" en perlre

Ganchos de caracteres de uso privado de Unicode
Introducido en Perl 5.30.0.

Esta característica es parte de una interfaz destinada al uso interno y experimental por parte de los desarrolladores de perl5. Es poco probable que la encuentres en la práctica.

El uso de esta característica activa advertencias en la categoría "experimental::private_use".

El ticket para este experimento es [perl #18758] https://github.com/Perl/perl5/issues/18758.

Comodines de propiedades de Unicode
Introducido en Perl 5.30.0.

Esta característica permite que la coincidencia de expresiones regulares contra propiedades de caracteres Unicode se exprese de forma más concisa.

El uso de esta característica activa advertencias en la categoría "experimental::uniprop_wildcards".

El ticket para este experimento es [perl #18759] https://github.com/Perl/perl5/issues/18759.

Estructura de control try/catch
Introducido en Perl 5.34.0.

El uso de la parte opcional del bloque "finally" de esta característica activa advertencias en la categoría "experimental::try".

El ticket para este experimento es [perl #18760] https://github.com/Perl/perl5/issues/18760

Uso de @_ dentro de firmas de subrutinas
Introducido en Perl 5.36.0 como parte de una reducción del alcance de las firmas de subrutinas experimentales.

El uso del array de argumentos por defecto (@_) dentro de una subrutina que usa firmas emitirá una advertencia en la categoría "experimental::args_array_with_signatures". Esto incluye @_ directamente, elementos de él como $_[$index], o situaciones donde el array de argumentos por defecto se accede implícitamente como "shift" o "pop" sin argumentos.

El espacio de nombres builtin
Introducido en Perl 5.36.0.

El uso de ciertas funciones de esta característica activa advertencias en la categoría "experimental::builtin".

En Perl 5.36.0, se creó un nuevo espacio de nombres, "builtin", para nuevas funciones del núcleo que no estarán presentes en todos los espacios de nombres, pero que estarán disponibles para importar. El propio espacio de nombres se consideró experimental hasta Perl 5.39.2. Algunas funciones específicas dentro de él siguen siendo experimentales.

El ticket para este experimento es [perl #19764] https://github.com/Perl/perl5/issues/19764.

El modificador de bloque defer
Introducido en Perl 5.36.0

El uso de esta característica activa advertencias en la categoría "experimental::defer".

Esta característica agrega un nuevo tipo de bloque, un bloque "defer", que no se ejecutará hasta que el bloque contenedor esté siendo salido.

El ticket para este experimento es [perl #17949] https://github.com/Perl/perl5/issues/17949.

Delimitadores pareados extra para operadores tipo comilla
Introducido en Perl 5.36.0

El uso de esta característica activa advertencias en la categoría "experimental::extra_paired_delimiters".

Esta característica permite muchos pares no ASCII de delimitadores que se reflejan, por ejemplo:

my @array = qw« tinker tailor soldier spy »;

El ticket para este experimento es [perl #19765] https://github.com/Perl/perl5/issues/19765.

Operadores de procesamiento de listas "any" y "all"
Introducido en Perl 5.41.7.

El uso de estas características activa advertencias en las categorías "experimental::any" o "experiment::all".

Esto agrega nuevos operadores de procesamiento de listas llamados "any" y "all", cada uno como su propia característica con nombre.

El ticket para este experimento es [perl #22794] https://github.com/Perl/perl5/issues/22794.

Características aceptadas

También se les otorga +5 Estabilidad y +3 Carisma.

Características abandonadas en el lugar

Estos son experimentos que se consideran fracasos, pero debido a su uso masivo se han dejado en su lugar.

Es probable que las características de switch y smartmatch sean las únicas que caigan en esta categoría. Se introdujeron antes de que tuviéramos un proceso de características experimentales bien definido.

Es poco probable que se actualicen con cambios de comportamiento.

Coincidencia inteligente ("~~")
Introducido en Perl 5.10.0

Modificado en Perl 5.10.1, 5.12.0

Deprecado en 5.38.0

Programado para su eliminación en 5.42.0, pero esto se revocó.

Habilitado por defecto, y en todos los paquetes de características hasta 5.40, deshabilitado por defecto en el paquete de características 5.42, pero se puede habilitar con use feature "smartmatch".

El ticket para este experimento es [perl #13173] https://github.com/Perl/perl5/issues/13173.

Switch (given/when)
Introducido en Perl 5.10.0

Deprecado en 5.38.0

Programado para su eliminación en 5.42.0, pero esto se revocó.

Habilitado por paquetes de características 5.10 a 5.34, pero se puede habilitar con "use feature "switch"".

El ticket para este experimento es [perl #13173] https://github.com/Perl/perl5/issues/13173.

perlexperiment(1perl)

NOMBRE

perlexperiment - Implementación experimental de Perl

DESCRIPCIÓN

La versión experimental de Perl contiene características que podrían ser añadidas a versiones futuras de Perl. No debe usarse en entornos de producción y está destinada a experimentar con nuevas funcionalidades.

Puede encontrar más información sobre las características experimentales y cómo utilizarlas en la documentación oficial de Perl.
