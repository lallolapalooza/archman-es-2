NOMBRE

perf-data - Procesamiento relacionado con archivos de datos

SINOPSIS

perf data [<opciones comunes>] <comando> [<opciones>]

DESCRIPCIÓN

Procesamiento relacionado con archivos de datos.

COMANDOS

convert

Convierte el archivo de datos perf a otro formato. Es posible establecer la variable de depuración data-convert para obtener mensajes de depuración de la conversión, como: perf --debug data-convert data convert ...

OPCIONES PARA CONVERTIR

--to-ctf

Inicia la conversión a CTF, especifica la ruta del directorio de datos CTF.

--to-json

Inicia la conversión a JSON. Especifica el nombre del archivo JSON de salida.

--tod

Convierte el tiempo a tiempo de reloj de pared.

-i

Especifica la ruta del archivo de datos perf de entrada.

-f, --force

No te quejes, hazlo.

-v, --verbose

Sea más detallado (muestre errores de apertura de contadores, etc.).

--all

Convierte todos los eventos, incluidos los eventos no de muestra (comm, fork, ...), a la salida. Por defecto está desactivado, solo convierte las muestras.

VER TAMBIÉN
