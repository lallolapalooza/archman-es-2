NOMBRE

perlvos - Perl para Stratus OpenVOS

SINOPSIS

Este archivo contiene notas para compilar Perl en el sistema operativo Stratus OpenVOS. Perl es un lenguaje de scripting o macro que es popular en muchos sistemas. Ver perlbook para obtener una serie de buenos libros sobre Perl.

Estas son instrucciones para compilar Perl desde el código fuente. Esta versión de Perl requiere el soporte de enlace dinámico que se encuentra en OpenVOS Release 17.1 y, por lo tanto, no es compatible con OpenVOS Release 17.0 o versiones anteriores.

Si está ejecutando VOS Release 14.4.1 o posterior, puede obtener una copia precompilada y compatible de Perl comprando el producto GNU Tools de Stratus Technologies.

COMPILACIÓN DE PERL PARA OPENVOS

Para compilar Perl desde su código fuente en la plataforma Stratus V Series, debe tener OpenVOS Release 17.1.0 o posterior, GNU Tools Release 3.5 o posterior, y las Bibliotecas de tiempo de ejecución C/POSIX.

Siga las instrucciones normales para compilar Perl; por ejemplo, ingrese bash, ejecute el script Configure, luego use "gmake" para compilar Perl.

INSTALACIÓN DE PERL EN OPENVOS

1.
Después de haber compilado Perl usando el script Configure, asegúrese de tener permisos de escritura para modificar y por defecto en ">system>ported" y todos sus subdirectorios. Luego, escriba 
gmake install
2.
Aunque actualmente no hay extensiones o módulos específicos de arquitectura distribuidos con Perl, los siguientes directorios se pueden utilizar para almacenar dichos archivos (reemplace la cadena VERSION por el número de versión apropiado): 
>system>ported>lib>perl5>VERSION>i786
3.
Las extensiones y módulos de Perl específicos del sitio se pueden instalar en uno de dos lugares. Coloque los archivos independientes de la arquitectura en: 
>system>ported>lib>perl5>site_perl>VERSION

Coloque los archivos específicos del sitio e independientes de la arquitectura en uno de los siguientes directorios:

>system>ported>lib>perl5>site_perl>VERSION>i786
4.
Puede examinar la variable @INC desde dentro de un programa Perl para ver el orden en que Perl busca en estos directorios.

USO DE PERL EN OPENVOS

Restricciones de Perl en OpenVOS

Este puerto de Perl versión 5 prefiere los nombres de ruta de estilo Unix, separados por barras, sobre los nombres de ruta de estilo OpenVOS, separados por signos de mayor que. Los nombres de ruta de estilo OpenVOS deberían funcionar en la mayoría de los contextos, pero si tiene problemas, reemplace todos los caracteres de mayor que por caracteres de barra. Dado que el carácter de barra se utiliza como delimitador de nombres de ruta, Perl no puede procesar nombres de ruta de OpenVOS que contengan un carácter de barra en un directorio o nombre de archivo; estos deben ser renombrados.

Este puerto de Perl también utiliza valores de fecha de época Unix internamente. Mientras se esté tratando con representaciones de cadenas de caracteres ASCII de fechas, esto no debería ser un problema. La época compatible es del 1 de enero de 1980 al 17 de enero de 2038.

Consulte el archivo pod/perlport.pod para obtener más información sobre el puerto de Perl para OpenVOS.

ESTADO DE LAS PRUEBAS

Varias de las autocomprobaciones de Perl fallan por diversas razones; en general, son menores y se deben a sutiles diferencias entre los entornos comunes basados en POSIX y el entorno POSIX de OpenVOS. Asegúrese de realizar pruebas suficientes de su código para garantizar que funcione correctamente en el entorno OpenVOS.

ESTADO DE SOPORTE

Ofrezco este puerto "tal cual". Puede hacerme preguntas, pero no puedo garantizar que pueda responderlas. Hay excelentes libros disponibles sobre el lenguaje Perl; consulte a un vendedor de libros.

Si desea una versión compatible de Perl para OpenVOS, compre el producto OpenVOS GNU Tools de Stratus Technologies, junto con un contrato de soporte (o a cualquier otra persona que le venda soporte).
