DESCRIPCIÓN

Declaración y Acceso de Arrays de Arrays

La estructura de datos de dos niveles más simple de construir en Perl es un array de arrays, a veces llamado casualmente lista de listas. Es razonablemente fácil de entender, y casi todo lo que se aplica aquí también será aplicable más adelante con las estructuras de datos más sofisticadas.

Un array de arrays es solo un array normal y corriente @AoA al que puedes acceder con dos subíndices, como "$AoA[3][2]". Aquí tienes una declaración del array:

  use v5.10;  # para poder usar say()
  # asignamos a nuestro array, un array de referencias a arrays
  @AoA = (
         [ "fred", "barney", "pebbles", "bambam", "dino", ],
         [ "george", "jane", "elroy", "judy", ],
         [ "homer", "bart", "marge", "maggie", ],
  );
  say $AoA[2][1];
bart

Ahora debes tener mucho cuidado de que el tipo de corchete exterior sea uno redondo, es decir, un paréntesis. Eso es porque estás asignando a un @array, por lo que necesitas paréntesis. Si quisieras que *no* hubiera un @AoA, sino solo una referencia a él, podrías hacer algo más parecido a esto:

  # asignamos una referencia a un array de referencias a arrays
  $ref_to_AoA = [
      [ "fred", "barney", "pebbles", "bambam", "dino", ],
      [ "george", "jane", "elroy", "judy", ],
      [ "homer", "bart", "marge", "maggie", ],
  ];
  say $ref_to_AoA->[2][1];
bart

Observa que el tipo de corchete exterior ha cambiado, y por lo tanto nuestra sintaxis de acceso también ha cambiado. Eso es porque, a diferencia de C, en Perl no puedes intercambiar libremente arrays y referencias a ellos. $ref_to_AoA es una referencia a un array, mientras que @AoA es un array propiamente dicho. Del mismo modo, $AoA[2] no es un array, sino una referencia a un array. Entonces, ¿por qué puedes escribir estas:

$AoA[2][2]
$ref_to_AoA->[2][2]

en lugar de tener que escribir estas:

$AoA[2]->[2]
$ref_to_AoA->[2]->[2]

Bueno, eso es porque la regla es que solo en corchetes adyacentes (ya sean cuadrados o rizados), eres libre de omitir la flecha de desreferenciación del puntero. Pero no puedes hacerlo para el primer elemento si es un escalar que contiene una referencia, lo que significa que $ref_to_AoA siempre la necesita.

Cultivando el Tuyo Propio

Todo eso está bien para la declaración de una estructura de datos fija, pero ¿qué pasa si quisieras añadir nuevos elementos sobre la marcha, o construirla completamente desde cero?

Primero, veamos cómo leer desde un archivo. Esto es algo así como añadir una fila a la vez. Supondremos que hay un archivo plano en el que cada línea es una fila y cada palabra un elemento. Si estás intentando desarrollar un array @AoA que contenga todo esto, esta es la manera correcta de hacerlo:

while (<>) {
    @tmp = split;
    push @AoA, [ @tmp ];
}

También podrías haberlo cargado desde una función:

for $i ( 1 .. 10 ) {
    $AoA[$i] = [ somefunc($i) ];
}

O podrías haber tenido una variable temporal con el array dentro.

for $i ( 1 .. 10 ) {
    @tmp = somefunc($i);
    $AoA[$i] = [ @tmp ];
}

Es importante asegurarse de usar el constructor de referencias a arrays "[ ]". Eso es porque esto no funcionaría:

$AoA[$i] = @tmp;   # ¡MAL!

La razón por la que eso no hace lo que quieres es porque al asignar un array con nombre de esa manera a un escalar, se está tomando un array en contexto escalar, lo que significa que solo cuenta el número de elementos en @tmp.

Si estás ejecutando bajo "use strict" (y si no lo estás, ¿por qué demonios no lo estás?), tendrás que añadir algunas declaraciones para que funcione:

use strict;
my(@AoA, @tmp);
while (<>) {
    @tmp = split;
    push @AoA, [ @tmp ];
}

Por supuesto, no necesitas que el array temporal tenga un nombre en absoluto:

while (<>) {
    push @AoA, [ split ];
}

Tampoco tienes que usar push(). Podrías hacer una asignación directa si supieras dónde quieres ponerlo:

my (@AoA, $i, $line);
for $i ( 0 .. 10 ) {
    $line = <>;
    $AoA[$i] = [ split " ", $line ];
}

o incluso solo

my (@AoA, $i);
for $i ( 0 .. 10 ) {
    $AoA[$i] = [ split " ", <> ];
}

En general, debes ser cauteloso al usar funciones que podrían potencialmente devolver listas en contexto escalar sin indicarlo explícitamente. Esto sería más claro para el lector casual:

my (@AoA, $i);
for $i ( 0 .. 10 ) {
    $AoA[$i] = [ split " ", scalar(<>) ];
}

Si quisieras tener una variable $ref_to_AoA como referencia a un array, tendrías que hacer algo como esto:

while (<>) {
    push @$ref_to_AoA, [ split ];
}

Ahora puedes añadir nuevas filas. ¿Qué pasa con la adición de nuevas columnas? Si solo trabajas con matrices, a menudo es más fácil usar la asignación simple:

for $x (1 .. 10) {
    for $y (1 .. 10) {
        $AoA[$x][$y] = func($x, $y);
    }
}
for $x ( 3, 7, 9 ) {
    $AoA[$x][20] += func2($x);
}

No importa si esos elementos ya existen o no: los creará encantado para ti, estableciendo los elementos intermedios a "undef" según sea necesario.

Si solo quisieras añadir al final de una fila, tendrías que hacer algo un poco más raro:

# añadir nuevas columnas a una fila existente
push $AoA[0]->@*, "wilma", "betty";   # desreferenciación explícita

Acceso e Impresión

Ahora es el momento de imprimir tu estructura de datos. ¿Cómo vas a hacerlo? Bueno, si solo quieres un elemento, es trivial:

print $AoA[0][0];

Sin embargo, si quieres imprimirlo todo, no puedes decir

print @AoA;         # ¡MAL!

porque solo obtendrás referencias listadas, y Perl nunca te desreferenciará automáticamente las cosas. En su lugar, tienes que crear un bucle o dos. Esto imprime toda la estructura, utilizando la construcción de bucle estilo shell for() para recorrer el conjunto exterior de subíndices.

for $aref ( @AoA ) {
    say "\t [ @$aref ],";
}

Si quisieras llevar un registro de los subíndices, podrías hacer esto:

for $i ( 0 .. $#AoA ) {
    say "\t el elemento $i es [ @{$AoA[$i]} ],";
}

o quizás incluso esto. Observa el bucle interior.

for $i ( 0 .. $#AoA ) {
    for $j ( 0 .. $#{$AoA[$i]} ) {
        say "el elemento $i $j es $AoA[$i][$j]";
    }
}

Como puedes ver, se está volviendo un poco complicado. Es por eso que a veces es más fácil tomar una variable temporal en tu recorrido:

for $i ( 0 .. $#AoA ) {
    $aref = $AoA[$i];
    for $j ( 0 .. $#{$aref} ) {
        say "el elemento $i $j es $AoA[$i][$j]";
    }
}

Hmm... eso todavía es un poco feo. ¿Qué tal esto:

for $i ( 0 .. $#AoA ) {
    $aref = $AoA[$i];
    $n = @$aref - 1;
    for $j ( 0 .. $n ) {
        say "el elemento $i $j es $AoA[$i][$j]";
    }
}

Cuando te canses de escribir una impresión personalizada para tus estructuras de datos, podrías mirar los módulos estándar Dumpvalue o Data::Dumper. El primero es lo que usa el depurador de Perl, mientras que el segundo genera código Perl analizable. Por ejemplo:

use v5.14;     # usando el prototipo +, nuevo en v5.14
sub show(+) {
       require Dumpvalue;
   state $prettify = Dumpvalue->new(
       tick        => q("),
       compactDump => 1,  # comenta estas dos líneas
       veryCompact => 1,  # si quieres un volcado más grande
   );
       $prettify->dumpValue(@_);
}
# Asignamos una lista de referencias a arrays a un array.
my @AoA = (
          [ "fred", "barney" ],
          [ "george", "jane", "elroy" ],
          [ "homer", "marge", "bart" ],
);
push $AoA[0]->@*, "wilma", "betty";
show @AoA;

imprimirá:

0  0..3  "fred" "barney" "wilma" "betty"
1  0..2  "george" "jane" "elroy"
2  0..2  "homer" "marge" "bart"

Porciones (Slices)

Si quieres acceder a una porción (una parte de una fila) en un array multidimensional, tendrás que hacer algunas operaciones de indexación avanzadas. Esto se debe a que, si bien tenemos un buen sinónimo para elementos individuales a través de la flecha del puntero para la desreferenciación, no existe tal conveniencia para las porciones.

Aquí te mostramos cómo hacer una operación usando un bucle. Asumiremos una variable @AoA como antes.

@part = ();
$x = 4;
for ($y = 7; $y < 13; $y++) {
    push @part, $AoA[$x][$y];
}

Ese mismo bucle podría ser reemplazado con una operación de porción:

@part = $AoA[4]->@[ 7..12 ];

Ahora, ¿qué pasaría si quisieras una porción de *dos dimensiones*, como tener $x desde 4..8 y $y desde 7 hasta 12? Mmm... aquí está la forma sencilla:

@newAoA = ();
for ($startx = $x = 4; $x <= 8; $x++) {
    for ($starty = $y = 7; $y <= 12; $y++) {
        $newAoA[$x - $startx][$y - $starty] = $AoA[$x][$y];
    }
}

Podemos reducir parte del bucle a través de porciones

for ($x = 4; $x <= 8; $x++) {
    push @newAoA, [ $AoA[$x]->@[ 7..12 ] ];
}

Si fueras de los que gustan de las Transformaciones de Schwartz, probablemente habrías seleccionado `map` para eso

@newAoA = map { [ $AoA[$_]->@[ 7..12 ] ] } 4 .. 8;

Aunque si tu jefe te acusara de buscar seguridad laboral (o rápida inseguridad) a través de código inescrutable, sería difícil discutir. :-) Si yo fuera tú, pondría eso en una función:

@newAoA = splice_2D( \@AoA, 4 => 8, 7 => 12 );
sub splice_2D {
    my $lrr = shift;        # ¡referencia a array de referencias a arrays!
    my ($x_lo, $x_hi,
        $y_lo, $y_hi) = @_;
    return map {
        [ $lrr->[$_]->@[ $y_lo .. $y_hi ] ]
    } $x_lo .. $x_hi;
}
