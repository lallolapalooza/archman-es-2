NOMBRE

perl5143delta - qué hay de nuevo para la versión perl v5.14.3

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.14.2 y la versión 5.14.3.

Si está actualizando desde una versión anterior como la 5.12.0, primero lea perl5140delta, que describe las diferencias entre 5.12.0 y 5.14.0.

Mejoras del núcleo

Sin cambios desde 5.14.0.

Seguridad

"Digest" uso inseguro de eval (CVE-2011-3597)

La función "Digest->new()" no sanitizaba adecuadamente la entrada antes de usarla en una llamada a eval(), lo que podía llevar a la inyección de código Perl arbitrario.

Para explotar esta falla, el atacante necesitaría poder establecer el nombre del algoritmo utilizado, o poder ejecutar código Perl arbitrario ya.

Este problema ha sido corregido.

Desbordamiento de búfer en la pila en el operador de repetición de cadenas 'x' (CVE-2012-5195)

El código Perl mal escrito que permite a un atacante especificar el contador para el operador de repetición de cadenas 'x' de Perl ya puede causar un ataque de denegación de servicio por agotamiento de memoria. Un fallo en las versiones de Perl anteriores a 5.15.5 puede escalar eso a un desbordamiento de búfer en la pila; acoplado con versiones de glibc anteriores a 2.16, posiblemente permite la ejecución de código arbitrario.

Este problema ha sido corregido.

Cambios incompatibles

No hay cambios intencionadamente incompatibles con 5.14.0. Si existen, son errores y se agradecen los informes.

Deprecaciones

No ha habido deprecaciones desde 5.14.0.

Módulos y pragmata actualizados

  • PerlIO::scalar fue actualizado para corregir un error en el que abrir un manejador de archivos a una copia glob causaba fallos de aserción (bajo depuración) o bloqueos u otro comportamiento errático sin depuración.
  • ODBM_File y NDBM_File fueron actualizados para permitir la compilación en GNU/Hurd.
  • IPC::Open3 ha sido actualizado para corregir una regresión introducida en perl 5.12, que rompió "IPC::Open3::open3($in, $out, $err, '-')". [perl #95748]
  • Digest ha sido actualizado de la versión 1.16 a 1.16_01.

    Ver "Seguridad".

  • Module::CoreList ha sido actualizado a la versión 2.49_04 para añadir datos para esta versión.

Notas específicas de la plataforma

FreeBSD
El archivo de pistas de FreeBSD se corrigió para ser compatible con FreeBSD 10.0.
Solaris y NetBSD
Configure fue actualizado para el soporte de "procselfexe" en Solaris y NetBSD.
HP-UX
README.hpux fue actualizado para notar la existencia de una cabecera rota en HP-UX 11.00.
Linux
libutil ya no se utiliza al compilar en plataformas Linux, lo que evita que se emitan advertencias.

El gcc del sistema (en lugar de cualquier otro gcc que pudiera estar en la ruta del usuario que compila) se utiliza ahora al buscar bibliotecas como "-lm".

Mac OS X
Las pruebas de localización se actualizaron para reflejar el comportamiento de las localizaciones en Mountain Lion.
GNU/Hurd
Se incluyeron varias correcciones de compilación y pruebas para GNU/Hurd.

Se habilitó el soporte LFS en GNU/Hurd.

NetBSD
El archivo de pistas de NetBSD se corrigió para ser compatible con NetBSD 6.*

Corrección de errores

  • Se ha corregido una regresión introducida en 5.14, en la coincidencia de expresiones regulares "/i", en la que una coincidencia falla incorrectamente si el patrón está en UTF-8, la cadena objetivo no lo está, y un carácter Latin-1 precede a un carácter en la cadena que debería coincidir con el patrón. [perl #101710]
  • En la coincidencia de patrones de expresiones regulares insensible a mayúsculas/minúsculas, en cadenas codificadas en UTF-8, la búsqueda del inicio de la coincidencia ya no solo mira la primera posición posible. Esto causó que coincidencias como ""f\x{FB00}" =~ /ff/i" fallaran.
  • El soporte de sitecustomize se hizo consciente de relocatableinc, de modo que -Dusesitecustomize y -Duserelocatableinc puedan usarse juntos.
  • El operador de coincidencia inteligente ("~~") fue modificado para que el lado derecho tenga prioridad durante las operaciones "Any ~~ Object".
  • Se ha corregido un error en el soporte de tainting, en el que una operación index() en una constante contaminada contaminaba todas las demás constantes. [perl #64804]
  • Se ha corregido una regresión introducida en perl 5.12, por la cual los errores de tainting no se propagaban correctamente a través de die(). [perl #111654]
  • Se ha corregido una regresión introducida en perl 5.14, en la que "/[[:lower:]]/i" y "/[[:upper:]]/i" ya no coincidían con el caso opuesto. [perl #101970]

Reporting Bugs

If you find what you think is a bug, you might check the articles recently posted to the comp.lang.perl.misc newsgroup and the perl bug database at http://rt.perl.org/perlbug/ . There may also be information at http://www.perl.org/ , the Perl Home Page.

If you believe you have an unreported bug, please run the perlbug program included with your release. Be sure to trim your bug down to a tiny but sufficient test case. Your bug report, along with the output of "perl -V", will be sent off to perlbug@perl.org to be analysed by the Perl porting team.

If the bug you are reporting has security implications, which make it inappropriate to send to a publicly archived mailing list, then please send it to perl5-security-report@perl.org. This points to a closed subscription unarchived mailing list, which includes all the core committers, who be able to help assess the impact of issues, figure out a resolution, and help co-ordinate the release of patches to mitigate or fix the problem across all platforms on which Perl is supported. Please only use this address for security issues in the Perl core, not for modules independently distributed on CPAN.
