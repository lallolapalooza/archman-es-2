NOMBRE

perf-ftrace - wrapper simple para la funcionalidad ftrace del kernel

SINOPSIS

perf ftrace {trace|latency|profile} <comando>

DESCRIPCIÓN

El comando perf ftrace proporciona una colección de subcomandos que utilizan la infraestructura ftrace del kernel.

'perf ftrace trace' es un wrapper simple de ftrace. Actualmente solo soporta
el rastreo de un solo hilo y simplemente lee trace_pipe en texto y luego
lo escribe en stdout.
'perf ftrace latency' calcula la latencia de ejecución de una función dada
(opcionalmente con BPF) y la muestra como un histograma.
'perf ftrace profile' muestra un perfil de ejecución para cada función, incluyendo
tiempo total, promedio, máximo y número de llamadas.

Las siguientes opciones se aplican a perf ftrace.

OPCIONES COMUNES

-p, --pid=

Rastrear en un proceso existente id (lista separada por comas).

--tid=

Rastrear en un hilo existente id (lista separada por comas).

-a, --all-cpus

Forzar la recolección a nivel de sistema. Los scripts que se ejecutan sin un <comando> normalmente usan -a por defecto, mientras que los scripts que se ejecutan con un <comando> normalmente no lo hacen; esta opción permite que estos últimos se ejecuten en modo a nivel de sistema.

-C, --cpu=

Rastrear solo para la lista de CPUs proporcionadas. Se pueden proporcionar múltiples CPUs como una lista separada por comas sin espacio, como: 0,1. Los rangos de CPUs se especifican con -: 0-2. Por defecto, se rastrea en todas las CPUs en línea.

-v, --verbose

Aumentar el nivel de verbosidad.

OPCIONES PARA PERF FTRACE TRACE

-t, --tracer=

Rastreador a usar cuando no se especifica la opción -G ni -F: function_graph o function.

-F, --funcs

Lista las funciones disponibles para rastrear. Acepta un patrón para listar solo las funciones de interés.

-D, --delay

Tiempo (ms) a esperar antes de comenzar el rastreo después del inicio del programa.

-m, --buffer-size

Establecer el tamaño del buffer de rastreo por CPU; se espera que <size> sea un número con un carácter de unidad appended - B/K/M/G.

--inherit

Rastrear procesos hijos generados por nuestro objetivo.

-T, --trace-funcs=

Seleccionar el rastreador de funciones y establecer un filtro de funciones en la función dada (o un patrón glob). Se pueden dar múltiples funciones usando esta opción más de una vez. El argumento de la función también puede ser un patrón glob. Se pasará a set_ftrace_filter en tracefs.

-N, --notrace-funcs=

Seleccionar el rastreador de funciones y no rastrear las funciones dadas por el argumento. Similar a la opción -T, esto se puede usar más de una vez para especificar múltiples funciones (o patrones glob). Se pasará a set_ftrace_notrace en tracefs.

--func-opts

Lista de opciones permitidas para establecer:
•call-graph - Mostrar el rastreo de pila del kernel para el rastreador de funciones.
•irq-info - Mostrar información de contexto de interrupción para el rastreador de funciones.

-G, --graph-funcs=

Seleccionar el rastreador function_graph y establecer un filtro de gráfico en la función dada (o un patrón glob). Esto es útil para rastrear funciones ejecutadas desde la función dada. Se puede usar más de una vez para especificar múltiples funciones. Se pasará a set_graph_function en tracefs.

-g, --nograph-funcs=

Seleccionar el rastreador function_graph y establecer un filtro de gráfico no rastreado en la función dada (o un patrón glob). Similar a la opción -G, esto es útil solo para el rastreador function_graph y deshabilita el rastreo de funciones ejecutadas desde la función dada. Se puede usar más de una vez para especificar múltiples funciones. Se pasará a set_graph_notrace en tracefs.

--graph-opts

Lista de opciones permitidas para establecer:
•args - Mostrar argumentos de la función.
•retval - Mostrar valor de retorno de la función.
•retval-hex - Mostrar valor de retorno de la función en formato hexadecimal.
•retaddr - Mostrar dirección de retorno de la función.
•nosleep-time - Medir solo el tiempo en CPU para el rastreador function_graph.
•noirqs - Ignorar funciones que ocurren dentro de una interrupción.
•verbose - Mostrar nombres de procesos, PIDs, marcas de tiempo, etc.
•thresh=<n> - Establecer el umbral de duración del rastreo en microsegundos.
•depth=<n> - Establecer la profundidad máxima para que el rastreador de gráficos de funciones la siga.
•tail - Imprimir el nombre de la función al final.

OPCIONES PARA PERF FTRACE LATENCY

-T, --trace-funcs=

Establecer el nombre de la función para obtener el histograma. A diferencia de perf ftrace trace, solo permite una sola función para calcular el histograma.

-e, --events=

Establecer el par de eventos para obtener el histograma. El histograma se calcula por la diferencia de tiempo entre los dos eventos del mismo hilo. Esto requiere la opción -b/--use-bpf.

-b, --use-bpf

Usar BPF para medir la latencia de la función en lugar de usar ftrace (usa el rastreador function_graph internamente).

-n, --use-nsec

Usar nanosegundos en lugar de microsegundos como unidad base del histograma.

--bucket-range=

Rango de cubetas en ms o ns (según -n/--use-nsec), por defecto es el modo log2().

--min-latency=

Latencia mínima para el inicio de la primera cubeta, en ms o ns (según -n/--use-nsec).

--max-latency=

Latencia máxima para el inicio de la última cubeta, en ms o ns (según -n/--use-nsec). La configuración se ignora si el valor resulta en más de 22 cubetas.

OPCIONES PARA PERF FTRACE PROFILE

-T, --trace-funcs=

Establecer un filtro de funciones en la función dada (o un patrón glob). Se pueden dar múltiples funciones usando esta opción más de una vez. El argumento de la función también puede ser un patrón glob. Se pasará a set_ftrace_filter en tracefs.

-N, --notrace-funcs=

No rastrear las funciones dadas por el argumento. Similar a la opción -T, esto se puede usar más de una vez para especificar múltiples funciones (o patrones glob). Se pasará a set_ftrace_notrace en tracefs.

-G, --graph-funcs=

Establecer un filtro de gráfico en la función dada (o un patrón glob). Esto es útil para rastrear funciones ejecutadas desde la función dada. Se puede usar más de una vez para especificar múltiples funciones. Se pasará a set_graph_function en tracefs.

-g, --nograph-funcs=

Establecer un filtro de gráfico no rastreado en la función dada (o un patrón glob). Similar a la opción -G, esto es útil solo para el rastreador function_graph y deshabilita el rastreo de funciones ejecutadas desde la función dada. Se puede usar más de una vez para especificar múltiples funciones. Se pasará a set_graph_notrace en tracefs.

-m, --buffer-size

Establecer el tamaño del buffer de rastreo por CPU; se espera que <size> sea un número con un carácter de unidad appended - B/K/M/G.

-s, --sort=

Ordenar el resultado por el campo dado. Los valores disponibles son: total, avg, max, count, name. Por defecto es total.

--graph-opts

Lista de opciones permitidas para establecer:
•nosleep-time - Medir solo el tiempo en CPU para el rastreador function_graph.
•noirqs - Ignorar funciones que ocurren dentro de una interrupción.
•thresh=<n> - Establecer el umbral de duración del rastreo en microsegundos.
•depth=<n> - Establecer la profundidad máxima para que el rastreador de gráficos de funciones la siga.
