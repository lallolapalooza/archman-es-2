NOMBRE

perl585delta - qué hay de nuevo para la versión perl v5.8.5

DESCRIPCIÓN

Este documento describe las diferencias entre la versión 5.8.4 y la versión 5.8.5.

Cambios incompatibles

No hay cambios incompatibles con la versión 5.8.4.

Mejoras centrales

El motor de expresiones regulares de Perl ahora contiene soporte para coincidir con la intersección de dos clases de caracteres Unicode. También puede hacer referencia a clases de caracteres definidas por el usuario dentro de otras clases de caracteres definidas por el usuario.

Módulos y Pragmata

  • Carp mejorado para funcionar bien con Safe. El informe de mensajes de Carp ahora debería estar libre de anomalías; siempre imprimirá información sobre el número de línea.
  • CGI actualizado a la versión 3.05
  • charnames ahora evita sobrescribir $_
  • Digest actualizado a la versión 1.08
  • Encode actualizado a la versión 2.01
  • FileCache actualizado a la versión 1.04
  • libnet actualizado a la versión 1.19
  • Pod::Parser actualizado a la versión 1.28
  • Pod::Perldoc actualizado a la versión 3.13
  • Pod::LaTeX actualizado a la versión 0.57
  • Safe ahora funciona correctamente con Carp
  • Scalar-List-Utils actualizado a la versión 1.14
  • La documentación de Shell ha sido reescrita, y su historial de auto-comillas parcial de argumentos de comandos ahora se puede deshabilitar.
  • Test actualizado a la versión 1.25
  • Test::Harness actualizado a la versión 2.42
  • Time::Local actualizado a la versión 1.10
  • Unicode::Collate actualizado a la versión 0.40
  • Unicode::Normalize actualizado a la versión 0.30

Cambios en utilidades

El depurador de Perl

El depurador ahora puede emular el retroceso, reiniciando y volviendo a ejecutar todos los comandos excepto el último a partir de un historial de comandos guardado.

h2ph

h2ph ahora es capaz de entender un conjunto muy limitado de funciones C en línea, básicamente, las funciones en línea que parecen macros CPP. Esto se ha introducido para tratar con algunas de las cabeceras de las versiones más recientes de glibc. Todavía se aplica la advertencia estándar; para citar la documentación de h2ph, es posible que necesite modificar los archivos producidos.

Mejoras en instalación y configuración

Perl 5.8.5 debería compilarse limpiamente desde la fuente en LynxOS.

Correcciones de errores seleccionadas

  • La optimización de ordenación in-situ introducida en 5.8.4 tenía un error. Por ejemplo, en código como 
    @a = sort ($b, @a)

    el resultado omitiría el valor $b. Esto ya está corregido.

  • La optimización para asignaciones innecesarias introducida en 5.8.4 podría generar advertencias falsas. Esto ha sido corregido.
  • Perl ahora debería detectar y leer correctamente scripts UTF-16 marcados con BOM y (sin BOM) de cualquier tipo de endianness.
  • La creación de un nuevo hilo cuando existen referencias débiles era errónea y a menudo causaba advertencias al destruir el intérprete. El error conocido ya está corregido.
  • Se han corregido varios errores oscuros relacionados con la manipulación de cadenas Unicode con "substr".
  • Anteriormente, si la función de globbing de archivos de Perl encontraba un directorio que no tenía permiso para abrir, devolvía inmediatamente, lo que provocaba una truncación inesperada de la lista de resultados. Esto se ha corregido, para ser coherente con el comportamiento de globbing de los shells de Unix.
  • El tiempo de creación del hilo podía variar drásticamente entre ejecuciones idénticas. Esto fue causado por un algoritmo de hash deficiente en las rutinas de clonación de hilos, que ahora ha sido corregido.
  • La implementación interna de ithreads no comprobaba si la creación de hilos a nivel de SO había fallado. threads->create() ahora devuelve "undef" si falla la creación del hilo, en lugar de fallar perl.

Diagnósticos nuevos o cambiados

•
Perl -V tiene varias mejoras
  • salida correcta de nombres de parches locales que contienen fragmentos de código incrustados u otros caracteres que solían confundirlo.
  • los argumentos para -V que parecen expresiones regulares darán múltiples líneas de salida.
  • un colon final suprime la interlínea y el terminador ';', permitiendo la incrustación de consultas en comandos de shell.
  • un colon inicial elimina la parte 'nombre=' de la respuesta, permitiendo el mapeo a cualquier nombre.
•
Cuando perl no encuentra el script especificado, ahora produce una segunda línea sugiriendo al usuario usar el flag "-S": 
$ perl5.8.5 missing.pl
Can't open perl script "missing.pl": No such file or directory.
Use -S to search $PATH for it.

Internals modificados

Los archivos de clases de caracteres Unicode utilizados por el motor de expresiones regulares ahora se construyen en tiempo de compilación a partir de los archivos de datos del consorcio Unicode proporcionados, en lugar de ser distribuidos precompilados. Esto hace que el archivo tarball de la fuente de Perl comprimido sea aproximadamente 200K más pequeño. Un efecto secundario es que el diseño de los archivos dentro de lib/unicore ha cambiado.

Problemas conocidos

La prueba de regresión t/uni/class.t ahora realiza considerablemente más pruebas y puede tardar varios minutos en ejecutarse incluso en una máquina rápida.

Problemas específicos de plataforma

Se sabe que esta versión no compila en Windows 95.

Reporte de errores

Si encuentra lo que cree que es un error, puede consultar los artículos publicados recientemente en el grupo de noticias comp.lang.perl.misc y la base de datos de errores de perl en http://bugs.perl.org. También puede haber información en http://www.perl.org, la Página Principal de Perl.

Si cree que tiene un error no reportado, ejecute el programa perlbug incluido con su versión. Asegúrese de reducir su error a un caso de prueba pequeño pero suficiente. Su informe de error, junto con la salida de "perl -V", se enviará a perlbug@perl.org para ser analizado por el equipo de portabilidad de Perl. Puede navegar y buscar los errores de Perl 5 en http://bugs.perl.org/
