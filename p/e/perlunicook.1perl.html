PERLUNICOOK(1perl) Guía de referencia para programadores de Perl PERLUNICOOK(1perl)

NOMBRE

perlunicook - ejemplos de libro de cocina para manejar Unicode en Perl

DESCRIPCIÓN

Esta página del manual contiene recetas cortas que demuestran cómo manejar operaciones comunes de Unicode en Perl, además de un programa completo al final. Se asume que cualquier variable no declarada en recetas individuales tiene un valor apropiado previo en ellas.

EJEMPLOS

℞ 0: Preámbulo estándar

A menos que se indique lo contrario, todos los ejemplos a continuación requieren este preámbulo estándar para funcionar correctamente, con el "#!" ajustado para funcionar en tu sistema:

#!/usr/bin/env perl
use v5.36;     # o posterior para obtener la característica "unicode_strings",
               #   además de strict, warnings
use utf8;      # para que los literales y identificadores puedan estar en UTF-8
use warnings  qw(FATAL utf8);    # fatalizar fallos de codificación
use open      qw(:std :encoding(UTF-8)); # flujos no declarados en UTF-8
use charnames qw(:full :short);  # no necesario en v5.16

Esto *sí* hace que incluso los programadores de Unix hagan "binmode" en sus flujos binarios, o los abran con ":raw", pero es la única forma de acceder a ellos de forma portátil de todos modos.

ADVERTENCIA: "use autodie" (pre 2.26) y "use open" no se llevan bien entre sí.

℞ 1: Filtro genérico compatible con Unicode

Siempre descompón al entrar, luego recompón al salir.

use Unicode::Normalize;
while (<>) {
    $_ = NFD($_);   # descomponer + reordenar canónicamente
    ...
} continue {
    print NFC($_);  # recomponer (donde sea posible) + reordenar canónicamente
}

℞ 2: Ajuste fino de advertencias de Unicode

A partir de la v5.14, Perl distingue tres subclases de advertencias UTF-8.

use v5.14;                  # subadvertencias no disponibles antes
no warnings "nonchar";      # los 66 no caracteres prohibidos
no warnings "surrogate";    # basura de UTF-16/CESU-8
no warnings "non_unicode";  # para puntos de código superiores a 0x10_FFFF

℞ 3: Declarar fuente en utf8 para identificadores y literales

Sin la declaración crucial "use utf8", poner UTF-8 en tus literales e identificadores no funcionará correctamente. Si usaste el preámbulo estándar que se dio arriba, esto ya sucedió. Si lo hiciste, puedes hacer cosas como esta:

use utf8;
my $measure   = "Ångström";
my @μsoft     = qw( cp852 cp1251 cp1252 );
my @ὑπέρμεγας = qw( ὑπέρ  μεγας );
my @鯉        = qw( koi8-f koi8-u koi8-r );
my $motto     = "👪 💗 🐪"; # FAMILIA, CORAZÓN CRECIENDO, CAMELLO

Si olvidas "use utf8", los bytes altos serán malinterpretados como caracteres separados, y nada funcionará correctamente.

℞ 4: Caracteres y sus números

Las funciones "ord" y "chr" funcionan de forma transparente en todos los puntos de código, no solo en ASCII; ni siquiera solo en Unicode.

# Caracteres ASCII
ord("A")
chr(65)
# caracteres del Plano Básico Multilingüe
ord("Σ")
chr(0x3A3)
# más allá del BMP
ord("𝑛")               # LETRA PEQUEÑA MATH MAYÚSCULA N EN CURSIVA
chr(0x1D45B)
# ¡más allá de Unicode! (hasta MAXINT)
ord("\x{20_0000}")
chr(0x20_0000)

℞ 5: Literales de Unicode por número de carácter

En un literal interpolado, ya sea una cadena entre comillas dobles o una expresión regular, puedes especificar un carácter por su número usando el escape "\x{HHHHHH}".

Cadena: "\x{3a3}"
Expresión regular:  /\x{3a3}/
Cadena: "\x{1d45b}"
Expresión regular:  /\x{1d45b}/
# incluso los rangos que no son del BMP en expresiones regulares funcionan bien
/[\x{1D434}-\x{1D467}]/

℞ 6: Obtener nombre de carácter por número

use charnames ();
my $name = charnames::viacode(0x03A3);

℞ 7: Obtener número de carácter por nombre

use charnames ();
my $number = charnames::vianame("GREEK CAPITAL LETTER SIGMA");

℞ 8: Caracteres con nombre de Unicode

Usa la notación "\N{nombre_caracter}" para obtener el carácter por ese nombre para usarlo en literales interpolados (cadenas entre comillas dobles y expresiones regulares). En v5.16, hay un implícito

use charnames qw(:full :short);

Pero antes de la v5.16, debes ser explícito sobre qué conjunto de nombres de caracteres quieres. Los nombres ":full" son el nombre oficial del carácter Unicode, alias o secuencia, que comparten un espacio de nombres.

use charnames qw(:full :short latin greek);
"\N{MATHEMATICAL ITALIC SMALL N}"      # :full
"\N{GREEK CAPITAL LETTER SIGMA}"       # :full

Cualquier otra cosa es una abreviatura de conveniencia específica de Perl. Especifica uno o más scripts por nombre si quieres nombres cortos específicos del script.

"\N{Greek:Sigma}"                      # :short
"\N{ae}"                               #  latin
"\N{epsilon}"                          #  greek

La versión v5.16 también admite la importación ":loose" para una coincidencia laxa de nombres de caracteres, que funciona igual que la coincidencia laxa de nombres de propiedades: es decir, ignora mayúsculas, minúsculas, espacios en blanco y guiones bajos:

"\N{euro sign}"                        # :loose (desde v5.16)

A partir de la v5.32, también puedes usar

qr/\p{name=euro sign}/

para obtener caracteres con nombre oficiales de Unicode en expresiones regulares. Siempre se realiza una coincidencia laxa para estos.

℞ 9: Secuencias con nombre de Unicode

Estas se ven igual que los nombres de caracteres pero devuelven múltiples puntos de código. Nota la funcionalidad de impresión de vectores "%vx" en "printf".

use charnames qw(:full);
my $seq = "\N{LATIN CAPITAL LETTER A WITH MACRON AND GRAVE}";
printf "U+%v04X\n", $seq;
U+0100.0300

℞ 10: Caracteres personalizados con nombre

Usa ":alias" para dar tus propios apodos léxicamente escopados a caracteres existentes, o incluso para dar nombres útiles a caracteres sin nombre de uso privado.

use charnames ":full", ":alias" => {
    ecute => "LATIN SMALL LETTER E WITH ACUTE",
    "APPLE LOGO" => 0xF8FF, # carácter de uso privado
};
"\N{ecute}"
"\N{APPLE LOGO}"

℞ 11: Nombres de puntos de código CJK

Los sinogramas como “東京” devuelven nombres de caracteres como "CJK UNIFIED IDEOGRAPH-6771" y "CJK UNIFIED IDEOGRAPH-4EAC", porque sus “nombres” varían. El módulo CPAN "Unicode::Unihan" tiene una gran base de datos para decodificar estos (y mucho más), siempre que sepas entender su salida.

# cpan -i Unicode::Unihan
use Unicode::Unihan;
my $str = "東京";
my $unhan = Unicode::Unihan->new;
for my $lang (qw(Mandarin Cantonese Korean JapaneseOn JapaneseKun)) {
    printf "CJK $str en %-12s es ", $lang;
    say $unhan->$lang($str);
}

imprime:

CJK 東京 en Mandarin     es DONG1JING1
CJK 東京 en Cantonese    es dung1ging1
CJK 東京 en Korean       es TONGKYENG
CJK 東京 en JapaneseOn   es TOUKYOU KEI KIN
CJK 東京 en JapaneseKun  es HIGASHI AZUMAMIYAKO

Si tienes un esquema de romanización específico en mente, usa el módulo específico:

# cpan -i Lingua::JA::Romanize::Japanese
use Lingua::JA::Romanize::Japanese;
my $k2r = Lingua::JA::Romanize::Japanese->new;
my $str = "東京";
say "Japonés para $str es ", $k2r->chars($str);

imprime

Japonés para 東京 es toukyou

℞ 12: Codificar/decodificar explícitamente

En raras ocasiones, como al leer una base de datos, se te puede dar texto codificado que necesitas decodificar.

 use Encode qw(encode decode);
 my $chars = decode("shiftjis&qu
ot;", $bytes, 1); # O my $bytes = encode("MIME-Header-ISO_2022_JP", $chars, 1);

Para flujos en la misma codificación, no uses encode/decode; en lugar de eso, establece la codificación del archivo cuando lo abras o inmediatamente después con "binmode" como se describe más adelante.

℞ 13: Decodificar argumentos del programa como utf8

    $ perl -CA ...
o
    $ export PERL_UNICODE=A
o
   use Encode qw(decode);
   @ARGV = map { decode('UTF-8', $_, 1) } @ARGV;

℞ 14: Decodificar argumentos del programa como codificación local

# cpan -i Encode::Locale
use Encode qw(locale);
use Encode::Locale;
# use "locale" como argumento para encode/decode
@ARGV = map { decode(locale => $_, 1) } @ARGV;

℞ 15: Declarar STD{IN,OUT,ERR} como utf8

Usa una opción de línea de comandos, una variable de entorno, o llama a "binmode" explícitamente:

    $ perl -CS ...
o
    $ export PERL_UNICODE=S
o
    use open qw(:std :encoding(UTF-8));
o
    binmode(STDIN,  ":encoding(UTF-8)");
    binmode(STDOUT, ":utf8");
    binmode(STDERR, ":utf8");

℞ 16: Declarar STD{IN,OUT,ERR} como codificación local 

# cpan -i Encode::Locale
use Encode;
use Encode::Locale;
# o como flujo para binmode o open
binmode STDIN,  ":encoding(console_in)"  if -t STDIN;
binmode STDOUT, ":encoding(console_out)" if -t STDOUT;
binmode STDERR, ":encoding(console_out)" if -t STDERR;

℞ 17: Hacer que la E/S de archivos sea utf8 por defecto

Los archivos abiertos sin un argumento de codificación estarán en UTF-8:

    $ perl -CD ...
o
    $ export PERL_UNICODE=D
o
    use open qw(:encoding(UTF-8));

℞ 18: Hacer que toda la E/S y los argumentos sean utf8 por defecto

    $ perl -CSDA ...
o
    $ export PERL_UNICODE=SDA
o
    use open qw(:std :encoding(UTF-8));
    use Encode qw(decode);
    @ARGV = map { decode('UTF-8', $_, 1) } @ARGV;

℞ 19: Abrir archivo con codificación específica

Especificar la codificación del flujo. Esta es la forma normal de tratar texto codificado, no llamando a funciones de bajo nivel.

# archivo de entrada
    open(my $in_file, "< :encoding(UTF-16)", "wintext");
O
    open(my $in_file, "<", "wintext");
    binmode($in_file, ":encoding(UTF-16)");
ENTONCES
    my $line = <$in_file>;
# archivo de salida
    open($out_file, "> :encoding(cp1252)", "wintext");
O
    open(my $out_file, ">", "wintext");
    binmode($out_file, ":encoding(cp1252)");
ENTONCES
    print $out_file "algún texto\n";

Se pueden especificar más capas que solo la codificación aquí. Por ejemplo, la incantación ":raw :encoding(UTF-16LE) :crlf" incluye manejo implícito de CRLF.

℞ 20: Mayúsculas/minúsculas Unicode

Las mayúsculas/minúsculas de Unicode son muy diferentes de las de ASCII.

uc("henry Ⅻ")  # "HENRY Ⅸ"
uc("tschüß")   # "TSCHÜSS"  notar ß => SS
# ambas son verdaderas:
"tschüß"  =~ /TSCHÜSS/i   # notar ß => SS
"Σίσυφος" =~ /ΣίσΥΦΟΣ/i   # notar Σ, σ, ς semejanza

℞ 21: Comparaciones de Unicode sin distinción entre mayúsculas y minúsculas

También disponible en el módulo CPAN Unicode::CaseFold, la nueva función "fc" "foldcase" de v5.16 otorga acceso al mismo plegado de mayúsculas/minúsculas de Unicode que el modificador de patrón "/i" siempre ha usado:

use feature "fc"; # la función fc() es de v5.16
# ordenar sin distinción entre mayúsculas y minúsculas
my @sorted = sort { fc($a) cmp fc($b) } @list;
# ambas son verdaderas:
fc("tschüß")  eq fc("TSCHÜSS")
fc("Σίσυφος") eq fc("ΣίσΥΦΟΣ")

℞ 22: Coincidir secuencia de salto de línea Unicode en expresiones regulares

Un salto de línea Unicode coincide con el grafema CRLF de dos caracteres o cualquiera de los siete caracteres de espacio en blanco verticales. Bueno para tratar con archivos de texto provenientes de diferentes sistemas operativos.

\R
s/\R/\n/g;  # normalizar todos los saltos de línea a \n

℞ 23: Obtener categoría de carácter

Encontrar la categoría general de un punto de código numérico.

use Unicode::UCD qw(charinfo);
my $cat = charinfo(0x3A3)->{category};  # "Lu"

℞ 24: Deshabilitar la conciencia de Unicode en clases de caracteres integradas

Deshabilitar que "\w", "\b", "\s", "\d", y las clases POSIX funcionen correctamente en Unicode, ya sea en este ámbito o en una sola expresión regular.

use v5.14;
use re "/a";
# O
my($num) = $str =~ /(\d+)/a;

O usar propiedades específicas no Unicode, como "\p{ahex}" y "\p{POSIX_Digit}". Las propiedades aún funcionan normalmente independientemente de los modificadores de conjunto de caracteres ("/d /u /l /a /aa") que estén activos.

℞ 25: Coincidir propiedades Unicode en expresiones regulares con \p, \P

Todas estas coinciden con un solo punto de código con la propiedad dada. Usa "\P" en lugar de "\p" para que coincida con un punto de código que carece de esa propiedad.

\pL, \pN, \pS, \pP, \pM, \pZ, \pC
\p{Sk}, \p{Ps}, \p{Lt}
\p{alpha}, \p{upper}, \p{lower}
\p{Latin}, \p{Greek}
\p{script_extensions=Latin}, \p{scx=Greek}
\p{East_Asian_Width=Wide}, \p{EA=W}
\p{Line_Break=Hyphen}, \p{LB=HY}
\p{Numeric_Value=4}, \p{NV=4}

℞ 26: Propiedades de caracteres personalizadas

Define en tiempo de compilación tus propias propiedades de caracteres personalizadas para su uso en expresiones regulares.

# usando caracteres de uso privado
sub In_Tengwar { "E000\tE07F\n" }
if (/\p{In_Tengwar}/) { ... }
# combinando propiedades existentes
sub Is_GraecoRoman_Title {<<'END_OF_SET'}
+utf8::IsLatin
+utf8::IsGreek
&utf8::IsTitle
END_OF_SET
if (/\p{Is_GraecoRoman_Title}/) { ... }

℞ 27: Normalización Unicode

Normalmente se renderiza a NFD en la entrada y a NFC en la salida. El uso de funciones NFKC o NFKD mejora la recuperación en búsquedas, asumiendo que ya has realizado la misma operación al texto que se va a buscar. Ten en cuenta que esto es mucho más que solo glifos pre-combinados de compatibilidad; también reordena las marcas según sus clases de combinación canónicas y elimina los singleton.

use Unicode::Normalize;
my $nfd  = NFD($orig);
my $nfc  = NFC($orig);
my $nfkd = NFKD($orig);
my $nfkc = NFKC($orig);

℞ 28: Convertir números Unicode no ASCII

A menos que hayas usado "/a" o , "\d" coincide con más que solo dígitos ASCII, pero la conversión implícita de cadena a número de Perl no los reconoce actualmente. Aquí se muestra cómo convertir dichas cadenas manualmente.

use utf8;
use v5.14;  # necesario para la función num()
use Unicode::UCD qw(num);
my $str = "contiene Ⅻ y  complex 90789 y ½ y 伍 here";
my @nums = ();
while ($str =~ /(\d+|\N)/g) {  # ¡no solo ASCII!
   push @nums, num($1);
}
say "@nums";   # 12 4567 0.875 1000000000000
use charnames qw(:full);
my $nv = num(" a౧౨");
say $nv;  # 12

℞ 29: Coincidir clúster de grafemas Unicode en expresiones regulares

Los "caracteres" visibles para el programador son puntos de código coincidentes por , pero los "caracteres" visibles para el usuario son grafemas coincidentes por .

# Encontrar vocal *más* cualquier diacrítico combinado, subrayado, etc.
my $nfd = NFD($orig);
$nfd =~ / (?=[aeiou]) \X /xi

℞ 30: Extraer por grafema en lugar de por punto de código (expresión regular)

# hacer coincidir y extraer los cinco primeros grafemas
my($first_five) = $str =~ /^ ( \X{5} ) /x;

℞ 31: Extraer por grafema en lugar de por punto de código (substr)

# cpan -i Unicode::GCString
use Unicode::GCString;
my $gcs = Unicode::GCString->new($str);
my $first_five = $gcs->substr(0, 5);

℞ 32: Invertir cadena por grafema

Invertir por punto de código arruina los diacríticos, convirtiendo erróneamente "crème brûlée" en "elûrb emèrc" en lugar de "eé lûrb emèrc"; así que invierte por grafema en su lugar. Ambos enfoques funcionan correctamente sin importar la normalización en la que se encuentre la cadena:

$str = join("", reverse $str =~ /\X/g);
# O: cpan -i Unicode::GCString
use Unicode::GCString;
$str = reverse Unicode::GCString->new($str);

℞ 33: Longitud de cadena en grafemas

La cadena "brûlée" tiene seis grafemas pero hasta ocho puntos de código. Esto cuenta por grafema, no por punto de código:

my $str = "brûlée";
my $count = 0;
while ($str =~ /\X/g) { $count++ }
 # O: cpan -i Unicode::GCString
use Unicode::GCString;
my $gcs = Unicode::GCString->new($str);
my $count = $gcs->length;

℞ 34: Ancho de columna Unicode para imprimir

El "printf" de Perl, "sprintf" y "format" piensan que todos los puntos de código ocupan 1 columna de impresión, pero muchos ocupan 0 o 2. Aquí, para mostrar que la normalización no hace ninguna diferencia, imprimimos ambas formas:

use Unicode::GCString;
use Unicode::Normalize;
my @words = qw/crème brûlée/;
@words = map { NFC($_), NFD($_) } @words;
for my $str (@words) {
    my $gcs = Unicode::GCString->new($str);
    my $cols = $gcs->columns;
    my $pad = " " x (10 - $cols);
    say $str, $pad, " |";
}

genera esto para mostrar que rellena correctamente sin importar la normalización:

crème      |
crème      |
brûlée     |
brûlée     |
