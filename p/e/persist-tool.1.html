SINOPSIS

persist-tool [comando] [opciones]

DESCRIPCIÓN

Esta página del manual es solo un resumen.

La aplicación persist-tool es una utilidad que se puede usar para volcar el contenido del archivo persistente y manipular su contenido.

[](/assets/images/caution.png) ¡CUIDADO!: Persist-tool es una herramienta especial para expertos de syslog-ng. No la use a menos que sepa exactamente lo que está haciendo. Una configuración incorrecta causará daños irreparables en el archivo persistente, sin ninguna advertencia.

Limitaciones: * Las funciones de estado persistente solo se pueden usar con archivos persistentes SLP4 o posteriores. Los archivos persistentes más antiguos no son compatibles. * Los caracteres comodín no son compatibles en los nombres de archivos y directorios.

El comando dump

dump [opciones] [archivo_persistente]

Use el comando dump para imprimir el contenido actual del archivo persistente en formato JSON en la consola.

El comando dump tiene las siguientes opciones: * --help o -?

Muestra un breve mensaje de ayuda.

Ejemplo: persist-tool dump

persist-tool dump /usr/var/syslog-ng.persist

Una salida válida es la siguiente:

run_id = { "value": "00 00 00 00 0C 00 00 00 " }
host_id = { "value": "00 00 00 00 5F 49 2F 01 " }

El comando add

add [opciones] [archivo_entrada]

Use el comando add para agregar o modificar una entrada de estado especificada en el archivo persistente. La entrada de estado debe estar en el mismo formato que muestra el comando dump. Si la entrada de estado dada ya existe, se actualizará. De lo contrario, se agregará un nuevo valor. Si el estado persistente dado no es válido, se omitirá.

Para usar el comando add: use persist-tool dump para imprimir el contenido del archivo persistente actual y redirigirlo a un archivo. Edite el contenido de este archivo. Use persist-tool add con este archivo para modificar el persistente.

El comando add tiene las siguientes opciones: * --help o -?

Muestra un breve mensaje de ayuda.
•
--output-dir=<directorio> o -o

Parámetro requerido. El directorio donde se encuentra el archivo persistente. El nombre del archivo persistente almacenado en este directorio debe ser syslog-ng.persist.

•
--persist-name=<nombre_archivo> o -p

Parámetro opcional. El nombre del archivo persistente a generar. Valor predeterminado: syslog-ng.persist.

Ejemplo: add dump_persist

/usr/bin/persist-tool add dump_persist -o .

Una salida válida es la siguiente:

log_reader_curpos(Application)      OK
affile_sd_curpos(/var/aaa.txt)        OK

Una salida inválida es la siguiente:

log_reader_curpos(Application)      OK
wrong
FAILED (error: Invalid entry syntax)
affile_sd_curpos(/var/aaa.txt)        OK
