PERLSH(1) Documentación de Perl aportada por el usuario PERLSH(1)

NOMBRE

perlsh - evaluador de perl en una línea con función de edición de línea y
función de completado de nombres de variable

SINOPSIS

perlsh

DESCRIPCIÓN

Este programa lee una línea de entrada y la evalúa con el intérprete de perl, e imprime el resultado. Si el resultado es un valor de lista, entonces cada valor de la lista se imprime línea por línea. Este programa puede ser utilizado como una calculadora muy potente que tiene todas las funciones de perl.

Este es un programa de ejemplo del módulo Term::ReadLine::Gnu. Cuando introduces una línea, la función de edición de línea de la Biblioteca GNU Readline está disponible. La función de completado de nombres de símbolos de Perl también está disponible.

Antes de invocarlo, este programa lee ~/.perlshrc y evalúa el contenido del archivo.

Cuando este programa se termina, el contenido del búfer de historial se guarda en un archivo ~/.perlsh_history, y se lee en la próxima invocación.

VARIABLES

Puedes personalizar el comportamiento de "perlsh" estableciendo las siguientes variables en ~/.perlshrc;

$PerlSh::PS1
La cadena de prompt principal. Se pueden utilizar los siguientes caracteres especiales escapados con barra invertida. 
\h: nombre del host
\u: nombre del usuario
\w: nombre del paquete
\!: número del historial

El valor por defecto es `"\w[\!]$ "'.

$PerlSh::PS2
La cadena de prompt secundaria. El valor por defecto es `"> "'.
$PerlSh::HISTFILE
El nombre del archivo en el que se guarda el historial de comandos. El valor por defecto es "~/.perlsh_history".
$PerlSh::HISTSIZE
Si no es "undef", este es el número máximo de comandos a recordar en el historial. El valor por defecto es 256.
$PerlSh::STRICT
Si es verdadero, restringe construcciones inseguras. Ver "use strict" en la página del manual de perl. El valor por defecto es 0;

ARCHIVOS

~/.perlshrc
Este archivo se evalúa al inicializar. Si una subrutina "afterinit" está definida en este archivo, se evaluará después de la inicialización. Aquí hay una muestra. 
# -*- mode: perl -*-
# decimal a hexa
sub h { map { sprintf("0x%x", $_ ) } @_;}
sub tk {
    $t->tkRunning(1);
    use Tk;
    $mw = MainWindow->new();
}
# para depurar Term::ReadLine::Gnu
sub afterinit {
    *t = \$PerlSh::term;
    *a = \$PerlSh::attribs;
}
~/.perlsh_history
~/.inputrc
Un archivo de inicialización para la Biblioteca GNU Readline. Consulta su manual para más detalles.
