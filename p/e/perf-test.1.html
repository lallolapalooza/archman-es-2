NOMBRE

perf-test - Ejecuta pruebas de sanidad.

SINOPSIS

perf test [<opciones>] [{lista <fragmento-nombre-prueba>|[<fragmentos-nombre-prueba>|<números-prueba>]}]

DESCRIPCIÓN

Este comando realiza pruebas de sanidad variadas, inicialmente a través de rutinas enlazadas, pero también buscará un directorio con más pruebas en forma de scripts.

Para obtener una lista de las pruebas disponibles, utiliza perf test lista, especificando un fragmento de nombre de prueba se mostrarán todas las pruebas que lo contengan.

Para ejecutar solo pruebas específicas, indica fragmentos de nombre de prueba o los números obtenidos de perf test lista.

OPCIONES

-s, --skip

Pruebas a omitir (lista numérica separada por comas).

-v, -vv, -vvv, --verbose

Con un único -v, nivel de verbosidad 1, solo se muestra la salida de las pruebas fallidas. Con -vv y superior se muestra toda la salida de las pruebas.

-S, --sequential

Ejecuta todas las pruebas una tras otra. Por defecto, las pruebas "exclusivas" se ejecutan secuencialmente, pero otras pruebas se ejecutan en paralelo para acelerar la ejecución.

-r, --runs-per-test

Ejecuta cada prueba el número de veces indicado, por defecto una vez. Esta opción puede ser útil para determinar si una prueba es inestable.

-F, --dont-fork

No crear un proceso hijo para cada prueba, ejecuta todas las pruebas dentro de un único proceso, esto establece el modo secuencial.

--dso

Especifica un DSO para la prueba "Symbols".

-w, --workload=

Ejecuta una carga de trabajo incorporada, para listarlas usa --list-workloads, las actuales incluyen: noploop, thloop, leafloop, sqrtloop, brstack, datasym y landlock. 
Usado con las pruebas de regresión de scripts de shell.
Algunas aceptan un parámetro adicional:
segundos: leafloop, noploop, sqrtloop, thloop
nrloops: brstack
Las cargas de trabajo datasym y landlock no aceptan ninguna.

--list-workloads

Lista las cargas de trabajo disponibles para usar con -w/--workload.
