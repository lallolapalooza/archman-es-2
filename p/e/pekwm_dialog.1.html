NOMBRE

pekwm_dialog - una aplicación de diálogo inspirada en xmessage

SINOPSIS

pekwm_dialog [--display] mensaje

DESCRIPCIÓN

pekwm_dialog presenta un diálogo simple con un título, una imagen, un mensaje de texto y un botón para cada opción especificada. Si no se especifican opciones, el diálogo tendrá un botón Aceptar.

El llamador puede identificar qué opciones se seleccionaron comprobando el código de salida de la aplicación. La primera opción saldrá con el código de estado 0, la siguiente con 1 y así sucesivamente.

Dado este comportamiento, se recomienda tener "Aceptar" como la primera opción y luego "Cancelar" como la segunda, y luego opciones adicionales. Esto se adapta al código de salida estándar 0 en Aceptar, y Cancelar proporcionaría el mismo código de salida que en caso de error.

La ilustración a continuación muestra la disposición de los elementos del diálogo:

--------------------------------------------
| TÍTULO                                   |
--------------------------------------------
|                                          |
| La imagen, si existe, se muestra aquí    |
|                                          |
--------------------------------------------
| Aquí va el texto del mensaje             |
|                                          |
--------------------------------------------
|           [Opción1] [Opción2]            |
--------------------------------------------

OPCIONES

--help Muestra información de ayuda.

--display DISPLAY Conéctate a DISPLAY en lugar de DISPLAY establecido en el entorno.

--geometry GEOMETRY Geometría de la ventana, por defecto es 200x50 expandiéndose para el tamaño de la imagen.

--image IMAGE Ruta a la imagen a mostrar.

--option STRING Título de la opción, se admiten múltiples opciones.

--title STRING Cadena de título.
