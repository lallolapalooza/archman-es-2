MYSQL_CONFIG(1) Sistema de bases de datos MySQL MYSQL_CONFIG(1)

NOMBRE

mysql_config - mostrar opciones para compilar clientes

SINOPSIS

mysql_config opciones

DESCRIPCIÓN

mysql_config le proporciona información útil para compilar su cliente MySQL y conectarlo a MySQL. Es un script de shell, por lo que solo está disponible en sistemas Unix y similares a Unix.


Nota

pkg-config se puede usar como alternativa a mysql_config para obtener información como indicadores del compilador o bibliotecas de enlace necesarias para compilar aplicaciones MySQL. Para más información, consulte Compilar programas cliente de la API C usando pkg-config[1].

mysql_config admite las siguientes opciones.

•--cflags Indicadores del compilador C para encontrar archivos de inclusión e indicadores y definiciones críticas del compilador utilizados al compilar la biblioteca libmysqlclient. Las opciones devueltas están ligadas al compilador específico que se utilizó cuando se creó la biblioteca y podrían entrar en conflicto con la configuración de su propio compilador. Use --include para obtener opciones más portátiles que contengan solo rutas de inclusión.
•--cxxflags Igual que --cflags, pero para indicadores del compilador C++.
•--include Opciones del compilador para encontrar archivos de inclusión de MySQL.
•--libs Bibliotecas y opciones necesarias para enlazar con la biblioteca cliente de MySQL.
•--libs_r Bibliotecas y opciones necesarias para enlazar con la biblioteca cliente de MySQL segura para hilos. En MySQL 8.4, todas las bibliotecas cliente son seguras para hilos, por lo que esta opción no necesita ser utilizada. La opción --libs se puede usar en todos los casos.
•--plugindir El nombre de la ruta del directorio de plugins predeterminado, definido al configurar MySQL.
•--port El número de puerto TCP/IP predeterminado, definido al configurar MySQL.
•--socket El archivo de socket Unix predeterminado, definido al configurar MySQL.
•--variable=nombre_var Muestra el valor de la variable de configuración nombrada. Los valores permitidos de nombre_var son pkgincludedir (el directorio de archivos de cabecera), pkglibdir (el directorio de bibliotecas) y plugindir (el directorio de plugins).
•--version Número de versión de la distribución de MySQL.

Si invoca mysql_config sin opciones, muestra una lista de todas las opciones que admite y sus valores:

$> mysql_config
Usage: ./mysql_config [OPTIONS]
Compiler: GNU 10.4.0
Options:
  --cflags         [-I/usr/local/mysql/include/mysql]
  --cxxflags       [-I/usr/local/mysql/include/mysql]
  --include        [-I/usr/local/mysql/include/mysql]
  --libs           [-L/usr/local/mysql/lib/mysql -lmysqlclient -lpthread -ldl  
                    -lssl  -lcrypto -lresolv -lm -lrt]
  --libs_r         [-L/usr/local/mysql/lib/mysql -lmysqlclient -lpthread -ldl  
                    -lssl  -lcrypto -lresolv -lm -lrt]
  --plugindir      [/usr/local/mysql/lib/plugin]
  --socket         [/tmp/mysql.sock]
  --port           [3306]
  --version        [8.4.0]
  --variable=VAR   VAR is one of:
          pkgincludedir [/usr/local/mysql/include]
          pkglibdir     [/usr/local/mysql/lib]
          plugindir     [/usr/local/mysql/lib/plugin]

Puede usar mysql_config dentro de una línea de comandos utilizando comillas invertidas para incluir la salida que produce para opciones específicas. Por ejemplo, para compilar y enlazar un programa cliente de MySQL, use mysql_config de la siguiente manera:

gcc -c `mysql_config --cflags` progname.c
gcc -o progname progname.o `mysql_config --libs`
