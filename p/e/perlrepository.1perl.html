NOMBRE

perlrepository - Enlaces a información actual sobre el repositorio de fuentes de Perl

DESCRIPCIÓN

El código fuente de Perl se almacena en un repositorio Git.

Consulte perlhack para obtener una explicación del desarrollo de Perl, incluida la Guía Súper Rápida de Parches para crear y enviar un pequeño parche.

Consulte perlgit para obtener información detallada sobre el repositorio Git de Perl.
