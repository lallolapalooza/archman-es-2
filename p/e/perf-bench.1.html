NOMBRE

perf-bench - Framework general para conjuntos de benchmarks

SINOPSIS

perf bench [<opciones comunes>] <subsistema> <conjunto> [<opciones>]

DESCRIPCIÓN

Este comando perf bench es un framework general para conjuntos de benchmarks.

OPCIONES COMUNES

-r, --repeat=

Especifica el número de veces que se repetirá la ejecución (por defecto 10).

-f, --format=

Especifica el estilo de formato. Los estilos de formato actualmente disponibles son:

default

Estilo por defecto. Esto es principalmente para lectura humana.
.ft C
% perf bench sched pipe                      # sin estilo especificado
(ejecutando 1000000 operaciones de pipe entre dos tareas)
        Tiempo total:5.855 seg
                5.855061 usecs/op
                170792 ops/sec
.ft

simple

Este estilo simple es amigable para el procesamiento automatizado por scripts.
.ft C
% perf bench --format=simple sched pipe      # simple especificado
5.988
.ft

SUBSISTEMA

sched

Mecanismos de planificación y IPC.

syscall

Rendimiento de llamadas al sistema (throughput).

mem

Rendimiento de acceso a memoria.

numa

Benchmarks de planificación y MM NUMA.

futex

Benchmarks de estrés futex.

epoll

Benchmarks de estrés epoll (Eventpoll).

internals

Benchmark de la funcionalidad interna de perf.

uprobe

Benchmark de la sobrecarga de uprobe + BPF.

all

Todos los subsistemas de benchmark.

CONJUNTOS PARA sched

messaging

Conjunto para evaluar el rendimiento de los mecanismos de planificación e IPC. Basado en hackbench de Rusty Russell.

Opciones de messaging

-p, --pipe

Usar pipe() en lugar de socketpair()

-t, --thread

Ser multi-hilo en lugar de multi-proceso

-g, --group=

Especificar número de grupos

-l, --nr_loops=

Especificar número de bucles

Ejemplo de messaging 

.ft C
% perf bench sched messaging                 # ejecutar con las opciones por defecto
(20 procesos remitentes y receptores por grupo)
(10 grupos == 400 procesos ejecutados)
      Tiempo total:0.308 seg
% perf bench sched messaging -t -g 20        # ser multi-hilo, con 20 grupos
(20 hilos remitentes y receptores por grupo)
(20 grupos == 800 hilos ejecutados)
      Tiempo total:0.582 seg
.ft

pipe

Conjunto para la llamada al sistema pipe(). Basado en pipe-test-1m.c de Ingo Molnar.

Opciones de pipe

-l, --loop=

Especificar número de bucles.

-G, --cgroups=

Nombres de cgroups para el remitente y receptor, separados por una coma. Esto es útil para comprobar la sobrecarga del cambio de contexto de cgroup. Tenga en cuenta que perf no crea ni elimina los cgroups, por lo que los usuarios deben asegurarse de que los cgroups existan y sean accesibles antes de usarlos.

Ejemplo de pipe 

.ft C
% perf bench sched pipe
(ejecutando 1000000 operaciones de pipe entre dos tareas)
        Tiempo total:8.091 seg
                8.091833 usecs/op
                123581 ops/sec
% perf bench sched pipe -l 1000              # bucle 1000
(ejecutando 1000 operaciones de pipe entre dos tareas)
        Tiempo total:0.016 seg
                16.948000 usecs/op
                59004 ops/sec
% perf bench sched pipe -G AAA,BBB
(ejecutando 1000000 operaciones de pipe entre cgroups)
# Ejecutando el benchmark 'sched/pipe':
# Ejecutadas 1000000 operaciones de pipe entre dos procesos
     Tiempo total: 6.886 [seg]
       6.886208 usecs/op
         145217 ops/sec
.ft

CONJUNTOS PARA syscall

basic

Conjunto para evaluar el rendimiento del throughput de llamadas al sistema centrales (métricas de usecs/op y ops/sec). Utiliza un solo hilo que realiza simplemente getppid(2), que es una llamada al sistema simple donde el resultado no es cacheadado por glibc.

CONJUNTOS PARA mem

memcpy

Conjunto para evaluar el rendimiento de copias simples de memoria de varias maneras.

Opciones de memcpy

-l, --size

Especifica el tamaño de la memoria a copiar (por defecto: 1MB). Las unidades disponibles son B, KB, MB, GB y TB (sin distinción de mayúsculas y minúsculas).

-f, --function

Especifica la función a copiar (por defecto: default). Las funciones disponibles dependen de la arquitectura. En x86-64, se soportan x86-64-unrolled, x86-64-movsq y x86-64-movsb.

-l, --nr_loops

Repite la invocación de memcpy este número de veces.

-c, --cycles

Usa el evento cpu-cycles de perf en lugar de la llamada al sistema gettimeofday.

memset

Conjunto para evaluar el rendimiento de inicialización simple de memoria de varias maneras.

Opciones de memset

-l, --size

Especifica el tamaño de la memoria a inicializar (por defecto: 1MB). Las unidades disponibles son B, KB, MB, GB y TB (sin distinción de mayúsculas y minúsculas).

-f, --function

Especifica la función a inicializar (por defecto: default). Las funciones disponibles dependen de la arquitectura. En x86-64, se soportan x86-64-unrolled, x86-64-stosq y x86-64-stosb.

-l, --nr_loops

Repite la invocación de memset este número de veces.

-c, --cycles

Usa el evento cpu-cycles de perf en lugar de la llamada al sistema gettimeofday.

CONJUNTOS PARA numa

mem

CONJUNTOS PARA epoll

Conjunto para evaluar llamadas concurrentes a epoll_wait.

CONJUNTOS PARA internals

Conjunto para evaluar el rendimiento de síntesis de eventos de perf.
