NOMBRE

perljp - Guía de referencia para programadores de Perl en japonés

説明'

¡Bienvenido al mundo de Perl!

Desde Perl 5.8.0, el soporte para Unicode se ha fortalecido considerablemente. Como resultado, se ha añadido soporte para codificaciones de caracteres distintas del latín, incluyendo las de Asia Oriental (chino, japonés y coreano). Unicode es un estándar que tiene como objetivo manejar todos los caracteres del mundo en un único juego de caracteres, e incluye caracteres de Europa del Este, Europa Occidental, el Mediterráneo, así como caracteres griegos, hebreos, árabes, siríacos, etc. que antes eran definidos independientemente por los vendedores de sistemas operativos (PC y Macintosh).

El propio Perl opera con Unicode. Los literales de cadenas de caracteres y las expresiones regulares dentro de un script de Perl asumen Unicode como base. Para la entrada y salida, el módulo estándar 'Encode' se incluye para permitir la conversión sin problemas entre Unicode y otras codificaciones de caracteres.

Por ejemplo, para convertir un archivo FOO a UTF-8, haga lo siguiente:

perl -Mencoding=FOO,STDOUT,utf8 -pe1 < file.FOO > file.utf8

Además, Perl incluye la utilidad de conversión de codificación de caracteres escrita completamente en Perl, piconv, por lo que también puede hacer lo siguiente:

piconv -f FOO -t utf8 < file.FOO > file.utf8
piconv -f utf8 -t FOO < file.utf8 > file.FOO

(jcode.pl|Jcode.pm|JPerl) Migración desde

Antes de la versión 5.8, los scripts que contenían literales en EUC-JP podían manejarlo. Además, como módulos para manejar la entrada/salida, Jcode.pm ( http://openlab.ring.gr.jp/Jcode/ ) y, como utilidad para Perl 4, jcode.pl existían y se utilizaban comúnmente en CGI japoneses. Sin embargo, era imposible manejar correctamente las expresiones regulares japonesas. Con Perl 5.005 y anteriores, existía una versión localizada para japonés, Jperl ( http://homepage2.nifty.com/kipp/perl/jperl/index.html *1 ). Además, la versión japonesa de Perl para Mac OS 9.x/Classic, MacPerl, existía como MacJPerl ( https://habilis.net/macjperl/ ). Estos podían manejar no solo EUC-JP sino también Shift_JIS como codificación de caracteres, y también eran capaces de manejar expresiones regulares japonesas.

En Perl 5.8, además de implementar estas funcionalidades en el núcleo de Perl, se pueden manejar todas las 114 codificaciones de caracteres mencionadas anteriormente, incluido el japonés, simultáneamente. Además, la obtención de módulos para nuevas codificaciones de caracteres desde CPAN se ha vuelto más sencilla.

*1: Debido a la finalización del servicio de alojamiento.

perljp - Perlの日本語ユーザーのためのページ

DESCRIPTION

このページは、Perlの使用方法や相关するリソースについて、ヤギーに箇分けています。

ユーザーのための経息

入手したしたのは、こちら Vector( https://www.vector.co.jp/soft/win95/util/se098198.html )からWindow用のバイナリを、CPAN( https://www.cpan.org/src/unsupported/4.036/jperl/ )からperl4用のパッチを入手することができます。

  • 入出力

    以下の例はいずれもShift_JISの入力をEUC-JPに変按して出力します。

    # jcode.pl
require "jcode.pl";
while(<>){
  jcode::convert(*_, 'euc', 'sjis');
  print;
}
# Jcode.pm
use Jcode;
while(<>){
      print Jcode->new($_, 'sjis')->euc;
}
# Perl 5.8
use Encode;
while(<>){
  from_to($_, 'shiftjis', 'euc-jp');
  print;
}
# Perl 5.8 - encoding を利用して
use encoding 'euc-jp', STDIN => 'shiftjis';
while(<>){
      print;
}
  • Jperl 互掛スクリプト

    いわゆる"shebang"を変更するだけで、Jperl用のscriptのほとんどは変更なしに利用可能だと思われます。

    #!/path/to/jperl
↓
#!/path/to/perl -Mencoding=euc-jp

    詳しくは perldoc encoding を参照してください。

さらに詳しく

Perlには膨大な資料が付属しており、Perlの新機能やUnicodeサポート、そしてEncodeモジュールの使用法などが細かく網羅されています（残念ながら、ほとんど英語ではありますが）。以下のコマンドでそれらの一部を閲覧することが可能です。

perldoc perlunicode # PerlのUnicodeサポート入般
perldoc Encode      # Encodeモジュールに関して
perldoc Encode::JP  # うち日本語文字コードに関して
