NOMBRE

penetrate - simula un clásico juego de disparos de arcade

SINOPSIS

penetrate [--display host:display.screen] [--root] [--window] [--window-id número] [--install] [--noinstall] [--visual visual] [--bgrowth microsegundos] [--lrate número] [--smart número] [--fps]

DESCRIPCIÓN

Penetrate simula el clásico de arcade con las ciudades y las cosas que caen del cielo y cosas así. La computadora juega contra sí misma, defendiendo desesperadamente las fuerzas del bien contra esas cositas que llueven. Se otorgan ciudades extra a intervalos cada vez mayores. Cada cinco niveles aparece una ronda de bonificación. El jugador de la computadora se vuelve progresivamente más inteligente a medida que avanza el juego. Mejor puntería, más económico con la munición y mejor selección de objetivos. Los puntos están en la parte inferior derecha y la puntuación más alta en la parte inferior izquierda. Comienza con -smart para que el jugador de la computadora se salte el proceso de aprendizaje.

OPCIONES

--display host:display.screen
Especifica qué pantalla X se debe usar.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--install
Instala un mapa de colores privado para la ventana.
--noinstall
No instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores válidos son el nombre de una clase visual o el número de identificación (decimal o hexadecimal) de un visual específico. Las opciones posibles incluyen
predeterminado, mejor, mono, monocromo, gris, color, estático gris, estático color, color verdadero, escala de grises, pseudocolor, color directo, número

Si se usa un número decimal o hexadecimal, se consulta XGetVisualInfo(3X) para obtener el visual requerido.

--foreground color
Especifica el color predeterminado del primer plano.
--background color
Especifica el color predeterminado del fondo.
--bgrowth entero
Especifica la tasa de crecimiento de las explosiones de bombas.
--lrate entero
Establece la tasa inicial de disparo láser.
-smart
Haz que el jugador de la computadora se salte el proceso de aprendizaje.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

ERRORES

La disposición de la pantalla no es exactamente la misma que la del juego que este programa intenta emular. En este programa, los misiles salen de las ciudades; cuando en realidad, se supone que hay tres bases de misiles en colinas, con las ciudades entre ellas.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN
