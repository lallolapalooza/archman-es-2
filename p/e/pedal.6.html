NOMBRE

pedal - programa de imágenes geométricas bonitas

SINOPSIS

pedal [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--delay segundos] [-maxlines número] [-mono] [--install] [--visual visual] [--fps]

DESCRIPCIÓN

El programa pedal muestra imágenes geométricas bonitas.

OPCIONES

pedal acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción predeterminada.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--foreground color
El color para el primer plano. El valor predeterminado es blanco.
--background color
El color para el fondo. El valor predeterminado es negro.
--delay segundos
El número de segundos a esperar entre cada imagen.
--maxlines número
El número máximo de líneas en el dibujo. Buenos valores están entre 20 y 2000. El valor máximo es 16K.

Para hacer que tu servidor X trabaje intensamente, y para impresionar a tus amigos, prueba pedal -mono -delay 0 -maxlines 100.

--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.

VER TAMBIÉN

X(1), xscreensaver(1)
