PERLAMIGA(1perl) Guía de Referencia para Programadores de Perl PERLAMIGA(1perl)

NOMBRE

perlamiga - Perl bajo AmigaOS 4.1

NOTA

Este es un port de Perl 5.22.1, es un port nuevo y no es compatible de ninguna manera con mis ports anteriores de Perl 5.8 y 5.16.3. Esto significa que necesitará reinstalar / reconstruir cualquier módulo de terceros que haya instalado.

Se requiere newlib.library versión 53.28 o superior.

SINOPSIS

Una vez que Perl esté instalado, puede leer este documento de la siguiente manera:

sh -c "perldoc perlamiga"

O puede leerlo tal cual: ya sea como README.amiga, o pod/perlamiga.pod.

DESCRIPCIÓN

Prerrequisitos para ejecutar Perl 5.22.1 bajo AmigaOS 4.1

AmigaOS 4.1 update 6 con todas las actualizaciones aplicadas hasta el 9 de octubre de 2013
La más importante de ellas es:
newlib.library versión 53.28 o superior
SDK de AmigaOS
Perl se instala en la estructura de directorios del SDK y espera que muchas de las herramientas de compilación presentes en el SDK estén disponibles. Por lo tanto, para obtener los mejores resultados, instale primero el SDK.
abc-shell
Si no tiene el SDK instalado, debe tener al menos abc-shell instalado o algún otro port de sh adecuado. Esto es necesario para ejecutar comandos externos y debería estar disponible como 'sh' en su PATH.

Iniciando programas Perl bajo AmigaOS 4.1

Perl puede ejecutarse desde la shell de AmigaOS, pero para obtener mejores resultados, debería ejecutarse bajo abc-shell. (abc-shell maneja la expansión de globos de archivos, la expansión de patrones y configura las variables de entorno de la manera UN*X que Perl espera).

Por ejemplo:

New Shell process 10
10.AmigaOS4:> sh
/AmigaOS4>perl ruta:a/mi_prog arg1 arg2 arg3

Abc-shell también puede lanzar programas a través de la sintaxis #! al principio del archivo del programa. Es mejor usar el formato #!SDK:Local/C/perl para que la shell de AmigaOS también pueda encontrar Perl de la misma manera. AmigaOS requiere que el bit de script esté configurado para que esto funcione.

10.AmigaOS4:> sh
/AmigaOS4>mi_prog arg1 arg2 arg3

Limitaciones de Perl bajo AmigaOS 4.1

Los programas de tubería anidados pueden fallar al ejecutarse desde shells abc antiguas
La versión 53.2 de abc-shell tiene un error que puede causar fallos en los subprocesos utilizados para ejecutar programas canalizados. Si hay disponible una versión posterior, debería instalarla en su lugar.
Desanidación de línea de comandos incorrecta o inesperada
newlib.library 53.30 y anteriores desanidan incorrectamente secuencias de escape con barra invertida, por ejemplo, \" \n \t, etc., lo que requiere un escape adicional inusual.
Iniciar subprocesos a través de open tiene limitaciones
open FH, "comando |"

Los subprocesos iniciados con open utilizan una rutina popen() mínima y, por lo tanto, no devuelven pids utilizables con waitpid, etc.

Si encuentra alguna otra limitación o error, hágamelo saber.
Por favor, informe de los errores en esta versión de perl a andy@broad.ology.org.uk en primera instancia.

INSTALACIÓN

Esta guía asume que ha obtenido un archivo precompilado de os4depot.net.

Descomprima el archivo principal en una ubicación temporal (RAM: está bien).

Ejecute el script de instalación proporcionado desde la shell o a través de su icono.

No debe intentar instalar manualmente.

Una vez instalado, puede eliminar el archivo temporal.

Este enfoque conservará los enlaces en la instalación sin crear binarios duplicados.

Si tiene instalados los ports anteriores de perl 5.16 o 5.8, es posible que desee renombrar su ejecutable de perl a perl516 o perl58 o algo similar antes de la instalación de 5.22.1, esto le permitirá usar ambas versiones al mismo tiempo.

Módulos Específicos de Amiga

Amiga::ARexx

El módulo Amiga::ARexx le permite crear fácilmente un host ARexx basado en perl o enviar comandos ARexx a otros programas.

Pruebe "perldoc Amiga::ARexx" para más información.

Amiga::Exec

El módulo Amiga::Exec introduce soporte para Wait().

Pruebe "perldoc Amiga::Exec" para más información.

COMPILACIÓN

Para compilar Perl bajo AmigaOS desde las fuentes parcheadas, necesitará tener una versión reciente del SDK. Se recomienda la versión 53.29, las versiones anteriores probablemente también funcionen.

Con la ayuda de Jarkko Hietaniemi, el sistema Configure se ha ajustado para ejecutarse bajo abc-shell, por lo que el proceso de compilación recomendado es el siguiente:

stack 2000000
sh Configure -de
gmake

Esto compilará la configuración predeterminada que se instala en SDK:local/newlib/lib/

NAME

perlamiga - Implementación de Perl para Amiga

NOTE

Este es un manual de la comunidad de Arch Linux y puede no ser una representación precisa de la página del manual oficial.

SYNOPSIS

perlamiga [opciones] [-e] ['programa'] [argumentos]
perlamiga -n [opciones] ['programa'] [argumentos]
perlamiga -p [opciones] ['programa'] [argumentos]
perlamiga -d [opciones] ['programa'] [argumentos]
perlamiga -x [opciones] ['archivo'] [argumentos]
perlamiga -c [opciones] ['archivo']
perlamiga -[letras de opción]

DESCRIPTION

Perl es un lenguaje de programación interpretado, dinámico, de alto nivel y de propósito general. El intérprete de Perl para Amiga es una versión de Perl adaptada para el sistema operativo Amiga.

Permite escribir scripts para automatizar tareas, manipular texto, desarrollar aplicaciones y mucho más. Esta implementación específica se centra en la compatibilidad y el rendimiento en la plataforma Amiga.

INSTALLATION

Para instalar Perl en Arch Linux, asegúrate de que tu sistema esté actualizado y luego instala el paquete 'perl':

sudo pacman -Syu perl

Para la implementación específica de Amiga, es posible que debas buscar paquetes o compilaciones disponibles para esa plataforma, o compilar Perl desde la fuente adaptada para Amiga.

Amiga Specific Modules

Existen módulos específicos para Amiga que extienden la funcionalidad de Perl en esta plataforma. Estos módulos pueden proporcionar acceso a las características del sistema operativo Amiga, como la interfaz gráfica, el manejo de archivos, la comunicación entre procesos, etc. La instalación de estos módulos puede variar.

BUILDING

Para compilar Perl para Amiga desde la fuente, necesitarás un entorno de desarrollo adecuado para Amiga (como GCC para Amiga) y las fuentes de Perl adaptadas para Amiga. El proceso general implicaría configurar, compilar e instalar.

CHANGES

Las notas de la versión detallan los cambios y las nuevas características introducidas en cada versión de Perl, incluyendo las adaptaciones específicas para Amiga. Consulta la documentación oficial o las notas de la versión del paquete específico de Amiga para obtener detalles.
