perfmonctl(2) Manual de llamadas al sistema perfmonctl(2)

NOMBRE

perfmonctl - interfaz a la unidad de monitorización de rendimiento IA-64

SINOPSIS

#include <syscall.h>
#include <perfmon.h>
long perfmonctl(int narg;
                int fd, int cmd, void arg[narg], int narg);

Nota: No hay un envoltorio de glibc para esta llamada al sistema; véase HISTORIA.

DESCRIPCIÓN

La llamada al sistema específica de IA-64 perfmonctl() proporciona una interfaz a la PMU (unidad de monitorización de rendimiento). La PMU consta de registros PMD (datos de monitorización de rendimiento) y registros PMC (control de monitorización de rendimiento), que recopilan estadísticas de hardware.

perfmonctl() aplica la operación cmd a los argumentos de entrada especificados por arg. El número de argumentos se define por narg. El argumento fd especifica el contexto perfmon sobre el que operar.

Los valores admitidos para cmd son:

PFM_CREATE_CONTEXT
perfmonctl(int fd, PFM_CREATE_CONTEXT, pfarg_context_t *ctxt, 1);
Configura un contexto.
El parámetro fd se ignora. Se crea un nuevo contexto perfmon especificado en ctxt y su descriptor de archivo se devuelve en ctxt->ctx_fd.
El descriptor de archivo se puede usar en llamadas posteriores a perfmonctl() y se puede utilizar para leer notificaciones de eventos (tipo pfm_msg_t) usando read(2). El descriptor de archivo se puede consultar usando select(2), poll(2) y epoll(7).
El contexto se puede destruir llamando a close(2) sobre el descriptor de archivo.
PFM_WRITE_PMCS
perfmonctl(int fd, PFM_WRITE_PMCS, pfarg_reg_t *pmcs, n);
Establece registros PMC.
PFM_WRITE_PMDS
perfmonctl(int fd, PFM_WRITE_PMDS, pfarg_reg_t *pmds, n);
Establece registros PMD.
PFM_READ_PMDS
perfmonctl(int fd, PFM_READ_PMDS, pfarg_reg_t *pmds, n);
Lee registros PMD.
PFM_START
perfmonctl(int fd, PFM_START, NULL, 0);
Inicia la monitorización.
PFM_STOP
perfmonctl(int fd, PFM_STOP, NULL, 0);
Detiene la monitorización.
PFM_LOAD_CONTEXT
perfmonctl(int fd, PFM_LOAD_CONTEXT, pfarg_load_t *largs, 1);
Adjunta el contexto a un hilo.
PFM_UNLOAD_CONTEXT
perfmonctl(int fd, PFM_UNLOAD_CONTEXT, NULL, 0);
Desvincula el contexto de un hilo.
PFM_RESTART
perfmonctl(int fd, PFM_RESTART, NULL, 0);
Reinicia la monitorización después de recibir una notificación de desbordamiento.
PFM_GET_FEATURES
perfmonctl(int fd, PFM_GET_FEATURES, pfarg_features_t *arg, 1);
PFM_DEBUG
perfmonctl(int fd, PFM_DEBUG, val, 0);
Si val es distinto de cero, habilita el modo de depuración, de lo contrario, lo deshabilita.
PFM_GET_PMC_RESET_VAL
perfmonctl(int fd, PFM_GET_PMC_RESET_VAL, pfarg_reg_t *req, n);
Restablece los registros PMC a los valores predeterminados.

VALOR DE RETORNO

perfmonctl() devuelve cero cuando la operación es exitosa. En caso de error, devuelve -1 y errno se establece para indicar el error.

ESTÁNDARES

Linux en IA-64.

HISTORIA

Añadida en Linux 2.4; eliminada en Linux 5.10.

Esta llamada al sistema estuvo rota durante muchos años y, finalmente, fue eliminada en Linux 5.10.

glibc no proporciona un envoltorio para esta llamada al sistema; en kernels donde existe, llámala usando syscall(2).
