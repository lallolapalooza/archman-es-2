NOMBRE

pedigree - crear un archivo TeX para un pedigrí a partir de un archivo csv

SINOPSIS

pedigree [-c archivo_configuración] [-d] [-o archivo_salida] [-s id_inicio] archivo_entrada

pedigree -v

DESCRIPCIÓN

El programa convierte un archivo_entrada separado por comas en un archivo TeX con macros pst-pdgr.

OPCIONES

-c archivo_configuración
El archivo de configuración a leer junto con los archivos de configuración del sistema y del usuario.
-d
Modo de depuración activado.
-o -archivo_salida
El archivo de salida en lugar de archivo_entrada.tex.
-s -id_inicio
Si se selecciona esta opción, el pedigrí se construye a partir del nodo con el ID id_inicio. De lo contrario, se inicia desde el nodo del probando.

Esta opción permite crear pedigrís con múltiples probandos o probandos ausentes, o mostrar personas que no son parientes del probando.

-v
Mostrar información de la versión.

ARCHIVOS

/etc/pedigree.cfg
Archivo de configuración global.
$HOME/.pedigreerc
Archivo de configuración del usuario.

VER TAMBIÉN

El manual distribuido con este programa describe el formato del archivo de configuración y del archivo de entrada.

Las funciones de la biblioteca se describen en Pedigree::Language(3), Pedigree::Parser(3), Pedigree::Node(3), Pedigree::PersonNode(3), Pedigree::MarriageNode(3), Pedigree::Area(3).
