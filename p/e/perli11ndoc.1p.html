PERLI11NDOC(1p) Documentación de Perl aportada por el usuario PERLI11NDOC(1p)

NOMBRE

perli11ndoc - ver la documentación de bibliotecas instaladas enlazadas usando Glib::Object::Introspection

RESUMEN

perli11ndoc permite ver la documentación de Perl para bibliotecas Glib enlazadas a Perl usando Glib::Object::Introspection. Glib::Object::Introspection utiliza los proyectos gobject-introspection y libffi para crear dinámicamente enlaces de Perl para una amplia variedad de bibliotecas. Los ejemplos incluyen gtk+, webkit, libsoup y muchos más. Todas las bibliotecas instaladas actualmente se mostrarán con documentación y ejemplos específicos de Perl. Donde Glib::Object::Introspection difiere de la biblioteca C, se señalan las diferencias y se define la interfaz específica de Perl.

DEPENDENCIAS

perli11ndoc requiere que XML::LibXML esté instalado para ejecutarse. También requiere que las cabeceras correspondientes de la biblioteca C estén instaladas en el sistema para proporcionar documentación. Por ejemplo, en un sistema basado en Debian, necesitarías libgtk-3-dev para ver la documentación introspeccionada por Perl de Gtk3.
