NOMBRE

perf-iostat - Muestra métricas de rendimiento de E/S

SINOPSIS

perf iostat list
perf iostat <puertos> -- <comando> [<opciones>]

DESCRIPCIÓN

El modo está destinado a proporcionar cuatro métricas de rendimiento de E/S por cada puerto raíz PCIe:

•Lectura de entrada - Los dispositivos de E/S debajo del puerto raíz leen de la memoria del host, en MB
•Escritura de entrada - Los dispositivos de E/S debajo del puerto raíz escriben en la memoria del host, en MB
•Lectura de salida - El CPU lee de los dispositivos de E/S debajo del puerto raíz, en MB
•Escritura de salida - El CPU escribe en los dispositivos de E/S debajo del puerto raíz, en MB

OPCIONES

<comando>...

Cualquier comando que puedas especificar en una shell.

list

Lista todos los puertos raíz PCIe.

<puertos>

Selecciona los puertos raíz para monitorizar. Se admite una lista separada por comas.

EJEMPLOS

1.Lista todos los puertos raíz PCIe (ejemplo para plataforma 2-S): 
$ perf iostat list
S0-uncore_iio_0<0000:00>
S1-uncore_iio_0<0000:80>
S0-uncore_iio_1<0000:17>
S1-uncore_iio_1<0000:85>
S0-uncore_iio_2<0000:3a>
S1-uncore_iio_2<0000:ae>
S0-uncore_iio_3<0000:5d>
S1-uncore_iio_3<0000:d7>
2.Recopila métricas para todos los puertos raíz PCIe: 
$ perf iostat -- dd if=/dev/zero of=/dev/nvme0n1 bs=1M oflag=direct
357708+0 registros en
357707+0 registros fuera
375083606016 bytes (375 GB, 349 GiB) copiados, 215.974 s, 1.7 GB/s

0000:00                    1                    0                    2                    3
0000:80                    0                    0                    0                    0
0000:17               352552                   43                    0                   21
0000:85                    0                    0                    0                    0
0000:3a                    3                    0                    0                    0
0000:ae                    0                    0                    0                    0
0000:5d                    0                    0                    0                    0
0000:d7                    0                    0                    0                    0
3.Recopila métricas para una lista separada por comas de puertos raíz PCIe: 
$ perf iostat 0000:17,0:3a -- dd if=/dev/zero of=/dev/nvme0n1 bs=1M oflag=direct
