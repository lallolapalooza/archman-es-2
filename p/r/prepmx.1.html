NOMBRE

prepmx - preprocesador para PMX, programa de composición musical fácil

SINOPSIS

prepmx [opciones] nombre_de_trabajo [dir_salida/] [archivo_estilo]

DESCRIPCIÓN

M-Tx es un lenguaje preprocesador fácil de usar para el programa de composición musical PMX, dirigido a personas que no son expertas. Para un ejemplo sencillo, echa un vistazo al siguiente ejemplo:


c2+ e4 g | b4d- c1 d c2 |
c8 g+ e g c- g+ e g | d g f g c- g+ e g |

Para referencia de sintaxis, por favor consulta el manual de M-Tx escrito por Dirk Laurie, el creador del lenguaje M-Tx y el autor de prepmx(1), su utilidad de línea de comandos.

prepmx procesa el archivo nombre_de_trabajo.mtx para generar nombre_de_trabajo.pmx. Luego puedes procesar este archivo usando el comando pmxab(1), que es un preprocesador para MusiXTeX.

dir_salida/ es el directorio donde `pmx' colocará el archivo .tex final. Ten en cuenta que la barra inclinada final es obligatoria. Puedes proporcionar un archivo_estilo para M-Tx. Si se omite, se usa el archivo `mtxstyle.txt' en el directorio actual, si existe.

OPCIONES

Las opciones también se pueden especificar en una línea `Options:' en el preámbulo, lo que tiene precedencia sobre la línea de comandos.

-b
desactivar unbeamVocal
-c
desactivar doChords
-D
activar debugMode
-f
activar solfaNoteNames
-i
activar ignoreErrors
-m
desactivar doLyrics
-n
activar instrumentNames
-t
desactivar doUptext
-u
desactivar uptextOnRests
-v
activar beVerbose
-w
activar pedanticWarnings
-n
seleccionar Caso Especial n
-H
imprimir el estado activado de todas las opciones

ESTADO DE SALIDA

Si no se encontró ningún error, prepmx sale con el código de retorno 0. En caso de error, se devuelve el número de línea del archivo procesado. Esto puede no ser siempre la línea que contiene el error real. Un estado de retorno de 10000 significa que el archivo de entrada estaba vacío o no se pudo abrir.
