FBB::PrimeFactors(3bobcat) Factorización de Primos FBB::PrimeFactors(3bobcat)

NOMBRE

FBB::PrimeFactors - Realiza la factorización de números primos de valores (BigInt)

SINOPSIS

#include <bobcat/primefactors>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Los valores integrales se dividen en dos categorías: números primos, cuyos únicos divisores integrales son sus propios valores y 1, y números compuestos, que también tienen al menos otro divisor integral (primo). Todos los valores integrales compuestos pueden factorizarse como el producto de números primos. Por ejemplo, 6 puede factorizarse como 2 * 3; 8 puede factorizarse como 2 * 2 * 2. Encontrar estos factores primos se llama factorización de números primos, o `factorización de primos'. Al factorizar un valor, sus factores primos a veces pueden usarse repetidamente como divisores integrales: 8 se factoriza como pow(2, 3), y 36 se factoriza como

    36 = pow(2, 2) * pow(3, 2)

La clase FBB::PrimeFactors realiza factorizaciones de números primos de valores FBB::BigInt. Al factorizar un valor, deben estar disponibles números primos hasta sqrt(valor), ya que los números primos hasta sqrt(valor) pueden ser factores de valor. Actualmente PrimeFactors utiliza el tamiz de Eratóstenes para encontrar estos números primos. Para encontrar el siguiente número primo después de lastPrime, el tamiz de Eratóstenes debe usarse repetidamente para lastPrime += 2 hasta que lastPrime sea primo. Una vez determinados, los números primos pueden usarse por supuesto directamente para determinar el siguiente número primo o para factorizar un valor integral. Para acelerar la factorización de números primos y el tamiz de Eratóstenes, PrimeFactors guarda todos sus números primos calculados en un std::vector o en un archivo. Una vez determinados, estos números primos pueden ser utilizados nuevamente al factorizar el siguiente valor integral.

Después de factorizar un valor integral, sus factores primos y las potencias asociadas se ponen a disposición en un vector de estructuras (PrimeFactors::PrimePower), que contiene los factores primos ordenados del valor y sus potencias asociadas.

CONSTRUCTORES

o
PrimeFactors(BigIntVector &primes):
Los números primos que se determinaron al factorizar valores se recopilan en el BigIntVector que se pasa como argumento a este constructor.
Inicialmente, el BigIntVector pasado como argumento puede estar vacío o puede contener al menos dos primos (que deben ser, respectivamente, 2 y 3). Los números primos en primes deben estar ordenados. El constructor no verifica si los números primos están realmente ordenados, pero si el BigIntVector contiene primos, sí verifica si los dos primeros números primos son efectivamente 2 y 3. Se lanza una FBB::Exception si esta condición no se cumple.
Mientras se factorizan números, se pueden agregar nuevos números primos a primes, y primes puede ser reutilizado por otros objetos PrimeFactors.
o
PrimeFactors(std::string const &name = "~/.primes", size_t blockSize = 1000):
Los números primos que se determinan al factorizar valores se recopilan en un stream cuyo nombre se pasa como argumento a este constructor. Por defecto se usa ~/.primes. Si name comienza con `~/`, entonces esta cadena se reemplaza por el directorio de inicio del usuario.
Los primos se leen del stream nombrado en bloques de como máximo blockSize, y los nuevos primos se envían a este stream una vez que se han generado blockSize nuevos primos o cuando el objeto PrimeFactors (es decir, el último objeto PrimeFactors que comparte el stream) deja de existir.
Si el stream aún no existe, es creado por PrimeFactors. El stream puede estar vacío, o debe contener números primos ordenados y delimitados por espacios en blanco (insertados como valores BigInt hexadecimales). Los dos primeros primos de este archivo deben ser, respectivamente, 2 y 3. El constructor no verifica si los números primos están realmente ordenados, pero si el stream contiene primos, sí verifica si los dos primeros números primos son efectivamente 2 y 3. Se lanza una FBB::Exception si esta condición no se cumple.
Mientras se factorizan números, se pueden agregar nuevos números primos al stream, y el stream puede ser reutilizado por otros objetos PrimeFactors.

Se dispone de constructores de copia y de movimiento (y operadores de asignación).

Los objetos FBB::PrimeFactor creados usando el constructor de copia o que reciben sus valores utilizando el operador de asignación de copia comparten el dispositivo de almacenamiento de números primos (el BigIntVector o el stream que contiene los primos) con sus objetos fuente.

FUNCIÓN MIEMBRO

o
Factors const &factorize(BigInt const &value):
Se determinan los factores primos de value y se devuelven en los vectores PrimeFactors::Factors. Mientras se determinan los factores primos de value, se pueden agregar nuevos números primos al BigIntVector o al stream que se pasa al objeto PrimeFactors. Los elementos de PrimeFactors::Factors están ordenados por sus números primos. El primer elemento contiene el factor primo más pequeño del valor.

EJEMPLO

#include <iostream>
#include <bobcat/primefactors>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    PrimeFactors pf1("/tmp/primes");
    PrimeFactors::Factors const *factors = &pf1.factorize(stoull(argv[1]));
    cout << "Usando /tmp/primes:\n";
    for (auto &factor: *factors)
        cout << factor.prime << "**" << factor.power << ’ ’;
    vector<BigInt> primes;
    PrimeFactors pf2(primes);
    factors = &pf2.factorize(stoull(argv[1]));
    cout << "\n"
            "Usando BigIntVector:\n";
    for (auto &factor: *factors)
        cout << factor.prime << "**" << factor.power << ’ ’;
    cout << "\n"
            "Primos recolectados: ";
    for (auto &prime: primes)
        cout << prime << ’ ’;
    cout << ’\n’;
}

Si este programa se ejecuta con el argumento 1950, produce la siguiente salida:

    Usando /tmp/primes:
    2**1 3**1 5**2 13**1
    Usando BigIntVector:
    2**1 3**1 5**2 13**1
    Primos recolectados: 2 3 5 7 11 13
