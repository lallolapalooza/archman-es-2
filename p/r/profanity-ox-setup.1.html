man(1) Cliente XMPP Profanity man(1)

NOMBRE

Profanity - un cliente XMPP simple basado en consola.

DESCRIPCIÓN

Esta página del manual tiene como objetivo ayudarte a configurar XEP-0374: OpenPGP para Mensajería Instantánea XMPP. También conocido como OX.

Para obtener detalles sobre el uso, consulta el manual profanity-ox o /help ox.

Profanity quiere dar al usuario la máxima libertad para configurar su sistema. Por lo tanto, no tocaremos tu configuración GPG directamente. Lo que significa que deberás realizar algunos pasos manuales. Se describen aquí.

Generar material de clave OpenPGP

El primer paso es crear un par de claves OpenPGP. La generación del par de claves se realizará con el comando gpg de GnuPG.

gpg --quick-generate-key xmpp:alice@domain.tld future-default default 3y

Este comando generará una clave OpenPGP con un UID xmpp:alice@domain.tld. La opción future-default se ha utilizado para generar una clave ed25519/cv25519. La clave está configurada para expirar en tres años.

Reemplaza la ID de Jabber con tu JID y no olvides el prefijo de URI xmpp:.

Ejemplo de salida:

pub   ed25519 2021-09-21 [SC] [caduca: 2024-09-20]
      583BAE703A801095B6B71A56BD801174B1A0B84A
uid                      xmpp:alice@domain.tld
sub   cv25519 2021-09-21 [E]

Exportar tu clave pública

Necesitas exportar tu clave pública para poder subirla más tarde a un nodo PEP. Es solo una forma en que tus compañeros de chat pueden recuperar la clave pública de ti. Usa el comando a continuación para exportar la clave pública:

Comando de ejemplo:

gpg --export \
  --export-options export-minimal \
  --export-filter 'keep-uid=uid =~ xmpp:alice@domain.tld' \
  --export-filter 'drop-subkey=usage =~ a' \
  583BAE703A801095B6B71A56BD801174B1A0B84A \
  > /tmp/pep-key.gpg

La clave se exportará a /tmp/pep-key.gpg. Puedes verificar la clave con el comando a continuación:

gpg --show-key --with-sig-list /tmp/pep-key.gpg

Ten en cuenta: Las claves públicas pueden tener alguna información (firmas, nombre, dirección de correo electrónico). Ten cuidado con qué datos se exportan. Las opciones export-options y export-filter de GnuPG te ayudarán a filtrar los datos.

Publicar tu clave

Puedes usar profanity para publicar tu clave exportada en tu cuenta (PEP). El comando /ox announce publicará tu clave.

/ox announce /tmp/pep-key.gpg

El comando creará dos registros de nodo PEP para almacenar la clave.

Descubrir claves

Para descubrir las claves públicas de tus compañeros, usa el comando /ox discover.

Ejemplo de salida:

/ox discover buddy@domain.tld
Descubriendo Clave Pública para buddy@domain.tld 
1234567890ABCDEF1234567890ABCDEF12345678

Para solicitar e importar una clave, puedes usar el comando /ox request.

/ox request buddy@domain.tld 1234567890ABCDEF1234567890ABCDEF12345678
Solicitando Clave Pública 1234567890ABCDEF1234567890ABCDEF12345678 para buddy@domain.tld
Clave Pública importada

La clave se importará en tu keyring de gnupg.

Firmar la clave importada

La clave se puede mostrar a través de gpg gpg -k xmpp:buddy@domain.tld. Asegúrate de que la clave sea la clave de tu compañero y firma la clave con tu clave.

gpg --ask-cert-level --default-key 583BAE703A801095B6B71A56BD801174B1A0B84A --sign-key 1234567890ABCDEF1234567890ABCDEF12345678

El comando /ox contacts mostrará las claves con UID XMPP. El comando /ox keys mostrará todas las claves OpenPGP conocidas.

Solo una vez que hayas firmado la clave, podrás usar OX con tu compañero.

Usar OX

Dentro de una ventana de chat, puedes iniciar OX con /ox start y detenerlo con /ox end.

Los mensajes se enviarán firmados y cifrados.
