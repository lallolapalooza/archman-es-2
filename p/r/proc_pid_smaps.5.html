NOMBRE

proc_pid_smaps(5) — XXX: ¿Qué significa la 's' en "smaps"?

DESCRIPCIÓN

/proc/pid/smaps (desde Linux 2.6.14)
Este archivo muestra el consumo de memoria para cada uno de los mapeos del proceso. (El comando pmap(1) muestra información similar, en un formato que puede ser más fácil de analizar). Para cada mapeo hay una serie de líneas como la siguiente:

00400000-0048a000 r-xp 00000000 fd:03 960637       /bin/bash
Size:                552 kB
Rss:                 460 kB
Pss:                 100 kB
Shared_Clean:        452 kB
Shared_Dirty:          0 kB
Private_Clean:         8 kB
Private_Dirty:         0 kB
Referenced:          460 kB
Anonymous:             0 kB
AnonHugePages:         0 kB
ShmemHugePages:        0 kB
ShmemPmdMapped:        0 kB
Swap:                  0 kB
KernelPageSize:        4 kB
MMUPageSize:           4 kB
Locked:                0 kB
ProtectionKey:         0
VmFlags: rd ex mr mw me dw

La primera de estas líneas muestra la misma información que se muestra para el mapeo en /proc/pid/maps. Las siguientes líneas muestran el tamaño del mapeo, la cantidad del mapeo que está actualmente residente en RAM ("Rss"), la parte proporcional de este mapeo que le corresponde al proceso ("Pss"), el número de páginas compartidas limpias y sucias en el mapeo, y el número de páginas privadas limpias y sucias en el mapeo. "Referenced" indica la cantidad de memoria actualmente marcada como referenciada o accedida. "Anonymous" muestra la cantidad de memoria que no pertenece a ningún archivo. "Swap" muestra cuánta memoria que sería anónima también se usa, pero está en swap.
La línea "KernelPageSize" (disponible desde Linux 2.6.29) es el tamaño de página utilizado por el kernel para respaldar el área de memoria virtual. Esto coincide con el tamaño utilizado por la MMU en la mayoría de los casos. Sin embargo, un contraejemplo ocurre en los kernels PPC64 donde un kernel que usa 64 kB como tamaño de página base aún puede usar páginas de 4 kB para la MMU en procesadores más antiguos. Para distinguir los dos atributos, la línea "MMUPageSize" (también disponible desde Linux 2.6.29) informa el tamaño de página utilizado por la MMU.
La línea "Locked" indica si el mapeo está bloqueado en memoria o no.
La línea "ProtectionKey" (disponible desde Linux 4.9, solo en x86) contiene la clave de protección de memoria (ver pkeys(7)) asociada con el área de memoria virtual. Esta entrada solo está presente si el kernel fue compilado con la opción de configuración CONFIG_X86_INTEL_MEMORY_PROTECTION_KEYS (desde Linux 4.6).
La línea "VmFlags" (disponible desde Linux 3.8) representa las banderas del kernel asociadas con el área de memoria virtual, codificadas utilizando los siguientes códigos de dos letras:
rd legible
wr escribible
ex ejecutable
sh compartido
mr puede leer
mw puede escribir
me puede ejecutar
ms puede compartir
gd el segmento de pila crece hacia abajo
pf rango PFN puro
dw deshabilitar escritura en el archivo mapeado
lo las páginas están bloqueadas en memoria
io área de E/S mapeada en memoria
sr se proporciona la indicación de lectura secuencial
rr se proporciona la indicación de lectura aleatoria
dc no copiar el área al hacer fork
de no expandir el área al remapear
ac el área es contable
nr no se reserva espacio de swap para el área
ht el área utiliza páginas huge tlb
sf realizar fallos de página síncronos (desde Linux 4.15)
nl mapeo no lineal (eliminado en Linux 4.0)
ar bandera específica de la arquitectura
wf borrar al hacer fork (desde Linux 4.14)
dd no incluir el área en el volcado principal
sd bandera soft-dirty (desde Linux 3.13)
mm área de mapeo mixto
hg bandera de indicación de página grande
nh bandera de indicación de no página grande
mg bandera de indicación de fusión
um seguimiento de páginas faltantes userfaultfd (desde Linux 4.3)
uw seguimiento de páginas wprotect userfaultfd (desde Linux 4.3)
El archivo /proc/pid/smaps está presente solo si la opción de configuración del kernel CONFIG_PROC_PAGE_MONITOR está habilitada.
