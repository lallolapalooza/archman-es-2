pr29_strerror(3)

Paquete: libidn

Licencias: GPL3, LGPL

pr29_strerror(3) libidn pr29_strerror(3)

NOMBRE

pr29_strerror - función de la API

SINOPSIS

#include <pr29.h>

const char * pr29_strerror(Pr29_rc rc);

ARGUMENTOS

Pr29_rc rc
un código de retorno Pr29_rc.

DESCRIPCIÓN

Convierte un entero de código de retorno a una cadena de texto. Esta cadena puede usarse para mostrar un mensaje de diagnóstico al usuario.

PR29_SUCCESS

Operación exitosa. Se garantiza que este valor siempre será cero, los restantes solo se garantizan que contendrán valores distintos de cero, para fines de comparación lógica.

PR29_PROBLEM

Se encontró una secuencia problemática.

PR29_STRINGPREP_ERROR

La conversión del conjunto de caracteres falló (solo para pr29_8z()).

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una descripción del error con el código de retorno rc .
