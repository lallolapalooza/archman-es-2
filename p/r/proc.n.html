proc(n) Comandos integrados de Tcl proc(n)

NOMBRE

proc - Crear un procedimiento Tcl

SINOPSIS

proc nombre argumentos cuerpo

DESCRIPCIÓN

El comando proc crea un nuevo procedimiento Tcl llamado nombre, reemplazando cualquier comando o procedimiento existente que pueda haber tenido ese nombre. Cada vez que se invoque el nuevo comando, el contenido de cuerpo será ejecutado por el intérprete Tcl. Normalmente, nombre no está cualificado (no incluye los nombres de ningún espacio de nombres contenedor), y el nuevo procedimiento se crea en el espacio de nombres actual. Si nombre incluye algún calificador de espacio de nombres, el procedimiento se crea en el espacio de nombres especificado. Argumentos especifica los argumentos formales del procedimiento. Consiste en una lista, posiblemente vacía, cada uno de cuyos elementos especifica un argumento. Cada especificador de argumento es también una lista con uno o dos campos. Si hay un solo campo en el especificador, entonces es el nombre del argumento; si hay dos campos, entonces el primero es el nombre del argumento y el segundo es su valor predeterminado. Los argumentos con valores predeterminados que son seguidos por argumentos no predeterminados se convierten en argumentos obligatorios; se deben suministrar suficientes argumentos reales para permitir todos los argumentos hasta el último argumento formal obligatorio.

Cuando se invoca nombre, se creará una variable local para cada uno de los argumentos formales del procedimiento; su valor será el valor del argumento correspondiente en el comando invocador o el valor predeterminado del argumento. Los argumentos reales se asignan a los argumentos formales estrictamente en orden. Los argumentos con valores predeterminados no necesitan ser especificados en una invocación de procedimiento. Sin embargo, debe haber suficientes argumentos reales para todos los argumentos formales que no tienen valores predeterminados, y no debe haber argumentos reales adicionales. Los argumentos con valores predeterminados que son seguidos por argumentos no predeterminados se convierten de facto en argumentos obligatorios, aunque esto puede cambiar en una versión futura de Tcl; el código portable debe asegurarse de que todos los argumentos opcionales vienen después de todos los argumentos obligatorios.

Hay un caso especial para permitir procedimientos con un número variable de argumentos. Si el último argumento formal tiene el nombre “args”, entonces una llamada al procedimiento puede contener más argumentos reales que los que el procedimiento tiene argumentos formales. En este caso, todos los argumentos reales a partir del que se asignaría a args se combinan en una lista (como si se hubiera utilizado el comando list); este valor combinado se asigna a la variable local args.

Cuando se ejecuta cuerpo, los nombres de las variables normalmente se refieren a variables locales, que se crean automáticamente cuando se referencian y se eliminan cuando el procedimiento retorna. Se crea automáticamente una variable local para cada uno de los argumentos del procedimiento. A otras variables solo se puede acceder invocando uno de los comandos global, variable, upvar o namespace upvar. El espacio de nombres actual cuando se ejecuta cuerpo será el espacio de nombres en el que existe el nombre del procedimiento, que será el espacio de nombres en el que se creó a menos que haya sido cambiado con rename.

El comando proc devuelve una cadena vacía. Cuando se invoca un procedimiento, el valor de retorno del procedimiento es el valor especificado en un comando return. Si el procedimiento no ejecuta un explícito return, entonces su valor de retorno es el valor del último comando ejecutado en el cuerpo del procedimiento. Si ocurre un error al ejecutar el cuerpo del procedimiento, entonces el procedimiento en su conjunto devolverá ese mismo error.

EJEMPLOS

Este es un procedimiento que toma dos argumentos e imprime su suma y su producto. También devuelve la cadena "OK" al llamador como resultado explícito.

proc imprimirSumaProducto {x y} {
    set suma [expr {$x + $y}]
    set prod [expr {$x * $y}]
    puts "la suma es $suma, el producto es $prod"
    return "OK"
}

Este es un procedimiento que acepta un número arbitrario de argumentos y los imprime, uno por uno.

proc imprimirArgumentos args {
    foreach arg $args {
        puts $arg
    }
}

Este procedimiento es un poco como el comando incr, excepto que multiplica el contenido de la variable nombrada por el valor, que por defecto es 2:

proc mult {nombreVar {multiplicador 2}} {
    upvar 1 $nombreVar var
    set var [expr {$var * $multiplicador}]
}
