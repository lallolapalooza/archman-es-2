proc_pid_map_files(5) Manual de formatos de archivo proc_pid_map_files(5)

NOMBRE

/proc/pid/map_files/ - archivos mapeados en memoria

DESCRIPCIÓN

/proc/pid/map_files/ (desde Linux 3.3)
Este subdirectorio contiene entradas correspondientes a archivos mapeados en memoria (ver mmap(2)). Las entradas se nombran por el par de direcciones de inicio y fin de la región de memoria (expresadas en números hexadecimales), y son enlaces simbólicos a los propios archivos mapeados. Aquí hay un ejemplo, con la salida envuelta y reformateada para que quepa en una pantalla de 80 columnas:

# ls -l /proc/self/map_files/
lr-------- 1 root root 64 Abr 16 21:31
            3252e00000-3252e20000 -> /usr/lib64/ld-2.15.so
...

Aunque estas entradas están presentes para regiones de memoria que se mapearon con la bandera MAP_FILE, la forma en que la memoria compartida anónima (regiones creadas con las banderas MAP_ANON | MAP_SHARED) se implementa en Linux significa que dichas regiones también aparecen en este directorio. Aquí hay un ejemplo donde el archivo de destino es el archivo /dev/zero eliminado:

lrw------- 1 root root 64 Abr 16 21:33
            7fc075d2f000-7fc075e6f000 -> /dev/zero (deleted)

El permiso para acceder a este archivo se rige por una comprobación de modo de acceso ptrace PTRACE_MODE_READ_FSCREDS; ver ptrace(2).
Hasta Linux 4.3, este directorio aparecía solo si la opción de configuración del kernel CONFIG_CHECKPOINT_RESTORE estaba habilitada.
Se requieren capacidades para leer el contenido de los enlaces simbólicos en este directorio: antes de Linux 5.9, el proceso de lectura requiere CAP_SYS_ADMIN en el espacio de nombres de usuario inicial; desde Linux 5.9, el proceso de lectura debe tener CAP_SYS_ADMIN o CAP_CHECKPOINT_RESTORE en el espacio de nombres de usuario inicial (es decir, raíz).
