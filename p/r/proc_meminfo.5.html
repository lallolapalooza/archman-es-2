proc_meminfo(5) Manual de Formatos de Archivo proc_meminfo(5)

NOMBRE

/proc/meminfo - uso de memoria

DESCRIPCIÓN

/proc/meminfo
Este archivo informa estadísticas sobre el uso de memoria en el sistema. Es utilizado por free(1) para informar la cantidad de memoria libre y utilizada (física y de intercambio) en el sistema, así como la memoria compartida y los búferes utilizados por el kernel. Cada línea del archivo consiste en un nombre de parámetro, seguido de dos puntos, el valor del parámetro y una unidad de medida opcional (por ejemplo, "kB"). La lista a continuación describe los nombres de los parámetros y el especificador de formato requerido para leer el valor del campo. Excepto donde se indica lo contrario, todos los campos han estado presentes al menos desde Linux 2.6.0. Algunos campos solo se muestran si el kernel fue configurado con varias opciones; esas dependencias se notan en la lista.
MemTotal %lu
RAM total utilizable (es decir, RAM física menos algunos bits reservados y el código binario del kernel).
MemFree %lu
La suma de LowFree+HighFree.
MemAvailable %lu (desde Linux 3.14)
Una estimación de cuánta memoria está disponible para iniciar nuevas aplicaciones, sin intercambiar.
Buffers %lu
Almacenamiento relativamente temporal para bloques de disco en bruto que no deberían ser muy grandes (unos 20 MB).
Cached %lu
Caché en memoria para archivos leídos desde el disco (la caché de páginas). No incluye SwapCached.
SwapCached %lu
Memoria que una vez fue enviada al intercambio (swap out), se ha vuelto a traer (swap in) pero aún se encuentra en el archivo de intercambio. (Si la presión de memoria es alta, estas páginas no necesitan ser enviadas al intercambio de nuevo porque ya están en el archivo de intercambio. Esto ahorra E/S).
Active %lu
Memoria que se ha utilizado más recientemente y que generalmente no se recupera a menos que sea absolutamente necesario.
Inactive %lu
Memoria que se ha utilizado con menos frecuencia. Es más elegible para ser recuperada para otros fines.
Active(anon) %lu (desde Linux 2.6.28)
[Por documentar.]
Inactive(anon) %lu (desde Linux 2.6.28)
[Por documentar.]
Active(file) %lu (desde Linux 2.6.28)
[Por documentar.]
Inactive(file) %lu (desde Linux 2.6.28)
[Por documentar.]
Unevictable %lu (desde Linux 2.6.28)
(Desde Linux 2.6.28 hasta Linux 2.6.30, se requería CONFIG_UNEVICTABLE_LRU.) [Por documentar.]
Mlocked %lu (desde Linux 2.6.28)
(Desde Linux 2.6.28 hasta Linux 2.6.30, se requería CONFIG_UNEVICTABLE_LRU.) [Por documentar.]
HighTotal %lu
(A partir de Linux 2.6.19, se requiere CONFIG_HIGHMEM.) Cantidad total de highmem. Highmem es toda la memoria por encima de ~860 MB de memoria física. Las áreas de highmem son para uso de programas del espacio de usuario, o para la caché de páginas. El kernel debe usar trucos para acceder a esta memoria, lo que la hace más lenta de acceder que lowmem.
HighFree %lu
(A partir de Linux 2.6.19, se requiere CONFIG_HIGHMEM.) Cantidad de highmem libre.
LowTotal %lu
(A partir de Linux 2.6.19, se requiere CONFIG_HIGHMEM.) Cantidad total de lowmem. Lowmem es memoria que puede ser utilizada para todo lo que highmem puede ser utilizada, pero también está disponible para el uso del kernel para sus propias estructuras de datos. Entre muchas otras cosas, es de donde se asigna todo de Slab. Ocurren cosas malas cuando te quedas sin lowmem.
LowFree %lu
(A partir de Linux 2.6.19, se requiere CONFIG_HIGHMEM.) Cantidad de lowmem libre.
MmapCopy %lu (desde Linux 2.6.29)
(Se requiere CONFIG_MMU.) [Por documentar.]
SwapTotal %lu
Cantidad total de espacio de intercambio (swap) disponible.
SwapFree %lu
Cantidad de espacio de intercambio que no se está utilizando actualmente.
Dirty %lu
Memoria que está esperando ser escrita de vuelta al disco.
Writeback %lu
Memoria que se está escribiendo activamente en el disco.
AnonPages %lu (desde Linux 2.6.18)
Páginas sin respaldo de archivo mapeadas en las tablas de páginas del espacio de usuario.
Mapped %lu
Archivos que se han mapeado en memoria (con mmap(2)), como bibliotecas.
Shmem %lu (desde Linux 2.6.32)
Cantidad de memoria consumida en los sistemas de archivos tmpfs(5), memoria compartida de System V y POSIX, así como mapeos anónimos compartidos (MAP_SHARED|MAP_ANONYMOUS).
KReclaimable %lu (desde Linux 4.20)
Asignaciones del kernel que el kernel intentará recuperar bajo presión de memoria. Incluye SReclaimable (abajo), y otras asignaciones directas con un reductor (shrinker).
Slab %lu
Caché de estructuras de datos dentro del kernel. (Ver slabinfo(5).)
SReclaimable %lu (desde Linux 2.6.19)
Parte de Slab, que podría ser recuperada, como las cachés.
SUnreclaim %lu (desde Linux 2.6.19)
Parte de Slab, que no puede ser recuperada bajo presión de memoria.
KernelStack %lu (desde Linux 2.6.32)
Cantidad de memoria asignada a las pilas del kernel.
PageTables %lu (desde Linux 2.6.18)
Cantidad de memoria dedicada al nivel más bajo de tablas de páginas.
Quicklists %lu (desde Linux 2.6.27)
(Se requiere CONFIG_QUICKLIST.) [Por documentar.]
NFS_Unstable %lu (desde Linux 2.6.18)
Páginas NFS enviadas al servidor, pero aún no comprometidas en almacenamiento estable.
Bounce %lu (desde Linux 2.6.18)
Memoria utilizada para los "bounce buffers" de dispositivos de bloque.
WritebackTmp %lu (desde Linux 2.6.26)
Memoria utilizada por FUSE para búferes temporales de escritura.
CommitLimit %lu (desde Linux 2.6.10)
Esta es la cantidad total de memoria actualmente disponible para ser asignada en el sistema, expresada en kilobytes. Este límite solo se cumple si la contabilidad de sobreasignación estricta está habilitada (modo 2 en /proc/sys/vm/overcommit_memory). El límite se calcula según la fórmula descrita en /proc/sys/vm/overcommit_memory. Para más detalles, consulte el archivo fuente del kernel Documentation/vm/overcommit-accounting.rst.
Committed_AS

proc(5) - Página del manual de Linux

NOMBRE

proc - información del sistema y de procesos

DESCRIPCIÓN

El sistema de archivos /proc es un sistema de archivos virtual que proporciona información sobre los procesos y otros detalles del kernel. No es un sistema de archivos real, sino que se genera sobre la marcha cuando se accede a él. Los detalles específicos de los archivos y directorios dentro de /proc pueden variar según la versión del kernel.

El archivo /proc/meminfo contiene información sobre el uso de la memoria del sistema.

MemTotal %lu
La cantidad total de RAM física disponible en el sistema.
MemFree %lu
La cantidad de memoria RAM física que no está siendo utilizada actualmente por ningún proceso ni por el caché del kernel.
MemAvailable %lu (desde Linux 3.14)
La cantidad de memoria que está disponible para iniciar nuevas aplicaciones sin necesidad de que el sistema de paginación se desborde. Es una estimación más útil de la memoria libre que MemFree, ya que tiene en cuenta la memoria que puede ser recuperada del caché o de los buffers del kernel.
Buffers %lu
La cantidad de memoria utilizada por los buffers del kernel. Los buffers se utilizan para almacenar temporalmente datos de disco que se van a escribir o que se han leído del disco.
Cached %lu
La cantidad de memoria utilizada por el caché del sistema de archivos. El caché almacena en memoria los datos accedidos recientemente del disco para acelerar el acceso futuro.
SwapCached %lu
La cantidad de memoria swap que todavía está en RAM. Cuando se agota la memoria RAM, el sistema mueve páginas de memoria menos utilizadas al espacio de intercambio en el disco. Esta métrica indica cuánta de esa memoria swap todavía reside en RAM porque se ha accedido a ella recientemente.
Active %lu
La cantidad de memoria que ha sido utilizada recientemente. El kernel intenta mantener la memoria activa en RAM tanto como sea posible.
Inactive %lu
La cantidad de memoria que no ha sido utilizada recientemente. Esta memoria es candidata a ser liberada si se necesita más memoria.
ActiveAnon %lu (desde Linux 2.6.18)
Memoria anónima activa (memoria que no está respaldada por un archivo, como montones y pilas de procesos).
InactiveAnon %lu (desde Linux 2.6.18)
Memoria anónima inactiva.
ActiveFile %lu (desde Linux 2.6.18)
Memoria respaldada por archivo activa (caché de página).
InactiveFile %lu (desde Linux 2.6.18)
Memoria respaldada por archivo inactiva.
Unevictable %lu (desde Linux 2.6.18)
Memoria que no puede ser desalojada (por ejemplo, memoria bloqueada por mlock).
Mlocked %lu
La cantidad de memoria que ha sido bloqueada por procesos utilizando la llamada al sistema mlock(2). Esta memoria no puede ser intercambiada al disco.
SwapTotal %lu
La cantidad total de espacio de intercambio configurado en el sistema.
SwapFree %lu
La cantidad de espacio de intercambio que no está en uso.
Dirty %lu
La cantidad de memoria que contiene datos que se han modificado pero aún no se han escrito en el disco.
AnonPages %lu
Número de páginas anónimas (no respaldadas por un archivo) en memoria. Esto incluye montones, pilas y otras estructuras de datos de procesos.
Mapped %lu
El número de bytes de memoria mapeada. Esto incluye la memoria respaldada por archivos (como bibliotecas cargadas) y la memoria anónima.
Shmem %lu
Número de bytes de memoria compartida (por ejemplo, utilizada por shm(5) y tmpfs(5)).
Slab %lu
El tamaño de la memoria utilizada por el caché Slab del kernel. El caché Slab se utiliza para almacenar objetos de kernel de uso frecuente.
SReclaimable %lu (desde Linux 2.6.19)
La porción del caché Slab que puede ser reclamada por el sistema si es necesario.
SUnreclaim %lu (desde Linux 2.6.19)
La porción del caché Slab que no puede ser reclamada, ya que está en uso activo.
KernelStack %lu (desde Linux 2.6.32)
Memoria utilizada por las pilas del kernel.
PageTables %lu (desde Linux 2.6.18)
Memoria utilizada por las tablas de páginas del kernel. Las tablas de páginas se utilizan para gestionar el mapeo de memoria virtual a memoria física.
NFS_Unstable %lu (desde Linux 2.6.17)
Número de bytes de datos NFS que se han escrito en el cliente pero aún no se han confirmado en el servidor.
Bounce %lu (desde Linux 2.6.18)
Memoria utilizada por los búferes de rebote para transferencias de E/S.
Writeback %lu
La cantidad de memoria que está actualmente en proceso de ser escrita en el disco.
WritebackTmp %lu
Memoria temporal utilizada durante el proceso de escritura en el disco.
CommitLimit %lu
El límite máximo de memoria que se puede asignar en el sistema. Este límite es la suma de la memoria física total y una parte de la memoria swap, menos una pequeña reserva para el kernel.
Committed_AS %lu
La cantidad de memoria actualmente asignada en el sistema. La memoria confirmada es la suma de toda la memoria que ha sido asignada por los procesos, incluso si aún no ha sido "utilizada" por ellos. Un proceso que asigna 1 GB de memoria (usando malloc(3) o similar), pero solo toca 300 MB de esa memoria, aparecerá como si usara solo 300 MB de memoria, incluso si tiene el espacio de direcciones asignado para los 1 GB completos.
Estos 1 GB son memoria que ha sido "confirmada" por el VM y puede ser utilizada en cualquier momento por la aplicación que la asigna. Con el sobrecompromiso estricto habilitado en el sistema (modo 2 en /proc/sys/vm/overcommit_memory), las asignaciones que excederían el CommitLimit no serán permitidas. Esto es útil si se necesita garantizar que los procesos no fallarán debido a la falta de memoria una vez que esa memoria haya sido asignada con éxito.
VmallocTotal %lu
Tamaño total del área de memoria vmalloc.
VmallocUsed %lu
Cantidad del área vmalloc que está en uso. Desde Linux 4.4, este campo ya no se calcula y está codificado como 0. Ver /proc/vmallocinfo.
VmallocChunk %lu
Bloque contiguo más grande del área vmalloc que está libre. Desde Linux 4.4, este campo ya no se calcula y está codificado como 0. Ver /proc/vmallocinfo.
HardwareCorrupted %lu (desde Linux 2.6.32)
(Se requiere CONFIG_MEMORY_FAILURE). [Por documentar.]
LazyFree %lu (desde Linux 4.12)
Muestra la cantidad de memoria marcada por madvise(2) MADV_FREE.
AnonHugePages %lu (desde Linux 2.6.38)
(Se requiere CONFIG_TRANSPARENT_HUGEPAGE). Páginas grandes no respaldadas por archivo mapeadas en las tablas de páginas del espacio de usuario.
ShmemHugePages %lu (desde Linux 4.8)
(Se requiere CONFIG_TRANSPARENT_HUGEPAGE). Memoria utilizada por memoria compartida (shmem) y tmpfs(5) asignada con páginas grandes.
ShmemPmdMapped %lu (desde Linux 4.8)
(Se requiere CONFIG_TRANSPARENT_HUGEPAGE). Memoria compartida mapeada en el espacio de usuario con páginas grandes.
CmaTotal %lu (desde Linux 3.1)
Total de páginas CMA (Contiguous Memory Allocator). (Se requiere CONFIG_CMA).
CmaFree %lu (desde Linux 3.1)
Páginas CMA (Contiguous Memory Allocator) libres. (Se requiere CONFIG_CMA).
HugePages_Total %lu
(Se requiere CONFIG_HUGETLB_PAGE). El tamaño del pool de páginas grandes.
HugePages_Free %lu
(Se requiere CONFIG_HUGETLB_PAGE). El número de páginas grandes en el pool que aún no han sido asignadas.
HugePages_Rsvd %lu (desde Linux 2.6.17)
(Se requiere CONFIG_HUGETLB_PAGE). Este es el número de páginas grandes para las cuales se ha hecho un compromiso de asignación del pool, pero aún no se ha realizado ninguna asignación. Estas páginas grandes reservadas garantizan que una aplicación podrá asignar una página grande del pool de páginas grandes en el momento de la falla.
HugePages_Surp %lu (desde Linux 2.6.24)
(Se requiere CONFIG_HUGETLB_PAGE). Este es el número de páginas grandes en el pool por encima del valor en /proc/sys/vm/nr_hugepages. El número máximo de páginas grandes excedentes se controla mediante /proc/sys/vm/nr_overcommit_hugepages.
Hugepagesize %lu
(Se requiere CONFIG_HUGETLB_PAGE). El tamaño de las páginas grandes.
DirectMap4k %lu (desde Linux 2.6.27)
Número de bytes de RAM mapeados linealmente por el kernel en páginas de 4 kB. (x86).
DirectMap4M %lu (desde Linux 2.6.27)
Número de bytes de RAM mapeados linealmente por el kernel en páginas de 4 MB. (x86 con CONFIG_X86_64 o CONFIG_X86_PAE habilitado).
DirectMap2M %lu (desde Linux 2.6.27)
Número de bytes de RAM mapeados linealmente por el kernel en páginas de 2 MB. (x86 sin CONFIG_X86_64 ni CONFIG_X86_PAE habilitado).
DirectMap1G %lu (desde Linux 2.6.27)
(x86 con CONFIG_X86_64 y CONFIG_X86_DIRECT_GBPAGES habilitado).
