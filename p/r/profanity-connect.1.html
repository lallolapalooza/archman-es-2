profanity-connect(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP de Profanity man(1)

NOMBRE

/connect

DESCRIPCIÓN

Inicia sesión en un servicio de chat. Si no se especifica ninguna cuenta, se utiliza la predeterminada si está configurada. Se crea una cuenta local con el JID como nombre si aún no existe. En caso de que desees conectarte a un servidor a través de SASL ANONYMOUS (ver XEP-0175), también puedes hacerlo.

SINOPSIS

/connect [<cuenta>]

/connect <cuenta> [servidor <servidor>] [puerto <puerto>] [tls forzar|permitir|confiar|legado|deshabilitar] [autenticación predeterminada|legado]

/connect <servidor>

ARGUMENTOS

<cuenta>

La cuenta local con la que deseas conectarte, o un JID si te conectas por primera vez.

servidor <servidor>

Proporciona un servidor si es diferente a la parte del dominio de tu JID.

puerto <puerto>

El puerto a utilizar si es diferente al predeterminado (5222, o 5223 para SSL).

<servidor>

Conéctate al servidor mencionado de forma anónima. (Ten en cuenta: No hay muchos servidores que soporten esto.)

tls forzar

Fuerza la conexión TLS y falla si no se puede establecer, este es el comportamiento predeterminado.

tls permitir

Usa TLS para la conexión si está disponible.

tls confiar

Fuerza la conexión TLS y confía en el certificado del servidor.

tls legado

Usa TLS legado para la conexión. Significa que el servidor no soporta STARTTLS y TLS se fuerza justo después de que se establece la conexión TCP.

tls deshabilitar

Deshabilita TLS para la conexión.

autenticación predeterminada

Proceso de autenticación predeterminado.

autenticación legado

Permite la autenticación legado.

EJEMPLOS

/connect

/connect odin@valhalla.edda

/connect odin@valhalla.edda servidor talk.google.com

/connect freyr@vanaheimr.edda puerto 5678

/connect me@localhost.test.org servidor 127.0.0.1 tls deshabilitar

/connect me@chatty servidor chatty.com puerto 5443

/connect servidor.que.soporta.sasl.anonimo.example
