proc_crypto(5) Manual de Formatos de Archivo proc_crypto(5)

NOMBRE

/proc/crypto - cifrados proporcionados por la API criptográfica del kernel

DESCRIPCIÓN

/proc/crypto
Una lista de los cifrados proporcionados por la API criptográfica del kernel. Para obtener detalles, consulte la documentación de la API criptográfica del kernel de Linux disponible en el directorio de código fuente del kernel Documentation/crypto/ (o Documentation/DocBook antes de Linux 4.10; la documentación se puede compilar con un comando como make htmldocs en el directorio raíz del árbol de fuentes del kernel).
