profanity(1) Cliente XMPP de Profanity profanity(1)

NOMBRE

Profanity - un cliente de chat XMPP simple basado en consola.

SINOPSIS

profanity [-vh] [-l nivel] [-a cuenta]

DESCRIPCIÓN

Profanity es un cliente de chat XMPP simple y ligero basado en consola. Su énfasis está en tener una interfaz de usuario simple y configurable impulsada por comandos, consulte la página de inicio en:

https://profanity-im.github.io

OPCIONES

-v, --version
Mostrar información de versión y compilación.
-h, --help
Mostrar ayuda sobre los argumentos de la línea de comandos.
-a, --account CUENTA
Conectar automáticamente a una cuenta al iniciar, CUENTA debe ser una cuenta existente.
-c, --config
Usar un archivo de configuración alternativo.
-l, --log NIVEL
Establecer el nivel de registro, NIVEL puede establecerse en DEBUG, INFO (el predeterminado), WARN o ERROR.
-f, --logfile
Especificar un archivo de registro diferente
-r, --cmd
Especificar los comandos que deben ejecutarse justo después de iniciar. Esto se puede proporcionar varias veces, por ejemplo: 
profanity --cmd /foo --cmd "/sleep 10" --cmd /quit
-t, --theme TEMA
Especificar qué tema usar. TEMA debe ser uno de los temas instalados en $XDG_CONFIG_HOME/profanity/themes

ATAJOS DE TECLADO

Tab, Shift+Tab
Autocompletado siguiente, anterior. Funciona para comandos, nicks y citas (cuando la línea de entrada comienza con >).
ALT+1..Alt-0 o F1..F10
Seleccionar ventana 1..10.
ALT+q..Alt-p (en diseño QWERTY)
Seleccionar ventana 11..20.
ALT+IZQUIERDA
Seleccionar ventana de chat anterior.
ALT+DERECHA
Seleccionar ventana de chat siguiente.
AV_PAG
Desplazar la ventana activa hacia arriba.
RE_PAG
Desplazar la ventana activa hacia abajo.
ALT+AV_PAG
Desplazar el panel de ocupantes o lista de contactos hacia arriba.
ALT+RE_PAG
Desplazar el panel de ocupantes o lista de contactos hacia abajo.
ALT+ARRIBA o ALT+RUEDAARRIBA
Desplazar hacia arriba. Nota: soporte limitado para desplazamiento con la rueda del ratón, por favor, póngase en contacto con los desarrolladores si sabe cómo añadir soporte para otras terminales.
ALT+ABAJO o ALT+RUEDAABAJO
Desplazar hacia abajo. Ver nota anterior.
ALT+a
Saltar a la siguiente ventana no leída.
ALT+v
Marcar la ventana actual para leerla más tarde con una bandera de atención.
ALT+m
Cambiar entre ventanas marcadas con la bandera de atención.
ALT+ENTER
Añadir carácter de nueva línea sin enviar un mensaje/comando.
ALT+c
Ejecutar editor externo (ver profanity-editor(1)) para la línea de entrada actual.
CTRL+ABAJO
Guardar la línea de entrada actual en el historial pero no ejecutarla.

Nota: Profanity utiliza la biblioteca GNU Readline para manejar la entrada, por lo que el archivo de configuración predeterminado ~/.inputrc afecta a su funcionamiento. Además, se lee $XDG_CONFIG_HOME/profanity/inputrc después de establecer todos los atajos de teclado predeterminados, por lo que se pueden anular o añadir configuraciones allí. Como referencia, consulte la documentación de Readline: info readline "Command Line Editing" "Readline Init File" "Readline Init File Syntax" y la lista de comandos disponibles de Profanity en inputwin.c. Se admiten los atajos de teclado estándar de Readline, incluidos C-r para la búsqueda interactiva del historial y C-x C-r para recargar inputrc sin reiniciar.

USANDO PROFANITY

El primer paso es conectarse a un servidor XMPP. Los comandos /connect y /account se pueden utilizar para configurar las cuentas XMPP dentro de profanity (ver profanity-connect(1) y profanity-account(1)) con una cuenta XMPP existente. El comando /register se puede utilizar para registrar una cuenta en un servidor. profanity-register(1) Use el comando /help commands connection en profanity para mostrar más comandos para administrar su conexión.

La lista de contactos es su libreta de direcciones. Por defecto, su lista de contactos se mostrará en la "ventana 1", que es la consola de profanity /console. Es posible /roster hide y /roster show la libreta de direcciones en la consola de profanity. Se pueden añadir contactos con /roster add JID.

Para ver el estado en línea de sus contactos, el comando /sub se puede utilizar para administrar las suscripciones a la presencia de contactos. /sub request enviará una solicitud. /sub allow se utiliza para aprobar la solicitud de suscripción de un contacto. Use /help commands roster para obtener una lista de comandos que se pueden utilizar para administrar su lista de contactos.

Las ventanas de chat abiertas se pueden mostrar con el comando /wins. Saltar a una ventana se puede hacer mediante /win NUMERO o /win JID. Profanity admite autocompletado con la tecla TAB. El comando /msg se puede utilizar para iniciar un chat con su contacto. Se pueden unir a chats grupales con el comando /join o gestionarlos dentro de las marcadores del cuenta. Se puede usar el comando /sendfile y /url para compartir y descargar archivos. Ingrese > y presione la tecla TAB para citar un mensaje existente en la ventana de chat.

La guía del usuario se puede encontrar en https://profanity-im.github.io/userguide.html.

CIFRADO

Profanity soporta varios tipos de cifrado: OMEMO, OTR, PGP, OX. Solo puede habilitar uno de ellos por corresponsal a la vez.

OMEMO
OMEMO (/omemo) se define en XEP-0384. Utiliza una implementación del protocolo Signal para la gestión de claves y para sincronizar mensajes entre diferentes clientes. Funciona incluso cuando otros clientes están desconectados. Y ofrece Perfect Forward Secrecy y Plausible deniability. Los servidores necesitan soportar PEP (XEP-0163). Implementamos la versión "siacs" de OMEMO. Versión 0.3.0, que es actualmente la opción más adoptada. OMEMO es la única opción de cifrado en Profanity que también soporta cifrado para MUCs (XEP-0045) y transferencia de archivos a través de carga HTTP (XEP-0363).
OTR
OTR (/otr) se define en XEP-0364. Utiliza una combinación del algoritmo de clave simétrica AES, el intercambio de claves Diffie-Hellman y la función hash SHA-1. Ofrece autenticación negable y Perfect Forward Secrecy. Para inicializar una sesión, ambos clientes deben estar en línea al mismo tiempo. Una sesión es entre dos clientes, por lo que los chats multicliente no funcionan. Lo cual es una característica, no un error. OTR, por diseño, no funciona para MUCs.
OpenPGP
OpenPGP (/pgp) se define en XEP-0027. Utiliza una clave pública y secreta. También se conoce como Lega

ENCRYPTION

Profanity offers multiple ways to encrypt your messages. The most common way is OMEMO (XEP-0384), but there are also other ways available which might be relevant for specific use cases.

OMEMO
OMEMO (XEP-0384) is the current recommended way to do end-to-end encryption on XMPP. It is based on the Signal protocol and provides forward secrecy. It also supports the multi-device usage of messages.
PGP
PGP (Pretty Good Privacy) encryption is supported via XEP-0027. It uses OpenPGP keys for encryption and signing. It has some shortcomings, like no support for multi-user chats or file transfer.
XEP0027
XEP-0027 defines the legacy OpenPGP extension for XMPP. It has been deprecated and is not recommended for general use. It doesn't provide protection against replay attacks. MUCs and file transfer via HTTP upload are not specified and thus not supported.
OX
OX (/ox) is defined in XEP-0373 and XEP-0374. It's a more modern way to use OpenPGP on XMPP and tries to fix the shortcomings of legacy XEP-0027. Servers need to support PEP (XEP-0163). MUCs and file transfer via HTTP upload are not specified and thus not supported.
DETAILS
For more details read the relevant XEPs and look at the overview at https://wiki.xmpp.org/web/XMPP_E2E_Security

TERMINOLOGY

There is some XMPP specific terminology that might be unknown for fresh users. We will try to describe them here since they are often references in the help and man pages.

JID
Stands for Jabber ID. It refers to an XMPP address. Historically XMPP was also known as Jabber.
MAM
Stands for Message Archive Management (XEP-0313) and describes the ability to store messages on the server and retrieve them later.
MUC
Stands for Mutli-User Chats (XEP-0045) and are also called, groups, group chats, chatrooms or conferences.
Roster
The roster is your contact list. By default displayed at the right side on the console window. See RFC6121.
XEP
XMPP is aa extendable protocol. There are core features and optional features described in XMPP Extension Protocols, short XEPs.
