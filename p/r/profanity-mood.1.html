profanity-mood(1)

Paquete: profanity-gtk

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/mood

DESCRIPCIÓN

Establece tu estado de ánimo (XEP-0107).

SINOPSIS

/mood on|off

/mood set <estado_de_animo> [texto]

/mood clear

ARGUMENTOS

on|off

Habilita o deshabilita la visualización del estado de ánimo de otros usuarios. Habilitado por defecto.

set <estado_de_animo> [texto]

Establece el estado de ánimo del usuario a <estado_de_animo> con un [texto] opcional. Usa /mood set <tab> para alternar entre estados de ánimo predefinidos.

clear

Borra el estado de ánimo de tu usuario.

EJEMPLOS

/mood set happy "¡Muy feliz de usar Profanity!"

/mood set amazed

/mood clear
