proc_pid_attr(5) Manual de formatos de archivo proc_pid_attr(5)

NOMBRE

/proc/pid/attr/ - atributos relacionados con la seguridad

DESCRIPCIÓN

/proc/pid/attr/
Los archivos en este directorio proporcionan una API para módulos de seguridad. El contenido de este directorio son archivos que se pueden leer y escribir para establecer atributos relacionados con la seguridad. Este directorio se añadió para soportar SELinux, pero la intención era que la API fuera lo suficientemente general como para soportar otros módulos de seguridad. A modo de explicación, se proporcionan ejemplos de cómo SELinux utiliza estos archivos a continuación.
Este directorio solo está presente si el kernel fue configurado con CONFIG_SECURITY.
/proc/pid/attr/current (desde Linux 2.6.0)
El contenido de este archivo representa los atributos de seguridad actuales del proceso.
En SELinux, este archivo se utiliza para obtener el contexto de seguridad de un proceso. Antes de Linux 2.6.11, este archivo no se podía utilizar para establecer el contexto de seguridad (una escritura siempre se denegaba), ya que SELinux limitaba las transiciones de seguridad del proceso a execve(2) (ver la descripción de /proc/pid/attr/exec, abajo). Desde Linux 2.6.11, SELinux levantó esta restricción y comenzó a soportar operaciones de "establecer" a través de escrituras en este nodo si lo autoriza la política, aunque el uso de esta operación solo es adecuado para aplicaciones que tienen la confianza de mantener cualquier separación deseada entre los contextos de seguridad antiguo y nuevo.
Antes de Linux 2.6.28, SELinux no permitía a los hilos dentro de un proceso multihilo establecer su contexto de seguridad a través de este nodo, ya que generaría una inconsistencia entre los contextos de seguridad de los hilos que comparten el mismo espacio de memoria. Desde Linux 2.6.28, SELinux levantó esta restricción y comenzó a soportar operaciones de "establecer" para hilos dentro de un proceso multihilo si el nuevo contexto de seguridad está limitado por el contexto de seguridad antiguo, donde la relación limitada se define en la política y garantiza que el nuevo contexto de seguridad tiene un subconjunto de los permisos del contexto de seguridad antiguo.
Otros módulos de seguridad pueden optar por soportar operaciones de "establecer" a través de escrituras en este nodo.
/proc/pid/attr/exec (desde Linux 2.6.0)
Este archivo representa los atributos que se asignarán al proceso tras una posterior llamada a execve(2).
En SELinux, esto es necesario para soportar transiciones de rol/dominio, y execve(2) es el punto preferido para realizar tales transiciones, ya que ofrece un mejor control sobre la inicialización del proceso en la nueva etiqueta de seguridad y la herencia de estado. En SELinux, este atributo se restablece en execve(2) para que el nuevo programa vuelva al comportamiento predeterminado para cualquier llamada a execve(2) que pueda realizar. En SELinux, un proceso solo puede establecer su propio atributo /proc/pid/attr/exec.
/proc/pid/attr/fscreate (desde Linux 2.6.0)
Este archivo representa los atributos que se asignarán a los archivos creados mediante posteriores llamadas a open(2), mkdir(2), symlink(2), y mknod(2)
SELinux emplea este archivo para soportar la creación de un archivo (utilizando las llamadas al sistema mencionadas anteriormente) en un estado seguro, de modo que no haya riesgo de acceso inapropiado entre el momento de la creación y el momento en que se establecen los atributos. En SELinux, este atributo se restablece en execve(2), para que el nuevo programa vuelva al comportamiento predeterminado para cualquier llamada de creación de archivos que pueda realizar, pero el atributo persistirá a través de múltiples llamadas de creación de archivos dentro de un programa a menos que se restablezca explícitamente. En SELinux, un proceso solo puede establecer su propio atributo /proc/pid/attr/fscreate.
/proc/pid/attr/keycreate (desde Linux 2.6.18)
Si un proceso escribe un contexto de seguridad en este archivo, todas las claves creadas posteriormente (add_key(2)) se etiquetarán con este contexto. Para obtener más información, consulte el archivo fuente del kernel Documentation/security/keys/core.rst (o el archivo Documentation/security/keys.txt entre Linux 3.0 y Linux 4.13, o Documentation/keys.txt antes de Linux 3.0).
/proc/pid/attr/prev (desde Linux 2.6.0)
Este archivo contiene el contexto de seguridad del proceso antes de la última llamada a execve(2); es decir, el valor anterior de /proc/pid/attr/current.
/proc/pid/attr/socketcreate (desde Linux 2.6.18)
Si un proceso escribe un contexto de seguridad en este archivo, todos los sockets creados posteriormente se etiquetarán con este contexto.
