prune(1) Manual de Comandos Generales prune(1)

NOMBRE

prune - Poda grafos dirigidos

SINOPSIS

prune [ -n nodo ] [ -N especificación_atributos ] [ -v ] [ -(h|?) ] [ archivos ... ]

DESCRIPCIÓN

prune lee grafos dirigidos en el mismo formato que usa dot(1) y elimina subgrafos enraizados en los nodos especificados en la línea de comandos mediante opciones. Estos nodos no se eliminarán, pero se les pueden asignar atributos para que sean fácilmente localizables por un editor de flujos de grafos como gvpr(1). prune maneja correctamente ciclos, bucles y multi-aristas.

Ambas opciones pueden aparecer varias veces en la línea de comandos. Entonces se procesarán todos los subgrafos enraizados en los nodos respectivos dados. Si un nodo no existe, prune lo omitirá e imprimirá un mensaje de advertencia en stderr. Si se dan múltiples atributos, se aplicarán a todos los nodos que hayan sido procesados. prune escribe el resultado en la salida estándar.

OPCIONES

-n nombre
Especifica el nombre del nodo a podar.
-N especificación_atributos
Especifica el atributo que se establecerá (o se cambiará si existe) para cualquier nodo podado. especificación_atributos es una cadena del tipo atributo=valor.
-v
Salida detallada.
-h -?
Imprime el uso y sale.

EJEMPLOS

Un grafo de entrada test.gv de la forma:

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;
}

, procesado por el comando

prune -n B test.gv

produciría la siguiente salida (el código real podría tener un formato ligeramente diferente).

digraph DG {
A -> B;
A -> C;
}

Otro grafo de entrada test.gv de la forma:

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;

C -> E;
}

(notar la arista adicional de C a E ), procesado por el comando

prune -n B -N color=red test.gv

resulta en:

digraph DG {
B [color=red];
A -> B;
A -> C;
C -> E;
}

El nodo E no ha sido eliminado ya que su segundo padre C no está siendo podado.

ESTADO DE SALIDA

prune devuelve 0 al completar con éxito. Devuelve 1 si ocurre un error.

VER TAMBIÉN

dot(1), gvpr(1)
