NOMBRE

/omemo

DESCRIPCIÓN

Comandos de OMEMO para gestionar claves y realizar encriptación durante sesiones de chat.

SINOPSIS

/omemo gen

/omemo log on|off|redact

/omemo start [<contacto>]

/omemo trust [<contacto>] <huella_digital>

/omemo end

/omemo fingerprint [<contacto>]

/omemo char <carácter>

/omemo trustmode manual|firstusage|blind

/omemo policy manual|automatic|always

/omemo clear_device_list

/omemo qrcode

ARGUMENTOS

gen

Genera materiales criptográficos OMEMO para la cuenta actual.

start [<contacto>]

Inicia una sesión OMEMO con el contacto, o con el destinatario actual si se omite.

end

Finaliza la sesión OMEMO actual.

log on|off

Habilita o deshabilita el registro en texto plano de mensajes encriptados OMEMO.

log redact

Registra mensajes encriptados OMEMO, pero reemplaza el contenido con [redacted].

fingerprint [<contacto>]

Muestra las huellas digitales del contacto, o las del destinatario actual si se omite.

char <carácter>

Establece el carácter que se mostrará junto a los mensajes encriptados OMEMO.

trustmode manual

Establece el modo de confianza OMEMO global en manual, las claves OMEMO deben ser confiadas manualmente.

trustmode firstusage

Establece el modo de confianza OMEMO global en ToFu, las primeras claves OMEMO se confían automáticamente.

trustmode blind

Establece el modo de confianza OMEMO global en ciego, TODAS las claves OMEMO se confían automáticamente.

policy manual

Establece la política OMEMO global en manual, las sesiones OMEMO deben iniciarse manualmente.

policy automatic

Establece la política OMEMO global en oportunista, se intentará una sesión OMEMO al iniciar una conversación.

policy always

Establece la política OMEMO global en siempre, se mostrará un error si no se puede iniciar una sesión OMEMO al comenzar una conversación.

clear_device_list

Borra tu propia lista de dispositivos en el lado del servidor. Cada cliente se reanunciará al conectarse de nuevo.

qrcode

Muestra el código QR de tu huella digital OMEMO.

EJEMPLOS

/omemo gen

/omemo start odin@valhalla.edda

/omemo trust c4f9c875-144d7a3b-0c4a05b6-ca3be51a-a037f329-0bd3ae62-07f99719-55559d2a

/omemo untrust loki@valhalla.edda c4f9c875-144d7a3b-0c4a05b6-ca3be51a-a037f329-0bd3ae62-07f99719-55559d2a

/omemo char *
