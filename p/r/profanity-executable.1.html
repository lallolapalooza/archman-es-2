Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

profanity-executable

DESCRIPCIÓN

Configura un ejecutable que se llamará ante un comando determinado.

SINOPSIS

/executable avatar set <plantilla_comando>

/executable avatar default

/executable urlopen set <plantilla_comando>

/executable urlopen default

/executable urlsave set <plantilla_comando>

/executable urlsave default

/executable editor set <plantilla_comando>

/executable editor default

/executable vcard_photo set <plantilla_comando>

/executable vcard_photo default

ARGUMENTOS

avatar set

Establece el ejecutable que se ejecutará con /avatar open. Utiliza tu visor de imágenes favorito.

avatar default

Restaura la configuración predeterminada.

urlopen set

Establece el ejecutable que se ejecutará con /url open. Acepta una plantilla de comando que reemplaza %u y %p con la URL y la ruta respectivamente.

urlopen default

Restaura la configuración predeterminada.

urlsave set

Establece el ejecutable que se ejecutará con /url save. Acepta una plantilla de comando que reemplaza %u y %p con la URL y la ruta respectivamente.

urlsave default

Utiliza el método de descarga integrado para guardar.

editor set

Establece el editor que se utilizará con /editor. Necesita un editor de terminal o un script para ejecutar un editor gráfico.

editor default

Restaura la configuración predeterminada.

vcard_photo set

Establece el ejecutable que se ejecutará con /vcard photo open. Acepta una plantilla de comando que reemplaza %p con la ruta.

vcard_photo default

Restaura la configuración predeterminada.

EJEMPLOS

/executable avatar xdg-open

/executable urlopen set "xdg-open %u"

/executable urlopen set "firefox %u"

/executable urlopen default

/executable urlsave set "wget %u -O %p"

/executable urlsave set "curl %u -o %p"

/executable urlsave default

/executable vcard_photo set "feh %p"

/executable editor set "emacsclient -t"
