NOMBRE

prosodyctl - Gestionar un servidor Prosody XMPP

SINOPSIS

prosodyctl comando [--help]

DESCRIPCIÓN

prosodyctl es la herramienta de control para el servidor Prosody XMPP. Puede ser utilizada para controlar el demonio del servidor y gestionar usuarios.

prosodyctl necesita ser ejecutado con privilegios suficientes para realizar sus comandos. Esto típicamente significa ejecutar prosodyctl como el usuario root. Si se encuentra un usuario llamado “prosody” entonces prosodyctl cambiará a ese usuario antes de ejecutar sus comandos.

COMANDOS

Gestión de usuarios

En los siguientes comandos, los usuarios son identificados por un ID de Jabber, jid, de la forma habitual: usuario@dominio.

adduser jid
Añade un usuario con el ID de Jabber, jid, al servidor. Se le pedirá que introduzca la contraseña del usuario.
passwd jid
Cambia la contraseña de un usuario existente con el ID de Jabber, jid. Se le pedirá que introduzca la nueva contraseña del usuario.
deluser jid
Elimina un usuario existente con el ID de Jabber, jid, del servidor.

Gestión del demonio

Aunque prosodyctl tiene comandos para gestionar el demonio de prosody, se recomienda que utilice las características de gestión de demonios de su distribución si obtuvo Prosody a través de un paquete.

Para realizar comandos de control del demonio, prosodyctl necesita un valor pidfile especificado en /etc/prosody/prosody.cfg.lua. No hacerlo provocará que prosodyctl se queje.

start
Inicia el demonio del servidor prosody. Si se ejecuta como root, prosodyctl intentará cambiar a un usuario llamado “prosody” antes de ejecutarlo. Esta operación se bloqueará hasta cinco segundos para esperar a que el servidor se ejecute.
stop
Detiene el demonio del servidor prosody. Esta operación se bloqueará hasta cinco segundos para esperar a que el servidor deje de ejecutarse.
restart
Reinicia el demonio del servidor prosody. Equivale a ejecutar prosodyctl stop seguido de prosodyctl start.
reload
Señala al demonio del servidor prosody que recargue la configuración y reabra los archivos de registro.
status
Imprime el estado de ejecución actual del demonio del servidor prosody.

Certificados

prosodyctl puede crear certificados autofirmados, solicitudes de certificados y claves privadas para su uso con Prosody. Los comandos tienen la forma prosodyctl cert subcomando. Los comandos toman una lista de hosts a incluir en el certificado.

request hosts
Crea un archivo de solicitud de certificado (CSR) para su envío a una autoridad de certificación. Se pueden proporcionar varios hosts, los subdominios se incluyen automáticamente.
generate hosts
Genera un certificado autofirmado.
key host [tamaño]
Genera una clave privada de `tamaño' bits (por defecto 2048). Se invoca automáticamente por `request' y `generate' si es necesario.
config hosts
Produce un archivo de configuración para la lista de hosts. Se invoca automáticamente por `request' y `generate' si es necesario.
import hosts rutas
Copia certificados para hosts en la ruta de certificados y recarga prosody.

Depuración

prosodyctl también puede mostrar información sobre el entorno, dependencias y otros elementos para ayudar en la depuración.

about
Muestra el entorno, varias rutas utilizadas por Prosody y las dependencias instaladas.
check [qué]
Realiza varias comprobaciones de sanidad en la configuración, configuración de DNS y certificados TLS configurados. qué puede ser config, dns, certs, disabled, o connectivity para ejecutar solo esa comprobación.

Compatibilidad con Ejabberd

ejabberd es otro servidor XMPP que proporciona una herramienta de control comparable, ejabberdctl, para controlar las operaciones de su servidor. prosodyctl implementa algunos comandos que son compatibles con ejabberdctl. Para detalles sobre cómo funcionan estos comandos, debe consultar ejabberdctl(8).

register usuario servidor contraseña
unregister usuario servidor

OPCIONES

--config nombre_archivo
Usa el archivo de configuración especificado en lugar del predeterminado.
--root
No soltar privilegios de root (por ejemplo, cuando se invoca con sudo).
--help
Muestra el texto de ayuda para el comando especificado.
--verbose
Aumenta el nivel de registro para mostrar mensajes de depuración.
--quiet
Reduce el nivel de registro para mostrar solo errores.
--silent
Deshabilita el registro por completo, dejando solo la salida del comando.

ARCHIVOS

/etc/prosody/prosody.cfg.lua
El archivo de configuración principal de prosody. prosodyctl lo lee para determinar el archivo PID del demonio del servidor prosody y para determinar si un host ha sido configurado.
