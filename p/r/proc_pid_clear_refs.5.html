proc_pid_clear_refs(5) Manual de Formatos de Archivos proc_pid_clear_refs(5)

NOMBRE

proc_pid_clear_refs(5) - reinicia los bits PG_Referenced y ACCESSED/YOUNG

DESCRIPCIÓN

/proc/pid/clear_refs (desde Linux 2.6.22)
Este es un archivo de solo escritura, escribible solo por el propietario del proceso.
Los siguientes valores pueden ser escritos en el archivo:
1 (desde Linux 2.6.22)
Reinicia los bits PG_Referenced y ACCESSED/YOUNG para todas las páginas asociadas con el proceso. (Antes de Linux 2.6.32, escribir cualquier valor distinto de cero en este archivo tenía este efecto.)
2 (desde Linux 2.6.32)
Reinicia los bits PG_Referenced y ACCESSED/YOUNG para todas las páginas anónimas asociadas con el proceso.
3 (desde Linux 2.6.32)
Reinicia los bits PG_Referenced y ACCESSED/YOUNG para todas las páginas mapeadas en archivo asociadas con el proceso.
Limpiar los bits PG_Referenced y ACCESSED/YOUNG proporciona un método para medir aproximadamente cuánta memoria está utilizando un proceso. Primero se inspeccionan los valores en los campos "Referenced" para los VMA que se muestran en /proc/pid/smaps para tener una idea de la huella de memoria del proceso. Luego se limpian los bits PG_Referenced y ACCESSED/YOUNG y, después de un intervalo de tiempo medido, se vuelven a inspeccionar los valores en los campos "Referenced" para tener una idea del cambio en la huella de memoria del proceso durante el intervalo medido. Si solo se está interesado en inspeccionar tipos de mapeo seleccionados, entonces se pueden usar los valores 2 o 3 en lugar de 1.
Se pueden escribir valores adicionales para afectar diferentes propiedades:
4 (desde Linux 3.11)
Limpia el bit soft-dirty para todas las páginas asociadas con el proceso. Esto se usa (en conjunción con /proc/pid/pagemap) por el sistema de restauración de puntos de control para descubrir qué páginas de un proceso han sido modificadas desde que se escribió el archivo /proc/pid/clear_refs.
5 (desde Linux 4.0)
Reinicia el tamaño máximo del conjunto residente ("marca de agua alta") al valor del tamaño residente actual del proceso.
Escribir cualquier valor en /proc/pid/clear_refs que no sea los enumerados anteriormente no tiene ningún efecto.
El archivo /proc/pid/clear_refs solo está presente si la opción de configuración del kernel CONFIG_PROC_PAGE_MONITOR está habilitada.
