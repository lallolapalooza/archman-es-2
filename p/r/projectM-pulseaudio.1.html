NOMBRE

projectM-pulseaudio - Módulo ProjectM para PulseAudio

DESCRIPCIÓN

Esta página del manual documenta el comando projectM-pulseaudio.

projectM-pulseaudio proporciona visualización directa de flujos de PulseAudio utilizando la biblioteca de visualización de audio projectM.

projectM-pulseaudio se puede ejecutar desde el menú Aplicaciones después de haber sido instalado.
