proc_kpageflags(5) Manual de Formatos de Archivo proc_kpageflags(5)

NOMBRE

/proc/kpageflags - máscaras de marcos de páginas físicas

DESCRIPCIÓN

/proc/kpageflags (desde Linux 2.6.25)
Este archivo contiene máscaras de 64 bits correspondientes a cada marco de página física; se indexa por el número de marco de página (ver la discusión de /proc/pid/pagemap). Los bits son los siguientes:
0 - KPF_LOCKED
1 - KPF_ERROR
2 - KPF_REFERENCED
3 - KPF_UPTODATE
4 - KPF_DIRTY
5 - KPF_LRU
6 - KPF_ACTIVE
7 - KPF_SLAB
8 - KPF_WRITEBACK
9 - KPF_RECLAIM
10 - KPF_BUDDY
11 - KPF_MMAP (desde Linux 2.6.31)
12 - KPF_ANON (desde Linux 2.6.31)
13 - KPF_SWAPCACHE (desde Linux 2.6.31)
14 - KPF_SWAPBACKED (desde Linux 2.6.31)
15 - KPF_COMPOUND_HEAD (desde Linux 2.6.31)
16 - KPF_COMPOUND_TAIL (desde Linux 2.6.31)
17 - KPF_HUGE (desde Linux 2.6.31)
18 - KPF_UNEVICTABLE (desde Linux 2.6.31)
19 - KPF_HWPOISON (desde Linux 2.6.31)
20 - KPF_NOPAGE (desde Linux 2.6.31)
21 - KPF_KSM (desde Linux 2.6.32)
22 - KPF_THP (desde Linux 3.4)
23 - KPF_BALLOON (desde Linux 3.18)
24 - KPF_ZERO_PAGE (desde Linux 4.0)
25 - KPF_IDLE (desde Linux 4.3)
26 - KPF_PGTABLE (desde Linux 4.18)
Para más detalles sobre el significado de estos bits, ver el archivo de código fuente del kernel Documentation/admin-guide/mm/pagemap.rst. Antes de Linux 2.6.29, KPF_WRITEBACK, KPF_RECLAIM, KPF_BUDDY y KPF_LOCKED no informaban correctamente.
El archivo /proc/kpageflags solo está presente si la opción de configuración del kernel CONFIG_PROC_PAGE_MONITOR está habilitada.
