profanity-blocked(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP de Profanity man(1)

NOMBRE

/blocked

DESCRIPCIÓN

Gestiona usuarios bloqueados (XEP-0191), llamar sin argumentos muestra la lista actual de usuarios bloqueados. Para bloquear a un usuario específico en un MUC, usa la siguiente JID: room@conference.example.org/spammy-user También es posible bloquear y reportar (XEP-0377) a un usuario con los comandos report-abuse y report-spam.

SINOPSIS

/blocked

/blocked add [<jid>]

/blocked report-abuse [<jid>] [<mensaje>]

/blocked report-spam [<jid>] [<mensaje>]

/blocked remove <jid>

ARGUMENTOS

add [<jid>]

Bloquea el Jabber ID especificado. Si estás en una ventana de chat y no se especifica ningún jid, se bloqueará al destinatario actual.

remove <jid>

Elimina el Jabber ID especificado de la lista de bloqueados.

report-abuse <jid> [<mensaje>]

Reporta la jid como abuso con un mensaje opcional al operador del servicio.

report-spam <jid> [<mensaje>]

Reporta la jid como spam con un mensaje opcional al operador del servicio.

EJEMPLOS

/blocked add hel@helheim.edda

/blocked report-spam hel@helheim.edda Un tipo muy molesto

/blocked add profanity@rooms.dismail.de/spammy-user
