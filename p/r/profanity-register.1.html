NOMBRE

/register

DESCRIPCIÓN

Registra una cuenta en un servidor.

SINOPSIS

/register <nombreusuario> <servidor> [puerto <puerto>] [tls forzar|permitir|confiar|legado|desactivar]

ARGUMENTOS

<nombreusuario>

Nombre de usuario con el que registrarse.

<servidor>

Servidor en el que registrar la cuenta.

puerto <puerto>

El puerto a usar si es diferente al predeterminado (5222, o 5223 para SSL).

tls forzar

Forzar conexión TLS y fallar si no se puede establecer una. Este es el comportamiento predeterminado.

tls permitir

Usar TLS para la conexión si está disponible.

tls confiar

Forzar conexión TLS y confiar en el certificado del servidor.

tls legado

Usar TLS legado para la conexión. Esto fuerza TLS justo después de que se establece la conexión TCP. Úsese cuando un servidor no soporte STARTTLS.

tls desactivar

Desactivar TLS para la conexión.

EJEMPLOS

/register odin valhalla.edda

/register freyr vanaheimr.edda puerto 5678

/register yo 127.0.0.1 tls desactivar

/register algunusuario mi.xmppserv.er puerto 5443 tls forzar
