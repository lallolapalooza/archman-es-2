PRTERUN(1) Entorno de tiempo de ejecución de referencia PMIx PRTERUN(1)

prterun — lanzar una aplicación con un DVM predeterminado

SINOPSIS

shell$ prterun ...opciones...

DESCRIPCIÓN

prterun envía un trabajo al Entorno de Tiempo de Ejecución de Referencia (PRRTE) de PMIx. Se utilizan un conjunto predeterminado de opciones de máquina virtual distribuida (DVM); utilice prun(1) si desea utilizar opciones específicas de DVM.

Gran parte de esta misma documentación de ayuda para este comando también se proporciona a través de prun --help [tema].
