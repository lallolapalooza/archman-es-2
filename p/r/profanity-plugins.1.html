profanity-plugins(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/plugins

DESCRIPCIÓN

Gestiona plugins. Si no se pasan argumentos, lista los plugins instalados y los plugins globales disponibles para instalación local. El directorio global para plugins de Python es /usr/local/share/profanity/plugins y para plugins de C es /usr/local/lib64/profanity/plugins.

SINOPSIS

/plugins

/plugins install [<ruta o URL>]

/plugins update [<ruta o URL>]

/plugins uninstall [<plugin>]

/plugins unload [<plugin>]

/plugins load [<plugin>]

/plugins reload [<plugin>]

/plugins python_version

ARGUMENTOS

install [<ruta o URL>]

Instala un plugin, o todos los plugins encontrados en un directorio (recursivo), o descarga e instala un plugin (el nombre del plugin se basa en el nombre base). Y lo/los carga.

update [<ruta o URL>]

Desinstala y luego instala el plugin. El nombre del plugin a actualizar es el nombre base.

uninstall [<plugin>]

Desinstala un plugin.

load [<plugin>]

Carga un plugin que ya existe en el directorio de plugins; si no se pasan argumentos, carga todos los plugins encontrados. Se cargará también en el próximo inicio a menos que se descargue.

unload [<plugin>]

Descarga un plugin cargado; si no se pasan argumentos, descargará todos los plugins.

reload [<plugin>]

Recarga un plugin; si no se pasan argumentos, recargará todos los plugins.

python_version

Muestra la versión del intérprete de Python.

EJEMPLOS

/plugins install /home/steveharris/Descargas/metal.py

/plugins install https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins update /home/steveharris/Descargas/metal.py

/plugins update https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins uninstall browser.py

/plugins load browser.py

/plugins unload say.py

/plugins reload wikipedia.py
