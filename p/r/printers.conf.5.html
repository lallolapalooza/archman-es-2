NOMBRE

printers.conf - archivo de configuración de impresoras para cups

DESCRIPCIÓN

El archivo printers.conf define las impresoras locales que están disponibles. Normalmente se encuentra en el directorio /etc/cups y es mantenido por el programa cupsd(8). Este archivo no está destinado a ser editado o gestionado manualmente.

NOTAS

El nombre, la ubicación y el formato de este archivo son un detalle de implementación que cambiará en futuras versiones de CUPS.

VER TAMBIÉN
