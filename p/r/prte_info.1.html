PRTE_INFO(1) Entorno de ejecución de referencia de PMIx PRTE_INFO(1)

prte_info — Proporciona información detallada sobre tu instalación de PRRTE.

SINOPSIS

prte_info ...opciones...

DESCRIPCIÓN

prte_info proporciona información detallada sobre tu instalación del Entorno de Ejecución de Referencia de PMIx (PRRTE).

Ayuda detallada para este comando se proporciona a través de prte_info --help [tema].

Por ahora, ese contenido no está disponible en formato de página de manual. Las solicitudes de extracción para agregar todo el contenido (a través de infraestructura repetible) serían muy apreciadas.
