procps_misc(3)

Paquete: procps-ng

Licencias: GPL, LGPL

PROCPS_MISC(3) Manual de funciones de biblioteca PROCPS_MISC(3)

NOMBRE

procps_misc - API para información miscelánea en el sistema de archivos /proc

SINOPSIS

#include <libproc2/misc.h>
Particularidades de la Plataforma
long         procps_cpu_count (void);
long         procps_hertz_get (void);
unsigned int procps_pid_length (void);
int          procps_linux_version (void);
Particularidades de Ejecución
int   procps_container_uptime (double *uptime_secs);
int   procps_loadavg (double *av1, double *av5, double *av15);
int   procps_uptime (double *uptime_secs, double *idle_secs);
int   procps_uptime_snprint ( char *restrict str, size_t size, double uptime_secs, const int pretty);
char *procps_uptime_sprint (void);
char *procps_uptime_sprint_short (void);
int   procps_users (void);
Particularidades de Espacios de Nombres
int         procps_ns_get_id (const char *name);
const char *procps_ns_get_name (int id);
int         procps_ns_read_pid (int pid, struct procps_ns *nsp);
Resolución de Nombres de Máscaras
int procps_sigmask_names (char *const str, size_t size , const char *sigmask);
int procps_capmask_names (char *const str, size_t size,  const char *capmask);
Enlazar con -lproc2.

DESCRIPCIÓN

procps_cpu_count() devuelve el número de CPU que están actualmente en línea como sysconf(_SC_NPROCESSORS_ONLY) o un 1 asumido.

procps_hertz_get() devuelve el número de tics de reloj por segundo como sysconf(_SC_CLK_TCK) o un 100 asumido. Dividir tics por este valor produce segundos.

procps_pid_length() devuelve la longitud máxima de cadena para un PID en el sistema. Por ejemplo, si el valor de PID más grande posible fuera 123, entonces la longitud sería 3. Si el archivo /proc/sys/kernel/pid_max no se puede leer, se asume el valor de 5.

procps_linux_version() devuelve la versión actual de Linux como un entero codificado. En sistemas que no son Linux que tienen un sistema de archivos proc emulado, esta función devuelve la versión de la emulación de Linux en su lugar. La versión consta de tres enteros positivos que representan los niveles mayor, menor y de parche. Las siguientes macros se proporcionan para codificar una versión dada de Linux o para separar los componentes de la versión actual.

LINUX_VERSION( mayor , menor , parche )

LINUX_VERSION_MAJOR( ver )

LINUX_VERSION_MINOR( ver )

LINUX_VERSION_PATCH( ver )

procps_loadavg() obtiene el promedio de carga del sistema y coloca los promedios de 1, 5 y 15 minutos en la(s) ubicación(es) especificada(s) por cualquier puntero que no sea NULL.

procps_container_uptime() devuelve el tiempo de actividad de un contenedor en la ubicación especificada por el puntero si no es NULL. Esto se determina actualmente por el tiempo transcurrido del PID 1, que podría proporcionarse con el comando:


$ ps -o etimes 1
ELAPSED
12345

No hay concepto de tiempo de inactividad en un contenedor, por lo que procps_container_uptime() no tiene ese parámetro.

procps_uptime() devuelve el tiempo de actividad y/o los segundos de inactividad en la(s) ubicación(es) especificada(s) por cualquier puntero que no sea NULL. Las variedades sprint devuelven una cadena legible por humanos en una de dos formas.

HH:MM:SS up HH:MM, # usuarios, promedio de carga: 1, 5, 15 promedios MM

up HH, MM

procps_uptime_snprint() Utiliza el búfer str dado de size longitud para rellenar la cadena de tiempo de actividad en lugar de un búfer asignado estáticamente. La función requiere el valor uptime_secs, que se puede obtener de procps_uptime() o procps_container_uptime() y el indicador pretty determina si la salida es estándar o bonita/corta.

procps_users() devuelve el número de usuarios en el sistema. Este valor proviene de sd_get_sessions(3) y contando las sesiones de la clase de usuario, usuario-temprano y usuario-incompleto o enumerando a través de getutent(3).

procps_ns_get_id() devuelve el id entero (enum namespace_type) del espacio de nombres para el name dado del espacio de nombres.

procps_ns_get_name() devuelve el nombre del espacio de nombres para el id dado (enum namespace_type).

procps_ns_read_pid() devuelve los inodos para los espacios de nombres del proceso dado en la estructura procps_ns apuntada por nsp. Esos inodos aparecerán en el orden prescrito por enum namespace_type.

enum namespace_type {
    PROCPS_NS_CGROUP,
    PROCPS_NS_IPC,
    PROCPS_NS_MNT,
    PROCPS_NS_NET,
    PROCPS_NS_PID,
    PROCPS_NS_TIME,
    PROCPS_NS_USER,
    PROCPS_NS_UTS
};

procps_sigmask_names() Rellena str con una cadena de texto legible por humanos de hasta size bytes de las señales establecidas en la máscara de señales hexadecimal sigmask, ver signal(7). Si la lista de señales excede size bytes, la cadena se truncará y terminará con un '+'. Es responsabilidad del programa que llama asegurarse de que str esté asignado correctamente con al menos size bytes.

procps_capmask_names() Rellena str con una cadena de texto legible por humanos de hasta size bytes de las capacidades establecidas en la máscara de capacidades hexadecimal capmask, ver capabilities(7). Si la lista de capacidades excede size bytes, la cadena se truncará y terminará con un '+'. Es responsabilidad del programa que llama asegurarse de que str esté asignado correctamente con al menos size bytes.

Para un proceso que no tiene capacidades o todas las capacidades, la cadena será "-" y "full" respectivamente.

VALOR DE RETORNO

Funciones que devuelven un ‘int’ o ‘long’

Un error se indicará mediante un número negativo que es siempre inverso de algún valor conocido de errno.h.

Funciones que devuelven una ‘dirección’

Un error se indicará mediante un puntero nulo devuelto con la razón encontrada en el valor formal errno.

ARCHIVOS

/proc/loadavg
Los valores brutos para el promedio de carga.
/proc/sys/kernel/osrelease
Contiene la versión de lanzamiento del kernel de Linux o del sistema de archivos proc.
/proc/sys/kernel/pid_max
Contiene el valor en el que los PID dan la vuelta, uno más que el valor máximo de PID.
/proc/uptime
Los valores brutos para el tiempo de actividad del sistema y el tiempo de inactividad.
/proc/PID/ns
contiene el conjunto de espacios de nombres para un PID particular.

VER TAMBIÉN

procps(3), procps_pids(3), getutent(3), sd_get_sessions(3), proc(5), capabilities(7), signal(7).
