prctl(2) Manual de llamadas al sistema prctl(2)

NOMBRE

prctl - operaciones sobre un proceso o hilo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <linux/prctl.h>  /* Definición de constantes PR_* */
#include <sys/prctl.h>
int prctl(int op, ...);

DESCRIPCIÓN

prctl() manipula varios aspectos del comportamiento del hilo o proceso que realiza la llamada.

prctl() se llama con un primer argumento que describe qué hacer, y argumentos adicionales cuya significancia depende del primero. El primer argumento puede ser:

VALOR DE RETORNO

En caso de éxito, se devuelve un valor no negativo. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
El valor de op no es reconocido o no es compatible en este sistema.
EINVAL
Un argumento no utilizado es distinto de cero.

VERSIONES

IRIX tiene una llamada al sistema prctl() (introducida también en Linux 2.1.44 como irix_prctl en la arquitectura MIPS), con el prototipo


ptrdiff_t prctl(int op, int arg2, int arg3);

y operaciones para obtener el número máximo de procesos por usuario, obtener el número máximo de procesadores que el proceso que realiza la llamada puede usar, averiguar

ADVERTENCIAS

El prototipo de la envoltura de libc utiliza una lista de argumentos variádica. Esto hace que sea necesario pasar los argumentos con el ancho correcto. Al pasar constantes numéricas, como 0, use un sufijo: 0L.

El uso descuidado de algunas operaciones prctl() puede confundir el entorno de ejecución del espacio de usuario, por lo que estas operaciones deben usarse con cuidado.
