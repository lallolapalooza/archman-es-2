NOMBRE

proj y invproj — Filtro de proyección cartográfica

SINOPSIS

proj [-beEfiIlmorsStTvVwW] [argumentos]] ([+opt[=arg] ...] | {crs}) archivo ...

invproj [-beEfiIlmorsStTvVwW] [argumentos]] ([+opt[=arg] ...] | {crs}) archivo ...

DESCRIPCIÓN

proj e invproj realizan la conversión respectiva, directa e inversa, de datos cartográficos a datos cartesianos o viceversa, con una amplia gama de funciones de proyección seleccionables.

invproj puede no estar disponible en todas las plataformas; en este caso, utilice proj -I en su lugar.

Los siguientes parámetros de control pueden aparecer en cualquier orden:

-b
Opción especial para entrada y salida de datos de coordenadas binarias a través de la entrada estándar y la salida estándar. Se asume que los datos están en palabras de punto flotante doble del tipo del sistema. Esta opción debe usarse cuando proj es un proceso hijo y permite omitir las operaciones de formato.
-d <n>

Añadido en la versión 5.2.0: Especifica el número de decimales a redondear en la salida.

-i
Selecciona solo entrada binaria (ver -b).
-I
Método alternativo para especificar la proyección inversa. Redundante cuando se usa con invproj.
-o
Selecciona solo salida binaria (ver -b).
-t<a>
Donde a especifica un carácter empleado como primer carácter para denotar una línea de control que se pasará sin procesar. Esta opción es aplicable solo a la entrada ASCII. (# es el valor predeterminado).
-e <cadena>
Donde cadena es una cadena arbitraria que se emitirá si se detecta un error durante las transformaciones de datos. El valor predeterminado es una cadena de tres caracteres: *\t*. Tenga en cuenta que si se emplean las opciones -b, -i u -o, se devuelve un error como el valor HUGE_VAL para ambos valores de retorno.
-E
Provoca que las coordenadas de entrada se copien en la línea de salida antes de imprimir los valores convertidos.
-l<[=id]>
Lista los identificadores de proyección que se pueden seleccionar con +proj. proj -l=id proporciona una descripción ampliada de la proyección id, por ejemplo, proj -l=merc.
-lp
Lista de todos los identificadores de proyección que se pueden usar con el parámetro +proj. Equivalente a proj -l.
-lP
Descripción ampliada de todas las proyecciones que se pueden usar con el parámetro +proj.
-le
Lista de todos los elipsoides que se pueden seleccionar con el parámetro +ellps.
-lu
Lista de todas las unidades de distancia que se pueden seleccionar con el parámetro +units.
-r
Esta opción invierte el orden de la entrada esperada de longitud-latitud o x-y a latitud-longitud o y-x.
-s
Esta opción invierte el orden de la salida de x-y o longitud-latitud a y-x o latitud-longitud.
-S
Provoca que se listen los factores de escala meridional y paralelo, el factor de escala de área y la distorsión angular, y los factores de escala máximo y mínimo entre <> para cada punto de entrada. Para proyecciones conformes, los factores de escala meridional y paralelo serán iguales y la distorsión angular será cero. Las proyecciones de área igual tendrán un factor de área de 1.
-m <mult>
Los datos cartesianos pueden escalarse por el parámetro mult. Al procesar datos en modo de proyección directa, los valores de salida cartesianos se multiplican por mult, de lo contrario, los valores cartesianos de entrada se dividen por mult antes de la proyección inversa. Si los dos primeros caracteres de mult son 1/ o 1: entonces se emplea el valor recíproco de mult.
-f <formato>
Donde formato es una cadena de formato printf para controlar la forma de los valores de salida. Para proyecciones inversas, la salida estará en grados cuando se emplee esta opción. El formato predeterminado es "%.2f" para la proyección directa y DMS para la inversa.
-w<n>
Donde n es el número de dígitos fraccionarios significativos a emplear para la salida de segundos (cuando no se especifica la opción, se asume -w3).
-W<n>
Donde n es el número de dígitos fraccionarios significativos a emplear para la salida de segundos. Cuando se emplea -W, los campos tendrán un ancho constante con ceros iniciales.
-v
Provoca que se imprima una lista de los parámetros de control cartográficos probados y utilizados por el programa antes de los datos de entrada.
-V
Esta opción provoca una lista ampliada y anotada de las características del punto proyectado. Se implica -v con esta opción.

Los argumentos de ejecución +opt están asociados con parámetros cartográficos. Pueden aparecer parámetros de control de proyección adicionales en dos archivos de control auxiliares: el primero se hace referencia opcionalmente con +init=file:id y el segundo siempre se procesa después del nombre de la proyección, que se ha establecido a partir de la línea de ejecución o del contenido del archivo +init. El parámetro de entorno PROJ_DATA establece el directorio predeterminado para una referencia de archivo sin una ruta absoluta. Esto también se utiliza para admitir archivos como archivos de desplazamiento de datum.

Añadido en la versión 9.3.0: {crs} es una de las posibilidades aceptadas por :c:proj_create(), siempre que exprese un SRC proyectado, como una cadena WKT, un código de objeto (como "EPSG:32632"), una cadena PROJJSON, etc. La proyección calculada será la de la proyección cartográfica implícita por la transformación desde el SRC geográfico base del SRC proyectado al SRC proyectado.

Uno o más archivos (procesados de izquierda a derecha) especifican la fuente de los datos a convertir. Un - especificará la ubicación de la entrada estándar de procesamiento. Si no se especifican archivos, se asume que la entrada proviene de stdin. Para datos de entrada ASCII, los dos valores de datos deben estar en los dos primeros campos separados por espacios en blanco y cuando tanto la entrada como la salida son ASCII, todas las porciones finales de la línea de entrada se añaden a la línea de salida.

Los datos geográficos de entrada (longitud y latitud) deben estar en formato DMS o grados decimales y los datos cartesianos de entrada deben estar en unidades consistentes con las unidades del semieje mayor del elipsoide o del radio de la esfera. Las coordenadas geográficas de salida estarán en formato DMS (si no se emplea el modificador -w) y tendrán una precisión de 0.001", eliminando los campos de minutos-segundos con ceros finales.

EJEMPLO

proj +proj=utm +zone=12 -r <<EOF
45d15'33.1" 111.5W
45d15.551666667N -111d30
+45.25919444444 111d30'000w
EOF

realizará una proyección UTM de la zona 12. Se utiliza el valor predeterminado +ellps=GRS80 ya que no se especificó ningún +ellps. Los valores geográficos de este ejemplo son equivalentes y se presentan como ejemplos de varias formas de entrada DMS. Los datos de salida x-y aparecerán en tres líneas:

460770.43     5011865.86

Este otro ejemplo

proj EPSG:6421 -V <<EOF
-120 35.8
EOF

OTROS PROGRAMAS

El programa proj se limita a convertir entre coordenadas geográficas y proyectadas dentro de un único datum.

El programa cs2cs opera de manera similar, pero permite la traducción entre cualquier par de sistemas de referencia de coordenadas definibles, incluido el soporte para la traducción de datum.
