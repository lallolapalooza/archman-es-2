NOMBRE

proxytrack - proxy para servir contenido archivado por el copiador de sitios web httrack

SINOPSIS

proxytrack proxy_direccion:puerto_proxy direccion_icp:puerto_icp [ archivo_cache_httrack_1 [ archivo_cache_httrack_2 .. ] ]

DESCRIPCIÓN

proxytrack este programa te permite crear un proxy para entregar contenido ya archivado por httrack(1) , un copiador de sitios web.

EJEMPLOS

proxytrack proxy:8080 localhost:3130 /home/archivos/ejemplo.com/hts-cache/new.zip

iniciará el proxytrack proxy, escuchando en :8080, para entregar contenido archivado en la caché /home/archivos/ejemplo.com/hts-cache/new.zip
