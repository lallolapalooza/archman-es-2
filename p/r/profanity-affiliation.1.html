man(1) Cliente XMPP Profanity man(1)

NOMBRE

/affiliation

DESCRIPCIÓN

Gestiona las afiliaciones de sala. La afiliación puede ser una de owner, admin, member, outcast o none.

SINOPSIS

/affiliation set <afiliación> <jid> [<razón>]

/affiliation list [<afiliación>]

/affiliation request

/affiliation register

ARGUMENTOS

set <afiliación> <jid> [<razón>]

Establece la afiliación del usuario con el jid, con una razón opcional.

list [<afiliación>]

Lista todos los usuarios con la afiliación especificada, o todos si no se especifica ninguno.

request

Solicita voz.

register

Registra tu apodo con el MUC.
