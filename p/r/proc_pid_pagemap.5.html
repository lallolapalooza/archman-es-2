NOMBRE

/proc/pid/pagemap - mapeo de páginas virtuales

DESCRIPCIÓN

/proc/pid/pagemap (desde Linux 2.6.25)
Este archivo muestra el mapeo de cada página virtual del proceso en marcos de página físicos o área de intercambio (swap). Contiene un valor de 64 bits por cada página virtual, con los bits establecidos de la siguiente manera:
63
Si está establecido, la página está presente en la RAM.
62
Si está establecido, la página está en el espacio de intercambio (swap).
61 (desde Linux 3.5)
La página es una página mapeada de archivo o una página anónima compartida.
60–58 (desde Linux 3.11)
Cero
57 (desde Linux 5.14)
Si está establecido, la página está protegida contra escritura a través de userfaultfd(2).
56 (desde Linux 4.2)
La página está mapeada de forma exclusiva.
55 (desde Linux 3.11)
PTE está "soft-dirty" (consulte el archivo fuente del kernel Documentation/admin-guide/mm/soft-dirty.rst).
54–0
Si la página está presente en la RAM (bit 63), estos bits proporcionan el número de marco de página, que se puede utilizar para indexar /proc/kpageflags y /proc/kpagecount. Si la página está presente en el intercambio (bit 62), entonces los bits 4-0 dan el tipo de intercambio, y los bits 54-5 codifican el desplazamiento del intercambio.
Antes de Linux 3.11, los bits 60-55 se usaban para codificar el logaritmo en base 2 del tamaño de la página.
Para utilizar /proc/pid/pagemap de manera eficiente, use /proc/pid/maps para determinar qué áreas de memoria están realmente mapeadas y busque saltar sobre regiones no mapeadas.
El archivo /proc/pid/pagemap solo está presente si la opción de configuración del kernel CONFIG_PROC_PAGE_MONITOR está habilitada.
El permiso para acceder a este archivo se rige por una comprobación del modo de acceso ptrace PTRACE_MODE_READ_FSCREDS; consulte ptrace(2).
