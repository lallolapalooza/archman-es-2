NOMBRE

primesieve - genera números primos

SINOPSIS

primesieve [INICIO] FIN [OPCIÓN]...

DESCRIPCIÓN

Genera los números primos y/o k-tuplas de primos dentro de [INICIO, FIN] (< 2^64) usando el tamiz de Eratóstenes segmentado. primesieve incluye una serie de extensiones al tamiz de Eratóstenes que mejoran significativamente el rendimiento: se tamizan múltiplos de primos pequeños previamente, usa factorización de ruedas para saltar múltiplos con factores primos pequeños y usa el algoritmo de tamiz de cubos que mejora la eficiencia de la caché al tamizar > 2^32. primesieve también es multi-hilo, utiliza todos los núcleos de CPU disponibles por defecto para contar primos y para encontrar el enésimo primo.

El tamiz de Eratóstenes segmentado tiene una complejidad de tiempo de ejecución de O(n log log n) operaciones y utiliza O(n^(1/2)) bits de memoria. Más específicamente, primesieve usa 8 bytes por primo tamizador, por lo tanto, su uso de memoria se puede aproximar por PrimePi(n^(1/2)) * 8 bytes (por hilo).

OPCIONES

-c[NÚM+], --count[=NÚM+]

Cuenta primos y/o k-tuplas de primos, 1 <= NÚM <= 6. Cuenta primos: -c o --count, cuenta primos gemelos: -c2 o --count=2, cuenta tríos de primos: -c3 o --count=3, ... También puedes contar primos y k-tuplas de primos al mismo tiempo, por ejemplo, -c123 cuenta primos, primos gemelos y tríos de primos.

--cpu-info

Imprime información de la CPU: nombre de la CPU, frecuencia, número de núcleos, tamaños de caché, ...

-d, --dist=DIST

Tamiza el intervalo [INICIO, INICIO + DIST].

-h, --help

Imprime este menú de ayuda.

-n, --nth-prime

Encuentra el enésimo primo, por ejemplo, 100 -n encuentra el 100º primo. Si se proporcionan 2 números N INICIO, encuentra el enésimo primo > INICIO, por ejemplo, 2 100 -n encuentra el 2º primo > 100.

--no-status

Desactiva el estado de progreso.

-p[NÚM], --print[=NÚM]

Imprime primos o k-tuplas de primos, 1 <= NÚM <= 6. Imprime primos: -p, imprime primos gemelos: -p2, imprime tríos de primos: -p3, ...

-q, --quiet

Modo silencioso, imprime menos salida.

-R, --RiemannR

Aproxima PrimePi(x) usando la función R de Riemann: R(x).

--RiemannR-inverse

Aproxima el enésimo primo usando la función R inversa de Riemann: R^-1(x).

-s, --size=TAMAÑO

Establece el tamaño del array de tamizado en KiB, 16 <= TAMAÑO <= 8192. Por defecto, primesieve utiliza un tamaño de tamiz que coincide con el tamaño de la caché L1 de tu CPU (por núcleo) o es ligeramente menor que el tamaño de la caché L2 de tu CPU. Esta configuración es crucial para el rendimiento; en CPUs exóticas, primesieve a veces no logra determinar los tamaños de caché de la CPU, lo que generalmente causa una gran desaceleración. En este caso, puedes obtener una mejora de velocidad significativa configurando manualmente el tamaño del tamiz al tamaño de la caché L1 o L2 de tu CPU (por núcleo).

-S, --stress-test[=MODO]

Ejecuta una prueba de estrés. El MODO puede ser CPU (por defecto) o RAM. El MODO CPU utiliza poca memoria (< 5 MiB por hilo) y ejerce la mayor carga sobre la CPU. El MODO RAM, por otro lado, utiliza mucha más memoria que el MODO CPU (cada hilo usa aproximadamente 1.16 GiB), pero la CPU generalmente no se calentará tanto como en el MODO CPU. Las pruebas de estrés continúan ejecutándose hasta que ocurre un error de cálculo (debido a un problema de hardware) o expira el tiempo de espera. El tiempo de espera predeterminado es de 24 horas; el tiempo de espera se puede cambiar usando la opción --timeout=SECS. Por defecto, la prueba de estrés utiliza un número de hilos que coincide con el número de núcleos de CPU; el número de hilos se puede cambiar usando la opción --threads=NÚM.

--test

Ejecuta varias pruebas de corrección (< 1 minuto).

-t, --threads=NÚM

Establece el número de hilos, 1 <= NÚM <= núcleos de CPU. Por defecto, primesieve utiliza todos los núcleos de CPU disponibles para contar primos y para encontrar el enésimo primo.

--time

Imprime el tiempo transcurrido en segundos.

--timeout=SECS

Establece el tiempo de espera de la prueba de estrés en segundos. También se admiten unidades de tiempo para segundos, minutos, horas, días y años con los sufijos s, m, h, d o y. Por ejemplo, --timeout 10m establece un tiempo de espera de 10 minutos. El tiempo de espera predeterminado de la prueba de estrés es de 24 horas.

-v, --version

Imprime información de versión y licencia.

EJEMPLOS

primesieve 1000

Cuenta los primos <= 1000.

primesieve 1e6 --print

Imprime los primos <= 10^6.

primesieve 1e6 --print > primes.txt

Almacena los primos <= 10^6 en un archivo de texto.

primesieve 2^32 --print=2

Imprime los primos gemelos <= 2^32.

primesieve 1e16 --dist=1e10 --threads=1

Cuenta los primos dentro de [10^16, 10^16 + 10^10] usando un solo hilo.
