NOMBRE

prunehistory - Eliminar tokens del archivo de historial de Usenet

SINOPSIS

prunehistory [-p] [-f archivo]

DESCRIPCIÓN

prunehistory modifica un archivo de texto en formato history(5) para "eliminar" un conjunto de tokens del mismo. Los tokens se eliminan sobrescribiéndolos con espacios, de modo que el tamaño y la posición de cualquier entrada posterior no cambian. Esto tiene un efecto similar a expirar el artículo, en el sentido de que todavía se menciona en la base de datos de historial pero no se puede recuperar.

prunehistory lee la entrada estándar. La entrada se toma como un conjunto de líneas. Las líneas en blanco y las líneas que comienzan con un signo de almohadilla ("#") se ignoran. Todas las demás líneas deben consistir en un ID de mensaje seguido de cero o más campos adicionales (que se ignoran). El ID del mensaje se utiliza como clave dbz para obtener un desplazamiento en el archivo de texto. Dado que innd solo se añade al archivo de texto, prunehistory no necesita interactuar con él.

OPCIONES

-p
prunehistory normalmente se quejará de las líneas que no siguen el formato correcto. Si se utiliza la opción -p, el programa imprimirá silenciosamente cualquier línea no válida en su salida estándar. (Las líneas en blanco y los comentarios también se pasan).
-f archivo
El nombre predeterminado del archivo de historial es pathdb/history; para especificar un nombre diferente, utilice la opción -f.
