NOMBRE

prepareHistFactory - crea un directorio de trabajo para las herramientas de HistFactory

SINOPSIS

prepareHistFactory [nombre_dir]

DESCRIPCIÓN

prepareHistFactory es un script simple que prepara un área de trabajo (y crea el directorio dir_name si se especifica). Dentro del directorio dir_name, crea un directorio results/, data/, y config/ relativo a la ruta dada. También copia HistFactorySchema.dtd y archivos XML de ejemplo en el directorio config/. Adicionalmente, copia un archivo root en el directorio data/ para su uso con los ejemplos. Una vez hecho esto, se está listo para ejecutar el ejemplo hist2workspace input.xml o editar los archivos XML para un nuevo proyecto.
