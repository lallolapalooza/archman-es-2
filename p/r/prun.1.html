PRUN(1) Entorno de ejecución de referencia de PMIx PRUN(1)

prun — lanzar una aplicación

SINOPSIS

shell$ prun ...opciones...

DESCRIPCIÓN

prun envía un trabajo al Entorno de Ejecución de Referencia de PMIx (PRRTE). El usuario tiene control sobre varias opciones de máquina virtual distribuida (DVM).

Gran parte de esta misma documentación de ayuda para este comando también se proporciona a través de prun --help [tema].
