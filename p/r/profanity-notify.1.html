profanity-notify(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/notify

DESCRIPCIÓN

Configura las notificaciones de escritorio. Para configurar mensajes de actualización de presencia en la consola, ventanas de chat y salas de chat, consulta '/help presence'.

SINOPSIS

/notify chat on|off

/notify chat current on|off

/notify chat text on|off

/notify room on|off

/notify room mention on|off

/notify room mention case_sensitive|case_insensitive

/notify room mention word_whole|word_part

/notify room offline on|off

/notify room current on|off

/notify room text on|off

/notify room trigger add <texto>

/notify room trigger remove <texto>

/notify room trigger list

/notify room trigger on|off

/notify on|off

/notify mention on|off

/notify trigger on|off

/notify reset

/notify remind <segundos>

/notify typing on|off

/notify typing current on|off

/notify invite on|off

/notify sub on|off

ARGUMENTOS

chat on|off

Notificaciones para mensajes de chat normales.

chat current on|off

Si se deben mostrar notificaciones de mensajes de chat normales cuando la ventana está enfocada.

chat text on|off

Mostrar el texto del mensaje en las notificaciones de mensajes normales.

room on|off

Notificaciones para todos los mensajes de las salas de chat.

room mention on|off

Notificaciones para mensajes de salas de chat cuando se menciona tu apodo.

room mention case_sensitive

Establece las notificaciones de mención de sala como sensibles a mayúsculas y minúsculas.

room mention case_insensitive

Establece las notificaciones de mención de sala como insensibles a mayúsculas y minúsculas.

room mention word_whole

Establece las notificaciones de mención de sala solo en coincidencias de palabra completa, es decir, cuando el apodo no es parte de una palabra más grande.

room mention word_part

Establece las notificaciones de mención de sala en coincidencias de palabra parcial, es decir, el apodo puede ser parte de una palabra más grande.

room offline on|off

Notificaciones para mensajes de salas de chat que se enviaron mientras estabas desconectado.

room current on|off

Si se deben mostrar notificaciones de todos los mensajes de salas de chat cuando la ventana está enfocada.

room text on|off

Mostrar el texto del mensaje en las notificaciones de mensajes de salas de chat.

room trigger add <texto>

Notificar cuando el texto especificado esté incluido en todos los mensajes de salas de chat.

room trigger remove <texto>

Elimina el desencadenador de notificación de sala de chat.

room trigger list

Lista todos los desencadenadores de resaltado de salas de chat.

room trigger on|off

Habilita o deshabilita todos los desencadenadores de notificación de salas de chat.

on|off

Anula la configuración global de mensajes para la sala de chat actual.

mention on|off

Anula la configuración global de 'mención' para la sala de chat actual.

trigger on|off

Anula la configuración global de 'desencadenador' para la sala de chat actual.

reset

Restablece la configuración de notificación global para la sala de chat actual.

remind <segundos>

Período de recordatorio de notificación para mensajes no leídos, usa 0 para deshabilitar.

typing on|off

Notificaciones cuando los contactos están escribiendo.

typing current on|off

Si las notificaciones de escritura se activan para la ventana actual.

invite on|off

Notificaciones para invitaciones a salas de chat.

sub on|off

Notificaciones para solicitudes de suscripción.

EJEMPLOS

/notify chat on

/notify chat text on

/notify room mention on

/notify room offline on

/notify room trigger add beer

/notify room trigger on

/notify room current off

/notify room text off

/notify remind 60

/notify typing on

/notify invite on
