proc_pid_timers(5) Manual de Formatos de Archivos proc_pid_timers(5)

NOMBRE

/proc/pid/timers - temporizadores POSIX

DESCRIPCIÓN

/proc/pid/timers (desde Linux 3.10)
Una lista de los temporizadores POSIX para este proceso. Cada temporizador se lista con una línea que comienza con la cadena "ID:". Por ejemplo:

ID: 1
signal: 60/00007fff86e452a8
notify: signal/pid.2634
ClockID: 0
ID: 0
signal: 60/00007fff86e452a8
notify: signal/pid.2634
ClockID: 1

Las líneas que se muestran para cada temporizador tienen los siguientes significados:
ID
El ID para este temporizador. Este no es el mismo que el ID del temporizador devuelto por timer_create(2); en su lugar, es el mismo ID interno del kernel que está disponible a través del campo si_timerid de la estructura siginfo_t (ver sigaction(2)).
signal
Este es el número de señal que este temporizador utiliza para entregar notificaciones seguido de una barra diagonal, y luego el valor sigev_value proporcionado al manejador de señales. Válido solo para temporizadores que notifican a través de una señal.
notify
La parte antes de la barra diagonal especifica el mecanismo que utiliza este temporizador para entregar notificaciones, y es uno de "thread", "signal", o "none". Inmediatamente después de la barra diagonal está la cadena "tid" para temporizadores con notificación SIGEV_THREAD_ID, o "pid" para temporizadores que notifican por otros mecanismos. Siguiendo el "." está el PID del proceso (o el ID de hilo del kernel del hilo) al que se le entregará una señal si el temporizador entrega notificaciones a través de una señal.
ClockID
Este campo identifica el reloj que utiliza el temporizador para medir el tiempo. Para la mayoría de los relojes, este es un número que coincide con una de las constantes CLOCK_* del espacio de usuario expuestas a través de <time.h>. Los temporizadores CLOCK_PROCESS_CPUTIME_ID se muestran con un valor de -6 en este campo. Los temporizadores CLOCK_THREAD_CPUTIME_ID se muestran con un valor de -2 en este campo.
Este archivo solo está disponible cuando el kernel fue configurado con CONFIG_CHECKPOINT_RESTORE.
