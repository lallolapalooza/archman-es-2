proc_filesystems(5) Manual de Formatos de Archivo proc_filesystems(5)

NOMBRE

/proc/filesystems - sistemas de archivos soportados

DESCRIPCIÓN

/proc/filesystems
Una lista de texto de los sistemas de archivos que son soportados por el kernel, es decir, sistemas de archivos que fueron compilados en el kernel o cuyos módulos del kernel están actualmente cargados. (Ver también filesystems(5).) Si un sistema de archivos está marcado con "nodev", esto significa que no requiere un dispositivo de bloque para ser montado (por ejemplo, sistema de archivos virtual, sistema de archivos de red).
Casualmente, este archivo puede ser utilizado por mount(8) cuando no se especifica ningún sistema de archivos y no se pudo determinar el tipo de sistema de archivos. Entonces se prueban los sistemas de archivos contenidos en este archivo (excepto aquellos que están marcados con "nodev").
