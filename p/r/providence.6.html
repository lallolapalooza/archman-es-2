NOMBRE

providence - salvapantallas de ojo en gloria

SINOPSIS

providence [--display host:display.screen] [--window] [--root] [--window-id número]
[--install] [--visual visual] [--delay microsegundos] [--wireframe] [--fps]

DESCRIPCIÓN

El código de providence muestra un ojo, envuelto en gloria, sobre la base de una pirámide.

OPCIONES

providence acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor por defecto.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--eye
Dibuja un ojo/$.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de id (decimal o hexadecimal) de un visual específico.
--wireframe
Renderiza en modo de alambre (con eliminación de líneas ocultas) en lugar de sólidos texturizados.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el número de polígonos.

ENTORNO

DISPLAY
para obtener el host y número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.

VER TAMBIÉN
