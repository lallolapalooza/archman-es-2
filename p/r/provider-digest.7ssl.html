NOMBRE

provider-digest - Las funciones de la biblioteca de resúmenes (digest) <-> proveedor

SINAPSIS

#include <openssl/core_dispatch.h>
#include <openssl/core_names.h>
/*
 * Los resúmenes soportan las siguientes firmas de función en arrays OSSL_DISPATCH.
 * (Las firmas de función no son funciones reales).
 */
/* Gestión de contexto */
void *OSSL_FUNC_digest_newctx(void *provctx);
void OSSL_FUNC_digest_freectx(void *dctx);
void *OSSL_FUNC_digest_dupctx(void *dctx);
void OSSL_FUNC_digest_copyctx(void *voutctx, void *vinctx);
/* Generación de resumen */
int OSSL_FUNC_digest_init(void *dctx, const OSSL_PARAM params[]);
int OSSL_FUNC_digest_update(void *dctx, const unsigned char *in, size_t inl);
int OSSL_FUNC_digest_final(void *dctx, unsigned char *out, size_t *outl,
                           size_t outsz);
int OSSL_FUNC_digest_digest(void *provctx, const unsigned char *in, size_t inl,
                            unsigned char *out, size_t *outl, size_t outsz);
/* Descriptores de parámetros de resumen */
const OSSL_PARAM *OSSL_FUNC_digest_gettable_params(void *provctx);
/* Descriptores de parámetros de operación de resumen */
const OSSL_PARAM *OSSL_FUNC_digest_gettable_ctx_params(void *dctx,
                                                       void *provctx);
const OSSL_PARAM *OSSL_FUNC_digest_settable_ctx_params(void *dctx,
                                                       void *provctx);
/* Parámetros de resumen */
int OSSL_FUNC_digest_get_params(OSSL_PARAM params[]);
/* Parámetros de operación de resumen */
int OSSL_FUNC_digest_set_ctx_params(void *dctx, const OSSL_PARAM params[]);
int OSSL_FUNC_digest_get_ctx_params(void *dctx, OSSL_PARAM params[]);

DESCRIPCIÓN

Esta documentación está dirigida principalmente a autores de proveedores. Consulte provider(7) para obtener más información.

La operación DIGEST permite a los proveedores implementar algoritmos de resumen (digest) y ponerlos a disposición de las aplicaciones a través de las funciones de la API EVP_DigestInit_ex(3), EVP_DigestUpdate(3) y EVP_DigestFinal(3) (y otras funciones relacionadas).

Todas las "funciones" mencionadas aquí se pasan como punteros a función entre libcrypto y el proveedor en arrays OSSL_DISPATCH(3) a través de arrays OSSL_ALGORITHM(3) que son devueltos por la función provider_query_operation() del proveedor (véase "Funciones del Proveedor" en provider-base(7)).

Todas estas "funciones" tienen una definición de tipo de función correspondiente llamada OSSL_FUNC_{name}_fn, y una función auxiliar para obtener el puntero de la función desde un elemento OSSL_DISPATCH(3) llamada OSSL_FUNC_{name}. Por ejemplo, la "función" OSSL_FUNC_digest_newctx() tiene estos:

typedef void *(OSSL_FUNC_digest_newctx_fn)(void *provctx);
static ossl_inline OSSL_FUNC_digest_newctx_fn
    OSSL_FUNC_digest_newctx(const OSSL_DISPATCH *opf);

Los arrays OSSL_DISPATCH(3) están indexados por números que se proporcionan como macros en openssl-core_dispatch.h(7), como sigue:

OSSL_FUNC_digest_newctx               OSSL_FUNC_DIGEST_NEWCTX
OSSL_FUNC_digest_freectx              OSSL_FUNC_DIGEST_FREECTX
OSSL_FUNC_digest_dupctx               OSSL_FUNC_DIGEST_DUPCTX
OSSL_FUNC_digest_copyctx              OSSL_FUNC_DIGEST_COPYCTX
OSSL_FUNC_digest_init                 OSSL_FUNC_DIGEST_INIT
OSSL_FUNC_digest_update               OSSL_FUNC_DIGEST_UPDATE
OSSL_FUNC_digest_final                OSSL_FUNC_DIGEST_FINAL
OSSL_FUNC_digest_digest               OSSL_FUNC_DIGEST_DIGEST
OSSL_FUNC_digest_get_params           OSSL_FUNC_DIGEST_GET_PARAMS
OSSL_FUNC_digest_get_ctx_params       OSSL_FUNC_DIGEST_GET_CTX_PARAMS
OSSL_FUNC_digest_set_ctx_params       OSSL_FUNC_DIGEST_SET_CTX_PARAMS
OSSL_FUNC_digest_gettable_params      OSSL_FUNC_DIGEST_GETTABLE_PARAMS
OSSL_FUNC_digest_gettable_ctx_params  OSSL_FUNC_DIGEST_GETTABLE_CTX_PARAMS
OSSL_FUNC_digest_settable_ctx_params  OSSL_FUNC_DIGEST_SETTABLE_CTX_PARAMS

Una implementación de algoritmo de resumen puede no implementar todas estas funciones. Para ser utilizables, se deben implementar todas o ninguna de OSSL_FUNC_digest_newctx, OSSL_FUNC_digest_freectx, OSSL_FUNC_digest_init, OSSL_FUNC_digest_update, OSSL_FUNC_digest_final y OSSL_FUNC_digest_get_params. Todas las demás funciones son opcionales.

Funciones de Gestión de Contexto

OSSL_FUNC_digest_newctx() debe crear y devolver un puntero a una estructura del lado del proveedor para mantener la información de contexto durante una operación de resumen. Se devolverá un puntero a este contexto en varias de las otras llamadas a funciones de operación de resumen. El parámetro provctx es el contexto del proveedor generado durante la inicialización del proveedor (véase provider(7)).

A OSSL_FUNC_digest_freectx() se le pasa un puntero al contexto de resumen del lado del proveedor en el parámetro dctx. Esta función debe liberar cualquier recurso asociado con ese contexto.

OSSL_FUNC_digest_dupctx() debe duplicar el contexto de resumen del lado del proveedor en el parámetro dctx y devolver la copia duplicada.

OSSL_FUNC_digest_copyctx() debe copiar el contexto de resumen del lado del proveedor en el parámetro vinctx al parámetro voutctx, que es otro contexto del lado del proveedor. La función OSSL_FUNC_digest_copyctx se utiliza en la función EVP_MD_CTX_copy_ex para acelerar las operaciones HMAC en PBKDF2. Esta función es opcional y se utilizará dupctx si no hay una función EVP_MD_CTX_copy_ex.

Funciones de Generación de Resumen

OSSL_FUNC_digest_init() inicializa una operación de resumen dado un contexto de resumen del lado del proveedor recién creado en el parámetro dctx. Los params, si no son NULL, deben establecerse en el contexto de una manera similar a como se usa OSSL_FUNC_digest_set_ctx_params().

OSSL_FUNC_digest_update() se llama para suministrar datos que se resumirán como parte de una operación de resumen previamente inicializada. El parámetro dctx contiene un puntero a un contexto del lado del proveedor previamente inicializado. OSSL_FUNC_digest_update() debe resumir inl bytes de datos en la ubicación apuntada por in. OSSL_FUNC_digest_update() puede llamarse varias veces para una única operación de resumen.

OSSL_FUNC_digest_final() genera un resumen iniciado a través de llamadas previas a OSSL_FUNC_digest_init() y OSSL_FUNC_digest_update(). El parámetro dctx contiene un puntero al contexto del lado del proveedor. El resumen debe escribirse en *out y la longitud del resumen en *outl. El resumen no debe exceder los outsz bytes.

OSSL_FUNC_digest_digest() es una función de resumen "de un solo disparo". No se utiliza ningún contexto de resumen del lado del proveedor. En su lugar, el contexto del proveedor que se creó durante la inicialización del proveedor se pasa en el parámetro provctx (véase provider(7)). Se deben resumir inl bytes en in y el resultado debe almacenarse en out. La longitud del resumen debe almacenarse en *outl, que no debe exceder los outsz bytes.

Parámetros de Resumen

Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros utilizada por estas funciones.

OSSL_FUNC_digest_get_params() obtiene detalles de la implementación del algoritmo y los almacena en params.

OSSL_FUNC_digest_set_ctx_params() establece los parámetros de la operación de resumen para el contexto de resumen del lado del proveedor dctx en params. Cualquier configuración de parámetro es adicional a las que se establecieron previamente. Pasar NULL para params debería devolver verdadero.

OSSL_FUNC_digest_get_ctx_params() obtiene detalles de la operación de resumen del contexto de resumen del lado del proveedor proporcionado dctx y los almacena en params. Pasar NULL para params debería devolver verdadero.

OSSL_FUNC_digest_gettable_params() devuelve un array constante de OSSL_PARAM(3) que contiene descriptores de los parámetros que OSSL_FUNC_digest_get_params() puede manejar.

OSSL_FUNC_digest_gettable_ctx_params() y OSSL_FUNC_digest_settable_ctx_params() devuelven arrays constantes de OSSL_PARAM(3) como descriptores de los parámetros que OSSL_FUNC_digest_get_ctx_params() y OSSL_FUNC_digest_set_

NOMBRE

provider-digest - Interfaz del proveedor Digest de OpenSSL

SINOPSIS

En la definición de la interfaz de un proveedor, hay varias funciones disponibles bajo el tema DIGEST. Estas son:

    OSSL_FUNC_digest_newctx, OSSL_FUNC_digest_init, OSSL_FUNC_digest_update,
    OSSL_FUNC_digest_final, OSSL_FUNC_digest_digest, OSSL_FUNC_digest_freectx,
    OSSL_FUNC_digest_dupctx, OSSL_FUNC_digest_get_size,
    OSSL_FUNC_digest_get_block_size, OSSL_FUNC_digest_get_params,
    OSSL_FUNC_digest_set_params, OSSL_FUNC_digest_get_ctx_params,
    OSSL_FUNC_digest_set_ctx_params.

DESCRIPCIÓN

Un proveedor puede implementar la interfaz DIGEST para proporcionar implementaciones de algoritmos de resumen (digests). La interfaz DIGEST se define en include/openssl/provider_ctx.h.

El proveedor debe registrar un conjunto de funciones de la interfaz DIGEST utilizando OSSL_PROVIDER_register_digest. Para ver un ejemplo de cómo se hace esto, consulte la documentación de provider(7).

La interfaz DIGEST se puede dividir en dos partes:

  • Funciones de configuración y administración del ciclo de vida del contexto.
  • Funciones de operación del resumen.

Las funciones de configuración y administración del ciclo de vida son:

OSSL_FUNC_digest_newctx
Crea un nuevo contexto de resumen del lado del proveedor. Esto debe ser una estructura opaca que contenga el estado del resumen. El parámetro name es el nombre del algoritmo de resumen, por ejemplo, "sha256".
OSSL_FUNC_digest_init
Inicializa o reinicializa un contexto de resumen del lado del proveedor existente ctx. Si provctx es NULL, el contexto se reinicializa a su estado predeterminado. De lo contrario, si provctx es un contexto de algoritmo válido, el contexto se inicializa con los parámetros especificados en provctx.
OSSL_FUNC_digest_update
Actualiza el resumen con los datos proporcionados en data con longitud len.
OSSL_FUNC_digest_final
Calcula el resumen final y lo almacena en digest. El contexto ctx puede reutilizarse después de una llamada exitosa a final. El valor de len debe ser lo suficientemente grande como para contener el resumen.
OSSL_FUNC_digest_digest
Una función conveniente que calcula el resumen de los datos en una sola llamada. Combina init, update y final. El parámetro digest debe ser lo suficientemente grande como para contener el resumen.
OSSL_FUNC_digest_freectx
Libera el contexto de resumen del lado del proveedor ctx.
OSSL_FUNC_digest_dupctx
Duplica el contexto de resumen del lado del proveedor ctx. El nuevo contexto duplicado puede ser utilizado independientemente del contexto original.
OSSL_FUNC_digest_get_size
Devuelve el tamaño del resumen en bytes.
OSSL_FUNC_digest_get_block_size
Devuelve el tamaño del bloque del algoritmo de resumen subyacente en bytes.

Las funciones de operación del resumen son:

OSSL_FUNC_digest_get_params
Recupera los parámetros del lado del proveedor asociados con el algoritmo de resumen provctx y los almacena en params. Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros.
OSSL_FUNC_digest_set_params
Establece los parámetros del lado del proveedor asociados con el algoritmo de resumen provctx de params. Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros.

Los parámetros del contexto del resumen son:

Tanto OSSL_FUNC_digest_get_ctx_params como OSSL_FUNC_digest_set_ctx_params manejan, respectivamente, los parámetros del contexto del resumen. El array se basa en el estado actual del contexto del lado del proveedor si dctx no es NULL y, de lo contrario, en el algoritmo del lado del proveedor provctx.

Los parámetros reconocidos actualmente por los resúmenes integrados con esta función son los siguientes. No todos los parámetros son relevantes para todos los resúmenes o son entendidos por ellos:

"blocksize" (OSSL_DIGEST_PARAM_BLOCK_SIZE) <entero sin signo>
El tamaño del bloque del resumen. La longitud del parámetro "blocksize" no debe exceder la de un size_t.
"size" (OSSL_DIGEST_PARAM_SIZE) <entero sin signo>
El tamaño de salida del resumen. La longitud del parámetro "size" no debe exceder la de un size_t.
"flags" (OSSL_DIGEST_PARAM_FLAGS) <entero sin signo>
Diversas banderas que describen un comportamiento excepcional para el resumen:
EVP_MD_FLAG_ONESHOT
Este método de resumen solo puede manejar un bloque de entrada.
EVP_MD_FLAG_XOF
Este método de resumen es una función de salida extensible (XOF).
EVP_MD_FLAG_DIGALGID_NULL
Al configurar un DigestAlgorithmIdentifier, esta bandera tendrá el parámetro establecido en NULL por defecto. Úselo para PKCS#1. Nota: si se combina con EVP_MD_FLAG_DIGALGID_ABSENT, este último anulará.
EVP_MD_FLAG_DIGALGID_ABSENT
Al configurar un DigestAlgorithmIdentifier, esta bandera tendrá el parámetro ausente por defecto. Nota: si se combina con EVP_MD_FLAG_DIGALGID_NULL, el último será anulado.
EVP_MD_FLAG_DIGALGID_CUSTOM
Manejo personalizado de DigestAlgorithmIdentifier a través de ctrl, con EVP_MD_FLAG_DIGALGID_ABSENT como valor predeterminado. Nota: si se combina con EVP_MD_FLAG_DIGALGID_NULL, el último será anulado. Actualmente no se utiliza.

La longitud del parámetro "flags" debe ser igual a la de un unsigned long int.

Parámetros del Contexto del Resumen

OSSL_FUNC_digest_set_ctx_params() establece los parámetros del resumen asociados con el contexto del resumen del lado del proveedor dado dctx a params. Cualquier configuración de parámetro es adicional a las que se establecieron previamente. Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros.

OSSL_FUNC_digest_get_ctx_params() obtiene detalles de los valores de parámetros actualmente establecidos asociados con el contexto del resumen del lado del proveedor dado dctx y los almacena en params. Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros.

VALORES DE RETORNO

OSSL_FUNC_digest_newctx() y OSSL_FUNC_digest_dupctx() deben devolver el contexto de resumen del lado del proveedor recién creado, o NULL en caso de fallo.

OSSL_FUNC_digest_init(), OSSL_FUNC_digest_update(), OSSL_FUNC_digest_final(), OSSL_FUNC_digest_digest(), OSSL_FUNC_digest_set_params() y OSSL_FUNC_digest_get_params() deben devolver 1 para éxito o 0 en caso de error.

OSSL_FUNC_digest_size() debe devolver el tamaño del resumen.

OSSL_FUNC_digest_block_size() debe devolver el tamaño del bloque del algoritmo de resumen subyacente.

ERRORES

Las llamadas a las API EVP_Q_digest(), EVP_Digest() y EVP_DigestFinal_ex() no esperan que el tamaño del resumen sea mayor que EVP_MAX_MD_SIZE. Cualquier algoritmo que produzca resúmenes más grandes no se puede utilizar con esas llamadas a la API.
