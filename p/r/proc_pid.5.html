proc_pid(5) Manual de formatos de archivo proc_pid(5)

NOMBRE

/proc/pid/, /proc/self/ - información del proceso

DESCRIPCIÓN

/proc/pid/
Existe un subdirectorio numérico para cada proceso en ejecución; el subdirectorio se nombra con el ID del proceso. Cada subdirectorio /proc/pid contiene los pseudo-archivos y directorios descritos a continuación.
Los archivos dentro de cada directorio /proc/pid normalmente son propiedad del ID de usuario y el ID de grupo efectivos del proceso. Sin embargo, como medida de seguridad, la propiedad se establece en root:root si el atributo "dumpable" del proceso se establece en un valor distinto de 1.
Antes de Linux 4.11, root:root se refería al ID de usuario y grupo "global" del usuario root (es decir, UID 0 y GID 0 en el espacio de nombres de usuario inicial). Desde Linux 4.11, si el proceso está en un espacio de nombres de usuario no inicial que tiene un mapeo válido para el ID de usuario (grupo) 0 dentro del espacio de nombres, entonces la propiedad de usuario (grupo) de los archivos bajo /proc/pid se establece en el mismo ID de usuario (grupo) root del espacio de nombres. Esto significa que dentro de un contenedor, las cosas funcionan como se esperaba para el usuario "root" del contenedor.
El atributo "dumpable" del proceso puede cambiar por las siguientes razones:
•
El atributo se estableció explícitamente a través de la operación prctl(2) PR_SET_DUMPABLE.
•
El atributo se restableció al valor en el archivo /proc/sys/fs/suid_dumpable (descrito a continuación), por las razones descritas en prctl(2).
Restablecer el atributo "dumpable" a 1 revierte la propiedad de los archivos /proc/pid/* al UID y GID efectivos del proceso. Tenga en cuenta, sin embargo, que si el UID o GID efectivos se modifican posteriormente, el atributo "dumpable" puede restablecerse, como se describe en prctl(2). Por lo tanto, puede ser deseable restablecer el atributo "dumpable" después de realizar cualquier cambio deseado en el UID o GID efectivos del proceso.
/proc/self/
Este directorio se refiere al proceso que accede al sistema de archivos /proc, y es idéntico al directorio /proc nombrado por el ID del proceso del mismo proceso.
