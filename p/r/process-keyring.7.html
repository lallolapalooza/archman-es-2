process-keyring(7) Manual de Información Miscelánea process-keyring(7)

NOMBRE

process-keyring - keyring compartido por proceso

DESCRIPCIÓN

El keyring de proceso es un keyring que se utiliza para anclar claves en nombre de un proceso. Se crea solo cuando un proceso lo solicita. El keyring de proceso tiene el nombre (descripción) _pid.

Se define un valor especial de número de serie, KEY_SPEC_PROCESS_KEYRING, que puede usarse en lugar del número de serie real del keyring de proceso del proceso que llama.

Desde la utilidad keyctl(1), '@p' puede usarse en lugar de un ID de clave numérico de manera similar, pero dado que keyctl(1) es un programa que se ejecuta después de hacer fork, esto no tiene utilidad.

Un hilo creado usando el indicador CLONE_THREAD de clone(2) tiene el mismo keyring de proceso que el llamador de clone(2). Cuando se crea un nuevo proceso usando fork(), inicialmente no tiene un keyring de proceso. El keyring de proceso de un proceso se borra en execve(2). El keyring de proceso se destruye cuando el último hilo que hace referencia a él termina.

Si un proceso no tiene un keyring de proceso cuando se accede a él, entonces el keyring de proceso se creará si el keyring va a ser modificado; de lo contrario, se producirá el error ENOKEY.

VER TAMBIÉN
