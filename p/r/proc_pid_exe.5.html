proc_pid_exe(5) Manual de formatos de archivo proc_pid_exe(5)

NOMBRE

proc_pid_exe(5) — enlace simbólico a la ruta del programa

DESCRIPCIÓN

/proc/pid/exe
En Linux 2.2 y posteriores, este archivo es un enlace simbólico que contiene la ruta real del comando ejecutado. Este enlace simbólico se puede resolver normalmente; intentar abrirlo abrirá el ejecutable. Incluso puede escribir /proc/pid/exe para ejecutar otra copia del mismo ejecutable que está ejecutando el proceso pid. Si la ruta ha sido desvinculada, el enlace simbólico contendrá la cadena ' (deleted)' añadida a la ruta original. En un proceso multihilo, el contenido de este enlace simbólico no está disponible si el hilo principal ya ha terminado (típicamente llamando a pthread_exit(3)).
El permiso para resolver o leer (readlink(2)) este enlace simbólico se rige por una verificación de modo de acceso ptrace PTRACE_MODE_READ_FSCREDS; consulte ptrace(2).
En Linux 2.0 y anteriores, /proc/pid/exe es un puntero al binario que se ejecutó y aparece como un enlace simbólico. Una llamada a readlink(2) en este archivo bajo Linux 2.0 devuelve una cadena en el formato:

[dispositivo]:inodo

Por ejemplo, [0301]:1502 sería el inodo 1502 en el dispositivo principal 03 (dispositivos IDE, MFM, etc.) secundario 01 (primera partición en el primer disco).
find(1) con la opción -inum se puede utilizar para localizar el archivo.
