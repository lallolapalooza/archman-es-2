PRS(1P) Manual del programador de POSIX PRS(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

prs — imprime un archivo SCCS (DESARROLLO)

SINOPSIS

prs [-a] [-d espec_datos] [-r[SID]] archivo...
prs [-e|-l] -c corte [-d espec_datos] archivo...
prs [-e|-l] -r[SID] [-d espec_datos] archivo...

DESCRIPCIÓN

La utilidad prs escribirá en la salida estándar partes o la totalidad de un archivo SCCS en un formato proporcionado por el usuario.

OPCIONES

La utilidad prs se ajustará a las Definiciones Base del volumen de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de la utilidad, excepto que la opción -r tiene un argumento de opción opcional. Este argumento de opción opcional no se puede presentar como un argumento separado. Se deberán soportar las siguientes opciones:

-d espec_datos
Especifica la especificación de datos de salida. La espec_datos será una cadena que consista en palabras clave de datos del archivo SCCS (consulte Palabras clave de datos) intercaladas con texto opcional proporcionado por el usuario.
-r[SID]
Especifica la cadena de identificación de SCCS (SID) de un delta para el cual se desea información. Si no se especifica un argumento de opción SID, se asumirá el SID del delta creado más recientemente.
-e
Solicita información para todos los deltas creados antes y que incluyan el delta designado a través de la opción -r o la fecha/hora dada por la opción -c.
-l
Solicita información para todos los deltas creados después y que incluyan el delta designado a través de la opción -r o la fecha/hora dada por la opción -c.
-c corte
Indica la fecha/hora de corte, en el formato:
AA[MM[DD[HH[MM[SS]]]]]

Para el componente AA, los valores en el rango [69,99] se referirán a los años 1969 a 1999 inclusive, y los valores en el rango [00,68] se referirán a los años 2000 a 2068 inclusive.

Nota:
Se espera que en una futura versión de este estándar el siglo por defecto inferido de un año de 2 dígitos cambie. (Esto se aplicaría a todos los comandos que aceptan un año de 2 dígitos como entrada).

No se incluirán en la salida cambios (deltas) al archivo SCCS que se hayan creado después de la fecha/hora de corte especificada. Las unidades omitidas de la fecha/hora se asumen sus valores máximos posibles; por ejemplo, -c 7502 es equivalente a -c 750228235959.

-a
Solicita la escritura de información tanto para deltas eliminados (es decir, tipo de delta=R (consulte rmdel)—) como existentes (es decir, tipo de delta=D). Si la opción -a no se especifica, se proporcionará información solo para deltas existentes.

OPERANDOS

Se deberá soportar el siguiente operando:

archivo
Una ruta de un archivo SCCS existente o un directorio. Si archivo es un directorio, la utilidad prs se comportará como si cada archivo en el directorio fuera especificado como un archivo nombrado, excepto que los archivos no SCCS (el último componente de la ruta no comienza con s.) y los archivos ilegibles se ignorarán silenciosamente.

Si aparece exactamente un operando archivo, y es '-', se leerá la entrada estándar; cada línea de la entrada estándar se tomará como el nombre de un archivo SCCS a procesar. Los archivos no SCCS y los archivos ilegibles se ignorarán silenciosamente.

STDIN

La entrada estándar será un archivo de texto utilizado solo cuando el operando archivo se especifique como '-'. Cada línea del archivo de texto se interpretará como una ruta SCCS.

ARCHIVOS DE ENTRADA

Cualquier archivo SCCS mostrado son archivos de formato no especificado.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de prs:

LANG
Proporciona un valor por defecto para las variables de internacionalización que no están definidas o están vacías. (Consulte las Definiciones Base del volumen de POSIX.1‐2017, Sección 8.2, Variables de internacionalización la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de locale).
LC_ALL
Si se establece en un valor de cadena no vacío, anulará los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la locale para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, un solo byte frente a caracteres multibyte en argumentos y archivos de entrada).
LC_MESSAGES

Determina la locale que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Por defecto.

STDOUT

La salida estándar será un archivo de texto cuyo formato depende de las palabras clave de datos especificadas con la opción -d.

Palabras clave de datos

Las palabras clave de datos especifican qué partes de un archivo SCCS se recuperarán y se mostrarán. Todas las partes de un archivo SCCS tienen una palabra clave de datos asociada. Una palabra clave de datos puede aparecer en una espec_datos varias veces.

La información escrita por prs consistirá en:

1.
El texto proporcionado por el usuario
2.
Los valores apropiados (extraídos del archivo SCCS) sustituidos por las palabras clave de datos reconocidas en el orden de aparición en la espec_datos

El formato de un valor de palabra clave de datos será simple ('S'), en el que la sustitución de palabras clave es directa, o multilínea ('M').

El texto proporcionado por el usuario será cualquier texto que no sean palabras clave de datos reconocidas. Un <tab> se especificará mediante '\t' y un <salto de línea> mediante '\n'. Cuando la opción -r no se especifica, la espec_datos por defecto será:

:PN::\n\n

y la siguiente espec_datos se utilizará para cada delta seleccionado:

:Dt:\t:DL:\nMRs:\n:MR:COMMENTS:\n:C:

Formato de Fecha y Hora

La fecha y hora de un delta se generarán en el formato:

AA/MM/DD HH:MM:SS

donde AA, MM, DD, HH, MM, y SS representan el año, mes, día, hora, minuto y segundo, respectivamente.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

0
Se ha ejecutado correctamente.
>0
Ha ocurrido un error.

CONFORME A

POSIX.1‐2008.

DIRECCIONES FUTURAS

El manejo del siglo para los años de dos dígitos en la opción -c puede cambiar en futuras versiones.

NAME

prs - process SCCS deltas

SYNOPSIS

prs [-a][-cdate_time][-dformat_string][-e][-ffile][-i][-lfile][-r[sid_mnemonic]][-t] SCCS_file ...

DESCRIPTION

The prs utility is used to process SCCS (Source Code Control System) files and write selected information to the standard output. It allows retrieval of information about deltas and can reformat this information based on the given format string. Without any options, prs produces a default report for each delta in the specified SCCS files.

The SCCS files are specified by one or more pathnames. Each SCCS_file argument must be the path to an SCCS file (typically with a .s suffix).

The format string, specified with the -d option, controls the output. It consists of plain text and SCCS replacement strings. Each replacement string starts with a colon (:) and is followed by one or more characters that identify the information to be substituted. All other characters in the format string are copied to the standard output verbatim.

The following replacement strings are supported:

Tag Description Format Example Type
:UN: User name " yes or no S
:J: Joint edit flag " yes or no S
:LK: Locked releases " :R: ... S
:Q: User-defined keyword " text S
:M: Module name " text S
:FB: Floor boundary " :R: S
:CB: Ceiling boundary " :R: S
:Ds: Default SID " :I: S
:ND: Null delta flag " yes or no S
:FD: File descriptive text Comments text M
:BD: Body Body text M
:GB: Gotten body " text M
:W: A form of what string N/A :Z::M:\t:I: S
:A: A form of what string N/A :Z::Y: :M: :I::Z: S
:Z: what string delimiter N/A @(#) S
:F: SCCS filename N/A text S
:PN: SCCS file pathname N/A text S
*
:Dt:=:DT: :I: :D: :T: :P: :DS: :DP:
**
:R:.:L:.:B:.:S: if the delta is a branch delta (:BF:==yes)
:R:.:L: if the delta is not a branch delta (:BF:==no)
***
The line statistics are capped at 99999. For example, if 100000 lines were unchanged in a certain revision, :Lu: shall produce the value 99999.

STDERR

The standard error shall be used only for diagnostic messages.

OUTPUT FILES

None.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The following exit values shall be returned:

0
Successful completion.
>0
An error occurred.

CONSEQUENCES OF ERRORS

Default.

The following sections are informative.

APPLICATION USAGE

None.

EXAMPLES

1.
The following example:
prs -d "User Names for :F: are:
:UN:" s.file

might write to standard output:

User Names for s.file are:
xyz
131
abc
2.
The following example:
prs -d "Delta for pgm :M:: :I: - :D: By :P:" -r s.file

might write to standard output:

Delta for pgm main.c: 3.7 - 77/12/01 By cas
3.
As a special case:
prs s.file

might write to standard output:

s.file:
<blank line>
D 1.1 77/12/01 00:00:00 cas 1 000000/00000/00000
MRs:
bl78-12345
bl79-54321
COMMENTS:
this is the comment line for s.file initial delta
<blank line>

for each delta table entry of the D type. The only option allowed to be used with this special case is the -a option.
