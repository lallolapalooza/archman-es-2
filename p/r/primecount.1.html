NOMBRE

primecount - contar números primos

SINOPSIS

primecount x [opciones]

DESCRIPCIÓN

Cuenta el número de primos menores o iguales a x (<= 10^31) utilizando implementaciones rápidas de los algoritmos de la función de conteo de primos combinatoria. Por defecto, primecount cuenta primos utilizando el algoritmo de Xavier Gourdon, que tiene una complejidad de tiempo de O(x^(2/3) / log^2 x) operaciones y utiliza O(x^(2/3) * log^3 x) de memoria. primecount es multi-hilo, utiliza todos los núcleos de CPU disponibles por defecto.

OPCIONES

-d, --deleglise-rivat

Cuenta primos usando el algoritmo de Deleglise-Rivat.

--double-check

Recomputa pi(x) con factores de ajuste de alfa alternativos para verificar el primer resultado. Esta redundancia ayuda a proteger contra posibles errores en primecount: si existe un error, es muy poco probable que ambas computaciones de pi(x) produzcan el mismo resultado (incorrecto).

-g, --gourdon

Cuenta primos usando el algoritmo de Xavier Gourdon (algoritmo por defecto).

-l, --legendre

Cuenta primos usando la fórmula de Legendre.

--lehmer

Cuenta primos usando la fórmula de Lehmer.

--lmo

Cuenta primos usando el algoritmo de Lagarias-Miller-Odlyzko.

-m, --meissel

Cuenta primos usando la fórmula de Meissel.

--Li

Aproxima pi(x) usando la integral logarítmica euleriana: Li(x), con Li(x) = li(x) - li(2).

--Li-inverse

Aproxima el enésimo primo usando la integral logarítmica euleriana inversa: Li^-1(x).

-n, --nth-prime

Calcula el enésimo primo.

-p, --primesieve

Cuenta primos usando el tamiz de Eratóstenes.

--phi X A

phi(x, a) cuenta los números <= x que no son divisibles por ninguno de los primeros a primos.

-R, --RiemannR

Aproxima pi(x) usando la función R de Riemann: R(x).

--RiemannR-inverse

Aproxima el enésimo primo usando la función R de Riemann inversa: R^-1(x).

-s, --status[=NUM]

Muestra el progreso de la computación, por ejemplo, 1%, 2%, 3%, ... Muestra NUM dígitos después del punto decimal: --status=1 imprime 99.9%.

--test

Ejecuta varias pruebas de corrección y sale.

--time

Imprime el tiempo transcurrido en segundos.

-t, --threads=NUM

Establece el número de hilos, 1 <= NUM <= núcleos de CPU. Por defecto, primecount utiliza todos los núcleos de CPU disponibles.

-v, --version

Imprime la información de la versión y la licencia.

-h, --help

Imprime este menú de ayuda.

OPCIONES AVANZADAS PARA EL ALGORITMO DE DELEGLISE-RIVAT

--P2

Calcula la 2ª función de tamizado parcial.

--S1

Calcula las hojas ordinarias.

--S2-trivial

Calcula las hojas especiales triviales.

--S2-easy

Calcula las hojas especiales fáciles.

--S2-hard

Calcula las hojas especiales difíciles.

FACTOR DE AJUSTE

El factor de ajuste alfa equilibra principalmente el cálculo de las fórmulas S2_easy y S2_hard. Al aumentar alfa, el tiempo de ejecución de la fórmula S2_hard generalmente disminuye, mientras que el tiempo de ejecución de la fórmula S2_easy aumenta. Por defecto, primecount selecciona automáticamente un factor de ajuste alfa que probablemente proporcione el mejor rendimiento para la entrada del usuario.

El factor de ajuste alfa también es muy útil para verificar los cálculos de pi(x). Se calcula pi(x) dos veces, pero para el segundo cálculo se utiliza un factor alfa ligeramente diferente. Si los resultados de ambos cálculos de pi(x) coinciden, entonces pi(x) se ha verificado exitosamente.

-a, --alpha=NUM

Establece el factor de ajuste alfa: y = x^(1/3) * alpha, 1 <= alpha <= x^(1/6).

OPCIONES AVANZADAS PARA EL ALGORITMO DE XAVIER GOURDON

--AC

Calcula las fórmulas A + C.

--B

Calcula la fórmula B.

--D

Calcula la fórmula D.

--Phi0

Calcula la fórmula Phi0.

--Sigma

Calcula las 7 fórmulas Sigma.

FACTORES DE AJUSTE

Los factores de ajuste alpha_y y alpha_z equilibran principalmente el cálculo de las fórmulas A, B, C y D. Al disminuir alpha_y y aumentar alpha_z, el tiempo de ejecución de la fórmula B aumenta, mientras que el tiempo de ejecución de las fórmulas A, C y D disminuye. Por defecto, primecount selecciona automáticamente los factores de ajuste alpha_y y alpha_z que probablemente proporcionen el mejor rendimiento para la entrada del usuario.

Tanto los factores de ajuste alpha_y como alpha_z también son muy útiles para verificar los cálculos de pi(x). Se calcula pi(x) dos veces, pero para el segundo cálculo se utilizan factores de ajuste alpha_y y/o alpha_z ligeramente diferentes. Si los resultados de ambos cálculos de pi(x) coinciden, entonces pi(x) se ha verificado exitosamente.

--alpha-y=NUM

Establece el factor de ajuste alpha_y: y = x^(1/3) * alpha_y, 1 <= alpha_y <= x^(1/6).

--alpha-z=NUM

Establece el factor de ajuste alpha_z: z = y * alpha_z, 1 <= alpha_z <= x^(1/6).

DOBLE VERIFICACIÓN DE CÁLCULOS DE PI(X)

Para cálculos grandes de pi(x) que se ejecutan durante varias semanas o meses, es importante verificar dichos cálculos para protegerse contra errores de cálculo debidos a errores de hardware y/o errores en primecount.

Para verificar un cálculo de pi(x), se calcula pi(x) dos veces. Pero para la segunda ejecución, se utiliza la opción --double-check. La opción --double-check habilita el uso de factores de ajuste alfa alternativos, asegurando que todos los límites internos en el segundo cálculo difieran ligeramente del primero. Esta redundancia ayuda a proteger contra posibles errores en primecount: si existe un error, es muy poco probable que ambos cálculos de pi(x) produzcan el mismo resultado (incorrecto).

primecount 1e20 --status

Primer cálculo de pi(x) usando factores de ajuste alfa por defecto.

primecount 1e20 --status --double-check

Segundo cálculo de pi(x) usando factores de ajuste alfa alternativos.

EJEMPLOS

primecount 1000

Cuenta los primos <= 1000.

primecount 1e17 --status

Cuenta los primos <= 10^17 e imprime información de estado.

primecount 1e15 --threads 1 --time

Cuenta los primos <= 10^15 usando un solo hilo e imprime el tiempo transcurrido.
