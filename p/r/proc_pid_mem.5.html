NOMBRE

/proc/pid/mem - memoria

DESCRIPCIÓN

/proc/pid/mem
Este archivo se puede utilizar para acceder a las páginas de memoria de un proceso a través de open(2), read(2) y lseek(2).
El permiso para acceder a este archivo se rige por una comprobación de modo de acceso ptrace PTRACE_MODE_ATTACH_FSCREDS; véase ptrace(2).
