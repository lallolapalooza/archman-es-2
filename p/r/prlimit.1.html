PRLIMIT(1) Comandos de usuario PRLIMIT(1)

NOMBRE

prlimit - obtener y establecer límites de recursos de procesos

SINOPSIS

prlimit [opciones] [--recurso[=límites]] [--pid PID]

prlimit [opciones] [--recurso[=límites]] comando [argumento...]

DESCRIPCIÓN

Dado un ID de proceso y uno o más recursos, prlimit intenta recuperar y/o modificar los límites.

Cuando se proporciona comando, prlimit ejecutará este comando con los argumentos dados.

El parámetro límites se compone de un valor blando y uno duro, separados por dos puntos (:), para modificar los valores existentes. Si no se dan límites, prlimit mostrará los valores actuales. Si no se proporciona uno de los valores, se utilizará el existente. Para especificar el límite ilimitado o infinito (RLIM_INFINITY), se puede pasar el string -1 o 'unlimited'.

Debido a la naturaleza de los límites, el límite blando debe ser menor o igual al límite alto (también llamado techo). Para ver todos los límites de recursos disponibles, consulte la sección OPCIONES DE RECURSOS.

•soft:hard Especifica ambos límites.
•soft: Especifica solo el límite blando.
•:hard Especifica solo el límite duro.
•valor Especifica ambos límites al mismo valor.

OPCIONES GENERALES

--noheadings

No imprimir una línea de encabezado.

-o, --output lista

Define las columnas de salida a utilizar. Si no se especifica un orden de salida, se utiliza un conjunto predeterminado. Utilice --help para obtener una lista de todas las columnas admitidas.

-p, --pid PID

Especifica el ID del proceso. Sin esta opción (y sin comando), se utilizará el proceso en ejecución.

--raw

Utilizar el formato de salida sin procesar.

--verbose

Modo detallado.

-h, --help

Mostrar texto de ayuda y salir.

-V, --version

Mostrar la versión y salir.

OPCIONES DE RECURSOS

-c, --core[=límites]

Tamaño máximo de un archivo core.

-d, --data[=límites]

Tamaño máximo de datos.

-e, --nice[=límites]

Prioridad nice máxima permitida para aumentar.

-f, --fsize[=límites]

Tamaño máximo de archivo.

-i, --sigpending[=límites]

Número máximo de señales pendientes.

-l, --memlock[=límites]

Espacio de direcciones máximo bloqueado en memoria.

-m, --rss[=límites]

Tamaño máximo del conjunto residente (RSS).

-n, --nofile[=límites]

Número máximo de archivos abiertos.

-q, --msgqueue[=límites]

Número máximo de bytes en colas de mensajes POSIX.

-r, --rtprio[=límites]

Prioridad máxima en tiempo real.

-s, --stack[=límites]

Tamaño máximo de la pila.

-t, --cpu[=límites]

Tiempo de CPU, en segundos.

-u, --nproc[=límites]

Número máximo de procesos.

-v, --as[=límites]

Límite del espacio de direcciones.

-x, --locks[=límites]

Número máximo de bloqueos de archivos activos.

-y, --rttime[=límites]

Tiempo de espera para tareas en tiempo real.

NOTAS

La llamada al sistema prlimit(2) es compatible desde Linux 2.6.36, los kernels más antiguos romperán este programa.

EJEMPLOS

prlimit --pid 13134

Mostrar los valores de límite para todos los recursos actuales.

prlimit --pid 13134 --rss --nofile=1024:4095

Mostrar los límites de RSS y establecer los límites blandos y duros para el número de archivos abiertos a 1024 y 4095, respectivamente.

prlimit --pid 13134 --nproc=512:

Modificar solo el límite blando para el número de procesos.

prlimit --pid $$ --nproc=unlimited

Establecer para el proceso actual tanto los valores blandos como los límites máximos para el número de procesos a ilimitado.

prlimit --cpu=10 sort -u hugefile

Establecer ambos límites de tiempo de CPU, blando y duro, a diez segundos y ejecutar sort(1).
