proc_stat(5) Manual de Formatos de Archivo proc_stat(5)

NOMBRE

/proc/stat - estadísticas del sistema del kernel

DESCRIPCIÓN

/proc/stat
estadísticas del kernel/sistema. Varía según la arquitectura. Las entradas comunes incluyen:
cpu 10132153 290696 3084719 46828483 16683 0 25195 0 175628 0
cpu0 1393280 32966 572056 13343292 6130 0 17875 0 23933 0
La cantidad de tiempo, medida en unidades de USER_HZ (1/100 de segundo en la mayoría de las arquitecturas, use sysconf(_SC_CLK_TCK) para obtener el valor correcto), que el sistema ("línea cpu") o la CPU específica ("línea cpuN") pasó en varios estados:
user
(1) Tiempo pasado en modo de usuario.
nice
(2) Tiempo pasado en modo de usuario con baja prioridad (nice).
system
(3) Tiempo pasado en modo de sistema.
idle
(4) Tiempo pasado en la tarea inactiva. Este valor debería ser USER_HZ multiplicado por la segunda entrada en el pseudoarchivo /proc/uptime.
iowait (desde Linux 2.5.41)
(5) Tiempo esperando a que I/O se complete. Este valor no es fiable, por las siguientes razones:
•
La CPU no esperará a que I/O se complete; iowait es el tiempo que una tarea está esperando a que I/O se complete. Cuando una CPU entra en estado inactivo para I/O pendiente de tareas, se programará otra tarea en esta CPU.
•
En una CPU multinúcleo, la tarea que espera a que I/O se complete no se está ejecutando en ninguna CPU, por lo que el iowait de cada CPU es difícil de calcular.
•
El valor en este campo puede *disminuir* en ciertas condiciones.
irq (desde Linux 2.6.0)
(6) Tiempo de servicio de interrupciones.
softirq (desde Linux 2.6.0)
(7) Tiempo de servicio de softirqs.
steal (desde Linux 2.6.11)
(8) Tiempo robado, que es el tiempo pasado en otros sistemas operativos al ejecutarse en un entorno virtualizado.
guest (desde Linux 2.6.24)
(9) Tiempo pasado ejecutando una CPU virtual para sistemas operativos invitados bajo el control del kernel de Linux.
guest_nice (desde Linux 2.6.33)
(10) Tiempo pasado ejecutando un invitado con nice (CPU virtual para sistemas operativos invitados bajo el control del kernel de Linux).
page 5741 1808
El número de páginas que el sistema trajo (paged in) y el número que sacó (paged out) (desde el disco).
swap 1 0
El número de páginas de swap que se han traído y sacado.
intr 1462898
Esta línea muestra los recuentos de interrupciones atendidas desde el arranque, para cada una de las posibles interrupciones del sistema. La primera columna es el total de todas las interrupciones atendidas, incluidas las interrupciones específicas de la arquitectura no numeradas; cada columna subsiguiente es el total para esa interrupción numerada en particular. Las interrupciones no numeradas no se muestran, solo se suman al total.
disk_io: (2,0):(31,30,5764,1,2) (3,0):...
(major,disk_idx):(noinfo, read_io_ops, blks_read, write_io_ops, blks_written)
(Solo Linux 2.4)
ctxt 115315
El número de cambios de contexto que experimentó el sistema.
btime 769041601
tiempo de arranque, en segundos desde la Época, 1970-01-01 00:00:00 +0000 (UTC).
processes 86031
Número de forks desde el arranque.
procs_running 6
Número de procesos en estado ejecutable. (Desde Linux 2.5.45 en adelante.)
procs_blocked 2
Número de procesos bloqueados esperando a que I/O se complete. (Desde Linux 2.5.45 en adelante.)
softirq 229245889 94 60001584 13619 5175704 2471304 28 51212741 59130143 0 51240672
Esta línea muestra el número de softirqs para todas las CPUs. La primera columna es el total de todos los softirqs y cada columna subsiguiente es el total para un softirq en particular. (Desde Linux 2.6.31 en adelante.)
