program_invocation_name(3) Manual de funciones de biblioteca program_invocation_name(3)

NOMBRE

program_invocation_name, program_invocation_short_name - obtener el nombre utilizado para invocar el programa que llama

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <errno.h>
extern char *program_invocation_name;
extern char *program_invocation_short_name;

DESCRIPCION

program_invocation_name contiene el nombre que se utilizó para invocar el programa que llama. Esto es lo mismo que el valor de argv[0] en main(), con la diferencia de que el ámbito de program_invocation_name es global.

program_invocation_short_name contiene el componente basename del nombre que se utilizó para invocar el programa que llama. Es decir, es el mismo valor que program_invocation_name, con todo el texto hasta la última barra (/) inclusive, si la hay, eliminado.

Estas variables son inicializadas automáticamente por el código de inicio de ejecución de glibc.

VERSIONES

El archivo específico de Linux /proc/pid/cmdline proporciona acceso a información similar.

ESTANDARES

GNU.

VER TAMBIÉN

proc(5)
