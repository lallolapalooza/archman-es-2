NOMBRE

/proc/pid/timerslack_ns - tiempo de espera del temporizador en nanosegundos

DESCRIPCIÓN

/proc/pid/timerslack_ns (desde Linux 4.6)
Este archivo expone el valor de "tiempo de espera" actual del proceso, expresado en nanosegundos. El archivo se puede escribir, lo que permite cambiar el valor del tiempo de espera del temporizador del proceso. Escribir 0 en este archivo restablece el tiempo de espera del temporizador "actual" al valor de tiempo de espera del temporizador "predeterminado". Para más detalles, consulte la discusión de PR_SET_TIMERSLACK en prctl(2).
Inicialmente, el permiso para acceder a este archivo estaba regido por una verificación de modo de acceso ptrace PTRACE_MODE_ATTACH_FSCREDS (ver ptrace(2)). Sin embargo, esto se consideró posteriormente un requisito demasiado estricto (y tuvo el efecto secundario de que requerir que un proceso tuviera la capacidad CAP_SYS_PTRACE también le permitiría ver y cambiar la memoria de cualquier proceso). Por lo tanto, desde Linux 4.9, solo se requiere la capacidad (más débil) CAP_SYS_NICE para acceder a este archivo.
