PRTED(1) Entorno de ejecución de referencia PMIx PRTED(1)

prted — demonio auxiliar para PRRTE

SINOPSIS

shell$ prted ...opciones...

DESCRIPCIÓN

prted es el demonio auxiliar de backend para el Entorno de Ejecución de Referencia PMIx (PRRTE).

La extensa documentación de ayuda para este comando se proporciona a través de prted --help [tema].

Al menos por ahora, ese contenido no está disponible en formato de página de manual. Las solicitudes de extracción (pull requests) para agregar todo el contenido (a través de infraestructura repetible) serían muy apreciadas.
