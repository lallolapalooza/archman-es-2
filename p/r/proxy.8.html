NOMBRE

proxy - Herramienta de prueba de Libproxy

SINOPSIS

proxy [esquema://host][:puerto]

DESCRIPCIÓN

El programa proxy muestra el servidor proxy que se debe utilizar para acceder a un recurso de red determinado. Puedes proporcionar una URL como parámetro o iniciar la herramienta en modo interactivo para introducir múltiples URLs. Como valor de retorno se mostrará el proxy requerido.

libproxy es una biblioteca que proporciona gestión automática de la configuración de proxy utilizando diferentes backends.

EJEMPLO

# proxy http://www.example.com

# http://127.0.0.1:8080

SALIDA DE DEPURACIÓN

Para mostrar más salida de depuración, puedes establecer la variable de entorno PX_DEBUG=1

Durante la ejecución, la herramienta muestra información interna de la biblioteca, como los módulos de plugin existentes, qué configuración se está utilizando y los valores de retorno.
