PROVIDER-SKEYMGMT(7ssl) OpenSSL PROVIDER-SKEYMGMT(7ssl)

NOMBRE

provider-skeymgmt - Funciones de la biblioteca SKEY MGMT <-> proveedor

SINOPSIS

#include <openssl/core_dispatch.h>
/*
 * Ninguna de estas son funciones reales, sino que se muestran de esta manera para
 * las firmas de las funciones que se ofrecen como punteros a función en arrays OSSL_DISPATCH.
 */
/* Destrucción de objetos de clave */
void OSSL_FUNC_skeymgmt_free(void *keydata);
/* Funciones de importación y exportación de objetos de clave */
void *OSSL_FUNC_skeymgmt_import(void *provctx, int selection,
                                const OSSL_PARAM params[]);
int OSSL_FUNC_skeymgmt_export(void *keydata, int selection,
                              OSSL_CALLBACK *param_cb, void *cbarg);
void *OSSL_FUNC_skeymgmt_generate(void *provctx,
                                  const OSSL_PARAM params[]);
const OSSL_PARAM *OSSL_FUNC_skeymgmt_gen_settable_params(void *provctx);
const OSSL_PARAM *OSSL_FUNC_skeymgmt_imp_settable_params(void *provctx);
const char *OSSL_FUNC_skeymgmt_get_key_id(void *keydata);

DESCRIPCIÓN

La operación SKEYMGMT no tiene mucha visibilidad pública en las bibliotecas de OpenSSL, sino que es una operación interna diseñada para funcionar con operaciones que utilizan objetos de clave simétrica opacos.

La operación SKEY MGMT comparte conocimientos con las operaciones con las que trabaja, por lo tanto, SKEY MGMT y los algoritmos que la utilizan deben pertenecer al mismo proveedor. Las bibliotecas de OpenSSL se asegurarán de que así sea.

La responsabilidad principal de la operación SKEY MGMT es mantener los datos de clave del lado del proveedor para la estructura EVP_SKEY de la biblioteca OpenSSL.

Todas las "funciones" mencionadas aquí se pasan como punteros a función entre libcrypto y el proveedor en los arrays de OSSL_DISPATCH(3) a través de los arrays de OSSL_ALGORITHM(3) que son devueltos por la función provider_query_operation() del proveedor (ver "Funciones del proveedor" en provider-base(7)).

Todas estas "funciones" tienen un tipo de función correspondiente definido llamado OSSL_FUNC_{name}_fn, y una función auxiliar para recuperar el puntero a función de un elemento de OSSL_DISPATCH(3) llamado OSSL_FUNC_{name}.

Los arrays de OSSL_DISPATCH(3) se indexan mediante números que se proporcionan como macros en openssl-core_dispatch.h(7), como sigue:

OSSL_FUNC_skeymgmt_free                 OSSL_FUNC_SKEY MGMT_FREE
OSSL_FUNC_skeymgmt_import               OSSL_FUNC_SKEY MGMT_IMPORT
OSSL_FUNC_skeymgmt_export               OSSL_FUNC_SKEY MGMT_EXPORT
OSSL_FUNC_skeymgmt_generate             OSSL_FUNC_SKEY MGMT_GENERATE
OSSL_FUNC_skeymgmt_get_key_id           OSSL_FUNC_SKEY MGMT_GET_KEY_ID
OSSL_FUNC_skeymgmt_imp_settable_params  OSSL_FUNC_SKEY MGMT_IMP_SETTABLE_PARAMS
OSSL_FUNC_skeymgmt_gen_settable_params  OSSL_FUNC_SKEY MGMT_GEN_SETTABLE_PARAMS

La gestión SKEY MGMT está inspirada en KEYMGMT pero es más sencilla.

Objetos de clave

Un objeto de clave es una colección de datos para una clave simétrica, y se representa como keydata en este manual.

El contenido exacto de un objeto de clave lo define el proveedor, y se asume que diferentes operaciones dentro de un mismo proveedor utilizan la misma estructura exacta para representar esta colección de datos, de modo que, por ejemplo, un objeto de clave creado utilizando la interfaz SKEY MGMT pueda pasarse tal cual a otras operaciones del mismo proveedor, como OSSL_FUNC_mac_init_opaque() (ver provider-mac(7)).

Con la función de exportación SKEY MGMT, es posible seleccionar un subconjunto específico de datos para manejar, regido por los bits en un indicador de selection. Los bits son:

OSSL_SKEYMGMT_SELECT_SECRET_KEY
Indica que se deben incluir los bytes crudos de la clave secreta en un objeto de clave.
OSSL_SKEYMGMT_SELECT_PARAMETERS
Indica que se deben incluir los parámetros en un objeto de clave.

También se definen bits combinados para facilitar su uso:

OSSL_SKEY MGMT_SELECT_ALL
Indica que se debe incluir todo en un objeto de clave.

La interpretación exacta de estos bits o cómo se combinan se deja a cada función donde se pueda especificar un selector.

Función de destrucción

OSSL_FUNC_skeymgmt_free() debe liberar el keydata pasado.

Funciones de importación y exportación de objetos de clave

OSSL_FUNC_skeymgmt_import() debe importar datos en keydata con valores tomados del array de OSSL_PARAM(3) params. Asigna memoria para el objeto keydata (no hay una función de asignación separada).

OSSL_FUNC_skeymgmt_imp_settable_params() devuelve una lista de parámetros que se pueden proporcionar a la función OSSL_FUNC_skeymgmt_import().

OSSL_FUNC_skeymgmt_export() debe extraer los valores indicados por selection de keydata, crear un array de OSSL_PARAM(3) con ellos y llamar a param_cb con ese array así como con el cbarg dado. El array de OSSL_PARAM(3) pasado es transitorio y se libera al retornar de param_cb.

Funciones de generación de objetos de clave

OSSL_FUNC_skeymgmt_generate() crea una nueva clave de acuerdo con los valores tomados del array de OSSL_PARAM(3) params. Asigna memoria para el objeto keydata.

OSSL_FUNC_skeymgmt_gen_settable_params() devuelve una lista de parámetros que se pueden proporcionar a la función OSSL_FUNC_skeymgmt_generate().

Funciones de información de objetos de clave

OSSL_FUNC_skeymgmt_get_key_id() devuelve una cadena terminada en NUL que identifica la clave particular. La cadena devuelta será liberada por una llamada a EVP_SKEY_free(), por lo que los llamadores deben copiarla si desean conservar el valor más allá de la vida útil de la clave. El propósito de esta función es proporcionar una cadena imprimible que pueda ayudar a los usuarios a acceder a la clave específica. El contenido de esta cadena es específico del proveedor.

Parámetros comunes de importación y exportación

Consulte OSSL_PARAM(3) para obtener más detalles sobre la estructura de parámetros.

Los parámetros de información comunes actualmente reconocidos por los algoritmos de skeymgmt integrados son los siguientes:

"raw-bytes" (SKEY_PARAM_RAW_BYTES) <cadena de octetos>
El valor representa la clave simétrica como un array de bytes.
"key-length" (SKEY_PARAM_KEY_LENGTH) <entero>
El valor es la longitud en bytes de la clave dada.

VALORES DE RETORNO

OSSL_FUNC_skeymgmt_import() y OSSL_FUNC_skeymgmt_generate() devuelven un puntero a un objeto asignado en caso de éxito y NULL en caso de error.

OSSL_FUNC_skeymgmt_export() devuelve 1 para éxito o 0 en caso de error.

OSSL_FUNC_skeymgmt_get_key_id() devuelve un puntero a una cadena terminada en 0 o NULL.

OSSL_FUNC_skeymgmt_gen_settable_params() y OSSL_FUNC_skeymgmt_imp_settable_params() devuelven referencias a un array de OSSL_PARAM que puede ser NULL si no hay parámetros configurables.
