NOMBRE

progpick - Fuerza bruta con un flujo de permutaciones de un patrón específico

SINOPSIS

progpick [-vqc] [-e comando] PATRÓN

DESCRIPCIÓN

progpick es un programa para generar permutaciones de un patrón explícitamente proporcionado. Es útil si olvidaste algunos detalles sobre una contraseña pero aún recuerdas la mayor parte de ella.

OPCIONES

-v, --verbose

Registros detallados (se puede usar varias veces, máximo: 4)

-q, --quiet

No imprimir la barra de progreso

-c, --count

Contar el número total de permutaciones en lugar de imprimirlas

-e comando, --exec comando

Enviar permutaciones a la entrada estándar de un subproceso. comando se analiza en una lista de argumentos y luego se ejecuta directamente en lugar de pasar por /bin/sh, por lo que el entrecomillado del shell funciona, pero otras características del shell no.

-h, --help

Imprime información de ayuda.

EJEMPLOS

Generar todas las combinaciones de a-z con una longitud de 5

progpick '{a..z}{a..z}{a..z}{a..z}{a..z}'

Con barra de progreso

progpick '{a..z}{a..z}{a..z}{a..z}{a..z}' > /dev/null

Sin barra de progreso

progpick -q '{a..z}{a..z}{a..z}{a..z}{a..z}' > /dev/null

Para hacer un carácter opcional

progpick '{a..z}{{a..z},}'

De a-z y 0-9

progpick '{{a..z},{0..9}}'

Ejecutar un script para cada resultado

progpick 'a{b,c{d,e{f,g}}}' | while read -r x; do
./script "$x"
done

Enviar el resultado a la entrada estándar de un script

progpick -e './script.sh' 'a{b,c{d,e{f,g}}}'

Intentar abrir una partición luks

sudo progpick -e 'cryptsetup open --test-passphrase /dev/sdc1' 'a{b,c{d,e{f,g}}}'
