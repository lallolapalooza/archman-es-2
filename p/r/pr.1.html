PR(1) Comandos de usuario PR(1)

NOMBRE

pr - convertir archivos de texto para imprimir

SINOPSIS

pr [OPCIÓN]... [ARCHIVO]...

DESCRIPCIÓN

Pagina o columna ARCHIVO(s) para imprimir.

Sin ARCHIVO, o cuando ARCHIVO es -, lee la entrada estándar.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

+PRIMERA_PAGINA[:ULTIMA_PAGINA], --páginas=PRIMERA_PAGINA[:ULTIMA_PAGINA]
comienza [termina] la impresión con la página PRIMERA_[ULTIMA_]PÁGINA
-COLUMNA, --columnas=COLUMNA
produce COLUMNA columnas e imprime las columnas hacia abajo, a menos que se use -a. Equilibra el número de líneas en las columnas de cada página
-a, --across
imprime las columnas de forma transversal en lugar de hacia abajo, se usa junto con -COLUMNA
-c, --show-control-chars
usa notación de gorro (^G) y notación octal con barra invertida
-d, --double-space
intercala doblemente la salida
-D, --date-format=FORMATO
usa FORMATO para la fecha del encabezado
-e[CAR[ANCHO]], --expand-tabs[=CAR[ANCHO]]
expande los CARACTERES de entrada (tabulaciones) a un ANCHO de tabulación (8)
-F, -f, --form-feed
usa saltos de página en lugar de saltos de línea para separar las páginas (con un encabezado de página de 3 líneas con -F o un encabezado y pie de página de 5 líneas sin -F)
-h, --header=ENCABEZADO
usa un ENCABEZADO centrado en lugar del nombre del archivo en el encabezado de página, -h "" imprime una línea en blanco, no uses -h""
-i[CAR[ANCHO]], --output-tabs[=CAR[ANCHO]]
reemplaza los espacios con CARACTERES (tabulaciones) para tabular ANCHO (8)
-J, --join-lines
une líneas completas, desactiva la truncación de líneas -W, sin alineación de columnas, --sep-string[=CADENA] establece separadores
-l, --length=LONGITUD_PAGINA
establece la longitud de página a LONGITUD_PAGINA (66) líneas (número predeterminado de líneas de texto 56, y con -F 63). implica -t si LONGITUD_PAGINA <= 10
-m, --merge
imprime todos los archivos en paralelo, uno en cada columna, trunca líneas, pero une líneas de longitud completa con -J
-n[SEP[DIGITOS]], --number-lines[=SEP[DIGITOS]]
enumera líneas, usa DIGITOS (5) dígitos, luego SEP (TAB), el conteo predeterminado comienza con la primera línea del archivo de entrada
-N, --first-line-number=NUMERO
comienza a contar con NUMERO en la primera línea de la primera página impresa (ver +PRIMERA_PAGINA)
-o, --indent=MARGEN
desplaza cada línea con MARGEN (cero) espacios, no afecta -w ni -W, MARGEN se añadirá a ANCHO_PAGINA
-r, --no-file-warnings
omite advertencias cuando un archivo no puede ser abierto
-s[CAR], --separator[=CAR]
separa columnas por un solo carácter, el predeterminado para CAR es el carácter sin -w y 'sin carácter' con -w. -s[CAR] desactiva el truncado de líneas de las tres opciones de columna (-COLUMNA|-a -COLUMNA|-m) excepto si se establece -w
-S[CADENA], --sep-string[=CADENA]
separa columnas por CADENA, sin -S: separador predeterminado con -J y en caso contrario (igual que -S" "), no tiene efecto en las opciones de columna
-t, --omit-header
omite encabezados y pies de página; implícito si LONGITUD_PAGINA <= 10
-T, --omit-pagination
omite encabezados y pies de página, elimina cualquier paginación por saltos de página establecidos en los archivos de entrada
-v, --show-nonprinting
usa notación octal con barra invertida
-w, --width=ANCHO_PAGINA
establece el ancho de página a ANCHO_PAGINA (72) caracteres solo para la salida de múltiples columnas de texto, -s[car] lo desactiva (72)
-W, --page-width=ANCHO_PAGINA
establece el ancho de página a ANCHO_PAGINA (72) caracteres siempre, trunca líneas, excepto cuando se establece la opción -J, sin interferencia con -S o -s
--help
muestra esta ayuda y sale
--version
muestra la información de la versión y sale

NAME

pr - prepare files for printing

SYNOPSIS

pr [option...] [file...]

DESCRIPTION

The pr utility reads files and prepares them for printing. By default, it formats them into a two-column layout, adds line numbers, and prints a header with the date, time, and filename.

pr can also merge its input files into a single column, sort them by name, produce a table of contents, and convert them into a format suitable for the diff(1) command.

Options can be specified in either of the following forms: an Option-Argument (`-f F`) or a separate option (`-f` `F`).

-columns
Produce output in columns columns.
-c
Print a table of contents for the given files.
-d
Produce output in the same format as the diff(1) command.
-e width
Set the width of the page to width.
-f formfeed
Print a form feed character between files.
-F
Print a form feed character between files.
-h header
Use header as the page header.
-l length
Set the page length to length.
-n [width]
Number all output lines.
-o indent
Indent each line by indent spaces.
-p
Pause before each page.
-r
Warn if input files cannot be opened.
-s [separator]
Separate the columns of output with the single character separator.
-t
Do not print a header or trailer.
-u
Produce output in the same format as the diff(1) command (unified format).
-v
Produce output in the same format as the diff(1) command (version control format).
-w width
Set the width of the page to width.
-+
Turn off the default header and trailer.
