PREZIP-BIN(1) Manual de usuario abreviado de Aspell PREZIP-BIN(1)

NOMBRE

prezip-bin - compresor/descompresor de listas de palabras delta prefijo zip

SINOPSIS

prezip-bin [ -V | -d | -z ]

DESCRIPCIÓN

prezip-bin comprime/descomprime listas de palabras ordenadas de la entrada estándar a la salida estándar.

Prezip-bin es similar a word-list-compress(1) pero permite un conjunto de caracteres más grande de {0x00...0x09, 0x0B, 0x0C, 0x0E...0xFF} y palabras múltiples de más de 255 caracteres de longitud. También puede descomprimir archivos compatibles con word-list-compress(1).

COMANDOS

Prezip-bin acepta solo uno de estos comandos.

-V
Muestra el número de versión de prezip-bin en la salida estándar.
-d
Lee una lista de palabras comprimida de la entrada estándar y la descomprime en la salida estándar. Puede ser un archivo comprimido de word-list-compress(1) o de prezip-bin.
-z
Lee una lista de palabras binaria de la entrada estándar y la comprime en la salida estándar.

EJEMPLOS

prezip-bin -d <wordlist.cwl >wordlist.txt
Descomprime el archivo wordlist.cwl en el archivo de texto wordlist.txt
prezip-bin -z <wordlist.txt >wordlist.pz 2>errors.txt
Comprime wordlist.txt en el archivo binario wordlist.pz y envía cualquier mensaje de error a un archivo de texto llamado errors.txt
LC_COLLATE=C sort -u <wordlist.txt | prezip-bin -z >wordlist.pz
Ordena una lista de palabras y luego la canaliza a prezip-bin para crear un archivo binario comprimido wordlist.pz.
prezip-bin -d <words.pz | aspell create master ./words.rws
Descomprime una lista de palabras, luego la canaliza a aspell(1) para crear una lista de ortografía. Por favor, consulte el manual de información de aspell(1) para un uso y opciones adecuados.

CONSEJOS

Prezip-bin se usa mejor con archivos de tipo lista de palabras ordenadas. No es un programa de compresión de propósito general, ya que los archivos resultantes pueden aumentar de tamaño.

A diferencia de word-list-compress(1), si tu lista de palabras tiene espacios en blanco al principio o al final por motivos de formato, deberías eliminarlos antes de comprimir tu lista usando prezip-bin -z, de lo contrario, esos espacios se incluirán en la salida binaria comprimida.

DIAGNÓSTICOS

Prezip-bin normalmente sale con un código de retorno de 0. Si encuentra un error, se envía un mensaje a la salida de error estándar (stderr), y prezip-bin sale con un valor de retorno distinto de cero. Los mensajes de error se enumeran a continuación:

(muestra mensaje de ayuda/uso)
Se dio un comando desconocido en la línea de comandos, por lo que prezip-bin muestra un mensaje de uso en la salida de error estándar.
formato desconocido
El archivo de entrada parece no tener el formato esperado, o puede ser un formato más avanzado. El archivo de salida estará vacío.
entrada corrupta
Esto es solo para el comando de descompresión -d. El archivo de entrada parecía tener el formato correcto, pero algo parece estar mal ahora. Puede haber algunos datos válidos en la salida, pero debido a la corrupción de la entrada, el resto del archivo no se puede completar.
EOF inesperado
El archivo de entrada parecía estar bien pero terminó antes de lo esperado, por lo tanto, el archivo de salida no está completo.
