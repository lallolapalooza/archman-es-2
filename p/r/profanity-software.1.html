man(1) Cliente XMPP de Profanity man(1)

NOMBRE

/software

DESCRIPCIÓN

Descubre la versión de software de un contacto o los miembros de una sala. Si estás en un chat privado iniciado desde una sala de chat, no se requiere parámetro. Si el software del contacto no admite solicitudes de versión de software, no se mostrará nada.

SINOPSIS

/software

/software <fulljid>|<nick>

ARGUMENTOS

<fulljid>

Si estás en la consola o en una ventana de chat, el JID completo del que deseas ver la información del software.

<nick>

Si estás en una sala de chat, el apodo del que deseas ver la información del software.

EJEMPLOS

/software odin@valhalla.edda/laptop

/software odin@valhalla.edda/phone

/software thor
