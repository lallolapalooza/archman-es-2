profanity-close(1)

Paquete: profanity-gtk

Licencias: GPL3

man(1) Cliente XMPP de Profanity man(1)

NOMBRE

/close

DESCRIPCIÓN

Cierra ventanas. Si no se pasa ningún argumento, se cierra la ventana actual.

SINOPSIS

/close

/close <num>

/close <barejid>

/close <nick>

/close <roomjid>

/close <roomoccupantjid>

/close xmlconsole

/close all|read

ARGUMENTOS

<num>

Cierra la ventana con el número especificado.

<barejid>

Cierra la ventana de chat con el contacto por JID si está abierta.

<nick>

Cierra la ventana de chat con el contacto por apodo si está abierta.

<roomjid>

Cierra la ventana de la sala de chat con el roomjid si está abierta.

<roomoccupantjid>

Cierra el chat privado roomoccupantjid si está abierto.

xmlconsole

Cierra la ventana de la Consola XML si está abierta.

all

Cierra todas las ventanas.

read

Cierra todas las ventanas que no tengan mensajes no leídos.
