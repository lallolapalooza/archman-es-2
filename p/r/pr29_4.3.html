NOMBRE

pr29_4 - función API

SINOPSIS

#include <pr29.h>

int pr29_4(const uint32_t * in, size_t len);

ARGUMENTOS

const uint32_t * in
array de entrada con puntos de código unicode.
size_t len
longitud del array de entrada con puntos de código unicode.

DESCRIPCIÓN

Comprueba la entrada para ver si puede ser normalizada en diferentes cadenas por diferentes implementaciones de NFKC, debido a una anomalía en las especificaciones de NFKC.

Valor de retorno: Devuelve el valor Pr29_rc PR29_SUCCESS en caso de éxito, y PR29_PROBLEM si la secuencia de entrada es una "secuencia problemática" (es decir, puede ser normalizada en diferentes cadenas por diferentes implementaciones).
