NOMBRE

projid - el archivo de mapeo de nombres de proyecto

DESCRIPCIÓN

El archivo /etc/projid proporciona un mapeo entre identificadores numéricos de proyecto y un nombre simple legible por humanos (similar a la relación que existe entre nombres de usuario y UIDs). Su formato es simplemente:

# los comentarios se prefijan con almohadilla
# ...
cage:10
logfiles:42

Este archivo es opcional, si un identificador de proyecto no se puede mapear a un nombre, se interpretará y mostrará como un valor numérico.

VER TAMBIÉN

xfs_quota(8), xfsctl(3), projects(5).
