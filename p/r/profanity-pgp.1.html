NOMBRE

/pgp

DESCRIPCIÓN

Comandos PGP para gestionar claves y realizar cifrado PGP durante sesiones de chat. Vea el comando /cuenta para configurar su propia clave PGP.

SINOPSIS

/pgp libver

/pgp keys

/pgp contacts

/pgp setkey <contacto> <keyid>

/pgp start [<contacto>]

/pgp end

/pgp log on|off|redact

/pgp char <char>

/pgp sendfile on|off

/pgp sendpub [<contacto>]

ARGUMENTOS

libver

Muestra qué versión de la biblioteca libgpgme se está utilizando.

keys

Lista todas las claves conocidas por el sistema.

contacts

Muestra los contactos con claves públicas asignadas.

setkey <contacto> <keyid>

Asocia manualmente un contacto con una clave pública.

start [<contacto>]

Inicia el chat cifrado PGP, se utilizará el contacto actual si no se especifica.

end

Finaliza el chat cifrado PGP con el destinatario actual.

log on|off

Habilita o deshabilita el registro en texto plano de los mensajes cifrados PGP.

log redact

Registra los mensajes cifrados PGP, pero reemplaza el contenido con [redacted]. Este es el valor predeterminado.

char <char>

Establece el carácter que se mostrará junto a los mensajes cifrados PGP.

sendfile on|off

Permite que /sendfile envíe archivos sin cifrar mientras se utiliza PGP.

autoimport on|off

Importa automáticamente claves PGP de los mensajes.

sendpub [<contacto>]

Envía un mensaje al destinatario actual con su clave pública PGP, se utilizará el contacto actual si no se especifica.

EJEMPLOS

/pgp log off

/pgp setkey odin@valhalla.edda BA19CACE5A9592C5

/pgp start odin@valhalla.edda

/pgp end

/pgp char P
