NOMBRE

/proc/pid/status - información de estado y uso de memoria

DESCRIPCIÓN

/proc/pid/status
Proporciona mucha de la información de /proc/pid/stat y /proc/pid/statm en un formato más fácil de analizar para los humanos. Aquí hay un ejemplo:

$ cat /proc/$$/status
Name:   bash
Umask:  0022
State:  S (sleeping)
Tgid:   17248
Ngid:   0
Pid:    17248
PPid:   17200
TracerPid:      0
Uid:    1000    1000    1000    1000
Gid:    100     100     100     100
FDSize: 256
Groups: 16 33 100
NStgid: 17248
NSpid:  17248
NSpgid: 17248
NSsid:  17200
VmPeak:	  131168 kB
VmSize:	  131168 kB
VmLck:	       0 kB
VmPin:	       0 kB
VmHWM:	   13484 kB
VmRSS:	   13484 kB
RssAnon:	   10264 kB
RssFile:	    3220 kB
RssShmem:	       0 kB
VmData:	   10332 kB
VmStk:	     136 kB
VmExe:	     992 kB
VmLib:	    2104 kB
VmPTE:	      76 kB
VmPMD:	      12 kB
VmSwap:	       0 kB
HugetlbPages:          0 kB		# 4.4
CoreDumping:	0                       # 4.15
Threads:        1
SigQ:   0/3067
SigPnd: 0000000000000000
ShdPnd: 0000000000000000
SigBlk: 0000000000010000
SigIgn: 0000000000384004
SigCgt: 000000004b813efb
CapInh: 0000000000000000
CapPrm: 0000000000000000
CapEff: 0000000000000000
CapBnd: ffffffffffffffff
CapAmb:	0000000000000000
NoNewPrivs:     0
Seccomp:        0
Seccomp_filters:        0
Speculation_Store_Bypass:       vulnerable
Cpus_allowed:   00000001
Cpus_allowed_list:      0
Mems_allowed:   1
Mems_allowed_list:      0
voluntary_ctxt_switches:        150
nonvoluntary_ctxt_switches:     545

Los campos son los siguientes:
Name
Comando ejecutado por este proceso. Las cadenas de más de TASK_COMM_LEN (16) caracteres (incluyendo el byte nulo de terminación) se truncan silenciosamente.
Umask
Umask del proceso, expresado en octal con un cero inicial; véase umask(2). (Desde Linux 4.7.)
State
Estado actual del proceso. Uno de "R (corriendo)", "S (durmiendo)", "D (dormido en disco)", "T (parado)", "t (parado por depuración)", "Z (zombie)" o "X (muerto)".
Tgid
ID del grupo de hilos (es decir, ID del proceso).
Ngid
ID del grupo NUMA (0 si no hay ninguno; desde Linux 3.13).
Pid
ID del hilo (ver gettid(2)).
PPid
PID del proceso padre.
TracerPid
PID del proceso que rastrea a este proceso (0 si no está siendo rastreado).
Uid
Gid
UIDs (GIDs) reales, efectivos, de conjunto guardado y del sistema de archivos.
FDSize
Número de ranuras de descriptores de archivo asignadas actualmente.
Groups
Lista de grupos suplementarios.
NStgid
ID del grupo de hilos (es decir, PID) en cada uno de los espacios de nombres PID de los que pid es miembro. La entrada más a la izquierda muestra el valor con respecto al espacio de nombres PID del proceso que montó este procfs (o el espacio de nombres raíz si lo montó el kernel), seguido del valor en los espacios de nombres internos sucesivamente anidados. (Desde Linux 4.1.)
NSpid
ID del hilo en cada uno de los espacios de nombres PID de los que pid es miembro. Los campos están ordenados como para NStgid. (Desde Linux 4.1.)
NSpgid
ID del grupo de procesos en cada uno de los espacios de nombres PID de los que pid es miembro. Los campos están ordenados como para NStgid. (Desde Linux 4.1.)
NSsid
ID de sesión de la jerarquía de espacios de nombres de ID de sesión en cada uno de los espacios de nombres PID de los que pid es miembro. Los campos están ordenados como para NStgid. (Desde Linux 4.1.)
VmPeak
Pico de tamaño de memoria virtual.
VmSize
Tamaño de memoria virtual.
VmLck
Tamaño de memoria bloqueada (ver mlock(2)).
VmPin
Tamaño de memoria fijada (desde Linux 3.2). Estas son páginas que no se pueden mover porque algo necesita acceder directamente a la memoria física.
VmHWM
Pico de tamaño del conjunto residente ("marca de agua alta"). Este valor es inexacto; ver /proc/pid/statm arriba.
VmRSS
Tamaño del conjunto residente. Tenga en cuenta que el valor aquí es la suma de RssAnon, RssFile y RssShmem. Este valor es inexacto; ver /proc/pid/statm arriba.
RssAnon
Tamaño de memoria anónima residente. (desde Linux 4.5). Este valor es inexacto; ver /proc/pid/statm arriba.
RssFile
Tamaño de mapeos de archivos residentes. (desde Linux 4.5). Este valor es inexacto; ver /proc/pid/statm arriba.
RssShmem
Tamaño de memoria compartida residente (incluye memoria compartida de System V, mapeos de tmpfs(5) y mapeos anónimos compartidos). (desde Linux 4.5).
VmData
VmStk
VmExe
Tamaño de los segmentos de datos, pila y código. Este valor es inexacto; ver /proc/pid/statm arriba.
VmLib
Tamaño del código de la biblioteca compartida.
VmPTE
Tamaño de las entradas de la tabla de páginas (desde Linux 2.6.10).
VmPMD
Tamaño de las tablas de páginas de segundo nivel (añadido en Linux 4.0; eliminado en Linux 4.15).
VmSwap
Tamaño de memoria virtual intercambiada por páginas privadas anónimas; no se incluye el uso de swap de shmem (desde Linux 2.6.34). Este valor es inexacto; ver /proc/pid/statm arriba.
HugetlbPages
Tamaño de las porciones de memoria hugetlb (desde Linux 4.4).
CoreDumping
Contiene el valor 1 si el proceso está volcando memoria principal actualmente y 0 si no lo está (desde Linux 4.15). Esta información puede ser utilizada por un proceso de monitorización para evitar matar un proceso que está volcando memoria principal, lo que podría resultar en un archivo de volcado de memoria principal dañado.
Threads
Número de hilos en el proceso que contiene este hilo.
SigQ
Este campo contiene dos números separados por una barra que se refieren a las señales en cola para el ID de usuario real de este proceso. El primero de ellos es el número de señales actualmente en cola para este ID de usuario real, y el segundo es el límite de recursos sobre el número de señales en cola para este proceso (ver la descripción de RLIMIT_SIGPENDING en getrlimit(2)).
SigPnd
ShdPnd
Máscara (expresada en hexadecimal) de señales pendientes para el hilo y para el proceso en general (ver pthreads(7) y signal(7)).

DESCRIPTION

SigBlk
SigIgn
SigCgt
Máscaras (expresadas en hexadecimal) que indican señales que están siendo bloqueadas, ignoradas y capturadas (ver signal(7)).
CapInh
CapPrm
CapEff
Máscaras (expresadas en hexadecimal) de capacidades habilitadas en los conjuntos heredables, permitidos y efectivos (ver capabilities(7)).
CapBnd
Conjunto de límites de capacidades, expresado en hexadecimal (desde Linux 2.6.26, ver capabilities(7)).
CapAmb
Conjunto de capacidades ambientales, expresado en hexadecimal (desde Linux 4.3, ver capabilities(7)).
NoNewPrivs
Valor del bit no_new_privs (desde Linux 4.10, ver prctl(2)).
Seccomp
Modo Seccomp del proceso (desde Linux 3.8, ver seccomp(2)). 0 significa SECCOMP_MODE_DISABLED; 1 significa SECCOMP_MODE_STRICT; 2 significa SECCOMP_MODE_FILTER. Este campo solo se proporciona si el kernel se compiló con la opción de configuración del kernel CONFIG_SECCOMP habilitada.
Seccomp_filters
Número de filtros seccomp adjuntos al proceso (desde Linux 5.9, ver seccomp(2)).
Speculation_Store_Bypass
Estado de mitigación de la falla de especulación (desde Linux 4.17, ver prctl(2)).
Cpus_allowed
Máscara hexadecimal de CPUs en las que este proceso puede ejecutarse (desde Linux 2.6.24, ver cpuset(7)).
Cpus_allowed_list
Igual que el anterior, pero en formato de "lista" (desde Linux 2.6.26, ver cpuset(7)).
Mems_allowed
Máscara de nodos de memoria permitidos para este proceso (desde Linux 2.6.24, ver cpuset(7)).
Mems_allowed_list
Igual que el anterior, pero en formato de "lista" (desde Linux 2.6.26, ver cpuset(7)).
voluntary_ctxt_switches
nonvoluntary_ctxt_switches
Número de cambios de contexto voluntarios e involuntarios (desde Linux 2.6.23).

VER TAMBIÉN
