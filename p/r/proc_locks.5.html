proc_locks(5) Manual de formatos de archivo proc_locks(5)

NOMBRE

/proc/locks - bloqueos y arrendamientos de archivos actuales

DESCRIPCIÓN

/proc/locks
Este archivo muestra los bloqueos (flock(2) y fcntl(2)) y arrendamientos (fcntl(2)) de archivos actuales.
Un ejemplo del contenido mostrado en este archivo es el siguiente:

1: POSIX  ADVISORY  READ  5433 08:01:7864448 128 128
2: FLOCK  ADVISORY  WRITE 2001 08:01:7864554 0 EOF
3: FLOCK  ADVISORY  WRITE 1568 00:2f:32388 0 EOF
4: POSIX  ADVISORY  WRITE 699 00:16:28457 0 EOF
5: POSIX  ADVISORY  WRITE 764 00:16:21448 0 0
6: POSIX  ADVISORY  READ  3548 08:01:7867240 1 1
7: POSIX  ADVISORY  READ  3548 08:01:7865567 1826 2335
8: OFDLCK ADVISORY  WRITE -1 08:01:8713209 128 191

Los campos mostrados en cada línea son los siguientes:
[1]
La posición ordinal del bloqueo en la lista.
[2]
El tipo de bloqueo. Los valores que pueden aparecer aquí incluyen:
FLOCK
Este es un bloqueo de archivo BSD creado usando flock(2).
OFDLCK
Este es un bloqueo de descripción de archivo abierto (OFD) creado usando fcntl(2).
POSIX
Este es un bloqueo de rango de bytes POSIX creado usando fcntl(2).
[3]
Entre las cadenas que pueden aparecer aquí se encuentran las siguientes:
ADVISORY
Este es un bloqueo de asesoramiento.
MANDATORY
Este es un bloqueo obligatorio.
[4]
El tipo de bloqueo. Los valores que pueden aparecer aquí son:
READ
Este es un bloqueo de lectura POSIX u OFD, o un bloqueo compartido BSD.
WRITE
Este es un bloqueo de escritura POSIX u OFD, o un bloqueo exclusivo BSD.
[5]
El PID del proceso que posee el bloqueo.
Dado que los bloqueos OFD no son propiedad de un solo proceso (ya que múltiples procesos pueden tener descriptores de archivo que se refieren a la misma descripción de archivo abierto), el valor -1 se muestra en este campo para los bloqueos OFD. (Antes de Linux 4.14, un error provocó que se mostrara el PID del proceso que adquirió inicialmente el bloqueo en lugar del valor -1).
[6]
Tres subcampos separados por dos puntos que identifican el ID del dispositivo principal y secundario del sistema de archivos donde reside el archivo bloqueado, seguido por el número de inodo del archivo bloqueado.
[7]
El desplazamiento en bytes del primer byte del bloqueo. Para los bloqueos BSD, este valor es siempre 0.
[8]
El desplazamiento en bytes del último byte del bloqueo. EOF en este campo significa que el bloqueo se extiende hasta el final del archivo. Para los bloqueos BSD, el valor mostrado es siempre EOF.
Desde Linux 4.9, la lista de bloqueos que se muestra en /proc/locks se filtra para mostrar solo los bloqueos de los procesos en el espacio de nombres PID (ver pid_namespaces(7)) para los que se montó el sistema de archivos /proc. (En el espacio de nombres PID inicial, no hay filtrado de los registros que se muestran en este archivo).
El comando lslocks(8) proporciona un poco más de información sobre cada bloqueo.
