profil(3) Manual de funciones de biblioteca profil(3)

NOMBRE

profil - perfil de tiempo de ejecución

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
int profil(unsigned short *buf, size_t bufsiz,
           size_t offset, unsigned int scale);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

profil():

    Desde glibc 2.21:
        _DEFAULT_SOURCE
    En glibc 2.19 y 2.20:
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPCIÓN

Esta rutina proporciona un medio para averiguar en qué áreas pasa la mayor parte de su tiempo su programa. El argumento buf apunta a bufsiz bytes de memoria. Cada 10 milisegundos virtuales, se examina el contador de programa (PC) del usuario: se resta offset y el resultado se multiplica por scale y se divide por 65536. Si el valor resultante es menor que bufsiz, entonces la entrada correspondiente en buf se incrementa. Si buf es NULL, la creación de perfiles se deshabilita.

VALOR DE RETORNO

Siempre se devuelve cero.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
profil () Seguridad de hilos MT-Unsafe

ESTÁNDARES

Ninguno.

HISTORIAL

Similar a una llamada en SVr4.

ERRORES

profil() no se puede usar en un programa que también usa temporizadores de intervalo ITIMER_PROF (ver setitimer(2)).

La creación de perfiles real en el kernel proporciona resultados más precisos.

VER TAMBIÉN

gprof(1), sprof(1), setitimer(2), sigaction(2), signal(2)
