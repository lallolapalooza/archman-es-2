PRIMUSRUN(1) Manual de comandos generales PRIMUSRUN(1)

NOMBRE

primusrun - ejecuta una aplicación en una tarjeta de video NVIDIA discreta

SINOPSIS

primusrun comando

DESCRIPCIÓN

Primus implementa la descarga de OpenGL del lado del cliente con una sobrecarga baja a través de la bifurcación GLX.

Actualmente está diseñado para usarse junto con Bumblebee y proporciona un reemplazo directo para optirun (es decir, "primusrun").

VARIABLES

La siguiente es una lista de variables de entorno que afectan a la biblioteca primus y que pueden ser relevantes para los usuarios finales:

PRIMUS_SYNC
Método de sincronización de lectura y pantalla (predeterminado: 0)
0: sin sincronización, 1: sincronizado, muestra el fotograma anterior, 2: sincronizado, muestra el último fotograma
PRIMUS_VERBOSE
Nivel de verbosidad (predeterminado: 1)
0: solo errores, 1: advertencias, 2: perfilado
PRIMUS_DISPLAY
El número de pantalla del servidor Xorg secundario (predeterminado: :8)

EJEMPLOS

primusrun glxgears -info
Ejecuta la demo gráfica suministrada por mesa-utils para confirmar si la tarjeta discreta se está utilizando para la renderización GL.
PRIMUS_VERBOSE=2 primusrun glxgears
Ejecuta la demo gráfica suministrada por mesa-utils con salida detallada de primus.
vblank_mode=0 primusrun glxgears
Desactiva la sincronización vblank, utilizada típicamente con fines de benchmarking.

PROBLEMAS

Dado que la composición perjudica el rendimiento, no se recomienda invocar primus cuando un WM de composición está activo. Si necesita usar primus con composición y experimenta parpadeo o mal rendimiento, la sincronización del hilo de visualización de primus con el hilo de renderizado de la aplicación puede ayudar.

PRIMUS_SYNC=1 primusrun ...

Esto hace que primus muestre el fotograma renderizado previamente. Alternativamente, con PRIMUS_SYNC=2, primus mostrará el último fotograma renderizado, sacrificando la tasa de fotogramas por una menor latencia visual.
