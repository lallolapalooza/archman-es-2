PRG2LOUT(1) Manual de Comandos Generales PRG2LOUT(1)

NOMBRE

prg2lout - convertir texto de programas informáticos a Lout

SINOPSIS

prg2lout -l lenguaje [ opciones ] archivos...

DESCRIPCIÓN

Reformula el texto de programas informáticos para la entrada al sistema de formato de documentos Lout, ocupándose de comentarios, cadenas de caracteres, tabulaciones, etc.

prg2lout lee los archivos fuente de programas nombrados y produce una salida adecuada para la entrada a lout -s. Por lo tanto,

prg2lout -l C foo.c | lout -s | lpr

imprimirá el programa C foo.c en una impresora PostScript. Cada archivo comenzará en una nueva página, precedido por su nombre en negrita.

OPCIONES

-llenguaje
(Obligatorio.) Los archivos se escriben en este lenguaje de programación. Ejecute prg2lout -u para ver la lista de lenguajes disponibles.
-pfijo
Usa una fuente de ancho fijo (el predeterminado para C).
-pvariable
Usa una fuente cursiva de ancho variable con palabras clave en negrita no cursivas (el predeterminado para Eiffel).
-psimbolo
Usa una fuente cursiva de ancho variable con símbolos matemáticos y palabras clave en negrita no cursivas.
-n
No imprima el nombre del archivo antes de cada archivo fuente.
-f fuente
Selecciona una familia de fuentes. El predeterminado es -fCourier para -pfijo, y -fTimes para -pvariable y -psimbolo.
-s tamaño
Selecciona un tamaño de fuente Lout. El predeterminado es -s9p (significa 9 puntos) para -pfijo, y -s10p para -pvariable y -psimbolo. Estos funcionan bien con programas de 80 caracteres de ancho.
-v alturav
Selecciona un espacio vertical entre líneas de Lout. El predeterminado es -v1.1fx, lo que significa 1.1 veces el tamaño de la fuente medido de línea base a línea base.
-b num
Selecciona un factor de escala para líneas en blanco. El predeterminado es -b1.0, lo que significa sin escala. Una buena alternativa es 0.6.
-t num
Establece el intervalo de tabulación a num caracteres (el predeterminado es -t8).
-T ancho
Sin esta opción, prg2lout simula tabulaciones con espacios. Con esta opción, prg2lout simula tabulaciones con operadores de tabulación de Lout; ancho es el ancho de un intervalo de tabulación en la impresión final, medido en unidades de Lout. Esto garantiza la alineación de caracteres después de las tabulaciones incluso con fuentes de ancho variable, siempre que ancho sea suficientemente grande. Por ejemplo, -T0.5i produce intervalos de tabulación de media pulgada.
-L número
Adjunta números de línea al texto del programa, comenzando con número o 1 si no se proporciona número. Es posible que necesite proporcionar el 1 de todos modos para evitar que .I prg2lout tome un nombre de archivo posterior como un número.
-N
No imprima números de línea en líneas en blanco.
-M
Como -N pero no asigne números de línea a líneas en blanco.
-S archivo
Use archivo como archivo de configuración en lugar del archivo de configuración predeterminado del sistema. El archivo de configuración determina el valor de todas las opciones de formato no proporcionadas a prg2lout como argumentos de línea de comandos.
-u
Imprima información de uso en stderr, incluyendo los lenguajes disponibles, y salga.
-V
Imprima información de la versión en stderr y salga.

Modo Bruto

Existe un uso de "modo bruto" de prg2lout invocado por un indicador -r (debe ser el primer argumento). Esto convierte un archivo de programa en una fuente legible por Lout sin ningún encabezado ni información final. SINOPSIS:

prg2lout -r -i archivo_entrada -o salida -e error -t num -T ancho

Los usuarios nunca deberían necesitar este modo; se invoca automáticamente desde Lout mediante símbolos proporcionados con la configuración estándar (ver referencia).

VER TAMBIÉN

lout(1), lpr(1), ghostview(1).

REFERENCIAS

Jeffrey H. Kingston, “A User's Guide to the Lout Document Formatting System”, Chapter 11.
