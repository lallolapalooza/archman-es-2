NOMBRE

/proc/sysrq-trigger - Función SysRq

DESCRIPCIÓN

/proc/sysrq-trigger (desde Linux 2.4.21)
Escribir un carácter en este archivo activa la misma función SysRq que escribir ALT-SysRq-<carácter> (ver la descripción de /proc/sys/kernel/sysrq). Este archivo normalmente solo es escribible por root. Para más detalles, ver el archivo fuente del kernel de Linux Documentation/admin-guide/sysrq.rst (o Documentation/sysrq.txt antes de Linux 4.10).
