profanity-log(1)

Paquete: profanity-gtk

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/log

DESCRIPCIÓN

Gestiona la configuración de registro de profanity.

SINOPSIS

/log where

/log rotate on|off

/log maxsize <bytes>

/log shared on|off

/log level INFO|DEBUG|WARN|ERROR

ARGUMENTOS

where

Muestra la ubicación actual del archivo de registro.

rotate on|off

Rota el registro, por defecto está activado. No tiene efecto si especificaste un nombre de archivo tú mismo al iniciar Profanity.

maxsize <bytes>

Con la rotación activada, especifica el tamaño máximo del registro, por defecto es 10485760 (10 MB).

shared on|off

Comparte los registros entre todas las instancias, por defecto: activado. Cuando está desactivado, el ID del proceso se incluirá en el nombre del archivo de registro. No tiene efecto si especificaste un nombre de archivo tú mismo al iniciar Profanity.

level INFO|DEBUG|WARN|ERROR

Establece el nivel de registro. El valor predeterminado es INFO. Solo funciona con el archivo de registro predeterminado, no con un archivo de registro proporcionado por el usuario al inicio a través de -f.
