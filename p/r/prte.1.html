PRTE(1) Entorno de Ejecución de Referencia PMIx PRTE(1)

prte — instancia de PRRTE DVM

SINOPSIS

shell$ prte ...opciones...

DESCRIPCIÓN

prte instancia un ejemplo del entorno de ejecución de referencia (PRRTE) de PMIx, una máquina virtual distribuida (DVM).

Se proporciona documentación de ayuda exhaustiva para este comando a través de prte --help [tema].

Por ahora, ese contenido no está disponible en formato de página del manual. Las solicitudes de extracción (pull requests) para agregar todo el contenido (a través de infraestructura repetible) serían muy apreciadas.
