PRINTENV(1) Comandos de usuario PRINTENV(1)

NOMBRE

printenv - imprime todo o parte del entorno

SINOPSIS

printenv [OPCIÓN] [VARIABLE]...

DESCRIPCIÓN

Imprime los valores de las Variables de entorno especificadas. Si no se especifica ninguna VARIABLE, imprime pares de nombre y valor para todas ellas.

-0, --null
termina cada línea de salida con NUL, no con nueva línea
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

Es posible que tu shell tenga su propia versión de printenv, que generalmente reemplaza a la versión aquí descrita. Consulta la documentación de tu shell para obtener detalles sobre las opciones que admite.
