PROCS(1) Comandos de usuario PROCS(1)

NOMBRE

procs - un reemplazo para `ps` escrito en Rust

SINOPSIS

procs [OPCIONES] [PALABRAS_CLAVE]

DESCRIPCIÓN

procs es una herramienta de línea de comandos que proporciona una alternativa al comando ps.

OPCIONES

--and

Muestra los procesos que coinciden con todas las palabras clave.

--or

Muestra los procesos que coinciden con alguna palabra clave.

--nand

Oculta los procesos que coinciden con todas las palabras clave.

--nor

Oculta los procesos que coinciden con alguna palabra clave.

--watch

Habilita el modo de observación para actualizaciones en tiempo real.

--watch-interval <segundo>

Establece el intervalo de actualización para el modo de observación.

--tree

Muestra los procesos en vista de árbol.

--sorta <columna>

Ordena los procesos en orden ascendente por la columna especificada.

--sortd <columna>

Ordena los procesos en orden descendente por la columna especificada.

--insert <columna>

Inserta una nueva columna en la posición de Slot o MultiSlot.

--gen-completion

Genera archivos de completado para shells compatibles.

EJEMPLOS

Mostrar todos los procesos

procs

Buscar por palabra clave no numérica

procs zsh

Buscar por palabra clave numérica

procs --or 6000 60000 60001 16723

Mostrar el nombre del contenedor de Docker

procs growi

PAGINADOR

En Linux y macOS, less es el paginador predeterminado. Si no está disponible, se utiliza more. Se puede usar el paginador incorporado configurando use_builtin. En Windows, siempre se utiliza el paginador incorporado.

ATAJOS DEL MODO OBSERVACIÓN

Si se utiliza la opción --watch o --watch-interval <segundo>, procs actualiza automáticamente la salida como top. Hay atajos de teclado disponibles para el control.

n

Cambia la columna de ordenación a la siguiente columna.

p

Cambia la columna de ordenación a la anterior.

a

Cambia el orden de ordenación a ascendente.

d

Cambia el orden de ordenación a descendente.

q

Salir.
