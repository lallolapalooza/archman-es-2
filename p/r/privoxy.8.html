NOMBRE

privoxy - Proxy para mejorar la privacidad

SINOPSIS

privoxy [--chroot ] [--config-test ] [--help ] [--no-daemon ] [--pidfile archivo_pid ] [--pre-chroot-nslookup nombre_host ] [--user usuario[.grupo] ] [--version ] [archivo_config ]

OPCIONES

Privoxy puede ser invocado con las siguientes opciones de línea de comandos:

--chroot
Antes de cambiar al ID de usuario dado en la opción --user, haz chroot al directorio personal de ese usuario, es decir, haz que el kernel finja para el proceso Privoxy que el árbol de directorios comienza allí. Si se configura cuidadosamente, esto puede limitar el impacto de posibles vulnerabilidades en Privoxy a los archivos contenidos en esa jerarquía.
--config-test
Salir después de cargar los archivos de configuración antes de vincularse a la dirección de escucha. El código de salida indica si los archivos de configuración se han cargado correctamente o no.

Si el código de salida es 1, al menos uno de los archivos de configuración es inválido; si es 0, todos los archivos de configuración se han cargado correctamente (pero aún pueden contener errores que actualmente solo se pueden detectar en tiempo de ejecución).

Esta opción no afecta la configuración del registro; se recomienda combinarla con "--no-daemon" si no se debe usar un archivo de registro configurado.

--help
Imprimir información breve de uso y salir.
--no-daemon
No convertirse en un demonio, es decir, no hacer fork ni convertirse en líder del grupo de procesos, no separarse del tty de control y realizar todo el registro allí.
--pidfile archivo_pid
Al iniciar, escribir el ID del proceso en archivo_pid. Eliminar el archivo_pid al salir. El fallo al crear o eliminar el archivo_pid no es fatal. Si no se proporciona la opción --pidfile, no se utilizará ningún archivo PID.
--pre-chroot-nslookup nombre_host
Inicializar la biblioteca del resolvedor usando nombre_host antes de hacer chroot. En algunos sistemas, esto reduce la cantidad de archivos que deben copiarse en el árbol de chroot.
--user usuario[.grupo]
Después de (opcionalmente) escribir el archivo PID, asumir el ID de usuario de usuario y el GID de grupo, o, si no se proporcionó grupo opcional, el grupo predeterminado de usuario. Salir si los privilegios no son suficientes para hacerlo.
--version
Imprimir información de la versión y salir.

Si no se especifica el archivo_config en la línea de comandos, Privoxy buscará un archivo llamado config en el directorio actual. Si no se encuentra ningún archivo_config, Privoxy fallará al iniciar.

DESCRIPCIÓN

Privoxy es un proxy web sin caché con capacidades avanzadas de filtrado para mejorar la privacidad, modificar datos de páginas web y encabezados HTTP, controlar el acceso y eliminar anuncios y otra basura molesta de Internet. Privoxy tiene una configuración flexible y puede personalizarse para adaptarse a las necesidades y gustos individuales. Tiene aplicaciones tanto para sistemas independientes como para redes de múltiples usuarios.

Privoxy es Software Libre y se distribuye bajo la GNU GPLv2 o posterior.

INSTALACIÓN Y USO

Los navegadores pueden configurarse individualmente para usar Privoxy como proxy HTTP (recomendado), o Privoxy puede combinarse con un filtro de paquetes para construir un proxy de interceptación (ver config). La configuración predeterminada es para localhost, en el puerto 8118 (configurable en el archivo de configuración principal). Para configurar el proxy HTTP en Firefox, ve a: Herramientas; Opciones; General; Configuración de conexión; Configuración manual del proxy.

Para Internet Explorer, ve a: Herramientas; Opciones de Internet; Conexiones; Configuración de LAN.

El proxy seguro (SSL) también debe configurarse con los mismos valores, de lo contrario, las URL https: no se proxearán. Nota: Privoxy solo puede proxear tráfico HTTP y HTTPS. No intentes usarlo con FTP u otros protocolos. HTTPS presenta algunas limitaciones y no todas las funciones funcionarán con conexiones HTTPS.

Para otros navegadores, consulta la documentación.

CONFIGURACIÓN

Privoxy puede configurarse con varios archivos de configuración. Los archivos de configuración predeterminados son: config, default.filter, default.action y default.action. Se debe usar user.action para excepciones definidas localmente a las reglas predeterminadas en match-all.action y default.action, y user.filter para filtros definidos localmente. Estos están bien comentados. En sistemas Unix y similares a Unix, se encuentran en /etc/privoxy/ por defecto.

Privoxy utiliza el concepto de acciones para manipular el flujo de datos entre el navegador y los sitios remotos. Hay varias acciones disponibles con funciones específicas para cosas como bloquear sitios web, administrar cookies, etc. Estas acciones se pueden invocar individualmente o combinadas, y se pueden usar contra URL individuales o grupos de URL que se pueden definir usando comodines y expresiones regulares. El resultado es que el usuario tiene un control y una libertad enormemente mejorados.

La lista de acciones (bloqueos de anuncios, etc.) también se puede configurar con tu navegador web en http://config.privoxy.org/ (asumiendo que la configuración lo permite). Los parámetros de configuración de Privoxy también se pueden ver en la misma página. Además, Privoxy se puede activar/desactivar. Esta es una página interna y no requiere acceso a Internet.

Consulta el Manual del usuario para una explicación detallada de la instalación, el uso general, todas las opciones de configuración, las nuevas funciones y las notas sobre la actualización.

SEÑALES

Privoxy termina con las señales SIGINT y SIGTERM. Los scripts de rotación de registros pueden hacer que se reabra el archivo de registro enviando una SIGHUP a Privoxy. Ten en cuenta que, a diferencia de otros demonios, Privoxy no necesita ser informado de los cambios en el archivo de configuración mediante SIGHUP; los detectará automáticamente. Las señales distintas de las enumeradas anteriormente no se manejan explícitamente y dan como resultado la acción predeterminada definida por el sistema operativo.
