Paquete: coreutils

PRINTF(1) Comandos de usuario PRINTF(1)

NOMBRE

printf - formatea e imprime datos

SINOPSIS

printf FORMATO [ARGUMENTO]...
printf OPCIÓN

DESCRIPCIÓN

Imprime ARGUMENTO(s) según FORMATO, o ejecuta según OPCIÓN:

--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

FORMATO controla la salida como en printf de C. Las secuencias interpretadas son:

\"
comillas dobles
\\
barra invertida
\a
alerta (BEL)
\b
retroceso (backspace)
\c
no produce más salida
\e
escape
\f
salto de página (form feed)
\n
nueva línea
\r
retorno de carro
\t
tabulación horizontal
\v
tabulación vertical
\NNN
byte con valor octal NNN (1 a 3 dígitos)
\xHH
byte con valor hexadecimal HH (1 a 2 dígitos)
\uHHHH
carácter Unicode (ISO/IEC 10646) con valor hexadecimal HHHH (4 dígitos)
\UHHHHHHHH
carácter Unicode con valor hexadecimal HHHHHHHH (8 dígitos)
%%
un único %
%b
ARGUMENTO como una cadena con escapes '\' interpretados, excepto que los escapes octales deben tener un 0 inicial como \0NNN
%q
ARGUMENTO se imprime en un formato que puede ser reutilizado como entrada del shell, escapando caracteres no imprimibles con la sintaxis POSIX $''

y todas las especificaciones de formato C que terminan con uno de diouxXfeEgGcs, con los ARGUMENTOs convertidos al tipo adecuado primero. Se manejan anchos variables.

Tu shell puede tener su propia versión de printf, que generalmente reemplaza a la versión descrita aquí. Consulta la documentación de tu shell para obtener detalles sobre las opciones que admite.
