NOMBRE

/proc/vmstat - estadísticas de memoria virtual

DESCRIPCIÓN

/proc/vmstat (desde Linux 2.6.0)
Este archivo muestra varias estadísticas de memoria virtual. Cada línea de este archivo contiene un único par nombre-valor, delimitado por espacios en blanco. Algunas líneas solo están presentes si el kernel se configuró con las opciones adecuadas. (En algunos casos, las opciones requeridas para archivos particulares han cambiado entre versiones del kernel, por lo que no se enumeran aquí. Los detalles se pueden encontrar consultando el código fuente del kernel.) Los siguientes campos pueden estar presentes:

proc_vmstat(5)

Linux Manual Pages

NOMBRE

proc_vmstat - información sobre el uso de memoria virtual en el proceso /proc/[pid]/statm

DESCRIPCIÓN

Este archivo es parte del subsistema procfs y se puede encontrar en el directorio `/proc`. Contiene una línea de texto con varios campos numéricos que describen el uso de memoria virtual por un proceso específico.

Los campos son los siguientes:

size
Tamaño total de memoria virtual asignada al proceso, en páginas.
resident
Tamaño del conjunto residente (memoria física real utilizada por el proceso), en páginas.
share
Tamaño del conjunto compartido (memoria compartida entre procesos), en páginas.
text
Tamaño del segmento de código (texto), en páginas.
lib
Tamaño de las bibliotecas en memoria, en páginas (este campo está obsoleto y generalmente es 0).
data
Tamaño del segmento de datos y pila, en páginas.
dt
Tamaño del segmento de datos y pila para el hilo actual. Este campo es similar a 'data' pero específico del hilo.

Todos los valores se expresan en páginas de memoria. El tamaño de una página depende de la arquitectura del sistema (por ejemplo, 4 KB en sistemas x86).
