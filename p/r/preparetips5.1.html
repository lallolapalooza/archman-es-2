NOMBRE

preparetips5
- extraer texto de un archivo de consejos

SINOPSIS

preparetips5

DESCRIPCIÓN

preparetips5 es un script para extraer el texto de un archivo de consejos (tips file). Produce el texto para que xgettext pueda añadir los consejos a un archivo PO. Los archivos PO proporcionan un formato de cadena legible por humanos utilizado para traducciones.

preparetips5 busca el archivo de consejos en data/tips.
