NOMBRE

/vcard

DESCRIPCIÓN

Lee tu vCard o la vCard de un usuario, obtén el avatar de un usuario a través de su vCard, o modifica tu vCard. Si no se proporcionan argumentos, tu vCard se mostrará en una nueva ventana, o en una ventana de vCard existente.

SINOPSIS

/vcard photo open <apodo|contacto> [<índice>]

/vcard photo save <apodo|contacto> [output <ruta_archivo>] [index <índice>]

ARGUMENTOS

get [<apodo|contacto>]

Obtiene tu vCard, si se proporciona un apodo/contacto, obtiene la vCard de ese usuario.

photo open <apodo|contacto> [<índice>]

Descarga la foto de un usuario desde su vCard a un archivo y la abre. Si no se especifica el índice, descarga la primera foto (generalmente el avatar) de su vCard.

photo save <apodo|contacto>

Descarga la foto de un usuario desde su vCard a un archivo. Si no se especifica el índice, descarga la primera foto (generalmente el avatar) de su vCard. Si no se especifica la salida, descarga la foto al directorio de fotos de Profanity.

photo open-self [<índice>]

Descarga una foto de tu vCard a un archivo y la abre. Si no se especifica el índice, descarga la primera foto (generalmente el avatar) de tu vCard.

photo save-self

Descarga una foto de tu vCard a un archivo. Si no se especifica el índice, descarga la primera foto (generalmente el avatar) de tu vCard. Si no se especifica la salida, descarga la foto al directorio de fotos de Profanity. Mismos argumentos que `photo open`.

set fullname <nombre_completo>

Establece el nombre completo de tu vCard al valor especificado.

set name family <apellido>

Establece el apellido de tu vCard al valor especificado.

set name given <nombre_propio>

Establece el nombre propio de tu vCard al valor especificado.

set name middle <segundo_nombre>

Establece el segundo nombre de tu vCard al valor especificado.

set name prefix <prefijo>

Establece el prefijo de tu vCard al valor especificado.

set name suffix <sufijo>

Establece el sufijo de tu vCard al valor especificado.

set <índice> [<valor>]

Establece el campo principal en un elemento de tu vCard al valor especificado, o si no se especificó ningún valor, modifica el campo en un editor. Esto solo funciona en elementos que tienen un solo campo.

set <índice> pobox <valor>

Establece el apartado postal (P.O. box) en un elemento de dirección de tu vCard al valor especificado.

set <índice> extaddr <valor>

Establece la dirección extendida en un elemento de dirección de tu vCard al valor especificado.

set <índice> street <valor>

Establece la calle en un elemento de dirección de tu vCard al valor especificado.

set <índice> locality <valor>

Establece la localidad en un elemento de dirección de tu vCard al valor especificado.

set <índice> region <valor>

Establece la región en un elemento de dirección de tu vCard al valor especificado.

set <índice> pocode <valor>

Establece el código postal en un elemento de dirección de tu vCard al valor especificado.

set <índice> type domestic|international

Establece el tipo en un elemento de dirección de tu vCard a `domestic` o `international`.

set <índice> home on|off

Establece la opción `home` en un elemento de tu vCard. (solo direcciones, teléfonos, correos electrónicos)

set <índice> work on|off
