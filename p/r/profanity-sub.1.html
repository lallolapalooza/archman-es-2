profanity-sub(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/sub

DESCRIPCIÓN

Gestiona las suscripciones a la presencia de contactos. Si se omite el jid, se utiliza el contacto de la ventana actual.

SINOPSIS

/sub request [<jid>]

/sub allow [<jid>]

/sub deny [<jid>]

/sub show [<jid>]

/sub sent

/sub received

ARGUMENTOS

request [<jid>]

Envía una solicitud de suscripción al usuario.

allow [<jid>]

Aprueba una solicitud de suscripción de un contacto.

deny [<jid>]

Elimina la suscripción de un contacto o deniega una solicitud.

show [<jid>]

Muestra el estado de la suscripción de un contacto.

sent

Muestra todas las solicitudes de suscripción enviadas que esperan una respuesta.

received

Muestra todas las solicitudes de suscripción recibidas que esperan tu respuesta.

EJEMPLOS

/sub request odin@valhalla.edda

/sub allow odin@valhalla.edda

/sub request

/sub sent
