proc_pid_task(5) Manual de Formatos de Archivo proc_pid_task(5)

NOMBRE

/proc/pid/task/, /proc/tid/, /proc/thread-self/ - información de hilos

DESCRIPCIÓN

/proc/pid/task/ (desde Linux 2.6.0)
Este es un directorio que contiene un subdirectorio por cada hilo en el proceso. El nombre de cada subdirectorio es el ID numérico del hilo (tid) del hilo (ver gettid(2)).
Dentro de cada uno de estos subdirectorios, hay un conjunto de archivos con los mismos nombres y contenidos que bajo los directorios de /proc/pid. Para atributos que son compartidos por todos los hilos, el contenido de cada uno de los archivos bajo los subdirectorios task/tid será el mismo que en el archivo correspondiente en el directorio padre /proc/pid (por ejemplo, en un proceso multihilo, todos los archivos task/tid/cwd tendrán el mismo valor que el archivo /proc/pid/cwd en el directorio padre, ya que todos los hilos en un proceso comparten un directorio de trabajo). Para atributos que son distintos para cada hilo, los archivos correspondientes bajo task/tid pueden tener valores diferentes (por ejemplo, varios campos en cada uno de los archivos task/tid/status pueden ser diferentes para cada hilo), o podrían no existir en /proc/pid en absoluto.
En un proceso multihilo, el contenido del directorio /proc/pid/task no está disponible si el hilo principal ya ha terminado (típicamente llamando a pthread_exit(3)).
/proc/tid/
Hay un subdirectorio numérico por cada hilo en ejecución que no es un líder de grupo de hilos (es decir, un hilo cuyo ID de hilo no es el mismo que su ID de proceso); el subdirectorio se llama por el ID del hilo. Cada uno de estos subdirectorios contiene archivos y subdirectorios que exponen información sobre el hilo con el ID de hilo tid. El contenido de estos directorios es el mismo que el de los directorios /proc/pid/task/tid correspondientes.
Los subdirectorios /proc/tid *no* son visibles al iterar a través de /proc con getdents(2) (y por lo tanto *no* son visibles cuando se usa ls(1) para ver el contenido de /proc). Sin embargo, las rutas de estos directorios son visibles para (es decir, utilizables como argumentos en) las llamadas al sistema que operan sobre rutas.
/proc/thread-self/ (desde Linux 3.17)
Este directorio se refiere al hilo que accede al sistema de archivos /proc, y es idéntico al directorio /proc/self/task/tid nombrado por el ID de hilo del proceso (tid) del mismo hilo.
