PTERM(1) Entorno de ejecución en tiempo de ejecución de referencia PMIx PTERM(1)

pterm — termina una instancia de DVM de PRRTE

SINOPSIS

shell$ pterm ...opciones...

DESCRIPCIÓN

pterm termina una instancia de la Máquina Virtual Distribuida (DVM) del Entorno de Ejecución de Referencia de PMIx (PRRTE).

Se proporciona una extensa documentación de ayuda para este comando a través de pterm --help [tema].

Por ahora, ese contenido no está disponible en formato de página de manual. Las solicitudes de extracción para agregar todo el contenido (a través de infraestructura repetible) serían muy apreciadas.
