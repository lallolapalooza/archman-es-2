NOMBRE

/time

DESCRIPCIÓN

Configura las preferencias de visualización de la hora. Los formatos de hora son cadenas compatibles con g_date_time_format. Consulte https://developer.gnome.org/glib/stable/glib-GDateTime.html#g-date-time-format para obtener más detalles. Si se establece el formato en una cadena no admitida, se mostrará la cadena. Si el formato contiene espacios, debe ir entre comillas dobles. Es posible pasar el formato como 'iso8601' para establecer el formato de hora según ISO-8601 (solo hora local, sin el designador de zona horaria).

SINOPSIS

/time all|console|chat|muc|config|private|xml set <formato>

/time all|console|chat|muc|config|private|xml off

/time statusbar set <formato>

/time statusbar off

/time lastactivity set <formato>

/time vcard set <formato>

ARGUMENTOS

console set <formato>

Establece el formato de hora para la ventana de consola.

console off

No mostrar la hora en la ventana de consola.

chat set <formato>

Establece el formato de hora para las ventanas de chat.

chat off

No mostrar la hora en las ventanas de chat.

muc set <formato>

Establece el formato de hora para las ventanas de salas de chat.

muc off

No mostrar la hora en las ventanas de salas de chat.

config set <formato>

Establece el formato de hora para las ventanas de configuración.

config off

No mostrar la hora en las ventanas de configuración.

private set <formato>

Establece el formato de hora para las ventanas de chat privado.

private off

No mostrar la hora en las ventanas de chat privado.

xml set <formato>

Establece el formato de hora para la ventana de consola XML.

xml off

No mostrar la hora en la ventana de consola XML.

statusbar set <formato>

Cambia el formato de hora en la barra de estado.

statusbar off

No mostrar la hora en la barra de estado.

lastactivity set <formato>

Cambia el formato de hora para la última actividad.

vcard set <formato>

Cambia el formato de hora utilizado para mostrar la hora/fechas en vCard (como cumpleaños).

all set <formato>

Establece la hora para: ventanas de consola, chat, muc, config, privada y xml.

all off

No mostrar la hora para: ventanas de consola, chat, muc, config, privada y xml.

EJEMPLOS

/time console set %H:%M:%S

/time chat set "%d-%m-%y %H:%M:%S"

/time xml off

/time statusbar set %H:%M

/time lastactivity set "%d-%m-%y %H:%M:%S"

/time all set "%d-%m-%y %H:%M:%S"

/time all set iso8601
