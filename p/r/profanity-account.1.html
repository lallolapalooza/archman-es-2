NOMBRE

/account

DESCRIPCIÓN

Comandos para crear y administrar cuentas. Llamar sin argumentos mostrará información de la cuenta actual.

SINOPSIS

/account

/account list

/account show <cuenta>

/account enable|disable <cuenta>

/account default set <cuenta>

/account default off

/account add <cuenta>

/account remove <cuenta>

/account rename <cuenta> <nuevacuenta>

/account set <cuenta> jid <jid>

/account set <cuenta> server <servidor>

/account set <cuenta> port <puerto>

/account set <cuenta> status <presencia>

/account set <cuenta> status last

/account set <cuenta> <presencia> <prioridad>

/account set <cuenta> resource <recurso>

/account set <cuenta> password <contraseña>

/account set <cuenta> eval_password <comando>

/account set <cuenta> muc <servicio>

/account set <cuenta> nick <apodo>

/account set <cuenta> otr <política>

/account set <cuenta> pgpkeyid <pgpkeyid>

/account set <cuenta> startscript <script>

/account set <cuenta> clientid "<nombre> <versión>"

/account set <cuenta> tls force|allow|trust|legacy|disable

/account set <cuenta> auth default|legacy

/account set <cuenta> theme <tema>

/account set <cuenta> session_alarm <max_sessions>

/account clear <cuenta> password

/account clear <cuenta> eval_password

/account clear <cuenta> server

/account clear <cuenta> port

/account clear <cuenta> otr

/account clear <cuenta> pgpkeyid

/account clear <cuenta> startscript

/account clear <cuenta> clientid

/account clear <cuenta> muc

/account clear <cuenta> resource

/account clear <cuenta> session_alarm

ARGUMENTOS

list

Lista todas las cuentas.

enable <cuenta>

Habilita la cuenta, se usará para autocompletado.

show <cuenta>

Muestra los detalles de la cuenta especificada.

disable <cuenta>

Deshabilita la cuenta.

default set <cuenta>

Establece la cuenta por defecto, utilizada cuando no se pasa ningún argumento al comando /connect.

default off

Borra la configuración de cuenta por defecto.

add <cuenta>

Crea una nueva cuenta.

remove <cuenta>

Elimina una cuenta.

rename <cuenta> <nuevacuenta>

Renombra 'cuenta' a 'nuevacuenta'.

set <cuenta> jid <jid>

Establece el Jabber ID para la cuenta, se usará el nombre de la cuenta si no está configurado.

set <cuenta> server <servidor>

El servidor de chat, si es diferente a la parte del dominio del JID.

set <cuenta> port <puerto>

El puerto utilizado para la conexión si no es el predeterminado (5222, o 5223 para SSL).

set <cuenta> status <presencia>

El estado de presencia a usar al iniciar sesión.

set <cuenta> status last

Utiliza tu último estado antes de desconectarte, al iniciar sesión.

set <cuenta> <presencia> <prioridad>

Establece la prioridad (-128..127) a usar para la presencia especificada.

set <cuenta> resource <recurso>

El recurso a utilizar para esta cuenta, por defecto es 'profanity'.

set <cuenta> password <contraseña>

Contraseña para la cuenta, ten en cuenta que actualmente se almacena en texto plano si se establece.

set <cuenta> eval_password <comando>

Comando de shell evaluado para obtener la contraseña de la cuenta. Puede usarse para obtener la contraseña del llavero.

set <cuenta> muc <servicio>

El servicio de chat MUC por defecto a utilizar, se obtiene de la respuesta de información disco del servidor.

set <cuenta> nick <apodo>

El apodo por defecto a utilizar al unirse a salas de chat.

set <cuenta> otr <política>

Anula la política OTR global para esta cuenta, ver /otr.

set <cuenta> pgpkeyid <pgpkeyid>

Establece el ID de la clave PGP para esta cuenta, ver /pgp.

set <cuenta> startscript <script>

Establece el script a ejecutar después de conectarse.

set <cuenta> clientid "<nombre> <versión>"

Establece el nombre del cliente XMPP para el descubrimiento según XEP-0092. Para expertos en privacidad. Se recomienda dejarlo como está.

set <cuenta> tls force

Fuerza la conexión TLS, y falla si no se puede establecer, este es el comportamiento por defecto.

set <cuenta> tls allow

Usa TLS para la conexión si está disponible.

set <cuenta> tls trust

Fuerza la conexión TLS y confía en el certificado del servidor.

set <cuenta> tls legacy

Usa TLS heredado para la conexión. Significa que el servidor no soporta STARTTLS y TLS se fuerza justo después de establecer la conexión TCP.

set <cuenta> tls disable

Deshabilita TLS para la conexión.

set <cuenta> auth default

Usa el proceso de autenticación por defecto.

set <cuenta> auth legacy

Permite la autenticación heredada.

set <cuenta> theme <tema>

Establece el tema de la interfaz de usuario para la cuenta.

set <cuenta> session_alarm <max_sessions>

Alarma sobre actividad sospechosa si el número de sesiones supera max_sessions.

clear <cuenta> server

Elimina la configuración del servidor para esta cuenta.

clear <cuenta> port

Elimina la configuración del puerto para esta cuenta.

clear <cuenta> password

Elimina la configuración de la contraseña para esta cuenta.

clear <cuenta> eval_password

Elimina la configuración de eval_password para esta cuenta.

clear <cuenta> otr

Elimina la configuración de la política OTR para esta cuenta.

clear <cuenta> pgpkeyid

Elimina el pgpkeyid asociado con esta cuenta.

clear <cuenta> startscript

Elimina el startscript asociado con esta cuenta.

clear <cuenta> clientid

Restablece el nombre del cliente a su valor por defecto.

clear <cuenta> theme

Borra la configuración del tema para la cuenta, se utilizará el tema global.

clear <cuenta> resource

Elimina la configuración del recurso para esta cuenta.

clear <cuenta> muc

Elimina la configuración del servicio MUC por defecto.

clear <cuenta> session_alarm

Deshabilita la alarma de sesión.

EJEMPLOS

/account add me

/account set me jid ulfhednar@valhalla.edda

/account set me server talk.chat.com

/account set me port 5111

/account set me muc chatservice.mycompany.com

NAME

profanity-account - manage accounts

DESCRIPTION

Manages accounts.

SYNOPSIS

/account [command] [arguments]

ARGUMENTS

me
Specifies that the current account should be modified.
set
Sets a property of the account.
nick
Sets the nick of the account.
status
Sets the status of the account (online, away, dnd, etc.).
dnd
Sets the Do Not Disturb message of the account.
clientid
Sets the client ID of the account.
rename
Renames the account.
clear
Clears a property of the account.
pgpkeyid
Clears the PGP key ID of the account.

EXAMPLES

Set the account nick to dennis:

/account set me nick dennis

Set the account status to do not disturb:

/account set me status dnd

Clear the do not disturb message:

/account set me dnd -1

Set the client ID to "Profanity 0.42 (Dev)":

/account set me clientid "Profanity 0.42 (Dev)"

Rename the account to chattyme:

/account rename me chattyme

Clear the PGP key ID:

/account clear me pgpkeyid
