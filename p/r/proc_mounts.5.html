proc_pid_mounts(5) Manual de formatos de archivo proc_pid_mounts(5)

NOMBRE

proc_pid_mounts(5) - montajes de sistemas de archivos

DESCRIPCIÓN

/proc/pid/mounts (desde Linux 2.4.19)
Este archivo lista todos los sistemas de archivos montados actualmente en el espacio de nombres de montaje del proceso (ver mount_namespaces(7)). El formato de este archivo se documenta en fstab(5).
Desde Linux 2.6.15, este archivo se puede sondear: después de abrir el archivo para lectura, un cambio en este archivo (es decir, el montaje o desmontaje de un sistema de archivos) hace que select(2) marque el descriptor de archivo como con una condición excepcional, y poll(2) y epoll_wait(2) marcan el archivo como con un evento de prioridad (POLLPRI). (Antes de Linux 2.6.30, un cambio en este archivo se indicaba marcando el descriptor de archivo como legible para select(2), y marcándolo como con una condición de error para poll(2) y epoll_wait(2).)
/proc/mounts
Antes de Linux 2.4.19, este archivo era una lista de todos los sistemas de archivos montados actualmente en el sistema. Con la introducción de espacios de nombres de montaje por proceso en Linux 2.4.19 (ver mount_namespaces(7)), este archivo se convirtió en un enlace a /proc/self/mounts, que lista los montajes del propio espacio de nombres de montaje del proceso. El formato de este archivo se documenta en fstab(5).
