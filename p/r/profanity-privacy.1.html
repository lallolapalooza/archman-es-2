profanity-privacy(1)

Paquete: profanity

Licencias: GPL3

man(1) Cliente XMPP Profanity man(1)

NOMBRE

/privacy

DESCRIPCIÓN

Configura los ajustes de privacidad. También revisa los siguientes ajustes en /account: clientid para establecer el nombre de identificación del cliente session_alarm para configurar una alarma cuando se conecten más clientes.

SINOPSIS

/privacy logging on|redact|off

/privacy os on|off

ARGUMENTOS

logging on|redact|off

Activa/desactiva el registro de chats. Esto también deshabilitará el registro en la base de datos SQL utilizada internamente. Tus mensajes no se guardarán en ningún lugar localmente. Esto podría tener consecuencias imprevistas, como no poder descifrar mensajes cifrados con OMEMO recibidos más tarde a través de MAM, y debe usarse con precaución.

os on|off

Elige si incluir el nombre del sistema operativo si un usuario solicita información del software (XEP-0092).

EJEMPLOS

/privacy logging off

/privacy os off
