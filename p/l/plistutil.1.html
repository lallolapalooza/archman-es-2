NOMBRE

plistutil - Convierte un ARCHIVO plist entre formatos binario, XML y JSON

SINOPSIS

plistutil [OPCIONES] [-i ARCHIVO] [-o ARCHIVO]

DESCRIPCIÓN

plistutil permite convertir un archivo de Lista de Propiedades entre formatos binario, XML y JSON.

OPCIONES

-i, --infile ARCHIVO
ARCHIVO de entrada para convertir. Si se omite este argumento o se pasa - como nombre de archivo, plistutil leerá desde stdin.
-o, --outfile ARCHIVO
ARCHIVO de salida para convertir. Si se omite este argumento o se pasa - como nombre de archivo, plistutil escribirá en stdout.
-f, --format [bin|xml|json|openstep]
Fuerza el formato de salida, independientemente del tipo de entrada. Esto es útil si el formato de entrada no se conoce, pero se desea que el formato de salida esté siempre en un formato específico (como xml o json).

Si se omite, los datos plist XML se convertirán a binario y viceversa. Para convertir a/desde JSON u OpenStep, se debe especificar el formato de salida.

-p, --print ARCHIVO
Imprime PList en formato legible para humanos.
-c, --compact
Solo JSON y OpenStep: Imprime la salida en formato compacto. Por defecto, la salida estará formateada de forma legible.
-s, --sort
Ordena todos los nodos de diccionario lexicográficamente por clave antes de convertir al formato de salida.
-h, --help
Imprime la información de uso.
-d, --debug
Habilita la salida de depuración extendida.
-v, --version
Imprime la información de la versión.

EJEMPLOS

plistutil -i test.plist -o out.plist
Convierte test.plist y escribe en out.plist. Si test.plist está en formato XML, out.plist estará en formato binario. Si test.plist está en formato binario, out.plist estará en formato XML.
plistutil -i test.plist -o out.plist -f bin
Igual que antes, pero la salida siempre estará en formato binario.
plistutil -i test.plist -f xml
Imprime test.plist como plist XML, independientemente del formato de entrada.
plistutil -i test.plist -f xml -o -
Igual que antes.
plistutil -i test.plist -f json
Imprime test.plist como plist JSON, independientemente del formato de entrada.
cat test.plist |plistutil -f xml
Toma datos plist de la entrada estándar - canalizados a través de cat - y escribe la salida como XML a la salida estándar.
