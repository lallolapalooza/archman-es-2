int LIBMTP_Create_New_Playlist (LIBMTP_mtpdevice_t * device, LIBMTP_playlist_t *const metadata)

Esta rutina crea una nueva lista de reproducción basada en los metadatos suministrados. Si el campo de pistas de los metadatos contiene una lista de pistas, estas pistas se añadirán a la lista de reproducción.

Parámetros

device un puntero al dispositivo en el que crear la nueva lista de reproducción.
metadata los metadatos para la nueva lista de reproducción. Si la función sale con éxito, el campo playlist_id de esta estructura contendrá el nuevo ID de lista de reproducción.
  • metadata->parent_id debe establecerse en el padre (por ejemplo, carpeta) donde almacenar esta pista. Dado que algunos dispositivos son un poco quisquillosos con la ubicación de los archivos, se elegirá una carpeta predeterminada si libmtp ha detectado una para el tipo de archivo actual y este parámetro se establece en 0. Si esto es 0 y no se encuentra ninguna carpeta predeterminada, el archivo se almacenará en la carpeta raíz.
  • metadata->storage_id debe establecerse en el almacenamiento deseado (por ejemplo, tarjeta de memoria o lo que sea que presente su dispositivo) donde almacenar esta pista. Establecer esto en 0 almacenará la pista en el almacenamiento principal.

Retorna

0 si tiene éxito, cualquier otro valor significa fallo.

void LIBMTP_destroy_playlist_t (LIBMTP_playlist_t * playlist)

Esto destruye una estructura de metadatos de lista de reproducción y libera la memoria utilizada por ella, incluidas las cadenas de texto. Nunca vuelva a utilizar una estructura de metadatos de pista después de llamar a esta función.

Parámetros

playlist los metadatos de la lista de reproducción a destruir.

LIBMTP_playlist_t * LIBMTP_new_playlist_t (void )

Esto crea una nueva estructura de metadatos de lista de reproducción y asigna memoria para ella. Tenga en cuenta que si añade cadenas de texto a esta estructura, estas serán liberadas por la operación correspondiente LIBMTP_destroy_playlist_t más adelante, así que tenga cuidado al usar strdup() al asignar cadenas, por ejemplo:

LIBMTP_playlist_t *pl = LIBMTP_new_playlist_t();
pl->name = strdup(str);
....
LIBMTP_destroy_playlist_t(pl);

Retorna

un puntero a la estructura de metadatos recién asignada.

int LIBMTP_Set_Playlist_Name (LIBMTP_mtpdevice_t * device, LIBMTP_playlist_t * playlist, const char * newname)

Esta función renombra un único contenedor de archivo de objeto de lista de reproducción. Esto simplemente significa que la propiedad PTP_OPC_ObjectFileName se actualiza, si es compatible con el dispositivo. El nombre del archivo de la lista de reproducción debería terminar nominalmente con una extensión como '.pla'.

NOTA: si desea cambiar los metadatos que el dispositivo muestra sobre una lista de reproducción, ¡debe *no* usar esta función, use LIBMTP_Update_Playlist() en su lugar!

Parámetros

device un puntero al dispositivo que contiene el archivo.
playlist los metadatos de la lista de reproducción a renombrar. Si tiene éxito, el miembro name se actualiza. Tenga en cuenta que este nombre puede ser diferente de newname dependiendo de las restricciones del dispositivo.
newname el nuevo nombre para este objeto.

Retorna

0 si tiene éxito, cualquier otro valor significa fallo.

Esta rutina actualiza una lista de reproducción basándose en los metadatos proporcionados. Si el campo de pistas de los metadatos contiene una lista de pistas, estas pistas se añadirán a la lista de reproducción en lugar de las que ya están presentes, es decir, la lista de pistas anterior se eliminará. Para los dispositivos Samsung, es probable que el ID de la lista de reproducción (metadatos->playlist_id) cambie.

Parámetros

dispositivo un puntero al dispositivo en el que crear la nueva lista de reproducción.
metadatos los metadatos de la lista de reproducción que se va a actualizar. Tenga en cuenta que el campo playlist_id debe contener el ID de lista de reproducción apropiado. El ID de lista de reproducción puede modificarse a un nuevo ID de lista de reproducción al regresar la función, ya que la edición en el lugar no siempre es posible.

Devoluciones

0 si la operación es exitosa, cualquier otro valor indica un fallo.
