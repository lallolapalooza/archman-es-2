platform::shell(n) Paquetes incluidos de Tcl platform::shell(n)

NOMBRE

platform::shell - Código y utilidades de soporte para la identificación del sistema

SINOPSIS

package require platform::shell ?1.1.4?

platform::shell::generic shell
platform::shell::identify shell
platform::shell::platform shell

DESCRIPCIÓN

El paquete platform::shell proporciona varios comandos útiles para la identificación de la arquitectura de un shell Tcl específico.

Este paquete permite la identificación de la arquitectura de un shell Tcl específico diferente del shell que ejecuta el paquete. El único requisito es que el otro shell (identificado por su ruta), sea realmente ejecutable en la máquina actual.

Si bien para la mayoría de las plataformas esto significa que la arquitectura del shell interrogado es idéntica a la arquitectura del shell en ejecución, esto no es generalmente cierto. Un contraejemplo son todas las plataformas que tienen variantes de 32 y 64 bits y donde un sistema de 64 bits puede ejecutar código de 32 bits. Para estos, el shell en ejecución y el interrogado pueden tener diferentes configuraciones de 32/64 bits y, por lo tanto, diferentes identificadores.

Para aplicaciones como un repositorio de código, es importante identificar la arquitectura del shell que realmente ejecutará los paquetes instalados, en contraposición a la arquitectura del shell que ejecuta el software del repositorio.

COMANDOS

platform::shell::identify shell
Este comando realiza la misma identificación que platform::identify, para el shell Tcl especificado, en contraste con el shell en ejecución.
platform::shell::generic shell
Este comando realiza la misma identificación que platform::generic, para el shell Tcl especificado, en contraste con el shell en ejecución.
platform::shell::platform shell
Este comando devuelve el contenido de tcl_platform(platform) para el shell Tcl especificado.
