PLASTIC(1) Manual General de Comandos PLASTIC(1)

NOMBRE


plastic - emulador de NES con interfaces gráfica (GUI) y de terminal (TUI).

SINOPSIS


plastic [archivo-rom]
plastic_tui [archivo-rom] [-a]

DESCRIPCIÓN


plastic es un emulador de NES escrito en Rust, diseñado para ejecutar juegos de NES con interfaces gráfica (GUI) y basada en terminal (TUI).


La interfaz gráfica (plastic) se puede lanzar sin argumentos (aunque se puede iniciar desde la terminal con un archivo ROM) y proporciona una experiencia gráfica fácil de usar.


La interfaz basada en terminal (plastic_tui) permite a los usuarios ejecutar el emulador en la terminal con opciones para control adicional.


Los estados guardados se almacenan en la siguiente ruta:
~/.local/share/plastic/saved_states

OPCIONES


plastic [archivo-rom]
Inicia el emulador con la interfaz gráfica. Si bien los argumentos son opcionales, se recomienda especificar un archivo ROM como argumento para jugar inmediatamente.


plastic_tui [archivo-rom] [-a]
Inicia el emulador con la interfaz basada en terminal. Las siguientes opciones están disponibles:
- archivo-rom: Especifica el archivo ROM de NES a cargar.
- -a: Deshabilita la salida de audio mientras se ejecuta en modo TUI.

INSTALACIÓN


Las últimas versiones de plastic y plastic_tui se pueden instalar usando Cargo:


cargo install plastic
cargo install plastic_tui

EJEMPLOS


Ejecutar plastic con la interfaz gráfica:


plastic


plastic ruta/a/rom.nes


Ejecutar plastic_tui con un archivo ROM específico:


plastic_tui ruta/a/rom.nes


Ejecutar plastic_tui sin audio:


plastic_tui ruta/a/rom.nes -a
