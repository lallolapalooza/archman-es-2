PLUMA(1) Manual de Comandos Generales PLUMA(1)

NOMBRE

Pluma - El Editor de Texto de MATE

SINOPSIS

pluma [OPCIONES...] [ARCHIVOS...]

DESCRIPCIÓN

Pluma es el editor de texto oficial del entorno de escritorio MATE. Aunque apunta a la simplicidad y facilidad de uso, Pluma es un editor de texto potente de propósito general. Puede ser utilizado para crear y editar todo tipo de archivos de texto.

Pluma cuenta con un sistema de plugins flexible que puede ser usado para agregar dinámicamente nuevas características avanzadas a Pluma.

Esta página del manual documenta brevemente el comando pluma.

OPCIONES

nombre-de-archivo(s)...
Especifica el archivo a abrir cuando se inicia pluma. Si esto no se especifica, pluma iniciará un archivo nuevo y en blanco con una etiqueta de "Documento no guardado". Se pueden cargar múltiples archivos si están separados por espacios. pluma también soporta el manejo de archivos remotos.
--display=MOSTRAR
Pantalla X a utilizar.
--encoding
Establece la codificación de caracteres a utilizar para abrir los archivos listados en la línea de comandos.
--new-window
Crea una nueva ventana de nivel superior en una instancia existente de pluma.
--new-document
Crea un nuevo documento en una instancia existente de pluma, en la última ventana de Pluma que tuvo el foco.
+[número]
Para el primer archivo, va a la línea especificada por "número" (no inserte un espacio entre el signo "+" y el número). Si "número" está ausente, va a la última línea.
--list-encodings
Muestra la lista de valores posibles para la opción de codificación y sale
--version
Muestra la información de la versión y sale
-?, -h, --help
Imprime las opciones estándar de la línea de comandos.
--help-all
Imprime todas las opciones de la línea de comandos.

Este programa también acepta las opciones estándar de GTK.

EJEMPLOS

pluma --encoding WINDOWS-1252 ftp://ftp.kernel.org/pub/linux/kernel/README

Abre el archivo README del servidor FTP de kernel.org usando la codificación de caracteres Windows-1252.

pluma +156 http://mate-desktop.org/

Abre la página principal de mate-desktop.org y salta a la línea 156.

pluma --new-window ~/.bashrc ~/.bash_history

Abre los archivos .bashrc y .bash_history del usuario actual en una nueva ventana de Pluma.
