PLUGINVIEWER(8) Manual del Administrador del Sistema PLUGINVIEWER(8)

NOMBRE

pluginviewer - lista los plugins SASL cargables y sus propiedades

SINOPSIS

pluginviewer [-a] [-s] [-c] [-b min=N,max=N] [-e ssf=N,id=ID] [-m MECHS] [-x AUXPROP_MECHS] [-f FLAGS] [-p PATH]

DESCRIPCIÓN

pluginviewer puede ser utilizado por un administrador del servidor para solucionar problemas de instalación de SASL. La utilidad puede listar plugins cargables (correctamente configurados) del lado del cliente y del servidor, así como plugins auxprop.

OPCIONES

-a
Lista plugins auxprop.
-s
Lista plugins de autenticación de servidor (SASL).
-c
Lista plugins de autenticación de cliente (SASL).
-b min=N1,max=N2
Lista plugins de autenticación de cliente (SASL). Fuerza de la capa de seguridad SASL en bits. min=N1 especifica la fuerza mínima a usar (1 => protección de integridad). max=N2 especifica la fuerza máxima a usar. Solo se mostrarán los mecanismos SASL que soporten una capa de seguridad con fuerza M tal que N1 <= M <= N2.
-e ssf=N,id=ID
Asume que se ha instalado una capa de seguridad externa (por ejemplo, TLS) con una fuerza de N bits. El ID es la identidad de autenticación utilizada por la capa de seguridad externa.
-m MECHS
Limita los plugins SASL listados a los incluidos en la lista MECHS (separados por espacios).
-x AUXPROP_MECHS
Limita los plugins auxprop listados al incluido en la lista AUXPROP_MECHS (separados por espacios).
-f FLAGS
Establece indicadores de seguridad. FLAGS es una lista separada por comas de uno o más de los siguientes indicadores de seguridad: noplain (el mecanismo SASL no envía la contraseña en texto claro durante la autenticación), noactive (requiere protección contra ataques activos), nodict (requiere mecanismos seguros contra ataques de diccionario pasivos), forwardsec (requiere secreto directo), passcred (requiere mecanismos que puedan delegar credenciales de cliente), maximum (requiere todos los indicadores de seguridad).
-p PATH
Especifica una ruta de búsqueda de plugins separada por dos puntos.
