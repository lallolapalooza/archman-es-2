NOMBRE

plymouth-set-default-theme - Establece el tema de plymouth

SINOPSIS

plymouth-set-default-theme [OPCIÓN...] [TEMA]

DESCRIPCIÓN

Cuando se llama con un argumento TEMA, el comando plymouth-set-default-theme cambia el tema de arranque preferido y también realiza la regeneración necesaria del disco ram inicial (initrd) ya que plymouth se carga desde el gestor de arranque desde el initrd antes de montar el sistema de archivos raíz.

Si plymouth-set-default-theme se invoca sin opciones ni parámetros, muestra el tema seleccionado actualmente por defecto. Esta salida es utilizada por los scripts auxiliares plymouth-generate-initrd y plymouth-update-initrd para establecer el tema adecuado en el disco ram inicial.

OPCIONES

Se entienden las siguientes opciones:

-h, --help

Muestra un resumen de las opciones.

-l, --list

Lista los temas disponibles.

-r, --reset

Restablece al tema predeterminado.

-R, --rebuild-initrd

Reconstruye el initrd (necesario después de cambiar el tema).
