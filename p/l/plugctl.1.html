NOMBRE

plugctl - un programa para obtener o establecer cualquier valor de registro MPR o PCR

SINOPSIS

plugctl [-p puerto] [-n nodo] enchufe.atributo[=valor]

DESCRIPCIÓN

plugctl es un programa para obtener o establecer el valor del atributo de un enchufe.

enchufe es uno de oMPR, iMPR, oPCR[n], o iPCR[n] (sin distinción de mayúsculas y minúsculas). Por favor, proporcione un índice numérico para [n].

Esta página del manual fue escrita para la distribución Debian porque el programa original no tiene una página del manual.

OPCIONES

Estos programas siguen la sintaxis habitual de línea de comandos de GNU. A continuación se incluye un resumen de las opciones.

-p puerto
Obtiene o establece el valor del atributo de un enchufe en este puerto.
-n nodo
Obtiene o establece el valor del atributo de un enchufe en este nodo.

VER TAMBIÉN
