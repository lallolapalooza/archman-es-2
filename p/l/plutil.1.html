NOMBRE

plutil — Utilidad de listas de propiedades

SINOPSIS

nombre_prog [-comando] [-opciones] archivo

DESCRIPCIÓN

La utilidad plutil se puede usar para editar listas de propiedades, verificar la sintaxis o convertir de un formato a otro. Si se proporciona ‘-’ como ruta de archivo, se utilizarán la entrada estándar y la salida estándar.

La primera parte es la acción a realizar, una de las siguientes:

-p
Imprimir toda la lista de propiedades en la salida estándar, en formato legible para humanos de GNUStep.
-lint
Verifica que la lista de propiedades se pueda analizar.
-convertir FMT
Convierte la lista de propiedades a otro formato. ‘FMT’ puede ser uno de los siguientes:
xml1
XML de Apple.
binary1
Binario de Apple.
openstep
OpenStep (legible para humanos sin tipo).
gnustep
GNUStep (legible para humanos con tipo).
json
JSON (legible para humanos con pérdida de información).
También se aceptan los nombres de formato NSPropertyListFormat.
-insertar RUTA CLAVE Valor
 
La acción predeterminada es ‘-lint.’

Las opciones generales son:

La "ruta de clave" de plutil es una cadena de claves separadas por puntos para recorrer un objeto de lista de propiedades. Una ruta de clave vacía se refiere al propio objeto. El formato de las claves se ajusta al de las literales de cadena de listas de propiedades de GNUStep.

NOTAS DE IMPLEMENTACIÓN

  • Las cadenas entre comillas en la ruta de clave son una extensión de GNUStep.
  • Los formatos de salida de literales de Objective-C y Swift aún no están implementados.
