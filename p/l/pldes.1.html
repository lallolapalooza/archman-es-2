PLDES(1) Manual del sistema GNUstep PLDES(1)

NOMBRE

pl, pldes, plser, plmerge, plparse, pl2link - herramientas de listas de propiedades

SINOPSIS

pldes nombre(s)-de-archivo
plget clave[más claves]
plser [ -formatofmt ] nombre(s)-de-archivo
plmerge [ archivo-destino ] [ nombre(s)-de-archivo-entrada ]
plparse nombre(s)-de-archivo
pl2link archivo-entrada [ archivo-destino ]
pl -entrada [ archivo-entrada ]  -salida [ archivo-destino ]

DESCRIPCIÓN

Las listas de propiedades en GNUstep son listas jerárquicas de valores o pares de atributos-valor. Programáticamente se representan mediante instancias de las clases NSString, NSData, NSArray o NSDictionary (la más común) (que pueden contener otras instancias de dichas clases). Estas instancias pueden serializarse como objetos binarios para formar una representación persistente. Además, existen dos representaciones alternativas legibles por humanos. La primera, utilizada en NeXTstep y OpenStep, utiliza un formato de texto con signos de igual que expresan enlaces de atributo-valor y llaves que expresan la organización jerárquica. La segunda, a menudo (poco informativamente) referida como formato "plist", está en XML y es utilizada por Mac OS X. Las herramientas descritas aquí son utilidades para manipular las diversas representaciones persistentes de listas de propiedades como archivos.

pldes nombre(s)-de-archivo
Convierte una lista de propiedades serializada binaria (instancia de clase) a una representación de texto.
plget clave
Lee una representación de texto de un diccionario en formato de lista de propiedades como entrada estándar, extrae el valor de cadena contenido en ese diccionario con la clave especificada y escribe el resultado en la salida estándar. Se pueden usar múltiples claves para extraer valores de diccionarios anidados.
plser [ -formato formato ] nombre(s)-de-archivo
Convierte una representación de texto de una lista de propiedades a una representación serializada binaria, o a otro formato seleccionado.
plmerge [ archivo-destino ] [ nombre(s)-de-archivo-entrada ]
Fusiona listas de propiedades de texto en una única lista de propiedades.
plparse nombre(s)-de-archivo
Comprueba que cada archivo contenga una representación de texto válida de una lista de propiedades.
pl2link archivo-entrada [ archivo-destino ]
Produce un archivo de enlace de escritorio para KDE y Gnome para la representación de texto dada de una lista de propiedades.
pl -entrada [ archivo-entrada ]
Toma la lista de propiedades serializada representada por archivo-entrada y la saca a la salida estándar.
pl -salida [ archivo-destino ]
Toma una lista de propiedades de la entrada estándar y la serializa en archivo-destino.
