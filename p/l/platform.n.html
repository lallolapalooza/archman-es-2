platform(n) Paquetes Empaquetados de Tcl platform(n)

NOMBRE

platform - Código y utilidades de soporte para la identificación del sistema

SINOPSIS

package require platform ?1.0.10?

platform::generic
platform::identify
platform::patterns identifier

DESCRIPCIÓN

El paquete platform proporciona varios comandos de utilidad útiles para la identificación de la arquitectura de una máquina que ejecuta Tcl.

Aunque Tcl proporciona la matriz tcl_platform para identificar la arquitectura actual (en particular, los elementos platform y machine), esto no siempre es suficiente. Esto se debe a que (en máquinas Unix) tcl_platform refleja los valores devueltos por el comando uname y estos no están estandarizados entre plataformas y arquitecturas. Además, en al menos una plataforma (AIX), tcl_platform(machine) contiene el número de serie de la CPU.

En consecuencia, las aplicaciones individuales necesitan manipular los valores en tcl_platform (junto con la salida de utilidades específicas del sistema), lo que resulta inconveniente para los desarrolladores e introduce la posibilidad de inconsistencias en la identificación de arquitecturas y en las convenciones de nomenclatura.

El paquete platform evita tal fragmentación, es decir, establece una convención de nomenclatura estándar para las arquitecturas que ejecutan Tcl y facilita a los desarrolladores la identificación de la arquitectura actual en la que se está ejecutando un programa Tcl.

COMANDOS

platform::identify
Este comando devuelve un identificador que describe la plataforma en la que se está ejecutando el núcleo de Tcl. El identificador devuelto tiene el formato general OS-CPU. La parte OS del identificador puede contener detalles como la versión del kernel, la versión de libc, etc., y esta información puede contener guiones. La parte CPU no contendrá guiones, haciendo que el guion anterior sea el último guion en el resultado.
platform::generic
Este comando devuelve un identificador simplificado que describe la plataforma en la que se está ejecutando el núcleo de Tcl. A diferencia de platform::identify, omite detalles como la versión del kernel, la versión de libc, etc. El identificador devuelto tiene el formato general OS-CPU.
platform::patterns identifier
Este comando toma un identificador como el devuelto por platform::identify y devuelve una lista de identificadores que describen arquitecturas compatibles.

EJEMPLO

Esto se puede usar para permitir que una aplicación se distribuya con múltiples compilaciones de una biblioteca compartida, de modo que el mismo paquete funcione en muchas versiones de un sistema operativo. Por ejemplo:

package require platform
# Supongamos que el script de la aplicación es .../theapp/bin/theapp.tcl
set binDir [file dirname [file normalize [info script]]]
set libDir [file join $binDir .. lib]
set platLibDir [file join $libDir [platform::identify]]
load [file join $platLibDir support[info sharedlibextension]]
