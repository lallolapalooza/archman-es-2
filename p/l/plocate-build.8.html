NOMBRE

plocate-build - generar índice para plocate

SINOPSIS

plocate-build [OPCIÓN]... MLOCATE_DB PLOCATE_DB

DESCRIPCIÓN

plocate-build crea un índice para plocate(1) a partir de un índice generado anteriormente por updatedb(8) del paquete mlocate(1). La mayoría de los usuarios preferirían usar el propio updatedb(8) de plocate, que es más directo. Si PLOCATE_DB ya existe, será sobrescrito (de forma no atómica). El archivo se crea de manera que no sea legible por todos, ya que la verificación de acceso final la realiza plocate(1) durante la búsqueda.

OPCIONES

-b, --tamaño-bloque TAMAÑO
Crea bloques que contienen TAMAÑO nombres de archivo cada uno, los comprime juntos y los trata como el mismo elemento en las listas de publicación. Esto hace que el índice sea más pequeño (ya que el algoritmo de compresión obtiene más contexto para trabajar y hay menos elementos en cada lista de publicación), pero también hace que las listas de publicación sean menos precisas, trasladando más trabajo a la eliminación de falsos positivos después de la intersección de listas de publicación.

Aumentar este número hará que la búsqueda lineal (para --regex, o patrones muy cortos) sea más rápida, con rendimientos decrecientes alrededor de 256 nombres de archivo por bloque. Sin embargo, hacerlo demasiado grande causará más falsos positivos, reduciendo el rendimiento general para consultas típicas. El valor predeterminado es 32. Establecerlo en 1 crea un bloque (comprimido) por nombre de archivo.

-p, --texto-plano
Trata la entrada como texto plano, con entradas delimitadas por saltos de línea, en lugar de una base de datos mlocate.
-l, --requerir-visibilidad BANDERA
Establece la bandera "requerir visibilidad del archivo antes de informarlo" en la base de datos generada a BANDERA. El valor predeterminado es sí, incluso para una base de datos mlocate con la bandera originalmente establecida en no (aunque esto último puede cambiar en el futuro).
--ayuda
Muestra la información de uso y luego sale exitosamente.
--version
Muestra la información de la versión y luego sale exitosamente.
