NOMBRE

playerctl — controla reproductores multimedia a través de MPRIS

SINOPSIS

playerctl [-aFhlV] [-f FORMATO] [-i NOMBRE] [-p NOMBRE] comando

DESCRIPCIÓN

La utilidad playerctl controla reproductores multimedia compatibles con MPRIS. Además de ofrecer control de reproducción, pausa y parada, playerctl también ofrece soporte para pistas anteriores y siguientes, la capacidad de avanzar y retroceder en una pista, y control de volumen. playerctl también soporta la visualización de metadatos (por ejemplo, artista, título, álbum) para la pista actual, y la visualización del estado del reproductor.

Los reproductores que se pueden controlar usando playerctl incluyen audacious(1), cmus(1), mopidy(1), mpd(1), quodlibet(1), rhythmbox(1), vlc(1) y xmms2(1). Sin embargo, cualquier reproductor que implemente la especificación de interfaz MPRIS puede ser controlado usando playerctl, incluyendo navegadores web.

Playerctl también viene con un demonio llamado playerctld que realiza un seguimiento de la actividad de los reproductores multimedia. Cuando playerctld está en ejecución, los comandos playerctl actuarán sobre el reproductor multimedia con la actividad más reciente. Ejecuta el comando playerctld daemon para iniciar el demonio.

Las opciones son las siguientes:

-a, --todos-los-reproductores
Aplica el comando a todos los reproductores disponibles.
-F, --seguir
Bloquea y emite la consulta actualizada cuando cambia.
-f FORMATO, --formato FORMATO
Establece la salida del comando actual a FORMATO. Ver Cadenas de formato.
-h, --ayuda
Imprime esta ayuda y luego sale.
-i NOMBRE, --ignorar-reproductor NOMBRE
Ignora el reproductor específico NOMBRE. Se pueden especificar varios reproductores en una lista separada por comas.
-l, --listar-todos
Lista los nombres de los reproductores en ejecución que se pueden controlar.
-p NOMBRE, --reproductor NOMBRE
Controla el reproductor específico NOMBRE. Se pueden especificar varios reproductores en una lista separada por comas. Por defecto, se utiliza el primer reproductor disponible. El nombre "nombre" coincide tanto con "nombre" como con "nombre.{INSTANCIA}". Además, el nombre "%any" coincide con cualquier reproductor.
-s, --sin-mensajes
Silencia algunos mensajes de diagnóstico y error.
-V, --versión
Imprime el número de versión y luego sale.

Los comandos son los siguientes:

estado
Obtiene el estado actual del reproductor.
reproducir
Ordena al reproductor que reproduzca.
pausar
Ordena al reproductor que pause.
reproducir-pausar
Ordena al reproductor que alternar entre reproducir y pausar.
detener
Ordena al reproductor que se detenga.
siguiente
Ordena al reproductor que salte a la siguiente pista.
anterior
Ordena al reproductor que salte a la pista anterior.
posicion [DESFASE[+|-]]
Imprime la posición de la pista actual en segundos. Con DESFASE especificado, busca en DESFASE segundos desde el inicio de la pista actual. Con el opcional [+|-] añadido, avanza o retrocede DESFASE segundos desde la posición actual.
volumen [NIVEL[+|-]]
Imprime el volumen del reproductor escalado de 0.0 (0%) a 1.0 (100%). Con NIVEL especificado, establece el volumen del reproductor a NIVEL. Con el opcional [+|-] añadido, aumenta o disminuye el volumen del reproductor en NIVEL.
metadatos [CLAVE]
Imprime todas las propiedades de metadatos de la pista actual establecidas por el reproductor actual. Si se especifica CLAVE, solo se imprime el valor de CLAVE.
abrir URI
Abre URI en el reproductor. URI puede ser el nombre de un archivo o una URL externa.
reproduccion-aleatoria [Activado | Desactivado | Alternar]
Imprime el estado de reproducción aleatoria del reproductor. Con el estado de reproducción aleatoria especificado, establece el estado de reproducción aleatoria en Activado, Desactivado o Alternar.
bucle [Ninguno | Pista | ListaDeReproduccion]
Imprime el estado de bucle del reproductor. Con el estado de bucle especificado, establece el estado de bucle en Ninguno (desactivar bucle), Pista (repetir la pista actual) o ListaDeReproduccion (repetir la lista de reproducción actual).

Cadenas de formato

La salida de los comandos posicion, metadatos, estado y volumen se puede controlar usando una cadena de formato. Las variables establecidas por estos comandos se pueden incluir en la cadena de formato encerrándolas entre llaves: ‘{{var}}’. Estas se expandirán en la salida.

Cada comando tiene acceso a las siguientes variables:

nombreReproductor
El nombre del reproductor actual.
posicion
La posición de tiempo de la pista actual, en microsegundos.
estado
El estado del reproductor actual.
volumen
El volumen del reproductor escalado de 0.0 (0%) a 1.0 (100%).

Cada propiedad listada en el comando metadatos también se establece como variable. Se recomienda consultar esta lista para cada reproductor, ya que diferentes reproductores pueden no establecer las mismas propiedades. NAME

playerctl - control music players

SYNOPSIS

playerctl [OPTION...] COMMAND

DESCRIPTION

playerctl provides a command-line interface to control players that support the MPRIS D-Bus Interface Specification.

Commands can be used to control playback, query metadata, and more. The playerctl utility supports formatting the output of commands using a template system. Variables are expanded to player metadata, and helper functions can be used to transform the output.

The available variables are as follows:

playerName, xesam:playerName
The name of the player.
identity, xesam:identity
The identity of the player.
filename, xesam:filename
The filename of the current track.
baseUri, xesam:baseUri
The base URI of the current track.
url, xesam:url
The URL of the current track.
title, xesam:title
The title of the current track.
subtitle, xesam:subtitle
The subtitle of the current track.
album, xesam:album
The album of the current track.
artist, xesam:artist
The artist of the current track.
albumArtist, xesam:albumArtist
The album artist of the current track.
trackNumber, xesam:trackNumber
The track number of the current track.
genre, xesam:genre
The genre of the current track.
duration, xesam:duration
The duration of the current track in microseconds.
comments, xesam:comments
The comments of the current track.
artUrl, xesam:artUrl
The URL of the cover art for the current track.
composer, xesam:composer
The composer of the current track.
discNumber, xesam:discNumber
The disc number of the current track.
creationDate, xesam:creationDate
The creation date of the current track.
lyrics, xesam:lyrics
The lyrics of the current track.
location, xesam:location
The location of the current track.
remainder, xesam:remainder
The remainder of the current track.
stripIds, xesam:stripIds
The strip IDs of the current track.
status
The playback status of the player (Playing, Paused, Stopped).
position
The current playback position in microseconds.
volume
The current volume of the player.
mpris:length
The duration of the current track in microseconds.
mpris:artUrl
The URL of the cover art for the current track.
mpris:trackid
The unique identifier for the current track.

Helper functions are also available to transform expanded variables into other representations. They are called in the form ‘{{func(var)}}’. The helper functions are as follows:

lc(str)
Convert string str to lowercase.
uc(str)
Convert string str to uppercase.
markup_escape(str)
Escape XML characters in string str. This is useful when displaying metadata that might contain characters like '&', '<', or '>' in a context where they would be interpreted as markup.
default(str1, str2)
Print str1 if it is set and not empty, otherwise print str2. This is useful for providing fallback values when a piece of metadata might be missing.
duration(time)
Reformat the microsecond timestamp time in the form ‘hh:mm:ss’. Can only be called with position or mpris:length. This function converts the raw microsecond value into a more human-readable time format.
emoji(key)
Try to convert the value for key to an emoji representation. Currently implemented for status and volume. For example, emoji(status) might return ▶ for Playing, ⏸ for Paused, and ■ for Stopped. emoji(volume) might return 🔈 for low volume, 🔉 for medium volume, and 🔊 for high volume.
trunc(str, len)
Truncate str to a maximum of len characters, adding an ellipsis (…) if necessary. This is useful for displaying metadata that might be too long to fit in a limited space, like a status bar.

The template language is also able to perform basic math operations.

References to unknown functions will cause playerctl to exit with an error. References to unknown variables will be expanded to empty strings. Text not enclosed in braces will be printed verbatim.

EXIT STATUS

The playerctl utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

Print the player name, playback status in lowercase, and position and length in human readable form:

$ playerctl metadata --format '{{playerName}}: {{lc(status)}} '\
'{{duration(position)}}|{{duration(mpris:length)}}'

Print the title and artist, falling back to the filename if the title is not available:

$ playerctl metadata --format '{{default(title, filename)}} - {{artist}}'

Print the album art URL, escaping any special XML characters:

$ playerctl metadata --format '{{markup_escape(mpris:artUrl)}}'

Print the track title, truncated to 50 characters:

$ playerctl metadata --format '{{trunc(title, 50)}}'
