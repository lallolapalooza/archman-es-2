PLASMAENGINEEXPLO(1) Manual del usuario de plasmaengineexplorer PLASMAENGINEEXPLO(1)

NOMBRE

plasmaengineexplorer - Proporciona acceso directo a los motores de datos de plasma

SINOPSIS

plasmaengineexplorer [-v, --version] [-h, --help] [--list] [--heightpíxeles] [--widthpíxeles] [-xpíxeles] [-ypíxeles] [--enginemotor de datos] [--sourcemotor de datos] [--intervalms] [--appaplicación]

plasmaengineexplorer [Opciones genéricas de KDE ] [Opciones genéricas de Qt ]

DESCRIPCIÓN

plasmaengineexplorer es una herramienta gráfica que permite a los desarrolladores probar los motores de datos de Plasma sin necesidad de escribir una aplicación de Plasma.

Si no se proporcionan opciones, se iniciará sin ningún motor de datos seleccionado. El motor de datos requerido puede seleccionarse de una lista desplegable.

Solo se encontrarán los motores de datos instalados. Es posible que necesite ejecutar kbuildsycoca4 para que se encuentren los motores de datos recién instalados.

OPCIONES

-v, --version

Muestra información de la versión.

-h, --help

Muestra esta ayuda.

--list píxeles

Muestra una lista de los motores conocidos y sus descripciones.

--height

Establece la altura de la ventana, en píxeles.

--width píxeles

Establece el ancho de la ventana, en píxeles.

-x píxeles

Establece la coordenada x (horizontal) de la esquina superior izquierda de la ventana, en píxeles.

-y píxeles

Establece la coordenada y (vertical) de la esquina superior izquierda de la ventana, en píxeles.

--engine motor de datos

Inicia plasmaengineexplorer con el motor de datos dado seleccionado. motor de datos es el nombre interno del motor de datos dado por la clave X-KDE-PluginInfo-Name del archivo de escritorio.

--source motor de datos

Solo válido en combinación con --engine. Solicita una fuente específica del motor de datos cuando se inicia plasmaengineexplorer.

--interval tiempo

Establece el intervalo de actualización predeterminado para las fuentes solicitadas a tiempo milisegundos. Si no se establece, la fuente se actualizará a petición (para algunas fuentes, esto será cuando haya nuevos datos disponibles).

Si se especifica --source, este será el intervalo de actualización que se utilizará al solicitar esa fuente.

--app aplicación

Solo muestra los motores asociados con la aplicación principal; se mapea a la entrada X-KDE-ParentApp en el archivo .desktop del DataEngine.

VER TAMBIÉN

Hay documentación de usuario más detallada disponible en help:/plasma-desktop (introduzca esta URL en Konqueror o ejecute khelpcenter help:/plasma-desktop).

EJEMPLOS

Cargar el motor de datos de tiempo, mostrando la hora local y actualizando cada segundo:

plasmaengineexplorer --engine time --source Local --interval 1000
