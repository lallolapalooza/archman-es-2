PLOT(1) Utilidades de trazado de GNU PLOT(1)

NOMBRE

plot - traduce metarchivos de GNU a otros formatos gráficos

SINOPSIS

plot [ opciones ] [ archivos ]

DESCRIPCIÓN

plot traduce archivos en formato de metarchivo de GNU a otros formatos gráficos, o los muestra en una pantalla del sistema de ventanas X. El formato de metarchivo de GNU es un formato independiente del dispositivo para el almacenamiento de datos gráficos. Es el formato de salida predeterminado de los programas graph(1), pic2plot(1), tek2plot(1), y plotfont(1), y se documenta además en plot(5), ya que es una versión mejorada del formato tradicional de plot(5) que se encuentra en sistemas que no son de GNU. También puede ser producido por la biblioteca de gráficos 2D libplot de GNU (ver plot(3)).

El formato de salida se especifica con la opción -T. Los formatos de salida y tipos de visualización posibles son los mismos que los soportados por graph(1), plotfont(1), pic2plot(1), y tek2plot(1). Si se produce un archivo de salida, se escribe en la salida estándar.

Las opciones y los nombres de archivo pueden intercalarse en la línea de comandos, pero las opciones se procesan antes de leer los nombres de archivo. Si se ve --, se interpreta como el final de las opciones. Si no se especifican nombres de archivo, o se encuentra el nombre de archivo -, se lee la entrada estándar.

OPCIONES

Opciones Generales

-T tipo

--output-format tipo
Selecciona tipo como el formato de salida. Puede ser "X", "png", "pnm", "gif", "svg", "ai", "ps", "cgm", "fig", "pcl", "hpgl", "regis", "tek", o "meta" (el predeterminado). Estos se refieren respectivamente al sistema de ventanas X, formato PNG (Portable Network Graphics), formato portable anymap (PBM/PGM/PPM), un formato pseudo-GIF que no utiliza codificación LZW, el nuevo formato SVG (Scalable Vector Graphics) basado en XML, el formato utilizado por Adobe Illustrator, Postscript o Encapsulated Postscript (EPS) que puede ser editado con idraw(1), formato CGM (por defecto, conforme al perfil WebCGM), el formato utilizado por el editor de dibujos xfig(1), el lenguaje de impresora Hewlett-Packard PCL 5, Hewlett-Packard Graphics Language, formato gráfico ReGIS (que puede ser mostrado por el emulador de terminal dxterm(1) o por un terminal VT330 o VT340), formato Tektronix (que puede ser mostrado por el emulador de terminal xterm(1)), y formato de metarchivo GNU independiente del dispositivo sí mismo. A menos que tipo sea "X", se produce un archivo de salida y se escribe en la salida estándar.
Omitir la opción -T es equivalente a especificar -T meta. Traducir de formato de metarchivo a sí mismo es ocasionalmente útil, ya que hay dos versiones del formato de metarchivo (ver la opción -O más adelante).
Una lista de las fuentes disponibles en cualquier formato de salida especificado puede obtenerse con la opción --help-fonts (ver más adelante). Si una fuente solicitada no está disponible, se sustituirá una fuente predeterminada. La fuente predeterminada es "Helvetica" para "X", "svg", "ai", "ps", "cgm", y "fig", "Univers" para "pcl", y "HersheySerif" para "png", "pnm", "gif", "hpgl", "regis", "tek", y "meta".
-p n

--page-number n
Generar solo la página número n, dentro del metarchivo o secuencia de metarchivos que se está traduciendo.
Los metarchivos pueden consistir en una o más páginas, numeradas a partir de 1. Además, cada página puede contener múltiples `fotogramas'. plot -T X, plot -T regis, y plot -T tek, que trazan en tiempo real, separarán los fotogramas sucesivos con borrado de pantalla. plot -T png, plot -T pnm, plot -T gif, plot -T svg, plot -T ai, plot -T ps, plot -T cgm, plot -T fig, plot -T pcl, y plot -T hpgl, que no trazan en tiempo real, generarán solo el último fotograma de cualquier página con múltiples fotogramas.
El comportamiento predeterminado, si no se usa -p, es generar todas las páginas. Por ejemplo, plot -T X muestra cada página en su propia ventana X. Si se utiliza la opción -T png, -T pnm, -T gif, -T ai, o -T fig, el comportamiento predeterminado es generar solo la primera página no vacía, ya que los archivos en esos formatos de salida contienen solo una única página de gráficos.
Los metarchivos producidos por graph(1) y plotfont(1) contienen solo una única página (página n.º 1), que consta de dos fotogramas: un fotograma vacío para limpiar la pantalla, y un segundo fotograma que contiene los gráficos.
-s

--merge-pages
Combinar todas las páginas mostradas en una sola página, y también combinar todos los `fotogramas'.
Esta opción es útil al combinar trazados de una sola página de diferentes fuentes. Por ejemplo, se puede usar para combinar trazados obtenidos de invocaciones separadas de graph(1).
--bitmap-size bitmap_size
Establece el tamaño de la pantalla gráfica en la que se dibujará el trazado, en píxeles, a ser bitmap_size. El valor predeterminado es "570x570". Esto solo es relevante para plot -T X, plot -T png, plot -T pnm, y plot -T gif, todas las cuales producen mapas de bits. Si elige un tamaño de ventana rectangular (no cuadrado), las fuentes del trazado se escalarán de forma anisotrópica, es decir, con diferentes factores en las direcciones horizontal y vertical. Para plot -T X, esto requiere una pantalla X11R6. Cualquier fuente que no pueda escalarse de esta manera será reemplazada por una fuente escalable predeterminada, como la fuente vectorial "HersheySerif".
La variable de entorno BITMAPSIZE puede usarse de la misma manera para especificar el tamaño de la ventana. Para compatibilidad hacia atrás, el recurso X Xplot.geometry puede usarse en su lugar.
--emulate-color option
Si option es yes, reemplaza cada color en la salida por un tono de gris apropiado. Esto rara vez es útil, excepto cuando se usa plot -T pcl para preparar la salida para un dispositivo PCL 5. (Muchos dispositivos PCL 5 monocromos, como los LaserJet monocromos, hacen un mal trabajo emulando color por sí mismos.) Igualmente puede solicitar la emulación de color estableciendo la variable de entorno EMULATE_COLOR a "yes".
--max-line-length max_line_length
Establece el número máximo de puntos que una línea poligonal puede contener, antes de ser vaciada, a max_line_length. Si ocurre este vaciado, la línea poligonal se dividirá en dos o más sublíneas, aunque la división no debería ser perceptible. El valor predeterminado de max_line_length es 500.
La razón para dividir líneas poligonales largas es que algunos dispositivos de visualización (por ejemplo, impresoras Postscript antiguas y trazadores HP-GL de pluma) tienen tamaños de búfer limitados. La variable de entorno MAX_LINE_LENGTH también puede usarse para especificar la longitud máxima de línea.
--page-size pagesize
Establece el tamaño de la página en la que se posicionará el trazado. Esto solo es relevante para plot -T svg, plot -T ai, plot -T ps, plot -T cgm
, plot -T fig, plot -T pcl, y plot -T hpgl. El valor por defecto es "letter", que significa una página de 8.5 por 11 pulgadas. Se puede especificar cualquier tamaño de página ISO en el rango "a0"..."a4" o tamaño de página ANSI en el rango "a"..."e" ("letter" es un alias para "a" y "tabloid" es un alias para "b"). También se reconocen los tamaños de página "legal" y "ledger". La variable de entorno PAGESIZE puede usarse igualmente para especificar el tamaño de página.
La pantalla gráfica en la que se dibuja el gráfico, por defecto, será una región cuadrada que ocupa casi la totalidad del ancho de la página especificada. Se puede especificar un tamaño alternativo para la pantalla gráfica. Por ejemplo, el tamaño de página podría especificarse como "letter,xsize=4in,ysize=6in", o "a4,xsize=5.0cm,ysize=100mm". Para todas las opciones excepto plot -T hpgl, la pantalla gráfica estará, por defecto, centrada en la página. Para todas las opciones excepto plot -T svg y plot -T cgm, la pantalla gráfica puede ser reposicionada manualmente, especificando la ubicación de su esquina inferior izquierda, en relación a la esquina inferior izquierda de la página. Por ejemplo, el tamaño de página podría especificarse como "letter,xorigin=2in,yorigin=3in", o "a4,xorigin=0.5cm,yorigin=0.5cm". También es posible especificar un vector de desplazamiento. Por ejemplo, el tamaño de página podría especificarse como "letter,xoffset=1in", o "letter,xoffset=1in,yoffset=1.2in", o "a4,yoffset=-1cm". En formato SVG y formato WebCGM es posible especificar el tamaño de la pantalla gráfica, pero no su posición.
--rotation angulo
Rota la pantalla gráfica en angulo grados. Los valores reconocidos son "0", "90", "180", y "270". "no" y "yes" son equivalentes a "0" y "90", respectivamente. La variable de entorno ROTATION también puede usarse para especificar un ángulo de rotación.

Opciones de Inicialización de Parámetros

Las siguientes opciones establecen los valores iniciales de los parámetros de dibujo. Sin embargo, todas ellas pueden ser anuladas por directivas en un metarchivo. De hecho, estas opciones son útiles principalmente al trazar metarchivos antiguos en el formato tradicional (pre-GNU) de plot(5), que no soportaba tales directivas.

--bg-color nombre
Establece el color inicialmente usado para el fondo como nombre. Esto solo es relevante para plot -T X, plot -T png, plot -T pnm, plot -T gif, plot -T svg, plot -T cgm, y plot -T regis. Un nombre no reconocido establece el color al por defecto, que es "white". La variable de entorno BG_COLOR puede usarse igualmente para especificar el color de fondo.
Si se usa la opción -T png o -T gif, se puede producir un archivo PNG transparente o un pseudo-GIF transparente, respectivamente, estableciendo la variable de entorno TRANSPARENT_COLOR al nombre del color de fondo. Si se usa la opción -T svg o -T cgm, se puede producir un archivo de salida sin fondo estableciendo el color de fondo a "none".
-f tamaño

--font-size tamaño
Establece el tamaño de la fuente inicialmente usada para renderizar texto, como una fracción del ancho de la pantalla gráfica, como tamaño. El valor por defecto es 0.0525.
-F nombre

--font-name nombre
Establece la fuente inicialmente usada para texto como nombre. Los nombres de fuentes no distinguen entre mayúsculas y minúsculas. Si la fuente especificada no está disponible, se usará la fuente por defecto. Qué fuentes están disponibles, y la fuente por defecto, dependen de qué opción -T se especifica (ver arriba). Se puede obtener una lista de fuentes disponibles con la opción --help-fonts (ver abajo).
-W ancho_linea

--line-width ancho_linea
Establece el ancho inicial de las líneas, como una fracción del ancho de la pantalla, como ancho_linea. Un valor negativo significa que se debe usar un valor por defecto. Este valor depende del formato. La interpretación de un ancho de línea cero también depende del formato (en algunos formatos de salida, una línea de ancho cero es la línea más delgada que se puede dibujar; en otros, una línea de ancho cero es invisible).
--pen-color nombre
Establece el color inicial del lápiz como nombre. Un nombre no reconocido establece el color del lápiz al por defecto, que es "black".

Opciones para Salida de Metarchivo

La siguiente opción solo es relevante si se omite la opción -T o si se usa -T meta. En este caso, la salida de plot, al igual que la entrada, estará en formato de metarchivo gráfico GNU.

-O

--portable-output
Emite la versión portable (legible por humanos) del formato de metarchivo GNU, en lugar de la versión binaria (el valor por defecto). El formato de la versión binaria depende de la máquina.

Opciones para Compatibilidad con Versiones Anteriores

Por defecto, plot asume que sus archivos de entrada están en el formato de metarchivo binario o en el formato de metarchivo portable de GNU. Puede especificar que la entrada está, en cambio, en el formato de metarchivo gráfico tradicional de Unix (pre-GNU), que se documenta en plot(5). El formato de metarchivo gráfico tradicional fue producido por versiones pre-GNU de graph(1).

-h

--high-byte-first-input
Se asume que los archivos de entrada están en la versión binaria, `high byte first' del formato de metarchivo tradicional. Esta variante es poco común.
-l

--low-byte-first-input
Se asume que los archivos de entrada están en la versión binaria, `low byte first' del formato de metarchivo tradicional. Esta variante es la más común.
-A

--ascii-input
Se asume que los archivos de entrada están en la variante ASCII (legible por humanos) del formato de metarchivo tradicional. En algunos sistemas Unix más antiguos, esta variante era producida por plottoa(1).

Opciones Informativas

--help
Imprime una lista de opciones de línea de comandos y sale.
--help-fonts
Imprime una tabla de fuentes disponibles y sale. La tabla dependerá del formato de salida especificado con la opción -T. plot -T X, plot -T svg, plot -T ai, plot -T ps, plot -T cgm, y plot -T fig soportan cada uno las 35 fuentes estándar de Postscript. plot -T svg, plot -T pcl, y plot -T hpgl soportan las 45 fuentes estándar PCL 5, y las dos últimas soportan un número de fuentes vectoriales Hewlett-Packard. Los siete soportan un conjunto de 22 fuentes vectoriales Hershey, al igual que plot -T png, plot -T pnm, plot -T gif, plot -T regis, y plot -T tek. plot sin opción -T en principio soporta cualquiera de estas fuentes, ya que su salida debe ser traducida a otros formatos por una invocación posterior de plot.
La utilidad plotfont(1) puede ser usada para obtener un mapa de caracteres de cualquier fuente soportada.
--list-fonts
Similar a --help-fonts, pero lista las fuentes en una sola columna para facilitar el envío a otros programas. Si no se especifica ninguna opción de salida con la opción -T, se lista el conjunto completo de fuentes soportadas.
--version
Imprime el número de versión de plot y el paquete de utilidades de trazado, y sale.

ENTORNO

Las variables de entorno BITMAPSIZE, PAGESIZE, BG_COLOR, EMULATE_COLOR, MAX_LINE_LENGTH y ROTATION sirven como copias de seguridad para las opciones --bitmap-size, --page-size, --bg-color, --emulate-color, --max-line-length, y --rotation, respectivamente. Las variables de entorno restantes son específicas para cada formato de salida individual.

plot -T X, que abre una ventana en una pantalla X Window System y dibuja gráficos en ella, comprueba la variable de entorno DISPLAY. Su valor determinará la pantalla que se utilizará.

plot -T png y plot -T gif, que producen salida en formato PNG y pseudo-GIF respectivamente, se ven afectadas por la variable de entorno INTERLACE. Si su valor es "yes", la salida estará entrelazada. Además, si la variable de entorno TRANSPARENT_COLOR se establece al nombre de un color, ese color se tratará como transparente en la salida.

plot -T pnm, que produce salida en formato portable anymap (PBM/PGM/PPM), se ve afectada por la variable de entorno PNM_PORTABLE. Si su valor es "yes", la salida estará en formato legible por humanos en lugar de binario (el valor por defecto).

NAME

plot - convert graphs to various graphics file formats

SYNOPSIS

plot [-T type] [file...]

DESCRIPTION

The plot utility converts graphs generated by utilities such as graph(1) and spline(1) into a variety of graphics file formats. The output format is specified by the -T option.

OPTIONS

Supported output types include:

-T cgm
CGM (Computer Graphics Metafile) version 3.0, binary encoding (default).
-T hpgl
HP-GL (Hewlett-Packard Graphics Language) suitable for HP7550A, HP758x, HP7595A, HP7596A plotters.
-T pcl
PCL 5 (Printer Control Language) for Hewlett-Packard printers and plotters.
-T tek
Tektronix 4010 format.
-T fig
FIGCGM output, for use with the fig2dev(1) utility.
-T ps
PostScript output.
-T gif
GIF output.
-T png
PNG output.
-T svg
SVG output.
-T canvas
Canvas format, for use with the canvas2ps(1) utility.

ENVIRONMENT

The behavior of plot is affected by several environment variables:

CGM_MAX_VERSION: Controls the version of CGM output. Setting it to "2" or "1" may be done for backward compatibility. The default is "3".

CGM_ENCODING: Controls the encoding of CGM output. If set to "clear_text", human-readable clear text encoding will be used. Otherwise, binary-encoded CGM files (which conform to the WebCGM profile) will be produced.

PCL_ASSIGN_COLORS: Affects plot -T pcl output for color devices. If set to "yes", the output device is given freedom to assign colors internally, ensuring accurate color reproduction. If set to "no", the device uses a fixed set of pens and emulates colors by shading. The default is "no" due to the prevalence of monochrome PCL 5 devices.

HPGL_VERSION: Affects plot -T hpgl output. It can be set to "1", "1.5", or "2" (the default).
"1": Generic HP-GL. Only vector fonts are available, and lines have a default width (-W option is disabled). Filling of arbitrary curves is not supported (except for circles and axis-aligned rectangles).
"1.5": Suitable for HP7550A, HP758x, HP7595A, and HP7596A plotters. Uses HP-GL with some HP-GL/2 extensions. Same font and line width limitations as "1".
"2": Modern HP-GL/2. Supports vector fonts and variable line widths (-W option works). Supports filling of arbitrary curves.

HPGL_ROTATE: Rotates the graphics display 90 degrees counterclockwise for plot -T hpgl. It also repositions the lower-left corner. Accepted values are "no" (equivalent to "0"), "yes" (equivalent to "90"), "180", and "270". Rotations "180" and "270" require HPGL_VERSION to be "2".

HPGL_PENS: Specifies the available pens for plot -T hpgl. The format is a colon-separated list of assignments like "pen_number=color_name".
Default for HPGL_VERSION="1": "1=black".
Default for HPGL_VERSION="1.5" or "2": "1=black:2=red:3=green:4=yellow:5=blue:6=magenta:7=cyan".
Pen #1 must always be present. Colors recognized by the X Window System are supported. Any pen from #1 to #31 can be specified; others may be omitted.

HPGL_ASSIGN_COLORS: Affects plot -T hpgl when HPGL_VERSION is "2". If set to "yes", plot assigns colors to logical pens #1...#31 as needed, not restricted by HPGL_PENS. The default is "no" because few HP-GL/2 devices support this. Color LaserJet printers and DesignJet plotters are exceptions.

HPGL_OPAQUE_MODE: Affects plot -T hpgl when HPGL_VERSION is "2". If set to "yes" (the default), opaque filling and visible white lines (drawn with pen #0) are supported. If set to "no", white lines are not drawn, accommodating older HP-GL/2 devices that may not support opacity or pen #0 for visible lines.

TERM: Affects plot -T tek.
If TERM starts with "xterm", "nxterm", or "kterm", plot assumes it's running in an X Window System VT100 terminal emulator. It emits escape sequences to pop up the Tektronix window before drawing and return control to the VT100 window afterward. The Tektronix window remains visible.
If TERM starts with "kermit", "ansi.sys", or "nansi.sys", plot assumes it's running in the MS-DOS Kermit VT100 emulator. It emits an escape sequence to switch to Tektronix mode, supports limited color (16 'ansi.sys' colors), and uses some Kermit-specific control codes. Afterward, it emits a sequence to return to VT100 mode. The key sequence `ALT minus' can be used manually in Kermit to switch modes.
