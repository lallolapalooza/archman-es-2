PLOTFONT(1) Utilidades de trazado de GNU PLOTFONT(1)

NOMBRE

plotfont - produce mapas de caracteres de las fuentes compatibles con las utilidades de trazado

SINOPSIS

plotfont [ opciones ] fuentes

DESCRIPCIÓN

plotfont produce un mapa de caracteres para cualquier fuente compatible con las utilidades de trazado, que incluyen graph(1), plot(1), pic2plot(1), tek2plot(1) y la biblioteca de exportación de gráficos 2-D GNU libplot (véase plot(3)). Qué fuentes son compatibles depende del formato de salida, que se especifica con la opción -T. Se puede obtener una lista de las fuentes disponibles en cualquier formato de salida especificado con la opción --help-fonts (ver más abajo).

El mapa de caracteres, o mapas, se escribirán en la salida estándar en el formato especificado. Por ejemplo, la fuente Times-Roman está disponible al producir salida Postscript. El comando plotfont -T ps Times-Roman > charmap.ps producirá un mapa de caracteres de la fuente Times-Roman, en un formato Postscript que puede ser visto o editado con el editor de dibujos idraw(1). La fuente Times-Roman también está disponible al producir salida Fig, que puede ser vista o editada con el editor de dibujos xfig(1). El comando plotfont -T fig Times-Roman > charmap.fig producirá el mismo mapa de caracteres, pero en formato Fig en lugar de Postscript.

Como otro ejemplo, la fuente Univers está disponible al producir salida PCL 5. El comando plotfont -T pcl Univers > charmap.pcl producirá un mapa de caracteres de la fuente Univers, en formato PCL 5.

Al producir salida para el Sistema de Ventanas X, es decir, para una ventana emergente, se admiten todas las fuentes escalables del Sistema de Ventanas X que tengan un nombre XLFD (es decir, Descripción Lógica de Fuente X). Por ejemplo, el comando plotfont -T X utopia-medium-r-normal abrirá una ventana y dibujará un mapa de caracteres de la fuente Utopia-Regular. "utopia-medium-r-normal" es una versión truncada del nombre XLFD de la fuente Utopia-Regular. La fuente Utopia-Regular está disponible en la mayoría de las pantallas del Sistema de Ventanas X.

OPCIONES

Opciones Generales

-T tipo

--output-format tipo
Selecciona tipo como formato de salida. Puede ser "X", "png", "pnm", "gif", "svg", "ai", "ps", "cgm", "fig", "pcl", "hpgl", "regis", "tek", o "meta" (el predeterminado). Estos se refieren respectivamente al Sistema de Ventanas X, formato PNG (Portable Network Graphics), formato portable anymap (PBM/PGM/PPM), un formato pseudo-GIF que no utiliza codificación LZW, el nuevo formato Scalable Vector Graphics basado en XML, el formato utilizado por Adobe Illustrator, Postscript o Encapsulated Postscript (EPS) que puede ser editado con idraw(1), formato CGM (por defecto, cumpliendo el perfil WebCGM), el formato utilizado por el editor de dibujos xfig(1), el lenguaje de impresora PCL 5 de Hewlett-Packard, el Lenguaje Gráfico de Hewlett-Packard, formato gráfico ReGIS (que puede ser mostrado por el emulador de terminal dxterm(1) o por una terminal VT330 o VT340), formato Tektronix (que puede ser mostrado por el emulador de terminal xterm(1)), y el formato meta GNU independiente del dispositivo. A menos que tipo sea "X", se produce un archivo de salida y se escribe en la salida estándar.
Los archivos en formato PNG, PNM, pseudo-GIF, AI o Fig contienen solo una página de gráficos. Por lo tanto, si se utiliza la opción -T png, la opción -T pnm, la opción -T gif, la opción -T ai o la opción -T fig, el archivo de salida contendrá un mapa de caracteres solo para la primera fuente especificada.
Se puede obtener una lista de las fuentes disponibles en cualquier formato de salida especificado con la opción --help-fonts (ver más abajo). Si una fuente solicitada no está disponible, se sustituirá una fuente predeterminada. La fuente predeterminada es "Helvetica" para "X", "svg", "ai", "ps", "cgm", y "fig", "Univers" para "pcl", y "HersheySerif" para "png", "pnm", "gif", "hpgl", "regis", "tek", y "meta".
-1

--lower-half
Genera un mapa de caracteres para la mitad inferior de cada fuente especificada. Esta es la opción predeterminada.
-2

--upper-half
Genera un mapa de caracteres para la mitad superior de cada fuente especificada.
-o

--octal
Numera los caracteres en octal en lugar de decimal (el valor predeterminado).
-x

--hexadecimal
Numera los caracteres en hexadecimal en lugar de decimal (el valor predeterminado).
--box
Rodea cada carácter con una caja, mostrando su extensión a izquierda y derecha. El valor predeterminado es no hacerlo.
-j fila

--jis-row fila
Genera un mapa de caracteres para la fila fila de una fuente japonesa dispuesta según JIS [Estándar Industrial Japonés] X0208. La única fuente de este tipo actualmente disponible es la fuente HersheyEUC [Extended Unix Code]. Si se utiliza, esta opción anula las opciones -1 y -2. Las filas válidas son 1...94. En el estándar JIS X0208, los caracteres romanos se encuentran en la fila 3, y los caracteres silábicos japoneses (Hiragana y Katakana) se encuentran en las filas 4 y 5. Los caracteres griegos y cirílicos se encuentran en las filas 6 y 7. Los caracteres ideográficos japoneses (Kanji) se encuentran en las filas 16...84.
--bg-color nombre
Establece el color utilizado para el fondo a nombre. Esto solo es relevante para plotfont -T X, plotfont -T png, plotfont -T pnm, plotfont -T gif, plotfont -T svg, plotfont -T cgm, y plotfont -T regis. Un nombre no reconocido establece el color al predeterminado, que es "white". La variable de entorno BG_COLOR puede usarse igualmente para especificar el color de fondo.
Si se utiliza la opción -T png o -T gif, se puede producir un archivo PNG transparente o un pseudo-GIF transparente, respectivamente, estableciendo la variable de entorno TRANSPARENT_COLOR al nombre del color de fondo. Si se utiliza la opción -T svg o -T cgm, se puede producir un archivo de salida sin fondo estableciendo el color de fondo a "none".
--bitmap-size tamano_mapa_bits
Establece el tamaño de la pantalla gráfica en la que se dibujarán los mapas de caracteres, en píxeles, a tamano_mapa_bits. El valor predeterminado es "570x570". Esto solo es relevante para plotfont -T X, plotfont -T png, plotfont -T pnm, y plotfont -T gif, todos los cuales producen mapas de bits. Si elige un tamaño de ventana rectangular (no cuadrado), las fuentes en los mapas de caracteres se escalarán anisotrópicamente, es decir, por factores diferentes en las direcciones horizontal y vertical. Para plotfont -T X, esto requiere una pantalla X11R6. Cualquier fuente que no pueda ser escalada de esta manera será reemplazada por una fuente escalable predeterminada, como la fuente vectorial "HersheySerif".
La variable de entorno BITMAPSIZE puede usarse igualmente para especificar el tamaño de la ventana. Por compatibilidad retroactiva, el recurso X Xplot.geometry puede usarse en su lugar.
--emulate-color opcion

OPTIONS

If option is yes, replace each color in the output by an appropriate shade of gray. This is seldom useful, except when using plotfont -T pcl to prepare output for a PCL 5 device. (Many monochrome PCL 5 devices, such as monochrome LaserJets, do a poor job of emulating color on their own.) You may equally well request color emulation by setting the environment variable EMULATE_COLOR to "yes".
--numbering-font name
Set the font used for the numbering of the characters in the character map(s) to be name, rather than the default.
--page-size pagesize
Set the size of size of the page on which the character map(s) will be positioned. This is relevant only to plotfont -T svg, plotfont -T ai, plotfont -T ps, plotfont -T cgm, plotfont -T fig, plotfont -T pcl, and plotfont -T hpgl. The default is "letter", which means an 8.5 inch by 11 inch page. Any ISO page size in the range "a0"..."a4" or ANSI page size in the range "a"..."e" may be specified ("letter" is an alias for "a" and "tabloid" is an alias for "b"). "legal" and "ledger" are recognized page sizes also. The environment variable PAGESIZE can equally well be used to specify the page size.
The graphics display in which each character map is drawn will be a square region that would occupy nearly the full width of the specified page. An alternative size for the graphics display can be specified. For example, the page size could be specified as "letter,xsize=4in,ysize=6in", or "a4,xsize=5.0cm,ysize=100mm". For all of the above except plotfont -T hpgl, the graphics display will, by default, be centered on the page. For all of the above except plotfont -T svg and plotfont -T cgm, the graphics display may be repositioned manually, by specifying the location of its lower left corner, relative to the lower left corner of the page. For example, the page size could be specified as "letter,xorigin=2in,yorigin=3in", or "a4,xorigin=0.5cm,yorigin=0.5cm". It is also possible to specify an offset vector. For example, the page size could be specified as "letter,xoffset=1in", or "letter,xoffset=1in,yoffset=1.2in", or "a4,yoffset=-1cm". In SVG format and WebCGM format it is possible to specify the size of the graphics display, but not its position.
--rotation angle
Rotate the graphics display by angle degrees. Recognized values are "0", "90", "180", and "270". "no" and "yes" are equivalent to "0" and "90", respectively. The environment variable ROTATION can also be used to specify a rotation angle.
--pen-color name
Set the pen color to be name. An unrecognized name sets the pen color to the default, which is "black".

Opciones de Salida de Metarchivo

La siguiente opción solo es relevante si se omite la opción -T o si se utiliza -T meta. En este caso, la salida de plotfont estará en formato de metarchivo gráfico de GNU. Puede traducirse a otros formatos invocando plot(1).

-O

--portable-output
Produce la versión portable (legible por humanos) del formato de metarchivo de GNU, en lugar de la versión binaria (la predeterminada). El formato de la versión binaria depende de la máquina.

Opciones Informativas

--help
Imprime una lista de opciones de línea de comandos y sale.
--help-fonts
Imprime una tabla de fuentes disponibles y sale. La tabla dependerá del formato de salida especificado con la opción -T. plotfont -T X, plotfont -T svg, plotfont -T ai, plotfont -T ps, plotfont -T cgm, y plotfont -T fig soportan cada uno las 35 fuentes estándar de Postscript. plotfont -T svg, plotfont -T pcl, y plotfont -T hpgl soportan las 45 fuentes estándar de PCL 5, y las dos últimas soportan un número de fuentes vectoriales de Hewlett-Packard. Los siete soportan un conjunto de 22 fuentes vectoriales de Hershey, al igual que plotfont -T png, plotfont -T pnm, plotfont -T gif, plotfont -T regis, y plotfont -T tek. plotfont sin opción -T en principio soporta cualquiera de estas fuentes, ya que su salida debe ser traducida a otros formatos invocando plot(1).
--list-fonts
Similar a --help-fonts, pero lista las fuentes en una sola columna para facilitar el reenvío a otros programas. Si no se especifica ninguna opción de formato de salida con la opción -T, se lista el conjunto completo de fuentes soportadas.
--version
Imprime el número de versión de plotfont y el paquete de utilidades de trazado, y sale.

ENTORNO

Las variables de entorno BITMAPSIZE, PAGESIZE, BG_COLOR, EMULATE_COLOR, y ROTATION sirven como respaldo para las opciones --bitmap-size, --page-size, --bg-color, --emulate-color, y --rotation, respectivamente. Las variables de entorno restantes son específicas de los formatos de salida individuales.

plotfont -T X, que abre una ventana en una pantalla del sistema X Window para cada mapa de caracteres, verifica la variable de entorno DISPLAY. Su valor determina la pantalla que se utilizará.

plotfont -T png y plotfont -T gif, que producen salida en formato PNG y formato pseudo-GIF respectivamente, se ven afectadas por la variable de entorno INTERLACE. Si su valor es "yes", la salida estará entrelazada. Además, si la variable de entorno TRANSPARENT_COLOR se establece en el nombre de un color, ese color se tratará como transparente en la salida.

plotfont -T pnm, que produce salida en formato portable anymap (PBM/PGM/PPM), se ve afectada por la variable de entorno PNM_PORTABLE. Si su valor es "yes", la salida estará en formato legible por humanos en lugar de binario (la predeterminada).

plotfont -T cgm, que produce salida en formato CGM (Computer Graphics Metafile), se ve afectada por las variables de entorno CGM_MAX_VERSION y CGM_ENCODING. Por defecto, produce una versión codificada en binario del formato CGM versión 3. Para compatibilidad con versiones anteriores, el número de versión puede reducirse estableciendo CGM_MAX_VERSION a "2" o "1". Independientemente de la versión, el archivo CGM de salida utilizará la codificación de texto claro legible por humanos si CGM_ENCODING se establece en "clear_text". Sin embargo, solo los archivos CGM codificados en binario cumplen con el perfil WebCGM.

plotfont -T pcl, que produce salida PCL 5 para impresoras y trazadores Hewlett-Packard, se ve afectada por la variable de entorno PCL_ASSIGN_COLORS. Debe establecerse en "yes" al producir salida PCL 5 para una impresora en color u otro dispositivo en color. Esto asegurará una reproducción precisa del color al dar al dispositivo de salida libertad total para asignar colores, internamente, a sus "bolígrafos lógicos". Si es "no", el dispositivo utilizará un conjunto fijo de bolígrafos de colores y emulará otros colores mediante sombreado. La predeterminada es "no" porque los dispositivos PCL 5 monocromáticos, que son mucho más comunes que los de color, deben usar sombreado para emular el color.

plotfont -T hpgl, que produce salida Hewlett-Packard Graphics Language, se ve afectada por varias variables de entorno. La más importante es HPGL_VERSION, que puede establecerse en "1", "1.5", o "2" (la predeterminada). "1" significa que la salida debe ser HP-GL genérico, "1.5" significa que la salida debe ser adecuada para el trazador gráfico HP7550A y los trazadores de diseño HP758x, HP7595A y HP7596A (HP-GL con algunas extensiones de HP-GL/2), y "2" significa que la salida debe ser HP-GL/2 moderno. Si la versión es "1" o "1.5", las únicas fuentes disponibles serán fuentes vectoriales, y todas las líneas se dibujarán con un ancho predeterminado. Además, si la versión es "1", no se admitirá el relleno de curvas arbitrarias con color sólido (los círculos y rectángulos alineados con los ejes de coordenadas se pueden rellenar, sin embargo).

La posición de la pantalla gráfica de plotfont -T hpgl en la página se puede rotar 90 grados en sentido antihorario estableciendo la variable de entorno HPGL_ROTATE en "yes". Esto no es lo mismo que la rotación obtenida con la opción --rotation, ya que rota la pantalla gráfica y reposiciona su esquina inferior izquierda hacia otra esquina de la página. Además de "no" y "yes", los valores reconocidos para HPGL_ROTATE son "0", "90", "180", y "270". "no" y "yes" son equivalentes a "0" y "90", respectivamente. "180" y "270" solo se soportan si HPGL_VERSION es "2" (la predeterminada).

Por defecto, plotfont -T hpgl dibujará con un conjunto fijo de bolígrafos. Qué bolígrafos están presentes se puede especificar estableciendo la variable de entorno HPGL_PENS. Si HPGL_VERSION es "1", el valor predeterminado de HPGL_PENS es "1=black"; si HPGL_VERSION es "1.5" o "2", el valor predeterminado de HPGL_PENS es "1=black:2=red:3=green:4=yellow:5=blue:6=magenta:7=cyan". El formato debería ser autoexplicativo. Al establecer HPGL_PENS, puede especificar un color para cualquier bolígrafo en el rango #1...#31. Se pueden usar todos los nombres de color reconocidos por el sistema X Window. El bolígrafo #1 siempre debe estar presente, aunque no sea negro. Cualquier otro bolígrafo en el rango #1...#31 puede omitirse.

NAME

plotfont - convert font files to HP-GL/2 or Tektronix format

SYNOPSIS

plotfont [-Tdevice] [-Wwidth] [-Hheight] [-v] [infile]

DESCRIPTION

plotfont converts font files to HP-GL/2 or Tektronix format for use by the `graph' program. The font file is assumed to be in X10 (or later) font file format. Output is written to standard output.

The default output device is `-Ttek'.

OPTIONS

-Tdevice
Specifies the output device. Supported devices are `hpgl' for HP-GL/2, and `tek' for Tektronix. The default is `tek'.
-Wwidth
Specifies the width of the output page in inches. The default is 8.5.
-Hheight
Specifies the height of the output page in inches. The default is 11.
-v
Causes plotfont to print its version number and exit.

ENVIRONMENT

Settings for the output device can also be controlled by environment variables. The relevant environment variables are:

HPGL_PENS
Used only when -T hpgl is specified. This variable contains a comma-separated list of pen colors, e.g., `black,red,blue,green'. Pen 0 is used for white lines (see below). The other pens are assigned to the colors in the list, in order. If more pens are needed than are specified in this list, the colors will be recycled. If the list is empty, all pens will be assigned the color of pen 0. The default value is `black'.
HPGL_VERSION
Used only when -T hpgl is specified. This variable may be set to "1" or "2" to select HP-GL/2 version 1 or version 2 output. Version 2 output is generally preferred. The default value is "2".
HPGL_OPAQUE_MODE
Used only when -T hpgl is specified. If set to "yes" (the default), then filled areas will be opaque, and white lines will be drawn with pen 0. If set to "no", then filled areas will be transparent, and white lines will not be drawn at all. This is to accommodate older HP-GL/2 devices that do not support opacity or use pen 0 for white lines.
HPGL_PEN_ASSIGNMENT
Used only when -T hpgl is specified. If set to "yes", then plotfont -T hpgl will not be restricted to the palette specified in HPGL_PENS: it will assign colors to "logical pens" in the range #1...#31, as needed. The default value is "no" because other than color LaserJet printers and DesignJet plotters, not many HP-GL/2 devices allow the assignment of colors to logical pens.

Opaque filling and the drawing of visible white lines are supported only if HPGL_VERSION is "2" and the environment variable HPGL_OPAQUE_MODE is "yes" (the default). If its value is "no" then white lines (if any), which are normally drawn with pen #0, will not be drawn. This feature is to accommodate older HP-GL/2 devices. HP-GL/2 pen plotters, for example, do not support opacity or the use of pen #0 to draw visible white lines. Some older HP-GL/2 devices may, in fact, malfunction if asked to draw opaque objects.

plotfont -T tek, which produces output for a Tektronix terminal or emulator, checks the TERM environment variable. If the value of TERM is a string beginning with "xterm", "nxterm", or "kterm", it is taken as a sign that plotfont is running in an X Window System VT100 terminal emulator: a copy of xterm(1), nxterm(1), or kterm(1). Before drawing graphics, plotfont -T tek will emit an escape sequence that causes the terminal emulator's auxiliary Tektronix window, which is normally hidden, to pop up. After the graphics are drawn, an escape sequence that returns control to the original VT100 window will be emitted. The Tektronix window will remain on the screen.

If the value of TERM is a string beginning with "kermit", "ansi.sys", or "nansi.sys", it is taken as a sign that plotfont is running in the VT100 terminal emulator provided by the MS-DOS version of kermit(1). Before drawing graphics, plotfont -T tek will emit an escape sequence that switches the terminal emulator to Tektronix mode. Also, some of the Tektronix control codes emitted by plotfont -T tek will be kermit-specific. There will be a limited amount of color support, which is not normally the case (the 16 `ansi.sys' colors will be supported). After drawing graphics, plotfont -T tek will emit an escape sequence that returns the emulator to VT100 mode. The key sequence `ALT minus' can be employed manually within kermit to switch between the two modes.
