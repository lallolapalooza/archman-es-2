NOMBRE

plymouth - Un sistema gráfico de arranque y registrador

DESCRIPCIÓN

plymouth es un sistema gráfico de arranque para Linux que aprovecha el modo de configuración del kernel (KMS) disponible para las tarjetas gráficas modernas para proporcionar una pantalla de arranque fluida, sin parpadeos y atractiva. Permite elegir entre varios temas gráficos, estáticos o animados, para embellecer el inicio y evitar el ruido generado por la gran cantidad de mensajes del kernel mientras la máquina arranca hasta X. En sistemas donde el modo de configuración del kernel no está disponible, plymouth recurre a una pantalla de arranque en modo texto que proporciona una simple barra de progreso para ofrecer retroalimentación durante el arranque.

Para que el tema predeterminado de plymouth configurado se cargue durante el arranque, la opción `splash' (o `rhgb' para compatibilidad con el splash de arranque RHGB) debe proporcionarse en la línea de comandos del kernel. Sin esta opción de línea de comandos, plymouth mostrará por defecto la salida detallada del arranque.

Durante el proceso de arranque, el usuario puede cambiar entre el tema gráfico y la salida detallada del arranque utilizando la tecla Escape.
