PHAR(1) Comandos de usuario PHAR(1)

NOMBRE

phar, phar.phar - Herramienta de línea de comandos PHAR (archivo PHP)

SINOPSIS

phar <comando> [opciones] ...

DESCRIPCIÓN

El formato de archivo PHAR proporciona una forma de poner aplicaciones PHP completas en un solo archivo llamado "phar" (Archivo PHP) para una fácil distribución e instalación.

Con el comando phar puedes crear, actualizar o extraer archivos PHP.

Comandos: add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

comando add

Añadir entradas a un paquete PHAR.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, solo se empaquetarán los archivos que coincidan con la expresión regular dada. Si se da -x, los archivos que coincidan con esa expresión regular NO se empaquetarán.

Argumentos opcionales:

-a alias
Proporciona un nombre de alias para el archivo phar.
-c algoritmo
Algoritmo de compresión (ver COMPRESIÓN )
-i regex
Especifica una expresión regular para los archivos de entrada.
-l nivel
Número de subdirectorios precedentes a eliminar de las entradas de archivo
-x regex
Expresión regular para los archivos de entrada a excluir.

comando compress

Comprimir o descomprimir todos los archivos o una entrada seleccionada.

Argumentos requeridos:

-c algoritmo
Algoritmo de compresión (ver COMPRESIÓN )
-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada en la que trabajar (debe incluir el nombre del directorio interno de PHAR si lo hubiera).

comando delete

Eliminar entrada de un archivo PHAR

Argumentos requeridos:

-e entrada
Nombre de la entrada en la que trabajar (debe incluir el nombre del directorio interno de PHAR si lo hubiera).
-f archivo
Especifica el archivo phar en el que trabajar.

comando extract

Extraer un paquete PHAR a un directorio.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-i regex
Especifica una expresión regular para los archivos de entrada.
-x regex
Expresión regular para los archivos de entrada a excluir.
...
Directorio al que extraer (por defecto '.').

comando help

Esta ayuda o ayuda para un comando seleccionado.

Argumentos opcionales:

...
Comando opcional para obtener ayuda.

comando help-list

Lista los comandos disponibles.

comando info

Obtener información sobre un paquete PHAR.

Usando -k es posible devolver un solo valor.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-k índice
Índice de suscripción en el que trabajar.

comando list

Listar contenido de un archivo PHAR.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-i regex
Especifica una expresión regular para los archivos de entrada.
-x regex
Expresión regular para los archivos de entrada a excluir.

comando meta-del

Eliminar información meta de una entrada PHAR o de un paquete PHAR.

Si se da -k, se espera que los metadatos sean un array y se elimina el índice dado.

Si se eliminó algo, el valor de retorno es 0, de lo contrario es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada en la que trabajar (debe incluir el nombre del directorio interno de PHAR si lo hubiera).
-k índice
Índice de suscripción en el que trabajar.

comando meta-get

Obtener información meta de una entrada PHAR o de un paquete PHAR en formato serializado. Si no se especifica ningún archivo de salida para los metadatos, se usa stdout. También puedes especificar un índice particular con -k. En ese caso, se espera que los metadatos sean un array y se devuelve el valor del índice dado mediante echo en lugar de usar serialize. Si ese índice no existe o no hay metadatos presentes, el valor de retorno es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada en la que trabajar (debe incluir el nombre del directorio interno de PHAR si lo hubiera).
-k índice
Índice de suscripción en el que trabajar.

comando meta-set

Establecer metadatos de una entrada PHAR o de un paquete PHAR utilizando entrada serializada. Si no se especifica ningún archivo de entrada para los metadatos, se usa stdin. También puedes especificar un índice particular con -k. En ese caso, se espera que los metadatos sean un array y se establece el valor del índice dado. Si los metadatos no están presentes o están vacíos, se creará un nuevo array. Si los metadatos están presentes y son un valor plano, el valor de retorno es 1. También, usando -k, la entrada se toma directamente en lugar de ser serializada.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
-m meta
Metadatos a almacenar con la entrada (datos PHP serializados).

Argumentos opcionales:

-e entrada
Nombre de la entrada en la que trabajar (debe incluir el nombre del directorio interno de PHAR si lo hubiera).
-k índice
Índice de suscripción en el que trabajar.

comando pack

Empaquetar archivos en un archivo PHAR.

Cuando se usa -s <stub>, el archivo stub se excluye de la lista de archivos/directorios de entrada. Para crear un archivo que contenga la clase PHP_Archive de PEAR, apunta el argumento -p a PHP/Archive.php.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, solo se empaquetarán los archivos que coincidan con la expresión regular dada. Si se da -x, los archivos que coincidan con esa expresión regular NO se empaquetarán.

Argumentos opcionales:

-a alias
Proporciona un nombre de alias para el archivo phar.
-b bang
Línea hash-bang para iniciar el archivo (por ejemplo, #!/usr/bin/php). La marca hash en sí misma '#!' y el carácter de nueva línea

COMPRESIÓN

Los siguientes algoritmos de compresión están disponibles:

  • GZ (zip)
  • BZ2 (bzip2)
  • XZ (xz)

EJEMPLOS

Para crear un archivo PHAR denominado my_phar.phar con la distribución de archivos de un directorio llamado my_dist:

phar pack -f my_phar.phar my_dist/

Para añadir un archivo llamado my_file.php al archivo my_phar.phar:

phar add -f my_phar.phar my_file.php

Para extraer el contenido de my_phar.phar al directorio actual:

phar extract -f my_phar.phar

Para obtener una lista de todos los comandos disponibles:

phar help-list

Para obtener ayuda sobre el comando `add`:

phar help add

phar

NAME

phar

PHAR Archiver

SYNOPSIS

phar [options] command [command-options]

DESCRIPTION

This program is a command-line utility to create and manage PHAR archives.

add command

Add files to a PHAR archive. If the archive does not exist, it will be created.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-a
Add files using existing metadata.
-c algo
Compression algorithm (see COMPRESSION )
-d files
Add files with metadata.
-i regex
Specifies a regular expression for input files.
-k
Keep all files.
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file.
-x regex
Regular expression for input files to exclude.
-y key
Private key for OpenSSL signing.

compress command

Compress PHAR archive files. You can set the compression algorithm by using the -c argument.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-c algo
Compression algorithm (see COMPRESSION )
-i regex
Specifies a regular expression for input files.
-x regex
Regular expression for input files to exclude.

delete command

Remove files from a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-i regex
Specifies a regular expression for input files.
-x regex
Regular expression for input files to exclude.

extract command

Extract all files from a PHAR archive to a directory.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-e dir
Extraction directory.
-i regex
Specifies a regular expression for input files.
-x regex
Regular expression for input files to exclude.

help command

Display help message.

help-list command

List available commands.

info command

Get information about the PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

list command

List files in a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-i regex
Specifies a regular expression for input files.
-l level
Number of preceding subdirectories to strip from file entries
-x regex
Regular expression for input files to exclude.

meta-del command

Remove metadata from a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-k key
Metadata key to remove.

meta-get command

Get metadata from a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-k key
Metadata key to retrieve.

meta-set command

Set metadata for a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-k key
Metadata key to set.
-v value
Metadata value.

pack command

Create a PHAR archive from a directory or a set of files.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-c algo
Compression algorithm (see COMPRESSION )
-h hash
Selects the hash algorithm (see HASH )
-i regex
Specifies a regular expression for input files.
-l level
Number of preceding subdirectories to strip from file entries
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file.
-x regex
Regular expression for input files to exclude.
-y key
Private key for OpenSSL signing.

sign command

Set signature hash algorithm.

Required arguments:

-f file
Specifies the phar file to work on.
-h hash
Selects the hash algorithm (see HASH )

Optional arguments:

-y key
Private key for OpenSSL signing.

stub-get command

Get the stub of a PHAR file. If no output file is specified as stub then stdout is being used.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-s stub
Select the stub file.

stub-set command

Set the stub of a PHAR file. If no input file is specified as stub then stdin is being used.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-b bang
Hash-bang line to start the archive (e.g. #!/usr/bin/php). The hash mark itself '#!' and the newline character are optional.
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file.

tree command

Get a directory tree for a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-i regex
Specifies a regular expression for input files.
-x regex
Regular expression for input files to exclude.
