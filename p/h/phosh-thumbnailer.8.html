Nombre

phosh-thumbnailer - Servicio D-Bus para crear miniaturas de archivos.

SINOPSIS

phosh-thumbnailer [OPCIÓN…]

DESCRIPCIÓN

phosh-thumbnailer proporciona un servicio D-Bus para crear miniaturas de archivos según el estándar de gestión de miniaturas https://specifications.freedesktop.org/thumbnail-spec/latest/. Consulte ptcli(1) para una forma sencilla de interactuar con este servicio.

-h, --help
Imprime las opciones de ayuda y sale.
-v, --verbose
Imprime información de depuración.
--version
Imprime la versión y sale.

VEA TAMBIÉN

ptcli(1)
