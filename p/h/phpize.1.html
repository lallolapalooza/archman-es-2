NOMBRE

phpize - prepara una extensión de PHP para compilar

SINOPSIS

phpize [opciones]

DESCRIPCIÓN

phpize es un script de shell para preparar una extensión de PHP para compilar.

OPCIONES

--clean
Eliminar todos los archivos creados
--help
Imprime información de uso
--version
-v
Imprime información de la versión de la API
