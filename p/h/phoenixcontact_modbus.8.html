NOMBRE

phoenixcontact_modbus - Driver para Phoenix Contact

SINOPSIS

phoenixcontact_modbus -h

phoenixcontact_modbus -a NOMBRE_DISPOSITIVO [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del driver phoenixcontact_modbus. Para obtener información sobre el driver principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este driver debería soportar el UPS industrial de corriente continua PhoenixContact QUINT-UPS, modelo 2320461 y todos los modelos compatibles. Se puede encontrar más información sobre este UPS en los recursos de Internet a continuación.

phoenixcontact_modbus utiliza el proyecto libmodbus para la implementación de Modbus.

CÓMO CONFIGURAR EL UPS

Nota: este UPS y su manual se refieren a "Low-Batt" (baja batería) como "Evento de apagado".

Necesita el "IFS-RS232-DATACABLE" para comunicarse con el UPS en Linux, ya que el cable IFS-USB no parece ser compatible. Los parámetros de comunicación son: 115200,E,8,1.

También necesita el software UPS-CONF de Windows (gratuito; descárguelo de su sitio web) para configurar las señales y temporizadores del UPS.

1. Ejecute UPS-CONF
2. Vaya a Configuración→Configuración de Hora
3. Elija "retraso de apagado por estado de carga"
4. Elija "Inicio remoto de apagado de PC" en modo de Red y Batería
5. En "Apagado de PC", introduzca el valor máximo (5 minutos)
6. En "Retraso de reinicio de PC", introduzca el tiempo que desea que el UPS deje la salida de energía apagada antes de reiniciar (por ejemplo, 60 segundos), después de que se restablezca la energía de la red.
7. En el UPS, gire el tornillo a la posición "MODO PC"

Configurar de la manera anterior asegura que:

•Cuando se pierde la energía, el UPS calcula constantemente el tiempo de batería restante.
•Cuando el tiempo de batería restante es inferior a 5 minutos (configuración de "Apagado de PC"), activará el evento "Apagado" (visto como LOW-BATT en NUT).
•A partir de ese momento, incluso si se restablece la energía de entrada, el UPS cortará la salida de energía a su carga después de 5 minutos.
•Cuando se restablece la energía de entrada, el UPS restablecerá la salida de energía después de 60 segundos (configuración de "Retraso de reinicio de PC").

Significado de las configuraciones:

•PC-Shutdown (Apagado de PC): ¿Cuánto tiempo antes del corte de salida activará el UPS la señal de "evento de apagado"? El valor máximo es de 5 minutos. Por lo tanto, el PC debería poder apagarse en 5 minutos.
•PC-Restart (Reinicio de PC): ¿Cuánto tiempo retrasar la salida de energía después de que se restablezca la energía? Máximo 60 segundos.

ARGUMENTOS ADICIONALES

Este driver no soporta ninguna configuración opcional.

INSTALACIÓN

Este driver puede no estar compilado por defecto. Puede compilarlo instalando libmodbus y ejecutando configure --with-modbus=yes.

También necesita dar los permisos adecuados al archivo de dispositivo serie local (/dev/ttyS0, por ejemplo) para permitir que el usuario NUT acceda a él.

COMANDOS INSTANTÁNEOS

Este driver no soporta ningún comando instantáneo.

VARIABLES CONFIGURABLES

Las siguientes variables se pueden configurar en la configuración de NUT como valores default.* para anular o monitorizar el comportamiento del UPS utilizando el driver phoenixcontact_modbus.


Nota

A partir de NUT v2.8.4, actualmente no hay soporte para la configuración en tiempo de ejecución de estos valores (por ejemplo, con upsrw(8)). Actualmente solo se consideran una vez, durante la inicialización del driver.

battery.energysave.delay=num

Tiempo después de entrar en modo de batería antes de que se active la señal de apagado del PC por el UPS (en segundos).

ups.timer.shutdown=num

Tiempo permitido para que el PC se apague (en segundos). Máximo 300 segundos.

ups.timer.start=num

Duración durante la cual la salida de energía permanece apagada antes de reiniciar el sistema del PC (en segundos).

ups.delay.start=num

Retraso antes de volver a la red después de que se restablezca la energía (en segundos). El voltaje de la red debe estar dentro del umbral durante este tiempo para iniciar el reinicio automático del PC.

experimental.ups.mode.selector=num

Modo de operación del UPS. Por ejemplo, 9 corresponde a Modo PC (definido por el proveedor).

experimental.battery.warning_soh=num

Umbral de advertencia de batería para Estado de Salud, en porcentaje.

input.voltage.low.critical=num

Voltaje umbral (en V) por debajo del cual el UPS se cambiará a modo de batería.

input.voltage.high.critical=num

Umbral de voltaje (en V) por encima del cual el UPS considerará que la energía de la red se ha restablecido (ver también abajo).

    NOMBRE

    phoenixcontact_modbus - Herramienta de configuración MODBUS RTU de Phoenix Contact

    SINOPSIS

    phoenixcontact_modbus [OPCIONES] <archivo>

    DESCRIPCIÓN

    phoenixcontact_modbus es una herramienta de línea de comandos para configurar dispositivos MODBUS RTU de Phoenix Contact. Permite leer la configuración de un dispositivo, escribir una nueva configuración en él y realizar otras operaciones relacionadas con MODBUS.

    OPCIONES

    <archivo>
    Ruta al archivo de configuración. Si se proporciona, el contenido del archivo se escribirá en el dispositivo. Si no se proporciona, la configuración actual del dispositivo se leerá y se mostrará en la salida estándar.
    -d <dispositivo>
    Especifica el dispositivo serial (por ejemplo, /dev/ttyUSB0). Si no se especifica, se intentará detectar automáticamente.
    -b <velocidad>
    Especifica la velocidad en baudios de la comunicación serial. El valor predeterminado es 9600.
    -p <paridad>
    Especifica la paridad de la comunicación serial. Los valores posibles son 'none', 'even' u 'odd'. El valor predeterminado es 'none'.
    -s <bits_de_parada>
    Especifica el número de bits de parada. Los valores posibles son 1 o 2. El valor predeterminado es 1.
    -a <dirección_esclavo>
    Especifica la dirección del esclavo MODBUS. El valor predeterminado es 1.
    -t <timeout>
    Especifica el tiempo de espera en segundos para las respuestas MODBUS. El valor predeterminado es 5.
    -r
    Lee la configuración del dispositivo y la muestra en la salida estándar. Esta es la acción predeterminada si no se proporciona un archivo de configuración.
    -w
    Escribe la configuración del archivo especificado en el dispositivo. Esta acción solo se realiza si se proporciona un archivo de configuración.
    -h
    Muestra un mensaje de ayuda y sale.

    EJEMPLOS

    Leer la configuración del dispositivo en /dev/ttyUSB0 y guardarla en config.json:

    phoenixcontact_modbus -d /dev/ttyUSB0 -r > config.json

    Escribir la configuración desde config.json en el dispositivo /dev/ttyUSB0 con una velocidad de 19200 baudios y dirección de esclavo 5:

    phoenixcontact_modbus -d /dev/ttyUSB0 -b 19200 -a 5 -w config.json
