NOMBRE

phpdbg - El depurador interactivo de PHP

SINOPSIS

phpdbg [opciones] [archivo] [args...]

DESCRIPCIÓN

phpdbg es una plataforma de depuración ligera, potente y fácil de usar para PHP.

OPCIONES

-c ruta|archivo
Busca el archivo php.ini en el directorio ruta o usa el archivo especificado
-d foo[=bar]
Define la entrada INI foo con el valor bar
-n
No se usará ningún archivo php.ini
-z archivo
Carga la extensión Zend archivo
-q
No imprime el banner al inicio
-v
Habilita la salida del oplog
-b
Deshabilita el uso de colores en la consola
-i ruta|archivo
Anula la ubicación de .phpgdbinit (implica -I)
-I
Ignora .phpdbginit (archivo init por defecto)
-r
Salta directamente a ejecutar
-e
Genera información extendida para el depurador/perfilador
-E
Habilita el paso a través de eval()
-s delimitador
Lee código para ejecutar desde stdin con un delimitador opcional
-S nombre_sapi
Anula el nombre SAPI
-p opcode
Muestra los opcodes y sale
-h
Imprime el resumen de ayuda
-V
Número de versión
args...
Argumentos pasados al script. Usa '--' args cuando el primer argumento comience con '-' o el script se lea desde stdin

NOTAS

Pasar -rr hará que phpdbg salga después de la ejecución, en lugar de volver a la consola

ARCHIVOS

php.ini
El archivo de configuración estándar
.phpdbginit
El archivo de inicialización
