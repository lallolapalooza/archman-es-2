PHAR(1) Comandos de usuario PHAR(1)

NOMBRE

phar, phar.phar - Herramienta de línea de comandos PHAR (archivo PHP)

SINOPSIS

phar <comando> [opciones] ...

DESCRIPCIÓN

El formato de archivo PHAR proporciona una forma de poner aplicaciones PHP completas en un solo archivo llamado "phar" (Archivo PHP) para una fácil distribución e instalación.

Con el comando phar puede crear, actualizar o extraer archivos PHP.

Comandos: add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

comando add

Añade entradas a un paquete PHAR.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, SOLO los archivos que coincidan con la expresión regular dada serán empaquetados. Si se da -x, los archivos que coincidan con esa expresión regular NO serán empaquetados.

Argumentos opcionales:

-a alias
Proporciona un alias para el archivo phar.
-c algoritmo
Algoritmo de compresión (ver COMPRESIÓN )
-i regex
Especifica una expresión regular para los archivos de entrada.
-l nivel
Número de subdirectorios precedentes a eliminar de las entradas de archivo
-x regex
Expresión regular para excluir archivos de entrada.

comando compress

Argumentos requeridos:

-c algoritmo

Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).

Especifica el archivo phar en el que trabajar.

-x regex

...

comando meta-del

Elimina metadatos de una entrada PHAR o un paquete PHAR.

Si se proporciona -k, se espera que los metadatos sean un array y se eliminará el índice dado.

Si algo fue eliminado, el valor de retorno es 0, de lo contrario es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando meta-get

Obtiene metadatos de una entrada PHAR o un paquete PHAR en formato serializado. Si no se especifica un archivo de salida para los metadatos, se utiliza stdout. También puede especificar un índice particular usando -k. En ese caso, se espera que los metadatos sean un array y se devolverá el valor del índice dado mediante `echo` en lugar de usar `serialize`. Si ese índice no existe o no hay metadatos presentes, el valor de retorno es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando meta-set

Establece metadatos de una entrada PHAR o un paquete PHAR utilizando entrada serializada. Si no se especifica un archivo de entrada para los metadatos, se utiliza stdin. También puede especificar un índice particular usando -k. En ese caso, se espera que los metadatos sean un array y se establecerá el valor del índice dado. Si los metadatos no están presentes o están vacíos, se creará un nuevo array. Si los metadatos están presentes y son un valor plano, el valor de retorno es 1. También, al usar -k, la entrada se toma directamente en lugar de ser serializada.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
-m meta
Metadatos a almacenar con la entrada (datos PHP serializados).

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando pack

Empaqueta archivos en un archivo PHAR.

Cuando se usa -s <stub>, el archivo stub se excluye de la lista de archivos/directorios de entrada. Para crear un archivo que contenga la clase PHP_Archive de PEAR, apunte el argumento -p a PHP/Archive.php.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, SOLO los archivos que coincidan con la expresión regular dada serán empaquetados. Si se da -x, los archivos que coincidan con esa expresión regular NO serán empaquetados.

Argumentos opcionales:

-a alias
Proporciona un alias para el archivo phar.
-b bang
Línea hash-bang para iniciar el archivo (por ejemplo, #!/usr/bin/php). La marca de hash en sí '#!' y la nueva línea

comando sign

Firma un archivo PHAR con una clave privada.

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.
-k clave
Archivo de clave privada (por defecto es phar.key).

Argumentos opcionales:

-p contraseña
Contraseña para la clave privada.
-t tipo
Tipo de firma (por defecto es GnuPG).

Argumentos requeridos:

-f archivo
Especifica el archivo phar en el que trabajar.

Argumentos opcionales:

comando version

Muestra la versión de la utilidad phar y la versión de PHP.

COMPRESIÓN

Los siguientes algoritmos de compresión son soportados:

GZ, GZIP, BZIP2, BZ2, COMPRESS, ZLIB, PLAIN.

Nota: La compresión PLAIN no hace nada y solo sirve para fines de demostración. La compresión COMPRESS solo está disponible en sistemas que soportan la librería zlib. El tipo de compresión GZ y GZIP son idénticos. Lo mismo ocurre con BZIP2 y BZ2.

add command

Adds files to the stub.

Required arguments:

-f file
Specifies the phar file to work on.
-a files
List of files to add to the phar archive. You can use wildcards in filenames. The character '*' in filenames is optional.

Optional arguments:

-c algo
Algoritmo de compresión (ver COMPRESION )
-h hash
Selecciona el algoritmo de hash (ver HASH )
-i regex
Especifica una expresión regular para los archivos de entrada.
-l level
Número de subdirectorios precedentes a eliminar de las entradas de archivo
-p loader
Ubicación del archivo de clase PHP_Archive (pear list-files PHP_Archive). Puedes usar '0' o '1' para localizarlo automáticamente usando el comando pear mencionado. Cuando se usa '0', el comando no genera un error si no se puede localizar el archivo de clase. Este switch también agrega código alrededor del stub para que la clase PHP_Archive se registre como envoltorio de stream phar:// si es necesario. Y finalmente, este switch agregará el archivo phar.inc de este paquete y lo cargará para asegurar que la clase Phar esté presente.
-s stub
Selecciona el archivo stub.
-x regex
Expresión regular para excluir archivos de entrada.
-y key
Clave privada para la firma OpenSSL.
