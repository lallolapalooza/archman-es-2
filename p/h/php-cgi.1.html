php-cgi(1)

Paquete: php-cgi

Licencias: PHP-3.01

php(1) Lenguaje de Scripting php(1)

NOMBRE

php - Interfaz de línea de comandos de PHP 'CLI'

php-cgi - Comando de interfaz de puerta de enlace común de PHP 'CGI'

SINOPSIS

php [opciones] [ -f ] archivo [[--] args...]

php [opciones] -r código [[--] args...]

php [opciones] [-B código_inicio] -R código [-E código_fin] [[--] args...]

php [opciones] [-B código_inicio] -F archivo [-E código_fin] [[--] args...]

php [opciones] -- [ args...]

php [opciones] -a

php [opciones] -S dirección:puerto [-t directorio_raíz]

DESCRIPCIÓN

PHP es un lenguaje de scripting de propósito general ampliamente utilizado que es especialmente adecuado para el desarrollo web y puede incrustarse en HTML. Esta es la interfaz de línea de comandos que le permite hacer lo siguiente:

Puede analizar y ejecutar archivos utilizando el parámetro -f seguido del nombre del archivo a ejecutar.

Usando el parámetro -r puede ejecutar directamente código PHP como lo haría dentro de un archivo .php al usar la función eval().

También es posible procesar la entrada estándar línea por línea utilizando el parámetro -R o -F. En este modo, cada línea de entrada separada provoca que el código especificado por -R o el archivo especificado por -F se ejecute. Puede acceder a la línea de entrada a través de $argn. Mientras procesa las líneas de entrada, $argi contiene el número de la línea actual que se está procesando. Además, los parámetros -B y -E se pueden usar para ejecutar código (ver -r) antes y después de que se procesen todas las líneas de entrada, respectivamente. Tenga en cuenta que la entrada se lee desde STDIN y, por lo tanto, leer desde STDIN cambia explícitamente la siguiente línea de entrada o omite líneas de entrada.

PHP también contiene un servidor web integrado para fines de desarrollo de aplicaciones. Al usar la opción -S donde dirección:puerto apunta a una dirección y puerto locales, PHP escuchará las solicitudes HTTP en esa dirección y puerto y servirá archivos desde el directorio de trabajo actual o el directorio_raíz pasado con la opción -t.

Si se proporciona un archivo PHP a la línea de comandos cuando se utiliza el servidor web integrado, se utilizará como script de enrutamiento. Este script se iniciará en cada solicitud HTTP. La salida del script se devuelve al navegador, a menos que el script de enrutamiento devuelva el valor false. En ese caso, el servidor integrado vuelve al comportamiento predeterminado, devolviendo el recurso solicitado tal cual, buscando los archivos relativos al directorio raíz del documento especificado por la opción -t, si se proporciona.

Si no están presentes -r, -f, -B, -R, -F, -E o -S, pero se proporciona un solo parámetro, este se toma como el nombre del archivo a analizar y ejecutar (igual que con -f). Si no hay ningún parámetro presente, se lee y ejecuta la entrada estándar.

--interactive
-a
Ejecutar PHP interactivamente. Esto le permite ingresar fragmentos de código PHP que se ejecutan directamente. Cuando el soporte de lectura de línea está habilitado, puede editar las líneas y también tener soporte de historial.

EJEMPLOS

php -r 'echo "Hola Mundo\n";'
Este comando simplemente escribe el texto "Hola Mundo" en la salida estándar.
php -r 'print_r(gd_info());'
Esto muestra la configuración de su extensión gd. Puede usar esto para verificar fácilmente qué formatos de imagen puede usar. Si tiene algún módulo dinámico, es posible que desee utilizar el mismo archivo ini que utiliza PHP cuando se ejecuta desde su servidor web. Hay más extensiones que tienen una función de este tipo. Para dba use:
php

-r 'print_r(dba_handlers(1));'
php -R 'echo strip_tags($argn)."\n";'
Este comando de PHP elimina las etiquetas HTML línea por línea y muestra el resultado. Para ver cómo funciona, primero puedes mirar el siguiente comando de PHP ´php -d html_errors=1 -i´ que utiliza PHP para mostrar información de configuración formateada en HTML. Si luego combina esos dos ´php ...|php ...´ verás lo que sucede.
php -E 'echo "Líneas: $argi\n";'
Usando este comando de PHP puedes contar las líneas de entrada.
php -R '@$l+=count(file($argn));' -E 'echo "Líneas:$l\n";'
En este ejemplo, PHP espera que cada línea de entrada sea un archivo. Cuenta todas las líneas de los archivos especificados por cada línea de entrada y muestra el resultado resumido. Puedes combinar esto con herramientas como find y cambiar el scriptlet de php.
php -R 'echo "$argn\n"; fgets(STDIN);'
Dado que tienes acceso a STDIN desde -B -R -F y -E, puedes omitir ciertas líneas de entrada con tu código. Pero ten en cuenta que en tales casos $argi solo cuenta las líneas que está procesando php. Habiendo leído esto, adivinarás lo que hace el programa anterior: omitir cada segunda línea de entrada.
