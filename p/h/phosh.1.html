Nombre

phosh - Phosh - Una shell para teléfono

SINOPSIS

phosh [OPCIONES...]

DESCRIPCIÓN

phosh es una shell de Wayland para dispositivos móviles que utiliza tecnologías GNOME.

OPCIONES

-h, --help
Imprime la ayuda y sale.
-U, --unlocked
No iniciar con la pantalla bloqueada.
-L, --locked
Iniciar con la pantalla bloqueada, sin importar qué.
--version
Muestra información de la versión.

CONFIGURACIÓN

phosh se configura a través de GSettings, ver phosh-config(5).

Plugins

Los plugins se configuran a través del esquema gsettings mobi.phosh.plugins y sm.puri.phosh.plugins. La clave lock-screen habilita los plugins en la pantalla de bloqueo, por ejemplo:

gsettings set  sm.puri.phosh.plugins lock-screen "['ticket-box', 'upcoming-events']"

VARIABLES DE ENTORNO

phosh respeta las siguientes variables de entorno con fines de depuración:

•
PHOSH_DEBUG: Una lista de flags separada por comas:
  • always-splash: Usar siempre la pantalla de inicio al iniciar aplicaciones (incluso en modo acoplado)
  • fake-builtin: Simular una pantalla integrada al usar una salida virtual, como en una sesión de Wayland anidada.
  • PHOSH_FAKE_CLOCK: Los valores permitidos son cadenas con formato ISO8601 o now. Establecer esta variable fija el reloj de la shell al valor especificado. Para el formato del reloj, ver g_date_time_new_from_iso8601().
  • G_MESSAGES_DEBUG, G_DEBUG y otras variables de entorno compatibles con glib. https://docs.gtk.org/glib/running.html
  • GTK_DEBUG y otras variables de entorno compatibles con GTK, ver https://docs.gtk.org/gtk3/running.html
