Nombre

phoc.gsettings - Gsettings utilizados por phoc

DESCRIPCIÓN

Phoc utiliza gsettings para la mayor parte de su configuración. Puede usar el comando gsettings(1) para cambiarlos o para obtener detalles sobre la opción. Para obtener más detalles sobre una opción, use gsettings describe, por ejemplo:

gsettings describe sm.puri.phoc auto-maximize

Estos son el esquema y las claves de gsettings que se usan actualmente:

GSettings
