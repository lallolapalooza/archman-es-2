NOMBRE

php-config - obtener información sobre la configuración de PHP y las opciones de compilación

SINOPSIS

php-config [opciones]

DESCRIPCIÓN

php-config es un script de shell simple para obtener información sobre la configuración de PHP instalada.

OPCIONES

--prefix
Directorio prefijo donde está instalado PHP, p.ej. /usr/local
--includes
Lista de opciones -I con todos los archivos de inclusión
--ldflags
Indicadores LD con los que se compiló PHP
--libs
Bibliotecas adicionales con las que se compiló PHP
--man-dir
El directorio prefijo donde se instalan las páginas man
--extension-dir
Directorio donde se buscan las extensiones por defecto
--include-dir
Directorio prefijo donde se instalan los archivos de cabecera por defecto
--lib-dir
Directorio donde se instalan las bibliotecas por defecto
--lib-embed
Nombre de la biblioteca de incrustación de PHP
--php-binary
Ruta completa al binario CLI o CGI de PHP
--php-sapis
Mostrar todos los módulos SAPI disponibles
--configure-options
Opciones de configuración para recrear la configuración de la instalación actual de PHP
--ini-path
Directorio desde el cual PHP lee su archivo de configuración INI (php.ini)
--ini-dir
Directorio desde el cual PHP escanea archivos de configuración INI adicionales
--version
Versión de PHP
--vernum
Versión de PHP como entero
