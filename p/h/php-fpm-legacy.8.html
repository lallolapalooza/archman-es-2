NOMBRE

php-fpm - Gestor de procesos FastCGI de PHP 'PHP-FPM'

SINOPSIS

php-fpm [opciones]

DESCRIPCIÓN

PHP es un lenguaje de scripting de propósito general ampliamente utilizado, especialmente adecuado para el desarrollo web y que puede ser incrustado en HTML. Esta es una variante de PHP que se ejecutará en segundo plano como un demonio, escuchando las solicitudes CGI. La salida se registra en /var/log/php-fpm.log.

La mayoría de las opciones se establecen en el archivo de configuración. El archivo de configuración es /etc/php-legacy/php-fpm.conf. Por defecto, php-fpm responderá a las solicitudes CGI escuchando en el puerto 9000 de http de localhost. Por lo tanto, php-fpm espera que su servidor web reenvíe todas las solicitudes de archivos '.php' al puerto 9000 y usted debe editar el archivo de configuración de su servidor web de manera apropiada.

ARCHIVOS

php-fpm.conf
El archivo de configuración para el demonio php-fpm.
php.ini
El archivo de configuración estándar de php.

EJEMPLOS

Para cualquier sistema unix que use init.d para su gestor de procesos principal, debe usar el script init proporcionado para iniciar y detener el demonio php-fpm.

sudo /etc/init.d/php-fpm start
Para cualquier sistema unix que use systemd para su gestor de procesos principal, debe usar el archivo de unidad proporcionado para iniciar y detener el demonio php-fpm.
sudo systemctl start php-fpm.service
Si su instalación no tiene un script init apropiado, inicie php-fpm sin argumentos. Se iniciará como un demonio (proceso en segundo plano) por defecto. El archivo /var/run/php-fpm.pid determina si php-fpm ya está en funcionamiento. Una vez iniciado, php-fpm responde a varias señales POSIX:
SIGINT,SIGTERM terminación inmediata
SIGQUIT parada con gracia
SIGUSR1 reabrir archivo de registro
SIGUSR2 recarga con gracia de todos los workers + recarga de la configuración/binario de fpm

CONSEJOS

El demonio CGI PHP-FPM funcionará bien con la mayoría de los servidores web populares, incluyendo Apache2, lighttpd y nginx.

    DESCRIPCIÓN

    El script php-fpm-legacy es un script wrapper que permite ejecutar la versión PHP-FPM utilizada por PHP 7.4.

    OPCIONES

    Este script no acepta opciones directas. Utiliza el archivo de configuración de PHP-FPM 7.4 para determinar su comportamiento.

    ARCHIVOS

    /etc/php/7.4/fpm/php-fpm.conf
    Archivo de configuración principal de PHP-FPM 7.4.
    /etc/php/7.4/fpm/pool.d/www.conf
    Archivo de configuración del pool por defecto para PHP-FPM 7.4.

    EJEMPLOS

    Para iniciar PHP-FPM 7.4, simplemente ejecuta:

    sudo systemctl start php7.4-fpm

    Para ver el estado:

    systemctl status php7.4-fpm

    Para detener PHP-FPM 7.4:

    sudo systemctl stop php7.4-fpm

    CONSEJOS

    Asegúrate de que la configuración de tu servidor web (por ejemplo, Nginx o Apache) esté apuntando al socket o puerto correcto de PHP-FPM 7.4 si estás utilizando este script.

    VER TAMBIÉN

    php-fpm(8), php.ini(5), nginx.conf(5), apache2.conf(5)
