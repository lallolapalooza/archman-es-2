Nombre

phosh.gsettings - GSettings utilizados por phosh

DESCRIPCIÓN

Phosh utiliza gsettings para la mayor parte de su configuración. Puedes usar el comando gsettings(1) para cambiarlos o para obtener detalles sobre la opción. Para obtener más detalles sobre una opción, usa gsettings describe, por ejemplo:

gsettings describe mobi.phosh.shell.cell-broadcast enabled

Estos son los esquemas y claves de gsettings actualmente utilizados:

GSettings

Estos gsettings son utilizados por phosh:

•
mobi.phosh.shell.cell-broadcast
•
enabled: Si la recepción de transmisiones de celdas está habilitada
•
sm.puri.phosh
•
app-filter-mode: Filtrado de aplicaciones en la vista general. Esto muestra todas las aplicaciones:
gsettings set sm.puri.phosh app-filter-mode '[]'
  • automatic-high-contrast-threshold: El umbral de brillo para activar el alto contraste automático
  • automatic-high-contrast: Si el alto contraste automático está habilitado
  • enable-suspend: Si la suspensión está habilitada en el menú del sistema:
  • favorites: Lista de aplicaciones favoritas
  • force-adaptive: Lista de IDs de aplicaciones que phosh considera adaptables (para que siempre se muestren):
gsettings set sm.puri.phosh force-adaptive "['chromium.desktop', 'firefox-esr.desktop']"
  • osk-unfold-delay: Cuánto tiempo presionar la pastilla de la barra inferior para que el OSK se despliegue
  • quick-silent: Silencia el dispositivo al presionar Vol- en llamadas entrantes
  • shell-layout: Cómo distribuir los elementos de la interfaz del shell alrededor de los recortes y muescas. device: Automático basado en la configuración del dispositivo, none: Sin diseño automático.
  • wwan-backend: Backend WWan a usar
•
sm.puri.phosh.emergency-calls
•
enabled: Si las llamadas de emergencia están habilitadas. Esto es experimental, por favor comprueba si funciona para tu proveedor / en tu país / para tu tarjeta SIM antes de confiar en ello.
•
sm.puri.phosh.lockscreen
  • require-unlock: Si se requiere desbloqueo mediante contraseña/PIN
  • shuffle-keypad: Mezclar teclas en el teclado numérico
•
sm.puri.phosh.plugins
  • lockscreen: Los plugins de pantalla de bloqueo habilitados
  • quick-settings: La configuración rápida personalizada habilitada
•
sm.puri.phosh.notifications
  • wakeup-screen-categories: Categorías de notificación que activan el despertar de la pantalla
  • wakeup-screen-triggers: Qué propiedades de una notificación activan el despertar de la pantalla
  • wakeup-screen-urgency: La urgencia más baja que activa el despertar de la pantalla (si es a través de wakeup-screen-triggers)
•
sm.puri.phosh.plugins.launcher-box
•
folder
•
sm.puri.phosh.plugins.ticket-box
•
folder: La carpeta que contiene los tickets a presentar en la pantalla de bloqueo.
•
sm.puri.phosh.plugins.upcoming-events
•
days
  • org.gnome.desktop.app-folders.folder: Soporte de carpetas
  • org.gnome.desktop.background: Fondo de pantalla
  • picture-uri
  • picture-uri-dark
  • primary-color
Por ejemplo, para recuperar la vista general "clásica" en negro usa:
gsettings set org.gnome.desktop.background picture-options none
gsettings set org.gnome.desktop.background primary-color '#000000'
•
org.gnome.desktop.interface1
•
show-battery-percentage
•
org.gnome.desktop.media-handling
•
automount
•
org.gnome.desktop.notifications
  • show-banners : Si se muestran banners de notificación
  • show-in-lockscreen : Si las notificaciones deben mostrarse en la pantalla de bloqueo
•
org.gnome.desktop.peripherals.touchscreen: Mapeos de pantalla táctil a salida. Ejemplo para NexDock 360:
gsettings set org.gnome.desktop.peripherals.touchscreen:/org/gnome/desktop/peripherals/touchscreens/27c0:0819/ output "\['Unknown', 'NexDock', '8R33926O00Q'\]"
•
org.gnome.desktop.screensaver:
  • lock-delay
  • lock-enabled
  • picture-uri: Imagen de fondo de pantalla de bloqueo.
  • picture-options: none deshabilita la imagen de la pantalla de bloqueo
•
org.gnome.shell.keybindings
  • toggle-message-tray
  • toggle-overview
