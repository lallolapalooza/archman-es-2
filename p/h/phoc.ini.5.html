Nombre

phoc.ini - Archivo de configuración para phoc

DESCRIPCIÓN

La mayor parte de la configuración de phoc se lee desde GSettings. La salida y la configuración principal se leen desde phoc.ini. El archivo de configuración se busca en el directorio de trabajo actual de phoc. Su ruta también se puede especificar en la línea de comandos mediante la opción -C.

El archivo phoc.ini se compone de múltiples secciones que pueden estar en cualquier orden. Si no se proporcionan valores, se utilizan los valores predeterminados integrados. El propósito principal de phoc.ini es especificar la configuración de salida y los diseños. Cada sección tiene el formato:

[Encabezado de sección]
clave1 = valor1
clave2 = valor2

Las líneas que comienzan con # se consideran comentarios y se ignoran. Los encabezados de sección pueden contener dos puntos, en cuyo caso la parte posterior de los dos puntos especifica el elemento de configuración, por ejemplo:

[salida:DSI-1]

es la sección de configuración para la salida DSI-1.

Los encabezados de sección disponibles son:

  • core: opciones principales
  • output: configuración de salida

Las modificaciones a este archivo requieren un reinicio del compositor para que surtan efecto.

SECCIÓN CORE

La sección principal solo puede aparecer una vez y tiene una única opción:

•
xwayland=[true|immediate|false]: Si se debe habilitar XWayland. Con true XWayland se activa cuando es necesario. immediate lo inicia inmediatamente y false lo desactiva.

SECCIÓN SALIDA

La sección de salida puede aparecer varias veces con diferentes elementos de configuración

[salida:ARTÍCULO]

ARTÍCULO es el nombre del conector DRM como DSI-1 o DP-2 o la marca, modelo y número de serie obtenidos de EDID separados por %: [salida:Marca%El Modelo%Número de serie]. La marca, el modelo y el número de serie se pueden especificar como * para coincidir con cualquier valor. Las opciones de configuración son:

  • enable=[true|false]: Si la salida debe estar habilitada
  • x, y: La posición x e y en el diseño de salida. Esto se puede usar para organizar las salidas. El valor predeterminado es usar el diseño automático (las nuevas salidas se agregan a la derecha del diseño actual).
  • scale: La escala de las salidas. El valor predeterminado auto calcula la escala según el tamaño de la pantalla.
  • rotate: La rotación. Los valores válidos son normal, 90, 180, 270, flipped, flipped-90, flipped-180 y flipped-270. El valor predeterminado es usar la orientación normal.
  • mode: El modo a usar. El modo debe ser un modo válido para esta salida. Consulte, por ejemplo, la salida de wlr-randr. El valor predeterminado es usar el modo preferido de la salida.
  • modeline: Un modo de video personalizado. Esto solo es válido para el backend DRM.
  • scale-filter: Filtro a usar para reducir el tamaño de las texturas. Los valores válidos son bilinear, nearest y auto. Este último selecciona bilinear para escalas fraccionarias y nearest para escalas enteras automáticamente. Si no se establece, se asume auto.
  • drm-panel-orientation: Si es true aplica la orientación del panel leída del conector DRM (si está disponible). Predeterminado a true.
  • phys_width, phys_height: Las dimensiones físicas de la pantalla en mm.
  • adaptive-sync: Si se establece en enabled, habilita la tasa de actualización variable, disabled o ausente la deshabilita.

Ejemplo:

[salida:DSI-1]
scale = 2
[salida:Algún Proveedor%Algún Modelo%*]
scale = 1
rotate = 90
x = 300
