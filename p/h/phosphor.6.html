NOMBRE

phosphor - simula un terminal antiguo con fósforo de larga persistencia

SINOPSIS

phosphor [--display host:display.screen] [--window] [--root] [--window-id number][--install] [--visual visual] [--font font] [--scale int] [--ticks int] [--delay usecs] [--no-cache] [--program command] [--meta] [--esc] [--bs] [--del] [--fps]

DESCRIPCIÓN

El programa phosphor dibuja texto en la pantalla con una fuente pixelada muy grande que se asemeja a una terminal tonta de baja resolución antigua. Los píxeles brillan y se desvanecen como si el fósforo tuviera una persistencia muy larga. También es un emulador de terminal vt100 completamente funcional.

OPCIONES

phosphor acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Esta es la opción por defecto.
--root
Dibuja en la ventana raíz.
--window-id number
Dibuja en la ventana especificada.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--font font-name
La fuente X a utilizar. Phosphor puede tomar cualquier fuente y escalarla para pixelarla. La fuente por defecto es fixed.
--scale int
Cuánto escalar la fuente: en otras palabras, el tamaño en píxeles reales de los píxeles simulados. Por defecto 6.
--ticks int
El número de colores a usar al desvanecerse a negro. Por defecto 20.
--delay usecs
La velocidad del terminal: cuánto esperar entre el dibujo de cada carácter. Por defecto 50000, o aproximadamente 1/20 de segundo.
--cache | --no-cache
Acelera la renderización a expensas de memoria y tiempo de inicio. Por defecto sí.
--pty
Lanza el sub-programa bajo un PTY, para que pueda acceder directamente a la pantalla. Esta es la opción por defecto.
--pipe
Lanza el sub-programa al final de una tubería: no le permitas acceder directamente a la pantalla.
--program sh-command
El comando a ejecutar para generar el texto a mostrar. Esta opción puede ser cualquier cadena aceptable por /bin/sh. El programa se ejecutará al final de un pty o tubería, y cualquier carácter que imprima en stdout se imprimirá en la ventana de phosphor. Los caracteres se imprimirán artificialmente despacio, según la opción --delay mencionada anteriormente. Si el programa finaliza, se lanzará de nuevo después de 5 segundos.

Por ejemplo:

  phosphor --program 'ping 8.8.8.8'
  phosphor --program 'ps -e'
  phosphor --program 'od -txC -w6 /dev/random'
  phosphor --program 'cat /dev/random'
  phosphor --scale 2 --program 'top'
  phosphor --scale 4 --program 'mtr www.kernel.org'
  phosphor --scale 4 --program 'emacs -nw -q -f life'
  phosphor --scale 4 --program 'emacs -nw -q --eval "(hanoi 5)"'
Si tiene instalado el sistema de texto a voz festival(1), puede hacer que lea la pantalla mientras phosphor la imprime: 
  phosphor --program \
      'xscreensaver-text | tee /dev/stderr | festival --tts'
También puede usar phosphor como un reemplazo de baja fidelidad para los emuladores de terminal xterm(1) y gnome-terminal(1): 
   phosphor -delay 0 -program $SHELL
--esc
Cuando el usuario presiona una tecla con las teclas Alt o Meta presionadas, envía primero un carácter ESC. Esta es la opción por defecto.
--meta
Cuando Meta o Alt están presionadas, en lugar de eso, establece el bit más significativo del carácter.
--del
Intercambia Backspace y Delete. Esta es la opción por defecto.
--bs
No intercambia Backspace y Delete.
--fps
Muestra la tasa de fotogramas actual y la carga de la CPU.

EMULACIÓN DE TERMINAL

Por defecto, phosphor asigna un pseudo-tty para que el subproceso se ejecute. Esto tiene el efecto secundario deseable de que el programa podrá usar ioctl(2) para obtener información sobre los parámetros del terminal y el tamaño de la ventana, lo cual muchos programas (como top(1)) necesitan para ejecutarse correctamente. phosphor también establecerá la variable de entorno TERM a vt100 en el proceso hijo.

Cualquier carácter tecleado en la ventana de phosphor se pasará al subproceso. (Tenga en cuenta que esto solo funciona cuando se ejecuta en modo "window", no cuando se ejecuta en modo --root bajo xscreensaver.)

ENTORNO

DISPLAY
para obtener el host y número de pantalla por defecto.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
TERM
para informar al subproceso del tipo de emulación de terminal.

phosphor(6)

NOMBRE

phosphor — Un protector de pantalla de fósforo.

SINOPSIS

phosphor [-root] [-nice priority] [-display display] [-visual visual] [-foreground color] [-background color] [-delay count] [-mode mode] [-speed speed] [-fade fade]

DESCRIPCIÓN

phosphor es un protector de pantalla que simula el efecto de una pantalla de fósforo verde en un CRT antiguo. Los caracteres se escapan de la parte superior de la pantalla, brillan brevemente y luego se desvanecen. Los caracteres y el brillo se generan aleatoriamente.

OPCIONES

phosphor acepta las siguientes opciones:

-root
Dibuja en la ventana raíz.
-nice priority
Establece la prioridad del proceso a priority. El valor predeterminado es 10, lo que significa que el proceso se ejecutará con una prioridad más baja.
-display display
Especifica la pantalla X a utilizar.
-visual visual
Especifica la información visual a utilizar. Consulte xdpyinfo(1) para obtener más detalles.
-foreground color
Especifica el color de primer plano. El valor predeterminado es verde.
-background color
Especifica el color de fondo. El valor predeterminado es negro.
-delay count
Especifica el número de milisegundos entre fotogramas. El valor predeterminado es 20.
-mode mode
Especifica el modo de visualización. Los modos disponibles son:
-random: Los caracteres se generan aleatoriamente.
-scroll: Los caracteres se desplazan de arriba a abajo.
-text string: Muestra la cadena dada.
-speed speed
Especifica la velocidad de las gotas de fósforo. El valor predeterminado es 1.0.
-fade fade
Especifica la velocidad de desvanecimiento de las gotas de fósforo. El valor predeterminado es 0.01.

EMULACIÓN DE TERMINAL

Este programa es un protector de pantalla y no requiere una terminal.

ENTORNO

phosphor utiliza la variable de entorno DISPLAY para determinar la pantalla en la que dibujar.

VER TAMBIÉN
