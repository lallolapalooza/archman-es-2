NOMBRE

photopile - muestra múltiples imágenes en una pila barajada periódicamente

SINOPSIS

photopile [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id numero] [--count int] [--scale factor] [--maxTilt grados] [--titles | --no-titles] [--polaroid | --no-polaroid] [--shadows | --no-shadows] [--font fuente] [--speed ratio] [--duration segundos] [--fps] [--debug] [--wireframe]

DESCRIPCIÓN

Carga varias imágenes aleatorias y las muestra como si estuvieran en una pila aleatoria. La pila se reorganiza periódicamente, con imágenes nuevas entrando y viejas saliendo.

Este programa requiere una tarjeta de video capaz de soportar texturas grandes.

Para especificar el directorio de donde se cargan las imágenes, ejecuta xscreensaver-settings(1) y haz clic en la pestaña "Avanzado".

OPCIONES

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de id (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--count int
Cuántas imágenes mostrar. Predeterminado 7.
--scale factor
Tamaño de las imágenes en relación con el tamaño de la ventana. Predeterminado 0.4.
--maxTilt grados
Desviación máxima de la vertical. Predeterminado 50 grados.
--duration segundos
Cada duración segundos, una de las imágenes será reemplazada por una nueva. Predeterminado 5 segundos.
--speed ratio
Acelera o ralentiza la animación. 0.5 significa la mitad de la velocidad predeterminada; 2.0 significa el doble de velocidad.
--delay numero
Retraso por fotograma, en microsegundos. Predeterminado: 10000 (0.01 segundos.).
--titles | --no-titles
Si se muestran o no los nombres de archivo de las imágenes debajo de ellas. Predeterminado: sí.
--polaroid | --no-polaroid
Si se simulan o no imágenes tomadas con una cámara instantánea. Predeterminado: sí.
--shadows | --no-shadows
Si se dibujan o no imágenes con sombras proyectadas. Predeterminado: no.
--font nombre-fuente
La fuente a utilizar para la pantalla de carga inicial y para los títulos de las imágenes.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.
--debug
Imprime información de depuración en stderr.
--wireframe
Otro modo de depuración.

AMBIENTE

DISPLAY
para obtener el host y número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
