Nombre

phoc - Un compositor Wayland para dispositivos móviles

SINOPSIS

phoc [OPCIONES...]

DESCRIPCIÓN

phoc es un compositor Wayland para dispositivos móviles que utiliza la biblioteca wlroots. A menudo se utiliza con el shell móvil phosh, pero funciona perfectamente por sí solo.

OPCIONES

-h, --help
Imprimir ayuda y salir
-C, --config ARCHIVO
Ruta al archivo de configuración. (por defecto: phoc.ini).
-E, --exec EJECUTABLE
El ejecutable (sesión) que se ejecutará al inicio
--socket
Socket de Wayland en el que escuchar las conexiones de los clientes
-S, --shell
Si se espera que se conecte un shell
-X, --xwayland
Si se iniciará XWayland
--no-xwayland
Si se deshabilitará XWayland
--version
Mostrar información de la versión

CONFIGURACIÓN

La configuración se lee de phoc.ini, hwdb, gsettings y $XDG_STATE_HOME/outputs.gvdb. Para más detalles sobre la configuración de salidas, consulte phoc.ini(5), para detalles sobre la configuración de teclas de activación a través de hwdb consulte gmobile.udev(5), para detalles sobre los gsettings manejados por phoc consulte phoc.gsettings(5). Para detalles sobre los estados de las salidas consulte phoc-outputs-states.

VARIABLES DE ENTORNO

phoc respeta las siguientes variables de entorno:

  • WLR_BACKENDS: Los backends que la biblioteca wlroots debe usar cuando phoc se inicie. Consulte https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md
  • WLR_RENDERER: El renderizador que la biblioteca wlroots debe usar cuando phoc se inicie. Consulte https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md
  • G_MESSAGES_DEBUG, G_DEBUG y otras variables de entorno soportadas por glib. https://docs.gtk.org/glib/running.html
  • PHOC_DEBUG: Lista separada por comas de indicadores de depuración:
  • help: Mostrar una lista de indicadores de depuración disponibles
  • auto-maximize: Maximizar ventanas principales
  • damage-tracking: Depurar seguimiento de daños
  • damage-whole: Dañar toda la salida en cada fotograma
  • no-quit: No salir cuando termina la sesión
  • touch-points: Depurar puntos táctiles
  • layer-shell: Depurar layer-shell
  • cutouts: Depurar recortes y muescas de pantalla
  • disable-animations: Desactivar animaciones
  • force-shell-reveal: Revelar siempre el shell sobre las aplicaciones a pantalla completa
  • ignore-state: Ignorar cualquier estado de salida guardado

PROPIEDADES UDEV

Además de las propiedades udev para las teclas de activación documentadas en gmobile.udev(5), phoc utiliza ID_INPUT_KEYBOARD para identificar teclados de hardware. Puede usar hwdb para anularlas.

INTERFAZ DBUS

phoc permite habilitar y deshabilitar ciertos indicadores de depuración en tiempo de ejecución a través de DBus. Para ver una lista de indicadores disponibles use:

busctl --user introspect mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl

Para alternar indicadores individuales:

busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl TouchPoints b true
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl DamageTracking b true
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl LogDomains as 1 all
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl LogDomains as 2 phoc-seat phoc-layer-surface

Tenga en cuenta que los indicadores no se consideran API estable, por lo que pueden cambiar entre versiones.
