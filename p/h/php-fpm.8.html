PHP-FPM(8) Lenguaje de scripting PHP-FPM(8)

NOMBRE

php-fpm - Gestor de Procesos FastCGI de PHP 'PHP-FPM'

SINOPSIS

php-fpm [opciones]

DESCRIPCIÓN

PHP es un lenguaje de scripting de propósito general muy utilizado que es especialmente adecuado para el desarrollo web y puede incrustarse en HTML. Esta es una variante de PHP que se ejecutará en segundo plano como un demonio, escuchando las solicitudes CGI. La salida se registra en /var/log/php-fpm.log.

La mayoría de las opciones se establecen en el archivo de configuración. El archivo de configuración es /etc/php/php-fpm.conf. Por defecto, php-fpm responderá a las solicitudes CGI que escuchen en localhost, puerto HTTP 9000. Por lo tanto, php-fpm espera que su servidor web reenvíe todas las solicitudes de archivos '.php' al puerto 9000 y debe editar el archivo de configuración de su servidor web en consecuencia.

OPCIONES

-C
No cambiar al directorio del script
--php-ini ruta|archivo
-c ruta|archivo
Buscar el archivo php.ini en el directorio ruta o usar el archivo especificado
--no-php-ini
-n
No se usará ningún archivo php.ini
--define foo[=bar]
-d foo[=bar]
Definir la entrada INI foo con el valor bar
-e
Generar información extendida para depurador/perfilador
--help
-h
Esta ayuda
--info
-i
Información y configuración de PHP
--modules
-m
Mostrar módulos compilados
--version
-v
Número de versión
--prefix ruta
-p
Especificar una ruta de prefijo alternativa (el valor predeterminado es /usr)
--pid archivo
-g
Especificar la ubicación del archivo PID.
--fpm-config archivo
-y
Especificar una ruta alternativa al archivo de configuración del gestor de procesos FastCGI (el valor predeterminado es /etc/php/php-fpm.conf)
--test
-t
Probar el archivo de configuración de FPM y salir. Si se llama dos veces (-tt), la configuración se vuelca antes de salir.
--daemonize
-D
Forzar la ejecución en segundo plano e ignorar la opción daemonize del archivo de configuración.
--nodaemonize
-F
Forzar a permanecer en primer plano e ignorar la opción daemonize del archivo de configuración.
--force-stderr
-O
Forzar la salida a stderr en nodaemonize, incluso si stderr no es una TTY.
--allow-to-run-as-root
-R
Permitir que el pool se ejecute como root (deshabilitado por defecto)

ARCHIVOS

php-fpm.conf
El archivo de configuración para el demonio php-fpm.
php.ini
El archivo de configuración estándar de php.

EJEMPLOS

Para cualquier sistema Unix que utilice init.d para su gestor de procesos principal, debe usar el script de inicio proporcionado para iniciar y detener el demonio php-fpm.

sudo /etc/init.d/php-fpm start
Para cualquier sistema Unix que utilice systemd para su gestor de procesos principal, debe usar el archivo de unidad proporcionado para iniciar y detener el demonio php-fpm.
sudo systemctl start php-fpm.service
Si su instalación no tiene un script de inicio apropiado, lance php-fpm sin argumentos. Se lanzará como un demonio (proceso en segundo plano) por defecto. El archivo /var/run/php-fpm.pid determina si php-fpm ya está en funcionamiento. Una vez iniciado, php-fpm responde a varias señales POSIX:
SIGINT,SIGTERM terminación inmediata
SIGQUIT parada con gracia
SIGUSR1 reabrir archivo de log
SIGUSR2 recarga con gracia de todos los workers + recarga de la conf/binario de fpm

CONSEJOS

El demonio CGI PHP-FPM funcionará bien con la mayoría de los servidores web populares, incluidos Apache2, lighttpd y nginx.
