PHAR(1) Comandos de usuario PHAR(1)

NOMBRE

phar, phar.phar - Herramienta de línea de comandos PHAR (archivo PHP)

SINOPSIS

phar <comando> [opciones] ...

DESCRIPCIÓN

El formato de archivo PHAR proporciona una forma de poner aplicaciones PHP completas en un único archivo llamado "phar" (Archivo PHP) para una fácil distribución e instalación.

Con el comando phar puede crear, actualizar o extraer archivos PHP.

Comandos: add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

comando add

Añadir entradas a un paquete PHAR.

Argumentos requeridos:

-f archivo
Especifica el archivo phar sobre el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, SOLO se empaquetan archivos que coinciden con la expresión regular dada. Si se da -x, los archivos que coinciden con esa expresión regular NO se empaquetan.

Argumentos opcionales:

-a alias
Proporciona un alias para el archivo phar.
-c algoritmo
Algoritmo de compresión (ver COMPRESIÓN)
-i regex
Especifica una expresión regular para los archivos de entrada.
-l nivel
Número de subdirectorios anteriores a eliminar de las entradas de archivo.
-x regex
Expresión regular para excluir archivos de entrada.

comando meta-del

Eliminar metadatos de una entrada PHAR o de un paquete PHAR.

Si se proporciona -k, se espera que los metadatos sean un array y se elimina el índice dado.

Si se eliminó algo, el valor de retorno es 0, de lo contrario es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar sobre el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando meta-get

Obtener metadatos de una entrada PHAR o de un paquete PHAR en formato serializado. Si no se especifica un archivo de salida para los metadatos, se utiliza stdout. También puede especificar un índice particular usando -k. En ese caso, se espera que los metadatos sean un array y se devuelve el valor del índice dado usando echo en lugar de serializar. Si ese índice no existe o no hay metadatos presentes, el valor de retorno es 1.

Argumentos requeridos:

-f archivo
Especifica el archivo phar sobre el que trabajar.

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando meta-set

Establecer metadatos de una entrada PHAR o de un paquete PHAR usando entrada serializada. Si no se especifica un archivo de entrada para los metadatos, se utiliza stdin. También puede especificar un índice particular usando -k. En ese caso, se espera que los metadatos sean un array y se establece el valor del índice dado. Si los metadatos no están presentes o están vacíos, se creará un nuevo array. Si los metadatos están presentes y son un valor plano, el valor de retorno es 1. También, al usar -k, la entrada se toma directamente en lugar de serializarse.

Argumentos requeridos:

-f archivo
Especifica el archivo phar sobre el que trabajar.
-m metadatos
Metadatos a almacenar con la entrada (datos PHP serializados).

Argumentos opcionales:

-e entrada
Nombre de la entrada sobre la que trabajar (debe incluir el nombre del directorio interno de PHAR si existe).
-k índice
Índice de suscripción sobre el que trabajar.

comando pack

Empaquetar archivos en un archivo PHAR.

Cuando se usa -s <stub>, el archivo stub se excluye de la lista de archivos/directorios de entrada. Para crear un archivo que contenga la clase PHP_Archive de PEAR, apunte el argumento -p a PHP/Archive.php.

Argumentos requeridos:

-f archivo
Especifica el archivo phar sobre el que trabajar.
...
Cualquier número de archivos y directorios de entrada. Si se usa -i, SOLO se empaquetan archivos que coinciden con la expresión regular dada. Si se da -x, los archivos que coinciden con esa expresión regular NO se empaquetan.

Argumentos opcionales:

-a alias
Proporciona un alias para el archivo phar.
-b bang
Línea de hash-bang para iniciar el archivo (por ejemplo, #!/usr/bin/php). La marca de hash en sí '#!' y el carácter de nueva línea a

add command

Add files to aphar archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-a
Appends the given files to thephar archive. Without this option the archive is overwritten.
-c algo
Compression algorithm (see COMPRESSION )
-h hash
Selects the hash algorithm (see HASH )
-i regex
Specifies a regular expression for input files.
-l level
Number of preceding subdirectories to strip from file entries
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file.
-x regex
Regular expression for input files to exclude.
-y key
Private key for OpenSSL signing.
