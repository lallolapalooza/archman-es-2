Nombre

phosh-session - Script de inicio de sesión para phosh

SINOPSIS

phosh-session [OPCIONES...]

DESCRIPCIÓN

phosh-session es el script para iniciar phosh incluyendo los componentes requeridos como el compositor Wayland phoc y un teclado en pantalla como stevia o squeekboard. El script raramente es invocado por un usuario, sino activado por un gestor de pantalla o una unidad de systemd. Sin embargo, es perfectamente válido, por ejemplo, iniciar sesión en una tty y ejecutar phosh-session para iniciar phosh y los componentes necesarios.

OPCIONES

-h, --help
Imprimir ayuda y salir
--version
Imprimir versión y salir

ARCHIVOS DE CONFIGURACIÓN

El script de sesión examina los siguientes archivos de configuración:

  • /usr/share/phosh/phoc.ini: Configuración pasada al compositor
  • /etc/phosh/phoc.ini: Se utiliza en lugar del anterior si está presente

VARIABLES DE ENTORNO

phosh-session respeta las siguientes variables de entorno:

•
WLR_BACKENDS: Los backends que la biblioteca wlroots debe usar cuando phoc se inicie. Ver https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md

Para fines de depuración, puede colocar variables de entorno en ~/.phoshdebug, que se lee al inicio de la sesión.
