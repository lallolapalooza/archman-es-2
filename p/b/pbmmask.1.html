NOMBRE

pbmmask - crear un mapa de bits de máscara a partir de un mapa de bits regular

SINOPSIS

pbmmask [-expandir] [archivo pbm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pbmmask lee una imagen PBM como entrada y genera una máscara correspondiente de las áreas de primer plano como otra imagen PBM.

El color que se interpretará como 'fondo' se determina automáticamente. Independientemente de qué color sea el fondo, la máscara será blanca donde esté el fondo y negra donde esté la figura.

Esto le permite hacer un pegado enmascarado como este, para objetos con fondo negro:

    pbmmask obj > objmask
    pnmpaste < dest -and objmask <x> <y> | pnmpaste -or obj <x> <y>

Para objetos con fondo blanco, puede invertirlos o agregar un paso:

    pbmmask obj > objmask
    pnminvert objmask | pnmpaste -and obj 0 0 > blackback
    pnmpaste < dest -and objmask <x> <y> | pnmpaste -or blackback <x> <y>

Tenga en cuenta que esta versión de tres pasos funciona también para objetos con fondos negros, si no le importa el tiempo perdido.

También puede usar máscaras con imágenes en escala de grises y color, usando la herramienta pnmarith. Por ejemplo:

    ppmtopgm obj.ppm | pamditherbw -threshold | pbmmask > objmask.pbm
    pnmarith -multiply dest.ppm objmask.pbm > t1.ppm
    pnminvert objmask.pbm | pnmarith -multiply obj.ppm - > t2.ppm
    pnmarith -add t1.ppm t2.ppm

Una variación interesante de esto es pasar la máscara a través de pnmsmooth antes de usarla. Esto hace que el borde entre las dos imágenes sea menos nítido.

OPCIONES

-expandir
Expande la máscara un píxel hacia afuera de la imagen. Esto es útil si desea un pequeño borde blanco alrededor de su imagen. (Una mejor solución podría ser convertir el programa pbmlife en una herramienta general de autómata celular...)
