PBIBTEX(1) Manual de comandos generales PBIBTEX(1)

NOMBRE

pbibtex, upbibtex - crear una bibliografía (japonesa) para (La)TeX

SINOPSIS

pbibtex [opciones] nombre_auxiliar[.aux]

DESCRIPCIÓN

pBibTeX (pbibtex) es una versión modificada de BibTeX para el manejo del japonés. Ordena las entradas según los puntos de código en EUC-JP. Además, se introduce una nueva función integrada is.kanji.str$ que determina si una entrada está fuera del ASCII.

upBibTeX (upbibtex) es una versión modificada de pBibTeX, que ordena las entradas según los puntos de código en Unicode.

Extensiones a las funciones de estilo bibliográfico

Una nueva función integrada está disponible, y algunas otras funciones se modifican para simplificar el manejo del japonés.

is.kanji.str$
[Nueva característica] Saca el literal superior (cadena) para ver si contiene algún carácter no ASCII. Empuja 1 si contiene al menos uno, 0 si no.
substring$
Modificado para evitar dividir una cadena de caracteres en medio de un carácter multibyte.
text.prefix$
Modificación similar a substring$ descrita anteriormente.
add.period$
Modificado para evitar añadir "." después de puntuaciones japonesas correspondientes a "!", "?" y "." (por ejemplo, U+FF01, U+FF1F, U+3002 y U+FF0E).
format.name$
Modificado para aceptar el espacio ideográfico zenkaku japonés (U+3000) para nombres mostrados en japonés. También modificado para reconocer comas japonesas (U+3001 y U+FF0C) de forma similar a "and" entre nombres.

VER TAMBIÉN

bibtex(1), ptex(1).

AUTORES

La versión japonesa de BibTeX fue desarrollada originalmente por Shouichi Matsui como JBibTeX hasta 1991. Se desarrolló para comportarse de manera consistente con NTT JTeX en el manejo de codificaciones japonesas heredadas. Las documentaciones antiguas jbibtex.pdf, jbtxdoc.tex, jbtxhak.tex (todas disponibles en TeX Live) describen la capacidad de manejo del japonés y algunas notas adicionales de JBibTeX.

El actual (u)pBibTeX es una versión bifurcada de JBibTeX, y ha reemplazado la rutina de conversión de codificación con una compatible con la edición comunitaria de (u)pTeX que utiliza la biblioteca ptexenc. Tenga en cuenta que las descripciones de codificaciones en las antiguas documentaciones j*.pdf (especialmente la Sección 3.3 de jbibtex.pdf, como BIBTERMCODE y BIBFILECODE) ya no son correctas.
