CPBCON

Propósito:

!>
!> CPBCON estima el recíproco del número de condición (en la norma 1)
!> de una matriz Hermitiana compleja definida positiva de banda, utilizando
!> la factorización de Cholesky A = U**H*U o A = L*L**H calculada por
!> CPBTRF.
!>
!> Se obtiene una estimación de norm(inv(A)), y el recíproco del número de
!> condición se calcula como RCOND = 1 / (ANORM * norm(inv(A))).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Factor triangular superior almacenado en AB;
!>          = 'L':  Factor triangular inferior almacenado en AB.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEJO, dimensión (LDAB,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H de la matriz de banda A, almacenado en
!>          las primeras KD+1 filas del array. La j-ésima columna de U o L
!>          se almacena en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM es REAL
!>          La norma 1 (o norma infinito) de la matriz Hermitiana de banda A.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(ANORM * AINVNM), donde AINVNM es una
!>          estimación de la norma 1 de inv(A) calculada en esta rutina.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME

pbcon - pbcon calculates the reciprocal of the condition number of a band matrix and estimates the error of the computed inverse of a band matrix

Detailed Description

This subroutine computes the reciprocal of the condition number of a band matrix that has been factored in the form:

A = UTU if UPLO = 'U', or

A = LLT if UPLO = 'L'.

Here U is a upper triangular band matrix and L is a lower triangular band matrix.

The condition number of A is defined as:

C(A) = norm(A) * norm(inv(A)) ,

where norm(inv(A)) is the 1-norm of the inverse of A.

This subroutine computes RCOND = 1 / C(A) using the Cholesky factorization. ANORM is the 1-norm of the original band matrix A.

PBCO

Purpose:

!>
!> PBCO calculates the reciprocal of the condition number of a band matrix
!> that has been factorized as U'U or LL'.
!>
!> Condition number of A = norm(A) * norm(inv(A)).
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U': Upper triangular factor is stored in AB.
!>          = 'L': Lower triangular factor is stored in AB.
!>

N

!>          N is INTEGER
!>          The order of the band matrix A. N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of super-diagonals of the matrix A if UPLO = 'U',
!>          or the number of sub-diagonals if UPLO = 'L'. KD >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB, N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U'U or A = LL' of the band matrix A, stored in the
!>          first KD+1 rows of the array. The j-th column of U or L is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(kd+1+i-j, j) = U(i,j) for max(1, j-kd) <= i <= j;
!>          if UPLO = 'L', AB(1+i-j, j)    = L(i,j) for j <= i <= min(N, j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB. LDAB >= KD+1.
!>

ANORM

!>          ANORM is DOUBLE PRECISION
!>          The 1-norm (or infinity-norm) of the symmetric band matrix A.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>          The reciprocal of the condition number of A, computed as
!>          RCOND = 1/(ANORM * AINVNM), where AINVNM is an estimate of
!>          the 1-norm of inv(A) computed in this routine.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>
