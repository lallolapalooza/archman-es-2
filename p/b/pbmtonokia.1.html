NOMBRE

pbmtonokia - convierte una imagen PBM a los formatos Nokia Smart Messaging

SINOPSIS

pbmtonokia [ -fmt
{
HEX_NOL,
HEX_NGG,
HEX_NPM,
NOL,
NGG,
NPM
} ] [-net codigodenetwork] [-txt texto] [archivopbm]

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pbmtonokia lee una imagen PBM como entrada y produce un archivo de Nokia Smart Messaging (código hexadecimal, .ngg, .nol, .npm) como salida.

OPCIONES

-fmt
Especifica el formato de salida (por defecto es HEX_NOL).
HEX_NOL
Logo de Operador Nokia como código hexadecimal (subible). Usa la opción -net para especificar el código de red.
HEX_NGG
Gráfico de Grupo Nokia como código hexadecimal (subible).
HEX_NPM
Mensaje de Imagen Nokia como código hexadecimal (subible). Usa la opción -txt para especificar un mensaje de texto opcional.
NOL
Logo de Operador Nokia en formato .nol. Puede ser editado por el Group-Graphic Editor de Kessler Wireless Design ( www.kessler-design.com )
NGG
Gráfico de Grupo Nokia en formato .ngg. Puede ser editado por el Group-Graphic Editor de Kessler Wireless Design ( www.kessler-design.com )
NPM
Mensaje de Imagen Nokia en formato .npm. Puede ser editado por el Picture-Message Editor de Kessler Wireless Design ( www.kessler-design.com )

Esta opción es nueva en Netpbm 10.36 (octubre de 2006).

-net
Especifica el código de red del operador de 6 dígitos hexadecimales para Logos de Operador (El valor predeterminado es 62F210 = D1, Alemania).
-txt
Especifica el mensaje de texto para los Mensajes de Imagen. El tamaño máximo de mensaje de texto permitido por el formato es de 120 caracteres.

El valor predeterminado es sin mensaje de texto.

LIMITACIONES

Este programa actualmente acepta todas las imágenes PBM con hasta 255 filas o hasta 255 columnas. (Los Gráficos de Grupo o Logos de Operador válidos para Nokia pueden tener 72 columnas por 14 filas y 78 columnas por 21 filas; los Mensajes de Imagen válidos para Nokia tienen 72 columnas por 28 filas.) Este programa genera gráficos en blanco y negro, no animados.
