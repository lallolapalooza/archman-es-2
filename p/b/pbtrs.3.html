CPBTRS

Propósito:

!>
!> CPBTRS resuelve un sistema de ecuaciones lineales A*X = B con una matriz
!> de banda Hermitiana positiva definida A utilizando la factorización de
!> Cholesky A = U**H*U o A = L*L**H calculada por CPBTRF.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Factor triangular superior almacenado en AB;
!>          = 'L':  Factor triangular inferior almacenado en AB.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX, dimension (LDAB,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H de la matriz de banda A, almacenado en las
!>          primeras KD+1 filas del array. La j-ésima columna de U o L está
!>          almacenada en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

B

!>          B es un array COMPLEX, dimension (LDB,NRHS)
!>          En la entrada, la matriz del lado derecho B.
!>          En la salida, la matriz solución X.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

pbtrs(3) - LAPACK

NAME

pbtrs — solves a system of linear equations with a band matrix.

SYNOPSIS

 SUBROUTINE SPBTRS(UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO)
  CHARACTER *1 UPLO
  INTEGER N, KD, NRHS, LDAB, LDB, INFO
  REAL AB(LDAB, *), B(LDB, *)

 SUBROUTINE DPBTRS(UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO)
  CHARACTER *1 UPLO
  INTEGER N, KD, NRHS, LDAB, LDB, INFO
  DOUBLE PRECISION AB(LDAB, *), B(LDB, *)

 SUBROUTINE CPBTRS(UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO)
  CHARACTER *1 UPLO
  INTEGER N, KD, NRHS, LDAB, LDB, INFO
  COMPLEX AB(LDAB, *), B(LDB, *)

 SUBROUTINE ZPBTRS(UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO)
  CHARACTER *1 UPLO
  INTEGER N, KD, NRHS, LDAB, LDB, INFO
  DOUBLE COMPLEX AB(LDAB, *), B(LDB, *)

Description

The subroutines `SPBTRS`, `DPBTRS`, `CPBTRS`, and `ZPBTRS` solve a system of linear equations A*X = B for a band matrix A of order N and with K super- or sub- diagonals, using the Cholesky factorization of A computed by PBTRF.

A is assumed to be Hermitian positive definite.

Function Documentation

subroutine spbtrs (character uplo, integer n, integer kd, integer nrhs, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldb, * ) b, integer ldb, integer info)

SPBTRS

Purpose:

!>
!> SPBTRS solves a system of linear equations A*X = B with a real
!> positive definite band matrix A using the Cholesky factorization
!> A = U**T *U or A = L*L**T computed by SPBTRF.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangular factor stored in AB;
!>          = 'L':  Lower triangular factor stored in AB.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**T *U or A = L*L**T of the band matrix A, stored in the
!>          first KD+1 rows of the array.  The j-th column of U or L is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO ='U', AB(kd+1+i-j,j) = U(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO ='L', AB(1+i-j,j)    = L(i,j) for j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
