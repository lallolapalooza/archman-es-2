NOMBRE

pbmupc - crear una imagen PBM de Código Universal de Producto

SINOPSIS

pbmupc

[-s1 | -s2] tipo fabricante producto

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pbmupc genera una imagen de un símbolo de Código Universal de Producto. Los tres argumentos son: un dígito de tipo de producto, un código de fabricante de cinco dígitos y un código de producto de cinco dígitos. Por ejemplo, '0 72890 00011' es el código de Heineken.

Tal como está configurado actualmente, pbmupc produce una imagen de 230 bits de ancho y 175 bits de alto. El tamaño se puede alterar cambiando las definiciones al principio del programa, o ejecutando la salida a través de pamenlarge o pamscale.

OPCIONES

Las opciones -s1 y -s2 seleccionan el estilo de UPC a generar. La opción predeterminada, -s1, se ve más o menos así:

 ||||||||||||||||
 ||||||||||||||||
 ||||||||||||||||
 ||||||||||||||||
0||12345||67890||5

El otro estilo, -s2, coloca el dígito del tipo de producto más arriba y no muestra el dígito de verificación:

 ||||||||||||||||
 ||||||||||||||||
0||||||||||||||||
 ||||||||||||||||
 ||12345||67890||
