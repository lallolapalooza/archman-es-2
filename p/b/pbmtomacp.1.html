NOMBRE

pbmtomacp - convertir una imagen PBM a un archivo MacPaint

SINOPSIS

pbmtomacp [-l izquierda]

[-r derecha]

[-b abajo]

[-t arriba]

[archivo_pbm]

DESCRIPCIÓN

Este programa forma parte de Netpbm(1)

pbmtomacp lee una imagen PBM como entrada y produce un archivo MacPaint como salida.

Si no especifica archivo_pbm, pbmtomacp usa la Entrada Estándar.


El archivo generado es solo la bifurcación de datos de una imagen. Necesitará un programa como mcvert para generar un archivo Macbinary o BinHex que contenga la información necesaria para identificar el archivo como un archivo PNTG para MacOS.

OPCIONES


-l, -r, -b y -t le permiten definir un cuadrado en el archivo pbm que debe ser convertido. Por defecto es el archivo completo. Si el archivo es demasiado grande para un archivo MacPaint, el mapa de bits se recorta para que encaje desde ( izquierda, arriba ).
