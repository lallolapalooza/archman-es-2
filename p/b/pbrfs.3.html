CPBRFS

Propósito:

!>
!> CPBRFS mejora la solución computada de un sistema de ecuaciones lineales
!> cuando la matriz de coeficientes es hermitiana definida positiva
!> y de banda, y proporciona límites de error y estimaciones de error hacia atrás
!> para la solución.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': el triángulo superior de A está almacenado;
!>          = 'L': el triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

AB

!>          AB es array COMPLEX, dimensión (LDAB,N)
!>          El triángulo superior o inferior de la matriz de banda hermitiana A,
!>          almacenado en las primeras KD+1 filas del array. La j-ésima columna
!>          de A está almacenada en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB. LDAB >= KD+1.
!>

AFB

!>          AFB es array COMPLEX, dimensión (LDAFB,N)
!>          El factor triangular U o L de la factorización de Cholesky
!>          A = U**H*U o A = L*L**H de la matriz de banda A, tal como la calcula
!>          CPBTRF, en el mismo formato de almacenamiento que A (ver AB).
!>

LDAFB

!>          LDAFB es INTEGER
!>          La dimensión principal del array AFB. LDAFB >= KD+1.
!>

B

!>          B es array COMPLEX, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es array COMPLEX, dimensión (LDX,NRHS)
!>          En la entrada, la matriz solución X, tal como la calcula CPBTRS.
!>          En la salida, la matriz solución mejorada X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          El límite de error directo estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error relativo componente a componente hacia atrás de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que hace de X(j) una solución exacta).
!>

WORK

!>          WORK es array COMPLEX, dimensión (2*N)
!>

RWORK

!>          RWORK es array REAL, dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Parámetros Internos:

!>  ITMAX es el número máximo de pasos de refinamiento iterativo.
!>

CBPBRFS

Purpose:

!>
!> CBPBRFS improves the computed solution to a system of linear
!> equations when the coefficient matrix is Hermitian positive definite
!> and banded, and provides error bounds and backward error estimates
!> for the solution.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>          The upper or lower triangle of the symmetric band matrix A,
!>          stored in the first KD+1 rows of the array.  The j-th column
!>          of A is stored in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!>

AFB

!>          AFB is COMPLEX array, dimension (LDAFB,N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**H*U or A = L*L**H of the band matrix A as computed by
!>          CPBTRF, in the same storage format as A (see AB).
!>

LDAFB

!>          LDAFB is INTEGER
!>          The leading dimension of the array AFB.  LDAFB >= KD+1.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          The right hand side matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          On entry, the solution matrix X, as computed by CPBTRS.
!>          On exit, the improved solution matrix X.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is COMPLEX array, dimension (3*N)
!>

RWORK

!>          RWORK is REAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

Internal Parameters:

!>  ITMAX is the maximum number of steps of iterative refinement.
!>

SGBRFS

Purpose:

!>
!> SGBRFS improves the computed solution to a system of linear
!> equations A*X = B when the coefficient matrix A is banded, and
!> provides error bounds and backward error estimates for the solution.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper banded part of A is stored;
!>          = 'L':  Lower banded part of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>          The number of subdiagonals of the matrix A. KL >= 0.
!>

KU

!>          KU is INTEGER
!>          The number of superdiagonals of the matrix A. KU >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          The upper or lower banded part of the matrix A, stored column
!>          by column in the manner described by UPLO and options KL and KU.
!>          The next KL rows below the main diagonal contain the subdiagonal
!>          entries. The next KU entries above the main diagonal contain the
!>          superdiagonal entries. More precisely, if UPLO = 'U' the
!>          information content of A is in the set of elements (i,j) such
!>          that max(1,j-KU) <= i <= min(n,j+KL) and KU + 1 <= i-j+KU+1 <= KU+KL+1.
!>          if UPLO = 'L' the information content of A is in the set of
!>          elements (i,j) such that max(1,j-KU) <= i <= min(n,j+KL) and
!>          1 <= i-j+KU+1 <= KL+KU+1.
!>

!>          LDAB is INTEGER
!>          The leading dimension of the array AB. LDAB >= KL + KU + 1.
!>

AFB

!>          AFB is REAL array, dimension (LDAFB,N)

Purpose:

!>
!> DPBTRS solves a system of linear equations with a symmetric positive
!> definite banded coefficient matrix A using the Cholesky factorization
!> computed by DPBTRF.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

TRANSR

!>          TRANSR is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N': A * X = B     (No transpose)
!>          = 'T': A**T * X = B  (Transpose)
!>          = 'C': A**H * X = B  (Conjugate transpose)
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'. KD >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          in the matrices B and X. NRHS >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          On entry, the triangular factor U or L from the Cholesky
!!>          factorization A = U**T*U or A = L*L**T computed by DPBTRF,
!>          stored in the same storage format as A (see AB description
!>          in DPBTRF).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB. LDAB >= KD+1.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          Details of the factorization of the band matrix A.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix of the system to be solved.
!>          On exit, if INFO = 0, B is overwritten by the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>

Purpose:

!>
!> ZGBBRFS improves the computed solution to a system of linear
!> equations A*X = B when the coefficient matrix A is banded, and
!> provides error bounds and backward error estimates for the solution.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper banded part of A is stored;
!>          = 'L':  Lower banded part of A is stored.
!>

N

!>

KL

!>          KL is INTEGER
!>          The number of subdiagonals of the matrix A. KL >= 0.

!>          The number of superdiagonals of the matrix A. KU >= 0.

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

AB

!>          AB is COMPLEX*16 array, dimension (LDAB,N)
!>          The upper or lower banded part of the matrix A, stored column
!>          by column in the manner described by UPLO and options KL and KU.
!>          The next KL rows below the main diagonal contain the subdiagonal
!>          entries. The next KU entries above the main diagonal contain the
!>          superdiagonal entries. More precisely, if UPLO = 'U' the
!>          information content of A is in the set of elements (i,j) such
!>          that max(1,j-KU) <= i <= min(n,j+KL) and KU + 1 <= i-j+KU+1 <= KU+KL+1.
!>          if UPLO = 'L' the information content of A is in the set of
!>          elements (i,j) such that max(1,j-KU) <= i <= min(n,j+KL) and
!>          1 <= i-j+KU+1 <= KL+KU+1.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB. LDAB >= KL + KU + 1.
!>

AFB

!>          AFB is COMPLEX*16 array, dimension (LDAFB,N)
!>          The factors L and U from the factorization A = P*L*U computed by
!>          ZGBTRF, stored in the same format as A.
!>

LDAFB

!>          LDAFB is INTEGER
!>          The leading dimension of the array AFB. LDAFB >= KL + KU + 1.

!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X. LDX >= max(1,N).
!>

FERR

!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
