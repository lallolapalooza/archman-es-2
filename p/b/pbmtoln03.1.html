NOMBRE

pbmtoln03 - convertir imagen PBM a salida Sixel de DEC LN03+

SINOPSIS

pbmtoln03 [-rltbf] archivo_pbm

DESCRIPCIÓN

Este programa es parte de Netpbm(1)

pbmtoln03 lee una imagen PBM como entrada y produce un archivo de salida Sixel DEC LN03+.

OPCIONES

-l nn
Utilizar 'nn' como valor para el margen izquierdo (por defecto 0).
-r nn
Utilizar 'nn' como valor para el margen derecho (por defecto 2400).
-t nn
Utilizar 'nn' como valor para el margen superior (por defecto 0).
-b nn
Utilizar 'nn' como valor para el margen inferior (por defecto 3400).
-f nn
Utilizar 'nn' como valor para la longitud del formulario (por defecto 3400).
