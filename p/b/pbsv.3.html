subrutina cpbsv (character uplo, integer n, integer kd, integer nrhs, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPBSV calcula la solución al sistema de ecuaciones lineales A * X = B para matrices OTHER

Propósito:

!>
!> CPBSV calcula la solución a un sistema de ecuaciones lineales complejas
!>    A * X = B,
!> donde A es una matriz de banda Hermitiana positiva definida de N por N y X
!> e B son matrices de N por NRHS.
!>
!> Se utiliza la descomposición de Cholesky para factorizar A como
!>    A = U**H * U,  si UPLO = 'U', o
!>    A = L * L**H,  si UPLO = 'L',
!> donde U es una matriz de banda triangular superior, y L es una matriz de banda
!> triangular inferior, con el mismo número de superdiagonales o
!> subdiagonales que A.  La forma factorizada de A se utiliza luego para resolver el
!> sistema de ecuaciones A * X = B.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es INTEGER
!>          El número de ecuaciones lineales, es decir, el orden de la
!>          matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de la matriz B.  NRHS >= 0.
!>

AB

!>          AB es un array COMPLEX, de dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras KD+1 filas del array.  La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) para max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(N,j+KD).
!>          Ver más abajo para más detalles.
!>
!>          En la salida, si INFO = 0, el factor triangular U o L de la
!>          factorización de Cholesky A = U**H*U o A = L*L**H de la matriz de banda
!>          A, en el mismo formato de almacenamiento que A.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,NRHS)
!>          En la entrada, la matriz B del lado derecho de N por NRHS.
!>          En la salida, si INFO = 0, la matriz solución X de N por NRHS.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento era ilegal
!>          > 0:  si INFO = i, el menor principal líder de orden i
!>                de A no es positivo, por lo que la factorización no pudo
!>                completarse y la solución no se ha calculado.
!>

!>
!>  El esquema de almacenamiento de banda se ilustra con el siguiente ejemplo, cuando
!>  N = 6, KD = 2, y UPLO = 'U':
!>
!>  En la entrada:                 En la salida:
!>
!>      *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56

!>
!>  En la entrada:                 En la salida:
!>

!>     a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
!>     a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
!>
!>  Los elementos del array marcados con * no son utilizados por la subrutina.
!>

 subroutine zpbsv(JOB, UPLO, N, NRHS, AB, LDAB, B, LDB, INFO) 






zpbsv resuelve el sistema de ecuaciones lineal Ax=B, donde A es una matriz Hermitiana por bloques y por bloques de banda.


zpbsv se puede usar para resolver el sistema de ecuaciones Ax=B:


zpbsv resuelve el sistema de ecuaciones lineal Ax=B donde A es una matriz Hermitiana por bloques y por bloques de banda.


Argumentos:


    

  • JOB CHARACTER*1
      

    • = 'N': la matriz de entrada A no se modifica.
      • 

    • = 'V': la matriz de entrada A se modifica.
      • 

    

    • 

  • UPLO CHARACTER*1
      

    • = 'U': Arriba triangular
      • 

    • = 'L': Abajo triangular
      • 

    

    • 

  • N INTEGER
      

    • El número de bloques.
      • 

    

    • 

  • NRHS INTEGER
      

    • El número de columnas en la matriz B.
      • 

    

    • 

  • AB COMPLEX*16, array, out
      

    • Matriz de banda de bloques de tamaño (LDAB, N).
      • 

    • Los bloques de la matriz de banda A de tamaño (NB, NB) están almacenados en la matriz AB.
      • 

    • Los bloques de la banda principal de A se almacenan en AB(1:NB,1:N).
      • 

    • Los bloques de la primera superdiagonal de A se almacenan en AB(NB+1:2*NB, 1:N-1).
      • 

    • Los bloques de la segunda superdiagonal de A se almacenan en AB(2*NB+1:3*NB, 1:N-2), etc.
      • 

    • Si UPLO = 'U', el contenido de AB por debajo de la primera superdiagonal de bloques es no especificado.
      • 

    • Si UPLO = 'L', el contenido de AB por encima de la primera subdiagonal de bloques es no especificado.
      • 

    

    • 

  • LDAB INTEGER
      

    • El número de filas de la matriz AB. LDAB >= NB.
      • 

    

    • 

  • B COMPLEX*16, array, out
      

    • Matriz de rhs de tamaño (LDB,NRHS).
      • 

    • En la entrada, B contiene el vector de rhs.
      • 

    • En la salida, el contenido de B se sobrescribe con la solución X.
      • 

    

    • 

  • LDB INTEGER
      

    • El número de filas de la matriz B. LDB >= max(N,NB).
      • 

    

    • 

  • INFO INTEGER
      

    • = 0: correcto.
      • 

    • < 0: si INFO = -i, la i-ésima entrada del argumento era ilegal.
      • 

    

    • 



Descripción


Esta rutina devuelve el resultado de aplicar una factorización LU en la matriz A y luego utiliza la factorización para resolver el sistema lineal.


La matriz A es una matriz compleja, Hermitiana, por bloques y de banda, de orden N, donde cada bloque tiene orden NB. La matriz A se representa en formato por bloques y de banda.


Detalles


La matriz AB se define como:


  if UPLO = 'U':
    AB(1:NB, K) contiene los elementos de la diagonal de bloques K de A.
    AB(NB+1:2*NB, K) contiene los elementos de la primera superdiagonal de bloques.
    AB(2*NB+1:3*NB, K) contiene los elementos de la segunda superdiagonal de bloques.
    ...
  if UPLO = 'L':
    AB(NB+1:2*NB, K) contiene los elementos de la subdiagonal de bloques K de A.
    AB(1:NB, K) contiene los elementos de la diagonal de bloques K de A.
    AB(2*NB+1:3*NB, K) contiene los elementos de la segunda subdiagonal de bloques.
    ...

  AB( (k-1)*NB+1 : k*NB, j ) contiene el bloque A( j, j+k-1 ) para k=1, ..., L.

El cálculo para la factorización LU se realiza de la siguiente manera:


  A = P * L * U

donde P es una matriz de permutación, L es una matriz triangular inferior y U es una matriz triangular superior.


El sistema Ax=B se resuelve luego como:


  P * L * U * x = B
  L * U * x = P' * B
  y luego se resuelven las ecuaciones triangulares.


La matriz AB es la matriz de banda de bloques donde se almacena la factorización LU.

  donde k es el índice de la banda (1 para la diagonal, 2 para la super/sub-diagonal, etc.)
  y i es el índice de fila dentro del bloque.
