CPBSTF

Propósito:

!>
!> CPBSTF calcula una factorización de Cholesky dividida de una matriz de banda
!> compleja Hermitiana positiva definida A.
!>
!> Esta subrutina está diseñada para ser utilizada en conjunto con CHBGST.
!>
!> La factorización tiene la forma  A = S**H*S  donde S es una matriz de banda
!> del mismo ancho de banda que A y la siguiente estructura:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> donde U es triangular superior de orden m = (n+kd)/2, y L es triangular
!> inferior de orden n-m.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  El triángulo superior de A está almacenado;
!>          = 'L':  El triángulo inferior de A está almacenado.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array COMPLEJO, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          Hermitiana A, almacenado en las primeras kd+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, si INFO = 0, el factor S de la factorización de Cholesky
!>          dividida A = S**H*S. Ver Detalles Adicionales.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0: si INFO = i, la factorización no pudo completarse,
!>               porque el elemento actualizado a(i,i) fue negativo; la
!>               matriz A no es positiva definida.
!>

NOMBRE

pbstf – librería de LAPACK para la factorización de Cholesky de banda dividida.

SINOPSIS

    character(len=1) :: uplo
    integer :: n, kd, ldab, info

    real :: ab(ldab, *)

    character(len=1) :: uplo
    integer :: n, kd, ldab, info
    complex*16 :: ab(ldab, *)

DESCRIPCIÓN DETALLADA

Las rutinas cpbstf, dpbstf, spbstf y zpbstf calculan una factorización de Cholesky dividida de una matriz de banda simétrica/Hermítica positiva definida.

Estas rutinas están diseñadas para ser utilizadas junto con CHBGST, DHBGST, SHBGST y ZHBGST respectivamente.

La factorización tiene la forma A = S**T * S (para matrices reales) o A = S**H * S (para matrices complejas), donde S es una matriz de banda del mismo ancho de banda que A y tiene la siguiente estructura:

    S = ( U    )
        ( M  L )

donde U es triangular superior de orden m = (n+kd)/2, y L es triangular inferior de orden n-m.

DPBSTF

Propósito:

!>
!> DPBSTF calcula una factorización de Cholesky dividida de una matriz de banda
!> simétrica real positiva definida A.
!>
!> Esta rutina está diseñada para ser utilizada junto con DHBGST.
!>
!> La factorización tiene la forma A = S**T * S donde S es una matriz de banda
!> del mismo ancho de banda que A y la siguiente estructura:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> donde U es triangular superior de orden m = (n+kd)/2, y L es triangular
!> inferior de orden n-m.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': Se almacena el triángulo superior de A;
!>          = 'L': Se almacena el triángulo inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB es array REAL, dimensión (LDAB,N)
!>          En la entrada, el triángulo superior o inferior de la matriz de banda
!>          simétrica A, almacenada en las primeras kd+1 filas del array. La
!>          columna j de A se almacena en la columna j del array AB
!>          como sigue:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>
!>          En la salida, si INFO = 0, el factor S de la factorización de Cholesky
!>          dividida A = S**T * S. Ver Detalles Adicionales.
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión líder del array AB. LDAB >= KD+1.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>          > 0: si INFO = i, la factorización no pudo ser completada,
!>               porque el elemento actualizado a(i,i) fue negativo; la
!>               matriz A no es positiva definida.
