subrutina cpbequ (character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) s, real scond, real amax, integer info)

CPBEQU

Propósito:

!>
!> CPBEQU calcula escalados de filas y columnas destinados a ecualizar una
!> matriz banda Hermítica positiva definida A y a reducir su número de
!> condición (con respecto a la norma dos). S contiene los factores de
!> escala, S(i) = 1/sqrt(A(i,i)), elegidos de tal manera que la matriz
!> escalada B con elementos B(i,j) = S(i)*A(i,j)*S(j) tenga unos en la
!> diagonal. Esta elección de S sitúa el número de condición de B dentro
!> de un factor N del menor número de condición posible sobre todos los
!> escalados diagonales posibles.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  Se almacena la parte triangular superior de A;
!>          = 'L':  Se almacena la parte triangular inferior de A.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es INTEGER
!>          El número de superdiagonales de la matriz A si UPLO = 'U',
!>          o el número de subdiagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB es un array de tipo COMPLEX, de dimensión (LDAB,N)
!>          La parte superior o inferior de la matriz banda Hermítica A,
!>          almacenada en las primeras KD+1 filas del array. La j-ésima
!>          columna de A se almacena en la j-ésima columna del array AB
!>          de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB es INTEGER
!>          La dimensión principal del array A.  LDAB >= KD+1.
!>

S

!>          S es un array de tipo REAL, de dimensión (N)
!>          Si INFO = 0, S contiene los factores de escala para A.
!>

SCOND

!>          SCOND es REAL
!>          Si INFO = 0, S contiene la relación entre el S(i) más pequeño
!>          y el S(i) más grande. Si SCOND >= 0.1 y AMAX no es
!>          demasiado grande ni demasiado pequeño, no merece la pena
!>          escalar con S.
!>

AMAX

!>          AMAX es REAL
!>          Valor absoluto del elemento de matriz más grande. Si AMAX está
!>          muy cerca del desbordamiento o del subdesbordamiento, la
!>          matriz debería ser escalada.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>          > 0:  si INFO = i, el i-ésimo elemento diagonal no es positivo.
!>

NAME

pbequ - equilibration routines for band matrices

SYNOPSIS

Subroutine SPBEQU(UPLO, N, KD, AB, LDAB, S, SCOND, AMAX, INFO)

CHARACTER UPLO
INTEGER N, KD, LDAB, INFO
REAL AB(LDAB, *)
REAL S(*)
REAL SCOND, AMAX

Subroutine ZPBEQU(UPLO, N, KD, AB, LDAB, S, SCOND, AMAX, INFO)

CHARACTER UPLO
INTEGER N, KD, LDAB, INFO
COMPLEX*16 AB(LDAB, *)
DOUBLE PRECISION S(*)
DOUBLE PRECISION SCOND, AMAX

Detailed Description

This routine is called by SPBTRF and ZPBTRF to compute row and column scalings intended to equilibrate a symmetric positive definite band matrix A and reduce its condition number (with respect to the two-norm). S contains the scale factors, S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.

subroutine spbequ (character uplo, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) s, real scond, real amax, integer info)

SPBEQU

Purpose:

!>
!> SPBEQU computes row and column scalings intended to equilibrate a
!> symmetric positive definite band matrix A and reduce its condition
!> number (with respect to the two-norm). S contains the scale factors,
!> S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with
!> elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal. This
!> choice of S puts the condition number of B within a factor N of the
!> smallest possible condition number over all possible diagonal
!> scalings.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangular of A is stored;
!>          = 'L':  Lower triangular of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          The upper or lower triangle of the symmetric band matrix A,
!>          stored in the first KD+1 rows of the array.  The j-th column
!>          of A is stored in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array A.  LDAB >= KD+1.
!>

S

!>          S is REAL array, dimension (N)
!>          If INFO = 0, S contains the scale factors for A.
!>

SCOND

!>          SCOND is REAL
!>          If INFO = 0, S contains the ratio of the smallest S(i) to
!>          the largest S(i).  If SCOND >= 0.1 and AMAX is neither too
!>          large nor too small, it is not worth scaling by S.
!>

AMAX

!>          AMAX is REAL
!>          Absolute value of largest matrix element.  If AMAX is very
!>          close to overflow or very close to underflow, the matrix
!>          should be scaled.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if INFO = i, the i-th diagonal element is nonpositive.
!>
