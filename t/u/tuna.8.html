TUNA(8) System Administration Utilities TUNA(8)

NOMBRE

tuna - programa para ajustar procesos en ejecución

SINOPSIS

tuna [OPCIONES]

DESCRIPCIÓN

Esta página del manual explica el programa tuna. El programa puede utilizarse para cambiar los atributos de los hilos de aplicación y del kernel. tuna puede operar sobre IRQs por nombre o número, y tareas o hilos por ID de proceso o línea de comandos. Las CPUs y los conjuntos de CPUs se pueden especificar por número de CPU o de socket. Los nombres de IRQ y las líneas de comandos de procesos pueden incluir comodines.

tuna puede cambiar la política de planificación, la prioridad del planificador y la afinidad del procesador para procesos e hilos de procesos. tuna también puede cambiar la afinidad del procesador para las interrupciones. Cuando se invoca tuna sin ninguna opción, se inicia en modo de interfaz gráfica. Esta página del manual solo explica las opciones de línea de comandos para tuna.

OPCIONES GLOBALES

-h, --help
Imprime una lista de opciones. tuna saldrá después de esta acción, ignorando el resto de la línea de comandos.
-v, --version
Mostrar versión
-L, --logging=NIVEL-LOG
Registrar detalles de la aplicación en un archivo para el NIVEL-LOG dado
-D, --debug
Imprimir detalles de registro de nivel DEBUG en la consola

tuna cpu_power
uso: tuna-cmd.py cpu_power [-h] (-c LISTA-CPU)

Establece o consulta los estados inactivos (de energía) de todas o una selección de CPUs en la LISTA-CPU. Los modificadores -c se pueden usar para pasar la LISTA-CPU de CPUs sobre las que realizar el comando.

argumentos opcionales:
-h, --help mostrar este mensaje de ayuda y salir
-i, --idle-info Imprimir información general inactiva para las CPUs seleccionadas, incluyendo
valores de índice para ESTADO-INACTIVO.
-s, --status ESTADO-INACTIVO
Imprimir si ESTADO-INACTIVO está habilitado en las CPUs seleccionadas.
-d, --disable ESTADO-INACTIVO
Deshabilitar ESTADO-INACTIVO en las CPUs seleccionadas.
-e, --enable ESTADO-INACTIVO
Habilitar ESTADO-INACTIVO en las CPUs seleccionadas.
-c LISTA-CPU, --cpus LISTA-CPU

tuna priority
uso: tuna-cmd.py priority [-h] -t LISTA-HILOS [POLICY:RTPRIO]

Establece los parámetros del planificador de hilos: POLICY y RTPRIO. POLICY es uno de OTHER, FIFO, RR, o BATCH. Proporcionar POLICY, RTPRIO, o POLICY:RTPRIO separados por ":". Si solo se establece POLICY, la prioridad RT será por defecto 1 si la política es RT, y 0 en caso contrario. Si solo se especifica RTPRIO, la política no se cambiará.

argumentos posicionales:
POLICY:RTPRIO Establece los parámetros del planificador de hilos: POLICY y RTPRIO

argumentos opcionales:
-h, --help mostrar este mensaje de ayuda y salir

LISTA-HILOS afectada por los comandos

NAME

tuna - Tune, and modify thread and IRQ affinities

SYNOPSIS

tuna [GLOBAL OPTIONS] COMMAND [COMMAND OPTIONS]

DESCRIPTION

The tuna utility is used to identify and modify thread and IRQ affinities.

GLOBAL OPTIONS

-h, --help
Show help message.
-L, --load

Load default profiles. Tuna can pre-load profiles that describe some common system configurations. This option loads them all.

-p, --profile=PROFILENAME

Load profile PROFILENAME.

-v, --verbose

Enable verbose output.

-C, --no-cgroups

Do not use cgroups to manage threads. This is the default.

-P, --perf

Use perf to gather thread information.

USAGE EXAMPLES

If for instance the Ethernet NICs have multiple queues for both receive and transmit, each with its own IRQ, the Ethernet IRQs can be associated with a CPU socket:

tuna isolate -S 2
tuna spread -q 'eth*' -S 2

Move everything off the CPUs in socket 2, then spread the IRQs for the Ethernet devices across those same CPUs.
