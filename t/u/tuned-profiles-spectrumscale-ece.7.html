NOMBRE

tuned-profiles-spectrumscale-ece - descripción de los perfiles proporcionados para Spectrum Scale Erasure Code Edition

DESCRIPCIÓN

Estos perfiles se proporcionan para servidores Spectrum Scale Erasure Code Edition.

PERFILES

Se proporcionan los siguientes perfiles:

spectrumscale-ece
Perfil optimizado para Spectrum Scale Erasure Code Edition basado en el perfil throughput-performance. Adicionalmente habilita el balanceo NUMA automático y modifica otros parámetros del kernel relacionados con el rendimiento.
