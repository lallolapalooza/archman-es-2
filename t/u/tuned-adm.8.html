NOMBRE

tuned-adm - herramienta de línea de comandos para cambiar entre diferentes perfiles de ajuste

SINOPSIS

tuned-adm [list | active | profile [perfil]... | profile_info [perfil]... | off | auto_profile | profile_mode | verify [-i | --ignore-missing] | recommend | instance_acquire_devices dispositivos instancia | get_instances [plugin] | instance_get_devices instancia]

DESCRIPCIÓN

Esta utilidad de línea de comandos te permite cambiar entre perfiles de ajuste definibles por el usuario. Varios perfiles predefinidos ya están incluidos. Incluso puedes crear tu propio perfil, ya sea basándote en uno de los existentes copiándolo o creando uno completamente nuevo. Los perfiles proporcionados por la distribución se almacenan en subdirectorios debajo de /usr/lib/tuned/profiles/ y los perfiles definidos por el usuario en subdirectorios debajo de /etc/tuned/profiles/. Si existen perfiles con el mismo nombre en ambos lugares, los perfiles definidos por el usuario tienen precedencia.

OPCIONES

list
Listar todos los perfiles disponibles.
profiles Listar todos los perfiles disponibles.

plugins Listar todos los plugins disponibles.

-v, --verbose Listar las opciones de configuración del plugin y sus indicaciones.

active
Mostrar el perfil activo actual.
profile [NOMBRE_PERFIL]...
Cambia al perfil dado. Si se dan varios perfiles, los perfiles se fusionan (en caso de configuraciones conflictivas, se usa la configuración del último perfil) y se aplica el perfil resultante. Si no se proporciona ningún perfil, se listan todos los perfiles disponibles. Si el perfil dado no es válido, el comando sale limpiamente sin realizar ninguna operación.
profile_info [NOMBRE_PERFIL]...
Mostrar información/descripción del perfil dado o del perfil actual si no se especifica ningún perfil.
verify [-i | --ignore-missing]
Verifica el perfil actual contra la configuración del sistema. Muestra información sobre si la configuración del sistema coincide o no con el perfil actual (por ejemplo, si alguien modificó un valor sysfs/sysctl manualmente). La información detallada sobre lo que se comprueba, qué valor se establece y qué valor se espera se puede encontrar en el registro. Con -i o --ignore-missing no trata el ajuste faltante (ajuste no soportado por la plataforma) como un error.
recommend
Recomienda un perfil adecuado para tu sistema. Actualmente solo se implementa la detección estática: decide según los datos en /etc/system-release-cpe y la salida de virt-what. Las reglas para la autodetcción se definen en el archivo /usr/lib/tuned/recommend.d/50-tuned.conf. Las reglas predeterminadas recomiendan perfiles dirigidos al mejor rendimiento, o el perfil equilibrado si no está seguro.

Las reglas predeterminadas pueden ser anuladas por el usuario colocando un archivo llamado recommend.conf en /etc/tuned, o creando un archivo en el directorio /etc/tuned/recommend.d. El archivo /etc/tuned/recommend.conf se evalúa primero. Si no se encuentra ninguna coincidencia, los archivos en el directorio /etc/tuned/recommend.d se fusionan con los archivos en el directorio /usr/lib/tuned/recommend.d (si hay un archivo con el mismo nombre en ambos directorios, se usa el de /etc/tuned/recommend.d) y los archivos se evalúan en orden alfabético. Se utiliza la primera coincidencia.

auto_profile
Habilita el modo de selección automática de perfil, cambia al perfil recomendado.
profile_mode
Muestra el modo de selección de perfil actual.
instance_acquire_devices dispositivos instancia
Mueve todos los dispositivos proporcionados bajo la instancia de plugin dada. La instancia del plugin se identifica usando su nombre del perfil de TuneD.

Los dispositivos se especifican usando una lista separada por comas. Al mover un conjunto de CPUs, es posible usar la sintaxis de lista de CPUs incluyendo el prefijo 'cpulist:'. Por ejemplo, 'cpulist:0,2-4' moverá los dispositivos cpu0, cpu1, cpu2 y cpu4.

get_instances [plugin]
Lista las instancias activas de un plugin dado o todas las instancias activas si no se especifica ningún plugin.
instance_get_devices instancia
Lista los dispositivos asignados actualmente a una instancia dada.
off
Descarga los ajustes.
