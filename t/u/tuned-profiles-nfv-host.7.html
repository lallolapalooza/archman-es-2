NOMBRE

tuned-profiles-nfv-host - descripción del perfil proporcionado para el host NFV

DESCRIPCIÓN

El perfil se proporciona para el host de Virtualización de Funciones de Red (NFV).

PERFILES

Se proporciona el siguiente perfil:

realtime-virtual-host
Perfil optimizado para hosts virtuales basado en el perfil en tiempo real.
