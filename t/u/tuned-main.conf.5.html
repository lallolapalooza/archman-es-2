tuned-main.conf(5) Descripción del formato del archivo tuned-main.conf tuned-main.conf(5)

NOMBRE

tuned-main.conf - Archivo de configuración global de TuneD

SINOPSIS

/etc/tuned/tuned-main.conf

DESCRIPCIÓN

Esta página del manual documenta el formato del archivo de configuración global de TuneD. El archivo tuned-main.conf utiliza el formato de archivo ini.

daemon=BOOL
Esto define si TuneD usará el demonio o no. Es un valor booleano. Puede ser True o 1 si el demonio está habilitado y False o 0 si está deshabilitado. No se recomienda deshabilitar el demonio, ya que muchas funciones no funcionarán sin él, por ejemplo, no habrá D-Bus, ni retroceso de configuraciones, ni soporte para hotplug, ni ajuste dinámico, etc.
dynamic_tuning=BOOL
Esto define si el ajuste dinámico está habilitado. Es un valor booleano. Puede ser True o 1 si el ajuste dinámico está habilitado y False o 0 si está deshabilitado. En ese caso, solo se utilizará el ajuste estático. Tenga en cuenta que si está habilitado aquí, aún es posible deshabilitarlo individualmente en los plugins. Solo es aplicable si daemon está habilitado.
sleep_interval=INT
El demonio de TuneD se activa periódicamente después de INT segundos y comprueba si hay eventos. Por defecto, se establece en 1 segundo. Si tiene un intérprete de Python 2 con el parche aplicado del Red Hat Bugzilla #917709, esto controla el tiempo de respuesta de TuneD a los comandos (es decir, si solicita un cambio de perfil, puede pasar hasta 1 segundo hasta que TuneD reaccione). Aumente este número para tiempos de respuesta más altos y mayores ahorros de energía (debido a un menor número de activaciones). En caso de tener un intérprete de Python 2 sin parchear, esta configuración no tendrá ningún efecto visible, ya que el intérprete consultará 20 veces por segundo. Solo es aplicable si daemon está habilitado.
update_interval=INT
Intervalo de actualización para el ajuste dinámico (en segundos). El demonio de TuneD se activa periódicamente después de INT segundos, actualiza sus monitores, calcula nuevos parámetros de ajuste para los plugins habilitados y aplica los cambios. Los plugins que han deshabilitado el ajuste dinámico no se procesan. Por defecto, INT se establece en 10 segundos. El demonio de TuneD no se activa periódicamente si el ajuste dinámico está globalmente deshabilitado (ver dynamic_tuning) o si esta configuración se establece en 0. Esto debe ser un múltiplo de sleep_interval. Solo es aplicable si daemon está habilitado.
recommend_command=BOOL
Esto controla si la funcionalidad de recomendación estará habilitada o no. Es un valor booleano. Puede ser True o 1 si el comando recommend está habilitado y False o 0 si está deshabilitado. Si está deshabilitado, el comando recommend no estará disponible en la CLI, TuneD no analizará recommend.conf y devolverá un perfil codificado (por defecto balanced). Solo es aplicable si daemon está habilitado. Por defecto está establecido en True.
reapply_sysctl=BOOL
Esto controla si se volverán a aplicar las configuraciones de sysctl de /run/sysctl.d/*.conf, /etc/sysctl.d/*.conf y /etc/sysctl.conf después de aplicar las configuraciones de sysctl de TuneD. Estas son las ubicaciones compatibles con sysctl --system, excluyendo aquellas que contienen archivos de configuración de sysctl proporcionados por paquetes del sistema. Por lo tanto, si reapply_sysctl está establecido en True o 1, las configuraciones de sysctl de TuneD no anularán las configuraciones de sysctl proporcionadas por el usuario. Si está establecido en False o 0, las configuraciones de sysctl de TuneD anularán las configuraciones de sysctl del sistema. Por defecto está establecido en True.
default_instance_priority=INT
Prioridad predeterminada de la instancia (unidad). Por defecto es 0. Cada unidad tiene una prioridad que por defecto está preestablecida en INT. Puede ser anulada en el perfil de TuneD por la opción priority. Las unidades de TuneD se procesan en el orden definido por sus prioridades, es decir, la unidad con el número más bajo se procesa primero.

EJEMPLO

  no_daemon = 0
  dynamic_tuning = 1
  sleep_interval = 1
  update_interval = 10
  recommend_command = 0
  reapply_sysctl = 1
  default_instance_priority = 0
