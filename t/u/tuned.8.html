tuned(8) Demonio de ajuste de sistema adaptable tuned(8)

NOMBRE

TuneD - Demonio de ajuste de sistema adaptativo dinámico

SINOPSIS

tuned [opciones]

DESCRIPCIÓN

tuned es un demonio de ajuste de sistema adaptativo dinámico que ajusta la configuración del sistema dinámicamente según el uso.

OPCIONES

-d, --daemon
Esta opción inicia tuned como un demonio, en lugar de en primer plano sin bifurcarse al inicio.
-D, --debug
Establece el nivel de registro más alto. Esto podría ser muy útil cuando se tienen problemas con tuned.
-h, --help
Muestra esta ayuda.
-l [LOG], --log[=LOG]
Registra en el archivo LOG. Si no se especifica ningún archivo LOG, se utiliza /var/log/tuned/tuned.log.
--no-dbus
No se conecta a DBus.
-P [PID], --pid[=PID]
Escribe el ID del proceso en el archivo PID. Si no se especifica ningún archivo PID, se utiliza /run/tuned/tuned.pid.
-p PERFIL, --profile PERFIL
Perfil de ajuste que se activará. Sobrescribirá otras configuraciones (por ejemplo, de tuned-adm). Esto está destinado a fines de depuración.
-v, --version
Muestra información de la versión.

ARCHIVOS

/etc/tuned

VER TAMBIÉN
