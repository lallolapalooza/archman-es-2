NOMBRE

tuned-profiles-postgresql - descripción de los perfiles proporcionados para PostgreSQL Server

DESCRIPCIÓN

Estos perfiles se proporcionan para el servidor de bases de datos PostgreSQL.

PERFILES

Se proporcionan los siguientes perfiles:

postgresql
Perfil optimizado para bases de datos PostgreSQL basado en el perfil de rendimiento de rendimiento (throughput-performance). Adicionalmente deshabilita las páginas gigantes transparentes y modifica algunos otros parámetros del kernel relacionados con el rendimiento.

ARCHIVOS

/etc/tuned/*
/usr/lib/tuned/*
