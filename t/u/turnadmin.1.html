turnadmin(1)

Paquete: coturn

TURN(1) TURN(1)

INFORMACIÓN GENERAL

turnadmin es una herramienta de administración de TURN. Esta herramienta se puede utilizar para administrar cuentas de usuario (agregar/eliminar usuarios, generar claves TURN para los usuarios). Por razones de seguridad, no recomendamos almacenar contraseñas de forma abierta. La mejor opción es utilizar "claves" preprocesadas que luego se utilizan para la autenticación. Estas claves son generadas por turnadmin. Turnadmin es un enlace al binario turnserver, pero turnadmin realiza funciones diferentes.

Nota sobre las opciones: turnadmin tiene nombres de opción largos y cortos para la mayoría de las opciones. Algunas opciones solo tienen forma larga, otras solo forma corta. Su sintaxis es algo diferente; si se requiere un argumento:

La forma corta debe usarse así (por ejemplo):

  $ turnadmin -u <nombre_usuario> ...
La forma larga equivalente debe usar el carácter "=": 
  $ turnadmin --user=<nombre_usuario> ...
Si es una opción de bandera (no se requiere argumento), entonces su uso es el mismo, por ejemplo: 
 $ turnadmin -k ...
es equivalente a: 
 $ turnadmin --key ...
Siempre debe usar la opción -r <dominio> con los comandos para credenciales a largo plazo, ya que los datos de múltiples dominios se pueden almacenar en la misma base de datos.

=====================================

NOMBRE

turnadmin - una herramienta de administración del relé TURN.

SINOPSIS

$ turnadmin [comando] [opciones]
$ turnadmin [ -h | --help]

DESCRIPCIÓN

Comandos:

-P, --generate-encrypted-password
Genera e imprime en la salida estándar una forma encriptada de una contraseña (para el usuario administrador web o la CLI). El valor puede usarse como una clave segura para el almacenamiento de contraseñas en disco o en la base de datos. Cada invocación para la misma contraseña produce un resultado diferente. El formato de la contraseña encriptada es: $5$<...sal...>$<...sha256(sal+contraseña)...>. La sal tiene 16 caracteres, la salida sha256 tiene 64 caracteres. El carácter 5 es el ID del algoritmo (sha256). Solo se admite sha256 como función de hash.
-k, --key
Genera una clave para un usuario del mecanismo de credenciales a largo plazo.
-a, --add
Agrega o actualiza un usuario a largo plazo.
-A, --add-admin
Agrega o actualiza un usuario administrador.
-d, --delete
Elimina un usuario a largo plazo.
-D, --delete-admin
Elimina un usuario administrador.
-l, --list
Lista los usuarios a largo plazo en la base de datos.
-L, --list-admin
Lista los usuarios administradores en la base de datos.

-s, --set-secret=<valor> Agrega un secreto compartido para la API REST de TURN

-S, --show-secret
Muestra los secretos compartidos almacenados para la API REST de TURN

-X, --delete-secret=<valor> Elimina un secreto compartido.

--delete-all_secrets
Elimina todos los secretos compartidos para la API REST.
-O, --add-origin
Agrega una relación origen-a-dominio.
-R, --del-origin
Elimina una relación origen-a-dominio.
-I, --list-origins
Lista las relaciones origen-a-dominio.
-g, --set-realm-option
Establece parámetros del dominio: max-bps, total-quota, user-quota.
-G, --list-realm-options
Lista los parámetros del dominio.
-E, --generate-encrypted-password-aes
Genera e imprime en la salida estándar una forma encriptada de una contraseña con AES-128.

Opciones con valores requeridos:

-b, --db, --userdb
Nombre del archivo de base de datos de usuarios SQLite (por defecto - /var/db/turndb o /usr/local/var/db/turndb o /var/lib/turn/turndb). Ver la misma opción en la sección turnserver.
-e, --psql-userdb
Cadena de conexión de la base de datos de usuarios PostgreSQL. Ver la opción --psql-userdb en la sección turnserver.
-M, --mysql-userdb
Cadena de conexión de la base de datos de usuarios MySQL. Ver la opción --mysql-userdb en la sección turnserver.
-J, --mongo-userdb
Cadena de conexión de la base de datos de usuarios MongoDB. Ver la opción --mysql-mongo en la sección turnserver.
-N, --redis-userdb
Cadena de conexión de la base de datos de usuarios Redis. Ver la opción --redis-userdb en la sección turnserver.
-u, --user
Nombre de usuario.
-r, --realm
Dominio.
-p, --password
Contraseña.
-x, --key-path
Genera una clave de 128 bits en la ruta dada.
-f, --file-key-path
Contiene una clave de 128 bits en la ruta dada.
-v, --verify
Verifica una contraseña encriptada dada en base64.
-o, --origin
Origen
--max-bps
Establece el valor del parámetro max-bps del dominio.
--total-quota
Establece el valor del parámetro total-quota del dominio.
--user-quota
Establece el valor del parámetro user-quota del dominio.
-h, --help
Ayuda.

Ejemplos de comandos:

Generar una forma encriptada de una contraseña:

$ turnadmin -P -p <contraseña>

Generar una clave:

$ turnadmin -k -u <nombre_usuario> -r <dominio> -p <contraseña>

Agregar/actualizar un usuario en la base de datos:

$ turnadmin -a [-b <archivo_base_datos_usuarios> | -e <cadena_conexión_bd> | -M <cadena_conexión_bd> | -N <cadena_conexión_bd> ] -u <nombre_usuario> -r <dominio> -p <contraseña>

Eliminar un usuario de la base de datos:

$ turnadmin -d [-b <archivo_base_datos_usuarios> | -e <cadena_conexión_bd> | -M <cadena_conexión_bd> | -N <cadena_conexión_bd> ] -u <nombre_usuario> -r <dominio>

Listar todos los usuarios a largo plazo en la base de datos MySQL:

$ turnadmin -l --mysql-userdb="<cadena_conexión_bd>" -r <dominio>

Listar todos los usuarios administradores en la base de datos Redis:

$ turnadmin -L --redis-userdb="<cadena_conexión_bd>"

Establecer secreto en la base de datos MySQL:

$ turnadmin -s <secreto> --mysql-userdb="<cadena_conexión_bd>" -r <dominio>

Mostrar secreto almacenado en la base de datos PostgreSQL:

$ turnadmin -S --psql-userdb="<cadena_conexión_bd>"

GENERAL INFORMATION

This section describes the turnadmin utility.

= ====================================='>=====================================

SYNOPSIS

turnadmin [--userdb <db-connection-string> | --mysql-userdb <db-connection-string> | --psql-userdb <db-connection-string> | --redis-userdb <db-connection-string>] [-a | -A | -l | -L | -r | -o | -d | -p | -x | -E | -v] [-u <user>] [-c <realm>] [-r <realm>] [-o <origin>] [-s <secret>] [-f <file>] [-n <nonce>] [-t <time>] [-k <key>] [--key-path <key-file>] [--file-key-path <key-file>] [-p <password>] [-i <id>] [-I]

DESCRIPTION

The turnadmin utility is used to manage the user database used by the turnserver. It supports different database backends such as SQL (MySQL, PostgreSQL) and Redis. It can be used to add, delete, list, and manage users and realms.

The utility can also be used for encryption and decryption of passwords for the MySQL database.

OPTIONS

-u <user>
Specify the username. Used when adding, deleting, or listing users.
-c <realm>
Specify the realm name. Used when adding, deleting, or listing users.
-s <secret>
Specify the shared secret for the realm. Used when adding or updating realms.
-f <file>
Specify a file containing the shared secret for the realm. Used when adding or updating realms.
-n <nonce>
Specify the nonce for authentication. Used when generating long-term credentials.
-t <time>
Specify the timestamp for authentication. Used when generating long-term credentials.
-k <key>
Specify the key for authentication. Used when generating long-term credentials.
-a
Add a new user.
-A
Add a new realm.
-l
List all users in a realm.
-L
List all realms.
-o <origin>
Specify the origin. Used for origin-based realm mapping.
-r <realm>
Specify the realm. Used for origin-based realm mapping.
-d
Delete a user.
-p <password>
Specify the password for a user. Used when adding or updating users.
-x
Update user's password.
-E
Enable encryption/decryption mode for MySQL passwords.
--key-path <key-file>
Path to the key file for MySQL password encryption.
--file-key-path <key-file>
Path to the key file used for encrypting/decrypting MySQL passwords.
-v <encrypted>
Verify/decrypt an encrypted password using the key file.
-i <id>
Specify the user ID. Used when adding, deleting, or listing users.
-I
List origin-to-realm relations.
--userdb <db-connection-string>
Specify the connection string for the user database (generic).
--mysql-userdb <db-connection-string>
Specify the connection string for the MySQL user database.
--psql-userdb <db-connection-string>
Specify the connection string for the PostgreSQL user database.
--redis-userdb <db-connection-string>
Specify the connection string for the Redis user database.
-h
Display help information.

EXAMPLES

Add a user to a MySQL database:

$ turnadmin --mysql-userdb="<db-connection-string>" -u <user> -c <realm> -p <password>

List all users in a realm from a PostgreSQL database:

$ turnadmin --psql-userdb="<db-connection-string>" -l -c <realm>

Add a realm with a shared secret from a Redis database:

$ turnadmin --redis-userdb="<db-connection-string>" -A -c <realm> -s <secret>

Delete a user from a MySQL database:

$ turnadmin --mysql-userdb="<db-connection-string>" -d -u <user> -c <realm>

List all realms from Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -L

Set origin-to-realm relation in MySQL database:

$ turnadmin --mysql-userdb="<db-connection-string>" -r <realm> -o <origin>

Delete origin-to-realm relation from Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -o <origin>

List all origin-to-realm relations in Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -I

List the origin-to-realm relations in PostgreSQL DB for a single realm:

$ turnadmin --psql-userdb="<db-connection-string>" -I -r <realm>

Create new key file for mysql password encryption:

$ turnadmin -E --key-path <key-file>

Create encrypted mysql password:

$ turnadmin -E --file-key-path <key-file> -p <secret>

Verify/decrypt encrypted password:

$ turnadmin --file-key-path <key-file> -v <encrypted>

Help:

$ turnadmin -h
