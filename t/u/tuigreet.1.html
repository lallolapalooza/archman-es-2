tuigreet(1) Manual de comandos generales tuigreet(1)

NOMBRE

tuigreet - Un saludo gráfico de consola para greetd

SINOPSIS

tuigreet [OPCIONES]...

OPCIONES

-h, --help

Muestra el uso y sale.

-v, --version

Imprime la versión del programa y sale.

-d, --debug [ARCHIVO]

Habilita el registro de depuración en el ARCHIVO proporcionado, o en /tmp/tuigreet.log si no se especifica ningún archivo.

-c, --cmd CMD

Especifica qué comando ejecutar en caso de autenticación exitosa. Esto puede ser anulado por selección manual dentro de tuigreet.

-s, --sessions DIR1[:DIR2]...

Ubicación de los archivos de escritorio para ser utilizados como definiciones de sesión de Wayland. Por defecto, las sesiones de Wayland se obtienen de /usr/share/wayland-sessions.

--session-wrapper 'CMD [ARGS]...'

Especifica un comando envoltorio para ejecutar en lugar de la sesión para sesiones que no son X11. Este comando recibirá el comando de sesión como sus argumentos.

-x, --xsessions DIR1[:DIR2]...

Ubicación de los archivos de escritorio para ser utilizados como definiciones de sesión X11. Por defecto, las sesiones X11 se obtienen de /usr/share/xsessions.

--xsession-wrapper 'CMD [ARGS]...'

Especifica un comando envoltorio para inicializar el servidor X y lanzar sesiones X11. Por defecto, startx /usr/bin/env se antepondrá a todos los comandos de sesión X11.

--no-xsession-wrapper

No envolver comandos para sesiones X11.

-w, --width COLS

Número de columnas que el área de prompt principal debe ocupar en la pantalla.

-i, --issue

Imprime el contenido de /etc/issue en la parte superior del área de prompt.

Esta opción es mutuamente excluyente con --greeting.

-g, --greeting GREETING

Especifica el texto que se mostrará en la parte superior del área de prompt.

Esta opción es mutuamente excluyente con --issue.

-t, --time

Imprime la fecha y hora actuales en la parte superior de la pantalla.

--time-format FORMAT

Configura una cadena de formato personalizada compatible con strftime para la fecha y hora actuales.

--user-menu

Permite seleccionar un usuario de un menú gráfico.

--user-menu-min-uid

UID mínimo de los usuarios a mostrar en el menú de selección.

--user-menu-max-uid

UID máximo de los usuarios a mostrar en el menú de selección.

-r, --remember

Recuerda el nombre de usuario de la última sesión abierta con éxito, por lo que el campo de nombre de usuario se autocompletará en la próxima ejecución.

--remember-session

Recuerda la última sesión seleccionada, anulando efectivamente la opción --cmd dada en ejecuciones posteriores.

--remember-user-session

Recuerda la última sesión abierta, por usuario (requiere --remember).

--theme SPEC

Define los colores a utilizar para dibujar los componentes de la interfaz de usuario. Puede encontrar la sintaxis correcta en el README del proyecto.

--asterisks

Añade retroalimentación visual al escribir secretos, como un asterisco por cada pulsación de tecla. Por defecto, no se da ninguna retroalimentación.

--asterisks-char CHARS

Cambia el carácter de retroalimentación predeterminado de un asterisco a una distribución aleatoria de los caracteres proporcionados.

--window-padding COLS

Añade espaciado entre el borde del área de pantalla y el área de dibujo.

--container-padding COLS

Añade espaciado entre el borde del área de prompt principal y su contenido.

--prompt-padding ROWS

Añade espaciado entre los campos del formulario.

--greet-align [left|center|right]

Alineación del texto de saludo en el contenedor del prompt principal (predeterminado: 'center').

--power-shutdown CMD [ARGS]...

Personaliza el comando que se ejecuta cuando se indica apagar la máquina. Debe ser un comando no interactivo (sudo no puede solicitar una contraseña, por ejemplo).

--power-reboot CMD [ARGS]...

Personaliza el comando que se ejecuta cuando se indica reiniciar la máquina. Debe ser un comando no interactivo (sudo no puede solicitar una contraseña, por ejemplo).

--power-no-setsid

No anteponer setsid a los comandos de energía, que se utiliza para desvincularlos del TTY actual.

--kb-[command|sessions|power] [1-12]

cambia las combinaciones de teclas F por defecto para acceder a los menús de comandos, sesiones y energía.
