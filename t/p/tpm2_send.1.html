tpm2_send(1) Manual de Comandos Generales tpm2_send(1)

NOMBRE

tpm2_send(1) - Envía un búfer de comando en bruto al TPM.

SINOPSIS

tpm2_send [OPCIONES] [STDIN]

DESCRIPCIÓN

tpm2_send(1) - Envía un comando TPM al TPM. El comando se lee de un archivo como un flujo binario y se transmite al TPM usando el TCTI especificado por el llamador. La respuesta recibida del TPM se escribe en el archivo de salida.

Es probable que el llamador quiera redirigir esto a un archivo o a un programa para decodificar y mostrar la respuesta de forma legible para el humano.

OPCIONES

•
-o, --output=ARCHIVO:

Archivo de salida al que enviar el búfer de respuesta. Por defecto es STDOUT.

•
**STDIN** el archivo que contiene el comando TPM2.

Configuración TCTI

El TCTI o “Interfaz de Transmisión” es el mecanismo de comunicación con el TPM. Los TCTI se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre anula la variable de entorno.

Los TCTI conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Normalmente se utiliza para comunicarse con el simulador de software del TPM.
•
device - Se utiliza al hablar directamente con el archivo del dispositivo TPM.
•
none - No inicializar una conexión con el TPM. Algunas herramientas permiten opciones fuera del tpm y por lo tanto soportan no usar un TCTI. Las herramientas que no lo soportan darán error cuando se intenten usar sin una conexión TCTI. No soporta NINGUNA opción y DEBE ser presentado como el texto exacto de “none”.

Los argumentos para la opción de línea de comandos o la variable de entorno están en el formato:

<nombre-tcti>:<config-opciones-tcti>

Especificar una cadena vacía para el <nombre-tcti> o la <config-opciones-tcti> resulta en que se use el valor predeterminado para esa parte respectivamente.

Valores Predeterminados TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado usando la semántica de dlopen(3). Las herramientas buscarán los TCTI tabrmd, device y mssim EN ESE ORDEN y USARÁN EL PRIMERO QUE ENCUENTREN. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de versión. El par clave-valor “default-tcti” indicará cuál de los TCTI mencionados es el predeterminado.

TCTIs Personalizados

Se puede cargar cualquier TCTI que implemente la interfaz TCTI dinámica. Las herramientas usan internamente dlopen(3), y el valor crudo nombre-tcti se utiliza para la búsqueda. Por lo tanto, esto podría ser una ruta a la biblioteca compartida, o un nombre de biblioteca según lo entendido por la semántica de dlopen(3).

OPCIONES TCTI

Esta colección de opciones se utilizan para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI de dispositivo, se puede especificar el archivo del dispositivo de caracteres TPM para uso por el TCTI de dispositivo. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Para el TCTI abrmd, el formato de la cadena de configuración es una serie de pares simples de clave-valor separados por un carácter `,`. Cada clave y valor de cadena están separados por un carácter `=).
•
El TCTI abrmd soporta dos claves:
1.
`bus_name' : El nombre del servicio tabrmd en el bus (una cadena).
2.
`bus_type' : El tipo de la instancia dbus (una cadena) limitada a `session' y `system'.

Especificar el nombre tcti tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Especificar el tcti predeterminado (abrmd) y una cadena de configuración de bus_type=session:

\--tcti:bus_type=session

NOTA: abrmd y tabrmd son sinónimos. los diversos módulos TCTI conocidos.

EJEMPLOS

Enviar y recibir comandos en bruto al TPM

Envía el contenido de tpm2-command.bin a un dispositivo y recopila la respuesta como tpm2-response.bin.

tpm2_send < tpm2-command.bin > tpm2-response.bin
tpm2_send < tpm2-command.bin -o tpm2-response.bin
