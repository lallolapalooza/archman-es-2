tpm2_getrandom(1) Manual de Comandos Generales tpm2_getrandom(1)

NOMBRE

tpm2_getrandom(1) - Obtiene bytes aleatorios del TPM.

SINOPSIS

tpm2_getrandom [OPCIONES] [ARGUMENTO]

DESCRIPCIÓN

tpm2_getrandom(1) - Devuelve los siguientes SIZE octetos del generador de números aleatorios. Se espera que el parámetro SIZE sea el único argumento para la herramienta.

Tenga en cuenta que la especificación del TPM recomienda que los TPM fijen el número de entradas disponibles al tamaño máximo de salida de un algoritmo de hash en bytes.

La mayoría de los TPM hacen esto, y por lo tanto la herramienta verifica que el tamaño de entrada esté limitado por la propiedad TPM2_PT_MAX_DIGEST y emite un error si es demasiado grande.

La salida por defecto es stdout y en formato binario, a menos que se especifique lo contrario con las opciones -o y --hex respectivamente.

OPCIONES

•
-o, --output=ARCHIVO

Especifica el nombre del archivo al que se volcarán los bytes en bruto. Por defecto es stdout en formato de cadena hexadecimal.

•
--hex

Convierte los datos de salida al formato hexadecimal sin un prefijo "0x".

•
-f, --force

Anula la verificación de que:

•
El tamaño solicitado está dentro del límite de tamaño de hash del TPM.
•
El número de bytes aleatorios recuperados coincide con la cantidad solicitada.
•
-S, --session=ARCHIVO:

La sesión creada usando tpm2_startauthsession. Se pueden especificar múltiples de estas. Por ejemplo, puede tener una sesión para auditoría y otra para encriptación de parámetros.

•
--cphash=ARCHIVO:

Ruta del archivo para registrar el hash de los parámetros del comando. Esto se denomina comúnmente cpHash. NOTA: Cuando se selecciona esta opción, en ausencia de la opción rphash, la herramienta no ejecutará el comando, simplemente devolverá un cpHash.

•
--rphash=ARCHIVO:

Ruta del archivo para registrar el hash de los parámetros de respuesta. Esto se denomina comúnmente rpHash.

•
ARGUMENTO el argumento de línea de comandos especifica el tamaño de la salida.

Configuración TCTI

El TCTI o "Interfaz de Transmisión" es el mecanismo de comunicación con el TPM. Los TCTI pueden cambiarse para comunicarse con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre tiene prioridad sobre la variable de entorno.

Los TCTI actualmente conocidos son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente utilizado para comunicarse con el simulador de software del TPM.
•
device - Utilizado cuando se habla directamente con un archivo de dispositivo TPM.
•
none - No inicializa una conexión con el TPM. Algunas herramientas permiten opciones fuera del TPM y, por lo tanto, admiten no usar un TCTI. Las herramientas que no lo soportan generarán un error cuando se intenten usar sin una conexión TCTI. No soporta NINGUNA opción y DEBE presentarse como el texto exacto de "none".

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<configuración-opción-tcti>

Especificar una cadena vacía para <nombre-tcti> o <configuración-opción-tcti> da como resultado el uso del valor predeterminado para esa parte respectivamente.

Valores Predeterminados TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado utilizando la semántica de dlopen(3). Las herramientas buscarán tabrmd, device y mssim TCTIs EN ESE ORDEN y USARÁN EL PRIMERO QUE ENCUENTREN. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de la versión. El par clave-valor "default-tcti" indicará cuál de los TCTIs mencionados anteriormente es el predeterminado.

TCTIs Personalizados

Cualquier TCTI que implemente la interfaz TCTI dinámica puede cargarse. Las herramientas utilizan internamente dlopen(3), y el valor bruto nombre-tcti se utiliza para la búsqueda. Por lo tanto, esto podría ser una ruta a la biblioteca compartida, o un nombre de biblioteca según lo entienda la semántica de dlopen(3).

tpm2_getrandom(1) — tpm2-tools

NOMBRE

tpm2_getrandom — obtener bytes aleatorios del TPM

SINOPSIS

tpm2_getrandom [ -h | --help ] [ -V | --version ] [ -f | --binary ] [ -o | --output ARCHIVO ] [ -T | --tcti TCTI ] [ -c | --context CONTEXTO ] SIZE

DESCRIPCIÓN

El comando tpm2_getrandom obtendrá el número especificado de bytes aleatorios del TPM. Los bytes aleatorios se obtienen utilizando la función TPM2_GetRandom.

OPCIONES

Las opciones disponibles son:

-h, --help
Muestra la ayuda y sale.
-V, --version
Muestra la información de la versión y sale.
-f, --binary
Imprime la salida en formato binario. Por defecto, la salida es en formato hexadecimal.
-o, --output ARCHIVO
Escribe la salida en el archivo especificado. Si no se especifica, la salida va a stdout.
-T, --tcti TCTI
Especifica el TCTI (Tabard / TPM Communication Transport Interface) a usar. La sintaxis es similar a la de otras herramientas de tpm2-tools, por ejemplo: --tcti=cmd o --tcti='socket:host=localhost,port=2321'. Si no se especifica, se usará el TCTI por defecto.
-c, --context CONTEXTO
Especifica el contexto de la sesión del TPM. Se usa para interactuar con una sesión de TPM preestablecida. Por defecto, se usa el contexto del sistema.

OPCIONES COMUNES

Las siguientes opciones son comunes a la mayoría de las herramientas de tpm2-tools:

-f, --force
Sobrescribe archivos existentes sin preguntar.
-P, --password PASSWORD
Contraseña para el propietario del TPM o para la autorización de objetos.
-u, --username USERNAME
Nombre de usuario para la autenticación.
-p, --pin PIN
PIN para la autenticación.

Configuración TCTI

El formato de la cadena de configuración de TCTI es una serie de pares clave-valor simples separados por un carácter ','. Cada clave y cadena de valor están separadas por un carácter '='.

•
El TCTI abrmd soporta dos claves:
1.
'bus_name' : El nombre del servicio tabrmd en el bus (una cadena).
2.
'bus_type' : El tipo de la instancia de dbus (una cadena) limitada a 'session' y 'system'.

Especifica el nombre del TCTI tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

--tcti=tabrmd:bus_name=com.example.FooBar

Especifica el TCTI por defecto (abrmd) y una cadena de configuración de bus_type=session:

--tcti:bus_type=session

NOTA: abrmd y tabrmd son sinónimos. de los diversos módulos TCTI conocidos.

EJEMPLOS

Generar 20 bytes aleatorios y mostrar los datos binarios en un archivo

tpm2_getrandom -o random.out 20

Generar 8 bytes aleatorios y mostrar los datos formateados en hexadecimal en stdout

tpm2_getrandom 8

Retornos

Las herramientas pueden devolver cualquiera de los siguientes códigos:

•
0 - Éxito.
•
1 - Error general no específico.
•
2 - Error en el manejo de opciones.
•
3 - Error de autenticación.
•
4 - Error relacionado con TCTI.
•
5 - Esquema no soportado. Aplicable a tpm2_testparams.
