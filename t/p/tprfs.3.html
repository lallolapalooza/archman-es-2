CTPRFS

Propósito:

!>
!> CTPRFS proporciona cotas de error y estimaciones de error hacia atrás para la
!> solución de un sistema de ecuaciones lineales con una matriz triangular empaquetada
!> como coeficiente.
!>
!> La matriz solución X debe ser calculada por CTPTRS o algún otro
!> medio antes de entrar en esta rutina. CTPRFS no realiza refinamiento
!> iterativo porque hacerlo no puede mejorar el error hacia atrás.
!>

Parámetros

UPLO 
!>          UPLO es CARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

TRANS

!>          TRANS es CARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AP

!>          AP es matriz COMPLEJA, dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por columnas en
!>          un array lineal. La j-ésima columna de A se almacena en el array
!>          AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen como 1.
!>

B

!>          B es matriz COMPLEJA, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,N).
!>

X

!>          X es matriz COMPLEJA, dimensión (LDX,NRHS)
!>          La matriz solución X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión principal del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          La cota de error hacia adelante estimada para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es una cota superior estimada para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividida por la magnitud del elemento más grande
!>          en X(j). La estimación es tan fiable como
!>          la estimación para RCOND, y es casi siempre una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es array COMPLEJO, dimensión (2*N)
!>

RWORK

!>          RWORK es array REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>
