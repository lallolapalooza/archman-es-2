tpm2_policyauthvalue(1) General Commands Manual tpm2_policyauthvalue(1)

NOMBRE

tpm2_policyauthvalue(1) - Habilita la vinculación de una política al valor de autorización del objeto TPM autorizado.

SINOPSIS

tpm2_policyauthvalue [OPCIONES]

DESCRIPCIÓN

tpm2_policyauthvalue(1) - Habilita una política que requiere que se proporcione la contraseña de autorización del objeto. Esto es equivalente a autenticarse usando la contraseña del objeto en texto plano o HMAC. Lo impone como una política. Proporciona un mecanismo para permitir la autenticación con contraseña cuando un objeto solo permite la autorización basada en políticas, es decir, el atributo del objeto "userwithauth" es 0.

OPCIONES

•
-L, --policy=ARCHIVO:

Archivo donde guardar el resumen del hash de la política.

•
-S, --session=ARCHIVO:

Archivo de sesión de política generado a través de la opción -S de tpm2_startauthsession(1).

•
--cphash=ARCHIVO

Ruta del archivo donde registrar el hash de los parámetros del comando. Esto se denomina comúnmente cpHash. NOTA: Cuando se selecciona esta opción, la herramienta no ejecutará realmente el comando, simplemente devolverá un cpHash.

Configuración TCTI

El TCTI o "Interfaz de Transmisión" es el mecanismo de comunicación con el TPM. Los TCTI se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre anula la variable de entorno.

Los TCTI conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente utilizado para la comunicación con el simulador de software del TPM.
•
device - Utilizado al comunicarse directamente con el archivo del dispositivo TPM.
•
none - No inicializar una conexión con el TPM. Algunas herramientas permiten opciones fuera del TPM y, por lo tanto, admiten no usar un TCTI. Las herramientas que no lo admiten generarán un error cuando se intenten usar sin una conexión TCTI. No admite NINGUNA opción y DEBE presentarse como el texto exacto de "none".

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<config-opciones-tcti>

Especificar una cadena vacía para el <nombre-tcti> o <config-opciones-tcti> resulta en el uso del valor predeterminado para esa porción respectivamente.

Valores Predeterminados TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado utilizando la semántica de dlopen(3). Las herramientas buscarán los TCTI tabrmd, device y mssim **EN ESE ORDEN** y **USARÁN EL PRIMERO QUE ENCUENTREN**. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de la versión. El par clave-valor "default-tcti" indicará cuál de los TCTI mencionados es el predeterminado.

TCTIs Personalizados

Cualquier TCTI que implemente la interfaz TCTI dinámica puede ser cargado. Las herramientas utilizan internamente dlopen(3), y el valor crudo tcti-name se utiliza para la búsqueda. Por lo tanto, podría ser una ruta a la biblioteca compartida, o un nombre de biblioteca según lo entienda la semántica de dlopen(3).

OPCIONES TCTI

Esta colección de opciones se utiliza para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI device, se puede especificar el archivo del dispositivo carácter del TPM para su uso por el TCTI device. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Para el TCTI abrmd, el formato de la cadena de configuración es una serie de pares simples clave-valor separados por un carácter `,`. Cada clave y cadena de valor están separadas por un carácter `=`.
•
El TCTI abrmd admite dos claves:
1.
`bus_name': El nombre del servicio tabrmd en el bus (una cadena).
2.
`bus_type': El tipo de la instancia de dbus (una cadena) limitada a `session' y `system'.

Especificar el nombre TCTI de tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Especificar el TCTI predeterminado (abrmd) y una cadena de configuración de bus_type=session:

\--tcti:bus_type=session

NOTA: abrmd y tabrmd son sinónimos. los diversos módulos TCTI conocidos.

Crear la política de contraseña

tpm2_startauthsession -S session.dat
tpm2_policyauthvalue -S session.dat -L policy.dat
tpm2_flushcontext session.dat

Crear el objeto con una contraseña y la política de contraseña

tpm2_createprimary -C o -c prim.ctx
tpm2_create -g sha256 -G aes -u key.pub -r key.priv -C prim.ctx -L policy.dat \
  -p testpswd

Autenticarse con entrada de contraseña en texto plano

tpm2_load -C prim.ctx -u key.pub -r key.priv -n key.name -c key.ctx
echo "plaintext" > plain.txt
tpm2_encryptdecrypt -c key.ctx -o encrypt.out plain.txt -p testpswd

Autenticarse con contraseña y la política

tpm2_startauthsession --policy-session -S session.dat
tpm2_policyauthvalue -S session.dat
tpm2_encryptdecrypt -c key.ctx -o encrypt.out -p session:session.dat+testpswd \
plain.txt
tpm2_flushcontext session.dat

Devoluciones

Las herramientas pueden devolver cualquiera de los siguientes códigos:

•
0 - Éxito.
•
1 - Error general no específico.
•
2 - Error en el manejo de opciones.
•
3 - Error de autenticación.
•
4 - Error relacionado con TCTI.
•
5 - Esquema no soportado. Aplicable a tpm2_testparams.

Limitaciones

Espera que una sesión ya esté establecida a través de tpm2_startauthsession(1) y requiere uno de los siguientes:

•
acceso directo al dispositivo
•
soporte de sesión extendida con tpm2-abrmd.

Sin él, la mayoría de los administradores de recursos no guardarán el estado de la sesión entre invocaciones de comandos.
