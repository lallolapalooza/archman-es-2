Propósito:

!>
!> CTPMLQT aplica una matriz unitaria compleja Q obtenida de un
!>  reflector de bloque complejo H a una matriz general
!> compleja C, que consta de dos bloques A y B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica Q o Q**H desde la Izquierda;
!>          = 'R': aplica Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transposición, aplica Q;
!>          = 'C':  Transpuesta conjugada, aplica Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!>

MB

!>          MB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= MB >= 1.
!>          Debe ser el mismo valor de MB utilizado para generar T
!>          en CTPLQT.
!>

V

!>          V es un array COMPLEX, dimension (LDV,K)
!>          La i-ésima fila debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, tal como lo devuelve
!>          CTPLQT en B.  Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión líder del array V. LDV >= K.
!>

T

!>          T es un array COMPLEX, dimension (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          tal como los devuelve CTPLQT, almacenados como una matriz MB-por-K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión líder del array T.  LDT >= MB.
!>

A

!>          A es un array COMPLEX, dimension
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX, dimension (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX. La dimensión de WORK es
!>           N*MB si SIDE = 'L', o  M*MB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal

Name

dtpmlqt — applies a real orthogonal matrix Q obtained from a real block reflector H to a general real matrix C, which consists of two blocks A and B.

Synopsis

Standard calls:

SUBROUTINE DTPMLQT(SIDE, TRANS, M, N, K, L, MB, V, LDV, T, LDT, A, LDA, B, LDB, WORK, INFO)

CHARACTER(1) SIDE, TRANS
INTEGER M, N, K, L, MB, LDV, LDT, LDA, LDB, INFO
REAL V(LDV,K), T(LDT,MB), A(LDA, *), B(LDB, *), WORK( * )

Description

This routine is part of the LAPACK routine DTPMLQT, which applies a real orthogonal matrix Q obtained from a real block reflector H to a general real matrix C, which consists of two blocks A and B.

The structure of the blocks A and B depends on the value of SIDE:

SIDE = 'L'
C has the structure: 
 C = [ A ]
        [ B ]
where A is K-by-N and B is M-by-N.
SIDE = 'R'
C has the structure: 
 C = [ A B ]
where A is M-by-K and B is M-by-N.

The block reflector H is defined by the elements of V and T, which are usually computed by a preliminary call to DTPLQT.

Q can be expressed as a product of k elementary reflectors:

 Q = H(1) H(2) ... H(k)

or

 Q**T = H(k)**T ... H(2)**T H(1)**T

The form of H(i) depends on the shape of the matrix where it is applied.

Parameters

SIDE
SIDE is CHARACTER*1
    = 'L': apply Q or Q**T from the Left.
    = 'R': apply Q or Q**T from the Right.
TRANS
TRANS is CHARACTER*1
    = 'N':  No transpose, apply Q;
    = 'T':  Transpose, apply Q**T.
M
M is INTEGER
    The number of rows of the matrix B. M >= 0.
N
N is INTEGER
    The number of columns of the matrix B. N >= 0.
K
K is INTEGER
    The number of elementary reflectors whose product defines
    the matrix Q.
L
L is INTEGER
    The order of the trapezoidal part of V.
    K >= L >= 0.  See Further Details.
MB
MB is INTEGER
    The block size used for the storage of T.  K >= MB >= 1.
    This must be the same value of MB used to generate T
    in DTPLQT.
V
V is REAL array, dimension (LDV,K)
    The i-th row must contain the vector which defines the
    elementary reflector H(i), for i = 1,2,...,k, as returned by
    DTPLQT in B.  See Further Details.
LDV
LDV is INTEGER
    The leading dimension of the array V. LDV >= K.
T
T is REAL array, dimension (LDT,K)
    The upper triangular factors of the block reflectors
    as returned by DTPLQT, stored as a MB-by-K matrix.
LDT
LDT is INTEGER
    The leading dimension of the array T.  LDT >= MB.
A
A is REAL array, dimension
    (LDA,N) if SIDE = 'L' or
    (LDA,K) if SIDE = 'R'
    On entry, the K-by-N or M-by-K matrix A.
    On exit, A is overwritten by the corresponding block of
    Q*C or Q**T*C or C*Q or C*Q**T.  See Further Details.
LDA
LDA is INTEGER
    The leading dimension of the array A.
    If SIDE = 'L', LDA >= max(1,K);
    If SIDE = 'R', LDA >= max(1,M).
B
B is REAL array, dimension (LDB,N)
    On entry, the M-by-N matrix B.
    On exit, B is overwritten by the corresponding block of
    Q*C or Q**T*C or C*Q or C*Q**T.  See Further Details.
LDB
LDB is INTEGER
    The leading dimension of the array B.
    LDB >= max(1,M).
WORK
WORK is REAL array. The dimension of WORK is
     N*MB if SIDE = 'L', or  M*MB if SIDE = 'R'.
INFO
INFO is INTEGER
    = 0:  successful exit
    < 0:  if INFO = -i, the i-th argument had an illegal value

Author

Univ. of Tennessee
Univ. of California Berkeley
Univ. of Colorado Denver
NAG Ltd.

Further Details

  The columns of the pentagonal matrix V contain the elementary reflectors
  H(1), H(2), ..., H(K); V is composed of a rectangular block V1 and a
  trapezoidal block V2:

        V = [V1] [V2].


  The size of the trapezoidal block V2 is determined by the parameter L,
  where 0 <= L <= K; V2 is lower trapezoidal, consisting of the first L
  rows of a K-by-K upper triangular matrix.  If L=K, V2 is lower triangular;
  if L=0, there is no trapezoidal block, hence V = V1 is rectangular.

  If SIDE = 'L':  C = [A]  where A is K-by-N,  B is M-by-N and V is K-by-M.
                      [B]

  If SIDE = 'R':  C = [A B]  where A is M-by-K, B is M-by-N and V is K-by-N.

  The real orthogonal matrix Q is formed from V and T.

  If TRANS='N' and SIDE='L', C is on exit replaced with Q * C.

  If TRANS='T' and SIDE='L', C is on exit replaced with Q**T * C.

  If TRANS='N' and SIDE='R', C is on exit replaced with C * Q.

  If TRANS='T' and SIDE='R', C is on exit replaced with C * Q**T.

ztpmlqt(3) — LAPACK — Arch Linux

NAME

ztpmlqt — ZTPMLQT applies a complex unitary matrix, formed by means of elementary reflectors of rank K, to a complex matrix.

SYNOPSIS

CALL ZTPMLQT( SIDE, TRANS, M, N, K, L, MB, V, LDV, T, LDT, A, LDA, B, LDB, WORK, INFO )

Detailed Description

ZTPMLQT is used in the process of updating a matrix in the LQP-trapezoidal form.

The unitary matrix Q has dimensions nu-by-nu, where nu = K if SIDE = 'L' and nu = M if SIDE = 'R'. Q is defined as the product of K elementary reflectors:

if TRANS = 'N' and SIDE = 'L', then Q = H(1) H(2) ... H(K) and C is on exit replaced with Q*C.

if TRANS = 'C' and SIDE = 'L', then Q = H(1)**H H(2)**H ... H(K)**H and C is on exit replaced with Q*C.

if TRANS = 'N' and SIDE = 'R', then Q = H(1) H(2) ... H(K) and C is on exit replaced with C*Q.

if TRANS = 'C' and SIDE = 'R', then Q = H(1)**H H(2)**H ... H(K)**H and C is on exit replaced with C*Q.

Here H(i) is the complex elementary reflector in the i-th column and has the form H(i) = I - tau(i) * v(i) * v(i)**H, where v(i) is a complex vector which is stored by rows in the i-th row of the array V, and tau(i) is a complex scalar which is stored in the i-th entry of the array T. The vector v(i) has the form [0; ...; 0; 1; z; ...; z], where the 1 is in the i-th position.

The elements of the array T are in the form of a rectangular matrix, which is conceptually partitioned into two blocks. The first block consists of the first L rows of T and is lower trapezoidal, with MB*MB upper triangular blocks of size MB*MB. The second block consists of the remaining K-L rows of T and is also lower trapezoidal, with MB*MB upper triangular blocks of size MB*MB.

The elements of the array V are also stored in the form of a rectangular matrix. The first block consists of the first L rows of V and is MB*MB upper triangular blocks of size MB*MB. The second block consists of the remaining K-L rows of V and is also MB*MB upper triangular blocks of size MB*MB.

The matrix C consists of two blocks A and B.

Further Details

!>
!>  The columns of the pentagonal matrix V contain the elementary reflectors
!>  H(1), H(2), ..., H(K); V is composed of a rectangular block V1 and a
!>  trapezoidal block V2:
!>
!>        V = [V1] [V2].
!>
!>
!>  The size of the trapezoidal block V2 is determined by the parameter L,
!>  where 0 <= L <= K; V2 is lower trapezoidal, consisting of the first L
!>  rows of a K-by-K upper triangular matrix.  If L=K, V2 is lower triangular;
!>  if L=0, there is no trapezoidal block, hence V = V1 is rectangular.
!>
!>  If SIDE = 'L':  C = [A]  where A is K-by-N,  B is M-by-N and V is K-by-M.
!>                      [B]
!>
!>  If SIDE = 'R':  C = [A B]  where A is M-by-K, B is M-by-N and V is K-by-N.
!>
!>  The complex unitary matrix Q is formed from V and T.
!>
!>  If TRANS='N' and SIDE='L', C is on exit replaced with Q * C.
!>
!>  If TRANS='C' and SIDE='L', C is on exit replaced with Q**H * C.
!>
!>  If TRANS='N' and SIDE='R', C is on exit replaced with C * Q.
!>
!>  If TRANS='C' and SIDE='R', C is on exit replaced with C * Q**H.
