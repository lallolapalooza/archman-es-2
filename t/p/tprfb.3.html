DOCUMENTACIÓN DE LA FUNCIÓN

subrutina ctprfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldwork, * ) work, integer ldwork)

CTPRFB aplica un reflector de bloque complejo "triangular-pentagonal" a una matriz compleja, que se compone de dos bloques.

Propósito:

!>
!> CTPRFB aplica un reflector de bloque complejo H o su
!> transpuesta conjugada H**H a una matriz compleja C, que se compone de dos
!> bloques A y B, ya sea desde la izquierda o desde la derecha.
!>
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplica H o H**H desde la Izquierda
!>          = 'R': aplica H o H**H desde la Derecha
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N': aplica H (Sin transposición)
!>          = 'C': aplica H**H (Transpuesta conjugada)
!>

DIRECT

!>          DIRECT es CHARACTER*1
!>          Indica cómo se forma H a partir de un producto de
!>          reflectores elementales
!>          = 'F': H = H(1) H(2) . . . H(k) (Adelante)
!>          = 'B': H = H(k) . . . H(2) H(1) (Atrás)
!>

STOREV

!>          STOREV es CHARACTER*1
!>          Indica cómo se almacenan los vectores que definen los
!>          reflectores elementales:
!>          = 'C': Columnas
!>          = 'R': Filas
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B.
!>          N >= 0.
!>

K

!>          K es INTEGER
!>          El orden de la matriz T, es decir, el número de reflectores
!>          elementales cuyo producto define el reflector de bloque.
!>          K >= 0.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0. Véase Detalles Adicionales.
!>

V

!>          V es un array COMPLEX, de dimensión
!>                                (LDV,K) si STOREV = 'C'
!>                                (LDV,M) si STOREV = 'R' y SIDE = 'L'
!>                                (LDV,N) si STOREV = 'R' y SIDE = 'R'
!>          La matriz pentagonal V, que contiene los reflectores elementales
!>          H(1), H(2), ..., H(K). Véase Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión principal del array V.
!>          Si STOREV = 'C' y SIDE = 'L', LDV >= max(1,M);
!>          Si STOREV = 'C' y SIDE = 'R', LDV >= max(1,N);
!>          Si STOREV = 'R', LDV >= K.
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,K)
!>          La matriz triangular KxK T en la representación del
!>          reflector de bloque.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T.
!>          LDT >= K.
!>

A

!>          A es un array COMPLEX, de dimensión
!>          (LDA,N) si SIDE = 'L' o (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de KxN o MxK.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          H*C o H**H*C o C*H o C*H**H. Véase Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.
!>          Si SIDE = 'L', LDA >= max(1,K);
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX, de dimensión (LDB,N)
!>          En la entrada, la matriz B de MxN.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          H*C o H**H*C o C*H o C*H**H. Véase Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es un array COMPLEX, de dimensión
!>          (LDWORK,N) si SIDE = 'L',
!>          (LDWORK,K) si SIDE = 'R'.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          Si SIDE = 'L', LDWORK >= K;
!>          Si SIDE = 'R', LDWORK >= M.
!>

Detalles Adicionales:

!>
!>  La matriz C es una matriz compuesta formada por los bloques A y B.
!>  El bloque B es de tamaño MxN; si SIDE = 'R', A es de tamaño MxK,
!>  y si SIDE = 'L', A es de tamaño KxN.
!>
!>  Si SIDE = 'R' y DIRECT = 'F', C = [A B].
!>
!>  Si SIDE = 'L' y DIRECT = 'F', C = [A]
!>                                      [B].
!>
!>  Si SIDE = 'R' y DIRECT = 'B', C = [B A].
!>
!>  Si SIDE = 'L' y DIRECT = 'B', C = [B]
!>                                      [A].
!>
!>  La matriz pentagonal V se compone de un bloque rectangular V1 y un
!>  bloque trapezoidal V2. El tamaño del bloque trapezoidal está determinado
!>  por el parámetro L, donde 0<=L<=K. Si L=K, el bloque V2 de V es triangular;
!>  si L=0, no hay bloque trapezoidal, por lo tanto V = V1 es rectangular.
!>
!>  Si DIRECT = 'F' y STOREV = 'C':  V = [V1]
!>                                         [V2]
!>     - V2 es un trapecio superior (primeras L filas de la triangular superior KxK)
!>
!>  Si DIRECT = 'F' y STOREV = 'R':  V = [V1 V2]
!>
!>     - V2 es un trapecio inferior (primeras L columnas de la triangular inferior KxK)
!>
!>  Si DIRECT = 'B' y STOREV = 'C':  V = [V2]
!>                                         [V1]
!>     - V2 es un trapecio inferior (últimas L filas de la triangular inferior KxK)
!>
!>  Si DIRECT = 'B' y STOREV = 'R':  V = [V2 V1]
!>
!>     - V2 es un trapecio superior (últimas L columnas de la triangular superior KxK)
!>
!>  Si STOREV = 'C' y SIDE = 'L', V es KxM con V2 LxK.
!>
!>  Si STOREV = 'C' y SIDE = 'R', V es KxN con V2 LxK.
!>
!>  Si STOREV = 'R' y SIDE = 'L', V es MxK con V2 LxK.
!>
!>  Si STOREV = 'R' y SIDE = 'R', V es NxK con V2 LxK.
!>

Detailed Description


This routine is part of the LAPACK routines that implement the
    reduced WY representation of an orthogonal matrix.


The routine computes a triangular-bordered matrix-vector
    multiplication.


The dimensions of V and V2 are determined by STOREV and SIDE:


    
  
  • If STOREV = 'N', V is M-by-K.
    • 
  
  • If STOREV = 'R', V is K-by-M.
    • 



The dimensions of V and V2 are determined by SIDE and TRLR:


    
  
  • If SIDE = 'L', V is M-by-K.
    • 
  
  • If SIDE = 'R', V is N-by-K.
    • 



The dimensions of V and W are determined by STOREV and SIDE:


    
  
  • If STOREV = 'N' and SIDE = 'L', V is M-by-K with V2 K-by-M.
    • 
  
  • If STOREV = 'N' and SIDE = 'R', V is N-by-K with V2 K-by-N.
    • 
  
  • If STOREV = 'R' and SIDE = 'L', V is K-by-M with V2 K-by-L.
    • 
  
  • If STOREV = 'R' and SIDE = 'R', V is K-by-N with V2 K-by-L.
    •
