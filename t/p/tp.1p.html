NOMBRE

tp - paginador de Perl puro

SINOPSIS

tp -[JSenrs] [-cols] [-f STR] [-j|+ #] [-p|+/ STR] [ARCHIVO]...

OPCIONES

-e
Salir al final del archivo.
-f STR
Si se define, el paginador hará una pausa cuando se encuentre la secuencia de caracteres especificada por STR en el texto de entrada.

El valor predeterminado cuando está habilitado es avance de forma, es decir, ^L; para imitar el comportamiento tradicional de "1" en more, pero debido a las peculiaridades de Getopt::Long> debes usar el separador de argumentos -- para activarlo, por ejemplo:

tp -f -- foo # hace una pausa en las líneas de foo con "^L" en ellas

También puedes proporcionar una expresión regular como STR, por ejemplo:

tp -f '[ie]t' bar # hace una pausa en las líneas de bar con "it" o "et" en ellas
-J
Añade una columna con marcadores que indican qué líneas coinciden con una expresión de búsqueda.
-n
Mostrar numeración de líneas. Se puede alternar en tiempo de ejecución con #.
-r
Envía caracteres de control crudos de la entrada sin adulterar a la terminal. Por defecto, los caracteres que no sean tabulación y nueva línea se convertirán a notación de careto, por ejemplo, ^@ para nulo o ^L para avance de forma.
-s
Comprime múltiples líneas en blanco en una.
-S
No plegar líneas largas.
-[ o --scrollbar
Muestra una barra de desplazamiento interactiva en la columna más a la derecha.
-$ o --tail
Sigue comprobando el archivo mostrado en busca de contenido nuevo. Solo disponible al paginar un solo archivo.
--cols
Establece el número de columnas para el paginador.

Si está ausente, la terminal se consulta directamente con Term::ReadKey si está cargado o con "stty" o "tput", y si estos fallan, por defecto es 80.

Interfaz de Usuario

"C-" es Control, "M-" es Meta/Alt, "S-" es Shift, y "\d+" es una secuencia de dígitos

General

ayuda - "h" o "H"
cerrar - "q" o "Q" o ":q" o ":Q"
refrescar - "r" o "C-l" o "C-R"
vaciar búfer - "R"
guardar búfer - ":w"
abrir archivo - ":e"

Navegación

abajo una línea - "ENTER" o "e" o "j" o "J" o "C-e" o "C-n" o "flecha abajo"
abajo media página - "d" o "C-d"
abajo una página - "ESPACIO" "f" o "z" o "C-f" o "C-v" o "M-espacio" o "PgDn"
arriba una página - "b" o "w" o "C-b" o "M-v" o "PgUp"
arriba media página - "u" o "C-u"
arriba una línea - "k" o "y" o "K" o "Y" o "C-K" o "C-P" o "C-Y" o "flecha arriba"
al final - "G" o "$" o ">" o "M->" o "End"
al principio - "g" o "<" o "M-<"
izquierda una tabulación - "flecha izquierda"
izquierda media pantalla - "S-flecha izquierda"
derecha una tabulación - "flecha derecha"
derecha media pantalla - "S-flecha derecha"
saltar a número de línea - "\d+"
siguiente archivo - ":n" o "S-M-flecha derecha"
archivo anterior - ":p" o "S-M-flecha izquierda"

Marcadores

Guardar marcador - "m" o "Ins"
Ir al marcador - "'"
Marcador especial: Principio del archivo - "^"
Marcador especial: Final del archivo - "$"
Marcador especial: Ubicación anterior - "'"
Marcador especial: Listar marcadores creados por el usuario - """
Marcador especial: "\d" - Parte superior del archivo \d al ver varios archivos

Búsqueda

adelante - /
atrás - ?
siguiente coincidencia - n o P
coincidencia anterior - p o N
grep (mostrar solo líneas coincidentes) - &

Opciones

alternar numeración de líneas - #
alternar plegado - S
alternar salida cruda/cocida - C

AMBIENTE

tp comprueba las variables LESS, MORE, TPOPT, TERM y TERMCAP.

La variable TPOPT se utiliza para establecer opciones explícitamente para tp, concatenando opciones sin decorar, por ejemplo, Sr para salida comprimida y cruda.

LESS y MORE se comprueban en busca de opciones que tp soporta, y si se detectan, se habilitan.
