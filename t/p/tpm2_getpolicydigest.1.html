tpm2_getpolicydigest(1) Manual de Comandos Generales tpm2_getpolicydigest(1)

NOMBRE

tpm2_getpolicydigest(1) - Recupera el digest de política de una sesión.

SINOPSIS

tpm2_getpolicydigest [OPCIONES] [ARGUMENTO]

DESCRIPCIÓN

tpm2_getpolicydigest(1) - Devuelve el digest de política de una sesión.

La salida por defecto es stdout y formato binario, a menos que se especifique lo contrario con las opciones -o y --hex respectivamente.

OPCIONES

•
-o, --output=ARCHIVO

Especifica el nombre del archivo al que se enviarán los bytes crudos. Por defecto es stdout como una cadena hexadecimal.

•
--hex

Convierte los datos de salida al formato hexadecimal sin un prefijo "0x".

•
-S, --session=ARCHIVO:

La sesión creada usando tpm2_startauthsession.

Configuración TCTI

El TCTI o "Interfaz de Transmisión" es el mecanismo de comunicación con el TPM. Los TCTI se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre tiene prioridad sobre la variable de entorno.

Los TCTI conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente utilizado para comunicarse con el simulador de software del TPM.
•
device - Utilizado cuando se comunica directamente con un archivo de dispositivo TPM.
•
none - No inicializa una conexión con el TPM. Algunas herramientas permiten opciones fuera del tpm y por lo tanto soportan no usar un TCTI. Las herramientas que no lo soportan fallarán cuando se intenten usar sin una conexión TCTI. No soporta NINGUNA opción y DEBE ser presentado como el texto exacto de "none".

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<configuración-opción-tcti>

Especificar una cadena vacía para el <nombre-tcti> o la <configuración-opción-tcti> resulta en el uso del valor predeterminado para esa parte respectivamente.

Predeterminados TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado utilizando la semántica de dlopen(3). Las herramientas buscarán los TCTI tabrmd, device y mssim EN ESE ORDEN y USARÁN EL PRIMERO QUE ENCUENTREN. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de la versión. El par clave-valor "default-tcti" indicará cuál de los TCTI mencionados es el predeterminado.

TCTIs Personalizados

Se puede cargar cualquier TCTI que implemente la interfaz TCTI dinámica. Las herramientas utilizan internamente dlopen(3), y el valor crudo tcti-name se utiliza para la búsqueda. Por lo tanto, podría ser la ruta a la biblioteca compartida, o un nombre de biblioteca según lo entiende la semántica de dlopen(3).

OPCIONES TCTI

Esta colección de opciones se utilizan para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI de dispositivo, se puede especificar el archivo del dispositivo de caracteres TPM para su uso por el TCTI de dispositivo. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Para el TCTI abrmd, el formato de la cadena de configuración es una serie de pares simples de clave-valor separados por un carácter `,'. Cada clave y valor de cadena están separados por un carácter `=´.
•
El TCTI abrmd soporta dos claves:
1.
`bus_name' : El nombre del servicio tabrmd en el bus (una cadena).
2.
`bus_type' : El tipo de la instancia de dbus (una cadena) limitada a `session' y `system'.

Especificar el nombre del TCTI tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Especificar el TCTI predeterminado (abrmd) y una cadena de configuración de bus_type=session:

\--tcti:bus_type=session

NOTA: abrmd y tabrmd son sinónimos. los diversos módulos TCTI conocidos.

EJEMPLOS

Crear una sesión y recuperar policydigest

tpm2 startauthsession -S session.ctx
tpm2 policypassword -S session.ctx -L test.policy
tpm2 getpolicydigest -S session.ctx -o policy.out
tpm2 flushco

•

•
2 - Error en el manejo de opciones.
•
3 - Error de autenticación.
•
4 - Error relacionado con TCTI.
•
5 - Esquema no soportado. Aplicable a tpm2_testparams.
