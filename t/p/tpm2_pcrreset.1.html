tpm2_pcrreset(1) Manual general de comandos tpm2_pcrreset(1)

NOMBRE

tpm2_pcrreset(1) - Restablece uno o más bancos de PCR

SINOPSIS

tpm2_pcrreset [OPCIONES] INDICE_PCR ...

DESCRIPCIÓN

tpm2_pcrreset(1) - Restablece el valor de PCR en todos los bancos para el índice especificado. Se pueden especificar varios índices de PCR.

El valor de restablecimiento depende del fabricante y es una secuencia de 00 o FF en la longitud del algoritmo hash para cada banco admitido.

INDICE_PCR es una lista separada por espacios de los índices de PCR que se restablecerán al emitir el comando.

OPCIONES

Esta herramienta no acepta opciones específicas de la herramienta.

•
--cphash=ARCHIVO

Ruta del archivo para registrar el hash de los parámetros del comando. Esto se conoce comúnmente como cpHash. NOTA: Cuando se selecciona esta opción, la herramienta no ejecutará realmente el comando, simplemente devolverá un cpHash.

Configuración de TCTI

El TCTI o "Interfaz de Transmisión" es el mecanismo de comunicación con el TPM. Los TCTI se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre anula la variable de entorno.

Los TCTI conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente se usa para comunicarse con el simulador de software del TPM.
•
device - Se usa al hablar directamente con el archivo del dispositivo TPM.
•
none - No inicializar una conexión con el TPM. Algunas herramientas permiten opciones fuera del TPM y, por lo tanto, admiten no usar un TCTI. Las herramientas que no lo admiten generarán un error cuando se intenten usar sin una conexión TCTI. No admite NINGUNA opción y DEBE presentarse como el texto exacto de "none".

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<config-opciones-tcti>

Especificar una cadena vacía para el <nombre-tcti> o <config-opciones-tcti> da como resultado que se use el valor predeterminado para esa parte respectivamente.

Valores Predeterminados de TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado utilizando la semántica de dlopen(3). Las herramientas buscarán los TCTI tabrmd, device y mssim EN ESE ORDEN y USARÁN EL PRIMERO QUE ENCUENTREN. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de la versión. El par clave-valor "default-tcti" indicará cuál de los TCTI mencionados anteriormente es el predeterminado.

TCTIs Personalizados

Se puede cargar cualquier TCTI que implemente la interfaz TCTI dinámica. Las herramientas utilizan internamente dlopen(3), y el valor de nombre-tcti en bruto se utiliza para la búsqueda. Por lo tanto, esta podría ser una ruta a la biblioteca compartida o un nombre de biblioteca según lo entienda la semántica de dlopen(3).

OPCIONES DE TCTI

Esta colección de opciones se utiliza para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI de dispositivo, se puede especificar el archivo de dispositivo de caracteres TPM para su uso por el TCTI de dispositivo. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Para el TCTI abrmd, el formato de la cadena de configuración es una serie de pares simples de clave-valor separados por un carácter `,`. Cada clave y cadena de valor están separadas por un carácter `=`.`
•
El TCTI abrmd admite dos claves:
1.
`bus_name' : El nombre del servicio tabrmd en el bus (una cadena).
2.
`bus_type' : El tipo de la instancia dbus (una cadena) limitado a `session' y `system'.

Especifica el nombre tcti tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Especifica el TCTI predeterminado (abrmd) y una cadena de configuración de bus_type=session:

\--tcti:bus_type=session

NOTA: abrmd y tabrmd son sinónimos.

tpm2_pcrreset 23

Restablecer PCR múltiples

tpm2_pcrreset 16 23

Dependencias

Fabricantes de TPM que podrían definir este PCR como reiniciable.

Los PCR 0 a 15 no son reiniciables (siendo parte de SRTM). Los PCR 16 a 22 están mayormente reservados para DRTM o dedicados a localidades específicas y podrían no ser reiniciables dependiendo de la localidad actual del TPM.

Devoluciones

Las herramientas pueden devolver cualquiera de los siguientes códigos:

•
0 - Éxito.
•
1 - Error general no específico.
•
2 - Error en el manejo de opciones.
•
3 - Error de autenticación.
•
4 - Error relacionado con TCTI.
•
5 - Esquema no soportado. Aplicable a tpm2_testparams.
