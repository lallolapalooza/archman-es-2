CTPCON

Propósito:

!>
!> CTPCON estima el recíproco del número de condición de una matriz
!> triangular empaquetada A, en la norma 1 o en la norma infinito.
!>
!> Se calcula la norma de A y se obtiene una estimación para
!> norm(inv(A)), luego se calcula el recíproco del número de condición como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es de tipo CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o en
!>          norma infinito:
!>          = '1' o 'O':  norma 1;
!>          = 'I':         norma infinito.
!>

UPLO

!>          UPLO es de tipo CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es de tipo CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

AP

!>          AP es un array de tipo COMPLEX, de dimensión (N*(N+1)/2)
!>          La matriz triangular superior o inferior A, empaquetada por
!>          columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen que son 1.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es un array de tipo COMPLEX, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array de tipo REAL, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
