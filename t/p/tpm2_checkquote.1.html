tpm2_checkquote(1) Manual de Comandos Generales tpm2_checkquote(1)

NOMBRE

tpm2_checkquote(1) - Valida una cita proporcionada por un TPM.

SINOPSIS

tpm2_checkquote [OPCIONES]

DESCRIPCIÓN

tpm2_checkquote(1) - Utiliza la porción pública de la clave proporcionada para validar una cita generada por un TPM. Esto validará la firma contra el mensaje de la cita y, si se proporcionan, verificará que los datos de calificación y los valores de PCR coincidan con los de la cita. Los valores de PCR se pueden proporcionar con o sin la información de selección de TPML_PCR_SELECTION. Un ejemplo de valores de PCR sin la información de selección de PCR es la salida de tpm2_pcrread. Si el valor de PCR se especifica sin la información de selección de PCR, entonces la cadena de selección de PCR debe especificarse utilizando la opción -l para interpretar los datos de PCR.

OPCIONES

•
-u, --public=ARCHIVO:

Entrada de archivo para la porción pública de la clave de verificación de firma. Ya sea el archivo pem o el archivo de formato público tss.

•
-g, --hash-algorithm=ALGORITMO:

El algoritmo de hash utilizado para digerir el mensaje.

•
-m, --message=ARCHIVO:

El archivo del mensaje de la cita que constituye los datos firmados por el TPM.

•
-s, --signature=ARCHIVO:

El archivo de entrada de la firma a validar.

•
-f, --pcr=ARCHIVO:

Archivo de entrada de PCR opcional para guardar la lista de valores de PCR incluidos en la cita.

•
-l, --pcr-list=PCR:

La lista de bancos de PCR y los IDs de PCR seleccionados para cada banco.

•
-q, --qualification=CADENA_HEX_O_RUTA:

Datos de calificación para la cita. Puede ser una cadena hexadecimal o una ruta. Esto se usa típicamente para agregar un nonce contra ataques de repetición.

•
-F, --format=FORMATO:

OBSOLETO e IGNORADO ya que es superfluo.

ESPECIFICADORES DE ALGORITMOS

Las opciones que toman algoritmos admiten "nombres agradables".

Hay dos clases principales de cadenas de especificación de algoritmos, simples y complejas. Solo ciertos algoritmos serán aceptados por el TPM, según el uso y las condiciones.

Especificadores complejos

Los objetos, cuando se especifican para su creación por el TPM, tienen numerosos algoritmos para poblar en los datos públicos. Cosas como el tipo, esquema y detalles asimétricos, tamaño de clave, etc. A continuación se muestra el formato general para especificar estos datos: <tipo>:<esquema>:<detalles-simétricos>

Especificadores de tipo

Esta porción del especificador de algoritmo complejo es requerida. El esquema restante y los detalles simétricos se establecerán por defecto según el tipo especificado y el tipo del objeto que se está creando.

•
aes - AES por defecto: aes128
•
aes128<modo> - AES de 128 bits con modo opcional (ctr|ofb|cbc|cfb|ecb). Si no se especifica el modo, se establece por defecto a null.
•
aes192<modo> - Igual que aes128<modo>, excepto para un tamaño de clave de 192 bits.
•
aes256<modo> - Igual que aes128<modo>, excepto para un tamaño de clave de 256 bits.
•
sm4 - SM4 por defecto: sm4128
•
sm4128 o sm4_128 <modo> - SM4 de 128 bits con modo opcional (ctr|ofb|cbc|cfb|ecb). Si no se especifica el modo, se establece por defecto a null.
•
ecc - Curva elíptica, por defecto es ecc256.
•
ecc192 o ecc_nist_p192 - Curva NIST ECC de 192 bits
•
ecc224 o ecc_nist_p224 - Curva NIST ECC de 224 bits
•
ecc256 o ecc_nist_p256 - Curva NIST ECC de 256 bits
•
ecc384 o ecc_nist_p384 - Curva NIST ECC de 384 bits
•
ecc521 o ecc_nist_p521 - Curva NIST ECC de 521 bits
•
ecc_sm2 o ecc_sm2_p256 - Curva SM2 de 256 bits
•
rsa - RSA por defecto: rsa2048
•
rsa1024 - RSA con tamaño de clave de 1024 bits.
•
rsa2048 - RSA con tamaño de clave de 2048 bits.
•
rsa3072 - RSA con tamaño de clave de 3072 bits.
•
rsa4096 - RSA con tamaño de clave de 4096 bits.

Especificadores de esquema

A continuación, hay un campo opcional, se puede omitir.

Los esquemas son generalmente Esquemas de Firma o Esquemas de Cifrado Asimétrico. La mayoría de los esquemas de firma toman un algoritmo de hash directamente después del esquema de firma. Si falta el algoritmo de hash, se establece por defecto a sha256. Algunos no toman argumentos y otros toman múltiples argumentos.
