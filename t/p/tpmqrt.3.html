CTPMQRT

Propósito:

!>
!> CTPMQRT aplica una matriz ortogonal compleja Q obtenida de un
!>  reflector de bloque complejo H a una matriz compleja general
!> C, que consta de dos bloques A y B.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'L': aplicar Q o Q**H desde la Izquierda;
!>          = 'R': aplicar Q o Q**H desde la Derecha.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          = 'N':  Sin transponer, aplicar Q;
!>          = 'C':  Transpuesta conjugada, aplicar Q**H.
!>

M

!>          M es INTEGER
!>          El número de filas de la matriz B. M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B. N >= 0.
!>

K

!>          K es INTEGER
!>          El número de reflectores elementales cuyo producto define
!>          la matriz Q.
!>

L

!>          L es INTEGER
!>          El orden de la parte trapezoidal de V.
!>          K >= L >= 0.  Ver Detalles Adicionales.
!>

NB

!>          NB es INTEGER
!>          El tamaño del bloque utilizado para el almacenamiento de T.  K >= NB >= 1.
!>          Debe ser el mismo valor de NB utilizado para generar T
!>          en CTPQRT.
!>

V

!>          V es array de COMPLEJO, dimensión (LDV,K)
!>          La i-ésima columna debe contener el vector que define el
!>          reflector elemental H(i), para i = 1,2,...,k, como devuelto por
!>          CTPQRT en B.  Ver Detalles Adicionales.
!>

LDV

!>          LDV es INTEGER
!>          La dimensión líder del array V.
!>          Si SIDE = 'L', LDV >= max(1,M);
!>          si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T es array de COMPLEJO, dimensión (LDT,K)
!>          Los factores triangulares superiores de los reflectores de bloque
!>          como los devuelve CTPQRT, almacenados como una matriz NB-por-K.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión líder del array T.  LDT >= NB.
!>

A

!>          A es array de COMPLEJO, dimensión
!>          (LDA,N) si SIDE = 'L' o
!>          (LDA,K) si SIDE = 'R'
!>          En la entrada, la matriz A de K-por-N o M-por-K.
!>          En la salida, A se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión líder del array A.
!>          Si SIDE = 'L', LDC >= max(1,K);
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B es array de COMPLEJO, dimensión (LDB,N)
!>          En la entrada, la matriz B de M-por-N.
!>          En la salida, B se sobrescribe con el bloque correspondiente de
!>          Q*C o Q**H*C o C*Q o C*Q**H.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión líder del array B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK es array de COMPLEJO. La dimensión de WORK es
!>           N*NB si SIDE = 'L', o  M*NB si SIDE = 'R'.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME


dtpmqrt, stpmqrt, ctpmqrt, ztpmqrt - Apply a real or complex
block reflector from a previous QU factorization






SYNOPSIS


This subroutine is part of the LAPACK library.




FORTRAN 77 INTERFACE


call dtpmqrt(side, trans, m, n, k, l, nb, v, ldv, t, ldt, a, lda, b, ldb,
             work, info)


call stpmqrt(side, trans, m, n, k, l, nb, v, ldv, t, ldt, a, lda, b, ldb,
             work, info)


call ctpmqrt(side, trans, m, n, k, l, nb, v, ldv, t, ldt, a, lda, b, ldb,
             work, info)


call ztpmqrt(side, trans, m, n, k, l, nb, v, ldv, t, ldt, a, lda, b, ldb,
             work, info)








DESCRIPTION


DTPMQRT applies a real orthogonal matrix Q obtained from a
real block reflector H to a general real matrix C, which consists of two
blocks A and B.


Let C = [A] if SIDE = 'L' and C = [A B] if SIDE = 'R'.


        [B]


The matrix Q is implicitly defined by the stored vectors in V and
the upper triangular factor T. It is assumed that Q is computed with
CTPQRT.


The operation performed is either:


if SIDE = 'L' and TRANS = 'N', C is replaced by Q*C.
if SIDE = 'L' and TRANS = 'T', C is replaced by Q^T*C.
if SIDE = 'R' and TRANS = 'N', C is replaced by C*Q.
if SIDE = 'R' and TRANS = 'T', C is replaced by C*Q^T.


Here Q is a real orthogonal matrix defined as the product of block
reflectors:


Q = H(1) H(2) ... H(K)


where H(i) is a rank-1 update applied to the i-th column of the
matrix V.


The block reflector H(i) is defined as:


H(i) = I - tau(i) * v(i) * v(i)^T * P(i)


where v(i) is the i-th column of V, and tau(i) is a scalar
supplied in T(1,i). P(i) is a permutation matrix which swaps the i-th and
(i+1)-th columns of the matrix it multiplies.


The parameter L determines the shape of the matrix V. V is composed of
a rectangular block V1 and a trapezoidal block V2:


V = [V1]
    [V2]


V2 is upper trapezoidal, consisting of the first L rows of a K-by-K
upper triangular matrix. If L=K, V2 is upper triangular. If L=0, there is no
trapezoidal block, and V = V1 is rectangular.


The matrix T is a NB-by-K matrix where NB is the block size used for the
storage of T. T contains the scalar factors tau(i) in its first row.






PARAMETERS




SIDE




SIDE is CHARACTER*1
= 'L': apply Q or Q^T from the Left;
= 'R': apply Q or Q^T from the Right.




TRANS




TRANS is CHARACTER*1
= 'N': No transpose, apply Q;
= 'T': Transpose, apply Q^T.




M




M is INTEGER
The number of rows of the matrix B. M >= 0.




N




N is INTEGER
The number of columns of the matrix B. N >= 0.




K




K is INTEGER
The number of elementary reflectors whose product defines
the matrix Q.




L




L is INTEGER
The order of the trapezoidal part of V.
K >= L >= 0. See Further Details.




NB




NB is INTEGER
The block size used for the storage of T.  K >= NB >= 1.
This must be the same value of NB used to generate T
in CTPQRT.




V




(Real for DTPQRT/STPMQRT, Complex for CTPQRT/ZTPQRT)
V is array, dimension (LDV,K)
The i-th column must contain the vector which defines the
elementary reflector H(i), for i = 1,2,...,k, as returned by
CTPQRT in B.  See Further Details.




LDV




LDV is INTEGER
The leading dimension of the array V.
If SIDE = 'L', LDV >= max(1,M);
if SIDE = 'R', LDV >= max(1,N).




T




(Real for DTPQRT/STPMQRT, Complex for CTPQRT/ZTPQRT)
T is array, dimension (LDT,K)
The upper triangular factors of the block reflectors
as returned by CTPQRT, stored as a NB-by-K matrix.




LDT




LDT is INTEGER
The leading dimension of the array T.  LDT >= NB.




A




(Real for DTPQRT/STPMQRT, Complex for CTPQRT/ZTPQRT)
A is array, dimension
(LDA,N) if SIDE = 'L' or
(LDA,K) if SIDE = 'R'
On entry, the K-by-N or M-by-K matrix A.
On exit, A is overwritten by the corresponding block of
Q*C or Q^T*C or C*Q or C*Q^T.  See Further Details.




LDA




LDA is INTEGER
The leading dimension of the array A.
If SIDE = 'L', LDA >= max(1,K);
If SIDE = 'R', LDA >= max(1,M).




B




(Real for DTPQRT/STPMQRT, Complex for CTPQRT/ZTPQRT)
B is array, dimension (LDB,N)
On entry, the M-by-N matrix B.
On exit, B is overwritten by the corresponding block of
Q*C or Q^T*C or C*Q or C*Q^T.  See Further Details.




LDB




LDB is INTEGER
The leading dimension of the array B.
LDB >= max(1,M).




WORK




(Real for DTPQRT/STPMQRT, Complex for CTPQRT/ZTPQRT)
WORK is array. The dimension of WORK is
N*NB if SIDE = 'L', or  M*NB if SIDE = 'R'.




INFO




INFO is INTEGER
= 0:  successful exit
< 0:  if INFO = -i, the i-th argument had an illegal value

ZTPMQRT aplica una matriz ortogonal compleja Q obtenida de un bloque reflector complejo H a una matriz compleja general C, que consta de dos bloques A y B.

El número de columnas de la matriz B. N >= 0.
