tpm2-totp(1) Manual de Comandos Generales tpm2-totp(1)

NOMBRE

tpm2-totp(1) – genera o calcula TOTPs basados en TPM

SINOPSIS

tpm2-totp [opciones]

DESCRIPCIÓN

tpm2-totp crea una clave dentro de un TPM 2.0 que puede ser utilizada para generar contraseñas de un solo uso basadas en tiempo (TOTPs) para demostrar al usuario que una plataforma no fue alterada durante su ausencia y por lo tanto sigue siendo confiable.

ARGUMENTOS

tpm2-totp espera uno de los cinco comandos y proporciona un conjunto de opciones.

COMANDOS

•
generate: Genera un nuevo secreto TOTP. Opciones posibles: -b, -l, -N, -p, -P, -T
•
calculate: Calcula un valor TOTP. Opciones posibles: -N, -t, -T
•
reseal: Re-sella el secreto TOTP a nuevos PCRs, bancos o valores. Opciones posibles: -b, -N, -p, -P (requerido), -T
•
recover: Recupera el secreto TOTP y lo muestra nuevamente. Opciones posibles: -N, -P (requerido), -T
•
clean: Elimina el índice NV consumido. Opciones posibles: -N, -T

OPCIONES

•
-b <banco>[,<banco>[,...]], --banks <banco>[,<banco>[,...]]: Bancos PCR seleccionados (por defecto: SHA1,SHA256)
•
-h, --help: Imprime la ayuda
•
-l, --label: Etiqueta para usar en la visualización en la aplicación autenticadora TOTP (por defecto: TPM2-TOTP)
•
-N <índice_nv>, --nvindex <índice_nv>: Índice NV del TPM para almacenar datos (por defecto: 0x018094AF)
•
-p <pcr>[,<pcr>[,...]], --pcrs <pcr>[,<pcr>[,...]]: Registros PCR seleccionados (por defecto: 0,2,4,6)
•
-P <contraseña>, --password <contraseña>: Contraseña para el secreto (por defecto: ninguna) (comandos: generate, recover, reseal)
•
-t, --time: Muestra la fecha/hora del cálculo del TOTP (comandos: calculate)
•
-T <nombre-tcti>[:<config-tcti>], --tcti <nombre-tcti>[:<config-tcti>]: Selecciona el TCTI a usar. nombre-tcti es el nombre de la biblioteca TCTI. Si está presente, la cadena de configuración config-tcti se pasa verbatim a la biblioteca TCTI elegida.

El TCTI también puede especificarse utilizando la variable de entorno TPM2TOTP_TCTI. Si tanto la opción de línea de comandos como la variable de entorno están presentes, se utiliza la opción de línea de comandos.

Si no se especifica ningún TCTI, se utiliza el TCTI predeterminado configurado en el sistema.

•
-v, --verbose: Imprime mensajes detallados

EJEMPLOS

Configuración

El secreto TOTP se puede generar con y sin contraseña. Se recomienda establecer una contraseña para habilitar las opciones de recuperación. También se pueden seleccionar los PCRs y bancos de PCR con -p y -b. Los valores predeterminados son PCRs 0,2,4 y bancos SHA1, SHA256.

tpm2-totp generate
tpm2-totp -P contraseña_muy_secreta generate
tpm2-totp -P contraseña_muy_secreta -p 0,1,2,3,4,5,6 generate
tpm2-totp -p 0,1,2,3,4,5,6 -b SHA1,SHA256 generate

Arranque

Durante el arranque, el valor TOTP para la hora actual, junto con la hora actual, debería mostrarse al usuario, por ejemplo, utilizando plymouth desde mkinitrd o desde dracut. El comando a ejecutar es:

tpm2-totp calculate
tpm2-totp -t calculate

Recuperación

Para recuperar el código QR:

tpm2-totp -P contraseña_muy_secreta recover

Para re-sellar el secreto:

tpm2-totp -P contraseña_muy_secreta reseal
tpm2-totp -P contraseña_muy_secreta -p 1,3,5,6 reseal

Eliminación

Para eliminar el índice NV creado:

tpm2-totp clean

Índice NV

Todos los comandos toman adicionalmente la opción -N para especificar el índice NV a utilizar. Por defecto, se utiliza y recomienda 0x018094AF.

tpm2-totp -N 0x01800001 -P contraseña_muy_secreta generate
tpm2-totp -N 0x01800001 calculate
tpm2-totp -N 0x01800001 -P contraseña_muy_secreta recover
tpm2-totp -N 0x01800001 -P contraseña_muy_secreta reseal

Configuración TCTI

Todos los comandos toman la opción -T o la variable de entorno TPM2TOTP_TCTI para especificar el TCTI a utilizar. Si el TCTI no se especifica explícitamente, se utiliza el TCTI predeterminado configurado en el sistema. Para usar, por ejemplo, el simulador de TPM conectado a un puerto dado, usa:

tpm2-totp -T mssim:port=2321 generate
