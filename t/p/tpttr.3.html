subrutina ctpttr (character uplo, integer n, complex, dimension( * ) ap, complex, dimension( lda, * ) a, integer lda, integer info)

CTPTTR copia una matriz triangular del formato empaquetado estándar (TP) al formato completo estándar (TR).

Propósito:

!>
!> CTPTTR copia una matriz triangular A del formato estándar empaquetado (TP)
!> al formato estándar completo (TR).
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior.
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

AP

!>          AP es un array COMPLEX, de dimensión ( N*(N+1)/2 ),
!>          En la entrada, la matriz triangular A superior o inferior, empaquetada
!>          por columnas en un array lineal. La j-ésima columna de A se almacena
!>          en el array AP de la siguiente manera:
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) para 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) para j<=i<=n.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, N )
!>          En la salida, la matriz triangular A. Si UPLO = 'U', la parte
!>          triangular superior N-por-N principal de A contiene la parte
!>          triangular superior de la matriz A, y la parte triangular estrictamente
!>          inferior de A no se referencia. Si UPLO = 'L', la parte triangular
!>          inferior N-por-N principal de A contiene la parte triangular inferior
!>          de la matriz A, y la parte triangular estrictamente superior de A
!>          no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

NAME

tpttr — copies a triangular matrix from the standard packed format (TP) to the standard full format (TR)

SYNOPSIS

subroutine tpttr(uplo, n, ap, a, lda, info)
    character uplo
    integer n
    complex*16 ap(*)
    complex*16 a(lda,*)
    integer lda
    integer info

Detailed Description

ZTPTTR copies a triangular matrix from the standard packed format (TP) to the standard full format (TR).

Function Documentation

subroutine ztpttr (character uplo, integer n, complex*16, dimension( * ) ap, complex*16, dimension( lda, * ) a, integer lda, integer info)

ZTPTTR copies a triangular matrix from the standard packed format (TP) to the standard full format (TR).

Purpose:

!>
!> ZTPTTR copies a triangular matrix A from standard packed format (TP)
!> to standard full format (TR).
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular.
!>          = 'L':  A is lower triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension ( N*(N+1)/2 ),
!>          On entry, the upper or lower triangular matrix A, packed
!>          columnwise in a linear array. The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

A

!>          A is COMPLEX*16 array, dimension ( LDA, N )
!>          On exit, the triangular matrix A.  If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
