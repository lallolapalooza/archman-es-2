tpmtool(1) Comandos de usuario tpmtool(1)

NOMBRE

tpmtool - Herramienta TPM de GnuTLS

SINOPSIS

tpmtool [-banderas] [-bandera [valor]] [--nombre-opcion[[=| ]valor]]

Todos los argumentos deben ser opciones.

DESCRIPCIÓN

Programa que permite el manejo de datos criptográficos del chip TPM.

OPCIONES

-d num, --debug=num

Habilita la depuración. Esta opción toma un número entero como argumento. El valor de num está restringido a: 
en el rango de 0 a 9999

Especifica el nivel de depuración.

--infile=archivo

Archivo de entrada.
--outfile=str

Archivo de salida.
--generate-rsa

Genera un par de claves RSA pública-privada.

Genera un par de claves RSA pública-privada en el chip TPM. La clave puede ser almacenada en el sistema de archivos y protegida por un PIN, o almacenada (registrada) en la memoria flash del chip TPM.

--register

Cualquier clave generada será registrada en el TPM. Esta opción debe aparecer en combinación con las siguientes opciones: generate-rsa.
--signing

Cualquier clave generada será una clave de firma. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: legacy. Esta opción debe aparecer en combinación con las siguientes opciones: generate-rsa.
--legacy

Cualquier clave generada será una clave heredada. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: signing. Esta opción debe aparecer en combinación con las siguientes opciones: generate-rsa.
--user

Cualquier clave registrada será una clave de usuario. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: system. Esta opción debe aparecer en combinación con las siguientes opciones: register.

La clave generada se almacenará en un almacenamiento persistente específico del usuario.

--system

Cualquier clave registrada será una clave del sistema. Esta opción no debe aparecer en combinación con ninguna de las siguientes opciones: user. Esta opción debe aparecer en combinación con las siguientes opciones: register.

La clave generada se almacenará en el almacenamiento persistente del sistema.

--pubkey=url

Imprime la clave pública del objeto proporcionado.
--list

Lista todas las claves almacenadas en el TPM.
--delete=url

Elimina la clave identificada por la URL dada (UUID).
--test-sign=url

Prueba la operación de firma del objeto proporcionado.

Puede ser utilizado para probar el correcto funcionamiento de la operación de firma. Esta operación firmará y verificará los datos firmados.

--sec-param=parámetro de seguridad

Especifica el nivel de seguridad [bajo, legado, medio, alto, ultra].

Esto es alternativo a la opción bits. Tenga en cuenta, sin embargo, que los valores permitidos por el chip TPM están cuantificados y los valores dados pueden ser redondeados al alza.

--bits=num

Especifica el número de bits para la generación de claves. Esta opción toma un número entero como argumento.
--inder, --no-inder

Usa el formato DER para las claves. La forma no-inder deshabilitará la opción.

Los archivos de entrada se asumirán en el formato DER portable del TPM. El formato por defecto es un formato personalizado utilizado por varias herramientas de TPM.

--outder, --no-outder

Usa el formato DER para las claves de salida. La forma no-outder deshabilitará la opción.

La salida estará en formato DER portable del TPM.

--srk-well-known

SRK tiene contraseña conocida (20 bytes de ceros).
-v arg, --version=arg

Muestra la versión del programa y sale. El modo por defecto es `v', una simple versión. El modo `c' mostrará información de derechos de autor y `n' mostrará el aviso de derechos de autor completo.
-h, --help

Muestra la información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a través de un paginador.

EJEMPLOS

Para generar una clave que se almacenará en el sistema de archivos, use: 

$ tpmtool --generate-rsa --bits 2048 --outfile tpmkey.pem

Para generar una clave que se almacenará en la memoria flash del TPM, use: 

$ tpmtool --generate-rsa --bits 2048 --register --user

Para obtener la clave pública de una clave TPM, use: 

$ tpmtool --pubkey tpmkey:uuid=58ad734b-bde6-45c7-89d8-756a55ad1891;storage=user           --outfile pubkey.pem

o si la clave está almacenada en el sistema de archivos: 

$ tpmtool --pubkey tpmkey:file=tmpkey.pem --outfile pubkey.pem

Para listar todas las claves almacenadas en el TPM, use: 

$ tpmtool --list

ESTADO DE SALIDA

Se devolverá uno de los siguientes valores de salida:

0 (EXIT_SUCCESS)

Ejecución exitosa del programa.
1 (EXIT_FAILURE)

La operación falló o la sintaxis del comando no fue válida.

TPMTOOL(1)

NOMBRE

tpmtool - Herramienta para interactuar con el Trusted Platform Module (TPM)

SINOPSIS

tpmtool [OPCIONES] [COMANDO] [ARGUMENTOS]

DESCRIPCIÓN

La herramienta tpmtool proporciona una interfaz de línea de comandos para interactuar con el chip TPM (Trusted Platform Module) presente en el sistema. Permite a los usuarios realizar diversas operaciones relacionadas con el TPM, como la recuperación de información, la gestión de claves y la ejecución de comandos específicos del TPM.

OPCIONES

-h, --help
Muestra un mensaje de ayuda y sale.
-v, --version
Muestra la información de la versión y sale.
-d, --device <dispositivo>
Especifica la ruta al dispositivo TPM (por ejemplo, /dev/tpm0). Si no se especifica, se intentará detectar automáticamente.
-c, --context <contexto>
Especifica un contexto de TPM predefinido para operaciones.
-f, --force
Fuerza la ejecución de una operación, incluso si hay advertencias.

EJEMPLOS

Para mostrar información básica del TPM: 

$ tpmtool info

Para listar las claves almacenadas en el TPM: 

$ tpmtool list-keys

Para obtener el PCR 0 del TPM: 

$ tpmtool pcr-read 0

Para crear una nueva clave de encriptación: 

$ tpmtool create-key --type encrypt

ESTADO DE SALIDA

0 si la operación se completó con éxito. 1 si ocurrió un error.

VER TAMBIÉN
