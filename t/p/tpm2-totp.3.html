Descripción Detallada

Verifica la confiabilidad de un dispositivo contra un humano usando contraseñas de un solo uso basadas en el tiempo.

int tpm2totp_calculate (const uint8_t * keyBlob, size_t keyBlob_size, TSS2_TCTI_CONTEXT * tcti_context, time_t * nowp, uint64_t * otp)

Calcula una contraseña de un solo uso basada en el tiempo para una clave.

Parámetros

keyBlob Clave para generar el TOTP.
keyBlob_size Tamaño de la clave.
tcti_context Contexto TCTI opcional para seleccionar el TPM a usar.
nowp Hora actual.
otp TOTP calculado.

Valores de retorno

0 en caso de éxito.
-1 en caso de fallo general/indefinido.
TSS2_RC código de respuesta para fallos transmitidos desde la biblioteca TSS.

Recupera un secreto de una clave.
