NOMBRE

tpm2_sessionconfig(1) - Configura atributos de sesión e imprime información de sesión desde un archivo de sesión.

SINOPSIS

tpm2_sessionconfig [OPCIONES] [ARGUMENTO]

DESCRIPCIÓN

tpm2_sessionconfig(1) - Configura atributos de sesión e imprime información de sesión desde un archivo de sesión.

La herramienta opera en uno de dos modos: 1. Configurar/modificar los atributos de sesión. 2. Imprimir la información de sesión. Este es el comportamiento por defecto.

OPCIONES

•
--enable-continuesession:

Habilita continueSession en los atributos de sesión.

•
--disable-continuesession

Deshabilita continuesession en los atributos de sesión.

•
--enable-auditexclusive

Habilita auditexclusive en los atributos de sesión.

•
--disable-auditexclusive

Deshabilita auditexclusive en los atributos de sesión.

•
--enable-auditreset

Habilita auditreset en los atributos de sesión.

•
--disable-auditreset

Deshabilita auditreset en los atributos de sesión.

•
--enable-decrypt

Habilita decrypt en los atributos de sesión.

•
--disable-decrypt

Deshabilita decrypt en los atributos de sesión.

•
--enable-encrypt

Habilita encrypt en los atributos de sesión.

•
--disable-encrypt

Deshabilita encrypt en los atributos de sesión.

•
--enable-audit

Habilita audit en los atributos de sesión.

•
--disable-audit

Deshabilita audit en los atributos de sesión.

•
ARGUMENTO el archivo de contexto de sesión.

Configuración TCTI

El TCTI o “Interfaz de Transmisión” es el mecanismo de comunicación con el TPM. Los TCTIs se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre tiene prioridad sobre la variable de entorno.

Los TCTIs conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente se usa para comunicarse con el simulador de software del TPM.
•
device - Se usa al hablar directamente con el archivo del dispositivo TPM.
•
none - No inicializar una conexión con el TPM. Algunas herramientas permiten opciones fuera del tpm y por lo tanto soportan no usar un TCTI. Las herramientas que no lo soportan darán error cuando se intenten usar sin una conexión TCTI. No soporta NINGUNA opción y DEBE ser presentado como el texto exacto de “none”.

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<configuración-opción-tcti>

Especificar una cadena vacía para el <nombre-tcti> o la <configuración-opción-tcti> resulta en el uso del valor predeterminado para esa parte respectivamente.

Valores predeterminados de TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado usando la semántica de dlopen(3). Las herramientas buscarán los TCTIs tabrmd, device y mssim EN ESE ORDEN y USARÁN EL PRIMERO ENCONTRADO. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de la versión. El par clave-valor “default-tcti” indicará cuál de los TCTIs mencionados es el predeterminado.

TCTIs personalizados

Cualquier TCTI que implemente la interfaz TCTI dinámica puede ser cargado. Las herramientas usan internamente dlopen(3), y el valor bruto tcti-name se utiliza para la búsqueda. Por lo tanto, esto podría ser una ruta a la biblioteca compartida, o un nombre de biblioteca tal como lo entiende la semántica de dlopen(3).

OPCIONES TCTI

Esta colección de opciones se utiliza para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI de dispositivo, se puede especificar el archivo del dispositivo de caracteres del TPM para su uso por el TCTI de dispositivo. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

NAME

tpm2_sessionconfig

configure session attributes

SYNOPSIS

tpm2_sessionconfig [OPTIONS] [session-handle] [session-handle ... ]

DESCRIPTION

The tpm2_sessionconfig utility is used to configure session attributes. This command allows users to specify session attributes, such as enabling or disabling session persistence, or setting the session to be tied to a specific primary key.

OPTIONS

The command supports the following options:

–c
–continue-session
Enable the continue session attribute. This allows the session to persist across TPM resets. The default is disabled.
–d
–disable-continuesession
Disable the continue session attribute. This is the default behavior.
–p
–primary-handle
Specify the primary handle for the session. This binds the session to a specific primary key, meaning the session will be reset if the primary key is cleared.
–P
–child-key
Specify the child key handle. This binds the session to a specific child key. This option is used in conjunction with the session tied to a primary key.
–t
–tcti
Specify the Test Control and Test Interface (TCTI) to use. The TCTI is used to connect to the TPM.
-?, --help
Print the help message and exit.
-v, --version
Print version information and exit.

COMMON OPTIONS

This tool shares common options with other tools in the tpm2-tools suite. For more information, see the tpm2_tools(7) man page.

TCTI Configuration

The tpm2_sessionconfig command supports configuring the TCTI. The TCTI is responsible for the communication with the TPM device. The configuration string is a series of key-value pairs separated by commas. Each key and value are separated by an equals sign.

TCTI abrmd La configuración de la cadena es una serie de pares simples clave-valor separados por un carácter `,'. Cada clave y cadena de valor están separadas por un carácter `=.
•
TCTI abrmd admite dos claves:
1.
`bus_name' : El nombre del servicio tabrmd en el bus (una cadena).
2.
`bus_type' : El tipo de la instancia dbus (una cadena) limitada a `session' y `system'.

Especifique el nombre del tcti tabrmd y una cadena de configuración de bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Especifique el tcti predeterminado (abrmd) y una cadena de configuración de bus_type=session:

\--tcti:bus_type=session

NOTE: abrmd y tabrmd son sinónimos. los varios módulos TCTI conocidos.

EXAMPLES

Iniciar una sesión enlazada y salada, deshabilitar la sesión continua y mostrar la sesión

tpm2 createprimary -c prim.ctx
tpm2 startauthsession -S session.ctx --policy-session -c prim.ctx
### Información de la sesión antes de cambiar los atributos
tpm2 sessionconfig session.ctx
### Información de la sesión después de cambiar los atributos
tpm2 sessionconfig --disable-continuesession
tpm2 sessionconfig session.ctx
