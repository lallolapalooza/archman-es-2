CTPLQT

Propósito:

!>
!> CTPLQT calcula una factorización LQ bloqueada de una matriz compleja
!>  C, la cual está compuesta por un
!> bloque triangular A y un bloque pentagonal B, utilizando la representación
!> WY compacta para Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz B, y el orden de la
!>          matriz triangular A.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B.
!>          N >= 0.
!>

L

!>          L es ENTERO
!>          El número de filas de la parte trapezoidal inferior de B.
!>          MIN(M,N) >= L >= 0.  Ver Detalles Adicionales.
!>

MB

!>          MB es ENTERO
!>          El tamaño del bloque a utilizar en la QR bloqueada.  M >= MB >= 1.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,M)
!>          En la entrada, la matriz triangular inferior M por M, A.
!>          En la salida, los elementos en y debajo de la diagonal del array
!>          contienen la matriz triangular inferior L.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

B

!>          B es un array COMPLEJO, dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M por N, B. Las primeras N-L columnas
!>          son rectangulares, y las últimas L columnas son trapezoidales inferiores.
!>          En la salida, B contiene la matriz pentagonal V.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

T

!>          T es un array COMPLEJO, dimensión (LDT,N)
!>          Los reflectores de bloque triangulares inferiores almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores.  Ver Detalles Adicionales.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.  LDT >= MB.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (MB*M)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Autor

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz M por (M+N)
!>
!>               C = [ A ] [ B ]
!>
!>
!>  donde A es una matriz M por M triangular inferior, y B es una matriz
!>  pentagonal M por N que consiste en una matriz rectangular M por (N-L), B1,
!>  a la izquierda de una matriz trapezoidal inferior M por L, B2:
!>          [ B ] = [ B1 ] [ B2 ]
!>                   [ B1 ]  <- rectangular M por (N-L)
!>                   [ B2 ]  <- trapezoidal inferior M por L.
!>
!>  La matriz trapezoidal inferior B2 consiste en las primeras L columnas de una
!>  matriz triangular inferior M por M, donde 0 <= L <= MIN(M,N).  Si L=0,
!>  B es rectangular M por N; si M=L=N, B es triangular inferior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima fila
!>  sobre la diagonal (de A) en la matriz de entrada C de M por (M+N)
!>            [ C ] = [ A ] [ B ]
!>                   [ A ]  <- triangular inferior M por M
!>                   [ B ]  <- pentagonal M por N
!>
!>  tal que W puede ser representada como
!>            [ W ] = [ I ] [ V ]
!>                   [ I ]  <- identidad, M por M
!>                   [ V ]  <- M por N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida en B,
!>  la cual llamamos V arriba.  Note que V tiene la misma forma que B; es decir,
!>            [ V ] = [ V1 ] [ V2 ]
!>                   [ V1 ] <- rectangular M por (N-L)
!>                   [ V2 ] <-     trapezoidal inferior M por L.
!>
!>  Las filas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(M/MB), donde cada
!>  bloque es de orden MB excepto el último bloque, que es de orden
!>  IB = M - (M-1)*MB.  Para cada uno de los B bloques, se calcula un factor
!>  reflector de bloque triangular superior: T1, T2, ..., TB. Los T de MB por MB
!>  (y IB por IB para el último bloque) se almacenan en la matriz T de MB por N como
!>
!>               T = [T1 T2 ... TB].
!>

DTPLQT

Purpose:

!>
!> DTPLQT computes a blocked LQ factorization of a double precision
!>  matrix C, which is composed of a
!> triangular block A and pentagonal block B, using the compact
!> WY representation for Q.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix B, and the order of the
!>          triangular matrix A.
!>          M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix B.
!>          N >= 0.
!>

L

!>          L is INTEGER
!>          The number of rows of the lower trapezoidal part of B.
!>          MIN(M,N) >= L >= 0.  See Further Details.
!>

MB

!>          MB is INTEGER
!>          The block size to be used in the blocked QR.  M >= MB >= 1.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,M)
!>          On entry, the lower triangular M-by-M matrix A.
!>          On exit, the elements on and below the diagonal of the array
!>          contain the lower triangular matrix L.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,N)
!>          On entry, the pentagonal M-by-N matrix B.  The first N-L columns
!>          are rectangular, and the last L columns are lower trapezoidal.
!>          On exit, B contains the pentagonal matrix V.  See Further Details.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,M).
!>

T

!>          T is DOUBLE PRECISION array, dimension (LDT,N)
!>          The lower triangular block reflectors stored in compact form
!>          as a sequence of upper triangular blocks.  See Further Details.
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of the array T.  LDT >= MB.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MB*M)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  The input matrix C is a M-by-(M+N) matrix
!>
!>               C = [ A ] [ B ]
!>
!>
!>  where A is an lower triangular M-by-M matrix, and B is M-by-N pentagonal
!>  matrix consisting of a M-by-(N-L) rectangular matrix B1 on left of a M-by-L
!>  upper trapezoidal matrix B2:
!>          [ B ] = [ B1 ] [ B2 ]
!>                   [ B1 ]  <- M-by-(N-L) rectangular
!>                   [ B2 ]  <-     M-by-L lower trapezoidal.
!>

NAME

ztplqt — block LQ factorization of a complex M-by-M triangular matrix

SYNOPSIS

SUBROUTINE ZTPLQT(M, N, L, A, LDA, B, LDB, T, LDT, WORK, INFO)
  CHARACTER * (*) A, B, T, WORK
  INTEGER M, N, L, LDA, LDB, LDT, INFO

Detailed Description

ZTPLQT performs an update of the matrix B of block LQ factorization of a triangular matrix A

  A = Q * T

where T is a M-by-M upper triangular block matrix and Q is a M-by-M orthogonal block matrix. Q is defined as a block product of elementary reflectors.

The lower triangular block matrix A is updated by the orthogonal block matrix Q.

  B = Q * B


Input:
  M       INTEGER
          The number of rows of the matrix A and the matrix B. M >= 0.
  N       INTEGER
          The number of columns of the matrix B. N >= 0.
  A       COMPLEX*16 array, dimension (LDA, M)
          On entry, the M-by-M lower triangular block matrix A.
  LDA     INTEGER
          The leading dimension of the array A. LDA >= max(1, M).
  B       COMPLEX*16 array, dimension (LDB, N)
          On entry, the M-by-N matrix B to be factorized.
  LDB     INTEGER
          The leading dimension of the array B. LDB >= max(1, M).
  T       COMPLEX*16 array, dimension (LDT, M)
          On exit, the upper triangular block matrix T.
          The factorization is not explicitly computed, but rather T is
          implicitly given by the product of T1, T2, ..., TB.
  LDT     INTEGER
          The leading dimension of the array T. LDT >= M.
  WORK    COMPLEX*16 array, dimension (MB*M)
          Local workspace array.
  INFO    INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
