tpm2tss-genkey(1) Manual de comandos generales tpm2tss-genkey(1)

NOMBRE

tpm2tss-genkey(1) – genera claves TPM para el motor tpm2-tss-engine

SINOPSIS

tpm2tss-genkey [opciones] <nombre_archivo>

DESCRIPCIÓN

tpm2tss-genkey crea una clave dentro de un TPM 2.0 conectado a través de la pila de software tpm2tss. Estas claves pueden ser una clave RSA para descifrado o firma, o una clave ECC para firmas ECDSA.

La herramienta respeta la opción OPENSSL_CONF para especificar parámetros de control específicos del motor. Consulte man(5) config para obtener detalles sobre los archivos de configuración de openssl.

ARGUMENTOS

El comando tpm2tss-genkey espera un nombre de archivo para almacenar la información resultante de la clave TPM. Este archivo puede ser cargado posteriormente con OpenSSL usando openssl pkeyutl -engine tpm2tss -keyform engine -inkey <nombre_archivo>.

OPCIONES

•
-a <algoritmo>, --alg <algoritmo>: El algoritmo de clave pública (rsa, ecdsa) (por defecto: rsa)
•
-c <curva>, --curve <curva>: Si se elige el algoritmo ecdsa, la curva para ecc (por defecto: nist_p256)
•
-u <archivo>, --public <archivo>: Clave pública (TPM2B_PUBLIC) a importar. Requiere -r.
•
-r <archivo>, --private <archivo>: La clave privada (cifrada) (TPM2B_PRIVATE) a importar. Requiere -u.
•
-e <exponente>, --exponent <exponente>: Si se elige el algoritmo rsa, el exponente para rsa (por defecto: 65537)
•
-h, --help: Imprime la ayuda
•
-o <contraseña>, --ownerpw <contraseña>: Contraseña para la jerarquía del propietario (por defecto: ninguna) Comando de control de configuración de Openssl: SET_OWNERAUTH
•
-p <contraseña>, --password <contraseña>: Contraseña para la clave creada (por defecto: ninguna)
•
-P <manejador>, --parent <manejador>: Manejador específico para la clave padre (por defecto: ninguno)
•
-s <tamaño_clave>, --keysize <tamaño_clave>: Si se elige el algoritmo rsa, el tamaño de la clave en bits (por defecto: 2048)
•
-v, --verbose: Imprime mensajes detallados
•
-W <contraseña>, --parentpw <contraseña>: Contraseña para la clave padre (por defecto: ninguna) Comando de control de configuración de Openssl: SET_PARENTAUTH
•
-t <tcti-conf>, --tcti <tcti-conf>: Cadena de configuración TCTI (por defecto: ninguna) Comando de control de configuración de Openssl: SET_TCTI

EJEMPLOS

La información del motor se puede obtener usando:

$ openssl engine -t -c tpm2tss

La siguiente secuencia de comandos crea una clave RSA utilizando el TPM, exporta la clave pública, cifra un archivo de datos y lo descifra usando el TPM:

$ tpm2tss-genkey -a rsa -s 2048 mi_clave
$ openssl rsa -engine tpm2tss -inform engine -in mi_clave -pubout -outform pem -out mi_clave.pub
$ openssl pkeyutl -pubin -inkey mi_clave.pub -in mis_datos -encrypt -out mis_datos_cifrados
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey mi_clave -decrypt -in mis_datos_cifrados -out mis_datos_descifrados

La siguiente secuencia de comandos crea una clave RSA utilizando el TPM, exporta la clave pública, firma un archivo de datos utilizando el TPM y valida la firma:

$ tpm2tss-genkey -a rsa -s 2048 mi_clave
$ openssl rsa -engine tpm2tss -inform engine -in mi_clave -pubout -outform pem -out mi_clave.pub
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey mi_clave -sign -in mis_datos -out mi_firma
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey mi_clave -verify -in mis_datos -sigfile mi_firma

La siguiente secuencia de comandos crea una clave ECDSA utilizando el TPM, exporta la clave pública, firma un archivo de datos utilizando el TPM y valida la firma:

$ tpm2tss-genkey -a ecdsa -c nist_p256 mi_clave
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey mi_clave -sign -in mis_datos -out mi_firma
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey mi_clave -verify -in mis_datos -sigfile mi_firma

RETORNA

0 en caso de éxito o 1 en caso de fallo.
