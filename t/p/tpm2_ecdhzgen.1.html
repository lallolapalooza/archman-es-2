NOMBRE

tpm2_ecdhzgen(1) - Recupera el valor del secreto compartido (Z) a partir de un punto público y una clave privada especificada.

SINOPSIS

tpm2_ecdhzgen [OPCIONES]

DESCRIPCIÓN

tpm2_ecdhzgen(1) - Recupera el valor del secreto compartido (Z) a partir de un punto público y una clave privada especificada. Realizará la multiplicación del punto de entrada inPoint (QB) con la clave privada (ds) y devolverá las coordenadas del punto resultante (Z = (xZ , yZ) ≔ [hds]QB; donde h es el cofactor de la curva).

OPCIONES

•
-c, --key-context=ARCHIVO:

Objeto de contexto que apunta a una clave ECC. Ya sea un archivo o un número de manejador. Ver sección “Formato del Objeto de Contexto”.

•
-p, --key-auth=AUTENTICACION:

El valor de autorización para el objeto de clave ECC.

•
-u, --public=ARCHIVO:

Punto ECC de entrada Q.

•
-k, --public-key=ARCHIVO:

Clave pública ECC de entrada con punto Q.

•
-o, --output=ARCHIVO

Especificar la ruta del archivo para guardar el secreto ecdh calculado o el punto Z.

•
--cphash=ARCHIVO

Ruta del archivo para registrar el hash de los parámetros del comando. Esto se denomina comúnmente cpHash. NOTA: Cuando se selecciona esta opción, la herramienta no ejecutará realmente el comando, simplemente devolverá un cpHash.

Especificadores Complejos

Los objetos, cuando se especifican para su creación por el TPM, tienen numerosos algoritmos para poblar los datos públicos. Cosas como tipo, esquema y detalles asimétricos, tamaño de clave, etc. A continuación se muestra el formato general para especificar estos datos: <tipo>:<esquema>:<detalles-simétricos>

Especificadores de Tipo

Esta parte del especificador de algoritmo complejo es requerida. El esquema restante y los detalles simétricos se establecerán por defecto según el tipo especificado y el tipo del objeto que se está creando.

•
aes - AES por defecto: aes128
•
aes128<modo> - AES de 128 bits con modo opcional (ctr|ofb|cbc|cfb|ecb). Si no se especifica el modo, el valor predeterminado es null.
•
aes192<modo> - Igual que aes128<modo>, excepto por un tamaño de clave de 192 bits.
•
aes256<modo> - Igual que aes128<modo>, excepto por un tamaño de clave de 256 bits.
•
sm4 - SM4 por defecto: sm4128
•
sm4128 o sm4_128 <modo> - SM4 de 128 bits con modo opcional (ctr|ofb|cbc|cfb|ecb). Si no se especifica el modo, el valor predeterminado es null.
•
ecc - Curva Elíptica, por defecto ecc256.
•
ecc192 o ecc_nist_p192 - Curva NIST ECC de 192 bits
•
ecc224 o ecc_nist_p224 - Curva NIST ECC de 224 bits
•
ecc256 o ecc_nist_p256 - Curva NIST ECC de 256 bits
•
ecc384 o ecc_nist_p384 - Curva NIST ECC de 384 bits
•
ecc521 o ecc_nist_p521 - Curva NIST ECC de 521 bits
•
ecc_sm2 o ecc_sm2_p256 - Curva SM2 de 256 bits
•
rsa - RSA por defecto: rsa2048
•
rsa1024 - RSA con tamaño de clave de 1024 bits.
•
rsa2048 - RSA con tamaño de clave de 2048 bits.
•
rsa3072 - RSA con tamaño de clave de 3072 bits.
•
rsa4096 - RSA con tamaño de clave de 4096 bits.

Especificadores de Esquema

A continuación, hay un campo opcional, se puede omitir.

Los esquemas son generalmente Esquemas de Firma o Esquemas de Cifrado Asimétrico. La mayoría de los esquemas de firma aceptan un algoritmo hash directamente después del esquema de firma. Si falta el algoritmo hash, el valor predeterminado es sha256. Algunos no toman argumentos y otros toman múltiples argumentos.

NOMBRE

tpm2_ecdhzgen - Crea un nuevo par de claves ECC efímero para intercambio de claves ECDH y genera el secreto compartido.

SINOPSIS

tpm2_ecdhzgen [OPCIONES] --prime-data --public-blob --private-blob --shared-secret

DESCRIPCIÓN

tpm2_ecdhzgen es una utilidad del TPM 2.0 que genera un par de claves ECC (clave privada y pública) efímeras para ser utilizadas en un intercambio de claves ECDH. También calcula el secreto compartido utilizando la clave pública proporcionada por la otra parte y la clave privada generada localmente.

OPCIONES

--prime-data
Los datos de la prima (Prime Data). Esto es un valor binario que representa los parámetros de la curva elíptica. El formato y los valores permitidos dependen de la curva seleccionada.
--public-blob
Ruta al archivo donde se guardará el blob de la clave pública generada.
--private-blob
Ruta al archivo donde se guardará el blob de la clave privada generada.
--shared-secret
Ruta al archivo donde se guardará el secreto compartido generado.
--parent-auth
La contraseña para autenticar el objeto padre (si se usa uno).
--parent-context
El archivo de contexto que contiene el handle del objeto padre.
--new-parent-auth
La nueva contraseña para el objeto padre después de la operación.
--caching
Habilita la caché de la sesión de autorización.
--disable-command-audit
Deshabilita la auditoría de comandos para esta operación.
--force
Fuerza la operación incluso si existen advertencias.

Especificadores de Algoritmo

Se pueden especificar algoritmos criptográficos y sus parámetros utilizando las siguientes opciones:

--ecc-algorithm
Especifica el algoritmo ECC a utilizar. Los valores comunes incluyen:
  • TPM2_ALG_ECC_NIST_P192
  • TPM2_ALG_ECC_NIST_P224
  • TPM2_ALG_ECC_NIST_P256
  • TPM2_ALG_ECC_NIST_P384
  • TPM2_ALG_ECC_NIST_P521
  • TPM2_ALG_ECC_BN_P256
  • TPM2_ALG_ECC_BN_P638
Si no se especifica, se utilizará el valor predeterminado de la plataforma.

OPCIONES COMUNES

Las siguientes opciones son comunes a la mayoría de las utilidades de tpm2-tools:

--tpm-device
Especifica la ruta al dispositivo TPM. Si no se especifica, se intentará detectar automáticamente.
--tpm-hash-algorithm
Especifica el algoritmo de hash a utilizar para las operaciones del TPM.
--tpm-state-file
Archivo para almacenar el estado del TPM entre comandos.
--session
Archivo de sesión para persistir sesiones de autorización.
--slot
Número de ranura de autenticación (para ciertos escenarios de autenticación).

Configuración de TCTI

El TCTI (Tab Character Translation Interface) es el mecanismo utilizado para comunicarse con el TPM. Las siguientes opciones se utilizan para configurar el TCTI:

--tcti
Especifica el nombre del TCTI a utilizar. Los valores comunes incluyen:
  • device
  • mssim
  • socket
  • libtpms
--tcti-opt
Opciones adicionales para el TCTI seleccionado. Por ejemplo, para el TCTI socket, se podría usar --tcti-opt host= port=.

OPCIONES TCTI

Estas opciones son específicas de ciertos TCTIs:

--server
(Para TCTI socket) Especifica el nombre de host del servidor remoto del TPM.
--port
(Para TCTI socket) Especifica el número de puerto del servidor remoto del TPM.
--path
(Para TCTI device) Especifica la ruta al dispositivo del TPM.
--vm-addr
(Para TCTI libtpms) Especifica la dirección de la máquina virtual.
--vm-port
(Para TCTI libtpms) Especifica el puerto de la máquina virtual.

EJEMPLOS

1. Generar un par de claves ECC efímeras y calcular el secreto compartido usando una curva P-256 y guardando los resultados en archivos:


tpm2_ecdhzgen \
    --prime-data $(cat /usr/share/tpm2-tools/curves/nist-p256.json | jq -r '.prime_data') \
    --public-blob ./my_public.bin \
    --private-blob ./my_private.bin \
    --shared-secret ./my_shared.bin

2. Usar una curva diferente y especificar el dispositivo TPM:


tpm2_ecdhzgen \
    --tpm-device /dev/tpm0 \
    --prime-data $(cat /usr/share/tpm2-tools/curves/nist-p384.json | jq -r '.prime_data') \
    --public-blob ./public_p384.bin \
    --private-blob ./private_p384.bin \
    --shared-secret ./shared_p384.bin

Devoluciones

tpm2_ecdhzgen devuelve 0 si la operación es exitosa, y un valor distinto de cero en caso de error.

ERRORES

Los errores comunes incluyen problemas de comunicación con el TPM, parámetros de entrada inválidos o errores criptográficos.
