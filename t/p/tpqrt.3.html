CTPQRT

Propósito:

!>
!> CTPQRT calcula una factorización QR bloqueada de una matriz compleja
!>  C, que se compone de un
!> bloque triangular A y un bloque pentagonal B, usando la representación
!> WY compacta para Q.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz B, y el orden de la
!>          matriz triangular A.
!>          N >= 0.
!>

L

!>          L es ENTERO
!>          El número de filas de la parte trapezoidal superior de B.
!>          MIN(M,N) >= L >= 0.  Ver Detalles Adicionales.
!>

NB

!>          NB es ENTERO
!>          El tamaño del bloque a utilizar en la QR bloqueada.  N >= NB >= 1.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la matriz triangular superior N-por-N A.
!>          En la salida, los elementos en y por encima de la diagonal del array
!>          contienen la matriz triangular superior R.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

B

!>          B es un array COMPLEJO, dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M-por-N B. Las primeras M-L filas
!>          son rectangulares, y las últimas L filas son trapezoidales superiores.
!>          En la salida, B contiene la matriz pentagonal V.  Ver Detalles Adicionales.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión principal del array B.  LDB >= max(1,M).
!>

T

!>          T es un array COMPLEJO, dimensión (LDT,N)
!>          Los reflectores de bloque triangulares superiores almacenados en forma compacta
!>          como una secuencia de bloques triangulares superiores.  Ver Detalles Adicionales.
!>

LDT

!>          LDT es ENTERO
!>          La dimensión principal del array T.  LDT >= NB.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (NB*N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz (N+M)-por-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!>  donde A es una matriz triangular superior N-por-N, y B es una matriz pentagonal M-por-N
!>  que consiste en una matriz rectangular B1 de (M-L)-por-N en la parte superior de una matriz
!>  trapezoidal superior L-por-N, B2:
!>
!>               B = [ B1 ]  <- (M-L)-por-N rectangular
!>                   [ B2 ]  <-     L-por-N trapezoidal superior.
!>
!>  La matriz trapezoidal superior B2 consiste en las primeras L filas de una
!>  matriz triangular superior N-por-N, donde 0 <= L <= MIN(M,N).  Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular superior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima columna
!>  debajo de la diagonal (de A) en la matriz de entrada (N+M)-por-N C
!>
!>               C = [ A ]  <- triangular superior N-por-N
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de modo que W puede representarse como
!>
!>               W = [ I ]  <- identidad, N-por-N
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida en B,
!>  a la que llamamos V arriba.  Tenga en cuenta que V tiene la misma forma que B; es decir,
!>
!>               V = [ V1 ] <- (M-L)-por-N rectangular
!>                   [ V2 ] <-     L-por-N trapezoidal superior.
!>
!>  Las columnas de V representan los vectores que definen los H(i).
!>
!>  El número de bloques es B = techo(N/NB), donde cada
!>  bloque es de orden NB excepto el último bloque, que es de orden
!>  IB = N - (B-1)*NB.  Para cada uno de los B bloques, se calcula un factor
!>  de reflector de bloque triangular superior: T1, T2, ..., TB.  Los T's de NB-por-NB
!>  (y de IB-por-IB para el último bloque) se almacenan en la matriz T de NB-por-N como
!>
!>               T = [T1 T2 ... TB].
!>
