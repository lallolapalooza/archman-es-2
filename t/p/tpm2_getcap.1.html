tpm2_getcap(1) Manual de Comandos Generales tpm2_getcap(1)

NOMBRE

tpm2_getcap(1) - Muestra las capacidades del TPM en un formato legible para humanos.

SINOPSIS

tpm2_getcap [OPCIONES] [CAPACIDAD]

DESCRIPCIÓN

tpm2_getcap(1) - Consulta el TPM para obtener sus capacidades / propiedades y las imprime en la consola. Toma una forma de cadena de la capacidad a consultar como argumento de la herramienta. Los grupos de capacidades actualmente soportados son:

•
algorithms: Muestra datos sobre algoritmos soportados.
•
commands: Muestra datos sobre comandos soportados.
•
pcrs: Muestra los PCRs actualmente asignados.
•
properties-fixed: Muestra propiedades fijas del TPM.
•
properties-variable: Muestra propiedades variables del TPM.
•
ecc-curves: Muestra datos sobre curvas elípticas.
•
handles-transient: Muestra identificadores de objetos transitorios.
•
handles-persistent: Muestra identificadores de objetos persistentes.
•
handles-permanent: Muestra identificadores de objetos permanentes.
•
handles-pcr: Muestra identificadores de PCRs.
•
handles-nv-index: Muestra identificadores de índices NV.
•
handles-loaded-session: Muestra identificadores de sesiones de HMAC y políticas cargadas.
•
handles-saved-session: Muestra identificadores de sesiones guardadas.
•
vendor[:num]: Muestra las propiedades del proveedor como salida de un buffer hexadecimal. La cadena “vendor” puede ser seguida por dos puntos y un número tal como lo entiende strtoul(3) con base 0. Ese valor se utiliza como el valor de la propiedad dentro del comando TPM2_GetCapability, y por defecto es 1. Un ejemplo para llamarlo con un valor de propiedad de 2 es: tpm2_getcap vendor:2

NOTA: Si las solicitudes de proveedor se bloquean, intente la opción “-i” para ignorar el campo moreData y leer solo una vez.

OPCIONES

•
-l, --list:

Lista los nombres de capacidad soportados conocidos. Estos nombres pueden ser proporcionados como argumento de la opción -c. La salida está en una lista compatible con YAML a la salida estándar.

Por ejemplo:

  - algorithms
  - commands
  - properties-fixed
  ...
•
--ignore-moredata

Ignora el campo moreData cuando se trata de respuestas de TPM defectuosas.

OPCIONES COMUNES

Esta colección de opciones son comunes a muchos programas y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help=[man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el visor de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si falla el visor de manuales, las opciones cortas se mostrarán en la salida estándar.

Para utilizar correctamente la función de manuales, se requiere que los manuales estén instalados o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, tctis soportados y sale.
•
-V, --verbose: Aumenta la información que la herramienta imprime en la consola durante su ejecución. Al usar esta opción, se imprime el archivo y el número de línea.
•
-Q, --quiet: Silencia la salida normal de la herramienta a la salida estándar.
•
-Z, --enable-errata: Habilita la aplicación de correcciones de erratas. Útil si se necesita aplicar una corrección de errata a los comandos enviados al TPM. Definir la variable de entorno TPM2TOOLS_ENABLE_ERRATA es equivalente.
•
-R, --autoflush: Habilita el autoflush para objetos transitorios creados por el comando. Si un objeto padre se carga desde un archivo de contexto, también se limpiará el objeto padre transitorio. El autoflush también se puede activar si la variable de entorno TPM2TOOLS_AUTOFLUSH se establece en yes o true.

Configuración TCTI

El TCTI o 'Interfaz de Transmisión' es el mecanismo de comunicación con el TPM. Los TCTIs se pueden cambiar para la comunicación con TPMs a través de diferentes medios.

Para controlar el TCTI, las herramientas respetan:

1.
La opción de línea de comandos -T o --tcti
2.
La variable de entorno: TPM2TOOLS_TCTI.

Nota: La opción de línea de comandos siempre anula la variable de entorno.

Los TCTIs conocidos actualmente son:

•
tabrmd - El gestor de recursos, llamado tabrmd. Tenga en cuenta que tabrmd y abrmd como nombre de tcti son sinónimos.
•
mssim - Típicamente usado para comunicarse con el simulador de software del TPM.
•
device - Usado cuando se habla directamente con el archivo del dispositivo TPM.
•
none - No inicializar una conexión con el TPM. Algunas herramientas permiten opciones fuera del TPM y por lo tanto soportan no usar un TCTI. Las herramientas que no lo soportan fallarán cuando se intenten usar sin una conexión TCTI. No soporta NINGUNA opción y DEBE SER presentado como el texto exacto de 'none'.

Los argumentos para la opción de línea de comandos o la variable de entorno tienen el formato:

<nombre-tcti>:<configuración-opción-tcti>

Especificar una cadena vacía para <nombre-tcti> o <configuración-opción-tcti> resulta en que se use el valor predeterminado para esa porción respectivamente.

Predeterminados TCTI

Cuando no se especifica un TCTI, se busca el TCTI predeterminado usando la semántica de dlopen(3). Las herramientas buscarán los TCTIs tabrmd, device y mssim EN ESE ORDEN y USARÁN EL PRIMERO ENCONTRADO. Puede consultar qué TCTI se elegirá como predeterminado usando la opción -v para mostrar la información de versión. El par clave-valor 'default-tcti' indicará cuál de los TCTIs mencionados es el predeterminado.

TCTIs Personalizados

Cualquier TCTI que implemente la interfaz TCTI dinámica puede ser cargado. Las herramientas internamente usan dlopen(3), y el valor bruto tcti-name se usa para la búsqueda. Por lo tanto, esta podría ser una ruta a la biblioteca compartida, o un nombre de biblioteca tal como lo entiende la semántica de dlopen(3).

OPCIONES TCTI

Esta colección de opciones se utiliza para configurar los diversos módulos TCTI conocidos disponibles:

•
device: Para el TCTI de dispositivo, se puede especificar el archivo del dispositivo de caracteres TPM a utilizar por el TCTI de dispositivo. El valor predeterminado es /dev/tpm0.

Ejemplo: -T device:/dev/tpm0 o export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Para el TCTI mssim, se puede especificar el nombre de dominio o la dirección IP y el número de puerto utilizados por el simulador. Los valores predeterminados son 127.0.0.1 y 2321.

Ejemplo: -T mssim:host=localhost,port=2321 o export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Para el TCTI abrmd, el formato de la cadena de configuración i

tpm2_getcap(1) — tpm2-tools

NAME

tpm2_getcap — retrieves capability data from the TPM

SYNOPSIS

tpm2_getcap [OPTIONS] CAPABILITY_GROUP

DESCRIPTION

tpm2_getcap is used to retrieve capability data from the TPM. The TPM has several capability groups that provide information about the device's fixed properties, algorithm properties, and various other settings.

The command takes a single argument, CAPABILITY_GROUP, which specifies the type of capability data to retrieve. The available capability groups are:

  • properties-fixed: Retrieves the fixed properties of the TPM. These properties are set at the time the TPM is manufactured and do not change.
  • properties-variable: Retrieves the variable properties of the TPM. These properties can change over the lifetime of the TPM.
  • algorithms: Retrieves a list of algorithms supported by the TPM.
  • commands: Retrieves a list of commands supported by the TPM.
  • ecc-curves: Retrieves a list of supported Elliptic Curve Cryptography (ECC) curves.

In addition to the capability group, the following options can be specified:

OPTIONS

TCTI Configuration

The TPM Communication and Transport Interface (TCTI) is used to establish communication with the TPM. The following options can be used to configure the TCTI:

-T, --tcti-list
List all available TCTI names.
-t name, --tcti=name
Specify the TCTI name to use for communication with the TPM. If not specified, the tool will attempt to use the default TCTI for the platform.

TCTI OPTIONS

Additional configuration options for the TCTI can be provided using the --tcti option. The format for these options is a comma-separated list of key-value pairs, where each key and value are strings. The keys and values are separated by an equals sign ('=').

A series of simple key value pairs separated by a `,’` character. Each key and value string are separated by a `=’` character.
•
TCTI abrmd supports two keys:
1.
`bus_name' : The name of the tabrmd service on the bus (a string).
2.
`bus_type' : The type of the dbus instance (a string) limited to `session' and `system'.

Specify the tabrmd tcti name and a config string of bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Specify the default (abrmd) tcti and a config string of bus_type=session:

\--tcti:bus_type=session

NOTE: abrmd and tabrmd are synonymous.

COMMON OPTIONS

The following options are common to most TPM2 tools:

-h, --help
Print the help message and exit.
-v, --version
Print the version string and exit.
-V, --verbose
Enable verbose output. Can be specified multiple times for increased verbosity.
-d, --debug
Enable debug output. Can be specified multiple times for increased verbosity.
-f FILE, --input-file=FILE
Read input from a file.
-o FILE, --output-file=FILE
Write output to a file.
-c SESSION, --session=SESSION
The session to use for TPM operations. This can be a session handle or a file containing session data.
-p POLICY, --policy=POLICY
The policy to use for TPM operations. This can be a policy digest or a file containing policy data.
-t TIME, --timeout=TIME
The timeout for TPM operations in seconds.

EXAMPLES

To list the fixed properties of the TPM

tpm2_getcap properties-fixed

To list the supported capability groups

tpm2_getcap -l

To list the supported algorithms

tpm2_getcap algorithms

To list the supported commands

tpm2_getcap commands

To list the supported ECC curves

tpm2_getcap ecc-curves

Returns

Tools can return any of the following codes:

•
0 - Success.
•
1 - General non-specific error.
•
2 - Options handling error.
•
3 - Authentication error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.
