tpm2_certifyX509certutil(1) Manual de Comandos Generales tpm2_certifyX509certutil(1)

NOMBRE

tpm2_certifyX509certutil(1) - Genera un certificado X509 parcial.

SINOPSIS

tpm2_certifyX509certutil [OPCIONES]

DESCRIPCIÓN

tpm2_certifyX509certutil(1) - Genera un certificado parcial que es adecuado como tercer parámetro de entrada para el comando TPM2_certifyX509. Los datos del certificado se escriben en un archivo en formato DER y pueden ser examinados utilizando la herramienta openssl asn1parse de la siguiente manera:

openssl asn1parse -in partial_cert.der -inform DER

OPCIONES

Estas son las opciones disponibles:

•
-o, --outcert=CADENA: El archivo de salida donde se escribirá el certificado. El valor predeterminado es partial_cert.der. Parámetro opcional.
•
-d, --days=NÚMERO: El número de días que el certificado será válido a partir de hoy. El valor predeterminado es 3560 (10 años). Parámetro opcional.
•
-i, --issuer=CADENA: La entrada EMISOR para el certificado en el siguiente formato: –issuer=“C=US;O=org;OU=Org unit;CN=cname” Los campos soportados son:
•
C - “País”, tamaño máximo = 2
•
O - “Organización”, tamaño máximo = 8
•
OU - “Unidad Organizacional”, tamaño máximo = 8
•
CN - “Nombre Común”, tamaño máximo = 8 Los campos deben estar separados por punto y coma. Se requiere al menos un campo soportado para que la opción sea válida. Parámetro opcional.
•
-s, --subject=CADENA: El ASUNTO para el certificado en el siguiente formato: –subject=“C=US;O=org;OU=Org unit;CN=cname” Los campos soportados son:
•
C - “País”, tamaño máximo = 2
•
O - “Organización”, tamaño máximo = 8
•
OU - “Unidad Organizacional”, tamaño máximo = 8
•
CN - “Nombre Común”, tamaño máximo = 8 Los campos deben estar separados por punto y coma. Se requiere al menos un campo soportado para que la opción sea válida. Parámetro opcional.
•
ARGUMENTO No se requieren argumentos.

OPCIONES COMUNES

Esta colección de opciones son comunes a muchos programas y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help=[man|no-man]: Muestra la página del manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si falla el paginador de manuales, las opciones cortas se mostrarán en stdout.

Para usar con éxito la función de páginas del manual, se requiere que las páginas del manual estén instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra la información de versión de esta herramienta, los tctis soportados y sale.
•
-V, --verbose: Incrementa la información que la herramienta imprime en la consola durante su ejecución. Al usar esta opción, se imprime el archivo y el número de línea.
•
-Q, --quiet: Silencia la salida normal de la herramienta en stdout.
•
-Z, --enable-errata: Habilita la aplicación de correcciones de erratas. Útil si se necesita aplicar una corrección de erratas a los comandos enviados al TPM. Definir la variable de entorno TPM2TOOLS_ENABLE_ERRATA es equivalente.
•
-R, --autoflush: Habilita el autoflush para objetos transitorios creados por el comando. Si un objeto padre se carga desde un archivo de contexto, también se liberará el objeto padre transitorio. El autoflush también se puede activar si la variable de entorno TPM2TOOLS_AUTOFLUSH está configurada como yes o true. información que muchos usuarios pueden esperar.

EJEMPLOS

tpm2 certifyX509certutil -o partial_cert.der -d 356

Devoluciones

Las herramientas pueden devolver cualquiera de los siguientes códigos:

•
0 - Éxito.
•
1 - Error general no específico.
•
2 - Error en el manejo de opciones.
•
3 - Error de autenticación.
•
4 - Error relacionado con TCTI.
•
5 - Esquema no soportado. Aplicable a tpm2_testparams.
