CTPLQT2

Propósito:

!>
!> CTPLQT2 calcula una factorización LQ de una matriz C compleja,
!> compuesta por un bloque triangular A y un bloque pentagonal B,
!> utilizando la representación WY compacta para Q.
!>

Parámetros

M 
!>          M es INTEGER
!>          El número total de filas de la matriz B.
!>          M >= 0.
!>

N

!>          N es INTEGER
!>          El número de columnas de la matriz B y el orden de
!>          la matriz triangular A.
!>          N >= 0.
!>

L

!>          L es INTEGER
!>          El número de filas de la parte trapezoidal inferior de B.
!>          MIN(M,N) >= L >= 0. Véase Detalles Adicionales.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,M)
!>          En la entrada, la matriz triangular inferior M-por-M A.
!>          En la salida, los elementos en y debajo de la diagonal del array
!>          contienen la matriz triangular inferior L.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX de dimensión (LDB,N)
!>          En la entrada, la matriz pentagonal M-por-N B. Las primeras N-L columnas
!>          son rectangulares y las últimas L columnas son trapezoidales inferiores.
!>          En la salida, B contiene la matriz pentagonal V. Véase Detalles Adicionales.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,M).
!>

T

!>          T es un array COMPLEX de dimensión (LDT,M)
!>          El factor triangular superior T de NxN del reflector de bloque.
!>          Véase Detalles Adicionales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,M)
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!>  La matriz de entrada C es una matriz de M por (M+N)
!>
!>               C = [ A ][ B ]
!>
!>
!>  donde A es una matriz M-por-M triangular inferior, y B es una matriz
!>  pentagonal M-por-N que consta de una matriz rectangular B1 de M-por-(N-L)
!>  a la izquierda de una matriz trapezoidal inferior B2 de M-por-L:
!>
!>               B = [ B1 ][ B2 ]
!>                   [ B1 ]  <-     rectangular M-por-(N-L)
!>                   [ B2 ]  <-     trapezoidal inferior M-por-L.
!>
!>  La matriz trapezoidal inferior B2 consta de las primeras L columnas de una
!>  matriz triangular inferior NxN, donde 0 <= L <= MIN(M,N). Si L=0,
!>  B es rectangular M-por-N; si M=L=N, B es triangular inferior.
!>
!>  La matriz W almacena los reflectores elementales H(i) en la i-ésima fila
!>  por encima de la diagonal (de A) en la matriz de entrada C de M-por-(M+N)
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- triangular inferior M-por-M
!>                   [ B ]  <- pentagonal M-por-N
!>
!>  de tal manera que W puede representarse como
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identidad, M-por-M
!>                   [ V ]  <- M-por-N, misma forma que B.
!>
!>  Por lo tanto, toda la información necesaria para W está contenida en la salida
!>  en B, que llamamos V arriba. Nótese que V tiene la misma forma que B; es decir,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     rectangular M-por-(N-L)
!>                   [ V2 ] <-     trapezoidal inferior M-por-L.
!>
!>  Las filas de V representan los vectores que definen los H(i).
!>  El reflector de bloque H de (M+N)-por-(M+N) viene dado entonces por
!>
!>               H = I - W**T * T * W
!>
!>  donde W^H es la transpuesta conjugada de W y T es el factor triangular superior
!>  del reflector de bloque.
!>

NAME


tplqt2 - tplqt2 computes a LQ factorization of a real or complex "triangular-pentagonal" matrix, which is composed of a triangular block and a pentagonal block, using the compact WY representation for Q.






SYNOPSIS




> subroutine   ctplqt2 (integer m, integer n, integer l, complex, dimension( lda, * ) a, integer   lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldt, * ) t,   integer ldt, integer info)


CTPLQT2 computes a LQ factorization of a real or complex "triangular-pentagonal" matrix, which is composed of a triangular block and a pentagonal block, using the compact WY representation for Q.


Purpose:




!>
!> CTPLQT2 computes a LQ a factorization of a complex
!> matrix C, which is composed of a triangular block A and pentagonal block B,
!> using the compact WY representation for Q.
!>




Parameters


M

!>          M is INTEGER
!>          The total number of rows of the matrix B.
!>          M >= 0.
!>


N


!>          N is INTEGER
!>          The number of columns of the matrix B, and the order of
!>          the triangular matrix A.
!>          N >= 0.
!>


L


!>          L is INTEGER
!>          The number of rows of the lower trapezoidal part of B.
!>          MIN(M,N) >= L >= 0.  See Further Details.
!>


A


!>          A is COMPLEX array, dimension (LDA,M)
!>          On entry, the lower triangular M-by-M matrix A.
!>          On exit, the elements on and below the diagonal of the array
!>          contain the lower triangular matrix L.
!>


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>


B


!>          B is COMPLEX array, dimension (LDB,N)
!>          On entry, the pentagonal M-by-N matrix B.  The first N-L columns
!>          are rectangular, and the last L columns are lower trapezoidal.
!>          On exit, B contains the pentagonal matrix V.  See Further Details.
!>


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,M).
!>


T


!>          T is COMPLEX array, dimension (LDT,M)
!>          The N-by-N upper triangular factor T of the block reflector.
!>          See Further Details.
!>


LDT


!>          LDT is INTEGER
!>          The leading dimension of the array T.  LDT >= max(1,M)
!>


INFO


!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>




Author


Univ. of Tennessee

Univ. of California Berkeley


Univ. of Colorado Denver


NAG Ltd.




Further Details:




!>
!>  The input matrix C is a M-by-(M+N) matrix
!>
!>               C = [ A ][ B ]
!>
!>
!>  where A is an lower triangular M-by-M matrix, and B is M-by-N pentagonal
!>  matrix consisting of a M-by-(N-L) rectangular matrix B1 left of a M-by-L
!>  upper trapezoidal matrix B2:
!>
!>               B = [ B1 ][ B2 ]
!>                   [ B1 ]  <-     M-by-(N-L) rectangular
!>                   [ B2 ]  <-     M-by-L lower trapezoidal.
!>
!>  The lower trapezoidal matrix B2 consists of the first L columns of a
!>  N-by-N lower triangular matrix, where 0 <= L <= MIN(M,N).  If L=0,
!>  B is rectangular M-by-N; if M=L=N, B is lower triangular.
!>
!>  The matrix W stores the elementary reflectors H(i) in the i-th row
!>  above the diagonal (of A) in the M-by-(M+N) input matrix C
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- lower triangular M-by-M
!>                   [ B ]  <- M-by-N pentagonal
!>
!>  so that W can be represented as
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identity, M-by-M
!>                   [ V ]  <- M-by-N, same form as B.
!>
!>  Thus, all of information needed for W is contained on exit in B, which
!>  we call V above.  Note that V has the same form as B; that is,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     M-by-(N-L) rectangular
!>                   [ V2 ] <-     M-by-L lower trapezoidal.
!>
!>  The rows of V represent the vectors which define the H(i)'s.
!>  The (M+N)-by-(M+N) block reflector H is then given by
!>
!>               H = I - W**T * T * W
!>
!>  where W^H is the conjugate transpose of W and T is the upper triangular
!>  factor of the block reflector.
!>

NAME


tplqt2 -  computes the LQT factorization of a pentagonal matrix






SYNOPSIS


    Subroutine tplqt2(M, N, L, A, LDA, B, LDB, WORK, INFO)



Return values


    INFO    Integer
            = 0: successful exit
            < 0: if INFO = -i, the i-th argument had an illegal value.
                < 0 if L < 0 or L > min(M,N)
                < 0 if LDA < M
                < 0 if LDB < M







Detailed Description


!>
!>  Purpose
!>  =======
!>
!>  This routine is the block version of the algorithm for computing the
!>  LQ factorization of a general pentagonal matrix A.
!>
!>  A pentagonal matrix is a matrix of the form
!>
!>            [ R ]
!>            [ T ]
!>
!>  where R is an M-by-N rectangular matrix and T is an N-by-N lower
!>  triangular matrix.
!>
!>  Thus the dimension of A is (M+N)-by-N.
!>
!>  The factorization is computed by the following algorithm:
!>
!>     call sqf K K ( M, N, L, A, LDA, B, LDB, WORK, INFO )
!>
!>  where A is an M-by-N matrix.
!>
!>  The routine computes the reduced LQT factorization of a
!>  pentagonal matrix A.
!>  A is an (M+N)-by-N matrix.
!>  The factorization is A = Q * L, where Q is an (M+N)-by-(M+N) orthogonal
!>  matrix, and L is a pentagonal matrix.
!>
!>  L is of the form
!>
!>            [ R ]
!>            [ T ]
!>
!>  where R is M-by-N and T is N-by-N lower triangular.
!>
!>  The orthogonal matrix Q is not formed explicitly. Instead, it is
!>  stored as a product of elementary reflectors
!>
!>            Q = H(1) * H(2) * ... * H(N)
!>
!>  where each H(i) is a Householder reflection of the form
!>
!>            H(i) = I - v(i) * v(i)^T * tau(i)
!>
!>  The vectors v(i) and scalars tau(i) are stored in the matrix A.
!>
!>  The input is a pentagonal matrix A with dimension (M+N)-by-N.
!>
!>  The input parameter L denotes the number of columns of the lower
!>  triangular part of the pentagonal matrix.
!>  0 <= L <= min(M,N).
!>
!>  If L=0, A is a rectangular matrix M-by-N.
!>  If M=N, the matrix is square.
!>  If M < N, the matrix is a tall pentagonal matrix.
!>  If M > N, the matrix is a wide pentagonal matrix.
!>
!>  The factorization is A = Q*L.
!>
!>  The matrix L is stored in the upper triangle of A.
!>
!>  The orthogonal matrix Q is represented as a product of elementary
!>  reflectors in the argument A.
!>
!>  The argument B stores the elementary reflectors H(i) in the i-th row
!>  above the diagonal (of A) in the M-by-(M+N) input matrix C
!>
!>               C = [ A ][ B ]
!>                   [ A ]  <- lower triangular M-by-M
!>                   [ B ]  <- M-by-N pentagonal
!>
!>  so that W can be represented as
!>
!>               W = [ I ][ V ]
!>                   [ I ]  <- identity, M-by-M
!>                   [ V ]  <- M-by-N, same form as B.
!>
!>  Thus, all of information needed for W is contained on exit in B, which
!>  we call V above. Note that V has the same form as B; that is,
!>
!>               W = [ V1 ][ V2 ]
!>                   [ V1 ] <-     M-by-(N-L) rectangular
!>                   [ V2 ] <-     M-by-L lower trapezoidal.
!>
!>  The rows of V represent the vectors which define the H(i)'s.
!>  The (M+N)-by-(M+N) block reflector H is then given by
!>
!>               H = I - W**T * T * W
!>
!>  where W^H is the conjugate transpose of W and T is the upper triangular
!>  factor of the block reflector.
!>
