NOMBRE

Template::Tools::tpage - Procesa plantillas desde la línea de comandos

USO

tpage [ --define var=valor ] archivo(s)

DESCRIPCIÓN

El script tpage es un simple envoltorio para el procesador Template Toolkit. Los archivos especificados por nombre en la línea de comandos se procesan en orden por el procesador de plantillas y la salida resultante se envía a STDOUT y puede ser redirigida en consecuencia. Por ejemplo:

tpage miarchivo > miarchivo.out
tpage cabecera miarchivo pie > miarchivo.html

Si no se especifican nombres de archivo en la línea de comandos, entonces tpage leerá STDIN para obtener la entrada.

La opción "--define" se puede usar para establecer los valores de las variables de plantilla. Por ejemplo:

tpage --define autor="Andy Wardley" esqueleto.pm > MiModulo.pm

El archivo de configuración .tpagerc

Puedes usar un archivo .tpagerc en tu directorio de inicio.

El propósito de este archivo es establecer cualquier opción de configuración *global* que desees que se aplique *cada vez* que se ejecute tpage. Por ejemplo, puedes usar el "include_path" para usar archivos de plantilla de un directorio de plantillas genérico.

Ejecuta "tpage -h" para obtener un resumen de las opciones disponibles.

Consulta Template para obtener información general sobre el Template Toolkit de Perl y el lenguaje y las características de las plantillas.
