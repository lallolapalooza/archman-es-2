NOMBRE

tpm2-abrmd - demonio de gestor de recursos y intermediario de acceso TPM2

SINOPSIS

tpm2-abrmd [-m][-e][-i][-o][-l nombre-registrador][-r][-s][-g /dev/urandom][-t conf]

DESCRIPCIÓN

tpm2-abrmd es un demonio que implementa el intermediario de acceso TPM y el gestor de recursos, tal como se describe en la especificación “TSS System Level API and TPM Command Transmission Interface Specification” del Trusted Computing Group (TGC). Este demonio utiliza el bus de sistema DBus y algunas tuberías para comunicarse con los clientes.

OPCIONES

-t, --tcti
Proporciona al demonio una cadena que describe el TCTI y cómo configurarlo para la comunicación con el siguiente componente de la pila TSS2. Esta cadena tiene el formato "nombre-tcti:conf-tcti" donde:
'nombre-tcti'
El nombre del archivo de objeto compartido de la biblioteca TCTI. Las bibliotecas se buscan utilizando el mismo algoritmo que dlopen (3). Si el nombre del archivo de la biblioteca TCTI sigue la convención de nombres: libtss2-tcti-<nombre>.so.0 donde <nombre> es el nombre del TCTI, el valor de <nombre> puede proporcionarse en lugar del nombre completo del archivo de la biblioteca. Véase 'EJEMPLOS' a continuación.
'conf-tcti'
La cadena de configuración que se pasa a la biblioteca TCTI durante la inicialización.

Si se omite esta opción (o se proporciona una cadena NULL) se utiliza un TCTI predeterminado en su configuración predeterminada. Si la cadena no contiene dos puntos, se interpretará únicamente como 'nombre-tcti'. Para proporcionar solo la cadena de configuración (utilizando el TCTI predeterminado) el primer carácter de la cadena pasada a esta opción debe ser un dos puntos seguido de la cadena de configuración. Véanse los ejemplos a continuación.

-o, --allow-root
Permite que el demonio se ejecute como root. Si esta opción no se proporciona, el demonio se negará a ejecutarse como usuario root. El uso de esta opción **no** es recomendable.
-m, --max-connections
Establece un límite superior en el número de conexiones de clientes concurrentes permitidas. Una vez alcanzado este número de conexiones de clientes, se rechazarán las nuevas conexiones con un error. Si no se especifica la opción, el valor predeterminado es 27.
-f, --flush-all
Descarga todos los objetos y sesiones al iniciar el demonio.
-l, --logger
Dirige la salida de registro a un destino de registro con nombre. Los destinos admitidos son stdout y syslog. Si no se especifica la opción de registrador, el valor predeterminado es stdout.
-e, --max-sessions
Establece un límite superior en el número de sesiones que cada conexión de cliente puede crear (cargadas o activas) en un momento dado. Si no se especifica la opción, el valor predeterminado es 4.
-r, --max-transients
Establece un límite superior en el número de objetos transitorios que cada conexión de cliente puede cargar. Una vez alcanzado este número de objetos, los intentos de cargar nuevos objetos transitorios generarán un error. Si no se especifica la opción, el valor predeterminado es 27.
-n, --dbus-name
Reclama el nombre dado en dbus. Esta opción anula el valor predeterminado de com.intel.tss2.Tabrmd.
-g, --prng-seed-file
Lee la semilla para el generador de números pseudoaleatorios desde el archivo proporcionado.
-s, --session
Conecta el demonio al bus de sesión. Si no se especifica la opción, el demonio se conecta al bus del sistema.
-v, --version
Muestra la cadena de versión.

EJEMPLOS

Ejecutar el demonio con TCTI predeterminado y opciones:
tpm2-abrmd
Ejecutar el demonio con TCTI predeterminado y cadena de configuración proporcionada:
tpm2-abrmd --tcti=":/dev/tpm0"
Esto es equivalente a:
tpm2-abrmd --tcti="device:/dev/tpm0"
tpm2-abrmd --tcti="libtss2-tcti-device.so.0:/dev/tpm0"
Tener el demonio usando la biblioteca TCTI del simulador swtpm TPM2
Esto se conecta a un simulador TPM2 a través de swtpm TCP.
tpm2-abrmd --tcti="swtpm"
tpm2-abrmd --tcti="libtss2-tcti-swtpm.so.0"
Tener el demonio usando la biblioteca TCTI 'libtss2-tcti-swtpm.so.0' y la cadena de configuración
tpm2-abrmd --tcti=swtpm:host=127.0.0.1,port=5555"
tpm2-abrmd --tcti="libtss2-tcti-swtpm.so.0:host=127.0.0.1,port=5555"
