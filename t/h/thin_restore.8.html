NOMBRE

thin_restore - restaura el archivo de metadatos de aprovisionamiento fino a un dispositivo o archivo.

SINOPSIS

thin_restore [opciones] -i {archivo xml} -o {dispositivo|archivo}

DESCRIPCIÓN

thin_restore restaura los metadatos de aprovisionamiento fino creados por el destino correspondiente de device-mapper volcados en un archivo con formato XML (ver thin_dump(8)), que opcionalmente pueden ser preprocesados antes de la restauración a otro dispositivo o archivo. Si se restaura a un dispositivo de metadatos, los metadatos pueden ser procesados por el destino de device-mapper.

Esta herramienta no se puede ejecutar en metadatos activos.

OPCIONES

-h, --help
Imprime la ayuda y sale.
-V, --version
Imprime la información de la versión y sale.
-q, --quiet
Suprime los mensajes de salida, devuelve solo el código de salida.
-i, --input {archivo xml}
Archivo de entrada que contiene los metadatos XML.
-o, --output {dispositivo|archivo}
Archivo o dispositivo de salida para los metadatos binarios restaurados.
    Si se utiliza un archivo para la salida, este debe estar preasignado y
    ser lo suficientemente grande para contener los metadatos.
--transaction-id {natural}
Sobrescribe el ID de transacción dado en el xml de entrada.
--data-block-size {natural}
Sobrescribe el tamaño del bloque de datos dado en el xml de entrada.
--nr-data-blocks {natural}
Sobrescribe el número de bloques de datos dado en el xml de entrada.

EJEMPLO

Restaura los metadatos de aprovisionamiento fino con formato XML en el archivo de metadatos al volumen lógico /dev/vg/metadata para su posterior procesamiento por el destino de device-mapper correspondiente:

    $ thin_restore -i metadatos -o /dev/vg/metadatos

DIAGNÓSTICOS

thin_restore devuelve un código de salida de 0 para éxito o 1 para error.

VER TAMBIÉN

thin_dump(8), thin_check(8), thin_repair(8), thin_rmap(8), thin_metadata_size(8)
