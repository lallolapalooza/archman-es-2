NOMBRE

thin_repair - repara metadatos binarios de aprovisionamiento fino.

SINOPSIS

thin_repair [opciones] -i {dispositivo|archivo} -o {dispositivo|archivo}

DESCRIPCIÓN

thin_repair lee metadatos binarios de aprovisionamiento fino creados por el target de device-mapper respectivo desde un dispositivo o archivo, los repara y los escribe en un dispositivo o archivo diferente. Si se escriben en un dispositivo de metadatos, los metadatos pueden ser procesados por el target de device-mapper.

Esta herramienta no puede ejecutarse en metadatos activos.

OPCIONES

-h, --help
Muestra la ayuda y sale.
-V, --version
Muestra la información de la versión y sale.
-i, --input {dispositivo|archivo}
Archivo o dispositivo de entrada con datos binarios.
-o, --output {dispositivo|archivo}
Archivo o dispositivo de salida para datos binarios.
    Si se utiliza un archivo para la salida, este debe estar preasignado y ser
    lo suficientemente grande para contener los metadatos.
--transaction-id {natural}
Sobrescribe el ID de transacción dado en el XML de entrada.
--data-block-size {natural}
Sobrescribe el tamaño del bloque de datos dado en el XML de entrada.
--nr-data-blocks {natural}
Sobrescribe el número de bloques de datos dado en el XML de entrada.

EJEMPLO

Lee los metadatos binarios de aprovisionamiento fino del archivo metadata, los repara y los escribe en el volumen lógico /dev/vg/metadata para su posterior procesamiento por el target de device-mapper correspondiente:

    $ thin_repair -i metadata -o /dev/vg/metadata

DIAGNÓSTICO

thin_repair devuelve un código de salida de 0 para éxito o 1 para error.
