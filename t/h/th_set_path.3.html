NOMBRE

th_set_from_stat, th_finish, th_set_type, th_set_path, th_set_link, th_set_device, th_set_user, th_set_group, th_set_mode, th_set_mtime, th_set_size - establecer campos de una cabecera de archivo tar

SINOPSIS

#include <libtar.h>

void th_set_from_stat(TAR *t, struct stat *s);

void th_set_type(TAR *t, mode_t mode);

void th_set_path(TAR *t, char *pathname);

void th_set_link(TAR *t, char *linkname);

void th_set_device(TAR *t, dev_t device);

void th_set_user(TAR *t, uid_t uid);

void th_set_group(TAR *t, gid_t gid);

void th_set_mode(TAR *t, mode_t mode);

void th_set_mtime(TAR *t, time_t fmtime);

void th_set_size(TAR *t, off_t fsize);

void th_finish(TAR *t);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

Las funciones th_set_*() establecen cada uno un campo individual de la cabecera tar actual asociada con el manejador t de TAR. Las funciones th_set_user() y th_set_group() establecen tanto los campos numéricos de ID de usuario/grupo como los campos de texto de nombre de usuario/grupo. Las otras funciones establecen solo el campo al que se refieren.

La función th_set_from_stat() utiliza las otras funciones th_set_*() para establecer todos los campos a la vez, basándose en los datos que se le pasan en el argumento s.

La función th_finish() establece las constantes apropiadas para los campos de magia y versión. Luego calcula la suma de verificación de la cabecera y rellena el campo de suma de verificación.
