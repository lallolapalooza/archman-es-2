thin_migrate(8) Manual del Administrador del Sistema thin_migrate(8)

NOMBRE

thin_migrate

SINOPSIS

thin_migrate [opciones] --source-dev {dispositivo} --dest-dev {dispositivo}
thin_migrate [opciones] --source-dev {dispositivo} --dest-file {archivo}

DESCRIPCIÓN

thin_migrate copia los bloques de datos aprovisionados de un dispositivo fino a otro dispositivo o archivo. Está diseñado para clonar una instantánea de solo lectura o un volumen fino dentro de un pool fino activo. Se requiere una instantánea de metadatos para leer los mapeos de datos.

OPCIONES

-h, --help
Imprime la ayuda y sale.
-V, --version
Imprime la información de la versión y sale.
--source-dev {dispositivo}
El dispositivo fino de solo lectura de entrada para copiar.
--dest-dev {dispositivo}
El dispositivo de salida como destino de la copia.
--dest-file {archivo}
El archivo de salida como destino de la copia.
-q, --quit
Suprime los mensajes de salida, devuelve solo el código de salida.
--buffer-size-meg {tamaño}
Especifica el tamaño de los búferes de datos, en megabytes.

EJEMPLO

Suponiendo que existe una instantánea fina 'vg/snap' para copiar, primero debemos establecer la instantánea como de solo lectura:

    $ lvchange vg/snap --permission r
A continuación, crea una instantánea de metadatos para ejecutar thin_migrate: 
    $ dmsetup message vg-mythinpool-tpool 0 reserve_metadata_snap
Una vez creada la instantánea de metadatos, copia la instantánea en otro volumen lineal o fino. El volumen de destino debe tener el mismo tamaño que el dispositivo de origen. 
    $ thin_migrate --src-device /dev/vg/snap --dest-device /dev/vg2/dest
Alternativamente, copia la instantánea en un archivo. thin_migrate puede crear opcionalmente el archivo de destino si no está presente, o el tamaño del archivo se truncará para que coincida con el del dispositivo de origen. 
    $ thin_migrate --src-device /dev/vg/snap --dest-file dest.bin
Finalmente, libera la instantánea de metadatos después de que thin_migrate termine su trabajo: 
    $ dmsetup message vg-mythinpool-tpool 0 release_metadata_snap

DIAGNÓSTICOS

thin_migrate devuelve un código de salida de 0 para éxito o 1 para error.
