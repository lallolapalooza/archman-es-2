NOMBRE

thcsyn6

SINOPSIS

thcsyn6 [-aAcdDfrORS] [-i microsegundos] [-m mac_dst] [-p puerto] [-s ip_fuente6] interfaz destino puerto

OPCIONES

 -i      intervalo de envío de paquetes (en microsegundos)
 -a      añade encabezado hop-by-hop con router alert
 -d      añade encabezado de destino (se puede establecer hasta 64 veces)
 -f      añade encabezado de fragmentación atómica (se puede establecer hasta 64 veces)
 -A      envía paquetes TCP-ACK
 -S      envía paquetes TCP-SYN-ACK
 -r      aleatoriza el origen de tu prefijo /64
 -R      aleatoriza completamente el origen
 -D      aleatoriza el destino (trátalo como /64)
 -O      añade una cookie de TCP Fast Open (solo paquetes SYN)
 -m dstmac     usa esta dirección MAC de destino
 -s sourceip6  usa esta como dirección IP de origen IPv6
 -p port       usa un puerto de origen fijo
Inunda el puerto de destino con paquetes TCP-SYN. Si proporcionas "x" como puerto,
este se aleatoriza.
