NOMBRE

threadsnoop.bt - Rastrea la creación de hilos mediante pthread_create(). Utiliza bpftrace/eBPF.

SINOPSIS

threadsnoop.bt

DESCRIPCIÓN

threadsnoop rastrea las llamadas a pthread_create(), mostrando esta ruta de creación de hilos. Esto se puede utilizar para la caracterización y descubrimiento de cargas de trabajo, y es un complemento de execsnoop.bt(8) que rastrea execve(2).

Esto funciona rastreando pthread_create() desde libpthread.so.0. Es posible que sea necesario ajustar la ruta a esta biblioteca en el código fuente de la herramienta para que coincida con su sistema.

Dado que esto utiliza BPF, solo el usuario root puede usar esta herramienta.

REQUISITOS

CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrea las llamadas a pthread_create():
# threadsnoop.bt

CAMPOS

TIEMPO(ms)
Tiempo transcurrido desde que la herramienta comenzó a rastrear (en milisegundos).
PID
El ID del proceso.
COMM
El nombre del proceso (hilo).
FUNCIÓN
El nombre de la rutina de inicio, si el símbolo está disponible, de lo contrario, una dirección hexadecimal para la dirección de la rutina de inicio.

SOBRECARGA

Se espera que la creación de hilos sea baja (<< 1000/s), por lo que se espera que la sobrecarga de esta herramienta sea insignificante.

FUENTE

Esta herramienta se originó en el libro "BPF Performance Tools", publicado por Addison Wesley (2019):

http://www.brendangregg.com/bpf-performance-tools-book.html

Consulte el libro para obtener más documentación sobre esta herramienta.

Esta versión se encuentra en el repositorio de bpftrace:

https://github.com/bpftrace/bpftrace

Busque también en la distribución de bpftrace un archivo _examples.txt complementario que contenga ejemplos de uso, salida y comentarios para esta herramienta.
