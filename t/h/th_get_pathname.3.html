th_get_pathname(3)

Paquete: libtar

Licencias: BSD

th_get_pathname(3) Llamadas a la biblioteca C th_get_pathname(3)

NOMBRE

th_get_pathname, th_get_uid, th_get_gid, th_get_mode, th_get_crc, th_get_size, th_get_mtime, th_get_devmajor, th_get_devminor, th_get_linkname - extraer campos individuales de una cabecera tar

TH_ISREG, TH_ISLNK, TH_ISSYM, TH_ISCHR, TH_ISBLK, TH_ISDIR, TH_ISFIFO - determinar a qué tipo de archivo se refiere una cabecera tar

TH_ISLONGNAME, TH_ISLONGLINK - determinar si se utilizan las extensiones GNU

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

Las funciones th_get_*() extraen campos individuales de la cabecera tar actual asociada con el manejador TAR t.

Las macros TH_IS*() se utilizan para evaluar a qué tipo de archivo apunta la cabecera tar actual asociada con el manejador TAR t.

Las macros TH_ISLONGNAME() y TH_ISLONGLINK() evalúan si las extensiones GNU están siendo utilizadas por la cabecera tar actual asociada con el manejador TAR t. Esto solo es relevante si se utilizó la opción TAR_GNU cuando se llamó a tar_open().
