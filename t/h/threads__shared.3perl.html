threads::shared(3perl) Guía del programador de Perl threads::shared(3perl)

NOMBRE

threads::shared - Extensión de Perl para compartir estructuras de datos entre hilos

VERSIÓN

Este documento describe threads::shared versión 1.70

SINOPSIS

use threads;
use threads::shared;
my $var :shared;
my %hsh :shared;
my @ary :shared;
my ($scalar, @array, %hash);
share($scalar);
share(@array);
share(%hash);
$var = $scalar_value;
$var = $shared_ref_value;
$var = shared_clone($non_shared_ref_value);
$var = shared_clone({'foo' => [qw/foo bar baz/]});
$hsh{'foo'} = $scalar_value;
$hsh{'bar'} = $shared_ref_value;
$hsh{'baz'} = shared_clone($non_shared_ref_value);
$hsh{'quz'} = shared_clone([1..3]);
$ary[0] = $scalar_value;
$ary[1] = $shared_ref_value;
$ary[2] = shared_clone($non_shared_ref_value);
$ary[3] = shared_clone([ {}, [] ]);
{ lock(%hash); ...  }
cond_wait($scalar);
cond_timedwait($scalar, time() + 30);
cond_broadcast(@array);
cond_signal(%hash);
my $lockvar :shared;
# cond var != lock var
cond_wait($var, $lockvar);
cond_timedwait($var, time()+30, $lockvar);

DESCRIPCIÓN

Por defecto, las variables son privadas para cada hilo, y cada hilo recién creado obtiene una copia privada de cada variable existente. Este módulo permite compartir variables entre diferentes hilos (y pseudo-forks en Win32). Se utiliza junto con el módulo threads.

Este módulo solo admite el intercambio de los siguientes tipos de datos: escalares y referencias a escalares, arrays y referencias a arrays, y hashes y referencias a hashes.

EXPORT

Las siguientes funciones son exportadas por este módulo: "share", "shared_clone", "is_shared", "cond_wait", "cond_timedwait", "cond_signal" y "cond_broadcast"

Tenga en cuenta que si este módulo se importa cuando threads aún no ha sido cargado, entonces todas estas funciones no tendrán efecto. Esto permite escribir módulos que funcionarán tanto en entornos con hilos como sin ellos.

FUNCIONES

share VARIABLE
"share" toma una variable y la marca como compartida: 
my ($scalar, @array, %hash);
share($scalar);
share(@array);
share(%hash);

"share" devolverá el valor r de solo lectura compartido, pero siempre como una referencia.

Las variables también se pueden marcar como compartidas en tiempo de compilación utilizando el atributo ":shared":

my ($var, %hash, @array) :shared;

Las variables compartidas solo pueden almacenar escalares, referencias a variables compartidas o referencias a datos compartidos (discutido en la siguiente sección):

my ($var, %hash, @array) :shared;
my $bork;
# Almacenamiento de escalares
$var = 1;
$hash{'foo'} = 'bar';
$array[0] = 1.5;
# Almacenamiento de referencias compartidas
$var = \%hash;
$hash{'ary'} = \@array;
$array[1] = \$var;
# Los siguientes son errores:
#   $var = \$bork;                    # ref de variable no compartida
#   $hash{'bork'} = [];               # ref de array no compartido
#   push(@array, { 'x' => 1 });       # ref de hash no compartido
shared_clone REF
"shared_clone" toma una referencia y devuelve una versión compartida de su argumento, realizando una copia profunda de cualquier elemento no compartido. Cualquier elemento compartido en el argumento se utiliza tal cual (es decir, no se clona). 
my $cpy = shared_clone({'foo' => [qw/foo bar baz/]});

El estado del objeto (es decir, la clase a la que está bendecido un objeto) también se clona.

my $obj = {'foo' => [qw/foo bar baz/]};
bless($obj, 'Foo');
my $cpy = shared_clone($obj);
print(ref($cpy), "\n");         # Muestra 'Foo'

Para clonar referencias vacías de arrays o hashes, también se puede utilizar lo siguiente:

$var = &share([]);   # Igual que $var = shared_clone([]);
$var = &share({});   # Igual que $var = shared_clone({});

No todos los tipos de datos de Perl se pueden clonar (por ejemplo, globs, referencias a código). Por defecto, "shared_clone" generará un error si encuentra tales elementos. Para cambiar este comportamiento a una advertencia, establezca lo siguiente:

$threads::shared::clone_warn = 1;

En este caso, "undef" se sustituirá por el elemento a clonar. Si se establece en cero:

$threads::shared::clone_warn = 0;

entonces la sustitución de "undef" se realizará de forma silenciosa.

is_shared VARIABLE
"is_shared" comprueba si la variable especificada está compartida o no. Si está compartida, devuelve el ID interno de la variable (similar a refaddr() (ver Scalar::Util). De lo contrario, devuelve "undef". 
if (is_shared($var)) {
    print("\$var está compartido\n");
} else {
    print("\$var no está compartido\n");
}

Cuando se utiliza en un elemento de un array o hash, "is_shared" comprueba si el elemento especificado pertenece a un array o hash compartido. (No comprueba el contenido de ese elemento). 

my %hash :shared;
if (is_shared(%hash)) {
    print("\&%hash está compartido\n");
}
$hash{'elem'} = 1;
if (is_shared($hash{'elem'})) {
    print("\$hash{'elem'} está en un hash compartido\n");
}
lock VARIABLE
"lock" coloca un bloqueo consultivo en una variable hasta que el bloqueo salga del ámbito. Si la variable está bloqueada por otro hilo, la llamada a "lock" se bloqueará hasta que esté disponible. Múltiples llamadas a "lock" por el mismo hilo desde ámbitos anidados dinámicamente son seguras: la variable permanecerá bloqueada hasta que el bloqueo más externo de la variable salga del ámbito.

"lock" sigue las referencias exactamente *un* nivel:

my %hash :shared;
my $ref = \%hash;
lock($ref);           # Esto es equivalente a lock(%hash)

Tenga en cuenta que no puede desbloquear explícitamente una variable; solo puede esperar a que el bloqueo salga del ámbito. Esto se logra más fácilmente bloqueando la variable dentro de un bloque.

my $var :shared;
{
    lock($var);
    # $var está bloqueado desde aquí hasta el final del bloque
    ...
}
# $var ahora está desbloqueado

Como los bloqueos son consultivos, no impiden el acceso o la modificación de datos por parte de otro hilo que no intente obtener un bloqueo sobre la variable.

No puede bloquear los elementos individuales de una variable contenedora:

my %hash :shared;
$hash{'foo'} = 'bar';
#lock($hash{'foo'});          # Error
lock(%hash);                  # Funciona

Si necesita un control más detallado sobre el acceso a variables compartidas, consulte Thread::Semaphore.

cond_wait VARIABLE
cond_wait CONDVAR, LOCKVAR
La función "cond_wait" toma una variable bloqueada como parámetro, desbloquea la variable y se bloquea hasta que otro hilo realice una llamada a "cond_signal" o "cond_broadcast" para la misma variable bloqueada. La variable en la que se bloqueó "cond_wait" se vuelve a bloquear después de que se satisfaga "cond_wait". Si hay varios hilos haciendo "cond_wait" sobre la misma variable, todos excepto uno volverán a bloquearse esperando para readquirir el bloqueo sobre la variable. (Así que si solo está usando "cond_wait" para sincronización, libere el bloqueo lo antes posible). Las dos acciones de desbloquear la variable y entrar en el estado de espera bloqueada son atómicas, las dos acciones de salir del estado de espera bloqueada y volver a bloquear la variable no lo son.

En su segunda forma, "cond_wait" toma una variable compartida y desbloqueada seguida de

por una variable compartida y bloqueada. La segunda variable no está bloqueada y la ejecución del hilo se suspende hasta que otro hilo señale la primera variable.

Es importante notar que la variable puede ser notificada incluso si ningún hilo realiza una "cond_signal" o "cond_broadcast" sobre la variable. Por lo tanto, es importante verificar el valor de la variable y volver a esperar si el requisito no se cumple. Por ejemplo, para pausar hasta que un contador compartido caiga a cero:

{ lock($counter); cond_wait($counter) until $counter == 0; }
cond_timedwait VARIABLE, ABS_TIMEOUT
cond_timedwait CONDVAR, ABS_TIMEOUT, LOCKVAR
En su forma de dos argumentos, "cond_timedwait" toma una variable bloqueada y un tiempo de espera absoluto en segundos de *época* (ver time() en perlfunc para más detalles) como parámetros, desbloquea la variable, y se bloquea hasta que se alcance el tiempo de espera o otro hilo señale la variable. Se devuelve un valor falso si se alcanza el tiempo de espera, y un valor verdadero en caso contrario. En cualquier caso, la variable se vuelve a bloquear al regresar.

Al igual que "cond_wait", esta función puede tomar una variable compartida y bloqueada como parámetro adicional; en este caso, el primer parámetro es una variable de condición no bloqueada protegida por una variable de bloqueo distinta.

De nuevo, al igual que "cond_wait", el despertar y la readquisición del bloqueo no son atómicos, y siempre debes verificar tu condición deseada después de que esta función regrese. Dado que el tiempo de espera es un valor absoluto, sin embargo, no tiene que ser recalculado con cada pasada:

lock($var);
my $abs = time() + 15;
until ($ok = desired_condition($var)) {
    last if !cond_timedwait($var, $abs);
}
# Lo obtuvimos si $ok, ¡de lo contrario, se agotó el tiempo!
cond_signal VARIABLE
La función "cond_signal" toma una variable bloqueada como parámetro y desbloquea un hilo que está realizando "cond_wait" sobre esa variable. Si más de un hilo está bloqueado en un "cond_wait" sobre esa variable, solo uno (y cuál es indeterminado) será desbloqueado.

Si no hay hilos bloqueados en un "cond_wait" sobre la variable, la señal se descarta. Al bloquear siempre antes de señalar, puedes (con cuidado) evitar señalar antes de que otro hilo haya entrado en cond_wait().

"cond_signal" normalmente generará una advertencia si intentas usarla en una variable no bloqueada. En las raras ocasiones en que hacer esto pueda ser sensato, puedes suprimir la advertencia con:

{ no warnings 'threads'; cond_signal($foo); }
cond_broadcast VARIABLE
La función "cond_broadcast" funciona de manera similar a "cond_signal". "cond_broadcast", sin embargo, desbloqueará todos los hilos que están bloqueados en un "cond_wait" sobre la variable bloqueada, en lugar de solo uno.

OBJETOS

threads::shared exporta una versión de bless() que funciona en objetos compartidos de tal manera que las *bendiciones* se propagan entre hilos.

# Crear un objeto 'Foo' compartido
my $foo :shared = shared_clone({});
bless($foo, 'Foo');
# Crear un objeto 'Bar' compartido
my $bar :shared = shared_clone({});
bless($bar, 'Bar');
# Poner 'bar' dentro de 'foo'
$foo->{'bar'} = $bar;
# Rebendecir los objetos a través de un hilo
threads->create(sub {
    # Rebendecir el objeto externo
    bless($foo, 'Yin');
    # No se puede rebendecir directamente el objeto interno
    #bless($foo->{'bar'}, 'Yang');
    # Recuperar y rebendecir el objeto interno
    my $obj = $foo->{'bar'};
    bless($obj, 'Yang');
    $foo->{'bar'} = $obj;
})->join();
print(ref($foo),          "\n");    # Imprime 'Yin'
print(ref($foo->{'bar'}), "\n");    # Imprime 'Yang'
print(ref($bar),          "\n");    # También imprime 'Yang'

NOTAS

threads::shared está diseñado para deshabilitarse silenciosamente si los hilos no están disponibles. Esto te permite escribir módulos y paquetes que pueden ser utilizados tanto en aplicaciones con hilos como sin ellos.

Si quieres acceso a los hilos, debes "use threads" antes de "use threads::shared". threads emitirá una advertencia si lo usas después de threads::shared.

ADVERTENCIAS

cond_broadcast() llamado en variable no bloqueada
cond_signal() llamado en variable no bloqueada
Ver "cond_signal VARIABLE", arriba.

ERRORES Y LIMITACIONES

Cuando se usa "share" en arreglos, hashes, referencias a arreglos o referencias a hashes, cualquier dato que contengan se perderá.

my @arr = qw(foo bar baz);
share(@arr);
# @arr está ahora vacío (es decir, == ());
# Crear un objeto 'foo'
my $foo = { 'data' => 99 };
bless($foo, 'foo');
# Compartir el objeto
share($foo);        # El contenido se borra ahora
print("ERROR: \$foo está vacío\n")
    if (! exists($foo->{'data'}));

Por lo tanto, llena dichas variables *después* de declararlas como compartidas. (Los escalares y las referencias a escalares no se ven afectados por este problema.)

Bendecir un objeto compartido después de que ha sido anidado en otro objeto compartido no propaga la bendición a la referencia compartida:

my $foo = &share({});
my $bar = &share({});
$bar->{foo} = $foo;
bless($foo, 'baz');   # $foo es ahora de clase 'baz',
                      # pero $bar->{foo} no está bendecido.

Por lo tanto, debes bendecir los objetos antes de compartirlos.

A menudo no es prudente compartir un objeto a menos que la clase misma haya sido escrita para admitir la compartición. Por ejemplo, el destructor de un objeto compartido puede ser llamado varias veces, una por cada salida del ámbito del hilo, o puede que no sea llamado en absoluto si está incrustado dentro de otro objeto compartido. Otro problema es que el contenido de los objetos basados en hash se perderá debido a la limitación mencionada anteriormente. Ver examples/class.pl (en la distribución CPAN de este módulo) para saber cómo crear una clase que admita la compartición de objetos.

Los destructores pueden no ser llamados en objetos si esos objetos todavía existen en el momento de la destrucción global. Si los destructores deben ser llamados, asegúrate de que no haya referencias circulares y de que nada esté haciendo referencia a los objetos antes de que termine el programa.

No soporta "splice" en arreglos. No soporta cambiar explícitamente las longitudes de los arreglos a través de $#array -- usa "push" y "pop" en su lugar.

Tomar referencias a los elementos de arreglos y hashes compartidos no autovivifica los elementos, ni tampoco el rebanado de un arreglo/hash compartido sobre índices/claves inexistentes autovivifica los elementos.

share() te permite share($hashref->{key}) y share($arrayref->[idx]) sin dar ningún mensaje de error. Pero "$hashref->{key}" o "$arrayref->[idx]" no está compartido, lo que provoca el error "lock can only be used on shared values" cuando intentas lock($hashref->{key}) o lock($arrayref->[idx]) en otro hilo.

Usar refaddr() no es confiable para probar si dos referencias compartidas son equivalentes (por ejemplo, al probar referencias circulares). Usa is_shared() en su lugar:

use threads;
use threads::shared;
use Scalar::Util qw(refaddr);
# Si ref es compartido, usa el ID interno de threads::shared.
# De lo contrario, usa refaddr().
my $addr1 = is_shared($ref1) || refaddr($ref1);
my $addr2 = is_shared($ref2) || refaddr($ref2);
if ($addr1 == $addr2) {
    # Las referencias son equivalentes
}

each() no funciona correctamente en referencias compartidas incrustadas en estructuras compartidas. Por ejemplo:

my %foo :shared;
$foo{'bar'} = shared_clone({'a'=>'x', 'b'=>'y', 'c'=>'z'});
while (my ($key, $val) = each(%{$foo{'bar'}})) {
    ...
}

Cualquiera de las siguientes opciones funcionará en su lugar:

my $ref = $foo{'bar'};
while (my ($key, $val) = each(%{$ref})) {
    ...
}
foreach my $key (keys(%{$foo{'bar'}})) {
    my $val = $foo{'bar'}{$key};
    ...
}

Este módulo soporta variables de doble valor creadas usando dualvar() de Scalar::Util. Sin embargo, aunque $! actúa como un dualvar, está implementado como un SV enlazado. Para propagar su valor, usa la siguiente construcción, si es necesario:

my $errno :shared = dualvar($!,$!);
