NOMBRE

th_print, th_print_long_ls - imprime información sobre una cabecera de archivo tar

SINOPSIS

#include <libtar.h>

void th_print_long_ls(TAR *t);

void th_print(TAR *t);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función th_print_long_ls() imprime una línea en stdout que describe el archivo apuntado por la cabecera de archivo actual asociada con el manejador TAR t. La salida es similar a la de "ls -l".

La función th_print() imprime el valor de cada campo de la cabecera de archivo actual asociada con el manejador TAR t en stdout. Esto se usa principalmente para fines de depuración.

VER TAMBIÉN
