NOMBRE

th_read, th_write - lee y escribe un bloque de cabecera de archivo de un archivo tar

SINOPSIS

#include <libtar.h>

int th_read(TAR *t);

int th_write(TAR *t);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función th_read() lee el siguiente bloque del archivo tar asociado con el manejador TAR t. Luego, establece la cabecera tar actual asociada con t con el contenido del bloque leído.

La función th_write() escribe el contenido de la cabecera tar actual asociada con t en el archivo tar asociado con t.

VALOR DEVUELTO

Al completarse con éxito, th_read() y th_write() devolverán 0. En caso de error, devolverán -1 y establecerán errno a un valor apropiado.

En caso de EOF, th_read() devolverá 1.

ERRORES

th_read() y th_write() fallarán si:

EINVAL
Se leyeron o escribieron menos de T_BLOCKSIZE bloques.

VER TAMBIÉN

tar_block_read(3), tar_block_write(3)
