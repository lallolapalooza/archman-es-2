NOMBRE

thcping6

SINOPSIS

thcping6 [-EafqxO] [-e ethertype] [-H t:l:v] [-D t:l:v] [-F dst] [-e ethertype] [-L length] [-N nextheader] [-V version] [-t ttl] [-c class] [-l label] [-d size] [-S port|-U port|-T type -C code] interface src6 dst6 [srcmac [dstmac [data]]]

OPCIONES

  -T numero       Tipo ICMPv6 a enviar (predeterminado: 128 = ping)
  -C numero       Código ICMPv6 a enviar (predeterminado: 0)
  -S puerto        usar un paquete TCP SYN en el puerto definido en lugar de ping
  -U puerto        usar un paquete UDP en el puerto definido en lugar de ping
  -n conteo       cuántas veces enviar el paquete (predeterminado: 1)
  -h              mostrar más opciones de línea de comandos (¡ayuda!)
Puedes poner una "x" en src6, srcmac y dstmac para un valor automático.
Crea un paquete ICMPv6/TCP/UDP con opciones especiales de cabecera IPv6 o EH.
Devuelve -1 en caso de error o no respuesta, 0 si hay respuesta normal o 1 si hay respuesta de error.
