THC-IPv6(8) Manual del Administrador del Sistema THC-IPv6(8)

NOMBRE

The Hacker Choice's IPv6 Attack Toolkit (también conocido como thc-ipv6)

SINOPSIS

herramienta [opciones] ...

DESCRIPCIÓN

Esta página del manual documenta brevemente cada una de las herramientas de attack-toolkit6. No todas las opciones se enumeran aquí; para ver la lista completa de opciones de cada herramienta, ejecútala con -h.

Tenga en cuenta que en Debian (si lee esto en Debian) los nombres de los comandos van precedidos de atk6-, por lo que, por ejemplo, la herramienta alive6 debería invocarse como atk6-alive6. Esta es una modificación exclusiva de Debian.
address6 <direccion-mac/direccion-ipv4/direccion-ipv6> [prefijo-ipv6]
Convierte una dirección mac o ipv4 en una dirección ipv6 (local de enlace si no se proporciona prefijo como segunda opción) o, cuando se proporciona una dirección ipv6, imprime la dirección mac o ipv4. Imprime todas las variaciones posibles. Devuelve -1 en caso de error o el número de variaciones encontradas.
alive6 <interfaz> [direccion-unicast-o-multicast [router-remoto]]
Muestra direcciones activas en el segmento. Si se especifica un router remoto, los paquetes se envían con una cabecera de enrutamiento precedida de fragmentación.
covert_send6 <interfaz> <objetivo> <archivo> [puerto]
Envía el contenido del ARCHIVO de forma encubierta al objetivo.
covert_send6d <interfaz> <archivo>
Escribe el contenido recibido de forma encubierta en el ARCHIVO.
denial6 <interfaz> <destino> <numero-caso-prueba>
Realiza varios ataques de denegación de servicio en un objetivo.
detect_sniffer6 <interfaz> [ip-objetivo]
Comprueba si los sistemas en la LAN local están espiando. Funciona contra sistemas Windows, Linux, OS/X y *BSD.
dnssecwalk [-e46] <servidor-dns> <dominio>
Realiza walking de NSEC de DNSSEC.
dos_mld <interfaz>
Esta herramienta impide que nuevas interfaces ipv6 suban, enviando respuestas a comprobaciones duplicadas de ip6 (DAD). Esto resulta en una DoS para los nuevos dispositivos ipv6.
dos-new-ip6 <interfaz>
Esta herramienta impide que nuevas interfaces ipv6 suban, enviando respuestas a comprobaciones duplicadas de ip6 (DAD). Esto resulta en una DoS para los nuevos dispositivos ipv6.
detect-new-ip6 <interfaz> [nombre-script]
Esta herramienta detecta nuevas direcciones ipv6 que se unen a la red local. Si se proporciona un nombre-script, se ejecutará con la dirección IPv6 detectada como opción.
dnsdict6 [-t HILOS] <dominio> [archivo-diccionario]
Enumera un dominio en busca de entradas DNS, utiliza un archivo de diccionario si se proporciona o una lista integrada en caso contrario.
dnsrevenum6 <servidor-dns> <direccion-ipv6>
Realiza una rápida enumeración de DNS inversa.
dump_router6 <interfaz>
Vuelca todos los routers locales y su información.
dump_dhcp6 <interfaz>
Vuelca todos los servidores DHCPv6 y su información
exploit6 <interfaz> <destino> [numero-caso-prueba]
Realiza exploits de varias vulnerabilidades IPv6 conocidas por CVE en el destino.
extract_hosts6 <archivo>
Imprime las partes de host de las direcciones ipv6 en el archivo.
extract_networks6 <interfaz>
Imprime las redes encontradas en el archivo.
fake_advertise6 <interfaz> <direccion-ip> [direccion-objetivo [direccion-mac-propia]]
Anuncia una dirección ipv6 en la red (con la MAC propia si no está definida) enviándola a la dirección multicast de todos los nodos si no se especifica objetivo.
fake_dhcps6 <interfaz> <direccion-red/longitud-prefijo> <servidor-dns>
Servidor DHCPv6 falso. Se utiliza para configurar una dirección y establecer un servidor DNS.
fake_dns6d <interfaz> <direccion-ipv6>
Servidor DNS falso que proporciona la misma dirección IPv6 a cualquier solicitud de consulta.
fake_dnsupdate6 <servidor-dns> <fqdn> <direccion-ipv6>
Envía solicitudes falsas de actualización DNS.
fake_mipv6 <interfaz> <direccion-home> <direccion-home-agent> <direccion-care-of>
Si el agente-home de movil IPv6 está mal configurado para aceptar actualizaciones MIPV6 sin IPSEC, esto redirigirá todos los paquetes para la direccion-home a la direccion-care-of.
fake_mld6 <interfaz> <direccion-multicast> [[direccion-objetivo] [[ttl] [[ip-propia] [direccion-mac-propia]]]]
Anuncia tu presencia en un grupo multicast de tu elección.
fake_mld26 [-l] <interfaz> <agregar|eliminar|consultar> [direccion-multicast [direccion-objetivo [ttl [ip-propia [direccion-mac-propia [direccion-mac-destino]]]]]]
Utiliza el protocolo MLDv2. Solo una parte de lo que el protocolo es capaz de hacer es posible de implementar a través de una línea de comandos.
fake_mldrouter6 [-l] <interfaz> <anunciar|solicitar|terminar> [ip-propia [direccion-mac-propia]]
Anuncia, elimina o solicita un router MLD - tú mismo u otros.
fake_pim6 [-t ttl] [-s src6] [-d dst6] <interfaz> {<hola> [prioridad-dr]|{unirse|pruina} <vecino6> <multicast6> <objetivo6>}
El comando hola acepta opcionalmente la prioridad del DR (por defecto: 0).
fake_router6 <interfaz> <direccion-ip-enlace-local-router
direccion-red/longitud-prefijo> <mtu> [direccion-mac] Anúnciate como router e intenta convertirte en el router por defecto. Si se proporciona una direccion-mac inexistente, esto resulta en una DoS.
fake_router26 <interfaz>
Similar a fake_router6 con más opciones disponibles.
fake_solicitate6 <interfaz> <ip-solicitada>
Solicita una dirección IPv6 en la red, enviándola a la dirección multicast de todos los nodos.
firewall6 [-u] <interfaz> <destino> <puerto> [numero-caso-prueba]
Realiza varios intentos de elusión de ACL para comprobar implementaciones. Por defecto utiliza puertos TCP; la opción -u cambia a UDP. Para que funcionen todos los casos de prueba, el ping ICMPv6 al destino debe estar permitido.
flood_advertise6 <interfaz>
Inunda la red local con anuncios de vecino.
flood_dhcpc6 <interfaz> [nombre-dominio]
Inundador de clientes DHCP. Utilizado para agotar el grupo de direcciones IP que ofrece un servidor DHCP6. Nota: si el grupo es muy grande, esto es más bien inútil.
flood_mld6 <interfaz>
Inunda la red local con informes MLD.
flood_mld26 <interfaz>
Inunda la red local con informes MLDv2.
flood_mldrouter6 <interfaz>
Inunda la red local con anuncios de router MLD.
