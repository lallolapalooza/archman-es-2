NOMBRE

thread-keyring - keyring por hilo

DESCRIPCIÓN

El keyring de hilo es un keyring utilizado para anclar claves en nombre de un proceso. Se crea solo cuando un hilo lo solicita. El keyring de hilo tiene el nombre (descripción) _tid.

Se define un valor especial de número de serie, KEY_SPEC_THREAD_KEYRING, que puede usarse en lugar del número de serie real del keyring de hilo del hilo que llama.

Desde la utilidad keyctl(1), '@t' se puede usar en lugar de un ID de clave numérico de la misma manera, pero como keyctl(1) es un programa que se ejecuta después de un fork, esto carece de utilidad.

Los keyrings de hilo no se heredan a través de clone(2) y fork(2) y se borran con execve(2). Un keyring de hilo se destruye cuando termina el hilo que hace referencia a él.

Inicialmente, un hilo no tiene un keyring de hilo. Si un hilo no tiene un keyring de hilo cuando se accede a él, se creará si se va a modificar; de lo contrario, la operación fallará con el error ENOKEY.
