NOMBRE

nat - acción de traducción de direcciones nativa sin estado

SINOPSIS


tc ... action nat DIRECCIÓN VIEJO NUEVO

DIRECCIÓN := { ingress | egress }

VIEJO := IPV4_ADDR_SPEC

NUEVO := IPV4_ADDR_SPEC

IPV4_ADDR_SPEC := { default | any | all | in_addr[/{prefijo|máscara_red}

DESCRIPCIÓN

La acción nat permite realizar NAT sin la sobrecarga de conntrack, lo cual es deseable si el número de flujos o direcciones sobre las que realizar NAT es grande. Esta acción se usa mejor en combinación con el filtro u32 para permitir búsquedas eficientes de un gran número de reglas NAT sin estado en tiempo constante.

OPCIONES

ingress
Traduce direcciones de destino, es decir, realiza DNAT.
egress
Traduce direcciones de origen, es decir, realiza SNAT.
VIEJO
Especifica las direcciones que deben ser traducidas.
NUEVO
Especifica en qué deben ser traducidas las direcciones de VIEJO.

NOTAS

El formato de dirección aceptado en VIEJO y NUEVO es bastante flexible. Puede consistir en una de las palabras clave default, any o all, representando la dirección IP de todos los ceros, o una combinación de dirección IP y máscara de red o longitud de prefijo separadas por una barra (/). En cualquier caso, el valor de la máscara (o longitud del prefijo) de VIEJO se utiliza también para NUEVO, de modo que se garantiza una correspondencia uno a uno de las direcciones.

La traducción de direcciones se realiza utilizando una combinación de operaciones binarias. Primero, la dirección original (de origen o destino) se compara con el valor de VIEJO. Si la dirección original encaja, se crea la nueva dirección tomando los bits iniciales de NUEVO (definidos por la máscara de red de VIEJO) y tomando los bits restantes de la dirección original.

Existe un soporte rudimentario para protocolos de capa superior, concretamente TCP, UDP e ICMP. Mientras que para los dos primeros solo se realiza el recálculo de la suma de comprobación, la acción también se ocupa de las cabeceras IP incrustadas en los paquetes ICMP traduciendo la dirección respectiva allí también.
