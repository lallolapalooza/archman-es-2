tc-matchall(8)

Paquete: iproute2

Licencias: GPL-2.0-or-later

Clasificador coincidente en tc(8) Linux Clasificador coincidente en tc(8)

NOMBRE

matchall - filtro de control de tráfico que coincide con cada paquete

SINOPSIS


tc filter ... matchall [ skip_sw | skip_hw ] [ action ACCIÓN_ESPEC ] [ classid CLASSID ]

DESCRIPCIÓN

El filtro matchall permite clasificar cada paquete que fluye por el puerto y ejecutar una acción sobre él.

OPCIONES

action ACCIÓN_ESPEC
Aplica una acción del framework de acciones genéricas a los paquetes coincidentes.
classid CLASSID
Inserta los paquetes coincidentes en la clase identificada por CLASSID.
skip_sw
No procesar el filtro por software. Si el hardware no tiene soporte de descarga para este filtro, o si la descarga TC no está habilitada para la interfaz, la operación fallará.
skip_hw
No procesar el filtro por hardware.

EJEMPLOS

Para crear un espejo de entrada desde el puerto eth1 al puerto eth2:

tc qdisc  add dev eth1 handle ffff: clsact
tc filter add dev eth1 ingress                \
        matchall skip_sw                      \
        action mirred egress mirror           \
        dev eth2

El primer comando crea una qdisc clsact con el manejador ffff: en el dispositivo eth1 donde el segundo comando adjunta un filtro matchall sobre él que refleja los paquetes al dispositivo eth2 para la entrada.

Para crear un espejo de salida desde el puerto eth1 al puerto eth2:

tc qdisc add dev eth1 handle ffff: clsact
tc filter add dev eth1 egress                  \
        matchall skip_sw                       \
        action mirred egress mirror            \
        dev eth2

El primer comando crea una qdisc clsact con el manejador ffff: en el dispositivo eth1 donde el segundo comando adjunta un filtro matchall sobre él que refleja los paquetes al dispositivo eth2 para la salida.

Para tomar una muestra de uno de cada 100 paquetes que fluyen hacia la interfaz eth0 al grupo de psample 12:

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12
