simple en tc(8) Linux simple en tc(8)

NOMBRE

simple - acción de ejemplo básica

SINTAXIS


tc ... action simple [ sdata CADENA ] [ index INDICE ] [ CONTROL ]

CONTROL := { reclassify | pipe | drop | continue | ok }

DESCRIPCIÓN

Este es un ejemplo pedagógico más que una acción realmente útil. En cada acceso, imprime la CADENA dada, que puede ser de longitud arbitraria.

OPCIONES

sdata CADENA
La cadena real a imprimir.
index INDICE
Valor opcional del índice de la acción.
CONTROL
Indica cómo debe proceder tc después de ejecutar la acción. Para una descripción de los posibles valores de CONTROL, véase tc-actions(8).

EJEMPLOS

El siguiente ejemplo hace que el kernel grite "¡ICMP entrante!" cada vez que ve un ICMP entrante en eth0. Los pasos son:

1)
Añadir un qdisc de entrada a eth0
2)
Iniciar una cadena en la entrada de eth0 que primero coincida con ICMP y luego invoque la acción simple para gritar.
3)
Mostrar estadísticas y ver que la acción no ha visto ningún paquete
4)
Enviar un paquete de ping a google (esperar recibir una respuesta)
5)
Buscar en los logs para ver el mensaje registrado
6)
Mostrar estadísticas de nuevo y observar el incremento en 1

  $ tc filter add dev eth0 parent ffff: protocol ip prio 5 \
