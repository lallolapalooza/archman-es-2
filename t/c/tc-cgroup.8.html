NOMBRE

cgroup - filtro de control de tráfico basado en grupos de control

SINOPSIS


tc filter ... cgroup [ match EMATCH_TREE ] [ action ACTION_SPEC ]

DESCRIPCIÓN

Este filtro sirve como una pista para tc de que el ID de clase asignado al grupo de control net_cls al que pertenece el proceso que origina el paquete se utilizará para la clasificación. Obviamente, solo es útil para paquetes generados localmente.

OPCIONES

action ACTION_SPEC
Aplica una acción del framework de acciones genéricas a los paquetes coincidentes.
match EMATCH_TREE
Coincide con paquetes utilizando la infraestructura de coincidencia extendida. Consulte tc-ematch(8) para obtener una descripción detallada de la sintaxis permitida en EMATCH_TREE.

EJEMPLOS

Para utilizar este filtro, primero se debe crear un grupo de control net_cls y asignarle una clase y uno o varios ID de proceso. Lo siguiente crea un grupo de control net_cls llamado "foobar":

modprobe cls_cgroup
mkdir /sys/fs/cgroup/net_cls
mount -t cgroup -onet_cls net_cls /sys/fs/cgroup/net_cls
mkdir /sys/fs/cgroup/net_cls/foobar

Para asignar un ID de clase al grupo de control creado, se debe crear un archivo llamado net_cls.classid que contenga el ID de clase a asignar como un número hexadecimal de 64 bits. Los 32 bits superiores están reservados para el identificador principal, y los restantes contienen el secundario. Por lo tanto, un ID de clase como, por ejemplo, ff:be debe escribirse así: 0xff00be (los ceros iniciales pueden omitirse). Para continuar con el ejemplo anterior, lo siguiente asigna el ID de clase 1:2 al grupo de control foobar:

echo 0x10002 > /sys/fs/cgroup/net_cls/foobar/net_cls.classid

Finalmente, se pueden asignar algunos PID al grupo de control dado:

echo 1234 > /sys/fs/cgroup/net_cls/foobar/tasks
echo 5678 > /sys/fs/cgroup/net_cls/foobar/tasks

Ahora, simplemente adjuntando un filtro cgroup a una qdisc, los paquetes de los PID 1234 y 5678 serán enviados a la clase 1:2.
