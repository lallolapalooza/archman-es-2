NOMBRE

tcpnice - ralentiza las conexiones TCP en una LAN

SINOPSIS

tcpnice [-A] [-I] [-M] [-i interfaz] expresión

DESCRIPCIÓN


tcpnice ralentiza las conexiones TCP especificadas en una LAN mediante la limitación de tráfico "activa".

OPCIONES

-A
Inyecta anuncios de ventana TCP diminutos.
-I
Inyecta respuestas ICMP source quench.
-M
Inyecta respuestas ICMP fragmentation-needed con MTUs de siguiente salto diminutos.
-i interfaz
Especifica la interfaz en la que escuchar.
expresión
Especifica una expresión de filtro de tcpdump(8) para seleccionar las conexiones a ralentizar.

Si no se especifica ningún tipo de ataque, se habilitarán todos los ataques.

VER TAMBIÉN

dsniff(8), tcpkill(8)
