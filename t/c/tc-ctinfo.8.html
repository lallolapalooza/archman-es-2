NOMBRE

ctinfo - acción de procesamiento de connmark de tc

SINOPSIS

tc ... action ctinfo [ dscp MASK [STATEMASK] ] [ cpmark [MASK] ] [ zone ZONE ] [ CONTROL ] [ index <INDEX> ]

DESCRIPCIÓN

CTINFO (Conntrack Information) es una acción de tc para recuperar datos de las marcas de conntrack en varios campos. Actualmente tiene dos modos de procesamiento independientes que pueden verse como subfunciones.

El modo DSCP copia un DSCP almacenado en el connmark de conntrack en el campo diffserv de IPv4/v6. La copia puede ocurrir condicionalmente basándose en una bandera también almacenada en el connmark. El modo DSCP fue diseñado para ayudar a restaurar las clasificaciones de paquetes en la entrada, clasificaciones que luego pueden ser utilizadas por qdiscs como CAKE. Puede ser utilizado en cualquier circunstancia donde la clasificación de entrada necesita ser mantenida a través de enlaces que de otra manera serían blanqueados o remapeados de acuerdo a sus propias políticas.

El modo CPMARK (copymark) copia el connmark de conntrack en el campo de marca del paquete. Sin parámetros adicionales, es funcionalmente equivalente a la acción connmark existente. Se puede especificar una máscara opcional para enmascarar qué bits del connmark se restauran. Esto puede ser útil cuando los modos DSCP y CPMARK se combinan.

Las estadísticas simples (tc -s) sobre restauraciones de DSCP y copias de CPMARK se mantienen donde los valores de establecido indican un recuento de paquetes alterados para ese modo. DSCP incluye un recuento de errores donde el campo diffserv del paquete de destino no era escribible.

PARÁMETROS

Parámetros del modo DSCP:

mask
Una máscara de 6 bits contiguos que indica dónde se encuentra el valor DSCP en el campo de marca de conntrack de 32 bits. Se debe proporcionar una máscara para este modo. La máscara es un valor entero sin signo de 32 bits.
statemask
Una máscara de al menos 1 bit que indica dónde se encuentra una bandera de restauración condicional en el campo de marca de conntrack de 32 bits. Los bits de la máscara de estado NO deben solaparse con los bits de la máscara. El DSCP se restaurará si el marca de conntrack se aplica lógicamente con la máscara de estado y el resultado es distinto de cero. La máscara de estado es un valor entero sin signo opcional de 32 bits.

Parámetros del modo CPMARK:

mask
Almacena el resultado de la operación lógica AND entre la marca de conntrack y la máscara en el campo de marca del paquete. El valor por defecto es 0xffffffff, es decir, todo el campo de marca. La máscara es un valor entero sin signo opcional de 32 bits.

Parámetros generales de la acción:

zone
Especifica la zona de conntrack al realizar búsquedas de conntrack para paquetes. La zona es un valor decimal sin signo de 16 bits. El valor por defecto es 0.
CONTROL
Las siguientes palabras clave permiten controlar cómo se recorre el árbol de qdiscs, clases, filtros y acciones después de esta acción.
reclassify
Reinicia con el primer filtro de la lista actual.
pipe
Continúa con la siguiente acción adjunta al mismo filtro.
drop
Descarta el paquete.
shot
sinónimo de drop
continue
Continúa la clasificación con el siguiente filtro en línea.
pass
Finaliza el proceso de clasificación y devuelve el control al qdisc llamador para un procesamiento adicional del paquete. Este es el comportamiento por defecto.
index
Especifica un índice para esta acción con el fin de poder identificarla en comandos posteriores. El índice es un valor decimal sin signo de 32 bits.

EJEMPLOS

Ejemplo que muestra la restauración condicional de DSCP en la entrada a través de un IFB

#Configurar la interfaz IFB
tc qdisc add dev ifb4eth0 handle ffff: ingress
#Poner qdisc CAKE en ella
tc qdisc add dev ifb4eth0 root cake bandwidth 40mbit
#Poner la interfaz en UP
ip link set dev ifb4eth0 up
#Añadir 2 acciones, ctinfo para restaurar dscp & mirred para redirigir los paquetes a IFB
tc filter add dev eth0 parent ffff: protocol all prio 10 u32 \
    match u32 0 0 flowid 1:1 action    \
    ctinfo dscp 0xfc000000 0x01000000  \
    mirred egress redirect dev ifb4eth0

iptables -t mangle -A POSTROUTING -o eth0 -m connmark \
