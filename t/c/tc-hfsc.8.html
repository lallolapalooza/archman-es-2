NOMBRE

HFSC - Control de Curvas de Servicio Jerárquicas Justas (Hierarchical Fair Service Curve) bajo Linux

SINTAXIS

tc qdisc add ... hfsc [ default CLASEID ]
tc class add ... hfsc [ [ rt SC ] [ ls SC ] | [ sc SC ] ] [ ul SC ]
rt : curva de servicio en tiempo real
ls : curva de servicio de recurso compartido (linkshare)
sc : curva de servicio rt+ls
ul : curva de límite superior
• se debe especificar al menos una de rt, ls o sc
• ul solo se puede especificar con ls o sc
SC := [ [ m1 BPS ] d SEG ] m2 BPS
m1 : pendiente del primer segmento
d  : coordenada x de la intersección
m2 : pendiente del segundo segmento
SC := [ [ umax BYTE ] dmax SEG ] rate BPS
umax : unidad máxima de trabajo
dmax : retraso máximo
rate : tasa

Para la descripción de BYTE, BPS y SEG - por favor, consulte la sección UNIDADES de tc(8).

DESCRIPCIÓN (qdisc)

El qdisc HFSC tiene solo un parámetro opcional: default. CLASEID especifica la parte menor del identificador de clase, donde se encolarán los paquetes no clasificados por otros medios (por ejemplo, filtro u32, objetivo CLASSIFY de iptables). Si no se especifica default, los paquetes no clasificados se descartarán.

DESCRIPCIÓN (clase)

La clase HFSC se utiliza para crear una jerarquía de clases para el planificador HFSC. Para obtener una explicación del algoritmo y el significado de las curvas de servicio rt, ls, sc y ul, consulte tc-hfsc(7).

Como puede ver en SINTAXIS, la curva de servicio (SC) se puede especificar de dos maneras. Ya sea como retraso máximo para una cierta cantidad de trabajo, o como ancho de banda asignado durante un cierto período de tiempo. Obviamente, m1 es simplemente umax/dmax.

Tanto m2 como rate son obligatorios. Si omite otros parámetros, especificará una curva de servicio lineal.
