NOMBRE

tca_correct - Calcula la aberración cromática transversal

SINOPSIS

tca_correct [opciones] archivo_entrada

archivo_entrada es el nombre base de 4 archivos de imagen:

<inputfile>
Archivo de color para computar parámetros de TCA
red_<archivo_entrada>
Canal rojo de <archivo_entrada>
green_<archivo_entrada>
Canal verde de <archivo_entrada>
blue_<archivo_entrada>
Canal azul de <archivo_entrada>

Las imágenes de canal deben ser imágenes en color con 3 canales idénticos. Si se proporciona alguno de -R, -G o -B, se utilizará este nombre de archivo en lugar del nombre derivado.

Salida: argumentos de línea de comandos para fulla

DESCRIPCIÓN

Genera parámetros de línea de comandos para fulla para la corrección de la aberración cromática transversal (TCA) a partir de fotos de muestra. Las fotos de muestra ideales tendrían mucho contraste en toda el área de la imagen, poco color saturado y sin resaltados quemados.

OPCIONES

-h
Muestra la ayuda
-l
El archivo de entrada es un archivo PTO en lugar de una imagen
-m método
Método de optimización (0 normal, 1 newfit)
-o vars_opt
Cadena de variables a optimizar ("abcvde")
-r
Restablecer valores (esto pondrá a cero los parámetros a,b,c,d,e y establecerá v a 10) solo tiene sentido con la opción -l
-s <escala>
Escala para la detección de esquinas
-n <número>
número de puntos por celda de la cuadrícula (por defecto: 10)
-g <número>
divide la imagen en <número>x<número> celdas de cuadrícula (por defecto: 10)
-t num
Elimina todos los puntos de control con un error superior a num píxeles (por defecto: 1.5)
-v
Detallado
--save-into-database
Guarda los datos de TCA en la base de datos de lentes de Hugin
-w nombre_archivo
escribe el archivo PTO
-R <r>
Usa este archivo como canal rojo
-G <g>
Usa este archivo como canal verde
-B <b>
Usa este archivo como canal azul
