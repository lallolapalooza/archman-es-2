NOMBRE

gact - acción genérica

SINOPSIS


tc ... action gact CONTROL [ RAND ] [ INDEX ] CONTROL := { reclassify | drop | continue | pass | pipe |
goto chain CHAIN_INDEX |
jump JUMP_COUNT }

RAND := random RANDTYPE CONTROL VAL RANDTYPE := { netrand | determ } VAL := número no superior a 10000 JUMP_COUNT := salto absoluto desde el inicio de la lista de acciones INDEX := valor de índice utilizado

DESCRIPCIÓN

La acción gact permite reclasificar, descartar, pasar o aceptar paquetes. En este momento, solo hay dos algoritmos. Uno es determinista y el otro utiliza netrand interno del kernel.

OPCIONES

random RANDTYPE CONTROL VAL
La probabilidad de tomar la acción expresada en términos de 1 de cada VAL paquetes.
CONTROL
Indica cómo debe proceder tc si el paquete coincide. Para una descripción de los posibles valores de CONTROL, consulte tc-actions(8).

EJEMPLOS

Aplicar una regla en la entrada para descartar paquetes de una dirección de origen dada.

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop

Permitir 1 de cada 10 paquetes del origen aleatoriamente usando el generador netrand

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop random netrand ok 10

Aceptar de forma determinista cada segundo paquete

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop random determ ok 2
