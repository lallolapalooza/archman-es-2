NOMBRE

sample - acción de muestreo de paquetes de tc

SINOPSIS


tc ... action sample rate TASA group GRUPO [ trunc TAMAÑO ] [ index INDICE ]

tc ... action sample index INDICE

DESCRIPCIÓN

La acción sample permite muestrear paquetes que coinciden con el clasificador.

Los paquetes se eligen aleatoriamente de acuerdo con el parámetro rate (tasa), y se muestrean utilizando el canal genérico netlink psample. El usuario también puede especificar la truncación de paquetes para ahorrar tráfico de usuario-kernel. Cada muestra incluye metadatos informativos sobre el paquete original, que se envían a través de atributos netlink, junto con los datos del paquete original.

El usuario puede especificar los parámetros de la acción de muestra como se presenta en la primera forma anterior, o utilizar una acción de muestra existente utilizando su índice, como se presenta en la segunda forma.

CAMPOS DE METADATOS DE PAQUETES MUESTRADOS

Los metadatos se entregan a las aplicaciones del espacio de usuario utilizando el canal genérico netlink psample, donde cada muestra incluye los siguientes atributos netlink:

PSAMPLE_ATTR_IIFINDEX
El índice de la interfaz de entrada del paquete, si existe.
PSAMPLE_ATTR_OIFINDEX
El índice de la interfaz de salida del paquete. Este campo no es relevante en el muestreo de entrada.
PSAMPLE_ATTR_ORIGSIZE
El tamaño del paquete original (antes de la truncación).
PSAMPLE_ATTR_SAMPLE_GROUP
El grupo psample al que se envió el paquete.
PSAMPLE_ATTR_GROUP_SEQ
Un número de secuencia del paquete muestreado. Este número se incrementa con cada paquete muestreado del grupo psample actual.
PSAMPLE_ATTR_SAMPLE_RATE
La tasa con la que se muestreó el paquete.

OPCIONES

rate TASA
La tasa de muestreo de paquetes. TASA es la relación esperada entre paquetes observados y paquetes muestreados. Por ejemplo, una TASA de 100 resultará en un promedio de un paquete muestreado de cada 100 observados.
trunc TAMAÑO
Al establecerse, define el tamaño máximo de los paquetes muestreados y provoca la truncación si es necesario.
group GRUPO
El grupo psample al que se enviará el paquete. El módulo psample define el concepto de grupos, que permite al usuario hacer coincidir paquetes muestreados específicos en caso de múltiples reglas de muestreo, identificando así solo los paquetes que provienen de una regla específica.
index INDICE
Es un ID único para una acción. Al crear una nueva instancia de acción, este parámetro permite establecer el nuevo índice de acción. Al usar una acción existente, este parámetro permite especificar el índice de la acción existente. El índice debe ser un entero sin signo de 32 bits mayor que cero.

EJEMPLOS

Muestrear uno de cada 100 paquetes que entran por la interfaz eth0 al grupo psample 12:

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12 index 19

Usar la misma instancia de acción para muestrear eth1 también:

tc qdisc add dev eth1 handle ffff: ingress
tc filter add dev eth1 parent ffff: matchall \
     action sample index 19
