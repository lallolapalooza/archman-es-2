tcgetsid(3) Manual de funciones de biblioteca tcgetsid(3)

NOMBRE

tcgetsid - obtener ID de sesión

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _XOPEN_SOURCE 500        /* Véase feature_test_macros(7) */
#include <termios.h>
pid_t tcgetsid(int fd);

DESCRIPCIÓN

La función tcgetsid() devuelve el ID de sesión de la sesión actual que tiene el terminal asociado a fd como terminal de control. Este terminal debe ser el terminal de control del proceso que llama.

VALOR DE RETORNO

Cuando fd se refiere al terminal de control de nuestra sesión, la función tcgetsid() devolverá el ID de sesión de esta sesión. En caso contrario, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
ENOTTY
El proceso que llama no tiene un terminal de control, o tiene uno pero no está descrito por fd.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, véase attributes(7).

Interfaz Atributo Valor
tcgetsid () Seguridad de hilos MT-Safe

ESTANDARES

POSIX.1-2008.

HISTORIAL

glibc 2.1. POSIX.1-2001.

Esta función se implementa a través de la llamada ioctl(2) TIOCGSID, presente desde Linux 2.1.71.
