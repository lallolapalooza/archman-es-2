NOMBRE

basic - filtro básico de control de tráfico

SINTAXIS


tc filter ... basic [ match EMATCH_TREE ] [ action ACTION_SPEC ] [ classid CLASSID ]

DESCRIPCIÓN

El filtro basic permite clasificar paquetes utilizando la infraestructura de coincidencias extendidas.

OPCIONES

action ACTION_SPEC
Aplica una acción del framework de acciones genéricas a los paquetes coincidentes.
classid CLASSID
Introduce los paquetes coincidentes en la clase identificada por CLASSID.
match EMATCH_TREE
Coincide con paquetes utilizando la infraestructura de coincidencias extendidas. Consulte tc-ematch(8) para una descripción detallada de la sintaxis permitida en EMATCH_TREE.

VER TAMBIÉN

tc(8), tc-ematch(8)
