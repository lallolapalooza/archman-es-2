TCFLOW(3P) Manual POSIX del programador TCFLOW(3P)

PROLOG

Esta página del manual forma parte del Manual POSIX del Programador. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tcflow — suspender o reanudar la transmisión o recepción de datos

SINOPSIS

#include <termios.h>
int tcflow(int fildes, int action);

DESCRIPCIÓN

La función tcflow() suspenderá o reanudará la transmisión o recepción de datos en el objeto al que se refiere fildes, dependiendo del valor de action. El argumento fildes es un descriptor de archivo abierto asociado a una terminal.

*
Si action es TCOOFF, la salida se suspenderá.
*
Si action es TCOON, la salida suspendida se reanudará.
*
Si action es TCIOFF y fildes se refiere a un dispositivo de terminal, el sistema transmitirá un carácter STOP, que está destinado a hacer que el dispositivo de terminal deje de transmitir datos al sistema. Si fildes está asociado a una pseudoterminal, el carácter STOP no necesita ser transmitido.
*
Si action es TCION y fildes se refiere a un dispositivo de terminal, el sistema transmitirá un carácter START, que está destinado a hacer que el dispositivo de terminal comience a transmitir datos al sistema. Si fildes está asociado a una pseudoterminal, el carácter START no necesita ser transmitido.

Por defecto, al abrir un archivo de terminal, ni su entrada ni su salida están suspendidas.

Los intentos de usar tcflow() desde un proceso que es miembro de un grupo de procesos en segundo plano en un fildes asociado a su terminal de control, causarán que al grupo de procesos se le envíe una señal SIGTTOU. Si el hilo que llama está bloqueando las señales SIGTTOU o el proceso está ignorando las señales SIGTTOU, se permitirá que el proceso realice la operación y no se enviará ninguna señal.

VALOR DEVUELTO

Tras una finalización exitosa, se devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función tcflow() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
EINVAL
El argumento action no es un valor compatible.
EIO
El grupo de procesos del proceso de escritura está huerfano, el hilo que llama no está bloqueando SIGTTOU y el proceso no está ignorando SIGTTOU.
ENOTTY
El archivo asociado a fildes no es una terminal.
