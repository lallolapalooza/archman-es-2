tc-ematch(8)

Paquete: iproute2

Licencias: GPL-2.0-or-later

ematch(8) Linux ematch(8)

NOMBRE

ematch - coincidencias extendidas para usar con filtros "basic", "cgroup" o "flow"

SINOPSIS

tc filter add .. basic match EXPR .. flowid ..

EXPR := TERM [ { and | or } EXPR ]

TERM := [ not ] { MATCH | '(' EXPR ')' }

MATCH := módulo '(' ARGUMENTOS ')'

ARGUMENTOS := ARG1 ARG2 ..

COINCIDENCIAS

cmp

ematch de comparación simple: comparación aritmética de datos del paquete con un valor dado.

cmp( ALIGN en OFFSET [ ATTRS ] { eq | lt | gt } VALOR )

ALIGN := { u8 | u16 | u32 }

ATTRS := [ capa CAPA ] [ máscara MASCARA ] [ trans ]

CAPA := { link | network | transport | 0..2 }

meta

ematch de metadatos

meta( OBJETO { eq | lt |gt } OBJETO )

OBJETO := { META_ID | VALOR }

META_ID := id [ shift SHIFT ] [ mask MASCARA ]

atributos meta:

random valor aleatorio de 32 bits

loadavg_1 Carga promedio en los últimos 5 minutos

nf_mark Marca de Netfilter

vlan Etiqueta Vlan

sk_rcvbuf Tamaño del buffer de recepción

sk_snd_queue Longitud de la cola de envío

Una lista completa de atributos meta se puede obtener a través de

# tc filter add dev eth1 basic match 'meta(list)'

nbyte

secuencia de bytes de datos del paquete de coincidencia

nbyte( AGUJA en OFFSET [ capa CAPA ] )

AGUJA := { string | secuencia-de-escape-c }

OFFSET := int

CAPA := { link | network | transport | 0..2 }

u32

ematch u32

u32( ALIGN VALOR MASCARA en [ nexthdr+ ] OFFSET )

ALIGN := { u8 | u16 | u32 }

ipset

prueba el paquete contra la pertenencia a ipset

ipset( NOMBRE_SET FLAGS )

NOMBRE_SET := string

FLAGS := { FLAG [, FLAGS] }

Las opciones de flags son las mismas que se utilizan en la coincidencia "set" de iptables.

Al utilizar el ematch ipset con el tipo de set "ip_set_hash:net,iface", la interfaz puede consultarse utilizando la sintaxis "src,dst (dirección IP de origen, interfaz de salida) o "src,src" (dirección IP de origen, interfaz de entrada).

ipt

prueba el paquete contra coincidencias xtables

ipt( [-6] -m NOMBRE_COINCIDENCIA FLAGS )

NOMBRE_COINCIDENCIA := string

FLAGS := { FLAG [, FLAGS] }

Las opciones de flags son las mismas que se utilizan en la coincidencia xtable utilizada.

canid

regla ematch para coincidir con tramas CAN

canid( LISTA_IDS )

LISTA_IDS := ESPEC_ID[LISTA_IDS]

ESPEC_ID := { ’sff’ CANID | ’eff’ CANID }

CANID := ID[:MASCARA]

ID, MASCARA := número hexadecimal (por ejemplo, 0x123)

ADVERTENCIAS

La sintaxis ematch utiliza '(' y ')' para agrupar expresiones. Todas las llaves deben escaparse correctamente para evitar que la línea de comandos del shell las interprete directamente.

Al usar el ematch ipset con el dispositivo "ifb", el dispositivo de salida será el propio dispositivo ifb, por ejemplo, "ifb0". La interfaz original (es decir, el dispositivo en el que llegó el paquete) se trata como la interfaz de entrada.

EJEMPLO & USO

# tc filter add .. basic match ...

# 'cmp(u16 at 3 layer 2 mask 0xff00 gt 20)'

# 'meta(nfmark gt 24)' and 'meta(tcindex mask 0xf0 eq 0xf0)'

# 'nbyte("ababa" at 12 layer 1)'

# 'u32(u16 0x1122 0xffff at nexthdr+4)'

Comprobar si la dirección IP de origen del paquete es miembro del conjunto llamado bulk:

# 'ipset(bulk src)'

Comprobar si la IP de origen del paquete y la interfaz por la que llegó el paquete son miembros del conjunto "hash:net,iface" llamado interactive:

# 'ipset(interactive src,src)'

Comprobar si el paquete coincide con un estado IPSec con reqid 1:

# 'ipt(-m policy --dir in --pol ipsec --reqid 1)'
