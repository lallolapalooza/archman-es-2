NOMBRE

skbmod - acción de editor de paquetes amigable para el usuario

SINOPSIS


tc ... action skbmod { set SETTABLE | swap SWAPPABLE | ecn } [ CONTROL ] [ index INDEX ]

SETTABLE := [ dmac DMAC ] [ smac SMAC ] [ etype ETYPE ]

SWAPPABLE := mac

CONTROL := { reclassify | pipe | drop | shot | continue | pass }

DESCRIPCIÓN

La acción skbmod pretende ser una mejora de usabilidad de la acción existente pedit. En lugar de tener que editar manualmente trozos de 8, 16 o 32 bits de una cabecera ethernet, skbmod permite la sustitución completa de elementos soportados. La acción debe ser una de set, swap y ecn. set y swap solo afectan a paquetes Ethernet, mientras que ecn solo afecta a paquetes IP.

OPCIONES

dmac DMAC
Cambia la dirección MAC de destino a la dirección especificada.
smac SMAC
Cambia la dirección MAC de origen a la dirección especificada.
etype ETYPE
Cambia el etertype al valor especificado.
mac
Se usa para intercambiar direcciones MAC.
ecn
Se usa para marcar los paquetes IP con Capacidad de Transporte ECN (ECT) como Encuentro de Congestión (CE). No afecta a los paquetes sin Capacidad de Transporte ECN (Non-ECT).
CONTROL
Las siguientes palabras clave permiten controlar cómo se recorre el árbol de qdiscs, clases, filtros y acciones después de esta acción.
reclassify
Reinicia con el primer filtro de la lista actual.
pipe
Continúa con la siguiente acción adjunta al mismo filtro.
drop
shot
Descarta el paquete.
continue
Continúa la clasificación con el siguiente filtro en línea.
pass
Finaliza el proceso de clasificación y regresa a la qdisc que llama para un procesamiento adicional del paquete. Este es el comportamiento por defecto.

EJEMPLOS

Para empezar, observe el siguiente filtro con una acción pedit:

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action pedit munge offset -14 u8 set 0x02 \
	munge offset -13 u8 set 0x15 \
	munge offset -12 u8 set 0x15 \
	munge offset -11 u8 set 0x15 \
	munge offset -10 u16 set 0x1515 \
	pipe

Usando la acción skbmod, este comando se puede simplificar a:

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod set dmac 02:15:15:15:15:15 \
	pipe

La complejidad aumentará si la dirección MAC de origen y el ethertype también se están editando como parte de la acción. Si los tres campos van a ser modificados con skbmod:

tc filter add dev eth5 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	set etype 0xBEEF \
	set dmac 02:12:13:14:15:16 \
	set smac 02:22:23:24:25:26

Para intercambiar las direcciones MAC de destino y origen en la cabecera Ethernet:

tc filter add dev eth3 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	swap mac

Finalmente, para marcar el punto de código CE en la cabecera IP para paquetes con Capacidad de Transporte ECN (ECT):

tc filter add dev eth0 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	ecn

Solo se debe usar una de las opciones set, swap y ecn en un solo comando. Intentar usar más de una en un solo comando se considera un comportamiento indefinido; encadene múltiples comandos en su lugar.
