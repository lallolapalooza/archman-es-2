NOMBRE

acciones - acciones definidas independientemente en tc

SINOPSIS

tc [ OPCIONES_TC ] acciones add | change | replace ESPEC_ACCION

tc [ OPCIONES_TC ] acciones get | delete ESPEC_ID_ACCION

tc [ OPCIONES_TC ] acciones flush ESPEC_NOMBRE_ACCION

tc [ OPCIONES_TC ] acciones ls | list ESPEC_NOMBRE_ACCION [ FILTRO_ACCION ]


ESPEC_ACCION := action DETALLE_ACCION [ ESPEC_INDICE ] [ ESPEC_COOKIE ] [ FLAGS ] [ ESPEC_ESTADISTICAS_HW ] [ CONTROL ] [ ESPEC_SALTO ]

ESPEC_ID_ACCION := ESPEC_NOMBRE_ACCION ESPEC_INDICE

ESPEC_NOMBRE_ACCION := action NOMBRE_ACCION

ESPEC_INDICE := index INDICE

FILTRO_ACCION := since TIEMPO_MS

ESPEC_COOKIE := cookie COOKIE

FLAGS := no_percpu

ESPEC_ESTADISTICAS_HW := hw_stats { immediate | delayed | disabled }

DETALLE_ACCION := NOMBRE_ACCION PARAMETROS_ACCION

NOMBRE_ACCION puede ser cualquier tipo de acción válido: gact, mirred, bpf, connmark, csum, police, etc.

TIEMPO_MS Tiempo desde la última actualización.

CONTROL := { reclassify | pipe | drop | continue | ok }

ESPEC_SALTO := { skip_sw | skip_hw }

OPCIONES_TC Estas son las opciones específicas de tc y no solo las opciones. Consulte tc(8) para más información.

DESCRIPCION

El objeto actions en tc permite a un usuario definir acciones independientemente de un clasificador (filtro). Estas acciones pueden luego asignarse a uno o más filtros, y los paquetes que coincidan con los criterios del clasificador realizarán la acción correspondiente.

Cada tipo de acción (mirred, police, etc.) tendrá su propia tabla para almacenar todas las acciones creadas.

OPERACIONES

add
Crear una nueva acción en la tabla de esa acción.
change
replace
Realizar modificaciones en una acción existente.
get
Mostrar la acción con el valor de índice especificado. Cuando se combina con la opción -s de tc, mostrar las estadísticas de esa acción.
delete
Eliminar la acción con el valor de índice especificado. Si la acción ya está asociada a un clasificador, no elimina el clasificador.
ls
list
Listar todas las acciones en la tabla especificada. Cuando se combina con la opción -s de tc, mostrar las estadísticas de todas las acciones en la tabla especificada. Cuando se combina con la opción since, permite aplicar un filtro de tiempo en milisegundos desde la última vez que una acción fue utilizada en el plano de datos.
flush
Eliminar todas las acciones almacenadas en la tabla especificada.

OPCIONES DE ACCIÓN

Tenga en cuenta que estas opciones están disponibles para todos los tipos de acción.

index INDICE
Especificar el valor del índice de tabla de una acción. INDICE es un valor de 32 bits que es único para el tipo específico de acción referenciada.
Para las operaciones add, change y replace, el índice es opcional. Al añadir una nueva acción, especificar un valor de índice asignará la acción a ese índice a menos que ese valor de índice ya haya sido asignado. Omitir el valor de índice para una operación de add hará que el kernel asigne un valor a la nueva acción.
Para las operaciones get y delete, el índice es requerido para identificar la acción específica que se mostrará o eliminará.
cookie COOKIE
Además de la acción específica, marcar el paquete coincidente con el valor especificado por COOKIE. La COOKIE es un valor de 128 bits que el kernel no interpretará en absoluto. Como tal, puede usarse como un valor de correlación para mantener el estado del usuario. El valor a almacenar es completamente arbitrario y no requiere un formato específico. Se almacena dentro de la propia estructura de acción.
FLAGS
Indicadores específicos de la acción. Actualmente, el único indicador soportado es no_percpu, que indica que se espera que la acción tenga un tráfico mínimo en el plano de datos de software y no necesite asignar contadores de estadísticas con el asignador percpu. Esta opción está destinada a ser utilizada por acciones descargadas por hardware.
hw_stats ESTADISTICAS_HW
Especifica el tipo de estadísticas HW de la nueva acción. Si se omite, se utilizará cualquier tipo de contador de estadísticas, según el controlador y sus recursos. La ESTADISTICAS_HW indica el tipo. Cualquiera de los siguientes es válido:
immediate
Significa que en el volcado, el usuario obtiene el estado actual de las estadísticas HW del dispositivo consultado en el momento del volcado.
delayed
Significa que en el volcado, el usuario obtiene estadísticas HW que pueden estar desactualizadas durante algún tiempo, quizás un par de segundos. Este es el caso cuando el controlador consulta las actualizaciones de estadísticas periódicamente o cuando recibe una actualización de estadísticas asíncrona del dispositivo.
disabled
No habrá estadísticas HW disponibles en el volcado.
since TIEMPO_MS
Al volcar un gran número de acciones, se puede especificar un filtro de tiempo en milisegundos TIEMPO_MS. El TIEMPO_MS es un recuento en milisegundos desde la última vez que un paquete alcanzó la acción. Como ejemplo, especificar "since 20000" implica volcar todas las acciones que han visto paquetes en los últimos 20 segundos. Esta opción es útil cuando el kernel tiene un gran número de acciones y solo está interesado en las acciones utilizadas recientemente.
CONTROL
El CONTROL indica cómo debe proceder tc después de ejecutar la acción. Cualquiera de los siguientes es válido:
reclassify
Reinicia la clasificación saltando de nuevo al primer filtro adjunto al padre de la acción.
pipe
Continúa con la siguiente acción. Este es el control por defecto.
drop
Descarta el paquete sin ejecutar más acciones.
continue
Continúa la clasificación con el siguiente filtro.
pass
Devuelve el paquete a la qdisc que lo llamó para su procesamiento y finaliza la clasificación de este paquete.
ESPEC_SALTO
El ESPEC_SALTO indica cómo debe proceder tc al ejecutar la acción. Cualquiera de los siguientes es válido:
skip_sw
No procesar la acción por software. Si el hardware no tiene soporte de descarga para esta acción, la operación fallará.
skip_hw
No procesar la acción por hardware.
