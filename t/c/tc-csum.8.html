NOMBRE

csum - acción de actualización de suma de verificación

SINOPSIS


tc ... action csum ACTUALIZACIÓN

ACTUALIZACIÓN := OBJETIVO [ ACTUALIZACIÓN ]

OBJETIVO := { ip4h | icmp | igmp | tcp | udp | udplite | sctp | DULCES }

DULCES := { and | or | + }

DESCRIPCIÓN

La acción csum activa el recálculo de la suma de verificación de las cabeceras de paquetes especificadas. Se utiliza comúnmente para corregir sumas de verificación incorrectas después de que la acción pedit haya modificado el contenido del paquete.

OPCIONES

OBJETIVO
Especifica qué cabeceras actualizar: cabecera IPv4 (ip4h), cabecera ICMP (icmp), cabecera IGMP (igmp), cabecera TCP (tcp), cabecera UDP (udp), cabecera UDPLite (udplite) o cabecera SCTP (sctp).
DULCES
Estos son meramente azúcar sintáctico y se ignoran internamente.

EJEMPLOS

Lo siguiente realiza NAT sin estado para paquetes entrantes de 192.0.2.100 a un nuevo destino 198.51.100.1. Suponiendo que son paquetes UDP, tanto las sumas de verificación IP como UDP tienen que ser recalculadas:

# tc qdisc add dev eth0 ingress handle ffff:
# tc filter add dev eth0 prio 1 protocol ip parent ffff: \
	u32 match ip src 192.0.2.100/32 flowid :1 \
	action pedit munge ip dst set 198.51.100.1 pipe \
	csum ip and udp
