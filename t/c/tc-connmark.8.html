NOMBRE

connmark - acción de recuperación de connmark de netfilter

SINOPSIS


tc ... action connmark [ zone u16_zone_index ] [ CONTROL ] [ index u32_index ]

CONTROL := { reclassify | pipe | drop | continue | ok }

DESCRIPCIÓN

La acción connmark se utiliza para restaurar el valor de la marca de la conexión en la marca del paquete (fwmark).

OPCIONES

zone u16_zone_index
Especifica la zona de conntrack al realizar búsquedas de conntrack para paquetes. u16_zone_index es un valor decimal sin signo de 16 bits.
CONTROL
Cómo continuar después de ejecutar esta acción.
reclassify
Reinicia la clasificación saltando al primer filtro adjunto al padre de esta acción.
pipe
Continúa con la siguiente acción, esta es la opción predeterminada.
drop
shot
El paquete será descartado sin ejecutar más acciones.
continue
Continúa la clasificación con el siguiente filtro en línea.
pass
Devuelve el control a la qdisc que llama para el procesamiento del paquete. Esto finaliza el proceso de clasificación.
index u32_index
Especifica un índice para esta acción con el fin de poder identificarla en comandos posteriores. u32_index es un valor decimal sin signo de 32 bits.
