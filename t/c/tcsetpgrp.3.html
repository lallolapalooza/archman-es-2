tcgetpgrp(3) Manual de funciones de biblioteca tcgetpgrp(3)

NOMBRE

tcgetpgrp, tcsetpgrp - obtener y establecer el grupo de procesos en primer plano de la terminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
pid_t tcgetpgrp(int fd);
int tcsetpgrp(int fd, pid_t pgrp);

DESCRIPCIÓN

La función tcgetpgrp() devuelve el ID del grupo de procesos del grupo de procesos en primer plano en la terminal asociada a fd, la cual debe ser la terminal de control del proceso que llama.

La función tcsetpgrp() convierte el grupo de procesos con el ID de grupo de procesos pgrp en el grupo de procesos en primer plano en la terminal asociada a fd, la cual debe ser la terminal de control del proceso que llama, y que todavía esté asociada a su sesión. Además, pgrp debe ser un grupo de procesos (no vacío) que pertenezca a la misma sesión que el proceso que llama.

Si un miembro de un grupo de procesos en segundo plano de su sesión llama a tcsetpgrp(), y el proceso que llama no está bloqueando o ignorando la señal SIGTTOU, se enviará una señal SIGTTOU a todos los miembros de este grupo de procesos en segundo plano.

VALOR DE RETORNO

Cuando fd se refiere a la terminal de control del proceso que llama, la función tcgetpgrp() devolverá el ID del grupo de procesos en primer plano de esa terminal si existe, y algún valor mayor que 1 que no sea actualmente un ID de grupo de procesos en caso contrario. Cuando fd no se refiere a la terminal de control del proceso que llama, se devuelve -1 y se establece errno para indicar el error.

Si tiene éxito, tcsetpgrp() devuelve 0. De lo contrario, devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
fd no es un descriptor de archivo válido.
EINVAL
pgrp tiene un valor no compatible.
ENOTTY
El proceso que llama no tiene una terminal de control, o tiene una pero no está descrita por fd, o, para tcsetpgrp(), esta terminal de control ya no está asociada a la sesión del proceso que llama.
EPERM
pgrp tiene un valor compatible, pero no es el ID del grupo de procesos de un proceso en la misma sesión que el proceso que llama.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
tcgetpgrp (), tcsetpgrp () Seguridad de hilos MT-Safe

VERSIONES

Estas funciones se implementan a través de las llamadas ioctl TIOCGPGRP y TIOCSPGRP.

ESTANDARES

POSIX.1-2008.

HISTORIA

POSIX.1-2001.

Las llamadas ioctl aparecieron en 4.2BSD. Las funciones son invenciones de POSIX.

VER TAMBIÉN

setpgid(2), setsid(2), credentials(7)
