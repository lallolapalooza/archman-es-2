NOMBRE

tcpretrans.bt - Rastrea o cuenta las retransmisiones TCP. Usa bpftrace/eBPF de Linux

SINOPSIS

tcpretrans.bt

DESCRIPCIÓN

Esto rastrea las retransmisiones TCP, mostrando la dirección, puerto e información del estado TCP, y a veces el PID (aunque generalmente no, ya que las retransmisiones suelen ser enviadas por el kernel por timeouts). Para mantener la sobrecarga muy baja, solo se rastrean las funciones de retransmisión TCP. Esto no rastrea cada paquete (como tcpdump(8) o un sniffer de paquetes). Opcionalmente, puede contar las retransmisiones durante un intervalo señalado por el usuario para detectar posibles rutas de red que se están perdiendo en los flujos que atraviesan.

Esto utiliza el rastreo dinámico de las funciones del kernel tcp_retransmit_skb() y tcp_send_loss_probe(), y deberá ser actualizado para coincidir con los cambios del kernel en estas funciones.

Dado que esto utiliza BPF, solo el usuario root puede utilizar esta herramienta.

REQUISITOS

CONFIG_BPF y bcc. CONFIG_BPF y bpftrace.

EJEMPLOS

Rastrear retransmisiones TCP:
# tcpretrans.bt

CAMPOS

HORA
Hora de la llamada, en formato HH:MM:SS.
PID
ID del proceso que estaba en la CPU. Esto es menos útil de lo que parece, ya que a menudo puede ser 0, para el kernel, para las retransmisiones basadas en temporizador.
LADDR
Dirección IP local.
LPORT
Puerto local.
RADDR
Dirección IP remota.
RPORT
Puerto remoto.
ESTADO
Estado de la sesión TCP.

SOBRECARGA

Debería ser insignificante: los eventos de retransmisión TCP deberían ser bajos (<1000/s), y la baja sobrecarga que esta herramienta añade a cada evento debería hacer que el costo sea insignificante.
