tc-bfifo(8)

Paquete: iproute2

Licencias: GPL-2.0-or-later

PBFIFO(8) Linux PBFIFO(8)

NOMBRE

pfifo - Cola de tipo First In, First Out con límite de paquetes

bfifo - Cola de tipo First In, First Out con límite de bytes

SINOPSIS

tc qdisc ... add pfifo [ limit paquetes ]

tc qdisc ... add bfifo [ limit bytes ]

DESCRIPCIÓN

Las colas pfifo y bfifo son colas First In, First Out (FIFO) sin adornos. Son las colas más simples posibles y, por lo tanto, no tienen sobrecarga. pfifo restringe el tamaño de la cola medido en paquetes. bfifo lo hace medido en bytes.

Al igual que todas las colas no predeterminadas, mantienen estadísticas. Esta podría ser una razón para preferir pfifo o bfifo sobre la predeterminada.

ALGORITMO

Se mantiene una lista de paquetes; cuando se encola un paquete, se inserta al final de una lista. Cuando un paquete necesita ser enviado a la red, se toma del principio de la lista.

Si la lista es demasiado larga, no se permiten más paquetes. Esto se denomina "tail drop" (descarte al final).

PARÁMETROS

limit
Tamaño máximo de la cola. Especificado en bytes para bfifo, en paquetes para pfifo. Para pfifo, el valor predeterminado es el txqueuelen de la interfaz, según lo especificado con ip(8). El rango para este parámetro es [0, UINT32_MAX].

Para bfifo, el valor predeterminado es el txqueuelen multiplicado por la MTU de la interfaz. El rango para este parámetro es [0, UINT32_MAX] bytes.

Nota: La cabecera de la capa de enlace se consideró al contar la longitud de los paquetes.

SALIDA

La salida de tc -s qdisc ls contiene el límite, ya sea en paquetes o en bytes, y el número de bytes y paquetes enviados. Un paquete no enviado y descartado solo aparece entre corchetes y no se cuenta como "Sent" (Enviado).

En este ejemplo, la longitud de la cola es de 100 paquetes, se enviaron 45894 bytes en 681 paquetes. No se descartaron paquetes, y como la cola pfifo no ralentiza los paquetes, tampoco hubo sobrecargas:

# tc -s qdisc ls dev eth0
qdisc pfifo 8001: dev eth0 limit 100p
 Sent 45894 bytes 681 pkts (dropped 0, overlimits 0)

Si se produce un backlog, también se muestra.
