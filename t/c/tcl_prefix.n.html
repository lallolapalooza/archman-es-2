tcl_prefix(n)

Paquete: tcl

Licencias: TCL

prefix(n) Comandos integrados de Tcl prefix(n)

NOMBRE

tcl::prefix - utilidades para la coincidencia de prefijos

SINOPSIS

::tcl::prefix all tabla cadena
::tcl::prefix longest tabla cadena
::tcl::prefix match ?opción ...? tabla cadena

DESCRIPCIÓN

Este documento describe los comandos para buscar un prefijo en una lista de cadenas. Se soportan los siguientes comandos:

::tcl::prefix all tabla cadena
Devuelve una lista de todos los elementos en tabla que comienzan con el prefijo cadena.
::tcl::prefix longest tabla cadena
Devuelve el prefijo común más largo de todos los elementos en tabla que comienzan con el prefijo cadena.
::tcl::prefix match ?opción ...? tabla cadena
Si cadena coincide con un elemento en tabla o es un prefijo de exactamente un elemento, se devuelve el elemento coincidente. De lo contrario, el resultado depende de la opción -error. (Se recomienda que la tabla se ordene antes de usarla con este subcomando, para que la lista de coincidencias presentadas en el mensaje de error también esté ordenada, aunque esto no es estrictamente necesario para el funcionamiento de este subcomando en sí mismo). Se soportan las siguientes opciones:
-exact 
Aceptar solo coincidencias exactas.
-message cadena
Usar cadena en el mensaje de error en caso de discrepancia. El valor predeterminado es “opción”.
-error opciones
Las opciones se utilizan cuando no se encuentra ninguna coincidencia. Si opciones está vacío, no se genera ningún error y se devuelve una cadena vacía. De lo contrario, las opciones se utilizan como opciones de return al generar el mensaje de error. El valor predeterminado corresponde a establecer “-level 0”. Ejemplo: Si se utiliza “-error {-errorcode MyError -level 1}”, se generaría un error como:
return -errorcode MyError -level 1 -code error \
       "opción ambigua ..."

EJEMPLOS

Uso básico:

namespace import ::tcl::prefix
prefix match {apa bepa cepa} apa
     → apa
prefix match {apa bepa cepa} a
     → apa
prefix match -exact {apa bepa cepa} a
     → opción incorrecta "a": debe ser apa, bepa o cepa
prefix match -message "interruptor" {apa ada bepa cepa} a
     → interruptor ambiguo "a": debe ser apa, ada, bepa o cepa
prefix longest {fblocked fconfigure fcopy file fileevent flush} fc
     → fco
prefix all {fblocked fconfigure fcopy file fileevent flush} fc
     → fconfigure fcopy

Simplificando la coincidencia de opciones:

array set opts {-apa 1 -bepa "" -cepa 0}
foreach {arg val} $args {
    set opts([prefix match {-apa -bepa -cepa} $arg]) $val
}

Creando un switch que admita prefijos:

switch [prefix match {apa bepa cepa} $arg] {
    apa  { }
    bepa { }
    cepa { }
}
