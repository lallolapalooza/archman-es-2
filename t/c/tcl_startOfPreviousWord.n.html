INTRODUCCIÓN

Tcl incluye una biblioteca de procedimientos Tcl para funciones de uso común. Los procedimientos definidos en la biblioteca Tcl son genéricos, adecuados para ser utilizados por muchas aplicaciones diferentes. La ubicación de la biblioteca Tcl se devuelve con el comando info library. Además de la biblioteca Tcl, cada aplicación normalmente tendrá su propia biblioteca de procedimientos de soporte; la ubicación de esta biblioteca se indica normalmente por el valor de la variable global $app_library, donde app es el nombre de la aplicación. Por ejemplo, la ubicación de la biblioteca Tk se mantiene en la variable tk_library.

Para acceder a los procedimientos de la biblioteca Tcl, una aplicación debe hacer 'source' del archivo init.tcl en la biblioteca, por ejemplo, con el comando Tcl

source [file join [info library] init.tcl]

Si se invoca el procedimiento de la biblioteca Tcl_Init desde el procedimiento Tcl_AppInit de una aplicación, esto ocurre automáticamente. El código en init.tcl definirá el procedimiento unknown y organizará la carga de los otros procedimientos bajo demanda utilizando el mecanismo de carga automática definido a continuación.

PROCEDIMIENTOS DE COMANDO

Los siguientes procedimientos se proporcionan en la biblioteca Tcl:

auto_execok cmd
Determina si existe un archivo ejecutable o una orden interna del shell con el nombre cmd. Si es así, devuelve una lista de argumentos que se pasarán a exec para ejecutar el archivo ejecutable o la orden interna del shell llamada cmd. Si no, devuelve una cadena vacía. Este comando examina los directorios en la ruta de búsqueda actual (proporcionada por la variable de entorno PATH) en su búsqueda de un archivo ejecutable llamado cmd. En plataformas Windows, la búsqueda se amplía con los mismos directorios y extensiones de archivo que utiliza exec. Auto_execok recuerda información sobre búsquedas anteriores en una matriz llamada auto_execs; esto evita la búsqueda de ruta en llamadas futuras para el mismo cmd. El comando auto_reset puede usarse para forzar a auto_execok a olvidar su información en caché.
auto_import patrón
Auto_import se invoca durante namespace import para ver si los comandos importados especificados por patrón residen en una biblioteca de carga automática. Si es así, los comandos se cargan para que estén disponibles para el intérprete para crear los enlaces de importación. Si los comandos no residen en una biblioteca de carga automática, auto_import no hace nada. La coincidencia de patrones se realiza de acuerdo con las reglas de coincidencia de namespace import.
auto_load cmd
Este comando intenta cargar la definición de un comando Tcl llamado cmd. Para hacerlo, busca en una ruta de carga automática, que es una lista de uno o más directorios. La ruta de carga automática se proporciona mediante la variable global auto_path si existe. Si no existe la variable auto_path, entonces se utiliza la variable de entorno TCLLIBPATH, si existe. De lo contrario, la ruta de carga automática consiste solo en el directorio de la biblioteca Tcl. Dentro de cada directorio de la ruta de carga automática debe haber un archivo tclIndex que describa uno o más comandos definidos en ese directorio y un script para evaluar y cargar cada uno de los comandos. El archivo tclIndex debe generarse con el comando auto_mkindex. Si cmd se encuentra en un archivo de índice, se evalúa el script apropiado para crear el comando. El comando auto_load devuelve 1 si cmd se creó con éxito. El comando devuelve 0 si no había ninguna entrada de índice para cmd o si el script no definió realmente cmd (por ejemplo, porque la información del índice está desactualizada). Si ocurre un error al procesar el script, ese error se devuelve. Auto_load solo lee la información del índice una vez y la guarda en la matriz auto_index; las llamadas futuras a auto_load buscan cmd en la matriz en lugar de volver a leer los archivos de índice. La información del índice en caché puede eliminarse con el comando auto_reset. Esto forzará al próximo comando auto_load a recargar la base de datos del índice desde el disco.
auto_mkindex dir patrón patrón ...
Genera un índice adecuado para su uso por auto_load. El comando busca en dir todos los archivos cuyos nombres coincidan con cualquiera de los argumentos patrón (la coincidencia se realiza con el comando glob), genera un índice de todos los procedimientos de comandos Tcl definidos en todos los archivos coincidentes y almacena la información del índice en un archivo llamado tclIndex en dir. Si no se proporciona ningún patrón, se asumirá un patrón de *.tcl. Por ejemplo, el comando
auto_mkindex foo *.tcl

leerá todos los archivos .tcl en el subdirectorio foo y generará un nuevo archivo de índice foo/tclIndex.

Auto_mkindex analiza los scripts Tcl ejecutándolos en un intérprete hijo y monitorizando los comandos proc y namespace que se ejecutan. Las extensiones pueden usar el paquete (no documentado) auto_mkindex_parser para registrar otros comandos que pueden contribuir al índice de carga automática. Tendrás que leer auto.tcl para ver cómo funciona esto.

Auto_mkindex_old (que tiene la misma sintaxis que auto_mkindex) analiza los scripts Tcl de una manera relativamente poco sofisticada: si alguna línea contiene la palabra “proc” como sus primeros caracteres, se asume que es una definición de procedimiento y la siguiente palabra de la línea se toma como el nombre del procedimiento. Las definiciones de procedimientos que no aparecen de esta manera (por ejemplo, tienen espacios antes de proc) no se indexarán. Si tu script contiene código "peligroso", como código de inicialización global o nombres de procedimientos con caracteres especiales como $, *, [ o ], es más seguro usar auto_mkindex_old.

auto_reset
Destruye toda la información almacenada en caché por auto_execok y auto_load. Esta información se volverá a leer desde el disco la próxima vez que se necesite. Auto_reset también elimina cualquier procedimiento listado en el índice de carga automática, de modo que se cargarán copias nuevas de ellos la próxima vez que se utilicen.
auto_qualify comando espacio_de_nombres
Calcula una lista de nombres completamente calificados para comando. Esta lista refleja la ruta que sigue un intérprete Tcl estándar para la búsqueda de comandos: primero busca el comando en el espacio de nombres actual y luego en el espacio de nombres global. En consecuencia, si comando es relativo y espacio_de_nombres no es ::, la lista devuelta tiene dos elementos: comando con ámbito de espacio_de_nombres, como si fuera un comando en el espacio de nombres espacio_de_nombres; y comando como si fuera un comando en el espacio de nombres global. De lo contrario, si comando es absoluto (comienza con ::), o espacio_de_nombres es ::, la lista contiene solo comando como si fuera un comando en el espacio de nombres global.

Auto_qualify es utilizado por las facilidades de carga automática en Tcl, tanto para producir índices de carga automática como pkgIndex.tcl, como para realizar la carga automática real de funciones en tiempo de ejecución.
