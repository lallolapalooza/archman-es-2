Clasificador de marca de firewall en tc(8) Linux Clasificador de marca de firewall en tc(8)

NOMBRE

fw - filtro de control de tráfico de marca de firewall

SINOPSIS


tc filter ... fw [ classid ID_CLASE ] [ action ACCION_ESPEC ]

DESCRIPCIÓN

El filtro fw permite clasificar paquetes basándose en una fwmark establecida previamente por iptables. Si el valor enmascarado de la fwmark coincide con el handle enmascarado del filtro, el filtro coincide. Por defecto, los 32 bits del handle y de la fwmark se enmascaran. iptables permite marcar paquetes individuales con el objetivo MARK, o conexiones enteras usando CONNMARK. El beneficio de usar este filtro en lugar de hacer el trabajo pesado con tc es que, por un lado, puede ser conveniente mantener el filtrado y la clasificación de paquetes en un solo lugar, posiblemente necesitando hacer coincidir un paquete solo una vez, y por otro lado, los usuarios familiarizados con iptables pero no con tc tendrán menos dificultades para añadir QoS a sus configuraciones.

OPCIONES

classid ID_CLASE
Empuja los paquetes coincidentes a la clase identificada por ID_CLASE.
action ACCION_ESPEC
Aplica una acción del framework de acciones genéricas a los paquetes coincidentes.

EJEMPLOS

Tomemos, por ejemplo, la siguiente declaración de filtro tc:

tc filter add ... handle 6 fw classid 1:1

coincidirá si el valor fwmark del paquete es 6. Esta es una declaración de ejemplo de iptables que marca los paquetes entrantes en eth0:

iptables -t mangle -A PREROUTING -i eth0 -j MARK --set-mark 6

Se pueden establecer bits específicos del fwmark del paquete usando la acción skbedit. Por ejemplo, para establecer solo un bit del fwmark sin cambiar ningún otro bit:

tc filter add ... action skbedit mark 0x8/0x8

El filtro fw se puede usar entonces para coincidir con este bit enmascarando el handle:

tc filter add ... handle 0x8/0x8 fw action drop

Esto es útil cuando diferentes bits del fwmark se asignan a significados diferentes.

VER TAMBIÉN

tc(8), iptables(8), iptables-extensions(8), tc-skbedit(8)
