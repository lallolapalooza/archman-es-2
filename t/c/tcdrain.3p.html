TCDRAIN(3P) Manual del programador POSIX TCDRAIN(3P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tcdrain — esperar la transmisión de salida

SINOPSIS

#include <termios.h>
int tcdrain(int fildes);

DESCRIPCION

La función tcdrain() se bloqueará hasta que toda la salida escrita en el objeto al que se refiere fildes se transmita. El argumento fildes es un descriptor de archivo abierto asociado a una terminal.

Cualquier intento de usar tcdrain() desde un proceso que es miembro de un grupo de procesos en segundo plano en un fildes asociado a su terminal de control, provocará que al grupo de procesos se le envíe una señal SIGTTOU. Si el hilo que llama está bloqueando las señales SIGTTOU o el proceso está ignorando las señales SIGTTOU, se permitirá que el proceso realice la operación y no se enviará ninguna señal.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función tcdrain() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
EINTR
Una señal interrumpió tcdrain().
EIO
El grupo de procesos del proceso de escritura está huérfano, el hilo que llama no está bloqueando SIGTTOU y el proceso no está ignorando SIGTTOU.
ENOTTY
El archivo asociado con fildes no es una terminal.
