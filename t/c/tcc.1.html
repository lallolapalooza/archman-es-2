NOMBRE

tcc - Tiny C Compiler

SINOPSIS

uso: tcc [opciones] [archivo_entrada1 archivo_entrada2...] [-run archivo_entrada args...]

DESCRIPCIÓN

Las opciones de TCC son muy parecidas a las de gcc. La principal diferencia es que TCC también puede ejecutar directamente el programa resultante y darle argumentos en tiempo de ejecución.

Aquí hay algunos ejemplos para entender la lógica:

"tcc -run a.c"
Compila a.c y lo ejecuta directamente
"tcc -run a.c arg1"
Compila a.c y lo ejecuta directamente. arg1 se pasa como primer argumento a la main() de a.c.
"tcc -run a.c b.c arg1"
Compila a.c y b.c, los enlaza y los ejecuta. arg1 se pasa como primer argumento a la main() del programa resultante.
"tcc -o mi_programa a.c b.c"
Compila a.c y b.c, los enlaza y genera el ejecutable mi_programa.
"tcc -o mi_programa a.o b.o"
Enlaza a.o y b.o juntos y genera el ejecutable mi_programa.
"tcc -c a.c"
Compila a.c y genera el archivo objeto a.o.
"tcc -c asmfile.S"
Preprocesa con el preprocesador C y ensambla asmfile.S y genera el archivo objeto asmfile.o.
"tcc -c asmfile.s"
Ensambla (pero no preprocesa) asmfile.s y genera el archivo objeto asmfile.o.
"tcc -r -o ab.o a.c b.c"
Compila a.c y b.c, los enlaza juntos y genera el archivo objeto ab.o.

Scripting:

TCC puede ser invocado desde scripts, al igual que los scripts de shell. Solo necesitas añadir "#!/usr/local/bin/tcc -run" al principio de tu fuente C:

#!/usr/local/bin/tcc -run
#include <stdio.h>

int main() 
{
    printf("Hola Mundo\n");
    return 0;
}

TCC puede leer código fuente C desde la entrada estándar cuando se utiliza - en lugar de archivo_entrada. Ejemplo:

echo 'main(){puts("hola");}' | tcc -run -

OPCIONES

-c
Genera un archivo objeto.
-o archivo_salida
Coloca el archivo objeto, ejecutable o dll en el archivo de salida archivo_salida.
-run fuente [args...]
Compila el archivo fuente y lo ejecuta con los argumentos de línea de comandos args. Para poder pasar más de un argumento a un script, se pueden dar varias opciones de TCC después de la opción -run, separadas por espacios: 
tcc "-run -L/usr/X11R6/lib -lX11" ex4.c

En un script, esto da el siguiente encabezado:

#!/usr/local/bin/tcc -run -L/usr/X11R6/lib -lX11
-v
Muestra la versión de TCC.
-vv
Muestra los archivos incluidos. Como único argumento, imprime los directorios de búsqueda. -vvv muestra también los intentos.
-bench
Muestra estadísticas de compilación.

Opciones del preprocesador:

-Idir
Especifica una ruta de inclusión adicional. Las rutas de inclusión se buscan en el orden en que se especifican.

Las rutas de inclusión del sistema siempre se buscan después. Las rutas de inclusión del sistema predeterminadas son: /usr/local/include, /usr/include y PREFIX/lib/tcc/include. (PREFIX es generalmente /usr o /usr/local).

-Dsym[=val]
Define el símbolo preprocesador sym a val. Si val no está presente, su valor es 1. También se pueden definir macros tipo función: -DF(a)=a+1
-Usym
Anula la definición del símbolo preprocesador sym.
-E
Solo preprocesa, a la salida estándar o a un archivo (con -o).

Bandera de compilación:

Nota: cada una de las siguientes opciones tiene una forma negativa que comienza con -fno-.

-funsigned-char
Que el tipo "char" sea sin signo.
-fsigned-char
Que el tipo "char" sea con signo.
-fno-common
No generar símbolos comunes para datos no inicializados.
-fleading-underscore
Añade un guion bajo inicial al principio de cada símbolo C.
-fms-extensions
Permite extensiones del compilador C de MS al lenguaje. Actualmente esto asume que una declaración de estructura nombrada anidada sin un identificador se comporta como una no nombrada.
-fdollars-in-identifiers
Permite signos de dólar en identificadores
-ftest-coverage
Crea código de cobertura de código. Después de ejecutar el código resultante, se genera un archivo executable.tcov o sofile.tcov con la cobertura del código.

Opciones de advertencia:

-w
Desactiva todas las advertencias.

Nota: cada una de las siguientes opciones de advertencia tiene una forma negativa que comienza con -Wno-.

-Wimplicit-function-declaration
Advierte sobre declaraciones de funciones implícitas.
-Wunsupported
Advierte sobre características de GCC no soportadas que son ignoradas por TCC.
-Wwrite-strings
Hace que las constantes de cadena sean del tipo "const char *" en lugar de "char *".
-Werror
Aborta la compilación si se emite una advertencia. Se le puede pasar una opción para habilitar la advertencia especificada y convertirla en un error, por ejemplo -Werror=unsupported.
-Wall
Activa algunas advertencias útiles.

Opciones del enlazador:

-Ldir
Especifica una ruta adicional de bibliotecas estáticas para la opción -l. Las rutas de bibliotecas predeterminadas son /usr/local/lib, /usr/lib y /lib.
-lxxx
Enlaza tu programa con la biblioteca dinámica libxxx.so o la biblioteca estática libxxx.a. La biblioteca se busca en las rutas especificadas por la opción -L y la variable LIBRARY_PATH.
-Bdir
Establece la ruta donde se pueden encontrar las bibliotecas internas de tcc (y los archivos de inclusión) (el valor predeterminado es PREFIX/lib/tcc).
-shared
Genera una biblioteca compartida en lugar de un ejecutable.
-soname nombre
Establece el nombre para la biblioteca compartida a usar en tiempo de ejecución
-static
Genera un ejecutable enlazado estáticamente (el valor predeterminado es un ejecutable enlazado dinámicamente).
-rdynamic
Exporta símbolos globales al enlazador dinámico. Es útil cuando una biblioteca abierta con dlopen() necesita acceder a símbolos del ejecutable.
-r
Genera un archivo objeto que combina todos los archivos de entrada.
-Wl,-rpath=ruta
Inserta una ruta de búsqueda personalizada para bibliotecas dinámicas en el ejecutable.
-Wl,--enable-new-dtags
Al insertar una ruta de búsqueda personalizada para bibliotecas dinámicas en el ejecutable, crea la nueva etiqueta dinámica ELF DT_RUNPATH en lugar de la antigua leg

OPTIONS

Tcc is a complete C compiler. It accepts the following options:

-c
Compile only, do not link.
-m
Generate relocatable object code.
-o outfile
Place the output in file outfile.
-E
Preprocess only; do not compile or link.
-S
Compile only; do not assemble or link.
-v
Print invocation command line.
-W
Print all unrecognized options found in the command line.
-ansi
Conform to the ANSI C standard.

It is equivalent to -D__STDC__=1. No, it is not.

-c11
Conform to the C11 standard.
-c99
Conform to the C99 standard.
-cpp
Use the C preprocessor. This is the default.
-nostdinc
Do not search the standard system include directories.
-nostdlib
Do not search the standard library directories.
-nostartfiles
Do not use the standard start files when linking.
-print-search-dirs
Print the configured installation directory and a list of library and include directories tcc will search.
-shared
Create a shared object.
-static
Build a static executable.
-Xlinker option
Pass option to the linker. This is equivalent to prefixing the option with -Wl,.
-Wl,option
Pass option to the linker. This is equivalent to using -Xlinker.

Options passed to the linker:

-Wl,--as-needed
-Wl,--no-as-needed
-Wl,-Bdynamic
-Wl,-Bstatic
-Wl,--cref
Output a cross reference table.
-Wl,--dtls
-Wl,--dynamic-linker file
Use file as the program interpreter.
-Wl,--emit-relocs
-Wl,--enable-newdtags
-Wl,--export-dynamic
Export global symbols to the dynamic linker. It is useful when a library opened with dlopen() needs to access executable symbols.
-Wl,-filter-library lib
Filter out symbols from library lib.
-Wl,-hash-style=style
Change the style of the symbol hash table.
-Wl,-init=func
Specify the initialization function.
-Wl,-instrument-code
Instrument code for profiling.
-Wl,--just-symbols file
Use symbols from file.
-Wl,-Map=mapfile
Output a linker map file.
-Wl,--no-define-common
-Wl,-no-whole-archive
Turn off linking of all objects in archives.
-Wl,-nostdlib
Do not use the standard libraries.
-Wl,-nxcompat
-Wl,--oformat=fmt
Use fmt as output format. The supported output formats are:
"elf32-i386"
ELF output format (default)
"binary"
Binary image (only for executable output)
"coff"
COFF output format (only for executable output for TMS320C67xx target)
-Wl,--out-implib file
Create an import library.
-Wl,--pack-dyn-relocs=value
-Wl,-rpath=dir
Add dir to the run-time search path.
-Wl,--relax
Enable linker relaxation.
-Wl,-shared-libgcc
Link against the shared libgcc.
-Wl,--sort-section pattern
Sort sections according to pattern.
-Wl,--split-large-relocations=value
-Wl,-static-libgcc
Link against the static libgcc.
-Wl,-stats
Print statistics about the linking process.
-Wl,--strip-debug
Strip debug information.
-Wl,--strip-unneeded
Strip unneeded symbols.
-Wl,-subsystem=console/gui/wince/...
Set type for PE (Windows) executables.
-Wl,-Tscript
Use script as the linker script.
-Wl,-Ttext=# | section-alignment=# | file-alignment=# | image-base=# | stack=#
Modify executable layout.
-Wl,-Tbss=addr
Set the base address for the bss section.
-Wl,-Tdata=addr
Set the base address for the data section.
-Wl,-Ttext=addr
Set the base address for the text section.
-Wl,-Urgent
-Wl,-verbose
-Wl,--version
Print the linker version.
-Wl,-(no-)whole-archive
Turn on/off linking of all objects in archives.

Debugger options:

-g
Generate run time stab debug information so that you get clear run time error messages: " test.c:68: in function 'test5()': dereferencing invalid pointer" instead of the laconic "Segmentation fault".
-gdwarf
Generate run time dwarf debug information instead of stab debug information.
-gdwarf-x
Generate run time dwarf debug information with extended info.
-b
Generate additional support code to check memory allocations and array/pointer bounds. -g is implied.
-bt
Display stack traces. Use -bt[N] to display N callers in stack traces. This is useful with -g or -b. When activated, "__TCC_BACKTRACE__" is defined.

With executables, additional support for stack traces is included. A function
" int tcc_backtrace(const char *fmt, ...); " is provided to trigger a stack trace with a message on demand.

Misc options:

-M
Just output makefile fragment with dependencies
-MM
Like -M except mention only user header files, not system header files.
-MD
Generate makefile fragment with dependencies.
-MMD
Like -MD except mention only user header files, not system header files.
-MF depfile
Use depfile as output for -MD.
-print-search-dirs
Print the configured installation directory and a list of library and include directories tcc will search.
-dumpversion
Print version.

Target specific options:

-mms-bitfields
Use an algorithm for bitfield alignment consistent with MSVC. Default is gcc's algorithm.
-mfloat-abi (ARM only)
Select the float ABI. Possible values: "softfp" and "hard"
-mno-sse
Do not use sse registers on x86_64
-m32, -m64
Pass command line to the i386/x86_64 cross compiler.

Note: GCC options -Ox, -fx and -mx are ignored.

ENVIRONMENT

Environment variables that affect how tcc operates.

CPATH
C_INCLUDE_PATH
A colon-separated list of directories searched for include files, directories given with -I are searched first.
LIBRARY_PATH
A colon-separated list of directories searched for libraries for the -l option, directories given with -L are searched first.
