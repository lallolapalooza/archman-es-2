NOMBRE

tcplay — herramienta para gestionar volúmenes TrueCrypt

SINOPSIS

tcplay -c -d dispositivo [-g] [-z] [-w] [-a hash_pbkdf] [-b cifrado] [-f archivo_clave_oculto] [-k archivo_clave] [-x hash_pbkdf] [-y cifrado]

tcplay -i -d dispositivo [-e] [-p] [-f archivo_clave_oculto] [-k archivo_clave] [-s dispositivo_sistema] [--fde] [--usar-copia-seguridad] [--usar-archivo-hdr archivo_hdr] [--usar-archivo-hdr-oculto archivo_hdr]

tcplay -j mapeo

tcplay -m mapeo -d dispositivo [-e] [-p] [-f archivo_clave_oculto] [-k archivo_clave] [-s dispositivo_sistema] [-t] [--fde] [--usar-copia-seguridad] [--usar-archivo-hdr archivo_hdr] [--usar-archivo-hdr-oculto archivo_hdr]

tcplay --modificar -d dispositivo [-k archivo_clave] [--nuevo-archivo-clave nuevo_archivo_clave] [--nuevo-prf-pbkdf hash_pbkdf] [-s dispositivo_sistema] [--fde] [--usar-copia-seguridad] [--usar-archivo-hdr archivo_hdr] [--usar-archivo-hdr-oculto archivo_hdr] [--guardar-copia-seguridad-hdr archivo_hdr] [-w]

tcplay --modificar -d dispositivo [-k archivo_clave] --restaurar-desde-copia-seguridad-hdr [-w]

tcplay -u mapeo

tcplay -h | -v

DESCRIPCIÓN

La utilidad tcplay proporciona soporte completo para crear y abrir/mapear volúmenes compatibles con TrueCrypt. Soporta los siguientes comandos, cada uno con un conjunto de opciones detalladas a continuación:

-c, --crear
Crea un nuevo volumen TrueCrypt cifrado en el dispositivo especificado por --dispositivo.
-h, --ayuda
Imprime el mensaje de ayuda y sale.
-i, --información
Imprime información sobre el dispositivo cifrado especificado por --dispositivo.
-j mapeo, --información-mapeado=mapeo
Imprime información sobre el volumen tcplay mapeado especificado por mapeo. La información como el CRC de la clave y el PRF de PBKDF2 no están disponibles a través de este comando.
--modificar
Modifica la cabecera del volumen. Este modo permite cambiar la contraseña, archivos de clave, PRF de PBKDF2, así como restaurar desde una cabecera de copia de seguridad.
-m mapeo, --mapear=mapeo
Mapea el volumen TrueCrypt cifrado en el dispositivo especificado por --dispositivo como un mapeo dm(4) llamado mapeo. El argumento mapeo no debe contener espacios ni caracteres especiales.
-u mapeo, --desmapear=mapeo
Elimina (desmapea) el mapeo dm(4) especificado por mapeo, así como cualquier mapeo en cascada relacionado. Si mapeó un volumen usando cifrado de disco completo y creó mapeos para particiones individuales usando kpartx(8), debe eliminarlos antes de desmapear el volumen.
-v, --versión
Imprime el mensaje de versión y sale.

Opciones comunes a todos los comandos son:

-d dispositivo, --dispositivo=dispositivo
Especifica el dispositivo de disco en el que reside/residirá el volumen TrueCrypt. Esta opción es obligatoria para todos los comandos.
-f archivo_clave_oculto, --archivo-clave-oculto=archivo_clave_oculto
Especifica un archivo de clave a usar además de la contraseña al crear un volumen oculto o al proteger un volumen oculto al mapear o consultar el volumen exterior. Si solo tiene la intención de mapear un volumen oculto, se debe usar la opción --archivo-clave. Esta opción puede aparecer varias veces; si es así, se usarán varios archivos de clave. Esta opción no es válida en el modo --modificar.
-k archivo_clave, --archivo-clave=archivo_clave
Especifica un archivo_clave a usar además de la contraseña. Esta opción puede aparecer varias veces; si es así, se usarán varios archivos de clave.

Opciones adicionales para el comando --crear son:

-a hash_pbkdf, --prf-pbkdf=hash_pbkdf
Especifica qué algoritmo de hash se utilizará para la derivación de la contraseña PBKDF2. Para ver qué algoritmos son compatibles, especifique --prf-pbkdf=ayuda.
-b cifrado, --cifrado=cifrado
Especifica qué algoritmo de cifrado o cascada de cifrados se utilizará para cifrar el nuevo volumen. Para ver qué algoritmos son compatibles, especifique --cifrado=ayuda.
-g, --oculto
Especifica que el volumen recién creado contendrá un volumen oculto. Las claves aplicadas a la contraseña para el volumen oculto son las especificadas por --archivo-clave-oculto. Se le pedirá al usuario el tamaño del volumen oculto

NAME

tcplay — interface to the tc-play kernel module

SYNOPSIS

tcplay --create --device=device [ --cipher=cipher ] [ --keyfile=keyfile ... ] [ --password=password ] [ --password-file=passwordfile ] [ --pbkdf-prf=prf ] [ --keyheader-ver=version ] [ --volume-type=type ] [ --fde ] [ --hidden [ --cipher-hidden=cipher ] [ --keyfile-hidden=keyfile ... ] [ --password-hidden=password ] [ --password-file-hidden=passwordfile ] [ --pbkdf-prf-hidden=prf ] ] [ --partition-size=size ] [ --partition-offset=offset ] [ --uuid=uuid ] [ --force ] [ --veracrypt ] [ --keyfiles-dont-match ] [ --xml ] --mount=mountpoint [ --keyfile=keyfile ... ] [ --password=password ] [ --password-file=passwordfile ] [ --protect-hidden=mountpoint ] [ --xml ] [ --map=name [ --device=device ] [ --keyfile=keyfile ... ] [ --password=password ] [ --password-file=passwordfile ] [ --protect-hidden=mountpoint ] [ --fde ] [ --xml ] [ --unmap=name ] [ --modify [ --device=device ] [ --keyfile=keyfile ... ] [ --password=password ] [ --password-file=passwordfile ] [ --restore-from-backup-hdr ] [ --save-hdr-backup=backupfile ] [ -use-hdr-file=headerfile ] [ -use-hidden-hdr-file=headerfile ] [ --protect-hidden=mountpoint ] [ --xml ] [ --dump-password [ --device=device ] ] [ --help ] [ --version ]

DESCRIPTION

The tcplay utility provides a command-line interface to the tc-play kernel module. It is used to create, mount, unmount, and modify TrueCrypt-compatible encrypted volumes. The tc-play kernel module can be loaded manually or will be loaded automatically when tcplay is invoked.

The tcplay utility can encrypt and decrypt any block device, including hard drives, USB drives, SD cards, and loopback devices.

A detailed description of the various options and functionalities can be found in the following sections.

NOTES

The tcplay utility requires root privileges to create, map, and unmap volumes.

When using keyfiles, ensure that they are stored securely and protected from unauthorized access.

The tc-play kernel module should be loaded before using tcplay for certain operations, although tcplay will attempt to load it automatically if necessary.

PLAUSIBLE DENIABILITY

The tcplay utility supports hidden volumes, which provide plausible deniability. A hidden volume is created within an outer volume, and its existence can be denied if the passphrase or keyfile for the outer volume is revealed. The hidden volume can use different encryption settings than the outer volume.

VERACRYPT SUPPORT

The tcplay utility supports Veracrypt volumes with the --veracrypt option.

EXAMPLES

Create a new encrypted volume on /dev/sdb1 with the AES-256 cipher and mount it on /mnt/myvolume:

tcplay --create --device=/dev/sdb1 --cipher=AES-256 --mount=/mnt/myvolume

Mount an existing encrypted volume secvol using a keyfile and mount it on /mnt:

tcplay --mount=/mnt --device=secvol --keyfile=my.key

Unmount the volume mounted on /mnt:

tcplay --unmount /mnt

Map an encrypted volume named truecrypt2 on device /dev/vn0 using a keyfile:

tcplay --map=truecrypt2 --device=/dev/vn0 --keyfile=hidden.key

Map and mount the volume in the file secvol on Linux:

losetup /dev/loop1 secvol
tcplay --map=secv --device=/dev/loop1
mount /dev/mapper/secv /mnt

Similarly on DragonFly:

vnconfig vn1 secvol
tcplay --map=secv --device=/dev/vn1
mount /dev/mapper/secv /mnt

Unmapping the volume truecrypt2 on both Linux and DragonFly after unmounting:

dmsetup remove truecrypt2

Or alternatively:

tcplay --unmap=truecrypt2

A hidden volume whose existance can be plausibly denied and its outer volume can for example be created with

tcplay --create --hidden --device=/dev/loop0 --cipher=TWOFISH-256-XTS,AES-256-XTS --pbkdf-prf=whirlpool --keyfile=one.key --cipher-hidden=AES-256-XTS --pbkdf-prf-hidden=whirlpool --keyfile-hidden=hidden.key

tcplay will prompt the user for the passphrase for both the outer and hidden volume as well as the size of the hidden volume inside the outer volume. The hidden volume will be created inside the area spanned by the outer volume. The hidden volume can optionally use a different cipher and prf function as specified by the --cipher-hidden and --pbkdf-prf-hidden options. Which volume is later accessed depends only on which passphrase and keyfile(s) are being used, so that the existance of the hidden volume remains unknown without knowledge of the passphrase and keyfile it is protected by since it is located within the outer volume. To map the outer volume without potentially damaging the hidden volume, the passphrase and keyfile(s) of the hidden volume must be known and provided alongside the --protect-hidden option.

A disk encrypted using full disk encryption can be mapped using

tcplay --map=tcplay_sdb --device=/dev/sdb --fde

To access individual partitions on the now mapped disk, the following command will generate mappings for each individual partition on the encrypted disk:

kpartx --av /dev/mapper/tcplay_sdb

To restore the main volume header from the backup header, the following command can be used:

tcplay --modify --device=/dev/sdb --restore-from-backup-hdr

As with most other commands, which header is saved (used as source) depends on the passphrase and keyfiles used.

To save a backup copy of a header, the following command can be used:

tcplay --modify --device=/dev/sdb --save-hdr-backup=/tmp/sdb_backup_header.hdr

As with most other commands, which header is saved (used as source) depends on the passphrase and keyfiles used.

To restore a header from a backup header file, the following command can be used:

tcplay --modify -use-hdr-file=/tmp/sdb_backup_header.hdr

Similarly, to restore a hidden header from a backup header file:

tcplay --modify -use-hidden-hdr-file=/tmp/sdb_backup_hidden_header.hdr

Which header is used as the source of the operation will still depend on the passphrase and keyfiles used. Even if you use the --use-hidden-hdr-file option, if you specify the passphrase and keyfiles for the main header, the main header will be used instead.
