NOMBRE

skbedit - Acción de edición SKB

SINOPSIS


tc ... action skbedit [ queue_mapping QUEUE_MAPPING ] [ priority PRIORITY ] [ mark MARK[/MASK] ] [ ptype PTYPE ] [ inheritdsfield ]

DESCRIPCIÓN

La acción skbedit permite modificar los metadatos asociados a un paquete. Complementa la acción pedit, que a su vez permite modificar partes de los propios datos del paquete.

La característica más única de skbedit es su capacidad para decidir sobre qué cola de una interfaz con múltiples colas de transmisión se enviará el paquete. El número de colas de transmisión disponibles se refleja en entradas de sysfs dentro de /sys/class/net/<interfaz>/queues con el nombre tx-N (donde N es el número real de la cola).

OPCIONES

queue_mapping QUEUE_MAPPING
Sobrescribe la cola de transmisión del paquete. Útil cuando se aplica a paquetes transmitidos a través de interfaces de red compatibles con MQ. QUEUE_MAPPING es un valor de 16 bits sin signo en formato decimal.
priority PRIORITY
Sobrescribe la decisión de clasificación del paquete. PRIORITY es root, none o un ID de clase principal hexadecimal seguido opcionalmente por dos puntos (:) y un ID de clase secundario hexadecimal.
mark MARK[/MASK]
Cambia el valor de la marca del firewall del paquete. MARK es un valor de 32 bits sin signo en formato detectado automáticamente (es decir, prefijo con '0x' para interpretación hexadecimal, etc.). MASK define la máscara de 32 bits que selecciona los bits del valor de la marca. El valor predeterminado es 0xffffffff.
ptype PTYPE
Sobrescribe el tipo de paquete. Útil para establecer el tipo de paquete a host cuando se necesita permitir paquetes entrantes con la dirección MAC incorrecta pero la dirección IP correcta. PTYPE es uno de: host, otherhost, broadcast, multicast
inheritdsfield
Sobrescribe la decisión de clasificación del paquete, y cualquier valor especificado con priority, utilizando la información almacenada en el Campo de Servicios Diferenciados de la cabecera IPv6/IPv4 (RFC2474).
