TCSENDBREAK(3P) Manual de Programador de POSIX TCSENDBREAK(3P)

PRÓLOGO

Esta página del manual es parte del Manual de Programador de POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tcsendbreak — enviar una interrupción durante un período específico

SINOPSIS

#include <termios.h>
int tcsendbreak(int fildes, int duration);

DESCRIPCIÓN

Si el terminal está utilizando transmisión de datos serie asíncrona, tcsendbreak() provocará la transmisión de una secuencia continua de bits de valor cero durante un período específico. Si duration es 0, provocará la transmisión de bits de valor cero durante al menos 0.25 segundos y no más de 0.5 segundos. Si duration no es 0, enviará bits de valor cero durante un período de tiempo definido por la implementación.

El argumento fildes es un descriptor de archivo abierto asociado con un terminal.

Si el terminal no está utilizando transmisión de datos serie asíncrona, se define por implementación si tcsendbreak() envía datos para generar una condición de interrupción o retorna sin tomar ninguna acción.

Los intentos de usar tcsendbreak() desde un proceso que es miembro de un grupo de procesos en segundo plano en un fildes asociado con su terminal de control provocarán que al grupo de procesos se le envíe una señal SIGTTOU. Si el hilo que llama está bloqueando las señales SIGTTOU o el proceso está ignorando las señales SIGTTOU, se permitirá al proceso realizar la operación y no se enviará ninguna señal.

VALOR DE RETORNO

Al completarse con éxito, se devolverá 0. De lo contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función tcsendbreak() fallará si:

EBADF
El argumento fildes no es un descriptor de archivo válido.
EIO
El grupo de procesos del proceso de escritura está huérfano, el hilo que llama no está bloqueando SIGTTOU y el proceso no está ignorando SIGTTOU.
ENOTTY
El archivo asociado con fildes no es un terminal.
