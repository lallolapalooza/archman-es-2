NOMBRE

mpls - módulo de manipulación mpls

SINOPSIS


tc ... action mpls { POP | PUSH | MODIFY | dec_ttl } [ CONTROL ]

POP := pop protocol MPLS_PROTO

PUSH := { push | mac_push } [ protocol MPLS_PROTO ] [ tc MPLS_TC ] [ ttl MPLS_TTL ] [ bos MPLS_BOS ] label MPLS_LABEL

MODIFY := modify [ label MPLS_LABEL ] [ tc MPLS_TC ] [ ttl MPLS_TTL ]

CONTROL := { reclassify | pipe | drop | continue | pass | goto chain CHAIN_INDEX }

DESCRIPCIÓN

La acción mpls realiza encapsulación o descapsulación MPLS en un paquete, reflejado por los modos de operación POP, PUSH, MODIFY y DEC_TTL. El modo POP requiere el etertype de la cabecera que sigue a la cabecera MPLS (por ejemplo, IPv4 u otro MPLS). Eliminará la cabecera MPLS externa y reemplazará el etype en la cabecera MAC con el proporcionado. Los modos PUSH y MODIFY actualizan la información de la cabecera MPLS actual o añaden una nueva cabecera. PUSH requiere al menos una MPLS_LABEL. DEC_TTL no requiere argumentos y simplemente resta 1 al campo TTL de la cabecera MPLS.

OPCIONES

pop
Modo de descapsulación. Requiere el protocolo de la siguiente cabecera.
push
Modo de encapsulación. Añade la cabecera MPLS entre las cabeceras MAC y de red. Requiere al menos la opción label.
mac_push
Modo de encapsulación. Añade la cabecera MPLS antes de la cabecera MAC. Requiere al menos la opción label.
modify
Modo de reemplazo. La etiqueta MPLS existente se reemplaza. label, tc y ttl son opcionales.
dec_ttl
Decrementa el campo TTL en la cabecera MPLS más externa.
label MPLS_LABEL
Especifica la ETIQUETA MPLS para la cabecera MPLS externa. MPLS_LABEL es un entero sin signo de 20 bits, el formato se detecta automáticamente (por ejemplo, prefijar con '0x' para interpretación hexadecimal, etc.).
protocol MPLS_PROTO
Elige el protocolo a usar. Para acciones push, debe ser mpls_uc o mpls_mc (mpls_uc es el valor predeterminado). Para acciones pop, debe ser el protocolo de la siguiente cabecera. Esta opción no se puede usar con modify.
tc MPLS_TC
Elige el valor TC para la cabecera MPLS externa. Número decimal en el rango de 0-7. El valor predeterminado es 0.
ttl MPLS_TTL
Elige el valor TTL para la cabecera MPLS externa. Número en el rango de 0-255. Se seleccionará un valor predeterminado distinto de cero si no se establece explícitamente.
bos MPLS_BOS
Configura manualmente el bit de fin de pila para un push de cabecera MPLS. El valor predeterminado es que TC establezca (o no) el bit automáticamente en función de la siguiente cabecera del paquete.
CONTROL
Cómo continuar después de ejecutar esta acción.
reclassify
Reinicia la clasificación saltando al siguiente filtro adjunto al padre de esta acción.
pipe
Continúa con la siguiente acción, este es el valor predeterminado.
drop
El paquete será descartado sin ejecutar más acciones.
continue
Continúa la clasificación con el siguiente filtro en línea.
pass
Vuelve a la qdisc de llamada para el procesamiento del paquete. Esto finaliza el proceso de clasificación.

EJEMPLOS

El siguiente ejemplo encapsula paquetes IP entrantes en eth0 en MPLS con una etiqueta 123 y los envía fuera por eth1:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol ip parent ffff: flower \
	action mpls push protocol mpls_uc label 123  \
	action mirred egress redirect dev eth1

En este ejemplo, los paquetes MPLS unicast entrantes en eth0 se descapsulan y se redirigen a eth1:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol mpls_uc parent ffff: flower \
	action mpls pop protocol ipv4  \
	action mirred egress redirect dev eth1

Aquí hay otro ejemplo, donde los frames Ethernet entrantes se encapsulan en MPLS con etiqueta 123 y TTL 64. Luego, se añade una cabecera Ethernet externa y el frame resultante finalmente se envía en eth1:

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress matchall \
	action mpls mac_push label 123 ttl 64 \
	action vlan push_eth \
		dst_mac 02:00:00:00:00:02 \
		src_mac 02:00:00:00:00:01 \
	action mirred egress redirect dev eth1

El siguiente ejemplo asume que los paquetes MPLS entrantes con etiqueta 123 transportan frames Ethernet. Se eliminan las cabeceras Ethernet y MPLS externas, luego el frame Ethernet interno se envía en eth1:

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress protocol mpls_uc \
	flower mpls_label 123 mpls_bos 1 \
	action vlan pop_eth \
	action mpls pop protocol teb \
	action mirred egress redirect dev eth1
