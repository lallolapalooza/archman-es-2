DESCRIPCIÓN

La biblioteca tcplay proporciona una interfaz para crear, consultar, mapear y gestionar volúmenes compatibles con TrueCrypt.

La función tc_api_init() inicializa los componentes internos de la biblioteca y la prepara para su uso a través de la API. Esta función debe llamarse antes de utilizar cualquier otra función de la API. Si el argumento verbose es distinto de cero, la biblioteca mostrará información como errores a través de stdout y stderr.

La función tc_api_uninit() limpia toda la memoria segura interna, como la memoria utilizada para cabeceras descifradas, contraseñas, archivos de clave, etc.

La función tc_api_has() comprueba si la biblioteca tcplay cargada tiene la característica especificada por el argumento feature. La versión actual de la biblioteca tcplay admite las siguientes características:

Característica Descripción
trim Permite habilitar descartes/TRIM al mapear un volumen

La función tc_api_cipher_iterate() pasa cada cadena de cifrado disponible a la función de llamada (callback) proporcionada en el argumento fn. El argumento priv se pasa en cada llamada a la función de llamada. El nombre de la cadena de cifrado se pasa a la función de llamada en el argumento name. De forma similar, el argumento ciphers_in_chain contiene el número de cifrados en la cadena actual, y key_length_in_bits contiene la longitud total de la clave para la cadena de cifrado, en bits.

La función tc_api_prf_iterate() pasa cada cadena de cifrado disponible a la función de llamada (callback) proporcionada en el argumento fn. El argumento priv se pasa en cada llamada a la función de llamada. El nombre del algoritmo PKBDF2 PRF se pasa a la función de llamada en el argumento name.

La función tc_api_task_init() inicializa y devuelve un puntero opaco tc_api_task que puede utilizarse para ejecutar comandos de tcplay. Cada tarea solo puede utilizarse para una única llamada a tc_api_task_do() y debe liberarse utilizando tc_api_task_uninit(). El argumento op puede ser una de las siguientes opciones:

crear
Crear un nuevo volumen TrueCrypt cifrado.
mapear
Mapear un volumen TrueCrypt existente.
info
Solicitar información sobre un volumen TrueCrypt cifrado.
info_mapeado
Solicitar información sobre un volumen TrueCrypt mapeado.
desmapear
Desmapear un volumen TrueCrypt mapeado.
modificar
Modificar el volumen TrueCrypt cambiando la contraseña, los archivos de clave, el algoritmo PRF, restaurando desde una cabecera de copia de seguridad, restaurando desde un archivo de cabecera o guardando en un archivo de cabecera.
restaurar
Modificar el volumen TrueCrypt como lo hace modificar, pero sin cambiar la contraseña, los archivos de clave o el algoritmo PRF.

La función tc_api_task_set() permite establecer una serie de opciones diferentes para la tarea actual. La siguiente tabla muestra las claves disponibles en las llamadas a tc_api_task_set() para cada una de las operaciones. La letra M indica que la configuración es obligatoria, mientras que * indica que la configuración es opcional.

El vararg es de tipo const char *. Establece el dispositivo que contiene el volumen TrueCrypt a operar.

secure_erase
El vararg es de tipo int. Determina si se realizará una eliminación segura como parte de la creación del volumen.
hidden_size_bytes
El vararg es de tipo int64_t. Si se establece en 0 implica que no se creará un volumen oculto. Un valor positivo implica que se creará un volumen oculto del tamaño especificado en bytes.

h_prf_algo
El vararg es de tipo const char * y debe ser un algoritmo PRF PBKDF2 válido. Determina qué algoritmo PRF PBKDF2 se utiliza para el volumen oculto.
cipher_chain
El vararg es de tipo const char * y debe ser una cadena de cifrado tcplay válida. Determina qué cadena de cifrado se utiliza para cifrar el volumen externo.
h_cipher_chain
El vararg es de tipo const char * y debe ser una cadena de cifrado tcplay válida. Determina qué cadena de cifrado se utiliza para cifrar el volumen oculto.
protect_hidden
El vararg es de tipo int. Determina si el tamaño del volumen externo se ajustará para proteger cualquier volumen oculto. El uso de este modo requiere contraseñas y archivos de clave tanto para el volumen externo como para el oculto.

El vararg es de tipo const char *. Determina si el volumen es un volumen cifrado del sistema y, en caso afirmativo, qué disco es el disco del sistema y, por lo tanto, contiene la cabecera. Si se establece en NULL, el volumen se tratará implícitamente como un volumen cifrado no del sistema.

El vararg es de tipo int. Determina si el disco utiliza cifrado completo del disco o no. NAME

tcplay_api - functions for programmatic access to tcplay volumes

LIBRARY

Tcplay API library (libtcplay.a, libtcplay.so)

SYNOPSIS

#include <tcplay/tcplay.h>

tc_api_task *tc_api_task_init(const char *task_name);

int tc_api_task_set(tc_api_task *task, const char *option, ...);

int tc_api_task_do(tc_api_task *task);

int tc_api_task_info_get(tc_api_task *task, const char *key, ...);

const char *tc_api_task_get_error(tc_api_task *task);

DESCRIPTION

The tcplay library provides an API that allows applications to access tcplay volumes. It mimics the interface provided by the original TrueCrypt library.

The API is task-oriented. An application must first initialize a task structure using tc_api_task_init(). Then it populates the task with parameters using tc_api_task_set(). Finally it runs the task using tc_api_task_do().

The following tasks are supported:

format
Formats a volume. Requires the following options to be set:
bad_sectors
The vararg is of type const char *. It can be either skip or donotuse. See the tcplay(8) man page for more information.
cascades
The vararg is of type const char *. It sets the number of cascades used when encrypting the volume. See the tcplay(8) man page for more information.
cipher
The vararg is of type const char *. It sets the cipher algorithm used for the volume. See the tcplay(8) man page for more information.
filesystem
The vararg is of type const char *. It specifies the filesystem to create on the volume. See the tcplay(8) man page for more information.
pim
The vararg is of type int. It sets the PIM value used when encrypting the volume. See the tcplay(8) man page for more information.
protect_hidden
The vararg is of type int. If non-zero, the hidden volume header is protected.
hash
The vararg is of type const char *. It sets the hash algorithm used for the volume. See the tcplay(8) man page for more information.
keyfiles
The vararg is of type const char *. If not NULL the given keyfile will be added to the keyfile pool. Multiple calls to set this option with a non- NULL argument result add additional keyfiles. If NULL all keyfiles are cleared.
h_keyfiles
The vararg is of type const char *. If not NULL the given keyfile will be added to the hidden keyfile pool. Multiple calls to set this option with a non- NULL argument result add additional keyfiles. If NULL all keyfiles are cleared. This option is only used if a hidden volume is being created or the protect_hidden setting is set.
new_passphrase
The vararg is of type const char *. It specifies the new passphrase to use when modifying the volume header.
new_keyfiles
The vararg is of type const char *. If not NULL the given keyfile will be added to the new keyfile pool. Multiple calls to set this option with a non- NULL argument result add additional keyfiles. If NULL all new keyfiles are cleared. When the volume header is modified, it will be reencrypted using the new keyfiles.
new_prf_algo
The vararg is of type const char * and must be a valid PBKDF2 PRF algorithm. It determines which PBKDF2 PRF algorithm is used when reencrypting the (modified) volume header.
passphrase
The vararg is of type const char *. It sets the passphrase that tcplay uses to access the volume.
h_passphrase
The vararg is of type const char *. It sets the passphrase that tcplay uses to unlock the hidden volume header. This option is only used if a hidden volume is being created or the protect_hidden setting is set. Otherwise tcplay will first use the regular passphrase to try to unlock the outer volume and then try to unlock the hidden volume header with the same passphrase without ever using h_passphrase.
state_change_fn
The first vararg is of type tc_api_state_change_fn and the second vararg is of type void *. It allows the consumer to provide a callback function which will be called when starting and stopping a time-intensive sub-operation such as collecting entropy or erasing a volume. The second vararg is passed as the priv argument to the callback. The enter_state argument to the callback determines whether tcplay is starting or stopping the time-intensive sub-task specified in the state argument.

keyfiles
The vararg is of type const char *. If not NULL the given keyfile will be added to the keyfile pool. Multiple calls to set this option with a non- NULL argument result add additional keyfiles. If NULL all keyfiles are cleared.
h_keyfiles
The vararg is of type const char *. If not NULL the given keyfile will be added to the keyfile pool. Multiple calls to set this option with a non- NULL argument result add additional keyfiles. If NULL all keyfiles are cleared. This option is only used if a hidden volume is being created or the protect_hidden setting is set. passphrase

h_passphrase
The vararg is of type const char *. It sets the passphrase that tcplay uses to unlock the hidden volume header. This option is only used if a hidden volume is being created or the protect_hidden setting is set. Otherwise tcplay will first use the regular passphrase to try to unlock the outer volume and then try to unlock the hidden volume header with the same passphrase without ever using h_passphrase.
new_passphrase

new_keyfiles

If NULL all new keyfiles are cleared. When the volume header is modified, it will be reencrypted using the new keyfiles.

Mounts a system encryption volume. This task is intended for use by the early boot environment. It takes the same arguments as mount.

Wipes the entire volume. This action is irreversible. Takes the same arguments as mount, except that the passphrase and keyfiles options are ignored.

The tc_api_task_init() function initializes a task structure identified by task_name. The task name must be one of the tasks listed above. It returns a pointer to a tc_api_task structure, or NULL if an error occurred.

The tc_api_task_do() function runs the task specified in the task argument. Before running the task, tc_api_task_do() performs a simple sanity check of the arguments set previously using tc_api_task_set() before performing the actual operation. After a call to tc_api_task_do() for the info or info_mapped operations, the queried information is available to be accessed using tc_api_task_info_get().

The tc_api_task_info_get() function can be used to query the result of a info or info_mapped operation. The task argument is the task used in a previous tc_api_task_do() call. The key argument can be one of the following:

Key type Description
device char * Corresponding device node
cipher char * Used cipher chain
prf char * Used PBKDF2 PRF algorithm
key_bits int * Number of key bits
size int64_t * Volume size in bytes
iv_offset int64_t * IV Offset of volume in bytes
block_offset int64_t * Block Offset of volume in bytes

The second vararg argument must be of the type specified in the above table. The first vararg argument is always the size of the storage provided in the second argument. For a char * argument, the size corresponds to the size of the buffer at the provided location and must be of type size_t. For an int * or int64_t * argument, it should be the size of the underlying type.

The tc_api_task_get_error() function can be used to get a detailed error message after a failed tc_api_task_do call. The task argument is the task used in a previous tc_api_task_do() call.

NOTES

TrueCrypt limits passphrases to 64 characters (including the terminating null character). To be compatible with it, tcplay does the same. All passphrases (exlcuding keyfiles) are trimmed to 64 characters. Similarly, keyfiles are limited to a size of 1 MB, but up to 256 keyfiles can be used.

RETURN VALUES

All functions except tc_api_task_init() and tc_api_task_get_error() return either TC_OK to indicate that the operation completed successfully, or TC_ERR_UNIMPL to indicate that the operation is not implemented , or TC_ERR to indicate that any other error occured.

The tc_api_task_get_error() function always return a valid, but possibly empty (or irrelevant, if not called after an error occurred) string.

The tc_api_task_init() function returns NULL if an error occurred and an opaque tc_api_task otherwise.

COMPATIBILITY

The tcplay library offers full compatibility with TrueCrypt volumes including hidden volumes, system encryption (map-only), keyfiles and cipher cascading.
