NOMBRE

tcplife.bt - Rastrea la vida útil de las sesiones TCP con detalles de conexión. Utiliza bpftrace/eBPF.

SINOPSIS

tcplife

DESCRIPCIÓN

Esta herramienta muestra la vida útil de las sesiones TCP que se abren y cierran mientras se rastrea, y muestra las estadísticas de duración y rendimiento. Para mayor eficiencia, esta herramienta solo instrumenta los cambios de estado TCP, en lugar de todos los paquetes.

Esta herramienta funciona utilizando el tracepoint sock:inet_sock_set_state, que se añadió en Linux 4.16.

Dado que utiliza BPF, solo el usuario root puede utilizar esta herramienta.

REQUISITOS

CONFIG_BPF, bpftrace y el tracepoint sock:inet_sock_set_state (Linux 4.16+).

EJEMPLOS

Mostrar sesiones TCP con detalles:
# tcplife.bt

CAMPOS

SOBRECARGA

Esto rastrea la función de establecimiento de estado TCP del kernel, que debería llamarse con mucha menos frecuencia que el rastreo de envío/recepción, y por lo tanto, debería tener una menor sobrecarga. La sobrecarga de la herramienta es relativa a la tasa de nuevas sesiones TCP: si esta es alta, más de 10.000 por segundo, entonces podría haber una sobrecarga notable solo para imprimir 10.000 líneas de salida formateada por segundo.

Puede averiguar la tasa de nuevas sesiones TCP usando "sar -n TCP 1", y sumando las columnas active/s y passive/s.

Como siempre, pruebe y comprenda la sobrecarga de esta herramienta para sus tipos de cargas de trabajo antes de usarla en producción.
