NOMBRE

route - filtro de control de tráfico de ruta

SINOPSIS


tc filter ... route [ from REALM | fromif TAG ] [ to REALM ] [ classid CLASSID ] [ action ACTION_SPEC ]

DESCRIPCIÓN

Coincide con paquetes basándose en las entradas de la tabla de enrutamiento. Este filtro se centra en la posibilidad de asignar un realm a las entradas de la tabla de enrutamiento. Para que un paquete sea clasificado por este filtro, se realiza una búsqueda en la tabla de enrutamiento y el realm devuelto se utiliza para decidir si el paquete es una coincidencia o no.

OPCIONES

action ACTION_SPEC
Aplica una acción del marco de acciones genéricas a los paquetes coincidentes.
classid CLASSID
Introduce los paquetes coincidentes en la clase identificada por CLASSID.
from REALM
fromif TAG
Realiza búsquedas de rutas de origen. TAG es el nombre de una interfaz que debe estar presente en el sistema en el momento de la invocación de tc.
to REALM
Coincide si el enrutamiento normal (es decir, de destino) devuelve el REALM dado.

EJEMPLOS

Considere la subred 192.168.2.0/24 conectada a eth0:

ip route add 192.168.2.0/24 dev eth0 realm 2

El siguiente filtro route coincidirá entonces con los paquetes de esa subred:

tc filter add ... route from 2 classid 1:2

y pasará los paquetes a la clase 1:2.

NOTAS

Debido a detalles de implementación, los valores de realm deben estar en un rango de 0 a 255, inclusive. Alternativamente, se puede proporcionar un nombre detallado definido en /etc/iproute2/rt_realms.
