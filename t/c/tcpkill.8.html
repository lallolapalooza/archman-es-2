NOMBRE

tcpkill - finalizar conexiones TCP en una LAN

SINOPSIS

tcpkill [-i interfaz] [-1...9] expresión

DESCRIPCIÓN


tcpkill finaliza conexiones TCP en curso especificadas (útil para aplicaciones basadas en libnids que requieren un 3-way handshake TCP completo para la creación de TCB).

OPCIONES

-i interfaz
Especifica la interfaz en la que escuchar.
-1...9
Especifica el grado de fuerza bruta a utilizar para finalizar una conexión. Las conexiones rápidas pueden requerir un número mayor para poder enviar un RST dentro de la ventana de recepción en movimiento. El valor predeterminado es 3.
expresión
Especifica una expresión de filtro de tcpdump(8) para seleccionar las conexiones a finalizar.

VER TAMBIÉN

dsniff(8), tcpnice(8)
