NOMBRE

tcpliveplay - Reproduce tráfico de red almacenado en un archivo pcap en redes en vivo utilizando nuevas conexiones TCP

SINOPSIS

tcpliveplay [-flags] [-flag [valor]] [--option-name[[=| ]valor]] <eth0/eth1> <archivo.pcap> <IP de destino [1.2.3.4]> <MAC de destino [0a:1b:2c:3d:4e:5f]> <'random' puerto de destino O especificar dport #>

Este programa, 'tcpliveplay', reproduce un conjunto de paquetes capturados utilizando nuevas conexiones TCP con las cargas útiles TCP capturadas contra un host remoto para realizar pruebas de vulnerabilidad exhaustivas.

DESCRIPCIÓN

La operación básica de tcpliveplay es reescribir el archivo pcap dado en un formato de evento programado y responde con el paquete apropiado si el host remoto cumple con la expectativa SEQ/ACK del protocolo TCP. Una vez que se cumplen las expectativas, se envían los paquetes locales con la misma carga útil excepto con nuevos números SEQ y ACK de TCP que cumplen con la respuesta del host remoto.

El archivo pcap de entrada se reescribe para comenzar en el primer encuentro del paquete SYN para un funcionamiento correcto, haciendo que este paquete sea la primera acción en el programa de eventos del host local que realiza la reproducción.

Para más detalles, por favor, consulte el Manual de Tcpreplay en: http://tcpreplay.appneta.com

OPCIONES

-d número, --dbug=número

Habilita la salida de depuración. Esta opción puede aparecer hasta 1 vez. Esta opción toma un número entero como argumento. El valor de número está restringido a: 
en el rango 0 a 5

El valor predeterminado de número para esta opción es:
0

Si se configura con --enable-debug, entonces puedes especificar un nivel de verbosidad para la salida de depuración. Los números más altos aumentan la verbosidad.

-V, --version

Imprime la información de la versión.
-h, --less-help

Muestra menos información de uso y sale.
-H, --help

Muestra información de uso y sale.
-!, --more-help

Pasa la información de uso extendida a través de un paginador.
--save-opts [=archivo_config]

Guarda el estado de la opción en archivo_config. El valor predeterminado es el último archivo de configuración listado en la sección AJUSTES PREESTABLECIDOS DE OPCIONES, más abajo. El comando saldrá después de actualizar el archivo de configuración.
--load-opts=archivo_config, --no-load-opts

Carga las opciones desde archivo_config. La forma no-load-opts deshabilitará la carga de archivos de configuración/rc/ini anteriores. --no-load-opts se maneja temprano, fuera de orden.

AJUSTES PREESTABLECIDOS DE OPCIONES

Cualquier opción que no esté marcada como no preseteable puede ser preconfigurada cargando valores de archivos de configuración ("RC" o ".INI"). El archivo homerc es "$$/", a menos que sea un directorio. En ese caso, el archivo ".tcpliveplayrc" se busca dentro de ese directorio.

ARCHIVOS

Consulte AJUSTES PREESTABLECIDOS DE OPCIONES para ver los archivos de configuración.
