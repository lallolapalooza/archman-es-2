TFTP(1) Manual del usuario TFTP(1)

NOMBRE

tftp - Cliente IPv4 del Protocolo Trivial de Transferencia de Archivos

SINOPSIS

tftp [ opciones... ] [host [puerto]] [-c comando]

DESCRIPCIÓN

tftp es un cliente para el Protocolo Trivial de Transferencia de Archivos, que puede usarse para transferir archivos desde y hacia máquinas remotas, incluyendo sistemas muy minimalistas, usualmente embebidos. El host remoto puede ser especificado en la línea de comandos, en cuyo caso tftp usa host como el host por defecto para futuras transferencias (ver el comando connect abajo.)

OPCIONES

-4
Conectar solo con IPv4, incluso si se compiló soporte para IPv6.
-6
Conectar solo con IPv6, si se compiló.
-c comando
Ejecutar comando como si se hubiera introducido en el prompt de tftp. Debe especificarse al final de la línea de comandos.
-l
Por defecto en modo literal. Se usa para evitar el procesamiento especial de ':' en un nombre de archivo.
-m modo
Establecer el modo de transferencia por defecto a modo. Esto se usa usualmente con -c.
-R puerto:puerto
Forzar que el número de puerto de origen esté en el rango especificado de números de puerto.
-v
Por defecto en modo verboso.
-V
Imprimir el número de versión y la configuración en la salida estándar, luego salir graciosamente.

COMANDOS

Una vez que tftp está en ejecución, emite el prompt tftp> y reconoce los siguientes comandos:

? nombre-comando...
help nombre-comando...
Imprimir información de ayuda
ascii
Abreviatura de mode ascii.
binary
Abreviatura de mode binary.
connect host [puerto]
Establecer el host (y opcionalmente el puerto) para las transferencias. Nótese que el protocolo TFTP, a diferencia del protocolo FTP, no mantiene conexiones entre transferencias; por lo tanto, el comando connect no crea realmente una conexión, sino que simplemente recuerda qué host se usará para las transferencias. No tiene que usar el comando connect; el host remoto puede ser especificado como parte de los comandos get o put.
get archivo
get archivo-remoto archivo-local
get archivo1 archivo2 archivo3...
Obtener un archivo o un conjunto de archivos de las fuentes especificadas. Un nombre de archivo remoto puede estar en una de dos formas: un nombre de archivo simple en el host remoto, si el host ya ha sido especificado, o una cadena de la forma host:nombre-archivo para especificar tanto un host como un nombre de archivo al mismo tiempo. Si se usa esta última forma, el último nombre de host especificado se convierte en el predeterminado para futuras transferencias. Habilite el modo literal para evitar el tratamiento especial del carácter ':' (p.ej., C:\dir\archivo).
literal
Alternar el modo literal. Cuando está activado, este modo evita el tratamiento especial de ':' en los nombres de archivo.
mode modo-transferencia
Especificar el modo para las transferencias; modo-transferencia puede ser uno de los siguientes: ascii (o netascii) o binary (o octet.) El valor predeterminado es ascii.
put archivo
put archivo-local archivo-remoto
put archivo1 archivo2 archivo3... directorio-remoto
Enviar un archivo o un conjunto de archivos al archivo o directorio remoto especificado. El destino puede estar en una de dos formas: un nombre de archivo en el host remoto, si el host ya ha sido especificado, o una cadena de la forma host:nombre-archivo para especificar tanto un host como un nombre de archivo al mismo tiempo. Si se usa la última forma, el nombre de host especificado se convierte en el predeterminado para futuras transferencias. Si se usa la forma de directorio-remoto, se asume que el host remoto es un sistema UNIX u otro sistema que usa / como separador de directorios. Habilite el modo literal para evitar el tratamiento especial del carácter ':' (p.ej., C:\dir\archivo).
quit
Salir de tftp. El fin de archivo también causará la salida.
rexmt tiempo-retransmision
Establecer el tiempo de espera de retransmisión por paquete, en segundos.
status
Mostrar el estado actual.
timeout tiempo-total-transmision
Establecer el tiempo de espera total de la transmisión, en segundos.
trace
Alternar el rastreo de paquetes (una característica de depuración.)
verbose
Alternar el modo verboso.

NOTAS

El protocolo TFTP no proporciona disposiciones para autenticación o seguridad. Por lo tanto, el servidor remoto probablemente implementará algún tipo de restricción de acceso o firewall. Estas restricciones de acceso probablemente serán específicas del sitio y del servidor.
