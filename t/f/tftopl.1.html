TFTOPL(1) Manual de Comandos Generales TFTOPL(1)

NOMBRE

tftopl - convierte archivos de métricas de fuentes TeX (tfm) a listas de propiedades

SINOPSIS

tftopl [OPCIONES] nombre_tfm[.tfm] [nombre_pl[.pl]]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa de esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: Una implementación de TeX.

El programa tftopl traduce un archivo de métricas de fuentes (orientado a programas) a un archivo de lista de propiedades (orientado a humanos). De este modo, puede editar el contenido de los archivos TFM, si el diseñador de fuentes no ha hecho su trabajo correctamente, o si está experimentando dificultades extrañas, o si simplemente tiene curiosidad. También sirve como programa de validación de archivos TFM, es decir, si no se dan mensajes de error, el archivo de entrada es correcto.

A nombre_pl se le añade .pl si carece de sufijo. Si no se proporciona nombre_pl, se utiliza la salida estándar. Igualmente, a nombre_tfm se le añade .tfm si carece de sufijo. Además, se realiza una búsqueda en la ruta del archivo TFM utilizando la variable de entorno TEXFONTS. Si esta no está configurada, tftopl utiliza la configuración predeterminada del sistema.

Consulte tex(1) para obtener detalles sobre la búsqueda.

OPCIONES

-formato-codigocaracter=formato
El argumento formato especifica cómo se muestran los códigos de carácter en el archivo PL. Por defecto, solo las letras y los dígitos se muestran utilizando el código entero C (es decir, en ASCII); los demás se muestran en octal. (A menos que el esquema de codificación de la fuente comience con TeX math sy o TeX math ex, en cuyo caso todos los códigos de carácter se muestran en octal). Si formato es ascii, todos los códigos de carácter que corresponden a caracteres gráficos, además de los paréntesis de apertura y cierre, se muestran en ASCII. Finalmente, si formato es octal, todos los códigos de carácter se muestran en octal.
-verboso
Sin esta opción, tftopl opera silenciosamente. Con ella, se imprime un encabezado y un informe de progreso en stdout.
