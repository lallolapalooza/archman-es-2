tsearch(3) Manual de Funciones de Biblioteca tsearch(3)

NOMBRE

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy - gestionar un árbol de búsqueda binario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* Véase feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

DESCRIPCIÓN

tsearch(), tfind(), twalk() y tdelete() gestionan un árbol de búsqueda binario. Se generalizan a partir del Algoritmo T de Knuth (6.2.2). El primer campo en cada nodo del árbol es un puntero al elemento de datos correspondiente. (El programa que llama debe almacenar los datos reales.) compar apunta a una rutina de comparación, que toma punteros a dos elementos. Debe devolver un entero que sea negativo, cero o positivo, dependiendo de si el primer elemento es menor que, igual a, o mayor que el segundo.

tsearch() busca en el árbol un elemento. key apunta al elemento a buscar. rootp apunta a una variable que apunta a la raíz del árbol. Si el árbol está vacío, la variable a la que apunta rootp debe establecerse en NULL. Si el elemento se encuentra en el árbol, entonces tsearch() devuelve un puntero al nodo del árbol correspondiente. (En otras palabras, tsearch() devuelve un puntero a un puntero al elemento de datos). Si el elemento no se encuentra, entonces tsearch() lo añade y devuelve un puntero al nodo del árbol correspondiente.

tfind() es como tsearch(), excepto que si el elemento no se encuentra, entonces tfind() devuelve NULL.

tdelete() elimina un elemento del árbol. Sus argumentos son los mismos que los de tsearch().

twalk() realiza un recorrido en profundidad, de izquierda a derecha, de un árbol binario. root apunta al nodo de inicio para el recorrido. Si ese nodo no es la raíz, entonces solo se visitará una parte del árbol. twalk() llama a la función de usuario action cada vez que se visita un nodo (es decir, tres veces para un nodo interno y una vez para una hoja). action, a su vez, toma tres argumentos. El primer argumento es un puntero al nodo que se está visitando. La estructura del nodo no se especifica, pero es posible convertir el puntero a un puntero a puntero a elemento para acceder al elemento almacenado dentro del nodo. La aplicación no debe modificar la estructura apuntada por este argumento. El segundo argumento es un entero que toma uno de los valores preorder, postorder o endorder dependiendo de si esta es la primera, segunda o tercera visita al nodo interno, o el valor leaf si esta es la visita única a un nodo hoja. (Estos símbolos se definen en <search.h>.) El tercer argumento es la profundidad del nodo; el nodo raíz tiene profundidad cero.

(Más comúnmente, preorder, postorder y endorder se conocen como preorden, inorden y postorden: antes de visitar los hijos, después del primero y antes del segundo, y después de visitar los hijos. Por lo tanto, la elección del nombre postorder es bastante confusa).

twalk_r() es similar a twalk(), pero en lugar del argumento depth, el puntero de argumento closure se pasa a cada invocación de la función de acción, sin cambios. Este puntero se puede usar para pasar información hacia y desde la función de devolución de llamada de forma segura en subprocesos, sin recurrir a variables globales.

tdestroy() elimina todo el árbol apuntado por root, liberando todos los recursos asignados por la función tsearch(). Para los datos en cada nodo del árbol se llama a la función free_node. El puntero a los datos se pasa como argumento a la función. Si no es necesario dicho trabajo, free_node debe apuntar a una función que no haga nada.

VALOR DE RETORNO

tsearch() devuelve un puntero a un nodo coincidente en el árbol, o al nodo recién añadido, o NULL si no hubo suficiente memoria para añadir el elemento. tfind() devuelve un puntero al nodo, o NULL si no se encuentra ninguna coincidencia. Si hay varios elementos que coinciden con la clave, el elemento cuyo nodo se devuelve no está especificado.

tdelete() devuelve un puntero al padre del nodo eliminado, o NULL si no se encontró el elemento. Si el nodo eliminado era el nodo raíz, tdelete() devuelve un puntero colgante al que no se debe acceder.

tsearch(), tfind() y tdelete() también devuelven NULL si rootp era NULL en la entrada.

NOTAS

twalk() toma un puntero a la raíz, mientras que las otras funciones toman un puntero a una variable que apunta a la raíz.

tdelete() libera la memoria necesaria para el nodo en el árbol. El usuario es responsable de liberar la memoria de los datos correspondientes.

El programa de ejemplo depende del hecho de que twalk() no hace ninguna referencia adicional a un nodo después de llamar a la función de usuario con los argumentos "endorder" o "leaf". Esto funciona con la implementación de la biblioteca GNU, pero no está en la documentación de System V.

tsearch(3) - Manual Page

NAME

tsearch, tfind, tdelete, twalk, tdestroy - manage binary search trees

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <search.h>

void *tsearch(const void *restrict key, void **restrict *restrict rootp, int (*compar)(const void *, const void *));
void *tfind(const void *key, void *const *rootp, int (*compar)(const void *, const void *));
void *tdelete(const void *key, void **rootp, int (*compar)(const void *, const void *));
void twalk(const void *root, void (*action)(const void *, VISIT, int));
void tdestroy(void *root, void (*free_node)(void *));

DESCRIPTION

These functions manage binary search trees. The trees store pointers to data, not the data itself. All functions operate on a tree whose root is pointed to by *rootp. If *rootp is NULL, the tree is empty.

tsearch inserts a new node into the tree if the key is not found. The tree is ordered according to the compar function, which is called with two pointers to keys. The compar function should return a negative value if the first key is less than the second, a positive value if the first key is greater than the second, and zero if the keys are equal.

tfind searches the tree for the specified key. It returns a pointer to the node containing the key, or NULL if the key is not found.

tdelete deletes the node containing the specified key from the tree. It returns a pointer to the deleted node, or NULL if the key is not found. The caller is responsible for freeing the memory associated with the deleted node.

twalk traverses the tree and performs the specified action for each node. The action function is called with a pointer to the node, a VISIT type, and the depth of the node in the tree. The VISIT types are preorder, postorder, endorder, and leaf.

tdestroy destroys the entire tree, freeing all nodes. The free_node function is called for each node to free its associated data.

RETURN VALUE

See the descriptions of each function above.

ATTRIBUTES

See attributes(7) for definitions of the following terms: MBeans, OldValue, NewValue.

STANDARDS

These functions conform to the POSIX.1-2001 standard.

HISTORY

These functions first appeared in FreeBSD 2.0.

NOTES

The tree nodes store pointers to the keys. This means that the caller is responsible for managing the memory associated with the keys. If a key is inserted into the tree and then later modified or freed, the tree may become corrupted.

The tsearch function may return a pointer to an existing node if a duplicate key is encountered. In this case, the new key is not inserted, and the caller should free the memory allocated for the new key.

EXAMPLES

/*
 * Example program for tsearch, twalk, and tdestroy.
 */
#include <search.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

// Global variable to hold the root of the binary search tree.
static void *root = NULL;

// Custom memory allocation function that exits on failure.
static void *
xmalloc(size_t n)
{
    void *p;
    p = malloc(n);
    if (p)
        return p;
    fprintf(stderr, "insufficient memory\n");
    exit(EXIT_FAILURE);
}

// Comparison function for integers.
// Used by tsearch and tfind to compare keys.
static int
compare(const void *pa, const void *pb)
{
    if (*(int *) pa < *(int *) pb)
        return -1;
    if (*(int *) pa > *(int *) pb)
        return 1;
    return 0;
}

// Action function to be called by twalk for each node.
// Prints the value of the node if it's a postorder or leaf traversal.
static void
action(const void *nodep, VISIT which, int depth)
{
    int *datap;
    switch (which) {
    case preorder:
        // Do nothing on preorder traversal.
        break;
    case postorder:
        // On postorder traversal, print the node's data.
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    case endorder:
        // Do nothing on endorder traversal.
        break;
    case leaf:
        // On leaf traversal, print the node's data.
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    }
}

// Main function to demonstrate the binary search tree functions.
int
main(void)
{
    int  *ptr;
    int  **val;

    // Seed the random number generator.
    srand(time(NULL));

    // Insert 12 random integers into the binary search tree.
    for (unsigned int i = 0; i < 12; i++) {
        // Allocate memory for the integer.
        ptr = xmalloc(sizeof(*ptr));
        // Assign a random value (0-255).
        *ptr = rand() & 0xff;
        // Try to insert the new node into the tree.
        val = tsearch(ptr, &root, compare);
        if (val == NULL)
            // Exit if tsearch fails (e.g., memory allocation error).
            exit(EXIT_FAILURE);
        // If the key was already in the tree, tsearch returns a pointer
        // to the existing node. In this case, we must free the newly
        // allocated memory for the duplicate key.
        if (*val != ptr)
            free(ptr);
    }

    // Traverse the tree and print the values using the action function.
    twalk(root, action);
    // Destroy the tree and free all allocated memory.
    tdestroy(root, free);

    // Exit successfully.
    exit(EXIT_SUCCESS);
}
