CTZRZF

Propósito:

!>
!> CTZRZF reduce la matriz A superior trapezoidal compleja M por N ( M<=N )
!> a forma triangular superior mediante transformaciones unitarias.
!>
!> La matriz trapezoidal superior A se factoriza como
!>
!>    A = ( R  0 ) * Z,
!>
!> donde Z es una matriz unitaria N por N y R es una matriz triangular
!> superior M por M.
!>

Parámetros

M 
!>          M es ENTERO
!>          El número de filas de la matriz A.  M >= 0.
!>

N

!>          N es ENTERO
!>          El número de columnas de la matriz A.  N >= M.
!>

A

!>          A es un array COMPLEJO, dimensión (LDA,N)
!>          En la entrada, la parte superior trapezoidal M por N principal
!>          del array A debe contener la matriz a factorizar.
!>          En la salida, la parte superior triangular M por M principal
!>          contiene la matriz triangular superior R, y los elementos M+1 a
!>          N de las primeras M filas de A, con el array TAU, representan la
!>          matriz unitaria Z como un producto de M reflectores elementales.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal del array A.  LDA >= max(1,M).
!>

TAU

!>          TAU es un array COMPLEJO, dimensión (M)
!>          Los factores escalares de los reflectores elementales.
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es ENTERO
!>          La dimensión del array WORK.  LWORK >= max(1,M).
!>          Para un rendimiento óptimo LWORK >= M*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo;
!>          la rutina solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

!>
!>  La matriz Z de N por N se puede calcular mediante
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  donde cada Z(k) de N por N viene dada por
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**H
!>
!>  con v(k) es el k-ésimo vector fila de la matriz M por N
!>

!>
!>  I es la matriz identidad M por M, A(:,M+1:N)
!>  es la salida almacenada en A al salir de CTZRZF,
!>  y tau(k) es el k-ésimo elemento del array TAU.
!>
!>

NAME

stzrzf, ztzrzf - factor a real or complex upper trapezoidal matrix and update other matrices.

SYNOPSIS

In order to use these subroutines, include these interfaces in your program:

SUBROUTINE STZRZF(M, N, A, LDA, TAU, WORK, LWORK, INFO)
INTEGER M, N, LDA, LWORK, INFO
REAL A(LDA,*)
REAL TAU(*)
REAL WORK(*)

SUBROUTINE ZTZRZF(M, N, A, LDA, TAU, WORK, LWORK, INFO)
INTEGER M, N, LDA, LWORK, INFO
COMPLEX*16 A(LDA,*)
COMPLEX*16 TAU(*)
COMPLEX*16 WORK(*)

Detailed Description

This subroutine is intended to be called after the routine DGEQRT or DGGQRT. It is described in Section 3.3.2 of the LAPACK User's Guide.

STZRZF reduces the M-by-N ( M<=N ) real upper trapezoidal matrix A to upper triangular form by means of orthogonal transformations.

The upper trapezoidal matrix A is factored as

   A = ( R  0 ) * Z,

where Z is an N-by-N orthogonal matrix and R is an M-by-M upper triangular matrix.

ZTZRZF reduces the M-by-N ( M<=N ) complex upper trapezoidal matrix A to upper triangular form by means of unitary transformations.

The upper trapezoidal matrix A is factored as

   A = ( R  0 ) * Z,

where Z is an N-by-N unitary matrix and R is an M-by-M upper triangular matrix.

STZRZF

Purpose:

!>
!> STZRZF reduces the M-by-N ( M<=N ) real upper trapezoidal matrix A
!> to upper triangular form by means of orthogonal transformations.
!>
!> The upper trapezoidal matrix A is factored as
!>
!>    A = ( R  0 ) * Z,
!>
!> where Z is an N-by-N orthogonal matrix and R is an M-by-M upper
!> triangular matrix.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= M.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the leading M-by-N upper trapezoidal part of the
!>          array A must contain the matrix to be factorized.
!>          On exit, the leading M-by-M upper triangular part of A
!>          contains the upper triangular matrix R, and elements M+1 to
!>          N of the first M rows of A, with the array TAU, represent the
!>          orthogonal matrix Z as a product of M elementary reflectors.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

TAU

!>          TAU is REAL array, dimension (M)
!>          The scalar factors of the elementary reflectors.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.  LWORK >= max(1,M).
!>          For optimum performance LWORK >= M*NB, where NB is
!>          the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
