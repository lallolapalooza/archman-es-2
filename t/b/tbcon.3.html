CTBCON

Propósito:

!>
!> CTBCON estima el recíproco del número de condición de una
!> matriz banda triangular A, en la norma 1 o en la norma infinito.
!>
!> Se calcula la norma de A y se obtiene una estimación para
!> norm(inv(A)), luego se calcula el recíproco del número de condición como
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parámetros

NORM 
!>          NORM es CHARACTER*1
!>          Especifica si se requiere el número de condición en norma 1 o en
!>          norma infinito:
!>          = '1' o 'O':  norma 1;
!>          = 'I':         norma infinito.
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales o subdiagonales de la
!>          matriz banda triangular A.  KD >= 0.
!>

AB

!>          AB es un array COMPLEJO, dimensión (LDAB,N)
!>          La matriz banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asume que son 1.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión principal del array AB.  LDAB >= KD+1.
!>

RCOND

!>          RCOND es REAL
!>          El recíproco del número de condición de la matriz A,
!>          calculado como RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK es un array COMPLEJO, dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>
