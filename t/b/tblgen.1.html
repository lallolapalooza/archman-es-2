NOMBRE

tblgen - Descripción a Código C++

SINOPSIS

clang-tblgen [opciones] [nombre_archivo]

lldb-tblgen [opciones] [nombre_archivo]

llvm-tblgen [opciones] [nombre_archivo]

mlir-tblgen [opciones] [nombre_archivo]

DESCRIPCIÓN

*-tblgen es una familia de programas que traduce archivos de descripción de destino (.td) a código C++ y otros formatos de salida. La mayoría de los usuarios de LLVM no necesitarán usar este programa. Se usa solo para escribir partes del compilador, depurador y backends de destino de LLVM.

Los detalles de la entrada y salida de los programas *-tblgen están fuera del alcance de esta breve introducción; por favor, consulte la Visión General de TableGen <> para una introducción y referencias a documentos adicionales de TableGen.

El argumento nombre_archivo especifica el nombre del archivo de Descripción de Destino (.td) que TableGen procesa.

OPCIONES

Opciones Generales

-help
Imprime una descripción de las opciones de la línea de comandos.
-help-list
Imprime una descripción de las opciones de la línea de comandos en un formato de lista simple.
-D=nombre_macro
Especifica el nombre de una macro a definir. El nombre se define, pero no tiene un valor particular.
-d=nombre_archivo
Especifica el nombre del archivo de dependencia.
-debug
Habilita la salida de depuración.
-dump-json
Imprime una representación JSON de todos los registros, adecuada para procesamiento automatizado posterior.
-I directorio
Especifica dónde encontrar otros archivos de descripción de destino para incluir. El valor de directorio debe ser una ruta completa o parcial a un directorio que contenga archivos de descripción de destino.
-null-backend
Analiza los archivos fuente y construye los registros, pero no ejecuta ningún backend. Esto es útil para medir el tiempo del frontend.
-o nombre_archivo
Especifica el nombre del archivo de salida. Si nombre_archivo es -, entonces *-tblgen envía su salida a la salida estándar.
-print-records
Imprime todas las clases y registros a la salida estándar (opción de backend predeterminada).
-print-detailed-records
Imprime un informe detallado de todas las variables globales, clases y registros a la salida estándar.
-stats
Imprime un informe con las estadísticas recopiladas por el backend.
-time-phases
Mide el tiempo de las fases del analizador y del backend e imprime un informe.
-version
Muestra el número de versión del programa.
-write-if-changed
Escribe el archivo de salida solo si es nuevo o ha cambiado.

NAME

tblgen

TableGen machine description language processor

SYNOPSIS

tblgen [options] [filename...]

DESCRIPTION

The tblgen utility is a tool used to process input files written in the TableGen language. TableGen is a generic, domain-independent language that is designed to specify the behavior of things that are naturally described by some form of machine description table. It is currently used in various parts of the LLVM compiler infrastructure, particularly for describing instruction sets, register allocation information, and other machine-specific details.

The primary purpose of tblgen is to read one or more TableGen definition files and generate C++ code, documentation, or other artifacts based on the definitions provided. The behavior of tblgen is controlled by a set of command-line options.

OPTIONS

-gen-emitter
Generate instruction emitter code.
-gen-intrinsic-emitter
Generate intrinsic emitter code.
-gen-register-info
Generate register information code.
-gen-scheduling-info
Generate instruction scheduler information code.
-gen-subtarget-emitter
Generate subtarget emitter code.
-gen-target-info
Generate target information code.
-gen-type-legalizer
Generate type legalizer code.
-gen-intrinsic-info
Generate intrinsic information code.
-gen-machine-function-info
Generate MachineFunction info code.
-gen-machine-module-info
Generate MachineModule info code.
-gen-target-call-conv
Generate target call-conv code.
-gen-target-header
Generate target header file.
-gen-target-mc-emitter
Generate target MC emitter code.
-gen-dag-isel
Generate DAG instruction selection code.
-gen-global-isel
Generate global instruction selection code.
-gen-op-decls
Generar declaraciones de operaciones.
-gen-op-defs
Generar definiciones de operaciones.
-asmformat-error-is-fatal
Emitir un error fatal si falla el análisis del formato.
-op-exclude-regex
Expresión regular del nombre de las operaciones a excluir (sin filtro si está vacía).

Expresión regular del nombre de las operaciones a incluir (sin filtro si está vacía).
-gen-op-doc
Generar documentación de operaciones.
-gen-pass-decls
Generar documentación de operaciones.
-name namestring
El nombre de este grupo de pases.
-gen-pass-doc
Generar documentación de pases.
-gen-rewriters
Generar reescritores de patrones.
-gen-spirv-avail-impls
Generar definiciones de utilidad de operaciones SPIR-V.
-gen-spirv-capability-implication
Generar una función de utilidad para devolver las capacidades implicadas para una capacidad dada.
-gen-spirv-enum-avail-decls
Generar declaraciones de disponibilidad de enumeraciones SPIR-V.
-gen-spirv-enum-avail-defs
Generar definiciones de disponibilidad de enumeraciones SPIR-V.
-gen-spirv-op-utils
Generar definiciones de utilidad de operaciones SPIR-V.
-gen-spirv-serialization
Generar utilidades y funciones de (de)serialización SPIR-V.
-gen-struct-attr-decls
Generar declaraciones de utilidad de estructuras.
-gen-struct-attr-defs
Generar definiciones de utilidad de estructuras.

Generar declaraciones de TypeDef.
-gen-typedef-defs
Generar definiciones de TypeDef.

Generar tipos para este dialecto.

EXIT STATUS

Si -tblgen tiene éxito, saldrá con 0. De lo contrario, si ocurre un error, saldrá con un valor distinto de cero.
