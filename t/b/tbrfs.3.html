CTBRFS

Propósito:

!>
!> CTBRFS proporciona límites de error y estimaciones de error hacia atrás
!> para la solución de un sistema de ecuaciones lineales con una matriz
!> de coeficiente triangular de banda.
!>
!> La matriz solución X debe ser calculada por CTBTRS o algún otro
!> medio antes de entrar en esta rutina. CTBRFS no realiza refinamiento
!> iterativo porque hacerlo no puede mejorar el error hacia atrás.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N':  A * X = B     (Sin transpuesta)
!>          = 'T':  A**T * X = B  (Transpuesta)
!>          = 'C':  A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

KD

!>          KD es ENTERO
!>          El número de superdiagonales o subdiagonales de la
!>          matriz de banda triangular A.  KD >= 0.
!>

NRHS

!>          NRHS es ENTERO
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X.  NRHS >= 0.
!>

AB

!>          AB es array COMPLEJO, dimensión (LDAB,N)
!>          La matriz de banda triangular superior o inferior A, almacenada en las
!>          primeras kd+1 filas del array. La j-ésima columna de A se almacena
!>          en la j-ésima columna del array AB de la siguiente manera:
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) para max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) para j<=i<=min(n,j+kd).
!>          Si DIAG = 'U', los elementos diagonales de A no se referencian
!>          y se asumen como 1.
!>

LDAB

!>          LDAB es ENTERO
!>          La dimensión líder del array AB.  LDAB >= KD+1.
!>

B

!>          B es array COMPLEJO, dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es ENTERO
!>          La dimensión líder del array B.  LDB >= max(1,N).
!>

X

!>          X es array COMPLEJO, dimensión (LDX,NRHS)
!>          La matriz solución X.
!>

LDX

!>          LDX es ENTERO
!>          La dimensión líder del array X.  LDX >= max(1,N).
!>

FERR

!>          FERR es array REAL, dimensión (NRHS)
!>          La estimación del error hacia adelante para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más grande
!>          en (X(j) - XTRUE) dividido por la magnitud del elemento más grande
!>          en X(j). La estimación es tan confiable como la estimación
!>          de RCOND, y casi siempre es una ligera
!>          sobreestimación del error verdadero.
!>

BERR

!>          BERR es array REAL, dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es array COMPLEJO, dimensión (2*N)
!>

RWORK

!>          RWORK es array REAL, dimensión (N)
!>

INFO

!>          INFO es ENTERO
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME

ZTBRFS - ZTBRFS computes the error bounds for the solution of a triangular band system of linear equations.

SYNOPSIS

    SUBROUTINE ZTBRFS( UPLO, DIAG, N, KD, NRHS, AB, LDAB, B, LDB, X, LDX,
                       FERR, BERR, WORK, RWORK, INFO )
        IMPLICIT NONE
        CHARACTER          *1        :: DIAG
        CHARACTER          *1        :: UPLO
        INTEGER                      :: KD, INFO, LDB, LDAB, LDX, N, NRHS
        DOUBLE PRECISION             :: BERR(*), RWORK(*), FERR(*)
        COMPLEX*16                  :: AB( LDAB, * ), B( LDB, * ), WORK( * ), X( LDX, * )

Detailed Description

ZTBRFS computes the error bounds for the solution of a triangular band system of linear equations.

Arguments:

  • UPLO

     UPLO is CHARACTER*1
          = 'U': A is an upper triangular band matrix.
          = 'L': A is a lower triangular band matrix.

  • DIAG

     DIAG is CHARACTER*1
          = 'N': The diagonal elements of A are not specified and are assumed
                 to be 1.
          = 'U': The diagonal elements of A are not specified and are assumed
                 to be 1.

  • N

     N is INTEGER
          The order of the matrix A.  N >= 0.

  • KD

     KD is INTEGER
          The number of superdiagonals or subdiagonals of the
          triangular band matrix A.  KD >= 0.

  • NRHS

     NRHS is INTEGER
          The number of right hand sides, i.e., the number of columns
          of the matrices B and X.  NRHS >= 0.

  • AB

     AB is COMPLEX*16 array, dimension (LDAB,N)
          The upper or lower triangular band matrix A, stored in the
          first kd+1 rows of the array. The j-th column of A is stored
          in the j-th column of the array AB as follows:
          if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;
          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(n,j+kd).
          If DIAG = 'U', the diagonal elements of A are not referenced
          and are assumed to be 1.

  • LDAB

     LDAB is INTEGER
          The leading dimension of the array AB.  LDAB >= KD+1.

  • B

     B is COMPLEX*16 array, dimension (LDB,NRHS)
          The right hand side matrix B.

  • LDB

     LDB is INTEGER
          The leading dimension of the array B.  LDB >= max(1,N).

  • X

     X is COMPLEX*16 array, dimension (LDX,NRHS)
          The solution matrix X.

  • LDX

     LDX is INTEGER
          The leading dimension of the array X.  LDX >= max(1,N).

  • FERR

     FERR is DOUBLE PRECISION array, dimension (NRHS)
          The estimated forward error bound for each solution vector
          X(j) (the j-th column of the solution matrix X).
          If XTRUE is the true solution corresponding to X(j), FERR(j)
          is an estimated upper bound for the magnitude of the largest
          element in (X(j) - XTRUE) divided by the magnitude of the
          largest element in X(j).  The estimate is as reliable as
          the estimate for RCOND, and is almost always a slight
          overestimate of the true error.

  • BERR

     BERR is DOUBLE PRECISION array, dimension (NRHS)
          The componentwise relative backward error of each solution
          vector X(j) (i.e., the smallest relative change in
          any element of A or B that makes X(j) an exact solution).

  • WORK

     WORK is COMPLEX*16 array, dimension (2*N)

  • RWORK

     RWORK is DOUBLE PRECISION array, dimension (N)

  • INFO

     INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
