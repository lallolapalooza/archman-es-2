CTBSV

Propósito:

!>
!> CTBSV  resuelve uno de los sistemas de ecuaciones
!>
!>    A*x = b,   o   A**T*x = b,   o   A**H*x = b,
!>
!> donde b y x son vectores de n elementos y A es una matriz de banda
!> triangular superior o inferior unitaria o no unitaria de n por n, con ( k + 1 )
!> diagonales.
!>
!> Esta rutina no incluye pruebas de singularidad o casi singularidad.
!> Dichas pruebas deben realizarse antes de llamar a esta rutina.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>           Al entrar, UPLO especifica si la matriz es triangular superior o
!>           inferior de la siguiente manera:
!>
!>              UPLO = 'U' o 'u'   A es una matriz triangular superior.
!>
!>              UPLO = 'L' o 'l'   A es una matriz triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>           Al entrar, TRANS especifica las ecuaciones a resolver de la
!>           siguiente manera:
!>
!>              TRANS = 'N' o 'n'   A*x = b.
!>
!>              TRANS = 'T' o 't'   A**T*x = b.
!>
!>              TRANS = 'C' o 'c'   A**H*x = b.
!>

DIAG

!>          DIAG es CHARACTER*1
!>           Al entrar, DIAG especifica si A es unitaria o no
!>           triangular de la siguiente manera:
!>
!>              DIAG = 'U' o 'u'   Se asume que A es triangular unitaria.
!>
!>              DIAG = 'N' o 'n'   No se asume que A es unitaria.
!>                                  triangular.
!>

N

!>          N es INTEGER
!>           Al entrar, N especifica el orden de la matriz A.
!>           N debe ser al menos cero.
!>

K

!>          K es INTEGER
!>           Al entrar con UPLO = 'U' o 'u', K especifica el número de
!>           superdiagonales de la matriz A.
!>           Al entrar con UPLO = 'L' o 'l', K especifica el número de
!>           subdiagonales de la matriz A.
!>           K debe satisfacer  0 .le. K.
!>

A

!>          A es un array COMPLEX, dimensión ( LDA, N )
!>           Antes de entrar con UPLO = 'U' o 'u', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte triangular superior
!>           de banda de la matriz de coeficientes, suministrada columna por
!>           columna, con la diagonal principal de la matriz en la fila
!>           ( k + 1 ) del array, la primera superdiagonal comenzando en la
!>           posición 2 en la fila k, y así sucesivamente. El triángulo superior
!>           izquierdo de k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá una matriz de banda
!>           triangular superior desde almacenamiento de matriz completa convencional
!>           a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Antes de entrar con UPLO = 'L' o 'l', la parte principal ( k + 1 )
!>           por n del array A debe contener la parte triangular inferior
!>           de banda de la matriz de coeficientes, suministrada columna por
!>           columna, con la diagonal principal de la matriz en la fila 1 del
!>           array, la primera subdiagonal comenzando en la posición 1 en
!>           la fila 2, y así sucesivamente. El triángulo inferior derecho
!>           de k por k del array A no se referencia.
!>           El siguiente segmento de programa transferirá una matriz de banda
!>           triangular inferior desde almacenamiento de matriz completa convencional
!>           a almacenamiento de banda:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           Tenga en cuenta que cuando DIAG = 'U' o 'u', los elementos del array A
!>           correspondientes a los elementos diagonales de la matriz no se
!>           referencian, pero se asumen unitarios.
!>

LDA

!>          LDA es INTEGER
!>           Al entrar, LDA especifica la primera dimensión de A tal como se declara
!>           en el programa (sub)llamador. LDA debe ser al menos
!>           ( k + 1 ).
!>

X

!>          X es un array COMPLEX, dimensión al menos
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Antes de entrar, el array X incrementado debe contener el vector
!>           de mano derecha b de n elementos. Al salir, X se sobrescribe
!>           con el vector solución x.
!>

INCX

!>          INCX es INTEGER
!>           Al entrar, INCX especifica el incremento para los elementos de
!>           X. INCX no debe ser cero.
!>

tbsv(3) - LAPACK

NAME

tbsv - solve a triangular band system of linear equations

SYNOPSIS

call ztbsv(UPLO, TRANS, DIAG, N, K, A, LDA, X, INCX)
call dtbsv(UPLO, TRANS, DIAG, N, K, A, LDA, X, INCX)
call ctbsv(UPLO, TRANS, DIAG, N, K, A, LDA, X, INCX)
call stbsv(UPLO, TRANS, DIAG, N, K, A, LDA, X, INCX)

Detailed Description

This routine is part of the LAPACK routines for solving triangular systems of linear equations. It is a band-matrix version of the general routine TRSV.

The structure of the matrix A is described below:

Function Documentation

UPLO

UPLO is CHARACTER*1
On entry, UPLO specifies whether the matrix A is upper or lower
triangular as follows:

UPLO = 'U' or 'u'   A is an upper triangular matrix.

UPLO = 'L' or 'l'   A is a lower triangular matrix.

TRANS

TRANS is CHARACTER*1
On entry, TRANS specifies the equations to be solved as
follows:

TRANS = 'N' or 'n'   A*x = b.

TRANS = 'T' or 't'   A**T*x = b.

TRANS = 'C' or 'c'   A**H*x = b.

DIAG

DIAG is CHARACTER*1
On entry, DIAG specifies whether or not A is unit
triangular as follows:

DIAG = 'U' or 'u'   A is assumed to be unit triangular.

DIAG = 'N' or 'n'   A is not assumed to be unit
triangular.

N

N is INTEGER
On entry, N specifies the order of the matrix A.
N must be at least zero.

K

K is INTEGER
On entry with UPLO = 'U' or 'u', K specifies the number of
super-diagonals of the matrix A.
On entry with UPLO = 'L' or 'l', K specifies the number of
sub-diagonals of the matrix A.
K must satisfy  0 .le. K.

A

A is COMPLEX*16 array, dimension ( LDA, N )
Before entry with UPLO = 'U' or 'u', the leading ( k + 1 )
by n part of the array A must contain the upper triangular
band part of the matrix of coefficients, supplied column by
column, with the leading diagonal of the matrix in row
( k + 1 ) of the array, the first super-diagonal starting at
position 2 in row k, and so on. The top left k by k triangle
of the array A is not referenced.
The following program segment will transfer an upper
triangular band matrix from conventional full matrix storage
to band storage:

      DO 20, J = 1, N
         M = K + 1 - J
         DO 10, I = MAX( 1, J - K ), J
            A( M + I, J ) = matrix( I, J )
  10    CONTINUE
  20 CONTINUE

Before entry with UPLO = 'L' or 'l', the leading ( k + 1 )
by n part of the array A must contain the lower triangular
band part of the matrix of coefficients, supplied column by
column, with the leading diagonal of the matrix in row 1 of
the array, the first sub-diagonal starting at position 1 in
row 2, and so on. The bottom right k by k triangle of the
array A is not referenced.
The following program segment will transfer a lower
triangular band matrix from conventional full matrix storage
to band storage:

      DO 20, J = 1, N
         M = 1 - J
         DO 10, I = J, MIN( N, J + K )
            A( M + I, J ) = matrix( I, J )
  10    CONTINUE
  20 CONTINUE

Note that when DIAG = 'U' or 'u' the elements of the array A
corresponding to the diagonal elements of the matrix are not
referenced, but are assumed to be unity.

LDA

LDA is INTEGER
On entry, LDA specifies the first dimension of A as declared
in the calling (sub) program. LDA must be at least
( k + 1 ).

X

X is COMPLEX*16 array, dimension at least
( 1 + ( n - 1 )*abs( INCX ) ).
Before entry, the incremented array X must contain the n
element right-hand side vector b. On exit, X is overwritten
with the solution vector x.

INCX

INCX is INTEGER
On entry, INCX specifies the increment for the elements of
X. INCX must not be zero.
