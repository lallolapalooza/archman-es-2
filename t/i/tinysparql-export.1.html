TINYSPARQL-EXPORT(1) Manual de TinySPARQL TINYSPARQL-EXPORT(1)

NOMBRE

tinysparql-export - Exporta todos los datos de una base de datos TinySPARQL.

SINOPSIS

tinysparql export [opciones...] [IRI...]

DESCRIPCIÓN

tinysparql export exporta los datos almacenados en una base de datos TinySPARQL, en formato Turtle. Por defecto se exportan todos los datos, si se especifica algún IRI, solo se imprimirán esos recursos.

La salida está pensada para ser legible por máquinas, no por humanos. Utiliza una herramienta como rapper(1) para convertir los datos a diferentes formatos.

OPCIONES

-o, --output-format=<FORMATO_RDF>

Elige qué formato RDF utilizar para la salida de resultados. Los formatos soportados son turtle, trig y json-ld.

-g, --show-graphs

Obsoleto. Hace lo mismo que --output-format trig.

--2to3

Ayuda para migrar datos de bases de datos Tracker 2.x. Esta opción toma un argumento que especifica el alcance. Por ahora, solo está disponible el argumento “files-starred”.

--keyfile

Exporta los datos en formato de archivo de clave. Solo se puede usar con --2to3

EJEMPLOS

Exporta todos los datos del Índice de Tracker y formatea la salida con rapper(1).::

$ tinysparql export -b org.freedesktop.Tracker3.Miner.Files | rapper - -I . -i turtle -o turtle

VER TAMBIÉN

tinysparql-import(1), tinysparql-sparql(1).
