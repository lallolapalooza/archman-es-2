TIME(3P) Manual POSIX para Programadores TIME(3P)

PRÓLOGO

Esta página del manual forma parte del Manual POSIX para Programadores. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

time — obtener la hora

SINOPSIS

#include <time.h>
time_t time(time_t *tloc);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1-2017 remite al estándar ISO C.

La función time() devolverá el valor de la hora en segundos desde la Época.

El argumento tloc apunta a un área donde también se almacena el valor de retorno. Si tloc es un puntero nulo, no se almacena ningún valor.

VALOR DE RETORNO

Al completarse con éxito, time() devolverá el valor de la hora. En caso contrario, se devolverá (time_t)-1.

ERRORES

La función time() puede fallar si:

EOVERFLOW
El número de segundos desde la Época no cabe en un objeto de tipo time_t.

Las siguientes secciones son informativas.

EJEMPLOS

Obtener la hora actual

El siguiente ejemplo utiliza la función time() para calcular el tiempo transcurrido, en segundos, desde la Época, localtime() para convertir ese valor a una hora desglosada, y asctime() para convertir los valores de hora desglosada en una cadena imprimible.

#include <stdio.h>
#include <time.h>
int main(void)
{
time_t result;
    result = time(NULL);
    printf("%s%ju secs since the Epoch\n",
        asctime(localtime(&result)),
            (uintmax_t)result);
    return(0);
}

Este ejemplo escribe la hora actual en stdout con un formato como este:

Mié Jun 26 10:32:15 1996
835810335 secs since the Epoch

Cronometrar un evento

El siguiente ejemplo obtiene la hora actual, la imprime en el formato del usuario e imprime el número de minutos hasta un evento que se está cronometrando.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
minutes_to_event = ...;
printf("The time is ");
puts(asctime(localtime(&now)));
printf("There are %d minutes to the event.\n",
    minutes_to_event);
...

USO POR LA APLICACIÓN

Ninguno.

FUNDAMENTO

La función time() devuelve un valor en segundos, mientras que clock_gettime() y gettimeofday() devuelven una struct timespec (segundos y nanosegundos) y una struct timeval (segundos y microsegundos), respectivamente, y por lo tanto son capaces de devolver horas más precisas. La función times() también es capaz de una mayor precisión que time() ya que devuelve un valor en tics de reloj, aunque devuelve el tiempo transcurrido desde un punto arbitrario como el arranque del sistema, no desde la época.

Las implementaciones en las que time_t es un entero con signo de 32 bits (muchas implementaciones históricas) fallan en el año 2038. POSIX.1-2008 no aborda este problema. Sin embargo, el uso del tipo time_t es obligatorio para facilitar la corrección eventual.

En algunos sistemas, la función time() se implementa utilizando una llamada al sistema que no devuelve una condición de error además del valor de retorno. En estos sistemas es imposible diferenciar entre valores de retorno válidos e inválidos y, por lo tanto, las condiciones de desbordamiento no se pueden detectar de forma fiable.

El uso de la cabecera <time.h> en lugar de <sys/types.h> permite la compatibilidad con el estándar ISO C.

Muchas implementaciones históricas (incluida la Versión 7) y el estándar /usr/group de 1984 usan long en lugar de time_t. Este volumen de POSIX.1-2017 utiliza el último tipo para coincidir con el estándar ISO C.

DIRECCIONES FUTURAS

En una versión futura de este volumen de POSIX.1-2017, es probable que se requiera que time_t sea capaz de representar tiempos muy en el futuro. Aún no se ha determinado si esto se exigirá como un tipo de 64 bits o un requisito para que una fecha específica en el futuro sea representable (por ejemplo, el año 10000 d.C.). Los sistemas comprados después de la aprobación de este volumen de POSIX.1-2017 deben evaluarse para determinar si su vida útil se extenderá más allá de 2038.

time(3p) - Arch Linux

NOMBRE

time - obtener el tiempo de reloj

SINOPSIS

#include <time.h>

time_t time(time_t *tloc);

DESCRIPCIÓN

La función time() devolverá el valor del tiempo actual. El valor devuelto es el número de segundos transcurridos desde la Época (véase clock(3)). Si tloc no es un puntero nulo, el valor devuelto también se almacenará en la ubicación de memoria a la que apunta tloc.

Si la hora del sistema no está disponible, time() devolverá (time_t)-1 y el valor de errno se establecerá apropiadamente.

VALOR DE RETORNO

La función time() devuelve el número de segundos transcurridos desde la Época. En caso de error, devuelve (time_t)-1 y establece errno para indicar el error.

ERRORES

EAGAIN
No se pudo obtener la hora del sistema.

EJEMPLOS

```c #include <stdio.h> #include <time.h> int main() { time_t current_time; time(¤t_time); printf("El tiempo actual es: %ld segundos desde la Época.\n", current_time); return 0; } ```

USO EN APLICACIONES

Esta función es fundamental para registrar eventos, medir la duración de operaciones, programar tareas o simplemente mostrar la hora actual al usuario.

FUNDAMENTO

La función time() proporciona un medio simple y portátil para obtener la hora actual del sistema en segundos desde la Época Unix. Es una piedra angular para la mayoría de las operaciones relacionadas con el tiempo en C.

DIRECCIONES FUTURAS

No se esperan cambios significativos en esta función estándar de POSIX.
