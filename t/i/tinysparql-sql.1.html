TINYSPARQL-SQL(1) Manual de TinySPARQL TINYSPARQL-SQL(1)

NOMBRE

tinysparql sql - Usa SQL para consultar las bases de datos de TinySPARQL.

SINOPSIS

tinysparql sql -q <sql> | -f <archivo>

DESCRIPCIÓN

Este comando permite sondear la base de datos actual. Al usar comandos como tinysparql sparql, el SPARQL utilizado se traduce a SQL antes de ejecutarse en la base de datos. Esto permite el uso directo de la base de datos usando SQL, evitando completamente el motor SPARQL.

El llamador puede ejecutar una consulta de dos maneras, ya sea proporcionando un archivo con la consulta o proporcionando una cadena con la consulta sql.

El argumento archivo puede ser una ruta local o una URI. Tampoco tiene que ser una ruta absoluta.

OPCIONES

-f, --file=<archivo>

Usa un archivo con contenido SPARQL para consultar. No olvides terminar todas las consultas con un punto y coma (;) y también usar comillas alrededor de los nombres de las tablas. Las comillas son importantes porque la mayoría de las tablas se nombran según clases de ontología como "nfo:Document" y las consultas fallarán sin las comillas.

-q, --query=<sql>

Usa una cadena sql para consultar la base de datos.

EJEMPLOS

Mostrar las primeras 10 entradas "nfo:Document" donde el TOC no es NULL

$ tinysparql sql -q 'SELECT * FROM "nfo:Document" WHERE "nfo:tableOfContents" NOT NULL LIMIT 10;'
