TINYSPARQL-QUERY(1) Manual de TinySPARQL TINYSPARQL-QUERY(1)

NOMBRE

tinysparql query - Consultar puntos finales SPARQL.

SINOPSIS

tinysparql query [(-d |--database) <archivo> | (-b | --dbus-service) <nombre_bus> | (-r | --remote-service) <url>]
    (-f | --file) <archivo>] [(-u | --update)] [-a <parámetro>:<valor>]... [SPARQL]

DESCRIPCIÓN

Este comando permite ejecutar consultas o actualizaciones en un punto final SPARQL.

Cuando el llamador ejecuta una consulta, la consulta está en el lenguaje SPARQL. Esto se puede hacer de dos maneras: proporcionando un *archivo* con la consulta o proporcionando una cadena con la consulta *sparql*.

El argumento *archivo* puede ser una ruta local o una URI. Tampoco tiene que ser una ruta absoluta.

OPCIONES

-b, --dbus-service=<nombre_del_servicio>

Se conecta a un punto final SPARQL en un nombre D-Bus.

-d, --database-path=<ruta_base_de_datos>

Se conecta a una base de datos por su ubicación en el sistema de archivos.

-r, --remote-service=<url>

Se conecta a un punto final SPARQL HTTP.

-f, --file=<archivo>

Utiliza un *archivo* con contenido SPARQL para consultar o actualizar.

-u, --update

Esto debe usarse con --query. Le dice a "tinysparql query" que use las extensiones de actualización SPARQL, para que sepa que no es una solicitud de búsqueda de datos normal. Por lo tanto, si su consulta está destinada a modificar datos en la base de datos, esta opción es necesaria.

-a, --arg=<parámetro>:<valor>

Proporciona un argumento para un parámetro declarado en la cadena de consulta SPARQL. Esto puede usarse con --file, --query o --update. Se pueden proporcionar múltiples argumentos para múltiples parámetros. Los valores de los argumentos se proporcionan como una cadena separada por dos puntos que contiene 3 valores: nombre, tipo y valor. El nombre es el mismo que se usa en la cadena de consulta, el valor es el deseado y el tipo es una cadena de un solo carácter que define el tipo:
•i: El valor describirá un entero
•d: El valor describirá un número de punto flotante
•b: El valor describirá un booleano
•s: El valor describirá una cadena simple

EJEMPLOS

Consultar un punto final D-Bus

$ tinysparql query --dbus-service org.example.Endpoint "SELECT ('Hola Mundo' AS ?str) {}"

Actualizar una base de datos directamente desde una consulta en un archivo

$ tinysparql query --database /tmp/db/ --update --file ./update.rq

Usar --arg para proporcionar argumentos a los parámetros de consulta

$ tinysparql query -b org.example.Endpoint \
    -a name:s:"Juan" -a age:i:42 -a available:b:true \
    "SELECT (~name AS ?name) (~age AS ?age) (~available AS ?avail) { }"
