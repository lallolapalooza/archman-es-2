TIMEW-CHART(1) Manuales de usuario TIMEW-CHART(1)

NOMBRE

timew-chart - muestra el informe de gráfico

SINOPSIS

timew day [<rango>] [<etiqueta>...]
timew month [<rango>] [<etiqueta>...]
timew week [<rango>] [<etiqueta>...]

DESCRIPCIÓN

Un gráfico resume el tiempo registrado y no registrado con bloques de colores dibujados en una línea de tiempo. Acepta rangos de fechas y etiquetas para filtrar. Hay tres tipos: day, week y month con sus comandos respectivos. La configuración de la opción reports.<tipo>.range anula el rango de fechas predeterminado. Se puede anular el rango de fechas predeterminado global con la configuración reports.range. Para más detalles y horas precisas, utilice el informe 'summary'.

month

El comando month muestra un gráfico que representa un mes (el mes actual por defecto). El rango de fechas predeterminado que se muestra es :month.

week

El comando week muestra un gráfico que representa una semana (la semana actual por defecto). El rango de fechas predeterminado que se muestra es :week.

day

El comando day muestra un gráfico que representa un día (hoy por defecto). El rango de fechas predeterminado que se muestra es :day.

SUGERENCIAS

Aparte de las sugerencias de rango (ver timew-hints(7)), los informes de gráfico se adhieren a las siguientes sugerencias:

:blank

La sugerencia ':blank' hace que solo se muestre el tiempo excluido, sin tiempo registrado. Esto se puede utilizar para mostrar las exclusiones.

:ids

La sugerencia ':ids' hace que los intervalos se muestren con sus IDs

CONFIGURACIÓN

<tipo> es uno de month, week, day.

reports.<tipo>.cell

Determina cuántos minutos representa una sola celda de carácter en los gráficos. El valor debe ser mayor que '0'. Un valor de '15' significa que una hora se representa con 60/15, o 4 celdas de carácter. Los valores adecuados son los divisores de 60 (30, 20, 15, 12, ...). El valor predeterminado es '15'.

reports.<tipo>.day

Determina si se muestra el día actual del mes en el margen izquierdo. El valor predeterminado es 'yes'.

reports.<tipo>.holidays

Determina si se muestran las festividades relevantes debajo del informe. El valor predeterminado es 'yes'.

reports.<tipo>.hours

Determina si el informe <tipo> muestra todas las horas del día ('all') o se limita solo a las horas en las que se registra tiempo ('auto'). El valor predeterminado es 'all'.

reports.<tipo>.lines

Determina cuántas líneas se utilizan para renderizar cada día en el informe <tipo>. El valor predeterminado es '1'.

reports.<tipo>.month

Determina si se muestra el mes actual en el margen izquierdo. El valor predeterminado es 'yes'.

reports.<tipo>.range

Para los informes que muestran un rango de datos, esta configuración anulará el valor predeterminado. El valor debe ser una sugerencia de rango (sin el prefijo de dos puntos), consulte timew-hints(7).

reports.<tipo>.spacing

Especifica cuántos espacios se insertan entre las horas en las exclusiones del informe <tipo>. Un valor de '0' produce un informe más compacto. El valor predeterminado es '1'.

reports.<tipo>.axis

El valor 'internal' coloca los marcadores de hora (línea de tiempo en la parte superior) dentro de los bloques de exclusión, 'external' coloca los marcadores de hora en una línea separada; es posible que se definan valores adicionales en el futuro. El valor predeterminado es 'internal' para el informe day y 'external' para otros informes.

reports.<tipo>.summary

Determina si se muestra el resumen de horas. El valor predeterminado es 'on'.

reports.<tipo>.totals

Determina si se muestran los totales de tiempo para cada día en el informe. El valor predeterminado es 'on'.

reports.<tipo>.week

Determina si se muestra el número de semana actual en el margen izquierdo. El valor predeterminado es 'yes'.

reports.<tipo>.weekday

Determina si se muestra el día de la semana actual en el margen izquierdo. El valor predeterminado es 'yes'.

tags.<etiqueta>.color

Asigna un color de primer plano y fondo específico a una etiqueta, en lugar de la paleta de colores predeterminada determinada por su tema actual. Ejemplos de colores válidos incluyen 'white', 'gray8', 'black on yellow' y 'rgb345'.

EJEMPLOS

Los gráficos aceptan rangos de fechas y/o etiquetas, o IDs para filtrar:

$ timew month 1st - today
$ timew week FOO BAR
$ timew day @3 @4

Consulte timew-ranges(7) y timew-hints(7) sobre las diferentes formas de proporcionar rangos de fechas.
