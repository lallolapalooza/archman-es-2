NOMBRE

timew-hints - Pistas de Timewarrior

SINOPSIS

DESCRIPCIÓN

Timewarrior soporta pistas (hints), que son características de línea de comandos de una sola palabra que comienzan con dos puntos, como esta:

:semana

Las pistas cumplen varios propósitos. Este ejemplo es un atajo para el rango de fechas que define la semana actual.

Otras pistas, como:

:silencioso

son formas de controlar el comportamiento de Timewarrior, en este caso eliminando todas las formas de retroalimentación, para fines de automatización.

Las pistas admitidas son:

:silencioso     Desactiva toda la retroalimentación. Para automatización
:debug          Ejecuta en modo de depuración, muestra muchos detalles de tiempo de ejecución
:si             Anula la confirmación respondiendo 'sí' a las preguntas
:color          Fuerza el color, incluso si no está conectado a una TTY
:nocolor        Fuerza el color desactivado, incluso si está conectado a una TTY
:blank          Deja el tiempo registrado fuera de un informe
:fill           Expande el tiempo para llenar el hueco disponible circundante
:adjust         Corrige automáticamente los solapamientos
:ids            Muestra los números de identificación de intervalos en el informe resumen

Las pistas de rango proporcionan atajos convenientes a rangos de fechas:

:todo           Todo el tiempo registrado
:ayer           Las 24 horas del día anterior
:dia / :hoy     Las 24 horas del día actual
:semana         Esta semana
:quincena       Esta semana y la anterior
:mes            Este mes
:trimestre      Este trimestre
:año            Este año
:semanapasada    La semana pasada
:mespasado      El mes pasado
:trimestepasado El trimestre pasado
:anopasado      El año pasado
:lunes          Lunes anterior
:martes         Martes anterior
:miercoles      Miércoles anterior
:jueves         Jueves anterior
:viernes        Viernes anterior
:sabado         Sábado anterior
:domingo        Domingo anterior
