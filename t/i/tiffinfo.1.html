NOMBRE

tiffinfo - imprime información sobre archivos TIFF

SINOPSIS

tiffinfo [ opciones ] archivo.tif …

DESCRIPCIÓN

tiffinfo muestra información sobre archivos creados de acuerdo con el Tag Image File Format, Revisión 6.0. Por defecto, se muestran los contenidos de cada directorio TIFF en cada archivo, con el valor de cada etiqueta mostrado simbólicamente (donde sea apropiado).

OPCIONES

-c
Muestra el mapa de colores y las curvas de respuesta de color/gris, si están presentes.
-D
Además de mostrar las etiquetas del directorio, lee y descomprime todos los datos de cada imagen (pero no los muestra).
-d
Además de mostrar las etiquetas del directorio, imprime cada byte de datos descomprimidos en hexadecimal.
-j
Muestra las etiquetas relacionadas con JPEG que estén presentes.
-o
Establece el directorio TIFF inicial según el desplazamiento de archivo especificado. El desplazamiento de archivo puede especificarse usando la sintaxis habitual de C; es decir, un prefijo 0x para hexadecimal y un prefijo 0 para octal.
-s
Muestra los desplazamientos y recuentos de bytes para cada tira de datos en un directorio.
-z
Habilita el troceado de tiras al leer datos de imagen.
-#
Establece el directorio TIFF inicial en #.

VER TAMBIÉN

tiffdump, libtiff
