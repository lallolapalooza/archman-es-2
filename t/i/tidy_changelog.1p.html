TIDY_CHANGELOG(1) Documentación de Contribución de Perl de Usuario TIDY_CHANGELOG(1)

NOMBRE

tidy_changelog - herramienta de línea de comandos para CPAN::Changes

SINOPSIS

$ tidy_changelog Changelog

DESCRIPCIÓN

Toma un archivo de registro de cambios, lo analiza usando CPAN::Changes y imprime la salida resultante. Si no se proporciona un archivo, el programa verificará si hay un archivo en el directorio actual que comience con 'change' (sin distinción entre mayúsculas y minúsculas) y, si es así, asumirá que es el registro de cambios.

ARGUMENTOS

--next

Si se proporciona, asume que hay un encabezado marcador de posición para la próxima versión pendiente. El token marcador de posición se proporciona a través de --token.

--token

Expresión regular a utilizar para detectar el token de una próxima versión si se usa --next. Si no se especifica explícitamente, el valor predeterminado es "\{\{\$NEXT\}\}".

--headers

Si se proporciona, solo imprime las líneas de encabezado de la versión, sin ninguno de los cambios.

--reverse

Imprime las versiones en orden inverso (de la más antigua a la más reciente).

--check

Solo verifica si el registro de cambios está formateado correctamente utilizando la función changes_file_ok de Test::CPAN::Changes.

--help
