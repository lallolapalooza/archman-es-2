NOMBRE

timew-move - cambiar la hora de inicio de un intervalo

SINOPSIS

timew move <id> <fecha>

DESCRIPCIÓN

El comando 'move' se utiliza para reposicionar un intervalo a una nueva hora de inicio. Usando el comando 'summary' y especificando la pista ':ids' se muestran los IDs de los intervalos. Usando el ID correcto, puedes identificar un intervalo para moverlo.

EJEMPLOS

Por ejemplo, muestra los IDs:

$ timew summary :week :ids

Luego, habiendo seleccionado '@2' como el intervalo que deseas mover:

$ timew move @2 9am
