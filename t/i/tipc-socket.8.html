NOMBRE

tipc-socket - mostrar información de sockets (puertos) TIPC

SINOPSIS


tipc socket list

OPCIONES

Opciones (flags) que se pueden pasar en cualquier lugar de la cadena de comandos.

-h, --help
Mostrar ayuda sobre el último comando válido. Por ejemplo, tipc socket --help mostrará la ayuda de sockets y tipc --help mostrará la ayuda general. La posición de la opción en la cadena es irrelevante.

DESCRIPCIÓN

Un socket TIPC se representa mediante un entero sin signo.

Estado Enlazado

Un socket enlazado tiene un nombre de puerto TIPC lógico asociado.

Estado Conectado

Un socket conectado está directamente conectado a otro socket, creando una conexión punto a punto entre sockets TIPC. Si la conexión a X se realizó utilizando un nombre de puerto lógico Y, ese nombre aparecerá como conectado a X vía Y

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.

VER TAMBIÉN

tipc(8), tipc-bearer(8) tipc-link(8), tipc-media(8), tipc-nametable(8), tipc-node(8),

REPORTAR ERRORES

Reporte cualquier error a la lista de correo de desarrolladores de red <netdev@vger.kernel.org> donde se realiza principalmente el desarrollo y mantenimiento. No necesita estar suscrito a la lista para enviar un mensaje allí.
