NOMBRE

tincd — demonio VPN de tinc

SINOPSIS

tincd [-cdDkKnoLRU] [--config=DIR] [--no-detach] [--debug[=NIVEL]] [--kill[=SEÑAL]] [--net=NOMBRE RED] [--generate-keys[=BITS]] [--option=[HOST.]CLAVE=VALOR] [--mlock] [--logfile[=ARCHIVO]] [--pidfile=ARCHIVO] [--bypass-security] [--chroot] [--user=USUARIO] [--help] [--version]

DESCRIPCIÓN

Este es el demonio de tinc, un proyecto de red privada virtual (VPN) segura. Al iniciarse, tincd leerá su archivo de configuración para determinar a qué subredes virtuales debe servir y con qué otros demonios de tinc debe conectarse. Se conectará al dispositivo ethertap o tun/tap y configurará un socket para conexiones entrantes. Opcionalmente, se ejecutará un script para configurar aún más el dispositivo virtual. Si esto tiene éxito, se separará de la terminal de control y continuará en segundo plano, aceptando y estableciendo conexiones con otros demonios de tinc que forman parte de la red privada virtual. En Windows (no Cygwin), tinc se instalará como un servicio, que se reiniciará automáticamente después de los reinicios.

OPCIONES

-c, --config=DIR
Lee los archivos de configuración del directorio DIR en lugar de /etc/tinc/.
-D, --no-detach
No dividir ni separar. Esto también deshabilitará el mecanismo de reinicio automático para errores fatales. Si no se indica lo contrario, esto mostrará mensajes de registro en la salida de error estándar.
-d, --debug[=NIVEL]
Aumenta el nivel de depuración o lo establece en NIVEL (ver abajo).
-k, --kill[=SEÑAL]
Intenta detener un tincd en ejecución (opcionalmente con la SEÑAL especificada en lugar de SIGTERM) y sale. En Windows (no Cygwin), el argumento opcional se ignora, el servicio siempre se detendrá y eliminará.
-n, --net=NOMBRE RED
Conéctate a la red NOMBRE RED. Esto hará que tinc lea todos los archivos de configuración de /etc/tinc/ NOMBRE RED. Especificar . para NOMBRE RED es lo mismo que no especificar ningún NOMBRE RED.
-K, --generate-keys[=BITS]
Genera un par de claves RSA pública/privada y sale. Si se omite BITS, la longitud predeterminada será de 2048 bits. Al guardar claves en archivos existentes, tinc no eliminará las claves antiguas, deberás eliminarlas manualmente.
-o, --option=[HOST.]CLAVE=VALOR
Sin especificar un HOST, esto establecerá la variable de configuración del servidor CLAVE a VALOR. Si se especifica como HOST.CLAVE=VALOR, esto establecerá la variable de configuración del host CLAVE del host llamado HOST a VALOR. Esta opción se puede usar varias veces para especificar múltiples variables de configuración.
-L, --mlock
Bloquea tinc en la memoria principal. Esto evitará que datos sensibles como claves privadas compartidas se escriban en los archivos/particiones de intercambio del sistema.
--logfile[=ARCHIVO]
Escribe las entradas de registro en un archivo en lugar de en el sistema de registro del sistema. Si se omite ARCHIVO, el predeterminado es /var/log/tinc.NOMBRE RED.log.
--pidfile=ARCHIVO
Escribe el PID en ARCHIVO en lugar de /var/run/tinc.NOMBRE RED.pid. En Windows, esta opción se ignorará.
--bypass-security
Deshabilita el cifrado y la autenticación del protocolo meta. Solo útil para depuración.
-R, --chroot
Con esta opción, tinc cambia de directorio al directorio donde se encuentra la configuración de red (/etc/tinc/NOMBRE RED si se usa la opción -n, o al directorio especificado con la opción -c) después de la inicialización.
-U, --user=USUARIO
Cambia de usuario (setuid) al USUARIO especificado después de la inicialización.
--help
Muestra una lista corta de opciones.
--version
Muestra información de la versión y sale.

SEÑALES

ALRM
Fuerza a tincd a intentar conectarse a todos los enlaces ascendentes inmediatamente. Normalmente tincd intenta hacer esto por sí mismo, pero aumenta el tiempo que espera entre intentos cada vez que falla, y si tincd no logra conectarse a un enlace ascendente la primera vez después de iniciarse, recurre al tiempo máximo de 15 minutos.
HUP
Vuelve a leer parcialmente los archivos de configuración. Se cierran las conexiones a hosts cuyos archivos de configuración han sido eliminados. Se establecerán nuevas conexiones salientes especificadas en tinc.conf. Si se usa la opción --logfile, esto también cerrará y reabrirá el archivo de registro, útil cuando se utiliza la rotación de registros.
INT
Aumenta temporalmente el nivel de depuración a 5. Envía esta señal de nuevo para revertir al nivel original.
USR1
Volca la lista de conexiones a syslog.
USR2
Volca estadísticas del dispositivo de red virtual, todos los nodos, aristas y subredes conocidos a syslog.
WINCH
Purga toda la información recordada sobre nodos inalcanzables.

NIVELES DE DEPURACIÓN

El demonio de tinc puede enviar muchos mensajes a syslog. Cuanto mayor sea el nivel de depuración, más mensajes registrará. Cada nivel hereda todos los mensajes del nivel anterior:

0
Registrará un mensaje que indica que tincd se ha iniciado junto con un número de versión. También registrará cualquier error grave.
1
Registrará todas las conexiones que se realizan con otros demonios de tinc.
2
Registrará mensajes de estado y error de scripts y otros demonios de tinc.
3
Registrará todas las solicitudes que se intercambian con otros demonios de tinc. Estas incluyen autenticación, intercambio de claves y actualizaciones de la lista de conexiones.
4
Registrará una copia de todo lo recibido en el socket meta.
5
Registrará todo el tráfico de red a través de la red privada virtual.

NAME

tincd

daemon for a virtual private network

SYNOPSIS

tincd

    tincd [-d[debuglevel]] [-f] [-k] [-l logfile] [-p port] [-r runtimelevel] [-s] [-D] [NETNAME]

DESCRIPTION

tincd is a daemon that listens for incoming connections and initiates outgoing connections to create a virtual private network. It supports protocols such as TCP and UDP, and uses various encryption methods.

OPTIONS

-d [debuglevel]
Sets the debug level. If no level is specified, it defaults to 1. Higher levels produce more verbose output.
-f
Run tincd in the foreground. Useful for debugging.
-k
Send a signal to tincd. This option is used for reloading configuration or shutting down the daemon.
-l logfile
Specify a log file. If not specified, logs are written to syslog.
-p port
Specify the port to listen on. If not specified, the port from tinc.conf is used, or the default port if not specified there either.
-r runtimelevel
Sets the runtime level. Used for controlling the daemon's behavior at runtime.
-s
Don't automatically restart on crashes.
-D
Don't daemonize; run in the foreground. Equivalent to -f.
NETNAME
The name of the network to start. This name is used to find the correct configuration and host files.

SIGNALS

tincd responds to the following signals:

SIGHUP
Reloads the configuration files.
SIGINT, SIGTERM
Shuts down the daemon gracefully.
SIGUSR1
Toggles debug level.
SIGUSR2
Toggles runtime level.

DEBUG LEVELS

The debug level controls the verbosity of the log output. Higher numbers mean more output.

0
No debugging output.
1
Basic debugging information.
2
More detailed debugging information.
3
Extremely verbose debugging, including packet contents.

FILES

/etc/tinc/NETNAME/tinc.conf
The main configuration file for tinc. For more information, see tinc.conf(5).
/var/run/tinc.NETNAME.pid
The PID of the currently running tincd is stored in this file.

BUGS

The BindToInterface option may not work correctly.

The cryptography in tinc is not well tested yet. Use it at your own risk!

If you find any bugs, report them to tinc@tinc-vpn.org.
