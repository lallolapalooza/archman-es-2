timespec_get(3) Manual de funciones de biblioteca timespec_get(3)

NOMBRE

timespec_get, timespec_getres - Interfaz C ISO a funciones de reloj y hora

BIBLIOTECA

Biblioteca C estándar (libc, -lc),

SINOPSIS

#include <time.h>
int timespec_get(struct timespec *res, int base);
int timespec_getres(struct timespec *tp, int base);

DESCRIPCIÓN

La función timespec_get() almacena la hora actual, basándose en la base de tiempo especificada, en la estructura timespec(3type) apuntada por res.

La función timespec_getres() almacena la resolución de las horas recuperadas por timespec_get() con la base de tiempo especificada en la estructura timespec(3type) apuntada por tp, si tp no es NULL. Para una base de tiempo dada, la resolución es constante durante la vida del proceso que llama.

TIME_UTC es siempre una base de tiempo soportada y es la única base de tiempo soportada en Linux. La hora y la resolución en esta base de tiempo son las mismas que las recuperadas por clock_gettime(CLOCK_REALTIME, res) y clock_getres(CLOCK_REALTIME, tp), respectivamente. Otros sistemas pueden soportar bases de tiempo adicionales.

VALOR DE RETORNO

timespec_get() devuelve el base distinto de cero si es una base de tiempo soportada y la hora actual se recuperó con éxito, o 0 en caso contrario.

timespec_getres() devuelve el base distinto de cero si es una base de tiempo soportada, o 0 en caso contrario.
