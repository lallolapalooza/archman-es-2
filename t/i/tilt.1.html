TILT(1) Manual de Comandos Generales TILT(1)

NOMBRE

tilt - procesa plantillas

SINOPSIS

tilt -l
tilt [-t patrón] [-y archivo] [-D nombre=valor] [-d archivo] [--vars=ruby] archivo

DESCRIPCIÓN

Procesa el archivo archivo y escribe la salida en stdout. Si no hay archivo o si archivo es ´-´, lee la plantilla de stdin y usa la opción --type para determinar el tipo de la plantilla.

OPCIONES

-l, --list
Lista los motores de plantillas + patrones de archivo y sale
-t, --type=patrón
Usa este motor de plantillas; requerido si no hay archivo
-y, --layout=archivo
Usa archivo como plantilla de diseño
-Dnombre=valor
Define la variable nombre como valor
-d, --define-file=archivo
Carga YAML o JSON desde archivo y úsalo para variables
--vars=ruby
Evalúa ruby a Hash y úsalo para variables
-h, --help
Muestra este mensaje de ayuda

EJEMPLOS

Convierte markdown a HTML:

$ tilt foo.markdown > foo.html

Procesa plantilla ERB:

$ echo "Respuesta: <%= 2 + 2 %>" | tilt -t erb
Respuesta: 4

Define variables:

$ echo ´{"n":40}´ > data.json
$ echo "Respuesta: <%= 2 + n %>" | tilt -t erb -d data.json
Respuesta: 42
$ echo "Respuesta: <%= 2 + n %>" | tilt -t erb --vars="{:n=>40}"
Respuesta: 42
$ echo "Respuesta: <%= 2 + n.to_i %>" | tilt -t erb -Dn=40
Respuesta: 42
