NOMBRE

timew-modify - cambiar el rango de un intervalo

SINOPSIS

timew modify (start|end) <id> <fecha>
timew modify range <id> <rango>

DESCRIPCION

El comando 'modify' se utiliza para cambiar el rango de un intervalo.

Usando el subcomando 'start' o 'end', se puede especificar una nueva fecha de inicio o fin respectivamente, o con el subcomando 'range', cambiar el rango completo. El intervalo a modificar se especifica a través de su id.

Si el intervalo resultante se superpone con un intervalo existente, el comando devolverá un error. Se puede añadir la sugerencia ':adjust' para forzar una sobrescritura en este caso.

Consulte timew-summary(1) sobre cómo obtener el id del intervalo.

SUGERENCIAS

El comando 'modify' acepta las siguientes sugerencias:

:fill

La sugerencia ':fill' puede ser utilizada en lugar de una fecha o rango de fechas para rellenar el hueco entre el intervalo a modificar y sus intervalos adyacentes. Para los subcomandos 'start' y 'end', la sugerencia ':fill' rellenará el hueco entre el intervalo objetivo y el siguiente o anterior intervalo respectivamente. Para el subcomando 'range', rellenará huecos en ambos lados del intervalo modificado.

:adjust

La sugerencia ':adjust' se puede añadir para forzar la modificación del intervalo, si este se superpone con un intervalo existente. Esto sobrescribirá el intervalo existente.

EJEMPLOS

Modificar la fecha de inicio de un intervalo

$ timew modify start @3 2020-12-28T17:00

Esto establece el inicio del intervalo '@3' a las '17:00' del '2020-12-28'. Si esta fecha y hora es posterior al final del intervalo, el comando devolverá un error.

Modificar la fecha de fin de un intervalo

Si el intervalo a modificar tiene la misma fecha que hoy, se puede omitir:

$ timew modify end @3 18:00

Similar a cuando se modifica el inicio del intervalo, la fecha y hora de fin debe ser posterior a la fecha y hora de inicio.

Modificar el rango de un intervalo

En lugar de modificar el inicio y el fin por separado, estos pueden combinarse en una sola llamada al subcomando 'range':

$ timew modify range @3 2020-12-28T17:00 - 2020-12-28T18:00

Como en los ejemplos anteriores, la parte de la fecha puede omitirse, si la fecha del intervalo es hoy.

Modificar el rango de un intervalo y rellenar huecos

$ timew modify range @3 :fill

Esto modifica el intervalo '@3' y rellena automáticamente cualquier hueco entre este intervalo y sus intervalos adyacentes.
