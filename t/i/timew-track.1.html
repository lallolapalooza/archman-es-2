NOMBRE

timew-track - añade intervalos a la base de datos

SINOPSIS

timew track <rango> [<etiqueta>...]

DESCRIPCIÓN

El comando track se utiliza para añadir tiempo registrado en el pasado. Quizás olvidaste registrar tiempo, o simplemente estás rellenando entradas antiguas.

INDICACIONES

Además de las indicaciones de rango (ver timew-hints(7)), el comando track acepta las siguientes indicaciones:

:fill

La indicación ':fill' se puede utilizar para crear un nuevo intervalo que rellene el hueco entre dos intervalos adyacentes.

EJEMPLOS

Registrar un intervalo cerrado

Por ejemplo: 
$ timew track :yesterday 'Curso de Formación'
$ timew track 9am - 11am 'Reunión de Personal'

Ten en cuenta que el comando track espera un intervalo cerrado (hora de inicio y fin) al registrar. Si no se proporciona un intervalo cerrado, el comando 'track' se comporta igual que el comando 'start'.

Rellenar el hueco entre dos intervalos

Para rellenar el hueco entre dos intervalos, sin tener que especificar las horas exactas, se puede usar la indicación :fill. Cuando, por ejemplo, el primer intervalo termina poco antes de las 10:00 y el segundo intervalo comienza poco después de las 11:00, llamar a 
$ timew track 10:00 - 11:00 :fill 'Pausa para el café'

instruirá a Timewarrior para que expanda el intervalo de modo que comience justo después del primer intervalo y termine justo antes del segundo intervalo.
