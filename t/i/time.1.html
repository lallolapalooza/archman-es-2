time(1) Manual de Comandos Generales time(1)

NOMBRE

time - mide el tiempo de un comando simple o proporciona estadísticas de uso de recursos

SINOPSIS

time [opción ...] comando [argumento ...]

DESCRIPCIÓN

El comando time ejecuta el programa especificado comando con los argumentos dados. Cuando comando termina, time escribe un mensaje en el error estándar que proporciona estadísticas de tiempo de esta ejecución del programa. Estas estadísticas consisten en (i) el tiempo real transcurrido entre la invocación y la terminación, (ii) el tiempo de CPU de usuario (la suma de los valores tms_utime y tms_cutime en una struct tms devuelta por times(2)), y (iii) el tiempo de CPU del sistema (la suma de los valores tms_stime y tms_cstime en una struct tms devuelta por times(2)).

Nota: algunas shells (por ejemplo, bash(1)) tienen un comando time incorporado que proporciona información similar sobre el uso del tiempo y posiblemente otros recursos. Para acceder al comando real, puede que necesite especificar su ruta (algo como /usr/bin/time).

OPCIONES

-p
Cuando esté en la locale POSIX, use el formato tradicional preciso

"real %f\nuser %f\nsys %f\n"

(con números en segundos) donde el número de decimales en la salida de %f no está especificado pero es suficiente para expresar la precisión del reloj de tick, y al menos uno.

CÓDIGO DE SALIDA

Si se invocó comando, el código de salida es el de comando. De lo contrario, es 127 si comando no se pudo encontrar, 126 si se pudo encontrar pero no se pudo invocar, y algún otro valor distinto de cero (1-125) si ocurrió algo más.

ENTORNO

Las variables LANG, LC_ALL, LC_CTYPE, LC_MESSAGES, LC_NUMERIC y NLSPATH se utilizan para el texto y el formato de la salida. PATH se utiliza para buscar comando.

VERSIÓN GNU

A continuación se describe la versión 1.7 de time de GNU. Independientemente del nombre de la utilidad, GNU hace que genere mucha información útil, no solo sobre el tiempo utilizado, sino también sobre otros recursos como la memoria, E/S y llamadas IPC (donde estén disponibles). La salida se formatea utilizando una cadena de formato que se puede especificar mediante la opción -f o la variable de entorno TIME.

La cadena de formato predeterminada es:


%Uusuario %Ssistema %Etranscurrido %PCPU (%Xtexto+%Ddatos %Mmáx)k
%Ientradas+%Ssalidas (%Fmayor+%Rmenor)fallos de página %Wswaps

Cuando se proporciona la opción -p, se utiliza el formato de salida (portable):


real %e
user %U
sys %S

La cadena de formato

El formato se interpreta de la manera habitual similar a printf(3). Los caracteres ordinarios se copian directamente, las tabulaciones, los saltos de línea y las barras invertidas se escapan usando \t, \n y \\, un signo de porcentaje se representa como %%, y de lo contrario % indica una conversión. El programa time siempre añadirá un salto de línea final. Las conversiones siguen. Todas las que usa tcsh(1) son compatibles.

Tiempo

%E
Tiempo real transcurrido (en [horas:]minutos:segundos).
%e
(¡No en tcsh(1)!) Tiempo real transcurrido (en segundos).
%S
Número total de segundos de CPU que el proceso pasó en modo kernel.
%U
Número total de segundos de CPU que el proceso pasó en modo usuario.
%P
Porcentaje de la CPU que recibió este trabajo, calculado como (%U + %S) / %E.

Memoria

%M
Tamaño máximo del conjunto residente del proceso durante su vida útil, en Kbytes.
%t
(¡No en tcsh(1)!) Tamaño medio del conjunto residente del proceso, en Kbytes.
%K
Uso medio total (datos+pila+texto) de memoria del proceso, en Kbytes.
%D
Tamaño medio del área de datos no compartida del proceso, en Kbytes.
%p
(¡No en tcsh(1)!) Tamaño medio del espacio de pila no compartida del proceso, en Kbytes.
%X
Tamaño medio del espacio de texto compartido del proceso, en Kbytes.
%Z
(¡No en tcsh(1)!) Tamaño de página del sistema, en bytes. Esta es una constante por sistema, pero varía entre sistemas.
%F
Número de fallos de página importantes que ocurrieron mientras el proceso estaba en ejecución. Estos son fallos en los que la página debe leerse desde disco.
%R
Número de fallos de página menores o recuperables. Estos son fallos de páginas que no son válidas pero que aún no han sido reclamadas por otras páginas virtuales. Por lo tanto, los datos de la página siguen siendo válidos pero las tablas del sistema deben actualizarse.
%W
Número de veces que el proceso fue sacado de la memoria principal.
%c
Número de veces que el proceso fue cambiado de contexto involuntariamente (porque se agotó el tiempo de la porción).
%w
Número de esperas: veces que el programa fue cambiado de contexto voluntariamente, por ejemplo, mientras esperaba a que se completara una operación de E/S.

E/S

%I
Número de entradas del sistema de archivos por el proceso.
%O
Número de salidas del sistema de archivos por el proceso.
%r
Número de mensajes de socket recibidos por el proceso.
%s
Número de mensajes de socket enviados por el proceso.
%k
Número de señales entregadas al proceso.
%C
(¡No en tcsh(1)!) Nombre y argumentos de línea de comandos del comando que se está midiendo.
%x
(¡No en tcsh(1)!) Código de salida del comando.

Opciones GNU

-f formato, --format=formato
Especifica el formato de salida, posiblemente anulando el formato especificado en la variable de entorno TIME.
-p, --portability
Utiliza el formato de salida portable.
-o archivo, --output=archivo
No envía los resultados a stderr, sino que sobrescribe el archivo especificado.
-a, --append
(Usado junto con -o.) No sobrescribe sino que añade.
-v, --verbose
Proporciona una salida muy detallada sobre todo lo que el programa sabe.
-q, --quiet
No informa de la terminación anormal del programa (donde comando es terminado por una señal) o de un código de salida distinto de cero.

Opciones estándar GNU

--help
Imprime un mensaje de uso en la salida estándar y sale exitosamente.
-V, --version
Imprime la información de la versión en la salida estándar y sale exitosamente.
--
Termina la lista de opciones.

BUGS

No todos los recursos son medidos por todas las versiones de UNIX, por lo que algunos de los valores podrían ser reportados como cero. La selección actual se inspiró principalmente en los datos proporcionados por 4.2 o 4.3BSD.

La versión 1.7 de GNU time aún no está localizada. Por lo tanto, no implementa los requisitos de POSIX.

La variable de entorno TIME fue mal elegida. No es inusual que sistemas como autoconf(1) o make(1) usen variables de entorno con el nombre de una utilidad para anular la utilidad a ser utilizada. Usos como MORE o TIME para opciones de programas (en lugar de rutas de programas) tienden a llevar a dificultades.

Parece desafortunado que -o sobrescriba en lugar de añadir. (Es decir, la opción -a debería ser la predeterminada.)

Envíe sugerencias e informes de errores para GNU time a bug-time@gnu.org. Por favor, incluya la versión de time, que puede obtener ejecutando


time --version

y el sistema operativo y el compilador C que utilizó.

VER TAMBIÉN

bash(1), tcsh(1), times(2), wait3(2)
