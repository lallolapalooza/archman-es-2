NOMBRE

tiffdump - imprime información literal sobre archivos TIFF

SINOPSIS

tiffdump [ opciones ] nombre …

DESCRIPCIÓN

tiffdump muestra información del directorio de archivos creados según el formato de archivo de imagen etiquetado (TIFF), Revisión 6.0. Se mostrará la cabecera de cada archivo TIFF (número mágico, versión y desplazamiento del primer directorio), seguida del contenido de las etiquetas de cada directorio en el archivo. Para cada etiqueta, se mostrará el nombre, tipo de datos, recuento y valor(es). Cuando el nombre simbólico de una etiqueta o tipo de datos es conocido, se mostrará el nombre simbólico seguido de su valor numérico (decimal). Los valores de las etiquetas se mostrarán encerrados entre corchetes < y > precedidos inmediatamente por el valor del campo de recuento. Por ejemplo, una etiqueta ImageWidth podría mostrarse como ImageWidth (256) SHORT (3) 1<800>.

tiffdump es particularmente útil para investigar el contenido de archivos TIFF que libtiff no entiende.

OPCIONES

-h
Fuerza la impresión de datos numéricos en hexadecimal en lugar del decimal predeterminado.
-m items
Cambia el número de elementos de datos indirectos que se imprimen. Por defecto, este valor será 24.
-o offset
Muestra el contenido del IFD en un desplazamiento de archivo particular. El desplazamiento del archivo puede especificarse usando la sintaxis habitual estilo C; es decir, un prefijo 0x para hexadecimal y un prefijo 0 para octal.
