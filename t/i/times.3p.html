NOMBRE

times — obtener tiempos del proceso y del proceso hijo esperado

SINÓPSIS

#include <sys/times.h>
clock_t times(struct tms *buffer);

DESCRIPCIÓN

La función times() rellena la estructura tms apuntada por buffer con información de contabilidad de tiempo. La estructura tms se define en <sys/times.h>.

Todos los tiempos se miden en términos del número de tics de reloj utilizados.

Los tiempos de un proceso hijo terminado se incluirán en los elementos tms_cutime y tms_cstime del padre cuando wait(), waitid(), o waitpid() devuelvan el ID de proceso de este hijo terminado. Si un proceso hijo no ha esperado a sus hijos, sus tiempos no se incluirán en sus tiempos.

*
El miembro de la estructura tms_utime es el tiempo de CPU facturado por la ejecución de instrucciones de usuario del proceso que llama.
*
El miembro de la estructura tms_stime es el tiempo de CPU facturado por la ejecución por parte del sistema en nombre del proceso que llama.
*
El miembro de la estructura tms_cutime es la suma de los tiempos tms_utime y tms_cutime de los procesos hijos.
*
El miembro de la estructura tms_cstime es la suma de los tiempos tms_stime y tms_cstime de los procesos hijos.

VALOR DE RETORNO

Al completarse con éxito, times() devolverá el tiempo real transcurrido, en tics de reloj, desde un punto arbitrario en el pasado (por ejemplo, la hora de inicio del sistema). Este punto no cambia de una invocación de times() dentro del proceso a otra. El valor de retorno puede desbordar el rango posible del tipo clock_t. Si times() falla, se devolverá (clock_t)-1 y se establecerá errno para indicar el error.

ERRORES

La función times() fallará si:

EOVERFLOW
El valor de retorno desbordaría el rango de clock_t.

EJEMPLOS

Medición del Tiempo de una Búsqueda en Base de Datos

El siguiente ejemplo define dos funciones, start_clock() y end_clock(), que se utilizan para medir el tiempo de una búsqueda. También define variables de tipo clock_t y tms para medir la duración de las transacciones. La función start_clock() guarda los tiempos de inicio proporcionados por la función times(). La función end_clock() obtiene los tiempos de finalización e imprime la diferencia entre los dos tiempos.

#include <sys/times.h>
#include <stdio.h>
...
void start_clock(void);
void end_clock(char *msg);
...
static clock_t st_time;
static clock_t en_time;
static struct tms st_cpu;
static struct tms en_cpu;
...
void
start_clock()
{
    st_time = times(&st_cpu);
}
/* Este ejemplo asume que el resultado de cada resta
   está dentro del rango de valores que se pueden representar en
   un tipo entero. */
void
end_clock(char *msg)
{
    en_time = times(&en_cpu);
    fputs(msg,stdout);
    printf("Tiempo Real: %jd, Tiempo de Usuario %jd, Tiempo de Sistema %jd\n",
        (intmax_t)(en_time - st_time),
        (intmax_t)(en_cpu.tms_utime - st_cpu.tms_utime),
        (intmax_t)(en_cpu.tms_stime - st_cpu.tms_stime));
}

USO POR LA APLICACIÓN

Las aplicaciones deben usar sysconf(_SC_CLK_TCK) para determinar el número de tics de reloj por segundo, ya que puede variar de un sistema a otro.

FUNDAMENTO

La precisión de los tiempos reportados se deja intencionalmente sin especificar para permitir flexibilidad en el diseño de las implementaciones, desde uniprocesadores hasta redes multiprocesador.

La inclusión de los tiempos de los procesos hijos es recursiva, de modo que un proceso padre puede recopilar los tiempos totales de todos sus descendientes. Pero los tiempos de un hijo solo se agregan a los de su padre cuando su padre espera con éxito al hijo. Por lo tanto, no se garantiza que un proceso padre siempre pueda ver los tiempos totales de todos sus descendientes; véase también la discusión del término "tiempo real" en alarm().

Si el tipo clock_t se define como un entero de 32 bits con signo, se desborda en poco más de un año si hay 60 tics de reloj por segundo, o menos de un año si hay 100. Hay sistemas individuales que se ejecutan continuamente durante más tiempo que eso. Este volumen de POSIX.1‐2017 permite a una implementación que el punto de referencia para el valor devuelto sea la hora de inicio del proceso, en lugar de la hora de inicio del sistema.

El término "cargo" en este contexto no tiene nada que ver con la facturación de servicios. El sistema operativo contabiliza el tiempo utilizado de esta manera. Esa información debe ser correcta, independientemente de cómo se utilice.

NAME

times - devolver el tiempo de uso del proceso

SYNOPSIS

#include <sys/times.h>

clock_t times(clock_t buf[5]);

DESCRIPTION

La función times() devuelve información sobre el tiempo de uso del procesador consumido por el proceso que realiza la llamada y sus hijos terminados que han sido señalados para ser rastreados por el padre. El argumento buf es un puntero a una estructura que contendrá la información de tiempo de uso. Esta estructura, definida en <sys/times.h>, debe contener al menos los siguientes miembros:

clock_t tms_utime;   /* tiempo de usuario */
clock_t tms_stime;   /* tiempo de sistema */
clock_t tms_cutime;  /* tiempo de usuario de los hijos terminados */
clock_t tms_cstime;  /* tiempo de sistema de los hijos terminados */

Los valores devueltos en buf->tms_utime y buf->tms_stime son el tiempo de reloj consumido por el proceso que realiza la llamada en modo de usuario y modo de sistema, respectivamente. El tiempo de reloj de los hijos terminados se devuelve en buf->tms_cutime y buf->tms_cstime.

El tiempo se mide en tics del reloj. El número de tics por segundo es determinado por la constante _SC_CLK_TCK, que puede ser obtenida usando sysconf(3). La resolución de los valores devueltos es la de un tipo clock_t.

La función times() devuelve el valor de reloj del sistema en el momento de la llamada. Si ocurre un error, devuelve (clock_t)-1 y errno se establece para indicar el error.

RETURN VALUE

En caso de éxito, times() devuelve el tiempo de reloj del proceso que realiza la llamada en el momento de la llamada. En caso de error, devuelve (clock_t)-1 y errno se establece adecuadamente.

ERRORS

EFAULT
El puntero buf no apunta a un espacio de direcciones válido.

EXAMPLES

El siguiente ejemplo muestra cómo usar la función times() para medir el tiempo de ejecución de un bloque de código:

#include <stdio.h>
#include <stdlib.h>
#include <sys/times.h>
#include <unistd.h>

int main() {
    struct tms tms_start, tms_end;
    clock_t start_clock, end_clock;
    long clk_tck = sysconf(_SC_CLK_TCK);

    start_clock = times(&tms_start);
    if (start_clock == (clock_t)-1) {
        perror("times");
        exit(EXIT_FAILURE);
    }

    /* Bloque de código a medir */
    printf("Ejecutando un bloque de código...\n");
    sleep(1); /* Simular algo de trabajo */

    end_clock = times(&tms_end);
    if (end_clock == (clock_t)-1) {
        perror("times");
        exit(EXIT_FAILURE);
    }

    printf("Tiempo de usuario: %.2f segundos\n",
           (double)(tms_end.tms_utime - tms_start.tms_utime) / clk_tck);
    printf("Tiempo de sistema: %.2f segundos\n",
           (double)(tms_end.tms_stime - tms_start.tms_stime) / clk_tck);
    printf("Tiempo de usuario de hijos: %.2f segundos\n",
           (double)(tms_end.tms_cutime - tms_start.tms_cutime) / clk_tck);
    printf("Tiempo de sistema de hijos: %.2f segundos\n",
           (double)(tms_end.tms_cstime - tms_start.tms_cstime) / clk_tck);

    return 0;
}

APPLICATION USAGE

La función times() se utiliza principalmente para medir el tiempo de CPU consumido por un proceso y sus hijos. Esto puede ser útil para la depuración, la optimización y la elaboración de perfiles de rendimiento.

RATIONALE

La función times() proporciona una forma portable de obtener información detallada sobre el uso del tiempo de CPU por un proceso. El uso de clock_t y la constante _SC_CLK_TCK garantiza la compatibilidad entre diferentes sistemas.
