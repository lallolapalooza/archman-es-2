NOMBRE

timew-report - ejecutar un informe de extensión

SINOPSIS

timew [report] <informe> [<rango>] [<etiqueta>...]
timew [report] <informe> <id>...

DESCRIPCIÓN

Ejecuta un informe de extensión y admite el filtrado de datos. El comando 'report' en sí es opcional, lo que significa que estos dos comandos son equivalentes:

$ timew report foo :semana
$ timew        foo :semana

Esto asume que hay una extensión 'foo' instalada.

El código de retorno es el código de retorno de la extensión. Si la extensión no produce salida y tiene un código de retorno distinto de cero, se devuelve 255.

El filtrado es posible por rango y/o etiquetas, o por ids.

CONFIGURACIÓN

reports.range

Establece el rango de fechas predeterminado para todos los informes. El valor debe corresponder a una pista de rango, consulte timew-hints(7). El valor predeterminado es all (todo).

reports.<nombre>.range

Establece el rango de fechas para el informe nombre, utilizado si no se proporciona ningún rango en la línea de comandos. Aquí, nombre es el nombre del ejecutable del informe sin su extensión (es decir, un ejecutable de informe 'foo.py' se hace referencia como 'foo'). El valor debe corresponder a una pista de rango, consulte timew-hints(7). El valor predeterminado es el valor de reports.range.
