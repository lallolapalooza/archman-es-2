NOMBRE

timew start - iniciar seguimiento de tiempo

SINOPSIS

timew start [<fecha>] [<etiqueta>...]

DESCRIPCIÓN

Comienza a rastrear usando la hora actual con cualquier conjunto de etiquetas especificado. Si una etiqueta contiene varias palabras, y por lo tanto contiene espacios, usa comillas para rodear la etiqueta completa.

INDICACIONES

El comando start acepta las siguientes indicaciones:

:fill

La indicación ':fill' se puede usar para crear un nuevo intervalo que comience justo después del último intervalo cerrado. Esto es útil cuando quieres comenzar a rastrear tiempo inmediatamente después de terminar una tarea anterior sin especificar una hora de inicio.

EJEMPLOS

Por ejemplo, este comando especifica dos etiquetas ('weekend' y 'Home & Garden'), la segunda de las cuales requiere comillas.

$ timew start weekend 'Home & Garden'

Se puede especificar una fecha opcional para indicar la hora de inicio deseada del tiempo rastreado:

$ timew start 8am weekend 'Home & Garden'

Si hay un intervalo abierto anterior, se cerrará a la hora de inicio dada.

Las comillas son inofensivas si se usan innecesariamente.
