NOMBRE

timew-tags - muestra una lista de etiquetas

SINOPSIS

timew tags [<rango>]

DESCRIPCIÓN

Muestra todas las etiquetas que se han utilizado por defecto. Cuando se especifica un filtro, muestra solo las etiquetas que se utilizaron durante ese tiempo.

CONFIGURACIÓN

tags.<etiqueta>.color

Asigna un color de primer plano y fondo específico a una etiqueta. Ejemplos de colores válidos incluyen 'blanco', 'gris8', 'negro sobre amarillo' y 'rgb345'.
