timer_settime(2) Manual de Llamadas al Sistema timer_settime(2)

NOMBRE

timer_settime, timer_gettime - armar/desarmar y obtener el estado del temporizador POSIX por proceso

BIBLIOTECA

Biblioteca de tiempo real (librt, -lrt)

SINOPSIS

#include <time.h>
int timer_gettime(timer_t timerid, struct itimerspec *curr_value);
int timer_settime(timer_t timerid, int flags,
                  const struct itimerspec *restrict new_value,
                  struct itimerspec *_Nullable restrict old_value);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

timer_settime(), timer_gettime():

    _POSIX_C_SOURCE >= 199309L

DESCRIPCIÓN

timer_settime() arma o desarma el temporizador identificado por timerid. El argumento new_value es un puntero a una estructura itimerspec que especifica el nuevo valor inicial y el nuevo intervalo para el temporizador. La estructura itimerspec se describe en itimerspec(3type).

Cada una de las subestructuras de la estructura itimerspec es una estructura timespec(3) que permite especificar un valor de tiempo en segundos y nanosegundos. Estos valores de tiempo se miden de acuerdo con el reloj que se especificó cuando se creó el temporizador mediante timer_create(2).

Si new_value->it_value especifica un valor distinto de cero (es decir, cualquiera de los subcampos es distinto de cero), entonces timer_settime() arma (inicia) el temporizador, estableciéndolo para que expire inicialmente en el tiempo dado. (Si el temporizador ya estaba armado, la configuración anterior se sobrescribe). Si new_value->it_value especifica un valor cero (es decir, ambos subcampos son cero), entonces se desarma el temporizador.

El campo new_value->it_interval especifica el período del temporizador, en segundos y nanosegundos. Si este campo no es cero, entonces cada vez que expira un temporizador armado, el temporizador se recarga desde el valor especificado en new_value->it_interval. Si new_value->it_interval especifica un valor cero, entonces el temporizador expira solo una vez, en el tiempo especificado por it_value.

Por defecto, el tiempo de expiración inicial especificado en new_value->it_value se interpreta en relación con la hora actual en el reloj del temporizador en el momento de la llamada. Esto se puede modificar especificando TIMER_ABSTIME en flags, en cuyo caso new_value->it_value se interpreta como un valor absoluto medido en el reloj del temporizador; es decir, el temporizador expirará cuando el valor del reloj alcance el valor especificado por new_value->it_value. Si la hora absoluta especificada ya ha pasado, entonces el temporizador expira inmediatamente y el recuento de excesos (ver timer_getoverrun(2)) se establecerá correctamente.

Si el valor del reloj CLOCK_REALTIME se ajusta mientras un temporizador absoluto basado en ese reloj está armado, la expiración del temporizador se ajustará adecuadamente. Los ajustes en el reloj CLOCK_REALTIME no tienen ningún efecto en los temporizadores relativos basados en ese reloj.

Si old_value no es NULL, entonces apunta a un búfer que se utiliza para devolver el intervalo anterior del temporizador (en old_value->it_interval) y la cantidad de tiempo hasta que el temporizador habría expirado previamente (en old_value->it_value).

timer_gettime() devuelve el tiempo hasta la próxima expiración, y el intervalo, para el temporizador especificado por timerid, en el búfer apuntado por curr_value. El tiempo restante hasta la próxima expiración del temporizador se devuelve en curr_value->it_value; este es siempre un valor relativo, independientemente de si se utilizó o no la bandera TIMER_ABSTIME al armar el temporizador. Si el valor devuelto en curr_value->it_value es cero, entonces el temporizador está actualmente desarmado. El intervalo del temporizador se devuelve en curr_value->it_interval. Si el valor devuelto en curr_value->it_interval es cero, entonces este es un temporizador de "un solo disparo".

VALOR DE RETORNO

En caso de éxito, timer_settime() y timer_gettime() devuelven 0. En caso de error, devuelven -1 y errno se establece para indicar el error.

ERRORES

Estas funciones pueden fallar con los siguientes errores:

EFAULT
new_value, old_value, o curr_value no es un puntero válido.
EINVAL
timerid es inválido.

timer_settime() puede fallar con los siguientes errores:

EINVAL
new_value.it_value es negativo; o new_value.it_value.tv_nsec es negativo o mayor que 999.999.999.

ESTÁNDARES

POSIX.1-2024.

HISTORIAL
