TIE(1) Manual de comandos generales TIE(1)

NOMBRE

tie - fusionar o aplicar archivos de cambio de WEB

SINOPSIS

tie -c|-m archivo_salida archivomaestro archivo_cambio...

DESCRIPCIÓN

El programa tie se utiliza para procesar múltiples archivos de cambio utilizados con el sistema WEB de programación literaria. Los programas WEB permiten aplicar parches a un archivo fuente (el archivomaestro) mediante una serie de archivos de cambio (a menudo, solo se permite un archivo de cambio). Tie se puede utilizar para fusionar hasta 32 archivos de cambio en uno solo o para aplicar los cambios al archivomaestro con el fin de crear uno nuevo. La salida, ya sea del nuevo archivo de cambio o del archivo maestro parcheado, va a archivo_salida.

OPCIONES

-c
Crear un único archivo de cambio a partir de los archivo_cambio dados.
-m
Crear un nuevo archivo maestro aplicando los archivo_cambio dados.

ENTORNO

La variable de entorno WEBINPUTS se utiliza para buscar los archivos de entrada, o la configuración predeterminada del sistema si WEBINPUTS no está configurada. Consulte tex(1) para obtener detalles sobre la búsqueda. Para evitar conflictos con otros programas que también utilizan la variable de entorno WEBINPUTS, puede ser más específico y usar WEBINPUTS_tie para requisitos especiales en TIE.

VER TAMBIÉN

web(1), ctie(1), cweb(1).
