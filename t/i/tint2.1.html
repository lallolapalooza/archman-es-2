NOMBRE

tint2 - panel/barra de tareas ligero

DESCRIPCIÓN

tint2 es un panel/barra de tareas simple hecho para gestores de ventanas modernos de X. Fue hecho específicamente para Openbox, pero también debería funcionar con otros gestores de ventanas (GNOME, KDE, XFCE, etc.).

Características:

  • Panel con barra de tareas, área de notificación, reloj e iconos de lanzador;
  • Fácil de personalizar: color/transparencia en fuentes, iconos, bordes y fondos;
  • Capacidad similar a un paginador: mover tareas entre espacios de trabajo (escritorios virtuales), cambiar entre espacios de trabajo;
  • Capacidad multi-monitor: crear un panel por monitor, mostrando solo las tareas del monitor actual;
  • Eventos del ratón personalizables.

Objetivos:

  • Ser discreto y ligero (en términos de memoria, CPU y estética);
  • Seguir las especificaciones de freedesktop.org;
  • Hacer que ciertos flujos de trabajo, como multi-escritorio y multi-monitor, sean fáciles de usar.

SINOPSIS

tint2 [OPCIÓN...]

OPCIONES

-c ruta_al_archivo_de_configuracion
Especifica qué archivo de configuración usar en lugar del predeterminado.
-v, --version
Imprime la información de la versión y sale.
-h, --help
Muestra esta ayuda y sale.

Introducción

Estas son instrucciones para configurar tint2 directamente editando su archivo de configuración. También puedes usar en su lugar la interfaz gráfica tint2conf.

La primera vez que ejecutes tint2, creará el archivo de configuración en $HOME/.config/tint2/tint2rc (Esto aplica si has hecho una instalación limpia. Ejecutar tint2 en el directorio de origen sin hacer 'make install' no creará el archivo de configuración).

También puedes especificar otro archivo en la línea de comandos con la opción -c, por ejemplo: tint2 -c $HOME/tint2.conf. Esto puede usarse para ejecutar múltiples instancias de tint2 que usen diferentes configuraciones.

Si cambias el archivo de configuración mientras tint2 se está ejecutando, el comando killall -SIGUSR1 tint2 forzará a tint2 a recargarlo.

Todas las opciones de configuración admitidas en el archivo de configuración se enumeran a continuación. Intenta respetar tanto como sea posible el orden de las opciones como se indica a continuación.

Fondos y bordes

El archivo de configuración de tint2 comienza con las opciones que definen elementos de fondo con bordes:

  • rounded = número_de_píxeles : el radio de la esquina
  • border_width = entero : el ancho del borde en píxeles
  • border_sides = LRTB : los lados en los que dibujar el borde (izquierdo, derecho, superior, inferior). Si no se especifica, se usan todos los lados. (desde 0.12.12)
  • background_color = color opacidad
  • color se especifica en RGB hexadecimal, por ejemplo, #ff0000 es rojo
  • opacidad varía de (0 a 100), donde 0 es totalmente transparente, 100 es totalmente opaco. Ten en cuenta que para un panel transparente necesitas habilitar un compositor de escritorio (como compton o compiz).

  • opacidad varía de (0 a 100), donde 0 es totalmente transparente, 100 es totalmente opaco
  • border_content_tint_weight = entero : Mezcla el color del borde con el color del contenido (para las tareas, este es el color promedio del icono de la ventana). Los valores deben estar entre 0 (sin mezcla) y 100 (reemplaza completamente el color). (desde 16.0)
  • background_content_tint_weight = entero : Mezcla el color de fondo con el color del contenido (para las tareas, este es el color promedio del icono de la ventana). Los valores deben estar entre 0 (sin mezcla) y 100 (reemplaza completamente el color). (desde 16.0)

Puedes definir tantos fondos como quieras. Por ejemplo, la siguiente configuración define dos fondos:

rounded = 1
border_width = 0
background_color = #282828 100
border_color = #000000 0
rounded = 1
border_width = 0
background_color = #f6b655 90
border_color = #cccccc 40

tint2 identifica automáticamente cada fondo con un número comenzando desde 1 (1, 2, ...). Después, puedes aplicar un fondo a los objetos (panel, barra de tareas, tarea, reloj, área de notificación) usando el ID del fondo, por ejemplo:

panel_background_id = 1
taskbar_background_id = 0
task_background_id = 0
task_active_background_id = 2
systray_background_id = 0
clock_background_id = 0

El identificador 0 se refiere a un fondo especial que es totalmente transparente, el identificador 1 aplica el primer fondo definido en el archivo de configuración, etc.

Gradientes

(Disponible desde 0.13.0)

Los fondos también permiten especificar capas de gradiente que se dibujan encima del fondo de color sólido.

Primero, el usuario debe definir uno o más gradientes en el archivo de configuración, cada uno comenzando con gradient = TIPO. Estos deben agregarse antes que los fondos.

Luego, los gradientes se pueden agregar por índice a los fondos, usando gradient_id = ÍNDICE, gradient_id_hover = ÍNDICE y gradient_id_pressed = ÍNDICE, donde ÍNDICE es el índice del gradiente, comenzando desde 1.

GRADIENTES

Los gradientes definen el color de fondo de los elementos de la barra. Los gradientes tienen puntos de control fijos y los colores varían entre ellos. El usuario debe especificar el color inicial y final, y puede añadir puntos de detención de color adicionales entre ellos usando la opción color_stop, como se explica a continuación.

Los colores varían entre los puntos de control fijos: * gradientes verticales: de arriba a abajo; * gradientes horizontales: de izquierda a derecha; * gradientes radiales: del centro a las esquinas.

El usuario debe especificar los colores de inicio y fin, y puede añadir opcionalmente puntos de detención de color adicionales usando la opción color_stop, como se explica a continuación.

Gradiente vertical, con color variando del borde superior al borde inferior, dos colores

gradient = vertical
start_color = #rrggbb opacidad
end_color = #rrggbb opacidad

Gradiente horizontal, con color variando del borde izquierdo al borde derecho, dos colores

gradient = horizontal
start_color = #rrggbb opacidad
end_color = #rrggbb opacidad

Gradiente radial, con color variando del centro a la esquina, dos colores:

gradient = radial
start_color = #rrggbb opacidad
end_color = #rrggbb opacidad

Añadiendo puntos de detención de color adicionales (0% y 100% permanecen fijos, más colores al x% entre los puntos de control de inicio y fin)

color_stop = porcentaje #rrggbb opacidad

Panel

•
panel_items = LTSBC define los elementos que tint2 mostrará y el orden de esos elementos. Cada letra se refiere a un elemento, definido como:
  • L muestra el Lanzador
  • T muestra la Barra de Tareas
  • S muestra la Bandeja del Sistema (también llamada área de notificación)
  • B muestra el estado de la Batería
  • C muestra el Reloj
  • F añade un espaciador extensible (espacio libre). Puedes especificar más de uno. No tiene efecto si también está presente T. (desde 0.12)
  • E añade un plugin ejecutable. Puedes especificar más de uno. (desde 0.12.4)
  • P añade un botón pulsador. Puedes especificar más de uno. (desde 0.14)
  • : añade un separador. Puedes especificar más de uno. (desde 0.13.0)

Por ejemplo, panel_items = STC mostrará la bandeja del sistema, la barra de tareas y el reloj (de izquierda a derecha).

•
panel_monitor = monitor (all o primary o 1 o 2 o ...) : En qué monitor dibuja tint2 el panel
  • El primer monitor es 1
  • Usa panel_monitor = all para tener un panel separado por monitor
•
primary_monitor_first = booleano (0 o 1) : Coloca el monitor principal antes que todos los demás monitores en la lista. (desde 0.12.4; eliminado en 1.0, usa primary en su lugar)

panel_position = vertical_position horizontal_position orientation
  • vertical_position es uno de: bottom, top, center
  • horizontal_position es uno de: left, right, center
  • orientation es uno de: horizontal, vertical

panel_size = width height
•
width y height pueden especificarse sin unidades (ej: 123) como píxeles, o seguidos por % como porcentajes del tamaño del monitor (ej: 50%). Usa 100% para el ancho/alto completo del monitor. Ejemplo:
  • scale_relative_to_dpi = entero : Si se establece a un valor distinto de cero, la escala HiDPI está habilitada. Cada panel es visible en un monitor diferente. Por lo tanto, cada panel tiene un factor de escala específico. El factor de escala se calcula como la relación entre el DPI del monitor (obtenido de las dimensiones en píxeles y milímetros de RandR) y un DPI de referencia configurado, este es el DPI para el cual las configuraciones de usuario existentes se veían normales, por compatibilidad hacia atrás.
  • scale_relative_to_screen_height = entero : Similar a scale_relative_to_dpi, excepto que el factor de escala se calcula como la relación entre la altura del monitor y scale_relative_to_screen_height. El efecto es acumulativo con scale_relative_to_dpi, es decir, si ambas opciones están presentes, los factores se multiplican.
# El ancho del panel es el 94% del tamaño del monitor, la altura es de 30 píxeles:
panel_size = 94% 30

  • panel_margin = horizontal_margin vertical_margin : Los márgenes definen la distancia entre el panel y el borde horizontal/vertical del monitor. Usa 0 para obtener un panel del mismo tamaño que el borde del monitor (sin margen).

  • wm_menu = booleano (0 o 1) : Define si tint2 reenvía eventos del ratón no manejados a tu gestor de ventanas. Útil para gestores de ventanas como openbox, que muestran el menú de inicio si haces clic derecho en el escritorio.

En algunos gestores de ventanas, esto permite colocar un panel en el medio de la pantalla virtual, por ejemplo, en el borde inferior del monitor superior en una configuración de doble monitor vertical.
  • panel_layer = bottom/normal/top : Coloca tint2 en la capa bottom/normal/top. Esto es útil para especificar si el panel puede ser cubierto por otras ventanas o no. El valor predeterminado es la capa inferior, pero con transparencia real, las capas normal o superior pueden ser una buena alternativa.

Nota: en configuraciones multimonitor (Xinerama), el panel generalmente debe colocarse en el borde (no en el medio) de la pantalla virtual para que esto funcione correctamente (aunque en algunos gestores de ventanas, configurar panel_pivot_struts puede sortear esta limitación).
  • follow_size significa que las ventanas maximizadas siempre se redimensionan para tener un borde común con tint2.
  • minimum significa que las ventanas maximizadas siempre se expanden para tener un borde común con el panel oculto. Esto es útil si la opción autohide está habilitada.
  • none significa que las ventanas maximizadas utilizan el tamaño completo de la pantalla.
  • panel_window_name = cadena : Define el nombre de la ventana del panel. Predeterminado: 'tint2'. (desde 0.12)
  • disable_transparency = booleano (0 o 1) : Si deshabilitar la transparencia en lugar de detectar si es compatible. Útil en pilas gráficas defectuosas. (desde 0.12)

  • autohide_show_timeout = flotante : Tiempo de espera para mostrar en segundos después de que el cursor del ratón entra en el panel. Usa '.' como separador decimal.
  • autohide_hide_timeout = flotante : Tiempo de espera para ocultar en segundos después de que el cursor del ratón sale del panel. Usa '.' como separador decimal.
  • autohide_height = entero : altura del panel (ancho para paneles verticales) en modo oculto.

Launcher

The launcher can be configured to show applications from specified directories.

  • launcher_show_desktop_files = boolean (0 or 1) : Whether to load and show applications defined in .desktop files (see http://standards.freedesktop.org/desktop-entry-spec/desktop-entry-spec-latest.html). File paths may begin with ~, which is expanded to the user's home directory. If only a file name is specified, the file is searched in the standard application directories ($XDG_DATA_HOME/applications, ~/.local/share/applications, $XDG_DATA_DIRS/applications, /usr/local/share/applications, /usr/share/applications, /opt/share/applications).
  • launcher_apps_dir = path_to_directory : Specifies a path to a directory from which the launcher loads all .desktop files (all subdirectories are explored recursively). Can be used multiple times. The path may begin with ~, which is expanded to the user's home directory. (since 0.12)
  • launcher_background_id = integer : Defines which background to use.
  • launcher_icon_background_id = integer : Defines which background to use for icons.
  • launcher_padding = horizontal_padding vertical_padding spacing
  • launcher_icon_size = integer : The launcher icon size, in pixels.
  • launcher_icon_theme = name_of_theme : (Optional) Uses the specified icon theme to display shortcut icons. Note that tint2 will detect and use the icon theme of your desktop if you have an XSETTINGS manager running (which you probably do), unless launcher_icon_theme_override = 1.
  • launcher_icon_theme_override = boolean (0 or 1) : Whether launcher_icon_theme overrides the value obtained from the XSETTINGS manager. (since 0.12)

Mouse actions for taskbar buttons

The possible mouse events are: left, middle, right, scroll_up, scroll_down.

The possible mouse actions are: none, close, toggle, iconify, shade, toggle_iconify, maximize_restore, desktop_left, desktop_right, next_task, prev_task.

Use mouse_event = action to customize mouse actions. Example:
mouse_middle = none
mouse_right = close
mouse_scroll_up = toggle
mouse_scroll_down = iconify

The action semantics:
* none : If wm_menu = 1 is set, the mouse event is forwarded to the window manager. Otherwise it is ignored. * close : close the task * toggle : toggle the task * iconify : iconify (minimize) the task * toggle_iconify : toggle or iconify the task * maximize_restore : maximized or minimized the task * shade : shades (collapses) the task * desktop_left : send the task to the desktop on the left * desktop_right : send the task to the desktop on the right * next_task : send the focus to next task * prev_task : send the focus to previous task

  • systray_sort = name/alpha/numeric : Order of systray icons. Default: name. (since 0.12)

  • systray_yalign = float (0 to 1) : Vertical alignment of systray icons. Default: 0.5. (since 0.12.1)
  • systray_xalign = float (0 to 1) : Horizontal alignment of systray icons. Default: 0.5. (since 0.12.1)

  • battery_hide = nunca/entero (0 a 100) : En qué porcentaje de batería se oculta el elemento de la batería.
  • battery_low_status = entero: En qué porcentaje de batería se ejecuta el comando de aviso de batería baja.
  • battery_low_cmd = xmessage 'tint2: ¡Batería baja!' : Comando a ejecutar cuando la batería esté baja.

  • bat1_format = CADENA_FORMATO : Formato para la línea 1 de la batería. Por defecto: %p. (desde 1.0) Especificación de formato:
  • %s: Estado (cargando, descargando, llena, desconocida).
  • %m: Minutos restantes hasta que esté completamente cargada/descargada (estimado).
  • %h: Horas restantes hasta que esté completamente cargada/descargada (estimado).
  • %t: Tiempo restante. Muestra "hrs:mins" al cargar/descargar, o "Ful\" al estar llena.
  • %p: Porcentaje. Incluye el signo %.
  • %P: Porcentaje. Sin el signo %.

Ejecutor

  • execp = new : Comienza la configuración de un nuevo plugin ejecutor. Se admiten varios plugins de este tipo; simplemente usa varias Es en panel_items. (desde 0.12.4)
  • execp_command = texto : Comando a ejecutar. (desde 0.12.4)
  • execp_interval = entero : El comando se vuelve a ejecutar después de execp_interval segundos desde el momento en que finaliza. Si es cero, el comando se ejecuta solo una vez. (desde 0.12.4)
  • execp_continuous = entero : Si es distinto de cero, las últimas execp_continuous líneas de la salida del comando se muestran cada execp_continuous líneas; esto es útil para mostrar la salida de comandos que se ejecutan indefinidamente, como ping 127.0.0.1. Si es cero, la salida del comando se muestra después de que finaliza su ejecución. (desde 0.12.4)
  • execp_has_icon = booleano (0 o 1) : Si execp_has_icon = 1, la primera línea impresa por el comando se interpreta como la ruta a un archivo de imagen. (desde 0.12.4)
  • execp_cache_icon = booleano (0 o 1) : Si execp_cache_icon = 0, la imagen se recarga cada vez que se ejecuta el comando (útil si el archivo de imagen es modificado en disco por el programa ejecutado por execp_command). (desde 0.12.4)
  • execp_icon_w = entero : Puedes usar execp_icon_w y execp_icon_h para redimensionar la imagen. Si uno de ellos es cero/faltante, la imagen se escala proporcionalmente. Si ambos son cero/faltantes, la imagen no se redimensiona. (desde 0.12.4)
  • execp_icon_h = entero : Ver execp_icon_w. (desde 0.12.4)
  • execp_tooltip = texto : La información emergente. Si se deja vacío, no se muestra ninguna información emergente. Si falta, el error estándar del comando se muestra como información emergente (una secuencia de borrado de pantalla ANSI puede restablecer el contenido, bash: printf '\e[2J', C: printf("\x1b[2J");). Si el error estándar está vacío, la información emergente mostrará información sobre la hora en que se ejecutó el comando por última vez. (desde 0.12.4)
  • execp_font = [LISTA-FAMILIAS] [OPCIONES-ESTILO] [TAMAÑO] : La fuente utilizada para dibujar el texto. (desde 0.12.4)
  • execp_font_color = color opacidad : El color de la fuente. (desde 0.12.4)
  • execp_markup = booleano (0 o 1) : Si es distinto de cero, la salida del comando se trata como marcado Pango, lo que permite formato de texto enriquecido. El formato se documenta aquí ⟨https://developer.gnome.org/pygtk/stable/pango-markup-language.html⟩. Ten en cuenta que usar esto con comandos que imprimen datos descargados de Internet es un posible riesgo de seguridad. (desde 0.12.4)
  • execp_background_id = entero : Qué fondo usar. (desde 0.12.4)
  • execp_centered = booleano (0 o 1) : Si centrar el texto. (desde 0.12.4)
  • execp_padding = padding_horizontal padding_vertical espacio_entre_icono_y_texto (desde 0.12.4)
  • execp_monitor = entero (1, 2, ...), primario o todos : En qué monitor dibujar el ejecutor. El primer monitor es 1. (desde 17.0)
  • execp_lclick_command = texto : Comando a ejecutar al hacer clic con el botón izquierdo. Si no está definido, execp_command se ejecuta inmediatamente, a menos que esté actualmente en ejecución. (desde 0.12.4)
  • execp_mclick_command = texto : Comando a ejecutar al hacer clic con el botón derecho. Si no está definido, execp_command se ejecuta inmediatamente, a menos que esté actualmente en ejecución. (desde 0.12.4)
  • execp_rclick_command = texto : Comando a ejecutar al hacer clic con el botón central. Si no está definido, execp_command se ejecuta inmediatamente, a menos que esté actualmente en ejecución. (desde 0.12.4)
  • execp_uwheel_command = texto : Comando a ejecutar al girar la rueda del ratón hacia arriba. Si no está definido, execp_command se ejecuta inmediatamente, a menos que esté actualmente en ejecución. (desde 0.12.4)
  • execp_dwheel_command = texto : Comando a ejecutar al girar la rueda del ratón hacia abajo. Si no está definido, execp_command se ejecuta inmediatamente, a menos que esté actualmente en ejecución. (desde 0.12.4)

tint2(1)

NAME

tint2 – a simple panel/taskbar optimized for modern desktops

DESCRIPTION

tint2 is a panel/taskbar, intended to be used with modern desktop environments. It is highly configurable and provides features such as task lists, menus, a system tray, clock, and battery monitor.

This manual page describes the configuration options for tint2.

SYNOPSIS

Configuration is done via the tint2rc configuration file, typically located in ~/.config/tint2/tint2rc or /etc/xdg/tint2/tint2rc.

OPTIONS

The configuration file is divided into sections, each corresponding to a specific element or functionality of the panel. Here are some of the key options:

CONFIGURATION

Taskbar buttons

execp = new
execp_command = echo /usr/share/icons/elementary-xfce/emblems/24/emblem-colors-blue.png; echo '<span foreground="#7f7">Click</span> <span foreground="#77f">me</span> <span foreground="#f77">pls</span>'
execp_has_icon = 1
execp_interval = 0
execp_centered = 1
execp_font = sans 9
execp_markup = 1
execp_font_color = #aaffaa 100
execp_padding = 2 0
execp_tooltip = I will tell you a secret...
execp_lclick_command = zenity --info "--text=$(uname -sr)"
execp_background_id = 2

Desktop pager with text

execp = new
execp_command = xprop -root -spy | awk '/^_NET_CURRENT_DESKTOP/ { print "Workspace " ($3 + 1) ; fflush(); }'
execp_interval = 1
execp_continuous = 1

Desktop pager with icon

execp_command = xprop -root -spy | awk -v home="$HOME" '/^_NET_CURRENT_DESKTOP/ { print home "/.config/myPager/" ($3 + 1) ".png\n" ; fflush(); }'
execp_interval = 1
execp_has_icon = 1
execp_cache_icon = 1
execp_continuous = 2

Round-trip time to the gateway, refreshed every second

execp = new
execp_command = ping -i 1 -c 1 -W 1 -O -D -n $(ip route | grep default | grep via | grep -o '[0-9]*\.[0-9]*\.[0-9]*\.[0-9]*') | awk '/no/ { print "<span foreground=\"#faa\">timeout</span>"; fflush(); }; /time=/ { gsub(/time=/, "", $8); printf "<span foreground=\"#7af\">%3.0f %s</span>\n", $8, $9); fflush(); } '
execp_continuous = 0
execp_interval = 1
execp_markup = 1

Memory usage

# Note the use of "stdbuf -oL" to force the program to flush the output line by line.
execp = new
execp_command = free -b -s1 | stdbuf -oL awk '/^Mem:/ { printf "Mem: %s %.0f%%\n", $2, 100 * ($2 - $7) / $2 }' | stdbuf -oL numfmt --to=iec-i --field=2 -d' '
execp_interval = 1
execp_continuous = 1

Network load

execp = new
execp_command = stdbuf -oL bwm-ng -o csv -t 1000 | stdbuf -oL awk -F ';' '/total/ { printf "Net: %.0f Mb/s\n", ($5*8/1.0e6) }'
execp_continuous = 1
execp_interval = 1

Button

  • button = new : Begins the configuration of a new button. Multiple such plugins are supported; just use multiple Ps in panel_items. (since 0.14)
  • button_icon = text : Name or path of icon (or empty). (since 0.14)
  • button_text = text : Text to display (or empty). (since 0.14)
  • button_tooltip = text : The tooltip (or empty). (since 0.14)
  • button_font = [FAMILY-LIST] [STYLE-OPTIONS] [SIZE] : The font used to draw the text. (since 0.14)
  • button_font_color = color opacity : The font color. (since 0.14)
  • button_background_id = integer : Which background to use. (since 0.14)
  • button_centered = boolean (0 or 1) : Whether to center the text. (since 0.14)
  • button_padding = horizontal_padding vertical_padding spacing_between_icon_and_text (since 0.14)
  • button_max_icon_size = integer : Sets a limit to the icon size. Otherwise, the icon will expand to the edges. (since 0.14)
  • button_lclick_command = text : Command to execute on left click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
  • button_mclick_command = text : Command to execute on right click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
  • button_rclick_command = text : Command to execute on middle click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
  • button_uwheel_command = text : Command to execute on wheel scroll up. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
  • button_dwheel_command = text : Command to execute on wheel scroll down. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)

Separator

  • separator = new : Begins the configuration of a new separator. Multiple such plugins are supported; just use multiple :s in panel_items. (since 0.13.0)
  • separator_background_id = integer : Which background to use. (since 0.13.0)
  • separator_color = color opacity : The foreground color. (since 0.13.0)
  • separator_style = [empty | line | dots] : The separator style. (since 0.13.0)
  • separator_size = integer : The thickness of the separator. Does not include the border and padding. For example, if the style is line, this is the line thickness; if the style is dots, this is the dot's diameter. (since 0.13.0)
  • separator_padding = side_padding cap_padding : The padding to add to the sides of the separator, in pixels. (since 0.13.0)
