TILDA(1) Comandos de usuario TILDA(1)

NOMBRE

tilda - emulador de terminal altamente configurable

SINOPSIS

tilda [-b|--background-color color] [-c|--command comando] [-h|--hidden] [-f|--font fuente] [-g|--config-file archivo] [-l|--lines archivo] [-s|--scrollbar] [-w|--working-dir directorio] [-x|--x-pos pos_x] [-y|--y-pos pos_y] [-t|--background-alpha alfa] [-C|--config] [--display pantalla]

tilda --dbus

tilda -T|--toggle-window [id_instancia]

tilda --version

tilda --help

tilda --help-all

DESCRIPCIÓN

Tilda es un emulador de terminal que es altamente configurable. La característica distintiva principal de tilda es que utiliza un atajo configurable para mostrar y ocultar la ventana de tilda. Esto permite a los usuarios cambiar rápidamente entre tilda y otras ventanas solo a través de atajos de teclado. Cuando tilda está oculto, se moverá fuera de la pantalla hasta que se presione nuevamente el atajo de tirar/alternar para mostrar la ventana de tilda. El comportamiento de tilda se puede configurar usando el diálogo de preferencias que está disponible a través del menú contextual. Un subconjunto de las opciones también se puede configurar desde la línea de comandos, como se documenta a continuación.

Tenga en cuenta que actualmente las opciones de la línea de comandos anulan la configuración del archivo de configuración y se guardan en el archivo de configuración.

En escritorios basados en Xorg, Tilda utiliza una función de filtro de X11 para registrar sus atajos de teclado. En Wayland, este método solo funciona mientras otros programas basados en X11 están activos, pero no podemos enviar atajos de teclado a tilda mientras las aplicaciones nativas de Wayland tengan el foco. Por lo tanto, en escritorios con Wayland, tilda debe iniciarse con soporte D-Bus (es decir, con --dbus) y se debe registrar una tecla de acceso directo global utilizando la configuración del entorno de escritorio para enviar una acción D-Bus para mostrar u ocultar la ventana de Tilda.

OPCIONES

Opciones de ayuda:

-?, --help
Mostrar opciones de ayuda
--help-all
Mostrar todas las opciones de ayuda, incluidas las opciones de D-Bus y GTK.

Opciones de aplicación:

-b, --background-color color
Establecer el color de fondo. El valor puede ser un nombre de color estándar de X11 o un valor hexadecimal (es decir, #rgb, #rrggbb, etc.).
-c, --command comando
Ejecutar un comando al inicio en lugar del shell predeterminado.
-h, --hidden
Iniciar Tilda oculto.
-f, --font fuente
Establecer la fuente en la Pango FontDescription especificada en fuente. Por defecto es "Monospace 11".
-l, --lines líneas
Establecer el tamaño del búfer de scrollback a un máximo de líneas.
-s, --scrollbar
Mostrar una barra de desplazamiento en el lateral de la terminal.
-v, --version
Imprimir la versión y salir.
-w, --working-dir directorio
Establecer el directorio de trabajo inicial en directorio.
-x, --x-pos pos_x
Establecer la posición X de la ventana de la terminal tilda en pos_x.
-y, --y-pos pos_y
Establecer la posición Y de la ventana de la terminal tilda en pos_y.
-t, --background-alpha alfa
Establecer la transparencia de la ventana de la terminal en alfa (es decir, 0-100%). Valores más altos aumentan el nivel de transparencia.
-C, --config
Mostrar el asistente de configuración.
--display=PANTALLA
Establecer la pantalla X a utilizar (es decir, :0, :0.0, etc.).

Opciones de D-Bus:

--dbus
Habilita el soporte D-Bus (ver D-Bus).
-T, --toggle-window [id_instancia]
Alterna una ventana de Tilda con id_instancia y sale. Si id_instancia no se especifica, por defecto será la instancia 0. Esta opción proporciona una forma conveniente de alternar ventanas de tilda en entornos Wayland y es equivalente al comando dbus-send más largo documentado a continuación. Puede usarse para configurar un atajo de teclado en un entorno de escritorio basado en Wayland que luego alternará la ventana de Tilda. Tenga en cuenta que esta opción se ve afectada por la configuración "Non-Focus Pull Up Behaviour" (Comportamiento de tirar hacia arriba sin foco).

NOTAS

D-Bus

Si D-Bus está habilitado, Tilda ofrece un método en D-Bus para alternar la Ventana de Tilda. Cada proceso de Tilda registra su propio nombre D-Bus, por lo que es posible ejecutar múltiples procesos de tilda cada uno con su propio archivo de configuración y controlarlos por separado a través de D-Bus. Cuando D-Bus está habilitado, el atajo de tirar hacia abajo no se registra como una función de filtro de Xorg, y se debe configurar un atajo global adecuado en el entorno de escritorio (ver --toggle-window). Opcionalmente, puede borrar el atajo de tirar en la configuración si el soporte D-Bus está habilitado.

Cada instancia de Tilda se registra utilizando un nombre de bus generado dinámicamente y una ruta de objeto que utiliza su número de instancia. La primera instancia de Tilda estará en el nombre del bus:


com.github.lanoxx.tilda.Actions0

con la ruta del objeto:


/com/github/lanoxx/tilda/Actions0

El nombre de la interfaz es siempre:


com.github.lanoxx.tilda.Actions

Para alternar la ventana de tilda, puede usar la opción -T|--toggle-window de tilda:

    tilda -T    # alternar instancia predeterminada (es decir, 0)
    tilda -T 0  # alternar explícitamente la instancia especificada (es decir, 0)

Alternativamente, también puede usar el comando dbus-send.

    dbus-send --session --type=method_call \
       --dest=com.github.lanoxx.tilda.Actions0 \
       /com/github/lanoxx/tilda/Actions0 \
       com.github.lanoxx.tilda.Actions.Toggle

Por cada instancia adicional de tilda, el nombre del bus y la ruta del objeto se incrementarán en uno (por ejemplo, Actions1, Actions2, etc.).

Puede usar uno de los comandos anteriores para registrar una tecla de acceso directo global en su sesión de Wayland. En Gnome, esto se puede hacer en Configuración -> Teclado -> Atajos de teclado.

ARCHIVOS

Tilda crea sus archivos de configuración en ~/.config/tilda/. Para cada instancia, creará un archivo de configuración llamado config_<N>, donde <N> comienza en 0 y se incrementa para cada proceso adicional que se inicia.

Tilda también crea un directorio de caché en ~/.cache/tilda/locks, donde creará un archivo de bloqueo global llamado lock_0_0 y archivos de bloqueo adicionales específicos de la instancia llamados lock_<PID>_<N>, donde <PID> es el id del proceso y <N> es el id de la instancia.

Opcionalmente, puede crear un archivo llamado style.css y colocarlo en el directorio de configuración de tilda si desea personalizar la apariencia de tilda.
