NOMBRE

timew-retag - reemplazar todas las etiquetas en intervalos

SINOPSIS

timew retag [<id>...] <etiqueta>...

DESCRIPCIÓN

El comando 'retag' se utiliza para reemplazar todas las etiquetas de un intervalo con las etiquetas proporcionadas recientemente. Usando el comando 'summary', y especificando la indicación ':ids' se muestran los IDs de los intervalos. Usando el ID correcto, puedes identificar un intervalo para renombrarlo.

EJEMPLOS

Por ejemplo, mostrar los IDs:

$ timew summary :week :ids

Luego de haber seleccionado '@2' como el intervalo que deseas renombrar:

$ timew retag @2 'Nueva Etiqueta'

Nota que puedes renombrar múltiples intervalos, con múltiples etiquetas:

$ timew retag @2 @10 @23 'Etiqueta Uno' etiqueta2 etiqueta3

Si hay un seguimiento de tiempo activo, puedes omitir el ID cuando quieras renombrar el intervalo abierto actual:

$ timew start foo
$ timew retag bar

Esto resulta en que el intervalo actual tenga solo la etiqueta 'bar'.
