NOMBRE

timew-resize - establece la duración de un intervalo

SINOPSIS

timew resize <id>... <duración>

DESCRIPCIÓN

El comando 'resize' se utiliza para cambiar la duración de un intervalo cerrado. Usando el comando 'summary' y especificando la pista ':ids' se muestran los IDs de los intervalos. Usando el ID correcto, puedes identificar un intervalo para redimensionarlo.

EJEMPLOS

Por ejemplo, mostrar los IDs:

$ timew summary :week :ids

Luego, habiendo seleccionado '@3' como el intervalo que deseas redimensionar:

$ timew resize @3 15mins

Ten en cuenta que puedes redimensionar múltiples intervalos:

$ timew resize @3 @1 @13 1hour
