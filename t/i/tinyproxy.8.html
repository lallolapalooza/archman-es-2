TINYPROXY(8) Manual de Tinyproxy TINYPROXY(8)

NOMBRE

tinyproxy - Un demonio proxy HTTP ligero

SINOPSIS

tinyproxy [-vdch]

DESCRIPCIÓN

tinyproxy es un demonio proxy HTTP ligero diseñado para consumir una cantidad mínima de recursos del sistema. Escucha en un puerto TCP dado y maneja solicitudes proxy HTTP. Diseñado desde cero para ser rápido y a la vez pequeño, es una solución ideal para casos de uso como implementaciones embebidas donde se requiere un proxy HTTP con todas las funciones, pero los recursos del sistema para un proxy más grande no están disponibles.

OPCIONES

tinyproxy acepta las siguientes opciones:

-c <archivo-de-configuracion>
Utiliza un archivo de configuración alternativo.
-d
No demonizar y permanecer en primer plano. Útil para fines de depuración.
-h
Muestra una breve pantalla de ayuda de los argumentos de la línea de comandos y sale.
-v
Muestra información de la versión y sale.

SEÑALES

Además de las opciones de línea de comandos, también hay varias señales que se pueden enviar a tinyproxy mientras se está ejecutando para generar información de depuración y forzar ciertos eventos.

SIGHUP
Obliga a Tinyproxy a realizar una recolección de basura en la lista enlazada de conexiones actuales. Esto generalmente se hace automáticamente después de que se han manejado un cierto número de conexiones. (Solo modo demonio)
SIGUSR1
Obliga a recargar el archivo de configuración y la lista de filtros. Esto es útil para actualizar la configuración si Tinyproxy se está ejecutando en primer plano sin descartar conexiones activas.

ARCHIVOS PLANTILLA

Hay dos ocasiones en las que Tinyproxy entrega páginas HTML al cliente por sí mismo:

  • Cuando ocurrió un error, se devuelve una página de error correspondiente.
  • Cuando se realiza una solicitud para el `stathost`, se devuelve una página que resume las estadísticas de conexión. (Ver STATHOST a continuación).

La disposición de las páginas de error y la página de estadísticas se puede controlar a través de archivos de plantilla HTML configurables que son archivos HTML simples que además entienden algunas variables de plantilla.

VARIABLES PLANTILLA

Hay varias variables HTML estándar que están disponibles en todos los archivos de plantilla:

request
La línea de solicitud HTTP completa.
cause
La causa abreviada de la condición de error.
clientip
La dirección IP del cliente que realiza la solicitud.
clienthost
El nombre de host del cliente que realiza la solicitud.
version
La versión de Tinyproxy.
package
El nombre del paquete. Actualmente, se resuelve a 'tinyproxy'.
date
La fecha/hora actual en formato HTTP.

Además, casi todas las plantillas admiten:

detail
Una explicación detallada en inglés simple del error y las posibles causas.

Cuando Tinyproxy encuentra un nombre de variable entre llaves, por ejemplo, "{request}", este se reemplaza por el valor de la variable correspondiente antes de entregar la página.

STATHOST

Tinyproxy devuelve una página HTML con estadísticas de conexión cuando recibe una solicitud HTTP para un cierto host: el `stathost`. El nombre del `stathost` por defecto es `tinyproxy.stats` y se puede cambiar en tiempo de ejecución a cualquier nombre o dirección IP con la variable de configuración `StatHost`.

El archivo de plantilla de estadísticas se puede cambiar en tiempo de ejecución a través de la variable de configuración `StatFile`.

ARCHIVOS

`/etc/tinyproxy/tinyproxy.conf`, `/var/run/tinyproxy/tinyproxy.pid`, `/var/log/tinyproxy/tinyproxy.log`
