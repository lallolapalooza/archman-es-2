TIPC-NODE(8) Linux TIPC-NODE(8)

NOMBRE

tipc-node - modifica y muestra los parámetros del nodo local o lista los nodos vecinos

SINOPSIS


tipc node set { address DIRECCIÓN | netid NETID }

tipc node get { address | netid }

tipc node list

OPCIONES

Opciones (banderas) que se pueden pasar en cualquier lugar de la cadena de comandos.

-h, --help
Muestra la ayuda sobre el último comando válido. Por ejemplo, tipc node --help mostrará la ayuda del nodo y tipc --help mostrará la ayuda general. La posición de la opción en la cadena es irrelevante.

DESCRIPCIÓN

Parámetros del nodo

address

La dirección lógica de TIPC. Con el formato x.y.z donde x, y y z son enteros sin signo.
netid

Identidad de red. Se puede usar para crear clústeres TIPC individuales en los mismos medios.

CÓDIGO DE SALIDA

El código de salida es 0 si el comando se ejecutó correctamente o un entero positivo en caso de error.

VER TAMBIÉN

tipc(8), tipc-bearer(8), tipc-link(8), tipc-media(8), tipc-nametable(8), tipc-peer(8), tipc-socket(8)

INFORMAR DE ERRORES

Informe de cualquier error a la lista de correo de desarrolladores de red <netdev@vger.kernel.org>, donde se realiza principalmente el desarrollo y el mantenimiento. No es necesario suscribirse a la lista para enviar un mensaje allí.
