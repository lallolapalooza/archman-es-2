NOMBRE

timew-fill - ajusta intervalos para rellenar huecos circundantes

SINOPSIS

timew fill <id>

DESCRIPCIÓN

El comando 'fill' se utiliza para ajustar cualquier intervalo y rellenar los huecos circundantes.

Rellenar el primer o el último intervalo solo dará como resultado un relleno hacia adelante o hacia atrás, respectivamente; es decir, el comando fill no creará un intervalo abierto.

Se puede lograr el mismo efecto con el comando 'modify range' en combinación con la pista ':fill'.

EJEMPLOS

Por ejemplo, asumiendo los siguientes intervalos:

$ timew summary
Wk  Date       Day ID Tags    Start      End    Time   Total
--- ---------- MTWTFSS -- -- ---- -------- -------- ------- -------
W32 2025-08-10 DLG @3 FOO   8:00:00  9:00:00 1:00:00
                   @2 BAR  10:00:00 11:00:00 1:00:00
                   @1 BAZ  12:00:00 13:00:00 1:00:00 3:00:00
                                                     -------
                                                     3:00:00

Luego, habiendo seleccionado '@2' como el intervalo que desea rellenar:

$ timew fill @2
Backfilled @2 to 2025-08-10T09:00:00
Filled @2 to 2025-08-10T12:00:00

Esto extenderá el inicio y el final del intervalo seleccionado a los adyacentes:

$ timew summary
Wk  Date       Day ID Tags    Start      End    Time   Total
--- ---------- --- -- ---- -------- -------- ------- -------
W32 2025-08-10 DLG @3 FOO   8:00:00  9:00:00 1:00:00
                   @2 BAR   9:00:00 12:00:00 3:00:00
                   @1 BAZ  12:00:00 13:00:00 1:00:00 5:00:00
                                                     -------
                                                     5:00:00
