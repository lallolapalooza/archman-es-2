NOMBRE

timew-export - exportar tiempo registrado en JSON

SINOPSIS

timew export [ <id>... | ([<rango>] [<etiqueta>...]) ]

DESCRIPCION

Exporta todo el tiempo registrado en formato JSON.

Proporcione una lista de IDs de intervalos, o un rango y/o un filtro de etiquetas (ver timew-ranges(7) y timew-tags(1)) para exportar solo un subconjunto de intervalos.

Los datos se exportan como una matriz JSON de objetos de intervalo, cada uno que contiene la hora de inicio, la hora de fin, el ID actual, las etiquetas y la anotación del intervalo, si están presentes.

EJEMPLOS

Exportar todos los intervalos

Llamar al comando export sin argumentos exporta todos los intervalos registrados en formato JSON:

$ timew export
[
{"id":2,"start":"20231001T103000Z","end":"20231001T120000Z","tags":["work"],"annotation":"Project work"},
{"id":1,"start":"20231001T090000Z","end":"20231001T100000Z","tags":["work"],"annotation":"Morning meeting"},
]

En este ejemplo, solo dos intervalos están presentes en la base de datos. La salida está ordenada por hora de inicio, con el intervalo más antiguo primero.

Exportar intervalos filtrados por rango y etiqueta

$ timew export from 2016-01-01 for 3wks tag1
...

Exportar intervalos por sus IDs

$ timew export @1 @3 @7
...
2025-08-16 timew 1.9.1
