timelocal(3) Manual de Funciones de Biblioteca timelocal(3)

NOMBRE

timegm, timelocal — inversos de gmtime y localtime

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <time.h>
[[deprecated]] time_t timelocal(struct tm *tm);
time_t timegm(struct tm *tm);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

timelocal(), timegm():

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Las funciones timelocal() y timegm() son los inversos de localtime(3) y gmtime(3). Ambas funciones toman un tiempo desglosado y lo convierten a tiempo de calendario (segundos desde la Época, 1970-01-01 00:00:00 +0000, UTC). La diferencia entre las dos funciones es que timelocal() tiene en cuenta la zona horaria local al realizar la conversión, mientras que timegm() toma el valor de entrada como Tiempo Universal Coordinado (UTC).

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el tiempo de calendario (segundos desde la Época), expresado como un valor de tipo time_t. En caso de error, devuelven el valor (time_t) -1 y establecen errno para indicar el error.

ERRORES

EOVERFLOW
El resultado no puede ser representado.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
timelocal (), timegm () Seguridad de hilos MT-Safe env locale

ESTÁNDARES

BSD.

HISTORIA

GNU, BSD.

La función timelocal() es equivalente a la función estándar POSIX mktime(3). No hay ninguna razón para utilizarla jamás.

VER TAMBIÉN

gmtime(3), localtime(3), mktime(3), tzset(3)
