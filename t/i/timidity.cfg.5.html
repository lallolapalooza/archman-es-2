NOMBRE

timidity.cfg - archivo de configuración de TiMidity++

DESCRIPCIÓN

El archivo timidity.cfg describe los entornos de ejecución de timidity(1): que son la ruta de la fuente de sonido, configuraciones de instrumentos, etc.
TiMidity++ busca el archivo de configuración timidity.cfg al arrancar, antes de procesar cualquier opción. Si no se puede acceder a él, y la ruta de la biblioteca se cambia con una opción -L en la línea de comandos, entonces se buscará el archivo predeterminado nuevamente en la nueva ruta de la biblioteca después de procesar todas las opciones, a menos que se haya especificado otro archivo de configuración con la opción -c.
Los archivos de configuración definen el mapeo de programas MIDI a archivos de instrumentos. Se pueden especificar varios archivos, y las declaraciones en los posteriores anularán las anteriores.

VARIABLE

Cuando los caracteres alfanuméricos y/o guiones bajos `_' continúan después del signo de dólar `$', se considera que la cadena es una variable y el archivo de configuración se procesa, se transpone a otra cadena. El nombre de la variable también se puede escribir con un paréntesis interior, para separarlo de un carácter siguiente.

Por ejemplo:
$variable
${variable} # igual que $variable

Por el momento, el comando que define nuevas variables no está preparado. La variable indefinida se transpone a una cadena nula.
La única variable definida como variable regular es la siguiente.

$basedir
Expresa el directorio donde existe el archivo de configuración. Mediante el comando que especifica principalmente una ruta, se utiliza para especificar la ruta relativa desde un archivo de configuración.
Si puede haber un espacio en $basedir, es necesario agruparlo con "".

Por ejemplo:
En /usr/local/share/timidity/timidity.cfg
dir $basedir/inst # fuente /usr/local/share/timidity/inst

SINTAXIS

Las siguientes declaraciones se pueden usar en un archivo de configuración:

dir directorio [...]
Agrega directorio a la ruta de búsqueda de la misma manera que la opción de línea de comandos -L.
Los archivos de archivo también están permitidos.

Por ejemplo:
dir /usr/local/share/timidity/inst/foo.zip#
bank 0
0 bar.pat
1 baz.pat
2 zoo.pat

Primero, dir especifica el nombre del archivo (seguido por `#') para la ruta de los archivos de parche, lo mismo que el nombre del directorio (en este caso, /usr/local/share/timidity/inst/foo.zip). TiMidity++ reconoce la ruta como un archivo de archivo si la expresión tiene el carácter `#'' al final, y también lee los archivos contenidos en este archivo de archivo. En el ejemplo anterior, los archivos de parche bar.pat, baz.pat y zoo.pat contenidos en foo.zip también se instalan.

source archivo [...]
Lee otro archivo de configuración y luego continúa procesando el actual.
progbase número
Establece y muestra el número de tono desde número hasta número+128. Si se especifica progbase 1, los números de tono siguientes se establecen y se muestran como los números del 1 al 128.
bank [MapID1] número
Selecciona el banco de tonos a modificar. Los mapeos de parches siguientes afectarán a este banco de tonos. Puede indicar un mapa específico como objetivo, especificando cualquiera de los siguientes para MapID1: gm2, sc55, sc88, sc88pro, sc8850, xg y xgsfx64.
drumset [MapID2] número
Selecciona el set de batería a modificar. Los mapeos de parches siguientes afectarán a este set de batería. Puede indicar un mapa específico como objetivo, especificando cualquiera de los siguientes para MapID2: gm2drum, sc55drum, sc88drum, sc88prodrum, sc8850drum, xgdrum y xgsfx126.
number archivo [opciones]

number %font archivo banco prog [nota] [opciones]

number %sample archivo [opciones]
Especifica que el número de programa MIDI en el banco de tonos o set de batería actual se reproducirá utilizando el archivo de parche. Si archivo es SoundFont, el instrumento específico con banco, prog y nota se extrae con el formato de number %font. Si archivo son datos de muestra AIFF o WAV lineales, el número de programa MIDI se especifica con el formato de number %sample. Las opciones pueden ser cualquiera de las siguientes:
amp=amplificación
Amplifica el volumen del instrumento en un amplificación por ciento. Si no se especifica ningún valor, se determinará automáticamente cada vez que se cargue el instrumento.
note=nota
Especifica una nota MIDI fija para usar al reproducir el instrumento. Si nota es 0, el instrumento se reproducirá en la nota que tenga el evento Note On que lo active. Para instrumentos de percusión, si no se especifica ningún valor en el archivo de configuración, se utilizará el predeterminado en el archivo de parche.
pan=paneo
Establece el paneo predeterminado del instrumento. paneo puede ser left (izquierda), right (derecha), center (centro), o un entero entre -100 y 100, que designa la izquierda y la derecha completas respectivamente. Si no se especifica ningún valor, se utilizará el valor predeterminado en el archivo de parche. Tenga en cuenta que los controles de paneo en los archivos MIDI anularán este valor.
tune=afinación[,...]
Ajusta la frecuencia raíz del instrumento. tune=1 causa 1 semitono más alto. Dado que una fracción está disponible para afinación, es posible realizar una afinación fina como tune=-0.2. Cuando hay dos o más datos de muestra, los argumentos después del segundo pueden especificar valores diferentes respectivamente.
rate=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece la tasa ADSR del instrumento. Cada valor puede ser un entero entre 0 y 255. Cuando solo se establece la tasa de sostenido,

6 GUS/hrpschrd.pat rate=::60

está disponible. Cuando solo se establece el tiempo de ataque rápido,

6 GUS/hrpschrd.pat rate=255

está disponible. Cuando hay dos o más datos de muestra, los argumentos después del segundo pueden especificar valores diferentes respectivamente.

offset=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el desplazamiento ADSR del instrumento. Cada valor puede ser un entero entre 0 y 255. El formato es el mismo que rate=.
keep={loop|env}
Por defecto, los instrumentos de percusión tienen su información de bucle y envolvente eliminada. Las envolventes de forma extraña también se eliminan automáticamente de los instrumentos melódicos. keep= se puede usar para evitar la eliminación de datos de bucle o envolvente. Por ejemplo, los instrumentos de viento de madera cortos y largos (números General Midi 71 y 72) necesitan que se especifique `keep=loop keep=env' en el archivo de configuración.
strip={loop|env|tail}
Fuerza la eliminación de información de bucle o envolvente de todos los parches del instrumento, o elimina la cola, es decir, todos los datos después del bucle. Algunos instrumentos de terceros tienen datos basura después del bucle, como lo demuestra un ruido de clic cada vez que se reproduce el instrumento, por lo que agregar la opción strip=tail mejorará notablemente la calidad del sonido.
tremolo=barrido_incremento:ratio_control:profundidad[,...]
Establece el trémolo del instrumento. Cada valor puede ser un entero entre 0 y 255. El formato es similar a rate=. barrido_incremento es el tiempo hasta que se inicia el trémolo. ratio_control es la tasa que cambia la amplificación. profundidad es la profundidad que cambia la amplificació

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

vibrato=sweep_increment:phase_increment:depth[,...]
Establece el vibrato del instrumento. Cada valor puede ser un entero entre 0 y 255. El formato es similar a rate=. sweep_increment es el tiempo hasta que comienza el vibrato. phase_increment es la tasa de cambio de frecuencia. depth es la profundidad del cambio de frecuencia.
sclnote=nota[,...]
Establece la nota estándar del instrumento para la afinación de escala. Por ejemplo, sclnote=60 hace que la nota central Do sea la nota estándar para la afinación de escala. Cuando hay dos o más datos de muestra, los argumentos posteriores al segundo pueden especificar valores diferentes respectivamente.
scltune=afinación[,...]
Establece el factor de afinación de escala del instrumento en centésimas. Por ejemplo, scltune=50 hace que los semitonos sean de 50 centésimas. Cuando hay dos o más datos de muestra, los argumentos posteriores al segundo pueden especificar valores diferentes respectivamente.
comm=comentario
Especifica el comentario.
modrate=ataque:decaimiento:sostenido:release1:release2:release3[,...]

modoffset=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el comportamiento del instrumento en el cambio del envolvente de modulación. El formato y los valores son fundamentalmente iguales a los del envolvente de volumen. Excepto por algunos SoundFonts, incluso si solo se especifica la opción, no sucede nada.
envkeyf=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el seguimiento de tecla del envolvente de volumen del instrumento. Basado en note=60, cambia el tiempo del envolvente según la nota. La unidad es +-centésimas/tecla. Por ejemplo, envkeyf=100 significa que el tiempo de ataque se duplicará al subir una octava. El formato es similar a rate=. El parámetro de decaimiento y sostenido puede estar preestablecido en algunos SoundFont.
envvelf=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el seguimiento de velocidad del envolvente de volumen del instrumento. Basado en velocity=64, cambia el tiempo del envolvente según la velocidad. La unidad es +-centésimas/velocidad. Por ejemplo, envvelf=100 significa que el tiempo de ataque será 38 veces mayor a velocity=127. El formato es similar a rate=. En el futuro, la especificación de esta opción puede cambiar.
modkeyf=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el seguimiento de tecla del envolvente de modulación del instrumento. Basado en note=60, cambia el tiempo del envolvente según la nota. La unidad es +-centésimas/tecla. Por ejemplo, modkeyf=100 significa que el tiempo de ataque se duplicará al subir una octava. El formato es similar a rate=. El parámetro de decaimiento y sostenido puede estar preestablecido en algunos SoundFont.
modvelf=ataque:decaimiento:sostenido:release1:release2:release3[,...]
Establece el seguimiento de velocidad del envolvente de modulación del instrumento. Basado en velocity=64, cambia el tiempo del envolvente según la velocidad. La unidad es +-centésimas/velocidad. Por ejemplo, modvelf=100 significa que el tiempo de ataque será 38 veces mayor a velocity=127. El formato es similar a rate=. En el futuro, la especificación de esta opción puede cambiar.
trempitch=num[,...]
Establece la profundidad del cambio de tono del instrumento según el trémolo. El efecto en sí mismo es igual que el vibrato, se utiliza para operar en otro sistema. La unidad son +-centésimas. El formato es similar a rate=.
tremfc=num[,...]
Establece la profundidad del cambio de frecuencia de corte del instrumento según el trémolo. Puede expresar el llamado efecto "glowl". La unidad, etc., son las mismas que para trempitch=.
modpitch=num[,...]
Establece la profundidad del cambio de tono del instrumento según el envolvente de modulación. Puede expresar temporalmente un aumento de tono solo para la etapa de ataque. La unidad, etc., son las mismas que para trempitch=.
modfc=num[,...]
Establece la profundidad del cambio de frecuencia de corte del instrumento según el envolvente de modulación. La unidad, etc., son las mismas que para trempitch=.
fc=num[,...]
Establece el estándar de frecuencia de corte del instrumento. La unidad es Hz. El formato es similar a rate=.
q=num[,...]
Establece la Q (resonancia) del instrumento. La unidad es cB. El formato es similar a rate=.
fckeyf=num
Establece el seguimiento de tecla del filtro del instrumento. Basado en note=60, cambia la frecuencia de corte según la nota. La unidad es +-centésimas/tecla. Por ejemplo, fckeyf=100 significa que cambia lo mismo que el tono.
fcvelf=num
Establece el seguimiento de velocidad del filtro del instrumento. Basado en velocity=127, cambia la frecuencia de corte según la velocidad. La unidad son +-centésimas. En SoundFont, se establece -2400 como valor característico.
qvelf=num
Establece el seguimiento de resonancia del instrumento según la velocidad. Basado en velocity=0, cambia la resonancia según la velocidad. La unidad son +-cB.
default archivo
Cuando aparece un programa MIDI que no está mapeado a un archivo de instrumento, este archivo se pronuncia como sustituto.
map MapID1 desde-banco desde-programa a-banco a-programa
El tono existente se asigna como tono de GS/XG para cada mapa. Se pueden especificar gm2, sc55, sc88, sc88pro, sc8850, xg y xgsfx64 para MapID1.
map MapID2 desde-batería desde-tecla-nota a-batería a-tecla-nota
La batería existente se asigna como batería de GS/XG para cada mapa. Se pueden especificar gm2drum, sc55drum, sc88drum, sc88prodrum, sc8850drum, xgdrum y xgsfx126 para MapID2.
soundfont archivo [opciones]
Lee todo el SoundFont. opciones pueden ser cualquiera de las siguientes:
order=número
Establece el orden de búsqueda de instrumentos. Cuando order=0, primero lee el SoundFont y luego busca las muestras insuficientes en GUS/patch. Cuando order=1, después de leer GUS/patch, busca en SoundFont.
amp=amplificación
Establece la amplificación de todo el SoundFont como amplificación%. Si no se especifica el valor, se establece en 100%.
cutoff=número
Especifica si el LPF en SoundFont está habilitado (1) o deshabilitado (0). Si no se especifica el valor, se considera habilitado.
reso=número
Especifica si la resonancia en SoundFont está habilitada (1) o deshabilitada (0). Si no se especifica el valor, se considera habilitada.
remove
Cancela el SoundFont objetivo de la memoria.
font exclude banco [programa [tecla]]
Suprime la búsqueda del SoundFont de banco, programa. Si la muestra es un set de batería, el banco es 128, el set de batería es programa, y la nota es tecla.
font order número banco [programa [tecla]]
Establece el orden de búsqueda de instrumentos individualmente. El formato es el mismo que font exclude.

Las siguientes sentencias solo están disponibles en la última versión de TiMidity++.

#extension altassign programa1 programa2 ...
Establece la asignación alternativa para el set de batería. Por ejemplo, si desea reproducir los platillos Hi-Hat (números de nota 42, 44 y 46) en el drumset 0 exclusivamente entre sí, especifique:

drumset 0
altassign 42 44 46

Tenga en cuenta que la asignación alternativa del drumset 0 se utiliza por defecto.

#extension comm programa comentario
Especifica el comentario para el número de tono programa. Estos comentarios se muestran en la línea del indicador cuando se inicia TiMidity++ con la opción -int, -iTt.
#extension timeout programa segundo
Especifica el valor de tiempo de espera del programa. Si alguna nota reproducida con el número de tono programa se suspende durante más de segundo segundos, TiMidity++ la cancela.
#extension copydrumset drumset
Copia toda la configuración del drumset al drumset actual.
#extension copybank banco
Copia toda la configuración del banco al banco actual.
#extension copymap a-MapID desde-MapID
Copia toda la configuración de los bancos definidos para el mapa desde-MapID al mapa a-MapID.
#extension HTTPproxy hostname:puerto
Especifica el proxy del protocolo HTTP. hostname y puerto son los del host proxy.
#extension FTPproxy hostname:puerto
Especifica el proxy del protocolo FTP. Igual que HTTP.
#extension mailaddr tu-dirección-de-correo
Especifica la dirección de correo del usuario. Esta dirección se envía al servidor FTP si TiMidity++ accede a algún archivo a través de FTP.
#extension opt opción
Establece el valor de las opciones de arranque.
#extension undef progno
Anula la definición del tono progno del banco de tonos actual.
#extension legato progno {0|1}
Especifica si el legato está habilitado (1) o deshabilitado (0) en progno.
#extension level progno tva_level
Establece el nivel de TVA

NAME

timidity.cfg

configuration file for TiMidity

DESCRIPTION

This file contains configuration parameters for TiMidity++. The parameters are specified in the following format:

variable = value

Blank lines and lines starting with a `#' character are ignored.

The format of the configuration file is similar to that of Xresources(5).

The following parameters are supported:

source file
Specifies a file to be read. You can use ~ and * characters in filenames. This option can be specified multiple times.
include file
Specifies a file to be included. This option can be specified multiple times.
sample-path path
Specifies a path to search for sample files. This option can be specified multiple times.
soundfont file
Specifies a default soundfont file. This option can be specified multiple times.
patch progno, bank, file
Maps a MIDI program number progno and bank number bank to a sample file file. progno and bank can be specified using the format start-end. Example:
patch 0-127,0,instrument.pat
patch 10,1,piano.pat
drum-patch drumno, file
Maps a drum note number drumno to a sample file file. This option can be specified multiple times. drumno can be specified using the format start-end. Example:
drum-patch 35-81,drum.pat
chorus nvoice
Sets the number of chorus voices to nvoice. The default value is 2.
reverb level
Sets the reverb level to level. The default value is 0.
master-volume volume
Sets the master volume to volume. The range is 0 to 100.
midi-volume progno, volume
Sets the MIDI volume for program progno to volume. The range is 0 to 100.
eq n, gain, freq, q
Sets the parameters for equalizer band n. gain is the gain in dB, freq is the center frequency in Hz, and q is the quality factor.
debug level
Sets the debug level to level.
pitch-bend progno, min, max
Sets the pitch bend range for program progno. min is the minimum bend in semitones, and max is the maximum bend in semitones.

VARIABLE

The following variables are supported:

note
The MIDI note number.
velocity
The MIDI velocity.
progno
The MIDI program number.
drumno
The MIDI drum note number.
bend
The pitch bend value.
ctl
The control change value.
pan
The panning value.
mod
The modulation wheel value.
volume
The volume value.
expr
An arbitrary expression.

SYNTAX

#extension command arguments...
This is an extension command. The following commands are supported:
#extension drumset progno
Sets the drum set for program progno. progno can carry out package specification by `,' and/or [start]-[end]. If start and end are omitted, they are assumed to be 0 and 127 respectively.
#extension TVA progno NRPN
Sets the standard value of changing amplification when processing Drum Instrument TVA Level of NRPN. Unless Drum Instrument TVA Level is specified at playing, the amplification is not influenced. progno can carry out package specification by `,' and/or [start]-[end]. If start and end are omitted, they are assumed to be 0 and 127 respectively.
#extension damper progno {0|1}
Specifies whether redamper and half-damper are enable (1) or disable (0) on progno.
#extension playnote progno note
Sets the frequency of pronounce to note. If the frequency of pronounce is specified by GS SysEx Play Note, the pitch is changed appropriately according to the value. progno can carry out package specification by `,' and/or [start]-[end]. If start and end are omitted, they are assumed to be 0 and 127 respectively.

For example:
drumset 0
#extension playnote -37,39,44-46,55-60

#extension delaysend progno level

#extension chorussend progno level

#extension reverbsend progno level
Sets the send level when drum part effect is enable. All initial value are 127. If one of delay, chorus and reverb is at least set up, the effect which is not set as the tone will become the initial value 0. progno can carry out package specification by `,' and/or [start]-[end]. If start and end are omitted, they are assumed to be 0 and 127 respectively.
#extension rnddelay progno msec
For every pronunciation, it is random and less than a maximum of msec delay. The distribution of random value is pink noise (1/f fluctuation) rather than a white noise.

These #extension statements are beginning with character `#' that is the comment flag of old TiMidity (version 0.2i or earlier). So these statements are treated as comment line.
The latest TiMidity++ treats #extension as white-space. So you can omit it.

If any file-name expression ended with character `|' (Ascii 0x7c), the file-name is treated as command and outputs of the command are also examined as arguments of statements.
source command| causes the output of command becomes the argument of source. It is convenient to choose settings of TiMidity++ according to environment. In addition, if a space enters on the way like command |, it will be divided at the time of setting file reading, and will no longer be regarded as a command. This function is applicable to all the places that can specify a file name.

timidity 'cat fild.mid|'

will read from the output of cat fild.mid.
