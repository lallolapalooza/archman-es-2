NOMBRE

iso_8859-11 - Conjunto de caracteres ISO/IEC 8859-11 codificado en octal, decimal y hexadecimal

DESCRIPCIÓN

El estándar ISO/IEC 8859 incluye varias extensiones de 8 bits al conjunto de caracteres ASCII (también conocido como ISO/IEC 646-IRV). ISO/IEC 8859-11 codifica los caracteres utilizados en el idioma tailandés.

Alfabetos ISO/IEC 8859

El conjunto completo de alfabetos ISO/IEC 8859 incluye:

ISO/IEC 8859-1 Idiomas de Europa Occidental (Latin-1)
ISO/IEC 8859-2 Idiomas de Europa Central y Oriental (Latin-2)
ISO/IEC 8859-3 Idiomas del Sudeste de Europa y varios (Latin-3)
ISO/IEC 8859-4 Idiomas escandinavos/bálticos (Latin-4)
ISO/IEC 8859-5 Latín/Cirílico
ISO/IEC 8859-6 Latín/Árabe
ISO/IEC 8859-7 Latín/Griego
ISO/IEC 8859-8 Latín/Hebreo
ISO/IEC 8859-9 Modificación de Latin-1 para turco (Latin-5)
ISO/IEC 8859-10 Idiomas lapón/nórdico/esquimal (Latin-6)
ISO/IEC 8859-11 Latín/Tailandés
ISO/IEC 8859-13 Idiomas de la cuenca del Báltico (Latin-7)
ISO/IEC 8859-14 Celta (Latin-8)
ISO/IEC 8859-15 Idiomas de Europa Occidental (Latin-9)
ISO/IEC 8859-16 Rumano (Latin-10)

NAME

tis-620 - TIS 620-2533 Thai character set

DESCRIPTION

The TIS 620-2533 standard defines a character set for the Thai language. This character set is also known as TIS-620. ISO/IEC 8859-11 is an international standard that is almost identical to TIS 620-2533.

The character set is encoded using 8 bits, but it is commonly represented as a 7-bit ASCII character set with an additional 128 characters for Thai letters and symbols. The following table shows the characters defined in ISO/IEC 8859-11, which are also included in TIS 620-2533.
