timespec(3type) timespec(3type)

NOMBRE

timespec - tiempo en segundos y nanosegundos

BIBLIOTECA

Biblioteca estándar C (libc)

SINOPSIS

#include <time.h>
struct timespec {
    time_t     tv_sec;   /* Segundos */
    /* ... */  tv_nsec;  /* Nanosegundos [0, 999'999'999] */
};

DESCRIPCIÓN

Describe tiempos en segundos y nanosegundos.

tv_nsec es de un tipo con signo definido por la implementación, capaz de contener el rango especificado. Bajo glibc, suele ser long, y long long en X32. Puede ser casteado de forma segura a cualquier tipo entero concreto de 32 bits para su procesamiento.

VERSIONES

Antes de C23, tv_nsec era long.

ESTÁNDARES

C11, POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan este tipo: <aio.h>, <mqueue.h>, <sched.h>, <signal.h>, <sys/select.h>, y <sys/stat.h>.

VER TAMBIÉN

clock_gettime(2), clock_nanosleep(2), nanosleep(2), timerfd_gettime(2), timer_gettime(2), time_t(3type), timeval(3type)
