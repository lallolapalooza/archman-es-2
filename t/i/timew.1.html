TIMEW(1) Manuales de usuario TIMEW(1)

NOMBRE

timew - un rastreador de tiempo de línea de comandos

SINOPSIS

timew [--version|--help]
timew [<comando> [<arg>...]]

DESCRIPCIÓN

Timewarrior es un rastreador de tiempo de línea de comandos. Te permite hacer un seguimiento de tu tiempo fácilmente y generar informes resumidos.

Esto es una referencia, no un tutorial. Si buscas un tutorial, consulta la documentación en línea aquí:

https://timewarrior.net/docs/

Cuando se ejecuta sin argumentos u opciones, se ejecuta el comando predeterminado, que indica si hay algún seguimiento activo y, en caso afirmativo, muestra un resumen y sale con el código 0. Si no hay seguimiento de tiempo activo, el código de salida es 1.

OPCIONES

--version

Muestra información de la versión de Timewarrior

--help

Muestra información de uso de Timewarrior

COMANDOS DE TIMEWARRIOR

Timewarrior soporta muchos comandos. Alfabéticamente:

timew-annotate(1)

Añade anotaciones a los intervalos

timew-cancel(1)

Cancela el seguimiento de tiempo

timew-config(1)

Obtiene y establece la configuración de Timewarrior

timew-continue(1)

Reanuda el seguimiento de un intervalo existente

timew-day(1)

Muestra el gráfico del día

timew-delete(1)

Elimina intervalos

timew-diagnostics(1)

Muestra información de diagnóstico

timew-export(1)

Exporta el tiempo rastreado en JSON

timew-extensions(1)

Lista las extensiones disponibles

timew-get(1)

Muestra valores DOM

timew-help(1)

Muestra ayuda

timew-join(1)

Une intervalos

timew-lengthen(1)

Alarga intervalos

timew-modify(1)

Cambia la hora de inicio o fin de un intervalo

timew-month(1)

Muestra el gráfico del mes

timew-move(1)

Cambia la hora de inicio del intervalo

timew-report(1)

Ejecuta un informe de extensión

timew-resize(1)

Establece la duración del intervalo

timew-retag(1)

Reemplaza etiquetas en intervalos

timew-shorten(1)

Acorta intervalos

timew-show(1)

Muestra la configuración

timew-split(1)

Divide intervalos

timew-start(1)

Inicia el seguimiento de tiempo

timew-stop(1)

Detiene el seguimiento de tiempo

timew-summary(1)

Muestra un resumen del seguimiento de tiempo

timew-tag(1)

Añade etiquetas a los intervalos

timew-tags(1)

Muestra una lista de etiquetas

timew-track(1)

Añade intervalos a la base de datos

timew-undo(1)

Deshace comandos de Timewarrior

timew-untag(1)

Elimina etiquetas de intervalos

timew-week(1)

Muestra el gráfico de la semana

ARCHIVOS

Sistemas no Unix

~/.timewarrior/timewarrior.cfg

Archivo de configuración del usuario.

~/.timewarrior/data/YYYY-MM.data

Archivos de datos de seguimiento de tiempo.

Sistemas Unix

${XDG_CONFIG_HOME:-$HOME/.config}/timewarrior/timewarrior.cfg

Archivo de configuración del usuario si el directorio heredado ~/.timewarrior no existe.

${XDG_DATA_HOME:-$HOME/.local/share}/timewarrior/data/YYYY-MM.data

Archivos de datos de seguimiento de tiempo si el directorio heredado ~/.timewarrior no existe.
