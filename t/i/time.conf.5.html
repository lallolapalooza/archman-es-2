TIME.CONF(5) Manual de Linux-PAM TIME.CONF(5)

NOMBRE

time.conf - archivo de configuración para el módulo pam_time

DESCRIPCIÓN

El módulo PAM pam_time no autentica al usuario, sino que restringe el acceso a un sistema y/o aplicaciones específicas en diferentes momentos del día y en días específicos o a través de varias líneas de terminal. Este módulo se puede configurar para denegar el acceso a usuarios (individuales) basándose en su nombre, la hora del día, el día de la semana, el servicio al que se están aplicando y su terminal desde el que están realizando su solicitud.

Para que este módulo funcione correctamente, debe existir un archivo /etc/security/time.conf correctamente formateado. Se ignoran los espacios en blanco y las líneas pueden extenderse con '\' (saltos de línea escapados). El texto que sigue a '#' se ignora hasta el final de la línea.

La sintaxis de las líneas es la siguiente:

servicios;ttys;usuarios;tiempos

En otras palabras, cada regla ocupa una línea, terminada por un salto de línea o el inicio de un comentario; un '#'. Contiene cuatro campos separados por punto y coma, ';'.

El primer campo, el campo de servicios, es una lista lógica de nombres de servicio PAM a los que se aplica la regla.

El segundo campo, el campo tty, es una lista lógica de nombres de terminal a los que se aplica esta regla.

El tercer campo, el campo de usuarios, es una lista lógica de usuarios o un netgroup de usuarios a los que se aplica esta regla.

Una lista lógica significa tokens individuales que opcionalmente se prefijan con '!' (no lógico) y se separan con '&' (y lógico) y '|' (o lógico).

Para estos elementos, el comodín simple '*' solo se puede usar una vez. Con netgroups no se permiten comodines ni operadores lógicos.

El campo de tiempos se utiliza para indicar los momentos en los que se aplica esta regla. El formato aquí es una lista lógica de entradas de día/rango de tiempo. Los días se especifican mediante una secuencia de entradas de dos caracteres, por ejemplo, MoTuSa significa lunes, martes y sábado. Tenga en cuenta que los días repetidos se establecen MoMo = ningún día, y MoWk = todos los días laborables menos el lunes. Las combinaciones de dos caracteres aceptadas son Mo Tu We Th Fr Sa Su Wk Wd Al, las dos últimas siendo días de fin de semana y todos los 7 días de la semana respectivamente. Como ejemplo final, AlFr significa todos los días excepto el viernes.

Cada día/rango de tiempo puede prefijarse con un '!' para indicar "cualquier cosa excepto". La parte del rango de tiempo son dos horas de 24 horas HHMM, separadas por un guion, que indican la hora de inicio y fin (si la hora de fin es menor que la hora de inicio, se considera que se aplica al día siguiente).

Para que una regla esté activa, TODOS los servicios+ttys+usuarios deben ser satisfechos por el proceso que la aplica.

Nota: Actualmente no hay ningún demonio que aplique el final de una sesión. Esto necesita ser corregido.

Las reglas mal formateadas se registran como errores utilizando syslog(3).

EJEMPLOS

Estas son algunas líneas de ejemplo que podrían especificarse en /etc/security/time.conf.

A todos los usuarios excepto a root se les deniega el acceso a la consola de inicio de sesión en todo momento:

login ; tty* & !ttyp* ; !root ; !Al0000-2400

Los juegos (configurados para usar PAM) solo deben ser accesibles fuera del horario laboral. Esta regla no se aplica al usuario waster:

games ; * ; !waster ; Wd0000-2400 | Wk1800-0800
