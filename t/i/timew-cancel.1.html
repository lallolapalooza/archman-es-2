NOMBRE

timew-cancel - cancelar el seguimiento del tiempo

SINOPSIS

timew cancel

DESCRIPCIÓN

Si hay un intervalo abierto, se abandona.

EJEMPLOS

Cancelar con seguimiento de tiempo activo

$ timew start
...
$ timew cancel
Canceled active time tracking.

Esto elimina el intervalo abierto.

Cancelar sin seguimiento de tiempo activo

...
$ timew stop
$ timew cancel
There is no active time tracking.

Cancelar no tiene efecto, solo se imprime una advertencia.

VER TAMBIÉN

timew-continue(1), timew-start(1), timew-stop(1), timew-track(1)
