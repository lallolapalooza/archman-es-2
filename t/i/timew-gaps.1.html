NOMBRE

timew-gaps - muestra huecos de seguimiento de tiempo

SINOPSIS

timew gaps [<rango>] [<etiqueta>...]

DESCRIPCIÓN

Muestra un resumen del tiempo que no está ni rastreado ni excluido del rastreo.

La configuración 'reports.gaps.range' anula el rango de fechas predeterminado. La indicación ':blank' hace que solo se muestre el tiempo excluido, sin tiempo rastreado. El rango de fechas predeterminado que se muestra es ':day'.

INDICACIONES

Además de las indicaciones de rango (ver timew-hints(7)), el informe de huecos se adhiere a las siguientes indicaciones:

:blank

Muestra solo el tiempo que está excluido del rastreo, sin mostrar ningún tiempo rastreado.

CONFIGURACIÓN

reports.gaps.range

Para los informes que muestran un rango de datos, esta configuración anulará el valor predeterminado. El valor debe ser una indicación de rango, ver timew-hints(7).
