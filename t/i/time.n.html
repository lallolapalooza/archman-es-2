time(n) Comandos integrados de Tcl time(n)

NOMBRE

time - Mide el tiempo de ejecución de un script

SINOPSIS

time script ?count?

DESCRIPCIÓN

Este comando llamará al intérprete Tcl count veces para evaluar script (o una vez si count no se especifica). Luego devolverá una cadena con el formato

503.2 microsegundos por iteración

que indica la cantidad promedio de tiempo requerida por iteración, en microsegundos. El tiempo se mide en tiempo transcurrido, no en tiempo de CPU.

EJEMPLO

Estimar cuánto tiempo tarda un simple bucle for de Tcl en contar hasta mil:

time {
    for {set i 0} {$i<1000} {incr i} {
        # cuerpo vacío
    }
}
