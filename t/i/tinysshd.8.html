tinysshd(8) Manual del Administrador del Sistema tinysshd(8)

NOMBRE

tinysshd - Demonio SSH Diminuto

SINOPSIS

tinysshd [ opciones ] dir_claves

DESCRIPCIÓN

tinysshd es un servidor SSH minimalista que implementa solo un subconjunto de las características de SSHv2.

tinysshd solo soporta criptografía segura (mínimo 128 bits de seguridad, protegido contra ataques de tiempo de caché)

tinysshd no implementa criptografía antigua (como RSA, DSA, HMAC-MD5, HMAC-SHA1, 3DES, RC4, ...)

tinysshd no implementa características inseguras (como autenticación por contraseña o basada en host)

tinysshd no tiene características como: protocolo SSH1, compresión, reenvío de puertos, reenvío de agente, reenvío X11 ...

tinysshd no usa asignación dinámica de memoria (sin fallos de asignación, etc.)

OPCIONES

-q
sin mensajes de error
-Q
mostrar mensajes de error (por defecto)
-v
mostrar información adicional
-s
habilitar criptografía de última generación (por defecto)

firma - ssh-ed25519

intercambio de claves - curve25519-sha256

simétrico - chacha20-poly1305@openssh.com

-S
deshabilitar criptografía de última generación
-p
habilitar criptografía post-cuántica (por defecto)

firma - TODO (aún no implementado)

intercambio de claves - sntrup761x25519-sha512@openssh.com

simétrico - chacha20-poly1305@openssh.com

-P
deshabilitar criptografía post-cuántica
-l
usar syslog en lugar de la salida de error estándar (útil para ejecutar desde inetd)
-L
no usar syslog, usar la salida de error estándar (por defecto)
-x nombre=comando
añadir comando de subsistema (ej: sftp=/usr/libexec/openssh/sftp-server)
-e comando
ejecutar el comando dado en lugar de iniciar el shell (deshabilita las solicitudes de canal de exec/subsystem)
dir_claves
directorio que contiene las claves de TinySSH, típicamente /etc/tinyssh/sshkeydir

AUTORIZACIÓN

tinysshd solo soporta autorización por clave pública a través de AuthorizedKeysFile ~/.ssh/authorized_keys. Cada línea del archivo contiene una clave en el formato "tipoclave clave-codificada-en-base64 comentario". tinyssh solo soporta el tipo de clave "ssh-ed25519".

Ejemplo de ~/.ssh/authorized_keys:

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAILV5AGhGQ1QVXjBWhTKJP3vrqE3isL4ivisBailQ14gS comentario

EJECUCIÓN

TCPSERVER
tcpserver -HRDl0 0.0.0.0 22 /usr/sbin/tinysshd -v /etc/tinyssh/sshkeydir &
BUSYBOX
busybox tcpsvd 0 22 tinysshd -v /etc/tinyssh/sshkeydir &
INETD
/etc/inetd.conf:
ssh stream tcp nowait root /usr/sbin/tinysshd tinysshd -l -v /etc/tinyssh/sshkeydir
SYSTEMD
tinysshd.socket: 
[Unit]
Description=Socket del servidor TinySSH
ConditionPathExists=!/etc/tinyssh/disable_tinysshd
[Socket]
ListenStream=22
Accept=yes
[Install]
WantedBy=sockets.target
tinysshd@.service: 
[Unit]
Description=Servidor SSH Diminuto
After=network.target auditd.service
[Service]
ExecStartPre=-/usr/sbin/tinysshd-makekey -q /etc/tinyssh/sshkeydir
EnvironmentFile=-/etc/default/tinysshd
ExecStart=/usr/sbin/tinysshd ${TINYSSHDOPTS} -- /etc/tinyssh/sshkeydir
KillMode=process
SuccessExitStatus=111
StandardInput=socket
StandardError=journal
[Install]
WantedBy=multi-user.target
