Paquete: tcl

timerate(n) Comandos integrados de Tcl timerate(n)

NOMBRE

timerate - Mediciones de rendimiento calibradas de la ejecución de scripts

SINOPSIS

timerate script ?tiempo? ?max-count?

timerate ?-direct? ?-overhead doble? script ?tiempo? ?max-count?

timerate ?-calibrate? ?-direct? script ?tiempo? ?max-count?

DESCRIPCIÓN

El comando timerate realiza mediciones de rendimiento calibradas de un comando o script Tcl, script. El script debe estar escrito de manera que pueda ejecutarse varias veces durante el proceso de medición del rendimiento. El tiempo se mide en tiempo transcurrido usando la resolución de temporizador más fina posible, no el tiempo de CPU; si script interactúa con el sistema operativo, se incluye el costo de esa interacción. Este comando puede usarse para proporcionar información sobre el rendimiento de un script o comando Tcl, y puede ayudar a determinar cuellos de botella y optimizar el rendimiento de la aplicación.

La primera y segunda forma evaluarán script hasta que transcurra el intervalo tiempo dado en milisegundos, o durante 1000 milisegundos (1 segundo) si no se especifica tiempo.

El parámetro max-count podría imponer adicionalmente una restricción adicional por el número máximo de iteraciones para evaluar el script. Si se especifica max-count, la evaluación se detendrá cuando se alcance este recuento de iteraciones o se exceda el tiempo.

Devolverá una lista Tcl canónica de la forma:

0.095977 µs/# 52095836 # 10419167 #/sec 5000.000 net-ms

que indica:

  • la cantidad promedio de tiempo requerida por iteración, en microsegundos ([lindex $resultado 0])
  • el recuento de cuántas veces se ejecutó ([lindex $resultado 2])
  • la tasa estimada por segundo ([lindex $resultado 4])
  • el tiempo de ejecución real estimado sin la sobrecarga de medición ([lindex $resultado 6])

Las siguientes opciones pueden ser suministradas al comando timerate:

-calibrate
Para medir scripts muy rápidos con la mayor precisión posible, puede ser necesario un proceso de calibración. La opción -calibrate se usa para calibrar timerate, calculando la sobrecarga estimada del script dado como la sobrecarga predeterminada para futuras invocaciones del comando timerate. Si el parámetro tiempo no se especifica, el procedimiento de calibración se ejecuta hasta por 10 segundos.

Tenga en cuenta que la calibración no es segura para hilos en la implementación actual.

-overhead doble
El parámetro -overhead suministra una estimación (en microsegundos) de la sobrecarga de medición de cada iteración del script probado. Esta cantidad se restará del tiempo medido antes de informar los resultados. Esto puede ser útil para eliminar el costo de los comandos de reinicio del estado del intérprete del script que se está midiendo.
-direct
La opción -direct causa la ejecución directa del script suministrado, sin compilación, de manera similar al comando time. Puede usarse para medir el costo de Tcl_EvalObjEx, de la invocación de listas canónicas y de las versiones no compiladas de comandos bytecode.

A diferencia del comando time, que ejecuta el script probado durante un número fijo de iteraciones, el comando timerate lo ejecuta durante un tiempo fijo. Además, la variante compilada del script se usará durante todo el período de medición, como si el script fuera parte de un procedimiento compilado, si la opción -direct no se especifica. El período de tiempo fijo y la posibilidad de compilación permiten resultados más precisos y evitan tiempos de ejecución muy largos para scripts lentos, lo que lo hace práctico para medir scripts con tiempos de ejecución muy inciertos.

EJEMPLOS

Estime cuánto tiempo tarda un simple bucle for de Tcl (incluyendo operaciones en la variable i) en contar hasta diez:

# calibrar
timerate -calibrate {}
# medir
timerate { for {set i 0} {$i<10} {incr i} {} } 5000

Estime cuánto tiempo tarda un simple bucle for de Tcl, ignorando la sobrecarga de la gestión de la variable que controla el bucle:

# calibrar para la sobrecarga de operaciones de variables
set i 0; timerate -calibrate {expr {$i<10}; incr i} 1000
# medir
timerate {
    for {set i 0} {$i<10} {incr i} {}
} 5000

Estime la velocidad de cálculo de la hora del día usando solo clock format, ignorando la sobrecarga de la parte del script que prepara el tiempo para que se calcule:

# calibrar
timerate -calibrate {}
# estimar sobrecarga
set tm 0
set ovh [lindex [timerate {
    incr tm [expr {24*60*60}]
}] 0]
# medir usando sobrecarga estimada
set tm 0
timerate -overhead $ovh {
    clock format $tm -format %H
    incr tm [expr {24*60*60}]; # la sobrecarga de esto se ignora
} 5000
