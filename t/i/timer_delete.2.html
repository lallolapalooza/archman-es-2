timer_delete(2) Manual de llamadas al sistema timer_delete(2)

NOMBRE

timer_delete - eliminar un temporizador POSIX por proceso

BIBLIOTECA

Biblioteca en tiempo real (librt, -lrt)

SINOPSIS

#include <time.h>
int timer_delete(timer_t timerid);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

timer_delete():

    _POSIX_C_SOURCE >= 199309L

DESCRIPCIÓN

timer_delete() elimina el temporizador cuyo ID se proporciona en timerid. Si el temporizador estaba armado en el momento de esta llamada, se desarma antes de ser eliminado. El tratamiento de cualquier señal pendiente generada por el temporizador eliminado no está especificado.

VALOR DE RETORNO

En caso de éxito, timer_delete() devuelve 0. En caso de error, se devuelve -1 y errno se establece para indicar el error.

ERRORES

EINVAL
timerid no es un ID de temporizador válido.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

Linux 2.6. POSIX.1-2001.

VER TAMBIÉN

clock_gettime(2), timer_create(2), timer_getoverrun(2), timer_settime(2), time(7)
