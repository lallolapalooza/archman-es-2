TIFICC(1) Manual de comandos generales TIFICC(1)

NOMBRE

tificc - aplicador de perfiles ICC de little cms para TIFF.

SINOPSIS

tificc [opciones] entrada.tif salida.tif

DESCRIPCIÓN

lcms es un motor CMM independiente, que se encarga de la gestión del color. Implementa una transformación rápida entre perfiles ICC. tificc es un aplicador de perfiles ICC de little cms para TIFF.

OPCIONES

-a
Maneja canales > 4 como alfa.
-b
Compensación del punto negro.
-c NÚM
Precalcula la transformación (0=Apagado, 1=Normal, 2=Alta resolución, 3=Baja resolución) [valor predeterminado 1].
-d NÚM
Estado de adaptación del observador (solo col. abs.), (0..1.0, valor flotante) [predeterminado 0.0].
-e
Incrusta el perfil de destino.
-g
Marca los colores fuera de gama en la prueba de pantalla.
-h NÚM
Muestra un resumen de opciones y ejemplos (0=ayuda, 1=Ejemplos, 2=Perfiles integrados, 3=Información de contacto)
-i perfil
Perfil de entrada (predeterminado sRGB).
-k límitedeTinta
Límite de tinta en % (solo CMYK), (0..400.0, valor flotante) [predeterminado 400.0].
-l perfil
Transforma mediante el perfil de enlace de dispositivo.
-m VERIFICAR: ¿son posibles valores fuera de 0..3?
Intención de prueba de pantalla [predeterminada 0].
-n
Ignora el perfil incrustado en la entrada.
-o perfil
Perfil de salida (predeterminado sRGB).
-p perfil
Perfil de prueba de pantalla.
-s nuevoperfil
Guarda el perfil incrustado como nuevoperfil.
-t NÚM
Intención de renderizado
0=Perceptual [predeterminado]
1=Colorimétrico relativo
2=Saturación
3=Colorimétrico absoluto
10=Perceptual preservando tinta negra
11=Colorimétrico relativo preservando tinta negra
12=Saturación preservando tinta negra
13=Perceptual preservando plano negro
14=Colorimétrico relativo preservando plano negro
15=Saturación preservando plano negro
-v
Detallado.
-w NÚM
Profundidad de salida (8, 16 o 32). Usar 32 para punto flotante.

PERFILES INTEGRADOS

*Lab2  -- CIEL*a*b v2 basado en D50
*Lab4  -- CIEL*a*b v4 basado en D50
*Lab   -- CIEL*a*b v4 basado en D50
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espacio de color sRGB
*Gray22 - Monocromo de Gamma 2.2
*Gray30 - Monocromo de Gamma 3.0
*null   - Negro monocromo para toda la entrada
*Lin2222- Linealización CMYK de gamma 2.2 en cada canal

EJEMPLOS

Para corrección de color de escáner a sRGB:
	tificc -iscanner.icm entrada.tif salida.tif
Para convertir de monitor1 a monitor2:
	tificc -imon1.icm -omon2.icm entrada.tif salida.tif
Para hacer una separación CMYK:
	tificc -oprinter.icm entradaRGB.tif salidaCMYK.tif
Para recuperar sRGB de una separación CMYK:
	tificc -iprinter.icm entradaCMYK.tif salidaRGB.tif
Para convertir de TIFF CIELab a sRGB
	tificc -i*Lab entrada.tif salida.tif
