TIG(1) Manual de Tig TIG(1)

NOMBRE

tig - interfaz en modo texto para Git

SINOPSIS

tig        [opciones] [revisiones] [--] [rutas]
tig log    [opciones] [revisiones] [--] [rutas]
tig show   [opciones] [revisiones] [--] [rutas]
tig reflog [opciones] [revisiones]
tig blame  [opciones] [rev] [--] ruta
tig grep   [opciones] [patrón]
tig refs   [opciones]
tig stash  [opciones]
tig status
tig <      [salida del comando Git]

DESCRIPCIÓN

Tig es una interfaz en modo texto basada en ncurses para git(1). Funciona principalmente como un navegador de repositorios Git, pero también puede ayudar a preparar cambios para confirmar a nivel de fragmento y actuar como un paginador para la salida de varios comandos Git.

OPCIONES

Las opciones de línea de comandos reconocidas por Tig incluyen todas las opciones válidas de git-log(1) y git-diff(1), así como los siguientes subcomandos y opciones específicas de Tig. El primer parámetro de línea de comandos que no comienza con "-" se interpreta como una especificación de revisión o una ruta y finalizará el análisis de opciones. Todas las opciones adicionales se pasarán al comando Git subyacente.

Tenga en cuenta que esto significa que los argumentos de las opciones deben especificarse juntos. Por ejemplo, ejecute tig -Sfoo en lugar de tig -S foo, y tig --grep=foo en lugar de tig --grep foo, de lo contrario foo se interpretará como una revisión en lugar de un argumento.

show

Abre la vista de diferencias usando las opciones de git-show(1) dadas.

blame

Muestra el archivo dado anotado por commits. Toma cero o más opciones de git-blame(1). Opcionalmente limitado desde una revisión dada.

status

Inicia la vista de estado.

log

Inicia la vista de registro, mostrando la salida de git-log(1).

reflog

Inicia la vista de reflog.

refs

Inicia la vista de referencias. Se muestran todas las referencias a menos que se limiten mediante el uso de uno de los parámetros --branches, --remotes o --tags.

stash

Inicia la vista de stash.

grep

Abre la vista grep. Admite las mismas opciones que git-grep(1).

+<número>

Muestra la primera vista con la línea <número> visible y seleccionada.

-v, --version

Muestra la versión y sale.

-h, --help

Muestra el mensaje de ayuda y sale.

-C <ruta>

Se ejecuta como si Tig se hubiera iniciado en <ruta> en lugar del directorio de trabajo actual.

MODO PAGINADOR

Tig entra en modo paginador cuando se proporciona entrada a través de stdin y admite los siguientes subcomandos y opciones:

•Cuando se especifica el subcomando show y se da la opción --stdin, se asume que stdin es una lista de IDs de commit y se reenviará al comando git-show(1) subyacente de la vista diff. Por ejemplo:
$ git rev-list --author=vivien HEAD | tig show --stdin
•Cuando se da --stdin, se asume que stdin es una lista de IDs de commit y se reenviará al comando git-log(1) subyacente de la vista principal. Por ejemplo:
$ tig --no-walk --stdin < cherry-picks.txt
•Cuando se da --pretty=raw, se asume que stdin es una salida formateada como "pretty=raw", similar a la de git-log(1). Por ejemplo:
$ git reflog --pretty=raw | tig --pretty=raw

Cuando no se dan subcomandos ni opciones, la vista paginador se utilizará para mostrar la entrada del comando Git dada en stdin. La vista paginador asume que la entrada proviene de git-log(1) o git-diff(1) y la resaltará de manera similar a las vistas de registro y diferencias. Por ejemplo:

$ git log -Schange -p --raw | tig

EJEMPLOS

Muestra la lista de commits de la rama actual:

$ tig

Muestra commits de una o más ramas:

$ tig test master

Actúa como si todas las referencias en refs/ se listaran en la línea de comandos:

$ tig --all

Muestra las diferencias entre dos ramas:

$ tig test..master

Muestra los cambios para las versiones de submódulos:

$ tig --submodule

Muestra los cambios para un solo archivo:

$ tig -- README

Muestra el contenido del archivo README en una revisión específica:

$ tig show tig-0.8:README

Muestra revisiones entre dos fechas para un archivo específico:

$ tig --after="2004-01-01" --before="2006-05-16" -- README

Anota el archivo con detección de copias habilitada:

$ tig blame -C README

Muestra la lista de stashes:

$ tig stash

Busca en todos los archivos líneas que contengan DEFINE_ENUM:

$ tig grep -p DEFINE_ENUM

Muestra referencias (ramas, remotos y etiquetas):

$ tig refs

Utiliza la diferencia de palabras en la vista de diferencias:

$ tig --word-diff=plain

VARIABLES DE ENTORNO

Además de las variables de entorno utilizadas por Git (por ejemplo, GIT_DIR), Tig define las siguientes. Las variables de entorno relacionadas con comandos tienen acceso al estado interno de Tig a través de variables de reemplazo, como %(commit) y %(blob). Consulte tigrc(5) para obtener una lista completa.

TIGRC_USER

Ruta del archivo de configuración del usuario (por defecto ~/.tigrc o $XDG_CONFIG_HOME/tig/config).

TIGRC_SYSTEM

Ruta del archivo de configuración a nivel de sistema (por defecto {sysconfdir}/tigrc). Defina a una cadena vacía para usar la configuración incorporada.

TIG_LS_REMOTE

Comando para recuperar todas las referencias del repositorio. El comando debe producir datos en el mismo formato que git-ls-remote(1).

TIG_DIFF_OPTS

Las opciones de diff a utilizar en la vista de diff. La vista de diff utiliza git-show(1) para el formato y siempre pasa --patch-with-stat. También puede configurar la opción diff-options en el archivo de configuración.

TIG_TRACE

Ruta del archivo de rastreo donde se registran las informaciones sobre los comandos Git.

TIG_SCRIPT

Ruta del script que se ejecutará automáticamente al arrancar. Si esta variable de entorno se define como una cadena vacía, el script se lee de stdin. El script se interpreta línea por línea y puede contener comandos de prompt y mapeos de teclas. Tenga en cuenta que el carácter < debe codificarse como <LT> dentro del script. 
Por ejemplo: TIG_SCRIPT=<(echo :set main-view-commit-title-graph = no) tig

TIG_NO_DISPLAY

Abre Tig sin renderizar nada en la terminal. Esto fuerza a Ncurses a escribir en /dev/null. El uso principal es para pruebas automatizadas de Tig.

TIG_EDITOR

El comando del editor que se utilizará al visitar archivos. Esta variable de entorno anula (en orden de precedencia) $GIT_EDITOR, la configuración core.editor, $VISUAL y $EDITOR, por lo que permite usar un editor diferente al que usa Git. Se pretende que el valor sea interpretado por el shell cuando se usa.

ARCHIVOS

$XDG_CONFIG_HOME/tig/config, ~/.config/tig/config, ~/.tigrc

El archivo de configuración de usuario de Tig se carga de la siguiente manera. Si $XDG_CONFIG_HOME está configurado, lea la configuración del usuario desde $XDG_CONFIG_HOME/tig/config. Si $XDG_CONFIG_HOME está vacío o no está definido, lea la configuración del usuario desde ~/.config/tig/config si existe y recurra a ~/.tigrc si no existe. Consulte tigrc(5) para ver ejemplos.

/etc/tigrc

Archivo de configuración a nivel de sistema.

$GIT_DIR/config, ~/.gitconfig, /etc/gitconfig

Archivos de configuración de Git

FILES

$XDG_DATA_HOME/tig/history, ~/.local/share/tig/history, ~/.tig_history

Cuando se compila con soporte readline, Tig escribe un historial persistente de comandos y búsquedas. La ubicación del archivo de historial se determina de la siguiente manera. Si $XDG_DATA_HOME está configurado y $XDG_DATA_HOME/ existe, crea $XDG_DATA_HOME/tig/ si es necesario y almacena el historial en $XDG_DATA_HOME/tig/history. Si $XDG_DATA_HOME está vacío o no definido, almacena el historial en ~/.local/share/tig/history si el directorio ~/.local/share/tig/ existe, y recurre a ~/.tig_history si no existe.
