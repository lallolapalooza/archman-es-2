TIMEW-ANNOTATE(1) Manuales de usuario TIMEW-ANNOTATE(1)

NOMBRE

timew-annotate - añade una anotación a los intervalos

SINOPSIS

timew annotate [<id>...] <anotacion>

DESCRIPCIÓN

El comando 'annotate' se usa para añadir una anotación a un intervalo.

Ver el comando 'summary' para ver cómo mostrar el <id> y la <anotacion> de un intervalo.

EJEMPLOS

Anotar un único intervalo

Ejecuta el comando con un id y la anotación:

$ timew annotate @2 'Lorem ipsum'
Anotado @2 con "Lorem ipsum"

Eliminar una anotación

Anotar un intervalo con una cadena vacía elimina la anotación:

$ timew annotate @1 ''
Anotación eliminada de @1

Anotar múltiples intervalos

Puedes anotar múltiples intervalos con la misma anotación a la vez, especificando sus ids:

$ timew annotate @2 @10 @23 'Lorem ipsum'
Anotado @1 con "Lorem ipsum"
Anotado @10 con "Lorem ipsum"
Anotado @23 con "Lorem ipsum"

Anotar el intervalo abierto actual

Si hay seguimiento de tiempo activo, puedes omitir el ID cuando quieras añadir una anotación al intervalo abierto actual:

$ timew start foo
...
$ timew annotate bar
Anotado @1 con "bar"

Esto resulta en que el intervalo actual tenga la etiqueta 'foo' y la anotación 'bar'.

ERRORES & LIMITACIONES

El comando summary trunca las anotaciones de más de 15 caracteres. Para mostrar anotaciones más largas, se puede usar el comando 'export', o un informe personalizado.

Actualmente, el comando de anotación elige el último token de la línea de comandos y lo usa como anotación. Es decir, usar comillas al revés en un comando de anotación como

$ timew annotate @1 lorem ipsum

resultará en que el intervalo @1 solo tenga 'ipsum' como su anotación. Usa comillas para evitar esto.
