TIPC-BEARER(8) Linux TIPC-BEARER(8)

NOMBRE

tipc-bearer - mostrar o modificar portadores TIPC

SINOPSIS


tipc bearer add media udp name NOMBRE remoteip IPREMOTO

tipc bearer enable [ domain DOMINIO ] [ priority PRIORIDAD ] media
{ { eth | ib } device DISPOSITIVO } |
{ udp name NOMBRE localip IPLOCAL [ localport PUERTOLOCAL ] [ remoteip IPREMOTO ] [ remoteport PUERTOREMOTO ] }

tipc bearer disable media
{ { eth | ib } device DISPOSITIVO } |
{ udp name NOMBRE }

tipc bearer set { priority PRIORIDAD | tolerance TOLERANCIA | window VENTANA } media
{ { eth | ib } device DISPOSITIVO } |
{ udp name NOMBRE }

tipc bearer get [ priority | tolerance | window ] media
{ { eth | ib } device DISPOSITIVO } |
{ udp name NOMBRE [ localip | localport | remoteip | remoteport ] }

tipc bearer list

OPCIONES

Opciones (flags) que se pueden pasar en cualquier parte de la cadena de comandos.

-h, --help
Muestra la ayuda sobre el último comando válido. Por ejemplo, tipc bearer --help mostrará la ayuda de portadores y tipc --help mostrará la ayuda general. La posición de la opción en la cadena es irrelevante.

DESCRIPCIÓN

Identificación del portador

media MEDIA

Especifica el tipo de medio TIPC para que opere un portador particular. Los diferentes tipos de medio tienen diferentes formas de identificar un portador único. Por ejemplo, ib e eth identifican un portador con un DISPOSITIVO mientras que udp identifica un portador con una IPLOCAL y un NOMBRE

ib - Infiniband

eth - Ethernet

udp - User Datagram Protocol (UDP)

name NOMBRE

Identificador lógico del portador válido para portadores en medio udp.
device DISPOSITIVO

Dispositivo físico del portador válido para portadores en medios eth e ib.

Propiedades del portador

domain

El dominio de direccionamiento (región) en el que un portador establecerá enlaces y aceptará solicitudes de establecimiento de enlaces.
priority

Prioridad de enlace predeterminada heredada por todos los enlaces que se establezcan posteriormente sobre un portador. Un solo portador solo puede alojar un enlace a un nodo en particular. Esto significa que la prioridad de enlace predeterminada para un portador típicamente afecta qué portador usar al comunicarse con un nodo en particular en una configuración de múltiples portadores. Para más información sobre la prioridad de enlace ver tipc-link(8)
tolerance

Tolerancia de enlace predeterminada heredada por todos los enlaces que se establezcan posteriormente sobre un portador. Para más información sobre la tolerancia de enlace ver tipc-link(8)
window

Tamaño de ventana de enlace predeterminado heredado por todos los enlaces que se establezcan posteriormente sobre un portador. Para más información sobre el tamaño de la ventana de enlace ver tipc-link(8)

Opciones del portador UDP

localip IPLOCAL

Especifica una dirección IP v4/v6 local para un portador udp.
localport PUERTOLOCAL

Especifica el puerto local para un portador udp. Se utiliza el puerto predeterminado 6118 si no se especifica ningún puerto.
remoteip IPREMOTO

Especifica una IP remota para un portador udp. Si no se especifica ninguna IP remota, un portador udp se ejecuta en modo multicast e intenta autodetectar sus vecinos. La dirección IP multicast se genera basándose en el ID de red TIPC. Si se especifica una IP remota, el portador udp se ejecuta en modo punto a punto.

Se pueden añadir múltiples direcciones remoteip a través del comando bearer add. Añadir una o más direcciones unicast remoteip a un portador udp existente pone al portador en modo replicast, donde el multicast IP se emula enviando múltiples mensajes unicast a cada remoteip configurado. Cuando un par ve un mensaje de descubrimiento TIPC de un par desconocido, la dirección del par se añade automáticamente a la lista remoteip (replicast), por lo que solo un lado de un enlace necesita ser configurado manualmente. No se puede añadir una dirección remoteip a un portador multicast.

remoteport PUERTOREMOTO

Especifica el puerto remoto para un portador udp. Se utiliza el puerto predeterminado 6118 si no se especifica ningún puerto.

ESTADO DE SALIDA

El estado de salida es 0 si el comando fue exitoso o un entero positivo en caso de fallo.

Linux **tipc-bearer** 2023-03-21 [FECHA DEL PAQUETE]

NOMBRE

tipc-bearer - utilidad de control para el soporte de BEARER del subsistema TIPC

SINOPSIS

tipc-bearer [opciones] [comando]

DESCRIPCIÓN

La utilidad tipc-bearer proporciona una interfaz para interactuar con el subsistema TIPC (Transparent IPC) en Linux, centrándose en la gestión de portadores de red (bearers).

Los portadores de red son los enlaces de comunicación subyacentes utilizados por TIPC para establecer conectividad entre nodos.

OPCIONES

La utilidad acepta varias opciones para modificar su comportamiento, pero estas no se especifican en este momento. Consulte la documentación de TIPC para obtener detalles completos.

COMANDOS

Los comandos disponibles permiten realizar diversas acciones sobre los portadores de red de TIPC:

  • list: Muestra una lista de todos los portadores de red TIPC conocidos.
  • add [nombre_interfaz] [tipo_portador]: Añade un nuevo portador de red TIPC asociado a una interfaz de red específica y un tipo de portador.
  • remove [nombre_portador]: Elimina un portador de red TIPC existente.
  • enable [nombre_portador]: Habilita un portador de red TIPC inactivo.
  • disable [nombre_portador]: Deshabilita un portador de red TIPC activo.
  • set-priority [nombre_portador] [prioridad]: Establece la prioridad de un portador de red TIPC.
  • set-cong-limit [nombre_portador] [límite]: Establece el límite de congestión para un portador de red TIPC.

nombre_interfaz: El nombre de la interfaz de red (por ejemplo, eth0). Se utiliza para portadores de tipo interface.

tipo_portador: El tipo de portador (por ejemplo, interface, static, tunnel).

nombre_portador: El nombre único del portador a gestionar.

prioridad: Un valor numérico que representa la prioridad del portador (los valores más altos suelen indicar mayor prioridad).

límite: Un valor numérico que representa el límite de congestión del portador.

EJEMPLOS

Para listar todos los portadores TIPC:

tipc-bearer list

Para añadir un portador TIPC utilizando la interfaz eth0 con el tipo interface:

tipc-bearer add eth0 interface

Para deshabilitar el portador llamado bearer1:

tipc-bearer disable bearer1
