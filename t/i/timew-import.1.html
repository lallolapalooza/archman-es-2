TIMEW-IMPORT(1) Manuales de usuario TIMEW-IMPORT(1)

NOMBRE

timew-import - importar datos de seguimiento de tiempo desde archivos

SINOPSIS

timew import [<archivo>...]

DESCRIPCIÓN

Importa el tiempo rastreado desde archivo. Si no se especifican archivos, el comando leerá de la entrada estándar.

Los datos a importar deben estar en formato JSON, tal como se exportan con timew-export(1), es decir, un único array con objetos de intervalo.

Al importar, se comprueban los intervalos para detectar solapamientos con los intervalos existentes. Si se encuentra un solapamiento, la importación se abortará en el primer solapamiento y no se importarán más intervalos, a menos que se especifique la pista :adjust.

En general, se recomienda hacer una copia de seguridad de sus datos antes de importar.

PISTAS

:adjust

Cuando se proporciona, el intervalo importado sobrescribirá cualquier intervalo existente con el que se solape.

EJEMPLOS

Importar intervalos desde un archivo

Importar intervalos desde un único archivo:

timew import intervalos.json

Cualquier ruta de archivo que no comience con un / se interpreta como relativa al directorio de trabajo actual.

Importar intervalos desde varios archivos

También se pueden usar comodines del shell y rutas absolutas:

timew import /ruta/a/intervalos/*.json

Importar intervalos desde la entrada estándar

Importar intervalos desde stdin:

timew export | ssh <servidor> 'timew import'

Esto es especialmente útil para sincronizar intervalos entre diferentes máquinas.
