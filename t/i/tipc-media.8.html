TIPC-MEDIA(8) Linux TIPC-MEDIA(8)

NOMBRE

tipc-media - listar o modificar propiedades de medios

SINOPSIS


tipc media set { priority PRIORIDAD | tolerance TOLERANCIA | window VENTANA } media MEDIO

tipc media get { priority | tolerance | window } media MEDIO

tipc media list

OPCIONES

Opciones (flags) que se pueden pasar en cualquier parte de la cadena de comandos.

-h, --help
Mostrar ayuda sobre el último comando válido. Por ejemplo, tipc media --help mostrará la ayuda de medios y tipc --help mostrará la ayuda general. La posición de la opción en la cadena es irrelevante.

DESCRIPCIÓN

Propiedades de medios

priority

Prioridad de enlace predeterminada heredada por todos los portadores habilitados posteriormente en un medio. Para más información sobre la prioridad de enlace, ver tipc-link(8)
tolerance

Tolerancia de enlace predeterminada heredada por todos los portadores habilitados posteriormente en un medio. Para más información sobre la tolerancia de enlace, ver tipc-link(8)
window

Ventana de enlace predeterminada heredada por todos los portadores habilitados posteriormente en un medio. Para más información sobre la ventana de enlace, ver tipc-link(8)

CÓDIGO DE SALIDA

El código de salida es 0 si el comando fue exitoso o un entero positivo en caso de error.

VER TAMBIÉN

tipc(8), tipc-bearer(8), tipc-link(8), tipc-nametable(8), tipc-node(8), tipc-peer(8), tipc-socket(8)

REPORTAR ERRORES

Reporte cualquier error a la lista de correo de desarrolladores de red <netdev@vger.kernel.org> donde se realiza principalmente el desarrollo y mantenimiento. No es necesario estar suscrito a la lista para enviar un mensaje allí.
