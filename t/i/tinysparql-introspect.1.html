NOMBRE

tinysparql-introspect - Introspeccionar puntos finales SPARQL.

SINOPSIS

tinysparql introspect [(-d |--database) <archivo> | (-b | --dbus-service) <nombre_bus> | (-r | --remote-service) <url>]
    [(-t | --tree)] [(-t | --tree) <clase>] [(-s | --search) <aguja>]t
tinysparql introspect [(-d |--database) <archivo> | (-b | --dbus-service) <nombre_bus> | (-r | --remote-service) <url>]
    [(-c | --list-classes)] [(-p | --list-properties)] [(-i | --list-indexes)] [(-n | --list-notifies)] [(-g | --list-graphs)]

DESCRIPCIÓN

Este comando permite explorar el esquema de la base de datos actual (también conocido como ontología) y las capacidades del punto final. Si se ejecuta sin argumentos adicionales al que especifica la conexión a la base de datos, se extrae toda la información.

En términos de la ontología de la base de datos, es fácil averiguar qué propiedades están indexadas para acelerar, o notificadas ante cambios, qué clases están disponibles y las propiedades que pertenecen a esas clases. También hay herramientas visuales para mostrar una disposición en árbol ASCII de las clases y sus relaciones entre sí.

OPCIONES

-b, --dbus-service=<nombre_servicio>

Se conecta a un punto final SPARQL en un nombre D-Bus.

-d, --database-path=<ruta_base_datos>

Se conecta a una base de datos por su ubicación en el sistema de archivos.

-r, --remote-service=<url>

Se conecta a un punto final SPARQL HTTP.

-c, --list-classes

Devuelve una lista de clases que describen la ontología utilizada para almacenar datos. Estas clases también se utilizan en las consultas. Por ejemplo, http://www.w3.org/2000/01/rdf-schema#Resource es una de las muchas clases que deberían aparecer aquí.

-x, --list-class-prefixes

Devuelve una lista de prefijos en forma abreviada y larga. Todas las clases y propiedades RDF tienen un prefijo de este tipo que puede expresarse en cualquiera de las dos formas.

-p, --list-properties=[clase]

Devuelve una lista de propiedades que pertenecen a una clase. Puede utilizar ambos formatos aquí para la clase, ya sea el nombre completo http://tracker.api.gnome.org/ontology/v3/nfo#Video o el nombre de prefijo abreviado nfo:Video. Ver también --tree y --query.

-n, --list-notifies=[clase]

Devuelve una lista de clases que se notifican a través de D-Bus sobre cualquier cambio que ocurra en la base de datos. La clase no tiene que ser suministrada aquí. Esto es opcional y filtra los resultados según cualquier argumento suministrado. Sin clase, se listan todas las clases.

-i, --list-indexes=[propiedad]

Devuelve una lista de propiedades que están indexadas en la base de datos. Los índices mejoran la velocidad de las consultas pero también añaden una penalización de indexación. La propiedad no tiene que ser suministrada aquí. Esto es opcional y filtra los resultados según cualquier argumento suministrado. Sin propiedad, se listan todas las propiedades.

-g, --list-graphs

Lista todos los grafos nombrados en la base de datos. Estos son utilizados por el minero de archivos para separar metadatos de forma que las aplicaciones solo vean la información relevante para ellas.

-t, --tree=[clase]

Imprime un árbol que muestra todas las clases padre de clase en la ontología. La clase se puede proporcionar en formato abreviado o completo (ver --get-shorthand y --get-longhand para más detalles).

Si no se proporciona ninguna clase, se muestra todo el árbol.

La opción de línea de comandos --search se puede utilizar para resaltar partes del árbol que esté buscando. La búsqueda no distingue entre mayúsculas y minúsculas.

La opción de línea de comandos --properties se puede utilizar para mostrar las propiedades de cada clase mostrada.

-s, --search=<aguja>

Devuelve una lista de clases y propiedades que coinciden parcialmente con aguja en la ontología. La búsqueda no distingue entre mayúsculas y minúsculas. Ver también --tree.
