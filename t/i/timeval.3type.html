timeval(3type) timeval(3type)

NOMBRE

timeval - tiempo en segundos y microsegundos

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <sys/time.h>
struct timeval {
    time_t       tv_sec;   /* Segundos */
    suseconds_t  tv_usec;  /* Microsegundos */
};

DESCRIPCIÓN

Describe tiempos en segundos y microsegundos.

ESTÁNDARES

POSIX.1-2024.

HISTORIA

POSIX.1-2001.

NOTAS

Las siguientes cabeceras también proporcionan este tipo: <sys/resource.h>, <sys/select.h> y <utmpx.h>.

VER TAMBIÉN

gettimeofday(2), select(2), utimes(2), adjtime(3), futimes(3), timeradd(3), suseconds_t(3type), time_t(3type), timespec(3type)
