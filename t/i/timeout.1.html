TIMEOUT(1) Comandos de usuario TIMEOUT(1)

NOMBRE

timeout - ejecuta un comando con un límite de tiempo

SINOPSIS

timeout [OPCIÓN]... DURACIÓN COMANDO [ARG]...

DESCRIPCIÓN

Inicia COMANDO, y lo termina si todavía está en ejecución después de DURACIÓN.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

-f, --foreground

cuando no se ejecuta timeout directamente desde un prompt de shell, permite que COMANDO lea desde el TTY y reciba señales TTY; en este modo, los hijos de COMANDO no serán limitados en tiempo

-k, --kill-after=DURACIÓN

también envía una señal KILL si COMANDO todavía está en ejecución después de que la señal inicial fue enviada

-p, --preserve-status

sale con el mismo estado que COMANDO, incluso cuando el comando excede el tiempo límite

-s, --signal=SEÑAL

especifica la señal a enviar al expirar el tiempo límite; SEÑAL puede ser un nombre como 'HUP' o un número; consulta 'kill -l' para ver una lista de señales
-v, --verbose
diagnostica en error estándar cualquier señal enviada al expirar el tiempo límite
--help
muestra esta ayuda y sale
--version
muestra información de la versión y sale

DURACIÓN es un número de punto flotante con un sufijo opcional: 's' para segundos (el valor predeterminado), 'm' para minutos, 'h' para horas o 'd' para días. Una duración de 0 deshabilita el tiempo límite asociado.

Al expirar el tiempo límite, se envía la señal TERM a COMANDO, si no se ha especificado otra SEÑAL. La señal TERM termina cualquier proceso que no bloquee o capture esa señal. Puede ser necesario usar la señal KILL, ya que esta señal no puede ser capturada.

Estado de salida:

124
si COMANDO excede el tiempo límite, y --preserve-status no se especifica
125
si el propio comando timeout falla
126
si COMANDO se encuentra pero no se puede invocar
127
si COMANDO no se encuentra
137
si COMANDO (o timeout en sí) recibe la señal KILL (9) (128+9)
-
el estado de salida de COMANDO en caso contrario

BUGS

Algunas plataformas no soportan actualmente tiempos límite posteriores al año 2038.
