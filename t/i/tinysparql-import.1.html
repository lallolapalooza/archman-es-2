TINYSPARQL-IMPORT(1) Manual de TinySPARQL TINYSPARQL-IMPORT(1)

NOMBRE

tinysparql-import - Importa datos a una base de datos TinySPARQL.

SINOPSIS

tinysparql import ARCHIVO.ttl

DESCRIPCIÓN

tinysparql import importa datos a una base de datos TinySPARQL.

Los datos deben ajustarse a la ontología existente de la base de datos.

Los datos deben estar en formato Turtle. Puede utilizar una herramienta como rapper(1) para convertir los datos de otros formatos a Turtle.

VéASE TAMBIÉN

tinysparql-export(1), tinysparql-sparql(1).
