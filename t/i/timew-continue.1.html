NOMBRE

timew-continue - reanudar el seguimiento de un intervalo existente

SINOPSIS

timew continue [<id>|<etiqueta>...] [<fecha-hora>|<rango>]

DESCRIPCIÓN

El comando 'continue' se usa para reanudar el seguimiento especificado por un intervalo cerrado. Este comando es una forma conveniente de reanudar el trabajo sin tener que volver a introducir las etiquetas.

El intervalo a reanudar se puede especificar por su id o por un conjunto de etiquetas. Especificar múltiples ids o ambos ids y etiquetas resultará en un error.

Cuando se le da un conjunto de etiquetas, el primer intervalo que coincida se tomará como modelo para el nuevo intervalo. Cuando no se especifica ni id ni etiquetas, se toma el primer intervalo de la base de datos.

Cuando no se especifica fecha-hora o rango, el nuevo intervalo se inicia en el momento actual.

EJEMPLOS

Usar el comando 'summary' y especificar la pista ':ids' muestra los IDs de los intervalos. Considere los siguientes intervalos:

$ src/timew summary :ids
Sem  Fecha      Día ID Etiquetas             Inicio      Fin    Tiempo  Total
Sem23 2020-06-04 Jue @4 BAR           13:00:00 14:00:00 1:00:00
                   @3 BAR, FOO      14:00:00 15:00:00 1:00:00
                   @2 BAR, BAZ, FOO 15:00:00 16:00:00 1:00:00
                   @1 FOO           16:00:00 17:00:00 1:00:00 4:00:00
4:00:00

Continuación simple

$ timew continue

El comando 'continue' crea un nuevo intervalo abierto, que comienza ahora, con la etiqueta 'FOO'.

Continuar un intervalo por id

$ timew continue @3

El comando 'continue' crea un nuevo intervalo abierto, que comienza ahora, con las etiquetas 'BAR' y 'FOO'.

Continuar un intervalo por conjunto de etiquetas

$ timew continue FOO BAR

El comando 'continue' crea un nuevo intervalo abierto, que comienza ahora, con las etiquetas 'FOO', 'BAR' y 'BAZ'.

Tenga en cuenta que el primer intervalo coincidente (aquí '@2') se toma como modelo para el nuevo intervalo, aunque '@3' habría sido una coincidencia perfecta para el conjunto de etiquetas dado. El comando 'timew continue BAR' tendría el mismo efecto. Esto significa que no hay forma de continuar '@4' a través de un conjunto de etiquetas.

Continuar un intervalo en una fecha y hora específicas

$ timew continue @4 19:00  (1)
$ timew continue FOO 19:00 (2)

El comando 'continue' crea un nuevo intervalo abierto

1.con la etiqueta 'BAR' (como se especifica en '@4') y la hora de inicio '19:00'.
2.con la etiqueta 'FOO' (como se especifica en '@1') y la hora de inicio '19:00'.

Continuar un intervalo con un rango específico

$ timew continue @4 19:00 - 20:00  (1)
$ timew continue FOO 19:00 - 20:00 (2)

El comando 'continue' crea un nuevo intervalo cerrado

1.con la etiqueta 'BAR' (como se especifica en '@4'), hora de inicio '19:00' y hora de fin '20:00'.
2.con la etiqueta 'FOO' (como se especifica en '@1') y hora de inicio '19:00' y hora de fin '20:00'.
