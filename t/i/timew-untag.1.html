NOMBRE

timew-untag - eliminar etiquetas de intervalos

SINOPSIS

timew untag [<id>... ] <etiqueta>...

DESCRIPCIÓN

El comando 'untag' se utiliza para eliminar una etiqueta de un intervalo. Usando el comando 'summary', y especificando la pista ':ids' se muestran los IDs de los intervalos. Usando el ID correcto, puedes identificar un intervalo para des-etiquetarlo.

EJEMPLOS

Por ejemplo, mostrar los IDs:

$ timew summary :week :ids

Luego, habiendo seleccionado '@2' como el intervalo que deseas des-etiquetar:

$ timew untag @2 'Etiqueta Antigua'

Ten en cuenta que puedes des-etiquetar múltiples intervalos, con múltiples etiquetas:

$ timew untag @2 @10 @23 'Etiqueta Antigua' etiqueta2 etiqueta3

Si hay seguimiento de tiempo activo, puedes omitir el ID cuando desees eliminar etiquetas del intervalo abierto actual:

$ timew start foo bar
$ timew untag bar

Esto resulta en que el intervalo actual tenga la etiqueta 'foo' pero no 'bar'.

VER TAMBIÉN
