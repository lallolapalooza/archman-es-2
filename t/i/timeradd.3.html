timeradd(3) Manual de funciones de biblioteca timeradd(3)

NOMBRE

timeradd, timersub, timercmp, timerclear, timerisset - operaciones con timeval

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <sys/time.h>
void timeradd(struct timeval *a, struct timeval *b,
              struct timeval *res);
void timersub(struct timeval *a, struct timeval *b,
              struct timeval *res);
void timerclear(struct timeval *tvp);
int timerisset(struct timeval *tvp);
int timercmp(struct timeval *a, struct timeval *b, CMP);
Requisitos de las macros de prueba de características para glibc (ver feature_test_macros(7)):

Todas las funciones mostradas arriba:

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Las macros se proporcionan para operar en estructuras timeval, definidas en <sys/time.h> como:


struct timeval {
    time_t      tv_sec;     /* segundos */
    suseconds_t tv_usec;    /* microsegundos */
};

timeradd() suma los valores de tiempo en a y b, y coloca la suma en el timeval apuntado por res. El resultado se normaliza de modo que res->tv_usec tenga un valor en el rango de 0 a 999.999.

timersub() resta el valor de tiempo en b del valor de tiempo en a, y coloca el resultado en el timeval apuntado por res. El resultado se normaliza de modo que res->tv_usec tenga un valor en el rango de 0 a 999.999.

timerclear() pone a cero la estructura timeval apuntada por tvp, de modo que represente la Época: 1970-01-01 00:00:00 +0000 (UTC).

timerisset() devuelve verdadero (distinto de cero) si algún campo de la estructura timeval apuntada por tvp contiene un valor distinto de cero.

timercmp() compara los valores de temporizador en a y b utilizando el operador de comparación CMP, y devuelve verdadero (distinto de cero) o falso (0) dependiendo del resultado de la comparación. Algunos sistemas (pero no Linux/glibc), tienen una implementación defectuosa de timercmp(), en la que los operadores CMP de >=, <= y == no funcionan; las aplicaciones portables pueden usar en su lugar


!timercmp(..., <)
!timercmp(..., >)
!timercmp(..., !=)

VALOR DE RETORNO

timerisset() y timercmp() devuelven verdadero (distinto de cero) o falso (0).

ERRORES

No se definen errores.

ESTÁNDARES

Ninguno.

HISTORIA

BSD.

VER TAMBIÉN
