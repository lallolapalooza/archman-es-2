termkey_start(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_START(3) Manual de funciones de la biblioteca TERMKEY_START(3)

NOMBRE

termkey_start, termkey_stop, termkey_is_started - habilitar o deshabilitar operaciones del terminal

SINOPSIS

#include <termkey.h>

int termkey_start(TermKey *tk);
int termkey_stop(TermKey *tk);

int termkey_is_started(TermKey *tk);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_start() habilita las operaciones de E/S del terminal de la instancia de termkey(7) dada, incluyendo el envío de una secuencia de control del terminal y la configuración de los modos de termios(3) requeridos.

termkey_stop() deshabilita las operaciones de E/S del terminal, invirtiendo los pasos tomados por termkey_start(). Una instancia de termkey recién construida ya tendrá las operaciones de E/S del terminal habilitadas.

termkey_is_started() consulta si las operaciones de E/S del terminal están actualmente habilitadas.

VALOR DE RETORNO

Si tiene éxito, termkey_start() y termkey_stop() devuelven un valor verdadero. En caso de fallo, se devuelve cero con errno establecido para indicar el fallo. termkey_is_started() devuelve verdadero o falso para indicar si las operaciones de E/S del terminal están actualmente habilitadas.

VER TAMBIÉN

termkey_new(3), termkey(7)
