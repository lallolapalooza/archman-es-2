TEMPNAM(3P) Manual de Programador POSIX TEMPNAM(3P)

PRÓLOGO

Esta página del manual es parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tempnam — crear un nombre para un archivo temporal

SINOPSIS

#include <stdio.h>
char *tempnam(const char *dir, const char *pfx);

DESCRIPCIÓN

La función tempnam() generará un nombre de ruta que puede utilizarse para un archivo temporal.

La función tempnam() permite al usuario controlar la elección de un directorio. El argumento dir apunta al nombre del directorio en el que se creará el archivo. Si dir es un puntero nulo o apunta a una cadena que no es un nombre de directorio apropiado, se usará el prefijo de ruta definido como P_tmpdir en la cabecera <stdio.h>. Si ese directorio no es accesible, se puede usar un directorio definido por la implementación.

Muchas aplicaciones prefieren que sus archivos temporales tengan ciertas secuencias de letras iniciales en sus nombres. El argumento pfx debería usarse para esto. Este argumento puede ser un puntero nulo o apuntar a una cadena de hasta cinco bytes que se usará como inicio del nombre del archivo.

Algunas implementaciones de tempnam() pueden usar tmpnam() internamente. En tales implementaciones, si se llama más de {TMP_MAX} veces en un solo proceso, el comportamiento es definido por la implementación.

VALOR DE RETORNO

Al completarse con éxito, tempnam() asignará espacio para una cadena, colocará el nombre de ruta generado en ese espacio y devolverá un puntero a ella. El puntero será adecuado para su uso en una llamada posterior a free(). De lo contrario, devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

La función tempnam() fallará si:

ENOMEM
No hay suficiente espacio de almacenamiento disponible.

Las siguientes secciones son informativas.

EJEMPLOS

Generación de un nombre de ruta

El siguiente ejemplo genera un nombre de ruta para un archivo temporal en el directorio /tmp, con el prefijo file. Después de crear el nombre de ruta, la llamada a free() libera el espacio utilizado para almacenar el nombre de ruta.

#include <stdio.h>
#include <stdlib.h>
...
const char *directory = "/tmp";
const char *fileprefix = "file";
char *file;
file = tempnam(directory, fileprefix);
free(file);

USO POR LA APLICACIÓN

Esta función solo crea nombres de ruta. Es responsabilidad de la aplicación crear y eliminar los archivos. Entre el momento en que se crea un nombre de ruta y se abre el archivo, es posible que otro proceso cree un archivo con el mismo nombre. Las aplicaciones pueden encontrar tmpfile() más útil.

Las aplicaciones deben usar las funciones tmpfile(), mkdtemp() o mkstemp() en lugar de la función obsoleta tempnam().

JUSTIFICACIÓN

Ninguna.

DIRECCIONES FUTURAS

La función tempnam() puede eliminarse en una versión futura.

VER TAMBIÉN

fopen(), free(), mkdtemp(), open(), tmpfile(), tmpnam(), unlink()
