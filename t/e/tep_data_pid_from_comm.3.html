tep_data_pid_from_comm(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_register_comm, tep_override_comm, tep_is_pid_registered, tep_data_comm_from_pid, tep_data_pid_from_comm, tep_cmdline_pid - Gestionar mapeos de pid a nombres de proceso.

SINOPSIS

#include <event-parse.h>
int tep_register_comm(struct tep_handle *tep, const char *comm, int pid);
int tep_override_comm(struct tep_handle *tep, const char *comm, int pid);
bool tep_is_pid_registered(struct tep_handle *tep, int pid);
const char *tep_data_comm_from_pid(struct tep_handle *pevent, int pid);
struct cmdline *tep_data_pid_from_comm(struct tep_handle *pevent, const char *comm, struct cmdline *next);
int tep_cmdline_pid(struct tep_handle *pevent, struct cmdline *cmdline);

DESCRIPCIÓN

Estas funciones se pueden usar para gestionar el mapeo entre el pid y el nombre del proceso. La biblioteca crea una caché de estos mapeos, que se utiliza para mostrar el nombre del proceso, en lugar de su pid. Esta información se puede obtener del archivo tracefs/saved_cmdlines.

La función tep_register_comm() registra un mapeo de pid / nombre de proceso. Si ya está registrado un comando con el mismo pid, se devuelve un error. El argumento pid es el ID del proceso, el argumento comm es el nombre del proceso, tep es el contexto del evento. El comm se duplica internamente.

La función tep_override_comm() registra un mapeo de pid / nombre de proceso. Si ya está registrado un proceso con el mismo pid, la cadena del nombre del proceso se actualiza con la nueva. El argumento pid es el ID del proceso, el argumento comm es el nombre del proceso, tep es el contexto del evento. El comm se duplica internamente.

La función tep_is_pid_registered() comprueba si un pid tiene un mapeo de nombre de proceso registrado. El argumento pid es el ID del proceso, tep es el contexto del evento.

La función tep_data_comm_from_pid() devuelve el nombre del proceso para un pid dado. El argumento pid es el ID del proceso, tep es el contexto del evento. La cadena devuelta no debe liberarse, sino que se liberará cuando se cierre el manejador tep.

La función tep_data_pid_from_comm() devuelve un pid para un nombre de proceso dado. El argumento comm es el nombre del proceso, tep es el contexto del evento. El argumento next es la estructura cmdline para buscar el siguiente pid. Como puede haber más de un pid para un proceso dado, el resultado de esta llamada se puede pasar de vuelta en una llamada recurrente en el parámetro next, para buscar el siguiente pid. Si next es NULL, devolverá el primer pid asociado con comm. La función realiza una búsqueda lineal, por lo que puede ser lenta.

La función tep_cmdline_pid() devuelve el pid asociado con una cmdline dada. El argumento tep es el contexto del evento.

VALOR DE RETORNO

La función tep_register_comm() devuelve 0 en caso de éxito. En caso de error, se devuelve -1 y errno se establece para indicar la causa del problema: ENOMEM, si no hay suficiente memoria para duplicar el comm o EEXIST si ya está registrado un mapeo para este pid.

La función tep_override_comm() devuelve 0 en caso de éxito. En caso de error, se devuelve -1 y errno se establece para indicar la causa del problema: ENOMEM, si no hay suficiente memoria para duplicar el comm.

La función tep_is_pid_registered() devuelve verdadero si el pid tiene un nombre de proceso mapeado, falso en caso contrario.

La función tep_data_comm_from_pid() devuelve el nombre del proceso como cadena, o la cadena "<...>" si no hay un mapeo para el pid dado.

La función tep_data_pid_from_comm() devuelve un puntero a una estructura cmdline, que contiene un pid para un proceso dado, o NULL si no se encuentra ninguno. Este resultado se puede pasar de vuelta en una llamada recurrente como el parámetro next de la función.

Las funciones tep_cmdline_pid() devuelven el pid para la cmdline dada. Si cmdline es NULL, se devuelve -1.

EJEMPLO

El siguiente ejemplo registra el pid para el comando "ls", en el contexto del evento tep y realiza varias búsquedas de mapeos de pid / nombre de proceso:

#include <event-parse.h>
...
int ret;
int ls_pid = 1021;
struct tep_handle *tep = tep_alloc();
...
        ret = tep_register_comm(tep, "ls", ls_pid);
        if (ret != 0 && errno == EEXIST)
                ret = tep_override_comm(tep, "ls", ls_pid);
        if (ret != 0) {
                /* Falló el registro del mapeo pid / comando */
        }
...
        if (tep_is_pid_registered(tep, ls_pid) == 0) {
                /* El mapeo de comando para ls_pid no está registrado */
        }
...
        const char *comm = tep_data_comm_from_pid(tep, ls_pid);
        if (comm) {
                /* Se encontró el nombre del proceso para ls_pid */
        }
...
        int pid;
        struct cmdline *cmd = tep_data_pid_from_comm(tep, "ls", NULL);
        while (cmd) {
                pid = tep_cmdline_pid(tep, cmd);
                /* Se encontró el pid para el proceso "ls" */
                cmd = tep_data_pid_from_comm(tep, "ls", cmd);
        }
