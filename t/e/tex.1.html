TEX(1) Manual de comandos generales TEX(1)

NOMBRE

tex, initex - formato de texto y composición tipográfica

SINOPSIS

tex [opciones] [&formato] [archivo|\comandos]

DESCRIPCIÓN

Ejecuta el componedor TeX en archivo, creando generalmente archivo.dvi. Si el argumento del archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede dar un conjunto de comandos TeX, el primero de los cuales debe empezar con una barra inversa. Con un argumento &formato, TeX usa un conjunto diferente de comandos precompilados, contenidos en formato.fmt; normalmente es mejor usar la opción -fmt formato en su lugar.

TeX formatea el texto intercalado y los comandos contenidos en los archivos con nombre y genera un archivo independiente del dispositivo de composición (llamado DVI, que es el acrónimo de Dispositivo Independiente). Las capacidades y el lenguaje de TeX se describen en The TeXbook. TeX se usa normalmente con un gran conjunto de macros precompiladas, y existen varios sistemas de formato específicos, como LaTeX, que requieren el soporte de varios archivos de macros.

Esta versión de TeX examina su línea de comandos para ver con qué nombre se invocó. Si existen, tanto initex como virtex son enlaces simbólicos al ejecutable tex. Cuando se invoca como initex (o cuando se da la opción -ini), se puede usar para precompilar macros en un archivo .fmt. Cuando se invoca como virtex, usará el formato plain. Cuando se invoca con cualquier otro nombre, TeX usará ese nombre como el nombre del formato a usar. Por ejemplo, cuando se invoca como tex, se usa el formato tex, que es idéntico al formato plain. Los comandos definidos por el formato plain se documentan en The TeXbook. Otros formatos que suelen estar disponibles incluyen latex y amstex.

Los argumentos de línea de comandos que no son opciones para el programa TeX se le pasan como la primera línea de entrada. (Pero a menudo es más fácil escribir argumentos extendidos como la primera línea de entrada, ya que los shells de UNIX tienden a engullir o malinterpretar los símbolos favoritos de TeX, como las barras invertidas, a menos que los cite.) Como se describe en The TeXbook, esa primera línea debe comenzar con un nombre de archivo, una \secuencia de control o un &nombre_de_formato.

El uso normal es escribir

tex paper
para empezar a procesar paper.tex. El nombre paper será el ``nombre del trabajo'' (jobname), y se utiliza para formar los nombres de los archivos de salida. Si TeX no recibe un nombre de archivo en la primera línea, el nombre del trabajo es texput. Al buscar un archivo, TeX busca el nombre con y sin la extensión predeterminada (.tex) añadida, a menos que el nombre ya contenga esa extensión. Si paper es el ``nombre del trabajo'', un registro de mensajes de error, con bastantes más detalles de los que normalmente aparecen en la pantalla, aparecerá en paper.log, y el archivo de salida estará en paper.dvi.

Esta versión de TeX puede buscar en la primera línea del archivo paper.tex para ver si comienza con la secuencia mágica %&. Si la primera línea comienza con %&formato -translate-file nombre_tcx, TeX usará el formato y la tabla de traducción nombre_tcx especificados para procesar el archivo fuente. Cualquiera de los dos, el nombre del formato o la especificación -translate-file, pueden omitirse, pero no ambos. Esto anula la selección del formato basada en el nombre con el que se invocó el programa. La opción -parse-first-line o la variable de configuración parse_first_line controlan si este comportamiento está habilitado.

La respuesta e a la indicación de error de TeX inicia el editor predeterminado del sistema en la línea actual del archivo actual. La variable de entorno TEXEDIT se puede usar para cambiar el editor utilizado. Puede contener una cadena con "%s" que indica dónde va el nombre del archivo y "%d" que indica dónde va el número de línea decimal (si lo hay). Por ejemplo, una cadena TEXEDIT para emacs se puede configurar con el comando sh

TEXEDIT="emacs +%d %s"; export TEXEDIT

Un archivo conveniente en la biblioteca es null.tex, que no contiene nada. Cuando TeX no puede encontrar un archivo que cree que desea introducir, sigue pidiéndole otro nombre de archivo; responder `null` te saca del bucle si no quieres introducir nada. También puedes escribir tu carácter de fin de archivo (EOF) (generalmente Ctrl-D).

OPCIONES

Esta versión de TeX entiende las siguientes opciones de línea de comandos.

-cnf-line cadena
Analiza cadena como una línea de configuración de texmf.cnf. Consulte el manual de Kpathsea.
-enc
Habilita las extensiones encTeX. Esta opción solo es efectiva en combinación con -ini. Para la documentación de las extensiones encTeX, consulte http://www.olsak.net/enctex.html.
-file-line-error
Imprime mensajes de error en el formato archivo:línea:error, que es similar a la forma en que muchos compiladores los formatean.
-no-file-line-error
Deshabilita la impresión de mensajes de error en el estilo archivo:línea:error.
-file-line-error-style
Este es el nombre antiguo de la opción -file-line-error.
-fmt formato
Usa formato como nombre del formato a utilizar, en lugar del nombre con el que se llamó a TeX o una línea %&.
-halt-on-error
Sale con un código de error cuando se encuentra un error durante el procesamiento.
-help
Imprime un mensaje de ayuda y sale.
-ini
Inicia en modo INI, que se usa para volcar formatos. El modo INI se puede usar para composición tipográfica, pero no se carga ningún formato precompilado, y pueden ser necesarias inicializaciones básicas como el establecimiento de códigos de categoría.
-interaction modo
Establece el modo de interacción. El modo puede ser batchmode, nonstopmode, scrollmode y errorstopmode. El significado de estos modos es el mismo que el de los \comandos correspondientes.
-ipc
Envía la salida DVI a un socket además del archivo de salida habitual. La disponibilidad de esta opción es a elección del instalador.
-ipc-start
Como -ipc, y también inicia el servidor en el otro extremo. La disponibilidad de esta opción es a elección del instalador.
-jobname nombre
Usa nombre como nombre del trabajo, en lugar de derivarlo del nombre del archivo de entrada.
-kpathsea-debug mascara_bits
Establece las banderas de depuración de búsqueda de rutas según la máscara de bits. Consulte el manual de Kpathsea para obtener detalles.
-mktex fmt
Habilita mktexfmt, donde fmt debe ser tex o tfm.
-mltex
Habilita las extensiones MLTeX. Solo efectivo en combinación con -ini.
-no-mktex fmt
Deshabilita mktexfmt, donde fmt debe ser tex o tfm.
-output-comment cadena
Usa cadena como comentario del archivo DVI en lugar de la fecha.
-output-directory directorio
Escribe los archivos de salida en directorio en lugar del directorio actual. Busca archivos de entrada primero en directorio, luego a lo largo de la ruta de búsqueda normal. Consulte también la descripción de la variable de entorno TEXMFOUTPUT.
