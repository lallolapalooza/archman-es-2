NOMBRE

Terminology - Emulador de terminal escrito con EFL (Enlightenment Foundation Libraries).

SINOPSIS

terminology [opciones]

DESCRIPCIÓN

Este es un emulador de terminal EFL con algunas características adicionales. Tiene muchas funcionalidades, incluyendo soporte para terminales divididas, soporte para pestañas, iconos de vista previa para archivos, etc.

OPCIONES

-e, --exec <cmnd>
Especifica el comando a ejecutar. Por defecto es $SHELL (o el shell de la contraseña o /bin/sh). Cuando se usa junto con -S/--split, cada argumento se usa como comando para una división, omitiendo los argumentos extra. Con 3 divisiones, una vertical, un comando a la derecha, una división horizontal a la izquierda con solo un comando abajo, los siguientes argumentos deben ser usados: --split v-h-- -e comando1 $SHELL comando2
-d=DIRECTORIO-ACTUAL, --current-directory=DIRECTORIO-ACTUAL
Cambia al directorio para la ejecución del comando de la terminal. Tipo: STR.
-t=TEMA, --theme=TEMA
Usa el tema de Edje con el nombre especificado o la ruta al archivo del tema. Tipo: STR.
-b=FONDO, --background=FONDO
Usa el archivo especificado como fondo de pantalla para terminology. Tipo: STR.
-g=GEOMETRÍA, --geometry=GEOMETRÍA
Geometría de la terminal a usar (ej. 80x24 o 80x24+50+20, etc.). Tipo: STR.
-n=NOMBRE, --name=NOMBRE
Establece el nombre de la ventana. Tipo: STR.
-r=ROL, --role=ROL
Establece el rol de la ventana. Tipo: STR.
-S=vh-, --split=vh-
Terminology puede iniciarse con divisiones abiertas como se describe a continuación. Los argumentos son una cadena con los siguientes caracteres:
-S v divide la terminal verticalmente
-S h divide horizontalmente
- define un marcador de posición para un shell o un comando cuando se usa con
--exec/-e
Ejemplos:
______
| | |
$ terminology -S v |__|__|


______
|_____|
$ terminology -S h |_____|


______
|__| |
$ terminology -S vh |__|__|


______
| |__|
$ terminology -S v-h |__|__|


______
$ terminology -S vh--h |__|__|
hv--v |__|__|
Tipo: STR.

-T=TÍTULO, --title=TÍTULO
Establece el título de la ventana. Tipo: STR.
-i=NOMBRE-ICONO, --icon-name=NOMBRE-ICONO
Establece el nombre del icono. Tipo: STR.
-f=FUENTE, --font=FUENTE
Establece la fuente (NOMBRE/TAMAÑO para escalable, NOMBRE para mapa de bits). Tipo: STR.
-l=LOGIN, --login=LOGIN
Ejecuta el shell como un shell de inicio de sesión. Tipo: BOOL.
-m=MUTEO-VIDEO, --video-mute=MUTEO-VIDEO
Establece el modo de silencio para la reproducción de video. Tipo: BOOL.
-c=CURSOR-PARPADEANTE, --cursor-blink=CURSOR-PARPADEANTE
Establece el modo de parpadeo del cursor. Tipo: BOOL.
-G=CAMPANA-VISUAL, --visual-bell=CAMPANA-VISUAL
Establece el modo de campana visual. Tipo: BOOL.
-F, --fullscreen
Entra en modo de pantalla completa desde el inicio.
-I, --iconic
Entra en estado icónico desde el inicio.
-B, --borderless
Conviértete en una ventana administrada sin bordes.
-O, --override
Conviértete en una ventana de redirección de anulación.
-M, --maximized
Maximízate desde el inicio.
-W, --nowm
Terminology se ejecuta sin un gestor de ventanas (wm).
-H, --hold
No salir cuando el proceso del comando finalice.
-s, --single
Forzar ejecutable único si la multi-instancia está habilitada.
-2, --256color
Establece TERM a xterm-256color en lugar de xterm.
--active-links=ACTIVAR-ENLACES
Si resaltar enlaces. Tipo: BOOL.
--no-wizard
No mostrar el asistente al iniciar. Tipo: BOOL.
--scale=SCALE
Factor de escala a usar en la interfaz de usuario. Tipo: DOUBLE.
--colorscheme=COLORSCHEME
Usa el esquema de color con el nombre especificado. Tipo: STR.
-V, --version
Mostrar la versión del programa.
-C, --copyright
Mostrar copyright.
-L, --license
Mostrar licencia.
-h, --help
Mostrar este mensaje.

ESCAPES EXTENDIDOS PARA TERMINOLOGY:

[\033][}][COMANDO][\000]
es decir,
1. Carácter ESC (\033 o 0x1b)
2. Carácter }
3... Secuencia de caracteres UTF8 distintos de nul (\000 o 0x00).
4 Carácter \000 (byte nul o 0x00 para indicar el final de la secuencia) por ejemplo,
echo -n '\033}Hola mundo\000'

Comandos:

Cualquier valor dentro de corchetes [] debe ser reemplazado por algún contenido (números, cadenas, rutas, url's, etc.). Ejemplo:

aa[RUTA-DEL-ARCHIVO] debería convertirse en algo como:
aa/tmp/archivo.png o aa[true/false] debería convertirse en algo como:
aatrue o
aafalse

---

bt[RUTA-COMPLETA-O-URL]

bp[RUTA-COMPLETA-O-URL]
establece permanentemente el archivo/url multimedia del fondo de la terminal.

at[on/true/yes/off/false/no]
establece temporalmente el estado alfa de la terminal a activado o desactivado.

ap[on/true/yes/off/false/no]
establece permanentemente el estado alfa de la terminal a activado o desactivado.

qs
consulta el tamaño de la cuadrícula y la fuente. stdin tendrá escrito:
A;A;AF;AF
donde A es el ancho de la cuadrícula de la terminal en caracteres
donde A es la altura de la cuadrícula de la terminal en caracteres
donde AF es el ancho de 1 celda de carácter en píxeles
donde AF es la altura de 1 celda de carácter en píxeles

is[AC;A;RUTA-COMPLETA-O-URL]
inserta medios ESTIRADOS (donde la imagen se estirará para llenar el
área de la celda) y define el área de celda esperada como A
celdas de ancho y A celdas de alto, con la imagen/medios/url.
donde C es el carácter de reemplazo a identificar en texto posterior
donde A es el ancho en celdas de carácter (hasta 511).
donde A es la altura en celdas de carácter (hasta 511).


ten en cuenta que este escape por sí solo no tiene efecto. Indica una intención futura de insertar medios en la terminal. La terminal ESPERARÁ una cuadrícula de A "caracteres de reemplazo", con cada secuencia de dichos caracteres de reemplazo comenzando con un comando de escape ib y terminando con un comando de escape ie.


la RUTA-COMPLETA-O-URL para todos los comandos i (is,
ic, if, it) puede tener el formato:


/ruta/completa/al/archivo.png


O


/ruta/completa/al/enlace0ruta/completa/al/archivo.png


donde un carácter de nueva línea separa una URI para un enlace y
una ruta completa a un archivo para mostrar en la región. el enlace
es el URI de destino cuando un usuario puede hacer clic en la imagen multimedia dada.


ejemplo:


printf("\ 33}is#5;3;%s 00"
"\ 33}ib#####\ 33}ie\0
"\ 33}ib#####\ 33}ie\0, "/tmp/icono.png");


ten en cuenta que # es el carácter de reemplazo, y los caracteres # posteriores si están dentro de los escapes de inicio/fin, serán reemplazados por los medios dados indicados en el escape de inserción de medios.

inserta medios CENTRADOS (centrados en el área de la celda). De lo contrario,

NAME

terminology - The Enlightenment Terminal Emulator

SYNOPSIS

terminology [options]

DESCRIPTION

terminology is a modern terminal emulator for the Enlightenment desktop, but also works standalone. It offers features like:

  • Customizable fonts, colors, and layout
  • Tabbed interface
  • Text and image rendering
  • Mouse support
  • Scrollback buffer
  • Customizable keybindings
  • Integration with Enlightenment desktop features
  • Support for extended escape sequences for rich media and control

OPTIONS

Refer to the man page for a full list of options. Common options include:

-g geometry
Set the window geometry (size and position).
-e command
Execute the given command instead of the default shell.
-f font
Set the font.
-c color_scheme
Set the color scheme.
-T title
Set the window title.
-i profile
Load the specified profile.

CONTROLS / SHORTCUTS

Ctrl+Shift+T
Open a new tab.
Ctrl+Shift+W
Close the current tab.
Ctrl+Tab
Switch to the next tab.
Ctrl+Shift+Tab
Switch to the previous tab.
Ctrl+Shift+F
Toggle fullscreen.
Ctrl+Shift+Plus
Increase font size.
Ctrl+Shift+Minus
Decrease font size.
Ctrl+Shift+C
Copy selected text.
Ctrl+Shift+V
Paste text.

MOUSE CONTROLS

Left-click
Select text.
Right-click
Show context menu.
Middle-click
Paste selection.
Scroll wheel
Scroll through buffer.

COMMAND MODE COMMANDS

When in command mode (usually accessed via Ctrl+Shift+E or similar), you can issue commands to control terminology.

i[CW;H;FULL-PATH-OR-URL]
insert media (image, video, etc.) in the cell area. Supported types depend on compile-time configuration.
it[CW;H;FULL-PATH-OR-URL]
insert THUMB media (thumbnail cell area). Otherwise parameters
are identical to the is command, but uses thumbnail
generation to make a fast to load but low resolution version
(cached) of the media.
it[CW;H;LINK\nFULL-PATH-OR-URL]
insert THUMB media with link (thumbnail cell area). Otherwise parameters
are identical to the is command, but uses thumbnail generation to
make a fast to load but low resolution version (cached) of the media.
LINK is a path (or url) to open _when_ the thumb is clicked on by the
user.
ij[CW;H;FULL-PATH\nGROUP][\n][cmd1][\r\n][cmd2]...
insert EDJE object with file path given, and the group name given.
The command list (and the \n whitespace delimiter before the list)
is optional, but is executed/parsed before display of the actual
object to do things like initialize its initial state. See `iC`
command for more details on the command list.

Be aware that once you have an object with an assigned channel id,
it can send back signals and messages via escapes on stdin. These
escapes will follow terminology extended escape format
(ESC + } ...  00), and the content will be one of:

;CHID\ndrag\nPART NAME\nVAL1\nVAL2
;CHID\ndrag,start\nPART NAME\nVAL1\nVAL2
;CHID\ndrag,stop\nPART NAME\nVAL1\nVAL2
;CHID\ndrag,step\nPART NAME\nVAL1\nVAL2
;CHID\drag,set\nPART NAME\nVAL1\nVAL2
signal;CHID\nSIGNAL STRING\nSOURCE STRING
message;CHID\nOPCODE ID\nstring\nSTRING1
message;CHID\nOPCODE ID\nint\nINT1
message;CHID\nOPCODE ID\nfloat\nFLOAT1
message;CHID\nOPCODE ID\nstring_set\nSTRING1\nSTRING2\nSTRING3...
message;CHID\nOPCODE ID\nint_set\nINT1\nINT2\nINT3...
message;CHID\nOPCODE ID\nfloat_set\nFLOAT1\nFLOAT2\nFLOAT3...
message;CHID\nOPCODE ID\nstring_int\nSTRING1\nINT1
message;CHID\nOPCODE ID\nstring_float\nSTRING1\nFLOAT1
message;CHID\nOPCODE ID\nstring_int_set\nSTRING1\nINT1\nINT2\nINT3...
message;CHID\nOPCODE ID\nstring_float_set\nSTRING1\nFLOAT1\nFLOAT2\nFLOAT3...
iC[CHID]\n[cmd1][\r\n][cmd2][\r\n][cmd3]...
send a COMMAND (cmd1, cmd2, cmd3 etc.) to an existing named
channel id CHID. this can be a list of 1 or more command strings,
with each string broken by a continuous sequence of 1 or more \r
and/or \n characters. e.g. "\n", "\r", "\r\n",
"\n\r", "\n\r\n\n\n", etc.

commands understood are:

text\nPART NAME\nTEXT STRING
set the text of "PART NAME" to string "TEXT STRING"

emit\nSIGNAL STRING\nSOURCE STRING
emit signal "SIGNAL STRING" "SOURCE STRING"

drag\nPART NAME\n[value|size|step|page]\nVAL1\nVAL2
manipulate dragable of name "PART NAME" and either set
"value", "size", "step" or "page" properties
to "VAL1" and "VAL2" for x and "y", where
VAL1 and VAL2 are floating point values

chid\nCHANNEL ID
set the channel id of a given edje object (only valid in setup
commands for the inline edje object) to "CHANNEL ID" so it can
be addressed later.

message\nOPCODE ID\n[string|int|float|string_set|int_set|...
float_set|string|int|string_float|string_int_set|...
string_float_set]\n[message data]
send a message with opcode (integer) id "OPCODE ID" of one of
the given types supported ("string", "int", "float",
etc.) and then with the given "message data" at the end.
message data format depends on message type:
string: STRING1
int: INT1
float: FLOAT1
string_set: STRING1\nSTRING2\nSTRING3...
int_set: INT1\nINT2\nINT3...
float_set: FLOAT1\nFLOAT2\nFLOAT3...
string_int: STRING1\nINT1
string_float: STRING1\nFLOAT1
string_int_set: STRING1\nINT1\nINT2\nINT3...
string_float_set: STRING1\nFLOAT1\nFLOAT2\nFLOAT3...
ib
begin media replace sequence run.
ie
end media replace sequence run.
fr[PATH/FILE]
begin file send for a file named PATH / FILE
fs[SIZE_BYTES]
set the size in bytes of a file send started with the above fr escape
fd[CHECKSUM DATA]
block of data for the current file transfer with checksum as a
string decimal which is the sum of every byte when taken as an
unsigned char per byte. the checksum is a signed 32bit integer.
the checksum is the sum of the data after escaping. 4 bits at a
time per data byte, encoded with high bits in one byte then low
bits, with the bits encoded as 4 bit value being 0x40 + 4 bit value
per byte. (@ == 0x0, A == 0x1, B == 0x2, ... N == 0xe, O == 0xf).
so to rebuild a byte will be (((bytes[0] - 0x40) & 0xf) << 4) |
((bytes[1] - 0x40) & 0xf) per byte pair in the data block.
fx
exit file send mode (normally at the end of the file or when it's
complete)

THEMES:

Terminology supports custom themes. You can create or download themes to change the appearance of the terminal. Theme files are typically located in ~/.config/terminology/themes/ or /usr/share/terminology/themes/.

COMPANION TOOLS:

terminology-ls: A utility to list files and directories in a format suitable for display within terminology.

terminology-view: A utility to view images and other media within terminology.

EXTENDED ESCAPES FOR TERMINOLOGY:

Terminology supports extended escape sequences for rich media, control, and communication between the terminal and external applications. These sequences typically start with the escape character (ESC) followed by `}' or `]'. The specific sequences are documented in the full manual page and related documentation.

Common extended escapes include:

  • Image embedding (e.g., `ESC ] 1337 ; File=... ST`)
  • Control sequences for cursor movement, colors, etc.
  • Inter-process communication (IPC) via stdin/stdout.
