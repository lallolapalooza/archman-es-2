NOMBRE

texconfig - configura teTeX o TeX Live

texconfig-sys - configura teTeX o TeX Live a nivel de sistema

SINOPSIS

texconfig

texconfig [comandos ...]

texconfig-sys

DESCRIPCIÓN

texconfig permite configurar y mantener TeX de una manera fácil y conveniente, ofreciendo una serie de cuadros de diálogo al usuario. El directorio en el que se encuentra texconfig también se utiliza de forma preferente para buscar subprogramas.

El programa tlmgr ha absorbido esta función para TeX Live. Este programa todavía es compatible, pero la interfaz de tlmgr está mucho más activamente desarrollada y probada.

Después de elegir configuraciones u opciones, los archivos correspondientes se modifican automáticamente y la nueva configuración se aplica para el usuario. Si es necesario, se crearán copias de los archivos en TEXMFDIST o TEXMFMAIN en el árbol TEXMFCONFIG del usuario.

texconfig utiliza el programa whiptail(1) o dialog(1) para comunicarse con el usuario, por lo que debe ejecutarse en una terminal.

Para realizar cambios a nivel de sistema, que se aplicarán a todos los usuarios de TeX (por ejemplo, el tamaño de papel predeterminado, etc.), ejecute texconfig-sys en su lugar. Los archivos modificados o generados se colocarán en TEXMFSYSCONFIG. (Es posible que necesite ser root para hacer esto).

texconfig también ofrece un modo por lotes no interactivo al que se puede acceder con los siguientes comandos

COMANDOS

Los comandos que aceptan opciones adicionales generalmente muestran las opciones disponibles si se llaman sin ellas. Por ejemplo, texconfig dvipdfm paper informará sobre las configuraciones de papel válidas.

conf
Muestra la configuración del sistema.
dvipdfm paper [letter|legal|ledger|tabloid|a4|a3]
Configura dvipdfm para usar por defecto el tamaño de papel PAPER.
dvips add NOMBRE_IMPRESORA
Crea un nuevo archivo de configuración (vacío) TEXMFCONFIG/dvips/config/config.NOMBRE_IMPRESORA. Este archivo puede ser rellenado posteriormente con las opciones mode, offset o printcmd
dvips del NOMBRE_IMPRESORA
Elimina config.NOMBRE_IMPRESORA
dvips mode
Lista los modos de Metafont disponibles.
dvips [-P IMPRESORA] mode MODO
Cambia el modo Metafont a MODO para IMPRESORA o para todos los archivos de salida (config.ps), si no se proporciona la opción -P.
dvips [-P IMPRESORA] offset OFFSET_X,OFFSET_Y
Establece el desplazamiento de la impresora para IMPRESORA o para todos los archivos de salida (config.ps), si no se proporciona la opción -P. Los desplazamientos deben proporcionarse con unidades, por ejemplo, 0pt,10pt. Puede usar testpage.tex de la distribución LaTeX para encontrar estos números.
dvips [-P IMPRESORA] printcmd CMD
Establece el comando de impresión para IMPRESORA o para todos los archivos de salida (config.ps), si no se proporciona la opción -P. Los comandos pueden ser lp o lpr. Consulte la descripción de la opción o en info dvips o la opción -O en dvips(1).
faq
Muestra la lista de Preguntas Frecuentes sobre teTeX (y sus respuestas).
font vardir DIR, font ro, font rw
formats
Este comando permite editar fmtutil.cnf(5) y (re)crea cualquier formato nuevo o cambiado después.
hyphen FORMATO
Este comando permite editar el archivo de configuración de guiones para formatos que lo soporten, y recrea los formatos después para habilitar los nuevos idiomas. Los formatos disponibles se muestran cuando no se proporciona FORMATO.
Tenga en cuenta que para los formatos que utilizan language.dat de LaTeX,
por ejemplo, (pdf)jadetex y latex sí mismo, este cambio no es persistente, ya que este archivo es un archivo generado. No debe usar este comando en estos casos, lea update-language(1) para alternativas.
init [formato]
Recrea formato o todos los formatos si no se proporciona ninguno, y la información de fuentes. Esto es lo mismo que llamar a fmtutil --byfmt formato o fmtutil --all, respectivamente, seguido de updmap.
mode-list
Lista los modos de impresora disponibles, junto con las impresoras para las que fueron desarrollados y su resolución DPI.
mode MODO
Establece el modo de impresora predeterminado en /etc/texmf/web2c/mktex.cnf o en el archivo de usuario respectivo en $TEXMFCONFIG/web2c a MODO.
paper [a4|letter]
Establece el tamaño de papel predeterminado para dvips, dvipdfm, pdftex y xdvi. El conjunto está restringido porque no todos los programas entienden todos los tamaños.
pdftex paper [a4|letter]
Establece el tamaño de papel predeterminado para pdftex.
rehash
Llama a mktexlsr.
xdvi paper PAPEL
Establece el tamaño de papel predeterminado para xdvi. La lista (larga) está disponible con texconfig xdvi paper.

AMBIENTE

Para permitirle modificar archivos, texconfig abrirá el editor especificado en las variables VISUAL o EDITOR, o sensible-editor si ambas no están definidas.

VER TAMBIÉN

whiptail(1), dialog(1), tlmgr(1), tex(1), mf(1), vi(1), variable de entorno EDITOR.
