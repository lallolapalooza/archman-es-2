NOMBRE

termkey_get_fd - obtener el descriptor de archivo para la terminal

SINOPSIS

#include <termkey.h>

int termkey_get_fd(TermKey *tk);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_get_fd() devuelve el descriptor de archivo que la instancia de termkey(7) está utilizando para leer bytes.

VALOR DE RETORNO

termkey_get_fd() devuelve el descriptor de archivo actual, o -1 si no hay ningún descriptor de archivo asociado con esta instancia.

VER TAMBIÉN

termkey_new(3), termkey_get_flags(3), termkey(7)
