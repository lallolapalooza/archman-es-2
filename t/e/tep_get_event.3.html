tep_get_event(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_get_event, tep_get_first_event, tep_get_events_count - Acceder a eventos.

SINOPSIS

#include <event-parse.h>
struct tep_event *tep_get_event(struct tep_handle *tep, int index);
struct tep_event *tep_get_first_event(struct tep_handle *tep);
int tep_get_events_count(struct tep_handle *tep);

DESCRIPCIÓN

La función tep_get_event() devuelve un puntero al evento en el índice dado. El argumento tep es el contexto del analizador de eventos de traza, el índice es el índice del evento solicitado.

La función tep_get_first_event() devuelve un puntero al primer evento. Como los eventos se almacenan en una matriz, esta función devuelve el puntero al principio de la matriz. El argumento tep es el contexto del analizador de eventos de traza.

La función tep_get_events_count() devuelve el número de eventos en la matriz. El argumento tep es el contexto del analizador de eventos de traza.

VALOR DE RETORNO

La función tep_get_event() devuelve un puntero al evento ubicado en el índice. Se devuelve NULL en caso de error, si no hay eventos o si el índice está fuera de rango.

La función tep_get_first_event() devuelve un puntero al primer evento. Se devuelve NULL en caso de error, o si no hay eventos.

La función tep_get_events_count() devuelve el número de eventos. Se devuelve 0 en caso de error, o si no hay eventos.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int i,count = tep_get_events_count(tep);
struct tep_event *event, *events = tep_get_first_event(tep);
if (events == NULL) {
        /* No hay eventos */
} else {
        for (i = 0; i < count; i++) {
                event = (events+i);
                /* procesar events[i] */
        }
        /* Obtener el último evento */
        event = tep_get_event(tep, count-1);
}
