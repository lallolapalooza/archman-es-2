NOMBRE

testasciidoc - Ejecuta pruebas de conformidad de AsciiDoc especificadas en el archivo de configuración.

SINOPSIS

testasciidoc [OPCIONES] COMANDO

DESCRIPCIÓN

El comando testasciidoc ejecuta pruebas de conformidad de AsciiDoc especificadas en el archivo de configuración.

COMANDOS

El conjunto de herramientas testasciidoc tiene tres comandos diferentes:

testasciidoc list
testasciidoc run [-n, --number NÚMERO] [-b, --backend BACKEND] [OPCIONES]
testasciidoc update [-n, --number NÚMERO] [-b, --backend BACKEND] [OPCIONES]

Los comandos realizan lo siguiente:

list

Lista los casos de prueba disponibles.

run

Ejecuta las pruebas (regenera casos de prueba temporales y los compara con los archivos de referencia).

update

Regenera y actualiza los archivos de referencia de datos de prueba. Debe lanzarse al menos una vez para tener los archivos de referencia para comparar durante las pruebas.

Donde:

NÚMERO

Es el número de índice del caso de prueba del comando de lista testasciidoc.

BACKEND

Es el backend de asciidoc a utilizar.

OPCIONES

Son las opciones listadas a continuación.

OPCIONES

-f, --conf-file=ARCHIVO_CONF

Utiliza el archivo de configuración ARCHIVO_CONF para más información sobre el formato del archivo de configuración, consulte la documentación de las pruebas.

--force

Actualiza todos los datos de prueba, sobrescribiendo los datos existentes.

EJEMPLOS

testasciidoc list

Lista todas las acciones de prueba disponibles para ejecutar o actualizar.

testasciidoc run

Ejecuta todas las acciones de prueba disponibles.

testasciidoc run --number 1 --backend html5 --conf-file=/etc/asciidoc/testasciidoc.conf

Ejecuta el caso de prueba 1 para el backend de asciidoc html5 utilizando el archivo de configuración /etc/asciidoc/testasciidoc.conf.

testasciidoc update --number 1 --backend html5

Genera o actualiza los archivos de referencia utilizados para la primera acción de los casos de prueba del backend de asciidoc html5.
