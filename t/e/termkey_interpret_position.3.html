termkey_interpret_position(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_INTERPRET_POSITION(3) Manual de funciones de la biblioteca TERMKEY_INTERPRET_POSITION(3)

NOMBRE

termkey_interpret_position - interpretar datos opacos del evento de posición del cursor

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_interpret_position(TermKey *tk, const TermKeyKey *key, 
    int *line, int *col);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_interpret_position() rellena las variables en los punteros pasados según el evento de informe de posición del cursor que se encuentra en key. Debería llamarse si termkey_getkey(3) o similar han devuelto un evento de tecla con el tipo TERMKEY_TYPE_POSITION.

Cualquier puntero puede darse en su lugar como NULL para no devolver ese valor.

Las variables line y col se rellenarán con la posición del cursor, indexadas a partir de 1. Tenga en cuenta que debido al número limitado de bytes en la estructura TermKeyKey, los números de línea y columna están limitados a 2047 y 4095 respectivamente.

VALOR DE RETORNO

Si se le pasa un evento key de tipo TERMKEY_TYPE_POSITION, esta función devolverá TERMKEY_RES_KEY y afectará a las variables cuyos punteros se pasaron, como se describe anteriormente.

Para otros tipos de eventos devolverá TERMKEY_RES_NONE, y sus efectos en cualquier variable cuyos punteros se pasaron, no están definidos.

VER TAMBIÉN

termkey_waitkey(3), termkey_getkey(3), termkey(7)
