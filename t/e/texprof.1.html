TEXPROF(1) Manual de Comandos Generales TEXPROF(1)

NOMBRE

texprof - Un perfilador para archivos fuente de TeX

SINOPSIS

texprof [opciones] [&formato] [archivo|\comandos]

DESCRIPCIÓN

Ejecuta el perfilador de TeX en archivo, creando normalmente archivo.dvi y archivo.tprof. Si el argumento archivo no tiene extensión, se le añadirá ".tex". En lugar de un nombre de archivo, se puede proporcionar una lista de comandos TeX, el primero de los cuales debe empezar con una barra invertida. Con un argumento &formato, el perfilador de TeX utiliza un conjunto diferente de comandos precompilados, contenidos en formato.fmt; normalmente es mejor usar la opción -fmt formato en su lugar.

El perfilador de TeX es una versión de TeX que mide el tiempo que TeX necesita para ejecutar líneas de entrada o macros individuales. Escribe los datos recopilados en un archivo con la extensión .tprof. Un programa separado, texprofile (ver texprofile(1)), se utiliza para mostrar el contenido de un archivo .tprof de forma legible.

El uso típico del perfilador de TeX es con formatos pregenerados. El comando texprof utiliza el equivalente al formato plain TeX, y el comando latexprof utiliza el equivalente al formato LaTeX. Para investigar el tiempo de las macros dirigidas a pdftex o pdflatex, se pueden usar pdftexprof o pdflatexprof.

El manejo de los argumentos de línea de comandos por parte del perfilador de TeX es similar al de otros programas TeX en la implementación de web2c.

OPCIONES

Esta versión del perfilador de TeX entiende las siguientes opciones de línea de comandos.

-cnf-line cadena
Analiza cadena como una línea de configuración de texmf.cnf. Ver el manual de Kpathsea.
-etex
Habilita las extensiones e-TeX. Esta opción solo es efectiva en combinación con -ini. Ver etex(1).
-file-line-error
Imprime mensajes de error en el formato archivo:línea:error que es similar a la forma en que muchos compiladores los formatean.
-no-file-line-error
Deshabilita la impresión de mensajes de error en el estilo archivo:línea:error.
-fmt formato
Utiliza formato como el nombre del formato a ser usado, en lugar del nombre por el cual se llamó al perfilador de TeX o una línea %&.
-help
Imprime el mensaje de ayuda y sale.
-ini
Inicia en modo INI, que se usa para volcar formatos. El modo INI puede ser usado para composición tipográfica, pero no se carga ningún formato previamente, y pueden ser necesarias inicializaciones básicas como el establecimiento de códigos de categoría.
-interaction modo
Establece el modo de interacción. El modo puede ser batchmode, nonstopmode, scrollmode y errorstopmode. El significado de estos modos es el mismo que el de los \comandos correspondientes.
-jobname nombre
Usa nombre para el nombre del trabajo, en lugar de derivarlo del nombre del archivo de entrada.
-kpathsea-debug mascara-de-bits
Establece las banderas de depuración de búsqueda de rutas según la máscara de bits. Ver el manual de Kpathsea para más detalles.
-ltx
Habilita las extensiones de LaTeX. Esta opción solo es efectiva en combinación con -ini. Ver latex(1).
-mktex fmt
Habilita mktexfmt, donde fmt debe ser tex, tfm, fmt, o pk.
-no-mktex fmt
Deshabilita mktexfmt, donde fmt debe ser tex, tfm, fmt, o pk.
-output-directory directorio
Escribe los archivos de salida en directorio en lugar del directorio actual. Busca los archivos de entrada en directorio primero, luego a lo largo de la ruta de búsqueda normal.
-parse-first-line
Si la primera línea del archivo de entrada principal comienza con %&, analízala para buscar un nombre de volcado.
-no-parse-first-line
Deshabilita el análisis de la primera línea del archivo de entrada principal.
-pdf
Habilita la simulación de primitivas comunes de pdftex. Esta opción requiere la opción -ini e implica la opción -ltx. Ver pdftex(1).
-prof
Habilita la generación de perfiles tan pronto como TeX entra en el bucle principal. Si esta opción no se usa, la generación de perfiles debe ser activada usando la primitiva \profileon. La generación de perfiles puede ser desactivada con la primitiva \profileoff.
-progname nombre
Finge ser el programa nombre. Esto afecta tanto al formato utilizado como a las rutas de búsqueda.
-version
Imprime la información de la versión y sale.

AMBIENTE

Ver la documentación de la biblioteca Kpathsea (por ejemplo, el nodo `Path specifications') para obtener detalles precisos sobre cómo se utilizan las variables de entorno. La utilidad kpsewhich se puede utilizar para consultar los valores de las variables.

TEXMFOUTPUT
Normalmente, TeX coloca sus archivos de salida en el directorio actual. Si no se puede abrir ningún archivo de salida allí, intenta abrirlo en el directorio especificado en la variable de entorno TEXMFOUTPUT. No hay un valor predeterminado para esa variable. Por ejemplo, si dices texprof paper y el directorio actual no es escribible y TEXMFOUTPUT tiene el valor /tmp, TeX intenta crear /tmp/paper.log, /tmp/paper.dvi y /tmp/paper.tprof. TEXMFOUTPUT también se consulta para archivos de entrada, ya que TeX a menudo genera archivos que posteriormente deben ser leídos; para la entrada, no se añaden sufijos (como ``.tex'') por defecto, el nombre de entrada simplemente se verifica tal como se proporciona.
TEXINPUTS
Ruta de búsqueda para archivos \\input y \\openin. Esto normalmente empieza con ``.'', de modo que los archivos del usuario se encuentran antes que los archivos del sistema. Un componente de ruta vacío será reemplazado por las rutas definidas en el archivo texmf.cnf. Por ejemplo, establece TEXINPUTS a ".:/home/usuario/tex:" para anteponer el directorio actual y ``/home/usuario/tex'' a la ruta de búsqueda estándar.
TEXFORMATS
Ruta de búsqueda para archivos de formato.
TFMFONTS
Ruta de búsqueda para archivos de métricas de fuentes (.tfm).
SOURCE_DATE_EPOCH
Si está configurada, su valor, tomado como segundos de época, se utilizará para la fecha de creación y como momento de referencia para las primitivas relacionadas con el tiempo de LaTeX. Esto es útil para crear compilaciones reproducibles.
FORCE_SOURCE_DATE
Si está configurada con el valor "1", las primitivas de TeX relacionadas con el tiempo (\\year, \\month, \\day, \\time) también se inicializan desde el valor de SOURCE_DATE_EPOCH. No se recomienda esto si existe alguna alternativa viable.

Muchas, muchas más variables de entorno pueden ser consultadas en relación con la búsqueda de rutas. Ver el manual de Kpathsea.

texprof.1.en - Manual page

FILES

The TeX profiler searches for files in locations specified by the Kpathsea library. Use the kpsewhich utility to find their locations.

*.tfm
Archivos de métricas para las fuentes de TeX.
*.fmt
Archivos de formato TeX pre-digeridos.
*.pk *.pfb
Archivos de fuente utilizados por TeX.

NOTAS

Esta página del manual no pretende ser exhaustiva. La documentación completa para el generador de perfiles de TeX se puede encontrar en texprof.pdf. Se puede encontrar más información en el manual de la biblioteca Kpathsea.

ERRORES

Esta versión del generador de perfiles de TeX no implementa todos los primitivos que proporciona pdftex y, además, no producirá los mismos efectos secundarios.

DISPONIBILIDAD

El generador de perfiles de TeX debería compilarse en una gran variedad de arquitecturas de máquinas y sistemas operativos. La función para obtener información de tiempo es específica de POSIX.

Las fuentes del generador de perfiles de TeX se alojan en https://github.com/ruckertm/HINT
