TEXPROFILE(1) Visualización de perfiles TeX TEXPROFILE(1)

NOMBRE

texprofile - Muestra los datos del perfil recopilados por texprof.

SINOPSIS

texprofile [Opciones] archivo_entrada

DESCRIPCIÓN

texprofile lee el archivo_entrada binario producido por texprof. Se puede omitir la extensión .tprof del archivo de entrada. Analiza los datos y presenta los resultados en una variedad de tablas, ya sea optimizadas para la legibilidad humana o como archivos CSV (valores separados por comas) para su posterior procesamiento.

La salida se escribe en el flujo de salida estándar, donde puede ser redirigida a un archivo o visualizada inmediatamente.

OPCIONES

Hay cuatro tipos de opciones: opciones generales, opciones de tabla, opciones de selección y opciones de formato.

Las opciones generales:

-? -h --help

Muestra un texto de ayuda breve y sale del programa.
--version

Muestra la información de la versión y sale.

Las opciones de tabla determinan las tablas que se mostrarán. Todas estas opciones usan letras mayúsculas. Si no se proporciona ninguna opción de tabla, solo se muestra información global.

-T

Muestra la tabla de las 10 líneas de entrada principales.
-G

Muestra la tabla del grafo de llamadas de macros.
-C

Muestra la tabla de tiempos por comando TeX.
-L

Muestra la tabla de tiempos por línea de entrada.
-R

Muestra la tabla de marcas de tiempo brutas.
-S

Muestra la tabla de cambios de pila de macros.
-F

Muestra la tabla de todos los archivos de entrada.
-M

Muestra la tabla de todas las macros llamadas.
-A

Muestra las tablas importantes (equivalente a -TGFC).
-N

No muestra la tabla de información global.

Las opciones de selección permiten reducir la cantidad de datos que se muestran en la tabla omitiendo las entradas de tabla que contribuyen poco al tiempo de ejecución total.

-pn

No muestra información para entradas de tabla con un tiempo acumulado inferior al n por ciento. El valor predeterminado es 1.0 por ciento.
-tn

Limita el número de líneas de entrada mostradas en la tabla del "Top Ten" a n. Esta opción solo es útil con la opción -T.

La opción de formato determina el formato de la información en las tablas, así como la selección de información que se muestra en ellas.

-i

Añade el número de archivo y línea de las macros después del nombre de la macro. Esta opción es útil para distinguir dos macros que comparten el mismo nombre.
-m

Optimiza la salida para legibilidad por máquina. Cuando está optimizada para legibilidad humana, los tiempos se redondean y se dan en forma abreviada con un identificador de unidad: s para segundos, ms para milisegundos, us para microsegundos y ns para nanosegundos. Este formato es inconveniente si desea importar los datos, por ejemplo, a una hoja de cálculo para su procesamiento posterior. Con la opción -m, los tiempos se dan simplemente en nanosegundos sin unidades. De manera similar, el tiempo combinado para el tiempo total utilizado por una macro y el tiempo utilizado como sub-macro del grafo de llamadas se presenta en una sola columna, separando ambos números con una barra, lo cual es agradable para lectores humanos. Con la opción -m, ambos números se presentarán simplemente en columnas separadas.
-n

Muestra los números de marca de tiempo. Esta opción es útil junto con la opción -R si importa la tabla a una base de datos o hoja de cálculo. Si ordena los datos por varias propiedades en diferentes categorías, el número de marca de tiempo se puede usar para mantener las entradas dentro de una categoría ordenadas por tiempo.
-s

Muestra los cambios de la pila de macros. Esta opción es útil con la opción -R si desea ver los cambios en la pila de macros (ver -S) junto con la información de tiempo en una sola tabla.

FORMATOS DE DATOS

NÚMEROS DE ARCHIVO

Mientras texprof se está ejecutando, a cada archivo de entrada de TeX se le asigna un número de archivo único. El nombre del archivo por sí solo a menudo no es único porque dos archivos en directorios diferentes pueden tener el mismo nombre de archivo. Sin embargo, mostrar el nombre de archivo completo con la ruta completa a menudo no es muy conveniente. Por lo tanto, si observa el mismo nombre de archivo junto con diferentes números de archivo, puede usar la opción -F para obtener una tabla de todos los números de archivo y sus nombres de archivo completos.

Pero incluso dentro del mismo directorio, TeX puede leer diferentes archivos con el mismo nombre durante una ejecución: TeX puede abrir un archivo para escribir, escribir contenido en el archivo, cerrarlo, abrirlo para leerlo, leerlo y volver a cerrarlo. Luego, TeX puede repetir este proceso una segunda vez, o varias veces, reutilizando el mismo nombre de archivo una y otra vez. texprof asignará un nuevo número de archivo a este archivo cada vez que se abra para leer. Por lo tanto, puede saber por la secuencia de números de archivo cuál fue el primero, el segundo o el tercero.

Por último, existen algunos números de archivo especiales:

0 - desconocido
Si el archivo es desconocido, lo que rara vez debería suceder, se utiliza el número de archivo 0.
1 - sistema
texprof asignará intervalos de tiempo utilizados para ejecutar ciertas rutinas del sistema al archivo pseudo "sistema" usando los números de línea para identificar la rutina específica, como la producción del archivo DVI de salida (shipout), la división de un párrafo en líneas (linebrk) o la división del documento en páginas (buildpg). Estos tiempos no dependen del uso de macros, sino simplemente del tamaño del documento.
2 - terminal
Los comandos TeX introducidos en la línea de comandos o interactivamente se mapean al número de archivo 2.

TIEMPO

Si se proporciona la opción -m, los tiempos se dan en nanosegundos. De lo contrario, los tiempos se redondean a una precisión máxima de 4 dígitos y se muestran con una unidad: segundos (s), milisegundos (ms), microsegundos (um) o nanosegundos (ns).

NOMBRES DE MACROS

Los nombres de las macros se muestran con la barra invertida inicial. Dado que los nombres de las macros a menudo no son únicos, se puede usar la opción de línea de comandos -i para mostrar después del nombre de la macro, entre corchetes, el número de archivo y el número de línea donde se define la macro. A menos que dos macros con el mismo nombre se definan en el mismo archivo y línea, esto es suficiente para identificar de forma única una macro. Una macro definida con "let" resulta en una copia completa de la macro original. Por lo tanto, no hará referencia al archivo y línea del comando "let", sino al mismo archivo y línea que la macro original.

EJEMPLOS

Supongamos que emite el comando texprof -prof hello.tex. Esto ejecutará texprof en el archivo de entrada hello.tex con la opción -prof. El programa texprof cargará el formato plain TeX y luego procesará hello.tex para producir hello.log y hello.dvi. Ejecutará exactamente los mismos pasos que TeX ejecutaría si hubiera emitido el comando tex hello.tex.

Además de hello.log y hello.dvi, texprof también producirá el archivo hello.tprof que contiene mediciones de tiempo realizadas mientras texprof se estaba ejecutando. La opción -prof activará la recopilación de datos de tiempo tan pronto como texprof ingrese a su procedimiento de control principal; el archivo hello.tprof contendrá una medida de tiempo
