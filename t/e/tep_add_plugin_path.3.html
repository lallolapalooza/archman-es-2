tep_add_plugin_path(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_load_plugins, tep_unload_plugins, tep_load_plugins_hook, tep_add_plugin_path, tep_plugin_add_option - Cargar / descargar plugins de traceevent.

SINOPSIS

#include <event-parse.h>
struct tep_plugin_list *tep_load_plugins(struct tep_handle *tep);
void tep_unload_plugins(struct tep_plugin_list *plugin_list, struct tep_handle *tep);
void tep_load_plugins_hook(struct tep_handle *tep, const char *suffix,
                           void (*load_plugin)(struct tep_handle *tep,
                                               const char *path,
                                               const char *name,
                                               void *data),
                           void *data);
int tep_add_plugin_path(struct tep_handle *tep, char *path,
                          enum tep_plugin_load_priority prio);
int tep_plugin_add_option(const char *name, const char *val);

DESCRIPCIÓN

La función tep_load_plugins() carga todos los plugins, ubicados en los directorios de plugins. El argumento tep es el contexto del analizador de eventos de traza. Los directorios de plugins son:

        - Directorios especificados en tep→plugins_dir con prioridad
          TEP_PLUGIN_FIRST
        - Directorio de plugins del sistema, definido en el momento de la compilación
          de la biblioteca. Depende del prefijo de instalación de la biblioteca y
          generalmente es (prefijo_instalacion)/lib/traceevent/plugins
        - Directorio definido por la variable de entorno
          TRACEEVENT_PLUGIN_DIR
        - Directorio de plugins del usuario, ubicado en
          ~/.local/lib/traceevent/plugins
        - Directorios especificados en tep→plugins_dir con prioridad
          TEP_PLUGIN_LAST

La carga de plugins puede ser controlada por tep_flags, usando la API tep_set_flag():

        TEP_DISABLE_SYS_PLUGINS       - no cargar plugins ubicados en el
                                        directorio de plugins del sistema.
        TEP_DISABLE_PLUGINS           - no cargar ningún plugin.

La API tep_set_flag() debe ser llamada antes de tep_load_plugins(), si no se desea cargar todos los plugins.

La función tep_unload_plugins() descarga los plugins, previamente cargados por tep_load_plugins(). El argumento tep es el contexto del analizador de eventos de traza. plugin_list es la lista de plugins cargados, devuelta por la función tep_load_plugins().

La función tep_load_plugins_hook() recorre todos los directorios con plugins y llama al hook de carga de plugin especificado por el usuario (load_plugin()) para cada archivo de plugin. Solo los archivos con el sufijo dado (suffix) se consideran plugins. El argumento data es un contexto especificado por el usuario, pasado a load_plugin(). Los directorios y el orden de recorrido son los mismos que en la API tep_load_plugins().

La función tep_add_plugin_path() agrega directorios adicionales con plugins a la lista tep→plugins_dir. Debe ser llamada antes de tep_load_plugins() para que los plugins de los nuevos directorios sean cargados. El argumento tep es el contexto del analizador de eventos de traza. El argumento path es la ruta completa al nuevo directorio de plugins. El argumento prio especifica el orden de prioridad de carga para el nuevo directorio de plugins. La prioridad de carga es importante en caso de diferentes versiones del mismo plugin ubicadas en múltiples directorios de plugins. El último plugin cargado gana. La prioridad puede ser:

        TEP_PLUGIN_FIRST      - Cargar plugins de este directorio primero
        TEP_PLUGIN_LAST       - Cargar plugins de este directorio al último

Donde los plugins en TEP_PLUGIN_LAST" tendrán precedencia sobre los plugins de los otros directorios.

La función tep_plugin_add_option() establece opciones definidas por un plugin. name es el nombre de la opción a establecer a val. Los plugins pueden agregar opciones para cambiar su comportamiento y tep_plugin_add_option() es utilizada por la aplicación para realizar esas modificaciones.

VALOR DE RETORNO

La función tep_load_plugins() devuelve una lista de plugins cargados exitosamente, o NULL en caso de que no se carguen plugins. La función tep_add_plugin_path() devuelve -1 en caso de error, 0 en caso contrario.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
tep_add_plugin_path(tep, "~/dev_plugins", TEP_PLUGIN_LAST);
...
struct tep_plugin_list *plugins = tep_load_plugins(tep);
if (plugins == NULL) {
        /* no se cargaron plugins */
}
...
tep_unload_plugins(plugins, tep);
...
void print_plugin(struct tep_handle *tep, const char *path,
                  const char *name, void *data)
{
        pritnf("Encontrado plugin libtraceevent %s/%s\n", path, name);
}
...
tep_load_plugins_hook(tep, ".so", print_plugin, NULL);
...
