termkey_interpret_csi(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_INTERPRET_CSI(3) Manual de funciones de biblioteca TERMKEY_INTERPRET_CSI(3)

NOMBRE

termkey_interpret_csi - interpretar secuencia CSI no reconocida

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_interpret_csi(TermKey *tk, const TermKeyKey *key, 
    long *args[], size_t *nargs, unsigned long *cmd);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_interpret_csi() rellena las variables en los punteros pasados de acuerdo con el evento de secuencia CSI no reconocida encontrado en key. Debe ser llamada si termkey_getkey(3) o similar han devuelto un evento de tecla con el tipo de TERMKEY_TYPE_UNKNOWN_CSI. Tenga en cuenta que es importante llamar a esta función tan pronto como sea posible después de obtener un evento de tecla TERMKEY_TYPE_CSI; específicamente, antes de llamar a termkey_getkey() o termkey_waitkey() de nuevo, ya que una llamada posterior sobrescribirá el espacio del búfer que contiene actualmente esta secuencia.

La matriz args se rellenará con los argumentos numéricos de la secuencia CSI. El número de elementos disponibles en esta matriz se proporcionará como el valor inicial del valor apuntado por nargs, que se ajustará para dar el número de argumentos encontrados realmente cuando la función regrese. La variable cmd contendrá el valor del comando CSI. Si se encontró un byte inicial (como '?') entonces se aplicará un OR a bit con el valor del comando, desplazado hacia arriba en 8 bits. Si se encontró un byte intermedio (como '$') entonces se aplicará un OR a bit con el valor del comando, desplazado hacia arriba en 16 bits.

    *cmd = command | (initial << 8) | (intermediate << 16);

VALOR DE RETORNO

Si se le pasa un evento key del tipo TERMKEY_TYPE_UNKNOWN_CSI, esta función devolverá TERMKEY_RES_KEY y afectará a las variables cuyos punteros se pasaron, como se describe arriba.

Para otros tipos de eventos devolverá TERMKEY_RES_NONE, y sus efectos sobre cualquier variable cuyos punteros se pasaron son indefinidos.

VER TAMBIÉN

termkey_waitkey(3), termkey_getkey(3), termkey(7)
