termios.h(0P) Manual del programador POSIX termios.h(0P)

PROLOGO

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

termios.h — definir valores para termios

SINOPSIS

#include <termios.h>

DESCRIPCIÓN

La cabecera <termios.h> contendrá las definiciones utilizadas por las interfaces de E/S de terminal (consulte el Capítulo 11, Interfaz General de Terminal para conocer las estructuras y los nombres definidos).

La estructura termios

La cabecera <termios.h> definirá los siguientes tipos de datos mediante typedef:

cc_t
Usado para caracteres especiales de terminal.
speed_t
Usado para velocidades en baudios de terminal.
tcflag_t
Usado para modos de terminal.

Los tipos anteriores serán todos tipos de enteros sin signo.

La implementación admitirá uno o más entornos de programación en los que los anchos de cc_t, speed_t y tcflag_t no sean mayores que el ancho del tipo long. Los nombres de estos entornos de programación se pueden obtener utilizando la función confstr() o la utilidad getconf.

La cabecera <termios.h> definirá la estructura termios, que contendrá al menos los siguientes miembros:

tcflag_t  c_iflag     Modos de entrada.
tcflag_t  c_oflag     Modos de salida.
tcflag_t  c_cflag     Modos de control.
tcflag_t  c_lflag     Modos locales.
cc_t      c_cc[NCCS]  Caracteres de control.

La cabecera <termios.h> definirá la siguiente constante simbólica:

NCCS
Tamaño del array c_cc para caracteres de control.

La cabecera <termios.h> definirá las siguientes constantes simbólicas para su uso como subíndices del array c_cc:

Uso de subíndices
Modo Canónico Modo No Canónico Descripción
VEOF Carácter EOF.
VEOL Carácter EOL.
VERASE Carácter ERASE.
VINTR VINTR Carácter INTR.
VKILL Carácter KILL.
VMIN Valor MIN.
VQUIT VQUIT Carácter QUIT.
VSTART VSTART Carácter START.
VSTOP VSTOP Carácter STOP.
VSUSP VSUSP Carácter SUSP.
VTIME Valor TIME.

Los valores de los subíndices serán adecuados para su uso en directivas de preprocesamiento #if y serán distintos, excepto que los subíndices VMIN y VTIME pueden tener los mismos valores que los subíndices VEOF y VEOL, respectivamente.

Ignorar la condición de break.

Ignorar CR.

IXON
Habilitar el control de inicio/parada de salida.
PARMRK
Marcar errores de paridad.

NAME

termios.h — termios interface

SYNOPSIS

#include <termios.h>

DESCRIPTION

The <termios.h> header defines the structures and symbolic constants used by the general terminal interface defined by POSIX.1.

The general terminal interface allows applications to control asynchronously communicating terminals in a portable manner.

The following are defined:

ISIG
Enable signals.

The <termios.h> header defines the following symbolic constants for use as flags in the c_iflag field. The c_iflag field describes the behavior of the terminal driver in terminals receiving input.

BRKINT
Strip the parity set bits from the input.
ICRNL
Map carriage return to new-line on input.
INLCR
Map new-line to carriage return on input.
IGNCR
Ignore carriage return on input.
IGNBRK
Ignore break condition.
IGNPAR
Ignore framing errors and parity errors.
INPCK
Enable input parity check.
ISTRIP
Strip any 8th bit from input characters.
IXANY
Carry on output on any character when the output is stopped.
IXOFF
Enable system level flow control.
IXON
Enable software flow control.
IEXTEN
Enable implementation-defined input processing.

The <termios.h> header defines the following symbolic constants for use as flags in the c_oflag field. The c_oflag field describes the behavior of the terminal driver in terminals sending output.

OPOST
Enable implementation-defined output processing.
OLCUC
Convert lower-case to upper-case on output.
OCRNL
Map carriage return to new-line on output.
ONLCR
Map new-line to carriage return on output.
ONOCR
Map carriage return to new-line only on output.
ONLRET
The ONLCR mapping of the newline character is `effective' only on the physical terminal device.
CS5
5 bits per character.
CS6
6 bits per character.
CS7
7 bits per character.
CS8
8 bits per character.
TCSANOW
Change attributes immediately.
TCSADRAIN
Wait for output to drain before changing attributes.
TCSAFLUSH
Wait for output to drain before changing attributes, then flush all input.
TCIFLUSH
Flush all queued input.
TCIOFLUSH
Flush all queued input and output.
TCOFLUSH
Flush all queued output.
TCION
Resume transmission on the serial line.
TCIOFF
Suspend transmission on the serial line.
TCOON
Resume transmission of output.
TCOOFF
Suspend transmission of output.

The <termios.h> header defines the following symbolic constants for use as values of the c_cc array.

VINTR
Interrupt character.
VQUIT
Quit character.
VERASE
Erase character.
VKILL
Kill character.
VEOF
End-of-file character.
VTIME
Minimum number of bytes for noncanonical read.
VMIN
Timeout in deciseconds for noncanonical read.
VSWTC
Suspends background output.
VSTART
Continues output.
VSTOP
Suspends output.
VDISCARD
Discard typed characters.
VWERASE
Erase next word.
VLNEXT
Literal next character.
BS0
Back-space delay type 0.
BS1
Backspace-delay type 1.
VTDLY
Select vertical-tab delays:
VT0
Vertical-tab delay type 0.
VT1
Vertical-tab delay type 1.
FFDLY
Select form-feed delays:
FF0
Form-feed delay type 0.
FF1
Form-feed delay type 1.

The <termios.h> header shall define the following symbolic constants for use as values of objects of type speed_t.

The input and output baud rates are stored in the termios structure. These are the valid values for objects of type speed_t. Not all baud rates need be supported by the underlying hardware.

Control Modes

The <termios.h> header shall define the following symbolic constants for use as flags in the c_cflag field. The c_cflag field describes the hardware control of the terminal; not all values specified are required to be supported by the underlying hardware.

CSIZE
Character size:
CS5
5 bits
CS6
6 bits
CS7
7 bits
CS8
8 bits
CSTOPB
Send two stop bits, else one.
CREAD
Enable receiver.
PARENB
Parity enable.
PARODD
Odd parity, else even.
HUPCL
Hang up on last close.
CLOCAL
Ignore modem status lines.

The implementation shall support the functionality associated with the symbols CS7, CS8, CSTOPB, PARODD, and PARENB.

Local Modes

The <termios.h> header shall define the following symbolic constants for use as flags in the c_lflag field. The c_lflag field of the argument structure is used to control various terminal functions.

ECHO
Enable echo.
ECHOE
Echo erase character as error-correcting backspace.
ECHOK
Echo KILL.
ECHONL
Echo NL.
ICANON
Canonical input (erase and kill processing).
IEXTEN
Enable extended input character processing.
ISIG
Enable signals.
NOFLSH
Disable flush after interrupt or quit.
TOSTOP
Send SIGTTOU for background output.

Attribute Selection

The <termios.h> header shall define the following symbolic constants for use with tcsetattr():

TCSANOW
Change attributes immediately.
TCSADRAIN
Change attributes when output has drained.
TCSAFLUSH
Change attributes when output has drained; also flush pending input.

Line Control

The <termios.h> header shall define the following symbolic constants for use with tcflush():

TCIFLUSH
Flush pending input.
TCIOFLUSH
Flush both pending input and untransmitted output.
TCOFLUSH
Flush untransmitted output.

The <termios.h> header shall define the following symbolic constants for use with tcflow():

TCIOFF
Transmit a STOP character, intended to suspend input data.
TCION
Transmit a START character, intended to restart input data.
TCOOFF
Suspend output.
TCOON
Restart output.

The <termios.h> header shall define the pid_t type as described in <sys/types.h>.

The following shall be declared as functions and may also be defined as macros. Function prototypes shall be provided.

speed_t cfgetispeed(const struct termios *);
speed_t cfgetospeed(const struct termios *);
int     cfsetispeed(struct termios *, speed_t);
int     cfsetospeed(struct termios *, speed_t);
int     tcdrain(int);
int     tcflow(int, int);
int     tcflush(int, int);
int     tcgetattr(int, struct termios *);
pid_t   tcgetsid(int);
int     tcsendbreak(int, int);
int     tcsetattr(int, int, const struct termios *);
