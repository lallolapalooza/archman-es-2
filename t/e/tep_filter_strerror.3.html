tep_filter_strerror(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_filter_alloc, tep_filter_free, tep_filter_reset, tep_filter_make_string, tep_filter_copy, tep_filter_compare, tep_filter_match, tep_event_filtered, tep_filter_remove_event, tep_filter_strerror, tep_filter_add_filter_str - APIs relacionadas con el filtrado de eventos.

SINOPSIS

#include <event-parse.h>
struct tep_event_filter *tep_filter_alloc(struct tep_handle *tep);
void tep_filter_free(struct tep_event_filter *filter);
void tep_filter_reset(struct tep_event_filter *filter);
enum tep_errno tep_filter_add_filter_str(struct tep_event_filter *filter, const char *filter_str);
int tep_event_filtered(struct tep_event_filter *filter, int event_id);
int tep_filter_remove_event(struct tep_event_filter *filter, int event_id);
enum tep_errno tep_filter_match(struct tep_event_filter *filter, struct tep_record *record);
int tep_filter_copy(struct tep_event_filter *dest, struct tep_event_filter *source);
int tep_filter_compare(struct tep_event_filter *filter1, struct tep_event_filter *filter2);
char *tep_filter_make_string(struct tep_event_filter *filter, int event_id);
int tep_filter_strerror(struct tep_event_filter *filter, enum tep_errno err, char *buf, size_t buflen);

DESCRIPCIÓN

Se pueden adjuntar filtros a los eventos rastreados. Se pueden utilizar para filtrar varios eventos al mostrarlos. Cada evento puede filtrarse según sus parámetros, descritos en el archivo de formato del evento. Este conjunto de funciones se puede usar para crear, eliminar, modificar y adjuntar filtros de eventos.

La función tep_filter_alloc() crea un nuevo filtro de eventos. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_filter_free() libera un filtro de eventos y todos los recursos que haya utilizado.

La función tep_filter_reset() elimina todas las reglas de un filtro de eventos y lo restablece.

La función tep_filter_add_filter_str() añade una nueva regla al filter. El argumento filter_str es la cadena del filtro, que contiene la regla.

La función tep_event_filtered() comprueba si el evento con event_id tiene filter.

La función tep_filter_remove_event() elimina un filter para un evento con event_id.

La función tep_filter_match() prueba si un record coincide con el filter dado.

La función tep_filter_copy() copia un filtro source en un filtro dest.

La función tep_filter_compare() compara dos filtros: filter1 y filter2.

La función tep_filter_make_string() construye una cadena que muestra el contenido del filter para el event_id dado.

La función tep_filter_strerror() copia el búfer de error del filter en el buf dado con el tamaño buflen. Si el búfer de error está vacío, en el buf se copia una cadena que describe el error err.

VALOR DE RETORNO

La función tep_filter_alloc() devuelve un puntero al filtro de eventos recién creado, o NULL en caso de error.

La función tep_filter_add_filter_str() devuelve 0 si la regla se añadió correctamente o un código de error negativo. Utilice tep_filter_strerror() para ver el mensaje de error real en caso de error.

La función tep_event_filtered() devuelve 1 si se encuentra el filtro para el evento dado, o 0 en caso contrario.

La función tep_filter_remove_event() devuelve 1 si se eliminó el evento, o 0 si no se encontró el evento.

La función tep_filter_match() devuelve tep_errno, según el resultado:

TEP_ERRNO__FILTER_MATCH        - se encuentra el filtro para el evento, el registro coincide.
TEP_ERRNO__FILTER_MISS         - se encuentra el filtro para el evento, el registro no coincide.
TEP_ERRNO__FILTER_NOT_FOUND    - no se encuentra ningún filtro para el evento del registro.
TEP_ERRNO__NO_FILTER           - no hay reglas en el filtro.

o cualquier otro tep_errno, si ocurrió un error durante la prueba.

La función tep_filter_copy() devuelve 0 si tiene éxito o -1 si no se copiaron todas las reglas.

La función tep_filter_compare() devuelve 1 si los dos filtros tienen el mismo contenido, o 0 si no es así.

La función tep_filter_make_string() devuelve una cadena que debe liberarse con free(), o NULL en caso de error.

La función tep_filter_strerror() devuelve 0 si el mensaje se rellenó correctamente, o -1 en caso de error.

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char errstr[200];
int ret;
struct tep_event_filter *filter = tep_filter_alloc(tep);
struct tep_event_filter *filter1 = tep_filter_alloc(tep);
ret = tep_filter_add_filter_str(filter, "sched/sched_wakeup:target_cpu==1");
if(ret < 0) {
        tep_filter_strerror(filter, ret, errstr, sizeof(errstr));
        /* Error al añadir una nueva regla al filtro, el mensaje de error está en errstr */
}
if (tep_filter_copy(filter1, filter) != 0) {
        /* Error al copiar el filtro en filter1 */
}
...
if (tep_filter_compare(filter, filter1) != 1) {
        /* Ambos filtros son diferentes */
}
...
void process_record(struct tep_handle *tep, struct tep_record *record)
{
        struct tep_event *event;
        char *fstring;
        event = tep_find_event_by_record(tep, record);
        if (tep_event_filtered(filter, event->id) == 1) {
                /* El evento tiene filtro */
                fstring = tep_filter_make_string(filter, event->id);
                if (fstring != NULL) {
                        /* El filtro para el evento está en fstring */
                        free(fstring);
                }
        }
        switch (tep_filter_match(filter, record)) {
        case TEP_ERRNO__FILTER_MATCH:
                /* El filtro coincide con el registro */
                break;
        case TEP_ERRNO__FILTER_MISS:
                /* El filtro no coincide con el registro */
                break;
        case TEP_ERRNO__FILTER_NOT_FOUND:
                /* No se encontró filtro para el evento del registro */
                break;
        case TEP_ERRNO__NO_FILTER:
                /* No hay reglas en el filtro */
                break
        default:
                /* Ocurrió un error durante la prueba */
                break;
        }
        if (tep_filter_remove_event(filter, event->id) == 1) {
                /* El evento se eliminó del filtro */
        }
}
...
tep_filter_reset(filter);
...
tep_filter_free(filter);
tep_filter_free(filter1);

tep_filter_strerror

3 11/16/2025

NAME

tep_filter_strerror - returns a string representation of an error code

SYNOPSIS

#include <eventparse.h>

char *
tep_filter_strerror(int error_code);

DESCRIPTION

The tep_filter_strerror() function returns a pointer to a static string describing the error code passed in error_code. The return value is NULL if the error code is unknown.

RETURN VALUE

On success, tep_filter_strerror() returns a pointer to the error description string. On failure, it returns NULL.

EXAMPLE

```c #include <stdio.h> #include <eventparse.h> int main(void) { int error_code = TEP_FILTER_ERROR_NOT_FOUND; char *error_str = tep_filter_strerror(error_code); if (error_str) { printf("Error description: %s\n", error_str); } else { printf("Unknown error code: %d\n", error_code); } return 0; } ```
