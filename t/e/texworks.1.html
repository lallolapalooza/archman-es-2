TEXWORKS(1) Manual de Comandos Generales TEXWORKS(1)

NOMBRE

texworks - un programa frontal simple de TeX

SINOPSIS

texworks [OPCIONES] [ARCHIVOS]

DESCRIPCIÓN

TeXworks es un entorno para escribir documentos TeX (LaTeX, ConTeXt, etc.), con un editor sensible a TeX basado en Unicode, visor de PDF integrado y una interfaz limpia y sencilla accesible a usuarios ocasionales y no técnicos.

Está inspirado en el premiado programa TeXShop de Dick Koch para Mac OS X, que ha hecho que la composición tipográfica de calidad a través de TeX sea accesible a una comunidad más amplia de usuarios, sin una cara técnica o intimidante. El objetivo de TeXworks es ofrecer un entorno integrado y fácil de usar similar para usuarios de otras plataformas, especialmente GNU/Linux y Windows.

OPCIONES

--ayuda, -?
Muestra un resumen breve de todas las opciones de la línea de comandos
--posiciÓn=, -p
Abre el siguiente archivo especificado en la posición dada (línea o página)
--versiÓn, -v
Muestra información de la versión

ENTORNO

TW_INIPATH
Anula la ubicación del archivo de preferencias.
TW_LIBPATH
Anula la ubicación de archivos adicionales de configuración y biblioteca.
TW_DICPATH
Anula la ubicación de los archivos de diccionario.
TW_HELPPATH
Anula la ubicación de los archivos de ayuda.
TW_PLUGINPATH
Anula la ubicación de los plugins.

ARCHIVOS

~/.config/TUG/TeXworks.conf
Archivo de texto para almacenar las preferencias.
~/.TeXworks/*
Archivos adicionales de configuración y biblioteca (por ejemplo, para autocompletado, plantillas, etc.).
/usr/local/bin/texworks-setup.ini
Archivo de configuración para anular la ubicación de los archivos mencionados anteriormente (por ejemplo, para habilitar la operación portátil).
