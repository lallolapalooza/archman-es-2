TERMINATOR_CONFIG(5) Manual para Terminator TERMINATOR_CONFIG(5)

NOMBRE

terminator_config - el archivo de configuración para el emulador de terminal Terminator

DESCRIPCIÓN

Este archivo contiene la configuración para terminator(1). Terminator gestiona su archivo de configuración a través de la biblioteca ConfigObj para combinar flexibilidad con archivos claros y editables por humanos.
Terminator ofrece un editor de preferencias GUI completo que guarda automáticamente su archivo de configuración para que no necesite escribir un archivo de configuración a mano.

UBICACIÓN DEL ARCHIVO

Normalmente, el archivo de configuración estará en ~/.config/terminator/config, pero puede ser anulado con $XDG_CONFIG_HOME (en cuyo caso será $XDG_CONFIG_HOME/terminator/config).

FORMATO DEL ARCHIVO

Así es como debería verse un archivo de configuración de Terminator:

# Esto es un comentario
[global_config]
  focus = system
[keybindings]
  full_screen = <Ctrl><Shift>F11
[profiles]
  [[default]]
    font = Fixed 10
    background_color = "#000000" # Un comentario
    foreground_color = "#FFFFFF" # Nótese que los valores de color hexadecimal deben estar entre comillas
    scrollback_lines = '500' # Más comentarios. Las comillas simples también son válidas
    cursor_blink = True
    custom_command = "echo \"foo#bar\"" # Comentario final - esto funcionará como se espera.
[layouts]
  [[default]]
    [[[window0]]]
      type = Window
      parent = ""
    [[[child1]]]
      type = Terminal
      parent = window0
[plugins]

CONFIGURACIÓN GLOBAL

Estas son las opciones que Terminator admite actualmente en la sección global_config.

Comportamiento y Apariencia de la Ventana

window_state = cadena

Controla cómo se abre la ventana de Terminator. 'normal' para abrirla normalmente. 'maximise' para abrirla maximizada. 'fullscreen' para abrirla en pantalla completa. 'hidden' para mantenerla oculta.
Valor por defecto: normal

always_on_top = booleano

Si se establece en True, la ventana siempre permanecerá encima de otras ventanas.
Valor por defecto: False

sticky = booleano

Si se establece en True, la ventana será visible en todos los escritorios virtuales.
Valor por defecto: False

hide_on_lose_focus = booleano

Si se establece en True, la ventana se ocultará cuando pierda el foco.
Valor por defecto: False

hide_from_taskbar = booleano

Si se establece en True, la ventana se ocultará de la barra de tareas.
Valor por defecto: False

geometry_hinting = booleano

Si se establece en True, la ventana se redimensionará al mismo ritmo que el tamaño de la fuente.
Valor por defecto: False

ask_before_closing = cadena

Especifica cuándo pedir confirmación antes de cerrar una ventana o una pestaña. Puede ser cualquiera de: 'always', 'multiple_terminals', 'never'. Valor por defecto: multiple_terminals

borderless = booleano

Si se establece en True, la ventana se iniciará sin bordes.
Valor por defecto: False

Comportamiento y Apariencia de las Pestañas

tab_position = cadena

Especifica dónde se colocan las pestañas. Puede ser cualquiera de: 'top', 'left', 'right', 'bottom', 'hidden'. Si se establece en 'hidden', la barra de pestañas no se mostrará. Ocultar la barra de pestañas no es recomendable, ya que puede ser muy confuso.
Valor por defecto: top

close_button_on_tab = booleano

Si se establece en True, las pestañas tendrán un botón de cierre en ellas.
Valor por defecto: True

scroll_tabbar = booleano

Si se establece en True, la barra de pestañas no ocupará todo el ancho de la ventana. Los títulos de las pestañas solo ocuparán el espacio necesario para el texto que contienen. Excepto, claro está, si las pestañas ya no caben en el ancho de la ventana, en cuyo caso aparecerán botones de desplazamiento para moverse entre las pestañas.
Valor por defecto: False

Comportamiento y Apariencia del Terminal

focus = cadena

Especifica cómo se otorga el foco a los terminales. 'click' significa que el foco solo se mueve a un terminal después de hacer clic en él. 'sloppy' significa que el foco seguirá al puntero del ratón. 'system' significa que el foco coincidirá con el utilizado por un gestor de ventanas GNOME.
Valor por defecto: click

always_split_with_profile = booleano

Especifica si las divisiones/pestañas continuarán utilizando el perfil de su terminal par. Si se establece en False, siempre usarán el perfil por defecto.
Valor por defecto: False

link_single_click = booleano

Si se establece en True, hacer clic en un enlace lo abrirá incluso si no se presiona Ctrl.
Valor por defecto: False

putty_paste_style = booleano

Si se establece en True, el clic derecho pegará texto, mientras que el clic central abrirá el menú contextual. La fuente del texto pegado depende del valor de putty_paste_style_source_clipboard.
Valor por defecto: False

putty_paste_style_source_clipboard = booleano

Si se establece en True, el portapapeles se utilizará como fuente para pegar al estilo PuTTY. De lo contrario, se utilizará la Selección Primaria.
Esta opción se ignora a menos que putty_paste_style esté establecido en True.
Valor por defecto: False

disable_mouse_paste = booleano

Si se establece en True, el pegado con el ratón estará deshabilitado.
Valor por defecto: False

smart_copy = booleano

Si se establece en True, y no hay selección, el atajo de teclado se permitirá pasar. Esto es útil para sobrecargar Ctrl-C para copiar una selección, o enviar la señal SIGINT al proceso actual si no hay selección. Si es False, el atajo de teclado no pasa en absoluto, y la señal SIGINT no se envía.
Valor por defecto: True

clear_select_on_copy = booleano

Si se establece en True, la selección de texto se borrará después de copiar usando el atajo de teclado copy.
Valor por defecto: False

handle_size = entero

Especifica el ancho del separador entre terminales. Cualquier valor fuera del rango 0-20 (inclusive) será ignorado y se usará el valor del tema por defecto en su lugar.
Valor por defecto: 1

inactive_color_offset = flotante

Especifica cuánto reducir los valores de color de las fuentes en los terminales que no tienen foco.
Valor por defecto: 0.8

inactive_bg_color_offset = flotante

Especifica cuánto reducir los valores de color del fondo en los terminales que no tienen foco.
Valor por defecto: 1.0

cell_width = flotante

Especifica la escala horizontal de las celdas de caracteres en el terminal.
Valor por defecto: 1.0

cell_height = flotante

Especifica la escala vertical de las celdas de caracteres en el terminal.
Valor por defecto: 1.0

title_at_bottom = booleano

Si se establece en True, la barra de título del terminal se dibujará en la parte inferior en lugar de en la superior.
Valor por defecto: False

Varios

dbus = booleano

Especifica si Terminator cargará su servidor DBus. Cuando este servidor está cargado, ejecutar Terminator varias veces hará que el primer proceso de Terminator abra ventanas adicionales. Si esta opción de configuración se establece en False, o si el módulo DBus de Python no está disponible, ejecutar Terminator varias veces ejecutará un proceso de Terminator separado para cada invocación.
Valor por defecto: True

extra_styling = booleano

Si se establece en True, Terminator puede cargar un archivo de estilo CSS adicional, dependiendo del tema.
Valor por defecto: False

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

ault value: True

broadcast_default = cadena

Especifica el comportamiento predeterminado de difusión. Puede ser cualquiera de: 'all', 'group', 'off'.
Valor por defecto: group

use_custom_url_handler = booleano

Si se establece en True, el manejo de URL se entregará completamente al programa especificado por 'custom_url_handler'.
Valor por defecto: False

custom_url_handler = cadena

Especifica la ruta a un programa que acepta una URI como argumento y hace algo relevante con ella. Esta opción se ignora a menos que use_custom_url_handler se establezca en True.

case_sensitive = booleano

Si se establece en True, los caracteres en mayúsculas y minúsculas se considerarán diferentes al buscar texto en la terminal.
Valor por defecto: True

invert_search = booleano

Si se establece en True, la dirección de búsqueda se invertirá (de abajo hacia arriba) al buscar texto en la terminal.
Valor por defecto: False

enabled_plugins = lista de cadenas

Especifica qué plugins se cargarán por defecto. Todas las demás clases de plugins se ignorarán.
Valor por defecto: ['LaunchpadBugURLHandler', 'LaunchpadCodeURLHandler', 'APTURLHandler']

PERFILES

Estas son las opciones que Terminator soporta actualmente en la sección perfiles. Cada perfil debe ser su propia subsección con un encabezado en el formato [[nombre]].

General

allow_bold = booleano

Si se establece en True, el texto en la terminal se puede mostrar en negrita.
Valor predeterminado: True

copy_on_selection = booleano

Si se establece en True, las selecciones de texto se copiarán automáticamente al portapapeles, además de copiarse a la Selección Primaria.
Valor predeterminado: False

disable_mousewheel_zoom = booleano

Si se establece en True, Ctrl + la rueda del ratón no ampliará ni reducirá la terminal.
Valor predeterminado: False

word_chars = cadena

Especifica los caracteres que se considerarán parte de una sola palabra al seleccionar texto por palabra. No es necesario especificar el guion y los alfanuméricos. Se pueden dar rangos, por ejemplo, "A-Z".
Por ejemplo, si word_chars = "," entonces "hola,mundo" se considera una sola palabra.
Valor predeterminado: -,./?% @_:

mouse_autohide = booleano

Si se establece en True, el puntero del ratón se ocultará al escribir.
Valor predeterminado: True

term = cadena

Especifica el valor que Terminator asignará a la variable de entorno 'TERM'.
Valor predeterminado: xterm-256color

colorterm = cadena

Especifica el valor que Terminator asignará a la variable de entorno 'COLORTERM'.
Valor predeterminado: truecolor

split_to_group = booleano

Si se establece en True, la terminal creada al dividir se insertará en el grupo de la terminal actual.
Valor predeterminado: False

autoclean_groups = booleano

Si se establece en True, se eliminarán los grupos vacíos.
Valor predeterminado: True

use_system_font = booleano

Si se establece en True, se utilizará la fuente predeterminada del sistema para el texto en la terminal. De lo contrario, se utilizará el valor de font.
Valor predeterminado: True

font = cadena

Especifica qué fuente se utilizará para el texto en la terminal. Esta opción se ignora a menos que use_system_font se establezca en False.
Valor predeterminado: Mono 10

cursor_blink = booleano

Si se establece en True, el cursor parpadeará cuando no se esté escribiendo.
Valor predeterminado: True

cursor_shape = cadena

Especifica la forma del cursor. Puede ser cualquiera de: 'block', 'underline', 'ibeam'.
Valor predeterminado: block

cursor_color_default = booleano

Si se establece en True, los colores de fondo y primer plano de la terminal se utilizarán como colores de primer plano y fondo para el cursor, respectivamente.
Valor predeterminado: True

cursor_fg_color = cadena de color

Especifica el color de primer plano que se utilizará para el cursor. Esta opción se ignora a menos que cursor_color_default se establezca en False.

cursor_bg_color = cadena de color

Especifica el color de fondo que se utilizará para el cursor. Esta opción se ignora a menos que cursor_color_default se establezca en False.

audible_bell = booleano

Si se establece en True, se reproducirá un sonido cuando una aplicación escriba la secuencia de escape para la campana de la terminal.
Valor predeterminado: False

visible_bell = booleano

Si se establece en True, la terminal parpadeará cuando una aplicación escriba la secuencia de escape para la campana de la terminal.
Valor predeterminado: False

urgent_bell = booleano

Si se establece en True, se establecerá la indicación de urgencia de la ventana cuando una aplicación escriba la secuencia de escape para la campana de la terminal.
Valor predeterminado: False

icon_bell = booleano

Si se establece en True, se mostrará un pequeño icono en la barra de título de la terminal cuando una aplicación escriba la secuencia de escape para la campana de la terminal.
Valor predeterminado: True

force_no_bell = booleano

Si se establece en True, la campana de la terminal se desactivará por completo.
Valor predeterminado: False

Comando

login_shell = booleano

Si se establece en True, la terminal ejecutará el shell predeterminado (o el comando especificado por custom_command) como un shell de inicio de sesión. Esto significa que el primer argumento pasado al shell/comando será '-l'.
Valor predeterminado: False

use_custom_command = booleano

Si se establece en True, se utilizará el valor de custom_command en lugar del shell predeterminado.
Valor predeterminado: False

custom_command = cadena

Especifica el comando a ejecutar en lugar del shell predeterminado. Esta opción se ignora a menos que use_custom_command se establezca en True.

exit_action = cadena

Especifica la acción a realizar cuando se cierre la terminal. 'close' para eliminar la terminal. 'restart' para reiniciar el shell (o el comando especificado por custom_command). 'hold' para mantener la terminal abierta, incluso si el proceso en ella ha terminado.
Valor predeterminado: close

Colores

use_theme_colors = booleano

Si se establece en True, se utilizarán los colores de primer plano y fondo del tema para la terminal. De lo contrario, se utilizarán los valores de foreground_color y background_color.
Valor predeterminado: False

foreground_color = cadena de color

Especifica el color de primer plano que se utilizará para la terminal. Esta opción se ignora a menos que use_theme_colors se establezca en False.
Valor predeterminado: #AAAAAA

background_color = cadena de color

Especifica el color de fondo que se utilizará para la terminal. Esta opción se ignora a menos que use_theme_colors se establezca en False.
Valor predeterminado: #000000

palette = lista de cadenas de colores

Especifica la paleta de 16 colores que se utilizará para la terminal. El valor debe ser una cadena que contenga una lista de colores separados por dos puntos en formato hexadecimal.
Por ejemplo, "#000000:#cd0000:#00cd00: ... ".

bold_is_bright = booleano

Si se establece en True, el texto en negrita tendrá colores más brillantes.
Valor predeterminado: False

Fondo

background_darkness = flotante

Especifica la transparencia del color de fondo. El valor debe estar entre 0.0 y 1.0. Esta opción se ignora a menos que background_type se establezca en 'transparent' o 'image'.
Valor predeterminado: 0.5

background_type = cadena

Especifica qué tipo de fondo tendrá la terminal. 'solid' para un fondo sólido (opaco). 'transparent' para un fondo transparente. 'image' para una imagen de fondo.
Si se establece en 'transparent', la transparencia del fondo será el valor de background_darkness. Si se establece en 'image', la imagen especificada por background_image será el fondo; el color de fondo se dibujará encima de ella, con una transparencia especificada por background_darkness.
Valor predeterminado: solid

background_image = cadena de ruta

Especifica la ruta a una imagen que se utilizará como fondo. Esta opción se ignora a menos que background_type se establezca en 'image'.

background_image_mode = cadena

Especifica cómo se dibujará la imagen de fondo. 'stretch_and_fill' para llenar completamente la terminal, sin necesariamente mantener la relación de aspecto. 'scale_and_fit' para ajustar la imagen dentro de la terminal, dejando eventualmente barras en blanco, manteniendo la relación de aspecto. 'scale_and_crop' para llenar completamente la terminal, recortando eventualmente la imagen, manteniendo la relación de aspecto. 'tiling' para repetir la imagen de manera que llene la terminal. Esta opción se ignora a menos que background_type se establezca en 'image'.
Valor predeterminado: stretch_and_fill

background_image_align_horiz = cadena

Especifica la alineación horizontal de la imagen de fondo. Puede ser cualquiera de: 'left', 'center', 'right'. Esta opción se ignora a menos que background_type se establezca en 'image'.
Valor predeterminado: center

background_image_align_vert = cadena

Especifica la alineación vertical de la imagen de fondo. Puede ser cualquiera de: 'top', 'middle', 'bottom'. Esta opción se ignora a menos que background_type se establezca en 'image'.
Valor predeterminado: middle

Desplazamiento

scrollbar_position = cadena

Especifica dónde se coloca la barra de desplazamiento de la terminal. Puede ser cualquiera de: 'left', 'right', 'hidden'.
Valor predeterminado: right

scroll_on_output = boolean

Si se establece en True, la terminal se desplazará hasta el final cuando una aplicación escriba texto en ella.
Valor predeterminado: False

scroll_on_keystroke = boolean

Si se establece en True, la terminal se desplazará hasta el final al escribir.
Valor predeterminado: True

scrollback_infinite = boolean

Si se establece en True, la terminal conservará todo el historial de scrollback.
Valor predeterminado: False

scrollback_lines = integer

Especifica cuántas líneas de historial de scrollback conservará la terminal. Las líneas que no quepan en el historial de scrollback se descartarán. Tenga en cuenta que establecer valores grandes puede ralentizar el reajuste de líneas y el redimensionamiento. Esta opción se ignora a menos que scrollback_infinite se establezca en False.
Valor predeterminado: 500

Compatibilidad

backspace_binding = string

Especifica qué código generará la tecla de retroceso. El valor puede ser: 'ascii-del' para el carácter ASCII DEL; 'control-h' para el carácter ASCII BS (Ctrl+H); 'escape-sequence' para la secuencia de escape típicamente asociada al retroceso o suprimir; 'automatic' para permitir que la terminal decida automáticamente la secuencia de caracteres a usar.
Valor predeterminado: ascii-del

delete_binding = string

Especifica qué código generará la tecla de suprimir. El valor puede ser: 'ascii-del' para el carácter ASCII DEL; 'control-h' para el carácter ASCII BS (Ctrl+H); 'escape-sequence' para la secuencia de escape típicamente asociada al retroceso o suprimir; 'automatic' para permitir que la terminal decida automáticamente la secuencia de caracteres a usar.
Valor predeterminado: escape-sequence

DISTRIBUCIÓN

La sección layouts contiene todas las distribuciones guardadas. Cada distribución debe ser su propia subsección con un encabezado en el formato [[nombre]].

Cada objeto en una distribución es una sub-subsección con nombre con varias propiedades.

type = string

Puede ser cualquiera de: 'Window', 'Notebook', 'HPaned', 'VPaned', 'Terminal'.

parent = string

Especifica qué objeto es el padre del componente que se está definiendo. Todos los objetos, excepto los de tipo Window, deben especificar un padre.

Este es un ejemplo de una sección layouts que contiene solo la distribución llamada "default".

[layouts]
  [[default]]
    [[[window0]]]
      type = Window
      parent = ""
    [[[child1]]]
      type = Terminal
      parent = window0

PLUGINS

Los plugins de Terminator pueden agregar su propia configuración al archivo de configuración, y aparecerá como una subsección. Consulte la documentación de los plugins individuales para obtener más información.
