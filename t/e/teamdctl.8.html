TEAMDCTL(8) control de teamd TEAMDCTL(8)

NOMBRE

teamdctl — herramienta de control del demonio de team

SINOPSIS

teamdctl [opciones] equipo_dispositivo comando [args_comando...]
teamdctl -h

DESCRIPCIÓN

teamdctl es una herramienta que permite a un usuario interactuar con una instancia de teamd en ejecución. Por defecto, utiliza sockets de dominio Unix, pero recurrirá a la API de D-Bus para garantizar un funcionamiento fiable en todos los entornos.

OPCIONES

-h, --help
Muestra el texto de ayuda en la consola y sale.
-v, --verbosity
Aumenta la verbosidad de la salida.
-o, --oneline
Fuerza la salida a una sola línea si es posible.
-D, --force-dbus
Fuerza el uso de la interfaz D-Bus.
-Z dirección, --force-zmq dirección
Fuerza el uso de la interfaz ZMQ. Las posibles formatos de dirección son "tcp://ip:puerto", "ipc://ruta" y otros. Una descripción detallada de la biblioteca ZMQ se encuentra en la página http://zguide.zeromq.org/page:all.
-U, --force-usock
Fuerza el uso de la interfaz de socket de dominio UNIX. Este es el comportamiento predeterminado.

COMANDO

config dump
Vuelca la configuración JSON de teamd.
config dump noports
Vuelca la configuración JSON de teamd sin incluir la sección "ports".
config dump actual
Vuelca la configuración JSON actual de teamd. Incluye los puertos que están actualmente presentes.
state dump | state
Vuelca el documento de estado JSON de teamd.
state view
Imprime el estado de teamd analizado a partir del documento de estado JSON.
state item get ruta_elemento_estado
Encuentra un elemento de estado en el documento de estado JSON y devuelve su valor.

Si PORTIFNAME en ruta_elemento_estado contiene algún carácter sensible, usa comillas dobles para escaparlo, como: ports."eth1.1".link_watches.up. El procesamiento de la ruta_elemento_estado para 'state item set' es el mismo que aquí.

state item set ruta_elemento_estado valor
Encuentra un elemento de estado en el documento de estado JSON y establece su valor mediante el parámetro valor. Esto solo está disponible para un número limitado de rutas:

setup.debug_level — El usuario puede establecer el nivel de depuración. Un nivel más alto es más verboso.

ports.NOMBRE_PUERTO.runner.aggregator.selected — Esto está disponible para el ejecutor lacp. El usuario puede seleccionar manualmente el agregador.

runner.active_port — Esto está disponible para el ejecutor activebackup. El usuario puede seleccionar manualmente el puerto activo.

port add puerto_dispositivo
Toma el nombre del dispositivo del puerto como argumento. Añade el dispositivo del puerto al equipo.
port remove puerto_dispositivo
Toma el nombre del dispositivo del puerto como argumento. Elimina el dispositivo del puerto del equipo.
port present puerto_dispositivo
Toma el nombre del dispositivo del puerto como argumento. Comprueba si el dispositivo del puerto está presente en el equipo.
port config update puerto_dispositivo cadena_config_puerto
Toma el nombre del dispositivo del puerto como primer argumento y una cadena de configuración en formato JSON como segundo argumento. Actualiza la configuración del dispositivo del puerto.
port config dump puerto_dispositivo
Toma el nombre del dispositivo del puerto como primer argumento. Vuelca la configuración JSON del dispositivo del puerto a la salida estándar.
