TEXTDOMAIN(3) Manual de funciones de biblioteca TEXTDOMAIN(3)

NOMBRE

textdomain - establece el dominio para futuras llamadas a gettext()

SINOPSIS

#include <libintl.h>

char * textdomain (const char * domainname);

DESCRIPCIÓN

La función textdomain establece o recupera el dominio de mensajes actual.

Un dominio de mensajes es un conjunto de mensajes msgid traducibles. Normalmente, cada paquete de software tiene su propio dominio de mensajes. El nombre del dominio se utiliza para determinar el catálogo de mensajes donde se busca una traducción; debe ser una cadena no vacía.

El dominio de mensajes actual es utilizado por las funciones gettext, ngettext, y por las funciones dgettext, dcgettext, dngettext y dcngettext cuando se llaman con un argumento domainname NULL.

Si domainname no es NULL, el dominio de mensajes actual se establece a domainname. La cadena que la función almacena internamente es una copia del argumento domainname.

Si domainname es NULL, la función devuelve el dominio de mensajes actual.

VALOR DE RETORNO

Si tiene éxito, la función textdomain devuelve el dominio de mensajes actual, después de posiblemente cambiarlo. La cadena resultante es válida hasta la próxima llamada a textdomain y no debe ser modificada ni liberada. Si ocurre un error de asignación de memoria, establece errno a ENOMEM y devuelve NULL.

ERRORES

Los siguientes errores pueden ocurrir, entre otros:

ENOMEM
No hay suficiente memoria disponible.

ERRORES GRAVES

El tipo de retorno debería ser const char *, pero es char * para evitar advertencias en código C anterior a ANSI C.

VER TAMBIÉN
