NOMBRE

testsolv - ejecuta un caso de prueba de libsolv a través del solucionador

SINOPSIS

testsolv [OPCIONES] CASO_DE_PRUEBA

DESCRIPCIÓN

La herramienta testsolv se puede utilizar para ejecutar un caso de prueba. Los casos de prueba pueden crearse manualmente para probar características específicas, o pueden ser escritos por la función testcase_write de libsolv. Esto es útil para evaluar informes de errores sobre el solucionador.

-v

Aumenta el nivel de depuración del solucionador. Esta opción puede especificarse varias veces para aumentar aún más la cantidad de datos de depuración.

-r

Escribe la salida en formato de caso de prueba en lugar de texto legible por humanos. La salida se puede usar luego en la sección de resultados del caso de prueba. Si la opción -r se da dos veces, la salida se formatea para incluirla literalmente.

-l PKGSPEC

En lugar de ejecutar el solucionador, lista los paquetes en los repositorios.

-s SOLUTIONSPEC

Se utiliza en la suite de pruebas de libsolv para probar las soluciones calculadas a los problemas encontrados.
