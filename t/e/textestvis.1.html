NOMBRE

textestvis - pruebas de regresión visual para LaTeX

SINOPSIS

textestvis [-cs] [-e MOTOR] [-d DENSIDAD] [PATRÓN]

textestvis approve [-e MOTOR] [PATRÓN]

textestvis compare [-d DENSIDAD] ARCHIVO ARCHIVO

textestvis perf [-cs] [-e MOTOR] ARCHIVO

DESCRIPCIÓN

Realiza pruebas de regresión visual para documentos LaTeX.

textestvis
Crea archivos PDF para todos los archivos tex que coinciden con el patrón y realiza una prueba de regresión visual. Si no se especifica ningún patrón, se prueban todos los archivos en el directorio actual, excepto los archivos cuyos nombres comienzan con un guion bajo.
textestvis approve
Reemplaza los archivos de referencia con los archivos de prueba.
textestvis compare
Crea una diferencia visual para dos archivos pdf.
textestvis perf
Mide el tiempo para crear un archivo pdf a partir del archivo tex dado.

OPCIONES

-c
Borra la caché.
-s
Habilita el escape de shell.
-d DENSIDAD
Establece la densidad en ppi (por defecto 72).
-e MOTOR
Establece el motor latex (por defecto xelatex).
--help
Imprime un mensaje de ayuda.
--version
Imprime información de la versión.

ENTORNO

textestvis requiere ImageMagick 7.0 o posterior.
