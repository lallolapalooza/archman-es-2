!>
!> Valores reales para la prueba:
!> (1) x = 2**m, donde m = MINEXPONENT-DIGITS, ..., MINEXPONENT-1.
!>     Tenga en cuenta que no todas las plataformas pueden implementar números subnormales.
!> (2) x = 2**m, donde m = MINEXPONENT, ..., 0.
!> (3) x = OV, donde OV es el umbral de desbordamiento. OV^2 se desborda pero la norma es OV.
!> (4) x = 2**m, donde m = MAXEXPONENT-1, ..., 1.
!>
!> Pruebas:
!> (a) y = x + 0 * I, y/y = 1
!> (b) y = 0 + x * I, y/y = 1
!> (c) y = x + x * I, y/y = 1
!> (d) y1 = 0 + x * I, y2 = x + 0 * I, y1/y2 = I
!> (e) y1 = 0 + x * I, y2 = x + 0 * I, y2/y1 = -I
!> (f) y = x + x * I, y/conj(y) = I
!>
!> Casos especiales:
!>
!> (i) Entradas Infinitas:
!>    (1) y = ( Inf + 0   * I)
!>    (2) y = ( 0   + Inf * I)
!>    (3) y = (-Inf + 0   * I)
!>    (4) y = ( 0   - Inf * I)
!>    (5) y = ( Inf + Inf * I)
!> Pruebas:
!>    (a) 0 / y es 0 o NaN.
!>    (b) 1 / y es 0 o NaN.
!>    (c) y / y es NaN.
!>
!> (n) Entradas NaN:
!>    (1) y = (NaN + 0   * I)
!>    (2) y = (0   + NaN * I)
!>    (3) y = (NaN + NaN * I)
!> Pruebas:
!>    (a) 0 / y es NaN.
!>    (b) 1 / y es NaN.
!>    (c) y / y es NaN.
!>
!>
