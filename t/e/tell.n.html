NOMBRE

tell - Devuelve la posición de acceso actual para un canal abierto

SINOPSIS

tell channelId

DESCRIPCIÓN

Devuelve una cadena de enteros que indica la posición de acceso actual en channelId. Este valor devuelto es un desplazamiento de bytes que puede pasarse a seek para establecer el canal en una posición determinada. Tenga en cuenta que este valor está en términos de bytes, no de caracteres como en read. El valor devuelto es -1 para canales que no admiten búsqueda.

ChannelId debe ser un identificador de un canal abierto, como un canal estándar de Tcl (stdin, stdout o stderr), el valor de retorno de una invocación de open o socket, o el resultado de un comando de creación de canal proporcionado por una extensión de Tcl.

EJEMPLO

Lee una línea de un canal de archivo solo si comienza con foobar:

# Guarda el desplazamiento en caso de que necesitemos deshacer la lectura...
set offset [tell $chan]
if {[read $chan 6] eq "foobar"} {
    gets $chan line
} else {
    set line {}
    # Deshace la lectura...
    seek $chan $offset
}
