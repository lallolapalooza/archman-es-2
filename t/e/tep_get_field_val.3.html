tep_get_field_val(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_get_any_field_val, tep_get_common_field_val, tep_get_field_val, tep_get_field_raw - Obtener el valor de un campo.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
int tep_get_any_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
int tep_get_common_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
int tep_get_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
void *tep_get_field_raw(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, int *len, int err);

DESCRIPCIÓN

Estas funciones se pueden usar para encontrar un campo y recuperar su valor.

La función tep_get_any_field_val() busca en el record un campo con el nombre name, parte del event. Si se encuentra el campo, su valor se almacena en val. Si hay un error y err no es cero, entonces se escribe una cadena de error en s.

La función tep_get_common_field_val() hace lo mismo que tep_get_any_field_val(), pero busca solo en los campos comunes. Esto funciona para cualquier evento, ya que todos los eventos incluyen los campos comunes.

La función tep_get_field_val() hace lo mismo que tep_get_any_field_val(), pero busca solo en los campos específicos del evento.

La función tep_get_field_raw() busca en el record un campo con el nombre name, parte del event. Si se encuentra el campo, se devuelve un puntero a dónde existe el campo en los datos crudos del registro. El tamaño de los datos se almacena en len. Si hay un error y err no es cero, entonces se escribe una cadena de error en s.

VALOR DE RETORNO

Las funciones tep_get_any_field_val(), tep_get_common_field_val() y tep_get_field_val() devuelven 0 en caso de éxito, o -1 en caso de error.

La función tep_get_field_raw() devuelve un puntero a los datos crudos del campo, y coloca la longitud de estos datos en len. En caso de error, se devuelve NULL.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
struct tep_event *event = tep_find_event_by_name(tep, "kvm", "kvm_exit");
...
void process_record(struct tep_record *record)
{
        int len;
        char *comm;
        struct tep_event *event;
        unsigned long long val;
        event = tep_find_event_by_record(tep, record);
        if (event != NULL) {
                if (tep_get_common_field_val(NULL, event, "common_type",
                                             record, &val, 0) == 0) {
                        /* Se obtuvo el valor del campo common_type */
                }
                if (tep_get_field_val(NULL, event, "pid", record, &val, 0) == 0) {
                        /* Se obtuvo el valor del campo específico pid */
                }
                comm = tep_get_field_raw(NULL, event, "comm", record, &len, 0);
                if (comm != NULL) {
                        /* Se obtuvo un puntero al campo específico comm del evento */
                }
        }
}
