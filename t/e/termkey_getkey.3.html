termkey_getkey(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_GETKEY(3) Manual de funciones de la biblioteca TERMKEY_GETKEY(3)

NOMBRE

termkey_getkey, termkey_getkey_force - recuperar el siguiente evento de tecla

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_getkey(TermKey *tk, TermKeyKey *key);
TermKeyResult termkey_getkey_force(TermKey *tk, TermKeyKey *key);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_getkey() intenta recuperar un único evento de pulsación de tecla del búfer de la instancia de termkey(7) y lo coloca en la estructura a la que se refiere key. Devuelve uno de los siguientes valores:

TERMKEY_RES_KEY
se ha eliminado una pulsación de tecla completa del búfer y se ha colocado en la estructura key.
TERMKEY_RES_AGAIN
se encontró un evento de pulsación de tecla parcial en el búfer, pero aún no contiene todos los bytes necesarios. Se ha colocado una indicación de lo que devolvería termkey_getkey_force() en la estructura key.
TERMKEY_RES_NONE
no hay bytes esperando en el búfer.
TERMKEY_RES_EOF

no hay bytes listos y el flujo de entrada está ahora cerrado.
TERMKEY_RES_ERROR
se llamó con la E/S del terminal detenida, debido a termkey_stop(3). En este caso, errno se establecerá en EINVAL.

termkey_getkey_force() es similar a termkey_getkey() pero no devolverá TERMKEY_RES_AGAIN si se encuentra una coincidencia parcial. En su lugar, forzará una interpretación de los bytes, incluso si esto significa interpretar el inicio de una secuencia de varios bytes prefijada por Escape como una tecla *Escape* literal seguida de letras normales.

Ninguna de estas funciones bloqueará ni realizará operaciones de E/S en el descriptor de archivo subyacente. Para usar la instancia en un programa asíncrono, consulte termkey_advisereadable(3). Para una llamada bloqueante adecuada para su uso en un programa síncrono, utilice termkey_waitkey(3) en lugar de termkey_getkey(). Para proporcionar entrada sin un descriptor de archivo legible, utilice termkey_push_bytes(3).

Antes de devolver, esta función normaliza la estructura key según las reglas dadas para termkey_canonicalise(3).

VALOR DE RETORNO

termkey_getkey() devuelve una enumeración de uno de TERMKEY_RES_KEY, TEMRKEY_RES_AGAIN, TERMKEY_RES_NONE, TERMKEY_RES_EOF o TERMKEY_RES_ERROR. termkey_getkey_force() devuelve uno de los anteriores, excepto TERMKEY_RES_AGAIN.

EJEMPLO

El siguiente programa de ejemplo imprime detalles de cada pulsación de tecla hasta que el usuario presiona *Ctrl-C*. Demuestra cómo usar la instancia termkey en un programa asíncrono típico impulsado por poll(2), que puede incluir E/S mixta con otros descriptores de archivo.


// <poll.h> podría necesitar esto para sigset_t
#define _XOPEN_SOURCE 600
#include <poll.h>
#include <stdio.h>
#include "termkey.h"
static void on_key(TermKey *tk, TermKeyKey *key)
{
  char buffer[50];
  termkey_strfkey(tk, buffer, sizeof buffer, key, TERMKEY_FORMAT_VIM);
  printf("%s\n", buffer);
}
int main(int argc, char *argv[])
{
  TERMKEY_CHECK_VERSION;
  TermKey *tk = termkey_new(0, 0);
  if(!tk) {
    fprintf(stderr, "No se puede asignar instancia de termkey\n");
    exit(1);
  }
  struct pollfd fd;
  fd.fd = 0; /* el descriptor de archivo que pasamos a termkey_new() */
  fd.events = POLLIN;
  TermKeyResult ret;
  TermKeyKey key;
  int running = 1;
  int nextwait = -1;
  while(running) {
    if(poll(&fd, 1, nextwait) == 0) {
      // Tiempo de espera agotado
      if(termkey_getkey_force(tk, &key) == TERMKEY_RES_KEY)
        on_key(tk, &key);
    }
    if(fd.revents & (POLLIN|POLLHUP|POLLERR))
      termkey_advisereadable(tk);
    while((ret = termkey_getkey(tk, &key)) == TERMKEY_RES_KEY) {
      on_key(tk, &key);
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers & TERMKEY_KEYMOD_CTRL &&
         (key.code.codepoint == 'C' || key.code.codepoint == 'c'))
        running = 0;
    }
    if(ret == TERMKEY_RES_AGAIN)
      nextwait = termkey_get_waittime(tk);
    else
      nextwait = -1;
  }
  termkey_destroy(tk);
}
