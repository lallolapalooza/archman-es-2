tep_set_test_filters(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_print_printk, tep_print_funcs, tep_set_test_filters, tep_plugin_print_options - Imprimir información interna de libtraceevent.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_printk(struct tep_handle *tep);
void tep_print_funcs(struct tep_handle *tep);
void tep_set_test_filters(struct tep_handle *tep, int test_filters);
void tep_plugin_print_options(struct trace_seq *s);

DESCRIPCIÓN

La función tep_print_printk() imprime los formatos de cadena printk que se almacenaron para esta sesión de rastreo. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_print_funcs() imprime el mapeo de nombre de función a dirección almacenado para esta sesión de rastreo. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_set_test_filters() establece una bandera para probar una cadena de filtro. Si esta bandera está establecida, cuando se llama a la API tep_filter_add_filter_str(), imprimirá la cadena de filtro en lugar de agregarla. El argumento tep es el contexto del analizador de eventos de rastreo. El argumento test_filters es la bandera de prueba que se establecerá.

La función tep_plugin_print_options() escribe una lista de las opciones de plugin registradas en s.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
        tep_print_printk(tep);
...
        tep_print_funcs(tep);
...
struct tep_event_filter *filter = tep_filter_alloc(tep);
        tep_set_test_filters(tep, 1);
        tep_filter_add_filter_str(filter, "sched/sched_wakeup:target_cpu==1");
        tep_set_test_filters(tep, 0);
        tep_filter_free(filter);
...
struct trace_seq seq;
trace_seq_init(&seq);
        tep_plugin_print_options(&s);
...
