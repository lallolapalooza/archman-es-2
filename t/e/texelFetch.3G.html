NOMBRE

texelFetch - realiza una búsqueda de un único texel dentro de una textura

DECLARACIÓN

gvec4 texelFetch(gsampler1D sampler, int P, int lod);

gvec4 texelFetch(gsampler2D sampler, ivec2 P, int lod);

gvec4 texelFetch(gsampler3D sampler, ivec3 P, int lod);

gvec4 texelFetch(gsampler2DRect sampler, ivec2 P);

gvec4 texelFetch(gsampler1DArray sampler, ivec2 P, int lod);

gvec4 texelFetch(gsampler2DArray sampler, ivec3 P, int lod);

gvec4 texelFetch(gsamplerBuffer sampler, int P);

gvec4 texelFetch(gsampler2DMS sampler, ivec2 P, int sample);

gvec4 texelFetch(gsampler2DMSArray sampler, ivec3 P, int sample);

PARÁMETROS

sampler

Especifica el sampler al que está enlazada la textura de la que se recuperarán los texels.

P

Especifica las coordenadas de textura en las que se muestreará la textura.

lod

Si está presente, especifica el nivel de detalle dentro de la textura de donde se obtendrá el texel.

sample

Para búsquedas multisescalonadas, especifica qué muestra dentro del texel se devolverá al leer de una textura multisescalonada.

DESCRIPCIÓN

texelFetch realiza una búsqueda de un único texel a partir de la coordenada de textura P en la textura enlazada a sampler. La capa de la matriz se especifica en el último componente de P para las formas de matriz. El parámetro lod (si está presente) especifica el nivel de detalle del que se obtendrá el texel. El parámetro sample especifica qué muestra dentro del texel se devolverá al leer de una textura multisescalonada.
