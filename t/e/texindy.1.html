NOMBRE

texindy - crea un índice ordenado y etiquetado a partir de un índice LaTeX crudo

SINOPSIS

texindy [-V?h] [-qv] [-iglr] [-d magic] [-o outfile.ind] [-t log] \
        [-L lang] [-C codepage] [-M module] [idx0 idx1 ...]

Opciones largas estilo GNU para opciones cortas:

-V / --version
-? / -h / --help
-q / --quiet
-v / --verbose
-i / --stdin
-g / --german
-l / --letter-ordering
-r / --no-ranges
-d / --debug          (múltiples veces)
-o / --out-file
-t / --log-file
-L / --language
-C / --codepage
-M / --module         (múltiples veces)
-I / --input-markup   (soportados: latex, xelatex, omega)

DESCRIPCIÓN

texindy es el comando específico para LaTeX de xindy, el sistema de indexación flexible. Toma un índice crudo como entrada y produce un índice fusionado, ordenado y etiquetado. La fusión, ordenación y etiquetado se controlan mediante módulos de xindy, con un conjunto conveniente ya precargado.

Los archivos con el índice crudo se pasan como argumentos. Si no se pasan argumentos, el índice crudo se leerá de la entrada estándar.

Una buena introducción a texindy aparece en el capítulo de indexación del LaTeX Companion (2ª ed.).

Si desea producir un índice para documentos LaTeX con marcas de índice especiales, el comando xindy(1) probablemente le interese más.

texindy es un enfoque para fusionar soporte para el marco de trabajo make-rules, módulos propios de xindy (p. ej., para comandos LaTeX especiales en el índice) y un nivel razonable de compatibilidad con MakeIndex.

OPCIONES

"--version" / -V
muestra los números de versión de todos los componentes relevantes y sale.
"--help" / -h / -?
muestra el mensaje de uso con la explicación de las opciones.
"--quiet" / -q
No muestra mensajes de progreso. Solo muestra mensajes de error.
"--verbose" / -v
Muestra mensajes de progreso detallados.
"--debug" magic / -d magic
Muestra mensajes de depuración, esta opción se puede especificar varias veces. magic determina qué se muestra: 
magic          observación
------------------------------------------------------------
script         mensajes de progreso internos de los scripts del controlador
keep_tmpfiles  no descartar archivos temporales
markup         muestra el rastreo de marcado, como se explica en el manual de xindy
level=n        nivel de registro, n es 0 (por defecto), 1, 2 o 3
"--out-file" outfile.ind / -o outfile.ind
Índice de salida al archivo outfile.ind. Si no se pasa esta opción, el nombre del archivo de salida es el nombre base del primer argumento y la extensión de archivo ind. Si el índice crudo se lee de la entrada estándar, esta opción es obligatoria.
"--log-file" log.ilg / -t log.ilg
Mensajes de registro de salida al archivo log.ilg. Estos mensajes de registro son independientes de los mensajes de progreso que puede influir con "--debug" o "--verbose".
"--language" lang / -L lang
El índice se ordena según las reglas del idioma lang. Estas reglas están codificadas en un módulo xindy creado por make-rules.

Si no se especifica ninguna codificación de entrada a través de "--codepage" o se fuerza mediante el marcado de entrada, se buscará un módulo xindy para ese idioma con una codificación latina, cp, iso, ascii o utf8, en ese orden.

"--codepage" enc / -C enc
Hay dos situaciones y casos de uso diferentes para esta opción.
1.
El marcado de entrada es "latex" (el predeterminado).

Entonces, se asume que la entrada cruda de texindy está codificada en Representación Interna de Caracteres de LaTeX (LICR). Es decir, los caracteres no ASCII están codificados como secuencias de comandos. Esta opción indica a xindy la codificación que debe usar para los encabezados de grupos de letras. (Además, especifica la codificación utilizada internamente para la ordenación, pero eso no importa para el resultado).

Solo se admiten codificaciones LICR para alfabetos de escritura latina; más precisamente, caracteres que se encuentran en las codificaciones LICR latinas, latinas2 y latinas3 de LaTeX.

Incluso cuando especifica "utf8" como página de códigos, solo se conocerán estos caracteres. Pero si utiliza alfabetos no latinos, probablemente utilice (o debería utilizar) XeLaTeX o LuaLaTeX y entonces tendrá un marcado de entrada diferente.

2.
El marcado de entrada es "xelatex" o "omega".

Entonces esta opción se ignora; se fuerza la página de códigos "utf8".

Se asume que la entrada cruda de texindy está codificada en UTF-8, no se utiliza LICR.

"--module" module / -M module
Carga el módulo xindy module.xdy. Esta opción puede especificarse múltiples veces. Los módulos se buscan en la ruta de búsqueda de xindy, que se puede cambiar con la variable de entorno "XINDY_SEARCHPATH".
"--input-markup" input / -I input
Especifica el marcado de entrada del índice crudo. Los valores admitidos para input son "latex", "xelatex" y "omega".

"latex" El marcado de entrada es el que emite por defecto el núcleo de LaTeX, o el paquete macro "index" de David Jones, cuando se utiliza con LaTeX estándar o pdfLaTeX. Se admite la notación ^^- de caracteres de un solo byte. Se asume también el uso del paquete inputenc de LaTeX, es decir, la entrada cruda está codificada en LICR.

"xelatex" El marcado de entrada es como "latex", pero sin uso de inputenc. La entrada cruda está codificada en UTF-8. LuaLaTeX tiene el mismo marcado de entrada, no hay un valor de opción especial para él.

"omega" El marcado de entrada es como el marcado de entrada "latex", pero con la notación ^^ de Omega como codificación para caracteres no ASCII. La codificación LICR no se usa entonces, y se fuerza "utf8" como página de códigos para la ordenación y para la salida de encabezados de grupos de letras.

MÓDULOS ESTÁNDAR DE TEXINDY

Hay un conjunto de módulos estándar de texindy que ayudan a procesar archivos de índice de LaTeX. Algunos de ellos se cargan automáticamente. Algunos se cargan por defecto, esto se puede desactivar con una opción de texindy. Otros pueden especificarse como argumento "--module" para lograr un efecto específico.

Módulo xindy    Categoría  Descripción

Ordenación

word-order      Predeterminado  Un espacio viene antes que cualquier letra del
                          alfabeto: ``index style'' se lista antes
                          que ``indexing''. Desactivarlo con la opción -l.
letter-order    Complemento   Los espacios se ignoran: ``index style''
                          se ordena después de ``indexing''.
keep-blanks     Complemento   Los espacios en blanco iniciales y finales (espacios
                          y tabulaciones) no se ignoran; los espacios intermedios
                          no se modifican.
ignore-hyphen   Complemento   Los guiones se ignoran:
                          ``ad-hoc'' se ordena como ``adhoc''.
ignore-punctuation Complemento  Se ignoran todo tipo de caracteres de puntuación:
                          guiones, puntos, comas, barras, paréntesis, etc.
numeric-sort    Automático  Los números se ordenan numéricamente, no como
                          caracteres: ``V64'' aparece antes que ``V128''.

Números de Página

page-ranges     Predeterminado  Las apariciones en más de dos páginas consecutivas
                          se listan como un rango: ``1--4''.
                          Desactivarlo con la opción -r.
ff-ranges       Complemento   Utiliza la notación implícita ``ff'' para rangos
                          de tres páginas, y rangos explícitos
                          después: 2f, 2ff, 2--6.
ff-ranges-only  Complemento   Utiliza solo rangos implícitos: 2f, 2ff.
book-order      Complemento   Ordena los números de página con el esquema común
                          de numeración de libros correctamente: primero números
                          romanos, luego números arábigos, luego otros: i, 1, A.

Marcado y Diseño

tex             Automático  Maneja convenciones básicas de TeX.
latex-loc-fmts  Automático  Proporciona comandos de formato de LaTeX
                          para la encapsulación de números de página.
latex           Automático  Maneja convenciones de LaTeX, tanto en entradas
                          de índice crudas como en marcado de salida; implica
                          tex.
makeindex       Automático  Emula la sintaxis de entrada y el comportamiento
                          de citación predeterminados de MakeIndex.
latin-lettergroups Automático   El diseño contiene una sola letra latina
                          encima de cada grupo de palabras que comienzan con
                          la misma letra.
german-sty      Complemento   Maneja el marcado de umlaut de las opciones
                          german y ngerman de babel.

COMPATIBILIDAD CON MAKEINDEX

xindy no afirma ser completamente compatible con MakeIndex, eso evitaría algunas de sus mejoras. Dicho esto, nos esforzamos por ofrecer la mayor compatibilidad posible. Las incompatibilidades más importantes son:

  • Para entradas de índice crudas en sintaxis LaTeX, "\index{aaa|bbb}" se interpreta de manera diferente. Para MakeIndex "bbb" es un marcado que se produce como una etiqueta LaTeX para este número de página. Para xindy, este es un atributo de ubicación, un identificador abstracto que posteriormente se asociará con el marcado que se debe producir para ese atributo.

    Para un uso directo, cuando "bbb" es "textbf" o similar, proporcionamos definiciones de atributos de ubicación que imitan el comportamiento de MakeIndex.

    Para un uso más complejo, cuando "bbb" no es un identificador, no existen tales definiciones de compatibilidad y tampoco se han creado con xindy actual. En particular, esto significa que por defecto el paquete LaTeX "hyperref" creará archivos de índice crudos que no pueden ser procesados con xindy. Esto no es un error, es el desafortunado resultado de una incompatibilidad intencionada. Actualmente no es posible obtener enlaces de índice de hyperref y usar xindy.

    Se informa que existe una situación similar para la clase LaTeX "memoir".

    Los programadores que conocen Common Lisp y Lex y desean trabajar en una solución, por favor contacten al autor.

  • Si tienes un rango de índice y un atributo de ubicación, por ejemplo, "\index{key\(attr}" inicia el rango, uno necesita (1) especificar también ese atributo en la entrada de cierre del rango (es decir, como "\index{key\)attr}") y (2) declarar el atributo de índice en un archivo de estilo xindy.

    MakeIndex producirá el marcado "\attr{page1--page2}" para tal constructo. Esto no es posible de lograr en xindy, la salida será "\attrMarkup{page1}--\attrMarkup{page2}". (Esto se considera en realidad un error, pero no uno de alta prioridad).

    La diferencia entre las etiquetas de número de página de MakeIndex y los atributos de ubicación de xindy ya se explicó en el punto anterior.

  • Las definiciones de compatibilidad de MakeIndex solo admiten la sintaxis cruda de índice y la definición de marcado predeterminadas. No es posible configurar el análisis de índice crudo o usar un archivo de estilo de MakeIndex para describir el marcado de salida.

ENTORNO

"TEXINDY_AUTO_MODULE"
Este es el nombre del módulo xindy que carga todos los módulos cargados automáticamente. El valor predeterminado es "texindy".
