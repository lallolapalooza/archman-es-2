tep_register_event_handler(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_register_event_handler, tep_unregister_event_handler - Registra/anula el registro de una función de devolución de llamada para analizar información de un evento.

SINOPSIS

#include <event-parse.h>
enum tep_reg_handler {
        TEP_REGISTER_SUCCESS,
        TEP_REGISTER_SUCCESS_OVERWRITE,
};
int tep_register_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
int tep_unregister_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
typedef int (*tep_event_handler_func)(struct trace_seq *s, struct tep_record *record, struct tep_event *event, void *context);

DESCRIPCIÓN

La función tep_register_event_handler() registra una función manejadora, que será llamada para analizar la información de un evento dado. El argumento tep es el contexto del analizador de eventos de traza. El argumento id es el ID del evento. El argumento sys_name es el nombre del sistema al que pertenece el evento. El argumento event_name es el nombre del evento. Si id es mayor o igual a 0, se usa para encontrar el evento; de lo contrario, se usan sys_name y event_name. El argumento func es un puntero a la función que será llamada para analizar la información del evento. El argumento context es un puntero a los datos de contexto, que se pasarán a func. Si ya está registrada una función manejadora para el mismo evento, será reemplazada por la nueva. Este mecanismo permite a un desarrollador anular el análisis de un evento dado. Si el formato de impresión predeterminado no es suficiente por alguna razón, el desarrollador puede registrar una función para un evento que se utilizará para analizar los datos en su lugar.

La función tep_unregister_event_handler() anula el registro de la función manejadora, previamente registrada con tep_register_event_handler(). El argumento tep es el contexto del analizador de eventos de traza. Los argumentos id, sys_name, event_name, func y context son los mismos argumentos que cuando se registró la función de devolución de llamada func.

tep_event_handler_func es el tipo de la función manejadora de eventos personalizada. El argumento s es la secuencia de traza, se puede usar para crear una cadena personalizada que describa el evento. Se pasa un record para obtener el evento como parámetro de entrada y también el event, el manejador del evento del registro. El context es un contexto personalizado, establecido cuando se registró la función manejadora de eventos personalizada.

VALOR DE RETORNO

La función tep_register_event_handler() devuelve TEP_REGISTER_SUCCESS si la nueva manejadora se registra correctamente o TEP_REGISTER_SUCCESS_OVERWRITE si se reemplaza una manejadora existente. Si no hay suficiente memoria para completar el registro, se devuelve TEP_ERRNO__MEM_ALLOC_FAILED.

La función tep_unregister_event_handler() devuelve 0 si func se eliminó correctamente o -1 si no se encontró el evento.

La función tep_event_handler_func debe devolver -1 en caso de error, o 0 en caso contrario.

tep_register_event_handler(3)

NAME

tep_register_event_handler - Register a handler for a specific event type.

SYNOPSIS

#include <tep.h>

int tep_register_event_handler(tep_event_handler_t handler,
                               void *data,
                               const char *event_type);

DESCRIPTION

The tep_register_event_handler function registers a callback function (handler) to be invoked when an event of the specified event_type occurs.

The handler function will be called with the data pointer and the event data. The data pointer is user-defined data that will be passed to the handler function. The event_type string specifies the type of event to listen for. If event_type is NULL, the handler will be called for all event types.

The handler function should have the following signature:

void handler(void *data, const char *event_type, void *event_data);

RETURN VALUE

On success, 0 is returned. On failure, a negative error code is returned.

EXAMPLE

#include <stdio.h>
#include <tep.h>

void my_event_handler(void *data, const char *event_type, void *event_data) {
    printf("Received event: %s\\n", event_type);
    // Process event_data here
}

int main() {
    if (tep_register_event_handler(my_event_handler, NULL, "user_event") < 0) {
        perror("tep_register_event_handler");
        return 1;
    }

    // ... later, when an event occurs ...
    // tep_trigger_event("user_event", some_data);

    return 0;
}
