tee(2) Manual de llamadas al sistema tee(2)

NOMBRE

tee - duplicar el contenido de una tubería

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <fcntl.h>
ssize_t tee(int fd_in, int fd_out, size_t size, unsigned int flags);

DESCRIPCIÓN

tee() duplica hasta size bytes de datos desde la tubería referenciada por el descriptor de archivo fd_in a la tubería referenciada por el descriptor de archivo fd_out. No consume los datos que se duplican desde fd_in; por lo tanto, esos datos pueden ser copiados por una posterior llamada a splice(2).

flags es una máscara de bits que se compone de OR lógico de cero o más de los siguientes valores:

SPLICE_F_MOVE
Actualmente no tiene efecto para tee(); ver splice(2).
SPLICE_F_NONBLOCK
No bloquear en I/O; ver splice(2) para más detalles.
SPLICE_F_MORE
Actualmente no tiene efecto para tee(), pero puede ser implementado en el futuro; ver splice(2).
SPLICE_F_GIFT
No utilizado para tee(); ver vmsplice(2).

VALOR DE RETORNO

Al completarse con éxito, tee() devuelve el número de bytes que se duplicaron entre la entrada y la salida. Un valor de retorno de 0 significa que no había datos para transferir, y no tendría sentido bloquear, ya que no hay escritores conectados al extremo de escritura de la tubería referenciada por fd_in.

En caso de error, tee() devuelve -1 y errno se configura para indicar el error.

ERRORES

EAGAIN
Se especificó SPLICE_F_NONBLOCK en flags o uno de los descriptores de archivo se marcó como no bloqueante (O_NONBLOCK), y la operación bloquearía.
EINVAL
fd_in o fd_out no se refieren a una tubería; o fd_in y fd_out se refieren a la misma tubería.
ENOMEM
Sin memoria.

ESTNDARES

Linux.

HISTORIAL

Linux 2.6.17, glibc 2.5.

NOTAS

Conceptualmente, tee() copia los datos entre las dos tuberías. En realidad, no se produce ninguna copia de datos real: bajo las capas, tee() asigna datos a la salida simplemente tomando una referencia a la entrada.

EJEMPLOS

El siguiente ejemplo implementa un programa básico tee(1) utilizando la llamada al sistema tee(). Aquí hay un ejemplo de su uso:


$ date | ./a.out out.log | cat;
Tue Oct 28 10:06:00 CET 2014
$ cat out.log;
Tue Oct 28 10:06:00 CET 2014

Código fuente del programa

#define _GNU_SOURCE
#include <errno.h>
#include <fcntl.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int      fd;
    ssize_t  size, ssize;
    if (argc != 2) {
        fprintf(stderr, "Uso: %s <archivo>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        /*
         * tee stdin a stdout.
         */
        size = tee(STDIN_FILENO, STDOUT_FILENO,
                  INT_MAX, SPLICE_F_NONBLOCK);
        if (size < 0) {
            if (errno == EAGAIN)
                continue;
            perror("tee");
            exit(EXIT_FAILURE);
        }
        if (size == 0)
            break;
        /*
         * Consumir stdin haciendo splice a un archivo.
         */
        while (size > 0) {
            ssize = splice(STDIN_FILENO, NULL, fd, NULL,
                          size, SPLICE_F_MOVE);
            if (ssize < 0) {
                perror("splice");
                exit(EXIT_FAILURE);
            }
            size -= ssize;
        }
    }
    close(fd);
    exit(EXIT_SUCCESS);
}

VER TAMBIÉN
