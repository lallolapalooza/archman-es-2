texlogfilter

NOMBRE

texlogfilter - filtrar la salida o el archivo de registro de motores latex

SINOPSIS

texlogfilter [opciones] archivo.log

DESCRIPCIÓN

Filtrar la salida o el archivo de registro de motores latex. Para la salida o el archivo de registro de latex, pdflatex, lualatex o xelatex.

Sin archivo de entrada, se utiliza la entrada estándar. Usar con la salida del motor latex con:

latex archivo.tex < /dev/null | texlogfilter

OPCIONES

--help                 : mostrar esta ayuda y salir
--version              : mostrar versión y salir
--box                  : mostrar advertencias de caja
--no-box               : ocultar advertencias de caja
--ref                  : mostrar advertencias de referencia/citación
--no-ref               : ocultar advertencias de referencia/citación
--info                 : mostrar mensajes de información de latex
--no-info              : ocultar mensajes de información de latex
--filename             : imprimir el nombre del archivo actual
--no-filename          : no imprimir el nombre del archivo actual
--files-ext=cadena     : patrón regex utilizado para coincidir con extensiones de archivo (por defecto: tex|sty|cls|bib)
--skips                : indicar líneas omitidas
--no-skips             : ocultar líneas omitidas
--skip-marker=cadena   : marcador utilizado para indicar líneas omitidas (por defecto: ...)
--add-filter=cadena    : agregar patrón de filtro de usuario (como expresión regular de perl)
--full-log             : mostrar registro completo (no filtrar - solo colorear la salida del motor latex)
--errors-color=cadena
--warnings-color=cadena
--infos-color=cadena
--skips-color=cadena
--user-color=cadena    : colores utilizados para errores, advertencias, informaciones y líneas omitidas
