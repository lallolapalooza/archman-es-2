TESTPARM(1) Comandos de usuario TESTPARM(1)

NOMBRE

testparm - comprueba un archivo de configuración smb.conf para ver su corrección interna

SINOPSIS

testparm [-s|--suppress-prompt] [-v|--verbose] [-?|--help] [--usage] [-d|--debuglevel=DEBUGLEVEL] [--debug-stdout] {nombre-archivo-config} [nombre-host IP-host]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

testparm es un programa de prueba muy simple para verificar la corrección interna de un archivo de configuración smbd(8). Si este programa no reporta problemas, puede usar el archivo de configuración con la confianza de que smbd cargará el archivo de configuración correctamente.

Tenga en cuenta que esto *NO* garantiza que los servicios especificados en el archivo de configuración estarán disponibles o funcionarán como se espera.

Si el nombre de host y la dirección IP del host opcionales se especifican en la línea de comandos, este programa de prueba revisará las entradas de servicio informando si el host especificado tiene acceso a cada servicio.

Si testparm encuentra un error en el archivo smb.conf, devuelve un código de salida de 1 al programa que lo llama, de lo contrario, devuelve un código de salida de 0. Esto permite a los scripts de shell probar la salida de testparm.

OPCIONES

-s|--suppress-prompt

Sin esta opción, testparm solicitará una pulsación de tecla después de imprimir los nombres de los servicios y antes de volcar las definiciones de servicios.

-v|--verbose

Si se especifica esta opción, testparm también mostrará todas las opciones que no se usaron en smb.conf(5) y, por lo tanto, se establecerán en sus valores predeterminados.

--parameter-name nombre-parametro

Vuelca el parámetro con nombre. Si no se establece ningún nombre de sección, la vista se limita por defecto a la sección global. También es posible volcar una opción paramétrica. Por lo tanto, la opción debe separarse por dos puntos del nombre-parametro.

--section-name nombre-seccion

Vuelca la sección con nombre.

--show-all-parameters

Muestra los parámetros, el tipo, los valores posibles.

-l|--skip-logic-checks

Omite las comprobaciones lógicas globales.

-?|--help

Imprime un resumen de las opciones de la línea de comandos.

--usage

Muestra un breve mensaje de uso.

-d|--debuglevel=nivel

nivel es un entero de 0 a 10. El valor predeterminado si no se especifica este parámetro es 1 para las aplicaciones cliente.

Cuanto mayor sea este valor, más detalles se registrarán en los archivos de registro sobre las actividades del servidor. En el nivel 0, solo se registrarán errores críticos y advertencias graves. El nivel 1 es un nivel razonable para el uso diario: genera una pequeña cantidad de información sobre las operaciones realizadas.

Los niveles superiores a 1 generarán una cantidad considerable de datos de registro y solo deben usarse al investigar un problema. Los niveles superiores a 3 están diseñados para ser utilizados solo por desarrolladores y generan ENORMES cantidades de datos de registro, la mayor parte de los cuales son extremadamente crípticos.

Tenga en cuenta que especificar este parámetro aquí anulará el parámetro log level en el archivo /etc/samba/smb.conf.

--debug-stdout

Redirigirá la salida de depuración a STDOUT. Por defecto, todos los clientes registran en STDERR.

--configfile=<archivo de configuración>

El archivo especificado contiene los detalles de configuración requeridos por el cliente. La información en este archivo puede ser general para el cliente y el servidor o solo proporcionar opciones específicas del cliente, como client smb encrypt. Consulte /etc/samba/smb.conf para obtener más información. El nombre del archivo de configuración predeterminado se determina en tiempo de compilación.

--option=<nombre>=<valor>

Establece la opción smb.conf(5) "<nombre>" al valor "<valor>" desde la línea de comandos. Esto anula los valores predeterminados compilados y las opciones leídas del archivo de configuración. Si un nombre o un valor incluyen un espacio, envuelva todo --option=nombre=valor entre comillas.

-V|--version

Imprime el número de versión del programa.

nombre-archivo-config

Este es el nombre del archivo de configuración a verificar. Si este parámetro no está presente, se verificará el archivo smb.conf(5) predeterminado.

nombre-host

Si este parámetro y los siguientes se especifican, entonces testparm examinará los parámetros hosts allow y hosts deny en el archivo smb.conf(5) para determinar si el nombre de host con esta dirección IP tendría acceso al servidor smbd. Si se proporciona este parámetro, el parámetro IP-host también debe proporcionarse.

IP-host

Esta es la dirección IP del host especificado en el parámetro anterior. Esta dirección debe proporcionarse si se proporciona el parámetro nombre-host.

ARCHIVOS

smb.conf(5)

Este es generalmente el nombre del archivo de configuración utilizado por smbd(8).

DIAGNÓSTICOS

El programa emitirá un mensaje indicando si el archivo de configuración se cargó correctamente o no. Este mensaje puede ir precedido por errores y advertencias si el archivo no se cargó. Si el archivo se cargó correctamente, el programa luego vuelca todos los detalles de servicio conocidos a stdout.

Para ciertos casos de uso, el protocolo SMB requiere el uso de algoritmos criptográficos que se sabe que son débiles y ya rotos. Las cifras DES y ARCFOUR (RC4) y los algoritmos hash SHA1 y MD5 se consideran débiles, pero son necesarios para la compatibilidad con versiones anteriores. La utilidad testparm muestra si las herramientas Samba recurrirán a estos algoritmos criptográficos débiles si no es posible utilizar criptografía fuerte por defecto. En modo FIPS, no se puede habilitar criptografía débil.

testparm(1)

NOMBRE

testparm - Verificar la configuración de Samba

SINOPSIS

testparm [-d] [-s] [-v] [archivo de configuración]...

DESCRIPCIÓN

testparm es una utilidad para comprobar la sintaxis de los archivos de configuración de Samba. Es una buena práctica ejecutar testparm después de realizar cualquier cambio en el archivo smb.conf.

Si se llama sin argumentos, testparm comprobará el archivo smb.conf por defecto. Si se proporcionan uno o más nombres de archivo, testparm comprobará cada uno de ellos.

El programa revisará la sintaxis del archivo de configuración y notificará cualquier error. Si el archivo de configuración está sintácticamente correcto, testparm imprimirá una lista de las opciones de configuración y sus valores, y terminará sin errores.

OPCIONES

  • -d, --debug-level=level Establece el nivel de depuración en level.
  • -s, --show-all Imprime la configuración completa, incluyendo las opciones por defecto.
  • -v, --version Imprime la versión de Samba y sale.

EJEMPLOS

Comprobar la configuración por defecto:

  testparm

Comprobar un archivo de configuración específico:

  testparm /etc/samba/smb.conf.nuevo

Comprobar todos los archivos de configuración y mostrar todas las opciones:

  testparm -s /etc/samba/smb.conf /etc/samba/smb.conf.viejo

ESTADO DE SALIDA

Devuelve 0 si la configuración es válida, y un valor distinto de cero si se detectan errores.

VER TAMBIÉN

smb.conf(5)

AUTOR
