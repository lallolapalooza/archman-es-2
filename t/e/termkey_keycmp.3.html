NOMBRE

termkey_keycmp - compara dos eventos de tecla

SINOPSIS

#include <termkey.h>

int termkey_keycmp(TermKey *tk, const TermKeyKey *key1,
             const TermKeyKey *key2);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_keycmp() compara dos estructuras de tecla y aplica un orden total, devolviendo un valor que es negativo, cero o positivo, para indicar si las estructuras dadas son crecientes, idénticas o decrecientes. Antes de la comparación, se toman copias de ambas estructuras referenciadas y se normalizan según las reglas de termkey_canonicalise(3).

Dos estructuras de diferente tipo se ordenan TERMKEY_TYPE_UNICODE, TERMKEY_TYPE_KEYSYM, TERMKEY_TYPE_FUNCTION, TERMKEY_TYPE_MOUSE. Las estructuras Unicode se ordenan por punto de código, las estructuras keysym se ordenan por número de keysym, las estructuras de función se ordenan por número de tecla de función y las estructuras de ratón se ordenan opacamente por un ordenamiento no especificado pero consistente. Dentro de estos valores, las teclas diferentes en bits modificadores se ordenan por los modificadores.

VALOR DE RETORNO

termkey_keycmp() devuelve un entero mayor que, igual a, o menor que cero para indicar la relación entre las dos estructuras de tecla dadas.

VER TAMBIÉN

termkey_strpkey(3), termkey_canonicalise(3), termkey(7)
