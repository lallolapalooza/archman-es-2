TERMINATOR(1) Manual para Terminator TERMINATOR(1)

NOMBRE

terminator - terminales GNOME múltiples en una ventana

SINOPSIS

terminator [opciones]

DESCRIPCIÓN

Esta página del manual documenta Terminator, una aplicación emuladora de terminal.

Terminator es un programa que permite a los usuarios configurar arreglos flexibles de terminales GNOME. Está dirigido a aquellos que normalmente organizan muchas terminales juntas, pero no quieren usar un gestor de ventanas basado en marcos.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`-'). A continuación se incluye un resumen de las opciones.

-h, --help

Muestra un resumen de las opciones.

-v, --version

Muestra la versión de la instalación de Terminator.

-m, -M, --maximise, --maximize

Inicia con una ventana maximizada.

-f, --fullscreen

Inicia con una ventana a pantalla completa.

-b, --borderless

Indica al gestor de ventanas que no renderice bordes/decoraciones en la ventana de Terminator (esto funciona bien con --maximise).

-H, --hidden

Oculta la ventana de Terminator por defecto. Su visibilidad se puede alternar con el atajo de teclado hide_window (Ctrl+Shift+Alt+A por defecto).

-T FORCEDTITLE, --title=FORCEDTITLE

Fuerza a la ventana de Terminator a usar un nombre específico en lugar de actualizarlo dinámicamente según los deseos del shell hijo.

--geometry=GEOMETRY

Especifica el tamaño y la posición preferidos de la ventana de Terminator; consulta X(7).

-e COMMAND, --command=COMMAND

Ejecuta el comando especificado en lugar del shell por defecto o el comando especificado en el perfil.
Nota: si Terminator se lanza como x-terminal-emulator, -e se comporta como -x, y la forma larga se convierte en --execute2=COMMAND.

-x COMMAND [ARGS], --execute=COMMAND [ARGS]

Ejecuta el resto de la línea de comandos en lugar del shell por defecto o el comando especificado en el perfil.

--working-directory=DIR

Establece el directorio de trabajo de la terminal.

-g FILE, --config=FILE

Utiliza el archivo especificado para la configuración.

-r ROLE, --role=ROLE

Establece una propiedad WM_WINDOW_ROLE personalizada en la ventana.

-l LAYOUT, --layout=LAYOUT

Inicia Terminator con un diseño específico. El argumento aquí es el nombre de un diseño guardado.

-s LAYOUT, --select-layout=LAYOUT

Abre la ventana del lanzador de diseños en lugar de la terminal normal.

-p, --profile=PROFILE

Utiliza un perfil diferente como predeterminado.

-i, --icon=FORCEDICON

Establece un icono personalizado para la ventana (por archivo o nombre).

-u, --no-dbus

Deshabilita DBus.

-d, --debug

Habilita la salida de depuración (úsalo al informar errores). Esto se puede especificar dos veces para habilitar un servidor de depuración de Python incorporado.

--debug-classes=DEBUG_CLASSES

Si se especifica como una lista separada por comas, la salida de depuración solo se imprimirá desde las clases especificadas.

--debug-methods=DEBUG_METHODS

Si se especifica como una lista separada por comas, la salida de depuración solo se imprimirá desde las funciones especificadas. Si esto se especifica además de --debug-classes, solo se mostrará la intersección de ambas listas.

--new-tab

Si se especifica y Terminator ya se está ejecutando, DBus se utilizará para generar una nueva pestaña en la primera ventana de Terminator.

--toggle-visibility

Si se especifica y Terminator ya se está ejecutando, DBus se utilizará para alternar la visibilidad de la ventana de Terminator. Útil bajo Wayland para reemplazar el atajo de teclado para ocultar.

ATajos DE TECLADO

Los siguientes atajos de teclado predeterminados se pueden usar para controlar Terminator. La mayoría de estos atajos se pueden cambiar en las Preferencias.

F1

Lanza el manual HTML completo.

Creación & Destrucción

Los siguientes elementos se relacionan con la creación y destrucción de terminales.

Ctrl+Shift+O

Divide las terminales Horizontalmente.

Ctrl+Shift+E

Divide las terminales Verticalmente.

Ctrl+Shift+T

Abre una nueva tab.

Ctrl+Shift+I

Abre una nueva ventana.
(Nota: a diferencia de versiones anteriores, esta ventana es parte del mismo proceso de Terminator.)

Super+I

Genera un nuevo proceso de Terminator.

Alt+L

Abre el lanzador de layouts.

Ctrl+Shift+W

Cierra la terminal actual.

Ctrl+Shift+Q

Cierra la ventana actual.

Navegación

Los siguientes elementos se relacionan con el movimiento entre terminales y alrededor de ellas.

Alt+Arriba

Mueve a la terminal que está arriba de la actual.

Alt+Abajo

Mueve a la terminal que está debajo de la actual.

Alt+Izquierda

Mueve a la terminal que está a la izquierda de la actual.

Alt+Derecha

Mueve a la terminal que está a la derecha de la actual.

Ctrl+PageDown

Mueve a la siguiente pestaña.

Ctrl+PageUp

Mueve a la pestaña anterior.

Ctrl+Shift+N o Ctrl+Tab

Mueve a la siguiente terminal dentro de la misma pestaña.

Ctrl+Shift+P o Ctrl+Shift+Tab

Mueve a la terminal anterior dentro de la misma pestaña.

Organización

Los siguientes elementos se relacionan con la organización y el redimensionamiento de terminales.

Ctrl+Shift+Derecha

Mueve la barra separadora principal hacia la derecha.

Ctrl+Shift+Izquierda

Mueve la barra separadora principal hacia la izquierda.

Ctrl+Shift+Arriba

Mueve la barra separadora principal hacia arriba.

Ctrl+Shift+Abajo

Mueve la barra separadora principal hacia abajo.

Super+R

Rota las terminales en sentido horario.

Super+Shift+R

Rota las terminales en sentido antihorario.

Ctrl+Shift+PageDown

Intercambia la posición de la pestaña con la siguiente pestaña.

Ctrl+Shift+PageUp

Intercambia la posición de la pestaña con la pestaña anterior.

Arrastrar y Soltar

El diseño se puede modificar moviendo terminales con Arrastrar y Soltar. Para empezar a arrastrar una terminal, haz clic y mantén presionado el botón del ratón en su barra de título. Alternativamente, mantén presionada la tecla Ctrl, haz clic y mantén presionado el botón derecho del ratón. Luego, suelta Ctrl. Ahora puedes arrastrar la terminal al punto del diseño donde deseas que esté. La zona donde se insertaría la terminal se resaltará.

Enfoque

Los siguientes elementos se relacionan con la ayuda para enfocar una terminal específica.

F11

Alterna la ventana a pantalla completa.

Ctrl+Shift+X

OPTIONS

Terminator accepts the following command line options:

-h, --help

Show help message and exit.

-v, --version

Show version information and exit.

-e, --execute COMMAND

Execute the specified COMMAND in the first terminal created.

-x, --execute-all COMMAND

Execute the specified COMMAND in all terminals created.

-t, --title TITLE

Set the initial window title.

-N, --new-tab

Create a new tab instead of a new window.

-g, --geometry GEOMETRY

Specify the window size and position.

-r, --rename-tab TABNAME

Rename the current tab to TABNAME.

--layout LAYOUT

Use the specified layout file.

-f, --fullscreen

Start terminator in fullscreen mode.

-m, --maximize

Start terminator maximized.

--tab-position TAB_POS

Set the position of the new tab.

-i, --icon-name ICON_NAME

Set the icon name for the window.

-p, --profile PROFILE

Use the specified profile for the terminal.

--hidden

Hide the terminator window on startup.

--notify

Notify the system when terminator has started.

--debug

Enable debug output.

--set KEY=VALUE

Set a preference key to a specific value.

--swap TERMINAL1 TERMINAL2

Swap the positions of two terminals.

KEYBINDINGS

The following keyboard shortcuts are available:

Window Management

Ctrl+Shift+O

Split the terminal horizontally.

Ctrl+Shift+E

Split the terminal vertically.

Ctrl+Shift+W

Close the current terminal.

Ctrl+Shift+N

Create a new terminal window.

Ctrl+Shift+T

Create a new tab.

Ctrl+PageDown

Switch to the next tab.

Ctrl+PageUp

Switch to the previous tab.

Ctrl+Shift+Tab

Switch to the previous tab.

Ctrl+Tab

Switch to the next tab.

Alt+1

Switch to tab 1.

Alt+2

Switch to tab 2.

Alt+3

Switch to tab 3.

Alt+4

Switch to tab 4.

Alt+5

Switch to tab 5.

Alt+6

Switch to tab 6.

Alt+7

Switch to tab 7.

Alt+8

Switch to tab 8.

Alt+9

Switch to tab 9.

Alt+0

Switch to tab 10.

Ctrl+Shift+Z

Toggle between showing all terminals and only showing a scaled version of the current one (zoom).

Ctrl+Shift+Alt+A

Hide the initial window. Note that this is a X11 global binding, and can only be bound once. On Wayland use window manager keyboard shortcuts to call terminator --toggle-visibility.

Grouping & Broadcasting

The following items relate to grouping and broadcasting.

Super+T

Group all terminals in the current tab so that any input sent to one of them goes to all of them.

Super+Shift+T

Remove grouping from all terminals in the current tab.

Super+G

Group all terminals so that any input sent to one of them goes to all of them.

Super+Shift+G

Remove grouping from all terminals.

Alt+A

Broadcast to all terminals.

Alt+G

Broadcast to grouped terminals.

Alt+O

Broadcast off.

Miscellaneous

The following items relate to miscellaneous terminal related functions.

Ctrl+Shift+C

Copy selected text to clipboard.

Ctrl+Shift+V

Paste clipboard text.

Ctrl+Shift+S

Toggle scrollbar.

Ctrl+Shift+F

Search within terminal scrollback.

Ctrl+Shift+R

Reset terminal state.

Ctrl+Shift+G

Reset terminal state and clear window.

Ctrl+Plus (+)

Increase font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Minus (-)

Decrease font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Zero (0)

Restore font size to original setting.

Ctrl+Alt+W

Rename window title.

Ctrl+Alt+A

Rename tab title.

Ctrl+Alt+X

Rename terminal title.

Super+1

Insert terminal number, i.e. 1 to 12.

Super+0

Insert padded terminal number, i.e. 01 to 12.
