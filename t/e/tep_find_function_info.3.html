tep_find_function_info(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_find_function, tep_find_function_address, tep_find_function_info - Encontrar nombre/dirección de inicio de función.

SINOPSIS

#include <event-parse.h>
const char *tep_find_function(struct tep_handle *tep, unsigned long long addr);
unsigned long long tep_find_function_address(struct tep_handle *tep, unsigned long long addr);
int tep_find_function_info(struct tep_handle *tep, unsigned long long addr, const char **name,
                           unsigned long long *start, unsigned long *size);

DESCRIPCIÓN

Estas funciones se pueden usar para encontrar el nombre y la dirección de inicio de una función, dada una dirección. La dirección proporcionada no tiene que ser exacta, seleccionará la función que la contendría.

La función tep_find_function() devuelve el nombre de la función que contiene la dirección addr proporcionada. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_find_function_address() devuelve la dirección de inicio de la función, dada la dirección addr. La dirección addr no tiene que ser exacta, seleccionará la función que la contendría. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_find_function_info() recupera el nombre, la dirección de inicio (start) y el tamaño del texto de la función en la dirección, si se encuentra. Tenga en cuenta que si el manejador tep tiene un resolvedor de funciones (utilizado por perf), entonces size se establece en cero.

VALOR DE RETORNO

La función tep_find_function() devuelve el nombre de la función, o NULL en caso de que no se pueda encontrar.

La función tep_find_function_address() devuelve la dirección de inicio de la función, o 0 en caso de que no se pueda encontrar.

La función tep_find_function_info() devuelve 1 si se encuentra una función para la dirección dada, o 0 si no.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
void show_function_name(unsigned long long addr)
{
        const char *fname = tep_find_function(tep, addr);
        if (fname)
                printf("Found function %s at 0x%0llx\n", fname, addr);
        else
                printf("No function found at 0x%0llx\n", addr);
}
void show_function_start_addr(unsigned long long addr)
{
        const char *fname = tep_find_function(tep, addr);
        unsigned long long fstart;
        if (!fname) {
                printf("No function found at 0x%0llx\n", addr);
                return;
        }
        fstart = tep_find_function_address(tep, addr);
        printf("Function %s at 0x%llx starts at 0x%0llx\n",
               fname, addr, fstart);
}
void show_function_info(unsigned long long addr)
{
        const char *fname;
        unsigned long long fstart;
        unsigned long size;
        ret = tep_find_function_info(tep, addr, &fname, &fstart, &size);
        if (!ret) {
                printf("No function found at 0x%0lx\n", addr);
                return;
        }
        printf("Function %s at 0x%lx starts at 0x%0lx and is %ld in size\n",
               fname, addr, fstart, size);
}
