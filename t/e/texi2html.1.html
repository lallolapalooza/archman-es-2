TEXI2HTML(1) Manual de comandos generales TEXI2HTML(1)

NOMBRE

texi2html - un conversor de Texinfo a HTML

SINOPSIS

texi2html [opciones] archivo

DESCRIPCIÓN

Texi2html convierte el archivo Texinfo dado a un conjunto de archivos HTML. Intenta manejar la mayoría de los comandos de Texinfo. Crea enlaces hipertexto para referencias cruzadas, notas al pie...

Texi2html además puede usar latex2html para generar HTML (código y/o imágenes) para las etiquetas @math y @iftex (ver la opción --l2h).

Texi2html crea varios archivos dependiendo del contenido del archivo Texinfo y de las opciones elegidas (ver ARCHIVOS).

Los archivos HTML creados por texi2html son, en general, más cercanos a TeX que a Info. Usando archivos de inicio (ver la opción --init-file), se pueden seleccionar otros estilos o formatos de salida.

OPCIONES

Las opciones pueden abreviarse hasta su prefijo único más corto. La siguiente es solo una lista incompleta de las opciones disponibles:

--help [1|2]
Imprime instrucciones de uso y lista las opciones de línea de comandos más importantes, todas las relevantes o todas las reconocidas (incluidas las obsoletas), y sale.
--split chapter|section|node
Divide la salida en varios archivos HTML (uno por capítulo/sección principal o nodo).
--ifinfo --iftex --ifxml --ifplaintext --ifhtml
Expande las regiones @ifinfo, @iftex y @tex, @ifxml y @xml, @ifplaintext, @ifhtml y @html, y no expande las regiones @ifnot correspondientes (por defecto: ifhtml).
--no-ifinfo --no-iftex --no-ifxml --no-ifplaintext --no-html
No expande las regiones @ifinfo, @iftex, @ifxml, @ifplaintext y expande las regiones @ifnot correspondientes.
-I dir
Añade dir a la lista de directorios buscados para archivos incluidos.
-P dir
Antepone dir a la lista de directorios buscados para archivos incluidos.
--l2h
Usa latex2html para el contenido de las etiquetas @math y @tex. El contenido debe ser tal que tanto latex como tex puedan traducirlo correctamente. Es decir, no deben usarse construcciones exclusivas de tex.
--css-include archivo
Usa el archivo css archivo.
--init-file archivo
Carga el archivo de inicio archivo (ver también ARCHIVOS).
--document-language lang
Usa lang como idioma del documento.
--macro-expand archivo
Salida del código fuente expandido de macros en archivo.
--no-menu
No mostrar los menús de Texinfo; por defecto se muestran.
--no-number
No numerar las secciones.
--use-nodes
Usar nodos para la sección.
--prefix
Usar como prefijo para los archivos de salida, en lugar del nombre base.
--node-files
Producir un archivo por nodo para referencias cruzadas.
--l2h-l2h prog
Usar prog como programa latex2html (por defecto latex2html). El programa debe ser ejecutable.
--l2h-init archivo
Usar archivo como archivo de inicio de latex2html. archivo debe usarse para especificar la forma en que latex2html maneja las expresiones matemáticas y fórmulas.
--l2h-tmp dir
Usar dir como directorio temporal para latex2html. Este directorio (o su ruta) no debe contener un punto (es decir, un ".").
--l2h-clean
eliminar todos los archivos intermedios generados por latex2html (¡evita el caché!).
--l2h-skip
No ejecutar realmente latex2html. Usar los archivos (guardados) de ejecuciones anteriores en su lugar.
--verbose
Dar una salida detallada.
--version
Imprimir la versión y salir.

ARCHIVOS

Las opciones de inicialización se leen primero de /usr/share/texi2html/Config (la ubicación exacta se puede cambiar con la opción --datadir=dir para el script configure), luego de /usr/etc/texi2html/Config (la ubicación exacta se puede cambiar con la opción --sysconfdir=dir para el script configure), luego de ./Config, de $HOME/.texi2html/Config, y de cualquier opción de línea de comandos, incluidas las opciones --init-file; las configuraciones posteriores anulan las anteriores.

Por defecto, texi2html puede crear los siguientes archivos (foo es el nombre del archivo Texinfo):

foo_toc.html
La tabla de contenidos (si está presente @contents).
foo.html
El contenido del documento o el elemento Top.
foo_fot.html
Las notas al pie (si las hay).
foo_abt.html
Una sección de ayuda.
foo_l2h_img*
Imágenes generadas por latex2html (si las hay).

Cuando se usa con la opción --split, crea varios archivos (uno por capítulo o nodo), llamados foo_n.html (n siendo el índice del capítulo o nodo), y el archivo foo.html contiene el elemento Top.

De lo contrario, crea solo un archivo: foo.html
