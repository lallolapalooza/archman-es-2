NOMBRE

textureGradOffset - realiza una búsqueda de textura con gradientes y desplazamiento explícitos

DECLARACIÓN

gvec4 textureGradOffset(gsampler1D sampler, float P, float dPdx, float dPdy, int offset);

gvec4 textureGradOffset(gsampler2D sampler, vec2 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

gvec4 textureGradOffset(gsampler3D sampler, vec3 P, vec3 dPdx, vec3 dPdy, ivec3 offset);

gvec4 textureGradOffset(gsampler2DRect sampler, vec2 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

float textureGradOffset(sampler2DRectShadow sampler, vec3 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

float textureGradOffset(sampler1DShadow sampler, vec3 P, float dPdx, float dPdy, int offset);

float textureGradOffset(sampler2DShadow sampler, vec3 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

gvec4 textureGradOffset(gsampler1DArray sampler, vec2 P, float dPdx, float dPdy, int offset);

gvec4 textureGradOffset(gsampler2DArray sampler, vec3 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

float textureGradOffset(sampler1DArrayShadow sampler, vec3 P, float dPdx, float dPdy, int offset);

float textureGradOffset(sampler2DArrayShadow sampler, vec4 P, vec2 dPdx, vec2 dPdy, ivec2 offset);

PARÁMETROS

sampler

Especifica el sampler al que está enlazada la textura desde la cual se recuperarán los texels.

P

Especifica las coordenadas de textura en las que se muestreará la textura.

dPdx

Especifica la derivada parcial de P con respecto a la ventana x.

dPdy

Especifica la derivada parcial de P con respecto a la ventana y.

offset

Especifica el desplazamiento que se aplicará a las coordenadas de textura antes de muestrear.

DESCRIPCIÓN

textureGradOffset realiza una búsqueda de textura en la coordenada P de la textura enlazada a sampler con gradientes de coordenadas de textura explícitos como se especifica en dPdx y dPdy. También se proporciona un desplazamiento explícito en offset. textureGradOffset consume dPdx y dPdy como textureGrad() y offset como textureOffset().

textureGradOffset(3G)

NAME

textureGradOffset - Returns the calculated texture gradient offset.

DESCRIPTION

textureGradOffset returns the calculated texture gradient offset for a given texture unit. The gradient offset is used in texture mapping to determine the sampling offset based on the texture coordinates.

This function is typically used in conjunction with texture derivatives functions such as textureGrad() or textureQueryLod() to achieve more precise texture sampling and mipmap selection.

SYNTAX

float textureGradOffset(sampler2D sampler, vec2 P, vec2 dPdx, vec2 dPdy, int offset);

PARAMETERS

  • sampler: The texture sampler to query.

  • P: The texture coordinates.

  • dPdx: The partial derivative of the texture coordinates with respect to the x-coordinate of the fragment.

  • dPdy: The partial derivative of the texture coordinates with respect to the y-coordinate of the fragment.

  • offset: The texture gradient offset. This is a 2D integer offset that is added to the calculated gradient offset.

RETURN VALUE

The calculated texture gradient offset. This is a floating-point value representing the offset in the texture's texel space.

EXAMPLE

// Sample a texture with a gradient offset
vec2 uv = texCoord;
vec2 grad_offset = textureGradOffset(my_texture, uv, dPdx, dPdy, ivec2(1, 0));
vec4 color = texture(my_texture, uv + grad_offset);
