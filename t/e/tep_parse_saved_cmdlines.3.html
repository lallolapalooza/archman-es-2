tep_parse_saved_cmdlines(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_parse_saved_cmdlines, tep_parse_printk_formats, tep_parse_kallsyms - Funciones de análisis para cargar mapeos

SINOPSIS

#include <event-parse.h>
int tep_parse_saved_cmdlines(struct tep_handle *tep, const char *buf);
int tep_parse_printk_formats(struct tep_handle *tep, const char *buf);
int tep_parse_kallsyms(struct tep_handle *tep, const char *buf);

DESCRIPCIÓN

tep_parse_saved_cmdlines() es una función auxiliar para analizar el contenido del sistema de archivos tracefs del archivo "saved_cmdlines" (almacenado en un búfer de cadena pasado por buf) y carga el mapeo de los IDs de proceso (pid) a los nombres de comando en el manejador tep. Los eventos almacenan el pid y esto se utiliza para poder mostrar los nombres de los procesos asociados a esos IDs de proceso. Analiza la cadena buf que contiene el contenido de saved_cmdlines y termina con un carácter nulo (\0).

tep_parse_printk_formats() es una función auxiliar para analizar el contenido del sistema de archivos tracefs del archivo "printk_formats" (almacenado en un búfer de cadena pasado por buf) y carga el mapeo de direcciones de cadenas que pueden ser referenciadas por eventos. Los eventos solo almacenan la dirección de cadenas constantes en el kernel, y el mapeo de su dirección a la cadena se exporta al espacio de usuario en el archivo printk_formats. Analiza la cadena buf que contiene el contenido de printk_formats y termina con un carácter nulo (\0).

tep_parse_kallsyms() es una función auxiliar para analizar el formato /proc/kallsyms del kernel de Linux (almacenado en un búfer de cadena pasado por buf) y carga las funciones en el manejador tep de modo que las direcciones IP de las funciones puedan mapearse a su nombre al analizar eventos con %pS en el campo de formato de impresión. Analiza la cadena buf que contiene el contenido de /proc/kallsyms y termina con un carácter nulo (\0).

VALOR DE RETORNO

La función tep_parse_saved_cmdlines() devuelve 0 en caso de éxito, o -1 en caso de error.

La función tep_parse_printk_formats() devuelve 0 en caso de éxito, o -1 en caso de error.

La función tep_parse_kallsyms() devuelve 0 en caso de éxito, o -1 en caso de error.

EJEMPLO

...
#include <event-parse.h>
#include <tracefs.h>
#include <stdlib.h>
int load_cmdlines(struct tep_handle *tep)
{
        char *buf = NULL;
        int r;
        buf = tracefs_instance_file_read(NULL, "saved_cmdlines", NULL);
        if (!buf)
                return -1;
        r = tep_parse_saved_cmdlines(tep, buf);
        free(buf);
        return r;
}
int load_print_strings(struct tep_handle *tep)
{
        char *buf = NULL;
        int r;
        buf = tracefs_instance_file_read(NULL, "printk_formats", NULL);
        if (!buf)
                return -1;
        r = tep_parse_printk_formats(tep, buf);
        free(buf);
        return r;
}
int load_kallsyms(struct tep_handle *tep)
{
        char *line = NULL;
        char *buf = NULL;
        size_t sz = 0;
        FILE *fp;
        int len = 0;
        int r;
        fp = fopen("/proc/kallsyms", "r");
        while ((r = getline(&line, &sz, fp)) >= 0) {
                buf = realloc(buf, len + r + 1);
                memcpy(buf + len, line, r);
                len += r;
        }
        free(line);
        fclose(fp);
        if (!buf)
                return -1;
        buf[len] = 0;
        r = tep_parse_kallsyms(tep, buf);
        free(buf);
        return r;
}
