TEXELFETCHOFFSET(3G) [FIJO: manual] TEXELFETCHOFFSET(3G)

NOMBRE

texelFetchOffset - realiza una búsqueda de un solo texel dentro de una textura con un desplazamiento

DECLARACIÓN

gvec4 texelFetchOffset(gsampler1D sampler, int P, int lod, int offset);

gvec4 texelFetchOffset(gsampler2D sampler, ivec2 P, int lod, ivec2 offset);

gvec4 texelFetchOffset(gsampler3D sampler, ivec3 P, int lod, ivec3 offset);

gvec4 texelFetchOffset(gsampler2DRect sampler, ivec2 P, ivec2 offset);

gvec4 texelFetchOffset(gsampler1DArray sampler, ivec2 P, int lod, ivec2 offset);

gvec4 texelFetchOffset(gsampler2DArray sampler, ivec3 P, int lod, ivec2 offset);

PARÁMETROS

sampler

Especifica el sampler al que está enlazada la textura de la que se obtendrán los texeles.

P

Especifica las coordenadas de textura en las que se muestreará la textura.

lod

Si está presente, especifica el nivel de detalle dentro de la textura de donde se obtendrá el texel.

offset

Especifica un desplazamiento, en texeles, que se aplicará a P antes de buscar el texel.

DESCRIPCIÓN

texelFetchOffset realiza una búsqueda de un solo texel desde la coordenada de textura P en la textura enlazada a sampler. Antes de obtener el texel, se añade el desplazamiento especificado en offset a P. offset debe ser una expresión constante. La capa de la matriz se especifica en el último componente de P para las formas de matriz. El parámetro lod (si está presente) especifica el nivel de detalle de donde se obtendrá el texel. El parámetro sample especifica qué muestra dentro del texel se devolverá al leer de una textura multimuestra.
