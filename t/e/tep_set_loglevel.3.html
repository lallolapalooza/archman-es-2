tep_set_loglevel(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_set_loglevel - Establece el nivel de registro de la biblioteca

SINOPSIS

#include <event-parse.h>
enum tep_loglevel {
        TEP_LOG_NONE = 0,
        TEP_LOG_CRITICAL,
        TEP_LOG_ERROR,
        TEP_LOG_WARNING,
        TEP_LOG_INFO,
        TEP_LOG_DEBUG,
        TEP_LOG_ALL
};
int tep_set_loglevel(enum tep_loglevel level);

DESCRIPCIÓN

La función tep_set_loglevel() establece el nivel de los registros de la biblioteca que se imprimirán en la consola. Los niveles de registro de la biblioteca son:

        TEP_LOG_NONE - No imprimir ningún registro.
        TEP_LOG_CRITICAL - Imprimir registros críticos, problemas que pueden causar un bloqueo.
        TEP_LOG_ERROR - Imprimir registros de error, problemas que podrían romper la lógica principal de una API.
        TEP_LOG_WARNING - Imprimir advertencias, problemas que podrían limitar el resultado de una API.
        TEP_LOG_INFO - Imprimir información sobre la ejecución normal de una API.
        TEP_LOG_DEBUG - Imprimir información de depuración.
        TEP_LOG_ALL - Imprimir registros de todos los niveles.

Establecer el nivel de registro a un valor específico significa que también se imprimirán los registros de los niveles anteriores. Por ejemplo, TEP_LOG_WARNING imprimirá cualquier registro con severidad TEP_LOG_WARNING, TEP_LOG_ERROR y TEP_LOG_CRITICAL. El nivel de registro predeterminado es TEP_LOG_CRITICAL.

EJEMPLO

#include <event-parse.h>
tep_set_loglevel(TEP_LOG_ALL);
...
/* llamar a las APIs de libtraceevent y observar los registros que producen */
...
tep_set_loglevel(TEP_LOG_CRITICAL);
