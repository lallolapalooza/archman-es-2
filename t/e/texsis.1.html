TEXSIS(1) Manuales de Usuario TEXSIS(1)

NOMBRE

TeXsis - Macros TeX para Físicos

SINOPSIS

texsis [ nombre_archivo ]

DESCRIPCIÓN

TeXsis es una colección de macros de TeX para componer documentos de física como artículos y preprints, actas de conferencias, libros, tesis, informes de referees, cartas y memorandos. Las macros de TeXsis proporcionan numeración automática de ecuaciones, numeración y formato automáticos de referencias, formato a doble columna, macros para crear tablas y figuras, con o sin leyendas, incluyendo tablas con líneas horizontales y verticales. TeXsis soporta una amplia variedad de tamaños de letra y un número de formatos de documentos especializados, e incluso incluye macros para crear cartas modelo para solicitudes de empleo o cartas de recomendación.

TeXsis es una extensión de TeX "simple", por lo que todo lo que sepas hacer en TeX simple, lo puedes hacer en TeXsis. Las instrucciones de macros de TeXsis son simplemente abreviaturas para combinaciones de secuencias de control usadas frecuentemente para componer documentos de física. Para más información sobre TeX simple, consulta las páginas del manual de tex(1), y/o The TeXbook, de D.E. Knuth.

TeXsis se almacena como un formato pre-cargado para que se cargue rápidamente (ver las páginas del manual de initex(1), y/o "formatos pre-cargados" en The TeXbook). Para ejecutar TeXsis, simplemente escribe el comando texsis en lugar del comando tex, es decir:


texsis [ nombre_archivo ]

donde nombre_archivo.tex es el nombre de un archivo que contiene secuencias de control de TeX y/o TeXsis.

TeXsis está inicialmente en modo TeX simple, es decir, tipo de 10pt y espaciado simple, pero la secuencia de control \texsis selecciona tipo de 12pt, doble espaciado, y habilita otras características útiles. Alternativamente, \paper activa estas características y lo configura para componer un artículo, \thesis hace lo mismo para componer una tesis, \letter se usa para producir una carta utilizando macros similares a las listadas al final de The TeXbook, \memo proporciona una configuración para producir memorandos, y así sucesivamente.

Hay disponible un manual que describe todas las instrucciones de macros de TeXsis. Está escrito en TeXsis, por lo que sirve como su propio ejemplo de cómo escribir un documento con TeXsis. El código fuente también está ampliamente comentado, por lo que es posible extraer macros útiles del código fuente y modificarlas para adaptarlas a tus propios propósitos. Se hacen disposiciones para la personalización local de TeXsis. En particular, el archivo TXSmods.tex, si existe, se lee del directorio actual o de la ruta TEXINPUTS cada vez que se inicia TeXsis. Por lo tanto, puedes colocar tus propias macros personalizadas para un proyecto dado en un directorio y se cargarán automáticamente cuando se ejecute TeXsis desde ese directorio.

INSTALACIÓN

Hay un apéndice en el manual impreso que contiene instrucciones detalladas de instalación, pero también se proporcionan en un formato que puede ser procesado por TeX simple, en el archivo Install.tex.

DIAGNÓSTICOS

Los mensajes informativos de TeXsis se escriben en la terminal y en el archivo de registro comenzando con `% '. Los mensajes de advertencia y error comienzan con `> '.

ARCHIVOS

Los archivos fuente para TeXsis y el manual de TeXsis suelen estar instalados en el mismo lugar donde se guarda el resto de TeX. Aunque esto puede variar de una instalación a otra, generalmente incluirá un directorio raíz llamado texmf. Ejemplos comunes son /usr/share/texmf/, /usr/lib/teTeX/texmf, o /usr/local/lib/texmf. Los nombres de archivo aquí son relativos a este directorio raíz texmf.

web2c/texsis.fmt
Formato pre-cargado de TeXsis.
tex/texsis/TXS*.tex
Código fuente de TeXsis.
tex/texsis/*.txs
"Archivos de estilo" que se pueden leer en tiempo de ejecución para formatos de documento especiales.
doc/texsis/TXS*.doc
Fuente del manual impreso de TeXsis (escrito en TeXsis).
tex/texsis/TXSsite.tex
Instrucciones de personalización del sitio local (esto se lee solo una vez, cuando se crea el archivo de formato).
tex/texsis/TXSpatch.tex
Archivo de parche en tiempo de ejecución (como un archivo rc de sistema TeXsis, se lee cada vez que se ejecuta TeXsis).
TXSmods.tex
Archivo de inicialización en tiempo de ejecución (se lee cada vez que se ejecuta TeXsis desde el directorio actual o desde la ruta de búsqueda en TEXINPUTS).

RESTRICCIONES

Tenga en cuenta que TeXsis está diseñado para ser completamente compatible con TeX simple. Como resultado, no puede ser compatible con LaTeX.

Tener el manual completo escrito en TeXsis puede causar un problema si no tienes una versión de TeXsis ya en ejecución. Para solucionar esto, puedes ejecutar Manual.tex a través de TeX simple y cargará los archivos TeXsis antes de procesar el manual. Esto lleva más tiempo, pero no mucho.

ERRORES

Por favor, informe de errores (o sugerencias de mejoras) a texsis@feynman.physics.lsa.umich.edu.

Los parches para corregir pequeños problemas o hacer pequeñas mejoras están disponibles en


ftp://feynman.physics.lsa.umich.edu/texsis/

en el archivo TXSpatch.tex (Si ese archivo no existe, entonces no hay parches actuales.)
