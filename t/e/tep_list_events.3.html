tep_list_events(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_list_events, tep_list_events_copy - Obtiene la lista de eventos, ordenada según los criterios dados.

SINOPSIS

#include <event-parse.h>
enum tep_event_sort_type {
        TEP_EVENT_SORT_ID,
        TEP_EVENT_SORT_NAME,
        TEP_EVENT_SORT_SYSTEM,
};
struct tep_event **tep_list_events(struct tep_handle *tep, enum tep_event_sort_type sort_type);
struct tep_event **tep_list_events_copy(struct tep_handle *tep, enum tep_event_sort_type sort_type);

DESCRIPCIÓN

La función tep_list_events() devuelve un array de punteros a los eventos, ordenado según los criterios de sort_type. El último elemento del array es NULL. La memoria devuelta no debe liberarse, es gestionada por la biblioteca. La función no es segura para hilos. El argumento tep es el contexto del analizador de eventos de traza. El argumento sort_type es el criterio de ordenación requerido:

        TEP_EVENT_SORT_ID     - ordenar por ID del evento.
        TEP_EVENT_SORT_NAME   - ordenar por el trío (nombre, sistema, id) del evento.
        TEP_EVENT_SORT_SYSTEM - ordenar por el trío (sistema, nombre, id) del evento.

La función tep_list_events_copy() es una versión segura para hilos de tep_list_events(). Tiene el mismo comportamiento, pero el array devuelto se asigna internamente y debe ser liberado por el llamante. Tenga en cuenta que el contenido del array no debe liberarse (ver EJEMPLO a continuación).

VALOR DE RETORNO

La función tep_list_events() devuelve un array de punteros a eventos. En caso de error, devuelve NULL. El array devuelto no debe ser liberado, es gestionado por la biblioteca.

La función tep_list_events_copy() devuelve un array de punteros a eventos. En caso de error, devuelve NULL. El array devuelto debe ser liberado por el llamante.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int i;
struct tep_event_format **events;
i=0;
events = tep_list_events(tep, TEP_EVENT_SORT_ID);
if (events == NULL) {
        /* Falló al obtener los eventos, ordenados por ID */
} else {
        while(events[i]) {
                /* Recorre la lista de eventos, ordenados por ID */
                i++;
        }
}
i=0;
events = tep_list_events_copy(tep, TEP_EVENT_SORT_NAME);
if (events == NULL) {
        /* Falló al obtener los eventos, ordenados por nombre */
} else {
        while(events[i]) {
                /* Recorre la lista de eventos, ordenados por nombre */
                i++;
        }
        free(events);
}
...
