mtxrun(1) Herramienta Ejecutora de ConTeXt TDS mtxrun(1)

NOMBRE


mtxrun - Herramienta Ejecutora de ConTeXt TDS

SINOPSIS

mtxrun [ OPCIONES ... ] [ ARCHIVOS ]

DESCRIPCIÓN

Herramienta Ejecutora de ConTeXt TDS

OPCIONES

--script
ejecutar un script mtx (método preferido lua) (--noquotes), ningún script da una lista
--evaluate
ejecutar código pasado en la línea de comandos (entre comillas) (=bucle) (exit|quit aborta)
--execute
ejecutar un script o programa (método texmfstart) (--noquotes)
--resolve
resolver argumentos con prefijo
--ctxlua
ejecutar internamente (usando libs precargadas)
--internal
ejecutar script usando bibliotecas incorporadas (igual que --ctxlua)
--locate
localizar un archivo dado en la base de datos (por defecto) o en el sistema (--first --all --detail)
--tree=pathtotree
usar el árbol texmf dado (archivo por defecto: setuptex.tmf)
--path=runpath
ir a la ruta dada antes de la ejecución
--ifchanged=filename
ejecutar solo cuando el archivo dado ha cambiado (checksum md)
--iftouched=old,new
ejecutar solo cuando el archivo dado ha cambiado (marca de tiempo)
--makestubs
crear stubs para scripts (relacionados con context)
--removestubs
eliminar stubs para scripts (relacionados con context)
--stubpath=binpath
rutas donde se escribirán los stubs
--windows
crear stubs para windows (mswin)
--unix
crear stubs para unix (linux)
--addbinarypath
anteponer la ruta binaria (encontrada) a los ejecutores
--verbose
dar un poco más de información
--trackers=list
habilitar los rastreadores dados
--progname=str
formato o backend
--systeminfo=str
mostrar el sistema operativo actual, procesador, etc.
--edit
lanzar editor con el archivo encontrado
--launch
lanzar archivos como manuales, asume soporte del SO (--all,--list)
--timedrun
ejecutar un script y medir su tiempo de ejecución
--autogenerate
regenerar bases de datos si es necesario (útil cuando se usa para ejecutar context en un editor)
--usekpse
usar kpse como respaldo (cuando no hay mkiv y caché instalado, a menudo más lento)
--forcekpse
forzar el uso de kpse (útil cuando no hay mkiv y caché instalado, pero con menos funcionalidad)
--prefixes
mostrar prefijos soportados
--generate
generar base de datos de archivos
--variables
mostrar variables de configuración
--configurations
mostrar orden de configuración
--directives
mostrar directivas (conocidas)
--trackers
mostrar rastreadores (conocidos)
--experiments
mostrar experimentos (conocidos)
--expand-braces
expandir variable compleja
--resolve-path
expandir variable (resolver rutas completamente)
--expand-path
expandir variable (resolver rutas)
--expand-var
expandir variable (resolver referencias)
--show-path
mostrar expansión de ruta de ...
--var-value
reportar valor de variable
--find-file
reportar ubicación del archivo
--find-path
reportar ruta del archivo
--pattern=string
filtrar variables
