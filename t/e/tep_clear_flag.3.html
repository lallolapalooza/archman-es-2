NOMBRE

tep_set_flag, tep_clear_flag, tep_test_flag - Gestionar flags del contexto del analizador de eventos de traza.

SINOPSIS

#include <event-parse.h>
enum tep_flag {
        TEP_NSEC_OUTPUT,
        TEP_DISABLE_SYS_PLUGINS,
        TEP_DISABLE_PLUGINS
};
void tep_set_flag(struct tep_handle *tep, enum tep_flag flag);
void tep_clear_flag(struct tep_handle *tep, enum tep_flag flag);
bool tep_test_flag(struct tep_handle *tep, enum tep_flag flag);

DESCRIPCIÓN

Los flags del contexto del analizador de eventos de traza se definen en enum tep_flag:

TEP_NSEC_OUTPUT - imprime la marca de tiempo del evento en nanosegundos, en lugar de microsegundos.
TEP_DISABLE_SYS_PLUGINS - deshabilita plugins, ubicados en el directorio de
                        plugins del sistema. Este directorio se define en el momento
                        de compilar la biblioteca, y generalmente depende del prefijo
                        de instalación de la biblioteca: (prefijo_instalacion)/lib/traceevent/plugins
TEP_DISABLE_PLUGINS - deshabilita todos los plugins de la biblioteca:
                        - en el directorio de plugins del sistema
                        - en el directorio definido por la variable de entorno TRACEEVENT_PLUGIN_DIR
                        - en el directorio de inicio del usuario, ~/.traceevent/plugins

Nota: los flags relacionados con plugins deben establecerse antes de llamar a la API tep_load_plugins().

La función tep_set_flag() establece el flag en el contexto tep.

La función tep_clear_flag() borra el flag del contexto tep.

La función tep_test_flag() comprueba si el flag está establecido en el contexto tep.

VALOR DE RETORNO

La función tep_test_flag() devuelve verdadero si el flag está establecido, falso en caso contrario.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
/* Imprimir marcas de tiempo en nanosegundos */
tep_set_flag(tep,  TEP_NSEC_OUTPUT);
...
if (tep_test_flag(tep, TEP_NSEC_OUTPUT)) {
        /* imprimir marcas de tiempo en nanosegundos */
} else {
        /* imprimir marcas de tiempo en microsegundos */
}
...
/* Imprimir marcas de tiempo en microsegundos */
tep_clear_flag(tep, TEP_NSEC_OUTPUT);
...
