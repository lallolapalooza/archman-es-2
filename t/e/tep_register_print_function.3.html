tep_register_print_function(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_register_print_function, tep_unregister_print_function - Registra / Anula el registro de una función auxiliar.

SINOPSIS

#include <event-parse.h>
enum tep_func_arg_type {
        TEP_FUNC_ARG_VOID,
        TEP_FUNC_ARG_INT,
        TEP_FUNC_ARG_LONG,
        TEP_FUNC_ARG_STRING,
        TEP_FUNC_ARG_PTR,
        TEP_FUNC_ARG_MAX_TYPES
};
typedef unsigned long long (*tep_func_handler)(struct trace_seq *s, unsigned long long *args);
int tep_register_print_function(struct tep_handle *tep, tep_func_handler func, enum tep_func_arg_type ret_type, char *name, ...);
int tep_unregister_print_function(struct tep_handle *tep, tep_func_handler func, char *name);

DESCRIPCIÓN

Algunos eventos pueden tener funciones auxiliares en los argumentos del formato de impresión. Esto permite que un plugin cree dinámicamente una forma de procesar una de estas funciones.

tep_register_print_function() registra dicha función auxiliar. El argumento tep es el contexto del analizador de eventos de traza. El argumento func es un puntero a la función auxiliar. El argumento ret_type es el tipo de retorno de la función auxiliar, un valor del enum tep_func_arg_type. El argumento name es el nombre de la función auxiliar, tal como se ve en los argumentos del formato de impresión. El argumento ... es una lista variable de enums tep_func_arg_type, los argumentos de la función func. Esta lista debe terminar con TEP_FUNC_ARG_VOID. Consulte la sección EJEMPLO.

tep_unregister_print_function() anula el registro de una función auxiliar, registrada previamente con tep_register_print_function(). El argumento tep es el contexto del analizador de eventos de traza. Los argumentos func y name son los mismos, utilizados cuando se registró la función auxiliar.

El tipo tep_func_handler es el tipo de la función auxiliar. El argumento s es la secuencia de traza, puede usarse para crear una cadena personalizada. El argumento args es una lista de argumentos, definidos cuando se registró la función auxiliar.

VALOR DE RETORNO

La función tep_register_print_function() devuelve 0 en caso de éxito. En caso de error, se devuelve un código TEP_ERRNO_...

La función tep_unregister_print_function() devuelve 0 en caso de éxito, o -1 en caso de error.

EJEMPLO

Algunos eventos tienen llamadas a funciones internas, que aparecen en la salida del formato de impresión. Por ejemplo "tracefs/events/i915/g4x_wm/format" tiene:

print fmt: "pipe %c, frame=%u, scanline=%u, wm %d/%d/%d, sr %s/%d/%d/%d, hpll %s/%d/%d/%d, fbc %s",
            ((REC->pipe) + 'A'), REC->frame, REC->scanline, REC->primary,
            REC->sprite, REC->cursor, yesno(REC->cxsr), REC->sr_plane,
            REC->sr_cursor, REC->sr_fbc, yesno(REC->hpll), REC->hpll_plane,
            REC->hpll_cursor, REC->hpll_fbc, yesno(REC->fbc)

Observe la llamada a la función yesno() en los argumentos de impresión. En el contexto del kernel, esta función tiene la siguiente implementación:

static const char *yesno(int x)
{
        static const char *yes = "yes";
        static const char *no = "no";
        return x ? yes : no;
}

El analizador de eventos del espacio de usuario no tiene idea de cómo manejar esta función yesno(). La API tep_register_print_function() puede usarse para registrar una función auxiliar del espacio de usuario, mapeada a la yesno() del kernel:

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
static const char *yes_no_helper(int x)
{
        return x ? "yes" : "no";
}
...
        if ( tep_register_print_function(tep,
                                    yes_no_helper,
                                    TEP_FUNC_ARG_STRING,
                                    "yesno",
                                    TEP_FUNC_ARG_INT,
                                    TEP_FUNC_ARG_VOID) != 0) {
                /* Falló el registro de la función yes_no_helper */
        }
/*
   Ahora, cuando el analizador de eventos encuentre esta función yesno(), sabrá
   cómo manejarla.
*/
...
        if (tep_unregister_print_function(tep, yes_no_helper, "yesno") != 0) {
                /* Falló la anulación del registro de la función yes_no_helper */
        }

ARCHIVOS

event-parse.h
        Archivo de cabecera para incluir con el fin de tener acceso a las APIs
        de la biblioteca.
trace-seq.h
        Archivo de cabecera para incluir con el fin de tener acceso a las APIs
        relacionadas con las secuencias de traza. Las secuencias de traza se
        usan para permitir que una función llame a varias otras funciones para
        crear una cadena de datos a usar.
-ltraceevent
        Opción del enlazador para agregar al compilar un programa que usa la
        biblioteca.
