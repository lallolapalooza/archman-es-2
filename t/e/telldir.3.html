telldir(3) Manual de funciones de biblioteca telldir(3)

NOMBRE

telldir - devuelve la ubicación actual en el flujo del directorio

BIBLIOTECA

Biblioteca estándar C (libc, -lc)

SINOPSIS

#include <dirent.h>
long telldir(DIR *dirp);
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

telldir():

    _XOPEN_SOURCE
       || /* glibc >= 2.19: */ _DEFAULT_SOURCE
       || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

La función telldir() devuelve la ubicación actual asociada con el flujo del directorio dirp.

VALOR DE RETORNO

En caso de éxito, la función telldir() devuelve la ubicación actual en el flujo del directorio. En caso de error, se devuelve -1 y se establece errno para indicar el error.

ERRORES

EBADF
Descriptor de flujo de directorio inválido dirp.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
telldir () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001, 4.3BSD.

Hasta glibc 2.1.1, el tipo de retorno de telldir() era off_t. POSIX.1-2001 especifica long, y este es el tipo utilizado desde glibc 2.1.2.

En los primeros sistemas de archivos, el valor devuelto por telldir() era un simple desplazamiento de archivo dentro de un directorio. Los sistemas de archivos modernos utilizan estructuras de árbol o hash, en lugar de tablas planas, para representar directorios. En tales sistemas de archivos, el valor devuelto por telldir() (y utilizado internamente por readdir(3)) es una "cookie" que se utiliza en la implementación para derivar una posición dentro de un directorio. Los programas de aplicación deben tratar esto estrictamente como un valor opaco, sin hacer ninguna suposición sobre su contenido.

VER TAMBIÉN

closedir(3), opendir(3), readdir(3), rewinddir(3), scandir(3), seekdir(3)
