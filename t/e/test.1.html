TEST(1) Comandos de usuario TEST(1)

NOMBRE

test - comprueba tipos de archivo y compara valores

SINOPSIS

test EXPRESION
test
[ EXPRESION ]
[ ]
[ OPCION

DESCRIPCIÓN

Sale con el estado determinado por EXPRESION. False por defecto si se omite EXPRESION.

--help
muestra esta ayuda y sale
--version
muestra información de versión y sale

Si no, EXPRESION es verdadera o falsa y establece el estado de salida. Es una de las siguientes opciones:

( EXPRESION )
EXPRESION es verdadera
! EXPRESION
EXPRESION es falsa
EXPRESION1 -a EXPRESION2
ambas EXPRESION1 y EXPRESION2 son verdaderas
EXPRESION1 -o EXPRESION2
o EXPRESION1 o EXPRESION2 es verdadera
-n CADENA
la longitud de CADENA es distinta de cero
CADENA
equivalente a -n CADENA
-z CADENA
la longitud de CADENA es cero
CADENA1 = CADENA2
las cadenas son iguales
CADENA1 != CADENA2
las cadenas no son iguales
CADENA1 > CADENA2
CADENA1 es mayor que CADENA2 en la configuración regional actual
CADENA1 < CADENA2
CADENA1 es menor que CADENA2 en la configuración regional actual
ENTERO1 -eq ENTERO2
ENTERO1 es igual a ENTERO2
ENTERO1 -ge ENTERO2
ENTERO1 es mayor o igual a ENTERO2
ENTERO1 -gt ENTERO2
ENTERO1 es mayor que ENTERO2
ENTERO1 -le ENTERO2
ENTERO1 es menor o igual a ENTERO2
ENTERO1 -lt ENTERO2
ENTERO1 es menor que ENTERO2
ENTERO1 -ne ENTERO2
ENTERO1 no es igual a ENTERO2
ARCHIVO1 -ef ARCHIVO2
ARCHIVO1 y ARCHIVO2 tienen el mismo número de dispositivo e inodo
ARCHIVO1 -nt ARCHIVO2
ARCHIVO1 es más reciente (fecha de modificación) que ARCHIVO2
ARCHIVO1 -ot ARCHIVO2
ARCHIVO1 es más antiguo que ARCHIVO2
-b ARCHIVO
ARCHIVO existe y es especial de bloque
-c ARCHIVO
ARCHIVO existe y es especial de carácter
-d ARCHIVO
ARCHIVO existe y es un directorio
-e ARCHIVO
ARCHIVO existe
-f ARCHIVO
ARCHIVO existe y es un archivo regular
-g ARCHIVO
ARCHIVO existe y tiene el bit set-group-ID activado
-G ARCHIVO
ARCHIVO existe y es propiedad del grupo efectivo
-h ARCHIVO
ARCHIVO existe y es un enlace simbólico (igual que -L)
-k ARCHIVO
ARCHIVO existe y tiene el sticky bit activado
-L ARCHIVO
ARCHIVO existe y es un enlace simbólico (igual que -h)
-N ARCHIVO
ARCHIVO existe y ha sido modificado desde la última vez que se leyó
-O ARCHIVO
ARCHIVO existe y es propiedad del usuario efectivo
-p ARCHIVO
ARCHIVO existe y es una tubería con nombre (FIFO)
-r ARCHIVO
ARCHIVO existe y el usuario tiene permiso de lectura
-s ARCHIVO
ARCHIVO existe y tiene un tamaño mayor que cero
-S ARCHIVO
ARCHIVO existe y es un socket
-t FD
el descriptor de archivo FD está abierto en una terminal
-u ARCHIVO
ARCHIVO existe y su bit set-user-ID está activado
-w ARCHIVO
ARCHIVO existe y el usuario tiene permiso de escritura
-x ARCHIVO
ARCHIVO existe y el usuario tiene permiso de ejecución (o búsqueda)

Excepto para -h y -L, todas las pruebas relacionadas con ARCHIVO desreferencian los enlaces simbólicos. Tenga cuidado, ya que los paréntesis necesitan ser escapados (por ejemplo, con barras invertidas) para los shells. ENTERO también puede ser -l CADENA, que se evalúa a la longitud de CADENA.

Los binarios -a y -o son ambiguos. Use 'test EXPR1 && test EXPR2' o 'test EXPR1 || test EXPR2' en su lugar.

`[' honra --help y --version, pero `test` los trata como CADENAS.

Su shell puede tener su propia versión de test y/o [, que normalmente sustituye a la versión descrita aquí. Consulte la documentación de su shell para obtener detalles sobre las opciones que admite.

test(1)

USER COMMANDS

NAME

test - check if file exists or is readable, or compare strings or numbers

SYNOPSIS

test EXPRESS
[ EXPRESS ]

DESCRIPTION

test evaluates EXPRESS and exits with a status of 0 if EXPRESS is true and with a status of 1 if EXPRESS is false.
The [ command is a synonym for test, but it is often useful to include spacing around the brackets.
See also help test or one of the test(1) man pages for details.
