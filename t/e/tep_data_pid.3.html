tep_data_pid(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_data_type, tep_data_pid, tep_data_preempt_count, tep_data_flags - Extraer campos comunes de un registro.

SINOPSIS

#include <event-parse.h>
enum trace_flag_type {
        TRACE_FLAG_IRQS_OFF,
        TRACE_FLAG_IRQS_NOSUPPORT,
        TRACE_FLAG_NEED_RESCHED,
        TRACE_FLAG_HARDIRQ,
        TRACE_FLAG_SOFTIRQ,
};
int tep_data_type(struct tep_handle *tep, struct tep_record *rec);
int tep_data_pid(struct tep_handle *tep, struct tep_record *rec);
int tep_data_preempt_count(struct tep_handle *tep, struct tep_record *rec);
int tep_data_flags(struct tep_handle *tep, struct tep_record *rec);

DESCRIPCIÓN

Este conjunto de funciones se puede utilizar para extraer campos comunes de un registro.

La función tep_data_type() obtiene el ID del evento del registro rec. Lee el campo "common_type". El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_data_pid() obtiene el ID del proceso del registro rec. Lee el campo "common_pid". El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_data_preempt_count() obtiene la cuenta de preemption del registro rec. Lee el campo "common_preempt_count". El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_data_flags() obtiene las banderas de latencia del registro rec. Lee el campo "common_flags". El argumento tep es el contexto del analizador de eventos de rastreo. Las banderas de latencia soportadas son:

        TRACE_FLAG_IRQS_OFF,          Interrupciones deshabilitadas.
        TRACE_FLAG_IRQS_NOSUPPORT,    La lectura de la bandera IRQ no es soportada por la arquitectura.
        TRACE_FLAG_NEED_RESCHED,      La tarea necesita ser reprogramada.
        TRACE_FLAG_HARDIRQ,           Ejecutando IRQ duro.
        TRACE_FLAG_SOFTIRQ,           Ejecutando IRQ suave.

VALOR DE RETORNO

La función tep_data_type() devuelve un entero, representando el ID del evento.

La función tep_data_pid() devuelve un entero, representando el ID del proceso.

La función tep_data_preempt_count() devuelve un entero, representando la cuenta de preemption.

La función tep_data_flags() devuelve un entero, representando las banderas de latencia. Consulte la enumeración trace_flag_type para ver las banderas soportadas.

Todas estas funciones devuelven un entero negativo en caso de error.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
void process_record(struct tep_record *record)
{
        int data;
        data = tep_data_type(tep, record);
        if (data >= 0) {
                /* Se obtuvo el ID del evento */
        }
        data = tep_data_pid(tep, record);
        if (data >= 0) {
                /* Se obtuvo el ID del proceso */
        }
        data = tep_data_preempt_count(tep, record);
        if (data >= 0) {
                /* Se obtuvo la cuenta de preemption */
        }
        data = tep_data_flags(tep, record);
        if (data >= 0) {
                /* Se obtuvieron las banderas de latencia */
        }
}
...
