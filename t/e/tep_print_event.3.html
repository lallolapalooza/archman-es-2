tep_print_event(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_print_event - Escribe información de eventos en una secuencia de traza.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_event(struct tep_handle *tep, struct trace_seq*s, struct tep_record *record, const char *fmt, ...)

DESCRIPCIÓN

La función tep_print_event() analiza la información del evento del record dado y la escribe en la secuencia de traza s, de acuerdo con la cadena de formato fmt. La información deseada se especifica después de la cadena de formato. El fmt es una cadena de formato similar a printf, se admiten los siguientes argumentos:

        TEP_PRINT_PID, "%d"  - PID del evento.
        TEP_PRINT_CPU, "%d"  - CPU del evento.
        TEP_PRINT_COMM, "%s" - Cadena de comando del evento.
        TEP_PRINT_NAME, "%s" - Nombre del evento.
        TEP_PRINT_LATENCY, "%s" - Latencia del evento. Imprime 4 o más
                        campos - estado de interrupción, estado de planificación,
                        contexto actual y recuento de preempciones.
                        El campo 1 es el estado de interrupciones habilitadas:
                                d : Las interrupciones están deshabilitadas
                                . : Las interrupciones están habilitadas
                                X : La arquitectura no soporta esta
                                    información
                        El campo 2 es el estado de "necesita replanificar".
                                N : La tarea está configurada para llamar al planificador cuando
                                    sea posible, ya que es posible que sea necesario planificar otra tarea de mayor prioridad.
                                . : La tarea no está configurada para llamar al planificador.
                        El campo 3 es el estado del contexto.
                                . : Contexto normal
                                s : Contexto de interrupción suave
                                h : Contexto de interrupción fuerte
                                H : Contexto de interrupción fuerte que se activó
                                    durante el contexto de interrupción suave.
                                z : Contexto NMI
                                Z : Contexto NMI que se activó durante el contexto de
                                    interrupción fuerte
                        El campo 4 es el recuento de preempciones.
                                . : El recuento de preempciones es cero.
                        En kernels preemptibles (donde la tarea puede ser desplanificada en ubicaciones arbitrarias mientras está en contexto de kernel), el
                        recuento de preempciones, cuando no es cero, evitará que el kernel
                        desplanifique la tarea actual. Se muestra el número del recuento de
                        preempciones cuando no es cero.
                        Dependiendo del kernel, puede mostrar otros campos
                        (profundidad de bloqueo o migración deshabilitada, que son exclusivos de
                        kernels especializados).
        TEP_PRINT_TIME, %d - marca de tiempo del evento. Se puede especificar un divisor y una precisión
                        como parte de esta cadena de formato:
                        "%precision.divisord". Ejemplo:
                        "%3.1000d" - divide el tiempo por 1000 e imprime los primeros
                        3 dígitos antes del punto. Por lo tanto, la marca de tiempo
                        "123456000" se imprimirá como "123.456"
        TEP_PRINT_INFO, "%s" - información del evento.
        TEP_PRINT_INFO_RAW, "%s" - información del evento, en formato crudo.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct trace_seq seq;
trace_seq_init(&seq);
struct tep_handle *tep = tep_alloc();
...
void print_my_event(struct tep_record *record)
{
        trace_seq_reset(&seq);
        tep_print_event(tep, s, record, "%16s-%-5d [%03d] %s %6.1000d %s %s",
                        TEP_PRINT_COMM, TEP_PRINT_PID, TEP_PRINT_CPU,
                        TEP_PRINT_LATENCY, TEP_PRINT_TIME, TEP_PRINT_NAME,
                        TEP_PRINT_INFO);
}
...

ARCHIVOS

event-parse.h
        Archivo de encabezado para incluir con el fin de tener acceso a las API de la biblioteca.
trace-seq.h
        Archivo de encabezado para incluir con el fin de tener acceso a las API relacionadas con secuencias de traza.
        Las secuencias de traza se utilizan para permitir que una función llame a varias otras funciones
        para crear una cadena de datos para usar.
-ltraceevent
        Interruptor del enlazador para añadir al compilar un programa que utiliza la biblioteca.
