TELNET(1) Comandos de usuario TELNET(1)

NOMBRE

telnet - Interfaz de usuario para TELNET

SINOPSIS

telnet [OPCIÓN...] [HOST [PUERTO]]

DESCRIPCIÓN

Inicia sesión en el sistema remoto HOST (opcionalmente, en el puerto de servicio PUERTO)

Opciones generales:
-4, --ipv4
usar solo IPv4
-6, --ipv6
usar solo IPv6
-8, --binary
usar una transmisión de datos de 8 bits
-a, --login
intentar inicio de sesión automático
-b, --bind=DIRECCION
enlazar con la DIRECCION local específica
-c, --no-rc
no leer el archivo .telnetrc del usuario
-d, --debug
activar depuración
-e, --escape=CARACTER
usar CARACTER como carácter de escape
-E, --no-escape
no usar carácter de escape
-K, --no-login
no iniciar sesión automáticamente en el sistema remoto
-l, --user=USUARIO
intentar inicio de sesión automático como USUARIO
-L, --binary-output
usar una transmisión de datos de 8 bits solo para salida
-n, --trace=ARCHIVO
registrar información de rastreo en ARCHIVO
-r, --rlogin
usar una interfaz de usuario similar a rlogin
-?, --help
mostrar esta lista de ayuda
--usage
mostrar un breve mensaje de uso
-V, --version
imprimir la versión del programa

Los argumentos obligatorios u opcionales para las opciones largas también son obligatorios u opcionales para sus correspondientes opciones cortas.
