texexec(1) TeXExec texexec(1)

NOMBRE


texexec - TeXExec

SINOPSIS

texexec [ OPCIONES ... ] [ NOMBRES_DE_ARCHIVOS ]

DESCRIPCIÓN

TeXExec

OPCIONES

--make
crear formatos
--check
verificar versiones
--process
procesar archivo
--mptex
procesar archivo mp
--mpxtex
procesar archivo mpx
--mpgraphic
procesar archivo mp a gráficos independientes
--mpstatic
procesar archivo mp/ctx a gráficos independientes
--listing
lista del contenido del archivo
--figures
generar resumen de figuras
--modules
generar documentación de módulos
--pdfarrange
imponer páginas (folletos)
--pdfselect
seleccionar páginas de archivo(s)
--pdfcopy
copiar páginas de archivo(s)
--pdftrim
recortar páginas de archivo(s)
--pdfcombine
combinar múltiples páginas
--pdfsplit
dividir archivo en páginas
