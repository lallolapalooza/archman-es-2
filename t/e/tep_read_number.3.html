tep_read_number(3)

Paquete: libtraceevent

NOMBRE

tep_read_number - Lee un número de datos brutos.

SINOPSIS

#include <event-parse.h>
unsigned long long tep_read_number(struct tep_handle *tep, const void *ptr, int size);

DESCRIPCIÓN

La función tep_read_number() lee un entero de datos brutos, teniendo en cuenta el orden de bytes de los datos brutos y del host actual. El argumento tep es el contexto del analizador de eventos de traza. ptr es un puntero a los datos brutos, donde se encuentra el entero, y size es el tamaño del entero.

VALOR DE RETORNO

La función tep_read_number() devuelve el entero en el orden de bytes del host actual. En caso de error, se devuelve 0.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
void process_record(struct tep_record *record)
{
        int offset = 24;
        int data = tep_read_number(tep, record->data + offset, 4);
        /* Lee los 4 bytes en el offset 24 de data como un entero */
}
