tep_unregister_event_handler(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_register_event_handler, tep_unregister_event_handler - Registrar / desregistrar una función de callback para analizar información de eventos.

SINOPSIS

#include <event-parse.h>
enum tep_reg_handler {
        TEP_REGISTER_SUCCESS,
        TEP_REGISTER_SUCCESS_OVERWRITE,
};
int tep_register_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
int tep_unregister_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
typedef int (*tep_event_handler_func)(struct trace_seq *s, struct tep_record *record, struct tep_event *event, void *context);

DESCRIPCIÓN

La función tep_register_event_handler() registra una función manejadora (handler), que será llamada para analizar la información de un evento dado. El argumento tep es el contexto del analizador de eventos de traza. El argumento id es el ID del evento. El argumento sys_name es el nombre del sistema al que pertenece el evento. El argumento event_name es el nombre del evento. Si id es >= 0, se usa para encontrar el evento, de lo contrario se usan sys_name y event_name. El argumento func es un puntero a la función que será llamada para analizar la información del evento. El argumento context es un puntero a los datos de contexto, que se pasarán a func. Si ya hay una función manejadora registrada para el mismo evento, será sobrescrita por la nueva. Este mecanismo permite a un desarrollador sobrescribir el análisis de un evento dado. Si por alguna razón el formato de impresión predeterminado no es suficiente, el desarrollador puede registrar una función para un evento que se usará para analizar los datos en su lugar.

La función tep_unregister_event_handler() desregistra la función manejadora, previamente registrada con tep_register_event_handler(). El argumento tep es el contexto del analizador de eventos de traza. Los argumentos id, sys_name, event_name, func y context son los mismos argumentos que cuando se registró la función de callback func.

tep_event_handler_func es el tipo de la función manejadora de eventos personalizada. El argumento s es la secuencia de traza, se puede usar para crear una cadena personalizada que describa el evento. Se pasa un record para obtener el evento como parámetro de entrada y también el event, el manejador del evento del registro. El context es un contexto personalizado, establecido cuando se registró el manejador de eventos personalizado.

VALOR DE RETORNO

La función tep_register_event_handler() devuelve TEP_REGISTER_SUCCESS si el nuevo manejador se registra exitosamente o TEP_REGISTER_SUCCESS_OVERWRITE si se sobrescribe un manejador existente. Si no hay suficiente memoria para completar el registro, se devuelve TEP_ERRNO__MEM_ALLOC_FAILED.

La función tep_unregister_event_handler() devuelve 0 si func se eliminó correctamente o -1 si no se encontró el evento.

La función tep_event_handler_func debería devolver -1 en caso de error, o 0 en caso contrario.

    tep_unregister_event_handler.3

    NAME

    tep_unregister_event_handler - Unregister an event handler for a specific event.

    SYNOPSIS

    #include <tep.h>

    void tep_unregister_event_handler(tep_event_handler_t handler);

    DESCRIPTION

    The tep_unregister_event_handler function removes an previously registered event handler. The handler function pointer passed must match one that was previously registered with tep_register_event_handler.

    PARAMETERS

    handler

    A pointer to the event handler function to be unregistered.

    RETURN VALUE

    This function does not return a value.

    EXAMPLE

    #include <stdio.h>
#include <tep.h>

static void my_event_handler(tep_event_t *event, void *data) {
    printf("Event received: %s\n", tep_event_name(event));
}

int main() {
    tep_event_t *event;

    // Register the event handler
    tep_register_event_handler(my_event_handler);

    // ... (code that might trigger events) ...

    // Unregister the event handler
    tep_unregister_event_handler(my_event_handler);

    return 0;
}
