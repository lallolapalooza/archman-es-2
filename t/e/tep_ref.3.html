LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_alloc, tep_free, tep_ref, tep_unref, tep_get_ref, tep_kbuffer - Crear, destruir, gestionar referencias del contexto del analizador de eventos de traza.

SINOPSIS

#include <event-parse.h>
struct tep_handle *tep_alloc(void);
void tep_free(struct tep_handle *tep);
void tep_ref(struct tep_handle *tep);
void tep_unref(struct tep_handle *tep);
int tep_get_ref(struct tep_handle *tep);
struct kbuffer *tep_kbuffer(struct tep_handle *tep);

DESCRIPCIÓN

Estas son las funciones principales para crear y destruir tep_handle, la estructura principal que representa el contexto del analizador de eventos de traza. Este contexto se utiliza como parámetro de entrada de la mayoría de las APIs de la biblioteca.

La función tep_alloc() asigna e inicializa el contexto tep.

La función tep_free() decrementa la referencia del manejador tep. Cuando no quedan más referencias, libera el manejador, así como todos sus recursos asociados. El argumento tep es el puntero al contexto del analizador de eventos de traza.

La función tep_ref() añade una referencia al manejador tep.

La función tep_unref() elimina una referencia del manejador tep. Cuando se elimina la última referencia, se destruye tep y se liberan todos los recursos que utilizaba.

La función tep_ref_get() obtiene las referencias actuales del manejador tep.

La función tep_kbuffer() asigna un descriptor kbuffer que puede ser utilizado para analizar datos brutos representados por el manejador tep. Debe liberarse con kbuf_free(3).

VALOR DE RETORNO

tep_alloc() devuelve un puntero a una estructura tep_handle recién creada. Devuelve NULL en caso de que no haya suficiente memoria libre para asignarla.

tep_ref_get() devuelve las referencias actuales de tep. Si tep es NULL, se devuelve 0.

tep_kbuffer() devuelve un descriptor kbuffer que puede analizar los datos brutos que representan el manejador tep. Debe liberarse con kbuf_free(3).

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int ref = tep_get_ref(tep);
tep_ref(tep);
if ( (ref+1) != tep_get_ref(tep)) {
        /* Algo salió mal, el contador no se incrementó en 1 */
}
tep_unref(tep);
...
tep_free(tep);
...
