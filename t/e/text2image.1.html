TEXT2IMAGE(1)   TEXT2IMAGE(1)

NOMBRE

text2image - genera páginas de entrenamiento OCR.

SINOPSIS

text2image --text ARCHIVO --outputbase RUTA --fonts_dir RUTA [OPCIÓN]

DESCRIPCIÓN

text2image(1) genera páginas de entrenamiento OCR. Dado un archivo de texto, produce una imagen con una fuente y degradación dadas.

OPCIONES

--text ARCHIVO

Nombre del archivo de texto de entrada a utilizar para crear datos de entrenamiento sintéticos. (tipo:cadena valor por defecto:)

--outputbase ARCHIVO

Nombre base para el archivo de imagen/caja de salida (tipo:cadena valor por defecto:)

--fontconfig_tmpdir RUTA

Anula el directorio temporal predeterminado de fontconfig (tipo:cadena valor por defecto:/tmp)

--fonts_dir RUTA

Si está vacío, utiliza el predeterminado del sistema. De lo contrario, anula la ubicación de fuentes predeterminada del sistema (tipo:cadena valor por defecto:)

--font NOMBRE_DE_FUENTE

Nombre de descripción de la fuente a utilizar (tipo:cadena valor por defecto:Arial)

--writing_mode MODO

Especifica uno de los siguientes modos de escritura. horizontal : Renderiza texto horizontal normal. (predeterminado) vertical : Renderiza texto vertical. La orientación de los glifos la selecciona Pango. vertical-upright : Renderiza texto vertical. La orientación de los glifos se establece para que sea vertical. (tipo:cadena valor por defecto:horizontal)

--tlog_level INT

Nivel mínimo de registro para la salida de tlog() (tipo:entero valor por defecto:0)

--max_pages INT

Número máximo de páginas a generar (0=ilimitado) (tipo:entero valor por defecto:0)

--degrade_image BOOL

Degrada la imagen renderizada con ruido de sal y pimienta, dilatación/erosión y rotación (tipo:booleano valor por defecto:true)

--rotate_image BOOL

Rota la imagen de forma aleatoria. (tipo:booleano valor por defecto:true)

--strip_unrenderable_words BOOL

Elimina palabras no renderizables del texto fuente (tipo:booleano valor por defecto:true)

--ligatures BOOL

Reconstruye y renderiza ligaduras (tipo:booleano valor por defecto:false)

--exposure INT

Nivel de exposición en fotocopiadora (tipo:entero valor por defecto:0)

--resolution INT

Píxeles por pulgada (tipo:entero valor por defecto:300)

--xsize INT

Ancho de la imagen de salida (tipo:entero valor por defecto:3600)

--ysize INT

Alto de la imagen de salida (tipo:entero valor por defecto:4800)

--margin INT

Margen alrededor de los bordes de la imagen (tipo:entero valor por defecto:100)

--ptsize INT

Tamaño del texto impreso (tipo:entero valor por defecto:12)

--leading INT

Espacio entre líneas (en píxeles) (tipo:entero valor por defecto:12)

--box_padding INT

Relleno alrededor de las cajas delimitadoras producidas (tipo:entero valor por defecto:0)

--char_spacing DOBLE

Espacio entre caracteres en ems (tipo:doble valor por defecto:0)

--underline_start_prob DOBLE

Fracción de palabras a subrayar (valor en [0,1]) (tipo:doble valor por defecto:0)

--underline_continuation_prob DOBLE

Fracción de palabras a subrayar (valor en [0,1]) (tipo:doble valor por defecto:0)

--render_ngrams BOOL

Coloca cada entidad separada por espacios del archivo de entrada en una sola caja delimitadora. Los n-gramas del archivo de entrada se permutarán aleatoriamente (para que haya suficiente variedad de caracteres en cada línea) antes de renderizarlos (tipo:booleano valor por defecto:false)

--output_word_boxes BOOL

Genera cajas delimitadoras de palabras en lugar de caracteres. Esto se utiliza para el entrenamiento de Cube y se implica con --render_ngrams. (tipo:booleano valor por defecto:false)

--unicharset_file ARCHIVO

Archivo con los caracteres en el unicharset. Si --render_ngrams es verdadero y --unicharset_file está especificado, se omitirán los n-gramas con caracteres que no estén en el unicharset (tipo:cadena valor por defecto:)

--bidirectional_rotation BOOL

Rota los caracteres generados en ambas direcciones. (tipo:booleano valor por defecto:false)

--only_extract_font_properties BOOL

Asume que el archivo de entrada contiene una lista de n-gramas. Renderiza cada n-grama, extrae propiedades de espaciado y las registra en output_base/[font_name].fontinfo (tipo:booleano valor por defecto:false)

UTILIZA ESTAS BANDERAS PARA PRODUCIR IMÁGENES DE CARACTERES INDIVIDUALES RELLENADAS CON CEROS Y CUADRADAS

--output_individual_glyph_images BOOL

Si es verdadero, también genera imágenes de caracteres individuales (tipo:booleano valor por defecto:false)

--glyph_resized_size INT

Cada glifo es cuadrado con esta longitud de lado en píxeles (tipo:entero valor por defecto:0)

--glyph_num_border_pixels_to_pad INT

Tamaño_final=glyph_resized_size+2*glyph_num_border_pixels_to_pad (tipo:entero valor por defecto:0)

UTILIZA ESTAS BANDERAS PARA ENCONTRAR FUENTES QUE PUEDAN RENDERIZAR UN TEXTO DADO

--find_fonts BOOL

Busca todas las fuentes que puedan renderizar el texto (tipo:booleano valor por defecto:false)

--render_per_font BOOL

Si find_fonts==verdadero, renderiza cada fuente a su propia imagen. Los nombres de archivo de imagen tienen el formato output_name.font_name.tif (tipo:booleano valor por defecto:true)

--min_coverage DOBLE

Si find_fonts==verdadero, la cobertura mínima que tiene la fuente de los caracteres en el archivo de texto para incluirla, entre 0 y 1. (tipo:doble valor por defecto:1)

Ejemplo de uso: ``` text2image --find_fonts \ --fonts_dir /usr/share/fonts \ --text ../langdata/hin/hin.training_text \ --min_coverage .9 \ --render_per_font \ --outputbase ../langdata/hin/hin \ |& grep raw | sed -e s/ :.*/" \\/g | sed -e s/^/ "/ >../langdata/hin/fontslist.txt ```

OPCIONES ÚNICAS

--list_available_fonts BOOL

Lista las fuentes disponibles y sale. (tipo:booleano valor por defecto:false)

HISTORIAL

text2image(1) estuvo disponible por primera vez para tesseract 3.03.
