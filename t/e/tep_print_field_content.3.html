tep_print_field_content(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_print_field_content, tep_print_fields, tep_print_num_field, tep_print_func_field, tep_record_print_fields, tep_record_print_selected_fields - Imprimir el contenido de un campo.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_field_content(struct trace_seq *s, void *data, int size, struct tep_format_field *field);
void tep_print_fields(struct trace_seq *s, void *data, int size, struct tep_event *event);
int tep_print_num_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
int tep_print_func_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
void tep_record_print_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event);
void tep_record_print_selected_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event, int select_mask);

DESCRIPCIÓN

Estas funciones imprimen los datos del campo registrado, de acuerdo con el tipo de campo.

La función tep_print_field_content() extrae del valor crudo registrado data del field y lo imprime en s, de acuerdo con el tipo de campo.

La función tep_print_fields() imprime el nombre de cada campo seguido del valor del campo del registro de acuerdo con el tipo de campo:

"nombre_campo1=valor_campo1 nombre_campo2=valor_campo2 ..."

Itera sobre todos los campos del event y llama a tep_print_field_content() para cada uno de ellos.

La función tep_print_num_field() imprime un campo numérico con una cadena de formato dada. Se realiza una búsqueda en el event para un campo con el name. Si se encuentra dicho campo, su valor se extrae del record y se imprime en s, de acuerdo con la cadena de formato dada fmt. Si el argumento err no es cero, y ocurre un error, se imprime en s.

La función tep_print_func_field() imprime un campo de función con una cadena de formato dada. Se realiza una búsqueda en el event para un campo con el name. Si se encuentra dicho campo, su valor se extrae del record. Se asume que el valor es una dirección de función, y se realiza una búsqueda para encontrar el nombre de esta función. El nombre de la función (si se encuentra) y su dirección se imprimen en s, de acuerdo con la cadena de formato dada fmt. Si el argumento err no es cero, y ocurre un error, se imprime en s.

La función tep_record_print_fields() imprime el nombre del campo seguido de su valor para todos los campos del registro.

La función tep_record_print_selected_fields() imprime el nombre del campo seguido de su valor para un subconjunto seleccionado de campos del registro. Los campos a imprimir se definen por la máscara de bits select_mask.

VALOR DE RETORNO

Las funciones tep_print_num_field() y tep_print_func_field() devuelven 1 en caso de éxito, -1 en caso de error o 0 si el búfer de impresión s está lleno.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
struct trace_seq seq;
trace_seq_init(&seq);
struct tep_event *event = tep_find_event_by_name(tep, "timer", "hrtimer_start");
...
void process_record(struct tep_record *record)
{
        struct tep_format_field *field_pid = tep_find_common_field(event, "common_pid");
        trace_seq_reset(&seq);
        /* Imprimir el valor de "common_pid" */
        tep_print_field_content(&seq, record->data, record->size, field_pid);
        /* Imprimir todos los campos del evento "hrtimer_start" */
        tep_print_fields(&seq, record->data, record->size, event);
        /* Imprimir el valor del campo "expires" con una cadena de formato personalizada */
        tep_print_num_field(&seq, " el temporizador expira en %llu ", event, "expires", record, 0);
        /* Imprimir la dirección y el nombre del campo "function" con una cadena de formato personalizada */
        tep_print_func_field(&seq, " la función del temporizador es %s ", event, "function", record, 0);
 }
 ...

ARCHIVOS

event-parse.h
        Archivo de cabecera para incluir con el fin de tener acceso a las API de la biblioteca.
trace-seq.h
        Archivo de cabecera para incluir con el fin de tener acceso a las API relacionadas con secuencias de rastreo.
        Las secuencias de rastreo se utilizan para permitir que una función llame a varias otras funciones
        para crear una cadena de datos para usar.
-ltraceevent
        Opción del enlazador para añadir al compilar un programa que utiliza la biblioteca.
