termkey_interpret_string(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_INTERPRET_STRING(3) Manual de funciones de biblioteca TERMKEY_INTERPRET_STRING(3)

NOMBRE

termkey_interpret_string - obtener cadena almacenada

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_interpret_string(TermKey *tk, const TermKeyKey *key, 
    const char **strp);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_interpret_string() obtiene la cadena almacenada en la instancia TermKey del evento más reciente de tipo TERMKEY_TYPE_DCS o TERMKEY_TYPE_OSC. Tenga en cuenta que es importante llamar a esta función tan pronto como sea posible después de obtener uno de estos eventos de clave de cadena; específicamente, antes de volver a llamar a termkey_getkey() o termkey_waitkey(), ya que una llamada posterior sobrescribirá el espacio del búfer que contiene actualmente esta cadena.

El puntero de cadena cuya dirección se proporciona en strp se establecerá para apuntar a la cadena almacenada real en la instancia. El llamante es libre de leer esta cadena (que estará correctamente terminada en NUL), pero no debe modificarla. No es necesario llamar a free() para el puntero; la instancia TermKey contenedora se encargará de ello.

VALOR DE RETORNO

Si se le pasa el evento key más reciente de tipo TERMKEY_TYPE_DCS o TERMKEY_TYPE_OSC, esta función devolverá TERMKEY_RES_KEY y afectará a las variables cuyos punteros se pasaron, como se describe anteriormente.

Para otros tipos de eventos, o eventos obsoletos, devolverá TERMKEY_RES_NONE, y sus efectos en cualquier variable cuyos punteros se pasaron no están definidos.

VER TAMBIÉN

termkey_waitkey(3), termkey_getkey(3), termkey(7)
