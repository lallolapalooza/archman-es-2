TEXDOC(1) Manual de Texdoc TEXDOC(1)

NOMBRE

texdoc - encontrar y ver documentación en TeX Live

SINOPSIS

texdoc [OPCIÓN]... NOMBRE...
texdoc [OPCIÓN]... ACCIÓN

DESCRIPCIÓN

Intenta encontrar la documentación de TeX adecuada para los NOMBRE(s) especificados. Alternativamente, realiza la ACCIÓN dada y sale.

OPCIONES

-w, --ver
Usar modo de vista: inicia un visor. (predeterminado)
-m, --mixto
Usar modo mixto (ver o listar).
-l, --listar
Usar modo de lista: muestra una lista de resultados.
-s, --mostrar-todo
Usar modo mostrar-todo: muestra también resultados "malos".
-i, --interactivo
Usar menús interactivos. (predeterminado)
-I, --no-interactivo
Usar listas simples, no se requiere interacción.
-M, --maquina
Salida legible por máquina para listas (implica -I).
-q, --silencioso
Suprime advertencias y la mayoría de los mensajes de error.
-v, --detallado
Imprime información adicional (por ejemplo, comando del visor).
-D, --depurar
Activa toda la salida de depuración (equivalente a "--depurar=todo").
-d LISTA, --depurar=LISTA
Activa la salida de depuración restringida a las categorías especificadas en LISTA.
Categorías disponibles: config, archivos, busqueda, archivodocumento, puntuacion, documentostex, tlpdb, version, ver, y todo para activar todas estas.
-c NOMBRE=VALOR
Establece el elemento de configuración NOMBRE a VALOR.

ACCIONES

-h, --ayuda
Imprime este mensaje de ayuda.
-V, --version
Imprime el número de versión.
-f, --archivos
Imprime la lista de archivos de configuración utilizados.
--solo-ver ARCHIVO
Muestra ARCHIVO, dado con ruta completa (sin buscar).
--imprimir-completado SHELL
Imprime completado para SHELL.

ENTORNO

Las siguientes variables de entorno se pueden dividir por dos puntos y utilizar para establecer visores:

BROWSER, BROWSER_texdoc
Establece el comando que se utilizará para documentos HTML.
DVIVIEWER, DVIVIEWER_texdoc
Establece el comando que se utilizará para documentos DVI.
MDVIEWER, MDVIEWER_texdoc
Establece el comando que se utilizará para documentos Markdown.
PAGER, PAGER_texdoc
Establece el comando que se utilizará para documentos de texto.
PDFVIEWER, PDFVIEWER_texdoc
Establece el comando que se utilizará para documentos PDF.
PSVIEWER, PSVIEWER_texdoc
Establece el comando que se utilizará para documentos PS.

Las siguientes variables de entorno también se utilizan:

LANG, LC_ALL, LANGUAGE, LANGUAGE_texdoc
Establece la configuración regional, que influirá en los resultados de la búsqueda.
TEXDOCS
Además de los documentos incluidos en la base de datos de TeX Live, Texdoc también busca documentación en los árboles TEXMF especificados por la variable kpathsea TEXDOCS.

ARCHIVOS

<texmf>/texdoc/texdoc.cnf, ver la salida de la opción --archivos.

ESTADO DE SALIDA

El comando texdoc sale con uno de los siguientes valores:

0
Éxito.
1
Error interno.
2
Error de uso.
3
No se encontró documentación.
