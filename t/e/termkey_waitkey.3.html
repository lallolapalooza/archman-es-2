termkey_waitkey(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_WAITKEY(3) Manual de Funciones de Biblioteca TERMKEY_WAITKEY(3)

NOMBRE

termkey_waitkey - esperar y recuperar el siguiente evento de tecla

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_waitkey(TermKey *tk, TermKeyKey *key);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_waitkey() intenta recuperar un solo evento de pulsación de tecla del búfer de la instancia de termkey(7), y ponerlo en la estructura referenciada por key. Si tiene éxito, devolverá TERMKEY_RES_KEY para indicar que la estructura ahora contiene un nuevo evento de pulsación de tecla. Si no hay nada en el búfer, se bloqueará hasta que uno esté disponible. Si no hay eventos listos y el flujo de entrada está ahora cerrado, devolverá TERMKEY_RES_EOF. Si no hay ningún descriptor de archivo asociado con esta instancia, se devolverá TERMKEY_RES_ERROR con errno establecido a EBADF.

Antes de devolver, esta función canonicaliza la estructura key de acuerdo con las reglas dadas para termkey_canonicalise(3).

Algunas pulsaciones de teclas generan múltiples bytes desde la terminal. Dado que puede haber retrasos de red u otros entre la terminal y una aplicación que utiliza termkey, termkey_waitkey() intentará esperar a que lleguen los bytes restantes si detecta el inicio de una secuencia multibyte. Si no llegan más bytes dentro de un tiempo determinado, los bytes se informarán tal como están, incluso si esto resulta en la interpretación de una secuencia de escape parcialmente completa como una tecla Escape literal seguida de algunas letras normales u otros símbolos. La cantidad de tiempo de espera se puede establecer mediante termkey_set_waittime(3).

VALOR DE RETORNO

termkey_waitkey() devuelve una de las siguientes constantes:

TERMKEY_RES_KEY
Se ha proporcionado un evento de tecla.
TERMKEY_RES_EOF
No hay eventos de tecla listos y la terminal se ha cerrado, por lo que no llegarán más.
TERMKEY_RES_ERROR
Ocurrió un error de E/S. errno se conservará. Si el error es EINTR, esto solo se devolverá si la bandera TERMKEY_FLAG_EINTR no está establecida; si lo está, la operación de E/S se reintentará en su lugar. Si se llama con la E/S de la terminal detenida, debido a termkey_stop(3), entonces errno se establecerá a EINVAL.

EJEMPLO

El siguiente programa de ejemplo imprime detalles de cada pulsación de tecla hasta que el usuario presiona Ctrl-C.


// queremos optarg
#define _XOPEN_SOURCE 600
#include <stdio.h>
#include <unistd.h>
#include <errno.h>
#include "termkey.h"
int main(int argc, char *argv[])
{
  TERMKEY_CHECK_VERSION;
  int mouse = 0;
  int mouse_proto = 0;
  TermKeyFormat format = TERMKEY_FORMAT_VIM;
  char buffer[50];
  TermKey *tk;
  int opt;
  while((opt = getopt(argc, argv, "m::p:")) != -1) {
    switch(opt) {
    case 'm':
      if(optarg)
        mouse = atoi(optarg);
      else
        mouse = 1000;
      break;
    case 'p':
      mouse_proto = atoi(optarg);
      break;
    default:
      fprintf(stderr, "Uso: %s [-m]\n", argv[0]);
      return 1;
    }
  }
  tk = termkey_new(0, TERMKEY_FLAG_SPACESYMBOL|TERMKEY_FLAG_CTRLC);
  if(!tk) {
    fprintf(stderr, "No se puede asignar instancia de termkey\n");
    exit(1);
  }
  if(termkey_get_flags(tk) & TERMKEY_FLAG_UTF8)
    printf("Termkey en modo UTF-8\n");
  else if(termkey_get_flags(tk) & TERMKEY_FLAG_RAW)
    printf("Termkey en modo RAW\n");
  TermKeyResult ret;
  TermKeyKey key;
  if(mouse) {
    printf("\033[?%dhModo ratón activo\n", mouse);
    if(mouse_proto)
      printf("\033[?%dh", mouse_proto);
  }
  while((ret = termkey_waitkey(tk, &key)) != TERMKEY_RES_EOF) {
    if(ret == TERMKEY_RES_KEY) {
      termkey_strfkey(tk, buffer, sizeof buffer, &key, format);
      if(key.type == TERMKEY_TYPE_MOUSE) {
        int line, col;
        termkey_interpret_mouse(tk, &key, NULL, NULL, &line, &col);
        printf("%s en línea=%d, col=%d\n", buffer, line, col);
      }
      else if(key.type == TERMKEY_TYPE_POSITION) {
        int line, col;
        termkey_interpret_position(tk, &key, &line, &col);
        printf("Informe de posición del cursor en línea=%d, col=%d\n", line, col);
      }
      else if(key.type == TERMKEY_TYPE_MODEREPORT) {
        int initial, mode, value;
        termkey_interpret_modereport(tk, &key, &initial, &mode, &value);
        printf("Informe de modo %s modo %d = %d\n", initial ? "DEC" : "ANSI", mode, value);
      }
      else if(key.type == TERMKEY_TYPE_UNKNOWN_CSI) {
        long args[16];
        size_t nargs = 16;
        unsigned long command;
        termkey_interpret_csi(tk, &key, args, &nargs, &command);
        printf("CSI desconocido %c %ld;%ld %c%c\n", (char)(command >> 8), args[0], args[1], (char)(command >> 16), (char)command);
      }
      else {
        printf("Tecla %s\n", buffer);
      }
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers & TERMKEY_KEYMOD_CTRL &&
         (key.code.codepoint == 'C' || key.code.codepoint == 'c'))
        break;
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers == 0 &&
         key.code.codepoint == '?') {
        // printf("\033[?6n"); // DECDSR 6 == solicitud de posición del cursor
        printf("\033[?1$p"); // DECRQM == solicitud de modo, modo de origen DEC
        fflush(stdout);
      }
    }
    else if(ret == TERMKEY_RES_ERROR) {
      if(errno != EINTR) {
        perror("termkey_waitkey");
        break;
      }
      printf("Interrumpido por señal\n");
    }
  }
  if(mouse)
    printf("\033[?%dlModo ratón desactivado\n", mouse);
  termkey_destroy(tk);
}

Esta función no está disponible en Windows.
