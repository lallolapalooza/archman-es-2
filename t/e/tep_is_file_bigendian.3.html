NOMBRE

tep_is_file_bigendian, tep_set_file_bigendian - Obtener / establecer la endianidad de los datos crudos a los que se accede mediante el manejador tep.

SINOPSIS

#include <event-parse.h>
enum tep_endian {
        TEP_LITTLE_ENDIAN = 0,
        TEP_BIG_ENDIAN
};
bool tep_is_file_bigendian(struct tep_handle *tep);
void tep_set_file_bigendian(struct tep_handle *tep, enum tep_endian endian);

DESCRIPCIÓN

La función tep_is_file_bigendian() obtiene la endianidad de los datos crudos a los que se accede mediante el manejador tep. El argumento tep es el contexto del analizador de eventos de traza.

La función tep_set_file_bigendian() establece la endianidad de los datos crudos a los que se accede mediante el manejador tep. El argumento tep es el contexto del analizador de eventos de traza.

El argumento endian es la endianidad:
        TEP_LITTLE_ENDIAN - los datos crudos están en formato little endian,
        TEP_BIG_ENDIAN - los datos crudos están en formato big endian.

VALOR DE RETORNO

La función tep_is_file_bigendian() devuelve verdadero si los datos están en formato bigendian, falso en caso contrario.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        tep_set_file_bigendian(tep, TEP_LITTLE_ENDIAN);
...
        if (tep_is_file_bigendian(tep)) {
                /* Los datos crudos están en big endian */
        } else {
                /* Los datos crudos están en little endian */
        }
