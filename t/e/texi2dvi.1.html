TEXI2DVI(1) Comandos de usuario TEXI2DVI(1)

NOMBRE

texi2dvi - convierte documentos Texinfo a DVI o PDF

SINOPSIS

texi2dvi [OPCIÓN]... ARCHIVO...
texi2pdf [OPCIÓN]... ARCHIVO...
pdftexi2dvi [OPCIÓN]... ARCHIVO...

DESCRIPCIÓN

Ejecuta cada ARCHIVO de Texinfo o (La)TeX en turno hasta que se resuelvan todas las referencias cruzadas, construyendo todos los índices. El directorio que contiene cada ARCHIVO se busca para encontrar archivos incluidos. La extensión de ARCHIVO se utiliza para determinar su idioma ((La)TeX o Texinfo). Para procesar archivos (e)plain TeX, establezca la variable de entorno LATEX=tex.

Cuando se invoca como `texi2pdf' o se le da la opción --pdf genera salida PDF. De lo contrario, genera DVI.

Opciones generales:

-D, --debug
activa la depuración del shell (establece -x)
-h, --help
muestra esta ayuda y sale con éxito
-o, --output=ARCHIVO_SALIDA
deja la salida en ARCHIVO_SALIDA; solo se permite un ARCHIVO de entrada
-q, --quiet
sin salida a menos que haya errores
-v, --version
muestra información de versión y sale con éxito
-V, --verbose
informa sobre lo que se está haciendo
--max-iterations=N
no procesar archivos más de N veces [7]
--mostly-clean
elimina archivos o directorios auxiliares de ejecuciones anteriores (pero no la salida)

Formato de salida:

--dvi
genera un archivo DVI [por defecto]
--dvipdf
genera un archivo PDF a través de DVI (usando un programa de DVI a PDF)
-p, --pdf
usa pdftex o pdflatex para el procesamiento
--ps
genera un archivo PostScript a través de DVI (usando dvips)

Ajuste de TeX:

-E, --expand
expansión de macros usando makeinfo
-I DIR
busca en DIR archivos Texinfo
-l, --language=IDIOMA
especifica IDIOMA para ARCHIVO, ya sea latex o texinfo
--no-line-error
no pasar --file-line-error a TeX
--shell-escape
pasar --shell-escape a TeX
--src-specials
pasar --src-specials a TeX
--translate-file=ARCHIVO
usa el archivo de traducción de juego de caracteres dado para TeX
-t, --command=COMANDO
inserta COMANDO en una copia del archivo de entrada

Modos de compilación:

--build=MODO
especifica el tratamiento de los archivos auxiliares [local]
--tidy
igual que --build=tidy
-c, --clean
igual que --build=clean
--build-dir=DIR
especifica dónde se realiza la compilación ordenada; implica --tidy

El MODO especifica dónde tiene lugar la compilación de TeX y, en consecuencia, cómo se tratan los archivos auxiliares.

Los valores válidos de MODO son:

`local'
compila en el directorio actual, dejando todos los archivos auxiliares alrededor. Este es el uso tradicional de TeX.
`tidy'
compila en un directorio local *.t2d, donde se dejan los archivos auxiliares. Los archivos de salida se copian de nuevo al archivo original.
`clean'
igual que `tidy', pero elimina el directorio auxiliar después. Cada compilación requiere, por lo tanto, el ciclo completo.

El modo de compilación también se puede establecer utilizando la variable de entorno TEXI2DVI_BUILD_MODE. El directorio de compilación ordenada también se puede establecer utilizando la variable de entorno TEXI2DVI_BUILD_DIRECTORY.

Los valores de estas variables de entorno se utilizan para ejecutar los comandos correspondientes, si están establecidos:

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

Con respecto a --dvipdf, si DVIPDF no está establecido en el entorno, se buscan los siguientes programas (en este orden): dvipdfmx dvipdfm dvipdf dvi2pdf dvitopdf.

Si Texinfo está instalado en su sitio, entonces el comando

info texi2dvi

debería darle acceso a más documentación.

texi2dvi - Convierte archivos Texinfo a DVI.

NOMBRE

texi2dvi - Convierte archivos Texinfo a DVI.

SINOPSIS

texi2dvi [OPCIÓN...] [Archivo Texinfo...]

DESCRIPCIÓN

texi2dvi es un script de shell que utiliza texindex y texi2pdf para convertir archivos Texinfo a formato DVI.

Está diseñado para ser un reemplazo de alto nivel para llamar directamente a texi2pdf. El propósito principal de texi2dvi es generar la salida DVI, aunque el programa subyacente, texi2pdf, soporta la generación de PDF.

OPCIONES

texi2dvi acepta la mayoría de las opciones de texi2pdf. Consulte la página del manual de texi2pdf para obtener una lista completa de opciones y su descripción. Algunas opciones comunes que podrían ser relevantes incluyen:

  • --output-dir=DIRECTORIO: Especifica el directorio de salida para los archivos generados.
  • --force: Fuerza la regeneración de los archivos incluso si parecen estar actualizados.
  • --clean: Limpia los archivos intermedios generados durante el proceso de compilación.
  • --verbose: Muestra más información detallada sobre el proceso de compilación.
  • -p texi2pdf_options: Pasa opciones adicionales directamente al comando texi2pdf.

VER TAMBIÉN

texindex(1), texi2pdf(1)
