tep_set_page_size(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_get_page_size, tep_set_page_size, tep_get_sub_buffer_data_size, tep_get_sub_buffer_size - Obtener / establecer el tamaño de una página de memoria en la máquina, donde se genera el rastreo

SINOPSIS

#include <event-parse.h>
int tep_get_page_size(struct tep_handle *tep);
void tep_set_page_size(struct tep_handle *tep, int page_size);
int tep_get_sub_buffer_size(struct tep_handle *tep);
int tep_get_sub_buffer_data_size(struct tep_handle *tep);
int tep_get_sub_buffer_commit_offset(struct tep_handle *tep);

DESCRIPCIÓN

La función tep_get_page_size() devuelve el tamaño de una página de memoria en la máquina donde se genera el rastreo. El argumento tep es el contexto del analizador de eventos de rastreo.

La función tep_set_page_size() almacena en el contexto tep el tamaño de una página de memoria en la máquina donde se genera el rastreo. El argumento tep es el contexto del analizador de eventos de rastreo. El argumento page_size es el tamaño de una página de memoria, en bytes.

La función tep_get_sub_buffer_size() devuelve el tamaño de cada "sub buffer" del buffer circular. El buffer circular del kernel de Linux se divide en secciones llamadas sub buffers. Esta función devuelve el tamaño de esos buffers.

La función tep_get_sub_buffer_data_size() devuelve el tamaño solo de la porción de datos de los sub buffers.

La función tep_get_sub_buffer_commit_offset() devuelve el desplazamiento en el sub buffer que contiene la porción de datos confirmada. Este número contiene el índice de la porción de datos del sub buffer que es el final del último elemento en el sub buffer.

VALOR DE RETORNO

La función tep_get_page_size() devuelve el tamaño de la página de memoria, en bytes.

La función tep_get_sub_buffer_size() devuelve el número de bytes que componen cada sub buffer.

La función tep_get_sub_buffer_commit_offset() devuelve la ubicación en el sub buffer que contiene el índice del último elemento.

EJEMPLO

#include <unistd.h>
#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        int page_size = getpagesize();
        tep_set_page_size(tep, page_size);
        printf("El tamaño de página de esta máquina es %d\n", tep_get_page_size(tep));
