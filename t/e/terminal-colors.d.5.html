TERMINAL-COLORS.D(5) Formatos de archivo TERMINAL-COLORS.D(5)

NOMBRE

terminal-colors.d - configurar la colorización de salida para varias utilidades

SINOPSIS

/etc/terminal-colors.d/[[nombre][@termina].][tipo]

DESCRIPCIÓN

Los archivos en este directorio determinan el comportamiento predeterminado para las utilidades al colorear la salida.

El nombre es el nombre de una utilidad. El nombre es opcional y cuando no se especifica, el archivo se utiliza para todas las utilidades no especificadas.

El termina es un identificador de terminal (la variable de entorno TERM). El identificador de terminal es opcional y cuando no se especifica, el archivo se utiliza para todas las terminales no especificadas.

El tipo es un tipo de archivo. Los tipos de archivo compatibles son:

disable

Desactiva la colorización de salida para todas las utilidades compatibles. Ver también la variable de entorno NO_COLOR a continuación.

enable

Activa la colorización de salida; se ignoran los archivos disable coincidentes.

scheme

Especifica los colores utilizados para la salida. El formato del archivo puede ser específico de la utilidad; el formato predeterminado se describe a continuación.

Si hay más archivos que coinciden para una utilidad, el archivo con el nombre de archivo más específico tiene prioridad. Por ejemplo, el nombre de archivo "@xterm.scheme" tiene menos prioridad que "dmesg@xterm.scheme". La menor prioridad la tienen los archivos sin nombre de utilidad ni identificador de terminal (por ejemplo, "disable").

El directorio específico del usuario $XDG_CONFIG_HOME/terminal-colors.d o $HOME/.config/terminal-colors.d anula la configuración global.

FORMATO PREDETERMINADO DE LOS ARCHIVOS DE ESQUEMA

La siguiente declaración es reconocida:

nombre secuencia-de-color

El nombre es un nombre lógico de la secuencia de color (por ejemplo, "error"). Los nombres son específicos de las utilidades. Para más detalles, consulte siempre la sección COLORES en la página del manual de la utilidad.

La secuencia-de-color es un nombre de color, secuencias de color ASCII o secuencias de escape.

Nombres de color

negro, parpadeo, azul, negrita, marrón, cian, grisoscuro, gris, verde, semibrillante, azulclaro, cianclaro, grisclaro, verdeclaro, magentaclara, rojoclaro, magenta, rojo, restablecer, invertir y amarillo.

Secuencias de color ANSI

Las secuencias de color se componen de secuencias de números separados por puntos y comas. Los códigos más comunes son:

0 para restaurar el color predeterminado
1 para colores más brillantes
4 para texto subrayado
5 para texto parpadeante
30 para primer plano negro
31 para primer plano rojo
32 para primer plano verde
33 para primer plano amarillo (o marrón)
34 para primer plano azul
35 para primer plano morado
36 para primer plano cian
37 para primer plano blanco (o gris)
40 para fondo negro
41 para fondo rojo
42 para fondo verde
43 para fondo amarillo (o marrón)
44 para fondo azul
45 para fondo morado
46 para fondo cian
47 para fondo blanco (o gris)

Secuencias de escape

Para especificar caracteres de control o en blanco en las secuencias de color, se puede usar la notación de escape estilo C con barra invertida (\):

\a Campana (ASCII 7)
\b Retroceso (ASCII 8)
\e Escape (ASCII 27)
\f Avance de formulario (ASCII 12)
\n Nueva línea (ASCII 10)
\r Retorno de carro (ASCII 13)
\t Tabulación (ASCII 9)
\v Tabulación vertical (ASCII 11)
\? Suprimir (ASCII 127)
\_ Espacio
\\ Barra invertida (\)
\^ Acento circunflejo (^)
\# Almohadilla (#)

Tenga en cuenta que son necesarios escapes para introducir un espacio, barra invertida, acento circunflejo o cualquier carácter de control en cualquier parte de la cadena, así como una almohadilla como primer carácter.

Por ejemplo, para usar un fondo rojo para los mensajes de alerta en la salida de dmesg(1), use:

echo 'alert 37;41' >> /etc/terminal-colors.d/dmesg.scheme

Comentarios

Las líneas donde el primer carácter que no es un espacio en blanco es un # (almohadilla) se ignoran. Cualquier otro uso del carácter de almohadilla no se interpreta como la introducción de un comentario.

AMBIENTE

TERMINAL_COLORS_DEBUG=all

habilita la salida de depuración.

NO_COLOR

si está definido, esto deshabilita la colorización de salida a menos que se habilite explícitamente con una opción de línea de comandos. Ver https://no-color.org/ para más detalles. Soportado desde la versión 2.41 de util-linux.

EJEMPLO

Deshabilitar colores para todas las utilidades compatibles:

touch /etc/terminal-colors.d/disable

Deshabilitar colores para todas las utilidades compatibles en una terminal vt100:

touch /etc/terminal-colors.d/@vt100.disable

Deshabilitar colores para todas las utilidades compatibles excepto dmesg(1):

touch /etc/terminal-colors.d/disable

touch /etc/terminal-colors.d/dmesg.enable

COMPATIBILIDAD

La funcionalidad terminal-colors.d actualmente es soportada por todas las utilidades de util-linux que proporcionan salida de color. Para más detalles, consulta siempre la sección COLORS en la página del manual de la utilidad.
