NOMBRE

testsaslauthd - una herramienta de prueba para saslauthd

SINOPSIS

testsaslauthd -u nombredeusuario -p contraseña
[-r dominio] [-s nombreservicio]
[-f ruta_socket] [-R numerorepeticiones]

DESCRIPCIÓN

Esta herramienta sirve para probar el demonio saslauthd. No la utilice a menos que sepa lo que está haciendo. Lea el código fuente si necesita más información.
