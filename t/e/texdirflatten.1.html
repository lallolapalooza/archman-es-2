TEXDIRFLATTEN(1) Documentación de Perl aportada por el usuario TEXDIRFLATTEN(1)

NOMBRE

texdirflatten - Recopila todos los componentes de un archivo (La)TeX en un único directorio de salida, es decir, aplana su jerarquía.

SINOPSIS

texdirflatten [-1|--onetex] [-f|--file input.tex] [-o outputdir]
[--imgexts .ext1,.ext2,...] [--debug] [-V|--version] [-?|--help]

DESCRIPCIÓN

Este script de Perl analiza un archivo LaTeX de forma recursiva, escaneando todos los archivos hijos y recopilando detalles de cualquier archivo incluido y otros archivos de datos, como gráficos y archivos de bibliografía BiBTeX. Estos archivos de componentes se colocan luego en un solo directorio (de ahí el nombre "flatten", que significa aplanar la estructura de directorios del documento). Esto es útil para distribuir manuscritos a colaboradores o para enviarlos a revistas.

OPCIONES

--file, -f input.tex
Especifica el archivo (La)TeX de entrada.
--onetex, -1
Si se especifica, produce un único archivo TeX expandiendo todos los comandos \input y \include en su lugar.
--output, -o outputdir
Directorio donde recopilar todos los archivos. texdirflatten copiará cada archivo fuente, gráfico y de bibliografía a este directorio. Se creará si no existe. Si no se especifica, se usará por defecto "flat/".
--imgexts .ext1,.ext2[,...]
Antepone a la lista priorizada de extensiones de imagen para buscar al intentar encontrar la imagen que copiar a la carpeta de salida. El primer archivo con la extensión encontrada se copiará y la búsqueda se detendrá. El orden por defecto es "", ".eps", ".pdf", ".pstex" (tenga en cuenta que incluye archivos sin extensión). Si usa pdflatex, puede que desee agregar PDF antes que EPS con "--imgexts .pdf". ¡No olvide el punto antes de la extensión!
--debug
Habilita una gran cantidad de salida de depuración; útil si algo va mal.
--version, -V
Muestra el número de versión actual y el uso, y sale.
--help, -?
Muestra esta página del manual.

EJEMPLOS

El siguiente ejemplo analiza "manuscript.tex" en el directorio actual y lo recopila junto con todos sus componentes en el directorio "submit_01/":

$ texdirflatten -f manuscript.tex -o submit_01

ADVERTENCIAS

Por favor, haga copias de seguridad antes de ejecutar este comando. No se proporcionan garantías de ningún tipo.

Es posible que necesite ejecutar "epstopdf" en los archivos EPS si está utilizando "pdflatex":

$ for i in *.eps; do epstopdf $i; done
