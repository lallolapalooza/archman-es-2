tep_find_any_field(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_find_common_field, tep_find_field, tep_find_any_field - Buscar un campo en un evento.

SINOPSIS

#include <event-parse.h>
struct tep_format_field *tep_find_common_field(struct tep_event *event, const char *name);
struct tep_format_field *tep_find_field(struct tep_event_ormat *event, const char *name);
struct tep_format_field *tep_find_any_field(struct tep_event *event, const char *name);

DESCRIPCIÓN

Estas funciones buscan un campo con el nombre dado en un evento. El campo devuelto puede usarse para encontrar el contenido del campo dentro de un registro de datos.

La función tep_find_common_field() busca un campo común con el nombre name en el event.

La función tep_find_field() busca un campo específico del evento con el nombre name en el event.

La función tep_find_any_field() busca cualquier campo con el nombre name en el event.

VALOR DE RETORNO

Las funciones tep_find_common_field(), tep_find_field() y _tep_find_any_field() devuelven un puntero al campo encontrado, o NULL en caso de que no exista un campo con el nombre solicitado.

EJEMPLO

#include <event-parse.h>
...
void get_htimer_info(struct tep_handle *tep, struct tep_record *record)
{
        struct tep_format_field *field;
        struct tep_event *event;
        long long softexpires;
        int mode;
        int pid;
        event = tep_find_event_by_name(tep, "timer", "hrtimer_start");
        field = tep_find_common_field(event, "common_pid");
        if (field == NULL) {
                /* No se pudo encontrar el campo "common_pid" en el evento */
        } else {
                /* Obtener pid del registro de datos */
                pid = tep_read_number(tep, record->data + field->offset,
                                      field->size);
        }
        field = tep_find_field(event, "softexpires");
        if (field == NULL) {
                /* No se pudo encontrar el campo específico del evento "softexpires" en el evento */
        } else {
                /* Obtener el parámetro softexpires del registro de datos */
                softexpires = tep_read_number(tep, record->data + field->offset,
                                              field->size);
        }
        field = tep_find_any_field(event, "mode");
        if (field == NULL) {
                /* No se pudo encontrar el campo "mode" en el evento */
        } else
        {
                /* Obtener el parámetro mode del registro de datos */
                mode = tep_read_number(tep, record->data + field->offset,
                                       field->size);
        }
}
