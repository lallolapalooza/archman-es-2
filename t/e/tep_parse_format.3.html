tep_parse_format(3)

Paquete: libtraceevent

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_parse_event, tep_parse_format - Analizar la información del formato de evento

SINOPSIS

#include <event-parse.h>
enum tep_errno tep_parse_event(struct tep_handle *tep, const char *buf, unsigned long size, const char *sys);
enum tep_errno tep_parse_format(struct tep_handle *tep, struct tep_event **eventp, const char *buf, unsigned long size, const char *sys);

DESCRIPCIÓN

La función tep_parse_event() analiza el formato del evento y crea una estructura de evento para analizar rápidamente datos crudos para un evento dado. El argumento tep es el contexto del analizador de eventos de rastreo. La estructura de evento creada se almacena en el contexto tep. El argumento buf es un búfer con size, donde están los datos del formato del evento. Los datos del formato del evento se pueden tomar de los archivos tracefs/events/.../.../format. El argumento sys es el sistema del evento.

La función tep_parse_format() hace lo mismo que tep_parse_event(). La única diferencia está en el argumento extra eventp, donde se devuelve la estructura de evento recién creada.

VALOR DE RETORNO

Ambas funciones, tep_parse_event() y tep_parse_format(), devuelven 0 en caso de éxito, o TEP_ERRNO__... en caso de error.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *buf;
int size;
struct tep_event *event = NULL;
buf = read_file("/sys/kernel/tracing/events/ftrace/print/format", &size);
if (tep_parse_event(tep, buf, size, "ftrace") != 0) {
        /* Falló el análisis del formato de impresión de ftrace */
}
if (tep_parse_format(tep, &event, buf, size, "ftrace") != 0) {
        /* Falló el análisis del formato de impresión de ftrace */
}
...
