termkey_advisereadable(3)

Paquete: libtermkey

Licencias: MIT

TERMKEY_ADVISEREADABLE(3) Manual de Funciones de Biblioteca TERMKEY_ADVISEREADABLE(3)

NOMBRE

termkey_advisereadable - leer más bytes del terminal subyacente

SINOPSIS

#include <termkey.h>

TermKeyResult termkey_advisereadable(TermKey *tk);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_advisereadable() informa a la instancia de termkey(7) de que puede haber nueva entrada disponible en el descriptor de archivo subyacente y, por lo tanto, debe llamar a read(2) para obtenerla. Si se leyó al menos un byte más, devolverá TERMKEY_RES_AGAIN para indicar que puede ser útil llamar de nuevo a termkey_getkey(3). Si no se leyó más entrada, se devolverá TERMKEY_RES_NONE. Si no quedaba espacio en el búfer, se devolverá TERMKEY_RES_ERROR con errno establecido en ENOMEM. Si no hay ningún manejador de archivos asociado a esta instancia, se devolverá TERMKEY_RES_ERROR con errno establecido en EBADF.

Esta función, junto con termkey_getkey(3), permite usar la instancia de termkey en un programa asíncrono. Para proporcionar bytes sin usar un manejador de archivos legible, utilice termkey_push_bytes(3).

Para uso síncrono, termkey_waitkey(3) realiza la tarea de bloqueo de entrada.

VALOR DE RETORNO

termkey_advisereadable() devuelve una de las siguientes constantes:

TERMKEY_RES_AGAIN
Se leyó al menos un byte.
TERMKEY_RES_NONE
No se leyeron más bytes.
TERMKEY_RES_ERROR
Ocurrió un error de E/S. Se conservará errno. Si el error es EINTR, solo se devolverá si la bandera TERMKEY_FLAG_EINTR no está establecida; si lo está, se reintentará la operación de E/S en su lugar.

VER TAMBIÉN

termkey_getkey(3), termkey_waitkey(3), termkey_set_waittime(3), termkey(7)
