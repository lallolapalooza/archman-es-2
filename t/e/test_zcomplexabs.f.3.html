!>
!> Valores reales para la prueba:
!> (1) x = 2**m, donde m = MINEXPONENT-DIGITS, ..., MINEXPONENT-1. Detenerse en el primer éxito.
!>     Tenga en cuenta que no todas las plataformas pueden implementar números subnormales.
!> (2) x = 2**m, donde m = MINEXPONENT, ..., 0. Detenerse en el primer éxito.
!> (3) x = OV, donde OV es el umbral de desbordamiento. OV^2 se desborda pero la norma es OV.
!> (4) x = 2**m, donde m = MAXEXPONENT-1, ..., 1. Detenerse en el primer éxito.
!>
!> Pruebas:
!> (a) y = x + 0 * I, |y| = x
!> (b) y = 0 + x * I, |y| = x
!> (c) y = (3/4)*x + x * I, |y| = (5/4)*x siempre que (3/4)*x y (5/4)*x se puedan almacenar exactamente
!> (d) y = (1/2)*x + (1/2)*x * I, |y| = (1/2)*x*sqrt(2) siempre que (1/2)*x se pueda almacenar exactamente
!>
!> Casos especiales:
!>
!> (i) Propagación de Inf
!>    (1) y = Inf + 0 * I, |y| es Inf.
!>    (2) y =-Inf + 0 * I, |y| es Inf.
!>    (3) y = 0 + Inf * I, |y| es Inf.
!>    (4) y = 0 - Inf * I, |y| es Inf.
!>    (5) y = Inf + Inf * I, |y| es Inf.
!>
!> (n) Propagación de NaN
!>    (1) y = NaN + 0 * I, |y| es NaN.
!>    (2) y = 0 + NaN * I, |y| es NaN.
!>    (3) y = NaN + NaN * I, |y| es NaN.
!>
!>
