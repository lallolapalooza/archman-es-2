NOMBRE

termkey_get_keyname - devuelve un nombre de cadena para una tecla simbólica

SINOPSIS

#include <termkey.h>

const char *termkey_get_keyname(TermKey *tk, TermKeySym sym);

Enlazar con -ltermkey.

DESCRIPCIÓN

termkey_get_keyname() devuelve un nombre de cadena legible por humanos para el valor de tecla simbólica dado por sym. La cadena devuelta pertenece a la instancia de termkey(7) tk, por lo que no debe modificarse ni liberarse. El puntero devuelto está garantizado que sea válido hasta que la instancia se libere usando termkey_destroy(3). Esta función es la inversa de termkey_keyname2sym(3).

VALOR DE RETORNO

termkey_get_key() devuelve un puntero a una cadena.

VER TAMBIÉN

termkey_lookup_keyname(3), termkey_keyname2sym(3), termkey_strfkey(3), termkey(7)
