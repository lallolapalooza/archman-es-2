NOMBRE

tep_filter_alloc, tep_filter_free, tep_filter_reset, tep_filter_make_string, tep_filter_copy, tep_filter_compare, tep_filter_match, tep_event_filtered, tep_filter_remove_event, tep_filter_strerror, tep_filter_add_filter_str - APIs relacionadas con filtros de eventos.

SINOPSIS

#include <event-parse.h>
struct tep_event_filter *tep_filter_alloc(struct tep_handle *tep);
void tep_filter_free(struct tep_event_filter *filter);
void tep_filter_reset(struct tep_event_filter *filter);
enum tep_errno tep_filter_add_filter_str(struct tep_event_filter *filter, const char *filter_str);
int tep_event_filtered(struct tep_event_filter *filter, int event_id);
int tep_filter_remove_event(struct tep_event_filter *filter, int event_id);
enum tep_errno tep_filter_match(struct tep_event_filter *filter, struct tep_record *record);
int tep_filter_copy(struct tep_event_filter *dest, struct tep_event_filter *source);
int tep_filter_compare(struct tep_event_filter *filter1, struct tep_event_filter *filter2);
char *tep_filter_make_string(struct tep_event_filter *filter, int event_id);
int tep_filter_strerror(struct tep_event_filter *filter, enum tep_errno err, char *buf, size_t buflen);

DESCRIPCIÓN

Los filtros se pueden adjuntar a eventos trazados. Se pueden usar para filtrar varios eventos al emitirlos. Cada evento se puede filtrar según sus parámetros, descritos en el archivo de formato del evento. Este conjunto de funciones se puede usar para crear, eliminar, modificar y adjuntar filtros de eventos.

La función tep_filter_alloc() crea un nuevo filtro de eventos. El argumento tep es el contexto del analizador de eventos de trazado.

La función tep_filter_free() libera un filtro de eventos y todos los recursos que haya utilizado.

La función tep_filter_reset() elimina todas las reglas de un filtro de eventos y lo restablece.

La función tep_filter_add_filter_str() agrega una nueva regla al filter. El argumento filter_str es la cadena del filtro, que contiene la regla.

La función tep_event_filtered() verifica si el evento con event_id tiene un filter.

La función tep_filter_remove_event() elimina un filter para un evento con event_id.

La función tep_filter_match() prueba si un record coincide con el filter dado.

La función tep_filter_copy() copia un filtro de source en un filtro de dest.

La función tep_filter_compare() compara dos filtros: filter1 y filter2.

La función tep_filter_make_string() construye una cadena, mostrando el contenido del filter para el event_id dado.

La función tep_filter_strerror() copia el búfer de error del filter en el buf dado con el tamaño buflen. Si el búfer de errores está vacío, en el buf se copia una cadena que describe el error err.

VALOR DE RETORNO

La función tep_filter_alloc() devuelve un puntero al filtro de eventos recién creado, o NULL en caso de error.

La función tep_filter_add_filter_str() devuelve 0 si la regla se agregó correctamente o un código de error negativo. Use tep_filter_strerror() para ver el mensaje de error real en caso de error.

La función tep_event_filtered() devuelve 1 si se encuentra el filtro para el evento dado, o 0 en caso contrario.

La función tep_filter_remove_event() devuelve 1 si se eliminó el evento, o 0 si no se encontró el evento.

La función tep_filter_match() devuelve tep_errno, según el resultado:

TEP_ERRNO__FILTER_MATCH        - se encontró filtro para el evento, el registro coincide.
TEP_ERRNO__FILTER_MISS         - se encontró filtro para el evento, el registro no coincide.
TEP_ERRNO__FILTER_NOT_FOUND    - no se encontró filtro para el evento del registro.
TEP_ERRNO__NO_FILTER           - no hay reglas en el filtro.

o cualquier otro tep_errno, si ocurrió un error durante la prueba.

La función tep_filter_copy() devuelve 0 en caso de éxito o -1 si no se copiaron todas las reglas.

La función tep_filter_compare() devuelve 1 si los dos filtros contienen el mismo contenido, o 0 si no.

La función tep_filter_make_string() devuelve una cadena, que debe liberarse con free(), o NULL en caso de error.

La función tep_filter_strerror() devuelve 0 si el mensaje se rellenó correctamente, o -1 en caso de error.

void process_record(struct tep_handle *tep, struct tep_record *record)
{
        struct tep_event *event;
        char *fstring;
        event = tep_find_event_by_record(tep, record);
        if (tep_event_filtered(filter, event->id) == 1) {
                /* El evento tiene filtro */
                fstring = tep_filter_make_string(filter, event->id);
                if (fstring != NULL) {
                        /* El filtro para el evento está en fstring */
                        free(fstring);
                }
        }
        switch (tep_filter_match(filter, record)) {
        case TEP_ERRNO__FILTER_MATCH:
                /* El filtro coincide con el registro */
                break;
        case TEP_ERRNO__FILTER_MISS:
                /* El filtro no coincide con el registro */
                break;
        case TEP_ERRNO__FILTER_NOT_FOUND:
                /* No se encontró filtro para el evento del registro */
                break;
        case TEP_ERRNO__NO_FILTER:
                /* No hay reglas en el filtro */
                break
        default:
                /* Ocurrió un error durante la prueba */
                break;
        }
        if (tep_filter_remove_event(filter, event->id) == 1) {
                /* El evento fue eliminado del filtro */
        }
}

tep_filter_make_string(3)
char * tep_filter_make_string( const char *fmt, ... );

Creates a string from a format string and arguments.

SYNOPSIS

#include <trace-event-parse.h>

DESCRIPTION

The tep_filter_make_string function creates a new string by formatting the given format string fmt and the subsequent arguments. This function is similar to the standard C sprintf function, but it allocates memory for the resulting string, which must be freed by the caller using free.

RETURN VALUE

On success, tep_filter_make_string returns a pointer to the newly allocated string. If memory allocation fails, it returns NULL. The caller is responsible for freeing the returned string.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <trace-event-parse.h>

int main() {
    char *message;
    int event_id = 123;
    const char *event_name = "syscall_enter";

    message = tep_filter_make_string("Event ID: %d, Name: %s", event_id, event_name);

    if (message) {
        printf("%s\n", message);
        free(message);
    } else {
        fprintf(stderr, "Failed to create string\n");
    }

    return 0;
}
