Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_set_function_resolver, tep_reset_function_resolver, tep_register_function, tep_register_print_string, tep_get_function_count - APIs relacionadas con funciones tep

SINOPSIS

#include <event-parse.h>
typedef char *(tep_func_resolver_t)(void *priv, unsigned long long *addrp, char **modp);
int tep_set_function_resolver(struct tep_handle *tep, tep_func_resolver_t *func, void *priv);
void tep_reset_function_resolver(struct tep_handle *tep);
int tep_register_function(struct tep_handle *tep, char *name, unsigned long long addr, char *mod);
int tep_register_print_string(struct tep_handle *tep, const char *fmt, unsigned long long addr);
int tep_get_function_count(struct tep_handle *tep)

DESCRIPCIÓN

Algunas herramientas pueden tener ya una forma de resolver las funciones del kernel. Estas APIs les permiten seguir usándola en lugar de duplicar todas las entradas dentro.

El tipo tep_func_resolver_t es el prototipo del resolvedor alternativo de funciones del kernel. Esta función recibe un puntero a su contexto personalizado (establecido con la llamada tep_set_function_resolver()) y la dirección de una función del kernel, la cual debe ser resuelta. En caso de éxito, debe devolver el nombre de la función y su módulo (si existe) en modp.

La función tep_set_function_resolver() registra func como un resolvedor alternativo de funciones del kernel. El argumento tep es el contexto del analizador de eventos de traza. El argumento priv es un contexto personalizado de la función func. El resolvedor de funciones es utilizado por las APIs tep_find_function(3), tep_find_function_address(3), y tep_print_func_field() para resolver una dirección de función a un nombre de función.

La función tep_reset_function_resolver() restablece el resolvedor de funciones del kernel a la función predeterminada. El argumento tep es el contexto del analizador de eventos de traza.

Estas APIs pueden usarse para encontrar el nombre y la dirección de inicio de una función, dada una dirección. La dirección dada no tiene que ser exacta, seleccionará la función que la contendría.

La función tep_register_function() registra un nombre de función mapeado a una dirección y (opcionalmente) un módulo. Este mapeo se utiliza en caso de que el rastreador de funciones o los eventos tengan parámetros "%pS" en su cadena de formato. Es común pasar los nombres de funciones de kallsyms con sus direcciones correspondientes con esta función. El argumento tep es el contexto del analizador de eventos de traza. El name es el nombre de la función, la cadena se copia internamente. El addr es la dirección de inicio de la función. El mod es el módulo del kernel en el que puede estar la función (NULL si no hay ninguno).

La función tep_register_print_string() registra una cadena por la dirección en la que fue almacenada en el kernel. Algunas cadenas internas del kernel con dirección estática se pasan a ciertos eventos. El "%s" en el campo de formato del evento que tiene una dirección necesita saber qué cadena estaría en esa dirección. tep_register_print_string() proporciona al análisis el mapeo entre las direcciones del kernel y esas cadenas. El argumento tep es el contexto del analizador de eventos de traza. El fmt es la cadena a registrar, se copia internamente. El addr es la dirección donde se encontraba la cadena.

tep_get_function_count() devuelve el número de funciones registradas en un manejador tep.

VALOR DE RETORNO

La función tep_set_function_resolver() devuelve 0 en caso de éxito, o -1 en caso de error.

La función tep_register_function() devuelve 0 en caso de éxito. En caso de error, se devuelve -1 y errno se establece al número de error apropiado.

La función tep_register_print_string() devuelve 0 en caso de éxito. En caso de error, se devuelve -1 y errno se establece al número de error apropiado.

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *my_resolve_kernel_addr(void *context,
                             unsigned long long *addrp, char **modp)
{
        struct db *function_database = context;
        struct symbol *sym = sql_lookup(function_database, *addrp);
        if (!sym)
                return NULL;
        *modp = sym->module_name;
        return sym->name;
}
void show_function( unsigned long long addr)
{
        unsigned long long fstart;
        const char *fname;
        if (tep_set_function_resolver(tep, my_resolve_kernel_addr,
                                      function_database) != 0) {
                /* falló al registrar my_resolve_kernel_addr */
        }
        /* Estas APIs usan my_resolve_kernel_addr() para resolver la dirección */
        fname = tep_find_function(tep, addr);
        fstart = tep_find_function_address(tep, addr);
        /*
           la dirección está en la función llamada fname, comenzando en fstart,
           con un desplazamiento (addr - fstart)
        */
        tep_reset_function_resolver(tep);
}

        if (tep_register_function(tep, "kvm_exit",

        }
...
        if (tep_register_print_string(tep, "print string",
