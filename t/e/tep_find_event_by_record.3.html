tep_find_event_by_record(3)

Paquete: libtraceevent

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

tep_find_event, tep_find_event_by_name, tep_find_event_by_record, tep_record_is_event - Buscar eventos por clave dada.

SINOPSIS

#include <event-parse.h>
struct tep_event *tep_find_event(struct tep_handle *tep, int id);
struct tep_event *tep_find_event_by_name(struct tep_handle *tep, const char *sys, const char *name);
struct tep_event *tep_find_event_by_record(struct tep_handle *tep, struct tep_record *record);
bool tep_record_is_event(struct tep_record *record, struct tep_event *event);

DESCRIPCIÓN

Este conjunto de funciones se puede utilizar para buscar un evento, basado en un criterio dado. Todas las funciones requieren un puntero a tep, el contexto del analizador de eventos de traza.

La función tep_find_event() busca un evento por el id del evento dado. El ID del evento se asigna dinámicamente y se puede ver en el archivo de formato del evento, campo "ID".

La función tep_find_event_by_name() busca un evento por el nombre del evento dado, bajo el sistema sys. Si sys es NULL (no especificado), se devuelve el primer evento con el name.

La función tep_find_event_by_record() busca un evento a partir de un record dado.

La función tep_record_is_event() comprueba si el record dado es del tipo del event. Esto se usa normalmente para saber si el record que se está procesando es de un event donde se debe realizar un procesamiento adicional.

VALOR DE RETORNO

Todas estas funciones, excepto tep_record_is_event(), devuelven un puntero al evento encontrado, o NULL si no existe dicho evento.

EJEMPLO

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
struct tep_event *event;
event = tep_find_event(tep, 1857);
if (event == NULL) {
        /* No hay evento con ID 1857 */
}
event = tep_find_event_by_name(tep, "kvm", "kvm_exit");
if (event == NULL) {
        /* No hay evento kvm_exit, del sistema kvm */
}
void event_from_record(struct tep_record *record)
{
 struct tep_event *event = tep_find_event_by_record(tep, record);
        if (event == NULL) {
                /* No hay evento del registro dado */
        }
}
