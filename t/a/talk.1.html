NOMBRE

talk - Hablar con otro usuario

SINOPSIS

talk [OPCIÓN...] persona [ttyname]

DESCRIPCIÓN

Hablar con otro usuario.

-?, --help
mostrar esta lista de ayuda
--usage
mostrar un mensaje de uso corto
-V, --version
mostrar la versión del programa
