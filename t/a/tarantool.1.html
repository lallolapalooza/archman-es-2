TARANTOOL(1) Servidor de aplicaciones Lua y sistema de gestión de bases de datos TARANTOOL(1)

NOMBRE

tarantool - servidor de aplicaciones Lua y sistema de gestión de bases de datos

SINOPSIS

tarantool [OPCIONES] [SCRIPT [ARGUMENTOS]]

DESCRIPCIÓN

Tarantool es un servidor de aplicaciones Lua completamente compatible con Lua 5.1.

Incluye una base de datos madura para persistir, replicar y recuperar el estado de la aplicación, y un conjunto curado de módulos Lua para redes, E/S, mensajería, formatos de datos y más.

Está diseñado para permitir a los desarrolladores crear rápidamente microservicios y aplicaciones de backend eficientes, fiables y potentes para Internet.

Características principales:

  • Completamente compatible con Lua 5.1.
  • Corrutinas y E/S asíncrona para implementar acceso a datos sin bloqueo de alto rendimiento.
  • Transacciones ACID.
  • SQL ANSI, procedimientos almacenados en Lua y disparadores.
  • Autenticación y control de acceso.
  • Replicación maestro-maestro y fragmentación automática.

OPCIONES

Puede utilizar estas opciones antes (o en lugar de) el nombre de 'SCRIPT' interpretado:

-h, --help
Muestra la pantalla de ayuda y sale.
-V, -v, --version
Imprime la versión del programa y sale.
-e EXPR
Ejecuta la cadena 'EXPR'.
-l NOMBRE
Requiere la biblioteca 'NOMBRE'.
-i
Entra en modo interactivo después de ejecutar 'SCRIPT'.
--
Deja de procesar opciones.
-
Ejecuta desde la entrada estándar y deja de procesar opciones.
