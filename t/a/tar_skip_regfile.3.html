tar_extract_file(3) Llamadas a la biblioteca C tar_extract_file(3)

NOMBRE

tar_extract_file, tar_extract_regfile, tar_extract_hardlink, tar_extract_symlink, tar_extract_chardev, tar_extract_blockdev, tar_extract_dir, tar_extract_fifo, tar_skip_regfile, tar_set_file_perms - extraer archivos de un archivo tar

SINOPSIS

#include <libtar.h>

int tar_extract_file(TAR *t, char *realname);

int tar_extract_regfile(TAR *t, char *realname);

int tar_skip_regfile(TAR *t);

int tar_extract_dir(TAR *t, char *realname);

int tar_extract_hardlink(TAR *t, char *realname);

int tar_extract_symlink(TAR *t, char *realname);

int tar_extract_blockdev(TAR *t, char *realname);

int tar_extract_chardev(TAR *t, char *realname);

int tar_extract_fifo(TAR *t, char *realname);

int tar_set_file_perms(TAR *t, char *realname);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función tar_extract_file() actúa como una interfaz para las otras funciones tar_extract_*(). Comprueba la cabecera tar actual asociada con el manejador TAR t (que debe ser inicializado primero llamando a th_read()) para determinar a qué tipo de archivo se refiere la cabecera. Luego llama a la función apropiada tar_extract_*() para extraer ese tipo de archivo.

La función tar_skip_regfile() omite los bloques de contenido del archivo y posiciona el puntero del archivo en la ubicación esperada del siguiente bloque de cabecera tar.

La función tar_set_file_perms() establece los atributos del archivo extraído para que coincidan con los valores codificados. Esto incluye la hora de modificación del archivo, el modo, el propietario y el grupo. Esta función es llamada automáticamente por tar_extract_file(), pero las aplicaciones que llaman directamente a las otras funciones tar_extract_*() necesitarán llamar a tar_set_file_perms() manualmente si se desea este comportamiento.

VALORES DE RETORNO

Al completarse con éxito, las funciones aquí documentadas devolverán 0. En caso de fallo, devolverán -1 y establecerán errno a un valor apropiado.

La función tar_extract_dir() devolverá 1 si el directorio ya existe.

ERRORES

La función tar_extract_file() fallará si:

EEXIST
Si el flag O_NOOVERWRITE está establecido y el archivo ya existe.

Las funciones tar_extract_*() fallarán si:

EINVAL
No se pudo añadir una entrada a la tabla hash interna de archivos.
EINVAL
Se leyeron menos de T_BLOCKSIZE bytes del archivo tar.
EINVAL
La cabecera del archivo actual asociada con t se refiere a un tipo de archivo distinto al que la función llamada conoce.

También pueden fallar si alguna de las siguientes funciones falla: mkdir(), write(), link(), symlink(), mknod(), mkfifo(), utime(), chown(), lchown(), chmod(), o lstat().
