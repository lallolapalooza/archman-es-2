tangram(6) Manual de XScreenSaver tangram(6)

NOMBRE

tangram - observa la computadora resolver acertijos de tangram.

SINOPSIS

tangram [--display host:display.screen] [--visual visual] [--window] [--root] [--window-id numero] [--delay numero] [--wireframe] [--viewing_time numero] [--rotate] [--fps]

DESCRIPCIÓN

El programa tangram utiliza algunas formas básicas para construir siluetas de objetos reconocibles.

OPCIONES

tangram acepta las siguientes opciones:

--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual o el número de ID (decimal o hexadecimal) de un visual específico.
--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id numero
Dibuja en la ventana especificada.
--delay numero
Retraso por fotograma, en microsegundos. Predeterminado: 10000 (0.01 segundos).
--wireframe | --no-wireframe
Renderiza en modo de alambre en lugar de sólido.
--viewing_time numero
Especifica la duración, en segundos, que se mostrará el acertijo completado. Predeterminado: 5
--rotate | --no-rotate
Gira la cámara alrededor del acertijo.
--fps
Muestra la tasa de fotogramas actual, la carga de la CPU y el recuento de polígonos.

ENTORNO

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de ventana a usar con --root.
