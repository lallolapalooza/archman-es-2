tar_append_file(3)

Paquete: libtar

Licencias: BSD

tar_append_file(3) Llamadas a la biblioteca C tar_append_file(3)

NOMBRE

tar_append_file, tar_append_eof, tar_append_regfile - añadir datos a archivos tar

SINOPSIS

#include <libtar.h>

int tar_append_file(TAR *t, char *realname, char *savename);

int tar_append_regfile(TAR *t, char *realname);

int tar_append_eof(TAR *t);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función tar_append_file() crea un bloque de cabecera de archivo tar que describe el archivo nombrado por el argumento realname, pero con el nombre de archivo codificado de savename. Luego establece la cabecera actual asociada con el manejador TAR t al bloque de cabecera recién creado y escribe este bloque en el archivo tar asociado con t. Si el archivo nombrado por realname es un archivo regular (y no está codificado como un enlace físico), tar_append_file() llamará a tar_append_regfile() para añadir el contenido del archivo.

La función tar_append_regfile() añade el contenido de un archivo regular al archivo tar asociado con t. Dado que esta función es llamada por tar_append_file(), solo debería ser necesaria para aplicaciones que construyen y escriben la cabecera del archivo tar por su cuenta.

La función tar_append_eof() escribe un marcador de fin de archivo (dos bloques de ceros) en el archivo tar asociado con t.

VALORES DE RETORNO

Al completarse con éxito, estas funciones devolverán 0. En caso de error, devolverán -1 y establecerán errno a un valor apropiado.

ERRORES

Las funciones tar_append_*() fallarán si:

EINVAL
Se escribieron menos de T_BLOCKSIZE bytes en el archivo tar.
EINVAL
Se leyeron menos de T_BLOCKSIZE bytes del archivo realname.

También pueden fallar si alguna de las siguientes funciones falla: lstat(), malloc(), open(), read(), th_write(), o la función de escritura para el tipo de archivo asociado con el manejador TAR t.

VER TAMBIÉN

read(2), open(2), lstat(2), th_write(3)
