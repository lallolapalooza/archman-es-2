TANGLE(1) Manual de Comandos Generales TANGLE(1)

NOMBRE

tangle - traduce WEB a Pascal

SINOPSIS

tangle [opciones] archivo.web[.web] [{archivo.ch[.ch]|-} [salida.p[.p]]]

DESCRIPCIÓN

Esta página del manual no pretende ser exhaustiva. La documentación completa para esta versión de TeX se puede encontrar en el archivo info o en el manual Web2C: A TeX implementation.

El programa tangle convierte un documento fuente Web en un programa Pascal que puede ser compilado de la manera habitual con el compilador Pascal en línea (por ejemplo, pc(1)). El archivo de salida se empaqueta en líneas de 72 caracteres o menos, con la única concesión a la legibilidad de terminar las líneas en punto y coma cuando esto se puede hacer convenientemente.

El lenguaje Web le permite preparar un único documento que contiene toda la información necesaria tanto para producir un programa Pascal compilable como para producir un documento bien formateado que describa el programa con el detalle que el escritor desee. El usuario de Web debe estar familiarizado tanto con TeX como con Pascal. Web también proporciona un sistema de macros relativamente simple, aunque adecuado, que permite escribir un programa Pascal en módulos pequeños y fáciles de entender.

La línea de comandos debe tener uno, dos o tres nombres. El primero se toma como el archivo Web (y se le añade .web si no tiene extensión). Si hay un segundo nombre, es un archivo de cambios (y se le añade .ch si no tiene extensión). El archivo de cambios anula partes del archivo Web, como se describe en la documentación del sistema Web.

Si hay un tercer nombre, es el archivo de salida Pascal (y se le añade .p si no tiene extensión). En este caso, puede especificar un archivo de cambios vacío con '-' como segundo argumento. De lo contrario, el nombre del archivo Pascal se forma añadiendo .p a la raíz del nombre del archivo Web.

Un segundo archivo de salida opcional es un archivo de grupo de cadenas, cuyo nombre se forma añadiendo .pool a la raíz del nombre del archivo Pascal.

OPCIONES

Esta versión de tangle entiende las siguientes opciones. Tenga en cuenta que algunas de estas opciones pueden hacer que la salida no sea adecuada para ser procesada por un compilador Pascal.

--help
Imprime el mensaje de ayuda y sale.
--length número
Compara solo los primeros número caracteres de los identificadores al verificar colisiones. El valor predeterminado es 32; el tangle original usaba 7.
--loose
Al verificar colisiones entre identificadores, respeta la configuración de las opciones --lowercase, --mixedcase, --uppercase y --underline. Este es el valor predeterminado.
--lowercase
Convierte todos los identificadores a minúsculas.
--mixedcase
Mantiene la capitalización de los identificadores. Este es el valor predeterminado.
--strict
Al verificar colisiones entre identificadores, elimina los guiones bajos y convierte todos los identificadores a mayúsculas primero.
--underline
Mantiene los guiones bajos en los identificadores.
--uppercase
Convierte todos los identificadores a mayúsculas. Este es el comportamiento del tangle original.
--version
Imprime la información de la versión y sale.

MEDIO AMBIENTE

La variable de entorno WEBINPUTS se utiliza para buscar los archivos de entrada, o el valor predeterminado del sistema si WEBINPUTS no está configurado. Consulte tex(1) para obtener detalles sobre la búsqueda.
