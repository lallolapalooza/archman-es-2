FBB::Table(3bobcat) Construye tablas de texto FBB::Table(3bobcat)

NOMBRE

FBB::Table - Genera tablas rellenas por fila o por columna a partir de información insertada en un std::ostream

SINOPSIS

#include <bobcat/tablebuf>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::Table son objetos std::streambuf que pueden ser utilizados para crear tablas. Las tablas se rellenan por columna o por fila. Muchas de las características de la tabla pueden ser ajustadas finamente por un objeto FBB::TableSupport separado, descrito en una página de manual separada (TableSupport(3bobcat)). Cuando no se usa un objeto FBB::TableSupport, se construye una tabla simple por fila o por columna que puede ser insertada en un std::ostream. Mostrar una tabla (por ejemplo, en el flujo de salida estándar) implica los siguientes pasos:

o
Opcionalmente, se crea un objeto TableSupport;
o
Se crea un objeto Tablebuf (quizás pasándole un objeto TableSupport);
o
El objeto Tablebuf se utiliza para inicializar un std::ostream
o
Los elementos de la tabla se rellenan insertando información en ese std::ostream
o
El propio Tablebuf contiene la tabla formateada y puede ser insertado en un std::ostream como std::cout.

Las tablas definidas por TableBuf consisten en un número de filas (dependiente del número de elementos) y un número fijo de columnas, este último valor se especifica en el momento de la construcción. Las columnas y filas se direccionan normalmente usando valores de índice (empezando en 0). Antes de la columna más a la izquierda, entre las columnas y más allá de la última columna se definen separadores. Por defecto, los separadores están vacíos, pero cada separador puede tener un ancho o contenido (fijo). El separador antes de la columna col se aborda como separador col, el separador más a la derecha se aborda como separador nColummns.

De igual manera, las filas pueden separarse entre sí usando separadores. Estas filas separadoras también están vacías por defecto. El separador de fila antes de la fila row se aborda como separador de fila row. El separador de fila que sigue a la fila final se aborda como separador de fila nRows, donde nRows es el valor devuelto por la función miembro nRows.

Los separadores no predeterminados (es decir, no vacíos) se definen usando objetos FBB::TableSupport (cf. tablesupport(3bobcat)).

La clase hermana de TableBuf, Table, puede ser usada para insertar elementos en una tabla de una manera más directa. Con TableBuf se usan separadores de campo para cambiar al siguiente elemento de tabla, y (con tablas rellenadas por fila) se puede usar un separador de fila para cambiar a la siguiente fila cuando está solo parcialmente definida. En su lugar, con objetos Table cada nueva inserción define otro elemento de tabla, y no se requiere un objeto std::ostream envolvente.

NOMBRE DE ESPACIO

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::streambuf - permitiendo que los objetos TableBuf sean envueltos en objetos std::ostream.

FBB::TableBase - Esta clase implementa elementos comunes de la implementación de tablas (la clase FBB::TableBuf también deriva de TableBase). La clase TableBase no está destinada a ser usada de otra manera, y no se proporciona una página de manual separada. Todas las facilidades proporcionadas por Table heredadas de TableBase se describen en esta página de manual.

ENUMERACIONES

Las siguientes enumeraciones están definidas en la clase FBB::Tablebuf.

enum FillDirection
Esta enumeración tiene dos valores:

o
ROWWISE:
Cuando este valor se especifica en el momento de la construcción, los elementos se añaden por fila a la tabla. Es decir, el segundo elemento insertado en la Table se encontrará en la segunda columna de la primera fila.
o
COLUMNWISE:
Cuando este valor se especifica en el momento de la construcción, los elementos se añaden por columna a la tabla. Es decir, el segundo elemento se encontrará en la segunda fila de la primera columna.

enum WidthType
Esta enumeración contiene dos valores:

o
COLUMNWIDTH:
Este valor puede especificarse cuando las columnas deben tener anchos variables. En este caso, cada columna será tan ancha como su elemento más ancho. Este es el WidthType predeterminado utilizado por los objetos Table.
o
EQUALWIDTH:
Este valor puede especificarse cuando todas las columnas de la tabla deben tener un ancho igual (es decir, igual al ancho del elemento de tabla más ancho),

CONSTRUCTORES

o
Tablebuf(size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
Se debe proporcionar el número de columnas de la tabla, las direcciones de relleno y el tipo de ancho de columna. El número de filas se deduce de la combinación de este parámetro y el número de elementos que se insertan realmente en el objeto Table. El parámetro direction especifica la forma en que se añaden nuevos elementos al objeto Table: por fila o por columna. Finalmente, el parámetro widthType se utiliza para especificar la forma en que se determina el ancho de las columnas de la tabla. Cada columna define su propio ancho o todas las columnas tienen anchos iguales.
o
TableBuf(TableSupport &tableSupport, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
Este constructor opera de manera idéntica al constructor anterior, pero espera una referencia adicional a un objeto TableSupport. Un objeto TableSupport ofrece características de formato adicionales utilizadas por los elementos que definen la tabla, como líneas horizontales entre filas, separadores adicionales, etc. El objeto TableSupport se pasa como una referencia no constante, ya que el objeto Table debe poder manipular sus datos. Consulte tablesuppport(3bobcat) para obtener más información sobre TableSupport.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

OPERADORES SOBRECARGADOS

o
std::ostream &operator<<(std::ostream &out, TableBuf &tablebuf):
Este operador inserta un TableBuf en un objeto std::ostream. Tenga en cuenta que el objeto TableBuf insertado en out es un objeto no constante, ya que la tabla puede tener que completarse añadiendo elementos vacíos para los faltantes. El flujo out no debe ser igual al objeto std::ostream que se utiliza para envolver un objeto TableBuf.
o
TableBuf &operator<<(TableBuf &obj, Align const &align):
Este operador se utiliza para cambiar la alineación predeterminada de una columna o de un elemento. Es un envoltorio para la función miembro setAlign() (ver su descripción más abajo). Por defecto, todos los elementos están alineados a la derecha. Consulte align(3bobcat) para obtener más información sobre la clase Align. A diferencia de los operadores de inserción disponibles para objetos de tipo Table, el operador de inserción para objetos TableBuf solo se utiliza para definir la alineación de columnas o celdas.

DESCRIPCIÓN

La clase TableBuf de la biblioteca Bobcat es una clase de buffer de tabla que permite la construcción de tablas de texto alineadas en columnas.

HEREDA DE

ENUMERACIONES

o

Define la dirección de llenado de la tabla.
ROWWISE
Llenado fila por fila.
COLUMNWISE
Llenado columna por columna.

CONSTRUCTORES

o
TableBuf(size_t columns, FillDirection fillDirection = ROWWISE):
Constructor que crea un objeto TableBuf con un número específico de columnas y una dirección de llenado dada. El valor predeterminado es `ROWWISE`.

TableBuf(TableLines const &tableLines, size_t columns, FillDirection fillDirection = ROWWISE):
Constructor que crea un objeto TableBuf utilizando un objeto TableLines para definir los anchos de las columnas y la dirección de llenado.

void clear():
El contenido de la tabla se borra. Se eliminan todos los elementos existentes y la tabla quedará vacía.
o
size_t nRows():
Se devuelve el número de filas actualmente disponibles en la tabla. Su valor solo está definido después de llamar a def().
o
TableBuf &setAlign(Align const &align):
El tipo de alineación de una columna o un elemento del objeto TableBuf se define usando setAlign. Se pueden especificar las alineaciones estándar std::left, std::right y std::internal, pero además se puede usar la alineación FBB::center si los elementos deben centrarse en su columna. Una construcción como 
tab << Align(2, FBB::center)
solicita el centrado de todos los elementos en la columna de la tabla con índice 2 (es decir, la tercera columna de la tabla), mientras que una construcción como 
tab << Align(2, 3, FBB::center)
solicita el centrado del elemento [2][3]. Es responsabilidad del programador asegurarse de que dichos elementos existan. Por defecto, todos los elementos están alineados a la derecha.
o
TableBuf &def():
Después de insertar elementos en un objeto TableBuf, su número de elementos puede ser o no un múltiplo entero del número de columnas especificado en el momento de la construcción. Para `completar' un objeto TableBuf para que sea un objeto rectangular, para el cual se han determinado todos los anchos de columna y alineaciones, se puede llamar a def. Se llama automáticamente por operator<<(ostream, TableBuf). En otras situaciones, puede llamarse explícitamente para forzar la inserción de otra fila en una tabla usando inserciones ROWWISE. Con inserciones COLUMNWISE, su funcionamiento es complejo, ya que los nuevos elementos añadidos a una tabla rellenada en COLUMNWISE reorganizarán sus elementos entre las columnas de la tabla.
o
setFieldSeparator(char fs):
El separador de campos predeterminado es el carácter de `retroceso' (\b). Después de insertar un separador de campos, se definirá el siguiente elemento de la tabla. La inserción de dos separadores de campos inserta un elemento de tabla vacío y comienza la definición del siguiente elemento. Este carácter separador de campos se puede redefinir con esta función. Llamar a setFieldSeparator sin argumentos deshabilita el uso de un carácter separador de campos, y solo deja el uso del manipulador fs para pasar al siguiente campo.
o
setRowSeparator(char rs):
El separador de filas predeterminado es el carácter de nueva línea (\n). Después de insertar un separador de filas, el siguiente elemento a insertar en la tabla será el elemento más a la izquierda de la siguiente fila. La inserción de dos separadores de filas añade una fila vacía a la tabla. Llamar a setRowSeparator sin argumentos deshabilita el uso de un carácter separador de filas, y solo deja el uso del manipulador rs para pasar al siguiente campo.

MANIPULADORES

o
Table &def(Table &table):
Este manipulador se puede insertar en el ostream que envuelve un TableBuf para llamar al miembro def() de la tabla.
o
FBB::fs:
Este manipulador se puede insertar en el ostream que envuelve un TableBuf para pasar al siguiente campo de la tabla. Es una alternativa al uso del carácter separador de campos.
o
FBB::rs:
Este manipulador se puede insertar en el ostream que envuelve un TableBuf para pasar a la siguiente fila de la tabla. Es una alternativa al uso del carácter separador de filas.

EJEMPLO

#include <iostream>
#include <ostream>
#include <string>
#include <algorithm>
#include <iterator>
#include <bobcat/tablebuf>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main()
{
    TableLines tablelines;
    tablelines << 0;            // establece los anchos de los separadores
    for (size_t sep = 0; sep != 8; ++sep)
        tablelines << 3;
    TableBuf tab(tablelines, 8, TableBuf::ROWWISE);
    ostream out(&tab);
    copy(istream_iterator<string>(cin), istream_iterator<string>(),
            ostream_iterator<string>(out, "\b"));
    cout << tab << ’\n’;            // completa la tabla e inserta
}
