tar_append_tree(3)

Paquete: libtar

tar_extract_all(3) Llamadas a la biblioteca C tar_extract_all(3)

NOMBRE

tar_extract_all, tar_extract_glob, tar_append_tree - funciones de manipulación de archivos tar de alto nivel

SINOPSIS

#include <libtar.h>

int tar_extract_all(TAR *t, char *prefix);

int tar_extract_glob(TAR *t, char *globname, char *prefix);

int tar_append_tree(TAR *t, char *realdir, char *savedir);

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función tar_extract_all() extrae todos los archivos del archivo tar asociado con el manejador TAR t en la ruta nombrada por el argumento prefix.

La función tar_extract_glob() extrae todos los archivos que coinciden con el patrón glob dado del archivo tar asociado con el manejador TAR t en la ruta nombrada por el argumento prefix.

La función tar_append_tree() añade todos los archivos del árbol de directorios nombrado por realdir al archivo tar asociado con el manejador TAR t. Los nombres de ruta almacenados en el archivo tar se modifican reemplazando realdir con savedir, de modo que los archivos se extraerán en savedir.

VALORES DE RETORNO

Al completarse con éxito, estas funciones devolverán 0. En caso de error, devolverán -1 y establecerán errno a un valor apropiado.

ERRORES

Estas funciones fallarán bajo las mismas condiciones que las funciones tar_skip_regfile(), tar_extract_regfile(), opendir(), lstat(), o tar_append_file().

VER TAMBIÉN

opendir(2), lstat(2), tar_skip_regfile(3), tar_extract_regfile(3), tar_append_file(3)
