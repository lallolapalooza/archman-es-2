FBB::Table(3bobcat) Table-formatter FBB::Table(3bobcat)

NOMBRE

FBB::Table - Genera tablas rellenadas por filas o columnas

SINOPSIS

#include <bobcat/table>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos FBB::Table se pueden usar para crear tablas. Las tablas se rellenan por columna o por fila. Muchas de las características de la tabla se pueden ajustar finamente utilizando un objeto FBB::TableSupport separado (cf. tablesupport(3bobcat)). Cuando no se utiliza ningún objeto FBB::TableSupport, se construye una tabla simple, rellenada por fila o columna, que se puede insertar en un std::ostream.

Las tablas definidas por Table consisten en filas y un número fijo de columnas. El número de columnas se especifica en el momento de la construcción, el número de filas también depende del número de elementos insertados. Las columnas y filas se abordan mediante índices (a partir de 0). Antes de la columna más a la izquierda, entre las columnas y más allá de la última columna se definen separadores. Por defecto, estos separadores están vacíos, pero a cada separador se le puede dar un ancho o contenido (fijo). El separador antes de la columna col se aborda como separador col, el separador más a la derecha se aborda como separador nColummns.

Las filas también se pueden separar entre sí utilizando separadores. Estas filas separadoras están vacías por defecto. El separador de fila antes de la fila row se aborda como separador-fila row. El separador de fila después de la última fila se aborda como separador-fila nRows, donde nRows es el valor devuelto por la función miembro nRows.

Los separadores no predeterminados (es decir, no vacíos) se definen utilizando objetos FBB::TableSupport (cf. tablesupport(3bobcat)).

Los objetos Table se parecen mucho a los objetos ostream, utilizando una forma sencilla de definir nuevos elementos: cada inserción nueva define otro elemento de tabla, y es difícil terminar una fila antes de que haya recibido su número de elementos nColumn. La clase hermana de Table, TableBuf, es una clase de tipo std::streambuf, que ofrece control adicional a través del uso de un objeto de clase ostream envolvente.

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página de manual están definidos en el espacio de nombres FBB.

HEREDA DE

std::ostringstream - Table hereda de std::ostringstream, lo que permite inserciones en un objeto Table. Cada inserción separada añade otro elemento al objeto Table.

FBB::TableBase - Esta clase implementa elementos comunes de la implementación de la tabla. La clase TableBase no está pensada para ser utilizada por sí sola, y no se proporciona una página de manual separada. Las facilidades proporcionadas por Table que se heredaron de TableBase se describen en esta página de manual.

ENUMERACIONES

Las siguientes enumeraciones están definidas por la clase FBB::Table: enum FillDirection
Esta enumeración define dos valores:

o
ROWWISE:
Cuando se especifica este valor en el momento de la construcción, los elementos se añaden a la tabla por filas. Es decir, el segundo elemento insertado en Table se encontrará en la segunda columna de la primera fila;
o
COLUMNWISE:
Cuando se especifica este valor en el momento de la construcción, los elementos se añaden a la tabla por columnas. Es decir, el segundo elemento se encuentra en la segunda fila de la primera columna.

enum WidthType
Esta enumeración define dos valores:

o
COLUMNWIDTH:
Especifique este valor cuando las columnas puedan tener anchos variables. En este caso, cada columna será tan ancha como su elemento más ancho. Este es el WidthType predeterminado utilizado por los objetos Table.
o
EQUALWIDTH:
Especifique este valor cuando todas las columnas de la tabla deban tener anchos iguales (es decir, iguales al ancho del elemento de tabla más ancho),

CONSTRUCTORES

o
Table(size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
Se deben proporcionar el número de columnas de la tabla, las direcciones de relleno y el tipo de ancho de columna. El número de filas se deduce de la combinación de este parámetro y el número de elementos que se insertan realmente en el objeto Table. El parámetro direction especifica la forma en que se añaden nuevos elementos al objeto Table: por filas o por columnas. Finalmente, el parámetro widthType se utiliza para especificar la forma en que se determina el ancho de las columnas de la tabla. Cada columna define su propio ancho o todas las columnas tienen anchos iguales.
o
Table(TableSupport &tableSupport, size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
Este constructor opera de manera idéntica al constructor anterior, pero espera una referencia adicional a un objeto TableSupport. Un objeto TableSupport ofrece características de formato adicionales utilizadas por los elementos que definen la tabla, como líneas horizontales entre filas, separadores adicionales, etc. El objeto TableSupport se pasa como una referencia no constante, ya que el objeto Table debe poder manipular sus datos. Consulte tablesuppport(3bobcat) para obtener más información sobre TableSupport.

Los constructores de copia y movimiento (y los operadores de asignación) no están disponibles.

OPERADORES SOBRECARGADOS

o
std::ostream &operator<<(std::ostream &str, Table &table):
Este operador inserta una Table en un objeto std::ostream. Este operador requiere una tabla no constante, ya que puede tener que completar la tabla añadiendo elementos vacíos (es decir, cadenas vacías) para obtener una tabla rectangular completamente rellena;
o
Table &operator<<(Table &obj, Align const &align):
Este operador cambia la alineación predeterminada de una columna o un elemento. Es un envoltorio alrededor del miembro setAlign (ver más abajo para su descripción). Por defecto, todos los elementos están alineados a la derecha (ver también align(3bobcat));
o
Table &operator<<(Table &obj, Type const &item):
Este operador se define como una plantilla de función: Type es un parámetro de tipo plantilla instanciado a un tipo para el cual son posibles las inserciones en std::ostringstream. Inserta el valor/objeto item en el objeto de clase base std::ostringstream de la Table como el siguiente elemento de la tabla.

FUNCIONES MIEMBRO

o
Table &append(std::string const &text char const *sep = " \t", bool addEmpty = false):
Los campos en text separados por uno de los caracteres en sep se añaden como elementos al objeto Table. Los campos vacíos se ignoran a menos que el parámetro addEmpty sea true;
o
void clear():
Se borra el contenido de la tabla;
o
void clearStr():
Se borra el contenido del buffer de su clase base std::ostringstream;
o
Table &def():
Después de insertar elementos en un objeto Table, su número de elementos puede o no ser un múltiplo entero del número de columnas especificado en la construc

DESCRIPCIÓN

void def()
Este miembro se llama para completar un objeto Table a un objeto rectangular, para el cual todos los anchos de columna y alineaciones se han determinado. def puede ser llamado. Es llamado automáticamente por operator<<(ostream, Table). En otras situaciones, puede ser llamado explícitamente para forzar la inserción de otra fila en una tabla usando inserciones ROWWISE. Con inserciones COLUMNWISE su funcionamiento es complejo, ya que los nuevos elementos añadidos a una tabla completada COLUMNWISE reorganizarán sus elementos a través de las columnas de la tabla;
o
void fill(InputIterator begin, InputIterator end):
Este miembro está definido como una plantilla miembro; InputIterator es un parámetro de tipo plantilla que representa cualquier iterador de entrada. También puede ser, por ejemplo, un puntero a un tipo insertable. Los iteradores deben apuntar a elementos de datos que puedan ser insertados en un std::ostream. El rango de valores implícito por el par de iteradores del miembro se insertan en la tabla como nuevos elementos;
o
void push_back(std::string const &element):
Se pueden añadir nuevos elementos a la tabla usando push_back. Podría, por ejemplo, ser llamado desde un adaptador back_inserter;
o
size_t nRows():
Se devuelve el número actual de filas de la tabla. Se inicializa a 0, y después se actualiza cuando se ha llamado a def;
o
Table &setAlign(Align const &align):
El tipo de alineación de una columna o un elemento del objeto Table se define usando setAlign. Las alineaciones estándar std::left, std::right y std::internal pueden ser especificadas, pero además la alineación FBB::center puede ser utilizada si los elementos deben ser centrados en su columna. Una construcción como 
tab << Align(2, FBB::center)
solicita el centrado de todos los elementos en la columna de la tabla con índice 2 (es decir, la 3ª columna de la tabla), mientras que una construcción como 
tab << Align(2, 3, FBB::center)
solicita el centrado del elemento [2][3]. Es responsabilidad del programador asegurarse de que dichos elementos existan. Por defecto, todos los elementos están alineados a la derecha. )

MANIPULADORES

o
Table &def(Table &table):
Este manipulador puede ser insertado en una tabla para llamar al miembro def de la tabla.

EJEMPLO

#include <iostream>
#include <bobcat/table>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    TableLines tablelines;
                                // ancho/separadores de cols 0, 1 y 2
    tablelines << 0 << " | " << " | ";
                                // hline sobre cols 1 y 2 de la fila 1
    tablelines << TableLines::HLine(1, 1, 3);
    Table tab(tablelines, 3, Table::ROWWISE, Table::EQUALWIDTH);
    // o: Table tab(tablelines, 3, Table::ROWWISE);
    tab << Align(0, std::left);     // establecer alineación no predeterminada de columna
    tab.fill(argv + 1, argv + argc);// llenar rango de valores
    cout << tab << ’\n’;            // completar la tabla e insertar
    tab << "hello" << "" << "wo";   // añadir elementos adicionales.
    if (tab.nRows() > 2)
        tab << Align(2, 2, center); // establecer el diseño de un elemento específico
    cout << tab << ’\n’;
}
