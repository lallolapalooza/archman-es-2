NOMBRE

tailcall - Reemplaza el procedimiento actual por otro comando

SINOPSIS

tailcall comando ?arg ...?

DESCRIPCIÓN

El comando tailcall reemplaza el procedimiento, la aplicación lambda o el método que se está ejecutando actualmente por otro comando. El comando, al que se le pasarán arg ... como argumentos si se suministran, se buscará en el contexto del espacio de nombres actual, no en el del llamador. Aparte de esta diferencia en la resolución, es equivalente a:

return [uplevel 1 [list comando ?arg ...?]]

Este comando no puede invocarse desde dentro de un uplevel hacia un procedimiento o dentro de un catch dentro de un procedimiento o lambda.

EJEMPLO

Calcular el factorial de un número.

proc factorial {n {accum 1}} {
    if {$n < 2} {
        return $accum
    }
    tailcall factorial [expr {$n - 1}] [expr {$accum * $n}]
}

Imprimir los elementos de una lista con líneas alternas que tienen diferentes indentaciones.

proc printList {theList} {
    if {[llength $theList]} {
        puts "> [lindex $theList 0]"
        tailcall printList2 [lrange $theList 1 end]
    }
}
proc printList2 {theList} {
    if {[llength $theList]} {
        puts "< [lindex $theList 0]"
        tailcall printList [lrange $theList 1 end]
    }
}
