tagmp3(1) Manual de usuario tagmp3(1)

NOMBRE

tagmp3 - manipula etiquetas ID3v1

SINOPSIS

tagmp3 [ -n ] modo [ formato ] [ archivo ] ...

DESCRIPCIÓN

tagmp3 te permite establecer y eliminar etiquetas ID3v1 de archivos mp3. Adicionalmente, el modo move puede usarse para mover archivos mp3 de acuerdo con su etiqueta ID3v1. Una etiqueta ID3v1 es un bloque de información adicional como el nombre del artista, álbum y género. Las etiquetas ID3v1 son mostradas por la mayoría de los reproductores mp3.

MODO

show
muestra la etiqueta ID3v1 del archivo.
set
establece la etiqueta ID3v1 del archivo de acuerdo al formato.
move
mueve el archivo a un destino basado en FORMATO.
del
elimina la etiqueta ID3v1 del archivo si existe.
list
muestra los géneros musicales numéricos junto con su significado.
-h
imprime un mensaje de ayuda (no tan) corto.
-v
imprime la versión y sale.

OPCIONES

-n
Muestra lo que se hará, no altera ningún archivo.

CADENA DE FORMATO

La cadena de formato es una cadena de caracteres compuesta por cero o más directivas: caracteres ordinarios (no %), que no se interpretan y especificaciones de conversión, cada una de las cuales resulta en la sustitución del campo de etiqueta ID3v1 correspondiente. Cada especificación de conversión se introduce con el carácter %. Las siguientes líneas describen cada especificación de conversión junto con su campo ID3v1 asociado. La secuencia especial %% se sustituye por un solo %.

%A
Nombre del Artista
%a
Nombre del Álbum
%t
Título de la Canción
%T
Número de Pista
%y
Año
%g
Género
%c
Comentarios

cadena de formato para modo set

Para el modo set, la cadena de formato es una lista de campos ID3v1 seguida de ':' (los siguientes caracteres son el valor del campo) o '?' (pregunta al usuario por el valor del campo)

ejemplo: tagmp3 set "%A:Pink Floyd %a:The Wall %t? %T?" *.mp3
Para cada mp3 de este directorio, establece el nombre del artista a Pink Floyd y el álbum a The Wall. Para cada archivo, pregunta por el título y el número de pista. Deja los otros campos sin tocar. Ten en cuenta que el campo de género requiere un valor numérico. Los géneros conocidos se pueden mostrar con el modo list.

cadena de formato para modo move

La cadena de formato es la ruta de destino donde cada identificador de campo se sustituye por el valor de la etiqueta.

ejemplo: tagmp3 move "/home/foo/mp3/%A/%a/%T-%t.mp3" *.mp3
con el ejemplo de set anterior moverá todos los mp3 a "/home/foo/mp3/Pink Floyd/The Wall/{track}-{title}.mp3"
Si prefieres el esquema de nombres "plano", usarías algo como
tagmp3 move "%A-%t.mp3" *.mp3

NOTAS

El modo move nunca sobrescribe archivos.
El modo move crea directorios intermedios especificados en la cadena de formato. Cada creación de directorio debe ser confirmada por el usuario.
Las etiquetas ID3v2 no son compatibles hasta ahora.
Si un archivo no se puede mover (tipo de archivo incorrecto, etiqueta ID3v1 ausente o campo en blanco, ...), entonces se deja sin modificar.
Los mp3 falsos (es decir, archivos Wave con extensión .mp3) se mueven al directorio "fake-mp3/" en modo move. El modo set se niega a etiquetarlos ya que esto añadiría artefactos ruidosos al final de la canción.

ERRORES

Muchos :)
Para el modo move, el origen y el destino deben residir en el mismo sistema de archivos / partición.
