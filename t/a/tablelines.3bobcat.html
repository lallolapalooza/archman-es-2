FBB::TableLines(3bobcat) Clase de soporte de tabla FBB::TableLines(3bobcat)

NOMBRE

FBB::TableLines - Una especialización de TableSupport que escribe líneas de separación horizontales

SINOPSIS

#include <bobcat/tableLines>
Opción de enlazado: -lbobcat

DESCRIPCIÓN

Esta clase es una especialización de FBB::TableSupport y puede ser utilizada para escribir separadores de línea horizontales (y verticales) en tablas generadas por objetos Table o TableBuf.

ESPACIO DE NOMBRES

FBB
Todos los constructores, miembros, operadores y manipuladores mencionados en esta página del manual están definidos en el espacio de nombres FBB.

HEREDA DE

FBB::TableSupport

CONSTRUCTORES

Los constructores por defecto y de movimiento, y el operador de asignación de movimiento están disponibles.

FUNCIONES MIEMBRO

Todos los miembros públicos de TableSupport están disponibles. Consulte la página del manual tablesupport(3bobcat) para ver los detalles.

EJEMPLO

#include <iostream>
#include <bobcat/table>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    TableLines tablelines;
                                // ancho/separadores de las columnas 0, 1 y 2
    tablelines << 0 << " | " << " | ";
                                // línea horizontal sobre las columnas 1 y 2 de la fila 1
    tablelines << TableLines::HLine(1, 1, 3);
    Table tab(tablelines, 3, Table::ROWWISE, Table::EQUALWIDTH);
    // o: Table tab(tablelines, 3, Table::ROWWISE);
    tab << Align(0, std::left);     // establecer alineación de columna no predeterminada
    tab.fill(argv + 1, argv + argc);// llenar rango de valores
    cout << tab << ’\n’;            // completar la tabla e insertar
    tab << "hello" << "" << "wo";   // añadir elementos adicionales.
    if (tab.nRows() > 2)
        tab << Align(2, 2, center); // establecer el diseño de un elemento específico
    cout << tab << ’\n’;
}
