NOMBRE

taskwarrior-tui — Una interfaz de usuario de terminal para taskwarrior (https://github.com/kdheepak/taskwarrior-tui)

SINOPSIS

taskwarrior-tui

taskwarrior-tui es una interfaz de usuario de terminal para taskwarrior.

EJEMPLOS

taskwarrior-tui
Inicia una interfaz de usuario de terminal para taskwarrior.
alias tt=taskwarrior-tui
Añade lo anterior a tus archivos de configuración para usar tt para iniciar taskwarrior-tui.

NAME

taskwarrior-tui — Tarea de interfaz gráfica de usuario para Taskwarrior

SYNOPSIS

taskwarrior-tui [--config <config_file>] [--debug] [--no-color] [--font-size <size>] [--theme <theme_file>]

EXAMPLES

Iniciar la interfaz gráfica de usuario de Taskwarrior con el tema predeterminado:

$ taskwarrior-tui

Iniciar con un archivo de configuración personalizado:

$ taskwarrior-tui --config ~/.config/taskwarrior-tui/config.yml

Iniciar con un tema personalizado:

$ taskwarrior-tui --theme ~/.config/taskwarrior-tui/themes/mytheme.yml

KEYBINDINGS

La mayoría de las combinaciones de teclas se pueden encontrar en la documentación de Taskwarrior:

https://taskwarrior.org/docs/keybindings.html

Las siguientes combinaciones de teclas son específicas de taskwarrior-tui:

  • g<motion> : Ir a la línea <motion>.
  • G : Ir a la última línea.
  • l : Ampliar.
  • h : Reducir.
  • v : Seleccionar.
  • V : Seleccionar línea.
  • <C-a> : Seleccionar todo.
  • <C-d> : Deseleccionar.
  • y : Copiar selección.
  • p : Pegar.
  • u : Deshacer.
  • r : Rehacer.
  • q : Salir.

EXIT STATUSES

El código de salida 0 indica éxito. Cualquier otro valor indica un error.
