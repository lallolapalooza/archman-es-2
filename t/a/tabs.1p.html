TABS(1P) Manual del Programador de POSIX TABS(1P)

PROLOG

Esta página del manual forma parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tabs — establecer tabulaciones de terminal

SINOPSIS

tabs [-n|-a|-a2|-c|-c2|-c3|-f|-p|-s|-u] [-T tipo]
tabs [-T tipo] n[[sep[+]n]...]

DESCRIPCIÓN

La utilidad tabs mostrará una serie de caracteres que primero borran la configuración de tabulación de hardware de la terminal y luego inicializan las posiciones de tabulación en las posiciones especificadas y, opcionalmente, ajustan el margen.

La frase "posición de tabulación N" se tomará como que, desde el inicio de una línea de salida, al tabular a la posición N hará que el siguiente carácter de salida esté en la posición de columna (N+1) en esa línea. El número máximo de posiciones de tabulación permitidas depende de la terminal.

Es posible que no se pueda implementar tabs en ciertas terminales. Si el tipo de terminal obtenido de la variable de entorno TERM o la opción -T representa una terminal de este tipo, se escribirá un mensaje de diagnóstico apropiado en el error estándar y tabs saldrá con un estado mayor que cero.

OPCIONES

La utilidad tabs cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Guías de Sintaxis de Utilidades, excepto por varias extensiones: las opciones -a2, -c2 y -c3 son de varios caracteres.

Se soportarán las siguientes opciones:

-n
Especifica posiciones de tabulación repetitivas separadas por un número uniforme de posiciones de columna, n, donde n es un dígito decimal de un solo dígito. El uso predeterminado de tabs sin argumentos será equivalente a tabs -8. Cuando se usa -0, las posiciones de tabulación se borrarán y no se establecerán nuevas.
-a
1,10,16,36,72
Ensamblador, aplicable a algunos mainframes.
-a2
1,10,16,40,72
Ensamblador, aplicable a algunos mainframes.
-c
1,8,12,16,20,55
COBOL, formato normal.
-c2
1,6,10,14,49
COBOL, formato compacto (columnas 1 a 6 omitidas).
-c3
1,6,10,14,18,22,26,30,34,38,42,46,50,54,58,62,67
Formato compacto COBOL (columnas 1 a 6 omitidas), con más tabulaciones que -c2.
-f
1,7,11,15,19,23
FORTRAN
-p
1,5,9,13,17,21,25,29,33,37,41,45,49,53,57,61
PL/1
-s
1,10,55
SNOBOL
-u
1,12,20,44
Ensamblador, aplicable a algunos mainframes.
-T tipo
Indica el tipo de terminal. Si no se proporciona esta opción y la variable TERM no está establecida o está vacía, se utilizará un tipo de terminal predeterminado no especificado. La configuración de tipo tendrá prioridad sobre el valor en TERM.

OPERANDOS

Se soportará el siguiente operando:

n[[sep[+]n]...]
Un único argumento de línea de comandos que consta de uno o más valores de posición de tabulación (n) separados por un carácter separador (sep) que es una <coma> o un <espacio>. La aplicación garantizará que los valores de las posiciones de tabulación sean enteros decimales positivos en orden estrictamente ascendente. Si algún valor de posición de tabulación (excepto el primero) va precedido por un <signo más>, se toma como un incremento que se agregará al valor anterior. Por ejemplo, las listas de tabulación 1,10,20,30 y "110+10+10" se consideran idénticas.

STDIN

No se utiliza.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de tabs:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de configuración regional).
LC_ALL
Si se establece en un valor de cadena no vacío, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la configuración regional para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en argumentos).
LC_MESSAGES

Determina la configuración regional que se debe utilizar para afectar el formato y el contenido de los mensajes de diagnóstico escritos en el error estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.
TERM
Determina el tipo de terminal. Si esta variable no está establecida o está vacía, y si la opción -T no se especifica, se utilizará un tipo de terminal predeterminado no especificado.

EVENTOS ASINCRONOS

Predeterminado.

STDOUT

Si la salida estándar es una terminal, la secuencia apropiada para borrar y establecer las posiciones de tabulación puede escribirse en la salida estándar en un formato no especificado. Si la salida estándar no es una terminal, ocurren resultados indefinidos.

STDERR

El error estándar se utilizará solo para mensajes de diagnóstico.

USO DE APLICACIÓN

Esta utilidad hace uso de las tabulaciones de hardware de la terminal y la opción stty tabs.

No se recomienda el uso de esta utilidad para aplicaciones.

Algunas unidades de visualización integradas podrían no tener secuencias de escape para establecer posiciones de tabulación, pero pueden configurarse mediante llamadas al sistema internas. En estas terminales, tabs funciona si la salida estándar está dirigida a la terminal; sin embargo, si la salida está dirigida a otro archivo, tabs falla.

RATIONALE

Se consideró la posibilidad de que la utilidad tput manejara todas las funciones descritas en tabs. Sin embargo, se conservó la utilidad separada tabs porque parece más intuitivo usar un comando llamado tabs que tput con una nueva opción. La utilidad tput no admite el establecimiento ni la limpieza de tabulaciones, y no se conoce ninguna versión histórica de tabs que admita la capacidad de establecer paradas de tabulación arbitrarias.

La interfaz tabs de System V es muy compleja; la versión de este volumen de POSIX.1-2017 tiene una lista de funciones reducida, pero muchas de las funciones omitidas se restauraron como parte de la opción XSI aunque los lenguajes y estilos de codificación compatibles son principalmente históricos.

Hubo un sentimiento considerable a favor de especificar solo un medio para restablecer las tabulaciones a un estado conocido, presumiblemente el "estándar" de tabulaciones cada ocho posiciones. Se omitieron las siguientes funciones:

*
Establecer paradas de tabulación a través de la primera línea de un archivo, usando --file. Dado que incluso el SVID no tiene una explicación completa de esta función, es dudoso que se use ampliamente.

En una propuesta temprana, se agregó una opción -t tablist para la coherencia con expand; esto se eliminó más tarde cuando se identificaron inconsistencias con la lista histórica de tabulaciones.

Se consideró agregar una opción -p que mostraría la configuración actual de las tabulaciones para que pudieran guardarse y luego restaurarse. Esto no fue aceptado porque consultar las paradas de tabulación de la terminal no es una capacidad en las instalaciones históricas de terminfo o termcap y podría no ser compatible en una amplia gama de terminales.
