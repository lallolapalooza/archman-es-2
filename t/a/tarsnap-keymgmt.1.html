TARSNAP-KEY MGMT(1) Manual de comandos generales TARSNAP-KEY MGMT(1)

NOMBRE

tarsnap-keymgmt — genera subconjuntos de archivos de clave de tarsnap(1)

SINOPSIS

tarsnap-keymgmt --outkeyfile archivo-clave-nuevo [-r] [-w] [-d] [--nuke] [--passphrased] [--passphrase-mem memmax] [--passphrase-time tiemposeg] archivo-clave ...

tarsnap-keymgmt --print-key-id archivo-clave

tarsnap-keymgmt --print-key-permissions archivo-clave

tarsnap-keymgmt --version

DESCRIPCIÓN

tarsnap-keymgmt lee los archivos de clave proporcionados y escribe un nuevo archivo de clave (especificado por --outkeyfile archivo-clave-nuevo) que contiene solo las claves necesarias para las operaciones especificadas a través de las opciones -r (listar y extraer archivos), -w (escribir archivos), -d (eliminar archivos) y --nuke. Tenga en cuenta que -d implica -r ya que es imposible eliminar un archivo individual sin poder leerlo; mientras que un archivo de clave generado con --nuke se puede usar para eliminar todos los archivos almacenados, pero no archivos individuales.

La siguiente lista muestra qué permisos se requieren para los distintos tarsnap(1) modos de comando.

--recover
requiere (1) -d (eliminación de archivos), (2) -w (creación de archivos), o (3) claves --nuke.
--fsck
requiere (1) claves -w (escritura de archivos) y -r (lectura de archivos), o (2) claves -d (eliminación de archivos).
--fsck-prune
requiere claves -d (eliminación de archivos), ya que necesita poder eliminar archivos corruptos.

Si se especifica la opción --passphrased, se le pedirá al usuario que introduzca una frase de contraseña (dos veces) que se utilizará para cifrar el archivo de clave.

Si se especifica la opción --passphrase-mem memmax, se utilizará un máximo de memmax bytes de RAM en la función de derivación de clave scrypt para cifrar el archivo de clave; puede ser necesario establecer esta opción si se está creando un archivo de clave en un sistema con mucha más RAM que el sistema en el que se utilizará el archivo de clave.

Si se especifica la opción --passphrase-time tiemposeg, se utilizará un máximo de aproximadamente tiemposeg segundos en la función de derivación de clave scrypt para cifrar el archivo de clave.

Tenga en cuenta que si no se especifican las opciones -w, -r, -d o --nuke, se producirá un archivo de clave que no contiene ninguna clave. Esto probablemente no sea muy útil.

La opción --print-key-id archivo-clave muestra el entero de 64 bits correspondiente al número de máquina de la clave. Esto puede ser útil para scripts o interfaces gráficas que gestionan la cuenta de Tarsnap de un usuario, pero es poco probable que sea útil para uso en línea de comandos.

La opción --print-key-permissions archivo-clave muestra los permisos que posee la clave.

La opción --version muestra el número de versión de tarsnap-keymgmt y luego sale.
