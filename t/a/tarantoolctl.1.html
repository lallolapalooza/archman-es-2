TARANTOOLCTL(1) Control de instancias de Tarantool TARANTOOLCTL(1)

NOMBRE

tarantoolctl - una utilidad para controlar instancias de Tarantool

SINOPSIS

tarantoolctl COMANDO [INSTANCIA] [ARCHIVO] [URI] [OPCIONES...]

DESCRIPCIÓN

tarantoolctl puede ser utilizado para introspeccionar y controlar el estado de las instancias de Tarantool.

El "INSTANCIA" representa el nombre de un archivo de instancia.

COMANDOS

Se entienden los siguientes comandos:

start INSTANCIA
Inicia la instancia de Tarantool especificada en la línea de comandos si la instancia no se está ejecutando. Esto no hace nada si la instancia está ejecutándose.
stop INSTANCIA
Detiene la instancia de Tarantool especificada en la línea de comandos si la instancia está ejecutándose. Esto no hace nada si la instancia no está ejecutándose.
status INSTANCIA
Muestra el estado de la instancia de Tarantool especificada en la línea de comandos (iniciada/detenida). Si el archivo pid existe y existe un socket de control activo, el código de retorno es 0. De lo contrario, el código de retorno no es 0. Informa problemas típicos a stderr (por ejemplo, existe el archivo pid y no el socket de control).
restart INSTANCIA
Detiene e inicia la instancia de Tarantool especificada en la línea de comandos si la instancia está ejecutándose. Esto no hace nada si la instancia no está ejecutándose.
logrotate INSTANCIA
Rota los registros de la instancia de Tarantool especificada en la línea de comandos si la instancia está ejecutándose. Esto solo funciona si el registro en archivo está habilitado en el archivo de instancia (parámetro "box.cfg{log=...}"). Las tuberías/syslog no tienen efecto.
check INSTANCIA
Verifica si hay errores de sintaxis en el script de la instancia de Tarantool especificada en la línea de comandos.
enter INSTANCIA
Entra en la consola interactiva de la instancia de Tarantool especificada en la línea de comandos.
eval INSTANCIA ARCHIVO
COMANDO | tarantoolctl eval INSTANCIA
Evalúa un archivo local en la instancia de Tarantool especificada en la línea de comandos si la instancia está ejecutándose. Esto no hace nada si la instancia no está ejecutándose.
connect URI
COMANDO | tarantoolctl connect URI
Se conecta a un puerto de consola de administración a la instancia de Tarantool con la URI especificada en la línea de comandos. Esto admite sockets TCP/Unix.
cat ARCHIVO... [--space=numero_espacio...] [--show-system] [--from=lsn_desde] [--to=lsn_hasta] [--replica=id_replica]
Imprime en stdout el contenido de los archivos .snap/.xlog especificados en la línea de comandos.
play URI ARCHIVO... [--space=numero_espacio...] [--show-system] [--from=lsn_desde] [--to=lsn_hasta] [--replica=id_replica]
Reproduce el contenido de los archivos .snap/.xlog a otra instancia de Tarantool con la URI especificada en la línea de comandos.

OPCIONES

Se entienden las siguientes opciones:

--space=numero_espacio
Filtra la salida por número de espacio. Se puede pasar varias veces.
--show-system
Muestra/reproduce el contenido de los espacios del sistema.
--from=lsn_desde
Muestra/reproduce operaciones a partir de la lsn dada.
--to=lsn_hasta
Muestra/reproduce operaciones hasta la lsn dada.
--replica=id_replica
Filtra la salida por ID de réplica. Se puede pasar varias veces.

CONFIGURACIÓN

El archivo con los valores predeterminados del sistema para tarantoolctl se instala en "/etc/default/tarantool". Este archivo se utiliza cuando tarantoolctl es invocado por root. Cuando es invocado por un usuario local, tarantoolctl primero busca su archivo de valores predeterminados en el directorio actual ("$PWD/.tarantoolctl"), y luego en el directorio principal del usuario actual ("$HOME/.config/tarantool/tarantool"). Si no se encuentra, tarantoolctl recurre a los valores predeterminados integrados:

default_cfg = {
pid_file  = "/var/run/tarantool",
wal_dir   = "/var/lib/tarantool",
memtx_dir = "/var/lib/tarantool",
vinyl_dir = "/var/lib/tarantool",
log       = "/var/log/tarantool",
username  = "tarantool",
}
instance_dir = "/etc/tarantool/instances.enabled"

La mayoría de estos parámetros son similares a los de "box.cfg{}":

pid_file
Directorio para el archivo pid y el archivo de socket de control; tarantoolctl agregará "/nombre_instancia" al nombre del directorio.
wal_dir
Directorio para los archivos *.xlog de solo escritura; tarantoolctl agregará "/nombre_instancia" al nombre del directorio.
memtx_dir
Directorio para los archivos de snapshot *.snap; tarantoolctl agregará "/nombre_instancia" al nombre del directorio.
vinyl_dir
Directorio para los archivos vinyl; tarantoolctl agregará "/nombre_instancia" al nombre del directorio.
log
El lugar donde irá el registro de la aplicación; tarantoolctl agregará "/nombre_instancia.log" al nombre.
username
El usuario que ejecuta la instancia de Tarantool. Este es el nombre de usuario del sistema operativo en lugar del nombre de usuario del cliente de Tarantool. Tarantool cambiará su usuario efectivo a este usuario después de convertirse en un demonio.
instance_dir
El directorio donde se almacenan todos los archivos de instancia para este host. Coloque los archivos de instancia en este directorio o cree enlaces simbólicos.

Como ejemplo completo, puede tomar el script "example.lua" que se incluye con Tarantool y define todas las opciones de configuración.

ESTADO DE SALIDA

En caso de éxito, se devuelve 0, un código de fallo distinto de cero en caso contrario.
