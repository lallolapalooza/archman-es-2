NOMBRE

task-color - Un tutorial de color para el gestor de tareas pendientes de línea de comandos Taskwarrior.

MONOCROMO AUTOMÁTICO

Cabe mencionar que Taskwarrior es consciente de si su salida se dirige a una terminal, o a un archivo o a través de una tubería. Cuando la salida de Taskwarrior va a una terminal, el color es deseable, pero considere el siguiente comando:

    $ task list > file.txt

¿Realmente queremos todos esos códigos de control de color en el archivo? Taskwarrior asume que no, y temporalmente establece el color en 'off' mientras genera la salida. Esto explica la salida del siguiente comando:

    $ task show | grep '^color '
    color                        off

siempre devuelve 'off', sin importar la configuración, porque la salida se está enviando a una tubería.

Si quisiera esos códigos de color, puede anular este comportamiento estableciendo la variable _forcecolor en on, de esta manera:

    $ task config _forcecolor on
    $ task config | grep '^color '
    color                        on

o anulándolo temporalmente de esta manera:

    $ task rc._forcecolor=on config | grep '^color '
    color                        on

COLORES DISPONIBLES

Taskwarrior tiene un comando 'color' que mostrará todos los colores que es capaz de mostrar. Pruebe esto:

    $ task color

La salida no se puede replicar aquí en una página de manual, pero debería ver un conjunto de muestras de color. Cuántas vea depende de la capacidad de su programa de terminal para renderizarlas.

Debería ver al menos los colores Básicos y Efectos; si los ve, entonces tiene soporte para 16 colores. ¡Si su terminal soporta 256 colores, lo sabrá!

SOPORTE DE 16 COLORES

El soporte básico de color se proporciona a través de colores con nombre:

    black, red, blue, green, magenta, cyan, yellow, white

El color de primer plano (para el texto) se especifica simplemente como uno de los colores anteriores, o no se especifica en absoluto para usar el color de texto predeterminado de la terminal.

El color de fondo se especifica usando la palabra 'on', y uno de los colores anteriores. Algunos ejemplos:

    green                 # texto verde, color de fondo predeterminado
    green on yellow       # texto verde, fondo amarillo
    on yellow             # color de texto predeterminado, fondo amarillo

Estos colores se pueden modificar aún más, haciendo que el primer plano sea negrita, o haciendo que el fondo sea brillante. Algunos ejemplos:

    bold green
    bold white on bright red
    on bright cyan

El orden de las palabras no es importante, por lo que lo siguiente es equivalente:

    bold green
    green bold

Pero la palabra 'on' es importante: los colores antes de 'on' son de primer plano, y los colores después de 'on' son de fondo.

Hay un atributo adicional 'underline' que puede usarse:

    underline bold red on black

Y un atributo 'inverse':

    inverse red

Taskwarrior tiene un comando que te ayuda a visualizar estas combinaciones de colores. Prueba esto:

    $ task color underline bold red on black

Puedes usar este comando para ver cómo funcionan las diversas combinaciones de colores. También verás algunas muestras de colores mostradas, como las anteriores, además de la muestra solicitada.

Algunas combinaciones se ven muy bien, otras se ven terribles. Diferentes programas de terminal implementan versiones ligeramente diferentes de 'red', por ejemplo, por lo que puede ver alguna variación inesperada entre máquinas. El brillo de su pantalla también es un factor.

SOPORTE DE 256 COLORES

Usar 256 colores sigue la misma forma, pero los nombres son diferentes, y algunos colores se pueden referenciar de diferentes maneras. Primero está por número de color, que es así:

    color0
    color1
    color2
    ...
    color255

Esto le da acceso a los 256 colores, pero no le ayuda mucho. Este rango es una combinación de 8 colores básicos (color0 - color7), luego 8 variaciones más brillantes (color8 - color15). Luego un bloque de 216 colores (color16 - color231). Luego un bloque de 24 colores grises (color232 - color255).

El gran bloque de 216 colores (6x6x6 = 216) representa un cubo de color, que se puede direccionar mediante valores RGB de 0 a 5 para cada componente de color. Un valor de 0 significa ninguno de este componente de color, y un valor de 5 significa el componente de color más intenso. Por ejemplo, un rojo brillante se especifica como:

    rgb500

Y un rojo más oscuro sería:

    rgb300

Tenga en cuenta que los tres dígitos representan los tres valores de componente, por lo que en este ejemplo el 5, 0 y 0 representan rojo=5, verde=0, azul=0. Combinar rojo intenso con ningún verde y ningún azul produce rojo. De manera similar, azul y verde son:

    rgb005
    rgb050

Otro ejemplo: el amarillo brillante es una mezcla de rojo brillante y verde brillante, pero sin componente azul, por lo que el amarillo brillante se direcciona como:

    rgb550

Un rosa suave se direcciona como:

    rgb515

Compruebe si está de acuerdo, ejecutando:

    $ task color black on rgb515

Puede notar que el gran bloque de color se representa como 6 cuadrados. Todos los colores del primer cuadrado tienen un valor de rojo de 0. Todos los colores del sexto cuadrado tienen un valor de rojo de 5. Dentro de cada cuadrado, el azul varía de 0 a 5 de izquierda a derecha, y dentro de cada cuadrado el verde varía de 0 a 5, de arriba a abajo. Este esquema requiere acostumbrarse.

El bloque de 24 colores grises también se puede acceder como gray0 - gray23, en una rampa continua de negro a blanco.

MEZCLA DE 16- Y 256-COLORES

Si especifica 16 colores y ve en una terminal de 256 colores, no hay problema. Si intenta lo contrario, especificando 256 colores y viendo en una terminal de 16 colores, se decepcionará, quizás incluso se horrorizará.

Hay un mapeo de color limitado: por ejemplo, si especificara esta combinación:

    red on gray3

está mezclando una especificación de 16 colores y 256 colores. Taskwarrior mapeará red a color1 y continuará. Tenga en cuenta que red y color1 no son exactamente el mismo tono.

Tenga en cuenta también que no hay atributos de negrita o brillante cuando se trata de 256 colores, pero todavía hay subrayado disponible.

LEYENDA

Taskwarrior mostrará ejemplos de todos los colores definidos utilizados en su .taskrc, o tema, si ejecuta este comando:

    $ task color legend

Esto le da un ejemplo de cada uno de los colores, para que pueda ver el efecto, sin necesidad de crear un conjunto de tareas que cumplan cada uno de los criterios de la regla.

REGLAS

Taskwarrior soporta reglas de coloración. Estos son valores de configuración que especifican un color y las condiciones bajo las cuales se utiliza ese color. Por ejemplo, agreguemos algunas tareas:

    $ task add project:Home priority:H pay the bills               (1)
    $ task add project:Home            clean the rug               (2)
    $ task add project:Garden          clean out the garage        (3)

Podemos agregar una regla de color que use un fondo azul para todas las tareas en el proyecto Home:

    $ task config color.project.Home 'on blue'

Usamos comillas alrededor de 'on blue' porque hay dos palabras, pero representan un solo valor en el archivo .taskrc. Ahora supongamos que deseamos usar un color de texto amarillo en negrita para todo el trabajo de limpieza:

    $ task config color.keyword.clean 'bold yellow'

Ahora, ¿qué sucede con la tarea 2, que pertenece al proyecto Home (fondo azul) y también es una tarea de limpieza (primer plano amarillo en negrita)? Los colores se combinan y la tarea se muestra como "amarillo en negrita sobre azul".

Las reglas de color se pueden aplicar por proyecto y palabra clave de descripción, como se muestra, y también por prioridad (o falta de ella), por estado activo, por estar debida o vencida, por tener una etiqueta o haberla etiquetado (quizás la regla más útil) o por ser una tarea recurrente.

Es posible crear una mezcla de reglas muy colorida. Con el soporte de 256 colores, esos colores se pueden hacer sutiles y complementarios, pero sin cuidado, esto puede ser un desastre visual. ¡Tenga cuidado!

En tales casos, considere usar la opción 'rule.color.merge=no' para deshabilitar la mezcla de colores.

COLORES

Taskwarrior admite la personalización del color para cada tarea. Esto le permite configurar colores para las diferentes prioridades, etiquetas, proyectos, vencimientos y más.

La configuración de color se realiza en el archivo taskrc(5). Aquí hay una lista de las reglas de color disponibles:

    color.active
    color.blocked
    color.deleted
    color.due
    color.due.today
    color.keyword
    color.none
    color.overdue
    color.project
    color.recurring
    color.scheduled
    color.strikethrough
    color.stop
    color.tag
    color.timed
    color.waiting

Este es el conjunto de reglas de color tal como se enumeran en el archivo de configuración. Si se especifica una regla de color, se aplicará al color de la tarea.

Aquí hay una lista de las reglas de color que se pueden usar en su archivo taskrc(5). El orden en que se listan aquí es el orden de precedencia, de mayor a menor:

    deleted,completed,active,keyword.,tag.,project.,overdue,scheduled,due.today,due,blocked,blocking,recurring,tagged,uda.

Estas son solo las reglas de color con el prefijo 'color.' eliminado. La regla 'color.deleted' tiene la mayor precedencia y 'color.uda.' la menor.

La regla de palabras clave que se muestra aquí como 'keyword.' corresponde a un patrón comodín, lo que significa 'color.keyword.*', o en otras palabras, todas las reglas de palabras clave.

También existe 'color.project.none', 'color.tag.none' y 'color.uda.priority.none' para representar específicamente datos faltantes.

TEMAS

Taskwarrior admite temas. Lo que esto realmente significa es que con la capacidad de incluir otros archivos en el archivo .taskrc, se pueden incluir diferentes conjuntos de reglas de color.

Para tener una buena idea de cómo se ve un tema de color, intente agregar esta entrada a su archivo .taskrc:

    include dark-256.theme

Puede usar cualquiera de los temas estándar de Taskwarrior:

    dark-16.theme
    dark-256.theme
    dark-blue-256.theme
    dark-gray-256.theme
    dark-green-256.theme
    dark-red-256.theme
    dark-violets-256.theme
    dark-yellow-green.theme
    light-16.theme
    light-256.theme
    solarized-dark-256.theme
    solarized-light-256.theme
    dark-default-16.theme
    dark-gray-blue-256.theme
    no-color.theme

Tenga en cuenta que si está utilizando una terminal con un fondo oscuro, obtendrá mejores resultados utilizando un tema oscuro.

También puede ver cómo el tema coloreará las diversas tareas con el comando:

    $ task color legend

Mejor aún, cree el suyo propio y compártalo. Estaremos encantados de alojar el archivo de tema en https://taskwarrior.org.
