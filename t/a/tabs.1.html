tabs(1) Comandos de usuario tabs(1)

NOMBRE

tabs - establecer paradas de tabulación en el terminal

SINOPSIS

tabs [opciones] [lista-de-paradas-de-tabulacion]

DESCRIPCIÓN

El programa tabs borra y establece paradas de tabulación en el terminal. Esto utiliza las capacidades clear_all_tabs y set_tab de terminfo. Si alguna de ellas está ausente, tabs no puede borrar/establecer las paradas de tabulación. El terminal debe estar configurado para usar tabulaciones físicas, por ejemplo:

stty tab0

Al igual que clear(1), tabs escribe en la salida estándar. Puede redirigir la salida estándar a un archivo (lo que impide que tabs cambie realmente las paradas de tabulación), y más tarde hacer un cat del archivo a la pantalla, estableciendo las paradas de tabulación en ese momento.

Estas son tabulaciones físicas, que no pueden ser consultadas rápidamente por aplicaciones que se ejecutan en el terminal, si es que se pueden consultar. Curses y otras aplicaciones de pantalla completa pueden usar tabulaciones físicas para optimizar su salida al terminal. Si las paradas de tabulación físicas difieren de la información en la base de datos del terminal, el resultado es impredecible. Antes de ejecutar programas de curses, debe restablecer las paradas de tabulación al intervalo estándar

tabs -8

o usar el programa reset, ya que las secuencias de inicialización normales no aseguran que las paradas de tabulación se restablezcan.

OPCIONES

Opciones Generales

-Tnombre
Indica a tabs qué tipo de terminal usar. Si esta opción no se proporciona, tabs utilizará la variable de entorno $TERM. Si esta no está establecida, utilizará la entrada ansi+tabs.
-d
La opción de depuración muestra una línea de regla, seguida de dos líneas de datos. La primera línea de datos muestra las paradas de tabulación esperadas marcadas con asteriscos. La segunda línea de datos muestra las paradas de tabulación reales, marcadas con asteriscos.
-n
Esta opción indica a tabs que verifique las opciones y ejecute cualquier opción de depuración, pero que no modifique la configuración del terminal.
-V
informa la versión de ncurses que se utilizó en este programa y sale.

El programa tabs procesa una única lista de paradas de tabulación. La última opción procesada que define una lista es la que determina la lista a procesar.

Listas Implícitas

Use un solo número como opción, por ejemplo, “-5” para establecer tabulaciones en el intervalo dado (en este caso 1, 6, 11, 16, 21, etc.). Las tabulaciones se repiten hasta el margen derecho de la pantalla.

Use “-0” para borrar todas las tabulaciones.

Use “-8” para establecer las tabulaciones al intervalo estándar.

Listas Explícitas

Se puede definir una lista explícita después de las opciones (esto no usa un “-”). Los valores de la lista deben estar en orden numérico creciente y ser mayores que cero. Se separan por una coma o un espacio, por ejemplo,

tabs 1,6,11,16,21
tabs 1 6 11 16 21

Use un “+” para tratar un número como un incremento relativo al valor anterior, por ejemplo,

tabs 1,+5,+5,+5,+5

lo cual es equivalente al ejemplo 1,6,11,16,21.

Márgenes

Algunos terminales exponen un medio para cambiar sus márgenes izquierdo y derecho. tabs soporta esta característica con una opción.

+m margen
El efecto depende de si el terminal tiene las capacidades de margen:
  • Si el terminal proporciona la capacidad de establecer el margen izquierdo, tabs la utiliza y ajusta los anchos de las paradas de tabulación disponibles.
  • Si el terminal no proporciona las capacidades de margen, tabs imita su efecto, colocando paradas de tabulación en lugares apropiados en cada línea. El margen izquierdo del terminal no se modifica.
Si se omite el parámetro margen, el valor predeterminado es 10. Use +m0 para restablecer el margen izquierdo, es decir, para que sea el borde izquierdo de la pantalla del terminal. Antes de establecer un margen izquierdo, tabs restablece el margen para reducir los problemas que pudieran surgir al mover el cursor a la izquierda del margen izquierdo actual.

Al establecer o restablecer el margen izquierdo, tabs también puede restablecer el margen derecho.

PORTABILIDAD

IEEE Std 1003.1/The Open Group Base Specifications Issue 7 (POSIX.1-2008) describe una utilidad tabs. Sin embargo,

  • este estándar describe una opción +m para establecer el margen izquierdo de un terminal. Muy pocas de las entradas en la base de datos del terminal proporcionan las capacidades set_left_margin (smgl) o set_left_margin_parm (smglp) necesarias para soportar esta característica.
  • No hay una contraparte en X/Open Curses Issue 7 para esta utilidad, a diferencia de tput(1).

Las opciones -d (depurar) y -n (no operar) son extensiones de ncurses no proporcionadas por otras implementaciones.

HISTORIA

Una utilidad tabs apareció en PWB/Unix 1.0 (1977). Una versión reducida se distribuyó en Seventh Edition Unix (principios de 1979) y en 3BSD (más tarde ese año); soportaba una opción “-n” para establecer la primera parada de tabulación en el margen izquierdo. Esa opción no está especificada por POSIX.

La utilidad tabs de PWB/Unix regresó en System III (1980), y usó tablas incorporadas para soportar media docena de tipos de terminales de impresión (hardcopy). También tenía lógica para soportar el establecimiento del margen izquierdo, así como una característica para copiar la configuración de tabulación desde un archivo.

Las versiones del programa en lanzamientos posteriores de AT&T Unix, como SVr4, añadieron soporte para la base de datos de terminales, pero mantuvieron las tablas para soportar las impresoras. Para entonces, tput de System V había incorporado la característica de inicialización de paradas de tabulación de tset de BSD de 1982, pero la empleó para ello utilizando la base de datos de terminfo.

La opción +m se documentó en las POSIX Base Specifications Issue 5 (Unix98, 1997), luego se omitió en la Issue 6 (Unix03, 2004) sin motivación expresa, aunque un comentario introductorio “y opcionalmente ajusta el margen” permanece, pasado por alto en la eliminación. La utilidad tabs documentada en las Issues 6 y posteriores no tiene un mecanismo para establecer márgenes. PORTABILITY

The POSIX standard specifies that the tabs utility should set tab stops to columns 8, 16, 24, and 32, unless overridden by the -t option.

The -t option is intended to provide an arbitrary list of tab stops. POSIX specifies that the tab stops be set to columns 1, 2, 3, ..., 64, unless overridden by the -t option. The default list of tab stops is an implementation-defined value; the default is 1, 10, 16, 24, 32, 40, 48, 56, 64.

POSIX documents no limit on the number of tab stops. Other implementations impose one; the limit is 20 in PWB/Unix's tabs utility. While some terminals may not accept an arbitrary number of tab stops, ncurses tabs attempts to set tab stops up to the right margin if the list thereof is sufficiently long.

The “Rationale” section of the Issue 6 tabs reference page details how the committee considered redesigning the tabs and tput utilities, without settling on an improved solution. It claims that

“no known historical version of tabs supports the capability of setting arbitrary tab stops.”

The feature described in subsection “Explicit Lists” above was implemented in PWB/Unix, and permitted the setting of abitrary tab stops nevertheless.

HISTORY

A tabs command appeared in Version 1 AT&T UNIX. The option syntax has evolved. The capability to set tab stops for arbitrary columns was added in PWB/UNIX.

The tabs utility was rewritten for the 4.3BSD-Reno release to support terminfo. This version is derived from that utility.
