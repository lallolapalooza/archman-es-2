DESCRIPCIÓN

Estas macros definen y operan sobre colas de doble enlace con cola.

En las definiciones de las macros, TIPO es el nombre de una estructura definida por el usuario, que debe contener un campo de tipo TAILQ_ENTRY, llamado NOMBRE. El argumento NOMBRE_CABECERA es el nombre de una estructura definida por el usuario que debe declararse usando la macro TAILQ_HEAD().

Creación

Una cola de cola está encabezada por una estructura definida por la macro TAILQ_HEAD(). Esta estructura contiene un par de punteros, uno al primer elemento de la cola y otro al último elemento de la cola. Los elementos están enlazados doblemente para que un elemento arbitrario pueda ser eliminado sin recorrer la cola. Se pueden añadir nuevos elementos a la cola después de un elemento existente, antes de un elemento existente, al principio de la cola o al final de la cola. Una estructura TAILQ_HEAD se declara de la siguiente manera:


TAILQ_HEAD(NOMBRE_CABECERA, TIPO) cabecera;

donde struct NOMBRE_CABECERA es la estructura a definir, y struct TIPO es el tipo de los elementos a enlazar en la cola. Un puntero a la cabecera de la cola se puede declarar posteriormente como:


struct NOMBRE_CABECERA *puntero_cabecera;

(Los nombres cabecera y puntero_cabecera son seleccionables por el usuario.)

TAILQ_ENTRY() declara una estructura que conecta los elementos de la cola.

TAILQ_HEAD_INITIALIZER() evalúa a un inicializador para la cola cabecera.

TAILQ_INIT() inicializa la cola referenciada por

TAILQ_EMPTY() evalúa a verdadero si no hay elementos en la cola. cabecera.

Inserción

TAILQ_INSERT_HEAD() inserta el nuevo elemento elem al principio de la cola.

TAILQ_INSERT_TAIL() inserta el nuevo elemento elem al final de la cola.

TAILQ_INSERT_BEFORE() inserta el nuevo elemento elem antes del elemento elem_lista.

TAILQ_INSERT_AFTER() inserta el nuevo elemento elem después del elemento elem_lista.

Recorrido

TAILQ_FIRST() devuelve el primer elemento de la cola, o NULL si la cola está vacía.

TAILQ_LAST() devuelve el último elemento de la cola. Si la cola está vacía, el valor de retorno es NULL.

TAILQ_PREV() devuelve el elemento anterior de la cola, o NULL si este elemento es el primero.

TAILQ_NEXT() devuelve el siguiente elemento de la cola, o NULL si este elemento es el último.

TAILQ_FOREACH() recorre la cola referenciada por cabecera en la dirección hacia adelante, asignando cada elemento en turno a var. var se establece en NULL si el bucle se completa normalmente, o si no había elementos.

TAILQ_FOREACH_REVERSE() recorre la cola referenciada por cabecera en la dirección inversa, asignando cada elemento en turno a var.

Eliminación

TAILQ_REMOVE() elimina el elemento elem de la cola.

Otras características

TAILQ_CONCAT() concatena la cola encabezada por cabecera2 al final de la encabezada por cabecera1, eliminando todas las entradas de la primera.

VALOR DE RETORNO

TAILQ_EMPTY() devuelve un valor distinto de cero si la cola está vacía, y cero si la cola contiene al menos una entrada.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), y TAILQ_NEXT() devuelven un puntero a la estructura TIPO primera, última, anterior o siguiente, respectivamente.

TAILQ_HEAD_INITIALIZER() devuelve un inicializador que puede ser asignado a la cola cabecera.

ESTÁNDARES

BSD.

HISTORIA

4.4BSD.

ADVERTENCIAS

TAILQ_FOREACH() y TAILQ_FOREACH_REVERSE() no permiten que var sea eliminado o liberado dentro del bucle, ya que interferiría con el recorrido. TAILQ_FOREACH_SAFE() y TAILQ_FOREACH_REVERSE_SAFE(), que están presentes en los BSD pero no en glibc, solucionan esta limitación al permitir que var sea eliminado de forma segura de la lista y liberado desde dentro del bucle sin interferir con el recorrido.

int
main(void)

    struct entrada *n1, *n2, *n3, *np;
    struct cabecera_cola cabeza;                   /* Cabecera de la cola de cola */
    int i;
    TAILQ_INIT(&cabeza);                      /* Inicializar la cola */

    TAILQ_INSERT_HEAD(&cabeza, n1, entradas);

    TAILQ_INSERT_TAIL(&cabeza, n1, entradas);

    TAILQ_INSERT_AFTER(&cabeza, n1, n2, entradas);

EJEMPLOS

    /* Example of using tailq with a list of integers. */
    #include <sys/queue.h>
    #include <stdio.h>
    #include <stdlib.h>

    struct item {
        int value;
        TAILQ_ENTRY(item) entries;
    };

    TAILQ_HEAD(item_list, item);

    int
    main() {
        struct item_list head;
        struct item *n1, *n2;

        TAILQ_INIT(&head);

        /* Add some items to the list */
        n1 = malloc(sizeof(struct item));
        n1->value = 10;
        TAILQ_INSERT_TAIL(&head, n1, entries);

        n1 = malloc(sizeof(struct item));
        n1->value = 20;
        TAILQ_INSERT_TAIL(&head, n1, entries);

        /* Iterate through the list and print values */
        printf("List items:\n");
        TAILQ_FOREACH(n1, &head, entries) {
            printf("%d\n", n1->value);
        }

        /* Remove and free all items from the list */
        TAILQ_FOREACH_SAFE(n1, &head, entries, n2) {
            TAILQ_REMOVE(&head, n1, entries);
            free(n1);
        }

        /* The list is now empty and ready to be reused. */
        return 0;
    }
