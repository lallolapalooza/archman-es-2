TAN(3P) Manual del programador POSIX TAN(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tan, tanf, tanl — función tangente

SINOPSIS

#include <math.h>
double tan(double x);
float tanf(float x);
long double tanl(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es no intencional. Este volumen de POSIX.1-2017 se remite al estándar ISO C.

Estas funciones calcularán la tangente de su argumento x, medido en radianes.

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, ha ocurrido un error.

VALOR DEVUELTO

Al completarse con éxito, estas funciones devolverán la tangente de x.

Si el valor correcto causara un subdesbordamiento y no fuera representable, puede ocurrir un error de rango, y tan(), tanf() y tanl() devolverán 0.0, o (si no se soporta punto flotante IEC 60559) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es NaN, se devolverá un NaN.

Si x es ±0, se devolverá x.

Si x es subnormal, puede ocurrir un error de rango
y se debe devolver x.

Si x no se devuelve, tan(), tanf() y tanl() devolverán un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN y LDBL_MIN, respectivamente.

Si x es ±Inf, ocurrirá un error de dominio y se devolverá un NaN (si se soporta) o un valor definido por la implementación.

Si el valor correcto causara un subdesbordamiento y fuera representable, puede ocurrir un error de rango y se devolverá el valor correcto.

Si el valor correcto causara un desbordamiento, ocurrirá un error de rango y tan(), tanf() y tanl() devolverán ±HUGE_VAL, ±HUGE_VALF y ±HUGE_VALL, respectivamente, con el mismo signo que el valor correcto de la función.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El valor de x es ±Inf.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante inválida.

Error de Rango
El resultado se desborda.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante por desbordamiento.

Estas funciones pueden fallar si:

Error de Rango
El resultado sufre subdesbordamiento, o el valor de x es subnormal.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se activará la excepción de punto flotante por subdesbordamiento.

Las siguientes secciones son informativas.

EJEMPLOS

Tomando la Tangente de un Ángulo de 45 Grados

#include <math.h>
...
double radianes = 45.0 * M_PI / 180;
double resultado;
...
resultado = tan (radianes);

USO DE LA APLICACIÓN

No existen representaciones de punto flotante conocidas tales que para un argumento normal, tan(x) sea un desbordamiento o subdesbordamiento.

Estas funciones pueden perder precisión cuando su argumento está cerca de un múltiplo de π/2 o está lejos de 0.0.

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
