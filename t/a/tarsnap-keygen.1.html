TARSNAP-KEYGEN(1) Manual de comandos generales TARSNAP-KEYGEN(1)

NOMBRE

tarsnap-keygen — genera un archivo de clave para usar con tarsnap(1)

SINOPSIS

tarsnap-keygen --keyfile archivo-clave --user nombre-usuario --machine nombre-máquina [--passphrased] [--passphrase-mem memmax] [--passphrase-time tiempos]

tarsnap-keygen --version

DESCRIPCIÓN

tarsnap-keygen genera claves criptográficas, se registra en el servidor tarsnap y escribe un archivo de clave para usar con tarsnap(1).

La opción --keyfile archivo-clave especifica el nombre del archivo en el que se escribirán las claves recién generadas. La opción --user nombre-usuario especifica el nombre (es decir, la dirección de correo electrónico) de la cuenta Tarsnap. La opción --machine nombre-máquina especifica un nombre que se mostrará en los informes de contabilidad para que pueda ver cuántos datos está almacenando cada máquina.

Si se especifica la opción --passphrased, se le pedirá al usuario que introduzca una contraseña (dos veces) que se utilizará para cifrar el archivo de clave.

Si se especifica la opción --passphrase-mem memmax, se utilizará un máximo de memmax bytes de RAM en la función de derivación de clave scrypt para cifrar el archivo de clave; puede ser necesario establecer esta opción si se está generando un archivo de clave en un sistema con mucha más RAM que el sistema en el que se utilizará el archivo de clave.

Si se especifica la opción --passphrase-time tiempos, se utilizará un máximo de aproximadamente tiempos segundos en la función de derivación de clave scrypt para cifrar el archivo de clave.

La opción --version imprime el número de versión de tarsnap-keygen, y luego sale.
