NOMBRE

tar_open, tar_close - acceder a un archivo tar a través de un manejador

SINOPSIS

#include <libtar.h>

int tar_open(TAR **t, char *pathname, tartype_t *type, int oflags, int mode, int options);

int tar_fdopen(TAR **t, int fd, char *pathname, tartype_t *type, int oflags, int mode, int options);

int tar_fd(TAR *t");"

int tar_close(TAR *t");"

VERSIÓN

Esta página del manual documenta la versión 1.2 de libtar.

DESCRIPCIÓN

La función tar_open() abre un archivo tar correspondiente al nombre de archivo especificado por el argumento pathname. El argumento oflags debe ser O_RDONLY u O_WRONLY.

El argumento type especifica los métodos de acceso para el tipo de archivo dado. La estructura tartype_t tiene miembros llamados openfunc, closefunc, readfunc() y writefunc(), que son punteros a las funciones para abrir, cerrar, leer y escribir el archivo, respectivamente. Si type es NULL, el tipo de archivo se establece por defecto en un archivo normal y se utilizan las funciones estándar open(), close(), read() y write().

El argumento options es una combinación mediante OR lógico de cero o más de las siguientes opciones:

TAR_GNU
Utiliza extensiones GNU.
TAR_VERBOSE
Envía mensajes de estado a stdout.
TAR_NOOVERWRITE
No sobrescribe archivos preexistentes.
TAR_IGNORE_EOT
Omite los bloques de ceros en lugar de tratarlos como fin de transmisión (EOT).
TAR_IGNORE_MAGIC
No valida el campo mágico en las cabeceras de archivo.
TAR_CHECK_VERSION
Comprueba el campo de versión en las cabeceras de archivo. (Este campo normalmente se ignora).
TAR_IGNORE_CRC
No valida la CRC de las cabeceras de archivo.

La función tar_open() asigna memoria para un manejador TAR, y un puntero a la memoria asignada se guarda en la ubicación especificada por t. El manejador TAR puede pasarse a otras llamadas de libtar para modificar el archivo tar abierto. El manejador TAR mantiene toda la información sobre el archivo tar abierto, incluyendo el type, las options y las oflags del archivo seleccionadas cuando se llamó a tar_open().

El manejador TAR generado por tar_open() contiene una estructura de cabecera de archivo. Al leer un archivo tar, esta estructura contiene la última cabecera de archivo leída del archivo tar. Al escribir un archivo tar, esta estructura se utiliza como un área de preparación para construir la siguiente cabecera de archivo que se escribirá en el archivo. Además, el manejador TAR contiene una tabla hash que se utiliza para realizar un seguimiento de la información del dispositivo e inodo de cada archivo que se escribe en el archivo tar. Esto se utiliza para detectar enlaces duros, de modo que los archivos no necesiten duplicarse en el archivo.

La función tar_fdopen() es idéntica a la función tar_open(), excepto que fd se utiliza como el descriptor de archivo previamente abierto para el archivo tar en lugar de llamar a type->openfunc() para abrir el archivo.

La función tar_fd() devuelve el descriptor de archivo asociado con el manejador TAR t.

La función tar_close() cierra el descriptor de archivo asociado con el manejador TAR t y libera toda la memoria asignada dinámicamente.

VALOR DE RETORNO

Las funciones tar_open(), tar_fdopen() y tar_close() devuelven 0 si tienen éxito. En caso de fallo, devuelven -1 y establecen errno.

La función tar_fd() devuelve el descriptor de archivo asociado con el manejador TAR t.

ERRORES

tar_open() fallará si:

EINVAL
El argumento oflags era algo distinto de O_RDONLY u O_WRONLY.

Además, tar_open() y tar_close() pueden fallar si no pueden asignar memoria usando calloc(), o si las funciones de apertura o cierre para el type de archivo tar especificado fallan.

VER TAMBIÉN
