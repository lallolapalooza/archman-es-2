TOXIC.CONF(5) Manual de Toxic TOXIC.CONF(5)

NOMBRE

toxic.conf - Archivo de configuración para toxic

SINOPSIS

~/.config/tox/toxic.conf

DESCRIPCIÓN

El archivo toxic.conf es el archivo de configuración principal para el cliente toxic(1). Utiliza la sintaxis aceptada por libconfig. Las líneas que comienzan con "//" son comentarios y se ignorarán.

EJEMPLO

// Configuración de la interfaz
ui = {
    timestamps = true;
    alerts = false;
};
// Configuración del audio
audio = {
    input_device = 1;
};

OPCIONES

ui

Configuración relacionada con los elementos de la interfaz.

timestamps

Habilitar o deshabilitar marcas de tiempo. true o false

time_format

Seleccionar entre formato de 24 o 12 horas. Especificar 24 o 12. Establecer timestamp_format y log_timestamp_format anulará esta configuración.

timestamp_format

Cadena de formato de hora para la interfaz entre comillas dobles. Ver date(1)

log_timestamp_format

Cadena de formato de hora para el registro entre comillas dobles. (Nota: la parte de hora de la cadena de formato debe estar entre corchetes para que sea analizada por toxic). Ver date(1)

alerts

Habilitar o deshabilitar alertas acústicas en eventos. true o false

show_notification_content

Mostrar el contenido de las notificaciones de escritorio. true o false

native_colors

Seleccionar entre colores nativos de terminal y el tema de colores de toxic. true o false

color_bar_bg

Establecer el color de fondo de las barras de estado de chat. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

color_bar_fg

Establecer el color de primer plano (texto) de las barras de estado de chat. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

color_bar_accent

Establecer el color de acento de primer plano de las barras de estado de chat. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

color_bar_notify

Establecer el color de notificación (y escritura) de primer plano en la barra de estado del chat. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

autolog

Habilitar o deshabilitar el registro automático. true o false

show_typing_other

Mostrar cuando otros están escribiendo en un chat 1 a 1. true o false

show_typing_self

Mostrar a otros cuando usted está escribiendo en un chat 1 a 1. true o false

show_welcome_msg

Mostrar mensaje de bienvenida al iniciar. true o false

show_connection_msg

Habilitar notificaciones de cambio de conexión de amigos. true o false

show_group_connection_msg

Habilitar notificaciones de cambio de conexión de grupo. true o false

nodelist_update_freq

Con qué frecuencia en días se actualizará la lista de nodos DHT. (entero; 0 para deshabilitar)

autosave_freq

Con qué frecuencia en segundos se guardará automáticamente el archivo de datos de Tox. (entero; 0 para deshabilitar)

history_size

Líneas máximas para el historial de la ventana de chat. Valor entero. (por ejemplo: 700)

notification_timeout

Tiempo en milisegundos para mostrar una notificación. Valor entero. (por ejemplo: 3000)

line_join

Indicador de cuándo alguien se conecta o se une a un grupo. Máximo tres caracteres para la configuración de línea.

line_quit

Indicador de cuándo alguien se desconecta o abandona un grupo.

line_alert

Indicador de mensajes de alerta.

line_normal

Indicador de mensajes normales.

line_padding

Rellenar cada línea envuelta de un mensaje con suficientes espacios para alinearlo al principio de la primera línea. true o false

mplex_away

Establecer el estado del usuario al adjuntar y desadjuntar de GNU screen o tmux. true o false

mplex_away_note

Mensaje de estado a establecer cuando el estado se pone en ausente debido a la desconexión de screen/tmux. Al adjuntar, el mensaje de estado se restaura a su valor original.

group_part_message

Mensaje de salida que se enviará a todos los pares del chat grupal cuando abandones el grupo. 
Las siguientes opciones controlan si se emite una campana de terminal en ciertos eventos.
Algunas terminales marcan la ventana como urgente cuando se recibe una campana. Las ventanas urgentes suelen destacarse en la barra de tareas y algunos administradores de ventanas incluso proporcionan atajos para saltar a la siguiente ventana urgente.
Estas opciones no afectan a la opción "alerts".

bell_on_message

Habilitar/Deshabilitar la campana de terminal al recibir un mensaje. true o false

bell_on_filetrans

Habilitar/Deshabilitar la campana de terminal al recibir una transferencia de archivos. true o false

bell_on_filetrans_accept

Habilitar/Deshabilitar la campana de terminal cuando se acepta una transferencia de archivos. true o false

bell_on_invite

Habilitar/Deshabilitar la campana de terminal al recibir una invitación de grupo/llamada. true o false

audio

Configuración relacionada con los dispositivos de audio.

input_device

Dispositivo de entrada de audio. Valor entero. El número corresponde a /lsdev en

output_device

Dispositivo de salida de audio. Valor entero. El número corresponde a /lsdev fuera

VAD_threshold

Umbral de Detección de Voz (VAD). Valor flotante. Valores recomendados son 1.0-40.0

conference_audio_channels

Número de canales para la transmisión de audio de conferencias. Valor entero. 1 (mono) o 2 (estéreo)

chat_audio_channels

Número de canales para la transmisión de audio 1 a 1. Valor entero. 1 (mono) o 2 (estéreo)

push_to_talk

Habilitar/Deshabilitar Pulsar para Hablar para chats de audio de conferencias (tecla activa es F2). true o false

tox

Configuración relacionada con las rutas.

download_path

Ruta predeterminada para las descargas. Valor de cadena. Ruta absoluta para los archivos descargados.

avatar_path

Ruta para tu avatar (el archivo debe ser un .png y no puede exceder los 16.3 KiB)

autorun_path

Ruta para cualquier script que deba ejecutarse al inicio

chatlogs_path

Ruta predeterminada para los registros de chat. Valor de cadena. Ruta absoluta para los archivos de registro de chat.

password_eval

Reemplaza la solicitud de contraseña ejecutando este comando y usando su salida como contraseña.

friends

Configuración específica de amigos (prioridad sobre la configuración global)

alias

Establece un alias para este amigo. Valor de cadena.

auto_accept_files

Habilitar o deshabilitar la aceptación automática de transferencias de archivos entrantes. true o false

autolog

Habilitar o deshabilitar el registro automático. true o false

show_connection_msg

Habilitar notificaciones de cambio de conexión. true o false

tab_name_colour

El color del nombre de la ventana de pestaña del amigo. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

groupchats

Configuración específica de chats grupales (prioridad sobre la configuración global)

autolog

Habilitar o deshabilitar el registro automático. true o false

tab_name_colour

El color del nombre de la ventana de pestaña del grupo. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

conferences

Ajustes específicos de la conferencia (priorizados sobre los ajustes globales)

autolog

Habilitar o deshabilitar el registro automático. true o false

tab_name_colour

El color del nombre de la ventana de la pestaña de las conferencias. (negro, blanco, gris, marrón, rojo, verde, azul, cian, amarillo, magenta, naranja, rosa)

blocked_words

Una lista de palabras que no distinguen entre mayúsculas y minúsculas que no se pueden enviar en los mensajes. Valor de cadena. Debe estar entre comillas dobles y no debe superar los 256 caracteres.

sounds

Configuración relacionada con los sonidos de notificación. El valor especial "silent" se puede utilizar para deshabilitar una notificación específica.

Cada valor es una cadena que corresponde a la ruta absoluta de un archivo de sonido wav.

notif_error

Sonido a reproducir cuando ocurre un error.

self_log_in

Sonido a reproducir cuando inicias sesión.

self_log_out

Sonido a reproducir cuando cierras sesión.

user_log_in

Sonido a reproducir cuando un contacto se conecta.

user_log_out

Sonido a reproducir cuando un contacto se desconecta.

call_incoming

Sonido a reproducir cuando recibes una llamada entrante.

call_outgoing

Sonido a reproducir cuando inicias una llamada.

generic_message

Sonido a reproducir cuando ocurre un evento.

transfer_pending

Sonido a reproducir cuando recibes una solicitud de transferencia de archivos.

transfer_completed

Sonido a reproducir cuando se completa una transferencia de archivos.

keys

Configuración relacionada con la interacción de la interfaz de usuario. Actualmente se admiten: teclas modificadas por Ctrl, Tab, PAGEUP y PAGEDOWN.

Cada valor es una cadena que corresponde a una combinación de teclas.

next_tab

Combinación de teclas para cambiar a la siguiente pestaña.

prev_tab

Combinación de teclas para cambiar a la pestaña anterior.

scroll_line_up

Combinación de teclas para desplazarse una línea hacia arriba.

scroll_line_down

Combinación de teclas para desplazarse una línea hacia abajo.

half_page_up

Combinación de teclas para desplazarse media página hacia arriba.

half_page_down

Combinación de teclas para desplazarse media página hacia abajo.

page_bottom

Combinación de teclas para desplazarse hasta el final de la página.

toggle_peerlist

Activar y desactivar la lista de peers.

toggle_paste_mode

Activar y desactivar el tratamiento de saltos de línea como pulsación de la tecla Intro.

reload_config

Recargar el archivo de configuración de Toxic.

BUGS

-Los colores no predeterminados (gris, marrón, naranja y rosa) no funcionarán en emuladores de terminal que no admitan 256 colores. Konsole, qterminal y posiblemente otros también tienen problemas con ellos. Si estás usando screen o tmux, intenta configurarlo para que use la variable de entorno TERM xterm-256color.

-Al recargar el archivo de configuración durante una sesión en vivo, algunos cambios en la interfaz de usuario pueden presentar errores y requerir un reinicio completo del cliente.
