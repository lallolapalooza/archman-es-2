NOMBRE

toolbox.conf - Archivo de configuración de Toolbx

DESCRIPCIÓN

Sobrescribe persistentemente el comportamiento predeterminado de toolbox(1). La sintaxis es TOML y los nombres de las opciones coinciden con sus contrapartes de línea de comandos. Actualmente, la única sección compatible es general.

OPCIONES

distro = "DISTRO"

Crea un contenedor de Toolbx para un sistema operativo DISTRO diferente al del host. No se puede usar con image.

image = "NOMBRE"

Cambia el NOMBRE de la imagen utilizada para crear el contenedor de Toolbx. Esto es útil para crear contenedores a partir de imágenes personalizadas. No se puede usar con distro y release.

Si NOMBRE no contiene un registro, se consultará el almacenamiento de imágenes local y, si no está presente allí, se extraerá de un registro remoto adecuado.

release = "RELEASE"

Crea un contenedor de Toolbx para un RELEASE de sistema operativo diferente al del host. No se puede usar con image.

ARCHIVOS

Las siguientes ubicaciones se buscan en orden creciente de prioridad:

/etc/containers/toolbox.conf

Está destinado a ser proporcionado por el distribuidor del sistema operativo o el administrador del sistema, y afecta a todos los usuarios en el host.

Los campos especificados aquí pueden ser sobrescritos por cualquiera de los archivos a continuación.

$XDG_CONFIG_HOME/containers/toolbox.conf

Está destinado a cambios específicos del usuario. Los campos especificados aquí anulan cualquiera de los archivos anteriores.

EJEMPLOS

Sobrescribir la distro del sistema operativo predeterminada:

[general]
distro = "fedora"
release = "36"

Sobrescribir la imagen predeterminada:

[general]
image = "registry.fedoraproject.org/fedora-toolbox:36"
