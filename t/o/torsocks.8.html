NOMBRE

torsocks — Biblioteca para interceptar conexiones de red salientes y redirigirlas a través del proxy SOCKS de Tor.

DESCRIPCIÓN

La biblioteca Torsocks sobrecarga los símbolos de libc utilizados para la comunicación por Internet, como la llamada al sistema connect(2). Utilizando esta técnica, la biblioteca envía todo a través de la red Tor, incluyendo la resolución DNS realizada por la aplicación.

Para DNS, las funciones de la familia gethostbyname(3) se redirigen a través de Tor. Tenga en cuenta que la API res_* de ISC no es compatible actualmente.

Aquí hay un ejemplo de cómo usar la biblioteca torsocks con ssh(1):

$ LD_PRELOAD=/ruta/a/libtorsocks.so ssh -l kalexander -p 1234 prism.nsa.gov [...]

USO DE SHELL

Configure LD_PRELOAD para cargar la biblioteca y luego utilice las aplicaciones como de costumbre. La sintaxis para forzar la precarga de la biblioteca para diferentes shells se especifica a continuación:

Bash, Ksh y Bourne shell:

$ export LD_PRELOAD=/ruta/a/libtorsocks.so

C Shell:

$ setenv LD_PRELOAD=/ruta/a/libtorsocks.so

Este proceso puede automatizarse (para usuarios de Bash, Bourne y Korn shell) para un solo comando o para todos los comandos en una sesión de shell utilizando el script torsocks(1).

También puede configurar torsocks(1) de tal manera que todos los procesos lo utilicen automáticamente, una configuración muy útil. Consulte la documentación del script torsocks para obtener más información.

VARIABLES DE ENTORNO

TORSOCKS_CONF_FILE
Esta variable de entorno anula la ubicación predeterminada del archivo de configuración de torsocks. Esta variable no se respeta si el programa en el que está incrustado torsocks tiene el bit setuid.
TORSOCKS_LOG_LEVEL
Habilita el nivel de registro de la biblioteca torsocks. Por defecto, se imprimen advertencias y errores (nivel 3). Tenga en cuenta que cada nivel incluye los inferiores, excepto el 1, que deshabilita cualquier registro posible. (predeterminado: 3)
1 Sin registro.
2 Mensajes de error.
3 Mensajes de advertencia.
4 Mensajes de notificación.
5 Mensajes de depuración.
TORSOCKS_LOG_TIME
Controla si se agrega la hora a cada línea de registro. (predeterminado: 1)
TORSOCKS_LOG_FILE_PATH
Si se establece, torsocks registrará en el archivo especificado por esta variable. (predeterminado: stderr)
TORSOCKS_USERNAME
Establece el nombre de usuario para el método de autenticación SOCKS5. La contraseña DEBE establecerse también con la variable siguiente.
TORSOCKS_PASSWORD
Establece la contraseña para el método de autenticación SOCKS5. El nombre de usuario DEBE establecerse también con la variable anterior.
TORSOCKS_TOR_ADDRESS
Establece la dirección de Tor. (predeterminado: 127.0.0.1)
TORSOCKS_TOR_PORT
Establece el puerto de Tor. (predeterminado: 9050)
TORSOCKS_ALLOW_INBOUND
Permite conexiones entrantes para que la aplicación pueda aceptar y escuchar conexiones.
TORSOCKS_ISOLATE_PID
Establece el nombre de usuario y la contraseña para el método de autenticación SOCKS5 a un valor basado en PID/hora actual automáticamente. NO se deben establecer el nombre de usuario ni la contraseña.

PROBLEMAS CONOCIDOS

DNS

Torsocks no puede enviar consultas DNS a través de Tor ya que UDP no es compatible. Por lo tanto, se niega cualquier socket UDP. Sin embargo, las consultas DNS que se pueden interceptar se envían a Tor y se devuelven al llamador.

ERRORES

Torsocks puede generar mensajes de error y imprimirlos en stderr cuando hay problemas con el archivo de configuración o la negociación SOCKS con el demonio Tor. La variable de entorno TORSOCKS_LOG_LEVEL controla ese comportamiento, así como la opción de archivo de registro. Tenga en cuenta que esta biblioteca puede generar salida en el stderr de la aplicación.

LIMITACIONES

Solo se pueden redirigir a través de la red Tor las conexiones TCP salientes.

Torsocks fuerza al resolvedor de libc a usar TCP para las consultas de nombres; si lo hace, lo hace independientemente de si la consulta DNS es local o no. Esto introduce sobrecarga y solo debe usarse cuando sea necesario.

Torsocks utiliza las características del cargador dinámico ELF para interceptar llamadas dinámicas de funciones de programas en los que está incrustado. Como resultado, los ejecutables que no son ELF, o los ejecutables que realizan llamadas al sistema directamente con la trampa de llamada al sistema (int 0x80) no son compatibles.
