NOMBRE

totem-video-thumbnailer - creador de miniaturas de vídeo para el escritorio GNOME

SINOPSIS

totem-video-thumbnailer [-j|--jpeg] [-l|--no-limit] [-s tamaño] entrada salida [opciones de backend]

DESCRIPCIÓN

Esta página del manual documenta brevemente el comando totem-video-thumbnailer. Esta página del manual fue escrita para el Proyecto Debian porque el programa original no tiene una página del manual.

totem-video-thumbnailer es utilizado internamente por aplicaciones de GNOME como nautilus para generar miniaturas de archivos de vídeo en formato PNG. Si bien es posible invocarlo manualmente, normalmente lo hace automáticamente nautilus.

ARGUMENTOS

entrada
El nombre del archivo de entrada. Puede estar en cualquier formato que totem pueda reproducir.
salida
El nombre del archivo de salida, en formato PNG.
opciones de backend
Opciones que se pasarán al backend (es decir, gstreamer).

OPCIONES

-j --jpeg
Cambia el formato de salida a JPEG. El predeterminado es PNG.
-l --no-limit
No limita el tiempo de creación de miniaturas a 30 segundos. Para fines de depuración.
-s tamaño
El tamaño de la miniatura. Ejemplo: "64x64". El valor predeterminado es "128x96".
