NOMBRE

toc2cue - convierte un archivo TOC de cdrdao(1) en un archivo .cue

SINOPSIS

toc2cue [-v nivel_de_verbosidad] archivo_toc_entrada archivo_cue_salida

toc2cue [-V]

DESCRIPCIÓN

toc2cue convierte un archivo TOC de cdrdao(1) en un archivo .cue.

Tenga en cuenta que el archivo cue resultante solo es válido si el archivo toc fue creado con cdrdao(1) usando los comandos 'read-toc' o 'read-cd'. Para archivos toc creados o editados manualmente, el archivo cue puede no ser correcto. Este programa solo verifica las características más obvias del archivo toc que no se pueden convertir a un archivo cue. Además, si el archivo toc contiene pistas de audio, el orden de bytes del archivo de imagen será incorrecto. Esto resultará en ruido estático cuando se use el archivo cue para grabar (incluso con el propio cdrdao(1)).

OPCIONES

-v nivel_de_verbosidad
Establece el nivel de verbosidad a usar, puede ser un entero entre 1 y 3. Por defecto, solo se muestran los errores fatales. Un nivel de verbosidad de 1 muestra advertencias, 2 advertencias y errores, 3 advertencias, errores y errores internos.
-V
Imprime la versión de toc2cue.
