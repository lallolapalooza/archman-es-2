toe(1M) Comandos de usuario toe(1M)

NOMBRE

toe - lista tabla de entradas de tipos de terminal terminfo

SINOPSIS

toe [-ahs] [-v [n]] [directorio ...]

toe [-u|-U] archivo

toe -V

DESCRIPCIÓN

toe reporta al flujo de salida estándar los nombres (primarios) y descripciones de los tipos de terminal disponibles para la biblioteca terminfo. Cada directorio se escanea; si no se proporcionan ninguno, toe escanea el directorio predeterminado de terminfo.

OPCIONES

La opción -h puede ser útil para observar dónde está buscando toe las descripciones de terminal. Otras opciones soportan a los mantenedores de las descripciones de terminal terminfo.

-a
lista las entradas de todos los directorios de la base de datos de terminales que buscaría terminfo, en lugar de solo el primero que encuentra.
Si también se proporciona -s, toe reporta adicionalmente, como conflict(1), qué entradas corresponden a una base de datos de terminal dada. Un “*” marca las entradas que difieren, y “+” marca las entradas equivalentes.
Sin la opción -s, toe no intenta fusionar duplicados en su informe.
-h
escribe un encabezado nombrando cada directorio al acceder a él.
-s
ordena la salida por los nombres de las entradas.
-u archivo
lista las dependencias de tipos de terminal en archivo, una fuente de entrada terminfo o un archivo de base de datos termcap. El informe resume las relaciones “use” (terminfo) y tc (termcap): cada línea comprende el nombre primario de un tipo de terminal que emplea capacidades use/tc, dos puntos, una lista separada por espacios y tabulaciones de nombres primarios de tipos de terminal así nombrados, y un salto de línea.
-U archivo
lista las dependencias inversas de tipos de terminal en archivo, una fuente de entrada terminfo o un archivo de base de datos termcap. El informe resume las relaciones inversas “use” (terminfo) y tc (termcap): cada línea comprende el nombre primario de un tipo de terminal que aparece en capacidades use/tc, dos puntos, una lista separada por espacios y tabulaciones de nombres primarios de tipos de terminal que los nombran así, y un salto de línea.
-v [n]
reporta información de estado detallada al flujo de error estándar, mostrando el progreso de toe.
El parámetro opcional n es un entero entre 1 y 10 inclusive, interpretado como para tic(1M). Si ncurses está compilado sin soporte de rastreo, n se ignora.
-V
reporta la versión de ncurses asociada con este programa y sale con estado exitoso.

ARCHIVOS

/usr/share/terminfo
base de datos compilada de descripciones de terminal

PORTABILIDAD

toe no es proporcionado por otras implementaciones. No existe un estándar X/Open o POSIX aplicable para él.

HISTORIA

toe reemplaza una opción -T que fue brevemente soportada por la utilidad ncurses infocmp en 1995.

Las opciones -a y -s se añadieron en 2006 y 2011, respectivamente.

El nombre del programa se origina de un juego de palabras de un desarrollador:

  • tic,
  • tac (ahora tack),
  • toe.

EJEMPLOS

Cuando no se ordena con la opción -s, la opción -a reporta todos los nombres encontrados en todos los directorios de la base de datos de terminales nombrados en las variables de entorno TERMINFO y TERMINFO_DIRS.

xterm-color xterm de color genérico
xterm-xfree86 emulador de terminal xterm (XFree86)
xterm-vt220 xterm emulando vt220
xterm-256color xterm con 256 colores
xterm-r6 versión xterm X11R6
xterm-r5 versión xterm R5
xterm-mono xterm monocromático
xterm emulador de terminal xterm (X Window System)
vt220 dec vt220
vt102 dec vt102
vt100 dec vt100 (con video avanzado)
vt52 dec vt52
...

Use las opciones -a y -s juntas para mostrar dónde se encontró cada descripción de terminal.

COMANDANTE DE MANIPULACIÓN DE USUARIOS

SINOPSIS

toe

DESCRIPCIÓN

toe es un programa simple que muestra los nombres de los caracteres de los 256 caracteres de una tabla de códigos de página.

Imprime una lista de los caracteres de la página de códigos actual, mostrando para cada uno su nombre simbólico, su representación hexadecimal y su representación decimal.

OPCIONES

toe no tiene opciones.

ESTADO DE SALIDA

toe siempre sale con 0.

HISTORIA

Un programa llamado toe apareció por primera vez en el conjunto de herramientas toe(1) en FreeBSD 1.1.1.

EJEMPLOS

Para mostrar los caracteres de la página de códigos actual:

$ toe
