NOMBRE

toolbox-help - Muestra información de ayuda sobre Toolbx

SINOPSIS

toolbox help [COMANDO]

DESCRIPCIÓN

Cuando no se especifica un COMANDO, se muestra el manual de toolbox(1). Si se especifica un COMANDO, se abre una página del manual para ese comando.

Tenga en cuenta que toolbox --help ... es idéntico a toolbox help ... porque el primero se convierte internamente en el segundo.

Esta página se puede mostrar con toolbox help help o toolbox help --help.

EJEMPLOS

Mostrar el manual de toolbox

$ toolbox help

Mostrar el manual del comando create

$ toolbox help create
