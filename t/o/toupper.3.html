toupper(3) Manual de funciones de biblioteca toupper(3)

NOMBRE

toupper, tolower, toupper_l, tolower_l - convertir a mayúsculas o minúsculas

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <ctype.h>
int toupper(int c);
int tolower(int c);
int toupper_l(int c, locale_t locale);
int tolower_l(int c, locale_t locale);
Requisitos de macro de prueba de funciones para glibc (ver feature_test_macros(7)):

toupper_l(), tolower_l():

    Desde glibc 2.10:
        _XOPEN_SOURCE >= 700
    Antes de glibc 2.10:
        _GNU_SOURCE

DESCRIPCIÓN

Estas funciones convierten letras minúsculas a mayúsculas y viceversa.

Si c es una letra minúscula, toupper() devuelve su equivalente en mayúsculas, si existe una representación en mayúsculas en la configuración regional actual. De lo contrario, devuelve c. La función toupper_l() realiza la misma tarea, pero utiliza la configuración regional a la que se refiere el identificador de configuración regional locale.

Si c es una letra mayúscula, tolower() devuelve su equivalente en minúsculas, si existe una representación en minúsculas en la configuración regional actual. De lo contrario, devuelve c. La función tolower_l() realiza la misma tarea, pero utiliza la configuración regional a la que se refiere el identificador de configuración regional locale.

Si c no es un valor de unsigned char ni EOF, el comportamiento de estas funciones es indefinido.

El comportamiento de toupper_l() y tolower_l() es indefinido si locale es el objeto de configuración regional especial LC_GLOBAL_LOCALE (ver duplocale(3)) o no es un identificador de objeto de configuración regional válido.

VALOR DE RETORNO

El valor devuelto es el de la letra convertida, o c si la conversión no fue posible.

NOTAS

Los estándares requieren que el argumento c para estas funciones sea EOF o un valor que sea representable en el tipo unsigned char. Si el argumento c es de tipo char, debe convertirse a unsigned char, como en el siguiente ejemplo:


char c;
...
res = toupper((unsigned char) c);

Esto es necesario porque char puede ser el equivalente a signed char, en cuyo caso un byte con el bit superior establecido se extendería con signo al convertir a int, produciendo un valor que está fuera del rango de unsigned char.

Los detalles de lo que constituye una letra mayúscula o minúscula dependen de la configuración regional. Por ejemplo, la configuración regional predeterminada **"C"** no conoce las diéresis, por lo que no se realiza ninguna conversión para ellas.

En algunas configuraciones regionales no inglesas, existen letras minúsculas sin un equivalente en mayúsculas correspondiente; la s alemana (eszett) es un ejemplo.
