NOMBRE

tor-resolve - resolver un nombre de host a una dirección IP a través de tor

SINOPSIS

tor-resolve [-4|-5] [-v] [-x] [-p puerto_socks] nombre_host [host_socks[:puerto_socks]]

DESCRIPCIÓN

tor-resolve es un script simple para conectarse a un proxy SOCKS que conoce el comando SOCKS RESOLVE, entregarle un nombre de host y devolver una dirección IP.

Por defecto, tor-resolve utiliza el servidor Tor en ejecución en 127.0.0.1 en el puerto SOCKS 9050. Si esto no es lo que desea, debería especificar un host_socks y/o puerto_socks explícito en la línea de comandos.

OPCIONES

-v

Mostrar salida detallada.

-x

Realizar una búsqueda inversa: obtener el registro PTR para una dirección IPv4.

-5

Usar el protocolo SOCKS5. (Por defecto)

-4

Usar el protocolo SOCKS4a en lugar del protocolo SOCKS5 por defecto. No soporta DNS inverso.

-p puerto_socks

Anular el puerto SOCKS por defecto sin establecer el nombre de host.

VER TAMBIÉN

tor(1), torify(1).

Para detalles del protocolo, ver: https://spec.torproject.org/socks-extensions
