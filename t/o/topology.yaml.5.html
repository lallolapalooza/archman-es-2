NOMBRE

topology.yaml - Archivo de configuración de Slurm para los plugins de topología

DESCRIPCIÓN

topology.yaml es un archivo de configuración con formato YAML que define múltiples topologías de red para optimizar la asignación de recursos de trabajos en Slurm. El archivo debe estar ubicado en el mismo directorio que slurm.conf. Cualquier texto que siga a un "#" en este archivo se tratará como un comentario hasta el final de esa línea.

Hay detalles adicionales disponibles en topology.conf(5) y en la Guía de Topología: https://slurm.schedmd.com/topology.html

NOTA: Slurm primero buscará topology.yaml. Si este archivo existe, topology.conf será ignorado.

PARÁMETROS

Cada topología contiene los siguientes atributos:

topology
Nombre único de la topología, se usará para identificarla en las configuraciones de particiones. Debe ser el primer atributo.
cluster_default
La primera topología definida con cluster_default: true se usará para particiones sin una topología especificada explícitamente y para operaciones a nivel de clúster no ligadas a una partición (por ejemplo, comunicación slurmctld-a-slurmd). Por defecto es false.

Cada topología también debe definir exactamente uno de los siguientes tipos de topología:

block
Esta topología usará el plugin topology/block. Debe contener campos adicionales, ver abajo.
flat
Si se establece en true, esta topología usará el plugin topology/flat, que es el valor predeterminado si no se especifica ningún TopologyPlugin o topology.yaml.
tree
Esta topología usará el plugin topology/tree. Debe contener campos adicionales, ver abajo.

Definiciones de bloque

Cada topología de bloque contiene los siguientes atributos:

block_sizes
Lista del tamaño de bloque base de planificación, junto con cualquier tamaño de bloque de nivel superior que se aplicaría. Los BlockSizes sucesivos deben ser una potencia de dos mayor que los valores anteriores.
blocks
Lista de bloques disponibles en esta topología. Cada bloque contiene los siguientes atributos:
block
El nombre de un bloque. Este nombre es interno para Slurm y arbitrario. Cada bloque debe tener un nombre único. Este campo es obligatorio.
nodes
Nodos hijos del bloque con nombre.

Definiciones de árbol

Cada topología de árbol contiene el siguiente atributo:

switches
Lista de switches disponibles en esta topología. Cada switch contiene los siguientes atributos:
switch
El nombre de un switch. Este nombre es interno para Slurm y arbitrario. Cada switch debe tener un nombre único. Este campo es obligatorio y no puede tener más de 64 caracteres.
children
Switches hijos del switch con nombre.
nodes
Nodos hijos del switch hoja con nombre.

EJEMPLO

---
- topology: topo1
  cluster_default: true
  tree:
    switches:
      - switch: sw_root
        children: s[1-2]
      - switch: s1
        nodes: node[01-02]
      - switch: s2
        nodes: node[03-04]
- topology: topo2
  cluster_default: false
  block:
    block_sizes:
      - 4
      - 16
    blocks:
      - block: b1
        nodes: node[01-04]
      - block: b2
        nodes: node[05-08]
      - block: b3
        nodes: node[09-12]
      - block: b4
        nodes: node[13-16]
- topology: topo3
  cluster_default: false
  flat: true
