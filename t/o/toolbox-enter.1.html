NOMBRE

toolbox-enter - Entra en un contenedor Toolbx para uso interactivo

SINOPSIS

toolbox enter [--distro DISTRO | -d DISTRO]
[--release RELEASE | -r RELEASE]
[CONTENEDOR]

DESCRIPCIÓN

Inicia un shell interactivo dentro de un contenedor Toolbx que fue creado usando el comando toolbox create. Intenta iniciar el shell predeterminado del usuario, pero si no está disponible dentro del contenedor, recurre a /bin/bash.

Cuando se invoca sin ninguna opción, toolbox enter intentará entrar en el contenedor Toolbx predeterminado para el host, o si solo hay un contenedor disponible, lo usará. En Fedora, el contenedor predeterminado se conoce como fedora-toolbox-N, donde N es la versión del host. Si no hay ningún contenedor, toolbox enter ofrecerá crearlo por usted.

Se puede seleccionar un contenedor específico usando el argumento CONTENEDOR.

Un contenedor Toolbx es un contenedor OCI. Por lo tanto, toolbox enter es análogo a un podman start seguido de un podman exec.

OPCIONES

Se entienden las siguientes opciones:

--distro DISTRO, -d DISTRO

Entra en un contenedor Toolbx para un sistema operativo DISTRO diferente al del host. Debe ir acompañado de --release a menos que el DISTRO seleccionado coincida con el del host.

--release RELEASE, -r RELEASE

Entra en un contenedor Toolbx para una versión RELEASE de sistema operativo diferente a la del host.

EJEMPLOS

Entrar en el contenedor Toolbx predeterminado que coincide con el SO del host

$ toolbox enter

Entrar en el contenedor Toolbx predeterminado para Fedora 36

$ toolbox enter --distro fedora --release f36

Entrar en un contenedor Toolbx con un nombre personalizado

$ toolbox enter foo
