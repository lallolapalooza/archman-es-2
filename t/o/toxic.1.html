NOMBRE

toxic - cliente CLI para Tox

SINOPSIS

toxic [-f archivo-datos] [-x] [-4] [-c archivo-config] [-n archivo-nodos] [-h]

DESCRIPCIÓN

toxic es un cliente de mensajería instantánea basado en ncurses para Tox que anteriormente residía en el repositorio central de Tox y ahora está disponible como una aplicación independiente.

OPCIONES

-4, --ipv4

Forzar conexión IPv4

-b, --debug

Habilitar stderr para depuración. Redirigir la salida para evitar romper la interfaz curses y capturar mejor los mensajes.

-c, --config archivo-config

Usar el archivo-config especificado en lugar de ~/.config/tox/toxic.conf

-d, --default-locale

Usar localización predeterminada

-e, --encrypt-data

Cifrar un archivo de datos no cifrado. Se producirá un error si se utiliza esta opción con un archivo de datos cifrado.

-f, --file archivo-datos

Usar el archivo-datos especificado en lugar de ~/.config/tox/toxic_profile.tox

-h, --help

Mostrar mensaje de ayuda

-l, --logging

Habilitar registro de toxcore en stderr

-n, --nodes archivo-nodos

Usar el archivo-nodos especificado para los nodos de bootstrap de DHT en lugar de ~/.config/tox/DHTnodes.json

-o, --noconnect

No conectar a la red DHT

-p, --SOCKS5-proxy

Usar un proxy SOCKS5: Requiere [IP] [puerto]

-P, --HTTP-proxy

Usar un proxy HTTP: Requiere [IP] [puerto]

-r, --namelist

Usar la lista de servidores de nombres especificada

-t, --force-tcp

Forzar conexión TCP (usar esto con proxies)

-T, --tcp-relay

Actuar como un servidor de retransmisión TCP para la red (Nota: esto consume significativamente más ancho de banda)

-u, --unencrypt-data

Descifrar un archivo de datos. Aparecerá una advertencia si se utiliza esta opción con un archivo de datos que ya está descifrado.

ARCHIVOS

~/.config/tox/DHTnodes.json

Ubicación predeterminada para la lista de nodos de bootstrap de DHT (lista obtenida de https://nodes.tox.chat). Esta lista se actualiza automáticamente. Consulte toxic.conf(5) para obtener detalles sobre cómo controlar la frecuencia de actualización.

~/.config/tox/toxic_profile.tox

Estado guardado que contiene tu información personal (apodo, ID de Tox, contactos, etc.)

~/.config/tox/toxic.conf

Archivo de configuración. Consulte toxic.conf(5) para obtener más detalles.

/usr/share/toxic/toxic.conf.example

Ejemplo de configuración.

ERRORES

- Los caracteres Unicode con un ancho mayor que 1 columna pueden causar un comportamiento extraño.

- El parpadeo de la pantalla ocurre a veces en terminales específicas.

- Redimensionar la ventana de la terminal cuando hay una ventana de juego abierta romperá cosas.
