NOMBRE

toolbox-run - Ejecutar un comando en un contenedor Toolbx existente

SINOPSIS

toolbox run [--container NOMBRE | -c NOMBRE]
[--distro DISTRO | -d DISTRO]
[--preserve-fds N]
[--release RELEASE | -r RELEASE]
[COMANDO]

DESCRIPCIÓN

Ejecuta un comando dentro de un contenedor Toolbx existente. El contenedor debe haber sido creado usando el comando toolbox create.

En Fedora, el contenedor por defecto se conoce como fedora-toolbox-N, donde N es la versión del sistema anfitrión. Se puede seleccionar un contenedor específico usando la opción --container.

Un contenedor Toolbx es un contenedor OCI. Por lo tanto, toolbox run es análogo a un podman start seguido de un podman exec.

OPCIONES

Se reconocen las siguientes opciones:

--container NOMBRE, -c NOMBRE

Ejecutar el comando dentro de un contenedor Toolbx con el NOMBRE dado. Esto es útil cuando hay múltiples contenedores Toolbx creados a partir de la misma imagen, o contenedores completamente personalizados creados a partir de imágenes construidas a medida.

--distro DISTRO, -d DISTRO

Ejecutar el comando dentro de un contenedor Toolbx para un sistema operativo DISTRO diferente al del anfitrión. Debe ir acompañado de --release a menos que el DISTRO seleccionado coincida con el sistema anfitrión.

--preserve-fds N

Pasar N descriptores de archivo adicionales al comando (además de 0, 1, 2). El número total de descriptores de archivo será 3+N.

--release RELEASE, -r RELEASE

Ejecutar el comando dentro de un contenedor Toolbx para una versión RELEASE de sistema operativo diferente a la del anfitrión.

ESTADO DE SALIDA

El código de salida proporciona información sobre por qué el comando dentro del contenedor no pudo ejecutarse o por qué terminó.

1 Hubo un error interno en Toolbx

125 Hubo un error interno en Podman

126 No se pudo invocar el comando de ejecución

$ toolbox run /etc; echo $?
/bin/sh: line 1: /etc: Is a directory
/bin/sh: line 1: exec: /etc: cannot execute: Is a directory
Error: failed to invoke command /etc in container fedora-toolbox-36
126

127 El comando de ejecución no se puede encontrar o el directorio de trabajo no existe

$ toolbox run foo; echo $?
/bin/sh: line 1: exec: foo: not found
Error: command foo not found in container fedora-toolbox-36
127

Código de salida El código de salida del comando de ejecución

$ toolbox run false; echo $?
1

EJEMPLOS

Ejecutar ls dentro del contenedor Toolbx por defecto que coincide con el SO anfitrión

$ toolbox run ls -la

Ejecutar emacs dentro del contenedor Toolbx por defecto para Fedora 36

$ toolbox run --distro fedora --release f36 emacs

Ejecutar uptime dentro de un contenedor Toolbx con un nombre personalizado

$ toolbox run --container foo uptime
