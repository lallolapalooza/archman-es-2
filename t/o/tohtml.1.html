NOMBRE

tohtml - Crear HTML a partir de entrada LaTeX

SINOPSIS

tohtml [-latex] [-info] [-mapref nombre_archivo] [-basedir dir_nombre] [-userpath ruta] [-iftex] [-split n] [-headeroffset n ] [-mapman nombre_archivo ] [-cvtlatex] [-cvttables] [-cvtmath] [-simplemath] [-useimg] [-gaudy] [-iftex] [-default] [-nonavnames] [-notopnames] [-nobottomnav] [-basedef nombre_archivo] [-endpage nombre_archivo ] [-beginpage nombre_archivo] [-citeprefix str] [-citesuffix str] [-o nombre_salida ] nombre_archivo

PARÁMETROS DE ENTRADA

-iftex
- Incluir texto en modo begin{iftex}...end{iftex}
-cvtlatex
- Convertir LaTeX que no puede ser representado como texto en mapas de bits
-cvttables
- Convertir entornos tabulares en mapas de bits
-useimg
- Cuando se usa con -cvtlatex, usar mapas de bits existentes de una ejecución anterior
-gaudy
- Usar imágenes a color para los puntos de las listas (itemize)
-nocopy
- No copiar los mapas de bits predefinidos
-dosnl
- Generar saltos de línea estilo Windows/DOS (retorno de nueva línea)
-split n
- Dividir el documento hasta secciones en el nivel n -split -1 prohíbe la división; 0 = capítulo, 1 = sección, etc.
-headeroffset n
- Desplazar las cabeceras HTML generadas por la sección. Por ejemplo, para usar H2 en lugar de H1 para secciones de nivel superior, usar -headeroffset 1
-nonavnames
- No mostrar los botones de navegación
-notopnames
- No mostrar los nombres en la parte superior de la página
-nobottomnav
- No mostrar los nombres o botones en la parte inferior de una sección
-nocontents
- No generar la página de contenidos
-mapref archivo
- Convertir referencias en \\cite en hipervínculos utilizando el archivo especificado
-mapman archivo
- Convertir ocurrencias de tokens en hipervínculos a archivos
-default
- Elegir valores predeterminados relativamente buenos
-citeprefix str
- Establecer el prefijo para las citas ( [ por defecto)
-citesuffix str
- Establecer el sufijo para las citas ( ] por defecto)
-basedef nombre
- Usar el nombre del archivo para definir comandos TeX
-beginpage nombre_archivo
- Añadir el html del archivo al final de cada página
-endpage nombre_archivo
- Añadir el html del archivo al final de cada página
-o nombre_salida
- Especificar el nombre que se usará como nombre de archivo de salida (en lugar de basar el nombre de archivo de salida en el nombre del archivo de entrada). Este nombre debe incluir la extensión natural; por ejemplo, para salida HTML, usar algo como tohtml -latex -o mi_salida.htm mi_archivo.tex .
