topology.conf(5) Archivo de configuración de Slurm topology.conf(5)

NOMBRE

topology.conf - Archivo de configuración de Slurm para los plugins de topología.

DESCRIPCIÓN

topology.conf es un archivo de texto ASCII que describe la topología de red del clúster para la asignación optimizada de recursos de trabajos. El archivo se encontrará siempre en el mismo directorio que slurm.conf. NOTA: Este archivo se ignora si existe topology.yaml(5).

Los nombres de los parámetros no distinguen entre mayúsculas y minúsculas. Cualquier texto que siga a un "#" en el archivo de configuración se trata como un comentario hasta el final de esa línea. Los cambios en el archivo de configuración surten efecto tras reiniciar los demonios de Slurm, la recepción de la señal SIGHUP por parte de un demonio o la ejecución del comando "scontrol reconfigure", a menos que se indique lo contrario.

Consulte la guía de topología para más detalles: https://slurm.schedmd.com/topology.html

topology/tree

Este plugin requiere que utilice el plugin select/cons_tres. La configuración de la topología de red, cada línea define un nombre de switch y sus hijos, ya sean nombres de nodo o nombres de switch. Se utiliza el analizador de expresiones de listas de hosts de Slurm, por lo que los nombres de los nodos y switches no necesitan ser consecutivos (por ejemplo, "Nodes=tux[0-3,12,18-20]" y "Switches=s[0-2,4-8,12]" se analizarán correctamente). También se puede especificar una velocidad de enlace opcional.

Todos los nodos de la red deben estar conectados al menos a un switch. La red debe estar completamente conectada para usar TopologyParam=RouteTree. Los trabajos solo pueden abarcar nodos conectados por la misma estructura de switch, incluso si hay nodos inactivos disponibles en otras áreas del clúster.

El archivo topology.conf para un switch Infiniband puede ser generado automáticamente utilizando la herramienta slurmibtopology que se encuentra aquí: https://github.com/OleHolmNielsen/Slurm_tools/tree/master/slurmibtopology.

Los parámetros de configuración generales disponibles para topology/tree incluyen:

NombreSwitch
El nombre de un switch. Este nombre es interno de Slurm y arbitrario. Cada switch debe tener un nombre único. Este campo debe especificarse y no puede tener más de 64 caracteres.
Switches
Switches hijos del switch nombrado.
Nodos
Nodos hijos del switch de hoja nombrado.
VelocidadEnlace
Un valor opcional que especifica el rendimiento de este enlace de comunicación. Las unidades utilizadas son arbitrarias y esta información no se utiliza actualmente. Puede utilizarse en el futuro para optimizar las asignaciones de recursos.

topology/block

La configuración de la topología de red, cada línea define un nombre de bloque y sus nodos hijos. Se utiliza el analizador de expresiones de listas de hosts de Slurm, por lo que los nombres de los nodos no necesitan ser consecutivos (por ejemplo, "Nodes=tux[0-3,12,18-20]").

Este plugin de topología pone énfasis en reducir la fragmentación del clúster, permitiendo que los trabajos aprovechen las conexiones de menor latencia entre "bloques" más pequeños de nodos, en lugar de iniciar trabajos lo más rápido posible en los recursos disponibles.

Los bloques de nodos definidos se emparejan con otros bloques contiguos, para crear un bloque de nodos de mayor nivel. Estos bloques más grandes pueden ser emparejados con otros bloques del mismo nivel para obtener bloques de nodos contiguos cada vez más grandes con comunicación optimizada entre ellos. Los tamaños de bloque forzados se definen mediante TamañosBloque.

Los parámetros de configuración generales disponibles para topology/block incluyen:

NombreBloque
El nombre de un bloque. Este nombre es interno de Slurm y arbitrario. Cada bloque debe tener un nombre único. Este campo debe especificarse.
Nodos
Nodos hijos del bloque nombrado.
TamañosBloque
Lista del tamaño base de planificación del bloque, junto con cualquier tamaño de bloque de nivel superior que se aplicará. Cada bloque debe tener al menos el recuento de nodos del tamaño base de planificación. Los sucesivos TamañosBloque deben ser una potencia de dos mayor que los valores anteriores.

EJEMPLO

##################################################################
# Archivo de configuración de topología de red de Slurm para usar con el
# plugin topology/tree
##################################################################
NombreSwitch=s0 Nodos=dev[0-5]
NombreSwitch=s1 Nodos=dev[6-11]
NombreSwitch=s2 Nodos=dev[12-17]
NombreSwitch=s3 Switches=s[0-2]
##################################################################
# Archivo de configuración de topología de red de Slurm para usar con el
# plugin topology/block
##################################################################
NombreBloque=bloque1 Nodos=nodo[1-32]
NombreBloque=bloque2 Nodos=nodo[33-64]
NombreBloque=bloque3 Nodos=nodo[65-96]
NombreBloque=bloque4 Nodos=nodo[97-128]
TamañosBloque=30,120
