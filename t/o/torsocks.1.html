NOMBRE

torsocks — Script de shell para simplificar el uso de la biblioteca torsocks(8) para torificar transparentemente una aplicación.

SINOPSIS

torsocks [OPCIONES] [COMANDO [ARG ...]]

DESCRIPCIÓN

torsocks es un script de envoltura entre la biblioteca torsocks y la aplicación para hacer que toda la comunicación por Internet pase a través de la red Tor.

Por defecto, torsocks asumirá que debe conectarse al proxy SOCKS de Tor que se ejecuta en 127.0.0.1 en el puerto 9050, que son los valores predeterminados del demonio Tor.

Para usar un archivo de configuración, torsocks intenta leer el archivo /etc/tor/torsocks.conf o busca la variable de entorno TORSOCKS_CONF_FILE con la ubicación del archivo. Si no se puede leer ese archivo, torsocks utilizará valores predeterminados razonables para la mayoría de las instalaciones de Tor.

Para más información sobre la configuración, consulte torsocks.conf(5).

OPCIONES

-h, --help
Muestra un resumen de las opciones y comandos posibles.
--shell
Crea un nuevo shell con LD_PRELOAD que incluye torsocks(8).
--version
Muestra la versión.
-u, --user
Establece el nombre de usuario para la autenticación SOCKS5. Úselo para el aislamiento de circuitos en Tor. Tenga en cuenta que DEBE tener una contraseña establecida ya sea por la línea de comandos, la variable de entorno o el archivo de configuración (torsocks.conf(5).
-p, --pass
Establece la contraseña para la autenticación SOCKS5. Úselo para el aislamiento de circuitos en Tor. Tenga en cuenta que DEBE tener un nombre de usuario establecido ya sea por la línea de comandos, la variable de entorno o el archivo de configuración (torsocks.conf(5)).
-a, --address
Establece la dirección de Tor.
-P, --port
Establece el puerto de Tor.
-i, --isolate
Aislamiento automático de Tor. Establece el nombre de usuario y la contraseña para el método de autenticación SOCKS5 a un valor basado automáticamente en el PID/hora actual. El nombre de usuario y la contraseña NO DEBEN estar establecidos.
-d, --debug
Activa el modo de depuración. La salida se escribirá en stderr.
-q, --quiet
Suprime todos los mensajes de registro (incluso errores).
on | off
Esta opción agrega o elimina torsocks(8) de la variable de entorno LD_PRELOAD para el shell actual. Si desea utilizar esta opción, DEBE obtener torsocks de su shell. 
Agrega la biblioteca torsocks a LD_PRELOAD
$ . torsocks on
Elimina la biblioteca torsocks de LD_PRELOAD
$ . torsocks off
show | sh
Muestra el valor actual de la variable de entorno LD_PRELOAD.
