NOMBRE

tvtime - una aplicación de televisión de alta calidad

SINOPSIS

tvtime [ OPCIÓN ] ...

DESCRIPCIÓN

tvtime es una aplicación de televisión de alta calidad para usar con tarjetas de captura de vídeo. tvtime procesa la entrada de una tarjeta de captura y la muestra en un monitor de ordenador o proyector.

tvtime soporta:

  • Salida entrelazada a la velocidad entrelazada completa de 59.94 fotogramas por segundo para fuentes NTSC, o 50 fotogramas por segundo para fuentes PAL. Esto proporciona fluidez de movimiento y alta calidad visual.
  • Múltiples algoritmos de desentrelazado para encontrar el modo óptimo para el contenido de vídeo y la velocidad del procesador disponible.
  • Modo de relación de aspecto 16:9 para la resolución más alta disponible al procesar la entrada de un reproductor de DVD externo o un receptor de satélite digital.
  • Una pantalla en pantalla (OSD) muy elegante para la experiencia televisiva completa, con un sistema de menús lleno de funciones.

OPCIONES

-a, --widescreen
Esta opción inicia tvtime en modo de relación de aspecto 16:9.
-A, --nowidescreen
Esta opción inicia tvtime en modo de relación de aspecto 4:3.
-h, --help
Mostrar información de uso.
-k, --slave
Deshabilita la entrada del teclado en tvtime para el modo esclavo. El modo esclavo se añadió para la integración con aplicaciones PVR como freevo o mythtv, de modo que freevo pueda manejar la entrada del teclado mientras tvtime se está ejecutando. En modo esclavo, las pulsaciones de teclas se ignoran pero se imprimen en la salida estándar, y los comandos se leen de la entrada estándar con la misma sintaxis que tvtime-command.
-m, --fullscreen
Iniciar tvtime en modo de pantalla completa.
-M, --window
Iniciar tvtime en modo de ventana.
-s, --showdrops
Imprimir información de omisión de fotogramas (para depuración).
-S, --saveoptions
Guardar las opciones de la línea de comandos en el archivo de configuración. Esto guardará el dispositivo V4L, el dispositivo VBI, el número de entrada, la norma, la frecuencia, la configuración de pantalla completa al inicio, la relación de aspecto, el modo detallado y la altura de la ventana de salida.
-v, --verbose
La configuración detallada indica que debemos imprimir mensajes informativos y de advertencia completos en el error estándar mientras ejecutamos tvtime. De lo contrario, solo se imprimirán errores críticos en la salida.
-F, --configfile=ARCHIVO
Archivo de configuración adicional para cargar la configuración.
-g, --geometry=GEOMETRIA
Establece la geometría de la ventana, por ejemplo, 400x300 para una ventana de 400 píxeles de ancho y 300 píxeles de alto. Un valor de ancho de 0 significa que se usará el ancho apropiado para la altura dada. Para contenido 4:3 en una pantalla de píxeles cuadrados, esto tiene por defecto una ventana de 768×576.
-I, --inputwidth=MUESTREO
Muestreo de líneas de barrido de entrada V4L (por defecto es 720. Esto establece cuántos píxeles por línea de barrido solicitar de la tarjeta de captura. Una configuración más alta da mejor calidad, mientras que una configuración más baja significa que hacemos menos trabajo, y por lo tanto tvtime se ejecutará más rápido. Si tienes una CPU más lenta (como, menos de 500Mhz o así), quizás valores de 480 o 400 te convengan más. Para la mejor calidad, elige un valor alto como 720 o 768. Muchas tarjetas de captura no pueden muestrear más de 768 píxeles por línea de barrido.
-d, --device=NOMBRE
dispositivo video4linux a usar (por defecto es /dev/video0).
-b, --vbidevice=DISPOSITIVO
dispositivo VBI a usar (por defecto es /dev/vbi0).
-i, --input=NUMENTRADA
número de entrada video4linux (por defecto es 0). Las tarjetas comúnmente tienen un montón de fuentes, por ejemplo, en mi tarjeta WinTV, fuente 0 es mi sintonizador y fuente 1 es la entrada compuesta.
-c, --channel=CANAL
Al iniciar, tvtime sintonizará el canal dado. De lo contrario, se usarán los canales del archivo de configuración.
-n, --norm=NORMA
El modo en el que se establecerá el sintonizador (por defecto es NTSC). Los modos válidos son:
• NTSC
• PAL
• SECAM
• PAL-NC
• PAL-M
• PAL-N
• NTSC-JP
-f, --frequencies=NOMBRE
Los canales que estás recibiendo con el sintonizador (por defecto es us-cable). Los valores válidos son:
• us-cable
• us-broadcast
• japan-cable
• japan-broadcast
• europe
• australia
• australia-optus
• newzealand
• france
• russia
• custom (ejecutar primero 'tv tvtime(1)

NAME

tvtime - Television viewer for Linux

SYNOPSIS

tvtime [OPTIONS]

DESCRIPTION

tvtime is a television viewer for Linux that uses the Video4Linux API. It has support for a number of TV capture cards.

USAGE

Run tvtime and use the arrow keys to change channels, volume, etc. Use the tvtime-command(1) program to control tvtime from the command line.

OPTIONS

-A, --adevice=DEVICE
Sets the audio device. (defaults to /dev/dsp).
-b, --burntime=SECONDS
Set the time that the OSD is displayed in seconds. (defaults to 5)
-c, --channels=INTEGER
Set the number of channels to scan.
-C, --config=FILE
Use the given configuration file. The default is ~/.tvtime/tvtime.xml and /etc/tvtime/tvtime.xml.
-d, --driver=DRIVER
Select the driver to use. Defaults to auto-probing.
-D, --debug
Enable debug messages.
-f, --fullscreen
Start tvtime in fullscreen mode.
-F, --fly
Enable flyby mode. This displays the channel name and program title in the corner of the screen.
-g, --geometry=GEOMETRY
Set the window geometry. For example: 640x480x16.
-h, --help
Show help on all options.
-H, --hide-mouse-delay=SECONDS
Sets the delay before the mouse cursor is hidden. (defaults to 2)
-i, --input=INPUT
Set the video input to use. Defaults to auto-probing.
-I, --iconfig=FILE
Use the given input configuration file. The default is ~/.tvtime/input.conf and /etc/tvtime/input.conf.
-k, --key=KEY
Set the channel to switch to.
-l, --list-drivers
Lists available video drivers.
-m, --mixer=DEVICE
The mixer device to use. (defaults to /dev/mixer).
-M, --monitor=SECONDS
Set the monitor rate. (defaults to 1/10)
-n, --nodefault
Do not load the default config file.
-o, --outorder=ORDER
Set the channel order. This can be asc or desc.
-p, --pid=INTEGER
Set the program pid to switch to.
-P, --pause
Pause the video.
-q, --quiet
Disable all OSD messages.
-r, --restart
Restart the tvtime program.
-s, --scan
Scan for channels.
-S, --no-scan
Do not scan for channels.
-t, --xmltv=FILE
Reads XMLTV listings from the given file to display on the OSD. Channels are looked up based on their name, and tvtime will display the show title, sub-title and show description on the OSD.
-l, --xmltvlanguage=LANG
Use XMLTV data in given language, if available. Languages are represented by their two-letter language code (for example, "de" for German). The default language used in the file will be used if this is unset or set to "none"
-X, --display=DISPLAY
Uses the given X display to connect to.
-x, --mixer=DEVICE[:CH]
The mixer device and channel for the volume controls. (defaults to /dev/mixer:line). Valid channels are:
• vol
• bass
• treble
• synth
• pcm
• speaker
• line
• mic
• cd
• mix
• pcm2
• rec
• igain
• ogain
• line1
• line2
• line3
• dig1
• dig2
• dig3
• phin
• phout
• video
• radio
• monitor
