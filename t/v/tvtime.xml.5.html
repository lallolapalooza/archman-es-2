NOMBRE

tvtime.xml - archivo de configuración de tvtime

SINOPSIS

~/.tvtime/tvtime.xml
/etc/tvtime/tvtime.xml

DESCRIPCIÓN

El archivo tvtime.xml es el archivo de configuración principal para tvtime. Contiene todas las configuraciones predeterminadas y los atajos de teclado. El archivo tvtime.xml es actualizado por tvtime en tiempo de ejecución, para almacenar las configuraciones entre sesiones. Por esta razón, no debe editar el archivo tvtime.xml mientras tvtime esté en ejecución, ya que sus cambios podrían ser sobrescritos.

La sintaxis global es la siguiente:


<?xml version="1.0"?>
<!DOCTYPE tvtime PUBLIC "-//tvtime//DTD tvtime 1.0//EN"
"http://tvtime.sourceforge.net/DTD/tvtime1.dtd">
<tvtime xmlns="http://tvtime.sourceforge.net/DTD/">
</tvtime>

Puede encontrar el DTD y otra información sobre los archivos de configuración XML en http://tvtime.sourceforge.net/DTD/

OPCIONES

tvtime admite una multitud de opciones. La etiqueta <option> debe estar contenida dentro de una etiqueta <tvtime>.

La siguiente es una lista de opciones y sus valores predeterminados, junto con una descripción de lo que hace la opción.

<option name="Verbose" value="0"/>
La configuración de verbosidad indica que debemos imprimir mensajes completos de información y advertencia a stderr mientras se ejecuta tvtime. De lo contrario, solo se imprimirán errores fatales en la salida.
<option name="V4LDevice" value="/dev/video0"/>
Esto establece el dispositivo de captura predeterminado a usar.
<option name="V4LInput" value="0"/>
Esto establece la entrada predeterminada de la tarjeta de captura que será abierta por tvtime. Por ejemplo, mi tarjeta WinTV tiene el sintonizador como fuente 0, y su entrada compuesta como fuente 1. Las fuentes se pueden cambiar en tiempo de ejecución usando el comando toggle_input, que es el comando de tecla “i” por defecto.
<option name="Norm" value="NTSC"/>
Esto establece la norma de TV predeterminada. Las opciones válidas son:
• NTSC
• NTSC-JP
• SECAM
• PAL
• PAL-Nc
• PAL-M
• PAL-N
• PAL-60
<option name="SaveAndRestorePictureSettings" value="1"/>
Esta opción indica si tvtime debe habilitar su propio guardado y restauración de configuraciones de imagen, tanto al inicio como al cambiar de canal.
<option name="AudioMode" value="stereo"/>
Esta opción guarda el último modo de audio utilizado. Esto se usará para recordar qué modo de audio seleccionar la próxima vez que se inicie la aplicación. Las opciones válidas aquí son "mono", "stereo", "lang1", "lang2" o "sap".
<option name="AudioBoost" value="-1"/>
Esta opción establece el aumento de audio. Es un porcentaje de cuánto aumentar el volumen que sale de la tarjeta de captura. Por defecto, tvtime no configura el audio en absoluto. Sin embargo, dado que el volumen a veces no tiene un valor predeterminado sensato, o es reiniciado por otras aplicaciones, puedes usar este valor para que siempre se establezca en tu volumen favorito. Usa -1 para que tvtime no toque el volumen.
<option name="ShowCC" value="0"/>
Esta opción guarda el estado de la decodificación de subtítulos. Los subtítulos son una versión en texto del audio específica de NTSC para personas con problemas de audición.
<option name="ColourInvert" value="0"/>
Este valor guarda el estado de encendido/apagado del filtro de inversión de color entre sesiones.
<option name="MirrorInput" value="0"/>
Este valor guarda el estado de encendido/apagado del filtro de espejo entre sesiones.
<option name="Frequencies" value="US-Cable"/>
Esto establece la tabla de frecuencias predeterminada a usar para cualquier sintonizador encontrado. Las posibilidades son:
• us-cable
• us-broadcast
• japan-cable
• japan-broadcast
• europe
• australia
• australia-optus
• newzealand
• france
• russia
<option name="NTSCCableMode" value="Standard"/>
Hay dos estándares especiales de cable NTSC en los EE. UU.: IRC y HRC. En IRC, los canales 5 y 6 están en frecuencias diferentes, y el modo HRC desplaza todas las frecuencias hacia arriba en 1.25MHz (y también es extraño en los canales 5 y 6). Usa esta opción para establecer el modo de cable en Standard, IRC o HRC. Es muy raro ver sistemas de cable que usen cable IRC o HRC.
<option name="CheckForSignal" value="1"/>
Alterna si tvtime debe verificar si hay una señal presente al cambiar de canal, etc. Si tu tarjeta no apesta, no deberías necesitar desactivar esto. Desactivar esta característica también deshabilitará el escáner de canales.
<option name="InputWidth" value="720"/>
Esto establece cuántos píxeles por línea de escaneo solicitar a la tarjeta de captura. Una configuración más alta da mejor calidad, mientras que una configuración más baja significa que hacemos menos trabajo, y por lo tanto tvtime se ejecutará más rápido. Si tienes una CPU más lenta (como, menos de 500MHz o así), quizás valores de 480 o 400 te convengan más. Para la mejor calidad, elige un valor alto como 720 o 768. La mayoría de las tarjetas de captura no pueden muestrear más allá de 768 píxeles por línea de escaneo.
<option name="XMLTVFile" value="none"/>
Establece esto a un nombre de archivo para obtener listados de programas de un archivo xmltv. Establécelo a "none" si no deseas usar xmltv.
<option name="XMLTVLanguage" value="none"/>
Establece esto a un código de idioma de dos letras para establecer el idioma a usar para las entradas en el archivo XMLTV (por ejemplo, usa "de" para alemán). Establécelo a "none" si deseas usar el idioma predeterminado del archivo.
<option name="UseXDS" value="0"/>
Establece esto a 1 para habilitar la decodificación de información de canal XDS. Esta opción es específica para regiones NTSC. XDS se usa para enviar información sobre el canal, incluyendo el nombre de la red y las letras de llamada, y a veces información sobre el programa actual.
<option name="VBIDevice" value="/dev/vbi0"/>
Esto establece qué dispositivo usar para la decodificación VBI.
<option name="MixerDevice" value="/dev/mixer:line"/>
Esto establece el dispositivo mezclador y el canal a usar. El formato es nombre_dispositivo:nombre_canal para mezclador OSS (por ejemplo, "/dev/mixer:Line") o dispositivo/canal para ALSA (por ejemplo, "hw:0/CD").

Los canales OSS válidos son:

vol, bass, treble, synth, pcm, speaker, line, mic, cd, mix, pcm2, rec, igain, ogain, line1, line2, line3, dig1, dig2, dig3, phin, phout, video, radio, monitor
