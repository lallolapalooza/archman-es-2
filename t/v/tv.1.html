television(1) Manual de comandos generales television(1)

NOMBRE

television - Un buscador difuso portátil y hackeable para la terminal

SINOPSIS

television [--preview-offset] [--no-preview] [--hide-preview] [--show-preview] [--no-status-bar] [--hide-status-bar] [--show-status-bar] [-t|--tick-rate] [--watch] [-k|--keybindings] [--expect] [-i|--input] [--input-header] [--input-prompt] [--input-border] [--input-padding] [--preview-header] [--preview-footer] [--preview-border] [--preview-padding] [--hide-preview-scrollbar] [-s|--source-command] [--ansi] [--source-display] [--source-output] [--results-border] [--results-padding] [--source-entry-delimiter] [-p|--preview-command] [--cache-preview] [--layout] [--autocomplete-prompt] [--exact] [--select-1] [--take-1] [--take-1-fast] [--no-remote] [--hide-remote] [--show-remote] [--no-help-panel] [--hide-help-panel] [--show-help-panel] [--ui-scale] [--preview-size] [--config-file] [--cable-dir] [--global-history] [--height] [--width] [--inline] [-h|--help] [-V|--version] [CANAL] [RUTA] [subcomandos]

DESCRIPCIÓN

Un buscador difuso portátil y hackeable para la terminal

OPCIONES

--preview-offset <CADENA>
Un desplazamiento de número de línea de vista previa para usar al desplazar la vista previa para cada entrada.

Cuando se especifica un canal: Esto anula el desplazamiento definido en el prototipo del canal. Cuando no se especifica ningún canal: esta bandera requiere que se establezca --preview-command.

Esta plantilla utiliza la misma sintaxis que la opción `preview` y se formateará utilizando la entrada actualmente seleccionada.

--no-preview
Desactiva el panel de vista previa por completo al inicio.

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. Cuando se establece, no se mostrará ningún panel de vista previa independientemente de la configuración del canal o de las banderas relacionadas con la vista previa.

--hide-preview
Oculta el panel de vista previa al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. La vista previa permanece funcional y puede ocultarse/mostrarse más tarde.

--show-preview
Muestra el panel de vista previa al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. Esto anula cualquier configuración de canal que pueda tenerlo deshabilitado.

--no-status-bar
Desactiva la barra de estado por completo al inicio.

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. Cuando se establece, no se mostrará ninguna barra de estado independientemente de la configuración del canal o de las banderas relacionadas con la barra de estado.

--hide-status-bar
Oculta la barra de estado al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. La barra de estado permanece funcional y puede ocultarse/mostrarse más tarde.

--show-status-bar
Muestra la barra de estado al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc. Esto anula cualquier configuración de canal que pueda tenerla deshabilitada.

-t, --tick-rate <INT>
La tasa de actualización de la aplicación.

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc.

La tasa de actualización es el número de veces que la aplicación se actualizará por segundo. Esto se puede usar para controlar la capacidad de respuesta y el uso de CPU en máquinas muy lentas o muy rápidas, pero el valor predeterminado debería ser un buen compromiso para la mayoría de los usuarios.

--watch <FLOAT>
Modo de vigilancia: recarga el comando fuente cada N segundos.

Cuando se especifica un canal: Anula el intervalo de vigilancia definido en el prototipo del canal. Cuando no se especifica ningún canal: establece el intervalo de vigilancia para el canal ad-hoc.

Cuando se establece en un número positivo, la aplicación recargará automáticamente el comando fuente en el intervalo especificado. Esto es útil para monitorear fuentes de datos cambiantes. Establézcalo en 0 para deshabilitar (predeterminado).

-k, --keybindings <CADENA>
Atajos de teclado para anular los atajos de teclado predeterminados.

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc.

Esto se puede usar para anular los atajos de teclado predeterminados con un subconjunto personalizado. Los atajos de teclado se especifican como una lista separada por punto y coma de expresiones de atajos de teclado utilizando el formalismo del archivo de configuración.

Ejemplo: `tv --keybindings='quit="esc";select_next_entry=["down","ctrl-j"]'`

--expect <CADENA>
Teclas que se pueden usar para confirmar la selección actual además de las predeterminadas (típicamente `enter`).

Cuando esto se establece, la confirmación de la selección primero generará una línea adicional con la tecla que se utilizó para confirmar la selección antes de generar la entrada seleccionada.

Ejemplo: `tv --expect='ctrl-q'` generará `ctr-q\n<entrada_seleccionada>` cuando se presiona `ctrl-q` para confirmar la selección.

-i, --input <CADENA>
Texto de entrada para pasar al canal y prellenar el prompt.

Esta bandera funciona de manera idéntica tanto en el modo de canal como en el modo ad-hoc.

Esto se puede usar para proporcionar un valor predeterminado para el prompt al inicio.

--input-header <CADENA>
Plantilla de encabezado del campo de entrada.

Cuando se especifica un canal: Anula el encabezado de entrada definido en el prototipo del canal. Cuando no se especifica ningún canal: establece el encabezado de entrada para el canal ad-hoc.

El valor proporcionado se analiza como una `MultiTemplate`. Se evalúa con el nombre del canal actual y el texto resultante se muestra como el título del campo de entrada. Predeterminado al nombre del canal actual cuando se omite.

--input-prompt <CADENA>
Cadena de prompt de entrada

Cuando se especifica un canal: Esto anula el prompt definido en el prototipo del canal. Cuando no se especifica ningún canal: establece el prompt de entrada para el canal ad-hoc.

El valor proporcionado se utiliza como la cadena de prompt que se muestra antes del campo de entrada. Predeterminado a ">" cuando se omite.

--input-border <BORDE_DE_ENTRADA>
Establece el tipo de borde del panel de entrada.

Las opciones disponibles son: `none`, `plain`, `rounded`, `thick`.

[posibles valores: none, plain, rounded, thick]

--input-padding <CADENA>
Establece el relleno del panel de entrada.

Formato: `top=INTEGER;left=INTEGER;bottom=INTEGER;right=INTEGER`

Ejemplo: `--input-padding='top=1;left=2;bottom=1;right=2'`

--preview-header <CADENA>
Plantilla de encabezado de vista previa

Cuando se especifica un canal: Esto anula el encabezado definido en el prototipo del canal. Cuando no se especifica ningún canal: esta bandera requiere que se establezca --preview-command.

El valor proporcionado se analiza como una `MultiTemplate`. Se evalúa para cada entrada y su resultado se muestra encima del panel de vista previa.

--preview-footer <CADENA
>
Vista previa de la plantilla del pie de página

Cuando se especifica un canal: Esto anula el pie de página definido en el prototipo del canal. Cuando no se especifica ningún canal: Esta bandera requiere que se establezca --preview-command.

El valor dado se analiza como `MultiTemplate`. Se evalúa para cada entrada y su resultado se muestra debajo del panel de vista previa.

--preview-border <PREVIEW_BORDER>
Establece el tipo de borde del panel de vista previa.

Las opciones disponibles son: `none`, `plain`, `rounded`, `thick`.

[posibles valores: none, plain, rounded, thick]

--preview-padding <STRING>
Establece el relleno del panel de vista previa.

Formato: `top=INTEGER;left=INTEGER;bottom=INTEGER;right=INTEGER`

Ejemplo: `--preview-padding='top=1;left=2;bottom=1;right=2'`

--hide-preview-scrollbar
Oculta la barra de desplazamiento del panel de vista previa.
-s, --source-command <STRING>
Comando fuente a utilizar para el canal actual.

Cuando se especifica un canal: Esto anula el comando definido en el prototipo del canal. Cuando no se especifica ningún canal: Esto crea un canal ad-hoc con el comando dado.

Ejemplo: `find . -name '*.rs'`

--ansi
Si tv debe extraer y analizar códigos de estilo ANSI de la salida del comando fuente.

Esto es útil cuando el comando fuente produce texto coloreado u otros estilos ANSI y desea que `tv` los conserve en la interfaz de usuario. Conlleva un ligero costo de rendimiento, pero que en gran medida pasará desapercibido para las cargas de trabajo típicas de interacción humana.

Ejemplo: `tv --source-command="echo -e '\x1b[31mRojo\x1b[0m'" --ansi`

--source-display <STRING>
Plantilla de visualización fuente a utilizar para el canal actual.

Cuando se especifica un canal: Esto anula la plantilla de visualización definida en el prototipo del canal. Cuando no se especifica ningún canal: Esta bandera requiere que se establezca --source-command.

La plantilla se utiliza para formatear cada entrada en la lista de resultados. Ejemplo: `{split:/:-1}` (mostrar solo el último segmento de ruta)

--source-output <STRING>
Plantilla de salida fuente a utilizar para el canal actual.

Cuando se especifica un canal: Esto anula la plantilla de salida definida en el prototipo del canal. Cuando no se especifica ningún canal: Esta bandera requiere que se establezca --source-command.

La plantilla se utiliza para formatear la salida final cuando se selecciona una entrada. Ejemplo: `"{}"` (mostrar la entrada completa)

--results-border <RESULTS_BORDER>
Establece el tipo de borde del panel de resultados.

Las opciones disponibles son: `none`, `plain`, `rounded`, `thick`.

[posibles valores: none, plain, rounded, thick]

--results-padding <STRING>
Establece el relleno del panel de resultados.

Formato: `top=INTEGER;left=INTEGER;bottom=INTEGER;right=INTEGER`

Ejemplo: `--results-padding='top=1;left=2;bottom=1;right=2'`

--source-entry-delimiter <STRING>
El byte delimitador a utilizar para dividir la salida del comando fuente en entradas.

Esto puede ser útil cuando el comando fuente produce entradas multilínea y desea confiar en otro delimitador para dividir las entradas, como un byte nulo o un carácter personalizado.

-p, --preview-command <STRING>
Comando de vista previa a utilizar para el canal actual.

Cuando se especifica un canal: Esto anula el comando de vista previa definido en el prototipo del canal. Cuando no se especifica ningún canal: Esto habilita la funcionalidad de vista previa para el canal ad-hoc.

Ejemplo: `"cat {}"` (donde {} se reemplazará con la entrada)

Partes de la entrada se pueden extraer posicionalmente utilizando la opción `delimiter`. Ejemplo: `"echo {0} {1}"` dividirá la entrada por el delimitador y pasará los dos primeros campos al comando.

--cache-preview
Si se debe almacenar en caché la salida del comando de vista previa para cada entrada.

Esto puede ser útil cuando el comando de vista previa es costoso de ejecutar y desea evitar ejecutarlo varias veces para la misma entrada.

--layout <LAYOUT>
Orientación del diseño para la interfaz de usuario.

Cuando se especifica un canal: Anula la disposición/orientación definida en el prototipo del canal. Cuando no se especifica ningún canal: Establece la orientación del diseño para el canal ad-hoc.

Las opciones son "landscape" o "portrait".

[posibles valores: landscape, portrait]

--autocomplete-prompt <STRING>
Intenta adivinar el canal de la indicación de entrada proporcionada.

Esta bandera selecciona automáticamente el modo de canal al adivinar el canal apropiado. Entra en conflicto con la especificación manual de un canal, ya que determina el canal automáticamente.

Esto se puede utilizar para seleccionar automáticamente un canal basándose en la indicación de entrada mediante el mapeo `shell_integration` en el archivo de configuración.

--exact
Utiliza la coincidencia de subcadenas en lugar de la coincidencia difusa.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Esto utilizará la coincidencia de subcadenas en lugar de la coincidencia difusa al buscar entradas. Esto es útil cuando el usuario desea buscar una coincidencia exacta en lugar de una coincidencia difusa, por ejemplo, para mejorar el rendimiento.

--select-1
Selecciona y muestra automáticamente la primera entrada si solo hay una entrada.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Tenga en cuenta que la mayoría de los canales transmiten entradas de forma asíncrona, lo que significa que saber si hay una sola entrada requerirá esperar a que el canal termine de cargarse primero.

Para la mayoría de los canales y cargas de trabajo, esto no debería ser un problema, ya que los tiempos de carga suelen ser muy cortos y pasarán desapercibidos para el usuario.

--take-1
Toma la primera entrada de la lista después de que el canal haya terminado de cargarse.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Esto esperará a que el canal termine de cargar todas las entradas y luego seleccionará y mostrará automáticamente la primera entrada. A diferencia de `select_1`, esto siempre tomará la primera entrada independientemente de cuántas entradas estén disponibles.

--take-1-fast
Toma la primera entrada de la lista tan pronto como esté disponible.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Esto seleccionará y mostrará inmediatamente la primera entrada tan pronto como aparezca en los resultados, sin esperar a que el canal termine de cargarse. Esta es la opción más rápida cuando solo desea el primer resultado.

--no-remote
Deshabilita el control remoto.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Esto deshabilitará el panel de control remoto y las acciones asociadas por completo. Esto es útil cuando el control remoto no es necesario o cuando el usuario desea que `tv` se ejecute en modo de canal único (por ejemplo, al usarlo como selector de archivos para un script o al integrarlo en una aplicación más grande).

--hide-remote
Oculta el control remoto al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc. El control remoto permanece funcional y se puede mostrar más tarde.

--show-remote
Muestra el control remoto al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

--no-help-panel
Deshabilita el panel de ayuda por completo al inicio.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc. Cuando se establece, no se mostrará ningún panel de ayuda independientemente de la configuración del canal o de las banderas relacionadas con el panel de ayuda.

--hide-help-panel
Oculta el panel de ayuda al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc. El panel de ayuda permanece funcional y se puede mostrar más tarde.

--show-help-panel
Muestra el panel de ayuda al inicio (solo funciona si la función está habilitada).

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc. Anula cualquier configuración del canal que pueda tenerla deshabilitada.

--ui-scale <INTEGER>
Cambia el tamaño de la pantalla en relación con el área disponible.

Esta bandera funciona de manera idéntica en el modo de canal y en el modo ad-hoc.

Esto recortará la interfaz de usuario a un rectángulo centrado del porcentaje especificado del área disponible.

--preview-size <INTEGER>
Porcentaje de la pantalla a asignar al panel de vista previa (1-99).

Cuando se especifica un canal: Esto anula cualquier `preview_size` definido en los archivos de configuración o prototipos de canal. Cuando no se especifica ningún canal: Esta bandera requiere que se establezca --preview-command.

--config-file <PATH>
Proporciona un archivo de configuración personalizado para usar.

Esta flag funciona idénticamente en modo de canal y en modo ad-hoc.

--cable-dir <PATH>
Proporciona un directorio de cables personalizado para usar.

Este indicador funciona idénticamente en modo de canal y en modo ad-hoc.

--global-history
Utiliza el historial global en lugar del historial específico del canal.

Este indicador solo funciona en modo de canal.

Cuando está habilitado, la navegación del historial mostrará entradas de todos los canales. Cuando está deshabilitado (por defecto), la navegación del historial se limita al canal actual.

--height <INTEGER>
Altura en líneas para el modo no pantalla completa.

Este indicador funciona idénticamente en modo de canal y en modo ad-hoc.

Cuando se especifica, el selector se mostrará como una interfaz no pantalla completa.

--width <INTEGER>
Ancho en columnas para el modo no pantalla completa.

Este indicador solo se puede usar en combinación con --inline o --height. Cuando se especifica, el selector se limitará al ancho especificado.

--inline
Utiliza todo el espacio libre disponible en la parte inferior de la terminal como una interfaz en línea.

Este indicador funciona idénticamente en modo de canal y en modo ad-hoc.

Cuando está habilitado, el selector se mostrará como una interfaz en línea que utiliza todo el espacio libre disponible en la parte inferior de la terminal. Si no hay suficiente espacio para cumplir con la altura mínima, la terminal se desplazará.

-h, --help
Imprimir ayuda (ver un resumen con '-h')
-V, --version
Imprimir versión
[CHANNEL]
¿Qué canal debemos observar?

Cuando se especifica: La aplicación opera en 'modo de canal' donde el canal seleccionado proporciona la configuración base, y los indicadores de la CLI actúan como anulaciones.

Cuando se omite: La aplicación opera en 'modo ad-hoc' donde debes proporcionar al menos --source-command para crear un canal personalizado. En este modo, los indicadores de vista previa y fuente tienen reglas de validación más estrictas.

Se puede mostrar una lista de los canales disponibles usando el comando `list-channels`. El canal también se puede cambiar desde dentro de la aplicación.

[PATH]
El directorio de trabajo desde donde iniciar la aplicación.

Este indicador funciona idénticamente en modo de canal y en modo ad-hoc.

Esto se puede usar para especificar un directorio de trabajo diferente para que la aplicación comience. Esto es útil cuando la aplicación se inicia desde un directorio diferente al que el usuario quiere interactuar.
