TWILL(1) Manual de Comandos Generales TWILL(1)

NOMBRE

twill, twill-refsort - traduce Web a TeX con mini-índices

SINOPSIS

twill [-x] archivo_web[.web] [{archivo_cambios[.ch]|-} [archivo_salida[.tex]]]

twill-refsort < archivo_ref.ref > archivo_sref.sref

DESCRIPCIÓN

El programa twill se utiliza para crear un archivo TeX para visualizar un programa Web. Se ocupa adecuadamente de los detalles tipográficos como el diseño de la página y el uso de sangría, cursiva, negrita, etc., y proporciona información extensiva de referencias cruzadas en forma de 'mini-índices' para cada extensión de páginas y un 'índice maestro' al final que recopila automáticamente.

Los argumentos de la línea de comandos son los mismos que para weave, incluida la opción: -x indica que se omitan los índices, la lista de nombres de módulos y las páginas de índice. (Sin embargo, se escribirá un archivo CONTENTS.tex cuando se procese el archivo TeX, a menos que se redefinan algunas macros en twimac-web.tex.)

El nombre del archivo TeX de salida se forma añadiendo .tex a la raíz del nombre del archivo Web.

Hay varias macros que probablemente deberían ser redefinidas por el programador al principio del archivo Web. Es una buena idea establecer \title al nombre del programa.

twill es exactamente igual a weave excepto que produce mejor documentación, para la cual debes trabajar más. Debes ejecutar twill dos veces, una para preparar la bomba y otra para obtener respuestas decentes. Además, debes ejecutar la salida dos veces a través de TeX.

Después de tex foo tendrás una salida que se parece a las páginas finales excepto que las entradas de los mini-índices no estarán alfabetizadas. La primera ejecución produce un archivo extraño llamado foo.ref. Ejecuta twill-refsort < foo.ref > foo.sref y luego otro tex foo producirá una salida alfabetizada.

AMBIENTE

La variable de entorno WEBINPUTS se utiliza para buscar los archivos de entrada, o el valor predeterminado del sistema si WEBINPUTS no está establecido. Consulte tex(1) para obtener detalles sobre la búsqueda.

ARCHIVOS

$TEXMFMAIN/tex/plain/cweb/cwebbin/twimac-web.tex
Macros TeX utilizadas por la salida de twill.
