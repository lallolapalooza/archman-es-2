NOMBRE

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy - gestionar un árbol de búsqueda binaria

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

DESCRIPCIÓN

tsearch(), tfind(), twalk() y tdelete() gestionan un árbol de búsqueda binaria. Están generalizados del Algoritmo T de Knuth (6.2.2). El primer campo de cada nodo del árbol es un puntero al elemento de datos correspondiente. (El programa que llama debe almacenar los datos reales.) compar apunta a una rutina de comparación, que toma punteros a dos elementos. Debe devolver un entero que sea negativo, cero o positivo, dependiendo de si el primer elemento es menor que, igual que o mayor que el segundo.

tsearch() busca en el árbol un elemento. key apunta al elemento a buscar. rootp apunta a una variable que apunta a la raíz del árbol. Si el árbol está vacío, entonces la variable a la que apunta rootp debe establecerse en NULL. Si el elemento se encuentra en el árbol, entonces tsearch() devuelve un puntero al nodo del árbol correspondiente. (En otras palabras, tsearch() devuelve un puntero a un puntero al elemento de datos.) Si el elemento no se encuentra, entonces tsearch() lo añade y devuelve un puntero al nodo del árbol correspondiente.

tfind() es como tsearch(), excepto que si el elemento no se encuentra, entonces tfind() devuelve NULL.

tdelete() elimina un elemento del árbol. Sus argumentos son los mismos que para tsearch().

twalk() realiza un recorrido de profundidad, de izquierda a derecha, de un árbol binario. root apunta al nodo de inicio del recorrido. Si ese nodo no es la raíz, entonces solo se visitará parte del árbol. twalk() llama a la función de usuario action cada vez que se visita un nodo (es decir, tres veces para un nodo interno y una vez para una hoja). action, a su vez, toma tres argumentos. El primer argumento es un puntero al nodo que se está visitando. La estructura del nodo no está especificada, pero es posible hacer un cast del puntero a un puntero a puntero a elemento para acceder al elemento almacenado dentro del nodo. La aplicación no debe modificar la estructura apuntada por este argumento. El segundo argumento es un entero que toma uno de los valores preorder, postorder o endorder dependiendo de si esta es la primera, segunda o tercera visita al nodo interno, o el valor leaf si esta es la única visita a un nodo hoja. (Estos símbolos están definidos en <search.h>.) El tercer argumento es la profundidad del nodo; el nodo raíz tiene profundidad cero.

(Más comúnmente, preorder, postorder y endorder se conocen como preorden, inorden y postorden: antes de visitar los hijos, después del primero y antes del segundo, y después de visitar los hijos. Por lo tanto, la elección del nombre postorder es bastante confusa.)

twalk_r() es similar a twalk(), pero en lugar del argumento depth, el puntero al argumento closure se pasa a cada invocación de la función de acción, sin cambios. Este puntero puede usarse para pasar información desde y hacia la función de callback de manera segura para hilos, sin recurrir a variables globales.

tdestroy() elimina todo el árbol apuntado por root, liberando todos los recursos asignados por la función tsearch(). Para los datos en cada nodo del árbol se llama a la función free_node. Se pasa un puntero a los datos como argumento a la función. Si no es necesario tal trabajo, free_node debe apuntar a una función que no haga nada.

VALOR DE RETORNO

tsearch() devuelve un puntero a un nodo coincidente en el árbol, o al nodo recién añadido, o NULL si no hubo suficiente memoria para añadir el elemento. tfind() devuelve un puntero al nodo, o NULL si no se encuentra ninguna coincidencia. Si hay varios elementos que coinciden con la clave, el elemento cuyo nodo se devuelve no está especificado.

tdelete() devuelve un puntero al padre del nodo eliminado, o NULL si el elemento no se encontró. Si el nodo eliminado era el nodo raíz, tdelete() devuelve un puntero colgante al que no se debe acceder.

tsearch(), tfind() y tdelete() también devuelven NULL si rootp era NULL en la entrada.

NOTAS

twalk() toma un puntero a la raíz, mientras que las otras funciones toman un puntero a una variable que apunta a la raíz.

tdelete() libera la memoria necesaria para el nodo en el árbol. El usuario es responsable de liberar la memoria para los datos correspondientes.

El programa de ejemplo depende del hecho de que twalk() no hace ninguna referencia adicional a un nodo después de llamar a la función de usuario con los argumentos "endorder" o "leaf". Esto funciona con la implementación de la biblioteca GNU, pero no está en la documentación de System V.

NAME

twalk - walk a binary search tree

LIBRARY

Tree search functions (search)

SYNOPSIS

#include <search.h>

void twalk(const void *root, void (*action)(const void *, VISIT, int));

DESCRIPTION

The twalk function traverses the binary search tree whose root is root, calling the function pointed to by action for each node visited. The action function is called with three arguments: a pointer to the node's data, a VISIT enumeration value indicating the type of traversal, and the depth of the node (the root node is at depth 0).

The VISIT enumeration is defined as:

typedef enum {
    preorder,
    postorder,
    endorder,
    leaf
} VISIT;

The action function is called in the following order:

  • preorder: The node is visited before its children.
  • leaf: The node is a leaf (has no children). This is a special case of preorder and postorder traversal.
  • postorder: The node is visited after its children.
  • endorder: The node is visited after its children. This is a synonym for postorder.

The root argument is the value returned by tsearch or tds. If the tree is empty, twalk does nothing.

RETURN VALUE

The twalk function returns no value.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Stability Evolving

STANDARDS

These functions are POSIX.1-2001 and later extensions.

HISTORY

The twalk function first appeared in FreeBSD 3.0.

NOTES

The action function receives a pointer to a pointer to the data. This is because the tree nodes store pointers to the data, not the data itself. For example, if the tree stores integers, the action function would have the following signature:

static void action(const void *nodep, VISIT which, int depth) {
    int **datap = (int **)nodep;
    // ... use **datap
}

The tsearch function returns a pointer to the node in the tree. This pointer is what should be passed as the root argument to twalk.

EXAMPLES

The following program inserts 12 random numbers between 0 and 255 into a binary search tree and then traverses the tree, printing the nodes in postorder.

#include <search.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
static void *root = NULL;
static void *
xmalloc(size_t n)
{
    void *p;
    p = malloc(n);
    if (p)
        return p;
    fprintf(stderr, "insufficient memory\n");
    exit(EXIT_FAILURE);
}
static int
compare(const void *pa, const void *pb)
{
    if (*(int *) pa < *(int *) pb)
        return -1;
    if (*(int *) pa > *(int *) pb)
        return 1;
    return 0;
}
static void
action(const void *nodep, VISIT which, int depth)
{
    int *datap;
    switch (which) {
    case preorder:
        break;
    case postorder:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    case endorder:
        break;
    case leaf:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    }
}
int
main(void)
{
    int  *ptr;
    int  **val;
    srand(time(NULL));
    for (unsigned int i = 0; i < 12; i++) {
        ptr = xmalloc(sizeof(*ptr));
        *ptr = rand() & 0xff;
        val = tsearch(ptr, &root, compare);
        if (val == NULL)
            exit(EXIT_FAILURE);
        if (*val != ptr)
            free(ptr);
    }
    twalk(root, action);
    tdestroy(root, free);
    exit(EXIT_SUCCESS);
}
