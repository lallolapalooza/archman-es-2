NOMBRE

twill - traduce WEB a TeX

SINOPSIS

twill [-x] archivo_web[.web] [{archivo_cambios[.ch]|-} [archivo_salida[.tex]]]

DESCRIPCIÓN

El programa twill se utiliza para crear un archivo TeX para ver un programa Web. Se encarga adecuadamente de los detalles tipográficos como el diseño de página y el uso de sangría, cursiva, negrita, etc., y proporciona información exhaustiva de referencias cruzadas en forma de 'mini-índices' para cada extensión de páginas y un 'índice maestro' al final que recopila automáticamente.

Los argumentos de la línea de comandos son los mismos que para tangle, excepto por la opción: -x indica omitir los índices, la lista de nombres de módulos y las páginas de índice. (Sin embargo, se seguirá escribiendo un archivo CONTENTS.tex cuando se procese el archivo TeX, a menos que se redefinan algunas macros en twimac-web.tex).

El nombre del archivo TeX de salida se forma añadiendo .tex a la raíz del nombre del archivo Web.

Hay varias macros que probablemente deberían ser redefinidas por el programador al principio del archivo Web. Es una buena idea establecer \title al nombre del programa. Y, para generar solo los módulos modificados, se puede decir \let\maybe=\iffalse (generalmente como el primer cambio en el archivo de cambios).

ENTORNO

La variable de entorno WEBINPUTS se utiliza para buscar los archivos de entrada, o la predeterminada del sistema si WEBINPUTS no está configurada. Consulte tex(1) para obtener detalles sobre la búsqueda.

ARCHIVOS

$TEXMFMAIN/tex/plain/knuth-lib/twimac-web.tex
Macros TeX utilizadas por la salida de twill.

VER TAMBIÉN

tangle(1) para referencias, autores y otra información.
