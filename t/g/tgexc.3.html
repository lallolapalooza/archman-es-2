CTGEXC

Propósito:

!>
!> CTGEXC reordena la descomposición de Schur generalizada de un par de
!> matrices complejas (A,B), utilizando una transformación de equivalencia
!> unitaria
!> (A, B) := Q * (A, B) * Z**H, de modo que el bloque diagonal de (A, B) con
!> el índice de fila IFST se mueva a la fila ILST.
!>
!> (A, B) debe estar en forma canónica de Schur generalizada, es decir, A y
!> B son ambas triangulares superiores.
!>
!> Opcionalmente, las matrices Q y Z de vectores de Schur generalizados se
!> actualizan.
!>
!>        Q(in) * A(in) * Z(in)**H = Q(out) * A(out) * Z(out)**H
!>        Q(in) * B(in) * Z(in)**H = Q(out) * B(out) * Z(out)**H
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación izquierda Q;
!>          .FALSE.: no actualiza Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualiza la matriz de transformación derecha Z;
!>          .FALSE.: no actualiza Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es array COMPLEX, dimensión (LDA,N)
!>          En la entrada, la matriz triangular superior A en el par (A, B).
!>          En la salida, la matriz A actualizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es array COMPLEX, dimensión (LDB,N)
!>          En la entrada, la matriz triangular superior B en el par (A, B).
!>          En la salida, la matriz B actualizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es array COMPLEX, dimensión (LDQ,N)
!>          En la entrada, si WANTQ = .TRUE., la matriz unitaria Q.
!>          En la salida, la matriz Q actualizada.
!>          Si WANTQ = .FALSE., Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1;
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es array COMPLEX, dimensión (LDZ,N)
!>          En la entrada, si WANTZ = .TRUE., la matriz unitaria Z.
!>          En la salida, la matriz Z actualizada.
!>          Si WANTZ = .FALSE., Z no se referencia.
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1;
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

IFST

!>          IFST es INTEGER
!>

ILST

!>          ILST es INTEGER
!>          Especifica la reordenación de los bloques diagonales de (A, B).
!>          El bloque con índice de fila IFST se mueve a la fila ILST,
!>          mediante una secuencia de intercambios entre bloques adyacentes.
!>

INFO

!>          INFO es INTEGER
!>           =0:  Salida exitosa.
!>           <0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal.
!>           =1:  El par de matrices transformado (A, B) estaría demasiado lejos
!>                de la forma de Schur generalizada; el problema está mal
!>                condicionado. (A, B) puede haber sido reordenado parcialmente,
!>                y ILST apunta a la primera fila de la posición actual
!>                del bloque que se está moviendo.
!>

NAME

dtgexc - reorders the generalized Schur decomposition of a real matrix pair (A,B) using an orthogonal equivalence transformation

SYNOPSIS

SUBROUTINE DTGEXC(
          WANTQ, WANTZ, N, A, LDA, B, LDB, Q, LDQ, Z, LDZ, IFST, ILST,
          WORK, LWORK, INFO)
INTEGER N, LDA, LDB, LDQ, LDZ, IFST, ILST, LWORK, INFO
LOGICAL WANTQ, WANTZ
DOUBLE PRECISION A(LDA,*), B(LDB,*), Q(LDQ,*), Z(LDZ,*), WORK(*)

Description

DTGEXC reorders the generalized real Schur decomposition of a real matrix pair (A,B) using an orthogonal equivalence transformation

                 (A, B) = Q * (A, B) * Z**T,

so that the diagonal block of (A, B) with row index IFST is moved to row ILST. (A, B) must be in generalized real Schur canonical form (as returned by DGGEVX), i.e. A is block upper triangular with 1-by-1 and 2-by-2 diagonal blocks. B is upper triangular. Optionally, the matrices Q and Z of generalized Schur vectors are updated.

         Q(in) * A(in) * Z(in)**T = Q(out) * A(out) * Z(out)**T
         Q(in) * B(in) * Z(in)**T = Q(out) * B(out) * Z(out)**T

Parameters

WANTQ

WANTQ is LOGICAL

.

TRUE. : update the left transformation matrix Q;
.FALSE.: do not update Q.
WANTZ

WANTZ is LOGICAL

.

TRUE. : update the right transformation matrix Z;
.FALSE.: do not update Z.
N

N is INTEGER

The order of the matrices A and B. N >= 0.

A

A is DOUBLE PRECISION array, dimension (LDA,N)

On entry, the matrix A in generalized real Schur canonical form. On exit, the updated matrix A, again in generalized real Schur canonical form.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1,N).

B

B is DOUBLE PRECISION array, dimension (LDB,N)

On entry, the matrix B in generalized real Schur canonical form (A,B). On exit, the updated matrix B, again in generalized real Schur canonical form (A,B).

LDB

LDB is INTEGER

The leading dimension of the array B. LDB >= max(1,N).

Q

Q is DOUBLE PRECISION array, dimension (LDQ,N)

On entry, if WANTQ = .TRUE., the orthogonal matrix Q. On exit, the updated matrix Q. If WANTQ = .FALSE., Q is not referenced.

LDQ

LDQ is INTEGER

The leading dimension of the array Q. LDQ >= 1. If WANTQ = .TRUE., LDQ >= N.

Z

Z is DOUBLE PRECISION array, dimension (LDZ,N)

On entry, if WANTZ = .TRUE., the orthogonal matrix Z. On exit, the updated matrix Z. If WANTZ = .FALSE., Z is not referenced.

LDZ

LDZ is INTEGER

The leading dimension of the array Z. LDZ >= 1. If WANTZ = .TRUE., LDZ >= N.

IFST

IFST is INTEGER

ILST

ILST is INTEGER

Specify the reordering of the diagonal blocks of (A, B). The block with row index IFST is moved to row ILST, by a sequence of swapping between adjacent blocks. On exit, if IFST pointed on entry to the second row of a 2-by-2 block, it is changed to point to the first row; ILST always points to the first row of the block in its final position (which may differ from its input value by +1 or -1). 1 <= IFST, ILST <= N.

WORK

WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK. LWORK >= 1 when N <= 1, otherwise LWORK >= 4*N + 16. If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

INFO

INFO is INTEGER

=0: successful exit. <0: if INFO = -i, the i-th argument had an illegal value. =1: The transformed matrix pair (A, B) would be too far from generalized Schur form; the problem is ill- conditioned. (A, B) may have been partially reordered, and ILST points to the first row of the current position of the block being moved.

NAME

ztgexc

reorders the generalized Schur decomposition of a complex matrix pair (A,B)

SYNOPSIS

Detailed Description

ZTGEXC reorders the generalized Schur decomposition of a complex matrix pair (A,B), using an unitary equivalence transformation (A, B) := Q * (A, B) * Z**H, so that the diagonal block of (A, B) with row index IFST is moved to row ILST.

(A, B) must be in generalized Schur canonical form, that is, A and B are both upper triangular.

Optionally, the matrices Q and Z of generalized Schur vectors are updated.

Q(in) * A(in) * Z(in)**H = Q(out) * A(out) * Z(out)**H

Q(in) * B(in) * Z(in)**H = Q(out) * B(out) * Z(out)**H
