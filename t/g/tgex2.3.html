CTGEX2 intercambia bloques diagonales adyacentes en un par de matrices (cuasi) triangulares superiores mediante una transformación de equivalencia unitaria.

Propósito:

!>
!> CTGEX2 intercambia bloques diagonales adyacentes de 1 por 1 (A11,B11) y
!> (A22,B22) en un par de matrices triangulares superiores (A, B) mediante una
!> transformación de equivalencia unitaria.
!>
!> (A, B) debe estar en forma canónica de Schur generalizada, es decir, A y
!> B son ambas triangulares superiores.
!>
!> Opcionalmente, las matrices Q y Z de vectores de Schur generalizados se
!> actualizan.
!>
!>        Q(entrada) * A(entrada) * Z(entrada)**H = Q(salida) * A(salida) * Z(salida)**H
!>        Q(entrada) * B(entrada) * Z(entrada)**H = Q(salida) * B(salida) * Z(salida)**H
!>
!>

Parámetros

WANTQ 
!>          WANTQ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación izquierda Q;
!>          .FALSE.: no actualizar Q.
!>

WANTZ

!>          WANTZ es LOGICAL
!>          .TRUE. : actualizar la matriz de transformación derecha Z;
!>          .FALSE.: no actualizar Z.
!>

N

!>          N es INTEGER
!>          El orden de las matrices A y B. N >= 0.
!>

A

!>          A es array COMPLEX, dimension (LDA,N)
!>          En la entrada, la matriz A en el par (A, B).
!>          En la salida, la matriz A actualizada.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es array COMPLEX, dimension (LDB,N)
!>          En la entrada, la matriz B en el par (A, B).
!>          En la salida, la matriz B actualizada.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

Q

!>          Q es array COMPLEX, dimension (LDQ,N)
!>          Si WANTQ = .TRUE, en la entrada, la matriz unitaria Q. En la
!>          salida, la matriz Q actualizada.
!>          No referenciado si WANTQ = .FALSE..
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q. LDQ >= 1;
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z es array COMPLEX, dimension (LDZ,N)
!>          Si WANTZ = .TRUE, en la entrada, la matriz unitaria Z. En la
!>          salida, la matriz Z actualizada.
!>          No referenciado si WANTZ = .FALSE..
!>

LDZ

!>          LDZ es INTEGER
!>          La dimensión principal del array Z. LDZ >= 1;
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

J1

!>          J1 es INTEGER
!>          El índice del primer bloque (A11, B11).
!>

INFO

!>          INFO es INTEGER
!>           =0:  Salida exitosa.
!>           =1:  El par de matrices transformado (A, B) estaría demasiado
!>                lejos de la forma de Schur generalizada; el problema es
!>                mal condicionado.
!>

subroutine dtgex2 (logical wantq, logical wantz, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldz, * ) z, integer ldz, integer j1, integer n1, integer n2, double precision, dimension( * ) work, integer lwork, integer info)

DTGEX2 swaps adjacent diagonal blocks in an upper (quasi) triangular matrix pair by an orthogonal equivalence transformation.

Purpose:

!>
!> DTGEX2 swaps adjacent diagonal blocks (A11, B11) and (A22, B22)
!> of size 1-by-1 or 2-by-2 in an upper (quasi) triangular matrix pair
!> (A, B) by an orthogonal equivalence transformation.
!>
!> (A, B) must be in generalized real Schur canonical form (as returned
!> by DGGEES), i.e. A is block upper triangular with 1-by-1 and 2-by-2
!> diagonal blocks. B is upper triangular.
!>
!> Optionally, the matrices Q and Z of generalized Schur vectors are
!> updated.
!>
!>        Q(in) * A(in) * Z(in)**T = Q(out) * A(out) * Z(out)**T
!>        Q(in) * B(in) * Z(in)**T = Q(out) * B(out) * Z(out)**T
!>
!>

Parameters

WANTQ 
!>          WANTQ is LOGICAL
!>          .TRUE. : update the left transformation matrix Q;
!>          .FALSE.: do not update Q.
!>

WANTZ

!>          WANTZ is LOGICAL
!>          .TRUE. : update the right transformation matrix Z;
!>          .FALSE.: do not update Z.
!>          Note that we do not select the orthogonal transformations,
!>          so we do not need to know WANTZ. We are just given the
!>          current orthogonal transformations.
!>          The routine will not update Z.
!>

N

!>          N is INTEGER
!>          The order of the matrices A and B. N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimensions (LDA,N)
!>          On entry, the matrix A in the pair (A, B).
!>          On exit, the updated matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

B

!>          B is DOUBLE PRECISION array, dimensions (LDB,N)
!>          On entry, the matrix B in the pair (A, B).
!>          On exit, the updated matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

Q

!>          Q is DOUBLE PRECISION array, dimension (LDQ,N)
!>          On entry, if WANTQ = .TRUE., the orthogonal matrix Q.
!>          On exit, the updated matrix Q.
!>          Not referenced if WANTQ = .FALSE..
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= 1.
!>          If WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (LDZ,N)
!>          On entry, if WANTZ =.TRUE., the orthogonal matrix Z.
!>          On exit, the updated matrix Z.
!>          Not referenced if WANTZ = .FALSE..
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1.
!>          If WANTZ = .TRUE., LDZ >= N.
!>

J1

!>          J1 is INTEGER
!>          The index to the first block (A11, B11). 1 <= J1 <= N.
!>

N1

!>          N1 is INTEGER
!>          The order of the first block (A11, B11). N1 = 0, 1 or 2.
!>

N2

!>          N2 is INTEGER
!>          The order of the second block (A22, B22). N2 = 0, 1 or 2.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)).
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >=  MAX( 1, N*(N2+N1), (N2+N1)*(N2+N1)*2 )
!>

INFO

!>          INFO is INTEGER
!>            =0: Successful exit
!>            >0: If INFO = 1, the transformed matrix (A, B) would be
!>                too far from generalized Schur form; the blocks are
!>                not swapped and (A, B) and (Q, Z) are unchanged.
!>                The problem of swapping is too ill-conditioned.
!>            <0: If INFO = -16: LWORK is too small. Appropriate value
!>                for LWORK is returned in WORK(1).
!>

ztgex2(3)`LAPACK` man page

NAME

ztgex2

swaps adjacent diagonal blocks in an upper (quasi) triangular matrix pair by an unitary equivalence transformation

SYNOPSIS

subroutine   ztgex2 (logical wantq, logical wantz, integer n, complex*16, dimension( lda, *   ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16,   dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer   ldz, integer j1, integer info)

Detailed Description

ZTGEX2 swaps adjacent diagonal blocks in an upper (quasi) triangular matrix pair by an unitary equivalence transformation.

Purpose:

!>
!> ZTGEX2 swaps adjacent diagonal 1 by 1 blocks (A11,B11) and (A22,B22)
!> in an upper triangular matrix pair (A, B) by an unitary equivalence
!> transformation.
!>
!> (A, B) must be in generalized Schur canonical form, that is, A and
!> B are both upper triangular.
!>
!> Optionally, the matrices Q and Z of generalized Schur vectors are
!> updated.
!>
