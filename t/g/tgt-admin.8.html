NOMBRE

tgt-admin - Herramienta de configuración de destino SCSI de Linux

SINOPSIS

tgt-admin [-e --execute] [--delete <valor>] [--offline <valor>] [--ready <valor>] [-s --show] [-C --control-port <NNNN>] [-c --conf <archivo>] [--ignore-errors] [-f --force] [-p --pretend] [--dump] [-v --verbose] [-h --help]

DESCRIPCIÓN

tgt-admin es una utilidad que permite una configuración persistente de destinos y LUNs. Utiliza comandos `tgtadm` para crear, eliminar y mostrar destinos.

OPCIONES

-e, --execute

Lee `/etc/tgt/targets.conf` y ejecuta comandos `tgtadm`. Si el destino ya existe, no se procesará. Ver `--update`.

-d, --delete <valor>

Elimina todos o destinos seleccionados. El destino solo se eliminará si no está en uso (ningún iniciador está conectado a él).

Si desea eliminar destinos que están en uso, debe agregar el flag `--force`.

Ejemplo de uso:
    --delete ALL            - elimina todos los destinos
    --delete tid=4          - elimina el destino 4
                              (destino con tid 4)
    --delete iqn.2008-08.com.example:some.target
                            - elimina este destino

--offline

Pone todos o destinos seleccionados en estado fuera de línea. 
Ejemplo de uso:
    --offline ALL           - pone fuera de línea todos los destinos
    --offline tid=4         - pone fuera de línea el destino 4
                              (destino con tid 4)
    --offline iqn.2008-08.com.example:some.target
                            - pone fuera de línea este destino

--ready

Pone todos o destinos seleccionados en estado listo. 
Ejemplo de uso:
    --ready ALL             - pone listos todos los destinos
    --ready tid=4           - pone listo el destino 4
                              (destino con tid 4)
    --ready iqn.2008-08.com.example:some.target
                            - pone listo este destino

--update <valor>

Actualiza todos o destinos seleccionados. El destino solo se actualizará si no está en uso (ningún iniciador está conectado a él).

Si desea actualizar destinos que están en uso, debe agregar el flag `--force`.

Ejemplo de uso:
    --update ALL             - pone listos todos los destinos
    --update tid=4           - pone listo el destino 4
                               (destino con tid 4)
    --update iqn.2008-08.com.example:some.target
                             - actualiza este destino

-s, --show

Muestra todos los destinos.

-C, --control-port <NNNN>

Es posible ejecutar múltiples instancias concurrentes de `tgtd` en un host. Este argumento se utiliza para controlar con qué instancia operará el comando `tgt-admin`.

-c, --conf <archivo de configuración>

Especifica un archivo de configuración alternativo en lugar de `/etc/tgt/targets.conf`, que es el predeterminado.

--ignore-errors

Continúa incluso si `tgtadm` sale con un código distinto de cero.

-f, --force

Fuerza algunas operaciones incluso si el destino está en uso.

-p, --pretend

Solo imprime las opciones de `tgtadm` que se usarían; no ejecuta ninguna acción. Asume `-v`.

--dump

Descarga la configuración actual de `tgtd`. Nota: no incluye parámetros detallados, como el almacenamiento en caché de escritura.

-v, --verbose

Aumenta la verbosidad (muestra los comandos `tgtadm` utilizados).

-h, --help

Muestra una lista de las opciones disponibles y sale.

ARCHIVOS

/etc/tgt/targets.conf

Archivo de configuración para `tgt-admin`.

/usr/share/doc/tgt/targets.conf.example

Archivo de configuración de ejemplo para `tgt-admin`.
