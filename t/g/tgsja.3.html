CTGSJA

Propósito:

!>
!> CTGSJA calcula la descomposición de valores singulares generalizada (GSVD)
!> de dos matrices complejas triangulares superiores (o trapezoidales) A y B.
!>
!> A la entrada, se asume que las matrices A y B tienen las siguientes
!> formas, que pueden haberse obtenido mediante la subrutina de preprocesamiento CGGSVP
!> de una matriz general M-por-N A y una matriz P-por-N B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz K-por-K A12 y la matriz L-por-L B13 son triangulares
!> superiores no singulares; A23 es L-por-L triangular superior si M-K-L >= 0,
!> de lo contrario, A23 es (M-K)-por-L trapezoidal superior.
!>
!> A la salida,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices unitarias.
!> R es una matriz triangular superior no singular, y D1
!> y D2 son matrices "diagonales", que son de las siguientes
!> estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) a la salida.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> donde
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) se almacena en A(1:M, N-K-L+1:N) y R33 se almacena
!>     (  0  R22 R23 )
!> en B(M-K+1:L,N+M-K-L+1:N) a la salida.
!>
!> El cálculo de las matrices de transformación unitaria U, V o Q
!> es opcional. Estas matrices pueden formarse explícitamente, o
!> pueden premultiplicarse por las matrices de entrada U1, V1 o Q1.
!>

CTGSJA


Purpose:




!>
!> CTGSJA computes the generalized singular value decomposition (GSVD)
!> of two complex upper triangular (or trapezoidal) matrices A and B.
!>
!> On entry, it is assumed that matrices A and B have the following
!> forms, which may be obtained by the preprocessing subroutine CGGSVP
!> from a general M-by-N matrix A and P-by-N matrix B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) if M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) if M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> where the K-by-K matrix A12 and L-by-L matrix B13 are nonsingular
!> upper triangular; A23 is L-by-L upper triangular if M-K-L >= 0,
!> otherwise A23 is (M-K)-by-L upper trapezoidal.
!>
!> On exit,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> where U, V and Q are unitary matrices.
!> R is a nonsingular upper triangular matrix, and D1 and D2 are
!> ``diagonal'' matrices, which are of the following structures:
!>
!> If M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> where
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R is stored in A(1:K+L,N-K-L+1:N) on exit.
!>
!> If M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> where
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) is stored in A(1:M, N-K-L+1:N) and R33 is stored
!>     (  0  R22 R23 )
!> in B(M-K+1:L,N+M-K-L+1:N) on exit.
!>
!> The computation of the unitary transformation matrices U, V or Q
!> is optional.  These matrices may either be formed explicitly, or they
!> may be postmultiplied into input matrices U1, V1, or Q1.
!> 




Parameters

!>          JOBU is CHARACTER*1
!>          = 'U':  U must contain a unitary matrix U1 on entry, and
!>                  the product U1*U is returned;
!>          = 'I':  U is initialized to the unit matrix, and the
!>                  unitary matrix U is returned;
!>          = 'N':  U is not computed.
!> 


JOBV


!>          JOBV is CHARACTER*1

!>          = 'N':  V is not computed.
!> 


JOBQ


!>          JOBQ is CHARACTER*1
!>          = 'Q':  Q must contain a unitary matrix Q1 on entry, and
!>                  the product Q1*Q is returned;
!>          = 'I':  Q is initialized to the unit matrix, and the
!>                  unitary matrix Q is returned;
!>          = 'N':  Q is not computed.
!> 


M


!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 


P


!>          P is INTEGER
!>          The number of rows of the matrix B.  P >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the matrices A and B.  N >= 0.
!> 


K


!>          K is INTEGER
!> 


L


!>          L is INTEGER
!>
!>          K and L specify the subblocks in the input matrices A and B:

!>          See Further Details.
!>

!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, A(N-K+1:N,1:MIN(K+L,M) ) contains the triangular
!>          matrix R or part of R.  See Purpose for details.
!>

!>          On entry, the P-by-N matrix B.
!>          On exit, if necessary, B(M-K+1:L,N+M-K-L+1:N) contains
!>          a part of R.  See Purpose for details.
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,P).
!> 


TOLA


!>          TOLA is REAL
!> 


TOLB


!>          TOLB is REAL
!>
!>          TOLA and TOLB are the convergence criteria for the Jacobi-
!>          Kogbetliantz iteration procedure. Generally, they are the
!>          same as used in the preprocessing step, say
!>              TOLA = max(M,N)*norm(A)*MAZHEPS,
!>              TOLB = max(P,N)*norm(B)*MAZHEPS.
!> 


ALPHA


!>          ALPHA is COMPLEX array, dimension (N)
!> 


BETA


!>          BETA is COMPLEX array, dimension (N)
!>
!>          On exit, ALPHA and BETA contain the diagonal entries of
!>          the matrices C and S respectively. alpha(1:k) and beta(1:k)
!>          are not explicitly set.
!>          If K+L < N, the remaining entries of ALPHA and BETA are set to 0.
!>          We assume ALPHA(1:K+L) = 1 and BETA(1:K+L) = 0 if K+L = 0.
!>          If K+L > 0, ALPHA(1:K+L) = 1 and BETA(1:K+L) = 0.
!>          Note that if K+L < N,
!>          ALPHA(K+L+1:N) = 0
!>          BETA(K+L+1:N)  = 0.
!> 


U


!>          U is COMPLEX array, dimension (LDU,M)
!>          On entry, if JOBU = 'U', U must contain a matrix U1 (usually
!>          the unitary matrix returned by CGGSVP).
!>          On exit,
!>          if JOBU = 'I', U contains the unitary matrix U;
!>          if JOBU = 'U', U contains the product U1*U.
!>          If JOBU = 'N', U is not referenced.
!> 


LDU


!>          LDU is INTEGER
!>          The leading dimension of the array U. LDU >= max(1,M) if
!>          JOBU = 'U'; LDU >= 1 otherwise.
!> 


V


!>          V is COMPLEX array, dimension (LDV,P)
!>          On entry, if JOBV = 'V', V must contain a matrix V1 (usually
!>          the unitary matrix returned by CGGSVP).
!>          On exit,
!>          if JOBV = 'I', V contains the unitary matrix V;
!>          if JOBV = 'V', V contains the product V1*V.
!>          If JOBV = 'N', V is not referenced.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V. LDV >= max(1,P) if
!>          JOBV = 'V'; LDV >= 1 otherwise.
!> 


Q


!>          Q is COMPLEX array, dimension (LDQ,N)
!>          On entry, if JOBQ = 'Q', Q must contain a matrix Q1 (usually
!>          the unitary matrix returned by CGGSVP).

LDQ

Further Details:




!>
!> CTGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
!> min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
!> matrix B13 to the form:
!>
!>           U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,
!>
!> where U1, V1 and Q1 are unitary matrix.
!> C1 and S1 are diagonal matrices satisfying
!>
!>                C1**2 + S1**2 = I,
!>
!> and R1 is an L-by-L nonsingular upper triangular matrix.
!>

!>
!> STGSJA calcula la descomposición de valores singulares generalizados (GSVD)
!> de dos matrices reales triangulares superiores (o trapezoidales) A y B.
!>
!> En la entrada, se asume que las matrices A y B tienen las siguientes
!> formas, que pueden ser obtenidas por la subrutina de preprocesamiento SGGSVP
!> a partir de una matriz general M-por-N A y una matriz P-por-N B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> donde la matriz A12 de K-por-K y la matriz B13 de L-por-L son superiores triangulares
!> no singulares; A23 es superior triangular de L-por-L si M-K-L >= 0,
!> de lo contrario A23 es superior trapezoidal de (M-K)-por-L.
!>
!> En la salida,
!>
!>        U**T *A*Q = D1*( 0 R ),    V**T *B*Q = D2*( 0 R ),
!>
!> donde U, V y Q son matrices ortogonales.
!> R es una matriz superior triangular no singular, y D1 y D2 son
!> matrices "diagonales", que tienen las siguientes estructuras:
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> donde
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R se almacena en A(1:K+L,N-K-L+1:N) en la salida.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>

!> S = diag( BETA(K+1),  ... , BETA(M) ),

NAME

                    
tgsja — generalized singular value decomposition

                

                

                    
SYNOPSIS

                    
SUBROUTINE ZTGSJA(JOBU, JOBV, JOBQ, M, N, K, L, A, LDA, B, LDB, ALPHA, BETA, U, LDU, V, LDV, Q, LDQ, WORK, NCYCLE, INFO)
    CHARACTER JOBU, JOBV, JOBQ
    INTEGER M, N, K, L, LDA, LDB, LDU, LDV, LDQ, NCYCLE, INFO
    DOUBLE PRECISION ALPHA( * ), BETA( * )
    COMPLEX*16 A( * ), B( * ), U( * ), V( * ), Q( * ), WORK( * )
                    

                

                

                    
Description

                    
ZTGSJA uses the Kogbetliantz algorithm to compute the
                        generalized singular value decomposition of an M-by-N
                        matrix A and an M-by-P matrix B.

                    
The side effect of this computation is that the
                        matrices A and B are reduced to the generalized upper
                        triangular form:

                    

                        
     A = U*S1*Q'
     B = V*S2*Q'
                        

                    

                    
where U, V, and Q are unitary matrices. S1 and S2 are
                        generalized upper triangular matrices.

                    
If B is M-by-N, the generalized singular value
                        decomposition is:

                    

                        
     A = U*S1*Q'
     B = V*S2*Q'
                        

                    

                    
where S1 and S2 are M-by-N matrices.

                    
The generalized singular values are the ratios
                        alpha(i)/beta(i). For this to be
                        defined, one requires that beta(i) is nonzero. The routine
                        ensures that beta(i) are always nonzero.

                    
The routine ZTGSJA is the core part of the SVD
                        and GSVD algorithm.

Further Details

                    

                        
  The Kogbetliantz iteration procedure. Generally, they are the
  same as used in the preprocessing step, say
      TOLA = MAX(M,N)*norm(A)*MAZHEPS,
      TOLB = MAX(P,N)*norm(B)*MAZHEPS.
                        

                    

                    

                        
  ZTGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
  min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
  matrix B13 to the form:

       U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,

  where U1, V1 and Q1 are unitary matrix.
  C1 and S1 are diagonal matrices satisfying

                   C1**2 + S1**2 = I,

  and R1 is an L-by-L nonsingular upper triangular matrix.
