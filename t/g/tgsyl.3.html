CTGSYL

Propósito:

!>
!> CTGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C            (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de m x n, (A, D), (B, E) y
!> (C, F) son pares de matrices dados de tamaño m x m, n x n y m x n,
!> respectivamente, con entradas complejas. A, B, D y E son triangulares
!> superiores (es decir, (A,D) y (B,E) en forma de Schur generalizada).
!>
!> La solución (R, L) sobrescribe a (C, F). 0 <= SCALE <= 1
!> es un factor de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial (1) es equivalente a resolver Zx = scale*b, donde Z
!> se define como
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]        (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Aquí Ix es la matriz identidad de tamaño x y X**H es la transpuesta conjugada
!> de X. Kron(X, Y) es el producto de Kronecker entre las matrices X e Y.
!>
!> Si TRANS = 'C', se resuelve y en el sistema transpuesto conjugado Z**H *y = scale*b,
!> que es equivalente a resolver para R y L en
!>
!>             A**H * R + D**H * L = scale * C           (3)
!>             R * B**H + L * E**H = scale * -F
!>
!> Este caso (TRANS = 'C') se utiliza para calcular una estimación basada en la
!> norma uno de Dif[(A,D), (B,E)], la separación entre los pares de matrices (A,D)
!> y (B,E), utilizando CLACON.
!>
!> Si IJOB >= 1, CTGSYL calcula una estimación basada en la norma de Frobenius de
!> Dif[(A,D),(B,E)]. Es decir, la inversa de un límite inferior de la
!> inversa del valor singular más pequeño de Z.
!>
!> Este es un algoritmo BLAS de nivel 3.
!>

Parámetros

TRANS 
!>          TRANS es CHARACTER*1
!>          = 'N': resuelve la ecuación de Sylvester generalizada (1).
!>          = 'C': resuelve el sistema (3).
!>

IJOB

!>          IJOB es INTEGER
!>          Especifica qué tipo de funcionalidad se va a realizar.
!>          =0: resolver solo (1).
!>          =1: La funcionalidad de 0 y 3.
!>          =2: La funcionalidad de 0 y 4.
!>          =3: Solo se estima Dif[(A,D), (B,E)].
!>              (se utiliza estrategia de previsualización).
!>          =4: Solo se estima Dif[(A,D), (B,E)].
!>              (se utiliza CGECON en subsistemas).
!>          No se hace referencia si TRANS = 'C'.
!>

M

!>          M es INTEGER
!>          El orden de las matrices A y D, y la dimensión de fila de
!>          las matrices C, F, R y L.
!>

N

!>          N es INTEGER
!>          El orden de las matrices B y E, y la dimensión de columna de
!>          las matrices C, F, R y L.
!>

A

!>          A es un array COMPLEX, dimensión (LDA, M)
!>          La matriz triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1, M).
!>

B

!>          B es un array COMPLEX, dimensión (LDB, N)
!>          La matriz triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1, N).
!>

C

!>          C es un array COMPLEX, dimensión (LDC, N)
!>          En la entrada, C contiene el lado derecho de la primera matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrito por
!>          la solución R. Si IJOB = 3 o 4 y TRANS = 'N', C contiene R,
!>          la solución obtenida durante el cálculo de la
!>          estimación de Dif.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1, M).
!>

D

!>          D es un array COMPLEX, dimensión (LDD, M)
!>          La matriz triangular superior D.
!>

LDD

!>          LDD es INTEGER
!>          La dimensión principal del array D. LDD >= max(1, M).
!>

E

!>          E es un array COMPLEX, dimensión (LDE, N)
!>          La matriz triangular superior E.
!>

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E. LDE >= max(1, N).
!>

F

!>          F es un array COMPLEX, dimensión (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          de la ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrito por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución obtenida durante el cálculo de la
!>          estimación de Dif.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1, M).
!>

DIF

!>          DIF es REAL
!>          En la salida, DIF es la inversa de un límite inferior de la
!>          inversa de la función Dif, es decir, DIF es un límite superior de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), donde Z es como en (2).
!>          Si IJOB = 0 o TRANS = 'C', DIF no se hace referencia.
!>

SCALE

!>          SCALE es REAL
!>          En la salida, SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          de un sistema ligeramente perturbado, pero las matrices de entrada A, B,
!>          D y E no se han modificado. Si SCALE = 0, R y L contendrán
!>          las soluciones del sistema homogéneo con C = F = 0.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK > = 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y XERBLA no emite
!>          ningún mensaje de error relacionado con LWORK.
!>

IWORK

!>          IWORK es un array INTEGER, dimensión (M+N+2)
!> 
<p class="Pp">INFO</p>
<pre>!>          INFO is INTEGER
!>            =0: successful exit
!>            <0: If INFO = -i, the i-th argument had an illegal value.
!>            >0: (A, D) and (B, E) have common or very close
!>                eigenvalues.
!>/pre>

STGSYL

Propósito

!>
!> STGSYL resuelve la ecuación de Sylvester generalizada:
!>
!>             A * R - L * B = scale * C                 (1)
!>             D * R - L * E = scale * F
!>
!> donde R y L son matrices desconocidas de m x n, (A, D), (B, E) y
!> (C, F) son pares de matrices dadas de tamaño m x m, n x n y m x n,
!> respectivamente, con entradas reales. (A, D) y (B, E) deben estar en
!> forma canónica de Schur generalizada (real), es decir, A y B son cuasi
!> triangulares superiores y D y E son triangulares superiores.
!>
!> La solución (R, L) sobrescribe a (C, F). 0 <= SCALE <= 1 es un factor
!> de escala de salida elegido para evitar el desbordamiento.
!>
!> En notación matricial, (1) es equivalente a resolver Zx = scale b, donde
!> Z se define como
!>
!>            Z = [ kron(In, A)  -kron(B**T, Im) ]         (2)
!>                [ kron(In, D)  -kron(E**T, Im) ].
!>
!> Aquí Ik es la matriz identidad de tamaño k y X**T es la transpuesta de
!> X. kron(X, Y) es el producto de Kronecker entre las matrices X e Y.

!>          ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, C ha sido sobrescrito por

LDE

!>          LDE es INTEGER
!>          La dimensión principal del array E. LDE >= max(1, N).
!>

F

!>          F es COMPLEX*16 array, dimension (LDF, N)
!>          En la entrada, F contiene el lado derecho de la segunda matriz
!>          ecuación en (1) o (3).
!>          En la salida, si IJOB = 0, 1 o 2, F ha sido sobrescrito por
!>          la solución L. Si IJOB = 3 o 4 y TRANS = 'N', F contiene L,
!>          la solución lograda durante el cálculo de la
!>          estimación de Dif.
!>

LDF

!>          LDF es INTEGER
!>          La dimensión principal del array F. LDF >= max(1, M).
!>

DIF

!>          DIF es DOUBLE PRECISION
!>          En la salida, DIF es la recíproca de un límite inferior de la
!>          recíproca de la función Dif, es decir, DIF es un límite superior de
!>          Dif[(A,D), (B,E)] = sigma-min(Z), donde Z como en (2).
!>          Si IJOB = 0 o TRANS = 'C', DIF no se referencia.
!>

SCALE

!>          SCALE es DOUBLE PRECISION
!>          En la salida, SCALE es el factor de escala en (1) o (3).
!>          Si 0 < SCALE < 1, C y F contienen las soluciones R y L, respectivamente,
!>          de un sistema ligeramente perturbado pero las matrices de entrada A, B,
!>          D y E no han sido modificadas. Si SCALE = 0, R y L contendrán
!>          las soluciones del sistema homogéneo con C = F = 0.
!>

WORK

!>          WORK es COMPLEX*16 array, dimension (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK > = 1.
!>          Si IJOB = 1 o 2 y TRANS = 'N', LWORK >= max(1,2*M*N).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina

IWORK

!>          IWORK es INTEGER array, dimension (M+N+2)
