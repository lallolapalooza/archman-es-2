tkill(2) Manual de llamadas al sistema tkill(2)

NOMBRE

tkill, tgkill - enviar una señal a un hilo

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <signal.h>           /* Definición de constantes SIG* */
#include <sys/syscall.h>      /* Definición de constantes SYS_* */
#include <unistd.h>
[[deprecated]] int syscall(SYS_tkill, pid_t tid, int sig);
#include <signal.h>
int tgkill(pid_t tgid, pid_t tid, int sig);

Nota: glibc no proporciona un envoltorio para tkill(), lo que hace necesario usar syscall(2).

DESCRIPCIÓN

tgkill() envía la señal sig al hilo con el ID de hilo tid en el grupo de hilos tgid. (Por el contrario, kill(2) se puede usar para enviar una señal solo a un proceso (es decir, grupo de hilos) en su conjunto, y la señal se entregará a un hilo arbitrario dentro de ese proceso).

tkill() es un predecesor obsoleto de tgkill(). Permite especificar solo el ID de hilo de destino, lo que puede resultar en que se señale al hilo incorrecto si un hilo termina y su ID de hilo se recicla. Evite usar esta llamada al sistema.

Estas son las interfaces de llamadas al sistema brutas, destinadas al uso interno de la biblioteca de hilos.

VALOR DE RETORNO

En caso de éxito, se devuelve cero. En caso de error, se devuelve -1, y errno se establece para indicar el error.

ERRORES

EAGAIN
Se alcanzó el límite de recursos RLIMIT_SIGPENDING y sig es una señal en tiempo real.
EAGAIN
No había suficiente memoria del kernel disponible y sig es una señal en tiempo real.
EINVAL
Se especificó un ID de hilo, ID de grupo de hilos o señal inválido.
EPERM
Permiso denegado. Para los permisos requeridos, consulte kill(2).
ESRCH
No existe ningún proceso con el ID de hilo y el ID de grupo de hilos especificados.

ESTANDARES

Linux.

HISTORIA

tkill()
Linux 2.4.19 / 2.5.4.
tgkill()
Linux 2.5.75, glibc 2.30.

NOTAS

Consulte la descripción de CLONE_THREAD en clone(2) para una explicación de los grupos de hilos.

VER TAMBIÉN

clone(2), gettid(2), kill(2), rt_sigqueueinfo(2)
