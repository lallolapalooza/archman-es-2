tgamma(3) Manual de funciones de la biblioteca tgamma(3)

NOMBRE

tgamma, tgammaf, tgammal - función gamma verdadera

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double tgamma(double x);
float tgammaf(float x);
long double tgammal(long double x);
Requisitos de macro de prueba de funciones para glibc (ver feature_test_macros(7)):

tgamma(), tgammaf(), tgammal():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones calculan la función Gamma de x.

La función Gamma se define como:

Gamma(x) = integral de 0 a infinito de t^(x-1) e^-t dt

Está definida para todos los números reales excepto para los enteros no positivos. Para el entero no negativo m se tiene:

Gamma(m+1) = m!

y, de forma más general, para todos los x:

Gamma(x+1) = x * Gamma(x)

Además, lo siguiente es válido para todos los valores de x fuera de los polos:

Gamma(x) * Gamma(1 - x) = PI / sin(PI * x)

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven Gamma(x).

Si x es un NaN, se devuelve un NaN.

Si x es infinito positivo, se devuelve infinito positivo.

Si x es un entero negativo o infinito negativo, ocurre un error de dominio y se devuelve un NaN.

Si el resultado desborda, ocurre un error de rango y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el signo matemático correcto.

Si el resultado se desborda hacia cero, ocurre un error de rango y las funciones devuelven 0, con el signo matemático correcto.

Si x es -0 o +0, ocurre un error de polo y las funciones devuelven HUGE_VAL, HUGE_VALF o HUGE_VALL, respectivamente, con el mismo signo que el 0.

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si se ha producido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es un entero negativo o infinito negativo
errno se establece en EDOM. Se genera una excepción de punto flotante no válida (FE_INVALID) (pero ver BUGS).
Error de polo: x es +0 o -0
errno se establece en ERANGE. Se genera una excepción de punto flotante de división por cero (FE_DIVBYZERO).
Error de rango: desbordamiento del resultado
errno se establece en ERANGE. Se genera una excepción de punto flotante de desbordamiento (FE_OVERFLOW).

glibc también da el siguiente error que no está especificado en C99 o POSIX.1-2001.

Error de rango: desbordamiento hacia cero del resultado
Se genera una excepción de punto flotante de desbordamiento hacia cero (FE_UNDERFLOW) y errno se establece en ERANGE.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, ver attributes(7).

Interfaz Atributo Valor
tgamma (), tgammaf (), tgammal () Seguridad de hilos MT-Safe

ESTANDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.

NOTAS

Esta función tuvo que llamarse "función gamma verdadera" ya que ya existe una función gamma(3) que devuelve otra cosa (ver gamma(3) para más detalles).

ERRORES CONOCIDOS

Antes de glibc 2.18, la implementación de glibc de estas funciones no establecía errno en EDOM cuando x es infinito negativo.

Antes de glibc 2.19, la implementación de glibc de estas funciones no establecía errno en ERANGE en un error de rango por desbordamiento hacia cero.

En las versiones 2.3.3 y anteriores de glibc, un argumento de +0 o -0 producía incorrectamente un error de dominio (errno establecido en EDOM y una excepción FE_INVALID generada), en lugar de un error de polo.
