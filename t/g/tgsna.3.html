CTGSNA

Propósito:

!>
!> CTGSNA estima los números de condición recíprocos para valores
!> propios y/o vectores propios especificados de un par de matrices (A, B).
!>
!> (A, B) debe estar en forma canónica de Schur generalizada, es decir,
!> A y B son ambas matrices triangulares superiores.
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (DIF):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (DIF);
!>          = 'B': para ambos, valores propios y vectores propios (S y DIF).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcula los números de condición para todos los pares
!>                 de valores propios;
!>          = 'S': calcula los números de condición para pares de valores
!>                 propios seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares de valores propios
!>          para los cuales se requieren números de condición. Para
!>          seleccionar los números de condición para el j-ésimo valor
!>          propio y/o vector propio correspondiente, SELECT(j) debe
!>          establecerse a .TRUE..
!>          Si HOWMNY = 'A', SELECT no se utiliza.
!>

N

!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,N)
!>          La matriz triangular superior A en el par (A,B).
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX de dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A, B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

VL

!>          VL es un array COMPLEX de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios
!>          izquierdos de (A, B), correspondientes a los pares de valores
!>          propios especificados por HOWMNY y SELECT. Los vectores
!>          propios deben almacenarse en columnas consecutivas de VL,
!>          tal como devuelve CTGEVC.
!>          Si JOB = 'V', VL no se utiliza.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1; y
!>          Si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios
!>          derechos de (A, B), correspondientes a los pares de valores
!>          propios especificados por HOWMNY y SELECT. Los vectores
!>          propios deben almacenarse en columnas consecutivas de VR,
!>          tal como devuelve CTGEVC.
!>          Si JOB = 'V', VR no se utiliza.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1;
!>          Si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array REAL de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array.
!>          Si JOB = 'V', S no se utiliza.
!>

DIF

!>          DIF es un array REAL de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos
!>          estimados de los vectores propios seleccionados, almacenados
!>          en elementos consecutivos del array.
!>          Si los valores propios no pueden reordenarse para calcular DIF(j),
!>          DIF(j) se establece a 0; esto solo puede ocurrir cuando el valor
!>          real sería muy pequeño de todos modos.
!>          Para cada valor/vector propio especificado por SELECT, DIF
!>          almacena una estimación basada en la norma de Frobenius de Difl.
!>          Si JOB = 'E', DIF no se utiliza.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S y DIF. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y DIF utilizados para
!>          almacenar los números de condición especificados; se utiliza
!>          un elemento por cada valor propio seleccionado. Si HOWMNY = 'A',
!>          M se establece a N.
!>

WORK

!>          WORK es un array COMPLEX de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' o 'B', LWORK >= max(1,2*N*N).
!>

IWORK

!>          IWORK es un array INTEGER de dimensión (N+2)
!>          Si JOB = 'E', IWORK no se utiliza.
!>

INFO

!>          INFO es INTEGER
!>          = 0: Salida exitosa
!>          < 0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Purpose:

!>
!> DTGSNA estima los números de condición recíprocos para valores y/o
!> vectores propios especificados de un par de matrices (A, B) en
!> forma canónica de Schur real generalizada (o de cualquier par de
!> matrices (Q*A*Z**T, Q*B*Z**T) con matrices ortogonales Q y Z, donde
!> Z**T denota la transpuesta de Z.
!>
!> (A, B) deben estar en forma de Schur real generalizada (tal como la
!> devuelve DGGES), es decir, A es cuasi-triangular por bloques con
!> bloques diagonales de 1x1 y 2x2. B es triangular superior.
!>
!>

Parameters

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (DIF):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (DIF);
!>          = 'B': para ambos, valores propios y vectores propios (S y DIF).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcula los números de condición para todos los pares
!>                 propios;
!>          = 'S': calcula los números de condición para pares propios
!>                 seleccionados especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los
!>          cuales se requieren los números de condición. Para seleccionar
!>          los números de condición para el par propio correspondiente
!>          a un valor propio real w(j), SELECT(j) debe ser .TRUE.. Para
!>          seleccionar los números de condición correspondientes a un par
!>          conjugado complejo de valores propios w(j) y w(j+1), uno o
!>          ambos, SELECT(j) o SELECT(j+1), deben ser .TRUE..
!>          Si HOWMNY = 'A', SELECT no se referencia.
!>

N

!>          N es INTEGER
!>          El orden del par de matrices cuadradas (A, B). N >= 0.
!>

A

!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array DOUBLE PRECISION, de dimensión (LDB,N)
!>          La matriz triangular superior B en el par (A,B).
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

VL

!>          VL es un array DOUBLE PRECISION, de dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios
!>          izquierdos de (A, B), correspondientes a los pares propios
!>          especificados por HOWMNY y SELECT. Los vectores propios deben
!>          estar almacenados en columnas consecutivas de VL, tal como
!>          devuelto por DTGEVC.
!>          Si JOB = 'V', VL no se referencia.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1.
!>          Si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array DOUBLE PRECISION, de dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios
!>          derechos de (A, B), correspondientes a los pares propios
!>          especificados por HOWMNY y SELECT. Los vectores propios deben
!>          estar almacenados en columnas consecutivas de VR, tal como
!>          devuelto por DTGEVC.
!>          Si JOB = 'V', VR no se referencia.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1.
!>          Si JOB = 'E' o 'B', LDVR >= N.

S

!>          S es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos
!>          consecutivos del array. Para un par conjugado complejo de
!>          valores propios, dos elementos consecutivos de S se establecen
!>          al mismo valor. Así, S(j), DIF(j), y las columnas j de VL y VR
!>          corresponden todos al mismo par propio (pero no en general
!>          al j-ésimo par propio, a menos que todos los pares propios
!>          sean seleccionados).
!>          Si JOB = 'V', S no se referencia.
!>

DIF

!>          DIF es un array DOUBLE PRECISION, de dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos
!>          estimados de los vectores propios seleccionados, almacenados
!>          en elementos consecutivos del array. Para un vector propio
!>          complejo, dos elementos consecutivos de DIF se establecen al
!>          mismo valor. Si los valores propios no pueden ser reordenados

!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S y DIF. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y DIF utilizados para
!>          almacenar los números de condición especificados; para cada
!>          valor propio real seleccionado se utiliza un elemento, y para
!>          cada par conjugado complejo de valores propios se utilizan dos
!>          elementos.
!>          Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array DOUBLE PRECISION, de dimensión (MAX(1,LWORK))
!>          A la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,N).
!>          Si JOB = 'V' o 'B', LWORK >= 2*N*(N+2)+16.

!>          Si LWORK = -1, entonces se asume una consulta de espacio de

IWORK

!>          IWORK es un array INTEGER, de dimensión (N + 6)

!>

INFO

!>          INFO es INTEGER
!>          =0: Salida exitosa
!>          <0: Si INFO = -i, el i-ésimo argumento tenía un valor ilegal

Further Details:

!>
!>  El recíproco del número de condición de un valor propio generalizado
!>  w = (a, b) se define como
!>
!>       S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  donde u y v son los vectores propios izquierdo y derecho de (A, B)
!>  correspondientes a w; |z| denota el valor absoluto del número
!>  complejo, y norm(u) denota la norma 2 del vector u.
!>  El par (a, b) corresponde a un valor propio w = a/b (= u**TAv/u**TBv)
!>  del par de matrices (A, B). Si tanto a como b son cero, entonces (A B)
!>  es singular y se devuelve S(I) = -1.
!>
!>  Una cota de error aproximada en la distancia de cuerda entre el i-ésimo
!>  valor propio generalizado calculado w y el valor propio verdadero
!>  es
!>
!>                      EPS * norm(A,B) / S(i)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El número de condición recíproco de un vector propio generalizado v
!>  se define como
!>
!>          Dif[(a, b), (A22, B22)] = sigma-min( Zl )
!>
!>  donde sigma-min(Zl) denota el valor singular mínimo de
!>
!>         Zl = [ kron(a, In-1) -kron(1, A22) ]
!>              [ kron(b, In-1) -kron(1, B22) ].
!>
!>  Aquí In-1 es la matriz identidad de tamaño n-1 y X**H es la transpuesta
!>  conjugada de X. kron(X, Y) es el producto de Kronecker entre las
!>  matrices X e Y.
!>
!>  Aproximamos el valor singular mínimo de Zl con una cota superior.
!>  Esto se hace mediante CLATDF.
!>
!>  Una cota de error aproximada para un vector propio calculado VL(i) o
!!>  VR(i) se da por
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  Ver ref. [2-3] para más detalles y referencias adicionales.
!>

!>       A chord(w, lambda) is defined as the distance between the
!>       eigenvalue w and the matrix lambda. For a generalized
!>       eigenvalue problem A*x = lambda*B*x, a chord(w, lambda) is
!>       defined as the distance between the computed eigenvalue w and
!>       the corresponding exact eigenvalue lambda.
!>
!>       chord(w, lambda) <= EPS * norm(A, B) / S(I)
!>
!>  donde EPS es la precisión de la máquina.
!>
!>  El recíproco del número de condición DIF(i) del vector propio derecho u
!>  y el vector propio izquierdo v correspondientes al valor propio generalizado w
!>  se define de la siguiente manera:
!>
!>  a) Si el i-ésimo valor propio w = (a,b) es real
!>
!>     Supongamos que U y V son transformaciones ortogonales tales que
!>
!>              U**T*(A, B)*V  = (S, T) = ( a   *  ) ( b  *  )  1
!>                                        ( 0  S22 ),( 0 T22 )  n-1
!>                                          1  n-1     1 n-1
!>
!>     Entonces el recíproco del número de condición DIF(i) es
!>
!>                Difl((a, b), (S22, T22)) = sigma-min( Zl ),
!>
!>     donde sigma-min(Zl) denota el valor singular mínimo de la
!>     matriz de 2(n-1) por 2(n-1)
!>
!>         Zl = [ kron(a, In-1)  -kron(1, S22) ]
!>              [ kron(b, In-1)  -kron(1, T22) ] .
!>
!>     Aquí In-1 es la matriz identidad de tamaño n-1. kron(X, Y) es el
!>     producto de Kronecker entre las matrices X e Y.
!>
!>     Tenga en cuenta que si se desea el método predeterminado para calcular DIF(i)
!>     (ver DLATDF), entonces el parámetro DIFDRI (ver más abajo) debe
!>     cambiarse de 3 a 4 (se utilizará la rutina DLATDF (IJOB = 2)).
!>     Ver DTGSYL para más detalles.
!>
!>  b) Si los valores propios i-ésimo y (i+1)-ésimo son un par conjugado complejo,
!>
!>     Supongamos que U y V son transformaciones ortogonales tales que
!>
!>              U**T*(A, B)*V = (S, T) = ( S11  *   ) ( T11  *  )  2
!>                                       ( 0    S22 ),( 0    T22) n-2
!>                                         2    n-2     2    n-2
!>
!>     y (S11, T11) corresponde al par de valores propios conjugados complejos
!>     (w, conjg(w)). Existen matrices unitarias U1 y V1 tales que
!>
!>       U1**T*S11*V1 = ( s11 s12 ) y U1**T*T11*V1 = ( t11 t12 )
!>                      (  0  s22 )                    (  0  t22 )
!>
!>     donde los valores propios generalizados w = s11/t11 y
!>     conjg(w) = s22/t22.
!>
!>     Entonces, el recíproco del número de condición DIF(i) está acotado por
!>
!>         min( d1, max( 1, |real(s11)/real(s22)| )*d2 )
!>
!>     donde, d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), donde
!>     Z1 es la matriz compleja de 2 por 2
!>
!>              Z1 =  [ s11  -s22 ]
!>                    [ t11  -t22 ],
!>
!>     Esto se hace calculando (usando aritmética real) las
!>     raíces del polinomio característico det(Z1**T * Z1 - lambda I),
!>     donde Z1**T denota la transpuesta de Z1 y det(X) denota
!>     el determinante de X.
!>
!>     y d2 es una cota superior para Difl((S11, T11), (S22, T22)), es decir, una
!>     cota superior para sigma-min(Z2), donde Z2 es (2n-2) por (2n-2)
!>
!>              Z2 = [ kron(S11**T, In-2)  -kron(I2, S22) ]
!>                   [ kron(T11**T, In-2)  -kron(I2, T22) ]
!>
!>     Tenga en cuenta que si se desea el método predeterminado para calcular DIF (ver
!>     DLATDF), entonces el parámetro DIFDRI (ver más abajo) debe
!>     cambiarse de 3 a 4 (se utilizará la rutina DLATDF (IJOB = 2)). Ver
!>     DTGSYL para más detalles.
!>

!>  estimación basada en la norma de Frobenius de Difl.

DESCRIPCIÓN

ztgsna estima los números recíprocos de condición para valores y/o vectores propios especificados de un par de matrices (A, B).

(A, B) deben estar en forma canónica de Schur generalizada, es decir, A y B son ambas triangulares superiores.

Los números recíprocos de condición se calculan para los pares propios seleccionados por el usuario en la matriz de Schur generalizada (A, B). Estos números recíprocos de condición son útiles para estimar la precisión de los valores y vectores propios calculados.

DETALLES ADICIONALES

!>
!> El recíproco del número de condición de un valor propio generalizado
!> w = (a, b) se define como
!>
!>      S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!> donde u y v son los vectores propios izquierdos y derechos de (A, B)
!> correspondientes a w; |z| denota el valor absoluto del número complejo,
!> y norm(u) denota la norma 2 del vector u.
!> El par (a, b) corresponde a un valor propio w = a/b (= u**TAv/u**TBv)
!> del par de matrices (A, B). Si tanto a como b son cero, entonces (A B) es
!> singular y se devuelve S(I) = -1.
!>
!> Una cota de error aproximada en la distancia de cuerda entre el i-ésimo
!> valor propio generalizado calculado w y el valor propio exacto
!> correspondiente lambda es
!>
!>      chord(w, lambda) <= EPS * norm(A, B) / S(I)
!>
!> donde EPS es la precisión de la máquina.
!>
!> El recíproco del número de condición DIF(i) del vector propio derecho u
!> y el vector propio izquierdo v correspondientes al valor propio generalizado w
!> se define de la siguiente manera:
!>
!> a) Si el i-ésimo valor propio w = (a,b) es real
!>
!>    Supóngase que U y V son transformaciones ortogonales tales que
!>
!>             U**T*(A, B)*V  = (S, T) = ( a   *  ) ( b  *  )  1
!>                                      ( 0  S22 ),( 0 T22 )  n-1
!>                                        1  n-1     1 n-1
!>
!>    Entonces el número recíproco de condición DIF(i) es
!>
!>               Difl((a, b), (S22, T22)) = sigma-min( Zl ),
!>
!>    donde sigma-min(Zl) denota el valor singular más pequeño de la
!>    matriz de 2(n-1)-por-2(n-1)
!>
!>        Zl = [ kron(a, In-1)  -kron(1, S22) ]
!>             [ kron(b, In-1)  -kron(1, T22) ] .
!>
!>    Aquí In-1 es la matriz identidad de tamaño n-1. kron(X, Y) es el
!>    producto de Kronecker entre las matrices X e Y.
!>
!>    Tenga en cuenta que si se desea el método por defecto para calcular
!>    DIF(i) (ver SLATDF), entonces el parámetro DIFDRI (ver abajo) debe
!>    cambiarse de 3 a 4 (se utilizará la rutina SLATDF (IJOB = 2)).
!>    Ver STGSYL para más detalles.
!>
!> b) Si el i-ésimo y (i+1)-ésimo valores propios son un par conjugado complejo,
!>
!>    Supóngase que U y V son transformaciones ortogonales tales que
!>
!>             U**T*(A, B)*V = (S, T) = ( S11  *   ) ( T11  *  )  2
!>                                      ( 0    S22 ),( 0    T22) n-2
!>                                        2    n-2     2    n-2
!>
!>    y (S11, T11) corresponde al par de valores propios conjugados complejos
!>    (w, conjg(w)). Existen matrices unitarias U1 y V1 tales que
!>
!>      U1**T*S11*V1 = ( s11 s12 ) y U1**T*T11*V1 = ( t11 t12 )
!>                     (  0  s22 )                    (  0  t22 )
!>
!>    donde los valores propios generalizados w = s11/t11 y
!>    conjg(w) = s22/t22.
!>
!>    Entonces el número recíproco de condición DIF(i) está acotado por
!>
!>        min( d1, max( 1, |real(s11)/real(s22)| )*d2 )
!>
!>    donde, d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), donde
!>    Z1 es la matriz compleja de 2x2
!>
!>             Z1 =  [ s11  -s22 ]
!>                   [ t11  -t22 ],
!>
!>    Esto se hace calculando (usando aritmética real) las
!>    raíces del polinomio característico det(Z1**T * Z1 - lambda I),
!>    donde Z1**T denota la transpuesta de Z1 y det(X) denota
!>    el determinante de X.
!>
!>    y d2 es una cota superior de Difl((S11, T11), (S22, T22)), es decir, una
!>    cota superior de sigma-min(Z2), donde Z2 es (2n-2)-por-(2n-2)
!>
!>             Z2 = [ kron(S11**T, In-2)  -kron(I2, S22) ]
!>                  [ kron(T11**T, In-2)  -kron(I2, T22) ]
!>
!>    Tenga en cuenta que si se desea el método por defecto para calcular
!!>    DIF (ver SLATDF), entonces el parámetro DIFDRI (ver abajo) debe
!>    cambiarse de 3 a 4 (se utilizará la rutina SLATDF (IJOB = 2)). Ver
!>    STGSYL para más detalles.
!>
!>  Para cada valor propio/vector propio especificado por SELECT, DIF almacena
!>  una estimación basada en la norma de Frobenius de Difl.
!>
!>  Una cota de error aproximada para el i-ésimo vector propio calculado VL(i) o
!>  VR(i) viene dada por
!>
!>             EPS * norm(A, B) / DIF(i).
!>
!>  Ver refs. [2-3] para más detalles y referencias adicionales.

!>
!>  The reciprocal of the condition number of a generalized eigenvalue
!>  w = (a, b) is defined as
!>
!>       S(w) = (|u**TAv|**2 + |u**TBv|**2)**(1/2) / (norm(u)*norm(v))
!>
!>  where u and v are the left and right eigenvectors of (A, B)
