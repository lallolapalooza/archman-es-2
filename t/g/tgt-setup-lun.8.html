NOMBRE

tgt-setup-lun - Script auxiliar que crea un destino, añade un dispositivo al destino y define iniciadores que pueden conectarse al destino

SINOPSIS

tgt-setup-lun -d <dispositivo> -n <nombre_destino> [-b <nombre_bs>] [-t <transporte>] [-C <puerto_control>] [IP_iniciador...] [-h]

DESCRIPCIÓN

Crea un destino según el nombre_destino proporcionado. tgtd debe estar ejecutándose. El formato del IQN por defecto generado a partir del nombre del destino es: "iqn.2001-04.com.<nombre_host>-<nombre_destino>", o se puede proporcionar un IQN completo. El nombre del destino debe ser único.

El script añade a continuación el dispositivo solicitado al destino. Si se definen direcciones IP específicas, se añaden a la lista de iniciadores permitidos para ese destino. Si no se define ninguna dirección IP, se define que el destino acepta cualquier iniciador.

EJEMPLOS

Crear un destino que utilice /dev/sdb1 y permita conexiones solo desde 192.168.10.81:

      tgt-setup-lun -d /dev/sdb1 -n mi_destino 192.168.10.81

Crear un destino que utilice /dev/sdb1 y permita conexiones solo desde 192.168.10.81 y 192.168.10.82:

      tgt-setup-lun -d /dev/sdb1 -n mi_destino 192.168.10.81 192.168.10.82

Crear un destino que utilice /dev/sdb1 y permita conexiones desde cualquier iniciador:

      tgt-setup-lun -d /dev/sdb1 -n mi_destino

Mostrar ayuda:

      tgt-setup-lun -h
