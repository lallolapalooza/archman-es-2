PROLOG

Esta página del manual forma parte del Manual del Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tgamma, tgammaf, tgammal — calcular la función gamma()

SINÓPSIS

#include <math.h>
double tgamma(double x);
float tgammaf(float x);
long double tgammal(long double x);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

Estas funciones calcularán Γ(x) donde Γ(x) se define como ∫0∞e^ −tt^ x−1dt .

Una aplicación que desee verificar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno no es cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) no es cero, ha ocurrido un error.

VALOR DE RETORNO

Tras una finalización satisfactoria, estas funciones devolverán la gamma de x.

Si x es un entero negativo, puede ocurrir un error de dominio y se devolverá un NaN (si es compatible) o un valor definido por la implementación. En sistemas que soportan la opción de punto flotante IEC 60559, ocurrirá un error de dominio y se devolverá un NaN.

Si x es ±0, tgamma(), tgammaf(), y tgammal() devolverán ±HUGE_VAL, ±HUGE_VALF, y ±HUGE_VALL, respectivamente. En sistemas que soportan la opción de punto flotante IEC 60559, ocurrirá un error de polo; de lo contrario, puede ocurrir un error de polo.

Si el valor correcto causara un desbordamiento, ocurrirá un error de rango y tgamma(), tgammaf(), y tgammal() devolverán ±HUGE_VAL, ±HUGE_VALF, o ±HUGE_VALL, respectivamente, con el mismo signo que el valor correcto de la función.

Si el valor correcto causara un subdesbordamiento y no es representable, puede ocurrir un error de rango, y tgamma(), tgammaf(), y tgammal() devolverán 0.0, o (si no se soporta el punto flotante IEC 60559) un valor definido por la implementación no mayor en magnitud que DBL_MIN, FLT_MIN, y LDBL_MIN, respectivamente.

Si el valor correcto causara un subdesbordamiento y es representable, puede ocurrir un error de rango y se devolverá el valor correcto.

Si x es subnormal y 1/x es representable, se devolverá 1/x.

Si x es NaN, se devolverá un NaN.

Si x es +Inf, se devolverá x.

Si x es -Inf, ocurrirá un error de dominio y se devolverá un NaN.

ERRORES

Estas funciones fallarán si:

Error de Dominio
El valor de x es un entero negativo, o x es -Inf.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante inválida.

Error de Polo
El valor de x es cero.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de división por cero en punto flotante.

Error de Rango
El valor causa desbordamiento.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de desbordamiento en punto flotante.

Estas funciones pueden fallar si:

Error de Dominio
El valor de x es un entero negativo.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de punto flotante inválida.

Error de Polo
El valor de x es cero.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de división por cero en punto flotante.

Error de Rango
El resultado causa subdesbordamiento.

Si la expresión entera (math_errhandling & MATH_ERRNO) no es cero, entonces errno se establecerá en [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) no es cero, entonces se activará la excepción de subdesbordamiento en punto flotante.

Las siguientes secciones son informativas.

EJEMPLOS

Ninguno.

USO DE LA APLICACIÓN

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.

RACIÓN

Esta función se llama tgamma() para evitar conflictos con las funciones históricas gamma() y lgamma().

DIRECCIONES FUTURAS

Es posible que la respuesta de error para un argumento entero negativo se cambie a un error de polo y un valor de retorno de ±Inf.

tgamma(3p)

LOGARITHMIC GAMMA FUNCTION tgamma(3p)

SYNOPSIS

#include <math.h>

double tgamma(double x);
float tgammaf(float x);
long double tgamma l(long double x);

DESCRIPTION

The tgamma() function shall compute the natural logarithm of the absolute value of the gamma function of x.

The gamma function is defined for all complex numbers except the non-positive integers. The gamma function is defined as:

Γ(z) = ∫0∞ tz-1e-t dt

for Re(z) > 0. It can be analytically continued to the whole complex plane, except for the non-positive integers, where it has simple poles.

The tgamma() function is intended to provide better precision than the logarithm of the absolute value of the gamma function computed by taking the logarithm of the absolute value of the result of gamma().

RETURN VALUE

Upon successful completion, tgamma(), tgammaf(), and tgammal() shall return the natural logarithm of the absolute value of the gamma function of x.

If x is a non-positive integer, a pole is encountered. The domain error produces an infinite result, and a floating-point "divide-by-zero" exception is raised.

If the result is not representable, a range error occurs and an appropriate value is returned.

ERRORS

The tgamma() function may fail if:

EDOM
The value of x is a non-positive integer.
ERANGE
The result is not representable.

EXAMPLES

None.

APPLICATION USAGE

The tgammaf() and tgammal() functions are respectively for single-precision and extended-precision arguments.

The tgamma() function is intended to provide better precision than log(fabs(gamma(x))).

RATIONALE

None.

FUTURE DIRECTIONS

None.
