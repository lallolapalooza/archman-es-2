NOMBRE

tgtimg - Utilidad de archivo de imagen del Marco de Destino SCSI de Linux

SINOPSIS

tgtimg [-o --op <operación>] [-Y --device-type <tipo-dispositivo>] [-b --barcode <código-barras>] [-s --size <tamaño>] [-t --type <tipo-medio>] [-f --file <ruta>] [-T --thin-provisioning]

tgtimg --help

DESCRIPCIÓN

Tgtimg es una utilidad para crear y administrar los archivos de imagen utilizados por la emulación de dispositivos TGTD.

Este comando se utiliza para inicializar archivos de imagen de dispositivo con metadatos adicionales, como código de barras, lista de bloques, tamaño total, etc., que necesita la emulación TGTD.

OPCIONES

-h, --help

Muestra una pantalla de ayuda y sale.

-o, --op {new|show}

Operación. Es `new` para crear un nuevo archivo de imagen o `show` para mostrar el contenido de un archivo de imagen existente.

-Y, --device-type <tipo>

Esto especifica el tipo de archivo de imagen.
Los tipos de dispositivo soportados son:
    cd   : para crear medios para un dispositivo de dvd
    disk : para crear medios para un dispositivo de disco
    tape : para crear medios para un dispositivo de cinta

-t, --type <tipo-medio>

Al crear una nueva imagen, esto especifica el tipo de medio a emular. Los tipos de medios disponibles dependen del tipo de dispositivo.
Los tipos de medio soportados para dispositivos cd son:
    dvd+r : crea un disco DVD+R grabable en blanco
Los tipos de medio soportados para dispositivos de disco son:
    disk  : crea un disco vacío
Los tipos de medio soportados para dispositivos de cinta son:
    data  : crea una cinta de datos normal
    clean : crea una cinta de limpieza
    worm  : crea una cinta WORM (Write Once, Read Many)

-b, --barcode <código-barras>

Al crear una nueva imagen, este argumento especifica el código de barras a usar con este archivo de imagen. El software de aplicación de copias de seguridad a menudo utiliza códigos de barras para identificar cintas específicas. Al emular una VTL (Virtual Tape Library), asegúrese de que todas las imágenes de cinta utilicen códigos de barras únicos.

-s, --size <tamaño>

Al crear una nueva imagen, esto especifica el tamaño en megabytes para la imagen de cinta virtual.

-f, --file <ruta>

El nombre del archivo de imagen.

-T, --thin-provisioning

Este argumento hace que la asignación del formato de imagen utilice aprovisionamiento fino (thin-provisioning). Esto significa que el archivo creado será un archivo disperso que asignará bloques del sistema de archivos bajo demanda.

Tenga cuidado al usar el aprovisionamiento fino. Si el sistema de archivos se llena, una escritura iSCSI a un LUN aprovisionado finamente puede fallar. Los iniciadores generalmente no manejan bien los errores de "espacio insuficiente".

El aprovisionamiento fino utiliza FALLOC_FL_PUNCH_HOLE, que solo está disponible en algunos sistemas de archivos de Linux. El aprovisionamiento fino solo se puede usar para imágenes de DISCO.

EJEMPLOS

Para crear un disco nuevo de 100 MB

      tgtimg --op new --device-type disk --type disk --size 100 --file /data/hd001.raw

Para crear una nueva imagen de cinta

      tgtimg --op new --device-type tape --barcode 12345 --size 100 --type data --file /data/tape001.img

Para ver el contenido de una imagen existente

      tgtimg --op show --device-type tape --file /data/tape001.img

Para crear una nueva imagen de DVD+R en blanco

      tgtimg --op new --device-type cd --type dvd+r --file /data/dvd001.iso
