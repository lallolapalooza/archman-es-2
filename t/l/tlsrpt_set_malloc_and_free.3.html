tlsrpt_set_malloc_and_free(3)

Paquete: libtlsrpt

Licencias: LGPL-3.0-or-later

TLSRPT_SET_MALLOC_AND_FREE(3) tlsrpt_set_malloc_and_free TLSRPT_SET_MALLOC_AND_FREE(3)

NOMBRE

tlsrpt_set_malloc_and_free - reemplaza la implementación de malloc utilizada dentro de libtlsrpt

SINOPSIS

#include <tlsrpt.h>

void tlsrpt_set_malloc_and_free(void* (*malloc_function)(size_t size), void (*free_function)(void *ptr))

DESCRIPCIÓN

La función tlsrpt_set_malloc_and_free reemplaza la implementación de malloc utilizada dentro de libtlsrpt. El malloc reemplazado se utiliza dentro de libtlsrpt solo para asignar las estructuras struct tlsrpt_connection_t y struct tlsrpt_dr_t. Otras llamadas a malloc desde la biblioteca estándar de C no se ven afectadas.


Nota

¡Esta función debe llamarse antes de que se llame a cualquiera de las funciones de asignación tlsrpt_open y tlsrpt_init_delivery_request! De lo contrario, una implementación de malloc intenta liberar un puntero asignado por una implementación de malloc diferente.

VALOR DE RETORNO

La función tlsrpt_set_malloc_and_free no tiene valor de retorno.

VER TAMBIÉN

tlsrpt_open(3), tlsrpt_init_delivery_request(3)
