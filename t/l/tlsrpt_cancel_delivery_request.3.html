TLSRPT_CANCEL_DELIVERY_REQUEST(3) tlsrpt_cancel_delivery_request TLSRPT_CANCEL_DELIVERY_REQUEST(3)

NOMBRE

tlsrpt_cancel_delivery_request - marca la solicitud de entrega como cancelada

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_cancel_delivery_request(struct tlsrpt_dr_t** pdr)

DESCRIPCIÓN

La función tlsrpt_cancel_delivery_request marca la solicitud de entrega como cancelada. Esto se hace con un "error interno" de la biblioteca TLSRPT_ERR_TLSRPT_CANCELLED que, como todos los errores, evitará que se envíe la solicitud de entrega. Luego, la función llama a tlsrpt_finish_delivery_request, que se encargará de liberar todos los recursos utilizados.

VALOR DE RETORNO

La función tlsrpt_cancel_delivery_request devuelve 0 en caso de éxito y un código de error combinado en caso de fallo. El código de error combinado se puede analizar con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_init_delivery_request(3), tlsrpt_finish_delivery_request(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
