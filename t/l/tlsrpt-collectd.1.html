TLSRPT-COLLECTD(1) tlsrpt-collectd TLSRPT-COLLECTD(1)

NOMBRE

tlsrpt-collectd - Un demonio que recopila datos de informes TLSRPT de instancias MTA a través de un socket de dominio Unix.

SINOPSIS

tlsrpt-collectd [OPCIÓN]

DESCRIPCIÓN

El tlsrpt-collectd recopila datos de las MTA sobre la entrega cifrada exitosa de correos electrónicos o sobre los fallos que ocurrieron durante los intentos de entrega. Los datos se pre-agregan y serán recuperados por los tlsrpt-fetcher coincidentes.

Los tlsrpt-collectd pueden utilizar diferentes backends de almacenamiento y para cada una de esas implementaciones se debe proporcionar una implementación de fetcher coincidente si los datos van a ser utilizados por un tlsrpt-reportd.

También es posible implementar backends de almacenamiento que no son consultados por un tlsrpt-reportd. Dichos backends de "almacenamiento" solo recopilarían los datos con fines de análisis, pero no proporcionarían medios para recuperar los datos nuevamente.

OPCIONES

--storage=URL

Utilice el almacenamiento de datos descrito por URL. Esto puede ser una lista separada por comas de múltiples backends de almacenamiento. El esquema de la URL identifica el backend de almacenamiento.

--socketname=ruta

Escuche en el socket de dominio Unix ruta para obtener datos de informes.

--socketuser=nombre

Establezca la propiedad del usuario del socket a nombre.

--socketgroup=nombre

Establezca la propiedad del grupo del socket a nombre.

--socketmode=octal

Establezca los bits del modo de archivo del socket a modo numérico octal. Por ejemplo, 0200 para permitir solo acceso de escritura al propietario.

--sockettimeout=n

Confirme los datos acumulados en el almacenamiento de datos si han transcurrido n segundos desde la última confirmación.

--max_uncommited_datagrams=n

Confirme los datos acumulados en el almacenamiento de datos después de recibir n datagramas.

--retry_commit_datagram_count=n

Después de que una confirmación de los datos acumulados haya fallado, reintente después de recibir n datagramas más en lugar de hacerlo inmediatamente después del siguiente datagrama. Si una confirmación falla debido a un tiempo de espera, reintentar después de cada datagrama podría arriesgarse a encontrarse una y otra vez con el mismo tiempo de espera. Reintentar solo cada n datagramas reduce el tiempo de espera de dichos tiempos de espera.

--daily_rollover_script=script

Si esta opción está configurada, el script se ejecutará después de que haya pasado la medianoche UTC y se hayan realizado los pasos de mantenimiento. Esto puede ser útil para enviar la base de datos de collectd a otro lugar en configuraciones donde un TLSRPT-collectd remoto no puede ser consultado fácilmente por el TLSRPT-reportd, pero el TLSRPT-collectd puede enviar datos al TLSRPT-reportd.

--dump_path_for_invalid_datagram=ruta

Si se recibe un datagrama inválido y esta opción está configurada, el datagrama inválido se guardará en el archivo llamado ruta.

Opciones generales

--config_file=nombre_archivo

Lea las opciones de la sección tlsrpt_collectd del archivo de configuración estilo INI nombre_archivo. Las variables de entorno anulan la configuración del archivo y las opciones de línea de comandos anulan ambas.

--help

Imprima un mensaje de ayuda que describa todas las opciones.

--pidfilename=ruta

Especifica el archivo que contiene el ID del proceso del demonio tlsrpt-collectd. Una cadena vacía hará que no se cree ningún archivo PID.

Opciones de registro

--logfilename=nombre_archivo

Use nombre_archivo como archivo de registro.

--log_level=nivel

Establezca el nivel de registro a nivel, valores permitidos: debug, info, warn, error.

ENTORNO

Todas las opciones de configuración, excepto --help y --config_file, también se pueden establecer a través de variables de entorno. La variable de entorno para una opción de configuración es el prefijo TLSRPT_COLLECTD_ seguido del nombre de la configuración en mayúsculas. Por ejemplo, la opción --log_level se puede configurar en su lugar utilizando la variable de entorno TLSRPT_COLLECTD_LOG_LEVEL.

ESTADO DE SALIDA

0

Éxito.

1

Fallo. No se pudieron entregar los datos.

2

Fallo. No se pudieron entregar los datos.

3

Error de uso.

EJEMPLOS

Ejecutar tlsrpt-collectd con un archivo de configuración especial y anular la configuración del nivel de registro:

tlsrpt-collectd --config-file /ruta/a/config.cfg --log_level info
