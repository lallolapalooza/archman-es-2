TLSRPT_ADD_DELIVERY_REQUEST_FAILURE(3) tlsrpt_add_delivery_request_failure TLSRPT_ADD_DELIVERY_REQUEST_FAILURE(3)

NOMBRE

tlsrpt_add_delivery_request_failure - añade un fallo a la política actual

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_add_delivery_request_failure(struct tlsrpt_dr_t* dr, tlsrpt_failure_t failure_code, const char* sending_mta_ip, const char* receiving_mx_hostname, const char* receiving_mx_helo, const char* receiving_ip, const char* additional_information, const char* failure_reason_code)

DESCRIPCIÓN

La función tlsrpt_add_delivery_request_failure añade un fallo a la política actual. Se pueden añadir múltiples fallos dentro de una política.

Algunos de los parámetros pueden ser NULL y en ese caso se omitirán en el datagrama.

VALOR DE RETORNO

La función tlsrpt_add_delivery_request_failure devuelve 0 en caso de éxito y un código de error combinado en caso de fallo. El código de error combinado puede ser analizado con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
