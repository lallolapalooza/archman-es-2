NOMBRE

tlp-rdw - desactiva temporalmente el Asistente de Radio (hasta el reinicio).

SINOPSIS

tlp-rdw [comando]

COMANDOS

desactivar
Desactiva las acciones de RDW.
activar
Activa las acciones de RDW.
<ninguno>
Muestra el estado de RDW.
--version
Imprime la versión de TLP.

AUTORIZACIÓN

El comando tlp-rdw requiere privilegios de root para activar/desactivar acciones.

VER TAMBIÉN
