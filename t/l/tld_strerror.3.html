tld_strerror(3)

Paquete: libidn

Licencias: GPL3, LGPL

tld_strerror(3) libidn tld_strerror(3)

NOMBRE

tld_strerror - función de la API

SINOPSIS

#include <tld.h>

const char * tld_strerror(Tld_rc rc);

ARGUMENTOS

Tld_rc rc
código de retorno tld

DESCRIPCIÓN

Convierte un código de retorno entero a una cadena de texto. Esta cadena se puede usar para mostrar un mensaje de diagnóstico al usuario.

TLD_SUCCESS

Operación exitosa. Se garantiza que este valor siempre es cero, y se garantiza que los restantes contendrán valores distintos de cero, para fines de comparación lógica.

TLD_INVALID

Se encontró un carácter no válido.

TLD_NODATA

No se proporcionaron datos de entrada.

TLD_MALLOC_ERROR

Error durante la asignación de memoria.

TLD_ICONV_ERROR

Error de conversión de codificación de caracteres.

TLD_NO_TLD

No se encontró ningún dominio de nivel superior en la cadena del dominio.

Valor de retorno: Devuelve un puntero a una cadena asignada estáticamente que contiene una descripción del error con el código de retorno rc.
