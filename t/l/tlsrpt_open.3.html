tlsrpt_open(3)

Paquete: libtlsrpt

Licencias: LGPL-3.0-or-later

TLSRPT_OPEN(3) tlsrpt_open TLSRPT_OPEN(3)

NOMBRE

tlsrpt_open - `tlsrpt_open` asigna e inicializa el objeto `struct tlsrpt_connection_t`

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_open(struct tlsrpt_connection_t** pcon, const char* socketname)

DESCRIPCIÓN

La función tlsrpt_open asigna e inicializa el objeto struct tlsrpt_connection_t. Esta función crea el socket e inicializa la dirección del socket de destino del collectd de TLSRPT. No hay una conexión real internamente, el socket es un socket de datagrama sin conexión.

VALOR DE RETORNO

La función tlsrpt_open devuelve 0 en caso de éxito y un código de error combinado en caso de fallo. El código de error combinado puede ser analizado con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_close(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
