NOMBRE

tld_get_z - función de API

SINOPSIS

#include <tld.h>

int tld_get_z(const char * in, char ** out);

ARGUMENTOS

const char * in
Array de caracteres terminado en cero para procesar.
char ** out
Puntero a la cadena de resultado ASCII terminada en cero.

DESCRIPCIÓN

Aísla el dominio de nivel superior de in y lo devuelve como una cadena ASCII en out . La cadena de entrada in puede ser UTF-8, ISO-8859-1 o cualquier codificación de caracteres compatible con ASCII.

Valor de retorno: Devuelve TLD_SUCCESS en caso de éxito, o el código de error Tld_rc correspondiente en caso contrario.
