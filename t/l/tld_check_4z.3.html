NOMBRE

tld_check_4z - función de API

SINOPSIS

#include <tld.h>

int tld_check_4z(const uint32_t * in, size_t * errpos, const Tld_table ** overrides);

ARGUMENTOS

const uint32_t * in
Array terminado en cero de puntos de código unicode a procesar.
size_t * errpos
La posición del carácter ofensivo se devuelve aquí.
const Tld_table ** overrides
Un array Tld_table de estructuras de restricción de dominio adicionales que complementan y reemplazan la información integrada.

DESCRIPCIÓN

Comprueba cada uno de los puntos de código en in para ver si están permitidos por la información en overrides o por los datos de restricción de TLD integrados. Cuando hay datos para el mismo TLD disponibles tanto internamente como en overrides , la información en overrides tiene precedencia. Si se encuentran varias entradas para un TLD específico, se utiliza la primera. Si overrides es NULL, solo se utiliza la información integrada. La posición del primer carácter ofensivo se devuelve en errpos .

Valor de retorno: Devuelve el valor Tld_rc TLD_SUCCESS si todos los puntos de código son válidos o cuando tld es nulo, TLD_INVALID si un carácter no está permitido, o códigos de error adicionales en condiciones de error generales.
