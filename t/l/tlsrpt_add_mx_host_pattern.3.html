TLSRPT_ADD_MX_HOST_PATTERN(3) tlsrpt_add_mx_host_pattern TLSRPT_ADD_MX_HOST_PATTERN(3)

NOMBRE

tlsrpt_add_mx_host_pattern - añade un patrón de host MX a la política actual

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_add_mx_host_pattern(struct tlsrpt_dr_t* dr, const char* mx_host_pattern)

DESCRIPCIÓN

La función tlsrpt_add_mx_host_pattern añade un patrón de host MX a la política actual. Se pueden añadir múltiples patrones de host MX dentro de una política.

VALOR DE RETORNO

La función tlsrpt_add_mx_host_pattern devuelve 0 en caso de éxito y un código de error combinado en caso de fallo. El código de error combinado puede ser analizado con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
