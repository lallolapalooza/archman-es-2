tlsrpt_error_code_is_internal(3)

Licencias: LGPL-3.0-or-later

TLSRPT_ERROR_CODE_IS_INTERNAL(3) tlsrpt_error_code_is_internal TLSRPT_ERROR_CODE_IS_INTERNAL(3)

NOMBRE

tlsrpt_error_code_is_internal - devuelve si el código de error es interno a la biblioteca TLSRPT

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_error_code_is_internal(int errorcode)

DESCRIPCIÓN

La función tlsrpt_error_code_is_internal devuelve si el código de error es interno a la biblioteca TLSRPT. tlsrpt_error_code_is_internal devuelve 1 si el código de error describe un error interno a la biblioteca TLSRPT. tlsrpt_error_code_is_internal devuelve 0 si el código de error es un código de error compuesto que combina la función de la biblioteca C y el punto de llamada dentro de la biblioteca TLSRPT y el valor errno resultante de la llamada fallida a la biblioteca C.

VALOR DE RETORNO

La función tlsrpt_error_code_is_internal devuelve si el código de error es interno a la biblioteca TLSRPT.

VER TAMBIÉN

tlsrpt_strerror(3), tlsrpt_errno_from_error_code(3)
