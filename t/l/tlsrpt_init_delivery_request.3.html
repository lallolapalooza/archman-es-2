tlsrpt_init_delivery_request(3)

Paquete: libtlsrpt

Licencias: LGPL-3.0-or-later

TLSRPT_INIT_DELIVERY_REQUEST(3) tlsrpt_init_delivery_request TLSRPT_INIT_DELIVERY_REQUEST(3)

NOMBRE

tlsrpt_init_delivery_request - asigna e inicializa el objeto `struct tlsrpt_dr_t`

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_init_delivery_request(struct tlsrpt_dr_t** pdr, struct tlsrpt_connection_t* con, const char* domainname, const char* policyrecord)

DESCRIPCIÓN

La función tlsrpt_init_delivery_request asigna e inicializa el objeto struct tlsrpt_dr_t. Los recursos que asigna deben liberarse llamando a tlsrpt_finish_delivery_request o a tlsrpt_cancel_delivery_request.

VALOR DE RETORNO

La función tlsrpt_init_delivery_request devuelve 0 en caso de éxito y un código de error combinado en caso de fallo. El código de error combinado puede ser analizado con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_cancel_delivery_request(3), tlsrpt_finish_delivery_request(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
