NOMBRE

tlsrpt-reportd - Un demonio para crear y entregar informes TLSRPT según RFC 8460.

SINOPSIS

tlsrpt-reportd [OPCIÓN]

DESCRIPCIÓN

tlsrpt-reportd es el componente final del framework TLSRPT. Un MTA (Agente de Transferencia de Correo) informa sobre la entrega exitosa o los errores encontrados a través de libtlsrpt a un tlsrpt-collectd, que recopila y pre-agrega los datos. El tlsrpt-fetcher asociado a un tlsrpt-collectd transfiere los datos pre-agregados al tlsrpt-reportd. tlsrpt-reportd puede recuperar datos de múltiples tlsrpt-fetcher y agrega los datos pre-agregados en los informes finales. Estos informes se comprimen con gzip y se envían a los destinos especificados en los registros DNS TLSRPT de los dominios que han recibido correos electrónicos del MTA.

Un diagrama de flujo de datos simple que visualiza la interacción de los componentes es el siguiente: (MTA) v libtlsrt v tlsrpt-collectd v (almacenamiento) v tlsrpt-fetcher v tlsrpt-reportd v (destino del informe)

OPCIONES

Opciones de creación y configuración del informe

--contact_info=dir

Utiliza dir como información de contacto en el informe TLSRPT según RFC 8460.

--organization_name=desc

Utiliza desc como nombre de la organización que envía el informe TLSRPT según RFC 8460.

--sender_address=email

Utiliza email como dirección "From:" al enviar informes por correo electrónico.

--fetchers=lista

Lista de comandos fetcher para recuperar datos. Se pueden dar múltiples comandos fetcher separados por comas.

--dbname=ruta

Utiliza la base de datos SQLite en la ubicación ruta.

--compression_level=n

Utiliza el nivel de compresión n para comprimir con gzip los informes TLSRPT.

--keep_days=n

Conserva los datos antiguos durante n días antes de eliminarlos de la base de datos.

Opciones de entrega de informes

--spread_out_delivery=seg

Distribuye la entrega de informes TLSRPT a lo largo de seg segundos. Esta configuración debe establecerse en varias horas, según la sección 4.1 de RFC8460. Por ejemplo, establezca spread_out_delivery a 14400 para distribuir la entrega de los informes a lo largo de cuatro horas.

--sendmail_script=ruta

Utiliza el script ruta para enviar un informe TLSRPT por correo electrónico.

--sendmail_timeout=seg

Establece un tiempo de espera de seg segundos para las solicitudes de envío de correo para entregar informes.

--http_script=ruta

Utiliza el script ruta para subir un informe TLSRPT a través de HTTP(S).

--http_timeout=seg

Establece un tiempo de espera de seg segundos para las solicitudes POST HTTP para entregar informes.

--max_retries_delivery=n

Abandona después de n intentos fallidos de entregar un informe a su destino.

--min_wait_delivery=seg

Tiempo mínimo de espera antes de reintentar un intento de entrega de informe fallido.

--max_wait_delivery=seg

Tiempo máximo de espera antes de reintentar un intento de entrega de informe fallido.

Opciones que controlan la interacción con uno o más tlsrpt-collectd

--max_collectd_timediff=seg

Registra una advertencia si el reloj del collectd, informado por su fetcher, difiere en más de seg segundos del reloj del reportd. El reportd comienza a consultar a los fetchers seg segundos después del cambio de día UTC, por lo que una diferencia de reloj mayor que seg segundos indica que el collectd podría aún no estar listo para proporcionar los datos completos del día anterior.

--max_collectd_timeout=seg

Espera como máximo seg segundos a que un fetcher complete una solicitud de datos de su collectd.

--max_retries_domaindetails=n

Abandona después de n intentos fallidos de recuperar los detalles del informe para un dominio.

--min_wait_domaindetails=seg

Tiempo mínimo de espera antes de reintentar un intento fallido de obtener los detalles del informe para un dominio de un tlsrpt-collectd.

--max_wait_domaindetails=seg

Tiempo máximo de espera antes de reintentar un intento fallido de obtener los detalles del informe para un dominio de un tlsrpt-collectd.

--max_retries_domainlist=n

Abandona después de n intentos fallidos de recuperar la lista de dominios de un tlsrpt-collectd.

--min_wait_domainlist=seg

Tiempo mínimo de espera antes de reintentar un intento fallido de obtener la lista de dominios de un tlsrpt-collectd.

--max_wait_domainlist=seg

Tiempo máximo de espera antes de reintentar un intento fallido de obtener la lista de dominios de un tlsrpt-collectd.

--interval_main_loop=seg

Despierta un bucle principal inactivo incluso si no hay tareas después de seg segundos de inactividad.

Opciones de depuración y desarrollo

--debug_db=n

Controla la depuración de la base de datos: 0 desactiva la depuración de la base de datos, 1 activa el registro de sentencias de base de datos.

--debug_send_file_dest=dir

Guarda los informes en el directorio dir además de su entrega por correo electrónico o solicitudes POST HTTP.

--debug_send_mail_dest=ruta

Anula el destino de correo electrónico para enviar informes por correo electrónico. Tenga en cuenta: ¡Con esta opción activada, los informes a destinos de correo electrónico no se enviarán al destino solicitado del registro DNS TLSRPT, sino a esta dirección de reemplazo! ¡Esta opción no debe usarse en sistemas de producción!

--debug_send_http_dest=ruta

Anula el destino POST HTTP para enviar informes a través de solicitudes POST HTTP. Tenga en cuenta: ¡Con esta opción activada, los informes a destinos POST HTTP no se enviarán al destino solicitado del registro DNS TLSRPT, sino a esta URL de reemplazo! ¡Esta opción no debe usarse en sistemas de producción!

Opciones generales

--config_file=nombrearchivo

Lee las opciones de la sección tlsrpt_reportd del archivo de configuración estilo INI nombrearchivo. Las variables de entorno anulan la configuración del archivo y las opciones de línea de comandos anulan ambas.

--help

Imprime un mensaje de ayuda que describe todas las opciones.

--pidfilename=ruta

Especifica el archivo que contiene el ID del proceso del demonio tlsrpt-reportd. Una cadena vacía hará que no se cree ningún archivo PID.

Opciones de registro

--logfilename=nombrearchivo

Utiliza nombrearchivo como archivo de registro.

--log_level=nivel

Establece el nivel de registro a nivel, valores permitidos: debug, info, warn, error.

ENTORNO

Todas las opciones de configuración excepto --help y --config_file también se pueden establecer a través de variables de entorno. La variable de entorno para una opción de configuración es el prefijo TLSRPT_REPORTD_ seguido del nombre de la configuración en mayúsculas. Por ejemplo, la opción --log_level se puede configurar en su lugar utilizando la variable de entorno TLSRPT_REPORTD_LOG_LEVEL.

EJEMPLOS

Recupera datos de un fetcher local con configuración estándar y de otro fetcher local con un almacenamiento diferente:

tlsrpt-reportd --fetchers "tlsrpt-fetcher, tlsrpt-fetcher --storage sqlite:///tmp/test.sqlite"

Recupera datos de un fetcher local y un fetcher remoto:

tlsrpt-reportd --fetchers "tlsrpt-fetcher, ssh user@remote tlsrpt-fetcher"
