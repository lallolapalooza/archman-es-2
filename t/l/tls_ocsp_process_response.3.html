NOMBRE

tls_ocsp_process_response, tls_peer_ocsp_url, tls_peer_ocsp_response_status, tls_peer_ocsp_cert_status, tls_peer_ocsp_crl_reason, tls_peer_ocsp_result, tls_peer_ocsp_revocation_time, tls_peer_ocsp_this_update, tls_peer_ocsp_next_update — inspeccionar una respuesta OCSP

SINOPSIS

#include <tls.h>

int
tls_ocsp_process_response(struct tls *ctx, const unsigned char *response, size_t size);

const char *
tls_peer_ocsp_url(struct tls *ctx);

int
tls_peer_ocsp_response_status(struct tls *ctx);

int
tls_peer_ocsp_cert_status(struct tls *ctx);

int
tls_peer_ocsp_crl_reason(struct tls *ctx);

const char *
tls_peer_ocsp_result(struct tls *ctx);

time_t
tls_peer_ocsp_revocation_time(struct tls *ctx);

time_t
tls_peer_ocsp_this_update(struct tls *ctx);

time_t
tls_peer_ocsp_next_update(struct tls *ctx);

DESCRIPCIÓN

tls_ocsp_process_response() procesa una respuesta OCSP en bruto en response de tamaño size para verificar el estado de revocación del certificado del par en ctx. Un código de retorno exitoso de 0 indica que el certificado no ha sido revocado.

tls_peer_ocsp_url() devuelve la URL para la validación OCSP del certificado del par desde ctx.

Las siguientes funciones devuelven información sobre el certificado del par desde ctx que se obtuvo al validar una respuesta OCSP grapada durante el handshake, o a través de una llamada anterior a tls_ocsp_process_response().

tls_peer_ocsp_response_status() devuelve el estado de la respuesta OCSP según la RFC 6960 sección 2.3.

tls_peer_ocsp_cert_status() devuelve el código de estado del certificado OCSP según la RFC 6960 sección 2.2.

tls_peer_ocsp_crl_reason() devuelve el código de estado de la razón de revocación del certificado OCSP según la RFC 5280 sección 5.3.1.

tls_peer_ocsp_result() devuelve una representación textual del código de estado OCSP devuelto por una de las tres funciones anteriores. Si la respuesta OCSP fue válida y el certificado no fue revocado, la cadena indica el estado del certificado OCSP. De lo contrario, la cadena indica la razón de revocación del certificado OCSP o el error OCSP.

tls_peer_ocsp_revocation_time() devuelve la hora de revocación OCSP.

tls_peer_ocsp_this_update() devuelve la hora de esta actualización OCSP.

tls_peer_ocsp_next_update() devuelve la hora de la próxima actualización OCSP.

VALORES DE RETORNO

tls_ocsp_process_response() devuelve 0 en caso de éxito o -1 en caso de error.

tls_peer_ocsp_url() y tls_peer_ocsp_result() devuelven NULL en caso de error o falta de memoria.

La función tls_peer_ocsp_response_status() devuelve uno de TLS_OCSP_RESPONSE_SUCCESSFUL, TLS_OCSP_RESPONSE_MALFORMED, TLS_OCSP_RESPONSE_INTERNALERROR, TLS_OCSP_RESPONSE_TRYLATER, TLS_OCSP_RESPONSE_SIGREQUIRED, o TLS_OCSP_RESPONSE_UNAUTHORIZED en caso de éxito o -1 en caso de error.

La función tls_peer_ocsp_cert_status() devuelve uno de TLS_OCSP_CERT_GOOD, TLS_OCSP_CERT_REVOKED, o TLS_OCSP_CERT_UNKNOWN en caso de éxito, y -1 en caso de error.

La función tls_peer_ocsp_crl_reason() devuelve uno de TLS_CRL_REASON_UNSPECIFIED, TLS_CRL_REASON_KEY_COMPROMISE, TLS_CRL_REASON_CA_COMPROMISE, TLS_CRL_REASON_AFFILIATION_CHANGED, TLS_CRL_REASON_SUPERSEDED, TLS_CRL_REASON_CESSATION_OF_OPERATION, TLS_CRL_REASON_CERTIFICATE_HOLD, TLS_CRL_REASON_REMOVE_FROM_CRL, TLS_CRL_REASON_PRIVILEGE_WITHDRAWN, o TLS_CRL_REASON_AA_COMPROMISE en caso de éxito o -1 en caso de error.

tls_peer_ocsp_revocation_time(), tls_peer_ocsp_this_update(), y tls_peer_ocsp_next_update() devuelven un tiempo en segundos de época (epoch-seconds) en caso de éxito o -1 en caso de error.

VER TAMBIÉN

tls_client(3), tls_config_ocsp_require_stapling(3), tls_conn_version(3), tls_connect(3), tls_handshake(3), tls_init(3)

HISTORIA

Estas funciones aparecieron en OpenBSD 6.1.

NOMBRE

tls_ocsp_process_response - procesa una respuesta OCSP

SINOPSIS

#include <libretls/tls.h>

int
tls_ocsp_process_response(struct tls_config *config,
    const uint8_t *buf, size_t len,
    struct tls_ocsp_status **status);

DESCRIPCIÓN

La función tls_ocsp_process_response parsea y valida la respuesta OCSP contenida en buf con longitud len . El valor de retorno apunta a una estructura tls_ocsp_status si la respuesta se procesa con éxito. La estructura contiene la respuesta de cada certificado en la respuesta OCSP. El campo status será NULL si no se pueden procesar las respuestas OCSP.

La estructura tls_ocsp_status contiene los siguientes campos:

int error
Indica si se produjo un error al procesar la respuesta OCSP. Los valores posibles son 
TLS_OCSP_SUCCESS
(0), 
TLS_OCSP_ERROR
(1) o 
TLS_OCSP_TRY_AGAIN
(2).
int cert_status
El estado del certificado en la respuesta OCSP. Los valores posibles son 
TLS_OCSP_CERT_GOOD
(0), 
TLS_OCSP_CERT_REVOKED
(1) o 
TLS_OCSP_CERT_UNKNOWN
(2).
time_t produced_at
La marca de tiempo en la que se produjo la respuesta OCSP.
time_t this_update
La marca de tiempo de la última actualización de la respuesta OCSP.
time_t next_update
La marca de tiempo de la próxima actualización de la respuesta OCSP.

VALORES DE RETORNO

La función tls_ocsp_process_response devuelve 0 en caso de éxito, o -1 en caso de error.

VER TAMBIÉN

tls_ocsp_verify(3), tls_config(3)

HISTORIA

La función tls_ocsp_process_response apareció por primera vez en OpenBSD 6.3.
