Paquete: libtlsrpt

Licencias: LGPL-3.0-or-later

TLSRPT_GET_SOCKET(3) tlsrpt_get_socket TLSRPT_GET_SOCKET(3)

NOMBRE

tlsrpt_get_socket - devuelve el descriptor de archivo del socket utilizado dentro de una `tlsrpt_connection_t`

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_get_socket(struct tlsrpt_connection_t* con)

DESCRIPCIÓN

La función tlsrpt_get_socket devuelve el descriptor de archivo del socket utilizado dentro de una tlsrpt_connection_t. Esto puede ser útil para configurar opciones del socket.

VALOR DE RETORNO

La función tlsrpt_get_socket devuelve el descriptor de archivo del socket utilizado dentro de una tlsrpt_connection_t.

VER TAMBIÉN
