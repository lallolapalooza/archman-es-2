TLSRPT_ERRNO_FROM_ERROR_CODE(3) tlsrpt_errno_from_error_code TLSRPT_ERRNO_FROM_ERROR_CODE(3)

NOMBRE

tlsrpt_errno_from_error_code - devuelve la parte `errno` de un código de error

SINOPSIS

#include <tlsrpt.h>

int tlsrpt_errno_from_error_code(int errorcode)

DESCRIPCIÓN

La función tlsrpt_errno_from_error_code devuelve la parte errno de un código de error. En caso de errores internos de la biblioteca del bloque TLSRPT_ERR_TLSRPT, el valor devuelto será un número alto para evitar conflictos con los valores existentes de errno. Es decir, TLSRPT_ERR_TLSRPT_NESTEDPOLICY es 10731 en lugar de 10031 para evitar que la parte errno se decodifique como EMLINK.

VALOR DE RETORNO

La función tlsrpt_errno_from_error_code devuelve 0 si tiene éxito y un código de error combinado si falla. El código de error combinado puede ser analizado con la función tlsrpt_strerror.

VER TAMBIÉN

tlsrpt_error_code_is_internal(3), tlsrpt_strerror(3)
