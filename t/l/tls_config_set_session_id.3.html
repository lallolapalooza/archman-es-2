tls_config_set_session_id(3)

Paquete: libretls

Licencias: ISC, BSD, MIT

TLS_CONFIG_SET_SESSION_ID(3) Manual de funciones de biblioteca TLS_CONFIG_SET_SESSION_ID(3)

NOMBRE

tls_config_set_session_fd, tls_config_set_session_id, tls_config_set_session_lifetime, tls_config_add_ticket_key — configurar la reanudación de handshakes TLS

SINOPSIS

#include <tls.h>

int
tls_config_set_session_fd(struct tls_config *config, int session_fd);

int
tls_config_set_session_id(struct tls_config *config, const unsigned char *session_id, size_t len);

int
tls_config_set_session_lifetime(struct tls_config *config, int lifetime);

int
tls_config_add_ticket_key(struct tls_config *config, uint32_t keyrev, unsigned char *key, size_t keylen);

DESCRIPCIÓN

tls_config_set_session_fd() establece un descriptor de archivo que se utilizará para administrar datos de sesiones TLS (solo cliente). El descriptor de archivo proporcionado debe ser un archivo regular y pertenecer al usuario actual, con permisos restringidos para permitir solo al propietario leer y escribir en el archivo (0600). Si el archivo tiene una longitud distinta de cero, el cliente intentará leer los datos de la sesión de este archivo y reanudar la sesión TLS anterior con el servidor. Tras un handshake exitoso, el archivo se actualizará con los datos de la sesión actual, si están disponibles. El llamante es responsable de cerrar este descriptor de archivo, después de que todos los contextos TLS que se hayan configurado para usarlo hayan sido liberados mediante tls_free().

tls_config_set_session_id() establece el identificador de sesión que será utilizado por el servidor TLS cuando las sesiones estén habilitadas (solo servidor). Por defecto, se utiliza un valor aleatorio.

tls_config_set_session_lifetime() establece el tiempo de vida que se utilizará para las sesiones TLS (solo servidor). El soporte de sesiones se deshabilita si se especifica un tiempo de vida de cero, que es el valor predeterminado.

tls_config_add_ticket_key() añade una clave utilizada para la encriptación y autenticación de tickets TLS (solo servidor). Por defecto, las claves se generan y rotan automáticamente en función de su tiempo de vida. Esta función solo debe usarse para sincronizar claves de encriptación de tickets entre múltiples procesos. Volver a añadir una clave conocida resultará en un error, a menos que sea la clave añadida más recientemente.

VALORES DE RETORNO

Estas funciones devuelven 0 en caso de éxito o -1 en caso de error.

VER TAMBIÉN

tls_accept_socket(3), tls_config_set_protocols(3), tls_init(3), tls_load_file(3), tls_server(3)

HISTORIA

tls_config_set_session_id(), tls_config_set_session_lifetime() y tls_config_add_ticket_key() aparecieron en OpenBSD 6.1.

tls_config_set_session_fd() apareció en OpenBSD 6.3.
