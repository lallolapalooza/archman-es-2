TLS_CONFIG_SET_PROTOCOLS(3) Manual de funciones de la biblioteca TLS_CONFIG_SET_PROTOCOLS(3)

NOMBRE

tls_config_set_protocols, tls_config_parse_protocols, tls_config_set_alpn, tls_config_set_ciphers, tls_config_set_dheparams, tls_config_set_ecdhecurves, tls_config_prefer_ciphers_client, tls_config_prefer_ciphers_server — Selección de protocolos y cifrados TLS

SINOPSIS

#include <tls.h>

int
tls_config_set_protocols(struct tls_config *config, uint32_t protocols);

int
tls_config_parse_protocols(uint32_t *protocols, const char *protostr);

int
tls_config_set_alpn(struct tls_config *config, const char *alpn);

int
tls_config_set_ciphers(struct tls_config *config, const char *ciphers);

int
tls_config_set_dheparams(struct tls_config *config, const char *params);

int
tls_config_set_ecdhecurves(struct tls_config *config, const char *curves);

void
tls_config_prefer_ciphers_client(struct tls_config *config);

void
tls_config_prefer_ciphers_server(struct tls_config *config);

DESCRIPCIÓN

Estas funciones modifican una configuración estableciendo parámetros. Las opciones de configuración se aplican tanto a clientes como a servidores, a menos que se indique lo contrario.

tls_config_set_protocols() especifica qué versiones del protocolo TLS pueden ser utilizadas. Los valores posibles son el OR a nivel de bits de:

  • TLS_PROTOCOL_TLSv1_2
  • TLS_PROTOCOL_TLSv1_3

Adicionalmente, los valores TLS_PROTOCOL_TLSv1 (TLSv1.2, TLSv1.3), TLS_PROTOCOLS_ALL (todos los protocolos soportados) y TLS_PROTOCOLS_DEFAULT (TLSv1.2 y TLSv1.3) pueden ser usados.

La función utilitaria tls_config_parse_protocols() analiza una cadena de protocolo y devuelve el valor correspondiente a través del argumento protocols. Este valor puede ser pasado luego a la función tls_config_set_protocols(). La cadena de protocolo es una lista de palabras clave separadas por comas o dos puntos. Las palabras clave válidas son:

tlsv1.2
 
tlsv1.3
 
all
(todos los protocolos soportados)
default
(un alias para secure)
legacy
(un alias para all)
secure
(actualmente TLSv1.2 y TLSv1.3)

Si un valor tiene un prefijo negativo (en forma de un signo de exclamación inicial), entonces se elimina de la lista de protocolos disponibles, en lugar de agregarse a ella.

tls_config_set_alpn() establece los protocolos ALPN que son soportados. La cadena alpn es una lista de protocolos separada por comas, en orden de preferencia.

tls_config_set_ciphers() establece la lista de cifrados que pueden ser utilizados. Las listas de cifrados se especifican por nombre, y los nombres permitidos son:

  • secure (o el alias default)
  • compat
  • legacy
  • insecure (o el alias all)

Alternativamente, se pueden especificar cadenas de cifrado de libssl. Consulte la sección CIPHERS de openssl(1) para más información.

tls_config_set_dheparams() especifica los parámetros que se utilizarán durante el intercambio de claves Diffie-Hellman Ephemeral (DHE). Los valores posibles son:

  • none
  • auto
  • legacy

En el modo auto, el tamaño de clave para la clave efímera se selecciona automáticamente en función del tamaño de la clave privada que se utiliza para la firma. En el modo legacy, se utilizan claves efímeras de 1024 bits. El valor por defecto es none, que deshabilita el intercambio de claves DHE.

tls_config_set_ecdhecurves() especifica los nombres de las curvas elípticas que pueden utilizarse durante el intercambio de claves Diffie-Hellman Ephemeral de Curva Elíptica (ECDHE). Esta es una lista separada por comas, dada en orden de preferencia. El valor especial de "default" usará las curvas por defecto (actualmente X25519, P-256 y P-384). Esta función reemplaza tls_config_set_ecdhecurve(), que está obsoleta.

tls_config_prefer_ciphers_client() prefiere los cifrados en la lista de cifrados del cliente al seleccionar un conjunto de cifrados (solo servidor). Esto se considera menos seguro que preferir la lista del servidor.

tls_config_prefer_ciphers_server() prefiere los cifrados en la lista de cifrados del servidor al seleccionar un conjunto de cifrados (solo servidor). Esto se considera más seguro que preferir la lista del cliente y es el valor por defecto.

VALORES DE RETORNO

Estas funciones devuelven 0 en caso de éxito o -1 en caso de error.

tls_config_set_protocols(3) — LibreTLS

NAME

tls_config_set_protocols, tls_config_parse_protocols, tls_config_set_dheparams, tls_config_set_ecdhecurve, tls_config_prefer_ciphers_client, tls_config_prefer_ciphers_server, tls_config_set_alpn, tls_config_get_protocol

configure TLS protocols and cipher suites

SYNOPSIS

bool
tls_config_set_protocols(struct tls_config *config, int min_vers, int max_vers);
bool
tls_config_parse_protocols(struct tls_config *config, const char *protocols);
bool
tls_config_set_dheparams(struct tls_config *config, const char *params);
bool
tls_config_set_ecdhecurve(struct tls_config *config, const char *curve);
bool
tls_config_prefer_ciphers_client(struct tls_config *config, const char *ciphers);
bool
tls_config_prefer_ciphers_server(struct tls_config *config, const char *ciphers);
bool
tls_config_set_alpn(struct tls_config *config, const char *protocols);
int
tls_config_get_protocol(struct tls_config *config);

DESCRIPTION

The function tls_config_set_protocols() sets the minimum and maximum TLS protocol versions that LibreTLS will negotiate. The versions are specified using constants like TLS_PROTOCOL_TLSV1_0, TLS_PROTOCOL_TLSV1_1, TLS_PROTOCOL_TLSV1_2, and TLS_PROTOCOL_TLSV1_3. For example, to allow only TLSv1.2, you would call tls_config_set_protocols(config, TLS_PROTOCOL_TLSV1_2, TLS_PROTOCOL_TLSV1_2).

The function tls_config_parse_protocols() parses a string of protocols, separated by commas, and sets the minimum and maximum protocol versions accordingly. The supported protocol names are "ssl2", "ssl3", "tls1", "tls1.1", "tls1.2", and "tls1.3". The string "default" is an alias for "tls1.2,tls1.3".

The function tls_config_set_dheparams() sets the Diffie-Hellman parameters to use for ephemeral Diffie-Hellman key exchange. The parameter params must be a string representing the DH group, e.g. "auto" or a string generated by openssl dhparam.

The function tls_config_set_ecdhecurve() sets the Elliptic Curve Diffie-Hellman (ECDHE) curve to use. The parameter curve must be a string representing the curve name, e.g. "auto", "secp256r1", or "x25519".

The functions tls_config_prefer_ciphers_client() and tls_config_prefer_ciphers_server() set the preferred cipher suites for the client and server respectively. The parameter ciphers must be a string representing a list of cipher suites, in order of preference, separated by colons. The format of the string is similar to the one used by OpenSSL's ciphers(1) command.

The function tls_config_set_alpn() sets the Application-Layer Protocol Negotiation (ALPN) list for the TLS configuration. The parameter protocols must be a string containing a comma-separated list of protocols (e.g., "h2,http/1.1").

The function tls_config_get_protocol() returns the negotiated protocol version for the given tls_config. This function is intended for server-side use to determine which protocol version was negotiated with the client.

RETURN VALUES

All functions except tls_config_get_protocol() return 1 on success and 0 on failure. tls_config_get_protocol() returns the negotiated protocol version, or TLS_PROTOCOL_UNKNOWN if no protocol has been negotiated yet.

SEE ALSO

HISTORY
