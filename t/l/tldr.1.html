TLDR(1) tldr TLDR(1)

NOMBRE

tldr - tldr 3.4.3

Cliente de línea de comandos de Python para tldr

uso: tldr comando [opciones]

ARGUMENTOS POSICIONALES

comando
comando a buscar

ARGUMENTOS NOMBRADOS

-v, --version
mostrar número de versión del programa y salir
--search
Buscar un comando específico a partir de una consulta
-u, --update, --update_cache
Actualizar la caché local de páginas y salir

Por defecto: False

-k, --clear-cache
Eliminar la caché local de páginas y salir

Por defecto: False

-p, --platform
Posibles opciones: android, freebsd, linux, netbsd, openbsd, osx, sunos, windows, common

Anular el sistema operativo [android, freebsd, linux, netbsd, openbsd, osx, sunos, windows, common]

-l, --list
Listar todos los comandos disponibles para el sistema operativo

Por defecto: False

-s, --source
Anular la fuente de página predeterminada

Por defecto: 'https://raw.githubusercontent.com/tldr-pages/tldr/main/pages'

-c, --color
Anular la eliminación de colores
-r, --render
Renderizar archivos markdown locales

Por defecto: False

-L, --language
Anular el idioma predeterminado
-m, --markdown
Solo imprimir el archivo de página plano.

Por defecto: False

--short-options
Mostrar opciones cortas en lugar de largas

Por defecto: False

--long-options
Mostrar opciones largas en lugar de cortas

Por defecto: False

--print-completion
Posibles opciones: bash, zsh, tcsh

Imprimir script de finalización de shell
