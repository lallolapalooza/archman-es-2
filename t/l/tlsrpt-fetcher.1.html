NOMBRE

tlsrpt-fetcher - El agente de transferencia de datos para llevar los datos del informe TLSRPT desde tlsrpt-collectd a tlsrpt-reportd.

SINOPSIS

tlsrpt-fetcher [OPCIÓN] DÍA [DOMINIO]

DESCRIPCIÓN

El tlsrpt-fetcher es llamado por el tlsrpt-reportd para recopilar los datos pre-agregados de los tlsrpt-collectds. La recuperación de datos se realiza en dos pasos.

En el primer paso, el reportd solicita una lista de dominios para los cuales se recopilaron datos.

En este paso, el reportd primero verifica si el tlsrpt-fetcher soporta una versión de protocolo coincidente en caso de que futuras versiones utilicen un protocolo diferente. Por lo tanto, la versión del protocolo fetcher es la primera línea.

La segunda línea es la hora actual del paquete tlsrpt-collectd/tlsrpt-fetcher. Si la hora difiere demasiado de la hora del tlsrpt-reportd, se muestra una advertencia de que los datos pueden no haber sido completamente procesados.

Las siguientes líneas son los dominios, un dominio por línea. El final de la lista se señala con una línea que contiene solo un "."

OPCIONES

--storage=URL

Utiliza el almacenamiento de datos descrito por URL.

Opciones generales

--config_file=nombre_archivo

Lee las opciones de la sección tlsrpt_fetcher del archivo de configuración estilo INI nombre_archivo. Las variables de entorno anulan las configuraciones del archivo de configuración y las opciones de línea de comandos anulan ambas.

--help

Imprime un mensaje de ayuda que describe todas las opciones.

Opciones de registro

--logfilename=nombre_archivo

Utiliza nombre_archivo como archivo de registro.

--log_level=nivel

Establece el nivel de registro a nivel, valores permitidos: debug, info, warn, error.

AMBIENTE

Todas las opciones de configuración excepto --help y --config_file también se pueden configurar a través de variables de entorno. La variable de entorno para una opción de configuración es el prefijo TLSRPT_FETCHER_ seguido del nombre de la configuración en mayúsculas. Por ejemplo, la opción --log_level se puede configurar en su lugar utilizando la variable de entorno TLSRPT_FETCHER_LOG_LEVEL.

ESTADO DE SALIDA

0

Éxito.

1

Fallo. No se pudieron entregar los datos.

EJEMPLOS

Obtener la lista de dominios que tienen datos de informes para el día 2001-02-03. Imprime una cabecera de protocolo de transferencia y una lista de los dominios con un dominio por línea. La cabecera del protocolo consiste en dos líneas: - la versión del protocolo - la hora actual de la fuente de datos en UTC

Un solo "." marca el final de la lista:

tlsrpt-fetcher 2001-02-03

Obtener los detalles del informe para el dominio example.com para el día 2001-02-03:

tlsrpt-fetcher 2001-02-03 example.com
