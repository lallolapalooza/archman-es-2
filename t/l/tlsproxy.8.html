TLSPROXY(8) Manual del Administrador del Sistema TLSPROXY(8)

NOMBRE

tlsproxy - Proxy TLS de Postfix

SINOPSIS

tlsproxy [opciones genéricas del demonio Postfix]

DESCRIPCIÓN


El servidor tlsproxy(8) implementa un proxy TLS bidireccional. Es utilizado por el servidor postscreen(8) para hablar SMTP sobre TLS con clientes SMTP remotos que no están en la lista blanca (incluyendo clientes cuyo estado de lista blanca ha expirado), y por el cliente smtp(8) para soportar la reutilización de conexiones TLS, pero también debería funcionar para protocolos no SMTP.

Aunque un proceso tlsproxy(8) puede servir múltiples sesiones al mismo tiempo, es una buena idea permitir que el número de procesos aumente con la carga, para que el servicio siga siendo receptivo.

EJEMPLO DE PROTOCOLO

El siguiente ejemplo se refiere a postscreen(8). Sin embargo, el servidor tlsproxy(8) es agnóstico del protocolo de aplicación, y el ejemplo se adapta fácilmente a otras aplicaciones.

Después de recibir un comando STARTTLS válido del cliente SMTP remoto, el servidor postscreen(8) envía la cadena del punto final del cliente SMTP remoto, el rol solicitado (servidor) y el tiempo de espera solicitado a tlsproxy(8). A continuación, postscreen(8) recibe una indicación de "TLS disponible" de tlsproxy(8). Si el servicio TLS está disponible, postscreen(8) envía el descriptor de archivo del cliente SMTP remoto a tlsproxy(8) y envía el saludo 220 en texto plano al cliente SMTP remoto. Esto activa las negociaciones TLS entre el cliente SMTP remoto y tlsproxy(8). Una vez completado el handshake a nivel TLS, tlsproxy(8) traduce entre texto plano desde/hacia postscreen(8) y texto cifrado hacia/desde el cliente SMTP remoto.

SEGURIDAD

El servidor tlsproxy(8) es moderadamente sensible a la seguridad. Habla con clientes no confiables en la red. El proceso se puede ejecutar en modo chroot con privilegios bajos fijos.

DIAGNÓSTICOS


Los problemas y las transacciones se registran en syslogd(8) o postlogd(8).

PARÁMETROS DE CONFIGURACIÓN

Los cambios en main.cf no se detectan automáticamente, ya que los procesos tlsproxy(8) pueden ejecutarse durante mucho tiempo dependiendo de la carga del servidor de correo. Use el comando "postfix reload" para acelerar un cambio.

El texto a continuación proporciona solo un resumen de los parámetros. Consulte postconf(5) para obtener más detalles, incluidos ejemplos.

CONTROLES GLOBALES STARTTLS

La siguiente configuración es global y, por lo tanto, no puede ser anulada por información especificada en una solicitud del cliente tlsproxy(8).

tls_append_default_CA (no)
Añade los certificados de Autoridad de Certificación predeterminados proporcionados por el sistema a los especificados con *_tls_CApath o *_tls_CAfile.
tls_daemon_random_bytes (32)
El número de bytes pseudoaleatorios que un proceso smtp(8) o smtpd(8) solicita al servidor tlsmgr(8) para inicializar su generador de números pseudoaleatorios (PRNG) interno.
tls_high_cipherlist (ver la salida de 'postconf -d')
La lista de cifrados de OpenSSL para cifrados de grado "alto".
tls_medium_cipherlist (ver la salida de 'postconf -d')
La lista de cifrados de OpenSSL para cifrados de grado "medio" o superior.
tls_null_cipherlist (eNULL:!aNULL)
La lista de cifrados de OpenSSL para cifrados de grado "NULL" que proporcionan autenticación sin cifrado.
tls_eecdh_strong_curve (prime256v1)
La curva elíptica utilizada por el servidor SMTP de Postfix para un intercambio de claves ECDH efímero sensiblemente fuerte.
tls_eecdh_ultra_curve (secp384r1)
La curva elíptica utilizada por el servidor SMTP de Postfix para un intercambio de claves ECDH efímero máximamente fuerte.
tls_disable_workarounds (ver la salida de 'postconf -d')
Lista o máscara de bits de las soluciones alternativas para errores de OpenSSL que se van a deshabilitar.
tls_preempt_cipherlist (no)
Con SSLv3 y posteriores, utiliza el orden de preferencia de cifrado del servidor SMTP de Postfix en lugar del orden de preferencia de cifrado del cliente remoto.

Disponible en la versión de Postfix 2.8..3.7:

tls_low_cipherlist (ver la salida de 'postconf -d')
La lista de cifrados de OpenSSL para cifrados de grado "bajo" o superior.
tls_export_cipherlist (ver la salida de 'postconf -d')
La lista de cifrados de OpenSSL para cifrados de grado "exportación" o superior.

Disponible en la versión de Postfix 2.9 y posteriores:

tls_legacy_public_key_fingerprints (no)
Una ayuda temporal de migración para sitios que utilizan huellas digitales de claves públicas de certificados con Postfix 2.9.0..2.9.5, que utilizan un algoritmo incorrecto.

Disponible en la versión de Postfix 2.11-3.1:

tls_dane_digest_agility (on)
Configura la agilidad del algoritmo de resumen DANE TLSA de RFC7671.
tls_dane_trust_anchor_digest_enable (yes)
Habilita el soporte para registros DNS RFC 6698 (DANE TLSA) que contienen resúmenes de anclajes de confianza con uso de certificado "2".

Disponible en la versión de Postfix 2.11 y posteriores:

tlsmgr_service_name (tlsmgr)
El nombre de la entrada del servicio tlsmgr(8) en master.cf.

Disponible en la versión de Postfix 3.0 y posteriores:

tls_session_ticket_cipher (Postfix >= 3.0: aes-256-cbc, Postfix < 3.0: aes-128-cbc)
Algoritmo utilizado para cifrar tickets de sesión TLS RFC5077.
openssl_path (openssl)
La ubicación del programa de línea de comandos de OpenSSL openssl(1).

Disponible en la versión de Postfix 3.2 y posteriores:

tls_eecdh_auto_curves (ver la salida de 'postconf -d')
La lista priorizada de curvas elípticas, que deben habilitarse en el cliente y servidor SMTP de Postfix.

Disponible en la versión de Postfix 3.4 y posteriores:

tls_server_sni_maps (vacío)
Tablas de búsqueda opcionales que mapean nombres recibidos de clientes SMTP remotos a través de la extensión TLS Server Name Indication (SNI) a las claves y cadenas de certificados apropiadas.

Disponible en Postfix 3.5, 3.4.6, 3.3.5, 3.2.10, 3.1.13 y posteriores:

tls_fast_shutdown_enable (yes)
Una solución temporal para implementaciones que bloquean Postfix al cerrar una sesión TLS, hasta que Postfix alcance el tiempo de espera.

Disponible en la versión 3.8 de Postfix y posteriores:

tls_ffdhe_auto_groups (ver salida de 'postconf -d')
La lista priorizada de grupos de intercambio de claves Diffie-Hellman efímero de campo finito (FFDHE) compatibles con el cliente y servidor SMTP de Postfix.

Disponible en Postfix 3.9, 3.8.1, 3.7.6, 3.6.10, 3.5.20 y posteriores:

tls_config_file (default)
Archivo de configuración opcional con configuraciones base de OpenSSL.
tls_config_name (empty)
El nombre de la aplicación que Postfix pasa a las funciones de inicialización de la biblioteca OpenSSL.

CONTROLES DEL SERVIDOR STARTTLS

Estas configuraciones son clones de las configuraciones del servidor SMTP de Postfix. Permiten a tlsproxy(8) cargar la misma información de certificado y clave privada que el servidor SMTP de Postfix, antes de reducir privilegios, para que los archivos de clave puedan mantenerse de solo lectura para root. Actualmente, estas configuraciones no pueden ser anuladas por información en una solicitud de cliente de tlsproxy(8), pero esa limitación puede eliminarse en una versión futura.

tlsproxy_tls_CAfile ($smtpd_tls_CAfile)
Un archivo que contiene certificados CA (formato PEM) de CAs raíz de confianza para firmar certificados de cliente SMTP remotos o certificados de CA intermedia.
tlsproxy_tls_CApath ($smtpd_tls_CApath)
Un directorio que contiene certificados CA (formato PEM) de CAs raíz de confianza para firmar certificados de cliente SMTP remotos o certificados de CA intermedia.
tlsproxy_tls_always_issue_session_ids ($smtpd_tls_always_issue_session_ids)
Forzar al servidor tlsproxy(8) de Postfix a emitir un ID de sesión TLS, incluso cuando el almacenamiento en caché de sesiones TLS está desactivado.
tlsproxy_tls_ask_ccert ($smtpd_tls_ask_ccert)
Solicitar a un cliente SMTP remoto un certificado de cliente.
tlsproxy_tls_ccert_verifydepth ($smtpd_tls_ccert_verifydepth)
La profundidad de verificación para los certificados de cliente SMTP remotos.
tlsproxy_tls_cert_file ($smtpd_tls_cert_file)
Archivo con el certificado RSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_ciphers ($smtpd_tls_ciphers)
El grado mínimo de cifrado TLS que el servidor tlsproxy(8) de Postfix utilizará con cifrado TLS oportunista.
tlsproxy_tls_dcert_file ($smtpd_tls_dcert_file)
Archivo con el certificado DSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_dh1024_param_file ($smtpd_tls_dh1024_param_file)
Archivo con parámetros DH que el servidor tlsproxy(8) de Postfix debería usar con cifrados EDH que no sean de exportación.
tlsproxy_tls_dh512_param_file ($smtpd_tls_dh512_param_file)
Archivo con parámetros DH que el servidor tlsproxy(8) de Postfix debería usar con cifrados EDH de grado de exportación.
tlsproxy_tls_dkey_file ($smtpd_tls_dkey_file)
Archivo con la clave privada DSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_eccert_file ($smtpd_tls_eccert_file)
Archivo con el certificado ECDSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_eckey_file ($smtpd_tls_eckey_file)
Archivo con la clave privada ECDSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_eecdh_grade ($smtpd_tls_eecdh_grade)
El grado de seguridad del servidor tlsproxy(8) de Postfix para el intercambio de claves Diffie-Hellman efímero de curva elíptica (EECDH).
tlsproxy_tls_exclude_ciphers ($smtpd_tls_exclude_ciphers)
Lista de cifrados o tipos de cifrados a excluir de la lista de cifrados del servidor tlsproxy(8) en todos los niveles de seguridad TLS.
tlsproxy_tls_fingerprint_digest ($smtpd_tls_fingerprint_digest)
El algoritmo de resumen de mensajes para construir huellas digitales de certificados de cliente SMTP remotos.
tlsproxy_tls_key_file ($smtpd_tls_key_file)
Archivo con la clave privada RSA del servidor tlsproxy(8) de Postfix en formato PEM.
tlsproxy_tls_loglevel ($smtpd_tls_loglevel)
Habilita el registro adicional de actividad TLS del servidor tlsproxy(8) de Postfix.
tlsproxy_tls_mandatory_ciphers ($smtpd_tls_mandatory_ciphers)
El grado mínimo de cifrado TLS que el servidor tlsproxy(8) de Postfix utilizará con cifrado TLS obligatorio.
tlsproxy_tls_mandatory_exclude_ciphers ($smtpd_tls_mandatory_exclude_ciphers)
Lista adicional de cifrados o tipos de cifrados a excluir de la lista de cifrados del servidor tlsproxy(8) en niveles de seguridad TLS obligatorios.
tlsproxy_tls_mandatory_protocols ($smtpd_tls_mandatory_protocols)
Los protocolos SSL/TLS aceptados por el servidor tlsproxy(8) de Postfix con cifrado TLS obligatorio.
tlsproxy_tls_protocols ($smtpd_tls_protocols)
Lista de protocolos TLS que el servidor tlsproxy(8) de Postfix excluirá o incluirá con cifrado TLS oportunista.
tlsproxy_tls_req_ccert ($smtpd_tls_req_ccert)
Con cifrado TLS obligatorio, requiere un certificado de cliente SMTP remoto de confianza para permitir que las conexiones TLS continúen.
tlsproxy_tls_security_level ($smtpd_tls_security_level)
El nivel de seguridad TLS SMTP para el servidor tlsproxy(8) de Postfix; cuando se especifica un valor no vacío, anula los parámetros obsoletos smtpd_use_tls y smtpd_enforce_tls.
tlsproxy_tls_chain_files ($smtpd_tls_chain_files)
Archivos con las claves y cadenas de certificados del servidor tlsproxy(8) de Postfix en formato PEM.

Disponible en la versión 3.9 de Postfix y posteriores:

tlsproxy_tls_enable_rpk ($smtpd_tls_enable_rpk)
Solicitar que los clientes SMTP remotos envíen una clave pública raw RFC7250 en lugar de un certificado X.509, al solicitar o requerir autenticación de cliente.

Estas configuraciones son clones de las configuraciones del cliente SMTP de Postfix. Permiten a tlsproxy(8) cargar la misma información de certificado y clave privada que el cliente SMTP de Postfix, antes de reducir privilegios, para que los archivos de clave puedan mantenerse de solo lectura para root. Algunas configuraciones pueden ser anuladas por información en una solicitud de cliente de tlsproxy(8).

Disponible en la versión 3.4 de Postfix y posteriores:

tlsproxy_client_CAfile ($smtp_tls_CAfile)
Un archivo que contiene certificados CA de CAs raíz de confianza para firmar certificados de servidor TLS remotos o certificados de CA intermedia.
tlsproxy_client_CApath ($smtp_tls_CApath)
Directorio con certificados de Autoridad de Certificación en formato PEM que el cliente tlsproxy(8) de Postfix utiliza para verificar un certificado de servidor TLS remoto.
tlsproxy_client_chain_files ($smtp_tls_chain_files)
Archivos con las claves y cadenas de certificados del cliente tlsproxy(8) de Postfix en formato PEM.
tlsproxy_client_cert_file ($smtp_tls_cert_file)
Archivo con el certificado RSA del cliente tlsproxy(8) de Postfix en formato PEM.
tlsproxy_client_key ($smtp_tls_key_file)
Archivo con la clave privada RSA del cliente tlsproxy(8) de Postfix en formato PEM.

CONTROLES OBSOLETOS DE SOPORTE STARTTLS

Estos parámetros se admiten para compatibilidad con parámetros heredados de smtpd(8).

tlsproxy_use_tls ($smtpd_use_tls)
TLS Oportunista: anuncia soporte STARTTLS a clientes SMTP remotos, pero no requiere que los clientes utilicen cifrado TLS.
tlsproxy_enforce_tls ($smtpd_enforce_tls)
TLS Obligatorio: anuncia soporte STARTTLS a clientes SMTP remotos y requiere que los clientes utilicen cifrado TLS.
tlsproxy_client_use_tls ($smtp_use_tls)
Modo Oportunista: utiliza TLS cuando un servidor remoto anuncia soporte TLS.
tlsproxy_client_enforce_tls ($smtp_enforce_tls)
Modo de imposición: requiere que los servidores SMTP utilicen cifrado TLS.
