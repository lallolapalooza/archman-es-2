TCTI-TABMRD(7) Pila de software TPM2 TCTI-TABMRD(7)

NOMBRE

tcti-tabrmd - biblioteca TCTI de tabrmd

SINOPSIS

Un módulo de Interfaz de Transmisión de Comandos TPM (TCTI) para la interacción con tpm2-abrmd.

DESCRIPCIÓN

tcti-tabrmd es una biblioteca que abstrae la magia de IPC necesaria para comunicarse con tpm2-abrmd. Consulte la "Especificación de la API del Sistema TSS y la Interfaz de Transmisión de Comandos TPM" para una discusión detallada de la API TCTI.
