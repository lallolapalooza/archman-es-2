tss2_verifyquote(1) Manual de Comandos Generales tss2_verifyquote(1)

NOMBRE

tss2_verifyquote(1) -

SINOPSIS

tss2_verifyquote [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y el TCTI, o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos y parámetros criptográficos para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_verifyquote(1) - Este comando verifica que los datos devueltos por una cita son válidos. Esto incluye

•
Reconstruir los valores de PCR de quoteInfo a partir de eventLog (si se proporcionó un eventLog)
•
Verificar quoteInfo usando la firma y publicKeyPath

El esquema de verificación de firma utilizado se especifica en el perfil criptográfico (véase fapi-profile(5)).

Una aplicación que utilice tss2_verifyquote() además deberá

•
Evaluar la confiabilidad de la clave pública (publicKey)
•
Evaluar la confiabilidad de las entradas de eventLog

OPCIONES

Estas son las opciones disponibles:

•
-Q, --qualifyingData=NOMBRE_ARCHIVO o - (para stdin):

Un nonce proporcionado por el llamador para asegurar la frescura de la firma. Parámetro opcional.

•
-l, --pcrLog=NOMBRE_ARCHIVO o - (para stdin):

Devuelve el registro de eventos de PCR para la PCR elegida. Parámetro opcional.

Los registros de eventos de PCR son una lista (arreglo JSON de longitud arbitraria) de entradas de registro con el siguiente contenido.

- recnum: Número de registro único
- pcr: Índice de PCR
- digest: Los resúmenes (digests)
- type: El tipo de evento. En este momento, el único valor posible es: "LINUX_IMA" (IMA heredado)
- eventDigest: Resumen (digest) del evento; por ejemplo, el resumen del archivo medido
- eventName: Nombre del evento; por ejemplo, el nombre del archivo medido.
•
-q, --quoteInfo=NOMBRE_ARCHIVO o - (para stdin):

La estructura codificada en JSON que contiene las entradas para la operación de cita (quote).

•
-k, --publicKeyPath=CADENA:

Identifica la clave de firma. PUEDE ser una ruta a la jerarquía de clave pública /ext.

•
-i, --signature=NOMBRE_ARCHIVO o - (para stdin):

La firma sobre el material citado (quoted material).

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de error, mostrará un resumen breve de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción 'man', sin embargo, si se solicita explícitamente 'man', la herramienta proporcionará errores de man en stderr. Si se especifica la opción 'no-man', o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar correctamente las páginas del manual, se requiere que estén instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

    tss2_verifyquote --publicKeyPath="ext/myNewParent" --qualifyingData=qualifyingData.file --quoteInfo=quoteInfo.file --signature=signature.file --pcrLog=pcrLog.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
