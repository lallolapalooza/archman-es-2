TSK_RECOVER(1) Manual de comandos generales TSK_RECOVER(1)

NOMBRE

tsk_recover - Exporta archivos de una imagen a un directorio local

SINOPSIS

tsk_recover [-vVae] [ -f tipo_fs ] [ -i tipo_img ] [ -b tamano_sector_dev ] [ -o desplazamiento_sector ] [ -d inodo_dir ] imagen [imagenes] dir_salida

DESCRIPCIÓN

tsk_recover recupera archivos a dir_salida desde la imagen. Por defecto, recupera solo archivos no asignados. Con indicadores, exportará todos los archivos.

Los argumentos son los siguientes:

-v
salida detallada a stderr
-V
Imprime la versión
-a
Recuperar solo archivos asignados
-e
Recuperar todos los archivos (asignados y no asignados)
-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-i tipo_img
El formato del archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-b tamano_sector_dev
El tamaño (en bytes) de los sectores del dispositivo. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento_sector
Desplazamiento de sector para un volumen a recuperar (recupera solo ese volumen). Si no se proporciona, intentará recuperar todos los volúmenes de la imagen y los guardará en carpetas diferentes.
-d inodo_dir
Inodo de directorio del que recuperar (también se debe especificar una partición específica con -o o no debe haber un sistema de volúmenes)
imagen [imagenes]
La imagen de disco o partición para leer, cuyo formato se da con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.
dir_salida
El directorio en el que guardar los archivos recuperados.

EJEMPLOS

Para recuperar solo archivos no asignados de image.dd al directorio recuperado:

# tsk_recover ./image.dd ./recuperado
