TSOCKS(1) Manual de Comandos Generales TSOCKS(1)

NOMBRE

tsocks - Script de shell para simplificar el uso de la biblioteca tsocks(8) para permitir que una aplicación utilice de forma transparente un proxy SOCKS

SINOPSIS

tsocks [aplicación [argumentos de la aplicación]]
o tsocks [on|off]
o tsocks

DESCRIPCIÓN

tsocks es un script de envoltura entre la biblioteca tsocks y la aplicación que deseas ejecutar con socksificación.

OPCIONES

[aplicación [argumentos de la aplicación]]
ejecuta la aplicación especificada con el entorno (LD_PRELOAD) establecido de forma que tsocks(8) proxyará de forma transparente las conexiones SOCKS en ese programa.
[on|off]
esta opción añade o elimina tsocks(8) de la variable de entorno LD_PRELOAD. Cuando tsocks(8) está en esta variable, todas las aplicaciones ejecutadas se procesan automáticamente con socksificación. Si deseas usar esta función, DEBES hacer un `source` del script de shell desde el tuyo, así: "source /usr/bin/tsocks" o ". /usr/bin/tsocks"
Ejemplo:
". tsocks on" -- añade la biblioteca tsocks a LD_PRELOAD
". tsocks off" -- elimina la biblioteca tsocks de LD_PRELOAD
[show|sh]
muestra el valor actual de la variable LD_PRELOAD.
<sin argumento>
crea un nuevo shell con LD_PRELOAD incluyendo tsocks(8).

AUTOR

Este script fue creado por Tamas SZERB <toma@rulez.org> para el paquete debian de tsocks. Ha sido adaptado (junto con esta página del manual) al proyecto principal de tsocks y modificado.
