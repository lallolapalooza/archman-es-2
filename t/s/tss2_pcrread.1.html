tss2_pcrread(1) Manual de Comandos Generales tss2_pcrread(1)

NOMBRE

tss2_pcrread(1) -

SINOPSIS

tss2_pcrread [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y los parámetros para todas las claves y operaciones de una interacción específica con el TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_pcrread(1) - Este comando proporciona un valor de PCR y su registro de eventos correspondiente. El banco de PCR a utilizar por cada PCR se define en el perfil criptográfico (véase fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-o, --pcrValue=NOMBRE_ARCHIVO o - (para salida estándar):

Devuelve el digest de la PCR. Parámetro opcional.

•
-x, --pcrIndex=ENTERO:

Identifica la PCR a leer.

•
-f, --force:

Forzar la sobrescritura de los archivos de salida.

•
-l, --pcrLog=NOMBRE_ARCHIVO o - (para salida estándar):

Devuelve el registro de eventos de la PCR para esa PCR. Parámetro opcional.

Los registros de eventos de PCR son una lista (array JSON de longitud arbitraria) de entradas de registro con el siguiente contenido.

- recnum: Número de registro único
- pcr: Índice de la PCR
- digest: Los digests
- type: El tipo de evento. Actualmente, el único valor posible es: "LINUX_IMA" (IMA heredado)
- eventDigest: Digest del evento; por ejemplo, el digest del archivo medido
- eventName: Nombre del evento; por ejemplo, el nombre del archivo medido.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar al paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen breve de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar con éxito las páginas del manual, estas deben estar instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

tss2_pcrread --pcrIndex=16 --pcrValue=pcrValue.file --pcrLog=pcrLog.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
