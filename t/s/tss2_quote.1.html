tss2_quote(1) Manual de Comandos Generales tss2_quote(1)

NOMBRE

tss2_quote(1) -

SINOPSIS

tss2_quote [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y los TCTI o directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_quote(1) - Este comando realiza una autenticación utilizando el TPM. El banco de PCR para cada índice de PCR y esquema de firma proporcionados se establecen en el perfil criptográfico (cf., fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-x, --pcrList=CADENA:

Un array que contiene los índices de PCR contra los que autenticarse.

•
-Q, --qualifyingData=NOMBRE_ARCHIVO o - (para stdin):

Un nonce proporcionado por el llamador para garantizar la frescura de la firma. Parámetro opcional.

•
-l, --pcrLog=NOMBRE_ARCHIVO o - (para stdout):

Devuelve el registro de PCR para la PCR elegida. Parámetro opcional.

Los registros de eventos de PCR son una lista (array JSON de longitud arbitraria) de entradas de registro con el siguiente contenido.

- recnum: Número de registro único
- pcr: Índice de PCR
- digest: Los resúmenes
- type: El tipo de evento. En este momento, el único valor posible es: "LINUX_IMA" (IMA heredado)
- eventDigest: Resumen del evento; por ejemplo, el resumen del archivo medido
- eventName: Nombre del evento; por ejemplo, el nombre del archivo medido.
•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-p, --keyPath=CADENA:

Identifica la clave de firma.

•
-q, --quoteInfo=NOMBRE_ARCHIVO o - (para stdout):

Devuelve una estructura codificada en JSON que contiene las entradas para la operación de cotización. Esto incluye el valor del resumen y los valores de PCR.

•
-o, --signature=NOMBRE_ARCHIVO o - (para stdout):

Devuelve la firma sobre el material cotizado.

•
-c, --certificate=NOMBRE_ARCHIVO o - (para stdout):

El certificado asociado con keyPath en formato PEM. Parámetro opcional.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para utilizar correctamente la función de manuales, se requiere que los manuales estén instalados o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

tss2_quote --keyPath=HS/SRK/quotekey --pcrList="10,16" --qualifyingData=qualifyingData.file --signature=signature.file --pcrLog=pcrLog.file --certificate=certificate.file --quoteInfo=quoteInfo.info

RETORNOS

0 en caso de éxito o 1 en caso de fallo.
