TS_CALIBRATE(1) tslib TS_CALIBRATE(1)

NOMBRE

ts_calibrate - Un programa de prueba para calibrar una pantalla táctil utilizada por tslib.

SINOPSIS

ts_calibrate

DESCRIPCIÓN

ts_calibrate se utiliza para configurar manualmente el plugin de filtro linear de tslib. Dibuja cruces en el framebuffer para ser tocadas por el usuario y registra las posiciones esperadas frente a las reales de contacto táctil necesarias para aplicar el filtro y proporcionar una experiencia de usuario táctil deseada. Utiliza la variable de entorno TSLIB_CALIBFILE para almacenar sus valores.

-r, --rotate [valor]

Gira la pantalla. El valor es 0 para 0 grados, 1 para 90 grados (en el sentido de las agujas del reloj), 2 para 180 grados (boca abajo) y 3 para 270 grados (en sentido contrario a las agujas del reloj). Este valor se añadirá al archivo de configuración de calibración TSLIB_CALIBFILE y será recogido desde allí por el módulo de filtro lineal. Puede ser cambiado por un parámetro del módulo lineal.

-t, --min_interval

El tiempo en milisegundos que debe pasar antes de que se presione una cruz por el usuario. Esto puede ser útil para evitar toques increíblemente rápidos o accidentalmente incorrectos y, por lo tanto, una calibración inexacta. Por defecto: 0.

-c, --validate

Valida la calibración. Asegúrate de que el módulo lineal esté configurado en ts.conf para que se aplique la calibración actual. En este modo, se muestran cruces en ubicaciones aleatorias en la pantalla y los toques se evalúan frente a sus posiciones. En este modo, las opciones --loops y --boundary están disponibles.

-b, --boundary

Límite de validación en píxeles. Disponible solo cuando se usa --validate. Define qué tan estricta debe ser la validación. Es la distancia que puede estar separada una entrada táctil evaluada de una cruz para que la validación sea exitosa. Si se cruza este límite, la validación falla. Por defecto: 10.

-o, --border

Número de píxeles a mantener alejados del borde de la pantalla. Disponible solo cuando se usa --validate. Por defecto: 0.

-l, --loops

Número de bucles en modo de validación. Disponible solo cuando se usa --validate. Define cuántas cruces deben tocarse y evaluarse. Por defecto: 3.
