ts_conf_set(3)

Paquete: tslib

Licencias: LGPL-2.1-only

TS_CONF_GET(3) tslib TS_CONF_GET(3)

NOMBRE

ts_conf_set - escribe un nuevo archivo de configuración TSLIB_CONFFILE y lo recarga.

SINOPSIS

#include <tslib.h>

int ts_conf_set(struct ts_module_conf *conf);

DESCRIPCIÓN

ts_conf_set() Esta función toma un puntero a una estructura ts_module_conf. Lee datos de todas las estructuras enlazadas en la lista (punteros next y prev) y escribe un nuevo TSLIB_CONFFILE. La primera estructura de la lista (donde prev es NULL) es la primera línea y así sucesivamente. Después de escribir, se debe llamar a ts_reconfig() para que los nuevos módulos y parámetros se recarguen y apliquen al programa en ejecución.

El conjunto dado de estructuras ts_module_conf se libera y destruye aquí. Después de llamar a ts_conf_set(), hay que usar ts_conf_get() de nuevo, para un cambio diferente.

struct ts_module_conf {
	char *name;
	char *params;
	int raw;
	int nr;
	struct ts_module_conf *next;
	struct ts_module_conf *prev;
};

VALOR DE RETORNO

Esta función devuelve cero si tiene éxito y un entero negativo en caso de error.

VER TAMBIÉN

ts_conf_get(3), ts_config(3), ts.conf(5)
