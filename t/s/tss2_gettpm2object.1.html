tss2_gettpm2object(1) Manual de Comandos Generales tss2_gettpm2object(1)

NOMBRE

tss2_gettpm2object(1)

SINOPSIS

tss2_gettpm2object [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y el TCTI, o los directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y los parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_gettpm2object(1) - Con este comando se pueden crear archivos de contexto de objetos FAPI que pueden ser utilizados por los comandos de la herramienta tpm2. Para objetos persistentes, solo se escribirá la representación textual del número de identificador como un número hexadecimal, y para las claves se escribirá un archivo de contexto de la herramienta tpm2. Si el TCTI predeterminado difiere del perfil FAPI, el TCTI predeterminado puede definirse con la opción -T (–tcti). Nota Para evitar estados incorrectos de nv_written en el almacén de claves antes de escribir datos en la memoria RAM NV con tpm2_nvwrite, se debe escribir al menos una cadena vacía con tss2_nvwrite.

OPCIONES

Estas son las opciones disponibles:

•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-p, --path=CADENA:

Ruta del objeto para el cual se cargarán los datos de la aplicación.

•
-c, --context=NOMBRE_ARCHIVO o - (para stdout):

El contexto de clave o identificador devuelto.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de man para la herramienta; sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción "man", sin embargo, si se solicita explícitamente "man", la herramienta proporcionará errores de man en stderr. Si se especifica la opción "no-man", o si falla el paginador de man, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de páginas de manual, se requiere que las páginas de manual estén instaladas o en el MANPATH, consulte man(1) para más detalles.

•
-v, --version: Muestra la información de la versión de esta herramienta, los TCTIs compatibles y sale.

EJEMPLOS

tss2_gettpm2object --path=/HS/SRK/myRSACrypt --key-context=mykey.ctx
tss2_gettpm2object --path=/nv/Owner/mynv -c-

El comando se puede utilizar en opciones de comandos tpm2:

handle=$(tss2_gettpm2object --path=/nv/Owner/mynv -c-)
tpm2_nvread $handle

RETORNOS

0 en caso de éxito o 1 en caso de fallo.
