TCTILDR(7) Manual de Información Miscelánea TCTILDR(7)

NOMBRE

tss2-tctildr - Simplifica la gestión del ciclo de vida de las instancias TCTI.

SINOPSIS

Esta biblioteca simplifica la instanciación y finalización de instancias TCTI.

DESCRIPCIÓN

El protocolo de carga e inicialización dinámica de TCTI requiere mucho código repetitivo. Para reducir duplicaciones, la biblioteca tss2-tctildr añade las funciones Tss2_TctiLdr_Initialize(), Tss2_TctiLdr_Initialize_Ex() y Tss2_TctiLdr_Finalize() para abstraer la maquinaria necesaria para cargar, inicializar y finalizar un contexto TCTI.

Para ayudar en el descubrimiento de TCTIs, esta biblioteca proporciona la función Tss2_TctiLdr_GetInfo(). Esta función, emparejada con una función de 'liberación' para liberar la memoria asignada por 'GetInfo', proporciona una interfaz de consulta simple para descubrir los TCTIs disponibles y predeterminados disponibles para la implementación de tss2-tctildr.

La interfaz expuesta por esta biblioteca se define en la "Especificación de la Interfaz de Transmisión de Comandos de TPM y la API a Nivel de Sistema TSS".
