tss2_createnv(1) Manual de Comandos Generales tss2_createnv(1)

NOMBRE

tss2_createnv(1) -

SINOPSIS

tss2_createnv [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos y parámetros criptográficos para todas las claves y operaciones de una interacción específica con TPM, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_createnv(1) - Este comando crea un índice NV en el TPM.

OPCIONES

Estas son las opciones disponibles:

•
-p, --path=CADENA:

Ruta del nuevo espacio NV.

La ruta se compone de tres elementos, separados por “ / ”. Una ruta NV comienza con “ /nv ”. El segundo elemento de la ruta identifica el rango de manejador NV para el objeto nv. Esto incluye los siguientes valores: Propietario, TPM, Plataforma, Certificado de respaldo, Certificado de plataforma, OEM de componente, OEM de TPM, OEM de plataforma, Cliente de PC, Servidor, Plataforma virtualizada, MPWG, Embebido. El tercer elemento de la ruta identifica el índice NV real utilizando un nombre significativo.

•
-t, --type=CADENA:

Identifica el uso previsto. Parámetro opcional. Los tipos pueden ser cualquier combinación separada por comas de:

- "noda": Establece el atributo noda de una clave o índice NV.
- "bitfield": Establece el tipo NV a campo de bits.
- "counter": Establece el tipo NV a contador.
- "pcr": Establece el tipo NV a comportamiento similar a pcr.
- Pista: Si no se proporciona ninguna de las tres palabras clave anteriores,
  se crea un índice NV regular.
•
-s, --size=ENTERO:

El tamaño en bytes del índice NV a crear. Puede omitirse si el tamaño se puede inferir del tipo; por ejemplo, un índice NV de tipo contador tiene un tamaño de 8 bytes.

•
-P, --policyPath=CADENA:

Identifica la política que se asociará con el nuevo espacio NV. Parámetro opcional. Si se omite, no se asociará ninguna política con la clave.

Una ruta de política se compone de dos elementos, separados por “ / ”. Una ruta de política comienza con “ /policy ”. El segundo elemento de la ruta identifica la política o la plantilla de política utilizando un nombre significativo.

•
-a, --authValue=CADENA:

La nueva contraseña UTF-8. Parámetro opcional. Si se omite, se le pedirá interactivamente al usuario una contraseña. Para establecer ninguna contraseña, esta opción debe usarse con la cadena vacía (““). El tamaño máximo de la contraseña está determinado por el tamaño del resumen del algoritmo de hash de nombre elegido en el perfil criptográfico (consulte fapi-profile(5)). Por ejemplo, elegir SHA256 como algoritmo de hash permite contraseñas de un tamaño máximo de 32 caracteres.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manpage de la herramienta. Por defecto, intenta invocar el paginador de man para la herramienta; sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si falla el paginador de man, las opciones cortas se mostrarán en stdout.

Para utilizar correctamente la función de manpages se requiere que las manpages estén instaladas o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra la información de versión de esta herramienta, tctis compatibles y sale.

EJEMPLO

tss2_createnv --authValue=abc --path=/nv/Owner/myNV --size=20 --type="noDa"

RETORNA

0 si tiene éxito o 1 si falla.
