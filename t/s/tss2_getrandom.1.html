VER TAMBIÉN

fapi-config(5) para ajustar parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos y parámetros criptográficos para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_getrandom(1) - Este comando utiliza el TPM para crear una matriz de bytes aleatorios.

OPCIONES

Estas son las opciones disponibles:

•
-n, --numBytes=ENTERO:

El número de bytes solicitados por el llamador.

•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-o, --data=NOMBRE_ARCHIVO o - (para stdout):

Los bytes aleatorios devueltos.

•
--hex

Convertir los datos de salida a formato hexadecimal sin un prefijo “0x”.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra la página del manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta; sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción 'man', sin embargo, si se solicita explícitamente 'man', la herramienta proporcionará errores de man en stderr. Si se especifica la opción 'no-man', o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar con éxito la función de páginas del manual, se requiere que las páginas del manual estén instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, tctis compatibles y sale.

EJEMPLO

    tss2_getrandom --numBytes=20 --data=- | hexdump -C

DEVUELVE

0 en caso de éxito o 1 en caso de fallo.
