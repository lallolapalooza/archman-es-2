Licencias: LGPL-2.1-only

TS_CONFIG(3) tslib TS_CONFIG(3)

NOMBRE

ts_config, ts_reconfig - leer la configuración de tslib

SINOPSIS

#include <tslib.h>

int ts_config(struct tsdev *dev);

int ts_reconfig(struct tsdev *dev);

DESCRIPCIÓN

ts_config() carga e inicializa todos los módulos configurados en el archivo de configuración de tslib TSLIB_CONFFILE, ver ts.conf (5). ts_reconfig() vuelve a ejecutar ts_config y actualiza la configuración si el archivo de configuración ha cambiado.

VALOR DE RETORNO

Se devuelve cero si la operación es exitosa. Se devuelve un valor negativo en caso de error.

VER TAMBIÉN

ts_read(3), ts_open(3), ts_setup(3), ts_close(3), ts.conf(5)
