tss2_createkey(1) Manual de comandos generales tss2_createkey(1)

NOMBRE

tss2_createkey(1) -

SINOPSIS

tss2_createkey [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos y parámetros criptográficos para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_createkey(1) - Este comando crea una clave dentro del TPM y la almacena en el almacén de metadatos de Fapi y, si se solicita, de forma persistente dentro del TPM. Dependiendo del tipo de clave especificado, los algoritmos y parámetros criptográficos para la clave creada se determinan por el perfil criptográfico correspondiente (véase fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-p, --path=CADENA:

La ruta a la nueva clave.

•
-t, --type=CADENA:

Identifica el uso previsto. Parámetro opcional. Los tipos pueden ser cualquier combinación separada por comas de:

- "sign": Establece el atributo de firma de una clave.
- "decrypt": Establece el atributo de descifrado de una clave.
- Pista: Si no se proporciona ni sign ni decrypt, ambos atributos se establecen.
- "restricted": Establece el atributo restringido de una clave.
- Pista: Si se establece restricted, se necesita sign o decrypt (pero no ambos).
- "exportable": Borra los atributos fixedTPM y fixedParent de una clave o
  objeto sellado.
- "noda": Establece el atributo noda de una clave o índice NV.
- "system": Almacena los blobs de datos y metadatos para una clave creada o
  un sello en el directorio del sistema en lugar del directorio personal del
  usuario.
- Un número hexadecimal (por ejemplo, "0x81000001"): Marca un objeto
  clave para que se haga persistente y establece el manejador del objeto
  persistente a este valor.
•
-P, --policyPath=CADENA:

La política que se asociará con la nueva clave. Parámetro opcional. Si se omite, no se asociará ninguna política con la clave.

Un policyPath se compone de dos elementos, separados por “/”. Un policyPath comienza con “/policy”. El segundo elemento de la ruta identifica la política o plantilla de política utilizando un nombre significativo.

•
-a, --authValue=CADENA:

La nueva contraseña UTF-8. Parámetro opcional. Si se omite, se le pedirá interactivamente al usuario una contraseña. Para establecer ninguna contraseña, esta opción debe usarse con la cadena vacía (““). El tamaño máximo de la contraseña está determinado por el tamaño del digest del algoritmo de hash de nombres elegido en el perfil criptográfico (véase fapi-profile(5)). Por ejemplo, si se elige SHA256 como algoritmo de hash, se permiten contraseñas de un tamaño máximo de 32 caracteres.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta; sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para utilizar correctamente la función de páginas del manual, se requiere que las páginas del manual estén instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, TCTIs soportados y sale.

EJEMPLO

Crear una clave sin contraseña

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt" --authValue=""

Crear una clave, preguntar por la contraseña en la línea de comandos

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt"

Crear una clave con contraseña “abc”.

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt" --authValue=abc

RETORNA

0 en caso de éxito o 1 en caso de fallo.
