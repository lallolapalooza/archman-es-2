tsearch(3) Manual de funciones de biblioteca tsearch(3)

NOMBRE

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy - gestionar un árbol de búsqueda binario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* Ver feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

DESCRIPCIÓN

tsearch(), tfind(), twalk() y tdelete() gestionan un árbol de búsqueda binario. Están generalizados del Algoritmo T de Knuth (6.2.2). El primer campo en cada nodo del árbol es un puntero a los datos correspondientes. (El programa que llama debe almacenar los datos reales.) compar apunta a una rutina de comparación, que toma punteros a dos elementos. Debería devolver un entero que sea negativo, cero o positivo, dependiendo de si el primer elemento es menor que, igual o mayor que el segundo.

tsearch() busca un elemento en el árbol. key apunta al elemento que se busca. rootp apunta a una variable que apunta a la raíz del árbol. Si el árbol está vacío, entonces la variable a la que apunta rootp debe establecerse en NULL. Si el elemento se encuentra en el árbol, entonces tsearch() devuelve un puntero al nodo del árbol correspondiente. (En otras palabras, tsearch() devuelve un puntero a un puntero al elemento de datos.) Si el elemento no se encuentra, entonces tsearch() lo agrega y devuelve un puntero al nodo del árbol correspondiente.

tfind() es como tsearch(), excepto que si el elemento no se encuentra, entonces tfind() devuelve NULL.

tdelete() elimina un elemento del árbol. Sus argumentos son los mismos que para tsearch().

twalk() realiza un recorrido en profundidad, de izquierda a derecha, de un árbol binario. root apunta al nodo de inicio para el recorrido. Si ese nodo no es la raíz, entonces solo se visitará una parte del árbol. twalk() llama a la función de usuario action cada vez que se visita un nodo (es decir, tres veces para un nodo interno y una vez para una hoja). action, a su vez, toma tres argumentos. El primer argumento es un puntero al nodo que se está visitando. La estructura del nodo no está especificada, pero es posible convertir el puntero a un puntero a puntero a elemento para acceder al elemento almacenado dentro del nodo. La aplicación no debe modificar la estructura apuntada por este argumento. El segundo argumento es un entero que toma uno de los valores preorder, postorder o endorder dependiendo de si es la primera, segunda o tercera visita al nodo interno, o el valor leaf si es la única visita a un nodo hoja. (Estos símbolos están definidos en <search.h>.) El tercer argumento es la profundidad del nodo; el nodo raíz tiene profundidad cero.

(Más comúnmente, preorder, postorder y endorder se conocen como preorder, inorder y postorder: antes de visitar los hijos, después del primero y antes del segundo, y después de visitar los hijos. Por lo tanto, la elección del nombre postorder es bastante confusa.)

twalk_r() es similar a twalk(), pero en lugar del argumento depth, el puntero de argumento closure se pasa a cada invocación de la función de acción, sin cambios. Este puntero puede usarse para pasar información desde y hacia la función de acción de manera segura para hilos, sin recurrir a variables globales.

tdestroy() elimina todo el árbol apuntado por root, liberando todos los recursos asignados por la función tsearch(). Para los datos en cada nodo del árbol, se llama a la función free_node. El puntero a los datos se pasa como argumento a la función. Si no es necesario dicho trabajo, free_node debe apuntar a una función que no haga nada.

VALOR DE RETORNO

tsearch() devuelve un puntero a un nodo coincidente en el árbol, o al nodo recién agregado, o NULL si no hubo suficiente memoria para agregar el elemento. tfind() devuelve un puntero al nodo, o NULL si no se encuentra ninguna coincidencia. Si hay varios elementos que coinciden con la clave, el elemento cuyo nodo se devuelve no está especificado.

tdelete() devuelve un puntero al padre del nodo eliminado, o NULL si el elemento no se encontró. Si el nodo eliminado era el nodo raíz, tdelete() devuelve un puntero colgante al que no se debe acceder.

tsearch(), tfind() y tdelete() también devuelven NULL si rootp era NULL en la entrada.

NOTAS

twalk() toma un puntero a la raíz, mientras que las otras funciones toman un puntero a una variable que apunta a la raíz.

tdelete() libera la memoria requerida para el nodo en el árbol. El usuario es responsable de liberar la memoria para los datos correspondientes.

El programa de ejemplo depende del hecho de que twalk() no hace ninguna referencia adicional a un nodo después de llamar a la función de usuario con el argumento "endorder" o "leaf". Esto funciona con la implementación de la biblioteca de GNU, pero no está en la documentación de System V.

EJEMPLOS

LIBRARY

Data Synchronization Library (librt, -lrt)

SYNOPSIS

#include <search.h>
void *root = NULL;
void *tsearch(const void *key, void **rootp,
              int (*compar)(const void *, const void *));
void *tfind(const void *key, void **rootp,
            int (*compar)(const void *, const void *));
void *tdelete(const void *key, void **rootp,
              int (*compar)(const void *, const void *));
void twalk(const void *root, void (*action)(const void *, VISIT, int));
void tdestroy(void *root, void (*free_node)(void *));

DESCRIPTION

These functions implement a binary search tree. The tree is not self-balancing, and duplicate keys are not allowed. The tree is composed of nodes, where each node is a structure containing a pointer to the data, and pointers to the left and right children. The data itself is not stored in the nodes; rather, the nodes contain pointers to the data. This allows the tree to store any type of data, as long as a suitable comparison function is supplied.

The tree is managed through a pointer to the root node. This pointer is passed by reference (i.e., as a pointer to a pointer) to tsearch, tfind, and tdelete. This allows these functions to modify the root pointer if necessary (e.g., when inserting the first node into an empty tree).

tsearch searches the tree rooted at *rootp for the node containing key. If the node is found, tsearch returns a pointer to it. If the node is not found, tsearch allocates a new node, makes it the root of a subtree, and returns a pointer to the new node. The function returns NULL if memory allocation fails. The compar function is used to compare keys. It should return a negative value if the first key is less than the second, zero if they are equal, and a positive value if the first key is greater than the second.

tfind works like tsearch, but it does not insert nodes that are not found. If the node is not found, tfind returns NULL.

tdelete searches the tree for the node containing key. If found, the node is deleted from the tree, and its memory is freed. The function returns a pointer to the parent of the deleted node, or NULL if the node was not found or if the deleted node was the root. Note that this function free's the memory for the node itself, but not the data pointed to by the node. The caller is responsible for freeing the data if necessary.

twalk traverses the tree rooted at root in preorder, postorder, or endorder. For each node visited, it calls the supplied action function. The action function receives a pointer to the node's data, a VISIT flag indicating the type of traversal, and the depth of the node (0 for the root). The VISIT flags are:

preorder
Visit the node before visiting its children.
postorder
Visit the node after visiting its children.
endorder
Visit the node after visiting its children (same as postorder).
leaf
Visit the node if it is a leaf node.

tdestroy traverses the tree rooted at root and calls the supplied free_node function for each node's data. It then frees the memory used by the nodes themselves.

RETURN VALUE

tsearch and tfind return a pointer to the node containing the key, or NULL if the key is not found or if memory allocation fails.

tdelete returns a pointer to the parent of the deleted node, or NULL if the node was not found or if the deleted node was the root.

twalk does not return a value.

tdestroy does not return a value.

STANDARDS

These functions are POSIX.1-2008 extensions.

HISTORY

The binary search tree functions first appeared in FreeBSD 2.2.

NOTES

The root pointer should be initialized to NULL before the first call to tsearch, tfind, or tdelete.

The tsearch function inserts duplicate keys, but they are not explicitly handled by the other functions. The tfind function will return the first instance of the key it encounters.

The twalk function visits nodes in a way that allows them to be processed in sorted order if the comparison function is consistent with the desired order.

EXAMPLES

The following program inserts 12 random numbers into a binary search tree, collapses duplicate numbers, then prints the numbers in order.

#define _GNU_SOURCE     /* Expose declaration of tdestroy() */
#include <search.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
static void *root = NULL;
static void *
xmalloc(size_t n)
{
    void *p;
    p = malloc(n);
    if (p)
        return p;
    fprintf(stderr, "insufficient memory\n");
    exit(EXIT_FAILURE);
}
static int
compare(const void *pa, const void *pb)
{
    if (*(int *) pa < *(int *) pb)
        return -1;
    if (*(int *) pa > *(int *) pb)
        return 1;
    return 0;
}
static void
action(const void *nodep, VISIT which, int depth)
{
    int *datap;
    switch (which) {
    case preorder:
        break;
    case postorder:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    case endorder:
        break;
    case leaf:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    }
}
int
main(void)
{
    int  *ptr;
    int  **val;
    srand(time(NULL));
    for (unsigned int i = 0; i < 12; i++) {
        ptr = xmalloc(sizeof(*ptr));
        *ptr = rand() & 0xff;
        val = tsearch(ptr, &root, compare);
        if (val == NULL)
            exit(EXIT_FAILURE);
        if (*val != ptr)
            free(ptr);
    }
    twalk(root, action);
    tdestroy(root, free);
    exit(EXIT_SUCCESS);
}
