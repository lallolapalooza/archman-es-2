tss2_verifysignature(1) Manual de comandos generales tss2_verifysignature(1)

NOMBRE

tss2_verifysignature(1) -

SINOPSIS

tss2_verifysignature [OPCIONES]

DESCRIPCIÓN

tss2_verifysignature(1) - Este comando verifica una firma usando una clave pública encontrada en la ruta de clave proporcionada. El esquema de verificación de firma utilizado se especifica en el perfil criptográfico (ver fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-d, --digest=NOMBRE_ARCHIVO o - (para stdin):

Los datos que fueron firmados, ya hasheados según el perfil criptográfico (ver fapi-profile(5)).

•
-p, --keyPath=CADENA:

Ruta a la clave pública de verificación.

•
-i, --signature=NOMBRE_ARCHIVO o - (para stdin):

La firma a verificar.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si falla el paginador de manuales, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de manuales se requiere que los manuales estén instalados o en el MANPATH, ver man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, tctis soportados y sale.

EJEMPLO

tss2_verifysignature --keyPath=ext/myRSASign --digest=digest.file --signature=signature.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
