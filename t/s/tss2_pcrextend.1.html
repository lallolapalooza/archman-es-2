tss2_pcrextend(1) Manual de Comandos Generales tss2_pcrextend(1)

NOMBRE

tss2_pcrextend(1) -

SINOPSIS

tss2_pcrextend [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción específica de TPM, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_pcrextend(1) - Este comando extiende los datos al PCR listado. El parámetro logData se extiende al registro de PCR. Si logData es NULL, solo se realiza la extensión del PCR. Se extienden todos los PCR actualmente activos en el TPM.

OPCIONES

Estas son las opciones disponibles:

•
-x, --pcr=ENTERO:

El PCR a extender.

•
-i, --data=NOMBRE_ARCHIVO o - (para stdin):

Los datos del evento a extender.

•
-l, --logData=NOMBRE_ARCHIVO o - (para stdin):

Contiene una representación JSON de los datos a escribir en el registro de eventos del PCR. Parámetro opcional.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual del programa. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción "man", sin embargo, si se solicita explícitamente "man", la herramienta proporcionará errores de man en stderr. Si se especifica la opción "no-man", o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de manuales, se requiere que los manuales estén instalados o en MANPATH. Ver man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, TCTIs compatibles y sale.

EJEMPLO

tss2_pcrextend --pcr=16 --data=data.file --logData=logData.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
