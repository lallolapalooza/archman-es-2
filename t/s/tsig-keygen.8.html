NOMBRE

tsig-keygen - Herramienta de generación de claves TSIG

SINOPSIS

tsig-keygen [-a algoritmo] [-h] [nombre]

DESCRIPCIÓN

tsig-keygen es una utilidad que genera claves para usar con TSIG (Firmas de Transacción) según se define en el RFC 2845 https://datatracker.ietf.org/doc/html/rfc2845.html. Las claves resultantes pueden usarse, por ejemplo, para asegurar actualizaciones dinámicas de DNS a una zona, o para el canal de comandos de rndc <#std-iscman-rndc>.

Se puede especificar un nombre de dominio en la línea de comandos para que se use como nombre de la clave generada. Si no se especifica ningún nombre, el valor predeterminado es tsig-key.

OPCIONES

-a algoritmo
Esta opción especifica el algoritmo a utilizar para la clave TSIG. Las opciones disponibles son: hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384 y hmac-sha512. El valor predeterminado es hmac-sha256. Las opciones no distinguen entre mayúsculas y minúsculas, y se puede omitir el prefijo "hmac-".
-h
Esta opción imprime un resumen breve de las opciones y argumentos.
