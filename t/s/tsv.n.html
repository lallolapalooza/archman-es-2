NOMBRE

tsv - Parte de la extensión de hilos de Tcl que permite la manipulación a nivel de script de datos compartidos entre hilos.

package require Thread ?2.8?

DESCRIPCIÓN

Esta sección describe los comandos que implementan variables compartidas entre hilos. Una variable compartida entre hilos es muy similar a un array de Tcl, pero a diferencia de un array de Tcl, se crea en memoria compartida y puede ser accedida desde muchos hilos al mismo tiempo. Una característica importante de la variable compartida entre hilos es que cada acceso a la variable está protegido internamente por un mutex, por lo que el programador de scripts no tiene que preocuparse por bloquear la variable él mismo.

Las variables compartidas entre hilos no están ligadas explícitamente a ningún hilo. Esto significa que cuando un hilo que creó alguna de las variables compartidas entre hilos sale, la variable y la memoria asociada no se anulan/recuperan. El usuario debe anular explícitamente la variable para recuperar la memoria consumida por la variable.

COMANDOS DE ELEMENTO

tsv::names ?patrón?
Devuelve los nombres de las variables compartidas que coinciden con el ?patrón? opcional o todas las variables conocidas si se omite el patrón.
tsv::object nombre_var elemento
Crea un comando de acceso a objetos para el elemento en la variable compartida nombre_var. Usando este comando, se pueden aplicar la mayoría de los otros comandos de variables compartidas como funciones de método del comando de objeto elemento. El comando de objeto se elimina automáticamente cuando se anula el elemento al que apunta este comando.
    % tsv::set foo bar "Una cadena compartida"
    % set cadena [tsv::object foo bar]
    % $cadena append " añadida"
    => Una cadena compartida añadida
tsv::set nombre_var elemento ?valor?
Establece el valor del elemento en la variable compartida nombre_var a valor y devuelve el valor al llamador. El valor puede omitirse, en cuyo caso el comando devolverá el valor actual del elemento. Si no se encuentra el elemento, se produce un error.
tsv::get nombre_var elemento ?var_nombrada?
Recupera el valor del elemento de la variable compartida nombre_var. Si se proporciona el argumento opcional var_nombrada, el valor se almacena en la variable nombrada. El valor de retorno del comando depende de la existencia del argumento opcional var_nombrada. Si el argumento se omite y no se encuentra el elemento solicitado en el array compartido, el comando genera un error. Si, sin embargo, se proporciona el argumento opcional en la línea de comandos, el comando devuelve verdadero (1) si se encuentra el elemento o falso (0) si no se encuentra.
tsv::unset nombre_var ?elemento?
Anula el elemento de la variable compartida nombre_var. Si no se proporciona el elemento opcional, elimina la variable.
tsv::exists nombre_var elemento
Comprueba si el elemento existe en la variable compartida nombre_var y devuelve verdadero (1) si lo hace o falso (0) si no existe.
tsv::pop nombre_var elemento
Devuelve el valor del elemento en la variable compartida nombre_var y anula el elemento, todo en una operación atómica.
tsv::move nombre_var nombre_antiguo nombre_nuevo
Renombra el elemento nombre_antiguo a nombre_nuevo en la variable compartida nombre_var. Esto realiza efectivamente una secuencia de operaciones de obtener/anular/establecer, pero todo en un solo paso atómico.
tsv::incr nombre_var elemento ?cuenta?
Similar al comando incr estándar de Tcl, pero incrementa el valor del elemento en la variable compartida nombre_var en lugar de la variable de Tcl.
tsv::append nombre_var elemento valor ?valor ...?
Similar al comando append estándar de Tcl, pero añade uno o más valores al elemento en la variable compartida nombre_var en lugar de la variable de Tcl.
tsv::lock nombre_var arg ?arg ...?
Este comando concatena los argumentos pasados y evalúa el script resultante bajo la protección interna del mutex. Durante la evaluación del script, toda la variable compartida está bloqueada. Para los comandos de variables compartidas dentro del script, el bloqueo interno está deshabilitado para que no se produzcan interbloqueos. También está permitido anular la variable compartida desde dentro del script. La variable compartida se crea automáticamente si no existía en el momento de la primera operación de bloqueo.
    % tsv::lock foo {
        tsv::lappend foo bar 1
        tsv::lappend foo bar 2
        puts stderr [tsv::set foo bar]
        tsv::unset foo
    }
tsv::handlers
Devuelve los nombres de todos los manejadores de almacenamiento persistente habilitados en tiempo de compilación. Consulte COMANDOS DE ARRAY para obtener más detalles.

COMANDOS DE LISTA

Estos comandos son similares a los comandos de Tcl con el mismo nombre. La diferencia es que operan sobre elementos de arrays compartidos.

tsv::lappend nombre_var elemento valor ?valor ...?
Similar al comando lappend estándar de Tcl, pero añade uno o más valores al elemento en la variable compartida nombre_var en lugar de la variable de Tcl.
tsv::linsert nombre_var elemento índice val
Similar al comando linsert estándar de Tcl, pero inserta uno o más valores en el elemento de la variable compartida nombre_var en una posición especificada.

LIST COMMANDS

The following commands are identical in syntax to the standard Tcl list commands, but they operate on an element of the shared variable varname instead of a Tcl variable.

tsv::lappend varname element ?value ...?
Similar to standard Tcl lappend command but appends one or more values to the end of the element in the shared variable varname instead of the Tcl variable.
tsv::linsert varname element index ?value ...?
Similar to standard Tcl linsert command but inserts one or more values at the index list position in the element in the shared variable varname instead of the Tcl variable.
tsv::lreplace varname element first last ?value ...?
Similar to standard Tcl lreplace command but replaces one or more values between the first and last position in the element of the shared variable varname instead of the Tcl variable.
tsv::llength varname element
Similar to standard Tcl llength command but returns length of the element in the shared variable varname instead of the Tcl variable.
tsv::lindex varname element ?index?
Similar to standard Tcl lindex command but returns the value at the index list position of the element from the shared variable varname instead of the Tcl variable.
tsv::lrange varname element from to
Similar to standard Tcl lrange command but returns values between from and to list positions from the element in the shared variable varname instead of the Tcl variable.
tsv::lsearch varname element ?options? pattern
Similar to standard Tcl lsearch command but searches the element in the shared variable varname instead of the Tcl variable.
tsv::lset varname element index ?index ...? value
Similar to standard Tcl lset command but sets the element in the shared variable varname instead of the Tcl variable.
tsv::lpop varname element ?index?
Similar to the standard Tcl lindex command but in addition to returning, it also splices the value out of the element from the shared variable varname in one atomic operation. In contrast to the Tcl lindex command, this command returns no value to the caller.
tsv::lpush varname element ?index?
This command performes the opposite of the tsv::lpop command. As its counterpart, it returns no value to the caller.

COMANDOS DE ARREGLO

Este comando soporta la mayoría de las opciones del comando estándar de Tcl array. Además de esas, permite vincular una variable compartida a algunas bases de datos de almacenamiento persistente. Actualmente las opciones persistentes soportadas son las famosas GNU Gdbm y LMDB. Estas opciones deben ser seleccionadas durante el tiempo de compilación del paquete. La implementación provee hooks para definir otras capas de persistencia, si es necesario.

tsv::array set varname list
Hace lo mismo que el comando estándar de Tcl array set.
tsv::array get varname ?pattern?
Hace lo mismo que el comando estándar de Tcl array get.
tsv::array names varname ?pattern?
Hace lo mismo que el comando estándar de Tcl array names.
tsv::array size varname
Hace lo mismo que el comando estándar de Tcl array size.
tsv::array reset varname list
Hace lo mismo que el comando estándar de Tcl array set pero borra la varname y establece nuevos valores de la lista atómicamente.
tsv::array bind varname handle
Vincula la varname al almacenamiento persistente handle. El formato del handle es <handler>:<address>, donde <handler> es "gdbm" para GNU Gdbm y "lmdb" para LMDB y <address> es la ruta al archivo de la base de datos.
tsv::array unbind varname
Desvincula el array compartido de su almacenamiento persistente vinculado.
tsv::array isbound varname
Devuelve verdadero (1) si la varname compartida está vinculada a algún almacenamiento persistente o cero (0) si no lo está.

COMANDOS DE LISTA CLAVE

Los comandos de lista clave se toman prestados del paquete TclX. Las listas clave proporcionan un tipo de dato estructurado construido sobre listas estándar de Tcl. Esta es una funcionalidad similar a las estructuras en el lenguaje de programación C.

Una lista clave es una lista en la que cada elemento contiene un par clave-valor. Estos pares de elementos se almacenan como listas en sí mismos, donde la clave es el primer elemento de la lista y el valor es el segundo. Los pares clave-valor se conocen como campos. Este es un ejemplo de una lista clave:

    {{NAME  {Frank  Zappa}} {JOB {músico y compositor}}}
Los campos pueden contener subcampos; `.' es el carácter separador. Los subcampos son en realidad campos donde el valor es otra lista clave. Por lo tanto, la siguiente lista tiene los campos de nivel superior ID y NAME, y los subcampos NAME.FIRST y NAME.LAST: 
    {ID 106} {NAME {{FIRST Frank} {LAST Zappa}}}
No hay límite para la profundidad recursiva de los subcampos, lo que permite construir estructuras de datos complejas. Las listas clave se construyen y acceden a través de una serie de comandos. Todos los comandos de gestión de listas clave toman el nombre de la variable que contiene la lista clave como argumento (es decir, se pasan por referencia), en lugar de pasar la lista directamente.
tsv::keyldel varname keylist key
Elimina el campo especificado por key de la lista clave keylist en la variable compartida varname. Esto elimina tanto la clave como el valor de la lista clave.
tsv::keylget varname keylist key ?retvar?
Devuelve el valor asociado con key de la lista clave keylist en la variable compartida varname. Si la variable opcional retvar no se especifica, entonces el valor se devolverá como resultado del comando. En este caso, si la clave no se encuentra en la lista, se producirá un error.

Si se especifica retvar y key está en la lista, entonces el valor se devuelve en la variable retvar y el comando devuelve 1 si la clave estaba presente en la lista. Si key no está en la lista, el comando devolverá 0, y retvar permanecerá sin cambios. Si se especifica {} para retvar, el valor no se devuelve, lo que permite al programador de Tcl determinar si una key está presente en una lista clave sin establecer una variable como efecto secundario.

tsv::keylkeys varname keylist ?key?
Devuelve una lista de las claves en la lista clave keylist en la variable compartida varname. Si se especifica key, entonces es el nombre de un campo clave cuyas claves de subcampo se recuperarán.
tsv::keylset varname keylist key value ?key value..?
Establece el valor asociado con key, en la lista clave keylist a value. Si la keylist no existe, se creará. Si la key no está actualmente en la lista, se añadirá. Si ya existe, value reemplazará el valor existente. Se pueden especificar múltiples palabras clave y valores, si se desea.

DISCUSIÓN

La implementación actual de variables compartidas por hilos permite un acceso fácil y conveniente a datos compartidos entre diferentes hilos. Internamente, los datos se almacenan en objetos Tcl y todos los comandos del paquete operan en la representación de datos interna, minimizando así el resplandor y mejorando el rendimiento. Se ha tenido especial cuidado para asegurar que todos los datos de objetos estén debidamente bloqueados y copiados en profundidad al mover objetos entre hilos.

Debido al diseño interno del núcleo de Tcl, lamentablemente no hay disposición para la integración completa de variables compartidas dentro de la sintaxis de Tcl. Todo acceso a datos compartidos debe realizarse con los comandos del paquete suministrados. Además, no se soportan los rastreadores de variables. Pero aun así, los beneficios de una manipulación de datos compartidos fácil, simple y segura superan las limitaciones impuestas.

CRÉDITOS

Las variables compartidas por hilos se inspiran en la interfaz nsv que se encuentra en AOLserver, un servidor web altamente escalable de America Online.

NAME

tsv - Tcl Data Serialization

SYNOPSIS

package require tsv

DESCRIPTION

The tsv package provides commands for serializing and deserializing data structures in the Tcl language. It supports various data types, including simple strings, lists, arrays, and keyed lists (dictionaries). The serialization format is designed to be human-readable and easily parsable, while also being efficient for data exchange.

ELEMENT COMMANDS

These commands handle the serialization and deserialization of individual elements.

  • tsv::element serialize <value>: Serializes a single Tcl value into its TSV representation.
  • tsv::element deserialize <tsv_string>: Deserializes a TSV string back into a Tcl value.

LIST COMMANDS

These commands are used for working with Tcl lists.

  • tsv::list serialize <list_variable>: Serializes a Tcl list into a TSV string.
  • tsv::list deserialize <tsv_string> ?<list_variable>?: Deserializes a TSV string into a Tcl list. If a list variable name is provided, the result is stored in that variable. Otherwise, it is returned as a string.

ARRAY COMMANDS

These commands are for serializing and deserializing Tcl arrays.

  • tsv::array serialize <array_name>: Serializes a Tcl array into a TSV string.
  • tsv::array deserialize <tsv_string> ?<array_name>?: Deserializes a TSV string into a Tcl array. If an array name is provided, the result is stored in that array. Otherwise, it is returned as a string representing the array elements.

KEYED_LIST_COMMANDS

These commands are used for Tcl keyed lists (dictionaries).

  • tsv::keyedlist serialize <dict_variable>: Serializes a Tcl dictionary into a TSV string.
  • tsv::keyedlist deserialize <tsv_string> ?<dict_variable>?: Deserializes a TSV string into a Tcl dictionary. If a dictionary variable name is provided, the result is stored in that variable. Otherwise, it is returned as a string representing the dictionary.

DISCUSSION

The tsv package aims to provide a simple and robust way to serialize and deserialize common Tcl data structures. The format is based on tab-separated values, with specific conventions for handling nested structures and special characters. It is particularly useful for saving and loading configurations, exchanging data between different Tcl scripts, or interfacing with external systems that can parse TSV data.

The serialization format is designed to be unambiguous. For example, strings containing tabs, newlines, or backslashes are properly escaped to ensure correct deserialization.
