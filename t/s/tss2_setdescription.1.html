tss2_setdescription(1) Manual de comandos generales tss2_setdescription(1)

NOMBRE

tss2_setdescription(1)

SINOPSIS

tss2_setdescription [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y el TCTI, o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos y parámetros criptográficos para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_setdescription(1) - Este comando permite a una aplicación asignar una descripción legible por humanos a un objeto en el almacén de metadatos de Fapi. Los datos almacenados se pueden recuperar con tss2_getdescription. Los datos almacenados previamente se sobrescriben con esta función. Si se proporciona una descripción vacía, los datos almacenados se eliminan.

OPCIONES

Estas son las opciones disponibles:

•
-i, --description=CADENA:

Los datos que se almacenarán como descripción del objeto. Parámetro opcional. Las descripciones almacenadas previamente se sobrescriben con esta función. Si se omite, se elimina cualquier descripción almacenada.

•
-p, --path=CADENA:

La ruta del objeto para el que se almacenará la descripción.

OPCIONES COMUNES

Esta colección de opciones es común a todos los programas de tss2 y proporciona información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta; sin embargo, en caso de fallo, mostrará un resumen breve de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción "man", sin embargo, si se solicita explícitamente "man", la herramienta proporcionará errores del manual en la salida estándar de error. Si se especifica la opción "no-man", o si el paginador de manuales falla, las opciones cortas se mostrarán en la salida estándar.

Para utilizar con éxito la función de manuales se requiere que los manuales estén instalados o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

tss2_setdescription --path=HS/SRK --description=descripción

RETORNA

0 en caso de éxito o 1 en caso de fallo.
