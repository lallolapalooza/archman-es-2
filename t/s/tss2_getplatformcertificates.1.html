tss2_getplatformcertificates(1) Manual de Comandos Generales tss2_getplatformcertificates(1)

NOMBRE

tss2_getplatformcertificates(1) -

SINOPSIS

tss2_getplatformcertificates [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, esquema y parámetros y la selección de bancos de PCR.

DESCRIPCIÓN

tss2_getplatformcertificates(1) - Este comando devuelve el conjunto de certificados de plataforma concatenados en un búfer continuo si la plataforma proporciona certificados de plataforma. Los certificados de plataforma para TPM 2.0 pueden consistir no solo en un solo certificado, sino también en una serie de certificados llamados certificados delta.

OPCIONES

Estas son las opciones disponibles:

•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-o, --certificates=NOMBRE_ARCHIVO o - (para salida estándar):

Devuelve un búfer continuo que contiene los certificados de plataforma concatenados.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual del programa. Por defecto, intenta invocar el paginador de man para la herramienta, sin embargo, en caso de fallo mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción "man", sin embargo si se solicita explícitamente "man", la herramienta proporcionará errores de man en la salida estándar. Si se especifica la opción "no-man", o si el paginador de man falla, las opciones cortas se mostrarán en la salida estándar.

Para utilizar con éxito la función de páginas de manual se requieren las páginas de manual instaladas o en el MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, TCTIs compatibles y sale.

EJEMPLO

tss2_getplatformcertificates --certificates=archivo.certificados

DEVOLUCIONES

0 en caso de éxito o 1 en caso de fallo.
