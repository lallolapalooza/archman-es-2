TCTI-SPI(7) Manual de Información Miscelánea TCTI-SPI(7)

NOMBRE

tcti-spi-ltt2go - Biblioteca TCTI para LetsTrust-TPM2Go USB TPM

SINOPSIS

Un módulo TCTI (TPM Command Transmission Interface) para la interacción con el TPM USB LetsTrust-TPM2Go.

DESCRIPCIÓN

tcti-spi-ltt2go es una biblioteca que abstrae los detalles de comunicación con el TPM USB LetsTrust-TPM2Go. La interfaz expuesta por esta biblioteca está definida en la especificación "TSS System Level API and TPM Command Transmission Interface Specification".

AUTOR

TPM2 Software Project https://github.com/tpm2-software/tpm2-tss

VER TAMBIÉN

Tss2_Tcti_Device_Init(3), Tss2_Tcti_Socket_Init(3), Tss2_TctiLdr_Initialize(3), Tss2_TctiLdr_Finalize(3), tcti-device(7), tcti-socket(7), tcti-tabrmd(7), tpm2-abrmd(8)

COLOFÓN

Esta página forma parte de la versión 4.1.3 de la implementación de código abierto del TCG TPM2 Software Stack (TSS2). Una descripción del proyecto, información sobre cómo reportar errores y la última versión de esta página se pueden encontrar en https://github.com/tpm2-software/tpm2-tss/.
