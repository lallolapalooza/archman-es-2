tss2_setappdata(1) Manual de Comandos Generales tss2_setappdata(1)

NOMBRE

tss2_setappdata(1)

SINOPSIS

tss2_setappdata [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y los parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_setappdata(1) - Este comando permite a una aplicación asociar un blob de datos arbitrario con un objeto dado. Los datos se almacenan y se pueden recuperar con tss2_getappdata. Los datos almacenados previamente se sobrescriben con esta función. Si se pasan datos vacíos, los datos almacenados se eliminan.

OPCIONES

Estas son las opciones disponibles:

•
-p, --path=CADENA:

Ruta del objeto para el que se almacenarán los appData.

•
-i, --appData=NOMBRE_ARCHIVO o - (para stdin):

Los datos a almacenar. Parámetro opcional. Si se omite, se eliminan los datos almacenados.

OPCIONES COMUNES

Esta colección de opciones es común a todos los programas tss2 y proporciona información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para utilizar correctamente la función de manuales se requiere que los manuales estén instalados o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

tss2_setappdata --path=HS/SRK/myRSACrypt --appData=appData.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
