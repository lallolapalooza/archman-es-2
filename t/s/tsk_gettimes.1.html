TSK_GETTIMES(1) Manual de Comandos Generales TSK_GETTIMES(1)

NOMBRE

tsk_gettimes - Recopila tiempos MAC de una imagen de disco en un archivo de cuerpo.

SINOPSIS

tsk_gettimes [-vV] [ -f tipo_fs ] [ -i tipo_img ] [ -b tamaño_sector_dev ] [ -z zona ] [ -s segundos ] imagen [imágenes]

DESCRIPCIÓN

tsk_gettimes examina cada uno de los sistemas de archivos en una imagen de disco y devuelve los datos sobre ellos en el formato de cuerpo MACtime (el mismo que al ejecutar 'fls -m' en cada sistema de archivos). La salida de esto se puede usar como entrada para mactime para crear una línea de tiempo de la actividad de los archivos. Los datos se imprimen en STDOUT, que luego puede ser redirigido a un archivo.

Los argumentos son los siguientes:

-v
salida detallada a stderr
-V
Imprimir versión
-f tipo_fs
Especifica el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-i tipo_img
El formato del archivo de imagen, como raw. Usa '-i list' para listar los tipos compatibles. Si no se proporciona, se utilizan métodos de autodetección.
-b tamaño_sector_dev
El tamaño (en bytes) de los sectores del dispositivo. Si no se proporciona, se utilizan métodos de autodetección.
-o desplazamiento_sector
Desplazamiento de sector para un volumen a recuperar (recupera solo ese volumen). Si no se proporciona, intentará recuperar todos los volúmenes de la imagen y guardarlos en carpetas diferentes.
-s segundos
El desfase temporal del sistema original en segundos. Por ejemplo, si el sistema original estaba 100 segundos atrasado, este valor sería -100.
-z zona
La cadena ASCII de la zona horaria del sistema original. Por ejemplo, EST o GMT. Estas cadenas deben estar definidas por su sistema operativo y pueden variar.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se indica con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se da un archivo de imagen y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.

EJEMPLOS

Para recopilar datos sobre la imagen image.dd:

# tsk_gettimes ./image.dd > body.txt
