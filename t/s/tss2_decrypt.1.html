tss2_decrypt(1) Manual de Comandos Generales tss2_decrypt(1)

NOMBRE

tss2_decrypt(1) - descifra datos

SINOPSIS

tss2_decrypt [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi, como el perfil criptográfico utilizado y los TCTI o directorios para los almacenes de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo de hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección de bancos de PCR.

DESCRIPCIÓN

tss2_decrypt(1) - Este comando descifra datos que fueron cifrados usando tss2_encrypt utilizando los esquemas de descifrado del TPM especificados en el perfil criptográfico (cf., fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-p, --keyPath=CADENA:

Identifica la clave de descifrado.

•
-i, --cipherText=ARCHIVO o - (para stdin):

El texto cifrado codificado en JSON.

•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-o, --plainText=ARCHIVO o - (para stdout):

Devuelve los datos descifrados. Parámetro opcional.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un breve resumen de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción "man", sin embargo si se solicita explícitamente "man", la herramienta proporcionará errores de man en stderr. Si se especifica la opción "no-man" o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de manuales se requiere que los manuales estén instalados o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra la información de versión de esta herramienta, los TCTI compatibles y sale.

EJEMPLO

    tss2_decrypt --keyPath=HS/SRK/myRSACrypt --cipherText=cipherText.file --plainText=plainText.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
