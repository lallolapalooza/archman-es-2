tslmendian(1)

Paquete: sunpinyin

Licencias: LGPL

TSLMENDIAN(1) Documentación de Perl aportada por el usuario TSLMENDIAN(1)

NOMBRE

tslmendian - cambia el orden de bytes del modelo de lenguaje de "back-off" en hilos de sunpinyin

SINOPSIS

tslmendian [opción]

DESCRIPCIÓN

slmendian convierte los archivos binarios del modelo de lenguaje utilizados por SunPinyin de big-endian a small-endian o viceversa.

OPCIONES

-e endian
Especifica el orden de bytes del archivo-lm-salida. Puede ser le o ge. Si no se proporciona, tslmendian utiliza el orden de bytes del host.
-v
Imprime el orden de bytes del archivo-lm-entrada.
-i archivo-lm-entrada
Identifica el archivo de entrada para la conversión. Generalmente, este archivo es generado por slmthread.
-o archivo-lm-salida
Identifica el archivo de salida de la conversión.

NOTAS

El archivo de salida convertido es equivalente a la entrada. Pero si compara la salida de tslminfo de ambos archivos, el archivo ARPA generado por tslminfo puede ser diferente. Esto se debe a la diferente precisión en diferentes máquinas.

Y debido a datos de relleno no inicializados en la estructura de datos, la suma de verificación del archivo de datos original puede ser diferente del archivo convertido de nuevo, aunque sean idénticos desde el punto de vista de SunPinyin.
