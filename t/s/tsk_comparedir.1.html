TSK_COMPAREDIR(1) Manual de Comandos Generales TSK_COMPAREDIR(1)

NOMBRE

tsk_comparedir - compara el contenido de un directorio con el contenido de una imagen o un dispositivo local.

SINOPSIS

tsk_comparedir [-vV] [-n inum_inicio ] [ -f tipo_fs ] [ -i tipo_img ] [ -b tamano_sectores_disp ] [ -o desplazamiento_sectores ] imagen [imagenes] directorio_comparacion

DESCRIPCIÓN

tsk_comparedir compara el contenido de imagen con el contenido de directorio_comparacion. Esto puede ser útil para detectar rootkits y durante las pruebas. Los rootkits generalmente no ocultan datos cuando se leen directamente del dispositivo sin procesar.

Los argumentos son los siguientes:

-o desplazamiento_sectores
Desplazamiento de sectores para una partición en la imagen o dispositivo a comparar.
-n inum_inicio
Inum de inicio para un directorio en la imagen desde donde comenzar la comparación.
-v
salida detallada a stderr
-V
Imprimir versión
-f tipo_fs
Especificar el tipo de sistema de archivos. Usa '-f list' para listar los tipos de sistemas de archivos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-i tipo_img
El formato del archivo de imagen, como 'raw'. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-b tamano_sectores_disp
El tamaño (en bytes) de los sectores del dispositivo. Si no se proporciona, se utilizan métodos de autodetección.
imagen [imagenes]
La imagen de disco o partición a leer, cuyo formato se especifica con '-i'. Se pueden proporcionar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona una imagen y su nombre es el primero de una secuencia (por ejemplo, si termina en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.

EJEMPLOS

Para comparar los directorios en image.dd con los de directory:

# tsk_comparedir ./image.dd ./directory
