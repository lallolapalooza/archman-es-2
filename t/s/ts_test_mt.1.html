NOMBRE

ts_test_mt - Un programa de prueba multitáctil básico para tslib.

SINOPSIS

ts_test_mt [OPCIÓN]

DESCRIPCIÓN

ts_test_mt se utiliza para probar tslib usando ts_read_mt() , ver ts_read_mt (3). Se puede usar para dispositivos de un solo toque y multitáctiles y le permite probar el comportamiento de entrada con los filtros de tslib aplicados. Se ofrecen dos modos mediante botones en la pantalla:

En modo Arrastrar, se dibuja una retícula por cada contacto táctil realizado concurrentemente en la pantalla del framebuffer.

En modo Dibujar, se dibujan líneas para cada contacto táctil.

-r, --rotar [valor]

Rota la pantalla. El valor es 0 para 0 grados, 1 para 90 grados (en sentido horario), 2 para 180 grados (boca abajo) y 3 para 270 grados (en sentido antihorario).

-v, --verbose

Imprime los valores de las muestras de entrada en la consola.

-j, --slots

Anula el número de contactos táctiles concurrentes a asignar.

-i, --idev

Elige explícitamente el dispositivo de eventos de entrada original que tslib debe usar. Por defecto: el valor de la variable de entorno TSLIB_TSDEVICE.

-n, --muestras

Sale automáticamente después de leer n muestras.

-a, --altcross

Muestra un símbolo de retícula alternativo en los puntos de contacto.

VER TAMBIÉN

ts.conf (5), ts_calibrate (1), ts_uinput (1), ts_test (1)
