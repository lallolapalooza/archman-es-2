TS_CONF_GET(3) tslib TS_CONF_GET(3)

NOMBRE

ts_conf_get - Obtener un puntero a la estructura ts_module_conf que contiene datos del archivo TSLIB_CONFFILE.

SINOPSIS

#include <tslib.h>

struct ts_module_conf *ts_conf_get(struct tsdev *ts);

DESCRIPCIÓN

ts_conf_get() Esta función devuelve un puntero a una estructura ts_module_conf que forma parte de una lista de módulos listados en el archivo de configuración TSLIB_CONFFILE. ts_conf_get() realmente lee TSLIB_CONFFILE. Una estructura representa una línea en el archivo. Se asignan para el usuario aquí:

struct ts_module_conf {
	char *name;
	char *params;
	int raw;
	int nr;
	struct ts_module_conf *next;
	struct ts_module_conf *prev;
};

VALOR DE RETORNO

Esta función devuelve un puntero a una estructura ts_module_conf.

VER TAMBIÉN

ts_conf_set(3), ts.conf(5)
