NOMBRE

ts_test - Una rutina de prueba básica para tslib.

SINOPSIS

ts_test

DESCRIPCIÓN

ts_test se utiliza para probar manualmente tslib usando ts_read(). Dibuja una mira y botones de modo en el framebuffer y te permite probar el comportamiento de las muestras de entrada con tus filtros configurados aplicados, ver ts.conf (5). Dado que utiliza ts_read(), solo admite un toque.

-r, --rotate [valor]

Rota la pantalla. El valor es 0 para 0 grados, 1 para 90 grados (en sentido horario), 2 para 180 grados (boca abajo) y 3 para 270 grados (en sentido antihorario).

VER TAMBIÉN

ts.conf (5), ts_test_mt (1), ts_calibrate (1)
