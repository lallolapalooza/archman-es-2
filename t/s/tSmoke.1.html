NOMBRE

tSmoke - Herramienta de línea de comandos para enviar información de SmokePing

SINOPSIS

tSmoke [ --testmail | --morning | --weekly | --version | --help | --man | --slaves ]

Opciones:
--man      Mostrar la página man
--help     Ayuda :-)
--version  Mostrar la versión de SmokePing
--testmail Enviar un mensaje de prueba
--listrrds Listar los RRD utilizados por este Smokeping
--morning  Enviar un resumen matutino
--weekly   Enviar un informe de estado semanal
--to       Dirección de correo electrónico a la que enviar el mensaje (ej. '--to=xyz@company.com.invalid'
--detail   Cuántos detalles enviar en el informe semanal (ej. '--detail=1')
--quiet    No imprimir mensaje de bienvenida
--slaves   Habilitar soporte para esclavos, asume todos los esclavos a menos que se agregue una lista CSV de esclavos
           (ej. '--slaves' o '--slaves=esclavo1[,esclavo2...]')

DESCRIPCIÓN

La herramienta tSmoke es una herramienta de línea de comandos que interactúa con el sistema SmokePing. Su función principal es enviar un mensaje que indique el estado actual de los sistemas monitoreados por Smokeping o un archivo de correo HTML que contenga el estado durante el último día, la última semana y el último mes, incluyendo un resumen general.

Crontabs típicos utilizados para invocar esto son:

# Alerta rápida matutina para ver qué está caído
0 6 * * * /usr/local/smokeping/bin/tSmoke.pl --q --to=mobilephone@att.net.invalid --morning
# Informe semanal sobre el porcentaje de disponibilidad de los sistemas de red sin detalle
0 8 * * * /usr/local/smokeping/bin/tSmoke.pl --q --to=mailbox@company.com.invalid --weekly --detail=0

CONFIGURACIÓN

Al instalar tSmoke, algunas variables deben ajustarse para adaptarse a su sistema local.

Necesitamos usar las siguientes bibliotecas:

Smokeping
Bindings de Perl de RRDTool
Getopt::Long

Configura tus bibliotecas:

use lib "/usr/local/smokeping/lib";
use lib "/usr/local/rrdtool-1.0.39/lib/perl";

Puntero a tu archivo de configuración de Smokeping

my $cfgfile = "/usr/local/smokeping/etc/config";

Modifica el archivo de configuración de Smokeping para incluir una ruta para tmail en la sección General:

tmail = /usr/local/smokeping/etc/tmail
