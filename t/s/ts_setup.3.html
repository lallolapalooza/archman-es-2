NOMBRE

ts_setup - encontrar, abrir y configurar un dispositivo de entrada de pantalla táctil

SINOPSIS

#include <tslib.h>

struct tsdev *ts_setup(const char *dev_name, int nonblock);

DESCRIPCIÓN

ts_setup() intentará encontrar, abrir y configurar el dispositivo de pantalla táctil. En caso de éxito, asignará memoria para un nuevo dispositivo de pantalla táctil, abrirá y enlazará el dispositivo de eventos de entrada a él, y cargará e inicializará todos los módulos configurados en el archivo de configuración de tslib TSLIB_CONFFILE.

Si dev_name es NULL, ts_setup() utilizará el dispositivo definido por la variable de entorno TSLIB_TSDEVICE.

Si TSLIB_TSDEVICE no está definido, ts_setup() intentará utilizar los siguientes dispositivos:

/dev/input/ts,
/dev/input/touchscreen,
/dev/touchscreen/ucb1x00.
Después de eso, ts_setup() escanea /dev/input/event* para el primer dispositivo con la propiedad INPUT_PROP_DIRECT.

VALOR DE RETORNO

Se devuelve un puntero a la struct tsdev abierta.

VER TAMBIÉN

ts_open(3), ts_close(3), ts_read(3), ts_config(3), ts.conf(5)
