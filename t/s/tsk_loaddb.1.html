TSK_LOADDB(1) Manual de Comandos Generales TSK_LOADDB(1)

NOMBRE

tsk_loaddb - poblar una base de datos SQLite con metadatos de una imagen de disco

SINOPSIS

tsk_loaddb [-ahkvV] [ -i tipos_img ] [ -b tam_sector_dev ] [ -i tipos_img ] [ -d base_datos ] imagen [imágenes]

DESCRIPCIÓN

tsk_loaddb carga información del disco de imagen a una base de datos SQLite. Esta base de datos puede ser utilizada posteriormente por herramientas en otros lenguajes para análisis. Por defecto, la base de datos se almacena en el mismo directorio que la imagen con ".db" añadido al nombre, o el nombre de la base de datos puede ser especificado con '-d'.

Los argumentos son los siguientes:

-a
Añade la imagen a una base de datos existente en lugar de crear una nueva. Requiere que se especifique también -d.
-d base_datos
Ruta para la base de datos (el valor por defecto es el mismo directorio que la imagen con el nombre derivado del nombre de la imagen).
-v
salida detallada a stderr
-V
Imprimir versión
-k
No crear tabla de datos de bloques. Esta tabla mapea cada bloque con el archivo que lo asignó. Esta opción hará que este programa se ejecute más rápido.
-h
Calcular el valor hash MD5 para cada archivo y almacenarlo en la tabla. Esta opción hará que el programa se ejecute más lento.
-i tipos_img
El formato del archivo de imagen, como raw. Usa '-i list' para listar los tipos soportados. Si no se proporciona, se utilizan métodos de autodetección.
-b tam_sector_dev
El tamaño (en bytes) de los sectores del dispositivo. Si no se proporciona, se utilizan métodos de autodetección.
imagen [imágenes]
La imagen de disco o partición a leer, cuyo formato se proporciona con '-i'. Se pueden dar varios nombres de archivo de imagen si la imagen está dividida en varios segmentos. Si solo se proporciona un archivo de imagen, y su nombre es el primero de una secuencia (por ejemplo, indicado por terminar en '.001'), los segmentos de imagen subsiguientes se incluirán automáticamente.

EJEMPLOS

Para cargar los datos de la imagen desde image.dd a image.dd.db:

# tsk_loaddb ./image.dd
