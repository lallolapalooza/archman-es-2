NOMBRE

ts_conf - Un programa de prueba para probar la API ts_conf_get() y ts_conf_set()

SINOPSIS

ts_conf

DESCRIPCIÓN

ts_conf es un programa de manipulación interactiva para el archivo de configuración ts.conf y la configuración que se está ejecutando actualmente.

VARIABLES DE ENTORNO

ver ts.conf (5)

VER TAMBIÉN

ts.conf (5), ts_conf_get (3), ts_conf_set (3)
