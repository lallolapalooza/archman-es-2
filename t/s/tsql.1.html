NOMBRE

tsql — utilidad para probar conexiones y consultas de FreeTDS

SINOPSIS

tsql {-S nombre_servidor [-I interfaz] | -H nombre_host [-L] [-p puerto]} [-D nombre_bd] [-U nombre_usuario] [-P contraseña] [-o opciones]

tsql -C

DESCRIPCIÓN

tsql es una herramienta de diagnóstico de FreeTDS. Utiliza el protocolo TDS para conectarse a un servidor Sybase o Microsoft SQL Server, y permite al usuario emitir consultas. tsql no utiliza las bibliotecas cliente de FreeTDS. En cambio, utiliza solo la biblioteca de nivel más bajo, libtds, para probar la implementación del protocolo.

tsql puede ejecutarse de dos maneras: una que utiliza el freetds.conf y otra que se conecta directamente usando el nombre de host y el puerto del servidor. Los parámetros -H y -p se proporcionan para permitir al usuario verificar si un servidor está escuchando en el host y puerto especificados. Estos parámetros anulan cualquier archivo de configuración y variables de entorno. El parámetro -S se puede usar para probar la configuración local. FreeTDS utilizará freetds.conf (o equivalente) y las variables de entorno de la manera habitual para determinar la dirección IP y el puerto del servidor. Puede usar -I para especificar un nombre de archivo, lo que anula el algoritmo de búsqueda de archivos de configuración de FreeTDS.

OPCIONES

-S nombre_servidor
servidor de base de datos al que conectarse.
-D nombre_bd
base de datos a utilizar.
-I interfaz
archivo freetds.conf o interfaces que describe el nombre_servidor.
-H nombre_host
nombre de host DNS del servidor.
-p puerto
puerto en el que está escuchando SQL Server.
-U nombre_usuario
nombre de inicio de sesión de la base de datos. Si no se proporciona el nombre de usuario, se intentará un inicio de sesión de dominio para las conexiones TDS 7+.
-P contraseña
contraseña de la base de datos.
-L
listar instancias de servidor de Microsoft (con -H).
-C
imprimir algunos de los parámetros de configuración en tiempo de compilación.
-o opciones
aplicar las opciones especificadas a cada comando.
-f
Sin pie de página [recuento de resultados]
-h
Sin encabezado [títulos]
-t
Imprimir tiempo
-v
Imprimir versión
-q
Silencioso
-a nombre_aplicacion
nombre de la aplicación.
-t terminador_columna
terminador de columna.
-r terminador_fila
terminador de fila.
-r terminador_fila
terminador de fila.
-J conjunto_caracteres
conjunto de caracteres.
-v
modo detallado.

NOTAS

Si puedes conectarte con ‘tsql -S nombre_servidor’,tu instalación básica de FreeTDS está funcionando.

Escribir ‘exit’,‘quit’,o ‘bye’ (o ^D) sale de tsql.

Escribir ‘version’ muestra la versión del protocolo TDS.

Los lotes de comandos pueden separarse con ‘go’ o ‘GO’. Si se usa ‘GO’, se informa la cadena de versión antes de ejecutar el lote.

Después de solicitar la contraseña (si no se proporcionó con -P), tsql intentará conectarse al servidor remoto. tsql muestra un contador que indica los segundos transcurridos durante el intento de conexión. Típicamente, tsql responde inmediatamente con un prompt ‘1>’. Si ve el contador (1, 2, 3, ...), lo más probable es que tsql no pueda conectarse al servidor indicado.

tsql no es un reemplazo para un isql completo como sqsh (www.sqsh.org). Si tiene sugerencias sobre cómo hacer que tsql sea más útil como herramienta de diagnóstico, por favor publíquelas en la lista de correo de FreeTDS para su consideración.
