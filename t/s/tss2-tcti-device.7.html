TCTI-DEVICE(7) Manual de Información Miscelánea TCTI-DEVICE(7)

NOMBRE

tcti-device - biblioteca TCTI del controlador de dispositivo

SINOPSIS

Un módulo de Interfaz de Transmisión de Comandos TPM (TCTI) para la interacción con el controlador de dispositivo.

DESCRIPCIÓN

tcti-device es una biblioteca que abstrae los detalles de la comunicación directa con el nodo del dispositivo expuesto por el controlador del kernel de Linux (típicamente /dev/tpm0). La interfaz expuesta por esta biblioteca está definida en la especificación "TSS System Level API and TPM Command Transmission Interface Specification".

AUTOR

Proyecto de Software TPM2 https://github.com/tpm2-software/tpm2-tss
