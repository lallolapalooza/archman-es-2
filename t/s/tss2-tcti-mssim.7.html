TCTI-SOCKET(7) Información Miscelánea Manual TCTI-SOCKET(7)

NOMBRE

tcti-socket - biblioteca TCTI de simulador TPM

SINOPSIS

Una biblioteca de Interfaz de Transmisión de Comandos TPM (TCTI) para la interacción con el simulador TPM2 de Microsoft.

DESCRIPCIÓN

tcti-socket es una biblioteca que abstrae los detalles de la comunicación directa con la interfaz y el protocolo expuestos por el demonio que aloja la implementación de referencia de TPM2. La interfaz expuesta por esta biblioteca se define en la especificación de “TSS System Level API and TPM Command Transmission Interface Specification”.

AUTOR

Proyecto de Software TPM2 https://github.com/tpm2-software/tpm2-tss
