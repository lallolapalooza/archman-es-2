tss2_changeauth(1) Manual de comandos generales tss2_changeauth(1)

NOMBRE

tss2_changeauth(1) - Este comando cambia los datos de autorización de una entidad referenciada por la ruta.

SINOPSIS

tss2_changeauth [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y los parámetros para todas las claves y operaciones de una interacción específica del TPM, como el algoritmo hash de nombres, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_changeauth(1) -

OPCIONES

Estas son las opciones disponibles:

•
-a, --authValue=CADENA:

La nueva contraseña UTF-8. Parámetro opcional. Si se omite, se le pedirá interactivamente al usuario una contraseña. Para establecer ninguna contraseña, esta opción debe usarse con la cadena vacía (““). El tamaño máximo de la contraseña está determinado por el tamaño del digest del algoritmo hash de nombres elegido en el perfil criptográfico (cf., fapi-profile(5)). Por ejemplo, elegir SHA256 como algoritmo hash permite contraseñas de un tamaño máximo de 32 caracteres.

•
-p, --entityPath=CADENA:

La ruta que identifica la entidad a modificar.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un breve resumen de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si el paginador de manuales falla, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de manuales, estos deben estar instalados o en MANPATH. Consulte man(1) para más detalles.

•
-v, --version: Muestra información de la versión de esta herramienta, tctis compatibles y sale.

EJEMPLOS

Cambiar una contraseña para una entidad HS/SRK/myRSACryptKey a M1

tss2_changeauth --entityPath=HS/SRK/myRSACryptKey --authValue=M1

Cambiar una contraseña para una entidad HS/SRK/myRSACryptKey y pedir al usuario que introduzca la contraseña.

tss2_changeauth --entityPath=HS/SRK/myRSACryptKey

RETORNOS

0 en caso de éxito o 1 en caso de fallo.
