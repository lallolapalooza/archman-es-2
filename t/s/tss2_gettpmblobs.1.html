tss2_gettpmblobs(1) Manual de Comandos Generales tss2_gettpmblobs(1)

NOMBRE

tss2_gettpmblobs(1) -

SINOPSIS

tss2_gettpmblobs [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar los parámetros de Fapi como el perfil criptográfico utilizado y el TCTI, o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción específica con TPM, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_gettpmblobs(1) - Este comando devuelve los blobs públicos y privados de un objeto, de modo que puedan ser cargados por una API de bajo nivel (por ejemplo, ESAPI). También devuelve la política asociada con estos blobs en formato JSON.

OPCIONES

Estas son las opciones disponibles:

•
-f, --force:

Forzar la sobrescritura del archivo de salida.

•
-p, --path=CADENA:

La ruta del objeto para el cual se devolverán los blobs.

•
-u, --tpm2bPublic=NOMBRE_ARCHIVO o - (para salida estándar):

El área pública devuelta del objeto como un TPM2B_PUBLIC serializado. Parámetro opcional.

•
-r, --tpm2bPrivate=NOMBRE_ARCHIVO o - (para salida estándar):

El área privada devuelta del objeto como un TPM2B_PRIVATE serializado. Parámetro opcional.

•
-l, --policy=NOMBRE_ARCHIVO o - (para stdout):

La política devuelta asociada con el objeto, codificada en JSON. Parámetro opcional.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra el manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción 'man', sin embargo, si se solicita explícitamente 'man', la herramienta proporcionará errores de man en stderr. Si se especifica la opción 'no-man' o el paginador de manuales falla, las opciones cortas se mostrarán en la salida estándar.

Para utilizar correctamente la función de manuales, es necesario que los manuales estén instalados o en el MANPATH. Consulte man(1) para obtener más detalles.

•
-v, --version: Muestra la información de la versión de esta herramienta, los TCTIs soportados y sale.

EJEMPLO

tss2_gettpmblobs --path=HS/SRK/myRSACrypt --tpm2bPublic=tpm2bPublic.file --tpm2bPrivate=tpm2bPrivate.file --policy=policy.file

RETORNA

0 en caso de éxito o 1 en caso de fallo.
