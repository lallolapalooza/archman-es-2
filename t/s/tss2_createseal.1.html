tss2_createseal(1)

Paquete: tpm2-tools

Licencias: BSD-3-Clause

tss2_createseal(1) Manual General de Comandos tss2_createseal(1)

NOMBRE

tss2_createseal(1) -

SINOPSIS

tss2_createseal [OPCIONES]

VER TAMBIÉN

fapi-config(5) para ajustar parámetros de Fapi como el perfil criptográfico utilizado y el TCTI o los directorios para los almacenamientos de metadatos de Fapi.

fapi-profile(5) para determinar los algoritmos criptográficos y parámetros para todas las claves y operaciones de una interacción TPM específica, como el algoritmo de hash de nombre, el algoritmo de firma asimétrica, el esquema y los parámetros, y la selección del banco de PCR.

DESCRIPCIÓN

tss2_createseal(1) - Este comando crea un objeto sellado y lo almacena en el almacén de metadatos de Fapi. Si no se proporcionan datos (es decir, un puntero NULL), el TPM genera datos aleatorios y llena el objeto sellado. Se utilizan esquemas de firma de TPM según lo especificado en el perfil criptográfico (ver fapi-profile(5)).

OPCIONES

Estas son las opciones disponibles:

•
-p, --path=CADENA:

La ruta a la nueva clave.

•
-t, --type=CADENA:

Identifica el uso previsto. Parámetro opcional. Los tipos pueden ser cualquier combinación separada por comas de:

- "exportable": Borra los atributos fixedTPM y fixedParent de una clave u
  objeto sellado.
- "noda": Establece el atributo noda de una clave o índice NV.
- "system": Almacena los blobs de datos y metadatos para una clave creada o sello
  en el directorio del sistema en lugar del directorio personal del usuario.
- Un número hexadecimal (por ejemplo, "0x81000001"): Marca un objeto de clave para
  hacerlo persistente y establece el manejador del objeto persistente a este valor.
•
-P, --policyPath=CADENA:

Identifica la política a asociar con la nueva clave. Parámetro opcional. Si se omite, no se asociará ninguna política con la clave.

Un policyPath se compone de dos elementos, separados por “/”. Un policyPath comienza con “/policy”. El segundo elemento de la ruta identifica la política o plantilla de política utilizando un nombre significativo.

•
-a, --authValue=CADENA:

La nueva contraseña UTF-8. Parámetro opcional. Si se omite, se le pide interactivamente al usuario una contraseña. Para establecer ninguna contraseña, esta opción debe usarse con la cadena vacía (““). El tamaño máximo de la contraseña está determinado por el tamaño del digest del algoritmo de hash de nombre elegido en el perfil criptográfico (ver fapi-profile(5)). Por ejemplo, elegir SHA256 como algoritmo de hash, permite contraseñas de un tamaño máximo de 32 caracteres.

•
-i, --data=NOMBRE_ARCHIVO o - (para stdin):

Los datos a ser sellados por el TPM. Parámetro opcional. No debe usarse junto con --size.

•
-s, --size=ENTERO:

Determina el número de bytes aleatorios que el TPM debe generar y sellar. Parámetro opcional. No debe ser “0”. No debe usarse junto con --data.

OPCIONES COMUNES

Esta colección de opciones son comunes a todos los programas tss2 y proporcionan información que muchos usuarios pueden esperar.

•
-h, --help [man|no-man]: Muestra la página del manual de la herramienta. Por defecto, intenta invocar el paginador de manuales para la herramienta, sin embargo, en caso de fallo, mostrará un resumen corto de la herramienta. Este es el mismo comportamiento si se especifica el argumento de opción “man”, sin embargo, si se solicita explícitamente “man”, la herramienta proporcionará errores de man en stderr. Si se especifica la opción “no-man”, o si falla el paginador de manuales, las opciones cortas se mostrarán en stdout.

Para usar correctamente la función de páginas del manual, se requiere que las páginas del manual estén instaladas o en MANPATH. Ver man(1) para más detalles.

•
-v, --version: Muestra información de versión para esta herramienta, TCTIs compatibles y sale.

EJEMPLO

Crea una clave con contraseña “abc” y lee los datos de sellado del archivo.

tss2_createseal --path=HS/SRK/mySealKey --type="noDa" --authValue=abc --data=data.file

RETORNOS

0 en caso de éxito o 1 en caso de fallo.
