NOMBRE

tkwait - Esperar a que una variable cambie o una ventana sea destruida

SINOPSIS

tkwait variable nombre

tkwait visibility nombre

tkwait window nombre

DESCRIPCIÓN

El comando tkwait espera a que ocurra una de varias cosas, y luego devuelve sin realizar ninguna otra acción. El valor de retorno es siempre una cadena vacía. Si el primer argumento es variable (o cualquier abreviatura del mismo) entonces el segundo argumento es el nombre de una variable global y el comando espera a que esa variable sea modificada. Si el primer argumento es visibility (o cualquier abreviatura del mismo) entonces el segundo argumento es el nombre de una ventana y el comando tkwait espera a un cambio en su estado de visibilidad (indicado por la llegada de un evento VisibilityNotify). Esta forma se usa típicamente para esperar a que una ventana recién creada aparezca en la pantalla antes de tomar alguna acción. Si el primer argumento es window (o cualquier abreviatura del mismo) entonces el segundo argumento es el nombre de una ventana y el comando tkwait espera a que esa ventana sea destruida. Esta forma se usa típicamente para esperar a que un usuario termine de interactuar con un cuadro de diálogo antes de usar el resultado de esa interacción.

Mientras el comando tkwait está esperando, procesa eventos de la manera normal, por lo que la aplicación continuará respondiendo a las interacciones del usuario. Si un manejador de eventos invoca tkwait nuevamente, la llamada anidada a tkwait debe completarse antes de que la llamada externa pueda completarse.

VER TAMBIÉN

bind(n), vwait(n)
