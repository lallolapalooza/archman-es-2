TKIPTUN-NG(8) Manual del Administrador del Sistema TKIPTUN-NG(8)

NOMBRE

tkiptun-ng - inyecta unos pocos paquetes en una red WPA TKIP con QoS

SINOPSIS

tkiptun-ng [opciones] <interfaz de repetición>

DESCRIPCIÓN

tkiptun-ng es una herramienta creada por Martin Beck, alias hirte, miembro del equipo de aircrack-ng. Esta herramienta es capaz de inyectar unos pocos paquetes en una red WPA TKIP con QoS. Trabajó con Erik Tews (quien creó el ataque PTW) para una conferencia en PacSec 2008: "Gone in 900 Seconds, Some Crypto Issues with WPA".

OPERACIÓN

-H, --help
Muestra la pantalla de ayuda.
Opciones de filtro:
-d <dmac>
Dirección MAC de destino.
-s <smac>
Dirección MAC de origen.
-m <len>
Longitud mínima del paquete.
-n <len>
Longitud máxima del paquete.
-t <tods>
Control de trama, bit "To" DS.
-f <fromds>
Control de trama, bit "From" DS.
-D
Deshabilitar la detección de AP.
Opciones de repetición:
-x <nbpps>
Número de paquetes por segundo.
-p <fctrl>
Establecer palabra de control de trama (hexadecimal).
-a <bssid>
Establecer la dirección MAC del Punto de Acceso.
-c <dmac>
Establecer la dirección MAC de destino.
-h <smac>
Establecer la dirección MAC de origen.
-e <essid>
Establecer el SSID de destino.
-M <sec>
Tiempo de espera para el error MIC en segundos. Por defecto: 60 segundos.
Opciones de depuración:
-K <prga>
Flujo de claves para la continuación.
-y <file>
Archivo de flujo de claves para la continuación.
-j
Inyectar paquetes FromFS.
-P <PMK>
Clave maestra de pares (PMK) para verificación o prueba de vulnerabilidad.
-p <PSK>
Clave precompartida (PSK) para calcular la PMK con el essid.
Opciones de origen:
-i <iface>
Capturar paquetes de esta interfaz.
-r <file>
Extraer paquetes de este archivo pcap.
