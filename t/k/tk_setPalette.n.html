tk_setPalette(n) Comandos integrados de Tk tk_setPalette(n)

NOMBRE

tk_setPalette, tk_bisque - Modificar la paleta de colores de Tk

SINOPSIS

tk_setPalette fondo

tk_setPalette nombre valor ?nombre valor ...?

tk_bisque

DESCRIPCIÓN

El procedimiento tk_setPalette cambia el esquema de color de Tk. Lo hace modificando los colores de los widgets existentes y cambiando la base de datos de opciones para que los widgets futuros utilicen el nuevo esquema de color. Si se invoca tk_setPalette con un solo argumento, el argumento es el nombre de un color para usar como color de fondo normal; tk_setPalette calculará una paleta de colores completa a partir de este color de fondo. Alternativamente, los argumentos de tk_setPalette pueden consistir en cualquier número de pares nombre-valor, donde el primer argumento del par es el nombre de una opción en la base de datos de opciones de Tk y el segundo argumento es el nuevo valor a usar para esa opción. Los siguientes nombres de base de datos son compatibles actualmente:

activeBackground	foreground	selectColor
activeForeground	highlightBackground	selectBackground
background	highlightColor	selectForeground
disabledForeground	insertBackground	troughColor

tk_setPalette intenta calcular valores predeterminados razonables para cualquier opción que usted no especifique. Puede especificar opciones distintas de las anteriores y Tk también cambiará esas opciones en los widgets. Esta característica puede ser útil si está utilizando widgets personalizados con opciones de color adicionales.

Una vez que ha calculado el nuevo valor a usar para cada una de las opciones de color, tk_setPalette escanea la jerarquía de widgets para modificar las opciones de todos los widgets existentes. Para cada widget, comprueba si alguna de las opciones anteriores está definida para el widget. Si es así, y si el valor actual de la opción es el predeterminado, el valor se cambia; si la opción tiene un valor distinto del predeterminado, tk_setPalette no lo cambiará. El valor predeterminado de una opción es el proporcionado por el widget ([lindex [$w configure $option] 3]) a menos que tk_setPalette se haya ejecutado previamente, en cuyo caso es el valor especificado en la invocación anterior de tk_setPalette.

Después de modificar todos los widgets de la aplicación, tk_setPalette añade opciones a la base de datos de opciones para cambiar los valores predeterminados de los widgets creados en el futuro. Las nuevas opciones se añaden en la prioridad widgetDefault, por lo que serán anuladas por las opciones del archivo .Xdefaults o por las opciones especificadas en la línea de comandos que crean un widget.

El procedimiento tk_bisque se proporciona para compatibilidad con versiones anteriores: restaura los colores de la aplicación al esquema de color marrón claro ("bisque") utilizado en Tk 3.6 y versiones anteriores.
