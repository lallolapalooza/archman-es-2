tk_getOpenFile(n) Comandos integrados de Tk tk_getOpenFile(n)

NOMBRE

tk_getOpenFile, tk_getSaveFile - mostrar un cuadro de diálogo para que el usuario seleccione un archivo para abrir o guardar.

SINOPSIS

tk_getOpenFile ?opción valor ...?
tk_getSaveFile ?opción valor ...?

DESCRIPCIÓN

Los procedimientos tk_getOpenFile y tk_getSaveFile muestran un cuadro de diálogo para que el usuario seleccione un archivo para abrir o guardar. El comando tk_getOpenFile se asocia generalmente con el comando Abrir en el menú Archivo. Su propósito es que el usuario seleccione un archivo existente *solamente*. Si el usuario introduce un archivo inexistente, el cuadro de diálogo muestra un mensaje de error y requiere que el usuario proporcione una selección alternativa. Si una aplicación permite al usuario crear nuevos archivos, debería hacerlo proporcionando un comando separado en el menú Nuevo.

El comando tk_getSaveFile se asocia generalmente con el comando Guardar como en el menú Archivo. Si el usuario introduce un archivo que ya existe, el cuadro de diálogo solicita al usuario confirmación para sobrescribir el archivo existente.

Los siguientes pares de *opción-valor* son posibles como argumentos de línea de comandos a estos dos comandos:

-command cadena
Especifica el prefijo de un comando Tcl para invocar cuando el usuario cierra el diálogo después de haber seleccionado un elemento. Esta devolución de llamada no se llama si el usuario canceló el diálogo. El comando real consiste en *cadena* seguida de un espacio y el valor seleccionado por el usuario en el diálogo. Esto solo está disponible en macOS.
-confirmoverwrite booleano
Configura cómo reacciona el diálogo de Guardar cuando el archivo seleccionado ya existe y guardarlo lo sobrescribiría. Un valor verdadero solicita que se presente un diálogo de confirmación al usuario. Un valor falso solicita que la sobrescritura se realice sin confirmación. El valor predeterminado es verdadero.
-defaultextension extensión
Especifica una cadena que se añadirá al nombre del archivo si el usuario introduce un nombre de archivo sin extensión. El valor predeterminado es la cadena vacía, lo que significa que no se añadirá ninguna extensión al nombre del archivo en ningún caso. Esta opción se ignora en macOS, que no requiere extensiones para los nombres de archivo, y la implementación de UNIX adivina valores razonables para esto a partir de la opción -filetypes cuando esta no se suministra.
-filetypes listaPatronesArchivo
Si existe una lista de selección de tipos de archivo en el diálogo de archivos de la plataforma particular, esta opción proporciona los *tipos de archivo* en esta lista. Cuando el usuario elige un tipo de archivo en la lista, solo se listan los archivos de ese tipo. Si esta opción no se especifica, o si se establece en la lista vacía, o si la lista de tipos de archivo no es compatible con la plataforma particular, entonces se listan todos los archivos independientemente de sus tipos. Consulte la sección ESPECIFICACIÓN DE PATRONES DE ARCHIVOS a continuación para una discusión sobre el contenido de *listaPatronesArchivo*.
-initialdir directorio
Especifica que los archivos en *directorio* se muestren cuando aparezca el diálogo. Si no se especifica este parámetro, el directorio inicial es por defecto el directorio de trabajo actual en sistemas no Windows y en sistemas Windows anteriores a Vista. En sistemas Vista y posteriores, el directorio inicial es por defecto el último directorio seleccionado por el usuario para la aplicación. Si el parámetro especifica una ruta relativa, el valor de retorno convertirá la ruta relativa a una ruta absoluta.
-initialfile nombreArchivo
Especifica un nombre de archivo que se mostrará en el diálogo cuando aparezca.
-message cadena
Especifica un mensaje a incluir en el área de cliente del diálogo. Esto solo está disponible en macOS.
-multiple booleano
Permite al usuario elegir múltiples archivos en el diálogo de Abrir.
-parent ventana
Hace que *ventana* sea el padre lógico del diálogo de archivo. El diálogo de archivo se muestra encima de su ventana padre. En macOS, esto convierte el diálogo de archivo en una hoja adjunta a la ventana padre.
-title cadenaTítulo
Especifica una cadena para mostrar como título del cuadro de diálogo. Si no se especifica esta opción, se muestra un título predeterminado.
-typevariable nombreVariable
La variable global *nombreVariable* se utiliza para preseleccionar qué filtro se usa de *listaFiltros* cuando se abre el cuadro de diálogo y se actualiza cuando se cierra el cuadro de diálogo, al último filtro seleccionado. La variable se lee una vez al principio para seleccionar el filtro apropiado. Si la variable no existe, o su valor no coincide con ningún tipo de filtro, o está vacía ({}), el cuadro de diálogo volverá al comportamiento predeterminado de seleccionar el primer filtro de la lista. Si el diálogo se cancela, la variable no se modifica.

Si el usuario selecciona un archivo, tanto tk_getOpenFile como tk_getSaveFile devuelven la ruta completa de este archivo. Si el usuario cancela la operación, ambos comandos devuelven la cadena vacía.

ESPECIFICACIÓN DE PATRONES DE ARCHIVOS

El valor *listaPatronesArchivo* dado por la opción -filetypes es una lista de patrones de archivo. Cada patrón de archivo es una lista de la forma

nombreTipo {extensión ?extensión ...?} ?{tipoMac ?tipoMac ...?}?
*nombreTipo* es el nombre del tipo de archivo descrito por este patrón de archivo y es la cadena de texto que aparece en la lista de selección de Tipos de archivo. *extensión* es una extensión de archivo para este patrón de archivo. *tipoMac* es un tipo de archivo de Macintosh de cuatro caracteres. La lista de *tipoMac* es opcional y puede omitirse para aplicaciones que no necesitan ejecutarse en la plataforma Macintosh.

Varios patrones de archivo pueden tener el mismo *nombreTipo*, en cuyo caso se refieren al mismo tipo de archivo y comparten la misma entrada en la lista de selección. Cuando el usuario selecciona una entrada en la lista de selección, se listan todos los archivos que coinciden con al menos uno de los patrones de archivo correspondientes a esa entrada. Normalmente, cada patrón de archivo corresponde a un tipo de archivo distinto. El uso de más de un patrón de archivo para un tipo de archivo solo es necesario en la plataforma Macintosh.

En la plataforma Macintosh, un archivo coincide con un patrón de archivo si su nombre coincide con al menos una de las *extensiones* Y pertenece al menos a uno de los *tipoMac* del patrón de archivo. Por ejemplo, el patrón de archivo Archivos de código fuente C en el código de ejemplo coincide con archivos que tienen una extensión de .c Y pertenecen al *tipoMac* TEXT. Para usar la regla OR en su lugar, puede usar dos patrones de archivo, uno solo con las *extensiones* y otro solo con el *tipoMac*. El tipo de archivo Archivos GIF en el código de ejemplo coincide con archivos que *o bien* tienen una extensión de .gif *o bien* pertenecen al *tipoMac* GIFF.

En las plataformas Unix y Windows, un archivo coincide con un patrón de archivo si su nombre coincide con al menos una de las *extensiones* del patrón de archivo. Los *tipoMac* se ignoran.

ESPECIFICACIÓN DE EXTENCIONES

En las plataformas Unix y Macintosh, las extensiones se comparan utilizando la coincidencia de patrones estilo glob. En la plataforma Windows, las extensiones son comparadas por el sistema operativo subyacente. Los tipos de extensiones posibles son:

(1)
la extensión especial “*” coincide con cualquier archivo;
(2)
la extensión especial “” coincide con cualquier archivo que no tenga extensión (es decir, el nombre del archivo no contiene ningún carácter de punto);
(3)
cualquier cadena de caracteres que no contenga caracteres comodín (* y ?).

Debido a las diferentes reglas de coincidencia de patrones en las diversas plataformas, para garantizar la portabilidad, no se permiten caracteres comodín en las extensiones, excepto como en la extensión especial “*”. Las extensiones sin un punto completo

NOMBRE

tk_getOpenFile – abre un cuadro de diálogo para seleccionar un archivo para abrir.

SINOPSIS

tk_getOpenFile ?opciones?

DESCRIPCIÓN

El comando tk_getOpenFile muestra un cuadro de diálogo de selección de archivo modal. El usuario puede navegar por el sistema de archivos, introducir un nombre de archivo y elegir abrirlo. Si el usuario confirma su selección, el comando devuelve la ruta completa al archivo seleccionado; de lo contrario, devuelve una cadena vacía.

Este comando puede aceptar las siguientes opciones:

-defaultextension string
Especifica una extensión de archivo que se añadirá automáticamente si el usuario no proporciona ninguna. Por ejemplo, si se establece en .txt y el usuario introduce myfile, el nombre del archivo se convertirá en myfile.txt.
-filetypes lista
Define los tipos de archivo que se pueden mostrar en el cuadro de diálogo. Cada elemento de la lista es una lista de dos o tres elementos que describe un tipo de archivo. El primer elemento es una cadena de descripción (que aparece en el cuadro de selección de tipo de archivo), el segundo es un patrón de nombre de archivo (que se utiliza para filtrar los archivos que se muestran), y opcionalmente un tercer elemento que es un patrón de nombre de archivo o una cadena especial para determinar el modo de apertura del archivo (por ejemplo, TEXT para archivos de texto, BINARY para binarios).
-initialdir directorio
Especifica el directorio que se mostrará inicialmente en el cuadro de diálogo.
-initialfile nombrearchivo
Especifica el nombre de archivo que se mostrará inicialmente en el campo de entrada de nombre de archivo. Esto puede ser útil para sugerir un nombre de archivo para guardar.
-parent ventana
Especifica la ventana padre del cuadro de diálogo. Si no se proporciona, se utiliza la ventana raíz.
-title cadena
Establece el texto que se muestra en la barra de título del cuadro de diálogo.

ESPECIFICACIÓN DE PATRONES DE ARCHIVO

Los patrones de nombre de archivo pueden contener los siguientes comodines:

  • * Coincide con cualquier secuencia de caracteres.
  • ? Coincide con cualquier carácter individual.
  • [seq] Coincide con cualquier carácter en la secuencia.
  • [!seq] Coincide con cualquier carácter que no esté en la secuencia.

Los patrones también pueden incluir especificadores de tipo de archivo, como *.txt para archivos de texto, *.tcl para scripts Tcl, etc. El guion (-) no está permitido en los patrones de nombre de archivo, ya que se utiliza para separar los patrones de extensión.

ESPECIFICACIÓN DE EXTENSIONES

Las extensiones de archivo se pueden especificar de varias maneras:

  • .ext: Coincide con archivos que terminan con la extensión especificada (por ejemplo, .txt).
  • *: Coincide con todos los archivos.
  • Cualquier otra cadena: Se interpreta como una extensión literal.

Los caracteres de escape como “~” (tildes) están permitidos, pero pueden no funcionar en todas las plataformas.

EJEMPLO

set types {
    {{Archivos de texto}       {.txt}        }
    {{Scripts TCL}      {.tcl}        }
    {{Archivos fuente C}   {.c}      TEXT}
    {{Archivos GIF}        {.gif}        }
    {{Archivos GIF}        {}        GIFF}
    {{Todos los archivos}        *             }
}
set filename [tk_getOpenFile -filetypes $types]
if {$filename ne ""} {
    # Abrir el archivo ...
}
