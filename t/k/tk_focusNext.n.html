tk_focusNext(n)

Paquete: tk

Licencias: TCL

tk_focusNext(n) Comandos integrados de Tk tk_focusNext(n)

NOMBRE

tk_focusNext, tk_focusPrev, tk_focusFollowsMouse - Procedimientos de utilidad para gestionar el foco de entrada.

SINOPSIS

tk_focusNext ventana

tk_focusPrev ventana

tk_focusFollowsMouse

DESCRIPCIÓN

tk_focusNext es un procedimiento de utilidad utilizado para la navegación por teclado. Devuelve la ventana "siguiente" después de ventana en el orden de foco. El orden de foco se determina por el orden de apilamiento de las ventanas y la estructura de la jerarquía de ventanas. Entre hermanos, el orden de foco es el mismo que el orden de apilamiento, siendo la ventana más baja la primera. Si una ventana tiene hijos, se visita primero la ventana, seguida de sus hijos (recursivamente), seguida de su hermano siguiente. Las ventanas de nivel superior distintas de ventana se omiten, de modo que tk_focusNext nunca devuelve una ventana en un nivel superior diferente al de ventana.

Después de calcular la siguiente ventana, tk_focusNext examina la opción -takefocus de la ventana para ver si debe omitirse. Si es así, tk_focusNext continúa con la siguiente ventana en el orden de foco, hasta que finalmente encuentra una ventana que acepta el foco o regresa a ventana.

tk_focusPrev es similar a tk_focusNext excepto en que devuelve la ventana anterior a ventana en el orden de foco.

tk_focusFollowsMouse cambia el modelo de foco de la aplicación a uno implícito donde la ventana debajo del ratón obtiene el foco. Después de llamar a este procedimiento, cada vez que el ratón entra en una ventana, Tk le otorgará automáticamente el foco de entrada. El comando focus puede usarse para mover el foco a una ventana distinta a la que está bajo el ratón, pero tan pronto como el ratón se mueva a una nueva ventana, el foco saltará a esa ventana. Nota: en este momento no hay soporte integrado para devolver la aplicación a un modelo de foco explícito; para hacerlo, tendrá que escribir un script que elimine los enlaces creados por tk_focusFollowsMouse.
