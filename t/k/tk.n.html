tk(n) Comandos integrados de Tk tk(n)

NOMBRE

tk — Manipular el estado interno de Tk

SINOPSIS

tk opción ?arg ...?

DESCRIPCIÓN

El comando tk proporciona acceso a elementos misceláneos del estado interno de Tk. La mayor parte de la información manipulada por este comando pertenece a la aplicación en su conjunto, o a una pantalla o visualización, en lugar de a una ventana en particular. El comando puede tomar cualquiera de una serie de formas diferentes dependiendo del argumento opción. Las formas legales son:

tk appname ?nuevoNombre?
Si no se especifica nuevoNombre, este comando devuelve el nombre de la aplicación (el nombre que puede usarse en comandos send para comunicarse con la aplicación). Si se especifica nuevoNombre, el nombre de la aplicación se cambia a nuevoNombre. Si el nombre dado ya está en uso, se le añade un sufijo de la forma “ #2” o “ #3” para hacer el nombre único. El resultado del comando es el nombre realmente elegido. nuevoNombre no debe comenzar con una letra mayúscula. Esto interferirá con el procesamiento de opciones, ya que se asume que los nombres que comienzan con mayúsculas son clases; como resultado, Tk podría no ser capaz de encontrar algunas opciones para la aplicación. Si los envíos se han deshabilitado al borrar el comando send, este comando los volverá a habilitar y recreará el comando send.
tk busy subcomando ...
Este comando controla la marcación de jerarquías de ventanas como "ocupadas", haciéndolas no interactivas mientras se está procesando alguna otra operación. Para más detalles, consulte la página del manual busy.
tk caret ventana ?-x x? ?-y y? ?-height altura?
Establece y consulta la ubicación del cursor para la visualización de la ventana Tk especificada ventana. El cursor es la ubicación del cursor por pantalla utilizada para indicar el foco global (por ejemplo, para cumplir con las directrices de accesibilidad de Microsoft), así como para la ubicación de las ventanas XIM (Métodos de entrada X) o IME de Windows sobre la posición. Si no se especifican opciones, se devuelven los últimos valores utilizados para establecer el cursor en formato de par opción-valor. -x y -y representan coordenadas relativas a la ventana, y -height es la altura de la ubicación actual del cursor, o la altura de la ventana especificada si no se da ninguna.
tk inactive ?-displayof ventana? ?reset?
Devuelve un entero positivo, el número de milisegundos transcurridos desde la última vez que el usuario interactuó con el sistema. Si se proporciona la opción -displayof, el valor de retorno se refiere a la visualización de ventana; de lo contrario, se refiere a la visualización de la ventana principal de la aplicación.

tk inactive devolverá -1, si la consulta del tiempo de inactividad del usuario no es compatible con el sistema, y en intérpretes seguros.

Si se proporciona la cadena literal reset como argumento adicional, el temporizador se reinicia y se devuelve una cadena vacía. El reinicio del tiempo de inactividad está prohibido en intérpretes seguros y lanzará un error si se intenta.

tk fontchooser subcomando ...
Controla el diálogo de selección de fuentes de Tk. Para más detalles, consulte la página del manual fontchooser.
tk scaling ?-displayof ventana? ?número?
Establece y consulta el factor de escala actual utilizado por Tk para convertir entre unidades físicas (por ejemplo, puntos, pulgadas o milímetros) y píxeles. El argumento número es un número de punto flotante que especifica el número de píxeles por punto en la pantalla de ventana. Si se omite el argumento ventana, por defecto es la ventana principal. Si se omite el argumento número, se devuelve el valor actual del factor de escala.

Un “punto” es una unidad de medida igual a 1/72 de pulgada. Un factor de escala de 1.0 corresponde a 1 píxel por punto, que es equivalente a un monitor estándar de 72 dpi. Un factor de escala de 1.25 significaría 1.25 píxeles por punto, que es la configuración para un monitor de 90 dpi; establecer el factor de escala a 1.25 en un monitor de 72 dpi haría que todo en la aplicación se mostrara 1.25 veces más grande de lo normal. El valor inicial del factor de escala se establece cuando la aplicación se inicia, basándose en las propiedades del monitor instalado, pero puede cambiarse en cualquier momento. Las mediciones realizadas después de cambiar el factor de escala utilizarán el nuevo factor de escala, pero no está definido si los widgets existentes se redimensionarán dinámicamente para adaptarse al nuevo factor de escala.

tk useinputmethods ?-displayof ventana? ?booleano?
Establece y consulta el estado de si Tk debe usar XIM (Métodos de entrada X) para filtrar eventos. Se devuelve el estado resultante. XIM se utiliza en algunas localidades (es decir, japonés, coreano), para manejar dispositivos de entrada especiales. Esta característica solo es significativa en X. Si el soporte XIM no está disponible, esto siempre devolverá 0. Si se omite el argumento ventana, por defecto es la ventana principal. Si se omite el argumento booleano, se devuelve el estado actual. Esto está activado por defecto para la pantalla principal.
tk windowingsystem
Devuelve el sistema de ventanas de Tk actual, uno de x11 (basado en X11), win32 (MS Windows) o aqua (macOS Aqua).
