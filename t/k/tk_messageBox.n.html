Paquete: tk

Licencias: TCL

tk_messageBox(n) Comandos integrados de Tk tk_messageBox(n)

NOMBRE

tk_messageBox - muestra una ventana de mensaje y espera la respuesta del usuario.

SINOPSIS

tk_messageBox ?opción valor ...?

DESCRIPCIÓN

Este procedimiento crea y muestra una ventana de mensaje con un mensaje especificado por la aplicación, un icono y un conjunto de botones. Cada uno de los botones de la ventana de mensaje se identifica por un nombre simbólico único (ver las opciones de -type). Después de mostrar la ventana de mensaje, tk_messageBox espera a que el usuario seleccione uno de los botones. Luego devuelve el nombre simbólico del botón seleccionado.

Las siguientes combinaciones de opción-valor son compatibles:

-command cadena
Especifica el prefijo de un comando Tcl a invocar cuando el usuario cierra el diálogo. El comando real consiste en cadena seguido de un espacio y el nombre del botón en el que hizo clic el usuario para cerrar el diálogo. Esto solo está disponible en macOS.
-default nombre
Nombre da el nombre simbólico del botón predeterminado para esta ventana de mensaje ( “ok”, “cancel”, y así sucesivamente). Consulte -type para obtener una lista de los nombres simbólicos. Si esta opción no se especifica, el primer botón del diálogo se convertirá en el predeterminado.
-detail cadena
Especifica un mensaje auxiliar al mensaje principal dado por la opción -message. El detalle del mensaje se presentará debajo del mensaje principal y, donde sea compatible con el sistema operativo, con una fuente menos destacada que el mensaje principal.
-icon imagenIcono
Especifica un icono a mostrar. imagenIcono debe ser uno de los siguientes: error, info, question o warning. Si esta opción no se especifica, se mostrará el icono de información.
-message cadena
Especifica el mensaje a mostrar en este cuadro de mensaje. El valor predeterminado es una cadena vacía.
-parent ventana
Hace que ventana sea el padre lógico del cuadro de mensaje. El cuadro de mensaje se muestra encima de su ventana padre.
-title cadenaTítulo
Especifica una cadena a mostrar como título del cuadro de mensaje. El valor predeterminado es una cadena vacía.
-type tipoPredefinido
Organiza la visualización de un conjunto predefinido de botones. Los siguientes valores son posibles para tipoPredefinido:
abortretryignore
Muestra tres botones cuyos nombres simbólicos son abort, retry y ignore.
ok
Muestra un botón cuyo nombre simbólico es ok. Este es el predeterminado.
okcancel
Muestra dos botones cuyos nombres simbólicos son ok y cancel.
retrycancel
Muestra dos botones cuyos nombres simbólicos son retry y cancel.
yesno
Muestra dos botones cuyos nombres simbólicos son yes y no.
yesnocancel
Muestra tres botones cuyos nombres simbólicos son yes, no y cancel.

EJEMPLO

set answer [tk_messageBox -message "¿Realmente quieres salir?" \
        -icon question -type yesno \
        -detail "Selecciona \"Sí\" para que la aplicación salga"]
switch -- $answer {
    yes exit
    no {tk_messageBox -message "¡Sé que te gusta esta aplicación!" \
            -type ok}
