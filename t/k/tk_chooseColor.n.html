tk_chooseColor(n) Comandos integrados de Tk tk_chooseColor(n)

NOMBRE

tk_chooseColor - muestra un cuadro de diálogo para que el usuario seleccione un color.

SINOPSIS

tk_chooseColor ?opción valor...?

DESCRIPCIÓN

El procedimiento tk_chooseColor muestra un cuadro de diálogo para que el usuario seleccione un color. Los siguientes pares de *opción-valor* son posibles como argumentos de línea de comandos:

-initialcolor color
Especifica el color que se mostrará en el cuadro de diálogo de color cuando aparezca. color debe estar en un formato aceptable para la función Tk_GetColor.
-parent ventana
Convierte ventana en el padre lógico del cuadro de diálogo de color. El cuadro de diálogo de color se muestra encima de su ventana padre.
-title cadenaDeTítulo
Especifica una cadena que se mostrará como título del cuadro de diálogo. Si esta opción no se especifica, se mostrará un título predeterminado.

Si el usuario selecciona un color, tk_chooseColor devolverá el nombre del color en un formato aceptable para Tk_GetColor. Si el usuario cancela la operación, ambos comandos devolverán la cadena vacía.

EJEMPLO

button .b -bg [tk_chooseColor -initialcolor gray -title "Elige color"]

PALABRAS CLAVE

color, selección de color, diálogo
