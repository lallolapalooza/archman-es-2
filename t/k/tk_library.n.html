tkvars(n) Comandos integrados de Tk tkvars(n)

NOMBRE

geometry, tk_library, tk_patchLevel, tk_strictMotif, tk_version - Variables utilizadas o establecidas por Tk

DESCRIPCIÓN

Las siguientes variables de Tcl son establecidas o utilizadas por Tk en varios momentos de su ejecución:

tk_library
Esta variable contiene el nombre de archivo de un directorio que contiene una biblioteca de scripts Tcl relacionados con Tk. Estos scripts incluyen un archivo de inicialización que normalmente se procesa cada vez que una aplicación Tk se inicia, además de otros archivos que contienen procedimientos que implementan comportamientos predeterminados para los widgets.

El valor inicial de tk_library se establece cuando Tk se añade a un intérprete; esto se hace buscando varios directorios diferentes hasta que se encuentra uno que contenga un script de inicio de Tk apropiado. Si la variable de entorno TK_LIBRARY existe, entonces se comprueba primero el directorio que nombra. Si TK_LIBRARY no está establecido o no se refiere a un directorio apropiado, entonces Tk comprueba varios otros directorios basándose en una ubicación predeterminada compilada, la ubicación del directorio de la biblioteca Tcl, la ubicación del binario que contiene la aplicación y el directorio de trabajo actual.

Una aplicación puede modificar la variable para cambiar a una biblioteca diferente.

tk_patchLevel
Contiene una secuencia de enteros decimales separados por puntos que indica el nivel de parche actual de Tk. El nivel de parche se incrementa con cada nueva versión o parche, y identifica de forma única una versión oficial de Tk.

Este valor es normalmente el mismo que el resultado de “package require Tk”.

tk_strictMotif
Esta variable se establece en cero por defecto. Si una aplicación la establece en uno, entonces Tk intenta adherirse lo más posible a los estándares de apariencia de Motif. Por ejemplo, los elementos activos como los botones y los deslizadores de las barras de desplazamiento no cambiarán de color cuando el puntero pase sobre ellos. Las aplicaciones modernas no deberían establecer normalmente esta variable.
tk_version
Tk establece esta variable en el intérprete para cada aplicación. La variable contiene el número de versión actual de la biblioteca Tk en el formato major.minor. Major y minor son enteros. El número de versión principal aumenta en cualquier lanzamiento de Tk que incluya cambios que no sean compatibles con versiones anteriores (es decir, cuando las aplicaciones y scripts de Tk existentes puedan tener que cambiar para funcionar con la nueva versión). El número de versión secundaria aumenta con cada nuevo lanzamiento de Tk, excepto que se reinicia a cero cada vez que cambia el número de versión principal.

VARIABLES INTERNAS Y DE DEPURACIÓN

Estas variables normalmente no deben ser establecidas por código de usuario.

tk::Priv
Esta variable es una matriz que contiene varias piezas de información que son privadas para Tk. Los elementos de tk::Priv son utilizados por los procedimientos de la biblioteca Tk y las uniones predeterminadas. No deben ser accedidos por ningún código fuera de Tk.
tk_textRedraw
tk_textRelayout
Estas variables son establecidas por los widgets de texto cuando tienen la depuración activada. Los valores escritos en estas variables se pueden utilizar para probar o depurar operaciones de widgets de texto. Estas variables son utilizadas principalmente por el conjunto de pruebas de Tk.

OTRAS VARIABLES GLOBALES

Las siguientes variables solo están garantizadas de existir en los ejecutables de wish; la biblioteca Tk no las define por sí misma, pero muchos entornos Tk sí lo hacen.

geometry
Si está establecida, contiene la especificación de geometría proporcionada por el usuario para la ventana principal de Tk.
