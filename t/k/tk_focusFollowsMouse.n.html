tk_focusFollowsMouse(n)

Paquete: tk

Licencias: TCL

tk_focusNext(n) Comandos incorporados de Tk tk_focusNext(n)

NOMBRE

tk_focusNext, tk_focusPrev, tk_focusFollowsMouse - Procedimientos de utilidad para gestionar el foco de entrada.

SINOPSIS

tk_focusNext ventana

tk_focusPrev ventana

tk_focusFollowsMouse

DESCRIPCIÓN

tk_focusNext es un procedimiento de utilidad utilizado para la travésía del teclado. Devuelve la ventana "siguiente" después de ventana en el orden del foco. El orden del foco está determinado por el orden de apilamiento de las ventanas y la estructura de la jerarquía de ventanas. Entre hermanos, el orden del foco es el mismo que el orden de apilamiento, siendo la ventana más baja la primera. Si una ventana tiene hijos, se visita primero la ventana, seguida de sus hijos (recursivamente), seguida de su hermano siguiente. Se omiten las ventanas de nivel superior distintas de ventana, de modo que tk_focusNext nunca devuelve una ventana en un nivel superior diferente al de ventana.

Después de calcular la siguiente ventana, tk_focusNext examina la opción -takefocus de la ventana para ver si debe omitirse. Si es así, tk_focusNext continúa a la siguiente ventana en el orden del foco, hasta que finalmente encuentra una ventana que acepte el foco o regresa a ventana.

tk_focusPrev es similar a tk_focusNext excepto en que devuelve la ventana anterior a ventana en el orden del foco.

tk_focusFollowsMouse cambia el modelo de foco de la aplicación a uno implícito en el que la ventana bajo el ratón obtiene el foco. Después de llamar a este procedimiento, cada vez que el ratón entre en una ventana, Tk le otorgará automáticamente el foco de entrada. El comando focus puede usarse para mover el foco a una ventana distinta de la que está bajo el ratón, pero tan pronto como el ratón se mueva a una nueva ventana, el foco saltará a esa ventana. Nota: actualmente no hay soporte incorporado para devolver la aplicación a un modelo de foco explícito; para hacerlo, tendrá que escribir un script que elimine las asociaciones creadas por tk_focusFollowsMouse.
