tk_dialog(n) Comandos integrados de Tk tk_dialog(n)

NOMBRE

tk_dialog - Crear un diálogo modal y esperar respuesta

SINOPSIS

tk_dialog ventana título texto mapa de bits valor predeterminado cadena cadena ...

DESCRIPCIÓN

Este procedimiento forma parte de la biblioteca de scripts de Tk. Está en gran medida *obsoleto* por el comando tk_messageBox. Sus argumentos describen un cuadro de diálogo:

ventana
Nombre de la ventana de nivel superior a utilizar para el diálogo. Cualquier ventana existente con este nombre se destruye.
título
Texto que aparecerá en la barra de título del gestor de ventanas para el diálogo.
texto
Mensaje que aparecerá en la parte superior del cuadro de diálogo.
mapa de bits
Si no está vacío, especifica un mapa de bits (en un formato adecuado para Tk_GetBitmap) para mostrar en la parte superior del diálogo, a la izquierda del texto. Si esta es una cadena vacía, no se mostrará ningún mapa de bits en el diálogo.
valor predeterminado
Si es un entero mayor o igual a cero, indica el índice del botón que será el botón predeterminado para el diálogo (0 para el botón más a la izquierda, y así sucesivamente). Si es menor que cero o una cadena vacía, no habrá ningún botón predeterminado.
cadena
Habrá un botón por cada uno de estos argumentos. Cada cadena especifica el texto a mostrar en un botón, en orden de izquierda a derecha.

Después de crear un cuadro de diálogo, tk_dialog espera a que el usuario seleccione uno de los botones, ya sea haciendo clic en el botón con el ratón o pulsando Intro para invocar el botón predeterminado (si lo hay). Luego devuelve el índice del botón seleccionado: 0 para el botón más a la izquierda, 1 para el botón a su lado, y así sucesivamente. Si la ventana del diálogo se destruye antes de que el usuario seleccione uno de los botones, se devuelve -1.

Mientras espera la respuesta del usuario, tk_dialog establece un "grab" local. Esto evita que el usuario interactúe con la aplicación de ninguna manera, excepto para invocar el cuadro de diálogo.

EJEMPLO

set reply [tk_dialog .foo "El Título" "¿Quieres decir sí?" \
        questhead 0 Sí No "No estoy seguro"]
