NOMBRE

tk_popup - Mostrar un menú emergente

SINOPSIS

tk_popup menú x y ?entrada?

DESCRIPCIÓN

Este procedimiento muestra un menú en una posición dada en la pantalla y configura Tk para que el menú y sus submenús puedan ser recorridos con el ratón o el teclado. menú es el nombre de un widget de menú y x e y son las coordenadas de la raíz en las que mostrar el menú. Si entrada se omite o es una cadena vacía, la esquina superior izquierda del menú se posicionará en el punto dado. De lo contrario, entrada proporciona el índice de una entrada en menú y el menú se posicionará de manera que la entrada se posicione sobre el punto dado.

EJEMPLO

Cómo adjuntar un menú emergente simple a un widget.

# Crear un menú
set m [menu .popupMenu]
$m add command -label "Ejemplo 1" -command bell
$m add command -label "Ejemplo 2" -command bell
# Crear algo a lo que adjuntarlo
pack [label .l -text "¡Haz clic aquí!"]
# Organizar para que el menú aparezca cuando se haga clic en la etiqueta
bind .l <1> {tk_popup .popupMenu %X %Y}
