NOMBRE

tkpp - interfaz gráfica para pp escrita en Perl/Tk.

SINOPSIS

Simplemente tienes que ejecutar el comando:

tkpp

DESCRIPCIÓN

Tkpp es una interfaz gráfica para pp, que puede convertir scripts de Perl en archivos PAR independientes, scripts de Perl o ejecutables.

Puedes guardar la línea de comandos generada, cargar y guardar tu configuración gráfica de Tkpp. A continuación se explica brevemente la GUI de tkpp.

Menú

Archivo -> Guardar línea de comandos

Cuando creas o muestras la línea de comandos en la GUI de Tkpp, puedes guardarla en un archivo separado. Esta línea de comandos puede ser ejecutada desde una terminal.

Archivo -> Guardar configuración

Puedes guardar la configuración de tu GUI (todas las opciones utilizadas) para cargarla y ejecutarla la próxima vez.

Archivo -> Cargar configuración

Carga tu archivo de configuración guardado. Todas las opciones guardadas se establecerán en la GUI.

Archivo -> Salir

Cierra Tkpp.

Ayuda -> Documentación de Tkpp

Muestra la documentación POD de Tkpp.

Ayuda -> Documentación de pp

Muestra la documentación POD de pp.

Ayuda -> Acerca de Tkpp

Muestra la versión y los autores de Tkpp.

Ayuda -> Acerca de pp

Muestra la versión y los autores de pp (pp --version).

Pestañas GUI

Hay cinco pestañas en la GUI: Opciones generales, Información, Tamaño, Otras opciones y Salida.

Todas las pestañas contienen todas las opciones que se pueden utilizar con pp. Se conservan todas las opciones predeterminadas de pp. Ahora puedes configurar las opciones como desees. Cuando hayas terminado, puedes mostrar la línea de comandos o empezar a crear tu paquete. Tendrás la pestaña de salida para ver los mensajes de error o verbosos.

NOTAS

En el sistema Win32, la compilación se ejecuta en un proceso separado, por lo que la GUI no se congela.

La primera vez que uses Tkpp, te pedirá que instales algunos módulos de CPAN para usar la GUI (como Tk, Tk::ColoredButton...).
