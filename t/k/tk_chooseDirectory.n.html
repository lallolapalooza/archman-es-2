tk_chooseDirectory(n) Comandos integrados de Tk tk_chooseDirectory(n)

NOMBRE

tk_chooseDirectory - muestra un cuadro de diálogo para que el usuario seleccione un directorio.

SINOPSIS

tk_chooseDirectory ?opción valor ...?

DESCRIPCIÓN

El procedimiento tk_chooseDirectory muestra un cuadro de diálogo para que el usuario seleccione un directorio. Las siguientes pares de *opción-valor* son posibles como argumentos de línea de comandos:

-comando cadena
Especifica el prefijo de un comando Tcl para invocar cuando el usuario cierra el diálogo después de haber seleccionado un elemento. Esta devolución de llamada no se llama si el usuario canceló el diálogo. El comando real consiste en *cadena* seguida de un espacio y el valor seleccionado por el usuario en el diálogo. Esto solo está disponible en macOS.
-directorioinicial nombre_directorio
Especifica que los directorios en *directorio* se deben mostrar cuando aparezca el diálogo. Si no se especifica este parámetro, el directorio inicial se establecerá por defecto en el directorio de trabajo actual en sistemas que no son Windows y en sistemas Windows anteriores a Vista. En Vista y sistemas posteriores, el directorio inicial se establecerá por defecto en el último directorio seleccionado por el usuario para la aplicación. Si el parámetro especifica una ruta relativa, el valor de retorno convertirá la ruta relativa a una ruta absoluta.
-mensaje cadena
Especifica un mensaje para incluir en el área del cliente del diálogo. Esto solo está disponible en macOS.
-debeserexistente booleano
Especifica si al usuario se le permite especificar directorios inexistentes. Si este parámetro es verdadero, entonces el usuario solo puede seleccionar directorios que ya existen. El valor por defecto es *falso*.
-padre ventana
Hace que *ventana* sea el padre lógico del diálogo. El diálogo se muestra encima de su ventana padre. En macOS, esto convierte el archivo diálogo en una hoja adjunta a la ventana padre.
-titulo cadena_titulo
Especifica una cadena para mostrar como título del cuadro de diálogo. Si esta opción no se especifica, entonces se mostrará un título por defecto.

EJEMPLO

set dir [tk_chooseDirectory \
        -initialdir ~ -title "Elige un directorio"]
if {$dir eq ""} {
   label .l -text "No se seleccionó ningún directorio"
} else {
   label .l -text "Seleccionado $dir"
}
