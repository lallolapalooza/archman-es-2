Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_kprobe_alloc, tracefs_kretprobe_alloc, tracefs_kprobe_raw, tracefs_kretprobe_raw, tracefs_kprobe_destroy - Asignar, obtener, crear y eliminar kprobes

SINOPSIS

#include <tracefs.h>
struct tracefs_dynevent *
tracefs_kprobe_alloc(const char *system, const char *event,
                       const char *addr, const char *format);
struct tracefs_dynevent *
tracefs_kretprobe_alloc(const char *system, const char *event,
                          const char *addr, const char *format, unsigned int max);
int tracefs_kprobe_raw(const char *system, const char *event,
                         const char *addr, const char *format);
int tracefs_kretprobe_raw(const char *system, const char *event,
                            const char *addr, const char *format);
int tracefs_kprobe_destroy(const char *system, const char *event,
                           const char *addr, const char *format, bool force);

DESCRIPCIÓN

tracefs_kprobe_alloc() asigna un nuevo contexto kprobe. El kprobe no está configurado en el sistema. El kprobe puede agregarse al sistema pasando el descriptor devuelto a tracefs_dynevent_create(3). El nuevo kprobe estará en el grupo system (o kprobes si system es NULL) y tendrá el nombre de event (o addr si event es NULL). El kprobe se insertará en addr (nombre de función, con o sin desplazamiento, o una dirección), y format definirá el formato del kprobe. Consulte el archivo de documentación de Linux en: Documentation/trace/kprobetrace.rst

tracefs_kretprobe_alloc() es lo mismo que tracefs_kprobe_alloc, pero asigna contexto para kretprobe. Tiene un parámetro adicional, que es opcional, max: el número máximo de elementos activos. Consulte la descripción de kretprobes en el archivo Documentation/trace/kprobetrace.rst.

tracefs_kprobe_raw() creará un evento kprobe. Si system es NULL, se utilizará el predeterminado "kprobes" para el grupo (sistema de eventos). De lo contrario, si se especifica system, el kprobe se creará en el grupo con ese nombre. event es el nombre del evento kprobe a crear. addr puede ser una función, una función y un desplazamiento, o una dirección del kernel. Aquí es donde se insertará la ubicación del kprobe en el kernel. format es el formato del kprobe tal como se especifica en FETCHARGS en el código fuente del kernel de Linux en el documento Documentation/trace/kprobetrace.rst.

tracefs_kretprobe_raw() es lo mismo que tracefs_kprobe_raw(), excepto que crea un kretprobe en lugar de un kprobe. La diferencia también se describe en el código fuente del kernel de Linux en el archivo Documentation/trace/kprobetrace.rst.

tracefs_kprobe_destroy() destruirá un kprobe o kretprobe específico creado por tracefs_kprobe_raw() o tracefs_kretprobe_raw() con los mismos parámetros.

VALOR DE RETORNO

tracefs_kprobe_raw() y tracefs_kretprobe_raw() devuelven 0 si tienen éxito, o -1 si hay un error. Si ocurre un error de análisis sintáctico en tracefs_kprobe_raw() o tracefs_kretprobe_raw(), se puede usar tracefs_error_last(3) para recuperar el mensaje de error que explica el problema de análisis sintáctico.

Las API tracefs_kprobe_alloc() y tracefs_kretprobe_alloc() devuelven un puntero a una estructura tracefs_dynevent asignada, que describe la sonda. Este puntero debe liberarse con tracefs_dynevent_free(3). Tenga en cuenta que esto solo asigna un descriptor que representa el kprobe. No modifica el sistema en ejecución.

tracefs_kprobe_destroy() devuelve 0 si tiene éxito o -1 si hay un error si no pudo destruir (o encontrar) el kprobe o kretprobe con éxito.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM El usuario no se ejecutó como root.

ENODEV Los eventos kprobe no están configurados para el kernel en ejecución.

ENOMEM Error de asignación de memoria.

tracefs_kprobe_raw(), tracefs_kretprobe_raw(), tracefs_kprobe_alloc() y tracefs_kretprobe_alloc() pueden fallar con los siguientes errores:

EBADMSG si addr es NULL.

EINVAL Lo más probable es que haya ocurrido un error de análisis sintáctico (use tracefs_error_last(3) para ver posiblemente cuál fue ese error).

Otros errores también pueden ocurrir causados por llamadas internas al sistema.

EJEMPLO

#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <tracefs.h>
static struct tep_event *open_event;
static struct tep_format_field *file_field;
static struct tep_event *openret_event;
static struct tep_format_field *ret_field;
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: ", TEP_PRINT_PID, TEP_PRINT_COMM);
        if (event->id == open_event->id) {
                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}
static pid_t run_exec(char **argv, char **env)
{
        pid_t pid;
        pid = fork();
        if (pid)
                return pid;
        execve(argv[0], argv, env);
        perror("exec");
        exit(-1);
}
const char *mykprobe = "my_kprobes";
enum kprobe_type {
        KPROBE,
        KRETPROBE,
};
static void __kprobe_create(enum kprobe_type type, const char *event,
                            const char *addr, const char *fmt)
{
        char *err;
        int r;
        if (type == KPROBE)
                r = tracefs_kprobe_raw(mykprobe, event, addr, fmt);
        else
                r = tracefs_kretprobe_raw(mykprobe, event, addr, fmt);
        if (r < 0) {
                err = tracefs_error_last(NULL);
                perror("Failed to create kprobe:");
                if (err && strlen(err))
                        fprintf(stderr, "%s\n", err);
        }
}
static void kprobe_create(const char *event, const char *addr,
                          const char *fmt)
{
        __kprobe_create(KPROBE, event, addr, fmt);
}
static void kretprobe_create(const char *event, const char *addr,
                             const char *fmt)
{
        __kprobe_create(KRETPROBE, event, addr, fmt);
}
int main (int argc, char **argv, char **env)
{
        struct tracefs_instance *instance;
        struct tep_handle *tep;
        const char *sysnames[] = { mykprobe, NULL };
        pid_t pid;
        if (argc < 2) {
                printf("usage: %s command\n", argv[0]);
                exit(-1);
        }
        instance = tracefs_instance_create("exec_open");
        if (!instance) {
                perror("creating instance");
                exit(-1);
        }
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);
        kprobe_create("open", "do_sys_openat2",
                      "file=+0($arg2):ustring flags=+0($arg3):x64 mode=+8($arg3):x64\n");
        kretprobe_create("openret", "do_sys_openat2", "ret=%ax");
        tep = tracefs_local_events_system(NULL, sysnames);
        if (!tep) {
                perror("reading events");
                exit(-1);
        }
        open_event = tep_find_event_by_name(tep, mykprobe, "open");
        file_field = tep_find_field(open_event, "file");
        openret_event = tep_find_event_by_name(tep, mykprobe, "openret");
        ret_field = tep_find_field(openret_event, "ret");
        tracefs_event_enable(instance, mykprobe, NULL);
        pid = run_exec(&argv[1], env);
        /* Let the child start to run */
        sched_yield();
        do {
                tracefs_load_cmdlines(NULL, tep);
                tracefs_iterate_raw_events(tep,
                                         callback,
                                         NULL,
                                         instance);
        } while (waitpid(pid, NULL, WNOHANG) == 0);
        return 0;
}

NOMBRE

tracefs_kretprobe_raw - Obtiene los datos de un evento de kretprobe como datos sin procesar.

SINOPSIS

#include <tracefs.h>
int tracefs_kretprobe_raw(struct tracefs_instance *instance,
                          const char *event, const char *format,
                          tracefs_event_callback callback, void *data);

DESCRIPCIÓN

La función tracefs_kretprobe_raw permite capturar los datos de un evento de kretprobe (retorno de sonda de kernel) como datos sin procesar. En lugar de que la biblioteca analice los datos del evento en tipos de datos específicos, se le proporcionan los datos del evento en su forma original, lo que permite un mayor control sobre el procesamiento.

El parámetro instance es un puntero a una estructura de instancia de tracefs válida, obtenida previamente a través de funciones como tracefs_instance_create.

El parámetro event especifica el nombre del evento de kretprobe que se desea capturar. Este nombre generalmente corresponde a la función del kernel para la que se configuró la kretprobe.

El parámetro format define el formato de los datos del evento. Para datos sin procesar, este campo puede contener una cadena que describa la estructura de los datos, o puede ser NULL si se confía en la información de formato predeterminada.

El parámetro callback es un puntero a una función de devolución de llamada que se invocará cada vez que se active el evento de kretprobe especificado. La función de devolución de llamada recibirá un puntero a la estructura de datos del evento sin procesar y cualquier dato adicional proporcionado en el parámetro data.

El parámetro data es un puntero a datos definidos por el usuario que se pasarán a la función de devolución de llamada cuando se invoque.

Una vez que se llama a tracefs_kretprobe_raw, la biblioteca comenzará a monitorear el evento especificado. Cuando ocurra el evento, se llamará a la función de devolución de llamada con los datos sin procesar del evento.

Para detener la captura de eventos y limpiar los recursos, es necesario llamar a funciones como tracefs_dynevent_destroy o tracefs_dynevent_destroy_all, y luego tracefs_instance_destroy.

VALOR DE RETORNO

En caso de éxito, la función devuelve 0. En caso de error, devuelve un valor negativo que indica el código de error.

ERRORES

Los posibles códigos de error incluyen:

EACCES
No se tienen los permisos necesarios para acceder a los archivos de traza.
EBADF
El descriptor de archivo de traza no es válido.
ENOENT
El evento especificado no se encontró o no es accesible.
ENOMEM
No hay suficiente memoria disponible.
ENOSPC
No queda espacio en el dispositivo de traza.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <tracefs.h>
#include <tracefs_dynevent.h>
#include <libgen.h>

// Función de devolución de llamada para procesar los datos sin procesar
static int my_callback(struct tracefs_event *event, void *data)
{
    pid_t pid = getpid();
    printf("[%d] Evento kretprobe activado (sin procesar): %s\n", pid, event->name);
    // Aquí puedes procesar los datos sin procesar del evento (event->raw_data)
    // y la longitud (event->raw_data_len) según sea necesario.
    // Por ejemplo, podrías imprimirlos como bytes hexadecimales.
    // Para este ejemplo simple, solo imprimimos el nombre del evento.
    return 0;
}

int main(int argc, char **argv)
{
    struct tracefs_instance *instance = NULL;
    struct tep_handle *tep = NULL;
    int ret;
    pid_t pid;

    // Verificar argumentos
    if (argc != 3) {
        fprintf(stderr, "Uso: %s <nombre_evento_kretprobe> <formato_evento>\n", basename(argv[0]));
        return 1;
    }
    const char *event_name = argv[1];
    const char *format = argv[2];

    // Inicializar el manejador de tracefs
    tep = tep_alloc();
    if (!tep) {
        fprintf(stderr, "Error al asignar tep_handle\n");
        return 1;
    }

    // Crear una instancia de traza
    instance = tracefs_instance_create(tep, NULL);
    if (!instance) {
        fprintf(stderr, "Error al crear la instancia de tracefs\n");
        tep_free(tep);
        return 1;
    }

    // Habilitar el evento de kretprobe
    ret = tracefs_dynevent_create(instance, TRACEFS_DYNEVENT_KRETPROBE, event_name, format, 0, NULL);
    if (ret < 0) {
        fprintf(stderr, "Error al crear el evento de kretprobe '%s': %d\n", event_name, ret);
        tracefs_instance_destroy(instance);
        tep_free(tep);
        return 1;
    }

    printf("Esperando evento kretprobe '%s'...\n", event_name);

    // Configurar el evento para ser capturado como datos sin procesar
    // En un escenario real, esto podría implicar un bucle para leer eventos.
    // Aquí usamos un fork para simular un proceso que podría generar el evento.
    pid = fork();
    if (pid == 0) {
        // Proceso hijo: solo esperamos un poco y salimos para simular el evento
        sleep(2);
        printf("[%d] Proceso hijo saliendo.\n", getpid());
        exit(0);
    } else if (pid < 0) {
        perror("fork");
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KRETPROBE | TRACEFS_DYNEVENT_KPROBE, true);
        tracefs_instance_destroy(instance);
        tep_free(tep);
        return 1;
    }

    // Proceso padre: llamamos a tracefs_kretprobe_raw
    // Nota: En una implementación real, la lectura de eventos ocurriría en un bucle
    // o de forma asíncrona. Aquí, para simplificar y asegurar que el evento se
    // capture si ocurre, confiamos en que tracefs_kretprobe_raw lo manejará internamente
    // para la llamada a callback en este ejemplo. Sin embargo, la forma más común
    // de usar esto sería dentro de un bucle de lectura de eventos.

    // Para este ejemplo, simulamos la captura llamando a la función directamente.
    // En una aplicación real, se leerían los eventos del buffer del kernel.
    // La siguiente línea es una simplificación y no representa la lectura real de eventos.
    // tracefs_read_events(instance, callback, NULL); // Esto iría en un bucle

    // Como estamos usando la función tracefs_kretprobe_raw para configurar el callback,
    // la biblioteca debería llamar a my_callback si el evento ocurre.
    // El ejemplo real de cómo se activaría y capturaría esto requeriría más
    // configuración y un bucle de lectura.

    // Configurar y esperar un evento específico.
    // La función tracefs_kretprobe_raw configura el evento para ser capturado por la devolución de llamada.
    // En la práctica, necesitarías un bucle que lea los eventos una vez que estén disponibles.
    // Este ejemplo está simplificado para mostrar cómo *configurar* la llamada.

    // Para hacer este ejemplo más funcional, necesitaríamos un bucle que lea los eventos.
    // Sin embargo, la firma de tracefs_kretprobe_raw solo CONFIGURA el evento.
    // La lectura y el procesamiento de los eventos se harían después.
    // Ejemplo simplificado para demostrar la configuración:
    printf("Configurando el callback para datos sin procesar del evento: %s\n", event_name);
    ret = tracefs_kretprobe_raw(instance, event_name, format, my_callback, NULL);
    if (ret < 0) {
        fprintf(stderr, "Error al configurar tracefs_kretprobe_raw: %d\n", ret);
        // Limpieza
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);
        tracefs_instance_destroy(instance);
        tep_free(tep);
        return 1;
    }

    // En una aplicación real, aquí habría un bucle para leer los eventos.
    // Ejemplo:
    // while (tracefs_read_event(instance, 0) >= 0) {
    //     // Los eventos se procesan a través del callback configurado.
    // }

    // Dado que este es un ejemplo de configuración y el proceso hijo simplemente duerme,
    // esperamos para ver si el callback se dispara (dependiendo de cómo se configure
    // internamente tracefs_kretprobe_raw y el mecanismo de lectura de eventos).
    // Para asegurar la limpieza, esperamos a que el proceso hijo termine.
    waitpid(pid, NULL, 0);

    printf("Evento capturado (si ocurrió). Limpiando...\n");

    // Deshabilitar todos los eventos y limpiar
    tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);
    tracefs_instance_destroy(instance);
    tep_free(tep);

    return 0;
}

El ejemplo anterior muestra cómo configurar un evento de kretprobe para que sus datos se capturen sin procesar. Se define una función de devolución de llamada my_callback que simplemente imprime el nombre del evento. El programa principal crea una instancia de tracefs, habilita un evento de kretprobe específico (pasado como argumento de línea de comandos) y luego usa tracefs_kretprobe_raw para registrar la función de devolución de llamada. Para fines de demostración, se crea un proceso hijo que sale después de un corto período. En una aplicación real, necesitaría un bucle para leer continuamente los eventos del sistema de trazas del kernel y la función de devolución de llamada se invocaría cuando ocurriera el evento.
