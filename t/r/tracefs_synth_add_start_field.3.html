DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir otros dos eventos que desencadenan un evento sintético. Un evento es el evento de inicio del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, entonces desencadenará el evento sintético. Los valores de campo distintos de los campos coincidentes pueden pasarse del evento de inicio al evento de fin para realizar cálculos, o simplemente como parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando un proceso se despierta. Luego, establezca "sched_switch" como el evento de fin. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice *TRACEFS_TIMESTAMP_USECS" como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_alloc() asigna e inicializa un evento sintético. No crea el evento sintético, sino que proporciona la información mínima para hacerlo. Consulte tracefs_synth_create(3) para ver cómo crear el evento sintético en el sistema. Requiere un manejador tep que puede ser creado por tracefs_local_events(3) para más información. El name contiene el nombre del evento sintético que se creará. El start_system es el nombre del sistema para el evento de inicio. Puede ser NULL y se elegirá el primer evento con el nombre start_event. El end_system es el nombre del sistema para el evento de fin. Puede ser NULL y se elegirá el primer evento con el nombre end_event como evento de fin. Si se proporciona match_name, entonces este será el campo del evento sintético creado que contendrá las claves coincidentes del start_match_field del evento de inicio y el end_match_field del evento de fin. Si match_name es NULL, entonces no se registrará en el evento sintético creado.

tracefs_synth_add_match_field() agregará una segunda clave para que coincida entre el evento de inicio y el evento de fin. Si se proporciona name, entonces el contenido del campo coincidente se guardará con este name en el evento sintético. El start_match_field es el campo del evento de inicio que debe coincidir con el end_match_field del evento de fin.

tracefs_synth_add_compare_field() se utiliza para comparar el start_compare_field del evento de inicio con el end_compare_field del evento de fin. Se debe proporcionar name para que el resultado se guarde en el evento sintético. No tiene sentido no pasar esto al evento sintético después de realizar el trabajo de los campos comparados, ya que no tiene ningún otro propósito. El parámetro calc puede ser uno de:

TRACEFS_SYNTH_DELTA_END - calcula la diferencia entre el contenido en el end_compare_field y el contenido del start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcula la diferencia entre el contenido en el start_compare_field y el contenido del end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Suma el contenido del start_compare_field al contenido del end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Registra el start_field del evento de inicio como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que start_field.

tracefs_synth_add_end_field() - Registra el end_field del evento de fin como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que end_field.

tracefs_synth_append_start_filter() crea un filtro o se une a él para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede agregar una comparación de field a val según compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Agrega "&&" al filtro TRACEFS_FILTER_OR - Agrega "||" al filtro TRACEFS_FILTER_NOT - Agrega "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Agrega "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Agrega ")" al filtro

field, compare y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces _compare se utilizará para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de flags.

tracefs_synth_append_end_filter() es lo mismo que tracefs_synth_append_start_filter pero filtra en el evento de fin.

tracefs_synth_free() libera el descriptor asignado devuelto por tracefs_synth_alloc().

DESCRIPTION

A synthetic event is a trace event that is created by combining two other events. The most common use case is to measure the latency between two events.

For example, we can measure the latency of a process waking up until it gets scheduled. This would involve combining the sched_waking event with the sched_switch event.

The combination is done by: 

end_event - start_event

The start and end events need to be related in some way, typically by having a common field, like the PID of the process.

The synthetic event needs a name to be registered with the kernel trace infrastructure. This name is given via the name parameter to tracefs_synth_alloc.

The tracefs_synth_alloc function allocates and initializes a synthetic event descriptor. It takes the trace event handle tep, the synthetic event name name, an optional match event name match_event (if not specified, then start_event is used), the start event name start_event, the end event name end_event, the field name from the start event to match start_field, the field name from the end event to match end_field, and the name of the field to match on match_name.

A synthetic event is not enabled by default. It needs to be created using tracefs_synth_create. Once created, it can be used like any other event by trace-cmd or perf. It can be destroyed using tracefs_synth_destroy.

The synthetic event creation can be controlled by filters. Filters can be appended to the start and end events using tracefs_synth_append_start_filter and tracefs_synth_append_end_filter respectively. Filters can be compared to constants or other fields.

Fields from the start and end events can be saved using tracefs_synth_add_start_field and tracefs_synth_add_end_field. These fields will be available in the output of the synthetic event.

The time difference between the end and start event can also be saved using tracefs_synth_add_compare_field. op_type can be TRACEFS_SYNTH_DELTA_END or TRACEFS_SYNTH_DELTA_START.

The tracefs_synth_complete function is used to finalize the synthetic event definition, resolving any pending filters or fields. This function must be called before creating or displaying the synthetic event.

The tracefs_synth_trace and tracefs_synth_snapshot functions enable the synthetic event for tracing and take a snapshot of the current trace buffer, respectively.

The tracefs_synth_save function saves the synthetic event definition to a file.

The tracefs_synth_echo_cmd and tracefs_synth_show_event functions print the command line needed to create the synthetic event or display the event details.

The tracefs_synth_get_start_hist and tracefs_synth_get_end_hist functions return the field definitions for the start and end events respectively.

The tracefs_synth_get_name function returns the name of the synthetic event.

The tracefs_synth_get_event function returns the underlying tracefs_event structure for the synthetic event.

The tracefs_synth_raw_fmt function prints the raw format string for the synthetic event.

The tracefs_synth_show_start_hist and tracefs_synth_show_end_hist functions print the field definitions for the start and end events respectively.

The tracefs_synth_free function frees the memory allocated for the synthetic event descriptor.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
