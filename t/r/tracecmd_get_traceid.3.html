tracecmd_get_traceid(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_get_traceid, tracecmd_get_guest_cpumap - Gestiona sesiones de traza con múltiples pares de traza, registrados en múltiples archivos de traza.

SINOPSIS

#include <trace-cmd.h>
unsigned long long tracecmd_get_traceid(struct tracecmd_input *handle);
int tracecmd_get_guest_cpumap(struct tracecmd_input *handle, unsigned long long trace_id, const char **name, int *vcpu_count, const int **cpu_pid);

DESCRIPCIÓN

Este conjunto de API puede usarse para gestionar una sesión de traza con múltiples pares de traza, por ejemplo, trazando tanto un host como una o más máquinas virtuales invitadas. Los datos de traza de cada par de la sesión se registran en archivos de traza separados. La información sobre los pares de la sesión se almacena en los metadatos de cada archivo de traza. Estas API utilizan esa información para extraer y sincronizar los datos de traza.

La función tracecmd_get_traceid() devuelve el ID de traza almacenado en los metadatos del archivo de traza asociado con handle. Cada par de una sesión de traza tiene un ID único para ese par y solo para esa sesión de traza. Este ID se usa para emparejar múltiples archivos de traza registrados en la misma sesión de traza.

La función tracecmd_get_guest_cpumap() obtiene el mapeo de las CPU virtuales invitadas (VCPU) al proceso host que representa esas VCPU y que se almacena en los metadatos del archivo de traza asociado con handle. Esta información se recopila durante una sesión de traza host-invitado y se almacena en el archivo de traza del host. El parámetro trace_id es el ID de traza del invitado en esta sesión de traza en particular. Si un invitado con ese ID fue parte de esa sesión, su mapeo de VCPU a proceso host está en el archivo de traza del host y la información se devuelve en los parámetros name, vcpu_count y cpu_pid. El parámetro name contiene el nombre del invitado, vcpu_count contiene el número de VCPU de ese invitado y el array cpu_pid contiene el mapeo de VCPU a proceso host. El array es de tamaño vcpu_count donde el índice es la VCPU y el valor es el ID de proceso (PID) del proceso host que ejecuta esa VCPU. Los valores de name, vcpu_count y cpu_pid no deben liberarse.

VALOR DE RETORNO

La función tracecmd_get_traceid() devuelve un ID de traza de 64 bits.

La función tracecmd_get_guest_cpumap() devuelve -1 en caso de error o 0 en caso contrario. Si se devuelve 0, los parámetros name, vcpu_count y cpu_pid contienen la información solicitada.

EJEMPLO

#include <trace-cmd.h>
...
struct tracecmd_input *host = tracecmd_open("trace.dat");
        if (!host) {
                /* Falló la apertura del archivo de traza del host */
        }
struct tracecmd_input *guest1 = tracecmd_open_head("trace-Guest1.dat");
        if (!guest1) {
                /* Falló la apertura del archivo de traza del invitado1 */
        }
struct tracecmd_input *guest2 = tracecmd_open_head("trace-Guest2.dat");
        if (!guest2) {
                /* Falló la apertura del archivo de traza del invitado2 */
        }
unsigned long long guest_id_1 = tracecmd_get_traceid(guest1);
unsigned long long guest_id_2 = tracecmd_get_traceid(guest2);
int *cpu_pid_1, *cpu_pid_2;
int vcount_1, vcount_2;
char *name_1, *name_2;
        if (!tracecmd_get_guest_cpumap(host, guest_id_1, &name_1, &vcount_1, &cpu_pid_1)) {
                /* El Host y un invitado1 con name_1 forman parte de la misma sesión de traza.
                 * Se obtuvo el mapeo de VCPU a PID del host del invitado1.
                 */
        }
        if (!tracecmd_get_guest_cpumap(host, guest_id_2, &name_2, &vcount_2, &cpu_pid_2)) {
                /* El Host y un invitado2 con name_2 forman parte de la misma sesión de traza.
                 * Se obtuvo el mapeo de VCPU a PID del host del invitado2.
                 */
        }
...
        tracecmd_close(guest1);
        tracecmd_close(guest2);
        tracecmd_close(handle);
