CTRRFS

Propósito:

!>
!> CTRRFS proporciona límites de error y estimaciones de error hacia atrás para la
!> solución de un sistema de ecuaciones lineales con una matriz
!> coeficiente triangular.
!>
!> La matriz solución X debe ser calculada por CTRTRS o algún otro
!> medio antes de entrar en esta rutina. CTRRFS no realiza refinamiento
!> iterativo porque hacerlo no puede mejorar el error hacia atrás.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U': A es triangular superior;
!>          = 'L': A es triangular inferior.
!>

TRANS

!>          TRANS es CHARACTER*1
!>          Especifica la forma del sistema de ecuaciones:
!>          = 'N': A * X = B     (Sin transposición)
!>          = 'T': A**T * X = B  (Transpuesta)
!>          = 'C': A**H * X = B  (Transpuesta conjugada)
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N': A es triangular no unitaria;
!>          = 'U': A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A. N >= 0.
!>

NRHS

!>          NRHS es INTEGER
!>          El número de lados derechos, es decir, el número de columnas
!>          de las matrices B y X. NRHS >= 0.
!>

A

!>          A es un array COMPLEX de dimensión (LDA,N)
!>          La matriz triangular A. Si UPLO = 'U', la parte superior triangular
!>          de tamaño N x N de la matriz A contiene la matriz triangular
!>          superior, y la parte estrictamente triangular inferior de A no se
!>          referencia. Si UPLO = 'L', la parte inferior triangular de tamaño
!>          N x N de la matriz A contiene la matriz triangular inferior, y la
!>          parte estrictamente triangular superior de A no se referencia.
!>          Si DIAG = 'U', los elementos diagonales de A tampoco se
!>          referencian y se asumen como 1.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,N).
!>

B

!>          B es un array COMPLEX de dimensión (LDB,NRHS)
!>          La matriz del lado derecho B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

X

!>          X es un array COMPLEX de dimensión (LDX,NRHS)
!>          La matriz solución X.
!>

LDX

!>          LDX es INTEGER
!>          La dimensión principal del array X. LDX >= max(1,N).
!>

FERR

!>          FERR es un array REAL de dimensión (NRHS)
!>          El límite de error hacia adelante estimado para cada vector solución
!>          X(j) (la j-ésima columna de la matriz solución X).
!>          Si XTRUE es la solución verdadera correspondiente a X(j), FERR(j)
!>          es un límite superior estimado para la magnitud del elemento más
!>          grande en (X(j) - XTRUE) dividido por la magnitud del elemento más
!>          grande en X(j). La estimación es tan confiable como la estimación
!>          para RCOND, y es casi siempre una ligera sobreestimación del error real.
!>

BERR

!>          BERR es un array REAL de dimensión (NRHS)
!>          El error hacia atrás relativo componente a componente de cada vector solución
!>          X(j) (es decir, el cambio relativo más pequeño en
!>          cualquier elemento de A o B que haga que X(j) sea una solución exacta).
!>

WORK

!>          WORK es un array COMPLEX de dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

CTRFFS


Purpose:




!>
!> CTRRFS provides error bounds and backward error estimates for the
!> solution to a system of linear equations with a triangular
!> coefficient matrix.
!>
!> The solution matrix X must be computed by CTRTRS or some other
!> means before entering this routine.  CTRRFS does not do iterative
!> refinement because doing so cannot improve the backward error.
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N':  A * X = B     (No transpose)
!>          = 'T':  A**T * X = B  (Transpose)
!>          = 'C':  A**H * X = B  (Conjugate transpose)
!> 


DIAG


!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


NRHS


!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA,N)
!>          The triangular matrix A.  If UPLO = 'U', the leading N-by-N
!>          upper triangular part of the array A contains the upper
!>          triangular matrix, and the strictly lower triangular part of
!>          A is not referenced.  If UPLO = 'L', the leading N-by-N lower
!>          triangular part of the array A contains the lower triangular
!>          matrix, and the strictly upper triangular part of A is not
!>          referenced.  If DIAG = 'U', the diagonal elements of A are
!>          also not referenced and are assumed to be 1.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


B


!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          The right hand side matrix B.
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!> 


X


!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          The solution matrix X.
!> 


LDX


!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!> 


FERR


!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!> 


BERR


!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!> 


WORK


!>          WORK is COMPLEX array, dimension (3*N)
!> 


RWORK


!>          RWORK is REAL array, dimension (N)
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

NAME


trrfs - trrfs






SYNOPSIS


SUBROUTINE ZTRRFS(
  UPLO, N, NRHS, A, LDA, B, LDB, X, LDX, FERR, BERR, WORK, RWORK, INFO
)
  CHARACTER UPLO
  INTEGER N, NRHS, LDA, LDB, LDX, INFO
  COMPLEX*16 A( LDA, * ), B( LDB, * ), X( LDX, * )
  DOUBLE PRECISION FERR( * ), BERR( * )
  COMPLEX*16 WORK( * )
  DOUBLE PRECISION RWORK( * )







Detailed Description


This routine is an example of how to use the output of the
    direct solvers (LU, QR, Cholesky) to estimate the error bounds for the
    solution of a system of linear equations.


The routine computes the forward error, backward error and
    condition number estimates for the solution X of the system of linear
    equations A*X = B. A is a triangular matrix.


This routine is not called directly by the user. It is called
    by the high-level interface routines like ZTTRS, ZTSRFS, ZTTRS.


The solution X is computed by the direct solvers.




UPLO


CHARACTER


Specifies whether the matrix A is upper or lower triangular.




='U': Upper triangular


='L': Lower triangular


N


INTEGER


The order of the matrix A. N >= 0.


NRHS


INTEGER


The number of right hand sides, i.e., the number of columns of the
        matrices B, X, FERR, and BERR. NRHS >= 0.


A


COMPLEX*16 array, dimension (LDA, N)


The triangular matrix A. The other parts of the array are not
        referenced if UPLO = 'U' or UPLO = 'L'. If UPLO = 'U', the upper
        triangular part of the array A contains the upper triangular
        matrix, and the strictly lower triangular part of A is not
        referenced. If UPLO = 'L', the leading N-by-N lower triangular
        part of the array A contains the lower triangular matrix, and
        the strictly upper triangular part of A is not referenced. If
        DIAG = 'U', the diagonal elements of A are also not referenced
        and are assumed to be 1.


LDA


INTEGER


The leading dimension of the array A. LDA >= max(1,N).


B


COMPLEX*16 array, dimension (LDB, NRHS)


The right hand side matrix B.


LDB


INTEGER


The leading dimension of the array B. LDB >= max(1,N).


X


COMPLEX*16 array, dimension (LDX, NRHS)


The solution matrix X.


LDX


INTEGER


The leading dimension of the array X. LDX >= max(1,N).


FERR


DOUBLE PRECISION array, dimension (NRHS)


The estimated forward error bound for each solution vector X(j)
        (the j-th column of the solution matrix X). If XTRUE is the
        true solution corresponding to X(j), FERR(j) is an estimated
        upper bound for the magnitude of the largest element in
        (X(j) - XTRUE) divided by the magnitude of the largest element
        in X(j). The estimate is as reliable as the estimate for RCOND,
        and is almost always a slight overestimate of the true error.


BERR


DOUBLE PRECISION array, dimension (NRHS)


The componentwise relative backward error of each solution
        vector X(j) (i.e., the smallest relative change in any element
        of A or B that makes X(j) an exact solution).


WORK


COMPLEX*16 array, dimension (2*N)


RWORK


DOUBLE PRECISION array, dimension (N)


INFO


INTEGER


 = 0: successful exit


 < 0: if INFO = -i, the i-th argument had an illegal value
