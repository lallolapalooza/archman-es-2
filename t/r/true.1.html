TRUE(1) Comandos de usuario TRUE(1)

NOMBRE

true - no hacer nada, exitosamente

SINOPSIS

true [argumentos de línea ignorados]
true OPCIÓN

DESCRIPCIÓN

Salir con un código de estado que indica éxito.

--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir

Tu shell puede tener su propia versión de true, que usualmente reemplaza a la versión descrita aquí. Por favor, consulta la documentación de tu shell para detalles sobre las opciones que soporta.
