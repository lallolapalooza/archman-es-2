NOMBRE

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Creación de eventos sintéticos

SINOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos, lo que desencadena un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, se desencadenará el evento sintético. Los valores de los campos, aparte de los campos coincidentes, pueden pasarse del evento de inicio al evento final para realizar cálculos, o simplemente como un parámetro para el evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, establecer "sched_switch" como el evento final. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice TRACEFS_TIMESTAMP_USECS como campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_create() crea el evento sintético en el sistema. Por defecto, los disparadores de histograma se crean en la instancia de traza superior, ya que cualquier evento sintético puede utilizarse globalmente en todas las instancias. En caso de que una aplicación quiera mantener los disparadores de histograma fuera de la instancia de nivel superior, puede utilizar tracefs_synth_set_instance() para que los histogramas se utilicen para crear el evento sintético en una instancia distinta de la superior. Se debe crear un descriptor de evento sintético con tracefs_synth_alloc(3) antes de poder utilizarlo para crearlo en el sistema.

tracefs_synth_destroy() destruye el evento sintético. Intentará detener su ejecución en su instancia (la superior por defecto), pero si se está ejecutando en otra instancia, esto puede fallar por estar ocupado.

tracefs_synth_complete() devuelve verdadero si el evento sintético synth tiene un evento de inicio y uno de fin.

tracefs_synth_trace() En lugar de hacer solo una traza al coincidir los eventos de inicio y fin, realiza el manejador type donde TRACEFS_SYNTH_HANDLE_MAX realizará una traza cuando la variable dada var alcance un nuevo máximo para las claves coincidentes. O TRACEFS_SYNTH_HANDLE_CHANGE cuando la var cambie. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si TRACEFS_SYNTH_HANDLE_CHANGE, se toma una "instantánea" del búfer. La instantánea mueve el búfer de "traza" normal a un búfer de "instantánea", al que se puede acceder a través del archivo "snapshot" en el directorio tracefs de nivel superior, o en una de las instancias. Cambia var. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_save() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si TRACEFS_SYNTH_HANDLE_CHANGE, se guarda la lista dada de save_fields. Los campos se almacenarán en el archivo "hist" del histograma del evento, que puede recuperarse con tracefs_event_file_read(3). var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Establece la instancia de traza, donde se crearán los disparadores de histograma que crean el evento sintético. Por defecto, se utiliza la instancia superior. Esta API debe llamarse antes de la llamada a tracefs_synth_create(), para poder utilizar la nueva instancia al crear el evento. Tenga en cuenta que, aunque el evento sintético se cree en una instancia, sigue siendo visible para todas las demás instancias, incluida la de nivel superior. Es decir, otras instancias pueden habilitar el evento sintético creado y que se trace en los búferes que pertenecen a la instancia que lo habilitó.

VALOR DE RETORNO

Todas las funciones devuelven cero si tienen éxito o -1 si hay un error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecuta como usuario root cuando es necesario.

EINVAL Un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encuentra un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para coincidencia o comparación.

ENOMEM No hay suficiente memoria disponible.

Y pueden ocurrir más errores de las llamadas al sistema al sistema.

EJEMPLO

Consulte tracefs_sql(3) para un uso más detallado de parte de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento final */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento final */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar la diferencia de tiempo en microsegundos entre el final y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Registrar solo si el "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Registrar solo si el "next_prio" del evento final es menor que 50
         * o la prioridad de la tarea anterior no era mayor o igual que 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);

DESCRIPTION

The libtracefs library provides functions to create, manage, and interact with synthetic trace events. Synthetic events are custom events that can be defined and injected into the Linux kernel's tracing infrastructure.

The functions can be categorized as follows:

Event Creation and Management:

tracefs_synth_alloc()
Allocates and initializes a structure for defining a synthetic event.
tracefs_synth_create()
Creates a synthetic event in the kernel's tracefs filesystem. This function is typically called after defining the event's properties using other `tracefs_synth_*` functions.
tracefs_synth_delete()
Deletes a synthetic event from the tracefs filesystem.
tracefs_synth_destroy()
Destroys a synthetic event definition. This does not remove the event from tracefs, but frees the memory associated with the definition.
tracefs_synth_free()
Frees all memory associated with a synthetic event structure.

Event Definition and Filtering:

tracefs_synth_append_start_filter()
Appends a filter condition to the start event of a synthetic trace event. This function is used to specify criteria that must be met for the start event to be recorded.
tracefs_synth_append_end_filter()
Appends a filter condition to the end event of a synthetic trace event. Similar to `tracefs_synth_append_start_filter`, but for the end event.
tracefs_synth_add_match_field()
Adds a field to be matched in the synthetic event. This is often used in conjunction with filters.
tracefs_synth_add_compare_field()
Adds a field for comparison in the synthetic event. This is used with comparison operators in filters.
tracefs_synth_add_start_field()
Adds a field that will be associated with the start of the synthetic event.
tracefs_synth_add_end_field()
Adds a field that will be associated with the end of the synthetic event.
tracefs_synth_raw_fmt()
Allows specifying a raw format string for the synthetic event, giving fine-grained control over its output.

Event Information and Display:

tracefs_synth_echo_cmd()
Writes the command string to create the synthetic event to a given trace_seq structure. This is useful for debugging or generating scripts.
tracefs_synth_show_event()
Prints the definition of the synthetic event to standard output.
tracefs_synth_get_event()
Returns the name of the synthetic event.
tracefs_synth_get_name()
Returns the name of the synthetic event.
tracefs_synth_get_start_hist()
Retrieves the histogram structure associated with the start event.
tracefs_synth_get_end_hist()
Retrieves the histogram structure associated with the end event.
tracefs_synth_show_start_hist()
Prints the definition of the histogram for the start event.
tracefs_synth_show_end_hist()
Prints the definition of the histogram for the end event.

RETURN VALUE

Most functions return 0 on success or a negative value on error. Specific return values are detailed in the individual man pages.

ERRORS

Errors can occur due to invalid arguments, issues interacting with the tracefs filesystem, or memory allocation failures.

EXAMPLE

The following example demonstrates how to create a synthetic event that triggers when the `prev_prio` is greater than or equal to 100 and the `next_prio` is less than 50.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <tracefs.h>

struct tracefs_synth *synth;

/* Create the synthetic event */
static void make_event(void)
{
        synth = tracefs_synth_alloc();
        if (!synth) {
                fprintf(stderr, "Failed to allocate synth\n");
                exit(-1);
        }

        /*
         * Define the event name. This will be the name of the trace event
         * that appears in the kernel's trace buffer.
         */
        if (tracefs_synth_set_name(synth, "my_custom_event") < 0) {
                fprintf(stderr, "Failed to set event name\n");
                tracefs_synth_free(synth);
                exit(-1);
        }

        /*
         * Add fields that will be available for filtering and matching.
         * These fields correspond to values that can be read from the
         * trace event when it occurs.
         */
        tracefs_synth_add_match_field(synth, "next_prio");
        tracefs_synth_add_match_field(synth, "prev_prio");

        /*
         * Define filters for the start and end of the event.
         * This example creates a filter that checks conditions on
         * 'next_prio' and 'prev_prio'.
         */

        /* Filter for the start of the event */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);

        /* Filter for the end of the event */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
