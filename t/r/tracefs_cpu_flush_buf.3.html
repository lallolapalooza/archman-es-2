tracefs_cpu_flush_buf(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_cpu_read_buf, tracefs_cpu_buffered_read_buf, tracefs_cpu_flush_buf - Leer datos de trace_pipe_raw devolviendo un kbuffer

SINOPSIS

#include <tracefs.h>
struct kbuffer *tracefs_cpu_read_buf(struct tracefs_cpu *tcpu, bool nonblock);
struct kbuffer *tracefs_cpu_buffered_read_buf(struct tracefs_cpu *tcpu, bool nonblock);
struct kbuffer *tracefs_cpu_flush_buf(struct tracefs_cpu *tcpu);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para leer los datos crudos de los archivos trace_pipe_raw en el sistema de archivos tracefs y devolver una estructura kbuffer para leerlos.

tracefs_cpu_read_buf() lee los archivos trace_pipe_raw asociados a tcpu y devuelve una estructura kbuffer que se puede usar para iterar sobre los eventos. Si nonblock está activado y no hay datos disponibles, devolverá inmediatamente. De lo contrario, dependiendo de cómo se abrió tcpu, se bloqueará. Si tcpu se abrió con nonblock activado, entonces este nonblock no tendrá ninguna diferencia.

tracefs_cpu_buffered_read_buf() es básicamente lo mismo que tracefs_cpu_read_buf() excepto que utiliza una tubería a través de splice para almacenar en búfer las lecturas. Esto agrupará las lecturas, haciendo que la lectura del búfer de anillo sea menos intrusiva para el sistema, ya que solo leer todo el tiempo puede causar bastante perturbación. Tenga en cuenta que una diferencia entre esto y tracefs_cpu_read() es que solo leerá en páginas de sub-búfer. Si el búfer de anillo no ha llenado una página, no devolverá nada, incluso con nonblock activado. Se deben realizar llamadas a tracefs_cpu_flush_buf() o tracefs_cpu_flush() para leer el resto del archivo al final del rastreo.

tracefs_cpu_flush_buf() lee el archivo trace_pipe_raw asociado por el tcpu y lo coloca en buffer, que debe tener el tamaño del sub-búfer que se recupera. Esto debe llamarse al final del rastreo para obtener el resto de los datos. Esta llamada convertirá el descriptor de archivo de trace_pipe_raw a modo no bloqueante.

VALOR DE RETORNO

Las funciones tracefs_cpu_read_buf(), tracefs_cpu_buffered_read_buf() y tracefs_cpu_flush() devuelven un descriptor de kbuffer que se puede iterar para encontrar los eventos. Tenga en cuenta que este descriptor es parte de la estructura tracefs_cpu y no debe liberarse. Se liberará. Devuelve NULL en caso de error o si nonblock está activado y no hay eventos disponibles. En el caso de que no haya eventos, errno se establecerá con EAGAIN.

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_page(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %9d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        while ((kbuf = tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_page(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_page(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}
