Paquete: libtracefs

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_tracers, tracefs_tracer_available, tracefs_get_clock, tracefs_list_free, tracefs_list_add, tracefs_list_size - Funciones auxiliares para trabajar con el sistema de archivos tracefs.

SINOPSIS

#include <tracefs.h>
char **tracefs_tracers(const char *tracing_dir);
bool tracefs_tracer_available(const char *tracing_dir, const char *tracer);
char *tracefs_get_clock(struct tracefs_instance *instance);
void tracefs_list_free(char **list);
char **tracefs_list_add(char **list, const char *string);
int *tracefs_list_size(char **list);

DESCRIPCIÓN

Varias funciones útiles para trabajar con el sistema de archivos tracefs.

La función tracefs_tracers() devuelve una matriz de cadenas con los nombres de los plugins de trazado compatibles, ubicados en el directorio tracing_dir dado. Este podría ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de trazado de la máquina local, o puede ser una ruta a una copia del directorio tracefs de otra máquina. La última entrada en la matriz es un puntero NULL. La matriz debe liberarse con la API tracefs_list_free().

La función tracefs_tracer_available() devuelve true si el tracer está disponible en el directorio tracing_dir dado, y false en caso contrario.

La función tracefs_get_clock() devuelve el nombre del reloj de trazado actual, utilizado en la instance dada. Si instance es NULL, se devuelve el reloj de la instancia de trazado principal. La cadena devuelta debe liberarse con free().

La función tracefs_list_free() libera una matriz de cadenas, devuelta por las APIs tracefs_event_systems(), tracefs_system_events() y tracefs_tracers().

La función tracefs_list_add() agrega string a la matriz de cadenas list. Si list es NULL, se crea una nueva matriz con el primer elemento como una copia de string, y el segundo elemento será un puntero NULL. Si list no es NULL, se realoca para incluir un nuevo elemento y un terminador NULL, y se devuelve la nueva matriz asignada. Se debe ignorar la matriz pasada, ya que se liberará si se asignó una nueva.

tracefs_list_size() es una forma rápida de conocer el número de elementos en una matriz de cadenas que se liberará con tracefs_list_free(). Tenga en cuenta que esto depende de metadatos que se crean para estas matrices y no funcionará en matrices de cadenas normales como argv.

VALOR DE RETORNO

La función tracefs_tracers() devuelve una matriz de cadenas. El último elemento de esa matriz es un puntero NULL. La matriz debe liberarse con la API tracefs_list_free(). En caso de error, se devuelve NULL.

La función tracefs_tracer_available() devuelve true si el tracer está disponible, y false en caso contrario.

La función tracefs_get_clock() devuelve una cadena, que debe liberarse con free(), o NULL en caso de error.

La función tracefs_list_add() devuelve una matriz de cadenas asignada que debe liberarse con tracefs_list_free() en caso de éxito o NULL en caso de error. Si se devuelve NULL, la lista pasada no se modifica. Por lo tanto, tracefs_list_add() debe tratarse de forma similar a realloc(3).

La función tracefs_list_size() devuelve el número de cadenas en la list. La lista pasada debe ser una que se liberará con tracefs_list_free(), ya que la lista tiene metadatos que se utilizan para determinar el tamaño y esto no funciona en ninguna matriz de cadenas normal como argv.

EJEMPLO

#include <tracefs.h>
char **tracers = tracefs_tracers(NULL);
        if (tracers) {
                /* Se obtuvieron los plugins de trazado de la instancia de trazado principal */
                ...
                tracefs_list_free(tracers);
        }
....
char *clock = tracefs_get_clock(NULL);
        if (clock) {
                /* Se obtuvo el reloj de trazado actual de la instancia de trazado principal */
                ...
                free(clock);
        }
