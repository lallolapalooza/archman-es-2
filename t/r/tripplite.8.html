NOMBRE

tripplite - Driver para equipos Tripp-Lite SmartPro UPS

SINOPSIS

tripplite -h

tripplite -a NOMBRE_UPS [OPCIONES]


Nota

Esta página del manual solo documenta las características específicas del hardware del driver tripplite. Para información sobre el driver principal, consulte nutupsdrv(8).

HARDWARE SOPORTADO

Este driver debería funcionar en la línea SmartPro, incluyendo SMART700 y SMART700SER. Solo soporta modelos SmartPro que se comunican a través del puerto serial.

ARGUMENTOS ADICIONALES

Este driver soporta las siguientes configuraciones opcionales en el archivo ups.conf(5):

offdelay=num

Tiempo a esperar antes de que la UPS se apague después de enviar el comando de corte de energía. El valor por defecto es 64 (en segundos).

rebootdelay=num

Configura el temporizador antes de que la UPS se reinicie después de enviar el comando de reinicio. El valor por defecto es 64 (en segundos).

startdelay=num

Configura el tiempo que la UPS espera antes de volver a encenderse después de un comando de reinicio. El valor por defecto es 60 (en segundos).

PROBLEMAS CONOCIDOS Y ERRORES

La información de carga de la batería puede no ser correcta para todas las UPS. Está ajustada para ser correcta para un SMART700SER. Otros modelos pueden no proporcionar información correcta. Sería útil tener información del fabricante.
