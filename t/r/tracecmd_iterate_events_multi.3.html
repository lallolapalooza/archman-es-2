NOMBRE

tracecmd_iterate_events, tracecmd_iterate_events_multi, tracecmd_follow_event, tracecmd_follow_missed_events, tracecmd_filter_add, tracecmd_iterate_reset - Leer eventos de un archivo de traza

SINOPSIS

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                  int nr_handles,
                                  int (*callback)(struct tracecmd_input *,
                                                           struct tep_record *,
                                                           int, void *),
                                  void *callback_data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data, bool cont);
int tracecmd_follow_event(struct tracecmd_input *handle,
                          const char *system, const char *event_name,
                          int (*callback)(struct tracecmd_input *,
                                          struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracecmd_follow_missed_events(struct tracecmd_input *handle,
                                   int (*callback)(struct tracecmd_input *,
                                                   struct tep_event *,
                                                   struct tep_record *,
                                                   int, void *),
                                   void *callback_data);
struct tracecmd_filter *tracecmd_filter_add(struct tracecmd_input handle,
                                            const char *filter_str, bool neg);
int *tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para iterar sobre eventos después de abrir un archivo de traza usando una de las funciones de apertura como tracecmd_open(3) o tracecmd_open_fd(3).

La función tracecmd_iterate_events() iterará a través de todos los eventos en el archivo de traza definido por handle, donde handle es devuelto por una de las funciones de tracecmd_open(3). Llamará a la función callback() en los eventos de las CPU definidas por cpus. El cpu_size debe ser el tamaño de cpus (ver CPU_SET(3)). Si cpus es NULL, entonces cpu_size se ignora y callback() será llamado para todos los eventos en todas las CPU del archivo de traza. El callback_data se pasa a callback() como su último parámetro. callback puede ser NULL, lo cual es útil si se usa tracecmd_follow_event(), pero ten en cuenta que si callback es NULL, entonces callback_data se ignora y no se envía al callback de tracecmd_follow_event().

La función tracecmd_iterate_events_multi() es similar a tracecmd_iterate_events(), excepto que permite iterar sobre más de un archivo de traza. Si se usa tracecmd agent(1) para obtener una traza tanto del host como del invitado, asegúrate de que el archivo de traza del host sea la primera entrada en handles y tracecmd_iterate_events_multi() se encargará de la sincronización de los metadatos para los archivos de invitado que vengan después en handles. handles es una matriz de descriptores de archivos de traza que fueron abiertos por tracecmd_open(3) y similares. Nota, a diferencia de tracecmd_iterate_events(), tracecmd_iterate_events_multi() no filtra por CPU, ya que haría que la API fuera demasiado compleja al saber en qué handle filtrar las CPU. Si se desea filtrar por CPU, entonces el callback debe verificar record→cpu y devolver 0 si no es la CPU deseada para procesar. nr_handles denota el número de elementos en handles. El callback_data se pasa al callback como su último parámetro. callback puede ser NULL, lo cual es útil si se usa tracecmd_follow_event(), pero ten en cuenta que si callback es NULL, entonces callback_data se ignora y no se envía al callback de tracecmd_follow_event().

La función tracecmd_iterate_events_reverse() funciona de manera muy similar a como funciona tracecmd_iterate_events(), pero en lugar de llamar a la función callback() para cada evento en orden cronológico, llamará a la función callback() para cada evento en orden inverso de la marca de tiempo. Si cont es falso, comenzará llamando al evento con la marca de tiempo más antigua en el archivo trace.dat. Si cont se establece en verdadero, continuará desde donde está la posición actual de los datos de traza. Por ejemplo, si el callback() devuelve algo diferente de cero, saldrá de la iteración. Si se vuelve a llamar a tracecmd_iterate_events_reverse() con cont en verdadero, continuará donde lo dejó. Si cont es falso, comenzará de nuevo en el evento con la marca de tiempo más antigua. El handle, cpus, cpu_size y callback_data actúan igual que en tracecmd_iterate_events().

El callback() para tracecmd_iterate_events(), tracecmd_iterate_events_reverse() y tracecmd_iterate_events_multi() es del prototipo:

int callback()(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data);

El handle es el mismo handle pasado a tracecmd_iterate_events() o el handle actual de handles pasado a tracecmd_iterate_events_multi() al que pertenece el record. El record es el registro de evento actual. El cpu es la CPU actual que se está procesando. Nota, para tracecmd_iterate_events_multi() puede que no sea la CPU real del archivo, sino la n-ésima CPU de todos los handles juntos. Usa record→cpu para obtener la CPU real en la que se encuentra el evento.

La función tracecmd_follow_event() se adjuntará a un descriptor de archivo de traza handle y llamará al callback cuando el evento descrito por system y name coincida con un evento en la iteración de tracecmd_iterate_events() o tracecmd_iterate_events_multi(). Nota, el cpu es la n-ésima CPU tanto para tracecmd_iterate_events() como para tracecmd_iterate_events_multi(). Si se necesita la CPU real de record, usa record→cpu. Para tracecmd_iterate_events_multi(), el callback solo se llama si el handle coincide con el descriptor de archivo de traza actual dentro de handles. El callback_data se pasa como último parámetro a la función callback(). Nota, este callback() se llamará antes que la función callback() de tracecmd_iterate_events() o tracecmd_iterate_events_multi().

El prototipo del callback() para *tracecmd_follow_event()* es:

int callback()(struct tracecmd_input *handle, struct tep_event *event, struct tep_record *_record, int cpu, void *data);

La función tracecmd_follow_missed_events() se adjuntará a un descriptor de archivo de traza handle y llamará al callback cuando se detecten eventos perdidos. El event contendrá el tipo de evento que es el record. El record contendrá la información de los eventos perdidos. El cpu es la n-ésima CPU tanto para tracecmd_iterate_events() como para tracecmd_iterate_events_multi(). Si se necesita la CPU para la que son los eventos perdidos, usa record→cpu. Si record→missed_events es un número positivo, entonces contiene el número de eventos perdidos desde el último evento en su CPU, de lo contrario será negativo, y eso significará que el número de eventos perdidos es desconocido pero existen eventos perdidos desde el último evento en la CPU. El callback y callback_data tienen el mismo formato que tracecmd_follow_event() arriba. Los eventos perdidos

NAME

tracecmd_iterate_events, tracecmd_iterate_events_reverse, tracecmd_iterate_events_multi, tracecmd_filter_add, tracecmd_iterate_reset - iterate and filter trace events

SYNOPSIS

#include <trace-cmd.h>

int
tracecmd_iterate_events(struct tracecmd_input *handle, cpu_set_t *cpuset,
                          size_t cpusetsize,
                          int (*callback)(struct tracecmd_input *handle,
                                          struct tep_record *record, int cpu,
                                          void *data),
                          void *data);

int
tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                                  cpu_set_t *cpuset, size_t cpusetsize,
                                  int (*callback)(struct tracecmd_input *handle,
                                                  struct tep_record *record, int cpu,
                                                  void *data),
                                  void *data);

int
tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                int nr_handles,
                                int (*callback)(struct tracecmd_input *handle,
                                                struct tep_event *event,
                                                struct tep_record *record, int cpu,
                                                void *data),
                                void *data);

int
tracecmd_filter_add(struct tracecmd_input *handle,
                      const char *filter_str, bool neg);

int
tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPTION

The tracecmd_iterate_events() function, iterates through the trace buffer provided by handle. If cpuset and cpusetsize are provided, it will only iterate through the CPUs specified in the cpuset. Otherwise, it iterates through all available CPUs in the trace buffer.

The callback function is called for each event found during the iteration. The callback function takes the handle, a pointer to the current record (struct tep_record *record), the CPU number that the record was recorded on, and the private data pointer (data) passed to tracecmd_iterate_events().

If callback returns a non-zero value, the iteration stops and that value is returned to the caller.

The tracecmd_iterate_events_reverse() function, iterates through the trace buffer in reverse order. The rest of the functionality is the same as tracecmd_iterate_events().

The tracecmd_iterate_events_multi() function, iterates through multiple trace buffers provided by the array of handles handles. The nr_handles parameter specifies the number of handles in the array. The callback function for this iterator is slightly different, it takes an additional argument: struct tep_event *event, which contains information about the event type.

The tracecmd_iterate_reset() function resets the iterator associated with handle back to the beginning of the trace data. This allows you to re-iterate over the same trace data multiple times without having to reopen the trace file.

In addition to the above, you can add event filters using tracecmd_filter_add(). This function allows you to specify a filter string that will be applied to the events during iteration. The filter string format is described in tep_filter_add_filter_str(3). The neg parameter determines whether to include (false) or exclude (true) events that match the filter. Filters added with this function are applied before the callbacks are invoked.

There is also a special callback that can be registered using tracecmd_follow_event(). This callback is invoked only for the specified event type. If this callback is registered, the general event callback for tracecmd_iterate_events() and tracecmd_iterate_events_multi() will not be called for that event type.

The tracecmd_follow_missed_events() function allows you to register a callback that will be called when the iterator encounters missed events. The callback function takes the same arguments as the general event callback, but it is only called when `record->missed_events > 0`.

The order of callbacks is as follows:

  1. If a callback is registered with tracecmd_follow_missed_events() and the record indicates missed events, that callback is invoked first.
  2. If a callback is registered with tracecmd_follow_event() for the specific event type, that callback is invoked.
  3. If neither of the above applies, but a general callback is registered with tracecmd_iterate_events() or tracecmd_iterate_events_multi(), that callback is invoked.

Callbacks registered via tracecmd_follow_event() are called before any of the other callbacks and any filters that were added by tracecmd_filter_add() are ignored. If callback returns a non zero, it will stop the iterator before it calls any of the other iterator callbacks for the given record.

The tracecmd_filter_add() function, adds a filter to handle that affects both tracecmd_iterate_events() and tracecmd_iterate_events_multi(). The filter_str is a character string defining a filter in a format that is defined by tep_filter_add_filter_str(3). If neg is true, then the events that match the filter will be skipped, otherwise the events that match will execute the callback() function in the iterators.

The tracecmd_iterate_reset() sets the handle back to start at the beginning, so that the next call to tracecmd_iterate_events() starts back at the first event again, instead of continuing where it left off.

RETURN VALUE

Both tracecmd_iterate_events(), tracecmd_iterate_events_reverse() and tracecmd_iterate_events_multi() return zero if they successfully iterated all events (handling the follow and filters appropriately). Or an error value, which can include returning a non-zero result from the callback() function.

tracecmd_iterate_reset() returns 0 on success and -1 if an error occurred. Note, if -1 is returned, a partial reset may have also happened.

EXAMPLE

#define _GNU_SOURCE
#include <sched.h>
#include <stdlib.h>
#include <getopt.h>
#include <trace-cmd.h>
struct private_data {
        int             cpu;
        const char      *file;
};
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        struct private_data *pdata = tracecmd_get_private(handle);
        /* For multi handles we need this */
        if (pdata->cpu >= 0 && pdata->cpu != record->cpu)
                return 0;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", pdata->file);
        tep_print_event(tep, &seq, record, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
static int print_event(struct tracecmd_input *handle, struct tep_event *event,
                       struct tep_record *record, int cpu, void *data)
{
        return print_events(handle, record, cpu, data);
}
static int missed_events(struct tracecmd_input *handle, struct tep_event *event,
                         struct tep_record *record, int cpu, void *data)
{
        if (record->missed_events > 0)
                printf("CPU [%03d] has %d missed events\n",
                         record->cpu, record->missed_events);
        else
                printf("CPU [%03d] has missed events\n", record->cpu);
        return 0;
}
static void usage(const char *argv0)
{
        printf("usage: [-c cpu][-f filter][-e event] %s trace.dat [trace.dat ...]\n",
               argv0);
        exit(-1);
}
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        const char *filter_str = NULL;
        const char *argv0 = argv[0];
        struct private_data *priv;
        cpu_set_t *cpuset = NULL;
        char *event = NULL;
        size_t cpusize = 0;
        int nr_handles = 0;
        int cpu = -1;
        int i;
        int c;
        while ((c = getopt(argc, argv, "c:f:e:")) >= 0) {
                switch (c) {
                case 'c':
                        /* filter all trace data to this one CPU. */
                        cpu = atoi(optarg);
                        break;
                case 'f':
                        filter_str = optarg;
                        break;
                case 'e':
                        event = optarg;
                        break;
                default:
                        usage(argv0);
                }
        }
        argc -= optind;
        argv += optind;
        if (argc == 0)
                usage(argv0);
        for (i = 0; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[i]);
                        exit(-1);
                }
                if (filter_str) {
                        if (tracecmd_filter_add(handles[nr_handles], filter_str, false) == NULL) {
                                perror("adding filter");
                                exit(-1);
                        }
                }
                priv = calloc(1, sizeof(*priv));
                if (!priv)
                        exit(-1);
                priv->file = argv[i];
                priv->cpu = cpu;
                tracecmd_set_private(handles[nr_handles], priv);
                if (event) {
                        if (tracecmd_follow_event(handles[nr_handles], NULL, event, print_event, NULL) < 0) {
                                printf("Could not follow event %s for file %s\n", event, argv[i]);
                                exit(-1);
                        }
                }
                tracecmd_follow_missed_events(handles[nr_handles], missed_events, NULL);
                nr_handles++;
        }
        /* Shortcut */
        if (nr_handles == 1) {
                if (cpu >= 0) {
                        cpuset = CPU_ALLOC(cpu + 1);
                        if (!cpuset)
                                exit(-1);
                        cpusize = CPU_ALLOC_SIZE(cpu + 1);
                        CPU_SET_S(cpu, cpusize, cpuset);
                }
                if (event)
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, NULL, NULL);
                else
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, print_events, NULL);
        } else {
                if (event)
                        tracecmd_iterate_events_multi(handles, nr_handles, NULL, NULL);
                else
                        tracecmd_iterate_events_multi(handles, nr_handles, print_events, NULL);
        }
        for (i = 0; i < nr_handles; i++) {
                priv = tracecmd_get_private(handles[i]);
                free(priv);
                tracecmd_close(handles[i]);
        }
        free(handles);
}
