CTRSYL3

Propósito:

!>
!>  CTRSYL3 resuelve la ecuación matricial de Sylvester compleja:
!>
!>     op(A)*X + X*op(B) = scale*C o
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  donde op(A) = A o A**H, y A y B son ambas triangulares superiores. A es
!>  de tamaño M por M y B es de tamaño N por N; el lado derecho C y la solución X son
!>  de tamaño M por N; y scale es un factor de escala de salida, establecido en <= 1 para evitar
!>  desbordamiento en X.
!>
!>  Esta es la versión de bloque del algoritmo.
!>

Parámetros

TRANA 
!>          TRANA es CHARACTER*1
!>          Especifica la opción op(A):
!>          = 'N': op(A) = A    (Sin transpuesta)
!>          = 'C': op(A) = A**H (Transpuesta conjugada)
!>

TRANB

!>          TRANB es CHARACTER*1
!>          Especifica la opción op(B):
!>          = 'N': op(B) = B    (Sin transpuesta)
!>          = 'C': op(B) = B**H (Transpuesta conjugada)
!>

ISGN

!>          ISGN es INTEGER
!>          Especifica el signo en la ecuación:
!>          = +1: resuelve op(A)*X + X*op(B) = scale*C
!>          = -1: resuelve op(A)*X - X*op(B) = scale*C
!>

M

!>          M es INTEGER
!>          El orden de la matriz A, y el número de filas en las
!>          matrices X y C. M >= 0.
!>

N

!>          N es INTEGER
!>          El orden de la matriz B, y el número de columnas en las
!>          matrices X y C. N >= 0.
!>

A

!>          A es un array COMPLEX, dimension (LDA,M)
!>          La matriz triangular superior A.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A. LDA >= max(1,M).
!>

B

!>          B es un array COMPLEX, dimension (LDB,N)
!>          La matriz triangular superior B.
!>

LDB

!>          LDB es INTEGER
!>          La dimensión principal del array B. LDB >= max(1,N).
!>

C

!>          C es un array COMPLEX, dimension (LDC,N)
!>          En la entrada, la matriz C del lado derecho de tamaño M por N.
!>          En la salida, C se sobrescribe con la matriz solución X.
!>

LDC

!>          LDC es INTEGER
!>          La dimensión principal del array C. LDC >= max(1,M)
!>

SCALE

!>          SCALE es REAL
!>          El factor de escala, scale, establecido en <= 1 para evitar desbordamiento en X.
!>

SWORK

!>          SWORK es un array REAL, dimension (MAX(2, ROWS), MAX(1,COLS)).
!>          En la salida, si INFO = 0, SWORK(1) devuelve el valor óptimo ROWS
!>          y SWORK(2) devuelve el valor óptimo COLS.
!>

LDSWORK

!>          LDSWORK es INTEGER
!>          LDSWORK >= MAX(2,ROWS), donde ROWS = ((M + NB - 1) / NB + 1)
!>          y NB es el tamaño de bloque óptimo.
!>
!>          Si LDSWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula las dimensiones óptimas de la matriz SWORK,
!>          devuelve estos valores como la primera y segunda entrada de la matriz SWORK,
!>          y XERBLA no emite ningún mensaje de error relacionado con LWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>          = 1: A y B tienen valores propios comunes o muy cercanos; se utilizaron
!>               valores perturbados para resolver la ecuación (pero las matrices
!>               A y B no cambian).
!>

DTRSYL3

Propósito:

!>
!>  DTRSYL3 resuelve la ecuación matricial de Sylvester real:
!>
!>     op(A)*X + X*op(B) = scale*C o
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  donde op(A) = A o A**T, y A y B son ambas cuasi-triangulares superiores. A es

!>  Esta es la versión de bloque del algoritmo.

NAME

DTRSYL3 - solve the real Sylvester matrix equation AX+XB=C

SYNOPSIS

SUBROUTINE DTRSYL3(TRANSA, TRANSB, ISGN, M, N, A, LDA, B, LDB, C, LDC, SCALE, IWORK, LIWORK, SWORK, LDSWORK, INFO)
      CHARACTER * 1 TRANA, TRANB
      INTEGER M, N, LDA, LDB, LDC, LIWORK, LDSWORK, INFO
      DOUBLE PRECISION A(LDA, *), B(LDB, *), C(LDC, *), SCALE
      INTEGER IWORK(*)
      DOUBLE PRECISION SWORK(*)

PURPOSE

 DTRSYL3 solves the real Sylvester matrix equation:

    op(A)*X + X*op(B) = scale*C or
    op(A)*X - X*op(B) = scale*C,

 where op(A) = A or A**T, and  A and B are both upper quasi-
 triangular. A is M-by-M and B is N-by-N; the right hand side C and
 the solution X are M-by-N; and scale is an output scale factor, set
 <= 1 to avoid overflow in X.

 A and B must be in Schur canonical form (as returned by SHSEQR), that
 is, block upper triangular with 1-by-1 and 2-by-2 diagonal blocks;
 each 2-by-2 diagonal block has its diagonal elements equal and its
 off-diagonal elements of opposite sign.

 This is the block version of the algorithm.

PARAMETERS

TRANSA

TRANSA is CHARACTER*1

Specifies the option op(A):

               = 'N': op(A) = A    (No transpose)
               = 'T': op(A) = A**T (Transpose)
               = 'C': op(A) = A**H (Conjugate transpose = Transpose)
TRANB

TRANB is CHARACTER*1

Specifies the option op(B):

               = 'N': op(B) = B    (No transpose)
               = 'T': op(B) = B**T (Transpose)
               = 'C': op(B) = B**H (Conjugate transpose = Transpose)
ISGN

ISGN is INTEGER

Specifies the sign in the equation:

               = +1: solve op(A)*X + X*op(B) = scale*C
               = -1: solve op(A)*X - X*op(B) = scale*C
M

M is INTEGER

The order of the matrix A, and the number of rows in the matrices X and C. M >= 0.

N

N is INTEGER

The order of the matrix B, and the number of columns in the matrices X and C. N >= 0.

A

A is DOUBLE PRECISION array, dimension (LDA,M)

The upper quasi-triangular matrix A, in Schur canonical form.

LDA

LDA is INTEGER

The leading dimension of the array A. LDA >= max(1,M).

B

B is DOUBLE PRECISION array, dimension (LDB,N)

The upper quasi-triangular matrix B, in Schur canonical form.

LDB

LDB is INTEGER

The leading dimension of the array B. LDB >= max(1,N).

C

C is DOUBLE PRECISION array, dimension (LDC,N)

On entry, the M-by-N right hand side matrix C.

On exit, C is overwritten by the solution matrix X.

LDC

LDC is INTEGER

The leading dimension of the array C. LDC >= max(1,M)

SCALE

SCALE is DOUBLE PRECISION

The scale factor, scale, set <= 1 to avoid overflow in X.

IWORK

IWORK is INTEGER array, dimension (MAX(1,LIWORK))

On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.

LIWORK

IWORK is INTEGER

The dimension of the array IWORK. LIWORK >= ((M + NB - 1) / NB + 1) + ((N + NB - 1) / NB + 1), where NB is the optimal block size.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal dimension of the IWORK array, returns this value as the first entry of the IWORK array, and no error message related to LIWORK is issued by XERBLA.

SWORK

SWORK is DOUBLE PRECISION array, dimension (MAX(2, ROWS), MAX(1,COLS)).

On exit, if INFO = 0, SWORK(1) returns the optimal value ROWS and SWORK(2) returns the optimal COLS.

LDSWORK

LDSWORK is INTEGER

LDSWORK >= MAX(2,ROWS), where ROWS = ((M + NB - 1) / NB + 1) and NB is the optimal block size.

If LDSWORK = -1, then a workspace query is assumed; the routine only calculates the optimal dimensions of the SWORK matrix, returns these values as the first and second entry of the SWORK matrix, and no error message related LWORK is issued by XERBLA.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

NAME

trsyl3 - solves the Sylvester equation.

SYNOPSIS

SUBROUTINE TRSYL3( TRANSA, TRANSB, SIGN, M, N, A, LDA, B, LDB, C, LDC, SCALE, SWORK, LDSWORK, INFO )

Detailed Description

trsyl3 solves the Sylvester equation:

  op(A)*X*op(B) + sign*C*X*D = op(B) or op(A)*X*op(B) + sign*X*op(D) = op(B)

where op(A) is A or A^H, and X is the unknown M-by-N matrix which is computed.

A and B are upper triangular matrices.

sign = -1 or +1.

TRANSA, TRANSB, SIGN, M, N, A, LDA, B, LDB, C, LDC, SCALE, SWORK, LDSWORK, and INFO are described below.

Parameters

TRANSA

CHARACTER*1. On entry, TRANSA specifies the form of op(A) as follows:

  TRANSA = 'N'      op(A) = A
  TRANSA = 'C'      op(A) = A**H

Unchanged on exit.

TRANSB

CHARACTER*1. On entry, TRANSB specifies the form of op(B) as follows:

  TRANSB = 'N'      op(B) = B
  TRANSB = 'C'      op(B) = B**H

Unchanged on exit.

SIGN

INTEGER. On entry, SIGN specifies the sign of the term C*X*D (for the first formulation of the Sylvester equation):

  SIGN = -1         op(A)*X*op(B) - C*X*D = op(B)
  SIGN = +1         op(A)*X*op(B) + C*X*D = op(B)

Unchanged on exit.

M

INTEGER.

  On entry, M is the number of rows of matrices A, X and C.
  M >= 0.

Unchanged on exit.

N

INTEGER.

  On entry, N is the number of columns of matrices B, X and C.
  N >= 0.

Unchanged on exit.

A

COMPLEX*16 array, dimension (LDA, M).

  On entry, the leading M-by-M upper triangular part of the array A must
  contain the upper triangular matrix A.

Unchanged on exit.
