NOMBRE

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Crear y destruir histogramas de eventos

SINOPSIS

#include <tracefs.h>
enum tracefs_hist_key_type {
        TRACEFS_HIST_KEY_NORMAL = 0,
        TRACEFS_HIST_KEY_HEX,
        TRACEFS_HIST_KEY_SYM,
        TRACEFS_HIST_KEY_SYM_OFFSET,
        TRACEFS_HIST_KEY_SYSCALL,
        TRACEFS_HIST_KEY_EXECNAME,
        TRACEFS_HIST_KEY_LOG,
        TRACEFS_HIST_KEY_USECS,
        TRACEFS_HIST_KEY_MAX
};
struct tracefs_hist_axis {
        const char *key;
        enum tracefs_hist_key_type type;
};
struct tracefs_hist *tracefs_hist_alloc(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key, enum tracefs_hist_key_type type);
struct tracefs_hist *tracefs_hist_alloc_2d(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key1, enum tracefs_hist_key_type type1,
                        const char *key2, enum tracefs_hist_key_type type2));
struct tracefs_hist *tracefs_hist_alloc_nd(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        struct tracefs_hist_axis *axes);
struct tracefs_hist *tracefs_hist_alloc_nd_cnt(struct tep_handle *tep,
                          const char *system, const char *event_name,
                          struct tracefs_hist_axis_cnt *axes);
void tracefs_hist_free(struct tracefs_hist *hist);
int tracefs_hist_add_key(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type);
int tracefs_hist_add_key_cnt(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type, int cnt);
int tracefs_hist_add_value(struct tracefs_hist *hist, const char *value);

DESCRIPCIÓN

Los histogramas de eventos se crean mediante el archivo de activación en el directorio del evento. La sintaxis puede ser compleja y difícil de conseguir correctamente. Esta API maneja la sintaxis y facilita la creación e interacción con los histogramas de eventos. Consulte https://www.kernel.org/doc/html/latest/trace/histogram.html para obtener más información.

tracefs_hist_alloc() asigna un descriptor de "struct tracefs_hist" de un histograma unidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de rastreo (ver tracefs_local_events(3)), que contiene el system y event al que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key es un campo del evento que se utilizará como clave (dimensión) del histograma. El type es el tipo de la key. Consulte TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_2d() asigna un descriptor de "struct tracefs_hist" de un histograma bidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de rastreo (ver tracefs_local_events(3)), que contiene el system y event al que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key1 es el primer campo del evento que se utilizará como clave (dimensión) del histograma. El type1 es el tipo de la key1. Consulte TIPOS DE CLAVE a continuación. La key2 es el segundo campo del evento que se utilizará como clave (dimensión) del histograma. El type2 es el tipo de la key2. Consulte TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_nd() asigna un descriptor de "struct tracefs_hist" de un histograma N-dimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de rastreo (ver tracefs_local_events(3)), que contiene el system y event al que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. Los axes es un arreglo de pares key / type, que definen las dimensiones del histograma.

tracefs_hist_alloc_nd_cnt() inicializará un descriptor de histograma que se adjuntará al system/event. Esto solo inicializa el descriptor con las claves axes dadas como primarias. Esto solo inicializa el descriptor, no inicia el histograma en el kernel. La diferencia entre esto y tracefs_hist_alloc_nd() es que el parámetro axes es de tipo struct tracefs_hist_axis_cnt y no struct tracefs_hist_axis.

tracefs_hist_free() libera el descriptor tracefs_hist. Tenga en cuenta que no detiene ni deshabilita el histograma en ejecución si se inició. Es necesario llamar a tracefs_hist_destroy() para hacerlo.

tracefs_hist_add_key() agrega una clave secundaria o terciaria al histograma. La clave pasada a tracefs_hist_alloc_nd() es la clave primaria del histograma. La primera vez que se llama a esta función, agregará una clave secundaria (o un histograma bidimensional). Si esta función se vuelve a llamar en el mismo histograma, agregará una clave terciaria (o un histograma tridimensional). El parámetro hist es el descriptor del histograma al que se agregará la key. El type es el tipo de clave a agregar (Ver TIPOS DE CLAVE a continuación).

tracefs_hist_add_key_cnt() es lo mismo que tracefs_hist_add_key() excepto que permite agregar un contador para el tipo dado. Actualmente, solo existe el tipo buckets que requiere un contador. Al agregar una clave con el tipo buckets, tracefs_hist_add_key() no es suficiente, ya que el tipo buckets requiere un contador o un tamaño de balde. Utilice tracefs_hist_add_key_cnt() al especificar una clave que se divide en baldes, y pase el tamaño de esos baldes en cnt.

tracefs_hist_add_value() agregará un valor para registrar. Por defecto, el valor es simplemente el "hitcount" de cuántas veces se golpeó una instancia de la clave del histograma. El hist es el descriptor del histograma al que se agregará el valor. El value es un campo en el histograma que se agregará cuando se golpee una instancia de la clave.

TIPOS DE CLAVE

tracefs_hist_alloc_nd() y tracefs_hist_add_key() ambos agregan una clave y requieren que esa clave tenga un tipo. Los tipos pueden ser:

TRACEFS_HIST_KEY_NORMAL o cero (0) que es no modificar el tipo.

TRACEFS_HIST_KEY_HEX para mostrar la clave en formato hexadecimal.

TRACEFS_HIST_KEY_SYM para mostrar la clave como un símbolo del kernel (si se encuentra). Si la clave es una dirección, esto es útil ya que mostrará los nombres de las funciones en lugar de solo un número.

TRACEFS_HIST_KEY_SYM_OFFSET similar a TRACEFS_HIST_KEY_SYM pero también incluirá el desplazamiento de la función para coincidir con la dirección exacta.

TRACEFS_HIST_KEY_SYSCALL Si la clave es un "id" de llamada al sistema (el número que se pasa del espacio de usuario al kernel para indicarle qué llamada al sistema está realizando), se mostrará el nombre de la llamada al sistema.

TRACEFS_HIST_KEY_EXECNAME Si "common_pid" es la clave (el pid de la tarea en ejecución), en lugar de mostrar el número, se mostrará el nombre de la tarea en ejecución.

TRACEFS_HIST_KEY_LOG mostrará la clave en una escala logarítmica binaria.

TRACEFS_HIST_KEY_USECS para usar con "common_timestamp" o TRACEFS_HIST_TIMESTAMP, en cuyo caso mostrará la marca de tiempo en microsegundos en lugar de nanosegundos.

VALOR DE RETORNO

tracefs_hist_alloc_nd() devuelve un descriptor de histograma asignado que debe ser liberado por tracefs_hist_free() o NULL en caso de error.

Todas las demás funciones devuelven cero en caso de éxito o -1 en caso de error.

Si tracefs_hist_start() devuelve un error, se puede mostrar un mensaje en el kernel que se puede recuperar con tracefs_error_last().

Las funciones de finalización devuelven cero en caso de éxito o -1 en caso de error. La obtención de los datos de histograma devolverá un descriptor para la tabla del histograma o NULL en caso de error.

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Failed to allocate axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "'buckets' key type requires '=<size>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Undefined attribute '%s'\n", att);
                                fprintf(stderr,"  Acceptable attributes:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Failed instance create\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Could not read events");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Reading hist file");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "Command needs -k option\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "No keys??\n");
                exit(-1);
        }
        /* buckets require the nd_cnt function */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* fall through */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Show examples of hist1d and hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Really, 1 and 2 could use this too */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Failed hist create\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add value %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add sort key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add ascending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add descending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* Show was already done */
                break;
        }
        if (ret)
                fprintf(stderr, "Failed: command\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Unknown command %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

DESCRIPTION

The tracefs library provides a way to create and manage trace events for tracing purposes. The functions described in this man page provide helper routines for creating and manipulating 2D histograms which can be used to visualize the distribution of trace events.

A 2D histogram is created using tracefs_hist_alloc_2d(). It is freed using tracefs_hist_free_2d().

Events can be added to the histogram using tracefs_hist_add_event_2d() and removed using tracefs_hist_remove_event_2d(). The number of events that can be added is limited by the maximum number of events supported by the library.

The names of the events that have been added to the histogram can be retrieved using tracefs_hist_get_event_2d().

A name for the histogram itself can be set using tracefs_hist_set_name_2d() and retrieved using tracefs_hist_get_name_2d().

The actual histogram data is stored as an array of sizes. The array can be retrieved using tracefs_hist_get_array_2d() and its size can be obtained using tracefs_hist_get_array_size_2d().

The range of values for the histogram can be set using tracefs_hist_set_range_2d() and retrieved using tracefs_hist_get_range_2d().

The number of bins in the histogram can be obtained using tracefs_hist_get_num_bins_2d() and the size of each bin can be obtained using tracefs_hist_get_bin_size_2d().

KEY TYPES

struct tracefs_hist_2d
This structure represents a 2D histogram.

RETURN VALUE

Most of the functions return 0 on success and a negative value on error. Refer to the individual function descriptions for more details.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>

int main(void) {
    struct tracefs_hist_2d *hist;
    int ret;

    hist = tracefs_hist_alloc_2d();
    if (!hist) {
        perror("tracefs_hist_alloc_2d");
        return 1;
    }

    ret = tracefs_hist_add_event_2d(hist, "sched_switch");
    if (ret < 0) {
        fprintf(stderr, "Failed to add event: %d\n", ret);
        goto out;
    }

    ret = tracefs_hist_set_name_2d(hist, "my_2d_hist");
    if (ret < 0) {
        fprintf(stderr, "Failed to set name: %d\n", ret);
        goto out;
    }

    ret = tracefs_hist_set_range_2d(hist, 0, 1000000);
    if (ret < 0) {
        fprintf(stderr, "Failed to set range: %d\n", ret);
        goto out;
    }

    printf("Histogram name: %s\n", tracefs_hist_get_name_2d(hist));
    printf("Event 0: %s\n", tracefs_hist_get_event_2d(hist, 0));

    unsigned long long min, max;
    tracefs_hist_get_range_2d(hist, &min, &max);
    printf("Range: %llu - %llu\n", min, max);

    printf("Number of bins: %d\n", tracefs_hist_get_num_bins_2d(hist));
    printf("Bin size: %d\n", tracefs_hist_get_bin_size_2d(hist));

out:
    tracefs_hist_free_2d(hist);
    return ret < 0 ? 1 : 0;
}
