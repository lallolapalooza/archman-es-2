tracefs_instance_reset(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_create, tracefs_instance_destroy, tracefs_instance_alloc, tracefs_instance_free, tracefs_instance_is_new, tracefs_instances, tracefs_instance_clear, tracefs_instance_reset - Gestionar instancias de traza.

SINOPSIS

#include <tracefs.h>
struct tracefs_instance *tracefs_instance_create(const char *name);
int tracefs_instance_destroy(struct tracefs_instance *instance);
struct tracefs_instance *tracefs_instance_alloc(const char *tracing_dir, const char *name);
void tracefs_instance_free(struct tracefs_instance *instance);
bool tracefs_instance_is_new(struct tracefs_instance *instance);
char **tracefs_instances(const char *regex);
void tracefs_instance_clear(struct tracefs_instance *instance);
void tracefs_instance_reset(struct tracefs_instance *instance);

DESCRIPCIÓN

Este conjunto de funciones se puede utilizar para gestionar instancias de traza. Una instancia de traza es un búfer secundario utilizado por el sistema de trazas de Linux. Dada una instancia única, los eventos habilitados en una instancia no afectan al sistema de trazas principal, ni a otras instancias, ya que los eventos habilitados en el sistema de trazas principal o en otras instancias no afectan a la instancia dada.

La función tracefs_instance_create() asigna e inicializa una nueva estructura tracefs_instance y la devuelve. Si la instancia con name aún no existe en el sistema, se creará. El name puede ser NULL, en cuyo caso la nueva estructura tracefs_instance se inicializa para la instancia superior. Tenga en cuenta que la instancia superior no se puede crear en el sistema si no existe.

La función tracefs_instance_destroy() elimina la instancia del sistema, pero no libera la estructura. Todavía se debe llamar a tracefs_instance_free() en instance.

La función tracefs_instance_alloc()* asigna una nueva estructura tracefs_instance para una instancia de traza existente. Si la instancia no existe en el sistema, la función falla. El parámetro tracing_dir apunta al directorio de trazas del sistema. Puede ser NULL, en cuyo caso se utiliza el directorio de trazas del sistema por defecto. Este parámetro es útil para asignar instancias a directorios de trazas, copiados de otra máquina. El name es el nombre de la instancia, o NULL para la instancia superior en el tracing_dir dado.

La función tracefs_instance_free() libera la estructura tracefs_instance, sin eliminar la instancia de traza del sistema.

La función tracefs_instance_is_new() comprueba si la instance dada fue creada recientemente por tracefs_instance_create(), o si ya existía en el sistema antes de eso.

La función tracefs_instances() devuelve una lista de instancias que existen en el sistema y que coinciden con la expresión regular regex. Si regex es NULL, entonces coincidirá con todas las instancias existentes. La lista devuelta debe ser liberada con tracefs_list_free(3). Tenga en cuenta que si no se encuentran instancias, se devuelve una lista vacía y también debe ser liberada con tracefs_list_free(3).

La función tracefs_instance_clear() borra el búfer de anillo de la instance dada o el búfer de anillo de nivel superior si instance es NULL.

La función tracefs_instance_reset() restablece la instance dada a su estado predeterminado.

VALOR DE RETORNO

Las funciones tracefs_instance_create() y tracefs_instance_alloc() devuelven un puntero a una estructura tracefs_instance recién asignada. Debe ser liberada con tracefs_instance_free().

La función tracefs_instance_destroy() devuelve 0 si tiene éxito al eliminar la instancia, de lo contrario, devuelve -1 si la instancia no existe o falla al eliminarla.

La función tracefs_instance_is_new() devuelve verdadero si tracefs_instance_create(), que asignó instance, también creó la instancia de traza en el sistema, o falso si la instancia de traza ya existía en el sistema cuando instance fue asignada por tracefs_instance_create() o tracefs_instance_alloc().

La función tracefs_instances() devuelve una lista de nombres de instancias que existen en el sistema. La lista debe ser liberada con tracefs_list_free(3). Se devuelve una lista vacía si no existe ninguna instancia que coincida con regex, y esta también debe ser liberada con tracefs_list_free(3). Se devuelve NULL en caso de error.

La función tracefs_instance_clear() devuelve 0 si borró correctamente el búfer de anillo, o -1 en caso de error.

EJEMPLO

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Error al crear una nueva instancia de traza */
                ...
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        tracefs_instance_free(inst);
...
struct tracefs_instance *inst = tracefs_instance_alloc(NULL, "bar");
        if (!inst) {
                /* Error al asignar la instancia de traza 'bar' */
                ...
        }
        ...
        tracefs_instance_reset(inst);
        tracefs_instance_free(inst);
