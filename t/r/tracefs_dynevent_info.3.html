tracefs_dynevent_info(3)

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_dynevent_create, tracefs_dynevent_destroy, tracefs_dynevent_destroy_all, tracefs_dynevent_free, tracefs_dynevent_list_free, tracefs_dynevent_get, tracefs_dynevent_get_all, tracefs_dynevent_info, tracefs_dynevent_get_event - Crear, destruir, liberar y obtener eventos dinámicos.

SINOPSIS

#include <tracefs.h>
struct tracefs_dynevent;
enum tracefs_dynevent_type;
int tracefs_dynevent_create(struct tracefs_dynevent *devent);
int tracefs_dynevent_destroy(struct tracefs_dynevent *devent, bool force);
int tracefs_dynevent_destroy_all(unsigned int types, bool force);
void tracefs_dynevent_free(struct tracefs_dynevent *devent);
void tracefs_dynevent_list_free(struct tracefs_dynevent **events);
struct tracefs_dynevent *tracefs_dynevent_get(enum tracefs_dynevent_type type, const char *system, const char *event);
struct tracefs_dynevent **tracefs_dynevent_get_all(unsigned int types, const char *system);
enum tracefs_dynevent_type tracefs_dynevent_info(struct tracefs_dynevent *dynevent, char **system, char **event, char **prefix, char **addr, char **format);
struct tep_event *tracefs_dynevent_get_event(struct tep_handle *tep, struct tracefs_dynevent *dynevent);

DESCRIPCIÓN

La función tracefs_dynevent_create() crea el evento dinámico devent en el sistema.

La función tracefs_dynevent_destroy() elimina el evento dinámico devent del sistema. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar el evento dinámico. El contexto devent no se libera, use tracefs_dynevent_free() para liberarlo.

La función tracefs_dynevent_destroy_all() elimina todos los eventos dinámicos de los tipos dados del sistema. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de los tipos de eventos dinámicos tracefs_dynevent_type, que serán eliminados. Si types es 0, se eliminarán los eventos dinámicos de todos los tipos. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar los eventos dinámicos.

La función tracefs_dynevent_get() asigna y devuelve una única instancia de un evento dinámico que coincide con el type, system y event dados. Se devuelve NULL si no hay coincidencia. El evento devuelto es lo que se encuentra en el sistema y debe liberarse con tracefs_dynevent_free(). Si system es NULL, entonces se devolverá el primer event de cualquier sistema del tipo dado que tenga el nombre de event.

La función tracefs_dynevent_get_all() asigna y devuelve un arreglo de punteros a eventos dinámicos de los tipos dados que existen en el sistema. El último elemento del arreglo es un puntero NULL. El arreglo debe liberarse con tracefs_dynevent_list_free(). Si no hay eventos, se devuelve un puntero NULL. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de los tipos de eventos dinámicos tracefs_dynevent_type, que serán recuperados. Si types es 0, se recuperarán los eventos dinámicos de todos los tipos.

La función tracefs_dynevent_free() libera un contexto de evento dinámico devent.

La función tracefs_dynevent_list_free() libera un arreglo de punteros a eventos dinámicos, devuelto por la API tracefs_dynevent_get_all().

La función tracefs_dynevent_info() devuelve el tipo e información de un evento dinámico dado dynevent. Si alguno de los argumentos system, event, prefix, addr o format no son NULL, entonces se asignan cadenas de caracteres y se devuelven a través de estos argumentos. El system y event contienen el sistema y el nombre del evento dinámico. Si prefix no es NULL, entonces contendrá una cadena asignada que contiene la porción de prefijo del evento dinámico (el contenido hasta el ":", sin incluirlo). Si addr no es NULL, contendrá la dirección o función a la que está adjunto el evento dinámico, si es relevante para este tipo de evento. Si format no es NULL, contendrá la cadena de formato del evento dinámico. Tenga en cuenta que el contenido en group, event, prefix, addr y format debe liberarse con free(3) si se establecen.

La función tracefs_dynevent_get_event() devuelve un evento tep, que describe el evento dinámico dado. La API detecta cualquier evento dinámico recién creado o eliminado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

VALOR DE RETORNO

tracefs_dynevent_create() devuelve 0 si tiene éxito, o -1 en caso de error. Si ocurre un error de análisis, tracefs_error_last(3) puede ser utilizado para recuperar el mensaje de error que explica el problema de análisis.

tracefs_dynevent_destroy() y tracefs_dynevent_destroy_all() devuelven 0 si tienen éxito, o -1 en caso de error. Si force está habilitado, las funciones pueden fallar al deshabilitar los eventos.

tracefs_dynevent_get() devuelve un evento dinámico asignado del sistema que coincide con el tipo, sistema y evento dados.

tracefs_dynevent_get_all() devuelve un arreglo asignado de punteros a eventos dinámicos, o NULL en caso de error o si no hay eventos en el sistema. Ese arreglo debe liberarse con tracefs_dynevent_list_free().

tracefs_dynevent_info() devuelve el tipo del evento dinámico dado o TRACEFS_DYNEVENT_UNKNOWN en caso de error. Si system, event, prefix, addr o format no son NULL, contendrán cadenas asignadas que deben liberarse con free(3).

La función tracefs_dynevent_get_event() devuelve un puntero a un evento tep o NULL en caso de error o si el evento dinámico solicitado no se encuentra. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

ENODEV Los eventos dinámicos del tipo solicitado no están configurados para el kernel en ejecución.

ENOMEM Error de asignación de memoria.

tracefs_dynevent_create() puede fallar con los siguientes errores:

EINVAL Lo más probable es que haya ocurrido un error de análisis (use tracefs_error_last(3) para ver posiblemente cuál fue ese error).

Pueden ocurrir otros errores causados por llamadas internas al sistema.

#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <tracefs.h>
static struct tep_event *open_event;
static struct tep_format_field *file_field;
static struct tep_event *openret_event;
static struct tep_format_field *ret_field;
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: ", TEP_PRINT_PID, TEP_PRINT_COMM);
        if (event->id == open_event->id) {
                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}
static pid_t run_exec(char **argv, char **env)
{
        pid_t pid;
        pid = fork();
        if (pid)
                return pid;
        execve(argv[0], argv, env);
        perror("exec");
        exit(-1);
}
