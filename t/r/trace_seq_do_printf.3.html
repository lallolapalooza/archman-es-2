trace_seq_do_printf(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

trace_seq_init, trace_seq_destroy, trace_seq_reset, trace_seq_terminate, trace_seq_putc, trace_seq_puts, trace_seq_printf, trace_seq_vprintf, trace_seq_do_fprintf, trace_seq_do_printf - Inicializar / destruir una secuencia de traza.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void trace_seq_init(struct trace_seq *s);
void trace_seq_destroy(struct trace_seq *s);
void trace_seq_reset(struct trace_seq *s);
void trace_seq_terminate(struct trace_seq *s);
int trace_seq_putc(struct trace_seq *s, unsigned char c);
int trace_seq_puts(struct trace_seq *s, const char *str);
int trace_seq_printf(struct trace_seq *s, const char *fmt, ...);
int trace_seq_vprintf(struct trace_seq *s, const char *fmt, va_list args);
int trace_seq_do_printf(struct trace_seq *s);
int trace_seq_do_fprintf(struct trace_seq *s, FILE *fp);

DESCRIPCIÓN

Las secuencias de traza se utilizan para permitir que una función llame a otras funciones para crear una cadena de datos para su uso.

La función trace_seq_init() inicializa la secuencia de traza s.

La función trace_seq_destroy() destruye la secuencia de traza s y libera todos sus recursos que haya utilizado.

La función trace_seq_reset() reinicializa la secuencia de traza s. Se eliminarán todos los caracteres ya escritos en s.

La función trace_seq_terminate() termina la secuencia de traza s. Coloca el carácter nulo '\0' al final del buffer.

La función trace_seq_putc() coloca un solo carácter c en la secuencia de traza s.

La función trace_seq_puts() coloca una cadena terminada en NULL str en la secuencia de traza s.

La función trace_seq_printf() coloca una cadena formateada fmt _con argumentos variables _... en la secuencia de traza s.

La función trace_seq_vprintf() coloca una cadena formateada fmt _con una lista de argumentos _args en la secuencia de traza s.

La función trace_seq_do_printf() imprime el buffer de la secuencia de traza s en la salida estándar stdout.

La función trace_seq_do_fprintf() imprime el buffer de la secuencia de traza s en el archivo dado fp.

VALOR DE RETORNO

Tanto las funciones trace_seq_putc() como trace_seq_puts() devuelven el número de caracteres puestos en la secuencia de traza, o 0 en caso de error.

Tanto las funciones trace_seq_printf() como trace_seq_vprintf() devuelven 0 si la traza excede el espacio libre del buffer, el número de caracteres impresos, o un valor negativo en caso de error.

Tanto las funciones trace_seq_do_printf() como trace_seq_do_fprintf() devuelven el número de caracteres impresos, o -1 en caso de error.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct trace_seq seq;
trace_seq_init(&seq);
...
void foo_seq_print(struct trace_seq *tseq, char *format, ...)
{
        va_list ap;
        va_start(ap, format);
        if (trace_seq_vprintf(tseq, format, ap) <= 0) {
                /* Falló al imprimir en la secuencia de traza */
        }
        va_end(ap);
}
trace_seq_reset(&seq);
char *str = " Ejemplo de página man";
if (trace_seq_puts(&seq, str) != strlen(str)) {
        /* Falló al poner str en la secuencia de traza */
}
if (trace_seq_putc(&seq, ':') != 1) {
        /* Falló al poner ':' en la secuencia de traza */
}
if (trace_seq_printf(&seq, " secuencia de traza: %d", 1) <= 0) {
        /* Falló al imprimir en la secuencia de traza */
}
foo_seq_print( &seq, "  %d\n", 2);
trace_seq_terminate(&seq);
...
if (trace_seq_do_printf(&seq) < 0 ) {
        /* Falló al imprimir el buffer de la secuencia en la salida estándar */
}
FILE *fp = fopen("trace.txt", "w");
if (trace_seq_do_fprintf(&seq, fp) < 0 ) [
        /* Falló al imprimir el buffer de la secuencia en el archivo trace.txt */
}
trace_seq_destroy(&seq);
...
