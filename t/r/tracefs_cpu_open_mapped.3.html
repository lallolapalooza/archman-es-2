tracefs_cpu_open_mapped(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_cpu_open_mapped, tracefs_cpu_is_mapped, tracefs_mapped_is_supported, tracefs_cpu_map, tracefs_cpu_unmap - Mapeo de memoria del búfer de anillo

SINOPSIS

#include <tracefs.h>
bool tracefs_cpu_is_mapped(struct tracefs_cpu *tcpu);
bool tracefs_mapped_is_supported(void);
int tracefs_cpu_map(struct tracefs_cpu *tcpu);
void tracefs_cpu_unmap(struct tracefs_cpu *tcpu);
struct tracefs_cpu *tracefs_cpu_open_mapped(struct tracefs_instance *instance,
                                            int cpu, bool nonblock);

DESCRIPCIÓN

Si trace_pipe_raw soporta mapeo de memoria, este es usualmente un método más eficiente para transmitir datos desde el búfer de anillo del kernel que leerlo, ya que no requiere copiar la memoria que se está leyendo.

Si el kernel soporta el mapeo de memoria y la aplicación solicita usar el mapeo de memoria a través de tracefs_cpu_map() o tracefs_cpu_open_mapped(), entonces las funciones tracefs_cpu_read(3) y tracefs_cpu_read_buf(3) usarán el mapeo directamente en lugar de llamar a la llamada del sistema read.

Nota, el mapeo hará que tracefs_cpu_buffered_read(3) y tracefs_cpu_buffered_read_buf(3) actúen igual que tracefs_cpu_read(3) y tracefs_cpu_read_buf(3) respectivamente, ya que no tiene sentido usar un pipe splice cuando está mapeado. El kernel hará una copia para las lecturas splice en el mapeo, y luego otra copia en la función cuando pueda evitar las copias si el búfer de anillo está mapeado en memoria.

Si el tcpu está mapeado en memoria, también forzará a tracefs_cpu_write(3) y tracefs_cpu_pipe(3) a copiar desde el mapeo en lugar de usar splice. Por lo tanto, se debe tener cuidado al decidir si mapear o no el búfer de anillo, y por qué no se mapea por defecto.

La función tracefs_cpu_is_mapped() devolverá verdadero si tcpu tiene actualmente su búfer de anillo mapeado en memoria y falso en caso contrario. Esto no devuelve si el kernel soporta el mapeo de memoria, pero eso usualmente se puede determinar llamando a tracefs_cpu_map().

La función tracefs_mapped_is_supported() devuelve verdadero si el búfer de anillo puede ser mapeado en memoria.

La función tracefs_cpu_map() intentará mapear el búfer de anillo asociado a tcpu si aún no está mapeado.

La función tracefs_cpu_unmap() desmapeará el búfer de anillo asociado a tcpu si está mapeado.

La función tracefs_cpu_open_mapped() es equivalente a llamar a tracefs_cpu_open(3) seguido de tracefs_cpu_map() en el tcpu devuelto por tracefs_cpu_open(3). Nota, esto aún tendrá éxito si el mapeo falla, en cuyo caso actúa igual que tracefs_cpu_open(3). Si se quiere saber si el mapeo tuvo éxito o no, se debe llamar a tracefs_cpu_is_mapped() en el tcpu de retorno.

VALOR DE RETORNO

tracefs_cpu_is_mapped() devuelve verdadero si el tcpu dado tiene su búfer de anillo mapeado en memoria o falso en caso contrario.

tracefs_mapped_is_supported() devuelve verdadero si el búfer de anillo de trazado puede ser mapeado en memoria o falso si no puede o ocurrió un error.

tracefs_cpu_map() devuelve 0 en caso de éxito y -1 en caso de error al mapear. Si se devuelve 0, entonces tracefs_cpu_is_mapped() devolverá verdadero después, o falso si el mapeo falló.

tracefs_cpu_open_mapped() devuelve un tracefs_cpu asignado en caso de éxito de creación, independientemente de si tuvo éxito al mapear el búfer de anillo o no. Devuelve NULL por las mismas razones que tracefs_cpu_open(3) devuelve NULL. Si se quiere conocer el éxito del mapeo, es necesario llamar a tracefs_cpu_is_mapped() después.

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_subbuf(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        int missed_events;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                missed_events = kbuffer_missed_events(kbuf);
                if (missed_events) {
                        printf("[MISSED EVENTS");
                        if (missed_events > 0)
                                printf(": %d]\n", missed_events);
                        else
                                printf("]\n");
                }
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        bool mapped;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open_mapped(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        /*
         * If this kernel supports mapping, use normal read,
         * otherwise use the piped buffer read, although if
         * the mapping succeeded, tracefs_cpu_buffered_read_buf()
         * acts the same as tracefs_cpu_read_buf(). But this is just
         * an example on how to use tracefs_cpu_is_mapped().
         */
        mapped = tracefs_cpu_is_mapped(tcpu);
        if (!mapped)
                printf("Was not able to map, falling back to buffered read\n");
        while ((kbuf = mapped ? tracefs_cpu_read_buf(tcpu, true) :
                        tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_subbuf(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_subbuf(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}
