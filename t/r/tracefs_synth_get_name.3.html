tracefs_synth_get_name(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_synth_echo_cmd, tracefs_synth_get_start_hist, tracefs_synth_get_name, tracefs_synth_raw_fmt, tracefs_synth_show_event, tracefs_synth_show_start_hist, tracefs_synth_show_end_hist, tracefs_synth_get_event - Recuperar datos de eventos sintéticos.

SINOPSIS

#include <tracefs.h>
int tracefs_synth_echo_cmd(struct trace_seq *seq, struct tracefs_synth *synth);
struct tracefs_hist *tracefs_synth_get_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_get_name(struct tracefs_synth *synth);
int tracefs_synth_raw_fmt(struct trace_seq *seq, struct tracefs_synth *synth);
const char *tracefs_synth_show_event(struct tracefs_synth *synth);
const char *tracefs_synth_show_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_show_end_hist(struct tracefs_synth *synth);
struct tep_event *tracefs_synth_get_event(struct tep_handle *tep, struct tracefs_synth *synth);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos que activan un evento sintético. Un evento es el evento de inicio del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, activará el evento sintético. Los valores de campo distintos de los campos coincidentes pueden pasarse del evento de inicio al evento final para realizar cálculos, o simplemente pasarse como un parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, establecer "sched_switch" como el evento de fin. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como un campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice TRACEFS_TIMESTAMP_USECS como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como el ejemplo a continuación.

Consulte tracefs_synth_alloc(3) para la asignación de eventos sintéticos, y tracefs_synth_create() para crear el evento sintético en el sistema.

tracefs_synth_echo_cmd() actúa como tracefs_synth_create(), pero en lugar de crear el evento sintético en el sistema, escribirá los comandos de eco para crearlo manualmente en el seq proporcionado.

tracefs_synth_get_start_hist() devuelve un descriptor de struct tracefs_hist que describe el histograma utilizado para crear el evento sintético.

enum tracefs_synth_handler {
        TRACEFS_SYNTH_HANDLE_MATCH,
        TRACEFS_SYNTH_HANDLE_MAX,
        TRACEFS_SYNTH_HANDLE_CHANGE,
};

tracefs_synth_get_name() devuelve el nombre del evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto del evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_raw_fmt() escribe las cadenas de formato sin procesar (evento dinámico e histogramas) del evento sintético en el seq proporcionado.

tracefs_synth_show_event() devuelve el formato del evento dinámico utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto del evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_show_start_hist() devuelve el formato del histograma de inicio utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto del evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_show_end_hist() devuelve el formato del histograma final utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto del evento synth y se libera con el evento mediante tracefs_synth_free().

La función tracefs_synth_get_event() devuelve un evento tep, que describe el evento sintético dado. La API detecta cualquier evento dinámico recién creado o eliminado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

VALOR DE RETORNO

tracefs_synth_get_name(), tracefs_synth_show_event(), tracefs_synth_show_start_hist() y tracefs_synth_show_end_hist() devuelven una cadena propiedad del objeto del evento synth.

La función tracefs_synth_get_event() devuelve un puntero a un evento tep o NULL en caso de error o si el evento sintético solicitado no está presente. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

Todas las demás funciones devuelven cero en caso de éxito y -1 en caso de error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecuta como usuario root cuando es necesario.

EINVAL Ya sea un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encuentra un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para la coincidencia o la comparación.

ENOMEM no hay suficiente memoria disponible.

Y pueden haber ocurrido más errores de las llamadas del sistema al sistema.

EJEMPLO

Consulte tracefs_sql(3) para un uso más detallado de parte de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento final */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento final */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar una diferencia de tiempo en microsegundos entre el final y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Registrar solo si "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Registrar solo si "next_prio" del evento final es menor que 50
         * o si la prioridad de la tarea anterior no era mayor o igual a 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Nota, lo anterior solo añadió: "next_prio < 50 || !(prev_prio >= 100"
         * Esto es porque, cuando se ejecute el synth, se añadirán los paréntesis
         * de cierre restantes. Es decir, la cadena terminará siendo:
         * "next_prio < 50 || !(prev_prio >= 100)" cuando se ejecute
         * tracefs_sync_create() o tracefs_sync_echo_cmd().
         */
}
/* Mostrar cómo */
/*
 * Crea el evento sintético
 */
static void show_event(void)
{
	struct trace_seq s;
	trace_seq_init(&s);
	tracefs_synth_echo_cmd(&s, synth);
	trace_seq_terminate(&s);
	trace_seq_do_printf(&s);
	trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
	make_event();
	if (argc > 1) {
		if (!strcmp(argv[1], "create")) {
			/* Crea el evento sintético */
			tracefs_synth_create(synth);
		} else if (!strcmp(argv[1], "delete")) {
			/* Elimina el evento sintético */
			tracefs_synth_destroy(synth);
		} else {
			printf("uso: %s [crear|eliminar]\n", argv[0]);
			exit(-1);
		}
	} else
		show_event();
	tracefs_synth_free(synth);
	return 0;
}
