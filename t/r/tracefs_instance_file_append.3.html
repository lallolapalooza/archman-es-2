tracefs_instance_file_append(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_file_open, tracefs_instance_file_write, tracefs_instance_file_write_number, tracefs_instance_file_append, tracefs_instance_file_clear, tracefs_instance_file_read, tracefs_instance_file_read_number - Trabajar con archivos de rastreo en instancias.

SINOPSIS

#include <tracefs.h>
int tracefs_instance_file_open(struct tracefs_instance *instance, const char *file, int mode);
int tracefs_instance_file_write(struct tracefs_instance *instance, const char *file, const char *str);
int tracefs_instance_file_write_number(struct tracefs_instance *instance, const char *file, size_t val);
int tracefs_instance_file_append(struct tracefs_instance *instance, const char *file, const char *str);
int tracefs_instance_file_clear(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_file_read(struct tracefs_instance *instance, const char *file, int *psize);
int tracefs_instance_file_read_number(struct tracefs_instance *instance, const char *file, long long int *res);

DESCRIPCIÓN

Este conjunto de APIs se puede usar para trabajar con archivos de rastreo en todas las instancias de rastreo. Cada una de estas APIs toma un argumento instance, que puede ser NULL para actuar sobre la instancia de nivel superior. De lo contrario, actúa sobre una instancia creada con tracefs_insance_create(3)

La función tracefs_instance_file_open() abre el archivo de rastreo file de la instancia dada instance y devuelve un descriptor de archivo. El modo de acceso al archivo mode se puede especificar; consulte open(3) para más detalles. Si se pasa -1 como mode, se utiliza el valor predeterminado O_RDWR.

La función tracefs_instance_file_write() escribe una cadena str en un archivo file de la instancia dada instance, sin el carácter nulo de terminación. Al abrir el archivo, esta función intenta truncar el tamaño del archivo a cero, lo que borra todas las configuraciones existentes previamente.

La función tracefs_instance_file_write_number() convierte val en una cadena y luego la escribe en el archivo dado. Esta es una función auxiliar que realiza la conversión de número a cadena y luego llama a tracefs_instance_file_write().

La función tracefs_instance_file_append() escribe una cadena str en un archivo file de la instancia dada instance, sin el carácter nulo de terminación. Esta función es similar a tracefs_instance_file_write(), pero el contenido existente del archivo no se borra. Por lo tanto, la nueva configuración se agrega a la existente (si la hubiera).

La función tracefs_instance_file_clear() intenta truncar el tamaño del archivo a cero, lo que borra todas las configuraciones existentes previamente. Si el archivo tiene contenido que no se borra de esta manera, esto no tendrá ningún efecto.

La función tracefs_instance_file_read() lee el contenido de un archivo file de la instancia dada instance.

La función tracefs_instance_file_read_number() lee el contenido de un archivo file de la instancia dada instance y lo convierte en un entero long long, que se almacena en res.

VALOR DE RETORNO

La función tracefs_instance_file_open() devuelve un descriptor de archivo al archivo abierto. Debe cerrarse con close(3). En caso de error, se devuelve -1.

La función tracefs_instance_file_write() devuelve el número de bytes escritos, o -1 en caso de error.

La función tracefs_instance_file_write_number() devuelve 0 en caso de éxito y -1 en caso de error.

La función tracefs_instance_file_append() devuelve el número de bytes escritos, o -1 en caso de error.

La función tracefs_instance_file_clear() devuelve 0 en caso de éxito, o -1 en caso de error.

La función tracefs_instance_file_read() devuelve un puntero a una cadena terminada en NULL, leída del archivo, o NULL en caso de error. La cadena devuelta debe liberarse con free().

La función tracefs_instance_file_read_number() devuelve 0 si se lee un entero válido del archivo y se almacena en res, o -1 en caso de error.

EJEMPLO

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Error al crear una nueva instancia de rastreo */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* La instancia foo soporta trace clock */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Error al obtener la ruta al archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Falló la lectura del archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Falló el establecimiento del trace clock global en la instancia foo */
                        ...
                }
        } else {
                /* La instancia foo no soporta trace clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* La instancia foo soporta opciones de rastreo */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Error al obtener la ruta al directorio options en la instancia foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* La instancia foo no soporta opciones de rastreo */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* el rastreo está deshabilitado en la instancia superior */
                } else if (res == 1) {
                        /* el rastreo está habilitado en la instancia superior */
                } else {
                        /* Estado de rastreo desconocido de la instancia superior */
                }
        } else {
                /* Falló la lectura del entero del archivo tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Obtuvo el descriptor del archivo tracing_on de la instancia superior para escribir */
                ...
                close(fd);
        }
