CTRSNA

Propósito:

!>
!> CTRSNA estima los números de condición recíprocos para valores propios
!> y/o vectores propios derechos especificados de una matriz triangular superior
!> compleja T (o de cualquier matriz Q*T*Q**H con Q unitaria).
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para
!>          valores propios (S) o vectores propios (SEP):
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para vectores propios (SEP);
!>          = 'B': para ambos, valores propios y vectores propios (S y SEP).
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A': calcular números de condición para todos los pares propios;
!>          = 'S': calcular números de condición para pares propios seleccionados
!>                 especificados por el array SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los pares propios para los cuales
!>          se requieren los números de condición. Para seleccionar los números
!>          de condición para el j-ésimo par propio, SELECT(j) debe ser .TRUE..
!>          Si HOWMNY = 'A', SELECT no se utiliza.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX, dimensión (LDT,N)
!>          La matriz triangular superior T.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX, dimensión (LDVL,M)
!>          Si JOB = 'E' o 'B', VL debe contener los vectores propios izquierdos de T
!>          (o de cualquier Q*T*Q**H con Q unitaria), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VL, tal como devueltos
!>          por CHSEIN o CTREVC.
!>          Si JOB = 'V', VL no se utiliza.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1; y si JOB = 'E' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, dimensión (LDVR,M)
!>          Si JOB = 'E' o 'B', VR debe contener los vectores propios derechos de T
!>          (o de cualquier Q*T*Q**H con Q unitaria), correspondientes a los
!>          pares propios especificados por HOWMNY y SELECT. Los vectores propios
!>          deben almacenarse en columnas consecutivas de VR, tal como devueltos
!>          por CHSEIN o CTREVC.
!>          Si JOB = 'V', VR no se utiliza.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1; y si JOB = 'E' o 'B', LDVR >= N.
!>

S

!>          S es un array REAL, dimensión (MM)
!>          Si JOB = 'E' o 'B', los números de condición recíprocos de los
!>          valores propios seleccionados, almacenados en elementos consecutivos
!>          del array. Por lo tanto, S(j), SEP(j), y las j-ésimas columnas de VL y VR
!>          corresponden al mismo par propio (pero no necesariamente al j-ésimo par
!>          propio, a menos que se seleccionen todos los pares propios).
!>          Si JOB = 'V', S no se utiliza.
!>

SEP

!>          SEP es un array REAL, dimensión (MM)
!>          Si JOB = 'V' o 'B', los números de condición recíprocos estimados de los
!>          vectores propios seleccionados, almacenados en elementos consecutivos
!>          del array.
!>          Si JOB = 'E', SEP no se utiliza.
!>

MM

!>          MM es INTEGER
!>          El número de elementos en los arrays S (si JOB = 'E' o 'B')
!>           y/o SEP (si JOB = 'V' o 'B'). MM >= M.
!>

M

!>          M es INTEGER
!>          El número de elementos de los arrays S y/o SEP realmente
!>          utilizados para almacenar los números de condición estimados.
!>          Si HOWMNY = 'A', M se establece en N.
!>

WORK

!>          WORK es un array COMPLEX, dimensión (LDWORK,N+6)
!>          Si JOB = 'E', WORK no se utiliza.
!>

LDWORK

!>          LDWORK es INTEGER
!>          La dimensión principal del array WORK.
!>          LDWORK >= 1; y si JOB = 'V' o 'B', LDWORK >= N.
!>

RWORK

!>          RWORK es un array REAL, dimensión (N)
!>          Si JOB = 'E', RWORK no se utiliza.
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles Adicionales:

!>
!> El recíproco del número de condición de un valor propio lambda se define como
!>
!>          S(lambda) = |v**H*u| / (norm(u)*norm(v))
!>
!> donde u y v son los vectores propios derechos e izquierdos de T correspondientes
!> a lambda; v**H denota la transpuesta conjugada de v, y norm(u)
!> denota la norma Euclidiana. Estos números de condición recíprocos siempre
!> están entre cero (muy mal condicionado) y uno (muy bien
!> condicionado). Si n = 1, S(lambda) se define como 1.
!>
!> Un límite de error aproximado para un valor propio calculado W(i) viene dado por
!>
!>                      EPS * norm(T) / S(i)
!>
!> donde EPS es la precisión de la máquina.
!>
!> El recíproco del número de condición del vector propio derecho u
!> correspondiente a lambda se define como sigue. Supongamos que
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!> Entonces el número de condición recíproco es
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!> donde sigma-min denota el valor singular más pequeño. Aproximamos
!> el valor singular más pequeño por el recíproco de una estimación de
!> la norma uno de la inversa de T22 - lambda*I. Si n = 1, SEP(1) es
!> definido como abs(T(1,1)).
!>
!> Un límite de error aproximado para un vector propio derecho calculado VR(i)
!> viene dado por
!>
!>                      EPS * norm(T) / SEP(i)
!>

Further Details:




 The reciprocal of the condition number of an eigenvalue lambda is
 defined as

 S(lambda) = |v**T*u| / (norm(u)*norm(v))

 where u and v are the right and left eigenvectors of T corresponding
 to lambda; v**T denotes the transpose of v, and norm(u)
 denotes the Euclidean norm. These reciprocal condition numbers always
 lie between zero (very badly conditioned) and one (very well
 conditioned). If n = 1, S(lambda) is defined to be 1.

 An approximate error bound for a computed eigenvalue W(i) is given by

 EPS * norm(T) / S(i)

 where EPS is the machine precision.

 The reciprocal of the condition number of the right eigenvector u
 corresponding to lambda is defined as follows. Suppose

 T = ( lambda  c  )
     (   0    T22 )

 Then the reciprocal condition number is

 SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )

 where sigma-min denotes the smallest singular value. We approximate
 the smallest singular value by the reciprocal of an estimate of the
 one-norm of the inverse of T22 - lambda*I. If n = 1, SEP(1) is
 defined to be abs(T(1,1)).

 An approximate error bound for a computed right eigenvector VR(i)
 is given by

 EPS * norm(T) / SEP(i)

 The reciprocal of the condition number of an eigenvalue lambda is
 defined as

 S(lambda) = |v**H*u| / (norm(u)*norm(v))

 where u and v are the right and left eigenvectors of T corresponding
 to lambda; v**H denotes the conjugate transpose of v, and norm(u)
 denotes the Euclidean norm. These reciprocal condition numbers always
 lie between zero (very badly conditioned) and one (very well
 conditioned). If n = 1, S(lambda) is defined to be 1.

 An approximate error bound for a computed eigenvalue W(i) is given by

 EPS * norm(T) / S(i)

 where EPS is the machine precision.

 The reciprocal of the condition number of the right eigenvector u
 corresponding to lambda is defined as follows. Suppose

 T = ( lambda  c  )
     (   0    T22 )

 Then the reciprocal condition number is

 SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )

 where sigma-min denotes the smallest singular value. We approximate
 the smallest singular value by the reciprocal of an estimate of the
 one-norm of the inverse of T22 - lambda*I. If n = 1, SEP(1) is
 defined to be abs(T(1,1)).

 An approximate error bound for a computed right eigenvector VR(i)
 is given by

 EPS * norm(T) / SEP(i)

Detailed Description

This routine computes the reciprocal of the condition numbers for the eigenvalues and/or right eigenvectors of a general upper triangular matrix T.

The condition number is defined as the reciprocal of the distance from the eigenvalue (or eigenvector) to the nearest other eigenvalue (or eigenpair).

Arguments:

JOBZ
CHARACTER*1
Specifies whether to compute the condition numbers for the eigenvalues and/or eigenvectors.
'E': Computes and returns the reciprocal condition numbers for the eigenvalues only.
'V': Computes and returns the reciprocal condition numbers for the right eigenvectors only.
'B': Computes and returns the reciprocal condition numbers for both the eigenvalues and the right eigenvectors.

'L': T is lower triangular.
