NOMBRE

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Crear y destruir histogramas de eventos

SINOPSIS

#include <tracefs.h>
enum tracefs_hist_key_type {
        TRACEFS_HIST_KEY_NORMAL = 0,
        TRACEFS_HIST_KEY_HEX,
        TRACEFS_HIST_KEY_SYM,
        TRACEFS_HIST_KEY_SYM_OFFSET,
        TRACEFS_HIST_KEY_SYSCALL,
        TRACEFS_HIST_KEY_EXECNAME,
        TRACEFS_HIST_KEY_LOG,
        TRACEFS_HIST_KEY_USECS,
        TRACEFS_HIST_KEY_MAX
};
struct tracefs_hist_axis {
        const char *key;
        enum tracefs_hist_key_type type;
};
struct tracefs_hist *tracefs_hist_alloc(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key, enum tracefs_hist_key_type type);
struct tracefs_hist *tracefs_hist_alloc_2d(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key1, enum tracefs_hist_key_type type1,
                        const char *key2, enum tracefs_hist_key_type type2));
struct tracefs_hist *tracefs_hist_alloc_nd(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        struct tracefs_hist_axis *axes);
struct tracefs_hist *tracefs_hist_alloc_nd_cnt(struct tep_handle *tep,
                          const char *system, const char *event_name,
                          struct tracefs_hist_axis_cnt *axes);
void tracefs_hist_free(struct tracefs_hist *hist);
int tracefs_hist_add_key(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type);
int tracefs_hist_add_key_cnt(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type, int cnt);
int tracefs_hist_add_value(struct tracefs_hist *hist, const char *value);

DESCRIPCIÓN

Los histogramas de eventos se crean mediante el archivo trigger en el directorio del evento. La sintaxis puede ser compleja y difícil de obtener correctamente. Esta API maneja la sintaxis y facilita la creación e interacción con los histogramas de eventos. Consulte https://www.kernel.org/doc/html/latest/trace/histogram.html para más información.

tracefs_hist_alloc() asigna un descriptor "struct tracefs_hist" de un histograma unidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key es un campo del evento que se utilizará como clave (dimensión) del histograma. El type es el tipo de la key. Ver TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_2d() asigna un descriptor "struct tracefs_hist" de un histograma bidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key1 es el primer campo del evento que se utilizará como clave (dimensión) del histograma. El type1 es el tipo de la key1. Ver TIPOS DE CLAVE a continuación. La key2 es el segundo campo del evento que se utilizará como clave (dimensión) del histograma. El type2 es el tipo de la key2. Ver TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_nd() asigna un descriptor "struct tracefs_hist" de un histograma N-dimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. Los axes son un array de pares key / type, que definen las dimensiones del histograma.

tracefs_hist_alloc_nd_cnt() inicializará un descriptor de histograma que se adjuntará al system/event. Esto solo inicializa el descriptor con las claves de axes dadas como primarias. Esto solo inicializa el descriptor, no inicia el histograma en el kernel. La diferencia entre esto y tracefs_hist_alloc_nd() es que el parámetro axes es de tipo struct tracefs_hist_axis_cnt y no struct tracefs_hist_axis.

tracefs_hist_free() libera el descriptor tracefs_hist. Tenga en cuenta que no detiene ni deshabilita el histograma en ejecución si se inició. Es necesario llamar a tracefs_hist_destroy() para hacerlo.

tracefs_hist_add_key() añade una clave secundaria o terciaria al histograma. La clave pasada a tracefs_hist_alloc_nd() es la clave primaria del histograma. La primera vez que se llama a esta función, añadirá una clave secundaria (o un histograma bidimensional). Si esta función se llama de nuevo en el mismo histograma, añadirá una clave terciaria (o un histograma tridimensional). El parámetro hist es el descriptor del histograma al que se añadirá la key. El type es el tipo de clave a añadir (Ver TIPOS DE CLAVE a continuación).

tracefs_hist_add_key_cnt() es igual a tracefs_hist_add_key() excepto que permite añadir un contador para el tipo dado. Actualmente, solo el tipo buckets requiere un contador. Al añadir una clave con el tipo buckets, tracefs_hist_add_key() no es suficiente, ya que el tipo buckets requiere un contador o tamaño de cubeta. Use tracefs_hist_add_key_cnt() al especificar una clave que se divide en cubetas, y pase el tamaño de esas cubetas en cnt.

tracefs_hist_add_value() añadirá un valor a registrar. Por defecto, el valor es simplemente el "hitcount" (recuento de aciertos) del número de veces que se activó una instancia de la clave del histograma. El hist es el descriptor del histograma al que se añadirá el valor. El value es un campo en el histograma que se incrementará cuando se active una instancia de la clave.

TIPOS DE CLAVE

tracefs_hist_alloc_nd() y tracefs_hist_add_key() ambos añaden una clave y requieren que esa clave tenga un tipo. Los tipos pueden ser:

TRACEFS_HIST_KEY_NORMAL o cero (0), que es para no modificar el tipo.

TRACEFS_HIST_KEY_HEX para mostrar la clave en hexadecimal.

TRACEFS_HIST_KEY_SYM para mostrar la clave como un símbolo del kernel (si se encuentra). Si la clave es una dirección, esto es útil ya que mostrará los nombres de las funciones en lugar de solo un número.

TRACEFS_HIST_KEY_SYM_OFFSET similar a TRACEFS_HIST_KEY_SYM pero también incluirá el desplazamiento de la función para que coincida con la dirección exacta.

TRACEFS_HIST_KEY_SYSCALL Si la clave es un "id" de llamada al sistema (el número que se pasa desde el espacio de usuario al kernel para indicar qué llamada al sistema se está realizando), se mostrará el nombre de la llamada al sistema.

TRACEFS_HIST_KEY_EXECNAME Si "common_pid" es la clave (el pid de la tarea en ejecución), en lugar de mostrar el número, mostrará el nombre de la tarea en ejecución.

TRACEFS_HIST_KEY_LOG mostrará la clave en una escala logarítmica binaria.

TRACEFS_HIST_KEY_USECS para usar con "common_timestamp" o TRACEFS_HIST_TIMESTAMP, en cuyo caso mostrará la marca de tiempo en microsegundos en lugar de nanosegundos.

VALOR DE RETORNO

tracefs_hist_alloc_nd() devuelve un descriptor de histograma asignado que debe ser liberado por tracefs_hist_free() o NULL en caso de error.

Todas las demás funciones devuelven cero en caso de éxito o -1 en caso de error.

Si tracefs_hist_start() devuelve un error, se puede mostrar un mensaje en el kernel que se puede recuperar con tracefs_error_last().

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Error al asignar ejes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "El tipo de clave 'buckets' requiere '=<tamaño>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Atributo indefinido '%s'\n", att);
                                fprintf(stderr,"  Atributos aceptables:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Error al crear instancia\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("No se pudieron leer los eventos");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Error al leer el archivo hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "El comando necesita la opción -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "¿No hay claves?\n");
                exit(-1);
        }
        /* buckets requiere la función nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* continuemos */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Mostrar ejemplos de hist1d y hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* En realidad, 1 y 2 también podrían usar esto */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Error al crear hist\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Error al agregar valor %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Error al agregar clave/valor de ordenación %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Error al agregar clave/valor ascendente %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Error al agregar clave/valor descendente %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW ya se realizó */
                break;
        }
        if (ret)
                fprintf(stderr, "Fallo: comando\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "uso: %s comando [-B instancia][-e [sistema/]evento][-k claves][-v valores][-s ordenación]\n", argv[0]);
                fprintf(stderr, "      [-a ascendente][-d descendente]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Comando desconocido %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

DESCRIPTION

The tracefs filesystem provides a mechanism for creating and managing histograms for kernel tracepoints. The functions described in this man page allow userspace programs to interact with these histograms.

tracefs_hist_alloc allocates memory for a new Histogram structure. The structure can then be populated with field information and registered with the kernel.

tracefs_hist_free frees the memory associated with a Histogram structure.

tracefs_hist_reset clears all fields from a Histogram structure.

tracefs_hist_get retrieves a histogram with the specified name from the kernel.

tracefs_hist_set registers or updates a histogram with the specified name in the kernel.

tracefs_hist_enable enables tracing for the specified histogram.

tracefs_hist_disable disables tracing for the specified histogram.

tracefs_hist_list returns a list of all available histogram names in the kernel.

tracefs_hist_get_name, tracefs_hist_get_nr_fields, tracefs_hist_get_field_name, tracefs_hist_get_field_type, tracefs_hist_get_field_size, and tracefs_hist_get_field_offset provide access to the properties of a histogram and its fields.

tracefs_hist_alloc_field allocates memory for a new Field structure.

tracefs_hist_free_field frees the memory associated with a Field structure.

tracefs_hist_add_field adds a field to an existing histogram.

tracefs_hist_set_field_name, tracefs_hist_set_field_type, tracefs_hist_set_field_size, and tracefs_hist_set_field_offset modify the properties of a field within a histogram.

tracefs_hist_clear_fields removes all fields from a histogram.

tracefs_hist_pause pauses the collection of data for the specified histogram.

tracefs_hist_continue resumes the collection of data for the specified histogram.

KEY TYPES

The following types are defined:

Histogram
Represents a histogram structure.
Field
Represents a field within a histogram.

RETURN VALUE

On success, most functions return a pointer to the relevant structure or 0. On failure, they return NULL or -1, and set $errno appropriately.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    Histogram *hist;
    Field *field;
    int ret;

    /* Allocate a new histogram */
    hist = tracefs_hist_alloc();
    if (!hist) {
        perror("tracefs_hist_alloc");
        return 1;
    }

    /* Allocate and add a field */
    field = tracefs_hist_alloc_field();
    if (!field) {
        perror("tracefs_hist_alloc_field");
        tracefs_hist_free(hist);
        return 1;
    }
    tracefs_hist_set_field_name(hist, 0, "my_field");
    tracefs_hist_set_field_type(hist, 0, TRACEFS_FIELD_TYPE_STRING);
    tracefs_hist_set_field_size(hist, 0, 64);
    tracefs_hist_set_field_offset(hist, 0, 0);

    ret = tracefs_hist_add_field(hist, field);
    if (ret < 0) {
        perror("tracefs_hist_add_field");
        tracefs_hist_free(hist);
        tracefs_hist_free_field(field);
        return 1;
    }

    /* Set the histogram name and register it */
    tracefs_hist_set("my_histogram", hist);

    /* Enable the histogram */
    tracefs_hist_enable("my_histogram");

    /* ... collect data ... */

    /* Disable and free the histogram */
    tracefs_hist_disable("my_histogram");
    tracefs_hist_free(hist);

    return 0;
}
