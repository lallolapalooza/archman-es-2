tracefs_synth_trace(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Creación de eventos sintéticos

SINOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos que desencadenan un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, activará el evento sintético. Los valores de los campos, aparte de los campos coincidentes, pueden pasarse del evento de inicio al evento final para realizar cálculos o simplemente pasarlos como un parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como evento de inicio. Este evento se activa cuando un proceso se despierta. Luego, establezca "sched_switch" como evento de finalización. Este evento se activa cuando una nueva tarea se programa en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Use TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o use TRACEFS_TIMESTAMP_USECS como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_create() crea el evento sintético en el sistema. Por defecto, los disparadores de histograma se crean en la instancia de rastreo superior, ya que cualquier evento sintético se puede utilizar globalmente en todas las instancias. En caso de que una aplicación quiera mantener los disparadores de histograma fuera de la instancia de nivel superior, puede usar tracefs_synth_set_instance() para que los histogramas se utilicen para crear el evento sintético en una instancia que no sea la de nivel superior. Un descriptor de evento sintético debe crearse con tracefs_synth_alloc(3) antes de que esto se pueda usar para crearlo en el sistema.

tracefs_synth_destroy() destruye el evento sintético. Intentará detener su ejecución en su instancia (la superior por defecto), pero si se está ejecutando en otra instancia, esto puede fallar por estar ocupado.

tracefs_synth_complete() devuelve verdadero si el evento sintético synth tiene un evento de inicio y uno de finalización.

tracefs_synth_trace() En lugar de hacer solo un rastreo al hacer coincidir los eventos de inicio y fin, realiza el manejador de type donde TRACEFS_SYNTH_HANDLE_MAX hará un rastreo cuando la variable dados var alcance un nuevo máximo para las claves coincidentes. O TRACEFS_SYNTH_HANDLE_CHANGE para cuando var cambie. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente cambia si TRACEFS_SYNTH_HANDLE_CHANGE, toma una "instantánea" del búfer. La instantánea mueve el búfer de "rastreo" normal a un búfer de "instantánea", al que se puede acceder a través del archivo "snapshot" en el directorio tracefs de nivel superior, o en una de las instancias. var cambia. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_save() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente cambia si TRACEFS_SYNTH_HANDLE_CHANGE, guarda la lista dada de save_fields. Los campos se almacenarán en el archivo "hist" del histograma del evento que se puede recuperar con tracefs_event_file_read(3). var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Establece la instancia de rastreo, donde se crearán los disparadores de histograma que crean el evento sintético. Por defecto, se utiliza la instancia superior. Esta API debe llamarse antes de la llamada a tracefs_synth_create(), para poder utilizar la nueva instancia al crear el evento. Tenga en cuenta que, incluso si el evento sintético se crea en una instancia, sigue siendo visible para todas las demás instancias, incluida la de nivel superior. Es decir, otras instancias pueden habilitar el evento sintético creado y hacer que se rastree en los búferes que pertenecen a la instancia que lo habilitó.

VALOR DEVUELTO

Todas las funciones devuelven cero en caso de éxito o -1 en caso de error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecutó como usuario root cuando era necesario.

EINVAL Un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encontró un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para la coincidencia o la comparación.

ENOMEM no hay suficiente memoria disponible.

Y puede que hayan ocurrido más errores de las llamadas del sistema al sistema.

EJEMPLO

Vea tracefs_sql(3) para un uso más detallado de parte de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar la diferencia de tiempo en microsegundos entre el fin y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Solo registrar si "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Solo registrar si "next_prio" del evento de fin es menor que 50
         * o la prioridad de la tarea anterior no era mayor o igual a 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL); tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE, "prev_prio", TRACEFS_COMPARE_GE, "100"); /* * Nota, lo anterior solo agregó: "next_prio < 50 || !(prev_prio >= 100" * Esto se debe a que, cuando se ejecute el synth, se agregará el paréntesis de cierre restante. * Es decir, la cadena terminará siendo: * "next_prio < 50 || !(prev_prio >= 100)" cuando se ejecute tracefs_sync_create() * o tracefs_sync_echo_cmd(). */ } /* Muestra cómo crear el evento sintético */ static void show_event(void) { struct trace_seq s; trace_seq_init(&s); tracefs_synth_echo_cmd(&s, synth); trace_seq_terminate(&s); trace_seq_do_printf(&s); trace_seq_destroy(&s); } int main (int argc, char **argv) { make_event(); if (argc > 1) { if (!strcmp(argv[1], "create")) { /* Crea el evento sintético */ tracefs_synth_create(synth); } else if (!strcmp(argv[1], "delete")) { /* Elimina el evento sintético */ tracefs_synth_destroy(synth); } else { printf("uso: %s [crear|eliminar]\n", argv[0]); exit(-1); } } else show_event(); tracefs_synth_free(synth); return 0; } ```
