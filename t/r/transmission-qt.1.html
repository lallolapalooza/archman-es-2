TRANSMISSION-QT(1) Manual de comandos generales TRANSMISSION-QT(1)

NOMBRE

transmission-qt — un cliente BitTorrent

SINOPSIS

transmission-qt -h

transmission-qt [opciones] [archivo-torrent ...]

DESCRIPCIÓN

transmission-qt es un cliente BitTorrent rápido y fácil.

BitTorrent es un protocolo de transferencia de archivos entre pares que utiliza un archivo metainfo (generalmente con extensión .torrent) y un rastreador central para distribuir datos de archivos entre un grupo de pares. Para más información sobre el protocolo BitTorrent, consulte http://www.bittorrent.org/

OPCIONES

-h --help
Mostrar opciones de ayuda.
-g --config-dir directorio
Dónde buscar los archivos de configuración. Esto se puede usar para alternar entre el uso de los clientes cli, daemon, gtk y qt. Consulte https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md para más información.
-m --minimized
Iniciar minimizado en el área de notificación.
-p --port puerto
Puerto a usar al conectarse a una sesión existente.
-r --remote host
Conectarse a una sesión existente en el host especificado.
-u --username nombre de usuario
Nombre de usuario a usar al conectarse a una sesión existente.
-v --version
Mostrar el número de versión y salir.
-w --password contraseña
Contraseña a usar al conectarse a una sesión existente.

Se pueden añadir múltiples archivos .torrent al inicio añadiéndolos en la línea de comandos. Si transmission-qt ya se está ejecutando, los torrents se añadirán a la instancia en ejecución.

AMBIENTE

TRANSMISSION_HOME
Establece el directorio de configuración por defecto.

ARCHIVOS

~/.config/transmission
El directorio de configuración utilizado cuando no se especifica ni [ TRANSMISSION_HOME ] ni [ -g ].
