TRANSMISSION-CLI(1) Manual de comandos generales TRANSMISSION-CLI(1)

NOMBRE

transmission-cli — un cliente de bittorrent

SINOPSIS

transmission-cli -h
transmission-cli [-b | -B] [-d número | -D] [-er | -ep | -et] [-f script] [-g directorio] [-h] [-m | -M] [-p puerto] [--tos tos] [-u número | -U] [-v] [-w directorio] archivo-torrent

DESCRIPCIÓN

El programa transmission-cli es un cliente BitTorrent ligero y de línea de comandos con capacidades de scripting.

Las opciones son las siguientes:

-b --blocklist
Habilita listas de bloqueo de pares. Transmission entiende el formato de archivo de lista de bloqueo bluetack. Se pueden agregar nuevas listas de bloqueo copiándolas al subdirectorio "blocklists" del directorio de configuración.
-B --no-blocklist
Deshabilita las listas de bloqueo.
-d --downlimit número
Establece la velocidad máxima de descarga en KB/s
-D --no-downlimit
No limitar la velocidad de descarga
-er --encryption-required
Cifra todas las conexiones de pares.
-ep --encryption-preferred
Prefiere conexiones de pares cifradas.
-et --encryption-tolerated
Prefiere conexiones de pares no cifradas.
-f --finish script
Establece un script para ejecutar cuando el torrent finalice
-g --config-dir directorio
Dónde buscar los archivos de configuración. Esto se puede usar para alternar entre el uso de los clientes cli, daemon, gtk y qt. Consulte https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md para obtener más información.
-h --help
Imprime un resumen de uso corto.
-m --portmap
Habilita el mapeo de puertos mediante NAT-PMP o UPnP
-M --no-portmap
Deshabilita el mapeo de puertos
-p --port puerto
Establece el puerto para escuchar a los pares entrantes. (Predeterminado: 51413)
--tos tos
Usa un nombre ToS o DSCP para establecer el tipo de servicio del socket
del par para la modelación de tráfico basada en el enrutador local.
Los valores válidos son un valor decimal 0-255, o cualquiera de estas
cadenas DSCP:

“af11”, “af12”, “af13”, “af21”, “af22”, “af23”, “af31”, “af32”, “af33”, “af41”, “af42”, “af43”, “cs0”, “cs1”, “cs2”, “cs3”, “cs4”, “cs5”, “cs6”, “cs7”, “ef”, “le” Estas claves ToS están obsoletas y serán eliminadas en el futuro: “default”, “lowcost”, “lowdelay,” “reliability”, “throughput”

-u --uplimit número
Establece la velocidad máxima de subida en KB/s
-U --no-uplimit
No limitar la velocidad de subida
-v --verify
Verifica los datos descargados del torrent.
-w --download-dir directorio
Dónde guardar los datos descargados.

SEÑALES

Además de estas opciones, el envío de una señal SIGHUP a transmission-cli contactará al rastreador para obtener más pares.

ENTORNO

TRANSMISSION_HOME
Establece el directorio de configuración predeterminado.
http_proxy
libcurl utiliza esta variable de entorno al realizar anuncios de rastreador.

ARCHIVOS

~/.config/transmission
Directorio donde transmission-cli guarda la información del torrent para futuras operaciones de siembra y reanudación.
