NOMBRE

transfig - crea un makefile para figuras portátiles de LaTeX

SINOPSIS

transfig [ -L lenguaje ] [ -M makefile ] [ -T texfile ] [ -I macrofile ] [ -V ] [ control_specs figfile ... ]

DESCRIPCIÓN

Transfig crea un makefile para traducir figuras descritas en código Fig o PIC a un lenguaje de gráficos LaTeX especificado. Los archivos PIC se identifican por el sufijo ".pic"; los archivos Fig se pueden especificar con o sin el sufijo ".fig". Transfig también crea un archivo de macros TeX apropiado para el lenguaje de destino.

OPCIONES

El especificador de lenguaje debe ser uno de box, cgm, eepic, eepicemu, emf, epic, eps, ge, gif, ibmgl, jpeg, latex, map, mf, mmp, mp, pcx, pdf, pdftex, pdftex_t, pic, pictex, png, ppm, ps, psfig, pstex, pstex_t, ptk, sld, textyl, tiff, tk, tpic, xbm, xpm o null. El especificador psfig es como el especificador ps, excepto que utiliza el paquete de macros psfig. El especificador pstex es como psfig, excepto que utiliza LaTeX para procesar texto formateado (especial). El especificador null da como resultado que las figuras se reemplacen por cajas vacías del tamaño apropiado. Si no se especifica ningún lenguaje, el predeterminado es epic.

Los nombres del makefile y del archivo de macros TeX se pueden establecer con las opciones -M y -T. Los nombres predeterminados son "Makefile" y "transfig.tex", respectivamente. Si ya existe un makefile en el directorio, transfig primero lo renombra a makefile~. Lo mismo ocurre con cualquier archivo de macros TeX existente. Si se especifica la opción -I, se inserta un comando para leer macrofile en el archivo de macros TeX. Si se especifica la opción -V, solo se imprime el número de versión del programa.

Los especificadores de control son

-m mag
establece la magnificación a la que se renderiza la figura (predeterminado 1.0).
-f fuente
establece la familia de fuentes predeterminada utilizada para los objetos de texto (predeterminado "rm").
-s tamaño
establece el tamaño de fuente predeterminado (en puntos) para los objetos de texto (predeterminado 11*mag).
-o opción
pasa la cadena de opción especificada a fig2dev.

Si no hay escalado, la fuente predeterminada es una fuente romana de once puntos. Los especificadores de lenguaje y control pueden aparecer más de una vez; afectan la traducción de los archivos que aparecen a su derecha en la lista de argumentos. Si no se especifican archivos, se asume "*.fig".
