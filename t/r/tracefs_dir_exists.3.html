NOMBRE

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Trabajar con archivos y directorios en instancias de rastreo.

SINOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para trabajar con archivos de rastreo en todas las instancias de rastreo. Cada una de estas APIs toma un argumento instance, que puede ser NULL para actuar en la instancia de nivel superior. De lo contrario, actúa sobre una instancia creada con tracefs_insance_create(3)

La función tracefs_file_exists() comprueba si existe un archivo con el nombre en la instancia.

La función tracefs_dir_exists() comprueba si existe un directorio con el nombre en la instancia.

La función tracefs_instance_get_file() devuelve la ruta completa del archivo con el nombre dado en la instancia. Nota: no comprueba si el archivo existe en la instancia.

La función tracefs_instance_get_dir() devuelve la ruta completa del directorio con el nombre dado en la instancia. Nota: no comprueba si el directorio existe en la instancia.

VALOR DE RETORNO

Las funciones tracefs_file_exists() y tracefs_dir_exists() devuelven true si el archivo/directorio existe en la instancia dada o false si no existe.

Las funciones tracefs_instance_get_file() y tracefs_instance_get_dir() devuelven una cadena o NULL en caso de error. La cadena devuelta debe liberarse con tracefs_put_tracing_file().

EJEMPLO

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Error al crear una nueva instancia de rastreo */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* La instancia foo soporta trace clock */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Error al obtener la ruta del archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Falló la lectura del archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Falló el establecimiento del reloj de rastreo global en la instancia foo */
                        ...
                }
        } else {
                /* La instancia foo no soporta trace clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* La instancia foo soporta opciones de rastreo */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Error al obtener la ruta del directorio de opciones en la instancia foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* La instancia foo no soporta opciones de rastreo */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* el rastreo está deshabilitado en la instancia superior */
                } else if (res == 1) {
                        /* el rastreo está habilitado en la instancia superior */
                } else {
                        /* Estado de rastreo desconocido de la instancia superior */
                }
        } else {
                /* Falló la lectura del entero del archivo tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Se obtuvo el descriptor de archivo del archivo tracing_on de la instancia superior para escritura */
                ...
                close(fd);
        }

tracefs_dir_exists(3)

tracefs_dir_exists - Query if a tracefs directory exists

Library

libtracefs

Synopsis

#include <tracefs.h>

int tracefs_dir_exists(const char *name);

Description

Checks if the directory with the given name exists within the tracefs filesystem. This function looks for a directory with the given name in the root of the tracefs filesystem.

Parameters

name
The name of the directory to check for.

Return value

Returns 1 if the directory exists, 0 if it does not exist, and -1 if an error occurred.

Example

#include <stdio.h>
#include <tracefs.h>

int main() {
    if (tracefs_dir_exists("events/sched")) {
        printf("The 'events/sched' directory exists.\n");
    } else {
        printf("The 'events/sched' directory does not exist.\n");
    }
    return 0;
}

See also

tracefs_is_mounted(3), tracefs_get_trace_dir(3)
