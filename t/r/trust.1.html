TRUST(1) User Commands TRUST(1)

NOMBRE

trust - Herramienta para operar en el almacén de políticas de confianza

SINOPSIS

trust list

trust extract --filter=<qué> --format=<tipo> /ruta/al/destino

trust anchor /ruta/al/certificado.crt

trust dump

trust check-format /ruta/al/archivo.p11-kit...

DESCRIPCIÓN

trust es una herramienta de línea de comandos para examinar y modificar el almacén compartido de políticas de confianza.

Vea los diversos subcomandos a continuación. Se pueden usar las siguientes opciones globales:

-v, --verbose

Ejecutar en modo detallado con salida de depuración.

-q, --quiet

Ejecutar en modo silencioso sin mensajes de advertencia o error.

LISTAR

Listar los elementos del almacén de políticas de confianza.

$ trust list

Lista información sobre los diversos elementos en el almacén de políticas de confianza. Cada elemento se lista con su URI PKCS#11 y alguna información descriptiva.

Puede especificar las siguientes opciones para controlar qué listar.

--filter=<qué>

Especifica qué certificados extraer. Puede especificar los siguientes valores:

ca-anchors

Anclajes de certificados

trust-policy

Anclajes y lista de bloqueo (por defecto)

blocklist

Certificados no confiables

certificates

Todos los certificados

pkcs11:object=xx

Un URI PKCS#11 para filtrar

Si se elige un formato de salida que no puede admitir el tipo especificado por el filtro, se imprimirá un mensaje.

Ninguno de los formatos disponibles admite el almacenamiento de entradas de lista de bloqueo que no contengan un certificado completo. Por lo tanto, cualquier certificado que no sea de confianza por su emisor y número de serie solos, no se incluye en la lista de bloqueo extraída.

--purpose=<uso>

Limitar a los certificados utilizables para el uso dado. Puede especificar uno de los siguientes valores:

server-auth

Para autenticar servidores

client-auth

Para autenticar clientes

email

Para protección de correo electrónico

code-signing

Para código firmado autenticado

1.2.3.4.5...

Un OID de propósito arbitrario

ANCLAJE

Almacenar o eliminar anclajes de confianza.

$ trust anchor /ruta/al/certificado.crt
$ trust anchor --remove /ruta/al/certificado.crt
$ trust anchor --remove "pkcs11:id=%AA%BB%CC%DD%EE;type=cert"

Almacena o elimina anclajes de confianza en el almacén de políticas de confianza. Estos suelen ser autoridades de certificación raíz.

Especifique las operaciones --store o --remove. Si no se especifica ninguna operación, se asume --store.

Al almacenar, se esperan uno o más archivos de certificado en la línea de comandos. Estos se almacenan como anclajes, a menos que ya estén presentes.

Al eliminar un anclaje, especifique archivos de certificado o URIs PKCS#11 en la línea de comandos. Se eliminarán los anclajes coincidentes.

Es posible que este comando necesite ejecutarse como root para modificar el almacén de políticas de confianza del sistema, si no hay un almacén específico para el usuario disponible.

Puede especificar las siguientes opciones.

--remove

Elimina uno o más anclajes del almacén de políticas de confianza. Especifique archivos de certificado o URIs PKCS#11 en la línea de comandos.

--store

Almacena uno o más anclajes en el almacén de políticas de confianza. Especifique archivos de certificado en la línea de comandos.

EXTRAER

Extrae la política de confianza del almacén compartido de políticas de confianza.

$ trust extract --format=x509-directory --filter=ca-anchors /ruta/al/directorio

Puede especificar las siguientes opciones para controlar qué extraer. Se deben especificar los argumentos --filter y --format. Por defecto, este comando no sobrescribirá el archivo o directorio de destino.

--comment

Agrega comentarios identificativos a los archivos de salida del paquete PEM antes de cada certificado.

--filter=<qué>

Especifica qué certificados extraer. Puede especificar los siguientes valores:

ca-anchors

Anclajes de certificados (por defecto)

trust-policy

Anclajes y lista de bloqueo

blocklist

Certificados no confiables

certificates

Todos los certificados

pkcs11:object=xx

Un URI PKCS#11

Si se elige un formato de salida que no puede admitir el tipo especificado por el filtro, se imprimirá un mensaje.

Ninguno de los formatos disponibles admite el almacenamiento de entradas de lista de bloqueo que no contengan un certificado completo. Por lo tanto, cualquier certificado que no sea de confianza por su emisor y número de serie solos, no se incluye en la lista de bloqueo extraída.

--format=<tipo>

El formato del archivo o directorio de destino. Puede especificar uno de los siguientes valores:

x509-file

Archivo de certificado DER X.509

x509-directory

Directorio de certificados X.509

pem-bundle

Archivo que contiene uno o más bloques de certificado PEM

pem-directory

Directorio de archivos PEM que contienen cada uno un certificado

pem-directory-hash

Directorio de archivos PEM que contienen cada uno un certificado, con enlaces simbólicos hash

openssl-bundle

Paquete de certificados PEM específico de OpenSSL

openssl-directory

Directorio de archivos PEM específicos de OpenSSL

java-cacerts

Paquete de certificados 'cacerts' del almacén de claves de Java

--overwrite

Sobrescribir el archivo o directorio de salida.

--purpose=<uso>

Limitar a los certificados utilizables para el uso dado. Puede especificar uno de los siguientes valores:

server-auth

Para autenticar servidores

client-auth

Para autenticar clientes

email

Para protección de correo electrónico

code-signing

Para código firmado autenticado

1.2.3.4.5...

Un OID de propósito arbitrario

EXTRACT_COMPAT

Extraer paquetes de certificados de confianza de compatibilidad.

$ trust extract-compat

OpenSSL, Java y algunas versiones de GnuTLS no pueden leer actualmente la información de confianza directamente del almacén de políticas de confianza. Este comando extrae información de confianza, como anclajes de certificados, para su uso por estas bibliotecas.

Lo que hace este comando y dónde extrae los archivos es específico de la distribución o del sitio. Se espera que los empaquetadores o administradores personalicen este comando.

VOLCAR

Volcar elementos PKCS#11 en los diversos tokens.

$ trust dump

Volca información sobre los diversos elementos PKCS#11 en los tokens. Cada elemento se vuelca con su URI PKCS#11 e información en el formato de persistencia .p11-kit.

Puede especificar las siguientes opciones para controlar qué volcar.

--filter=<qué>

Especifica qué certificados extraer. Puede especificar los siguientes valores:

all

Todos los objetos. Este es el valor por defecto.

pkcs11:object=xx

Un URI PKCS#11 para filtrar

CHECK_FORMAT

Verificar el formato de los archivos de almacén de políticas de confianza.

$ trust check-format /etc/pki/trust-policy/

Verifica que el formato de los archivos del almacén de políticas de confianza sea correcto. Devuelve 0 si el formato es correcto y cualquier otro valor en caso de error.

VERIFICAR FORMATO

Verifica el formato de los archivos .p11-kit.

$ trust check-format /ruta/al/archivo.p11-kit...

Los administradores a veces necesitan escribir un archivo .p11-kit personalizado para modificar la información de confianza. Este es un proceso propenso a errores ya que el formato del archivo es principalmente para procesamiento de máquina. Los administradores pueden usar este comando para verificar si un archivo tiene un formato .p11-kit correcto.

Este comando toma un número arbitrario de archivos como entrada. Cada archivo se analiza y cualquier discrepancia con el formato .p11-kit se informa en la salida de error estándar. Después de procesar el archivo, se imprime un resultado de verificación en la salida estándar.
