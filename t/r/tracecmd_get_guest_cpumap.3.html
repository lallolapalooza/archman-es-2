tracecmd_get_guest_cpumap(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_get_traceid, tracecmd_get_guest_cpumap - Gestionar sesiones de rastreo con múltiples pares de rastreo, registradas en múltiples archivos de rastreo.

SINOPSIS

#include <trace-cmd.h>
unsigned long long tracecmd_get_traceid(struct tracecmd_input *handle);
int tracecmd_get_guest_cpumap(struct tracecmd_input *handle, unsigned long long trace_id, const char **name, int *vcpu_count, const int **cpu_pid);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para gestionar una sesión de rastreo con varios pares de rastreo, por ejemplo, rastreando tanto un host como una o más máquinas virtuales invitadas. Los datos de rastreo de cada par de la sesión se registran en archivos de rastreo separados. La información sobre los pares de la sesión se almacena en los metadatos de cada archivo de rastreo. Estas APIs utilizan esa información para extraer y sincronizar los datos de rastreo.

La función tracecmd_get_traceid() devuelve el ID de rastreo almacenado en los metadatos del archivo de rastreo asociado con handle. Cada par de una sesión de rastreo tiene un ID único para ese par y solo para esa sesión de rastreo. Este ID se utiliza para emparejar múltiples archivos de rastreo registrados en la misma sesión de rastreo.

La función tracecmd_get_guest_cpumap() obtiene el mapeo de las CPUs virtuales invitadas (VCPU) al proceso host que representa esas VCPUs y que se almacena en los metadatos del archivo de rastreo asociado con handle. Esta información se recopila durante una sesión de rastreo host-invitado y se almacena en el archivo de rastreo del host. El parámetro trace_id es el ID de rastreo del invitado en esta sesión de rastreo particular. Si un invitado con ese ID formó parte de esa sesión, su mapeo de VCPU a proceso host está en el archivo de rastreo del host y la información se devuelve en los parámetros name, vcpu_count y cpu_pid. El parámetro name contiene el nombre del invitado, vcpu_count contiene el número de VCPUs de ese invitado y la matriz cpu_pid contiene el mapeo de VCPU a proceso host. La matriz es de tamaño vcpu_count, donde el índice es la VCPU y el valor es el ID del proceso (PID) del proceso host que ejecuta esa VCPU. Los valores de name, vcpu_count y cpu_pid no deben ser liberados.

VALOR DE RETORNO

La función tracecmd_get_traceid() devuelve un ID de rastreo de 64 bits.

La función tracecmd_get_guest_cpumap() devuelve -1 en caso de error o 0 en caso contrario. Si se devuelve 0, los parámetros name, vcpu_count y cpu_pid contienen la información solicitada.

EJEMPLO

#include <trace-cmd.h>
...
struct tracecmd_input *host = tracecmd_open("trace.dat");
        if (!host) {
                /* Error al abrir el archivo de rastreo del host */
        }
struct tracecmd_input *guest1 = tracecmd_open_head("trace-Guest1.dat");
        if (!guest1) {
                /* Error al abrir el archivo de rastreo del invitado1 */
        }
struct tracecmd_input *guest2 = tracecmd_open_head("trace-Guest2.dat");
        if (!guest2) {
                /* Error al abrir el archivo de rastreo del invitado2 */
        }
unsigned long long guest_id_1 = tracecmd_get_traceid(guest1);
unsigned long long guest_id_2 = tracecmd_get_traceid(guest2);
int *cpu_pid_1, *cpu_pid_2;
int vcount_1, vcount_2;
char *name_1, *name_2;
        if (!tracecmd_get_guest_cpumap(host, guest_id_1, &name_1, &vcount_1, &cpu_pid_1)) {
                /* El host y un invitado1 con name_1 forman parte de la misma sesión de rastreo.
                 * Se obtuvo el mapeo VCPU a PID del host del invitado1.
                 */
        }
        if (!tracecmd_get_guest_cpumap(host, guest_id_2, &name_2, &vcount_2, &cpu_pid_2)) {
                /* El host y un invitado2 con name_2 forman parte de la misma sesión de rastreo.
                 * Se obtuvo el mapeo VCPU a PID del host del invitado2.
                 */
        }
...
        tracecmd_close(guest1);
        tracecmd_close(guest2);
        tracecmd_close(handle);
