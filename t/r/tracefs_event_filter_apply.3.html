NOMBRE

tracefs_filter_string_append, tracefs_filter_string_verify, tracefs_event_filter_apply, tracefs_event_filter_clear - Añadir, verificar y aplicar filtros de eventos

SINOPSIS

#include <tracefs.h>
int tracefs_filter_string_append(struct tep_event *event, char **filter,
                                 struct tracefs_filter type, const char *field,
                                 enum tracefs_synth_compare compare, const char *val);
int tracefs_filter_string_verify(struct tep_event *event, const char *filter, char **err);
int tracefs_event_filter_apply(struct tracefs_instance *instance, struct tep_event *event, const char *filter);
int tracefs_event_filter_clear(struct tracefs_instance *instance, struct tep_event *event);

DESCRIPCIÓN

tracefs_filter_string_append() es una forma de crear y verificar filtros de eventos para un evento dado. Verificará que el campo pertenece al evento y que la opción de comparación que se utiliza es válida para el tipo del campo, así como para val. Para el tipo que no sea de TRACEFS_FILTER_COMPARE, construirá la cadena lógica y también se asegurará de que la sintaxis sea correcta. Por ejemplo, que no haya más paréntesis de cierre que de apertura. Que un AND (&&) o un OR (||) no estén mal colocados, etc.

tracefs_synth_append_start_filter() crea un filtro o le añade contenido para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede añadir una comparación de field con val basándose en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Añadir "&&" al filtro TRACEFS_FILTER_OR - Añadir "||" al filtro TRACEFS_FILTER_NOT - Añadir "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añadir "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añadir ")" al filtro

field, compare, y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, en cuyo caso _compare se utilizará para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de flags.

tracefs_filter_string_verify() analizará filter para asegurarse de que los campos pertenecen al event y que la sintaxis es correcta. Si hay un error en la sintaxis, y err no es NULL, se asignará memoria con un mensaje de error que indique qué salió mal con el filtro. err debe ser liberado con free().

tracefs_event_filter_apply() aplica la cadena de filter dada en el event en la instance dada.

tracefs_event_filter_clear() borra todos los filtros en el event en la instance dada.

VALOR DE RETORNO

tracefs_filter_string_append() devuelve 0 en caso de éxito y -1 en caso de error.

tracefs_filter_string_verify() devuelve 0 en caso de éxito y -1 en caso de error. Si hay un error, y errno no es ENOMEM, se asignará memoria a err y contendrá una cadena que describe lo que estaba mal con filter. err debe ser liberado con free().

tracefs_event_filter_apply() devuelve 0 en caso de éxito y -1 en caso de error.

tracefs_event_filter_clear() devuelve 0 en caso de éxito y -1 en caso de error.

NAME


tracefs_event_filter_apply, tracefs_event_filter_apply_all, tracefs_event_filter_delete - Apply and delete filters for trace events






SYNOPSIS


#include <tracefs.h>

int
tracefs_event_filter_apply(struct tep_handle *tep, struct tep_event *event,
    const char *filter);
int
tracefs_event_filter_apply_all(struct tep_handle *tep, const char *filter);
int
tracefs_event_filter_delete(struct tep_handle *tep, struct tep_event *event,
    const char *filter);







DESCRIPTION


The tracefs_event_filter_apply function
    applies a filter string to a specific trace event. The event is identified by
    its name and the handle used to access the tracefs library. The filter string
    is a comma separated list of conditions that can match a trace event. A
    condition is of the form: <field> [operator] <value>.
    For example: syscall=open,
    pid != 123, comm ~ "bash*".


The tracefs_event_filter_apply_all function
    applies the given filter string to all trace events.


The tracefs_event_filter_delete function
    removes the filter string from the specified trace event or all trace events
    if event is NULL.


A filter string is a comma separated list of conditions. Each
    condition applies to a specific field of a trace event. The operators can
    be:



  
=

  
Equal to

  
!=

  
Not equal to

  
<

  
Less than

  
<=

  
Less than or equal to

  
>

  
Greater than

  
>=

  
Greater than or equal to

  
~

  
Matches a regular expression (see regex(7))

  
!~

  
Does not match a regular expression




If no operator is specified, it defaults to '='.


Fields that can be filtered include:



  
event

  
The name of the trace event.

  
common_cpu

  
The CPU core number.

  
common_pid

  
The process ID.

  
common_tgid

  
The thread group ID.

  
common_ppid

  
The parent process ID.

  
common_name

  
The name of the process.

  
common_flags

  
Flags.

  
common_preempt_count

  
Preemption count.

  
common_lock_depth

  
Lock depth.

  
common_irq_count

  
Interrupt count.

  
common_syscall_depth

  
Syscall depth.

  
common_host

  
The hostname.




User-defined fields for specific events are also available. For
    example, for the syscalls:sys_enter_open event, you can
    filter by filename.


Special values can be used:



  
"*"

  
Matches any value.

  
"NULL"

  
Matches NULL value.




Strings can be quoted with single or double quotes. Backslashes
    can be used to escape quotes and backslashes within strings.


The tracefs_event_filter_apply function uses
    the tracefs_filter_string_append function internally
    to parse the filter string and build a filter object. The filter object is
    then applied to the event.


If tep is NULL, the default tracefs handle
    is used.






RETURN VALUE


On success, tracefs_event_filter_apply,
    tracefs_event_filter_apply_all, and
    tracefs_event_filter_delete return 0. On failure, they
    return -1 and set errno appropriately.






EXAMPLE




#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main(int argc, char **argv) {
        struct tep_handle *tep;
        struct tep_event *event;
        char *new_filter;
        char val[256];
        const char *filter_str = "syscall=open,pid!=123,comm ~ \"bash*\"";
        int i = 0, n, start_i, quote, backslash, compare = TRACEFS_COMPARE_EQ;
        char type = 's', field[256];

        tep = tep_alloc(NULL, NULL);
        if (!tep) {
                fprintf(stderr, "Failed to allocate tep handle\n");
                return -1;
        }

        event = tep_get_event_by_name(tep, "syscalls:sys_enter_open");
        if (!event) {
                fprintf(stderr, "Failed to find event syscalls:sys_enter_open\n");
                tep_free(tep);
                return -1;
        }

        new_filter = NULL;
        while(filter_str[i]) {
                while(isspace(filter_str[i]))
                        i++;
                start_i = i;
                while(filter_str[i] && filter_str[i] != ',' && !isspace(filter_str[i]))
                        i++;
                n = i - start_i;
                strncpy(field, filter_str + start_i, n);
                field[n] = '\0';

                if (filter_str[i] == ',') {
                        compare = TRACEFS_COMPARE_EQ;
                        type = 's';
                } else {
                        if (filter_str[i+1] == '=') {
                                switch(filter_str[i]) {
                                case '<':
                                        compare = TRACEFS_COMPARE_LE;
                                        break;
                                case '>':
                                        compare = TRACEFS_COMPARE_GE;
                                        break;
                                case '!':
                                        compare = TRACEFS_COMPARE_NE;
                                        break;
                                case '~':
                                        compare = TRACEFS_COMPARE_REGEXP;
                                        break;
                                default:
                                        compare = TRACEFS_COMPARE_EQ;
                                }
                                i++; /* Skip the '=' */
                        } else {
                                switch(filter_str[i]) {
                                case '<':
                                        compare = TRACEFS_COMPARE_LT;
                                        break;
                                case '>':
                                        compare = TRACEFS_COMPARE_GT;
                                        break;
                                case '!':
                                        compare = TRACEFS_COMPARE_NE;
                                        break;
                                case '~':
                                        compare = TRACEFS_COMPARE_REGEXP;
                                        break;
                                default:
                                        compare = TRACEFS_COMPARE_EQ;
                                }
                        }
                        i++; /* Skip the operator */
                        while(isspace(filter_str[i]))
                                i++;
                        quote = 0;
                        backslash = false;
                        start_i = i;
                        for (; filter_str[i]; i++) {
                                if (quote) {
                                        if (backslash)
                                                backslash = false;
                                        else if (filter_str[i] == '\\')
                                                backslash = true;
                                        else if (filter_str[i] == quote)
                                                quote = 0;
                                        continue;
                                }
                                switch(filter_str[i]) {
                                case '"': case ''':
                                        quote = filter_str[i];
                                        continue;
                                case 'a' ... 'z':
                                case 'A' ... 'Z':
                                case '0' ... '9':
                                case '_':
                                        continue;
                                }
                                break;
                        }
                        n = i - start_i;
                        strncpy(val, filter_str + start_i, n);
                        val[n] = '\0';
                        if (strcmp(field, "pid") == 0 || strcmp(field, "common_pid") == 0 ||
                            strcmp(field, "common_tgid") == 0 || strcmp(field, "common_ppid") == 0 ||
                            strcmp(field, "common_cpu") == 0 || strcmp(field, "common_flags") == 0 ||
                            strcmp(field, "common_preempt_count") == 0 ||
                            strcmp(field, "common_lock_depth") == 0 ||
                            strcmp(field, "common_irq_count") == 0 ||
                            strcmp(field, "common_syscall_depth") == 0) {
                                type = 'n'; /* Numeric */
                        } else if (strcmp(field, "event") == 0 || strcmp(field, "common_name") == 0 ||
                                   strcmp(field, "common_host") == 0) {
                                type = 's'; /* String */
                        } else {
                                /* Assume it is a string field unless specified otherwise */
                                type = 's';
                        }
                        if (strcmp(field, "event") == 0) {
                                field[n] = '\0';
                                event = tep_get_event_by_name(tep, val);
                                if (!event) {
                                        fprintf(stderr, "Failed to find event %s\n", val);
                                        tep_free(tep);
                                        return -1;
                                }
                                continue; /* Apply filter to the new event */
                        }
                }
                n = tracefs_filter_string_append(event, &new_filter, type,
                                                field, compare, val);
                if (n < 0) {
                        fprintf(stderr, "Failed making new filter:\n'%s'\n",
                                new_filter ? new_filter : "(null)");
                        exit(-1);
                }
                if (filter_str[i] == ',')
                        i++; /* Skip the comma */
        }
        if (tracefs_event_filter_apply(tep, event, new_filter))
                fprintf(stderr, "Failed to apply filter on event");
        tep_free(tep);
        printf("Created new filter: '%s'\n", new_filter);
        free(new_filter);
        exit(0);
}
