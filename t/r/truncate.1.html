TRUNCATE(1) Comandos de usuario TRUNCATE(1)

NOMBRE

truncate - reducir o extender el tamaño de un archivo al tamaño especificado

SINOPSIS

truncate OPCIÓN... ARCHIVO...

DESCRIPCIÓN

Reduce o extiende el tamaño de cada ARCHIVO al tamaño especificado

Un argumento ARCHIVO que no existe se crea.

Si un ARCHIVO es más grande que el tamaño especificado, los datos adicionales se pierden. Si un ARCHIVO es más corto, se extiende y la parte extendida dispersa (agujero) se lee como cero bytes.

Los argumentos obligatorios para las opciones largas son obligatorios para las opciones cortas también.

-c, --no-create
no crear ningún archivo
-o, --io-blocks
tratar TAMAÑO como número de bloques de E/S en lugar de bytes
-r, --reference=ARCHIVO_REF
basar el tamaño en ARCHIVO_REF
-s, --size=TAMAÑO
establecer o ajustar el tamaño del archivo en TAMAÑO bytes
--help
mostrar esta ayuda y salir
--version
mostrar información de la versión y salir

El argumento TAMAÑO es un entero y una unidad opcional (ejemplo: 10K es 10*1024). Las unidades son K,M,G,T,P,E,Z,Y,R,Q (potencias de 1024) o KB,MB,... (potencias de 1000). También se pueden usar prefijos binarios: KiB=K, MiB=M, y así sucesivamente.

TAMAÑO también puede ir precedido por uno de los siguientes caracteres modificadores: '+' extender en, '-' reducir en, '<' como máximo, '>' como mínimo, '/' redondear hacia abajo a un múltiplo de, '%' redondear hacia arriba a un múltiplo de.
