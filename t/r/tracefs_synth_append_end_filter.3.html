DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos diferentes, lo que activa un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coinciden con el campo (o campos) del evento de inicio, se activará el evento sintético. Los valores de los campos, aparte de los campos coincidentes, pueden pasarse del evento de inicio al evento final para realizar cálculos sobre ellos, o simplemente pasarlos como parámetros al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, se establece "sched_switch" como el evento final. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo transcurrido entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice *TRACEFS_TIMESTAMP_USECS" como campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_alloc() asigna e inicializa un evento sintético. No crea el evento sintético, sino que proporciona la información mínima para hacerlo. Consulte tracefs_synth_create(3) para saber cómo crear el evento sintético en el sistema. Requiere un manejador tep que se puede crear mediante tracefs_local_events(3) para más información. El name contiene el nombre del evento sintético que se creará. El start_system es el nombre del sistema para el evento de inicio. Puede ser NULL y se elegirá el primer evento con el nombre start_event. El end_system es el nombre del sistema para el evento final. Puede ser NULL y se elegirá el primer evento con el nombre end_event como evento final. Si se proporciona match_name, este será el campo del evento sintético creado que contendrá las claves coincidentes del start_match_field del evento de inicio y el end_match_field del evento final. Si match_name es NULL, no se registrará en el evento sintético creado.

tracefs_synth_add_match_field() añadirá una segunda clave para que coincida entre el evento de inicio y el evento final. Si se proporciona name, el contenido del campo coincidente se guardará con este name en el evento sintético. El start_match_field es el campo del evento de inicio que coincide con el end_match_field del evento final.

tracefs_synth_add_compare_field() se utiliza para comparar el start_compare_field del evento de inicio con el end_compare_field del evento final. Se debe proporcionar el name para que el resultado se guarde en el evento sintético. No tiene sentido no pasar esto al evento sintético después de realizar el trabajo de los campos comparados, ya que no tiene otro propósito. El parámetro calc puede ser uno de:

TRACEFS_SYNTH_DELTA_END - calcula la diferencia entre el contenido en end_compare_field y el contenido de start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcula la diferencia entre el contenido en start_compare_field y el contenido de end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Suma el contenido de start_compare_field al contenido de end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Registra el start_field del evento de inicio como name en el evento sintético. Si name es NULL, el nombre utilizado será el mismo que start_field.

tracefs_synth_add_end_field() - Registra el end_field del evento final como name en el evento sintético. Si name es NULL, el nombre utilizado será el mismo que end_field.

tracefs_synth_append_start_filter() crea un filtro o lo añade para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede añadir una comparación de field con val basada en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Añade "&&" al filtro TRACEFS_FILTER_OR - Añade "||" al filtro TRACEFS_FILTER_NOT - Añade "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añade "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añade ")" al filtro

field, compare y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces se usará _compare para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de flags.

tracefs_synth_append_end_filter() es lo mismo que tracefs_synth_append_start_filter pero filtra en el evento final.

tracefs_synth_free() libera el descriptor asignado devuelto por tracefs_synth_alloc().

DESCRIPTION

A synthetic event is an event created from existing events. The purpose is to simplify the creation of tracepoints that are not directly available but can be derived from the combination of other tracepoints.

For example, we might want to know the latency between a task being woken up and it starting to run. The wake up event (e.g. sched_waking) and the context switch event (e.g. sched_switch) can be combined to create such a synthetic event.

The synthetic event creation is a two step process:

  • Configuration: Use the functions tracefs_synth_alloc() through tracefs_synth_append_end_filter() to define the synthetic event. This step is done in user space.

  • Creation/Execution: Use tracefs_synth_create() to create the synthetic event in the kernel, or tracefs_synth_echo_cmd() to get the command that would create the event and print it to stdout (which can be piped to trace-cmd to execute it).

tracefs_synth_alloc() allocates and initializes a tracefs_synth structure for a new synthetic event named name. The aux_name is optional and is used when the synthetic event is composed of multiple start/end events.

The synthetic event will be triggered when start_event occurs. The trigger will match a previous event based on start_field and end_field. The match will be performed using match_name. The end_event is the event that completes the synthetic event.

tracefs_synth_free() frees the tracefs_synth structure. The synthetic event itself is not destroyed from the kernel.

tracefs_synth_create() creates the synthetic event in the kernel. The event will be available in tracefs under /sys/kernel/debug/tracing/events/.../synthetic_name. The tracefs_synth structure is not freed.

tracefs_synth_destroy() destroys the synthetic event from the kernel.

tracefs_synth_add_start_field() adds a field from the start event to be saved in the synthetic event. If new_name is provided, the field will be renamed. Otherwise, it keeps the original name.

tracefs_synth_add_end_field() adds a field from the end event to be saved in the synthetic event. If new_name is provided, the field will be renamed. Otherwise, it keeps the original name.

tracefs_synth_add_compare_field() adds a calculated field to the synthetic event. The value is calculated by comparing a field from the start event (start_type) and a field from the end event (end_type) using the operation op. The result is stored under the name new_name.

Possible values for start_type and end_type are defined in tracefs.h, e.g.:

TRACEFS_TIMESTAMP_USECS
TRACEFS_TIMESTAMP_NS
TRACEFS_EVENT_FIELD(field_name)

Possible values for op are defined in tracefs.h, e.g.:

TRACEFS_COMPARE_EQ
TRACEFS_COMPARE_NE
TRACEFS_COMPARE_LT
TRACEFS_COMPARE_LE
TRACEFS_COMPARE_GT
TRACEFS_COMPARE_GE
TRACEFS_SYNTH_DELTA_END (calculates end - start)

tracefs_synth_append_start_filter() and tracefs_synth_append_end_filter() append filters to the synthetic event's start and end events respectively. The filter restricts when the synthetic event is created. Filters are appended in order and processed with logical operators.

Possible values for type are defined in tracefs.h, e.g.:

TRACEFS_FILTER_COMPARE
TRACEFS_FILTER_OPEN_PAREN
TRACEFS_FILTER_CLOSE_PAREN
TRACEFS_FILTER_AND
TRACEFS_FILTER_OR
TRACEFS_FILTER_NOT

tracefs_synth_echo_cmd() prints the command that would create the synthetic event to the given trace_seq structure. This can be used to generate the command line for trace-cmd.

tracefs_synth_show_event() prints the definition of the synthetic event to the given trace_seq structure.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_synth_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
