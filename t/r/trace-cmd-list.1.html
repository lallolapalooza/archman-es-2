TRACE-CMD-LIST(1) Manual de libtracefs TRACE-CMD-LIST(1)

NOMBRE

trace-cmd-list - lista los plugins, eventos u opciones de Ftrace disponibles.

SINOPSIS

trace-cmd list [OPCIONES]

DESCRIPCIÓN

trace-cmd(1) list muestra los plugins, eventos u opciones de Ftrace disponibles que están configurados en la máquina actual. Si no se proporciona ninguna opción, lista todos los plugins, sistemas de eventos, eventos y opciones de Ftrace en la salida estándar.

OPCIONES

-e [regex]

Esta opción listará los eventos disponibles que están habilitados en el sistema local. 
Toma un argumento opcional que utiliza expresiones de 'regcomp(3)' para buscar.
trace-cmd list -e '^sys.*'

-F

Usado con -e regex para mostrar los campos del evento.

--full

Usado con -F que mostrará el "print fmt" del evento junto con los campos.

-l

Usado con -e regex para mostrar los filtros de eventos.

-R

Usado con -e regex para mostrar los disparadores de eventos.

-s

Esta opción listará los sistemas de eventos disponibles.

-t

Esta opción listará los trazadores disponibles que están habilitados en el sistema local.

-p

Igual que -t y solo por motivos de compatibilidad con versiones anteriores.

-o

Esta opción listará las opciones de Ftrace disponibles que están configuradas en el sistema local.

-f [regex]

Esta opción listará las funciones de filtro disponibles. Esta es la lista de funciones en el sistema que puedes trazar o filtrar. Toma un argumento opcional que utiliza expresiones de regcomp(3) para buscar. 
trace-cmd list -f '^sched.*'

-P

Lista los archivos de plugin que se cargan en el informe de trace-cmd.

-O

Lista las opciones de plugin que pueden ser utilizadas por la opción -O del informe de trace-cmd.

-B

Lista las instancias de búfer definidas (búferes secundarios).

-C

Lista los relojes definidos que se pueden usar con trace-cmd record -C. El que está entre corchetes ([]) es el reloj activo.

-c

Lista los algoritmos de compresión de archivos de traza disponibles.
