tracefs_print_close(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_print_init, tracefs_print_close, tracefs_printf, tracefs_vprintf - Abrir, cerrar y escribir cadenas formateadas en el búfer de rastreo.

SINOPSIS

#include <tracefs.h>
int tracefs_print_init(struct tracefs_instance *instance);
int tracefs_printf(struct tracefs_instance *instance, const char *fmt, ...);
int tracefs_vprintf(struct tracefs_instance *instance, const char *fmt, va_list ap);
void tracefs_print_close(struct tracefs_instance *instance);

DESCRIPCIÓN

Conjunto de funciones para escribir cadenas formateadas en el búfer de rastreo. Consulte Documentation/trace/ftrace.rst del árbol del kernel de Linux para obtener más información sobre cómo escribir datos desde el espacio de usuario en el búfer de rastreo. Todas estas API tienen instance como primer argumento. Si se pasa NULL como instance, se utiliza la instancia de rastreo superior.

La función tracefs_print_init() inicializa la biblioteca para escribir en el búfer de rastreo de la instance seleccionada. No es obligatorio llamar a esta API antes de escribir cadenas; cualquiera de las API printf la llamará automáticamente si la biblioteca aún no está inicializada. Pero llamar a tracefs_print_init() con antelación acelerará la escritura.

La función tracefs_printf() escribe una cadena formateada en el búfer de rastreo de la instance seleccionada. El argumento fmt es una cadena en formato printf, seguida de argumentos variables ....

La función tracefs_vprintf() escribe una cadena formateada en el búfer de rastreo de la instance seleccionada. El argumento fmt es una cadena en formato printf, seguida de la lista de argumentos ap.

La función tracefs_print_close() cierra los recursos utilizados por la biblioteca para escribir en el búfer de rastreo de la instancia seleccionada.

VALOR DE RETORNO

Las funciones tracefs_print_init(), tracefs_printf() y tracefs_vprintf() devuelven 0 si la operación es exitosa, o -1 en caso de error.

EJEMPLO

#include <tracefs.h>
if (tracefs_print_init(NULL) < 0) {
 /* Falló la inicialización de la biblioteca para escribir en el búfer de rastreo de la instancia de rastreo superior */
}
void foo_print(char *format, ...)
{
        va_list ap;
        va_start(ap, format);
        if (tracefs_vprintf(NULL, format, ap) < 0) {
                /* Falló la impresión en el búfer de rastreo */
        }
        va_end(ap);
}
void foo_print_string(char *message)
{
        if (tracefs_printf(NULL, "Mensaje desde el espacio de usuario: %s", message) < 0) {
                /* Falló la impresión en el búfer de rastreo */
        }
}
tracefs_print_close();
