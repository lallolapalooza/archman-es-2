TRACE-CMD-STOP(1) Manual de libtracefs TRACE-CMD-STOP(1)

NOMBRE

trace-cmd-stop - detiene el rastreador del kernel Ftrace de escribir en el búfer de anillo.

SINOPSIS

trace-cmd stop [OPCIONES]

DESCRIPCIÓN

El comando trace-cmd stop es un complemento de trace-cmd-start(1). Deshabilitará que Ftrace escriba en el búfer de anillo. Esto no detiene la sobrecarga que el rastreo puede ocasionar. Solo se deshabilita la actualización del búfer de anillo, el rastreo de Ftrace aún puede estar induciendo sobrecarga.

Después de detener el rastreo, trace-cmd-extract(1) puede extraer los datos del búfer de anillo y crear un archivo trace.dat. El sistema de archivos pseudo de Ftrace también puede ser examinado.

Para deshabilitar completamente el rastreo y eliminar la sobrecarga que causa, use trace-cmd-reset(1). Pero después de realizar un restablecimiento, los datos que se han registrado se pierden.

OPCIONES

-B nombre-del-buffer

Si el kernel soporta múltiples búferes, esto detendrá el rastreo solo para el búfer dado. No afecta a ningún otro búfer. Puede ser utilizado múltiples veces para especificar diferentes búferes. Cuando se usa esta opción, la instancia de nivel superior no se detendrá a menos que se proporcione -t.

-a

Detiene el rastreo para todas las instancias de búfer existentes. Cuando se usa esta opción, la instancia de nivel superior no se detendrá a menos que se proporcione -t.

-t

Detiene el búfer de instancia de nivel superior. Sin la opción -B o -a, esto es lo mismo que el comportamiento por defecto. Pero si se usa -B o -a, esto es necesario si el búfer de instancia de nivel superior también debe detenerse.
