trace.h(0P) Manual del programador POSIX trace.h(0P)

PROLOG

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

trace.h — rastreo

SINOPSIS

#include <trace.h>

DESCRIPCIÓN

La cabecera <trace.h> definirá la estructura posix_trace_event_info, que incluirá al menos los siguientes miembros:

trace_event_id_t  posix_event_id
pid_t             posix_pid
void             *posix_prog_address
pthread_t         posix_thread_id
struct timespec   posix_timestamp
int               posix_truncation_status

La cabecera <trace.h> definirá la estructura posix_trace_status_info, que incluirá al menos los siguientes miembros:

int     posix_stream_full_status
int     posix_stream_overrun_status
int     posix_stream_status
int     posix_log_full_status
int     posix_log_overrun_status
int     posix_stream_flush_error
int     posix_stream_flush_status

La cabecera <trace.h> definirá las siguientes constantes simbólicas:

La cabecera <trace.h> definirá los tipos size_t, trace_attr_t, trace_event_id_t, trace_event_set_t y trace_id_t tal como se describen en <sys/types.h>.
