tracefs_instances_walk(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Funciones auxiliares para trabajar con instancias de rastreo.

SINOPSIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPCIÓN

Funciones auxiliares para trabajar con instancias de rastreo.

La función tracefs_instance_get_name() devuelve el nombre de la instance dada. Tenga en cuenta que la instancia superior no tiene nombre; la función devuelve NULL para ella.

La función tracefs_instance_get_trace_dir() devuelve el directorio de rastreo donde está configurada la instance dada.

La función tracefs_instances_walk() recorre todas las instancias de rastreo configuradas en el sistema y llama a callback para cada una de ellas. El argumento context se pasa al callback, junto con el nombre de la instancia. Si el callback devuelve un valor distinto de cero, la iteración se detiene. Tenga en cuenta que el callback no se llama para la instancia superior.

La función tracefs_instance_exists() comprueba si existe una instancia con el name dado en el sistema.

La función tracefs_instace_get_buffer_size() devuelve el tamaño del búfer de anillo. Si cpu es negativo, devuelve el tamaño total de todos los búferes de anillo por CPU; de lo contrario, devuelve el tamaño del búfer de anillo por CPU para cpu.

La función tracefs_instance_set_buffer_size() establece el tamaño del búfer de anillo. Si cpu es negativo, establece todos los búferes de anillo por CPU a size (tenga en cuenta que el tamaño total es el número de CPUs * size). Si se especifica cpu, solo establece el tamaño del búfer de anillo por CPU.

La función tracefs_instance_set_buffer_percent() establece el valor del porcentaje del búfer del búfer de anillo de rastreo para instance o el búfer de nivel superior si instance es NULL. El porcentaje del búfer decide cuándo los lectores en tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) y tracefs_cpu_pipe(3) se bloquearán cuando O_NONBLOCK no esté configurado. El valor de val debe estar entre 0 y 100, donde:

  0   - bloquear hasta que haya algún dato en el búfer de anillo
  1   - bloquear hasta que se llenen el 1% de los subbúferes del búfer de anillo
  50  - bloquear hasta que se llenen el 50% de los subbúferes del búfer de anillo
  100 - bloquear hasta que se llene todo el búfer de anillo

Tenga en cuenta que se puede usar cualquier número de 0 a 100, donde es el porcentaje del búfer de anillo que debe llenarse antes de que un lector bloqueado sea notificado de que hay datos para recuperar.

La función tracefs_instance_get_buffer_percent() recupera la configuración actual del porcentaje del búfer del búfer de anillo de rastreo para instance o el búfer de nivel superior si instance es NULL.

VALOR DE RETORNO

La función tracefs_instance_get_name() devuelve una cadena o NULL en caso de la instancia superior. La cadena devuelta no debe liberarse.

La función tracefs_instance_get_trace_dir() devuelve una cadena o NULL en caso de error. La cadena devuelta no debe liberarse.

La función tracefs_instances_walk() devuelve 0 si se iteraron todas las instancias, 1 si la iteración fue detenida por el callback, o -1 en caso de error.

La función tracefs_instance_exists() devuelve true si existe una instancia con el name dado en el sistema o false en caso contrario.

La función tracefs_instance_get_buffer_size() devuelve el tamaño del búfer de anillo dependiendo del valor cpu pasado, o -1 en caso de error.

La función tracefs_instance_set_buffer_size() devuelve cero en caso de éxito y -1 en caso de error.

NOMBRE

tracefs_instances_walk — caminar a través de las instancias de traza

SINOPSIS

```c
#include <tracefs.h>

typedef int (*tracefs_instance_callback_t)(struct tracefs_instance *instance,
void *data);

int tracefs_instances_walk(tracefs_instance_callback_t callback,
void *data);
```

DESCRIPCIÓN

La función tracefs_instances_walk recorre todas las instancias de traza encontradas en el sistema. Para cada instancia de traza encontrada, llama a la función proporcionada por callback con un puntero a la estructura tracefs_instance y los datos proporcionados por data.

La función callback debe devolver 0 para continuar la iteración o cualquier otro valor para detenerla.

VALOR DE RETORNO

Devuelve 0 si la iteración se completó con éxito, o el valor devuelto por la función callback si se detuvo prematuramente. En caso de error, devuelve un valor negativo.

EJEMPLO

```c
#include <stdio.h>
#include <tracefs.h>

static int print_instance_name(struct tracefs_instance *instance,
void *data)
{
printf("Instance name: %s\n", tracefs_instance_name(instance));
return 0;
}

int main()
{
int ret = tracefs_instances_walk(print_instance_name, NULL);
if (ret < 0) {
fprintf(stderr, "Error walking instances: %d\n", ret);
return 1;
}
return 0;
}
```
