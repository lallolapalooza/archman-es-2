DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir otros dos eventos que activan un evento sintético. Un evento es el evento de inicio del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, activará el evento sintético. Los valores de los campos, aparte de los campos coincidentes, pueden pasarse del evento de inicio al evento de fin para realizar cálculos sobre ellos, o simplemente para pasarlos como un parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, establecer "sched_switch" como el evento de fin. Este evento se activa cuando se planifica una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice *TRACEFS_TIMESTAMP_USECS" como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_alloc() asigna e inicializa un evento sintético. No crea el evento sintético, sino que proporciona la información mínima para hacerlo. Consulte tracefs_synth_create(3) para saber cómo crear el evento sintético en el sistema. Requiere un manejador tep que puede ser creado por tracefs_local_events(3) para más información. El name contiene el nombre del evento sintético que se creará. El start_system es el nombre del sistema para el evento de inicio. Puede ser NULL y se elegirá el primer evento con el nombre start_event. El end_system es el nombre del sistema para el evento de fin. Puede ser NULL y se elegirá el primer evento con el nombre end_event como evento de fin. Si se proporciona match_name, este será el campo del evento sintético creado que contiene las claves coincidentes del start_match_field del evento de inicio y el end_match_field del evento de fin. Si match_name es NULL, no se registrará en el evento sintético creado.

tracefs_synth_add_match_field() agregará una segunda clave para que coincida entre el evento de inicio y el evento de fin. Si se proporciona name, el contenido del campo coincidente se guardará con este name en el evento sintético. El start_match_field es el campo del evento de inicio que coincide con el end_match_field del evento de fin.

tracefs_synth_add_compare_field() se utiliza para comparar el start_compare_field del evento de inicio con el end_compare_field del evento de fin. Se debe proporcionar el name para que el resultado se guarde en el evento sintético. No tiene sentido no pasar esto al evento sintético después de realizar el trabajo de los campos comparados, ya que no tiene ningún otro propósito. El parámetro calc puede ser uno de:

TRACEFS_SYNTH_DELTA_END - calcula la diferencia entre el contenido en el end_compare_field y el contenido del start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcula la diferencia entre el contenido en el start_compare_field y el contenido del end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Suma el contenido del start_compare_field al contenido del end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Registra el start_field del evento de inicio como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que start_field.

tracefs_synth_add_end_field() - Registra el end_field del evento de fin como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que end_field.

tracefs_synth_append_start_filter() crea un filtro o lo añade para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede añadir una comparación de field con val basada en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver más abajo TRACEFS_FILTER_AND - Añade "&&" al filtro TRACEFS_FILTER_OR - Añade "||" al filtro TRACEFS_FILTER_NOT - Añade "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añade "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añade ")" al filtro

field, compare y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces se usará _compare para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de banderas.

tracefs_synth_append_end_filter() es lo mismo que tracefs_synth_append_start_filter pero filtra en el evento de fin.

tracefs_synth_free() libera el descriptor asignado devuelto por tracefs_synth_alloc().

DESCRIPTION

Synthetic events allow the creation of new events from existing events. This can be used to derive new metrics or to simplify the analysis of complex event chains.

The core of a synthetic event is the relationship between a start event and an end event. When the start event occurs, the synthetic event starts tracking. When the end event occurs, the synthetic event records the data and the event is finished.

The fields that can be extracted from the start and end events are defined using tracefs_synth_add_start_field() and tracefs_synth_add_end_field(). The fields from both events can be compared and used to derive new fields. This is done using tracefs_synth_add_compare_field().

Filters can be appended to the start and end events to restrict when the synthetic event will be recorded. This is done using tracefs_synth_append_start_filter() and tracefs_synth_append_end_filter().

Once the synthetic event is defined, it can be created in the tracefs filesystem using tracefs_synth_create(). This will create a new event under /sys/kernel/debug/tracing/events/. The event can then be enabled and disabled like any other trace event.

The synthetic event can also be displayed using tracefs_synth_echo_cmd() which prints the command line arguments that would be used to create the event.

The synthetic event can be destroyed by calling tracefs_synth_destroy().

The synthetic event definition can be freed using tracefs_synth_free().

The tracefs_synth_complete() function can be used to finalize the synthetic event definition. This is useful if you want to save the synthetic event definition to a file or send it to another process.

The tracefs_synth_trace(), tracefs_synth_snapshot() and tracefs_synth_save() functions are used to enable, disable and save the synthetic event tracing.

The tracefs_synth_get_start_hist(), tracefs_synth_show_start_hist(), tracefs_synth_show_end_hist() and tracefs_synth_get_event() functions return the histogram associated with the start event, display the start and end histograms, and return the underlying tracefs_event structure.

tracefs_synth_raw_fmt() allows to specify a raw format string to be used when printing the synthetic event.

tracefs_synth_get_name() returns the name of the synthetic event.

tracefs_synth_show_event() prints the synthetic event definition.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

NOMBRE

tracefs_synth_alloc - Crear un evento sintético.

SINOPSIS

#include <tracefs.h>

int tracefs_synth_alloc(const char *name, const char *event_fields);

DESCRIPCIÓN

La función tracefs_synth_alloc crea un evento sintético en el sistema de archivos tracefs. Los eventos sintéticos son eventos personalizados que se pueden generar y registrar en el búfer de trazas del sistema.

El parámetro name especifica el nombre del evento sintético. Este nombre se utilizará para identificar el evento en el sistema de trazas.

El parámetro event_fields es una cadena que describe los campos del evento sintético. El formato de esta cadena sigue las convenciones de BPF (Berkeley Packet Filter) para la definición de eventos.

VALOR DE RETORNO

En caso de éxito, la función devuelve 0. En caso de error, devuelve un valor negativo que indica el código de error.

NOTAS

Esta función requiere privilegios de root para ejecutarse, ya que modifica el sistema de archivos tracefs.

La definición de los campos del evento en event_fields debe ser precisa y cumplir con el formato esperado por el sistema de trazas.

EJEMPLO

A continuación, se muestra un ejemplo de cómo crear un evento sintético simple llamado "my_event" con un campo de tipo entero llamado "value":

#include <tracefs.h>
#include <stdio.h>

int main() {
    const char *event_name = "my_event";
    const char *fields = "value:u64";
    int ret;

    ret = tracefs_synth_alloc(event_name, fields);
    if (ret < 0) {
        fprintf(stderr, "Error al crear el evento sintético: %d\n", ret);
        return 1;
    }

    printf("Evento sintético '%s' creado con éxito.\n", event_name);

    // Aquí se podrían generar eventos y leerlos del tracefs...

    return 0;
}
