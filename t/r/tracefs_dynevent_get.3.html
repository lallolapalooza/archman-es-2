tracefs_dynevent_get(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_dynevent_create, tracefs_dynevent_destroy, tracefs_dynevent_destroy_all, tracefs_dynevent_free, tracefs_dynevent_list_free, tracefs_dynevent_get, tracefs_dynevent_get_all, tracefs_dynevent_info, tracefs_dynevent_get_event - Crear, destruir, liberar y obtener eventos dinámicos.

SINOPSIS

#include <tracefs.h>
struct tracefs_dynevent;
enum tracefs_dynevent_type;
int tracefs_dynevent_create(struct tracefs_dynevent *devent);
int tracefs_dynevent_destroy(struct tracefs_dynevent *devent, bool force);
int tracefs_dynevent_destroy_all(unsigned int types, bool force);
void tracefs_dynevent_free(struct tracefs_dynevent *devent);
void tracefs_dynevent_list_free(struct tracefs_dynevent **events);
struct tracefs_dynevent *tracefs_dynevent_get(enum tracefs_dynevent_type type, const char *system, const char *event);
struct tracefs_dynevent **tracefs_dynevent_get_all(unsigned int types, const char *system);
enum tracefs_dynevent_type tracefs_dynevent_info(struct tracefs_dynevent *dynevent, char **system, char **event, char **prefix, char **addr, char **format);
struct tep_event *tracefs_dynevent_get_event(struct tep_handle *tep, struct tracefs_dynevent *dynevent);

DESCRIPCIÓN

La función tracefs_dynevent_create() crea el evento dinámico devent en el sistema.

La función tracefs_dynevent_destroy() elimina el evento dinámico devent del sistema. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar el evento dinámico. El contexto devent no se libera, use tracefs_dynevent_free() para liberarlo.

La función tracefs_dynevent_destroy_all() elimina todos los eventos dinámicos de los tipos dados del sistema. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de tipos de eventos dinámicos tracefs_dynevent_type, que serán eliminados. Si types es 0, se eliminarán los eventos dinámicos de todos los tipos. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar los eventos dinámicos.

La función tracefs_dynevent_get() asigna y devuelve una única instancia de un evento dinámico que coincide con el type, system y event dados que se le pasan. Se devuelve NULL si no hay coincidencia. El evento devuelto es lo que se encuentra en el sistema y debe liberarse con tracefs_dynevent_free(). Si system es NULL, se devolverá el primer event de cualquier sistema del tipo dado que tenga el nombre de event.

La función tracefs_dynevent_get_all() asigna y devuelve un arreglo de punteros a eventos dinámicos de los tipos dados que existen en el sistema. El último elemento del arreglo es un puntero NULL. El arreglo debe liberarse con tracefs_dynevent_list_free(). Si no hay eventos, se devuelve un puntero NULL. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de tipos de eventos dinámicos tracefs_dynevent_type, que se recuperarán. Si types es 0, se recuperarán los eventos dinámicos de todos los tipos.

La función tracefs_dynevent_free() libera un contexto de evento dinámico devent.

La función tracefs_dynevent_list_free() libera un arreglo de punteros a eventos dinámicos, devuelto por la API tracefs_dynevent_get_all().

La función tracefs_dynevent_info() devuelve el tipo e información de un evento dinámico dado dynevent. Si alguno de los argumentos system, event, prefix, addr o format no son NULL, se asignarán cadenas y se devolverán a través de estos argumentos. El system y event contienen el sistema y el nombre del evento dinámico. Si prefix no es NULL, contendrá una cadena asignada que contiene la porción de prefijo del evento dinámico (el contenido hasta el ":", sin incluirlo). Si addr no es NULL, contendrá la dirección o función a la que está adjunto el evento dinámico, si es relevante para este tipo de evento. Si format no es NULL, contendrá la cadena de formato del evento dinámico. Tenga en cuenta que el contenido en group, event, prefix, addr y format deben liberarse con free(3) si se establecen.

La función tracefs_dynevent_get_event() devuelve un evento tep, que describe el evento dinámico dado. La API detecta cualquier evento dinámico recién creado o eliminado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

VALOR DE RETORNO

tracefs_dynevent_create() devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error de análisis, tracefs_error_last(3) puede usarse para recuperar el mensaje de error que explica el problema de análisis.

tracefs_dynevent_destroy() y tracefs_dynevent_destroy_all() devuelven 0 en caso de éxito, o -1 en caso de error. Si force está habilitado, las funciones pueden fallar al deshabilitar los eventos.

tracefs_dynevent_get() devuelve un evento dinámico asignado del sistema que coincide con el tipo, sistema y evento dados.

tracefs_dynevent_get_all() devuelve un arreglo asignado de punteros a eventos dinámicos, o NULL en caso de error o si no hay eventos en el sistema. Ese arreglo debe liberarse con tracefs_dynevent_list_free().

tracefs_dynevent_info() devuelve el tipo del evento dinámico dado o TRACEFS_DYNEVENT_UNKNOWN en caso de error. Si system, event, prefix, addr o format no son NULL, contendrán cadenas asignadas que deben liberarse con free(3).

La función tracefs_dynevent_get_event() devuelve un puntero a un evento tep o NULL en caso de error o si el evento dinámico solicitado falta. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

ERRORES

Los siguientes errores son para todas las llamadas anteriores:

ENODEV Los eventos dinámicos del tipo solicitado no están configurados para el kernel en ejecución.

ENOMEM Error de asignación de memoria.

tracefs_dynevent_create() puede fallar con los siguientes errores:

EINVAL Lo más probable es que ocurriera un error de análisis (use tracefs_error_last(3) para posiblemente ver cuál fue ese error).

También pueden ocurrir otros errores causados por llamadas internas al sistema.

DESCRIPTION

The dynamic event interface allows for the creation of tracepoints on-the-fly. You can create kprobe and kretprobe events to trace any function within the kernel, as well as any userspace function accessible via the uprobes interface.

tracefs_kprobe_alloc() allocates a new kprobe event structure. The instance_name is an identifier for the instance of the tracefs that is creating this event. The event_name is the name you want to give this dynamic event. The sym is the kernel symbol (function name) to instrument. The args is a string describing the arguments to retrieve from the kprobe. The format is a comma-separated list of fields. Each field is defined as “[name]=[offset_expr][:[type]]. The offset_expr can be a register name (e.g., $arg1, $arg2, $arg3, $arg4, $arg5, $arg6, $arg7, $arg8), a constant (e.g., 0x10, 10), or an offset from a register (e.g., 0($arg2), 8($sp)). The type specifies the data type, which can be u (unsigned integer), x (hexadecimal integer), s (string), ustring (userspace string), p (pointer), f (signed integer), d (signed integer), B (unsigned 8-bit integer), H (unsigned 16-bit integer), I (unsigned 32-bit integer), Q (unsigned 64-bit integer). If no type is specified, it defaults to unsigned integer. The flags can be TRACEFS_DYNEVENT_UPROBE to create a userspace probe instead of a kernel probe. For userspace probes, the sym is the path to the executable file and the function name. For example: “/usr/bin/bash:main”.

tracefs_kretprobe_alloc() allocates a kretprobe event structure. The args string describes the return value, typically using %ax, %nx for normal and non-normal return values, respectively, followed by the format specification.

tracefs_dynevent_create() creates the dynamic event in the tracefs filesystem.

tracefs_dynevent_destroy() destroys a single dynamic event.

tracefs_dynevent_destroy_all() destroys all dynamic events of the specified type. If destroy_instance is true, it will also destroy the associated tracefs instance.

tracefs_dynevent_enable() enables a dynamic event for a given instance or a regex of instance names. If instance_name_regex is NULL, it will enable the event for the specific instance named instance_name.

tracefs_dynevent_disable() disables a dynamic event for a given instance or a regex of instance names.

tracefs_dynevent_get() retrieves a pointer to an allocated dynamic event structure.

tracefs_dynevent_type() returns the type of the dynamic event (e.g., TRACEFS_DYNEVENT_KPROBE, TRACEFS_DYNEVENT_KRETPROBE, TRACEFS_DYNEVENT_UPROBE, TRACEFS_DYNEVENT_URETPROBE).

RETURN VALUE

On success, tracefs_kprobe_alloc(), tracefs_kretprobe_alloc() return a pointer to the newly allocated dynamic event structure. On failure, they return NULL.

tracefs_dynevent_create(), tracefs_dynevent_destroy(), tracefs_dynevent_destroy_all(), tracefs_dynevent_enable(), tracefs_dynevent_disable() return 0 on success, or a negative value on failure.

tracefs_dynevent_get() returns a pointer to the dynamic event on success, or NULL on failure.

tracefs_dynevent_type() returns the type of the dynamic event.

ERRORS

See tracefs(3) for common errors.

Specific errors for dynamic events include:

ENOMEM - Insufficient memory to allocate event structure. EPERM - Insufficient privileges to create/destroy/enable/disable events. EINVAL - Invalid arguments (e.g., invalid symbol, invalid argument format). ENOENT - Event not found. EEXIST - Event with the same name already exists.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
#include <traceevent.h>

static char *mykprobe = "mykprobe_instance";
static struct tracefs_instance *instance;
static struct tracefs_event_pid *tep;
static struct tracefs_dynevent *kprobe, *kretprobe;
static struct tracefs_event *open_event;
static struct tracefs_field *file_field, *ret_field;
static pid_t pid;

static int callback(struct tracefs_raw_event *raw_event, void *priv)
{
        if (raw_event->event == open_event) {
                const char *filename = tracefs_field_string(raw_event, file_field);
                fprintf(stdout, "[pid %d] opening file: %s\n",
                        raw_event->pid, filename);
        } else if (raw_event->event == openret_event) {
                long long ret = tracefs_field_value(raw_event, ret_field);
                fprintf(stdout, "[pid %d] open returned: %lld\n",
                        raw_event->pid, ret);
        }
        return 0;
}

int main(int argc, char **argv, char **env)
{
        const char *sysnames[] = { "openat", NULL };

        if (argc < 2) {
                fprintf(stderr, "Usage: %s <command> [args...]\n", argv[0]);
                exit(-1);
        }

        instance = tracefs_instance_create(mykprobe);
        if (!instance) {
                perror("tracefs_instance_create");
                exit(-1);
        }
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);
        kprobe = tracefs_kprobe_alloc(mykprobe, "open", "do_sys_openat2",
                                      "file=+0($arg2):ustring flags=+0($arg3):x64 mode=+8($arg3):x64\n");
        kretprobe = tracefs_kretprobe_alloc(mykprobe, "openret", "do_sys_openat2", "ret=%ax", 0);
        if (!kprobe || !kretprobe) {
                perror("allocating dynamic events");
                exit(-1);
        }
        if (tracefs_dynevent_create(kprobe) || tracefs_dynevent_create(kretprobe)){
                char *err = tracefs_error_last(NULL);
                perror("Failed to create kprobes:");
                if (err && strlen(err))
                        fprintf(stderr, "%s\n", err);
                exit(-1);
        }
        tep = tracefs_local_events_system(NULL, sysnames);
        if (!tep) {
                perror("reading events");
                exit(-1);
        }
        open_event = tep_find_event_by_name(tep, mykprobe, "open");
        file_field = tep_find_field(open_event, "file");
        openret_event = tep_find_event_by_name(tep, mykprobe, "openret");
        ret_field = tep_find_field(openret_event, "ret");
        tracefs_event_enable(instance, mykprobe, NULL);
        pid = run_exec(&argv[1], env);
        /* Let the child start to run */
        sched_yield();
        do {
                tracefs_load_cmdlines(NULL, tep);
                tracefs_iterate_raw_events(tep, instance, NULL, 0, callback, NULL);
        } while (waitpid(pid, NULL, WNOHANG) != pid);
        /* Will disable the events */
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);
        tracefs_dynevent_free(kprobe);
        tracefs_dynevent_free(kretprobe);
        tracefs_instance_destroy(instance);
        tep_free(tep);
        return 0;
}
