tracefs_option_name(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_option_enable, tracefs_option_disable, tracefs_option_name - Varias funciones de opciones de trace.

SINOPSIS

#include <tracefs.h>
int tracefs_option_enable(struct tracefs_instance *instance, enum tracefs_option_id id);
int tracefs_option_disable(struct tracefs_instance *instance, enum tracefs_option_id id);
const char *tracefs_option_name(enum tracefs_option_id id);

DESCRIPCIÓN

Este conjunto de APIs se puede usar para habilitar y deshabilitar opciones de ftrace y para obtener el nombre de una opción.

La función tracefs_option_enable() habilita la opción con id en la instance dada. Si instance es NULL, la opción se habilita en la instancia de trace principal.

La función tracefs_option_disable() deshabilita la opción con id en la instance dada. Si instance es NULL, la opción se deshabilita en la instancia de trace principal.

La función tracefs_option_name() devuelve una cadena, representando la opción con id. La cadena no debe ser liberada.

VALOR DE RETORNO

Las funciones tracefs_option_enable() y tracefs_option_disable() devuelven 0 si el estado de la opción se establece correctamente, o -1 en caso de error.

La función tracefs_option_name() devuelve una cadena con el nombre de la opción, o "unknown" en caso de error. La cadena devuelta no debe ser liberada.

EJEMPLO

#include <tracefs.h>
...
if (tracefs_option_enable(NULL, TRACEFS_OPTION_ANNOTATE)) {
        /* Fallo al habilitar la opción annotate en la instancia de trace principal */
}
...
if (tracefs_option_disable(NULL, TRACEFS_OPTION_CONTEXT_INFO)) {
        /* Fallo al deshabilitar la opción context info en la instancia de trace principal */
}
...
char *name = tracefs_option_name(TRACEFS_OPTION_FUNC_STACKTRACE);
if (strcmp(name, "unknown")) {
        /* No se puede obtener el nombre de la opción */
}
