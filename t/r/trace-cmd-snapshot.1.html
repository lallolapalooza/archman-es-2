TRACE-CMD-SNAPSHOT(1) Manual de libtracefs TRACE-CMD-SNAPSHOT(1)

NOMBRE

trace-cmd-snapshot - tomar, reiniciar, liberar o mostrar una instantánea del kernel Ftrace

SINOPSIS

trace-cmd snapshot [OPCIONES]

DESCRIPCIÓN

La instantánea de trace-cmd(1) controla o muestra la función de instantánea del kernel de Ftrace Linux (si el kernel la soporta). Esto es útil para "congelar" una instancia de un rastreo en vivo pero sin detener el rastreo.

 trace-cmd start -p function
 trace-cmd snapshot -s
 trace-cmd snapshot
[ vuelca el contenido del buffer en 'trace-cmd snapshot -s' ]
 trace-cmd snapshot -s
 trace-cmd snapshot
[ vuelca el nuevo contenido del buffer de la última operación -s ]

OPCIONES

-s

Toma una instantánea del buffer en ejecución actualmente.

-r

Borra el buffer.

-f

Libera el buffer de instantánea. El buffer consume memoria dentro del kernel. Es mejor liberarlo cuando no se está usando. La primera operación -s lo asignará si aún no está asignado.

-c cpu

Opera sobre una instantánea por cpu (puede que no sea totalmente soportada por todos los kernels)

-B buf

Si se creó una instancia de buffer, la opción -B operará sobre la instantánea dentro del buffer.
