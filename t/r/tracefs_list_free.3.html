tracefs_list_free(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) libtracefs Manual LIBTRACEFS(3)

NOMBRE

tracefs_tracers, tracefs_tracer_available, tracefs_get_clock, tracefs_list_free, tracefs_list_add, tracefs_list_size - Funciones auxiliares para trabajar con el sistema de archivos trace.

SINOPSIS

#include <tracefs.h>
char **tracefs_tracers(const char *tracing_dir);
bool tracefs_tracer_available(const char *tracing_dir, const char *tracer);
char *tracefs_get_clock(struct tracefs_instance *instance);
void tracefs_list_free(char **list);
char **tracefs_list_add(char *list, const char *string);
int *tracefs_list_size(char **list);

DESCRIPCIÓN

Varias funciones útiles para trabajar con el sistema de archivos trace.

La función tracefs_tracers() devuelve un array de cadenas con los nombres de los plugins de tracer soportados, ubicados en el directorio tracing_dir dado. Este podría ser NULL o la ubicación del punto de montaje tracefs para los sistemas de trace de la máquina local, o puede ser una ruta a una copia del directorio tracefs de otra máquina. La última entrada en el array es un puntero NULL. El array debe liberarse con la API tracefs_list_free().

La función tracefs_tracer_available() devuelve true si el tracer está disponible en el directorio tracing_dir_director dado, y false en caso contrario.

La función tracefs_get_clock() devuelve el nombre del reloj de trace actual, utilizado en la instance dada. Si instance es NULL, se devuelve el reloj de la instancia de trace principal. La cadena devuelta debe liberarse con free().

La función tracefs_list_free() libera un array de cadenas, devuelto por las APIs tracefs_event_systems(), tracefs_system_events() y tracefs_tracers().

La función tracefs_list_add() añade string a la lista de cadenas list. Si list es NULL, se crea una nueva lista con el primer elemento como una copia de string, y el segundo elemento será un puntero NULL. Si list no es NULL, se reasigna para incluir un nuevo elemento y un terminador NULL, y se devuelve el nuevo array asignado. Se debe ignorar la lista pasada, ya que se liberará si se asignó una nueva.

tracefs_list_size() es una forma rápida de averiguar el número de elementos en un array de cadenas que debe liberarse con tracefs_list_free(). Tenga en cuenta que esto depende de metadatos que se crean para estas listas y no funcionará en arrays de cadenas normales como argv.

VALOR DEVUELTO

La función tracefs_tracers() devuelve un array de cadenas. El último elemento de ese array es un puntero NULL. El array debe liberarse con la API tracefs_list_free(). En caso de error, se devuelve NULL.

La función tracefs_tracer_available() devuelve true si el tracer está disponible, y false en caso contrario.

La función tracefs_get_clock() devuelve una cadena, que debe liberarse con free(), o NULL en caso de error.

La función tracefs_list_add() devuelve un array de cadenas asignado que debe liberarse con tracefs_list_free() en caso de éxito o NULL en caso de error. Si se devuelve NULL, la lista pasada no se modifica. Por lo tanto, tracefs_list_add() debe tratarse de manera similar a realloc(3).

La función tracefs_list_size() devuelve el número de cadenas en la list. La lista pasada debe ser una que se vaya a liberar con tracefs_list_free(), ya que la lista tiene metadatos que se utilizan para determinar el tamaño y esto no funciona en ningún array de cadenas normal como argv.

EJEMPLO

#include <tracefs.h>
char **tracers = tracefs_tracers(NULL);
        if (tracers) {
                /* Obtener plugins de tracer de la instancia de trace principal */
                ...
                tracefs_list_free(tracers);
        }
....
char *clock = tracefs_get_clock(NULL);
        if (clock) {
                /* Obtener el reloj de trace actual de la instancia de trace principal */
                ...
                free(clock);
        }
