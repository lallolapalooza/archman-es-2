troff(1) Manual de Comandos Generales troff(1)

Nombre

troff - Compilador de documentos y formateador de tipos GNU roff

Sinopsis

troff [-abcCEiRUz] [-d ctexto] [-d cadena=texto] [-f familia-de-fuentes] [-F directorio-de-fuentes] [-I directorio-de-inclusión] [-m paquete-de-macros] [-M directorio-de-macros] [-n número-de-página] [-o lista-de-páginas] [-r expresión-numérica-c] [-r registro=expresión-numérica] [-T dispositivo-de-salida] [-w categoría-de-advertencia] [-W categoría-de-advertencia] [archivo ...]
troff --help
troff -v
troff --version

Descripción

GNU troff transforma la entrada del lenguaje groff(7) en el formato de salida independiente del dispositivo descrito en groff_out(5); troff es, por lo tanto, el corazón del sistema de formateo de documentos GNU roff. Si no se proporcionan operandos archivo en la línea de comandos, o si archivo es “-”, se lee el flujo de entrada estándar.

GNU troff es funcionalmente compatible con el compilador de tipos AT&T troff y presenta numerosas extensiones. Muchas personas prefieren usar el comando groff(1), un front-end que también ejecuta preprocesadores y controladores de salida en el orden y con las opciones apropiadas.

Opciones

-h y --help muestran un mensaje de uso, mientras que -v y --version muestran información de la versión; todas salen después.

-a
Genera una aproximación de texto plano de la salida compuesta. El registro de solo lectura .A se establece en 1. Esta opción produce una especie de vista previa abstracta de la salida formateada.
•
Los saltos de página se marcan con una frase entre corchetes; por ejemplo, “<inicio de página>”.
•
Las líneas se cortan donde lo estarían en la salida formateada.
•
Un movimiento horizontal de cualquier tamaño se representa como un espacio. Los movimientos horizontales adyacentes no se combinan. Los nodos de espacio inter-sentencia (aquellos que surgen del segundo argumento a la solicitud .ss) no se representan.
•
Los movimientos verticales no se representan.
•
Los caracteres especiales se representan entre corchetes; por ejemplo, el carácter predeterminado de guion suave aparece como “<hy>”.
La descripción anterior no debe considerarse una especificación; los detalles de la salida -a están sujetos a cambios.
-b
Escribe un volcado de pila que informa el estado del analizador de entrada de troff al flujo de error estándar con cada mensaje de diagnóstico. Los números de línea proporcionados en el volcado de pila no siempre pueden ser correctos, ya que la idea de los números de línea de troff puede ser confundida por solicitudes que añaden a macros.
-c
Inicia con la salida a color deshabilitada.
-C
Habilita el modo de compatibilidad con AT&T troff; implica -c. Ver groff_diff(7).
-d ctexto
-d cadena=texto
Define la cadena roff c o cadena como texto. c debe ser un carácter; cadena puede tener una longitud arbitraria. Tales asignaciones de cadenas ocurren antes de que se cargue cualquier archivo de macros, incluido el archivo de inicio. Debido a las limitaciones de getopt_long(3), c no puede ser, y cadena no puede contener, un signo igual, aunque ese sea un carácter válido en un identificador de roff.
-E
Inhibe los mensajes de error de troff; implica -Ww. Esta opción no suprime los mensajes enviados al flujo de error estándar por documentos o paquetes de macros que utilizan tm o solicitudes relacionadas.
-f fam
Usa fam como la familia de fuentes predeterminada.
-F dir
Busca en el directorio dir el directorio de archivos de descripción de dispositivos y fuentes del dispositivo de salida seleccionado. Ver la descripción de GROFF_FONT_PATH en la sección “Entorno” a continuación para las ubicaciones de búsqueda predeterminadas y el orden.
-i
Lee el flujo de entrada estándar después de que se hayan procesado todos los archivos de entrada nombrados.
-I dir
Busca en el directorio dir archivos (los nombrados en la línea de comandos; en las solicitudes psbb, so y soquiet; y en las secuencias de escape de control de dispositivo “\X'ps: import'”, “\X'ps: file'”, y “\X'pdf: pdfpic'”). -I se puede especificar más de una vez; cada dir se busca en el orden dado. Para buscar en el directorio de trabajo actual antes que en otros, añada “-I .” en el lugar deseado; de lo contrario, se busca al final. -I funciona de manera similar, y se llama así, a la opción “include” de los compiladores C de Unix.
-m nombre
Procesa el archivo nombre.tmac antes que cualquier archivo de entrada. Si no se encuentra, se intenta con tmac.nombre. nombre (en ambas disposiciones) se presupone que es un archivo de macros; ver la descripción de GROFF_TMAC_PATH en la sección “Entorno” a continuación para las ubicaciones de búsqueda predeterminadas y el orden.
-M dir
Busca en el directorio dir archivos de macros. Ver la descripción de GROFF_TMAC_PATH en la sección “Entorno” a continuación para las ubicaciones de búsqueda predeterminadas y el orden.
-n num
Comienza a numerar las páginas en num. El valor predeterminado es 1.
-o lista
Imprime solo las páginas de lista, que es una lista separada por comas de rangos de páginas inclusivos; n significa página n, m-n significa cada página entre m y n, -n significa cada página hasta n, y n- significa cada página desde n en adelante. troff deja de procesar y sale después de formatear la última página enumerada en lista.
-r expresión-numérica-c
-r registro=expresión-numérica
Define el registro roff c o registro como expresión-numérica. c debe ser un nombre de un solo carácter; registro puede tener una longitud arbitraria. Tales asignaciones de registros ocurren antes de que se cargue cualquier archivo de macros, incluido el archivo de inicio. Debido a las limitaciones de getopt_long(3), c no puede ser, y registro no puede contener, un signo igual, aunque ese sea un carácter válido en un identificador de roff.
-R
No cargue troffrc y troffrc-end.
-T dev
Prepara la salida para el dispositivo dev. El valor predeterminado es ps; ver groff(1).
-U
Opera en modo inseguro, habilitando las solicitudes open, opena,

Mandatory arguments

-f name
Print the name of the character for code name. The name can be either a character name from the current font, or a decimal, octal, or hexadecimal character code. Only one character can be printed per invoking. Use the -F option to specify the font directory.
-t
Print the version of troff. This option requires no arguments. This option is intended to be used by scripts that may not know which version of troff is available.
-U
Enable the pi, pso, and sy requests, which are disabled by default because they allow an untrusted input document to write to arbitrary file names and run arbitrary commands. This option also adds the current directory to the macro package search path; see the -m and -M options above.
-w name
-W name
Enable (-w) or inhibit (-W) warnings in category name. See section “Warnings” below.
-z
Suppress formatted output.

Warnings

Warning diagnostics emitted by troff are divided into named, numbered categories. The name associated with each warning category is used by the -w and -W options. Each category is also assigned a power of two; the sum of enabled category codes is used by the warn request and the .warn register. All warning categories except di, mac, and reg. This shorthand is intended to produce all warnings that are useful with macro packages and documents written for AT&T troff and its descendants, which have less fastidious diagnostics than GNU troff.
w
All warning categories. Authors of documents and macro packages targeting groff are encouraged to use this setting.

Name

troff - macro package for the groff document formatting system

Synopsis

troff [-sn] [-z] [-a[c]] [-b] [-C] [-dcs[a]] [-Ddir] [-E] [-Fdir] [-i] [-mname] [-Mdir] [-ni] [-op] [-rrc[a]] [-Tdev[w]] [-U] [-Wo] [file... ]

Description

The troff command runs the groff compiler, which is a preprocessor to the formatter groff. It is used to format documents. It processes input files written in the troff language, and produces output suitable for displaying on a terminal, a line printer, or a phototypesetter. Because groff is intended to be a drop-in replacement for the original troff, it supports troff macro packages and commands.

This implementation of troff is part of the GNU groff package. It is a complete rewrite of the original Unix troff, and is intended to be a complete reimplementation of that system.

See groff(1) for more information about the groff system.

Options

The options are:

-sn
Causes troff to be run in safety mode. The n is a digit from 0 to 2. If n is 0 (the default), all dangerous commands are ignored. If n is 1, the PS font-changing command is not permitted. If n is 2, only the PS and font-changing commands are permitted.
-z
Suppresses the normal output. Only messages usually printed on the diagnostic output file are written.
-a[c]
Produces output in ASCII format on the standard output. The optional character c is a digit from 0 to 4. If c is 0 (the default), all characters are printed. If c is greater than 0, characters whose names are in the first c classes of the troff character set are printed. This option is useful for viewing documents on terminals that do not support all of the characters.
-b
Causes messages about output errors to be printed on the standard output.
-C
Adds the % character to the set of characters that can be used in internal character names.
-Ddir
Add dir to the path searched for device description files.
-dcs[a]
Adds the character c to the character name mapping. If a is given, it is the name to be mapped. The default mapping is to use the specified character.
-E
Causes troff to output error messages in English.
-Fdir
Causes troff to search for font description files in dir instead of the default directory.
-i
Causes the troff preprocessor to read the standard input.
-mname
Causes the macro file named name.tmac to be loaded.
-Mdir
Causes troff to search for macro files in dir instead of the default directory.
-ni
Causes page numbering to begin at page i. The default is 1.
-op
Causes only pages specified by the comma-separated list p to be printed.
-rrc[a]
Sets the number register r to the value c. If a is given, it is the name of the number register.
-Tdev[w]
Causes troff to generate output for the device dev. The optional character w indicates that the output should be in 7-bit ASCII.
-U
Causes troff to run in unsafe mode. This allows certain commands that would otherwise be disallowed in safety mode.
-Wo
Causes troff to warn about the use of troff requests that are not part of the standard troff language. The optional character o can be used to specify the type of warning.

Warnings

The -U option is dangerous because it allows the execution of arbitrary commands through the pipe command, and may allow the reading of arbitrary files. It is recommended that you do not use it unless you trust the input files completely.

Environment

GROFF_TMAC_PATH
A colon-separated list of directories to search for macro files. If this environment variable is set, directories specified with the -M option are searched only if they are specified in this variable. Otherwise, directories given as arguments to any specified -M options before these, then the current directory (only if in unsafe mode), the user's home directory, a site-specific directory (/usr/share/groff/site-tmac), and a standard location (/usr/share/groff/1.23.0/tmac) after them.
GROFF_TYPESETTER
Set the default output device. If empty or not set, ps is used. The -T option overrides GROFF_TYPESETTER.
SOURCE_DATE_EPOCH
A timestamp (expressed as seconds since the Unix epoch) to use as the output creation timestamp in place of the current time. The time is converted to human-readable form using localtime(3) when the formatter starts up and stored in registers usable by documents and macro packages.
TZ
The timezone to use when converting the current time (or value of SOURCE_DATE_EPOCH) to human-readable form; see tzset(3).

Files

/usr/share/groff/1.23.0/tmac/troffrc
is an initialization macro file loaded before any macro packages specified with -m options.
/usr/share/groff/1.23.0/tmac/troffrc-end
is an initialization macro file loaded after all macro packages specified with -m options.
/usr/share/groff/1.23.0/tmac/name.tmac
are macro files distributed with groff.
/usr/share/groff/1.23.0/font/devname/DESC
describes the output device name.
/usr/share/groff/1.23.0/font/devname/F
describes the font F of device name.

troffrc and troffrc-end are sought neither in the current nor the home directory by default for security reasons, even if the -U option is specified. Use the -M command-line option or the GROFF_TMAC_PATH environment variable to add these directories to the search path if necessary.
