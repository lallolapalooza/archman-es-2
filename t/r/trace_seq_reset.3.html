trace_seq_reset(3)

Paquete: libtraceevent

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manual de libtraceevent LIBTRACEEVENT(3)

NOMBRE

trace_seq_init, trace_seq_destroy, trace_seq_reset, trace_seq_terminate, trace_seq_putc, trace_seq_puts, trace_seq_printf, trace_seq_vprintf, trace_seq_do_fprintf, trace_seq_do_printf - Inicializar / destruir una secuencia de rastreo.

SINOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void trace_seq_init(struct trace_seq *s);
void trace_seq_destroy(struct trace_seq *s);
void trace_seq_reset(struct trace_seq *s);
void trace_seq_terminate(struct trace_seq *s);
int trace_seq_putc(struct trace_seq *s, unsigned char c);
int trace_seq_puts(struct trace_seq *s, const char *str);
int trace_seq_printf(struct trace_seq *s, const char *fmt, ...);
int trace_seq_vprintf(struct trace_seq *s, const char *fmt, va_list args);
int trace_seq_do_printf(struct trace_seq *s);
int trace_seq_do_fprintf(struct trace_seq *s, FILE *fp);

DESCRIPCIÓN

Las secuencias de rastreo se utilizan para permitir que una función llame a otras funciones para crear una cadena de datos a utilizar.

La función trace_seq_init() inicializa la secuencia de rastreo s.

La función trace_seq_destroy() destruye la secuencia de rastreo s y libera todos los recursos que haya utilizado.

La función trace_seq_reset() reinicializa la secuencia de rastreo s. Se eliminarán todos los caracteres ya escritos en s.

La función trace_seq_terminate() termina la secuencia de rastreo s. Coloca el carácter nulo '\0' al final del búfer.

La función trace_seq_putc() inserta un único carácter c en la secuencia de rastreo s.

La función trace_seq_puts() inserta una cadena terminada en NULL str en la secuencia de rastreo s.

La función trace_seq_printf() inserta una cadena formateada fmt con argumentos variables ... en la secuencia de rastreo s.

La función trace_seq_vprintf() inserta una cadena formateada fmt con una lista de argumentos args en la secuencia de rastreo s.

La función trace_seq_do_printf() imprime el búfer de la secuencia de rastreo s en la salida estándar stdout.

La función trace_seq_do_fprintf() imprime el búfer de la secuencia de rastreo s en el archivo dado fp.

VALOR DE RETORNO

Ambas funciones, trace_seq_putc() y trace_seq_puts(), devuelven el número de caracteres insertados en la secuencia de rastreo, o 0 en caso de error.

Ambas funciones, trace_seq_printf() y trace_seq_vprintf(), devuelven 0 si el rastreo excede el espacio libre del búfer, el número de caracteres impresos, o un valor negativo en caso de error.

Ambas funciones, trace_seq_do_printf() y trace_seq_do_fprintf(), devuelven el número de caracteres impresos, o -1 en caso de error.

EJEMPLO

#include <event-parse.h>
#include <trace-seq.h>
...
struct trace_seq seq;
trace_seq_init(&seq);
...
void foo_seq_print(struct trace_seq *tseq, char *format, ...)
{
        va_list ap;
        va_start(ap, format);
        if (trace_seq_vprintf(tseq, format, ap) <= 0) {
                /* Falló al imprimir en la secuencia de rastreo */
        }
        va_end(ap);
}
trace_seq_reset(&seq);
char *str = " Ejemplo de página del manual";
if (trace_seq_puts(&seq, str) != strlen(str)) {
        /* Falló al insertar str en la secuencia de rastreo */
}
if (trace_seq_putc(&seq, ':') != 1) {
        /* Falló al insertar ':' en la secuencia de rastreo */
}
if (trace_seq_printf(&seq, " secuencia de rastreo: %d", 1) <= 0) {
        /* Falló al imprimir en la secuencia de rastreo */
}
foo_seq_print( &seq, "  %d\n", 2);
trace_seq_terminate(&seq);
...
if (trace_seq_do_printf(&seq) < 0 ) {
        /* Falló al imprimir el búfer de la secuencia en la salida estándar */
}
FILE *fp = fopen("trace.txt", "w");
if (trace_seq_do_fprintf(&seq, fp) < 0 ) [
        /* Falló al imprimir el búfer de la secuencia en el archivo trace.txt */
}
trace_seq_destroy(&seq);
...
