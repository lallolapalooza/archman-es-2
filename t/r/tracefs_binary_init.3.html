tracefs_binary_init(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_binary_init, tracefs_binary_close, tracefs_binary_write - Abrir, cerrar y escribir datos binarios en el búfer de rastreo.

SINOPSIS

#include <tracefs.h>
int tracefs_binary_init(struct tracefs_instance *instance);
int tracefs_binary_write(struct tracefs_instance *instance, void *data, int len);
void tracefs_binary_close(struct tracefs_instance *instance);

DESCRIPCIÓN

Conjunto de funciones para escribir datos binarios en el búfer de rastreo. Consulte Documentation/trace/ftrace.rst del árbol del kernel de Linux para obtener más información sobre cómo escribir datos desde el espacio de usuario en el búfer de rastreo. Todas estas API tienen instance como primer argumento. Si se pasa NULL como instance, se utiliza la instancia de rastreo superior.

La función tracefs_binary_init() inicializa la biblioteca para escribir en el búfer de rastreo de la instance seleccionada. No es obligatorio llamar a esta API antes de escribir datos, tracefs_binary_write() la llamará automáticamente si la biblioteca aún no está inicializada. Pero llamar a tracefs_binary_init() con antelación acelerará la escritura.

La función tracefs_binary_write() escribe datos binarios en el búfer de rastreo de la instance seleccionada. data apunta a los datos con una longitud de len, que se van a escribir en el búfer de rastreo.

La función tracefs_binary_close() cierra los recursos utilizados por la biblioteca para escribir en el búfer de rastreo de la instancia seleccionada.

VALOR DE RETORNO

Las funciones tracefs_binary_init() y tracefs_binary_write() devuelven 0 si la operación es exitosa, o -1 en caso de error.

EJEMPLO

#include <tracefs.h>
if (tracefs_binary_init(NULL) < 0) {
 /* Error al inicializar la biblioteca para escribir en el búfer de rastreo de la instancia de rastreo superior */
}
unsigned int data = 0xdeadbeef;
        if (tracefs_binary_write(NULL, &data, sizeof(data)) < 0) {
                /* Error al escribir en el búfer de rastreo */
        }
tracefs_binary_close();
