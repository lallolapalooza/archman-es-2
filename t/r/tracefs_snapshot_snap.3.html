Paquete: libtracefs

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_snapshot_snap, tracefs_snapshot_clear, tracefs_snapshot_free - API para crear, limpiar y leer instantáneas

SINOPSIS

#include <tracefs.h>
int tracefs_snapshot_snap(struct tracefs_instance *instance);
int tracefs_snapshot_clear(struct tracefs_instance *instance);
int tracefs_snapshot_free(struct tracefs_instance *instance);

DESCRIPCIÓN

El rastreo del kernel de Linux proporciona una característica de "instantánea". El kernel tiene dos búferes de anillo. Uno que es escrito por el sistema de rastreo y otro que es el búfer de "instantánea". Cuando ocurre una instantánea, los dos búferes se intercambian, y el búfer de instantánea actual se convierte en el que se está escribiendo, y el búfer que se estaba escribiendo se convierte en la instantánea guardada.

Nota, el búfer de instantánea se asigna la primera vez que se toma, por lo que es mejor tomar una instantánea al principio antes de que se necesite para que se asigne y haya una instantánea lista, entonces la instantánea ocurrirá inmediatamente.

tracefs_snapshot_snap() asignará (si aún no está asignado) el búfer de instantánea y luego tomará una "instantánea" (intercambiará el búfer principal que se está escribiendo con el búfer de instantánea asignado). Hará esto al búfer de instancia dado o a la instancia superior si instancia es NULL.

tracefs_snapshot_clear() borrará el contenido del búfer de instantánea para la instancia dada o la instancia de nivel superior si instancia es NULL.

tracefs_snapshot_free() liberará la instantánea asignada para la instancia dada o la instancia de nivel superior si instancia es NULL. Es decir, si se realiza otra llamada a tracefs_snapshot_snap() después de esto, deberá asignar el búfer de instantánea nuevamente antes de que pueda tomar una instantánea. Esta función debe usarse para liberar la memoria del kernel utilizada por el búfer de instantánea cuando ya no esté en uso.

VALOR DE RETORNO

Los tracefs_snapshot_snap(), tracefs_snapshot_clear() y tracefs_snapshot_free() devuelven 0 en caso de éxito y -1 en caso de fallo.

EJEMPLO

#include <stdlib.h>
#include <stdio.h>
#include <tracefs.h>
static int callback(struct tep_event *event, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = event->tep;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        tep_print_event(tep, &seq, record, "[%03d] %s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_CPU,
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
        trace_seq_do_printf(&seq);
        return 0;
}
int main (int argc, char **argv)
{
        struct tracefs_instance *instance;
        struct tep_handle *tep;
        char *line = NULL;
        size_t len = 0;
        int ret;
        instance = tracefs_instance_create("my_snapshots");
        if (!instance) {
                perror("creating instance");
                exit(-1);
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("reading event formats");
                goto out;
        }
        /* Make sure the snapshot buffer is allocated */
        ret = tracefs_snapshot_snap(instance);
        if (ret < 0)
                goto out;
        ret = tracefs_event_enable(instance, "sched", NULL);
        if (ret < 0) {
                perror("enabling event");
                goto out;
        }
        for (;;) {
                printf("Hit enter without text to take snapshot!\n");
                printf("Enter any text to display the snapshot\n");
                printf("Enter 'quit' to exit\n");
                getline(&line, &len, stdin);
                ret = tracefs_snapshot_snap(instance);
                if (ret < 0) {
                        perror("taking snapshot");
                        goto out;
                }
                if (!line)
                        break;
                if (strlen(line) < 2)
                        continue;
                if (strncmp(line, "quit", 4) == 0)
                        break;
                tracefs_iterate_snapshot_events(tep, instance, NULL, 0, callback, NULL);
        }
        free(line);
        tracefs_instance_clear(instance);
 out:
        tracefs_snapshot_free(instance);
        tracefs_event_disable(instance, "sched", NULL);
        tracefs_instance_destroy(instance);
        tracefs_instance_free(instance);
        exit(0);
}

NAME

tracefs_snapshot_snap - capture the current state of tracefs into a snapshot file

SYNOPSIS

int tracefs_snapshot_snap(const char *snapshot_path);

DESCRIPTION

The tracefs_snapshot_snap function captures the current state of the tracefs filesystem and saves it to a specified snapshot file. Tracefs is a filesystem provided by the Linux kernel for tracing events. This function allows users to save the configuration and contents of tracefs at a specific point in time, which can be useful for debugging or reproducing trace sessions.

ARGUMENTS

snapshot_path: A null-terminated string representing the path where the snapshot file should be saved. This path should be a writable location on the filesystem.

RETURN VALUE

Returns 0 on success, or a negative value on error.

  • -EACCES: Permission denied to write to snapshot_path.
  • -ENOENT: The specified snapshot_path does not exist or is invalid.
  • -ENOMEM: Insufficient memory to perform the operation.
  • Other negative values may indicate other system errors.

NOTES

The snapshot will include the configuration of enabled tracepoints, kprobes, trace events, and any data currently held in the trace buffer. The exact format of the snapshot file is implementation-dependent and may change between kernel versions. It is intended to be read by tracefs-aware tools, not necessarily by direct human inspection.

EXAMPLE

#include <tracefs/tracefs.h>

int ret = tracefs_snapshot_snap("/tmp/tracefs_snapshot.snap");
if (ret < 0) {
perror("Failed to capture tracefs snapshot");
} else {
printf("Tracefs snapshot saved to /tmp/tracefs_snapshot.snap\n");
}
