NOMBRE

trace-cmd-split - Divide un archivo trace.dat en archivos más pequeños

SINOPSIS

trace-cmd split [OPCIONES] [hora-inicio [hora-fin]]

DESCRIPCIÓN

El comando trace-cmd split se utiliza para dividir un trace.dat en archivos pequeños. La hora-inicio especifica dónde comenzará el nuevo archivo. Utilizando trace-cmd-report(1) y copiando la marca de tiempo dada en un evento particular, se puede usar como entrada para la hora-inicio o la hora-fin. La división se detendrá al crear archivos cuando alcance un evento posterior a la hora-fin. Si solo se necesita la hora de fin, use 0.0 como hora de inicio.

Si se omite la hora de inicio, la división comenzará desde el principio del archivo. Si se omite la hora de fin, la división continuará hasta el final a menos que cumpla uno de los requisitos especificados por las opciones.

OPCIONES

-i archivo

Si no se especifica esta opción, el comando split buscará el archivo llamado trace.dat. Esta opción permitirá leer un archivo distinto de trace.dat.

-o archivo

Por defecto, el comando split usará el nombre del archivo de entrada como base para escribir los archivos divididos. El archivo de salida será el archivo de entrada con un '.#\' adjunto al final: trace.dat.1, trace.dat.2, etc. 
Esta opción cambiará el nombre del archivo base utilizado.
-o archivo creará archivo.1, archivo.2, etc.

-s segundos

Especifica cuántos segundos se grabarán antes de que el nuevo archivo deba detenerse.

-m milisegundos

Especifica cuántos milisegundos se grabarán antes de que el nuevo archivo deba detenerse.

-u microsegundos

Especifica cuántos microsegundos se grabarán antes de que el nuevo archivo deba detenerse.

-e eventos

Especifica cuántos eventos se grabarán antes de que el nuevo archivo deba detenerse.

-p páginas

Especifica el número de páginas que se grabarán antes de que el nuevo archivo deba detenerse. 
Nota: solo se puede especificar una de las opciones *-p*, *-e*, *-u*, *-m*, *-s* a la vez.
Si se especifica *-p*, entonces *-c* se establece automáticamente.

-r

Esta opción hace que la división se repita hasta que se alcance la hora de fin (o el final de la entrada si no se especifica la hora de fin). 
trace-cmd split -r -e 10000
Esto dividirá trace.dat en varios archivos más pequeños, cada uno con un
máximo de 10.000 eventos.

-c

Esta opción hace que la división anterior sea por CPU. 
trace-cmd split -c -p 10
Esto creará un archivo que tiene 10 páginas por cada CPU de la entrada.

-C cpu

Esta opción dividirá para una sola CPU. Solo se extraerán los eventos de la CPU especificada del archivo. 
trace-cmd split -C 1
Esto dividirá todos los eventos para la CPU 1 en el archivo.

--top

Esto permite mantener el búfer superior. El búfer superior se puede renombrar usando la opción -b. 
trace-cmd split --top
Esto mantendrá solo el búfer superior.
trace-cmd split --top -b old_top
Esto mantendrá solo el búfer superior y lo renombrará a 'old_top'.

-B buffer

Esto permite mantener el búfer seleccionado. Un búfer se puede promover al búfer superior usando la opción -t. 
trace-cmd split -B timer -B sched
Esto mantendrá los búferes 'timer' y 'sched'.
trace-cmd split -B timer -t -B sched
Esto mantendrá los búferes 'timer' y 'sched', con los eventos del búfer
'timer' promovidos a la instancia superior.
