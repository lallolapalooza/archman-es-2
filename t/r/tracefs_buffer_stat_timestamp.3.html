LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_get_stat, tracefs_instance_put_stat, tracefs_buffer_stat_entries, tracefs_buffer_stat_overrun, tracefs_buffer_stat_commit_overrun, tracefs_buffer_stat_bytes, tracefs_buffer_stat_event_timestamp, tracefs_buffer_stat_timestamp, tracefs_buffer_stat_dropped_events, tracefs_buffer_stat_read_events - Manejo de estadísticas de búfer de rastreo

SINOPSIS

#include <tracefs.h>
struct tracefs_buffer_stat *tracefs_instance_get_stat(struct tracefs_instance *instance, int cpu);
void tracefs_instance_put_stat(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_entries(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_overrun(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_commit_overrun(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_bytes(struct tracefs_buffer_stat *tstat);
long long tracefs_buffer_stat_event_timestamp(struct tracefs_buffer_stat *tstat);
long long tracefs_buffer_stat_timestamp(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_dropped_events(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_read_events(struct tracefs_buffer_stat *tstat);

DESCRIPCIÓN

Este conjunto de funciones lee y analiza el archivo tracefs/per_cpu/cpuX/stats. Estos archivos contienen las estadísticas del búfer de anillo por CPU, como cuántos eventos hay en el búfer de anillo, cuántos se han leído y así sucesivamente.

La función tracefs_instance_get_stat() leerá y analizará un archivo de estadísticas dado para una instancia y cpu determinadas. Dado que el búfer de anillo se divide en búferes por CPU, la información solo está asociada a la cpu dada. El puntero tracefs_buffer_stat devuelto se puede usar con las otras funciones de tracefs_buffer_stat y debe liberarse con tracefs_instance_put_stat().

La función tracefs_instance_put_stat() liberará los recursos asignados para el stat dado creado por tracefs_instance_get_stat().

La función tracefs_buffer_stat_entries() devuelve el número de eventos que se encuentran actualmente en el búfer de anillo asociado a tstat.

La función tracefs_buffer_stat_overrun() devuelve el número de eventos que se perdieron debido a que el escritor del búfer de anillo se adelantó al lector.

La función tracefs_buffer_stat_commit_overrun() devuelve el número de eventos que se perdieron porque el búfer de anillo era demasiado pequeño y una interrupción interrumpió la grabación de un evento de contexto inferior y agregó más eventos de los que el búfer de anillo podía contener. Tenga en cuenta que esta no es una ocurrencia común y, cuando sucede, significa que algo no se configuró correctamente.

La función tracefs_buffer_stat_bytes() devuelve el número de bytes que ocupan los eventos actuales. Tenga en cuenta que incluye los metadatos de los eventos, pero no los metadatos de los sub-búferes.

La función tracefs_buffer_stat_event_timestamp() devuelve la marca de tiempo del último evento en el búfer de anillo.

La función tracefs_buffer_stat_timestamp() devuelve la marca de tiempo actual del búfer de anillo. Tenga en cuenta que solo se lee cuando se llama a tracefs_instance_get_stat(). Tendrá la marca de tiempo del búfer de anillo cuando se llamó a esa función.

La función tracefs_buffer_stat_dropped_events() devuelve el número de eventos que se descartaron si el modo de sobrescritura está deshabilitado. Mostrará los eventos que se perdieron porque el escritor alcanzó al lector y no pudo escribir más eventos.

La función tracefs_buffer_stat_read_events() devuelve el número de eventos que fueron consumidos por un lector.

VALOR DE RETORNO

La función tracefs_instance_get_stat() devuelve una estructura tracefs_buffer_stat que se puede utilizar para recuperar las estadísticas a través de las otras funciones. Debe liberarse con tracefs_instance_put_stat().

Las otras funciones que devuelven valores diferentes de la estructura tracefs_buffer_stat devuelven el valor, o -1 si el valor no se encontró.

EJEMPLO

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(int argc, char **argv)
{
        char *trace;
        char buf[1000];
        int ret;
        int i;
        for (i = 0; i < sizeof(buf) - 1; i++) {
                buf[i] = '0' + i % 10;
        }
        buf[i] = '\0';
        tracefs_instance_clear(NULL);
        for (i = 0; i < 4; i++) {
                ret = tracefs_printf(NULL, "%s\n", buf);
                if (ret < 0)
                        perror("write");
        }
        trace = tracefs_instance_file_read(NULL, "trace", NULL);
        printf("%s\n", trace);
        free(trace);
        for (i = 0; i < sysconf(_SC_NPROCESSORS_CONF); i++) {
                struct tracefs_buffer_stat *tstat;
                ssize_t entries, eread;
                tstat = tracefs_instance_get_stat(NULL, i);
                if (!tstat)
                        continue;
                entries = tracefs_buffer_stat_entries(tstat);
                eread = tracefs_buffer_stat_read_events(tstat);
                if (!entries && !eread) {
                        tracefs_instance_put_stat(tstat);
                        continue;
                }
                printf("CPU: %d\n", i);;
                printf("\tentries: %zd\n", entries);
                printf("\toverrun: %zd\n", tracefs_buffer_stat_overrun(tstat));
                printf("\tcommit_overrun: %zd\n", tracefs_buffer_stat_commit_overrun(tstat));
                printf("\tbytes: %zd\n", tracefs_buffer_stat_bytes(tstat));
                printf("\tevent_timestamp: %lld\n", tracefs_buffer_stat_event_timestamp(tstat));
                printf("\ttimestamp: %lld\n", tracefs_buffer_stat_timestamp(tstat));
                printf("\tdropped_events: %zd\n", tracefs_buffer_stat_dropped_events(tstat));
                printf("\tread_events: %zd\n", eread);
                tracefs_instance_put_stat(tstat);
        }
}

tracefs_buffer_stat_timestamp(3)

NAME

tracefs_buffer_stat_timestamp - Get the timestamp counter values.

SYNOPSIS

#include <tracefs.h>

int tracefs_buffer_stat_timestamp(const char *path, uint64_t *tspec, uint64_t *tcount);

DESCRIPTION

This function retrieves the timestamp counter values of a trace buffer within the tracefs filesystem. The tracefs filesystem allows access to the Linux kernel tracing infrastructure.

The path argument specifies the path to the trace buffer file within the tracefs filesystem. This is typically something like /sys/kernel/tracing/trace_pipe or a specific buffer file if multiple are supported.

The tspec argument is a pointer to a uint64_t where the timestamp specification will be stored. This value indicates how the timestamps are generated.

The tcount argument is a pointer to a uint64_t where the timestamp counter will be stored. This value represents the current value of the timestamp counter.

RETURN VALUE

On success, 0 is returned. On failure, a negative error code is returned, which can be one of the following:

  • -ENOENT: The specified path does not exist.
  • -EACCES: Permission denied to access the path.
  • -EINVAL: Invalid arguments were provided.
  • -EIO: An I/O error occurred.

EXAMPLE

```c
#include <stdio.h>
#include <tracefs.h>

int main() {
uint64_t tspec, tcount;
const char *buffer_path = "/sys/kernel/tracing/trace_pipe";

if (tracefs_buffer_stat_timestamp(buffer_path, &tspec, &tcount) == 0) {
printf("Timestamp Specification: %llu\n", tspec);
printf("Timestamp Counter: %llu\n", tcount);
} else {
perror("Failed to get buffer timestamp stats");
}

return 0;
}
```

FILES

  • /sys/kernel/tracing/trace_pipe: Default path for the trace buffer.
