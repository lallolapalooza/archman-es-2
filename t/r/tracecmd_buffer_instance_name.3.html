tracecmd_buffer_instance_name(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_buffer_instances, tracecmd_buffer_instance_name, tracecmd_buffer_instance_handle - Leer instancias de rastreo de un archivo de rastreo.

SINOPSIS

#include <trace-cmd.h>
int tracecmd_buffer_instances(struct tracecmd_input *handle);
const char *tracecmd_buffer_instance_name(struct tracecmd_input *handle, int indx);
struct tracecmd_input *tracecmd_buffer_instance_handle(struct tracecmd_input *handle, int indx);

DESCRIPCIÓN

Este conjunto de API se puede usar para obtener información y leer datos de rastreo de instancias de rastreo almacenadas en un archivo de rastreo.

La función tracecmd_buffer_instances() obtiene el número de instancias de rastreo registradas en un archivo de rastreo. La instancia superior no se cuenta. El handle es un manejador tracecmd_input devuelto por tracecmd_open_head().

La función tracecmd_buffer_instance_name() obtiene el nombre de la instancia de rastreo con el índice indx dado, registrada en un archivo de rastreo. El indx es un número en el intervalo [0 .. count-1], donde count es el número devuelto por tracecmd_buffer_instances(). El handle es un manejador tracecmd_input devuelto por tracecmd_open_head().

La función tracecmd_buffer_instance_handle() asigna e inicializa un manejador tracecmd_input, asociado con la instancia de rastreo con índice indx de un archivo de rastreo. El handle es un manejador tracecmd_input devuelto por tracecmd_open_head(). El indx es un número en el intervalo [0 .. count-1], donde count es el número devuelto por tracecmd_buffer_instances().

VALOR DE RETORNO

La función tracecmd_buffer_instances() devuelve el número de instancias de rastreo registradas en un archivo de rastreo.

La función tracecmd_buffer_instance_name() devuelve una cadena, el nombre de una instancia de rastreo, o NULL en caso de error. La cadena no debe ser liberada.

La función tracecmd_buffer_instance_handle() devuelve un puntero a un manejador tracecmd_input recién asignado o NULL en caso de error. El manejador devuelto debe cerrarse con tracecmd_close()(3).

EJEMPLO

#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open_head("trace.dat");
        if (!handle) {
                /* Falló al abrir el archivo trace.dat */
        }
...
int num = tracecmd_buffer_instances(handle);
        while(num) {
                struct tracecmd_input *h;
                char *name;
                name = tracecmd_buffer_instance_name(handle, num);
                if (!name) {
                        /* Falló al obtener el nombre de la instancia num */
                }
                h = tracecmd_buffer_instance_handle(handle, num);
                if (!h) {
                        /* Falló al inicializar el manejador para la instancia num */
                }
                ...
                tracecmd_close(h);
                num--;
        }
...
        tracecmd_close(handle);
