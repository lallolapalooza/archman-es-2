TRACE-CMD-CLEAR(1) Manual de libtracefs TRACE-CMD-CLEAR(1)

NOMBRE

trace-cmd-clear - Limpia el buffer de Ftrace.

SINOPSIS

trace-cmd clear [OPCIONES]

DESCRIPCIÓN

trace-cmd(1) clear limpia el contenido del buffer circular de Ftrace.

OPCIONES

-B nombre-del-buffer

Si el kernel soporta múltiples buffers, esto limpiará solo el buffer dado. No afectará a ningún otro buffer. Esto puede usarse múltiples veces para especificar diferentes buffers. El buffer de nivel superior no se limpiará si se da esta opción.

-a

Limpia todos los buffers existentes, incluido el de nivel superior.
