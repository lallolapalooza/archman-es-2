TRIETOOL(1) Manual de Comandos Generales TRIETOOL(1)

NOMBRE

trietool - herramienta de manipulación de trie

SINOPSIS

trietool [ opciones ] trie comando argumento ...

DESCRIPCIÓN

trietool es la herramienta de línea de comandos para manipular datos de trie de doble array. Se puede utilizar para consultar, agregar y eliminar palabras en un trie.

El Trie

El argumento trie especifica el nombre del trie a manipular. Un trie se almacena en un archivo con la extensión `.tri'. Sin embargo, para crear un nuevo trie, es necesario preparar un archivo con la extensión `.abm', que describe los rangos Unicode del conjunto de alfabetos del trie. El ABM define un conjunto de vectores que mapean caracteres Unicode a un rango continuo de enteros. Los enteros mapeados se utilizarán como alfabeto interno para el trie. Dicho mapeo puede mejorar la asignación de espacio dentro de los datos del trie, independientemente de la discontinuidad del conjunto de caracteres que se esté utilizando, ya que el rango mapeado es siempre continuo.

El archivo ABM es un archivo de texto plano, donde cada línea enumera un rango de Unicodes de 32 bits que se añadirán al conjunto de alfabetos, en el formato:

[0xSSSS,0xTTTT]

donde `0xSSSS' y `0xTTTT' son valores hexadecimales del código de carácter de inicio y fin para el rango, respectivamente.

Por ejemplo, para un diccionario que solo contenga palabras en inglés sin ninguna puntuación, se podría preparar `trie.abm' como:

[0x0041,0x005a]
[0x0061,0x007a]

La primera línea enumera los códigos ASCII para A-Z, y la segunda para a-z.

No se permiten más de 255 alfabetos en un trie.

El archivo `.tri' creado incorporará los datos del ABM. Por lo tanto, el archivo `.abm' no es necesario después de la primera creación y será ignorado.

COMANDOS

Los comandos disponibles son:

añadir palabra dato ...
Agrega palabra al trie, asociada con el dato entero. Se puede proporcionar un número arbitrario de pares palabra-dato. Se leerán dos argumentos a la vez, el primero se tratará como palabra y el segundo como dato.
add-list [ opciones ] archivo-lista
Agrega palabras con datos asociados listados en archivo-lista al trie. El archivo-lista debe ser un archivo de texto que enumere una palabra por línea. El campo de datos se puede colocar después de la palabra en la misma línea, separado por un carácter de tabulación (`\t'). Si se omite el campo de datos, se utilizará un valor predeterminado (-1).
Opciones disponibles para este comando:
-e, --encoding codificación
Especifica la codificación de caracteres del contenido del archivo-lista, como `UTF-8'. Si se omite, se asume la codificación del entorno local actual.
eliminar palabra ...
Elimina palabra del trie. Se puede proporcionar un número arbitrario de palabras para eliminar.
delete-list [ opciones ] archivo-lista
Elimina las palabras listadas en archivo-lista del trie. El archivo-lista debe ser un archivo de texto que enumere una palabra por línea.
Opciones disponibles para este comando:
-e, --encoding codificación
Especifica la codificación de caracteres del contenido del archivo-lista, como `UTF-8'. Si se omite, se asume la codificación del entorno local actual.
consultar palabra
Busca palabra en el trie. Si palabra existe, su dato asociado se imprime en la salida estándar. De lo contrario, se imprime un mensaje de error en la salida de error estándar, sin imprimir nada en la salida estándar.
listar
Enumera todas las palabras del trie en la salida estándar. La salida enumera un par palabra-dato por línea, separados por un carácter de tabulación (`\t'), el formato apropiado para ser un archivo-lista para el comando add-list.

OPCIONES

Este programa sigue la sintaxis habitual de línea de comandos de GNU, con opciones largas que comienzan con dos guiones (`--'). A continuación se incluye un resumen de las opciones.

-p, --path directorio
Establece el directorio del trie a directorio [predeterminado=`.']
-h, --help
Muestra un resumen de las opciones.
-V, --version
Muestra la versión del programa.
