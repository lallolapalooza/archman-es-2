NOMBRE

trace-cmd-stat - muestra el estado del sistema de rastreo (ftrace)

SINOPSIS

trace-cmd stat [OPCIONES]

DESCRIPCIÓN

trace-cmd(1) stat muestra varios estados del sistema de rastreo (ftrace). Los estados que muestra son:

Instancias: Lista todas las instancias de ftrace configuradas.

Trazador: si uno de los trazadores (como function_graph) está activo. De lo contrario, no se muestra nada.

Eventos: Lista los eventos que están habilitados.

Filtros de eventos: Muestra cualquier filtro que se haya establecido para cualquier evento.

Filtros de funciones: Muestra cualquier filtro para los trazadores de funciones.

Funciones de gráfico: Muestra cualquier función que el trazador de gráficos de funciones deba graficar.

Búferes: Muestra el tamaño del búfer de rastreo si se han expandido. Por defecto, los búferes de rastreo están en formato comprimido hasta que se utilizan. Si están comprimidos, la visualización del búfer no se mostrará.

Reloj de rastreo: Si el reloj de rastreo es algo diferente del valor predeterminado "local", se mostrará.

Máscara de CPU de rastreo: Si no todas las CPU disponibles están en la máscara de CPU de rastreo, se mostrará la máscara de CPU de rastreo.

Latencia máxima de rastreo: Muestra el valor de la latencia máxima de rastreo si es distinto de cero.

Kprobes: Muestra cualquier kprobe que esté definida para el rastreo.

Uprobes: Muestra cualquier uprobe que esté definida para el rastreo.

Registro de errores: Descarga el contenido del archivo error_log de ftrace.

OPCIONES

-B nombre-buffer

Muestra el estado de una instancia de búfer dada. Se puede especificar varias veces para mostrar el estado de múltiples instancias.

-t

Si también se especifica -B, muestra el estado del directorio de rastreo de nivel superior, así como el de la(s) instancia(s).

-o

Muestra todas las opciones junto con sus valores. Si empiezan con "no", entonces la opción está deshabilitada.
