tracefs_option_is_supported(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_options_get_supported, tracefs_option_is_supported, tracefs_options_get_enabled, tracefs_option_is_enabled, tracefs_option_mask_is_set, tracefs_option_id - Obtener y verificar opciones de ftrace.

SINOPSIS

#include <tracefs.h>
const struct tracefs_options_mask *tracefs_options_get_supported(struct tracefs_instance *instance);
bool tracefs_option_is_supported(struct tracefs_instance *instance, enum tracefs_option_id id);
const struct tracefs_options_mask *tracefs_options_get_enabled(struct tracefs_instance *instance);
bool tracefs_option_is_enabled(struct tracefs_instance *instance, enum tracefs_option_id id);
bool tracefs_option_mask_is_set(const struct tracefs_options_mask options, enum tracefs_option_id id);
enum tracefs_option_id *tracefs_option_id(const char *name);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para obtener y verificar las opciones actuales de ftrace. Las opciones de ftrace compatibles pueden depender de la versión del kernel y de la configuración del kernel.

La función tracefs_options_get_supported() obtiene todas las opciones de ftrace compatibles con el sistema en la instancia dada. Si instance es NULL, se devuelven las opciones compatibles de la instancia de traza superior. El conjunto de opciones compatibles es el mismo en todas las instancias de traza creadas, pero puede ser diferente al de la instancia de traza superior.

La función *tracefs_option_is_supported()/ verifica si la opción con el id dado es compatible con el sistema en la instancia dada. Si instance es NULL, se utiliza la instancia de traza superior. Si una opción es compatible en la instancia de traza superior, es posible que no sea compatible en una instancia de traza creada.

La función tracefs_options_get_enabled() obtiene todas las opciones de ftrace, actualmente habilitadas en la instancia dada. Si instance es NULL, se devuelven las opciones habilitadas de la instancia de traza superior.

La función tracefs_option_is_enabled() verifica si la opción con el id dado está habilitada en la instancia dada. Si instance es NULL, se utiliza la instancia de traza superior.

La función tracefs_option_mask_is_set() verifica si el bit, correspondiente a la opción con id, está establecido en la máscara de bits options devuelta por tracefs_option_get_enabled() y tracefs_option_is_supported().

La función tracefs_option_id() convierte un nombre de opción en su id correspondiente, si se encuentra. Esto permite encontrar el id de opción a utilizar en las otras funciones si solo se conoce el nombre.

VALOR DE RETORNO

Las funciones tracefs_options_get_supported() y tracefs_options_get_enabled(), en caso de éxito, devuelven un puntero a la máscara de bits dentro de la instancia, o una máscara de bits global para el nivel superior, o NULL en caso de error. Dado que la máscara de bits devuelta forma parte de la estructura de la instancia (o de una variable global), no debe liberarse ni modificarse.

Las funciones tracefs_option_is_supported() y tracefs_option_is_enabled() devuelven verdadero si la opción es compatible/habilitada, o falso en caso contrario.

La función tracefs_option_mask_is_set() devuelve verdadero si la opción correspondiente está establecida en la máscara o falso en caso contrario.

La función tracefs_option_id() devuelve el id correspondiente definido por tracefs_options(3) a partir del name dado. Si el name no se puede encontrar, se devuelve TRACEFS_OPTION_INVALID.

EJEMPLO

#include <tracefs.h>
...
const struct tracefs_options_mask *options;
...
options = tracefs_options_get_supported(NULL);
if (!options) {
        /* Error al obtener las opciones compatibles */
} else {
        ...
}
...
options = tracefs_options_get_enabled(NULL);
if (!options) {
        /* Error al obtener las opciones habilitadas en la instancia superior */
} else {
        ...
}
if (tracefs_options_mask_is_set(options, TRACEFS_OPTION_LATENCY_FORMAT)) {
        ...
}
...
if (tracefs_option_is_supported(NULL, TRACEFS_OPTION_LATENCY_FORMAT)) {
        /* La opción de formato de latencia es compatible */
}
...
if (tracefs_option_is_enabled(NULL, TRACEFS_OPTION_STACKTRACE)) {
        /* La opción de rastreo de pila está habilitada en la instancia superior */
}
