tracefs_instance_get_dir(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Trabajar con archivos y directorios en instancias de traza.

SINOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPCIÓN

Este conjunto de API se puede utilizar para trabajar con archivos de traza en todas las instancias de traza. Cada una de estas API toma un argumento instance, que puede ser NULL para actuar sobre la instancia de nivel superior. De lo contrario, actúa sobre una instancia creada con tracefs_insance_create(3)

La función tracefs_file_exists() comprueba si existe un archivo con el nombre name en la instancia instance.

La función tracefs_dir_exists() comprueba si existe un directorio con el nombre name en la instancia instance.

La función tracefs_instance_get_file() devuelve la ruta completa del archivo con el nombre file dado en la instancia instance. Nota: no comprueba si el archivo existe en la instancia.

La función tracefs_instance_get_dir() devuelve la ruta completa del directorio con el nombre name dado en la instancia instance. Nota: no comprueba si el directorio existe en la instancia.

VALOR DE RETORNO

Las funciones tracefs_file_exists() y tracefs_dir_exists() devuelven `true` si el archivo/directorio existe en la instancia dada o `false` si no existe.

Las funciones tracefs_instance_get_file() y tracefs_instance_get_dir() devuelven una cadena o NULL en caso de error. La cadena devuelta debe liberarse con tracefs_put_tracing_file().

EJEMPLO

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Error al crear una nueva instancia de traza */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* La instancia foo soporta trace clock */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Error al obtener la ruta al archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Falló la lectura del archivo trace_clock en la instancia foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Falló el establecimiento del trace clock global en la instancia foo */
                        ...
                }
        } else {
                /* La instancia foo no soporta trace clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* La instancia foo soporta opciones de traza */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Error al obtener la ruta al directorio options en la instancia foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* La instancia foo no soporta opciones de traza */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* la traza está deshabilitada en la instancia superior */
                } else if (res == 1) {
                        /* la traza está habilitada en la instancia superior */
                } else {
                        /* Estado de traza desconocido de la instancia superior */
                }
        } else {
                /* Falló la lectura del entero del archivo tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Se obtuvo el descriptor de archivo del archivo tracing_on de la instancia superior para escritura */
                ...
                close(fd);
        }

tracefs_instance_get_dir(3)

NAME

tracefs_instance_get_dir - Obtain the directory path of a specific tracefs instance

SYNOPSIS

#include <tracefs.h>

const char *tracefs_instance_get_dir(const struct tracefs_instance *instance);

DESCRIPTION

The tracefs_instance_get_dir function retrieves the absolute path of the directory associated with the given tracefs_instance.

A tracefs instance represents a specific trace event buffer, which is typically mounted under a unique directory within the tracefs filesystem (e.g., /sys/kernel/tracing/instances/my_instance).

This function is useful when you need to directly access or manipulate files within a specific tracefs instance's directory, such as reading event data or writing configuration options.

RETURN VALUE

On success, tracefs_instance_get_dir returns a pointer to a null-terminated string containing the absolute path of the tracefs instance directory. The returned string is owned by the tracefs_instance object and should not be freed by the caller.

On failure, it returns NULL. The error cause can be determined by checking errno.

EXAMPLE

#include <stdio.h>
#include <tracefs.h>

int main() {
    struct tracefs_instance *instance;
    const char *dir_path;

    // Assume 'instance' is a valid tracefs_instance obtained from tracefs_instance_open()
    // For demonstration purposes, let's assume we have a valid instance.
    // In a real scenario, you would open an instance like:
    // instance = tracefs_instance_open("my_instance");
    // if (!instance) {
    //     perror("tracefs_instance_open");
    //     return 1;
    // }

    // Mocking a tracefs_instance for example purposes
    // In a real application, this would come from tracefs_instance_open()
    struct tracefs_instance mock_instance = {
        .name = "example_instance",
        .dir = "/sys/kernel/tracing/instances/example_instance"
    };
    instance = &mock_instance;


    dir_path = tracefs_instance_get_dir(instance);

    if (dir_path) {
        printf("Directory path for instance '%s': %s\n", instance->name, dir_path);
    } else {
        fprintf(stderr, "Failed to get directory path for instance '%s'.\n", instance->name);
    }

    // In a real scenario, you would close the instance:
    // tracefs_instance_close(instance);

    return 0;
}

NOTES

The path returned by tracefs_instance_get_dir is an absolute path. The tracefs filesystem must be mounted for this function to succeed.

The validity of the returned pointer is tied to the lifetime of the tracefs_instance object. If the instance is closed or invalidated, the pointer may become dangling.
