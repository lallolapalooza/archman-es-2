CTREVC3

Propósito:

!>
!> CTREVC3 calcula algunos o todos los vectores propios derechos y/o izquierdos
!> de una matriz triangular superior T compleja.
!> Las matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general compleja:  A = Q*T*Q**H, tal como es calculada por CHSEQR.
!>
!> Los vectores propios derechos x y los vectores propios izquierdos y de T correspondientes
!> a un valor propio w se definen por:
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada del vector y.
!> Los valores propios no son una entrada para esta rutina, sino que se leen directamente
!> de la diagonal de T.
!>
!> Esta rutina devuelve las matrices X y/o Y de los vectores propios derechos e izquierdos
!> de T, o los productos Q*X y/o Q*Y, donde Q es una
!> matriz de entrada. Si Q es el factor unitario que reduce una matriz A a
!> forma de Schur T, entonces Q*X y Q*Y son las matrices de los vectores propios
!> derechos e izquierdos de A.
!>
!> Esto utiliza una versión de BLAS Nivel 3 de la retrotransformación.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  calcular solo los vectores propios derechos;
!>          = 'L':  calcular solo los vectores propios izquierdos;
!>          = 'B':  calcular ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  calcular todos los vectores propios derechos y/o izquierdos,
!>                  retrotransformados usando las matrices suministradas en
!>                  VR y/o VL;
!>          = 'S':  calcular vectores propios derechos y/o izquierdos seleccionados,
!>                  según lo indicado por el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a calcular.
!>          El vector propio correspondiente al j-ésimo valor propio
!>          se calcula si SELECT(j) = .TRUE..
!>          No se hace referencia si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,N)
!>          La matriz triangular superior T. T se modifica, pero se restaura
!>          al salir.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX, de dimensión (LDVL,MM)
!>          Al entrar, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N por N (generalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por CHSEQR).
!>          Al salir, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de los vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VL, en el mismo orden que sus
!>                           valores propios.
!>          No se hace referencia si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL.
!>          LDVL >= 1, y si SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, de dimensión (LDVR,MM)
!>          Al entrar, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N por N (generalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por CHSEQR).
!>          Al salir, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de los vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados por
!>                           SELECT, almacenados consecutivamente en las columnas
!>                           de VR, en el mismo orden que sus
!>                           valores propios.
!>          No se hace referencia si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR.
!>          LDVR >= 1, y si SIDE = 'R' o 'B', LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios.
!>          Si HOWMNY = 'A' o 'B', M se establece en N.
!>          Cada vector propio seleccionado ocupa una columna.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK. LWORK >= max(1,2*N).
!>          Para un rendimiento óptimo, LWORK >= N + 2*N*NB, donde NB es
!>          el tamaño de bloque óptimo.
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor en la primera entrada del array WORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LWORK.
!>

RWORK

!>          RWORK es un array REAL, de dimensión (LRWORK)
!>

LRWORK

!>          LRWORK es INTEGER
!>          La dimensión del array RWORK. LRWORK >= max(1,N).
!>
!>          Si LRWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array RWORK, devuelve
!>          este valor en la primera entrada del array RWORK, y XERBLA no emite ningún mensaje de error
!>          relacionado con LRWORK.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tuvo un valor ilegal
!>

NAME


strevc - computes some or all of the right and/or left eigenvectors of a real upper quasi-triangular matrix T.


ztrevc - computes some or all of the right and/or left eigenvectors of a complex upper triangular matrix T.






SYNOPSIS


SUBROUTINE STREVC(SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M, WORK, INFO)
INTEGER N, LDT, LDVL, LDVR, MM, M, INFO
REAL T(LDT,*)
REAL VL(LDVL,*), VR(LDVR,*)
LOGICAL SELECT(*)
REAL WORK(*)
CHARACTER*1 SIDE, HOWMNY

SUBROUTINE ZTREVC(SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M, WORK, LWORK, RWORK, LRWORK, INFO)
INTEGER N, LDT, LDVL, LDVR, MM, M, LWORK, LRWORK, INFO
COMPLEX*16 T(LDT,*), VL(LDVL,*), VR(LDVR,*), WORK(*)
LOGICAL SELECT(*)
REAL RWORK(*)
CHARACTER*1 SIDE, HOWMNY







DESCRIPTION


STREVC computes some or all of the right and/or left eigenvectors of a real upper quasi-triangular matrix T. Matrices of this type are produced by the Schur factorization of a real general matrix: A = Q*T*QT, as computed by SHSEQR.


The right eigenvector x and the left eigenvector y of T corresponding to an eigenvalue w are defined by:


        T*x = w*x,     (yT)*T = w*(yT)



where yT denotes the transpose of the vector y. The eigenvalues are not input to this routine, but are read directly from the diagonal of T. T is assumed to be sorted in increasing order of magnitude of the imaginary part of the eigenvalues, and with the real eigenvalues in ascending order.


This routine returns the matrices X and/or Y of right and left eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an input matrix. If Q is the orthogonal factor that reduces a matrix A to Schur form T, then Q*X and Q*Y are the matrices of right and left eigenvectors of A.


A complex eigenvector corresponding to a complex eigenvalue w = a + ib is stored in two consecutive columns. The column corresponding to the eigenvalue w (considered to be the one with positive imaginary part) contains the real part of the eigenvector, and the column corresponding to the conjugate eigenvalue w' = a - ib contains the imaginary part of the eigenvector.


ZTREVC computes some or all of the right and/or left eigenvectors of a complex upper triangular matrix T. Matrices of this type are produced by the Schur factorization of a complex general matrix: A = Q*T*QH, as computed by ZHSEQR.


The right eigenvector x and the left eigenvector y of T corresponding to an eigenvalue w are defined by:


        T*x = w*x,     (yH)*T = w*(yH)



where yH denotes the conjugate transpose of the vector y. The eigenvalues are not input to this routine, but are read directly from the diagonal of T.


This routine returns the matrices X and/or Y of right and left eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an input matrix. If Q is the unitary factor that reduces a matrix A to Schur form T, then Q*X and Q*Y are the matrices of right and left eigenvectors of A.


This uses a Level 3 BLAS version of the back transformation.






PARAMETERS


SIDE


 SIDE is CHARACTER*1
 = 'R':  compute right eigenvectors only;
 = 'L':  compute left eigenvectors only;
 = 'B':  compute both right and left eigenvectors.



HOWMNY


 HOWMNY is CHARACTER*1
 = 'A':  compute all right and/or left eigenvectors;
 = 'B':  compute all right and/or left eigenvectors,
         backtransformed using the matrices supplied in
         VR and/or VL;
 = 'S':  compute selected right and/or left eigenvectors,
         as indicated by the logical array SELECT.



SELECT


 SELECT is LOGICAL array, dimension (N)
 If HOWMNY = 'S', SELECT specifies the eigenvectors to be
 computed.
 The eigenvector corresponding to the j-th eigenvalue is
 computed if SELECT(j) = .TRUE..
 For a complex conjugate pair of eigenvalues C and C',
 both SELECT(j) and SELECT(j+1) must be set to .TRUE.
 for the eigenvectors of the conjugate pair to be computed.
 Note that the routine will on exit set SELECT(j+1) to .FALSE.
 if SELECT(j) is .TRUE., and vice versa.
 Not referenced if HOWMNY = 'A' or 'B'.



N


 N is INTEGER
 The order of the matrix T. N >= 0.



T


 T is REAL array, dimension (LDT,N)
 The upper quasi-triangular matrix T in Schur canonical form.



 T is COMPLEX*16 array, dimension (LDT,N)
 The upper triangular matrix T.  T is modified, but restored
 on exit.



LDT


 LDT is INTEGER
 The leading dimension of the array T. LDT >= max(1,N).



VL


 VL is REAL array, dimension (LDVL,MM)
 On entry, if SIDE = 'L' or 'B' and HOWMNY = 'B', VL must
 contain an N-by-N matrix Q (usually the orthogonal matrix Q
 of Schur vectors returned by SHSEQR).
 On exit, if SIDE = 'L' or 'B', VL contains:
 if HOWMNY = 'A', the matrix Y of left eigenvectors of T;
 if HOWMNY = 'B', the matrix Q*Y;
 if HOWMNY = 'S', the left eigenvectors of T specified by
                          SELECT, stored consecutively in the columns
                          of VL, in the same order as their
                          eigenvalues.
 A complex eigenvector corresponding to a complex eigenvalue
 is stored in two consecutive columns, the first holding the
 real part, and the second the imaginary part.
 Not referenced if SIDE = 'R'.



 VL is COMPLEX*16 array, dimension (LDVL,MM)
 On entry, if SIDE = 'L' or 'B' and HOWMNY = 'B', VL must
 contain an N-by-N matrix Q (usually the unitary matrix Q of
 Schur vectors returned by ZHSEQR).
 On exit, if SIDE = 'L' or 'B', VL contains:
 if HOWMNY = 'A', the matrix Y of left eigenvectors of T;
 if HOWMNY = 'B', the matrix Q*Y;
 if HOWMNY = 'S', the left eigenvectors of T specified by
                          SELECT, stored consecutively in the columns
                          of VL, in the same order as their
                          eigenvalues.
 Not referenced if SIDE = 'R'.



LDVL


 LDVL is INTEGER
 The leading dimension of the array VL.
 LDVL >= 1, and if SIDE = 'L' or 'B', LDVL >= N.



VR


 VR is REAL array, dimension (LDVR,MM)
 On entry, if SIDE = 'R' or 'B' and HOWMNY = 'B', VR must
 contain an N-by-N matrix Q (usually the orthogonal matrix Q

FURTHER DETAILS


 The algorithm used in this program is basically backward (forward)
 substitution, with scaling to make the the code robust against
 possible overflow.

 Each eigenvector is normalized so that the element of largest
 magnitude has magnitude 1; here the magnitude of a complex number
 (x,y) is taken to be |x| + |y|.
