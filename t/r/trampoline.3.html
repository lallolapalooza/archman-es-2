NOMBRE

trampoline - clausuras como funciones C de primera clase

SINOPSIS

#include <trampoline.h>

function = alloc_trampoline(address, variable, data);

free_trampoline(function);

is_trampoline(function)
trampoline_address(function)
trampoline_variable(function)
trampoline_data(function)

DESCRIPCIÓN

Estas funciones implementan clausuras como funciones C de primera clase. Una clausura consiste en una función C normal y un fragmento de datos que se pasa a la función C cuando se llama a la clausura.

Las clausuras como funciones C de primera clase significa que encajan en un puntero de función y se pueden llamar exactamente como cualquier otra función C. function = alloc_trampoline(address, variable, data) asigna una clausura. Cuando se llama a function, almacena data en la variable variable y llama a la función C en address. La función en address es responsable de obtener data de variable inmediatamente, antes de la ejecución de cualquier otra llamada a función.

Esto es muy parecido a las funciones locales de gcc, excepto que las funciones locales de GNU C tienen una extensión dinámica (es decir, se desasignan cuando la función creadora retorna), mientras que trampoline proporciona funciones con extensión indefinida: function solo se desasigna cuando se llama a free_trampoline(function).

is_trampoline(function) comprueba si la función C function fue producida por una llamada a alloc_trampoline. Si esto retorna verdadero, los argumentos dados a alloc_trampoline pueden ser recuperados:

trampoline_address(function) retorna address,

trampoline_variable(function) retorna variable,

trampoline_data(function) retorna data.

VER TAMBIÉN

gcc(1), stdarg(3), callback(3)

ERRORES

Pasar los datos a través de una variable global no es reentrante. No llame a funciones de trampoline desde manejadores de señales. Esto está corregido en el paquete de callback(3).

PORTABILIDAD

La forma en que gcc construye funciones locales se describe en el código fuente de gcc, archivo gcc-2.6.3/config/cpu/cpu.h.
