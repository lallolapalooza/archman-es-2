tracefs_filter_pid_events_clear(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_filter_pid_function, tracefs_filter_pid_events, tracefs_filter_pid_function_clear, tracefs_filter_pid_events_clear - Añadir y eliminar filtrado de PID para funciones y eventos

SINOPSIS

#include <tracefs.h>
int tracefs_filter_pid_function(struct tracefs_instance *instance, int pid,
                                bool reset, bool notrace);
int tracefs_filter_pid_function_clear(struct tracefs_instance *instance, bool notrace);
int tracefs_filter_pid_events(struct tracefs_instance *instance, int pid,
                             bool reset, bool notrace);
int tracefs_filter_pid_events_clear(struct tracefs_instance *instance, bool notrace);

DESCRIPCIÓN

Tanto los eventos como las funciones pueden ser filtrados por PID, pero se hacen por separado. El filtrado de PID para funciones afecta al tracer de funciones y de grafos de funciones, mientras que el filtrado de PID para eventos afecta a todos los eventos como sched_switch y sched_waking. Si la opción TRACEFS_OPTION_FUNCTION_FORK está habilitada (ver tracefs_option_enable(3)), cualquier PID que se establezca como parte del filtrado de PID de funciones tendrá automáticamente sus hijos añadidos cuando se creen, así como el PID eliminado cuando salgan. Si se establece TRACEFS_OPTION_EVENT_FORK, lo mismo ocurre con el filtrado de PID de eventos. Esto también incluye la opción notrace, donde los hilos e procesos hijos de los PID marcados como notrace tampoco serán rastreados.

tracefs_filter_pid_function() afecta al filtrado de PID de funciones y tracefs_filter_pid_events() afecta al filtrado de PID de eventos. Para ambas funciones, añaden un pid a ser filtrado en la instance dada. Si reset es verdadero, entonces cualquier PID que ya se esté filtrando será eliminado, de lo contrario, el pid se añade simplemente al filtrado. Si notrace es verdadero, entonces el PID se añade a la lista de PID que no deben ser rastreados. Tenga en cuenta que reset solo afecta a la lista asociada con notrace. Es decir, si tanto reset como notrace son verdaderos, no afectará a los PID que deben ser rastreados. Lo mismo ocurre si reset es verdadero y notrace es falso, no afectará a los PID que no deben ser rastreados.

tracefs_filter_pid_function_clear() afecta al filtrado de PID de funciones y tracefs_filter_pid_events_clear() afecta al filtrado de PID de eventos. Para ambas funciones, borrará todos los PID que se estén filtrando para el filtro dado. Si notrace es verdadero, borra todos los PID que no deben ser rastreados; de lo contrario, si es falso, borra todos los PID que deben ser rastreados.

VALOR DE RETORNO

Todas las funciones devuelven 0 en caso de éxito y -1 en caso de error.

EJEMPLO

#include <stdlib.h>
#include <stdio.h>
#include <ctype.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [-e|-f][-c|-n] pid [pid ...]\n", argv[0]);
        fprintf(stderr, "   -e habilita filtro de eventos\n");
        fprintf(stderr, "   -f habilita filtro de funciones\n");
        fprintf(stderr, "     (por defecto son ambos, función y evento)\n");
        fprintf(stderr, "   -c limpia el filtro\n");
        fprintf(stderr, "   -n filtro notrace\n");
        exit(-1);
}
int main (int argc, char **argv)
{
        bool events = false;
        bool funcs = false;
        bool neg = false;
        bool clear = false;
        bool reset = true;
        int i;
        for (i = 1; i < argc && argv[i][0] == '-'; i++) {
                char *arg = argv[i];
                int c;
                for (c = 1; arg[c]; c++) {
                        switch (arg[c]) {
                        case 'e': events = true; break;
                        case 'f': funcs = true; break;
                        case 'n': neg = true; break;
                        case 'c': clear = true; break;
                        default:
                                usage(argv);
                        }
                }
                if (c == 1)
                        usage(argv);
        }
        if (i == argc && !clear)
                usage(argv);
        if (!events && !funcs) {
                events = true;
                funcs = true;
        }
        if (clear) {
                if (events)
                        tracefs_filter_pid_events_clear(NULL, neg);
                if (funcs)
                        tracefs_filter_pid_function_clear(NULL, neg);
                exit(0);
        }
        for (; i < argc; i++) {
                int pid = atoi(argv[i]);
                if (events)
                        tracefs_filter_pid_events(NULL, pid, reset, neg);
                if (funcs)
                        tracefs_filter_pid_function(NULL, pid, reset, neg);
                reset = false;
        }
        exit(0);
}
