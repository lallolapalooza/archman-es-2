trttf - trttf: matriz triangular, formato completo (tr) a formato de paquete rectangular (tf)

SINOPSIS

Funciones

Documentación de la Función

subrutina ctrttf (character transr, character uplo, integer n, complex, dimension( 0: lda-1, 0: * ) a, integer lda, complex, dimension( 0: * ) arf, integer info)

CTRTTF copia una matriz triangular del formato completo estándar (TR) al formato de paquete rectangular (TF).

Propósito:

!>
!> CTRTTF copia una matriz triangular A del formato completo estándar (TR)
!> al formato de paquete rectangular (TF).
!>

Parámetros

TRANSR 
!>          TRANSR es CHARACTER*1
!>          = 'N':  Se desea ARF en modo Normal;
!>          = 'C':  Se desea ARF en modo Transpuesta Conjugada;
!>

UPLO

!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión ( LDA, N )
!>          En la entrada, la matriz triangular A.  Si UPLO = 'U', la
!>          parte triangular superior N-por-N principal del array A contiene
!>          la matriz triangular superior, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior N-por-N principal del array A contiene
!>          la matriz triangular inferior, y la parte estrictamente triangular
!>          superior de A no se referencia.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

ARF

!>          ARF es un array COMPLEX, de dimensión ( N*(N+1)/2 ),
!>          En la salida, la matriz triangular superior o inferior A almacenada en
!>          formato RFP. Para una mayor discusión ver Notas abajo.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

!>

!>  Damos un ejemplo donde N = 6.

!>      AP es Superior             AP es Inferior

!>               44 45       40 41 42 43 44
!>                  55       50 51 52 53 54 55

!>  Sea TRANSR = 'N'. RFP contiene AP como sigue:
!>  Para UPLO = 'U' el trapecio superior A(0:5,0:2) consiste en las últimas
!>  tres columnas de AP superior. El triángulo inferior A(4:6,0:2) consiste en
!>  la transpuesta conjugada de las primeras tres columnas de AP superior.
!>  Para UPLO = 'L' el trapecio inferior A(1:6,0:2) consiste en las primeras
!>  tres columnas de AP inferior. El triángulo superior A(0:2,0:2) consiste en
!>  la transpuesta conjugada de las últimas tres columnas de AP inferior.
!>  Para denotar conjugado colocamos -- encima del elemento. Esto cubre el
!>  caso N par y TRANSR = 'N'.

!>         RFP A                   RFP A

!>        -- --
!>        01 11 55                40 41 42
!>        -- -- --
!>        02 12 22                50 51 52
