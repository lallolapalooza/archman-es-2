tracefs_instance_set_subbuf_size(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_get_subbuf_size, tracefs_instance_set_subbuf_size - Funciones de ayuda para trabajar con sub-búferes de búferes de anillo.

SINOPSIS

#include <tracefs.h>
size_t tracefs_instance_get_subbuf_size(struct tracefs_instance *instance);
int tracefs_instance_set_subbuf_size(struct tracefs_instance *instance, size_t size);

DESCRIPCIÓN

Funciones de ayuda para trabajar con los sub-búferes del búfer de anillo de rastreo. El búfer de anillo de rastreo se divide en sub-búferes. Un evento no puede ser más grande que la sección de datos del sub-búfer (ver tep_get_sub_buffer_data_size(3)). Por defecto, el búfer de anillo utiliza el tamaño de página de la arquitectura como tamaño por defecto del sub-búfer, pero esto puede ser limitante si hay necesidad de eventos grandes, por ejemplo, la aplicación quiere escribir cadenas grandes en el archivo trace_marker.

La función tracefs_instance_get_subbuf_size() devuelve el tamaño actual en kilobytes de los sub-búferes del búfer de anillo.

La función tracefs_instance_set_subbuf_size() escribirá el tamaño en kilobytes del nuevo tamaño deseado para el sub-búfer. Tenga en cuenta que esto es solo una sugerencia sobre el tamaño mínimo del sub-búfer. Tampoco tiene en cuenta los metadatos que se utilizan en el sub-búfer, por lo que el tamaño escrito no debe ser inferior a 16 bytes más que el tamaño máximo del evento que se utilizará. Es probable que el kernel haga el tamaño del sub-búfer mayor que el especificado, ya que puede ser necesario alinear el tamaño por razones de implementación.

VALOR DE RETORNO

La función tracefs_instance_get_subbuf_size() devuelve el tamaño del sub-búfer actual para el búfer de anillo de instance dado o -1 en caso de error.

La función tracefs_instance_set_subbuf_size() devolverá 0 si establece correctamente el tamaño del sub-búfer del búfer de anillo de instance en kilobytes, o -1 en caso de error.

EJEMPLO

#include <stdlib.h>
#include <tracefs.h>
#include <errno.h>
int main(int argc, char **argv)
{
        struct tep_handle *tep;
        ssize_t save_subsize;
        ssize_t subsize;
        char *trace;
        char buf[3000];
        int meta_size;
        int ret;
        int i;
        tep = tep_alloc();
        ret = tracefs_load_headers(NULL, tep);
        tep_free(tep);
        if (ret < 0) {
                perror("lectura de cabeceras");
                exit(-1);
        }
        meta_size = tep_get_sub_buffer_size(tep) - tep_get_sub_buffer_data_size(tep);
        save_subsize = tracefs_instance_get_subbuf_size(NULL);
        if (save_subsize < 0) {
                printf("Cambiar el tamaño del sub-búfer no está disponible\n");
                exit(-1);
        }
        subsize = save_subsize * 1024;
        /* Tener al menos 4 escrituras que quepan en un sub-búfer */
        if (subsize - meta_size < sizeof(buf) *4 ) {
                subsize = ((sizeof(buf) * 4 + meta_size) + 1023) / 1024;
                tracefs_instance_set_subbuf_size(NULL, subsize);
        }
        for (i = 0; i < sizeof(buf) - 1; i++) {
                buf[i] = '0' + i % 10;
        }
        buf[i] = '\0';
        tracefs_instance_clear(NULL);
        for (i = 0; i < 4; i++) {
                ret = tracefs_printf(NULL, "%s\n", buf);
                if (ret < 0)
                        perror("escritura");
        }
        trace = tracefs_instance_file_read(NULL, "trace", NULL);
        printf("%s\n", trace);
        free(trace);
        printf("El tamaño del búfer era: %zd * 1024\n",
               tracefs_instance_get_subbuf_size(NULL));
        tracefs_instance_set_subbuf_size(NULL, save_subsize);
}
