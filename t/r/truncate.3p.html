TRUNCATE(3P) Manual del programador POSIX TRUNCATE(3P)

PROLOGO

Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

truncate — truncar un archivo a una longitud especificada

SINOPSIS

#include <unistd.h>
int truncate(const char *ruta, off_t longitud);

DESCRIPCIÓN

La función truncate() hará que el archivo regular llamado por ruta tenga un tamaño igual a longitud bytes.

Si el archivo era previamente más grande que longitud, los datos adicionales se descartan. Si el archivo era previamente más corto que longitud, su tamaño se incrementa, y el área extendida aparece como si estuviera rellena de ceros.

La aplicación deberá asegurarse de que el proceso tiene permiso de escritura para el archivo.

Si la solicitud causara que el tamaño del archivo excediera el límite de tamaño de archivo blando para el proceso, la solicitud fallará y la implementación generará la señal SIGXFSZ para el proceso.

La función truncate() no modificará el desplazamiento del archivo para ninguna descripción de archivo abierta asociada con el archivo. Al completarse con éxito, truncate() marcará para actualización las marcas de tiempo de la última modificación de datos y del último cambio de estado del archivo, y los bits S_ISUID y S_ISGID del modo de archivo podrán ser borrados.

VALOR DE RETORNO

Al completarse con éxito, truncate() devolverá 0. En caso contrario, se devolverá -1 y se establecerá errno para indicar el error.

ERRORES

La función truncate() fallará si:

EINTR
Se capturó una señal durante la ejecución.
EINVAL
El argumento longitud fue menor que 0.
EFBIG o EINVAL

El argumento longitud fue mayor que el tamaño máximo de archivo.
EIO
Ocurrió un error de E/S al leer o escribir en un sistema de archivos.
EACCES
Un componente del prefijo de ruta niega el permiso de búsqueda, o se niega el permiso de escritura en el archivo.
EISDIR
El archivo nombrado es un directorio.
ELOOP
Existe un bucle en los enlaces simbólicos encontrados durante la resolución del argumento ruta.
ENAMETOOLONG

La longitud de un componente de un nombre de ruta es mayor que {NAME_MAX}.
ENOENT
Un componente de ruta no nombra un archivo existente o ruta es una cadena vacía.
ENOTDIR
Un componente del prefijo de ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio, o el argumento ruta contiene al menos un carácter no <barra> y termina con una o más barras <barra> finales y el último componente del nombre de ruta nombra un archivo existente que no es ni un directorio ni un enlace simbólico a un directorio.
EROFS
El archivo nombrado reside en un sistema de archivos de solo lectura.

La función truncate() puede fallar si:

ELOOP
Se encontraron más de {SYMLOOP_MAX} enlaces simbólicos durante la resolución del argumento ruta.
ENAMETOOLONG

La longitud de un nombre de ruta excede {PATH_MAX}, o la resolución de nombre de ruta de un enlace simbólico produjo un resultado intermedio con una longitud que excede {PATH_MAX}.

truncate(2)

NOMBRE

truncate, ftruncate - acortar o extender un archivo a una longitud dada

SINOPSIS

#include <unistd.h>

int truncate(const char *path, off_t length);

int ftruncate(int fd, off_t length);

DESCRIPCIÓN

La llamada al sistema truncate() acorta o extiende el archivo especificado por path a una longitud de length bytes. Si el archivo es más largo que length, se descartan los datos excedentes. Si el archivo es más corto que length, se extiende. Si se extiende un archivo, la parte añadida se rellena con bytes nulos (\0).

La llamada al sistema ftruncate() realiza la misma operación, pero actúa sobre el archivo al que hace referencia el descriptor de archivo abierto fd.

length debe ser un valor de tipo off_t. Si length es cero, el archivo se trunca a cero bytes.

VALOR DE RETORNO

En caso de éxito, truncate() y ftruncate() devuelven 0. En caso de error, devuelven -1 y errno se establece para indicar el error.

ERRORES

EACCES
El acceso de escritura está denegado para el archivo o un componente del prefijo de ruta.
EBADF
fd no es un descriptor de archivo válido.
EFBIG
length es mayor que el valor máximo permitido para un archivo en este sistema.
EINTR
Una llamada interrumpida por una señal.
EINVAL
length es negativo; o fd no es un descriptor de archivo abierto para escritura.
EIO
Se produjo un error de E/S al leer o escribir en el sistema de archivos.
EISDIR
path especifica un directorio.
EMFILE
Se han alcanzado los límites de descriptores de archivo para el proceso.
ENAMETOOLONG
path es demasiado largo.
ENOENT
El archivo no existe o path es una ruta vacía.
ENOSPC
No hay espacio suficiente en el dispositivo para completar la operación.
ENOTDIR
Un componente de path no es un directorio cuando debería serlo.
EROFS
El archivo está en un sistema de archivos de solo lectura.
ETXTBSY
El archivo está abierto para ejecución y se está modificando el archivo de texto ejecutable.

CONFORME A

POSIX.1-2001, POSIX.1-2008, SVr4, 4.3BSD.

VÉASE TAMBIÉN

open(2), ftruncate(3p)
