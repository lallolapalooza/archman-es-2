tracefs_hist_add_key(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Crear y destruir histogramas de eventos

SINOPSIS

#include <tracefs.h>
enum tracefs_hist_key_type {
        TRACEFS_HIST_KEY_NORMAL = 0,
        TRACEFS_HIST_KEY_HEX,
        TRACEFS_HIST_KEY_SYM,
        TRACEFS_HIST_KEY_SYM_OFFSET,
        TRACEFS_HIST_KEY_SYSCALL,
        TRACEFS_HIST_KEY_EXECNAME,
        TRACEFS_HIST_KEY_LOG,
        TRACEFS_HIST_KEY_USECS,
        TRACEFS_HIST_KEY_MAX
};
struct tracefs_hist_axis {
        const char *key;
        enum tracefs_hist_key_type type;
};
struct tracefs_hist *tracefs_hist_alloc(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key, enum tracefs_hist_key_type type);
struct tracefs_hist *tracefs_hist_alloc_2d(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key1, enum tracefs_hist_key_type type1,
                        const char *key2, enum tracefs_hist_key_type type2));
struct tracefs_hist *tracefs_hist_alloc_nd(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        struct tracefs_hist_axis *axes);
struct tracefs_hist *tracefs_hist_alloc_nd_cnt(struct tep_handle *tep,
                          const char *system, const char *event_name,
                          struct tracefs_hist_axis_cnt *axes);
void tracefs_hist_free(struct tracefs_hist *hist);
int tracefs_hist_add_key(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type);
int tracefs_hist_add_key_cnt(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type, int cnt);
int tracefs_hist_add_value(struct tracefs_hist *hist, const char *value);

DESCRIPCIÓN

Los histogramas de eventos se crean mediante el archivo trigger en el directorio del evento. La sintaxis puede ser compleja y difícil de acertar. Esta API maneja la sintaxis y facilita la creación e interacción con los histogramas de eventos. Consulte https://www.kernel.org/doc/html/latest/trace/histogram.html para obtener más información.

tracefs_hist_alloc() asigna un descriptor de "struct tracefs_hist" para un histograma unidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key es un campo del evento que se usará como clave (dimensión) del histograma. El type es el tipo de la key. Ver TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_2d() asigna un descriptor de "struct tracefs_hist" para un histograma bidimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. La key1 es el primer campo del evento que se usará como clave (dimensión) del histograma. El type1 es el tipo de la key1. Ver TIPOS DE CLAVE a continuación. La key2 es el segundo campo del evento que se usará como clave (dimensión) del histograma. El type2 es el tipo de la key2. Ver TIPOS DE CLAVE a continuación.

tracefs_hist_alloc_nd() asigna un descriptor de "struct tracefs_hist" para un histograma N-dimensional y devuelve su dirección. Este descriptor debe ser liberado por tracefs_hist_free(). El tep es un manejador de eventos de traza (ver tracefs_local_events(3)), que contiene el system y event a los que se adjuntará el histograma. El system es el sistema o grupo del evento. El event es el evento al que se adjuntará el histograma. Las axes es un array de pares key / type, que definen las dimensiones del histograma.

tracefs_hist_alloc_nd_cnt() inicializará un descriptor de histograma que se adjuntará al system/event. Esto solo inicializa el descriptor con las claves de axes dadas como primarias. Esto solo inicializa el descriptor, no inicia el histograma en el kernel. La diferencia entre esto y tracefs_hist_alloc_nd() es que el parámetro axes es de tipo struct tracefs_hist_axis_cnt y no struct tracefs_hist_axis.

tracefs_hist_free() libera el descriptor tracefs_hist. Nota: no detiene ni deshabilita el histograma en ejecución si se inició. Se debe llamar a tracefs_hist_destroy() para hacerlo.

tracefs_hist_add_key() agrega una clave secundaria o terciaria al histograma. La clave pasada a tracefs_hist_alloc_nd() es la clave primaria del histograma. La primera vez que se llama a esta función, agregará una clave secundaria (o un histograma bidimensional). Si esta función se llama nuevamente en el mismo histograma, agregará una clave terciaria (o un histograma tridimensional). El parámetro hist es el descriptor del histograma al que se agregará la key. El type es el tipo de clave a agregar (ver TIPOS DE CLAVE a continuación).

tracefs_hist_add_key_cnt() es lo mismo que tracefs_hist_add_key() excepto que permite agregar un contador para el tipo dado. Actualmente, solo el tipo buckets requiere un contador. Al agregar una clave con el tipo buckets, tracefs_hist_add_key() no es suficiente, ya que el tipo buckets requiere un contador o tamaño de cubeta. Utilice tracefs_hist_add_key_cnt() al especificar una clave que está dividida en cubetas, y pase el tamaño de esas cubetas en cnt.

tracefs_hist_add_value() agregará un valor para registrar. Por defecto, el valor es simplemente el "hitcount" (recuento de aciertos) del número de veces que se produjo una instancia de la clave del histograma. El hist es el descriptor del histograma al que agregar el valor. El value es un campo en el histograma al que agregar cuando se produce una instancia de la clave.

TIPOS DE CLAVE

tracefs_hist_alloc_nd() y tracefs_hist_add_key() ambos agregan una clave y requieren que esa clave tenga un tipo. Los tipos pueden ser:

TRACEFS_HIST_KEY_NORMAL o cero (0), que es no modificar el tipo.

TRACEFS_HIST_KEY_HEX para mostrar la clave en hexadecimal.

TRACEFS_HIST_KEY_SYM para mostrar la clave como un símbolo del kernel (si se encuentra). Si la clave es una dirección, esto es útil ya que mostrará los nombres de las funciones en lugar de solo un número.

TRACEFS_HIST_KEY_SYM_OFFSET similar a TRACEFS_HIST_KEY_SYM pero también incluirá el desplazamiento de la función para coincidir con la dirección exacta.

TRACEFS_HIST_KEY_SYSCALL Si la clave es un "id" de llamada al sistema (el número que se pasa desde el espacio de usuario al kernel para indicarle qué llamada al sistema está realizando), se mostrará el nombre de la llamada al sistema.

TRACEFS_HIST_KEY_EXECNAME Si la clave es "common_pid" (el pid de la tarea en ejecución), en lugar de mostrar el número, mostrará el nombre de la tarea en ejecución.

TRACEFS_HIST_KEY_LOG mostrará la clave en una escala logarítmica binaria.

TRACEFS_HIST_KEY_USECS para usar con "common_timestamp" o TRACEFS_HIST_TIMESTAMP, en cuyo caso mostrará la marca de tiempo en microsegundos en lugar de nanosegundos.

VALOR DE RETORNO

tracefs_hist_alloc_nd() devuelve un descriptor de histograma asignado que debe ser liberado por tracefs_hist_free() o NULL en caso de error.

Todas las demás funciones devuelven cero si tienen éxito o -1 en caso de error.

Si tracefs_hist_start() devuelve un error, se puede mostrar un mensaje en el kernel que se puede recuperar mediante tracefs_error_last().

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Fallo al asignar ejes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "'buckets' tipo de clave requiere '=<tamaño>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Atributo indefinido '%s'\n", att);
                                fprintf(stderr,"  Atributos aceptables:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Fallo al crear instancia\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("No se pudieron leer los eventos");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Error al leer el archivo hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "El comando necesita la opción -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "¿No hay claves?\n");
                exit(-1);
        }
        /* buckets requiere la función nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* continuar */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Mostrar ejemplos de hist1d y hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Realmente, 1 y 2 también podrían usar esto */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Fallo al crear hist\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Fallo al agregar valor %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Fallo al agregar clave/valor de ordenación %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Fallo al agregar clave/valor ascendente %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Fallo al agregar clave/valor descendente %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW ya se hizo */
                break;
        }
        if (ret)
                fprintf(stderr, "Fallo: comando\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "uso: %s comando [-B instancia][-e [sistema/]evento][-k claves][-v valores][-s ordenacion]\n", argv[0]);
                fprintf(stderr, "      [-a ascendente][-d descendente]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Comando desconocido %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

tracefs_hist_add_key(3)

NAME

tracefs_hist_add_key, tracefs_hist_add_key_by_name, tracefs_hist_add_key_by_size - add a key to a histogram

SYNOPSIS

#include <tracefs.h>

int tracefs_hist_add_key(struct tracefs_hist_entry *entry, const char *key_name);
int tracefs_hist_add_key_by_name(struct tracefs_hist *hist, const char *name);
int tracefs_hist_add_key_by_size(struct tracefs_hist *hist, size_t size);

DESCRIPTION

The function tracefs_hist_add_key adds a key with the given name key_name to a histogram entry entry. If the key already exists, it will be reused. The histogram entry needs to be created by tracefs_hist_new(3) beforehand.

The function tracefs_hist_add_key_by_name adds a key with the given name name to the histogram hist. If the histogram entry does not exist, it will be created. If the key already exists, it will be reused.

The function tracefs_hist_add_key_by_size adds a key with the size size to the histogram hist. If the histogram entry does not exist, it will be created. If the key already exists, it will be reused. The key name will be created from the size by formatting it as a string.

KEY TYPES

The keys can be of different types. The type is determined by the value of the type field of the struct tracefs_hist_entry. Possible values are:

  • TRACEFS_HIST_KEY_TYPE_STRING: The key is a string.
  • TRACEFS_HIST_KEY_TYPE_INT: The key is an integer.
  • TRACEFS_HIST_KEY_TYPE_ADDR: The key is an address.
  • TRACEFS_HIST_KEY_TYPE_STRING_OR_INT: The key is a string or an integer.

The type is set when the histogram is created using tracefs_hist_new(3).

RETURN VALUE

On success, these functions return 0. On failure, a negative error code is returned.

EXAMPLE

Add a key named "my_key" to a histogram:

    struct tracefs_hist *hist;
    int ret;

    hist = tracefs_hist_new("my_histogram", "my_event",
                           TRACEFS_HIST_KEY_TYPE_STRING, NULL);
    if (!hist) {
        /* handle error */
    }

    ret = tracefs_hist_add_key_by_name(hist, "my_key");
    if (ret < 0) {
        /* handle error */
    }

    tracefs_hist_free(hist);
