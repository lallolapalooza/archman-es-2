tracefs_instance_get_affinity_set(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_set_affinity, tracefs_instance_set_affinity_set, tracefs_instance_set_affinity_raw, tracefs_instance_get_affinity, tracefs_instance_get_affinity_set, tracefs_instance_get_affinity_raw - Establece o recupera la afinidad para una instancia o el nivel superior para qué CPUs habilitan el trazado.

SINOPSIS

#include <tracefs.h>
int tracefs_instance_set_affinity(struct tracefs_instance *instance, const char *cpu_str);
int tracefs_instance_set_affinity_set(struct tracefs_instance *instance, cpu_set_t *set, size_t set_size);
int tracefs_instance_set_affinity_raw(struct tracefs_instance *instance, const char *mask);
char *tracefs_instance_get_affinity(struct tracefs_instance *instance);
int tracefs_instance_get_affinity_set(struct tracefs_instance *instance, cpu_set_t *set, size_t set_size);
char *tracefs_instance_get_affinity_raw(struct tracefs_instance *instance);

DESCRIPCIÓN

Estas funciones establecen o recuperan la afinidad de CPU que limita qué CPUs tendrán el trazado habilitado para una instancia dada definida por el parámetro instance. Si instance es NULL, se afecta la instancia de nivel superior.

La función tracefs_instance_set_affinity() toma una cadena cpu_str que es una lista de CPUs para las cuales establecer la afinidad. Si cpu_str es NULL, se establecerán todas las CPUs del sistema. El formato de cpu_str es una cadena delimitada por comas de números decimales sin espacios. Se puede especificar un rango mediante un guion.

Por ejemplo: "1,4,6-8"

Los números no necesitan estar en orden, excepto para los rangos, donde el segundo número debe ser igual o mayor que el primero.

La función tracefs_instance_set_affinity_set() toma un conjunto de CPUs definido por CPU_SET(3). El tamaño del conjunto definido por set_size es el tamaño en bytes de set. Si set es NULL, se establecerán todas las CPUs del sistema y se ignora set_size.

La función tracefs_instance_set_affinity_raw() toma una cadena que contiene una máscara de bits hexadecimal, donde cada 32 bits se separa por una coma. Para una máquina con más de 32 CPUs, para establecer las CPUs 1-10 y la CPU 40:

"100,000007fe"

Donde lo anterior es una representación hexadecimal de los bits 1-10 y el bit 40 establecidos.

La función tracefs_instance_get_affinity() recuperará la afinidad en un formato legible por humanos.

Por ejemplo: "1,4,6-8"

La cadena devuelta debe liberarse con free(3).

La función tracefs_instance_get_affinity_set() establecerá todos los bits en el conjunto de CPUs proporcionado (de CPU_SET(3)). Tenga en cuenta que no borrará ningún bit que ya esté establecido en el conjunto pero las CPUs no lo estén. Si solo se deben establecer los bits de las CPUs que están habilitadas, se debe realizar un CPU_ZERO_S() en el conjunto antes de llamar a esta función.

La función tracefs_instance_get_affinity_raw() simplemente leerá la máscara de CPU de trazado de la instancia y devolverá esa cadena. La cadena devuelta debe liberarse con free(3).

VALOR DE RETORNO

Todas las funciones de establecimiento devuelven 0 si tienen éxito y -1 si hay un error.

Las funciones tracefs_instance_get_affinity() y tracefs_instance_get_affinity_raw() devuelven una cadena asignada que debe liberarse con free(3), o NULL si hay un error.

La función tracefs_instance_get_affinity_set() devuelve el número de CPUs que se encontraron establecidas, o -1 si hay un error.

ERRORES

Los siguientes errores son para todas las llamadas anteriores:

EFBIG si se establece una CPU que es mayor que las que hay en el sistema.

EINVAL Uno de los parámetros no era válido.

Los siguientes errores son para tracefs_instance_set_affinity() y tracefs_instance_set_affinity_set():

ENOMEM Error de asignación de memoria.

ENODEV los eventos dinámicos del tipo solicitado no están configurados para el kernel en ejecución.

Los siguientes errores son solo para tracefs_instance_set_affinity()

EACCES La cadena cpu_str fue modificada por otro hilo mientras se procesaba.

EJEMPLO

#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>
int main (int argc, char **argv)
{
        struct trace_seq seq;
        cpu_set_t *set;
        size_t set_size;
        char *c;
        int cpu1;
        int cpu2;
        int i;
        c = tracefs_instance_get_affinity(NULL);
        printf("La afinidad era %s\n", c);
        free(c);
        if (argc < 2) {
                tracefs_instance_set_affinity(NULL, NULL);
                exit(0);
        }
        /* Mostrar ejemplo usando un set */
        if (argc == 2 && !strchr(argv[1],',')) {
                cpu1 = atoi(argv[1]);
                c = strchr(argv[1], '-');
                if (c++)
                        cpu2 = atoi(c);
                else
                        cpu2 = cpu1;
                if (cpu2 < cpu1) {
                        fprintf(stderr, "Rango de CPU inválido\n");
                        exit(-1);
                }
                set = CPU_ALLOC(cpu2 + 1);
                set_size = CPU_ALLOC_SIZE(cpu2 + 1);
                CPU_ZERO_S(set_size, set);
                for ( ; cpu1 <= cpu2; cpu1++)
                        CPU_SET(cpu1, set);
                tracefs_instance_set_affinity_set(NULL, set, set_size);
                CPU_FREE(set);
                exit(0);
        }
        trace_seq_init(&seq);
        for (i = 1; i < argc; i++) {
                if (i > 1)
                        trace_seq_putc(&seq, ',');
                trace_seq_puts(&seq, argv[i]);
        }
        trace_seq_terminate(&seq);
        tracefs_instance_set_affinity(NULL, seq.buffer);
        trace_seq_destroy(&seq);
        exit(0);
        return 0;
}
