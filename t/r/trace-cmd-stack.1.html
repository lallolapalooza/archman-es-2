TRACE-CMD-STACK(1) Manual de libtracefs TRACE-CMD-STACK(1)

NOMBRE

trace-cmd-stack - leer, habilitar o deshabilitar el rastreo de pila del kernel de Linux Ftrace.

SINOPSIS

trace-cmd stack

DESCRIPCIÓN

El comando trace-cmd(1) stack habilita el rastreador de pila de Ftrace dentro del kernel. El rastreador de pila habilita el rastreador de funciones y en cada llamada de función dentro del kernel, se verifica la pila. Cuando se descubre un nuevo uso máximo de la pila, se registra.

Cuando no se usa ninguna opción, se muestra la pila actual.

Para habilitar el rastreador de pila, use la opción --start, y para deshabilitar el rastreador de pila, use la opción --stop. La salida será la pila máxima encontrada desde que se habilitó el inicio.

Use --reset para restablecer el contador de pila a cero.

Use --verbose[=nivel] para establecer el nivel de registro. Los niveles de registro admitidos son "none", "critical", "error", "warning", "info", "debug", "all" o sus identificadores "0", "1", "2", "3", "4", "5", "6". Establecer el nivel de registro a un valor específico habilita todos los registros de ese nivel y de todos los niveles anteriores. El nivel se establecerá por defecto en "info" si no se especifica ninguno.
