Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_cpu_open_mapped, tracefs_cpu_is_mapped, tracefs_mapped_is_supported, tracefs_cpu_map, tracefs_cpu_unmap - Mapeo en memoria del búfer de anillo

SINOPSIS

#include <tracefs.h>
bool tracefs_cpu_is_mapped(struct tracefs_cpu *tcpu);
bool tracefs_mapped_is_supported(void);
int tracefs_cpu_map(struct tracefs_cpu *tcpu);
void tracefs_cpu_unmap(struct tracefs_cpu *tcpu);
struct tracefs_cpu *tracefs_cpu_open_mapped(struct tracefs_instance *instance,
                                            int cpu, bool nonblock);

DESCRIPCIÓN

Si trace_pipe_raw soporta el mapeo en memoria, este es usualmente un método más eficiente para transmitir datos desde el búfer de anillo del kernel que leerlo, ya que no requiere copiar la memoria que se está leyendo.

Si el kernel soporta el mapeo en memoria y la aplicación pide usar el mapeo en memoria ya sea a través de tracefs_cpu_map() o de tracefs_cpu_open_mapped(), entonces las funciones tracefs_cpu_read(3) y tracefs_cpu_read_buf(3) usarán el mapeo directamente en lugar de llamar a la llamada del sistema read.

Nota, el mapeo hará que tracefs_cpu_buffered_read(3) y tracefs_cpu_buffered_read_buf(3) actúen igual que tracefs_cpu_read(3) y tracefs_cpu_read_buf(3) respectivamente, ya que no tiene sentido usar un pipe splice cuando está mapeado. El kernel hará una copia para las lecturas splice en el mapeo, y luego otra copia en la función cuando pueda evitar las copias si el búfer de anillo está mapeado en memoria.

Si el tcpu está mapeado en memoria, también forzará a tracefs_cpu_write(3) y tracefs_cpu_pipe(3) a copiar desde el mapeo en lugar de usar splice. Por lo tanto, se debe tener cuidado al determinar si mapear o no el búfer de anillo, y por qué no se mapea por defecto.

La función tracefs_cpu_is_mapped() devolverá true si tcpu tiene actualmente su búfer de anillo mapeado en memoria y false en caso contrario. Esto no indica si el kernel soporta el mapeo en memoria, pero eso generalmente se puede determinar llamando a tracefs_cpu_map().

La función tracefs_mapped_is_supported() devuelve true si el búfer de anillo puede ser mapeado en memoria.

La función tracefs_cpu_map() intentará mapear el búfer de anillo asociado a tcpu si aún no está mapeado.

La función tracefs_cpu_unmap() desmapeará el búfer de anillo asociado a tcpu si está mapeado.

La función tracefs_cpu_open_mapped() es equivalente a llamar a tracefs_cpu_open(3) seguido de tracefs_cpu_map() en el tcpu devuelto por tracefs_cpu_open(3). Nota, esto seguirá teniendo éxito si el mapeo falla, en cuyo caso actúa igual que tracefs_cpu_open(3). Si se quiere saber si el mapeo tuvo éxito o no, se debe llamar a tracefs_cpu_is_mapped() en el tcpu devuelto.

VALOR DE RETORNO

tracefs_cpu_is_mapped() devuelve true si el tcpu dado tiene su búfer de anillo mapeado en memoria o false en caso contrario.

tracefs_mapped_is_supported() devuelve true si el búfer de anillo de trazado puede ser mapeado en memoria o false si no puede o si ocurrió un error.

tracefs_cpu_map() devuelve 0 en caso de éxito y -1 en caso de error al mapear. Si se devuelve 0, entonces tracefs_cpu_is_mapped() devolverá true después, o false si el mapeo falló.

tracefs_cpu_open_mapped() devuelve un tracefs_cpu asignado en caso de éxito de creación, independientemente de si el mapeo del búfer de anillo tuvo éxito o no. Devuelve NULL por las mismas razones que tracefs_cpu_open(3) devuelve NULL. Si se quiere saber si el mapeo tuvo éxito, es necesario llamar a tracefs_cpu_is_mapped() después.

EJEMPLO

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_subbuf(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        int missed_events;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                missed_events = kbuffer_missed_events(kbuf);
                if (missed_events) {
                        printf("[MISSED EVENTS");
                        if (missed_events > 0)
                                printf(": %d]\n", missed_events);
                        else
                                printf("]\n");
                }
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        bool mapped;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open_mapped(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        /*
         * If this kernel supports mapping, use normal read,
         * otherwise use the piped buffer read, although if
         * the mapping succeeded, tracefs_cpu_buffered_read_buf()
         * acts the same as tracefs_cpu_read_buf(). But this is just
         * an example on how to use tracefs_cpu_is_mapped().
         */
        mapped = tracefs_cpu_is_mapped(tcpu);
        if (!mapped)
                printf("Was not able to map, falling back to buffered read\n");
        while ((kbuf = mapped ? tracefs_cpu_read_buf(tcpu, true) :
                        tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_subbuf(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_subbuf(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}

NAME

tracefs_cpu_map, tracefs_cpu_map_get_id, tracefs_cpu_map_get_name, tracefs_cpu_map_get_online, tracefs_cpu_map_get_nr_cpus, tracefs_cpu_map_foreach_cpu — CPU map manipulation

SYNOPSIS

#include <tracefs.h>

struct tracefs_cpu_map *
tracefs_cpu_map_get(void);

const char *
tracefs_cpu_map_get_name(struct tracefs_cpu_map *map, int cpu);

int
tracefs_cpu_map_get_id(struct tracefs_cpu_map *map, const char *name);

int
tracefs_cpu_map_get_nr_cpus(struct tracefs_cpu_map *map);

int
tracefs_cpu_map_get_online(struct tracefs_cpu_map *map, int cpu);

void
tracefs_cpu_map_put(struct tracefs_cpu_map *map);

int
tracefs_cpu_map_foreach_cpu(struct tracefs_cpu_map *map,
int (*callback)(int cpu, const char *name, void *data), void *data);

DESCRIPTION

The tracefs library provides functions to interact with the tracefs filesystem, which is used by the kernel for tracing purposes. The CPU map is a representation of the CPUs available on the system and their names (e.g., "cpu0", "cpu1").

The tracefs_cpu_map_get() function retrieves the CPU map for the current system. It returns a pointer to a struct tracefs_cpu_map on success, or NULL on failure.

The tracefs_cpu_map_get_name() function returns the name of the CPU specified by cpu (e.g., "cpu0" for CPU 0).

The tracefs_cpu_map_get_id() function returns the CPU ID for the given CPU name (e.g., 0 for "cpu0").

The tracefs_cpu_map_get_nr_cpus() function returns the total number of CPUs present in the map.

The tracefs_cpu_map_get_online() function returns 1 if the CPU is online, 0 if offline, and -1 on error.

The tracefs_cpu_map_put() function releases the resources associated with the CPU map.

The tracefs_cpu_map_foreach_cpu() function iterates over all CPUs in the map and calls the callback function for each CPU. The callback function receives the CPU ID, its name, and the user-provided data pointer. If the callback returns a non-zero value, the iteration stops.

RETURN VALUE

Functions return values as described above.

EXAMPLE

This example demonstrates how to iterate over the CPU map and print CPU information:

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int print_cpu_info(int cpu, const char *name, void *data)
{
    struct tracefs_cpu_map *map = data;
    int online = tracefs_cpu_map_get_online(map, cpu);

    printf("CPU %d: Name: %s, Online: %s
",
            cpu,
            name,
            online ? "Yes" : "No");

    return 0; /* Continue iteration */
}

int main(void)
{
    struct tracefs_cpu_map *map;

    map = tracefs_cpu_map_get();
    if (!map) {
        perror("Failed to get CPU map");
        return 1;
    }

    printf("Number of CPUs: %d
", tracefs_cpu_map_get_nr_cpus(map));

    if (tracefs_cpu_map_foreach_cpu(map, print_cpu_info, map) != 0) {
        fprintf(stderr, "Error during CPU iteration.
");
    }

    tracefs_cpu_map_put(map);

    return 0;
}
