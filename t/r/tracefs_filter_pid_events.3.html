NOMBRE

tracefs_filter_pid_function, tracefs_filter_pid_events, tracefs_filter_pid_function_clear, tracefs_filter_pid_events_clear - Añadir y eliminar el filtrado de PID para funciones y eventos

SINOPSIS

#include <tracefs.h>
int tracefs_filter_pid_function(struct tracefs_instance *instance, int pid,
                                bool reset, bool notrace);
int tracefs_filter_pid_function_clear(struct tracefs_instance *instance, bool notrace);
int tracefs_filter_pid_events(struct tracefs_instance *instance, int pid,
                             bool reset, bool notrace);
int tracefs_filter_pid_events_clear(struct tracefs_instance *instance, bool notrace);

DESCRIPCIÓN

Tanto los eventos como las funciones se pueden filtrar por PID, pero se hacen por separado. El filtrado de PID para funciones afecta al rastreador de funciones y de gráfico de funciones (function y function_graph), mientras que el filtrado de PID para eventos afecta a todos los eventos como sched_switch y sched_waking. Si la opción TRACEFS_OPTION_FUNCTION_FORK está habilitada (ver tracefs_option_enable(3)), cualquier PID que se establezca como parte del filtrado de PID de funciones tendrá automáticamente sus hijos añadidos cuando nazcan, así como el PID eliminado cuando salgan. Si se establece la opción TRACEFS_OPTION_EVENT_FORK, ocurre lo mismo para el filtrado de PID de eventos. Esto también incluye la opción notrace donde los hilos e hijos de los PIDs etiquetados como notrace tampoco serán rastreados.

La función tracefs_filter_pid_function() afecta al filtrado de PID de funciones y tracefs_filter_pid_events() afecta al filtrado de eventos de PID. Para ambas funciones, añaden un pid a filtrar en la instance dada. Si reset es verdadero, se eliminarán los PIDs que ya se estén filtrando; de lo contrario, el pid simplemente se añade al filtrado. Si notrace es verdadero, el PID se añade a la lista de PIDs que no deben ser rastreados. Nota, que reset solo afecta a la lista asociada con notrace. Es decir, si tanto reset como notrace son verdaderos, no afectará a los PIDs que deben ser rastreados. Lo mismo ocurre si reset es verdadero y notrace es falso, no afectará a los PIDs que no deben ser rastreados.

La función tracefs_filter_pid_function_clear() afecta al filtrado de PID de funciones y tracefs_filter_pid_events_clear() afecta al filtrado de eventos de PID. Para ambas funciones, eliminará todos los PIDs que se estén filtrando para el filtro dado. Si notrace es verdadero, eliminará todos los PIDs que no deben ser rastreados; de lo contrario, si es falso, eliminará todos los PIDs que deben ser rastreados.

VALOR DE RETORNO

Todas las funciones devuelven 0 en caso de éxito y -1 en caso de error.

EJEMPLO

#include <stdlib.h>
#include <stdio.h>
#include <ctype.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [-e|-f][-c|-n] pid [pid ...]\n", argv[0]);
        fprintf(stderr, "   -e habilita el filtro de eventos\n");
        fprintf(stderr, "   -f habilita el filtro de funciones\n");
        fprintf(stderr, "     (el valor predeterminado es ambos, función y evento)\n");
        fprintf(stderr, "   -c borra el filtro\n");
        fprintf(stderr, "   -n filtro notrace\n");
        exit(-1);
}
int main (int argc, char **argv)
{
        bool events = false;
        bool funcs = false;
        bool neg = false;
        bool clear = false;
        bool reset = true;
        int i;
        for (i = 1; i < argc && argv[i][0] == '-'; i++) {
                char *arg = argv[i];
                int c;
                for (c = 1; arg[c]; c++) {
                        switch (arg[c]) {
                        case 'e': events = true; break;
                        case 'f': funcs = true; break;
                        case 'n': neg = true; break;
                        case 'c': clear = true; break;
                        default:
                                usage(argv);
                        }
                }
                if (c == 1)
                        usage(argv);
        }
        if (i == argc && !clear)
                usage(argv);
        if (!events && !funcs) {
                events = true;
                funcs = true;
        }
        if (clear) {
                if (events)
                        tracefs_filter_pid_events_clear(NULL, neg);
                if (funcs)
                        tracefs_filter_pid_function_clear(NULL, neg);
                exit(0);
        }
        for (; i < argc; i++) {
                int pid = atoi(argv[i]);
                if (events)
                        tracefs_filter_pid_events(NULL, pid, reset, neg);
                if (funcs)
                        tracefs_filter_pid_function(NULL, pid, reset, neg);
                reset = false;
        }
        exit(0);
}

NAME

tracefs_filter_pid_events - Filter trace events for a specific PID

SYNOPSIS

#include <tracefs.h>

int tracefs_filter_pid_events(const char *pid);

DESCRIPTION

The tracefs_filter_pid_events function sets a filter to capture trace events only for the given Process ID (PID). This is useful for debugging specific processes without being overwhelmed by trace data from other processes.

The pid argument is a string representing the PID of the process for which events should be traced.

This function manipulates the tracefs filesystem to set the appropriate filter. It should be called before enabling tracing.

RETURN VALUE

On success, tracefs_filter_pid_events returns 0. On failure, it returns a negative value indicating an error.

EXAMPLE

To trace events for PID 1234: 

int ret = tracefs_filter_pid_events("1234");
if (ret < 0) {
    perror("tracefs_filter_pid_events");
    // handle error
}
