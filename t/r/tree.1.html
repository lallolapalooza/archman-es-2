TREE(1) Manual de Comandos Generales TREE(1)

NOMBRE

tree - lista el contenido de los directorios en formato de árbol.

SINOPSIS

tree [-acdfghilnpqrstuvxACDFJQNSUX] [-L nivel [-R]] [-H [-]baseHREF] [-T título] [-o nombre_archivo] [-P patrón] [-I patrón] [--gitignore] [--gitfile[=]archivo] [--matchdirs] [--metafirst] [--ignore-case] [--nolinks] [--hintro[=]archivo] [--houtro[=]archivo] [--inodes] [--device] [--sort[=]nombre] [--dirsfirst] [--filesfirst] [--filelimit[=]#] [--si] [--du] [--prune] [--charset[=]X] [--timefmt[=]formato] [--fromfile] [--fromtabfile] [--fflinks] [--info] [--infofile[=]archivo] [--noreport] [--hyperlink] [--scheme[=]esquema] [--authority[=]nombre_host] [--opt-toggle] [--version] [--help] [--] [directorio ...]

DESCRIPCIÓN

Tree es un programa de listado recursivo de directorios que produce un listado indentado en profundidad de los archivos, que se colorea al estilo de dircolors si la variable de entorno LS_COLORS está establecida y la salida es a tty. Sin argumentos, tree lista los archivos en el directorio actual. Cuando se dan argumentos de directorio, tree lista todos los archivos y/o directorios encontrados en los directorios dados, cada uno en su turno. Al finalizar el listado de todos los archivos/directorios encontrados, tree devuelve el número total de archivos y/o directorios listados.

Por defecto, cuando se encuentra un enlace simbólico, la ruta a la que se refiere el enlace simbólico se imprime después del nombre del enlace en el formato:


nombre -> ruta_real

Si se da la opción `-l' y el enlace simbólico se refiere a un directorio real, entonces tree seguirá la ruta del enlace simbólico como si fuera un directorio real.

OPCIONES

Tree entiende las siguientes opciones de línea de comandos:

OPCIONES DE LISTADO

-a
Se imprimen todos los archivos. Por defecto, tree no imprime archivos ocultos (aquellos que comienzan con un punto `.'). En ningún caso tree imprime las construcciones del sistema de archivos `.' (directorio actual) y `..' (directorio anterior).
-d
Listar solo directorios.
-l
Sigue los enlaces simbólicos si apuntan a directorios, como si fueran directorios. Se evitan los enlaces simbólicos que resulten en recursión al detectarse.
-f
Imprime el prefijo de ruta completa para cada archivo.
-x
Permanecer solo en el sistema de archivos actual. Similar a find-xdev.
-L nivel
Profundidad máxima de visualización del árbol de directorios.
-R
Cruza recursivamente hacia abajo en el árbol cada nivel de directorios (ver opción -L), y en cada nivel se escribe en un archivo llamado 00Tree.html (estilo -o).
-P patrón
Listar solo aquellos archivos que coincidan con el comodín patrón. Puede tener múltiples opciones -P. Nota: debe usar la opción -a para considerar también los archivos que comienzan con un punto `.', para la coincidencia. Los operadores de comodín válidos son `*' (cero o más caracteres), `**' (cero o más caracteres así como / nulo, es decir, /**/ puede coincidir con un solo /), `?' (cualquier carácter individual), `[...]' (cualquier carácter individual listado entre corchetes (opcionalmente - (guion) para rango de caracteres puede ser usado: ej: [A-Z]), y `[^...]' (cualquier carácter individual no listado entre corchetes) y `|' separa patrones alternativos. Un '/' al final del patrón coincide con directorios, pero no con archivos.
-I patrón
No listar aquellos archivos que coincidan con el comodín patrón. Puede tener múltiples opciones -I. Ver -P arriba para información sobre patrones de comodín.
--gitignore
Usa los archivos git .gitignore para filtrar archivos y directorios. También usa $GIT_DIR/info/exclude si está presente.
--gitfile[=]archivo
Usa archivo explícitamente como archivo gitignore.
--ignore-case
Si se especifica un patrón de coincidencia con la opción -P o -I, esto hará que el patrón coincida sin importar la mayúscula o minúscula de cada letra.
--matchdirs
Si se especifica un patrón de coincidencia con la opción -P, esto hará que el patrón se aplique a los nombres de los directorios (además de los nombres de archivo). En caso de coincidencia con el nombre del directorio, la coincidencia se desactiva para el contenido del directorio. Si se utiliza la opción --prune, los directorios vacíos que coincidan con el patrón no se podarán.
--metafirst
Imprime la información de metadatos al principio de la línea en lugar de después de las líneas de indentación.
--prune
Hace que tree elimine los directorios vacíos de la salida, útil cuando se usa junto con -P o -I. Ver BUGS AND NOTES abajo para más información sobre esta opción.
--info
Imprime comentarios de archivos encontrados en archivos .info. Ver ARCHIVOS .INFO abajo para más información sobre el formato de los archivos .info.
--infofile[=]archivo
Usa archivo explícitamente como archivo de información.
--noreport
Omite la impresión del informe de archivos y directorios al final del listado del árbol.
--charset[=]juego_de_caracteres
Establece el juego de caracteres a usar al generar HTML y para dibujar líneas.
--filelimit[=]#
No desciende en directorios que contengan más de # entradas.
--timefmt[=]formato
Imprime (implica -D) y formatea la fecha según la cadena de formato que usa la sintaxis de strftime(3).
-o nombre_archivo
Envía la salida al archivo nombre_archivo.

OPCIONES DE ARCHIVO

-q
Imprime caracteres no imprimibles en los nombres de archivo como signos de interrogación en lugar de lo predeterminado.
-N
Imprime caracteres no imprimibles tal cual en lugar de como números octales escapados.
-Q
Comilla los nombres de los archivos entre comillas dobles.
-p
Imprime el tipo de archivo y los permisos para cada archivo (como en ls -l).
-u
Imprime el nombre de usuario, o el UID # si no hay nombre de usuario disponible, del archivo.
-g
Imprime el nombre del grupo, o el GID # si no hay nombre de grupo disponible, del archivo.
-s
Imprime el tamaño de cada archivo en bytes junto con el nombre.
-h
Imprime el tamaño de cada archivo pero de una manera más legible por humanos, p. ej., añadiendo una letra de tamaño para kilobytes (K), megabytes (M), gigabytes (G), terabytes (T), petabytes (P) y exabytes (E).
--si
Similar a -h pero usa unidades SI (potencias de 1000) en lugar de

OPCIONES_DE_ARCHIVO

-a
Todos los archivos son impresos. Por defecto, los archivos que empiezan con un punto (.) se omiten, excepto para "." y "..".
-A
No imprime las líneas de indentación. Es útil si se usa junto con la opción -f. También elimina tanto espacio en blanco como sea posible si se usa con las opciones -J o -X.
-d
Lista los nombres de los archivos en lugar de sus contenidos. Esto es útil para listar un árbol de directorios, pero no los archivos que contiene.
-e
Cada archivo es impreso en una línea. Esto está desactivado por defecto cuando se imprime en la terminal, pero está activado si la salida es redirigida. Solo se imprime el nombre del archivo en la línea. Es útil para listar directorios, pero no los archivos que contienen.
-f
No se resuelve el recorrido de los enlaces simbólicos. Por defecto, tree sigue los enlaces simbólicos de directorios. Con esta opción, se imprimen los enlaces simbólicos como si fueran archivos normales. Implica -l.
-F
Añade un `/` para directorios, un `=` para archivos socket, un `*` para archivos ejecutables, un `>` para puertas (Solaris) y un `|` para FIFO, como en ls -F
-i
No imprime las líneas de indentación, útil cuando se usa junto con la opción -f. También elimina tanto espacio en blanco como sea posible cuando se usa con las opciones -J o -X.
-L level
No desciende más allá del level especificado de profundidad de directorios.
-l
Sigue los enlaces simbólicos de directorios. Por defecto, tree no los sigue.
-N
No resuelve los nombres de archivo. Esto es útil si tienes caracteres que tu terminal no puede mostrar correctamente. Implica -w.
-p
Imprime el modo de permisos para cada archivo, como en ls -l.
-q
Imprime el carácter `?' en lugar de los caracteres sin formato (como nueva línea, tabulador, etc.).
-Q
Pone comillas a los nombres de archivo y directorio. Útil para evitar problemas con espacios o caracteres especiales en los nombres.
-s
Imprime el tamaño de cada archivo en bytes.
-h
Imprime el tamaño de los archivos en un formato legible por humanos (ej. K, M, G).
-R
Lista los archivos de forma recursiva. Esto es lo mismo que listar los archivos de forma recursiva en el directorio actual.
--du
Para cada directorio, informa de su tamaño como la acumulación de tamaños de todos sus archivos y subdirectorios (y sus archivos, y así sucesivamente). La cantidad total de espacio utilizado también se proporciona en el informe final (como el comando 'du -c'). Esta opción requiere que tree lea todo el árbol de directorios antes de emitirlo, ver BUGS AND NOTES abajo. Implica -s.
-D
Imprime la fecha de la última hora de modificación o, si se usa -c, la última hora de cambio de estado del archivo listado.
--inodes
Imprime el número de inodo del archivo o directorio
--device
Imprime el número de dispositivo al que pertenece el archivo o directorio

OPCIONES_DE_ORDENACIÓN

-v
Ordena la salida por versión.
-t
Ordena la salida por la última hora de modificación en lugar de alfabéticamente.
-c
Ordena la salida por el último cambio de estado en lugar de alfabéticamente. Modifica la opción -D (si se usa) para imprimir el último cambio de estado en lugar de la hora de modificación.
-U
No ordenar. Lista los archivos en orden de directorio. Deshabilita --dirsfirst.
-r
Ordena la salida en orden inverso. Este es un meta-orden que altera los órdenes anteriores. Esta opción se deshabilita cuando se usa -U.
--dirsfirst
Lista directorios antes que archivos. Este es un meta-orden que altera los órdenes anteriores. Esta opción se deshabilita cuando se usa -U.
--filesfirst
Lista archivos antes que directorios. Este es un meta-orden que altera los órdenes anteriores. Esta opción se deshabilita cuando se usa -U.
--sort[=]type
Ordena la salida por type en lugar de por nombre. Los valores posibles son: ctime (-c), mtime (-t), size, version (-v) o none (-U).

OPCIONES_GRÁFICAS

-i
Hace que tree no imprima las líneas de indentación, útil cuando se usa junto con la opción -f. También elimina tanto espacio en blanco como sea posible cuando se usa con las opciones -J o -X.
-A
Activa el truco de gráficos de líneas ANSI al imprimir las líneas de indentación.
-S
Activa los gráficos de líneas CP437 (útil cuando se usan fuentes del modo consola de Linux). Esta opción ahora es equivalente a `--charset=IBM437' y puede ser depreciada eventualmente.
-n
Desactiva la colorización siempre, anulada por la opción -C, sin embargo, anula CLICOLOR_FORCE si está presente.
-C
Activa la colorización siempre, utilizando los valores predeterminados de color integrados si las variables de entorno LS_COLORS o TREE_COLORS no están establecidas. Útil para colorear la salida a una tubería.

OPCIONES_XML/JSON/HTML/HIPERVÍNCULOS

-X
Activa la salida XML. Emite el árbol de directorios como un archivo formateado en XML.
-J
Activa la salida JSON. Emite el árbol de directorios como una matriz formateada en JSON.
-H [-]baseHREF
Activa la salida HTML, incluyendo referencias HTTP. Útil para sitios ftp. baseHREF proporciona la ubicación base de ftp al usar la salida HTML. Es decir, el directorio local puede ser `/local/ftp/pub', pero debe referenciarse como `ftp://hostname.organization.domain/pub' (baseHREF debería ser `ftp://hostname.organization.domain'). Si baseHREF comienza con un guión (-), entonces se elimina el guión y se indica que tree debe eliminar el primer nombre de directorio de la URL href. Indicación: no usar líneas ANSI con esta opción, y no dar más de un directorio en la lista de directorios. Si desea utilizar colores mediante una hoja de estilos CSS, utilice la opción -C además de esta opción para forzar la salida de colores.
--hintro[=]file
Utiliza file como introducción HTML en lugar de la predeterminada. Utilice un archivo vacío o /dev/null para eliminar la introducción por completo.
--houtro[=]file
Utiliza file como conclusión HTML en lugar de la predeterminada. Utilice un archivo vacío o /dev/null para eliminar la conclusión por completo.
-T title
Establece el título y la cadena del encabezado H1 en el modo de salida HTML.
--nolinks
Desactiva los hipervínculos en la salida HTML.
--hyperlink
Habilita hipervínculos de terminal OSC 8 para terminales que los soporten. Ver BUGS AND NOTES abajo.
--scheme[=]schema
Establece el esquema utilizado en los hipervínculos OSC 8. El esquema predeterminado es 'file://'. Si el esquema omite los dos puntos (:), entonces se añadirán :// al esquema.
--authority[=]hostname|authority
Establece la autoridad (nombre de host) a utilizar para los hipervínculos OSC 8. Por defecto, se utiliza el nombre de host local de la máquina devuelto por gethostname() como autoridad. Un punto (.) o un conjunto de comillas dobles dobles (""), sin '= ', (es decir, la cadena vacía) se puede utilizar para indicar una autoridad nula.

OPCIONES_DE_ENTRADA

--fromfile
Lee una lista de directorios de un archivo en lugar del sistema de archivos. Las rutas proporcionadas en la línea de comandos son archivos de los que leer en lugar de directorios que buscar. El directorio punto (.) indica que tree debe leer rutas de la entrada estándar. NOTA: esto solo es adecuado para leer la salida de un programa como find, no 'tree -fi', ya que los enlaces simbólicos no se distinguen de los archivos que simplemente contienen ' -> ' como parte del nombre de archivo a menos que se utilice la opción --fflinks.
--fromtabfile
Similar a --fromfile, tree lee un árbol de directorios de un archivo de texto donde los archivos están indentados con tabulaciones en un formato similar a un árbol para indicar el nivel de anidamiento del directorio.
--fflinks
Procesa la información de enlaces simbólicos encontrada en un archivo, como la salida de 'tree -fi --noreport'. Solo la primera ocurrencia de la cadena ' -> ' se utiliza para denotar la separación del nombre de archivo del enlace.

OPCIONES_VARIAS

--opt-toggle
Habilita el "conmutador" de opciones. Activa la capacidad de conmutar opciones como -a, -h, etc. Útil para añadir a un alias cuando se desean deshabilitar opciones habilitadas en el alias.
--help
Muestra una lista de uso detallada.
--version
Muestra la versión de tree.
--
Terminador de procesamiento de opciones. No se procesarán más opciones después de este.

ARCHIVOS .INFO

Los archivos .info son similares a los archivos .gitignore; si se encuentra un archivo .info mientras se escanea un directorio, se lee y se añade a una pila de información .info. Cada archivo está compuesto por comentarios (líneas que comienzan con marcas de almohadilla (#)) o patrones comodín que pueden coincidir con un archivo relativo al directorio donde se encuentra el archivo .info. Si un archivo coincide con un patrón, el comentario indentado con tabulaciones que sigue al patrón se utiliza como comentario del archivo. Un comentario se termina con una línea no indentada con tabulaciones. Múltiples patrones, cada uno en una línea, pueden compartir el mismo comentario.

ENTORNO

LS_COLORS Información de color creada por dircolors
TREE_COLORS Utiliza esto para obtener información de color sobre LS_COLORS si está configurado.
TREE_CHARSET Juego de caracteres que tree utilizará en modo HTML.
CLICOLOR Habilita la colorización incluso si TREE_COLORS o LS_COLORS no están configurados.
CLICOLOR_FORCE Habilita la colorización siempre (efectivamente -C)
NO_COLOR Deshabilita la colorización (efectivamente -n) (ver https://no-color.org/)
LC_CTYPE Localidad para la salida de nombres de archivo.
LC_TIME Localidad para la salida de timefmt, ver strftime(3).
TZ Zona horaria para la salida de timefmt, ver strftime(3).
STDDATA_FD Habilita la función stddata, opcionalmente configura el descriptor a usar.

BUGS AND NOTES

El árbol no poda directorios "vacíos" cuando se utilizan las opciones -P e -I por defecto. Utilice la opción --prune.

Las opciones -h y --si redondean al número entero más cercano a diferencia de las implementaciones de ls que siempre redondean hacia arriba.

Podar archivos y directorios con las opciones -I, -P y --filelimit provocará informes de recuento de archivos/directorios incorrectos.

Las opciones --prune y --du hacen que tree acumule todo el árbol en memoria antes de emitirlo. Para árboles de directorios grandes, esto puede causar un retraso significativo en la salida y el uso de grandes cantidades de memoria.

El búfer de expansión de timefmt está limitado a unos ridículos 255 caracteres. La salida de cadenas de tiempo más largas que esto será indefinida, pero se garantiza que no excederá los 255 caracteres.

Los árboles XML/JSON no tienen color, lo cual es una pena. La utilidad jq puede colorear el JSON, pero no los nombres de archivo por tipo de archivo al estilo LS_COLORS.

Los hipervínculos OSC 8 pueden tener un soporte deficiente en su terminal. Para mi versión de Konsole es necesario establecer el esquema a file: (sin //) y utilizar una autoridad nula. También puede ser necesario pasar 3,5 horas buscando la opción para activar los hipervínculos.

Probablemente más.

A partir de la versión 2.0.0, en Linux, tree intentará generar automáticamente un árbol JSON compacto en el descriptor de archivo 3 (lo que llamo stddata), si está presente y la variable de entorno STDDATA_FD está definida o establecida a un valor de descriptor de archivo positivo y distinto de cero para usarlo en la salida. Se espera que algún día un mejor shell de Linux/Unix pueda aprovechar esta característica, aunque BSON probablemente sería un mejor formato para esto.
