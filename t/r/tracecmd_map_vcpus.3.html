tracecmd_map_vcpus(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_map_vcpus, tracecmd_get_cpu_map, tracecmd_map_find_by_host_pid, tracecmd_map_get_host_pid, tracecmd_map_get_guest, tracecmd_map_set_private, tracecmd_map_get_private - Mapeo de datos de host y guest

SINOPSIS

#include <trace-cmd.h>
int tracecmd_map_vcpus(struct tracecmd_input **handles, int nr_handles);
struct tracecmd_cpu_map *tracecmd_get_cpu_map(struct tracecmd_input *handle, int cpu);
struct tracecmd_cpu_map *tracecmd_map_find_by_host_pid(struct tracecmd_input *handle,
                                                      int host_pid);
int tracecmd_map_get_host_pid(struct tracecmd_cpu_map *map);
struct tracecmd_input *tracecmd_map_get_guest(struct tracecmd_cpu_map *map);
void tracecmd_map_set_private(struct tracecmd_cpu_map *map, void *priv);
void *tracecmd_map_get_private(struct tracecmd_cpu_map *map);

DESCRIPCIÓN

Este conjunto de APIs se utiliza para mapear archivos de traza de host y guest para facilitar un análisis de traza posterior.

tracecmd_map_vcpus() toma una matriz de handles donde cada elemento de esa matriz fue creado por una de las funciones tracecmd_open(3), y el número de handles como nr_handles. Se espera que el primer handle en la matriz de handles sea el descriptor del archivo de traza del host, y los restantes sean archivos de traza de guests que se ejecutan en el host y que fueron creados por las interacciones de trace-cmd record(1) y trace-cmd agent(1). Devuelve el número de guests encontrados en handles que fueron asociados con el host, o un valor negativo en caso de error.

tracecmd_get_cpu_map() devuelve un descriptor para una CPU dada para un handle. Si el handle era un guest definido por tracecmd_map_vcpus(), entonces el mapeo creado por esa función que está asociado con este vCPU en particular (denotado por cpu) de handle. Este descriptor puede ser utilizado por las funciones tarcecmd_map_get_guest(), tracecmd_map_set_private() y tracecmd_map_get_private().

tracecmd_map_find_by_host_pid() devolverá un mapeo para una CPU virtual de guest que está siendo manejada por el host_pid dado. Tenga en cuenta que el handle proporcionado puede ser el handle del host o uno de los handles del guest para ese host que fue mapeado por tracecmd_map_vcpus(), incluso si el handle del guest no tiene el vCPU que representa el host_pid.

tracecmd_map_get_host_pid() devolverá el host_pid para un map dado que fue recuperado por una de las funciones anteriores.

tracecmd_map_get_guest() devolverá el guest_handle para un map dado que fue recuperado por una de las funciones anteriores.

tracecmd_map_set_private() permite a la aplicación asignar datos privados para un mapeo de hilo de host a vCPU de guest definido por map.

tracecmd_map_get_private() recupera los datos priv de map que fueron establecidos por tracecmd_map_set_private().

VALOR DE RETORNO

tracecmd_map_vcpus() devuelve el número de guests en la matriz handles que fueron mapeados al handle del host que es la primera entrada en handles. Devuelve -1 en caso de error.

tracecmd_get_cpu_map() devuelve un mapa creado por tracecmd_map_vcpus() para una cpu dada para un handle dado, o NULL si no se encuentra.

tracecmd_map_find_by_host_pid() devuelve un mapa que está asociado por la tarea del host con host_pid como su ID de proceso. handle puede ser tanto un handle del host como uno de los handles del guest que fueron mapeados al host a través de tracecmd_map_vcpus(), incluso si el handle del guest es un guest diferente al para el cual es el mapeo. Devuelve NULL si no se encuentra.

tracecmd_map_get_host_pid() devuelve el ID de proceso del host para un mapeo asociado definido por map.

tracecmd_map_get_guest() devuelve el handle del guest para un mapeo asociado definido por map.

tracecmd_map_get_private() devuelve los datos privados de un mapeo definido por map que fue establecido por tracecmd_map_set_private().

EJEMPLO

#include <stdlib.h>
#include <errno.h>
#include <trace-cmd.h>
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        int nr_handles;
        int i;
        if (argc < 2) {
                printf("usage: host_trace.dat guest1_trace.dat [guest2_trace.dat ...]\n");
                exit(-1);
        }
        for (i = 1; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[1]);
                        exit(-1);
                }
                tracecmd_set_private(handles[nr_handles], argv[i]);
                nr_handles++;
        }
        tracecmd_map_vcpus(handles, nr_handles);
        for (i = 1; i < nr_handles; i++) {
                struct tracecmd_cpu_map *map;
                struct tep_handle *tep;
                const char *file = tracecmd_get_private(handles[i]);
                int cpus, cpu;
                printf("Mappings for guest %s:\n", file);
                tep = tracecmd_get_tep(handles[i]);
                cpus = tep_get_cpus(tep);
                for (cpu = 0; cpu < cpus; cpu++) {
                        printf("  [%03d] ", cpu);
                        map = tracecmd_get_cpu_map(handles[i], cpu);
                        if (!map) {
                                printf("Has no mapping!\n");
                                continue;
                        }
                        printf("host_pid: %d\n", tracecmd_map_get_host_pid(map));
                }
        }
        for (i = 0; i < nr_handles; i++)
                tracecmd_close(handles[i]);
        free(handles);
        exit(0);
}

NOMBRE

tracecmd_map_vcpus - Obtiene el mapeo de dispositivos de traza a CPUs virtuales.

SINOPSIS

#include <trace-cmd.h>

int tracecmd_map_vcpus(void *(*map_func)(void *), void *data);

DESCRIPCIÓN

La función tracecmd_map_vcpus itera sobre todos los dispositivos de traza disponibles en el sistema y llama a la función map_func proporcionada para cada uno. La función map_func recibe un puntero al dispositivo de traza como argumento y puede realizar cualquier operación deseada con él.

El argumento data es un puntero de propósito general que se pasa a map_func. Esto permite pasar datos adicionales a la función de mapeo.

VALOR DE RETORNO

Devuelve 0 si la operación se completa con éxito, o un código de error en caso contrario.

EJEMPLO

#include <stdio.h>
#include <trace-cmd.h>

static void* print_trace_device(void *data) {
    struct trace_device *td = data;
    printf("Trace device: %s\n", td->name);
    return NULL;
}

int main() {
    if (tracecmd_map_vcpus(print_trace_device, NULL) < 0) {
        perror("tracecmd_map_vcpus");
        return 1;
    }
    return 0;
}
