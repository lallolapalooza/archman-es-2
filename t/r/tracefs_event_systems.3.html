Paquete: libtracefs

LIBTRACEFS(3) libtracefs Manual LIBTRACEFS(3)

NOMBRE

tracefs_event_systems, tracefs_system_events, tracefs_event_enable, tracefs_event_disable, tracefs_event_is_enabled - Trabajar con sistemas y eventos de rastreo.

SINOPSIS

#include <tracefs.h>
enum tracefs_event_state {
        TRACEFS_ERROR = -1,
        TRACEFS_ALL_DISABLED = 0,
        TRACEFS_ALL_ENABLED = 1,
        TRACEFS_SOME_ENABLED = 2,
};
char **tracefs_event_systems(const char *tracing_dir);
char **tracefs_system_events(const char *tracing_dir, const char *system);
int tracefs_event_enable(struct tracefs_instance *instance, const char *system,
                           const char *event);
int tracefs_event_disable(struct tracefs_instance *instance, const char *system,
                            const char *event);
enum tracefs_enable_state tracefs_event_is_enabled(struct tracefs_instance *instance,
                         const char *system, const char *event);

DESCRIPCIÓN

APIs relacionadas con sistemas y eventos de rastreo.

La función tracefs_event_systems() devuelve un array de cadenas con los nombres de todos los sistemas de rastreo registrados, ubicados en el directorio tracing_dir dado. Este podría ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de rastreo de la máquina local, o podría ser una ruta a una copia del directorio tracefs de otra máquina. La última entrada en el array es un puntero NULL. El array debe ser liberado con la API tracefs_list_free().

La función tracefs_system_events() devuelve un array de cadenas con los nombres de todos los eventos de rastreo registrados para el sistema de rastreo dado especificado por system, ubicados en el directorio tracing_dir dado. Este podría ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de rastreo de la máquina local, o podría ser una ruta a una copia del directorio tracefs de otra máquina. La última entrada en el array es un puntero NULL. El array debe ser liberado con la API tracefs_list_free().

La función tracefs_event_enable() habilita un evento dado basado en el system y event pasados para la instance dada. Si instance es NULL, entonces se utiliza el directorio de rastreo de nivel superior. Si system y event son ambos NULL, entonces se habilitan todos los eventos para la instance. Si event es NULL, entonces se habilitan todos los eventos dentro del system. Si system es NULL, entonces se buscan todos los sistemas y se habilita cualquier evento dentro de un sistema que coincida con event. Tanto system como event pueden ser expresiones regulares tal como se definen en regex(3).

La función tracefs_event_disable() deshabilita los eventos que coinciden con los parámetros system y event para la instance dada. Qué eventos se deshabilitan sigue las mismas reglas que tracefs_event_enable() para hacer coincidir eventos. Es decir, si instance es NULL, entonces se utiliza el directorio de rastreo de nivel superior. Si tanto system como event son NULL, entonces se deshabilitan todos los eventos para la instance dada, y así sucesivamente.

La función tracefs_event_is_enabled() devuelve si un evento está habilitado, un conjunto de eventos están habilitados, un sistema está habilitado o todos los eventos están habilitados. Si tanto system como event son NULL, entonces devuelve el estado de habilitación de todos los eventos. Si system no es NULL y event es NULL, entonces comprobará si todos los eventos en todos los sistemas que system y devuelve el estado de habilitación de esos eventos. Si system es NULL y event no es NULL, entonces coincidirá con todos los eventos en todos los sistemas que coincidan con event y devolverá su estado de habilitación. Si tanto system como event no son NULL, entonces devolverá el estado de habilitación de todos los eventos coincidentes. El estado de habilitación se define como:

TRACEFS_ERROR - Ocurrió un error, incluido que no se encontró ninguna coincidencia de evento.

TRACEFS_ALL_DISABLED - Todos los eventos coincidentes están deshabilitados.

TRACEFS_ALL_ENABLED - Todos los eventos coincidentes están habilitados.

TRACEFS_SOME_ENABLED - Algunos eventos coincidentes estaban habilitados mientras que otros no.

VALOR DE RETORNO

Las funciones tracefs_event_systems() y tracefs_system_events() devuelven un array de cadenas. El último elemento de ese array es un puntero NULL. El array debe ser liberado con la API tracefs_list_free(). En caso de error, se devuelve NULL.

Tanto tracefs_event_enable() como tracefs_event_disable() devuelven 0 si encontraron algún evento coincidente (Nota: no comprueba el estado anterior del evento. Si tracefs_event_enable() encuentra un evento que ya está habilitado, y no hay otros errores, entonces devolverá 0). Si ocurre un error, incluso si se encontraron otros eventos, devolverá -1 y se establecerá errno. Si no ocurren errores, pero no se encuentran eventos que coincidan con los parámetros system y event, entonces se devuelve -1 y no se establece errno.

La función tracefs_event_is_enabled() devuelve el estado de habilitación de los eventos coincidentes o TRACEFS_ERROR en caso de error.

EJEMPLO

#include <tracefs.h>
char **systems = tracefs_event_systems(NULL);
        if (systems) {
                int i = 0;
                /* Obtener sistemas de rastreo registrados de la instancia de rastreo superior */
                while (systems[i]) {
                        char **events = tracefs_system_events(NULL, systems[i]);
                        if (events) {
                                /* Obtener eventos registrados en system[i] de la instancia de rastreo superior */
                                int j = 0;
                                while (events[j]) {
                                        /* Obtener event[j] en system[i] de la instancia de rastreo superior */
                                        j++;
                                }
                                tracefs_list_free(events);
                        }
                        i++;
                }
                tracefs_list_free(systems);
        }
