NOMBRE

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Trabajar con archivos y directorios en instancias de trazado.

SINOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPCIÓN

Este conjunto de API se puede utilizar para trabajar con archivos de trazado en todas las instancias de trazado. Cada una de estas API toma un argumento instance, que puede ser NULL para actuar sobre la instancia de nivel superior. De lo contrario, actúa sobre una instancia creada con tracefs_insance_create(3)

La función tracefs_file_exists() comprueba si existe un archivo con el nombre name en la instancia instance.

La función tracefs_dir_exists() comprueba si existe un directorio con el nombre name en la instancia instance.

La función tracefs_instance_get_file() devuelve la ruta completa del archivo con el nombre file dado en la instancia instance. Nota: no comprueba si el archivo existe en la instancia.

La función tracefs_instance_get_dir() devuelve la ruta completa del directorio con el nombre dado en la instancia instance. Nota: no comprueba si el directorio existe en la instancia.

VALOR DE RETORNO

Las funciones tracefs_file_exists() y tracefs_dir_exists() devuelven true si el archivo / directorio existe en la instancia dada o false si no existe.

Las funciones tracefs_instance_get_file() y tracefs_instance_get_dir() devuelven una cadena o NULL en caso de error. La cadena devuelta debe liberarse con tracefs_put_tracing_file().

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Error al crear una nueva instancia de trazado */
                ...

                path =  = tracefs_instance_get_file(inst, "trace_clock")

                        /* Error al obtener la ruta del archivo trace_clock en la instancia foo */
                        ...

                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Error al leer el archivo trace_clock en la instancia foo */
                        ...

                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Error al establecer el reloj de trazado global en la instancia foo */
                        ...
                }
        } else {
                /* La instancia foo no soporta trace clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* La instancia foo soporta opciones de trazado */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Error al obtener la ruta del directorio options en la instancia foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* La instancia foo no soporta opciones de trazado */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* El trazado está deshabilitado en la instancia principal */
                } else if (res == 1) {
                        /* El trazado está habilitado en la instancia principal */
                } else {
                        /* Estado de trazado desconocido de la instancia principal */
                }
        } else {
                /* Error al leer un entero del archivo tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Descriptor de archivo obtenido para el archivo tracing_on de la instancia principal para escritura */
                ...
                close(fd);
        }

NAME

tracefs_instance_get_file - Get a file descriptor for an instance file.

SYNOPSIS

#include <tracefs.h>

int tracefs_instance_get_file(const char *instance_name,
                              const char *filename,
                              int flags);

DESCRIPTION

The tracefs filesystem allows multiple independent tracing instances to coexist. Each instance has its own set of files under the tracefs mount point, typically located at tracefs mount point + "/instances//".

The function tracefs_instance_get_file() is a convenience function to open a specific file within a given tracing instance.

  • instance_name: The name of the tracing instance. This name is used to identify the subdirectory under tracefs where the instance's files reside.

  • filename: The name of the file within the instance directory. For example, "trace", "events/enable", etc.

  • flags: The flags to be passed to the open(2) system call. These control how the file is opened (e.g., O_RDONLY, O_WRONLY, O_RDWR).

The function constructs the full path to the file by concatenating the tracefs mount point, "/instances/", the instance_name, and the filename, and then opens it using the specified flags.

It's important to note that this function relies on the tracefs filesystem being mounted. The default mount point is typically "/sys/kernel/tracing".

RETURN VALUE

On success, tracefs_instance_get_file() returns a new file descriptor referring to the opened file. On failure, it returns -1 and sets errno to indicate the error.

EXAMPLE

#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>
#include <errno.h>
#include <tracefs.h>

int main() {
    int fd;
    char buf[1024];
    ssize_t n;

    // Attempt to open the 'trace' file in the 'my_instance' tracing instance for reading.
    fd = tracefs_instance_get_file("my_instance", "trace", O_RDONLY);
    if (fd < 0) {
        perror("Failed to open trace file for instance 'my_instance'");
        return 1;
    }

    // Read from the trace file.
    n = read(fd, buf, sizeof(buf) - 1);
    if (n < 0) {
        perror("Failed to read from trace file");
        close(fd);
        return 1;
    }
    buf[n] = '\0';
    printf("Trace data:\n%s\n", buf);

    close(fd);
    return 0;
}
