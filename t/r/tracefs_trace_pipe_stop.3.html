tracefs_trace_pipe_stop(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_trace_pipe_stream, tracefs_trace_pipe_print, tracefs_trace_pipe_stop - redirige el flujo de datos de traza a una salida o a stdout.

SINOPSIS

#include <tracefs.h>
ssize_t tracefs_trace_pipe_stream(int fd, struct tracefs_instance *instance, int flags);
ssize_t tracefs_trace_pipe_print(struct tracefs_instance *instance, int flags);
void tracefs_trace_pipe_stop(struct tracefs_instance *instance);

DESCRIPCIÓN

Si se pasa NULL como instance, se usa la instancia de traza superior.

La lectura del archivo trace_pipe se puede detener llamando a tracefs_trace_pipe_stop(), que podría colocarse en un manejador de señales en caso de que la aplicación desee detener la lectura, por ejemplo, al presionar Ctrl-C.

La función tracefs_trace_pipe_stream() redirige el flujo de datos de traza a un archivo de salida. Se utiliza la llamada al sistema "splice" para mover los datos sin copiarlos entre el espacio de direcciones del kernel y el espacio de direcciones del usuario. El fd es el descriptor de archivo del archivo de salida y flags es una máscara de bits de banderas que se pasarán a la llamada al sistema open del archivo trace_pipe (ver open(2)). Si las banderas contienen O_NONBLOCK, entonces eso también se pasa a las llamadas splice que pueden leer el archivo al descriptor de archivo de la secuencia de salida. Tenga en cuenta que O_RDONLY se combina con las flags y solo O_NONBLOCK es útil para este parámetro.

La función tracefs_trace_pipe_print() es similar a tracefs_trace_pipe_stream(), pero el flujo de datos de traza se redirige a stdout.

VALOR DE RETORNO

Las funciones tracefs_trace_pipe_stream() y tracefs_trace_pipe_print() devuelven el número de bytes transferidos si la operación es exitosa, o -1 en caso de error.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include <fcntl.h>
#include <tracefs.h>
void stop(int sig)
{
        tracefs_trace_pipe_stop(NULL);
}
int main(int argc, char **argv)
{
        mode_t mode = S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH;
        const char *filename;
        int fd;
        int ret;
        if (argc < 2) {
                fprintf(stderr, "uso: %s archivo_salida\n", argv[0]);
                exit(-1);
        }
        filename = argv[1];
        fd = creat(filename, mode);
        if (fd < 0) {
                perror(filename);
                exit(-1);
        }
        signal(SIGINT, stop);
        ret = tracefs_trace_pipe_stream(fd, NULL, SPLICE_F_NONBLOCK);
        close(fd);
        return ret;
}
