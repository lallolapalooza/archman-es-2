Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

TRACE-CMD-ATTACH(1) Manual de libtracefs TRACE-CMD-ATTACH(1)

NOMBRE

trace-cmd-attach - adjunta un archivo trace.dat de invitado a un archivo trace.dat de anfitrión

SINOPSIS

trace-cmd attach [OPCIONES] archivo-trace-anfitrion archivo-trace-invitado pid-invitado [pid-invitado ...]

DESCRIPCIÓN

El trace-cmd(1) attach se utiliza para tomar un archivo trace.dat creado en un invitado y adjuntarlo a un archivo trace.dat que se creó en el anfitrión. En la mayoría de los casos, trace-cmd-agent(1) puede usarse para automatizar esto, pero si por alguna razón el agente no es apropiado, puede ser necesario iniciar la grabación de trace-cmd en el invitado con trace-cmd-record(1). Si la grabación del anfitrión se activa al mismo tiempo, se puede usar trace-cmd attach(1) para conectar los archivos del invitado y del anfitrión como si hubieran sido creados por el agente trace-cmd.

archivo-trace-anfitrion

El archivo trace.dat creado por el anfitrión. Debe tener eventos kvm_exit y kvm_entry, y usar el reloj "tsc2nsec".

archivo-trace-invitado

El archivo trace.dat creado por el invitado. Debe usar el reloj "x86-tsc". Por ahora, esto solo se admite en x86, puede que admita otras arquitecturas más adelante.

pid-invitado

El ID de proceso del hilo anfitrión que representa a los hilos del invitado. Se deben enumerar todos los IDs de proceso que representan a todas las vCPUs del invitado. Nota: puede agregar más que solo los hilos que representan a las vCPUs del invitado, ya que la herramienta buscará en el archivo-trace-anfitrion los eventos kvm_exit y kvm_entry para hacer coincidir estos PIDs con las vCPUs que representan.

OPCIONES

-c cpus

Especifica el número de CPUS que tiene el invitado.

-s timeshift

Una lista separada por comas del formato offset,escala,frac,timestamp. Estos valores se mapean a lo que se proporciona en /sys/kernel/kvm/<pid>/vcpu/* 
*offset*: Es el desplazamiento del invitado. "tsc-offest" en el directorio.
          Tenga en cuenta que el valor indicado aquí es el negativo de lo que
          se indica en el directorio.
*escala*: El factor de escala. "tsc-scaling-ratio"
*frac*:   Los bits de fracción. "tsc-scaling-ratio-frac-bits"
*timestamp*: La marca de tiempo a partir de la cual se usarán los valores
          anteriores. En algunos casos, los valores pueden cambiar con el
          tiempo. Al agregar una marca de tiempo, surtirá efecto después de
          haberla alcanzado. Normalmente, esto sería cero.
Actualmente, solo se proporciona un timeshift por CPU. Se debe proporcionar
una opción *-s* por cada CPU. Si hay menos opciones que CPUs, la última opción
proporcionada se usará para el resto de las CPUs. Si solo se proporciona una
opción, los valores de esa opción se usarán para todas las CPUs.

EJEMPLOS

Habilitar todos los eventos para el rastreo:

  $ # encontrar el proceso para un invitado dado
  $ ps aux |grep qemu
 libvirt+   63170  5.6  1.6 13994848 4257540 ?    Sl   May02 2884:49 /usr/bin/qemu-system-x86_64...
  $ # Usar 63170 para encontrar todos los PIDs del invitado dado
  $ ls /proc/63170/task
 1541591  63170  63198  63209  63211  63213  63214  63215  63216  63217  63218  63219  63234
  $ # Encontrar el desplazamiento tsc
  $ su
  # cat /sys/kernel/debug/kvm/63170-15/vcpu0/tsc-offset
 -27950965013436847
  # trace-cmd record -C tsc2nsec -e kvm -e sched -e irq -e timer
# en el invitado:
  # trace-cmd record -C x86-tsc -e sched -e irq -e timer sleep 10
# de vuelta en el anfitrión, presiona Ctrl^C para detener el rastreo después de que el invitado termine
  # # Haz que trace.dat sea propiedad de tu cuenta de usuario.
  # chown usuario.usuario trace.dat
  # exit
  $ scp root@invitado:trace.dat trace-invitado.dat
  $ # ahora adjunta los dos archivos (el invitado tiene 8 CPUs)
  $ trace-cmd attach -c 8 -s 27950965013436847 trace.dat trace-invitado.dat 1541591  63170  63198  63209  63211  63213  63214  63215  63216  63217  63218  63219  63234
  $ trace-cmd report -i trace.dat -i trace-invitado.dat
  $ # ahora deberías ver el rastreo del invitado intercalado dentro del rastreo del anfitrión.
