tracefs_local_events(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_local_events, tracefs_local_events_system, tracefs_fill_local_events, tracefs_load_cmdlines, tracefs_load_headers - Inicializar un manejador tep con eventos de traza del sistema local.

SINOPSIS

#include <tracefs.h>
struct tep_handle *tracefs_local_events(const char *tracing_dir);
struct tep_handle *tracefs_local_events_system(const char *tracing_dir, const char * const *sys_names);
int tracefs_fill_local_events(const char *tracing_dir, struct tep_handle *tep, int *parsing_failures);
int tracefs_load_cmdlines(const char *tracing_dir, struct tep_handle *tep);
int tracefs_load_headers(const char *tracing_dir, struct tep_handle *tep);

DESCRIPCIÓN

Funciones para inicializar un manejador tep con eventos de traza del sistema local.

La función tracefs_local_events() asigna un nuevo manejador tep y lo inicializa con eventos de todos los sistemas de traza, ubicados en el directorio tracing_dir dado. Este puede ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de traza de la máquina local, o puede ser la ruta a una copia del directorio tracefs de otra máquina.

La función tracefs_local_events_system() asigna un nuevo manejador tep y lo inicializa con eventos de los sistemas de traza especificados sys_names, ubicados en el directorio tracing_dir dado. Este puede ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de traza de la máquina local, o puede ser la ruta a una copia del directorio tracefs de otra máquina. El argumento sys_names es un array de nombres de sistemas de traza, que se utilizarán para la inicialización del manejador tep. El último elemento de ese array debe ser un puntero NULL.

La función tracefs_fill_local_events() inicializa un manejador tep ya asignado con eventos de todos los sistemas de traza, ubicados en el directorio tracing_dir dado. Este puede ser NULL o la ubicación del punto de montaje de tracefs para los sistemas de traza de la máquina local, o puede ser la ruta a una copia del directorio tracefs de otra máquina. El argumento tep debe ser un puntero a un manejador tep ya asignado, que va a ser inicializado. El argumento parsing_failures puede ser NULL o un puntero a un entero, donde se devuelve el número de fallos al analizar los archivos de eventos.

Las funciones anteriores también cargarán las correspondencias entre pids y los nombres de comandos de proceso. En algunos casos, el manejador tep se crea con una de las funciones anteriores antes de que comience la traza. A medida que las correspondencias se actualizan durante la traza, puede ser necesario leer las correspondencias nuevamente después de la traza. La función tracefs_load_cmdlines() hace precisamente eso. El tracing_dir es el directorio del punto de montaje desde donde cargar, o NULL para usar el punto de montaje del sistema de archivos tracefs.

La función tracefs_load_headers() leerá la "header_page" del directorio de eventos, lo que actualizará el manejador tep con información sobre cómo analizar el sub-búfer del búfer de anillo de traza.

VALOR DE RETORNO

Las funciones tracefs_local_events() y tracefs_local_events_system() devuelven un puntero al manejador tep asignado e inicializado, o NULL en caso de error. El manejador tep devuelto debe liberarse con tep_free(3).

La función tracefs_fill_local_events() devuelve -1 en caso de error, o 0 en caso contrario.

La función tracefs_load_cmdlines() devuelve -1 en caso de error, o 0 en caso contrario.

EJEMPLO

#include <tracefs.h>
struct tep_handle *tep;
...
        tep = tracefs_local_events(NULL);
        if (!tep) {
                /* Falló la inicialización del manejador tep con eventos locales de la instancia superior */
                ...
        }
...
        tep_free(tep);
...
        const char *systems[] = {"ftrace", "irq", NULL};
        tep = tracefs_local_events_system(NULL, systems);
        if (!tep) {
                /* Falló la inicialización del manejador tep con eventos locales de los sistemas
                 * ftrace e irq en la instancia superior.
                 */
                ...
        }
...
        tep_free(tep);
...
        int parsing_failures;
        tep = tep_alloc();
        if (!tep) {
                /* Falló la asignación de un manejador tep */
                ...
        }
        if (tracefs_fill_local_events(NULL, tep, &parsing_failures) < 0) {
                /* Falló la inicialización del manejador tep con eventos locales de la instancia superior */
        }
        tracefs_load_cmdlines(NULL, tep);
...
        tep_free(tep);
