Documentación de la Función

subrutina ctrti2 (carácter uplo, carácter diag, entero n, complejo, dimensión( lda, * ) a, entero lda, entero info)

CTRTI2 calcula la inversa de una matriz triangular superior o inferior compleja (algoritmo sin bloques).

Propósito:

!>
!> CTRTI2 calcula la inversa de una matriz triangular superior o inferior compleja.
!>
!> Esta es la versión del algoritmo BLAS de Nivel 2.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          Especifica si la matriz A es triangular superior o inferior.
!>          = 'U':  Triangular superior
!>          = 'L':  Triangular inferior
!>

DIAG

!>          DIAG es CHARACTER*1
!>          Especifica si la matriz A es unitriangular o no.
!>          = 'N':  Triangular no unitaria
!>          = 'U':  Triangular unitaria
!>

N

!>          N es ENTERO
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es una matriz de tipo COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz triangular A.  Si UPLO = 'U', la
!>          parte triangular superior de n por n de la matriz A contiene
!>          la matriz triangular superior, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior de n por n de la matriz A contiene
!>          la matriz triangular inferior, y la parte estrictamente triangular
!>          superior de A no se referencia.  Si DIAG = 'U', los
!>          elementos diagonales de A tampoco se referencian y se
!>          asumen como 1.
!>
!>          En la salida, la inversa (triangular) de la matriz original, en
!>          el mismo formato de almacenamiento.
!>

LDA

!>          LDA es ENTERO
!>          La dimensión principal de la matriz A.  LDA >= max(1,N).
!>

INFO

!>          INFO es ENTERO
!>          = 0: salida exitosa
!>          < 0: si INFO = -k, el k-ésimo argumento tenía un valor ilegal
!>

Function Documentation

subroutine ctrti2 (character uplo, character diag, integer n, complex, dimension( lda, * ) a, integer lda, integer info)

CTIRTI2 computes the inverse of a triangular matrix (unblocked algorithm).

Purpose:

!>
!> CTRTI2 computes the inverse of a single-precision complex upper or
!> lower triangular matrix.
!>
!> This is the Level 2 BLAS version of the algorithm.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

DIAG

!>          DIAG is CHARACTER*1
!>          Specifies whether or not the matrix A is unit triangular.
!>          = 'N':  Non-unit triangular
!>          = 'U':  Unit triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the triangular matrix A.  If UPLO = 'U', the
!>          leading n by n upper triangular part of the array A contains
!>          the upper triangular matrix, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading n by n lower triangular part of the array A contains
!>          the lower triangular matrix, and the strictly upper
!>          triangular part of A is not referenced.  If DIAG = 'U', the
!>          diagonal elements of A are also not referenced and are
!>          assumed to be 1.
!>
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same storage format.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>
