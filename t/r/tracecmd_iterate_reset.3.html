NOMBRE

tracecmd_iterate_events, tracecmd_iterate_events_multi, tracecmd_follow_event, tracecmd_follow_missed_events, tracecmd_filter_add, tracecmd_iterate_reset - Leer eventos de un archivo de rastreo

SINOPSIS

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                  int nr_handles,
                                  int (*callback)(struct tracecmd_input *,
                                                           struct tep_record *,
                                                           int, void *),
                                  void *callback_data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data, bool cont);
int tracecmd_follow_event(struct tracecmd_input *handle,
                          const char *system, const char *event_name,
                          int (*callback)(struct tracecmd_input *,
                                          struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracecmd_follow_missed_events(struct tracecmd_input *handle,
                                   int (*callback)(struct tracecmd_input *,
                                                   struct tep_event *,
                                                   struct tep_record *,
                                                   int, void *),
                                   void *callback_data);
struct tracecmd_filter *tracecmd_filter_add(struct tracecmd_input handle,
                                            const char *filter_str, bool neg);
int *tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para iterar sobre eventos después de abrir un archivo de rastreo usando una de las funciones de apertura como tracecmd_open(3) o tracecmd_open_fd(3).

La función tracecmd_iterate_events() iterará a través de todos los eventos en el archivo de rastreo definido por handle, donde handle es devuelto por una de las funciones tracecmd_open(3). Llamará a la función callback() en los eventos de las CPUs definidas por cpus. cpu_size debe ser el tamaño de cpus (ver CPU_SET(3)). Si cpus es NULL, entonces cpu_size se ignora y callback() será llamado para todos los eventos en todas las CPUs del archivo de rastreo. callback_data se pasa a callback() como su último parámetro. callback puede ser NULL, lo cual es útil si se usa tracecmd_follow_event(), pero tenga en cuenta que si callback es NULL, entonces callback_data se ignora y no se envía al callback de tracecmd_follow_event().

La función tracecmd_iterate_events_multi() es similar a tracecmd_iterate_events() excepto que permite iterar sobre más de un archivo de rastreo. Si se usa tracecmd agent(1) para obtener un archivo de rastreo tanto para el host como para el invitado, asegúrese de que el archivo de rastreo del host sea la primera entrada en handles y tracecmd_iterate_events_multi() sincronizará los metadatos para los archivos invitados que vienen después en handles. handles es un array de descriptores de archivos de rastreo que fueron abiertos por tracecmd_open(3) y similares. Tenga en cuenta que, a diferencia de tracecmd_iterate_events(), tracecmd_iterate_events_multi() no filtra por CPUs, ya que haría que la API fuera demasiado compleja al saber en qué handle filtrar las CPUs. Si se desea filtrar por CPU, entonces el callback debería verificar record→cpu y devolver 0 si no es la CPU deseada para procesar. nr_handles denota el número de elementos en handles. callback_data se pasa al callback como su último parámetro. callback puede ser NULL, lo cual es útil si se usa tracecmd_follow_event(), pero tenga en cuenta que si callback es NULL, entonces callback_data se ignora y no se envía al callback de tracecmd_follow_event().

La función tracecmd_iterate_events_reverse() funciona de manera bastante similar a como funciona tracecmd_iterate_events(), pero en lugar de llamar a la función callback() para cada evento en orden de marca de tiempo, llamará a la función callback() para cada evento en orden inverso de marca de tiempo. Si cont es falso, comenzará llamando al evento con la marca de tiempo más antigua en el archivo trace.dat. Si cont se establece en verdadero, comenzará donde sea la posición actual de los datos de rastreo. Por ejemplo, si callback() devuelve algo diferente de cero, saldrá de la iteración. Si se vuelve a llamar a tracecmd_iterate_events_reverse() con cont en verdadero, continuará desde donde lo dejó. Si cont es falso, comenzará de nuevo en el evento con la marca de tiempo más antigua. handle, cpus, cpu_size y callback_data actúan igual que en tracecmd_iterate_events().

El callback() para tracecmd_iterate_events(), tracecmd_iterate_events_reverse() y tracecmd_iterate_events_multi() tiene el prototipo:

int callback()(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data);

El handle es el mismo handle pasado a tracecmd_iterate_events() o el handle actual de handles pasado a tracecmd_iterate_events_multi() al que pertenece el record. El record es el registro de evento actual. El cpu es la CPU actual que se está procesando. Tenga en cuenta que, para tracecmd_iterate_events_multi(), puede que no sea la CPU real del archivo, sino la enésima CPU de todos los handles combinados. Use record→cpu para obtener la CPU real en la que se encuentra el evento.

La función tracecmd_follow_event() se adjuntará a un descriptor de archivo de rastreo handle y llamará al callback cuando el evento descrito por system y name coincida con un evento en la iteración de tracecmd_iterate_events() o tracecmd_iterate_events_multi(). Tenga en cuenta que el cpu es la enésima CPU tanto para tracecmd_iterate_events() como para tracecmd_iterate_events_multi(). Si se necesita la CPU real del record, use record→cpu. Para tracecmd_iterate_events_multi(), el callback solo se llama si el handle coincide con el descriptor de archivo de rastreo actual dentro de handles. callback_data se pasa como el último parámetro a la función callback(). Tenga en cuenta que esta función callback() se llamará antes que la función callback() de tracecmd_iterate_events() o tracecmd_iterate_events_multi().

El prototipo de callback() para *tracecmd_follow_event()* es:

int callback()(struct tracecmd_input *handle, struct tep_event *event, struct tep_record *_record, int cpu, void *data);

La función tracecmd_follow_missed_events() se adjuntará a un descriptor de archivo de rastreo handle y llamará al callback cuando se detecten eventos perdidos. El event contendrá el tipo de evento que es el record. El record contendrá la información de los eventos perdidos. El cpu es la enésima CPU tanto para tracecmd_iterate_events() como para tracecmd_iterate_events_multi(). Si se necesita la CPU para la que son los eventos perdidos, use record→cpu. Si record→missed_events es un número positivo, entonces contiene el número de eventos perdidos desde el último evento en su CPU, de lo contrario será negativo, y eso significará que el número de eventos perdidos es desconocido pero existen eventos perdidos desde el último evento en la CPU. NOMBRE

tracecmd_iterate_events, tracecmd_iterate_events_reverse, tracecmd_iterate_events_multi, tracecmd_filter_add, tracecmd_iterate_reset - iterar sobre los eventos de un trace

SINOPSIS

#include <trace-cmd.h>

int tracecmd_iterate_events(struct tracecmd_input *handle,
                            const cpu_set_t *cpuset, size_t cpusetsize,
                            tracecmd_event_callback callback,
                            void *data);

int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                                   const cpu_set_t *cpuset, size_t cpusetsize,
                                   tracecmd_event_callback callback,
                                   void *data);

int tracecmd_iterate_events_multi(struct tracecmd_input **handles, int nr_handles,
                                 tracecmd_event_callback callback,
                                 void *data);

struct tracecmd_filter *tracecmd_filter_add(struct tracecmd_input *handle,
                                            const char *filter_str, bool neg);

int tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPCIÓN

Estas funciones son utilizadas para iterar sobre los eventos registrados en un archivo de trace, ya sea hacia adelante o hacia atrás, y para aplicar filtros.

La función tracecmd_iterate_events() itera sobre los eventos registrados en el handle dado. El argumento cpuset y cpusetsize especifican qué CPUs deben ser procesadas. Si se establece en NULL, todas las CPUs serán procesadas. La función callback será llamada para cada evento encontrado. El argumento data es un puntero a datos definidos por el usuario que se pasarán a la función callback.

La función tracecmd_iterate_events_reverse() funciona de manera similar a tracecmd_iterate_events(), pero itera sobre los eventos en orden inverso.

La función tracecmd_iterate_events_multi() itera sobre múltiples handles de trace simultáneamente. El argumento nr_handles especifica el número de handles en el array handles. La función callback será llamada para cada evento encontrado en cualquiera de los handles.

La función tracecmd_filter_add() añade un filtro al handle dado. El argumento filter_str es una cadena que define el filtro. El argumento neg indica si los eventos que coinciden con el filtro deben ser saltados (si es true) o si deben ejecutar la función callback (si es false).

La función tracecmd_iterate_reset() restablece el handle para que la próxima iteración comience desde el principio.

Si se proporciona una función callback al tracecmd_iterate_events(), esta se llama antes que cualquier otro callback y cualquier filtro añadido por tracecmd_filter_add() se ignora. Si callback devuelve un valor distinto de cero, detendrá el iterador antes de llamar a cualquier otro callback del iterador para el registro dado.

La función tracecmd_filter_add() añade un filtro al handle que afecta tanto a tracecmd_iterate_events() como a tracecmd_iterate_events_multi(). El filter_str es una cadena de caracteres que define un filtro en un formato definido por tep_filter_add_filter_str(3). Si neg es true, los eventos que coinciden con el filtro se omitirán, de lo contrario, los eventos que coinciden ejecutarán la función callback() en los iteradores.

La función tracecmd_iterate_reset() establece el handle de nuevo al inicio, de modo que la próxima llamada a tracecmd_iterate_events() comience de nuevo en el primer evento, en lugar de continuar donde lo dejó.

VALOR DE RETORNO

Tanto tracecmd_iterate_events(), tracecmd_iterate_events_reverse() como tracecmd_iterate_events_multi() devuelven cero si iteraron exitosamente todos los eventos (manejando adecuadamente los seguidores y filtros). O un valor de error, que puede incluir la devolución de un resultado distinto de cero de la función callback().

tracecmd_iterate_reset() devuelve 0 en caso de éxito y -1 si ocurrió un error. Tenga en cuenta que si se devuelve -1, es posible que también haya ocurrido un restablecimiento parcial.

EJEMPLO

#define _GNU_SOURCE
#include <sched.h>
#include <stdlib.h>
#include <getopt.h>
#include <trace-cmd.h>
struct private_data {
        int             cpu;
        const char      *file;
};
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        struct private_data *pdata = tracecmd_get_private(handle);
        /* Para handles múltiples necesitamos esto */
        if (pdata->cpu >= 0 && pdata->cpu != record->cpu)
                return 0;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", pdata->file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
static int print_event(struct tracecmd_input *handle, struct tep_event *event,
                       struct tep_record *record, int cpu, void *data)
{
        return print_events(handle, record, cpu, data);
}
static int missed_events(struct tracecmd_input *handle, struct tep_event *event,
                         struct tep_record *record, int cpu, void *data)
{
        if (record->missed_events > 0)
                printf("CPU [%03d] tiene %d eventos perdidos\n",
                         record->cpu, record->missed_events);
        else
                printf("CPU [%03d] tiene eventos perdidos\n", record->cpu);
        return 0;
}
static void usage(const char *argv0)
{
        printf("uso: [-c cpu][-f filtro][-e evento] %s trace.dat [trace.dat ...]\n",
               argv0);
        exit(-1);
}
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        const char *filter_str = NULL;
        const char *argv0 = argv[0];
        struct private_data *priv;
        cpu_set_t *cpuset = NULL;
        char *event = NULL;
        size_t cpusize = 0;
        int nr_handles = 0;
        int cpu = -1;
        int i;
        int c;
        while ((c = getopt(argc, argv, "c:f:e:")) >= 0) {
                switch (c) {
                case 'c':
                        /* filtrar todos los datos de trace a esta única CPU. */
                        cpu = atoi(optarg);
                        break;
                case 'f':
                        filter_str = optarg;
                        break;
                case 'e':
                        event = optarg;
                        break;
                default:
                        usage(argv0);
                }
        }
        argc -= optind;
        argv += optind;
        if (argc == 0)
                usage(argv0);
        for (i = 0; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[i]);
                        exit(-1);
                }
                if (filter_str) {
                        if (tracecmd_filter_add(handles[nr_handles], filter_str, false) == NULL) {
                                perror("añadiendo filtro");
                                exit(-1);
                        }
                }
                priv = calloc(1, sizeof(*priv));
                if (!priv)
                        exit(-1);
                priv->file = argv[i];
                priv->cpu = cpu;
                tracecmd_set_private(handles[nr_handles], priv);
                if (event) {
                        if (tracecmd_follow_event(handles[nr_handles], NULL, event, print_event, NULL) < 0) {
                                printf("No se pudo seguir el evento %s para el archivo %s\n", event, argv[i]);
                                exit(-1);
                        }
                }
                tracecmd_follow_missed_events(handles[nr_handles], missed_events, NULL);
                nr_handles++;
        }
        /* Atajo */
        if (nr_handles == 1) {
                if (cpu >= 0) {
                        cpuset = CPU_ALLOC(cpu + 1);
                        if (!cpuset)
                                exit(-1);
                        cpusize = CPU_ALLOC_SIZE(cpu + 1);
                        CPU_SET_S(cpu, cpusize, cpuset);
                }
                if (event)
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, NULL, NULL);
                else
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, print_events, NULL);
        } else {
                if (event)
                        tracecmd_iterate_events_multi(handles, nr_handles, NULL, NULL);
                else
                        tracecmd_iterate_events_multi(handles, nr_handles, print_events, NULL);
        }
        for (i = 0; i < nr_handles; i++) {
                priv = tracecmd_get_private(handles[i]);
                free(priv);
                tracecmd_close(handles[i]);
        }
        free(handles);
}
