TRACELOG(3) Manual de LTTng TRACELOG(3)

NOMBRE

tracelog - Interfaz de LTTng-UST similar a printf(3) con nivel de registro

SINOPSIS

#include <lttng/tracelog.h>
#define tracelog(nivel, fmt, ...)

Enlazar con -llttng-ust -llttng-ust-common.

DESCRIPCIÓN

La macro tracelog() forma parte de la versión 0 de la API LTTng-UST (ver la sección “Compatibilidad con APIs anteriores” de lttng-ust(3)).

Prefiere usar lttng_ust_tracelog(3), que forma parte de la versión 1 de la API y tiene el espacio de nombres lttng_ust_.
