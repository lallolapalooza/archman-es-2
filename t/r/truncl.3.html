trunc(3) Manual de Funciones de Biblioteca trunc(3)

NOMBRE

trunc, truncf, truncl - redondear a entero, hacia cero

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double trunc(double x);
float truncf(float x);
long double truncl(long double x);
Requisitos de Macro de Prueba de Características para glibc (ver feature_test_macros(7)):

trunc(), truncf(), truncl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPCIÓN

Estas funciones redondean x al valor entero más cercano que no sea mayor en magnitud que x.

VALOR DE RETORNO

Estas funciones devuelven el valor entero redondeado, en formato de coma flotante.

Si x es un entero, infinito o NaN, se devuelve x mismo.

ERRORES

No ocurren errores.

ATRIBUTOS

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
trunc (), truncf (), truncl () Seguridad de hilos MT-Safe

ESTÁNDARES

C11, POSIX.1-2008.

HISTORIA

glibc 2.1. C99, POSIX.1-2001.

NOTAS

El valor entero devuelto por estas funciones puede ser demasiado grande para almacenarse en un tipo entero (int, long, etc.). Para evitar un desbordamiento, que producirá resultados indefinidos, una aplicación debe realizar una verificación de rango en el valor devuelto antes de asignarlo a un tipo entero.

VER TAMBIÉN

ceil(3), floor(3), lrint(3), nearbyint(3), rint(3), round(3)
