TRAFFIC_LEARNER(7) Comandos de Usuario TRAFFIC_LEARNER(7)

NOMBRE

traffic_learner - Herramienta de Samba para ayudar con la generación de tráfico.

SINOPSIS

traffic_learner {-o ARCHIVO_SALIDA ...} [-h] [--modo-dns {inline|count}] [ARCHIVO_RESUMEN] [ARCHIVO_RESUMEN ...]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(7).

Esta herramienta ayuda a la generación de tráfico de Samba. Toma un archivo de resumen de tráfico (producido por traffic_summary.pl) como entrada y produce un archivo de modelo de tráfico que puede ser utilizado por traffic_replay para la generación de tráfico.

El archivo de modelo resume los tipos de tráfico ('conversaciones' entre un host y un DC de Samba) que ocurren en una red. El archivo de modelo describe el tráfico de una manera que permite escalarlo para que se envíen más (o menos) paquetes, y los paquetes puedan enviarse a una velocidad más rápida (o más lenta) que la observada en la red.

OPCIONES

-h|--help

Imprime un resumen de las opciones de la línea de comandos.

ARCHIVO_RESUMEN

Archivo que contiene un resumen del tráfico de red. El archivo de resumen de tráfico debe ser generado por traffic_summary.pl a partir de una captura de paquetes del tráfico de red real. Se puede especificar más de un archivo, en cuyo caso el tráfico se combinará en un único modelo de tráfico. Si no se especifica ningún ARCHIVO_RESUMEN, esta herramienta leerá el resumen de tráfico desde STDIN, es decir, puede canalizar la salida de traffic_summary.pl directamente a esta herramienta.

-o|--out ARCHIVO_SALIDA

El modelo de tráfico que se producirá se escribirá en este archivo. ARCHIVO_SALIDA puede ser pasado a traffic_replay para generar (y manipular) el tráfico de red de Samba.

--modo-dns [inline|count]

Cómo se manejará el tráfico DNS en el modelo.

EJEMPLOS

Para tomar un archivo de resumen de tráfico y producir un archivo de modelo de tráfico, use:

traffic_learner archivo-resumen.txt -o modelo-trafico.txt

Para generar un modelo de tráfico a partir de una captura de paquetes, puede canalizar el resumen de tráfico a STDIN usando:

tshark -r capture.pcapng -T pdml | traffic_summary.pl | traffic_learner -o modelo-trafico.txt

FORMATO DEL ARCHIVO DE SALIDA

El archivo de modelo de salida describe un modelo de Markov que estima la probabilidad de que ocurra un paquete dados los dos últimos paquetes.

Se almacena el recuento de cada continuación después de un par de paquetes sucesivos, y las proporciones de estos recuentos se utilizan para calcular las probabilidades del siguiente paquete.

El modelo se almacena en formato JSON, y también contiene información sobre la tasa de paquetes y la tasa de tráfico DNS.

Ejemplo de listado de ngramas

El siguiente listado muestra un ejemplo artificial de una entrada de ngram.

          "ngrams": {
             "ldap:0\tdcerpc:11": {
                 "lsarpc:77": 1,
                 "ldap:2": 370,
                 "ldap:3": 62,
                 "wait:3": 2,
                 "-": 1
             }, [...]
          }

Esto cuenta las continuaciones observadas después de un paquete ldap con opcode 0 (un bind) seguido de un paquete dcerpc con opcode 11 (también un bind). El siguiente paquete más común es "ldap:2", que es un unbind, por lo que este es el tipo de paquete más probable a seleccionar en la reproducción. En el otro extremo, lsarpc opcode 77 (lookup names) se ha visto solo una vez, y es poco probable pero posible que se seleccione en la reproducción.

Hay dos tipos de paquete especiales aquí. "wait:3" se refiere a una pausa temporal en la conversación, donde el pseudo-opcode "3" indica la duración de la pausa en una escala exponencial. Es decir, una pausa "wait:4" sería aproximadamente 2.7 veces más larga que una pausa "wait:3", que a su vez sería de manera similar más larga que una pausa "wait:2".

El otro paquete especial es "-", que representa el fin de la conversación. En el ejemplo, esto indica que una conversación observada terminó después de este ngram en particular. Este opcode especial también se usa al principio de las conversaciones, que se indican con el ngram "-\t-".
