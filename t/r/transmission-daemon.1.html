TRANSMISSION-DAEMON(1) Manual de Comandos Generales TRANSMISSION-DAEMON(1)

NOMBRE

transmission-daemon — un cliente de bittorrent

SINOPSIS

transmission-daemon -h

transmission-daemon [-a x.x.x.x,...] [-b | -B] [-c directorio] [-C] [-d] [-f] [-g directorio] [-h] [-p puerto] [-t | -T] [-u nombredeusuario] [-v contraseña] [-P puerto] [-m | -M] [-l límite] [-L límite] [-er | -ep | -et] [-utp | -no-utp] [-V] [-w dir-descargas] [-e archivo-log] [-x archivo-pid] [-log-error | -log-info | -log-debug]

DESCRIPCIÓN

transmission-daemon es una sesión de Transmission basada en demonios que puede ser controlada mediante comandos RPC desde la interfaz web de transmission o transmission-remote(1).

OPCIONES

-a --allowed x.x.x.x,...
Permitir acceso RPC a una lista blanca delimitada por comas de direcciones IP. Se pueden especificar comodines en una dirección usando '*'. Predeterminado: "127.0.0.1,::1" Ejemplo: "127.0.0.*,192.168.1.*"
-b --blocklist
Habilitar listas de bloqueo de pares. Transmission entiende el formato de archivo de lista de bloqueo bluetack. Se pueden añadir nuevas listas de bloqueo copiándolas al subdirectorio "blocklists" del directorio de configuración.
-c directorio
Directorio a vigilar para añadir nuevos archivos .torrent. A medida que se añaden a este directorio, el demonio los cargará en Transmission.
-C
No vigilar nuevos archivos .torrent.
-B --no-blocklist
Deshabilitar listas de bloqueo.
-d
Volcar la configuración de transmission-daemon a stderr.
-f --foreground
Ejecutar en primer plano e imprimir errores en stderr.
-g --config-dir directorio
Dónde buscar los archivos de configuración. Esto se puede usar para cambiar entre usar los clientes cli, daemon, gtk y qt. Consulte https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md para más información.
-er --encryption-required
Cifrar todas las conexiones de pares.
-ep --encryption-preferred
Preferir conexiones de pares cifradas.
-et --encryption-tolerated
Preferir conexiones de pares no cifradas.
-gsr --global-seedratio ratio
Todos los torrents, a menos que se anulen por una configuración por torrente, deben sembrarse hasta una ratio específica
-GSR --no-global-seedratio
Todos los torrents, a menos que se anulen por una configuración por torrente, deben sembrarse independientemente de la ratio
-h --help
Imprimir descripciones de las opciones de línea de comandos.
--incomplete-dir dir
Al añadir nuevos torrents, almacenar sus contenidos en directorio hasta que el torrente termine.
--no-incomplete-dir
No almacenar torrents incompletos en un directorio diferente.
-i --bind-address-ipv4
Escuchar conexiones BitTorrent IPv4 en una dirección específica. Solo se permite una dirección de escucha IPv4. Predeterminado: 0.0.0.0 (Todas las direcciones)
-I --bind-address-ipv6
Escuchar conexiones BitTorrent IPv6 en una dirección específica. Solo se permite una dirección de escucha IPv6. Predeterminado: :: (Todas las direcciones)
-r --rpc-bind-address
Escuchar conexiones RPC en una dirección específica. Debe ser una dirección IPv4 o IPv6. Solo se permite una dirección de escucha RPC. Predeterminado: 0.0.0.0 (Todas las direcciones IPv4)
--paused
Pausar todos los torrents al inicio
-L --peerlimit-global límite
Límite global de pares. Útil en sistemas embebidos donde el predeterminado podría no ser adecuado. Predeterminado: 240
-l --peerlimit-torrent límite
Límite de pares por torrente. Útil en sistemas embebidos donde el predeterminado podría no ser adecuado. Predeterminado: 60
-m --portmap
Habilitar mapeo de puertos mediante NAT-PMP o UPnP
-M --no-portmap
Deshabilitar mapeo de puertos
-o --dht
Habilitar tabla hash distribuida (DHT).
-O --no-dht
Deshabilitar tabla hash distribuida (DHT).
-p --port puerto
Puerto a abrir y escuchar para peticiones RPC. Predeterminado: 9091
-P --peerport puerto
Puerto a escuchar para pares entrantes. Predeterminado: 51413
-t --auth
Requerir que los clientes se autentiquen. Esto no es muy útil a menos que también se establezcan el nombredeusuario y la contraseña.
-T --no-auth
No requerir autenticación de los clientes.
-u --username nombredeusuario
Usado para la autenticación del cliente.
--password contraseña
Usado para la autenticación del cliente.
--utp
Habilitar la conexión uTP (μTP).
--no-utp
Deshabilitar la conexión uTP (μTP).
-V --version
Imprimir la versión de Transmission.
-w --download-dir directorio
Directorio de destino para las descargas de torrents.
-e --logfile archivo-log
Escribir todas las salidas (incluidos los errores) en el archivo-log especificado.
-x --pid-file archivo-pid
Escribir el ID del proceso en el archivo especificado.
--log-error
Registrar solo errores.
--log-info
Registrar información, advertencias y errores.
--log-debug
Registrar todos los eventos de depuración, incluyendo los de info, advertencia y error.

transmission-daemon(1) — Arch Linux man pages

NAME

transmission-daemon — command-line daemon for Transmission

SYNOPSIS

transmission-daemon [-h | --help] [-v | --version]

transmission-daemon [-f file | --config-dir file] [-t time | --incomplete-dir-enabled time] [-I dir | --incomplete-dir dir] [-o file | --download-dir file] [-c dir | --watch-dir dir] [-u name | --username name] [-p password | --password password] [-l file | --logfile file] [-e | --log-error] [-i | --log-info] [-d | --log-debug] [-x file | --pid-file file] [-a address | --auth-address address] [-P port | --auth-port port] [-r address | --rpc-address address] [-R port | --rpc-port port] [-o file | --allowed-peers file] [-O file | --denied-peers file] [-U time | --peer-timeout-when-unsupervised time] [-k file | --encryption file] [-d file | --dht-announce-interval file] [-m file | --message-level file] [-S file | --scrape-paused-torrents file] [-a file | --ratio file] [-L file | --incomplete-ratio file] [-V file | --download-limit file] [-Y file | --upload-limit file] [-T file | --torrent-done-script file] [-t file | --torrent-moved-script file] [-n file | --script-torrent-added file] [-W file | --script-torrent-done file] [-P file | --script-torrent-moved file] [-u file | --script-torrent-started file] [-s file | --script-torrent-stopped file] [-i file | --script-torrent-seeded file] [-N file | --script-torrent-seeding-done file] [-l file | --script-torrent-stopped-seeding file] [-D file | --script-torrent-downloaded file] [-d | --utp] [-D | --no-utp] [-o file | --port-forwarding-enabled file] [-p port | --port-forwarding-port port]

DESCRIPTION

The transmission-daemon program is a command-line daemon that can be used to run Transmission without a GUI.

It provides a JSON-RPC interface for remote control and uses a configuration file to manage its settings.

OPTIONS

-h --help
Show help message and exit
-v --version
Show version number and exit
-f --config-dir directory
Use specified directory for configuration files.
-t --incomplete-dir-enabled time
Enable incomplete directory.
-I --incomplete-dir directory
Directory to store incomplete downloads.
-o --download-dir directory
Directory to store completed downloads.
-c --watch-dir directory
Directory to watch for new torrent files.
-u --username username
Username for basic authentication.
-p --password password
Password for basic authentication.
-a --auth-address address
Listen for authentication requests on specified address.
-P --auth-port port
Listen for authentication requests on specified port.
-r --rpc-address address
Listen for RPC requests on specified address.
-R --rpc-port port
Listen for RPC requests on specified port.
-l --logfile file
Log messages to specified file.
-e --log-error
Log error messages.
-i --log-info
Log info messages.
-d --log-debug
Log debug messages.
-x --pid-file file
Write process ID to specified file.
-k --encryption mode
Set encryption mode (required, preferred, allowed, demanded).
--utp
Enable uTP for peer connections.
--no-utp
Disable uTP for peer connections.

ENVIRONMENT

http_proxy
Used by libcurl when performing tracker announces.
TRANSMISSION_HOME
Sets the default config-dir.

FILES

~/.config/transmission-daemon
The default config-dir if neither TRANSMISSION_HOME nor -f is specified.
