tracefs_tracing_dir(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_get_tracing_file, tracefs_put_tracing_file, tracefs_tracing_dir, tracefs_debug_dir, tracefs_set_tracing_dir, tracefs_tracing_dir_is_mounted - Encontrar y establecer ubicaciones del directorio y archivos de rastreo.

SINOPSIS

#include <tracefs.h>
char *tracefs_get_tracing_file(const char *name);
void tracefs_put_tracing_file(char *name);
const char *tracefs_tracing_dir(void);
const char *tracefs_debug_dir(void);
int tracefs_set_tracing_dir(char *tracing_dir)
int tracefs_tracing_dir_is_mounted(bool mount, const char **path);

DESCRIPCIÓN

Este conjunto de API se puede utilizar para encontrar la ruta completa del punto de montaje del sistema de archivos de rastreo y los archivos de rastreo dentro de él.

La función tracefs_set_tracing_dir() establece una ubicación personalizada para el punto de montaje del directorio de rastreo del sistema. Normalmente, la biblioteca lo detecta automáticamente utilizando la información del archivo /proc/mounts. Utilice esta API solo si el punto de montaje no es estándar y la biblioteca no puede detectarlo. El argumento tracing_dir puede ser NULL; en ese caso, se elimina la ubicación personalizada y se utiliza la lógica de detección automática de la biblioteca.

La función tracefs_get_tracing_file() devuelve la ruta completa del archivo con el name dado en el sistema de archivos de rastreo. La función solo funciona con archivos en el directorio principal de tracefs; no es consciente de las instancias de rastreo. Se recomienda usar tracefs_instance_get_file() y tracefs_instance_get_dir() en su lugar. La cadena devuelta debe liberarse con tracefs_put_tracing_file().

La función tracefs_put_tracing_file() libera el nombre del archivo de rastreo, devuelto por tracefs_get_tracing_file().

La función tracefs_tracing_dir() devuelve la ruta completa al sistema de archivos de rastreo. En la primera llamada a la función, se localiza, se almacena en caché y se devuelve el punto de montaje del sistema de archivos de rastreo. Lo montará si no está montado. En cualquier llamada posterior, se devuelve la ruta en caché. La cadena devuelta no debe liberarse.

La función tracefs_debug_dir() es similar a tracefs_tracing_dir(), excepto que devolverá dónde está montado el sistema de archivos debugfs. Si no está montado, intentará montarlo. La cadena devuelta no debe liberarse.

tracefs_tracing_dir_is_mounted() devuelve 1 si el directorio de rastreo ya está montado y 0 si no lo está. Si mount es true, intentará montarlo si no lo está, y devuelve 0 si lo montó exitosamente y -1 si no. Si path está establecido, se le asignará la ruta donde lo montó. path es interno y no debe liberarse.

VALOR DE RETORNO

La función tracefs_set_tracing_dir() devuelve 0 si tiene éxito, -1 en caso contrario.

La función tracefs_get_tracing_file() devuelve una cadena o NULL en caso de error. La cadena devuelta debe liberarse con tracefs_put_tracing_file().

La función tracefs_tracing_dir() devuelve una cadena constante o NULL en caso de error. La cadena devuelta no debe liberarse.

La función tracefs_debug_dir() devuelve una cadena constante o NULL en caso de error. La cadena devuelta no debe liberarse.

La función tracefs_tracing_dir_is_mounted() devuelve 1 si el directorio de rastreo ya está montado, 0 si no lo está, y -1 en caso de error.

EJEMPLO

#include <tracefs.h>
...
char *trace_on = tracefs_get_tracing_file("tracing_on");
        if (trace_on) {
                ...
                tracefs_put_tracing_file(trace_on);
        }
...
const char *trace_dir = tracefs_tracing_dir();
