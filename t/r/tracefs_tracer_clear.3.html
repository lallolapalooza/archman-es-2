tracefs_tracer_clear(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_tracers, tracefs_tracer_set, tracefs_tracer_clear - Habilitar o deshabilitar un rastreador en una instancia o en el nivel superior

SINOPSIS

#include <tracefs.h>
char ** tracefs_instance_tracers(struct tracefs_instance *instance);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer, const char *name);
int tracefs_tracer_clear(struct tracefs_instance *instance);

DESCRIPCIÓN

tracefs_instance_tracers devolverá una lista de rastreadores disponibles para una instancia dada (nota: una instancia puede no tener el mismo conjunto de rastreadores disponibles que el nivel superior). Si instance es NULL, entonces la lista de rastreadores disponibles devuelta será para el nivel superior.

tracefs_tracer_set habilita un rastreador en la instancia dada, definida por el parámetro instance. Si instance es NULL, entonces se cambia la instancia de nivel superior. Si tracer se establece en TRACFES_TRACER_CUSTOM, entonces se debe pasar una cadena name como tercer parámetro, y esta se escribe en la instancia para habilitar el rastreador con ese nombre. Esto es útil para kernels más nuevos o personalizados que contienen rastreadores que aún no están identificados por la enumeración tracefs_tracers.

tracefs_tracer_clear deshabilita el rastreador para la instancia dada definida por la variable instance, o la instancia de nivel superior si es NULL. Esto es lo mismo que llamar a tracefs_tracer_set con TRACEFS_TRACER_NOP como parámetro tracer.

ENUMERACIONES DE TRACEFS_TRACER

Las enumeraciones definidas actualmente que se aceptan son:

TRACEFS_TRACER_NOP : Este es el rastreador inactivo, que no hace nada y se usa para borrar cualquier rastreador activo.

TRACEFS_TRACER_FUNCTION : Habilita que la mayoría de las funciones en el kernel sean rastreadas.

TRACEFS_TRACER_FUNCTION_GRAPH : Habilita que la mayoría de las funciones en el kernel sean rastreadas, así como el retorno de la función.

TRACEFS_TRACER_IRQSOFF : Rastrea la latencia de las interrupciones deshabilitadas.

TRACEFS_TRACER_PREEMPTOFF : Rastrea la latencia de la preemptión deshabilitada (el tiempo en el kernel que las tareas no pueden ser programadas desde la CPU).

TRACEFS_TRACER_PREEMPTIRQSOFF : Rastrea el total de latencia combinado de cuándo se deshabilitan las interrupciones y cuándo se deshabilita la preemptión.

TRACEFS_TRACER_WAKEUP : Rastrea la latencia de cuándo tarda en activarse la tarea de mayor prioridad.

TRACEFS_TRACER_WAKEUP_RT : Rastrea la latencia de cuándo tarda en activarse la tarea en tiempo real de mayor prioridad. Todas las demás tareas se ignoran.

TRACEFS_TRACER_WAKEUP_DL : Rastrea la latencia de cuándo tarda en activarse la tarea DEADLINE de mayor prioridad. Todas las demás tareas se ignoran.

TRACEFS_TRACER_MMIOTRACE : Rastrea la interacción de dispositivos con el kernel.

TRACEFS_TRACER_HWLAT : Detecta la latencia causada por el hardware que está fuera del alcance del kernel.

TRACEFS_TRACER_BRANCH : Rastrea cuándo se toman ramas probables o improbables.

TRACEFS_TRACER_BLOCK : Rastreador especial para los dispositivos de bloque.

Tenga en cuenta que los rastreadores anteriores pueden no estar disponibles en el kernel y tracefs_tracer_set() devolverá un error con errno establecido en ENODEV, si el kernel no soporta la opción tracer, o la personalizada si se usa TRACEFS_TRACER_CUSTOM.

VALOR DE RETORNO

Devuelve 0 en caso de éxito, o -1 en caso de error.

ERRORES

tracefs_tracer_set() puede fallar con los siguientes errores:

EINVAL El parámetro tracer está fuera del alcance de lo que está definido.

ENOMEM Error de asignación de memoria.

ENOENT Los rastreadores no son compatibles en el kernel en ejecución.

ENODEV El rastreador especificado no es compatible con el kernel en ejecución.

Otros errores también pueden ocurrir debido a llamadas internas del sistema.

EJEMPLO

#include <stdlib.h>
#include <stdio.h>
#include <getopt.h>
#include <errno.h>
#include <tracefs.h>
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = NULL;
        enum tracefs_tracers t = TRACEFS_TRACER_NOP;
        const char *cust = NULL;
        const char *buf = NULL;
        char **tracers;
        int ret;
        int ch;
        int i;
        while ((ch = getopt(argc, argv, "nfgiwdc:B:")) > 0) {
                switch (ch) {
                case 'f': t = TRACEFS_TRACER_FUNCTION; break;
                case 'g': t = TRACEFS_TRACER_FUNCTION_GRAPH; break;
                case 'i': t = TRACEFS_TRACER_PREEMPTIRQSOFF; break;
                case 'w': t = TRACEFS_TRACER_WAKEUP_RT; break;
                case 'd': t = TRACEFS_TRACER_WAKEUP_DL; break;
                case 'c':
                        t = TRACEFS_TRACER_CUSTOM;
                        cust = optarg;
                        break;
                case 'B':
                        buf = optarg;
                        break;
                case 'n':
                        /* nop */
                        break;
                default:
                        printf("Argumento desconocido %c\n", ch);
                        exit(-1);
                }
        }
        if (buf) {
                inst = tracefs_instance_create(buf);
                if (!inst) {
                        printf("Error al crear la instancia\n");
                        exit(-1);
                }
        }
        if (t == TRACEFS_TRACER_CUSTOM)
                ret = tracefs_tracer_set(inst, t, cust);
        else
                ret = tracefs_tracer_set(inst, t);
        if (ret < 0) {
                if (errno == ENODEV) {
                        if (cust)
                                printf("Rastreador '%s' no soportado por el kernel\n", cust);
                        else
                                printf("Rastreador no soportado por el kernel\n");
                        tracers = tracefs_instance_tracers(inst);
                        printf("Rastreadores disponibles:");
                        for (i = 0; tracers && tracers[i]; i++)
                                printf(" %s", tracers[i]);
                        tracefs_list_free(tracers);
                        printf("\n");
                } else
                        perror("Error");
                if (inst) {
                        tracefs_instance_destroy(inst);
                        tracefs_instance_free(inst);
                }
                exit(-1);
        }
        tracefs_instance_free(inst);
        exit(0);
}
