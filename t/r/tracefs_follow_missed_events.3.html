DESCRIPCIÓN

Iterador de Tracefs sobre eventos crudos.

La función tracefs_iterate_raw_events() leerá los búferes de datos crudos de tracefs y llamará a la función callback especificada para cada evento que encuentre. Los eventos se iteran en orden ordenado: el más antiguo primero. Se requiere un manejador tep inicializado (Ver tracefs_local_events(3)). Si instance es NULL, se utilizará el búfer de tracefs de nivel superior, de lo contrario, se leerá el búfer para la instance correspondiente. Para filtrar solo en un subconjunto de CPUs, cpus y cpu_size pueden establecerse para llamar a callback solo con eventos que ocurrieron en las CPUs especificadas, de lo contrario, si cpus es NULL, la función callback se llamará para todos los eventos, y cpu_size se ignorará. La función callback se llamará con los siguientes parámetros: Un puntero a una struct tep_event que corresponde al tipo de evento del registro; El registro que representa el evento; La CPU en la que ocurrió el evento; y un puntero al callback_context especificado por el usuario. Si el callback devuelve un valor distinto de cero, la iteración se detiene.

La función tracefs_iterate_snapshot_events() funciona igual que tracefs_iterate_raw_events(), excepto que opera en el búfer de instantáneas.

Use tracefs_iterate_stop() para forzar la interrupción de una ejecución de tracefs_iterate_raw_events(). Esto puede llamarse desde un callback que es llamado por el iterador (aunque devolver un valor distinto de cero lo detendrá), o desde otro hilo.

La función tracefs_follow_event() se usa con tracefs_iterate_raw_events() pero en lugar de llamar al callback para cada evento, solo se llama para el system / event_name especificado a la función. El callback es el mismo que para tracefs_iterate_raw_events(), y el callback_context pasado también se pasará al callback. Tenga en cuenta que si devuelve algo distinto de 0, detendrá el bucle antes de que se llame al callback de tracefs_iterate_raw_events().

La función tracefs_follow_missed_events() llamará al callback cuando se detecten eventos perdidos. Establecerá el parámetro record del callback al registro que vino después de los eventos perdidos y event será del tipo de evento que es record. cpu se establecerá a la CPU que perdió los eventos, y callback_data será el contenido que se pasó a la función.

La función tracefs_follow_event_clear() eliminará seguidores de instance que coincidan con system y event_name. Si system y event_name son ambos NULL, eliminará todos los seguidores de eventos asociados a instance. Si solo system es NULL, eliminará todos los seguidores que siguen eventos que coinciden con event_name. Si solo event_name es NULL, eliminará todos los seguidores que están conectados a eventos que forman parte de un sistema que coincide con system.

La función tracefs_follow_missed_events_clear() eliminará todos los seguidores de eventos perdidos.

VALOR DE RETORNO

La función tracefs_iterate_raw_events() devuelve -1 en caso de error o 0 en caso contrario.

Tanto tracefs_follow_event_clear() como tracefs_follow_missed_events_clear() devuelven 0 en caso de éxito y -1 en caso de error, o si no encontró ningún seguidor que coincidiera y que debiera ser eliminado.

static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct my_struct *my_data = data;
        static struct trace_seq seq;
        if (counter++ > MAX_COUNT) {
                my_data->stopped = true;
                return 1;
        }
        if (!seq.buffer)
                trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%16s-%-5d [%03d] %6.1000d %s: %s\n",
                        TEP_PRINT_COMM, TEP_PRINT_PID, TEP_PRINT_CPU,
                        TEP_PRINT_TIME, TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        trace_seq_reset(&seq);
        return 0;
}
static int sched_callback(struct tep_event *event, struct tep_record *record,
                          int cpu, void *data)
{
        static struct tep_format_field *prev_pid;
        static struct tep_format_field *next_pid;
        unsigned long long pid;
        int this_pid = *(int *)data;
        if (!prev_pid) {
                prev_pid = tep_find_field(event, "prev_pid");
                next_pid = tep_find_field(event, "next_pid");
                if (!prev_pid || !next_pid) {
                        fprintf(stderr, "No pid fields??\n");
                        return -1;
                }
        }
        tep_read_number_field(prev_pid, record->data, &pid);
        if (pid == this_pid)
                printf("WE ARE LEAVING!\n");
        tep_read_number_field(next_pid, record->data, &pid);
        if (pid == this_pid)
                printf("WE ARE ARRIVING!\n");
        return 0;
}

        printf("events\n");
        return 0;
}

tracefs_follow_missed_events(3) — libtracefs 1.8.2

NAME

tracefs_follow_missed_events, tracefs_follow_missed_events_clear - set and unset missed event tracking

SYNOPSIS

#include <tracefs.h>
int
tracefs_follow_missed_events(struct tracefs_instance *instance,
    const char *event_name, const char *filter);
int
tracefs_follow_missed_events_clear(struct tracefs_instance *instance);

DESCRIPTION

The function tracefs_follow_missed_events() enables tracing of missed events for a given event and optionally a filter. When tracing is active, if the system's trace buffer overflows, the kernel will record this event and log it in the trace output. This can be useful to detect if tracing is dropping events due to buffer limitations.

The function tracefs_follow_missed_events_clear() disables the tracking of missed events for the given instance.

Missed event tracking is tied to the instance's events. When the instance is destroyed, the missed event tracking is automatically disabled for that instance.

RETURN VALUE

On success, both functions return 0. On failure, a negative value is returned, and errno is set to indicate the error.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>

#define MAX_COUNT 10000

int main(int argc, char **argv) {
        struct tracefs_instance *instance;
        int counter = 0;
        int ret;

        struct my_data {
                volatile int stopped;
        } my_data = {0};

        signal(SIGINT, [](int sig) {
                // Set my_data.stopped to 1 when SIGINT is received
        });

        instance = tracefs_instance_alloc(NULL, NULL);
        if (!instance) {
                perror("tracefs_instance_alloc");
                return 1;
        }

        // Enable tracing for the 'sched_switch' event
        ret = tracefs_event_enable(instance, "sched_switch", NULL);
        if (ret < 0) {
                perror("tracefs_event_enable");
                tracefs_instance_free(instance);
                return 1;
        }

        // Enable missed event tracking for 'sched_switch'
        ret = tracefs_follow_missed_events(instance, "sched_switch", NULL);
        if (ret < 0) {
                perror("tracefs_follow_missed_events");
                // No need to clean up other things, they're not needed
                // here because tracefs_instance_free() will clean them up.
                tracefs_follow_event_clear(instance, NULL, NULL);
                tracefs_follow_missed_events_clear(instance);
                tracefs_instance_destroy(instance);
                tracefs_instance_free(instance);
                if (my_data.stopped) {
                        if (counter > MAX_COUNT)
                                printf("Finished max count\n");
                        else
                                printf("Finished via signal\n");
                }
                return 0;
        }

        // Dummy loop to simulate work and potentially trigger missed events
        while (!my_data.stopped && counter < MAX_COUNT) {
                counter++;
                // In a real scenario, you might be reading trace data here
        }

        // Clean up
        tracefs_follow_event_clear(instance, "sched_switch", NULL);
        tracefs_follow_missed_events_clear(instance);
        tracefs_instance_destroy(instance);
        tracefs_instance_free(instance);

        if (my_data.stopped) {
                if (counter > MAX_COUNT)
                        printf("Finished max count\n");
                else
                        printf("Finished via signal\n");
        }
        return 0;
}
