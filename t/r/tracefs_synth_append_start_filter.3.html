tracefs_synth_append_start_filter(3)

NOMBRE

SINOPSIS

#include <tracefs.h>
struct tracefs_synth *tracefs_synth_alloc(struct tep_handle *tep,
                                         const char *name,
                                         const char *start_system,
                                         const char *start_event,

int tracefs_synth_add_compare_field(struct tracefs_synth *synth,
                                    const char *start_compare_field,
                                    const char *end_compare_field,
                                    enum tracefs_synth_calc calc,
                                    const char *name);
int tracefs_synth_add_start_field(struct tracefs_synth *synth,
                                  const char *start_field,
                                  const char *name);
int tracefs_synth_add_end_field(struct tracefs_synth *synth,

                                const char *name);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir otros dos eventos, lo que desencadena un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincida con el campo (o campos) del evento de inicio, desencadenará el evento sintético. Los valores de los campos, aparte de los campos coincidentes, pueden pasarse del evento de inicio al evento final para realizar cálculos o simplemente como parámetros para el evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando un proceso se despierta. Luego, establezca "sched_switch" como el evento de finalización. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo transcurrido entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice *TRACEFS_TIMESTAMP_USECS" como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_alloc() asigna e inicializa un evento sintético. No crea el evento sintético, sino que proporciona la información mínima para hacerlo. Consulte tracefs_synth_create(3) para saber cómo crear el evento sintético en el sistema. Requiere un manejador tep que puede ser creado por tracefs_local_events(3) para más información. El name contiene el nombre del evento sintético que se creará. El start_system es el nombre del sistema para el evento de inicio. Puede ser NULL y se elegirá el primer evento con el nombre start_event. El end_system es el nombre del sistema para el evento de fin. Puede ser NULL y se elegirá el primer evento con el nombre end_event como evento de fin. Si se proporciona match_name, este será el campo del evento sintético creado que contendrá las claves coincidentes del start_match_field del evento de inicio y el end_match_field del evento de fin. Si match_name es NULL, no se registrará en el evento sintético creado.

tracefs_synth_add_match_field() agregará una segunda clave para que coincida entre el evento de inicio y el evento de fin. Si se proporciona name, el contenido del campo coincidente se guardará con este name en el evento sintético. El start_match_field es el campo del evento de inicio que debe coincidir con el end_match_field del evento de fin.

tracefs_synth_add_compare_field() se utiliza para comparar el start_compare_field del evento de inicio con el end_compare_field del evento de fin. Se debe proporcionar name para que el resultado se guarde en el evento sintético. No tiene sentido no pasar esto al evento sintético después de realizar el trabajo de los campos comparados, ya que no sirve para ningún otro propósito. El parámetro calc puede ser uno de:

TRACEFS_SYNTH_DELTA_END - calcula la diferencia entre el contenido en el end_compare_field y el contenido del start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcula la diferencia entre el contenido en el start_compare_field y el contenido del end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Suma el contenido del start_compare_field al contenido del end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Registra el start_field del evento de inicio como name en el evento sintético. Si name es NULL, el nombre utilizado será el mismo que start_field.

tracefs_synth_add_end_field() - Registra el end_field del evento de fin como name en el evento sintético. Si name es NULL, el nombre utilizado será el mismo que end_field.

tracefs_synth_append_start_filter() crea un filtro o se lo añade para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede añadir una comparación del field con val basándose en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Añade "&&" al filtro TRACEFS_FILTER_OR - Añade "||" al filtro TRACEFS_FILTER_NOT - Añade "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añade "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añade ")" al filtro

field, compare y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces se usará _compare para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de flags.

tracefs_synth_append_end_filter() es igual que tracefs_synth_append_start_filter pero filtra en el evento de fin.

tracefs_synth_free() libera el descriptor asignado devuelto por tracefs_synth_alloc().

VALOR DE RETORNO

En caso de éxito, tracefs_synth_alloc() devuelve un puntero al descriptor del evento sintético. En caso de error, devuelve NULL.

Las funciones tracefs_synth_add_match_field(), tracefs_synth_add_compare_field(), tracefs_synth_add_start_field(), tracefs_synth_add_end_field(), tracefs_synth_append_start_filter() y tracefs_synth_append_end_filter() devuelven 0 en caso de éxito, o un valor distinto de cero en caso de error.

EJEMPLO

Este ejemplo muestra cómo medir la latencia de despertar de un proceso.

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main(void)
{
        struct tep_handle *tep;
        struct tracefs_synth *synth;
        int ret;

        tep = tracefs_local_events(NULL);
        if (!tep) {
                fprintf(stderr, "Failed to get tracefs handle\n");
                return 1;
        }

        /* Create a synthetic event to measure wake up latency */
        synth = tracefs_synth_alloc(tep, "wake_latency",
                                    "sched", "sched_waking",
                                    "sched", "sched_switch",
                                    "common_pid", "common_pid",
                                    "pid");
        if (!synth) {
                fprintf(stderr, "Failed to allocate synthetic event\n");
                tracefs_close(tep);
                return 1;
        }

        /* Record the timestamp delta in nanoseconds */
        ret = tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP,
                                            TRACEFS_TIMESTAMP,
                                            TRACEFS_SYNTH_DELTA_END,
                                            "latency_ns");
        if (ret < 0) {
                fprintf(stderr, "Failed to add compare field\n");
                tracefs_synth_free(synth);
                tracefs_close(tep);
                return 1;
        }

        /* Create the synthetic event on the system */
        ret = tracefs_synth_create(synth);
        if (ret < 0) {
                fprintf(stderr, "Failed to create synthetic event\n");
                tracefs_synth_free(synth);
                tracefs_close(tep);
                return 1;
        }

        printf("Synthetic event 'wake_latency' created.\n");
        printf("To view trace data, use:\n");
        printf("  # traceon -e wake_latency\n");
        printf("  # tracemerge ---\n");

        /* Clean up */
        tracefs_synth_free(synth);
        tracefs_close(tep);

        return 0;
}

ERRORES

Los siguientes errores son aplicables a todas las llamadas anteriores:

EPERM No se ejecutó como usuario root cuando era necesario.

EINVAL Un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encuentra un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para la coincidencia o la comparación.

ENOMEM No hay suficiente memoria disponible.

Y pueden haber ocurrido más errores de las llamadas al sistema al sistema.

EJEMPLO

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar la diferencia de tiempo en microsegundos entre el fin y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Solo registrar si el "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Solo registrar si el "next_prio" del evento de fin es menor que 50
         * o si el prio de la tarea anterior no era mayor o igual a 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Nota, lo anterior solo agregó: "next_prio < 50 || !(prev_prio >= 100"
         * Esto se debe a que, cuando se ejecute synth, se agregará el paréntesis de cierre restante.
         * Es decir, la cadena terminará siendo:
         * "next_prio < 50 || !(prev_prio >= 100)" cuando se ejecute tracefs_sync_create()
         * o tracefs_sync_echo_cmd().
         */
}
/* Mostrar cómo crear el evento sintético */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Crear el evento sintético */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Eliminar el evento sintético */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("uso: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

tracefs_synth_append_start_filter(3)

NAME

tracefs_synth_append_start_filter, tracefs_synth_append_event_filter, tracefs_synth_append_field_filter, tracefs_synth_append_regex_filter - append a filter to a synthetic tracepoint

SYNOPSIS

#include <tracefs.h>

int
tracefs_synth_append_start_filter(const char *name,
    const char *subsystem, const char *event, int type);

int
tracefs_synth_append_event_filter(const char *name,
    const char *subsystem, const char *event);

int
tracefs_synth_append_field_filter(const char *name,
    const char *subsystem, const char *event, const char *field,
    const char *value);

int
tracefs_synth_append_regex_filter(const char *name,
    const char *subsystem, const char *event, const char *field,
    const char *regex);

DESCRIPTION

The tracefs synthetic tracepoint framework allows users to create their own tracepoints. These tracepoints can be filtered using standard tracepoint filtering mechanisms.

The functions described herein provide a convenient API to create and manage these filters.

The name, subsystem, and event arguments identify the synthetic tracepoint to which the filter will be applied. The name is the name of the synthetic tracepoint, the subsystem is the subsystem to which it belongs, and the event is the event name.

tracefs_synth_append_start_filter() creates a new filter for the specified synthetic tracepoint. The type argument specifies the type of filter, which can be one of the following:

  • TRACF_TYPE_PROBE: A probe event.
  • TRACF_TYPE_SIGNAL: A signal event.
  • TRACF_TYPE_SCHED: A scheduler event.
  • TRACF_TYPE_RAW: A raw event.

tracefs_synth_append_event_filter() appends a filter to match a specific event for the given synthetic tracepoint.

tracefs_synth_append_field_filter() appends a filter to match a specific field value for the given synthetic tracepoint.

tracefs_synth_append_regex_filter() appends a filter to match a specific field against a regular expression for the given synthetic tracepoint.

RETURN VALUE

On success, these functions return 0. On failure, they return a negative error code.

EXAMPLES

The following example demonstrates how to create a synthetic tracepoint named "my_tracepoint" in the "my_subsystem" subsystem with an event named "my_event", and then append a filter to match only events where the "pid" field is equal to "123":

#include <tracefs.h>

int main() {
    int ret;

    ret = tracefs_synth_append_start_filter("my_tracepoint", "my_subsystem", "my_event", TRACF_TYPE_PROBE);
    if (ret < 0) {
        perror("tracefs_synth_append_start_filter");
        return 1;
    }

    ret = tracefs_synth_append_field_filter("my_tracepoint", "my_subsystem", "my_event", "pid", "123");
    if (ret < 0) {
        perror("tracefs_synth_append_field_filter");
        return 1;
    }

    return 0;
}
