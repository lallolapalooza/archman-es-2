tracefs_event_file_append(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_event_get_file, tracefs_event_file_read, tracefs_event_file_write, tracefs_event_file_append, tracefs_event_file_clear, tracefs_event_file_exists - Trabajar con archivos de eventos de trace.

SINOPSIS

#include <tracefs.h>
char *tracefs_event_get_file(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file);
char *tracefs_event_file_read(struct tracefs_instance *instance, const char *system, const char *event,
                              const char *file, int *psize);
int tracefs_event_file_write(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file, const char *str);
int tracefs_event_file_append(struct tracefs_instance *instance, const char *system, const char *event,
                              const char *file, const char *str);
int tracefs_event_file_clear(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file);
bool tracefs_event_file_exists(struct tracefs_instance *instance, const char *system, const char *event,
                               const char *file);

DESCRIPCIÓN

Estas son funciones para acceder a archivos específicos de eventos de tracefs. Estas funciones actúan de manera similar a las funciones de archivos de instancia de tracefs, pero son más fáciles de acceder si el sistema y los eventos se conocen de antemano.

tracefs_event_get_file() devuelve la ruta completa del archivo para el sistema y evento dados que se encuentra dentro de la instancia dada. Si instance es NULL, entonces se devuelve el archivo para el evento de la instancia de nivel superior. Tenga en cuenta que no hay ninguna comprobación para ver si el archivo realmente existe o incluso si el sistema y el evento existen. Solo crea el nombre de la ruta para un evento de este tipo si existiera. Esto actúa de forma similar a tracefs_instance_get_file(3), pero se utiliza para obtener archivos de eventos si el sistema y el evento ya se conocen.

tracefs_event_file_read() lee el contenido del archivo del evento para la instancia dada o la instancia de nivel superior si instance es NULL. Se devuelve el contenido del archivo y psize se establece en la cantidad de datos leídos. El contenido devuelto debe liberarse con free(3). Esto actúa de forma similar a tracefs_instance_file_read(3), pero se utiliza para leer el archivo del evento si el sistema y el evento ya se conocen.

tracefs_event_file_write() escribe str en el archivo del evento. Truncará cualquier cosa que ya esté en ese archivo. Esto actúa de forma similar a tracefs_instance_file_write(3), pero se utiliza para leer el archivo del evento si el sistema y el evento ya se conocen.

tracefs_event_file_append() agrega str al archivo del evento. No borrará el archivo al escribir la cadena. Esto actúa de forma similar a tracefs_instance_file_append(3), pero se utiliza para leer el archivo del evento si el sistema y el evento ya se conocen.

tracefs_event_file_clear() borra el contenido del archivo del evento. Esto actúa de forma similar a tracefs_instance_file_clear(3), pero se utiliza para leer el archivo del evento si el sistema y el evento ya se conocen.

tracefs_event_file_exists() devuelve verdadero si el archivo del evento existe y falso en caso contrario. Esto actúa de forma similar a tracefs_instance_file_exists(3), pero se utiliza para leer el archivo del evento si el sistema y el evento ya se conocen.

VALOR DE RETORNO

tracefs_event_get_file() devuelve la ruta del archivo del sistema/evento dado en caso de éxito y NULL en caso de error. El valor de retorno debe liberarse con tracefs_put_tracing_file(3).

tracefs_event_file_read() lee el contenido del archivo del sistema/evento o NULL en caso de error. El puntero devuelto debe liberarse con free(3).

tracefs_event_file_write() y tracefs_event_file_append() devuelven el número de bytes escritos en el archivo del sistema/evento o un valor negativo en caso de error.

tracefs_event_file_clear() devuelve cero en caso de éxito y -1 en caso de error.

tracefs_event_file_exists() devuelve verdadero si el archivo del sistema/evento existe para la instancia dada (o el nivel superior si instance es NULL) o falso en caso contrario.

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(int argc, char **argv)
{
        char *system;
        char *event;
        char *file;
        char *cmd = NULL;
        char *buf;
        char *str;
        char ch = 'r';
        int size;
        if (argc < 4) {
                printf("uso: %s system event file [(-a|-w) escritura | -c]\n"
                       "   lee el archivo system/event o escribe si [escritura se suministra]\n",
                       argv[0]);
                exit(0);
        }
        system = argv[1];
        event = argv[2];
        file = argv[3];
        if (argc > 4)
                cmd = argv[4];
        if (!tracefs_event_file_exists(NULL, system, event, file)) {
                fprintf(stderr, "El archivo %s/%s/%s no existe\n",
                                system, event, file);
                exit(-1);
        }
        if (cmd) {
                if (cmd[0] != '-')
                        ch = cmd[0];
                else
                        ch = cmd[1];
                if (!ch)
                        ch = 'c';
        }
        switch (ch) {
        case 'r':
                buf = tracefs_event_file_read(NULL, system, event, file, &size);
                if (buf)
                        printf("%s", buf);
                else
                        fprintf(stderr, "Fallo al leer %s/%s/%s\n",
                                system, event, file);
                free(buf);
                break;
        case 'w':
        case 'a':
                if (argc < 6) {
                        fprintf(stderr, "El comando %s requiere algo que escribir\n",
                                ch == 'w' ? "escribir" : "agregar");
                        exit(-1);
                }
                if (ch == 'w')
                        size = tracefs_event_file_write(NULL, system, event, file, argv[5]);
                else
                        size = tracefs_event_file_append(NULL, system, event, file, argv[5]);
                if (size < 0) {
                        fprintf(stderr, "Fallo al escribir '%s' en %s/%s/%s\n",
                                        argv[5], system, event, file);
                        exit(-1);
                }
                break;
        case 'c':
                if (tracefs_event_file_clear(NULL, system, event, file) < 0) {
                        fprintf(stderr, "Fallo al borrar %s/%s/%s\n",
                                system, event, file);
                        exit(-1);
                }
                break;
        default:
                fprintf(stderr, "Comando desconocido '%c'\n", ch);
                exit(-1);
        }
        exit(0);
}
