Paquete: libtracefs

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_function_filter, tracefs_function_notrace, tracefs_filter_functions - Funciones para modificar los filtros de traza de funciones

SINOPSIS

#include <tracefs.h>
int tracefs_function_filter(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_function_notrace(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_filter_functions(const char *filter, const char *module, char ***list);

DESCRIPCIÓN

tracefs_function_filter y tracefs_function_notrace se pueden usar para limitar las funciones del kernel de Linux que serían trazadas por los trazadores de funciones y de gráfico de funciones. tracefs_function_filter define una lista de funciones que pueden ser trazadas. tracefs_function_notrace define una lista de funciones que no serán trazadas. Si una función está en ambas listas, no será trazada.

Toman una instancia , que puede ser NULL para la traza de nivel superior, filtro, una cadena que representa un filtro que debe aplicarse para definir qué funciones se van a trazar, módulo, para limitar el filtrado a un módulo específico (o NULL para filtrar en todas las funciones), flags, que contiene indicadores de control sobre cómo se manejarán los filtros (ver la sección FLAGS a continuación).

tracefs_filter_functions devuelve una lista de funciones que pueden ser filtradas por el filtro y el módulo suministrados. Si tanto filtro como módulo son NULL, entonces se devuelven todas las funciones disponibles que se pueden filtrar. En caso de éxito, lista debe liberarse con tracefs_list_free()(3).

El filtro puede ser una coincidencia directa de una función, un comodín (glob) o una expresión regular (regex(3)). Un comodín es donde * coincide con cero o más caracteres, ? coincidirá con cero o un carácter, y . solo coincide con un punto. Si se determina que filtro es una expresión regular (donde contiene algo que no sean caracteres alfanuméricos, o ., *, ?) entonces filtro se procesará como una expresión regular(3) siguiendo las reglas de regex(3), y . no es un punto, sino que coincidirá con cualquier carácter. Para forzar una expresión regular, prefije filtro con un ^ o apéndalo con un $ ya que el filtro realiza coincidencias completas de las funciones de todos modos.

Si módulo está establecido y filtro es NULL, esto implicará lo mismo que si filtro fuera igual a "*". Lo que habilitará todas las funciones para un módulo dado. De lo contrario, filtro puede ser NULL si una llamada anterior a tracefs_function_filter() con la misma instancia tenía TRACEFS_FL_CONTINUE establecido y esta llamada no lo tiene. Esto es útil para simplemente confirmar los filtros anteriores. También puede ser NULL si TRACEFS_FL_RESET está establecido y la llamada anterior no tenía la misma instancia y TRACEFS_FL_CONTINUE establecido. Esto es útil para simplemente borrar el filtro.

FLAGS

El parámetro flags puede tener los siguientes valores establecidos, o ser cero.

TRACEFS_FL_RESET : Si flags contiene TRACEFS_FL_RESET, entonces borrará los filtros que están actualmente establecidos antes de aplicar filtro. De lo contrario, filtro se agrega al conjunto actual de filtros ya habilitados. Si esta bandera está establecida y la llamada anterior a tracefs_function_filter() tenía la misma instancia y la bandera TRACEFS_FL_CONTINUE estaba establecida, entonces la función fallará con un retorno de -1 y errno establecido en EBUSY.

TRACEFS_FL_CONTINUE : Si flags contiene TRACEFS_FL_CONTINUE, entonces filtro no tendrá efecto después de una llamada exitosa a tracefs_function_filter(). Esto permite múltiples llamadas a tracefs_function_filter() para actualizar la función de filtro y luego una única llamada (una sin la bandera TRACEFS_FL_CONTINUE establecida) para confirmar todos los filtros. Puede ser llamada múltiples veces para agregar más filtros. Una llamada sin esta bandera establecida confirmará los cambios antes de devolver (si el filtro pasado tuvo éxito). Una llamada a tracefs_function_filter() después de una que tuvo la bandera TRACEFS_FL_CONTINUE establecida para la misma instancia fallará si la bandera TRACEFS_FL_RESET está establecida, ya que la bandera de restablecimiento solo es aplicable para el primer filtro que se agrega antes de confirmar.

TRACEFS_FL_FUTURE : Si flags contiene TRACEFS_FL_FUTURE y módulo contiene una cadena de un módulo, entonces si el módulo no está cargado, intentará escribir el filtro con el módulo en el archivo de filtro. A partir de Linux v4.13, las funciones del módulo podían agregarse al filtro antes de que fueran cargadas. El filtro se almacenará en caché y, cuando se cargue el módulo, se establecerá el filtro antes de que la función del módulo se ejecute, lo que permitirá rastrear las funciones de inicialización de un módulo. Esto solo funcionará si el filtro no es una expresión regular.

VALOR DE RETORNO

Para tracefs_function_filter() y tracefs_function_notrace() un retorno de 0 significa éxito. Si hay un error pero el filtrado no se inició, entonces se devuelve 1. Si el filtrado se inició pero ocurre un error, entonces se devuelve -1. El estado del filtrado puede ser desconocido.

Si TRACEFS_FL_CONTINUE estaba establecido, y se devolvió 0 o -1, entonces se debe hacer otra llamada a tracefs_function_filter() sin TRACEFS_FL_CONTINUE establecido para confirmar (y cerrar) el filtrado.

Para tracefs_filter_functions(), un retorno de 0 significa éxito, y el parámetro lista se llena con una lista de nombres de funciones que coincidieron con filtro y módulo. lista es una matriz de cadenas, donde el último puntero de cadena en la matriz es NULL. La lista debe liberarse con tracefs_list_free(). En caso de fallo, se devuelve un valor negativo, y se ignora lista.

ERRORES

tracefs_function_filter() puede fallar con los siguientes errores:

EINVAL El filtro no es válido o no coincidió con ninguna función.

EBUSY La llamada anterior de tracefs_function_filter() se realizó con la misma instancia y TRACEFS_FL_CONTINUE establecido, y la llamada actual tenía TRACEFS_FL_RESET establecido.

Otros errores también pueden ocurrir debido a llamadas internas del sistema.

#include <errno.h>
#include <tracefs.h>

static const char *filters[] = { "run_init_process", "try_to_run_init_process", "dummy1", NULL };
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = tracefs_instance_create(INST);
        char **func_list;
        int ret;
        int i;
        if (!inst) {
                /* Error al crear una nueva instancia de traza */
        }
        if (tracefs_filter_functions("*lock*", NULL, &func_list) < 0) {
                printf("No se pudo leer las funciones de filtro\n");
                goto out;
        }
        printf("Ignorando las siguientes funciones:\n");
        for (i = 0; func_list[i]; i++)
                printf("  %s\n", func_list[i]);
        tracefs_list_free(func_list);
        /* No trazar ninguna función con la palabra "lock" en ella */
        ret = tracefs_function_notrace(inst, "*lock*", NULL, TRACEFS_FL_RESET);
        if (ret) {
                printf("Fallo al establecer el filtro notrace\n");
                goto out;
        }
        /* Primero restablecer el filtro */
        ret = tracefs_function_filter(inst, NULL, NULL,
                                      TRACEFS_FL_RESET | TRACEFS_FL_CONTINUE);
        if (ret) {
                printf("Fallo al restablecer el filtro\n");
                /* Asegurarse de que se cierra, -1 significa que el filtro se inició */
                if (ret < 0)
                        tracefs_function_filter(inst, NULL, NULL, 0);
        }
        for (i = 0; filters[i]; i++) {
                ret = tracefs_function_filter(inst, filters[i], NULL,
