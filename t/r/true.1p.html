Esta página del manual es parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

true — devuelve valor verdadero

SINOPSIS

true

DESCRIPCIÓN

Las siguientes secciones son informativas.

USO PARA APLICACIONES

Esta utilidad se usa típicamente en scripts de shell, como se muestra en la sección EJEMPLOS. La utilidad incorporada especial : es a veces más eficiente que true.

EJEMPLOS

Este comando se ejecuta indefinidamente:

while true
do
    command
done

FUNDAMENTACIÓN

La utilidad true se ha mantenido en este volumen de POSIX.1‐2017, aunque la utilidad especial incorporada del shell : proporciona una funcionalidad similar, porque true es ampliamente utilizada en scripts históricos y es menos críptica para los lectores de scripts novatos.
