TRACE-CMD-SHOW(1) Manual de libtracefs TRACE-CMD-SHOW(1)

NOMBRE

trace-cmd-show - muestra el contenido del búfer de rastreo del kernel de Ftrace.

SINOPSIS

trace-cmd show [OPCIONES]

DESCRIPCIÓN

trace-cmd(1) show muestra el contenido de uno de los archivos de rastreo del kernel de Ftrace: trace, snapshot o trace_pipe. Es básicamente el equivalente a hacer:

cat /sys/kernel/debug/tracing/trace

OPCIONES

-p

En lugar de mostrar el contenido del archivo "trace", usa el archivo "trace_pipe". La diferencia entre ambos es que el archivo "trace" es estático. Es decir, si el rastreo se detiene, el archivo "trace" mostrará el mismo contenido cada vez. 
El archivo "trace_pipe" es de lectura y consume. Una lectura del archivo consumirá la salida de lo que se leyó y no leerá lo mismo una segunda vez, incluso si el rastreo se detiene. Este archivo también se bloquea. Si no hay datos disponibles, trace-cmd show se detendrá y esperará a que aparezcan datos.

-s

En lugar de leer el archivo "trace", lee el archivo snapshot. La instantánea la realiza una aplicación que escribe en ella y el kernel realizará un intercambio entre el búfer activo actual y el búfer de instantánea actual. Si no se realizan más intercambios, la instantánea permanecerá estática. Esta no es una lectura que consume.

-c cpu

Lee solo el archivo trace para una CPU especificada.

-f

Muestra el nombre de ruta completo del archivo que se está mostrando.

-B buf

Si se creó una instancia de búfer, la opción -B accederá a los archivos asociados con el búfer dado.

--tracing_on

Muestra si el rastreo está activado para la instancia dada.

--current_tracer

Muestra cuál es el rastreador actual.

--buffer_size

Muestra el tamaño actual del búfer (por CPU).

--buffer_total_size

Muestra el tamaño total de todos los búferes.

--buffer_subbuf_size

Muestra el tamaño en kilobytes de los sub-búferes del búfer de anillo. El búfer de anillo se divide en sub-búferes de igual tamaño, donde un evento solo puede ser tan grande como la sección de datos del sub-búfer (el tamaño menos sus metadatos).

--buffer_percent

Muestra el porcentaje del búfer que debe estar lleno antes de que se despierte a un lector que está bloqueado en el archivo trace_pipe_raw. 
0       : despertarse inmediatamente ante cualquier dato nuevo
1 - 99  : despertarse en este porcentaje de sub-búferes llenos
100     : despertarse después de que el búfer esté lleno y el escritor esté en el último sub-búfer

--ftrace_filter

Muestra qué filtros de funciones están configurados.

--ftrace_notrace

Muestra qué filtros de funciones deshabilitadas están configurados.

--ftrace_pid

Muestra los PID a los que está limitado el rastreador de funciones (si los hay).

--graph_function

Muestra las funciones que se graficarán.

--graph_notrace

Muestra las funciones que no se graficarán.

--hist [sistema:]evento

Muestra el contenido de un archivo "hist" de histograma para un evento dado.

--trigger [sistema:]evento

Muestra el contenido del archivo "trigger" para un evento dado.

--cpumask

Muestra la máscara de CPU que rastreará el rastreo.
