NOMBRE

transmission-remote-gtk - Cliente RPC para el cliente bittorrent Transmission.

SINOPSIS

transmission-remote-gtk [OPCIONES] [archivo torrent|enlace magnet|url]

DESCRIPCIÓN

transmission-remote-gtk es una aplicación para la gestión remota del cliente BitTorrent Transmission utilizando su interfaz RPC.

OPCIONES

Las siguientes opciones se aceptan al ejecutar "transmission-remote-gtk":

-m, --minimized, /m
Inicia la aplicación minimizada

ENTORNO

Las siguientes variables de entorno se pueden usar al ejecutar "transmission-remote-gtk":

$TRG_CLIENT_DEBUG
Cuando esta variable de entorno esté configurada, se registrará información HTTP y JSON detallada en la salida estándar para fines de depuración.
