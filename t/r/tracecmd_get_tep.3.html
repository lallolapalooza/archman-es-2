tracecmd_get_tep(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_read_cpu_first, tracecmd_read_data, tracecmd_read_at, tracecmd_free_record, tracecmd_get_tep - Leer eventos grabados de un archivo de traza.

SINOPSIS

#include <trace-cmd.h>
struct tep_record *tracecmd_read_cpu_first(struct tracecmd_input *handle, int cpu);
struct tep_record *tracecmd_read_data(struct tracecmd_input *handle, int cpu);
struct tep_record *tracecmd_read_at(struct tracecmd_input *handle, unsigned long long offset, int *cpu);
void tracecmd_free_record(struct tep_record *record);
struct tep_handle *tracecmd_get_tep(struct tracecmd_input *handle);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para leer datos de traza de un archivo de traza abierto con tracecmd_open()(3), tracecmd_open_fd()(3) o tracecmd_open_head()(3).

La función tracecmd_read_cpu_first() lee el primer registro de traza para un cpu dado de un archivo de traza asociado con handle. El registro devuelto debe liberarse con tracecmd_free_record().

La función tracecmd_read_data() lee el siguiente registro de traza para un cpu dado de un archivo de traza asociado con handle e incrementa el puntero de ubicación de lectura, de modo que la próxima llamada a tracecmd_read_data() no leerá el mismo registro de nuevo. El registro devuelto debe liberarse con tracecmd_free_record().

La función tracecmd_read_at() lee un registro de traza desde una offset específica dentro del archivo asociado con handle. El CPU en el que ocurrió el evento registrado se almacena en *cpu. La función no cambia el puntero de ubicación de lectura actual. El registro devuelto debe liberarse con tracecmd_free_record().

La función tracecmd_free_record() libera un record devuelto por cualquiera de las APIs de tracecmd_read_.

La función tracecmd_get_tep() devuelve un contexto tep para un handle dado.

VALOR DE RETORNO

Las funciones tracecmd_read_cpu_first(), tracecmd_read_data() y tracecmd_read_at() devuelven un puntero a struct tep_record o NULL en caso de error. El registro devuelto debe liberarse con tracecmd_free_record().

La función tracecmd_get_tep() devuelve un puntero al contexto tep o NULL si no hay un contexto tep para el handle dado. El puntero tep devuelto no debe liberarse.

EJEMPLO

#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open("trace.dat");
        if (!handle) {
                /* Falló la apertura del archivo trace.dat */
        }
...
unsigned long long offset = 0;
struct tep_record *rec;
int cpu = 0;
        rec = tracecmd_read_cpu_first(handle, cpu);
        while (rec) {
                ...
                if ( /* algún registro interesante detectado */) {
                        /* almacena el offset del registro interesante */
                        offset = rec->offset;
                }
                ...
                tracecmd_free_record(rec);
                rec = tracecmd_read_data(handle, cpu);
        }
        ...
        if (offset) {
                rec = tracecmd_read_at(handle, offset, &cpu);
                if (rec) {
                        /* Obtuvo registro en offset en cpu */
                        ...
                        tracecmd_free_record(rec);
                }
        }
...
        tracecmd_close(hadle);
