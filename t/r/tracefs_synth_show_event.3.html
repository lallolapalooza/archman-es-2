tracefs_synth_show_event(3)

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_synth_echo_cmd, tracefs_synth_get_start_hist, tracefs_synth_get_name, tracefs_synth_raw_fmt, tracefs_synth_show_event, tracefs_synth_show_start_hist, tracefs_synth_show_end_hist, tracefs_synth_get_event - Recuperar datos de eventos sintéticos.

SINOPSIS

#include <tracefs.h>
int tracefs_synth_echo_cmd(struct trace_seq *seq, struct tracefs_synth *synth);
struct tracefs_hist *tracefs_synth_get_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_get_name(struct tracefs_synth *synth);
int tracefs_synth_raw_fmt(struct trace_seq *seq, struct tracefs_synth *synth);
const char *tracefs_synth_show_event(struct tracefs_synth *synth);
const char *tracefs_synth_show_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_show_end_hist(struct tracefs_synth *synth);
struct tep_event *tracefs_synth_get_event(struct tep_handle *tep, struct tracefs_synth *synth);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos que activan un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, activará el evento sintético. Los valores de los campos distintos de los campos coincidentes pueden pasarse del evento de inicio al evento final para realizar cálculos sobre ellos, o simplemente pasarse como parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, se establece "sched_switch" como el evento de fin. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como un campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice TRACEFS_TIMESTAMP_USECS como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

Consulte tracefs_synth_alloc(3) para la asignación de eventos sintéticos, y tracefs_synth_create() para la creación del evento sintético en el sistema.

tracefs_synth_echo_cmd() actúa como tracefs_synth_create(), pero en lugar de crear el evento sintético en el sistema, escribirá los comandos echo para crearlo manualmente en el seq proporcionado.

tracefs_synth_get_start_hist() devuelve un descriptor struct tracefs_hist que describe el histograma utilizado para crear el evento sintético.

enum tracefs_synth_handler {
        TRACEFS_SYNTH_HANDLE_MATCH,
        TRACEFS_SYNTH_HANDLE_MAX,
        TRACEFS_SYNTH_HANDLE_CHANGE,
};

tracefs_synth_get_name() devuelve el nombre del evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto de evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_raw_fmt() escribe las cadenas de formato sin procesar (evento dinámico e histogramas) del evento sintético en el seq proporcionado.

tracefs_synth_show_event() devuelve el formato del evento dinámico utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto de evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_show_start_hist() devuelve el formato del histograma de inicio utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto de evento synth y se libera con el evento mediante tracefs_synth_free().

tracefs_synth_show_end_hist() devuelve el formato del histograma de fin utilizado por el evento sintético o NULL en caso de error. La cadena devuelta pertenece al objeto de evento synth y se libera con el evento mediante tracefs_synth_free().

La función tracefs_synth_get_event() devuelve un evento tep, que describe el evento sintético dado. La API detecta cualquier evento dinámico recién creado o eliminado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

VALOR DE RETORNO

tracefs_synth_get_name(), tracefs_synth_show_event(), tracefs_synth_show_start_hist() y tracefs_synth_show_end_hist() devuelven una cadena propiedad del objeto de evento synth.

La función tracefs_synth_get_event() devuelve un puntero a un evento tep o NULL en caso de error o si el evento sintético solicitado no se encuentra. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

Todas las demás funciones devuelven cero en caso de éxito o -1 en caso de error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecuta como usuario root cuando es necesario.

EINVAL Un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encuentra un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para coincidencia o comparación.

ENOMEM no hay suficiente memoria disponible.

Y pueden haber ocurrido más errores en las llamadas del sistema al sistema.

EJEMPLO

Consulte tracefs_sql(3) para un uso más detallado de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar la diferencia de tiempo en microsegundos entre el fin y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Registrar solo si el "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Registrar solo si el "next_prio" del evento de fin es menor que 50
         * o si la prioridad de la tarea anterior no era mayor o igual a 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Nota, lo anterior solo agregó: "next_prio < 50 || !(prev_prio >= 100"
         * Esto se debe a que, cuando se ejecute el synth, se agregará el paréntesis de cierre restante. Es decir, la cadena terminará siendo:
         * "next_prio < 50 || !(prev_prio >= 100)" cuando se ejecute tracefs_sync_create()
         * o tracefs_sync_echo_cmd().
         */
}

NAME

tracefs_synth_show_event - create, delete and show synthetic events

SYNOPSIS

/* Includes needed headers */
#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
static struct tracefs_synth *synth;
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

DESCRIPTION

The tracefs synthetic events are a way to simulate events that are not generated by the kernel itself. These events can be used for testing purposes, or for generating custom event streams that can be traced by the kernel tracing infrastructure.

The provided C code snippet demonstrates how to use the libtracefs library to manage these synthetic events.

The program can be executed with optional arguments:

- create
This option creates a synthetic event using the tracefs_synth_create function.
- delete
This option deletes a synthetic event using the tracefs_synth_destroy function.

If no arguments are provided, the program will display the details of the synthetic event using the show_event function.

The make_event function is assumed to be defined elsewhere and is responsible for initializing the synthetic event structure pointed to by the global variable synth.

The show_event function utilizes trace_seq to format and print the synthetic event command, effectively displaying its definition.

Finally, regardless of the operation performed, the synthetic event structure is cleaned up using tracefs_synth_free.

RETURN VALUE

This program returns 0 on success. If an invalid argument is provided, it prints a usage message and exits with -1.

ERRORS

The program can exit with -1 if an invalid argument is provided.

EXAMPLE

To create a synthetic event:

$ ./your_program create

To delete a synthetic event:

$ ./your_program delete

To show the details of the synthetic event:

$ ./your_program

The output of the last command will depend on how the synthetic event was defined in the assumed make_event function.
