DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos que desencadenan un evento sintético. Un evento es el evento de inicio del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, desencadenará el evento sintético. Los valores de campo distintos de los campos coincidentes pueden pasarse del evento de inicio al evento final para realizar cálculos sobre ellos, o simplemente pasarse como un parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, establezca "sched_switch" como el evento final. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice *TRACEFS_TIMESTAMP_USECS" como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_alloc() asigna e inicializa un evento sintético. No crea el evento sintético, sino que proporciona la información mínima para hacerlo. Consulte tracefs_synth_create(3) para ver cómo crear el evento sintético en el sistema. Requiere un manejador tep que puede ser creado por tracefs_local_events(3) para más información. El name contiene el nombre del evento sintético que se creará. El start_system es el nombre del sistema para el evento de inicio. Puede ser NULL y se elegirá el primer evento con el nombre de start_event. El end_system es el nombre del sistema para el evento final. Puede ser NULL y se elegirá el primer evento con el nombre de end_event como evento final. Si se proporciona match_name, entonces este será el campo del evento sintético creado que contiene las claves coincidentes del start_match_field del evento de inicio y el end_match_field del evento final. Si match_name es NULL, entonces no se registrará en el evento sintético creado.

tracefs_synth_add_match_field() agregará una segunda clave para que coincida entre el evento de inicio y el evento final. Si se proporciona name, entonces el contenido del campo coincidente se guardará con este name en el evento sintético. El start_match_field es el campo del evento de inicio para que coincida con el end_match_field del evento final.

tracefs_synth_add_compare_field() se utiliza para comparar el start_compare_field del evento de inicio con el end_compare_field del evento final. Se debe proporcionar el name para que el resultado se guarde en el evento sintético. No tiene sentido no pasar esto al evento sintético después de realizar el trabajo de los campos comparados, ya que no tiene ningún otro propósito. El parámetro calc puede ser uno de:

TRACEFS_SYNTH_DELTA_END - calcula la diferencia entre el contenido en el end_compare_field y el contenido del start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcula la diferencia entre el contenido en el start_compare_field y el contenido del end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Suma el contenido del start_compare_field al contenido del end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Registra el start_field del evento de inicio como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que start_field.

tracefs_synth_add_end_field() - Registra el end_field del evento final como name en el evento sintético. Si name es NULL, entonces el nombre utilizado será el mismo que end_field.

tracefs_synth_append_start_filter() crea un filtro o se adhiere a él para el evento de inicio. Dependiendo de type, construirá una cadena de tokens para paréntesis o declaraciones lógicas, o puede agregar una comparación de field con val basada en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver más abajo TRACEFS_FILTER_AND - Añade "&&" al filtro TRACEFS_FILTER_OR - Añade "||" al filtro TRACEFS_FILTER_NOT - Añade "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añade "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añade ")" al filtro

field, compare, y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces _compare se utilizará para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de banderas.

tracefs_synth_append_end_filter() es igual a tracefs_synth_append_start_filter pero filtra en el evento final.

tracefs_synth_free() libera el descriptor asignado devuelto por tracefs_synth_alloc().

DESCRIPTION

Synthetic events allow users to create new events based on existing events. A synthetic event is defined by a start event and an end event. When the start event occurs, it is recorded. When the end event occurs, the start event is searched for and if found, a new synthetic event is created by combining information from both the start and end events.

The tracefs_synth_alloc() function allocates and initializes a new synthetic event descriptor. The tep argument is a handle to the trace event parsing library. The name is the name of the synthetic event. The group is the group name for the synthetic event. The start_event and end_event arguments are the names of the events that will trigger the start and end of the synthetic event, respectively. The start_field and end_field arguments are the names of fields in the start and end events that will be used to match them. The match_field argument is the name of the field that will be used to link the start and end events together. For example, if both events have a PID field, then match_field can be set to "pid".

The tracefs_synth_free() function frees the memory allocated for the synthetic event descriptor.

The tracefs_synth_create() function creates the synthetic event on the system. This will make the synthetic event visible to the kernel's tracing infrastructure.

The tracefs_synth_destroy() function destroys a previously created synthetic event.

The tracefs_synth_complete() function completes the definition of a synthetic event. This should be called after all fields and filters have been added.

The tracefs_synth_trace() function enables tracing of the synthetic event to the specified file. If filename is NULL, the event will be traced to the default trace file.

The tracefs_synth_snapshot() function takes a snapshot of the synthetic event. This will capture all current synthetic events.

The tracefs_synth_save() function saves the synthetic event to the specified file. This can be used to later recreate the synthetic event.

The tracefs_synth_echo_cmd() function prints the command that would be used to create the synthetic event to the given trace_seq buffer.

The tracefs_synth_get_start_hist() function returns a pointer to the trace event functions for the start event.

The tracefs_synth_get_name() function returns the name of the synthetic event.

The tracefs_synth_raw_fmt() function allows for raw formatting of the synthetic event. This can be used to define custom event formats.

The tracefs_synth_show_event(), tracefs_synth_show_start_hist(), and tracefs_synth_show_end_hist() functions print information about the synthetic event, its start event, and its end event, respectively, to the given trace_seq buffer.

The tracefs_synth_get_event() function returns a pointer to the trace event functions for the synthetic event itself.

The tracefs_synth_add_start_field() function adds a field from the start event to the synthetic event. The name argument is the name of the field in the start event. The new_name argument is the name of the field in the synthetic event. If new_name is NULL, the original field name will be used.

The tracefs_synth_add_end_field() function adds a field from the end event to the synthetic event. The name argument is the name of the field in the end event. The new_name argument is the name of the field in the synthetic event. If new_name is NULL, the original field name will be used.

The tracefs_synth_add_compare_field() function adds a field that is calculated by comparing fields from the start and end events. The start_field_type and end_field_type arguments specify the type of the fields in the start and end events, respectively. The type argument specifies the type of comparison to perform (e.g., delta, difference). The name argument is the name of the new field in the synthetic event.

The tracefs_synth_append_start_filter() and tracefs_synth_append_end_filter() functions append a filter condition to the start and end events, respectively. The type argument specifies the type of filter (e.g., comparison, boolean logic). The field argument is the name of the field to filter on. The op argument is the comparison operator. The value argument is the value to compare against.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
