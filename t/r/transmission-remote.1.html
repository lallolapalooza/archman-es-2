NOMBRE

transmission-remote — una utilidad de control remoto para transmission-daemon(1) y transmission(1)

SINOPSIS

transmission-remote [host:puerto | host | puerto] [-a nombres-de-archivo-o-URLs] [-as] [-AS] [-asd número] [-asu número] [-asc] [-ASC] [-b] [-c ruta | -C] [-d número | -D] [-e tamaño] [-er | -ep | -et] [--exit] [-f] [-F filtro] [-g archivos] [-G archivos] [-gsr ratio] [-GSR] [-h] [-i] [-ic] [-ids] [-if] [-ip] [-it] [-j] [-l] [-m | -M] [-n usuario:contraseña] [-ne] [-N netrc] [-o | -O] [-p puerto] [-Bh] [-Bn] [-Bl] [-ph archivos] [-pl archivos] [-pn archivos] [-pr peers] [-r] [-rad] [-s | -S] [-sr ratio] [-SR] [-srd] [-si] [-st] [-t todos | activos | id | hash] [-hl] [-HL] [-u número | -U] [-utp | -no-utp] [-v] [-V] [-w directorio-descarga] [-x | -X] [-y | -Y] [-pi]

DESCRIPCIÓN

transmission-remote es una utilidad de control remoto para transmission(1) y transmission-daemon(1).

Por defecto, transmission-remote se conecta a la sesión de transmission en localhost:9091. Se pueden controlar otras sesiones especificando un host y/o puerto diferentes.

EJEMPLOS

Para añadir un torrent desde un URL y establecer el directorio de descarga:

transmission-remote -a http://example.com/torrent.torrent -w /home/user/downloads

Para iniciar todos los torrents pausados:

transmission-remote -S -t paused

Para eliminar un torrent y sus datos:

transmission-remote -rad -t 23

transmission-remote(1)

NAME

transmission-remote - Interfaz de línea de comandos para transmission-daemon(1)

SYNOPSIS

transmission-remote [options] [host[:port]]

DESCRIPTION

transmission-remote es un cliente de línea de comandos para interactuar con un transmission-daemon(1) en ejecución.

Las opciones se pueden agrupar. Por ejemplo, -t1-3 -tdl equivale a -t1 -t2 -t3 -td -tl.

Para aplicar una opción a un solo torrent, use la opción -t, --torrent. Por ejemplo, -t1 --stop para detener el torrent con ID 1.

Para aplicar una opción a todos los torrents, use -tall. Por ejemplo, -tall --stop para detener todos los torrents.

Para aplicar una opción a todos los torrents que actualmente están en ejecución, use -tactive.

Para aplicar una opción a todos los torrents que están actualmente en pausa, use -tpaused.

Para aplicar una opción a todos los torrents que están actualmente descargando, use -tdownloading.

Para aplicar una opción a todos los torrents que están actualmente subiendo, use -tuploading.

Para aplicar una opción a todos los torrents que están actualmente detenidos (no descargando ni subiendo), use -tstopped.

Puede seleccionar un conjunto de torrents usando la opción -t, --torrent, seguido de una lista de IDs de torrents separados por comas o rangos. Por ejemplo, -t2,4,6-8 operará en los torrents con IDs 2, 4, 6, 7 y 8.

OPTIONS

-a --add torrent_file...
Añade uno o más torrents desde el archivo especificado.
-b --batch
Modo batch. Se utiliza para interactuar con el demonio sin necesidad de la interfaz de usuario interactiva.
-d --downlimit limit
Limita la velocidad de descarga máxima a limit kB/s. Si se seleccionan torrents actuales, opera sobre ellos. De lo contrario, cambia la configuración global.
-D --no-downlimit
Deshabilita los límites de velocidad de descarga.
-e --encryption mode
Establece el modo de cifrado. Los modos disponibles son: preferred, required, tolerated.
-E --no-encryption
Deshabilita el cifrado para las conexiones de pares.
-F --filter rule
Filtra los torrents por las reglas especificadas. Las reglas pueden ser:
  • n: seguido del nombre del torrent.
  • l: seguido de la etiqueta del torrent.
  • s: seguido del estado del torrent (ej. downloading, paused, etc.).
Puede usar múltiples filtros combinados con operadores lógicos si es necesario (ver el manual de transmission-cli para más detalles).
-f --files
Lista los archivos del torrent actual.
-g --get-files file_ids
Descarga solo los archivos especificados por sus IDs (separados por comas).
-G --set-files file_ids
Establece los archivos especificados por sus IDs (separados por comas) a descargar o no. Útil en combinación con --add.
-h --help
Muestra el mensaje de ayuda y sale.
-i --info
Muestra información detallada sobre el torrent actual.
-I --ids
Devuelve una lista de IDs de torrents que coinciden con los filtros aplicados.
-l --list
Lista todos los torrents.
-m --move directory
Mueve el torrent actual al directorio especificado.
-n --next-announce url
Añade una nueva URL de anuncio al torrent actual.
-o --output directory
Establece el directorio de salida para las descargas. Si se usa con --add, establece el directorio de descarga para el nuevo torrent.
-p --paused
Pausa el torrent actual.
-P --resume
Reanuda el torrent actual.
-pa --path directory
Establece el directorio de descarga para el torrent actual. Si se usa con --add, establece el directorio de descarga para el nuevo torrent.
-ph --priority-high file_ids
Establece la prioridad de los archivos especificados a alta.
-pl --priority-low file_ids
Establece la prioridad de los archivos especificados a baja.
-pn --priority-normal file_ids
Establece la prioridad de los archivos especificados a normal.
-r --remove
Elimina el torrent actual.
-re --remove-with-files
Elimina el torrent actual y sus archivos asociados.
--rename new_name
Renombra el torrent actual o una carpeta dentro de él.
-s --start
Inicia el torrent actual.
-S --stop
Detiene el torrent actual.
-sd --seed-ratio ratio
Establece la relación de seeding para el torrent actual. El torrent se eliminará o pausará cuando alcance esta relación.
-st --seed-time minutes
Establece el tiempo de seeding en minutos para el torrent actual. El torrent se eliminará o pausará cuando alcance este tiempo.
-t --torrent hash
Especifica el torrent en el que operar. Para establecer más de un torrent actual, una sus IDs juntas en una lista, como "-t2,4,6-8" para operar en los torrents cuyos IDs son 2, 4, 6, 7 y 8.
--trash-torrent
Elimina los torrents después de añadirlos.
--no-trash-torrent
No elimina los torrents después de añadirlos.
-hl --honor-session
Hace que el torrent actual respete los límites de la sesión.
-HL --no-honor-session
Hace que el torrent actual no respete los límites de la sesión.
-u --uplimit limit
Limita la velocidad de subida máxima a limit kB/s. Si se seleccionan torrents actuales, opera sobre ellos. De lo contrario, cambia la configuración global.
-U --no-uplimit
Deshabilita los límites de velocidad de subida.
--utp
Habilita uTP para las conexiones de pares.
--no-utp
Deshabilita uTP para las conexiones de pares. Si se seleccionan torrents actuales, opera sobre ellos. De lo contrario, cambia la configuración global.
-v --verify
Verifica el torrent actual.
-V --version
Muestra el número de versión y sale.
-w --download-dir directory
Cuando se usa junto con --add, establece la carpeta de descarga del nuevo torrent. De lo contrario, establece la carpeta de descarga predeterminada.
-x --pex
Habilita el intercambio de pares (PEX).
-X --no-pex
Deshabilita el intercambio de pares (PEX).
-y --lds
Habilita el descubrimiento de pares locales (LPD).
-Y --no-lds
Deshabilita el descubrimiento de pares locales (LPD).
-pi --peer-info
Lista los pares conectados del torrent actual. En la sección `status' de la lista, se utiliza la siguiente abreviatura:
D: Descargando de este par
d: Descargaríamos de este par si nos dejaran
E: Conexión cifrada
H: Par descubierto a través de DHT
I: Par es una conexión entrante
K: El par nos ha desbloqueado, pero no estamos interesados
O: Desbloqueo optimista
T: Par conectado a través de uTP
U: Subiendo al par
u: Subiríamos a este par si nos lo pidieran
X: Par descubierto a través de Intercambio de Pares (PEX)
?: Hemos desbloqueado a este par, pero no está interesado
--blocklist-update
Actualiza la lista de bloqueo desde la URL especificada en la clave blocklist-url de la configuración del cliente remoto.

EJEMPLOS

Listar todos los torrents:

$ transmission-remote -l
Listar todos los torrents activos: 
$ transmission-remote -tactive -l
Listar todos los torrents con etiqueta "abc": 
$ transmission-remote -F l:abc -l
Listar todos los torrents con nombre que contenga "def" o con etiqueta "abc": 
$ transmission-remote -t $( transmission-remote -F n:def -ids )$( transmission-remote -F l:abc -ids ) -l
Renombrar la carpeta raíz del torrent de "test1/examplefile.txt" a "test2/examplefile.txt" 
$ transmission-remote -t1 --path test1 --rename test2
Establecer los límites de descarga y subida a 400 kB/s y 60 kB/s respectivamente: 
$ transmission-remote -d400 -u60
$ transmission-remote --downlimit=400 --uplimit=60
Establecer los límites de descarga y subida alternativos a 100 kB/s y 20 kB/s respectivamente: 
$ transmission-remote -asd100 -asu20
$ transmission-remote --alt-speed-downlimit=100 --alt-speed-uplimit=20
Establecer el planificador para usar los límites de velocidad alternativos los días laborables entre las 10 AM y las 11 PM 
$ transmission-remote --alt-speed-time-begin=1000
$ transmission-remote --alt-speed-time-end=2300
$ transmission-remote --alt-speed-days=1-5
$ transmission-remote --alt-speed-scheduler
Listar los IDs y estados de todos los torrents: 
$ transmission-remote -l
Listar todos los torrents de una sesión remota que requiere autenticación: 
$ transmission-remote host:9091 --auth=username:password -l
Iniciar todos los torrents: 
$ transmission-remote -tall --start
Añadir dos torrents: 
$ transmission-remote -a one.torrent two.torrent
Añadir todos los torrents en ~/Desktop: 
$ transmission-remote -a ~/Desktop/*torrent
Obtener información detallada sobre el torrent con ID '1': 
$ transmission-remote -t1 -i
Obtener una lista de los archivos de un torrent: 
$ transmission-remote -t1 -f
Descargar solo sus segundo y cuarto archivos: 
$ transmission-remote -t1 -Gall -g2,4
Establecer la prioridad de los dos primeros archivos de todos los torrents a alta: 
$ transmission-remote -tall -ph1,2
Establecer la prioridad de los archivos de todos los torrents a normal: 
$ transmission-remote -tall -pnall
