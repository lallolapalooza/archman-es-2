NOMBRE

truchet - dibuja patrones de Truchet curvos o angulares

SINOPSIS

truchet [--display host:display.screen] [--foreground color] [--background color] [--window] [--root] [--window-id número][--mono] [--install] [--visual visual] [--delay milisegundos] [--min-width entero] [--min-height entero] [--max-width entero] [--max-height entero] [--max-linewidth entero] [--min-linewidth entero] [--erase] [--no-erase] [--erase-count entero] [--square] [--not-square] [--curves] [--no-curves] [--angle] [--no-angles] [--scroll] [--scroll-overlap entero] [--anim-delay entero] [--anim-step-size entero]

[--fps]

DESCRIPCIÓN

El programa truchet dibuja patrones de Truchet basados en arcos y líneas.

OPCIONES

truchet acepta las siguientes opciones:

--window
Dibuja en una ventana recién creada. Este es el valor predeterminado.
--root
Dibuja en la ventana raíz.
--window-id número
Dibuja en la ventana especificada.
--mono
Si está en una pantalla a color, simula que estamos en una pantalla monocromática.
--install
Instala un mapa de colores privado para la ventana.
--visual visual
Especifica qué visual usar. Los valores legales son el nombre de una clase visual, o el número de ID (decimal o hexadecimal) de un visual específico.
--delay milisegundos
Cuánto esperar entre el dibujo de cada pantalla. El valor predeterminado es 1 segundo.
--min-width entero
El ancho mínimo en píxeles de cada cuadrado. El valor predeterminado es 40.
--min-height entero
La altura mínima en píxeles de cada cuadrado. El valor predeterminado es 40.
--max-width entero
El ancho máximo en píxeles de cada cuadrado. El valor predeterminado es 150.
--max-height entero
La altura máxima en píxeles de cada cuadrado. El valor predeterminado es 150.
--max-linewidth entero
El ancho máximo de las líneas utilizadas para dibujar. El valor predeterminado es 25.
--min-linewidth entero
El ancho mínimo de las líneas utilizadas para dibujar. El valor predeterminado es 2.
--erase
--no-erase
Si borrar la pantalla después de dibujar cada pantalla. El valor predeterminado es True (borrar).
--erase-count entero
El número de pantallas a dibujar antes de borrar. El valor predeterminado es 25.
--square
--not-square
Si forzar que los mosaicos sean cuadrados. El valor predeterminado es True (cuadrado).
--curves
--no-curves
Si dibujar el patrón de Truchet basado en arcos. El valor predeterminado es True (curvas).
--angles
--no-angles
Si dibujar o no el patrón de Truchet basado en líneas. El valor predeterminado es True (ángulos)
--scroll
Usar el modo de desplazamiento. El valor predeterminado es False.
--scroll-overlap
La cantidad de desplazamiento de un lado a otro. El valor predeterminado es 400.
--anim-delay
El tiempo de pausa entre cada paso de animación. El valor predeterminado es 100.
--anim-step-size
La cantidad de pasos a saltar entre cada paso de animación. El valor predeterminado es 3.
--fps
Muestra la velocidad de fotogramas actual y la carga de la CPU.

AMBIENTE

DISPLAY
para obtener el host y el número de pantalla predeterminados.
XENVIRONMENT
para obtener el nombre de un archivo de recursos que anula los recursos globales almacenados en la propiedad RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
El ID de la ventana a usar con --root.
