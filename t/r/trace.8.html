NOMBRE

bounce - Informes de estado de entrega de Postfix

SINOPSIS

bounce [opciones genéricas de demonios de Postfix]

DESCRIPCIÓN


El demonio bounce(8) mantiene archivos de registro por mensaje con información sobre el estado de entrega. Cada archivo de registro se nombra según el archivo de cola al que corresponde y se mantiene en un subdirectorio de cola con el nombre del servicio en el archivo master.cf (ya sea bounce, defer o trace). Este programa espera ser ejecutado desde el gestor de procesos master(8).

El demonio bounce(8) procesa dos tipos de solicitudes de servicio:

  • Añadir un registro de estado de entrega (o no entrega) a un destinatario a un archivo de registro por mensaje.
  • Poner en cola un mensaje de notificación de estado de entrega, con una copia de un archivo de registro por mensaje y del mensaje correspondiente. Cuando el mensaje de notificación de estado de entrega se pone en cola correctamente, el archivo de registro por mensaje se elimina.

El software realiza un esfuerzo máximo de notificación. Se envía una notificación de no entrega incluso cuando el archivo de registro o el mensaje original no se pueden leer.

Opcionalmente, un cliente de rebote (defer, trace) puede solicitar que el archivo de registro por mensaje se elimine cuando la operación solicitada falle. Esto es utilizado por clientes que no pueden reintentar transacciones por sí mismos y que dependen de la lógica de reintento en su propio cliente.

DIAGNÓSTICOS


Los problemas y las transacciones se registran en syslogd(8) o postlogd(8).

PARÁMETROS DE CONFIGURACIÓN

Los cambios en main.cf se detectan automáticamente, ya que los procesos bounce(8) se ejecutan durante un tiempo limitado. Utilice el comando "postfix reload" para acelerar un cambio.

trace - registro de entrega de mensajes de correo electrónico

trace(8)

NOMBRE

trace - registro de entrega de mensajes de correo electrónico

SINOPSIS

trace -d hash
trace -i hash
trace -r hash
trace -s hash
trace -t hash

DESCRIPCIÓN

El comando trace se utiliza para solicitar información del estado de entrega de mensajes de correo electrónico desde el sistema de buzones de correo Postfix. El hash es un identificador hexadecimal para un mensaje específico, normalmente obtenido de un registro de error de entrega o de un registro de seguimiento. El formato del hash depende de la operación solicitada.

Las siguientes operaciones están disponibles:

-d
Solicitar la información de estado de entrega para el mensaje especificado. El hash es el nombre del archivo en el directorio /var/spool/postfix/bounce.
-i
Solicitar la información de estado de entrega para el mensaje especificado. El hash es el nombre del archivo en el directorio /var/spool/postfix/defer.
-r
Solicitar información sobre un mensaje de retorno (bounce). El hash es el nombre del archivo en el directorio /var/spool/postfix/bounce.
-s
Solicitar información del estado del servicio para el mensaje especificado. El hash es el nombre del archivo en el directorio /var/spool/postfix/defer.
-t
Solicitar información de seguimiento del mensaje. El hash es el nombre del archivo en el directorio /var/spool/postfix/trace.

El comando trace consultará los archivos correspondientes en los directorios de buzón de correo de Postfix y mostrará la información encontrada en la salida estándar. Si no se encuentra información, el comando terminará silenciosamente.

ESTÁNDARES

El formato del registro de estado de entrega se basa en la definición de registros de estado de entrega de Postfix, que se pueden encontrar en la documentación de Postfix. El formato del hash está documentado en RFC 8689.

DIAGNÓSTICOS

Los errores de acceso al sistema de archivos o los problemas de permisos pueden causar fallos en la operación. El comando trace registrará los errores relevantes en el registro de sistema de Postfix.

PARÁMETROS DE CONFIGURACIÓN

Los directorios de buzón de correo utilizados por trace están definidos por los parámetros de configuración de Postfix, como bounce_directory, defer_directory y trace_directory. Estos parámetros se pueden ajustar en el archivo de configuración principal de Postfix, main.cf.

ARCHIVOS

/var/spool/postfix/bounce/* registros de no entrega
/var/spool/postfix/defer/* registros de no entrega
/var/spool/postfix/trace/* registros de estado de entrega
