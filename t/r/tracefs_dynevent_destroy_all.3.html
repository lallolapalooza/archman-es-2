LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_dynevent_create, tracefs_dynevent_destroy, tracefs_dynevent_destroy_all, tracefs_dynevent_free, tracefs_dynevent_list_free, tracefs_dynevent_get, tracefs_dynevent_get_all, tracefs_dynevent_info, tracefs_dynevent_get_event - Crear, destruir, liberar y obtener eventos dinámicos.

SINOPSIS

#include <tracefs.h>
struct tracefs_dynevent;
enum tracefs_dynevent_type;
int tracefs_dynevent_create(struct tracefs_dynevent *devent);
int tracefs_dynevent_destroy(struct tracefs_dynevent *devent, bool force);
int tracefs_dynevent_destroy_all(unsigned int types, bool force);
void tracefs_dynevent_free(struct tracefs_dynevent *devent);
void tracefs_dynevent_list_free(struct tracefs_dynevent **events);
struct tracefs_dynevent *tracefs_dynevent_get(enum tracefs_dynevent_type type, const char *system, const char *event);
struct tracefs_dynevent **tracefs_dynevent_get_all(unsigned int types, const char *system);
enum tracefs_dynevent_type tracefs_dynevent_info(struct tracefs_dynevent *dynevent, char **system, char **event, char **prefix, char **addr, char **format);
struct tep_event *tracefs_dynevent_get_event(struct tep_handle *tep, struct tracefs_dynevent *dynevent);

DESCRIPCIÓN

La función tracefs_dynevent_create() crea el evento dinámico devent en el sistema.

La función tracefs_dynevent_destroy() elimina el evento dinámico devent del sistema. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar el evento dinámico. El contexto devent no se libera, use tracefs_dynevent_free() para liberarlo.

La función tracefs_dynevent_destroy_all() elimina todos los eventos dinámicos de los tipos dados del sistema. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de los tipos de eventos dinámicos tracefs_dynevent_type, que se eliminarán. Si types es 0, se eliminarán los eventos dinámicos de todos los tipos. Si force es verdadero, la función intentará deshabilitar todos los eventos en todas las instancias de traza, antes de eliminar los eventos dinámicos.

La función tracefs_dynevent_get() asigna y devuelve una única instancia de un evento dinámico que coincide con el type, system y event dados. Se devuelve NULL si no hay coincidencia. El evento devuelto es lo que se encuentra en el sistema y debe liberarse con tracefs_dynevent_free(). Si system es NULL, se devolverá el primer event de cualquier sistema del tipo dado que tenga el nombre de event.

La función tracefs_dynevent_get_all() asigna y devuelve una matriz de punteros a eventos dinámicos de los tipos dados que existen en el sistema. El último elemento de la matriz es un puntero NULL. La matriz debe liberarse con tracefs_dynevent_list_free(). Si no hay eventos, se devuelve un puntero NULL. El parámetro types es un tipo de evento dinámico específico, o una máscara de bits de los tipos de eventos dinámicos tracefs_dynevent_type, que se recuperarán. Si types es 0, se recuperarán los eventos dinámicos de todos los tipos.

La función tracefs_dynevent_free() libera un contexto de evento dinámico devent.

La función tracefs_dynevent_list_free() libera una matriz de punteros a eventos dinámicos, devuelta por la API tracefs_dynevent_get_all().

La función tracefs_dynevent_info() devuelve el tipo e información de un evento dinámico dado dynevent. Si alguno de los argumentos system, event, prefix, addr o format no son NULL, se asignarán cadenas y se devolverán a través de estos argumentos. El system y event contienen el sistema y el nombre del evento dinámico. Si prefix no es NULL, contendrá una cadena asignada que contiene la parte del prefijo del evento dinámico (el contenido hasta el ":" , excluyéndolo). Si addr no es NULL, contendrá la dirección o la función a la que está adjunto el evento dinámico, si es relevante para este tipo de evento. Si format no es NULL, contendrá la cadena de formato del evento dinámico. Tenga en cuenta que el contenido en group, event, prefix, addr y format deben liberarse con free(3) si se establecen.

La función tracefs_dynevent_get_event() devuelve un evento tep, que describe el evento dinámico dado. La API detecta cualquier evento dinámico recién creado o eliminado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

VALOR DE RETORNO

tracefs_dynevent_create() devuelve 0 en caso de éxito, o -1 en caso de error. Si ocurre un error de análisis, se puede usar tracefs_error_last(3) para recuperar el mensaje de error que explica el problema de análisis.

tracefs_dynevent_destroy() y tracefs_dynevent_destroy_all() devuelven 0 en caso de éxito, o -1 en caso de error. Si force está habilitado, las funciones pueden fallar al deshabilitar los eventos.

La función tracefs_dynevent_get() devuelve un evento dinámico asignado del sistema que coincide con el tipo, sistema y evento dados.

La función tracefs_dynevent_get_all() devuelve una matriz asignada de punteros a eventos dinámicos, o NULL en caso de error o en caso de que no haya eventos en el sistema. Esa matriz debe liberarse con tracefs_dynevent_list_free().

tracefs_dynevent_info() devuelve el tipo del evento dinámico dado o TRACEFS_DYNEVENT_UNKNOWN en caso de error. Si system, event, prefix, addr o format no son NULL, contendrán cadenas asignadas que deben liberarse con free(3).

La función tracefs_dynevent_get_event() devuelve un puntero a un evento tep o NULL en caso de error o si falta el evento dinámico solicitado. El puntero devuelto al evento tep está controlado por @tep y no debe liberarse.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

ENODEV Los eventos dinámicos del tipo solicitado no están configurados para el kernel en ejecución.

ENOMEM Error de asignación de memoria.

tracefs_dynevent_create() puede fallar con los siguientes errores:

EINVAL Lo más probable es que haya ocurrido un error de análisis (use tracefs_error_last(3) para ver posiblemente cuál fue ese error).

También pueden ocurrir otros errores causados por llamadas al sistema internas.

tracefs_dynevent_destroy_all(3) — libtracefs — Arch manual pages

NAME

tracefs_dynevent_destroy_all — Destruye todos los eventos dinámicos de un tipo dado.

SYNOPSIS

#include <tracefs.h>
int tracefs_dynevent_destroy_all(enum tracefs_dynevent_type type, bool flush);

DESCRIPTION

La función tracefs_dynevent_destroy_all() destruye todos los eventos dinámicos registrados en tracefs del tipo especificado por type.

Los tipos de eventos dinámicos son:

  • TRACEFS_DYNEVENT_KPROBE: eventos Kprobe.
  • TRACEFS_DYNEVENT_KRETPROBE: eventos Kretprobe.
  • TRACEFS_DYNEVENT_UPROBE: eventos Uprobe.
  • TRACEFS_DYNEVENT_UPROBE_RET: eventos Uprobe return.
  • TRACEFS_DYNEVENT_RAW: eventos raw (no implementado actualmente).
  • TRACEFS_DYNEVENT_ALL: todos los tipos de eventos dinámicos.

Si el argumento flush es verdadero, la función también intentará limpiar cualquier dato pendiente asociado con los eventos que se están destruyendo.

RETURN VALUE

Devuelve 0 si la operación se realiza correctamente, o un valor negativo en caso de error.

ERRORS

En caso de error, se puede consultar el último mensaje de error con tracefs_error_last(NULL).

EXAMPLE

El siguiente ejemplo muestra cómo destruir todos los Kprobes y Kretprobes:

#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <sched.h>

void mykprobe(int argc, char **argv, int cpu, void *data)
{
        char *file = argv[0];
        int flags = *(int *)argv[1];
        long mode = *(long *)argv[2];

        printf("open: file=%s flags=0x%x mode=0x%lx\n", file, flags, mode);
}

int callback(const char *event, int cpu, int pid, void *data, struct tep_event_triggers *triggers)
{
        if (strcmp(event, "open") == 0) {
                mykprobe(4, (char **)&argv, cpu, NULL);
        } else if (strcmp(event, "openret") == 0) {
                long ret = *(long *)argv[0];
                printf("openret: ret=%ld\n", ret);
        }
        return 0;
}

int run_exec(char **argv, char **env)
{
        pid_t pid;

        pid = fork();
        if (pid == 0) {
                execve(argv[0], argv, env);
                perror("execve failed");
                exit(-1);
        } else if (pid < 0) {
                perror("fork failed");
                exit(-1);
        }
        return pid;
}

int main(int argc, char **argv, char **env)
{
        struct tracefs_instance *instance;
        struct tracefs_dynevent *kprobe, *kretprobe;
        struct tep_handle *tep;
        struct tep_event *open_event, *openret_event;
        struct tep_field *file_field, *ret_field;
        pid_t pid;
        const char *sysnames[] = { "openat", NULL };

        if (argc < 2) {
                fprintf(stderr, "Usage: %s <command> [args...]\n", argv[0]);
                exit(-1);
        }

        instance = tracefs_instance_new(NULL);
        if (!instance) {
                perror("tracefs_instance_new");
                exit(-1);
        }

        /* Destroy any previous dynamic events of kprobe/kretprobe type */
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);

        /* Allocate kprobe and kretprobe */
        kprobe = tracefs_kprobe_alloc(mykprobe, "open", "do_sys_openat2",
                                      "file=+0($arg2):ustring flags=+0($arg3):x64 mode=+8($arg3):x64\n");
        kretprobe = tracefs_kretprobe_alloc(mykprobe, "openret", "do_sys_openat2", "ret=%ax", 0);
        if (!kprobe || !kretprobe) {
                perror("allocating dynamic events");
                exit(-1);
        }

        /* Create the dynamic events */
        if (tracefs_dynevent_create(kprobe) || tracefs_dynevent_create(kretprobe)){
                char *err = tracefs_error_last(NULL);
                perror("Failed to create kprobes:");
                if (err && strlen(err))
                        fprintf(stderr, "%s\n", err);
                exit(-1);
        }

        /* Read events */
        tep = tracefs_local_events_system(NULL, sysnames);
        if (!tep) {
                perror("reading events");
                exit(-1);
        }

        /* Find events and fields */
        open_event = tep_find_event_by_name(tep, mykprobe, "open");
        file_field = tep_find_field(open_event, "file");
        openret_event = tep_find_event_by_name(tep, mykprobe, "openret");
        ret_field = tep_find_field(openret_event, "ret");

        /* Enable the events */
        tracefs_event_enable(instance, mykprobe, NULL);

        /* Run the command */
        pid = run_exec(&argv[1], env);

        /* Let the child start to run */
        sched_yield();

        /* Collect events */
        do {
                tracefs_load_cmdlines(NULL, tep);
                tracefs_iterate_raw_events(tep, instance, NULL, 0, callback, NULL);
        } while (waitpid(pid, NULL, WNOHANG) != pid);

        /* Destroy all dynamic events */
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_KPROBE | TRACEFS_DYNEVENT_KRETPROBE, true);

        /* Free allocated resources */
        tracefs_dynevent_free(kprobe);
        tracefs_dynevent_free(kretprobe);
        tracefs_instance_destroy(instance);
        tep_free(tep);

        return 0;
}
