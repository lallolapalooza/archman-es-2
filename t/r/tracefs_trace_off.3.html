tracefs_trace_off(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_trace_is_on, tracefs_trace_on, tracefs_trace_off, tracefs_trace_on_get_fd, tracefs_trace_on_fd, tracefs_trace_off_fd - Funciones para habilitar o deshabilitar el rastreo.

SINOPSIS

#include <tracefs.h>
int tracefs_trace_is_on(struct tracefs_instance *instance);
int tracefs_trace_on(struct tracefs_instance *instance);
int tracefs_trace_off(struct tracefs_instance *instance);
int tracefs_trace_on_get_fd(struct tracefs_instance *instance);
int tracefs_trace_on_fd(int fd);
int tracefs_trace_off_fd(int fd);

DESCRIPCIÓN

Este conjunto de funciones se puede utilizar para comprobar, habilitar o deshabilitar la escritura en el búfer circular de la instancia de rastreo dada. El rastreo se habilita cuando la escritura en el búfer circular está habilitada.

La función tracefs_trace_is_on() comprueba si el rastreo está habilitado para la instancia dada. Si instance es NULL, se utiliza la instancia superior.

Las funciones tracefs_trace_on() y tracefs_trace_off() establecen el rastreo en la instancia a estado habilitado o deshabilitado. Si instance es NULL, se utiliza la instancia superior.

La función tracefs_trace_on_get_fd() devuelve un descriptor de archivo del archivo "tracing_on" de la instancia dada. Si instance es NULL, se utiliza la instancia de rastreo superior. El descriptor devuelto se puede utilizar para habilitar o deshabilitar rápidamente el rastreo de la instancia.

Las funciones tracefs_trace_on_fd() y tracefs_trace_off_fd() establecen el estado del rastreo a habilitado o deshabilitado utilizando el fd dado. Este descriptor de archivo debe haberse abierto para escritura con tracefs_trace_on_get_fd(3) de la instancia de rastreo deseada. Estas funciones son más rápidas que tracefs_trace_on y tracefs_trace_off.

VALOR DE RETORNO

La función tracefs_trace_is_on() devuelve 0 si el rastreo está deshabilitado, 1 si está habilitado o -1 en caso de error.

La función tracefs_trace_on_get_fd() devuelve un descriptor de archivo del archivo "tracing_on" para lectura y escritura, que debe cerrarse con close(). En caso de error, se devuelve -1.

Las funciones tracefs_trace_on(), tracefs_trace_off(), tracefs_trace_on_fd() y tracefs_trace_off_fd() devuelven -1 en caso de error o 0 en caso contrario.

EJEMPLO

#include <tracefs.h>
        int ret;
        ret = tracefs_trace_is_on(NULL);
        if (ret == 0) {
                /* El rastreo está deshabilitado en la instancia superior */
        } else if (ret == 1) {
                /* El rastreo está habilitado en la instancia superior */
        } else {
                /* Error al obtener el estado del rastreo de la instancia superior */
        }
        ...
        if (!tracefs_trace_on(NULL)) {
            /* Rastreo habilitado en la instancia superior */
            ...
            if (!tracefs_trace_off(NULL)) {
                /* Rastreo deshabilitado en la instancia superior */
            } else {
                /* Error al deshabilitar el rastreo en la instancia superior */
            }
        } else {
                /* Error al habilitar el rastreo en la instancia superior */
        }
        ...
        int fd = tracefs_trace_on_get_fd(NULL);
        if (fd < 0) {
                /* Error al abrir el archivo tracing_on */
        }
        ...
        if (!tracefs_trace_on_fd(fd)) {
            /* Rastreo habilitado en la instancia superior */
            ...
            if (!tracefs_trace_off_fd(fd)) {
                /* Rastreo deshabilitado en la instancia superior */
            } else {
                /* Error al deshabilitar el rastreo en la instancia superior */
            }
        } else {
                /* Error al habilitar el rastreo en la instancia superior */
        }
        ...
        close(fd);
