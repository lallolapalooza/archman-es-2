NOMBRE

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Creación de eventos sintéticos

SINOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos, lo que desencadena un evento sintético. Un evento es el evento de inicio del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, entonces desencadenará el evento sintético. Los valores de los campos distintos de los campos coincidentes pueden pasarse del evento de inicio al evento final para realizar cálculos, o simplemente para pasarlos como parámetro al evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando un proceso se despierta. Luego, establece "sched_switch" como el evento final. Este evento se activa cuando una nueva tarea se planifica en la CPU. Al establecer el "common_pid" de ambos eventos como los campos coincidentes, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Utilice TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o utilice TRACEFS_TIMESTAMP_USECS como campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza en el siguiente ejemplo.

tracefs_synth_create() crea el evento sintético en el sistema. Por defecto, los desencadenadores de histograma se crean en la instancia de traza superior, ya que cualquier evento sintético puede utilizarse globalmente en todas las instancias. En caso de que una aplicación quiera mantener los desencadenadores de histograma fuera de la instancia de nivel superior, puede utilizar tracefs_synth_set_instance() para que los histogramas se utilicen para crear el evento sintético en una instancia distinta de la superior. Un descriptor de evento sintético debe crearse con tracefs_synth_alloc(3) antes de que esto pueda usarse para crearlo en el sistema.

tracefs_synth_destroy() destruye el evento sintético. Intentará detener su ejecución en su instancia (la superior por defecto), pero si se está ejecutando en otra instancia, esto puede fallar por estar ocupado.

tracefs_synth_complete() devuelve verdadero si el evento sintético synth tiene tanto un evento de inicio como uno de finalización.

tracefs_synth_trace() En lugar de hacer solo una traza al coincidir los eventos de inicio y finalización, realiza el manejador type donde TRACEFS_SYNTH_HANDLE_MAX realizará una traza cuando la variable dada var alcance un nuevo máximo para las claves coincidentes. O TRACEFS_SYNTH_HANDLE_CHANGE para cuando la variable var cambie. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si es TRACEFS_SYNTH_HANDLE_CHANGE, entonces se toma una "instantánea" del búfer. La instantánea mueve el búfer de "traza" normal a un búfer de "instantánea", que puede ser accesado a través del archivo "snapshot" en el directorio tracefs de nivel superior, o en una de las instancias. var cambia. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_save() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si es TRACEFS_SYNTH_HANDLE_CHANGE, entonces se guarda la lista dada de save_fields. Los campos se almacenarán en el archivo "hist" del histograma del evento, que puede recuperarse con tracefs_event_file_read(3). var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Establece la instancia de traza, donde se crearán los desencadenadores de histograma que crean el evento sintético. Por defecto, se utiliza la instancia superior. Esta API debe llamarse antes de la llamada a tracefs_synth_create(), para utilizar la nueva instancia al crear el evento. Tenga en cuenta que, incluso si el evento sintético se crea en una instancia, sigue siendo visible para todas las demás instancias, incluida la de nivel superior. Es decir, otras instancias pueden habilitar el evento sintético creado y tenerlo trazado en los búferes que pertenecen a la instancia que lo habilitó.

VALOR DE RETORNO

Todas las funciones devuelven cero en caso de éxito o -1 en caso de error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecutó como usuario root cuando era necesario.

EINVAL Un parámetro no es válido (NULL cuando no debería serlo) o un campo incompatible para cálculos.

ENODEV No se encontró un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y finalización no son compatibles para coincidir o comparar.

ENOMEM No hay suficiente memoria disponible.

Y pueden haber ocurrido más errores en las llamadas del sistema al sistema.

EJEMPLO

Consulte tracefs_sql(3) para un uso más detallado de parte de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento final */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento final */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar la diferencia de tiempo en microsegundos entre el final y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Solo registrar si el campo "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Solo registrar si el campo "next_prio" del evento final es menor que 50
         * o si la prioridad de la tarea anterior no era mayor o igual a 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);

DESCRIPTION

These functions manipulate and create synthetic events. Synthetic events are events that are created dynamically.

tracefs_synth_snapshot creates a synthetic event that will snapshot the trace buffer when the event is triggered.

tracefs_synth_create creates the synthetic event. The synthetic event will be created in the tracefs file system. The synthetic event will be named after the name that was given to the tracefs_synth_alloc call.

tracefs_synth_delete deletes the synthetic event. This will remove the event from the tracefs file system.

tracefs_synth_destroy frees the memory associated with the synthetic event.

tracefs_synth_free frees the memory associated with the synthetic event.

tracefs_synth_add_filter adds a filter to the synthetic event. The filter will be applied when the synthetic event is triggered.

tracefs_synth_append_filter appends a filter to the synthetic event. This is the same as tracefs_synth_add_filter but appends the filter to the end of the filter list.

tracefs_synth_add_match_field adds a field to be matched by the synthetic event.

tracefs_synth_add_compare_field adds a field to be compared by the synthetic event.

tracefs_synth_add_start_field adds a field to be used as the start of a synthetic event.

tracefs_synth_add_end_field adds a field to be used as the end of a synthetic event.

tracefs_synth_append_start_filter appends a filter to the start of the synthetic event.

tracefs_synth_append_end_filter appends a filter to the end of the synthetic event.

tracefs_synth_raw_fmt returns the raw format string for the synthetic event.

tracefs_synth_echo_cmd echoes the command to create the synthetic event to the given trace sequence.

tracefs_synth_get_name returns the name of the synthetic event.

tracefs_synth_get_start_hist returns the histogram associated with the start of the synthetic event.

tracefs_synth_get_end_hist returns the histogram associated with the end of the synthetic event.

tracefs_synth_get_event returns the synthetic event.

tracefs_synth_show_event prints the synthetic event to the given trace sequence.

tracefs_synth_show_start_hist prints the start histogram of the synthetic event to the given trace sequence.

tracefs_synth_show_end_hist prints the end histogram of the synthetic event to the given trace sequence.

RETURN VALUE

On success, tracefs_synth_snapshot, tracefs_synth_create, and tracefs_synth_delete return 0. On failure, they return a negative error code.

tracefs_synth_free, tracefs_synth_destroy, tracefs_synth_add_filter, tracefs_synth_append_filter, tracefs_synth_add_match_field, tracefs_synth_add_compare_field, tracefs_synth_add_start_field, tracefs_synth_add_end_field, tracefs_synth_append_start_filter, tracefs_synth_append_end_filter, tracefs_synth_echo_cmd, tracefs_synth_show_event, tracefs_synth_show_start_hist, and tracefs_synth_show_end_hist return void.

tracefs_synth_raw_fmt returns a pointer to the raw format string.

tracefs_synth_get_name returns the name of the synthetic event.

tracefs_synth_get_start_hist returns a pointer to the start histogram.

tracefs_synth_get_end_hist returns a pointer to the end histogram.

tracefs_synth_get_event returns a pointer to the synthetic event.

EXAMPLE

/* create a synthetic event that will snapshot the trace buffer when
 * next_prio is less than 50, or when prev_prio is greater than or equal to 100.
 */
struct tracefs_synth *synth;
struct trace_seq s;
int ret;
synth = tracefs_synth_snapshot("my_snapshot", "sched_switch");
if (!synth)
        return -1;
tracefs_synth_append_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_COMPARE,
                            "next_prio", TRACEFS_COMPARE_LT, "50");
tracefs_synth_append_filter(synth, TRACEFS_FILTER_CLOSE_PAREN, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
tracefs_synth_append_filter(synth, TRACEFS_FILTER_COMPARE,
                            "prev_prio", TRACEFS_COMPARE_GE, "100");
/*
 * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
 * That's because, when the synth is executed, the remaining close parenthesis
 * will be added. That is, the string will end up being:
 * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
 * or tracefs_sync_echo_cmd() is run.
 */
/* Display how to create the synthetic event */
static void show_event(void)
{
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
