CTREVC

Propósito:

!>
!> CTREVC calcula algunos o todos los vectores propios derechos y/o izquierdos
!> de una matriz T triangular superior compleja.
!> Matrices de este tipo son producidas por la factorización de Schur de
!> una matriz general compleja:  A = Q*T*Q**H, como se calcula por CHSEQR.
!>
!> Los vectores propios derechos x y los vectores propios izquierdos y de T
!> correspondientes a un valor propio w se definen por:
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> donde y**H denota la transpuesta conjugada del vector y.
!> Los valores propios no son una entrada para esta rutina, sino que se
!> leen directamente de la diagonal de T.
!>
!> Esta rutina devuelve las matrices X e/o Y de los vectores propios derechos
!> e izquierdos de T, o los productos Q*X y/o Q*Y, donde Q es una matriz de
!> entrada. Si Q es el factor unitario que reduce una matriz A a la forma
!> de Schur T, entonces Q*X y Q*Y son las matrices de los vectores propios
!> derechos e izquierdos de A.
!>

Parámetros

SIDE 
!>          SIDE es CHARACTER*1
!>          = 'R':  solo calcular vectores propios derechos;
!>          = 'L':  solo calcular vectores propios izquierdos;
!>          = 'B':  calcular ambos vectores propios derechos e izquierdos.
!>

HOWMNY

!>          HOWMNY es CHARACTER*1
!>          = 'A':  calcular todos los vectores propios derechos y/o izquierdos;
!>          = 'B':  calcular todos los vectores propios derechos y/o izquierdos,
!>                  transformados hacia atrás usando las matrices
!>                  suministradas en VR y/o VL;
!>          = 'S':  calcular vectores propios derechos y/o izquierdos
!>                  seleccionados, como se indica en el array lógico SELECT.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          Si HOWMNY = 'S', SELECT especifica los vectores propios a
!>          calcular.
!>          El vector propio correspondiente al j-ésimo valor propio se
!>          calcula si SELECT(j) = .TRUE..
!>          No referenciado si HOWMNY = 'A' o 'B'.
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,N)
!>          La matriz triangular superior T. T se modifica, pero se restaura
!>          al salir.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

VL

!>          VL es un array COMPLEX, de dimensión (LDVL,MM)
!>          En la entrada, si SIDE = 'L' o 'B' y HOWMNY = 'B', VL debe
!>          contener una matriz Q de N*N (normalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por CHSEQR).
!>          En la salida, si SIDE = 'L' o 'B', VL contiene:
!>          si HOWMNY = 'A', la matriz Y de los vectores propios izquierdos de T;
!>          si HOWMNY = 'B', la matriz Q*Y;
!>          si HOWMNY = 'S', los vectores propios izquierdos de T especificados
!>                           por SELECT, almacenados consecutivamente en las
!>                           columnas de VL, en el mismo orden que sus
!>                           valores propios.
!>          No referenciado si SIDE = 'R'.
!>

LDVL

!>          LDVL es INTEGER
!>          La dimensión principal del array VL. LDVL >= 1, y si
!>          SIDE = 'L' o 'B', LDVL >= N.
!>

VR

!>          VR es un array COMPLEX, de dimensión (LDVR,MM)
!>          En la entrada, si SIDE = 'R' o 'B' y HOWMNY = 'B', VR debe
!>          contener una matriz Q de N*N (normalmente la matriz unitaria Q de
!>          vectores de Schur devuelta por CHSEQR).
!>          En la salida, si SIDE = 'R' o 'B', VR contiene:
!>          si HOWMNY = 'A', la matriz X de los vectores propios derechos de T;
!>          si HOWMNY = 'B', la matriz Q*X;
!>          si HOWMNY = 'S', los vectores propios derechos de T especificados
!>                           por SELECT, almacenados consecutivamente en las
!>                           columnas de VR, en el mismo orden que sus
!>                           valores propios.
!>          No referenciado si SIDE = 'L'.
!>

LDVR

!>          LDVR es INTEGER
!>          La dimensión principal del array VR. LDVR >= 1, y si
!>          SIDE = 'R' o 'B'; LDVR >= N.
!>

MM

!>          MM es INTEGER
!>          El número de columnas en los arrays VL y/o VR. MM >= M.
!>

M

!>          M es INTEGER
!>          El número de columnas en los arrays VL y/o VR realmente
!>          utilizadas para almacenar los vectores propios. Si HOWMNY = 'A' o 'B',
!>          M se establece a N. Cada vector propio seleccionado ocupa una
!>          columna.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (2*N)
!>

RWORK

!>          RWORK es un array REAL, de dimensión (N)
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

NAME

dtrevc - computes some or all of the right and/or left eigenvectors of a real upper quasi-triangular matrix T.

SYNOPSIS

SUBROUTINE DTREVC( SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M, WORK, INFO )


      CHARACTER          SIDE, HOWMNY
      LOGICAL            SELECT( * )
      INTEGER            N
      DOUBLE PRECISION   T( LDT, * ), VL( LDVL, * ), VR( LDVR, * ), WORK( * )
      INTEGER            LDT, LDVL, LDVR, MM, M, INFO

SUBROUTINE STREVC( SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M, WORK, INFO )


      CHARACTER          SIDE, HOWMNY
      LOGICAL            SELECT( * )
      INTEGER            N
      REAL               T( LDT, * ), VL( LDVL, * ), VR( LDVR, * ), WORK( * )
      INTEGER            LDT, LDVL, LDVR, MM, M, INFO

DESCRIPTION

The routines **DTREVC** and **STREVC** compute some or all of the right and/or left eigenvectors of a real upper quasi-triangular matrix T.

Matrices of this type are produced by the Schur factorization of a real general matrix: A = Q*T*Q**T, as computed by **DHSEQR** or **SHSEQR**, respectively.

The right eigenvector x and the left eigenvector y of T corresponding to an eigenvalue w are defined by:

   T*x = w*x,     (y**H)*T = w*(y**H)

where y**H denotes the conjugate transpose of y. The eigenvalues are not input to this routine, but are read directly from the diagonal blocks of T.

This routine returns the matrices X and/or Y of right and left eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an input matrix. If Q is the orthogonal factor that reduces a matrix A to Schur form T, then Q*X and Q*Y are the matrices of right and left eigenvectors of A.

Parameters

SIDE

SIDE is CHARACTER*1
  • 'R': compute right eigenvectors only;
  • 'L': compute left eigenvectors only;
  • 'B': compute both right and left eigenvectors.

HOWMNY

HOWMNY is CHARACTER*1
  • 'A': compute all right and/or left eigenvectors;
  • 'B': compute all right and/or left eigenvectors, backtransformed by the matrices in VR and/or VL;
  • 'S': compute selected right and/or left eigenvectors, as indicated by the logical array SELECT.

SELECT

SELECT is LOGICAL array, dimension (N)

If HOWMNY = 'S', SELECT specifies the eigenvectors to be computed. If w(j) is a real eigenvalue, the corresponding real eigenvector is computed if SELECT(j) is .TRUE.. If w(j) and w(j+1) are the real and imaginary parts of a complex eigenvalue, the corresponding complex eigenvector is computed if either SELECT(j) or SELECT(j+1) is .TRUE., and on exit SELECT(j) is set to .TRUE. and SELECT(j+1) is set to .FALSE.. Not referenced if HOWMNY = 'A' or 'B'.

N

N is INTEGER

The order of the matrix T. N >= 0.

T

T is DOUBLE PRECISION (for DTREVC) or REAL (for STREVC) array, dimension (LDT,N)

The upper quasi-triangular matrix T in Schur canonical form.

LDT

LDT is INTEGER

The leading dimension of the array T. LDT >= max(1,N).

VL

VL is DOUBLE PRECISION (for DTREVC) or REAL (for STREVC) array, dimension (LDVL,MM)

On entry, if SIDE = 'L' or 'B' and HOWMNY = 'B', VL must contain an N-by-N matrix Q (usually the orthogonal matrix Q of Schur vectors returned by DHSEQR or SHSEQR). On exit, if SIDE = 'L' or 'B', VL contains:

  • if HOWMNY = 'A', the matrix Y of left eigenvectors of T;
  • if HOWMNY = 'B', the matrix Q*Y;
  • if HOWMNY = 'S', the left eigenvectors of T specified by SELECT, stored consecutively in the columns of VL, in the same order as their eigenvalues.

A complex eigenvector corresponding to a complex eigenvalue is stored in two consecutive columns, the first holding the real part, and the second the imaginary part. Not referenced if SIDE = 'R'.

LDVL

LDVL is INTEGER

The leading dimension of the array VL. LDVL >= 1, and if SIDE = 'L' or 'B', LDVL >= N.

VR

VR is DOUBLE PRECISION (for DTREVC) or REAL (for STREVC) array, dimension (LDVR,MM)

On entry, if SIDE = 'R' or 'B' and HOWMNY = 'B', VR must contain an N-by-N matrix Q (usually the orthogonal matrix Q of Schur vectors returned by DHSEQR or SHSEQR). On exit, if SIDE = 'R' or 'B', VR contains:

  • if HOWMNY = 'A', the matrix X of right eigenvectors of T;
  • if HOWMNY = 'B', the matrix Q*X;
  • if HOWMNY = 'S', the right eigenvectors of T specified by SELECT, stored consecutively in the columns of VR, in the same order as their eigenvalues.

A complex eigenvector corresponding to a complex eigenvalue is stored in two consecutive columns, the first holding the real part and the second the imaginary part. Not referenced if SIDE = 'L'.

LDVR

LDVR is INTEGER

The leading dimension of the array VR. LDVR >= 1, and if SIDE = 'R' or 'B', LDVR >= N.

MM

MM is INTEGER

The number of columns in the arrays VL and/or VR. MM >= M.

M

M is INTEGER

The number of columns in the arrays VL and/or VR actually used to store the eigenvectors. If HOWMNY = 'A' or 'B', M is set to N. Each selected real eigenvector occupies one column and each selected complex eigenvector occupies two columns.

WORK

WORK is DOUBLE PRECISION (for DTREVC) or REAL (for STREVC) array, dimension (3*N)

INFO

INFO is INTEGER
  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value

FURTHER DETAILS

The algorithm used in this program is basically backward (forward)
substitution, with scaling to make the the code robust against
possible overflow.

Each eigenvector is normalized so that the element of largest
magnitude has magnitude 1; here the magnitude of a complex number
(x,y) is taken to be |x| + |y|.
