LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Funciones auxiliares para trabajar con instancias de trazado.

SINOPSIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPCIÓN

Funciones auxiliares para trabajar con instancias de trazado.

La función tracefs_instance_get_name() devuelve el nombre de la instancia dada. Tenga en cuenta que la instancia superior no tiene nombre, la función devuelve NULL para ella.

La función tracefs_instance_get_trace_dir() devuelve el directorio de trazado donde está configurada la instancia dada.

La función tracefs_instances_walk() recorre todas las instancias de trazado configuradas en el sistema y llama a callback para cada una de ellas. El argumento context se pasa a la callback, junto con el nombre de la instancia. Si la callback devuelve un valor distinto de cero, la iteración se detiene. Tenga en cuenta que la callback no se llama para la instancia superior.

La función tracefs_instance_exists() comprueba si existe una instancia con el nombre dado en el sistema.

La función tracefs_instace_get_buffer_size() devuelve el tamaño del búfer de anillo. Si cpu es negativo, devuelve el tamaño total de todos los búferes de anillo por CPU; de lo contrario, devuelve el tamaño del búfer de anillo por CPU para cpu.

La función tracefs_instance_set_buffer_size() establece el tamaño del búfer de anillo. Si cpu es negativo, establece todos los búferes de anillo por CPU a size (tenga en cuenta que el tamaño total es el número de CPUs * size). Si se especifica cpu, solo establece el tamaño del búfer de anillo por CPU.

La función tracefs_instance_set_buffer_percent() establece el valor de porcentaje del búfer del anillo de trazado para instance o el búfer de nivel superior si instance es NULL. El porcentaje del búfer decide cuándo los lectores en tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) y tracefs_cpu_pipe(3) se bloquearán cuando O_NONBLOCK no esté configurado. El valor de val debe estar entre 0 y 100, donde:

  0   - bloquear hasta que haya datos en el búfer de anillo
  1   - bloquear hasta que se llenen el 1% de los sub-búferes del búfer de anillo
  50  - bloquear hasta que se llenen el 50% de los sub-búferes del búfer de anillo
  100 - bloquear hasta que se llene todo el búfer de anillo

Tenga en cuenta que se puede utilizar cualquier número de 0 a 100, donde es el porcentaje del búfer de anillo que debe llenarse antes de que un lector bloqueado sea notificado de que hay datos para recuperar.

La función tracefs_instance_get_buffer_percent() recupera la configuración actual del porcentaje del búfer del anillo de trazado para instance o el búfer de nivel superior si instance es NULL.

VALOR DE RETORNO

La función tracefs_instance_get_name() devuelve una cadena o NULL en caso de la instancia superior. La cadena devuelta no debe liberarse.

La función tracefs_instance_get_trace_dir() devuelve una cadena o NULL en caso de error. La cadena devuelta no debe liberarse.

La función tracefs_instances_walk() devuelve 0, si se iteraron todas las instancias, 1 si la iteración fue detenida por la callback, o -1 en caso de error.

La función tracefs_instance_exists() devuelve true si una instancia con el nombre dado existe en el sistema o false en caso contrario.

La función tracefs_instance_get_buffer_size() devuelve el tamaño del búfer de anillo dependiendo del valor cpu pasado, o -1 en caso de error.

La función tracefs_instance_set_buffer_size() devuelve cero en caso de éxito y -1 en caso de error.

NAME

tracefs_instance_set_buffer_size - Set the buffer size for a tracefs instance.

SYNOPSIS

#include <tracefs.h> int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size);

DESCRIPTION

The tracefs_instance_set_buffer_size function sets the size of the buffer for the given tracefs instance.

The instance is a pointer to a struct tracefs_instance that was previously opened with tracefs_open or tracefs_instance_open.

The size is the desired buffer size in bytes. If size is 0, the default buffer size will be used.

RETURN VALUE

On success, 0 is returned. On error, a negative value is returned and errno is set to indicate the error.

EXAMPLE


            struct tracefs_instance *instance;
            int ret;

            instance = tracefs_open(NULL);
            if (!instance) {
                perror("tracefs_open");
                return 1;
            }

            ret = tracefs_instance_set_buffer_size(instance, 1024 * 1024); // 1MB buffer
            if (ret < 0) {
                perror("tracefs_instance_set_buffer_size");
                tracefs_close(instance);
                return 1;
            }

            tracefs_close(instance);
