TRANSMISSION-GTK(1) Manual de Comandos Generales TRANSMISSION-GTK(1)

NOMBRE

transmission-gtk — un cliente de bittorrent

SINOPSIS

transmission-gtk -?

transmission-gtk [-pqm] [archivo-torrent ...]

DESCRIPCIÓN

transmission-gtk es un cliente BitTorrent rápido y fácil.

BitTorrent es un protocolo de transferencia de archivos peer-to-peer que utiliza un archivo de metadatos (normalmente con extensión .torrent) y un rastreador central para distribuir datos de archivos entre un grupo de peers. Para más información sobre el protocolo BitTorrent, consulta http://www.bittorrent.org/

OPCIONES

-? --help
Mostrar opciones de ayuda
-p --paused
Iniciar con todos los torrents en pausa
-m --minimized
Iniciar minimizado en el área de notificación
-g --config-dir directorio
Dónde buscar los archivos de configuración. Esto se puede usar para alternar entre el uso de los clientes cli, daemon, gtk y qt. Consulta https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md para más información.

Se pueden añadir múltiples archivos .torrent al inicio añadiéndolos en la línea de comandos. Si transmission-gtk ya se está ejecutando, los torrents se añadirán a la instancia en ejecución.

AMBIENTE

TRANSMISSION_HOME
Establece el directorio de configuración predeterminado.
http_proxy
libcurl usa esta variable de entorno al realizar anuncios de rastreo. Si se establece, anula las preferencias de proxy de GNOME.

ARCHIVOS

~/.config/transmission
El directorio de configuración utilizado cuando no se especifica [TRANSMISSION_HOME] ni [-g].
