tracefs_follow_missed_events_clear(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_iterate_raw_events, tracefs_iterate_stop, tracefs_follow_event, tracefs_follow_missed_events, tracefs_follow_event_clear, tracefs_follow_missed_events_clear, tracefs_iterate_snapshot_events - Iterar sobre eventos en el búfer circular

SINOPSIS

#include <tracefs.h>
int tracefs_iterate_raw_events(struct tep_handle *tep, struct tracefs_instance *instance,
                                 cpu_set_t *cpus, int cpu_size,
                                 int (*callback)(struct tep_event *, struct tep_record *, int, void *),
                                 void *callback_context);
void tracefs_iterate_stop(struct tracefs_instance *instance);
int tracefs_follow_event(struct tep_handle *tep, struct tracefs_instance *instance,
                          const char *system, const char *event_name,
                          int (*callback)(struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracefs_follow_missed_events(struct tracefs_instance *instance,
                          int (*callback)(struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracefs_follow_event_clear(struct tracefs_instance *instance,
                          const char *system, const char *event_name);
int tracefs_follow_missed_events_clear(struct tracefs_instance *instance);
int tracefs_iterate_snapshot_events(struct tep_handle *tep, struct tracefs_instance *instance,
                                 cpu_set_t *cpus, int cpu_size,
                                 int (*callback)(struct tep_event *, struct tep_record *, int, void *),
                                 void *callback_context);

DESCRIPCIÓN

Iterador de Tracefs sobre eventos crudos.

La función tracefs_iterate_raw_events() leerá los búferes de datos crudos de tracefs y llamará a la función callback especificada para cada evento que encuentre. Los eventos se iteran en orden ordenado: el más antiguo primero. Se requiere un manejador tep inicializado (Ver tracefs_local_events(3)). Si instance es NULL, se utilizará el búfer tracefs de nivel superior, de lo contrario, se leerá el búfer para la instance correspondiente. Para filtrar solo en un subconjunto de CPUs, cpus y cpu_size pueden establecerse para llamar a callback solo con eventos que ocurrieron en las CPUs especificadas; de lo contrario, si cpus es NULL, la función callback se llamará para todos los eventos y cpu_size se ignora. La función callback se llamará con los siguientes parámetros: un puntero a un struct tep_event que corresponde al tipo de evento del registro; el registro que representa el evento; la CPU en la que ocurrió el evento; y un puntero al callback_context especificado por el usuario. Si el callback devuelve un valor distinto de cero, la iteración se detiene.

La función tracefs_iterate_snapshot_events() funciona igual que tracefs_iterate_raw_events() excepto que opera sobre el búfer de instantánea.

Utilice tracefs_iterate_stop() para forzar la detención de una ejecución de tracefs_iterate_raw_events(). Esto se puede llamar desde un callback que es llamado por el iterador (aunque devolver un valor distinto de cero lo detendrá), o desde otro hilo.

La función tracefs_follow_event() se utiliza con tracefs_iterate_raw_events(), pero en lugar de que el callback se llame para cada evento, solo se llama para el system / event_name especificado en la función. El callback es el mismo que para tracefs_iterate_raw_events(), y el callback_context pasado se pasará también al callback. Tenga en cuenta que si devuelve algo distinto de 0, detendrá el bucle antes de que se llame al callback de tracefs_iterate_raw_events().

La función tracefs_follow_missed_events() llamará al callback cuando se detecten eventos omitidos. Establecerá el parámetro record del callback al registro que vino después de los eventos omitidos y event será del tipo de evento que es el record. cpu se establecerá en la CPU que omitió los eventos, y callback_data será el contenido que se pasó a la función.

La función tracefs_follow_event_clear() eliminará seguidores de instance que coincidan con system y event_name. Si system y event_name son ambos NULL, eliminará todos los seguidores de eventos asociados a instance. Si solo system es NULL, eliminará todos los seguidores que siguen eventos que coinciden con event_name. Si solo event_name es NULL, eliminará todos los seguidores que están adjuntos a eventos que forman parte de un sistema que coincide con system.

La función tracefs_follow_missed_events_clear() eliminará todos los seguidores de eventos omitidos.

VALOR DE RETORNO

La función tracefs_iterate_raw_events() devuelve -1 en caso de error o 0 en caso contrario.

Tanto tracefs_follow_event_clear() como tracefs_follow_missed_events_clear() devuelven 0 en caso de éxito y -1 en caso de error, o si no encontró seguidores que coincidieran y debieran ser eliminados.

EJEMPLO

#include <unistd.h>
#include <tracefs.h>
#include <stdbool.h>
#include <signal.h>
struct my_struct {
        bool            stopped;
};
#define MAX_COUNT 500000
static int counter;
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct my_struct *my_data = data;
        static struct trace_seq seq;
        if (counter++ > MAX_COUNT) {
                my_data->stopped = true;
                return 1;
        }
        if (!seq.buffer)
                trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%16s-%-5d [%03d] %6.1000d %s: %s\n",
                        TEP_PRINT_COMM, TEP_PRINT_PID, TEP_PRINT_CPU,
                        TEP_PRINT_TIME, TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        trace_seq_reset(&seq);
        return 0;
}
static int sched_callback(struct tep_event *event, struct tep_record *record,
                          int cpu, void *data)
{
        static struct tep_format_field *prev_pid;
        static struct tep_format_field *next_pid;
        unsigned long long pid;
        int this_pid = *(int *)data;
        if (!prev_pid) {
                prev_pid = tep_find_field(event, "prev_pid");
                next_pid = tep_find_field(event, "next_pid");
                if (!prev_pid || !next_pid) {
                        fprintf(stderr, "No pid fields??\n");
                        return -1;
                }
        }
        tep_read_number_field(prev_pid, record->data, &pid);
        if (pid == this_pid)
                printf("WE ARE LEAVING!\n");
        tep_read_number_field(next_pid, record->data, &pid);
        if (pid == this_pid)
                printf("WE ARE ARRIVING!\n");
        return 0;
}
static int missed_callback(struct tep_event *event, struct tep_record *record,
                           int cpu, void *data)
{
        printf("OOPS! cpu %d dropped ", cpu);
        if (record->missed_events > 0)
                printf("%lld ", record->missed_events);
        printf("events\n");
        return 0;
}
static struct tracefs_instance *instance;
static struct my_struct my_data;
static void sig(int s)
{
        tracefs_iterate_stop(instance);
        my_data.stopped = true;
}
int main (int argc, char **argv, char **env)
{
        struct tep_handle *tep;
        int this_pid = getpid();
        instance = tracefs_instance_create("my-buffer");
        if (!instance)
                return -1;
        signal(SIGINT, sig);
        tracefs_event_enable(instance, NULL, NULL);
        sleep(1);
        tracefs_event_disable(instance, NULL, NULL);
        tep = tracefs_local_events(NULL);
        tep_load_plugins(tep);
        tracefs_follow_missed_events(instance, missed_callback, NULL);
        tracefs_follow_event(tep, instance, "sched", "sched_switch", sched_callback, &this_pid);
        tracefs_iterate_raw_events(tep, instance, NULL, 0, callback, &my_data);
        /* Note, the clear here is to show how to clear all followers
         * in case tracefs_iterate_raw_events() is called again, but
         * does not want to include */
        tracefs_follow_event_clear(instance, "sched", "sched_switch");
        tracefs_follow_missed_events_clear(instance);
        return 0;
}

#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/time.h>
#include <tracefs.h>

#define MAX_COUNT 100000

struct my_data {
        int stopped;
};

struct my_data my_data = { .stopped = 0 };

static void sig_handler(int sig)
{
        my_data.stopped = 1;
}

int main(int argc, char **argv)
{
        struct tracefs_instance *instance;
        struct tracefs_event_ops ops;
        unsigned long long counter = 0;
        int ret;

        signal(SIGINT, sig_handler);
        signal(SIGTERM, sig_handler);

        instance = tracefs_instance_open(NULL);
        if (!instance) {
                fprintf(stderr, "Failed to open tracefs instance\n");
                return -1;
        }

        /*
         * We are only interested in sched:sched_switch events.
         *
         * For other events, the tracefs_event_func() will be called.
         * For the sched:sched_switch event, the tracefs_sched_switch_func()
         * will be called.
         */
        memset(&ops, 0, sizeof(ops));
        ops.sched_switch = tracefs_sched_switch_func;
        ops.event = tracefs_event_func;

        /*
         * Set the callback for the sched:sched_switch event.
         * This will also enable the event for tracing.
         */
        ret = tracefs_set_event_callback(instance, "sched", "sched_switch",
                                         &ops, NULL);
        if (ret < 0) {
                fprintf(stderr, "Failed to set sched_switch callback: %d\n", ret);
                tracefs_instance_destroy(instance);
                tracefs_instance_free(instance);
                return -1;
        }

        /* Enable tracing */
        ret = tracefs_start(instance);
        if (ret < 0) {
                fprintf(stderr, "Failed to start tracing: %d\n", ret);
                tracefs_instance_destroy(instance);
                tracefs_instance_free(instance);
                return -1;
        }

        printf("Tracing sched_switch events. Press Ctrl+C to stop...\n");

        /*
         * Loop until stopped by signal or max count is reached.
         * tracefs_poll() will block until an event occurs or a timeout.
         * Here we don't use a timeout, so it will block indefinitely.
         */
        while (!my_data.stopped && counter < MAX_COUNT) {
                ret = tracefs_poll(instance, -1); /* Block indefinitely */
                if (ret < 0) {
                        fprintf(stderr, "tracefs_poll failed: %d\n", ret);
                        break;
                }
                /*
                 * The callbacks are called within tracefs_poll().
                 * We just need to count how many times tracefs_poll() returns.
                 * This is a simple way to count events. A more accurate way
                 * would be to increment a counter within the callback itself.
                 */
                counter++;
        }

        /* Stop tracing */
        tracefs_stop(instance);

        /*
         * Clean up all the followers. It's not needed
         * here because tracefs_instance_free() will clean them up.
         */
        tracefs_follow_event_clear(instance, NULL, NULL);
        tracefs_follow_missed_events_clear(instance);
        tracefs_instance_destroy(instance);
        tracefs_instance_free(instance);
        if (my_data.stopped) {
                if (counter > MAX_COUNT)
                        printf("Finished max count\n");
                else
                        printf("Finished via signal\n");
        }
        return 0;
}
