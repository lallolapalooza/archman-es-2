TRACE-CMD(1) Manual de libtracefs TRACE-CMD(1)

NOMBRE

trace-cmd - interactúa con el trazador interno del kernel de Linux Ftrace

SINOPSIS

trace-cmd COMANDO [OPCIONES]

DESCRIPCIÓN

El comando trace-cmd(1) interactúa con el trazador Ftrace que está integrado en el kernel de Linux. Se interconecta con los archivos específicos de Ftrace que se encuentran en el sistema de archivos debugfs, en el directorio de trazado (tracing). Se debe especificar un COMANDO para indicar a trace-cmd qué hacer.

COMANDOS

record  - graba un trazado en vivo y escribe un archivo trace.dat en el
          disco local o en la red.
set     - establece un parámetro de configuración de ftrace.
report  - lee un archivo trace.dat y convierte los datos binarios a un
          formato legible de texto ASCII.
stream  - Inicia el trazado y lee la salida directamente
profile - Inicia la generación de perfiles y lee la salida directamente
hist    - muestra un histograma de los eventos.
stat    - muestra el estado del trazado (ftrace) del sistema en ejecución
options - lista las opciones de plugin disponibles para *report*
start   - inicia el trazado sin grabar en un archivo trace.dat.
stop    - detiene el trazado (solo deshabilita la grabación, la sobrecarga del
          trazador todavía está en efecto)
restart - reinicia el trazado desde una parada anterior (solo afecta a la grabación)
extract - extrae los datos del búfer del kernel y crea un archivo trace.dat.
show    - muestra el contenido de uno de los archivos de trazado del kernel de Linux de Ftrace
reset   - deshabilita todo el trazado y restaura el rendimiento del sistema.
          (borra todos los datos de los búferes del kernel)
clear   - borra el contenido de los búferes de anillo de Ftrace.
split   - divide un archivo trace.dat en archivos más pequeños.
list    - lista los plugins o eventos disponibles que se pueden grabar.
listen  - abre un puerto para escuchar conexiones de trazado remotas.
agent   - escucha en un vsocket para clientes de trazado
setup-guest - crea FIFOs para trazar máquinas virtuales invitadas (guest)
restore - restaura los archivos de datos de una ejecución fallida de trace-cmd record
snapshot- toma una instantánea del trazado en curso
stack   - ejecuta y muestra el trazador de pila (stack tracer)
check-events - analiza cadenas de formato para todos los eventos de trazado y devuelve
               si todos los formatos son analizables
convert   - convierte archivos de trazado
attach   - adjunta un archivo trace.dat del host a un archivo trace.dat del invitado
dump    - lee los metadatos de un archivo de trazado

OPCIONES

-h, --help

Muestra el texto de ayuda.

Otras opciones, consulte la página del manual del comando correspondiente.
