DESCRIPCIÓN

Los histogramas de eventos se crean mediante el archivo trigger en el directorio del evento. La sintaxis puede ser compleja y difícil de obtener correctamente. Esta API maneja la sintaxis y facilita la creación e interacción con los histogramas de eventos. Consulte https://www.kernel.org/doc/html/latest/trace/histogram.html para más información.

tracefs_hist_add_sort_key() agregará una clave para ordenar. El hist es el descriptor del histograma al que se agregará la clave de ordenación. La sort_key es una cadena que debe coincidir con una clave ya definida del histograma o con un valor ya definido. Si hist ya tiene claves de ordenación (agregadas previamente), la nueva sort_key tendrá menor prioridad (será secundaria, etc.) al ordenar.

tracefs_hist_set_sort_key() restablecerá la lista de claves para ordenar. El hist es el descriptor del histograma al que se restablecerá la clave de ordenación. La sort_key es una cadena que debe coincidir con una clave ya definida del histograma o con un valor ya definido. Se pueden agregar múltiples claves de ordenación para denotar un orden de clasificación secundario, etc., pero todas las claves de ordenación deben coincidir con una clave o valor existente, o ser TRACEFS_HIST_HITCOUNT. El último parámetro de tracefs_hist_add_sort_key() debe ser NULL.

tracefs_hist_sort_key_direction() permite cambiar la dirección de una clave de ordenación existente de hist. La sort_key es la clave de ordenación a cambiar, y dir puede ser TRACEFS_HIST_SORT_ASCENDING o TRACEFS_HIST_SORT_DESCENDING, para que la dirección de la clave de ordenación sea ascendente o descendente respectivamente.

tracefs_hist_add_name() agrega un nombre a un histograma. Un histograma puede tener un nombre y si el nombre coincide entre más de un evento y tienen claves compatibles, los múltiples histogramas con el mismo nombre se fusionarán en un solo histograma (mostrado por el archivo hist de cualquiera de los eventos). El hist es el histograma que se nombrará, y el name es el nombre que se le dará.

tracefs_hist_append_filter() crea un filtro o se le agrega a uno para el evento del histograma. Dependiendo de type, construirá una cadena de tokens para paréntesis o declaraciones lógicas, o puede agregar una comparación de field a val basada en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Agrega "&&" al filtro TRACEFS_FILTER_OR - Agrega "||" al filtro TRACEFS_FILTER_NOT - Agrega "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Agrega "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Agrega ")" al filtro

field, compare, y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces compare se usará para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de banderas (flags).

trace_hist_echo_cmd() imprime los comandos necesarios para crear el histograma dado en la instance dada, o NULL para el nivel superior, en el seq. El comando que se imprime está descrito por command y muestra la funcionalidad que realizaría tracefs_hist_command(3).

tracefs_hist_command() se llama para procesar un comando en el histograma hist para su evento en la instance dada, o NULL para el nivel superior. El cmd puede ser uno de:

TRACEFS_HIST_CMD_START o cero para iniciar la ejecución del histograma.

TRACEFS_HIST_CMD_PAUSE para pausar el histograma dado.

TRACEFS_HIST_CMD_CONT para continuar un histograma pausado.

TRACEFS_HIST_CMD_CLEAR para restablecer los valores de un histograma.

TRACEFS_HIST_CMD_DESTROY para destruir el histograma (deshacer un START).

Las siguientes funciones son envoltorios (wrappers) de tracefs_hist_command() para hacer las convenciones de llamada un poco más fáciles de entender lo que está sucediendo.

TIPOS DE CLAVE

tracefs_hist_alloc_nd() y tracefs_hist_add_key() ambos agregan una clave y requieren que esa clave tenga un tipo. Los tipos pueden ser:

TRACEFS_HIST_KEY_NORMAL o cero (0) que es no modificar el tipo.

TRACEFS_HIST_KEY_HEX para mostrar la clave en formato hexadecimal.

TRACEFS_HIST_KEY_SYM para mostrar la clave como un símbolo del kernel (si se encuentra). Si la clave es una dirección, esto es útil ya que mostrará los nombres de las funciones en lugar de solo un número.

TRACEFS_HIST_KEY_SYM_OFFSET similar a TRACEFS_HIST_KEY_SYM pero también incluirá el desplazamiento de la función para que coincida con la dirección exacta.

TRACEFS_HIST_KEY_SYSCALL Si la clave es un "id" de llamada al sistema (el número que se pasa desde el espacio de usuario al kernel para indicarle qué llamada al sistema está realizando), se mostrará el nombre de la llamada al sistema.

TRACEFS_HIST_KEY_EXECNAME Si la clave es "common_pid" (el pid de la tarea en ejecución), en lugar de mostrar el número, se mostrará el nombre de la tarea en ejecución.

TRACEFS_HIST_KEY_LOG mostrará la clave en una escala logarítmica binaria.

TRACEFS_HIST_KEY_USECS para usar con "common_timestamp" o TRACEFS_HIST_TIMESTAMP, en cuyo caso mostrará la marca de tiempo en microsegundos en lugar de nanosegundos.

VALOR DE RETORNO

tracefs_hist_get_name() devuelve el nombre del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto histograma y se libera junto con el histograma mediante tracefs_hist_free().

tracefs_hist_get_event() devuelve el nombre del evento del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto histograma y se libera junto con el histograma mediante tracefs_hist_free().

tracefs_hist_get_system() devuelve el nombre del sistema del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto histograma y se libera junto con el histograma mediante tracefs_hist_free().

tracefs_hist_alloc_nd() devuelve un descriptor de histograma asignado que debe liberarse con tracefs_hist_free() o NULL en caso de error.

DESCRIPCIÓN

Las funciones de histograma de trazas le permiten crear y manipular histogramas de trazas. Un histograma de trazas agrupa eventos de trazas en cubos basados en los valores de uno o más campos de eventos.

La función tracefs_hist_create reserva una estructura de histograma de trazas y la vincula a un manejador de eventos de trazas tep. El evento de traza que se va a histogramar se identifica mediante el sistema system y el nombre del evento event. El campo que se va a utilizar para la creación de cubos se especifica mediante el nombre de campo key y su tipo type.

Las funciones tracefs_hist_alloc, tracefs_hist_alloc_2d y tracefs_hist_alloc_nd son similares a tracefs_hist_create, pero permiten la creación de histogramas unidimensionales, bidimensionales y multidimensionales, respectivamente. La función tracefs_hist_alloc_nd toma una matriz de estructuras tracefs_hist_axis para especificar las dimensiones y los tipos de los cubos.

La función tracefs_hist_add_value añade un valor a un cubo del histograma. La función tracefs_hist_add_sort_key añade una clave de ordenación al histograma. La función tracefs_hist_sort_key_direction especifica la dirección de ordenación (ascendente o descendente) para una clave de ordenación determinada.

Las funciones tracefs_hist_start, tracefs_hist_pause, tracefs_hist_continue, tracefs_hist_reset y tracefs_hist_destroy se utilizan para controlar el ciclo de vida del histograma. La función tracefs_hist_start inicia la recopilación de datos para el histograma. La función tracefs_hist_pause pausa la recopilación de datos. La función tracefs_hist_continue reanuda la recopilación de datos. La función tracefs_hist_reset restablece el histograma. La función tracefs_hist_destroy libera los recursos asociados con el histograma.

Las funciones tracefs_hist_event_name, tracefs_hist_get_event y tracefs_hist_get_system devuelven cadenas de caracteres propiedad del objeto histograma.

Todas las demás funciones devuelven cero si la operación se realiza correctamente o -1 en caso de error.

EJEMPLO

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Failed to allocate axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else {
                                fprintf(stderr, "Undefined attribute '%s'\n", att);
                                fprintf(stderr,"  Acceptable attributes:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Failed instance create\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Could not read events");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Reading hist file");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "Command needs -k option\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "No keys??\n");
                exit(-1);
        }
        /* Show examples of hist1d and hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Really, 1 and 2 could use this too */
                hist = tracefs_hist_alloc_nd(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Failed hist create\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add value %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add sort key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add ascending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add descending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* Show was already done */
                break;
        }
        if (ret)
                fprintf(stderr, "Failed: command\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Unknown command %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}
