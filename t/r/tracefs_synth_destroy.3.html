LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Creación de eventos sintéticos

SINOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPCIÓN

Los eventos sintéticos son eventos dinámicos que se crean al hacer coincidir dos eventos que desencadenan un evento sintético. Un evento es el evento de inicio, del cual se registra un campo, y cuando se ejecuta el segundo evento, si tiene un campo (o campos) que coincide con el campo (o campos) del evento de inicio, se desencadenará el evento sintético. Los valores de los campos distintos de los campos coincidentes pueden pasarse del evento de inicio al evento final para realizar cálculos o simplemente como parámetro para el evento sintético.

Un caso de uso común es establecer "sched_waking" como el evento de inicio. Este evento se activa cuando se despierta un proceso. Luego, se establece "sched_switch" como el evento final. Este evento se activa cuando se programa una nueva tarea en la CPU. Al establecer el "common_pid" de ambos eventos como los campos de coincidencia, el tiempo entre los dos eventos se considera la latencia de despertar de ese proceso. Use TRACEFS_TIMESTAMP como campo para ambos eventos para calcular la diferencia en nanosegundos, o use TRACEFS_TIMESTAMP_USECS como los campos de comparación para ambos eventos para calcular la diferencia en microsegundos. Esto se utiliza como ejemplo a continuación.

tracefs_synth_create() crea el evento sintético en el sistema. Por defecto, los desencadenadores de histograma se crean en la instancia de traza superior, ya que cualquier evento sintético puede usarse globalmente en todas las instancias. En caso de que una aplicación quiera mantener los desencadenadores de histograma fuera de la instancia de nivel superior, puede usar tracefs_synth_set_instance() para que los histogramas se utilicen para crear el evento sintético en una instancia distinta de la superior. Un descriptor de evento sintético debe crearse con tracefs_synth_alloc(3) antes de que pueda usarse para crearlo en el sistema.

tracefs_synth_destroy() destruye el evento sintético. Intentará detener su ejecución en su instancia (la superior por defecto), pero si se está ejecutando en otra instancia, esto puede fallar si está ocupado.

tracefs_synth_complete() devuelve verdadero si el evento sintético synth tiene un evento de inicio y uno final.

tracefs_synth_trace() En lugar de realizar solo una traza al coincidir los eventos de inicio y fin, realiza el manejador type donde TRACEFS_SYNTH_HANDLE_MAX realizará una traza cuando la variable dada var alcance un nuevo máximo para las claves coincidentes. O TRACEFS_SYNTH_HANDLE_CHANGE para cuando la variable var cambie. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si es TRACEFS_SYNTH_HANDLE_CHANGE, entonces se toma una "instantánea" del búfer. La instantánea mueve el búfer de "traza" normal a un búfer de "instantánea", al que se puede acceder a través del archivo "snapshot" en el directorio tracefs de nivel superior, o en una de las instancias. var cambia. var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_save() Cuando la variable dada var es un nuevo máximo si handler es TRACEFS_SYNTH_HANDLE_MAX o simplemente ha cambiado si es TRACEFS_SYNTH_HANDLE_CHANGE, entonces se guarda la lista dada de save_fields. Los campos se almacenarán en el archivo "hist" del histograma del evento, que se puede recuperar con tracefs_event_file_read(3). var debe ser uno de los elementos name utilizados en tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Establece la instancia de traza, donde se crearán los desencadenadores de histograma que crean el evento sintético. Por defecto, se utiliza la instancia superior. Esta API debe llamarse antes de la llamada a tracefs_synth_create(), para poder utilizar la nueva instancia al crear el evento. Tenga en cuenta que, incluso si el evento sintético se crea en una instancia, sigue siendo visible para todas las demás instancias, incluida la superior. Es decir, otras instancias pueden habilitar el evento sintético creado y hacer que se trace en los búferes que pertenecen a la instancia que lo habilitó.

VALOR DE RETORNO

Todas las funciones devuelven cero en caso de éxito o -1 en caso de error.

ERRORES

Los siguientes errores se aplican a todas las llamadas anteriores:

EPERM No se ejecutó como usuario root cuando era necesario.

EINVAL Ya sea un parámetro no es válido (NULL cuando no debería serlo) o un campo que no es compatible para cálculos.

ENODEV No se encontró un evento o uno de sus campos.

EBADE Los campos de los eventos de inicio y fin no son compatibles para coincidencia o comparación.

ENOMEM no hay suficiente memoria disponible.

Y pueden haber ocurrido más errores de las llamadas del sistema al sistema.

EJEMPLO

Consulte tracefs_sql(3) para un uso más detallado de parte de este código.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Cargar todos los eventos del sistema */
        tep = tracefs_local_events(NULL);
        /* Inicializar el evento sintético */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* El tep ya no es necesario */
        tep_free(tep);
        /* Guardar el campo "prio" como "prio" del evento de inicio */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Guardar el campo "next_comm" como "comm" del evento final */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Guardar el campo "prev_prio" como "prev_prio" del evento final */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Tomar una diferencia de tiempo en microsegundos entre el final y el inicio
         * y registrarla como "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Solo registrar si el campo "prio" del evento de inicio es menor que 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Solo registrar si el campo "next_prio" del evento final es menor que 50
         * o si el prio de la tarea anterior no era mayor o igual que 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);

DESCRIPCIÓN

Estas funciones se utilizan para crear un evento sintético que se puede invocar posteriormente para añadir un evento a un búfer de traza. Un evento sintético puede ser una traza de un evento existente o una traza de un evento personalizado.

Las funciones tracefs_synth_alloc y tracefs_synth_free se utilizan para asignar y liberar la memoria del objeto sintético.

La función tracefs_synth_add_match_field se utiliza para añadir un campo que se utilizará para emparejar eventos. Cuando un evento coincide con el campo especificado, se invoca el evento sintético.

La función tracefs_synth_add_compare_field se utiliza para añadir un campo que se utilizará para comparar eventos. Cuando un evento satisface la condición de comparación especificada, se invoca el evento sintético.

La función tracefs_synth_add_start_field se utiliza para añadir un campo que se utilizará para iniciar el evento sintético. El evento sintético se invoca cuando el campo especificado se encuentra.

La función tracefs_synth_add_end_field se utiliza para añadir un campo que se utilizará para finalizar el evento sintético. El evento sintético se invoca cuando el campo especificado se encuentra.

La función tracefs_synth_append_start_filter se utiliza para añadir un filtro al evento sintético. El filtro se utiliza para determinar cuándo invocar el evento sintético.

La función tracefs_synth_append_end_filter se utiliza para añadir un filtro al evento sintético. El filtro se utiliza para determinar cuándo invocar el evento sintético.

La función tracefs_synth_create se utiliza para crear el evento sintético en el sistema. Una vez creado el evento sintético, se puede invocar para añadir un evento a un búfer de traza.

La función tracefs_synth_destroy se utiliza para eliminar el evento sintético del sistema.

La función tracefs_synth_echo_cmd se utiliza para imprimir el comando para crear el evento sintético. Esto puede ser útil para depurar o para crear scripts.

La función tracefs_synth_get_start_hist se utiliza para obtener el nombre del histograma de inicio del evento sintético.

La función tracefs_synth_get_name se utiliza para obtener el nombre del evento sintético.

La función tracefs_synth_raw_fmt se utiliza para establecer el formato de cadena cruda para el evento sintético. Esto puede ser útil para la depuración o para el registro.

La función tracefs_synth_show_event se utiliza para mostrar el evento sintético. Esto puede ser útil para depurar o para verificar que el evento sintético se ha creado correctamente.

La función tracefs_synth_show_start_hist se utiliza para mostrar el histograma de inicio del evento sintético. Esto puede ser útil para la depuración.

La función tracefs_synth_show_end_hist se utiliza para mostrar el histograma final del evento sintético. Esto puede ser útil para la depuración.

La función tracefs_synth_get_event se utiliza para obtener el evento sintético. Esto puede ser útil para manipular el evento sintético.

VALOR DE RETORNO

Las funciones que asignan memoria devuelven un puntero al objeto asignado en caso de éxito, o NULL en caso de error.

Las funciones que modifican el estado devuelven 0 en caso de éxito, o un valor negativo en caso de error.

ERRORES

En caso de error, las funciones que devuelven un valor entero establecen errno para indicar la causa del error.

EJEMPLO

struct tracefs_synth *synth;
int ret;
/*
 * Allocate the synthetic event
 */
synth = tracefs_synth_alloc("my_synthetic_event");
if (!synth) {
        /* Handle error */
        return -1;
}
/*
 * Add a filter to match events where the next_prio field is less than 50.
 * This means the synthetic event will be created only when next_prio < 50.
 */
ret = tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
if (ret < 0) {
        /* Handle error */
        tracefs_synth_free(synth);
        return -1;
}
/*
 * Add a filter to compare the previous priority with the current priority.
 * This means the synthetic event will be created only if prev_prio >= 100.
 * Note that the syntax for the filters is appended to the current filter string.
 * The current filter string is "next_prio < 50".
 * We need to add an OR condition, so we add "||".
 * Then we add the opening parenthesis for the next condition.
 * Then we add the compare condition.
 * Finally, we add the closing parenthesis.
 */
tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                "prev_prio", TRACEFS_COMPARE_GE, "100");
/*
 * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
 * That's because, when the synth is executed, the remaining close parenthesis
 * will be added. That is, the string will end up being:
 * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
 * or tracefs_sync_echo_cmd() is run.
 */
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
