tracefs_kprobe_raw(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_kprobe_alloc, tracefs_kretprobe_alloc, tracefs_kprobe_raw, tracefs_kretprobe_raw, tracefs_kprobe_destroy - Asignar, obtener, crear y eliminar kprobes

SINOPSIS

#include <tracefs.h>
struct tracefs_dynevent *
tracefs_kprobe_alloc(const char *system, const char *event,
                       const char *addr, const char *format);
struct tracefs_dynevent *
tracefs_kretprobe_alloc(const char *system, const char *event,
                          const char *addr, const char *format, unsigned int max);
int tracefs_kprobe_raw(const char *system, const char *event,
                         const char *addr, const char *format);
int tracefs_kretprobe_raw(const char *system, const char *event,
                            const char *addr, const char *format);
int tracefs_kprobe_destroy(const char *system, const char *event,
                           const char *addr, const char *format, bool force);

DESCRIPCIÓN

tracefs_kprobe_alloc() asigna un nuevo contexto de kprobe. El kprobe no está configurado en el sistema. El kprobe se puede agregar al sistema pasando el descriptor devuelto a tracefs_dynevent_create(3). El nuevo kprobe estará en el grupo system (o kprobes si system es NULL) y tendrá el nombre de event (o addr si event es NULL). El kprobe se insertará en addr (nombre de función, con o sin desplazamiento, o una dirección), y format definirá el formato del kprobe. Consulte el archivo de documentación de Linux en: Documentation/trace/kprobetrace.rst

tracefs_kretprobe_alloc() es lo mismo que tracefs_kprobe_alloc, pero asigna contexto para kretprobe. Tiene un parámetro adicional, que es opcional, max - número máximo de activaciones. Consulte la descripción de kretprobes en el archivo Documentation/trace/kprobetrace.rst.

tracefs_kprobe_raw() creará un evento kprobe. Si system es NULL, entonces se usará el predeterminado "kprobes" para el grupo (sistema de eventos). De lo contrario, si se especifica system, el kprobe se creará bajo el grupo con ese nombre. event es el nombre del evento kprobe a crear. addr puede ser una función, una función con desplazamiento o una dirección del kernel. Aquí es donde se insertará la ubicación del kprobe en el kernel. format es el formato del kprobe como se especifica en FETCHARGS en el código fuente del kernel de Linux en el documento Documentation/trace/kprobetrace.rst.

tracefs_kretprobe_raw() es lo mismo que tracefs_kprobe_raw(), excepto que crea un kretprobe en lugar de un kprobe. La diferencia también se describe en el código fuente del kernel de Linux en el archivo Documentation/trace/kprobetrace.rst.

tracefs_kprobe_destroy() destruirá un kprobe o kretprobe específico creado por tracefs_kprobe_raw() o tracefs_kretprobe_raw() con los mismos parámetros.

VALOR DE RETORNO

tracefs_kprobe_raw() y tracefs_kretprobe_raw() devuelven 0 en caso de éxito, o -1 en caso de error. Si ocurre un error de análisis sintáctico en tracefs_kprobe_raw() o tracefs_kprobe_raw(), entonces tracefs_error_last(3) puede usarse para recuperar el mensaje de error que explica el problema de análisis sintáctico.

Las API tracefs_kprobe_alloc() y tracefs_kretprobe_alloc() devuelven un puntero a una estructura tracefs_dynevent asignada, que describe la sonda. Este puntero debe liberarse mediante tracefs_dynevent_free(3). Tenga en cuenta que esto solo asigna un descriptor que representa el kprobe. No modifica el sistema en ejecución.

tracefs_kprobe_destroy() devuelve 0 en caso de éxito o -1 en caso de error si no pudo destruir (o encontrar) con éxito el kprobe o kretprobe.

ERRORES

Los siguientes errores son para todas las llamadas anteriores:

EPERM No se ejecutó como usuario root

ENODEV Los eventos kprobe no están configurados para el kernel en ejecución.

ENOMEM Error de asignación de memoria.

tracefs_kprobe_raw(), tracefs_kretprobe_raw(), tracefs_kprobe_alloc() y tracefs_kretprobe_alloc() pueden fallar con los siguientes errores:

EBADMSG si addr es NULL.

EINVAL Lo más probable es que haya ocurrido un error de análisis sintáctico (use tracefs_error_last(3) para ver posiblemente cuál fue ese error).

También pueden ocurrir otros errores causados por llamadas internas del sistema.

static int callback(struct tep_event *event, struct tep_record *record,

{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: ", TEP_PRINT_PID, TEP_PRINT_COMM);
        if (event->id == open_event->id) {
                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}

        pid_t pid;
        pid = fork();
        if (pid)
                return pid;
        execve(argv[0], argv, env);
        perror("exec");
        exit(-1);
}
const char *mykprobe = "my_kprobes";
enum kprobe_type {
        KPROBE,
        KRETPROBE,
};
static void __kprobe_create(enum kprobe_type type, const char *event,
                            const char *addr, const char *fmt)
{
        char *err;
        int r;
        if (type == KPROBE)
                r = tracefs_kprobe_raw(mykprobe, event, addr, fmt);
        else
                r = tracefs_kretprobe_raw(mykprobe, event, addr, fmt);
        if (r < 0) {
                err = tracefs_error_last(NULL);
                perror("Failed to create kprobe:");
                if (err && strlen(err))
                        fprintf(stderr, "%s\n", err);
        }
}
static void kprobe_create(const char *event, const char *addr,
                          const char *fmt)
{
        __kprobe_create(KPROBE, event, addr, fmt);
}
static void kretprobe_create(const char *event, const char *addr,
                             const char *fmt)
{
        __kprobe_create(KRETPROBE, event, addr, fmt);
}
