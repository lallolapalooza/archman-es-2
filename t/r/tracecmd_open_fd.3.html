tracecmd_open_fd(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_open, tracecmd_open_fd, tracecmd_open_head, tracecmd_init_data, tracecmd_close, tracecmd_set_private, tracecmd_get_private - Abrir y cerrar un archivo de traza.

SINOPSIS

#include <trace-cmd.h>
struct tracecmd_input *tracecmd_open(const char *file, int flags);
struct tracecmd_input *tracecmd_open_fd(int fd, int flags);
struct tracecmd_input *tracecmd_open_head(const char *file, int flags);
int tracecmd_init_data(struct tracecmd_input *handle);
void tracecmd_close(struct tracecmd_input *handle);
void tracecmd_set_private(struct tracecmd_input *handle, void *data);
void *tracecmd_get_private(struct tracecmd_input *handle);

DESCRIPCIÓN

Este conjunto de APIs se puede utilizar para abrir y cerrar un archivo de traza registrado por trace-cmd(1) y que contiene información de rastreo de ftrace, el rastreador oficial del kernel de Linux. El archivo abierto se representa mediante una estructura tracecmd_input, todas las demás APIs de la biblioteca que trabajan con el archivo requieren un puntero a la estructura. Las APIs para abrir un archivo de traza tienen un parámetro de entrada flag, que controla cómo se abrirá y analizará el archivo. El flag es una combinación de estas opciones:

TRACECMD_FL_LOAD_NO_PLUGINS - No cargar ningún plugin
TRACECMD_FL_LOAD_NO_SYSTEM_PLUGINS - No cargar plugins a nivel de sistema, cargar solo plugins
                                       "solo locales" del directorio personal del usuario.

La función tracecmd_open() abre un archivo de traza especificado (file), analiza las cabeceras de metadatos del archivo, asigna e inicializa una estructura de manejador tracecmd_input que representa el archivo. También inicializa el manejador para leer datos de traza del archivo. El manejador devuelto está listo para ser utilizado con las APIs tracecmd_read_.

La función tracecmd_open_fd() hace lo mismo que tracecmd_open(), pero funciona con un descriptor de archivo para un archivo de traza, abierto para lectura.

La función tracecmd_open_head() es igual que tracecmd_open(), pero no inicializa el manejador para leer datos de traza. Lee y analiza solo las cabeceras de metadatos. Se debe usar tracecmd_init_data() antes de usar las APIs tracecmd_read_.

La función tracecmd_init_data() inicializa un handle, asignado con tracecmd_open_head(), para leer datos de traza del archivo asociado. Esta API debe llamarse antes que cualquiera de las APIs tracecmd_read_.

La función tracecmd_close() libera un handle, puntero a la estructura tracecmd_input, previamente asignado con las APIs tracecmd_open(), tracecmd_open_fd() o tracecmd_open_head().

La función tracecmd_set_private() permite añadir data específicos al handle que pueden ser recuperados más tarde.

La función tracecmd_get_private() recuperará la data establecida por tracecmd_set_private() para el handle dado.

VALOR DE RETORNO

Las funciones tracecmd_open(), tracecmd_open_fd() y tracecmd_open_head() devuelven un puntero a la estructura tracecmd_input o NULL en caso de error. La estructura devuelta debe liberarse con tracecmd_close(). Tenga en cuenta que si se utiliza tracecmd_open_fd() para asignar un manejador tracecmd_input, al llamar a tracecmd_close() para cerrarlo, ese fd también se cerrará.

La función tracecmd_init_data() devuelve -1 en caso de error o 0 en caso contrario.

La función tracecmd_get_private() devuelve la data establecida por tracecmd_set_private().

EJEMPLO

Hay dos patrones de uso diferentes para abrir y leer datos de traza desde
un archivo de traza, que pueden usarse dependiendo del caso de uso.
1. Abrir e inicializar el archivo de traza en un solo paso:
#include <stdlib.h>
#include <trace-cmd.h>
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        const char *file = tracecmd_get_private(handle);
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
int main(int argc, char **argv)
{
        struct tracecmd_input *handle;
        if (argc < 2) {
                printf("uso: %s trace.dat\n", argv[0]);
                exit(-1);
        }
        handle = tracecmd_open(argv[i], 0);
        if (!handle)
                exit(-1);
        tracecmd_set_private(handles[nr_handles], argv[i]);
        tracecmd_iterate_events(handles, NULL, 0, print_events, NULL);
        tracecmd_close(handle);
}
2. Abrir e inicializar el archivo de traza en dos pasos. Esto permite realizar
algún procesamiento basado en metadatos, leídos del archivo, antes de inicializar
los datos de traza para la lectura. Un ejemplo de este caso de uso es al abrir
múltiples archivos de traza registrados en una misma sesión de traza. En ese
caso, las marcas de tiempo de todos los eventos de traza deben ajustarse en
función de la información de los metadatos del archivo y antes de leer los
datos de traza.
#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open_head("trace.dat");
        if (!handle) {
                /* Falló al abrir el archivo trace.dat */
        }
...
        /* realizar algún procesamiento, antes de inicializar los datos de traza para la lectura */
...
        if (tracecmd_init_data(handle) < 0) {
                /* Falló al inicializar el manejador para leer los datos de traza */
        }
...
        /* Leer datos de traza del archivo, usando el manejador */
...
        tracecmd_close(handle);
...
