NOMBRE

tracecmd_set_loglevel - Establecer el nivel de registro de la biblioteca

SINOPSIS

#include <trace-cmd.h>
int tracecmd_set_loglevel(enum tep_loglevel level);

DESCRIPCIÓN

La función tracecmd_set_loglevel() establece el nivel de los registros de la biblioteca que se imprimirán en la consola. Consulte libtraceevent(3) para una descripción detallada de los niveles de registro. Establecer el nivel de registro a un valor específico significa que también se imprimirán los registros de los niveles anteriores. Por ejemplo, TEP_LOG_WARNING imprimirá todos los registros con severidad TEP_LOG_WARNING, TEP_LOG_ERROR y TEP_LOG_CRITICAL. El nivel de registro predeterminado es TEP_LOG_CRITICAL. Cuando se establece un nuevo nivel, este también se propaga a libtracefs y libtraceevent.

EJEMPLO

#include <trace-cmd.h>
...
tracecmd_set_loglevel(TEP_LOG_ALL);
...
/* llamar a las API de libtracecmd, libtracefs o libtraceevent y observar cualquier registro que produzcan */
...
tracecmd_set_loglevel(TEP_LOG_CRITICAL);
