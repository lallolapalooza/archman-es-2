NOMBRE

trace-cmd-listen - escucha las conexiones entrantes para grabar el rastreo.

SINOPSIS

trace-cmd listen -p puerto [OPCIONES]

DESCRIPCIÓN

trace-cmd(1) listen configura un puerto para escuchar, esperando conexiones de otros hosts que ejecutan trace-cmd-record(1) con la opción -N. Cuando se establece una conexión y el host remoto envía datos, creará un archivo llamado trace.HOST:PUERTO.dat. Donde HOST es el nombre del host remoto y PUERTO es el puerto que usó el host remoto para conectarse.

OPCIONES

-p puerto

Esta opción especificará el puerto al que escuchar.

-D

Esta opción hace que trace-cmd listen entre en modo demonio y se ejecute en segundo plano.

-V

Escucha en un vsocket en su lugar. Esto es útil para rastrear entre el host y las máquinas virtuales invitadas.

-d directorio

Esta opción especifica un directorio para escribir los archivos de datos.

-o nombre_archivo

Esta opción anula el valor predeterminado trace en el trace.HOST:PUERTO.dat que se crea cuando se conecta un host remoto.

-l nombre_archivo

Esta opción escribe los mensajes de salida en un archivo de registro en lugar de la salida estándar.

--verbose[=nivel]

Establece el nivel de registro. Los niveles de registro soportados son "none", "critical", "error", "warning", "info", "debug", "all" o sus identificadores "0", "1", "2", "3", "4", "5", "6". Establecer el nivel de registro en un valor específico habilita todos los registros de ese nivel y todos los niveles anteriores. El nivel por defecto será "info" si no se especifica uno. 
Ejemplo: habilitar todos los registros críticos, de error y de advertencia
trace-cmd listen --verbose=warning
