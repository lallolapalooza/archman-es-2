tracecmd_map_find_by_host_pid(3)

Paquete: trace-cmd

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manual de libtracefs LIBTRACECMD(3)

NOMBRE

tracecmd_map_vcpus, tracecmd_get_cpu_map, tracecmd_map_find_by_host_pid, tracecmd_map_get_host_pid, tracecmd_map_get_guest, tracecmd_map_set_private, tracecmd_map_get_private - Mapeo de datos de host y guest

SINOPSIS

#include <trace-cmd.h>
int tracecmd_map_vcpus(struct tracecmd_input **handles, int nr_handles);
struct tracecmd_cpu_map *tracecmd_get_cpu_map(struct tracecmd_input *handle, int cpu);
struct tracecmd_cpu_map *tracecmd_map_find_by_host_pid(struct tracecmd_input *handle,
                                                      int host_pid);
int tracecmd_map_get_host_pid(struct tracecmd_cpu_map *map);
struct tracecmd_input *tracecmd_map_get_guest(struct tracecmd_cpu_map *map);
void tracecmd_map_set_private(struct tracecmd_cpu_map *map, void *priv);
void *tracecmd_map_get_private(struct tracecmd_cpu_map *map);

DESCRIPCIÓN

Este conjunto de APIs se utiliza para mapear archivos de trace de host y guest para facilitar análisis posteriores del trace.

tracecmd_map_vcpus() toma un array de handles donde cada elemento de ese array fue creado por una de las funciones de tracecmd_open(3), y el número de handles como nr_handles. Se espera que el primer handle en el array de handles sea el descriptor del archivo de trace del host, y los restantes son archivos de trace de guests que se ejecutan en el host, y que fueron creados por las interacciones de trace-cmd record(1) y trace-cmd agent(1). Devuelve el número de guests encontrados en handles que fueron asociados con el host, o un valor negativo en caso de error.

tracecmd_get_cpu_map() devuelve un descriptor para una CPU dada para un handle. Si el handle era un guest definido desde tracecmd_map_vcpus(), entonces el mapeo creado desde esa función que está asociado a esta vCPU particular (denotada por cpu) desde handle. Este descriptor puede ser utilizado por las funciones tarcecmd_map_get_guest(), tracecmd_map_set_private() y tracecmd_map_get_private().

tracecmd_map_find_by_host_pid() devolverá un mapeo para una vCPU de guest que es manejada por el host_pid dado. Nota, el handle pasado puede ser tanto el handle del host como uno de los handles del guest para ese host que fue mapeado por tracecmd_map_vcpus(), incluso si el handle del guest no tiene la vCPU que representa el host_pid.

tracecmd_map_get_host_pid() devolverá el host_pid para un map dado que fue obtenido por una de las funciones anteriores.

tracecmd_map_get_guest() devolverá el guest_handle para un map dado que fue obtenido por una de las funciones anteriores.

tracecmd_map_set_private() permite a la aplicación asignar datos privados para un mapeo de hilo host a vCPU de guest definido por map.

tracecmd_map_get_private() recupera los datos priv de map que fueron establecidos por tracecmd_map_set_private().

VALOR DE RETORNO

tracecmd_map_vcpus() devuelve el número de guests en el array handles que fueron mapeados al handle del host que es la primera entrada en handles. Devuelve -1 en caso de error.

tracecmd_get_cpu_map() devuelve un mapa creado por tracecmd_map_vcpus() para una cpu dada para un handle dado, o NULL si no se encuentra.

tracecmd_map_find_by_host_pid() devuelve un mapa que está asociado por la tarea del host con host_pid como su ID de proceso. handle puede ser tanto el handle del host como uno de los handles de guest que fueron mapeados al host a través de tracecmd_map_vcpus(), incluso si el handle del guest es otro guest diferente al para el cual es el mapeo. Devuelve NULL si no se encuentra.

tracecmd_map_get_host_pid() devuelve el ID de proceso del host para un mapeo asociado definido por map.

tracecmd_map_get_guest() devuelve el handle del guest para un mapeo asociado definido por map.

tracecmd_map_get_private() devuelve los datos privados de un mapeo definido por map que fue establecido por tracecmd_map_set_private().

EJEMPLO

#include <stdlib.h>
#include <errno.h>
#include <trace-cmd.h>
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        int nr_handles;
        int i;
        if (argc < 2) {
                printf("uso: host_trace.dat guest1_trace.dat [guest2_trace.dat ...]\n");
                exit(-1);
        }
        for (i = 1; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[1]);
                        exit(-1);
                }
                tracecmd_set_private(handles[nr_handles], argv[i]);
                nr_handles++;
        }
        tracecmd_map_vcpus(handles, nr_handles);
        for (i = 1; i < nr_handles; i++) {
                struct tracecmd_cpu_map *map;
                struct tep_handle *tep;
                const char *file = tracecmd_get_private(handles[i]);
                int cpus, cpu;
                printf("Mapeos para el guest %s:\n", file);
                tep = tracecmd_get_tep(handles[i]);
                cpus = tep_get_cpus(tep);
                for (cpu = 0; cpu < cpus; cpu++) {
                        printf("  [%03d] ", cpu);
                        map = tracecmd_get_cpu_map(handles[i], cpu);
                        if (!map) {
                                printf("¡No tiene mapeo!\n");
                                continue;
                        }
                        printf("host_pid: %d\n", tracecmd_map_get_host_pid(map));
                }
        }
        for (i = 0; i < nr_handles; i++)
                tracecmd_close(handles[i]);
        free(handles);
        exit(0);
}

NAME

tracecmd_map_find_by_host_pid - Find a trace event mapping by host PID

SYNOPSIS

#include <trace-cmd.h>

struct trace_event_file *tracecmd_map_find_by_host_pid(pid_t pid);

DESCRIPTION

The tracecmd_map_find_by_host_pid function searches for a trace event mapping associated with the given host process ID (PID). A trace event mapping represents the set of trace events that are currently enabled and being recorded for a specific process.

When tracing is enabled for a particular process using tools like trace-cmd or ftrace, a mapping is created to manage the events being traced for that process. This function allows you to retrieve a pointer to the structure that represents this mapping for a given PID.

RETURN VALUE

On success, it returns a pointer to a struct trace_event_file representing the trace event mapping for the specified PID.

If no trace event mapping is found for the given PID, it returns NULL.

EXAMPLE

```c

#include <stdio.h>

#include <unistd.h>

#include <trace-cmd.h>

int main() {

pid_t my_pid = getpid();

struct trace_event_file *event_file;

event_file = tracecmd_map_find_by_host_pid(my_pid);

if (event_file) {

printf("Trace event mapping found for PID %d.\\n", my_pid);

// You can now use the event_file pointer to interact with the trace events

// For example, to get the number of enabled events:

// printf("Number of enabled events: %d\\n", event_file->nr_events);

// Remember to free the resource if necessary, depending on the library's management

} else {

printf("No trace event mapping found for PID %d.\\n", my_pid);

}

return 0;

}

```

FILES

This function interacts with the kernel's tracing infrastructure, typically found under /sys/kernel/tracing/. The specific files and directories involved depend on the kernel version and configuration, but commonly include:

  • /sys/kernel/tracing/events/: Base directory for trace events.
  • /sys/kernel/tracing/trace_pipe: For reading trace output.
  • Per-process trace files might be managed within /sys/kernel/tracing/instances/ or similar structures depending on how tracing is set up.

This function is part of the trace-cmd library, which provides an interface for interacting with the Linux kernel's tracing capabilities (ftrace).

The struct trace_event_file contains information about the enabled trace events for a specific process, including counts of enabled events and pointers to the event structures.

Ensure that the tracing subsystem is enabled in your kernel and that the necessary permissions are available to access the tracing information.
