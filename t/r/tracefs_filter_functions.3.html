NOMBRE

tracefs_function_filter, tracefs_function_notrace, tracefs_filter_functions - Funciones para modificar los filtros de rastreo de funciones

SINOPSIS

#include <tracefs.h>
int tracefs_function_filter(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_function_notrace(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_filter_functions(const char *filter, const char *module, char ***list);

DESCRIPCIÓN

tracefs_function_filter y tracefs_function_notrace pueden usarse para limitar las funciones del kernel de Linux que serían rastreadas por los rastreadores de funciones y gráfico de funciones. tracefs_function_filter define una lista de funciones que pueden ser rastreadas. tracefs_function_notrace define una lista de funciones que no serán rastreadas. Si una función está en ambas listas, no será rastreada.

Toman una instancia, que puede ser NULL para el rastreo de nivel superior, filtro, una cadena que representa un filtro que debe aplicarse para definir qué funciones deben rastrearse, módulo, para limitar el filtrado a un módulo específico (o NULL para filtrar todas las funciones), y flags que contiene controles sobre cómo se manejarán los filtros (ver sección FLAGS a continuación).

tracefs_filter_functions devuelve una lista de funciones que pueden ser filtradas mediante el filtro y el módulo que se proporcionan. Si tanto filtro como módulo son NULL, se devuelven todas las funciones disponibles que se pueden filtrar. En caso de éxito, lista debe liberarse con tracefs_list_free()(3).

El filtro puede ser una coincidencia directa de una función, un patrón glob o una expresión regular (regex). Un glob es donde * coincide con cero o más caracteres, ? coincidirá con cero o un carácter, y . solo coincide con un punto. Si el filtro se determina que es una expresión regular (donde contiene cualquier cosa que no sean caracteres alfanuméricos, o ., *, ?), el filtro se procesará como una expresión regular (regex(3)) siguiendo las reglas de regex(3), y . no es un punto, sino que coincidirá con cualquier carácter individual. Para forzar una expresión regular, prefije el filtro con un ^ o agréguele un $, ya que el filtro realiza coincidencias completas de las funciones de todos modos.

Si módulo está establecido y filtro es NULL, esto implicará lo mismo que filtro sea igual a "*". Lo que habilitará todas las funciones para un módulo dado. De lo contrario, el filtro puede ser NULL si una llamada anterior a tracefs_function_filter() con la misma instancia tenía establecida la opción TRACEFS_FL_CONTINUE y esta llamada no la tiene. Esto es útil para simplemente confirmar los filtros anteriores. También puede ser NULL si se establece TRACEFS_FL_RESET y la llamada anterior no tenía la misma instancia y TRACEFS_FL_CONTINUE establecida. Esto es útil para simplemente limpiar el filtro.

FLAGS

El parámetro flags puede tener los siguientes valores establecidos, o ser cero.

TRACEFS_FL_RESET : Si flags contiene TRACEFS_FL_RESET, entonces limpiará los filtros que están actualmente establecidos antes de aplicar filtro. De lo contrario, filtro se añade al conjunto actual de filtros ya habilitados. Si se establece esta bandera y la llamada anterior a tracefs_function_filter() tuvo la misma instancia y la bandera TRACEFS_FL_CONTINUE estaba establecida, la función fallará con un retorno de -1 y errno establecido en EBUSY.

TRACEFS_FL_CONTINUE : Si flags contiene TRACEFS_FL_CONTINUE, entonces filtro no tendrá efecto después de una llamada exitosa a tracefs_function_filter(). Esto permite múltiples llamadas a tracefs_function_filter() para actualizar la función de filtro y luego una sola llamada (una sin la bandera TRACEFS_FL_CONTINUE establecida) para confirmar todos los filtros. Puede llamarse varias veces para añadir más filtros. Una llamada sin esta bandera establecida confirmará los cambios antes de retornar (si el filtro pasado coincidió con éxito). Una llamada a tracefs_function_filter() después de una que tuvo la bandera TRACEFS_FL_CONTINUE establecida para la misma instancia fallará si la bandera TRACEFS_FL_RESET está establecida, ya que la bandera de reinicio solo es aplicable para el primer filtro a añadir antes de confirmar.

TRACEFS_FL_FUTURE : Si flags contiene TRACEFS_FL_FUTURE y módulo contiene una cadena de un módulo, entonces si el módulo no está cargado, intentará escribir el filtro con el módulo en el archivo de filtro. A partir de Linux v4.13, las funciones de módulo podían añadirse al filtro antes de que se cargaran. El filtro se almacenará en caché, y cuando el módulo se cargue, el filtro se establecerá antes de que el módulo se ejecute, permitiendo rastrear las funciones de inicialización de un módulo. Esto solo funcionará si el filtro no es una expresión regular.

VALOR DE RETORNO

Para tracefs_function_filter() y tracefs_function_notrace(), un retorno de 0 significa éxito. Si hay un error pero el filtrado no se inició, se devuelve 1. Si el filtrado se inició pero ocurre un error, se devuelve -1. El estado del filtrado puede ser desconocido.

Si se estableció TRACEFS_FL_CONTINUE y se devolvió 0 o -1, entonces se debe realizar otra llamada a tracefs_function_filter() sin TRACEFS_FL_CONTINUE establecida para confirmar (y cerrar) el filtrado.

Para tracefs_filter_functions(), un retorno de 0 significa éxito, y el parámetro lista se llena con una lista de nombres de funciones que coincidieron con filtro y módulo. lista es un array de cadenas, donde el último puntero de cadena en el array es NULL. lista debe liberarse con tracefs_list_free(). En caso de fallo, se devuelve un valor negativo y se ignora lista.

ERRORES

tracefs_function_filter() puede fallar con los siguientes errores:

EINVAL El filtro es inválido o no coincidió con ninguna función.

EBUSY La llamada anterior de tracefs_function_filter() se realizó con la misma instancia y TRACEFS_FL_CONTINUE establecida, y la llamada actual tenía TRACEFS_FL_RESET establecida.

Otros errores también pueden ocurrir debido a llamadas internas del sistema.

EJEMPLO

#include <stdio.h>
#include <errno.h>
#include <tracefs.h>
#define INST "dummy"
static const char *filters[] = { "run_init_process", "try_to_run_init_process", "dummy1", NULL };
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = tracefs_instance_create(INST);
        char **func_list;
        int ret;
        int i;
        if (!inst) {
                /* Error al crear nueva instancia de rastreo */
        }
        if (tracefs_filter_functions("*lock*", NULL, &func_list) < 0) {
                printf("No se pudo leer el filtro de funciones\n");
                goto out;
        }
        printf("Ignorando las siguientes funciones:\n");
        for (i = 0; func_list[i]; i++)
                printf("  %s\n", func_list[i]);
        tracefs_list_free(func_list);
        /* No rastrear ninguna función con la palabra "lock" */
        ret = tracefs_function_notrace(inst, "*lock*", NULL, TRACEFS_FL_RESET);
        if (ret) {
                printf("No se pudo establecer el filtro notrace\n");
                goto out;
        }
        /* Primero restablecer el filtro */
        ret = tracefs_function_filter(inst, NULL, NULL,
                                      TRACEFS_FL_RESET | TRACEFS_FL_CONTINUE);
        if (ret) {
                printf("No se pudo restablecer el filtro\n");
                /* Asegurarse de que se cierra, -1 significa que el filtro se inició */
                if (ret < 0)
                        tracefs_function_filter(inst, NULL, NULL, 0);
        }
        for (i = 0; filters[i]; i++) {
                ret = tracefs_function_filter(inst, filters[i], NULL,
                                              TRACEFS_FL_CONTINUE);
                if (ret) {
                        if (errno == EINVAL)
                                printf("El filtro %s no coincidió\n", filters[i]);
                        else
                                printf("Error al escribir %s\n", filters[i]);
                }
        }
        ret = tracefs_function_filter(inst, "*", "ext4", 0);
        if (ret) {
                printf("Error al establecer filtros para ext4\n");
                goto out;
        }
out:
        tracefs_instance_destroy(inst);
        return 0;
}

NAME

tracefs_filter_functions, tracefs_function_filter - set filters for functions

SYNOPSIS

#include <tracefs.h>
int tracefs_filter_functions(tracefs_instance_t *inst, const char *filter_str);
int tracefs_function_filter(tracefs_instance_t *inst, const char *trace_str, const char *event_str, int flags);

DESCRIPTION

The tracefs_filter_functions function allows to set a filter for functions. It takes a string which can contain multiple tracefs_function_filter calls. The string is parsed and tracefs_function_filter is called for each entry.

The tracefs_function_filter function allows to filter a specific trace event or a group of events. The trace_str is the name of the trace event (e.g. syscalls, sched_switch, etc.). The event_str is the function name. The flags can be used to specify options:

0
No special options.
TRACEFS_FUNCTION_FILTER_BLACK
Blacklist the function. This means tracing will skip this function.
TRACEFS_FUNCTION_FILTER_WHITE
Whitelist the function. Tracing will only trace this function.

To clear the filters, call tracefs_filter_functions with an empty string or call tracefs_function_filter with NULL for trace_str and event_str.

FLAGS

See the DESCRIPTION section.

RETURN VALUE

On success, these functions return 0. On failure, a negative error code is returned.

ERRORS

The following error codes are defined:

-EINVAL
Invalid arguments.
-ENOMEM
Out of memory.
-ENOSYS
The function is not implemented.
-EPERM
Operation not permitted.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>
int main(void) {
        tracefs_instance_t *inst;
        int ret;
        /* Create a tracefs instance */
        inst = tracefs_instance_create(NULL);
        if (!inst) {
                fprintf(stderr, "Failed to create tracefs instance\n");
                return 1;
        }
        /* Filter only 'do_sys_open' syscall */
        ret = tracefs_filter_functions(inst, "syscalls:do_sys_open");
        if (ret < 0) {
                fprintf(stderr, "Failed to set filter: %d\n", ret);
                goto out;
        }
        /* Or filter 'do_sys_open' and 'sys_read' syscalls */
        ret = tracefs_filter_functions(inst, "syscalls:do_sys_open,syscalls:sys_read");
        if (ret < 0) {
                fprintf(stderr, "Failed to set filter: %d\n", ret);
                goto out;
        }
        /* Filter only specific functions for all events */
        ret = tracefs_function_filter(inst, NULL, "kmalloc,kfree",
                                        TRACEFS_FUNCTION_FILTER_WHITE);
        if (ret < 0) {
                fprintf(stderr, "Failed to set filter: %d\n", ret);
                goto out;
        }
        /* Blacklist specific functions for all events */
        ret = tracefs_function_filter(inst, NULL, "schedule",
                                        TRACEFS_FUNCTION_FILTER_BLACK);
        if (ret < 0) {
                fprintf(stderr, "Failed to set filter: %d\n", ret);
                goto out;
        }
        /* Clear all filters */
        ret = tracefs_filter_functions(inst, ""
