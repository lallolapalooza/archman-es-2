NOMBRE

trojan - un mecanismo irreconocible que te ayuda a eludir el GFW

SINOPSIS

trojan [-htv] [-l LOG] [-k KEYLOG] [[-c] CONFIG]

DESCRIPCIÓN

trojan es un mecanismo irreconocible que te ayuda a eludir el GFW. Cargará el archivo de configuración ubicado en CONFIG y iniciará un cliente proxy o un servidor proxy.

OPCIONES

-c, --config=CONFIG
Establece el archivo de configuración a cargar. Por defecto es /etc/trojan/config.json.
-h, --help
Imprime el mensaje de ayuda.
-k, --keylog=KEYLOG
Establece el archivo de registro de claves a escribir.
-l, --log=LOG
Establece el archivo de registro a escribir. Si no se especifica, el registro se enviará a stderr.
-t, --test
Prueba el archivo de configuración, sin iniciar un servidor.
-v, --version
Imprime la versión e información de compilación.

ARCHIVOS

/etc/trojan/config.json
El archivo de configuración por defecto. Ver https://trojan-gfw.github.io/trojan/config para más detalles.

VER TAMBIÉN

Documentación completa en: https://trojan-gfw.github.io/trojan/
