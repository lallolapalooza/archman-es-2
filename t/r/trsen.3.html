CTRSEN

Propósito:

!>
!> CTRSEN reordena la factorización de Schur de una matriz compleja
!> A = Q*T*Q**H, de modo que un clúster seleccionado de valores propios aparezca en
!> las posiciones principales de la diagonal de la matriz triangular superior
!> T, y las columnas principales de Q formen una base ortonormal del
!> subespacio invariante derecho correspondiente.
!>
!> Opcionalmente, la rutina calcula los números de condición recíprocos del
!> clúster de valores propios (S) y/o del subespacio invariante (SEP).
!>

Parámetros

JOB 
!>          JOB es CHARACTER*1
!>          Especifica si se requieren números de condición para el
!>          clúster de valores propios (S) o el subespacio invariante (SEP):
!>          = 'N': ninguno;
!>          = 'E': solo para valores propios (S);
!>          = 'V': solo para subespacio invariante (SEP);
!>          = 'B': para valores propios y subespacio invariante (S y
!>                 SEP).
!>

COMPQ

!>          COMPQ es CHARACTER*1
!>          = 'V': actualiza la matriz Q de vectores de Schur;
!>          = 'N': no actualiza Q.
!>

SELECT

!>          SELECT es un array LOGICAL, de dimensión (N)
!>          SELECT especifica los valores propios en el clúster seleccionado. Para
!>          seleccionar el j-ésimo valor propio, SELECT(j) debe establecerse en .TRUE..
!>

N

!>          N es INTEGER
!>          El orden de la matriz T. N >= 0.
!>

T

!>          T es un array COMPLEX, de dimensión (LDT,N)
!>          En la entrada, la matriz triangular superior T.
!>          En la salida, T se sobrescribe con la matriz T reordenada, con los
!>          valores propios seleccionados como los elementos diagonales principales.
!>

LDT

!>          LDT es INTEGER
!>          La dimensión principal del array T. LDT >= max(1,N).
!>

Q

!>          Q es un array COMPLEX, de dimensión (LDQ,N)
!>          En la entrada, si COMPQ = 'V', la matriz Q de vectores de Schur.
!>          En la salida, si COMPQ = 'V', Q ha sido postmultiplicada por la
!>          matriz de transformación unitaria que reordena T; las M columnas
!>          principales de Q forman una base ortonormal para el subespacio
!>          invariante especificado.
!>          Si COMPQ = 'N', Q no se referencia.
!>

LDQ

!>          LDQ es INTEGER
!>          La dimensión principal del array Q.
!>          LDQ >= 1; y si COMPQ = 'V', LDQ >= N.
!>

W

!>          W es un array COMPLEX, de dimensión (N)
!>          Los valores propios reordenados de T, en el mismo orden en que
!>          aparecen en la diagonal de T.
!>

M

!>          M es INTEGER
!>          La dimensión del subespacio invariante especificado.
!>          0 <= M <= N.
!>

S

!>          S es REAL
!>          Si JOB = 'E' o 'B', S es un límite inferior del número de condición
!>          recíproco para el clúster seleccionado de valores propios.
!>          S no puede subestimar el número de condición recíproco real
!>          en más de un factor de sqrt(N). Si M = 0 o N, S = 1.
!>          Si JOB = 'N' o 'V', S no se referencia.
!>

SEP

!>          SEP es REAL
!>          Si JOB = 'V' o 'B', SEP es el número de condición recíproco estimado
!>          del subespacio invariante especificado. Si
!>          M = 0 o N, SEP = norm(T).
!>          Si JOB = 'N' o 'E', SEP no se referencia.
!>

WORK

!>          WORK es un array COMPLEX, de dimensión (MAX(1,LWORK))
!>          En la salida, si INFO = 0, WORK(1) devuelve el LWORK óptimo.
!>

LWORK

!>          LWORK es INTEGER
!>          La dimensión del array WORK.
!>          Si JOB = 'N', LWORK >= 1;
!>          si JOB = 'E', LWORK = max(1,M*(N-M));
!>          si JOB = 'V' o 'B', LWORK >= max(1,2*M*(N-M)).
!>
!>          Si LWORK = -1, entonces se asume una consulta de espacio de trabajo; la rutina
!>          solo calcula el tamaño óptimo del array WORK, devuelve
!>          este valor como la primera entrada del array WORK, y ninguna
!>          mensaje de error relacionado con LWORK es emitido por XERBLA.
!>

INFO

!>          INFO es INTEGER
!>          = 0:  salida exitosa
!>          < 0:  si INFO = -i, el i-ésimo argumento tenía un valor ilegal
!>

Detalles adicionales:

!>
!> CTRSEN primero recopila los valores propios seleccionados calculando una transformación unitaria
!> Z para moverlos a la esquina superior izquierda de T. En otras palabras, los valores propios seleccionados son los valores propios de T11 en:
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!> donde N = n1+n2. Las primeras
!> n1 columnas de Z abarcan el subespacio invariante especificado de T.
!>
!> Si T se ha obtenido de la factorización de Schur de una matriz
!> A = Q*T*Q**H, entonces la factorización de Schur reordenada de A viene dada por
!> A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, y las primeras n1 columnas de Q*Z abarcan el
!> subespacio invariante correspondiente de A.
!>
!> El número de condición recíproco del promedio de los valores propios de
!> T11 puede devolverse en S. S se encuentra entre 0 (muy mal condicionado)
!> y 1 (muy bien condicionado). Se calcula de la siguiente manera. Primero calculamos
!> R tal que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!> es el proyector sobre el subespacio invariante asociado con T11.
!> R es la solución de la ecuación de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!> Sea F-norm(M) la norma de Frobenius de M y 2-norm(M) la
!> norma 2 de M. Entonces S se calcula como el límite inferior
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!> del recíproco de 2-norm(P), el número de condición recíproco real.
!> S no puede subestimar 1 / 2-norm(P) en más de un factor de
!> sqrt(N).
!>
!> Un límite de error aproximado para el promedio calculado de los
!> valores propios de T11 es
!>
!>                         EPS * norm(T) / S
!>
!> donde EPS es la precisión de la máquina.
!>
!> El número de condición recíproco del subespacio invariante derecho
!> abarcado por las primeras n1 columnas de Z (o de Q*Z) se devuelve en SEP.
!> SEP se define como la separación de T11 y T22:
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!> donde sigma-min(C) es el valor singular más pequeño de la
!> matriz n1*n2 por n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!> I(m) es una matriz identidad de m por m, y kprod denota el producto de Kronecker. Estimamos

Propósito:

!>
!> STRSEN reordena la factorización de Schur real de una matriz real
!> A = Q*T*Q**T, de modo que un cúmulo seleccionado de autovalores aparezca en
!> los bloques diagonales principales de la matriz cuasi-triangular superior T,
!> y las columnas principales de Q formen una base ortonormal del
!> subespacio invariante correspondiente.
!>
!> Opcionalmente, la rutina calcula los números recíprocos de condición de
!> el cúmulo de autovalores (S) y/o el subespacio invariante (SEP).
!>
!> T debe estar en forma canónica de Schur (como se devuelve por SHSEQR), es decir,
!> triangular por bloques con bloques diagonales de 1x1 y 2x2; cada
!> bloque diagonal de 2x2 tiene sus elementos diagonales iguales y sus
!> elementos fuera de la diagonal de signo opuesto.
!>

!>
!>  STRSEN primero agrupa los autovalores seleccionados calculando una
!>  transformación ortogonal Z para moverlos a la esquina superior izquierda de T.
!>  En otras palabras, los autovalores seleccionados son los autovalores de T11
!>  en:
!>
!>          Z**T * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  donde N = n1+n2 y Z**T significa la transpuesta de Z. Las primeras n1 columnas
!>  de Z abarcan el subespacio invariante especificado de T.
!>
!>  Si T se ha obtenido de la factorización de Schur real de una matriz
!>  A = Q*T*Q**T, entonces la factorización de Schur real reordenada de A se da
!>  por A = (Q*Z)*(Z**T*T*Z)*(Q*Z)**T, y las primeras n1 columnas de Q*Z abarcan
!>  el subespacio invariante correspondiente de A.
!>
!>  El número recíproco de condición del promedio de los autovalores de
!>  T11 puede ser devuelto en S. S se encuentra entre 0 (muy mal condicionado)
!>  y 1 (muy bien condicionado). Se calcula de la siguiente manera. Primero calculamos
!>  R tal que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  es el proyector sobre el subespacio invariante asociado con T11.
!>  R es la solución de la ecuación de Sylvester:
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Sea norma-F(M) la norma de Frobenius de M y norma-2(M) la

NAME

ztrsen

reorder the Schur factorization of a general matrix

SYNOPSIS

Detailed Description

ZTRSEN reorders the Schur factorization of a complex matrix A = Q*T*Q**H, so that a selected cluster of eigenvalues appears in the leading positions on the diagonal of the upper triangular matrix T, and the leading columns of Q form an orthonormal basis of the corresponding right invariant subspace.

Optionally the routine computes the reciprocal condition numbers of the cluster of eigenvalues and/or the invariant subspace.

The version of the algorithm depends on the values of JOB.

Reference:

  • H. Andersen, T. Davis, J. Demmel, and E. Gu. "Progress in numerical linear algebra", Applied Numerical Mathematics, 21:291-310, 1996.

Further Details:

  ZTRSEN first collects the selected eigenvalues by computing a unitary
  transformation Z to move them to the top left corner of T. In other
  words, the selected eigenvalues are the eigenvalues of T11 in:

          Z**H * T * Z = ( T11 T12 ) n1
                         (  0  T22 ) n2
                            n1  n2

  where N = n1+n2. The first
  n1 columns of Z span the specified invariant subspace of T.

  If T has been obtained from the Schur factorization of a matrix
  A = Q*T*Q**H, then the reordered Schur factorization of A is given by
  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, and the first n1 columns of Q*Z span the
  corresponding invariant subspace of A.

  The reciprocal condition number of the average of the eigenvalues of
  T11 may be returned in S. S lies between 0 (very badly conditioned)
  and 1 (very well conditioned). It is computed as follows. First we
  compute R so that

                          P = ( I  R ) n1
                              ( 0  0 ) n2
                                 n1 n2

  is the projector on the invariant subspace associated with T11.
  R is the solution of the Sylvester equation:

                        T11*R - R*T22 = T12.

  Let F-norm(M) denote the Frobenius-norm of M and 2-norm(M) denote
  the two-norm of M. Then S is computed as the lower bound

                    (1 + F-norm(R)**2)**(-1/2)

  on the reciprocal of 2-norm(P), the true reciprocal condition number.
  S cannot underestimate 1 / 2-norm(P) by more than a factor of
  sqrt(N).

  An approximate error bound for the computed average of the
  eigenvalues of T11 is

                     EPS * norm(T) / S

  where EPS is the machine precision.

  The reciprocal condition number of the right invariant subspace
  spanned by the first n1 columns of Z (or of Q*Z) is returned in SEP.
  SEP is defined as the separation of T11 and T22:

                     sep( T11, T22 ) = sigma-min( C )

  where sigma-min(C) is the smallest singular value of the
  n1*n2-by-n1*n2 matrix

     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )

  I(m) is an m by m identity matrix, and kprod denotes the Kronecker
  product. We estimate sigma-min(C) by the reciprocal of an estimate of
  the 1-norm of inverse(C). The true reciprocal 1-norm of inverse(C)
  cannot differ from sigma-min(C) by more than a factor of sqrt(n1*n2).

  When SEP is small, small changes in T can cause large changes in
  the invariant subspace. An approximate bound on the maximum angular
  error in the computed right invariant subspace is

                     EPS * norm(T) / SEP
