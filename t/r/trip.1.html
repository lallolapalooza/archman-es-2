trip(1) Manual de comandos generales trip(1)

NOMBRE

trip - Una herramienta de diagnóstico de red

SINOPSIS

trip [-c|--config-file] [-m|--mode] [-u|--unprivileged] [-p|--protocol] [--udp] [--tcp] [--icmp] [-F|--addr-family] [-4|--ipv4] [-6|--ipv6] [-P|--target-port] [-S|--source-port] [-A|--source-address] [-I|--interface] [-i|--min-round-duration] [-T|--max-round-duration] [-g|--grace-duration] [--initial-sequence] [-R|--multipath-strategy] [-U|--max-inflight] [-f|--first-ttl] [-t|--max-ttl] [--packet-size] [--payload-pattern] [-Q|--tos] [-e|--icmp-extensions] [--read-timeout] [-r|--dns-resolve-method] [-y|--dns-resolve-all] [--dns-timeout] [--dns-ttl] [-z|--dns-lookup-as-info] [-s|--max-samples] [--max-flows] [-a|--tui-address-mode] [--tui-as-mode] [--tui-custom-columns] [--tui-icmp-extension-mode] [--tui-geoip-mode] [-M|--tui-max-addrs] [--tui-preserve-screen] [--tui-refresh-rate] [--tui-privacy-max-ttl] [--tui-locale] [--tui-timezone] [--tui-theme-colors] [--print-tui-theme-items] [--tui-key-bindings] [--print-tui-binding-commands] [-C|--report-cycles] [-G|--geoip-mmdb-file] [--generate] [--generate-man] [--print-config-template] [--print-locales] [--log-format] [--log-filter] [--log-span-events] [-v|--verbose] [-h|--help] [-V|--version] [OBJETIVOS]

DESCRIPCIÓN

Una herramienta de diagnóstico de red

OPCIONES

-c, --config-file=ARCHIVO_CONFIG
Archivo de configuración
-m, --mode=MODO
Modo de salida [predeterminado: tui]

Valores posibles:

  • tui: Mostrar TUI interactivo
  • stream: Mostrar un flujo continuo de datos de rastreo
  • pretty: Generar un informe de tabla de texto bonito para N ciclos
  • markdown: Generar un informe de tabla de texto Markdown para N ciclos
  • csv: Generar un informe CSV para N ciclos
  • json: Generar un informe JSON para N ciclos
  • dot: Generar un archivo Graphviz DOT para N ciclos
  • flows: Mostrar todos los flujos para N ciclos
  • silent: No generar ninguna salida de rastreo para N ciclos
-u, --unprivileged
Rastrear sin requerir privilegios elevados en plataformas compatibles [predeterminado: false]
-p, --protocol=PROTOCOLO
Protocolo de rastreo [predeterminado: icmp]

Valores posibles:

  • icmp: Protocolo de mensajes de control de Internet
  • udp: Protocolo de datagramas de usuario
  • tcp: Protocolo de control de transmisión
--udp
Rastrear usando el protocolo UDP
--tcp
Rastrear usando el protocolo TCP
--icmp
Rastrear usando el protocolo ICMP
-F, --addr-family=FAMILIA_DIRECCION
La familia de direcciones [predeterminado: ipv4-then-ipv6]

Valores posibles:

  • ipv4: Solo IPv4
  • ipv6: Solo IPv6
  • ipv6-then-ipv4: IPv6 con respaldo a IPv4
  • ipv4-then-ipv6: IPv4 con respaldo a IPv6
  • system: Si se está utilizando el resolvedor del sistema operativo, utiliza la primera dirección IP devuelta, de lo contrario busca IPv6 con respaldo a IPv4
-4, --ipv4
Usar solo IPv4
-6, --ipv6
Usar solo IPv6
-P, --target-port=PUERTO_OBJETIVO
El puerto de destino (solo TCP y UDP) [predeterminado: 80]
-S, --source-port=PUERTO_ORIGEN
El puerto de origen (solo TCP y UDP) [predeterminado: auto]
-A, --source-address=DIRECCION_ORIGEN
La dirección IP de origen [predeterminado: auto]
-I, --interface=INTERFAZ
La interfaz de red [predeterminado: auto]
-i, --min-round-duration=DURACION_MIN_RONDA
La duración mínima de cada ronda [predeterminado: 1s]
-T, --max-round-duration=DURACION_MAX_RONDA
La duración máxima de cada ronda [predeterminado: 1s]
-g, --grace-duration=DURACION_GRACIA
El período de tiempo para esperar respuestas ICMP adicionales después de que el objetivo haya respondido [predeterminado: 100ms]
--initial-sequence=SECUENCIA_INICIAL
El número de secuencia inicial [predeterminado: 33434]
-R, --multipath-strategy=ESTRATEGIA_MULTIPATH
La estrategia de enrutamiento de rutas múltiples de igual costo (solo UDP) [predeterminado: classic]

Valores posibles:

  • classic: El puerto de origen o destino se utiliza para almacenar el número de secuencia
  • paris: El campo `checksum` de UDP se utiliza para almacenar el número de secuencia
  • dublin: El campo `identifier` de IP se utiliza para almacenar el número de secuencia
-U, --max-inflight=MAX_EN_CURSO
El número máximo de solicitudes de eco ICMP en curso [predeterminado: 24]
-f, --first-ttl=PRIMER_TTL
El TTL desde el cual comenzar [predeterminado: 1]
-t, --max-ttl=MAX_TTL
El número máximo de saltos TTL [predeterminado: 64]
--packet-size=TAMANO_PAQUETE
El tamaño del paquete IP a enviar (encabezado IP + encabezado ICMP + carga útil) [predeterminado: 84]
--payload-pattern=PATRON_CARGA
El patrón repetido en la carga útil del paquete ICMP [predeterminado: 0]
-Q, --tos=TOS
El valor del encabezado IP TOS (es decir, DSCP + ECN) (solo IPv4) [predeterminado: 0]
-e, --icmp-extensions
Analizar extensiones ICMP
--read-timeout=TIEMPO_ESPERA_LECTURA
El tiempo de espera de lectura del socket [predeterminado: 10ms]
-r, --dns-resolve-method=METODO_RESOLUCION_DNS
Cómo realizar consultas DNS [predeterminado: system]

Valores posibles:

  • system: Resolver usando el resolvedor del sistema operativo
  • resolv: Resolver usando la configuración DNS de `/etc/resolv.conf`
  • google: Resolver usando el servicio DNS de Google `8.8.8.8`
  • cloudflare: Resolver usando el servicio DNS de Cloudflare `1.1.1.1`
-y, --dns-resolve-all
Rastrear a todas las IPs resueltas de la consulta DNS [predeterminado: false]
--dns-timeout=TIEMPO_ESPERA_DNS
El tiempo máximo de espera para realizar consultas DNS [predeterminado: 5s]
--dns-ttl=DNS_TTL
El tiempo de vida (TTL) de las entradas DNS [predeterminado: 300s]
-z, --dns-lookup-as-info
Buscar información del sistema autónomo (AS) durante las consultas DNS [predeterminado: false]
-s, --max-samples=MAX_MUESTRAS
El número máximo de muestras a registrar por salto [predeterminado: 100]

NAME

trip - trace and network diagnostic tool

SYNOPSIS

trip

    [OPTIONS] [TARGETS]...

DESCRIPTION

This tool traces the network path to a target, showing all hops along the way. It aims to provide a more user-friendly and informative experience than traditional tools like traceroute.

When run without arguments, it will run interactively.

OPTIONS

--addresses-mode=ADDRESSES_MODE
How to render IP addresses [default: both]

Possible values:

  • ip: Show IP address only
  • host: Show reverse-lookup DNS hostname only
  • both: Show both IP address and reverse-lookup DNS hostname
-c, --count=COUNT
Number of probes per hop [default: 3]
-d, --debug
Enable debug logging
-f, --first-hop=FIRST_HOP
The first hop to use
-I, --interface=INTERFACE
The network interface to use
-i, --interval=INTERVAL
Interval between probes [default: 1s]
-L, --max-hops=MAX_HOPS
Maximum number of hops to probe [default: 64]
--max-flows=MAX_FLOWS
The maximum number of flows to record [default: 64]
-a, --tui-address-mode=TUI_ADDRESS_MODE
How to render addresses [default: host]

Possible values:

  • ip: Show IP address only
  • host: Show reverse-lookup DNS hostname only
  • both: Show both IP address and reverse-lookup DNS hostname
--tui-as-mode=TUI_AS_MODE
How to render autonomous system (AS) information [default: asn]

Possible values:

  • asn: Show the ASN
  • prefix: Display the AS prefix
  • country-code: Display the country code
  • registry: Display the registry name
  • allocated: Display the allocated date
  • name: Display the AS name
--tui-custom-columns=TUI_CUSTOM_COLUMNS
Custom columns to be displayed in the TUI hops table [default: holsravbwdt]
--tui-icmp-extension-mode=TUI_ICMP_EXTENSION_MODE
How to render ICMP extensions [default: off]

Possible values:

  • off: Do not show `icmp` extensions
  • mpls: Show MPLS label(s) only
  • full: Show full `icmp` extension data for all known extensions
  • all: Show full `icmp` extension data for all classes
--tui-geoip-mode=TUI_GEOIP_MODE
How to render GeoIp information [default: short]

Possible values:

  • off: Do not display GeoIp data
  • short: Show short format
  • long: Show long format
  • location: Show latitude and Longitude format
-M, --tui-max-addrs=TUI_MAX_ADDRS
The maximum number of addresses to show per hop [default: auto]
--tui-preserve-screen
Preserve the screen on exit [default: false]
--tui-refresh-rate=TUI_REFRESH_RATE
The TUI refresh rate [default: 100ms]
--tui-privacy-max-ttl=TUI_PRIVACY_MAX_TTL
The maximum ttl of hops which will be masked for privacy [default: none]

If set, the source IP address and hostname will also be hidden.

--tui-locale=TUI_LOCALE
The locale to use for the TUI [default: auto]
--tui-timezone=TUI_TIMEZONE
The timezone to use for the TUI [default: auto]

The timezone must be a valid IANA timezone identifier.

--tui-theme-colors=TUI_THEME_COLORS
The TUI theme colors [item=color,item=color,..]
--print-tui-theme-items
Print all TUI theme items and exit
--tui-key-bindings=TUI_KEY_BINDINGS
The TUI key bindings [command=key,command=key,..]
--print-tui-binding-commands
Print all TUI commands that can be bound and exit
-C, --report-cycles=REPORT_CYCLES
The number of report cycles to run [default: 10]
-G, --geoip-mmdb-file=GEOIP_MMDB_FILE
The supported MaxMind or IPinfo GeoIp mmdb file
--generate=GENERATE
Generate shell completion

[possible values: bash, elvish, fish, powershell, zsh]

--generate-man
Generate ROFF man page
--print-config-template
Print a template toml config file and exit
--print-locales
Print all available TUI locales and exit
--log-format=LOG_FORMAT
The debug log format [default: pretty]

Possible values:

  • compact: Display log data in a compact format
  • pretty: Display log data in a pretty format
  • json: Display log data in a json format
  • chrome: Display log data in Chrome trace format
--log-filter=LOG_FILTER
The debug log filter [default: trippy=debug]
--log-span-events=LOG_SPAN_EVENTS
The debug log format [default: off]

Possible values:

  • off: Do not display event spans
  • active: Display enter and exit event spans
  • full: Display all event spans
-v, --verbose
Enable verbose debug logging
-h, --help
Print help (see a summary with '-h')
-V, --version
Print version
[TARGETS]
A space delimited list of hostnames and IPs to trace
