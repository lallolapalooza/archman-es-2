tracefs_hist_add_sort_key(3)

Paquete: libtracefs

Licencias: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_hist_add_sort_key, tracefs_hist_set_sort_key, tracefs_hist_sort_key_direction, tracefs_hist_add_name, tracefs_hist_append_filter, tracefs_hist_echo_cmd, tracefs_hist_command, tracefs_hist_get_name, tracefs_hist_get_event, tracefs_hist_get_system - Actualizar y describir un histograma de eventos

SINOPSIS

#include <tracefs.h>
int tracefs_hist_add_sort_key(struct tracefs_hist *hist,
                              const char *sort_key);
int tracefs_hist_set_sort_key(struct tracefs_hist *hist,
                              const char *sort_key, ...);
int tracefs_hist_sort_key_direction(struct tracefs_hist *hist,
                                    const char *sort_key,
                                    enum tracefs_hist_sort_direction dir);
int tracefs_hist_add_name(struct tracefs_hist *hist, const char *name);
int tracefs_hist_append_filter(struct tracefs_hist *hist,
                               enum tracefs_filter type,
                               const char *field,
                               enum tracefs_compare compare,
                               const char *val);
int tracefs_hist_echo_cmd(struct trace_seq *s, struct tracefs_instance *instance,
                          struct tracefs_hist *hist,
                          enum tracefs_hist_command command);
int tracefs_hist_command(struct tracefs_instance *instance,
                         struct tracefs_hist *hist,
                         enum tracefs_hist_command command);
const char *tracefs_hist_get_name(struct tracefs_hist *hist);
const char *tracefs_hist_get_event(struct tracefs_hist *hist);
const char *tracefs_hist_get_system(struct tracefs_hist *hist);

DESCRIPCIÓN

Los histogramas de eventos se crean mediante el archivo trigger en el directorio del evento. La sintaxis puede ser compleja y difícil de obtener correctamente. Esta API maneja la sintaxis y facilita la creación e interacción con los histogramas de eventos. Consulte https://www.kernel.org/doc/html/latest/trace/histogram.html para más información.

tracefs_hist_add_sort_key() añadirá una clave para ordenar. El hist es el descriptor del histograma al que se añadirá la clave de ordenación. El sort_key es una cadena que debe coincidir con una clave ya definida del histograma o con un valor ya definido. Si hist ya tiene claves de ordenación (añadidas previamente), la nueva sort_key tendrá menor prioridad (será secundaria, etc.) al ordenar.

tracefs_hist_set_sort_key() restablecerá la lista de claves para ordenar. El hist es el descriptor del histograma al que se restablecerá la clave de ordenación. El sort_key es una cadena que debe coincidir con una clave ya definida del histograma o con un valor ya definido. Se pueden añadir múltiples claves de ordenación para denotar un orden de clasificación secundario, terciario, etc., pero todas las claves de ordenación deben coincidir con una clave o valor existente, o ser TRACEFS_HIST_HITCOUNT. El último parámetro de tracefs_hist_add_sort_key() debe ser NULL.

tracefs_hist_sort_key_direction() permite cambiar la dirección de una clave de ordenación existente de hist. El sort_key es la clave de ordenación a cambiar, y dir puede ser TRACEFS_HIST_SORT_ASCENDING o TRACEFS_HIST_SORT_DESCENDING, para hacer que la dirección de la clave de ordenación sea ascendente o descendente respectivamente.

tracefs_hist_add_name() añade un nombre a un histograma. Un histograma puede ser nombrado y si el nombre coincide entre más de un evento, y tienen claves compatibles, los múltiples histogramas con el mismo nombre se fusionarán en un único histograma (mostrado por el archivo hist de cualquiera de los eventos). El hist es el histograma al que nombrar, y name es el nombre a darle.

tracefs_hist_append_filter() crea un filtro o se le añade para el evento del histograma. Dependiendo de type, construirá una cadena de tokens para paréntesis o sentencias lógicas, o puede añadir una comparación de field a val basada en compare.

Si type es: TRACEFS_FILTER_COMPARE - Ver abajo TRACEFS_FILTER_AND - Añadir "&&" al filtro TRACEFS_FILTER_OR - Añadir "||" al filtro TRACEFS_FILTER_NOT - Añadir "!" al filtro TRACEFS_FILTER_OPEN_PAREN - Añadir "(" al filtro TRACEFS_FILTER_CLOSE_PAREN - Añadir ")" al filtro

field, compare y val se ignoran a menos que type sea igual a TRACEFS_FILTER_COMPARE, entonces compare se usará para lo siguiente:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : donde field es una cadena.

TRACEFS_COMPARE_AND - field & val : donde field es un campo de flags.

trace_hist_echo_cmd() imprime los comandos necesarios para crear el histograma dado en la instance dada, o NULL para el nivel superior, en el seq. El comando que se imprime está descrito por command y muestra la funcionalidad que realizaría tracefs_hist_command(3).

tracefs_hist_command() se llama para procesar un comando en el histograma hist para su evento en la instance dada, o NULL para el nivel superior. El cmd puede ser uno de:

TRACEFS_HIST_CMD_START o cero para iniciar la ejecución del histograma.

TRACEFS_HIST_CMD_PAUSE para pausar el histograma dado.

TRACEFS_HIST_CMD_CONT para continuar un histograma pausado.

TRACEFS_HIST_CMD_CLEAR para restablecer los valores de un histograma.

TRACEFS_HIST_CMD_DESTROY para destruir el histograma (deshacer un START).

Las siguientes funciones son envoltorios para tracefs_hist_command() para hacer las convenciones de llamada un poco más fáciles de entender lo que está sucediendo.

TIPOS DE CLAVE

tracefs_hist_alloc_nd() y tracefs_hist_add_key() ambos añaden una clave y requieren que esa clave tenga un tipo. Los tipos pueden ser:

TRACEFS_HIST_KEY_NORMAL o cero (0) que es no modificar el tipo.

TRACEFS_HIST_KEY_HEX para mostrar la clave en hexadecimal.

TRACEFS_HIST_KEY_SYM para mostrar la clave como un símbolo del kernel (si se encuentra). Si la clave es una dirección, esto es útil ya que mostrará los nombres de las funciones en lugar de solo un número.

TRACEFS_HIST_KEY_SYM_OFFSET similar a TRACEFS_HIST_KEY_SYM pero también incluirá el desplazamiento de la función para coincidir con la dirección exacta.

TRACEFS_HIST_KEY_SYSCALL Si la clave es un ID de llamada al sistema (el número pasado desde el espacio de usuario al kernel para indicarle qué llamada al sistema está haciendo), entonces se mostrará el nombre de la llamada al sistema.

TRACEFS_HIST_KEY_EXECNAME Si "common_pid" es la clave (el pid de la tarea en ejecución), en lugar de mostrar el número, mostrar el nombre de la tarea en ejecución.

TRACEFS_HIST_KEY_LOG mostrará la clave en una escala logarítmica binaria.

TRACEFS_HIST_KEY_USECS para usar con "common_timestamp" o TRACEFS_HIST_TIMESTAMP, en cuyo caso mostrará la marca de tiempo en microsegundos en lugar de nanosegundos.

VALOR DE RETORNO

tracefs_hist_get_name() devuelve el nombre del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto del histograma y se libera junto con el histograma por tracefs_hist_free().

tracefs_hist_get_event() devuelve el nombre del evento del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto del histograma y se libera junto con el histograma por tracefs_hist_free().

tracefs_hist_get_system() devuelve el nombre del sistema del histograma o NULL en caso de error. La cadena devuelta pertenece al objeto del histograma y se libera junto con el histograma por tracefs_hist_free().

tracefs_hist_alloc_nd() devuelve un descriptor de histograma asignado que debe ser liberado por tracefs_hist_free() o NULL en caso de error.

DESCRIPTION

The tracefs_hist_get_event(), tracefs_hist_get_system() and tracefs_hist_get_instance() functions return strings owned by the histogram object.

All the other functions return zero on success or -1 on error.

EXAMPLE

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Failed to allocate axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else {
                                fprintf(stderr, "Undefined attribute '%s'\n", att);
                                fprintf(stderr,"  Acceptable attributes:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Failed instance create\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Could not read events");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Reading hist file");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "Command needs -k option\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "No keys??\n");
                exit(-1);
        }
        /* Show examples of hist1d and hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Really, 1 and 2 could use this too */
                hist = tracefs_hist_alloc_nd(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Failed hist create\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add value %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add sort key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add ascending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add descending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* Show was already done */
                break;
        }
        if (ret)
                fprintf(stderr, "Failed: command\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Unknown command %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

tracefs_hist_add_sort_key(3)

NAME

tracefs_hist_add_sort_key, tracefs_hist_sort_keys, tracefs_hist_clear_sort_keys - add/get/clear sort keys from a trace event histogram

SYNOPSIS

#include <tracefs.h>

int
tracefs_hist_add_sort_key(struct tracefs_event *event,
    const char *key);
const char **
tracefs_hist_sort_keys(struct tracefs_event *event);
int
tracefs_hist_clear_sort_keys(struct tracefs_event *event);

DESCRIPTION

The trace event histogram feature allows to sort the output of the histogram by different keys. The keys are a subset of the fields of the trace event itself.

The function tracefs_hist_add_sort_key() adds the string key as a sort key to the specified trace event. The event must have been opened with tracefs_open() and it must have histogram tracing enabled via tracefs_hist_enable().

The function tracefs_hist_sort_keys() returns a NULL-terminated array of strings representing the current sort keys of the trace event event. If there are no sort keys set, it will return a NULL pointer.

The function tracefs_hist_clear_sort_keys() removes all previously added sort keys from the trace event event.

KEY TYPES

The available keys depend on the trace event. Some common keys include:

•
pid
•
comm
•
common_fields.stack_depth
•
common_fields.preempt_count

Refer to the specific trace event's format definition for a complete list of available fields that can be used as sort keys.

RETURN VALUE

On success, tracefs_hist_add_sort_key() and tracefs_hist_clear_sort_keys() return 0. On failure, they return a negative value indicating the error.

tracefs_hist_sort_keys() returns a pointer to the array of sort keys, or NULL if no sort keys are set or if an error occurred.

EXAMPLE

        struct tracefs_event *event;
        const char **keys;
        int ret;

        event = tracefs_open("sched_switch");
        if (!event) {
            perror("tracefs_open");
            return 1;
        }

        ret = tracefs_hist_enable(event, 1024); /* Enable histogram with 1024 entries */
        if (ret < 0) {
            fprintf(stderr, "tracefs_hist_enable failed: %s\n", strerror(-ret));
            tracefs_close(event);
            return 1;
        }

        /* Add 'pid' and 'comm' as sort keys */
        ret = tracefs_hist_add_sort_key(event, "pid");
        if (ret < 0) {
            fprintf(stderr, "tracefs_hist_add_sort_key(pid) failed: %s\n", strerror(-ret));
        }
        ret = tracefs_hist_add_sort_key(event, "comm");
        if (ret < 0) {
            fprintf(stderr, "tracefs_hist_add_sort_key(comm) failed: %s\n", strerror(-ret));
        }

        /* Get the current sort keys */
        keys = tracefs_hist_sort_keys(event);
        if (keys) {
            printf("Current sort keys:\n");
            for (int i = 0; keys[i]; i++) {
                printf(" - %s\n", keys[i]);
            }
        } else {
            printf("No sort keys are set.\n");
        }

        /* Clear the sort keys */
        ret = tracefs_hist_clear_sort_keys(event);
        if (ret < 0) {
            fprintf(stderr, "tracefs_hist_clear_sort_keys failed: %s\n", strerror(-ret));
        }

        tracefs_close(event);
