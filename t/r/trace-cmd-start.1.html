TRACE-CMD-START(1) Manual de libtracefs TRACE-CMD-START(1)

NOMBRE

trace-cmd-start - inicia el rastreador del kernel de Ftrace sin registrar

SINOPSIS

trace-cmd start [OPCIONES]

DESCRIPCIÓN

El trace-cmd(1) start habilita todo el rastreo de Ftrace de la misma manera que lo hace trace-cmd-record(1). La diferencia es que no ejecuta hilos para crear un archivo trace.dat. Esto es útil solo para habilitar Ftrace y usted solo está interesado en el rastro después de que ha ocurrido algún evento y se ha detenido el rastro. Luego, el rastro se puede leer directamente del sistema de archivos pseudo de Ftrace o se puede extraer con trace-cmd-extract(1).

OPCIONES

Las opciones son las mismas que las de trace-cmd-record(1), excepto que no toma opciones específicas para grabar (-s, -o, -N y -t).

--fork

Esta opción solo está disponible para trace-cmd start. Indica a trace-cmd que no espere a que el proceso termine antes de regresar. Con esta opción, trace-cmd start regresará justo después de crear el proceso en la línea de comandos. Esta opción solo tiene un efecto si trace-cmd start también ejecuta un comando.
