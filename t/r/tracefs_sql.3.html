NOMBRE

tracefs_sql - Crear un evento sintético a través de una sentencia SQL

SINOPSIS

#include <tracefs.h>
struct tracefs_synth *tracefs_sql(struct tep_handle *tep, const char *name,
                                        const char *sql_buffer, char **err);

DESCRIPCIÓN

Los eventos sintéticos son eventos creados dinámicamente que unen dos eventos existentes a través de uno o más campos coincidentes entre los dos eventos. Se puede utilizar para encontrar la latencia entre los eventos, o simplemente para pasar campos del primer evento al segundo para mostrarlos como un solo evento.

La interfaz del kernel de Linux para crear eventos sintéticos es compleja, y se necesita una mejor manera de crear eventos sintéticos que sea fácil y comprensible a través de la tecnología existente.

Si piensas en cada evento como una tabla, donde los campos son las columnas de la tabla y cada instancia del evento como una fila, puedes entender cómo se puede usar SQL para unir dos eventos y formar otro evento (tabla). Utilizando la sintaxis SQL SELECT FROM JOIN ON [ WHERE ], se puede crear fácilmente un evento sintético a partir de dos eventos diferentes.

Para consultas SQL simples que crean un histograma en lugar de un evento sintético, consulte HISTOGRAMAS más abajo.

tracefs_sql() toma un manejador tep (ver tep_local_events(3)) que se utiliza para verificar los eventos dentro de la expresión sql_buffer. El name es el nombre del evento sintético a crear. Si err apunta a la dirección de una cadena, se llenará con un mensaje detallado sobre cualquier tipo de error de análisis, incluyendo campos que no pertenecen a un evento, o si los eventos o campos no se comparan correctamente.

El programa de ejemplo a continuación es un analizador totalmente funcional que creará un evento sintético a partir de una sintaxis SQL pasada por línea de comandos o archivo.

El formato SQL es el siguiente:

SELECT <campos> FROM <evento-inicio> JOIN <evento-fin> ON <campos-coincidentes> WHERE <filtro>

Nota, aunque los ejemplos muestran los comandos SQL en mayúsculas, no es obligatorio. Es decir, puedes usar "SELECT" o "select" o "sElEct".

Por ejemplo:

SELECT syscalls.sys_enter_read.fd, syscalls.sys_exit_read.ret FROM syscalls.sys_enter_read
   JOIN syscalls.sys_exit_read
   ON syscalls.sys_enter_read.common_pid = syscalls.sys_exit_write.common_pid

Creará un evento sintético con los campos:

u64 fd; s64 ret;

Dado que la función toma un manejador tep, y generalmente todos los nombres de eventos son únicos, puedes omitir el nombre del sistema (grupo) del evento, y tracefs_sql() lo descubrirá por ti.

Es decir, la sentencia anterior funcionaría con:

SELECT sys_enter_read.fd, sys_exit_read.ret FROM sys_enter_read JOIN sys_exit_read
   ON sys_enter_read.common_pid = sys_exit_write.common_pid

La palabra clave AS se puede utilizar para nombrar los campos, así como para dar un alias a los eventos, de modo que lo anterior se puede simplificar aún más como:

SELECT start.fd, end.ret FROM sys_enter_read AS start JOIN sys_exit_read AS end ON start.common_pid = end.common_pid

Lo anterior aliasa sys_enter_read como start y sys_exit_read como end y utiliza esos alias para referenciar el evento a lo largo de la sentencia.

El uso de la palabra clave AS en la porción de selección de la sentencia SQL definirá cómo se llamarán esos campos en el evento sintético.

SELECT start.fd AS filed, end.ret AS return FROM sys_enter_read AS start JOIN sys_exit_read AS end
   ON start.common_pid = end.common_pid

Lo anterior etiqueta el fd de start como filed y el ret de end como return, donde el evento sintético que se crea ahora tendrá los campos:

u64 filed; s64 return;

Los campos también se pueden calcular con los resultados pasados al evento sintético:

select start.truesize, end.len, (start.truesize - end.len) as diff from napi_gro_receive_entry as start
   JOIN netif_receive_skb as end ON start.skbaddr = end.skbaddr

Lo que mostraría el truesize del evento napi_gro_receive_entry, la longitud real len del contenido, mostrada por el netif_receive_skb, y la diferencia entre ambos, expresada por el campo diff.

El código también soporta el registro de las marcas de tiempo en cualquiera de los eventos y la realización de cálculos sobre ellas. Para la latencia de activación, tienes:

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid

Lo anterior creará un evento sintético que registra el pid de la tarea que se está despertando, y la diferencia de tiempo entre el evento sched_waking y el evento sched_switch. TIMESTAMP_USECS truncará el tiempo a microsegundos ya que la marca de tiempo normalmente registrada en el búfer de rastreo tiene resolución de nanosegundos. Si no deseas esa truncación, usa TIMESTAMP en lugar de TIMESTAMP_USECS.

Dado que es muy común tener:

   (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS)

Lo anterior puede representarse con TIMESTAMP_DELTA_USECS o, si los nanosegundos están bien, puedes usar TIMESTAMP_DELTA. Es decir, el `SELECT` anterior también puede ser representado por:

select start.pid, TIMESTAMP_DELTA_USECS as lat from sched_waking as start JOIN sched_switch as end ON start.pid = end.next_pid

Finalmente, se puede añadir la cláusula WHERE, que te permitirá añadir filtros a uno o ambos eventos.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 && (!(end.prev_pid < 1 || end.prev_prio > 100) || end.prev_pid == 0)

NOTA

Aunque ambos eventos se pueden usar juntos en la cláusula WHERE, no deben mezclarse fuera de las sentencias "&&" de nivel superior. No puedes hacer OR (||) los eventos, donde un filtro de un evento se hace OR con un filtro de otro evento. Esto no tiene sentido, ya que el evento sintético requiere que ambos eventos ocurran para ser registrados. Si uno es filtrado, entonces el evento sintético no se ejecuta.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 && end.prev_prio < 100

Lo anterior es válido.

Mientras que lo siguiente no lo es.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 || end.prev_prio < 100

Si el kernel lo soporta, puedes pasar una traza de pila entre eventos.

select start.prev_pid as pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as delta, start.STACKTRACE as stack
   FROM sched_switch as start JOIN sched_switch as end ON start.prev_pid = end.next_pid
   WHERE start.prev_state == 2

Lo anterior registrará una traza de pila cuando una tarea esté en el estado NO INTERRUMPIBLE (bloqueado) y activará el evento sintético cuando se programe de nuevo, registrando la diferencia de tiempo que estuvo bloqueado. Registrará la traza de pila de dónde estaba cuando se desprogramó junto con la delta.

PALABRAS CLAVE COMO CAMPOS DE EVENTOS

En algunos casos, un evento puede tener una palabra clave. Por ejemplo, regcache_drop_region tiene "from" como campo y lo siguiente no funcionará

  select from from regcache_drop_region

En tales casos, añada una barra invertida al campo en conflicto, y esto le dirá al analizador que "from" es un campo y no una palabra clave:

  select \from from regcache_drop_region

HISTOGRAMAS

Sentencias SQL simples sin la cláusula JOIN ON también se puede usar, lo que creará un histograma en su lugar. Al hacerlo, el descriptor `tracefs_hist` se puede recuperar del descriptor de evento sintético devuelto a través de `tracefs_synth_get_start_hist(3).

Para utilizar los tipos de histograma (ver xxx), se puede usar el comando CAST de SQL.

Es decir:

  select CAST(common_pid AS comm), CAST(id AS syscall) FROM sys_enter

Lo que produce:

Tenga en cuenta que los campos de cadena de caracteres no se pueden convertir.

Los tipos posibles a los que se puede convertir son:

HEX - convierte el valor para usar hexadecimal y no decimal

SYM - convierte un puntero a simbólico (valores kallsyms)

SYM-OFFSET - convierte un puntero a simbólico e incluye el desplazamiento.

SYSCALL - convierte el número al nombre de llamada al sistema mapeado

EXECNAME o COMM - solo se puede usar con el campo `common_pid`. Mostrará el nombre de la tarea del proceso.

LOG o LOG2 - agrupa los valores de clave en un logaritmo base 2 (1, 2, 3-4, 5-8, 9-16, 17-32, ...)

Los campos anteriores no distinguen entre mayúsculas y minúsculas, y "LOG2" funciona tan bien como "log".

Un CAST especial a `_COUNTER_` hará que el campo sea un valor y no una clave. Por ejemplo:

  SELECT common_pid, CAST(bytes_req AS _COUNTER_) FROM kmalloc

Lo que creará:

  echo 'hist:keys=common_pid:vals=bytes_req' > events/kmem/kmalloc/trigger
  cat events/kmem/kmalloc/hist
{ common_pid:       1812 } hitcount:          1  bytes_req:         32
{ common_pid:       9111 } hitcount:          2  bytes_req:        272
{ common_pid:       1768 } hitcount:          3  bytes_req:       1112
{ common_pid:          0 } hitcount:          4  bytes_req:        512
{ common_pid:      18297 } hitcount:         11  bytes_req:       2004

VALOR DE RETORNO

Devuelve 0 en caso de éxito y -1 en caso de error. En caso de error, si `err` está definido, se asignará para contener una descripción detallada de lo que salió mal si el error fue causado por un error de análisis, o que un evento o campo no existe o no es compatible con lo que se combinó.

CREAR UNA HERRAMIENTA

El siguiente ejemplo es un programa funcional que se puede utilizar para analizar comandos SQL en eventos sintéticos.

   man tracefs_sql | sed -ne '/^EXAMPLE/,/FILES/ { /EXAMPLE/d ; /FILES/d ; p}' > sqlhist.c
   gcc -o sqlhist sqlhist.c `pkg-config --cflags --libs libtracefs`

Luego puede ejecutar los ejemplos anteriores:

  sudo ./sqlhist 'select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
                  JOIN sched_switch as end ON start.pid = end.next_pid
                  WHERE start.prio < 100 || end.prev_prio < 100'

EJEMPLO

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
#include <string.h>
#include <errno.h>
#include <unistd.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [-ed][-n name][-s][-S fields][-m var][-c var][-T][-t dir][-f file | sql-command-line]\n"
                "  -n name - name of synthetic event 'Anonymous' if left off\n"
                "  -t dir - use dir instead of /sys/kernel/tracing\n"
                "  -e - execute the commands to create the synthetic event\n"
                "  -m - trigger the action when var is a new max.\n"
                "  -c - trigger the action when var changes.\n"
                "  -s - used with -m or -c to do a snapshot of the tracing buffer\n"
                "  -S - used with -m or -c to save fields of the end event (comma deliminated)\n"
                "  -T - used with -m or -c to do both a snapshot and a trace\n"
                "  -f file - read sql lines from file otherwise from the command line\n"
                "            if file is '-' then read from standard input.\n",
                argv[0]);
        exit(-1);
}
enum action {
        ACTION_DEFAULT          = 0,
        ACTION_SNAPSHOT         = (1 << 0),
        ACTION_TRACE            = (1 << 1),
        ACTION_SAVE             = (1 << 2),
        ACTION_MAX              = (1 << 3),
        ACTION_CHANGE           = (1 << 4),
};
#define ACTIONS ((ACTION_MAX - 1))
static int do_sql(const char *instance_name,
                  const char *buffer, const char *name, const char *var,
                  const char *trace_dir, bool execute, int action,
                  char **save_fields)
{
        struct tracefs_synth *synth;
        struct tep_handle *tep;
        struct trace_seq seq;
        enum tracefs_synth_handler handler;
        char *err;
        int ret;
        if ((action & ACTIONS) && !var) {
                fprintf(stderr, "Error: -s, -S and -T not supported without -m or -c");
                exit(-1);
        }
        if (!name)
                name = "Anonymous";
        trace_seq_init(&seq);
        tep = tracefs_local_events(trace_dir);
        if (!tep) {
                if (!trace_dir)
                        trace_dir = "tracefs directory";
                perror(trace_dir);
                exit(-1);
        }
        synth = tracefs_sql(tep, name, buffer, &err);
        if (!synth) {
                perror("Failed creating synthetic event!");
                if (err)
                        fprintf(stderr, "%s", err);
                free(err);
                exit(-1);
        }
        if (tracefs_synth_complete(synth)) {
                if (var) {
                        if (action & ACTION_MAX)
                                handler = TRACEFS_SYNTH_HANDLE_MAX;
                        else
                                handler = TRACEFS_SYNTH_HANDLE_CHANGE;
                        if (action & ACTION_SAVE) {
                                ret = tracefs_synth_save(synth, handler, var, save_fields);
                                if (ret < 0) {
                                        err = "adding save";
                                        goto failed_action;
                                }
                        }
                        if (action & ACTION_TRACE) {
                                /*
                                 * By doing the trace before snapshot, it will be included
                                 * in the snapshot.
                                 */
                                ret = tracefs_synth_trace(synth, handler, var);
                                if (ret < 0) {
                                        err = "adding trace";
                                        goto failed_action;
                                }
                        }
                        if (action & ACTION_SNAPSHOT) {
                                ret = tracefs_synth_snapshot(synth, handler, var);
                                if (ret < 0) {
                                        err = "adding snapshot";
 failed_action:
                                        perror(err);
                                        if (errno == ENODEV)
                                                fprintf(stderr, "ERROR: '%s' is not a variable\n",
                                                        var);
                                        exit(-1);
                                }
                        }
                }
                tracefs_synth_echo_cmd(&seq, synth);
                if (execute) {
                        ret = tracefs_synth_create(synth);
                        if (ret < 0) {
                                fprintf(stderr, "%s\n", tracefs_error_last(NULL));
                                exit(-1);
                        }
                }
        } else {
                struct tracefs_instance *instance = NULL;
                struct tracefs_hist *hist;
                hist = tracefs_synth_get_start_hist(synth);
                if (!hist) {
                        perror("get_start_hist");
                        exit(-1);
                }
                if (instance_name) {
                        if (execute)
                                instance = tracefs_instance_create(instance_name);
                        else
                                instance = tracefs_instance_alloc(trace_dir,
                                                                  instance_name);
                        if (!instance) {
                                perror("Failed to create instance");
                                exit(-1);
                        }
                }
                tracefs_hist_echo_cmd(&seq, instance, hist, 0);
                if (execute) {
                        ret = tracefs_hist_start(instance, hist);
                        if (ret < 0) {
                                fprintf(stderr, "%s\n", tracefs_error_last(instance));
                                exit(-1);
                        }
                }
        }
        tracefs_synth_free(synth);
        trace_seq_do_printf(&seq);
        trace_seq_destroy(&seq);
        return 0;
}
int main (int argc, char **argv)
{
        char *trace_dir = NULL;
        char *buffer = NULL;
        char buf[BUFSIZ];
        int buffer_size = 0;
        const char *file = NULL;
        const char *instance = NULL;
        bool execute = false;
        char **save_fields = NULL;
        const char *name;
const char *var;
int action = 0;
char *tok;
FILE *fp;
size_t r;
int c;
int i;
for (;;) {
    c = getopt(argc, argv, "ht:f:en:m:c:sS:TB:");
    if (c == -1)
        break;
    switch(c) {
    case 'h':
        usage(argv);
    case 't':
        trace_dir = optarg;
        break;
    case 'f':
        file = optarg;
        break;
    case 'e':
        execute = true;
        break;
    case 'm':
        action |= ACTION_MAX;
        var = optarg;
        break;
    case 'c':
        action |= ACTION_CHANGE;
        var = optarg;
        break;
    case 's':
        action |= ACTION_SNAPSHOT;
        break;
    case 'S':
        action |= ACTION_SAVE;
        tok = strtok(optarg, ",");
        while (tok) {
            save_fields = tracefs_list_add(save_fields, tok);
            tok = strtok(NULL, ",");
        }
        if (!save_fields) {
            perror(optarg);
            exit(-1);
        }
        break;
    case 'T':
        action |= ACTION_TRACE | ACTION_SNAPSHOT;
        break;
    case 'B':
        instance = optarg;
        break;
    case 'n':
        name = optarg;
        break;
    }
}
if ((action & (ACTION_MAX|ACTION_CHANGE)) == (ACTION_MAX|ACTION_CHANGE)) {
    fprintf(stderr, "Can not use both -m and -c together\n");
    exit(-1);
}
if (file) {
    if (!strcmp(file, "-"))
        fp = stdin;
    else
        fp = fopen(file, "r");
    if (!fp) {
        perror(file);
        exit(-1);
    }
    while ((r = fread(buf, 1, BUFSIZ, fp)) > 0) {
        buffer = realloc(buffer, buffer_size + r + 1);
        strncpy(buffer + buffer_size, buf, r);
        buffer_size += r;
    }
    fclose(fp);
    if (buffer_size)
        buffer[buffer_size] = '\0';
} else if (argc == optind) {
    usage(argv);
} else {
    for (i = optind; i < argc; i++) {
        r = strlen(argv[i]);
        buffer = realloc(buffer, buffer_size + r + 2);
        if (i != optind)
            buffer[buffer_size++] = ' ';
        strcpy(buffer + buffer_size, argv[i]);
        buffer_size += r;
    }
}
do_sql(instance, buffer, name, var, trace_dir, execute, action, save_fields);
free(buffer);
return 0;
