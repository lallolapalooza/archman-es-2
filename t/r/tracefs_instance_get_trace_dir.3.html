LIBTRACEFS(3) Manual de libtracefs LIBTRACEFS(3)

NOMBRE

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Funciones auxiliares para trabajar con instancias de trazado.

SINOPSIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPCIÓN

Funciones auxiliares para trabajar con instancias de trazado.

La función tracefs_instance_get_name() devuelve el nombre de la instance dada. Tenga en cuenta que la instancia superior no tiene nombre; la función devuelve NULL para ella.

La función tracefs_instance_get_trace_dir() devuelve el directorio de trazado donde está configurada la instance dada.

La función tracefs_instances_walk() recorre todas las instancias de trazado configuradas en el sistema y llama a callback para cada una de ellas. El argumento context se pasa al callback, junto con el nombre de la instancia. Si el callback devuelve un valor distinto de cero, la iteración se detiene. Tenga en cuenta que el callback no se llama para la instancia superior.

La función tracefs_instance_exists() comprueba si una instancia con el name dado existe en el sistema.

La función tracefs_instace_get_buffer_size() devuelve el tamaño del búfer de anillo. Si cpu es negativo, devuelve el tamaño total de todos los búferes de anillo por CPU; de lo contrario, devuelve el tamaño del búfer de anillo por CPU para cpu.

La función tracefs_instance_set_buffer_size() establece el tamaño del búfer de anillo. Si cpu es negativo, establece todos los búferes de anillo por CPU a size (tenga en cuenta que el tamaño total es el número de CPUs * size). Si se especifica cpu, solo establece el tamaño del búfer de anillo por CPU.

La función tracefs_instance_set_buffer_percent() establece el valor de porcentaje del búfer del búfer de anillo de trazado para instance o el búfer de nivel superior si instance es NULL. El porcentaje del búfer decide cuándo los lectores en tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) y tracefs_cpu_pipe(3) se bloquearán cuando O_NONBLOCK no esté configurado. El valor de val debe estar entre 0 y 100, donde:

  0   - bloquear hasta que haya datos en el búfer de anillo
  1   - bloquear hasta que se llene el 1% de los sub-búferes del búfer de anillo
  50  - bloquear hasta que se llene el 50% de los sub-búferes del búfer de anillo
  100 - bloquear hasta que se llene todo el búfer de anillo

Tenga en cuenta que se puede usar cualquier número del 0 al 100, donde es el porcentaje del búfer de anillo que debe llenarse antes de que un lector bloqueado sea notificado de que hay datos para recuperar.

La función tracefs_instance_get_buffer_percent() recupera la configuración actual del porcentaje del búfer del búfer de anillo de trazado para instance o el búfer de nivel superior si instance es NULL.

VALOR DE RETORNO

La función tracefs_instance_get_name() devuelve una cadena o NULL en caso de la instancia superior. La cadena devuelta no debe ser liberada.

La función tracefs_instance_get_trace_dir() devuelve una cadena o NULL en caso de error. La cadena devuelta no debe ser liberada.

La función tracefs_instances_walk() devuelve 0 si se iteraron todas las instancias, 1 si la iteración fue detenida por el callback, o -1 en caso de error.

La función tracefs_instance_exists() devuelve verdadero si una instancia con el name dado existe en el sistema o falso en caso contrario.

La función tracefs_instance_get_buffer_size() devuelve el tamaño del búfer de anillo dependiendo del valor cpu pasado, o -1 en caso de error.

La función tracefs_instance_set_buffer_size() devuelve cero en caso de éxito y -1 en caso de error.

NOMBRE

tracefs_instance_get_trace_dir - Obtener el directorio de traza de una instancia de traza.

SINOPSIS

#include <tracefs.h>

const char *
tracefs_instance_get_trace_dir(tracefs_instance_t *instance);

DESCRIPCIÓN

La función tracefs_instance_get_trace_dir devuelve el puntero a una cadena de caracteres que contiene la ruta absoluta al directorio de traza (trace directory) de la instancia de traza especificada por instance.

El directorio de traza es el punto de montaje del sistema de archivos tracefs. Las operaciones de traza (como habilitar/deshabilitar eventos, leer datos de traza) se realizan dentro de este directorio.

La cadena devuelta es un puntero a memoria gestionada por la biblioteca libtracefs y no debe ser modificada ni liberada por el usuario.

VALOR DE RETORNO

En caso de éxito, devuelve un puntero constante a una cadena de caracteres que representa la ruta al directorio de traza. En caso de error (por ejemplo, si instance es NULL o inválido), devuelve NULL.

EJEMPLO

```c #include <stdio.h> #include <tracefs.h> int main() { tracefs_instance_t *instance; const char *trace_dir; // Obtener la instancia predeterminada instance = tracefs_instance_open_default(NULL); if (!instance) { perror("Failed to open default tracefs instance"); return 1; } // Obtener el directorio de traza trace_dir = tracefs_instance_get_trace_dir(instance); if (trace_dir) { printf("Trace directory: %s\n", trace_dir); } else { fprintf(stderr, "Failed to get trace directory\n"); } // Cerrar la instancia tracefs_instance_close(instance); return 0; } ```
