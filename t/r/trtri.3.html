subrutina ctrtri (character uplo, character diag, integer n, complex, dimension( lda, * ) a, integer lda, integer info)

CTRTRI

Propósito:

!>
!> CTRTRI calcula la inversa de una matriz triangular superior o inferior compleja
!> A.
!>
!> Esta es la versión del algoritmo de BLAS de Nivel 3.
!>

Parámetros

UPLO 
!>          UPLO es CHARACTER*1
!>          = 'U':  A es triangular superior;
!>          = 'L':  A es triangular inferior.
!>

DIAG

!>          DIAG es CHARACTER*1
!>          = 'N':  A es triangular no unitaria;
!>          = 'U':  A es triangular unitaria.
!>

N

!>          N es INTEGER
!>          El orden de la matriz A.  N >= 0.
!>

A

!>          A es un array COMPLEX, de dimensión (LDA,N)
!>          En la entrada, la matriz triangular A.  Si UPLO = 'U', la
!>          parte triangular superior de N por N de la matriz A contiene
!>          la matriz triangular superior, y la parte estrictamente triangular
!>          inferior de A no se referencia.  Si UPLO = 'L', la
!>          parte triangular inferior de N por N de la matriz A contiene
!>          la matriz triangular inferior, y la parte estrictamente triangular
!>          superior de A no se referencia.  Si DIAG = 'U', los
!>          elementos diagonales de A tampoco se referencian y se
!>          asumen como 1.
!>          En la salida, la inversa (triangular) de la matriz original, en
!>          el mismo formato de almacenamiento.
!>

LDA

!>          LDA es INTEGER
!>          La dimensión principal del array A.  LDA >= max(1,N).
!>

INFO

!>          INFO es INTEGER
!>          = 0: salida exitosa
!>          < 0: si INFO = -i, el argumento i tenía un valor ilegal
!>          > 0: si INFO = i, A(i,i) es exactamente cero. La matriz
!>               triangular es singular y su inversa no puede ser calculada.
!>
