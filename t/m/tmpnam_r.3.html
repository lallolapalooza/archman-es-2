tmpnam(3) Manual de Funciones de Biblioteca tmpnam(3)

NOMBRE

tmpnam, tmpnam_r - crear un nombre para un archivo temporal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <stdio.h>
[[deprecated]] char *tmpnam(char *s);
[[deprecated]] char *tmpnam_r(char *s);
Requisitos de Macro de Prueba de Funciones para glibc (ver feature_test_macros(7)):

tmpnam_r()

    Desde glibc 2.19:
        _DEFAULT_SOURCE
    Hasta e incluyendo glibc 2.19:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPCIÓN

Nota: evite usar estas funciones; use mkstemp(3) o tmpfile(3) en su lugar.

La función tmpnam() devuelve un puntero a una cadena que es un nombre de archivo válido, y tal que un archivo con ese nombre no existió en algún momento, para que los programadores ingenuos piensen que es un nombre adecuado para un archivo temporal. Si el argumento s es NULL, este nombre se genera en un buffer interno estático y puede ser sobrescrito por la siguiente llamada a tmpnam(). Si s no es NULL, el nombre se copia al array de caracteres (de longitud al menos L_tmpnam) apuntado por s y se devuelve el valor s en caso de éxito.

El nombre de ruta creado tiene un prefijo de directorio P_tmpdir. (Tanto L_tmpnam como P_tmpdir se definen en <stdio.h>, al igual que el TMP_MAX mencionado a continuación).

La función tmpnam_r() realiza la misma tarea que tmpnam(), pero devuelve NULL (para indicar un error) si s es NULL.

VALOR DE RETORNO

Estas funciones devuelven un puntero a un nombre de archivo temporal único, o NULL si no se puede generar un nombre único.

ERRORES

No se definen errores.

Para obtener una explicación de los términos utilizados en esta sección, consulte attributes(7).

C11, POSIX.1-2008.

Ninguno.

HISTORIA

tmpnam()
SVr4, 4.3BSD, C89, POSIX.1-2001. Obsoleto en POSIX.1-2008.

Solaris.

NOTAS

La función tmpnam() genera una cadena diferente cada vez que se llama, hasta TMP_MAX veces. Si se llama más de TMP_MAX veces, el comportamiento es específico de la implementación.

Aunque estas funciones generan nombres que son difíciles de adivinar, es posible que entre el momento en que se devuelve el nombre de ruta y el momento en que el programa lo abre, otro programa pueda crear ese nombre de ruta usando open(2), o crearlo como un enlace simbólico. Esto puede conducir a vulnerabilidades de seguridad. Para evitar tales posibilidades, use el flag open(2) O_EXCL para abrir el nombre de ruta. O mejor aún, use mkstemp(3) o tmpfile(3).

Las aplicaciones portátiles que usan hilos no pueden llamar a tmpnam() con un argumento NULL si _POSIX_THREADS o _POSIX_THREAD_SAFE_FUNCTIONS está definido.

ERRORES GRAVES

Nunca use estas funciones. Use mkstemp(3) o tmpfile(3) en su lugar.

VER TAMBIÉN

mkstemp(3), mktemp(3), tempnam(3), tmpfile(3)
