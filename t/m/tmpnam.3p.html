TMPNAM(3P) Manual de Programador POSIX TMPNAM(3P)

PROLOGO

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento en Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tmpnam — crear un nombre para un archivo temporal

SINOPSIS

#include <stdio.h>
char *tmpnam(char *s);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia se alinea con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 se remite al estándar ISO C.

La función tmpnam() generará una cadena que es un nombre de ruta válido que no nombra un archivo existente. La función es potencialmente capaz de generar {TMP_MAX} cadenas diferentes, pero cualquiera de ellas o todas pueden estar ya en uso por archivos existentes y, por lo tanto, no ser valores de retorno adecuados.

La función tmpnam() genera una cadena diferente cada vez que se llama desde el mismo proceso, hasta {TMP_MAX} veces. Si se llama más de {TMP_MAX} veces, el comportamiento es definido por la implementación.

La implementación se comportará como si ninguna función definida en este volumen de POSIX.1‐2017, excepto tempnam(), llame a tmpnam().

La función tmpnam() no necesita ser segura para hilos si se llama con un parámetro NULL.

VALOR DE RETORNO

Al completarse con éxito, tmpnam() devolverá un puntero a una cadena. Si no se puede generar una cadena adecuada, la función tmpnam() devolverá un puntero nulo.

Si el argumento s es un puntero nulo, tmpnam() dejará su resultado en un objeto estático interno y devolverá un puntero a ese objeto. Las llamadas posteriores a tmpnam() pueden modificar el mismo objeto. Si el argumento s no es un puntero nulo, se presume que apunta a una matriz de al menos L_tmpnam chars; tmpnam() escribirá su resultado en esa matriz y devolverá el argumento como su valor.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

Generación de un nombre de ruta

El siguiente ejemplo genera un nombre de ruta único y lo almacena en la matriz a la que apunta ptr.

#include <stdio.h>
...
char pathname[L_tmpnam+1];
char *ptr;
ptr = tmpnam(pathname);

USO DE APLICACIONES

Esta función solo crea nombres de ruta. Es responsabilidad de la aplicación crear y eliminar los archivos.

Entre el momento en que se crea un nombre de ruta y se abre el archivo, es posible que otro proceso cree un archivo con el mismo nombre. Las aplicaciones pueden encontrar tmpfile() más útil.

Las aplicaciones deben usar las funciones tmpfile(), mkstemp() o mkdtemp() en lugar de la función obsoleta tmpnam().

RACIONALE

Ninguno.

DIRECCIONES FUTURAS

La función tmpnam() puede eliminarse en una versión futura.

VER TAMBIÉN

fopen(), open(), mkdtemp(), tempnam(), tmpfile(), unlink()
