tm(3type) tm(3type)

NOMBRE

tm - tiempo desglosado

BIBLIOTECA

Biblioteca C estándar (libc)

SINOPSIS

#include <time.h>
struct tm {
    int         tm_sec;    /* Segundos          [0, 60] */
    int         tm_min;    /* Minutos          [0, 59] */
    int         tm_hour;   /* Hora             [0, 23] */
    int         tm_mday;   /* Día del mes [1, 31] */
    int         tm_mon;    /* Mes            [0, 11]  (Enero = 0) */
    int         tm_year;   /* Año menos 1900 */
    int         tm_wday;   /* Día de la semana  [0, 6]   (Domingo = 0) */
    int         tm_yday;   /* Día del año  [0, 365] (Ene/01 = 0) */
    int         tm_isdst;  /* Indicador de horario de verano */
    /* Desde POSIX.1-2024:  */
    long        tm_gmtoff; /* Segundos al Este de UTC */
    const char *tm_zone;   /* Abreviatura de la zona horaria */
};
Requisitos de macro de prueba de características para glibc (ver feature_test_macros(7)):

tm_gmtoff, tm_zone:

    Desde glibc 2.20:
        _DEFAULT_SOURCE
    glibc 2.20 y anteriores:
        _BSD_SOURCE

DESCRIPCIÓN

Describe el tiempo, desglosado en componentes distintos.

tm_isdst describe si el horario de verano está en vigor en el momento descrito. El valor es positivo si el horario de verano está en vigor, cero si no lo está, y negativo si la información no está disponible.

tm_gmtoff es la diferencia, en segundos, de la zona horaria representada por este tiempo desglosado y UTC (esta es la inversa aditiva de timezone(3)).

tm_zone es el equivalente de tzname(3) para la zona horaria representada por este tiempo desglosado.

VERSIÓNES

En C90, tm_sec podía representar valores en el rango [0, 61], que podían representar un segundo bisiesto doble. UTC no permite segundos bisiestos dobles, por lo que se limitó a 60 en C99.

timezone(3), como variable, es una extensión XSI: algunos sistemas proporcionan la función timezone(3) compatible con V7. El campo tm_gmtoff proporciona una alternativa (con signo opuesto) para esos sistemas.

tm_zone apunta a almacenamiento estático y puede ser reemplazado en llamadas posteriores a localtime(3) y funciones similares (sin embargo, esto nunca ocurre en glibc).

ESTÁNDARES

C23, POSIX.1-2024.

HISTORIA

C89, POSIX.1-1988.

tm_gmtoff y tm_zone se originan en 4.3BSD-Tahoe (donde tm_zone es un char *), y se estandarizaron por primera vez en POSIX.1-2024.

NOTAS

tm_sec puede representar un segundo bisiesto con el valor 60.

VéASE TAMBIÉN

ctime(3), strftime(3), strptime(3), time(7)
