TMPFILE(3P) Manual del programador POSIX TMPFILE(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles sobre el comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tmpfile — crear un archivo temporal

SINOPSIS

#include <stdio.h>
FILE *tmpfile(void);

DESCRIPCIÓN

La funcionalidad descrita en esta página de referencia está alineada con el estándar ISO C. Cualquier conflicto entre los requisitos descritos aquí y el estándar ISO C es involuntario. Este volumen de POSIX.1‐2017 remite al estándar ISO C.

La función tmpfile() creará un archivo temporal y abrirá un stream correspondiente. El archivo se eliminará automáticamente cuando se cierren todas las referencias al archivo. El archivo se abrirá como en fopen() para actualización (wb+), excepto que las implementaciones pueden restringir los permisos, ya sea borrando los bits del modo de archivo o estableciéndolos al valor S_IRUSR | S_IWUSR.

En algunas implementaciones, puede quedar un archivo permanente si el proceso que llama a tmpfile() se interrumpe mientras procesa una llamada a tmpfile().

Puede escribirse un mensaje de error en la salida estándar si el stream no se puede abrir.

VALOR DE RETORNO

Al completarse con éxito, tmpfile() devolverá un puntero al stream del archivo que se crea. De lo contrario, devolverá un puntero nulo y establecerá errno para indicar el error.

ERRORES

La función tmpfile() fallará si:

EINTR
Se capturó una señal durante tmpfile().
EMFILE
Todos los descriptores de archivo disponibles para el proceso están actualmente abiertos.
EMFILE
{STREAM_MAX} streams están actualmente abiertos en el proceso llamante.
ENFILE
El número máximo permitido de archivos está actualmente abierto en el sistema.
ENOSPC
El directorio o el sistema de archivos que contendrían el nuevo archivo no pueden ser expandidos.
EOVERFLOW
El archivo es un archivo regular y el tamaño del archivo no se puede representar correctamente en un objeto de tipo off_t.

La función tmpfile() puede fallar si:

EMFILE
{FOPEN_MAX} streams están actualmente abiertos en el proceso llamante.
ENOMEM
No hay suficiente espacio de almacenamiento disponible.

Las siguientes secciones son informativas.

EJEMPLOS

Creación de un Archivo Temporal

El siguiente ejemplo crea un archivo temporal para actualización, y devuelve un puntero a un stream para el archivo creado en la variable fp.

#include <stdio.h>
...
FILE *fp;
fp = tmpfile ();

USO POR LA APLICACIÓN

Debería ser posible abrir al menos {TMP_MAX} archivos temporales durante la vida del programa (este límite puede ser compartido con tmpnam()) y no debería haber ningún límite en el número abierto simultáneamente aparte de este límite y cualquier límite en el número de descriptores de archivo o streams abiertos ({OPEN_MAX}, {FOPEN_MAX}, {STREAM_MAX}).
