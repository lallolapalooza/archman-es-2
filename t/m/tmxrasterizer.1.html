NOMBRE

tmxrasterizer - renderiza un mapa de teselas en una imagen

SINOPSIS

tmxrasterizer [OPCIONES] [ARCHIVO DE ENTRADA] [ARCHIVO DE SALIDA]

DESCRIPCIÓN

Esta aplicación se puede utilizar para renderizar mapas creados por el Tiled Map Editor en una imagen. Esto es muy útil para crear previsualizaciones a pequeña escala, como minimapas.

OPCIONES

-h --help
Muestra la ayuda
-v --version
Muestra la versión
-s --scale TAMAÑO
La escala de la imagen de salida
-t --tilesize TAMAÑO
El tamaño solicitado en píxeles al que se renderiza una tesela. Anula la opción --scale.
--size TAMAÑO
La imagen de salida cabe dentro de un cuadrado de TAMAÑO x TAMAÑO. Anula las opciones --scale y --tilesize.
-a --anti-aliasing
Suaviza la imagen de salida utilizando antialiasing
--ignore-visibility
Ignora todas las banderas de visibilidad de capa en el archivo de mapa y renderiza todas las capas en la salida (el valor predeterminado es omitir las capas invisibles).
--hide-layer
Especifica una capa que se omitirá de la imagen de salida. Se puede repetir para ocultar varias capas. El nombre de la capa no distingue entre mayúsculas y minúsculas.
Ejemplo:
tmxrasterizer --hide-layer collision --hide-layer otherlayer [...]
