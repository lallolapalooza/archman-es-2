NOMBRE

typst - El compilador de Typst

SINOPSIS

typst [--color] [--cert] [-h|--help] [-V|--version] <subcomandos>

DESCRIPCIÓN

El compilador de Typst

OPCIONES

--color=COLOR [predeterminado: auto]
Si usar color. Cuando se establece en `auto`, si la terminal lo soporta.

[posibles valores: auto, always, never]

--cert=CERT
Ruta a un certificado CA personalizado para usar al realizar solicitudes de red.
También se puede especificar con la variable de entorno TYPST_CERT.
-h, --help
Imprime la ayuda.
-V, --version
Imprime la versión.

SUBCOMANDOS

typst-compile(1)
Compila un archivo de entrada a un formato de salida compatible.
typst-watch(1)
Observa un archivo de entrada y lo recompila ante cambios.
typst-init(1)
Inicializa un nuevo proyecto a partir de una plantilla.
typst-query(1)
Procesa un archivo de entrada para extraer metadatos proporcionados.
typst-fonts(1)
Lista todas las fuentes descubiertas en el sistema y en rutas de fuentes personalizadas.
typst-completions(1)
Genera scripts de finalización de shell.
typst-info(1)
Muestra información de depuración sobre Typst.
typst-help(1)
Imprime este mensaje o la ayuda de los subcomandos dados.
