FBB::TypeTrait(3bobcat) Rasgos de tipo FBB::TypeTrait(3bobcat)

NOMBRE

FBB::TypeTrait - Clase de rasgos de tipo

SINOPSIS

#include <bobcat/typetrait>

DESCRIPCIÓN

FBB::TypeTrait es una clase de rasgos. No define ninguna función miembro ni miembro de datos, sino meramente tipos. Se puede utilizar para determinar el tipo básico y otras características de tipos (constantes) simples, (constantes) punteros o (constantes) referencias. Fue diseñada siguiendo la clase de plantilla TypeTraits de Alexandrescu (2001).

La plantilla de clase FBB::LpromotesR se utiliza para determinar, en tiempo de compilación, si su segundo tipo (el de la derecha) puede ser promovido a su primer tipo (el de la izquierda).

La plantilla de clase FBB::Use espera dos nombres de tipo LHS y RHS y define typename Use<LHS, RHS>::type como LHS si RHS puede ser promovido a LHS, o define typename Use<LHS, RHS>::type como RHS.

ESPACIO DE NOMBRES

FBB

HEREDA DE

-

TypeTrait<TIPO>

TIPO es el parámetro de tipo de plantilla cuyas características deben determinarse.

TypeTrait<TIPO> define el tipo Plain: el tipo simple (el tipo sin const, puntero, indicador de tipo de referencia) de cualquier tipo de referencia simple, puntero, lvalue o rvalue, sea const o no.

TypeTrait<TIPO> define los siguientes valores bool:

o
isClass: true si el argumento de tipo de plantilla representa un tipo de clase (struct), false en caso contrario.
o
isConst: true si el argumento de tipo de plantilla representa un tipo const, false en caso contrario.
o
isPointer: true si el argumento de tipo de plantilla representa un tipo puntero, false en caso contrario.
o
isR_Ref: true si el argumento de tipo de plantilla representa un tipo de referencia rvalue, false en caso contrario.
o
isRef: true si el argumento de tipo de plantilla representa un tipo de referencia lvalue, false en caso contrario.

LpromotesR<TipoIzquierdo, TipoDerecho>

LpromotesR<TipoIzquierdo, TipoDerecho> define la constante enum yes como 1 si un argumento de TipoDerecho puede ser promovido a valor u objeto de TipoIzquierdo. El valor enum yes se define como 0 si no hay un constructor de este tipo disponible o si dicho constructor está definido usando la palabra clave explicit.

EJEMPLOS

Aquí hay un ejemplo usando LpromotesR:

    int main()
    {
        cout << "string promueve char const *: " <<
                LpromotesR<string, char const *>::yes << ’\n’;  // 1
        cout << "string promueve string " <<
                LpromotesR<string, string>::yes << ’\n’;        // 1
        cout << "char const * promueve string " <<
                LpromotesR<char const *, string>::yes << ’\n’;  // 0
    }
