Documentación de Definición de Macros

#define BROTLI_BOOL int

Un reemplazo portátil de bool. BROTLI_BOOL es un tipo de 'documentación': en realidad es un int, pero en la API denota un tipo, cuyos únicos valores son BROTLI_TRUE y BROTLI_FALSE.

Los valores de BROTLI_BOOL pasados a Brotli deben ser BROTLI_TRUE o BROTLI_FALSE, o ser el resultado de las macros TO_BROTLI_BOOL.

Los valores de BROTLI_BOOL devueltos por Brotli no deben compararse con true, false, BROTLI_TRUE, BROTLI_FALSE, sino que deben evaluarse, por ejemplo:

if (SomeBrotliFunction(encoder, BROTLI_TRUE) &&
    !OtherBrotliFunction(decoder, BROTLI_FALSE)) {
  bool x = !!YetAnotherBrotliFunction(encoder, TO_BROLTI_BOOL(2 * 2 == 4));
  DoSomething(x);
}

Documentación de Typedef

typedef void*(* brotli_alloc_func) (void *opaque, size_t size)

Tipo de puntero a función de asignación.

Parámetros:

opaque manejador del gestor de memoria personalizado proporcionado por el cliente
size tamaño de memoria solicitado; no puede ser 0

Retorna:

0 en caso de fallo

un puntero válido a una región de memoria de al menos tamaño bytes de largo de lo contrario

typedef void(* brotli_free_func) (void *opaque, void *address)

Tipo de puntero a función de desasignación. Esta función DEBERÍA no hacer nada si address es 0.

Parámetros:

opaque manejador del gestor de memoria personalizado proporcionado por el cliente
address puntero a la región de memoria devuelto por brotli_alloc_func, o 0
