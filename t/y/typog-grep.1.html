NOMBRE

typog-grep - grep especializado para elementos de typog-inspect en archivos de log de LaTeX

SINOPSIS

typog-grep -a|--all|--any [OPCIÓN...] ARCHIVO-DE-LOG...
typog-grep [OPCIÓN...] EXPRESIÓN-REGULAR ARCHIVO-DE-LOG...

La primera forma, ``modo descubrimiento'', muestra todos los IDs de

<typog-inspect id="ID" ...>

elementos en ARCHIVO-DE-LOG.

La segunda forma muestra el contenido, DATOS-DE-LOG, de los elementos

<typog-inspect id="ID" ...>
DATOS-DE-LOG
</typog-inspect>

cuyos IDs coinciden con EXPRESIÓN-REGULAR en ARCHIVO-DE-LOG.

Si no se proporciona ARCHIVO-DE-LOG, se lee desde stdin. El nombre de archivo "-" es sinónimo de stdin.

DESCRIPCIÓN

typog-grep es un post-procesador a medida para archivos log de LaTeX y el entorno "typoginspect" tal como lo proporciona el paquete de LaTeX typog. Comparte más con el venerable sgrep https://www.cs.helsinki.fi/u/jjaakkol/sgrep.html que con grep https://pubs.opengroup.org/onlinepubs/9699919799/utilities/grep.html de POSIX.

En el archivo fuente de LaTeX, el usuario encierra su texto o código en un entorno "typoginspect":

\begin{typoginspect}{ID}
TEXTO-O-CÓDIGO-A-INVESTIGAR
\end{typoginspect}

donde ID se utiliza para identificar uno o más fragmentos encerrados entre corchetes. ID no tiene por qué ser único. El mecanismo EXPRESIÓN-REGULAR facilita la selección de grupos de IDs relacionados si se nombran en consecuencia.

En el ARCHIVO-DE-LOG, el resultado del entorno aparece, empaquetado con información de rastreo, como

<typog-inspect id="ID" job="NOMBRE-DEL-TRABAJO" line="NÚMERO-DE-LÍNEA" page="NÚMERO-DE-PÁGINA">
DATOS-DE-LOG
</typog-inspect>

donde todas las secuencias de letras mayúsculas son meta-variables y, en particular, NOMBRE-DEL-TRABAJO es la expansión de "\jobname", NÚMERO-DE-LÍNEA es el número de línea del archivo fuente de LaTeX donde se encontró el entorno "typoginspect", y NÚMERO-DE-PÁGINA es la página donde aparece la salida de "TEXTO-O-CÓDIGO-A-INVESTIGAR".

typog-grep revela el contenido de ARCHIVO-DE-LOG entre "<typog-inspect id="ID" ...>" y "</typog-inspect>" excluyendo las etiquetas XML. Accede a NOMBRE-DEL-TRABAJO, NÚMERO-DE-LÍNEA y NÚMERO-DE-PÁGINA con las opciones de línea de comandos --job-name, --line-number y --page-number, respectivamente. Usa --id para mostrar el nombre de los IDs que coincidieron con EXPRESIÓN-REGULAR.

Los entornos "typoginspect" pueden anidarse. typog-grep respeta el anidamiento, es decir, si el ID del entorno anidado no coincide con EXPRESIÓN-REGULAR, no se incluirá en la salida del programa.

OPCIONES

La lista de opciones está ordenada por los nombres de las opciones largas.

-a, --all, --any
Modo descubrimiento de ID: Descubre todos los elementos "typog-inspect" independientemente de cualquier patrón coincidente e imprime sus IDs. Los resultados se imprimen en su orden de aparición en los respectivos ARCHIVO-DE-LOGs. Canaliza la salida a sort para obtener IDs ordenados alfabéticamente.

Aumenta con las opciones --job-name, --line-number, --log-line-number o --page-number para más información.

--color, colour CUÁNDO
Colorea contenidos de log específicos para los IDs coincidentes. El argumento CUÁNDO determina cuándo aplicar color: "always", "never", o "auto". La configuración "auto" comprueba si la salida estándar ha sido redirigida. Este es el valor por defecto.
-C, --config CLAVE=VALOR[:CLAVE=VALOR[:...]]
Establece una o más CLAVEs de configuración a pares VALOR. Consulte la sección "CONFIGURACIÓN" para obtener una descripción de todos los elementos de configuración disponibles. Use la opción --show-config para mostrar la configuración por defecto.
--debug
Activa la salida de depuración en stderr.
-E, --encoding CODIFICACIÓN
Establece la CODIFICACIÓN de ARCHIVO-DE-LOG para la traducción a UTF-8. El valor por defecto es indefinido.

Use esta opción para eliminar las molestas secuencias "<DÍGITOS-HEX>" en terminales UTF-8. Consulte la opción --show-encodings para conocer las codificaciones conocidas y Encode::Supported para un resumen de todas las codificaciones. Consulte también la sección "Algunas Codificaciones Comunes".

Aplique iconv https://pubs.opengroup.org/onlinepubs/9699919799/utilities/iconv.html (POSIX) o recode https://github.com/rrthomas/recode/ (GNU) en ARCHIVO-DE-LOG antes de usar esta herramienta para evitar tener que usar la opción --encoding.

-h, --help
Muestra ayuda breve y sale.
-i, --[no-]id
Imprime el nombre del ID real que coincidió con EXPRESIÓN-REGULAR. Controle la apariencia del ID coincidente con el elemento de configuración "id-heading".
-y, --[no-]ignore-case
Coincide IDs ignorando las distinciones de mayúsculas y minúsculas en patrones y datos.
-j, --[no-]job-name
Imprime el "\jobname" que latex asoció con el archivo de entrada.
-n, --[no-]line-number
Imprime el número de línea donde se encontró el entorno "typoginspect" en el archivo fuente de LaTeX.
-N, --[no-]log-line-number
Imprime el número de línea del archivo de log donde se encontró la línea actual.
-p, --[no-]page-number
Imprime el número de página donde comienza el contenido del entorno "typoginspect" en el documento maquetado.
-P, --[no-]pager
Redirige la salida de stdout al paginador configurado.
--show-config
Muestra la configuración por defecto y sale.
--show-encodings
Muestra todas las codificaciones conocidas y sale.
-V, --version
Muestra la información de la versión y sale.
-w, --[no-]word-regexp
Coincide solo con palabras completas.

t;=0|1
Elige entre imprimir los IDs coincidentes con la opción --id: En línea (0) o encabezado antes de los datos coincidentes (1). Por defecto: 0.
"id-heading-format"=FORMAT
Controla el FORMAT para imprimir los IDs coincidentes en modo encabezado, donde FORMAT se pasa a "printf" de Perl. Por defecto: "--> %s <--".
"id-indent"=INDENT
Sangría de las etiquetas anidadas de typog-inspect. Solo se usa en ``modo descubrimiento'' (primera forma), es decir, si --all está activo. Por defecto: 8.
"id-max-length"=MAXIMUM-LENGTH
Establece la longitud máxima de un ID coincidente para su impresión. Si un ID coincidente excede esta longitud, se truncará y los últimos tres caracteres (menos de MAXIMUM-LENGTH) se reemplazarán por puntos. Por defecto: 40.
"line-number-format"=FORMAT
Controla el FORMAT para imprimir los números de línea de código fuente TeX, donde FORMAT se pasa a "printf" de Perl. Por defecto: %5d.
"log-line-number-format"=FORMAT
Controla el FORMAT para imprimir los números de línea del registro, donde FORMAT se pasa a "printf" de Perl. Por defecto: %6d.
"page-number-format"=FORMAT
Controla el FORMAT para imprimir los números de página, donde FORMAT se pasa a "printf" de Perl. Por defecto: "[%3d]".
"pager"=PAGER
Nombre de la aplicación paginador a la que se enviará la salida si se ejecuta con la opción --pager. Por defecto: "less".
"pager-flags"=FLAGS
Pasa FLAGS a PAGER. Por defecto: "--quit-if-one-screen".

ESTADO DE SALIDA

El estado de salida es 0 si al menos un ID coincidió con REGEXP, 1 si ningún ID coincidió con REGEXP y 2 si ocurrió un error.

ADVERTENCIAS

La etiqueta de fin "</typog-inspect>" a veces se coloca demasiado pronto en la salida y el rastreo *parece* truncado. Sin embargo, LaTeX registra de manera confiable la información de rastreo solicitada, pero las operaciones de escritura para los datos de rastreo y el código que se utiliza para imprimir la etiqueta de fin no están sincronizados.
