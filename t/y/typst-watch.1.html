typst-watch(1) Manual de comandos generales typst-watch(1)

NOMBRE

typst-watch - Observa un archivo de entrada y recompila ante cambios

SINOPSIS

typst-watch [-f|--format] [--root] [--input] [--font-path] [--ignore-system-fonts] [--ignore-embedded-fonts] [--package-path] [--package-cache-path] [--creation-timestamp] [--pages] [--pdf-standard] [--no-pdf-tags] [--ppi] [--deps] [--deps-format] [-j|--jobs] [--features] [--diagnostic-format] [--open] [--timings] [--no-serve] [--no-reload] [--port] [-h|--help] <ENTRADA> [SALIDA]

DESCRIPCIÓN

Observa un archivo de entrada y recompila ante cambios

OPCIONES

-f, --format=FORMATO
El formato del archivo de salida, inferido de la extensión por defecto

[posibles valores: pdf, png, svg, html]

--root=DIR
Configura la raíz del proyecto (para rutas absolutas)
También puede especificarse con la variable de entorno TYPST_ROOT.
--input=clave=valor
Añade un par clave-valor de cadena visible a través de `sys.inputs`
--font-path=DIR
Añade directorios adicionales que se buscarán recursivamente para encontrar fuentes.

Si se especifican varias rutas, estas se separan por el separador de rutas del sistema (`:` en sistemas tipo Unix y `;` en Windows).

También puede especificarse con la variable de entorno TYPST_FONT_PATHS.
--ignore-system-fonts
Asegura que las fuentes del sistema no se buscarán, a menos que se incluyan explícitamente a través de `--font-path`
También puede especificarse con la variable de entorno TYPST_IGNORE_SYSTEM_FONTS.
--ignore-embedded-fonts
Asegura que las fuentes incrustadas en Typst no se considerarán
También puede especificarse con la variable de entorno TYPST_IGNORE_EMBEDDED_FONTS.
--package-path=DIR
Ruta personalizada para paquetes locales, por defecto es la ubicación dependiente del sistema
También puede especificarse con la variable de entorno TYPST_PACKAGE_PATH.
--package-cache-path=DIR
Ruta personalizada para la caché de paquetes, por defecto es la ubicación dependiente del sistema
También puede especificarse con la variable de entorno TYPST_PACKAGE_CACHE_PATH.
--creation-timestamp=MARCA_DE_TIEMPO_UNIX
La fecha de creación del documento formateada como una marca de tiempo UNIX.

Para más información, véase https://reproducible-builds.org/specs/source-date-epoch/.

También puede especificarse con la variable de entorno SOURCE_DATE_EPOCH.
--pages=PÁGINAS
Qué páginas exportar. Si no se especifica, se exportan todas las páginas.

Las páginas a exportar se separan por comas y pueden ser números de página simples (ej. '2,5' para exportar solo las páginas 2 y 5) o rangos de páginas (ej. '2,3-6,8-' para exportar la página 2, las páginas 3 a 6 (inclusive), la página 8 y cualquier página posterior).

Los números de página están indexados desde 1 y corresponden a los números de página físicos en el documento (por lo tanto, no se ven afectados por el contador de páginas del documento).

--pdf-standard=ESTÁNDAR_PDF
Uno (o varios separados por comas) de los estándares PDF con los que Typst forzará la conformidad

Posibles valores:

  • 1.4: PDF 1.4
  • 1.5: PDF 1.5
  • 1.6: PDF 1.6
  • 1.7: PDF 1.7
  • 2.0: PDF 2.0
  • a-1b: PDF/A-1b
  • a-1a: PDF/A-1a
  • a-2b: PDF/A-2b
  • a-2u: PDF/A-2u
  • a-2a: PDF/A-2a
  • a-3b: PDF/A-3b
  • a-3u: PDF/A-3u
  • a-3a: PDF/A-3a
  • a-4: PDF/A-4
  • a-4f: PDF/A-4f
  • a-4e: PDF/A-4e
  • ua-1: PDF/UA-1
--no-pdf-tags
Por defecto, incluso cuando no se produce un documento `PDF/UA-1`, se escribe un documento PDF etiquetado para proporcionar una base de accesibilidad. En algunas circunstancias (por ejemplo, al intentar reducir el tamaño de un documento) puede ser deseable deshabilitar el PDF etiquetado.
--ppi=PPI [por defecto: 144]
El PPI (píxeles por pulgada) a utilizar para la exportación PNG
--deps=RUTA
Ruta del archivo donde se escribirá una lista de las dependencias de la compilación actual. Usa `-` para escribir a stdout
--deps-format=FORMATO_DEPS [por defecto: json]
Formato de archivo a utilizar para las dependencias

Posibles valores:

  • json: Codifica como JSON, falla para rutas no Unicode
  • zero: Separa las rutas con bytes NULL y puede expresar todas las rutas
  • make: Emite en formato Make, omitiendo rutas no expresables
-j, --jobs=TRABAJOS
Número de trabajos paralelos iniciados durante la compilación. Por defecto, el número de CPUs. Establecerlo en 1 deshabilita el paralelismo
--features=CARACTERÍSTICAS
Habilita características en desarrollo que pueden ser cambiadas o eliminadas en cualquier momento

[posibles valores: html, a11y-extras]

También puede especificarse con la variable de entorno TYPST_FEATURES.
--diagnostic-format=FORMATO_DIAGNÓSTICO [por defecto: human]
El formato en el que se emitirán los diagnósticos

[posibles valores: human, short]

--open=VISOR
Abre el archivo de salida con el visor por defecto o un programa específico después de la compilación. Ignorado si la salida es stdout
--timings=SALIDA_JSON
Produce tiempos de rendimiento del proceso de compilación. (experimental)

El archivo JSON resultante puede cargarse en una herramienta de rastreo como https://ui.perfetto.dev. No contiene información sensible aparte de nombres de archivo y números de línea.

--no-serve
Deshabilita el servidor HTTP integrado para la exportación HTML
--no-reload
Deshabilita el script de recarga en vivo inyectado para la exportación HTML. El HTML que se escribe en disco no se ve afectado de ninguna manera
--port=PUERTO
El puerto donde se sirve el HTML.

Por defecto, el primer puerto libre en el rango 3000-3005.

-h, --help
Imprime la ayuda (ver un resumen con '-h')
<ENTRADA>
Ruta al archivo Typst de entrada. Usa `-` para leer la entrada desde stdin
[SALIDA]
Ruta al archivo de salida (PDF, PNG, SVG o HTML). Usa `-` para escribir la salida a stdout.

Para los formatos de salida que emiten un archivo por página (PNG y SVG), debe haber una plantilla de número de página si el documento fuente se renderiza en varias páginas. Usa `{p}` para los números de página, `{0p}` para los números de página con ceros a la izquierda y `{t}` para el número total de páginas. Por ejemplo, `page-{0p}-of-{t}.png` crea `page-01-of-10.png`, `page-02-of-10.png`, etc.
