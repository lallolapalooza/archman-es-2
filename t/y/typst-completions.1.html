NOMBRE

typst-completions - Genera scripts de autocompletado para la shell

SINOPSIS

typst-completions [-h|--help] <SHELL>

DESCRIPCIÓN

Genera scripts de autocompletado para la shell.

OPCIONES

-h, --help
Imprime la ayuda.
<SHELL>
La shell para la cual generar los autocompletados.

[posibles valores: bash, elvish, fish, powershell, zsh]
