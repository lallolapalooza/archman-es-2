typedef uint16_t(* MTPDataPutFunc) (void *params, void *priv, uint32_t sendlen, unsigned char *data, uint32_t *putlen)

Función de callback para poner datos desde la función manejadora

Parámetros

params los parámetros del dispositivo
priv un puntero dereferenciable definido por el usuario
sendlen el número de bytes disponibles
data un buffer para leer los datos
putlen puntero al número de bytes leídos realmente de data

Retorna

LIBMTP_HANDLER_RETURN_OK si es exitoso, LIBMTP_HANDLER_RETURN_ERROR en caso de error o LIBMTP_HANDLER_RETURN_CANCEL para cancelar la transferencia
