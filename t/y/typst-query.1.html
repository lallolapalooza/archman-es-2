NOMBRE

typst-query - Procesa un archivo de entrada para extraer metadatos proporcionados

SINOPSIS

typst-query [--field] [--one] [--format] [--pretty] [--target] [--root] [--input] [--font-path] [--ignore-system-fonts] [--ignore-embedded-fonts] [--package-path] [--package-cache-path] [--creation-timestamp] [-j|--jobs] [--features] [--diagnostic-format] [-h|--help] <ENTRADA> <SELECTOR>

DESCRIPCIÓN

Procesa un archivo de entrada para extraer metadatos proporcionados

OPCIONES

--field=CAMPO
Extrae solo un campo de todos los elementos recuperados
--one
Espera y recupera exactamente un elemento
--format=FORMATO [por defecto: json]
El formato en el que serializar

[valores posibles: json, yaml]

--pretty
Si se debe imprimir en formato legible la salida serializada.

Solo se aplica al formato JSON.

--target=TARGET [por defecto: paged]
El objetivo para compilar

Posibles valores:

  • paged: Formatos PDF e imagen
  • html: HTML
--root=DIR
Configura la raíz del proyecto (para rutas absolutas)
También se puede especificar con la variable de entorno TYPST_ROOT.
--input=clave=valor
Añade un par clave-valor de cadena visible a través de `sys.inputs`
--font-path=DIR
Añade directorios adicionales que se buscarán recursivamente en busca de fuentes.

Si se especifican varias rutas, estas se separan por el separador de rutas del sistema (`:` en sistemas tipo Unix y `;` en Windows).

También se puede especificar con la variable de entorno TYPST_FONT_PATHS.
--ignore-system-fonts
Asegura que no se buscarán fuentes del sistema, a menos que se incluyan explícitamente a través de `--font-path`
También se puede especificar con la variable de entorno TYPST_IGNORE_SYSTEM_FONTS.
--ignore-embedded-fonts
Asegura que las fuentes incrustadas en Typst no se considerarán
También se puede especificar con la variable de entorno TYPST_IGNORE_EMBEDDED_FONTS.
--package-path=DIR
Ruta personalizada para paquetes locales, por defecto es la ubicación específica del sistema
También se puede especificar con la variable de entorno TYPST_PACKAGE_PATH.
--package-cache-path=DIR
Ruta personalizada para la caché de paquetes, por defecto es la ubicación específica del sistema
También se puede especificar con la variable de entorno TYPST_PACKAGE_CACHE_PATH.
--creation-timestamp=MARCA_DE_TIEMPO_UNIX
La fecha de creación del documento formateada como una marca de tiempo UNIX.

Para más información, véase https://reproducible-builds.org/specs/source-date-epoch/.

También se puede especificar con la variable de entorno SOURCE_DATE_EPOCH.
-j, --jobs=TRABAJOS
Número de trabajos paralelos generados durante la compilación. Por defecto, el número de CPUs. Establecerlo en 1 deshabilita el paralelismo
--features=CARACTERÍSTICAS
Habilita características en desarrollo que pueden ser cambiadas o eliminadas en cualquier momento

[valores posibles: html, a11y-extras]

También se puede especificar con la variable de entorno TYPST_FEATURES.
--diagnostic-format=FORMATO_DIAGNÓSTICO [por defecto: human]
El formato en el que emitir los diagnósticos

[valores posibles: human, short]

-h, --help
Imprime la ayuda (ver un resumen con '-h')
<ENTRADA>
Ruta al archivo Typst de entrada. Usa `-` para leer la entrada desde stdin
<SELECTOR>
Define qué elementos recuperar
