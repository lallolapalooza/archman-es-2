TYPE(1P) Manual de Programador POSIX TYPE(1P)

PROLOG

Esta página del manual forma parte del Manual de Programador POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

type — escribe una descripción del tipo de comando

SINOPSIS

type nombre...

DESCRIPCIÓN

La utilidad type indicará cómo se interpretaría cada argumento si se usara como nombre de comando.

OPCIONES

Ninguna.

OPERANDOS

Se admitirá el siguiente operando:

nombre
Un nombre a interpretar.

STDIN

No se utiliza.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de type:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de Internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte en lugar de multibyte en los argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.
PATH
Determina la ubicación de nombre, tal como se describe en el volumen de Definiciones Base de POSIX.1‐2017, Capítulo 8, Variables de Entorno.

EVENTOS ASÍNCRONOS

Predeterminado.

STDOUT

La salida estándar de type contiene información sobre cada operando en un formato no especificado. La información proporcionada típicamente identifica al operando como un comando interno del shell, una función, un alias o una palabra clave, y donde sea aplicable, puede mostrar la ruta del operando.

STDERR

La salida estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
Finalización exitosa.
>0
Ocurrió un error.

CONSECUENCIAS DE ERRORES

Predeterminado.

Las siguientes secciones son informativas.

USO DE LA APLICACIÓN

Dado que type debe ser consciente del contenido del entorno de ejecución del shell actual (como las listas de comandos, funciones y comandos internos procesados por hash), siempre se proporciona como un comando interno regular del shell. Si se llama en un entorno de ejecución de utilidad separado, como uno de los siguientes:

nohup type writer
find . -type f | xargs type

puede que no produzca resultados precisos.

type(1)

NAME

type - display information about shell builtin commands, external commands and builtins

SYNOPSIS

type [shell-builtin] [command] ...

DESCRIPTION

For each command given as an argument, describe how the shell interprets it. This is used to list the commands available in the shell, and to indicate how the shell will execute each command.

OPTIONS

-a, --all

List all possible interpretations of command, including aliases, functions, builtins, and disk files.

-p, --path

Only print the first disk file found that satisfies the command, which will be a full pathname.

-t, --type

Only print the type of the command, which will be one of alias, keyword, function, builtin, or file.

-f, --flow-control

Only print the first disk file found that satisfies the command, which will be a full pathname.

Inhibit the shell function lookup. If command is a shell builtin or a file, then the output will be the same as if -t was given.

ENVIRONMENT

See bash(1) for a description of the shell environment.
