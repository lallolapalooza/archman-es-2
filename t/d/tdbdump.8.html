TDBDUMP(8) Herramientas de administración del sistema TDBDUMP(8)

NOMBRE

tdbdump - herramienta para imprimir el contenido de un archivo TDB

SINOPSIS

tdbdump [-k nombre_clave] [-e] [-h] [-x] {nombre_archivo}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades de samba(1).

tdbdump es una utilidad muy simple que 'vuelca' el contenido de un archivo TDB (Base de Datos Trivial) a la salida estándar en un formato legible por humanos.

Esta herramienta puede ser utilizada para depurar problemas con archivos TDB. Está pensada para aquellos que están algo familiarizados con los internos de Samba.

OPCIONES

-h

Obtener información de ayuda.

-k nombre_clave

La opción -k restringe el volcado a una única clave, si se encuentra.

-e

La opción -e intenta realizar un volcado desde una base de datos corrupta. Naturalmente, tal volcado no es fiable, como mucho.

-x

La opción -x cambia los datos de salida a un volcado hexadecimal, desde la mezcla predeterminada de ASCII y volcado hexadecimal.

VERSIÓN
