PROLOGO

Esta página del manual es parte del Manual del Programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual correspondiente de Linux para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tdelete, tfind, tsearch, twalk — administrar un árbol de búsqueda binario

SINOPSIS

#include <search.h>
void *tdelete(const void *restrict key, void **restrict rootp,
    int(*compar)(const void *, const void *));
void *tfind(const void *key, void *const *rootp,
    int(*compar)(const void *, const void *));
void *tsearch(const void *key, void **rootp,
    int (*compar)(const void *, const void *));
void twalk(const void *root,
    void (*action)(const void *, VISIT, int));

DESCRIPCIÓN

Las funciones tdelete(), tfind(), tsearch(), y twalk() manipulan árboles de búsqueda binarios. Las comparaciones se realizan con una rutina proporcionada por el usuario, cuya dirección se pasa como argumento compar. Esta rutina se llama con dos argumentos, que son punteros a los elementos que se comparan. La aplicación deberá asegurarse de que la rutina proporcionada por el usuario devuelva un entero menor que, igual a, o mayor que 0, según si el primer argumento debe considerarse menor que, igual a, o mayor que el segundo argumento. La función de comparación no necesita comparar cada byte, por lo que pueden contenerse datos arbitrarios en los elementos además de los valores que se comparan.

La función tsearch() creará y accederá al árbol. El argumento key es un puntero a un elemento que se va a acceder o almacenar. Si hay un nodo en el árbol cuyo elemento es igual al valor apuntado por key, se devolverá un puntero a este nodo encontrado. De lo contrario, el valor apuntado por key se insertará (es decir, se creará un nuevo nodo y el valor de key se copiará a este nodo), y se devolverá un puntero a este nodo. Solo se copian los punteros, por lo que la aplicación deberá asegurarse de que la rutina de llamada almacene los datos. El argumento rootp apunta a una variable que apunta al nodo raíz del árbol. Un valor de puntero nulo para la variable apuntada por rootp denota un árbol vacío; en este caso, la variable se establecerá para que apunte al nodo que será la raíz del nuevo árbol.

Al igual que tsearch(), tfind() buscará un nodo en el árbol, devolviendo un puntero a él si se encuentra. Sin embargo, si no se encuentra, tfind() devolverá un puntero nulo. Los argumentos para tfind() son los mismos que para tsearch().

La función tdelete() eliminará un nodo de un árbol de búsqueda binario. Los argumentos son los mismos que para tsearch(). La variable apuntada por rootp se cambiará si el nodo eliminado era la raíz del árbol. Si el nodo eliminado era la raíz del árbol y no tenía hijos, la variable apuntada por rootp se establecerá a un puntero nulo. La función tdelete() devolverá un puntero al padre del nodo eliminado, o un puntero no nulo no especificado si el nodo eliminado era el nodo raíz, o un puntero nulo si el nodo no se encuentra.

Si tsearch() añade un elemento a un árbol, o tdelete() elimina con éxito un elemento de un árbol, el uso concurrente de ese árbol en otro hilo, o el uso de punteros producidos por una llamada anterior a tfind() o tsearch(), produce resultados indefinidos.

La función twalk() recorrerá un árbol de búsqueda binario. El argumento root es un puntero al nodo raíz del árbol que se va a recorrer. (Cualquier nodo de un árbol puede usarse como raíz para un recorrido por debajo de ese nodo.) El argumento action es el nombre de una rutina que se invocará en cada nodo. Esta rutina, a su vez, se llama con tres argumentos. El primer argumento será la dirección del nodo que se está visitando. La estructura apuntada por este argumento no se especifica y no debe ser modificada por la aplicación, pero deberá ser posible convertir un puntero-a-nodo en un puntero-a-puntero-a-elemento para acceder al elemento almacenado en el nodo. El segundo argumento será un valor de un tipo de enumeración:

typedef enum { preorder, postorder, endorder, leaf } VISIT;

(definido en <search.h>), dependiendo de si esta es la primera, segunda o tercera vez que se visita el nodo (durante un recorrido en profundidad de izquierda a derecha del árbol), o si el nodo es una hoja. El tercer argumento será el nivel del nodo en el árbol, con la raíz en el nivel 0.

Si la función de llamada altera el puntero a la raíz, el resultado es indefinido.

Si las funciones apuntadas por action o compar (para cualquiera de estas funciones de búsqueda binaria) cambian el árbol, los resultados son indefinidos.

Estas funciones son seguras para hilos solo mientras varios hilos no accedan al mismo árbol.

VALOR DE RETORNO

Si se encuentra el nodo, tanto tsearch() como tfind() devolverán un puntero a él. Si no, tfind() devolverá un puntero nulo, y tsearch() devolverá un puntero al elemento insertado.

Se devolverá un puntero nulo por tsearch() si no hay suficiente espacio disponible para crear un nuevo nodo.

Se devolverá un puntero nulo por tdelete(), tfind(), y tsearch() si rootp es un puntero nulo en la entrada.

La función tdelete() devolverá un puntero al padre del nodo eliminado, o un puntero no nulo no especificado si el nodo eliminado era el nodo raíz, o un puntero nulo si el nodo no se encuentra.

La función twalk() no devolverá ningún valor.

ERRORES

No se definen errores.

Las siguientes secciones son informativas.

EJEMPLOS

El siguiente código lee cadenas y almacena estructuras que contienen un puntero a cada cadena y un contador de su longitud. Luego recorre el árbol, imprimiendo las cadenas almacenadas y sus longitudes en orden alfabético.

#include <stdlib.h>

#include <stdio.h>

    int     count;
    char    string[];
};
void  *root = NULL;          /* This points to the root. */
int main(void)
{
    char   str[_POSIX2_LINE_MAX+1];
    int    length = 0;
    struct element *elementptr;
    void   *node;
    void   print_node(const void *, VISIT, int);
    int    node_compare(const void *, const void *),

    while (fgets(str, sizeof(str), stdin))  {
        /* Set element. */
        length = strlen(str);
        if (str[length-1] == '\n')
            str[--length] = '\0';
        elementptr = malloc(sizeof(struct element) + length + 1);
        strcpy(elementptr->string, str);
        elementptr->count = 1;
        /* Put element into the tree. */
        node = tsearch((void *)elementptr, &root, node_compare);
        if (node == NULL) {
            fprintf(stderr,
                    "tsearch: Not enough space available\n");
            exit(EXIT_FAILURE);
        }
        else if (*(struct element **)node != elementptr) {
            /* A node containing the element already exists */
            (*(struct element **)node)->count++;
            free(elementptr);
        }
    }
    twalk(root, print_node);
    /* Delete all nodes in the tree */
    while (root != NULL) {
        elementptr = *(struct element **)root;
        printf("deleting node: string = %s,  count = %d\n",
               elementptr->string,
               elementptr->count);
        tdelete((void *)elementptr, &root, delete_root);
        free(elementptr);
    }
    return 0;
}

NAME

tsearch, tdelete, twalk, tfind — maintain a binary search tree

SYNOPSIS

#include <search.h>

void *tsearch(const void *v_ptr, void **rootp, int (*comp)(const void *, const void *));

void *tdelete(const void *v_ptr, void **rootp, int (*comp)(const void *, const void *));

void twalk(const void *v_ptr, void (*action)(const void *, VISIT, int), int (*comp)(const void *, const void *));

void *tfind(const void *v_ptr, void **rootp, int (*comp)(const void *, const void *));

DESCRIPTION

These functions maintain a binary search tree. The tree nodes store pointers to user-supplied data. The ordering of the nodes in the tree is determined by the comparison function comp.

The comparison function comp must return an integer less than, equal to, or greater than zero if the first argument is considered to be less than, equal to, or greater than the second argument, respectively. It is the caller’s responsibility to ensure that the comparison function implements a total ordering of the keys.

The functions tsearch() and tdelete() use a comparison function comp to locate the node containing the specified key v_ptr. If rootp is NULL, a new tree is created. Otherwise, it points to a pointer to the root of the tree. It is the caller’s responsibility to initialize this pointer to NULL.

The tsearch() function inserts the element v_ptr into the tree if it is not already present. It returns a pointer to the data element in the tree. If the tree is newly created, the return value is the pointer to the data element inserted.

The tdelete() function deletes the element v_ptr from the tree. If the element is deleted, tdelete() returns a pointer to the new root of the tree. If the root of the tree is deleted, the return value is an unspecified non-NULL pointer. If the element is not found, tdelete() returns NULL.

The tfind() function searches the tree for the element v_ptr. If found, it returns a pointer to the element in the tree. Otherwise, it returns NULL.

The twalk() function traverses the tree using the traversal order specified by order. For each node visited, the function action is called. The action function is passed a pointer to the data element, a VISIT code, and the level of the node (root is level 0). The traversal starts from the root node pointed to by v_ptr.

The VISIT codes are:

  • preorder: Visit the node, then traverse the left subtree, then traverse the right subtree.
  • postorder: Traverse the left subtree, then traverse the right subtree, then visit the node.
  • endorder: Same as postorder.
  • leaf: Visit only leaf nodes.

The tsearch(), tdelete(), and tfind() functions use the rootp argument to point to the root of the tree. The twalk() function uses the v_ptr argument to point to the root of the tree.

The tree is composed of nodes of type NODE_T. Each node contains a key, which is a pointer to the user-supplied data, and pointers to the left and right children.

The tree functions allocate and deallocate memory for nodes using the standard malloc(3) and free(3) functions, respectively. It is the caller’s responsibility to free the memory allocated for the tree nodes when the tree is no longer needed.

RETURN VALUE

tsearch() returns a pointer to the data element in the tree, or NULL if memory allocation fails.

tdelete() returns a pointer to the new root of the tree, or NULL if the element was not found or if memory allocation fails.

tfind() returns a pointer to the data element in the tree if found, otherwise NULL.

twalk() returns no value.

ERRORS

The tree functions may call malloc(3) and free(3). If memory allocation fails, tsearch() and tfind() return NULL. tdelete() returns NULL if the element is not found or if memory allocation fails.

EXAMPLES

The following example demonstrates how to use tsearch() and tdelete() to build and maintain a binary search tree.

#include <stdio.h>
#include <search.h>

struct element {
    char *key;
    int value;
};

int
compare_elements(const void *a, const void *b)
{
    return strcmp(((const struct element *)a)->key, ((const struct element *)b)->key);
}

void
print_tree(const void *ptr, VISIT order, int level)
{
    const struct element *p = *(const struct element **) ptr;

    if (order == postorder || order == leaf) {
        (void) printf("key = %s, value = %d\n", p->key, p->value);
    }
}

int
main(void)
{
    void *root = NULL;
    struct element *elem;
    struct element **found;

    /* Insert elements into the tree */
    struct element elem1 = {"apple", 1};
    elem = tsearch(&elem1, &root, compare_elements);
    printf("Inserted %s, value %d\n", elem->key, elem->value);

    struct element elem2 = {"banana", 2};
    elem = tsearch(&elem2, &root, compare_elements);
    printf("Inserted %s, value %d\n", elem->key, elem->value);

    struct element elem3 = {"cherry", 3};
    elem = tsearch(&elem3, &root, compare_elements);
    printf("Inserted %s, value %d\n", elem->key, elem->value);

    /* Search for an element */
    struct element elem4 = {"banana", 0};
    found = tfind(&elem4, &root, compare_elements);
    if (found) {
        printf("Found %s, value %d\n", (*found)->key, (*found)->value);
    } else {
        printf("Did not find %s\n", elem4.key);
    }

    /* Traverse the tree */
    printf("Traversing tree (postorder):\n");
    twalk(root, print_tree, compare_elements);

    /* Delete an element */
    struct element elem5 = {"banana", 0};
    root = tdelete(&elem5, &root, compare_elements);
    printf("Deleted %s\n", elem5.key);

    /* Traverse the tree again */
    printf("Traversing tree after deletion (postorder):\n");
    twalk(root, print_tree, compare_elements);

    return 0;
}
