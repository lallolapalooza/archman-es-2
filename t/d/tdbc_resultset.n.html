tdbc_resultset(n)

Paquete: tcl

Licencias: TCL

tdbc::resultset(n) Conectividad de bases de datos TDBC tdbc::resultset(n)

NOMBRE

tdbc::resultset - Objeto conjunto de resultados TDBC

SINOPSIS

package require tdbc 1.0
package require tdbc::driver version
tdbc::driver::connection create db ?-option value...?
set stmt [db prepare sql-code]
set resultset [$stmt execute ?args...?]
$resultset columns
$resultset rowcount
$resultset nextrow ?-as lists|dicts? ?--? varname
$resultset nextlist varname
$resultset nextdict varname
$resultset nextresults

$resultset allrows ?-as lists|dicts? ?-columnsvariable name? ?--?
$resultset foreach ?-as lists|dicts? ?-columnsvariable name? ?--? varname script
$resultset close

DESCRIPCIÓN

Cada controlador de bases de datos para TDBC (Tcl DataBase Connectivity) implementa un objeto de *conjunto de resultados* que representa los resultados devueltos por la ejecución de una sentencia SQL en una base de datos. Las instancias de este objeto se crean ejecutando el comando de objeto execute sobre un objeto de sentencia.

El comando de objeto columns devuelve una lista de los nombres de las columnas en el conjunto de resultados. Las columnas aparecerán en el mismo orden en que aparecieron en la sentencia SQL que realizó la consulta a la base de datos. Si la sentencia SQL no devuelve un conjunto de columnas (por ejemplo, si es una sentencia INSERT, UPDATE o DELETE), el comando columns devolverá una lista vacía.

El comando de objeto rowcount devuelve el número de filas en la base de datos que se vieron afectadas por la ejecución de una sentencia INSERT, UPDATE o DELETE. Para una sentencia SELECT, el recuento de filas no está especificado.

El comando de objeto nextlist establece la variable dada por varname en el ámbito del llamador a la siguiente fila de los resultados, expresada como una lista de valores de columna. Los valores NULL se reemplazan por cadenas vacías. Las columnas de la fila de resultados aparecen en el mismo orden en que aparecieron en la sentencia SELECT. La devolución de nextlist es 1 si la operación tuvo éxito y 0 si se alcanzó el final del conjunto de resultados.

El comando de objeto nextdict establece la variable dada por varname en el ámbito del llamador a la siguiente fila de los resultados, expresada como un diccionario. Las claves del diccionario son los nombres de las columnas y los valores son los valores de esas columnas en la fila. Si el valor de una columna en la fila es NULL, su clave se omite del diccionario. Las claves aparecen en el diccionario en el mismo orden en que las columnas aparecieron en la sentencia SELECT. La devolución de nextdict es 1 si la operación tuvo éxito y 0 si se alcanzó el final del conjunto de resultados.

El comando de objeto nextrow es precisamente equivalente al comando de objeto nextdict o nextlist, dependiendo de si se especifica -as dicts (el valor por defecto) o -as lists.

Algunas bases de datos admiten la idea de una única sentencia que devuelve varios conjuntos de resultados. El comando de objeto nextresults se ejecuta, normalmente después de que el comando de objeto nextlist o nextdict haya devuelto 0, para avanzar al siguiente conjunto de resultados. Devuelve 1 si hay otro conjunto de resultados para procesar y 0 si el conjunto de resultados que se acaba de procesar fue el último. Después de llamar a nextresults y obtener el valor de retorno de 0, el llamador puede volver a llamar a columns para obtener las descripciones de las columnas del siguiente conjunto de resultados, y luego volver a llamar a nextdict o nextlist para procesar las filas del siguiente conjunto de resultados. Es un error llamar a columns, nextdict, nextlist o nextrow después de que nextresults haya devuelto 0.

El comando de objeto allrows establece la variable designada por la opción -columnsvariable (si está presente) al resultado del comando de objeto columns. Luego ejecuta el comando de objeto nextrow repetidamente hasta que se alcance el final del conjunto de resultados. Si nextresults devuelve un valor distinto de cero, ejecuta los dos pasos anteriores (columns seguido de llamadas iteradas a nextrow) mientras haya más resultados disponibles. Las filas devueltas por nextrow se ensamblan en una lista Tcl y se convierten en el valor de retorno del comando allrows; el último valor devuelto por columns es lo que la aplicación verá en -columnsvariable.

El comando de objeto foreach establece la variable designada por la opción -columnsvariable (si está presente) al resultado del comando de objeto columns. Luego ejecuta el comando de objeto nextrow repetidamente hasta que se alcance el final del conjunto de resultados, almacenando las filas sucesivas en la variable designada por varName. Para cada fila, ejecuta el script dado. Si el script termina con un error, el error es reportado por el comando foreach y la iteración se detiene. Si el script realiza una operación break, la iteración termina prematuramente. Si el script realiza una operación continue, la iteración se reinicia con la siguiente fila. Si el script realiza un return, los resultados son los mismos que si un script fuera del control de foreach hubiera devuelto. Cualquier otro código de retorno inusual termina la iteración y se reporta desde el foreach.

Una vez que nextrow devuelve 0, el comando de objeto foreach intenta avanzar al siguiente conjunto de resultados usando nextresults. Si nextresults devuelve 1, los pasos anteriores (columns y nextrow, con invocación de script) se repiten mientras queden más conjuntos de resultados. El script siempre verá la descripción correcta de las columnas del conjunto de resultados actual en la variable designada por -columnsvariable. Al final de la llamada, la variable designada por -columnsvariable tendrá la descripción de las columnas del último conjunto de resultados.

El comando de objeto close elimina el conjunto de resultados y libera cualquier recurso del sistema asociado.
