tsearch(3) Manual de funciones de la biblioteca tsearch(3)

NOMBRE

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy - gestionar un árbol de búsqueda binario

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* Véase feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

DESCRIPCIÓN

tsearch(), tfind(), twalk(), y tdelete() gestionan un árbol de búsqueda binario. Están generalizados del algoritmo T de Knuth (6.2.2). El primer campo en cada nodo del árbol es un puntero al elemento de datos correspondiente. (El programa que llama debe almacenar los datos reales.) compar apunta a una rutina de comparación, que toma punteros a dos elementos. Debería devolver un entero que sea negativo, cero o positivo, dependiendo de si el primer elemento es menor que, igual o mayor que el segundo.

tsearch() busca en el árbol un elemento. key apunta al elemento que se busca. rootp apunta a una variable que apunta a la raíz del árbol. Si el árbol está vacío, entonces la variable a la que apunta rootp debe establecerse a NULL. Si el elemento se encuentra en el árbol, entonces tsearch() devuelve un puntero al nodo del árbol correspondiente. (En otras palabras, tsearch() devuelve un puntero a un puntero al elemento de datos.) Si el elemento no se encuentra, entonces tsearch() lo añade y devuelve un puntero al nodo del árbol correspondiente.

tfind() es como tsearch(), excepto que si el elemento no se encuentra, entonces tfind() devuelve NULL.

tdelete() elimina un elemento del árbol. Sus argumentos son los mismos que para tsearch().

twalk() realiza una traversal de profundidad, de izquierda a derecha, de un árbol binario. root apunta al nodo de inicio para la traversal. Si ese nodo no es la raíz, entonces solo se visitará parte del árbol. twalk() llama a la función de usuario action cada vez que se visita un nodo (es decir, tres veces para un nodo interno y una vez para una hoja). action, a su vez, toma tres argumentos. El primer argumento es un puntero al nodo que se está visitando. La estructura del nodo no se especifica, pero es posible convertir el puntero a un puntero a puntero al elemento para acceder al elemento almacenado dentro del nodo. La aplicación no debe modificar la estructura apuntada por este argumento. El segundo argumento es un entero que toma uno de los valores preorder, postorder o endorder dependiendo de si esta es la primera, segunda o tercera visita al nodo interno, o el valor leaf si esta es la única visita a un nodo hoja. (Estos símbolos están definidos en <search.h>.) El tercer argumento es la profundidad del nodo; el nodo raíz tiene profundidad cero.

(Más comúnmente, preorder, postorder y endorder se conocen como preorden, inorden y postorden: antes de visitar los hijos, después del primero y antes del segundo, y después de visitar los hijos. Por lo tanto, la elección del nombre postorder es bastante confusa).

twalk_r() es similar a twalk(), pero en lugar del argumento depth, el puntero del argumento closure se pasa a cada invocación de la función de acción, sin cambios. Este puntero puede usarse para pasar información hacia y desde la función de callback de manera segura para hilos, sin recurrir a variables globales.

tdestroy() elimina todo el árbol apuntado por root, liberando todos los recursos asignados por la función tsearch(). Para los datos en cada nodo del árbol, se llama a la función free_node. El puntero a los datos se pasa como argumento a la función. Si no se necesita tal trabajo, free_node debe apuntar a una función que no haga nada.

VALOR DE RETORNO

tsearch() devuelve un puntero a un nodo coincidente en el árbol, o al nodo recién añadido, o NULL si no hubo suficiente memoria para añadir el elemento. tfind() devuelve un puntero al nodo, o NULL si no se encuentra ninguna coincidencia. Si hay varios elementos que coinciden con la clave, el elemento cuyo nodo se devuelve no está especificado.

tdelete() devuelve un puntero al padre del nodo eliminado, o NULL si el elemento no se encontró. Si el nodo eliminado era el nodo raíz, tdelete() devuelve un puntero colgante al que no se debe acceder.

tsearch(), tfind() y tdelete() también devuelven NULL si rootp era NULL en la entrada.

NOTAS

twalk() toma un puntero a la raíz, mientras que las otras funciones toman un puntero a una variable que apunta a la raíz.

tdelete() libera la memoria requerida para el nodo en el árbol. El usuario es responsable de liberar la memoria para los datos correspondientes.

El programa de ejemplo depende del hecho de que twalk() no hace más referencias a un nodo después de llamar a la función de usuario con el argumento "endorder" o "leaf". Esto funciona con la implementación de la biblioteca GNU, pero no está en la documentación de System V.

EJEMPLOS

El siguiente programa inserta doce números aleatorios en un árbol binario, donde los números duplicados se fusionan, y luego imprime los números en orden.

#define _GNU_SOURCE     /* Exponer la declaración de tdestroy */
#include <stdio.h>
#include <stdlib.h>
#include <search.h>
#include <errno.h>
static void *
root;
int
compar(const void *arth, const void *barth)
{
    const int *a = arth;
    const int *b = barth;
    if (*a < *b)
        return (-1);
    else if (*a > *b)
        return (1);
    else
        return (0);
}
static void
print_node(const void *nodep, VISIT order, int level)
{
    const int *const *node = nodep;
    if (order == preorder || order == postorder)
        return;
    printf("%d (level %d)", **node, level);
    if (order == leaf)
        printf(" leaf\n");
    else
        printf("\n");
}
int
main(void)
{
    int *retval;
    int data[] = { 5, 1, 7, 3, 8, 9, 2, 4, 6, 0, 10, 11 };
    size_t i;
    for (i = 0; i < sizeof(data) / sizeof(data[0]); ++i) {
        retval = tsearch(&data[i], &root, compar);
        if (retval == NULL) {
            if (errno == ENOMEM)
                fprintf(stderr, "Out of memory.\n");
            else
                fprintf(stderr, "tsearch: unexpected error %d.\n", errno);
            exit(EXIT_FAILURE);
        }
        if (*retval != data[i])
            printf("Duplicate: %d was already present.\n", data[i]);
    }
    printf("Traversing tree:\n");
    twalk(root, print_node);
    printf("Destroying tree...\n");
    tdestroy(root, NULL);
    printf("Done.\n");
    exit(EXIT_SUCCESS);
}
