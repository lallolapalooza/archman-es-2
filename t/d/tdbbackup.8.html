TDBBACKUP(8) Herramientas de administración del sistema TDBBACKUP(8)

NOMBRE

tdbbackup - herramienta para realizar copias de seguridad y validar la integridad de los archivos .tdb de samba

SINOPSIS

tdbbackup [-s sufijo] [-v] [-h] [-n tamaño_hash] [-l]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(1).

tdbbackup es una herramienta que puede ser utilizada para realizar copias de seguridad de los archivos .tdb de samba. Esta herramienta también puede ser utilizada para verificar la integridad de los archivos .tdb antes de iniciar samba o durante la operación normal. Si encuentra daños en el archivo y encuentra una copia de seguridad previa, se restaurará el archivo de copia de seguridad.

OPCIONES

-h

Obtener información de ayuda.

-s sufijo

La opción -s permite al administrador especificar una extensión para la copia de seguridad del archivo. De esta manera es posible mantener un historial de archivos de copia de seguridad de tdb utilizando un nuevo sufijo para cada copia de seguridad.

-v

La opción -v verificará la base de datos en busca de daños (datos corruptos) que, si se detectan, provocarán la restauración de la copia de seguridad.

-n tamaño_hash

La opción -n establece el tamaño del hash para el nuevo tdb de copia de seguridad.

-l

Esta opción deshabilita cualquier bloqueo, pasando TDB_NOLOCK a tdb_open_ex(). ¡Úsela solo para archivos de base de datos que no estén siendo utilizados por ningún otro proceso! Y también solo si de otra manera no es posible abrir la base de datos, por ejemplo, bases de datos que fueron creadas con bloqueo de mutua exclusión.

COMANDOS

INFORMACIÓN GENERAL

La utilidad tdbbackup puede ser ejecutada de forma segura en cualquier momento. Fue diseñada para poder ser utilizada en cualquier momento para validar la integridad de los archivos tdb, incluso durante la operación de Samba. El uso típico del comando será:

tdbbackup [-s sufijo] *.tdb

Antes de reiniciar samba, se puede ejecutar el siguiente comando para validar los archivos .tdb:

tdbbackup -v [-s sufijo] *.tdb

Los archivos .tdb de Samba se almacenan en varias ubicaciones, asegúrese de realizar una copia de seguridad de todos los archivos .tdb del sistema. Los archivos importantes incluyen:

•secrets.tdb - ubicación habitual en el directorio /usr/local/samba/private, o en algunos sistemas en /etc/samba.
•passdb.tdb - ubicación habitual en el directorio /usr/local/samba/private, o en algunos sistemas en /etc/samba.
•*.tdb ubicados en el directorio /usr/local/samba/var o en algunos sistemas en los directorios /var/cache o /var/lib/samba.
