tdbc::mysql(n) Conectividad de bases de datos Tcl tdbc::mysql(n)

NOMBRE

tdbc::mysql - Puente TDBC-MYSQL

SINOPSIS

package require tdbc::mysql 1.0

tdbc::mysql::connection create db ?-opción valor...?
tdbc::mysql::connection new ?-opción valor...?

tdbc::mysql::datasources ?-system|-user?

tdbc::mysql::drivers

tdbc::mysql::datasource comando nombreDriver ?palabraClave-valor?...

DESCRIPCIÓN

El controlador tdbc::mysql proporciona una interfaz de base de datos que se ajusta a la Conectividad de Bases de Datos Tcl (TDBC) y permite que un script Tcl se conecte a una base de datos MySQL.

La conexión a una base de datos MYSQL se establece invocando tdbc::mysql::connection create, pasándole el nombre que se le dará al manejador de la base de datos y un conjunto de pares -opción-valor. Las opciones disponibles se enumeran en OPCIONES DE CONEXIÓN más abajo. Como alternativa, se puede usar tdbc::mysql::connection new para crear una conexión a la base de datos con un nombre asignado automáticamente. El valor de retorno de tdbc::mysql::connection new es el nombre que se eligió para el manejador de la conexión.

El efecto secundario de tdbc::mysql::connection create es la creación de una nueva conexión a la base de datos. Consulte tdbc::connection(n) para obtener detalles sobre cómo usar la conexión para manipular una base de datos.

OPCIONES DE CONEXIÓN

El comando de objeto tdbc::mysql::connection create admite las opciones -encoding, -isolation, -readonly y -timeout comunes a todos los controladores TDBC. La opción -encoding siempre fallará a menos que la codificación sea utf-8; la conexión a la base de datos siempre utiliza la codificación UTF-8 para poder transferir caracteres Unicode arbitrarios. La opción -readonly debe ser 0, ya que MySQL no ofrece conexiones de solo lectura.

Además, se reconocen las siguientes opciones:

-host nombreHost
Se conecta al host especificado por nombreHost. Esta opción debe establecerse en la creación inicial de la conexión; no se puede cambiar después de conectarse. El valor predeterminado es conectarse al host local.
-port número
Se conecta a un servidor MySQL que escucha en el puerto especificado por número. Esta opción no se puede cambiar después de conectarse. Se utiliza solo cuando se especifica host y no es localhost.
-socket ruta
Se conecta a un servidor MySQL que escucha en el socket Unix o pipe con nombre especificado por ruta. Esta opción no se puede cambiar después de conectarse. Se utiliza solo cuando -host no se especifica o es localhost.
-user nombre
Presenta nombre como el nombre de usuario al servidor MySQL. El valor predeterminado es el ID de usuario actual.
-passwd contraseña
-password contraseña
Estas dos opciones son sinónimas. Presentan la contraseña dada como contraseña del usuario al servidor MySQL. El valor predeterminado es no presentar contraseña.
-database nombre
-db nombre
Estas dos opciones son sinónimas. Presentan el nombre dado como el nombre de la base de datos predeterminada a utilizar en las consultas MySQL. Si no se especifica, se utiliza la base de datos predeterminada para el usuario actual.
-interactive bandera
El valor de bandera debe ser un valor booleano. Si es true (o cualquier equivalente), el tiempo de espera predeterminado se establece para un usuario interactivo, de lo contrario, el tiempo de espera predeterminado se establece para un usuario de lotes. Esta opción solo es significativa en la conexión inicial. Al usar el método configure en una conexión MySQL, use la opción -timeout para establecer el tiempo de espera deseado.
-ssl_ca
-ssl_capath
-ssl_cert
-ssl_cipher
-ssl_key
Estas cinco opciones establecen la autoridad de certificación, la ruta de búsqueda de la autoridad de certificación, el certificado SSL, el cifrado de transferencia y la clave SSL a los argumentos de cadena dados. Estas opciones solo se pueden especificar en la conexión inicial a una base de datos, no en el método configure de una conexión existente. El valor predeterminado es no usar SSL.

EJEMPLOS

tdbc::mysql::connection -user joe -passwd sesame -db joes_database

Se conecta al servidor MySQL en el host local utilizando el método de conexión predeterminado, presentando el ID de usuario 'joe' y la contraseña 'sesame'. Utiliza 'joes_database' como el nombre de la base de datos predeterminada.

MÉTODOS DE CONEXIÓN ADICIONALES

Además de los métodos habituales en el objeto tdbc::connection(n), las conexiones a una base de datos MySQL admiten un método adicional:

$conexión evaldirect sentenciaSql
Este método toma la sentenciaSql dada y la interpreta como código SQL nativo de MySQL y la evalúa sin prepararla. La sentencia no puede contener sustituciones de variables. El conjunto de resultados se devuelve como una lista de listas, donde cada sublista es la lista de columnas de una fila de resultados formateada como cadenas de texto. Tenga en cuenta que el formateo de cadenas lo realiza MySQL y no Tcl, por lo que los detalles, como la apariencia de los números de punto flotante, pueden diferir. Este comando no se recomienda para nada en lo que los métodos habituales prepare o preparecall funcionen correctamente. Se proporciona para que se puedan ejecutar sentencias de lenguaje de administración de datos que no están implementadas en la API de sentencias preparadas de MySQL, como CREATE DATABASE o CREATE PROCEDURE.
