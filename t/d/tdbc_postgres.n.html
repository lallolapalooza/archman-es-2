tdbc::postgres(n) Conectividad de bases de datos Tcl tdbc::postgres(n)

NOMBRE

tdbc::postgres - Puente TDBC-POSTGRES

SINOPSIS

package require tdbc::postgres 1.0

tdbc::postgres::connection create db ?-opción valor...?
tdbc::postgres::connection new ?-opción valor...?

DESCRIPCIÓN

El controlador tdbc::postgres proporciona una interfaz de base de datos que cumple con la conectividad de bases de datos Tcl (TDBC) y permite que un script Tcl se conecte a una base de datos Postgres.

La conexión a una base de datos POSTGRES se establece invocando tdbc::postgres::connection create, pasándole el nombre que se le dará al manejador de la base de datos y un conjunto de pares -opción-valor. Las opciones disponibles se enumeran en OPCIONES DE CONEXIÓN a continuación. Como alternativa, se puede usar tdbc::postgres::connection new para crear una conexión de base de datos con un nombre asignado automáticamente. El valor de retorno de tdbc::postgres::connection new es el nombre que se eligió para el manejador de conexión.

El efecto secundario de tdbc::postgres::connection create es crear una nueva conexión de base de datos. Consulte tdbc::connection(n) para obtener detalles sobre cómo usar la conexión para manipular una base de datos.

OPCIONES DE CONEXIÓN

El comando de objeto tdbc::postgres::connection create soporta las opciones -encoding, -isolation, -readonly y -timeout comunes a todos los controladores TDBC. La opción -timeout solo afectará al proceso de conexión; una vez conectado, este valor será ignorado y no se puede cambiar después de la conexión.

Además, se reconocen las siguientes opciones (estas opciones deben establecerse en la creación inicial de la conexión; no se pueden cambiar después de la conexión):

-host nombre_host
Se conecta al host especificado por nombre_host. El valor por defecto es conectarse usando un socket de dominio Unix local.
-hostaddr dirección
Se conecta al host especificado por la dirección IP dada. Si se proporcionan tanto -host como -hostaddr, se ignora el valor de -host. El valor por defecto es conectarse usando un socket de dominio Unix local.
-port número
Se conecta a un servidor Postgres escuchando en el puerto especificado por número. Solo se usa cuando se especifica host o hostaddr.
-user nombre
Presenta nombre como el nombre de usuario al servidor Postgres. El valor por defecto es el ID de usuario actual.
-passwd contraseña
-password contraseña
Estas dos opciones son sinónimas. Presentan la contraseña dada como la contraseña del usuario al servidor Postgres. El valor por defecto es no presentar ninguna contraseña.
-database nombre
-db nombre
Estas dos opciones son sinónimas. Presentan el nombre dado como el nombre de la base de datos por defecto a utilizar en las consultas de Postgres. Si no se especifica, se utiliza la base de datos por defecto para el usuario actual.
-options opts
Esto establece opts como opciones adicionales de línea de comandos enviadas al servidor.
-tty archivo
Esta opción se ignora en los servidores antiguos. Anteriormente, especificaba dónde enviar la salida de depuración. Esta opción se mantiene por compatibilidad con servidores más antiguos.
-sslmode modo
Esta opción determina si se negociará una conexión SSL con el servidor y con qué prioridad. Hay cuatro modos: disable intentará solo una conexión SSL no cifrada; allow negociará, intentando primero una conexión no SSL, luego si falla, intentando una conexión SSL; prefer (el valor por defecto) negociará, intentando primero una conexión SSL, luego si falla, intentando una conexión no SSL regular; require intentará solo una conexión SSL. Si PostgreSQL se compila sin soporte SSL, usar la opción require causará un error, y las opciones allow y prefer serán toleradas pero el controlador no podrá negociar una conexión SSL.
-requiressl
Esta opción está obsoleta en favor de la configuración de -sslmode. El valor de flag debe ser un valor booleano. Si es true (o cualquier equivalente), el controlador se negará a conectarse si el servidor no acepta una conexión SSL. El valor por defecto es false (o cualquier equivalente), y actúa de la misma manera que -sslmode preferido
-service
Especifica un nombre de servicio en el archivo pg_service.conf que contiene parámetros de conexión adicionales. Esto permite a las aplicaciones especificar solo un nombre de servicio para que los parámetros de conexión puedan mantenerse centralmente. Consulte la Documentación de PostgreSQL o el archivo PREFIX/share/pg_service.conf.sample para obtener detalles.

EJEMPLOS

tdbc::postgres::connection -user joe -passwd sesame -db joes_database

Se conecta al servidor Postgres en la máquina local usando el método de conexión por defecto, presentando el ID de usuario 'joe' y la contraseña 'sesame'. Usa 'joes_database' como nombre de base de datos por defecto.
