tdbc::statement(n) Conectividad de base de datos Tcl tdbc::statement(n)

NOMBRE

tdbc::statement - Objeto de sentencia TDBC

SINOPSIS

package require tdbc 1.0
package require tdbc::driver version
tdbc::driver::connection create db ?-option value...?
set stmt [db prepare código-sql]
set stmt [db preparecall llamada]
$stmt params
$stmt paramtype ?dirección? tipo ?precisión? ?escala?
$stmt execute ?diccionario?
$stmt resultsets

$stmt allrows ?-as listas|diccionarios? ?-columnsvariable nombre? ?--? ?diccionario
$stmt foreach ?-as listas|diccionarios? ?-columnsvariable nombre? ?--? nombreVar ?diccionario? script
$stmt close

DESCRIPCIÓN

Cada controlador de base de datos para TDBC (Tcl DataBase Connectivity) implementa un objeto de sentencia que representa una sentencia SQL en una base de datos. Las instancias de este objeto se crean ejecutando el comando de objeto prepare o preparecall en una conexión de base de datos.

El comando de objeto prepare contra la conexión acepta código SQL arbitrario para ser ejecutado contra la base de datos. El código SQL puede contener variables enlazadas, que son cadenas de caracteres alfanuméricos o guiones bajos (el primer carácter de la cadena no puede ser numérico), prefijados con dos puntos (:). Si una variable enlazada aparece en la sentencia SQL, y no está en una cadena delimitada por comillas simples o dobles, ni en un comentario introducido por --, se convierte en un valor que se sustituye cuando la sentencia se ejecuta. Una variable enlazada se convierte en un valor único (cadena o numérico) en la sentencia resultante. Los controladores son responsables de asegurar que el mecanismo para enlazar variables previene la inyección SQL.

El comando de objeto preparecall contra la conexión acepta una sentencia estilizada en la forma:

nombreproc (?:nombrevar? ?,:nombrevar...?)

o

nombrevar = nombreproc (?:nombrevar? ?,:nombrevar...?)

Esta sentencia representa una llamada a un procedimiento almacenado nombreproc en la base de datos. El nombre de variable a la izquierda del signo igual (si está presente), y todos los nombres de variables que son parámetros dentro de los paréntesis, se convierten en variables enlazadas.

El comando de objeto params contra un objeto de sentencia enumera las variables enlazadas que aparecen en la sentencia. El resultado devuelto por el comando params es un diccionario cuyas claves son los nombres de las variables enlazadas (listados en el orden en que las variables aparecen por primera vez en la sentencia), y cuyos valores son diccionarios. Los sub-diccionarios incluyen al menos las siguientes claves (los controladores de base de datos pueden añadir claves adicionales que no están en esta lista).

dirección
Contiene una de las palabras clave, in, out o inout según si la variable es una entrada o salida de la sentencia. Solo las llamadas a procedimientos almacenados tendrán parámetros out o inout.
tipo
Contiene el tipo de dato de la columna, y generalmente será elegido del conjunto, bigint, binary, bit, char, date, decimal, double, float, integer, longvarbinary, longvarchar, numeric, real, time, timestamp, smallint, tinyint, varbinary, y varchar. (Si la variable tiene un tipo que no puede representarse como uno de los anteriores, tipo contendrá una descripción dependiente del controlador del tipo.)
precisión
Contiene la precisión de la columna en bits, dígitos decimales, o el ancho en caracteres, de acuerdo con el tipo.
escala
Contiene la escala de la columna (el número de dígitos después del punto decimal), para los tipos que soportan el concepto.
nullable
Contiene 1 si la columna puede contener valores NULL, y 0 en caso contrario.

El comando de objeto paramtype permite al script especificar el tipo y la dirección de la transmisión de parámetros de una variable en una sentencia. (Algunas bases de datos no proporcionan ningún método para determinar esta información automáticamente y dejan la carga al llamador para hacerlo.) Los argumentos dirección, tipo, precisión, escala y nullable tienen el mismo significado que los valores de diccionario correspondientes en el comando de objeto params.

El comando de objeto execute ejecuta la sentencia. Antes de ejecutar la sentencia, se proporcionan valores para las variables enlazadas que aparecen en ella. Si se suministra el parámetro diccionario, se busca en él una clave cuyo nombre coincida con el nombre de la variable enlazada. Si la clave está presente, su valor se convierte en la variable sustituida. Si no, el valor de la variable sustituida se convierte en un NULL de SQL. Si el parámetro diccionario no se suministra, el comando execute busca una variable en el ámbito del llamador cuyo nombre coincida con el nombre de la variable enlazada. Si se encuentra una, su valor se convierte en el valor de la variable enlazada. Si no se encuentra ninguna, a la variable enlazada se le asigna un NULL de SQL como valor. Una vez terminada la sustitución, se ejecuta la sentencia resultante. El valor de retorno es un objeto de conjunto de resultados (ver tdbc::resultset para detalles).

El comando de objeto resultsets devuelve una lista de todos los conjuntos de resultados que han sido devueltos por la ejecución de la sentencia y aún no han sido cerrados.

El comando de objeto allrows ejecuta la sentencia como con el comando de objeto execute, aceptando un parámetro opcional diccionario que proporciona variables de enlace. Después de ejecutar la sentencia, utiliza el comando allrows del conjunto de resultados (ver tdbc::resultset) para construir una lista de los resultados. Finalmente, el conjunto de resultados se cierra. El valor de retorno es la lista de resultados.

El comando de objeto foreach ejecuta la sentencia como con el comando de objeto execute, aceptando un parámetro opcional diccionario que proporciona variables de enlace. Después de ejecutar la sentencia, utiliza el comando foreach del conjunto de resultados (ver tdbc::resultset) para evaluar el script dado para cada fila de los resultados. Finalmente, el conjunto de resultados se cierra, incluso si el script dado resulta en un return, un error o un código de retorno inusual.

El comando de objeto close elimina una sentencia y cualquier conjunto de resultados que haya creado. Todos los recursos del sistema asociados con los objetos son liberados.

EJEMPLOS

El siguiente código buscaría un número de teléfono en una guía, asumiendo un esquema SQL apropiado:

package require tdbc::sqlite3
tdbc::sqlite3::connection create db phonebook.sqlite3
set statement [db prepare {
    select phone_num from directory
    where first_name = :firstname and last_name = :lastname
}]
set firstname Fred
set lastname Flintstone
$statement foreach row {
    puts [dict get $row phone_num]
}
$statement close
db close
