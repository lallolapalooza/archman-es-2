tdbc::tokenize(n) Conectividad de bases de datos TDBC tdbc::tokenize(n)

NOMBRE

tdbc::tokenize - Tokenizador SQL de TDBC

SINOPSIS

package require tdbc 1.0
tdbc::tokenize cadena

DESCRIPCIÓN

Como una conveniencia para los controladores de bases de datos, Tcl Database Connectivity (TDBC) proporciona un comando para dividir código SQL en tokens de modo que las variables enlazadas puedan identificarse y sustituirse fácilmente.

El comando tdbc::tokenize acepta como parámetro una cadena que se espera contenga una o más sentencias SQL. Devuelve una lista de subcadenas; la concatenación de estas subcadenas producirá la cadena original. Cada subcadena es una de las siguientes:

[1]
Una variable enlazada, que comienza con uno de los caracteres ':', '@', o '$'. El resto de la cadena es el nombre de la variable y consistirá en caracteres alfanuméricos y guiones bajos. (El carácter inicial no será numérico.)
[2]
Un punto y coma que separa dos sentencias SQL.
[3]
Algo más en una sentencia SQL. El tokenizador no intenta analizar SQL; simplemente identifica variables enlazadas (distinguiéndolas de cadenas similares que aparecen dentro de comillas o comentarios) y delimitadores de sentencia.
