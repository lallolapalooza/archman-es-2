tdbc::sqlite3(n) Conectividad de Base de Datos Tcl tdbc::sqlite3(n)

NOMBRE

tdbc::sqlite3 - Controlador TDBC para el gestor de bases de datos SQLite3

SINOPSIS

package require tdbc::sqlite3 1.0

tdbc::sqlite3::connection create db nombreArchivo ?-opción valor...?

DESCRIPCIÓN

El controlador tdbc::sqlite3 proporciona una interfaz de base de datos que se ajusta a la Conectividad de Base de Datos Tcl (TDBC) y permite que un script Tcl se conecte a una base de datos SQLite3. También se proporciona como un ejemplo de trabajo de cómo escribir un controlador de base de datos en Tcl, para que los autores de controladores tengan un punto de partida para un mayor desarrollo.

La conexión a una base de datos SQLite3 se establece invocando tdbc::sqlite3::connection create, pasándole una cadena para ser usada como manejador de conexión seguido del nombre del archivo de la base de datos. El efecto secundario de tdbc::sqlite3::connection create es crear una nueva conexión a la base de datos. Como alternativa, se puede usar tdbc::sqlite::connection new para crear una conexión a la base de datos con un nombre asignado automáticamente. El valor de retorno de tdbc::sqlite::connection new es el nombre que se eligió para el manejador de conexión. Consulte tdbc::connection(n) para obtener los detalles de cómo usar la conexión para manipular una base de datos.

OPCIONES DE CONFIGURACIÓN

Las opciones de configuración estándar -encoding, -isolation, -readonly y -timeout son reconocidas, tanto en tdbc::sqlite3::connection create como en el método configure de la conexión resultante.

Dado que la codificación de una base de datos SQLite3 siempre se conoce bien, la opción -encoding solo acepta utf-8 como codificación y siempre devuelve utf-8 como codificación. La codificación real se puede establecer usando una declaración PRAGMA de SQLite3 al crear una nueva base de datos.

Solo se implementan los niveles de aislamiento readuncommitted y serializable. Otros niveles de aislamiento se promocionan a serializable.

La bandera -readonly no está implementada. Se acepta un valor booleano false silenciosamente, mientras que cualquier otro valor genera un error.

La bandera -keepcase es especial y controla cómo se informan los nombres de tablas y columnas en los diversos métodos para recuperar metadatos de la base de datos. Por defecto, la bandera es cero, es decir, los nombres de tablas y columnas se informan en minúsculas. De lo contrario, los nombres de tablas y columnas se informan como se definen en la base de datos.

ERRORES

Si algún nombre de columna no es único entre las columnas en un conjunto de resultados, los resultados de -as dicts devueltos carecerán de todas las columnas duplicadas excepto la más a la derecha. Esta limitación se puede solucionar añadiendo cláusulas AS apropiadas a las instrucciones SELECT para asegurar que todos los nombres de columnas devueltos sean únicos. Hay planes para corregir este error utilizando una implementación en C del controlador, lo que también mejorará significativamente el rendimiento.
