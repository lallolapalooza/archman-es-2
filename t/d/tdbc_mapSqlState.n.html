tdbc::mapSqlState(n) Conectividad de base de datos Tcl tdbc::mapSqlState(n)

NOMBRE

tdbc::mapSqlState - Mapear SQLSTATE a clase de error

SINOPSIS

package require tdbc 1.0
tdbc::mapSqlState sqlstate

DESCRIPCIÓN

El comando tdbc::mapSqlState acepta una cadena que se espera sea un 'estado SQL' de cinco caracteres devuelto por una base de datos SQL cuando ocurre un error. Examina los dos primeros caracteres de la cadena y devuelve una clase de error como un nombre legible para humanos y máquinas (por ejemplo, FEATURE_NOT_SUPPORTED, DATA_EXCEPTION o INVALID_CURSOR_STATE).

La especificación TDBC requiere que los controladores de base de datos devuelvan una descripción de un error en el código de error cuando ocurre un error. La descripción es una cadena que tiene al menos cuatro elementos: "TDBC errorClass sqlstate driverName details...". El comando tdbc::mapSqlState proporciona una forma conveniente para que un controlador TDBC genere el elemento errorClass dado el estado SQL devuelto por una base de datos.
