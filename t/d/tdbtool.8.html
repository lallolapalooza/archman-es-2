TDBTOOL(8) Herramientas de administración del sistema TDBTOOL(8)

NOMBRE

tdbtool - manipular el contenido de los archivos TDB

SINOPSIS

tdbtool

tdbtool [-l] ARCHIVO TDB [COMANDOS...]

DESCRIPCIÓN

Esta herramienta forma parte del conjunto samba(1).

tdbtool es una herramienta para mostrar y modificar el contenido de los archivos TDB (Base de Datos Trivial) de Samba. Cada uno de los comandos listados a continuación puede introducirse interactivamente o proporcionarse en la línea de comandos.

OPCIONES

-l

Esta opción deshabilita cualquier bloqueo, pasando TDB_NOLOCK a tdb_open_ex(). ¡Solo úsela para archivos de base de datos que no estén siendo utilizados por ningún otro proceso! Y también solo si de otra manera no es posible abrir la base de datos, por ejemplo, bases de datos que se crearon con bloqueo de exclusión mutua (mutex).

COMANDOS

create ARCHIVO TDB

Crea una nueva base de datos llamada ARCHIVO TDB.

open ARCHIVO TDB

Abre una base de datos existente llamada ARCHIVO TDB.

erase

Borra la base de datos actual.

dump

Vuelca la base de datos actual como cadenas de texto.

cdump

Vuelca la base de datos actual como registros de conexión.

keys

Vuelca las claves de la base de datos actual como cadenas de texto.

hexkeys

Vuelca las claves de la base de datos actual como valores hexadecimales.

info

Imprime información resumen sobre la base de datos actual.

insert CLAVE DATOS

Inserta un registro en la base de datos actual.

move CLAVE ARCHIVO TDB

Mueve un registro de la base de datos actual a ARCHIVO TDB.

store CLAVE DATOS

Almacena (reemplaza) un registro en la base de datos actual.

storehex CLAVE DATOS

Almacena (reemplaza) un registro en la base de datos actual donde la clave y los datos están en formato hexadecimal.

show CLAVE

Muestra un registro por clave.

delete CLAVE

Elimina un registro por clave.

list

Imprime la tabla hash de la base de datos actual y la lista de libres.

free

Imprime la base de datos actual y la lista de libres.

! COMANDO

Ejecuta el comando del sistema dado.

first

Imprime el primer registro de la base de datos actual.

next

Imprime el siguiente registro de la base de datos actual.

check

Comprueba la integridad de la base de datos actual.

repack

Repackea una base de datos usando un archivo temporal para eliminar la fragmentación.

quit

Sale de tdbtool.

ADVERTENCIAS

El contenido de los archivos TDB de Samba es privado de la implementación y no debe ser alterado con tdbtool.

VERSIÓN

Esta página del manual es correcta para la versión 3.6 del conjunto Samba.

ESTADO DE SALIDA

El programa tdbtool devuelve 0 si la operación tuvo éxito, o 1 si la operación falló.
