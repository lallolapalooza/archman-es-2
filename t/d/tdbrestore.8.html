TDBRESTORE(8) Herramientas de administración del sistema TDBRESTORE(8)

NOMBRE

tdbrestore - herramienta para crear un archivo TDB a partir de la salida de tdbdump

SINOPSIS

tdbrestore {nombre_archivo_tdb}

DESCRIPCIÓN

Esta herramienta forma parte del conjunto de utilidades de samba(1).

tdbrestore es una utilidad muy simple que 'restaura' el contenido de un archivo de volcado en un archivo TDB (Base de Datos Trivial). El archivo de volcado se obtiene del comando tdbdump.

Esta herramienta espera la entrada estándar para obtener el contenido del volcado y escribirá el tdb en el parámetro nombre_archivo_tdb.

Esta herramienta se puede utilizar para desempaquetar el contenido de tdb como medio de copia de seguridad.
