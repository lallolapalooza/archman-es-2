NOMBRE

tdbc - Conectividad de Base de Datos Tcl

SINOPSIS

package require tdbc 1.0
package require tdbc::driver version
tdbc::driver::connection create db ?-opción valor...?

DESCRIPCIÓN

Tcl Database Connectivity (TDBC) es una interfaz común para que los programas Tcl accedan a bases de datos SQL. Se implementa mediante una serie de controladores de base de datos: módulos separados, cada uno de los cuales adapta Tcl a la interfaz de un sistema de base de datos en particular. Todos los controladores implementan una serie común de comandos para manipular la base de datos. Todos estos comandos se nombran dinámicamente, ya que todos representan objetos en el sistema de base de datos. Incluyen conexiones, que representan conexiones a una base de datos; sentencias, que representan sentencias SQL, y conjuntos de resultados, que representan los conjuntos de filas que resultan de la ejecución de sentencias. Todos estos tienen sus propias páginas de manual, listadas en VER TAMBIÉN.

Además, TDBC en sí tiene algunos procedimientos de servicio que son principalmente de interés para los escritores de controladores. VER TAMBIÉN también los enumera.
