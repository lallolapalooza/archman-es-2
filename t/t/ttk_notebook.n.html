ttk::notebook(n) Tk Themed Widget ttk::notebook(n)

NOMBRE

ttk::notebook - Widget contenedor de múltiples paneles

SINOPSIS

ttk::notebook ruta ?opciones...?
ruta add ventana ?opciones...?
ruta insert índice ventana ?opciones...?

DESCRIPCIÓN

Un widget ttk::notebook gestiona una colección de ventanas y muestra solo una a la vez. Cada ventana de contenido está asociada con una pestaña, que el usuario puede seleccionar para cambiar la ventana actualmente mostrada.

OPCIONES ESTÁNDAR

-class	-cursor	-takefocus
-style

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Si está presente y es mayor que cero, especifica la altura deseada del área del panel (sin incluir el relleno interno ni las pestañas). De lo contrario, se utiliza la altura máxima de todos los paneles.
Nombre de línea de comandos:	-padding
Nombre de base de datos:	padding
Clase de base de datos:	Padding
Especifica la cantidad de espacio adicional que se agregará alrededor del exterior del notebook. El relleno es una lista de hasta cuatro especificaciones de longitud izquierda arriba derecha abajo. Si se especifican menos de cuatro elementos, abajo por defecto es arriba, derecha por defecto es izquierda, y arriba por defecto es izquierda. En otras palabras, una lista de tres números especifica el relleno izquierdo, vertical y derecho; una lista de dos números especifica el relleno horizontal y vertical; un solo número especifica el mismo relleno alrededor del widget completo.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Si está presente y es mayor que cero, especifica el ancho deseado del área del panel (sin incluir el relleno interno). De lo contrario, se utiliza el ancho máximo de todos los paneles.

OPCIONES DE PESTAÑA

Las siguientes opciones se pueden especificar para paneles individuales del notebook:

Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Puede ser normal, disabled o hidden. Si es disabled, entonces la pestaña no es seleccionable. Si es hidden, entonces la pestaña no se muestra.
Nombre de línea de comandos:	-sticky
Nombre de base de datos:	sticky
Clase de base de datos:	Sticky
Especifica cómo se posiciona la ventana de contenido dentro del área del panel. El valor es una cadena que contiene cero o más de los caracteres n, s, e, o w. Cada letra se refiere a un lado (norte, sur, este u oeste) al que se "pegará" la ventana de contenido, según el administrador de geometría grid.
Nombre de línea de comandos:	-padding
Nombre de base de datos:	padding
Clase de base de datos:	Padding
Especifica la cantidad de espacio adicional que se agregará entre el notebook y este panel. La sintaxis es la misma que para la opción -padding del widget.
Nombre de línea de comandos:	-text
Nombre de base de datos:	text
Clase de base de datos:	Text
Especifica una cadena que se mostrará en la pestaña.
Nombre de línea de comandos:	-image
Nombre de base de datos:	image
Clase de base de datos:	Image
Especifica una imagen para mostrar en la pestaña. Consulte ttk_widget(n) para obtener detalles.
Nombre de línea de comandos:	-compound
Nombre de base de datos:	compound
Clase de base de datos:	Compound
Especifica cómo mostrar la imagen en relación con el texto, en caso de que estén presentes tanto -text como -image. Consulte label(n) para ver los valores permitidos.
Nombre de línea de comandos:	-underline
Nombre de base de datos:	underline
Clase de base de datos:	Underline
Especifica el índice entero (basado en 0) de un carácter para subrayar en la cadena de texto. El carácter subrayado se utiliza para la activación mneomónica si se llama a ttk::notebook::enableTraversal.

IDENTIFICADORES DE PESTAÑA

El argumento id_pestaña para los siguientes comandos puede tomar cualquiera de las siguientes formas:

  • Un entero entre cero y el número de pestañas;
  • El nombre de una ventana de contenido;
  • Una especificación posicional de la forma “@x,y”, que identifica la pestaña
  • La cadena literal “current”, que identifica la pestaña seleccionada actualmente; o:
  • La cadena literal “end”, que devuelve el número de pestañas (solo válido para “ruta index”).

COMANDO DEL WIDGET

ruta add ventana ?opciones...?
Agrega una nueva pestaña al notebook. Consulte OPCIONES DE PESTAÑA para ver la lista de opciones disponibles. Si ventana es gestionada actualmente por el notebook pero oculta, se restaura a su posición anterior.
ruta configure ?opciones?
Consulte ttk::widget(n).
ruta cget opción
Consulte ttk::widget(n).
ruta forget id_pestaña
Elimina la pestaña especificada por id_pestaña, desmapeando y eliminando la gestión de la ventana asociada.
ruta hide id_pestaña
Oculta la pestaña especificada por id_pestaña. La pestaña no se mostrará, pero la ventana asociada seguirá siendo gestionada por el notebook y su configuración se recordará. Las pestañas ocultas se pueden restaurar con el comando add.
ruta identify componente x y
Devuelve el nombre del elemento que se encuentra debajo del punto dado por x e y, o una cadena vacía si no hay ningún componente en esa ubicación. Los siguientes subcomandos son compatibles:
ruta identify element x y
Devuelve el nombre del elemento en la ubicación especificada.
ruta identify tab x y
Devuelve el índice de la pestaña en la ubicación especificada.
ruta index id_pestaña
Devuelve el índice numérico de la pestaña especificada por id_pestaña, o el número total de pestañas si id_pestaña es la cadena “end”.
ruta insert pos subventana opciones...
Inserta un panel en la posición especificada. pos es la cadena end, un índice numérico, o el nombre de una subventana gestionada. Si subventana ya está gestionada por el notebook, se mueve a la posición especificada. Consulte OPCIONES DE PESTAÑA para ver la lista de opciones disponibles.
ruta instate espec_estados ?script...?
Consulte ttk::widget(n).
ruta select ?id_pestaña?
Selecciona la pestaña especificada. La ventana de contenido asociada se mostrará, y la ventana seleccionada previamente (si es diferente) se desmapea. Si se omite id_pestaña, devuelve el nombre del widget de la ventana actualmente seleccionada.
ruta state ?espec_estados?
Consulte ttk::widget(n).
ruta tab id_pestaña ?-opción ?valor ...

TRAVERSAL DEL TECLADO

Para habilitar el traversal del teclado para una ventana de nivel superior que contiene un widget de notebook $nb, llame a:

ttk::notebook::enableTraversal $nb

Esto extenderá las vinculaciones para la ventana de nivel superior que contiene el notebook de la siguiente manera:

  • Control-Tab selecciona la pestaña siguiente a la actualmente seleccionada.
  • Control-Shift-Tab selecciona la pestaña anterior a la actualmente seleccionada.
  • Alt-K, donde K es el carácter mnemónico (subrayado) de cualquier pestaña, seleccionará esa pestaña.

Se pueden habilitar varios notebooks en una única ventana de nivel superior para el traversal, incluidos los notebooks anidados. Sin embargo, el traversal del notebook solo funciona correctamente si todos los paneles son hijos directos del notebook.

EVENTOS VIRTUALES

El widget notebook genera un evento virtual <<NotebookTabChanged>> después de que se selecciona una nueva pestaña.

EJEMPLO

pack [ttk::notebook .nb]
.nb add [frame .nb.f1] -text "Primera pestaña"
.nb add [frame .nb.f2] -text "Segunda pestaña"
.nb select .nb.f2
ttk::notebook::enableTraversal .nb

OPCIONES DE ESTILO

El nombre de clase para un ttk::notebook es TNotebook. La pestaña tiene un nombre de clase de TNotebook.Tab

Estados dinámicos: active, disabled, selected.

Las opciones de estilo TNotebook configurables con ttk::style son:

-background color
-bordercolor color
-darkcolor color
-foreground color
-lightcolor color
-padding padding
-tabmargins padding
-tabposition position

Especifica la posición de la fila o columna de pestañas como una cadena de longitud 1 o 2. El primer carácter indica el lado como n, s, w o e, mientras que el segundo carácter (si está presente) es el bit de sujeción (especificado como w, e, n o s) dentro de la posición de la pestaña. La posición predeterminada es n para el tema aqua y nw para todos los demás temas integrados.

Las opciones de estilo TNotebook.Tab configurables con ttk::style son:

-background color
-bordercolor color
-compound compound
-expand padding

Define cuánto crece la pestaña en tamaño. Normalmente se usa con el estado dinámico selected. -tabmargins debe configurarse adecuadamente para que haya espacio para el crecimiento de la pestaña. Por ejemplo, el archivo de la biblioteca Ttk vistaTheme.tcl contiene las líneas 
ttk::style configure TNotebook -tabmargins {2 2 2 0}
ttk::style map TNotebook.Tab -expand {selected {2 2 2 2}}
que son válidas para el valor predeterminado nw de la opción de estilo -tabposition. Para un estilo de notebook ttk::notebook nbStyle definido por 
set nbStyle SW.TNotebook
ttk::style configure $nbStyle -tabposition sw
tendrás que adaptar la configuración anterior de la siguiente manera: 
ttk::style configure $nbStyle -tabmargins {2 0 2 2}
ttk::style map $nbStyle.Tab -expand {selected {2 2 2 2}}
La forma más fácil de hacerlo es invocar el procedimiento de la biblioteca ttk::configureNotebookStyle con $nbStyle como argumento, después de configurar la opción -tabposition del estilo.
-font font
-foreground color
-padding padding
Algunos temas usan un padding diferente para la pestaña seleccionada. Por ejemplo, el archivo de la biblioteca Ttk clamTheme.tcl contiene las líneas 
ttk::style configure TNotebook.Tab -padding {6 2 6 2}
ttk::style map TNotebook.Tab -padding {selected {6 4 6 2}}
que son válidas para el valor predeterminado nw de la opción de estilo -tabposition. Para un estilo de notebook ttk::notebook con una posición de pestaña diferente, tendrás que adaptar la configuración anterior en consecuencia. Nuevamente, la forma más fácil de hacerlo es invocar el procedimiento de la biblioteca ttk::configureNotebookStyle con el nombre del estilo como argumento, después de configurar la opción -tabposition del estilo.

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.
