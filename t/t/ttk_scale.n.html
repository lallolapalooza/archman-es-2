ttk::scale(n) Tk Themed Widget ttk::scale(n)

NOMBRE

ttk::scale - Crear y manipular un widget de escala

SINOPSIS

ttk::scale rutaNombre ?opciones...?

DESCRIPCIÓN

Un widget ttk::scale se utiliza típicamente para controlar el valor numérico de una variable vinculada que varía uniformemente en un rango determinado. Una escala muestra un deslizador que puede moverse a lo largo de una guía, con la posición relativa del deslizador sobre la guía indicando el valor de la variable.

OPCIONES ESTÁNDAR

-class	-cursor	-style
-takefocus

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Especifica el prefijo de un comando Tcl que se invocará cada vez que el valor de la escala cambie a través de un comando de widget. El comando real consta de esta opción seguida de un espacio y un número real que indica el nuevo valor de la escala.
Nombre de línea de comandos:	-from
Nombre de base de datos:	from
Clase de base de datos:	From
Un valor real correspondiente al extremo izquierdo o superior de la escala.
Nombre de línea de comandos:	-length
Nombre de base de datos:	length
Clase de base de datos:	Length
Especifica la dimensión larga deseada de la escala en unidades de pantalla (es decir, cualquiera de las formas aceptables para Tk_GetPixels). Para escalas verticales es la altura de la escala; para escalas horizontales es el ancho de la escala.
Nombre de línea de comandos:	-orient
Nombre de base de datos:	orient
Clase de base de datos:	Orient
Especifica si el widget debe distribuirse horizontal o verticalmente. Debe ser horizontal o vertical o una abreviatura de uno de estos.
Nombre de línea de comandos:	-to
Nombre de base de datos:	to
Clase de base de datos:	To
Especifica un valor real correspondiente al extremo derecho o inferior de la escala. Este valor puede ser menor o mayor que la opción -from.
Nombre de línea de comandos:	-value
Nombre de base de datos:	value
Clase de base de datos:	Value
Especifica el valor flotante actual de la variable. Si -variable se establece en una variable existente, especificar -value no tiene efecto (el valor de la variable tiene prioridad).
Nombre de línea de comandos:	-variable
Nombre de base de datos:	variable
Clase de base de datos:	Variable
Especifica el nombre de una variable global a vincular con la escala. Cada vez que cambie el valor de la variable, la escala se actualizará para reflejar este valor. Cada vez que se manipule la escala interactivamente, la variable se modificará para reflejar el nuevo valor de la escala.

COMANDO DEL WIDGET

rutaNombre cget opción
Devuelve el valor actual de la opción especificada; consulte ttk::widget(n).
rutaNombre configure ?opción? ?valor opción valor ...?
Modifica o consulta las opciones del widget; consulte ttk::widget(n).
rutaNombre get ?x y?
Obtiene el valor actual de la opción -value, o el valor correspondiente a las coordenadas x,y si se especifican. X e Y son coordenadas de píxeles relativas al origen del widget de escala.
rutaNombre identify x y
Devuelve el nombre del elemento en la posición x, y. Consulte ttk::widget(n).
rutaNombre instate estadospec ?script?
Prueba el estado del widget; consulte ttk::widget(n).
rutaNombre set valor
Establece el valor del widget (es decir, la opción -value) a valor. El valor se recortará al rango dado por las opciones -from y -to. Tenga en cuenta que el establecimiento de la variable vinculada (es decir, la variable denominada en la opción -variable) no provoca dicho recorte.
rutaNombre state ?stateSpec?
Modifica o consulta el estado del widget; consulte ttk::widget(n).

COMANDOS INTERNOS

rutaNombre coords ?valor?
Obtiene las coordenadas correspondientes a valor, o las coordenadas correspondientes al valor actual de la opción -value si se omite valor.

OPCIONES DE ESTILADO

El nombre de clase para un ttk::scale es TScale.

Estados dinámicos: active.

Las opciones de estilado de TScale configurables con ttk::style son:

-background color
-borderwidth cantidad
-darkcolor color
-groovewidth cantidad
-lightcolor color
-sliderwidth cantidad
-troughcolor color
-troughrelief relieve

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.
