ttk::style(n) Widget temático de Tk ttk::style(n)

NOMBRE

ttk::style - Manipular la base de datos de estilos

SINOPSIS

ttk::style opción ?argumentos?

NOTAS

Ver también la presentación de la conferencia Tcl'2004, disponible en https://tktable.sourceforge.net/tile/tile-tcl2004.pdf

DEFINICIONES

A cada widget se le asigna un estilo, que especifica el conjunto de elementos que componen el widget y cómo se organizan, junto con ajustes dinámicos y predeterminados para las opciones de los elementos. Por defecto, el nombre del estilo es el mismo que la clase del widget; esto puede ser anulado por la opción -style.

Un tema es una colección de elementos y estilos que controla el aspecto general de una aplicación.

DESCRIPCION

El comando ttk::style toma los siguientes argumentos:

ttk::style configure estilo ?-opción ?valor opción valor...? ?
Establece el valor predeterminado de la(s) opción(es) especificada(s) en estilo.
ttk::style element argumentos
ttk::style element create nombreElemento tipo ?argumentos...?
Crea un nuevo elemento en el tema actual de tipo tipo. El único tipo de elemento integrado multiplataforma es image (ver ttk_image(n)), pero los temas pueden definir otros tipos de elementos (ver Ttk_RegisterElementFactory). En versiones adecuadas de Windows, se registra una fábrica de elementos para crear elementos del tema de Windows (ver ttk_vsapi(n)).
ttk::style element names
Devuelve la lista de elementos definidos en el tema actual.
ttk::style element options elemento
Devuelve la lista de opciones del elemento.
ttk::style layout estilo ?especificaciónLayout?
Define el diseño del widget para el estilo estilo. Ver DISEÑOS a continuación para el formato de especificaciónLayout. Si se omite especificaciónLayout, devuelve la especificación de diseño para el estilo estilo.
ttk::style lookup estilo -opción ?estado ?valorPredeterminado??
Devuelve el valor especificado para -opción en el estilo estilo en el estado estado, utilizando las reglas de búsqueda estándar para las opciones de los elementos. estado es una lista de nombres de estado; si se omite, por defecto tiene todos los bits desactivados (el estado "normal"). Si el argumento valorPredeterminado está presente, se utiliza como valor de respaldo en caso de que no se encuentre ninguna especificación para -opción.
ttk::style map estilo ?-opción { especificaciónEstado valor... }?
Establece valores dinámicos de la(s) opción(es) especificada(s) en estilo. Cada par especificaciónEstado / valor se examina en orden; se utiliza el valor correspondiente a la primera especificaciónEstado coincidente.
ttk::style theme argumentos
ttk::style theme create nombreTema ?-parent basadoEn? ?-settings script... ?
Crea un nuevo tema. Es un error si nombreTema ya existe. Si se especifica -parent, el nuevo tema heredará estilos, elementos y diseños del tema padre basadoEn. Si está presente -settings, se evalúa script en el contexto del nuevo tema, según ttk::style theme settings.
ttk::style theme names
Devuelve una lista de todos los temas conocidos.
ttk::style theme settings nombreTema script
Establece temporalmente el tema actual a nombreTema, evalúa script y luego restaura el tema anterior. Típicamente, script simplemente define estilos y elementos, aunque puede aparecer código Tcl arbitrario.
ttk::style theme use ?nombreTema?
Sin argumentos, el resultado es el nombre del tema actual. De lo contrario, este comando establece el tema actual a nombreTema y actualiza todos los widgets.

DISEÑOS

Un diseño especifica una lista de elementos, cada uno seguido por una o más opciones que especifican cómo organizar el elemento. El mecanismo de diseño utiliza una versión simplificada del gestor de geometría pack: dada una cavidad inicial, se asigna un espacio a cada elemento. Luego, el espacio utilizado por el elemento se ajusta dentro del espacio asignado. Las opciones válidas son:

-children { subdiseño... }
Especifica una lista de elementos para colocar dentro del elemento.
-expand booleano
Especifica si el espacio asignado es toda la cavidad. Si es así, la especificación simultánea de -side se ignora. Por defecto es 0.
-side lado
Especifica qué lado de la cavidad colocar el elemento; uno de left, right, top o bottom. Por ejemplo, -side top asigna el espacio a lo largo de la parte superior de la cavidad, con un ancho y alto respectivamente del ancho de la cavidad y la altura del elemento. Si se omite, el espacio asignado es toda la cavidad (mismo efecto que -expand 1).
-sticky [nswe]
Especifica la posición y el tamaño real del espacio dentro del espacio asignado. Si se especifica como una cadena vacía, el espacio real se centra en el espacio asignado. Por defecto es nswe.

Por ejemplo:

ttk::style layout Horizontal.TScrollbar {
    Scrollbar.trough -children {
        Scrollbar.leftarrow -side left
        Scrollbar.rightarrow -side right
        Horizontal.Scrollbar.thumb -side left -sticky ew
    }
}
