TTY(1P) Manual del programador de POSIX TTY(1P)

PROLOG

Esta página del manual forma parte del Manual del programador de POSIX. La implementación de Linux de esta interfaz puede diferir (consulte la página del manual de Linux correspondiente para obtener detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

tty — devuelve el nombre de la terminal del usuario

SINOPSIS

tty

DESCRIPCIÓN

La utilidad tty escribirá en la salida estándar el nombre de la terminal que está abierta como entrada estándar. El nombre que se utilice será equivalente a la cadena que devolvería la función ttyname() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017.

OPCIONES

La utilidad tty cumplirá con el volumen de Definiciones Base de POSIX.1‐2017, Sección 12.2, Directrices de sintaxis de utilidades.

OPERANDOS

Ninguno.

ENTRADA ESTÁNDAR

Aunque no se lee ninguna entrada de la entrada estándar, se examinará la entrada estándar para determinar si es una terminal y, en caso afirmativo, para determinar el nombre de la terminal.

ARCHIVOS DE ENTRADA

Ninguno.

VARIABLES DE ENTORNO

Las siguientes variables de entorno afectarán la ejecución de tty:

LANG
Proporciona un valor predeterminado para las variables de internacionalización que no están establecidas o están vacías. (Consulte el volumen de Definiciones Base de POSIX.1‐2017, Sección 8.2, Variables de internacionalización para conocer la precedencia de las variables de internacionalización utilizadas para determinar los valores de las categorías de localización).
LC_ALL
Si se establece en una cadena de valor no vacía, anula los valores de todas las demás variables de internacionalización.
LC_CTYPE
Determina la localización para la interpretación de secuencias de bytes de datos de texto como caracteres (por ejemplo, caracteres de un solo byte frente a caracteres multibyte en argumentos).
LC_MESSAGES

Determina la localización que debe utilizarse para afectar el formato y el contenido de los mensajes de diagnóstico escritos en la salida de error estándar y los mensajes informativos escritos en la salida estándar.
NLSPATH
Determina la ubicación de los catálogos de mensajes para el procesamiento de LC_MESSAGES.

EVENTOS ASÍNCRONOS

Predeterminado.

SALIDA ESTÁNDAR

Si la entrada estándar es un dispositivo de terminal, se escribirá en la salida estándar una ruta del terminal, según lo especificado por la función ttyname() definida en el volumen de Interfaces del Sistema de POSIX.1‐2017, en el siguiente formato:

"%s\n", <nombre del terminal>

De lo contrario, se escribirá un mensaje indicando que la entrada estándar no está conectada a una terminal. En la localización POSIX, la utilidad tty utilizará el formato:

"not a tty\n"

SALIDA DE ERROR ESTÁNDAR

La salida de error estándar se utilizará solo para mensajes de diagnóstico.

ARCHIVOS DE SALIDA

Ninguno.

DESCRIPCIÓN EXTENDIDA

Ninguna.

ESTADO DE SALIDA

Se devolverán los siguientes valores de salida:

 0
La entrada estándar es una terminal.
 1
La entrada estándar no es una terminal.
>1
Ocurrió un error.

CONSECUENCIAS DE LOS ERRORES

Predeterminado.

USO DE LA APLICACIÓN

Esta utilidad comprueba el estado del archivo abierto como entrada estándar frente a un conjunto de archivos definido por la implementación. Es posible que no se encuentre ninguna coincidencia, o que la coincidencia encontrada no sea el mismo archivo que se abrió para la entrada estándar (aunque sean el mismo dispositivo).
