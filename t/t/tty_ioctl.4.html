ioctl_tty(2) Manual de llamadas al sistema ioctl_tty(2)

NOMBRE

ioctl_tty - ioctls para terminales y líneas serie

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <asm/termbits.h>  /* Definición de constantes */
#include <sys/ioctl.h>
int ioctl(int fd, int op, ...);

DESCRIPCIÓN

La llamada ioctl(2) para terminales y puertos serie acepta muchos argumentos de operación posibles. La mayoría requieren un tercer argumento, de tipo variable, aquí llamado argp o arg.

El uso de ioctl() hace que los programas no sean portables. Utilice la interfaz POSIX descrita en termios(3) siempre que sea posible.

VALOR DE RETORNO

En caso de éxito, se devuelve 0. En caso de error, se devuelve -1 y se establece errno para indicar el error.
