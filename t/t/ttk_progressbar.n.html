ttk_progressbar(n)

Paquete: tk

Licencias: TCL

ttk::progressbar(n) Tk Themed Widget ttk::progressbar(n)

NOMBRE

ttk::progressbar - Proporcionar retroalimentación de progreso

SINOPSIS

ttk::progressbar rutaNombre ?opciones?

DESCRIPCIÓN

Un widget ttk::progressbar muestra el estado de una operación larga. Pueden operar en dos modos: el modo determinado muestra la cantidad completada en relación con la cantidad total de trabajo a realizar, y el modo indeterminado proporciona una visualización animada para informar al usuario que algo está sucediendo.

OPCIONES ESTÁNDAR

-class	-cursor	-takefocus
-style

Consulte la entrada del manual de ttk::widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-length
Nombre de base de datos:	length
Clase de base de datos:	Length
Especifica la longitud del eje largo de la barra de progreso (ancho si es horizontal, alto si es vertical).
Nombre de línea de comandos:	-maximum
Nombre de base de datos:	maximum
Clase de base de datos:	Maximum
Un número de punto flotante que especifica el -value máximo. Predeterminado a 100.
Nombre de línea de comandos:	-mode
Nombre de base de datos:	mode
Clase de base de datos:	Mode
Uno de determinate o indeterminate.
Nombre de línea de comandos:	-orient
Nombre de base de datos:	orient
Clase de base de datos:	Orient
Uno de horizontal o vertical. Especifica la orientación de la barra de progreso.
Nombre de línea de comandos:	-phase
Nombre de base de datos:	phase
Clase de base de datos:	Phase
Opción de solo lectura. El widget incrementa periódicamente el valor de esta opción siempre que el -value sea mayor que 0 y, en modo determinado, menor que -maximum. Esta opción puede ser utilizada por el tema actual para proporcionar efectos de animación adicionales.
Nombre de línea de comandos:	-value
Nombre de base de datos:	value
Clase de base de datos:	Value
El valor actual de la barra de progreso. En modo determinado, esto representa la cantidad de trabajo completado. En modo indeterminado, se interpreta módulo -maximum; es decir, la barra de progreso completa un “ciclo” cuando el -value aumenta en -maximum. Si -variable está configurado a una variable existente, especificar -value no tiene efecto (el valor de la variable tiene precedencia).
Nombre de línea de comandos:	-variable
Nombre de base de datos:	variable
Clase de base de datos:	Variable
El nombre de una variable global de Tcl que está vinculada al -value. Si se especifica a una variable existente, el -value de la barra de progreso se establece automáticamente al valor de la variable cada vez que esta última se modifica.

COMANDO DEL WIDGET

rutaNombre cget opción
Devuelve el valor actual de la opción especificada; vea ttk::widget(n).
rutaNombre configure ?opción? ?valor opción valor ...?
Modifica o consulta las opciones del widget; vea ttk::widget(n).
rutaNombre identify x y
Devuelve el nombre del elemento en la posición x, y. Vea ttk::widget(n).
rutaNombre instate estadospec ?script?
Prueba el estado del widget; vea ttk::widget(n).
rutaNombre start ?intervalo?
Inicia el modo de autoincremento: programa un evento de temporizador recurrente que llama a step cada intervalo milisegundos. Si se omite, intervalo tiene un valor predeterminado de 50 milisegundos (20 pasos/segundo).
rutaNombre state ?estadoSpec?
Modifica o consulta el estado del widget; vea ttk::widget(n).
rutaNombre step ?cantidad?
Incrementa el -value en cantidad. cantidad tiene un valor predeterminado de 1.0 si se omite.
rutaNombre stop
Detiene el modo de autoincremento: cancela cualquier evento de temporizador recurrente iniciado por rutaNombre start.

OPCIONES DE ESTILADO

El nombre de clase para un ttk::progressbar es TProgressbar.

Las opciones de estilado de TProgressbar configurables con ttk::style son:

-background color
-bordercolor color
-darkcolor color
-lightcolor color
-maxphase

Para el tema aqua.
-period
Para el tema aqua.
-troughcolor color

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos de ttk.
