ttk_radiobutton(n)

Paquete: tk

Licencias: TCL

ttk::radiobutton(n) Tk Themed Widget ttk::radiobutton(n)

NOMBRE

ttk::radiobutton - Widget de opción mutuamente excluyente

SINOPSIS

ttk::radiobutton rutaNombre ?opciones?

DESCRIPCIÓN

Los widgets ttk::radiobutton se utilizan en grupos para mostrar o cambiar un conjunto de opciones mutuamente excluyentes. Los botones de radio están vinculados a una variable Tcl y tienen un valor asociado; cuando se hace clic en un botón de radio, este establece la variable a su valor asociado.

OPCIONES ESTÁNDAR

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Un script Tcl para evaluar cada vez que se invoca el widget.
Nombre de línea de comandos:	-value
Nombre de base de datos:	Value
Clase de base de datos:	Value
El valor a almacenar en la -variable asociada cuando se selecciona el widget.
Nombre de línea de comandos:	-variable
Nombre de base de datos:	variable
Clase de base de datos:	Variable
El nombre de una variable global cuyo valor está vinculado al widget. El valor predeterminado es ::selectedButton.

COMANDO DEL WIDGET

Además de los comandos estándar cget, configure, identify, instate y state, los botones de radio admiten los siguientes comandos de widget adicionales:

rutaNombre invoke
Establece la -variable al -value, selecciona el widget y evalúa el -command asociado. Devuelve el resultado del -command, o una cadena vacía si no se especifica ningún -command.

ESTADOS DEL WIDGET

El widget no responde a la entrada del usuario si se establece el estado disabled. El widget establece el estado selected cada vez que la -variable enlazada se establece al -value del widget, y lo borra en caso contrario. El widget establece el estado alternate cada vez que la -variable enlazada se desestablece. (El estado alternate puede usarse para indicar una selección de "tres estados" o "indeterminada").

ESTILOS ESTÁNDAR

Los widgets Ttk::radiobutton admiten el estilo Toolbutton en todos los temas estándar, lo cual es útil para crear widgets para barras de herramientas.

OPCIONES DE ESTILADO

El nombre de clase para un ttk::radiobutton es TRadiobutton.

Estados dinámicos: active, alternate, disabled, pressed, readonly, selected.

Las opciones de estilo de TRadiobutton configurables con ttk::style son:

-background color
-compound compound
-foreground color
-indicatorbackground color
-indicatorcolor color
-indicatormargin padding
-indicatorrelief relief
-padding padding

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos de ttk.

VER TAMBIÉN

ttk::widget(n), ttk::checkbutton(n), radiobutton(n)
