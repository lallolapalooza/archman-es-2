FBB::Tty(3bobcat) Controla el eco de caracteres FBB::Tty(3bobcat)

NOMBRE

FBB::Tty - Controla el eco de caracteres introducidos en la terminal

SINOPSIS

#include <bobcat/tty>
Opción de enlace: -lbobcat

DESCRIPCIÓN

Los objetos Tty(3bobcat) se pueden utilizar para controlar el eco de los caracteres introducidos en la terminal (normalmente en /dev/tty). Leer directamente desde /dev/tty permite a los programas leer información (por ejemplo, contraseñas o frases de contraseña) incluso si el flujo de entrada estándar está redirigido a un archivo. A menos que se redirija, std::cin está conectado a /dev/tty.

Los objetos Tty(3bobcat) pueden usarse como objetos independientes o los objetos Tty(3bobcat) (normalmente anónimos) pueden insertarse o extraerse de flujos. Al insertar o extraer objetos, los flujos involucrados no se ven afectados; solo se manipula el eco de los caracteres introducidos en /dev/tty.

El destructor de Tty(3bobcat) no restablece el estado de eco de /dev/tty a su valor original. Si eso es necesario, se debe crear primero un objeto Tty(3bobcat), llamando a su miembro echo(Tty::RESET) en el momento apropiado.

ESPACIO DE NOMBRES

FBB

HEREDA DE

ENUMERACIÓN

El enum EchoType solicita el tipo de manejo del eco:

o
RESET se utiliza para restablecer el estado de /dev/tty al estado actual cuando se construyó un objeto Tty(3bobcat)
o
ON se utiliza para activar el eco de los caracteres introducidos en /dev/tty.
o
OFF se utiliza para suprimir el eco de los caracteres introducidos en /dev/tty.

CONSTRUCTORES

o
Tty():
Se guarda el estado actual de /dev/tty.
o
Tty(EchoType type):
Se guarda el estado actual de /dev/tty y se llama al miembro echo(type) del objeto.

Los constructores y operadores de asignación de copia y movimiento están disponibles.

OPERADORES SOBRECARGADOS

o
std::istream &operator>>(std::istream &in, Tty const &tty):
El operador de extracción no afecta a in, pero el estado de /dev/tty se establece de acuerdo con la forma en que se construyó el objeto tty.
o
std::ostream &operator<<(std::ostream &out, Tty const &tty):
El operador de inserción no afecta a out, pero el estado de /dev/tty se establece de acuerdo con la forma en que se construyó el objeto tty.

FUNCIÓN MIEMBRO

o
echo(EchoType type):
El estado de /Dev/tty se establece de acuerdo con el valor EchoType que se pasa a este miembro.

EJEMPLO

#include <iostream>
#include <string>
#include <bobcat/tty>
using namespace std;
using namespace FBB;
int main()
{
    cout << "Introduce algo de texto (sin eco): " << Tty(Tty::OFF);
    string line;
    getline(cin, line);
    cout << "\n"
            "Introdujiste: `" << line << "’\n";
    cout << "Introduce algo de texto (con eco): ";
    getline(cin >> Tty(Tty::ON), line);
    cout << "Introdujiste: `" << line << "’\n";
}

TTY(3bobcat)

tty - información sobre el controlador de terminal

NOMBRE

tty - información sobre el controlador de terminal

SINOPSIS

#include <stdio.h>
int tty_init(void);
int tty_read(char *buf, int nbytes);
int tty_write(const char *buf, int nbytes);
int tty_close(void);

DESCRIPCIÓN

La función tty proporciona una interfaz para interactuar con el controlador de terminal en sistemas tipo Unix.

tty_init()

Inicializa el controlador de terminal.

tty_read()

Lee hasta nbytes de datos del terminal en el búfer buf. Devuelve el número de bytes leídos o un valor negativo en caso de error.

tty_write()

Escribe nbytes de datos desde el búfer buf al terminal. Devuelve el número de bytes escritos o un valor negativo en caso de error.

tty_close()

Cierra la conexión con el controlador de terminal.

VALOR DE RETORNO

Las funciones tty_init, tty_read, tty_write y tty_close devuelven 0 si tienen éxito y un valor negativo en caso de error.
