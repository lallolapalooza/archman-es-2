ttk::spinbox(n) Tk Themed Widget ttk::spinbox(n)

NOMBRE

ttk::spinbox - Widget de campo de texto para selección

SINOPSIS

ttk::spinbox nombreRuta ?opciones?

DESCRIPCIÓN

Un widget ttk::spinbox es un widget ttk::entry con botones de subir y bajar integrados que se utilizan para modificar un valor numérico o para seleccionar entre un conjunto de valores. El widget implementa todas las características del widget ttk::entry, incluido el soporte de la opción -textvariable para vincular el valor mostrado por el widget a una variable Tcl.

-style	-takefocus	-xscrollcommand

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre en línea de comandos:	-command
Nombre en base de datos:	command
Clase de base de datos:	Command
Especifica un comando Tcl que se invocará cada vez que se accione un botón giratorio.
Nombre en línea de comandos:	-format
Nombre en base de datos:	format
Clase de base de datos:	Format
Especifica un formato alternativo a utilizar al establecer el valor de cadena cuando se utiliza el rango -from y -to. Debe ser un especificador de formato de la forma %<relleno>.<relleno>f, ya que formateará un número de punto flotante.
Nombre en línea de comandos:	-from
Nombre en base de datos:	from
Clase de base de datos:	From
Un valor de punto flotante que especifica el valor más bajo para el spinbox. Se utiliza junto con -to y -increment para establecer un rango numérico.
Nombre en línea de comandos:	-increment
Nombre en base de datos:	increment
Clase de base de datos:	Increment
Un valor de punto flotante que especifica el cambio de valor que se aplicará cada vez que se presione uno de los botones giratorios del widget. El botón de subir aplica un incremento positivo, el botón de bajar aplica un incremento negativo.
Nombre en línea de comandos:	-to
Nombre en base de datos:	to
Clase de base de datos:	To
Un valor de punto flotante que especifica el valor más alto permitido para el widget. Ver también -from y -increment. rango.
Nombre en línea de comandos:	-values
Nombre en base de datos:	values
Clase de base de datos:	Values
Debe ser una lista Tcl de valores. Si se establece esta opción, anulará cualquier rango establecido utilizando las opciones -from, -to y -increment. El widget utilizará en su lugar los valores especificados comenzando por el primer valor.
Nombre en línea de comandos:	-wrap
Nombre en base de datos:	wrap
Clase de base de datos:	Wrap
Debe ser un valor booleano válido. Si está activado, el spinbox ciclará por los valores de los datos en el widget.

COMANDO DEL WIDGET

Los siguientes subcomandos son posibles para los widgets spinbox además de los comandos descritos para el widget ttk::entry:

nombreRuta get
Devuelve el valor actual del spinbox.
nombreRuta set valor
Establece la cadena del spinbox a valor. Si se ha configurado una opción -format, se aplicará este formato. Si el formato falla o no está establecido, o si se ha utilizado la opción -values, el valor se establecerá directamente.

EVENTOS VIRTUALES

El widget spinbox genera un evento virtual <<Increment>> cuando el usuario presiona <Arriba>, y un evento virtual <<Decrement>> cuando el usuario presiona <Abajo>.

OPCIONES DE ESTILISMO

El nombre de clase para un ttk::spinbox es TSpinbox.

Estados dinámicos: active, disabled, focus, readonly.

Las opciones de estilismo de TSpinbox configurables con ttk::style son:

-arrowcolor color
-arrowsize cantidad
-background color

Para compatibilidad con versiones anteriores, cuando se utiliza el tema aqua (para macOS), esta opción se comporta como un alias de -fieldbackground siempre que no se especifique ningún valor para -fieldbackground. De lo contrario, se ignora.
-bordercolor color
-darkcolor color
-fieldbackground color
-foreground color
-insertcolor color
-insertwidth cantidad
-lightcolor color
-padding relleno
-selectbackground color
-selectforeground color

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos de ttk.
