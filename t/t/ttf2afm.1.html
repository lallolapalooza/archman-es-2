TTF2AFM(1) Manual de Comandos Generales TTF2AFM(1)

NOMBRE

ttf2afm - utilidad para generar archivos AFM para fuentes TrueType

SINOPSIS

ttf2afm [OPCIONES] ARCHIVO_FUENTE

DESCRIPCIÓN

ttf2afm se utiliza para generar archivos Adobe Font Metrics (AFM) para fuentes TrueType (TTF) para permitir su uso con TeX.

ttf2afm toma el nombre de un archivo de fuente TrueType como argumento obligatorio. También puede tomar una o más opciones de la lista siguiente (-i y -u son mutuamente excluyentes).

OPCIONES

-i
forzar la impresión de nombres de glifos en forma `index'númdec
-u
forzar la impresión de nombres de glifos en forma `uni'númhex
-c nombre
escribir tablas de codificación en el archivo nombre.eMN, donde M es el ID de plataforma y N es el ID de codificación
-v
imprimir la versión del programa
-e codificación
codificar la salida AFM usando el vector de codificación de codificación
-o archivo_salida
enviar la salida al archivo archivo_salida en lugar de a la salida estándar
-m num
usar el mapeo Unicode num en la fuente

Los números de plataforma pueden ser uno de:

0
Apple Unicode
1
Macintosh
2
ISO
3
Microsoft

Las codificaciones pueden ser:

0
Roman (si la plataforma es Macintosh)
0
Symbol (si la plataforma es Microsoft)
1
Unicode (si la plataforma es Microsoft)

VER TAMBIÉN

afm2tfm(1), afm2pl(1). FontForge (https://fontforge.org). LCDF TypeTools (https://lcdf.org). A closer look at TrueType fonts and pdfTeX, Han The Thanh (https://tug.org/TUGboat/tb30-1/tb94thanh.pdf).
