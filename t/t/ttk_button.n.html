ttk::button(n) Widget temático de Tk ttk::button(n)

NOMBRE

ttk::button - Widget que emite un comando al ser presionado

SINOPSIS

ttk::button nombreDeRuta ?opciones?

DESCRIPCIÓN

Un ttk::button muestra una etiqueta de texto y/o una imagen, y evalúa un comando cuando se presiona.

OPCIONES ESTÁNDAR

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Consulte la entrada del manual ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Un script para evaluar cuando se invoca el widget.
Nombre de línea de comandos:	-default
Nombre de base de datos:	default
Clase de base de datos:	Default
Puede establecerse en uno de normal, active o disabled. En un cuadro de diálogo, se puede designar un botón como el botón “predeterminado” (lo que significa, aproximadamente, “el que se invoca cuando el usuario presiona <Enter>”). active indica que este es actualmente el botón predeterminado; normal significa que puede convertirse en el botón predeterminado y disabled significa que no es predeterminable. El valor predeterminado es normal.

Dependiendo del tema, el botón predeterminado puede mostrarse con un anillo de resaltado adicional o con un color de borde diferente.

COMANDO DEL WIDGET

Además de los comandos estándar cget, configure, identify, instate y state, los botones admiten los siguientes comandos de widget adicionales:

nombreDeRuta invoke
Invoca el comando asociado con el botón.

ESTILOS ESTÁNDAR

Los widgets ttk::button admiten el estilo Toolbutton en todos los temas estándar, lo cual es útil para crear widgets para barras de herramientas.

OPCIONES DE ESTILO

El nombre de clase para un ttk::button es TButton.

Estados dinámicos: active, disabled, pressed, readonly.

Las opciones de estilo de TButton configurables con ttk::style son:

-anchor ancla
-background color
-bordercolor color
-compound compuesto
-darkcolor color
-foreground color
-font fuente
-highlightcolor color
-highlightthickness cantidad
-lightcolor color
-padding relleno
-relief relieve
-shiftrelief cantidad

-shiftrelief especifica cuánto se desplaza el contenido del botón hacia abajo y hacia la derecha en el estado pressed. Esta acción proporciona retroalimentación esquemórfica adicional.
-width cantidad

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual ttk::style para obtener información sobre cómo configurar los estilos ttk.

VER TAMBIÉN
