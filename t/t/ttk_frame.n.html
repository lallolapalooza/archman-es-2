ttk::frame(n) Widget Tematizado de Tk ttk::frame(n)

NOMBRE

ttk::frame - Contenedor simple de widgets

SINOPSIS

ttk::frame rutaNombre ?opciones?

DESCRIPCIÓN

Un widget ttk::frame es un contenedor, utilizado para agrupar otros widgets.

OPCIONES ESTÁNDAR

-class	-cursor	-padding
-style	-takefocus

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-borderwidth
Nombre de base de datos:	borderWidth
Clase de base de datos:	BorderWidth
El ancho deseado del borde del widget. Por defecto es 0. Puede ser ignorado dependiendo del tema utilizado.
Nombre de línea de comandos:	-relief
Nombre de base de datos:	relief
Clase de base de datos:	Relief
Uno de los estilos de borde estándar de Tk: flat, groove, raised, ridge, solid, o sunken. Por defecto es flat.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Si se especifica, el ancho solicitado del widget en píxeles.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Si se especifica, la altura solicitada del widget en píxeles.

COMANDO DEL WIDGET

Admite los comandos estándar del widget configure, cget, identify, instate y state; consulte ttk::widget(n).

NOTAS

Tenga en cuenta que si se utilizan los gestores de geometría pack, grid u otros para gestionar los hijos del frame, el tamaño solicitado por el GM normalmente tendrá prioridad sobre las opciones -width y -height del widget frame. pack propagate y grid propagate se pueden utilizar para cambiar esto.

OPCIONES DE ESTILO

El nombre de clase para un ttk::frame es TFrame.

Las opciones de estilo de TFrame configurables con ttk::style son:

-background color
-relief relief

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.

ASOCIACIONES

Cuando se crea un nuevo ttk::frame, no tiene asociaciones de eventos predeterminadas; los ttk::frame no están pensados para ser interactivos.

VER TAMBIÉN

ttk::widget(n), ttk::labelframe(n), frame(n)

PALABRAS CLAVE

widget, frame, contenedor
