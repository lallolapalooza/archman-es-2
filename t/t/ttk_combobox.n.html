ttk_combobox(n)

Paquete: tk

Licencias: TCL

ttk::combobox(n) Widget Temático de Tk ttk::combobox(n)

NOMBRE

ttk::combobox - campo de texto con lista desplegable de selección

SINOPSIS

ttk::combobox rutaNombre ?opciones?

DESCRIPCIÓN

Un ttk::combobox combina un campo de texto con una lista desplegable de valores; el usuario puede seleccionar el valor del campo de texto entre los valores de la lista.

OPCIONES ESTÁNDAR

-class	-cursor	-takefocus
-style

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-exportselection
Nombre de base de datos:	exportSelection
Clase de base de datos:	ExportSelection
Valor booleano. Si se establece, la selección del widget se vincula a la selección X.
Nombre de línea de comandos:	-justify
Nombre de base de datos:	justify
Clase de base de datos:	Justify
Especifica cómo se alinea el texto dentro del widget. Debe ser uno de left, center, o right.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Especifica la altura de la lista desplegable, en filas.
Nombre de línea de comandos:	-postcommand
Nombre de base de datos:	postCommand
Clase de base de datos:	PostCommand
Un script Tcl para evaluar inmediatamente antes de mostrar la lista. El script -postcommand puede especificar los -values a mostrar.
Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Uno de normal, readonly, o disabled. En el estado readonly, el valor no se puede editar directamente y el usuario solo puede seleccionar uno de los -values de la lista desplegable. En el estado normal, el campo de texto es directamente editable. En el estado disabled, no es posible ninguna interacción.
Nombre de línea de comandos:	-textvariable
Nombre de base de datos:	textVariable
Clase de base de datos:	TextVariable
Especifica el nombre de una variable global cuyo valor está vinculado al valor del widget y viceversa.
Nombre de línea de comandos:	-values
Nombre de base de datos:	values
Clase de base de datos:	Values
Especifica la lista de valores a mostrar en la lista desplegable.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica un valor entero que indica el ancho deseado de la ventana de entrada, en caracteres de tamaño promedio de la fuente del widget.

COMANDO DEL WIDGET

Los siguientes subcomandos son posibles para los widgets combobox:

rutaNombre current ?nuevoÍndice?
Si se proporciona nuevoÍndice, establece el valor del combobox al elemento en la posición nuevoÍndice en la lista de -values (además de los enteros, se admite el índice end que indica el último elemento de la lista). De lo contrario, devuelve el índice del valor actual en la lista de -values o -1 si el valor actual no aparece en la lista.
rutaNombre get
Devuelve el valor actual del combobox.
rutaNombre set valor
Establece el valor del combobox a valor.

El widget combobox también admite los siguientes subcomandos del widget ttk::entry (ver ttk::entry(n) para más detalles):

bbox	delete	icursor
index	insert	selection
xview

El widget combobox también admite los siguientes subcomandos genéricos del widget ttk::widget (ver ttk::widget(n) para más detalles):

cget	configure	identify
instate	state

EVENTOS VIRTUALES

El widget combobox genera un evento virtual <<ComboboxSelected>> cuando el usuario selecciona un elemento de la lista de valores. Si la acción de selección desactiva la lista, este evento se entrega después de que la lista se desactiva.

OPCIONES DE ESTILIZACIÓN

El nombre de la clase para un ttk::combobox es TCombobox. El ttk::combobox utiliza los widgets entry y listbox internamente. El marco de la lista tiene un nombre de clase de ComboboxPopdownFrame.

Estados dinámicos: disabled, focus, pressed, readonly.

Las opciones de estilo TCombobox configurables con ttk::style son:

-arrowcolor color
-arrowsize cantidad
-background color
-bordercolor color
-darkcolor color
-focusfill color
-foreground color
-fieldbackground color

Solo se puede cambiar cuando se usan temas no nativos y no gráficos.
-insertcolor color
-insertwidth cantidad
-lightcolor color
-padding relleno
-postoffset relleno
-selectbackground color
Fondo de selección de entrada de texto.
-selectforeground color
Primer plano de selección de entrada de texto.

La lista desplegable del ttk::combobox no se puede configurar usando ttk::style ni a través del comando configure del widget. La lista se puede configurar usando la base de datos de opciones.

option add *TCombobox*Listbox.background color
option add *TCombobox*Listbox.font fuente
option add *TCombobox*Listbox.foreground color
option add *TCombobox*Listbox.selectBackground color
option add *TCombobox*Listbox.selectForeground color

Para configurar una lista específica (sujeto a cambios futuros):

set popdown [ttk::combobox::PopdownWindow .mi_combobox]
$popdown.f.l configure -font fuente

Las opciones de estilo ComboboxPopdownFrame configurables con ttk::style son:

-borderwidth cantidad
-relief relief

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.
