ttytype(5) Manual de formatos de archivo ttytype(5)

NOMBRE

ttytype - mapeo de dispositivo tty a tipo de terminal predeterminado

DESCRIPCIÓN

El archivo /etc/ttytype asocia nombres de tipo de terminal de termcap(5) y terminfo(5) con líneas tty. Cada línea consiste en un tipo de terminal, seguido de espacios en blanco, seguido de un nombre de tty (un nombre de dispositivo sin el prefijo /dev/).

Esta asociación es utilizada por el programa tset(1) para establecer la variable de entorno TERM al nombre de terminal predeterminado para la tty actual del usuario.

Esta funcionalidad fue diseñada para un entorno de tiempo compartido tradicional que presenta terminales de celda de caracteres cableadas a un minicomputador UNIX. Se utiliza poco en los sistemas UNIX modernos de estaciones de trabajo y personales.

ARCHIVOS

/etc/ttytype
el archivo de definiciones tty.

EJEMPLOS

Un /etc/ttytype típico es:


con80x25 tty1
vt320 ttys0

VER TAMBIÉN

termcap(5), terminfo(5), agetty(8), mingetty(8)
