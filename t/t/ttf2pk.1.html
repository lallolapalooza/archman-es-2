TTF2PK(1) Manual de Comandos Generales TTF2PK(1)

NOMBRE

ttf2pk - convertir una fuente TrueType al formato PK de TeX

SINOPSIS

ttf2pk [-q] [-n] nombre-fuente resolución
ttf2pk -t [-q] nombre-fuente
ttf2pk --version | --help

DESCRIPCIÓN

Este programa convierte una fuente TrueType en un archivo PK; la fuente creada puede ser utilizada posteriormente con TeX o LaTeX.

También se soportan subfuentes CJKV (chino/japonés/coreano/vietnamita antiguo) creadas por ttf2tfm.

ttf2pk asume siempre 10pt como tamaño de diseño para la fuente TeX escrita.

PARÁMETROS

-q
Este interruptor opcional hace que ttf2pk sea silencioso. Suprime cualquier salida informativa excepto los mensajes de advertencia y error.
-n
Usar solo `.pk' como extensión en lugar de `.<resolución>pk'.
-t
Comprueba la existencia de nombre-fuente. Devuelve 0 si tiene éxito e imprime la línea correspondiente de un archivo de mapa (por defecto: ttfonts.map), siempre que no se establezca el interruptor -q.
nombre-fuente
El nombre TeX de la fuente. ttf2pk busca este nombre en un archivo de mapa (ver abajo) para obtener más información sobre cómo procesar la fuente.
resolución
La resolución, dada en puntos por pulgada. Actualmente, la resolución horizontal es igual a la resolución vertical. El tamaño de diseño se asume siempre como 10pt.
--version
Muestra la versión actual de ttf2pk y la biblioteca de búsqueda de archivos utilizada (por ejemplo, kpathsea).
--help
Muestra información de uso.

Las variables de entorno para la búsqueda de archivos se describen en la página del manual de ttf2tfm.

EL ARCHIVO DE CONFIGURACIÓN

ttf2pk utiliza un pequeño archivo de configuración llamado ttf2pk.cfg; en cada línea contiene una palabra clave con su valor, separados por espacios en blanco. Las líneas de comentarios pueden comenzar con cualquiera de los siguientes caracteres: `*', `#', `;', y `%'. Se ignoran los espacios en blanco iniciales.

Actualmente, solo una palabra clave, `map', es reconocida en este archivo; toma un nombre de archivo de mapa como parámetro. Si no se le da extensión al nombre del archivo de mapa, se le añade .map. No se permiten espacios en blanco en el nombre del archivo de mapa. La palabra clave `map' puede aparecer más de una vez para especificar varios archivos de mapa; si el nombre del archivo de mapa va precedido por un signo más, se añade a la lista de archivos de mapa a utilizar. Ejemplo:


map foo
map +bar

Esto hace que ttf2pk lea primero foo.map y luego bar.map.

Si no se encuentra el archivo de configuración, ttf2pk intenta usar ttfonts.map en su lugar.

ARCHIVOS DE MAPA

Los parámetros especificados a ttf2tfm se conservan para ttf2pk en los archivos de mapa; ttf2tfm escribe en la salida estándar, como última línea, una entrada adecuada para un archivo de mapa.

Por ejemplo, una llamada a


ttf2tfm arial -p T1.enc -s 0.25 -P 1 -E 0 arials

producirá la siguiente línea:


arials arial Slant=0.25 Pid=1 Eid=0 Encoding=T1.enc

Ver ttf2tfm(1) y afm2tfm(1) del paquete dvips para una descripción detallada de los archivos de codificación.

Aquí hay una tabla que enumera los diversos parámetros de ttf2tfm y las entradas correspondientes en un archivo de mapa:


-s Slant
-e Extend
-p Encoding
-f Fontindex
-P Pid
-E Eid
-n PS=Yes
-N PS=Only
-R Replacement
-x Rotate=Yes
-y Y-Offset

Los nombres de glifo de reemplazo únicos dados a ttf2tfm con `-r nombre-glifo-antiguo nombre-glifo-nuevo' se especifican directamente con `nombre-glifo-antiguo=nombre-glifo-nuevo'. Se ignorarán si se está en modo subfuente o si no se proporciona un archivo de codificación.

Un parámetro adicional en un archivo de mapa es único para ttf2pk: `Hinting', que puede tomar los valores `On' u `Off'. Algunas fuentes (por ejemplo, la parte CJK de cyberbit.ttf) se renderizan incorrectamente si se activa el hinting. El valor predeterminado es `On' (también puede usar `Yes', `No', `1' y `0').

Para una descripción de las subfuentes (es decir, entradas de la forma `<nombre-base>@<nombre-archivo-sfd>@') consulte ttf2tfm(1).

El formato de un archivo de mapa es simple. Cada línea define una fuente; primero viene el nombre de la fuente TeX, luego el nombre de su archivo de fuente TrueType, seguido de los parámetros en cualquier orden. La capitalización es significativa (incluso para los nombres de los parámetros); los parámetros se separan de sus valores por un signo igual, con espacios en blanco posiblemente rodeándolo. ttf2pk lee todos los archivos de mapa línea por línea en el orden dado en el archivo de configuración, continuando hasta que se encuentra la fuente TeX especificada en la línea de comandos, de lo contrario, el programa sale con el código de error 2. Por lo tanto, puede usar cualquier carácter no válido en un nombre de fuente TeX para comenzar una línea de comentario.

Puede usar `\' como el carácter final de una línea para indicar que la entrada continúa en la siguiente línea. Se eliminarán la barra invertida y el carácter de nueva línea siguiente.

ttf2pk abortará si no puede encontrar o leer el archivo de métricas de fuentes TeX del nombre de fuente TeX dado.

VALOR DE RETORNO

Si la llamada fue exitosa, se devolverá 0. En caso de error, el valor de retorno es 1. Finalmente, si la fuente no se puede encontrar en los archivos de mapa, se devolverá 2. Esto simplifica la inclusión de ttf2pk en scripts como mktexpk para la generación automática de fuentes.

VER TAMBIÉN

ttf2tfm(1), afm2tfm(1)

DISPONIBILIDAD

ttf2pk es parte del paquete FreeType 1, una biblioteca de renderizado TrueType de alta calidad.

ttf2pk(1)

NAME

ttf2pk - TTF to PK font converter

SYNOPSIS

ttf2pk [<options>] <ttf-file> [<pk-file>]

DESCRIPTION

ttf2pk converts TrueType fonts to PK (packed) format for use with TeX.

OPTIONS

This program follows the usual GNU command line syntax, with long options starting with two dashes (--) and short options starting with a single dash (-). A summary of options is included below.

-h, --help
Show summary of options.
-v, --version
Show version information.
-f, --force
Overwrite output file if it exists.
-p, --pixelsize=<size>
Set the pixel size (default: 10).
-x, --xresolution=<res>
Set the X resolution (default: 72).
-y, --yresolution=<res>
Set the Y resolution (default: 72).
-l, --ligatures=<on|off>
Enable/disable ligatures (default: on).
-s, --substitute=<name>
Substitute font with the given name.

EXAMPLES

Convert myfont.ttf to myfont.pk with default settings:

ttf2pk myfont.ttf myfont.pk

Convert myfont.ttf with a pixel size of 12 and resolution of 300 dpi:

ttf2pk -p 12 -x 300 -y 300 myfont.ttf myfont.pk
