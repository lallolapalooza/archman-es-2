ttk::scrollbar(n) Widget Tematizado de Tk ttk::scrollbar(n)

NOMBRE

ttk::scrollbar - Controlar la vista de un widget desplazable

SINOPSIS

ttk::scrollbar rutaNombre ?opciones...?

DESCRIPCIÓN

Los widgets ttk::scrollbar suelen estar enlazados a una ventana asociada que muestra un documento de algún tipo, como un archivo que se está editando o un dibujo. Una barra de desplazamiento muestra un cursor en la porción central de la barra, cuya posición y tamaño proporciona información sobre la porción del documento visible en la ventana asociada. El cursor puede ser arrastrado por el usuario para controlar la región visible. Dependiendo del tema, también pueden estar presentes uno o dos botones de flecha; estos se usan para desplazar la región visible en unidades discretas.

OPCIONES ESTÁNDAR

-class	-cursor	-style
-takefocus

Consulte la entrada del manual de ttk::widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Un script Tcl prefijo para evaluar para cambiar la vista en el widget asociado con la barra de desplazamiento. Se añaden argumentos adicionales al valor de esta opción, según se describe en COMANDOS DE DESPLAZAMIENTO a continuación, cada vez que el usuario solicita un cambio de vista manipulando la barra de desplazamiento.

Esta opción normalmente consiste en una lista de dos elementos, que contiene el nombre de un widget desplazable seguido de xview (para barras de desplazamiento horizontales) o yview (para barras de desplazamiento verticales).

Nombre de línea de comandos:	-orient
Nombre de base de datos:	orient
Clase de base de datos:	Orient
Uno de horizontal o vertical. Especifica la orientación de la barra de desplazamiento.

COMANDO DEL WIDGET

rutaNombre cget opción
Devuelve el valor actual de la opción especificada; véase ttk::widget(n).
rutaNombre configure ?opción? ?valor opción valor ...?
Modificar o consultar opciones del widget; véase ttk::widget(n).
rutaNombre get
Devuelve la configuración de la barra de desplazamiento en forma de lista cuyos elementos son los argumentos del comando set más reciente.
rutaNombre identify x y
Devuelve el nombre del elemento en la posición x, y. Véase ttk::widget(n).
rutaNombre instate estadospec ?script?
Probar el estado del widget; véase ttk::widget(n).
rutaNombre set primero último
Este comando normalmente lo invoca el widget asociado a la barra de desplazamiento desde una devolución de llamada -xscrollcommand o -yscrollcommand. Especifica el rango visible a mostrar. primero y último son fracciones reales entre 0 y 1.
rutaNombre state ?estadoSpec?
Modificar o consultar el estado del widget; véase ttk::widget(n).

COMANDOS INTERNOS

Los siguientes comandos de widget son utilizados internamente por las asociaciones de la clase de widget TScrollbar.

rutaNombre delta deltaX deltaY
Devuelve un número real que indica el cambio fraccional en la configuración de la barra de desplazamiento que corresponde a un cambio dado en la posición del cursor. Por ejemplo, si la barra de desplazamiento es horizontal, el resultado indica cuánto debe cambiar la configuración de la barra para mover el cursor deltaX píxeles hacia la derecha (deltaY se ignora en este caso). Si la barra de desplazamiento es vertical, el resultado indica cuánto debe cambiar la configuración de la barra para mover el cursor deltaY píxeles hacia abajo. Los argumentos y el resultado pueden ser cero o negativos.
rutaNombre fraction x y
Devuelve un número real entre 0 y 1 que indica dónde se encuentra el punto dado por x e y en el canal de la barra de desplazamiento, donde 0.0 corresponde a la parte superior o izquierda del canal y 1.0 corresponde a la parte inferior o derecha. X e y son coordenadas de píxeles relativas al widget de la barra de desplazamiento. Si x e y se refieren a un punto fuera del canal, se usará el punto más cercano en el canal.

COMANDOS DE DESPLAZAMIENTO

Cuando el usuario interactúa con la barra de desplazamiento, por ejemplo, arrastrando el cursor, la barra de desplazamiento notifica al widget asociado que debe cambiar su vista. La barra de desplazamiento realiza la notificación evaluando un comando Tcl generado a partir de la opción -command de la barra de desplazamiento. El comando puede tomar cualquiera de las siguientes formas. En cada caso, prefijo es el contenido de la opción -command, que normalmente tiene una forma como .t yview

prefijo moveto fracción
Fracción es un número real entre 0 y 1. El widget debe ajustar su vista para que el punto dado por fracción aparezca al principio del widget. Si fracción es 0 se refiere al principio del documento. 1.0 se refiere al final del documento, 0.333 se refiere a un punto a un tercio del camino a través del documento, y así sucesivamente.
prefijo scroll número unidades
El widget debe ajustar su vista en número unidades. Las unidades se definen de la forma que tenga más sentido para el widget, como caracteres o líneas en un widget de texto. Número es 1, lo que significa que una unidad debe salir de la parte superior o izquierda de la ventana, o -1, lo que significa que una unidad debe salir de la parte inferior o derecha de la ventana.
prefijo scroll número páginas
El widget debe ajustar su vista en número páginas. Depende del widget definir el significado de una página; normalmente es ligeramente menor que lo que cabe en la ventana, de modo que haya una ligera superposición entre las vistas antigua y nueva. Número es 1, lo que significa que la siguiente página debe quedar visible, o -1, lo que significa que la página anterior debe quedar visible.

ESTADOS DEL WIDGET

La barra de desplazamiento establece automáticamente el bit de estado disabled cuando todo el rango es visible (el rango es de 0.0 a 1.0), y lo borra en caso contrario. También establece las banderas de estado active y pressed de los elementos individuales, basándose en la posición y el estado del puntero del ratón.

EJEMPLO

set f [frame .f]
ttk::scrollbar $f.hsb -orient horizontal -command [list $f.t xview]
ttk::scrollbar $f.vsb -orient vertical -command [list $f.t yview]
text $f.t -xscrollcommand [list $f.hsb set] -yscrollcommand [list $f.vsb set]
grid $f.t -row 0 -column 0 -sticky nsew
grid $f.vsb -row 0 -column 1 -sticky nsew
grid $f.hsb -row 1 -column 0 -sticky nsew
grid columnconfigure $f 0 -weight 1
grid rowconfigure $f 0 -weight 1
pack $f

OPCIONES DE ESTILISMO

El nombre de la clase para un ttk::scrollbar es TScrollbar.

Estados dinámicos: active, disabled.

Las opciones de estilismo de TScrollbar (o más específicamente Vertical.TScrollbar y Horizontal.TScrollbar) que son configurables con ttk::style son:

-arrowcolor color
-arrowsize cantidad
-background color
-bordercolor

> color
-darkcolor color (color de la parte oscura del relieve 3D)
-foreground color
-gripcount count (número de líneas en el pulgar)
-lightcolor color (color de la parte clara del relieve 3D)
-troughcolor color

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos ttk.
