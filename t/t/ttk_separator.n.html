ttk::separator(n) Widget Tematizado de Tk ttk::separator(n)

NOMBRE

ttk::separator - Barra separadora

SINOPSIS

ttk::separator nombreRuta ?opciones?

DESCRIPCIÓN

Un widget ttk::separator muestra una barra separadora horizontal o vertical.

OPCIONES ESTÁNDAR

-class	-cursor
-style	-takefocus

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre en la línea de comandos:	-orient
Nombre en la base de datos:	orient
Clase en la base de datos:	Orient
Uno de horizontal o vertical. Especifica la orientación del separador.

COMANDO DEL WIDGET

Los widgets separadores admiten los métodos estándar cget, configure, identify, instate y state. No se utilizan otros métodos de widget.

OPCIONES DE ESTILO

El nombre de la clase para un ttk::separator es TSeparator.

Las opciones de estilo de TSeparator configurables con ttk::style son:

-background color

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.
