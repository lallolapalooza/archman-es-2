ttk::widget(n) Tk Themed Widget ttk::widget(n)

NOMBRE

ttk::widget - Opciones y comandos estándar soportados por los widgets temáticos de Tk

DESCRIPCIÓN

Este manual describe las opciones y comandos comunes de los widgets.

OPCIONES ESTÁNDAR

Las siguientes opciones son soportadas por todos los widgets temáticos de Tk:

Nombre de línea de comandos:	-class
Nombre de base de datos:	undefined
Clase de base de datos:	undefined
Especifica la clase de la ventana. La clase se utiliza al consultar la base de datos de opciones para las otras opciones de la ventana, para determinar los bindtags predeterminados para la ventana y para seleccionar el diseño y el estilo predeterminados del widget. Esta es una opción de solo lectura: solo puede especificarse cuando se crea la ventana y no se puede cambiar con el comando de widget configure.
Nombre de línea de comandos:	-cursor
Nombre de base de datos:	cursor
Clase de base de datos:	Cursor
Especifica el cursor del ratón que se utilizará para el widget. Consulte Tk_GetCursor y cursors(n) en el manual de referencia de Tk para ver los valores legales. Si se establece en una cadena vacía (el valor predeterminado), el cursor se hereda del widget padre.
Nombre de línea de comandos:	-takefocus
Nombre de base de datos:	takeFocus
Clase de base de datos:	TakeFocus
Determina si la ventana acepta el foco durante la navegación por teclado. Puede ser 0, 1, un prefijo de comando (al que se añade la ruta del widget y que debería devolver 0 o 1), o una cadena vacía. Consulte options(n) en el manual de referencia de Tk para obtener la descripción completa.
Nombre de línea de comandos:	-style
Nombre de base de datos:	style
Clase de base de datos:	Style
Puede usarse para especificar un estilo de widget personalizado.

OPCIONES DE WIDGET DESPLAZABLE

Las siguientes opciones son soportadas por los widgets que pueden ser controlados por una barra de desplazamiento. Consulte scrollbar(n) para más información.

Nombre de línea de comandos:	-xscrollcommand
Nombre de base de datos:	xScrollCommand
Clase de base de datos:	ScrollCommand
Un prefijo de comando, utilizado para comunicarse con barras de desplazamiento horizontales.
Cuando la vista en la ventana del widget cambia, el widget generará un comando Tcl concatenando el comando de desplazamiento y dos números. Cada uno de los números es una fracción entre 0 y 1 que indica una posición en el documento; 0 indica el principio y 1 indica el final. La primera fracción indica la primera información en el widget que es visible en la ventana, y la segunda fracción indica la información justo después de la última parte que es visible.

Normalmente, la opción -xscrollcommand consiste en el nombre de ruta de un widget scrollbar seguido de “set”, por ejemplo, “.x.scrollbar set”. Esto hará que la barra de desplazamiento se actualice cada vez que cambie la vista en la ventana.

Si esta opción se establece en una cadena vacía (el valor predeterminado), no se ejecutará ningún comando.

Nombre de línea de comandos:	-yscrollcommand
Nombre de base de datos:	yScrollCommand
Clase de base de datos:	ScrollCommand
Un prefijo de comando, utilizado para comunicarse con barras de desplazamiento verticales. Consulte la descripción de -xscrollcommand anterior para obtener detalles.

OPCIONES DE ETIQUETA

Las siguientes opciones son soportadas por etiquetas, botones y otros widgets similares a botones:

Nombre de línea de comandos:	-compound
Nombre de base de datos:	compound
Clase de base de datos:	Compound
Especifica cómo mostrar la imagen en relación con el texto, en caso de que estén presentes tanto -text como -image. Si se establece en una cadena vacía (el valor predeterminado), las reglas descritas en la sección "Elementos" de ttk::intro(n) explican qué valor se utiliza realmente. Los otros valores válidos son:
text
Mostrar solo texto.
image
Mostrar solo imagen.
center
Mostrar texto centrado sobre la imagen.
top
bottom
left
right
Mostrar la imagen encima, debajo, a la izquierda o a la derecha del texto, respectivamente.
none
Mostrar la imagen si está presente, de lo contrario el texto.
Nombre de línea de comandos:	-font
Nombre de base de datos:	font
Clase de base de datos:	Font
Fuente a utilizar para el texto mostrado por el widget.
Nombre de línea de comandos:	-foreground
Nombre de base de datos:	textColor
Clase de base de datos:	TextColor
Color de primer plano del widget. Si no se especifica, se utiliza el valor predeterminado del tema.
Nombre de línea de comandos:	-image
Nombre de base de datos:	image
Clase de base de datos:	Image
Especifica una imagen a mostrar. Es una lista de uno o más elementos. El primer elemento es el nombre de la imagen predeterminada. El resto de la lista es una secuencia de pares statespec / valor según style map, que especifican diferentes imágenes a utilizar cuando el widget está en un estado o combinación de estados particular. Todas las imágenes de la lista deben tener el mismo tamaño.
Nombre de línea de comandos:	-padding
Nombre de base de datos:	padding
Clase de base de datos:	Padding
Especifica el relleno interno del widget. El relleno es una lista de hasta cuatro especificaciones de longitud left top right bottom. Si se especifican menos de cuatro elementos, bottom toma el valor de top, right toma el valor de left, y top toma el valor de left. En otras palabras, una lista de tres números especifica el relleno izquierdo, vertical y derecho; una lista de dos números especifica el relleno horizontal y vertical; un solo número especifica el mismo relleno alrededor del widget.
Nombre de línea de comandos:	-text
Nombre de base de datos:	text
Clase de base de datos:	Text
Especifica una cadena de texto a mostrar dentro del widget (a menos que sea reemplazada por -textvariable para los widgets que admiten esta opción).
Nombre de línea de comandos:	-textvariable
Nombre de base de datos:	textVariable
Clase de base de datos:	Variable
Especifica el nombre de una variable global cuyo valor se utilizará en lugar del recurso -text.
Nombre de línea de comandos:	-underline
Nombre de base de datos:	underline
Clase de base de datos:	Underline
Si se establece, especifica el índice entero (basado en 0) de un carácter a subrayar en la cadena de texto. El carácter subrayado se utiliza para la activación mnemotécnica.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Si es mayor que cero, especifica cuánta espacio, en anchos de carácter, se asigna para la etiqueta de texto. Si es menor que cero, especifica un ancho mínimo. Si es cero o no se especifica, se utiliza el ancho natural de la etiqueta de texto.

OPCIONES DE COMPATIBILIDAD

Esta opción solo está disponible para widgets temáticos que tienen widgets tradicionales de Tk "correspondientes".

Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Puede establecerse en normal o disabled para controlar el bit de estado disabled. Esta es una opción de solo escritura: establecerla cambia el estado del widget, pero el comando de widget state no afecta a la opción -state.

COMANDOS

pathName cget option
Devuelve el valor actual de la opción de configuración dada por option.
pathName configure ?option? ?value option value ...?
Se utiliza para modificar las opciones de configuración del widget. Si se especifica un argumento option, devuelve el valor de esa opción. Si se especifican pares option value, se modifican las opciones del widget. Si no se especifica ningún argumento, se devuelve una lista de todas las opciones y sus valores.

Este sitio no está asociado de ninguna forma con Arch Linux ni afiliado a este proyecto. El contenido es únicamente una traducción de las páginas del manual de Arch publicadas en man.archlinux.org.

Consulta o modifica las opciones de configuración del widget. Si se especifican uno o más pares de opción-valor, el comando modifica las opciones del widget dadas para que tengan los valores dados; en este caso, el comando devuelve una cadena vacía. Si se especifica opción sin valor, el comando devuelve una lista que describe la opción nombrada: los elementos de la lista son el nombre de la opción, el nombre de la base de datos, la clase de la base de datos, el valor predeterminado y el valor actual. Si no se especifica ninguna opción, devuelve una lista que describe todas las opciones disponibles para rutaNombre.
rutaNombre identificar elemento x y
Devuelve el nombre del elemento debajo del punto dado por x e y, o una cadena vacía si el punto no se encuentra dentro de ningún elemento. x e y son coordenadas de píxeles relativas al widget. Algunos widgets aceptan otros subcomandos de identificar descritos en la documentación de estos widgets.
rutaNombre instate especifEstado ?script?
Prueba el estado del widget. Si no se especifica script, devuelve 1 si el estado del widget coincide con especifEstado y 0 en caso contrario. Si se especifica script, es equivalente a:
si {[rutaNombre instate especifEstado]} script
rutaNombre estado ?especifEstado?
Modifica o consulta el estado del widget. Si especifEstado está presente, establece el estado del widget: por cada indicador en especifEstado, establece el indicador correspondiente o lo borra si va precedido por un signo de exclamación.
Devuelve una nueva especificación de estado que indica qué indicadores se cambiaron: 
set cambios [rutaNombre estado especif]
rutaNombre estado $cambios
restaurará rutaNombre al estado original. Si especifEstado no se especifica, devuelve una lista de los indicadores de estado actualmente habilitados.
rutaNombre xview args
Este comando se utiliza para consultar y cambiar la posición horizontal del contenido en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
rutaNombre xview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo horizontal que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo es .6, el 20% del contenido del widget está fuera de la pantalla hacia la izquierda, el 40% medio es visible en la ventana y el 40% del contenido está fuera de la pantalla hacia la derecha. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -xscrollcommand.
rutaNombre xview índice
Ajusta la vista en la ventana para que el contenido dado por índice se muestre en el borde izquierdo de la ventana.
rutaNombre xview moveto fracción
Ajusta la vista en la ventana para que el carácter en la fracción del contenido aparezca en el borde izquierdo de la ventana. Fracción debe ser una fracción entre 0 y 1.
rutaNombre xview scroll número qué
Este comando desplaza la vista en la ventana hacia la izquierda o hacia la derecha según número y qué. Número debe ser un entero. Qué debe ser unidades o páginas. Si qué es unidades, la vista se ajusta a izquierda o derecha por número de caracteres de ancho promedio en la pantalla; si es páginas, la vista se ajusta por número de pantallas completas. Si número es negativo, se hacen visibles caracteres más hacia la izquierda; si es positivo, se hacen visibles caracteres más hacia la derecha.
rutaNombre yview args
Este comando se utiliza para consultar y cambiar la posición vertical del contenido en la ventana del widget. Puede tomar cualquiera de las siguientes formas:
rutaNombre yview
Devuelve una lista que contiene dos elementos. Cada elemento es una fracción real entre 0 y 1; juntos describen el tramo vertical que es visible en la ventana. Por ejemplo, si el primer elemento es .2 y el segundo es .6, el 20% del contenido del widget está fuera de la pantalla hacia arriba, el 40% medio es visible en la ventana y el 40% del contenido está fuera de la pantalla hacia abajo. Estos son los mismos valores que se pasan a las barras de desplazamiento a través de la opción -yscrollcommand.
rutaNombre yview índice
Ajusta la vista en la ventana para que el contenido dado por índice se muestre en el borde superior de la ventana.
rutaNombre yview moveto fracción
Ajusta la vista en la ventana para que el elemento en la fracción del contenido aparezca en el borde superior de la ventana. Fracción debe ser una fracción entre 0 y 1.
rutaNombre yview scroll número qué
Este comando desplaza la vista en la ventana hacia arriba o hacia abajo según número y qué. Número debe ser un entero. Qué debe ser unidades o páginas. Si qué es unidades, la vista se ajusta hacia arriba o hacia abajo por número de caracteres de ancho promedio en la pantalla; si es páginas, la vista se ajusta por número de pantallas completas. Si número es negativo, se hacen visibles elementos más hacia arriba; si es positivo, se hacen visibles elementos más hacia abajo.

ESTADOS DEL WIDGET

El estado del widget es un mapa de bits de indicadores de estado independientes. Los indicadores de estado del widget incluyen:

activo
El cursor del ratón está sobre el widget y al presionar un botón del ratón se producirá alguna acción. (también conocido como "preiluminado" (Gnome), "caliente" (Windows), "hover").
deshabilitado
Widget deshabilitado por control del programa (también conocido como "no disponible", "inactivo").
foco
El widget tiene el foco del teclado.
presionado
El widget se está presionando (también conocido como "activado" en Motif).
seleccionado
"Encendido", "verdadero" o "actual" para cosas como casillas de verificación y botones de radio.
fondo
Las ventanas y Mac tienen una noción de una ventana "activa" o frontal. El estado fondo se establece para los widgets en una ventana de fondo y se borra para los de la ventana frontal.
sololectura
El widget no debe permitir la modificación por parte del usuario.
alternativo
Un formato de visualización alternativo específico del widget. Por ejemplo, se utiliza para casillas de verificación y botones de radio en el estado de "tercer estado" o "mixto", y para botones con -predeterminado activo.
invalido
El valor del widget no es válido. (Usos potenciales: valor del widget de escala fuera de límites, valor del widget de entrada no válido).
hover
El cursor del ratón está dentro del widget. Esto es similar al estado activo; se utiliza en algunos temas para widgets que proporcionan retroalimentación visual distinta para el widget activo además del elemento activo dentro del widget.
usuario1-usuario3
Libremente utilizable para otros fines.

Una especificación de estado o especifEstado es una lista de nombres de estado, opcionalmente precedidos por un signo de exclamación (!) que indica que el bit está apagado.

EJEMPLOS

set b [ttk::button .b]
# Deshabilitar el widget:
$b estado deshabilitado
# Invocar el widget solo si está actualmente presionado y habilitado:
$b instate {presionado !deshabilitado} { .b invocar }
# Volver a habilitar el widget:
$b estado !deshabilitado

DESCRIPCIÓN

El módulo ttk contiene varios widgets, además de un tema de compatibilidad para Tk 8.4 y un sistema de temas para que los widgets se vean y se sientan nativos en diferentes sistemas operativos.

Para usar un widget ttk, primero debe importarlo: 

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
label = ttk.Label(root, text="¡Hola Mundo!")
label.pack()
root.mainloop()

OPCIONES ESTÁNDAR

Los widgets ttk admiten las siguientes opciones estándar:

  • class: El nombre de clase del widget. Esto se usa para estilizar el widget.
  • cursor: El cursor que se mostrará cuando el mouse esté sobre el widget.
  • font: La fuente del texto del widget.
  • padding: Relleno alrededor del contenido del widget.
  • relief: El estilo del borde del widget. Los valores posibles son flat, raised, sunken, groove, y ridge.
  • style: El nombre de estilo del widget. Esto se usa para aplicar estilos específicos al widget.
  • takefocus: Indica si el widget debe recibir el foco del teclado.
  • tooltip: El texto que se mostrará en una información emergente cuando el mouse esté sobre el widget.

COMANDOS DE WIDGET

Los widgets ttk admiten los siguientes comandos estándar:

  • cget(option): Devuelve el valor de la opción dada.
  • configure(option=value, ...): Configura las opciones dadas del widget.
  • state(state=None): Devuelve o establece el estado del widget.

ESTADOS DE WIDGET

Los widgets ttk admiten los siguientes estados:

  • normal: El widget está habilitado y se puede usar.
  • disabled: El widget está deshabilitado y no se puede usar.
  • active: El widget está activo. Por ejemplo, un botón está activo cuando el mouse está sobre él.
  • selected: El widget está seleccionado. Por ejemplo, un cuadro de verificación está seleccionado.
  • readonly: El widget es de solo lectura. Por ejemplo, un campo de entrada puede ser de solo lectura.

EJEMPLOS

Aquí hay un ejemplo de cómo crear un botón ttk: 

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
button = ttk.Button(root, text="Haz clic aquí")
button.pack()
root.mainloop()

Aquí hay un ejemplo de cómo crear una etiqueta ttk: 

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
label = ttk.Label(root, text="Esto es una etiqueta")
label.pack()
root.mainloop()
