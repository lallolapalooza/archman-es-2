ttk_treeview(n)

Paquete: tk

Licencias: TCL

ttk::treeview(n) Widget temático de Tk ttk::treeview(n)

NOMBRE

ttk::treeview - widget de visualización de datos jerárquicos multicolumna

SINOPSIS

ttk::treeview ruta_de_acceso ?opciones?

DESCRIPCIÓN

El widget ttk::treeview muestra una colección jerárquica de elementos. Cada elemento tiene una etiqueta textual, una imagen opcional y una lista opcional de valores de datos. Los valores de datos se muestran en columnas sucesivas después de la etiqueta del árbol.

El orden en el que se muestran los valores de los datos puede ser controlado estableciendo la opción del widget -displaycolumns. El widget de árbol también puede mostrar encabezados de columna. Las columnas se pueden acceder por número o por nombres simbólicos listados en la opción del widget -columns; ver IDENTIFICADORES DE COLUMNA.

Cada elemento es identificado por un nombre único. El widget generará IDs de elemento si no son suministrados por el llamador. Hay un elemento raíz distinguido, llamado {}. El elemento raíz en sí no se muestra; sus hijos aparecen en el nivel superior de la jerarquía.

Cada elemento también tiene una lista de etiquetas, que pueden ser usadas para asociar enlaces de eventos con elementos individuales y controlar la apariencia del elemento.

Los widgets Treeview soportan desplazamiento horizontal y vertical con las opciones estándar -[xy]scrollcommand y comandos de widget [xy]view.

OPCIONES ESTÁNDAR

-class	-cursor	-takefocus
-style	-xscrollcommand	-yscrollcommand
-padding

Ver la entrada del manual de ttk::widget para detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-columns
Nombre de base de datos:	columns
Clase de base de datos:	Columns
Una lista de identificadores de columna, que especifica el número de columnas y sus nombres.
Nombre de línea de comandos:	-displaycolumns
Nombre de base de datos:	displayColumns
Clase de base de datos:	DisplayColumns
Una lista de identificadores de columna (ya sean nombres simbólicos o índices enteros) que especifican qué columnas de datos se muestran y el orden en que aparecen, o la cadena #all. Si se establece en #all (el valor por defecto), se muestran todas las columnas en el orden dado.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Especifica el número de filas que deben ser visibles. Nota: el ancho solicitado se determina a partir de la suma de los anchos de columna.
Nombre de línea de comandos:	-selectmode
Nombre de base de datos:	selectMode
Clase de base de datos:	SelectMode
Controla cómo los enlaces de clase incorporados gestionan la selección. Uno de extended, browse, o none.

Si se establece en extended (el valor por defecto), se pueden seleccionar varios elementos. Si es browse, solo se seleccionará un elemento a la vez. Si es none, la selección no se modificará.

Tenga en cuenta que el código de la aplicación y los enlaces de etiquetas pueden establecer la selección como deseen, independientemente del valor de -selectmode.

Nombre de línea de comandos:	-show
Nombre de base de datos:	show
Clase de base de datos:	Show
Una lista que contiene cero o más de los siguientes valores, especificando qué elementos del árbol se muestran.
tree
Muestra las etiquetas del árbol en la columna #0.
headings
Muestra la fila de encabezados.

El valor por defecto es tree headings, es decir, muestra todos los elementos.

NOTA: La columna #0 siempre se refiere a la columna del árbol, incluso si -show tree no está especificado.

COMANDO DEL WIDGET

ruta_de_acceso bbox item ?columna?
Devuelve el cuadro delimitador (relativo a la ventana del widget treeview) del item especificado en el formato x y ancho alto. Si se especifica columna, devuelve el cuadro delimitador de esa celda. Si el item no es visible (es decir, si es un descendiente de un elemento cerrado o está fuera de la pantalla), devuelve la lista vacía. Si el elemento es parcialmente visible, el resultado da el área completa del elemento, incluyendo cualquier parte que no sea visible.
ruta_de_acceso cget opción
Devuelve el valor actual de la opción especificada; ver ttk::widget(n).
ruta_de_acceso children item ?nuevos_hijos?
Si nuevos_hijos no se especifica, devuelve la lista de hijos pertenecientes a item.

Si se especifica nuevos_hijos, reemplaza la lista de hijos de item con nuevos_hijos. Los elementos de la lista de hijos antigua que no estén presentes en la nueva lista de hijos se desvinculan del árbol. Ninguno de los elementos de nuevos_hijos puede ser un ancestro de item.

ruta_de_acceso column columna ?-opción ?valor -opción valor...?
Consulta o modifica las opciones para la columna especificada. Si no se especifica ninguna -opción, devuelve un diccionario de pares opción/valor. Si se especifica una única -opción, devuelve el valor de esa opción. De lo contrario, las opciones se actualizan con los valores especificados. Las siguientes opciones se pueden establecer en cada columna:
-id nombre
El nombre de la columna. Esta es una opción de solo lectura. Por ejemplo, [$ruta_de_acceso column #n -id] devuelve la columna de datos asociada con la columna de visualización #n.
-anchor anclaje
Especifica cómo debe alinearse el texto en esta columna con respecto a la celda. Anclaje es uno de n, ne, e, se, s, sw, w, nw, o center.
-minwidth ancho_minimo
El ancho mínimo de la columna en píxeles. El treeview no hará la columna más pequeña que -minwidth cuando el widget se redimensione o el usuario arrastre un separador de columna. Por defecto es 20 píxeles.
-stretch booleano
Especifica si el ancho de la columna debe ajustarse o no cuando el widget se redimensiona o el usuario arrastra un separador de columna. Booleano puede tener cualquiera de los formatos aceptados por Tcl_GetBoolean. Por defecto, las columnas son extensibles.
-width ancho
El ancho de la columna en píxeles. Por defecto es 200 píxeles. El ancho de columna especificado puede ser modificado por Tk para respetar -stretch y/o -minwidth, o cuando el widget se redimensiona o el usuario arrastra un separador de columna.

Use ruta_de_acceso column #0 para configurar la columna del árbol.

ruta_de_acceso configure ?opción? ?valor opción valor ...?
Modifica o consulta las opciones del widget; ver ttk::widget(n).
ruta_de_acceso delete lista_elementos
Elimina cada uno de los elementos en lista_elementos y todos sus descendientes. El elemento raíz no puede ser eliminado. Ver también: detach.
ruta_de_acceso detach lista_elementos
Desvincula todos los elementos especificados en lista_elementos del árbol. Los elementos y todos sus descendientes todavía están presentes y pueden ser reinsertados en otro punto del árbol con la operación move, pero no se mostrarán hasta que eso se haga. El elemento raíz no puede ser desvinculado. Ver también: delete.
ruta_de_acceso exists item
Devuelve 1 si el item especificado está presente en el árbol, 0 en caso contrario.
ruta_de_acceso focus ?item?
Devuelve el elemento que tiene el foco de teclado, o establece el foco en el item especificado.

Si item está vacío, el foco se elimina del árbol.

ruta_de_acceso get itemList ?column?
Devuelve los valores de los datos para los elementos en itemList. Si column se especifica, devuelve solo el valor para esa columna.

Si itemList contiene varios elementos, o si column contiene varias columnas, los resultados se devuelven como listas anidadas.

ruta_de_acceso heading column ?-option? ?value -option value...?
Consulta o modifica las opciones de encabezado para la columna especificada. Si no se especifican opciones, devuelve un diccionario de pares opción/valor. Si se especifica una opción, devuelve el valor de esa opción. De lo contrario, las opciones se actualizan con los valores especificados. Las siguientes opciones son compatibles:
-text cadena
El texto a mostrar en el encabezado de la columna.
-image imagen
La imagen a mostrar en el encabezado de la columna.
-command cmd
Un comando a invocar cuando se haga clic en el encabezado de la columna. El comando se invoca con un solo argumento, el nombre de la columna.
-anchor anclaje
Especifica cómo debe alinearse el texto y la imagen en el encabezado. Anclaje es uno de los valores enumerados para la opción -anchor de celda.
-state estado
Especifica el estado del encabezado, ya sea normal o desactivado.
ruta_de_acceso identify x y
Dado un par de coordenadas x y (relativo a la ventana del widget treeview), devuelve el identificador del elemento y columna en esas coordenadas, o la cadena vacía si las coordenadas no caen dentro de ningún elemento/columna.
ruta_de_acceso index item
Devuelve el índice (posición dentro de su padre) del item especificado.
ruta_de_acceso insert parent item olditem ?options...?
Crea un nuevo elemento con un ID de elemento dado por item. parent es el ID del elemento padre, o la cadena vacía para insertar en la raíz. olditem es el ID del elemento que debe preceder al nuevo elemento; si está vacío, el nuevo elemento se agrega al final de los hijos de parent. El nuevo elemento hereda todos los atributos de olditem. Si olditem está vacío, el nuevo elemento se crea con valores por defecto.

Las siguientes opciones pueden ser especificadas para el nuevo elemento:

-image imagen
Imagen para mostrar junto a la etiqueta del elemento.
-state estado
Valor del estado del elemento, ya sea normal o desactivado.
-values valorList
Una lista de valores para mostrar en las columnas de datos. La longitud de esta lista debe ser igual al número de columnas de datos.
-tags tagList
Una lista de etiquetas para asociar con este elemento.

Si el ID item ya está en uso, se genera uno nuevo. El ID generado se devuelve como resultado del comando.

ruta_de_acceso item item ?-option? ?value -option value...?
Consulta o modifica las opciones de un elemento específico. Si no se especifican opciones, devuelve un diccionario de opciones/valores para el elemento. Si se especifica una opción, devuelve el valor de esa opción. De lo contrario, las opciones se actualizan con los valores especificados. Las opciones disponibles son:
-text cadena
La etiqueta textual para el elemento.
-image imagen
Imagen para mostrar junto a la etiqueta del elemento.
-state estado
Valor del estado del elemento, ya sea normal o desactivado.
-values valorList
Una lista de valores para mostrar en las columnas de datos. La longitud de esta lista debe ser igual al número de columnas de datos.
-tags tagList
Una lista de etiquetas para asociar con este elemento.
ruta_de_acceso move item parent index
Mueve el item especificado (y todos sus descendientes) para que sea el hijo index de parent. index puede ser un entero (0 para el principio, 1 para el segundo, etc.) o la cadena end para agregar al final. Si el item ya es un hijo de parent, se elimina su posición anterior. No se puede mover un elemento bajo uno de sus propios descendientes. El elemento raíz no se puede mover.
ruta_de_acceso next item
Devuelve el ID del siguiente hermano del item especificado, o la cadena vacía si no tiene siguiente hermano.
ruta_de_acceso parent item
Devuelve el ID del padre del item especificado, o la cadena vacía si el elemento es un hijo directo de la raíz.
ruta_de_acceso prev item
Devuelve el ID del hermano anterior del item especificado, o la cadena vacía si no tiene hermano anterior.
ruta_de_acceso see item
Asegura que el item especificado sea visible en la pantalla. Si el elemento es un descendiente de un elemento cerrado, se abrirán todos los elementos intermedios. Si el elemento está fuera de la pantalla, la vista se desplazará para hacerlo visible.
ruta_de_acceso selection ?itemList?
Si itemList no se especifica, devuelve una lista de los elementos actualmente seleccionados.

Si se especifica itemList, la selección actual se reemplaza por los elementos en itemList.

ruta_de_acceso set item &column ?value?
Devuelve el valor del campo column para el item especificado. Si se proporciona value, establece el campo column al nuevo value. Si column es #* (la primera columna), establece la etiqueta y la imagen del elemento.
ruta_de_acceso tag tagName ?itemList?
Devuelve una lista de elementos que tienen la etiqueta tagName. Si se especifica itemList, agrega la etiqueta tagName a cada elemento en itemList.

Los siguientes comandos de etiqueta están disponibles:

ruta_de_acceso tag opción ...
Este es un subcomando para la gestión de etiquetas. Las opciones disponibles son:
-add tagName itemList
Agrega la etiqueta tagName a cada elemento en itemList.
-remove tagName itemList
Elimina la etiqueta tagName de cada elemento en itemList.
-bind tagName tagBindList
Define o anula los enlaces de eventos para los elementos que tienen la etiqueta tagName. Ver la sección EVENT BINDINGS para más detalles.
-configure tagName ?option value ...?
Consulta o modifica las opciones de visualización para los elementos con la etiqueta tagName. Las opciones disponibles son las mismas que las opciones de elemento: -text, -image, -values, -foreground, -background, -font, y -relief.
-lower tagName itemList
Quita la etiqueta tagName de cada elemento en itemList.
-raise tagName itemList
Agrega la etiqueta tagName a cada elemento en itemList.
ruta_de_acceso xview ?args?
Este comando se usa para manipular la barra de desplazamiento horizontal del widget. Consulte la documentación de Tk scrollbar widget para más detalles.
ruta_de_acceso yview ?args?
Este comando se usa para manipular la barra de desplazamiento vertical del widget. Consulte la documentación de Tk scrollbar widget para más detalles.

IDENTIFICADORES DE COLUMNA

Los identificadores de columna se utilizan para referirse a columnas específicas. Pueden ser los nombres simbólicos definidos en la opción -columns, o pueden ser índices numéricos de columna. La columna #0 siempre se refiere a la columna del árbol (la que contiene las etiquetas y la información de jerarquía). Las columnas de datos se indexan a partir de #1.

Por ejemplo, si la opción -columns se establece como $tv -columns {name age city}, entonces las siguientes son formas válidas de referirse a las columnas:

name, age, city

Además, estas columnas se pueden referir por sus índices numéricos:

#0 (la columna del árbol)
#1 (corresponde a `name`)
#2 (corresponde a `age`)
#3 (corresponde a `city`)

La opción -displaycolumns controla qué columnas se muestran y en qué orden. Si se establece como $tv -displaycolumns {#0 #2 #1}, entonces las columnas se mostrarán en el orden: árbol, edad, nombre. La columna `city` no se mostrará.

IDENTIFICADORES DE ELEMENTO

Los elementos se identifican mediante ID de elemento únicos. Si no se proporciona un ID de elemento al insertar un elemento, el widget genera uno. Para la mayoría de los comandos, los IDs de elemento devueltos por el widget son cadenas únicas que representan los elementos.

El ID de elemento especial {} se refiere al elemento raíz, que no se muestra.

ETIQUETAS

Los elementos pueden tener cero o más etiquetas asociadas. Las etiquetas se utilizan para agrupar elementos para fines de modificación o asociación de eventos. Los comandos tag y item se pueden usar para manipular las etiquetas y sus propiedades.

Cada etiqueta puede tener un conjunto de opciones de visualización asociadas (-foreground, -background, -font, -}). Si un elemento tiene varias etiquetas, las opciones de la última etiqueta especificada en la lista de etiquetas del elemento tendrán precedencia.

EVENT BINDINGS

Los enlaces de eventos para el widget treeview se pueden especificar de forma similar a otros widgets de Tk. Sin embargo, los enlaces de eventos para elementos individuales se pueden definir usando el comando tag bind. El formato es:

widget tag bind tagName sequence cmd

Cuando ocurre un evento de sequence en un elemento que tiene la etiqueta tagName, el comando cmd se invoca.

Los comandos de enlace de eventos para treeview tienen acceso a variables especiales:

%x, %y
Las coordenadas del puntero del ratón en el momento del evento.
%X, %Y
Las coordenadas del puntero del ratón relativas a la ventana del widget treeview.
%W
El nombre del widget treeview.
%e
El nombre del elemento en el que ocurrió el evento.
%T
El nombre de la etiqueta que activó el enlace.

Se pueden definir enlaces de eventos para el widget completo, así como para elementos individuales mediante el uso de etiquetas.

EJEMPLO

El siguiente ejemplo crea un widget treeview simple con tres columnas, agrega algunos elementos y configura algunos enlaces de eventos básicos.

package require Tk
package require Ttk

set tv [ttk::treeview .tv -columns {name age city} -show headings]
.tv heading #0 -text "Name"
.tv heading #1 -text "Age"
.tv heading #2 -text "City"

.tv insert {} end -text "John Doe" -values {30 New York}
.tv insert {} end -text "Jane Smith" -values {25 London}

.tv column #0 -width 100 -stretch 1
.tv column #1 -width 50 -stretch 0
.tv column #2 -width 100 -stretch 1

pack .tv -expand 1 -fill both

bind .tv <Double-1> [.tv @%x,%y get %e]

NAME

ttk::treeview — widget that displays items in a hierarchical tree

SYNOPSIS

ttk::treeview widgetName options

DESCRIPTION

The ttk::treeview widget displays a list of items. Each item may have child items, and may have associated values displayed in columns to the right of the tree. The widget supports hierarchical display of items, scrolling, column headings, and item selection.

The treeview widget supports the following options:

-bootstyle style
The widget style to use for the boot style. See ttk::style(n) for more information.
-columns columns
A list of symbolic names for the columns. The first column, which displays the tree, is not in this list. Its name is always “#0”. These names are used to identify columns in the -displaycolumns option, and when creating column headings.
-displaycolumns columns
A list of columns to be displayed. The list may contain column names or integers. If a column name is specified, it must be one of the symbolic names specified in the -columns option. If an integer n is specified, it refers to the nth data column (the nth value in an item's -values list). If this option is not set, all columns are displayed in the order they are defined in the -columns option. The list may also include the symbolic name “#0” to explicitly include the tree column. For example: -displaycolumns {#0 1 3}.
-height amount
The number of rows to display. If less than the number of items, the widget will be scrolled.
-padding padding
Specifies the padding around the outside of the treeview widget. The value is a list of lengths, same format as Tk_ConfigureWidget. Defaults to 0.
-selectmode mode
Specifies the selection mode. Possible values are: browse, extended, none.
-show visibletype
Specifies which parts of the widget are visible. Valid values are: tree, headings, both, none. Default is both.
-takefocus boolean
Specifies whether the widget can receive keyboard focus. Defaults to 1.
-xscrollcommand command
Command used to manage the horizontal scrollbar. Default is empty.
-yscrollcommand command
Command used to manage the vertical scrollbar. Default is empty.

STANDARD OPTIONS

The ttk::treeview widget supports the following standard options:

-class, -colormap, -cursor, -height, -label, -orient, -relief, -width.

All other standard options are unchanged.

WIDGET-SPECIFIC OPTIONS

The treeview widget also supports the following generic ttk::widget widget subcommands (see ttk::widget(n) for details):

xview	yview

WIDGET COMMAND

The widgetName command supports the following subcommands:

children item
Returns a list of the child items of item.
column columnName ?option value ...?
Query or modify the properties of columnName. If no option value pairs are supplied, returns a dictionary of the column's options. Valid options are: -id, -anchor, -command, -flags, -heading, -movable, -minwidth, -padding, -stretch, -width.
delete item ?item ...?
Deletes the specified items and all their descendants.
detach item ?item ...?
Detaches the specified items from the tree. They can later be re-attached using the move command.
focus ?item?
If item is specified, sets the focus item to item. Otherwise, returns the item that currently has focus.
heading columnName ?option value ...?
Query or modify the properties of the heading for columnName. If no option/value pairs are supplied, returns a dictionary of the heading's options. Valid options are: -text, -image, -compound, -anchor, -state.
identify component x y
Returns the item and component that are at the screen coordinates x and y. component can be item, column, or region. Returns an empty string if the coordinates are not in the widget.
index item
Returns the index of item relative to its parent.
insert parent itemname ?itemname ...? ?option value ...?
Creates a new item. parent is the parent item, or "" for a top-level item. itemname is the name for the new item. If itemname is omitted, a unique name is generated. The options are item options (see ITEM OPTIONS below).
item item ?option value ...?
Query or modify the properties of item. If no option/value pairs are supplied, returns a dictionary of the item's options. Valid options are the item options described below.
move item name position
Moves item to a new position under the given name. If name is empty, the item is moved to the top level. If position is empty, the item is appended to the end of the parent's children.
next item
Returns the next sibling of item, or an empty string if there is no next sibling.
parent item
Returns the parent of item, or an empty string if item is a top-level item.
prev item
Returns the previous sibling of item, or an empty string if there is no previous sibling.
set item columnName ?value?
If value is specified, sets the value of the cell identified by item and columnName to value. Otherwise, returns the current value.
size item
Returns the number of children of item.
tag ?option value ...? item ?item ...?
Query or modify the tags associated with the specified items. Valid options are: -add, -remove, -select, -conflicts.
view
Returns a list of the items currently visible in the widget.

ITEM OPTIONS

The following item options may be specified for items in the insert and item widget commands.

Command-Line Name:	-text
Database Name:	text
Database Class:	Text
The textual label to display for the item.
Command-Line Name:	-image
Database Name:	image
Database Class:	Image
A Tk image, displayed to the left of the label.
Command-Line Name:	-values
Database Name:	values
Database Class:	Values
The list of values associated with the item.

Each item should have the same number of values as the -columns widget option. If there are fewer values than columns, the remaining values are assumed empty. If there are more values than columns, the extra values are ignored.

Command-Line Name:	-open
Database Name:	open
Database Class:	Open
A boolean value indicating whether the item's children should be displayed (-open true) or hidden (-open false).
Command-Line Name:	-tags
Database Name:	tags
Database Class:	Tags
A list of tags associated with this item.

TAG OPTIONS

The following options may be specified on tags:

-foreground
Specifies the text foreground color.
-background
Specifies the cell or item background color.
-font
Specifies the font to use when drawing text.
-image
Specifies the item image, in case the item's -image option is empty.

Tag priority is decided by the creation order: tags created first receive higher priority.

COLUMN IDENTIFIERS

Column identifiers take any of the following forms:

  • A symbolic name from the list of -columns.
  • An integer n, specifying the nth data column.
  • A string of the form #n, where n is an integer, specifying the nth display column.

NOTE: Item -values may be displayed in a different order than the order in which they are stored.

NOTE: Column #0 always refers to the tree column, even if -show tree is not specified.

A data column number is an index into an item's -values list; a display column number is the column number in the tree where the values are displayed. Tree labels are displayed in column #0. If -displaycolumns is not set, then data column n is displayed in display column #n+1. Again, column #0 always refers to the tree column.

VIRTUAL EVENTS

The treeview widget generates the following virtual events.

<<TreeviewSelect>>
Generated whenever the selection changes. It might also be generated when selection is affected but not actually changed. Further, multiple selection changes could happen before events can be processed leading to multiple events with the same visible selection.
<<TreeviewOpen>>
Generated just before setting the focus item to -open true.
<<TreeviewClose>>
Generated just after setting the focus item to -open false.

The focus and selection widget commands can be used to determine the affected item or items.

STYLING OPTIONS

The class name for a ttk::treeview is Treeview. The treeview header class name is Heading. The treeview item class name is Item. The treeview cell class name is Cell.

Dynamic states: disabled, selected.

Treeview styling options configurable with ttk::style are:

-background color
-fieldbackground color
-font font
-foreground color
-indent amount

Specifies how far items are indented from their parents. Defaults to 20 pixels. The value may have any of the forms acceptable to Tk_GetPixels.
-rowheight amount
This is the standard height for an item. Defaults to 20 pixels. The value may have any of the forms acceptable to Tk_GetPixels. If -rowheight is not set by the style, it is set by measuring an item and a cell layout with the style's settings. This thus picks up the font and any focus ring or padding from the theme's layout. The -rowheight may need to be set to make sure that a row is large enough to contain any images.

To adjust the -rowheight for the Treeview style, use the following code after tk scaling has been applied. Note that even if you do not support or change tk scaling in your program, your users may have it set in their .wishrc.

ttk::style configure Treeview \
     -rowheight [expr {[font metrics font -linespace] + 2}]

Heading styling options configurable with ttk::style are:

-background color
-font font
-relief relief

Item styling options configurable with ttk::style are:

-foreground color
-indicatormargins padding
-indicatorsize amount
-padding padding

Cell styling options configurable with ttk::style are:

-padding padding

Some options are only available for specific themes.

See the ttk::style manual page for information on how to configure ttk styles.
