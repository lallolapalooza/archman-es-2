ttk_panedwindow(n)

Paquete: tk

Licencias: TCL

ttk::panedwindow(n) Tk Themed Widget ttk::panedwindow(n)

NOMBRE

ttk::panedwindow - Ventana contenedor de múltiples paneles

SINOPSIS

ttk::panedwindow pathname ?options?
pathname add window ?options...?
pathname insert index window ?options...?

DESCRIPCIÓN

Un widget ttk::panedwindow muestra una serie de subventanas, apiladas vertical u horizontalmente. El usuario puede ajustar los tamaños relativos de las subventanas arrastrando el separador entre los paneles.

OPCIONES ESTÁNDAR

-class	-cursor	-takefocus
-style

Vea la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-orient
Nombre de base de datos:	orient
Clase de base de datos:	Orient
Especifica la orientación de la ventana. Si es vertical, los subpaneles se apilan de arriba a abajo; si es horizontal, los subpaneles se apilan de izquierda a derecha.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Si está presente y es mayor que cero, especifica el ancho deseado del widget en píxeles. De lo contrario, el ancho solicitado se determina por el ancho de las ventanas gestionadas.
Nombre de línea de comandos:	-height
Nombre de base de datos:	height
Clase de base de datos:	Height
Si está presente y es mayor que cero, especifica la altura deseada del widget en píxeles. De lo contrario, la altura solicitada se determina por la altura de las ventanas gestionadas.

OPCIONES DE PANEL

Las siguientes opciones se pueden especificar para cada panel:

Nombre de línea de comandos:	-weight
Nombre de base de datos:	weight
Clase de base de datos:	Weight
Un entero que especifica la extensibilidad relativa del panel. Cuando se redimensiona la ventana dividida, el espacio adicional se agrega o se resta a cada panel en proporción a su -weight.

COMANDO DEL WIDGET

Admite los comandos estándar configure, cget, state e instate; consulte la entrada del manual de ttk::widget(n) para obtener detalles. Comandos adicionales:

pathname add subwindow opciones...
Añade un nuevo panel a la ventana. Consulte OPCIONES DE PANEL para la lista de opciones disponibles.
pathname forget pane
Elimina el subpanel especificado del widget. pane es un índice entero o el nombre de una subventana gestionada.
pathname identify component x y
Devuelve el nombre del elemento que se encuentra debajo del punto dado por x e y, o la cadena vacía si no hay ningún componente en esa ubicación. Si se omite component, se usa sash por defecto. Se admiten los siguientes subcomandos:
pathname identify element x y
Devuelve el nombre del elemento en la ubicación especificada.
pathname identify sash x y
Devuelve el índice del separador en la ubicación especificada.
pathname insert pos subwindow opciones...
Inserta un panel en la posición especificada. pos es la cadena end, un índice entero o el nombre de una subventana gestionada. Si subwindow ya está gestionado por la ventana dividida, lo mueve a la posición especificada. Consulte OPCIONES DE PANEL para la lista de opciones disponibles.
pathname pane pane -option ?value ?-option value...
Consulta o modifica las opciones del pane especificado, donde pane es un índice entero o el nombre de una subventana gestionada. Si no se especifica ninguna opción -option, devuelve un diccionario con los valores de las opciones del panel. Si se especifica una única opción -option, devuelve el valor de esa option. De lo contrario, establece las opciones -option a los valores correspondientes.
pathname panes
Devuelve la lista de todas las ventanas gestionadas por el widget, en el orden de índice de sus paneles asociados.
pathname sashpos index ?newpos?
Si se especifica newpos, establece la posición del separador número index. Puede ajustar las posiciones de los separadores adyacentes para asegurar que las posiciones sean monótonamente crecientes. Las posiciones de los separadores están además limitadas a estar entre 0 y el tamaño total del widget. Devuelve la nueva posición del separador número index.

El widget panedwindow también admite los siguientes subcomandos genéricos del widget ttk::widget (consulte ttk::widget(n) para obtener detalles):

cget	configure
instate	state

EVENTOS VIRTUALES

El widget panedwindow genera un evento virtual <<EnteredChild>> en los eventos LeaveNotify/NotifyInferior.

OPCIONES DE ESTILO

El nombre de clase para un ttk::panedwindow es TPanedwindow. El separador tiene un nombre de clase de Sash.

Las opciones de estilo de TPanedwindow configurables con ttk::style son:

-background color

Las opciones de estilo de Sash configurables con ttk::style son:

-background color
-bordercolor color
-gripcount count
-handlepad amount
-handlesize amount
-lightcolor color
-sashpad amount
-sashrelief relief
-sashthickness amount

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar estilos ttk.
