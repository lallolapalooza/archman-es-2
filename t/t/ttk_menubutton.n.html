ttk::menubutton(n) Tk Themed Widget ttk::menubutton(n)

NOMBRE

ttk::menubutton - Widget que muestra un menú al ser presionado

SINOPSIS

ttk::menubutton rutaNombre ?opciones?

DESCRIPCIÓN

Un widget ttk::menubutton muestra una etiqueta de texto y/o una imagen, y muestra un menú cuando se presiona.

OPCIONES ESTÁNDAR

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Consulte la entrada del manual ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-direction
Nombre de base de datos:	direction
Clase de base de datos:	Direction
Especifica dónde se mostrará el menú en relación con el menubutton. Uno de: above, below, left, right, o flush. El valor predeterminado es below. flush muestra el menú directamente sobre el menubutton.
Nombre de línea de comandos: -menu
Nombre de base de datos: menu
Clase de base de datos: Menu
Especifica el nombre de ruta del menú asociado con el menubutton. Para estar seguro, el menú debe ser un hijo directo del menubutton.

COMANDO DEL WIDGET

Los widgets Menubutton soportan los métodos estándar cget, configure, identify, instate y state. No se utilizan otros métodos de widget.

ESTILOS ESTÁNDAR

Los widgets ttk::menubutton admiten el estilo Toolbutton en todos los temas estándar, lo cual es útil para crear widgets para barras de herramientas.

OPCIONES DE ESTILISMO

El nombre de clase para un ttk::menubutton es TMenubutton.

Estados dinámicos: active, disabled, readonly.

Las opciones de estilismo de TMenubutton configurables con ttk::style son:

-arrowsize cantidad
-background color
-compound compound
-foreground color
-font fuente
-padding relleno
-relief relieve
-width cantidad

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual ttk::style para obtener información sobre cómo configurar estilos ttk.

VER TAMBIÉN

ttk::widget(n), menu(n), menubutton(n)

PALABRAS CLAVE
