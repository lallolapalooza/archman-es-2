ttk::label(n) Tk Themed Widget ttk::label(n)

NOMBRE

ttk::label - Muestra una cadena de texto y/o una imagen

SINOPSIS

ttk::label rutaNombre ?opciones?

DESCRIPCIÓN

Un widget ttk::label muestra una etiqueta textual y/o una imagen. La etiqueta puede estar enlazada a una variable Tcl para cambiar automáticamente el texto mostrado.

OPCIONES ESTÁNDAR

-class	-compound	-cursor
-image	-padding	-state
-style	-takefocus	-text
-textvariable	-underline	-width

Consulte la entrada del manual de ttk::widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-anchor
Nombre de la base de datos:	anchor
Clase de la base de datos:	Anchor
Especifica cómo se posiciona la información dentro de los márgenes internos del widget. Los valores legales son n, ne, e, se, s, sw, w, nw y center. Vea también -justify.
Nombre de línea de comandos:	-background
Nombre de la base de datos:	frameColor
Clase de la base de datos:	FrameColor
El color de fondo del widget. Si no se especifica, se utiliza el valor predeterminado del tema.
Nombre de línea de comandos:	-font
Nombre de la base de datos:	font
Clase de la base de datos:	Font
Fuente a utilizar para el texto de la etiqueta.
Nombre de línea de comandos:	-foreground
Nombre de la base de datos:	textColor
Clase de la base de datos:	TextColor
El color de primer plano del widget. Si no se especifica, se utiliza el valor predeterminado del tema.
Nombre de línea de comandos:	-justify
Nombre de la base de datos:	justify
Clase de la base de datos:	Justify
Si hay varias líneas de texto, especifica cómo se distribuyen las líneas unas con respecto a las otras. Uno de left, center o right. Vea también -anchor.
Nombre de línea de comandos:	-relief
Nombre de la base de datos:	relief
Clase de la base de datos:	Relief
Especifica el efecto 3D deseado para el borde del widget. Los valores válidos son flat, groove, raised, ridge, solid y sunken.
Nombre de línea de comandos:	-wraplength
Nombre de la base de datos:	wrapLength
Clase de la base de datos:	WrapLength
Especifica la longitud máxima de línea (en píxeles). Si esta opción es menor o igual a cero, el ajuste automático de línea no se realiza; de lo contrario, el texto se divide en líneas de forma que ninguna supere el valor especificado.

COMANDO DEL WIDGET

Admite los comandos estándar del widget configure, cget, identify, instate y state; consulte ttk::widget(n).

OPCIONES DE ESTILADO

El nombre de clase para un ttk::label es TLabel.

Estados dinámicos: disabled, readonly.

Las opciones de estilado de TLabel configurables con ttk::style son:

-background color
-compound compound
-foreground color
-font font

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos ttk.
