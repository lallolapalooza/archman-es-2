ttk_image(n) Tk Themed Widget ttk_image(n)

NOMBRE

ttk_image - Define un elemento basado en una imagen

SINOPSIS

ttk::style element create nombre image especif_imagen ?opciones?

DESCRIPCIÓN

El factor de forma de elemento image crea un nuevo elemento en el tema actual cuya apariencia visual está determinada por imágenes de Tk. especif_imagen es una lista de uno o más elementos. El primer elemento es el nombre de la imagen predeterminada. El resto de la lista es una secuencia de pares especif_estado / valor que especifican otras imágenes a usar cuando el elemento se encuentra en un estado particular o combinación de estados.

OPCIONES

Las opciones válidas son:

-borde relleno
relleno es una lista de hasta cuatro enteros, que especifican los bordes izquierdo, superior, derecho e inferior, respectivamente. Si se especifican menos de cuatro elementos, inferior toma el valor de superior, derecho toma el valor de izquierdo y superior toma el valor de izquierdo. En otras palabras, una lista de tres números especifica el borde izquierdo, vertical y derecho; una lista de dos números especifica el borde horizontal y vertical; un solo número especifica el mismo borde en todos los lados del elemento. Véase ESTIRAMIENTO DE IMAGEN, más abajo.
-altura altura
Especifica una altura mínima para el elemento. Si es menor que cero, se usa la altura de la imagen base como valor predeterminado.
-relleno relleno
Especifica el relleno interior del elemento. El relleno es una lista de hasta cuatro especificaciones de longitud izquierda superior derecha inferior. Si se especifican menos de cuatro elementos, inferior toma el valor de superior, derecho toma el valor de izquierdo y superior toma el valor de izquierdo. En otras palabras, una lista de tres números especifica el relleno izquierdo, vertical y derecho; una lista de dos números especifica el relleno horizontal y vertical; un solo número especifica el mismo relleno en todos los lados del widget. Por defecto es -borde si no se especifica.
-ajuste espec
Especifica cómo se coloca la imagen dentro del paquete final. espec contiene cero o más caracteres “n”, “s”, “w”, o “e”.
-ancho ancho
Especifica un ancho mínimo para el elemento. Si es menor que cero, se usa el ancho de la imagen base como valor predeterminado.

ESTIRAMIENTO DE IMAGEN

Si el paquete asignado al elemento es más grande que la imagen, la imagen se colocará en el paquete según la opción -ajuste. Si la imagen necesita estirarse horizontalmente (es decir, -ajuste ew) o verticalmente (-ajuste ns), se replicarán subregiones de la imagen para llenar el paquete basándose en la opción -borde. El -borde divide la imagen en 9 regiones: cuatro esquinas fijas, los bordes superior e izquierdo (que pueden repetirse horizontalmente), los bordes izquierdo y derecho (que pueden repetirse verticalmente), y el área central (que puede repetirse en ambas direcciones).

Un elemento de imagen que no debe reclamar ningún espacio (por ejemplo, cuando se usa como imagen de fondo) debe usar -ancho 0 y -altura 0.

EJEMPLO

set img1 [image create photo -file button.png]
set img2 [image create photo -file button-pressed.png]
set img3 [image create photo -file button-active.png]
ttk::style element create Button.button image \
    [list $img1  pressed $img2  active $img3] \
    -borde {2 4} -ajuste we
