ttk::checkbutton(n) Widget temático de Tk ttk::checkbutton(n)

NOMBRE

ttk::checkbutton - Widget de encendido/apagado

SINOPSIS

ttk::checkbutton rutaNombre ?opciones?

DESCRIPCIÓN

Un ttk::checkbutton se utiliza para mostrar o cambiar una configuración. Tiene dos estados, seleccionado y deseleccionado. El estado del checkbutton puede estar vinculado a una variable Tcl.

OPCIONES ESTÁNDAR

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-command
Nombre de base de datos:	command
Clase de base de datos:	Command
Un script Tcl para ejecutar cada vez que se invoca el widget.
Nombre de línea de comandos:	-offvalue
Nombre de base de datos:	offValue
Clase de base de datos:	OffValue
El valor que se almacenará en el -variable asociado cuando el widget se deseleccione. Por defecto es 0.
Nombre de línea de comandos:	-onvalue
Nombre de base de datos:	onValue
Clase de base de datos:	OnValue
El valor que se almacenará en el -variable asociado cuando el widget se seleccione. Por defecto es 1.
Nombre de línea de comandos:	-variable
Nombre de base de datos:	variable
Clase de base de datos:	Variable
El nombre de una variable global cuyo valor está vinculado al widget. Por defecto es el nombre de ruta del widget si no se especifica.

COMANDO DEL WIDGET

Además de los comandos estándar cget, configure, identify, instate y state, los checkbuttons admiten los siguientes comandos de widget adicionales:

rutaNombre invoke
Alterna entre los estados seleccionado y deseleccionado y evalúa el -command asociado. Si el widget está actualmente seleccionado, establece la -variable en el -offvalue y deselecciona el widget; de lo contrario, establece la -variable en el -onvalue. Devuelve el resultado del -command.

ESTADOS DEL WIDGET

El widget no responde a la entrada del usuario si se establece el estado disabled. El widget establece el estado selected cada vez que la -variable vinculada se establece en el -onvalue del widget, y lo borra en caso contrario. El widget establece el estado alternate cada vez que la -variable vinculada se desvincula. (El estado alternate puede utilizarse para indicar una selección de tres estados o indeterminada).

ESTILOS ESTÁNDAR

Los widgets Ttk::checkbutton admiten el estilo Toolbutton en todos los temas estándar, lo que es útil para crear widgets para barras de herramientas.

OPCIONES DE ESTILADO

El nombre de clase para un ttk::checkbutton es TCheckbutton.

Estados dinámicos: active, alternate, disabled, pressed, selected, readonly.

Las opciones de estilado de TCheckbutton configurables con ttk::style son:

-background color
-compound compound
-foreground color
-indicatorbackground color
-indicatorcolor color
-indicatormargin padding
-indicatorrelief relief
-padding padding

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos ttk.
