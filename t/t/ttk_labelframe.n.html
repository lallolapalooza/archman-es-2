ttk::labelframe(n) Tk Themed Widget ttk::labelframe(n)

NOMBRE

ttk::labelframe - Widget contenedor con etiqueta opcional

SINOPSIS

ttk::labelframe rutaNombre ?opciones?

DESCRIPCIÓN

Un widget ttk::labelframe es un contenedor utilizado para agrupar otros widgets. Tiene una etiqueta opcional, que puede ser una cadena de texto plano u otro widget.

OPCIONES ESTÁNDAR

-class	-cursor	-padding
-style	-takefocus

Consulte la entrada del manual de ttk_widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-height
Nombre de la base de datos:	height
Clase de la base de datos:	Height
Si se especifica, la altura solicitada del widget en píxeles. (Ver ttk::frame(n) para notas adicionales sobre -width y -height).
Nombre de línea de comandos:	-labelanchor
Nombre de la base de datos:	labelAnchor
Clase de la base de datos:	LabelAnchor
Especifica dónde colocar la etiqueta. Los valores permitidos son (en sentido horario desde la esquina superior izquierda): nw, n, ne, en, e, es, se, s,sw, ws, w y wn. El valor predeterminado depende del tema.
Nombre de línea de comandos:	-labelwidget
Nombre de la base de datos:	labelWidget
Clase de la base de datos:	LabelWidget
El nombre de un widget para usar como etiqueta. Si se establece, anula la opción -text. El -labelwidget debe ser un hijo del widget labelframe o uno de sus ancestros, y debe pertenecer al mismo widget de nivel superior que el labelframe.
Nombre de línea de comandos:	-text
Nombre de la base de datos:	text
Clase de la base de datos:	Text
Especifica el texto de la etiqueta.
Nombre de línea de comandos:	-underline
Nombre de la base de datos:	underline
Clase de la base de datos:	Underline
Si se establece, especifica el índice entero (basado en 0) de un carácter para subrayar en la cadena de texto. El carácter subrayado se utiliza para la activación mnemotécnica. La activación mnemotécnica para un ttk::labelframe establece el foco del teclado en el primer hijo del widget ttk::labelframe.
Nombre de línea de comandos:	-width
Nombre de la base de datos:	width
Clase de la base de datos:	Width
Si se especifica, el ancho solicitado del widget en píxeles.

COMANDO DEL WIDGET

Admite los comandos estándar de widget configure, cget, identify, instate y state; vea ttk::widget(n).

OPCIONES DE ESTILO

El nombre de la clase para un ttk::labelframe es TLabelframe. La etiqueta de texto tiene una clase de TLabelframe.Label.

Estados dinámicos: disabled, readonly.

Las opciones de estilo TLabelframe configurables con ttk::style son:

-background color
-bordercolor color
-borderwidth cantidad
-darkcolor color
-labelmargins cantidad
-labeloutside booleano
-lightcolor color
-relief relieve

Las opciones de estilo TLabelframe.Label configurables con ttk::style son:

-background color
-font fuente
-foreground color

Algunas opciones solo están disponibles para temas específicos.

Consulte la página del manual de ttk::style para obtener información sobre cómo configurar los estilos ttk.

VER TAMBIÉN

ttk::widget(n), ttk::frame(n), labelframe(n)
