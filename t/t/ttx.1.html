TTX(1) Manual de Comandos Generales (manual de fonttools) TTX(1)

NOMBRE

ttx — herramienta para manipular fuentes TrueType y OpenType

SINOPSIS

ttx [opción ...] archivo ...

DESCRIPCIÓN

ttx es una herramienta para manipular fuentes TrueType y OpenType. Puede convertir fuentes TrueType y OpenType a y desde un formato basado en XML llamado TTX. Los archivos TTX tienen una extensión ‘.ttx’.

Para cada argumento archivo que se le da, ttx detecta si es un archivo ‘.ttf’, ‘.otf’ o ‘.ttx’ y actúa en consecuencia: si es un archivo ‘.ttf’ o ‘.otf’, genera un archivo ‘.ttx’; si es un archivo ‘.ttx’, genera un archivo ‘.ttf’ o ‘.otf’.

Por defecto, cada archivo de salida se crea en el mismo directorio que el archivo de entrada correspondiente y con el mismo nombre, excepto por la extensión, que se sustituye apropiadamente. ttx nunca sobrescribe archivos existentes; si es necesario, añade un sufijo al nombre del archivo de salida antes de la extensión, como en Arial#1.ttf.

Opciones generales

-h
Muestra información de uso.
-d dir
Escribe los archivos de salida en el directorio dir en lugar de escribir cada archivo de salida en el mismo directorio que el archivo de entrada correspondiente.
-o archivo
Escribe la salida en archivo en lugar de escribirla en el mismo directorio que el archivo de entrada correspondiente.
-v
Sea verboso. Escribe más mensajes en la salida estándar describiendo lo que se está haciendo.
-a
Permite IDs de glifos virtuales al compilar o descomprimir.

Opciones de volcado

Las siguientes opciones controlan el proceso de volcado de archivos de fuentes (TrueType u OpenType) a archivos TTX.

-l
Lista información de tablas. En lugar de volcar la fuente a un archivo TTX, muestra información mínima sobre cada tabla.
-t tabla
Vuelca la tabla tabla. Esta opción se puede dar múltiples veces para volcar varias tablas a la vez. Cuando no se especifica, se vuelcan todas las tablas.
-x tabla
Excluye la tabla tabla de la lista de tablas a volcar. Esta opción se puede dar múltiples veces para excluir varias tablas del volcado. Las opciones -t y -x son mutuamente excluyentes.
-s
Divide las tablas. Vuelca cada tabla a un archivo TTX separado y escribe (bajo el nombre que se habría utilizado para el archivo de salida si la opción -s no se hubiera dado) un pequeño archivo TTX que contiene referencias a los archivos de volcado de tablas individuales. Este archivo se puede usar como entrada para ttx siempre que los archivos referenciados se encuentren en el mismo directorio.
-i
No desensamblar instrucciones TrueType. Cuando se especifica esta opción, todos los programas TrueType (programas de glifos, el programa de fuentes y el pre-programa) se escriben en el archivo TTX como datos hexadecimales en lugar de ensamblador. Esto ahorra algo de tiempo y da como resultado archivos TTX más pequeños.
-y n
Al descomprimir un archivo de Colección TrueType (TTC), descomprime la fuente número n, comenzando desde 0.

Opciones de compilación

Las siguientes opciones controlan el proceso de compilación de archivos TTX a archivos de fuentes (TrueType u OpenType):

-m archivofuente
Fusiona el archivo TTX de entrada archivo con archivofuente. No se puede especificar más de un argumento archivo cuando se usa esta opción.
-b
No recalcular los cuadros delimitadores de glifos. Utilizar los valores del archivo TTX tal cual.

EL FORMATO DEL ARCHIVO TTX

Puede encontrar información sobre el formato del archivo TTX en documentation.html. En particular, encontrará en ese archivo la lista de tablas entendidas por ttx y las relaciones entre los GlyphIDs de TrueType y los nombres de glifos utilizados en los archivos TTX.

EJEMPLOS

En los siguientes ejemplos, todos los archivos se leen y escriben en el directorio actual. Además, el nombre dado para el archivo de salida asume en cada caso que no existía antes de que se invocara ttx.

Volcar la fuente TrueType contenida en FreeSans.ttf a FreeSans.ttx:

ttx FreeSans.ttf

Compilar MyFont.ttx en un archivo de fuente TrueType u OpenType:

ttx MyFont.ttx

Listar las tablas en FreeSans.ttf junto con alguna información:

ttx -l FreeSans.ttf

Volcar la tabla ‘cmap’ de FreeSans.ttf a FreeSans.ttx:

ttx -t cmap FreeSans.ttf

NOTAS

En MS-Windows y MacOS, ttx está disponible como una aplicación gráfica a la que se pueden arrastrar y soltar archivos.

ttx(1)

NAME

ttx - convert TrueType fonts to and from XML

SYNOPSIS

ttx [options] [font.ttf ...]

DESCRIPTION

The ttx command-line tool takes one or more TrueType font files, converts them to XML (TTX) format, and saves them to disk. It can also convert TTX files back to TrueType font files.

The primary purpose of TTX is to allow manipulation of font data using standard XML tools, and to serve as a portable and human-readable format for storing font data.

THE TTX FILE FORMAT

The TTX file format is an XML representation of the OpenType, TrueType, and SFNT font files. It contains all the information present in the binary font file, but in a structured, human-readable text format. This allows for easy inspection and modification of font data.

EXAMPLES

Convert a TrueType font to TTX format:

ttx font.ttf

This will create a file named font.ttx in the current directory.

Convert a TTX file back to a TrueType font:

ttx font.ttx

This will create a file named font.ttf in the current directory.

Convert multiple fonts:

ttx font1.ttf font2.ttf

This will create font1.ttx and font2.ttx.

NOTES

The ttx tool is part of the fonttools Python package, a collection of tools for manipulating font files.

When converting from TTX to a binary font format, ttx attempts to reconstruct the font file as accurately as possible. However, some information might be lost or altered during the round-trip process, especially if the TTX file has been manually edited.
