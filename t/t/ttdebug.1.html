NOMBRE

ttdebug - un depurador de bytecode TrueType

SINOPSIS

ttdebug [opciones] índice tamaño fuente

DESCRIPCIÓN

ttdebug es un depurador interactivo de bytecode TrueType que funciona en una terminal. Su interfaz espartana se asemeja vagamente a depuradores como gdb.

Para la fuente especificada, se carga un glifo con el índice y tamaño dados, lo que permite rastrear la ejecución del bytecode paso a paso.

Este programa forma parte del paquete de demostraciones de FreeType.

OPCIONES

-I ver
Utiliza la versión del intérprete TrueType ver. Las versiones disponibles dependen de las opciones de compilación de FreeType; llama a ttdebug sin argumentos para obtener la lista real.
-f índice_de_fuente
Para acceder a la fuente miembro índice_de_fuente (por defecto cero) en los TTC.
-d "eje1 eje2 ..."
Especifica las coordenadas de diseño para cada eje de variación al arrancar.
-v
Muestra la versión.
