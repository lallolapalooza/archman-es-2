ttyname(3) Manual de funciones de biblioteca ttyname(3)

NOMBRE

ttyname, ttyname_r - devolver el nombre de una terminal

BIBLIOTECA

Biblioteca C estándar (libc, -lc)

SINOPSIS

#include <unistd.h>
char *ttyname(int fd);
int ttyname_r(size_t size;
              int fd, char buf[size], size_t size);

DESCRIPCIÓN

La función ttyname() devuelve un puntero al nombre de ruta terminado en nulo del dispositivo de terminal que está abierto en el descriptor de archivo fd, o NULL en caso de error (por ejemplo, si fd no está conectado a una terminal). El valor de retorno puede apuntar a datos estáticos, posiblemente sobrescritos por la próxima llamada. La función ttyname_r() almacena este nombre de ruta en el búfer buf de tamaño size.

VALOR DE RETORNO

La función ttyname() devuelve un puntero a un nombre de ruta en caso de éxito. En caso de error, se devuelve NULL y se establece errno para indicar el error. La función ttyname_r() devuelve 0 en caso de éxito y un número de error en caso de error.

ERRORES

EBADF
Descriptor de archivo incorrecto.
ENODEV
fd se refiere a un dispositivo pseudoterminal esclavo pero no se pudo encontrar el nombre de ruta correspondiente (ver NOTAS).
ERANGE
(ttyname_r()) size era demasiado pequeño para permitir el almacenamiento del nombre de ruta.

ATRIBUTOS

Para una explicación de los términos utilizados en esta sección, consulte attributes(7).

Interfaz Atributo Valor
ttyname () Seguridad de hilos MT-Unsafe race:ttyname
ttyname_r () Seguridad de hilos MT-Safe

ESTÁNDARES

POSIX.1-2008.

HISTORIAL

POSIX.1-2001, 4.2BSD.

NOTAS

Un proceso que mantiene abierto un descriptor de archivo que se refiere a un dispositivo pts(4) al cambiar a otro espacio de nombres de montaje que utiliza una instancia diferente de /dev/ptmx puede seguir encontrando accidentalmente que existe una ruta de dispositivo con el mismo nombre para ese descriptor de archivo. Sin embargo, esta ruta de dispositivo se refiere a un dispositivo diferente y, por lo tanto, no se puede utilizar para acceder al dispositivo al que se refiere el descriptor de archivo. La llamada a ttyname() o ttyname_r() en el descriptor de archivo en el nuevo espacio de nombres de montaje hará que estas funciones devuelvan NULL y establezcan errno en ENODEV.

VER TAMBIÉN

tty(1), fstat(2), ctermid(3), isatty(3), pts(4)
