ttyS(4) Manual de Controladores de Dispositivos ttyS(4)

NOMBRE

ttyS - líneas de terminal serie

DESCRIPCIÓN

ttyS[0-3] son dispositivos de caracteres para las líneas de terminal serie.

Normalmente se crean mediante:


mknod -m 660 /dev/ttyS0 c 4 64 # dirección base 0x3f8
mknod -m 660 /dev/ttyS1 c 4 65 # dirección base 0x2f8
mknod -m 660 /dev/ttyS2 c 4 66 # dirección base 0x3e8
mknod -m 660 /dev/ttyS3 c 4 67 # dirección base 0x2e8
chown root:tty /dev/ttyS[0-3]

ARCHIVOS

/dev/ttyS[0-3]

VER TAMBIÉN

chown(1), mknod(1), tty(4), agetty(8), mingetty(8), setserial(8)
