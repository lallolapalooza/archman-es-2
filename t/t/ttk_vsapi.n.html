ttk_vsapi(n) Widget temático de Tk ttk_vsapi(n)

NOMBRE

ttk_vsapi - Definir un elemento de estilos visuales de Microsoft

SINOPSIS

ttk::style element create nombre vsapi nombreClase idParte ?mapaEstados? ?opciones?

DESCRIPCIÓN

El factor de elemento vsapi crea un nuevo elemento en el tema actual cuya apariencia visual se dibuja utilizando la API de Estilos Visuales de Microsoft, que es responsable de los estilos temáticos en Windows XP y Vista. Este factor permite declarar cualquier parte de los Estilos Visuales como elementos Ttk que luego pueden incluirse en un diseño de estilo para modificar la apariencia de los widgets Ttk.

nombreClase y idParte son parámetros requeridos y especifican la clase y la parte de los Estilos Visuales según se indica en la documentación de Microsoft. Se puede proporcionar mapaEstados para mapear los estados Ttk a los estados de la API de Estilos Visuales (ver MAPA DE ESTADOS).

OPCIONES

Las opciones válidas son:

-relleno relleno
Especifica el relleno interior del elemento. relleno es una lista de hasta cuatro enteros que especifican las cantidades de relleno izquierdo, superior, derecho e inferior respectivamente. Si se especifican menos de cuatro elementos, inferior toma el valor de superior, derecho toma el valor de izquierdo, y superior toma el valor de izquierdo. En otras palabras, una lista de tres números especifica el relleno izquierdo, vertical y derecho; una lista de dos números especifica el relleno horizontal y vertical; un solo número especifica el mismo relleno alrededor del widget. Esta opción no se puede combinar con ninguna otra opción.
-márgenes relleno
Especifica el relleno exterior de los elementos. relleno es una lista de hasta cuatro enteros que especifican las cantidades de relleno izquierdo, superior, derecho e inferior respectivamente. Esta opción no se puede combinar con ninguna otra opción.
-ancho ancho
Especifica la altura para el elemento. Si esta opción está establecida, la API de Estilos Visuales no será consultada para obtener el tamaño o la parte recomendada. Si esta opción está establecida, también se debe establecer -alto. Las opciones -ancho y -alto no se pueden mezclar con las opciones -relleno o -márgenes.
-alto alto
Especifica la altura del elemento. Ver los comentarios para -ancho.

MAPA DE ESTADOS

El parámetro mapaEstados es una lista de estados ttk y el valor de estado correspondiente de la API de Estilos Visuales. Esto permite que la apariencia del elemento responda a los cambios en el estado del widget, como volverse activo o ser presionado. La lista debe ser como se describe para el comando ttk::style map, pero tenga en cuenta que el último par de la lista debe ser el estado predeterminado y típicamente es una lista vacía y 1. Desafortunadamente, todas las partes de los Estilos Visuales tienen diferentes valores de estado y estos deben buscarse en la documentación de Microsoft o, lo que es más probable, en los archivos de encabezado. El encabezado original a usar era tmschema.h, pero en versiones más recientes del Kit de Desarrollo de Windows es vssym32.h.

Si no se proporciona el parámetro mapaEstados, hay un mapa predeterminado implícito de {{} 1}

EJEMPLO

Crear un botón de cierre correctamente temático cambiando el diseño de un ttk::button(n). Esto utiliza la parte WINDOW WP_SMALLCLOSEBUTTON y, como se documenta, los estados CBS_DISABLED, CBS_HOT, CBS_NORMAL y CBS_PUSHED se mapean desde los estados ttk.

ttk::style element create smallclose vsapi WINDOW 19 \
    {disabled 4 pressed 3 active 2 {} 1}
ttk::style layout CloseButton {CloseButton.smallclose -sticky news}
pack [ttk::button .close -style CloseButton]

Cambiar la apariencia de un ttk::checkbutton(n) para usar la parte de pin de Explorer EBP_HEADERPIN.

ttk::style element create pin vsapi EXPLORERBAR 3 {
    {pressed !selected} 3
    {active !selected} 2
    {pressed selected} 6
    {active selected} 5
    {selected} 4
    {} 1
}
ttk::style layout Explorer.Pin {Explorer.Pin.pin -sticky news}
pack [ttk::checkbutton .pin -style Explorer.Pin]
