ttk::entry(n) Tk Themed Widget ttk::entry(n)

NOMBRE

ttk::entry - Widget de campo de texto editable

SINOPSIS

ttk::entry nombreRuta ?opciones?

DESCRIPCIÓN

Un widget ttk::entry muestra una cadena de texto de una sola línea y permite al usuario editar esa cadena. El valor de la cadena puede enlazarse a una variable Tcl con la opción -textvariable. Los widgets Entry soportan desplazamiento horizontal con la opción estándar -xscrollcommand y el comando de widget xview.

OPCIONES ESTÁNDAR

-class	-cursor
-font	-foreground
-style
-takefocus	-xscrollcommand

Consulte la entrada del manual de ttk::widget para obtener detalles sobre las opciones estándar.

OPCIONES ESPECÍFICAS DEL WIDGET

Nombre de línea de comandos:	-exportselection
Nombre de base de datos:	exportSelection
Clase de base de datos:	ExportSelection
Un valor booleano que especifica si una selección en el widget debe ser enlazada a la selección X. Si la selección se exporta, entonces seleccionar en el widget deselecciona la selección X actual, seleccionar fuera del widget deselecciona cualquier selección del widget, y el widget responderá a las solicitudes de recuperación de selección cuando tenga una selección.
Nombre de línea de comandos:	-invalidcommand
Nombre de base de datos:	invalidCommand
Clase de base de datos:	InvalidCommand
Una plantilla de script para evaluar siempre que -validatecommand retorne 0. Consulte VALIDACIÓN a continuación para obtener más información.
Nombre de línea de comandos:	-justify
Nombre de base de datos:	justify
Clase de base de datos:	Justify
Especifica cómo se alinea el texto dentro del widget entry. Una de las opciones: left, center o right.
Nombre de línea de comandos:	-show
Nombre de base de datos:	show
Clase de base de datos:	Show
Si se especifica esta opción, el contenido real de la entrada no se muestra en la ventana. En su lugar, cada carácter del valor de la entrada se mostrará como el primer carácter del valor de esta opción, como “*” o un punto. Esto es útil, por ejemplo, si la entrada se va a utilizar para introducir una contraseña. Si los caracteres de la entrada se seleccionan y copian en otro lugar, la información copiada será lo que se muestra, no el contenido real de la entrada.
Nombre de línea de comandos:	-state
Nombre de base de datos:	state
Clase de base de datos:	State
Opción de compatibilidad; consulte la entrada del manual de ttk::widget(n) para obtener detalles. Especifica uno de los tres estados para la entrada: normal, disabled o readonly. Consulte ESTADOS DEL WIDGET, a continuación.
Nombre de línea de comandos:	-textvariable
Nombre de base de datos:	textVariable
Clase de base de datos:	Variable
Especifica el nombre de una variable global cuyo valor está enlazado al contenido del widget de entrada. Cada vez que la variable cambia de valor, el contenido del widget se actualiza, y viceversa.
Nombre de línea de comandos:	-validate
Nombre de base de datos:	validate
Clase de base de datos:	Validate
Especifica el modo en el que debe operar la validación: none, focus, focusin, focusout, key o all. El valor predeterminado es none, lo que significa que la validación está deshabilitada. Consulte VALIDACIÓN a continuación.
Nombre de línea de comandos:	-validatecommand
Nombre de base de datos:	validateCommand
Clase de base de datos:	ValidateCommand
Una plantilla de script para evaluar cada vez que la validación se active. Si se establece como una cadena vacía (el valor predeterminado), la validación está deshabilitada. El script debe retornar un valor booleano. Consulte VALIDACIÓN a continuación.
Nombre de línea de comandos:	-width
Nombre de base de datos:	width
Clase de base de datos:	Width
Especifica un valor entero que indica el ancho deseado de la ventana de entrada, en caracteres de tamaño promedio de la fuente del widget.

NOTAS

Una porción de la entrada puede seleccionarse como se describe a continuación. Si una entrada está exportando su selección (consulte la opción -exportselection), entonces observará los protocolos X11 estándar para manejar la selección; las selecciones de entrada están disponibles como tipo STRING. Las entradas también observan las reglas estándar de Tk para tratar con el foco de entrada. Cuando una entrada tiene el foco de entrada, muestra un cursor de inserción para indicar dónde se insertarán los nuevos caracteres.

Las entradas son capaces de mostrar cadenas que son demasiado largas para caber completamente dentro de la ventana del widget. En este caso, solo se mostrará una porción de la cadena; los comandos descritos a continuación pueden usarse para cambiar la vista en la ventana. Las entradas utilizan el mecanismo estándar -xscrollcommand para interactuar con las barras de desplazamiento (consulte la descripción de la opción -xscrollcommand para obtener detalles).

ÍNDICES

Muchos de los comandos del widget entry toman uno o más índices como argumentos. Un índice especifica un carácter particular en la cadena de la entrada, de cualquiera de las siguientes maneras:

número
Especifica el carácter como un índice numérico, donde 0 corresponde al primer carácter de la cadena.
@número
En esta forma, número se trata como una coordenada x en la ventana de la entrada; se utiliza el carácter que abarca esa coordenada x. Por ejemplo, “@0” indica el carácter más a la izquierda en la ventana.
end
Indica el carácter justo después del último en la cadena de la entrada. Esto es equivalente a especificar un índice numérico igual a la longitud de la cadena de la entrada.
insert
Indica el carácter adyacente e inmediatamente posterior al cursor de inserción.
sel.first
Indica el primer carácter de la selección. Es un error usar esta forma si la selección no está en la ventana de la entrada.
sel.last
Indica el carácter justo después del último de la selección. Es un error usar esta forma si la selección no está en la ventana de la entrada.

Se pueden usar abreviaturas para cualquiera de las formas anteriores, por ejemplo “e” o “sel.l”. En general, los índices fuera de rango se redondean automáticamente al valor legal más cercano.

COMANDO DEL WIDGET

Los siguientes subcomandos son posibles para los widgets entry:

nombreRuta bbox indice
Devuelve una lista de cuatro números que describen el cuadro delimitador del carácter dado por indice. Los dos primeros elementos de la lista dan las coordenadas x e y de la esquina superior izquierda del área de la pantalla cubierta por el carácter (en píxeles relativos al widget) y los dos últimos elementos dan el ancho y la altura del carácter, en píxeles. El cuadro delimitador puede referirse a una región fuera del área visible de la ventana.
nombreRuta delete primero ?ultimo?
Elimina uno o más elementos de la entrada. Primero es el índice del primer carácter a eliminar, y último es el índice del carácter justo después del último a eliminar. Si último no se especifica, se predetermina a primero+1, es decir, se elimina un solo carácter. Este comando devuelve la cadena vacía.
nombreRuta get
Devuelve la cadena de la entrada.
nombreRuta icursor indice
Organiza la visualización del cursor de inserción justo antes del carácter dado por indice. Devuelve la cadena vacía.
nombreRuta index indice
Devuelve el índice numérico correspondiente a indice.
nombreRuta insert indice ?string?
Inserta string en la posición especificada por indice. Si string no se especifica, se inserta una cadena vacía (lo que solo mueve el cursor). Este comando devuelve la cadena vacía.
nombreRuta scan cmd ?arg ...?
Similar al comando scan de otros widgets Tk, se usa para asociar la información de escaneo de eventos de ratón a una ubicación dentro del widget.
nombreRuta selection cmd ?arg ...?
Gestiona la selección dentro del widget. Consulte la página del manual de Tk widgets para obtener más información.
nombreRuta xview ?args?
Este comando se utiliza para anclar la vista horizontal del texto dentro del widget. Consulte la sección sobre Gestión del desplazamiento en la página del manual de Tk widgets para obtener más detalles.

VALIDACIÓN

La validación de la entrada se puede habilitar con las opciones -validate y -validatecommand. Los modos de validación son: none, focus, focusin, focusout, key y all.

Cuando se activa la validación, el script especificado en -validatecommand se evalúa. La cadena %P se reemplaza por el valor que tendría el campo si el cambio fuera permitido. La cadena %S se reemplaza por la cadena que se está insertando o eliminando. La cadena %V se reemplaza por el modo de validación que se está ejecutando (por ejemplo, key, focusout). La cadena %W se reemplaza por el nombre del widget.

Si el script de validación se evalúa a falso, se evalúa el script de -invalidcommand. Si el cambio de valor todavía resulta en un valor inválido, el widget permanecerá en su estado anterior.

La validación key se produce cada vez que el contenido del widget está a punto de cambiar debido a una pulsación de tecla.

La validación focus se produce cuando el widget gana o pierde el foco, o cuando su contenido cambia.

La validación focusin se produce cuando el widget gana el foco.

La validación focusout se produce cuando el widget pierde el foco.

La validación all se produce en todos los casos anteriores en los que se realiza la validación.

ESTADOS DEL WIDGET

Los widgets Entry admiten los siguientes estados:

normal
El widget está activo y responderá a las interacciones del usuario.
disabled
El widget está deshabilitado y no responderá a las interacciones del usuario. Su apariencia visual puede cambiar para indicar que está deshabilitado.
readonly
El contenido del widget no puede ser modificado por el usuario, pero el widget sigue siendo interactivo. Esto significa que el contenido se puede seleccionar y copiar, y el widget todavía puede responder a los eventos del ratón.

EJEMPLO

# Crear un widget de entrada simple
set my_entry [ttk::entry .e -textvariable myvar]
pack $my_entry

# Establecer el contenido inicial de la entrada
set myvar "Hello, World!"

VALIDACIÓN

Las opciones -validate, -validatecommand y -invalidcommand se utilizan para habilitar la validación del widget de entrada.

MODOS DE VALIDACIÓN

Hay dos modos principales de validación: prevalidación, en la que se evalúa -validatecommand antes de cada edición y el valor de retorno se utiliza para determinar si aceptar o rechazar el cambio; y revalidación, en la que se evalúa -validatecommand para determinar si el valor actual es válido.

La opción -validate determina cuándo ocurre la validación; puede establecerse en cualquiera de los siguientes valores:

none
Predeterminado. Esto significa que la validación solo ocurrirá cuando se solicite específicamente mediante el comando de widget validate.
key
La entrada se prevalidará antes de cada edición (específicamente, siempre que se llamen los comandos de widget insert o delete). Si la prevalidación falla, la edición se rechaza.
focus
La entrada se revalidará cuando reciba o pierda el foco.
focusin
La entrada se revalidará cuando reciba el foco.
focusout
La entrada se revalidará cuando pierda el foco.
all
La validación se realiza para todas las condiciones anteriores.

El -invalidcommand se evaluará cada vez que -validatecommand devuelva un valor falso.

El -validatecommand y el -invalidcommand pueden modificar el valor del widget de entrada a través de los comandos de widget insert o delete, o estableciendo el -textvariable vinculado. Si alguno de ellos lo hace durante la prevalidación, la edición se rechaza independientemente del valor devuelto por el -validatecommand.

Si -validatecommand está vacío (predeterminado), la validación siempre tendrá éxito.

SUSTITUCIONES DE SCRIPTS DE VALIDACIÓN

Es posible realizar sustituciones de porcentaje en -validatecommand y -invalidcommand, al igual que en un script bind. Se reconocen las siguientes sustituciones:

%d
Tipo de acción: 1 para prevalidación de insert, 0 para prevalidación de delete, o -1 para revalidación.
%i
Índice del carácter a insertar/eliminar, si existe, de lo contrario -1.
%P
En prevalidación, el nuevo valor de la entrada si se acepta la edición. En revalidación, el valor actual de la entrada.
%s
El valor actual de la entrada antes de la edición.
%S
La cadena de texto que se está insertando/eliminando, si existe, {} en caso contrario.
%v
El valor actual de la opción -validate.
%V
La condición de validación que activó la devolución de llamada (key, focusin, focusout o forced).
%W
El nombre del widget de entrada.

DIFERENCIAS CON LA VALIDACIÓN DEL WIDGET DE ENTRADA DE TK

El widget de entrada estándar de Tk deshabilita automáticamente la validación (estableciendo -validate en none) si -validatecommand o -invalidcommand modifican el valor de la entrada. El widget de entrada temático de Tk solo deshabilita la validación si uno de los scripts de validación genera un error, o si -validatecommand no devuelve un valor booleano válido. (Por lo tanto, no es necesario volver a habilitar la validación después de modificar el valor de la entrada en un script de validación).

Además, el widget de entrada estándar invoca la validación cada vez que se modifica el -textvariable vinculado; el widget de entrada temático de Tk no lo hace.

ENLACES PREDETERMINADOS

Los enlaces predeterminados del widget de entrada habilitan el siguiente comportamiento. En las descripciones siguientes, "palabra" se refiere a un grupo continuo de letras, dígitos o caracteres "_" , o cualquier carácter individual que no sean estos.

 •
Hacer clic con el botón 1 del ratón posiciona el cursor de inserción justo antes del carácter sobre el que se encuentra el cursor del ratón, establece el foco de entrada en este widget y borra cualquier selección en el widget. Arrastrar con el botón 1 del ratón presionado marca una selección entre el cursor de inserción y el carácter sobre el ratón.
 •
Hacer doble clic con el botón 1 del ratón selecciona la palabra sobre la que se encuentra el ratón y posiciona el cursor de inserción al final de la palabra. Arrastrar después de un doble clic marca una selección que consiste en palabras completas.
 •
Hacer triple clic con el botón 1 del ratón selecciona todo el texto de la entrada y posiciona el cursor de inserción al final de la línea.
 •
Los extremos de la selección se pueden ajustar arrastrando con el botón 1 del ratón mientras se mantiene presionada la tecla Mayús. Si se hace doble clic en el botón antes de arrastrar, la selección se ajustará en unidades de palabras completas.
 •
Hacer clic con el botón 1 del ratón con la tecla Control presionada posicionará el cursor de inserción en la entrada sin afectar la selección.
 •
Si se escriben caracteres de impresión normales en una entrada, se insertan en el punto del cursor de inserción.
 •
La vista en la entrada se puede ajustar arrastrando con el botón central del ratón (botón 2, o botón 3 en TkAqua). Si se hace clic con el botón central del ratón sin mover el ratón, la selección se copia en la entrada en la posición del cursor del ratón.
 •
Si el ratón se arrastra fuera de la entrada por los lados izquierdo o derecho mientras se presiona el botón 1, la entrada se desplazará automáticamente para hacer visible más texto (si hay más texto fuera de la pantalla en el lado donde el ratón salió de la ventana).
 •
Las teclas Izquierda y Derecha mueven el cursor de inserción un carácter hacia la izquierda o la derecha; también borran cualquier selección en la entrada. Si se presiona Izquierda o Derecha con la tecla Mayús presionada, el cursor de inserción se mueve y la selección se extiende para incluir el nuevo carácter. Control-Izquierda y Control-Derecha mueven el cursor de inserción por palabras, y Control-Mayús-Izquierda y Control-Mayús-Derecha mueven el cursor de inserción por palabras y también extienden la selección. Control-b y Control-f se comportan igual que Izquierda y Derecha, respectivamente.
 •
Las teclas Inicio y Control-a mueven el cursor de inserción al principio de la entrada y borran cualquier selección en la entrada. Mayús-Inicio mueve el cursor de inserción al principio de la entrada y extiende la selección hasta ese punto.
 •
Las teclas Fin y Control-e mueven el cursor de inserción al final de la entrada y borran cualquier selección en la entrada. Mayús-Fin mueve el cursor al final y extiende la selección hasta ese punto.
 •
Control-/ selecciona todo el texto de la entrada.
 •
Control-\ borra cualquier selección en la entrada.
 •
Los eventos virtuales estándar de Tk <<Cut>>, <<Copy>>, <<Paste>> y <<Clear>> operan sobre la selección de la manera esperada.
 •
La tecla Suprimir elimina la selección, si existe en la entrada. Si no hay selección, elimina el carácter a la derecha del cursor de inserción.
 •
La tecla Retroceso y Control-h eliminan la selección, si existe en la entrada. Si no hay selección, eliminan el carácter a la izquierda del cursor de inserción.
 •
Control-d elimina el carácter a la derecha del cursor de inserción.
 •
Control-k elimina todos los caracteres a la derecha del cursor de inserción.

ESTADOS DEL WIDGET

En el estado disabled, la entrada no se puede editar y el texto no se puede seleccionar. En el estado readonly, no se muestra ningún cursor de inserción y la entrada no se puede editar (específicamente: los comandos insert y delete no tienen efecto). NOTAS

El estado readonly es similar al estado disabled, excepto que el widget sigue siendo seleccionable y copiable.

El texto no se puede seleccionar en el estado disabled.

Tenga en cuenta que los cambios en el -textvariable enlazado todavía se reflejarán en la entrada, incluso si está deshabilitada o es de solo lectura.

Normalmente, el texto se muestra en gris en el estado disabled, y se utiliza un fondo diferente en el estado readonly.

El widget de entrada establece el estado invalid si la revalidación falla, y lo borra cada vez que la validación tiene éxito.
