T1REENCODE(1) Manual de Comandos Generales T1REENCODE(1)

NOMBRE

t1reencode - re-codifica una fuente PostScript Type 1

SINOPSIS

t1reencode -e CODIFICACION [OPCIONES...] fuente [archivo_salida]

DESCRIPCIÓN

T1reencode cambia la codificación embebida de una fuente PostScript Type 1. La fuente re-codificada se escribe en la salida estándar (pero ver la opción --output). Si no se proporciona un archivo de fuente de entrada, t1reencode lee una fuente PFA o PFB de la entrada estándar.

VALORES DE RETORNO

T1reencode sale con valor 0 si se generó una fuente re-codificada con éxito, y 1 en caso contrario.

NOTAS

T1reencode solo debe usarse en situaciones especiales. Generalmente es mucho mejor usar comandos PostScript para re-codificar una fuente; por ejemplo, ejecutar los comandos PostScript para generar dos versiones de una misma fuente con codificaciones diferentes ocupará mucha menos memoria que cargar dos fuentes t1reencoded.

EJEMPLOS

Este comando re-codifica Frutiger Roman en la codificación ISO Latin 1. La nueva fuente tendrá el nombre PostScript Frutiger-RomanISOLatin1Encoding.

    t1reencode -e ISOLatin1Encoding FrutiRom.pfb \
            -o FrutiRomISOL1.pfb

Esta serie de comandos, que utilizan cfftot1(1) y otftotfm(1) así como el propio t1reencode, generan una versión de Warnock Pro Regular con cifras de estilo antiguo en las posiciones de los números (debido a la opción -fonum de otftotfm). La nueva fuente se llamará WarnockPro-RegularOsF.

    otftotfm -fonum WarnockPro-Regular.otf \
            --output-encoding /tmp/osf.enc
    cfftot1 WarnockPro-Regular.otf | t1reencode -e /tmp/osf.enc \
            -n WarnockPro-RegularOsF -N "Warnock Pro Regular OsF" \
            -o WarnoProRegOsF.pfb

t1reencode(1)

NAME

t1reencode - TransType 4 Type 1 font re-encoder

SYNOPSIS

t1reencode [ -a | -b ] [ -c ] [ -d ] [ -e ] [ -f ] [ -h ] [ -i ] [ -l ] [ -o ] [ -p ] [ -q ] [ -r ] [ -s ] [ -t ] [ -u ] [ -v ] [ -w ] [ -x ] [ -z ] [ -number ] [ -- ] [ input.pfb [ output.pfb ] ]

DESCRIPTION

The t1reencode utility is a front-end to the Adobe Type 1 font re-encoding program, that is provided by the t1asm and t1ascii utilities.

This program can be used to convert between ASCII and binary formats of Type 1 fonts and to re-encode the character set of Type 1 fonts.

OPTIONS

All options are passed directly to the t1asm and t1ascii utilities.

Refer to the manual pages of t1asm(1) and t1ascii(1) for a detailed description of the available options.

SEE ALSO

t1ascii(1), t1asm(1)
