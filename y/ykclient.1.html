YKCLIENT(1) Comandos de usuario YKCLIENT(1)

NOMBRE

ykclient - Cliente de validación de contraseñas de un solo uso YubiCloud

SINOPSIS

ykclient [OPCIÓN]... CLIENTID YUBIKEYOTP

DESCRIPCIÓN

Valida la contraseña de un solo uso YUBIKEYOTP contra YubiCloud usando CLIENTID como identificador de cliente.

Los argumentos obligatorios para las opciones largas también son obligatorios para las opciones cortas.

--help
Muestra esta pantalla de ayuda
--version
Muestra información de la versión
--debug
Imprime información de depuración
--url URL
URL del servicio de validación, por ejemplo, "https://api.yubico.com/wsapi/2.0/verify"
--ca CADIR
Ruta al directorio que contiene la Autoridad Certificadora, por ejemplo, "/usr/local/etc/CERTS"
--cai CAFILE
Ruta a un archivo que contiene uno o más certificados para verificar al par con
--apikey Key
Clave API para la validación HMAC de la solicitud/respuesta
--proxy ip:puerto
Conéctese al servicio de validación a través de un proxy, por ejemplo, "socks5h://usuario:contraseña@127.0.0.1:1080"

El código de salida es 0 en caso de éxito, 1 si hay un error grave, 2 si se reprodujo el OTP, 3 para otros errores leves relacionados con el OTP.

REPORTE DE ERRORES

Reporte errores en https://github.com/Yubico/yubico-c-client.
