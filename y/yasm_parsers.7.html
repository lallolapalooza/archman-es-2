YASM_PARSERS(7) Analizadores soportados por Yasm YASM_PARSERS(7)

NOMBRE

yasm_parsers - Analizadores soportados por Yasm (Sintaxis de ensamblador)

SINOPSIS

yasm -p analizador [-r preproc] ...

DESCRIPCIÓN

La distribución estándar de Yasm incluye un número de módulos para diferentes analizadores (sintaxis de ensamblador).

El analizador se selecciona en la línea de comandos de yasm(1) mediante el uso de la opción de línea de comandos -p analizador.

ANALIZADOR NASM

La sintaxis NASM, seleccionada con -p nasm, es la sintaxis con más características soportada por Yasm. Yasm es casi 100% compatible con NASM para código x86 de 16 y 32 bits. Yasm además soporta código AMD64 de 64 bits con extensiones de Yasm a la sintaxis NASM; véase yasm_arch(7) para más detalles. La sintaxis NASM es la predeterminada de Yasm.

ANALIZADOR GAS

El Ensamblador GNU (GAS) es el ensamblador multiplataforma de facto para sistemas Unix modernos, y se utiliza como backend para el compilador GCC. El soporte de Yasm para la sintaxis GAS es moderadamente bueno, aunque inmaduro: no todas las directivas son soportadas, y solo se soportan las arquitecturas x86 de 32 bits y AMD64. Casi todo el preprocesador de GAS también está soportado. El soporte de sintaxis GAS de Yasm es lo suficientemente bueno para manejar esencialmente toda la salida del compilador GCC para x86 y AMD64. El analizador GAS se puede seleccionar con -p gas.

VER TAMBIÉN

yasm(1), yasm_arch(7)
