YTFZF(1) Manual de Comandos Generales YTFZF(1)

NOMBRE

ytfzf - buscar y reproducir videos

SINOPSIS

ytfzf [opciones] [consulta-de-búsqueda]
ytfzf [opciones] -

DESCRIPCIÓN

ytfzf es un script POSIX que te ayuda a encontrar videos de Youtube, Peertube u Odysee (sin API) y los abre/descarga usando mpv/youtube-dl.

OPERADORES DE BÚSQUEDA

Los operadores de búsqueda son consultas de búsqueda especiales.

Los operadores de búsqueda estándar incluyen:

:ayuda
Imprime una descripción posiblemente breve de cómo usar el scraper.

Los scrapers complementarios pueden tener más o menos operadores de búsqueda

ATAJOS

Estos atajos se aplicarán en cualquier menú que lo soporte.
El único menú que actualmente lo soporta es fzf.
Los atajos que comienzan con alt, saldrán del menú, los atajos que comienzan con ctrl no.
Para cambiar cualquiera de los valores predeterminados, establece la variable correspondiente en tu archivo de configuración.

descargar
alt-d (atajo_descargar)
ver video
alt-v (atajo_video)
solo audio
alt-m (atajo_audio)
desacoplar
alt-e (atajo_desacoplar)
imprimir enlace
alt-l (atajo_imprimir_enlace)
mostrar formatos
alt-f (atajo_mostrar_formatos)
mostrar toda información
alt-i (atajo_informacion)
nueva búsqueda
alt-s (atajo_volver_a_buscar)
raspar siguiente página
ctrl-p (atajo_accion_siguiente_pagina)

OPCIONES

Información

-h, --help
Muestra el texto de ayuda.
--version
Muestra la versión de ytfzf.

Cómo reproducir los videos seleccionados.

-d, --download
Descarga los videos seleccionados. Esto también se puede configurar en el archivo de configuración con is_download.
-m, --audio-only
Reproduce solo audio. Esto también se puede configurar en el archivo de configuración con is_audio_only.
-f, --formats
Muestra los formatos disponibles antes de continuar.
--format-selection=pantalla
El tipo de pantalla de selección de formato a utilizar.
Tipos:
normal
simple
Esto también se puede configurar en el archivo de configuración con format_selection_screen.
--format-sort=orden
El --format-sort a usar en ytdl. Esto también se puede configurar en el archivo de configuración con format_selection_sort.
--video-pref=pref
Establece el formato de video de ytdl a pref. Esto también se puede configurar en el archivo de configuración con video_pref.
--audio-pref=pref
Establece el formato de audio de ytdl a pref. Esto también se puede configurar en el archivo de configuración con audio_pref.
--ytdl-pref=pref
Establece el formato de ytdl a pref. Esto también se puede configurar en el archivo de configuración con ytdl_pref.
--detach
Desacopla el reproductor de video de la terminal. Esto también se puede configurar en el archivo de configuración con is_detach.
-u, --url-handler=handler
La función/programa a usar como manejador de URL. Esto también se puede configurar en el archivo de configuración añadiendo load_url_handler <handler>.
-I opción
En lugar de reproducir los videos seleccionados, obtén información sobre ellos en el formato seleccionado. Las opciones disponibles son:
L|l|enlace
Imprime la URL de los videos seleccionados.
VJ|vj|video-json
Imprime el json de los videos seleccionados.
J|j|json
Imprime el json de todos los videos en los resultados de la búsqueda.
F|f|formato
Imprime el formato de video que se está utilizando.
R|r|raw
Imprime los datos de los videos seleccionados, tal como aparecen en el menú.
-L
Alias de -I L
--info-action=Iaccion
La acción a realizar cuando --info-wait es 1. info_wait_action.
--info-wait=número
Si esperar o no después de imprimir la información solicitada con -I o -L. Esto también se puede configurar en el archivo de configuración con info_wait.
--url-handler-opts=opts
Opciones a pasar al manejador de URL, por defecto pasará opciones extra a mpv. Esto también se puede configurar en el archivo de configuración con url_handler_opts.

Opciones del menú

-l, --loop
Vuelve a abrir el menú cuando el video deja de reproducirse. Esto también se puede configurar en el archivo de configuración con is_loop.
-s, --search-again
Después de cerrar fzf, realiza otra búsqueda. Esto también se puede configurar en el archivo de configuración con search_again.
-t, --show-thumbnails
Muestra miniaturas. No funciona con -D o -H. Esto también se puede configurar en el archivo de configuración con show_thumbnails.
--async-thumbnails
Si descargar miniaturas de forma asíncrona o no.
La descarga asíncrona abrirá el menú antes de que todas las miniaturas se hayan descargado. Esto también se puede configurar en el archivo de configuración con async_thumbnails.
--skip-thumb-download
Si omitir la descarga de miniaturas o no. Esto se usa si quieres no tener miniaturas, o usar miniaturas personalizadas en $YTFZF_CUSTOM_THUMBNAILS_DIR.
Para más información, consulta MINIATURAS PERSONALIZADAS en ytfzf(5)
Esto también se puede configurar en el archivo de configuración con skip_thumb_download.
--notify-playing
Muestra notificaciones cuando un video está a punto de reproducirse y otras notificaciones relacionadas con la reproducción de videos. Esto también se puede configurar en el archivo de configuración con notify_playing.
--preview-side=lado
El lado de vista previa en fzf.
Opciones:
izquierda
derecha
arriba
abajo
/dl>
Esto también se puede cambiar en el archivo de configuración con fzf_preview_side.
-T, --thumb-viewer=programa
Usa el programa para mostrar miniaturas.
Programas integrados:
chafa,chafa-16,chafa-tty
chafa, chafa con 16 colores, chafa con 4 colores.
catimg,catimg-256
catimg, catimg con 256 colores.
imv
Bueno con gestores de ventanas de mosaico.
mpv
Similar a imv.
swayimg
Solo funciona en el compositor sway de wayland.
swayimg-hyprland
Solo funciona en el compositor hyprland. Usa swayimg para renderizar una imagen.
<personalizado>
Se pueden agregar visores adicionales en $YTFZF_THUMBNAIL_VIEWERS_DIR.
Esto también se puede cambiar en el archivo de configuración agregando
load_thumbnail_viewer <visor>.
-D, --external-menu
Usa un menú externo en lugar de fzf. El valor predeterminado es dmenu. Esto también se puede establecer en el archivo de configuración con interface="ext".
-i, --interface=interfaz
Usa un script de interfaz personalizado, que estaría en $YTFZF_CUSTOM_INTERFACES_DIR. Esto también se puede establecer en el archivo de configuración agregando load_interface <interfaz>.
--sort
Ordena los videos (después de raspar) por fecha de subida. Esto también se puede establecer en el archivo de configuración agregando is_sort.
--sort-name=nombre
Llama a una función establecida en $YTFZF_CONFIG_FILE. O carga un script en $YTFZF_SORT_NAMES_DIR (si existe). Consulte SORT NAMES en ytfzf(5) para obtener más información.
--fancy-subs
Si debe haber un separador entre cada suscripción o no. Cuando se usa esta opción, deshabilita automáticamente --sort ya que estropeará esta opción.
Esto también se puede establecer en el archivo de configuración con fancy_subs.
--disable-back
Si se debe deshabilitar el botón de retroceso en los submenús o no.
Esto también se puede establecer en el archivo de configuración con enable_back_button. --disable-actions Si se deben deshabilitar las acciones como submenús y el botón de retroceso o no.
Esto también se puede establecer en el archivo de configuración con enable_actions.
--disable-submenus
Si se deben deshabilitar los submenús o no.
Los submenús son los menús que aparecen después de seleccionar una lista de reproducción o un canal (actualmente solo compatible con youtube/invidious)
Esto también se puede establecer en el archivo de configuración con enable_submenus.
--keep-vars
Si las opciones pasadas a ytfzf también se pasan a los submenús o no. Esto también se puede establecer en el archivo de configuración con keep_vars.
--submenu-opts=opts
Las opciones a utilizar en el submenú.
Esto también se puede establecer en el archivo de configuración con submenu_opts.
--submenu-scraping-opts=opts
OBSOLETO (usa --submenu-opts en su lugar) Hace lo mismo que --submenu-opts.
Esto también se puede establecer en el archivo de configuración con submenu_scraping_opts.

Selección automática

-a, --auto-select
Reproduce automáticamente el primer resultado.
-A, --select-all
Selecciona todos los resultados.
-r, --random-select
Reproduce automáticamente un resultado aleatorio.
-S dirección sed, --select=dirección sed
Reproduce automáticamente un video específico.
Ejemplos:
2
Selecciona el segundo video
$
Selecciona el último video
/^h/
Selecciona todos los videos que comienzan con h
-n número, --link-count=número
El número de videos a seleccionar con -a o -r.

Raspadores

-c raspadores, --scrape=raspadores
Establece qué raspador usar. Se pueden separar múltiples raspadores con coma (,). Los raspadores integrados compatibles actualmente son:
youtube|Y
Rasca la API de invidious con una consulta de búsqueda
youtube-channel
Rasca un canal de youtube con youtube
invidious-channel
Rasca un canal de youtube con $invidious_instance
Cuando este raspado está activo, la consulta de búsqueda es el enlace a un canal.
video-recommended|R
Rasca los videos recomendados de un enlace de video de invidious
youtube-playlist|invidious-playlist
Rasca una lista de reproducción de youtube
Cuando este raspado está activo, la consulta de búsqueda es el enlace a una lista de reproducción.
youtube-trending|T
Rasca la API de invidious para obtener las tendencias de youtube.
Cuando este raspado está activo, la consulta de búsqueda es la pestaña de tendencias a raspar.
from-cache
Rasca un raspado anterior que ocurrió usando --keep-cache de la caché guardada.
M|multi
Usa ytfzf recursivamente para raspar múltiples cosas con múltiples opciones diferentes
Consulta ytfzf -c M :help para más información
Pestañas:
gaming
music
movies
youtube-subscriptions|S|SI
SI Raspa invidious para canales en lugar de youtube. Raspar youtube puede resultar en limitación de velocidad.
scrape-list|SL
usa tu $YTFZF_SCRAPELIST_FILE como entrada de raspado y búsqueda. Consulte "listas de raspado" ytfzf(5) para obtener más información.
peertube|P
odysee|lbry|O
history|H
(Solo si $enable_hist está habilitado)
url|U
Abre la URL en el reproductor de video y sale
u
Trata la URL como un elemento, y abrirá fzf, o el menú externo.
comments
Rasca los comentarios de un enlace de video de youtube
-H, --history
Alias para -c H.
Rasca el archivo de historial.
--scrape+=scrapers
Igual que -c, pero mantiene también el raspado predeterminado.
--scraper-=scrapers
Elimina el raspador de la lista de raspadores a usar
--multi-search
Si se debe usar la búsqueda múltiple o no.
Para usar la búsqueda múltiple, separa cada búsqueda con una coma, esto funciona bien cuando se usan múltiples raspadores.
Esto también se puede establecer en el archivo de configuración con multi_search.
--force-youtube
Al usar el raspador youtube, convierte los enlaces de invidious a enlaces de youtube antes de reproducir/descargar.
--force-invidious
Al usar el raspador youtube, usa la instancia de invidious que se haya elegido en lugar de convertir a enlaces de youtube.

Opciones del Raspador

Actualmente, --video-duration, --type, --thumbnail-quality y --features solo se aplican al raspado: youtube/Y

--pages=amount
Cantidad de páginas a raspar en youtube/invidious y el raspador de comentarios. Esto también se puede establecer en el archivo de configuración con pages_to_scrape.
--pages-start=page
La página de inicio. Esto también se puede establecer en el archivo de configuración con pages_start.
--max-threads=amount
Cantidad de hilos que se pueden usar para raspar búsquedas, listas de reproducción y canales de youtube. (esto no se aplica al raspador de suscripciones).
Esto también se puede establecer en el archivo de configuración con max_thread_count.
--single-threaded
Establece max_thread_count en 1, esto tiene el mismo efecto que hacer todo de un solo hilo. (esto no se aplica al raspador de suscripciones).
Esto también se puede establecer en el archivo de configuración con max_thread_count=1.
--odysee-video-count=amount
Cantidad de videos a raspar en odysee. Esto también se puede establecer en el archivo de configuración con odysee_video_search_count.
--nsfw
Si se deben buscar videos nsfw o no.
Solo funciona con odysee/O Esto también se puede establecer en el archivo de configuración con nsfw.
--sort-by=sort
Funciona con yout ube/Y y odysee/O.
Para usar un ordenamiento diferente para cada scrape, usa coma (,) para separar los ordenamientos.
A diferencia de --sort, esto ocurre durante la búsqueda, no después. Los resultados deberían ordenarse por:
relevancia
calificación (solo youtube)
fecha_de_subida
mas_antiguos_primero (solo odysee)
cantidad_de_vistas (solo youtube)
--fecha-de-subida=marco-temporal
Funciona con youtube/Y y odysee/O
Para usar una fecha diferente para cada scrape, usa coma (,) para separar las fechas.
Buscar videos dentro de:
hora
hoy
semana
mes
año
--duracion-video=duracion
Si buscar videos largos o cortos. Opciones posibles:
corto
largo
--tipo=tipo
El tipo de resultados a obtener.
video
lista_de_reproduccion
canal
todos
--calidad-miniatura=calidad
Selecciona la calidad de las miniaturas. Opciones disponibles:
maxres
maxresdefault
sddefault
alta (predeterminado)
media
predeterminada
inicio
El primer fotograma del video (baja calidad)
medio
El fotograma medio del video (baja calidad)
fin
El fotograma final del video (baja calidad)
--caracteristicas=caracteristicas
Las características que debe tener un video (separadas por comas).
hd
subtitulos
creative_commons
3d
en_vivo
4k
360
ubicacion
hdr
--region
La región (código de país) para buscar.
Soportado por los scrapes youtube/Y y youtube-trending/T

Misceláneos

--ii=instancia,--instancia-invidious=instancia
Usa una instancia de invidious diferente.
--rii,--refrescar-instancia-inv
Si se proporciona esta bandera, se refresca la caché de instancias con instancias saludables usando la API de Invidious.
--instancias-inv-disponibles
Imprime las instancias de invidious que pueden ser usadas y sale.
--enlace-canal=enlace
Convierte enlaces de canal de 'https://youtube.com/c/nombre' a 'https://youtube.com/channel/id'
-q
Usa el historial de búsqueda en lugar de una búsqueda. Esto también puede ser configurado en el archivo de configuración con fuente_busqueda=hist.
--fuente-busqueda
La fuente a usar para la consulta de búsqueda. Los valores válidos incluyen:
args
Usa los argumentos de la línea de comandos como búsqueda (predeterminado)
prompt
Pregunta por una búsqueda a través de un prompt
hist
Usa el historial de búsqueda.
next
Se usa internamente para usar la siguiente búsqueda en la lista cuando multi_busqueda está habilitado.
fn-args
Se usa internamente para usar los argumentos de la función pasados a la función como la fuente.
<custom>
Puede usarse una fuente de búsqueda personalizada si existe una función llamada get_search_from_<source>. La función debe establecer la variable _search a una búsqueda.
-x, --limpiar-historial=<busqueda|ver>
Limpia el historial de búsqueda y de visualización (si se usa -x o --limpiar-historial)
Para especificar solo el historial de búsqueda o de visualización usa --limpiar-historial=<busqueda|ver>
--mantener-cache
Si se debe mantener la caché después de que ytfzf salga. Esto también puede ser configurado en el archivo de configuración con mantener_cache.
--opciones-ytdl=opcion
Pasa opciones de línea de comandos a youtube-dl al descargar. 
ejemplo: --opciones-ytdl=
--ruta-ytdl=ruta
Especifica la ruta a youtube-dl o a una bifurcación de youtube-dl para descargar.
Esto también puede ser configurado en el archivo de configuración con ruta_ytdl.
-e, --ext=extension
Carga una extensión.
También puedes agregar cargar_extension extension a tu archivo de configuración.
--listar-addons
Lista todos los addons y sale.
--log-miniaturas
Establece el archivo donde se registrarán las informaciones de depuración de miniaturas. Esto también puede ser configurado en el archivo de configuración con log_debug_miniaturas.

El comportamiento predeterminado de ytfzf puede ser cambiado modificando el archivo de configuración. Ver ytfzf(5) para más información.

ADDONS

Hay algunos tipos de addons,
interfaces (-i, --interface)
scrapers (-c, --scrape)
sort-names (--sort-name)
thumbnail-viewers (-T, --thumb-viewer)
url-handlers (-u, --url_handler)
extensions (-e, --ext)

Para instalar un addon, coloca el addon en $YTFZF_SYSTEM_ADDON_DIR/<tipo-addon>/nombre-addon

Para usar un addon, usa una de las opciones listadas arriba, o agrega
cargar_interfaz <interfaz>
scrape=<scraper>
cargar_sort_name <sort-name>
cargar_thumbnail_viewer <viewer>
cargar_url_handler <url-handler>
cargar_extension <ext>

ENTORNO

$YTFZF_CONFIG_DIR
El directorio para almacenar los archivos de configuración. El valor predeterminado es $XDG_CONFIG_HOME/ytfzf (o ~/.config/ytfzf)
$YTFZF_CONFIG_FILE
El archivo de configuración a usar. El valor predeterminado es $YTFZF_CONFIG_DIR/conf.sh
$YTFZF_SUBSCRIPTIONS_FILE
El archivo de suscripciones a usar. El valor predeterminado es $YTFZF_CONFIG_DIR/subscriptions
$YTFZF_SCRAPELIST_FILE
El archivo de lista de scrapes a usar. El valor predeterminado es $YTFZF_CONFIG_DIR/scrapelist
$YTFZF_THUMBNAIL_VIEWERS_DIR
El directorio para mantener visores de miniaturas adicionales. El valor predeterminado es $YTFZF_CONFIG_DIR/thumbnail-viewers
$YTFZF_CUSTOM_SCRAPERS_DIR
El directorio para almacenar scripts de scrapers personalizados. El valor predeterminado es $YTFZF_CONFIG_DIR/scrapers
$YTFZF_CUSTOM_INTERFACES_DIR
El directorio para almacenar scripts de interfaces personalizadas. El valor predeterminado es $YTFZF_CONFIG_DIR/interfaces
$YTFZF_SORT_NAMES_DIR
El directorio para almacenar scripts de nombres de ordenamiento personalizados. El valor predeterminado es $YTFZF_CONFIG_DIR/sort-names
$YTFZF_URL_HANDLERS_DIR
El directorio para almacenar manejadores de URL personalizados. El valor predeterminado es $YTFZF_CONFIG_DIR/url-handlers
$YTFZF_CUSTOM_THUMBNAILS_DIR
El directorio para almacenar miniaturas personalizadas. El valor predeterminado es $YTFZF_CONFIG_DIR/thumbnails
$YTFZF_EXTENSIONS_DIR
El directorio para almacenar extensiones. El valor predeterminado es $YTFZF_CONFIG_DIR/extensions
$YTFZF_SYSTEM_ADDON_

ENVIRONMENT

The following environment variables can be set:

$YTFZF_ADDONS_DIR
El directorio donde se instalarán los complementos del sistema. El valor predeterminado puede variar dependiendo de cómo hayas instalado ytfzf.
$YTFZF_CHECK_VARS_EXISTS
Si se comprueba si las variables están establecidas en el entorno antes de establecer valores predeterminados. El valor predeterminado es 1
$YTFZF_TEMP_DIR
El directorio temporal. El valor predeterminado es $TMPDIR/ytfzf-$user-id.
Si $TMPDIR no está definido, usará /tmp

FILES

~/.config/ytfzf/conf.sh
El archivo de configuración. Si submenu-conf.sh no existe, este también se utilizará como la configuración en los submenús
~/.config/ytfzf/submenu-conf.sh
El archivo de configuración de submenús
~/.config/ytfzf/subscriptions
El archivo de suscripciones.

CACHE

Cada instancia de ytfzf tiene su propio directorio en $YTFZF_TEMP_DIR, si $keep_cache está habilitado, usa $cache_dir en su lugar.
La estructura de cada carpeta de instancia se ve así: (<> representa un marcador de posición, ? significa opcional)
Si se utiliza un rastreador de complementos, puede utilizar archivos no documentados.

$cache_dir
| -- watch_hist
| -- <search>-<pid>
|  | -- created-at
|  | -- searches.list
|  | -- post-scrape
|  | -- <submenu-search>-<submenu-pid>?
|  | -- thumbnails?
|  | -- environment
|  | -- tmp
|  |  | -- curl_config
|  |  | -- <scrape>.html
|  |  | -- <scrape>.json
|  |  | -- <scrape>.json.final?
|  |  | -- menu_keypress
|  |  | -- all-ids.list
|  |  | -- downloaded-ids.list
|  | -- ids
|  | -- videos_json

Una explicación de cada directorio/archivo:

created-at
Contiene la marca de tiempo unix cuando se creó la carpeta
searches.list
Una lista de todas las búsquedas
Si --multi-search está habilitado, cada búsqueda está separada por una nueva línea
watch_hist
El archivo de historial de visualización.
<search>-<pid>
La carpeta principal de una instancia.
Si no se proporcionó ninguna búsqueda, utiliza el nombre "SCRAPE-<scrape>-<pid>" en su lugar.
post-scrape
Una carpeta que contiene archivos relacionados con el rastreo de un resultado seleccionado.
<submenu-search>-<submenu-pid>
Creado cuando se abre un submenú (por ejemplo, cuando se selecciona un canal/lista de reproducción).
thumbnails
Almacena las miniaturas de la instancia (solo con -t).
environment
Todas las variables que se establecen y su valor, en esa instancia de ytfzf
tmp
Almacena archivos temporalmente utilizados de menor importancia.
curl_config
El archivo de configuración para curl para descargar miniaturas (solo con -t).
<scrape>.html
Para los rastreadores que necesitan rastrear sitios web, esta es la salida de curl.
<scrape>.json
El json rastreado de un sitio web.
<scrape>.json.final
El json final rastreado de un sitio web. (Se utiliza cuando se utilizan varios hilos para el rastreo)
menu_keypress
La tecla presionada en fzf.
all-ids.json
Archivo que contiene todos los ids rastreados. Principalmente para comparar con downloaded-ids.json
downloaded-ids.json
Archivo que contiene qué miniaturas se han descargado
ids
El archivo que almacena el id de cada video seleccionado.
videos_json
El archivo que almacena un json de todos los videos mostrados en fzf.
Este archivo es muy útil para crear listas de reproducción, ya que tiene el mismo formato.
