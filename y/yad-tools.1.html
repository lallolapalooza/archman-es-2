YAD-TOOLS(1) Comandos de usuario YAD-TOOLS(1)

NOMBRE

yad-tools - muestra algunas cosas varias.

SINOPSIS

yad-tools [OPCIONES] CADENA

DESCRIPCIÓN

yad-tools es una pequeña utilidad de línea de comandos para obtener información que puede ser útil en scripts.

OPCIONES

Opciones generales

-f, --pfd
Este modo está destinado a transformar nombres de fuentes de pango a la especificación xft y viceversa. El argumento adicional es el nombre de la fuente.
-i, --icon
Este modo está destinado a obtener la ruta completa a un archivo de icono a partir de su nombre. El argumento adicional es el nombre del icono.
-c, --color
Este modo está destinado a trabajar con colores.
--show-langs
Muestra la lista de idiomas disponibles para la corrección ortográfica. Solo funciona si yad se compiló con soporte para GSpell.
--show-themes
Muestra la lista de temas disponibles de GtkSourceView. Solo funciona si yad se compiló con soporte para GtkSourceView.

Opciones del modo PFD

-x, --xft
Imprime el nombre de la fuente en formato xft. Este es el valor por defecto.
-p, --pango
Imprime el nombre de la fuente en formato pango.

Opciones del modo icono

-s, --size=TAMAÑO
Utiliza el tamaño de icono especificado. El valor predeterminado es 24.
-t, --type=TIPO
Obtiene el tamaño del icono de uno de los tipos predefinidos de GTK+. TIPO es uno de los siguientes: menu, button, small_toolbar, large_toolbar, dnd o dialog,
-m, --mime
Obtiene el nombre genérico del icono para el tipo mime especificado.
--theme=TEMA
Utiliza el tema de iconos especificado en lugar del predeterminado.

Opciones del modo color

--pick
Selecciona un color de la pantalla.
