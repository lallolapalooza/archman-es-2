NOMBRE

yaz-record-conv - Utilidad de Conversión de Registros YAZ

SINOPSIS

yaz-record-conv [-v nivel_log] [config] [archivo...]

DESCRIPCIÓN

yaz-record-conv es un programa que ejercita el subsistema de conversión de registros. Consulte el archivo de cabecera record_conv.h.

OPCIONES

-v nivel

Establece el nivel de LOG a nivel. El nivel es una secuencia de tokens separados por comas. Cada token es un entero o un elemento LOG nombrado — uno de fatal, debug, warn, log, malloc, all, none.

EJEMPLOS

La siguiente configuración de backend convierte registros MARC (ISO2709) a XML Dublin-Core.

    <backend name="F" syntax="usmarc">
      <marc inputcharset="marc-8" inputformat="marc" outputformat="marcxml"/>
      <xslt stylesheet="../etc/MARC21slim2DC.xsl"/>
    </backend>

Podemos convertir uno de los registros de ejemplo del directorio de pruebas de YAZ con:

$ ../util/yaz-record-conv record-conv-conf.xml marc6.marc
<?xml version="1.0"?>
<dc:dc xmlns:dc="http://purl.org/dc/elements/1.1/">
  <dc:title>How to program a computer</dc:title>
  <dc:creator>
    Jack Collins
  </dc:creator>
  <dc:type>text</dc:type>
  <dc:publisher>Penguin</dc:publisher>
  <dc:language>eng</dc:language>
</dc:dc>
