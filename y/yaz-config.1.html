NOMBRE

yaz-config - Script para obtener información sobre YAZ.

SINOPSIS

yaz-config [--prefix[=DIR]] [--version] [--libs] [--lalibs] [--cflags] [--include] [--comp] [-V] [bibliotecas...]

DESCRIPCIÓN

yaz-config es un script que devuelve información que tu propio software debe utilizar para construir software que utilice YAZ.

Las siguientes bibliotecas son compatibles:

threads

Utiliza la versión con hilos de YAZ.

OPCIONES

--prefix[=DIR]

Devuelve el prefijo de YAZ o asume uno diferente si se especifica DIR.

--version

Devuelve la versión de YAZ.

--libs

Especificación de bibliotecas que se utilizarán al usar YAZ.

--lalibs

Devuelve la especificación de bibliotecas.

--cflags

Devuelve los flags del compilador C.

--include

Devuelve las inclusiones del compilador C para los archivos de cabecera de YAZ (-Ipath).

--comp

Devuelve la ruta completa al compilador ASN.1 de YAZ: yaz-asncomp.

-V

Devuelve el ID SHA1 de YAZ (desde Git) y la versión.

ARCHIVOS

/usr/bin/yaz-config

/usr/lib/libyaz*.a

/usr/include/yaz/*.h

VER TAMBIÉN
