NOMBRE

yaz-json-parse - Analizador JSON de YAZ

SINOPSIS

yaz-json-parse [-p]

DESCRIPCIÓN

yaz-json-parse es una utilidad que demuestra la API JSON de YAZ (yaz/json.h).

El programa intenta analizar un JSON de la entrada estándar (stdin). Devolverá el código de salida 1 si el análisis falla y el mensaje de error del análisis se imprimirá en la salida estándar de error (stderr). El programa devuelve el código de salida 0 si el análisis tiene éxito y no devuelve ninguna salida a menos que se proporcione -p (ver abajo).

OPCIONES

-p

Hace que el analizador JSON imprima el resultado JSON en la salida estándar, si el análisis desde stdin tuvo éxito. Si se proporciona -p dos veces, la salida será una salida multilínea con sangría (impresión bonita).
