YRD(1) Comandos de usuario YRD(1)

NOMBRE

yrd - navaja suiza de cjdns

SINOPSIS

yrd [--ayuda] <comando> [<argumentos>]

DESCRIPCIÓN

yrd es una interfaz inspirada en iproute2 para cjdroute.

OPCIONES

--ayuda

Muestra la ayuda de yrd

COMANDOS

iniciar
Inicia cjdroute y lo configura después de que se inicia. Los pares se obtienen de /etc/yrd/peers.d y se envían al cjdroute en ejecución. Usa --adjuntar para configurar un cjdroute ya en ejecución.
dir, dirección
Muestra tu dirección cjdns. Usa -i para formatearla como dirección IPv6.
v, vecinos
Muestra los vecinos con los que estás emparejado directamente. Usa -n para mostrar también sus vecinos. Usa -i para formatearlos como direcciones IPv6.
r, ruta
Muestra las direcciones en tu nodestore. Usa -f para un comportamiento similar a tailf. Usa -i para formatearlas como direcciones IPv6.
ping
Ping a un nodo a través de cjdns, sin usar icmp. Usa --cambiar para hacer un ping de cambio o -c para especificar cuántos pings se enviarán.
top
Muchos colores.
mon
Muestra información de depuración de cjdroute.

-l, --nivel filtra por nivel de registro

-f, --archivo filtra por archivo de origen

-n, --línea filtra por número de línea

uplinks
Muestra los enlaces conocidos desde un nodo dado en la red.
