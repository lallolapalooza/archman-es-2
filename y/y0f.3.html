y0(3) Manual de funciones de biblioteca y0(3)

NOMBRE

y0, y0f, y0l, y1, y1f, y1l, yn, ynf, ynl - funciones de Bessel de segunda especie

BIBLIOTECA

Biblioteca matemática (libm, -lm)

SINOPSIS

#include <math.h>
double y0(double x);
double y1(double x);
double yn(int n, double x);
float y0f(float x);
float y1f(float x);
float ynf(int n, float x);
long double y0l(long double x);
long double y1l(long double x);
long double ynl(int n, long double x);
Requisitos de macros de prueba de características para glibc (ver feature_test_macros(7)):

y0(), y1(), yn():

    _XOPEN_SOURCE
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

y0f(), y0l(), y1f(), y1l(), ynf(), ynl():

    _XOPEN_SOURCE >= 600
        || (_ISOC99_SOURCE && _XOPEN_SOURCE)
        || /* Desde glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPCIÓN

Las funciones y0() y y1() devuelven las funciones de Bessel de x de segunda especie de órdenes 0 y 1, respectivamente. La función yn() devuelve la función de Bessel de x de segunda especie de orden n.

El valor de x debe ser positivo.

Las funciones y0f(), y1f() y ynf() son versiones que toman y devuelven valores float. Las funciones y0l(), y1l() y ynl() son versiones que toman y devuelven valores long double.

VALOR DE RETORNO

En caso de éxito, estas funciones devuelven el valor de Bessel de segunda especie apropiado para x.

Si x es un NaN, se devuelve un NaN.

Si x es negativo, ocurre un error de dominio y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente. (POSIX.1-2001 también permite un retorno NaN para este caso).

Si x es 0.0, ocurre un error de polo y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente.

Si el resultado es un subdesbordamiento, ocurre un error de rango y las funciones devuelven 0.0

Si el resultado es un desbordamiento, ocurre un error de rango y las funciones devuelven -HUGE_VAL, -HUGE_VALF o -HUGE_VALL, respectivamente. (POSIX.1-2001 también permite un retorno 0.0 para este caso).

ERRORES

Ver math_error(7) para obtener información sobre cómo determinar si ha ocurrido un error al llamar a estas funciones.

Los siguientes errores pueden ocurrir:

Error de dominio: x es negativo
errno se establece en EDOM. Se genera una excepción de punto flotante inválida (FE_INVALID).
Error de polo: x es 0.0
errno se establece en ERANGE y se genera una excepción FE_DIVBYZERO (pero ver ERRORES).
Error de rango: subdesbordamiento del resultado
errno se establece en ERANGE. No se devuelve ninguna excepción FE_UNDERFLOW en fetestexcept(3) para este caso.
Error de rango: desbordamiento del resultado
errno se establece en ERANGE (pero ver ERRORES). Se genera una excepción de desbordamiento de punto flotante (FE_OVERFLOW).

ERRORES CONOCIDOS

Antes de glibc 2.19, estas funciones diagnosticaban erróneamente los errores de polo: errno se establecía en EDOM, en lugar de ERANGE y no se generaba ninguna excepción FE_DIVBYZERO.

Antes de glibc 2.17, no se establecía errno para "error de rango: subdesbordamiento del resultado".

En glibc 2.3.2 y anteriores, estas funciones no generan una excepción de punto flotante inválida (FE_INVALID) cuando ocurre un error de dominio.
