NOMBRE

yate-config - recuperar metainformación sobre el motor de telefonía YATE

SINOPSIS

yate-config [opciones]

DESCRIPCIÓN

El programa yate-config se utiliza para recuperar información sobre el motor YATE instalado. Normalmente se usa para compilar y enlazar módulos contra la biblioteca del motor.

Aquí hay un escenario de uso típico en un Makefile:

module.yate: module.cpp
g++ `yate-config --c-all --ldflags` module.cpp `yate-config --libs`

OPCIONES

Versión y rutas

--version
Informa de la versión de YATE instalada (en formato x.y.z)
--release
Informa del estado del código de YATE instalado (si no es versión de producción) y el número de versión
--config
Devuelve el directorio de archivos de configuración
--modules
Devuelve el directorio de módulos
--share
Devuelve el directorio base compartido
--scripts
Devuelve el directorio de scripts
--skins
Devuelve el directorio base de skins

Opciones del compilador

--cflags
Varias opciones del compilador C++
--includes
Opción de inclusión y ruta a los archivos de cabecera
--c-all
Todas las opciones del compilador: las dos anteriores concatenadas

Opciones del enlazador

--ldflags
Varias opciones del enlazador
--libs
Opción de biblioteca y nombres de bibliotecas
--ld-all
Todas las opciones del enlazador: las dos anteriores concatenadas
