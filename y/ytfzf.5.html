YTFZF(5) Manual de formatos de archivo YTFZF(5)

NOMBRE

ytfzf - el archivo de configuración para ytfzf.

SINOPSIS

~/.config/ytfzf/conf.sh

DESCRIPCIÓN

El archivo de configuración es un archivo .sh y puede usarse como tal. El archivo puede estar completamente vacío y ytfzf seguirá funcionando con la configuración predeterminada. Las opciones deben configurarse como variables de entorno y funciones.

ARCHIVOS DE CONFIGURACIÓN

Los archivos de configuración se almacenan en $XDG_CONFIG_HOME/ytfzf (o $HOME/.config/ytfzf).

conf.sh

Un script de shell que se carga en ytfzf cuando se ejecuta ytfzf.

suscripciones

Un archivo que es una lista de enlaces a la página de videos del canal de YouTube, como:

https://www.youtube.com/channel/UCtMVHI3AJD4Qk4hcbZnI9ZQ

Cada enlace debe estar separado por un salto de línea.

Si un canal aparece similar a "https://www.youtube.com/c/SomeOrdinaryGamers", ejecuta
ytfzf --channel-link="https://www.youtube.com/c/SomeOrdinaryGamers"
antes de agregarlo a tu archivo de suscripciones.

Se puede crear un comentario teniendo '#comentario' en su propia línea o después de un enlace. Por ejemplo:

enlace-al-canal
#comentario
enlace-al-canal #mejor canal

scrapers

Una carpeta que contiene archivos ejecutables que extraen información de sitios web. Ver SCRAPERS PERSONALIZADOS para más información.

OPCIONES DE CONFIGURACIÓN

VARIABLES

conf.sh se utiliza principalmente para establecer variables para ytfzf. Si una variable no tiene un valor predeterminado, significa que se establece como una cadena vacía.
Para establecer una variable en conf.sh, asegúrate de usar
nombre_variable="valor"
omitiendo el $ al principio del nombre de la variable.

Archivos y directorios

$cache_dir
El directorio donde almacenar los archivos de caché.
Se recomienda encarecidamente cambiar esto solo si $__is_submenu es 0, o podrían ocurrir cosas extrañas.
predeterminado: $XDG_CACHE_HOME/ytfzf (o $HOME/.cache/ytfzf)
$hist_file
El archivo donde escribir el historial de visualización si $enable_hist es 1.
Se recomienda encarecidamente cambiar esto solo si $__is_submenu es 0, o podrían ocurrir cosas extrañas.
predeterminado: $cache_dir/watch_hist
$search_hist_file
El archivo donde escribir el historial de búsqueda si $enable_search_hist es 1.
predeterminado: $cache_dir/search_hist

Cómo reproducir los videos seleccionados.

$is_detach
Si se debe o no separar el reproductor de video de la terminal.
predeterminado: 0
$is_audio_only
Si se debe o no reproducir solo audio.
predeterminado: 0
$url_handler
La función/programas para manejar los videos seleccionados.
Se recomienda no establecer esta variable directamente, sino usar el comando load_url_handler.
Ver MANEJADORES DE URL para una lista de manejadores de URL incorporados. predeterminado: multimedia_player
$yt_video_link_domain
El dominio desde el cual reproducir videos de YouTube (no se aplica a odysee y peertube ni a listas de reproducción de YouTube).
Si se deja en blanco, el valor será la instancia de invidio que ytfzf haya elegido.
predeterminado: https://www.youtube.com
$info_to_print
La información a imprimir en lugar de reproducir un video. Las opciones disponibles para esta variable son:
L | l | link
Imprime la URL de los videos seleccionados.
VJ | vj | video-json
Imprime el json de los videos seleccionados.
J | j | json
Imprime el json de todos los videos en los resultados de búsqueda.
F | f | format
Imprime el formato de video que se está utilizando.
R | r | raw
Imprime los datos de los videos seleccionados, tal como aparecen en el menú.
$info_wait_action
La acción a realizar cuando $info_wait es 1.
Acciones válidas:
q
salir (volverá al menú, si $is_loop es 1).
Q
salir independientemente de si el bucle está habilitado o no.
m
volver al menú.
predeterminado: q
$info_wait
Si se debe esperar o no la entrada después de imprimir la información.
predeterminado: 0
$video_pref
La preferencia de video a usar para youtube-dl en mpv.
predeterminado: bestvideo
$audio_pref
La preferencia de audio a usar para youtube-dl en mpv.
predeterminado: bestaudio
$ytdl_pref
La preferencia a usar para youtube-dl en mpv.
predeterminado: $video_pref+$audio_pref/best/$video_pref/$audio_pref
$url_handler_opts
Opciones a pasar al manejador de URL, por defecto esto pasará opciones adicionales a mpv. Esto también se puede establecer en el archivo de configuración con url_handler_opts

FUNCIONES

Los archivos de configuración también pueden definir funciones personalizadas que ytfzf puede usar. Estas funciones se definen como cualquier otra función de shell.

my_custom_function() {
  echo "Esta es mi función personalizada."
}

Luego, puedes llamar a esta función desde la línea de comandos de ytfzf, por ejemplo:

ytfzf --script -e 'my_custom_function'

EJEMPLOS

Aquí hay algunos ejemplos de cómo podrías configurar tu archivo conf.sh:

Reproducción de audio solamente

is_audio_only=1
url_handler() {
  mpv --no-video --loop=inf "$1"
}

Usando un manejador de URL personalizado

url_handler() {
  # Abre el enlace en firefox en lugar del reproductor predeterminado
  firefox "$1"
}

Habilitando el historial

enable_hist=1
enable_search_hist=1

Cambiando la instancia de invidio

invidious_instance="https://invidious.fdg.li/"

EXTENSIONES

Las extensiones son esencialmente archivos de configuración adicionales que puedes cargar en tu propio archivo de configuración.

Las extensiones deben estar en $YTFZF_EXTENSIONS_DIR o $YTFZF_SYSTEM_ADDON_DIR/extensions

Una extensión puede hacer cualquier cosa que un archivo de configuración pueda hacer, esto incluye modificar las funciones de utilidad predeterminadas en ytfzf (lo que podría romper el script)

A las extensiones se les dará una variable llamada $__loaded_path que es la ruta completa a la extensión que se está cargando.
Esto es útil cuando se necesita determinar la ruta de ejecución actual para la extensión.

Para cargar una extensión, agrega load_extension nombre-de-la-extensión a $YTFZF_CONFIG_FILE

Hay dos extensiones cargadas automáticamente: __ytfzf__ y __ytfzf_multisearch__
__ytfzf_multisearch__ solo se carga si $multi_search es 1

Funciones para extensiones, donde <ext> se reemplaza con el nombre de la extensión, y todos los - se reemplazan con _.

clean_up()
Esta función elimina todos los subprocesos de ytfzf(1) y elimina $session_cache_dir si $session_cache_dir existe, y si $keep_cache es igual a 0.
Por último, ejecuta el evento on_clean_up. Esta función no toma argumentos.
is_relative_dir()
Comprueba si una cadena es una ruta relativa. Esta función sale con el código de estado 0 si es relativa, y 1 si no lo es. Esta función toma un argumento.
1
La ruta a comprobar
die()
Esta función ejecuta print_error con una cadena y luego sale con un código de estado. Esta función toma dos argumentos.
1
El estado de salida
2
El texto a imprimir con print_error.
trim_url()
Esta función lee líneas de la entrada estándar e imprime la url de ellas en la salida estándar. Las líneas deben tener el siguiente formato: 
texto....|url
Esta función no toma argumentos.
get_search_from_source()
Esta función establece _search a una búsqueda dependiendo de la fuente. Esta función toma un número ilimitado de argumentos.
1
La fuente de la que obtener la búsqueda.
...
Los argumentos a usar como búsqueda si $1 es fn-args, o si 1 no coincide, ... se pasa a get_search_from_<1>.
load_extension()
Esta función añade una extensión a la variable $loaded_extensions y carga la extensión. Esta función busca la extensión en las siguientes ubicaciones: 
$YTFZF_EXTENSIONS_DIR
$YTFZF_SYSTEM_ADDON_DIR/extensions
$PATH
Esta función sale con el mismo código de salida que cuando se cargó la extensión. Esta función toma un argumento.
1
La extensión a cargar
extension_is_loaded()
Esta función comprueba si una extensión está cargada. Esta función toma un argumento.
1
La extensión a comprobar
load_sort_name()
Esta función carga un nombre de ordenación. Esta función busca el nombre de ordenación en las siguientes ubicaciones: 
$YTFZF_SORT_NAMES_DIR
$YTFZF_SYSTEM_ADDON_DIR/sort-names
Esta función sale con el código de estado 1 si el nombre de ordenación no existe, de lo contrario, sale con el mismo código de estado que cuando se cargó el nombre de ordenación. Esta función toma un argumento.
1
El nombre de ordenación a cargar
load_url_handler()
Esta función establece $url_handler a un manejador de url. Esta función busca el manejador de url en las siguientes ubicaciones: 
$PATH, y funciones en el archivo de configuración
$YTFZF_URL_HANDLERS_DIR
$YTFZF_SYSTEM_ADDON_DIR/url-handlers
Si el manejador de url no existe, esta función ejecuta die.
Esta función toma un argumento.
1
El manejador de url a cargar
load_interface()
Esta función establece $interface a una interfaz.
Si $1 es igual a ext, scripting, o "", $interface se establece a 1.
Esta función busca la interfaz en las siguientes ubicaciones:
$1
$YTFZF_CUSTOM_INTERFACES_DIR
$YTFZF_SYSTEM_ADDON_DIR/interfaces
Esta función toma un argumento.
1
La interfaz a cargar
load_thumbnail_viewer()
Esta función establece $thumbnail_viewer a un visor de miniaturas. Si $i es igual a un visor de miniaturas incorporado, $thumbnail_viewer se establece a ese. De lo contrario, se buscan las siguientes ubicaciones: 
$1
$YTFZF_THUMBNAIL_VIEWERS_DIR
$YTFZF_SYSTEM_ADDON_DIR
Esta función toma un argumento.
1
El visor de miniaturas a cargar
_get_request()
Esta función envía una solicitud a un servidor e imprime la respuesta. Esta función toma argumentos ilimitados.
1
La url a la que enviar una solicitud
...
Argumentos para pasar a curl(1)
_get_real_channel_link()
Esta función convierte un enlace de canal de youtube en la forma de 
@usuario
https://www.youtube.com/user/<nombre-de-canal>
https://www.youtube.com/c/<nombre-de-canal>
Esta función toma un argumento.
1
El enlace a convertir
