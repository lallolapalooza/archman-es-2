YKPARSE(1) Manual de la Biblioteca C de YubiKey YKPARSE(1)

NOMBRE

ykparse - descifra y muestra información dentro de una OTP de YubiKey

SINOPSIS

ykparse CLAVE_AES TOKEN

DESCRIPCIÓN

Descifra y muestra información dentro de una OTP de YubiKey.

OPCIONES

CLAVE_AES

La clave AES-128 de 16 caracteres a utilizar en formato hexadecimal.

TOKEN

La contraseña de un solo uso (OTP) codificada en modhex.

EJEMPLOS

El uso típico de la herramienta es el siguiente.

ykparse ecde18dbe76fbd0c33330f1c354871db dteffujedcflcindvdbrblehecuitvjkjevvehjd

VER TAMBIÉN

Las YubiKeys se pueden obtener de Yubico: http://www.yubico.com/
