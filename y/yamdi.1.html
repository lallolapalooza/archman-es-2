YAMDI(1) Manual de comandos generales YAMDI(1)

NOMBRE

yamdi - otro inyector de metadatos (flv)

SINOPSIS

yamdi -i archivo de entrada [-x archivo xml | -o archivo de salida [-x archivo xml]] [-t archivo temporal] [-c creador] [-a intervalo] [-skMXw] [-h]

DESCRIPCIÓN

yamdi significa Yet Another MetaData Injector (otro inyector de metadatos) y es un inyector de metadatos para archivos FLV. Agrega el evento onMetaData a tus archivos FLV.

OPCIONES

-i
El archivo FLV de origen. Si el nombre del archivo es '-' se leerá el archivo de entrada desde stdin. Usa la opción -t para especificar un archivo temporal.
-o
El archivo FLV resultante con las etiquetas de metadatos. Si el archivo de salida es '-' se escribirá el archivo FLV a stdout.
-x
Un archivo XML con la información de metadatos resultante. Si se omite el archivo de salida, solo se generarán metadatos.
-t
Un archivo temporal para almacenar el archivo FLV de origen si el archivo de entrada se lee desde stdin.
-c
Una cadena que se escribirá en la etiqueta del creador.
-s, -l
Agrega el evento onLastSecond. La opción -l está obsoleta y será eliminada en una versión futura.
-k
Agrega el evento onLastKeyframe.
-M
Elimina todos los metadatos del FLV. Las opciones -s y -k se ignorarán.
-X
Omite la etiqueta de fotogramas clave en la salida XML.
-a
Tiempo en milisegundos entre fotogramas clave si solo hay audio. Esta opción se ignorará si hay un flujo de video. No se agregarán fotogramas clave si se omite esta opción.
-w
Reemplaza el archivo de entrada con el archivo de salida. Se requiere que -i y -o sean archivos diferentes, de lo contrario, esta opción se ignorará.
-h
Muestra un resumen de las opciones.

ESTADO DE SALIDA

yamdi sale con 0 en caso de éxito y >0 si ocurre un error.
