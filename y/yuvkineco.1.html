NOMBRE

yuvkineco - revertir película con pulldown 2-3

SINOPSIS

yuvkineco [opciones] [-C RUTA]
yuvkineco [opciones] -O|N RUTA

DESCRIPCIÓN

yuvkineco revierte a fotogramas originales no entrelazados, desde video NTSC que se originó en película y se aplicó pulldown 2-3. El código de fps de entrada debe ser 4 (29.97fps), el código de fps de salida se puede seleccionar desde 1 (23.97fps) hasta 4 (29.97fps). Si se selecciona 2, 3 o 4, los fotogramas duplicados permanecen, pero se revierten a no entrelazados. Si la entrada no fue entrelazada, solo se eliminan los fotogramas duplicados. La detección de fotogramas entrelazados puede fallar en condiciones como:
Ciclo de pulldown cambiado (edición de video).
Pulldown de baja calidad.
Escena sin movimiento.
Si se especificó -C RUTA, yuvkineco genera una lista del ciclo de pulldown 2-3 en el archivo. Puede editar este archivo manualmente y alimentarlo a yuvkineco con la opción -O o -N para corregir errores del primer yuvkineco. Pruebe -C y vea la lista de ciclos.
EJEMPLO #1: para película 24p / automáticamente
lav2yuv 60i.eli | \
yuvkineco -F 1 | yuv2lav -f a -I 0 -o 24p.avi
EJEMPLO #2: para mezcla 30p/24p / automáticamente
lav2yuv 60i.eli | \
yuvkineco -F 4 | yuv2lav -f a -I 0 -o 30p.avi
EJEMPLO #3: para película 24p / verificar y reparar
lav2yuv 60i.eli | \
yuvkineco -F 1 -C 60i.23c | \
yuv2lav -f a -I 1 -o take1.avi
glav -F +n take1.avi  # verificar y editar 60i.23c
lav2yuv take1.avi | \
yuvkineco -F 1 -N 60i.23c | \
yuv2lav -f a -I 0 -o take2.avi
EJEMPLO #4: para película 24p / verificar y reintentar
lav2yuv 60i.eli | \
yuvkineco -F 1 -C 60i.23c | \
yuv2lav -f a -I 0 -o take1.avi
glav -F +n take1.avi  # verificar y editar 60i.23c
lav2yuv 60i.eli | \
yuvkineco -F 1 -O 60i.23c | \
yuv2lav -f a -I 0 -o take2.avi

OPCIONES

yuvkineco acepta las siguientes opciones:

-F CODIGODFPS
Establece el código de fps de salida (por defecto: igual que la entrada).
-C RUTA
Especifica el nombre del archivo de lista de ciclos de pulldown 2-3 para escribir.
-O RUTA
Especifica el nombre de la lista de ciclos para leer con el flujo YUV antiguo para reintentar.
-N RUTA
Especifica el nombre de la lista de ciclos para leer con el flujo YUV nuevo para reparar.
-n NIVEL
Especifica el nivel de ruido de la entrada (por defecto: 10). Esto afecta tanto a la detección del ciclo de pulldown como a la desentrelazación.
-c UMBRAL
Especifica el umbral para decidir si las imágenes en 2 fotogramas son iguales (por defecto: 4). yuvkineco compara varios fotogramas, busca pares de fotogramas que contengan imágenes iguales, para decidir qué fotograma debe descartarse. Si UMBRAL es 0, se seleccionará el par con la menor diferencia. Si es 16, se seleccionará entre los pares cuya diferencia sea menor que el promedio.
-i PORMIL
yuvkineco desentrelaza cada fotograma después del proceso de reversión de pulldown 2-3, especifica cuántos píxeles se desentrelazaron para decidir usar o no el resultado de la desentrelazación (por defecto: 10). Si PORMIL es 10 y el 1% o más de los píxeles se desentrelaza, se usará el resultado de la desentrelazación. Si es 0, siempre se usará el resultado de la desentrelazación. Si es 1000, el resultado de la desentrelazación no se usará, pero el proceso de desentrelazación se ejecutará en todos los fotogramas. Para deshabilitar el proceso de desentrelazación, especifique un valor negativo.
-u
Establece la información de entrelazado en la cabecera de salida como desconocida (por defecto: no entrelazado).
