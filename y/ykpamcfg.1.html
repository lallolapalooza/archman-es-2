YKPAMCFG(1) Manual del Módulo PAM de Yubico YKPAMCFG(1)

NOMBRE

ykpamcfg - Gestiona la configuración de usuario para el módulo PAM de Yubico

SINOPSIS

ykpamcfg [-1 | -2] [-A] [-p] [-i] [-v] [-V] [-h]

OPCIONES

-1

Usar la ranura 1. Este es el valor predeterminado.

-2

Usar la ranura 2.

-A acción

Elige la acción a realizar. Ver ACCIONES más abajo.

-p ruta

Especifica el archivo de salida, el valor predeterminado es ~/.yubico/challenge.

-i iteraciones

Número de iteraciones a usar para PBKDF2 de la respuesta esperada.

-v

Habilitar el modo detallado.

-V

Mostrar la versión y salir.

-h

Mostrar la ayuda y salir.

ACCIONES

add_hmac_chalresp

El módulo PAM puede utilizar el modo HMAC-SHA1 Desafío-Respuesta (C/R) que se encuentra en las YubiKeys a partir de la versión 2.2 para la **autenticación sin conexión**. Esta acción crea la información de estado inicial con el C/R que se emitirá en el próximo inicio de sesión.

La utilidad actualmente emite la información de estado a un archivo en el directorio de inicio del usuario actual (~/.yubico/challenge-123456 para una YubiKey con lectura de API de número de serie habilitada, y ~/.yubico/challenge para una sin ella).

El módulo PAM admite un directorio para todo el sistema para estos archivos de estado (en caso de que los directorios de inicio de los usuarios estén cifrados), pero en un directorio para todo el sistema, la parte del challenge debe reemplazarse por el nombre de usuario. Ejemplo: /var/yubico/challenges/alice-123456

Para usar el modo para todo el sistema, actualmente debe mover los archivos de estado generados manualmente y configurar el módulo PAM en consecuencia.

EJEMPLOS

Primero, programa una YubiKey para desafío-respuesta en la ranura 2:

$ ykpersonalize -2 -ochal-resp -ochal-hmac -ohmac-lt64 -oserial-api-visible
...
¿Confirmar? (s/n) [n]: s

Ahora, configura al usuario actual para que requiera esta YubiKey para el inicio de sesión:

$ ykpamcfg -2 -v
...
Se almacenó el desafío inicial y la respuesta esperada en '/home/alice/.yubico/challenge-123456'.

Luego, configura la autenticación con PAM, por ejemplo, de esta manera (haz una copia de seguridad primero):

/etc/pam.d/common-auth (de Ubuntu 10.10):

auth  required        pam_unix.so nullok_secure try_first_pass
auth  [success=1 new_authtok_reqd=ok ignore=ignore default=die] pam_yubico.so mode=challenge-response
auth  requisite       pam_deny.so
auth  required        pam_permit.so
auth  optional        pam_ecryptfs.so unwrap
