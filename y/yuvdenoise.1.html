NOMBRE

yuvdenoise - reductor de ruido de fotogramas YUV4MPEG2 con compensación de movimiento

SINOPSIS

yuvdenoise [opciones] </dev/stdin >/dev/stdout

DESCRIPCIÓN

yuvdenoise es un filtro de ruido espacio-temporal para flujos YUV4MPEG2. Esto es útil para reducir el bitrate necesario para codificar tus películas capturadas para la creación de VCD y SVCD.

OPCIONES

yuvdenoise acepta las siguientes opciones:

-g y,u,v [0..255] Umbrales del filtro Gaussiano
Esto establece los umbrales para el filtro gaussiano. Un valor de 0 desactiva el filtrado para un componente específico y 0,0,0 desactiva/omite completamente el filtro. Este filtro se aplica antes del filtro temporal (-t).
(por defecto=0,0,0)
-m y,u,v [0..255] Umbrales del filtro Mediana 3D previo
Esto establece los umbrales para el filtro de mediana 3D de preprocesamiento. Un valor de 0 desactiva el filtrado de mediana para un componente específico y 0,0,0 desactiva/omite completamente el filtro. Este filtro se aplica antes del filtro temporal (-t).
(por defecto=0,0,0)
-r y,u,v [0..255] Umbrales del filtro de renodificado
Esto establece los umbrales para añadir "ruido" aleatorio de vuelta al flujo de video. Por defecto está desactivado (no se añade ruido aleatorio). Este filtro, si está activado, se ejecuta como el filtro Blast (después de los filtros de mediana y temporal). Un valor razonable es 4,8,8 pero si estás trabajando con películas monocromáticas (blanco y negro) entonces 4,0,0 acelerará las cosas al no procesar los planos de croma.
(por defecto=0,0,0)
-t y,u,v [0..255] Umbrales del filtro de ruido temporal
Esto establece los umbrales para el filtro de ruido temporal. Valores por encima de 12 pueden introducir fantasmas. El valor por defecto para Y' (y) suele ser un poco alto y reducirlo a 4 o 5 puede ser necesario. Si el croma se difumina o produce fantasmas, intenta usar valores de 5 o 6 en lugar del valor por defecto (12). Un valor de 0 desactiva el filtrado temporal para el componente especificado (0,0,0 desactiva/omite todo el filtrado temporal). Por lo tanto, para películas en blanco y negro, 4,0,0 será más rápido al no reducir el ruido de los planos de croma.
(por defecto=4,8,8)
-M y,u,v [0..255] Umbrales del filtro Mediana 3D posterior
Esto establece los umbrales para el filtro de mediana 3D de postprocesamiento. Un valor de 0 desactiva el filtrado de mediana para un componente específico y 0,0,0 desactiva/omite completamente el filtro. Este filtro se aplica después del filtro temporal (-t). Un valor razonable es 4,8,8 pero si estás trabajando con películas monocromáticas (blanco y negro) entonces 4,0,0 acelerará las cosas al no procesar los planos de croma.
(por defecto=0,0,0)

USO TÍPICO Y CONSEJOS

Como se auto-adapta a la situación de ruido encontrada en el flujo, normalmente puedes usarlo sin ninguna opción configurada:

lav2yuv mi-video.avi | yuvdenoise | mpeg2enc -t 1 -o mi-video.m1v
