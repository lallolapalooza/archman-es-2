YUBICO-PIV-TOOL(1) Comandos de usuario YUBICO-PIV-TOOL(1)

NOMBRE

yubico-piv-tool - Herramienta para gestionar credenciales de Verificación de Identidad Personal (PIV) en Yubikeys

SINOPSIS

yubico-piv-tool [OPCIÓN]...

DESCRIPCIÓN

-h, --help
Imprime la ayuda y sale
--full-help
Imprime la ayuda, incluyendo opciones ocultas, y sale
-V, --version
Imprime la versión y sale
-v, --verbose[=INT]
Imprime más información (por defecto=`0')
-r, --reader=CADENA
Solo usa un lector que coincida (por defecto=`Yubikey')
-k, --key[=CADENA]
Clave de gestión a usar, si no se especifica valor se pedirá la clave (por defecto=`010203040506070801020304050607080102030405060708')
-a, --action=ENUM
Acción a tomar (valores posibles="version", "generate", "set-mgm-key", "reset", "pin-retries", "import-key", "import-certificate", "set-chuid", "request-certificate", "verify-pin", "verify-bio", "change-pin", "change-puk", "unblock-pin", "selfsign-certificate", "delete-certificate", "read-certificate", "read-public-key", "status", "test-signature", "test-decipher", "list-readers", "set-ccc", "write-object", "read-object", "attest", "move-key", "delete-key")
Se pueden dar varias acciones a la vez y se ejecutarán en orden, por ejemplo --action=verify-pin --action=request-certificate
-s, --slot=ENUM
En qué ranura de clave operar (valores posibles="9a", "9c", "9d", "9e", "82", "83", "84", "85", "86", "87", "88", "89", "8a", "8b", "8c", "8d", "8e", "8f", "90", "91", "92", "93", "94", "95", "f9")
9a es para Autenticación PIV, 9c para Firma Digital (PIN siempre verificado), 9d para Gestión de Claves, 9e para Autenticación de Tarjeta (PIN nunca verificado), 82-95 para Gestión de Claves Retiradas, f9 para Atestación.
--to-slot=ENUM
A qué ranura mover una clave existente (valores posibles="9a", "9c", "9d", "9e", "82", "83", "84", "85", "86", "87", "88", "89", "8a", "8b", "8c", "8d", "8e", "8f", "90", "91", "92", "93", "94", "95", "f9")
9a es para Autenticación PIV, 9c para Firma Digital (PIN siempre verificado), 9d para Gestión de Claves, 9e para Autenticación de Tarjeta (PIN nunca verificado), 82-95 para Gestión de Claves Retiradas, f9 para Atestación.
-A, --algorithm=ENUM
Qué algoritmo usar (valores posibles="RSA1024", "RSA2048", "RSA3072", "RSA4096", "ECCP256", "ECCP384", "ED25519", "X25519" por defecto=`RSA2048')
-H, --hash=ENUM
Hash a usar para firmas (valores posibles="SHA1", "SHA256", "SHA384", "SHA512" por defecto=`SHA256')
-n, --new-key=CADENA
Nueva clave de gestión a usar para la acción set-mgm-key, si se omite se pedirá la clave
--pin-retries=INT
Número de reintentos antes de que el código PIN sea bloqueado
--puk-retries=INT
Número de reintentos antes de que el código PUK sea bloqueado
-i, --input=CADENA
Nombre de archivo a usar como entrada, - para stdin (por defecto=`-')
-o, --output=CADENA
Nombre de archivo a usar como salida, - para stdout (por defecto=`-')
-K, --key-format=ENUM
Formato de la clave que se lee/escribe (valores posibles="PEM", "PKCS12", "GZIP", "DER", "SSH" por defecto=`PEM')
--compress
Comprimir un certificado grande usando GZIP antes de importarlo (por defecto=apagado)
--global
Restablecer todo el dispositivo sobre todas las aplicaciones (por defecto=apagado)
-p, --password=CADENA
Contraseña para descifrar el archivo de clave privada, si se omite se pedirá la contraseña
-S, --subject=CADENA
El sujeto a usar para la solicitud de certificado
El sujeto debe escribirse como: /CN=host.example.com/OU=test/O=example.com/
--serial=INT
Número de serie del certificado autofirmado
--valid-days=INT
Tiempo (en días) hasta que el certificado autofirmado expire (por defecto=`365')
-P, --pin=CADENA
Código PIN/PUK para verificación, si se omite se pedirá el PIN/PUK
-N, --new-pin=CADENA
Nuevo código PIN/PUK para cambiar, si se omite se pedirá el PIN/PUK
--pin-policy=ENUM
Establecer la política de PIN para la acción generate o import-key. Solo disponible en YubiKey 4 o más reciente (valores posibles="never", "once", "always", "matchonce", "matchalways")
--touch-policy=ENUM
Establecer la política de toque para la acción generate, import-key o set-mgm-key. Solo disponible en YubiKey 4 o más reciente (valores posibles="never", "always", "cached")
--id=INT
ID del objeto para escribir/leer objeto
-f, --format=ENUM
Formato de los datos para escribir/leer objeto (valores posibles="hex", "base64", "binary" por defecto=`hex')
--attestation
Añadir una firma cruzada de atestación (por defecto=apagado)
-m, --new-key-algo=ENUM
Algoritmo de la nueva clave de gestión a usar para la acción set-mgm-key (valores posibles="TDES", "AES128", "AES192", "AES256" por defecto=`TDES')
--scp11
La comunicación con YubiKey se realiza a través de un canal cifrado. ¡OBSOLETO! Por favor, usa la bandera '--enc' en su lugar (por defecto=apagado)
--enc
La comunicación con YubiKey se realiza a través de un canal cifrado (por defecto=apagado)
