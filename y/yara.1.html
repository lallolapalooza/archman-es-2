NOMBRE

yara - encuentra archivos que coincidan con patrones y reglas escritos en un lenguaje de propósito especial.

SINOPSIS

yara [OPCIÓN]... [NAMESPACE:]ARCHIVO_DE_REGLAS... ARCHIVO | DIRECTORIO | PID

DESCRIPCIÓN

yara escanea el ARCHIVO dado, todos los archivos contenidos en el directorio DIRECTORIO, o el proceso identificado por PID buscando coincidencias de patrones y reglas proporcionadas en un lenguaje de propósito especial. Las reglas se leen de uno o más ARCHIVOS_DE_REGLAS.

Las opciones para yara(1) son:

--atom-quality-table
Ruta a un archivo con la tabla de calidad de átomos.
-C --compiled-rules
ARCHIVO_DE_REGLAS contiene reglas ya compiladas con yarac.
-c --count
Imprime solo el número de coincidencias.
-d --define=identificador=valor
Define una variable externa. Esta opción se puede usar varias veces.
--fail-on-warnings
Trata las advertencias como errores. No tiene efecto si se usa con --no-warnings.
-f --fast-scan
Acelera el escaneo buscando solo la primera ocurrencia de cada patrón.
-i identificador --identifier=identificador
Imprime las reglas llamadas identificador e ignora el resto. Esta opción se puede usar varias veces.
--max-process-memory-chunk=tamaño
Al escanear la memoria del proceso, lee datos en trozos del tamaño dado en bytes.
-l número --max-rules=número
Aborta el escaneo después de que coincidan número de reglas.
--max-strings-per-rule=número
Establece el número máximo de cadenas por regla (por defecto=10000)
-x --module-data=modulo=archivo
Pasa el contenido del archivo como datos adicionales al módulo. Esta opción se puede usar varias veces.
-n --negate
Imprime las reglas que no se aplican (niega).
-w --no-warnings
Desactiva las advertencias.
-m --print-meta
Imprime los metadatos asociados a la regla.
-D --print-module-data
Imprime los datos del módulo.
-M --module-names
muestra los nombres de los módulos
-e --print-namespace
Imprime el espacio de nombres asociado a la regla.
-S --print-stats
Imprime las estadísticas de las reglas.
-s --print-strings
Imprime las cadenas encontradas en el archivo.
-L --print-string-length
Imprime la longitud de las cadenas encontradas en el archivo.
-X --print-xor-key
Imprime la clave XOR de las cadenas coincidentes.
-g --print-tags
Imprime las etiquetas asociadas a la regla.
-r --recursive
Escanea archivos en directorios de forma recursiva. Sigue los enlaces simbólicos.
--scan-list
Escanea los archivos listados en ARCHIVO, uno por línea.
-z tamaño --skip-larger=tamaño
Omite archivos más grandes que el tamaño dado en bytes al escanear un directorio.
-k ranuras --stack-size=ranuras
Establece el tamaño máximo de la pila al número especificado de ranuras.
--strict-escape
Imprime advertencias si las reglas contienen declaraciones de escape ambiguas.
-t etiqueta --tag=etiqueta
Imprime las reglas etiquetadas como etiqueta e ignora el resto. Esta opción se puede usar varias veces.
-p número --threads=número
Usa el número de hilos especificado para escanear un directorio.
-a segundos --timeout=segundos
Aborta el escaneo después de que transcurra un número de segundos.
-v --version
Muestra la información de la versión.

EJEMPLOS

$ yara /foo/bar/rules .

Aplica las reglas de /foo/bar/rules a todos los archivos del directorio actual. Los subdirectorios no se escanean.

$ yara -t Packer -t Compiler /foo/bar/rules bazfile

Aplica las reglas de /foo/bar/rules a bazfile. Solo informa las reglas etiquetadas como Packer o Compiler.

$ cat /foo/bar/rules | yara -r /foo

Escanea todos los archivos del directorio /foo y sus subdirectorios. Las reglas se leen de la entrada estándar.

$ yara -d mybool=true -d myint=5 -d mystring="my string" /foo/bar/rules bazfile

Define tres variables externas mybool myint y mystring.

$ yara -x cuckoo=cuckoo_json_report /foo/bar/rules bazfile

Aplica las reglas de /foo/bar/rules a bazfile mientras pasa el contenido de cuckoo_json_report al módulo cuckoo.
