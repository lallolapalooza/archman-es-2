Y0(3P) Manual del programador POSIX Y0(3P)

PROLOG

Esta página del manual forma parte del Manual del programador POSIX. La implementación de esta interfaz en Linux puede diferir (consulte la página del manual de Linux correspondiente para conocer los detalles del comportamiento de Linux), o la interfaz puede no estar implementada en Linux.

NOMBRE

y0, y1, yn — funciones de Bessel de segunda clase

SINOPSIS

#include <math.h>
double y0(double x);
double y1(double x);
double yn(int n, double x);

DESCRIPCIÓN

Las funciones y0(), y1() y yn() calcularán las funciones de Bessel de x de segunda clase de órdenes 0, 1 y n, respectivamente.

Una aplicación que desee comprobar situaciones de error debe establecer errno a cero y llamar a feclearexcept(FE_ALL_EXCEPT) antes de llamar a estas funciones. Al regresar, si errno es distinto de cero o fetestexcept(FE_INVALID | FE_DIVBYZERO | FE_OVERFLOW | FE_UNDERFLOW) es distinto de cero, se ha producido un error.

VALOR DE RETORNO

Tras una finalización correcta, estas funciones devolverán el valor de Bessel de segunda clase relevante de x.

Si x es NaN, se devolverá NaN.

Si el argumento x de estas funciones es negativo, se devolverá -HUGE_VAL o NaN, y puede ocurrir un error de dominio.

Si x es 0.0, se devolverá -HUGE_VAL y puede ocurrir un error de polo.

Si el resultado correcto causara un desbordamiento inferior (underflow), se devolverá 0.0 y puede ocurrir un error de rango.

Si el resultado correcto causara un desbordamiento superior (overflow), se devolverá -HUGE_VAL o 0.0 y puede ocurrir un error de rango.

ERRORES

Estas funciones pueden fallar si:

Error de Dominio
El valor de x es negativo.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [EDOM]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante inválida.

Error de Polo
El valor de x es cero.

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante de división por cero.

Error de Rango
El resultado correcto causaría un desbordamiento superior (overflow).

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante de desbordamiento superior.

Error de Rango
El valor de x es demasiado grande en magnitud, o el resultado correcto causaría un desbordamiento inferior (underflow).

Si la expresión entera (math_errhandling & MATH_ERRNO) es distinta de cero, entonces errno se establecerá a [ERANGE]. Si la expresión entera (math_errhandling & MATH_ERREXCEPT) es distinta de cero, entonces se generará la excepción de punto flotante de desbordamiento inferior.

USO EN APLICACIONES

En caso de error, las expresiones (math_errhandling & MATH_ERRNO) y (math_errhandling & MATH_ERREXCEPT) son independientes entre sí, pero al menos una de ellas debe ser distinta de cero.
