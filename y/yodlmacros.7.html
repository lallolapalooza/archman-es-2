NOMBRE

yodlmacros - Macros para los convertidores Yodl

SINOPSIS

Esta página del manual enumera las macros estándar del paquete Yodl.

DESCRIPCIÓN

La siguiente lista muestra las macros definidas por los convertidores de Yodl y que se pueden utilizar en documentos Yodl. Consulte la guía del usuario de Yodl, distribuida con el paquete Yodl, para obtener una descripción completa.

La siguiente lista muestra todas las macros del paquete en orden alfabético.

`abstract(texto)’
Define un resumen para un artículo o un tipo de documento informe. Los resúmenes no están implementados para libros o páginas man. Debe aparecer antes de iniciar el documento usando la macro `article’ o `report’.
`addntosymbol(símbolo)(n)(texto)’
Añade `texto’ `n’ veces a `símbolo’. El valor `n’ también puede ser el nombre de un contador definido (que no se modifica).
`affiliation(sitio)’
Define una afiliación, que aparecerá en la portada del documento debajo del campo autor. Debe aparecer antes de iniciar el documento con `article’, `report’ o `book’. La afiliación solo se imprime cuando el campo autor no está vacío. Al convertir a html, la forma en que se muestra la afiliación se puede ajustar usando especificaciones de selectores de ID CSS. La afiliación tiene `id="affiliation"’.
`AfourEnlarged()’
Aumenta la altura utilizable del papel A4 en 2 cm.: el margen superior se reduce en 2 cm. Esta macro debe llamarse en el preámbulo. La macro solo está disponible para conversiones a LaTeX.
Esta macro está algo obsoleta. En su lugar, se recomienda usar `PageEnlarged’
`appendix()’
Inicia apéndices
`article(título)(autor)(fecha)’
Inicia un artículo. El comando de sección de nivel superior es `(n)sect’. En conversiones HTML solo se escribe un archivo de salida, mientras que la forma en que se muestran los encabezados se puede ajustar usando especificaciones de selectores de ID CSS: el título tiene `id="title"’, el autor `id="author"’, y la fecha `id="date"’.)
`attrib(texto)’
En html, empuja `texto’ como un atributo para la siguiente etiqueta html que admita `attrib’. Por ejemplo, para establecer un color azul y un margen izquierdo de 30 píxeles para una sección use 
    attrib(style="color:blue;margin-left:30px;")\ 
    sect(Nombre de sección)
Esto da como resultado el marcado html 
    <h1 style="color:blue;margin-left:30px;">Nombre de sección</h1>
Esta macro solo es efectiva con conversiones html. Se aplica de forma de pila: cuando se usan múltiples llamadas `attrib’, la cadena de atributos superior se añade a la primera macro que llama a la macro `attribinsert’, y las macros subsiguientes utilizan elementos subsiguientes de la pila de atributos.
Los atributos de uso común son `id="idnombre"’, esperando una etiqueta CSS `#idnombre’ en especificaciones CSS internas o externas, o `style="especificación"’ (como se muestra en el ejemplo).
Ejemplo: al usar 
    attrib(width = "100" height = "100")
    attrib(id = "#fig")
    figure(archivoimg)(Leyenda)(IMG)
entonces el atributo `#id’ se aplica a `<figure>’, y los atributos `width’ y `height’ se aplican a `<img>’, que es el marcado html insertado por la macro `figure’.
La macro `attrib’ es compatible con las siguientes macros predefinidas (entre paréntesis el número de cadenas de atributos que son insertadas por estas macros; si solo se inserta 1 cadena de atributo, no se muestra número):
`bf cell cells center chapter code dashes dit em figure(3) file htmltag itdesc lchapter link lref lsect lsubsect lsubsubsect nchapter npart nsect nsubsect nsubsubsect paragraph part quote row sc sect strong subs subsect subsubsect subsubsubsect sups tableatt tbl tac tc tnac tnc tr tt ttbegin url verb verborg verbinclude’.
`attribclear()’
Elimina cualquier contenido existente de la pila de atributos. Esta macro solo está activa al convertir a html
`attribinsert()’
En html, si la pila de atributos no está vacía, inserta el valor en la cima de la pila de atributos y luego extrae el valor superior. Si la pila de atributos está vacía, no ocurre nada.
`bf(texto)’
Establece `texto’ en negrita.
`bind(texto)’
Genera un carácter de unión (espacio no rompible) después del texto.
`book(título)(autor)(fecha)’
Inicia un documento tipo libro. El comando de sección de nivel superior es `(n)chapter’, siendo `(n)part’ opcional. En la salida HTML se crean archivos para cada capítulo, mientras que la forma en que se muestran los encabezados se puede ajustar usando especificaciones de selectores de ID CSS: el título tiene `id="title"’, el autor `id="author"’, y la fecha `id="date"’.)
`cell(contenido)’
Establece una celda de tabla, es decir, un elemento en una fila. Con los convertidores man/ms, los espacios múltiples entre llamadas a la macro `cell()’ se fusionan en un solo carácter de espacio.
En lugar de usar `cell’ en `table’, considere usar `tc’ en `tbl’.
`cells(nColumnas)(contenido)’
Establece una celda de tabla que abarca `nColumnas’ columnas. Con LaTeX y xml, la información en las celdas combinadas se centra.
Con las conversiones man/ms, la macro `cells()’ simplemente llama a la macro `cell()’, pero aquí la macro `setmanalign()’ puede usarse para determinar la alineación de múltiples celdas.
Con html, la macro `attrib’ puede ser usada, pero cuando contiene una especificación `style’, la especificación por defecto de la macro `style="text-align: center"’ se ignora (pero puede especificarse opcionalmente usando la macro `attrib’).
En lugar de usar `cells’ en `table’, considere usar `tnc’ en `tbl’.
`cellsline(desde)(cuenta)’
Establece una línea horizontal comenzando en el número de columna `desde’ a lo largo de `cuenta’ columnas en una fila. Si `desde’ es menor que el número de columnas ya añadidas a una fila, se ignora. Esta macro debe incrustarse en una macro `row’ que defina una fila de tabla. Para poner una línea a lo ancho completo de la tabla use `rowline’. Para establecer líneas horizontales a través de las columnas 1 hasta 2 y columnas 4 hasta 5 de una tabla use: 
    row(cellsline(1)(2)cellsline(4)(2))
Combinar `cellsline’ y llamadas `cell’ o `cells’ en una misma fila produce resultados indefinidos.
En lugar de usar `cellsline’ en `table’, considere usar `tline’ en `tbl’.
`center(texto)’
Centra `texto’. Use `nl()’ en el texto para saltar líneas. En html la macro `attrib’ no es compatible, pero se usa una división (`div’) con la definición de estilo `text-align: center’. Para centrar una tabla en html use la macro `tableatt’. Si una macro `table’ o `tableatt’ se usa dentro de una macro `center’, entonces los contenidos de las columnas se centran columna por columna.
Dentro de un contexto `center(...)’, el contador `XXcenter’ es distinto de 0.
`chapter(título)’
Inicia un nuevo capítulo en libros o informes.
`cindex()’
Genera una entrada de índice para índices c de LaTex() o texinfo. Su argumento es la entrada del índice. Ver también la macro `[fptv]index’.
`cite(texto)’
Establece `texto’ como una cita o una cita textual
`clearpage()’
Inicia una nueva página, cuando el formato de salida lo permite. Bajo HTML se dibuja una línea horizontal.
`code(texto)’
Establece `texto’ en fuente de código y evita que se expanda. Para listas de parámetros desequilibradas, use `CHAR(40)’ para obtener `(’ y `CHAR(41)’ para obtener `)’.
`columnline(desde)(hasta)’
Establece una línea horizontal sobre algunas columnas en una fila. Tenga en cuenta que `columnline’ define una fila por sí misma, que consiste solo en una línea horizontal que abarca algunas de sus columnas, en lugar de abarcar todo el ancho de la tabla, como `rowline’. Los dos argumentos representan números de columna. Es responsabilidad del autor asegurarse de que los valores `desde’ y `hasta’ sean sensatos. Es decir, 
    1 <= desde <= hasta <= ncolumnas
Para establecer una línea horizontal en una sola columna, seleccione `hasta’ igual a `desde’.

`dashes()’
Inserta dos guiones en fuente de teletipo, y evita que se expandan.
En HTML, la macro `attrib’ es reconocida por la etiqueta `<code>’ que se usa para incrustar los dos guiones.
`def(macroname)(nrofargs)(redefinition)’
Define `macroname’ como una macro, teniendo `nrofargs’ argumentos, y expandiendo a `redefinition’. Esta macro es un atajo para `DEFINEMACRO’. Ocurre un error cuando la macro ya está definida. Usa `redef()’ para definir o redefinir incondicionalmente una macro.
`description(list)’
Establece `list’ como una lista de descripción. Usa `dit(item)’ para indicar elementos en la lista.
`dit(itemname)’
Inicia un elemento llamado `itemname’ en una lista de descripción. La lista debe usarse en macros `description’. Con las conversiones de `html’, el contenido de un elemento de descripción se separa del elemento mismo. La macro `dit’ solo define el elemento, y no la descripción en sí. Esta macro establece el elemento en negrita (fuente `strong’). La macro `itdesc’, disponible desde Yodl 3.05, se puede usar para definir un elemento y su descripción, utilizando su formato sugerido (es decir, indentando la descripción en relación con el elemento).
`eit()’
Indica un elemento en una lista enumerada. La macro `eit’ debe usarse como argumento en las macros `enumeration’.
`ellipsis()’
Establece puntos suspensivos (...).
`em(text)’
Establece `text’ como enfatizado, usualmente en cursiva.
`email(address)’
En HTML, esta macro establece la `address’ en un localizador `<a href="mailto=..">’. En otros formatos de salida, la `address’ se envía a la salida. La macro `email’ es un caso especial de `url’.
`enumeration(list)’
`enumeration()’ inicia una lista enumerada. Usa `eit()’ en la lista para indicar los elementos de la lista.
`euro()’
Establece el símbolo de la moneda euro en latex, html, (y posiblemente sgml y xml). En todas las demás conversiones, EUR, que es la abreviatura textual oficial (cf. http://ec.europa.eu/euro/entry.html), se escribe. Ten en cuenta que LaTeX puede requerir el paquete latex `latexpackage()(eurosym)’.
`evalsymbol(symbol)(expression)’
El símbolo symbol recibe el valor resultante de evaluar la expression. Por ejemplo, si `sym’ es un símbolo definido, entonces 
    evalsymbol(sym)(SUBSTR(hello world)(3)(2))
asigna el valor `lo’ a `sym’.
`fig(label)’
Esta macro es un atajo para `figure ref(label)’ y simplemente hace la escritura más corta, como en `ver fig(schematic) para ..’ Ver `getfigurestring()’ y `setfigurestring()’ para el texto de `figure’.
`figure(file)(caption)(label)’
Establece la imagen en `file’ como una figura en el documento actual, usando el texto descriptivo `caption’. La `label’ se define como un marcador de posición para el número de figura y se puede usar en una declaración `ref’ correspondiente. Ten en cuenta que `file’ debe ser el nombre del archivo sin extensión: Por defecto, Yodl suministrará `.gif’ cuando esté en modo HTML, o `.ps’ cuando esté en modo LaTeX. Las figuras en otros modos pueden no estar (todavía) implementadas.
Al convertir a HTML, esta macro usa tres cadenas de atributos (si están disponibles). La cadena insertada primero usando una llamada `attrib` define los atributos para el marcado HTML `<figcaption>’; la cadena insertada a continuación define los atributos para el marcado HTML `<img>’; la cadena insertada al final define los atributos para el marcado HTML `<figure>’. La salida HTML de la macro `figure’ está organizada de la siguiente manera: 
    <figure -cadena de atributos insertada al final (si la hay)>
        <img ... -cadena de atributos insertada penúltima>
        <figcaption -cadena de atributos insertada antepenúltima>
            ...
        </figcaption>
    </figure>
A partir de Yodl 3.07.00, ya no se define un atributo `alt="Se muestra la Figura # ..."’ para el marcado `img’: un atributo `alt’ se puede definir fácilmente en la última llamada `attrib`, usando `getfigurestring()’ para obtener `Figure’ o su traducción específica del idioma, y `COUNTERVALUE(XXfigurecounter)’ para obtener el número de orden de la figura mostrada en la siguiente llamada de macro `figure’.
`file(text)’
Establece `text’ como nombre de archivo, usualmente en negrita. En HTML, la macro `attrib’ se aplica a la etiqueta `<strong>’.
`findex()’
Genera una entrada de índice para índices f de LaTex() o texinfo. Su argumento es la entrada del índice. Ver también la macro `[cptv]index’.
`footnote(text)’
Establece `text’ como nota al pie de página, o entre paréntesis cuando el formato de salida no permite notas al pie de página.
`gagmacrowarning(name name ...)’
Evita que el programa `yodl’ imprima cannot expand possible user macro. Por ejemplo, si tienes en tu documento `the file(s) are ..’ entonces quizás quieras poner antes: `gagmacrowarning(file)’. Llama a `NOUSERMACRO’.
`getaffilstring()’
Se expande a la cadena que define el nombre de Información de Afiliación, por defecto INFORMACIÓN DE AFILIACIÓN. Puede ser redefinida para soporte de idiomas nacionales por `setaffilstring()’. Actualmente, solo es relevante para txt.
`getauthorstring()’
Se expande a la cadena que define el nombre de Información del Autor, por defecto INFORMACIÓN DEL AUTOR. Puede ser redefinida para soporte de idiomas nacionales por `setauthorstring()’. Actualmente, solo es relevante para txt.
`getchapterstring()’
Se expande a la cadena que define una entrada de `chapter’, por defecto Chapter. Puede ser redefinida para soporte de idiomas nacionales por `setchapterstring()’.
`getdatestring()’
Se expande a la cadena que define el nombre de Información de Fecha, por defecto INFORMACIÓN DE FECHA. Puede ser redefinida para soporte de idiomas nacionales por `setdatestring()’. Actualmente, solo es relevante para txt.
`getfigurestring()’
Devuelve la cadena que define el texto de una `figure’, en títulos o en la macro `fig()’. La cadena puede ser redefinida usando la macro `setfiguretext()’.
`getpartstring()’
Se expande a la cadena que define una entrada de `part’, por defecto Part. Puede ser redefinida para soporte de idiomas nacionales por `setpartstring()’.
`gettitlestring()’
Se expande a la cadena que define el nombre de Información del Título, por defecto INFORMACIÓN DEL TÍTULO. Puede ser redefinida para soporte de idiomas nacionales por `settitlestring()’. Actualmente, solo es relevante para txt.
`gettocstring()’
Se expande a la cadena que define el nombre de la tabla de contenidos, por defecto Table of Contents. Puede ser redefinida para soporte de idiomas nacionales por `settocstring()’.
`htmlcommand(cmd)’
Escribe `cmd’ en la salida al convertir a HTML. El `cmd’ no es expandido adicionalmente por Yodl.
`htmlheadfile(file)’
Agrega el contenido de `file’ a la sección `head’ de un documento HTML. El contenido del archivo no se interpreta y debe contener texto HTML plano. Esta opción puede ser útil cuando grandes bloques de texto, como el contenido de secciones `<script>’, deben incluirse en la sección head de los documentos HTML. Esta macro solo está activa en el preámbulo, solo debe especificarse una vez y solo se interpreta para conversiones HTML.
`htmlheadopt(option)’
Agrega el texto literal `option’ a la información actual en la sección `head’ de un documento HTML. `Option’ puede (o: debe) contener texto HTML plano. Una opción de encabezado que ocurre comúnmente es `link`, que define, por ejemplo, una hoja de estilos. Dado que esa opción se usa con frecuencia, ha recibido una macro dedicada: `htmlstylesheet’. Cuando se deben agregar grandes bloques de texto HTML a los documentos HTML, se debe usar la macro `htmlheadfile’. Esta macro solo está activa en el preámbulo y solo se interpreta para conversiones HTML.
`htmlnewfile()’
En la salida HTML, inicia un nuevo archivo. Todos los demás formatos no se ven afectados. Ten en cuenta que debes tomar tus propias medidas para acceder al nuevo archivo; por ejemplo, a través de enlaces. Además, es seguro iniciar un nuevo archivo justo antes de abrir una nueva sección, ya que las secciones son accesibles desde la tabla de contenidos hacible clic. El conversor HTML normalmente solo inicia nuevos archivos antes de una definición de `chapter’.
`htmlstyle(tag)(definition)’
Agrega un elemento `<style type="text/css"> ... </style>’ a la sección head de un documento HTML.
Usa `htmlstyle’ para especificar una o más definiciones CSS que eventualmente se insertan en las elipses (`...’) en la definición genérica `style` que se muestra arriba. Por ejemplo, (usando `#rrggbb’ para especificar un color, donde `rr’ son dos dígitos hexadecimales que especifican el componente rojo del color, `gg’ dos dígitos hexadecimales que especifican el componente verde del color, y `bb’ dos dígitos hexadecimales que especifican el componente azul del color) especificar 
    htmlstyle(body)(color: #rrggbb; background-color: #rrggbb)
    htmlstyle(h1)(color: blue; text-align: center)
    htmlstyle(h2)(color: green)
resulta en el elemento 
    <style type="text/css">
        body {color: #rrggbb; background-color: #rrggbb;}
        h1 {color: blue; text-align: center;}
        h2 {color: green;}
    </style>
Las macros `htmlheadopt’ y `htmlstylesheet’ también podrían usarse para poner información en la sección head de un documento HTML, pero `htmlheadopt’ es de naturaleza mucho más general, mientras que `htmlstylesheet’ se refiere a elementos CSS almacenados en un archivo externo. La macro `attrib’ se puede usar para definir estilos en línea.
La macro `htmlstyle’ solo está activa en el preámbulo y solo se interpreta para conversiones HTML.
Consulta las especificaciones CSS disponibles (cf. http://www.w3schools.com/cssref/ para una descripción general de cómo se usan las especificaciones CSS y qué especificaciones CSS están disponibles).
Por defecto, la especificación de estilo interno
`figure {text-align: center;} img {vertical-align: center;}’
se utiliza. Si esto no es apropiado, especifique `nohtmlimgstyle()’ en la preámbulo.
`htmlstylesheet(url)’
Añade un elemento `<link rel="stylesheet" type="text/css" ...>’ a la sección head de un documento HTML, utilizando `url’ en su campo `href’. El argumento `url’ no se expande y debe ser texto HTML plano, sin comillas circundantes. La macro `htmlheadopt’ también se puede usar para colocar información en la sección head de un documento HTML, pero `htmlheadopt’ es de naturaleza mucho más general. Esta macro solo está activa en el preámbulo y solo se interpreta para conversiones html.
`htmltag(tagname)(start)’
Establece `tagname’ como una etiqueta HTML, encerrada por `<’ y `>’. Cuando `start’ es cero, `tagname’ se prefija con `/’. Como no todas las etiquetas html están disponibles a través de macros Yodl predefinidas (hay demasiadas, algunas se usan con muy poca frecuencia y puede definir fácilmente macros para las etiquetas para las que Yodl no ofrece las predefinidas), la macro `htmltag’ se puede usar para manejar su propio conjunto de macros. En html se soporta la macro `attrib’. Por ejemplo: 
attrib(title="Organización Mundial de la Salud")    htmltag(abbr)()OMS+htmltag(abbr)(0)
`ifnewparagraph(truelist)(falselist)’
La macro `ifnewparagraph’ debe llamarse desde la macro `PARAGRAPH’, si está definida. Insertará `truelist’ si se inserta un nuevo párrafo, de lo contrario se insertará `falselist’ (por ejemplo, después de dos llamadas consecutivas a PARAGRAPH). Esta macro puede usarse para evitar la salida de múltiples líneas en blanco.
`includefile(file)’
Incluye `file’. La extensión predeterminada `.yo’ se proporciona si es necesario.
Desde la versión 3.00.0 de Yodl, el comportamiento predeterminado de inclusión de archivos de Yodl ha cambiado. El directorio de trabajo actual ya no permanece fijo en el directorio en el que se llama a Yodl, sino que es volátil, cambiando al directorio en el que se encuentra un archivo yodl. Esto tiene la ventaja de que el comportamiento de inclusión de archivos de Yodl ahora coincide con la forma en que opera la directiva `#include’ de **C**. El comportamiento de inclusión de archivos implementado originalmente se utiliza cuando se utiliza la opción `-L’ (`--legacy-include’) de Yodl.
`includeverbatim(file)’
Incluye `file’ en la salida. No se realiza ningún procesamiento, `file’ debe estar en formato preformateado, por ejemplo: 
whenhtml(includeverbatim(foo.html))
`it()’
Indica un elemento en una lista de elementos. Los elementos en macros `it()’ son argumentos de macros `itemization()’.
`itdesc(itemname)(contents)’
Inicia un elemento y su descripción en una lista de descripción. Su nombre es `itemname’, el contenido del elemento se define mediante `contents’. El `itemname’ se define utilizando la macro `dit()’.
Con las conversiones `html’ el contenido se rodea de etiquetas `<dd>’ y `</dd>’, resultando en contenido que está indentado con respecto al nombre del elemento. Cuando se utiliza la macro `attrib()’ se aplica al nombre del elemento (etiquetas `<dt>’).
Con otras conversiones, el `contents’ se cita (como si se usara `quote(contents)’).
`itemization(list)’
Establece `list’ como una lista de ítems. Usa `it()’ para indicar los elementos de la lista.
`kindex()’
Genera una entrada de índice para índices k de LaTex() o texinfo. Su argumento es la entrada del índice. Ver también la macro `[cfptv]vindex()’.
`label(labelname)’
Define `labelname’ como una ancla para un comando `link()’, o para representar la última numeración de una sección o figura en un comando `ref()’.
`langle()’
Carácter <
`languagedutch()’
Define los encabezados específicos del idioma holandés. Activa esta macro a través de `setlanguage(dutch)’.
`languageenglish()’
Define los encabezados específicos del idioma inglés. Activa esta macro a través de `setlanguage(english)’.
`languageportugese()’
Define los encabezados específicos del idioma portugués. Activa esta macro a través de `setlanguage(portugese)’.
`LaTeX()’
El símbolo de LaTeX.
`latexaddlayout(arg)’
Esta macro se proporciona para añadir texto interpretado por Yodl a sus propios comandos de diseño de LaTeX. El comando se termina con un fin de línea. Ver también la macro `latexlayoutcmds()’.
`latexcommand(cmd)’
Escribe `cmd’ más un espacio en blanco a la salida al convertir a LaTeX. `cmd’ no se expande más por Yodl.
`latexdocumentclass(class)’
Fuerza la configuración de `\documentclass{...}’ de LaTeX a `class’. Normalmente la clase se define por las macros `article()’, `report()’ o `book()’. Esta macro es una ruta de escape en caso de que necesite especificar su propia clase de documento para LaTeX. Esta opción es un *modificador* y debe aparecer *antes* de las macros `article()’, `report()’ o `book()’.
`latexlayoutcmds(NOTRANSs)’
Esta macro se proporciona en caso de que desee incluir sus propios comandos de diseño de LaTeX en la salida de LaTeX. Los `NOTRANSs’ se pegan justo después del bloque `\documentclass’. El valor predeterminado es, por supuesto, ningún comando local de LaTeX. Tenga en cuenta que esta macro **no** anula mi diseño favorito de LaTeX. Use `nosloppyhfuzz()’ y `standardlayout()’ para deshabilitar mi diseño favorito de LaTeX.
`latexoptions(options)’
Establece opciones de latex: `documentclass[options]’. Este comando **debe** aparecer antes de que se establezca el tipo de documento mediante `article()’, `report()’, etc..
`latexpackage(options)(name)’
Incluye paquete(s) de latex, un paquete útil es, por ejemplo, `epsf’. Este comando **debe** aparecer antes de que se establezca el tipo de documento mediante `article()’, `report()’, etc..
`lchapter(label)(title)’
Inicia un nuevo capítulo en libros o informes, estableciendo una etiqueta al principio del capítulo.
`letter(language)(date)(subject)(opening)(salutation)(author)’
Inicia una carta escrita en el idioma indicado. La fecha de la carta se establece en `date’, el asunto de la carta será `subject’. La carta comienza con `opening’. Se basa en la definición de la clase de documento `letter.cls’. La macro está disponible solo para LaTeX. Sugerencias de comandos para el preámbulo:
o
`latexoptions(11pt)’

Usa `l’ para alineación izquierda, `c’ para alineación centrada y `r’ para alineación derecha. Las celdas individuales de la tabla pueden anular estas configuraciones predeterminadas usando las macros `tac’ y `tnac’.
Su segundo argumento define el contenido de la tabla que consiste en filas (usando `tr’) y líneas horizontales (usando `tline’), que pueden extenderse por todo el ancho de la tabla o pueden cubrir una o más columnas individuales. Las tablas definidas por la macro `tbl’ se centran (se usa centrado pseudo (8 espacios) para la conversión `txt’) cuando se usan como argumento de la macro `center’.
Ver también la macro `tao’ para obtener información sobre cómo realizar alineaciones específicas para tipos de conversión específicos.

`tline(numInicio)(numFin)’
Esta macro se usa para insertar una línea horizontal que abarca una o más columnas de una tabla definida por la macro `tbl’.
Si `numFin’ no se especifica, y la llamada `tline’ no sigue a una llamada `line’ anterior en la que sí se especificó `numFin’, entonces se define una línea horizontal que abarca todo el ancho de la tabla (excepto cuando se convierte a texto plano en cuyo caso se escribe una línea de caracteres - (menos); si `numInicio’ no se especifica, entonces se escribe una línea de 60 - caracteres).
Si `numFin’ no se especifica, pero la llamada `tline’ sigue a llamadas `tline’ anteriores que sí especificaron `numFin’, entonces la fila actual se termina.
Si `numFin’ se especifica, entonces se establece una línea horizontal, comenzando en el número de columna `numInicio’ y continuando hasta el número de columna `numFin’. Tenga en cuenta que estos son *números*, no *desplazamientos*: `numInicio’ debe ser al menos 1, `numFin’ debe ser al menos igual a `numInicio’ y debe ser
igual o menor que el número de columnas en la tabla. Los valores `beginNr' de llamadas posteriores a `tline' se refieren a la misma fila que la primera llamada `tline', y deben superar `endNr' de la llamada `tline' anterior.
Ejemplos: 
    tline()()       establece una línea que abarca todo el ancho de la tabla
    tline(1)(1)     establece una línea en la columna 1
    tline(3)(4)     establece otra línea en las columnas 3 y 4
    tline()()       termina la línea anterior
    tline()()       establece una línea que abarca todo el ancho de la tabla

`verb%s(text)'
The `verb%s`-macro is used for longer pieces of text that should be included literally, e.g. source code listings. It is often used in conjunction with the `PUSHSUBST`- and `POPSUBST`-macros.
The text that is passed as argument to the `verborg’-macro appears literally on the output, albeit that `SUBST’ definitions are processed, usually in a teletype font (that depends on the output format). This macro is for larger chunks, e.g., listings.
