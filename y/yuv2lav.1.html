yuv2lav(1) Manual de herramientas MJPEG yuv2lav(1)

NOMBRE

yuv2lav - codifica flujos de fotogramas YUV crudos de lavtool en archivos MJPEG

SINOPSIS

yuv2lav [-f a|A|q|m] [-q num] [-b num] [-I num] [-m num] [-v num] [-w archivo] -o archivo-salida

DESCRIPCIÓN

yuv2lav es un codificador MJPEG simple para flujos de fotogramas YUV crudos tal como los emiten lav2yuv(1) o lavpipe(1), por ejemplo. Lee su entrada desde stdin y es capaz de escribir AVI y Quicktime.

OPCIONES

Las opciones de línea de comandos permiten especificar el nombre del archivo de salida, la calidad de codificación JPEG y la cantidad de memoria que se asignará para los datos comprimidos JPEG.

-o archivo-salida
Esta opción (obligatoria) establece el nombre del archivo al que yuv2lav escribirá su salida. Si el archivo de salida contiene un % (por ejemplo, archivo%02d.avi), la salida se escribirá en varios archivos si es necesario (archivo00.avi, archivo01.avi y así sucesivamente).
-f a|A|q
Esto establece el formato del archivo de salida, que debe ser uno de
 a - para salida de archivo AVI,
 A - para AVI con campos invertidos,
 q - para salida Quicktime o
AVI con campo invertido, por supuesto, solo tiene sentido si la entrada de yuv2lav es una fuente de video entrelazada y solo debería ser necesaria si experimenta problemas de inversión de fotogramas en su salida. Si no usa esta opción, yuv2lav establecerá el formato de salida a AVI si los últimos 3 caracteres son avi, o a Quicktime si usa mov. Si utiliza la opción -f, anula la configuración en el nombre del archivo.
-q num
Esta opción especifica la calidad de codificación JPEG que se pasa a libjpeg. El valor predeterminado es 80, num debe estar entre 24 y 100 inclusive (piénselo como valores porcentuales, aunque con un algoritmo de compresión con pérdida como JPEG, mantener el 100% de la calidad original es, por supuesto, realmente imposible).
-b num
Esta opción especifica el tamaño del búfer (en kBytes) que yuv2lav asigna para almacenar los datos comprimidos JPEG. El valor predeterminado (256k) es perfectamente suficiente para PAL/NTSC a pantalla completa con calidad del 100%, pero si desea comprimir Super-Mega-HDTV o si tiene poca memoria, puede usar esta opción para adaptarla a sus necesidades.
-m num
Este es el tamaño máximo (en MB) por archivo. Normalmente esto depende del tipo de archivo de salida.
-I num
Forzar un tipo de entrelazado específico. 0 significa sin entrelazado, 1 significa campo superior primero, 2 significa campo inferior primero.
-w archivo
Este es el archivo WAV que contiene datos de audio para combinarlos con el flujo de video en el archivo de salida.
-v num
Nivel de verbosidad. 0 significa solo mostrar mensajes de error, 2 muestra una salida de depuración completa.
-?
Mostrar una sinopsis de la sintaxis del comando.

EJEMPLOS

lav2yuv movie.avi | yuv2lav -fq -q 30 lowbitrate.qt
recomprimiría movie.avi como un archivo Quicktime de baja tasa de bits.
lavpipe input.pli | yuv2lav -q80 output.avi
guardaría la película ensamblada por lavpipe como un único archivo AVI.
