NOMBRE

yuvinactive - Establece una parte del video a un estado definido

SINOPSIS

yuvinactive [opciones] </dev/stdin >/dev/stdout

DESCRIPCIÓN

yuvinactive opera con un área (rectángulo) que tú defines. Por defecto, la establece a negro. Pero puedes indicar a yuvinactive que oscurezca el área o la rellene con un color determinado. También puede hacer que el contenido del área sea ilegible, como un suavizado extremo del área. O copiar el área circundante al área especificada. Normalmente, debes usar la opción -i, que establece el área en la que trabajará yuvinactive. Si no se proporciona ninguna opción adicional, yuvinactive establece el área a negro. Pero puedes usar las opciones -d -s -a -c para indicar a yuvinactive que haga algo diferente con esa área. Solo puedes usar una opción adicional. yuvinactive fue creado para eliminar elementos no deseados de la película, como un logo.

OPCIONES

lav2yuv acepta las siguientes opciones:

-h
Muestra información de ayuda
-iXxY+XOFF+YOFF
Especifica el área en la que trabajará yuvinactive. Con esta opción, el área se establece a negro. No hay restricciones debido al entrelazado.
-d num
Cuánto más oscuro debe ser el área en comparación con el color original. Esto se hace estableciendo un valor más bajo para la luminancia. El valor está en porcentaje de la luminancia original.
-s num
Aquí especificas un color determinado en formato yuv.
-a num
Con esta opción, el programa utiliza un píxel y promedia los píxeles circundantes con el mismo color para hacer el original menos legible. El número indica al programa cuántos píxeles alrededor del píxel original deben sobrescribirse con el mismo color. Debes usar un número par aquí.
-c num
Establece el número de píxeles circundantes que yuvinactive debe usar para copiarlos en el área dada. Debes usar un número par aquí. yuvinactive utiliza las líneas por encima y por debajo del área especificada para copiarlas en el área.

BUGS

Así es, hay errores ocultos. La cosa no está bien probada, y es posible que no todas las opciones funcionen. yuvinactive está en la primera etapa de convertirse en un programa útil.
