YAZ-MARCDUMP(1) Comandos YAZ-MARCDUMP(1)

NOMBRE

yaz-marcdump - Utilidad para volcar registros MARC

SINOPSIS

yaz-marcdump [-i formato] [-o formato] [-f desde] [-t a] [-l espéc] [-c archivo_c] [-s prefijo] [-C tamaño] [-O desplazamiento] [-L límite] [-n] [-p] [-r] [-v] [-V] [archivo...]

DESCRIPCIÓN

yaz-marcdump lee registros MARC de uno o más archivos. Analiza cada registro y admite la salida en formato de línea, ISO2709, MARCXML[1], MARC-in-JSON[2], MarcXchange[3], así como salida Hexadecimal.

Esta utilidad analiza registros en formato ISO2709 (MARC crudo), formato de línea, MARC-in-JSON, así como XML si está estructurado como MARCXML/MarcXchange.

La codificación/decodificación MARC-in-JSON es compatible en YAZ 5.0.5 y versiones posteriores.


Nota

A partir de YAZ 2.1.18, OAI-MARC ya no es compatible. OAI-MARC está obsoleto. Utilice MARCXML en su lugar.

Por defecto, cada registro se escribe en la salida estándar en un formato de línea con un salto de línea para cada campo, $x para cada subcampo x. El formato de salida se puede cambiar con la opción -o.

yaz-marcdump también puede solicitar la conversión de conjuntos de caracteres de cada registro.

OPCIONES

-i formato

Especifica el formato de entrada. Debe ser uno de marcxml, marc (ISO2709), marcxchange (ISO25577), line (MARC en modo línea), turbomarc (Turbo MARC), o json (MARC-in-JSON).

-o formato

Especifica el formato de salida. Debe ser uno de marcxml, marc (ISO2709), marcxchange (ISO25577), line (MARC en modo línea), turbomarc (Turbo MARC), o json (MARC-in-JSON).

-f desde

Especifica el conjunto de caracteres del registro MARC de entrada. Debe usarse junto con la opción -t. Consulte la página del manual de yaz-iconv para ver los conjuntos de caracteres compatibles.

-t a

Especifica el conjunto de caracteres de salida. Debe usarse junto con la opción -f. Consulte la página del manual de yaz-iconv para ver los conjuntos de caracteres compatibles.

-l espéc_líder

Especifica una cadena de modificación simple para el líder MARC. espéc_líder es una lista de pares pos=valor, donde pos es un desplazamiento entero (0 - 23) para el líder. Valor es una cadena entre comillas o un entero (valor de carácter en decimal). Los pares están separados por comas. Por ejemplo, para establecer el líder en el desplazamiento 9 a, use 9='a'.

-s prefijo

Escribe un fragmento de registros en un archivo separado con el prefijo dado, es decir, divide un lote de registros en archivos con como máximo "chunk" registros ISO2709 por archivo. Por defecto, chunk es 1 (un registro por archivo). Ver opción -C.

-C tamaño_chunk

Especifica el tamaño del fragmento; para ser utilizado en conjunción con la opción -s.

-O desplazamiento

Desplazamiento entero para la posición en la que se escribirán los registros. 0=primer registro, 1=segundo, ... Con la opción -L, esto permite procesar un rango específico de registros.

-L límite

Límite entero de cuántos registros como máximo se escribirán. Con la opción -O, esto permite procesar un rango específico de registros.

-p

Hace que yaz-marcdump imprima el número de registro y el desplazamiento del archivo de entrada de cada registro leído.

-n

La salida MARC se omite para que solo se verifique la entrada MARC.

-r

Escribe en stderr un resumen del número de registros leídos por yaz-marcdump.

-v

Escribe más información sobre el proceso de análisis. Útil si tiene registros ISO2709 mal formateados como entrada.

-V

Imprime la versión de YAZ.

EJEMPLOS

El siguiente comando convierte MARC21/USMARC en codificación MARC-8 a MARC21/USMARC en codificación UTF-8. El desplazamiento del líder 9 se establece en 'a'. Tanto la entrada como la salida de registros están codificadas en ISO2709.

    yaz-marcdump -f MARC-8 -t UTF-8 -o marc -l 9=97 marc21.raw >marc21.utf8.raw

Los mismos registros pueden convertirse a MARCXML en UTF-8:

    yaz-marcdump -f MARC-8 -t UTF-8 -o marcxml marc21.raw >marcxml.xml

Turbo MARC es una notación XML compacta con la misma semántica que MARCXML, pero que permite un procesamiento más rápido a través de XSLT. Para generar registros Turbo MARC codificados en UTF-8 desde MARC21 (ISO), se podría usar:

    yaz-marcdump -f MARC8 -t UTF8 -o turbomarc -i marc marc21.raw >out.xml
