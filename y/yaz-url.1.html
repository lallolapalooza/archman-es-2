NOMBRE

yaz-url - Utilidad de obtención de URL de YAZ

SINOPSIS

yaz-url [-H nombre:valor] [-m método] [-O nombrearchivo] [-p nombrearchivo] [-R num] [-u usuario/contraseña] [-v] [-x proxy] [url...]

DESCRIPCIÓN

yaz-url es una utilidad para obtener contenido web. Es muy limitada en funcionalidad en comparación con programas como curl, wget.

Las opciones deben preceder a la URL dada en la línea de comandos para que surtan efecto.

El contenido HTTP obtenido se escribe en la salida estándar, a menos que se proporcione la opción -O.

OPCIONES

-H nombre:valor

Especifica el contenido de la cabecera HTTP con nombre y valor. Esta opción se puede dar varias veces (para nombres diferentes, por supuesto).

-m método

Especifica el método HTTP que se utilizará para la siguiente URL. El valor predeterminado es el método "GET". Sin embargo, la opción -p lo establece a "POST".

-O nombrearchivo

Establece el nombre del archivo de salida para el contenido HTTP.

-p nombrearchivo

Establece un archivo para ser enviado en el método POST en la siguiente URL.

-R num

Establece el número máximo de redirecciones HTTP a seguir. Un valor de cero deshabilita el seguimiento de redirecciones HTTP.

-u usuario/contraseña

Especifica un usuario y una contraseña a utilizar en la autenticación básica HTTP en la siguiente obtención de URL. El usuario y la contraseña deben estar separados por una barra (por lo tanto, no es posible especificar un usuario con una barra en él).

-v

Hace que yaz-url muestre cada solicitud/respuesta HTTP en la salida estándar.

-x proxy

Especifica un proxy a utilizar para la obtención de la URL.
