NOMBRE

yarac - compilar reglas a yara

SINOPSIS

yarac [OPCIÓN]... [ARCHIVO_REGLAS]... ARCHIVO_SALIDA

DESCRIPCIÓN

Para invocar YARA necesitarás dos cosas: un archivo con las reglas que quieres usar (en código fuente o en forma compilada) y el objetivo a ser escaneado. El objetivo puede ser un archivo, una carpeta o un proceso.

Los archivos de reglas se pueden pasar directamente en forma de código fuente o se pueden compilar previamente con la herramienta yarac. Puede preferir usar sus reglas en forma compilada si va a invocar YARA varias veces con las mismas reglas. De esta manera ahorrará tiempo, ya que para YARA es más rápido cargar reglas compiladas que compilar las mismas reglas una y otra vez.

Las reglas se aplicarán al objetivo especificado como el último argumento de YARA; si es una ruta a un directorio, todos los archivos contenidos en él serán escaneados.

OPCIONES

-d <identificador>=<valor>
definir variable externa.
-w --no-warnings
Desactivar advertencias.
--fail-on-warnings
Tratar las advertencias como errores. No tiene efecto si se usa con --no-warnings.
-v --version
Mostrar información de la versión.

EJEMPLO

La opción -d se usa para definir variables externas. Por ejemplo:

-d flag=true

-d beast=666

-d name="James Bond"
