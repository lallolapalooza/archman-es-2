YDOTOOL(1) Manual de Comandos Generales YDOTOOL(1)

NOMBRE

ydotool - herramienta de automatización de /dev/uinput en línea de comandos

SINOPSIS

ydotool cmd args

ydotool cmd --help

DESCRIPCIÓN

ydotool te permite simular programáticamente (o manualmente) la entrada del teclado y la actividad del ratón, etc. El demonio ydotoold(8) debe estar en ejecución.

Comandos implementados actualmente:

type

Escribe una cadena
key
Presiona teclas
mousemove
Mueve el puntero del ratón a una posición absoluta
click
Hace clic en los botones del ratón

COMANDOS DE TECLADO

key [-d,--key-delay <ms>] [<KEYCODE:PRESIONADO> ...]

Escribe un código de tecla dado.

p. ej., 28:1 28:0 significa presionar el botón Enter en un teclado estándar de EE. UU. (donde :1 para presionado significa que la tecla está abajo y luego :0 significa que la tecla está liberada)

42:1 38:1 38:0 24:1 24:0 38:1 38:0 42:0 - "LOL"

Los valores no interpretables, como 0, aaa, l0l, solo causarán un retraso.

Consulta `/usr/include/linux/input-event-codes.h' para ver los códigos de tecla disponibles (KEY_*).

Puedes encontrar el nombre/número de tecla que tu teclado está enviando a libinput ejecutando `sudo libinput record` y luego seleccionando tu teclado de la lista; te mostrará el nombre y número de tecla propio de libinput para cada tecla que presiones.

Opciones: -d,--key-delay <ms>

Tiempo de espera entre pulsaciones de teclas. Por defecto 12ms.

type [-D,--next-delay <ms>] [-d,--key-delay <ms>] [-f,--file <rutaarchivo>] "texto"

Escribe texto como si lo hubieras escrito en el teclado.

Opciones:

-d,--key-delay <ms>

Tiempo de espera entre eventos de tecla (arriba/abajo cada uno). Por defecto 12ms.

-D,--next-delay <ms>

Tiempo de espera entre cadenas. Por defecto 0ms.

-f,--file <rutaarchivo>

Especifica un archivo, cuyo contenido se escribirá como si se pasara como argumento. La ruta del archivo también puede ser '-' para leer desde la entrada estándar.

Ejemplo: para escribir 'Hola mundo!' harías:

ydotool type 'Hola mundo!'

COMANDOS DE RATÓN

mousemove [-a,--absolute] <x> <y>

Mueve el ratón a las coordenadas X e Y relativas en la pantalla.

Opciones: --absolute

Usa posición absoluta

Ejemplo: para mover el cursor a las coordenadas absolutas (100,100):

ydotool mousemove --absolute 100 100

click [-d,--next-delay <ms>] [-r,--repeat N ] [botón ...]

Envía un clic.

Opciones: -d,--next-delay <ms>

Tiempo de espera entre eventos de entrada (arriba/abajo, un clic completo significa tiempo duplicado). Por defecto 25ms.

-r,--repeat N

Repite la secuencia completa N veces

Todos los botones del ratón se representan utilizando valores numéricos hexadecimales, con una máscara de bits opcional para especificar si se debe omitir el clic de ratón arriba/abajo.

  • 0x00 - IZQUIERDO
  • 0x01 - DERECHO
  • 0x02 - MEDIO
  • 0x03 - LATERAL
  • 0x04 - EXTR
  • 0x05 - ADELANTE
  • 0x06 - ATRÁS
  • 0x07 - TAREA
  • 0x40 - Botón abajo del ratón
  • 0x80 - Botón arriba del ratón
Ejemplos:
  • 0x00: elige el botón izquierdo, pero no hace nada (puedes usar esto para implementar pausas adicionales)
  • 0xC0: clic con el botón izquierdo (abajo luego arriba)
  • 0x41: botón derecho abajo
  • 0x82: botón medio arriba

El prefijo '0x' puede omitirse si lo deseas.

SOCKET DE YDOTOOL

El socket al que escribir para ydotoold(8) puede cambiarse mediante la variable de entorno YDOTOOL_SOCKET.
