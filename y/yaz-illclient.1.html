YAZ-ILLCLIENT(1) Comandos YAZ-ILLCLIENT(1)

NOMBRE

yaz-illclient - Cliente ILL

SINOPSIS

yaz-illclient [-f nombre_archivo] [-v nivel_log] [-D nombre=valor...] [-o] [-u usuario] [-p contraseña] [-V] [direccion_servidor]

DESCRIPCIÓN

yaz-illclient es un cliente que envía una solicitud ISO ILL a un servidor remoto y decodifica la respuesta del mismo. Se debe especificar exactamente una dirección de servidor ( direccion_servidor ).

OPCIONES

-f nombre_archivo]

Especificar nombre de archivo.

-v nivel_log]

Especificar el nivel de registro.

-D nombre=valor]

Define un par de nombre y valor.

-o

Habilitar autenticación OCLC.

-u usuario]

Especificar usuario.

-p contraseña]

Especificar contraseña.

-V

Mostrar la versión de yaz-illclient.
