NOMBRE

yubikey-personalization-gui - personaliza tokens OTP de YubiKey

SINOPSIS

yubikey-personalization-gui

DESCRIPCIÓN

Interfaz gráfica para la configuración de tokens OTP de YubiKey. Hay ayuda disponible dentro del programa.

ERRORES

Reporta los errores de yubikey-personalization-gui en el rastreador de problemas ⟨URL: https://github.com/Yubico/yubikey-personalization-gui/issues ⟩

VER TAMBIÉN

Las YubiKeys se pueden obtener de Yubico ⟨URL: https://www.yubico.com/ ⟩.
