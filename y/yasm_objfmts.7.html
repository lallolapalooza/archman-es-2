YASM_OBJFMTS(7) Formatos de Objeto Soportados por Yasm YASM_OBJFMTS(7)

NOMBRE

yasm_objfmts - Formatos de objeto soportados por Yasm

SINOPSIS

yasm -f formato_objeto ...

DESCRIPCIÓN

La distribución estándar de Yasm incluye una serie de módulos para diferentes formatos de objeto (la salida principal de Yasm).

El formato de objeto se selecciona en la línea de comandos de yasm(1) mediante la opción de línea de comandos -f formato_objeto.

BIN

El formato de objeto "bin" produce un archivo binario de formato plano, no relocable. Es apropiado para producir ejecutables .COM de DOS o cosas como bloques de arranque. Solo soporta 3 secciones y estas secciones se escriben en un orden predefinido en el archivo de salida.

COFF

El formato de objeto COFF es un formato de objeto relocable más antiguo utilizado en sistemas Unix y compatibles más antiguos, y también (más recientemente) en el sistema de desarrollo DJGPP para DOS.

DBG

El formato de objeto "dbg" no es un formato de objeto "real"; el archivo de salida que crea simplemente describe la secuencia de llamadas hechas a él por Yasm y la información final del objeto y de la tabla de símbolos en un formato de texto legible por humanos (que en un formato de objeto normal se procesaría en la representación binaria particular de ese formato de objeto). Este formato de objeto no está destinado a un uso real, sino a la depuración de los internos de Yasm.

ELF

El formato de objeto ELF viene realmente en tres sabores: "elf32" (para objetivos de 32 bits), "elf64" (para objetivos de 64 bits y "elfx32" (para objetivos x32). ELF es un formato de objeto estándar de uso común en sistemas Unix modernos y compatibles (por ejemplo, Linux, FreeBSD). ELF tiene un soporte complejo para objetos relocables y compartidos.

MACHO

El formato de objeto Mach-O viene realmente en dos sabores: "macho32" (para objetivos de 32 bits) y "macho64" (para objetivos de 64 bits). Mach-O se utiliza como formato de objeto en MacOS X. Como Yasm actualmente solo soporta los conjuntos de instrucciones x86 y AMD64, solo puede generar objetos Mach-O para Macs basados en Intel.

RDF

El formato de objeto RDOFF2 es un formato simple multisección diseñado originalmente para NASM. Soporta referencias de segmento pero no referencias WRT. Fue diseñado principalmente para la simplicidad y tiene cabeceras minimalistas para facilitar la carga y el enlace. Una cadena de herramientas completa (enlazador, archivador y cargador) se distribuye con NASM.

WIN32

El formato de objeto Win32 produce archivos objeto compatibles con compiladores de Microsoft (como Visual C++) que se dirigen a la plataforma Windows de 32 bits x86. El formato de objeto en sí es una versión extendida de COFF.

WIN64

El formato de objeto Win64 produce archivos objeto compatibles con compiladores de Microsoft que se dirigen a la plataforma Windows de 64 bits "x64". Este formato es muy similar al formato de objeto win32, pero produce objetos de 64 bits.

XDF

El formato de objeto XDF es esencialmente una versión simplificada de COFF. Es un formato relocable multisección que soporta direcciones físicas y virtuales de 64 bits.
