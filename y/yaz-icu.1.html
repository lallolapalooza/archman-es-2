NOMBRE

yaz-icu - Utilidad YAZ ICU

SINOPSIS

yaz-icu [-c config] [-p opt] [-s] [-x] [archivo_entrada]

DESCRIPCIÓN

yaz-icu es una utilidad que demuestra el módulo de cadena ICU de yaz (yaz/icu.h).

La utilidad puede usarse de dos maneras. Puede leer algún texto utilizando una configuración XML para configurar ICU y mostrar análisis de texto. Este modo se activa mediante la opción -c que especifica la configuración a utilizar. El archivo de entrada se lee desde la entrada estándar o desde un archivo si se especifica archivo_entrada.

La utilidad también puede mostrar información de ICU. Esto se activa mediante la opción -p.

OPCIONES

-c config

Especifica el archivo que contiene la configuración de cadena ICU, basada en XML.

-p tipo

Especifica información adicional a imprimir sobre el sistema ICU. Si tipo es c, se imprimen los conversores ICU. Si tipo es l, se imprimen las locales disponibles. Si tipo es t, se imprimen los transliteradores disponibles.

-s

Especifica que la salida también debe incluir la clave de ordenación. Tenga en cuenta que la clave de ordenación difiere entre versiones de ICU.

-x

Especifica que la salida debe basarse en XML en lugar de basarse en "texto".

CONFIGURACIÓN DE CADENA ICU

La configuración de cadena ICU especifica una o más reglas para convertir datos de texto en tokens. El formato de configuración se basa en XML.

El elemento raíz debe llamarse icu_chain. El elemento icu_chain tiene un atributo requerido locale que especifica la locale ICU a usar en los pasos de conversión.

El elemento icu_chain debe incluir elementos donde cada elemento especifica un paso de conversión. La conversión se realiza en el orden en que se especifican los pasos de conversión. Cada elemento de conversión toma un atributo: rule, que sirve como argumento para el paso de conversión.

Los siguientes elementos de conversión están disponibles:

casemap

Convierte mayúsculas/minúsculas (y la regla especifica cómo):

l

Minúscula, usando la función ICU u_strToLower.

u

Mayúscula, usando la función ICU u_strToUpper.

t

A título, usando la función ICU u_strToTitle.

f

Doblar mayúsculas/minúsculas, usando la función ICU u_strFoldCase.

display

Este es un paso meta que especifica que un término/token debe mostrarse. Este término se recupera en una aplicación utilizando la función icu_chain_token_display (yaz/icu.h).

transform

Especifica una regla de transformación ICU usando un Identificador de transliterador. El atributo rule es el Identificador del transliterador. Ver ICU Transforms[1] para más información.

transliterate

Especifica un transliterador basado en reglas. El atributo rule es la regla de transformación personalizada a utilizar. Ver ICU Transforms[1] para más información.

tokenize

Divide una cadena en componentes utilizando las funciones ICU ubrk_open, ubrk_setText, ... La regla es una de las siguientes:

l

Línea. ICU: UBRK_LINE.

s

Oración. ICU: UBRK_SENTENCE.

w

Palabra. ICU: UBRK_WORD.

c

Carácter. ICU: UBRK_CHARACTER.

t

Título. ICU: UBRK_TITLE.

join

Une tokens en una sola cadena. El atributo rule es la cadena de unión, que puede estar vacía. El elemento de conversión join se añadió en YAZ 4.2.49.

EJEMPLOS

El siguiente comando analiza texto en el archivo text usando la configuración de cadena ICU chain.xml:

    cat text | yaz-icu -c chain.xml

chain.xml podría verse así:

<icu_chain locale="en">
  <transform rule="[:Control:] Any-Remove"/>
  <tokenize rule="w"/>
  <transform rule="[[:WhiteSpace:][:Punctuation:]] Remove"/>
  <transliterate rule="xy > z;"/>
  <display/>
  <casemap rule="l"/>
</icu_chain>
