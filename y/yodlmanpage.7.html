NOMBRE

yodlmanpage - Tipo de documento `manpage’ de Yodl

SINOPSIS

El tipo de documento manpage fue implementado específicamente para escribir páginas de manual de estilo Unix. Otros formatos de documento de Yodl, como article, report y book, se documentan en la guía de Yodl y en la página de manual de yodlmacros.

DESCRIPCIÓN

Esta página de manual describe brevemente el tipo de documento manpage del lenguaje de documentos Yodl. Este tipo de documento es lo suficientemente específico como para merecer su propia página de manual.

Los documentos manpage de Yodl pueden ser convertidos a documentos `groff’ (usando `yodl2man’), a documentos `html’ (usando `yodl2html’), o a documentos de texto plano ascii (usando `yodl2txt’).

Los documentos manpage no utilizan los comandos de sección `estándar’ (por ejemplo, sect() y subsect()), sino que tienen macros específicas manpage...(). Sin embargo, puede usar (y se le anima a ello) otras macros `normales’, como description(...) o itemization(...) para listas, o bf() para negrita y em() para énfasis. En cuanto a las fuentes, se sugiere lo siguiente:

o
Use em(texto) cuando texto sea una variable, o un marcador de posición, etc..
o
Use bf(texto) cuando texto sea literal, como un comando, un nombre de archivo, un directorio. Cada documento manpage en Yodl debe organizarse de la siguiente manera:
o
manpage(nombre) (sección) (fecha) (paquete) (fuente): Este es el preámbulo del documento. Indica lo que la página describe, la sección a la que pertenece, la fecha de lanzamiento, el paquete al que pertenece y la fuente del paquete. El número de sección debe ser (según la página de manual de Linux sobre man): 1 para comandos, 2 para llamadas al sistema, 3 para llamadas de biblioteca, 4 para archivos especiales, 5 para formatos de archivo, 6 para juegos, 7 para paquetes de macros y convenciones, 8 para comandos de administración del sistema, y 9 para otros temas especiales (por ejemplo, comandos del kernel).
o
manpagename(nombre) (descripción corta): El nombre es nuevamente lo que se describe, la descripción corta es lo que, por ejemplo, utiliza la base de datos whatis para descripciones.
o
manpagesynopsis(): información de `uso’ muy corta o similar. Mantenga esta sección corta, por ejemplo, una línea con todas las opciones del programa es aceptable pero sin descripciones (estas vienen después).
o
manpagedescription(): el propósito del programa y demás. Este es también el lugar para documentar su funcionamiento.
o
manpageoptions(): Este es el lugar para documentar, por ejemplo, las banderas que se indican en manpagesynopsis(). Esta sección es opcional, pero si está presente, debe aparecer en este lugar.
o
manpagefiles(): los archivos relevantes se describen en esta sección.
o
manpageseealso(): esta sección enumera las páginas de manual relacionadas.
o
manpagediagnostics(): Condiciones de error, mensajes de error, etc..
o
manpagebugs(): Aquí se describen los errores conocidos. Esta sección es opcional.
o
manpageauthor(): indicando el autor y/o el mantenedor.
o
manpagesection(NOMBRE): Esta macro inicia una sección genérica, no requerida. Por ejemplo, podría querer una manpagesection(EJEMPLOS) en su documento. Como sugerencia tipográfica, use mayúsculas para el argumento NOMBRE por razones de consistencia.
