YAPS(1) Manual de comandos generales YAPS(1)

NOMBRE

YAPS - convierte un archivo abc a un archivo PostScript

SINOPSIS

yaps archivo.abc [-d] [-e <lista>] [-E] [-l] [-M XXXxYYY] [-N] [-k nn] [-o nombre_archivo] [-P -ss] [-s XX] [-V][-ver] [-x] [-OCC]

OPCIONES

-d
Solo para depuración. Muestra las estructuras de datos internas utilizadas en el programa.
-e <lista>
Dibuja melodías con números de referencia en una lista separada por comas. No se permiten espacios, pero se puede especificar un rango de números de referencia. Por ejemplo, 1,3,7-10.
-E
Genera salida PostScript encapsulada.
-M XXXxYYY
Establece los márgenes en puntos, donde 28.3 puntos = 1 cm y 72 puntos = 1 pulgada.
-N
Añade numeración de página.
-k [nn]
Añade numeración de compás. Si se incluye el número nn, entonces se numera cada nn compás. De lo contrario, se numeran todos los compases.
-o nombre_archivo
Especifica el nombre del archivo postscript de salida.
-P ss
Especifica el tamaño del papel, donde 0 es A4 y 1 es US Letter, o XXXxYYY establece el tamaño del papel en unidades de puntos.
unidades.
-s XX
Especifica el factor de escala (por defecto es 0.7)
-V
Las voces se imprimen por separado para una melodía con múltiples voces. De lo contrario, se intercalan.
se intercalan.
-ver
Imprime el número de versión y sale.
-x
Imprime el número de melodía en el campo X:
-OCC
Requerido si la melodía utiliza la convención antigua para los acordes delineados con +..+ en lugar de [...].

CARACTERÍSTICAS

* Utiliza el código de análisis de abc2midi, por lo que se espera una buena compatibilidad con abc2midi.

* Mide el ancho del texto de la letra para la composición tipográfica de las letras.

* Utiliza estructuras de datos extensibles dinámicamente en la mayoría de los lugares, por lo que no deberías estar limitado por límites compilados.

* Múltiples voces dibujadas con notas tocadas al mismo tiempo alineadas.

* Admite caracteres especiales utilizando la fuente latina 1 de ISO. Los caracteres especiales se crean con un código similar a TeX, por ejemplo, ´E o un código octal de 3 dígitos, por ejemplo, 315.

* Admite las siguientes claves: barítono, tenor, contralto, mezzosoprano, soprano, agudo, bajo. El uso recomendado es

* Los silencios invisibles (x) se muestran como silencios normales.

* Se aceptan identificadores de voz no numéricos, por ejemplo, V: soprano.


I:clef=bass

Para facilitar la entrada de melodías en claves distintas a la clave de agudos, yaps admite I:octave=-1 para indicar que un Do en la melodía representa la nota una octava por debajo del tono definido en el estándar abc. Estos pueden combinarse en una única declaración I:, por ejemplo,

I:clef=bass octave=-2

También puede usar claves que estén una, dos o tres octavas más altas o más bajas de lo normal usando, por ejemplo, treble-8, treble+15, treble-22. La clave se dibuja con un pequeño 8, 15 o 22 encima o debajo del símbolo de clave. Los comandos clef= y octave= también pueden ir en el campo K:, por ejemplo,

K:G clef=bass-8 octave=-3

Tenga en cuenta que existe una incompatibilidad entre el comportamiento de yaps y el comportamiento de abc2ps 1.3.3. abc2ps 1.3.3 no admite el comando I:octave=N, pero la selección de ciertas claves hace que transponga automáticamente varias octavas. Puede producir un archivo abc que funcione para ambos siguiendo el cambio de clave con un comando I:octave=N para realizar la transposición que abc2ps hace automáticamente.

* Produce etiquetas de parte enmarcadas.

* Admite el símbolo segno con !segno! y coda con !coda!. Otras instrucciones musicales como !fine! y !D.C.! aparecen como texto. * Admite el campo U: para abreviar símbolos a un solo carácter. por ejemplo,

U:S = !segno!

permite usar S para producir el símbolo segno. Actualmente, esto solo permite definir nuevos símbolos y no permite alterar los símbolos predefinidos existentes M, L, R, H y T.

* Admite las instrucciones !red! y !black! para cambiar de negro a rojo o viceversa.

* Admite las siguientes extensiones de abc2ps para abc:

Si %%text o %%centre aparecen en el encabezado, el texto aparece encima

coloca el título a la izquierda mientras que N = 0 lo centra.
%%titlecaps - el título se muestra en mayúsculas.
%%textfont NOMBRE TAMAÑO - selecciona la fuente llamada NOMBRE y el tamaño en puntos TAMAÑO
para el texto producido por %%text o %%centre. Si solo se da el NOMBRE, la

solo cambia el tamaño de la fuente.
%%titlefont NOMBRE TAMAÑO - selecciona la fuente para el título.
%%subtitlefont NOMBRE TAMAÑO - selecciona la fuente para los títulos posteriores al primer

%%wordsfont NOMBRE TAMAÑO - selecciona la fuente para las palabras en los campos W:.
%%partsfont NOMBRE TAMAÑO - selecciona la fuente para las partes enmarcadas y
!instrucción!.
%%vocalfont NOMBRE TAMAÑO - selecciona la fuente para las palabras en los campos w:.
%%gchordfont NOMBRE TAMAÑO - selecciona la fuente para los acordes de guitarra en la música.
(Es aconsejable no cambiar el nombre de la fuente para los dos últimos, ya que
el programa calcula el ancho de las cadenas utilizando fuentes predeterminadas)
%%titlespace, %%subtitlespace, %%textspace, %%composerspace,
%%wordsspace, %%partsspace, %%vocalspace y %%gchordspace
determinan la cantidad de espacio dejada encima del tipo relevante
de texto. Cada uno de ellos debe ir seguido de un tamaño en puntos
o un valor en centímetros o pulgadas.
por ejemplo, %%composerfont 3
%%titlefont 2cm

* Admite la colocación de acordes de acompañamiento encima o debajo del pentagrama.
%%chordsabove - coloca los acordes de acompañamiento encima del pentagrama
(predeterminado).
%%chordsbelow - coloca los acordes de acompañamiento debajo del pentagrama.

* Admite texto opcional encerrado entre comillas antes y después de la especificación del tempo en el campo Q:. Esta extensión proviene de
abc2ps.

YAPS - Yet Another PDF Signer

NAME
yaps - yet another pdf signer
SYNOPSIS

yaps [options] input.pdf output.pdf certificate.p12

DESCRIPTION

yaps is a command-line tool that adds a digital signature to a PDF document. It supports signing with certificates stored in PKCS#12 (.p12) files, which can contain both the certificate and its private key.

The tool allows for customization of the signature appearance, including the reason for signing, location, contact information, and an optional image to be displayed as the signature.

OPTIONS
-c, --reason reason
Sets the reason for signing the document. This text will be included in the signature's properties.
-l, --location location
Specifies the location where the document was signed. This will be part of the signature's properties.
-t, --contact contact
Provides contact information for the signer. This will also be included in the signature's properties.
-i, --image image.png
Specifies an optional image (e.g., a scanned signature) to be displayed on the PDF page where the signature is applied. The image should be in PNG format.
-s, --use-cert-alias alias
If the PKCS#12 file contains multiple certificates, this option allows you to specify which certificate's alias to use for signing.
-p, --password password
Provides the password for the PKCS#12 file. If not provided, yaps will prompt for it.
-d, --digest-algorithm algorithm
Specifies the digest algorithm to use for the signature. Common options include SHA1, SHA256, etc. Defaults to SHA256.
-v, --version
Displays the version of yaps and exits.
-h, --help
Shows a help message and exits.
FEATURES
  • Adds visible digital signatures to PDF documents.
  • Supports signing with PKCS#12 certificates.
  • Customizable signature appearance (reason, location, contact).
  • Option to include a signature image.
  • Password prompt for certificate protection.
  • Choice of digest algorithms.
